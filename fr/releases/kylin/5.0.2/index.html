#kylin kylin-5.0.2

Avec 6 votes contraignants (et 2 non contraignants), Apache Kylin 5.0.2 est publié. Les liens de téléchargement seront bientôt mis à jour sur le site Web.

Faits saillants du changement : Nouvelles fonctionnalités :

  • [KYLIN-5993] - Table interne Pour site Web
  • [KYLIN-5996] - Prise en charge du préchargement du cache de table interne
  • [KYLIN-6025] - Prise en charge de la fusion de fichiers dans les partitions pour les tables internes Amélioration :
  • [KYLIN-5995] - Récommandez le chargeur de pots de gluten
  • [KYLIN-6000] - Après le démarrage de Kylin, le fichier krb5cc_gluten est généré dans le répertoire au même niveau que Kylin_Home. L'emplacement de génération du fichier doit être ajusté.
  • [KYLIN-6009] - Le test de performances du API montre une diminution par rapport au Kylin4
  • [KYLIN-6020] - Ajout d'une configuration au niveau du système/au niveau du projet pour permettre l'interrogation directe des tables internes.
  • [KYLIN-6022] - Prise en charge du chargement incrémentiel parallèle pour les tables internes
  • [KYLIN-6024] - La mise en cache des métadonnées du gluten prend en charge RocksDB
  • [KYLIN-6030] - Style de nom d'attribut incohérent dans le message de réponse des tables
  • [KYLIN-6031] - Ajout d'une table interne OpenAPI pour prendre en charge l'affichage des détails d'une table interne spécifiée
  • [KYLIN-6033] - Lorsque vous répondez aux requêtes min et max à l'aide de métadonnées, dirigez-vous vers le moteur Calcite pour éviter de soumettre des tâches Spark.
  • [KYLIN-6039] - Optimisation des performances pour l'analyse SQL longue avec des paramètres dynamiques
  • [KYLIN-6051] - Nettoyage du code historique + Refactoring
  • [KYLIN-6052] - Les tables internes Kylin5 prennent en charge les vues logiques
  • [KYLIN-6053] - Ajout d'OpenAPI pour afficher les détails d'une table interne spécifiée
  • [KYLIN-6054] - Optimiser la logique d'élagage des partitions pour éviter les échecs de requête
  • [KYLIN-6060] - Ajout de méthodes de chargement distinctes pour différents types de stockage de tables internes
  • [KYLIN-6061] - Prise en charge de la création de fichiers d'index à l'aide de Gluten
  • [KYLIN-6068] - Nettoyage de la session de printemps pour éviter les avertissements de blocage MySQL
  • [KYLIN-6069] - [Tableau interne - Charge incrémentielle] Chevauchement des plages de temps interdites pour le chargement
  • [KYLIN-6071] - Prise en charge de la découverte de services JDBC
  • [KYLIN-6072] - Refactorisation du catalogue StorageV3 pour éviter les conflits avec le catalogue Iceberg
  • [KYLIN-6073] - Le bouton d'actualisation pour les tables internes non partitionnées dans le temps ne doit pas être grisé et le backend renvoie une erreur lors de l'actualisation Correction d'un bug : https://issues.apache.org/jira/projects/KYLIN/versions/12355670

Merci à tous ceux qui ont contribué à cette version. Voici les release note : https://issues.apache.org/jira/secure/ReleaseNote.jspa?version=12355670&styleName=Html&projectId=12316121

Le commit : https://github.com/apache/kylin/tree/kylin-5.0.2 (33cfb69)
