#AstrBot v4.14.3

Ce qui a changé

correctif de v4.14.0

correctif

  • Correction d'un problème où le hook on_llm_request pouvait ne pas être en mesure d'appliquer des effets
  • La fonction de réponse proactive de sensibilisation au contexte du chat de groupe peut ne pas être disponible en raison de l'obsolescence du event.request_llm()

Ce qui a changé - GRANDE ET BELLE VERSION

Si vous avez utilisé Skill dans la version précédente, vous devrez reconfigurer les options liées à Skill Runtime après cette mise à jour.

Nouveau

  • 🔥 Ajout du système de tâches futures. Attribuez des tâches futures à AstrBot afin qu'AstrBot puisse se réveiller automatiquement à un certain moment pour vous aider à terminer la tâche. Voir [Tâche active] (https://docs.astrbot.app/use/proactive-agent.html) pour plus de détails. (Expérimental) (#4697)
  • 🔥 Ajout de l'orchestrateur SubAgent. (Expérimental)(#4697)
  • 🔥 AstrBot peut actuellement transmettre des images/fichiers aux utilisateurs directement en appelant l'outil, améliorant considérablement l'effet d'interaction.
  • Ajout de la configuration d'exécution de l'utilisation de l'ordinateur pour fusionner les configurations Skill et Sandbox (#4831)
  • Ajout d'une fonction de personnalisation du thème, vous pouvez définir la couleur principale et la couleur auxiliaire
  • Prise en charge de l'édition de la personnalité dans la boîte de dialogue de personnalité sous la page de configuration (#4826)
  • Prend en charge la fonction « trace » du commutateur ; prise en charge de la configuration de l'écriture ou non des journaux dans le fichier journal dans la configuration du système (#4822)

Correction

  • ‼ ️ Correction des problèmes de rapport d'erreurs liés à missing 2 required positional arguments: 'filter1' and 'filter2' introduits dans les versions récentes.
  • ‼ ️ Correction du problème d'affichage anormal des images, pensées, etc. ChatUI.
  • ‼ ️Correction du problème selon lequel la compétence n'était pas automatiquement décompressée après avoir été téléchargée dans le bac à sable, empêchant l'agent de la lire.
  • ‼ ️ Correction du problème de filtrage des outils MCP lors de la configuration d'un ensemble de plug-ins spécifique (#4825)
  • ‼ ️ Supprimez l'invite fournie avec ChatUI pour laisser LLM poser enfin la question (#4824)
  • ‼ ️ Correction du bug où WebUI affiche toujours un message de réussite après l'échec du téléchargement de la compétence (#4768)
  • Correction du problème où le serveur MCP ne peut pas être renommé (#4766)
  • Correction du problème selon lequel l'outil plug-in ne peut pas voir la source dans le comportement de gestion WebUI (#4776)
  • ‼ ️ Correction du problème d'échec d'appel de l'outil en mode outil de type compétence (#4775)

Optimisation

  • Optimisation globale de l'effet de l'interface utilisateur WebUI
  • Certains styles de titre de dialogue sont unifiés

Ce qui a changé (FR)

Nouvelles fonctionnalités

  • Introduire le système CronJob avec des tâches ponctuelles et une gestion améliorée des tableaux de bord
  • Ajoutez une personnalisation du thème avec des options de couleurs primaires et secondaires
  • Ajouter une configuration d'exécution utilisée par l'ordinateur pour l'exécution du sandbox de compétences (#4831)
  • Ajouter un bouton d'édition à la boîte de dialogue de sélection de personnage (#4826)
  • Ajouter une bascule de journalisation de trace et une interface utilisateur de configuration (#4822)
  • Ajoutez une capacité de messagerie proactive avec le déclencheur cron-tool
  • Implémenter l'orchestrateur de sous-agents avec des politiques de gestion d'outils configurables
  • Prise en charge de la résolution des chemins de fichiers sandbox et du téléchargement automatique si nécessaire
  • Ajoutez des styles d'image et d'audio intégrés dans MessagePartsRenderer
  • Présentation de la fondation i18n
  • Conserver l'historique des interactions entre agents
  • Ajouter des notifications utilisateur pour le succès/suppression du téléchargement de fichiers

Corrections de bugs

  • Améliorer la précision de détection des plugins fantômes
  • Ajout d'une gestion des erreurs pour éviter les plantages du plugin fantôme
  • Empêcher l'ensemble de compétences d'écraser les fichiers existants
  • Correction d'un échec de décompression du paquet de compétences dans le bac à sable
  • Correction des outils MCP filtrés lorsqu'un ensemble de plugins spécifiques est configuré (#4825)
  • Fusionner la fenêtre contextuelle du personnage ChatUI avec le personnage par défaut (#4824)
  • Correction du style du bloc de raisonnement
  • Ajouter une virgule manquante dans l'indice truncate_and_compress
  • Correction du frontend affichant toujours un message de réussite (#4768)
  • Correction impossible de renommer le serveur MCP (#4766)
  • Supprimer la gestion restante du runtime sandbox lors du téléchargement de compétences (#4798)
  • Correction de la construction du chemin du module de gestionnaire (#4776)
  • Correction d'une erreur d'invocation d'outil de type compétence (#4775)

Améliorations

  • Conseils d'exécution et interface utilisateur raffinée dans la gestion des compétences
  • Améliorations des performances et de l'UX sur la page cron-job
  • Amélioration générale des performances de l'interface Web
  • Regrouper les outils par plugin dans la liste déroulante
  • Titres de dialogue cohérents avec remplissage et styles de texte
  • Formatage du code unifié (format ruff)
  • Version bosse vers 4.13.2

Autres

  • Supprimer le code de rappel obsolète
  • Extraire le module main-agent pour une meilleure architecture
  • Fusionner les modifications de la branche AstrBot_skill
