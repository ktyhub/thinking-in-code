bookkeeper release-4.17.2

Version Publié5 juil. 2025 Sourceapache/bookkeeper Anglais original

Cette page est traduite automatiquement. Le texte anglais original fait foi.

version du comptable-4.17.2

La version 4.17.2 inclut plusieurs corrections de bogues et quelques mises à jour de dépendances.

Les utilisateurs d'Apache BookKeeper sont encouragés à passer à 4.17.2 si vous utilisez 4.17.x. Les détails techniques de cette version sont résumés ci-dessous.

Faits saillants

Bogues

  • Correction d'un bug NPE après le refactorisation du recycleur de BookieClient PR #4610
  • Correction d'une fuite de mémoire dans le recycleur Netty de Bookie Client [PR #4609] (https://github.com/apache/bookkeeper/pull/4609)
  • Correction du problème de perte de données provoqué par un en-tête de journal d'entrée incorrect PR #4607
  • Correction du coredump qui se produit lors de l'appel de KeyValueStorageRocksDB.count après la fermeture de rocksdb PR #4581
  • Correction et amélioration de la localisation des fichiers de configuration RocksDB PR #4560
  • [correctif] Écriture bloquée en raison d'un rappel d'ajout en attente par plusieurs threads PR #4557
  • Correction des fichiers SST qui n'étaient pas nettoyés dans le dossier des emplacements PR #4555
  • Correction de l'action tune-runner-vm pour qu'elle s'exécute correctement sur l'image ubuntu-24.04 PR #4536
  • [cli] Correction : la commande de récupération n'accepte pas le paramètre de limite de débit PR #4535
  • Correction des endingDeletedLedgers ne supprime pas l'erreur du grand livre PR #4525
  • Correction de la politique de placement en fonction de la région, la dose de poids du disque n'est pas mise à jour. PR #4522
  • Correction d'un problème de fuite de mémoire d'entrée ayant échoué lors de la vérification de la lecture. PR #4513
  • [correctif] supprimer dans adresse2Region pendant que le bookmaker est parti pour obtenir les informations correctes sur le rack PR #4504
  • correctif : installez netcat-openbsd au lieu de netcat dans la construction de l'image de test PR #4476
  • [fix][ci] Correction du téléchargement de la vérification des dépendances OWASP à l'aide de la clé NVD API PR #4473
  • Correction du problème de fuite ReadOnlyLedgerHandle lors de checkAllLedgers. PR #4468
  • fix[rocksdb] : correction de l'erreur de configuration par défaut de rocksdb pour CFOptions PR #4466
  • [correctif] Correction des données perdues après l'écriture du grand livre et la suppression de la simultanéité d'exécution du registre [PR #4462] (https://github.com/apache/bookkeeper/pull/4462)
  • [BugFix] Correctif pour éviter les fuites de ressources dans 3 classes PR #4449
  • Corrigez RackawareEnsemblePlacementPolicyImpl defaultRack lorsque le bookmaker n'est pas disponible. PR #4439
  • Correction du problème de fuite de CompletionObjects. PR #4285
  • Problème 2161 : définir le type de contenu du point de terminaison des métriques PR #4208

Améliorations

  • Ajustez l'expiration du cache DNS dans les tests pour réduire les échecs d'expiration du délai de test PR #4586
  • Modifiez le nouveau journal d'ensemble au niveau info PR #4566
  • Ajouter de la documentation à bk_server.conf sur la configuration RocksDB PR #4561
  • Réduire les conflits de métadonnées dans LedgerHandle PR #4549
  • [améliorer] lorsque rackaware n'a pas réussi à choisir un bookmaker, imprimez la liste de l'ensemble. PR #4482
  • Assurez-vous que formatVersion est spécifié pour toutes les bases de données RocksDB PR #4559
  • Définissez format_version par défaut sur 5 pour les bases de données RocksDB PR #4480
  • [améliorer] Optimiser reorderReadSequence pour vérifier WriteSet PR #4478
  • Mettre à jour les instructions du script de version et les scripts de publication Python PR #4458
  • Activez ZooKeeper client pour établir une connexion en mode lecture seule PR #4244
  • L'allocateur prend en charge la configuration exitOnOutOfMemory. PR #3984

Mises à jour des dépendances

  • Mettez à niveau commons-beanutils vers 1.11.0 pour résoudre le problème CVE-2025-48734 PR #4608
  • Migrer la configuration commons 1.x obsolète vers la configuration commons 2.x PR #4604
  • Mettez à niveau Jetty vers 9.4.57.v20241219 pour atténuer CVE-2024-6763 PR #4600
  • Mise à niveau du Netty vers le 4.1.121.Final PR #4597
  • Mise à niveau vers grpc 1.72.0 PR #4591
  • Mettez à niveau la version OpenTelemetry et alignez les versions à l'aide des nomenclatures PR #4589
  • Mise à niveau de Netty vers 4.1.119, tcnative vers 2.0.70 et io_uring vers 0.0.26 PR #4584
  • Mettez à niveau les bibliothèques Apache Commons vers des versions compatibles PR #4582 * Transférez vertx.version de 4.5.7 à 4.5.11 pour adresser CVE-2024-8391 PR #4545
  • Mise à niveau vers Netty 4.1.115.Final pour adresser CVE-2024-47535 PR #4524
  • Mettez à niveau Zookeeper vers 3.9.3 pour adresser CVE-2024-51504 PR #4523
  • Mise à niveau du gRPC vers le 1.70.0 PR #4512
  • Mettez à niveau protobuf vers 3.25.5 pour adresser CVE-2024-7254 PR #4508
  • Mise à niveau vers Netty 4.1.113.Final et netty-tcnative 2.0.66.Final PR #4502
  • Faites passer le grpc de 1.56.0 à 1.64.0 pour adresser la liste CVE PR #4344
