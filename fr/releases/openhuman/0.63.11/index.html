openhuman v0.63.11

#OpenHuman v0.63.11

187 commits — 52 fonctionnalités, 90 correctifs, 45 refactors, documents et CI. Cette version contient tout ce qui a été fusionné dans main depuis v0.63.9, y compris la restructuration du noyau, les agents vocaux ElevenLabs et une grande transmission de fiabilité à travers la mémoire, l'inférence et la voix.

Remarque sur les notes précédentes : une version antérieure de cette page répertoriait uniquement les deux PR de promotion de la version. Il s'agissait d'un artefact de la façon dont release est mis à jour, pas d'une description de la version. Le contenu complet est ci-dessous.

Faits saillants

Voix

  • ElevenLabs Voice Agents — RPC principal, session en temps réel et gestionnaire de relais d'agent local (#5407)
  • Envoyer le jeton d'identité du relais là où le backend peut le lire (#5428)
  • Arrêtez la fuite de l'identifiant vocal Piper vers les fournisseurs TTS non Piper (#5367)
  • Réparer le bit d'exécution sur les binaires Piper extraits (#5216), gérer le format d'échantillon U16 dans le chemin de capture de secours (#4537)

Mémoire et intégrations

  • Avertir avant que le budget d'intégration n'arrête silencieusement la mémoire (#5402)
  • Arrêtez l'échec des intégrations d'un utilisateur connecté et décochez la file d'attente parquée (#5427)
  • Classifier les échecs d'intégration Ollama indisponibles de manière exploitable (#5398)
  • Drainer le retard des sessions de codage sur les passes délimitées (#5368)
  • Canoniser symétriquement les identifiants de mémoire (#5275); arrêter la recherche de personnes en cas d'erreurs de schéma d'ingestion de charge utile de l'appelant (#5280)

Inférence et routage de modèles

  • Acheminer le chat Codex OAuth vers le backend d'abonnement (#5371)
  • Erreur sur un modèle de vision mal configuré au lieu de substitution (#5262) ; vision d'itinéraire sur les modèles compatibles avec la vision (#5253)
  • Expliquer le repli du fournisseur de rôle en arrière-plan et vérifier les clés BYOK (#5254)
  • Acheminer l'IA locale via TinyAgents RPC (#5240) ; fiabilité du modèle local — solution de repli /api/tags et identifiants de modèle Ollama réels (#5219)

Flux

  • Boucles délimitées par la surface du moteur tinyflows (#5366)
  • Accepter les entrées de workflow déclarées sur chaque chemin d'exécution (#5304)
  • Distribution par élément : exécutez simultanément un ensemble de travaux de flux (#5302)
  • Actualisation visuelle du canevas : types de tuiles, élévation, numéros de pas (#5303)

Agent et chat

  • Envoyer les pièces jointes d'images de l'utilisateur sous forme de blocs d'images, pas de texte (#5370)
  • Préserver le contexte de discussion via un commutateur rapide/raisonnement (#5401)
  • Nommer un fil de discussion en trois mots (#5412)
  • Nommez le rejet du modèle de discussion au lieu de blâmer le modèle/la température (#5309)
  • Convention de déchargement du système de fichiers pour les artefacts de travail sur les tâches à long horizon (#5217)

Restructuration du noyau

  • Réduire 124 domaines plats en 31 familles alignées sur des portes (#5328) — mouvements purs, surface de fil identique en octets
  • Kernelize openhuman : réduit le niveau de dépendance du workflow de 418 → 280 crates (#5314)
  • Réalignez DomainGroup avec les répertoires familiaux (#5332) et protégez trois consommateurs non appliqués (#5364)
  • Gérez la cohorte de contacts macOS derrière contacts (#5365) ; adaptateurs de capacité hôte et couture de configuration (#5396)

Médias, mascotte et configuration

  • Erreur au lieu d'un faux succès sur le timeout du sondage de génération (#5411)
  • Acceptez les avatars personnalisés PNG/GIF/JPEG/WebP avec le téléchargement de fichiers (#5420)
  • Afficher un avis utilisateur lorsqu'un config.toml corrompu est réinitialisé (#5340) ; arrêter les défauts transitoires de lecture active_user.toml suite à la réinitialisation du profil (#5337)

### Chaînes et sessions

  • Empêcher une route d'édition manquante de ressembler à un message supprimé (#5283)
  • Gardez le /auth/me 401 classifiable comme expiration de session plutôt que comme déconnexion matérielle (#5311)
  • Arrêtez les éclaireurs en arrière-plan hors générique d'appeler Sentry (#5310)
