opentelemetry-java v1.64.0

Mineure Publié10 juil. 2026 Sourceopen-telemetry/opentelemetry-java Anglais original

Cette page est traduite automatiquement. Le texte anglais original fait foi.

opentelemetry-java v1.64.0

###API

  • Correction de W3CBaggagePropagator pour autoriser les valeurs de bagages vides selon les spécifications du W3C (#8468)
  • Correction de l'analyse des bagages pour les membres non valides avec un pourcentage codé (#8480)

Incubation

  • BREAKING Supprimer le InstrumentationConfigUtil.peerServiceMapping obsolète (#8542)
  • Correction de EnvironmentGetter/EnvironmentSetter pour ne pas énumérer ou normaliser les entrées d'opérateur, et normaliser les noms vides de manière cohérente (#8474, #8481)

###SDK

Traces

  • Ajoutez l'usine pratique BatchSpanProcessor.create(SpanExporter) pour refléter SimpleSpanProcessor.create(SpanExporter) (#8564)
  • Correction des compteurs auxiliaires de référence BatchSpanProcessor (exportedSpans/droppedSpans) rapportant toujours zéro (#8539)

Métriques

  • Correction de PooledHashMap supprimant les entrées en direct lorsqu'une entrée est supprimée pendant forEach (#8499)
  • Initialisez en toute sécurité un stockage de réservoir exemplaire dans FixedSizeExemplarReservoir (#8524)
  • Utilisez failExceptionally dans PeriodicMetricReader lorsque l'exportateur est occupé (#8525)
  • Ne définissez valuesRecorded dans AggregatorHandle que lorsque faux (#8559)
  • Utilisez volatile au lieu des atomes dans Double/LongLastValueAggregator (#8560)
  • Randomisez l'ordre d'enregistrement par thread dans les benchmarks métriques pour éviter les points chauds de concurrence (#8550)

Journaux

  • Correction du thread de travail BatchLogRecordProcessor tué par des exceptions non liées à l'exécution (#8529)

Exportateurs

  • BREAKING Prometheus : abandon des constructeurs PrometheusMetricReader obsolètes (#8541)
  • OTLP : rejeter les points de terminaison sans hôte dans EndpointUtil.validateEndpoint (#8489)
  • OTLP : remplacez la sérialisation Jackson OTLP JSON par une implémentation manuelle (#8545)
  • Profils OTLP : correction du nom de classe OtlpGrpcProfileExporter toString (#8492)
  • Prometheus : ajout de la prise en charge de la stratégie de traduction (#8346)
  • Prometheus : correction de la sérialisation de la portée et des attributs de ressources à valeur de tableau dans les chaînes JSON (#8497)

Extensions

  • BREAKING Configuration déclarative : déplacer les types expérimentaux vers le package interne (#8530)
  • Configuration déclarative : valider les POJO de schéma générés dans git (#8408)
  • Configuration déclarative : mise à jour vers opentelemetry-configuration v1.1.0 (#8451)
  • Configuration déclarative : ajustez POJO toString/hashCode/equals pour qu'il corresponde à la sémantique AutoValue (#8526)
  • Configuration déclarative : ajoutez des descriptions de référence aux classes de modèles générées (#8540)
  • Configuration déclarative : émettre des annotations @JsonProperty cohérentes sur les modèles générés (#8563)
  • Configuration déclarative : supprimez le résolveur en double dans DeclarativeConfigPropertyUtil (#8579)

Outillage de projet

* Ajouter des conseils sur la stratégie de configuration (#8429)

  • Exclure certaines actions GitHub de l'exécution sur les forks (#8466)
  • Ajouter des conseils pour préférer les tests paramétrés (#8469)
  • Rendre le chemin de référence configurable (#8557)
