opentelemetry-java v1.67.0

Mineure Publié9 oct. 2026 Sourceopen-telemetry/opentelemetry-java Anglais original

Cette page est traduite automatiquement. Le texte anglais original fait foi.

opentelemetry-java v1.67.0

###API

  • Déprécier TextMapGetter.keys() et faire de TextMapGetter une interface fonctionnelle (#8531)
  • Ajoutez des gardes nulles et la journalisation de l'utilisation du API pour le traçage, les bagages, les attributs, la journalisation et les métriques (#8803, #8863, #8864).
  • Allocations liées et évitez le retour en arrière des regex lors de l'analyse de W3C tracestate (#8817, #8914)

Incubation

  • Ajouter des méthodes d'introspection de type à DeclarativeConfigProperties (#8883)

Extensions

  • Propagateurs de traces : allocations liées lors de l'analyse des bagages Jaeger et de la propagation à en-tête unique B3 (#8817)

###SDK

  • Exécutez les actions d'achèvement de CompletableResultCode en dehors des verrous internes pour éviter les blocages (#8773)
  • Ne comptez pas les écrasements d'attributs comme des attributs supprimés (#8833).
  • Évitez le retour en arrière des regex dans la correspondance globale (#8909)
  • Ajoutez la prise en charge des entités de ressources expérimentales, l'exportation OTLP et la configuration via otel.entities et les détecteurs de ressources déclaratifs (#8464)

Traces

  • Renvoie les traceurs noop lorsqu'aucun processeur span n'est configuré (#8815)
  • Attrapez Throwable dans SimpleSpanProcessor et MultiSpanExporter (#8848)
  • Utilisez les unités {span} pour les mesures d'auto-observabilité du processeur span (#8873)

Métriques

  • Stabiliser PeriodicMetricReaderBuilder.setMaxExportBatchSize(int) (#8829)
  • Supprimer l'attribut métrique expérimental/le traitement des bagages (#8818)
  • Correction : Réinitialiser le contexte de span exemplaire lorsqu'une cellule de réservoir est écrasée en dehors d'un span (#8871)

Journaux

  • Renvoie les enregistreurs noop de SdkLoggerProvider.get() lorsqu'aucun processeur d'enregistrement de journal n'est configuré (#8838)
  • Attrapez Throwable dans SimpleLogRecordProcessor et MultiLogRecordExporter (#8848)

Profils

  • Correction de KeyValueAndUnitData.create() pour renvoyer l'interface publique KeyValueAndUnitData (#8875)

Exportateurs

  • OTLP : correction des limites de taille de requête manquantes, par défaut à 64 Mio, configurables via setMaxRequestBodySize(long) et setMaxRequestMessageSize(long) et via la configuration déclarative OtlpGrpcExporter, OtlpHttpExporter (voir la documentation complète du schéma ici) (#8446)
  • OTLP : réduire les journaux d'échecs à FINE après l'arrêt (#8819)
  • OTLP : réessayez gRPC en fonction des codes d'état de réponse dans les en-têtes de fin (#8854)
  • Prometheus : évitez le retour en arrière des regex lors de la suppression des annotations d'unité (#8910)

Extensions

  • Configuration automatique : stabilisez ServiceInstanceIdResourceProvider et générez service.instance.id par défaut (#8770)
  • Configuration automatique : conserver les caractères non-ASCII non codés lors du décodage des attributs de ressources (#8893)
  • Configuration automatique : ajout d'indices d'artefacts manquants pour les exportateurs span et métriques experimental-otlp/stdout (#8897)
  • Configuration déclarative : mise à jour vers le schéma v1.2.0 et prise en charge de l'échantillonneur always_record (#8801)
  • Configuration déclarative : ignorer les attributs de ressources avec des valeurs nulles (#8889)
  • Configuration déclarative : faire correspondre les attributs du tableau par élément dans l'échantillonneur rule_based (#8895)
  • Échantillonneur à distance Jaeger : réduire les journaux d'échecs à FINE après l'arrêt (#8819)
  • Échantillonneur à distance Jaeger : préserve les stratégies d'échantillonnage par opération lorsque la limite de taux est nulle (#8888)
  • Incubateur : Rendre OnEndSpanProcessor.create() public (#8892)
  • Incubateur : correction du nom de la classe dans les descriptions ComposableProbabilitySampler (#8891)

Tests

  • Correction des messages d'échec d'assertion signalant une valeur ou un type incorrect (#8872)

Cales

  • OpenCensus : ignorez les clés tracestate multi-locataires W3C lors de la conversion des étendues (#8810)
  • OpenTracing : propager les bagages au contexte parent dans SpanBuilderShim (#8812)

Outillage de projet

  • Extension Kotlin : augmentez la version minimale de Kotlin à 2.2 (#8804)
