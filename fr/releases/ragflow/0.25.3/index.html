#ragflow v0.25.3

Résumé

Nouvelles fonctionnalités

  • Source de données et analyse : ajout d'un contrôle sémantique/métadonnées au niveau des colonnes pour l'analyseur de fichiers de feuille de calcul ; introduit l'optimisation ETag pour la synchronisation incrémentielle des sources de données S3 afin d'éviter les transferts de fichiers inutiles.
  • Permet d'attribuer des rôles spécifiques tels que le contenu, les métadonnées et la clé primaire aux colonnes du tableau. #13710

Améliorations

  • Refactorisation et sécurité API
    • Poursuite de la transition des API Web vers les conventions RESTful, garantissant une compatibilité ascendante pour tous les points de terminaison existants.
    • Lie le user_id dans POST /api/v1/messages au principal JWT authentifié. #14745
    • Sécurise l'exécuteur sandbox contre les contournements d'exécution de code dynamiques et indirects. #14690
    • Contrôle du délai d'attente des requêtes LLM
    • Pool de threads d'appel bloquant la concurrence élevée
  • Réduit le temps de démarrage du serveur d'ingestion. #14894

Corrections de bugs

  • Les images des classeurs Excel multi-feuilles n'étaient pas définies par feuille, ce qui entraînait une attribution incorrecte des images entre différentes feuilles de calcul. #14120
  • Passage d'alias d'élément d'itération
  • Analyse du modèle de paramètres d'outil
  • Sortie de pièce jointe d'exécution de code
  • Correction de l'ajout du modèle de volcan
