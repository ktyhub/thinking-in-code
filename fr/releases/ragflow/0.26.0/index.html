ragflow v0.26.0

Résumé

Nouvelles fonctionnalités

  • Fournisseurs de modèles
    • Implémente des listes de modèles remplies automatiquement pour plusieurs fournisseurs, éliminant ainsi le besoin de saisir manuellement les noms de modèles. Cette fonctionnalité prend actuellement en charge : Ollama, OpenRouter, vLLM, OpenAI-API-Compatible, LM-Studio, VolcEngine, Xinference, LocalAI, BaiduYiyan, GPUStack et Fish Audio.
    • Permet de configurer plusieurs clés API pour le même fournisseur de modèle. #14595
    • Remplit dynamiquement les listes déroulantes de sélection de modèles dans l'interface utilisateur en récupérant les modèles actuellement disponibles directement auprès des fournisseurs de modèles distants. #15711
  • Connecteurs de source de données : implémente de nouveaux connecteurs de source de données pour Outlook, OneDrive, Microsoft Teams, Slack, SharePoint, Salesforce et Azure Blob Storage. #15333#15330#15332#15188#15190#15462#15466
  • Ensemble de données - Implémente une fonctionnalité de point de contrôle et de reprise pour l'extraction de communauté et la résolution d'entités, les parties les plus coûteuses et les plus longues du pipeline d'indexation GraphRAG. #15518#15523

Améliorations

  • Supprime la mise en mémoire tampon de texte <think> pour garantir que les modèles capables de raisonner se sentent plus rapides et plus transparents lors des interactions. #15891
  • Marque les migrations MySQL comme appliquées. #15504

Prise en charge des modèles

  • Quatre nouveaux modèles SiliconFlow #15383
  • Modèle MiniMax-M3 #15513
  • Derniers modèles anthropiques #15516
  • Famille de modèles Voyage 4 #15516
  • Cohérer la liste des modèles. #15576

i18n

  • Termine la traduction coréenne. #15863
  • Termine la traduction italienne. #15729

Corrections de bugs

  • Le mode réflexion des modèles MiniMax n'était pas correctement activé. #15496
  • Des boucles infinies étaient déclenchées lorsque le mode réflexion était activé pour les modèles Qwen3.5 et Qwen3.6. #15101
  • Les réponses diffusées en streaming étaient dupliquées lors de l'utilisation du point de terminaison de chat compatible OpenAI API. #15286#15443
  • Des erreurs de sérialisation étaient provoquées lors de la fin du chat lorsque des scores numériques non valides tels que NaN (Not-a-Number) ou Inf (Infinity) étaient transmis à l'encodeur JSON. #15245#15266
  • Les finalisations de chat à l'aide des fournisseurs LiteLLM échouaient car les paramètres de configuration internes non reconnus n'étaient pas filtrés avant d'atteindre les API externes. #15427#15432
  • Les complétions de chat compatibles OpenAI API étaient par défaut des réponses diffusées en continu. #15356#15394
  • Les résultats AND vides ont été incorrectement supprimés lors du filtrage des métadonnées. #15477
  • Les éléments chromés répétitifs des pages, tels que les en-têtes et les pieds de page, ont été incorrectement extraits en tant que texte principal par l'analyseur MinerU. #15335#15387
  • Les titres des graphiques en anglais manquaient lors de l'extraction des documents dans le module DeepDoc. #15481
  • Des sorties vides ont été renvoyées par TitleChunker pour les formats amont json et chunks #14247#15396
  • Un message d'erreur manquait lorsqu'une tentative de téléchargement de fichier .tsv échouait. #15284
  • Les valeurs bêta manquantes des jetons API provoquaient des erreurs de récupération des jetons. #15405
  • Limite la taille maximale de la page pour corriger les pannes du système ou les ralentissements dus à des requêtes volumineuses. #15292
  • Les erreurs Client ont été causées par le fait que l'achèvement du chat compatible OpenAI API était incorrectement défini par défaut sur les réponses diffusées en continu. #15356#15394
  • Des erreurs de serveur interne HTTP 500 étaient déclenchées au lieu des erreurs standard 4xx client lorsque les utilisateurs tentaient de télécharger des fichiers manquants à partir du backend de stockage. #15369#15371
  • Le classement des entités GraphRAG a été rompu. #15795#15797
