#ragflow v0.26.2

Résumé

Sortie le 29 juin 2026.

Nouvelles fonctionnalités

  • Canaux de discussion :
    • Intègre WhatsApp via un scan de code QR. #16238
    • Intègre DingTalk via les informations d'identification du bot API. #16183
    • Intègre WeCom via une connexion WebSocket. #16175
  • Analyse de fichiers : ajoute une logique de secours pour PP-OCRv6 et des modèles de reconnaissance de texte similaires, et intègre l'analyse d'images dans le pipeline PaddleOCR. #16150

Améliorations

  • Ensembles de données
    • Ajoute une vérification des cas extrêmes à la logique d'ingestion de fichiers pour lier en toute sécurité des dossiers vides à un ensemble de données. #16296
    • Ajoute la pagination à la méthode get_flatted_meta_by_kbs() pour éviter les échecs CRUD liés aux ensembles de données contenant plus de 10 000 documents. #16095
  • Canaux de discussion : garantit que les historiques de conversations des utilisateurs finaux persistent lors des redémarrages mais sont toujours séparés lorsqu'un canal est lié à une nouvelle boîte de dialogue. #16274

i18n

  • Étend la couverture i18n et affine les traductions pour l'interface utilisateur coréenne. #16203；
  • Ajoute les traductions françaises manquantes pour les canaux de discussion, la validation du nom d'utilisateur et l'édition du modèle. #16217

Corrections de bugs

  • Analyse de fichiers :
    • Un ValueError a été généré lors de l'analyse de .docx sur les styles 'Heading'. #16284
    • Les tableaux des fichiers .docx ont été supprimés silencieusement par l'analyseur de documents de lois. #16155
    • Les en-têtes Lone Markdown ont été séparés de leurs sections suivantes lorsqu'un délimiteur DeepDoc a été défini. #16109
    • Les tableaux Markdown sont apparus deux fois dans les résultats de blocs, une fois en tant que bloc autonome et de nouveau dans un bloc de texte normal. #16143 -MCP
    • Le serveur MCP se bloquait indéfiniment lorsqu'il rencontrait des pages de document vides ; la dernière page des documents a été silencieusement supprimée en raison d'une pagination défectueuse. #16285
    • La connexion MCP et le processus de découverte de l'ensemble de données ont échoué car la limite d'extraction codée en dur du serveur dépassait la restriction page_size introduite. #16148
  • Flux de données
    • Restaure le point de terminaison de réexécution du flux de données et garantit que la réponse d'ingestion inclut la charge utile DSL pour restituer de manière fiable la chronologie et les vues de l'analyseur. #16292
    • Restaure les valeurs par défaut de l'analyseur de flux de données et renvoie la charge utile SSE réelle, garantissant ainsi que le pipeline s'exécute correctement, affiche les ID de message et les mises à jour des journaux. #16290
  • LLM : échec de l'utilisation du nouveau modèle gemini-3.5-flash via le fournisseur Google Cloud (Vertex AI) à l'aide du point de terminaison de région eu ou us. Ce problème est résolu par des requêtes de routage explicitement multirégionales vers les domaines aiplatform.<region>.rep.googleapis.com requis au lieu des hôtes <region>-aiplatform.googleapis.com synthétisés. #15990
  • UI/UX : le modal d'ajout de métadonnées envoie des valeurs vides au backend. #15229
