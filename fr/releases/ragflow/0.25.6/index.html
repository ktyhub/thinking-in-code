#ragflow v0.25.6

Résumé

Sortie le 26 mai 2026.

Nouvelles fonctionnalités

  • Agent : ajoute un composant Navigateur qui permet à l'IA de naviguer et d'interagir de manière autonome avec les pages Web. #14888

Améliorations

  • RAG : la construction RAPTOR introduit désormais le mode AHC (Ψ-RAG), qui étend la sémantique du niveau du document au niveau de l'ensemble de données. Non seulement les performances de construction de l'indice sont nettement supérieures à celles du précédent RAPTOR, mais elles surpassent également l'ancien RAPTOR sur Recall@5 et la moyenne F1. Les utilisateurs peuvent basculer entre les modes AHC et GMM. Cette fonctionnalité a été introduite dans v0.25.3 et cette version corrige plusieurs bugs. #14674#14679
  • Agent : introduit le décorateur léger @tool pour rationaliser le processus d'enregistrement de la fonction Python pour les modèles de discussion. #15047
  • Agent : permet aux messages de l'agent d'afficher des images codées en base64. #15212
  • Agent : expose les métadonnées de fichier du composant Doc Generator sous forme de variables discrètes. #15080
  • Agent : permet aux développeurs de transmettre chat_template_kwargs au point de terminaison de fin de discussion de l'agent. #14182#14542

Corrections de bugs

  • Corrige /chat/completions pour permettre l'envoi uniquement du dernier message dans la charge utile API et supprime l'obligation de transmettre l'historique complet des conversations. #15197 Voir aussi Converser avec l'assistant de chat.
  • Le poids attribué à la similarité des vecteurs n'a pas été appliqué lors de la phase de récupération. #15108
  • Corrige les configurations de l'analyseur qui ne sont pas enregistrées sur la page de configuration de l'ensemble de données.
  • Les journaux n'étaient pas entièrement affichés sur la page de détails de la source de données.
  • Corrige l'échec du filtrage de l'état des documents.
  • Corrige le crash guard pour les réponses aux choix LLM vides.
  • RAG : arrêt du processus de construction de RAPTOR lors de l'utilisation du moteur de documents Infinity. #14998
  • Corrige l'analyse des réponses en streaming pour les modèles de raisonnement Mistral/Upstage.
  • Corrige les balises HTML dans la sortie de l'analyseur du pipeline d'ingestion.
  • Corrige les métadonnées de l'analyseur de table.
  • Résout les problèmes d'imbrication de boucles d'événements asyncio et de tâches de lancement et d'oubli.
  • Corrige asyncio.Semaphore lié à une erreur de boucle d'événement différente.
  • Agent : corrige la disparition de la variable d'invite du composant Agent et les problèmes de recherche de vector_similarity_weight.
