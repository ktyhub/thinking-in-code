#ragflow v0.27.1

Nouvelles fonctionnalités

  • Nouveau connecteur Azure DevOps pour les sources de données (#18715)
  • Nouveau moteur de recherche Web You.com pour le chat et l'agent (#18478)
  • Nouveau fournisseur de recherche Web Serply pour le chat (#18475)

Prise en charge du modèle

  • Nouveau fournisseur de modèles Synthorai (#18830)
  • Modèles DeepSeek manquants ajoutés (#18678)
  • Prise en charge de l'authentification par clé AWS Bedrock API (#18301)

Améliorations

  • La récupération API expose rerank_candidates_count, knn top_k et num_candidates (#18768, #18737)
  • Filtres de métadonnées poussés vers l'index des métadonnées pour une récupération plus rapide (#18219)
  • Le formulaire des paramètres de discussion défile automatiquement jusqu'à l'emplacement de l'erreur lors de l'enregistrement (#18811).
  • La page de recherche valide les bases de connaissances supprimées (#18522)

Corrections de bugs

  • Correction d'un échec d'analyse PDF dans le chat (#18860)
  • Correction de la compilation wiki acceptant les réponses d'erreur LLM (#18857)
  • Correction de la stabilité du rendu MinerU, de la visibilité des erreurs et de l'analyse des blocs de code (#18617)
  • Correction des ensembles de données 0-chunk ne s'affichant pas, empêchant le défilement pour récupérer plus d'ensembles de données (#18810)
  • Correction de l'analyseur QA Excel supprimant les lignes dont la réponse est zéro (#17902)
  • Correction d'un analyseur naïf traitant un téléchargement vide comme un binaire manquant (#18826)
  • Correction de la détection d'encodage rejetant les résultats de détection fiables (#15793)
  • Correction du chat activé par le raisonnement ignorant l'invite du système de dialogue (#18842)
  • Correction de la compilation des connaissances en utilisant le LLM locataire par défaut au lieu du LLM pipeline (#18572)
  • Correction du service de recherche sur le réseau de discussion qui ne peut pas être nul (#18791)
  • Correction du défilement automatique du chat Firefox non épinglé en bas (#18736)
  • Correction du défilement automatique du chat ne suivant pas les réponses diffusées (#18570)
  • Correction de la progression de l'analyse non visible après la sélection du téléchargement (#18741)
  • Correction du connecteur BigQuery construisant incorrectement les requêtes SQL (#17500)
  • Correction des erreurs de listage WebDAV non propagées, entraînant une perte de données d'élagage (#18694)
  • Correction d'une collision d'ID de document entre Ko dans la synchronisation des sources de données (#18244)
  • Correction de la découverte du modèle GPUStack et de la prise en charge audio (#18599)
  • Correction de la température du Kimi K3 (#18564)
  • Correction du texte OCR perdu lorsqu'aucun modèle image2text n'est configuré (#18012)
  • Correction de la navigation hiérarchique des sujets Wiki (#18721)
