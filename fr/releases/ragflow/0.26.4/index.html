ragflow v0.26.4

Résumé

Sortie le 7 juillet 2026.

Nouvelles fonctionnalités

  • NLP/Tokenisation : ajoute un stemmer Snowball prenant en charge 16 langues, intègre le paramètre de jeu de données language dans le pipeline de tokenisation et ajoute le néerlandais au frontend. #14140

Corrections de bugs

  • Le système plante avec un ValueError lors de l'analyse des noms de modèles LM-Studio contenant un symbole '@'. #16467
  • Le serveur MCP a planté car la fonction list_chats attendait une liste du /chats API mais a reçu un dictionnaire paginé à la place. #16639
  • L'analyseur Docling supprimait silencieusement les formules mathématiques des documents au lieu de les extraire. #16645
  • Le système n'a pas réussi à conserver les modifications en ligne apportées aux valeurs de métadonnées dans le backend. #16655
  • Le système a supprimé les liens existants lors de la liaison groupée de fichiers à des ensembles de données. #16587
  • Le filtre n'a pas réussi à utiliser le chinois. #16673
  • Le système n'a pas réussi à imposer que le poids des étiquettes soit supérieur à zéro. #16657
  • La présentation du menu déroulant des invites de l'agent n'est pas affichée correctement. #16653
  • Le module Laws a classé à tort les références croisées à points comme en-têtes. #16626
  • Le système n'a pas réussi à empêcher les utilisateurs d'enregistrer les noms de serveur MCP en double pendant le processus d'édition. #16588
  • Le système permettait aux utilisateurs d'exporter une sélection de serveur MCP vide. #16589
