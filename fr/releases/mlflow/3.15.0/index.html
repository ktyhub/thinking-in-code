mlflow v3.15.0

MLflow 3.15.0 comprend plusieurs fonctionnalités et améliorations majeures

Nouvelles fonctionnalités majeures

  • 🧩 Registre MCP : Un catalogue centralisé pour l'enregistrement, la gestion des versions et le partage des serveurs Model Context Protocol — avec des configurations versionnées sémantiquement, des alias promouvables, des balises, des outils de découverte automatique et des instructions de connexion prêtes à l'emploi pour Claude Code et .mcp.json. Gérez-le depuis l'interface utilisateur, REST API ou Python !
  • 🤖 Améliorations de MLflow Assistant : L'assistant d'IA intégré à l'application prend désormais en charge plusieurs fournisseurs LLM (Claude Code, Codex et points de terminaison compatibles OpenAI/Gateway) choisis à partir d'une seule page de paramètres, affiche l'utilisation du jeton par session en direct et le coût estimé dans le compositeur, et est plus facile à configurer — mlflow agent setup peut l'activer en une seule invite, avec les clés API stockées en toute sécurité dans les connexions LLM de la passerelle.
  • 🗂️ Vues de table partageables : enregistrez les vues nommées de la table Runs (capturant les colonnes, l'ordre, les largeurs, les filtres et le tri) et partagez-les par URL.
  • ⚡ Téléchargement/téléchargement d'artefacts sans proxy via des URL prédéfinies : les transferts d'artefacts volumineux peuvent désormais contourner le serveur de suivi et communiquer directement avec le stockage cloud (par exemple S3) via des URL prédéfinies, réduisant ainsi la charge du serveur et les délais d'attente sur les gros fichiers. Nous revenons automatiquement au transfert par proxy pour une compatibilité ascendante.
  • 🖼️ Pièces jointes multimodales dans les juges LLM : les juges {{ trace }} créés avec make_judge() peuvent désormais voir les images capturées dans des intervalles de trace via un nouvel outil get_span_image, qui récupère les pièces jointes sous forme d'URL de données base64 et les transmet aux modèles multimodaux (compatibles Anthropic, Gemini et OpenAI via litellm) — permettant l'évaluation des tâches de vision, des captures d'écran et d'autres contenus visuels.
