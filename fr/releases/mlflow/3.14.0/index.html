mlflow v3.14.0

MLflow 3.14.0 comprend plusieurs fonctionnalités et améliorations majeures

Nouvelles fonctionnalités majeures

  • 🚀 Intégration d'un agent à une seule commande avec mlflow agent setup : installez MLflow, configurez le traçage et transmettez à votre agent de codage préféré (Claude Code, OpenAI Codex ou OpenCode) les compétences MLflow pour instrumenter votre application, le tout à partir d'une seule commande.
  • ⚡ [Traçage durable et à faible latence pour Claude Code] (https://mlflow.org/docs/latest/genai/tracing/integrations/listing/claude_code) : Déployez le traçage de Claude Code au sein d'une équipe en toute confiance : un journal à écriture anticipée l'empêche de ralentir l'agent, de surcharger le serveur de suivi ou de perdre des traces en cas de problème ou de panne du réseau.
  • 📝 Files d'attente de révision pour les traces : attribuez des traces aux réviseurs (ou agents) et collectez des commentaires structurés et des annotations de vérité terrain dans l'interface utilisateur, écrites directement sur la trace afin qu'elles soient immédiatement utilisables pour l'évaluation.
  • 🗂️ Interface utilisateur de l'ensemble de données d'évaluation remaniée : parcourez, inspectez, modifiez et gérez en masse les enregistrements de l'ensemble de données d'évaluation directement dans l'interface utilisateur, avec cli jusqu'à la trace source.
  • **🧪 [Intégration Pytest pour les tests de régression] (https://mlflow.org/docs/latest/genai/eval-monitor/regression-testing) ** : écrivez des tests de régression GenAI sous forme de fonctions pytest simples avec le marqueur @mlflow.test, placez-les dans CI, examinez l'historique des tests et jugez les résultats par assertion dans l'interface utilisateur.
  • 🎛️ LLM Playground : itérez sur les invites dans le navigateur par rapport à vos points de terminaison AI Gateway et aux versions de Prompt Registry, avec des paramètres, des outils, une sortie structurée et des variables de modèle.
