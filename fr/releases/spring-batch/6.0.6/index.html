spring-batch v6.0.6

Correctif Publié22 oct. 2026 Sourcespring-projects/spring-batch Anglais original

Cette page est traduite automatiquement. Le texte anglais original fait foi.

lot de printemps v6.0.6

:fusée : améliorations

  • Ajoutez @FunctionalInterface à StepInterruptionPolicy #5402
  • Correction du message d'état SimpleJobOperator jobRegistry #5369
  • Améliorer JdbcJobExecutionDao#synchronizeStatus(StepExecution) #5365
  • Remplacer le Jackson2JsonMessageConverter obsolète par JacksonJsonMessageConverter #5350
  • Remplacez System.getProperty("line.separator") par System.lineSeparator() #5341
  • Supprimer la vérification nulle inutile par rapport à createTime d'exécution #5304
  • Message d'exception inexact lors de la tentative de démarrage d'une tâche en cours d'exécution #5280
  • Remplacez CopyOnWriteArrayList par ArrayList dans JdbcPagingItemReader et JpaPagingItemReader pour plus de performances et d'exactitude #5112
  • Élimine les requêtes inutiles pour la version actuelle #4797
  • L'exécution d'un travail entraîne la récupération de l'historique complet des exécutions du travail #4169
  • Les noms d'étapes non uniques dans un FlowJob doivent enregistrer un avertissement #3757
  • Supprimer l'importation ClassUtils inutilisée de JdbcPagingItemReader #5407

## :lady_beetle : corrections de bugs

  • ChunkOrientedStep ne restaure pas l'exécution de l'étape lorsqu'une transaction chunk n'est pas validée #5594
  • MongoCursorItemReader lance NullPointerException lorsqu'il est fermé avant l'ouverture #5589
  • La migration MariaDB 6.0 échoue lors du changement de nom de BATCH_JOB_SEQ #5586
  • les exceptions d'écoute peuvent être ignorées en mode scan mais fatales ailleurs #5585
  • Correction de l'augmentation des pages manquantes dans AbstractPaginatedDataItemReader #5583
  • Les beans de portée tâche ne sont pas utilisables à partir des threads de travail des étapes multithread et des flux parallèles #5576
  • Le redémarrage après un échec lors de l'analyse du fragment ignore les éléments restants du fragment dans ChunkOrientedStep #5558
  • NullPointerException lors de la fermeture d'un JpaPagingItemReader non ouvert #5539
  • Les méthodes @OnSkipInRead/@OnSkipInProcess/@OnSkipInWrite sont ignorées par ChunkOrientedStepBuilder#listener(Object) #5531
  • Journaux trompeurs en mode analyse sans tentatives #5527
  • FlatFileItemReaderBuilder.addComment() lance UnsupportedOperationException après comments(...) #5520
  • DelimitedLineTokenizer lance StringIndexOutOfBoundsException lorsqu'un champ est un guillemet simple #5519
  • FixedLengthTokenizer en mode strict rejette les lignes lorsque la plage ouverte commence au plus tard au min de la première plage #5518
  • JobFlowExecutor divulgue un StepExecution lors des exécutions de tâches sur un thread partagé lorsqu'aucune transition ne correspond au ExitStatus d'une étape #5514
  • Morceau annulé compté comme écrit et étape COMPLÉTÉ dans ChunkOrientedStep (nouvelle tentative tolérante aux pannes de OptimisticLockException) #5509
  • TransientTransactionError dans MongoSequenceIncrementer lors d'exécutions de tâches parallèles #5507
  • Correction de la désérialisation QName dans JacksonExecutionContextStringSerializer #5502
  • Le mode d'analyse ChunkOrientedStep transmet le morceau traité à ChunkListener#beforeChunk et supprime silencieusement les éléments d'analyse lorsque l'auditeur lance #5493
  • ChunkOrientedStep ne réinvoque pas le ItemProcessor pendant l'analyse de fragments, contrairement au FaultTolerantChunkProcessor #5490
  • JpaCursorItemReader.doClose() manque la vérification nulle sur entityManager #5486
  • Correction d'un contrat de nullité incorrect pour encoding dans StaxEventItemReader #5483
  • JsonFunctionalTests échoue sous Windows à cause de CRLF #5481
  • @OnChunkError n'est jamais invoqué sur une étape orientée chunk #5468
  • Les rappels de l'écouteur d'interface sont invoqués deux fois lorsqu'un gestionnaire d'éléments a également une annotation d'écouteur #5466
  • spring.batch.job.launch.count manque silencieusement : le JobOperator conserve ObservationRegistry.NOOP sur la plupart des chemins de configuration #5463
  • Gestion incohérente du type JobParameter entre le stockage et la récupération dans Spring Batch 6.x #5455
  • Les méthodes @BeforeStep/@AfterStep sont ignorées par ChunkOrientedStepBuilder#listener(Object) #5451
  • Remplacez jetbrains @NotNull par jspecify @NonNull #5443
  • SimpleJobOperator.restart(JobExecution) masque la véritable raison de l'échec avec un message trompeur "exécution du travail déjà en cours" #5439
  • Astuces d'exécution GraalVM manquantes pour les classes et ressources du modèle de persistance MongoDB #5435
  • Correction de JsonFileItemWriter pour produire un JSON valide lorsque l'ajout est autorisé avec un rappel d'en-tête/pied de page personnalisé #5432
  • Le nom de l'étape est nul lorsque l'étape n'est pas définie en tant que bean et n'a pas reçu de nom #5278
  • Passage de tri forcé via la méthode sorts() lors de la construction avec MongoCursorItemReaderBuilder et requête #4860

## :notebook_with_decorative_cover : Documentation

  • La description du JpaItemWriter dans l'annexe de la documentation est erronée #5556
  • Documentation inexacte des exemples de segmentation et de partitionnement à distance concernant les en-têtes JMS #5513
  • Correction de fautes de frappe dans les commentaires Javadoc #5511
  • Clarifier la compatibilité des lectures réessayables avec la sémantique avant uniquement #5510
  • Clarifier le contrat SkipListener et les documents de référence sur la portée de la transaction #5494
  • L'exemple de traçage de la documentation de référence enregistre un gestionnaire qui ne crée aucun span et échoue au travail #5475
  • Correction d'une faute de frappe dans Javadoc de JobOperator.start() #5434
  • Mauvais exemple dans "Enregistrement d'un ItemStream avec un Step" #5429
  • Correction d'une référence Javadoc incorrecte dans JobExecution.isStopped() #5414
  • Correction de javadoc dans SqlPagingQueryUtils #5403
  • Correction d'une faute de frappe dans le Javadoc EnableBatchProcessing #5375
  • JavaDoc inexact de BatchStatus.isLessThanOrEqualTo #5285
  • Améliorer la documentation sur l'utilisation de IteratorItemReader pour réutiliser les API défilants à partir de Spring Data #4484

:hammer: Tâches

  • Mettre à jour Apache Artemis groupId vers org.apache.artemis #5482
  • Mettre à jour la version Groovy vers 5.1.2 #5327
  • Utilisez systématiquement le suffixe .version pour les propriétés de version dans pom.xml #5506
