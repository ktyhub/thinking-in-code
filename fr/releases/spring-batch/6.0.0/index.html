spring-batch v6.0.0

Majeure Publié19 nov. 2025 Sourcespring-projects/spring-batch Anglais original

Cette page est traduite automatiquement. Le texte anglais original fait foi.

lot de printemps v6.0.0

Spring Batch 6.0 est une version majeure dotée de plusieurs nouvelles fonctionnalités, améliorations et corrections de bugs. Cette version introduit un certain nombre de modifications et de dépréciations de rupture de API. Veuillez vous référer au guide de migration pour la liste complète des modifications.
