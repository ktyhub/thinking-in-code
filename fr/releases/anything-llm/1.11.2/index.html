Plus d'améliorations de l'interface utilisateur

https://github.com/user-attachments/assets/9f2a0363-e905-420e-9c80-3b96fdb07368 Désormais, dans l'interface utilisateur principale du chat, nous avons ajouté des améliorations et des correctifs très souhaités.

  • [x] Nouvelle saisie d'invite
  • [x] Meilleure interface utilisateur et rapports sur les citations
  • [x] Métriques pour les appels d'agent
  • [x] Signalez les citations de documents et de recherches sur le Web lors des appels d'agent !
  • [x] Possibilité d'activer/désactiver les compétences d'agent à partir de l'invite
  • [x] Possibilité de sélectionner le fournisseur et le modèle de l'espace de travail sans quitter la page.
