anything-llm v1.16.2

Correctif Publié22 sept. 2026 SourceMintplex-Labs/anything-llm Anglais original

Cette page est traduite automatiquement. Le texte anglais original fait foi.

n'importe quoi-llm v1.16.2

Nouvelles fonctionnalités

  • [x] LLMman - OSS est désormais disponible en tant que fournisseur LLM local, remplaçant Docker Model Runner
  • [x] Google Vertex AI est désormais disponible en tant que fournisseur LLM
  • [x] Nouvelle compétence d'agent generate-image pour créer des images à partir du chat
  • [x] You.com est désormais le fournisseur de recherche Web par défaut pour des recherches Web plus riches avec zéro rétention de données
  • [x] Les variables de flux d'agent prennent désormais en charge les arguments facultatifs
  • [x] Ajout de la prise en charge des langues hindi, bulgare et suédoise
  • [x] GenieX sous Windows sur ARM répertorie désormais les modèles trouvés dans votre répertoire de modèles local et vous permet d'extraire des modèles directement depuis Hugging Face dans l'interface utilisateur.
  • [x] Clicochez la balise de version en haut de la fenêtre pour accéder plus facilement à vos journaux et à votre répertoire de stockage

Améliorations

  • [x] La navigation Web est désormais activée par défaut pour les agents
  • [x] Les fournisseurs locaux signalent désormais l'état de chargement du modèle dans le chat afin que vous sachiez pourquoi la première réponse est lente
  • [x] Le runtime Ollama est passé à 0.33.3 avec une liste de modèles groupés mise à jour
  • [x] Suppression des bordures autour de la zone de contenu principale pour une présentation plus propre du bureau
  • [x] Refonte de la disposition modale "nouvelle fonctionnalité"
  • [x] Les dates dans les tableaux sont désormais affichées dans un format lisible par l'homme
  • [x] Les pages Web supprimées préservent désormais les tableaux, les listes ordonnées et les blocs de code au lieu de les aplatir.
  • [x] pages PDF sont désormais jointes avec des sauts de ligne afin que les mots ne fusionnent pas au-delà des limites des pages
  • [x] Les intégrations Mistral sont désormais regroupées, ce qui rend l'intégration de documents volumineux beaucoup plus rapide.
  • [x] La recherche de documents correspond désormais à vos termes littéralement plutôt que sous forme d'expression régulière
  • [x] Les documents surveillés effacent désormais les vecteurs obsolètes lors de la synchronisation
  • [x] AnySearch en tant que fournisseur de recherche sur le Web
  • [x] Le fournisseur KoboldCPP révisé et modernisé pour correspondre au reste de nos fournisseurs
  • [x] Keenable ajouté en tant que fournisseur de recherche Web
  • [x] Sélection du niveau de service OpenRouter pour contrôler le coût et la priorité du routage
  • [x] Édition d'images LocalAI via des images de référence
