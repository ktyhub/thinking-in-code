n'importe quoi-llm v1.12.1

Améliorations notables

Intégration de documents en streaming

Désormais, lorsque vous téléchargez un document dans l'espace de travail, le processus par document est désormais signalé lors de l'intégration. Il s’agit d’une énorme amélioration des performances et de l’expérience utilisateur. Au cours de ce processus, vous pouvez ajouter et supprimer des documents à la file d'attente, ainsi que fermer et quitter la page sans perdre votre progression.

<img width="1745" height="1011" alt="queue-embedding" src="https://github.com/user-attachments/assets/ffbd06ad-cd2c-480a-89ba-bb7a0068abbc" />

Intégrations d'applications

Il existe désormais des intégrations intégrées pour les applications suivantes avec une configuration minimale, voire nulle, requise pour les compétences d'agent :

  • Gmail
  • Perspectives
  • Google Agenda

Autres améliorations

  • [x] Image Lightbox dans l'interface utilisateur principale
  • [x] Activation de la prise en charge des caractères coréens, chinois et japonais pour la génération de PDF via un fork mdpdf personnalisé
  • [x] De meilleures citations pour les intégrations d'applications
  • [x] Recherche Web par défaut du DDG dans les compétences des agents
  • [x] Ouvrir des documents dans une application native sur la machine lorsqu'ils sont générés par l'agent de génération de documents
  • [x] Approuver automatiquement la compétence de l'agent via le paramètre ENV
  • [x] Ollama est passé à 0.20.7 (support Qwen3.5, Gemma 4, etc.)
  • [x] Nouveau paramètre de personnalisation > Chat pour Unload model when closed pour décharger le modèle lorsque l'utilisateur ferme la fenêtre de discussion.
  • [x] Détection de capacité OpenAI générique/paramètre ENV
  • [x] Mettre à jour Lemonade pour prendre en charge les modifications de 1.10.0
  • [x] traductions catalanes
  • [x] Champ de nom ajouté aux clés API
  • [x] ID de chat signalé dans les sessions d'agent, vous pouvez donc désormais régénérer les chats, TTS et plus d'actions sans recharger la page.
