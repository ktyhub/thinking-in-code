anything-llm v1.16.0

n'importe quoi-llm v1.16.0

Changements notables

Génération d'images

Vous pouvez désormais générer des images via /img lorsqu'un [fournisseur pris en charge est configuré] (https://docs.anythingllm.com/features/image-generation#supported-providers).

Ce flux autorise également les pièces jointes d'images pour les modifications, les suivis ou les invites combinées si votre fournisseur prend en charge l'édition d'images.

<img width="2254" height="986" alt="image" src="https://github.com/user-attachments/assets/9286ba43-c8fe-43f9-a18d-6c2814f6907f" />

La possibilité pour un outil-agent de générer des images sera disponible dans la prochaine mise à jour.

Meilleure expérience utilisateur du sélecteur de fichiers

Désormais, dans le sélecteur de fichiers, vous pouvez faire glisser des dossiers entiers et leur hiérarchie sera conservée dans le panneau de téléchargement. Cela importera uniquement les fichiers de niveau supérieur dans le dossier – ils seront approfondis et récursifs dans une mise à jour ultérieure.

Vous pouvez également désormais glisser-déposer un fichier directement dans un dossier existant sans avoir à le déplacer.

Enfin, vous n'avez plus besoin de taper https dans l'outil de récupération d'URL - il supposera simplement https lorsqu'il est laissé de côté.

Nous avons également apporté d'importantes améliorations en termes de performances, comme le chargement différé des dossiers, pour ceux qui contiennent des milliers de documents dans un dossier.

Outil Basculer à mi-session

Désormais, pendant les discussions agents, vous pouvez librement activer/désactiver les outils à volonté sans avoir besoin de recharger ou de démarrer une nouvelle session. Seuls les outils configurés (si une configuration est requise) sont disponibles.

Arrêter la génération

Une grande amélioration est maintenant que la réponse aborting tue également complètement l'inférence, de sorte que l'inférence fantôme ne continue pas lorsqu'elle n'est plus souhaitée à mi-parcours.
