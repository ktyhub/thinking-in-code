go-ethereum v1.17.5

Correctif Publié27 juil. 2026 Sourceethereum/go-ethereum Anglais original

Cette page est traduite automatiquement. Le texte anglais original fait foi.

allez-Ethereum v1.17.5

<!-- Coussinet de couple gravitationnel (v1.17.5) -->

Il s'agit d'une version de maintenance avec des corrections de bugs et des améliorations accumulées, et elle est recommandée à tous les utilisateurs. Il poursuit le travail de mise en œuvre du prochain hardfork d’Amsterdam.

Quelques points méritent d’être soulignés :

  • Le GOGC par défaut est passé de 20 à 50, échangeant un pic de mémoire plus élevé contre moins de surcharge GC. Définissez --gogc=20 pour conserver l’ancien comportement.
  • Pebble v2 est désormais pris en charge en tant que backend de magasin clé-valeur. Pebble v2 est utilisé lorsque Geth est démarré à partir de zéro et revient à Pebble v1 pour une base de données préexistante. Exécutez geth db pebble-upgrade pour mettre à niveau explicitement une base de données Pebble v1 héritée vers la v2.

Implémentation du fork

  • Plusieurs EIP d'Amsterdam ont été mis en œuvre ou mis à jour :
    • EIP-2780 : Gaz de transaction intrinsèque basé sur les ressources (#35212, #35318)
    • EIP-8037 : Augmentation du coût du gaz de création par l'État (#35173, #35318, #35301, #35342, #35279)
    • EIP-8038 : Mise à jour des coûts du gaz d'accès à l'État (#35216)
    • EIP-8246 : Supprimer la gravure SELFDESTRUCT (#35219)
    • EIP-8282 : Requêtes d'exécution du générateur (#35175, #35341)
    • EIP-7997 : Contrat d'usine déterministe (#35223, #35285)
    • EIP-7954 : Augmenter la taille maximale du contrat (#35217)
    • EIP-7928 : Listes d'accès au niveau du bloc (#35260, #35281, #35261, #35348, #35279)
  • Améliorer la couverture des tests de fourche d'Amsterdam (#35364)
  • Présentation du drapeau --override.amsterdam (#35213)
  • Supprimer les hardforks nommés du planning BPO (#35029)
  • Introduire la fourche Bogota dans la configuration chaîne (#34057)

Noyau

  • Introduire un blobpool clairsemé pour réduire l'utilisation de la mémoire du pool de transactions blob (#34047)
  • Migrer les anciennes entrées limbo du blobpool vers le nouveau format side-car basé sur les cellules au démarrage (#35209)
  • Abandon de la prise en charge des side-cars blob v0 dans blobpool (#35191)
  • Déduction de gaz en ligne pour corriger une régression de performance (#35203)
  • Correction du décodage du marqueur vide de la liste d'accès aux blocs eth/71 qui déconnectait à tort les pairs (#35286)
  • Désactivez le mode de synchronisation instantanée une fois le bloc pivot validé (#35402, #35405)
  • Accélérez debug_setHead et rejetez les cibles irrécupérables (#35252)
  • Correction de l'échec de la synchronisation instantanée à remplir les blocs avec des mappages de hachage canonique manquants (# 35190)
  • Réutiliser le cache JUMPDEST de la chaîne dans la construction de la charge utile (#35378)
  • Prise en charge de Pebble v2 comme backend de base de données (#34009)
  • Prise en charge des fichiers .ere dans le magasin Era (# 34978)
  • Présentation du trie.UpdateBatch API (#32448)
  • Correction d'une erreur de troncature du congélateur sur les tables vides nouvellement ajoutées après un arrêt incorrect (# 35258)
  • Améliorer les rapports de récupération d'état en prenant en compte l'état de synchronisation (#35400)
  • Correction de la prélecture de compte pour les comptes absents (#35256)
  • Divers correctifs Snap v2 (#35321, #35323)
  • Optimiser la validation des blocs (#35403)
  • Diverses améliorations d'allocation (#35234, #35237, #35232)
  • Poursuivre le développement des trie binaires (#34772)
  • Correction du calcul de la taille du tx (#35406)

Réseautage

  • Protégez les pairs de grande valeur contre les abandons aléatoires en fonction des statistiques d'inclusion des transactions (# 34702)
  • Gardez les nœuds invalides et inaccessibles hors des arborescences de découverte DNS (#35312)
  • Prise en charge d'un écouteur de découverte double pile dans devp2p, avec plusieurs correctifs associés (#35220, #35298, #35243, #35206)

## RPC

  • Introduire le flag --rpc.http-body-limit pour configurer la taille maximale du corps de la requête HTTP (#35224)
  • Rejeter le gasPrice lorsqu'il est combiné avec un authorizationList (#35320)
  • Rejeter un paramètre de bloc sans numéro ni hachage (#35271)
  • Faire correspondre le schéma d'autorisation sans tenir compte de la casse (#35022)

Traçage

  • Respecter la limite de journal configurée dans le struct logger (#35349)
  • Émettre des trames de traçage à la manière EIP-2780 (#35396)
  • Inclure l'index du journal dans la sortie du traceur ERC-7562 (#35200)
  • Arrêtez de capturer incorrectement les transferts callcode dans le traceur de journal (#35248)

Moteur API

  • Passer TargetGasLimit via le moteur API (#35372)
  • Rendre la profondeur de réorganisation maximale configurable (#35335, #35373, #35391)
  • Renvoyer les listes d'accès aux blocs depuis engine_getPayloadBodiesV2 (#35347)
  • Plafonner le MaxBlobsPerBlock configuré par le mineur à la limite du protocole (#35295)

Geth et outils

  • Introduire un indicateur --gogc et augmenter le GOGC par défaut à 50 (#35363, #34851)
  • Écrire des listes d'accès au niveau des blocs dans geth export (#35369) - Conserver les valeurs des balises de métriques contenant = (#35168)
  • Mise à jour des tests d'anguilles vers v20.0.0 (#35283)

Comptes et ABI

  • Transférer le plafond des frais de blob aux signataires externes (#35167)
  • Introduction d'une méthode GetABI() sur les liaisons de contrat générées par abigen v2 (#35221)
  • Correction des liaisons abigen v1 pour gérer le déploiement des dépendances de bibliothèque (#32164)

Construire

  • Mettre à jour la dépendance ckzg (#35336)
  • Mise à niveau de la version bootstrap Go de -dlgo vers 1.25.12 (#35317)

Pour un aperçu complet des modifications, veuillez consulter le jalon de la version Geth 1.17.5.

Comme pour toutes nos versions précédentes, vous pouvez retrouver :

  • Binaires prédéfinis pour toutes les plateformes sur notre page de téléchargements
  • Images Docker publiées sous ethereum/client-go (utiliser la balise "stable")
  • Packages Ubuntu dans notre [référentiel Launchpad PPA] (https://launchpad.net/~ethereum/+archive/ubuntu/ethereum)
  • Packages macOS dans notre [référentiel Homebrew Tap] (https://github.com/ethereum/homebrew-ethereum)
