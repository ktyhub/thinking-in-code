go-ethereum v1.17.3

Correctif Publié11 mai 2026 Sourceethereum/go-ethereum Anglais original

Cette page est traduite automatiquement. Le texte anglais original fait foi.

allez-Ethereum v1.17.3

<!-- Injecteur enzymatique (v1.17.3) -->

Il s'agit d'une version de maintenance avec des progrès continus dans la mise en œuvre du fork d'Amsterdam. Il introduit également ETH/70, qui est désormais disponible sur le réseau.

Changement radical pour le traçage des API (debug_trace*), en particulier le traceur structLog (opcode). Les champs de réponse suivants suivent désormais la nouvelle spécification client-wide (ethereum/execution-apis#762) et reexec a été supprimé de la configuration de traçage :

  • memory : les mots sont préfixés par 0x et complétés à 32 octets
  • storage : les clés et les valeurs sont préfixées par 0x
  • error : omis lorsqu'il est vide (précédemment sérialisé comme "")

###Geth

  • Ajout d'un mécanisme de nouvelle tentative pour l'initialisation du point de contrôle dans blsync (#33966)
  • Ajout d'une sous-commande pour la conversion d'arbre binaire hors ligne (#33740)
  • Ajouter un exportateur de code pour l'exportation de base de données (#34696)

Noyau

  • Mises à jour de la fourchette d'Amsterdam :

    • Conditions préalables de l'EIP-8037 : Augmentation du coût du gaz de création de l'État (#34691, #34712, #34841)
    • EIP-7976: Increase Calldata Floor Cost (#34748)
    • EIP-7981 : Augmenter le coût de la liste d'accès (#34755)
    • EIP-7610 : Rejeter la création de contrat lorsque le stockage n'est pas vide (#34718)
    • Mettre à jour les tests d'état (#34671)
  • Implémenter l'arène de pile (#33960)
  • Implement EIP-7975: eth/70 partial block receipt lists (#33153)
  • Prérequis du protocole snap/2 (#34083, #34649, #34654, #34874)
  • Implémentation d'un élagage d'index d'historique pour les nœuds d'archive en mode chemin (#33999)
  • Add Prague chain segment pruning point for Hoodi (#34714)
  • Autoriser la réorganisation de la tête vers le parent dans les 32 blocs sous ePBS (#34767)
  • Arrêter de répondre aux demandes de segments de chaîne lorsque les données ne sont pas disponibles (#34787)
  • Drop peers sending invalid bodies or receipts (#34745, #34870)
  • Ajout de fonctions liées aux cellules kzg4844 (#34766)
  • Refactorisation de la base de données d'état (#33102, #34700, #34763, #34724)
  • Améliorations des trie binaires (#34055, #34110, #34670, #34676, #34680, #34690, #34754, #34758, #34777, #34794)
  • Merge EIP-4762 access events for all system calls (#34637)
  • Rejeter les couches en double dans la base de données des chemins (#34642)
  • Omit empty slotNumber and fix block value collection in pre-Amsterdam engine API payloads (#34704)
  • Include the operand in EIP-8024 error messages (#34635)
  • Fix vmodule downgrades and propagate verbosity changes to derived loggers (#33111)
  • Fix incorrect fsync ordering for index file truncation (#34728)

  • Correction du calcul de la taille dans la base de données des chemins (#34828)
  • Correction du plafond de taille de file d'attente espacé dans blobpool (#34831)
  • Improve txpool pending concurrency by using read-only locking (#32924)
  • Remplacer le TypeMux obsolète par Feed (#32585)
  • Continue blob retrieval when individual cell proof extraction fails (#34891)
  • Utilisez uint256 dans le message principal pour des calculs de gaz plus rapides (#34934)

Réseautage

  • Correction de la sortie anticipée de la boucle de délai d'attente lors de la suppression des matchers expirés (#34743, #34878)
  • Empêchez les courses de données en copiant les tampons de découverte avant les erreurs de lecture non gérées (#34888)
  • Fix discover waitForNodes deadlock by decoupling nodeFeed from table mutex (#34898)
