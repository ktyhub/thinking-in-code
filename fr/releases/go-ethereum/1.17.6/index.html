go-ethereum v1.17.6

Correctif Publié23 sept. 2026 Sourceethereum/go-ethereum Anglais original

Cette page est traduite automatiquement. Le texte anglais original fait foi.

allez-Ethereum v1.17.6

<!-- Lubrifiant inorganique (v1.17.6) -->

Il s'agit d'une version de maintenance avec un certain nombre d'améliorations de performances pour le traitement des blocs et la synchronisation initiale, et elle est recommandée à tous les utilisateurs.

Quelques points méritent d’être soulignés :

  • Le hardfork d'Amsterdam est programmé sur le testnet Sepolia à l'horodatage 1791294816 (6 octobre 2026, 13:53:36 UTC). Les opérateurs de nœuds Sepolia doivent effectuer une mise à niveau avant cette date.
  • Le testnet Holesky a été supprimé, car le réseau a atteint sa fin de vie.
  • Go 1.24 n'est plus pris en charge. Les binaires de version et les images Docker sont désormais construits avec Go 1.27.

Implémentation du fork

  • Programmer le fork d'Amsterdam sur Sepolia (#35734)
  • Supprimer l'implémentation EIP-7610 (#35581)
  • Mise à jour des paramètres de gaz EIP-2780 et EIP-8038 (#35454, #35497)
  • Mise à jour du contrat d'usine déterministe EIP-7997 (#35458)
  • Mise à jour EIP-8037, remboursant d'abord la dette de gaz impayée après avoir absorbé un cadre enfant (#35633)
  • Implémenter l'exécution de blocs parallèles pilotée par la liste d'accès au niveau des blocs (#35264, #35441, #35443, #35459, #35461, #35465, #35575, #35693)
  • Renommez « gaz ordinaire » en « gaz d'exécution » pour correspondre à EIP-8037 (#35457, #35486)

Noyau

  • Supprimez le testnet Holesky (#35591)
  • Optimiser le décodage JSON des requêtes volumineuses telles que engine_newPayload (#35518)
  • Traiter les reçus de construction de bloom et de calcul de racine parallèlement à l'exécution (#35738)
  • Introduire un cache de résultats de précompilation partagé entre le préfetcher, le traitement des blocs et le mineur (#35388, #35473, #35526, #35578, #35753)
  • Paralléliser les données de la chaîne et les écritures d'état dans le commit post-exécution (#35595)
  • Ne pas sceller un bloc si une erreur de base de données s'est produite (#35427)
  • Correction d'une panique dans l'indexeur de log lorsqu'une réorganisation raccourcit la chaîne sur le bloc rendu (#35619)
  • Honorez ExecuteConfig.EnableTracer pour les hooks de traçage de niveau EVM (#35512)
  • Ajouter une variante de cache LRU mesurée (#33719)
  • Conserver les listes d'accès au niveau des blocs aux côtés des blocs défectueux (# 35423)
  • Désactivez la liste d'accès au niveau du bloc à la fin de chaque transaction (#35498)
  • Correction de l'initialisation du cache blob (#35509)
  • Correction d'une troncature de tête sous un groupe de queue divergé (#35551)
  • Améliorer le récupérateur de blob avec quelques opérations défensives (#35572)
  • Correction d'un blocage lors de la nouvelle demande de reçus partiels dans eth/70 (#35537)
  • Rejeter les réponses de reçus partiels vides dans eth/70 (#35593)
  • Limiter la taille totale des transactions blob bloquées dans le blobpool clairsemé (#35367)
  • Correction de l'encodage RLP Cells/GetCells dans eth/72 (#35428)
  • Mettre en cache les blobs récupérés dans le blobpool pour accélérer le service des pairs pré-eth/72 (#35543)
  • Ajout d'une validation fork pour les types de transactions dans la transition d'état (#35588)
  • Évitez d'annoncer des transmissions blob éparses aux anciens pairs (# 35589)
  • Ajouter des tests eth/71 (EIP-8159) (#35389)
  • Fixer les crochets traceurs de gaz et mesure de gaz (#35646)
  • Le tampon blob eth/72 est plafonné à 128 Mio au total et 16 Mio par homologue (#35766)

Synchronisation

  • Optimiser la synchronisation des états en parallélisant le traitement des réponses (#35533)
  • Implémenter le téléchargement au mieux des listes d'accès au niveau des blocs (#35386, #35493)
  • Retravailler la planification des récupérations de corps et de reçus lors de la synchronisation (#35680)
  • Ajouter des métriques pour le téléchargement des segments de chaîne et la progression de la synchronisation instantanée (#35678, #35689)
  • Divers correctifs et améliorations de Snap v2 (#35299, #35316, #35463, #35477, #35705, #35722)

Réseautage

  • Valider la taille de transaction blob annoncée par rapport à la version du protocole de l'annonceur (#35524)
  • Ajouter plus de couverture de ruche discv5 à devp2p (#34770)
  • Ajouter les tests eth/72 et les données de test d'Amsterdam à devp2p (#35368, #35637, #35647, #35648, #35687)
  • Ajoutez devp2p discovery listen pour servir discv4 et discv5 sur un seul socket UDP (#35254)

Cryptographie

  • Reconstruire les blobs directement à partir des cellules de données sans récupération KZG (#35528)
  • Récupérer l'ensemble complet de cellules d'un blob avec un chemin rapide pour les cellules de données complètes (#35529)
  • Correction de G2.Neg dans la bibliothèque bn256 en synchronisant avec l'amont (#35686)

Moteur API

  • Ajoutez la prise en charge de TargetGasLimit en option et appliquez la vérification du code du contrat système (# 35514)
  • Autoriser la réorganisation de headBlock jusqu'à finalized (#35519)
  • Fixer le portail de fourche sur engine_forkchoiceUpdatedWithWitnessV3/V4 (#35719)
  • Passer targetGasLimit dans testing_buildBlockV1 (#35501)
  • Correction des échecs de la ruche (#35580, #35664)
  • Correction de engine_getBlobsV4 renvoyant des cellules nulles pour les entrées de cache en mode blob (#35439)

## RPC

  • Rejeter null pour les arguments requis (#35576)
  • Unescape les clés d'objet JSON lors de l'analyse d'un message (#35587)
  • Rejeter les gammes eth_getLogs avec toBlock avant fromBlock (#35070)
  • Ignorer les forks non configurés lors du calcul du prochain fork dans eth_config (#35553)
  • Renvoyez null pour pending et les balises insolubles dans eth_getHeaderByNumber (#35627)
  • Traitez un remplacement de difficulté post-fusion comme une non-opération dans eth_simulateV1 (#35672)
  • Rejeter les arguments d'appel blob et setcode sans to (#35695)
  • Supprimer la protection contre les gaz par autorisation dans le eth_createAccessList (#35698)
  • Renvoyez le gaz réellement utilisé pour les estimations de transfert simples après Amsterdam (#35592)
  • Rendre le paramètre de bloc du debug_traceCall facultatif (#35583)
  • Ajouter slotNumber au schéma de bloc GraphQL (#35469)
  • Renvoie NotFound lorsque le nombre de transactions en bloc est nul dans ethclient (#35605)
  • Vérifiez la liste de retrait par rapport à la racine d'en-tête dans ethclient (#35610)

Geth et outils

  • Déprécier l'outil de dimensionnement d'état (#35520)
  • Utiliser les noms Solidity d'origine pour les erreurs personnalisées dans les liaisons abigen v2 (#35332)
  • Filtrer les journaux inattendus du flux d'abonnement aux événements au lieu d'y mettre fin (#35701)
  • Respecter la limite de log configurée dans les hooks struct logger OnEnter/OnExit (#35360)
  • Ajout d'un test t8n pour une configuration manquante des frais de base à Londres (#35636)

Construire

  • Supprimez la prise en charge de Go 1.24 et ajoutez la prise en charge de Go 1.27 (# 35573)
  • Mise à niveau de la version bootstrap Go du -dlgo vers 1.27.1 (#35656)
  • Créer des packages RPM pour Fedora COPR (#35557)
  • Ajout d'un mécanisme de nouvelle tentative pour le téléchargement des packages (#35510)

Pour un aperçu complet des modifications, veuillez consulter le jalon de la version Geth 1.17.6.

Comme pour toutes nos versions précédentes, vous pouvez retrouver :

  • Binaires prédéfinis pour toutes les plateformes sur notre page de téléchargements
  • Images Docker publiées sous ethereum/client-go (utiliser la balise "stable")
  • Packages Ubuntu dans notre [référentiel Launchpad PPA] (https://launchpad.net/~ethereum/+archive/ubuntu/ethereum)
  • Packages macOS dans notre [référentiel Homebrew Tap] (https://github.com/ethereum/homebrew-ethereum)
