appsmith v2.5.0

🗑️ Rappel de suppression de fonctionnalités - 30 septembre 2026 - EOL

Appsmith AI a atteint la fin de sa vie utile le 30 septembre 2026.

Vous ne pouvez plus ajouter de nouvelles connexions ou requêtes de source de données Appsmith AI. Les requêtes existantes ont cessé de fonctionner, que vous ayez effectué ou non la mise à niveau.

Migrez les requêtes Appsmith AI restantes vers une source de données directe d'un fournisseur, telle qu'OpenAI, Anthropic ou Google AI.

⚠️ Notes de mise à niveau importantes

  • Les applications connectées à Git sont mises à jour vers le schéma de serveur 13 lors de leur prochaine ouverture. Cela peut créer une validation système unique. Les applications exportées à partir de cette version ne peuvent pas être importées dans un serveur plus ancien qui prend uniquement en charge le schéma 12. (#42322)
  • Lorsque vous modifiez un paramètre de connexion à une source de données, vous devez saisir à nouveau les informations d'identification pour les paramètres d'authentification active, TLS et SSH. Les connexions inchangées peuvent continuer à utiliser les informations d'identification enregistrées. (#42339)
  • Les liaisons de corps Elasticsearch utilisent désormais la substitution typée JSON. Examinez les requêtes qui insèrent JSON sérialisé, créent une partie d’une chaîne JSON ou construisent des chemins dynamiques. Les liaisons invalides renvoient désormais une erreur de requête. (#42342)

🔐 Sécurité

  • Mise à jour des dépendances groupées pour corriger les vulnérabilités signalées. (#42314, #42324, #42331)
  • La réutilisation des informations d'identification de la source de données est désormais liée à la configuration de connexion enregistrée, et les demandes de test, de structure et de déclenchement de la source de données utilisent des contrôles d'autorisation plus stricts. (#42339)
  • Les requêtes de l'environnement d'évaluation conservent désormais la protection contre les omissions d'informations d'identification même si le constructeur de requête global change. (#42355)
  • Les limites de taux de connexion utilisent désormais la même identité de compte normalisée que l'authentification. (#42337)
  • Les mises à jour de la source de données préservent désormais l'identité de la source de données sélectionnée par la requête. (#42356)
  • Les requêtes Elasticsearch valident désormais les valeurs JSON substituées et les chemins dynamiques avant l'exécution. (#42342)

🛠️ Fiabilité

  • Les appels de procédure stockée MySQL préparés peuvent désormais s'exécuter avec une requête de fin et conserver les valeurs liées sous forme de données. (#42329)
  • Les échecs de connexion OAuth2 et SSO renvoient désormais les utilisateurs à la page de connexion de l'instance. (#42330)
  • Les zones dans les cartes, onglets, feuilles et éléments de liste utilisent désormais toute la largeur disponible au lieu de se réduire en une colonne étroite. (#42364)
  • La création de sources de données MCP permet désormais au serveur de sélectionner le bon environnement. (#42341)

✨ Nouvelles fonctionnalités et améliorations

  • Les candidatures peuvent désormais avoir une description facultative qui apparaît sur les fiches de candidature. (#42312)
  • Les widgets de liste disposent désormais d'une option Désactiver la sélection pour les applications qui n'ont pas besoin de sélection de ligne ou de comportement item-click. (#42261)
  • MCP peut désormais créer et mettre à jour des objets JS structurés, utiliser davantage de types de filtres MongoDB, corriger davantage de paramètres de widget, câbler des appels de fonction JS et détecter les problèmes de mise en page courants. (#42311)

🎨 Améliorations de l'interface utilisateur et des widgets

  • Les colonnes de tableau disposent désormais d'un paramètre facultatif En-tête pour les titres de colonnes longs. (#42354)
  • Les en-têtes de tableau prennent désormais en charge l'épaisseur de police configurable, le texte en italique et le soulignement. (#42323)
  • La page Applications reste désormais sous la bannière URL de base manquante, de sorte que les contrôles de l'espace de travail restent visibles. (#42319)

🔧 Git, déploiement et configuration

  • Les journaux MCP enregistrent désormais le résultat réel de chaque appel d'outil et conservent l'ID de demande correct sur les appels backend associés. (#42350)
