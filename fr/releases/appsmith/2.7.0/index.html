appsmith v2.7.0

⚠️ Notes de mise à niveau importantes

  • Helm chart : si vous définissez des touches probes, les touches que vous n'avez pas définies prennent désormais les nouvelles valeurs par défaut (période de 10 s, timeout de 5 s). Si vous avez réglé failureThreshold pour l'ancienne période des années 60, réglez également periodSeconds: 60. Les valeurs de sonde qui ne sont pas des entiers positifs échouent désormais à helm install et helm upgrade. Les numéros cités tels que "5" fonctionnent toujours. (#42571)
  • navigateTo sur un nom de page qui n'existe plus échoue désormais avec "Entrez une URL ou un nom de page valide", même lorsqu'une valeur de paramètre contient un point. Avant, il ouvrait le nom sous forme d'adresse Web, telle que https://OldPage?file=report.pdf. Un hôte à un seul mot tel que intranet avec un paramètre en pointillés échoue désormais également. Utilisez plutôt une URL complète. (#42513)

🔐 Sécurité

  • Mise à jour des dépendances groupées pour résoudre une vulnérabilité signalée. (#42502)
  • La lecture des bibliothèques JS personnalisées d'une application nécessite désormais un accès en lecture à cette application. (#42431)
  • L'activation de Rendre l'application forkable nécessite désormais une autorisation d'exportation sur l'application. Les utilisateurs disposant d'un accès en modification peuvent toujours le désactiver et apporter d'autres modifications. (#42411)
  • Les sources de données compatibles S3 et DynamoDB suivent désormais la politique d'hôte restreint qui couvre déjà REST, GraphQL, Elasticsearch, Redis et SMTP. Une source de données dont l'hôte de point de terminaison est bloqué ne parvient pas à enregistrer, tester ou exécuter avec Host not allowed. (#42527)

🛠️ Fiabilité

  • La suppression d'une application connectée à Git revient dès que l'application est supprimée. Le nettoyage du référentiel local s'exécute ensuite, de sorte qu'un disque lent n'expire plus le délai de suppression et ne laisse plus la carte d'application en place. (#42519)
  • MCP read_pages renvoie un layoutId pour chaque page. Les lectures de pages parallèles ne sont plus refusées par la vérification des jetons, une lecture échouée est réessayée une fois et une page qui échoue toujours indique pourquoi. (#42360, #42529)
  • MCP refuse les entrées qui donnaient des résultats erronés ou erronés. Exemples : des accolades déséquilibrées dans les arguments d'appel de wire_event, une page d'une autre application dans les outils de mise en page et un filtre SQL structuré sur une colonne nommée comme un mot-clé SQL. (#42536, #42537)
  • Les mises à jour de la mise en page MCP sont refusées lorsque la page a changé après sa lecture par l'agent. (#42538)

✨ Nouvelles fonctionnalités et améliorations

  • Hauteur automatique du tableau : définissez la Hauteur du tableau sur Hauteur automatique (ou Hauteur automatique avec limites) et choisissez Lignes par page. Le tableau s'agrandit pour s'adapter à ces lignes et la page défile à la place du tableau. Les tables existantes restent Fixes. (#42489, #42585)
  • Paramètres de l'application → La navigation comporte les options Afficher le partage et Afficher toutes les applications pour masquer ces boutons dans l'application publiée. Les deux sont activés par défaut. Les autorisations de partage ne changent pas. (#42487)
  • L'exportation de page (menu de la page → Exporter) comporte Sélectionner tout dans chaque section : objets JS, bases de données, requêtes et bibliothèques personnalisées. (#42453)
  • Les boutons du groupe de boutons peuvent afficher une info-bulle, comme le fait le widget Bouton. (#42583)
  • Le formulaire JSON a un paramètre Couleur de police du titre sous Style → Couleur. (#42565)
  • Le SQL structuré MCP peut afficher une valeur de secours pour une colonne NULL avec coalesce. (#42497)
  • Le SQL structuré MCP peut filtrer les groupes agrégés avec having. (#42503)
  • Le SQL structuré MCP peut diviser une colonne délimitée et compter chaque élément, sur PostgreSQL. (#42504)
  • MCP get_action renvoie le SQL d'une requête écrite par MCP, à condition que personne ne l'ait modifié dans l'éditeur. (#42505)
  • Le nouvel outil MCP set_page_visibility masque ou affiche une page. La page d'accueil ne peut pas être masquée. (#42506)
  • Les événements de navigation MCP peuvent transmettre des paramètres d'URL, tels que l'identifiant de la ligne sélectionnée. (#42507)
  • La suppression de widgets via MCP nécessite désormais l'approbation de l'utilisateur (prepare_remove_widgets, confirm_remove_widgets), comme le fait déjà la suppression d'une page ou d'une requête. (#42509)
  • Les objets MCP JS peuvent trier, couper, additionner, faire la moyenne et regrouper les lignes, ainsi que les dates de compartiment par jour, semaine ou mois. (#42511)
  • MCP peut créer des formulaires conditionnels : valeurs par défaut et limites qui dépendent d'un choix, date mathématique, champs affichés ou obligatoires dans un cas, un bouton de soumission désactivé jusqu'à ce que le formulaire soit valide et le nom ou l'adresse e-mail de l'utilisateur connecté. (#42540)
  • MCP peut lire les objets JS écrits dans l'éditeur. Lorsque l'approbation est configurée, elle peut les remplacer une fois que l'utilisateur a approuvé. (#42538)
  • MCP écrit les objets JS sous forme de code lisible et formaté. (#42549)
  • Les requêtes structurées MCP produisent un corps exécutable sur Oracle et utilisent des valeurs strictes dans les requêtes MongoDB. (#42538)

🎨 Améliorations de l'interface utilisateur et des widgets

  • Les téléchargements de tableaux CSV et Excel écrivent du texte brut pour les colonnes HTML, pas du HTML brut. (#42557)
  • Les contrôles Bouton Icône, Bouton Menu et Vidéo dans les cellules du tableau s'adaptent à la hauteur de la ligne, de sorte que les tableaux paginés n'ont plus besoin d'une barre de défilement pour atteindre la dernière ligne. (#42570)
  • La désactivation du défilement infini dans un tableau n'active plus Autoriser l'ajout d'une ligne, la recherche, les filtres et le tri. Ils restent éteints jusqu'à ce que vous les allumiez. (#42573)
  • Le champ Désactivé de la colonne Table Save/Discard affiche à nouveau sa liaison complète. Le modifier n'active plus Enregistrer/Rejeter sur chaque ligne. (#42589)
  • La réinitialisation d'un formulaire JSON maintient un champ de tableau vide, le formulaire reste donc valide. (#42226)
  • Un champ de date obligatoire dans le formulaire JSON affiche son erreur uniquement après que l'utilisateur l'a touché, comme les autres champs. (#42514)
  • Le sélecteur de logo de l'espace de travail ne propose plus le SVG, que le serveur rejetait toujours. Les fichiers JPG peuvent désormais être sélectionnés. (#42594)
  • L'éditeur masque la source de données Appsmith AI retirée et ses requêtes. Le service s'est arrêté le 30 septembre 2026. Ask AI n'est pas concerné. (#42559)

🔧 Git, déploiement et configuration

  • Les sondes d'intégrité du graphique de barre s'exécutent désormais toutes les 10 s avec un délai d'attente de 5 s. Le démarrage permet de démarrer pendant 600 s, la vivacité redémarre le conteneur après 180 s d'échec et l'état de préparation indique que le pod n'est pas prêt après 30 s. L’enregistrement des paramètres d’administration qui redémarrent le serveur n’entraîne plus la mort du conteneur. (#42571)
  • Les sauvegardes peuvent ignorer les collections MongoDB répertoriées dans APPSMITH_BACKUP_EXCLUDE_COLLECTIONS (séparées par des virgules). (#42581)
  • Le serveur enregistre les raisons pour lesquelles il refuse un jeton MCP, comme une clé expirée ou révoquée. Il n'enregistre jamais le secret. (#42593)
