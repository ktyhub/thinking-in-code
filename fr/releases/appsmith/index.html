v2.7.0 Mineure MT

Helm chart : si vous définissez certaines clés de sondes, les clés que vous n'avez pas définies prennent désormais les nouvelles valeurs par défaut (période de 10 s, délai d'attente de 5 s). Si vous avez réglé FailureThreshold pour l'ancienne période de 60 s, définissez également periodSeconds : 60.
