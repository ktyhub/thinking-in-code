agent-lightning v0.2.0

Agent-Lightning v0.2.0 introduit des améliorations majeures du framework, de nouvelles stratégies d'exécution, une documentation étendue et une fiabilité améliorée dans le flux de travail de formation et de déploiement des agents. Cette version comprend 78 pull request depuis v0.1.2.

Améliorations principales

  • Lightning Store : ajout d'une interface unifiée et d'une implémentation pour le stockage principal d'Agent-lightning.
  • Émetteur : émission d'objets sous forme de spans vers le magasin.
  • Adaptateur et Tracer : adaptation aux messages de type OpenAI et traceur factice OpenTelemetry.
  • LLM Proxy : Ajout du LLM Proxy en tant que citoyen de première classe dans Agent-lightning.
  • Agent Runner : Nouvelle version offrant une conception de coureur plus modulaire et plus robuste.
  • Algorithmes intégrés : les algorithmes sont désormais intégrés directement dans les entraîneurs pour plus de simplicité.
  • Nouvelles stratégies d'exécution : introduction des modèles d'exécution Client-Server et Shared Memory.
  • Mises à jour du formateur : interfaces v0.2 intégrées et validation FastAlgorithm.

Documentation et exemples

  • Documentation remaniée avec de nouveaux guides pour la création d'agent, la formation, le débogage et les concepts de magasin. * Tutoriels de démarrage rapide améliorés, installation clarifiée et nouveaux articles approfondis.
  • Exemples ajoutés et mis à jour : SQL Agent, Calc-X, Local SFT, Search-R1 et APO algorithm.

Expérience du développeur

  • Migration des pipelines de build et CI vers 1ES, fractionnement des flux de travail et regroupement des badges pour plus de clarté.
  • Adoption de uv comme gestionnaire de dépendances.
  • Ajout de workflows pytest basés sur GPU pour une couverture complète des tests.
  • Amélioration de l'expérience utilisateur de débogage, des configurations de pré-validation et du peluchage (correctifs Pyrright, tri des importations).

Écosystème et intégrations

  • Ajout de la prise en charge des agents créés avec Agent-framework.
  • Ajout de nouvelles listes de communautés : DeepWerewolf et AgentFlow.

Nouveaux contributeurs

Bienvenue à nos nouveaux contributeurs : @hzy46, @lunaqiu, @syeehyn, @linhx1999, @SiyunZhao et @acured 🎉 changelog complet : v0.1.2 → v0.2.0
