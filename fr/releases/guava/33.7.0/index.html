Problème nouvellement introduit pour Java 9 et Java 10 uniquement

Guava 33.7.0 inclut une ligne Multi-Release dans son manifeste de pot, même s'il ne s'agit plus d'un pot à versions multiples. Cela provoque quelques problèmes avec les outils de Java 9 et Java 10. Le problème est résolu dans la version 33.7.1. Désolé pour le problème.

Maven

<dependency>
  <groupId>com.google.guava</groupId>
  <artifactId>guava</artifactId>
  <version>33.7.0-jre</version>
  <!-- or, for Android: -->
  <version>33.7.0-android</version>
</dependency>

###Changelog

  • Le jar Android contient désormais nos configurations Proguard. (b0668e7174)
  • Le Guava module-info.class est désormais présent à la racine du pot au lieu de sous [une racine multi-release] (https://openjdk.org/jeps/238). Cela empêche le fichier jar de contenir un fichier sur META-INF/versions/9/OSGI-INF/MANIFEST.MF, ce qui provoque parfois des [problèmes pour certains utilisateurs] (https://github.com/jspecify/jspecify/issues/484#issuecomment-2819506604). (230019b31e)
  • Notre Android minSdkVersion a désormais 24 ans (Nougat). Cela suit le minimum des bibliothèques Android fondamentales de Google, et nous nous attendons à ce que cela n'ait aucun impact pratique sur les utilisateurs. (ea0af870d5)
  • collect : Modification de certaines implémentations de ImmutableMap pour créer un nouvel objet léger à chaque appel pour afficher des méthodes comme keySet(), plutôt que de créer et de stocker cet objet lors du premier appel pour une réutilisation ultérieure. Cela améliorera probablement légèrement les performances pour certains utilisateurs, mais cela pourrait entraîner des régressions dans des cas inhabituels, comme l'appel répété de asMultimap().inverse() sur la même instance de ImmutableMap. (e87d019e47)
  • net : Ajout de la constante HttpHeaders pour on-prefetch-activation. (abd06a3679)
  • net : Ajout des constantes MediaType pour application/yaml et application/x-pem-file. (a8e9533b49, 1d40e27a4b)
  • util.concurrent : Correction du blocage de la file d'attente ExecutionSequencer lorsque l'exécuteur délégué lance RejectedExecutionException. (8410194eed)
