herdr v0.9.2

Correctif Publié29 sept. 2026 Sourceherdrdev/herdr Anglais original

Cette page est traduite automatiquement. Le texte anglais original fait foi.

troupeau v0.9.2

Modifications radicales

  • Le volet graphique spécifique à Herdr API a disparu. pane.graphics.info, set, clear et stream renvoient désormais unknown_method. Les applications affichent des images en écrivant des graphiques Kitty standard sur leur terminal, que Herdr restitue de manière native. (#4561)

Ajouté

  • Les agents peuvent signaler leur propre commande de reprise. Herdr rouvre ensuite sa session exacte après un redémarrage du serveur, sans qu'aucune intégration intégrée ne soit nécessaire. Les agents auto-déclarés sont également effacés une fois que leur volet est de nouveau inactif. Le nouveau guide [Ajouter le support Herdr à votre agent] (https://herdr.dev/docs/add-herdr-support/) couvre l'état, le CV et la version pour les auteurs d'agents. (#4687)
  • Utilisez plusieurs touches de préfixe : prefix = ["ctrl+space", "ctrl+s"]. Chaque entrée entre dans le même mode de préfixe et prefix+? les répertorie toutes. (#4653, merci @JJLiebig)
  • Go To affiche chaque agent et terminal sur sa propre ligne, regroupés par espace de travail, avec son statut et son chemin. Sautez à gauche et à droite entre les espaces de travail. (#4384)
  • Liez keys.clear_pane pour effacer l'écran du volet sélectionné et faire défiler l'écran tout en conservant la ligne d'invite actuelle. Il n'est pas lié par défaut et laisse seules les applications plein écran telles que Vim. (#4383)
  • herdr machine status vérifie les machines enregistrées sans invite. herdr machine reconnect termine l'authentification SSH, y compris MFA, dans votre terminal. Open clients revérifie les machines en panne toutes les 30 secondes, donc aucun redémarrage n'est nécessaire après avoir réparé une connexion. (#3763)
  • Interactive machine add trouve les sessions Herdr déjà en cours d'exécution sur l'hôte et vous permet d'en choisir une. --label est facultatif ; la machine porte le nom de son hôte SSH. (#4204, #4678, merci @JJLiebig et @dhh)
  • terminal session control accepte les événements terminal.mouse, de sorte que les ponts clients peuvent click boutons dans les applications qui activent les rapports de souris. (#4685)
  • Les agents restaurés démarrent un par un, à 100 ms d'intervalle par défaut, au lieu de tous en même temps. Modifiez l'espacement avec [session] startup_per_agent_delay_ms. (#4102, merci @JJLiebig)

Modifié

  • Les images s'affichent plus rapidement et de manière plus fiable. Local Ghostty reçoit les données d'image via des fichiers temporaires au lieu de la sortie du terminal. Les fenêtres contextuelles et les notifications recadrent les images autour d'elles au lieu de les masquer. Les images qui défilent hors de vue restent chargées, donc le défilement vers l'arrière ne les renvoie plus. (#4561, #4652, #4686)
  • Les connexions SSH demandent une compression. Sur les liens lents, les volets distants rattrapent leur retard après le défilement en une fraction du temps. (#4340)
  • Le défilement de la sortie sur les machines enregistrées envoie uniquement les lignes qui ont changé, réduisant ainsi la bande passante pour les journaux de build et les agents de streaming. Les anciens serveurs et clients continuent de fonctionner avec le format précédent. (#4711)
  • Nouveaux jeux de vitres TERM_PROGRAM=herdr et TERM_PROGRAM_VERSION. Ils n'héritent plus des identifiants de session de terminal, tels que ceux d'iTerm2, ou des marqueurs de session Claude Code du terminal qui a démarré le serveur. (#4104)
  • Les volets Windows utilisent par défaut PowerShell 7 (pwsh) lors de leur installation, revenant à Windows PowerShell. Un default_shell explicite gagne toujours. (#4297, merci @JJLiebig)
  • La fermeture du dernier onglet d'un espace de travail demande désormais une confirmation. (#4379, #4409, merci @minatoaquaMK2)
  • Les abonnements aux événements offrent des rafales complètes. Un lecteur qui prend trop de retard obtient désormais une erreur events_lost au lieu de sauter silencieusement des événements. (#4178, #4225, merci @minatoaquaMK2)
  • Sous Unix, l'envoi de SIGWINCH à un Herdr client relit les couleurs du terminal hôte, afin que les sélecteurs de thème qui changent de couleur sans notification claire/foncée puissent actualiser les volets. (#4349, merci @dhh)

Corrigé

  • Les mises en page enregistrées survivent à l'arrêt de l'hôte et aux échecs de restauration. Sous Linux avec logind, Herdr enregistre avant l'arrêt du système. Chaque plate-forme conserve jusqu'à 48 instantanés de mise en page dans session-snapshots/ pour une récupération manuelle. (#4320)
  • Cli cliquer sur un volet n'envoie plus d'échappement parasite qui interrompt un agent en activité. (#3480)
  • La première tâche d'un agent compte désormais comme terminée, même si elle a commencé par une invite. Le démarrage, les sessions restaurées et le /new de Pi ne déclenchent plus de fausses notifications de fin. L’état signalé par Hook survit au transfert en direct. (#3338, #3990, #3916)
  • Le serveur utilise beaucoup moins de CPU avec de nombreux volets remplis. Le navigateur, les divisions de volets et les cibles nommées restent rapides dans les sessions volumineuses, et les rafales d'événements externes ne bloquent plus le rendu. (#4506, #4546, #4426, #4669, #4670, #4671, #4672, merci @JJLiebig et @minatoaquaMK2)
  • Les applications qui utilisent la sortie synchronisée n'affichent plus d'images déchirées pendant que vous tapez. Le curseur ne scintille plus lors des redessins d'état ou ne saute plus dans un Codex inactif sous Windows. (#2968, #4303, merci @JJLiebig)
  • Le socket API continue d'accepter les connexions après une erreur passagère, de sorte que les commandes CLI et le transfert en direct n'échouent plus pendant que le serveur continue de fonctionner. (#4601)
  • Les opérations Git lentes lors des recherches dans l'arbre de travail ne gèlent plus la saisie. (#4492, merci @JJLiebig)
  • worktree open ne prend plus en charge le propre espace de travail du référentiel, donc la suppression de l'arbre de travail ne le ferme plus. (#4293)
  • Les agents SSH transférés continuent de fonctionner dans les volets distants après une reconnexion. Les commandes --machine répétées ouvrent beaucoup moins de connexions SSH. (#1931, #4252)
  • Les volets OpenCode V1 restent fonctionnels ou bloqués pendant l'exécution de leurs sous-agents. Un enregistrement existant dans tui.json est respecté au lieu de régénérer tui.jsonc. (#1362, #4240)
  • Le Codex n'est plus signalé comme inactif pendant la sortie active, ses fenêtres contextuelles de mention sont reconnues et les touches d'interruption remappées n'interrompent plus la détection. (#4507, #4196, merci @JJLiebig et @unmanbearpig)
  • Les invites d'approbation Kiro sont signalées comme bloquées. Les volets inactifs de Grok sont réglés avec des titres OSC personnalisés ou désactivés. (#4203, #4372, #4333, merci @vinayshah1998)
  • Les effacements de défilement de Droid sont honorés, donc son en-tête de bienvenue et son ancienne transcription ne se répètent plus. (#4432, merci @factory-ain3sh)
  • Le mode copie reste actif pendant que la sortie se poursuit et qu'une touche de mouvement est maintenue. (#3812, #4281, merci @marcomayer)
  • Ctrl+Shift+lettre maintient Shift dans les volets qui n'ont pas activé la saisie améliorée au clavier, donc Ctrl+Shift+C n'arrive plus sous la forme Ctrl+C. (#4581, #4597, merci @factory-ain3sh)
  • Les rapports de souris répartis entre les lectures ne fuient plus dans le shell après un changement de focus via SSH. (#4630)
  • Windows : les collages multilignes dans Claude Code ne sont plus soumis à la première nouvelle ligne, et Shift+Enter est conservé. La capture de la souris survit aux changements de focus et au redimensionnement, Ctrl+Win n'ouvre plus le mode préfixe avec un préfixe ctrl+space et le collage d'image clipboard à distance fonctionne à nouveau. (#4251, #4284, #4470, #4314, merci @JJLiebig)
  • Windows : l'OMP installé par npm et les agents lancés via des environnements d'exécution renforcés sont détectés. machine add sur un hôte Windows n'échoue plus comme « non prêt pour les machines enregistrées ». (#4313, #4579, #4309, merci @JJLiebig)
  • La surbrillance de l'espace de travail en mode navigation est visible avec theme = "terminal". La recherche du navigateur de session fait correspondre les mots indépendamment. La barre latérale révèle les agents sélectionnés par cycling ou des raccourcis. (#4300, #4408, #4273, #4535, #4355, merci @minatoaquaMK2)
  • session attach sans terminal explique le problème au lieu de laisser une nouvelle session en cours d'exécution. (#4393)
  • Les réponses aux erreurs de socket conservent l'ID de demande d'origine, y compris les erreurs de configuration d'abonnement. (#4344)
  • plugin install accepte les options avant le référentiel. (#4446)
  • Les volets Windows récupèrent les couleurs claires ou sombres du terminal hôte dès le début, de sorte que les applications ne passent plus par défaut en mode sombre à l'intérieur d'un terminal clair. (#1530, #4369)
  • Après herdr update, Herdr répertorie les serveurs en cours d'exécution qui sont toujours sur l'ancienne version, avec les commandes exactes pour redémarrer chacun d'eux, et vous rappelle de mettre à jour vos machines SSH enregistrées.
