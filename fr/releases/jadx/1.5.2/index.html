jadx v1.5.2

Principales fonctionnalités

Noyau :

  • Implémentation d'un lecteur zip personnalisé pour lutter contre la falsification
  • Ajoutez des modèles d'exportation Gradle, prenez en charge l'application/lib Android et Java simple
  • Prise en charge initiale de DEX v41 (#2128)

Interface graphique :

  • Ajouter une boîte de dialogue d'exportation avec des options (PR #2378)
  • Une recherche d'utilisation de l'arborescence (PR #2498)
  • Ajouter un thème d'éditeur de code dynamique à partir du thème de l'interface utilisateur (PR #2471)
  • Ajouter une fonctionnalité d'onglet Aperçu (PR #2474)
  • Nouveau HexViewer (PR #2469)

Plugins :

  • Ajouter le support APKM (PR #2379)
  • Analyser et utiliser Kotlin SourceDebugExtension avec SMAP pour renommer les classes et les packages (PR #2389)

API :

  • Ajout de la méthode 'unload' à JadxPlugin (#2463)
  • Méthode pour ajouter une entrée de menu contextuel pour les nœuds d'arbre (#2412)
  • Ajout d'une méthode pour obtenir les icônes jadx-gui par nom
  • Ajouter une méthode pour ouvrir la boîte de dialogue d'utilisation
