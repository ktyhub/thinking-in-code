helm v4.1.3

Correctif Publié11 mars 2026 Sourcehelm/helm Anglais original

Cette page est traduite automatiquement. Le texte anglais original fait foi.

barre v4.1.3

Helm v4.1.3 est une version de correctif. Les utilisateurs sont encouragés à effectuer une mise à niveau pour la meilleure expérience. Notez qu'il n'y a pas eu de version 4.1.2 en raison d'un problème d'automatisation de la version. La communauté ne cesse de s'agrandir et nous serions ravis de vous y voir !

  • Rejoignez la discussion dans Kubernetes Slack :
    • pour des questions et juste pour sortir
    • pour discuter des PR, du code et des bugs
  • Participez à l'appel public aux développeurs : jeudi, 9h30 Pacifique via Zoom
  • Testez, déboguez et contribuez aux graphiques : ArtifactHub/packages

Changements notables

  • Correction d'un bug où --dry-run=server ne respectait pas generateName #31563
  • Correction d'un bug où les ressources CRD vides provoquaient un crash. Maintenant, il imprime une erreur #31578
  • Correction d'un bug où les références OCI avec tag+digest échouaient avec l'erreur "octet invalide" #31601
  • Correction d'un bug où la valeur nulle fournie par l'utilisateur n'était pas conservée lorsque le graphique avait une carte vide ou aucune valeur par défaut pour une clé #31644
  • Correction d'une régression depuis Helm 3.18.0 où l'extraction de graphiques à partir de référentiels OCI qui utilisent un index pour stocker à la fois les images de conteneur et les graphiques Helm sous la même balise échouait #31776
  • Correction d'une régression Helm 4 où l'espace blanc du modèle obtenu était coupé directement après les séparateurs de documents YAML, lorsqu'ils étaient présents après le post-rendu, provoquait une corruption du fichier YAML #31868
  • Correction d'un bug où FailedStatus est traité comme un état de terminal, provoquant l'échec prématuré des mises à niveau lorsque les autoscalers de cluster avaient besoin de temps pour provisionner les nœuds, ou lorsque les pods étaient supprimés lors des mises à jour propagées #31897
  • Correction d'une compatibilité ascendante cassée pour l'indicateur --atomic obsolète sur la commande d'installation #31901
  • SDK : correction d'une erreur Windows "Access Deined" si plusieurs processus tentent de télécharger simultanément la même version du graphique #31128
  • SDK : Correction d'un bug où les utilisateurs ne recevaient aucun journal du serveur, provoquant une confusion car plusieurs minutes pouvaient s'écouler sans retour de l'utilisateur #31717
  • SDK : Correction d'un bug où les valeurs par défaut d'application côté serveur ne correspondaient pas toujours aux valeurs par défaut de CLI #31732
  • SDK : Correction d'un problème d'importation Go lorsque les outils en aval tentaient d'accéder au fournisseur helm.sh/helm/v4/pkg/kube #31852
