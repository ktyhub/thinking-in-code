codebase-memory-mcp v0.5.0

Terminé Aller à C Rewrite

v0.5.0 est la première version entièrement construite à partir de C. L'ensemble de la base de code - pipeline, magasin, serveur MCP, CLI, observateur - a été réécrit de Go à C, avec des grammaires arborescentes compilées via CGo remplacées par la source C vendue pour les 64 langues.

Ce que cela permet

  • Pipeline RAM-first : toutes les indexations s'exécutent en mémoire (lecture compressée LZ4 HC, SQLite en mémoire, vidage unique à la fin). Zéro E/S disque entre le chargement en masse et l’écriture finale.
  • Correspondance multi-modèles fusionnés Aho-Corasick : la résolution des appels utilise un seul passage sur l'AST avec tous les modèles chargés simultanément, remplaçant le grep séquentiel par fonction.
  • Résolveur LSP hybride C/C++ : substitution de modèle, chaînes de pointeurs intelligents, notation de surcharge, inférence lambda/decltype, répartition virtuelle -- plus de 700 tests dédiés.
  • allocateur global mimalloc : suit toutes les allocations (C + C++ via le remplacement global), permettant une budgétisation précise de la mémoire par travailleur.
  • Pas de surcharge de limite CGo : toute l'analyse des arborescences s'effectue en C pur -- pas de saut CGo par fichier.

Performances

Indexation du noyau Linux (28M LOC, 75K fichiers) :

  • Mode complet : 2,1 M de nœuds, 5 m33 s (Apple M3 Pro)
  • Mode rapide : 1,88 M de nœuds, 1 m12 s (Apple M3 Pro)

Nouveau : interface utilisateur de visualisation graphique

Le v0.5.0 est livré en deux variantes :

  • standard -- Serveur MCP uniquement (binaire plus petit)
  • ui -- Serveur MCP + visualisation graphique 3D intégrée Activez l'interface utilisateur : ```bash codebase-memory-mcp --ui=true --port=9749 ``` Ensuite, ouvrez http://localhost:9749 pour explorer visuellement votre graphique de connaissances. L'interface utilisateur s'exécute comme un thread d'arrière-plan sur localhost, servant les ressources frontales intégrées et transmettant les requêtes par proxy à une connexion SQLite en lecture seule.

Détection automatique de session + indexation automatique

Le serveur MCP détecte désormais la racine de votre projet à partir du répertoire de travail au démarrage de la session. Combiné avec le magasin de configuration : ```bash configuration codebase-memory-mcp définie auto_index true ``` Lorsqu'ils sont activés, les nouveaux projets sont automatiquement indexés lors de la première connexion MCP et l'observateur les enregistre pour une détection continue des modifications basée sur Git. Les projets précédemment indexés sont toujours enregistrés auprès de l'observateur, quel que soit ce paramètre. La configuration CLI prend en charge : `list`, `get <key>`, `set <key> <value>`, `reset <key>`.

Installation multi-agents (8 agents de codage)

`codebase-memory-mcp install` détecte désormais automatiquement tous les agents de codage installés et configure chacun d'eux avec les entrées du serveur MCP, les fichiers d'instructions et les hooks pré-outils lorsqu'ils sont pris en charge. | Agent | Configuration MCP | Instructions | Crochets | |-------|-----------|-------------|-------| | Claude Code | .claude/.mcp.json | 4 Compétences (modèle directif) | PreToolUse sur Grep/Glob/Read | | Codex CLI | .codex/config.toml | .codex/AGENTS.md | -- | | Gémeaux CLI | .gemini/settings.json | .gemini/GEMINI.md | BeforeTool sur grep/read | | Zed | paramètres.json (JSONC) | -- | -- | | Code Ouvert | code ouvert.json | .config/opencode/AGENTS.md | -- | | Antigravité | mcp_config.json | .gemini/antigravité/AGENTS.md | -- | | Aide | -- | CONVENTIONS.md | -- | | KiloCode | mcp_settings.json | ~/.kilocode/rules/ | -- |

Améliorations du comportement agent

Les agents préfèrent désormais activement les outils MCP à grep/glob/read pour la découverte de code :

  • Les descriptions de compétences directives permettent une activation automatique d'environ 100 % (contre environ 37 % avec l'ancien modèle descriptif)
  • PreToolUse / BeforeTool hooks imprime des rappels lorsque les agents accèdent aux outils de recherche intégrés
  • Descriptions d'outils MCP riches en mots clés améliorent la découverte de la recherche d'outils de Claude
  • Fichiers d'instructions avec des exemples concrets et des conseils de secours explicites pour tous les agents
  • La vérification des mises à jour au démarrage informe lors du premier appel de l'outil si une version plus récente est disponible Ces améliorations ont été motivées par les rapports et contributions de la communauté :
  • @David34920 -- a signalé que Claude ignorait les outils MCP sans les modifications CLAUDE.md (#69)
  • @sonicviz -- analyse détaillée de l'heuristique de sélection des outils d'agent (#34)
  • @chitralverma -- a signalé que Gemini CLI utilisait par défaut les outils intégrés (#19)
  • @noelkurian -- identification d'un bug du format de configuration Zed et d'un problème d'analyse JSONC (#24)
  • @zeval -- PR d'installation OpenCode avec recherche du chemin de configuration (#36)
  • @harshil480 -- PR d'installation de KiloCode avec format de configuration et plan de test (#53)

Correctifs

  • Zed : Config utilise désormais args:[""] au lieu de source cassée :"custom" (#24)
  • Zed : l'analyseur gère JSONC (commentaires + virgules de fin) dans les paramètres existants.json
  • L'installation est idempotente : exécuter l'installation deux fois ne produit aucun doublon -- upsert basé sur des marqueurs pour les instructions, upsert basé sur des clés pour les configurations JSON/TOML

Prise en charge multiplateforme

Entièrement testé sur toutes les plateformes avec ASan + LeakSanitizer + UBSan : | Plateforme | Essais | Construire | |--------------|-------|-------| | macOS arm64 | 2030 est passé | D'accord | | macOS amd64 | D'accord | D'accord | | Linux arm64 | 2012 passé | D'accord | | Linux amd64 | D'accord | D'accord | | Windowsamd64 | D'accord | D'accord (CLANG64) | Dépendances fournies (aucune exigence de bibliothèque système) : sqlite3, mimalloc, tree-sitter runtime, yyjson, zlib, TRE regex (Windows uniquement).

Mise à niveau

```bash mise à jour de la base de code-mémoire-mcp ``` Ou une nouvelle installation : ```bash curl -fsSL https://raw.githubusercontent.com/DeusData/codebase-memory-mcp/main/install.sh | coup codebase-memory-mcp install -y ``` Les index existants seront reconstruits automatiquement : le pipeline C produit un format de graphique différent (amélioré).
