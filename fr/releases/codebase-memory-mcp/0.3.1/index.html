codebase-memory-mcp v0.3.1

Quoi de neuf

outil de détection_changes (NOUVEAU)

Mappez les modifications git non validées sur les symboles graphiques concernés et leur rayon d'explosion avec la classification des risques. Prend en charge plusieurs étendues :

  • unstaged — modifications du répertoire de travail
  • staged — modifications par étapes uniquement
  • all (par défaut) — à la fois mis en scène et non mis en scène
  • branch — différence avec une branche de base (par exemple main) Renvoie les fichiers modifiés, les symboles modifiés, les appelants concernés avec des scores de risque et un résumé de l'impact.

Score des risques sur trace_call_path

Le nouveau paramètre risk_labels=true ajoute une classification d'impact basée sur la profondeur aux traces de chaîne d'appel :

  • CRITIQUE (saut 1) — appelants/appelés directs, s'interrompra
  • ÉLEVÉ (saut 2) — indirect, probablement affecté
  • MEDIUM (saut 3) — peut être affecté
  • FAIBLE (saut 4+) — peu probable mais possible Comprend impact_summary avec décomptes par niveau de risque et indicateur has_cross_service.

Prise en charge plus large de l'éditeur

codebase-memory-mcp install enregistre désormais automatiquement la configuration MCP pour :

  • Curseur (~/.cursor/mcp.json)
  • Planche à voile (~/.codeium/windsurf/mcp_config.json) En plus du support existant de Claude Code et Codex CLI. uninstall nettoie tous les éditeurs.

Mise à niveau du MCP SDK

go-sdk mis à niveau de v1.3.1 à v1.4.0 — inclut des correctifs de sécurité et des améliorations de conformité aux spécifications MCP.

Descriptions des outils améliorées

Les exemples d'expressions régulières en ligne sur les paramètres de recherche aident les agents IA à créer des recherches précises à requête unique.

Nombre d'outils

14 outils (au lieu de 13). Seulement 1 nouvel outil ajouté (detect_changes), 1 outil existant étendu (trace_call_path + risk_labels).

Performances

Zéro surcharge d’indexation. La notation des risques est un pur post-traitement sur les résultats BFS existants. detect_changes exécute git uniquement au moment de l’appel de l’outil – aucun nouveau pipeline ni stockage.

Installation/Mise à niveau

```bash

Première installation

allez installer github.com/DeusData/codebase-memory-mcp/cmd/codebase-memory-mcp@v0.3.1 installation de codebase-memory-mcp

Mise à niveau (utilisateurs existants)

mise à jour de la base de code-mémoire-mcp ```
