codebase-memory-mcp v0.10.8

#v0.10.8

Remarque sur v0.10.7 : cette version remplace v0.10.7, qui a été perdue dans un pipeline de versions erreur de publication (publiée sous le tag 0.10.7 au lieu de v0.10.7 ; installateurs de packages résolvez la balise préfixée par v et l'immuabilité de la version rend le nom irrécupérable). Le npm et les packages PyPI 0.10.7 sont obsolètes/tirés pour cette raison — leurs binaires étaient corrects, leurs URL de téléchargement ne l'étaient pas. v0.10.8 contient le même contenu de code ainsi que le pipeline un durcissement qui évite une récidive.

Une version de correctif à forte intensité communautaire : 19 demandes d'extraction fusionnées depuis v0.10.6, la plupart provenant de contributeurs. Merci à tous !

Exactitude du graphique

  • Les agrégats de chiffrement ne sont plus sous-estimés (#1196). Les deux mécanismes de troncature sont corrigés : les analyses non étiquetées ont cessé de collecter des candidats à max_rows avant l'exécution de l'agrégation (#1323, @Enferlain), et les tampons d'expansion des relations étaient plafonnés afin que l'agrégation ne soit jamais a vu des rangées au-delà d'une limite de croissance interne (#1698). count()/collect(), voyez maintenant le ensemble de correspondance complet ; max_rows limite uniquement les lignes renvoyées, comme indiqué.
  • Python alias from-imports se résout à la définition réelle (#1371, @Joseph-MingEn). from .gate import execute as bridge_execute produit désormais un front CALLS vers execute lui-même plutôt que de perdre l'appel, et les importations de classe de base alias atterrissent sur la classe réelle nœud. Sur notre benchmark Django, cela a récupéré 26 bords INHERITS et 42 OVERRIDE avec zéro pertes ailleurs, et a laissé les graphiques TypeScript identiques en octets.
  • Correspondance de suffixes multilingues pour les recherches de noms qualifiés (#1647, @rudi193-cmd).
  • search_graph arrête de renvoyer des fantômes uniquement sémantiques — résultats soutenus par rien d'autre qu'un le bord de similarité n'apparaît plus comme s'il s'agissait de correspondances définitives (#1319, @JJordan0C).
  • Les champs à valeur de liste sont extraits correctement au lieu de se réduire à leur premier élément (#1325, @Enferlain).
  • Les réponses à l'index rapportent fidèlement la couverture persistante (#1326, @Enferlain) : un l'exécution incrémentielle qui ne revisite pas un fichier avec des lacunes d'analyse enregistrées ne rapporte plus ces lacunes ont disparu - la réponse compose désormais ses résumés ignorés/analyseurs partiels à partir de l’état de couverture stocké, en revenant aux données par exécution uniquement si cette lecture échoue.

Fenêtres

  • Le contenu de recherche non-ASCII ne se dégrade plus en ? (#1704). L'analyse brute search_code canalise la sortie PowerShell et PowerShell 5.1 code ce canal dans l'OEM de la console page de code - donc le contenu cyrillique, CJK ou accentué se transforme en points d'interrogation en fonction de dont le serveur a hérité de la console. Le canal est désormais épinglé sans condition sur UTF-8.
  • search_code comprend les chemins de sortie UTF-8 et obtient une colonne de contexte pour les correspondances (#1253, @anfedoro).
  • La recherche de code est limitée et annulable — l'abandon d'une requête ne laisse plus de analyse orpheline en cours d'exécution (#1608, @ertankucukoglu).

Plateformes et outils

  • Prise en charge de FreeBSD (#1467, @PR9000).
  • pagination list_projects : une réponse par défaut allégée plus offset/limite et include_details pour la vue complète (#1181, @tmonestudio).
  • Les scripts shebang sans extension détectent leur langue (#1203, @ibaldr89).
  • Reconstruction des capacités en mode index (#1263, @astandrik).
  • détection is_test pour les tests/répertoires (#1308) et un clang-tidy prenant en charge les différences crochet (#1310, les deux @Yyunozor).

Release pipeline (la leçon v0.10.7, renforcée)

  • Les portes de libération ne se ferment pas sur les tâches annulées : une porte expirée ne peut plus entrer en cascade dans une matrice de test ignorée silencieusement (#1719).
  • Les entrées de versions mal formées sont refusées au contrôle en amont — une version nue, sans préfixe v, ne peut jamais publiez à nouveau une balise insoluble (#1719).

Interne

  • Les harnais de test utilisent des environnements d'exécution de démon isolés afin que les exécutions de suites ne puissent pas toucher le compte démon (#1695, @astandrik) ; Contrats de paiement LF pour les points d'entrée du shell et les hooks git (#1314 @mlandolfi90, #1699 avec @xumian520) ; les tests de régression stdin-gate ne sont plus dépendent du registre qui expédie un outil sans argument (#1704).
