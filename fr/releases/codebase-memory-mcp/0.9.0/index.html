codebase-memory-mcp v0.9.0

codebase-memory-mcp v0.9.0

Une version importante en termes de robustesse et de prise en charge de la plate-forme depuis v0.8.1 : prise en charge Windows de première classe, gains importants en termes de performances d'indexation et de sécurité de la mémoire, correctifs de précision d'extraction étendus dans de nombreux langages et interface utilisateur graphique nettement meilleure.

Faits saillants

  • Support Windows de première classe — gestion des chemins non-ASCII de bout en bout, correctifs de fiabilité de l'installateur/de l'exécution, un correctif de blocage de l'interface utilisateur et un build natif windows-arm64 + pipeline de fumée.
  • Performances et résilience d'indexation : une campagne à l'échelle du noyau a réduit le temps d'indexation d'environ 61 % avec une sortie déterministe, plus un superviseur de blocage/blocage qui met en quarantaine un fichier défectueux et indexe le reste au lieu d'abandonner l'exécution entière.
  • Sécurité de la mémoire sur les grands référentiels : comptabilité RSS Linux précise, réconciliation entre pic et direct, rétention parallèle limitée pour les machines à faible RAM et correctif d'utilisation après libération dans les libérations de dalles multi-threads.
  • Graph UI — un budget de nœuds configurable jusqu'à 10 millions de nœuds avec des contrôles de rendu et de contraste mis à l'échelle, un filtrage des codes morts, un aperçu du code des nœuds, des liens profonds GitHub, un routage d'URL et un rendu d'étiquettes hors ligne (pas de récupération de polices à distance).
  • Précision de l'extraction — de nombreux correctifs d'APPELS/IMPORTATIONS/extraction de route en C/C++, Python, Go, PHP, Kotlin, Java, TypeScript/JavaScript, Rust, et plus encore.

Qu'est-ce qui a changé

Prise en charge de Windows

Prise en charge de bout en bout des chemins non-ASCII (_wfopen, Wide-argv + CreateProcessW, lignes de commande de travail avec échappement/terminaison NUL) ; fiabilité de l'installateur et documents Mark-of-the-Web ; un correctif d'héritage de handle git-spawn qui a résolu un blocage de l'interface utilisateur ; gestion des lettres de lecteur dans l'augmentateur de crochet ; gestion des grandes tailles .db ; une véritable erreur lorsque l'exportation de persistance Windows échoue ; et une version native complète de Windows-arm64 + un pipeline de fumée.

Indexation, performances et sécurité de la mémoire

Indexation à l'échelle du noyau environ 61 % plus rapide avec sortie déterministe ; un correctif en cascade TypeScript à grande échelle avec récupération après incident en parallèle uniquement ; un superviseur de crash/hang qui met en quarantaine le fichier coupable ; RSS /proc précis sous Linux ; rapprochement RSS pic/live ; rétention parallèle limitée et limitée à la source pour les pics RSS à faible RAM ; Isolation RSS des sous-processus supervisés pour l'indexation/l'observation automatique en arrière-plan ; un correctif sans dalle de fil croisé de page alignée O (1) (utilisation après libération); correctifs de contrat d'upsert de tampon graphique et de budget mem ; budget RAM au niveau de l'hôte ; et les échecs d'indexation par fichier sont désormais signalés via skipped[] + un fichier journal au lieu d'échouer silencieusement.

LSP / précision d'extraction

Exactitude des bords CALLS (bords de répartition des chaînes, attribution de fonctions englobantes C/C++, auto-récursivité consciente du récepteur, limites de profondeur de récursion dans py/go/php/kotlin, une garde mémorisée pour un blocage de réévaluation exponentielle Python) ; extraction de route/HTTP (rejeter les chemins du système de fichiers afin que les routes client rejoignent les routes du serveur, canoniser les chemins paramétrés, les routes Spring sur les contrôleurs Kotlin, Django REST @action) ; importations/résolution (IMPORTS saisis par nom local, rejet des cibles non de type fichier, alias tsconfig ../ climbs, bords de callgraph mixtes Java/Kotlin, propriété stable de Java USAGE) ; plus la précision Class.lines, les HÉRITES/IMPLEMENTS comptés en degrés, un débordement de pile de correction de pile de cadres walk_defs alloué au tas sur les fichiers profonds et une suite de bogues reproduisant en premier avec une carte à 5 plates-formes.

Interface utilisateur graphique

Budget de nœuds jusqu'à 10 M avec rendu à l'échelle et contrôles de contraste ; rendu des étiquettes hors ligne (pas de polices CDN distantes) ; filtrage des codes morts, aperçu du code du nœud et liens profonds GitHub ; Routage d'URL, UX du panneau de filtrage et accès à la caméra ; la barre latérale du filtre reste visible lorsque tout est filtré ; Navigation dans les dossiers Windows dans le sélecteur d'index ; des échecs de tâches d'indexation sont apparus au lieu de se terminer silencieusement ; projets non surveillés lors de la suppression de l'interface utilisateur ; récursivité octree limitée pour les points coïncidents.

Serveur MCP & CLI

Métadonnées structurées des outils ; le CLI accepte les drapeaux, stdin et --args-file avec --help par outil ; résolution du projet par nom interne + filtrage ghost-DB et alias project_name ; trace_path ne confond plus les fonctions distinctes du même nom et suit les arêtes CROSS_* ; extraits de code UTF-8 valides pour les sources non UTF-8 ; corriger le caractère de contrôle JSON escaping ; Le parcours filtré par étiquettes de chiffrement ne tronque plus à 10 et préserve les propriétés du nœud via WITH ; Sous-ensemble de présentation get_architecture ; detect_changes rend hommage à since.

Découverte, observateur et cycle de vie

Honorez les sources .git/info/exclude, globales core.excludesFile et linked-worktree ; honorer les exclusions dans les promenades pkgmap/path-alias/envscan ; La négation de .cbmignore ne peut plus ignorer les répertoires du noyau de sécurité ; déployer/répertoires n'est plus doublement indexé ; la recherche étendue gère les chemins de dépôt avec des espaces ; élaguer les projets dont la racine reste manquante ; une porte de configuration auto_watch ; corriger canonical_root pour les arbres de travail et les projets de sous-répertoire ; Préservation de l’ADR lors d’une réindexation complète.

Grammaires, construction et documentation

Grammaires ObjectScript InterSystems vendues et analyseur Mojo ; SBOM calcule maintenant le nombre de grammaire et complète le résumé des licences non-MIT. Pipeline de validation complet sur les PR avec annulation d'exécution remplacée ; des robots de tri des problèmes ; un contrôle de fumée par jambe qui corrige l'effondrement de la matrice/le faux vert ; Correctifs de build gcc-15 et Nix-on-macOS. Référence du fichier de configuration et documentation extra_extensions.
