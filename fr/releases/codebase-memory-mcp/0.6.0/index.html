v0.6.0 — Recherche sémantique, bords SIMILAR_TO et intelligence multilingue

Plus de 85 commits depuis v0.5.7. Version majeure ajoutant une recherche sémantique vectorielle, une détection structurelle de quasi-clone, une résolution d'importation multilingue et des améliorations significatives de la qualité de vie sur toutes les plates-formes.

Recherche sémantique et intégrations vectorielles

  • Outil semantic_query : recherche vectorielle basée sur des mots-clés sur l'ensemble du graphe de base de code via la fonction SQL cbm_cosine_i8
  • Incorporations nomiques de code nomic-embed : 40 000 vecteurs de jetons pré-entraînés (768d int8), distillés à partir de nomic-ai/nomic-embed-code avec une attention simulée
  • Score combiné à 11 signaux : TF-IDF, indexation aléatoire réfléchissante, signatures API/Type/Decorator, profils structurels AST, flux de données approximatif, métriques Halstead-lite, MinHash, proximité de module, diffusion de graphiques
  • SEMANTICALLY_RELATED edge : connecter des fonctions avec une inadéquation de vocabulaire mais un objectif similaire (score >= 0.80, max 10 par nœud, même langue uniquement)
  • La notation min-cosinus par mot-clé remplace la moyenne vectorielle fusionnée pour une meilleure précision
  • Blocage du score à [0,1] — le multiplicateur de proximité ne pousse plus les scores au-dessus de 1.0
  • Déduplication de clone : SIMILAR_TO s'associe avec Jaccard >= saut de seuil SEMANTICALLY_RELATED

SIMILAR_TO Edges (détection de quasi-clone)

  • Empreinte digitale MinHash : signatures de 64 hachages provenant de jetons AST feuilles uniquement avec pondération structurelle
  • Indice LSH : hachage sensible à la localité basé sur la bande pour la récupération de candidats O(1)
  • Score parallèle : le pool de travailleurs interroge LSH, note les candidats, émet des bords
  • Filtres de porte trigramme uniques pour des fonctions trivialement courtes
  • Bords SIMILAR_TO avec similarité Jaccard et indicateur de même fichier dans les propriétés

Recherche en texte intégral

  • Recherche en texte intégral BM25 via FTS5 avec tokenizer cbm_camel_split (compatible camelCase/snake_case)
  • Reconstruction incrémentielle de FTS5 lors des mises à jour d'index

Nouveaux types de bords et détection

  • Bords EMITS / LISTENS_ON pour Socket.IO, EventEmitter et modèles de canal génériques
  • Résolution constante : const EVENT = "foo"; emit(EVENT) résout les noms de canaux via des tables de constantes par fichier
  • Bords IMPORTS avec résolution de chemin relatif pour JS/TS (./foo, ../bar), Python (.helpers, ..utils), Ruby
  • Bords DATA_FLOWS avec mappage argument-paramètre + chaînes d'accès aux champs
  • Découverte de communication interservices + indexation incrémentielle RAM-first
  • Enregistrement d'itinéraire basé sur AST remplaçant l'infrastructure de pré-analyse
  • Extraction de liaison d'infrastructure HCL + correctif de faux positifs du décorateur de préfixe
  • Enregistrement d'itinéraire généralisé + pont de liaison infra

Améliorations des requêtes et des outils graphiques

  • 6 paramètres précédemment ignorés câblés : min_degree, max_degree, exclude_entry_points, include_connected, filtre aspects, since pour détecter_changes
  • Param include_tests sur trace_path — marque les fichiers de test dans les résultats BFS
  • risk_labels sur trace_path pour le traçage de chemin sensible à la sécurité
  • Drapeau --progress CLI pour un retour d'indexation en temps réel
  • CBM_CACHE_DIR env var pour le répertoire de base de données configurable
  • Mode index moderate ajouté au schéma de l'outil (entre complet et rapide)
  • Exposition des propriétés du schéma pour param_names, param_types, decorators
  • Correctif include_connected : BFS entrant et sortant s'exécutait séparément (fusionnait incorrectement)

Qualité de vie

  • Support .gitignore imbriqué : le sous-répertoire gitignores est désormais respecté lors de l'indexation — critique pour les monorepos (#178)
  • Consolidation des compétences : 4 compétences distinctes fusionnées en 1 avec divulgation progressive
  • Mise à jour intelligente : skip update when already on latest version
  • Détection binaire d'exécution dans la commande d'installation (n'est plus codée en dur)
  • Prise en charge des sous-modules Git dans watcher : détecte l'état sale à l'intérieur des sous-modules
  • Détection de changement de mode rapide → complet + activation automatique de l'interface utilisateur pour le binaire de la variante ui
  • Point final de mise en page : mappage de bord O(n*e) remplacé par une recherche binaire
  • Mise en page JSON : gestion des UTF-8 et NaN invalides en sérialisation

Correctifs de la plate-forme

  • Windows : chemins de configuration Zed/VS Code/KiloCode, délimiteur PATH, vérification S_IXUSR, détection d'agent à l'aide de chemins relatifs à home_dir, test de configuration utilisateur basé sur APPDATA
  • Linux portable : compatibilité Alpine Musl, audits de sécurité ajoutés aux tests de fumée, XDG_CONFIG_HOME dans un environnement de fumée
  • Assemblage de blob vectoriel multiplateforme : conditions de préprocesseur pour macOS Mach-O / Linux ELF / Windows COFF
  • Correctif C++ SEGV : deref NULL dans le résolveur de type LSP sur les gros fichiers d'en-tête

Qualité du code et peluchage

  • 337 avertissements linter résolus sur 16 fichiers (constantes nommées, extraction de complexité cognitive)
  • Seuil de complexité cognitive défini par défaut dans l'industrie (25), 168 fonctions réparties
  • Division de la fonction divine cbm_write_db (569 → 325 lignes)
  • Toutes les suppressions NOLINTNEXTLINE éliminées, marcheurs AST itératifs
  • Correction d'une fuite ASan dans le corpus sémantique token_map

CI/CD et sécurité

  • Porte de sécurité découplée : sécurité statique + CodeQL exécutés indépendamment, ne bloquez pas le pipeline de test/construction/fumée
  • Audits de sécurité sur TOUTES les variantes binaires (standard + UI) — auparavant, les binaires de l'interface utilisateur n'étaient pas audités
  • Vocabulaire de jetons AV-safe : 11 mots déclencheurs heuristiques supprimés des intégrations Nomic
  • CI divisé en composants de workflow réutilisables
  • Améliorations des dépendances vendues : SQLite 3.51.3, Mongoose 7.21, mimalloc 3.2.8
  • Actions supprimées : téléchargement-artefact v8.0.1, attest-sbom v2, cosign v4.1.1, msys2 v2.31.0, extraction v6.0.2, cache v5.0.4, téléchargement-artefact v7.0.0, attest-build-provenance v4.1.0, codeql-action v4.35.1
