codebase-memory-mcp 0.6.1

📦 Page de version archivée — les binaires de cette version ne sont plus publiés. Obtenez la [dernière version] (https://github.com/DeusData/codebase-memory-mcp/releases/latest).

v0.6.1 — 89 nouvelles langues, intelligence inter-repo, artefact graphique partagé en équipe, distribution npm+PyPI

Plus de 50 commits depuis v0.6.0. Ajoute 89 grammaires arborescentes (66 → 155 langues), introduit l'intelligence cross-repo avec CROSS_* Edges, fournit des artefacts graphiques partagés en équipe (.codebase-memory/graph.db.zst), introduit des wrappers de distribution complets (npm/PyPI/Homebrew/Scoop/Winget/Chocolatey/AUR/Go) avec npm + PyPI désormais auto-publiés dans le cadre du pipeline de publication et déploie un renforcement complet de la sécurité de l'installateur.

Langues et analyse – 66 → 155

  • 89 nouvelles grammaires arborescentes vendues, avec tokenisation avec vocabulaire nettoyé et script d'audit de sécurité grammatical
  • Couverture des spécifications linguistiques renseignée pour 114 langues avec les types de nœuds appropriés — Go (func_literal), JS (do_statement, case_clause obsolète corrigé), importations C#/Python, tableaux partagés
  • 77 nouveaux tests de mappage d'extension couvrant les nouvelles langues
  • C#, Rust, grammaires Scala mises à jour avec la dernière version en amont
  • Refactor lang_specs : initialiseurs désignés + pointeur d'usine

Intelligence inter-repo

  • CROSS_ types de bord* pour les dépendances entre pensions et les relations architecturales
  • Détection de service gRPC / GraphQL / tRPC avec extraction de route protobuf
  • Détection de stub gRPC en résolution d'appel + extraction d'appel enchaîné
  • Disposition de l'interface utilisateur multi-galaxie + vue récapitulative de l'architecture cross-repo

Artefact graphique partagé en équipe

  • .codebase-memory/graph.db.zst — graphe de connaissances compressé en zstd qui peut être validé dans le dépôt. Les coéquipiers démarrent à partir de l’artefact au lieu d’exécuter une réindexation complète à partir de zéro.
  • Zstd 1.5.7 vendu (fusionné, ~52K LOC) pour une compression de 8 à 13:1
  • Export à deux niveaux : zstd -9 + suppression d'index + VACUUM INTO pour les index explicites (meilleur ratio) ; zstd -3 pour les mises à jour automatiques de surveillance/incrémentales (faible latence)
  • Chemin d'importation : décompresser → vérifier l'intégrité → recréer automatiquement les index
  • Auto-bootstrap dans index_repository : lorsqu'aucune base de données locale n'existe mais que l'artefact est présent, importez d'abord puis exécutez l'indexation incrémentielle
  • Crée automatiquement .gitattributes avec merge=ours pour éviter les conflits de fusion sur l'artefact binaire

Importations et canaux

  • Résolution générique de package/module pour les bords IMPORTS dans 10 langues (résout les spécificateurs nus tels que @myorg/pkg, github.com/foo/bar, use my_crate::foo via l'analyse de manifeste : package.json, go.mod, Cargo.toml, pyproject.toml, composer.json, pubspec.yaml, pom.xml, build.gradle, mix.exs, *.gemspec)
  • Détection de chaînes étendue de JS/TS à 8 langues

Répartition

Désormais installable directement à partir des registres de packages publics :

npm install -g codebase-memory-mcp     # npm
pip install codebase-memory-mcp         # PyPI
go install github.com/DeusData/codebase-memory-mcp/pkg/go@latest   # Go
  • npm + PyPI auto-publish intégré dans le pipeline de versions (tâche publish-registries après verify, puis atomique publish-final annule la version GitHub uniquement après la réussite des deux registres - pas d'état à moitié expédié)
  • Le package npm utilise --provenance (attestations de build OIDC GitHub visibles sur npmjs.com)
  • Wrappers de distribution complète dans pkg/ pour : npm, PyPI, Homebrew, Scoop, Winget, Chocolatey, AUR, Go

Renforcement de la sécurité

  • Installateur PyPI : renforcé contre les attaques tar-slip et Scheme-Confusion (PR #248 par @dLo999, ferme le #246)
  • installateur npm : vérification de la somme de contrôle, redirections HTTPS uniquement, pas d'injection shell
  • Renforcement multi-installateur : suppression de Unblock-File, ajout de la validation d'URL HTTPS uniquement
  • vite transféré vers 6.4.2 — corrige CVE GHSA-4w7w-66w2-5vf9 et GHSA-p9ff-h696-f583
  • Audit de sécurité grammatical ajouté au pipeline des fournisseurs
  • README : liens d'analyse VirusTotal (hachages binaires), badge SLSA, section Sécurité et Trust, clause de non-responsabilité en matière de transparence, invitation à la divulgation responsable
  • badge papier arXiv + citation

Stabilité et qualité

  • get_graph_schema expose désormais les définitions de propriétés par étiquette de nœud
  • pages de débordement sqlite_writer — corrige SIGBUS sur les enregistrements volumineux (#139)
  • Récupération RSS après delete_project : mem_collect explicite + purge immédiate
  • Outils MCP / CLI : gestion des erreurs, diagnostics et annulation améliorés
  • Améliorations de l'extraction et du chiffrement triées sur le volet du PR #162

Éditeur / Intégration d'agent

  • Support Kiro CLI (#96)

Correctifs de la plate-forme

  • Windows : pass_pkgmap utilise désormais cbm_strndup (mingw clang n'a pas POSIX strndup)
  • test_watcher : utilise les variables d'environnement GIT_AUTHOR_* / GIT_COMMITTER_* au lieu de muter la configuration git globale

CI / Fumée

  • Analyse du test de fumée JSON corrigée — Le mode par défaut du CLI déballe l'enveloppe MCP ; smoke analyse maintenant directement le JSON interne
  • Liste autorisée d'audit de chaînes binaires — Le schéma d'URI telnet de la première grammaire est documenté comme une correspondance bénigne connue

Contributeurs

Merci à tous ceux qui ont contribué à cette version :

  • @dLo999 — Renforcement de l'installateur PyPI (#248)
