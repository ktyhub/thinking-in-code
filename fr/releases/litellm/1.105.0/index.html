litellm v1.105.0

Vérifier la signature de l'image Docker

Toutes les images LiteLLM Docker sont signées avec cosign. Chaque version est signée avec la même clé introduite dans commit 0112e53. Vérifiez à l'aide du hachage de validation épinglé (recommandé) : Un hachage de validation est cryptographiquement immuable, c'est donc le moyen le plus efficace de garantir que vous utilisez la clé de signature d'origine :

cosign verify \
  --key https://raw.githubusercontent.com/BerriAI/litellm/0112e53046018d726492c814b3644b7d376029d0/cosign.pub \
  ghcr.io/berriai/litellm:v1.105.0

Vérifiez à l'aide de la balise de version (commodité) : Les balises sont protégées dans ce référentiel et sont résolues par la même clé. Cette option est plus facile à lire mais s'appuie sur des règles de protection des balises :

cosign verify \
  --key https://raw.githubusercontent.com/BerriAI/litellm/v1.105.0/cosign.pub \
  ghcr.io/berriai/litellm:v1.105.0
