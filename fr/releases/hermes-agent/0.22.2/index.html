#hermès-agent v0.22.2

Agent Hermès v0.22.2

Date de sortie : 15 octobre 2026

v0.22.1 a été construit à partir d'un mauvais commit. Il fournissait un travail de passerelle inédit et l'application Microsoft Store pouvait rester sur "Connexion". 0.22.2 est la version que 0.22.1 était censée être.

Problème connu : Les sessions exécutées sous la passerelle 0.22.1 ne peuvent pas être supprimées dans 0.22.2.

<!-- HERMES_BUILDS_TABLE -->

Faits saillants

  • La passerelle redémarre après un redémarrage. Après un redémarrage, Linux peut transmettre un PID précoce à un processus sans rapport, et la passerelle pourrait le prendre pour une passerelle en cours d'exécution, donc une passerelle supervisée (systemd, launchd, Docker) a refusé de démarrer. Hermes enregistre désormais le démarrage dans lequel il a démarré et, lorsqu'il ne peut pas le savoir, il demande le verrouillage de l'hôte, que seule une passerelle active détient. (#138594, correctifs #133744)
  • Les longs tours du modèle local survivent sur les ordinateurs portables. Les requêtes locales sont toujours diffusées avec une progression de lecture rapide (affichée dans la ligne d'état), les minuteries de décrochage sautent le temps pendant lequel la machine était en veille, un serveur local récupéré obtient un autre essai au lieu d'un disjoncteur qui a échoué à chaque message ultérieur, et la compression n'expire plus pendant que le serveur est encore en train de lire une longue conversation. Sur les machines Windows à mémoire unifiée, le lancement du modèle et le cache d'invite sont dimensionnés pour libérer de la mémoire. (#138560)

Vous trouverez ci-dessous tout ce qui se trouve dans la gamme de versions 0.22 depuis v0.22.0 : les correctifs 0.22.1 étaient censés être livrés, plus les deux ci-dessus. Travail uniquement sur les navires main avec v0.23.0.
