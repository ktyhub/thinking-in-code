#hermès-agent v2026.3.17

Agent Hermès v0.3.0 (v2026.3.17)

Date de sortie : 17 mars 2026

La version du streaming, des plugins et du fournisseur : livraison unifiée de jetons en temps réel, architecture de plug-in de première classe, système de fournisseur reconstruit avec Vercel AI Gateway, fournisseur Anthropic natif, approbations intelligentes, connexion au navigateur Chrome CDP en direct, intégration ACP IDE, mémoire Honcho, mode vocal, shell persistant et plus de 50 corrections de bugs sur chaque plate-forme.

✨ Points forts

  • Infrastructure de streaming unifiée — Livraison jeton par jeton en temps réel dans CLI et toutes les plates-formes de passerelle. Les réponses sont diffusées au fur et à mesure qu'elles sont générées au lieu d'arriver sous forme de bloc. (#1538)
  • Architecture de plugin de première classe — Déposez les fichiers Python dans ~/.hermes/plugins/ pour étendre Hermes avec des outils, des commandes et des hooks personnalisés. Aucune bifurcation requise. (#1544, #1555)
  • Native Anthropic Provider — Appels directs Anthropic API avec découverte automatique des informations d'identification Claude Code, flux OAuth PKCE et mise en cache native des invites. Aucun intermédiaire OpenRouter n’est nécessaire. (#1097)
  • Smart Approvals + /stop Command — Système d'approbation inspiré du Codex qui apprend quelles commandes sont sûres et mémorise vos préférences. /stop arrête immédiatement l'exécution de l'agent en cours. (#1543)
  • Honcho Memory Integration — Écritures de mémoire asynchrones, modes de rappel configurables, intégration du titre de session et isolation multi-utilisateurs en mode passerelle. Par @erosika. (#736)
  • Mode vocal — Push-to-talk dans CLI, notes vocales dans Telegram/Discord, prise en charge des canaux vocaux Discord et transcription Whisper locale via un chuchotement plus rapide. (#1299, #1185, #1429)
  • Exécution simultanée d'outils — Plusieurs appels d'outils indépendants s'exécutent désormais en parallèle via ThreadPoolExecutor, réduisant considérablement la latence pour les tours multi-outils. (#1152)
  • Rédaction PII — Lorsque privacy.redact_pii est activé, les informations personnelles identifiables sont automatiquement nettoyées avant d'envoyer le contexte aux fournisseurs LLM. (#1542)
  • /browser connect via CDP — Attachez les outils du navigateur à une instance Chrome en direct via le protocole Chrome DevTools. Déboguez, inspectez et interagissez avec les pages que vous avez déjà ouvertes. (#1549)
  • Vercel AI Gateway Provider — Acheminez Hermes via AI Gateway de Vercel pour accéder à son catalogue de modèles et à son infrastructure. (#1628)
  • Routeur de fournisseur centralisé — Système de fournisseur reconstruit avec call_llm API, commande unifiée /model, fournisseur de détection automatique sur le commutateur de modèle et remplacements directs des points de terminaison pour les clients auxiliaires/délégations. (#1003, #1506, #1375)
  • Serveur ACP (intégration IDE) — VS Code, Zed et JetBrains peuvent désormais se connecter à Hermes en tant que backend d'agent, avec une prise en charge complète des commandes slash. (#1254, #1532)
  • Mode Shell persistant — Les backends des terminaux locaux et SSH peuvent maintenir l'état du shell lors des appels d'outils — les cd, les variables d'environnement et les alias persistent. Par @alt-glitch. (#1067, #1483)
  • Agentic On-Policy Distillation (OPD) — Nouvel environnement de formation RL pour les politiques d'agent de distillation, élargissant l'écosystème de formation Atropos. (#1149)
