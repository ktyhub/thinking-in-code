#hermès-agent v2026.4.23

Agent Hermès v0.11.0 (v2026.4.23)

Date de sortie : 23 avril 2026 Depuis v0.9.0 : 1 556 commits · 761 PR fusionnés · 1 314 fichiers modifiés · 224 174 insertions · 29 contributeurs de la communauté (290 y compris les co-auteurs)

La version Interface : une réécriture complète de React/Ink du CLI interactif, une architecture de transport enfichable sous chaque fournisseur, la prise en charge native d'AWS Bedrock, cinq nouveaux chemins d'inférence, une 17e plate-forme de messagerie (QQBot), une surface de plugin considérablement étendue et GPT-5.5 via le Codex OAuth. Cette version intègre également tous les points forts différés du v0.10.0 (qui fournissait uniquement la passerelle Nous Tool) - elle couvre donc environ deux semaines de travail sur l'ensemble de la pile.

✨ Points forts

  • Nouveau TUI basé sur Ink — hermes --tui est désormais une réécriture complète React/Ink du CLI interactif, avec un backend Python JSON-RPC (tui_gateway). Sticky composer, diffusion en direct avec prise en charge OSC-52 clipboard, touches de sélection stables, barre d'état avec chronomètre par tour et branche git, confirmation /clear, préréglage de thème lumineux et superposition d'observabilité d'apparition de sous-agent. ~ 310 s'engage sur ui-tui/ + tui_gateway/. (@OutThisLife + Teknium)
  • Transport ABC + Native AWS Bedrock — La conversion de format et le transport HTTP ont été extraits de run_agent.py dans une couche agent/transports/ enfichable. AnthropicTransport, ChatCompletionsTransport, ResponsesApiTransport et BedrockTransport possèdent chacun leur propre conversion de format et leur propre forme API. La prise en charge native d'AWS Bedrock via le Converse API s'ajoute à la nouvelle abstraction. (#10549, #13347, #13366, #13430, #13805, #13814 — @kshitijk4poor + Teknium)
  • Cinq nouveaux chemins d'inférence — NVIDIA NIM natif (#11774), Arcee AI (#9276), Step Plan (#13893), Google Gemini CLI OAuth (#11270) et Vercel ai-gateway avec tarification + dynamique découverte (#13223 — @jerilynzheng). De plus, Gemini est acheminé via le AI Studio natif API pour de meilleures performances (#12674).
  • GPT-5.5 sur Codex OAuth — Le nouveau modèle de raisonnement GPT-5.5 d'OpenAI est désormais disponible via votre ChatGPT Codex OAuth, avec une découverte de modèle en direct connectée au sélecteur de modèle afin que les nouvelles versions d'OpenAI s'affichent sans mises à jour du catalogue. (#14720)
  • QQBot — 17e plate-forme prise en charge — Adaptateur QQBot natif via QQ Official API v2, avec assistant de configuration de numérisation pour configurer QR, curseur de streaming, réactions emoji et contrôle de politique DM/groupe qui correspond à la parité WeCom/Weixin. (#9364, #11831)
  • Surface du plugin étendue — Les plugins peuvent désormais enregistrer des commandes slash (register_command), envoyer des outils directement (dispatch_tool), bloquer l'exécution d'outils à partir de hooks (pre_tool_call peut y mettre son veto), réécrire les résultats de l'outil (transform_tool_result), transformer la sortie du terminal (transform_terminal_output), expédier les backends image_gen et ajouter des onglets de tableau de bord personnalisés. Le plugin de nettoyage de disque fourni est activé par défaut en tant qu'implémentation de référence. (#9377, #10626, #10763, #10951, #12929, #12944, #12972, #13799, #14175)
  • /steer — nudges d'agent à mi-exécution — /steer <prompt> injecte une note que l'agent en cours d'exécution voit après son prochain appel d'outil, sans interrompre le tour ni casser le cache d'invite. À utiliser lorsque vous souhaitez corriger le cap d'un agent en vol. (#12116)
  • Shell hooks — Connectez n'importe quel script shell en tant que hook de cycle de vie Hermes (pre_tool_call, post_tool_call, on_session_start, etc.) sans écrire de plugin Python. (#13296)
  • Mode de livraison directe Webhook — Les abonnements Webhook peuvent désormais transférer les charges utiles directement vers une discussion sur la plateforme sans passer par l'agent — notifications push zéro LLM pour les alertes, les contrôles de disponibilité et les flux d'événements. (#12473)
  • Délégation plus intelligente — Les sous-agents ont désormais un rôle orchestrator explicite qui peut générer leurs propres travailleurs, avec max_spawn_depth configurable (plat par défaut). Les sous-agents frères et sœurs simultanés partagent l'état du système de fichiers via une couche de coordination de fichiers afin de ne pas gêner les modifications des autres. (#13691, #13718)
  • Modèles auxiliaires — interface utilisateur configurable + modèle principal en premier — hermes model dispose d'un écran dédié « Configurer les modèles auxiliaires » pour les remplacements par tâche (compression, vision, session_search, title_Generation). Le routage auto utilise désormais par défaut le modèle principal pour les tâches secondaires de tous les utilisateurs (auparavant, les utilisateurs de l'agrégateur étaient acheminés silencieusement vers un modèle par défaut bon marché du côté du fournisseur). (#11891, #11900)
  • Système de plugin de tableau de bord + changement de thème en direct — Le tableau de bord Web est désormais extensible. Les plugins tiers peuvent ajouter des onglets, des widgets et des vues personnalisés sans bifurquer. Associé à un système de thèmes à commutation en direct (les thèmes contrôlent désormais les couleurs, les polices, la mise en page et la densité) afin que les utilisateurs puissent échanger à chaud l'apparence du tableau de bord sans recharger. Même discipline thématique que le CLI, maintenant sur le Web. (#10951, #10687, #14725)
  • Peaufinage du tableau de bord — i18n (anglais + chinois), disposition de la barre latérale du routeur React, adapté aux mobiles, déploiement Vercel, suivi réel des appels API par session et mise à jour One-click + boutons de redémarrage de la passerelle. (#9228, #9370, #9453, #10686, #13526, #14004 — @austinpickett + @DeployFaith + Teknium)
