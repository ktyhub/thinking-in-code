#hermès-agent v2026.3.23

Agent Hermès v0.4.0 (v2026.3.23)

Date de sortie : 23 mars 2026

La version d'extension de la plateforme : serveur API compatible OpenAI, 6 nouveaux adaptateurs de messagerie, 4 nouveaux fournisseurs d'inférence, gestion du serveur MCP avec OAuth 2.1, références de contexte @, mise en cache des invites de passerelle, streaming activé par défaut et une grande fiabilité avec plus de 200 corrections de bugs.

✨ Points forts

  • Serveur API compatible OpenAI — Exposez Hermes en tant que point de terminaison /v1/chat/completions avec un nouveau /api/jobs REST API pour la gestion des tâches cron, renforcé avec des limites d'entrée, des listes blanches de champs, une persistance des réponses basée sur SQLite et une protection de l'origine CORS (#1756, #2450, #2456, #2451, #2472)
  • 6 nouveaux adaptateurs de plateforme de messagerie — Les adaptateurs Signal, DingTalk, SMS (Twilio), Mattermost, Matrix et Webhook rejoignent Telegram, Discord et WhatsApp. La passerelle reconnecte automatiquement les plates-formes défaillantes avec une interruption exponentielle (#2206, #1685, #1688, #1683, #2166, #2584)
  • @références de contexte — Injection de contexte @file et @url de style Claude Code avec complétions de tabulation dans le CLI (#2343, #2482)
  • 4 nouveaux fournisseurs d'inférence — GitHub Copilot (OAuth + validation de jeton), Alibaba Cloud / DashScope, Kilo Code et OpenCode Zen/Go (#1924, #1879 par @mchzimm, #1673, #1666, #1650)
  • Gestion du serveur MCP CLI — Commandes hermes mcp pour l'installation, la configuration et l'authentification des serveurs MCP avec le flux PKCE OAuth 2.1 complet (#2465)
  • Mise en cache des invites de passerelle — Mettez en cache les instances d'AIAgent par session, en préservant le cache des invites Anthropic d'un tour à l'autre pour une réduction spectaculaire des coûts sur les longues conversations (#2282, #2284, #2361).
  • Révision de la compression de contexte — Résumés structurés avec mises à jour itératives, protection de la fin du budget des jetons, point de terminaison de résumé configurable et prise en charge du modèle de secours (#2323, #1727, #2224)
  • Streaming activé par défaut — Le streaming CLI est activé par défaut avec un affichage approprié de la progression du spinner/outil pendant le mode streaming, ainsi que de nombreux correctifs de saut de ligne et de concaténation (#2340, #2161, #2258).
