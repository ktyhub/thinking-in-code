Agent Hermès v0.18.1 (v2026.7.7)

Date de sortie : 7 juillet 2026

Sortie du correctif. Cette balise regroupe les ~ 660 PR fusionnés depuis v0.18.0 (1er juillet) – corrections de bugs, renforcement et travaux de fonctionnalités en cours – dans une version stable étiquetée pour les consommateurs en aval (images Docker, déploiements hébergés, installations PyPI).

À propos de cette version

Il s'agit d'une balise de correctif basée sur l'infrastructure plutôt que d'une version entièrement organisée. Depuis la livraison de v0.18.0 il y a six jours, main a accumulé environ 667 commits sur ~990 fichiers (+89,5 000/−10,4 000 lignes), y compris l'auto-réparation du programme d'installation/mise à jour sur Windows, les correctifs du tableau de bord et de la passerelle, le couplage du tableau de bord WhatsApp, les correctifs MCP et du fournisseur, et un grand volume de travail de stabilité. Les release note entièrement sélectionnés pour cette fenêtre seront livrés avec v0.19.0, qui documentera tout à partir de v0.18.0 : les points forts, les zones de fonctionnalités et les crédits complets des contributeurs. Rien dans cette fenêtre n'est ignoré ; c'est documenté dans la prochaine version mineure.
