#hermès-agent v2026.4.3

Agent Hermès v0.7.0 (v2026.4.3)

Date de sortie : 3 avril 2026

La version de résilience : fournisseurs de mémoire enfichables, rotation du pool d'informations d'identification, navigateur anti-détection Camofox, aperçus des différences en ligne, renforcement de la passerelle dans les conditions de concurrence et le routage d'approbation, et correctifs de sécurité approfondis pour 168 PR et 46 problèmes résolus.

✨ Points forts

  • Interface du fournisseur de mémoire enfichable — La mémoire est désormais un système de plug-in extensible. Les backends de mémoire tiers (Honcho, magasins de vecteurs, bases de données personnalisées) implémentent un fournisseur simple ABC et s'enregistrent via le système de plugins. La mémoire intégrée est le fournisseur par défaut. Intégration Honcho restaurée à la parité complète en tant que plugin de référence avec une résolution hôte/homologue au niveau du profil. (#4623, #4616, #4355)
  • Pools d'informations d'identification du même fournisseur — Configurez plusieurs clés API pour le même fournisseur avec rotation automatique. La stratégie least_used thread-safe répartit la charge entre les clés et les échecs 401 déclenchent une rotation automatique vers l'identifiant suivant. Configuration via l'assistant de configuration ou la configuration credential_pool. (#4188, #4300, #4361)
  • Camofox Anti-Detection Browser Backend — Nouveau backend de navigateur local utilisant Camoufox pour une navigation furtive. Sessions persistantes avec découverte d'URL VNC pour le débogage visuel, contournement SSRF configurable pour les backends locaux, installation automatique via hermes tools. (#4008, #4419, #4292)
  • Aperçus des différences en ligne — Les opérations d'écriture de fichiers et de correctifs affichent désormais les différences en ligne dans le flux d'activité de l'outil, vous donnant une confirmation visuelle de ce qui a changé avant que l'agent ne passe à autre chose. (#4411, #4423)
  • Continuité des sessions du serveur API et diffusion des outils — Le serveur API (intégration Open WebUI) diffuse désormais les événements de progression des outils en temps réel et prend en charge les en-têtes X-Hermes-Session-Id pour les sessions persistantes entre les requêtes. Les sessions persistent dans la SessionDB partagée. (#4092, #4478, #4802)
  • ACP : serveurs MCP fournis par Client — Les intégrations d'éditeurs (VS Code, Zed, JetBrains) peuvent désormais enregistrer leurs propres serveurs MCP, qu'Hermes sélectionne comme outils d'agent supplémentaires. L'écosystème MCP de votre éditeur circule directement dans l'agent. (#4705)
  • Gateway Hardening — Une stabilité majeure dans les conditions de concurrence, la livraison de médias photo, le contrôle des inondations, les sessions bloquées, le routage d'approbation et les spirales mortelles de compression. La passerelle est nettement plus fiable en production. (#4727, #4750, #4798, #4557)
  • Sécurité : Blocage de l'exfiltration secrète — Les URL du navigateur et les réponses LLM sont désormais analysées à la recherche de modèles secrets, bloquant les tentatives d'exfiltration via le codage d'URL, base64 ou l'injection rapide. Protections du répertoire d'informations d'identification étendues à .docker, .azure, .config/gh. La sortie du bac à sable Execute_code est rédigée. (#4483, #4360, #4305, #4327)
