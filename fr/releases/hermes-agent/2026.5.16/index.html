#hermès-agent v2026.5.16

Agent Hermès v0.14.0 (v2026.5.16)

Date de sortie : 16 mai 2026 Depuis v0.13.0 : 808 commits · 633 PR fusionnés · 1393 fichiers modifiés · 165 061 insertions · 545 numéros fermés (12 P0, 50 P1) · 215 contributeurs de la communauté (y compris les co-auteurs)

La version Foundation – Hermes s'installe et s'exécute n'importe où, est livré avec les éléments que vous souhaitez réellement utiliser et arrête de livrer les éléments que vous n'utilisez pas. xAI Grok débarque en tant que fournisseur SuperGrok OAuth avec grok-4.3 placé dans une fenêtre contextuelle de 1 M. Un nouveau proxy local compatible OpenAI transforme n'importe quel fournisseur Hermes authentifié par OAuth (Claude Pro, ChatGPT Pro, SuperGrok) en un point de terminaison que Codex / Aider / Cline / Continue peut atteindre. x_search devient un outil de recherche X (Twitter) de première classe avec l'authentification par clé OAuth-ou-API. La pile Microsoft Teams est câblée de bout en bout (authentification graphique + écouteur webhook + exécution du pipeline + livraison sortante). Une vague de déballage rend les installations considérablement plus légères : les backends lourds s'installent désormais paresseusement lors de la première utilisation, les extras [all] suppriment tout ce qui est couvert par les deps paresseux et une installation à plusieurs niveaux retombe lorsqu'une roue rejette sur votre plate-forme. pip install hermes-agent fonctionne à partir de PyPI. La vague de démarrage à froid réduit d'environ 19 secondes le lancement du hermes. Les appels CDP du navigateur sont 180 fois plus rapides. Deux nouvelles plates-formes de messagerie (LINE + SimpleX Chat) portent le total à 22. Mise en cache des invites Claude d'une heure entre sessions, /handoff qui transfère réellement les sessions en direct, interface utilisateur de bouton natif pour clarify sur Telegram et Discord, remplissage de l'historique des canaux Discord, diagnostics sémantiques LSP à chaque écriture, un video_generate enfichable unifié, un backend de pilote cua computer_use qui fonctionne enfin avec les fournisseurs non anthropiques, URL clickables dans n'importe quel terminal, intégration du registre Zed ACP via uvx, version bêta native de Windows, 9 nouvelles compétences facultatives, routeur OpenRouter Pareto Code, étreintes de visage/compétences en tant que tap par défaut du trusted. 12 fermetures P0 + 50 P1.

✨ Points forts

  • xAI Grok via SuperGrok OAuth — et grok-4.3 passe à une fenêtre contextuelle de 1 M — Si vous payez pour SuperGrok, vous pouvez désormais utiliser Grok dans Hermes en vous connectant avec votre compte xAI — pas de clé API, pas de facturation séparée. Le transfert transfère également grok-4.3 vers une fenêtre contextuelle de jeton de 1 million, afin que vous puissiez déposer des bases de code entières ou des corpus de recherche dans une seule invite. Comprend une gestion appropriée des erreurs de droit et une page de documentation SSH vers tunnel lorsque vous êtes connecté en SSH dans une boîte distante et que vous devez terminer le flux OAuth. (#26534, #26664, #26644, #26592)
  • Proxy local compatible OpenAI pour les fournisseurs OAuth — Exécutez hermes proxy et vous obtenez un point de terminaison http://localhost:port qui parle OpenAI API mais est soutenu par le fournisseur OAuth auquel vous êtes connecté — Claude Pro, ChatGPT Pro, SuperGrok. Désormais, tout outil qui attend un point de terminaison compatible OpenAI (Codex CLI, Aider, Cline, Continue, vos scripts personnalisés) fonctionne simplement avec votre abonnement existant, aucune clé API n'est requise. Un abonnement, chaque outil. (#25969)
  • x_search — outil de recherche X (Twitter) de première classe — L'agent peut désormais rechercher X directement sans installer de compétence ni configurer une intégration personnalisée. Recherchez dans la chronologie, trouvez des fils de discussion, publiez des publications spécifiques, directement depuis le chat. Authentifiez-vous avec votre connexion X OAuth ou une clé API, selon celle dont vous disposez. (#26763)
  • Microsoft Teams — de bout en bout — Hermes peut désormais lire les messages de Teams et les publier. La pile complète Microsoft Graph est réunie : la fondation auth + client, ​​un écouteur webhook qui reçoit les événements Teams, un runtime de plugin de pipeline et une livraison sortante. Connectez le bot une fois, puis discutez avec votre agent depuis n'importe quel canal, DM ou groupe Teams. (récupérations de #21408–#21411) (#21922, #21969, #22007, #22024)
  • Vague de déballage – installations plus légères, moins d'utilisations – Un pip install hermes-agent propre utilisé pour tout extraire : chaque adaptateur de messagerie SDK, chaque SDK de génération d'image, chaque fournisseur de voix/TTS, que vous les utilisiez ou non. Désormais, ces backends lourds (adaptateurs Slack / Matrix / Feishu / DingTalk, rétrospective client, ​​serveur d'applications codex, Pixverse / Camofox / image-gen SDK, fournisseurs de voix/TTS) s'installent automatiquement la première fois que vous les utilisez. Les extras [all] suppriment tout ce qui est couvert par les dépôts paresseux, l'installateur revient d'un niveau à l'autre lorsqu'une roue ne correspond pas à votre plate-forme, et un vérificateur consultatif de la chaîne d'approvisionnement analyse chaque installation à la recherche de versions dangereuses. Installations plus rapides, empreinte disque réduite, moins de vulnérabilités transitives. (#24220, #24515, #25014, #25038, #25766, #21818)
  • pip install hermes-agent && hermes — Hermes Agent est désormais un véritable package PyPI. Plus besoin de cloner le dépôt ou d'exécuter des programmes d'installation de shell : une commande pip et vous êtes en cours d'exécution. La roue est livrée avec le pack Ink TUI et le lanceur d'obus, de sorte que l'expérience complète sort de la boîte. (récupération de #26350) (#26593, #26148)
  • Cache d'invite Claude entre sessions 1h — Lorsque vous utilisez Claude via Anthropic, OpenRouter ou Nous Portal, le préfixe d'invite (invite système, compétences, mémoire) est désormais mis en cache pendant une heure entre les sessions. Démarrez une session /new et la première réponse revient plus rapidement et à moindre coût car le cache est encore chaud depuis votre dernière session. L'examen de la mémoire en arrière-plan touche également le cache, de sorte qu'il ne paie pas le prix fort à chaque tour. (#23828, #25434, #24778)
  • Évaluations browser_console 180 fois plus rapides — Lorsque l'agent utilise l'outil de navigation pour inspecter une page ou exécuter JavaScript, ces appels partagent désormais une connexion persistante à Chrome au lieu de lancer une nouvelle session DevTools à chaque fois. La différence est énorme : des choses qui prenaient auparavant quelques secondes par appel reviennent en millisecondes. Les interactions avec les pages du monde réel semblent instantanées. (#23226)
  • Vague de performances de démarrage à froid — ~ 19 secondes après le lancement de hermes — L'exécution de hermes vous faisait attendre pendant une partie de la surcharge d'importation et des appels réseau avant de voir une invite. Désormais, le chemin de lancement est en grande partie différé : les adaptateurs lourds ne se chargent que lorsque vous les utilisez, les catalogues de modèles proviennent d'abord du cache disque, les vérifications médicales s'exécutent en parallèle et chat -q ignore complètement la bannière de bienvenue. L'écran hermes tools toutes plates-formes à lui seul est passé de 14 secondes à moins de 1.5 secondes. (#22138, #22120, #22681, #22790, #22808, #22831, #22859, #22904, #22766, #25341)
  • Deux nouvelles plates-formes de messagerie — LINE + SimpleX Chat — LINE est très répandu au Japon, en Corée et à Taiwan, et Hermes fonctionne désormais nativement sur LINE Messaging API. SimpleX Chat est une messagerie décentralisée axée sur la confidentialité, sans identifiant d'utilisateur, également conçue comme une plate-forme de première classe. Cela porte Hermes à 22 plates-formes de messagerie au total, donc partout où vous et votre équipe discutez, l'agent peut être là. (#23197, #26232)
  • /handoff transfère en fait la session en direct — Changer de modèle ou de personnalité en cours de conversation signifiait auparavant perdre le contexte ou recommencer. Désormais, /handoff déplace votre session active (chaque message, chaque appel d'outil, chaque élément de contexte) vers le modèle, le personnage ou le profil cible, en direct, sans rien laisser tomber. En cours de débogage, passez d'un modèle rapide à un modèle à raisonnement approfondi, ou passez une session entre des profils pour différentes parties d'une tâche. (#23395)
  • Interface utilisateur des boutons natifs pour clarify sur Telegram et Discord — Lorsque l'agent utilise l'outil clarify pour vous poser une question à choix multiples, il affiche désormais de vrais boutons natifs de la plate-forme sur Telegram et Discord au lieu de vous demander de retaper le numéro d'option. Appuyez sur le bouton, l'agent obtient votre réponse. Particulièrement agréable sur mobile. (#24199, #25485)
  • Remplissage de l'historique du canal Discord (activé par défaut) — Lorsque Hermes rejoint un canal ou un fil de discussion Discord pour la première fois, il lit désormais l'historique des messages récents afin de savoir ce qui a été dit avant de répondre. Plus de « de quoi parle-t-on ? - l'agent a le contexte qui est déjà à l'écran pour tout le monde. (#25984)
  • vision_analyze renvoie les pixels aux modèles capables de vision — Lorsque vous pointez l'agent vers une image avec vision_analyze et que le modèle actif peut réellement voir (GPT-5, Claude, Gemini, Grok-vision), Hermes transmet désormais les pixels bruts directement au modèle au lieu de les convertir d'abord en une description textuelle. Vous obtenez le raisonnement visuel réel du modèle au lieu d’un aller-retour de résumé textuel dégradé. (#22955)
  • Bas de page du vérificateur de mutation de fichier par tour — Après chaque tour d'écriture ou de modification de fichiers, l'agent reçoit désormais un court pied de page résumant exactement ce qui a changé sur le disque : les chemins d'accès aux fichiers, le nombre de lignes, le delta réel. Cela signifie que l'agent détecte ses propres erreurs lorsqu'une écriture n'arrive pas ou est écrasée silencieusement, au lieu de vous dire avec assurance « J'ai ajouté la fonction » alors que le fichier n'a pas été réellement enregistré. (#24498)
  • Diagnostics sémantiques LSP à chaque écriture — Lorsque l'agent utilise write_file ou patch, Hermes exécute désormais un véritable serveur de langage sur le fichier modifié et signale toute nouvelle erreur à l'agent avant le prochain tour. Erreurs de type, symboles non définis, importations manquantes : détectées immédiatement. Va bien au-delà du peluchage de base Python/JSON/YAML/TOML de v0.13.0, car il s'agit d'une véritable analyse sémantique. (#24168, #25978)
  • video_generate unifié avec backends de fournisseur enfichables — Un outil, n'importe quel modèle vidéo. Hermes est déjà livré avec les backends évidents, mais vous pouvez ajouter un nouveau fournisseur vidéo en tant que plugin sans toucher au noyau. Ainsi, lorsqu'un nouveau modèle vidéo arrive le mois prochain, il peut s'agir d'un plugin à un seul fichier au lieu d'un fork. (#25126)
  • Backend du pilote cua-driver computer_use — fonctionne désormais avec les modèles non-Anthropic — L'utilisation de l'ordinateur (l'agent contrôlant votre souris et votre clavier pour piloter les applications GUI) était auparavant verrouillée sur le SDK d'Anthropic. Le nouveau backend cua-driver fonctionne également avec des fournisseurs non anthropiques, dispose d'opérations sécurisées appropriées et s'actualise sur hermes update. Désormais, n'importe quel modèle compatible avec la vision peut piloter votre bureau. (récupération du #16936) (#21967, #24063)
  • URL Clickable dans n'importe quel terminal — Les liens dans la sortie de l'agent sont désormais de véritables hyperliens OSC8 avec surbrillance dans n'importe quel terminal qui les prend en charge. Click pour l'ouvrir dans votre navigateur - plus besoin de copier-coller-découper les URL longues de la transcription. Fonctionne uniquement dans iTerm2, Kitty, Ghostty, le terminal Windows moderne, etc. (@OutThisLife) (#25071, #24013)
  • Registre Zed ACP — Installation de uvx dans un click — Hermes est désormais répertorié dans le registre du protocole de l'agent Client de Zed, afin que les utilisateurs de Zed puissent l'installer avec un click. Le chemin d'installation utilise uvx, il n'y a donc pas de dépendance npm. hermes acp --setup-browser amorce les outils du navigateur pour les installations basées sur le registre. (récupération de #25908) (#26079, #26120, #26234)
  • Routeur OpenRouter Pareto Code avec bouton min_coding_score — Le routeur « Pareto » d'OpenRouter sélectionne automatiquement le modèle le moins cher qui répond à une barre de qualité minimale. La nouvelle configuration min_coding_score vous permet de définir cette barre spécifiquement pour les tâches de codage – Hermes se dirige vers le modèle le plus abordable qui est au moins aussi bon en code. Arrêtez de payer pour des modèles haut de gamme alors qu’un modèle de niveau intermédiaire ferait l’affaire. (#22838)
  • NovitaAI en tant que nouveau fournisseur de modèles — NovitaAI rejoint la gamme de fournisseurs, vous offrant une autre option d'hébergement de modèles open source (Llama, Qwen, DeepSeek, etc.) avec leurs prix et leurs limites tarifaires. (récupération #7219) (@kshitijk4poor) (#25507)
  • Environnement d'exécution du serveur d'applications Codex pour les modèles OpenAI/Codex — Un environnement d'exécution facultatif qui pilote le Codex CLI d'OpenAI sous le capot lorsque vous utilisez des chemins OpenAI ou Codex. Vous bénéficiez de la réutilisation des sessions, du retrait automatique des sessions bloquées et d'une classification d'actualisation OAuth appropriée - le type de plomberie qui évite l'échec des longues exécutions agents. (#24182, #25769)
  • huggingface/skills en tant que tap par défaut du trusted — L'index de compétences de la communauté hébergé sur huggingface.co/skills est désormais connecté au Skills Hub par défaut. Ainsi, lorsque quelqu'un y publie une compétence utile, vous pouvez l'installer à partir de votre propre navigateur hermes skills sans aucune configuration supplémentaire. (ferme le #2549) (#26219)
  • 9 nouvelles compétences facultatives — Hyperliquide (perp + trading au comptant via le SDK et REST API), Yahoo Finance (données de marché en direct, fondamentaux, historiques), tests api (recettes de débogage REST + GraphQL), multi-chaîne EVM unifiée (une compétence couvre Ethereum + L2s + Base), darwinian-evolver (réglage évolutif des invites/compétences), osint-investigation (OSINT recettes pour les personnes/domaines/organisations), pinggy-tunnel (exposer les services locaux à l'Internet public), les observateurs (sondages RSS/HTTP JSON/GitHub via le mode cron no_agent pour la détection des changements), et une refonte complète de Notion pour la plateforme de développement de mai 2026. (#23582, #23583, #23590, #25299, #26760, #26729, #26765, #21881, #26612)
  • Le serveur API expose les événements d'approbation d'exécution — Si vous pilotez Hermes par programmation via HTTP API, les exécutions de longue durée ne se bloquent plus silencieusement lorsque l'agent exécute une commande requise pour l'approbation. La demande d'approbation apparaît désormais sur le flux API afin que votre client puisse inviter l'utilisateur et répondre - plus de blocages silencieux. (récupération de #20311) (#21899)
  • Les plugins peuvent exécuter n'importe quel appel LLM via ctx.llm + remplacer les outils intégrés via tool_override — Si vous écrivez un plugin Hermes, vous bénéficiez désormais d'un accès de première classe pour passer des appels LLM via le fournisseur actif et les informations d'identification — pas de câblage manuel client. Le nouvel indicateur tool_override permet à un plugin d'échanger proprement un outil intégré avec sa propre implémentation. Les auteurs de plugins bénéficient du même routage de modèle et de la même plomberie d'authentification que l'agent principal utilise. (ferme le #11049) (#23194, #26759)
  • Brave Search (niveau gratuit) + DuckDuckGo (DDGS) en tant que fournisseurs de recherche sur le Web — Deux nouveaux backends de recherche sur le Web gratuits rejoignent Tavily, SearXNG et Exa. Brave Search propose un niveau gratuit généreux ; DDGS est le grattoir DuckDuckGo qui ne nécessite aucune clé. Choisissez celui qui correspond à votre budget et à vos besoins en matière de limite de taux. (#21337)
  • Blocage par force brute Sudo + 3 contournements de commandes dangereuses fermés + désinfection des erreurs d'outil — La porte d'approbation bloque désormais les tentatives de force brute sudo -S et classe les invocations sudo alimentées par stdin ou supprimées par Askpass comme DANGEREUSES. Trois contournements connus de détection de commandes dangereuses sont fermés (inspirés des travaux de détection de commandes de Claude Code). Et les chaînes d'erreur de l'outil sont désormais nettoyées avant d'être réinjectées dans le contexte du modèle, de sorte qu'un fichier malveillant ou un service distant ne peut pas transmettre d'instructions à votre agent via une sortie d'erreur. (#23736, #26829, #26823)
  • /subgoal — critères ajoutés par l'utilisateur ajoutés à un /goal actif — Lorsque vous avez un /goal en cours d'exécution (l'objectif persistant de la boucle de Ralph dans lequel l'agent continue jusqu'à ce que les critères soient remplis), vous pouvez désormais utiliser /subgoal <text> pour lui superposer des critères de réussite supplémentaires à mi-exécution. Le juge prend en compte vos nouveaux critères dans la décision de faire ou de continuer sans recommencer la boucle. (#25449)
  • Renommer le fournisseur — Alibaba Cloud → Qwen Cloud — Le fournisseur Alibaba Cloud est renommé Qwen Cloud dans le sélecteur et la configuration pour correspondre à ce que le reste du monde l'appelle. Les clés de configuration existantes fonctionnent toujours – aucune modification radicale – mais l’interface utilisateur correspond désormais à la marque actuelle. (#24835)
  • Prise en charge native de Windows (première version bêta) — Hermes s'exécute désormais de manière native sur cmd.exe et PowerShell sans WSL. Un programme d'installation PowerShell complet gère l'installation automatique de MinGit, la détection du stub Microsoft Store python et la danse Ctrl+C au premier plan. Il y a encore des aspérités (il s'agit du tampon "première version bêta") - environ 40 correctifs de suivi réservés à Windows ont déjà été ajoutés dans la fenêtre - mais la boucle de base fonctionne de bout en bout sur une boîte Windows propre. (#21561)
