#LangBot v4.11.5

LangBot est une plate-forme de chatbot et d'agent IA open source qui prend en charge plusieurs plates-formes de messagerie instantanée, de grands modèles de langage, des bases de connaissances et des plug-ins pour vous aider à créer, déployer et gérer des assistants IA. LangBot est une plate-forme d'agent et de chatbot IA open source qui connecte des plates-formes de messagerie, de grands modèles de langage, des bases de connaissances et des plugins pour vous aider à créer, déployer et gérer des assistants IA.

LangBot v4.11.5

Cette version de correctif ouvre l'espace de travail et les API d'exécution aux plugins et aux agents, ajoute des modèles vocaux et des cartes interactives multiplateformes, retravaille la façon dont les Runners reçoivent les médias et corrige une série de problèmes de plate-forme et d'exécution.

Faits saillants

  • Espace de travail API / Espace de travail API : les plug-ins et les agents peuvent appeler l'espace de travail et les capacités d'exécution via le API unifié, y compris la recherche et l'installation du marché et la lecture du langage de l'espace de travail. Les plugins et les agents peuvent appeler des API de Workspace et d'exécution, y compris la recherche/l'installation de Marketplace et le langage Workspace.
  • Speech/Speech : ajout de couches de modèles et d'étapes de pipeline TTS et STT, et synchronisation du modèle TTS/ASR de LangBot Space. Ajoute des modèles TTS/STT et des étapes de pipeline, avec synchronisation des modèles Space TTS/ASR.
  • Cartes interactives/Cartes interactives : QQ, WeChat Enterprise, Feishu et DingTalk prennent en charge les cartes interactives multiplateformes. Cartes interactives multiplateformes pour QQ, WeCom, Feishu et DingTalk.
  • Runner media / Runner media input : Les médias saisis par le Runner sont unifiés dans une liste ordonnée et les pièces jointes sont lues à la demande selon la réf ; le Runner officiel (Dify, Coze, Tbox, ACP, etc.) a été adapté. Le support d'entrée Runner est une liste ordonnée et les pièces jointes sont lues par référence ; Les coureurs officiels sont mis à jour.
  • Surveillance : enregistre les messages traités par le plugin, les étapes supprimées par les règles du pipeline et les appels LLM lancés par le plugin en dehors du pipeline. La surveillance affiche les messages gérés par le plug-in, l'étape de règle qui a supprimé un message et les appels LLM du plug-in en dehors d'un pipeline.
  • Plateformes et modèles/Plateformes et modèles : ajout d'un adaptateur LINE natif basé sur les événements (l'ancienne version est marquée comme héritée), fil de discussion Slack, envoi actif automatique en mode compte public, analyse d'expression officielle QQ ; ajout de la lecture de découverte/inférence NVIDIA NIM et MiniMax. Adaptateur LINE natif basé sur les événements, fils de discussion Slack, envois proactifs du compte officiel, visages officiels QQ ; Relecture de découverte/raisonnement NVIDIA NIM et MiniMax.
  • Plugins/Plugins : prend en charge la mise à niveau par lots des plug-ins du marché pour chaque espace de travail ; ajout des plug-ins officiels MulticaAgent, HandoffBridge et LeadCapture. Balayage des opérateurs pour mettre à niveau les plugins Marketplace dans les espaces de travail ; nouveaux plugins officiels MulticaAgent, HandoffBridge et LeadCapture.
  • Fixes / Fixes : plus de routes vers les pipelines et agents supprimés ; les plateformes sans streaming envoient les messages Runner un par un ; HTTP Bot /sync ne renvoie qu'une seule fois pour chaque réponse ; Enterprise WeChat se reconnecte automatiquement après l'échec d'un saut ; La propriété du runtime Box est conservée lors des redémarrages ; les baux d'exécution évoluent en fonction du nombre de tâches en cours ; Les runtimes plug-ins/Box démarrés par Core sous Windows utilisent plutôt stdio. Arrêtez le routage vers les pipelines/agents supprimés, la livraison par message sur les plates-formes sans streaming, les réponses uniques du robot HTTP /sync, la reconnexion du battement de cœur WeCom, la propriété persistante du runtime Box, les baux d'exécution proportionnels et les runtimes stdio sous Windows.
  • SDK : langbot-plugin corrigé de 0.7.19 à 0.7.23. langbot-plugin est épinglé de 0.7.19 à 0.7.23.

Vérification de la version

  • Tests unitaires (Python 3.11/3.12/3.13), intégration rapide, contrat PostgreSQL, intégration Box, démarrage E2E, Core smoke, outils de régression, contrat HTTP CLI compilé, contrat d'identité officiel du plugin, Ruff et frontend lint transmis lors du commit de publication.
  • langbot-plugin==0.7.23 est publié sur PyPI et épinglé dans pyproject.toml et uv.lock depuis le registre, sans dépendance VCS.
