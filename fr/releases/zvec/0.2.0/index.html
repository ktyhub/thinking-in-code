#zvec v0.2.0

🚀 Zvec v0.2.0 Release Note

Une mise à jour majeure axée sur l'optimisation, l'expansion de la plateforme et l'amélioration de l'expérience développeur.

📦 Fonctionnalités et améliorations principales

  • Prise en charge du cadre d'extension IA pour les flux de travail d'intégration sur l'appareil (#88)
  • Métadonnées de segment auto-évolutives dans les fichiers de stockage MMap (#67)
  • Interface d'invocation de recherche unifiée dans le noyau (#15)
  • Prise en charge de la version Linux ARM64 (#71)
  • Échec silencieux lors de tentatives d'initialisation répétées (#79)

🐞 Corrections de bugs

  • Correction de la logique delete_by_filter utilisant la clé au lieu de l'index (#84, #87)
  • Correction des tests unitaires int quantifiés (#47)
  • Suppression du paramètre column_name inutile de AddColumn API (#59)
  • Correction de fautes de frappe dans l'implémentation de l'index HNSW (#50)
  • Suppression des attentes d'erreurs redondantes dans les tests (#82)
  • Nettoyage du module ailego inutilisé (#85)

🔧 Expérience développeur

  • Remplacement du typing_extensions par le typing standard (Python ≥3.10) (#99)
  • Amélioration de la journalisation des erreurs C++ via LOG_ERROR au lieu de cerr (#80)
  • Docstrings et stubs .pyi mis à jour pour les liaisons Python (#41)
  • Suppression de la définition obsolète de IndexMeta::MetricType (#53)
  • Ajout d'exemples C++ à la matrice macOS/Linux CI (#86)

🤖 CI/CD et outillage

  • Prise en charge des exécutions CI pour les PR fourchus (#52)
  • Ignorer CI sur les modifications Markdown uniquement (#55)
  • Ajout de modèles de problèmes pour un meilleur support communautaire (#46)
  • Mise à jour de la version minimale requise pour CMake (#44, #57)
  • Actualisation de la documentation de l'outil Bench (#77)

📚Documentation

  • Badges README mis à jour et section rejoignez-nous (#45, #54)

👋 Nouveaux contributeurs

  • @SYaoJun — première contribution (#50)

Changelog complet : https://github.com/alibaba/zvec/compare/v0.1.1...v0.2.0
Recommandation de mise à niveau : ✅ Recommandé pour tous les utilisateurs — inclut des améliorations critiques en matière de performances et de stabilité.
