sim v0.9.55

Fonctionnalités

  • feat(credentials) : audience configurable pour les informations d'identification sans clé AWS, Databricks, Snowflake, Microsoft et Google (#9962)
  • feat(gitlab) : ajout d'une autorisation pour l'exportateur CSV (#9955)
  • feat(computer-use) : active l'utilisation de l'ordinateur par défaut, régie par une restriction de groupe d'autorisations (#9944)
  • feat(library) : Comment créer un agent Shopify AI pour les commandes et l'inventaire (#9940)
  • exploit (bibliothèque) : Viabilité du fournisseur de plate-forme d'agent IA : comparaison du financement, de l'adoption et de la pérennité (#9941)
  • exploit (aws-marketplace) : facturer l'utilisation LLM d'une liste à AWS via un décompte par période (#9921)
  • feat(credentials) : connexions PostgreSQL, MySQL et SQL Server enregistrées (#9929)
  • feat(credentials) : deuxième modes d'authentification pour ServiceNow, Snowflake, Infisical et Google Ads (#9928)
  • exploit (connaissance) : laissez le connecteur S3 se synchroniser avec un identifiant AWS enregistré (#9934)
  • exploit (informations d'identification) : informations d'identification enregistrées pour Amplitude, Kalshi, Splunk, CB Insights, Railway et Qdrant ; correction de la signature Kalshi Ed25519 (#9927)
  • feat(credentials) : identifiants d'application Microsoft pour Power BI et Azure Data Explorer, avec des cloud nationaux (#9931)
  • exploit (informations d'identification) : délégation sans clé à l'échelle du domaine Google Workspace via IAM signJwt (#9933)
  • exploit (informations d'identification) : enregistrer, afficher et expliquer l'expiration du jeton enregistré (#9930)
  • feat(bedrock) : exécutez des modèles Bedrock avec un identifiant AWS enregistré (#9932)
  • feat (informations d'identification) : hôtes régionaux et d'instance pour les informations d'identification LaunchDarkly, LangSmith, New Relic, Square, SendGrid, Hex et Sentry enregistrées (#9926)
  • feat(apollo) : ajouter des connexions OAuth facultatives (#9922)
  • exploit (aws-marketplace) : vendre plusieurs annonces à partir d'une seule intégration via un catalogue de produits (#9920)

Améliorations

  • amélioration(desktop-browser) : click via un contrôle imbriqué qui remplit toute la cible (#9956)
  • amélioration (ordinateur de bureau-navigateur) : références d'éléments stables, observations en attente et moins de faux refus (#9953)
  • amélioration (aws-marketplace) : comblez les écarts de facturation et simplifiez les chemins d'écriture des licences (#9946)
  • amélioration (informations d'identification) : conserver les jetons d'identification client valides lors des pannes d'actualisation et rythmer les tentatives de jetons par type d'échec (#9925)
  • amélioration (changelog) : couvre les mises à jour significatives du produit via v0.9.54 (#9809)

Corrections de bugs

  • correctif (informations d'identification) : pointez l'indice sans clé AWS vers le public politique, citez la documentation client ID et corrigez un commentaire obsolète (# 9970)
  • correctif (aws) : curseurs DynamoDB typés aller-retour et autoriser les statistiques CloudWatch uniquement en percentile (#9967)
  • correctif (navigateur de bureau) : donne à l'instantané de clôture d'une attente un budget complet et confirme que la réutilisation des références nomme le même élément (#9966)
  • correctif (exécuteur) : résout les informations d'identification du modèle enregistré à chaque tentative de repli dans le routeur et l'évaluateur (#9968)
  • correctif (intégrations) : renvoie la taille de la page Dataverse et corrige les résultats de recherche de contacts (#9965)
  • fix(tests) : clôture de trois courses de tests d'intégration qui ont écaillé CI (#9964)
  • correctif (intégrations) : révision finale pour les balayages Atlassian et AWS (#9961)
  • correctif (intégrations) : fermez les fuites de valeurs obsolètes et vides provenant des balayages de Google et Microsoft (#9960)
  • correctif (navigateur de bureau) : refuser les références antérieures rééditées et récupérer après la réutilisation de références non validées (#9959)
  • correctif (gitlab) : nécessite des e-mails confirmés dans les exportations d'autorisations (#9958)
  • correctif (aws) : valider les intégrations AWS par rapport aux documents SDK et API (#9952)
  • correctif (atlassian) : valider Jira, Confluence, JSM, Bitbucket, Trello par rapport aux documents du fournisseur (#9950)
  • correctif (microsoft) : valider les intégrations Microsoft, renvoyer les champs supprimés et exposer les paramètres manquants (#9949)
  • correctif (google) : comblez les lacunes de vérification après la fusion du balayage de l'espace de travail (#9954)
  • correctif (google) : valider les intégrations Workspace, renvoyer les champs supprimés et exposer les paramètres manquants (#9947)
  • fix(mothership) : annulez le sondage de transport au lieu de réessayer toutes les secondes (#9945)
  • correctif (informations d'identification) : connexion par mot de passe Splunk, paire de clés Snowflake dans le CLI, recherche de personnes Apollo OAuth et une courte attente d'accélérateur SailPoint (#9943)
  • fix(api) : rapporte l'état réel d'une exécution terminée une fois ses pauses réglées ; afficher l'identifiant de la demande dans le CLI (#9924)

Autres changements

  • corvée(intégrations) : ranger deux commentaires laissés par le balayage Google/Microsoft (#9969)
  • corvée(api) : décrit la règle de pause réglée dans la superposition de statut d'exécution TSDoc (#9957)
  • revert(library) : restaurer les postes d'orchestration et de gouvernance avant #9938 et #9939 (#9951)
  • docs(library) : supprime les questions en double dans les messages d'orchestration et de gouvernance (#9948)
  • docs(library) : mise à jour de gouvernance-ai-agents-multiple-teams-enterprise-workspace (#9939)
  • docs(library) : mise à jour d'ai-agent-orchestration-frameworks-explained (#9938)
  • docs(library) : mise à jour du guide de déploiement d'entreprise-ai-agent-compliance-deployment-guide (#9937)
