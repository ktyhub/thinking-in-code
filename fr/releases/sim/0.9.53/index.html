sim v0.9.53

Fonctionnalités

  • exploit (informations d'identification) : configurer les informations d'identification sans clé à partir des v2 API, CLI et Sim MCP (#9875)
  • exploit (informations d'identification) : Snowflake sans clé, application Microsoft uniquement et Google sans clé, jetons GitHub et Bitbucket, DocuSign JWT (#9869)
  • feat(mistral) : extraire des images PDF sous forme de fichiers et exposer le format de table dans Mistral Parser (#9856)
  • feat(api) : exécutez une version de déploiement épinglée et exposez les points d'exécution en pause dans la v2 (#9854)
  • feat(api-keys) : clés API en lecture seule et expiration à la création (#9855)
  • feat(api) : santé et activation du déclenchement du workflow via la v2 API (#9853)
  • feat(network) : honorer HTTP_PROXY, HTTPS_PROXY et NO_PROXY pour les requêtes gardées, AWS SDK clients et export OTLP (#9851)
  • feat(credentials) : informations d'identification enregistrées pour 21 blocs de jeton et d'hôte sur une usine de contrôle prenant en charge l'hôte (#9849)
  • feat(api) : gérer les membres de l'espace de travail via la v2 API (#9852)
  • exploit (informations d'identification) : informations d'identification enregistrées pour 17 blocs supplémentaires, jetons GitLab et renforcement sans clé (#9840)
  • feat(search) : gérer les autorisations des sources via un API et un CLI partagés (#9845)
  • exploit (recherche) : mettre à jour les CSV d'autorisation GitLab via le API (#9841)
  • exploit (bibliothèque) : AI Agent Development Company vs Building In House : Comment décider (#9844)
  • feat(library) : Meilleures plates-formes d'agents IA prenant en charge le protocole A2A en 2026 (#9843)
  • exploit (bibliothèque) : Générateurs d'agents IA avec outils de recherche et de recherche Web intégrés en 2026 (#9842)
  • feat(credentials) : informations d'identification enregistrées et versions de bloc d'informations d'identification uniquement, avec OIDC AWS/Databricks sans clé (#9763)

Améliorations

  • amélioration (api) : suivis d'audit de publication pour les analyses des membres v2, le middleware d'accès au workflow et la documentation (#9858)
  • amélioration (recherche) : renvoie une fenêtre de lecture en direct plus longue lorsqu'un MCP client demande plus de morceaux (#9823)

Corrections de bugs

  • correctif (informations d'identification) : corrigez les instructions de configuration sans clé et appliquez le contrat d'informations d'identification enregistrées sur chaque bloc d'informations d'identification (#9878)
  • correctif (mistral) : disons que la V3 analyse un PDF téléchargé ou référencé et relie Max Images à 100 (#9872)
  • correctif (version) : host_not_allowed pour les hôtes refusés, la version secrète interne de JWT uniquement et les nettoyages d'audit de version finale (#9870)
  • fix(sim-setup) : empêche doctor --fix de transformer les références ${VAR} en littéraux (#9868)
  • correctif (informations d'identification) : signaler un hôte refusé en tant qu'entrée de l'utilisateur, conserver les identifiants de compte normalisés, limiter les lectures de Databricks (#9859)
  • correctif (version) : unicité du sujet sans clé, NO_PROXY IPv6/CIDR, secret de démarrage proxy et suivis d'audit restants (#9866)
  • fix(release) : petits nettoyages d'audit de version (#9863)
  • correctif (version) : réutilisez uniquement les clés de délégation d'accès complet et traitez une profondeur d'analyse vide comme non définie (#9857)
  • correctif (sécurité) : durcissement des informations d'identification enregistrées, de sortie du proxy et des chemins sans clé à partir de l'audit de version (#9865)
  • correctif (version) : rédigez les clés de déploiement, vérifiez les outils basés sur les opérations dans le contrat d'informations d'identification enregistrées et supprimez la copie SDK (#9864)
  • correctif (version) : exécutez les versions asynchrones épinglées sur leurs propres variables, mappez les erreurs de création de clé CLI, affichez les jetons GitLab comme bloc actuel (#9862)
  • correctif (sim-setup) : citez les valeurs d'environnement contenant $ pour que dotenv, Bun et Compose ne les développent pas (#9861)
  • correctif (version) : plafonner les réponses HTTP simples par proxy, compter la profondeur de Firecrawl à partir de l'URL de démarrage et supprimer le cache de route obsolète lors de la mise à niveau (#9860)
  • correctif (firecrawl) : réponse complète v2 et compatibilité en profondeur (#9847)
  • correctif (cli) : lie les conteneurs de sim-setup au bouclage, corrige la réinitialisation et la citation d'environnement, retire l'ancien simstudio CLI (#9830)
  • correctif (docker) : garder les caches ISR et de liste de suffixes accessibles en écriture sur une racine en lecture seule (#9829)

Autres changements

  • test (api-keys) : utilise un nom de rôle de base de données neutre dans le luminaire d'erreur interne (#9877)
  • test (identifiants) : utilisez un appareil GitHub sans forme de jeton pour que l'analyse secrète reste silencieuse (#9876)
  • docs(release) : corrigez la note de la liste blanche Discord, le nom de l'image Mistral et la référence NO_PROXY (#9874)
  • docs(skills) : nommez refuseUnsafeTypedUrl dans les étapes d'ajout d'informations d'identification de jeton d'intégration (#9873)
  • corvée (sdk) : utiliser une famille de versions en direct comme élément de version sans rapport avec le flux de bureau (#9850)
  • corvée(sdk) : supprimer les TypeScript et Python SDK (#9848)
  • corvée (deps) : prenez vitest 5.1, shiki 4.6, réagissez-hook-form 7.91, MCP SDK 2.4 et petites mises à jour dans la gamme (#9846)
  • corvée(deps) : mise à niveau de pi vers 1.5.0 (#9826)
  • ci : déplacer le groupe d'actions sur 2 répertoires avec 7 mises à jour (#9839)
