#adk-python v2.11.0

2.11.0 (2026-10-01)

Faits saillants

Cette version ajoute une annulation gracieuse et une confirmation d'outil aux flux de travail, un outil pour consulter un autre modèle en cours de tâche et un service de mémoire SQLite intégré.

  • Annulation d'exécution : transmettez un abort_signal à Runner, Workflow et aux nœuds pour arrêter une exécution en douceur ; /run_sse annule désormais l'exécution lorsque le client se déconnecte. Consultez le [guide de l'unité] (https://github.com/google/adk-python/blob/main/docs/guides/runners/runner/abort.md) pour plus de détails. (ef5bbcf, 3d73603)
  • Confirmation des outils dans les flux de travail : les nœuds d'outils s'arrêtent désormais pour l'approbation de l'utilisateur via RequestInput, de la même manière qu'un LlmAgent, au lieu de transmettre une erreur en aval. (ce132b9)
  • ModelConsultTool : permet à un agent de consulter un autre modèle en cours de tâche, plafonné par les budgets par tour et par session. Consultez le [guide de l'unité] (https://github.com/google/adk-python/blob/main/docs/guides/tools/model_consult/model_consult_tool/index.md) pour plus de détails. (84cc99a)
  • Service de mémoire SQLite : conservez la mémoire de l'agent dans une base de données SQLite locale, sélectionnée avec un URI de service de mémoire sqlite://. (9625b06)
  • MCP SDK 2.x : connectez-vous aux serveurs MCP via le protocole moderne via un nouveau chemin d'adhésion. (e738c26)
