#adk-python v2.12.0

2.12.0 (2026-10-13)

Faits saillants

Cette version améliore les performances d'exécution lors de longues sessions tout en introduisant un contrôle plus précis sur l'exécution des outils, les approbations de flux de travail et la sécurité du déploiement.

  • Performance : réduisez de 40 % le temps nécessaire à la première demande de modèle lors de sessions longues. (1754b3e)
  • Outils : interceptez et filtrez les sorties des outils avant de les renvoyer au modèle à l'aide de after_tool_callback. (fdda17c)
  • Workflows : nécessite une confirmation humaine avant d'exécuter des nœuds de workflow via require_confirmation. (988fd1a)
  • Déploiement : déployez des agents sur Agent Engine à l'aide de comptes de service personnalisés dédiés. (629e119)
  • Python 3.15 : installez et exécutez ADK sur Python 3.15. (75aef1e)
