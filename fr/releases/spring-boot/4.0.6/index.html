spring-boot v4.0.6

Correctif Publié23 avr. 2026 Sourcespring-projects/spring-boot Anglais original

Cette page est traduite automatiquement. Le texte anglais original fait foi.

botte à ressort v4.0.6

## :lady_beetle : corrections de bugs

  • La sécurité par défaut est mal configurée lorsque spring-boot-actuator-autoconfigure est présent et que spring-boot-health n'est pas #50188
  • La configuration automatique de Elasticsearch Rest5Client est mal configurée sous-jacente à HTTP client #50187
  • ApplicationPidFileWriter ne gère pas correctement les liens symboliques #50185
  • RandomValuePropertySource ne convient pas aux secrets #50183
  • La configuration automatique de Cassandra configure mal CqlSessionBuilder #50180
  • ApplicationTemp ne gère pas correctement les liens symboliques #50178
  • Remote DevTools effectue une comparaison incorrecte #50176
  • spring.rabbitmq.ssl.verify-hostname est appliqué de manière incohérente #50174
  • Les valeurs entières sont ignorées lors de la configuration des valeurs attendues min et max et des limites SLO pour un compteur récapitulatif de distribution #50077
  • Il manque plusieurs modules aux démarreurs classiques #50071
  • Le module spring-boot-resttestclient est absent de spring-boot-starter-test-classic #50069
  • Les annotations comme @Ssl ne fonctionnent pas sur les méthodes @Bean lors de l'utilisation de @ServiceConnection #50064
  • EnversRevisionRepositoriesRegistrar devrait réutiliser @EnableEnversRepositories plutôt que de configurer son homologue JPA #50039
  • Le point de terminaison des liens WebFlux Cloud Foundry inclut la chaîne de requête de la demande reçue dans les liens résolus #50017
  • Les importations sur une classe de test conteneur sont ignorées lorsqu'une classe imbriquée a des importations #50012
  • Avec spring.jackson.use-jackson2-defaults défini sur true, FAIL_ON_UNKNOWN_PROPERTIES est activé #49951
  • Réponse 500 du point de terminaison d'environnement lorsque le modèle fourni n'est pas valide #49946
  • Le démarreur réactif MongoDB a une dépendance transitive sur le pilote MongoDB synchrone #49945
  • La méthode HTTP est perdue lors de la configuration des exclusions dans EndpointRequest #49943
  • Honorez HttpMethod pour les chemins de points de terminaison supplémentaires réactifs #49880
  • La prise en charge de Docker Compose ne fonctionne pas avec l'image Apache/Artemis #49869
  • La prise en charge de Docker Compose ne fonctionne pas avec l'image Apache/activemq #49866
  • PathPatternRequestMatcher.Builder de Spring Security n'est pas configuré automatiquement lors de l'utilisation de WebMvcTest et spring-boot-security-test #49854
  • La stratégie de chemin de version API doit être appliquée en dernier chemin car elle n'est pas censée produire #49800

## :notebook_with_decorative_cover : Documentation

  • Mettre à jour la documentation pour encourager les fondamentaux de Java pour les débutants qui préfèrent apprendre de cette façon #50146
  • L'interface de service HTTP Clients documente toujours que la gestion des versions API peut être configurée via les propriétés #50126
  • Le lien vers la section observabilité de la documentation Lettuce est rompu #50097
  • Javadoc pour StaticResourceLocation.FAVICON ne décrit pas l'emplacement des icônes #50085
  • Il manque un exemple Kotlin à MySamlRelyingPartyConfiguration #50024
  • Valeur par défaut incorrecte pour management.httpexchanges.recording.include dans les métadonnées de configuration #50019
  • Lien vers la documentation du Kubernetes lors de la discussion des sondes de démarrage #50015
  • Faute de frappe dans JdbcSessionAutoConfiguration Javadoc #49873
  • Préciser que les valeurs par défaut des propriétés de configuration ne sont pas disponibles via l'environnement #49851
  • Documenter le besoin de démarreurs Liquibase et Flyway #49839
  • La documentation Kafka fait référence aux classes obsolètes du sérialiseur et du désérialiseur JSON #49826
