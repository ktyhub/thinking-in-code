spring-boot v4.0.9

botte à ressort v4.0.9

:star: Nouvelles fonctionnalités

  • Ajoutez TWENTY_SEVEN à l'énumération JavaVersion #51422

## :lady_beetle : corrections de bugs

  • Les JWT sont rejetés lorsque l'émetteur-uri est vide et que jwk-set-uri est défini #52249
  • Les attributs du manifeste du package sont manquants pour les fichiers JAR imbriqués sans entrées de répertoire #52244
  • OriginTrackedPropertiesLoader supprime les propriétés dont le nom commence par # ou ! #52207
  • OriginTrackedResource n'implémente pas correctement les égalités #52205
  • L'arrêt progressif de Tomcat ou Jetty peut rappeler avec REQUESTS_ACTIVE lorsque l'arrêt est appelé immédiatement après shutdownGracefully sur un serveur inactif #52195
  • La propriété système vide dans TestPropertyValues est effacée au lieu d'être restaurée à sa valeur vide #52125
  • MongoDB ne parvient pas à se connecter lorsque les informations d'identification contiennent un espace #52121
  • L'arrêt de NettyWebServer peut se bloquer lorsqu'il est appelé immédiatement après shutdownGracefully #52119
  • L'authentification échoue lorsque le mot de passe configuré dans spring.elasticsearch.uris contient deux points #52047
  • La journalisation peut être perdue lorsqu'un contexte est mis en pause par le framework de contexte de test #51959
  • La prise en charge de Docker Compose pour MongoDB ne parvient pas à se connecter lorsque les informations d'identification contiennent un caractère nécessitant un codage d'URL #51939
  • Jersey n'utilise pas le point de terminaison ObjectMapper lorsque Actuator s'exécute sur un port distinct #51937
  • BasicJsonParser gère mal les caractères d'échappement dans les listes et cartes imbriquées #51907
  • La conversion de la valeur de semaine zéro échoue avec l'exception « intValue ne peut pas être extrait de WEEKS » #51892
  • L'application ne démarre pas lors de l'utilisation de DevTools et de la configuration manuelle de JDBC ou R2DBC sans spring-boot-jdbc ou spring-boot-r2dbc #51872
  • La prise en charge de Docker Compose ne reconnaît pas correctement MARIADB_ALLOW_EMPTY_PASSWORD au lieu de MARIADB_ALLOW_EMPTY_ROOT_PASSWORD #51870
  • La personnalisation du codec JSON de sérialisation Kotlinx automatiquement configurée n'est pas appliquée #51842
  • NullPointerException peut être levée lors de l'utilisation d'Uber Jars en raison d'une condition de concurrence critique dans NestedJarFileResources #51744
  • DevTools ne détecte pas un environnement Web réactif #51708
  • La connexion échoue lorsque le service Rabbitmq Docker Compose est configuré pour utiliser SSL #51666
  • Lorsque server.reactive.session.cookie.same-site n'est pas défini, les cookies de session n'ont pas d'attribut SameSite #51636
  • Le serveur de ressources OAuth2 ignore le délimiteur de réclamation d'autorité lorsqu'il est défini seul #51619
  • Dans une application Web réactive, l'intégration de sécurité Cloud Foundry renvoie un 500 plutôt qu'un 503 lorsque l'URL du contrôleur cloud n'est pas disponible #51613
  • Certains messages d'assertion nomment le mauvais paramètre #51568
  • Les attributs du manifeste liés au SBOM sont absents des guerres packagées avec Maven #51551
  • L'intégration de Docker Compose pour RabbitMQ ignore les replis d'informations d'identification lorsqu'une variable d'environnement n'a aucune valeur #51546
  • Les commandes des outils jarmode impriment stacktrace au lieu d'un message d'erreur #51540
  • Le fichier temporaire de calque n'est pas supprimé lorsque la création de calque échoue #51519
  • NestedByteChannel.read(ByteBuffer) renvoie incorrectement 0 lorsque le tampon n'a pas pu être rempli #51515
  • Les vérifications nulles du personnalisateur dans les générateurs HTTP client affirment le mauvais attribut #51509
  • Les configurations developmentOnly et testAndDevelopmentOnly ne spécifient aucun attribut provoquant des problèmes de résolution potentiels #51492
  • L'intégration de SQL Server Docker Compose peut dupliquer le paramètre de chiffrement de l'URL JDBC #51467
  • Les personnalisations de la configuration de l'hôte SSL peuvent être perdues lors de l'initialisation de Tomcat #51466
  • Les propriétés OAuth2ClientProperties ne sont pas disponibles lorsqu'un bean ClientRegistrationRepository défini par l'utilisateur est fourni #51447
  • La source n'est pas fermée de manière cohérente par tous les testeurs de marshal JSON #51417
  • JmsHealthIndicator perd les threads de surveillance si le démarrage échoue immédiatement #51412
  • Le descripteur de fichier dans SpringBootJoranConfigurator doit être fermé #51398
  • La validation de io.buildpacks.stack.id obsolète est trop agressive #51390
  • Les personnalisations de la configuration de l'hôte SSL sont perdues lors du rechargement des bundles SSL #51290
  • Docker Compose ProcessRunner peut bloquer ou laisser des processus orphelins #50963
  • Les descriptions des propriétés de configuration peuvent être perdues lors de la construction incrémentielle avec Gradle #50489
