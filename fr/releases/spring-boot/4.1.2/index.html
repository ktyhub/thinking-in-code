botte à ressort v4.1.2

:star: Nouvelles fonctionnalités

  • Ajoutez TWENTY_SEVEN à l'énumération JavaVersion #51426

## :lady_beetle : corrections de bugs

  • OriginTrackedResource n'implémente pas correctement les égalités #52267
  • OriginTrackedPropertiesLoader supprime les propriétés dont le nom commence par # ou ! #52265
  • Les JWT sont rejetés lorsque l'émetteur-uri est vide et que jwk-set-uri est défini #52260
  • Les attributs du manifeste du package sont manquants pour les fichiers JAR imbriqués sans entrées de répertoire #52258
  • Logback ColorConverter analyse inutilement ses options pour chaque événement de journal #52228
  • La propriété système vide dans TestPropertyValues est effacée au lieu d'être restaurée à sa valeur vide #52208
  • L'arrêt progressif de Tomcat ou Jetty peut rappeler avec REQUESTS_ACTIVE lorsque l'arrêt est appelé immédiatement après shutdownGracefully sur un serveur inactif #52197
  • L'arrêt de NettyWebServer peut se bloquer lorsqu'il est appelé immédiatement après shutdownGracefully #52196
  • L'équilibrage de charge gRPC client 'grpc' ne parvient pas à se lier à une NullPointerException lorsqu'aucune stratégie enfant n'est configurée #52193
  • Empêcher les propriétés gRPC client de remplacer les personnalisations utilisateur #52175
  • MongoDB ne parvient pas à se connecter lorsque les informations d'identification contiennent un espace #52168
  • L'authentification échoue lorsque le mot de passe configuré dans spring.elasticsearch.uris contient deux points #52166
  • La journalisation peut être perdue lorsqu'un contexte est mis en pause par le framework de contexte de test #52088
  • La prise en charge de Docker Compose pour MongoDB ne parvient pas à se connecter lorsque les informations d'identification contiennent un caractère nécessitant un codage d'URL #52084
  • Jersey n'utilise pas le point de terminaison ObjectMapper lorsque Actuator s'exécute sur un port distinct #51982
  • Les fractions de seconde ne sont pas gérées correctement lors de la configuration des durées de configuration du service gRPC #51957
  • Les descriptions des propriétés de configuration peuvent être perdues lors de la construction incrémentielle avec Gradle #51925
  • BasicJsonParser gère mal les caractères d'échappement dans les listes et cartes imbriquées #51908
  • La conversion de la valeur de semaine zéro échoue avec l'exception « intValue ne peut pas être extrait de WEEKS » #51894
  • L'application ne démarre pas lors de l'utilisation de DevTools et de la configuration manuelle de JDBC ou R2DBC sans spring-boot-jdbc ou spring-boot-r2dbc #51890
  • La prise en charge de Docker Compose ne reconnaît pas correctement MARIADB_ALLOW_EMPTY_PASSWORD au lieu de MARIADB_ALLOW_EMPTY_ROOT_PASSWORD #51888
  • La personnalisation du codec JSON de sérialisation Kotlinx automatiquement configurée n'est pas appliquée #51877
  • NullPointerException peut être levée lors de l'utilisation d'Uber Jars en raison d'une condition de concurrence critique dans NestedJarFileResources #51745
  • DevTools ne détecte pas un environnement Web réactif #51730
  • spring.http.clients.cookie-handling n'a aucun effet lors de l'utilisation d'un client réactif soutenu par un connecteur HttpComponents #51724
  • La connexion échoue lorsque le service Rabbitmq Docker Compose est configuré pour utiliser SSL #51667
  • Les attributs du manifeste liés au SBOM sont absents des guerres packagées avec Maven #51651
  • Lorsque server.reactive.session.cookie.same-site n'est pas défini, les cookies de session n'ont pas d'attribut SameSite #51639
  • Le serveur de ressources OAuth2 ignore le délimiteur de réclamation d'autorité lorsqu'il est défini seul #51630
  • Les configurations developmentOnly et testAndDevelopmentOnly ne spécifient aucun attribut provoquant des problèmes de résolution potentiels #51623
  • Dans une application Web réactive, l'intégration de sécurité Cloud Foundry renvoie un 500 plutôt qu'un 503 lorsque l'URL du contrôleur cloud n'est pas disponible #51614
  • Le fichier temporaire de calque n'est pas supprimé lorsque la création de calque échoue #51581
  • L'intégration de Docker Compose pour RabbitMQ ignore les replis d'informations d'identification lorsqu'une variable d'environnement n'a aucune valeur #51578
  • Certains messages d'assertion nomment le mauvais paramètre #51574
  • OAuth2ResourceServerProperties.Jwt a un setter qui ne correspond pas à son getter #51562
  • Les commandes des outils jarmode impriment stacktrace au lieu d'un message d'erreur #51547
  • Docker Compose ProcessRunner peut bloquer ou laisser des processus orphelins #51538
  • NestedByteChannel.read(ByteBuffer) renvoie incorrectement 0 lorsque le tampon n'a pas pu être rempli #51520
  • Les vérifications nulles du personnalisateur dans les générateurs HTTP client affirment le mauvais attribut #51513
  • Les personnalisations de la configuration de l'hôte SSL peuvent être perdues lors de l'initialisation de Tomcat #51511
  • L'intégration de SQL Server Docker Compose peut dupliquer le paramètre de chiffrement de l'URL JDBC #51481
  • WritableJson.toByteArray() peut corrompre les caractères supplémentaires #51464
  • Les personnalisations de la configuration de l'hôte SSL sont perdues lors du rechargement des bundles SSL #51457
  • Les OAuth2ClientProperties ne sont pas disponibles lorsqu'un bean ClientRegistrationRepository défini par l'utilisateur est fourni #51450
  • LdapHealthIndicator signale UNKNOWN au lieu de UP lorsque le serveur LDAP n'expose pas de version de protocole #51441
  • JmsHealthIndicator perd les threads de surveillance si le démarrage échoue immédiatement #51433
  • La source n'est pas fermée de manière cohérente par tous les testeurs marshal JSON #51418
  • Le descripteur de fichier dans SpringBootJoranConfigurator doit être fermé #51415
  • Honorer le déballage d'un wrapper lors de la résolution du DataSource racine #51410
  • La validation de io.buildpacks.stack.id obsolète est trop agressive #51400
  • ReactiveOAuth2ResourceServerWebSecurityAutoConfiguration annoté avec une mauvaise condition #50778
