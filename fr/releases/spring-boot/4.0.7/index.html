spring-boot v4.0.7

Correctif Publié10 juin 2026 Sourcespring-projects/spring-boot Anglais original

Cette page est traduite automatiquement. Le texte anglais original fait foi.

botte à ressort v4.0.7

## :lady_beetle : corrections de bugs

  • La configuration automatique de MailSender n'active pas la vérification du nom d'hôte #50746
  • La configuration automatique d'Artemis utilise un emplacement par défaut prévisible pour les données du courtier intégré #50744
  • NullPointerException dans le réacteur-netty SniProvider et bundle SSL non mappé avec RSocket #50640
  • SSL ne doit pas être activé lorsqu'un bundle SSL est remplacé par une chaîne vide #50634
  • La prise en charge de Docker Compose ne restaure pas l'indicateur d'interruption de thread lors de la capture d'InterruptedException #50617
  • RabbitProperties active SSL même lorsque spring.rabbitmq.ssl.bundle est remplacé par une chaîne vide #50611
  • NullPointerException dans le réacteur-netty SniProvider lorsque le bundle SSL utilise client-auth ou le serveur truststore sans bundles de nom de serveur #50609
  • La configuration automatique des tests n'intègre plus Spring Security avec HtmlUnitDriver #50602
  • Une couche écrite en dehors de l'emplacement de sortie de '//' est levée lors de l'utilisation de couches d'extraction dans le répertoire racine #50509
  • ConfigurationPropertiesReportEndpoint expose les composants internes du proxy AOP #50416
  • Les instances StackTracePrinter créées n'ont pas accès à l'environnement #50413
  • MappingsEndpoint signale le propre ID du contexte en tant que parentId lorsqu'un parent existe #50411
  • Le module Buildpack ne valide pas les conversions long vers int #50409
  • La prise en charge de GraphQL WebSocket ne configure pas les origines autorisées #50393
  • Les métadonnées des propriétés de configuration incluent des références de classe incorrectes #50375
  • Le chargeur Spring Boot ne prend pas en charge les fichiers Jar signés RSA et EC #50297
  • Les registres de compteurs ne sont pas supprimés du registre global lorsque le contexte est fermé #50286
  • Les annotations nullables de AbstractErrorController.getErrorAttributes ne sont pas alignées sur l'implémentation #50265
  • Le comparateur de liens EndpointRequest correspond inutilement aux méthodes HTTP autres que GET #50260
  • Le point de terminaison « /cloudfoundryapplication » de l'actuateur ne fonctionne pas si une configuration CORS restrictive est fournie à l'aide d'un bean nommé corsConfigurationSource #50257
  • ThreadPoolTaskScheduleBuilder perd inutilement de la précision lors de la configuration de l'heure de fin d'attente #50233
  • NimbusJwtDecoder accepte silencieusement les valeurs inconnues pour spring.security.oauth2.resourceserver.jwt.jws-algorithms #50227
  • Appliquer HTML escaping à l'attribut d'horodatage dans la page d'erreur Whitelabel #50215
  • Le paramètre server.servlet.session.cookie.partitioned=true n'a aucun effet lors de l'utilisation de Tomcat #50201
