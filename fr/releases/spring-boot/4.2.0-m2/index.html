## :lady_beetle : corrections de bugs

  • spring.http.clients.cookie-handling n'a aucun effet lors de l'utilisation d'un client réactif soutenu par un connecteur HttpComponents #51767
  • NullPointerException peut être levée lors de l'utilisation d'Uber Jars en raison d'une condition de concurrence critique dans NestedJarFileResources #51746
  • La connexion échoue lorsque le service Rabbitmq Docker Compose est configuré pour utiliser SSL #51668
  • Les attributs du manifeste liés au SBOM sont absents des guerres packagées avec Maven #51652
  • Lorsque server.reactive.session.cookie.same-site n'est pas défini, les cookies de session n'ont pas d'attribut SameSite #51640
  • Le serveur de ressources OAuth2 ignore le délimiteur de réclamation d'autorité lorsqu'il est défini seul #51631
  • Les configurations developmentOnly et testAndDevelopmentOnly ne spécifient aucun attribut provoquant des problèmes de résolution potentiels #51624
  • Dans une application Web réactive, l'intégration de sécurité Cloud Foundry renvoie un 500 plutôt qu'un 503 lorsque l'URL du contrôleur cloud n'est pas disponible #51615
  • ReactiveOAuth2ResourceServerWebSecurityAutoConfiguration annoté avec une mauvaise condition #51588
  • WritableJson.toByteArray() peut corrompre les caractères supplémentaires #51586
  • Le fichier temporaire de calque n'est pas supprimé lorsque la création de calque échoue #51582
  • L'intégration de Docker Compose pour RabbitMQ ignore les replis d'informations d'identification lorsqu'une variable d'environnement n'a aucune valeur #51579
  • Certains messages d'assertion nomment le mauvais paramètre #51575
  • OAuth2ResourceServerProperties.Jwt a un setter qui ne correspond pas à son getter #51566
  • Les commandes des outils jarmode impriment stacktrace au lieu d'un message d'erreur #51548
  • Docker Compose ProcessRunner peut bloquer ou laisser des processus orphelins #51539
  • NestedByteChannel.read(ByteBuffer) renvoie incorrectement 0 lorsque le tampon n'a pas pu être rempli #51521
  • Les vérifications nulles du personnalisateur dans les générateurs HTTP client affirment le mauvais attribut #51514
  • Les personnalisations de la configuration de l'hôte SSL peuvent être perdues lors de l'initialisation de Tomcat #51512
  • L'intégration de SQL Server Docker Compose peut dupliquer le paramètre de chiffrement de l'URL JDBC #51482
  • Les personnalisations de la configuration de l'hôte SSL sont perdues lors du rechargement des bundles SSL #51458
  • Les propriétés OAuth2ClientProperties ne sont pas disponibles lorsqu'un bean ClientRegistrationRepository défini par l'utilisateur est fourni #51451
  • LdapHealthIndicator signale UNKNOWN au lieu de UP lorsque le serveur LDAP n'expose pas de version de protocole #51442
  • JmsHealthIndicator perd les threads de surveillance si le démarrage échoue immédiatement #51434
  • Honorer le déballage d'un wrapper lors de la résolution du DataSource racine #51420
  • La source n'est pas fermée de manière cohérente par tous les testeurs marshal JSON #51419
  • Le descripteur de fichier dans SpringBootJoranConfigurator doit être fermé #51416
  • La validation de io.buildpacks.stack.id obsolète est trop agressive #51401
