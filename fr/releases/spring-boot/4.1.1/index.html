spring-boot v4.1.1

Correctif Publié20 août 2026 Sourcespring-projects/spring-boot Anglais original

Cette page est traduite automatiquement. Le texte anglais original fait foi.

botte à ressort v4.1.1

:avertissement : Attention requise

  • Le plugin Gradle de Spring Boot ne configure plus automatiquement gRPC lorsque le plugin Protobuf est appliqué. Ce comportement a causé des problèmes à ceux qui utilisaient Protobuf sans gRPC. Pour adhérer à la configuration de gRPC, configurez l'extension protobuf avec le plugin grpc à l'aide d'un bloc vide. Le plugin Spring Boot Gradle configurera alors automatiquement l'utilisation de protoc-gen-grpc-java comme auparavant. #50822
