  • Exposer les getters Path sur ApplicationHome et ApplicationTemp #50194

## :lady_beetle : corrections de bugs

  • Journalisation structurée : un échec d'encodage JSON corrompt le prochain événement de journal écrit sur le même thread #51371
  • Le protocole de sécurité spécifique au consommateur Kafka n'est pas pris en compte #51370
  • L'exposition du port du serveur de test gRPC doit être interrompue si gRPC n'est pas présent #51291
  • Les registres micrométriques épinglent le contexte de l'application #51136
  • Le fichier temporaire n'est pas supprimé lorsque la construction de ExportedImageTar échoue #51133
  • spring.grpc.server.health.include-overall-health n'est pas pris en compte #51106
  • Le processeur d'annotation de métadonnées ignore @NestedConfigurationProperty au niveau getter pour les enregistrements #51099
  • spring-boot-h2-console extrait le servlet-api en tant que dépendance transitive #51096
  • PropertiesLauncher n'enregistre pas les chemins d'archives imbriqués #51090
  • Les méthodes qui renvoient le résultat de Map#remove ne sont pas déclarées avec un type de retour @Nullable #51088
  • NativeImageResourceProvider aplatit les chemins de migration Flyway dans les sous-répertoires #50965
  • Correction de l'ordre de Kotlinx Serialization CodecCustomizer #50962
  • JarFile n'est pas fermé lors de la recherche de la classe principale dans l'archive #50960

  • Utilisez JacksonJsonSerde dans la documentation Kafka Streams #51162
