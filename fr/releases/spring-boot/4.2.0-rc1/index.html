spring-boot v4.2.0-RC1

Mineure Publié22 oct. 2026 Sourcespring-projects/spring-boot Anglais original

Cette page est traduite automatiquement. Le texte anglais original fait foi.

botte à ressort v4.2.0-RC1

:star: Nouvelles fonctionnalités

  • Appliquer l'optimisation readAllBytes() aux entrées jar imbriquées dégonflées #52285
  • Améliorez les performances d'Uber Jar en recherchant des classes et des ressources directement dans des jars imbriqués #52246
  • Prise en charge de RABBITMQ_DEFAULT_VHOST dans l'intégration Docker Compose RabbitMQ #51940
  • Prise en charge des mots de passe root aléatoires dans MariaDB et intégration de MySQL Docker Compose #51938
  • Améliorer les performances de tri par configuration automatique #51867
  • Autoriser le migrateur de propriétés à échouer au démarrage de l'application #51855
  • Ajouter une propriété pour activer le mode cache asynchrone Caffeine #51844
  • Vérifiez l'existence des ressources une fois lors de la recherche de fichiers supprimés #51841
  • Évitez d'analyser les URL de fichiers jar imbriqués pour les recherches de ressources mises en cache #51827
  • Prise en charge des bibliothèques de portée fournie lors de l'extraction d'un exécutable war #51372
  • Passer à Ubuntu-resolute-builder comme constructeur par défaut #51249
  • Fournir un rappel pour personnaliser le serveur Tomcat #50259

## :lady_beetle : corrections de bugs

  • JarUrlClassLoader rejette les noms de classes valides depuis #52271 #52284
  • Les ressources contenant des espaces ne peuvent pas être lues à partir des fichiers JAR exécutables après #52246 #52280
  • L'équilibrage de charge gRPC client 'grpc' ne parvient pas à se lier à une NullPointerException lorsqu'aucune stratégie enfant n'est configurée #52269
  • OriginTrackedResource n'implémente pas correctement les égalités #52268
  • OriginTrackedPropertiesLoader supprime les propriétés dont le nom commence par # ou ! #52266
  • Logback ColorConverter analyse inutilement ses options pour chaque événement de journal #52262
  • Les JWT sont rejetés lorsque l'émetteur-uri est vide et que jwk-set-uri est défini #52261
  • Les attributs du manifeste du package sont manquants pour les fichiers JAR imbriqués sans entrées de répertoire #52259
  • La propriété système vide dans TestPropertyValues est effacée au lieu d'être restaurée à sa valeur vide #52209
  • L'arrêt progressif de Tomcat ou Jetty peut rappeler avec REQUESTS_ACTIVE lorsque l'arrêt est appelé immédiatement après shutdownGracefully sur un serveur inactif #52199
  • L'arrêt de NettyWebServer peut se bloquer lorsqu'il est appelé immédiatement après shutdownGracefully #52198
  • Empêcher les propriétés gRPC client de remplacer les personnalisations utilisateur #52194
  • MongoDB ne parvient pas à se connecter lorsque les informations d'identification contiennent un espace #52169
  • L'authentification échoue lorsque le mot de passe configuré dans spring.elasticsearch.uris contient deux points #52167
  • La journalisation peut être perdue lorsqu'un contexte est mis en pause par le framework de contexte de test #52089
  • Les fractions de seconde ne sont pas gérées correctement lors de la configuration des durées de configuration du service gRPC #52087
  • La prise en charge de Docker Compose pour MongoDB ne parvient pas à se connecter lorsque les informations d'identification contiennent un caractère nécessitant un codage d'URL #52085
  • Jersey n'utilise pas le point de terminaison ObjectMapper lorsque Actuator s'exécute sur un port distinct #51983
  • Les descriptions des propriétés de configuration peuvent être perdues lors de la construction incrémentielle avec Gradle #51926
  • BasicJsonParser gère mal les caractères d'échappement dans les listes et cartes imbriquées #51909
  • La conversion de la valeur de semaine zéro échoue avec l'exception « intValue ne peut pas être extrait de WEEKS » #51895
  • L'application ne démarre pas lors de l'utilisation de DevTools et de la configuration manuelle de JDBC ou R2DBC sans spring-boot-jdbc ou spring-boot-r2dbc #51891
  • La prise en charge de Docker Compose ne reconnaît pas correctement MARIADB_ALLOW_EMPTY_PASSWORD au lieu de MARIADB_ALLOW_EMPTY_ROOT_PASSWORD #51889
  • La personnalisation du codec JSON de sérialisation Kotlinx automatiquement configurée n'est pas appliquée #51878
  • Avertissement inévitable lors de l'utilisation d'ubuntu-resolute-builder avec une petite image d'exécution #51851

## :notebook_with_decorative_cover : Documentation

  • Correction d'une faute de frappe dans la documentation de test du gRPC #52188
  • Correction d'un exemple Gradle pour les serveurs gRPC basés sur des servlets #52086
  • Correction des noms de propriétés des points de terminaison de l'actionneur dans Javadoc #51887
  • Documenter les limitations d'InetAddressFilter par rapport aux serveurs proxy #51864
