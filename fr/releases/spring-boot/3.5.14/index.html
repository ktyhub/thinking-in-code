botte à ressort v3.5.14

## :lady_beetle : corrections de bugs

  • ApplicationPidFileWriter ne gère pas correctement les liens symboliques #50173
  • RandomValuePropertySource ne convient pas aux secrets #50172
  • La configuration automatique de Cassandra configure mal CqlSessionBuilder #50171
  • ApplicationTemp ne gère pas correctement les liens symboliques #50170
  • Remote DevTools effectue une comparaison incorrecte #50169
  • spring.rabbitmq.ssl.verify-hostname est appliqué de manière incohérente #50168
  • EnversRevisionRepositoriesRegistrar devrait réutiliser @EnableEnversRepositories plutôt que de configurer son homologue JPA #50035
  • Les annotations comme @Ssl ne fonctionnent pas sur les méthodes @Bean lors de l'utilisation de @ServiceConnection #50033
  • Les valeurs entières sont ignorées lors de la configuration des valeurs attendues min et max et des limites SLO pour un compteur récapitulatif de distribution #50021
  • Le point de terminaison des liens WebFlux Cloud Foundry inclut la chaîne de requête de la demande reçue dans les liens résolus #50008
  • Réponse 500 du point de terminaison d'environnement lorsque le modèle fourni n'est pas valide #49942
  • La méthode HTTP est perdue lors de la configuration des exclusions dans EndpointRequest #49885
  • La prise en charge de Docker Compose ne fonctionne pas avec l'image Apache/Artemis #49865
  • Honorez HttpMethod pour les chemins de points de terminaison supplémentaires réactifs #49864
  • La prise en charge de Docker Compose ne fonctionne pas avec l'image Apache/activemq #49863
  • Les importations sur une classe de test conteneur sont ignorées lorsqu'une classe imbriquée a des importations #49860

## :notebook_with_decorative_cover : Documentation

  • Le lien vers la section observabilité de la documentation Lettuce est rompu #50092
  • Javadoc pour StaticResourceLocation.FAVICON ne décrit pas l'emplacement des icônes #50083
  • Il manque un exemple Kotlin à MySamlRelyingPartyConfiguration #50023
  • Valeur par défaut incorrecte pour management.httpexchanges.recording.include dans les métadonnées de configuration #50010
  • Lien vers la documentation du Kubernetes lors de la discussion des sondes de démarrage #50007
  • Mettre à jour la documentation pour encourager les fondamentaux de Java pour les débutants qui préfèrent apprendre de cette façon #49895
  • Préciser que les valeurs par défaut des propriétés de configuration ne sont pas disponibles via l'environnement #49835
