spring-boot v4.2.0-RC2

Mineure Publié5 nov. 2026 Sourcespring-projects/spring-boot Anglais original

Cette page est traduite automatiquement. Le texte anglais original fait foi.

botte à ressort v4.2.0-RC2

:star: Nouvelles fonctionnalités

  • Supprimer la prise en charge du rechargement SSL LDAP #52365
  • Ajout de la prise en charge de X-Forwarded-Prefix avec le Reactor Netty #52316

## :lady_beetle : corrections de bugs

  • La configuration de management.observations.conventions sur open-telemetry n'active aucune des conventions sémantiques #52619
  • PushGatewayTaskScheduler n'arrête pas correctement le planificateur de tâches lorsque le contexte est fermé #52591
  • ClearCachesApplicationListener ne trouve pas les méthodes clearCache() héritées #52589
  • MongoTransactionManager créé par BatchDataMongoAutoConfiguration n'est pas personnalisé par TransactionManagerCustomizers #52572
  • Le processeur de configuration ne gère pas les types connus lorsqu'ils sont pleinement qualifiés #52571
  • Un hôte AMQP Rabbit non valide est signalé avec une valeur incorrecte #52568
  • Évitez les débordements prématurés lors de la conversion des durées en microsecondes #52561
  • La liaison d'une valeur à partir d'une arborescence de configuration échoue après qu'une collection du même type d'élément a été liée à partir de la même arborescence de configuration #52559
  • JsonWriter écrit un JSON non valide lorsque usingPairs est utilisé avec un membre nommé #52549
  • La journalisation structurée Logback GELF écrit un short_message nul lorsque le message de journal est nul #52547
  • KafkaTransactionManager configuré automatiquement n'est pas personnalisé par TransactionManagerCustomizers #52542
  • Les calques personnalisés du plugin Gradle incluent le contenu exclu au lieu de l'exclure #52540
  • Les adresses RabbitMQ sans port utilisent le port AMQP lorsque SSL est activé #52538
  • BasicJsonParser ne décode pas les séquences d'échappement \b, \f, \n, \r, \t et \uXXXX #52534
  • NestedJarFile.getComment() échoue avec une EOFException lorsque le pot n'a pas de commentaire #52513
  • Le thread dump en texte brut signale les threads dans Object.wait() comme étant garés sur Java 19+ #52511
  • Lors de l'utilisation à la fois de spring-boot-amqp-rabbitmq et de spring-boot-rabbitmq, les informations sur l'état de santé de ce dernier sont perdues #52506
  • Les échecs d'analyse JSON ne produisent plus d'exceptions DockerOutputParseExceptions #52500
  • La journalisation structurée ECS écrit des objets service et service.node vides #52497
  • ConfigurationMetadataAnnotationProcessor produit une sortie non répétable si plusieurs points de terminaison partagent le même ID #52494
  • L'arrêt progressif n'attend pas les requêtes actives après un redémarrage de Tomcat ou Jetty #52490
  • RabbitMQ utilise le mauvais port par défaut lorsqu'un bundle SSL est configuré #52488
  • R2dbcTransactionManager automatiquement configuré n'est pas personnalisé par TransactionManagerCustomizers #52485
  • JsonWriter écrit NaN et les valeurs infinies comme JSON invalide #52483
  • ZipEndOfCentralDirectoryRecord trouve la signature de l'enregistrement dans le commentaire zip #52481
  • La prise en charge de LLdap Docker Compose ne parvient pas à se connecter lorsque LLDAP_LDAP_USER_DN est configuré #52475
  • ZipContent.Entry hasNameStartingWith ignore le décalage des noms de répertoires imbriqués virtualisés #52464
  • ZipContent ne peut pas ouvrir un zip contenant des données après la fin de l'enregistrement du répertoire central #52461
  • ZipContent lit le commentaire zip à partir de la mauvaise position lorsque l'archive a des données préfixées #52459
  • La configuration de l'enregistreur racine ne peut pas être récupérée et n'a pas de niveau configuré avec Log4j2 #52455
  • L'intégration Docker Compose OTLP nécessite que les ports gRPC et HTTP soient exposés lorsque seul HTTP est utilisé #52451
  • La configuration automatique Spring Batch JDBC se connecte à la base de données au démarrage pour détecter son type, sans aucun moyen de la configurer #52449
  • Les caches OnAvailableEndpointCondition conservent les contextes d'application fermés via leur environnement #52447
  • DataSourceTransactionManagerAutoConfiguration utilise une ancienne propriété qui n'est plus prise en charge pour contrôler la traduction des exceptions #52445
  • La nouvelle propriété 'maxLocaleCount' de Tomcat ne peut pas être facilement configurée #52443
  • DevTools divulgue un thread File Watcher pour chaque échec de redémarrage #52441
  • Les chiffrements de bundle SSL et les protocoles activés sont parfois ignorés silencieusement lorsque le composant sous-jacent ne prend pas en charge leur configuration #52438
  • AMQP 1.0 ne doit définir aucun identifiant pour utiliser ANONYMOUS par défaut #52435
  • Port RabbitMQ AMQP 1.0 par défaut sur 5671 lorsqu'un bundle SSL est configuré #52432
  • Hikari n'enregistre pas ses propres MBeans lorsque la récupération de connexion paresseuse est utilisée avec JMX activé #52426
  • Les chiffrements de bundle SSL et les protocoles activés sont ignorés par RabbitMQ clients #52416
  • Les chiffrements de bundle SSL et les protocoles activés sont ignorés par Kafka clients #52413
  • Le point de terminaison d'intégrité échoue avec une erreur interne pour un chemin avec un segment intermédiaire inconnu #52411
  • L'application servlet ne démarre pas lorsque les propriétés du serveur de ressources JWT et opaque sont configurées #52409
  • Les coureurs peuvent être invoqués après la fermeture du contexte d'application lors du démarrage #52408
  • La liaison simultanée de beans @ConfigurationProperties peut corrompre les BoundConfigurationProperties et faire échouer la liaison #52406
  • JavaMailSender configuré automatiquement n'applique pas les chiffrements de bundle SSL ni les protocoles activés #52404
  • La racine du chemin de classe ne peut pas être résolue dans les fichiers JAR exécutables après #52246 #52402
  • La sérialisation Kotlin ne recule pas lorsque JSON-B est le seul convertisseur JSON #52389
  • Les paramètres matriciels déforment les valeurs transmises à un sélecteur de correspondance avec tous les restes lors de l'utilisation de WebMvc ou WebFlux #52378
  • Les bundles SSL de nom de serveur avec des noms de serveur en majuscules ne sont pas utilisés avec Netty #52364
  • Les emplacements des données de configuration avec des crochets dans leur chemin ne sont pas chargés correctement #52360
  • La fermeture du contexte peut se bloquer lorsque la suspension du pool Hikari est activée #52359
  • OriginTrackedPropertiesLoader supprime la ligne suivant un commentaire qui se termine par une barre oblique inverse #52357
  • La fermeture d'un contexte enfant arrête le thread keep-alive #52344
  • Les copies MimeMappings de DEFAULT sont vides et égales est asymétrique #52342
  • StringHttpMessageConverter ne peut pas être remplacé par un personnalisateur de convertisseurs de messages HTTP #52336
  • ConfigurationPropertyName accepte de manière incorrecte un crochet ouvrant à la fin d'un nom #52334
  • Les répertoires créés par l'extraction des outils jarmode rendent les couches Docker non reproductibles #52330
  • Les propriétés d'actualisation du cluster de laitue sont ignorées lorsque le cluster n'est pas configuré à l'aide des propriétés spring.data.redis.cluster #52328
  • BasicJsonParser gère mal les accolades dans les valeurs de chaîne #52326
  • MessageSourceMessageInterpolator gère mal les accolades fermantes déséquilibrées #52324
  • BasicJsonParser n'ignore pas les espaces autour des éléments d'une liste #52318
  • ZipContent ne gère pas les noms de répertoires imbriqués avec des caractères multi-octets #52315
  • RabbitMQ AMQP 1.0 ne doit pas définir d'échange vide par défaut #52305
  • spring.data.redis.database est ignoré lors de la configuration des nœuds maître/réplique #52189

  • Les métadonnées de certaines propriétés activées par les indicateurs de santé sont manquantes #52422
  • Documenter que les tests clients ne sont pas observés #52418
  • Correction des conseils de métadonnées de configuration obsolètes #52386
  • Correction d'une xréf cassée dans la documentation de test #52384
