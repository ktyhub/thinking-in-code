Scrapling v0.3

Scrapling v0.3.0 Release Note

🎉 Version majeure — Refonte complète de l'architecture Scrapling v0.3 représente la mise à jour la plus importante de l'histoire du projet, avec une réécriture architecturale complète, des améliorations considérables des performances et de nouvelles fonctionnalités puissantes, notamment l'intégration de l'IA et les capacités interactives du shell Web Scraping. Cette version inclut plusieurs modifications majeures ; veuillez examiner attentivement les release note.

🚀 Nouvelles fonctionnalités majeures

Architecture basée sur les sessions

  • Nouvelles classes de session : réécriture complète introduisant la prise en charge des sessions persistantes
    • FetcherSession - Requêtes HTTP avec gestion d'état persistante qui fonctionne à la fois avec le code de synchronisation et asynchrone
    • DynamicSession/AsyncDynamicSession - Automatisation du navigateur tout en gardant le navigateur ouvert jusqu'à la fin
    • StealthySession/AsyncStealthySession - Navigation furtive tout en gardant le navigateur ouvert jusqu'à la fin
  • Gestion asynchrone des onglets du navigateur : un nouveau pool d'onglets via l'argument max_pages qui fait pivoter les onglets du navigateur pour les récupérations simultanées du navigateur.
  • Sessions simultanées : exécutez plusieurs sessions isolées simultanément Reportez-vous à la section Fetching sur le site Web pour plus de détails.

De nombreuses nouvelles capacités furtives/anti-bots

  • 🤖 Cloudflare Solver : [Résolution automatique des défis Cloudflare Turnstile] (https://scrapling.readthedocs.io/en/latest/fetching/stealthy/#cloudflare-protection-bypass) dans StealthyFetcher et ses classes de session
  • Usuration d'identité d'empreinte digitale de navigateur : imitez les empreintes digitales TLS de vrais navigateurs, les en-têtes de navigateur correspondant à la version, la prise en charge HTTP/3 et bien plus encore avec la toute nouvelle classe Fetcher
  • Mode furtif amélioré : Le mode furtif de DynamicFetcher et de ses classes de session est désormais plus robuste et fiable (AKA PlayWrightFetcher)

Intégration IA et serveur MCP

  • Serveur MCP intégré : serveur de protocole de contexte de modèle pour le web scraping assisté par IA
  • 6 outils puissants : get, bulk_get, fetch, bulk_fetch, stealthy_fetch, bulk_stealthy_fetch
  • Extraction de contenu intelligente : convertissez des pages/éléments Web en Markdown, HTML ou extrayez une version propre du contenu texte
  • Prise en charge du sélecteur CSS : utilisez le moteur Scrapling pour cibler des éléments spécifiques avec précision avant de transmettre le contenu à l'IA
  • Anti-Bot Bypass : Gérez le tourniquet Cloudflare et d'autres protections
  • Support proxy : utilisez des proxys pour l'anonymat et le ciblage géographique
  • Ussuration d'identité de navigateur : imitez de vrais navigateurs avec les empreintes digitales TLS, de vrais en-têtes de navigateur correspondant à cette version, et bien plus encore.
  • Traitement parallèle : supprimez plusieurs URL simultanément pour plus d'efficacité
  • et plus...

Nouveau shell Web interactif Scraping

  • Un nouveau shell : shell IPython personnalisé avec de nombreux raccourcis intégrés intelligents comme get, post, put, delete, fetch et stealthy_fetch
  • Smart Page Management : Nouvelles commandes page et pages pour stocker automatiquement la page actuelle et l'historique de toutes les requêtes effectuées via le shell
  • Intégration Curl : convertissez les commandes curl du navigateur DevTools avec les fonctions uncurl et curl2fetcher en requêtes Fetcher
  • et plus...

Scraper depuis le terminal sans programmation

  • Nouvelles commandes d'extraction : scraping basé sur un terminal sans programmation
    • scrapling extract get/post/put/delete - Requêtes HTTP simples
    • scrapling extract fetch - Contenu dynamique scraping
    • scrapling extract stealthy-fetch - Contournement anti-bot
  • Télécharge les pages Web et enregistre leur contenu dans des fichiers.
  • Convertit le HTML en formats lisibles comme Markdown, le conserve au format HTML ou extrait simplement le contenu textuel de la page.
  • Prend en charge les sélecteurs CSS personnalisés pour extraire des parties spécifiques de la page.
  • Gère les requêtes HTTP et la récupération via les navigateurs.
  • Hautement personnalisable avec des en-têtes personnalisés, des cookies, des proxys et le reste des options. Presque toutes les options disponibles via le code sont également accessibles via le terminal.
  • et plus...

🔧 Améliorations techniques

Améliorations des performances

  • Fetcher est désormais 4 fois plus rapide - Oui, vous avez bien lu !
  • DynamicFetcher est désormais ~60% plus rapide - Une version beaucoup plus rapide selon votre configuration (notamment le mode furtif)
  • StealthyFetcher est désormais 20 à 30 % plus rapide - Utilisation de la nouvelle structure et commence à utiliser notre implémentation au lieu de l'interface Camoufox Python
  • Plus de 50 % de gains de vitesse combinés dans les méthodes de sélection de base (find_by_text, find_similar, find_by_regex, relocate, etc.) 🚀
  • ~10 % d'augmentation de la vitesse des premières méthodes CSS/XPath - css_first et xpath_first sont désormais plus rapides que css et xpath
  • Méthode get_all_text() 40 % plus rapide pour l'extraction de contenu
  • Amélioration de la vitesse de 20 % lors de la relocalisation adaptative des éléments
  • Optimisation des propriétés de navigation — Des propriétés telles que next, previous, below_elements et bien d'autres sont désormais nettement plus rapides
  • Opérations de nettoyage de texte 5 fois plus rapides
  • Améliorations de l'efficacité de la mémoire avec des importations optimisées et une réduction des frais généraux
  • ⚡ Importations ultra-rapides : temps de démarrage réduit avec chargement de module optimisé
  • Meilleurs benchmarks : toutes les améliorations de vitesse obtenues par Scrapling l'ont rendu beaucoup plus rapide qu'avant, par rapport aux autres bibliothèques (1775x plus rapide que BeautifulSoup et 5,1x plus rapide qu'AutoScraper, vérifiez benchmarks)

Architecture/Qualité du Code et Qualité de vie

  • Contexte persistant : tous les récupérateurs basés sur un navigateur utilisent désormais le contexte persistant par défaut. (Résout également le problème 64)
  • Utilisation de msgspec pour valider très rapidement tous les récupérateurs basés sur le navigateur avant d'exécuter les requêtes, il est donc désormais plus facile de déboguer les erreurs.
  • Tous les cookies renvoyés par les récupérateurs correspondent désormais au format accepté par le même récupérateur. Vous pouvez ainsi récupérer les cookies et les transmettre à nouveau à tous les récupérateurs et à leurs classes de session.
  • Peluchage et formatage plus rapides grâce à la migration vers ruff
  • Modern Build System : migré de setup.py vers pyproject.toml 📦
  • De meilleures actions et flux de travail GitHub pour un développement et des tests plus fluides
  • 🎨 Conseils de type améliorés : couverture complète des types avec les normes modernes Python pour une meilleure prise en charge et une meilleure fiabilité de l'IDE
  • Cleaner Codebase : suppression du code mort et fonctions de base optimisées 🧹
  • 🚀 Compatibilité descendante : ajout de raccourcis pour maintenir la compatibilité avec l'ancien code

Modifications radicales

Version minimale du Python

  • Python 3.10+ requis : suppression de la prise en charge de Python 3.9 et versions antérieures

Dénomination des classes et des méthodes

Ces changements de nom visent à améliorer la clarté et la cohérence, en particulier pour les nouveaux utilisateurs.

  • Adaptor → Selector : classe d'analyse de base renommée (mais peut toujours être importée en tant que Adaptor pour une compatibilité ascendante)
  • Adaptors → Selectors : classe de collection renommée (mais peut toujours être importée sous le nom Adaptors pour une compatibilité ascendante)
  • auto_match → adaptive : paramètre renommé dans toutes les méthodes
  • adaptor_arguments → selector_config : Paramètre de configuration renommé
  • automatch_domain → adaptive_domain : Paramètre de domaine renommé
  • additional_arguments → additional_args : Nom de paramètre raccourci
  • ⚠️ text/body → content : le paramètre du constructeur du sélecteur accepte désormais les formats str et bytes
  • PlayWrightFetcher → DynamicFetcher : classe d'automatisation du navigateur renommée (mais peut toujours être importée en tant que PlayWrightFetcher pour une compatibilité ascendante)
  • DynamicFetcher n'a plus la logique/les arguments NSTBrowser puisqu'il est inutile de quitter cette logique maintenant de toute façon.
  • L'argument sans tête de StealthyFetcher ne peut plus accepter « virtuel » comme argument puisque nous n'utilisons pas la bibliothèque de Camoufox pour le moment autre que pour obtenir le chemin d'installation du navigateur et le reste des options de lancement

🐛 Corrections de bugs

  • Correction du comptage des enfants imbriqués dans les balises ignorées pour get_all_text (#61)
  • Correction du problème d'installation dû à des espaces dans le chemin de l'exécutable de Python (#57)
  • Problèmes de threading résolus dans le stockage avec gestion de la récursion lorsque la fonctionnalité adaptative est activée
  • Correction de problèmes de priorité des arguments utilisant le modèle Sentinel dans FetcherSession
  • Gestion du type de proxy résolue dans StealthyFetcher
  • Correction des conflits d'arguments referer et google_search
  • Correction de problèmes d'injection de scripts furtifs asynchrones 🙏 Un merci spécial à notre [communauté Discord] (https://discord.gg/EMgGbDceNQ) pour tous les tests continus, commentaires et contributions au cours des quatre derniers mois
