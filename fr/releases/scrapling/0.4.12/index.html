Scrapling v0.4.12

Une version visant à rendre vos robots plus intelligents quant aux sites Web qu'ils explorent

[!NOTE] Suivez-nous sur X pour des trucs et astuces quotidiens

🚀 Nouveautés et changements dans la qualité de vie

  • Les araignées peuvent désormais régler leur propre vitesse avec AutoThrottle. Au lieu de deviner un download_delay qui est trop lent ou qui vous fait bannir, l'araignée mesure la rapidité avec laquelle chaque site Web répond et ajuste le délai de chaque domaine de manière indépendante. Lorsqu'un site Web commence à vous bloquer ou à vous limiter, il double le délai (ou attend exactement ce que demande l'en-tête Retry-After) jusqu'à ce que cela s'arrête, puis accélère. Votre download_delay et vos éventuels robots.txt Crawl-delay sont toujours respectés au minimum. (Consultez les docs)

    class MySpider(Spider):
    name = "adaptive"
    start_urls = ["https://example.com"]
    autothrottle_enabled = True
    autothrottle_start_delay = 2.0
    autothrottle_max_delay = 30.0
    autothrottle_block_backoff = True

  • Exportez vos résultats au format CSV et XML, à côté des exportateurs JSON/JSONL que vous aviez déjà. Les éléments qui ne partagent pas tous les mêmes clés sont toujours exportés sans rien perdre, et les valeurs imbriquées sont écrites sous la forme JSON. (Consultez les docs)

    result = MySpider().start()
result.items.to_csv("products.csv")
result.items.to_xml("products.xml")

  • Le serveur MCP peut désormais exiger une authentification, afin que vous puissiez l'exposer en toute sécurité au lieu de le conserver sur votre propre ordinateur. Toute demande sans jeton est rejetée et vous pouvez également restreindre les noms d'hôte auxquels le serveur répond. (Consultez les docs)

    scrapling mcp --http --auth-token "$(openssl rand -hex 32)"

  • Les navigateurs acceptent désormais les URL CDP via HTTP, pas seulement celles WebSocket. Ainsi, à côté des fournisseurs de navigateurs gérés pour les points de terminaison wss://, vous pouvez désormais pointer n'importe quel outil de récupération de navigateur ou session MCP vers un Chrome que vous avez vous-même démarré avec --remote-debugging-port=9222.

  • Les images Docker publiées sont désormais étiquetées avec leur version finale au lieu de seulement latest, afin que vous puissiez épingler la version exacte que vous souhaitez, par @JanRK dans #384.

🐛 Corrections de bugs

  • Correction des réponses mises en cache perdant tous leurs cookies lorsque la réponse provenait d'un moteur de navigateur, qui interrompait silencieusement toute session ou logique d'authentification s'appuyant sur elles lors de l'utilisation du mode de développement des araignées, par @amitvijapur dans #379. (Corrections #376)

  • Correction de StealthyFetcher forçant les paramètres régionaux en-US sur chaque navigateur au lieu de suivre ceux de votre système, ce qui faisait que les sites Web voyaient une inadéquation entre vos paramètres régionaux et votre adresse IP et vous traitaient comme suspect, comme Google répondant avec 429. (Corrections #381)

  • Correction d'un message d'erreur trompeur dans le système de stockage et suppression d'un appel mort laissé après les insertions, par @fix2015 dans #377.

Performances

  • get_all_text() est désormais O(nodes) au lieu de remonter les ancêtres de chaque nœud de texte, ce qui le rend environ 5 à 6 fois plus rapide sur les pages profondément imbriquées, par @yetval dans #378.
