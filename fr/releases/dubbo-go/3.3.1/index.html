dubbo-go v3.3.1

##3.3.1

Résumé

Cette version introduit des améliorations majeures du protocole Triple, des améliorations des centres de configuration et de registre (Nacos, Apollo, Zookeeper) et une refactorisation approfondie des modules de base pour améliorer la stabilité et les performances. Cette version met également à jour la compatibilité avec Go 1.24.

Nouvelles fonctionnalités

  • Prise en charge des caractères génériques de groupe et de version pour une correspondance exacte de l'interface. #3080
  • Prise en charge de l'injection de dubbo.tag dans les métadonnées du service. #3069
  • Exposer les API liés au routeur. #3066
  • Mettre à jour la prise en charge de la version Go vers Go 1.24 et supprimer l'utilisation obsolète de rand.seed. #3046
  • Introduire un outil de formatage des importations et l'intégrer dans les contrôles CI. #3019
  • Ajouter une capacité de rechargement à chaud de la configuration. #2992
  • Support exécutant simultanément des serveurs HTTP/2 et HTTP/3. #2972
  • Ajouter l'option WithInterface pour l'initialisation de client. #2946
  • Ajouter la prise en charge des outils pour générer la documentation OpenAPI pour les services Triple. #2951
  • Ajouter la prise en charge expérimentale de HTTP/3 pour le protocole Triple. #2916
  • Refonte des TLS API et ajout d'une nouvelle configuration TLS pour le protocole triple. #2852 #2891
  • Support Mode non-IDL dans la nouvelle implémentation Triple. #2858
  • Ajouter la prise en charge d'Apollo en tant que centre de configuration. #2857
  • Prise en charge du décodage du Hessian à partir du flux pour améliorer les performances de la transmission de gros paquets. #2841
  • Ajouter la prise en charge des appels génériques pour le nouveau protocole Triple. #2818

Corrections de bugs

  • Correction Échec de désenregistrement de Nacos lors de l'arrêt. #3108
  • Empêcher la panique lors de la récupération des métadonnées des fournisseurs Java. #3092
  • Ajustez le niveau de journalisation d'Erreur à Avertir lorsque les paramètres d'application sont vides dans Tag Router. #3035
  • Correction déréférencement de pointeur nul dans plusieurs modules. #3071
  • Résoudre la perte du paramètre URL dans la méthode SetParams. #3022
  • Gérer les échecs de création d'extensions de cluster au lieu de paniquer. #3021 #3064
  • Correction des chemins de rotation incorrects des journaux pour éviter la perte de fichiers. #3014
  • Corriger la logique de décrémentation du compteur en cas d'erreur. #3013
  • Correction des échecs de récupération de métadonnées causés par des erreurs meta-v et des paramètres de stockage distant vides. #2952 #2953
  • Correction du chargement de la configuration du fournisseur dans dubbo.Load(). #2941
  • Correction des problèmes de transmission des pièces jointes du serveur vers client dans le protocole triple. #2928 #2854
  • Correction La configuration du poids Nacos ne prend pas effet. #2937
  • Réduire la latence dans la perception du nœud Zookeeper client. #2930
  • Correction des erreurs de lecture du préfixe EOF dans la couche de communication. #2912
  • Réparer les problèmes d'écrasement de l'instance Nacos. #2882
  • Résoudre les problèmes de boucle logique infinie. #2879
  • Réparer les problèmes d'abonnement Nacos où les services nouvellement enregistrés n'étaient pas détectés. #2859
  • Correction Logique de configuration de l'option de poids Nacos. #2843
  • Correction de la propagation des erreurs dans marshalRequest. #2817
  • Correction Gestion des erreurs de pièce jointe de contexte dans les appels triple streaming. #2810

Améliorations du code

  • Refactor : Découplage de configuration. Dépendances découplées du package config pour résoudre les dépendances circulaires entre les modules de registre, de filtre et TLS.
  • Optimisez les performances en précompilant des modèles d'expressions régulières. #3067
  • Améliorez le RoundRobin pondéré en ajoutant le champ lastUpdate au stockage d'état. #3053
  • Correction de plusieurs importations de packages dans la génération de code triple. #3052
  • Résoudre les fuites de mémoire liées à la gestion des goroutines, aux descripteurs de fichiers et aux caches d'extension. #3023
  • Module enregistreur Refactor et ajout de tests unitaires complets. #2838 #2993
  • Réécrire Makefile pour améliorer la cohérence de la construction et l'expérience des développeurs. #2975
  • Utilisez errgroup pour améliorer la gestion des erreurs lors d'un arrêt progressif. #2973
  • Remplacer les opérations CAS obsolètes par CompareAndSwap. #2962
  • Harden Triple gestion des erreurs openServer pour les erreurs de configuration. #2945
  • Ajouter un contrôle de délai d'attente pour un arrêt progressif dans le protocole Triple. #2943
  • Migrer interface{} vers any dans toute la base de code pour la compatibilité Go 1.18+. #2848

Observabilité

  • Ajouter la journalisation pour le cycle de vie de l'enregistrement du service. #3043
  • Aligner les noms des étendues de trace avec les spécifications OpenTelemetry. #3041
  • Ajouter l'option Insecure à la configuration de traçage. #3028
  • Mise à niveau des dépendances OpenTelemetry vers v1.21.0. #2971

Documentation et CI

  • Ajouter la commande make check-fmt au pipeline CI. #3055
  • Mettre à jour les informations de contact README et corriger les liens invalides dans README_CN. #3020
  • Intégrer le formateur d'importations et les vérifications d'en-tête de licence dans CI. #2961 #2957
  • Résoudre divers faux positifs SonarQube/SonarCloud et avertissements de robots IA. #2902
