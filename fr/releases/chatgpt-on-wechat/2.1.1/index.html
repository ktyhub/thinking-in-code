🧬 Auto-évolution

CowAgent introduit Self-Evolution, permettant à l'agent d'aller au-delà d'une seule tâche et de continuer à s'améliorer grâce à une collaboration quotidienne avec vous :

  • Révision automatique après inactivité : une fois qu'une conversation reste inactive, l'agent l'examine en arrière-plan pour résoudre les problèmes liés à une compétence exposée en cours d'utilisation, créer de nouvelles compétences réutilisables, assurer le suivi des tâches inachevées et enregistrer des informations importantes dans la mémoire et la base de connaissances.
  • Silencieux par défaut, notifier à la demande : il signale ce qu'il a modifié uniquement lorsqu'il a réellement effectué une modification, et reste silencieux dans le cas contraire.
  • Sûr et réversible : Chaque révision est préalablement sauvegardée et peut être annulée à tout moment. Les compétences intégrées sont protégées et toutes les lectures et écritures restent dans l'espace de travail

Activé par défaut pour les nouvelles installations. Les utilisateurs existants peuvent l'activer avec un seul click dans la console Web sous Paramètres → Configuration de l'agent.

Documentation : [Auto-évolution] (https://docs.cowagent.ai/memory/self-evolution)

💬 Mises à niveau de la console Web

L'expérience de chat de la console Web bénéficie de plusieurs améliorations :

  • Gestion des messages : modifiez, supprimez et régénérez les messages des utilisateurs et des robots ; les blocs de code incluent désormais des étiquettes de langue et un bouton de copie one-click
  • Sessions parallèles : exécutez plusieurs sessions en même temps sans interférence, avec une reprise automatique de la diffusion en direct lorsque vous revenez à une session.
  • Affinements : faites glisser et déposez des fichiers n'importe où dans la vue de discussion ; passer automatiquement à une session frère après avoir supprimé la session active

Merci @core-power (#2865)

🧩 Améliorations MCP multiplateformes

  • Correction de compatibilité Windows : correction de l'échec de la communication stdio sous Windows et rendu le délai d'attente du serveur configurable via mcp.json
  • Appels simultanés : les transports sse et streamable-http prennent désormais en charge les appels simultanés entre les sessions pour des réponses multi-outils plus rapides

Merci @xliu123321 (#2859)

Documentation : Outils MCP

🤖 Nouveaux modèles et améliorations

  • MiniMax-M3 : Ajouté et défini comme modèle par défaut, la série M2.7 étant conservée en option. Merci @octo-patch (#2855)
  • Qwen3.7-plus : Ajout de la prise en charge des conversations multimodales
  • Modèle ASR sélectionnable : La console Web peut désormais sélectionner et conserver le modèle ASR (reconnaissance vocale). Merci @nightwhite (#2857)
  • Menu d'installation simplifié : Le script d'installation en une ligne rationalise le menu du modèle et ajoute l'option Xiaomi MiMo

Documentation : Présentation des modèles

🛠 Améliorations et correctifs

  • Support Python 3.13 : Correction de la compatibilité d'installation et des dépendances sur Python 3.13
  • Internationalisation : La liste des chaînes est désormais classée par langue d'interface ; affiné le repli automatique de la langue en mode auto
  • Annulation plus fiable : Correction des cas où une réponse en streaming ne pouvait pas être interrompue
  • CLI : cow status affiche désormais le chemin du projet actuel
  • Sécurité de déploiement renforcée : le bloc du fichier d'informations d'identification est limité à ~/.cow/.env afin que les autres répertoires ne soient plus affectés (Merci @orbisai0security #2863) ; le compte officiel WeChat rejette désormais les demandes de webhook lorsque wechatmp_token est vide
  • Plugin du tableau des tâches de groupe : Ajout de la source du plugin du tableau des tâches de groupe. Merci @Wyh-max-star (#2853)

📦 Mise à niveau

Les déploiements de code source peuvent exécuter cow update pour une mise à niveau d'un click, ou extraire le dernier code et redémarrer manuellement. Consultez le [Guide de mise à niveau] (https://docs.cowagent.ai/guide/upgrade) pour plus de détails.
