printemps-ai-alibaba v1.0.0.2

Nous sommes ravis d'annoncer la sortie de Spring AI Alibaba 1.0.0.2, la première version GA ! Construit sur Spring AI et profondément intégré à Bailian, Spring AI Alibaba prend en charge le développement d'applications ChatBot, Workflow et multi-agents.

Principales fonctionnalités

1. Intégration complète du framework

  • Intégration avec Alibaba Cloud : connectez-vous de manière transparente aux services Alibaba, y compris le Dashscope de Bailian, prenant en charge divers modèles d'IA grand public tels que Qwen et Deepseek.

2. Framework multi-agents

  • Framework multi-agent basé sur des graphiques : inspiré de Langgraph, Spring AI Alibaba Graph permet de créer des flux de travail et des applications multi-agents sans effort.

3. Solutions d'agents IA adaptées aux entreprises

  • Registre Nacos MCP
    • Découverte MCP distribuée et équilibre de charge
    • Proxy dynamique API vers MCP
  • NL2SQL pour transformer des requêtes en langage naturel en instructions SQL.
  • Observabilité

Expérience du développeur

Guide de démarrage rapide

Démarrez votre première application d'IA avec Spring AI Alibaba en ajoutant la dépendance suivante à votre projet Spring Boot :

<dependencyManagement>
    <dependencies>
        <dependency>
            <groupId>com.alibaba.cloud.ai</groupId>
            <artifactId>spring-ai-alibaba-bom</artifactId>
            <version>1.0.0.2</version>
            <type>pom</type>
            <scope>import</scope>
        </dependency>
    </dependencies>
</dependencyManagement>

<dependencies>
    <dependency>
        <groupId>com.alibaba.cloud.ai</groupId>
        <artifactId>spring-ai-alibaba-starter-dashscope</artifactId>
    </dependency>
</dependencies>

Spring Boot Démarreurs

  • spring-ai-alibaba-starter-dashscope - Adaptation du service de modèle intégré
  • spring-ai-alibaba-graph-core - Composants de base du framework AI Graph
  • spring-ai-alibaba-starter-nl2sql - Composant de conversion du langage naturel vers SQL
  • spring-ai-alibaba-starter-memory - Composant de mémoire de session
  • spring-ai-alibaba-starter-nacos-mcp-client - Nacos MCP client ; version recommandée : Nacos 3.0.1. Pour les utilisateurs du serveur Nacos 2, veuillez utiliser l'ancienne version (spring-ai-alibaba-starter-nacos2-mcp-client).
  • spring-ai-alibaba-starter-nacos-mcp-server - Serveur Nacos MCP ; version recommandée : Nacos 3.0.1. Pour les utilisateurs de Nacos 2 Server, veuillez utiliser l'ancienne version (spring-ai-alibaba-starter-nacos2-mcp-server).
  • spring-ai-alibaba-starter-nacos-prompt - Gestion des invites Nacos
  • spring-ai-alibaba-starter-arms-observation - Observabilité ARMS
  • Composants communautaires
    • spring-ai-alibaba-starter-tool-calling-* - Composant d'appel d'outil
    • spring-ai-alibaba-starter-document-reader-* - Composant de lecture de documents
    • spring-ai-alibaba-starter-vector-store-* - Composant Vector Store

Exemples de projets

La communauté officielle a développé un [exemple Playground] (https://github.com/springaialibaba/spring-ai-alibaba-examples/tree/main/spring-ai-alibaba-playground) qui comprend une interface utilisateur frontale et un backend complets basés sur Spring AI Alibaba. Playground permet aux utilisateurs de découvrir toutes les fonctionnalités de base du framework telles que le chat, l'observabilité, les conversations à plusieurs tours, la génération d'images, la multimodalité, l'appel d'outils, MCP et RAG.

Pour plus de cas d'utilisation, consultez [Référentiel d'exemples Alibaba Spring AI] (https://github.com/springaialibaba/spring-ai-alibaba-examples).
