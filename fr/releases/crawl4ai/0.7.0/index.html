🧠 Adaptive Crawling : l'intelligence grâce à l'apprentissage de modèles

Le problème : Les sites Web changent. Les noms de classe changent. Les identifiants disparaissent. Vos sélecteurs soigneusement conçus s'arrêtent à 3 heures du matin et vous vous réveillez avec des ensembles de données vides et des parties prenantes en colère.

Ma solution : J'ai mis en œuvre un système d'apprentissage adaptatif qui observe les modèles, établit des scores de confiance et ajuste les stratégies d'extraction à la volée. C'est comme avoir un développeur junior qui s'améliore dans son travail à chaque page qu'il gratte.

Approfondissement technique

Le robot d'exploration adaptatif maintient un état persistant pour chaque domaine, en suivant :

  • Taux de réussite des modèles
  • Stabilité du sélecteur dans le temps
  • Variations de la structure du contenu
  • Scores de confiance d'extraction
from crawl4ai import AdaptiveCrawler, AdaptiveConfig, CrawlState

# Initialize with custom learning parameters
config = AdaptiveConfig(
    confidence_threshold=0.7,    # Min confidence to use learned patterns
    max_history=100,            # Remember last 100 crawls per domain
    learning_rate=0.2,          # How quickly to adapt to changes
    patterns_per_page=3,        # Patterns to learn per page type
    extraction_strategy='css'   # 'css' or 'xpath'
)

adaptive_crawler = AdaptiveCrawler(config)

# First crawl - crawler learns the structure
async with AsyncWebCrawler() as crawler:
    result = await crawler.arun(
        "https://news.example.com/article/12345",
        config=CrawlerRunConfig(
            adaptive_config=config,
            extraction_hints={  # Optional hints to speed up learning
                "title": "article h1",
                "content": "article .body-content"
            }
        )
    )
    
    # Crawler identifies and stores patterns
    if result.success:
        state = adaptive_crawler.get_state("news.example.com")
        print(f"Learned {len(state.patterns)} patterns")
        print(f"Confidence: {state.avg_confidence:.2%}")

# Subsequent crawls - uses learned patterns
result2 = await crawler.arun(
    "https://news.example.com/article/67890",
    config=CrawlerRunConfig(adaptive_config=config)
)
# Automatically extracts using learned patterns!

🌊 Défilement virtuel : capture de contenu complète

Le problème : Les applications Web modernes n'affichent que ce qui est visible. Faites défiler vers le bas, un nouveau contenu apparaît, l'ancien contenu disparaît dans le vide. Les robots d'exploration traditionnels capturent cette première fenêtre d'affichage et manquent 90 % du contenu. C'est comme lire seulement la première page de chaque livre.

Ma solution : J'ai créé un support Virtual Scroll qui imite le comportement de navigation humain, capturant le contenu lors de son chargement et le préservant avant l'intervention du ramasse-miettes du navigateur.

Détails de mise en œuvre

from crawl4ai import VirtualScrollConfig

# For social media feeds (Twitter/X style)
twitter_config = VirtualScrollConfig(
    container_selector="[data-testid='primaryColumn']",
    scroll_count=20,                    # Number of scrolls
    scroll_by="container_height",       # Smart scrolling by container size
    wait_after_scroll=1.0,             # Let content load
    capture_method="incremental",       # Capture new content on each scroll
    deduplicate=True                   # Remove duplicate elements
)

# For e-commerce product grids (Instagram style)
grid_config = VirtualScrollConfig(
    container_selector="main .product-grid",
    scroll_count=30,
    scroll_by=800,                     # Fixed pixel scrolling
    wait_after_scroll=1.5,             # Images need time
    stop_on_no_change=True            # Smart stopping
)

# For news feeds with lazy loading
news_config = VirtualScrollConfig(
    container_selector=".article-feed",
    scroll_count=50,
    scroll_by="page_height",           # Viewport-based scrolling
    wait_after_scroll=0.5,
    wait_for_selector=".article-card",  # Wait for specific elements
    timeout=30000                      # Max 30 seconds total
)

# Use it in your crawl
async with AsyncWebCrawler() as crawler:
    result = await crawler.arun(
        "https://twitter.com/trending",
        config=CrawlerRunConfig(
            virtual_scroll_config=twitter_config,
            # Combine with other features
            extraction_strategy=JsonCssExtractionStrategy({
                "tweets": {
                    "selector": "[data-testid='tweet']",
                    "fields": {
                        "text": {"selector": "[data-testid='tweetText']", "type": "text"},
                        "likes": {"selector": "[data-testid='like']", "type": "text"}
                    }
                }
            })
        )
    )
    
    print(f"Captured {len(result.extracted_content['tweets'])} tweets")

Capacités clés :

  • DOM Recycling Awareness : Détecte et gère l'élément virtuel DOM recycling
  • Physique de défilement intelligent : trois modes : hauteur du conteneur, hauteur de la page ou pixels fixes
  • Content Preservation : capture le contenu avant qu'il ne soit détruit
  • Arrêt intelligent : s'arrête lorsqu'aucun nouveau contenu n'apparaît
  • Mémoire efficace : diffuse le contenu au lieu de tout conserver en mémoire

Impact attendu dans le monde réel :

  • Analyse des médias sociaux : capturez des fils de discussion Twitter entiers avec des centaines de réponses, pas seulement le top 10
  • E-commerce Scraping : extrayez plus de 500 produits de catalogues à défilement infini contre 20 à 50 avec les méthodes traditionnelles
  • Agrégation d'actualités : obtenez tous les articles des sites d'actualités modernes, pas seulement le contenu au-dessus de la ligne de flottaison
  • Applications de recherche : extraction complète de données à partir de bases de données académiques à l'aide de la pagination virtuelle

🔗 Aperçu des liens : analyse et notation intelligentes des liens

Le problème : Vous explorez une page et obtenez 200 liens. Lesquels comptent ? Qu'est-ce qui mène au contenu que vous souhaitez réellement ? Les robots d'exploration traditionnels vous obligent à tout suivre ou à créer des filtres complexes.

Ma solution : J'ai mis en place un système de notation à trois niveaux qui analyse les liens comme le ferait un humain, en tenant compte de leur position, de leur contexte et de leur pertinence par rapport à vos objectifs.

Le système de notation à trois niveaux

from crawl4ai import LinkPreviewConfig

# Configure intelligent link analysis
link_config = LinkPreviewConfig(
    # What to analyze
    include_internal=True,
    include_external=True,
    max_links=100,              # Analyze top 100 links
    
    # Relevance scoring
    query="machine learning tutorials",  # Your interest
    score_threshold=0.3,        # Minimum relevance score
    
    # Performance
    concurrent_requests=10,     # Parallel processing
    timeout_per_link=5000,      # 5s per link
    
    # Advanced scoring weights
    scoring_weights={
        "intrinsic": 0.3,       # Link quality indicators
        "contextual": 0.5,      # Relevance to query
        "popularity": 0.2       # Link prominence
    }
)

# Use in your crawl
result = await crawler.arun(
    "https://tech-blog.example.com",
    config=CrawlerRunConfig(
        link_preview_config=link_config,
        score_links=True
    )
)

# Access scored and sorted links
for link in result.links["internal"][:10]:  # Top 10 internal links
    print(f"Score: {link['total_score']:.3f}")
    print(f"  Intrinsic: {link['intrinsic_score']:.1f}/10")  # Position, attributes
    print(f"  Contextual: {link['contextual_score']:.1f}/1")  # Relevance to query
    print(f"  URL: {link['href']}")
    print(f"  Title: {link['head_data']['title']}")
    print(f"  Description: {link['head_data']['meta']['description'][:100]}...")

Composants de notation :

  1. Score intrinsèque (0-10) : basé sur des indicateurs de qualité de lien

    • Position sur la page (navigation, contenu, pied de page)
    • Attributs du lien (rel, titre, noms de classe)
    • Qualité et longueur du texte d'ancrage
    • Structure et profondeur de l'URL

  2. Score contextuel (0-1) : pertinence par rapport à votre requête

    • Similitude sémantique grâce aux intégrations
    • Correspondance des mots clés dans le texte et le titre du lien
    • Analyse de méta description
    • Notation de l'aperçu du contenu

  3. Score total : combinaison pondérée pour le classement final

Impact attendu dans le monde réel :

  • Efficacité de la recherche : trouvez des articles pertinents 10 fois plus rapidement en suivant uniquement les liens ayant obtenu des scores élevés
  • Analyse concurrentielle : identifiez automatiquement les pages importantes sur les sites concurrents
  • Découverte de contenu : créez des robots d'exploration axés sur un sujet qui restent sur la bonne voie
  • Audits SEO : identifiez et priorisez les opportunités de liens internes à forte valeur ajoutée

🎣 Async URL Seeder : découverte automatisée d'URL à grande échelle

Le problème : Vous souhaitez explorer un domaine entier mais ne disposez que de la page d'accueil. Ou pire, vous souhaitez des types de contenu spécifiques sur des milliers de pages. Découverte manuelle d'URL ? C'est un travail pour les machines, pas pour les humains.

Ma solution : J'ai créé Async URL Seeder, un moteur de découverte d'URL turbocompressé qui combine plusieurs sources avec un filtrage intelligent et une évaluation de la pertinence.

Architecture technique

from crawl4ai import AsyncUrlSeeder, SeedingConfig

# Basic discovery - find all product pages
seeder_config = SeedingConfig(
    # Discovery sources
    source="sitemap+cc",        # Sitemap + Common Crawl
    
    # Filtering
    pattern="*/product/*",      # URL pattern matching
    ignore_patterns=["*/reviews/*", "*/questions/*"],
    
    # Validation
    live_check=True,           # Verify URLs are alive
    max_urls=5000,             # Stop at 5000 URLs
    
    # Performance  
    concurrency=100,           # Parallel requests
    hits_per_sec=10           # Rate limiting
)

seeder = AsyncUrlSeeder(seeder_config)
urls = await seeder.discover("https://shop.example.com")

# Advanced: Relevance-based discovery
research_config = SeedingConfig(
    source="crawl+sitemap",    # Deep crawl + sitemap
    pattern="*/blog/*",        # Blog posts only
    
    # Content relevance
    extract_head=True,         # Get meta tags
    query="quantum computing tutorials",
    scoring_method="bm25",     # Or "semantic" (coming soon)
    score_threshold=0.4,       # High relevance only
    
    # Smart filtering
    filter_nonsense_urls=True,  # Remove .xml, .txt, etc.
    min_content_length=500,     # Skip thin content
    
    force=True                 # Bypass cache
)

# Discover with progress tracking
discovered = []
async for batch in seeder.discover_iter("https://physics-blog.com", research_config):
    discovered.extend(batch)
    print(f"Found {len(discovered)} relevant URLs so far...")

# Results include scores and metadata
for url_data in discovered[:5]:
    print(f"URL: {url_data['url']}")
    print(f"Score: {url_data['score']:.3f}")
    print(f"Title: {url_data['title']}")

Méthodes de découverte :

  • Sitemap Mining : analyse le fichier robots.txt et tous les plans de site liés
  • Common Crawl : interroge l'index Common Crawl pour les URL historiques
  • Intelligent Crawling : suit les liens avec un contrôle intelligent de la profondeur
  • Analyse de modèles : apprend les structures d'URL et génère des variations

Impact attendu dans le monde réel :

  • Projets de migration : découvrez plus de 10 000 URL d'anciens sites en moins de 60 secondes
  • Étude de marché : cartographiez automatiquement des écosystèmes entiers de concurrents
  • Recherche universitaire : créez des ensembles de données complets sans collecte manuelle d'URL
  • Audits SEO : trouvez chaque page indexable avec une notation de contenu
  • Archivage de contenu : assurez-vous qu'aucun contenu n'est laissé de côté lors des migrations de sites.

⚡ Optimisations des performances

Cette version inclut des améliorations significatives des performances grâce à une gestion optimisée des ressources, une meilleure gestion de la concurrence et une empreinte mémoire réduite.

Ce que nous avons optimisé

# Before v0.7.0 (slow)
results = []
for url in urls:
    result = await crawler.arun(url)
    results.append(result)

# After v0.7.0 (fast)
# Automatic batching and connection pooling
results = await crawler.arun_batch(
    urls,
    config=CrawlerRunConfig(
        # New performance options
        batch_size=10,              # Process 10 URLs concurrently
        reuse_browser=True,         # Keep browser warm
        eager_loading=False,        # Load only what's needed
        streaming_extraction=True,  # Stream large extractions
        
        # Optimized defaults
        wait_until="domcontentloaded",  # Faster than networkidle
        exclude_external_resources=True, # Skip third-party assets
        block_ads=True                  # Ad blocking built-in
    )
)

# Memory-efficient streaming for large crawls
async for result in crawler.arun_stream(large_url_list):
    # Process results as they complete
    await process_result(result)
    # Memory is freed after each iteration

Gains de performances :

  • Temps de démarrage : initialisation du navigateur 70 % plus rapide
  • Chargement de page : 40 % de réduction avec le blocage intelligent des ressources
  • Extraction : 3x plus rapide avec les sélecteurs CSS compilés
  • Utilisation de la mémoire : 60 % de réduction avec le traitement du streaming
  • Concurrent Crawls : gérez 5 fois plus de requêtes parallèles

📄 Prise en charge des PDF

L'extraction de PDF est désormais prise en charge nativement dans Crawl4AI.

# Extract data from PDF documents
result = await crawler.arun(
    "https://example.com/report.pdf",
    config=CrawlerRunConfig(
        pdf_extraction=True,
        extraction_strategy=JsonCssExtractionStrategy({
            # Works on converted PDF structure
            "title": {"selector": "h1", "type": "text"},
            "sections": {"selector": "h2", "type": "list"}
        })
    )
)

🔧 Changements importants

Modifications radicales

  • link_extractor renommé link_preview (reflète mieux la fonctionnalité)
  • Version minimale Python maintenant 3.9
  • CrawlerConfig divisé en CrawlerRunConfig et BrowserConfig

### Guide de migration

# Old (v0.6.x)
from crawl4ai import CrawlerConfig
config = CrawlerConfig(timeout=30000)

# New (v0.7.0)
from crawl4ai import CrawlerRunConfig, BrowserConfig
browser_config = BrowserConfig(timeout=30000)
run_config = CrawlerRunConfig(cache_mode=CacheMode.BYPASS)
