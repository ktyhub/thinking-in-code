chrome-devtools-mcp chrome-devtools-mcp-v1.13.0

1.13.0 (2026-11-11)

🎉 Caractéristiques

  • ajouter des points de journalisation construits sur DevTools BreakpointManager (#3211) (0877ee0)
  • ajouter des simulations de réseau à l'échelle de la page (#3384) (1d692d3)
  • Prise en charge des réponses simulées du réseau en amont (#3420) (c4bf342)

🛠️ Correctifs

  • config : accepte les fichiers de configuration avec une nomenclature UTF-8 (#3365) (63170b1)
  • console : arrête de résoudre une chaîne d'erreur cyclic.cause après 10 causes (#3338) (172656a)
  • désactiver set_logpoints lorsque --no-javascript-evaluation est défini (#3415) (11fcc59), ferme #3414
  • extensions : disons que list_extensions répertorie uniquement les extensions décompressées (#3433) (1383bb9)
  • ignorer une version mise en cache invalide lors de la vérification des mises à jour (#3392) (3a9f378)
  • input : valide les paramètres press_key et submitKey dans le schéma Zod (#3382) (375a269)
  • réseau : démarre une liste de requêtes vide pour les navigations sans requête (#3357) (b701776)
  • normaliser les valeurs non-erreur émises par les gestionnaires d'outils (#3068) (535a3dc)
  • performance : erreur lorsque performance_stop_trace est appelé sur une page sans enregistrement (#2971) (#3117) (1ab630a)
  • plugin : lancez le serveur Claude Code MCP avec npx --prefix (#3353) (a24334d)
  • préserver la sérialisation des tâches lors de l'annulation de la demande (#3079) (03fd4e8)
  • Chargements de pages de rapport qui conservent l'URL (#3395) (3cc38bb)
  • enregistrer les corps de requête binaire octet par octet (#3404) (e3eb901)
  • suggère --headless lorsque Chrome ne trouve pas de serveur X (#3428) (8b0856a)
  • url : déballez la source de vue : avant que tous les schémas soient vérifiés dans validateUrl (#3335) (7275268)
  • attendre : expliquer la correspondance de texte sensible aux espaces (#3350) (81a0379)

📄Documentation

  • ajouter la configuration Pi client (#3364) (bc0d93e)
  • clarifier les options de lancement et de connexion du navigateur personnalisé (#3386) (7e10c08)
  • input : notez que press_key ne peut pas piloter les popups <select> natifs sur macOS (#3288) (8e79bd0)

⚡Performances

  • mémoire : supprime les parents asynchrones des initiateurs de requêtes dans NetworkCollector (#3345) (ca6f834), ferme #3344

🏗️ Refactoriser

  • La réexportation n'a utilisé que les membres du runtime Zod à partir du baril tiers (#3439) (6b056c8)
  • réutiliser les schémas Zod et valider les dimensions entières de la fenêtre d'affichage (#3367) (3c609da)
