🎉 Caractéristiques

  • gérer les messages d'erreur qui ne sont pas des instances d'erreur (#618) (a67528a)

  • ignorer la qualité pour png (#589) (2eaf268)
  • inclure une note sur les éléments sélectionnés manquant dans l'instantané (#593) (80e77fd)
  • empêcher la suppression des avis de licence sur certains fichiers lors de la publication (#604) (94752ff)
  • Renommer le contenu de la page en dernier instantané de la page (#579) (9cb99ad)
  • wait_for : respecte le délai d'attente fourni (#630) (6b0984a), ferme #624

📄Documentation

  • ajouter la configuration antigravité (#580) (6f9182f)
