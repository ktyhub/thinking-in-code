débit d'air 3.2.1

📦PyPI : https://pypi.org/project/apache-airflow/3.2.1/ 📚 Documents : https://airflow.apache.org/docs/apache-airflow/3.2.1/ 🛠 Release Note : https://airflow.apache.org/docs/apache-airflow/3.2.1/release_notes.html 🐳 Docker Image : "docker pull apache/airflow :3.2.1" 🚏 Contraintes : https://github.com/apache/airflow/tree/constraints-3.2.1

Changements importants

  • Les utilisateurs qui ont uniquement un accès en lecture aux DAG ne pourront plus récupérer les données du point de terminaison /dags endpoint, as it now requires additional permissions (DagAccessEntity.RUN, DagAccessEntity.HITL_DETAIL, and DagAccessEntity.TASK_INSTANCE). This change was made because the endpoint returns aggregated data from these multiple entities. Please update your custom user roles to include read access for DAG Runs, Task Instances, and HITL Details if those users should still have access to the /dags. (#64822)

Améliorations

  • Autoriser la configuration du thème de l'interface utilisateur avec uniquement les remplacements CSS, les icônes uniquement ou le champ {} to restore OSS defaults. The tokens vide est désormais facultatif dans la configuration du thème. (#64552)
