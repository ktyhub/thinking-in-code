airflow 1.22.0

Mineure Publié13 juin 2026 Sourceapache/airflow Anglais original

Cette page est traduite automatiquement. Le texte anglais original fait foi.

diagramme de barre de débit d'air/1.22.0

Changements importants

La version minimale de Helm a été mise à jour vers 3.19.0 (#66970)

L'image du flux d'air par défaut est mise à jour vers 3.2.2 (#67681)

L'image Airflow par défaut utilisée avec le graphique est désormais 3.2.2, auparavant 3.2.1.

Ajout de la prise en charge de la configuration de enableServiceLinks (#67447)

La valeur par défaut deviendra false dans le graphique 2.0. Si vous comptez sur ces variables d'environnement, définissez explicitement enableServiceLinks: true ou migrez votre code pour utiliser les recherches de services basées sur DNS.

Nouvelles fonctionnalités

  • Ajouter le service OTel en option au Airflow Helm Chart (#64902)
  • Ajouter serviceAccountTokenVolume au nettoyage cron (#67446)
  • Ajouter l'option requirePersistence au travailleur logGroomerSidecar (#65884)

Améliorations

  • Ajouter une somme de contrôle pour la configuration du serveur api dans le déploiement du serveur API (#66468)

Corrections de bugs

  • Correction de l'étiquette de l'exécuteur du graphique Helm pour prendre en charge les alias de l'exécuteur (#67762)
  • Correction du rendu de connexion à la base de données KEDA du déclencheur (#67538)
  • Correction de la recherche du nom d'hôte de la sonde d'activité du travailleur Celery (# 67471)
  • Correction d'une erreur de modèle Go comparant la tranche à zéro à l'aide de eq (#64032)
  • Correction des valeurs du compte de service de travailleur Kubernetes (#66598)
  • Ajout d'une liaison pour workers.kubernetes et des conditionneurs ServiceAccount (#66730)
  • Correction du lanceur RBAC pour les chemins de classe de l'exécuteur (#66208)
  • Correction de l'accès au journal des tâches avec NetworkPolicies pour Airflow 2 et 3 (#65754)
  • Ajout du rendu tpl manquant pour les annotations ServiceAccount (#66095)
  • Correction des instructions go-template if pour les valeurs de rétention du log groomer (#66012)
  • Correction des hooks du cycle de vie du nettoyage de la base de données (#65881)
  • Correction des hooks de cycle de vie du pod de nettoyage qui ne sont pas appliqués (#65764)
  • Correction d'un avertissement de dépréciation (#66238)

# Le document ne change que

  • Développez les tâches de mise à niveau de Helm Chart dans le guide de migration Airflow 3 (#66118)

Divers

  • Modifier le rendu des liaisons de rôle job/pod et refactoriser les tests liés (#66626)
  • Standardiser la Dag capitalisation dans le libellé du graphique (#66114)
