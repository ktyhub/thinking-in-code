🔥 Quoi de neuf ?

Nouvelles fonctionnalités

  • #12440 - Ajouter l'importation de flux de travail à partir d'autres outils (n8n, Make.com, Zapier) (par @majdyz)
  • #12482 - Ajout d'un filtrage des capacités d'outils/blocs à AutoPilotBlock (par @majdyz)
  • #12472 - Activer l'exécution de blocs parallèles via le pré-lancement au niveau de l'infrastructure (par @majdyz)
  • #12483 - Ajout d'un mode d'exécution à sec avec simulation de bloc LLM (par @majdyz)
  • #12507 - Ajout de la compétence /pr-test + provisionnement automatique du mode abonnement (par @majdyz)

Améliorations

  • #12398 - Réduisez le coût du jeton de schéma d'outil de 34 % (par @majdyz)
  • #12511 - Renommez SmartDecisionMakerBlock en OrchestratorBlock pour une meilleure clarté (par @majdyz)
  • #12536 - Activer l'aperçu administrateur des soumissions du marché avant de les approuver (par @ntindle)
  • #12535 - Autoriser les administrateurs à télécharger les agents soumis en attente d'examen (par @ntindle)

Améliorations de l'interface utilisateur/UX

  • #12494 - Tronquer la description de la carte Marketplace à 2 lignes pour une mise en page plus claire (par @Abhi1992002)
  • #12486 - Déplacer le téléchargement ci-dessous Ajouter à la bibliothèque avec texte contextuel (par @0ubbe)
  • #12497 - Ajuster le débordement de hauteur de carte sur le marché (par @0ubbe)
  • #12443 - Détecte la fenêtre contextuelle OAuth fermée et autorise le rejet du modal d'attente (par @kcze)

Corrections de bugs

  • #12496 - Résoudre 5 alertes Sentry de production (par @majdyz)
  • #12513 - Réduisez le bruit Sentry dû aux erreurs causées par l'utilisateur (par @majdyz)
  • #12473 - Utiliser Chrome système pour le navigateur d'agent sur toutes les architectures (par @majdyz)
  • #12521 - Ajout de la variable d'environnement DB_STATEMENT_CACHE_SIZE pour le moteur Prisma (par @majdyz)
  • #12499 - Ajout d'un disjoncteur pour des boucles de relance d'appel d'outil infinies (par @majdyz)
  • #12516 - Rétrograder les erreurs LLM API causées par l'utilisateur au niveau d'avertissement (par @majdyz)
  • #12539 - Bump le machiniste ^0.5.1 → ^3.4.0 pour réparer le litellm tiré (par @majdyz)
  • #12544 - Filtre les informations d'identification par défaut SDK à partir des réponses aux informations d'identification API (par @majdyz)
  • #12501 - Autoriser /tmp comme chemin valide dans les outils de fichiers sandbox E2B (par @majdyz)
  • #12500 - Enregistrez les sessions AutoPilot avec le registre de flux pour les mises à jour SSE (par @majdyz)
  • #12547 - Empêcher la journalisation des données sensibles dans la solution de secours SafeJson (par @majdyz) ###Documentations
  • #12525 - Ajouter une structure Pourquoi/Quoi/Comment au modèle PR, CLAUDE.md et aux compétences PR (par @majdyz)
  • #12531 - Codifier les règles de workflow RP dans les documents de compétences et CLAUDE.md (par @majdyz)
  • #12518 - Améliorer la compétence /pr-test pour afficher des captures d'écran avec des explications (par @majdyz)
  • #12527 - Améliorer /pr-test pour exiger des captures d'écran, une vérification de l'état et corriger la responsabilité (par @majdyz)

Dépendances et maintenance

  • #12523 - Déplacez le groupe des dépendances de développement sur 1 répertoire avec 2 mises à jour (par @dependabot[bot])
