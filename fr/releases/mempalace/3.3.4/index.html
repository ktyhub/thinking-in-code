mempalace v3.3.4

  • La configuration est devenue intelligente et un modèle de langue locale fait le travail gratuitement. Mempalace init utilise désormais un LLM local si vous en avez un en cours d'exécution, Ollama ou LM Studio ou llama.cpp, selon votre préférence. Zéro appel cloud, pas de clé API à paramétrer, rien ne coûte rien. Si vous n’en avez pas en cours d’exécution, il retombe gracieusement et ne bloque jamais. Vous n’êtes jamais obligé d’attendre quelque chose qui n’est pas là.
  • Le palais connecte désormais les idées entre les projets. Les tunnels thématiques croisés sont une nouvelle fonctionnalité dans laquelle, lorsque deux projets parlent du même thème, comme un framework que vous utilisez partout ou une personne qui apparaît dans plusieurs domaines, le palais les relie entre eux. Ainsi, lorsqu'un LLM analyse vos souvenirs pour un projet, il peut suivre le fil des projets associés sans que vous ayez à configurer quoi que ce soit.
  • La configuration et la première ingestion ne constituent désormais qu'une seule étape. Lorsque vous exécutez mempalace init, il vous demande si vous souhaitez exploiter le répertoire juste après l'intégration et vous montre d'abord une estimation de la taille afin que vous ne soyez pas surpris par une longue ingestion. Une commande, deux choses faites, pas de deuxième passage manuel.
  • Un correctif de stockage a rendu les grands palais considérablement plus petits. Il y avait un bug qui faisait que les palais actifs pouvaient atteindre plusieurs gigaoctets sur le disque au fil du temps. Un contributeur a rapporté que leur palais était passé d'environ trente gigaoctets à moins de quatre cents mégaoctets après l'arrivée du correctif, et que les opérations qui étaient en attente d'expiration auparavant répondent désormais instantanément. Le numéro correspond au rapport de terrain d'une seule personne, mais le correctif sous-jacent est en place pour tout le monde.
  • Les hooks d'arrière-plan reconnaissent désormais correctement les conversations Claude Code. Les hooks qui enregistrent automatiquement vos sessions traitaient les transcriptions de conversation comme s'il s'agissait de code source, ce qui provoquait une confusion dans l'indexation. Désormais, elles sont correctement étiquetées comme conversations, ce qui signifie un stockage plus propre et un meilleur rappel lorsque vous recherchez ce que vous avez dit.
  • Les promesses n'ont pas bougé. Chaque mot stocké exactement. Tout reste sur votre machine. Rien ne va nulle part si nous ne lui avons pas explicitement dit d'aller. Pas de télémétrie. Zéro. Chaque version affine ce qui existe déjà au lieu de vous demander d'abandonner quelque chose qui vous tient à cœur.
