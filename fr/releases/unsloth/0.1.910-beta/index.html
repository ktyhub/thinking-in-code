paresseux v0.1.910-beta

Flint de Recursive, MOSS-Image et Nemotron Bolt 4B de NVIDIA sont là ! Exécutez-les localement dans Unsloth. Autre nouveauté : une installation Unsloth Desktop uniquement pour le chat, des modèles MLX MoE plus grands que la mémoire de votre Mac et un API de réglage fin compatible OpenAI.

Faits saillants

  • Modèles MoE plus gros sur Mac : les modèles MLX MoE trop volumineux pour la mémoire gardent les experts sur SSD, donc Qwen3.8-Flash-Next fonctionne sur un Mac de 32 Go.
  • Installation pour le chat uniquement : un bureau Unsloth beaucoup plus petit pour le chat GGUF ; ajoutez une formation plus tard dans Paramètres.
  • Flint : MoE de l'agent de codage 40B de Recursive, fonctionne en 24 Go à 3 bits [Guide] (https://unsloth.ai/docs/models/flint)
  • MOSS-Image : modèle d'image 5,1 B conçu pour la génération de premier plan GGUF + FP8
  • NVIDIA Nemotron 3.5 Bolt E4B : nouveau réglage fin du Gemma 4 E4B de NVIDIA, 63.2 sur Tau2-Bench par rapport au 38.7 d'origine Guide
  • Élagage expert du MoE : exportez un modèle MoE plus petit en supprimant 25 % ou 50 % de ses experts les moins utiles avec REAP.
  • Révision de l'interface utilisateur : Nouvelle interface utilisateur plus cohérente dans Unsloth (API, rondeur, etc.)

Images + vidéo

  • Générez des images contenant du texte anglais ou chinois avec MOSS-Image, SFT ou Base 5.1B d'OpenMOSS. GGUF · Base GGUF
  • MOSS-Image, le nouveau modèle d'image, fonctionne sur des GPU de 16 Go ; ses GGUF fonctionnent également sur les Mac et les ordinateurs sans GPU pris en charge.
  • La plupart des modèles d'images et de vidéos trop volumineux pour un seul GPU sont désormais répartis sur vos GPU NVIDIA, s'ils conviennent, au lieu de diffuser depuis la mémoire système.
  • Les nouveaux Hires corrigent la mise à l'échelle et affine un rendu en une seule étape sur SDXL, FLUX.1, Qwen-Image et Z-Image.
  • La nouvelle grille de comparaison affiche une invite tout en faisant varier jusqu'à trois paramètres, tels que le poids des graines, CFG ou LoRA, dans des grilles étiquetées.
  • Les tenseurs de sécurité SDXL bénéficient d'une pondération rapide de type AUTOMATIC1111, d'un saut CLIP, d'une redimensionnement CFG, de graines de variation et d'une inversion textuelle.
  • Les blocs de paramètres AUTOMATIC1111, Forge ou Civitai collés remplissent les paramètres de la page Images.
  • Si SAM 3 n'est pas déjà téléchargé, l'outil Masque à partir de texte utilise désormais SAM 3.1 : plus petit, sans connexion Hugging Face.

Chat + Bureau

  • Choisissez Chat uniquement (GGUF) lors du premier lancement d'Unsloth Desktop pour une installation beaucoup plus petite ; ajoutez une formation plus tard dans Paramètres.
  • Paramètres > Chat vous permet désormais d'afficher, de modifier, d'effacer ou de désactiver les notes de mémoire qu'Unsloth envoie à chaque chat.
  • Dans les discussions de recherche de documents, Afficher les passages répertorie le texte exact obtenu par le modèle et ouvre chaque passage sur sa page.
  • La page Audio peut parler et transcrire via une connexion API enregistrée, telle qu'OpenAI ou un serveur local.
  • Les installations, mises à jour et pip install -U unsloth d'Unsloth rejettent désormais les certificats emSign compromis d'eMudhra, qui permettent aux attaquants d'usurper l'identité de sites Web. Les moteurs optionnels vLLM et SGLang les trust.

Silex

  • Exécutez Flint de Recursive, un modèle MoE 40B avec 2,5B de paramètres actifs pour les agents de codage, avec raisonnement, utilisation des outils et contexte 256K. Guide · GGUF
  • En 3 bits, Flint tient dans 24 Go dans des contextes courts.
  • Sur SWE-bench Pro v2, Flint obtient 89.7 contre 73.8 de Qwen 3.6.

NVIDIA Nemotron 3.5 Boulon E4B

  • Exécutez et affinez le Gemma Nemotron 4B de NVIDIA, un réglage de raisonnement Gemma 4 E4B pour l'appel d'outils et le suivi des instructions.
  • Gemma Nemotron 4B bat Gemma 4 E4B dans 16 des 21 tests NVIDIA, gagnant le plus en termes d'utilisation des outils et de chat multi-tours.
  • DPO sur Gemma 4 E2B et E4B, y compris Gemma Nemotron 4B, ne plante plus.

Entraînement

  • Le réglage fin des modèles vocaux Whisper, Canary, Moonshine, Dia et CTC avec FastModel n'échoue plus.
  • L'entraînement vocal des perruches, des canaris et des CTC utilise jusqu'à 55 % de mémoire en moins.
  • La nouvelle recette Books & Documents to Text dans Data Recipes transforme les ebooks et les documents en un ensemble de données textuelles de pré-entraînement, aucun modèle n'est nécessaire.
  • Sous Windows et Linux, la page Export peut désormais élaguer 25 % ou 50 % des experts les moins utiles d'un modèle MoE avec REAP, à un certain coût en termes de qualité.
  • Dans le Python, le reap_prune exécute l'élagage expert REAP jusqu'à 54 fois plus rapide que celui du compresseur LLM.
  • unsloth train entraîne désormais des modèles de vision et, sauf sur Mac, d'audio.
  • Unsloth prend désormais en charge le réglage fin API d'OpenAI, de sorte que le SDK d'OpenAI peut télécharger des ensembles de données et exécuter un réglage fin supervisé des modèles locaux.

Performances

  • Les modèles MLX MoE trop gros pour votre Mac gardent des experts sur SSD, avec des réponses plus lentes. Qwen3.8-Flash-Next convient à un Mac de 32 Go ; DeepSeek-V4-Flash et GLM-5.3-Flash nécessitent beaucoup moins de mémoire que leur taille.
  • DPO et autres formations qui complètent les séquences s'exécutent jusqu'à 3,8 fois plus rapidement avec moins de mémoire sur NVIDIA Ampere ou plus récent.
  • La formation Qwen3-MoE, Gemma 3 et Gemma 4 sur GPU sans bf16 utilise désormais jusqu'à 7 fois moins de mémoire d'attention avec la torche 2.13 ou version antérieure.

Agents de codage + API

  • Dans le chat, les modèles peuvent désormais lire des fichiers texte et des documents sur les serveurs MCP connectés, et non plus simplement utiliser leurs outils.
  • Lors du lancement d'agents de codage, unsloth start n'envoie plus sa clé Unsloth API en texte brut via votre proxy HTTP à un Unsloth local.
  • Sous Windows, unsloth start ne rompt plus les hooks Claude Code ou la connexion Codex lors de leur lancement.
  • Les requêtes avec une clé Unsloth API ne peuvent plus exécuter Python et les outils de terminal sans bac à sable ; seule l'interface utilisateur d'Unsloth peut le permettre.
  • Le nouveau bouton Enregistrer pour ce modèle dans les paramètres de discussion définit vos paramètres d'échantillonnage par défaut pour ce modèle pour les nouvelles discussions et les requêtes API.

Modèles + matériel

  • Un point de contrôle gpt-oss BF16 chargé avec load_in_4bit = True ne reçoit plus de poids aléatoires d'experts et de routeurs.
  • Le sélecteur de modèles vous permet à nouveau d'exécuter des modèles sur des NPU Ryzen AI 300 et plus récents, sans variable d'environnement.
  • Sur certains PC Linux AMD dotés d'un ROCm à l'échelle du système, les GGUF exécutés sur le CPU s'exécutent désormais à nouveau sur le GPU.
