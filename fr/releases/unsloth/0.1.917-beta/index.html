unsloth v0.1.917-beta

Pré-version Publié11 nov. 2026 Sourceunslothai/unsloth Anglais original

Cette page est traduite automatiquement. Le texte anglais original fait foi.

paresseux v0.1.917-beta

Qwen3.8-27B est ici avec les GGUF Dynamic v3.1, prêts à fonctionner localement avec Unsloth. Cette version apporte également des améliorations majeures des performances, un rendu Glass plus fluide, des blocs de code et une interface utilisateur Thinking remaniés, des exportations de chat HTML/PDF et de nouvelles fonctionnalités de génération d'images et d'agent de codage.

Faits saillants

  • Nouveaux Qwen3.8-27B GGUF dynamiques v3.1.
  • Chats plus rapides : Améliorations majeures des performances du streaming, du défilement, des menus et des boîtes de dialogue, en particulier dans les longues conversations.
  • Verre plus lisse : Décalage réduit lors de la saisie, du défilement et de la génération.
  • Blocs de code et réflexion remaniés : Panneaux extensibles à défilement indépendant avec coloration syntaxique améliorée.
  • Exportations HTML et PDF : Exportez les discussions directement depuis le menu de discussion.
  • File d'attente d'images : Mettez en file d'attente les générations d'images à venir pendant qu'une autre est en cours de rendu.
  • Claude Code et Codex sur MLX : Exécutez des agents de codage avec des modèles MLX via unsloth start.

Chat et interface utilisateur

  • Les performances de streaming ne se dégradent plus à mesure que les conversations se développent.
  • Défilement plus fluide avec les images d'arrière-plan, avec ou sans verre.
  • Chargement plus rapide des menus, des boîtes de dialogue et du volet du navigateur.
  • La lecture à voix haute commence après la première phrase au lieu d'attendre la réponse complète.
  • Les préférences de discussion, le format de l'heure et la vérification orthographique se synchronisent désormais avec votre compte.

Images et vidéos

  • FLUX.2 et FLUX.3 utilisent 36 à 43 % de VRAM en moins lors du décodage d'images à la même vitesse.
  • Mettre en file d'attente les générations d'images à partir de la page Images ou API.
  • Les modèles d'image INT8 et FP8 se chargent désormais sur les anciens GPU NVIDIA, y compris le T4.
  • Correction des sorties d'images noires avec FLUX.3.
  • LTX-2.5 FP8 fonctionne désormais sur des GPU de 24 Go.
  • Cosmos3-Nano peut continuer la vidéo clips à partir de sa première ou de sa dernière image.

Agents de codage et API

  • Exécutez Claude Code et Codex avec les modèles MLX sur Mac en utilisant unsloth start.
  • Le nouveau préréglage Unsloth MCP permet aux agents de codage d'accéder aux outils Unsloth.
  • Les modèles Claude API sans limite explicite de jetons ne s'arrêtent plus à 1 024 jetons.
  • Les modèles MLX renvoient désormais une erreur de longueur de contexte appropriée au lieu d'une réponse vide.

Formation

  • model.generate() est désormais 2 à 8 fois plus rapide sur les GPU T4 par défaut sur tous les modèles FastModel.
  • Les colonnes vidéo sont désormais correctement prises en charge lors de la formation des modèles de vision.
  • Le parallélisme contextuel Ulysses prend désormais en charge les modèles de texte Kimi-Linear, DeepSeek, MiniMax et Gemma 4.
