DeepTutor v1.4.4

DeepTutor v1.4.4 Release Note

Date de sortie : 2026.06.13 Une version ciblée au-dessus de v1.4.3 : la bibliothèque de compétences s'ouvre jusqu'à l'écosystème Agent-Skills plus large - installez des compétences communautaires à partir de ClawHub avec une seule commande — et une base de connaissances les aperçus des documents rattrapent la visionneuse de fichiers de discussion. Entièrement accessible, non migrations, pas de changements radicaux.

Quoi de neuf

Compétences du Hub, à une seule commande

Les compétences DeepTutor partagent leur format avec l'écosystème Agent-Skills (SKILL.md + fichiers de support), donc les registres externes sont désormais natifs source de la bibliothèque de compétences :

deeptutor skill search "git release notes"        # semantic search on the hub
deeptutor skill install clawhub:gh-release-notes  # verify → fetch → register
deeptutor skill install some-skill@1.2.0          # hub defaults to clawhub; @ pins a version
deeptutor skill list                              # local skills with hub provenance

Chaque import passe par le même portail de sécurité, quelle que soit la source : le hub le verdict de sécurité est vérifié en premier (les colis signalés sont refusés sauf si --allow-unverified), les archives sont extraites avec zip-slip / zip-bomb gardes, les fichiers de support transmettent une liste blanche de suffixes de texte/script afin que les binaires n'atterrissez jamais dans l'espace de travail, et le front-matter de always: est supprimé - un Le package téléchargé ne peut jamais s’injecter dans chaque invite système. La provenance (hub, version, verdict) est enregistrée dans .hub-lock.json pour vérifications. Les registres au-delà de ClawHub se connectent via settings/skill_hubs.json. Dans les déploiements multi-utilisateurs, l'installation est réservée aux administrateurs (POST /api/v1/multi-user/admin/skills/install) et installer ≠ attribuer : la compétence atterrit dans le catalogue d'administration, invisible pour les autres utilisateurs jusqu'à ce qu'un Grant l'attribue - afin que les administrateurs puissent d'abord vérifier les compétences du hub dans leurs propres discussions.

Aperçus de la base de connaissances, pour de vrai

L'onglet Fichiers KB affiche désormais les documents Word et Excel dans le navigateur : les mêmes prévisualiseurs docx/xlsx fidèles dans lesquels le visualiseur de fichiers de discussion a obtenu v1.4.3 — et un nouveau point de terminaison file-preview-text sert de la plaine extraite texte à la demande, afin que PowerPoint et d'autres fichiers Office soient prévisualisés sous forme de texte au lieu d'un bouton de téléchargement. L'outil de prévisualisation DOCX a également appris à évoluer pages vers le bas pour s'adapter aux panneaux latéraux étroits au lieu de les placer.

Les aperçus Markdown rendent les images intégrées

Fichiers de démarques autonomes avec captures d'écran intégrées en base64 désormais affichez-les : les moteurs de rendu autorisent les URL raster data:image/* sécurisées sur images (react-markdown supprime chaque URL data: par défaut), tandis que les schémas compatibles avec les scripts restent bloqués.

README localisés, resynchronisés

Les dix README traduits (中文, 日本語, Español, Français, …) ont été reconstruit à partir du README anglais actuel — Partners, le v1.4.x historique des versions et mise en page actualisée incluse.

Notes de mise à niveau

  • Accès direct depuis v1.4.3 : pip install -U deeptutor ; Les utilisateurs du Docker tirent ghcr.io/hkuds/deeptutor:latest. Aucune migration.
  • deeptutor skill install parle à clawhub.ai via HTTPS ; entrefer les déploiements peuvent pointer un miroir ou récupérer un CLI via settings/skill_hubs.json. Changelog complet : https://github.com/HKUDS/DeepTutor/compare/v1.4.3...v1.4.4
