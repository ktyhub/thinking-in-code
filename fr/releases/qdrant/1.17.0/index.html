Qdrant Edge :hocho:

Qdrant Edge est une version en cours de Qdrant, qui partage les mêmes composants internes, le même format de stockage et les mêmes points API que la version serveur, mais conçue pour fonctionner localement. Qdrant Edge est compatible avec la version du serveur et peut lire les instantanés de partition créés par la version du serveur de Qdrant. Plus de documentation disponible ici.

Dépréciations :avertissement:

  • À partir de v1.17.0, Qdrant modifie le format de réponse pour les champs vectoriels dans l'interface gRPC. Tous les clients officiels de Qdrant devraient déjà être adoptés pour ce changement, alors assurez-vous de mettre à niveau vos bibliothèques client et vérifiez que vous n'utilisez pas de champs obsolètes. Plus d'informations : https://github.com/qdrant/qdrant/pull/7183

  • Dépréciations à venir :

    • Dans Qdrant v1.18.x, toutes les méthodes de recherche obsolètes seront complètement supprimées et ne seront pas disponibles même à partir des anciennes bibliothèques client.
    • Dans Qdrant v1.17.x, nous supprimerons complètement le support de RocksDB au profit de gridstore, ce qui signifie que la mise à niveau directe de v1.15.x vers v1.17.x ne sera pas possible. Veuillez suivre les [instructions de mise à niveau] (https://qdrant.tech/documentation/faq/qdrant-fundamentals/#how-do-i-avoid-issues-when-updating-to-the-latest-version) et mettre à niveau une version mineure à la fois pour éviter les erreurs de stockage non prises en charge. Notez que l'infrastructure Qdrant Cloud génère automatiquement des étapes de mise à niveau appropriées, vous n'avez donc pas à vous en soucier.
