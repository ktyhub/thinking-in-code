Baleine Code v0.9.12

L'ancien package npm deepseek-tui est obsolète et ne reçoit aucune autre version. Utilisateurs issus de l'héritage v0.8.x deepseek / Les noms deepseek-tui doivent migrer avec docs/REBRAND.md.

Installer

Recommandé — version officielle du GitHub

Nouvelle installation macOS/Linux (binaires avec somme de contrôle de cette version) :

curl -fsSL https://codewhale.net/install.sh | CODEWHALE_VERSION="v0.9.12" sh
"$HOME/.local/bin/codewhale" --version

Pour Windows, utilisez le programme d'installation ou l'archive correspondant ci-dessous. Pour un existant installation directe, exécutez codewhale update ; il imprime le chemin de l'exécutable et conserve les versions plus récentes. Si le répertoire d'installation est occupé par une autre build, utilisez la migration d'un nouveau répertoire dans [le guide d'installation] (https://github.com/Hmbown/CodeWhale/blob/main/docs/INSTALL.md).

Emballage secondaire — npm et Cargo

npm install -g codewhale
# or build from source
cargo install codewhale-cli --locked

Le wrapper télécharge les ressources de commande codewhale et codew correspondantes de cette version. Les deux contiennent le même runtime compilé.

Docker / GHCR

docker run --rm -it \
  -e DEEPSEEK_API_KEY="$DEEPSEEK_API_KEY" \
  -v codewhale-home:/home/codewhale/.codewhale \
  ghcr.io/hmbown/codewhale:v0.9.12

L'image expose le même runtime que codewhale et codew. Le La balise latest est également mise à jour lors de la sortie.

Cargaison (Linux / macOS)

cargo install codewhale-cli --locked

Le package Cargo installe codewhale. Cargo ne peut pas créer de deuxième commande alias d'une cible binaire ; les utilisateurs qui souhaitent une orthographe plus courte peuvent ajouter un Lien symbolique codew vers cet exécutable installé. Le npm, Homebrew, archive, Shell-installer et les canaux de conteneur installent directement les deux noms de commande.

Qu'y a-t-il dans v0.9.12

Codewhale v0.9.12 met l'utilisation de l'ordinateur en binaire et ouvre deux nouvelles routes — Alibaba Model Studio via la table des fournisseurs basés sur les données et Concentrate en tant que passerelle BYOK Responses opt-in - et ajoute la répartition dans le cloud ainsi qu'un Socket de contrôle par session contrôlé par la configuration. La coquille est l'autre moitié du sortie : une nouvelle carte de lancement, le plan de travail ancré sous le compositeur, un propriétaire du focus pour Tab, les cellules d'outils qui portent leur propre état et fleet comme la parole publique pour le collectif live. Le changement complet au niveau de l'article l'enregistrement est conservé sous les faits saillants de la version catégorisée.

Ajouté

  • L'utilisation de l'ordinateur est livrée avec le binaire. Le plugin computer-use — 38 outils sur macOS, Windows, Linux et HarmonyOS, observation axée sur l'accessibilité avec repli des pixels, captures d'écran, zoom, enregistrement d'écran et enregistrement ordinateurs distants via ssh et hdc - est intégré dans Codewhale et écrit sur $CODEWHALE_HOME/builtin-plugins lors de la première exécution, donc chaque canal d'installation le porte. Il est répertorié comme builtin · not-reviewed et reste désactivé jusqu'à ce que vous l'examinez et l'activez : l'expédier n'est pas y consentir. Le Le serveur informatique stdlib-Python qu'il remplace a disparu.
  • Alibaba Model Studio rejoint la table des fournisseurs basés sur les données en tant que Descripteur openai-compatible : point de terminaison en mode compatible international, Identifiant DASHSCOPE_API_KEY, découverte /v1/models en direct. Qwen 3.8 Flash et Qwen 3.8 Max arrivent via l'autorité du catalogue - jamais un identifiant codé en dur.
  • Concentrate : passerelle BYOK Responses opt-in de première classe avec modèles vivants découverte et streaming SSE typé (#5725).
  • Répartition dans le cloud : l'exécuteur distant décharge les tâches de l'agent de codage vers des tâches isolées. bacs à sable cloud avec authentification par jeton machine et suivi structuré des tâches (#5701, #5712).

Le le relais conserve un fichier d'état durable par portée derrière un propriétaire à l'échelle de la session verrouiller, lie une session enregistrée de manière permanente à sa première cible distante, rejoue commandes en double exactes à partir des résultats conservés au lieu de démarrer une seconde tour d'inférence, terminalise les réservations orphelines au redémarrage et rejette (ne fait jamais la queue) dans un tour de travail local occupé avec une tentative immédiate résultat. Les commandes d'arrêt nécessitent l'identité exacte de course et de virage, ainsi qu'un travailleur abandonne tout compte ou toute incompatibilité de cible lors de l'actualisation du jeton.

  • Ajout d'un chemin d'emballage Omarchy/AUR vérifié : packaging/aur porte désormais un Modèle PKGBUILD, moteur de rendu et tests .SRCINFO, version candidate étape de rendu et documents ; l'alias de compatibilité AUR en direct codewhale-tui -> codewhale est préservé, les dépendances AUR correspondent au package live et le self-updater refuse de combattre une installation Omarchy/package-manager.

  • Ajout d'un plafond de coût/jeton d'utilisation à l'échelle de la flotte (R6, #5567) : un accumulateur De plus, la porte d'admission et l'alerte ont limité les dépenses d'une série entière entre les travailleurs.

  • Ajout du taux de réussite du cache du fournisseur réel à /context (C3, DSH #3) : le Taux rapporté par le fournisseur, pondéré en termes de jetons, à partir de la même télémétrie /cache agrégats, plus un état honnête "pas encore de télémétrie de cache" lorsque rien n'est enregistré.

  • Ajout du mouvement des coûts par étape : les reçus TurnUsage sont tarifés au fur et à mesure de leur arrivée donc la surface du coût réel se déplace pendant les longs tours agentiques au lieu de seulement à TurnComplete (#5578), et le pied de page affiche désormais honnêtement cost: unknown quand rien ne peut être fixé au lieu de cacher la ligne.

  • Ajout de la surface de session sous-marine : l'eau ambiante lit l'état de la session de l'autre côté de la pièce, sa forme d'animation suit l'activité des agents en direct, et les teintes d'attention sont stables (pas de respiration) avec un traitement de lecture distinct et pas de joint mi-eau sur les fenêtres hautes.

  • Ajout des mentions de ligne à distance @path:START-END (#5550, moitié du sélecteur à suivre), un fichier de sauvegarde prévisible de dernière copie pour les exportations clipboard avec le chemin nommé lorsque le clipboard échoue (#5555), wait sur plusieurs shells d'arrière-plan tâches avec until=any|all (#5549, moitié nommée-kill à suivre) et compositeur Sélection de mots double-click/triple-click.

  • Ajout du succès partiel du slot parallèle-schema du workflow (#5583) : un slot qui produit un résultat partiel valide pour le schéma et n'échoue plus tout le parallèle branche.

  • Ajout d'indices de démarrage en cas d'échec de chargement du plugin (#5579) et de l'application OpenRouter en-têtes d'attribution sur les requêtes sortantes.

  • Ajout de codewhale doctor --fix (avec --yes pour le consentement non interactif) : le médecin calcule maintenant un plan de réparation concret — supprimer le .tmp* obsolète restes d'écritures atomiques interrompues, resserrez le fichier secret-store autorisations sur 0600, désactivation du MCP structurellement défectueux (statut d'erreur) entrées via le chemin de sauvegarde atomique MCP et échafaudage user-global manquant Répertoires skills/tools/plugins — les affiche et ne les applique qu'après consentement explicite. Chaque action est de portée étroite et idempotente ; JSON et Les modes context-JSON restent en lecture seule et entrent en conflit avec --fix (#5552, v1).

  • Ajout du rapport /context sur le taux de réussite du cache d'invite du fournisseur réel (C3) parallèlement à une pression symbolique.

Modifié

  • La recherche Web native du fournisseur applique désormais des contraintes de domaine avant d'accepter un tentative, rejette les réponses générées lorsque les citations renvoyées violent celles-ci contraintes et préserve le délai d'attente configuré/local de l'appelant en tant que budget de secours indépendant (#5681).

  • Les métriques de session inactive omettent les faits nuls (0 turns, LLM 0s) jusqu'à ce que le runtime a des preuves. Le chrome fonctionnel indique in the current au lieu d'un générique working.

  • Suppression de neuf fichiers intermédiaires runtime_contract/ non compilés. Contrats en direct restent model.rs et termination.rs.

  • Le premier balayage de code mort #5587 convertit les assistants de test audités uniquement en #[cfg(test)], gardant les versions de production exemptes de API de test uniquement sans changer le comportement d'exécution.

  • /plugin reload est désormais détectable lorsque les bundles de plugins sur disque changent : le prochain envoi et /plugin list pousse une fois avec Run /plugin reload to apply au lieu de conserver silencieusement le catalogue obsolète (#5579). Trust est inchangé ; cela ne recharge pas automatiquement.

  • Les avertissements de pression contextuelle et les alertes critiques restent désormais visibles dans l'interface utilisateur collante statut jusqu'au compactage ou au licenciement explicite, au lieu de disparaître dans défilement des métadonnées de tour (#5620).

  • Le magasin de threads d'exécution est par défaut une racine par session ($CODEWHALE_HOME/sessions/<id>/runtime), donc plusieurs processus Codewhale sur une machine ne partage plus un seul verrou de propriétaire (#5630). La serrure exclusive est inchangé ; CODEWHALE_RUNTIME_DIR sélectionne toujours une racine partagée lorsque celle-ci est prévu.

  • Les totaux des jetons de session incluent désormais les deltas d'appel par modèle en affichage uniquement tandis qu'un le tour est en cours d'exécution, y compris les compteurs d'entrée/sortie et de classe cache ; le les totaux TurnComplete faisant autorité se réconcilient toujours exactement une fois (#5581).

  • Le focus Transcript expose désormais les actions par bloc : y copie le contenu, Y copie la vue des métadonnées rendues, Entrée ouvre un pager de blocage en plein écran et r ouvre les détails bruts ; les raccourcis du rail Tâches existants restent inchangés (#5551).

  • Neutralité du fournisseur (#5588) : la résolution des modèles omis/aliasés est désormais, les valeurs par défaut natives d'OpenAI, relatives au fournisseur, ne transitent plus par table d'un autre fournisseur, les informations d'identification CLI restent limitées au fournisseur et NVIDIA les informations d’identification ne fuient plus dans le trousseau DeepSeek. Test de neutralité les matrices font appel à plusieurs fournisseurs au lieu d’en remplacer un seul.

  • Le module du moteur de workflow a été décomposé de son méga-fichier de 3 000 lignes en Modules journal, usage et report plus un répertoire de modules (#5586 tranches 1a/B/C/D), un déplacement sans sémantique vérifié par un hachage à contenu normalisé.

  • Les refus de compactage sont désormais toujours nommés (#5577) : prises silencieuses en contexte la pression a disparu, le compteur de contexte honore la même invite facturée par le fournisseur le déclencheur utilise (T1) et les résultats d'élagage sont projetés sans cloner le transcription.

  • Les budgets d'étape se terminent désormais honnêtement : un atterrissage en douceur d'environ 80 % pousse le modèle vers rédiger son rapport final, et l'épuisement accorde exactement un tour de rapport d’épuisement au lieu de mourir en silence (A1/A2).

  • Crédit contributeur : agents contributeurs reconnus (ex. Codewhale Agent) peut désormais transporter des remorques Co-authored-by ; des bandes-annonces de robots/outils inconnues sont toujours rejeté par la porte du crédit.

Corrigé

  • La saisie rapide ne corrompt plus le compositeur. L'heuristique de pâte-rafale s'est exécutée à chaque session jusqu'à ce qu'une véritable pâte entre crochets arrive, retenant, tamponnant, rétro-saisissant et absorbant Entrez sur les suppositions de timing ; c'est maintenant de secours uniquement (désactivé lorsque le terminal fournit un collage entre crochets), le retro-grab est supprimé et le texte de la commande Enter on hold est vidé et soumis.

  • Ctrl+C fonctionne sur le menu de lancement de pré-session et parle partout : le appuyez d'abord sur la fenêtre de sortie de deux secondes avec un message localisé visible Astuce "Appuyez à nouveau sur Ctrl+C pour quitter" (auparavant silencieuse), la seconde sortie. L'entrée du nom de l'arbre de travail conserve Ctrl+C comme entrée d'annulation.

  • Les nouvelles sessions interactives ne laissent plus de doublon fantôme d'un message derrière. Le TUI a revendiqué un identifiant de session (verrouillage du magasin d'exécution, crash au démarrage checkpoint) tandis que le moteur en frappait un deuxième ; le premier SessionUpdated j'ai re-saisi l'application, la validation d'achèvement a effacé uniquement l'identifiant du moteur point de contrôle, et codewhale --continue a ensuite "récupéré" l'orphelin point de contrôle comme une session en double au lieu de la vraie. Le moteur maintenant adopte l'identifiant appartenant à l'hôte lors de l'apparition (EngineConfig::session_id) et /clear crée l'identifiant suivant dans l'application, comme /new. Un --continue non TTY n'est plus favorise et consomme le point de contrôle de crash avant de faire échouer le terminal vérifier, et les drapeaux racine codewhale --resume <id> / --session-id <id> documenté dans le runbook des opérations est désormais analysé au lieu d'être avalé comme une invite.

  • Site Web : /signin, /signup et /auth/callback sont publics et sensibles aux paramètres régionaux. itinéraires au lieu de 404 localisés. Connectez-vous et créez un compte, envoyez la personne à l'application CWC ; Les rappels OAuth sautent vers app.codewhale.net avec la requête intact; /login et /register sont des alias. L'utilisation locale du CLI n'est pas présentée comme exigeant un compte (#5767).

  • La liste de refus de lecture du sandbox correspond au chemin résolu d'une règle ainsi qu'à son orthographe littérale. Sur macOS /etc et /var sont des liens symboliques vers /private, donc une lecture de /private/etc/sudoers a contourné la règle /etc/sudoers, et une règle écrite contre un répertoire lié symboliquement jamais déclenchée pour de vrai chemin que canonicalize et le processus cwd rendent.

  • Les coques de fond sont des rangées de bandes de travail de première classe (▾ Shells N) que vous pouvez ouvrez, regardez et annulez par l'identifiant shell_* sur la ligne. /jobs cancel all annule les obus en cours d'exécution ; il ne recherche plus une tâche nommée all. Le La miette de sablier du compositeur ne remplace plus la surface d'une coque.

  • codewhale logout et /logout effacent désormais la session du compte Codewhale et l'emplacement secret Daytona, pas seulement les clés du fournisseur API. La caisse TUI Le chemin login --api-key restant ne prétend plus enregistrer une clé.

  • Les sessions de compte ne lisent plus le trousseau macOS. Non signé ou reconstruit Les binaires codewhale étaient à chaque fois un nouveau principal ACL de trousseau, donc codewhale web et le TUI ont affiché une boîte de dialogue de mot de passe au démarrage. Séances utilisez maintenant ~/.codewhale/secrets/secrets.json (mode 0600), le même magasin comme clés de fournisseur. Extrait de la moitié du trousseau de retraite du #5632.

  • Renforcement de l'analyse de la configuration côté répartiteur de la même manière : ConfigStore les charges et l'analyse de la configuration du projet désérialisent désormais ConfigToml sur un thread de pile dédié de 16 Mio (le chemin de sauvegarde de la configuration guidée pourrait déborder) un travailleur de 2 Mio s'empile de la même manière que l'analyse ConfigFile de TUI), et le test toast de confirmation de configuration #5585 exécute son exécution sur un support de taille égale. thread au lieu de déborder de la pile libtest par défaut.

  • Correction des agents interactifs détachés signalant l'utilisation du travailleur après le parent le tour se termine avec l'utilisation manquante dans le total de la session/live /cost (#5597) : les tours interactifs acquièrent un bail d'utilisation d'exécution limité au propriétaire, une utilisation tardive entre dans le pool de coûts de session sans rouvrir le scellé la boîte aux lettres et la comptabilité du travailleur/session/rechargement partagent une réponse hachée l'identité afin que les livraisons retentées restent exactement une fois.

  • Correction de la classe fiasco des sous-agents : le git -C absolu dans l'espace de travail n'est plus déclenche la porte shell enfant en lecture seule avec une porte délimitée cohérente (# 5595), tourner les parcs à la fin des enfants à leur tour au lieu d'annuler silencieusement eux (# 5596), les revendications d'écriture périmées sont publiées par Liveness avec coordonnées version (# 5562), et la description du rôle de vérificateur correspond à sa véritable surface (#5562).

  • Correction du workflow de gestion des échecs de réponse au schéma (# 5583) : réparation limitée avec reçus dactylographiés (genre + tentative), reçus de sortie brute conservés sous forme d'artefacts qui survivent au rechargement, et des échecs sont apparus au lieu d'un succès nul (# 5528). Les instantanés du propriétaire dégradés ne sont plus projetés comme des exécutions terminées ordinaires (#5582), les types d'erreurs de tâches typées permettent un parallèle/pipeline ultra-rapide (R9), et /workflow confirm trouve le brouillon malgré les messages entrelacés.

  • Correction de la session DeepSeek qui n'était jamais compactée automatiquement à 842k/1M (#5577) : le précis billed_842k_on_a_1m_window_compacts_despite_a_small_estimate la régression bloque le déclencheur.

  • Correction des fuites de sandbox et des lacunes d'autorité : les outils d'écriture dans l'espace de travail résolvent fichiers liés en dur avant l'écriture (S2, # 5569), une liste de refus de lecture opt-in limite les lectures complètes du disque dans n'importe quelle posture (S1, #5568) et les autorisations de session correspondent la famille de commandes au lieu d’élargir l’ensemble de l’outil (R2).

  • Robustesse du transport du fournisseur fixe : les requêtes HTTP sans streaming sont limitées par un délai d'attente de lecture (R4) et une surface de trames d'erreur en cours de chat-achèvements au lieu de pendre (R3). L'expiration de MCP OAuth réagit désormais au 401/403 avec un nom chemin de récupération et indice de connexion au lieu de ressembler à un serveur en panne (T4, #5572).

  • Correction des écarts dans le cycle de vie de la flotte : les travailleurs détachés sont récoltés lorsque leur manager meurt (R7) et le délai d'attente d'horloge murale par tâche est appliqué (R5) ; le local L'hôte de la flotte se compile sur des cibles non Unix ; la réparation du schéma détaché reste à l'intérieur le budget d'exécution.

  • Correction de l'exactitude du cache d'invite : le catalogue d'outils est pris en compte dans ordre de virement du fournisseur (C1), les changements de préfixe entre les demandes sont toujours déclaré (C5) - y compris le nouveau change:tool_surface à mi-tour raisons de l'admission différée des outils, de l'activation de la recherche d'outils et du MCP d'exécution arrivée de l'outil - et une réponse de raisonnement uniquement s'est arrêtée à la limite de sortie maintenant échoue honnêtement au tour au lieu de réémettre une demande qui ne peut que reproduire l'arrêt.

  • Correction de la dérive docs/public-surface : REBRAND.md ne présente plus api.deepseeki.com comme solution de secours pour la Chine (#5564) et les faits/outils Web les comptes correspondent au référentiel.

  • Les requêtes d'extraction lourdes exécutent désormais le véritable espace de travail Linux nextest, doctest et verrouillez les voies directement sur les actions GitHub au lieu de signaler un vert espace réservé en attendant un miroir CNB spécifique à la branche (#5547).

  • Les membres de la liste de flotte dans une flotte sélectionnée exposent désormais une possibilité de modification visible et un raccourci direct de sélection de modèle m, tandis que la ligne du coordinateur reste lecture seule (#5604, couvre #5589).

  • L'inspecteur de contexte attribue désormais un coût de schéma d'outil limité au module intégré. catalogue et chaque serveur MCP découvert sans modifier l'assemblage d'invite ou comportement du cache (#5553).

  • La période calme de poursuite d'objectif ([goal] continuation_delay_seconds, ajouté dans #5508) s'applique désormais à chaque chemin de répartition. Auparavant le le crochet de répartition dans le tour a déclenché immédiatement l'invite de continuation suivante chaque fois qu'une étape du modèle se terminait avec l'objectif toujours actif, alors CLI reprenait et les sessions gérées par l'hôte n'ont jamais observé le délai configuré (mesuré intervalles de bout en bout d'environ 9 s avec un délai de 300 s configuré). L'attente maintenant fonctionne sans condition à l'intérieur de goal_continuation_message_if_needed, reste annulable, et les appels pause/effacement/terminal update_goal sont toujours annuler un laissez-passer en attente (#5534).

  • Deux tests unitaires ne dépendent plus de l'état de l'environnement global du processus qui les tests frères et sœurs mutent simultanément. route_budget::tests::v4_trigger_uses_window_percent_when_it_fits_spendable_input a affirmé des valeurs de budget de sortie sans remplacement lors de la lecture CODEWHALE_MAX_OUTPUT_TOKENS / DEEPSEEK_MAX_OUTPUT_TOKENS sans en maintenant lock_test_env(), afin qu'un rédacteur simultané puisse inverser la valeur mi-assertion (le flocon de suite complète dépendant de l'ordre). prompts::tests::system_prompt_prefix_never_leaks_private_content lire le vraie maison via HOME/USERPROFILE, donc une machine avec ~/.codewhale/instructions.md a divulgué son chemin absolu dans l'invite et l'affirmation de non-chemins privés a échoué à moins que le HOME temporaire d'un frère ou d'une sœur le garde était en direct. Les deux tests maintiennent désormais la barrière env et épinglent le variables (le test itinéraire-budget supprime les remplacements ; le test des invites pointe HOME/USERPROFILE dans un répertoire de travail). Affirmations inchangées.
