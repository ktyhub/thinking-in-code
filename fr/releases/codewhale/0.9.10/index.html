Baleine-code v0.9.10

Codewhale est le produit public de Shannon Labs. Le codewhale Les noms des commandes, des packages npm et des actifs de version restent techniques en minuscules identifiants. L'ancien package npm deepseek-tui est obsolète et ne reçoit aucune autre version. Utilisateurs issus de l'héritage v0.8.x deepseek / Les noms deepseek-tui doivent migrer avec docs/REBRAND.md.

Installer

Recommandé – npm (une commande, les deux points d'entrée)

npm install -g codewhale

Le wrapper télécharge les ressources de commande codewhale et codew correspondantes de cette version. Les deux contiennent le même runtime compilé.

Docker / GHCR

docker run --rm -it \
  -e DEEPSEEK_API_KEY="$DEEPSEEK_API_KEY" \
  -v codewhale-home:/home/codewhale/.codewhale \
  ghcr.io/hmbown/codewhale:v0.9.10

L'image expose le même runtime que codewhale et codew. Le La balise latest est également mise à jour lors de la sortie.

Cargaison (Linux / macOS)

cargo install codewhale-cli --locked

Le package Cargo installe codewhale. Cargo ne peut pas créer de deuxième commande alias d'une cible binaire ; les utilisateurs qui souhaitent une orthographe plus courte peuvent ajouter un Lien symbolique codew vers cet exécutable installé. Le npm, Homebrew, archive, Shell-installer et les canaux de conteneur installent directement les deux noms de commande.

  • Pour le chemin du programme d'installation, exécutez CodeWhaleSetup.exe ; il installe codewhale.exe, codew.exe et codewhale.bat sous %LOCALAPPDATA%\Programs\CodeWhale\bin, ajoute ce répertoire au PATH de l'utilisateur actuel et crée un raccourci du menu Démarrer qui préfère Terminal Windows (wt.exe) une fois installé.
  • Extrayez l'archive de votre machine : codewhale-windows-x64.zip ou codewhale-windows-arm64.zip
  • Double-click codewhale.bat (pas le .exe brut) pour lancer
  • Exécutez install.bat pour copier les binaires et le lanceur sur %USERPROFILE%\bin
  • Ajoutez %USERPROFILE%\bin à votre CHEMIN

L'archive Windows portable ignore le script d'installation : extrayez et exécutez codewhale.bat à partir de n'importe quel répertoire. Corrigé

  • La première exécution démarre à nouveau sur l'écran d'accueil. Une clé manquante n'est plus ignore l'accueil et ouvre automatiquement la liste des fournisseurs locaux : entrez les promenades vers le explication calme du fournisseur, puis Entrée ouvre le sélecteur donc une première touche API peut être réglé. Le retour de la récupération de clé manquante ouvre toujours le sélecteur lancement.
  • Une commande bash au premier plan qui n'a nommé aucun délai d'attente est à nouveau limitée. Le L'outil bash orienté vers le modèle a laissé un timeout_ms omis au niveau interne plafond (~24.8 jours) au lieu des 120 s par défaut, son propre schéma annonce, donc un CLI bloqué sur une invite interactive ou bloqué l'appel réseau a maintenu le tour ouvert indéfiniment - un rapport reposait sur un seul appel CLI non authentifié pendant plus de deux heures avec la rangée d'outils simplement compter les secondes. La valeur par défaut annoncée s'applique désormais, ce qui arme le récupération existante : le processus est tué et le modèle doit être réexécuté avec background=true et sondage avec action="wait". Un explicite timeout_ms est toujours honoré pour son travail de premier plan véritablement long, et les exécutions en arrière-plan et interactives conservent leur propre durée de vie.
  • Le marché des extensions (/plugin) n'est plus une liste en lecture seule. Chaque recommandation et candidat stocké nomme son état de vérité et action principale - Ajouter, Activer, Configuré ou Indisponible - et Entrée ou un la souris click exécute cette action via le fichier /mcp add existant révisé Contrôleurs recommandés, /mcp activate, and /plugin install/trust, donc aucun deuxième chemin trust n'existe. Utilisation du navigateur et Sandbox Runtime en direct Honnêtement, indisponible avec leur véritable routage de configuration au lieu d'impliquer un l'installation de Codewhale ne peut pas fonctionner.
  • L'onglet Extensions MCP affiche désormais un inventaire honnête : le nombre d'en-têtes et les lignes visibles proviennent du même ensemble de serveurs configurés, donc MCP (6) ne peut plus s'asseoir au-dessus de deux lignes rendues. Serveurs désactivés rester visible et étiqueté désactivé au lieu de disparaître silencieusement, et serveurs configurés absents de la liste des instantanés en direct car non encore inspectés avec leur propre capacité de rechargement explicite via la commande MCP contrôleur.
  • Les lignes du plugin installé agissent désormais sur leur état réel : Enter ouvre un actif bundle (/plugin show), propose Enable pour un bundle trusted mais désactivé, ou achemine un bundle untrusted vers la revue trust existante - via le mêmes contrôleurs de confirmation et de persistance que les commandes slash.
  • Transferts et listes de sous-agents, tâches shell en arrière-plan, tâches durables, les continuations retardées et les contrôles de flux de travail sont désormais limités au session qui les possède. Les enregistrements portent la propriété immuable de la session racine, les charges utiles obsolètes du canal de complétion sont rejetées avant la déduplication, le travail en arrière-plan s'écoule et ne rapporte qu'à sa propre session, et Les tâches héritées sans propriétaire échouent lors de la fermeture (classe d'échec n° 5 518 signalée par @hxfhd; la provenance exacte du rapport JavaScript n'a pas été revendiquée car reproduit).
  • L'enveloppe de route résolue atteint désormais chaque appel de modèle sortant : tous les dialectes filaires et les appels auxiliaires se fixent à la couture du transport partagé dans le cadre d'un budget de virement/réservation, les limites d'entrée des fournisseurs sont respectées, et changer de modèle sur le même protocole n’hérite plus du précédent limites du modèle (#5516, #5518).
  • Continuité dès la première exécution : le fournisseur d'intégration choisi persiste redémarre, une configuration de première exécution manquante n'interrompt plus le flux, et le point de contrôle automatique de l'accord de travail s'affiche sous la forme d'une configuration autonome transfert au lieu de régresser le rail d'intégration vers celui de l'assistant complet 4/10 de progression.
  • Les déclarations /goal en langage naturel formulées explicitement créent désormais un objectif durable dans le moteur indépendant du fournisseur avant l'envoi du modèle, tandis que les tâches ordinaires et les transcriptions citées restent en dehors du mode objectif et de la prose la reconnaissance à elle seule ne peut plus remplacer la création d’objectifs.
  • /model conserve désormais la valeur par défaut actuelle de Z.ai (GLM-5.3) visible lorsqu'un une installation plus ancienne a une route GLM-5.2 explicite enregistrée. Le 5.2 enregistré l'itinéraire reste exact ; Choisir 5.3 envoie et mémorise l'ID 5.3 distinct.
  • Le point de contrôle constitutionnel mène désormais avec l'accord global équilibré ; le chemin par défaut n'écrit aucune constitution personnalisée. La surface de lancement des startups distingue le chat en lecture seule du travail lié à un dossier et soumis à approbation.
  • Tabby et autres ponts IME n'observent plus un curseur visible obsolète lorsqu'un le diff du cadre est en cours de peinture ; Codewhale cache le curseur pendant la comparaison, restaure la cellule canonique du compositeur, puis la révèle à nouveau (BrathonBai, n° 5023).
