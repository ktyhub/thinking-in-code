Installer

Recommandé — version officielle du GitHub

Nouvelle installation macOS/Linux (binaires avec somme de contrôle de cette version) :

curl -fsSL https://codewhale.net/install.sh | CODEWHALE_VERSION="v0.10.1" sh
"$HOME/.local/bin/codewhale" --version

Pour Windows, utilisez le programme d'installation ou l'archive correspondant ci-dessous. Pour un existant installation directe, exécutez codewhale update ; il imprime le chemin de l'exécutable et conserve les versions plus récentes. Si le répertoire d'installation est occupé par une autre build, utilisez la migration d'un nouveau répertoire dans [le guide d'installation] (https://github.com/codewhale-hq/CodeWhale/blob/main/docs/INSTALL.md).

npm install -g codewhale

GIT affiche la branche et là où il se trouve face à son amont, les changements (avec leurs chemins un Enter away), les arbres de travail liés et les cinq derniers commits, et il conserve mise à jour pendant un tour alors qu'il est ouvert. Il est écrit "pas un dépôt git" seulement lorsque cela est vrai, signale l'échec des sondes d'état dans la vue et le compositeur au lieu de revendiquer un arbre propre, considère chaque chemin non fusionné comme un conflit, et seulement dit qu'il y a plus de chemins modifiés lorsque la liste est plafonnée. FILES répertorie les fichiers modifiés par cette session, y compris les écritures sans reçus de différence, et les fichiers qu'il lit, avec chaque chemin unique conservé au-delà du résumé d'activité aperçu de douze chemins. FILES et son badge actualisés depuis la session en cours avant même l'ouverture de TASKS. Les modifications avec les reçus affichent leur taille et ouvrent leur différentiel. NOTES répertorie vos notes /note. Le connard badge, la vue Git et la ligne git du modèle en partagent désormais une Appel git status --porcelain=v2, il y a donc moins de processus git que avant (#6565).
  • Le travail en arrière-plan vous indique quand il se termine, même entre les actualisations. Par lots les avis du shell couvrent les commandes explicitement en arrière-plan ou détachées ; premier plan les résultats et les anciens achèvements d'avant cette session TUI restent silencieux. Le changement de session ne répète pas un avis de fin. Par lots les avis comptent les travaux terminés, échoués et arrêtés séparément ; commandes shell, les invites de tâches et les erreurs restent dans l'application, loin des notifications sur l'écran de verrouillage. Un serveur de développement en cours d’exécution ne retient plus l’avis. Échoué, tué et les obus expirés conservent leurs résultats et les huit derniers obus terminés rester répertorié par session. Les tâches terminées ne semblent plus en direct ou rouvrent le quai. Les étiquettes d'arrière-plan suivent le langage de l'interface utilisateur, les aperçus longs des agents sont conservés leur pointeur de résultat complet, et l'indicateur silencieux utilise l'horloge du moteur et limiter sans marquer un outil actif comme silencieux (#6565).

###Plugins

  • Codewhale n'ajoute plus de recommandations de plugins à vos messages au modèle. Les suggestions apparaissent au même endroit, suivent un changement et un budget, et ne faites jamais de publicité pour les plugins intégrés, les mots génériques ou les plugins d'un autre système d'exploitation.
  • /plugin dismissals répertorie les suggestions de plugins ignorées, et /plugin dismissals reset [<name>] les ramène.
  • Les outils des plugins examinés qui se déclarent en lecture seule ne demandent plus pour approbation à chaque appel.
  • Le plugin Computer Use fourni est 0.12.0, la version publiée en amont 8435692 (#6303, #5856). Sur macOS, l'agent utilise son propre pointeur et ne pilote jamais votre curseur. app_script refuse le shell s'échappe. Clicks sur les actions irréversibles telles que Payer, envoyer ou supprimer nécessite une confirmation. Les décisions de consentement ne peuvent pas être prises en compte run_actions ou relecture de trajectoire, et trajectoires expurgées champs sécurisés. Autre nouveauté : un bail de contrôle d'ordinateur partagé qui suspend la saisie de l'agent pendant qu'un des lecteurs de personne et un mode de connexion de navigateur pour un Chromium partagé. Le vendu README ne prétend plus que les agents délégués partagent la session d'utilisation de l'ordinateur ; ils ne jamais recevoir ses outils.
  • La révision du marché des épingles du catalogue propriétaire fourni ae3dd2255a9a266365c6125a084f511eb26bc04d. Il répertorie l'utilisation de l'ordinateur 0.12.0 et ajoute Codewhale pour Chrome (Chromewhale) 0.3.0 en tant qu'aperçu du développeur : vous chargez son extension Chrome décompressée et, comme chaque plugin de catalogue qu'il installe désactivé et désactivé jusqu'à ce que vous le révisiez.

Fiabilité des versions

  • Téléchargez la version complète dans un brouillon privé, vérifiez la taille de chaque actif et SHA-256 digest, puis publiez. Une nouvelle tentative interrompue ne peut pas réutiliser les fichiers obsolètes octets de même taille. Les balises des versions CNB et GHCR suivent la publication canonique.
  • Le bootstrap d'Ubuntu Lighthouse nécessite des CIDR source SSH trusted ou un opt-in public-SSH avant de changer d'hôte ; IPv6 mal formé et défaut large les réseaux sont refusés.

###CI

  • Sceau de tests de commande et de session touchant l'état HOME, USERPROFILE et CODEWHALE_HOME sur des répertoires temporaires. Session non scellée, instantané, l'artefact, l'historique du compositeur, l'audit et le stockage de plug-in intégré se résolvent en une racine de test isolée ; les threads de travail non liés ne peuvent pas emprunter ceux d'un autre test sceau de la maison. Une sentinelle de processus enfants vérifie que la répartition des commandes connue et les cas de session laissent leur foyer ambiant inchangé.
  • Les requêtes Fork Pull restent sous la limite du coureur macOS et du cache Actions. reste sous son capuchon.
  • Les versions candidates et les versions partagent une porte de parité et une balise de version sans récépissé de libération, le candidat est refusé.
  • Les cliquets budgétaires bloquent les demandes d'extraction du même référentiel, sauf si la demande d'extraction met à jour le budget avec un reçu.
  • Un workflow de configuration avancée CodeQL est prêt lorsque le référentiel change à partir de la configuration par défaut.
