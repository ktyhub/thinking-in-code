Baleine-code v0.9.1

L'ancien package npm deepseek-tui est obsolète et ne reçoit aucune autre version. Utilisateurs issus de l'héritage v0.8.x deepseek / Les noms deepseek-tui doivent migrer avec docs/REBRAND.md.

Installer

Recommandé – npm (une commande, les trois points d'entrée)

npm install -g codewhale

Le wrapper télécharge les codewhale, codew et codewhale-tui correspondants binaires de cette version et les place dans le même répertoire.

Docker / GHCR

docker run --rm -it \
  -e DEEPSEEK_API_KEY="$DEEPSEEK_API_KEY" \
  -v codewhale-home:/home/codewhale/.codewhale \
  ghcr.io/hmbown/codewhale:v0.9.1

L'image contient le répartiteur codewhale, la cale codew et le runtime codewhale-tui. La balise latest est également mise à jour lors de la sortie.

Cargaison (Linux / macOS)

cargo install codewhale-cli codewhale-tui --locked

Les deux caisses sont requises : codewhale-cli produit le répartiteur codewhale et la cale codew, tandis que codewhale-tui produit le runtime interactif auquel le répartiteur délègue. L'installation d'une seule caisse échouera au moment de l'exécution avec une erreur MISSING_COMPANION_BINARY.

  • Extrayez l'archive de votre machine : codewhale-windows-x64.zip ou codewhale-windows-arm64.zip
  • Exécutez install.bat (copie dans %USERPROFILE%\bin)
  • Ajoutez %USERPROFILE%\bin à votre CHEMIN L'archive Windows portable ignore le script d'installation : extrayez et exécutez à partir de n'importe quel répertoire.   • Faire en sorte que la réparation du modèle-politique JSON prenne en compte les charges utiles des objets et des tableaux dans la source ordre, en faisant correspondre les délimiteurs imbriqués dans les chaînes entre guillemets et les échappements et renvoyer le premier candidat équilibré analysé, au lieu de laisser un délimiteur d'ouverture inégalé ou un tableau corrompu de préférence d'objet en premier charges utiles (#4430).
  • Convertir les événements persistants d'achèvement de sous-agent et de contrôle en cours d'exécution en points de contrôle de CV concis et ne faisant pas autorité, conservant leur durée d'exécution brute enveloppes, sentinelles et instructions de nouvelle tentative à partir du modèle restauré et de TUI état de conversation (#4409).
  • Livrer les résultats des sous-agents ayant échoué, arrêtés et obsolètes exactement une fois au en attente du parent, de la boîte aux lettres du cycle de vie et de la TUI avant de fermer leur environnement d'exécution état. Le redémarrage réconcilie désormais les enregistrements de travailleur orphelins en file d'attente/modèle/attente d'outil à interrompu tout en préservant les points de contrôle, et les travailleurs annulés non plus lu comme complété dans le TUI (#4408).
  • Donnez aux applications hôtes une limite d'annulation pour la connexion MCP OAuth afin qu'un la connexion du fournisseur bloquée ou abandonnée ne bloque plus la session d'appel (#4380).
  • Évitez les jointures de lecteur bloquées après la fin du processus Windows, le shell est donc terminé les sessions ne peuvent pas suspendre leurs lecteurs (#4383).
  • Donner des hooks d'observateur sans standard EOF immédiats et contenir un hook expiré traiter les arbres afin que les descendants et les lecteurs de tuyaux ne puissent pas fuir après le parent shell sort (#4489 par @luismateusvargas).
  • Préserver l'état complet du processus Windows PTY non signé au lieu de l'effondrer chaque exception de bit élevé ou NTSTATUS à 2147483647, y compris les valeurs décimales et Métadonnées de diagnostic hexadécimales pour les nouveaux tests de l'appareil (#4100 par @redjade75723).
  • Gardez la liste d'actions de configuration de la barre d'accès synchronisée avec le focus du clavier lorsque le la sélection se déplace au-delà des lignes visibles, y compris vers le bas après /export (#4418).
  • Acheminer les liens Windows OpenHarmony Cargo via la cible du référentiel lanceur clang pour que le lien final Rust conserve sa cible, sysroot et MUSL drapeaux et étendez la protection de libération no-SDK pour protéger ce contrat. Ceci complète le PR #4470 de @shenjackyuanjie configuration aux côtés de l'original de @shenyongqing approche bindgen dans PR #4384.
  • Concilier la feuille de route du site avec la réalité : le lien de partage retiré la direction est désormais un non-objectif explicite, Workrooms est le lieu considéré direction, et le web local client apparaît comme en cours, en anglais et Chinois (#3418).
  • Les avertissements de blocage de compétences et de charge de compétences à l'invite du système n'intègrent plus l'absolu. chemins domicile/espace de travail ; les entrées sont rendues relatives à l'espace de travail ou ~/… afin que le Le préfixe d'invite stable en octets ne divulgue jamais les chemins privés. Un nouveau test invariant protège les chemins absolus, les clés API et les chemins de l'espace de travail dans le préfixe (#4632).
  • Les tests unitaires de base de mode/autorisation ne lisent plus le live du développeur settings.toml ; ils isolent les E/S de configuration dans un répertoire temporaire (#4628).
  • Enter ne fige plus le compositeur à l'envoi : la répartition se divise en un phase de préparation de synchronisation (historique instantané + spinner) et un async généré phase (route automatique, contrôle en amont, envoi du moteur), avec soumissions fermées pendant une dépêche est en vol (#4605).
  • Les routes auto-hébergées conservent des limites de sortie explicites par modèle pour les inconnus des alias de fil au lieu du repli générique 4K (#4655 par @h3c-hexin ; RP #4656).
  • Les erreurs d'inactivité des achèvements de chat incluent désormais les octets reçus et télémétrie de synchronisation, distinguant les blocages de pré-remplissage du milieu du flux se bloque avec des arguments d'appel d'outil tronqués (#4657 par @h3c-hexin).
  • Le fournisseur set_config écrit désormais en gardant la route en mémoire au pas, donc une écriture de modèle suivante atterrit à la place dans la table du nouveau fournisseur d'écraser la racine default_text_model du fournisseur précédent (#4658 par @gaord, avec un correctif de synchronisation de route de suivi).

Sécurité

  • Restreindre les contrôles en amont du navigateur Runtime API d'origine croisée aux éléments documentés authentification et en-têtes de contenu, autorisant explicitement Authorization au lieu de s'appuyer sur un caractère générique (#4454).

Sécurité

  • Renforcer la frontière entre la communauté publique et le site : les versions de révision programmées utilisent désormais un espace de noms de fraîcheur canonique, la suppression de l'administrateur est limitée à la validation objets brouillon, les demandes de flux publics ne peuvent pas dépenser le GitHub détenu par le serveur le jeton et les corps de connexion du responsable sont limités par le type et la taille avant l'analyse.
