Codewhale v0.9.9

Baleine Code v0.9.9

Codewhale est le produit public de Shannon Labs. Le codewhale Les noms des commandes, des packages npm et des actifs de version restent techniques en minuscules identifiants. L'ancien package npm deepseek-tui est obsolète et ne reçoit aucune autre version. Utilisateurs issus de l'héritage v0.8.x deepseek / Les noms deepseek-tui doivent migrer avec docs/REBRAND.md.

Installer

Recommandé – npm (une commande, les deux points d'entrée)

npm install -g codewhale

Le wrapper télécharge les ressources de commande codewhale et codew correspondantes de cette version. Les deux contiennent le même runtime compilé.

Docker / GHCR

docker run --rm -it \
  -e DEEPSEEK_API_KEY="$DEEPSEEK_API_KEY" \
  -v codewhale-home:/home/codewhale/.codewhale \
  ghcr.io/hmbown/codewhale:v0.9.9

L'image expose le même runtime que codewhale et codew. Le La balise latest est également mise à jour lors de la sortie.

Cargaison (Linux / macOS)

cargo install codewhale-cli --locked

Le package Cargo installe codewhale. Cargo ne peut pas créer de deuxième commande alias d'une cible binaire ; les utilisateurs qui souhaitent une orthographe plus courte peuvent ajouter un Lien symbolique codew vers cet exécutable installé. Le npm, Homebrew, archive, Shell-installer et les canaux de conteneur installent directement les deux noms de commande.

Téléchargement manuel — archives de la plateforme (recommandé)

Chaque archive ci-dessous contient le même runtime sous le codewhale et Noms des commandes codew, plus un script d'installation :

| Plateforme | Archives | Script d'installation | |---|---|---| | Linuxx64 | codewhale-linux-x64.tar.gz | install.sh | | LinuxARM64 | codewhale-linux-arm64.tar.gz | install.sh | | Android ARM64 (Termux) | codewhale-android-arm64.tar.gz | install.sh | | macOS x64 | codewhale-macos-x64.tar.gz | install.sh | | MacOS BRAS | codewhale-macos-arm64.tar.gz | install.sh | | Windows x64 (installateur) | CodeWhaleSetup.exe | Configuration du NSIS | | Windowsx64 | codewhale-windows-x64.zip | install.bat | | Windows x64 (portable) | codewhale-windows-x64-portable.zip | — | | WindowsARM64 | codewhale-windows-arm64.zip | install.bat | | Windows ARM64 (portable) | codewhale-windows-arm64-portable.zip | — |

Unix (Linux/MacOS) :

tar xzf codewhale-<platform>.tar.gz
cd codewhale-<platform>
./install.sh

Fenêtres :

  • Pour le chemin du programme d'installation, exécutez CodeWhaleSetup.exe ; il installe codewhale.exe et codew.exe sous %LOCALAPPDATA%\Programs\CodeWhale\bin et ajoute ce répertoire au CHEMIN de l'utilisateur actuel.
  • Extrayez l'archive de votre machine : codewhale-windows-x64.zip ou codewhale-windows-arm64.zip
  • Exécutez install.bat (copie dans %USERPROFILE%\bin)
  • Ajoutez %USERPROFILE%\bin à votre CHEMIN

L'archive Windows portable ignore le script d'installation : extrayez-la et exécutez-la à partir de n'importe quel répertoire. Le programme d'installation NSIS n'est actuellement pas signé et peut déclencher Windows SmartScreen jusqu'à ce qu'un certificat de signature soit connecté au pipeline de publication.

Chaque plate-forme dispose également de codewhale-<platform> nus et non archivés et Actifs codew-<platform>. Les sept noms de fichiers codewhale-tui-<platform> attachés au v0.9.5 sont des copies de compatibilité à octets identiques utilisées uniquement pour permettre v0.9.4 clients déjà installé découvre et traverse ce binaire unique transition; les installateurs actuels n’exposent pas de troisième runtime. L'héritage NPM le package deepseek-tui est obsolète et n’est pas republié. Pour migrer à partir des noms binaires hérités v0.8.x, voir docs/REBRAND.md.

Qu'y a-t-il dans v0.9.9

Codewhale v0.9.9 est une version vérité et résilience : l'outil shell ne peut pas ne bloque plus une session lorsque l'hôte manque de disque ou de descripteurs, les fenêtres de contexte non vérifiées et les plafonds de sortie sont étiquetés honnêtement à chaque fois surface, DeepSeek V4 est tarifé sur les niveaux de pointe/hors pointe publiés, SSE UTF-8 échoue fermé dans tous les dialectes, l'observation de la flotte est visible, bwrap obtient contenant des essentiels et des racines supplémentaires, le skin dsh chevauche le paquet profil, le schéma de l'outil agent est réduit à 12 champs, et README/site Web les paramètres régionaux passent à 18 et 8.

Corrigé

  • L'outil minuscule bash ne se coince plus lorsque sa sortie complète se déverse le fichier ne peut pas être créé : un volume temporaire complet ou une table de descripteurs épuisée utilisé pour échouer chaque appel - echo ok inclus - avec le faisceau interne "Échec de la création de la sortie du shell de streaming" et ne jamais récupérer jusqu'à ce que le l'hôte a été nettoyé. Le déversement s'effectue désormais au mieux (la queue délimitée est toujours renvoyé et l'avis de troncature indique pourquoi le chemin de sortie complet est manquant), et tout échec d'apparition/flux restant nomme l'élément épuisé. ressource - disque, descripteurs de fichiers, mémoire - et indique que le prochain appel est sécurisé pour réessayer (#5465 ; le coin qui a supprimé la propre session 0.9.9 du propriétaire).
  • Une limite concrète de production d'itinéraires/d'offres surpasse désormais les conservateurs Supposition de compatibilité de 8 192 jetons pour un modèle non catalogué. Des itinéraires qui publier aucune limite de sortie rester fermé, les plafonds de modèle documentés restent fait autorité, et une limite de route ne peut jamais augmenter le plafond demandé (#5460).
  • Honnêteté de la fenêtre contextuelle sur chaque surface (#5239, #5441) : le Les réseaux model-name hint et fallback du schéma à contacts de la fenêtre contextuelle sont devine, et chaque surface qui en rend un le dit maintenant - la ligne d'état, /status, /config, le message de pression contextuelle, les puces du sélecteur de modèle, et l'inventaire des routeurs automatiques. Les fenêtres non vérifiées génèrent toujours de vrais budgets (déclencheur de compactage, compteur de contexte, réservation de sortie) ; ils s'arrêtent juste lecture en tant que capacités que quelqu'un a vérifiées. Une fenêtre analysée à partir d'un _Nk le suffixe du nom du modèle (qwen3-32b-256k → 256K) est désormais le sien model-name hint a sonné en dessous de catalog, car il est plutôt optimiste que conservateur – une valeur déclarée par un catalogue ou un fournisseur la bat. Le La substitution [providers.<name>] context_window reste la solution difficile et rendu comme configured sans marqueur.
  • Honnêteté du plafond de production (#5440) : un modèle de famille anthropique que le catalogue propose pas décrit conserve le plancher de messages 64K comme pince et le ChatGPT/ La route Codex OAuth conserve sa politique 4K, mais OutputCeilingSource a obtenu un Sonne unverified pour les deux, donc exécutable pour les reçus et le sélecteur de modèle étiquetez-les unverified/"étage supposé" au lieu de documented. Pince les valeurs sont inchangées.
  • L'activation par défaut de la télémétrie est visible (#5441) : codewhale doctor's La section runtime-posture a gagné une ligne de style telemetry=on (default) avec la source qui l'a décidé (cli | env | config | default), et codewhale config get telemetry signale le consentement résolu avec son source au lieu de key not found sur une machine dont les lots sont expédiés. Vérité changement seulement ; la résolution et le comportement sont intacts.
  • Flotte : la découpe d'obus en lecture seule d'un éclaireur (#5428) est désormais honorée par les deux la porte de posture et l'enveloppe d'exécution, donc git log, find | head, npm view et les autres commandes limitées en lecture seule s'exécutent sur place à la place d'être refusé en tant que "Exécute" (#5426). La délégation ne s’élargit toujours pas autorité : le test d'isolement des rôles et la broche docs/SUBAGENTS.md qu'un enfant ne peut pas dépasser la posture de son parent (#5426, #5435).
  • /rename et /title s'appliquent désormais au milieu du premier tour : le fichier de session le fait n'existe pas avant la première sauvegarde automatique, donc le changement de nom a échoué avec Introuvable ; le chemin partagé préfère désormais le point de contrôle par session et reconstruit à partir de l'état de l'application, avec un test de régression PTY via le live boucle d'événements (#5430).
  • integrations dsh plan ne refuse plus les valeurs par défaut de DeepSeek Itinéraire des réponses en dialecte (deepseek-v4-flash) ; Réponses et Les itinéraires des messages anthropiques sont acheminés via pi-ai openai-responses / anthropic-messages au lieu d'être approximé ou refusé ; seules les URL de base authentifiées sont toujours refusées, avec une erreur qui nomme le fournisseur et le modèle (#5434).
  • Le coût de la session ne s'élève plus à unverified_live_pricing lors de la tarification en direct ne peut pas être vérifié (plan de contrôle 503, capacités Models.dev uniquement) superpositions) : la documentation du fournisseur regroupe les taux de repli pour DeepSeek V4 famille sur Fireworks / OpenCode Zen restaurer une figure utilisable, en direct les lignes par fournisseur gagnent toujours, et kimi-k3 reste sans prix jusqu'à ce qu'un le taux publié existe (#5241 ; récolté à partir du #5402).
  • Libérer les actifs : les contrôles de fraîcheur des actifs release.yml sont comparés aux publier le propre started_at du travail, donc les réexécutions au niveau du travail de l'étape npm ne sont pas plus empoisonné par les téléchargements antérieurs (#5429).
  • macOS CI : le test de récépissé de révision automatique agent_focus_pty attendu sur un travailleur qui avait déjà terminé et couru le focus du rail ; ça tient maintenant la conclusion de l'enfant et attend une dispute en direct réglée (réf. #5056, #5403).
  • La tarification de DeepSeek V4 suit les niveaux de pointe/heures creuses publiés (pointe de 01h00 à 04h00 et de 06h00 à 10h00 UTC ; les heures creuses correspondent à la moitié des heures de pointe) pour deepseek-v4-flash et deepseek-v4-pro en USD et CNY, résolus à partir de le temps enregistré de chaque tour ; les lignes obsolètes à un seul niveau sous-estiment le coût à ~4×. Parce que chaque tarif direct DeepSeek de première partie est désormais fenêtré dans le temps, la carte de score échoue fermée (missing_recorded_time) sur un tour DeepSeek non daté au lieu de deviner un niveau (suivi #5470 ; #5241, vérifié par rapport à api-docs.deepseek.com le 17/08/2026).
  • SSE UTF-8 réparti sur les trames HTTP/2 DATA échoue désormais à chaque fermeture. dialecte de streaming : un décodeur strict partagé, un tail flush et La propagation decode_failed (InvalidSseUtf8) remplace la propagation par dialecte approximations, avec des tests de décodeur byte-chunk (#5374 ; remplace le brouillon #5404). -CI : release_four_read_only_fleet_roles_launch_with_canonical_prompts » ont répondu les enfants de la flotte atteints de SSE pendant qu'ils appellent le chemin bloquant JSON ; l'échec de l'analyse a été réessayé et le travailleur a été compté deux fois sur macOS lent coureurs (#5471 ; réf. #5056).
  • Contexte : chaque surface d'outil web (Web, web_search, web.run, fetch_url) utilise désormais la limite logicielle de résultat bruyant, les extractions volumineuses sont donc compacté comme la sortie du shell au lieu de consommer la limite stricte ordinaire (#5474, merci @h3c-hexin).
  • Routage : un sélecteur enregistré en minuscules tel que glm-5.2 se résout par rapport au posséder une ligne de catalogue Z.ai / DeepSeek (cas de repli, uniquement lorsque exactement l'identifiant du fil appartenant à un fournisseur correspond) au lieu d'être classé comme un autre modèle nu du fournisseur (#5475, merci @h3c-hexin ; diagnostic par @asto18089 dans Pinvou/CodeWhale#14).
  • Catalogue de modèles mis à jour au 17/08/2026 par rapport à l'officiel pages de tarification : tarifs gpt-5.6-terra / gpt-5.6-luna, claude-sonnet-5 conserve 2$/10$ (l'augmentation annoncée en septembre a été retirée), claude-opus-5 ajoutés, kimi-k3 et kimi-k2.7-code-highspeed, MiniMax-M2.7-highspeed, Lignes propriétaires Mistral, xAI grok-4.5 / grok-4.3 avec contexte long niveaux, les limites Gemini et Qwen et l'aperçu dots3-note de RedNote en tant que Ligne OpenRouter (aucun API propriétaire n'existe encore) — chaque numéro porte son source et un test épinglé (#5485).
  • Site Web : copie sur codewhale.net réécrite en phrases déclaratives simples — une idée par phrase, des chiffres issus des faits générés, pas d'auto-narration — avec une feuille vocale sur docs/design/WEB_VOICE.md (#5483).
  • CI : les workflows de release ne restaurent plus les caches npm/cargo après vérification d'un SHA fourni par l'appelant - les sommets d'empoisonnement du cache CodeQL Les numéros 88 à 107 sont clôturés par un test de contrat sur les fichiers de workflow (#5463).
  • Les lignes TUI compactes inférieures à 60 colonnes ne réservent plus de métriques de session cachées bande, donc les bornes étroites récupèrent la rangée au lieu de clipping la transcription (#5486).
  • Le champ sous-marin TrueColor de Ghostty utilise désormais un champ dédié synchronisé Voie de 60 FPS au lieu de l'ancien plafond de compatibilité de 30 FPS, avec continu les fondus caustiques remplacent les changements de couleur visiblement progressifs.
  • L'action Space:expand annoncée par Live Reasoning s'exécute désormais avant le le premier caractère du compositeur est maintenu en rafale, tandis que les espaces dans un collage actif restent la charge utile. Le dernier aperçu du raisonnement n'est également que véritablement gratuit lignes de la fenêtre d'affichage avant de tronquer au lieu de s'arrêter à la ligne fixe 10/12 repli sur des terminaux spacieux.
  • Les builds stricts de cargo doc n'échouent plus sur les URL nues dans les commentaires rustdoc ; les liens restants sont des cibles Markdown explicites (#5489).

Modifié

  • L'outil agent orienté modèle annonce exactement 12 champs - action, prompt, type, profile, name, agent_id, message, until, detached, worktree, write_roots, resume_from — contre 33 (#5324, réf. #5123). Budgets (max_steps, wall_time_secs, max_depth), remplacements de routage (model, model_strength, thinking), chemin d'arbre de travail boutons, les champs délibérés/spawn-contract et les champs wait/status/interrupt les extras ont été retirés du schéma annoncé. Chaque champ supprimé reste analyse acceptée et honorée inchangée (même contrat que token_budget), donc les transcriptions enregistrées, les ACP/MCP clients et les configurations de flotte sont relues telles quelles ; le Les pinces de confinement #5426/#5435 sont intactes. Les budgets enfants sont désormais résolus à partir des valeurs par défaut du rôle (60/120 tours, temps de mur de 1800 s, pinces inchangées) et nouvelles clés [subagents] default_max_steps / default_wall_time_secs. Parce que le catalogue d'outils fait partie du préfixe d'invite épinglé par session (docs/CACHE.md), la mise à niveau remplit à nouveau le préfixe KV une fois par session.
  • Prose TUI — messages des utilisateurs, réponses de l'assistant et raisonnement/réflexion — s'enroule désormais sur toute la largeur du contenu sur les terminaux larges, correspondant cellules d'outil/d'état, au lieu de s'arrêter à un rail de 105 colonnes qui laissait un marge morte à droite sur les écrans ultra-larges (#5436).
  • Les invites de compétences configurées sont stables à travers les racines de session et le fonctionnement systèmes : seules les racines configurées sur mesure cachent leur chemin physique, ordinaire l'espace de travail/les compétences globales gardent un chemin détectable et sécurisé pour la confidentialité, avertissement les remplacements tiennent compte des limites (y compris les chemins Unix non UTF-8), et Les séparateurs Windows s'affichent sous la forme /. L'invite de compétences fait également 50 octets plus léger sans augmenter le plafond du contrat d'exécution (#5492, #5473).
  • Les requêtes du classificateur de routeur automatique acceptent [auto.router] timeout_secs, tandis que en préservant la valeur par défaut existante lorsque la clé est absente (#5494).
  • Chaque tâche ci.yml dispose désormais d'un délai d'attente explicite de 10 à 90 minutes, adapté à sa charge de travail, limitant les coureurs assignés obsolètes au lieu d'hériter Valeur par défaut de six heures du GitHub (#5495).
  • Le shell Docs et les composants Web partagés acheminent désormais la copie localisée via le dos du dictionnaire dactylographié ; ce sont deux phases incrémentielles du #5337, pas l'achèvement de l'épopée complète (#5488, #5490).
  • Dépendance : rusqlite 0.40.2 (#5391).
  • Documentation : références obsolètes de niveau A/B/C, valeurs par défaut du fournisseur, module les descriptions et les ancres de ligne correspondent désormais au code actuel (#5481).

Ajouté

  • [transcript] prose_measure (entier positif, facultatif) : majuscules, prose envelopper N colonnes pour les propriétaires qui souhaitent une mesure de lecture limitée sur terminaux ultra-larges. 0 ou absent conserve toute la largeur ; négatif ou les valeurs non entières sont rejetées avec une erreur de configuration claire. Outil, différentiel, et les cellules d'état n'héritent jamais du plafond (#5436).
  • Localisation : traductions README pour Français, Deutsch, 繁體中文, हिन्दी, Türkçe, Italiano, Polski, العربية et Català rejoignent les neuf existants (#5451); codewhale.net routes fr, de, ca, hi, tr, it, pl et ar (avec plomberie dir="rtl") comme paramètres régionaux partiels (#5453).
  • Docs : section README Integrations (y compris le plugin DeepSeek Harness dsh path, docs/INTEGRATIONS_DSH.md) localisé dans tous les README ; Conservation des RFC l'hybride à révision automatique déterministe d'abord (# 5427); Parité Claude Code référence pour les agents/workflows/plugins/compétences (docs/design/CLAUDE_CODE_PARITY.md) ; config.example.toml / SUBAGENTS.md / TOOL_LIFECYCLE.md remis en conformité avec le code (#5447).
  • Intégration dsh : la palette Codewhale est appliquée via le bundle profil via le overrideTokens documenté de DSH (activé par défaut ; codewhale integrations dsh update --skin false l'éteint), en remplaçant le skin CSS exporté 0.9.8 que les variables de corps en ligne de DSH ont remplacé (docs/design/DSH_BUNDLE_SKIN.md, docs/INTEGRATIONS_DSH.md) (#5469).
  • Intégration dsh : une scène océanique ambiante derrière l'interface utilisateur Web DSH — lente des silhouettes de baleines, un banc de poissons glyphes ><>, des bulles — dessinées sur un toile sous un voile translucide de la palette Codewhale, plus un explicite verrouillage réactif WHALE BROTHERS / CODEWHALE × DEEPSEEK HARNESS ; lumière et sombre, ~ 30 ips plafonné, en pause lorsqu'il est caché, une image statique sous prefers-reduced-motion ; activé par défaut avec le skin, codewhale integrations dsh update --ocean false l'éteint (#5484).
  • Flotte : l'observation des agents est visible : un badge de ligne de liste, un bloc Calques dans détail de l'agent, et une section doctor « Couches de liste de flotte » (JSON operate_fleet.roster.multi_layer), dans les 15 paramètres régionaux TUI. Effondrement des calques et la migration [fleet.profiles] reste pour 0.9.10 (#5098).
  • Bac à sable : les conteneurs bwrap reçoivent les essentiels --dev/--proc/--tmpfs plus racines supplémentaires configurables (bwrap_ro_roots / bwrap_dev_roots) donc les chaînes d'outils qui se trouvent en dehors de l'espace de travail restent accessibles en lecture seule (#5410).
  • Tests : crates/tui/tests/README.md indique le trajet assemblé sans clé règle et mappe les éléments d'acceptation du tuteur de révision automatique au moteur des voyages qui les exercent (#5361).
  • Le point de terminaison par défaut d'OrcaRouter est classé comme facturation d'agrégateur surface, de sorte que les rapports sur les prix et les coûts de session utilisent la bonne facturation au lieu de le traiter comme un fournisseur propriétaire (#5493).
  • Dépendances : ratatui 0.30.2, cette erreur 2.0.20.

Supprimé

  • Intégration dsh : le fichier skin exporté-CSS et son statut "skin export" ligne (remplacée par le skin overrideTokens appliqué en bundle, #5469).
