Baleine-code v0.10.2

Qu'y a-t-il dans v0.10.2

Codewhale v0.10.2 ajoute une vue animée pour animaux de compagnie (/pet on), une œuvre de terminal en direct dock, couleurs du compositeur par chat (/color) et une note unique sur le premier commencer après une mise à jour indiquant ce qui a changé. Il clôture trois sessions chemins de perte de données et fuite de session codewhale web ; ajoute le Runtime par défaut emplacements des sockets du démon dans la liste de refus du bac à sable ; contient un curl ou un wget qui télécharge un informations d'identification ; refuse les commandes shell contenant de l'Unicode invisible ; garde le Le bac à sable Linux fonctionne lorsqu'un répertoire d'informations d'identification caché est un lien symbolique ; et réduit le travail de redessinage TUI inactif. /undo reprend un tout demande, y compris des invites longues et multilignes. exec --auto explique son Accès complet par défaut, honore un bac à sable explicitement plus strict et enregistre les exécutions activées par les outils et leurs reçus d'échec. Les runtimes locaux apparaissent pendant intégration, /diff fonctionne en dehors d'un référentiel Git, route des réponses de DeepSeek ne rejette plus l'historique des outils rejoué et les correctifs des contributeurs améliorent le jeton comptabilité, listes de modèles de relais, réponses localisées et lanceur Windows conseils. Le travail délégué se poursuit sans tour ou limite de temps inventé par le modèle, et les étapes de flux de travail indépendantes peuvent se poursuivre après l'échec d'un autre enfant.

Installer

Recommandé — version officielle du GitHub

Nouvelle installation macOS/Linux (binaires avec somme de contrôle de cette version) :

curl -fsSL https://codewhale.net/install.sh | CODEWHALE_VERSION="v0.10.2" sh
"$HOME/.local/bin/codewhale" --version

Pour Windows, utilisez le programme d'installation ou l'archive correspondant ci-dessous. Pour un existant installation directe, exécutez codewhale update ; il imprime le chemin de l'exécutable et conserve les versions plus récentes. Si le répertoire d'installation est occupé par une autre build, utilisez la migration d'un nouveau répertoire dans [le guide d'installation] (https://github.com/codewhale-hq/CodeWhale/blob/main/docs/INSTALL.md).

Emballage secondaire — npm et Cargo

npm install -g codewhale
# or build from source
cargo install codewhale-cli --locked

Le wrapper télécharge les ressources de commande codewhale et codew correspondantes de cette version. Les deux contiennent le même runtime compilé.

Docker / GHCR

docker run --rm -it \
  -e DEEPSEEK_API_KEY="$DEEPSEEK_API_KEY" \
  -v codewhale-home:/home/codewhale/.codewhale \
  ghcr.io/codewhale-hq/codewhale:v0.10.2

L'image expose le même runtime que codewhale et codew. Le La balise latest est également mise à jour lors de la sortie.

Cargaison (Linux / macOS)

cargo install codewhale-cli --locked

Le package Cargo installe codewhale. Cargo ne peut pas créer de deuxième commande alias d'une cible binaire ; les utilisateurs qui souhaitent une orthographe plus courte peuvent ajouter un Lien symbolique codew vers cet exécutable installé. Le npm, Homebrew, archive, Shell-installer et les canaux de conteneur installent directement les deux noms de commande.

Téléchargement manuel — archives de la plateforme (recommandé)

Chaque archive ci-dessous contient le même runtime sous codewhale et Noms des commandes codew, plus un script d'installation :

| Plateforme | Archives | Script d'installation | |---|---|---| | Linuxx64 | codewhale-linux-x64.tar.gz | install.sh | | LinuxARM64 | codewhale-linux-arm64.tar.gz | install.sh | | Android ARM64 (Termux) | codewhale-android-arm64.tar.gz | install.sh | | macOS x64 | codewhale-macos-x64.tar.gz | install.sh | | MacOS BRAS | codewhale-macos-arm64.tar.gz | install.sh | | Windows x64 (installateur) | CodeWhaleSetup.exe | Configuration du NSIS | | Windowsx64 | codewhale-windows-x64.zip | install.bat | | Windows x64 (portable) | codewhale-windows-x64-portable.zip | — | | WindowsARM64 | codewhale-windows-arm64.zip | install.bat | | Windows ARM64 (portable) | codewhale-windows-arm64-portable.zip | — |

Unix (Linux/MacOS) :

tar xzf codewhale-<platform>.tar.gz
cd codewhale-<platform>
./install.sh

Fenêtres :

  • Pour le chemin du programme d'installation, exécutez CodeWhaleSetup.exe ; il installe codewhale.exe, codew.exe et codewhale.bat sous %LOCALAPPDATA%\Programs\CodeWhale\bin, ajoute ce répertoire au PATH de l'utilisateur actuel et crée un raccourci du menu Démarrer qui préfère Terminal Windows (wt.exe) une fois installé.
  • Extrayez l'archive de votre machine : codewhale-windows-x64.zip ou codewhale-windows-arm64.zip
  • Double-click codewhale.bat (pas le .exe brut) pour lancer
  • Exécutez install.bat pour copier les binaires et le lanceur sur %USERPROFILE%\bin
  • Ajoutez %USERPROFILE%\bin à votre CHEMIN

L'archive Windows portable ignore le script d'installation : extrayez et exécutez codewhale.bat à partir de n'importe quel répertoire. Le programme d'installation NSIS n'est actuellement pas signé et peut déclencher Windows SmartScreen jusqu'à ce qu'un certificat de signature soit connecté au pipeline de publication.

Chaque plate-forme dispose également de codewhale-<platform> nus et non archivés et Actifs codew-<platform>. Les sept noms de fichiers codewhale-tui-<platform> attachés au v0.9.5 sont des copies de compatibilité à octets identiques utilisées uniquement pour permettre v0.9.4 clients déjà installé découvre et traverse ce binaire unique transition; les installateurs actuels n’exposent pas de troisième runtime. L'héritage NPM le package deepseek-tui est obsolète et n’est pas republié. Pour migrer à partir des noms binaires hérités v0.8.x, voir docs/REBRAND.md.

Vérifier (recommandé)

Téléchargez les manifestes de somme de contrôle de cette version et vérifiez :

# Linux — archive bundles
sha256sum -c codewhale-bundles-sha256.txt --ignore-missing

# Linux — individual binaries
sha256sum -c codewhale-artifacts-sha256.txt --ignore-missing

# macOS
shasum -a 256 -c codewhale-bundles-sha256.txt --ignore-missing
shasum -a 256 -c codewhale-artifacts-sha256.txt --ignore-missing
