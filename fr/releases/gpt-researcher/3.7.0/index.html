chercheur gpt v3.7.0

Contexte plus intelligent, aucune intégration requise

GPT Researcher sélectionne désormais le contexte qu'il envoie au LLM en fonction de l'utilité et non de la similitude. Chaque passage récupéré pour une question de recherche est noté par Jev sur son utilité pour répondre à cette question, et seuls les passages qui aident sont conservés.

Sur un benchmark de 28 tâches de recherche rejouées sur des sources identiques :

<img width="3200" height="1800" alt="image-1790437831580" src="https://github.com/user-attachments/assets/c2a7b305-2e60-4709-ad9c-8af09e297f9f" />

Rien n'est requis. Avec l'ensemble TYPESAFE_API_KEY, Jev est utilisé. Sans un, ou si un Jev appelle échoue, GPT Researcher revient au classement des mots clés locaux (BM25), vous n'avez donc plus besoin d'un fournisseur d'intégrations pour la recherche standard. Le chat de rapport utilise le même filtre.

  • Documents : https://docs.gptr.dev/docs/gpt-researcher/gptr/context-filter
  • Benchmark, méthode et code : evals/context_filter/

⚠️ Modifications à noter

  • Python 3.12+ est désormais requis.
  • Filtre contextuel par défaut : sans clé TypeSafe, la valeur par défaut est désormais le classement des mots clés au lieu de intégrations. Il correspondait ou battait les intégrations sur chaque mesure du benchmark. Pour garder l'ancien comportement, définissez CONTEXT_FILTER=embeddings.

Également dans cette version

  • Plugins Retriever : expédiez un moteur de recherche comme son propre package via le point d'entrée gpt_researcher.retrievers (#2154)
  • Correction du WebSocket frontend ouvrant une deuxième connexion lors d'une nouvelle exécution de recherche (#2159)
  • Les sections multi-agents ne répètent plus le contenu des autres (#2158)
  • Actifs frontend auto-hébergés, pas de CDN tiers (#2082)
  • Plus de 25 correctifs communautaires concernant les récupérateurs, les grattoirs et la recherche approfondie
  • Docs : page d'accueil repensée, classement actuel des hallucinations des modèles, versions corrigées sur de nouvelles installations

Installer : pip install -U gpt-researcher (0.16.0)
