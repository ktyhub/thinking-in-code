Agent-Reach v1.6.1

#Agent-Reach v1.6.1

Chinois :

  • Plusieurs "erreurs sont signalées bien qu'elles puissent être vérifiées" ou "affichées avec succès mais le contenu est vide" qui apparaîtraient dans l'ensemble de la recherche du réseau, Reddit, Xiaohongshu et le site B 1.6.0. Cette version a été entièrement corrigée.
  • Lorsqu'un autre logiciel de votre ordinateur occupe le port du navigateur, vous pouvez modifier le port sans fermer ce logiciel.
  • Lorsque la copie de connexion échoue, on vous dira la vérité et vous ne prétendrez plus réussir.
  • Les liens avec des symboles spéciaux dans Xiaohongshu sous Windows peuvent être ouverts normalement.

Anglais :

  • Plusieurs cas 1.6.0 où la recherche sur le Web, Reddit, Xiaohongshu ou Bilibili échouait alors que le contenu était accessible, ou signalaient un succès avec un contenu vide, sont corrigés.
  • Lorsqu'un autre programme sur votre ordinateur utilise le port du navigateur, Agent Reach peut en utiliser un autre ; vous n'êtes pas obligé de fermer ce programme.
  • Une copie de connexion qui échoue l'indique désormais au lieu de signaler le succès.
  • Sous Windows, les liens Xiaohongshu avec des caractères spéciaux s'ouvrent correctement.

Chinois (détails techniques) :

  • Rechercher sur l'ensemble du réseau : Les requêtes doivent toutes être marquées du logo agent-reach/<版本号> pour éviter d'être interceptées par la protection Exa (#877).
  • Reddit : lorsque les outils sur site échouent temporairement (par exemple, renvoyer des pages Web au lieu de données), passez automatiquement à la recherche et à la lecture de pages Web publiques (#880).
  • Xiaohongshu : Adapté au format de retour d'OpenCLI 2.0, la lecture n'est plus « réussie mais le contenu est vide » ; la recherche et le commentaire ne renvoient plus de données vides lorsqu'il n'y a aucun résultat (#861, #895).
  • Station B : Si aucune connexion valide n'est enregistrée après avoir scanné le code QR, la connexion réussie ne sera plus affichée ; l'invite sera modifiée pour exécuter agent-reach login bilibili (#866, #883).
  • Le port du navigateur dédié peut être modifié en : agent-reach configure browser-port <端口>, utilisé lorsque le 9222 est occupé par un autre logiciel (#848).
  • Copier la connexion : « 0 élément copié » ne sera plus enregistré lorsque le programme en arrière-plan du navigateur n'est pas ouvert ; une erreur sera clairement signalée lorsqu'aucun élément login <渠道> --import-existing n'est copié manuellement (#879).
  • Windows : les notes de Xiaohongshu avec & dans le lien peuvent être lues et visualisées normalement (#860).

Anglais (technique):

  • Recherche Web : chaque requête s'identifie comme agent-reach/<version>, donc la façade Cloudflare d'Exa ne la bloque plus (#877).
  • Reddit : lorsque l'outil de site échoue de manière transitoire (par exemple, il renvoie du HTML au lieu de données), la recherche et la lecture reviennent au Web public (#880).
  • Xiaohongshu : les résultats OpenCLI 2.0 sont mappés, donc la lecture ne réussit plus avec des champs vides ; la recherche et les commentaires ne renvoient plus une ligne vide lorsqu'il n'y a aucun résultat (#861, #895).
  • Bilibili : une connexion QR qui n'a enregistré aucun identifiant utilisable n'est plus signalée comme réussie, et l'indice indique désormais agent-reach login bilibili (#866, #883).
  • Le port du navigateur dédié est configurable avec agent-reach configure browser-port <port>, lorsqu'un autre outil contient 9222 (#848).
  • Réutilisation des connexions : pas d'enregistrement de "0 cookies copiés" lorsque le pont du navigateur est en panne ; un login <channel> --import-existing explicite qui ne copie rien échoue désormais clairement (#879).
  • Windows : les liens de notes Xiaohongshu contenant & peuvent être lus et leurs commentaires chargés (#860).
