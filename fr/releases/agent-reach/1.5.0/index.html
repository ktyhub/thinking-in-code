#Agent-Reach v1.5.0

Quelle est cette version ?

Agent Reach a été mis à niveau de « Collection d'outils » vers « Couche de capacités » : Chaque plate-forme = liste préférée + liste backend ordonnée alternative. La méthode d'accès la plus stable à l'heure actuelle est sélectionnée, installée et vérifiée pour vous grâce à des tests réels - vous n'aurez pas à vous soucier du remplacement des méthodes d'accès. Toutes les sélections de cette version sont basées sur des tests réels sur machine effectués en 2026-06 (32 tests de bout en bout).

Modifications du routage de la plate-forme

| Plateforme | La route actuelle | |------|--------------| | Xiaohongshu | OpenCLI (bureau, réutilisation de l'état de connexion du navigateur sans configuration) ▸ xiaohongshu-mcp (serveur, scan du code) ▸ xhs-cli (disponible en stock, l'amont a été arrêté) | | Reddit | OuvrirCLI ▸ rdt-cli. Calibre honnête : Reddit n'a pas de chemin de configuration zéro (l'interface anonyme a été complètement bloquée et le système d'approbation officiel API est requis), et vous devez vous connecter | | Gare B | bili-cli (Recherche/Populaire/Détails, pas besoin de se connecter) ▸ OpenCLI (Sous-titres) ▸ Recherchez API pour le savoir. yt-dlp a quitté le site B (complètement intercepté par le contrôle des risques 412, la dernière version + proxy + cookie testés sont invalides) ; yt-dlp continue de servir YouTube | | Twitter | twitter-cli Gatekeeper (stable en mesure réelle)▸ Alternative OpenCLI, détection et nouvelle tentative |

Le médecin est devenu un véritable examen physique

  • Exécute réellement la détection des commandes au lieu de simplement examiner l'existence des fichiers - peut identifier "installé mais cassé" (typique : le lien venv est rompu après la mise à niveau du système Python) et fournir des prescriptions de réinstallation qui peuvent être directement copiées
  • Signaler quel chemin est actuellement utilisé par chaque plate-forme multi-backend (active_backend de doctor --json)
  • L'effondrement d'un canal ne fera plus échouer l'examen physique dans son intégralité.

Stockage OpenCLI (backend de bureau)

agent-reach install --channels opencli : npm s'installe automatiquement, cliquez une fois sur le magasin d'extensions Chrome (modèle de sécurité Chrome, ne peut pas être cliqué au nom de). Réutilisez le statut de connexion de votre navigateur - vous pouvez l'utiliser directement après avoir parcouru Xiaohongshu ou vous être connecté à Reddit. Nécessite un ordinateur de bureau + Chrome, le serveur est automatiquement ignoré.

Expérience d'installation et de mise à jour

  • Installation en une phrase : 帮我安装 Agent Reach：https://raw.githubusercontent.com/Panniantong/agent-reach/main/docs/install.md
  • Mettre à jour une phrase : 帮我更新 Agent Reach：https://raw.githubusercontent.com/Panniantong/agent-reach/main/docs/update.md (ontologie + outils amont + compétences à rattraper d'un coup)
  • Réécriture des compétences : "Recherche à l'échelle du réseau" et "Aidez-moi à rechercher" sont déclenchés de manière fiable ; une fois que l'agent a terminé un gros travail, il vérifiera la version. S'il y a une nouvelle version, il fera un rappel à la fin (pas d'interruption, pas de harcèlement répété)
  • Correctif check-update : ne demande plus par erreur "mettre à jour" lorsque la version locale est antérieure à la dernière version (pour éviter une rétrogradation)

Qualité

  • Test 107 → 162 (Couverture complète du contrat/scénario de lien rompu/matrice de priorités backend/comparaison de versions)
  • Après trois séries d'examens contradictoires (les 12 résultats ont été corrigés) : des problèmes tels que le blocage du routage Twitter, les invites de rétrogradation de la montre, les commutateurs de proxy morts, etc. qui pourraient vraiment nuire aux utilisateurs ont été résolus.
  • Réussite des 32 tests de machine réelle de bout en bout sur 13 canaux

Remerciements

En amont nouvellement inclus : OpenCLI (@jackwener), xiaohongshu-mcp (@xpzouying).
