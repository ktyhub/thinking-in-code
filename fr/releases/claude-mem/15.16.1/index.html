#claude-mem v15.16.1

Correctif critique

  • Le manuel enregistre à nouveau le travail dans les projets avec des sessions manuelles plus anciennes. Dans v15.16.0, save_memory (et POST /api/memory/save) renvoyait HTTP 500 avec UNIQUE constraint failed: sdk_sessions.memory_session_id dans tout projet dont la session manuelle a été créée avant 15.16.0 avec une forme d'ID de session plus ancienne. Chaque sauvegarde de ce projet a échoué. claude-mem trouve et réutilise désormais cette ancienne session au lieu d'essayer de créer un doublon. Les sessions supprimées reçoivent toujours un nouvel identifiant, comme dans 15.16.0 (#5842).

Si vous utilisez 15.16.0, mettez à jour vers 15.16.1.

Nouveau (tous deux désactivés par défaut)

  • Désactiver les compétences groupées : répertoriez les noms de compétences dans CLAUDE_MEM_SKILLS_DISABLED dans ~/.claude-mem/settings.json, sous forme de chaîne séparée par des virgules ou de tableau JSON (par exemple "make-plan,do,smart-explore"). La liste est réappliquée après les installations, les réparations et les mises à jour du marché ; les nouvelles compétences restent activées à moins que vous ne les nommiez (#5837, merci @liuyinchu, ferme le #5132).
  • Ancres de ligne dans le contexte de fichier : définissez CLAUDE_MEM_LINE_ANCHORS_ENABLED sur "true" et les observations passées sur un fichier pointent sur la ligne où se trouve actuellement ce code (@L123), ou dites (code changed since) lorsqu'il s'éloigne. Rien n'est deviné. Avec le réglage désactivé, rien n'est enregistré et la sortie du hook est inchangée (#5841, merci @devkancheti4-design, ferme le #4943).

Correctifs

  • OpenClaw : le programme d'installation fonctionne à nouveau sur OpenClaw 2026.11.2, et OpenClaw actuel enregistre les invites, injecte le contexte et résume les sessions sans le hook before_agent_start supprimé. Les anciennes versions d'OpenClaw se comportent comme avant (#5840, correctifs #5838, rapportés par @JesseFranzen).
  • Désinstallation Warp : npx claude-mem uninstall supprime désormais le serveur MCP claude-mem que install --ide warp ajoute à ~/.warp/.mcp.json, au lieu de le laisser pointer sur le plugin supprimé (#5839, merci @tanishqbaweja).
  • ID de télémétrie : l'enregistrement d'une décision de consentement (invite du programme d'installation, telemetry enable, telemetry disable) conserve l'ID anonyme enregistré, de sorte qu'une installation n'apparaît plus comme deux. La divulgation telemetry enable répertorie désormais les événements réellement envoyés (#5836, merci @wiesenthal).

changelog complet : https://github.com/thedotmack/claude-mem/compare/v15.16.0...v15.16.1
