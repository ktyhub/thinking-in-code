d2 v0.6.9

Correctif Publié5 févr. 2025 Sourced2lang/d2 Anglais original

Cette page est traduite automatiquement. Le texte anglais original fait foi.

#d2v0.6.9

Fonctionnalités 🚀

  • Animations : style.animated: true est supporté sur les formes #2250
  • Les connexions prennent désormais en charge link #1955
  • Vars : les variables dans les blocs de démarques sont remplacées #2218
  • Markdown : les tables aromatisées Github fonctionnent dans les blocs md #2221
  • Rendu : ajoute des pointes de flèches de boîte #2227
  • d2 fmt prend désormais en charge un indicateur --check #2253
  • CLI : la sortie PNG vers la sortie standard est prise en charge avec --stdout-format png - #2291
  • Globs : les filtres &connected et &leaf sont implémentés #2299
  • CLI : ajoutez --no-xml-tag pour l'intégration HTML directe #2302
  • CLI : play cmd ajouté pour ouvrir l'entrée d2 dans l'aire de jeux en ligne #2242

Améliorations 🧹

  • Composition : les liens pointant vers son propre forum sont purgés #2203
  • Syntaxe : les mots-clés réservés doivent être sans guillemets #2231
  • Latex : Les barres obliques inverses dans les blocs Latex ne s'échappent pas #2232
    • C'est un changement radical. Auparavant, les blocs Latex nécessitaient d'escaping la barre oblique inverse. Alors pour les anciennes versions de D2, vous devez supprimer les barres obliques inverses en excès.
  • Liens : les liens de schéma d'URL non http sont pris en charge (par exemple x.link: vscode://file/) #2237
  • Compilateur : erreur de mots-clés réservés avec valeurs manquantes au lieu de ne rien faire en silence #2251
  • Rendu : les sorties SVG sont conformes aux normes HTML plus strictes, par ex. aucun identifiant en double #2273
  • Thèmes : les noms de thèmes sont systématiquement masqués #2322
  • Nears : les rapprochements constants évitent les collisions avec les routes de bord #2327

Corrections de bugs ⛑️

  • Imports : correctifs utilisant des substitutions dans les valeurs icon #2207
  • Markdown : corrige les esperluettes dans les URL en markdown #2219
  • Globs : corrige le cas extrême où les globs avec des tableaux importés créeraient des tableaux vides #2247
  • Diagrammes de séquence : corrige l'alignement des notes lorsque les messages personnels sont au-dessus #2264
  • Null : corrige nulling une connexion avec une syntaxe absolue #2318
  • Dégradés : fonctionne avec les remplissages de connexion #2326
  • Latex : corrige le doublement des antislashs lors des analyses successives #2328
