Faits saillants

Cette version contient 717 commits de 307 contributeurs (96 nouveaux) !

  • Performances DeepSeek-V4.1-Flash : la méga attention FlashMLA avec le cache KV compressé NVFP4 V4.1 est désormais la valeur par défaut du SM100 (#56935) ; Logits MQA clairsemés DeepGEMM pour l'indexeur (#56254) et Mega-Gate fusionnant la porte GEMM avec une sélection experte (#56266) ; les limites du décodeur fusionnent la préparation d'entrée TP all-reduce, mHC (#57643) et la finalisation MoE (#58586) ; un WO-A fusionné en petits lots avec RoPE inverse et quant MXFP8 sur SM100/SM103 (#58634) ; le MXFP8 wo_b GEMM fusionné avec la réduction-diffusion parallèle à la séquence (#57428) ; Engram wkv partagé entre les rangs TP (#58678) et les tables hôtes Engram partagées par défaut entre les répliques DP colocalisées (#57651) ; graphiques CUDA de l'encodeur pour la tour de vision (#56625) ; et la relecture limitée SWA qui maintient le KV à fenêtre coulissante hors de la mise en cache des préfixes (#56227).
  • Redémarrage rapide : le nouveau vllm preload CLI lance le démon de cache de poids qui maintient les poids post-quantifiés résidents dans la mémoire du GPU lors des redémarrages du moteur (#56680), désormais avec le parallélisme des données (#57386), les projets de modèles MTP (#57312), un point de terminaison /health (#58552) et une attente de préparation (#58370). Les instantanés expérimentaux de moteur initialisé (vllm snapshot create/restore) utilisent CRIU pour restaurer un moteur TP1 entièrement initialisé (#51360).
  • Model Runner V2 et décodage spéculatif : décodage spéculatif de modèle préliminaire (#43091) et processeurs logits personnalisés (#56497) sur Model Runner V2 ; le nouveau dessinateur LiLiCorr (#57934) ; planification asynchrone pour DFlash (#58065) ​​avec le précalcul contextuel K/V capturé dans le projet de graphique CUDA (#57632) ; Vérification adaptative DSpark pour Gemma4 (#57263) et décodage de longueur variable pour Kimi-K3 (#52988) ; une cible DCP avec un brouillon DSpark non-DCP (#56723) ; et la mémoire MoE est désormais prise en compte lors du profilage MRV2, évitant ainsi les MOO sur les déploiements WideEP (#57270, #58411).
  • Service à grande échelle : backend EP all2all équilibré MoonEP via --all2all-backend moonep (#52101), parallélisme de contexte de pré-remplissage avec parallélisme de données (#57075), réduction de la dispersion multimem à faible SM pour SM100/SM103 (#55072), DeepEPv2 avec parallélisme de séquence (#57210) et EPLB avec chevauchement d'experts partagés (#57236), prise en charge du sharding. Backend de transfert de poids NCCL M2N pour RL (#51520) et détection de contre-pression de déchargement KV (#50045).
  • Contrôles de planification : --max-num-active-seqs limite l'admission RUNNING indépendamment de max_num_seqs (#56758), --long-prefill-token-threshold s'adapte désormais au nombre de pré-remplissages en attente au lieu de fragmenter une requête isolée (#57951, #58459), la file d'attente a été retravaillée afin que les requêtes contenant déjà des blocs KV soient planifiées en premier (#58947), et le blocage du connecteur KV + MTP sous la pression KV a été corrigé. (#57104).
  • Renforcement HiSparse : lignes de vérification MTP résolues avec un noyau de résidence d'union (#59235), correction de l'effondrement de l'acceptation MTP sous les graphiques COMPLETS (#59309), pas de pages GPU sans support de l'hôte (#59036), correction d'un livelock de préemption de préremplissage fragmenté (#59494), taille du cache KV à partir des groupes alloués par HiSparse (#59450) et corrections de publication de préfixe d'hôte et d'adoption de préfixe GPU. (#59007, #59282).
  • Sécurité : les requêtes mm_processor_kwargs et media_io_kwargs sont rejetées sauf si --trust-request-mm-kwargs est défini (#58830) ; Les clés supplémentaires du cache de préfixe sont étiquetées par source afin qu'un nom LoRA et un cache_salt ne puissent plus entrer en collision (#51899), et le chemin LoRA fait partie du hachage de bloc (#59335) ; Les entrées de cache de récepteur multimodales obsolètes ne peuvent plus remplacer de nouvelles charges utiles (#57833).
  • Modifications récentes : kwargs multimodaux par demande fermés (#58830) ; tokenizer_mode="slow" supprimé (#58545) ; --enable-mamba-fine-grained-prefix-cache renommé --enable-mamba-shared-prefix-checkpoint (#57382) ; quantification en ligne via quantization="fp8" remplacée par le raccourci fp8_per_tensor (#53585) et quantification en ligne silencieuse Quark supprimée (#51800) ; le backend AllSpark INT8 W8A16 supprimé (#58001) ; --enforce-eager désactive désormais également le préchauffage du noyau JIT (#58197) ; Graphiques XPU activés par défaut avec VLLM_XPU_ENABLE_XPU_GRAPH supprimé (#51600).

Dernières modifications et dépréciations

  • Les requêtes par requête mm_processor_kwargs et media_io_kwargs renvoient désormais une erreur à moins que le serveur ne soit démarré avec --trust-request-mm-kwargs ; --mm-processor-kwargs / --media-io-kwargs au niveau du serveur et LLM hors ligne sont inchangés (# 58830).
  • tokenizer_mode="slow" a été supprimé ; il se comportait déjà comme "hf" sous Transformers v5 (#58545).
  • --enable-mamba-fine-grained-prefix-cache a été renommé --enable-mamba-shared-prefix-checkpoint (#57382).
  • La quantification en ligne via quantization="fp8" redirige désormais vers le raccourci en ligne fp8_per_tensor (#53585) ; La quantification en ligne silencieuse MXFP4 spécifique à Quark a été supprimée au profit de la quantification en ligne API (#51800).
  • Le backend AllSpark INT8 W8A16 GEMM a été supprimé (#58001). L'option return_assistant_tokens_mask de /render et le champ de réponse assistant_tokens_mask ont été supprimés (#57520).
  • VLLM_PLE_CPU_OFFLOAD a été supprimé ; utilisez --engram-config (n° 57937). VLLM_XPU_ENABLE_XPU_GRAPH a été supprimé et les graphiques XPU sont activés par défaut (#51600).
  • La forme de --collect-detailed-traces séparée par des virgules a été supprimée ; utilisez la syntaxe de liste (#55702).
  • Nouveaux paramètres par défaut : --enforce-eager désactive également le préchauffage du noyau JIT sauf si la tolérance aux pannes est activée (#58197, #58593) ; VLLM_BATCH_INVARIANT=1 utilise des graphiques CUDA sécables sans torch.compile (#57586) et désactive le parallélisme de séquence et le TP asynchrone (#56377) ; La relecture limitée DeepSeek-V4.1 SWA est activée (#56227) sauf sur ROCm (#57906) ; Les tables d'hôtes Engram sont partagées entre les répliques DP colocalisées lorsque cela est possible (#57651) ; La grande attention FlashMLA est la valeur par défaut de DeepSeek-V4.1 sur SM100 (#56935) ; l'AITER w4a4 ASM GEMM est désactivé par défaut sur ROCm (#57055).
  • Model Runner V1 + PP > 1 + planification asynchrone + sortie structurée est désormais rejetée au démarrage (#56250) ; json_object est rejeté lors de la validation avec le backend outlines (#57743).
  • transformers a désormais une limite supérieure dans les exigences (#59614).
