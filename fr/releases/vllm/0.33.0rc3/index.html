#vllm v0.33.0rc3

#v0.33.0

Faits saillants

Cette version contient 927 commits de 389 contributeurs (122 nouveaux) !

  • Nouveaux modèles : Reflection Beam-1.0 (501B MoE, 23B actif) avec son rédacteur DFlash2 (#62074), Yandex AliceAI-Foundation-80B-A3B (#57963), Recursive Flint (40B MoE, 2,5B actif) (#62938), Muse Spark Open (#61879), Step-5 Preview (#61727, #63147), NVIDIA Alpamayo 2 Super (#62957), Nemotron-Labs Dory1.0-4B (#60149), Nemotron Parse 3.5 (#61651), MiniCPM-OCR 1.0 (#63095), Domyn Edge (#62544) et le récupérateur de documents visuels ColUltraVBERT (#62237).
  • PyTorch 2.14 : vLLM est mis à niveau vers PyTorch 2.14.0, avec torchvision 0.29.0 et Triton 3.8.0 (#52183).
  • CUDA 12.9 abandonné : les roues de version et les images sont uniquement CUDA 13.0. Les roues CUDA 12.9 et les images -cu129 / -cu129-ubuntu2404 ne sont plus publiées (#62575) ; utilisez plutôt les artefacts CUDA 13.0 par défaut.
  • Roue CUDA stable ABI libtorch : la roue CUDA est désormais stable ABI avec libtorch.
  • Image AWS EFA : une nouvelle image vllm/vllm-openai:v0.33.0-efa (x86_64 et aarch64) regroupe les bibliothèques AWS EFA et la version EFA du moteur de transfert Mooncake, pour le transfert KV et le service multi-nœuds sur les instances EC2 compatibles EFA (#58768).
  • Alias ​​d'image vllm/vllm : chaque image de version est désormais également publiée sous le nom plus court de vllm/vllm, par ex. vllm/vllm:v0.33.0, vllm/vllm:v0.33.0-efa et vllm/vllm:v0.33.0-rocm.
  • Décodage spéculatif : le nouveau raffineur XPress pour les rédacteurs en diffusion de blocs tels que DFlash et DSpark (#54448) ; FLy, une politique de vérification avec perte opt-in avec débit de décodage 1.04-1.31x sur MI355X et B300 (#53987) ; DFlash/DSpark ne réserve plus d'emplacements de projet dans le budget des jetons, faisant passer DeepSeek-V4.1-Flash + DSpark sur GB300 de 1 373 à 3 390 tok/s de sortie dans le benchmark du PR (#59468) ; brouillon quantifié lm_head (draft_lm_head_quantization, décodage +18 % à la concurrence 1) (#59973) ; Les hachages de bloc d'anticipation afin que les accès au cache de préfixe EAGLE/MTP conservent leur dernier bloc, activé par défaut (#61589) ; et les brouillons MTP dans le backend de modélisation Transformers (#61270).
  • Décodage plus rapide sur NVIDIA : décodage spécialisé en latence opt-in sur GB300 pour Kimi-K3 (1.5-2x sur TP8/TP16, #61867) et DeepSeek-V4.1-Flash (étape de décodage 18.3 % plus rapide au lot 1, #61868) ; Les experts DeepSeek-V4/V4.1 MXFP4 fonctionnent en tant que bloc FP8 via Humming on Hopper (+9-21 % de décodage sur 4x H200, #61875) ; Décodage MLA clairsemé FA4 sur Blackwell (#55866) ; Pré-remplissage FlashInfer DCP sur trtllm-gen avec un TTFT moyen inférieur de 39 à 48 % à une entrée de 100 000 sur 8xB200 (#62029) ; et décoder uniquement des graphiques CUDA complets sous parallélisme de contexte de pré-remplissage MRV2 (2,6x sur impatient, # 62377).
  • AMD ROCm : l'image ROCm par défaut et les roues sont déplacées vers ROCm 10.0, avec ROCm 7.2 toujours publié sous le nom -rocm72 (#58761) ; Décodage MonoKernel via --monokernel pour DeepSeek-V4.1-Flash sur MI300X/MI325X (interactivité 2,32x P50 à concurrence 1, #60731) et sur chaque couche MI355X (#61082), et pour MiniMax-M3-MXFP4 sur MI355X (TPOT 16.6 % inférieur, #62712, #62994); le cache KV 3-4 bits ROCM_OCTAVE (4,6x les jetons KV de fp16 sur RX 7900 XTX, #59774) ; et activation gfx1250 pour gpt-oss-120b, DeepSeek-R1, DeepSeek-V4-Flash et MiniMax-M3 (#58800).
  • API et service : le point de terminaison /v1/decisions compatible OpenAI, activé par défaut pour les modèles de génération pris en charge (#60465, #61550) ; intégrations de jetons avec segmentation tardive en option sur /v1/embeddings (#61772, #63051, #60164) ; output_mode="derender" sur /inference/v1/generate (#60082) ; une grande poussée de parité frontale Rust, incluant plus de HTTP 500 sur les longues conversations (#62374) et les indicateurs non pris en charge échouant au démarrage (#62431) ; démarrage simultané d'un travailleur avec TP > 1 (#60028) ; et un chien de garde qui supprime les traces de pile des processus de moteur et de travail bloqués (#55700).
  • Modifications récentes : Suppression de Medusa et du spéculateur MLP (#61701) ; l'ancien exécuteur de graphes compilés Ray a été supprimé (#61712, #62228) ; --mamba-cache-mode obsolète (#60043) ; les requêtes envoyées pendant que la génération est en pause obtiennent désormais HTTP 503 (#51488) ; le connecteur NIXL nécessite NIXL 1.5 ou plus récent (#61032) ; LM Format Enforcer et --ir-op-priority sont obsolètes (#63423, #63371).

Construire

  • Les roues de sortie et les images sont uniquement CUDA 13.0 (#62575) ; nouvelle cible vllm-openai-efa Docker (#58768) ; ROCm 10.0 est l'image ROCm par défaut avec ROCm 7.2 comme -rocm72 (#58761) ; La roue ROCm se construit environ 4 à 7 fois plus rapidement (#63105).

Dernières modifications et dépréciations

  • Les roues et images CUDA 12.9 ne sont plus publiées (#62575).
  • Medusa et le spéculateur MLP ont été supprimés (#61701). L'ancien exécuteur de graphiques compilés Ray a été supprimé et VLLM_USE_RAY_V2_EXECUTOR_BACKEND a disparu ; RayExecutorV2 est le seul exécuteur Ray (#61712, #62228).
  • Obsolète : --mamba-cache-mode (aucun effet, #60043), --ir-op-priority (suppression dans v0.34.0, #63371) et le backend à sortie structurée LM Format Enforcer (opt-in dans v0.34.0, suppression dans v0.35.0, #63423).
  • Modifications de API : les requêtes envoyées pendant que la génération est en pause renvoient HTTP 503 (#51488) ; kv_transfer_params / ec_transfer_params déplacés vers le niveau supérieur de sortie de rendu (#61241) ; LoRA sur un modèle sans prise en charge LoRA échoue lors de la validation (#61884) ; le transfert de poids RL API utilise désormais ParamMeta, iter_full() et iter_local() (#63256) ; les scores de recherche de faisceau sont normalisés par la longueur générée (# 62928).
  • Frontend Rust : les indicateurs vllm serve non pris en charge et les champs de requête échouent au lieu d'être ignorés (#62431, #62434) ; les modèles de discussion fournis sur demande nécessitent --trust-request-chat-template (#62673) ; un tableau tools vide renvoie 400 (#63060).
  • Le connecteur NIXL nécessite NIXL 1.5 ou plus récent (#61032).
  • Vars d'environnement supprimés : VLLM_ROCM_AITER_MLA_DCP_VERIFY (#61628), VLLM_ROCM_USE_AITER_FP4_ASM_GEMM (#61278) et VLLM_ROCM_AITER_MEGA_MOE_FUSE_SHARED_EXPERTS (#61345) ; VLLM_ROCM_MONO_DECODE est remplacé par --monokernel (#61082).
  • Nouveaux paramètres par défaut : cache GLM-5.3-Flash FP8 KV (#61228) ; Hachages de blocs d'anticipation pour la mise en cache des préfixes EAGLE/MTP (#61589) ; Cohere2MoE double flux (#62101) ; Décodage MLA clairsemé FA4 à 16 têtes de requête ou moins par rang sur Blackwell (#55866) ; ROCm : AITER FP8/FP4 BMM pour MLA désactivé (#53123), pré-remplissage FlyDSL GDN (#60645), AITER topk_gating (#56226), rms_norm_gated (#60250) et cache K de l'indexeur MXFP4 sur CDNA4 pour DeepSeek-V4 (#63669).
