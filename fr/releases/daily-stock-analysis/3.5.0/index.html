daily_stock_analysis v3.5.0

Ajouté

  • 📊 Tiroir de rapport complet de l'interface utilisateur Web (Corrections n° 214) — la page d'historique ajoute un bouton « Rapport complet » pour afficher le rapport d'analyse Markdown complet dans un tiroir latéral ; nouveau point de terminaison GET /api/v1/history/{record_id}/markdown
  • 📊 Suivi des coûts LLM — tous les appels LLM (analyse, agent, revue de marché) enregistrés dans le tableau llm_usage ; le nouveau point de terminaison GET /api/v1/usage/summary?period=today|month|all renvoie l'utilisation agrégée des jetons par type d'appel et modèle
  • 🔍 Fournisseur de recherche SearXNG (Corrections #550) — solution de secours de recherche auto-hébergée sans quota ; priorité : Bocha > Tavily > Brave > SerpAPI > MiniMax > SearXNG
  • 🔍 Fournisseur de recherche Web MiniMax — MiniMaxSearchProvider avec disjoncteur (3 pannes → temps de recharge de 300 s) et double filtrage temporel ; configuré via MINIMAX_API_KEYS
  • 🤖 Découverte des modèles d'agent API — GET /api/v1/agent/models renvoie les déploiements de modèles disponibles (primary/fallback/source/api_base) pour le sélecteur de modèle de l'interface utilisateur Web
  • 🤖 Exportation et envoi de chat d'agent (#495) — exporter la conversation vers un fichier .md ; envoyer aux canaux de notification configurés ; nouveau POST /api/v1/agent/chat/send
  • 🤖 Exécution en arrière-plan de l'agent (#495) — l'analyse se poursuit lors du changement de page ; notification du badge à la fin ; annulation automatique du flux en cours lors du changement de session
  • 📝 Report Engine P0 — Validation du schéma Pydantic pour LLM JSON ; Modèles Jinja2 (markdown/wechat/brief) avec solution de secours héritée ; vérifications de l'intégrité du contenu avec nouvelle tentative ; mode bref (REPORT_TYPE=brief); comparaison des signaux historiques
  • 📦 Importation intelligente — importation multi-source depuis image/CSV/Excel/clipboard ; Vision LLM extrait le code+le nom+la confiance ; nom → résolveur de code (carte locale + pinyin + AkShare) ; confirmation à plusieurs niveaux de confiance
  • ⚙️ Configuration LiteLLM des actions GitHub — le workflow prend en charge LITELLM_CONFIG/LITELLM_CONFIG_YAML pour une configuration flexible du fournisseur d'IA
  • ⚙️ Refactor du moteur de configuration et système API (#602) — registre de configuration unifié, validation et exposition API
  • 📖 Guide de configuration LLM — nouveau docs/LLM_CONFIG_GUIDE.md couvrant la configuration à 3 niveaux, le démarrage rapide, Vision/Agent/dépannage

Corrigé

  • 🐛 analyze_trend rapporte toujours Aucune donnée historique (#600) — récupère désormais depuis DB/DataFetcher au lieu du get_analysis_context cassé
  • 🐛 Repli de la structure de la puce lorsque LLM l'omet (#589) — se remplit automatiquement à partir des données de la puce de la source de données pour un affichage cohérent sur tous les modèles
  • 🐛 Les points de tireur d'élite de l'historique affichent du texte brut (#452) — donne la priorité aux chaînes d'origine par rapport aux valeurs numériques compressées
  • 🐛 GitHub Actions ENABLE_CHIP_DISTRIBUTION configurables (#617) — n'est plus codé en dur, prend en charge le remplacement des vars/secrets
  • 🐛 La sauvegarde .env préserve les commentaires et les lignes vides — Les paramètres Web ne détruisent plus le formatage .env
  • 🐛 Corrections de découverte de modèles d'agent — le mode hérité inclut les fournisseurs natifs LiteLLM ; détection de source alignée sur le runtime ; Les déploiements de secours ne sont plus étendus par clé
  • 🐛 Sémantique de clôture précédente des actions Stooq US — n'utilise plus à mauvais escient le prix d'ouverture comme la clôture précédente
  • 🐛 Régression de prélecture du nom de stock — donne la priorité au STOCK_NAME_MAP local avant les requêtes à distance
  • 🐛 Calcul de limite haut/bas AkShare (#555) — statistiques d'analyse de marché fixes
  • 🐛 AkShare Tencent index de champ source et mappage de cotation ETF (#579)
  • 🐛 Pagination du cache des noms de stock Pytdx (#573) — empêche le débordement du cache
  • 🐛 ** Segmentation de rapport surdimensionnée PushPlus ** (#489) — segmente automatiquement le contenu long
  • 🐛 Annulation et changement de chat d'agent (#495) — l'annulation n'est plus signalée à tort comme un échec ; le commutateur rapide n'écrase plus l'état du flux
  • 🐛 Statut de recherche MiniMax dans la commande /status (#587)
  • 🐛 config_registry duplicate BOCHA_API_KEYS — suppression de l'entrée de dict en double qui écrasait silencieusement la configuration

Modifié

  • 🔎 Observabilité des échecs du Fetcher — enregistre les démarrages/succès/échecs avec le temps écoulé, les transitions de basculement ; Efinance/Akshare inclut les catégories de points de terminaison en amont et de défaillances classifiées
  • ♻️ Résilience et nettoyage des sources de données (#602) — optimisation de la chaîne de secours
  • ♻️ Extension d'extrait de réponse API — nouveau champ items (code/nom/confiance) ; codes préservé pour une compatibilité ascendante
  • ♻️ Importer les messages d'erreur d'analyse — raisons d'échec spécifiques pour Excel/CSV ; journalisation améliorée avec le type et la taille du fichier

Documents

  • 📖 Guide de configuration LLM refactorisé pour plus de clarté (#583)
  • 📖 image-extract-prompt.md avec une documentation rapide complète
  • 📖 Documentation TTL du cache de secours AkShare
