daily_stock_analysis v3.4.10

Corrigé

  • 🐛 Données EfinanceFetcher ETF OHLCV (#541, #527) — passez de _fetch_etf_data de ef.fund.get_quote_history (NAV uniquement, pas d'OHLCV, pas de paramètres beg/end) à ef.stock.get_quote_history ; Les ETF renvoient désormais les bons valeurs d'ouverture/haut/bas/fermeture/volume/montant au lieu de zéros ; supprimer les mappages de colonnes NAV obsolètes de _normalize_data
  • 🐛 tiktoken 0.12.0 Unknown encoding cl100k_base (#537) — épinglez tiktoken>=0.8.0,<0.12.0 dans exigences.txt pour éviter la régression d'enregistrement de plugin introduite dans 0.12.0
  • 🐛 Classification des erreurs API de l'interface utilisateur Web (#540) — le frontend ne traite plus chaque HTTP 400 comme le même échec « serveur/réseau » ; distingue désormais l'agent désactivé / les paramètres manquants / l'incompatibilité modèle-outil / les erreurs LLM en amont / les échecs de connexion locale
  • 🐛 Échec de l'identification du code North Exchange (#491, #533) — Le code à 6 chiffres commençant par 8/4/92 est maintenant correctement identifié comme North Exchange ; les sources de données telles que Tushare/Akshare/Yfinance prennent en charge le préfixe .BJ ou bj ; Baostock/Pytdx change explicitement de source de données pour les codes North Exchange ; éviter une identification erronée des actions Shanghai B 900xxx
  • 🐛 Erreur d'analyse des points de tireur d'élite (#488, #532) — Lorsque l'achat idéal/achat secondaire et d'autres champs ne contiennent pas le mot « yuan », les numéros d'indicateur technique entre parenthèses sont extraits par erreur ; maintenant le contenu après la première parenthèse est coupé puis extrait

Ajouté

  • Markdown-to-image pour le rapport du tableau de bord (#455, #535) — Le résumé quotidien des actions individuelles prend en charge la démarque vers l'image push (Telegram, WeChat, Custom, Email), ce qui est cohérent avec le comportement d'évaluation du marché.
  • moteur de démarque vers un fichier (#455) — MD2IMG_ENGINE=markdown-to-file en option, prend mieux en charge les emoji, nécessite npm i -g markdown-to-file
  • PREFETCH_REALTIME_QUOTES (#455) — Réglé sur false pour désactiver la prélecture des cotations en temps réel et éviter les tirages d'efinance/akshare_em à l'échelle du marché
  • Prélecture du nom du titre (#455) — Pré-récupère les noms des titres avant l'analyse, réduisant ainsi les espaces réservés « stock xxxxx » dans les rapports.

Modifié

  • Avertissement amélioré d'échec de démarque en image (#455) — Invite les dépendances spécifiques (wkhtmltopdf ou m2f) lorsque la conversion d'image échoue
  • Optimisation du routage d'images WeChat uniquement (#455) — Lors de la configuration uniquement des images WeChat d'entreprise, le transfert d'images redondant ne sera plus effectué sur le rapport complet pour éviter les journaux d'échec trompeurs.
  • Mode léger de prélecture du nom de stock (#455) — Ignorer la requête de cotation en temps réel lors de l'étape de prélecture du nom pour réduire la surcharge réseau supplémentaire
  • 📊 Marque du modèle de rapport d'analyse (#528, #534) — Afficher model_used (nom complet du modèle LLM) dans la méta du rapport d'analyse, à la fin du rapport et dans le contenu push ; lorsque l'agent est appelé lors de plusieurs tours, il enregistre et affiche le modèle réel utilisé à chaque tour (prend en charge la commutation de secours)
