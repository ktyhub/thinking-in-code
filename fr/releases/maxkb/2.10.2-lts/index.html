MaxKo v2.10.2-lts

Optimisations des fonctionnalités

  • Page Q&A : logique de saisie vocale optimisée pour ajouter du texte transcrit au lieu d'écraser le contenu d'entrée existant (#6212) ;
  • Page Q&A : Ajout d'une fonction de contenu de saisie clair une fois que les utilisateurs ont saisi le contenu dans la zone de saisie (#6212) ;
  • Page Q&A : les utilisateurs peuvent normalement envoyer de nouvelles questions après être passés à la session 2 pendant que la session 1 génère des réponses ;
  • Agent : les fichiers soumis via des formulaires peuvent être téléchargés à partir des journaux de conversation (#5271) ;
  • Agent : la méthode sendMessage dans la balise html_render des remarques d'ouverture avancées de l'agent prend en charge la transmission des paramètres API et des paramètres d'entrée utilisateur ;
  • Agent : Ajout de l'affichage des informations sur la source d'outils dans le menu d'opération des nœuds d'outils pour les agents avancés ;
  • Agent (X-Pack) : ajout d'une configuration de contrôle des autorisations pour le partage de conversations dans les paramètres d'affichage ;
  • Agent (X-Pack) : saisissez "/new" pour créer automatiquement une toute nouvelle conversation pour les intégrations d'applications tierces ;
  • Base de connaissances : les colonnes de la liste de documents prennent en charge le réglage manuel de la largeur ;
  • Base de connaissances : ajout d'un champ de créateur à la liste des documents, et le créateur des documents nouvellement téléchargés sera enregistré (#5240) ;
  • Base de connaissances : Fourniture de deux modes d'exportation permettant aux utilisateurs de choisir d'exporter ou non les fichiers source originaux lors de l'exportation d'une base de connaissances (#6137) ;
  • Base de connaissances : logique de pagination optimisée pour la gestion des balises afin d'éviter le décalage frontal causé par un excès de données sous une seule balise ;
  • Modèles : Ajout de la prise en charge du modèle de génération d'images Imagen sous le fournisseur Gemini (#5234) ;
  • Modèles : Ajout de la prise en charge du modèle de génération vidéo VEO sous le fournisseur Gemini (#5234) ;
  • Modèles : mise à jour de la liste déroulante des modèles de tous les fournisseurs de modèles pour afficher les derniers modèles ;
  • Gestion des autorisations : les utilisateurs qui disposent uniquement de l'autorisation d'affichage des outils n'ont pas le droit d'accéder à la page d'édition de l'outil ;
  • Workspace (X-Pack) : performances de chargement différé optimisées de la liste des espaces de travail.

Corrections de bugs

  • Page Q&A : Correction du problème selon lequel l'affichage de la progression de l'exécution du nœud n'était pas contrôlé par le commutateur à bascule des détails d'exécution ;
  • Page Q&A : masquez la progression de l'exécution du nœud lorsque la réponse de l'IA est suspendue et reprenez l'affichage de la progression après clicking Continue ;
  • Agent (X-Pack) : correction de l'échec de la prévisualisation des fichiers PDF à partir de sources de connaissances dans les conversations intégrées tierces (#6202) ;
  • Outils : Correction du marqueur de champ obligatoire manquant pour la zone de saisie du nom lors de la création d'un nouvel outil MCP ;
  • Base de connaissances : Correction des fichiers sources DOCX téléchargés corrompus après la mise à niveau de v2.3.1 vers v2.10.1 (#6238) ;
  • Base de connaissances : correction des erreurs d'exécution générées par le nœud Write-to-Knowledge-Base lors du débogage du flux de travail ;
  • Modèles : Correction d'erreurs lors de l'ajout du modèle qwen3-tts-flash du fournisseur Alibaba Cloud Bailian (#6236) ;
  • Paramètres de connexion : Correction de la vulnérabilité permettant aux utilisateurs de Community Edition de se connecter sans vérification captcha (#6214).
