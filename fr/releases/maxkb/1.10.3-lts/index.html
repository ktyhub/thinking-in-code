MaxKB v1.10.3-lts

Nouvelles fonctionnalités

  • Application : ajout d'un nœud d'appel MCP, qui a la capacité d'agir comme un service de bibliothèque de fonctions distantes. Les utilisateurs peuvent sélectionner des outils dans l'ensemble d'outils fourni par le service MCP pour les appels ; par @liuruibin dans https://github.com/1Panel-dev/MaxKB/pull/2665
  • Application : Ajout d'une fonction d'appel d'outil au nœud de dialogue AI. Une fois que les utilisateurs ont activé et terminé la configuration de l'outil MCP dans les paramètres de l'outil, le grand modèle de langage appellera de manière autonome l'outil MCP le plus approprié pour gérer les tâches en fonction des questions soulevées par les utilisateurs ; par @liuruibin dans https://github.com/1Panel-dev/MaxKB/pull/2665
  • Application : intégrez des fonctions tierces pour prendre en charge le mode mobile ; par @wangdan-fit2cloud dans https://github.com/1Panel-dev/MaxKB/pull/2615
  • Application (X-Pack) : dans les paramètres d'affichage, prend en charge le paramétrage de l'affichage des avatars des questions des utilisateurs et des avatars des réponses de l'IA ;
  • Bibliothèque de fonctions : ajout d'une bibliothèque de fonctions intégrée, notamment la recherche Google, la recherche Bocha, LangSearch, la requête MySQL et la requête PostgreSQL ; par @liuruibin dans https://github.com/1Panel-dev/MaxKB/pull/2611, @wangdan-fit2cloud dans https://github.com/1Panel-dev/MaxKB/pull/2725
  • Bibliothèque de fonctions : ajout de la configuration des paramètres de démarrage pour les fonctions ; par @liuruibin dans https://github.com/1Panel-dev/MaxKB/pull/2596 -Bibliothèque de fonctions : prise en charge de la définition du logo de la fonction ; par @wangdan-fit2cloud dans https://github.com/1Panel-dev/MaxKB/pull/2573
  • Base de connaissances (X-Pack) : prise en charge de l'amarrage avec la base de connaissances Feishu ;
  • Paramètres système (X-Pack) : ajout d'une fonction de journal des opérations ;
  • Paramètres système (X-Pack) : Enterprise WeChat, Feishu et DingTalk prennent en charge la connexion sans mot de passe.

Améliorations

  • Base de connaissances : ajout d'une nouvelle opération de génération de questions dans le fonctionnement du panneau de la base de connaissances pour faciliter le fonctionnement par lots ; par @shaohuzhang1 dans https://github.com/1Panel-dev/MaxKB/pull/2760
  • Base de connaissances : lors du téléchargement de fichiers dans la base de connaissances, l'aperçu du segment est optimisé en mode de chargement paresseux pour réduire le temps d'attente des utilisateurs ;
  • Base de connaissances : Optimiser la logique de recherche de texte intégral et améliorer le taux de rappel de segment ; par @shaohuzhang1 dans https://github.com/1Panel-dev/MaxKB/pull/2767
  • Page Q&A : La saisie vocale en mode intégré du terminal mobile prend en charge la pression et la parole, et prend en charge la libération et l'envoi après avoir défini l'envoi automatique ; par @wangdan-fit2cloud dans https://github.com/1Panel-dev/MaxKB/pull/2651
  • Page Q&A : optimise la logique de lecture vocale et prend en charge la lecture en streaming pendant la lecture automatique ; @shaohuzhang1 dans https://github.com/1Panel-dev/MaxKB/pull/2661
  • Page Q&A : optimisez l'interaction des paramètres de saisie utilisateur. Vous devez remplir les paramètres de saisie utilisateur avant d'entrer dans la boîte de dialogue. Après être entré dans la page de dialogue, les paramètres de saisie de l'utilisateur sont ajustés dans le coin supérieur droit de la zone de saisie des questions ; par @wangdan-fit2cloud dans https://github.com/1Panel-dev/MaxKB/pull/2680
  • Page Q&A : optimisez le problème selon lequel le bouton de fonctionnement des commentaires de l'utilisateur affiche un saut de ligne une fois la réponse de l'IA mobile terminée ; par @wangdan-fit2cloud dans https://github.com/1Panel-dev/MaxKB/pull/2772
  • Page Q&A : une fois la réponse de l'IA terminée, les données du formulaire sont filtrées lorsque l'utilisateur copie la réponse ; par @shaohuzhang1 dans https://github.com/1Panel-dev/MaxKB/pull/2778
  • Bibliothèque de fonctions : optimisez l'emplacement des paramètres d'autorisation des fonctions et ajustez-les à la liste déroulante des opérations du panneau de fonctions ; par @wangdan-fit2cloud dans https://github.com/1Panel-
  • Application : dans la configuration des paramètres du nœud de collecte de formulaires, prise en charge du réglage de l'ordre des paramètres ; par @wangdan-fit2cloud dans https://github.com/1Panel-dev/MaxKB/pull/2533
  • Application : lorsqu'un utilisateur a une conversation, si le paramètre demandeur est présent dans l'adresse URL, le paramètre sera affiché en tant qu'utilisateur interrogeant dans le journal de conversation ; par @shaohuzhang1 dans https://github.com/1Panel-dev/MaxKB/pull/2667
  • Application (X-Pack) : après qu'un utilisateur pose une question dans WeChat Enterprise, Feishu ou DingTalk, si aucune réponse n'est reçue pendant plus de 10 secondes, le système répond automatiquement : « En réfléchissant, veuillez patienter » ;
  • Documentation API (X-Pack) : L'accès au document Swagger nécessite une authentification de l'identité de l'utilisateur.

Corrections de bugs

  • Base de connaissances : correction du problème selon lequel le nom de la base de connaissances n'est pas entièrement affiché lors de la sélection de la page de la base de connaissances lors de la migration des documents ; par @wangdan-fit2cloud dans https://github.com/1Panel-dev/MaxKB/pull/2718
  • Base de connaissances : correction du problème selon lequel le nom de la base de connaissances n'est pas entièrement affiché lors du changement de base de connaissances dans la barre de navigation à l'intérieur de la base de connaissances ; par @wangdan-fit2cloud dans https://github.com/1Panel-dev/MaxKB/pull/2718
  • Base de connaissances : Correction du problème selon lequel lorsque le document téléchargé contient une image avec un titre défini, l'image ne peut pas être reconnue ; par @shaohuzhang1 dans https://github.com/1Panel-dev/MaxKB/pull/2683
  • Base de connaissances : Correction du problème selon lequel le nom du document après le téléchargement d'un fichier ZIP dans la base de connaissances s'affichait en caractères tronqués après décompression ; par @shaohuzhang1 dans https://github.com/1Panel-dev/MaxKB/pull/2747
  • Base de connaissances : Correction du problème selon lequel lorsque le nom du document est très long, le nom du document sera remplacé par "Feuille" lors de l'exportation de la base de connaissances ; par @shaohuzhang1 dans https://github.com/1Panel-dev/MaxKB/pull/2740
  • Application : correction du problème selon lequel après la suppression de l'application enfant intégrée dans le flux de travail, l'application parent signalera une erreur lors de l'ouverture ; par @shaohuzhang1 dans https://github.com/1Panel-dev/MaxKB/pull/2743
  • Application : Correction du problème selon lequel les résultats de la recherche dans la base de connaissances ne sont pas affichés par ordre décroissant en fonction de la similarité ; par @shaohuzhang1 dans https://github.com/1Panel-dev/MaxKB/pull/2791
  • Application : correction du problème de répétition du suffixe du nom de nœud dans le flux de travail, provoquant des erreurs d'analyse ; par @shaohuzhang1 dans https://github.com/1Panel-dev/MaxKB/pull/2513
  • Application : Correction du problème selon lequel lors de l'ajout de fonctions avec des noms différents dans le flux de travail, le numéro de suffixe sera automatiquement ajouté au nom du nœud ; par @shaohuzhang1 dans https://github.com/1Panel-dev/MaxKB/pull/2513
  • Application : correction de l'erreur lors de la définition d'une valeur entière dans le composant du curseur de collection de formulaires ; par @shaohuzhang1 dans https://github.com/1Panel-dev/MaxKB/pull/2601
  • Application : corrigez le problème selon lequel l'avatar de l'application est modifié avec succès, mais les informations d'invite sont incorrectes ; par @wangdan-fit2cloud dans https://github.com/1Panel-dev/MaxKB/pull/2749
  • Application : corrige le problème selon lequel lorsque plusieurs applications sont intégrées dans la même page, les utilisateurs seront informés que le dialogue n'existe pas lorsqu'ils posent des questions dans différentes applications ;
  • Paramètres du modèle : correction du problème d'erreur de vérification lors de l'ajout du modèle de type Alibaba Cloud Bailian QWQ ;
  • Authentification de connexion (X-Pack) : Correction du problème selon lequel après s'être connecté à la plateforme OAuth2, l'utilisateur renverra le code d'erreur « 500 » lors de la connexion ;
  • Authentification de connexion (X-Pack) : corrige le problème selon lequel plusieurs unités d'organisation (unités d'organisation) signalent des erreurs lors de la connexion à LDAP ;
  • Documentation API (X-Pack) : Correction d'un problème où des paramètres incorrects étaient affichés dans l'interface de dialogue OpenAI de la documentation API.
