MaxKB v2.9.0

MaxKo v2.9.0

Nouvelles fonctionnalités

  • Agent : ajout d'une capacité de mémoire à long terme. Il prend en charge la génération de mémoire par cycles de conversation et périodes de temps. Des souvenirs peuvent être injectés dans des invites via des références variables pour améliorer la personnalisation et la continuité de la conversation.
  • Agent : les nœuds des flux de travail d'agent avancés prennent en charge l'activation/la désactivation, permettant le débogage et le blindage logique temporaire sans supprimer de nœuds.
  • Agent : Ajout de la capacité d'affichage des ressources associées pour vérifier les ressources dépendantes et dépendantes (#4859, #4872).
  • Base de connaissances : ajout d'une capacité de visualisation des ressources associées avec suivi des dépendances bidirectionnel.
  • Outils : ajout d'une capacité de visualisation des ressources associées avec suivi des dépendances bidirectionnel.
  • Outils : les nœuds dans les outils de workflow prennent en charge l'activation/la désactivation, permettant le débogage et le blindage logique temporaire sans supprimer de nœuds.
  • Modèle : Ajout de la prise en charge de l'accès aux grands modèles de langage MiniMax et aux modèles de synthèse vocale (#4876).
  • Modèle : Alibaba Cloud Bailian a ajouté la prise en charge de l'accès au modèle vocal MiniMax Speech (#4950).

Optimisations des fonctionnalités

  • Agent : les nœuds de saisie utilisateur et de collecte de formulaires prennent désormais en charge le composant de sélection d'arborescence (#4903).
  • Agent : le nœud d'affectation de variable prend en charge l'attribution explicite d'une variable à null (#4964, #5107).
  • Agent : ajout de modes de correspondance d'expressions régulières et de caractères génériques pour les nœuds de jugement dans les agents avancés (#4975).
  • Agent : le copier-coller par lots est pris en charge pour les nœuds du canevas d'orchestration des agents et des flux de travail avancés.
  • Agent : les nœuds à l'intérieur des boucles prennent en charge le copier-coller par lots sur différents corps de boucle (#5128).
  • Agent : l'autorisation Publier des agents avancés est séparée indépendamment de l'autorisation de modification et peut être autorisée séparément.
  • Agent : Ajout de directives de format pour les paramètres variables des nœuds intégrés.
  • Modèle : la zone de sélection du modèle affiche uniquement les icônes des fournisseurs et les noms des modèles pour une interface plus propre.
  • Modèle : tous les fournisseurs de modèles prennent en charge l'URL de base API personnalisée pour s'adapter aux scénarios de déploiement privé.
  • Modèle : les modifications des paramètres du modèle sont automatiquement synchronisées avec toutes les ressources référencées associées (#5134).
  • Outils : les packages d'installation ZIP téléchargés pour les outils Skills prennent en charge le téléchargement.
  • Système : bégaiement optimisé du navigateur causé par des répertoires de fichiers excessifs.
  • Système : bégaiement frontal optimisé lors de l'ajout d'un grand nombre de membres à un rôle.

Corrections de bugs

  • Agent : Correction du problème où les nœuds suivants n'avaient aucune sortie après avoir imbriqué un nœud sous-agent dans un corps de boucle (#5197).
  • Agent : Correction du problème de perte des enregistrements de conversation après l'actualisation de la page lors du streaming des réponses dans les agents simples (#5156).
  • Agent : Correction d'une recherche invalide par créateur dans la liste des agents (#5177).
  • Agent : Correction du problème selon lequel des déclencheurs pouvaient être créés pour les agents non publiés (#5146).
  • Agent : Correction de l'affichage anormal des icônes des outils de workflow dans les outils de compétences.
  • Agent : Correction du problème où la dissociation de la base de connaissances associée dans les nœuds de récupération de la base de connaissances ne prenait pas effet (#5173).
  • Modèle : Correction de la configuration anormale des paramètres des modèles de génération d'images Volcano Engine (#5089).
  • Modèle : correction des erreurs des modèles vectoriels multimodaux Volcano Engine et des paramètres de modèle personnalisé pris en charge.
  • Modèle : Correction de la position d'affichage incorrecte de l'URL de base du modèle.
  • Modèle : Correction d'erreurs NaN occasionnelles dans le reclassement des modèles.

Correctifs de vulnérabilités de sécurité

  • Vulnérabilité de sécurité : correction de la vulnérabilité de sécurité liée à l'authentification manquante pour les points de terminaison de déclenchement Webhook, qui permettait aux requêtes non authentifiées de contourner l'autorisation et de déclencher des tâches arbitraires.
