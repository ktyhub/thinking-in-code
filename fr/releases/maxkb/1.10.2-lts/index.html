MaxKB v1.10.2-lts

Nouvelles fonctionnalités

  • Application (X-Pack) : l'accès aux applications prend désormais en charge Slack ;
  • Application : Ajouter un nœud d'affectation de variable ; par @liuruibin dans https://github.com/1Panel-dev/MaxKB/pull/2346 -Bibliothèque de fonctions : prend en charge les fonctions d'importation/exportation ; par @liuruibin dans https://github.com/1Panel-dev/MaxKB/pull/2294
  • Paramètres du modèle : ajout de la prise en charge du modèle de réapprovisionnement des fournisseurs Ollama ;

Améliorations

  • Application (X-Pack) : Après avoir démarré le processus de réflexion, optimisez le processus de réponse dans WeChat for Business, Feishu, DingTalk et les comptes publics ;
  • Application (X-Pack) : prise en charge du téléchargement d'images pendant les conversations WeChat for Business ;
  • Application (X-Pack) : prise en charge de la configuration des paramètres de portée pour les paramètres OIDC d'authentification de connexion ;
  • Application : prise en charge de la création d'applications vierges ; par @wangdan-fit2cloud dans https://github.com/1Panel-dev/MaxKB/pull/2377
  • Application : ajout de la prise en charge de la boîte de mot de passe et des composants de commutation pour les paramètres d'entrée utilisateur ; par @liuruibin dans https://github.com/1Panel-dev/MaxKB/pull/2307
  • Application : la saisie utilisateur prend en charge les titres personnalisés ; par @wangdan-fit2cloud dans https://github.com/1Panel-dev/MaxKB/pull/2313
  • Application : ajout de la prise en charge des composants de boîte de mot de passe pour les paramètres des nœuds de collecte de formulaires ; par @liuruibin dans https://github.com/1Panel-dev/MaxKB/pull/2307
  • Application : ajoutez le format m4a au type de fichier audio téléchargé ; par @wxg0103 dans https://github.com/1Panel-dev/MaxKB/pull/2277
  • Application : prise en charge du téléchargement des paramètres de fichier lors d'une conversation en appelant l'application API Key ; par @liuruibin dans https://github.com/1Panel-dev/MaxKB/pull/2300
  • Application : en appelant le mode clé de l'application API, prend en charge la sortie des paramètres du processus de réflexion ; par @shaohuzhang1 dans https://github.com/1Panel-dev/MaxKB/pull/2392
  • Application : les paramètres du tableau de saisie utilisateur dans le nœud d'informations de base prennent en charge l'ajustement par glisser-déposer de la commande ;
  • Application : la valeur conditionnelle dans le jugement prend en charge l'analyse des variables ; par @shaohuzhang1 dans https://github.com/1Panel-dev/MaxKB/pull/2311
  • Application : Dans la boîte de dialogue « Détails d'exécution » du nœud de rappel multidirectionnel, optimisez le contenu d'affichage du segment (y compris le titre du segment, le document et la base de connaissances) ; par @shaohuzhang1,@wangdan-fit2cloud dans https://github.com/1Panel-dev/MaxKB/pull/2309
  • Application : lorsque l'utilisateur quitte l'édition du flux de travail, invitez-le à enregistrer les données ; par @wangdan-fit2cloud dans https://github.com/1Panel-dev/MaxKB/pull/2312
  • Application : Le nombre maximum de segments de référence de la base de connaissances associée est ajusté à 10 000 ; par @shaohuzhang1 dans https://github.com/1Panel-dev/MaxKB/pull/2487
  • Application : L'opération de modification du nom du nœud dans l'arrangement avancé est remplacée par "..." → "Renommer" ; par @wangdan-fit2cloud dans https://github.com/1Panel-dev/MaxKB/pull/2432
  • Application : Lorsqu'un seul nœud de génération d'images génère plusieurs images, les images sont disposées horizontalement ; par @liuruibin dans https://github.com/1Panel-dev/MaxKB/pull/2423
  • Page Q&A : optimisez la mise en page de la page Q&A vers une disposition gauche-droite, avec les réponses de l'IA affichées à gauche et les questions des utilisateurs affichées à droite ; par @wangdan-fit2cloud dans https://github.com/1Panel-dev/MaxKB/pull/2258
  • Page Q&A : optimisez l'affichage des enregistrements de conversations historiques lorsque les utilisateurs ouvrent la page Q&A ; par @wangdan-fit2cloud dans https://github.com/1Panel-dev/MaxKB/pull/2301
  • Page Q&A : optimisez la lecture vocale pour lire uniquement le dernier contenu ; par @liuruibin dans https://github.com/1Panel-dev/MaxKB/pull/2431
  • Page Q&A : Prise en charge de la modification du titre de la session ; par @shaohuzhang1 dans https://github.com/1Panel-dev/MaxKB/pull/2348
  • Base de connaissances : prendre en charge la génération continue de questions pour le segment qui n'a pas réussi à générer des questions ; par @shaohuzhang1 dans https://github.com/1Panel-dev/MaxKB/pull/2299
  • Base de connaissances : prise en charge du tri de la liste des documents ; par @liuruibin dans https://github.com/1Panel-dev/MaxKB/pull/2284
  • Base de connaissances : Prise en charge de l'utilisation de la variable {title} pour obtenir le titre du segment dans la question générée ; par @shaohuzhang1 dans https://github.com/1Panel-dev/MaxKB/pull/2310
  • Bibliothèque de fonctions : ignore la casse lors de l'interrogation des fonctions ; par @liuruibin dans https://github.com/1Panel-dev/MaxKB/pull/2279
  • Paramètres du modèle : ignorez la casse lors de l'interrogation des modèles ; par @liuruibin dans https://github.com/1Panel-dev/MaxKB/pull/2279
  • Membres de l'équipe : ignorez la casse lors de l'interrogation des membres ; par @liuruibin dans https://github.com/1Panel-dev/MaxKB/pull/2279
  • Système : optimise le problème de consommation longue durée lors de la première connexion. par @shaohuzhang1 dans https://github.com/1Panel-dev/MaxKB/pull/2414

Corrections de bugs

  • Application : Correction du problème selon lequel l'image dans le contenu de la réponse AI ne pouvait pas être agrandie ; par @shaohuzhang1 dans https://github.com/1Panel-dev/MaxKB/pull/2327
  • Application : Correction du problème selon lequel la fenêtre de mot d'invite dans l'arrangement avancé n'est pas enregistrée après avoir modifié le contenu après avoir agrandi la fenêtre de mot d'invite et appuyé sur la touche ESC pour fermer la fenêtre ; par @wangdan-fit2cloud dans https://github.com/1Panel-dev/MaxKB/pull/2312
  • Application : Correction du problème selon lequel la réponse ne pouvait pas être terminée dans certains cas lors de l'utilisation du grand modèle de langage du fournisseur vLLM pour le dialogue ; par @shaohuzhang1 dans https://github.com/1Panel-dev/MaxKB/pull/2375
  • Application : Correction du problème selon lequel le calcul des jetons est inexact lors de l'utilisation du grand modèle de langage du fournisseur Kimi pour le dialogue ; par @shaohuzhang1 dans https://github.com/1Panel-dev/MaxKB/pull/2326
  • Application : corrige le problème selon lequel le réglage des paramètres n'est pas mis à jour après que le nœud de génération d'image ait changé de modèle ;
  • Application : Correction du problème selon lequel lorsque le tableau Excel contient des données de cellules fusionnées, les données sont manquantes lors de la lecture ; par @liuruibin dans https://github.com/1Panel-dev/MaxKB/pull/2265
  • Application : corrige le problème selon lequel le format d'appel OpenAI n'a pas le paramètre de processus de réflexion ; par @shaohuzhang1 dans https://github.com/1Panel-dev/MaxKB/pull/2392
  • Application : Correction du problème selon lequel s'il y a un paramètre non obligatoire dans le nœud enfant de l'application, si le paramètre n'est pas défini dans l'application parent, une erreur sera signalée lors du dialogue ; par @wxg0103 dans https://github.com/1Panel-dev/MaxKB/pull/2278
  • Application : Correction du problème selon lequel le grand modèle de langage du fournisseur Ollama utilise le paramètre num_ctx, et une erreur sera signalée lors du dialogue. par @itaa dans https://github.com/1Panel-dev/MaxKB/pull/2444
  • Page Q&A : corrige le problème selon lequel le navigateur ne peut pas lire la voix dans l'enregistrement historique de la conversation ; par @liuruibin dans https://github.com/1Panel-dev/MaxKB/pull/2378
  • Page Q&A : corrige le problème selon lequel l'actualisation de la page supprimerait la conversation en cours lors de la pose de la première question après la création d'une nouvelle conversation ; par @shaohuzhang1 dans https://github.com/1Panel-dev/MaxKB/pull/2428
  • Page Q&A : corrige le problème selon lequel les sauts de ligne ne peuvent pas être insérés au milieu du contenu dans la zone de questions ; par @wangdan-fit2cloud dans https://github.com/1Panel-dev/MaxKB/pull/2258
  • Page Q&A : corrige le problème selon lequel "/" est automatiquement ajouté après l'adresse URL du document dans certains cas, entraînant une inaccessibilité ;
  • Page Q&A (X-Pack) : Correction du problème selon lequel la nouvelle boîte de dialogue sur la page Q&A ne s'affiche pas après avoir désactivé l'historique dans les paramètres d'affichage ;
  • Bibliothèque de fonctions : corrige le problème selon lequel le résultat de sortie lors du débogage s'affiche incorrectement lorsque la valeur de retour de la fonction est 0 ; par @wangdan-fit2cloud dans https://github.com/1Panel-dev/MaxKB/pull/2413
  • Paramètres du modèle : corrigez l'erreur lors de l'ajout du grand modèle de langage d'Alibaba Cloud Bailian, s'il s'agit d'une soumission de modèle entièrement modal ; par @wxg0103 dans https://github.com/1Panel-dev/MaxKB/pull/2302
  • Paramètres du modèle : corrigez l'erreur lors de l'ajout du modèle DeepSeek -R1 au fournisseur Azure OpenAI ; par @liuruibin dans https://github.com/1Panel-dev/MaxKB/pull/2483
  • Paramètres système (X-Pack) : corrigez le problème selon lequel les paramètres d'interface dans le document Swagger ne sont pas entièrement affichés ;
  • Paramètres système (X-Pack) : corrigez le problème selon lequel la page Q&A n'affiche pas le nom de l'application après avoir défini le nom du site Web dans les paramètres d'apparence ;
  • Paramètres système (X-Pack) : corrigez le problème selon lequel le logo par défaut clignote lorsque la page de connexion est chargée.
