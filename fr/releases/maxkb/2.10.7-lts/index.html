MaxKo v2.10.7-lts

Améliorations

  • Base de connaissances : les caractères spéciaux tels que , /, ?, * et [] sont désormais interdits lors du renommage de documents.
  • Agent : une invite de confirmation s'affiche désormais lors de la suppression de l'historique des conversations, pour éviter toute suppression accidentelle.
  • Page Q&A : les tableaux dans les réponses AI prennent désormais en charge le défilement horizontal lorsque le nombre de colonnes dépasse la largeur visible.

Corrections de bugs

  • Agent : Correction d'un problème où le contenu enveloppé dans les balises html_render était rendu vide lors de l'exportation au format PDF ou image (#7222).
  • Agent : Correction d'un problème où la mémoire à long terme pouvait être enregistrée sans spécifier d'intervalle de déclenchement en mode de déclenchement planifié.
  • Agent : correction des étiquettes de nom de champ incorrectes dans le panneau des paramètres de mémoire à long terme.
  • Agent : Correction d'un problème où, lors de l'ajout d'agents créés presque en même temps que des compétences dans un nœud de conversation IA, un seul d'entre eux prenait effet.
  • Agent : Correction d'un problème où les détails d'exécution des outils de workflow étaient affichés dans le mauvais ordre dans les enregistrements de conversation (#7221).
  • Agent : Correction d'un problème où l'utilisation du modèle d'agent de rédaction longue du Template Center entraînait une erreur "la conversation n'existe pas" pendant le chat.
  • Agent : Correction d'un problème où le fait de cliquer sur le bouton J'aime ou Je n'aime pas sous une réponse provoquait une erreur système.
  • Agent : Correction d'un problème où, après avoir sélectionné un outil dans un nœud MCP, les paramètres non marqués comme requis étaient tous traités comme requis.
  • Agent : Règles de visibilité pour les paramètres d'entrée utilisateur — les paramètres facultatifs filtrent désormais les paramètres indisponibles des variables globales (#7224).
  • Déclencheur : correction d'un problème où les tâches de déclenchement planifiées ne s'exécutaient pas et qu'une erreur backend se produisait lors de l'enregistrement.
  • Base de connaissances : correction d'un problème où, après l'importation d'un PDF contenant des images, les liens des images étaient analysés mais les images n'étaient pas affichées.
  • Base de connaissances : Correction d'un problème où l'importation de documents volumineux dans une base de connaissances générale échouait (#7062).
  • Base de connaissances : correction d'un problème où les outils fournis avec un modèle Template Center devenaient indisponibles après l'application du modèle dans une base de connaissances de flux de travail (#7302).
  • Base de connaissances : correction d'un problème où la recherche en texte intégral renvoyait uniquement le contenu correspondant exactement au mot-clé (#7234).

Correctifs de sécurité

  • Sécurité : Correction d'une vulnérabilité où la clé de signature des messages de tâche Celery pouvait être dérivée, conduisant à l'exécution de code à distance (NVDB-CAIVD-2026894112).
  • Sécurité : correction d'une vulnérabilité d'autorisation de niveau fonction manquante (BFLA) dans le point de terminaison admin oss/get_url, qui pourrait conduire à un accès non autorisé et à SSRF (NVDB-CAIVD-2026080673).
  • Sécurité : Correction d'une vulnérabilité où chat_record_id pouvait être utilisé pour écraser les enregistrements de conversation d'autres visiteurs (intégrité de session).
  • Sécurité : correction d'une vulnérabilité dans laquelle les points de terminaison "J'aime" et "Je n'aime pas" acceptaient toujours les opérations croisées client.
  • Sécurité : Correction d'une vulnérabilité d'injection Eval dans les règles de validation "Init Param" des outils personnalisés, qui permettait l'exécution arbitraire de JavaScript.
  • Sécurité : correction d'une vulnérabilité de traversée de chemin dans les noms de bases de connaissances qui permettait d'écrire des fichiers .xlsx arbitraires et d'empoisonner les modèles d'importation à l'échelle de l'instance.
  • Sécurité : Correction d'une vulnérabilité de piratage de compte.
  • Sécurité : Correction d'une vulnérabilité SSRF non authentifiée dans le proxy du fichier de discussion causée par une liste de refus d'hôtes incomplète.
  • Sécurité : correction d'une vulnérabilité dans laquelle l'URL de configuration MCP n'était pas validée, permettant aux utilisateurs ayant le rôle USER d'exécuter SSRF sur des adresses arbitraires et de relire les réponses (connexion directe depuis le processus Web, contournant le bac à sable).
  • Sécurité : Correction d'une vulnérabilité où le CAPTCHA de connexion n'était pas détruit après une validation réussie, permettant le forçage brutal de mots de passe en ligne non authentifiés (prise de contrôle par l'administrateur).
  • Sécurité : Correction d'une vulnérabilité où les utilisateurs authentifiés pouvaient accéder aux enregistrements d'exécution multi-outils via un accès au cache non délimité.
