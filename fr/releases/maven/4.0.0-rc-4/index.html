maven maven-4.0.0-rc-4

Maven 4.0.0-rc-4 vise à être la dernière release candidate avant Maven 4.0.0 GA. Nous nous concentrerons sur la correction des bugs critiques soulevés avant GA. Il convient de mentionner le nouvel outil de mise à niveau qui peut être utilisé pour réparer vos fichiers pom.xml et les rendre utilisables dans Maven 4.
