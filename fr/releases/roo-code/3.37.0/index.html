Code Roo v3.37.0

[3.37.0] - 2025-12-22

Version 3.37.0 - Appel d'outil personnalisé

  • Ajoutez MiniMax M2.1 et améliorez la gestion des détails de l'environnement pour les modèles de pensée Minimax (PR #10284 par @hannesrudolph)
  • Ajoutez le modèle GLM-4.7 avec prise en charge du mode réflexion pour le fournisseur Zai (PR #10282 par @hannesrudolph)
  • Ajoutez des appels d'outils personnalisés expérimentaux - définissez des outils personnalisés qui s'intègrent parfaitement à votre flux de travail d'IA (PR #10083 par @cte)
  • Déprécier la sélection du protocole de l'outil XML et forcer le format d'outil natif pour les nouvelles tâches (PR #10281 par @daniel-lxs)
  • Correctif : émettre des événements tool_call_end dans le gestionnaire OpenAI à la fin du streaming (#10275 par @torxeon, PR #10280 par @daniel-lxs)
  • Correctif : émettre des événements tool_call_end dans BaseOpenAiCompatibleProvider (PR #10293 par @hannesrudolph)
  • Correctif : désactivez le mode strict pour les outils MCP afin de préserver les paramètres facultatifs (PR #10220 par @daniel-lxs)
  • Correctif : déplacez les propriétés spécifiques au tableau dans la variante anyOf dans normalizeToolSchema (PR #10276 par @daniel-lxs)
  • Correctif : ajout de la normalisation de fin de ligne CRLF aux outils search_replace et search_and_replace (PR #10288 par @hannesrudolph)
  • Correctif : ajout d'une solution de secours gracieuse pour l'analyse du modèle dans le fournisseur Chutes (PR #10279 par @hannesrudolph)
  • Correctif : activer les modèles d'actualisation Requesty avec les informations d'identification (PR #10273 par @daniel-lxs)
  • Correctif : améliorer l'accumulation et la sérialisation de Reasoning_details (PR #10285 par @hannesrudolph)
  • Correctif : conserver Reasoning_content dans le résumé condensé pour DeepSeek-reasoner (PR #10292 par @hannesrudolph)
  • Refactoriser le fournisseur Zai pour fusionner les détails de l'environnement dans le résultat de l'outil au lieu du message système (PR #10289 par @hannesrudolph)
  • Supprimez le paramètre parallel_tool_calls du fournisseur Litellm (PR #10274 par @roomote)
  • Ajouter une page Cloud Team avec des fonctionnalités complètes de gestion d'équipe (PR #10267 par @roomote)
  • Ajouter un utilitaire de déduplication du journal des messages pour les évaluations (PR #10286 par @hannesrudolph)
