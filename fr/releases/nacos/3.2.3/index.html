nacos 3.2.3

Correctif Publié14 juil. 2026 Sourcealibaba/nacos Anglais original

Cette page est traduite automatiquement. Le texte anglais original fait foi.

#nacos 3.2.3 Nacos 3.2.3 est principalement une version de correction de bugs et d'amélioration de l'expérience pour la série 3.2. Cette version se concentre sur :

  • Amélioration des flux de travail du registre AI, des compétences, du MCP et de la prochaine console.
  • Correction des problèmes d'isolation de l'espace de noms de configuration, de validation de dénomination et de stabilité de client.
  • Améliorer l'observabilité et l'hygiène des dépendances de release. Il corrige également des bogues dans Config, Naming, AI Registry, A2A, MCP, Client, ​​Core et Console.

Modifications détaillées dans cette version :

Fonctionnalité

  • #15143 #15463 Prend en charge les téléchargements de packages de compétences imbriqués et préserve les fichiers SKILL.md imbriqués en tant que ressources.

Amélioration/Refactorisation

  • #12737 #12867 Ajoutez le statut de leader par groupe de radeau et les métriques de terme.
  • #15321 Actualisez le cache disque de client de manière asynchrone après les notifications des abonnés.
  • #15322 Aligner la configuration de l'adaptateur Logback packagingData.
  • #15354 Ajustez les éléments suivants du menu de la barre latérale de la console.
  • #15435 Améliorer l'affichage des différences de version des ressources AI dans la prochaine console.

Correction de bugs

  • #12585 Correction de la liaison des paramètres de pagination afin que les espaces réservés ? fonctionnent correctement.
  • #14036 Prise en charge des préfixes HTTPS/TLS dans le traitement de connexion HTTP.
  • #14693 Correction de la pagination du sélecteur de service MCP dans la console.
  • #15032 Correction des fuites du contrôle de santé TCP SocketChannel et de la correspondance exacte des adresses IP des membres.
  • #15229 Normaliser les noms d'agent A2A nuls dans les requêtes de liste.
  • #15265 Autoriser les requêtes floues de liste de compétences lorsque skillName commence ou se termine par un trait d'union.
  • #15275 Copiez pg-upgrade-null-tenant-id.sql vers distribution/conf pour éviter les échecs de démarrage de la mise à niveau de PostgreSQL Docker.
  • #15296 Mettre à jour l'état détaillé du service après le basculement en ligne/hors ligne de l'instance.
  • #15305 Rejeter les adresses IP d'instance vides lors de l'enregistrement de nommage.
  • #15350 Correction de l'historique de configuration vide comparant le contenu dans la console suivante.
  • #15355 Restaurer les champs d'ID de données et de groupe cibles du clone de configuration modifiables.
  • #15359 Correction de la suppression de la version du registre AI corrompant les agrégats de versions et interrompant les requêtes A2A/MCP.
  • #15428 Conserver les paramètres de requête dans les URL des points de terminaison MCP après la publication.
  • #15430 Préservez transportProtocol dans les spécifications de point de terminaison MCP créées automatiquement.
  • #15498 Opérations d'exportation de configuration, de suppression par lots et de clonage basées sur l'ID de portée par espace de noms.

Dépendances

  • #15442 Intégrez les correctifs de dépendance de console-ui-next et reconstruisez les actifs statiques de la console suivante.

Configuration requise pour la version Java

| Module | Java requis | |--------|--------------| | Nacos-Serveur / Nacos-Console | Java17 | | Nacos-Client | Java8 | | Nacos-Maintainer-Client | Java8 |
