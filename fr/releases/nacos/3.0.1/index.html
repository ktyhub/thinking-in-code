#nacos 3.0.1

Les ressources de la version ont été mises à jour vers [3.0.1.1] (https://github.com/alibaba/nacos/releases/edit/3.0.1.1). Le téléchargement des ressources à partir de cette version est identique à celui de la version 3.0.1.1. Cette version est basée sur la version 3.0.0 et introduit la prise en charge des capacités de gestion multi-espaces de noms et des capacités de gestion multi-version de MCP. La communauté Nacos a contribué à la norme MCP Registry API et est la première à implémenter la norme MCP Registry API. Lors du déploiement de Nacos 3.0.1, le registre MCP standard API peut être activé en définissant le paramètre nacos.ai.mcp.registry.enabled=true, et le paramètre nacos.ai.mcp.registry.port (9080 par défaut) spécifie le port du registre MCP API. Étant donné que le registre MCP API nécessite des ports et des ressources supplémentaires, il reste désactivé par défaut dans les configurations standards. En raison de modifications apportées à la norme officielle API du registre MCP, les définitions de métadonnées du serveur MCP ont été mises à jour, entraînant des modifications potentielles de structure de données incompatibles. La mise à niveau de la version 3.0.0 vers 3.0.1 peut entraîner l'échec de la console lors de la lecture des données des serveurs MCP précédents. La communauté Nacos a fourni un outil de migration qui déplace les serveurs MCP existants vers l'espace de noms public par défaut après l'exécution. Des instructions détaillées sur l'utilisation de l'outil de migration mcp-migration-tool.jar sont disponibles dans la documentation. Le registre MCP API étant désormais finalisé, la structure des données du serveur MCP s'est stabilisée, garantissant une compatibilité ascendante dans les versions futures. En plus des nouvelles fonctionnalités, cette version optimise les invites de mot de passe initiales et les scripts de démarrage pour les systèmes Windows, tout en corrigeant également plusieurs bugs présents dans la version 3.0.0.
