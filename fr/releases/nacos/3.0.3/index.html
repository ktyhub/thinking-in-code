#nacos 3.0.3 Cette version se concentre principalement sur l'expansion de l'écosystème MCP et l'optimisation des performances tout en équilibrant l'expérience des développeurs et la robustesse du système. Et corrigez de nombreux bugs pour l’ancienne version. Concernant les nouvelles fonctionnalités du registre MCP, Nacos a ajouté une gestion dynamique des outils MCP (récupération automatique lors de la création/mise à jour), pris en charge l'importation d'outils de transfert HTTP via les fichiers Swagger API, ainsi que des définitions de schéma de sécurité améliorées et des interactions API côté IA client. Et introduction d'un index de mémoire pour optimiser les performances des requêtes d'ID/nom MCP, prise en charge de la configuration IP d'écoute personnalisée gRPC et ajout de frontEndpointConfig pour une intégration frontale rationalisée. Pour les améliorations du système et de l'expérience, Nacos a refactorisé l'interface utilisateur de gestion MCP, optimisé les conseils de configuration du port Docker, amélioré les flux de travail de création de services et renforcé les validations (par exemple, vérifications du nom d'utilisateur/mot de passe, vérification de l'existence de la table avant suppression). Nous avons également amélioré la logique des requêtes du serveur MCP et les journaux d'erreurs, standardisé les réponses API et assuré la cohérence SDK dans le renvoi des ID MCP.
