#nacos 3.2.0 Nacos 3.2.0 est une version majeure axée sur l'amélioration de l'architecture des plugins, l'extension du registre AI, la modernisation du API et l'amélioration de la qualité du code. Les principaux points saillants comprennent :

  • AI Registry complète la « triade IA » : le registre de compétences et le registre d'invites rejoignent le registre MCP/Agent existant, avec l'intégration de Nacos Copilot pour une gestion assistée par l'IA.
  • Modernisation de l'architecture des plugins : gestion complète des plugins basée sur SPI avec interface utilisateur de console, synchronisation à l'échelle du cluster et améliorations PostgreSQL
  • Nettoyage API : suppression de la prise en charge UDP PUSH héritée, API HTTP /v1 et /v2 extraits dans les sous-modules pour une suppression future
  • Sécurité et qualité du code : plugin d'authentification OIDC/OAuth2, plusieurs correctifs FindBugs, suppression du code mort et améliorations de la compatibilité JDK 17+
  • Modernisation de la console : prise en charge de la double interface utilisateur pour le changement de console nouvelle/ancienne avec une expérience utilisateur améliorée

⚠️ Dernières modifications et notes de migration

Modifications du schéma de base de données (importantes)

Action requise : Cette version introduit des modifications importantes au schéma de base de données avec plusieurs nouvelles tables ajoutées pour la gestion des plugins, le registre AI (compétence/invite) et des capacités d'audit améliorées. Avant la mise à niveau, vous devez appliquer le nouveau schéma :

  1. Sauvegardez votre base de données existante
  2. Appliquez le script de mise à niveau du schéma : conf/schema.sql (pour MySQL) ou le script correspondant à votre type de base de données.
  3. Redémarrez le serveur Nacos après la migration du schéma Si les modifications du schéma ne sont pas appliquées, la gestion des plugins, le registre AI et d'autres nouvelles fonctionnalités peuvent ne pas fonctionner correctement.

Plugin d'adaptateur hérité API

Le plugin api-legacy-adapter et les anciens HTTP /v1 et /v2 API ont été supprimés de cette version afin de réduire l'encombrement. Si votre déploiement dépend toujours des anciens /v1 ou /v2 API, vous pouvez introduire manuellement le plugin de compatibilité à partir de : https://github.com/nacos-group/nacos-api-legacy-adapter Veuillez télécharger et placer le plugin dans votre répertoire plugins pour restaurer la compatibilité héritée API.

Module de dénomination : prise en charge UDP PUSH supprimée

Le module de dénomination a supprimé la prise en charge UDP PUSH héritée, passant à une architecture HTTP API plus propre. Les Clients qui s'appuient sur des mises à jour de découverte de services basées sur UDP doivent migrer vers des mécanismes basés sur HTTP.

📚 Quoi de neuf dans le registre AI

Registre de compétences

  • Gestion centralisée : créez, mettez à jour et versionnez des compétences via l'interface utilisateur ou API avec changelog
  • Composition des compétences : enchaînez plusieurs outils MCP en fonctionnalités significatives pour l'entreprise (par exemple, "user_onboarding" = verify_email + create_profile + send_welcome_email)
  • Intégration MCP : les compétences déclarent explicitement les dépendances sur les outils MCP enregistrés avec validation d'intégrité
  • Organisation basée sur des dossiers : compétences affichées dans une structure de dossiers à plusieurs niveaux pour une meilleure organisation
  • Agent-Friendly APIs : REST/gRPC API pour les frameworks d'agents (LangChain, CrewAI, etc.) pour découvrir et souscrire à des compétences
  • Prise en charge du téléchargement : Téléchargez des packages de compétences (format zip, max 10 Mo) avec authentification
  • Security Scanning : scanner de compétences intégré pour la validation de la sécurité des compétences IA
  • Accès au niveau des données : visibilité fine et contrôle d'accès (phases 2 et 3)

Registre d'invite

  • Configuration de première classe : stockez les invites avec les métadonnées (agentId, modelId, version, tags) sous forme d'artefacts de configuration versionnés
  • Gestion multi-version : prise en charge de la gestion multi-version parallèle avec suivi des modèles et des messages de validation
  • Abonnement basé sur des balises : abonnez-vous aux invites par balises pour des mises à jour dynamiques
  • Débogage interactif : testez et comparez les résultats des invites entre les versions directement dans la console
  • AI Client Proxy : interface HTTP/gRPC client unifiée pour les opérations rapides

Copilote Nacos

  • Assistant alimenté par l'IA : assistant IA intégré pour aider à optimiser et à créer des invites et des compétences
  • Découverte intelligente : recherchez automatiquement les compétences existantes pertinentes à partir du registre
  • Intégration de la console : accessible directement depuis la console Nacos pour un flux de travail transparent
