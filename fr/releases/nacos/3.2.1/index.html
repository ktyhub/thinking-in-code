#nacos 3.2.1 Nacos 3.2.1 est une version de correctif axée sur les corrections de bugs critiques et les améliorations de fonctionnalités pour les problèmes découverts dans 3.2.0. Cette version apporte des améliorations significatives à la fonctionnalité AI Registry, à la compatibilité des bases de données, à la sécurité et à l'expérience utilisateur de la console. Les principaux points saillants comprennent :

  • Maturité du registre AI : gestion complète du cycle de vie des invites avec interface utilisateur, prise en charge du protocole A2A AgentCard v1, filtrage des compétences bizTag et stockage des spécifications de ressources pour les serveurs MCP
  • Améliorations de la sécurité : correction d'une vulnérabilité de contournement de l'authentification LDAP, ajout de la prise en charge de la connexion SSO OIDC/OAuth2 pour les deux consoles
  • Compatibilité des bases de données : correctifs complets pour PostgreSQL, Oracle, MySQL et Derby, y compris les problèmes de pagination déterministe et d'horodatage de schéma
  • Mises à niveau des dépendances : Spring Boot 3.5.13, MCP SDK 0.17.0 et log4j-core 2.25.4
  • Concurrence et fiabilité : élimination des conditions de concurrence dans le pipeline de publication AI, le module de dénomination, le basculement client et les opérations d'exportation de configuration
  • Console UX : Correction d'erreurs d'édition de configuration, de validation de l'ID d'espace de noms, d'importation par lots, de gestion de l'expiration des jetons et de bugs d'interface utilisateur dans les consoles anciennes et futures.

⚠️ Dernières modifications et notes de migration

Mises à jour du schéma de base de données (critique)

Action requise : Cette version inclut des correctifs critiques pour les schémas PostgreSQL, Oracle, MySQL et Derby, en particulier concernant les valeurs d'horodatage par défaut et les clauses ORDER BY pour la pagination déterministe. Avant la mise à niveau :

  1. Sauvegardez votre base de données existante
  2. Appliquez le script de schéma mis à jour : conf/schema.sql (pour votre type de base de données)
  3. Redémarrez le serveur Nacos après la migration du schéma Bases de données concernées :
  • PostgreSQL : Corrections d'horodatage par défaut, compatibilité avec la persistance des ressources IA
  • Oracle : Corrections d'horodatage par défaut
  • MySQL : Améliorations de la précision des requêtes de pagination
  • Derby : Ajouts de clause ORDER BY, correctifs de fuite de ressources JDBC Le fait de ne pas appliquer les modifications du schéma peut entraîner :
  • Échecs de démarrage de la base de données (PostgreSQL)
  • Résultats de pagination incohérents
  • Fuites de ressources JDBC
  • Contamination de la version des ressources IA

Configuration SSO OIDC/OAuth2

Cette version ajoute la prise en charge de la connexion SSO OIDC/OAuth2 pour les consoles anciennes et futures. Pour activer :

# OIDC Configuration
nacos.auth.oidc.enabled=true
nacos.auth.oidc.issuer-uri=<your-oidc-issuer-uri>
nacos.auth.oidc.client-id=<your-client-id>
nacos.auth.oidc.client-secret=<your-client-secret>
nacos.auth.oidc.redirect-uri=${domain}/v3/console/login

Configuration requise pour la version Java

| Module | Java requis | |--------|--------------| | Nacos-Serveur / Nacos-Console | Java17 | | Nacos-Client | Java8 | | Nacos-Maintainer-Client | Java8 |
