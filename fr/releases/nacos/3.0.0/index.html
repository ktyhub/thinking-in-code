#nacos 3.0.0 3.0.0 (25 avril 2025) Cette version est une version GA de 3.0.0. Dans cette version, Nacos est basé sur Nacos 3.0.0-BETA pour prendre en charge la gestion MCP (Model Content Protocol). Dans cette version 3.0.0 GA, Nacos effectuera ces fonctionnalités et modifications importantes :

  1. Les API sont classés en différents types, et différents types de API adopteront différentes stratégies d'authentification par défaut.
  2. Activation de l'authentification de la console nacos et nécessité de paramètres de configuration supplémentaires lors du premier déploiement.
  3. L'interface utilisateur de la console Nacos utilise la nouvelle console v3 API pour remplacer l'ancienne v1 API et désactive par défaut l'ancienne interface utilisateur de la console v1 API utilisée.
  4. L'espace de noms public par défaut change son identifiant de ``(empty string) to public.
  5. Prend en charge directement le protocole xDS. Actuellement, prend en charge EDS, LDS, RDS et CDS.
  6. Mettez à niveau spring boot vers 3.4.1 et mettez à niveau la version jdk vers 17.
  7. Ajoutez une série d'ADMIN API pour Nacos 3.0 afin que le responsable et la console personnalisée puissent conserver et obtenir les données de Nacos.
  8. Prise en charge du déploiement indépendant de la console Nacos, certaines configurations du serveur nacos et de la console nacos ont été modifiées, veuillez vérifier applciation.properties avant d'effectuer la mise à niveau.
  9. Prise en charge de la gestion MCP (Model Content Protocol).
  10. Prise en charge du verrouillage distribué des fonctionnalités expérimentales.
  11. Prise en charge des services et des configurations d'écoute floue des fonctionnalités expérimentales. Modifications détaillées dans 3.0.0 voir :
