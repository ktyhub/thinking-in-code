copilote-cli v1.0.100

2026-10-19

  • Ajoutez l'indicateur --disable-client-telemetry pour désactiver les téléchargements de télémétrie client à partir du CLI.
  • Ajoutez le dossier --trust pour les sessions ponctuelles en mode invite démarrées avec -p ou via stdin
  • Installez les compétences et les plugins vérifiés à partir des liens d'installation de GitHub via l'installation du plugin copilot "ghapp://air/install?..."
  • Ouvrir / partager sans arguments pour afficher un menu d'action en plein écran pour partager la session en cours
  • Le trafic des règles d'hôte Sandbox honore désormais HTTPS_PROXY et HTTP_PROXY lorsqu'aucun proxy Sandbox n'est configuré
  • La dictée vocale n'insère plus de marqueurs de langue comme <en-US> dans le texte de transcription
  • L'activation de la mise à jour des plugins gérés dans les sessions existantes lorsque la politique gérée change
  • Les sessions ne s'arrêtent plus pendant quelques minutes lorsqu'un serveur MCP se bloque lors du chargement des outils.
  • Les appels de l'outil Gemini n'échouent plus lorsque les paramètres du tableau définissent des valeurs d'énumération
  • Les discussions Gemini n'échouent plus après que les résultats des outils précédents ne contiennent aucun contenu lisible.
  • Les commandes shell du bac à sable expliquent désormais les échecs du certificat trust du certificat de proxy et d'informations d'identification et peuvent proposer une réexécution approuvée en dehors du bac à sable.
  • Conservez les commentaires de révision / diff enregistrés lors de la réouverture d'un diff inchangé dans la même session, avec une action de suppression explicite.
  • Les actions d'activation, de désactivation, de mise à jour et de désinstallation des plugins sont désormais acheminées de manière fiable après l'actualisation de l'inventaire des plugins.
  • Les réponses de raisonnement uniquement au jeton maximum ne bouclent plus indéfiniment et se terminent désormais par une erreur claire lorsqu'aucun progrès n'est réalisé
  • Afficher un avertissement clair et maintenir l'affichage du modèle actif synchronisé lorsqu'un modèle enregistré est automatiquement remplacé à la reprise.
  • Les commandes en bac à sable sous Linux démarrent de manière plus fiable sans échecs intermittents de configuration du bouclage
  • Les détails des ressources de retour depuis MCP restent sur la liste pendant l'actualisation des métadonnées en direct
  • Les discussions natives peuvent démarrer et se terminer tandis que les téléchargements de plugins gérés en option se poursuivent en arrière-plan.
  • Double Ctrl+C quitte immédiatement même lorsque l'interface utilisateur du CLI est occupée
  • La recherche dans le catalogue rapporte les exigences d'authentification du proxy pour les défis de proxy CONNECT
  • HydraFusion conserve une passe développée pendant son examen, les passes qui n'ont pas été conservées restent extensibles jusqu'à ce que vous changiez de session ou repreniez, et les passes d'un tour interrompu indiquent si elles ont été conservées.
  • La politique de compte géré et les avertissements de mode de contournement restent précis après un changement de compte, même en cas d'échec du cache de politique.
  • Évitez les faux épuisements de contexte et les refus de basculement lorsque les définitions d'outils sont différées
  • Les agents personnalisés qui déclarent les alias d'outils documentés search, web ou todo, ou nomment github-mcp-server/web_search, reçoivent désormais les outils correspondants.
  • Les indicateurs d'aide et de version de CLI se terminent de manière fiable après l'impression de leur sortie
  • Les autorisations de demande gérées par l'entreprise en mode assisté permettent désormais des actions sécurisées sans invites de confirmation inutiles.
  • Gardez votre compte Microsoft Entra sélectionné épinglé lors de la connexion et du renouvellement du jeton
  • À partir des actions d'en-tête de la barre latérale des sessions, elles se terminent jusqu'à la dernière session visible
  • Les badges des modes Plan, Pilote automatique et Shell restent visibles pendant le chargement des composants de démarrage et le fonctionnement de l'agent. Le badge remplace le suffixe de mode qui suivait le texte d'activité (Working - plan), et la ligne de démarrage Loading: tronque désormais ses diagnostics pour conserver la ligne d'état sur une seule ligne.
  • Les commandes en bac à sable peuvent écrire des packages et créer des caches lorsque l'accès à l'outil de développement est activé.
  • Les commandes Windows CLI Git récupèrent désormais les échecs de démarrage avec accès refusé aux threads.
  • Une règle de compétence allowed-tools conserve les virgules dans ses arguments au lieu d'être séparées. Lorsque la structure d'une liste est ambiguë, ses règles non étendues incitent désormais au lieu d'être accordées.
  • Le tableau de bord des ressources MCP reste interactif pendant l'actualisation des adaptateurs d'inventaire
  • Réessayez les demandes de réponses contenant des images avec des limites de charge utile plus petites lorsque les fournisseurs rejettent des corps surdimensionnés
  • Les rapports d'utilisation complets n'affichent plus le statut partiel ou les dépenses fantômes non attribuées après la reprise lorsque les données de facturation sont complètes.
  • Les autorisations assistées envoient des commandes PowerShell et bash -c imbriquées qui développent uniquement les variables d'environnement de données simples, les variables PowerShell entre guillemets simples et les déclarations de variables et d'alias PowerShell au juge des autorisations au lieu de nécessiter une approbation manuelle inutile.
  • Les fichiers d'instructions spécifiques au chemin dans la racine du référentiel .github/instructions sont désormais appliqués automatiquement lorsque l'agent lit ou modifie un fichier correspondant.
  • Démarrez git, les commandes shell et les serveurs MCP sous Windows lorsque l'énumération des threads d'instantané de processus échoue
  • Utilisez le navigateur de sessions unifié par défaut pour /sessions, /session et /resume.
  • La navigation par session limite désormais la découverte de compte à 500 enregistrements et respecte les conseils de réessai après pour le timing d'actualisation automatique.
  • Invite à mettre à jour l'autorité de certification du proxy sandbox lorsque les hôtes masqués changent
  • Afficher un avis clair lorsque les paramètres gérés par l'administrateur remplacent votre modèle sélectionné
  • Activer la recherche de code sémantique par défaut pour les sessions en ligne.
  • Améliorez /login pour Microsoft Entra en vous permettant de choisir un compte en cache ou de vous connecter explicitement avec un autre compte
  • Git en bac à sable sur github.com peut utiliser votre GITHUB_TOKEN configuré à partir des informations d'identification.envVars
  • /sandbox peut garder le sandboxing activé pour la session en cours sans l'activer globalement
  • Les plugins du référentiel Trusted s'installent et se mettent à jour automatiquement avant l'exécution du chat.
  • Renommez le plug-in de navigateur intégré en utilisation par navigateur et conservez les préférences de plug-in de navigateur existantes après la mise à niveau.
  • Sandbox autorise l'accès au réseau local par défaut afin que les commandes puissent atteindre les services de l'hôte local et du réseau privé.
