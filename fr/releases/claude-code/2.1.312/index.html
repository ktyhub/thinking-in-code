claude-code v2.1.312

Correctif Publié27 oct. 2026 Sourceanthropics/claude-code Anglais original

Cette page est traduite automatiquement. Le texte anglais original fait foi.

code-claude v2.1.312

Qu'est-ce qui a changé

  • Ajout de oidc.user_id_claim à la passerelle des applications Claude, pour identifier les personnes par une revendication id_token autre que sub, comme oid de Microsoft Entra ID
  • Ajout de click pour envoyer : en plein écran, click l'indication "à envoyer maintenant" sous un message en file d'attente l'envoie immédiatement, comme le fait sa clé
  • Correction des paramètres gérés et de la politique d'organisation qui n'étaient pas récupérés pour le reste de la session après la connexion à partir de l'extension VS Code
  • Correction de Claude écrasant un très gros fichier CLAUDE.md, de règles ou un fichier @-inclus dans un sous-répertoire après avoir vu seulement son début ; Write now demande à Claude de tout lire ou de le modifier sur place
  • Correction des compétences par répertoire et paths: introuvables après un Bash cd plus profond dans un référentiel git
  • Correction d'un cas rare où la première réponse après la reprise d'une session dans le terminal pouvait manquer lors de la prochaine reprise de la session
  • Correction d'une commande avec un nom invalide empêchant le chargement de toutes les commandes, ce qui pouvait laisser claude -p sans sortie
  • Correction de l'échec de l'outil de lecture sur les pages PDF avec "pdftoppm failed: Could not write image" lorsque le nettoyage des anciens fichiers de session s'exécutait en même temps
  • Correction du spinner, des valeurs OpenTelemetry effort et des transcriptions nommant un niveau d'effort nouvellement sélectionné lors d'une tâche avant que le modèle ne l'applique ; ils affichent maintenant le niveau en vigueur
  • Correction de l'avertissement du cache /model et /effort indiquant que la relecture attend votre prochain message ; un changement effectué pendant que Claude travaille peut le déclencher plus tôt
  • Correction de certaines sessions apparaissant comme vous attendant lorsque le dernier message ne mentionnait que les éléments qui vous attendaient au milieu d'une phrase
  • Correction de la vue de l'agent restaurant le texte saisi au prochain lancement après qu'il ait été effacé avec Ctrl+C juste avant de quitter.
  • Correction de la réouverture de la vue de l'agent en mode shell après avoir quitté avec Ctrl+D depuis une entrée ! vide
  • Correction du mode vim d, c et y avec un nombre de gj ou gk supérieur aux lignes restantes pour supprimer ou copier du texte ; comme Vim, ils déplacent désormais uniquement le curseur
  • Correction de /verify affichant une longue description destinée à Claude dans /help et le menu de commandes / au lieu d'une courte
  • Amélioration de l'indicateur d'effort de l'invite : une modification effectuée en cours de tâche indique désormais qu'elle peut attendre votre prochain message, et la note s'efface lorsqu'elle ne s'applique plus.
  • Amélioration des erreurs WebFetch dans les sessions cloud : un hôte qui ne se résout pas est désormais expliqué comme étant éventuellement en dehors des domaines réseau autorisés, donc Claude nomme l'hôte à autoriser
  • Modification de Bedrock, Vertex, Foundry et Mantle pour utiliser l'invite système plus courte pour les noms de modèles que Claude Code ne reconnaît pas, tels que les noms de déploiement personnalisés et les ARN de profil d'inférence, même lorsqu'ils font face à Sonnet ou Haiku ; configurez CLAUDE_CODE_SIMPLE_SYSTEM_PROMPT=0 pour conserver l'invite complète
  • Modification des changements de modèle automatiques après un message signalé pour couvrir également les noms de modèles que Claude Code ne reconnaît pas, tels que les noms de déploiement personnalisés ; réglez CLAUDE_CODE_DISABLE_REFUSAL_FALLBACK=1 pour les éteindre
  • Modification des messages de limite d'utilisation pour appeler la fenêtre de 5 heures "limite de 5 heures" au lieu de "limite de session".
  • Modification des sessions cloud démarrées à partir du CLI pour obtenir leurs noms et noms de branches du serveur
  • Modification des hooks d'invite et d'agent pour qu'ils s'exécutent au maximum 24 à la fois par session, sous-agents inclus, plus au maximum 12 ayant attendu plus longtemps que le délai d'expiration de leur événement ; un timeout en moins de 1 seconde compte désormais pour 1 seconde
  • Modification du autoCompactWindow d'un sous-agent pour abaisser la fenêtre définie par CLAUDE_CODE_AUTO_COMPACT_WINDOW, là où cela n'avait aucun effet auparavant ; il ne lève toujours jamais cette fenêtre
  • Modification de OpenTelemetry mcp_server.name pour signaler le vrai nom des serveurs MCP distants à URL fixe déclarés par les plugins du marché officiel Anthropic, au lieu de custom
  • Modification du code Claude pour arrêter l'envoi de l'événement claude_code.safety_event OpenTelemetry
  • [VSCode] Correction des sessions se terminant par un simple code de sortie lorsque les paramètres de votre organisation ne pouvaient pas être chargés ou étaient refusés au démarrage ; l'onglet indique maintenant pourquoi et propose de réessayer ou de se reconnecter
  • [VSCode] Modification de la réinitialisation de la limite d'utilisation pour afficher l'heure ("Réinitialisation à 15h10") et indiquer "Limite de 5 heures".
  • [Sessions Cloud] Ajout d'un niveau d'effort au sélecteur de modèle lorsque vous créez ou modifiez une routine qui s'exécute dans le cloud
  • [Sessions Cloud] Ajout d'un éditeur Bash avec des couleurs, des numéros de ligne et un bouton Copier dans la boîte de script de configuration dans les paramètres de l'environnement cloud
  • [Sessions Cloud] Amélioration de l'étape affichée lorsque Claude ajoute un référentiel à une session cloud : son ouverture affiche désormais un court tableau de ce qui s'est passé au lieu du JSON brut
  • [Sessions Cloud] Correction du renvoi d'un message inchangé après un échec d'envoi dans une session cloud l'exécutant parfois deux fois
  • [Sessions cloud] Correction d'un échec de création d'environnement cloud affichant son erreur uniquement sous forme de toast en dehors de la boîte de dialogue ouverte ; il apparaît maintenant dans la boîte de dialogue
  • [Sessions Cloud] Correction de l'édition dans le menu d'une routine sur la page Routines en accédant à la page de la routine sans ouvrir sa boîte de dialogue d'édition
  • [Télécommande] Correction d'une session de contrôle à distance non archivée qui fonctionnait jusqu'à ce qu'un ordinateur se reconnecte ; il apparaît maintenant comme inactif
  • [Claude Tag] Amélioration de l'avis de nouvelle tentative de Claude Tag dans Slack pour nommer le modèle utilisé, ou indiquer que les limites de débit ont été atteintes, au lieu d'une erreur générique API
  • [Claude Tag] Correction du commutateur marche/arrêt d'une chaîne Claude Tag et des paramètres d'agent retombant sur les valeurs par défaut de l'espace de travail lorsqu'une ancienne chaîne Slack privée devient publique et obtient un nouvel identifiant.
  • [Claude Tag] Correction de Claude dans Slack ne répondant pas dans les chaînes dont l'environnement a un accès réseau défini sur Aucun.
  • [Claude Tag] Correction de Claude dans Slack publiant parfois un fichier dans le mauvais fil alors qu'il répondait dans un autre fil du même canal
  • [Code Review] Correction de la révision du code examinant un commit obsolète, ou aucun, lorsque GitHub délivrait un événement push en retard ; il examine maintenant le commit actuel de la pull request
