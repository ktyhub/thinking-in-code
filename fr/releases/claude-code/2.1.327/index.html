  • Modification des sous-agents d'arrière-plan redémarrés et des tours qui démarrent d'eux-mêmes, pour attendre le chargement des plugins
  • Modification de l'historique des invites pour laisser de côté la plupart des invites de lancement des sessions démarrées par une autre session Claude Code, comme claude --bg exécuté par Claude
  • Modification des résumés de progression des sous-agents dans les sessions de terminal sur Amazon Bedrock, Google Vertex AI et Microsoft Foundry pour qu'ils soient rédigés à partir de notes courtes, et non de l'intégralité de la conversation, en utilisant beaucoup moins de jetons.
  • Modification du mode non interactif (-p) pour exécuter moins de commandes git avant la première requête
  • Modification de la configuration de première exécution pour ignorer la configuration du terminal dans les sessions distantes VS Code, Cursor et Devin Desktop, où il ne peut pas modifier les paramètres
  • Modification de la sélection de texte en plein écran pour laisser de côté le glyphe des lignes du système, de la réflexion et des messages entrants
  • Modification des sessions cloud hébergées par Anthropic pour ignorer davantage les paramètres de livraison des indicateurs et des plugins d'un référentiel ; son CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC agit désormais tout au plus comme DISABLE_TELEMETRY
  • [VSCode] Ajout de "Claude Code : Ajouter au chat" au menu droit click de l'explorateur, qui @-mentionne les fichiers et dossiers sélectionnés dans le chat
  • [VSCode] Correction de l'invite d'autorisation n'affichant pas la raison donnée par un hook PreToolUse lorsqu'il demande une confirmation (anthropics/claude-code#85950)
  • [VSCode] Correction des noms longs d'outils et de fichiers coupés dans le titre d'une invite d'autorisation
  • [VSCode] Correction du diff d'une session de terminal affichant la modification proposée précédente après que vous l'ayez tapée et que Claude ait à nouveau édité le même fichier
  • [VSCode] Correction de l'échappement arrêtant également la réponse de Claude lorsqu'il ferme la boîte de dialogue de feedback ou "Créer un style personnalisé", le menu @-mention, le menu modèle, mode ou "+", ou une autre fenêtre contextuelle
  • [VSCode] Amélioration de la vitesse lorsque Claude effectue plusieurs modifications d'affilée : les modifications en file d'attente partagent une attente pour de nouveaux problèmes ; un problème peut être signalé lors d'une modification ultérieure
  • [VSCode] Amélioration de la vitesse de recherche des fichiers @-mention dans les grands espaces de travail lorsque rg est sur votre PATH ; les résultats sont désormais classés comme dans le terminal, avec moins de tolérance pour les fautes de frappe
  • [VSCode] Démarrage amélioré : le sélecteur de modèles est prêt immédiatement dans les dossiers ouverts pour la première fois, les fenêtres et les worktrees vides, sauf chez les fournisseurs tiers
  • [VSCode] Modification de la différence d'édition d'un chat pour rester ouvert et continuer à demander l'approbation lorsqu'une session de terminal dans la même fenêtre envoie une invite
  • [VSCode] Suppression des outils inutilisés de la connexion IDE (openFile, saveDocument, getOpenEditors et associés)
