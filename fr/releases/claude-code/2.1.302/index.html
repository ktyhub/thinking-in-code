claude-code v2.1.302

Correctif Publié16 oct. 2026 Sourceanthropics/claude-code Anglais original

Cette page est traduite automatiquement. Le texte anglais original fait foi.

code-claude v2.1.302

Qu'est-ce qui a changé

  • Ajout de CLAUDE_CODE_AUTO_MODE_MODEL pour choisir le modèle utilisé par le classificateur en mode automatique côté client ; cela ne change pas le modèle pour le mode automatique côté serveur
  • Ajout d'une rangée Idle compaction à /config pour désactiver ou réactiver le compactage au ralenti ; les avis affichés après un compactage inactif indiquent maintenant comment l'éteindre
  • Ajout d'un avis à /design-sync et /design-login indiquant que Claude Design (claude.ai/design) autonome ferme ses portes d'ici le 14 décembre 2026.
  • Correction d'une erreur "L'invite est trop longue" lors de l'arrêt d'un tour pendant que la conversation était en cours de compactage
  • Correction des requêtes échouant avec « diagnostics : les entrées supplémentaires ne sont pas autorisées » après le passage à Vertex ou Bedrock en cours de session
  • Correction de l'outil de lecture chargeant un fichier image de n'importe quelle taille, ou un canal ou un périphérique nommé comme une image, entièrement en mémoire ; les sources d'images supérieures à 128 Mo sont désormais refusées
  • Correction de l'enregistrement de /autocompact et /effort sur le mauvais modèle lorsqu'une passerelle nomme Opus 4 ou 4.1 avec un préfixe, tel que anthropic/claude-opus-4-1
  • Correction d'un échec de cache d'invite lorsqu'un outil ajouté en cours de session était à nouveau chargé via ToolSearch ou après le compactage
  • Correction de claude plugin et d'autres sous-commandes qui se fermaient parfois avant la fin d'une configuration en file d'attente ou d'une écriture de configuration, ce qui pouvait perdre la modification ou laisser un fichier .tmp derrière.
  • Correction du reclonage des marchés de plugins à chaque actualisation et des plugins git nouvellement installés affichant la version "inconnue", lorsque git utilise par défaut le format de référence reftable
  • Correction de l'outil PowerShell ne trouvant pas de commandes dans le dossier bin/ d'un plugin et signalant une erreur lorsqu'une recherche qui ne trouve rien (rg, grep, findstr, git grep) est redirigée vers Select-Object ou une autre applet de commande de formatage
  • Correction de Claude dans l'application de bureau vous dirigeant vers les paramètres claude.ai ou /mcp pour autoriser ou reconnecter un serveur MCP lorsque cette option n'est pas disponible
  • Correction des publications d'artefacts qui échouaient parfois lorsque Claude envoyait une liste vide de modifications et que Claude réessayait une mise à jour d'artefact dans le mauvais sens après qu'une version plus récente de l'artefact l'ait refusée.
  • Correction de classifier_category manquant dans les événements OpenTelemetry tool_decision pour la plupart des blocs classificateurs en mode automatique, et nouveaux attributs tool_decision supprimant tool_use_id, tool_source et tool_parameters lorsque OTEL_LOGRECORD_ATTRIBUTE_COUNT_LIMIT est faible.
  • Correction des lignes dans la vue des agents restant vides après avoir parcouru une longue liste ou plié une section
  • Correction de claude remote-control --help qui n'imprimait pas son utilisation et quittait lorsqu'il n'était pas connecté
  • Correction de /design consent et /design revoke suggérant /design-login lorsqu'ils échouent dans une session cloud, où il n'est pas disponible ; le message pointe désormais vers claude.ai/design/settings
  • Correction des serveurs MCP n'affichant aucun outil, ou chaque appel d'outil échouant, lorsque le serveur négocie la version du protocole 2026-07-28 mais omet resultType, ttlMs ou cacheScope
  • Correction des suggestions d'invite dépensant des crédits d'utilisation sur des modèles pour lesquels votre forfait ne paie qu'avec des crédits : elles sont désormais ignorées après une réponse facturée aux crédits.
  • Correction des URL écrites en backticks étant clickable uniquement sur leur première ligne lors de leur retour à la ligne ; l'URL entière est désormais un lien dans les terminaux prenant en charge les hyperliens
  • Correction de claude plugin details <name>@builtin suggérant claude plugin list, qui n'affiche jamais les plugins intégrés, lorsque le plugin n'est pas trouvé ; il pointe maintenant vers /plugin
  • Correction d'un emoji indiquant qu'un lien commençait à l'intérieur d'une colonne trop large, ce qui le masquait dans les aperçus des questions et transformait les tableaux en listes
  • Correction de l'isolement de l'arbre de travail refusant de créer ou de reprendre des arbres de travail sous git 2.56 ou version ultérieure lorsqu'un fichier .git parasite pointe vers un répertoire qui n'existe pas.
  • Correction du coût et de l'utilisation d'une session cloud redémarrant à zéro après la reprise de la session dans un nouveau processus
  • Exécuteur auto-hébergé : correction de l'échec des récupérations de git avec des "références/têtes d'objets incorrects" dans les sessions qui réutilisent une extraction stockée au format reftable de git
  • Windows : Correction de chaque refus ou demande d'écriture de fichier pour les projets sur des lecteurs exFAT ou FAT32, y compris dans les sessions démarrées avec --plugin-dir
  • Temps de démarrage amélioré avec de nombreux plugins activés : les fichiers de commande et d'agent du plugin nécessitent désormais beaucoup moins d'appels au système de fichiers à charger, surtout sous Windows
  • Mode automatique amélioré avec le classificateur côté serveur : une conversation trop longue pour le contrôle de sécurité est désormais compactée, au lieu que chaque appel d'outil vérifié soit refusé
  • Amélioration du message lorsqu'une session en arrière-plan rouverte depuis un autre dossier n'a pas de passerelle LLM : il indique désormais pourquoi, au lieu de "Non connecté"
  • Modification des sessions claude -p et Agent SDK sans mode d'autorisation pour démarrer en mode default sur des fournisseurs tiers, avec la télémétrie désactivée ou sur une nouvelle installation ; --permission-mode auto conserve automatiquement
  • Modification des sous-agents fork (subagent_type: "fork") pour qu'ils soient activés par défaut dans claude -p, l'agent SDK, l'application de bureau et VS Code, comme ils le sont déjà dans le terminal ; CLAUDE_CODE_FORK_SUBAGENT=0 les désactive et claude mcp serve ne les propose jamais
  • Modification de l'application de bureau et de VS Code pour toujours exécuter les sous-agents de la conversation principale en arrière-plan, comme le fait le terminal, plutôt que de laisser Claude choisir ; les appels d'agent d'un sous-agent dans claude -p, l'agent SDK, l'application de bureau et VS Code s'exécutent désormais au premier plan par défaut
  • Modification de l'indice de pied de page ← for agents pour qu'il se masque 10 secondes après l'ouverture d'une session ; le nombre d'agents qui vous attendent est toujours affiché
  • Modification de l'emplacement des instructions de Claude dans Chrome dans l'invite système afin que les nouvelles conversations puissent les lire à partir du cache d'invite partagé.
  • Modification des hooks d'invite et d'agent afin qu'au plus 12 événements d'un même événement soient exécutés à la fois ; les autres attendent leur tour
  • Modification du message affiché lorsque la politique de votre organisation désactive /feedback : il pointe désormais vers les problèmes GitHub au lieu d'un administrateur de l'organisation.
  • [VSCode] Correction du texte après un bloc de code non fermé dans une liste s'affichant sous forme de texte brut pendant le flux d'une réponse, puis se transformant en code
  • [VSCode] Correction de la connexion au serveur MCP à partir du panneau ouvrant une page d'autorisation cassée lorsque l'URL du serveur contient une chaîne de requête
  • [VSCode] Correction de la bannière @browser indiquant "Navigateur connecté" lorsqu'aucun navigateur avec l'extension Claude n'est accessible
  • [Sessions cloud] Ajout d'une bannière sur la page d'une routine indiquant pourquoi sa dernière exécution n'a pas démarré, par exemple si votre organisation atteint sa limite de sessions cloud simultanées.
  • [Sessions cloud] Correction de l'échec de "Rewind to here" sur chaque message, à l'exception du plus récent dans les sessions cloud ; les coureurs auto-hébergés ont besoin du code Claude v2.1.246 ou version ultérieure
  • [Sessions Cloud] Correction de la barre d'état de la demande d'extraction dans les sessions cloud, retournant une demande d'extraction avec des conflits de fusion à prête pendant que GitHub la revérifiait
  • [Sessions cloud] Correction des exécutions de routine affichant comme terminées après l'arrêt inattendu de leur session cloud, et comme annulées lorsqu'elles sont archivées avant leur démarrage, au lieu d'avoir échoué.
  • [Sessions cloud] Correction de la vue différentielle dans les sessions cloud manquant de modifications ou ne se chargeant pas après que le référentiel GitHub de la session ait été renommé ou déplacé.
  • [Sessions Cloud] Correction d'une exécution de routine planifiée qui échouait à mi-chemin et qui était réexécutée depuis le début une heure ou plus plus tard, ce qui pouvait répéter le travail, comme la publication du même rapport deux fois.
  • [Sessions cloud] Correction d'une session cloud ouverte qui n'affichait parfois pas les messages envoyés depuis un autre appareil jusqu'à ce que vous rechargiez la page ou que vous clické et retour
  • [Sessions cloud] Amélioration de l'erreur affichée lorsqu'une session cloud ne démarre pas : elle indique désormais "Connexion perdue" ou "Erreur du serveur" au lieu de "Quelque chose s'est mal passé".
  • [Contrôle à distance] Correction du volet d'un sous-agent qui tournait indéfiniment dans une session de contrôle à distance après la mise hors ligne de votre ordinateur ; il dit maintenant que la télécommande est déconnectée
  • [Claude Tag] Correction de "je pense…" restant sous une mention dans une chaîne Slack ou un DM après que Claude y ait répondu en modifiant l'un de ses messages précédents
  • [Claude Tag] Correction des URL dans les blocs de code sous une étape numérotée ou à puces des réponses Slack de Claude étant placées entre crochets, ce qui cassait les commandes copiées
  • [Claude Tag] Correction des images HEIC, SVG, TIFF et BMP attachées dans Slack n'atteignant jamais Claude ; ils arrivent désormais sous forme de fichiers dans ses fichiers de travail, comme les autres types de fichiers
  • [Claude Tag] Correction des nouveaux gestionnaires de canaux perdant l'accès à Claude dans Slack dans les organisations qui restreignent Claude Tag par rôle ; le rôle de manager est désormais également accordé à Claude Tag dans Slack
  • [Claude Tag] Correction des connecteurs personnalisés dont les serveurs MCP partagent un hôte apparaissant comme un seul connecteur dans les paramètres d'administration de Claude Tag ; chaque serveur est désormais son propre connecteur
  • [Claude Tag] Correction de Claude dans Slack répondant parfois à un message direct avec « Les DM sont temporairement indisponibles » et le supprimant lorsqu'une seule recherche Slack était bloquée ; il réessaye maintenant en premier
  • [Claude Tag] Correction des messages directs avec Claude sur Slack Enterprise Grid ignorant la liste déroulante de l'espace de travail de Slack ; ils s'exécutent désormais sous l'espace de travail connecté dans lequel vous avez ouvert Claude pour la dernière fois
  • [Claude Tag] Correction de Claude dans l'avis de Slack concernant la limite de dépenses mensuelle d'une chaîne indiquant qu'un gestionnaire de chaîne peut l'augmenter ; il nomme désormais le propriétaire de l'organisation et relie la page d'utilisation
  • [Claude Tag] Correction des liens dans les réponses Slack de Claude absorbant les marques de fermeture en gras ou en italique, ou la ponctuation pleine chasse, juste après eux, ce qui cassait le lien et le formatage
  • [Claude Tag] Recherche de référentiel améliorée dans les paramètres d'administration de Claude Tag pour couvrir jusqu'à 100 comptes GitHub connectés et trouver des référentiels privés au-delà des 5 000 premiers d'une installation d'application GitHub
  • [Claude Tag] Amélioration de l'ajout d'un emplacement dans les paramètres d'administration de Claude Tag pour répertorier une chaîne que vous saisissez ou collez immédiatement, au lieu de seulement après le chargement de la liste complète des chaînes de votre organisation.
  • [Claude Tag] Amélioration de l'Ajout > Domaine sur la page d'un espace de travail ou d'une chaîne dans les paramètres d'administration de Claude Tag pour être disponible une fois cette page chargée, et pas seulement après le chargement de chaque chaîne.
  • [Claude Tag] Modification des paramètres d'administration de Claude Tag pour organiser l'accès de Claude en quatre onglets : Bundles, Connecteurs, Compétences et plugins, et Canaux.
  • [Claude Tag] Modification de la page Rôles dans les paramètres de l'organisation pour regrouper les rôles créés pour les gestionnaires de canaux Claude Tag dans une section réduite sous les propres rôles de votre organisation.
  • [Code Review] Correction de la configuration de la revue de code ne reprenant pas après avoir quitté le GitHub ; de retour dans les paramètres d'administration, il rouvre maintenant dans le sélecteur de référentiel
