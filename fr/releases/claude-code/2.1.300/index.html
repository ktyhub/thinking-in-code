claude-code v2.1.300

Correctif Publié14 oct. 2026 Sourceanthropics/claude-code Anglais original

Cette page est traduite automatiquement. Le texte anglais original fait foi.

code-claude v2.1.300

Qu'est-ce qui a changé

  • Ajout de virtualText aux décorations d'invite d'un mod : texte dessiné dans la boîte d'invite qui n'entre jamais dans le brouillon ou dans l'invite soumise.
  • Ajout de cache_creation_5m_tokens et cache_creation_1h_tokens à l'événement OpenTelemetry api_request, divisant les écritures du cache par durée de vie
  • Ajout de $.ui.view({ agentId }) pour les mods : affiche la transcription d'un agent dans la vue principale lorsque vous le demandez, et $.ui.view({}) revient en arrière
  • Ajout d'un accessoire dir sur le Text d'un mod pour le texte de droite à gauche : sous Windows et dans le terminal de VS Code, ses lignes se lisent dans cette direction et sont alignées à droite.
  • Ajout de /advisor sur la plateforme Claude sur AWS ; aucun conseiller ne court jusqu'à ce que vous en choisissiez un avec /advisor, advisorModel ou --advisor, et CLAUDE_CODE_DISABLE_ADVISOR_TOOL=1 le désactive
  • Ajout des attributs de convention sémantique OpenTelemetry GenAI pour tracer les étendues, tels que gen_ai.provider.name, gen_ai.conversation.id, gen_ai.tool.name et error.type
  • Ajout de la prise en charge de la réécriture des prompt et model d'un agent de workflow dans le mod hook agent.spawn, qui ne pouvait auparavant refuser les agents de workflow
  • Ajout du crochet de mod prompt.change, déclenché lorsque le texte de la boîte d'invite change sans modification tapée : une entrée d'historique rappelée, un effacement, une annulation ou un remplissage de plugin
  • Correction des sessions cloud indiquant à Claude qu'une politique d'organisation bloquait un hôte alors que les paramètres réseau de la session le faisaient
  • Correction de l'avertissement /autocompact concernant une utilisation élevée de jetons lorsque vous choisissez une fenêtre de compactage automatique plus petite
  • Correction des hooks SessionEnd qui ne s'exécutaient parfois pas lorsque vous quittez alors qu'une commande en arrière-plan est toujours en cours d'exécution
  • Correction de claude --help nommant un outil supprimé dans sa description de --restricted
  • Correction de claude agents qui n'actualisait pas le statut d'une demande d'extraction lorsque les données de l'une d'entre elles revenaient incomplètes.
  • Correction du message indiquant à Claude qu'un agent en arrière-plan était perdu et ne pouvait pas être repris après le remplacement du conteneur d'une session cloud, alors que l'agent avait déjà été repris une fois.
  • Correction des sous-agents avec lesquels vous aviez tapé des messages qui disparaissaient de /tasks peu de temps après avoir terminé, ne laissant aucun moyen de revenir à la conversation.
  • Correction d'un agent parent terminé laissant tomber le fil d'Ariane (son enfant affiché re-rooté au niveau supérieur) pendant que vous regardiez l'enfant
  • Correction de la vue des agents prenant un mot tapé tel que "haut", "bas" ou "évasion" pour cette touche lorsque l'entrée arrivait en rafale, ce qui pouvait déplacer le coup d'œil à mi-réponse ou effacer un brouillon
  • Correction de la désactivation de la recherche automatique d'outils (ENABLE_TOOL_SEARCH=auto) au cours d'une conversation, par exemple lorsque les serveurs MCP se reconnectent après une reprise
  • Correction d'une connexion refusée par forceLoginOrgUUID laissant le token de l'organisation refusée stocké, ou en direct après /login
  • Correction de la vue différentielle dans les sessions Claude Desktop et Remote Control ne remarquant pas un choix de cerises en conflit ou un retour dans les référentiels réftables
  • Correction de la ligne verbeuse et ctrl+o de l'outil Artifact lisant Artifact("(unprintable path)") lorsque l'entrée d'un appel arrive ; sa ligne affiche désormais "En attente…" et "En cours d'exécution…" comme le fait Bash
  • Correction de la perte de la première entrée de transcription écrite après la reprise d'une session lorsqu'un crash avait raccourci la dernière ligne de la transcription.
  • Correction du /branch supprimant les messages et du claude purge sautant les projets de sous-dossiers lorsqu'ils contiennent une ligne Unicode ou un séparateur de paragraphe (U+2028, U+2029)
  • Correction des hooks du plugin WorktreeCreate et WorktreeRemove ne fonctionnant pas lorsque Claude Code démarre avec --worktree (pas encore avec --tmux)
  • Correction des événements OpenTelemetry tool_result manquant git_commit_id après git commit -q dans les référentiels utilisant le stockage de référence reftable
  • Correction d'une invite indiquant que le crochet prompt.submit d'un mod était réécrit ou supprimé, alors qu'il était toujours enregistré tel que saisi dans l'événement OpenTelemetry user_prompt et la durée d'interaction, ainsi que dans les demandes de titre de session.
  • Correction d'une note destinée à Claude concernant le rechargement à chaud du mod apparaissant dans la transcription comme si vous l'aviez tapée
  • Correction des hooks d'agent ignorant leur model : les alias comme haiku sont désormais résolus, le modèle d'un sous-agent ne le remplace plus et un modèle indisponible revient à celui de l'appelant au lieu d'autoriser l'action.
  • Correction des sessions --worktree démarrant parfois à partir du mauvais commit lorsqu'une balise ou une branche était nommée comme un ID de commit, et leur statut git de départ nommant une branche autre que celle du nouvel arbre de travail.
  • Correction de la branche affichée comme ".invalid" et --worktree ne parvenait pas à rouvrir un arbre de travail dans les référentiels en utilisant le stockage de référence reftable de git
  • Correction de Claude nommant les fichiers dans le bloc-notes de session par un nom de fichier simple ou un chemin relatif au lieu de leur chemin complet
  • Correction des serveurs claude remote-control abandonnant le renouvellement de leur connexion après une brève erreur de connexion, comme un trousseau verrouillé ; ils réessayent maintenant et vous avertissent lorsque vous devez exécuter claude /login
  • Correction de l'échec de --worktree dans un arbre de travail d'un référentiel nu lorsque la branche par défaut d'origine ne peut pas être récupérée ; la base de secours est désormais le HEAD de la caisse actuelle, et non celui du référentiel principal
  • Correction du démarrage de Claude Code dans un terminal intégré VS Code, Cursor ou Devin Desktop lançant deux fois l'outil de ligne de commande de l'éditeur pour vérifier l'extension ; il le lance maintenant une fois
  • Correction du hook prompt.edit d'un mod qui n'était pas levé pour une nouvelle ligne saisie avec la combinaison de touches chat:newline (Ctrl+J, ou un rebond Entrée)
  • Correction d'un échec de conversation à chaque tour avec une erreur 400 lorsque le API rejetait le schéma d'entrée d'un outil MCP ; Claude Code envoie désormais cet outil sans paramètres pour le reste de la conversation
  • Correction de la reprise d'une session headless ou Agent SDK perdant les messages récents qu'un compactage avait conservés, lorsque le compactage suivait une réponse coupée à la limite du jeton de sortie (compactages à partir de cette version)
  • Correction de Claude qui n'était pas informé des outils et des instructions d'un serveur MCP jusqu'à son prochain appel d'outil, lorsque le serveur avait fini de se connecter après un compactage.
  • Correction des sessions de contrôle à distance marquées comme étant arrêtées alors qu'elles étaient encore en cours d'exécution, sur un ordinateur servant plusieurs sessions à la fois
  • Correction de la reprise d'une session sans tête ou de l'agent SDK perdant son résumé de compactage ou ramenant l'historique de pré-compactage, lorsque le compactage suivait une réponse réessayée ou inachevée dans le même tour
  • Correction de Claude interrogeant le fichier de sortie d'une commande en arrière-plan ou dormant pendant son exécution
  • Correction des indicateurs de fonctionnalités et des déploiements par étapes restant obsolètes derrière un proxy d'inspection TLS dont le certificat est trust uniquement via le magasin de certificats du système d'exploitation
  • Correction de l'impression du claude daemon stop --any "arrêtée" alors qu'un service d'arrière-plan bloqué continuait de fonctionner : il attend maintenant, tue de force le service, et le dit avec la sortie 1 s'il est toujours là
  • Correction de claude daemon stop quittant sans sortie et quittant les sessions répertoriées comme en cours d'exécution lorsque la télémétrie est désactivée
  • Correction des sessions Write, Edit et NotebookEdit dans le cloud Cowork signalant le succès d'un chemin sur votre propre ordinateur, où le fichier n'est jamais arrivé
  • Correction de Claude recherchant des outils différés déjà chargés plus tôt dans la conversation lorsqu'une session reprenait un historique qui ne les avait jamais répertoriés
  • Correction du texte secondaire (faible) ressemblant au texte normal sous le thème ANSI sombre et sur les terminaux 16 couleurs
  • Correction des sessions cloud suspendues 5 minutes par tour lorsque la politique de l'organisation ne peut pas être lue ; le tour se termine maintenant rapidement et dit pourquoi
  • Correction d'une session cloud exécutant parfois un message déjà répondu une deuxième fois après le redémarrage de la session lors d'une longue réponse
  • Runner auto-hébergé : correction du blocage du coureur et de l'orchestrateur (pas de sondages, arrêt de /healthz ou SIGTERM) alors que personne ne lit leur sortie ; les journaux conservent les 256 Kio les plus récents et comptent les pertes (pas sous Windows)
  • WebFetch amélioré dans les sessions cloud Cowork pour indiquer à Claude qu'une page a échoué il y a quelques instants au lieu de la récupérer à nouveau
  • Partage de mod amélioré dans la compétence plugin-authoring intégrée : Claude analyse les fichiers d'un mod à la recherche de clés avant de les ouvrir et demande avant d'analyser un dossier en dehors du projet
  • Amélioration de la note que les modèles Claude 3 reçoivent à propos d'un PDF mentionné en @, afin qu'ils répondent moins souvent sans le lire
  • Mises à jour améliorées des artefacts : Claude applique désormais une petite modification et republie l'artefact en un seul appel, et effectue des modifications et des republiations plus importantes en une seule réponse.
  • Modification des sessions CLAUDE_CODE_PROVIDER_MANAGED_BY_HOST pour ignorer les variables CA-bundle, tool-proxy, git TLS et git config comme SSL_CERT_FILE dans les paramètres ; sous Claude Desktop, uniquement dans les paramètres du projet
  • Modification de la sortie pour forcer l'élimination des commandes en arrière-plan exécutant toujours 1.5 quelques secondes après avoir été invité à s'arrêter ; en mode plein écran, ils pouvaient auparavant rester en cours d'exécution
  • Modification de l'onglet Code de Claude Desktop pour appliquer les paramètres gérés lorsque forceLoginGatewayUrl nomme une passerelle exploitée par Anthropic qui sert le nom d'hôte de la session ; cette passerelle doit être accessible au début
  • Modification de claude gateway pour qu'il s'arrête au démarrage, en nommant la clé, sur une clé de stratégie desktop: que Claude Desktop ne peut pas utiliser à partir d'une passerelle, où il avait démarré plus tôt avec un avertissement.
  • Modification des requêtes volumineuses adressées à api.anthropic.com pour utiliser la compression gzip même lorsque la télémétrie est désactivée ; réglez le CLAUDE_CODE_GZIP_REQUEST_BODIES=0 pour l'éteindre
  • Modification de la compétence claude-api pour laisser les sessions d'agents gérés en place, sauf si vous demandez de les archiver ou de les supprimer
  • Modification des sessions en arrière-plan pour reprendre un flux de travail effectué via l'approbation de l'outil Workflow au lieu de l'exécuter à partir du fichier de transfert
  • Modification des transcriptions de session locale pour enregistrer également l'invite système, les outils et les paramètres de chaque requête API, afin qu'une transcription que vous choisissez de partager puisse reproduire exactement une requête
  • Modification des options du mode /sandbox pour lire "Commandes Sandbox" au lieu de "Sandbox BashTool"
  • Modification des hooks PermissionRequest dans les sessions cloud Cowork : une mise à jour setMode dans l'autorisation d'un hook est désormais ignorée ; le reste de l'approbation s'applique toujours
  • Hooks modifiés : updatedInput des hooks PreToolUse et PermissionRequest est désormais validé comme la propre entrée de Claude : les clés inconnues sont supprimées et l'entrée rejetée par l'outil refuse l'appel.
  • Suppression des flags --sandbox et --no-sandbox de claude remote-control, qui n'avaient aucun effet ; passer l'un ou l'autre se termine maintenant avec une erreur. Définissez sandbox.enabled dans les paramètres sur les sessions sandbox
  • [VSCode] Ajout du paramètre claudeCode.attachSelection pour empêcher l'ajout du texte sélectionné dans l'éditeur à vos messages
  • [VSCode] Correction du mode rapide restant actif après l'épuisement des crédits d'utilisation, ce qui faisait que chaque demande était refusée et renvoyée ; il s'éteint maintenant jusqu'à ce que vous le rallumiez, avec un avis d'erreur
  • [VSCode] Correction du basculement de la réflexion sur Désactivé sur les modèles qui réfléchissent toujours ; la bascule n'est plus affichée pour ces modèles
  • [VSCode] Correction de "l'invite de modification" sur un message signalé ouvrant le fichier ou le menu de commande sur l'invite restaurée ; Enter l'envoie maintenant tel qu'écrit
  • [VSCode] Correction de Shift+glisser un fichier sur l'invite sous Windows en insérant un chemin /c:/… illisible au lieu d'une mention relative au répertoire de travail
  • [VSCode] Correction des modifications apportées aux paramètres de taille de police de discussion de VS Code nécessitant un rechargement de la fenêtre ou étant annulées par un changement de thème ; les différences et l'aperçu du plan les suivent désormais également
  • [VSCode] Correction de "Reprendre la session" et des onglets restaurés après un rechargement ouvrant une nouvelle conversation vide au lieu de celle qui avait été déplacée dans un arbre de travail git
  • [VSCode] Correction de ↑ puis Enter sur une commande slash rappelée l'exécutant sans ses arguments ; les menus de commande et de fichier ne s'ouvrent plus sur une invite rappelée jusqu'à ce que vous la modifiiez
  • [VSCode] Correction de Shift+glisser un fichier depuis l'explorateur ou un onglet d'éditeur vers l'invite sans rien insérer dans les fenêtres WSL, SSH et Dev Container
  • [VSCode] Correction de Ctrl+Alt+F pour basculer la vue Focus au lieu d'ouvrir Rechercher dans l'Explorateur, d'autres arborescences ou la console de débogage sous Windows et Linux.
  • [VSCode] Correction de la vérification des sessions ouvertes dans d'autres fenêtres ou terminaux créant des processus supplémentaires sur macOS : il démarre désormais directement /bin/ps au lieu de rechercher PATH pour ps à chaque vérification.
  • [VSCode] Windows : correction d'une conversation affichant "toujours ouvert ailleurs" après un crash ou une coupure de courant, alors que Windows avait depuis redémarré et donné l'ancien ID de processus à un autre programme
  • [Sessions Cloud] Correction de l'absence de « Autoriser cette tâche » dans les invites d'approbation de Cowork pour les outils de connecteur où une organisation désactive « Toujours autoriser » (régression dans 2.1.292)
  • [Sessions cloud] Correction de la plupart des commandes du menu / perdant leur description dans les sessions cloud une fois que vous avez envoyé un deuxième message
  • [Télécommande] Correction de la vue différentielle dans les sessions de contrôle à distance sur claude.ai et dans l'application de bureau affichant les fichiers supprimés et renommés tels que modifiés ; nécessite le code Claude v2.1.296 ou version ultérieure sur votre machine
  • [Claude Tag] Ajout de la prise en charge des canaux Slack Connect : un propriétaire ou un administrateur de Claude Tag peut laisser Claude dans Slack répondre dans les canaux partagés avec une autre organisation ; c'est désactivé par défaut
  • [Claude Tag] Ajout d'une carte privée Autoriser une fois / Refuser dans les fils de discussion Slack pour les actions de connecteur qui nécessitent votre approbation, donc Claude demande au lieu de refuser ; les autres voient seulement qu'il t'attend
  • [Claude Tag] Ajout de la prise en charge de la voix Slack clips dans Claude dans Slack : Claude lit la transcription de Slack d'un clip lorsque Slack en a une
  • [Claude Tag] Correction de Claude dans Slack ne répondant pas à une autre application qui le taguait dans un fil de discussion sous un message que Claude lui-même avait posté sur la chaîne
  • [Claude Tag] L'accès modifié regroupe un administrateur attaché à une chaîne Slack pour continuer à postuler une fois que la chaîne devient une chaîne Slack Connect, sans avoir besoin de les supprimer et de les rattacher.
  • [Révision du code] Correction de la révision du code ignorant les commentaires @claude review des personnes ayant un accès en écriture dont l'adhésion à l'organisation GitHub est privée ; leurs commentaires lancent maintenant une révision
  • [Code Review] Correction du commentaire « en pause pour ce référentiel » de Code Review envoyant les administrateurs aux paramètres de Code Review ; il indique maintenant qui peut le réparer et relie la page des fournisseurs Git
