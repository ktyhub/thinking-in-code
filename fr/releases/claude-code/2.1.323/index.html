code-claude v2.1.323

Qu'est-ce qui a changé

  • Ajout du Mode Code, un opt-in expérimental dans lequel Claude écrit JavaScript pour appeler ses outils ; voir https://code.claude.com/docs/en/code-mode pour l'activer ou pour le désactiver pour une organisation
  • Ajout de engines["claude-code"] à plugin.json : les plugins en dehors de la plage de versions indiquée de Claude Code ne sont pas installés, mis à jour ou chargés, et l'installation et la mise à jour choisissent la version la plus récente qui correspond
  • Ajout de la vérification de type du module hooks TypeScript d'un plugin à claude plugin validate ; chaque résultat est un avertissement et --strict échoue
  • Ajout à claude plugin validate des noms $. Le crochet engine.create d'un mod ajoute, retient ou remplace
  • Ajout de la prise en charge de CLAUDE_CODE_AUTO_MODE_MODEL dans les paramètres gérés pour les sessions Claude Desktop sur des fournisseurs tiers (prend effet une fois que Claude Desktop inclut cette version)
  • Ajout d'un menu d'options (arrêter, passer aux crédits d'utilisation, mettre à niveau) lorsqu'un modèle a besoin de crédits d'utilisation désactivés ou épuisés
  • Ajout d'un battement de coeur de progression toutes les 30 secondes pendant que les hooks s'exécutent longtemps dans les sessions claude -p et SDK, afin qu'un hôte tel que Claude Desktop ne termine pas le tour en étant bloqué (une fois qu'il inclut cette version)
  • Ajout de la prise en charge de .docx aux téléchargements d'actifs de l'outil Artifact
  • Ajout d'un indice /diff to close au panneau de comparaison, et des touches qui focalisent et ferment un panneau au guide de raccourcis ?
  • Ajout d'un avertissement de démarrage pour Bash autorisant les règles avec un * dans la valeur d'une variable, comme Bash(PORT=* npm run dev)
  • Ajout d'un avertissement lorsque le serveur de langue d'un plugin ne peut pas démarrer, nommant le serveur et ce qu'il faut vérifier
  • Ajout d'un avis de démarrage unique nommant CLAUDE_CODE_PERFORCE_MODE lorsque les paramètres Perforce sont trouvés et que le mode est désactivé
  • Ajout de CLAUDE_CODE_DISABLE_AGENT_PROGRESS_SUMMARIES (disponible depuis 2.1.318) : réglez-le sur 1 pour désactiver les résumés de progression des sous-agents et les requêtes qui les écrivent (anthropics/claude-code#86879)
  • Ajout de CLAUDE_CODE_RESUME_HINT_COMMAND, qu'un programme qui démarre Claude Code peut définir pour que l'indice de sortie nomme sa propre commande de reprise
  • Ajout de unsetOptionCount au résultat claude plugin install --json : combien d'options userConfig ne sont pas encore définies
  • Ajout de isPromptCovered aux accessoires avec lesquels le volet d'un mod est dessiné, lui indiquant quand une boîte de dialogue ou un champ au-dessus de l'invite couvre l'invite
  • Correction de l'exécution à nouveau de /compact, ou après une commande telle que /context, résumant un message auquel Claude n'avait pas encore répondu
  • Correction d'une reprise de session joignant votre prochain message à un ancien message interrompu qui n'a pas été repris
  • Correction d'un pic de mémoire à l'invite suivante après que Claude ait modifié un très gros fichier
  • Correction d'un paramètre enregistré dans une session en cours annulant une modification manuelle effectuée sur settings.json quelques instants plus tôt ; un fichier de paramètres que vous supprimez au cours d'une session reste désormais supprimé
  • Correction des commandes claude plugin et claude mcp list vous déconnectant d'un profil de console lorsqu'elles se terminaient pendant le renouvellement du jeton.
  • Correction du manque de mémoire de Edit et Bash sur certains fichiers /proc, et du blocage ou du manque de mémoire de Edit sur les appareils et les canaux nommés.
