claude-code v2.1.287

Correctif Publié1 oct. 2026 Sourceanthropics/claude-code Anglais original

Cette page est traduite automatiquement. Le texte anglais original fait foi.

code-claude v2.1.287

Qu'est-ce qui a changé

  • Ajout de Claude Mods : les plugins peuvent désormais modifier un comportement plus profond
  • Ajout de Vous devriez savoir, un mod intégré dans lequel un agent secondaire surveille vos arrières et signale les choses que vous ou Claude pourriez manquer. Allumez-le avec /plugin enable cc-plugin-you-should-know@builtin (pour les sessions propriétaires avec télémétrie activée)
  • Ajout d'un filtre n:<text> à la vue des agents qui correspond aux noms de session et aux tâches ; un filtre affiche désormais les correspondances dans des sections réduites et Entrée ouvre la première correspondance
  • Ajout de prompt_text à l'événement OpenTelemetry user_prompt, une copie de prompt pour les backends qui emboîtent les clés pointées ; déposez-le ou masquez-le partout où vous déposez ou masquez prompt (anthropics/claude-code#70763)
  • Ajout d'invites URL des serveurs MCP sur le protocole 2025-11-25, par exemple pour se connecter. Si un serveur ne se connecte plus après cette mise à jour, ajoutez "bareElicitationCapability": true à son entrée de configuration MCP
  • Windows : Ajout d'un avertissement de démarrage lors du refus de l'outil Bash désactive également l'outil PowerShell, donc Claude n'a pas d'outil shell
  • Exécuteur auto-hébergé : ajout d'un gh api intégré (REST uniquement) pour les sessions qui utilisent git géré par Anthropic sur les machines macOS et Linux sur lesquelles le GitHub CLI n'est pas installé
  • Correction du mode rapide restant désactivé dans les sessions à distance appartenant à un agent sans compte utilisateur, même lorsque l'organisation le permet
  • Correction de la télécommande ne recevant pas de messages pendant des minutes à un moment où une demande de reconnexion n'obtenait aucune réponse ; il abandonne maintenant après 30 secondes et réessaye
  • Correction des hooks configurés avec asyncRewake réveillant Claude encore et encore avec des notifications de « problèmes trouvés » lorsque le fichier de script du hook est manquant ; le crochet cassé est désormais signalé une fois
  • Correction des battements de cœur de l'outil n'atteignant pas les hôtes SDK alors que le flux de réponse du modèle était bloqué sans qu'aucune donnée n'arrive
  • Correction des vérifications des modèles de démarrage Bedrock et Vertex ignorant une liste availableModels appliquée, ce qui pouvait réduire /model à une seule ligne Opus.
  • Correction du sélecteur de navigateur Claude dans Chrome affichant une erreur d'analyse JSON lorsque Chrome n'était pas accessible
  • Correction du choix de Fable dans /model sur une connexion claude.ai en enregistrant l'identifiant de la version actuelle, de sorte que votre valeur par défaut enregistrée suit désormais la nouvelle Fable comme le font Opus et Sonnet.
  • Correction du basculement entre Opus 5.5 et Sonnet 5.5 (/model, opusplan) réécrivant les annonces précédentes de l'outil MCP, ce qui pourrait abandonner la réflexion étendue antérieure
  • Correction des blocs Amazon Bedrock Guardrails qui arrivent au milieu de la réponse et terminent le tour avec une erreur API au lieu du message du garde-corps lorsque la réponse commençait par une réflexion.
  • Correction d'un rm dangereux (comme celui sur / ou le répertoire personnel) perdant sa protection toujours demandée lorsque la même commande redirigeait également la sortie vers un ~ ou un chemin générique
  • Correction des sessions claude -p et SDK répétant un repli de modèle sur chaque message ultérieur après le changement de modèle pendant qu'une réponse était en cours d'exécution
  • Correction du CLAUDE.md d'un dossier étant attaché une seconde fois après la reprise d'une session ou après un compactage
  • Correction des sessions en arrière-plan qui ne pouvaient pas être rouvertes à partir de claude agents après la sortie de l'agent et suppression de l'arbre de travail dans lequel la session avait été démarrée.
  • Correction des vérifications d'appariement du /advisor : Sonnet 5.5 peut désormais conseiller les Opus 4.7 et 4.8, et les conseillers que le API refuserait sont signalés à l'avance au lieu d'être supprimés silencieusement.
  • Correction des invites d'autorisation Bash affichant les noms de l'analyseur interne tels que "Contient simple_expansion" au lieu d'une explication simple
  • Correction d'une cause de fermeture de sessions plein écran sur des machines lentes ou occupées avec "Claude Code quitté après une erreur d'interface irrécupérable" alors qu'une touche de défilement était maintenue enfoncée dans une longue conversation
  • Correction des plafonds d'autorisation d'organisation par outil étant supprimés silencieusement pour un outil MCP nommé __proto__
  • Correction de l'ordre de Claude de pager les résultats MCP volumineux enregistrés sous JSON avec le décalage et la limite de lecture, qui ne peuvent pas diviser une longue ligne.
  • Correction du rappel d'attribution de commit envoyé dans le résultat d'un outil après un compactage
  • Correction du mode lecteur d'écran laissant le curseur éloigné du texte saisi dans les champs de recherche (tels que /resume et /permissions) et les champs de code de connexion
  • Correction du mode lecteur d'écran refusant Enter sans rien taper dans les options de résumé de /rewind, dont le contexte ajouté est facultatif
  • Correction du mode lecteur d'écran affichant un indice "Tab pour modifier" dans les invites d'approbation, où Tab ne fait rien
  • Correction du mode lecteur d'écran répertoriant les touches fléchées qui ne font rien dans /permissions et /mcp, et disant "Sélectionner avec des chiffres" dans les menus vides ou lorsqu'un champ de recherche contient les touches
  • Correction du mode lecteur d'écran laissant de côté les lignes modifiées dans les invites d'approbation de modification de fichier et autres différences
  • Correction du mode lecteur d'écran envoyant à nouveau l'écran de progression du claude --teleport et un champ de formulaire MCP pendant sa vérification au lecteur d'écran à chaque image tournante.
  • Correction de CLAUDE_CODE_DISABLE_EXPERIMENTAL_BETAS ne supprimant pas le format de sortie structuré des demandes de titre de session et de hook d'invite, que les passerelles basées sur Bedrock rejettent
  • Correction du mode lecteur d'écran laissant de côté les lignes supérieures d'une deuxième invite d'approbation, une ligne /config modifiée ou la ligne de plan rejeté lorsque l'écran précédent était plus grand que la fenêtre du terminal
  • Correction de --include-partial-messages envoyant une réponse courte message_stop en retard ou jamais, afin que les applications puissent afficher la réponse comme étant toujours en cours
  • Correction de claude agents n'affichant parfois pas l'invite d'autorisation qu'une session en arrière-plan attend
  • Correction de /ultrareview donnant des conseils sur .git/info/attributes lorsque le téléchargement s'arrête sur un .gitattributes validé qu'il ne peut pas lire, comme celui enregistré au format UTF-16.
  • Correction de l'échec de l'enregistrement de claude remote-control derrière un proxy HTTP avec une erreur trompeuse "Vérifiez les autorisations de votre organisation" (anthropics/claude-code#97352)
  • Correction des commandes Bash en bac à sable sous Linux héritant d'un handle ouvert sur l'exécutable Claude Code
  • Correction du point de l'outil d'exécution et des trois roulettes toujours en mouvement avec le paramètre "Réduire le mouvement" activé, et l'écran de confirmation de /rewind mettant à jour son heure "il y a" pendant que vous tapez une note
  • Horaires fixes dans claude agents changeant toutes les secondes en mode lecteur d'écran ; ils changent désormais au maximum toutes les 10 secondes
  • Correction d'une connexion claude.ai révoquée affichant un API Error: 401 générique au lieu de "Jeton OAuth révoqué" ; en mode -p, l'erreur commence désormais par "Échec de l'authentification"
  • Correction des refus de téléchargement de /ultrareview vous conseillant de copier une variable nommée par le fichier de paramètres d'un référentiel dans vos propres paramètres utilisateur
  • Correction de --output-format stream-json et SDK ne diffusant pas les tours d'une compétence context: fork exécutée en tapant /<skill> comme invite, comme ils le font pour le fork de l'outil Compétence.
  • Correction de /feedback et /bug : le problème GitHub pré-rempli n'inclut plus vos messages d'erreur récents, et l'écran de confirmation les répertorie désormais dans le cadre du rapport.
  • Correction de l'échec des installations des plugins claude plugin marketplace add --sparse et git-subdir avec "transport 'http' non autorisé" lorsque le référentiel est servi via http simple.
  • Correction des sessions cloud perdant parfois la conversation précédente lorsque la session redémarrait pendant qu'elle était en cours de compactage
  • Correction d'un rechargement du plugin qui chevauchait le téléchargement de démarrage de --plugin-url, corrompant la copie en cache de la session de l'archive du plugin
  • Correction de /desktop citant une sortie partielle lors de l'ouverture de Claude Desktop, qui expirait ou imprimait trop de sortie ; l'erreur nomme maintenant la cause
  • Correction d'un appel de l'outil de connecteur MCP s'exécutant occasionnellement deux fois, ou des appels du connecteur échouant jusqu'au redémarrage, lorsque son serveur changeait la version du protocole MCP qu'il prend en charge.
  • Correction des hooks SessionStart des plugins synchronisés ne fonctionnant pas dans les nouvelles sessions cloud
  • Correction du résumé "N hooks exécutés" de la transcription et du nombre de hooks correspondants du journal de débogage détaillé, y compris les rappels internes de Claude Code, de sorte qu'un hook configuré n'apparaît plus comme deux
  • Correction des fichiers que Claude envoie depuis les sessions cloud et de contrôle à distance qui échouent lorsque le téléchargement se termine juste après le délai d'attente de 30 secondes ; il attend maintenant 35 secondes
  • Correction des dépôts ajoutés en milieu de session dans les sessions cloud et SDK ne chargeant pas leurs compétences et plugins, et chargeant CLAUDE.md tardivement, après que Claude ait changé de répertoire
  • Correction des images PNG, JPEG et WebP de plus de 8 000 pixels d'un côté qui ne pouvaient pas être envoyées depuis une session à distance ; Claude envoie maintenant une copie réduite
  • Correction des messages envoyés depuis les applications Claude avec 17 à 20 fichiers joints délivrant uniquement les 16 premiers
  • Correction des sessions sans tête signalant qu'un serveur MCP avait besoin d'une authentification après un appel refusé, même si les appels ultérieurs réussissent
  • macOS : correction des sessions de contrôle à distance démarrées avec l'arrêt du claude remote-control à mi-tour lorsque le Mac passait en mode veille
  • Windows : Correction du blocage ou du crash du claude interactif avec "Le mode brut n'est pas pris en charge" lorsque son entrée est redirigée ou redirigée ; il dit maintenant pourquoi et quitte (utilisez -p pour l'entrée canalisée)
  • Bedrock, Vertex, Mantle : correction des contrôles de disponibilité des modèles sous CLAUDE_CODE_SKIP_*_AUTH envoyant un en-tête Authorization différent des requêtes réelles lorsque ANTHROPIC_CUSTOM_HEADERS le répète
  • /config amélioré : les paramètres qui affichent ‹ › et avancent dans les deux sens avec ←/→, les terminaux étroits empilent chaque valeur sous son étiquette et PgUp/PgDn pagine la liste
  • Amélioration des erreurs du marché des plugins pour indiquer en termes simples pourquoi un marché a été ignoré ou refusé, et quoi faire
  • Listes de plugins améliorées pour noter quand les dépendances d'un plugin n'ont pas été installées, et la mise à jour d'un plugin réessaye désormais une installation qui ne s'est pas terminée
  • Amélioration de l'erreur de la passerelle des applications Claude lorsqu'Amazon Bedrock rejette un ID de modèle : les développeurs voient désormais quel modèle est indisponible et le journal de la passerelle nomme l'ID qui a été envoyé.
  • Sessions SDK améliorées afin qu'un message envoyé avec la priorité "maintenant" n'annule plus une récupération ou une recherche Web en cours ; il continue de se charger en arrière-plan
  • /memory amélioré : les touches fléchées gauche et droite activent/désactivent désormais les paramètres d'activation/désactivation, tels que la mémoire automatique
  • Amélioration des noms /skill saisis au milieu du message : Claude est maintenant informé qu'il s'agit de compétences, y compris celles de disable-model-invocation
  • Amélioration du contraste de la bordure de saisie rapide dans les thèmes clairs et du ❯ avant vos messages précédents
  • Amélioration de la livraison des fichiers que Claude envoie depuis les sessions cloud et Remote Control : un téléchargement qui échoue en raison d'un délai d'attente, d'une erreur réseau ou d'un 502, 503 ou 504 est désormais réessayé une fois
  • Amélioration de ce que dit Claude lorsqu'un fichier ne peut être envoyé pour une raison qui peut être temporaire : il mentionne désormais que vous pouvez redemander le fichier dans quelques minutes
  • Amélioration de l'invite pour un message en attente d'une autre session pour afficher le message entre des lignes pointillées, correspondant à d'autres invites d'autorisation
  • Amélioration du MCP et d'autres invites d'autorisation d'outil pour afficher l'appel de l'outil entre des lignes pointillées, correspondant aux invites de modification de fichier
  • Démarrage MCP amélioré en mode sans tête : un serveur distant dont la première connexion échoue de manière transitoire est désormais réessayé sans attendre que le serveur le plus lent ait fini de se connecter
  • Amélioration des fichiers que Claude envoie depuis une session distante : les fichiers volumineux sont désormais diffusés depuis le disque au lieu d'être lus en mémoire, et un fichier dépassant la limite de taille est refusé avec la limite du serveur nommée
  • Amélioration de l'explication donnée par Claude lorsque le serveur refuse un fichier qu'il envoie depuis une session Remote Control ou cloud, comme une image surdimensionnée
  • Gestion améliorée des résultats volumineux de l'outil MCP : moins de mémoire, des fichiers de session plus petits et aucun téléchargement supplémentaire pour compter les jetons pour les résultats dépassant largement la limite.
  • Windows : amélioration de la vitesse de l'outil Bash en supprimant un sous-shell exécuté avant chaque commande
  • Modification d'une écriture de shell via un lien symbolique repo-commit sur un fichier sensible ou hors de l'arborescence de travail pour nommer l'endroit où il atterrit et attendre une personne, également sur les lignes avec une cible ~
  • Modification d'Opus 4.7+ et Fable pour utiliser une fenêtre contextuelle de 1 M par défaut sur Bedrock, Vertex, Foundry et la passerelle des applications Claude, sans suffixe [1m] (CLAUDE_CODE_DISABLE_1M_CONTEXT=1 conserve 200K)
  • Modification des réponses de claude agents pour qu'elles arrivent sous forme de messages en file d'attente ; les commandes slash autres que /stop envoyées pendant qu'un tour est en cours s'exécutent désormais à la fin
  • Modification des règles d'autorisation de l'outil complet Bash et autorisation des hooks pour demander, et non exécuter, des écritures shell dans des fichiers. Les outils de fichiers de Claude Code refusent catégoriquement (le magasin de profils Anthropic, le fichier d'informations d'identification de l'hôte)
  • Modification du collage droit-click sous Windows et Linux, et du milieu-click collé sous Linux, pour qu'il se produise lorsque le bouton est relâché ; éloigner le pointeur avant de le relâcher l'annule
  • Modification du serveur MCP alwaysLoad: false pour reporter tous les outils de ce serveur derrière la recherche d'outils
  • Modification du mode de lecteur d'écran pour écrire des lignes nouvelles ou modifiées sans faire de pause préalable avec le curseur au début de la ligne ; régler CLAUDE_AX_PREPARK_MS=50 pour restaurer la pause
  • Changement de modèle automatique après un message signalé pour conserver votre niveau d'effort actuel au lieu de celui par défaut du nouveau modèle
  • Modification des invites d'autorisation d'attente pour afficher les plus anciennes en premier, de sorte qu'une nouvelle invite ne couvre plus celle que vous lisez (les invites avec un compte à rebours sont toujours ouvertes en haut)
  • [VSCode] Ajout de "Exécuter en arrière-plan" à une commande ou un sous-agent en cours d'exécution, pour le déplacer en arrière-plan et continuer à travailler
  • [VSCode] Ajout de la sortie des shells d'arrière-plan et des moniteurs sur leurs cartes dans la carte des agents
  • [VSCode] Correction des boîtes de dialogue de paramètres attribuant un délai d'attente lorsque la réponse de Claude Code était trop longue pour confirmer une sauvegarde
  • [VSCode] Correction de la réouverture d'une session cloud que la barre latérale apportait déjà à cette machine en l'ouvrant à nouveau dans un nouvel onglet ; la barre latérale est affichée à la place
  • [VSCode] Correction de l'onglet Web de la barre latérale ne répertoriant pas les sessions cloud démarrées après le chargement de la fenêtre ; un chargement échoué indique désormais "Le serveur distant n'est pas connecté" au lieu de "Aucune session Web pour le moment"
  • [VSCode] Correction d'un onglet restauré après un rechargement démarrant un deuxième processus Claude sur une conversation dont la barre latérale est déjà ouverte ; il affiche maintenant l'avis "toujours ouvert ailleurs"
  • [VSCode] Correction des liens vers les fichiers de lignes d'outils, des liens vers la liste de sessions et deux astuces affichées en texte brut
  • [VSCode] Correction d'une commande toujours en cours d'exécution d'un agent en arrière-plan qui s'affichait comme ayant échoué une fois le tour principal terminé.
  • [VSCode] Correction de la propre commande /usage ou /context d'un utilisateur ouvrant la boîte de dialogue de l'extension au lieu de s'exécuter lorsqu'elle était sélectionnée dans le menu de commandes.
  • [VSCode] Correction des liens de fichiers dans l'onglet d'aperçu du plan ne faisant rien lorsque clicked ; ils ouvrent maintenant le fichier comme des liens dans les réponses au chat
  • [VSCode] Correction de l'échec de l'ouverture de l'entrée ou de la sortie d'un outil dans un onglet d'éditeur avec "Timeout en attente après 1000 ms" sur des hôtes distants tels que WSL lorsque l'onglet met du temps à apparaître
  • [VSCode] Amélioration de la boîte de dialogue Gérer les plugins : un échec d'ajout, de suppression ou d'actualisation du marché indique désormais ce qui n'a pas fonctionné
  • [VSCode] Modification du commutateur Claude dans Chrome "Activé par défaut" pour connecter également les propres sessions de l'éditeur, qui demandent toujours avant les actions du navigateur
  • [Sessions Cloud] Correction d'échecs occasionnels lors de la récupération ou de la transmission vers GitHub lorsque GitHub refusait brièvement un jeton d'accès nouvellement émis.
  • [Tag Claude] Correction de Claude publiant un avertissement d'échec, tel qu'un avis de limite de dépenses, dans un fil de discussion Slack lorsqu'un événement en arrière-plan comme l'activité GitHub le réveillait et que personne n'attendait de réponse.
  • [Claude Tag] Correction de la page des limites de dépenses de Claude Tag dans les paramètres d'administration, laissant de côté les canaux récemment créés et privés dans les organisations comportant de nombreux canaux.
  • [Claude Tag] Amélioration de la liste des tâches de Claude dans les longs fils de discussion Slack : le travail en arrière-plan ne le republie plus comme un nouveau message, donc les personnes qui suivent le fil ne sont pas averties
  • [Révision du code] Correction des commentaires de recherche et de leur texte « Pourquoi cela a été signalé » s'arrêtant au milieu d'une phrase ; ils se terminent maintenant par une phrase complète
  • [Code Review] Correction de Code Review ignorant une pull request après un nouveau push alors que sa révision avait échoué deux fois lors du commit précédent ; il examine maintenant le dernier commit
  • [Code Review] Amélioration de la fiche d'échec de révision sur une pull request dont la conversation est verrouillée : elle indique désormais que le verrou a bloqué la révision et que rien n'a été publié ou facturé
