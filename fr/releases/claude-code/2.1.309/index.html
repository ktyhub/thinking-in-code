claude-code v2.1.309

code-claude v2.1.309

Qu'est-ce qui a changé

  • Correction des commandes Bash en bac à sable sur macOS et Linux exécutant les fichiers de démarrage du shell en dehors du bac à sable avant chaque commande
  • Correction des modèles globaux denyWrite du bac à sable macOS ne s'appliquant pas à l'emplacement réel d'un chemin lorsque le dossier du modèle est atteint via un lien symbolique
  • Correction des commandes en bac à sable et des modifications automatiquement acceptées permettant de modifier le fichier de configuration MCP transmis avec --mcp-config
  • Correction d'un serveur MCP désactivé étant reconnecté par une invite d'autorisation ultérieure dans les sessions d'impression et SDK
  • Correction du contrôle d'autorisation Bash trusting sur une variable définie par une commande dont la redirection peut échouer à s'ouvrir
  • Correction des contrôles d'autorisation Bash ne demandant pas certaines commandes composées qui changent de répertoire avant d'exécuter git lorsque le cd est encapsulé ou préfixé, comme c'est le cas pour un simple cd
  • Correction d'une règle de refus Edit(path) ne bloquant pas une redirection Bash vers ce chemin dans certaines commandes contenant également un sous-shell
  • Correction des sessions isolées par arbre de travail acceptant certaines commandes préfixées par les paramètres régionaux que le gardien d'isolation devrait refuser
  • Correction des sessions isolées par worktree sur zsh acceptant certaines commandes arithmétiques que le gardien d'isolement devrait refuser
  • Correction des arbres de travail et des extractions de branches créés par Claude Code afin qu'ils ignorent les références de remplacement de git, comme le font déjà ses autres opérations git.
  • Correction de la protection en écriture du magasin de profils ne s'appliquant pas lorsque le répertoire de configuration est atteint via un lien symbolique
  • Correction des sessions compactant à plusieurs reprises après la lecture de fichiers sous un très gros CLAUDE.md imbriqué ; un CLAUDE.md imbriqué au-delà de la limite de taille ne charge désormais que son début
  • Correction de ctrl+enter (envoyer maintenant) mettant uniquement un message en file d'attente lorsqu'il est pressé avant le début de la réponse, et redémarrant les hooks d'une invite tout en laissant le message en file d'attente lorsqu'il est pressé pendant que ces hooks étaient en cours d'exécution.
  • Correction des commandes slash liées aux touches exécutées dans le shell à partir du mode !
  • Correction de ctrl+o n'affichant pas les messages des autres agents et sessions qui sont toujours en attente d'être livrés ; ils apparaissent désormais intégralement sous le relevé de notes, marqués comme en attente
  • Correction des longs aperçus de sortie des outils coupés à travers un emoji, laissant des transcriptions de session que jq ne pouvait pas analyser
  • Correction du rapport de lecture « Le fichier n'existe pas » pour les plages de pages PDF dans les sandbox Linux qui partagent le /proc du parent.
  • Correction des messages d'une session hébergée par Claude Desktop étant parfois perdus lors de l'actualisation de sa connexion
  • Correction de fonctionnalités manquantes dans les sessions Claude Code dans l'application de bureau Claude lorsque le terminal du même ordinateur était connecté à un compte ou une organisation différente.
  • Correction de la ligne d'état claude remote-control affichant HEAD comme branche d'un dossier qui n'est pas dans un référentiel git
  • Correction des coéquipiers des agents à volet divisé n'héritant pas des règles de refus de l'outil et --tools données sur la ligne de commande du leader.
  • Correction des sessions renommées avec /rename apparaissant dans d'autres sessions sous un nom généré après un rechargement de fenêtre VS Code ou un --resume non interactif
  • Correction de la liste /rewind affichant "Aucun changement de code" pour un tour qui modifiait les fichiers contrôlés via /code-review --fix, un sous-agent ou une commande shell
  • Correction de /privacy-settings affichant une valeur obsolète « Aidez à améliorer nos modèles d'IA » ; il indique désormais également quand le paramètre ne peut pas être récupéré
  • Correction des commentaires indiquant « réessayez plus tard » lorsque votre organisation n'accepte pas les commentaires ; il montre maintenant la raison du serveur et où signaler un bug
  • Correction des rapports/feedback surdimensionnés qui échouaient au lieu d'être renvoyés sans la transcription
  • Correction d'une compétence dans un dossier --add-dir qui était inaccessible lorsqu'une autre compétence portait déjà son nom ; il est maintenant proposé sous le nom de <folder>:<name>
  • Correction de /verify et /code-review ne trouvant pas la propre compétence d'un package imbriqué lorsque ses fichiers étaient modifiés depuis le shell
  • Correction de la compétence /claude-api indiquant que ant beta:worker poll --on-work transmet le contexte de trace à la commande
  • Correction de la configuration de traçage C# de la compétence /claude-api manquant des travées de la plateforme cloud clients
  • Correction de la compétence /claude-api indiquant que API s'étend sur les requêtes adressées à la plateforme Claude sur AWS et ne peut pas rejoindre la trace de l'appelant.
  • Correction des hooks qui s'exécutent dans PowerShell ne se bloquant pas lorsque le programme du hook se termine avec le code 2, et sous Windows, les hooks PreToolUse et PermissionRequest avec "shell": "powershell" ne s'ouvrent pas lorsque Git pour Windows n'est pas installé
  • Correction du hook turn.step d'un mod qui nomme un modèle par alias, tel que haiku, faisant échouer chaque requête avec une erreur de modèle : l'alias est désormais résolu en son modèle.
  • Correction des plugins et des compétences synchronisés depuis claude.ai étant supprimés, parfois en cours de session, après une erreur de lecture du disque
  • Correction des publications et mises à jour d'artefacts refusées pour certaines pages ordinaires, telles que les pages avec certains scripts minifiés ou artefacts que Claude ne pouvait pas lire en premier
  • Correction de Claude demandant la permission sur chaque mise à jour d'artefact pour le reste d'un tour après que la conversation ait été compactée dans ce tour
  • Correction du streaming d'outils à granularité fine restant désactivé sur Amazon Bedrock lorsque ANTHROPIC_BEDROCK_BASE_URL est défini sur le point de terminaison bedrock-runtime.<region>.amazonaws.com par défaut
  • Correction de l'indicateur "En attente de réponse API" clignotant derrière les passerelles qui envoient uniquement des pings keepalive : les routes hors du backend d'Anthropic attendent désormais 45 secondes
  • Correction de Claude avertissant les utilisateurs GitHub non liés en écrivant les noms de rôle et les espaces réservés comme mentions dans les PR, les problèmes et les commentaires
  • Linux : correction de l'écriture sandbox refusant la levée lorsqu'une commande en arrière-plan a survécu à la session
  • Windows : correction des vérifications d'autorisation PowerShell approuvant automatiquement certaines commandes Set-Location ou cd qui ciblent le répertoire actuel et contiennent des arguments supplémentaires ; ceux-ci demandent désormais approbation
  • macOS : Correction de la boîte de dialogue "Installer les outils de développement en ligne de commande" qui s'ouvrait à chaque démarrage de Claude Code sur un Mac sans Xcode ni les outils de ligne de commande
  • Exécuteur auto-hébergé : correction de --startup-timeout-min arrêtant une session dont la première invite, telle que /code-review, fonctionnait toujours dans un sous-agent ; un processus gelé est toujours arrêté
  • Amélioration de la vitesse de nombreuses commandes git que Claude Code exécute pour lui-même sous Windows ; sur chaque plateforme, les erreurs de ces commandes s'affichent désormais en anglais même lorsque git est défini sur une autre langue
  • Amélioration de l'erreur lorsqu'un module hooks est imbriqué trop profondément pour être chargé : il nomme désormais le fichier au lieu d'afficher un simple message de débordement de pile.
  • Amélioration de la gestion des disques pleins : une commande Bash coupée par un disque plein le dit désormais et nomme le dossier à libérer, et démarrer sur un volume temporaire complet imprime un message clair, pas une erreur ENOSPC brute
  • Amélioration de la compétence /claude-api pour proposer le traçage API aux côtés du traçage SDK lorsqu'il est demandé d'ajouter OpenTelemetry
  • Amélioration de la compétence /claude-api pour vérifier les documents en direct avant de dire qu'une fonctionnalité n'est pas prise en charge
  • Runner auto-hébergé : sessions améliorées qui se déplacent vers un nouveau coureur : Claude voit désormais l'appel de l'outil qui a été interrompu, marqué comme résultat inconnu
  • Mise à jour de la compétence de visualisation de données intégrée pour accepter l'APCA comme mesure de contraste de texte (en conservant les ratios WCAG 2 là où la conformité AA est requise), ajout d'une fonction apca(text, background) à ses scripts de validation de palette et indication si une étiquette à l'intérieur d'un remplissage de graphique coloré doit être blanche ou presque noire.
  • Mise à jour de la compétence /claude-api : les clés de compte de service et les jetons Workload Identity Federation peuvent désormais gérer les destinations OpenTelemetry
  • Modification de sed -i pour obtenir l'invite Bash standard et l'exécuter tel qu'écrit, et non un aperçu d'édition de fichier simulé ; comme les autres modifications Bash, il n'est plus restauré par /rewind
  • Modification de claude ultrareview pour exiger l'espace de travail trust : il demande sur un terminal, sinon il refuse ; les scripts transmettent --trust-workspace, qui ne prend aucune valeur (mettez un numéro PR ou une branche de base avant), ou définissez CLAUDE_CODE_DISABLE_ULTRAREVIEW_TRUST_CHECK=1
  • Modification des invites dangereuses rm et rmdir en mode de contournement des autorisations dans l'application de bureau et VS Code pour refuser la commande immédiatement avec un indice de réécriture, afin que les sessions sans surveillance continuent
  • Modification des commandes que les paramètres excluent du bac à sable pour demander avant d'écrire dans ses chemins de liste d'écriture lorsque le bac à sable est activé mais ne peut pas s'exécuter ; le repli sans bac à sable y est refusé
  • Modification de la création et de la réutilisation de l'arbre de travail afin que git ne récupère plus les objets à la demande, dans les clones ordinaires et dans les clones partiels avec un bac à sable Bash configuré ; un tel clone partiel les récupère en premier
  • Modification de la compétence /claude-api pour créer des équipes de sous-agents d'agents gérés sur multiagent_20261001 avec des flux de travail dynamiques activés par défaut, au lieu de coordinator
  • [VSCode] Ajout d'un avertissement de journal indiquant quoi faire lorsque la dictée ou les propres requêtes de l'extension échouent à la vérification du certificat, par exemple derrière un proxy d'inspection TLS.
  • [VSCode] Correction du panneau Claude restant vide après que l'éditeur ait mis en cache une copie incomplète de ses fichiers ; il récupère maintenant tout seul, ou indique ce qui n'a pas fonctionné et comment y remédier
  • [VSCode] Correction de l'historique des sessions se remplissant de sessions "Sans titre" vides à chaque fois que vous démarrez une nouvelle session sans envoyer de message
  • [VSCode] Correction de longs messages de commande slash tels que /goal remplissant le panneau de discussion ; ils se replient désormais derrière Afficher plus comme les autres invites (anthropics/claude-code#97469)
  • [VSCode] Correction des messages longs qui ne se repliaient pas derrière Afficher plus après que le panneau de discussion soit rendu plus étroit
  • [VSCode] Correction de Ctrl+J dans l'entrée du chat insérant toujours une nouvelle ligne : c'est désormais laissé à VS Code et au système d'exploitation lorsque "ctrl+j" est défini sur null dans le contexte Chat de ~/.claude/keybindings.json
  • [VSCode] Correction de l'étiquette "Depuis le… plugin" d'un mod au-dessus de l'invite dessinée sur la commande slash et les menus @-mention (anthropics/claude-code#102981)
  • [VSCode] Correction d'un élément de liste vide, d'un paragraphe ou d'un bloc de code et d'éléments de liste renumérotés à partir de 1, lors du collage de mathématiques LaTeX copiées
  • [VSCode] Correction de l'erreur de commentaires affichant uniquement un statut HTTP lorsque votre organisation n'accepte pas les commentaires
  • [VSCode] Amélioration de la vitesse d'édition et d'écriture dans le panneau de discussion : l'attente de nouveaux problèmes après chaque modification est désormais de 0.75 secondes dans la plupart des cas, passant de 1 à 1.5 secondes
  • [Sessions Cloud] Correction de la liste Ajouter un connecteur dans les formulaires de routine indiquant qu'aucun connecteur n'était disponible pendant leur chargement
  • [Sessions cloud] Correction de l'éditeur d'environnement cloud mélangeant les variables d'environnement et ajoutant des barres obliques inverses aux valeurs contenant les deux types de citations.
  • [Sessions cloud] Correction de la boîte de dialogue des détails de l'environnement auto-hébergé dans les paramètres d'administration afin que son titre, ses onglets et ses boutons restent visibles pendant que seul le contenu défile
  • [Sessions cloud] Correction de la ligne d'outil "lire la documentation" dans les sessions cloud, qui affichait JSON échappé au lieu d'une page lisible
  • [Sessions cloud] Amélioration du volet Modifications d'une session cloud, qui indique désormais lorsqu'il répertorie uniquement les commits poussés ou uniquement les modifications de Claude.
  • [Claude Tag] Correction de Claude dans Slack publiant par erreur un brouillon que vous avez approuvé pour une chaîne dans votre DM ; une publication sans chaîne est désormais refusée afin qu'elle puisse être envoyée sur la chaîne approuvée
  • [Claude Tag] Correction des autorisations et des refus sur les cartes d'approbation de Claude dans Slack qui ne faisaient rien lorsque la session s'était arrêtée ; votre réponse redémarre maintenant la session
  • [Claude Tag] Correction de Claude ignorant les messages non balisés dans un canal Slack après le déplacement de son espace de travail vers une autre organisation Claude, y compris les canaux non partagés sur Enterprise Grid
  • [Claude Tag] Correction de Claude dans une chaîne Slack publiant une réponse dans un fil de discussion avant de lire un message plus récent que quelqu'un venait d'ajouter à ce fil de discussion.
  • [Claude Tag] Correction de la page Slack dans les paramètres d'administration de Claude Tag indiquant qu'aucun espace de travail n'était connecté lorsque la liste ne se chargeait pas ; il affiche maintenant une erreur avec un bouton Réessayer
  • [Révision du code] Correction d'une révision terminée ne montrant aucune vérification de la demande d'extraction lorsque les tentatives précédentes de création avaient échoué ; un dernier essai ajoute maintenant une vérification terminée
  • [Code Review] Correction d'un push mis en file d'attente derrière une révision en cours démarrant toujours une révision après @claude review stop ; son chèque se ferme maintenant et dit pourquoi
