claude-code v2.1.284

Correctif Publié28 sept. 2026 Sourceanthropics/claude-code Anglais original

Cette page est traduite automatiquement. Le texte anglais original fait foi.

code-claude v2.1.284

Qu'est-ce qui a changé

  • Ajout de Claude Sonnet 5.5 (claude-sonnet-5-5), désormais le modèle Sonnet par défaut sur l'Anthropic API — contexte 1M, 2 $/10 $ par Mtok avec lectures de cache $0.20/Mtok
  • Ajout d'une réponse "Oui, mais redemandez la prochaine fois" à l'invite du mode automatique avant une lecture en dehors des répertoires de travail, afin que vous puissiez autoriser cette lecture et toujours être interrogé sur les suivantes
  • Ajout de montants en dollars à la limite de dépenses de la passerelle des applications Claude dans /usage et à la ligne d'état (par exemple "$271.40 / $500.00 dépensés ce mois-ci") lorsque la passerelle exécute cette version ou une version ultérieure ; le rate_limits.spend_limit de la ligne d'état gagne également used_usd, limit_usd et period
  • Ajout des actions de liaison de touches effortSlider:decreaseEffort, increaseEffort et toggleUltracode, afin que les touches fléchées et tabulation du curseur /effort puissent être rebondies dans keybindings.json
  • Ajout de /rate-limit-options à /help et du menu de commandes pour les abonnés claude.ai, de sorte que les avis de limite d'utilisation qui le mentionnent pointent vers une commande que vous pouvez trouver
  • Ajout de /mcp reconnect all dans le terminal interactif pour réessayer immédiatement chaque serveur MCP qui n'a pas réussi à se connecter ou qui a besoin d'une authentification
  • Ajout d'avertissements de démarrage de la passerelle d'applications Claude lorsque le availableModels d'une stratégie gérée est vide ou omet le modèle sur lequel Claude Code démarre sans définir model ou enforceAvailableModels
  • Ajout de auth: { google: {} } pour les destinations telemetry.forward_to de la passerelle d'applications Claude, afin que la télémétrie puisse être exportée directement vers le point de terminaison OTLP de Google Cloud à l'aide des informations d'identification Google Cloud de la passerelle.
  • Ajout de l'authentification par certificat client (private_key_jwt) entre la passerelle des applications Claude et son fournisseur d'identité, pour les fournisseurs d'identité qui émettent des informations d'identification de certificat au lieu des secrets client
  • Correction d'un flux de réponse endommagé affichant des erreurs brutes telles que « JSON Erreur d'analyse » ou « undéfini n'est pas un objet », ou l'écriture du mot « non défini » dans une réponse, au lieu d'être réessayé ou signalé comme une réponse interrompue.
  • Correction d'une erreur de serveur surchargé ou arrivant juste après un bloc de réflexion terminant le tour avec une erreur au lieu d'être réessayé.
  • Correction des erreurs "L'invite est trop longue" qui persistaient après le compactage : lorsque la requête compactée est encore trop longue, Claude Code compacte désormais à nouveau, gardant moins de la conversation récente
  • Correction d'une session dont le modèle est indisponible, sans modèle de secours, affichant un simple message "est actuellement indisponible" (ou "Quelque chose s'est mal passé" dans les sessions cloud) au lieu de l'avis d'indisponibilité du modèle et de son lien En savoir plus
  • Correction des sessions de l'agent SDK qui plantaient lorsqu'un message utilisateur contenait une image avec un source mal formé, et échouaient à chaque tour ultérieur après un bloc de document mal formé ; une image mal formée est désormais remplacée par une note explicative
  • Correction des appels à l'outil MCP lors d'une reprise de session échouant avec "Aucun outil de ce type disponible" alors que leur serveur était toujours connecté ; l'appel attend maintenant jusqu'à 10 secondes pour le serveur
  • Correction des appels répétés au point de terminaison d'utilisation du plan après avoir limité ou rejeté votre connexion : les vues d'utilisation de /usage, /extra-usage et IDE sont désormais désactivées au lieu de demander à nouveau.
  • Correction du succès du rapport claude mcp add lorsque les paramètres gérés restreignent les serveurs MCP aux plugins ; il refuse maintenant et dit quoi faire, au lieu de sauvegarder un serveur qui ne charge jamais
  • Correction de l'écran de configuration du /plugin : les options booléennes sont désormais un choix vrai/faux au lieu du texte libre, les options numériques refusent les saisies invalides et ←/→ modifient un champ d'options au lieu de changer d'onglet.
  • Correction de ANTHROPIC_FOUNDRY_RESOURCE interpolé dans l'hôte du point de terminaison Foundry non validé ; une valeur qui n'est pas un nom de ressource simple est désormais refusée
  • Correction de Claude Desktop derrière une passerelle d'applications Claude n'offrant aucune option de contexte 1M : la passerelle marque désormais automatiquement chaque modèle compatible 1M pour Desktop
  • Correction de ↓ en mode shell, sélectionnant une pilule de tâches en arrière-plan cachée, qui empêchait Retour arrière et Ctrl+U de modifier l'invite
  • Correction de l'échec de l'outil Bash sous Windows avec de nombreux plugins activés : les répertoires du plugin bin/ qui n'existent pas ne sont plus ajoutés à PATH, et les entrées héritées ne sont pas ajoutées deux fois.
  • Correction des places de marché du plugin sparsePaths clonant vide et remplaçant une copie locale fonctionnelle sur un ancien git (avant 2.39), qui échouait à chaque actualisation avec "le fichier marketplace.json n'est plus présent".
  • Correction du rendu plein écran effaçant la sortie du terminal au-dessus de la session lorsque [ en mode transcription écrit la conversation en scrollback (macOS et Linux)
  • Correction de la position de défilement en plein écran sautant au message précédent ou vers le bas lorsqu'une réponse a fini de diffuser pendant le défilement vers le haut
  • Correction des barres d'onglets dans les boîtes de dialogue telles que /config et /plugin cassant le titre et les étiquettes d'onglets au milieu du mot dans un terminal étroit ; un onglet qui ne rentre pas passe maintenant à la ligne suivante entière
  • Correction du sélecteur /model affichant "+1 modèle" sous la liste après avoir fait défiler jusqu'au dernier modèle ; le décompte couvre désormais uniquement les modèles situés en dessous des lignes visibles
  • Correction de /keybindings écrivant les liaisons Retour arrière et Supprimer pour une action de pied de page qui ne fait rien dans le keybindings.json généré
  • Correction d'une touche de fermeture du panneau d'agent de rebond (footer:close) tapant "x" au lieu d'elle-même sur la ligne de l'agent que vous visualisez
  • Correction du mode vim . ne répétant pas le texte tapé très rapidement (par exemple via ssh ou dans tmux) ou collé sans collage entre crochets, et laissant l'invite en mode INSERT après avoir répété une modification sans rien taper (comme cw puis Esc)
  • Correction du mode vim laissant le curseur sur le support ouvrant d'un espace réservé d'image après dd sur la dernière ligne ou yy à la fin de l'invite, où r ou x casserait ou supprimerait l'image
  • Correction d'une touche enfoncée à l'instant où le terminal retrouvait la mise au point répondant à l'invite d'activation de la télécommande avant le redémarrage de son court délai de sécurité.
  • Correction de la boîte de dialogue trust de l'espace de travail apparaissant une deuxième fois après le changement de moteur de rendu ou la mise à jour lorsque Claude Code était démarré dans le répertoire personnel
  • Correction des règles liées symboliquement dans .claude/rules depuis l'extérieur du projet qui étaient ignorées sans jamais afficher l'invite d'approbation des importations externes ; un répertoire .claude lié symboliquement depuis l'extérieur du projet demande désormais la même approbation
  • Correction des plugins des places de marché, claude.ai et npm pré-approuvant leurs propres outils via allowed-tools sous allowManagedPermissionRulesOnly géré ; seuls les plugins provenant d'une source Anthropic officielle ou d'une source qui gère les paramètres se portent garants de conserver cette pré-approbation
  • Correction d'un premier échec de claude plugin install laissant le plugin activé et enregistré lorsque la plage de versions d'une dépendance ne pouvait pas être respectée
  • Correction du journal de débogage supprimant le stderr d'un hook défaillant lorsque le hook écrivait également sur stdout, et n'enregistrant rien pour un hook échoué sans sortie ; les hooks ayant échoué enregistrent désormais également leur code d'état
  • Correction de {"decision":"block"} renvoyé par les hooks Elicitation et ElicitationResult étant ignorés ; il déclines l'élicitation MCP, comme le fait le code de sortie 2
  • Correction des sessions lancées sans que l'outil SendMessage (comme par Claude Desktop) ne soit toujours invité à envoyer des messages à d'autres sessions avec lui
  • Correction d'une photo envoyée depuis l'application Claude via la télécommande qui était perdue lorsque son message en file d'attente était ramené dans l'invite du terminal pour la modifier, et le curseur déplaçait un caractère pour une photo sans légende
  • Correction de la saisie d'un message pendant une attente automatique de limite d'utilisation, supprimant l'attente du contrôle du paramètre "Continuer automatiquement à la limite d'utilisation" lorsque ce tour atteignait à nouveau la limite.
  • Correction des avertissements de limite d'utilisation suggérant /upgrade aux utilisateurs déjà sur le forfait Max le plus élevé ; les avertissements et /upgrade lui-même pointent désormais vers /usage-credits lorsqu'il est disponible
  • Correction du sous-agent Explore passant à Opus sur le Claude API lorsque la session exécute un ID de modèle que Claude Code ne reconnaît pas, comme un modèle personnalisé derrière un proxy ; Explore hérite désormais de ce modèle
  • Correction des mises à jour du statut du /loop en mode à votre rythme qui n'étaient souvent pas affichées car Claude les avait écrites uniquement dans son raisonnement ; Claude écrit désormais chaque mise à jour, et le résultat lorsque la boucle s'arrête, sous forme de texte visible
  • Correction de /ultrareview qui ne parvenait pas à télécharger l'arborescence de travail lorsqu'il était démarré à partir d'un arbre de travail git créé par l'application de bureau Claude sur macOS ou Linux.
  • Correction des commandes Bash en bac à sable qui ne démarrent pas sous Linux lorsque le répertoire de travail est refusé en écriture et contient un répertoire en lecture refusée.
  • Correction des résultats d'écriture de la base de données d'artefacts indiquant à Claude que chaque spectateur voit une écriture dans le sous-arbre privé data/users/ d'un spectateur, et ajout d'un niveau "vue" à as_level
  • Correction de la passerelle des applications Claude répondant à 431 Request Header Fields Too Large à chaque demande d'une connexion dont le fournisseur d'identité répertorie de nombreux groupes ; il accepte désormais les en-têtes de requête jusqu'à 256 Ko
  • Amélioration de l'attente de la limite d'utilisation : l'état de la limite et le compte à rebours avec l'option de crédits d'utilisation s'affichent désormais sous la forme d'un seul bloc sous l'invite, et les messages de limite ne répètent plus le compte à rebours.
  • Amélioration de l'erreur "Aucun outil de ce type disponible" pour Claude dans les outils Chrome appelés sans leur préfixe : il nomme désormais l'outil à appeler
  • Amélioration des lignes d'événements du moniteur pour afficher ce que chaque événement imprime au lieu de répéter la description, et arrêt de la répétition d'une ligne inchangée "En attente de N… pour terminer" après chaque événement
  • Amélioration du renforcement du bac à sable de l'outil Workflow pour les erreurs générées par les hooks de script asynchrone
  • Amélioration du temps de démarrage et de l'utilisation de la mémoire en créant uniquement les parties du schéma de paramètres que vos fichiers de paramètres utilisent réellement
  • /claude-api amélioré : hillclimb ne consacre plus de temps à des reformulations rapides trop petites pour que l'évaluation puisse être mesurée, et une page supplémentaire que vous demandez à côté de report.html est construite comme un fichier local qui ne charge rien depuis le réseau.
  • Listes améliorées telles que /tasks, /copy et /hooks : les détails après chaque nom s'alignent désormais dans une colonne lorsqu'ils correspondent, et sinon se trouvent sur le bord droit
  • claude plugin marketplace add amélioré pour indiquer quand il remplace une place de marché déjà ajoutée sous le même nom à partir d'une source différente, et comment l'annuler
  • Amélioration du refus de démarrage lorsque les paramètres gérés nécessitent une connexion (forceLoginMethod ou forceLoginOrgUUID) et qu'une clé, un jeton ou un apiKeyHelper API est configuré : il nomme désormais l'identifiant utilisé, où il est défini et comment le supprimer.
  • Chargement automatique de la mémoire amélioré : les caractères invisibles et les balises qui imitent le propre balisage de Claude Code sont neutralisés dans MEMORY.md et rappelés aux notes de mémoire avant qu'ils n'atteignent Claude
  • claude remote-control amélioré : dans un dossier que vous n'avez pas encore utilisé trust, il demande désormais l'espace de travail trust sur le terminal au lieu de quitter
  • Pages d'artefact améliorées : Claude écrit son plan de conception dans la page au lieu de la réponse et utilise le nom que vous avez déjà donné comme titre de page.
  • Amélioration de l'outil Artefact afin que lorsque Claude reçoit un chat ou un lien de projet claude.ai, un artefact d'un chat ou un identifiant d'artefact seul, il demande le bon lien ou le bon contenu au lieu de s'arrêter.
  • Modification du terminal interactif et des sessions VS Code pour démarrer en mode automatique lorsqu'aucun mode d'autorisation n'est configuré, sur chaque forfait et fournisseur ; permissions.defaultMode le remplace toujours
  • Modification d'Ultracode en sa propre bascule dans /effort (Tab ou /effort ultracode [on|off]) : il ne force plus un effort très élevé et reste activé à n'importe quel niveau d'effort
  • Modification des tentatives après une interruption de connexion en cours de réponse pour partager un budget avec le reste des tentatives de la demande, de sorte qu'une demande échouée abandonne plus tôt
  • Modification de l'avis affiché lorsque les protections d'un modèle Sonnet signalent un message pour expliquer pourquoi cela s'est produit et proposer une modification et une nouvelle tentative.
  • Modification des commutateurs de modèle liés à la sécurité dans les sessions qui épinglent un modèle Opus avec ANTHROPIC_DEFAULT_OPUS_MODEL ou modelOverrides : sur l'Anthropic API, le API sélectionne désormais le modèle vers lequel basculer pour chaque type de drapeau, et non le modèle épinglé.
  • Modification du premier tour non interactif pour qu'il attende toujours jusqu'à 2 secondes pour la connexion des serveurs MCP nommés par --allowedTools ou un hook mcp_tool, même lorsque CLAUDE_CODE_MCP_STARTUP_WAIT_MS est 0
  • Changement de /recap en decline avec un bref préavis lorsqu'il arrive relayé depuis un fil de discussion (le vôtre inclus) ou depuis une routine ou un webhook ; tapé dans le terminal, les applications Claude, Remote Control, -p ou un hôte SDK, ça tourne comme avant
  • Modification de /artifacts pour afficher ses onglets de filtre à côté du titre avec des étiquettes d'un seul mot (Tous, Mine, Partagé), en utilisant la même barre d'onglets que /config et /plugin
  • Modification de la publication d'artefacts pour refuser un fichier sur un partage réseau (un chemin \\host\share ou un montage automatique /net) sauf s'il se trouve sur un lecteur réseau mappé ajouté avec --add-dir
  • [VSCode] Ajout d'une heure facultative au-dessus de chaque invite et réponse, avec une ligne de date où le jour change (Code Claude : paramètre Afficher l'horodatage des messages, désactivé par défaut)
  • [VSCode] Ajout d'erreurs de chargement de plugin et de notes dans les lignes Gérer les plugins, avec une fenêtre contextuelle pour désactiver, désinstaller ou copier l'erreur
  • [VSCode] Ajout d'un interrupteur marche/arrêt Ultracode sous le curseur Effort, remplaçant l'arrêt Ultracode du curseur ; la pilule modèle affiche "· Ultracode" à n'importe quel niveau d'effort
  • [VSCode] Correction du rechargement de Claude à partir de la boîte de dialogue Mémoire avant qu'un fichier modifié ne soit enregistré
  • [VSCode] Correction d'un onglet restauré ouvrant une conversation qu'un autre processus Claude a encore ouverte ; il demande maintenant en premier
  • [VSCode] Correction des sections de vue que vous avez développées en se fermant d'elles-mêmes pendant qu'un sous-agent travaille ou lorsque la première étape de la section est supprimée de la vue.
  • [VSCode] Correction de la saisie de /model et de la saisie du texte d'utilisation de l'impression dans le chat au lieu d'ouvrir le sélecteur de modèle
  • [VSCode] Correction du refus de /feedback sur Vertex, Bedrock et Foundry après avoir appuyé sur Envoyer ; le rapport est désormais enregistré sur cet ordinateur, comme le fait le terminal
  • [VSCode] Correction de la connexion attendant jusqu'à une minute pour l'extension Python après un rechargement de fenêtre
  • [VSCode] Correction des onglets Claude Code qui ne répondaient plus après le redémarrage des extensions : ils rouvrent désormais sur leur conversation
  • [VSCode] Correction d'un message d'un autre agent sans expéditeur enregistré s'affichant au format XML brut dans le chat
  • [VSCode] Correction des messages d'autres agents, sessions ou canaux disparaissant après un rechargement
  • [VSCode] Correction de la propre commande /mcp, /config ou /settings d'un utilisateur masquée par la boîte de dialogue de l'extension
  • [VSCode] Correction d'Escape arrêtant chaque agent d'arrière-plan lorsqu'aucun tour n'était en cours
  • [VSCode] Correction des liens d'installation du plugin remplaçant un marché que vous possédez déjà et qui utilise le même nom
  • [VSCode] Correction des erreurs "L'invite est trop longue" après le compactage lorsqu'un fichier texte volumineux est joint à un message
  • [VSCode] Correction des liens de discussion vers des fichiers contenant des caractères non-ASCII, des espaces ou des crochets dans leur chemin qui ne s'ouvraient pas
  • [VSCode] Modification de CLAUDE_CONFIG_DIR dans le paramètre claudeCode.environmentVariables pour qu'il s'applique uniquement lorsqu'il s'agit d'un chemin absolu, et l'a transmis aux terminaux qui continuent le chat
  • [Sessions Cloud] Correction des contrôles d'édition et de duplication d'une routine indiquant que la routine était toujours en cours de chargement lorsque vous étiez hors ligne ; ils te disent maintenant que tu es hors ligne
  • [Claude Tag] Ajout de choix de famille de modèles tels que "Opus (dernier)" pour un fil de discussion, un canal par défaut ou votre DM, afin que le choix suive le modèle le plus récent de cette famille.
  • [Claude Tag] Ajout des dépenses prises en compte dans la limite à l'échelle de votre organisation au tableau de projection des dépenses analytiques, avec la part de la limite utilisée.
  • [Claude Tag] Correction de la carte de progression et des aperçus de liens de Claude dans l'application Slack, en omettant le référentiel et le bouton Créer PR lorsqu'un nom d'hôte GitHub Enterprise contient un trait de soulignement.
  • [Claude Tag] Correction de Claude restant silencieux dans un canal dont l'environnement declines pour le démarrer ; il publie désormais un avis vous demandant de contacter un administrateur et réessaye lorsque @-mentionné
  • [Claude Tag] Modification de Claude pour qu'il publie son avis de connexion privé à chaque @mention de quelqu'un qui n'a pas connecté son compte Claude, au lieu de se taire après la première
  • [Claude Tag] Amélioration de « Notifier les membres maintenant » dans les paramètres d'administration : une seule pression atteint chaque espace de travail revendiqué par votre organisation dans une Enterprise Grid, et davantage de membres dans les grands espaces de travail.
  • [Claude Tag] Amélioration du avis d'attente de Claude sur les environnements auto-hébergés avec des coureurs à la demande : il indique désormais si un coureur part, un départ sera retenté ou aucun coureur ne prendra le départ.
  • [Claude Tag] Amélioration de l'erreur affichée lors de l'échec de l'ajout d'un gestionnaire de chaîne car l'espace de travail Slack de la chaîne ne peut pas être confirmé comme étant connecté à votre organisation.
  • [Claude Tag] Amélioration des listes d'accès d'un canal dans les paramètres d'administration pour afficher les connecteurs, les référentiels et les plugins auxquels un modèle de jointure automatique est joint, et d'où chacun vient.
  • [Claude Tag] Amélioration de l'ajout de référentiels en tant que gestionnaire de canaux : lorsque votre connexion GitHub ne peut pas confirmer que vous êtes un administrateur de référentiel, la page vous demande de vous connecter avec GitHub
  • [Code Review] Correction de l'abandon de la révision de code sans publier une révision terminée lorsqu'une révision non soumise sous son application GitHub était ouverte sur la demande d'extraction ; il réessaye maintenant le message en premier
