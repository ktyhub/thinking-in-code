claude-code v2.1.286

Correctif Publié30 sept. 2026 Sourceanthropics/claude-code Anglais original

Cette page est traduite automatiquement. Le texte anglais original fait foi.

code-claude v2.1.286

Qu'est-ce qui a changé

  • Ajout d'un nombre tel que "2 sur 5" à l'invite d'autorisation lorsque plusieurs demandes d'autorisation s'empilent
  • Ajout de la prise en charge de la souris pour les lignes de listes "N plus" en mode plein écran : click une pour accéder à cette fin de la liste, avec les états de survol et d'appui.
  • Correction de plusieurs processus Claude Code et extensions IDE ouvrant chacun un navigateur de connexion lorsque les informations d'identification gcpAuthRefresh ou awsAuthRefresh expirent
  • Correction de claude --resume et --continue perdant parfois à chaque tour après un lot d'appels d'outils parallèles lorsque la session précédente plantait ou était tuée
  • Correction des erreurs API 400 après qu'un outil ou un hook renvoyait un objet, un nombre ou un booléen au lieu de texte, y compris lors de la reprise des sessions
  • Correction des sessions cloud avec des historiques très volumineux ne se réveillant jamais car le conteneur était arrêté alors que la transcription était encore en cours de chargement
  • Correction du compteur de dépenses de la passerelle d'applications Claude, qui tarife les écritures de cache d'invite d'une heure au tarif moins cher de 5 minutes, et ne compte que les jetons d'entrée du premier appel de modèle sur les tours en streaming qui exécutent un outil côté serveur tel que la recherche sur le Web.
  • Correction des sessions macOS affichant toujours "Non connecté" ou "Connexion expirée" après la réussite de /login dans une autre fenêtre Claude Code lorsqu'un ~/.claude/.credentials.json restant existe
  • Correction de chaque échec de tour lorsque l'Anthropic API refuse le modèle par défaut ou un alias de modèle se résout : Claude Code réessaye désormais une fois sur le modèle précédent du même niveau
  • Correction des sessions de contrôle à distance (y compris claude remote-control) restant connectées après que la politique de votre organisation désactive le contrôle à distance ; ils se déconnectent maintenant avec un avis
  • Correction du refus et des tentatives d'échec de --fallback-model lorsque le modèle de secours ne peut pas fonctionner rapidement ; ils fonctionnent désormais à vitesse standard, avec un préavis unique lors des sessions interactives
  • Correction des sessions sans tête répétant le rappel « Les serveurs MCP nécessitent une authentification » après une ré-authentification réussie lorsque le cache de découverte MCP est activé
  • Correction de claude auth status signalant la clé API stockée d'une connexion à la console comme claude.ai ; il signale désormais api_key et l'extension VS Code traite cette session comme une session clé API
  • Correction de /status listant un profil Anthropique à côté d'une clé API comme si les deux étaient en vigueur ; le profil est maintenant marqué comme non utilisé
  • Correction de Claude qui n'était pas informé lorsqu'un fichier joint à un message envoyé via la télécommande n'arrivait pas, et un fichier n'obtenait parfois que 10 secondes pour sa dernière tentative de téléchargement
  • Correction d'un message de télécommande qui arrivait alors que Claude Code sortait et était marqué comme livré et ne répondait jamais ; il reste désormais en file d'attente pour la prochaine exécution de la session
  • Correction des messages d'erreur MCP affichant la valeur d'un identifiant lorsque "Bearer" ou "Basic" apparaissait avant son nom de clé
  • Correction des jetons Bearer codés en pourcentage n'étant que partiellement masqués dans les messages d'erreur
  • Correction des journaux et des transcriptions expurgés montrant un secret dont le nom de clé contient un caractère invisible à l'intérieur, comme un espace de largeur nulle.
  • Correction des journaux et des transcriptions affichant une partie d'un mot de passe d'URL contenant des signes de ponctuation tels que ), des guillemets, ], & ou un deuxième @, ou qui dépasse un / vers un hôte entre crochets tel que [::1] dans une URL ssh.
  • Correction de la transcription de la session dans le zip que /feedback enregistre sur le disque contenant des lignes JSON invalides après rédaction secrète
  • Correction des connecteurs MCP ne répertoriant aucun outil jusqu'à un jour après que leur serveur ait abandonné l'ancienne poignée de main MCP.
  • Correction d'une demande répétée de connexion MCP de Claude remplaçant le lien de connexion en attente, ce qui pouvait empêcher ce lien de fonctionner
  • Correction de /usage ne créditant pas un serveur MCP pour un appel d'outil effectué alors que ce serveur était encore en train de se connecter ou venait juste de se connecter, comme juste après un redémarrage
  • Correction des plugins activés sur claude.ai manquant parfois dans Claude Code pour une session après une erreur de serveur passagère
  • Correction d'un message tapé dans un sous-agent en cours d'exécution qui s'affichait deux fois dans sa transcription après que le sous-agent l'ait lu
  • Correction des messages de renvoi du sous-agent affichant un identifiant de tâche brut au lieu du nom de l'agent lorsque le sous-agent n'avait pas de nom enregistré
  • Correction des sous-agents de premier plan manquant parfois des outils de suivi des tâches (TaskCreate/Get/Update/List, TodoWrite) dans les sessions pour lesquelles ils sont activés
  • Correction des sous-agents générés avec l'isolation de l'arbre de travail chargeant le projet CLAUDE.md et ses importations une seconde fois à partir de la copie de l'arbre de travail lors de leur première lecture de fichier
  • Correction des sous-agents de l'outil Workflow redémarrés à partir de leur invite d'origine lorsqu'une connexion était bloquée pendant quelques minutes en cours de réponse.
  • Correction de /compact, /clear et /rewind saisis lors de l'affichage de la transcription d'un agent ou d'un coéquipier en arrière-plan agissant silencieusement sur la conversation principale : une boîte de dialogue nomme désormais la cible et demande en premier
  • Correction des tâches en arrière-plan affichées en attendant votre approbation
  • Correction du rappel d'attribution de validation étant renvoyé dans la sortie de l'outil lorsqu'un repli de modèle ne dure qu'un tour
  • Correction d'un click sur l'espace entre les mots d'une ligne réduite (comme "Pensée pendant 4s") mettant en évidence la ligne sans l'agrandir en mode plein écran
  • Correction d'une ligne sans détails, telle qu'une ligne d'action avec un nom long, poussant les détails d'une ligne sur deux vers la droite dans les écrans de liste
  • Correction des fichiers avec des noms très longs n'atteignant pas une session cloud lorsqu'ils y sont attachés
  • Correction d'erreurs de plugin pour une marketplace que Claude Code refuse de charger : ils disent maintenant pourquoi et comment le réparer au lieu de "introuvable"
  • Correction de l'onglet Découverte de /plugin affichant un nom de marché sans guillemets dans sa ligne "Vérification… de nouveaux plugins" alors que ses lignes affichent déjà ce nom entre guillemets
  • Amélioration des conseils de validation : lorsque votre projet ou vos compétences utilisateur en incluent un nommé verify, Claude est désormais invité à l'exécuter juste avant de valider, sauf pour les validations de documents uniquement et de tests uniquement.
  • Amélioration de l'envoi immédiat (ctrl+entrée) dans la vue d'un sous-agent : il déplace désormais la commande en cours d'exécution du sous-agent en arrière-plan afin que votre message soit lu immédiatement
  • Amélioration des réponses des agents en arrière-plan à vos messages afin qu'ils ne s'ouvrent plus avec un récapitulatif séparé de ce que vous avez dit
  • Lecture améliorée du lien d'artefact claude.ai : WebFetch pose désormais les mêmes questions que la lecture de l'outil Artifact (pas d'invite d'artefact lorsque l'accès réseau de la session est activé, une par artefact lorsqu'il est désactivé), et un mode automatique oui ne compte plus là où vous seul pouvez répondre
  • Amélioration de la récupération, des compétences, de la lecture de fichiers, du réseau sandbox, de Claude dans Chrome, des invites de script de workflow et d'autorisation de modification du bloc-notes pour correspondre à l'apparence des invites de modification de fichiers
  • Amélioration des invites d'autorisation Bash, PowerShell et Monitor pour afficher la commande entre des lignes pointillées, correspondant aux invites de modification de fichier
  • Barres de défilement de liste améliorées en mode plein écran : dans la plupart des listes, la barre ne se déplace plus lorsque les lignes "N plus" vont et viennent, et elle comporte désormais des flèches ↑/↓ que vous pouvez appuyer ou maintenir enfoncées pour faire défiler
  • Amélioration de l'éditeur externe (Ctrl+G) : les éditeurs qui prennent un numéro de ligne s'ouvrent désormais sur la ligne sur laquelle se trouve votre curseur dans l'invite
  • Amélioration de la réactivité des suggestions de commandes slash lors de la saisie lorsque de nombreuses compétences ou commandes de plugin sont installées ; les descriptions des commandes correspondent désormais par préfixe de mot
  • Amélioration du sélecteur de style de sortie : il s'ouvre désormais sur votre style actuel au lieu de celui par défaut, avec la description de chaque style sur la ligne sous son nom ; les touches numériques ne choisissent plus un style
  • /hooks amélioré : la ligne de fermeture de l'écran de détail d'un crochet indique désormais "ce crochet" au lieu de "il"
  • Amélioration de l'avis de repli du modèle et de l'erreur d'autocompact-thrashing pour indiquer quand un repli a fait chuter la fenêtre contextuelle de 1 million à 200 000 jetons.
  • Amélioration de la réactivité des sessions SDK et -p lorsqu'un hôte renvoie une activation de serveur MCP pour un serveur déjà connecté
  • Amélioration de la page de protocole servie par une passerelle d'applications Claude sur /protocol : elle indique désormais de ne pas rejeter les entrées inconnues et correspond à ce que Claude Code envoie aujourd'hui
  • Modification des invites envoyées alors que rien n'est en cours d'exécution ou en file d'attente pour s'afficher immédiatement dans la couleur normale du texte au lieu du gris
  • Modification de la façon dont les requêtes API ayant échoué sont réessayées : une limite couvre désormais l'intégralité d'un appel de modèle, donc avec les paramètres de nouvelle tentative par défaut, un appel échoué envoie au maximum 14 requêtes.
  • Modification de --bare pour connecter uniquement les serveurs MCP nommés sur la ligne de commande, n'envoyer au modèle aucun rappel système et ne démarrer aucune tâche en arrière-plan ; sous --bare, une commande shell qui atteint son timeout s'arrête désormais au lieu de passer en arrière-plan
  • Modification de la touche d'envoi immédiat (ctrl+entrée) pour déplacer la commande shell d'une compétence en arrière-plan au lieu d'y mettre fin.
  • Modification de l'erreur WebFetch pour une vérification de sécurité de domaine à débit limité pour indiquer à Claude de ne pas réessayer en boucle
  • Modification des installations de plugin pour refuser les sources npm qui sont des référentiels ou des dossiers git, et pour installer les dépendances de plugin uniquement à partir des packages de registre
  • Modification des écrans de liste (/artifacts, /mcp, /skills, /hooks et autres) pour toujours aligner les détails de chaque ligne dans une colonne après les noms
  • Modification des lignes de débordement des listes pour lire "↑ N plus" / "↓ N plus" au lieu de "N plus au-dessus" / "N plus en dessous"
  • Modification de /hooks pour ouvrir sur une liste de vos hooks configurés regroupés par événement, donc l'affichage d'un hook prend une Entrée au lieu de trois
  • Modification du sélecteur de thème en une liste déroulante adaptée à votre terminal au lieu de pousser l'aperçu hors de l'écran ; les touches numériques ne choisissent plus un thème
  • Modification de l'arbre de travail Remove de /exit pour qu'il s'exécute après que Claude Code arrête les serveurs et les shells qu'il a démarrés là-bas, ce qui sous Windows pourrait empêcher la suppression du dossier.
  • Modification des exemples d'agents gérés de la compétence claude-api pour créer des environnements avec un réseau limité
  • Suppression du lien du navigateur de la sortie /ultrareview et claude ultrareview
  • Windows : Correction de claude --bg et de la vue des agents refusant un dossier que claude avait déjà trust lorsque son enregistrement trust était enregistré avec une casse différente
  • [VSCode] Ajout de signets : enregistrez les réponses de Claude et gardez-les visibles dans un panneau latéral de signets
  • [VSCode] Ajout des questions posées par Claude et de vos réponses à la conversation : après avoir répondu à une carte de questions, une ligne de questions affiche chaque question avec vos choix
  • [VSCode] Ajout d'aperçus d'options aux cartes de questions dans le panneau de discussion : la maquette ou l'extrait du choix en surbrillance s'affiche à côté ou sous les options
  • [VSCode] Ajout de lignes sous un message qui s'ouvrent sur la sortie du terminal, l'onglet du navigateur, les instructions du navigateur et le code sélectionné envoyé avec celui-ci
  • [VSCode] Correction d'une deuxième copie d'une conversation s'ouvrant dans un onglet alors qu'elle était déjà ouverte dans la barre latérale ; la barre latérale y bascule maintenant
  • [VSCode] Correction des boîtes de dialogue de paramètres signalant un échec de sauvegarde, sans revérification, lorsque Claude Code imprimait plus de 1 Mo de sortie
  • [VSCode] Correction d'un spinner "Session de téléportation…" sans fin lorsque l'extension cesse de répondre
  • [VSCode] Amélioration de la boîte de dialogue Gérer les plugins : elle indique quand un plugin désactivé est toujours activé en raison d'autres paramètres, et explique un conflit de dossier de plugin
  • [VSCode] Modification de Stop et Escape pour terminer uniquement le tour en cours ; les agents en arrière-plan continuent de fonctionner et peuvent être arrêtés un par un à partir de la carte des agents
  • [VSCode] Modification de l'élément de la barre d'état "✻ Claude Code" pour qu'il s'affiche dans chaque fenêtre, afin que vous puissiez ouvrir Claude lorsqu'aucun fichier n'est ouvert
  • [Sessions Cloud] Correction d'une carte de questions avec réponse ou d'un appel d'outil approuvé n'obtenant aucune réponse lorsque la session était devenue inactive après l'envoi d'un message par Claude
  • [Sessions cloud] Correction de la suppression du script de configuration d'un environnement d'organisation dans les paramètres d'administration, laissant les nouvelles sessions cloud exécutant toujours l'ancien script.
  • [Sessions Cloud] Correction du menu d'actions Runner sur la page d'administration des environnements auto-hébergés se fermant tout seul quelques secondes après son ouverture
  • [Sessions Cloud] Correction des exécutions de routine dont la session cloud n'a jamais commencé à apparaître comme réussie dans le volet Exécutions, la page de la routine et la barre latérale ; ils s'affichent maintenant comme Échec
  • [Sessions Cloud] Correction de clicking d'un fichier audio ou vidéo dans la carte Sorties d'une session cloud ouvrant une recherche de fichier vide au lieu de lire le fichier
  • [Sessions Cloud] Modification de la page d'une routine pour lire « Due » avec l'heure planifiée, au lieu d'une prochaine heure d'exécution dans le passé, lorsqu'une exécution planifiée est en retard et n'a pas démarré
  • [Claude Tag] Ajout d'un bouton Ajouter une chaîne à la page des limites de dépenses de Claude Tag dans les paramètres d'administration, afin qu'une limite puisse être définie sur n'importe quelle chaîne, y compris une chaîne privée, à partir de son identifiant de chaîne ou de son lien Slack.
  • [Claude Tag] Correction du rappel de mémoire ne trouvant rien dans les organisations qui ne peuvent pas utiliser le modèle Sonnet par défaut
  • [Claude Tag] Correction d'un canal Slack perdant ses paramètres Claude lorsqu'un administrateur Enterprise Grid le déplace vers un autre espace de travail et que le premier message suivant ne mentionne pas Claude
  • [Claude Tag] Correction de Claude dans un fil de discussion Slack qui recommençait occasionnellement sur une nouvelle machine, perdant le travail qu'il n'avait pas poussé, lorsque votre réponse répondait à une question qu'il venait de poser
  • [Claude Tag] Correction des noms de chaînes publiques sur la page des limites de dépenses de Claude Tag dans les paramètres d'administration, affichés sous forme d'identifiants Slack bruts dans les grandes organisations.
  • [Claude Tag] Amélioration des titres des sessions démarrées depuis Slack comme indiqué sur claude.ai : ils se lisent désormais comme les mots que vous avez tapés, sans identifiants utilisateur Slack ni codes d'échappement
