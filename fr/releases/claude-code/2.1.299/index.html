code-claude v2.1.299

Qu'est-ce qui a changé

  • Ajout de la variable d'environnement CLAUDE_CODE_DISABLE_FILE_MENTIONS : Claude obtient les chemins des mentions du fichier @ à lire avec ses outils de fichiers, pas le contenu des fichiers
  • Ajout du compactage inactif dans le terminal : une conversation de plus de 200 000 jetons laissée inactive pendant environ 54 minutes est compactée avant l'expiration de son cache d'invite d'une heure, de sorte que votre prochain message ne retraite pas tout cela.
  • Ajout de CLAUDE_CODE_IDLE_COMPACT_MIN_TOKENS pour modifier le minimum de 200 000 jetons du compactage inactif ; "idleCompaction": false dans les paramètres.json l'éteint. Les deux nécessitent v2.1.290 ou version ultérieure
  • Ajout de $.prompt.media afin qu'un hook prompt.submit d'un mod installé par les paramètres gérés puisse lire les octets d'une image ou d'un document joint à l'invite
  • Ajout de $.session.identity() pour les mods installés par les paramètres gérés : comment la session est connectée, ainsi que son organisation et son e-mail lorsqu'elle est gérée. forceLoginOrgUUID répertorie cette organisation
  • Ajout de size, weight, mono et tabular au Text d'un mod et pas d'espacement nommés (xs à xl) à son Box ; bold est obsolète au profit de weight
  • Ajout de --shutdown-drain-sec à claude self-hosted-runner orchestrator : sur SIGTERM, il arrête l'interrogation et donne à l'interrogation en vol et en cours d'exécution des crochets d'apparition jusqu'à autant de secondes pour terminer
  • Ajout du contenu de la compétence, de la source, du nom du plugin et du chemin du fichier à ce que reçoit le hook skill.prompt d'un mod.
  • Ajout de /effort et /fast dans la vue agent pour définir par quoi commencent les nouvelles sessions ; un /model, /effort ou /fast nu ouvre maintenant un sélecteur
  • Ajout d'une ligne "mode sans échec" au panneau d'aperçu des agents pour les sessions en arrière-plan démarrées avec --safe-mode
  • Ajout d'une note ponctuelle lorsque le mode plan ne demandera pas avant la plupart des modifications ou des commandes car les autorisations de contournement sont disponibles
  • Ajout de --disallow-tools et d'un champ de cas disallowed_tools à claude plugin eval pour garder les outils intégrés spécifiques, tels que l'agent, hors des exécutions d'évaluation.
  • Ajout de la prise en charge de la désactivation du bloc d'attribution dans l'onglet Code de Claude Desktop : définissez CLAUDE_CODE_ATTRIBUTION_HEADER=0 dans le env d'une stratégie code d'une passerelle d'applications Claude
  • Ajout d'un champ au bloc d'attribution dans les sessions Claude Code derrière une passerelle d'applications Claude ; retirer le bloc avec CLAUDE_CODE_ATTRIBUTION_HEADER=0
  • Ajout d'une porte queue au crochet de mod session.append, afin qu'un mod puisse faire en sorte que les enregistrements de la file d'attente de la transcription diffèrent de l'invite envoyée.
  • Ajout d'une note dans /plugin et claude plugin validate nommant les hooks d'un mod qui sont ignorés lorsqu'une organisation gère Claude Code
  • Ajout d'avertissements /usage pour un effort maximum, des flux de travail, un contexte toujours actif et des résultats d'outils volumineux
  • Correction de l'erreur d'une session cloud refusée, qui pouvait pointer vers la mauvaise organisation lorsqu'une clé de apiKeyHelper était utilisée
  • Correction des sessions sur un nom de modèle spécifique à la passerelle derrière un ANTHROPIC_BASE_URL personnalisé se terminant par "L'invite est trop longue · échec du compactage automatique" près de 200 000 jetons au lieu d'envoyer la demande

  • Amélioration de l'erreur de création d'un arbre de travail à la racine d'une présentation de référentiel nu : elle explique désormais la présentation au lieu d'une erreur git sans rapport
  • Surveillance améliorée des artefacts : une session locale peut désormais visualiser jusqu'à 25 artefacts publiés à la fois, contre 10 auparavant.
  • Notifications d'agent en arrière-plan améliorées : elles indiquent désormais lorsqu'un agent attend uniquement son propre travail en arrière-plan, a reçu un message trop tard pour son résultat ou a été arrêté par une limite d'utilisation.
  • Modification des hooks de plugin et des scripts de workflow pour refuser les valeurs qu'ils restituent qui s'imbriquent à plus de 28 000 niveaux, avec une erreur nommant la limite (les scripts de workflow autorisent 100 000)
  • Modification des actions qu'un hook de plugin peut bloquer pour être refusées, ne pas laisser passer, lorsque le hook ne peut pas leur être remis ou ne peut pas rendre sa réponse ; un outil qui a déjà été exécuté voit son résultat retenu
  • Modification des requêtes au proxy du connecteur de claude.ai et aux serveurs MCP hébergés par Anthropic pour ne plus suivre les redirections HTTP ; les redirections par le propre serveur d'un connecteur ne sont pas affectées
  • Modification des requêtes MCP dans les sessions cloud et auto-hébergées pour ne plus suivre les redirections HTTP du proxy MCP de la session
  • Modification des compétences et du chargement des commandes : celui dont le nom de fichier ou de dossier comporte des caractères masqués, changeant de direction ou ressemblant à des blancs, < ou > n'est plus proposé jusqu'à ce qu'il soit renommé ; un tel name: est ignoré
  • Modification des arbres ui.render dans claude plugin test : la racine de boîte ou de texte de chaque mod porte désormais part: { plugin } nommant le mod, donc les assertions d'arbre exact doivent l'inclure
  • Modification des lectures de la page WebFetch pour choisir leur effort comme le font les recherches sur le Web : le niveau de l'appelant sur son propre modèle, sinon les paramètres de niveau donnent le petit modèle
  • Modification de claude plugin test pour faire échouer un appel à la méthode $ servie par un mod qui n'a pas répondu dans les dix secondes, comme le fait une session.
  • Le MCP modifié permet aux règles d'atteindre uniquement le serveur qu'elles nomment : mcp__a n'autorise plus un serveur nommé a__b ou a_ ; écrivez mcp__<server>__* avec le nom complet normalisé du serveur
  • Modification des listes d'agents tools: pour prendre uniquement les outils du serveur MCP nommé ; lister un serveur dont le nom contient __ comme mcp__<whole name>__*
  • Modification de Claude dans Chrome dans les sessions cloud Cowork en dehors du mode automatique : une action du site approuvé que les indicateurs du classificateur de sécurité vous demandent désormais au lieu d'être refusée, à moins que les paramètres gérés ne s'appliquent.
  • Modification des connecteurs de session cloud et de contrôle à distance MCP pour négocier la version 2026-07-28 du protocole MCP par défaut sur les installations qui ne récupèrent aucun indicateur ; MCP_PROTOCOL_NEGOTIATION=legacy se désinscrit
  • Modification des descriptions des outils MCP et des instructions du serveur des serveurs MCP propriétaires d'Anthropic sur api.anthropic.com pour atteindre Claude dans son intégralité au lieu d'être réduit à 4 096 caractères.
  • Modification du mode automatique dans les sessions cloud Cowork : un hook PermissionRequest ne peut plus approuver les commandes shell ou les sous-agents ; ces invites attendent ou sont refusées
  • Modification de la commande de reprise affichée en sortie : elle nomme la session par son ID et non plus par son nom, afin que rien dans un nom de session ne puisse s'exécuter lorsque la ligne est collée
  • Modification de la commande de reprise affichée à la sortie d'une session worktree : elle utilise -w et -r si les drapeaux longs ne rentrent pas dans le terminal. Si aucun des deux ne correspond à un arbre de travail conservé, les lignes au-dessus indiquent où l'exécuter
  • Modification des questions secondaires /btw dans les sessions non interactives pour renvoyer une erreur de délai d'attente lorsqu'elles sont toujours sans réponse après 11 minutes
  • Modification des hooks UserPromptSubmit pour qu'ils s'exécutent avant qu'une compétence ou une commande slash personnalisée ne se développe, de sorte qu'un hook qui bloque l'invite arrête désormais également ses commandes shell intégrées
  • Modification du hook UserPromptSubmit d'une compétence pour qu'il s'exécute d'abord à l'invite après celui qui invoque la compétence.
  • Modification du crochet du mod turn.start pour entendre également les tours des sous-agents et des coéquipiers, pas seulement ceux de la boucle principale ; les différencier par e.agentId (absent sur la boucle principale)
  • Modification des erreurs affichées lorsque /ultrareview ne peut pas télécharger un référentiel pour arrêter de suggérer git add ., ce qui pourrait stocker ou valider des fichiers non suivis tels que .env
  • Modification de l'avis de cybersécurité pour ne plus demander aux gens de postuler au programme de cybervérification
  • [VSCode] Correction d'une invite non envoyée et de ses pièces jointes perdues lors du passage à une autre session et inversement
  • [VSCode] Correction des discussions vides inutilisées gardant un processus Claude en arrière-plan en cours d'exécution après le démarrage d'une nouvelle conversation
  • [VSCode] Correction du bouton micro affichant un message d'erreur interne lorsque vous êtes déconnecté de claude.ai ; il propose maintenant de vous connecter
  • [VSCode] Amélioration du temps de démarrage dans les espaces de travail sans environnement Python en démarrant Claude pendant le chargement de l'extension Python
  • [VSCode] Démarrage amélioré : le menu de sélection de modèle et de commande slash se remplit désormais immédiatement dans une nouvelle fenêtre sur un dossier que vous avez ouvert auparavant
  • [Sessions Cloud] Correction d'un pic de mémoire qui pouvait faire planter une session lorsque plusieurs de ses fichiers de sortie existants lui étaient renvoyés en même temps
  • [Sessions Cloud] Correction de l'enregistrement d'une routine modifiée en la déplaçant silencieusement vers un environnement différent lorsque la sienne avait été supprimée ou n'était pas dans la liste ; la routine garde désormais son environnement
  • [Sessions cloud] Correction de la recherche de sessions dans les détails d'administration d'un environnement auto-hébergé ne trouvant rien lorsque vous collez l'ID de session à partir du lien d'une session
  • [Sessions Cloud] Correction des listes de sessions et de coureurs dans les détails d'administration d'un environnement auto-hébergé indiquant que la liste est vide lorsqu'une recherche n'a tout simplement aucune correspondance.
  • [Sessions Cloud] Amélioration de la commande de déploiement affichée lorsque vous créez un environnement auto-hébergé ou une clé d'environnement : elle s'affiche dans son intégralité, s'enroule entre les arguments et comporte un bouton de copie visible
  • [Sessions Cloud] Modification de la suppression d'un environnement auto-hébergé pour désactiver immédiatement ses routines, avec la raison indiquée sur chaque routine, au lieu de laisser leurs exécutions échouer
  • [Télécommande] Correction des sessions de contrôle à distance dont l'ordinateur n'est pas accessible apparaissant toujours pour envoyer vos messages ; votre texte reste désormais dans la boîte et l'envoi est désactivé jusqu'à ce qu'il se reconnecte
  • [Claude Tag] Ajout de la possibilité pour Claude dans Slack de supprimer un canevas qu'il a créé dans une chaîne lorsque quelqu'un le lui demande.
  • [Claude Tag] Correction de Claude dans Slack qui restait silencieux sur les publications non taguées auxquelles les propres instructions d'une chaîne lui demandent de répondre, comme les publications qui marquent quelqu'un d'autre, dans les chaînes avec des invités.
  • [Claude Tag] Correction de Claude dans Slack signalant une réponse au fil de discussion d'une autre chaîne comme publiée alors qu'elle n'y est pas membre ; il dit maintenant que la réponse n'a pas été livrée et comment résoudre ce problème
  • [Claude Tag] Correction de Claude dans Slack qui terminait parfois un tour sans publier sa réponse lorsque l'image d'un coureur auto-hébergé n'avait pas de python3
  • [Claude Tag] Modification de la façon dont Claude dans Slack corrige un message erroné : il modifie le message sur place et ajoute une courte note "Modifié" au lieu de parcourir l'ancien texte
  • [Claude Tag] Modification de Claude dans Slack pour rejoindre tranquillement les chaînes de plus de 100 membres, sans message d'introduction
  • [Code Review] Correction du commentaire de limite de dépenses mensuelle et de la carte de vérification de Code Review envoyant les administrateurs aux paramètres de Claude Code ; ils relient désormais la page Utilisation, où cette limite est définie
