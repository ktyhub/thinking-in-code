claude-code v2.1.329

Correctif Publié19 nov. 2026 Sourceanthropics/claude-code Anglais original

Cette page est traduite automatiquement. Le texte anglais original fait foi.

code-claude v2.1.329

Qu'est-ce qui a changé

  • Ajout d'un avertissement de boîte de dialogue trust indiquant où les hooks d'un dossier sont déclarés
  • Ajout d'un avertissement dans la conversation, dans Claude Desktop et d'autres hôtes non interactifs, lorsque les hooks dans les paramètres gérés ne parviennent pas à se charger
  • Ajout des tâches planifiées de cette session, des réveils /loop, de l'objectif et des forks de cette conversation à /tasks ; x en arrête un après avoir demandé
  • Ajout d'une ligne "Message du serveur" à la page d'un serveur dans /mcp qui affiche le message d'erreur JSON-RPC d'un serveur HTTP MCP distant qui refuse la connexion
  • Ajout d'une ligne « Mise à jour automatique du Marketplace » à /status qui nomme les marchés gérés qui ne reçoivent aucune mise à jour automatique, et pourquoi
  • Ajout de la prise en charge de l'activation du mode Code lorsque les événements et les métriques OpenTelemetry sont activés ; chaque outil appelé par le code envoie ses événements ; le traçage l'empêche toujours
  • Correction de ~/.claude.json qui était parfois réinitialisé aux valeurs par défaut lorsqu'un blocage du réseau ou un verrouillage de fichier le rendait illisible et effacé lors d'une sauvegarde.
  • Correction des déconnexions répétées sur macOS lorsque Claude Code pouvait lire le trousseau mais pas y enregistrer. Cette session s'arrête désormais à l'expiration et indique pourquoi, et les autres sessions restent connectées.
  • Correction de /terminal-setup corrompant les paramètres de VS Code ou les fichiers de raccourcis clavier autour des commentaires de bloc, et signalant le succès tout en perdant la liaison Shift+Enter où keybindings.json a une chaîne non fermée
  • Correction des fichiers acceptés via la différence IDE étant enregistrés sans leur dernière nouvelle ligne et perdant leur marque d'ordre d'octet (BOM) lorsqu'une modification était acceptée en enregistrant la différence dans VS Code
  • Correction du choix d'une session cloud dans /teleport remplaçant votre conversation ouverte : le choix démarre désormais une nouvelle session, comme le fait /clear, et /resume ramène l'ancienne
  • Correction de /usage-credits demandant aux utilisateurs Pro et Max de se reconnecter après l'ouverture du navigateur, et le lien disparaissant après 8 secondes si le navigateur ne s'ouvre pas et qu'une tâche s'arrête pour des crédits d'utilisation
  • Correction de /usage indiquant que les crédits d'utilisation sont désactivés lorsqu'ils sont épuisés ou ont atteint la limite mensuelle, et /model n'informe pas les utilisateurs Pro et Max lorsque cette limite bloque un modèle qui fonctionne avec des crédits d'utilisation.
  • Correction du menu de limite de dépenses affichant vos dépenses comme limite mensuelle et en plaçant ses lignes sous le pointeur dans des fenêtres étroites
  • Correction d'un script de ligne d'état qui s'imprime sans fin, gelant l'invite et utilisant des gigaoctets de mémoire
  • Correction d'un écran vide et gelé après l'approbation des paramètres gérés pendant que le sélecteur --resume, la boîte de dialogue trust ou un autre écran de configuration attendait
  • Correction du choix par défaut dans /model en remplaçant votre modèle enregistré par celui par défaut de votre organisation lorsque la ligne par défaut affichait déjà votre modèle enregistré
  • Correction d'un serveur MCP étant à nouveau connecté après avoir effacé son authentification pendant qu'une actualisation de jeton était en cours
  • Correction des tâches MCP en arrière-plan qui bloquaient après une reconnexion lente : Claude Code reconnecte désormais automatiquement la plupart des serveurs HTTP MCP lorsque l'on reste sur une ancienne version du protocole
  • Correction des PDF, des images et des fichiers .docx, .xlsx ou .pptx que les serveurs ou sites Web MCP envoient sous le nom application/octet-stream étant enregistrés au format .bin, ce qui empêchait Claude de lire les PDF et les images
  • Correction de /code-review <pr number> examinant parfois la branche extraite au lieu de la pull request sans le dire : il lit désormais la pull request avec gh pr diff, ou indique quand il ne peut pas le faire
  • Correction du /code-review s'arrêtant à une invite d'autorisation, sur la plupart des modèles, pour rechercher un ~/.claude/CLAUDE.md qui n'existe pas
  • Runner auto-hébergé : correction de --push-outcome-on-release supprimant parfois la branche d'une session sur l'hôte git
  • Correction du mode Code masquant les modifications terminées d'un script et la commande arrêtée après Esc, et les perdant à la sortie
  • Correction d'une boucle incontrôlable en mode Code remplissant la mémoire de la machine ; il est maintenant arrêté à une limite
  • Correction d'un agent en arrière-plan qui s'exécutait lorsqu'il était arrêté alors qu'il était en cours de reprise
  • Correction des commandes du shell en arrière-plan utilisant la mémoire pour la conversation précédente jusqu'à leur sortie
  • Correction du contrôle à distance utilisant la mémoire pour la conversation précédente après un compactage ou /clear dans les sessions exécutées par Claude Desktop, les IDE ou le SDK
  • Correction de l'arrêt ne mettant pas fin à une requête dans les sessions Claude Desktop sur Bedrock pendant l'attente d'un AWS credential_process ou d'un appel de connexion bloqué.
  • Correction de Claude qui ne parvenait parfois pas à vous envoyer un fichier lors de son premier essai sur Opus 4.8 et Opus 5
  • Correction de Claude ne se faisant pas dire que les outils d'un serveur MCP connecté ne pouvaient pas être chargés, et le prenant pour un serveur sans outils, dans les sessions avec recherche d'outils
  • Correction de claude mcp login et /mcp indiquant qu'un service n'accepte pas les connexions de Claude Code lorsque l'enregistrement client du service a été retiré (HTTP 410 Gone)
  • Correction d'un autre cas d'échec des hooks de plugin claude.ai-synced avec "Le répertoire du plugin n'existe pas" alors qu'une session était encore en cours d'exécution sur macOS
  • Correction du mode automatique demandant une approbation manuelle à rm, un lien symbolique qui pointe en dehors du répertoire de travail ou vers lui-même
  • Correction de /sandbox sous Linux répertoriant les entrées allowUnixSockets comme autorisées : ils n'ouvrent pas ces sockets là-bas, et /sandbox le dit maintenant
  • Correction d'appuyer deux fois sur Echap pour effacer un code mal saisi mettant fin à la connexion dans /install-github-app
  • Contrôle à distance : Correction des sessions revenant à leur premier niveau d'effort après un redémarrage alors que l'application affichait toujours le niveau que vous aviez choisi (pas encore pour les sessions qui démarrent en Ultracode)
  • Correction du serveur MCP d'un plugin supprimé restant connecté dans les sessions sans tête après reload_plugins ou lorsque la liste des plugins du compte le supprime
  • Correction des outils du connecteur Claude Docs manquant lorsqu'un plugin ou un serveur MCP à la même adresse ne parvenait pas à se connecter, et son erreur suggérant à tort /login
  • Correction d'un nouveau dossier de compétences, de commandes ou d'agents manquant lorsque --add-dir nomme le répertoire de travail ou que Claude Code démarre dans le dossier personnel
  • Correction des sessions démarrées à partir d'un processus préchauffé ignorant le paramètre autoCompactWindow dans le .claude/settings.json du projet
  • Correction de CLAUDE_AUTOCOMPACT_PCT_OVERRIDE restant en vigueur dans une session en cours après sa suppression des paramètres.json
  • Correction du paramètre effort de l'outil Agent étant ignoré pour les coéquipiers nommés dans les équipes d'agents
  • Correction de /auto-mode-setup ignorant les refus récents du mode automatique lorsqu'il analyse un projet à la recherche de règles à suggérer ; il peut désormais proposer des règles d'autorisation, et vous les examinez avant de les enregistrer
  • Correction d'un faux avertissement "Impossible d'enregistrer cette modification" après l'ajout d'une règle d'autorisation ou d'un répertoire dans un sous-dossier ou un arbre de travail dont le propre .claude/settings.local.json est illisible ou mal formé
  • Correction des sessions cloud indiquant à Claude d'exécuter une vérification du proxy réseau après un échec de requête, quel mode automatique était alors bloqué
  • Correction du rembobinage et du fork sans tête alors qu'un message envoyé juste après un changement de modèle l'attendait toujours
  • Correction de Claude qui n'était pas informé de l'arrêt d'une tâche en arrière-plan lors du redémarrage d'une session cloud.
  • Correction de /team-onboarding signalant un guide partagé sur les forfaits Team et Enterprise lorsque le serveur refusait le téléchargement
  • Correction des panneaux et des questions coupés à l'invite en plein écran, /help, recherche d'historique et liste des tâches en arrière-plan perdant des lignes ou des titres dans des fenêtres courtes et des tableaux enroulés dans des boîtes de dialogue
  • Correction des sessions reprises affichant "Rejeté" ou "Declined" pour les modifications, les questions et les plans qui étaient interrompus à la fin de la session.
  • Correction de /passes affichant le mauvais nombre de laissez-passer après une erreur de serveur et offrant des crédits d'utilisation pour le partage lorsqu'il ne reste plus de laissez-passer invité
  • Correction de la sortie du claude --help qui était coupée lorsqu'elle était redirigée vers un autre programme
  • Correction de /terminal-setup activant "Utiliser l'option comme clé méta" dans Terminal.app sur macOS 27, et des astuces suggérant Option+Entrée au lieu de Shift+Entrée
  • Exécuteur auto-hébergé : correction de l'échec de la configuration sur les référentiels Git LFS clonés via git géré par Anthropic ; les sessions démarrent désormais sur les fichiers pointeurs et git lfs pull récupère le contenu
  • Correction des sessions sur les environnements auto-hébergés ne démarrant pas à partir d'une télécommande git avec un alias d'hôte SSH, des certificats SSH GitHub ou un utilisateur SSH GHE.com ; une erreur d'alias non résolue donne deux commandes git
  • Correction des serveurs MCP distants dans les sessions d'exécution auto-hébergées restant sans outils, ou (via https) déconnectés, après un délai d'attente ou une erreur réseau
  • Correction des sessions de coureur auto-hébergées affichées comme ayant cessé de répondre alors que Claude Code démarrait encore
  • Correction du mode Code gardant en mémoire tous les gros fichiers texte lus par le code, et la mémoire augmentant à chaque fois qu'un sous-agent en arrière-plan était réveillé
  • Correction du mode Code arrêtant un script à sa limite de dix minutes alors qu'un formulaire MCP, une invite de lien MCP ou une invite qui demande toujours attendait une réponse
  • Correction des scripts en mode Code recevant un message "déplacé en arrière-plan" comme données de la plupart des appels MCP sur deux minutes : le script attend désormais jusqu'à dix minutes, puis obtient une erreur
  • Correction des mods qui répertorient uniquement certains outils désactivant silencieusement le mode Code ; un tel mod ne le retient plus, alors utilisez les paramètres gérés pour cela
  • Correction du mode Code ignorant la demande d'un outil MCP de terminer le tour lorsque l'outil était appelé depuis un script que Claude attend
  • Correction du let x; d'un script en mode Code en conservant la valeur qu'un script précédent donnait à x
  • Correction d'un appel de script en mode Code sans échec avec une erreur de paramètre manquant sur les outils qui n'en ont pas besoin
  • Correction des scripts en mode Code perdant l'accès aux outils via tools dans les sessions avec plus de 4 096 outils
  • Correction de la carte de résultats du /code-review affichant souvent « élevé » pour une évaluation exécutée à moyen, sur la plupart des modèles.
  • Correction des indices clés dans les invites d'autorisation, les questions, /model et /rewind ignorant keybindings.json
  • Correction du défilement automatique, du badge d'état PR, de l'avertissement de compactage automatique et de la balise ultracode ne suivant pas les commutateurs /config qui les contrôlent lors d'une session en cours
  • Correction d'une touche d'annulation personnalisée ne fonctionnant pas dans les commentaires /add-dir, /tui et le formulaire de flux de travail de sauvegarde
  • Correction des touches fléchées dans le formulaire de sauvegarde du workflow déplaçant la sélection dans la vue du workflow derrière elle
  • Correction du /config ne disant rien, ou "rejeté", après avoir modifié de nombreux paramètres
  • Correction des lectures et @-mentions affichant une ligne de trop pour les fichiers se terminant par une nouvelle ligne
  • Correction de /status ne nommant pas le modèle utilisé par l'opusplan et le haïku en mode plan
  • Correction de claude doctor conseillant un déverrouillage du trousseau dans un bac à sable macOS, où le déverrouillage ne peut pas aider
  • Correction de la pilule "Sauter vers le bas" qui restait masquée après avoir copié le texte et fait défiler, la ligne en dessous devenant vide lorsque son étiquette changeait et les pressions rapides sur PageUp défilaient trop loin en plein écran
  • Correction d'une mise à jour de l'écran parfois ignorée lorsque la mémoire est faible
  • Correction de blocs de code longs perdant une ligne vide et en répétant une autre lors du défilement
  • Correction des suggestions d'invite affichant parfois du texte d'espace réservé tel que _(no suggestion)_
  • Correction de la ligne sur les messages précédents lors de la reprise accusant un fichier endommagé alors que le fichier était intact
  • Correction des caractères disparaissant de l'invite lorsque son texte contenait un code couleur qui définit plusieurs styles et qu'un mot-clé ou une commande était mis en surbrillance
  • Correction des titres hook /rename et UserPromptSubmit dans les sessions claude remote-control n'apparaissant pas sur claude.ai et mobile
  • Correction du diff de la télécommande répertoriant un fichier deux fois lorsque la branche le renommait et qu'il était ensuite modifié
  • Amélioration du nettoyage automatique des anciennes sessions sur les ordinateurs avec paramètres gérés
  • Amélioration de /tui et d'autres redémarrages sur place pour attendre brièvement une actualisation de connexion, afin qu'ils soient moins susceptibles de vous déconnecter
  • Utilisation améliorée de la mémoire dans les longues sessions qui éditent de nombreux fichiers, et dans les longues sessions Claude Desktop sur macOS et Linux avec de nombreux résultats d'outils MCP volumineux
  • Windows : Démarrage amélioré et première recherche sur PC où le programme de recherche de Claude Code démarre lentement
  • Amélioration de la gestion en mode automatique d'une réponse courte telle que "oui" à la question de Claude lorsque la télémétrie est désactivée, derrière une passerelle vers l'Anthropic API, ou sur Microsoft Foundry
  • Amélioration de l'utilisation de la mémoire des sessions inactives Claude Desktop et SDK après un long tour, et après --resume ou --continue d'une session contenant des captures d'écran ou des résultats d'outils volumineux
  • Amélioration de la rapidité avec laquelle une session Claude Desktop Code avec le contrôle à distance activé est prête pour le prochain message après une réponse
  • Sessions cloud améliorées pour réessayer les plugins dont le téléchargement n'a pas réussi au démarrage
  • Mode Code amélioré : le terminal se fige beaucoup moins longtemps après qu'un script ait effectué des milliers d'appels d'outils
  • Mode Code amélioré : après avoir démarré un sous-agent, Claude reçoit désormais les mêmes conseils d'attente qu'en dehors du mode Code.
  • Mise à jour de l'utilisation de l'ordinateur sur macOS vers des règles de sécurité plus récentes, de sorte que certaines actions sont refusées et certaines applications ont moins d'accès
  • Modification des tâches planifiées enregistrées : dans les nouvelles sessions connectées, la plupart enregistrées par les versions antérieures doivent être à nouveau planifiées, bien que --resume de leur propre session les exécute toujours
  • Modification de /code-review sans cible sur la plupart des modèles pour examiner la branche entière par rapport à la branche par défaut, et correction de la perte de la différence sur les branches multi-commit
  • Modification du mode automatique pour exécuter git status moins souvent afin que la plupart des requêtes attendent moins dans les grands référentiels ; une commande git qui ignore les modifications peut être bloquée jusqu'à ce que l'arborescence de travail soit vérifiée
  • Modification de /code-review <pr number> --fix et /code-review étant donné une URL de demande d'extraction, pour s'arrêter sans examen lorsque gh pr diff est refusé ou échoue
  • Modification de « Quitter et arrêter les tâches » pour mettre fin aux tâches planifiées de cette session afin qu'elles ne s'exécutent plus à la reprise, sauf si vous quittez pendant que Claude répond
  • Modification de certains volets des coéquipiers pour qu'ils démarrent via /bin/sh, afin qu'ils ne puissent pas lire les fichiers de démarrage du shell
  • Modification de l'utilisation de l'ordinateur sur macOS pour abandonner le lancement d'une application qui n'est pas terminée au bout de 30 secondes
  • Passerelle : modification de l'avertissement de démarrage affiché lorsque le access_control.allow_cidrs est vide en un avis à chaque démarrage, encadré dans les journaux de texte : n'exposez jamais la passerelle à l'Internet public
  • Exécuteur auto-hébergé : modification du clone d'un deuxième nom d'hôte du même propriétaire/nom pour le placer sous _repos/clones/<host>/ dans le dossier de base ; aucun clone ne bouge
  • Runner auto-hébergé : modifications des référentiels avec des caractères inhabituels dans leur chemin d'adresse pour les cloner à nouveau dans un nouveau dossier ; les règles et les volumes nommant l'ancien cessent de s'appliquer et l'ancien clone reste en place
  • Exécuteur auto-hébergé : modification de --repository-folder pour prendre la plupart des dossiers du dossier de base sur --capacity 1 (au-dessus de 1, celui-ci arrête le démarrage) ; la session d'un autre référentiel qui chevauche la première est refusée
  • Modification du mode Code afin qu'un hook PreToolUse qui erreurs ne refuse plus l'appel à l'outil d'un script, comme en dehors du mode Code ; définir "onFailure": "block" sur un hook d'outil de commande, HTTP ou MCP qui doit refuser
  • Modification du mode Code pour refuser la lecture par un script d'une plage de lignes supérieure à 256 Mio, ce qui pourrait utiliser des gigaoctets de mémoire, et correction du délai d'expiration des lectures de très longues lignes.
  • Modification du mode Code pour qu'il démarre également lorsque la télémétrie, le trafic non essentiel ou les indicateurs de fonctionnalité sont désactivés ; un administrateur peut le désactiver dans les paramètres gérés
  • Modification du mode Code pour exécuter un script qui déclare son propre log, preview ou sleep, qu'il refusait auparavant
  • Modification du renouvellement de la connexion macOS pour tester le trousseau avec un élément Claude Code-write-check
  • Modification de l'en-tête /tasks et du nombre d'arrière-plans du pied de page en un seul numéro couvrant les shells, les moniteurs, les appels MCP, les agents, les flux de travail et les tâches planifiées.
  • Modification des hooks Stop et SubagentStop pour répertorier le script d'un moniteur comme monitor, et non shell, dans background_tasks
  • Suppression de la nouvelle tentative automatique de 2.1.326 à la limite indiquée dans une erreur max_tokens ; derrière une passerelle dont le modèle prend moins de jetons de sortie, définissez CLAUDE_CODE_MAX_OUTPUT_TOKENS sur cette limite
  • [VSCode] Ajout d'une ligne au-dessus de la boîte de message après avoir supprimé l'invite trust, avec Review trust pour ramener l'invite sans recharger la fenêtre.
  • [VSCode] Correction de la déconnexion de Claude Code dans chaque fenêtre et terminal lorsque le serveur de connexion prenait 10 à 30 secondes pour répondre à l'actualisation du jeton de l'extension.
  • [VSCode] Correction des touches enfoncées pendant qu'une méthode de saisie (IME) compose le déplacement du focus sur ou la suppression d'une invite d'autorisation, l'exécution de lignes de menu et la fermeture de boîtes de dialogue (anthropics/claude-code#106358)
  • [VSCode] Correction de l'invite d'autorisation pour Bash, Edit, Write et d'autres outils intégrés n'indiquant pas pourquoi un contrôle de sécurité demande
  • [VSCode] Correction d'un commentaire de plan à moitié écrit perdu ou déplacé vers un autre passage, et Entrée d'une méthode de saisie envoyant le commentaire, mettant fin à une session, renommant ou sélectionnant un fichier mentionné par @
  • [VSCode] Correction de la bannière de limite n'indiquant pas quand les crédits d'utilisation sont utilisés, et de l'enquête de session couvrant cette bannière et la carte de crédits d'utilisation.
  • [VSCode] Correction des lecteurs d'écran n'annonçant pas une demande d'autorisation arrivée alors que la boîte de dialogue Compte et utilisation était ouverte jusqu'à ce que cette boîte de dialogue soit fermée.
  • [VSCode] Correction d'un onglet de modification proposé restant ouvert, avec un bouton Accepter qui ne faisait rien, après la déconnexion de la session Claude Code de son terminal
  • [VSCode] Correction des entrées et sorties d'outils courts coupées au bord du panneau sans aucun moyen de lire le reste (elles s'ouvrent maintenant dans un onglet d'éditeur), et en faisant glisser pour sélectionner le texte en ouvrant également un
  • [VSCode] Correction de la touche Haut plaçant un message antérieur sur le texte qu'une méthode de saisie (IME) compose dans la boîte de message (anthropics/claude-code#101294)
  • [VSCode] Correction du dépôt d'un dossier Explorer sur le chat en n'insérant rien sur VS Code 1.103 vers 1.139 ou dans une fenêtre de chat flottante, et la surbrillance du dépôt disparaissant avec un faux indice "Hold Shift"
  • [VSCode] Correction d'une invite d'autorisation déplaçant le focus du clavier loin des détails que vous faisiez défiler lorsque ses boutons étaient allumés
  • [VSCode] Correction des liens de fichiers dans un onglet Claude s'ouvrant dans un autre groupe d'éditeur lorsque claudeCode.lockEditorGroups est désactivé (anthropics/claude-code#108884)
  • [VSCode] Correction des plages écrites avec un seul tilde (3~5 … 7~10) perdant leurs tildes et affichant du texte barré entre elles ; seul ~~text~~ est barré maintenant
  • [VSCode] Correction d'erreurs de dictée s'enroulant dans une colonne étroite, la roulette tournant pendant qu'une carte de question attend et un symbole NUL après chaque lettre dans la sortie d'une commande UTF-16 ayant échoué
  • [VSCode] Modifié vers le bas pour s'arrêter au dernier élément d'une invite d'autorisation au lieu de passer à Oui
  • [VSCode] Modification de la sortie de la commande pour afficher les caractères masqués et les séquences de contrôle autres que les couleurs unies sous forme de symboles, de sorte que le texte persan, khmer, laotien, cinghalais et malayalam puisse paraître brisé ou dans le désordre.
