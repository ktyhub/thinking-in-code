claude-code v2.1.283

Correctif Publié25 sept. 2026 Sourceanthropics/claude-code Anglais original

Cette page est traduite automatiquement. Le texte anglais original fait foi.

code-claude v2.1.283

Qu'est-ce qui a changé

  • Ajout de x-claude-code-prompt-id aux en-têtes d'indication de passerelle afin que les passerelles LLM puissent regrouper les requêtes qui servent une invite utilisateur ; inscrivez-vous avec CLAUDE_CODE_GATEWAY_HINT_HEADERS=1
  • Ajout du paramètre géré availableModelsMatch : avec "exact", une entrée availableModels autorise uniquement la version du modèle qu'elle nomme, de sorte que les nouvelles versions restent bloquées jusqu'à ce qu'elles soient répertoriées.
  • Ajout d'un paramètre géré par deniedModels pour bloquer des modèles spécifiques, même lorsque availableModels les autorise
  • Ajout de l'outil MCP, des sorties WebFetch et WebSearch à l'événement span tool.output OpenTelemetry lorsque OTEL_LOG_TOOL_CONTENT=1
  • Ajout de /doctor prompt-audit (également /checkup prompt-audit) pour auditer vos fichiers, compétences, agents et commandes CLAUDE.md pour les modèles d'invite écrits pour les anciens modèles
  • Ajout de click-to-expand pour les messages tronqués de vos autres sessions en mode plein écran
  • Ajout des entrées d'échec de chargement path aux entrées --plugin-dir dans le flux-json system/init plugin_errors, nommant le répertoire qui ne s'est pas chargé
  • Ajout d'un bloc opt-in load_test_mode à la configuration de la passerelle des applications Claude : les requêtes sont créées et signées mais pas envoyées en amont, et les clients reçoivent une réponse standardisée, afin qu'un déploiement puisse être testé en charge
  • Ajout d'un fournisseur en amont mantle à la passerelle d'applications Claude pour le point de terminaison Mantle d'Amazon Bedrock
  • Correction des sessions SDK perdant un appel d'outil différé ou un résultat d'outil terminé lorsqu'un tour se terminait plus tôt, une invite d'approbation en attente après le redémarrage d'un travailleur et un result.usage de secours sans streaming
  • Correction des notifications de progression MCP étant supprimées une fois qu'un appel d'outil de longue durée passait en arrière-plan ; la tâche en arrière-plan affiche désormais la dernière progression
  • Correction des serveurs MCP stdio qui restaient en cours d'exécution à la fin de la session alors qu'ils étaient encore en cours de démarrage
  • Correction d'un bref HTTP 404 provenant d'un serveur MCP distant sans état (par exemple un proxy en cours de redéploiement), laissant ce serveur inutilisable pour le reste de la session tout en étant toujours affiché comme connecté
  • Correction de la connexion MCP pour un serveur sans URL valide échouant avec une erreur opaque SDK ; /mcp ne propose plus d'authentification pour ces serveurs
  • Correction de la limite hebdomadaire de Fable n'apparaissant pas dans /usage et les compteurs d'utilisation du VS Code lorsque la télémétrie est désactivée
  • Correction de /model acceptant Sonnet 4.6 ou Sonnet 5 avec [1m] lorsque l'identifiant portait une date ou un suffixe -v1:0, dans les cas où l'identifiant brut était refusé
  • Correction du sélecteur /model affichant une version et un prix Haiku codés en dur lorsque ANTHROPIC_DEFAULT_HAIKU_MODEL épingle un modèle différent
  • Correction des workflows dynamiques démarrés lors d'un repli de modèle exécutant chaque agent sur le modèle de repli au lieu de réessayer le modèle configuré
  • Correction du DISABLE_PROMPT_CACHING_HAIKU n'ayant aucun effet lorsque Haiku est le modèle principal de la session
  • Correction de claude plugin validate indiquant que Claude Code accepte un plugin ou un nom de marché qu'il ne peut pas installer ; ces noms dans marketplace.json échouent désormais à la validation
  • Correction des plugins passant claude plugin validate dont les chemins outputStyles, themes, monitors ou lspServers sont manquants ou pointent en dehors du répertoire du plugin
  • Correction de claude plugin details affichant 0 serveur MCP pour les plugins qui déclarent leurs serveurs dans plugin.json
  • Correction de claude plugin marketplace remove qui n'indiquait pas quels plugins installés il avait désinstallés avec le marché ; il les répertorie maintenant
  • Correction de claude plugin uninstall supprimant l'autre des deux plugins installés dont les identifiants diffèrent uniquement dans le cas, avec ses options et ses secrets, lorsque celui nommé n'avait pas d'entrée enabledPlugins à ce niveau.
  • Correction des plugins qui déclarent qu'aucune version n'est restaurée silencieusement lors du dernier commit de leur source, pas celui installé, lorsque leurs fichiers en cache étaient manquants
  • Correction des plugins et des places de marché installés par l'utilisateur qui ne se chargeaient pas avec "cache-miss" après le déplacement du répertoire home ou config, par exemple dans les devcontainers montés en liaison.
  • Correction de installed_plugins.json n'affichant aucun plugin lorsqu'il détient un enregistrement sous un identifiant de plugin invalide ; un tel fichier se charge à nouveau
  • Correction de installed_plugins.json étant réécrit, perdant des enregistrements, lorsqu'il détient un enregistrement que cette version ne peut pas lire ; Les commandes claude plugin nomment désormais l'enregistrement et indiquent comment le récupérer
  • Correction des boîtes de dialogue d'autorisation en mode lecteur d'écran lisant les commandes et les chemins cités comme s'il s'agissait du propre texte de la boîte de dialogue
  • Correction de /context ne comptant pas les instructions du serveur MCP : elles apparaissent désormais comme leur propre ligne et comptent dans le total
  • Correction des liens de démarque dans le rendu du terminal Warp sous forme de texte brut au lieu des hyperliens clickable
  • Correction du succès du rapport de claude mcp add, add-json et remove lorsque l'utilisateur ou le fichier de configuration local ne pouvait pas être écrit, par exemple dans un bac à sable
  • Correction des premiers mots d'une réponse dans une session cloud apparaissant parfois en retard au lieu d'être diffusés au fur et à mesure que Claude les écrit
  • Correction du guide de raccourcis clavier intégré de Claude indiquant que les accords expirent après 1 seconde au lieu de 3, et appelant cmd un alias de meta, ce qui pourrait produire des raccourcis cmd+ que la plupart des terminaux n'envoient jamais.
  • Correction de keybindings.json acceptant silencieusement un modificateur mal orthographié tel que ctl+k ; il avertit maintenant dans le journal de débogage et suggère le correctif
  • Correction des indices de pied de page indiquant toujours "Entrer pour afficher" après le rebond ou la dissociation de footer:openSelected dans keybindings.json
  • Correction des touches saisies rapidement ensemble (saisie anticipée, répétition de touche, rafales via ssh ou tmux) parfois traitées contre un état obsolète
  • Correction des extractions d'arbre de travail échouant à la vérification du certificat (par exemple sur les téléchargements Git LFS) lorsque le certificat CA est transmis à git en tant que paires d'environnement GIT_CONFIG_COUNT
  • Correction du git en bac à sable demandant aux assistants d'identification de stocker la connexion du proxy du bac à sable, qui affichait "échec du stockage".
  • Correction des paramètres gérés du sandbox étant entièrement ignorés lorsqu'une valeur imbriquée n'était pas valide ; la valeur invalide échoue désormais et le reste du bloc s'applique toujours
  • Correction du blocage des modifications de Claude sur ses propres notes de mémoire automatique lors de l'écriture de fichiers sensibles lorsque Claude Code était démarré dans un sous-répertoire d'un référentiel git.
  • Correction de la télécommande n'étant pas disponible sur les forfaits payants lorsque la télémétrie est désactivée avec DISABLE_TELEMETRY ou DO_NOT_TRACK
  • Correction du menu /remote-control coupant son indice de code QR au milieu d'un mot dans les terminaux étroits
  • Correction du mode vim . supprimant une nouvelle ligne Shift+Enter, laissant le curseur à l'intérieur d'une lettre accentuée et répétant une modification plus ancienne après 3J ou le mode visuel J sur la dernière ligne.
  • Correction du placement du curseur en mode vim : le rappel d'une invite de plus de 10 000 caractères en mode normal ne laisse plus le curseur au-delà de la fin, et V puis p atterrissent désormais sur le premier non vide
  • Correction du mode vim J joignant des lignes avec un espacement différent de celui de Vim (comme un espace avant ) ou après une tabulation), et 3J ou J en mode visuel sur la dernière ligne ne déplaçant pas le curseur comme le fait Vim.
  • Windows : Correction de l'outil PowerShell permettant à cmd /c rd, rmdir, del ou erase de supprimer les racines du lecteur, le dossier personnel et les autres dossiers refusés par Remove-Item
  • Amélioration de la liste d'outils /mcp : elle affiche plus d'outils à la fois, défile avec les touches de page et la souris et marque les outils bloqués par votre organisation avec une icône d'avertissement.
  • Résultats améliorés de l'outil MCP : les images renvoyées par les outils MCP sont désormais également enregistrées dans un fichier, afin que Bash, Read et d'autres outils puissent les ouvrir
  • /tasks amélioré : les lignes affichent une icône d'état, le nom et l'ensemble des faits, le titre et les touches clés restent à l'écran avec de nombreuses tâches, et la liste gagne les touches de pagination, la molette de la souris et les clicks
  • Listes améliorées dans /help, /hooks, /copy, /chrome, /memory, /ide, /release-notes, /rewind, /diff, /remote-env, /plugin et autres sélecteurs avec touches de page, molette de la souris et clicks
  • Listes améliorées à côté d'un champ de recherche, telles que /skills et /artifacts, pour dessiner leur pointeur en grisé pendant que le champ de recherche contient les clés, de sorte qu'un seul pointeur soit mis en surbrillance
  • Amélioration de la roulette de compactage : son chronomètre démarre désormais lorsque le compactage commence et il compte les jetons du résumé au fur et à mesure de leur diffusion, remplaçant la barre de pourcentage.
  • Amélioration de la page du navigateur affichée après la connexion à un serveur MCP : mise en page centrée, mode sombre et nouvelle illustration
  • Amélioration de la réponse de l'outil Skill lorsqu'une compétence appartient à un plugin dont le chargement a échoué, Claude vous indique donc que le plugin n'a pas pu être chargé au lieu d'appeler la compétence désinstallée.
  • Amélioration de prompt-audit sur la configuration de Claude Code : les chemins obsolètes, les commandes obsolètes et les fichiers d'instructions contradictoires mènent désormais le rapport, et les mots-clés de réflexion que les documents Claude Code sont conservés
  • Amélioration de la récupération à partir d'un installed_plugins.json qui ne peut pas être lu du tout : son contenu est conservé dans un fichier à côté avant qu'il ne soit reconstruit, et claude plugin list nomme ce fichier
  • Lectures améliorées de la base de données d'artefacts : une requête ordonnée qui renvoie une page complète indique désormais qu'il s'agit d'une page et comment lire le reste
  • Amélioration de la latence de la première réponse : une étape de compilation de modèles qui s'exécutait à la fin de la première réponse d'une session s'exécute désormais pendant que la réponse est diffusée
  • Amélioration de la latence à la première demande en réutilisant la connexion API préconnectée
  • Démarrage amélioré : claude -p et Claude Code Remote ne chargent plus l'interface utilisateur interactive, et les règles du classificateur en mode automatique ainsi que l'outil Artefact se chargent à la première utilisation plutôt qu'au lancement.
  • Démarrage amélioré pour les comptes claude.ai dont les fonctionnalités de l'outil Artifact ne sont pas encore connues, comme lors d'une première exécution : le prompt n'attend plus les 1.5 pour les vérifier ; le premier message attend si besoin
  • Modification des sessions interactives sur des fournisseurs tiers ou avec télémétrie désactivée pour démarrer en mode automatique lorsqu'aucun mode d'autorisation n'est configuré ; permissions.defaultMode le remplace toujours
  • Modification de la boîte de dialogue de lancement de /ultrareview pour indiquer que l'examen d'une branche locale peut télécharger des modifications non validées dans les fichiers suivis.
  • Modification de la ligne Opus du sélecteur /model et du nom du modèle par défaut pour supprimer "(contexte 1M)" là où Opus a déjà une fenêtre contextuelle 1M ; la fenêtre est inchangée
  • Modification des suggestions d'invite dans le terminal pour qu'elles apparaissent moins souvent après 20 suggestions consécutives inutilisées ; en utiliser un les ramène
  • Modification de --system-prompt et --append-system-prompt pour accepter leur texte et leurs formulaires -file ensemble ; le texte du fichier vient en premier
  • Modification des règles de refus de Skill(anthropic-skills:<name>) pour bloquer également cette compétence lorsque Claude Desktop la fournit en tant que plugin, et Skill(skill:<name>) refuse de correspondre à l'alias et au nom d'affichage de la compétence.
  • Modification des listes /rewind et /diff pour se déplacer sur les mêmes actions de raccourci clavier que toutes les autres listes (select:*) ; Les liaisons messageSelector:*/diff:* fonctionnent toujours
  • Modification de la liste d'exécution /workflows pour qu'elle se dimensionne comme les autres listes : la moitié du terminal en ligne, et elle conserve son titre à l'écran lorsque l'invite s'affiche ci-dessous
  • Modification de claude plugin eval pour exiger git 2.31 ou version ultérieure lorsque git est installé ; une exécution sur un ancien git est refusée avec un message nommant la version
  • Modification de la surveillance des artefacts : une montre qui a été armée automatiquement (pas celle que vous avez demandée) se termine désormais après 3.5 heures sans activité ; publier ou regarder à nouveau l'artefact le réarme
  • Exécuteur auto-hébergé : modification du git des hooks de cycle de vie pour ignorer le hook Git LFS pre-push d'un référentiel, ignorer un système inscriptible core.hooksPath et ne pas signer les commits sans --configure-git
  • Coureur auto-hébergé : modification de GIT_SSL_CAINFO et GIT_SSL_NO_VERIFY sous git géré par Anthropic : le propre git du coureur vérifie toujours la route git d'Anthropic, et les lignes d'avertissement indiquent ce qui s'applique où
  • Annulation de la réservation 2.1.282 du nom claude-ai : les compétences, les commandes, les flux de travail et les compétences et invites des serveurs MCP ainsi nommés se chargent à nouveau, et les règles Skill(claude-ai:*) sont des règles de préfixe ordinaires
  • [VSCode] Correction de l'indicateur de mode d'autorisation affichant Par défaut pendant que la session continuait de s'exécuter en mode automatique ou en mode contournement après l'échec d'une sortie automatique ; le commutateur est maintenant réessayé jusqu'à ce qu'il atterrisse
  • [VSCode] Correction d'une session téléportée depuis le web laissant tomber les messages envoyés pendant que Claude travaillait
  • [VSCode] Correction d'une session Web restant masquée dans la liste des sessions et d'un chat vide s'ouvrant à sa place, lorsqu'une ancienne version en avait enregistré une copie locale vide
  • [VSCode] Correction d'une session rouverte fractionnant un tour à un message que Claude recevait à mi-tour, comme une continuation automatique
  • [VSCode] Correction d'une session rechargée affichant un tour de rembobinage, ou uniquement les lignes avant un compactage
  • [VSCode] Correction de la pilule d'agents du pied de page dessinant son icône décentrée, avec le point d'état contre le bord, dans des panneaux étroits
  • [VSCode] Correction de l'entrée de chat affichant son texte légèrement en dessous du curseur et de la sélection après avoir collé des lignes se terminant par un saut de ligne dans une longue invite
  • [Sessions cloud] Amélioration de l'ajout d'un référentiel à une session cloud en cours d'exécution : un référentiel privé que votre compte GitHub peut lire mais pas pousser est désormais joint en lecture.
  • [Sessions cloud] Correction des sessions cloud refaisant occasionnellement une étape déjà terminée, telle que la publication d'un commentaire ou d'un push en double, après une récupération après un redémarrage côté serveur
  • [Sessions Cloud] Modification des nouveaux horaires de routine pour qu'ils soient par défaut quelques minutes après l'heure, avec une note que les routines définies exactement à l'heure peuvent démarrer plusieurs minutes en retard
  • [Claude Tag] Ajout d'un paramètre d'administration « Chaînes que Claude peut rechercher » qui limite la recherche Slack de Claude aux chaînes publiques auxquelles elle a été ajoutée, définie par organisation, espace de travail ou chaîne.
  • [Claude Tag] Ajout d'un bouton Retour à Slack sur la page affichée après la connexion de votre compte Claude, vous renvoyant au fil de discussion à partir duquel vous avez commencé
  • [Claude Tag] Correction de la page de configuration d'un canal ne répertoriant aucun connecteur ou plugin lorsque le canal obtient son bundle d'accès via une règle d'attachement ; les bundles attachés à des règles sont maintenant affichés
  • [Claude Tag] Correction de la recherche dans le référentiel d'accès groupé des référentiels manquants sur les installations de l'application GitHub qui sont limitées à une grande liste de référentiels sélectionnés
  • [Claude Tag] Correction de Claude publiant occasionnellement deux fois la même réponse lorsqu'un nouveau message l'interrompait au milieu de la réponse
  • [Claude Tag] Correction des routines de chaîne qui cessaient de s'exécuter dans les anciennes chaînes privées dont l'ID de chaîne Slack changeait, par exemple après un partage Slack Connect
  • [Claude Tag] Correction des conversations dans une chaîne définie sur « Chaîne uniquement » se terminant toutes lorsqu'un membre non invité la rejoignait et que Slack mettait du temps à confirmer son adhésion.
  • [Code Review] Correction des requêtes "@claude review" qui devenaient silencieuses lorsque GitHub ne parvenait pas à renvoyer la pull request : la requête est réessayée une fois, et un commentaire explique si elle échoue toujours
  • [Code Review] Correction de la facturation pour une révision qui s'est arrêtée à la date limite sans rien vérifier : elle s'affiche désormais comme incomplète, n'est pas facturée et est réessayée une fois.
