claude-code v2.1.330

code-claude v2.1.330

Qu'est-ce qui a changé

  • Ajout de la connexion aux organisations gérées dans la console d'administration d'entreprise d'Anthropic : après claude auth login, Claude Code applique les paramètres de l'organisation et utilise son fournisseur cloud ou sa passerelle.
  • Ajout de chevalet, un mod intégré qui dessine des graphiques lorsque cela est demandé et sous les résultats des métriques MCP, sur Pro, Max et, le cas échéant, Team et Enterprise sur macOS et Linux ; désactiver les graphiques automatiques dans /config
  • Ajout de CLAUDE_CODE_FULL_SIGN_IN_LINK=1 pour imprimer le lien de connexion complet, si le lien court affiche une erreur ou si un script en lit les valeurs
  • Runner auto-hébergé : Ajout de --start-dir / SELF_HOSTED_RUNNER_START_DIR pour que Claude démarre son travail dans un dossier d'un dépôt, pendant que les paramètres et les hooks se chargent comme sans lui
  • Ajout d'un avis dans les sessions cloud et auto-hébergées lorsqu'un marché de plugins ne peut pas être récupéré car son référentiel ne fait pas partie de la session.
  • Exécuteur auto-hébergé : ajout d'un avis lorsque git géré par Anthropic refuse le propre référentiel d'un plugin, nommant le plugin et quoi faire
  • Ajout des résultats commandPrinted aux résultats claude plugin install --json, vrai lorsque la commande d'installation du plugin écrit sur stderr, et commandFailed lorsqu'il se termine avec une erreur, est tué ou a expiré.
  • Ajout de claude_code_self_hosted_runner_order_to_registered_seconds au /metrics du coureur auto-hébergé : secondes entre le bon de travail émis et l'inscription acceptée, sur les coureurs générés par l'orchestrateur
  • Ajout de claude_code_self_hosted_runner_order_to_first_session_seconds au /metrics du coureur auto-hébergé : secondes entre le bon de travail et la première session remise, sur les coureurs démarrés pour une session
  • Correction du blocage de Claude Code pendant plusieurs minutes juste après avoir compacté une très longue conversation
  • Correction de WebFetch gelant la session pendant quelques minutes sur certaines pages et renvoyant un résultat vide pour d'autres
  • Correction de ExitWorktree et de la boîte de dialogue de sortie de l'arbre de travail supprimant un arbre de travail dans lequel travaillait une autre session Claude Code en cours d'exécution.
  • Correction des modifications apportées aux paramètres utilisateur étant perdues lorsque plusieurs processus Claude Code les enregistraient en même temps
  • Correction de --continue et --resume ouvrant une session vide ou échouant lorsque le dernier message enregistré avait un horodatage manquant ou invalide
  • Correction de la première invite après une veille de deux minutes ou plus en attente de trois minutes sur une connexion interrompue, sous Linux et WSL
  • Correction des échecs de tours avec "Le schéma JSON n'est pas valide" et des fichiers de session augmentant de plusieurs mégaoctets, lorsque de nombreux outils MCP ont un schéma d'entrée que le API refuse
  • Linux : Correction des commandes Bash attendant quelques secondes et n'affichant aucune différence de fichier pour le reste d'une session dans des référentiels lents avec de gros dossiers ignorés tels que node_modules
  • Windows : correction des commandes Bash s'exécutant plus lentement pour le reste d'une session après que Git Bash ait mis 10 à 60 secondes à démarrer, sur des machines sans fichiers de démarrage personnalisés
  • Correction de /rewind restaurant parfois une ancienne version d'un fichier lorsque deux invites en file d'attente ou des compétences empilées s'exécutaient ensemble juste après un tour qui le modifiait.
  • Correction du texte et des images ajoutés lors de l'approbation d'une invite d'autorisation supprimée lorsque la commande ou l'outil approuvé échouait.
  • Correction des ressources MCP des connecteurs claude.ai et des serveurs de plugins n'étant pas connectées lorsque @-mentionné dans la boîte d'invite du terminal
  • Correction d'un serveur MCP que les sous-agents déclarent être arrêté lorsque l'un d'entre eux a terminé, alors que d'autres sous-agents ou la session l'utilisaient encore
  • Correction de Claude dans Chrome restant "non connecté" après un bref problème de connexion, même si Chrome était ouvert et connecté
  • Correction des sessions de terminal sur Amazon Bedrock (Mantle) démarrées sans modèle sélectionné, ignorant un modèle Opus épinglé et appelant toujours un modèle par défaut indisponible après avoir annoncé une solution de repli
  • Correction du reste de ce que vous tapiez étant perdu lorsqu'un plan arrivait en mode plein écran
  • Correction des connecteurs claude.ai avec des noms différents étant supprimés lorsqu'ils partagent une URL de serveur (anthropics/claude-code#101856)
  • Correction des plugins manquant dans la liste installée lorsque plusieurs commandes claude plugin s'exécutaient en même temps
  • Correction des dépendances de tâches et des métadonnées perdues lorsque plusieurs mises à jour de tâches étaient exécutées en même temps
  • Correction des sauvegardes incomplètes de ~/.claude.json étant conservées et déplaçant les bonnes lorsque le disque était plein
  • Correction d'une longue pause en mode Code après la lecture de centaines de fichiers dans des projets avec des règles de portée de chemin ou des règles de refus de lecture.
  • Correction de l'échec de l'outil graphique intégré lorsque Claude l'appelait en mode Code
  • Correction du mode Code ignorant la demande d'un outil MCP pour mettre fin au tour d'un script en modes d'autorisations automatique et de contournement
  • Correction du mode Code en mode automatique supprimant la réflexion antérieure et réécrivant le cache d'invite lorsqu'un mod ajoutait une note après qu'un script ait chargé une compétence
  • Correction du mode Code ne restaurant pas un fichier qu'un script avait lu après Esc et /compact
  • Correction des outils du système de sous-comptage /context en mode Code avant la première réponse de Claude
  • Correction d'un sous-agent d'arrière-plan arrêté qui ne restait parfois pas arrêté
  • Correction de Claude toujours en attente d'un agent en arrière-plan qui était arrêté juste à la fin, dans les sessions exécutées par une application ou le SDK
  • Correction des sessions en arrière-plan se réveillant parfois dans leur mode d'autorisation précédent après l'approbation d'un plan
  • Contrôle à distance : correction de la note sur les agents en arrière-plan terminée par un arrêt depuis un téléphone ou le Web s'affichant dans le terminal comme si vous l'aviez tapée
  • Contrôle à distance : correction des applications mobiles masquant les boutons Diff et Pull Request, ou affichant une session arrêtée comme fonctionnant, après l'avoir activée à mi-conversation
  • Correction des variables d'environnement écrites par un hook SessionStart étant perdues avec claude -p --continue
  • Correction de claude -p quittant 0 sans message lorsque sa sortie allait vers un fichier sur un disque plein : il imprime désormais une erreur et quitte 1, bien qu'une exportation NFS complète puisse passer inaperçue
  • Correction de l'invite du système conservant les instructions du modèle précédent lorsque le modèle était modifié après /context mais avant le premier message
  • Correction de Claude répondant parfois à son rappel d'attribution de commit et mettant fin au tour plus tôt après un changement de modèle en cours de tour ; cela peut toujours arriver lorsque les paramètres gérés définissent la ligne d'attribution des relations publiques
  • Correction d'Esc ne mettant pas fin à un appel d'outil LSP qui attendait un serveur de langue lent ou bloqué
  • Correction des appels et des diagnostics de l'outil LSP échouant lorsque plusieurs appels ou modifications arrivaient alors qu'un serveur de langue était encore en démarrage
  • Correction de la liste des serveurs de plugins /mcp comme intégrés : ils se trouvent désormais sous "Plugin MCPs", --mcp-config et les serveurs intégrés sous "Autres MCPs", et la page d'un serveur nomme son plugin
  • Correction d'un avertissement "Serveur MCP bloqué par la politique d'entreprise : chevalet" s'affichant à chaque démarrage lorsqu'une liste d'autorisation ou une liste de refus MCP exclut l'outil de graphique intégré, qui reste bloqué
  • Correction de /stats comptant les nouvelles activités en jours UTC au lieu de votre fuseau horaire local
  • Correction de l'échec de /ultrareview ou de la révision du mauvais code après le déplacement du shell dans un autre référentiel : il s'arrête désormais et nomme les deux dossiers
  • Correction de Grep ne signalant aucune correspondance lorsque le modèle contenait un saut de ligne sans mode multiligne ; il signale maintenant le modèle rejeté
  • Correction des notebooks Jupyter enregistrés avec une marque d'ordre d'octet signalés comme JSON non valide par les outils Read et NotebookEdit
  • Correction des définitions de référence de lien supprimées de CLAUDE.md et des fichiers mémoire contenant un commentaire HTML
  • Correction des moniteurs en cours d'exécution gardant la conversation précédente en mémoire jusqu'à leur fin
  • Correction de certaines sessions Claude Desktop sur des fournisseurs tiers, autres que les tâches planifiées, terminant un tour par "L'invite est trop longue" lorsqu'un PDF plus grand que la fenêtre contextuelle suivait une longue conversation
  • Correction du choix entre deux fichiers utilisateur ou agent de projet déclarant le même nom en fonction de l'ordre dans lequel la recherche de fichiers les listait
  • Correction de claude daemon logs ne quittant jamais un référentiel git lorsqu'il n'y a pas de fichier journal
  • Correction du démarque masquant un caractère ou deux après le texte en gras ou en italique lorsqu'une barre oblique inverse se trouvait avant un emoji plus tard dans le paragraphe
  • Correction de l'édition refusant certaines commandes de hook valides dans les fichiers de paramètres de Claude
  • Correction de Read avec une plage de pages affichant les deux moitiés d'une double page numérisée sur chacune de ses pages
  • Correction des sauts de ligne et des stéréotypes de classe manquants dans les diagrammes Mermaid dans les artefacts HTML
  • Correction du sélecteur d'instructions de projet dans /config affichant un seul de ses quatre choix dans une fenêtre plein écran de 24 lignes
  • Correction des propres sous-agents et forks d'un sous-agent s'exécutant sur le modèle en mode plan en mode plan sous opusplan ou haiku
  • Correction des résumés de page WebFetch ignorant le niveau /effort lorsqu'une passerelle refuse le petit modèle rapide
  • Correction de claude -p sur la plateforme d'agent de Google Cloud ignorant --settings '{"fastMode":true}' lorsque le modèle provient de ANTHROPIC_MODEL ou d'un fichier de paramètres ; ces courses sont désormais facturées au prix du mode rapide
  • Correction du démarrage sous forceLoginOrgUUID étant refusé après une erreur temporaire du serveur ou une interruption de connexion
  • Correction de claude mcp remove ne donnant aucune possibilité d'avancer pour un connecteur claude.ai : il dit maintenant de le désactiver dans /mcp ou de le supprimer sur claude.ai
  • Correction de la vérification /mcp "Connect on claude.ai" disant "non connecté" lorsque claude.ai a un connecteur à l'URL du serveur sans sa requête
  • Correction de /install-github-app et /design-login affichant un échec générique pour un compte en attente au lieu de l'avis de mise en attente et du lien d'appel
  • Correction d'une tâche MCP en cours d'exécution signalée comme arrêtée lorsque vous déplacez une session en arrière-plan ; la session en arrière-plan peut désormais suivre la tâche, mais pas si son serveur utilise stdio ou définit des en-têtes
  • Correction des coureurs auto-hébergés ignorant une session jusqu'à ce qu'ils la quittent, après que son rapport d'échec ait été perdu ou que la session ait été rendue au même coureur
  • Correction des sessions auto-hébergées perdant le cache d'invite et réfléchissant plus tôt lorsque la liste des référentiels qu'un redémarrage ne pouvait pas préparer changeait
  • Coureur auto-hébergé : correction des appels d'outil derrière une invite d'autorisation disparaissant sans résultat lorsqu'un nouveau coureur prenait le relais, dans les sessions avec télémétrie désactivée
  • Correction de la reprise des sessions d'exécution auto-hébergées démarrant sans leur travail poussé dans les grands référentiels lorsque --push-outcome-on-release est défini
  • Correction des sessions de coureur auto-hébergées affichées comme fonctionnant lorsque Claude Code se bloque à chaque démarrage et que --startup-timeout-min est de 2 à environ 6.
  • Correction de pkill -f dans les sessions d'exécution auto-hébergées sous Linux mettant fin à son propre shell avec le code de sortie 144, ou au runner (nécessite un pkill avec --ignore-ancestors)
  • Correction des tâches planifiées sur les coureurs auto-hébergés n'ayant aucun outil pour avertir leur propriétaire lorsque la télémétrie est désactivée ou qu'un fournisseur tiers est utilisé
  • Exécuteur auto-hébergé : correction d'un hook lent spawn-runner empêchant l'orchestrateur de réclamer des sessions pour ses emplacements libres ; il interroge désormais toutes les 4 à 6 secondes lorsqu'un emplacement est libre
  • Exécuteur auto-hébergé : correction d'un 403, tel qu'une liste d'autorisation IP, enregistré comme un mauvais secret ou un jeton : la plupart de ces lignes commencent désormais par la raison du serveur, donc mettez à jour les alertes du journal qui correspondent aux anciens mots
  • Correction du mode d'avertissement des coureurs auto-hébergés pour les paramètres du référentiel, s'arrêtant à la première découverte de la plupart des types : il continue désormais, jusqu'à 50 pour une session, et indique s'il s'arrête plus tôt
  • Exécuteur auto-hébergé : correction des exécuteurs qui démarrent sur un disque plein prenant des sessions et les faisant échouer ; ils attendent maintenant une chambre et sortent 1 après une minute sans session, à moins d'avoir démarré à partir d'un bon de travail
  • Runner auto-hébergé : correction d'un échec de démarrage suggérant une nouvelle tentative lorsque la machine du coureur n'avait pas d'informations d'identification git ; l'erreur indique maintenant à qui demander et quoi faire si le référentiel est erroné
  • Correction du last_poll_age_seconds du coureur auto-hébergé indiquant 0 alors que le coureur n'avait jamais interrogé avec succès
  • Correction de l'avis concernant une tâche planifiée ignorée qui ne nomme aucune organisation : il est désormais demandé de démarrer Claude Code avec --resume, car /resume dans une session en cours n'exécute pas la tâche
  • Correction de claude plugin validate avertissant à tort que le hook AbovePrompt ou AbovePromptList d'un mod ne s'exécute jamais dans VS Code
  • Correction de /design-sync supprimant un fichier qu'il venait de télécharger lorsque Claude Design stockait ce fichier sous un nom modifié
  • Annulation de la suppression par 2.1.329 de la nouvelle tentative automatique lorsque max_tokens dépasse la limite d'un modèle ou d'une passerelle.
  • Amélioration du lien de connexion claude.ai affiché par /login, claude auth login et claude setup-token : il est désormais beaucoup plus court
  • Windows : amélioration de la vitesse de Grep et Glob en ne démarrant plus un hôte de console pour chaque recherche ripgrep intégrée sur un chemin local
  • Amélioration de la vitesse des différences de fichiers
  • Recherche /config améliorée : la plupart des paramètres dont le nom commence par ce que vous tapez viennent en premier, "effort" trouve le modèle et "sombre" ou "clair" trouve le thème
  • /resume amélioré : les sessions où vous avez uniquement ouvert un écran tel que /model et quitté ne sont plus répertoriées
  • Reconnexion améliorée dans /mcp et /plugin : la page d'un serveur reste désormais ouverte, avec la cause en vue, lorsque le serveur échoue toujours ou nécessite une connexion
  • Amélioration de l'erreur sur macOS lorsque les listes de refus du sandbox sont trop longues : il nomme désormais les longues listes et comment les raccourcir
  • Amélioration de /plugin en mode plein écran : la page d'un plugin avec des erreurs démarre désormais avec ces erreurs
  • Amélioration de la confirmation des coûts du /ultrareview sur les forfaits Team et Enterprise : elle indique désormais combien de votre limite de dépenses mensuelle il reste lorsqu'elle est inférieure au coût habituel d'un avis.
  • Amélioration des sessions d'exécution auto-hébergées sur Amazon Bedrock ou la plateforme d'agent de Google Cloud pour le dire lorsqu'elles démarrent sur un autre modèle par défaut parce que votre compte a refusé le premier
  • Windows : amélioration de l'erreur lorsque le dossier d'une session se trouve sur un lecteur que Claude Code ne peut pas vérifier : il indique pourquoi et si une nouvelle tentative peut aider
  • Mode Code amélioré : Claude apprend désormais comment regarder des images et des PDF
  • Mode Code amélioré : après Esc, "Interrompu" s'affiche désormais sous la commande arrêtée à la place d'une erreur rouge
  • Mode Code amélioré : le terminal se fige beaucoup moins longtemps après que le script d'un sous-agent ait effectué des milliers d'appels d'outils.
  • Modification des tâches planifiées récurrentes et de /loop pour qu'elles s'exécutent jusqu'à 30 jours au lieu de 7 pendant que leur session continue de s'exécuter, et indiquent quand elles se terminent ; les tâches effectuées avant cette version se terminent toujours à 7 jours
  • Modification de davantage de commandes rm destinées à la racine, à la maison, à un dossier de niveau supérieur ou au dossier de travail pour demander l'approbation ; là où personne ne peut répondre, ils sont refusés
  • Modification des entrées de nom deniedMcpServers pour masquer uniquement le connecteur nommé claude.ai, pas les autres au niveau de son URL ; pour les bloquer tous, refusez son URL exacte
  • Modification de claude --teleport dans certaines configurations pour imprimer les commandes git pour changer de branche au lieu de les exécuter ; avec -p il sort de 1 jusqu'à ce que vous changiez
  • Modification des noms de modèles non reconnus contenant « sonnet » ou « haïku » pour utiliser l'invite système plus courte, comme d'autres noms non reconnus ; CLAUDE_CODE_SIMPLE_SYSTEM_PROMPT=0 donne à chaque modèle le modèle complet
  • Modification des compétences que Claude exécute avec un paramètre model, autres que les compétences context: fork, pour laisser les sous-agents, les fourches, le compactage et /recap sur le modèle de la session.
  • Modification du modèle de repli d'un sous-agent pour qu'il soit reporté : les agents sans modèle et sans fourche commencent alors à s'exécuter sur le repli, et les agents qu'ils démarrent utilisent sa région Bedrock.
  • Exécuteur auto-hébergé : modification des hooks spawn-runner pour qu'ils démarrent alors que les précédents fonctionnent toujours, jusqu'à --hook-concurrency par orchestrateur (4 par défaut) ; réglez-le sur 1 si le vôtre ne peut pas fonctionner à côté d'un autre
  • Exécuteur auto-hébergé : modification des commandes Bash pour ignorer la différence de fichier lorsque rien n'en a besoin, afin que les transcriptions puissent en manquer ; définissez bashEditDiffEnabled sur true dans les paramètres gérés pour obtenir chaque différence
  • Modification des coureurs auto-hébergés pour arrêter le démarrage d'une session immédiatement, sans essayer d'autres coureurs, lorsqu'un hook de paiement se termine avec le statut 108
  • Modification des hooks d'invite pour accepter les alias de modèle tels que haiku ou sonnet dans leur champ model
  • Modification de la version de secours de /design-sync du Storybook de référence pour utiliser uniquement un Storybook installé dans le projet
  • Modification des résumés de progression des sous-agents dans les sessions de terminal connectées à une passerelle d'applications Claude pour qu'ils soient rédigés à partir de notes courtes au lieu de l'intégralité de la conversation, en utilisant beaucoup moins de jetons.

  • [VSCode] Correction d'une touche Entrée enfoncée envoyant un message à moitié écrit ou exécutant une commande slash tapée
