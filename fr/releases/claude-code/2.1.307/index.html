claude-code v2.1.307

Correctif Publié21 oct. 2026 Sourceanthropics/claude-code Anglais original

Cette page est traduite automatiquement. Le texte anglais original fait foi.

code-claude v2.1.307

Qu'est-ce qui a changé

  • Ajout de /claude-api api-version pour déplacer le code Claude API vers la version API 2026-10-21
  • Ajout de l'événement claude_code.safety_event OpenTelemetry pour chaque appel d'outil, une règle d'autorisation, un mode automatique, un contrôle de sécurité, un hook ou le bac à sable arrêté, invité ou renvoyé
  • Correction des requêtes échouant avec une erreur de modèle introuvable lorsque CLAUDE_CODE_DISABLE_1M_CONTEXT est défini et que le modèle est un alias avec le suffixe [1m], tel que opus[1m]
  • Correction de l'en-tête bêta prompt-caching-scope envoyé derrière des passerelles ANTHROPIC_BASE_URL personnalisées et sur Foundry, où il n'a aucun effet
  • Correction des serveurs MCP affichant « authentification nécessaire » dans claude -p sur macOS alors que le trousseau de connexion était verrouillé ; ils disent maintenant pourquoi, et la prochaine exécution après un déverrouillage se connecte sans nouvelle connexion
  • Correction des serveurs MCP signalés comme ayant expiré et échouant lors d'exécutions sans tête, lorsqu'un ordinateur macOS ou Linux se mettait en veille pendant leur connexion.
  • Correction des appels de l'outil HTTP MCP envoyés deux fois lorsque la connexion était fermée en cours d'appel ; seuls les outils en lecture seule ou idempotents sont désormais réessayés
  • Correction d'un tour démarrant parfois sans les derniers outils d'un serveur SDK MCP lorsqu'une tâche en arrière-plan était en cours d'exécution
  • Correction de quelques erreurs "Autocompact se débat" à tour de rôle qui lisaient de nombreuses pages PDF, images ou autres résultats d'outils volumineux
  • Correction de /autocompact dans les sessions cloud revenant à la fenêtre par défaut après le redémarrage de la session
  • Correction d'une conversation effacée avec /clear revenant parfois lors du redémarrage d'une session cloud ou d'un coureur auto-hébergé
  • Correction de CLAUDE_STREAM_FIRST_BYTE_TIMEOUT_MS étant ignoré dans les sessions de passerelle des applications Claude
  • Correction de la télémétrie des sessions Claude Desktop derrière une passerelle d'applications Claude rejetée lorsque OTEL_EXPORTER_OTLP_HEADERS est défini
  • Correction de /permissions > Récemment refusé, n'affichant pas la commande shell refusée et le classificateur local du mode automatique ignorant une approbation de là lorsqu'il vérifie une commande réessayée ; l'approbation d'une ligne nomme désormais la commande, pas sa description
  • Correction de /help et du menu de commandes / affichant de longues descriptions face au modèle pour les compétences groupées telles que /claude-api au lieu de leurs courtes descriptions
  • Correction des transcriptions de sous-agents enregistrant l'utilisation du jeton d'espace réservé et un motif d'arrêt vide pour les réponses diffusées en continu.
  • Correction des changements de modèle via le setModel() de l'agent SDK et des applications construites dessus, qui étaient refusés lorsque le API prenait plus de 5 secondes pour confirmer le modèle ; Claude Code attend désormais jusqu'à 15 secondes
  • Correction d'une commande en arrière-plan arrêtée via une application connectée (telle que l'application de bureau archivant une session inactive) signalée à Claude comme arrêtée par l'utilisateur ; l'avis nomme désormais son fichier de sortie
  • Correction de WebFetch dans les sessions cloud Cowork signalant une erreur d'outil lorsqu'un site répondait avec un statut 4xx ou un refus robots.txt ; c'est désormais un résultat normal, comme lors des séances locales
  • Correction des outils d'écriture sur un serveur MCP GitHub directement configuré affichant un formulaire qui se fermait sans rien créer dans l'onglet Code de l'application de bureau
  • Correction de l'échec des lectures de l'outil Artefact lors d'une réinitialisation de connexion lorsque le serveur avait fermé une connexion réutilisée.
  • Runner auto-hébergé : correction des sessions avec --use-anthropic-git-proxy validant un .claude/settings.local.json laissé dans le clone par une session précédente
  • Runner auto-hébergé : correction de l'archivage ou de la remise en file d'attente d'une session, ou de l'arrêt du coureur, pendant son hook de paiement, laissant les processus du hook en cours d'exécution et l'emplacement du coureur maintenu
  • Amélioration de la récupération suite aux appels d'outils non analysables : Claude Code réessaye désormais l'appel jusqu'à deux fois avant de terminer le tour avec une erreur
  • Amélioration des sous-agents fork lancés ensemble : chacun sait désormais quel lancement est le sien, donc les forks sont beaucoup moins susceptibles d'essayer de démarrer le travail de l'autre
  • Connexion améliorée au navigateur : la page de réussite apparaît désormais dès que la connexion est terminée, sans attendre le chargement de votre profil de compte
  • Amélioration des erreurs de recherche Web dans les sessions cloud et auto-hébergées : une recherche refusée avec un 403 qui donne une raison affiche désormais cette raison au lieu d'une "Erreur d'authentification" générique
  • Amélioration du délai de première réponse dans les sessions cloud lorsque l'un des serveurs MCP de l'application de bureau ne parvient pas à se connecter
  • Amélioration du temps de connexion du contrôle à distance pour les sessions dont la transcription contient de grandes images collées ou des lectures PDF
  • Modification de l'avertissement que Claude reçoit lorsque le budget WebSearch est épuisé pour lui indiquer également de ne pas interroger les moteurs de recherche dans un navigateur ou via un ordinateur.
  • Modification du paramètre axScreenReader et CLAUDE_AX_SCREEN_READER dans un bloc de paramètres env pour s'appliquer uniquement à partir des paramètres utilisateur, gérés ou --settings (depuis 2.1.305)
  • Exécuteur auto-hébergé : les hooks de paiement ont été modifiés pour être arrêtés après 30 minutes par défaut, ce qui a échoué lors de la configuration de la session ; si le vôtre a besoin de plus de temps, augmentez --checkout-hook-timeout-min ou réglez-le sur 0
  • Exécuteur auto-hébergé : modification du fichier de certificat créé pour git géré par Anthropic afin de filtrer ses certificats trusted comme le fait le CLI ; une ligne [runner:warn] donne le numéro laissé de côté
  • [VSCode] Ajout d'une notification sur le bouton du microphone lorsque la dictée vocale s'arrête d'elle-même (15 secondes sans parole reconnue, soit la limite de 2 minutes), indiquant pourquoi et que le texte jusqu'à présent est conservé
  • [VSCode] Correction d'une longue invite étendue avec Afficher plus couvrant l'ensemble du panneau de discussion : une invite épinglée est désormais plafonnée à 40 % du panneau et défile
  • [VSCode] Correction d'une partie d'un élément de liste ou d'une cellule de tableau avec le collage mathématique LaTeX en tant que nouvelle liste ou tableau dans les éditeurs de texte enrichi
  • [VSCode] Correction de l'échec de la dictée derrière un proxy d'inspection TLS lorsque NODE_EXTRA_CA_CERTS est défini uniquement dans ~/.claude/settings.json ; il suit désormais également CLAUDE_CODE_CERT_STORE
  • [VSCode] Modification de l'avis "toujours ouvert ailleurs" pour couvrir également un processus Claude laissé par un redémarrage d'extension, qui se termine généralement tout seul dans environ 10 minutes
  • [VSCode] Modification de la dictée vocale pour filtrer ses certificats trusted comme le fait le CLI
  • [VSCode] Modification des propres requêtes de l'extension pour filtrer leurs certificats trusted comme le fait le CLI, et en trust le fichier NODE_EXTRA_CA_CERTS nommé dans l'environnement ou dans les paramètres utilisateur
  • [Sessions Cloud] Correction du sélecteur de référentiel indiquant "Aucun référentiel ne correspond" alors qu'une recherche était toujours en cours ; il affiche maintenant "Recherche…" jusqu'à ce que les résultats arrivent
  • [Sessions Cloud] Correction du statut "En attente d'un coureur" sur les environnements auto-hébergés étant coupé ; avec les coureurs à la demande, il compte désormais à partir de votre dernier message et affiche les tentatives échouées
  • [Code Review] Ajout de @claude review stop (également off et pause) à Code Review, mettant fin à un abonnement @claude review always sur une pull request sans démarrer une nouvelle révision
