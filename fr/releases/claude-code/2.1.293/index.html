claude-code v2.1.293

Correctif Publié7 oct. 2026 Sourceanthropics/claude-code Anglais original

Cette page est traduite automatiquement. Le texte anglais original fait foi.

code-claude v2.1.293

Qu'est-ce qui a changé

  • Ajout de Claude Haiku 5.5 (claude-haiku-5-5), désormais le modèle Haiku par défaut sur le contexte Anthropic API — 1M, $0.10/$0.50 par Mtok ($0.50/$2.50 pour les invites supérieures à 100K)
  • Ajout de agentType à la charge utile subagentStatusLine, afin que les scripts puissent distinguer les types de sous-agents personnalisés
  • Ajout de isDeferred à $.tool.register pour les mods : false répertorie le schéma de l'outil dans l'invite dès le début au lieu de derrière la recherche d'outil
  • Correction de Claude traitant parfois ses dernières actions avant un compactage de contexte comme effectuées après, et rétractant ou refaisant le travail fini
  • Correction d'une fuite de mémoire où une connexion HTTP MCP conservait chaque requête envoyée jusqu'à sa fermeture
  • Correction d'un message envoyé pendant que Claude travaillait et se perdait lorsque ← déplaçait la session en arrière-plan ; si un message en file d'attente ne peut pas bouger, ← reste désormais en place et le dit
  • Correction de l'effort /model ←/→ dépassant le niveau le plus élevé ou le plus bas, ce qui pouvait accidentellement enregistrer Low comme effort par défaut d'un modèle.
  • Correction de /tui déconnectant Claude dans Chrome dans une session démarrée avec --chrome, et ignorant --no-chrome
  • Correction du message indiquant à Claude de continuer ou d'envoyer des messages aux sous-agents avec SendMessage dans les sessions, y compris celles reprises, où un hôte, une règle d'autorisation ou une liste --tools supprimait cet outil
  • Correction des sous-agents et des sessions --agent se voyant indiquer qu'un outil intégré était désactivé pour toute la session alors que seule leur propre liste d'outils l'avait laissé de côté.
  • Correction de la description modifiée d'une compétence synchronisée avec claude.ai qui n'atteignait parfois pas le modèle avant une nouvelle conversation ou /clear
  • Correction de claude logs, stop, kill, rm et claude daemon status, stop, uninstall vous déconnectant parfois lorsque votre connexion avait expiré ou était sur le point de le faire.
  • Correction du nombre d'agents du pied de page disparaissant après un échec momentané de lecture du dossier des sessions (par exemple, trop de fichiers ouverts)
  • Correction d'un agent personnalisé nommé worker affiché comme "Agent" lorsqu'il démarre, et le titre de la boîte de dialogue des détails de l'agent perdait le type d'agent une fois l'agent terminé.
  • Correction de la ligne de transcription de l'outil Artifact lisant brièvement Artifact("(unprintable path)") alors qu'un appel de publication était toujours en streaming
  • Correction du téléchargement de /ultrareview sous Linux refusant à tort certains dépôts, comme un dépôt dans un autre, sur un fichier de paramètres qui "ne pouvait pas être analysé" pendant l'exécution d'une commande en bac à sable
  • Correction du refus du téléchargement /ultrareview sur les fichiers à index fractionné conseillant une commande git qui pourrait empêcher git de lire son index
  • Correction des réponses dans les très longues sessions de contrôle à distance et cloud qui pouvaient toujours apparaître bloc par bloc au lieu d'être diffusées en continu
  • Correction du contrôle à distance téléchargeant à nouveau l'historique de démarrage d'une session après chaque récupération d'informations d'identification
  • Correction du rapport PushNotification "Télécommande inactive" dans les sessions démarrées avec claude remote-control
  • Correction des hooks d'un mod sur les événements classic.* qui étaient ignorés pendant le redémarrage du plugin hooks worker, ce qui laissait les hooks de paramètres répondre sans eux.
  • Correction de l'échec de claude plugin test pour les mods qui appellent $.session.append ; les tests peuvent relire les lignes ajoutées avec le nouveau mock.session
  • Correction de claude plugin eval refusant chaque exécution d'octroi de Bash sur Mac avec Docker Desktop (liens sous ~/.docker/bin) ; le refus indique désormais quelle partie d'un magasin d'informations d'identification détenait le lien
  • Correction de la passerelle des applications Claude refusant de démarrer lorsqu'une stratégie desktop définit les clés de navigateur intégrées de Claude Desktop, telles que builtinBrowserEnabled
  • Correction de claude agents offrant des autorisations de contournement que les sessions en arrière-plan ignoraient ensuite lorsque le consentement était enregistré uniquement dans .claude/settings.local.json ou dans un fichier --settings ; il demande maintenant d'abord le consentement, et une session qui ignore le contournement affiche un bref avis qui reste
  • Correction de ← mettant en arrière-plan une session après 10 secondes alors que l'invite contenait du texte non envoyé (cela annule désormais le déplacement) ou qu'une question attendait votre réponse
  • Correction de Esc, ou Non sans retour, sur une invite d'autorisation n'arrêtant pas le tour lorsque ← venait d'être appuyé pour déplacer la session en arrière-plan
  • Correction de la vue des agents remplaçant brièvement la liste des sessions par des lignes d'espace réservé lorsque le dossier des sessions ne pouvait pas être lu (par exemple, trop de fichiers ouverts)
  • Correction des règles de chemin et des fichiers CLAUDE.md imbriqués qui ne se chargeaient pas lorsque Claude visualisait un fichier avec une commande cat, head, tail, sed -n ou grep à fichier unique dans l'outil Bash au lieu de l'outil de lecture.
  • Correction du texte collé qui commençait et se terminait par les mêmes mots étant parfois envoyés à Claude comme s'il avait été tapé
  • Correction d'un nom de compétence dans le texte collé étant traité comme tapé lorsqu'un accent tapé ou collé juste après la pâte fusionnait dans sa dernière lettre.
  • Correction de /feedback retournant à la liste des brouillons après Ctrl+O ou Ctrl+Z pendant l'envoi d'un rapport, laissant l'envoi impossible à annuler
  • Correction de claude purge s'arrêtant silencieusement (sortie 0, ou blocage dans un terminal) lorsqu'un fichier ou un dossier ne pouvait pas être supprimé ; il supprime maintenant le reste, répertorie ce qu'il n'a pas pu supprimer et quitte 1
  • Correction des vérifications keybindings.json : un seul " " (touche espace) n'est plus signalé comme une erreur, et les touches comme "ctrl+ k" reçoivent désormais un avertissement
  • Correction du mode vim >> et << sur une ligne composée uniquement d'espaces laissant le curseur au-delà de la fin de la ligne, où un x suivant ne supprimait rien
  • Correction du mode vim : après avoir supprimé des lignes entières en mode Visuel (V puis d) le curseur se pose sur la première non vide, et . après il agit sur la ligne du curseur
  • Windows : correction de l'arrêt d'une ligne d'état, d'un hook ou d'une commande shell, mettant parfois fin à un processus sans rapport ayant reçu le même ID de processus
  • Annulation du changement de message de refus du mode automatique de 2.1.281 qui indiquait à Claude qu'un refus couvrait le résultat, pas seulement la commande exacte
  • Annulation du correctif 2.1.290 pour les sessions cloud restant en veille après le redémarrage d'un conteneur, perte d'un réveil /loop en attente ou d'une tâche planifiée ; Claude n'est plus prévenu, et la séance reste endormie
  • Démarrage amélioré pour les organisations Team et Enterprise : les paramètres de stratégie et gérés sont récupérés plus tôt et une demande bloquée est réessayée après 3 secondes.
  • Claude amélioré dans Chrome : moins d'actions de page sont refusées lorsque le navigateur tarde à signaler ses onglets
  • Amélioration du message Claude dans Chrome dans les sessions cloud lorsque le navigateur n'est pas joignable : si vous appartenez à plusieurs organisations, il indique désormais que l'extension doit être connectée à la même, et comment changer cela
  • Amélioration de la note diff d'édition Bash pour indiquer que les fichiers répertoriés ont été modifiés pendant l'exécution de la commande, ce qui peut inclure des écritures par d'autres processus.
  • Artefacts améliorés : Claude épingle les bibliothèques sur des versions exactes datant de deux semaines ou plus
  • Modification de la synchronisation des compétences claude.ai pour vérifier les changements environ toutes les 40 minutes, au lieu de toutes les 10, lorsqu'aucune session n'est en cours d'utilisation.
  • Modification de l'ordre des listes d'agents et des serveurs MCP annoncés au modèle : les noms avec des caractères non-ASCII sont désormais triés après les noms ASCII
  • Modification de la journalisation OpenTelemetry claude_code.at_mention pour émettre au maximum 100 événements d'agent et 100 événements de ressource MCP à chaque fois qu'une invite est lue
  • Exécuteur auto-hébergé : modification de l'orchestrateur pour qu'il dorme 4 à 6 secondes entre les interrogations au lieu de 5 constantes, de sorte que plusieurs répliques pour un environnement arrêtent l'interrogation au même moment.
  • [Claude Tag] Correction de Claude dans Slack indiquant qu'un espace de travail n'est pas configuré dans les canaux Enterprise Grid partagés entre les espaces de travail lorsque Slack étiquette un message avec un espace de travail qui n'est pas connecté.
  • [Claude Tag] Correction de Claude dans Slack qui s'arrêtait en cours de tâche dans un canal lorsqu'un administrateur modifiait les connecteurs, plugins, compétences ou règles du canal ; le changement s'applique désormais une fois que Claude a terminé
  • [Claude Tag] Correction du problème demandant à Claude dans Slack d'exécuter maintenant la routine d'un fil de discussion avec des notes supplémentaires démarrant une exécution distincte qui ne pouvait pas être publiée ; la course continue maintenant dans ce fil
  • [Claude Tag] Correction de la boîte de dialogue Ajouter un connecteur d'un bundle d'accès dans les paramètres d'administration de Claude Tag affichant chaque connecteur Google comme connecté après une connexion Google.
  • [Claude Tag] Amélioration des paramètres d'administration de Claude Tag pour lister une Enterprise Grid qui n'est pas encore connectée, avec un bouton Connecter
  • [Claude Tag] Modification de Claude dans Slack pour qu'il rejoigne les canaux d'annonce, où seuls les administrateurs peuvent publier, sans publier son intro
  • [Claude Tag] Modification de la limite des règles de canal dans les paramètres d'administration de Claude Tag de 20 à 50 pour chaque espace de travail et pour la page Slack à l'échelle de l'organisation.
  • [Code Review] Amélioration de la boîte de dialogue Ajouter un référentiel de Code Review pour répertorier chaque référentiel qui n'a pas pu être ajouté et pourquoi, comme l'accès en écriture GitHub manquant
