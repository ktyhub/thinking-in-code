claude-code v2.1.288

Correctif Publié2 oct. 2026 Sourceanthropics/claude-code Anglais original

Cette page est traduite automatiquement. Le texte anglais original fait foi.

code-claude v2.1.288

Qu'est-ce qui a changé

  • Ajout de $.ui.selection() pour les mods : renvoie le texte que vous avez sélectionné pour la dernière fois en mode plein écran et, lorsque la sélection se situe dans une ligne de transcription, cette ligne
  • Ajout d'un gh api intégré aux sessions cloud dont l'image n'a pas de GitHub CLI, et correction de l'envoi intégré de caractères de contrôle à partir des noms de fichiers, des filtres jq ou des erreurs GitHub au terminal
  • Ajout de la récupération pour une invite effacée avec Ctrl+C : appuyer sur Haut sur l'invite vide ramène le brouillon, y compris le texte et les images collés
  • Ajout d'une invite de ré-authentification lorsqu'un serveur MCP demande plus de portée OAuth lors d'un appel d'outil
  • Ajout de --max-findings <n>|all à /code-review pour rapporter plus ou moins de résultats que la limite habituelle ; le choix est réutilisé jusqu'à ce que vous passiez --max-findings default
  • Ajout de Ctrl+F pour rechercher une session par nom et Alt+↑/↓ pour passer d'un groupe à l'autre dans la vue des agents ; les deux, et leur renommage, peuvent être rebondis dans les raccourcis clavier.json
  • Ajout d'une annonce en mode lecteur d'écran du nouveau mode d'autorisation lorsque vous approuvez un plan, y compris avec Shift+Tab
  • Correction des délais d'attente à mi-réponse API en cas d'échec du tour : les sessions non interactives et les sous-agents continuent désormais à partir de la réponse partielle, et les réponses de réflexion uniquement sont réessayées
  • Correction des longues conversations qui échouaient avec "L'invite est trop longue" au lieu du compactage automatique lorsque la dernière réponse signalait une utilisation nulle du jeton.
  • Correction de --resume laissant parfois tomber des fichiers et autres contextes qu'un compactage venait de restaurer
  • Correction d'une reprise de session qui n'enregistrait parfois pas la dernière réponse d'un tour, de sorte que le --resume suivant affichait l'invite sans réponse
  • Correction du CV chargeant occasionnellement une transcription interrompue lorsque la même session réécrivait le fichier pendant le chargement
  • Correction de la reprise d'une conversation commencée sur 2.1.286 ou plus tôt, laissant tomber la réflexion précédente du modèle
  • Correction des titres de session, des rappels de mémoire et des hooks d'invite échouant sur Mantle ou derrière des passerelles qui rejettent les sorties structurées ; ajout de CLAUDE_CODE_DISABLE_STRUCTURED_OUTPUTS pour désactiver les sorties structurées
  • Correction des refus de mode automatique pointant Claude vers une règle d'autorisation Bash lorsque l'outil bloqué n'était pas Bash
  • Correction du mode automatique sur Bedrock et Mantle passant au classificateur local pour le reste de la session après une requête à un modèle plus ancien, comme un résumé WebFetch ou un sous-agent sonnet
  • Correction des sessions cloud qui redémarraient sur un modèle nouvellement sélectionné répondant avec ce modèle après que le serveur l'ait refusé
  • Correction des sessions cloud Cowork restant marquées comme en attente d'entrée après qu'une invite d'autorisation WebFetch pour une URL non approuvée soit restée sans réponse pendant cinq minutes
  • Correction des suggestions d'invite n'apparaissant pas sur un téléphone qui rejoint une session cloud Cowork démarrée sur un autre appareil
  • Correction d'un bouton de mod exécutant parfois l'action d'un bouton différent lorsqu'on appuie sur une vue dessinée avant le redémarrage de Claude Code
  • Correction du volet d'un plugin n'affichant rien lorsqu'un élément Code contenait un diff qui n'était pas analysé ; il dessine maintenant sous forme de code simple
  • Correction des serveurs LSP de plugin recevant des espaces réservés littéraux ${user_config.*} et ${CLAUDE_PLUGIN_ROOT} dans initializationOptions et settings au lieu de valeurs substituées ou de valeurs par défaut manifestes
  • Correction du hook tool.call d'un plugin faisant échouer Bash et les recherches de fichiers lisaient le mauvais dossier dans les sous-agents qui s'exécutent dans un arbre de travail
  • Correction de l'échec de l'installation du plugin git-subdir ou de la mise en cache d'un plugin incomplet sur un ancien git (avant 2.39, par exemple 2.34 d'Ubuntu 22.04)
  • Correction des plugins chargés avec --plugin-dir n'affichant pas "Configurer les options" dans /plugin
  • Correction des sessions en arrière-plan se terminant lorsqu'un plugin était rechargé ou désactivé alors qu'un de ses minuteurs ou lectures était toujours en cours d'exécution
  • Correction des héréditaires en bac à sable avec un délimiteur sans guillemets (python3 <<EOF) demandant l'approbation à chaque exécution sous autorisation automatique du bac à sable lorsque le corps ne contient que du texte brut et de simples références $VAR
  • Correction de la vérification des autorisations de l'outil Bash pour demander avant une affectation BASHPID dont le shell évaluerait la valeur comme arithmétique, au lieu de l'autoriser silencieusement
  • Correction des sessions plein écran se terminant avec une "erreur d'interface irrécupérable" lors de l'ouverture de la boîte de dialogue des tâches en arrière-plan alors qu'un plugin ou un mod affichait des lignes au-dessus de l'invite
  • Correction de Claude signalant qu'un message à une autre session était livré alors que cette session l'avait tenu : l'avis indique maintenant qu'il n'a pas été livré et nomme la session, et dans les sessions SDK, Claude peut désormais en prendre connaissance à mi-tour.
  • Correction des étendues OpenTelemetry claude_code.tool.blocked_on_user signalant la source ou la décision unknown dans les sessions -p et SDK et pour les approbations de hook PreToolUse
  • Correction des demandes d'autorisation qui se terminaient sans réponse, en -p ou sur un tour interrompu, n'émettant aucun événement tool_decision
  • Correction des modifications et des tentatives dans les sessions cloud Cowork refusant un message envoyé avant /compact même si son historique était toujours enregistré
  • Correction des sessions sans surveillance (CLAUDE_CODE_RETRY_WATCHDOG) qui réessayaient pendant des heures après l'échec d'un flux de réponse très long ; Claude Code streame à nouveau et abandonne après trois timeouts
  • Correction du rapport /login "Connexion réussie" lorsque les informations d'identification ne pouvaient pas être enregistrées dans un stockage sécurisé ; il affiche maintenant l'échec et propose une nouvelle tentative lorsque la nouvelle connexion n'a pas pris effet (anthropics/claude-code#73861)
  • Correction d'un arrêt lors de la recherche des informations d'identification Bedrock, déplaçant parfois la session vers un modèle de secours au lieu de mettre fin à la demande
  • Correction d'une deuxième ouverture de connexion au navigateur gcpAuthRefresh/awsAuthRefresh lorsqu'un ordinateur portable sort du mode veille pendant qu'un autre processus Claude Code se connecte
  • Correction des équipes d'agents : un agent défini par un plugin et généré par son nom s'exécute désormais avec ses propres invites, outils, outils interdits et efforts au lieu des valeurs par défaut.
  • Correction des sessions sans tête (-p / SDK) ignorant parfois SIGTERM lorsqu'un superviseur tel que timeout ou systemd envoie SIGCONT à côté de lui
  • Correction des sessions cloud redémarrées restaurant un modèle que la liste des modèles appliqués par l'organisation refuse
  • Correction des appels de l'outil MCP s'exécutant parfois deux fois lorsque le résultat d'un serveur distant dépassait 16 Mo ou ne pouvait pas être analysé
  • Correction des sous-agents dans l'onglet Code de Claude Desktop n'obtenant aucun des outils d'un serveur MCP configuré par l'utilisateur nommé memory
  • Correction de Claude dans Chrome demandant avant chaque capture d'écran et page lue sur un site que vous avez autorisé lorsque le mode automatique n'est pas disponible (comme avec disableAutoMode ou un modèle plus ancien) ; la saisie, la navigation et JavaScript demandent toujours
  • Correction de l'échec de claude plugin install pour les plugins source GitHub sur les machines macOS et Linux sans clé SSH GitHub : le clone revient désormais à HTTPS et imprime une notification
  • Correction des entrées sandbox.credentials.files sur les fichiers de configuration git ne prenant pas effet lorsque permissions.blockReadsOutsideWorkingDirectories est activé
  • Correction de Claude laissant de côté les systèmes de conception de votre organisation lors du démarrage de diapositives ou d'une conception avec l'outil Artefact sur les plans Team et Enterprise ou sur les machines avec paramètres gérés
  • Correction du clavier qui ne fonctionnait pas sous Windows après le redémarrage de Claude Code (première connexion à une passerelle d'applications Claude, configuration du fournisseur, /tui)
  • Correction d'un blocage au lancement d'un agent dont le tools: répertorie de très nombreuses entrées Agent(...)
  • Correction des sessions sur Claude 3 Opus et Claude 3 Sonnet qui échouaient à chaque tour après qu'un PDF entier soit entré dans la conversation
  • Correction du succès du rapport de mise à jour automatique npm lorsque le téléchargement du binaire natif de la plate-forme échouait et que seul le stub claude de l'espace réservé était installé
  • Correction du nettoyage de la télécommande archivant une session qui est toujours connectée ou qui vient d'être reconnectée par un autre processus Claude Code
  • Correction des marchés de plugins owner/repo affichant uniquement l'erreur de la deuxième tentative lorsque la récupération SSH et HTTPS échoue ; les deux erreurs sont maintenant affichées, avec le transport essayé en premier en haut
  • Correction des fichiers .claude/rules à portée de chemin et des fichiers CLAUDE.md imbriqués qui ne se chargeaient pas lorsque Write ou Edit créait ou modifiait un fichier dans leur portée (auparavant, seule la lecture les chargeait)
  • Correction d'un rm dangereux (comme celui sur / ou le répertoire personnel) dans un script bash -c ou sh -c s'exécutant sans invite en mode bypassPermissions ou sous une règle d'autorisation du shell (anthropics/claude-code#96300)
  • Correction des appels de l'outil LSP suspendus indéfiniment lorsqu'un serveur de langue utilise l'enregistrement de capacité dynamique ou cesse de répondre ; les requêtes expirent désormais après 60 s (par serveur requestTimeout)
  • Correction des hooks de notification idle_prompt se déclenchant alors que les agents en arrière-plan sont toujours en cours d'exécution (anthropics/claude-code#93672)
  • Correction des hooks PreToolUse et PermissionRequest étant ignorés en cas d'échec de leur correspondance ou lorsque l'entrée de l'outil ne pouvait pas être sérialisée sur JSON ; l'appel est maintenant bloqué
  • Correction de la première requête dans un nouvel environnement ou après un changement de modèle en utilisant la limite de sortie intégrée et la fenêtre de compactage automatique, et non celle du serveur ; cette requête peut maintenant attendre jusqu'à 1.5 secondes
  • Correction du problème "Que devrait faire Claude à la place ?" indice affiché sur la ligne Interrompu après l'envoi de messages en file d'attente avec ctrl+enter
  • Correction de /login dans une session --bare exécutant une connexion que la session ne lit jamais, ce qui pourrait remplacer votre connexion enregistrée ; il indique maintenant quelles informations d'identification fonctionnent
  • Correction du hook InstructionsLoaded omettant agent_id et agent_type lorsque l'accès au fichier d'un sous-agent charge une règle ou un CLAUDE.md imbriqué ; les règles et les fichiers CLAUDE.md imbriqués chargés lors de l'accès aux fichiers signalent désormais également l'effort
  • Correction de l'outil Agent dans claude mcp serve ne signalant toujours aucun agent disponible et rejetant chaque type de sous-agent
  • Correction du curseur du terminal ne suivant pas le texte saisi dans la recherche de la visionneuse de transcription plein écran et dans la recherche de couleurs personnalisées de /theme
  • Correction de /permissions en mode lecteur d'écran : taper le numéro d'une règle la sélectionne désormais au lieu d'ouvrir le champ de recherche
  • Mode automatique amélioré : lorsqu'une conversation devient trop longue pour que le classificateur de sécurité côté client puisse l'examiner, elle est désormais compactée au lieu de demander ou d'échouer à chaque appel d'outil.
  • Mode lecteur d'écran amélioré : les annonces courtes, comme un mot supprimé, restent désormais à l'écran jusqu'à votre prochaine pression sur une touche ou jusqu'à ce que quelque chose au-dessus d'elles change à l'écran.
  • Mode lecteur d'écran amélioré : les questions répondues dans les boîtes de dialogue de questions indiquent désormais "répondu" à côté de leur case
  • Amélioration du message /usage-credits affiché aux membres de l'équipe et de l'entreprise dont l'organisation a désactivé les demandes de crédit d'utilisation
  • Sessions cloud améliorées : le premier tour d'une nouvelle conversation n'attend plus un serveur MCP stdio dont la configuration définit alwaysLoad: false
  • Notes améliorées "Vous devriez savoir" pour dire "nous", "l'agent principal" ou "vous" selon qui était responsable d'une décision
  • Amélioration de l'erreur d'écriture refusée dans une base de données d'artefacts à la limite de taille de la base de données : elle indique désormais la limite et ce qui libère de l'espace.
  • Amélioration des invites d'autorisation Bash pour donner une raison plus courte lorsqu'une partie d'une commande ne peut pas être vérifiée avant son exécution
  • Exécuteur auto-hébergé : amélioration du gh api intégré : une commande gh refusée imprime désormais son équivalent gh api, --paginate suit chaque page des listes d'un référentiel et un claude imbriqué ne le supprime plus
  • Amélioration de la récupération de Remote Control à partir d'un identifiant de serveur expiré : les sessions restent connectées pendant le renouvellement et sont conservées en cas d'abandon après une panne de serveur
  • Modification de la limite de temps des commandes en arrière-plan pour qu'elle s'applique uniquement aux sessions sans surveillance (-p, Agent SDK, CI, cloud) ; Les sessions de terminal, d'application de bureau et VS Code n'ont pas de limite
  • Modification du classificateur de mode automatique côté client pour ignorer une broche ANTHROPIC_DEFAULT_SONNET_MODEL qui nomme Claude Sonnet 5.5 ou Opus 5.5 et utiliser Claude Sonnet 5 à la place
  • Changement de claude project purge en claude purge ; l'ancien nom fonctionne toujours et imprime un avis
  • Modification du filtre n: de la vue des agents (et de la recherche Ctrl+F) afin que Entrée ouvre la session dont le nom correspond le mieux au lieu de la ligne du haut
  • Modification de /autocompact pour enregistrer la fenêtre de compactage automatique par modèle, afin que chaque modèle conserve son propre paramètre lorsque vous changez
  • Modification des invites d'URL MCP des serveurs qui ne peuvent pas signaler lorsque vous avez terminé d'attendre "J'ai terminé, continuez" avant que l'appel de l'outil ne continue, afin que vous puissiez d'abord terminer dans le navigateur.
  • [VSCode] Correction d'un connecteur claude.ai restant sur "Authentification nécessaire" après l'avoir autorisé : la boîte de dialogue des serveurs MCP propose désormais Vérifier la connexion
  • [VSCode] Correction du raccourci optionnel Nouvelle conversation (Cmd/Ctrl+N) démarrant une conversation dans chaque vue Claude visible au lieu de seulement celle dans laquelle vous vous trouvez
  • [VSCode] Correction de la vue de discussion reprenant la prochaine session enregistrée après avoir archivé celle qu'elle affiche ; il démarre maintenant une nouvelle conversation
  • [Sessions Cloud] Correction du commutateur de sessions Cloud dans les paramètres d'administration de Claude Code qui restait verrouillé pendant le chargement ou l'échec du chargement d'un paramètre de sécurité sans rapport.
  • [Sessions Cloud] Correction du fait d'appuyer sur Stop alors qu'un coureur auto-hébergé démarrait encore, n'annulant pas le message en file d'attente, qui pouvait ensuite s'exécuter une fois que le coureur était debout
  • [Claude Tag] Correction des paramètres d'administration de Claude Tag offrant une option "Supprimer cette étendue", qui échouait toujours, sur les chaînes dont les paramètres étaient créés automatiquement
  • [Claude Tag] Amélioration de Claude pour qu'il suive également un fil de discussion Slack associé dans une autre chaîne qu'il ne fait que lire, afin que les mises à jour atteignent la conversation qui en dépend
  • [Claude Tag] Amélioration des erreurs de sauvegarde sur la page Configurer d'un canal : des instructions de canal trop longues disent désormais de les raccourcir, et une sauvegarde refusée pour accès perdu ne dit plus de réessayer
  • Correction des mods de rapport claude plugin test comme étant désactivés à distance lorsqu'il avait seulement lu un paramètre enregistré obsolète
