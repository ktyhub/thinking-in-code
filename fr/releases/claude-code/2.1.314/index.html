claude-code v2.1.314

Correctif Publié30 oct. 2026 Sourceanthropics/claude-code Anglais original

Cette page est traduite automatiquement. Le texte anglais original fait foi.

code-claude v2.1.314

Qu'est-ce qui a changé

  • Ajout de permissions.blockWritesOutsideWorkingDirectories : Write, Edit et NotebookEdit refusent les chemins en dehors des répertoires de travail dans tous les modes d'autorisation
  • Ajout d'une liste facultative groups à la passerelle des applications Claude en amont : seuls les développeurs des groupes IdP répertoriés y sont envoyés en amont, également en cas de basculement
  • Ajout de guardrail_trace à la passerelle des applications Claude Bedrock en amont, pour enregistrer quel filtre de garde-corps Amazon Bedrock s'est déclenché sur une demande, sans le texte correspondant
  • Ajout du compactage inactif à VS Code et à l'onglet Code de Claude Desktop : une conversation de plus de 200 000 jetons laissée inactive est résumée et le résumé est utilisé dans votre prochain message si le cache d'invite a expiré.
  • Correction des sessions qui échouaient tour après tour avec "Niveau d'effort invalide" lorsque l'administrateur d'une organisation plafonnait l'effort d'un modèle : Claude Code réduit désormais l'effort, réessaye et indique le niveau qu'il utilise.
  • Correction de claude -p sortant avec le code 0 et aucune sortie en cas d'échec du démarrage ; il imprime maintenant l'erreur et quitte 1
  • Correction des sessions Bedrock avec de nombreuses images échouant à chaque tour et /compact avec "400 Entrées trop longues". au lieu de supprimer les anciennes images et de les compacter
  • Correction des sessions Microsoft Foundry échouant lorsque la ressource n'a pas de déploiement pour le modèle Sonnet, Opus ou Haiku par défaut : Claude Code revient désormais à un ancien modèle de cette famille
  • Correction des requêtes refusées répétées derrière une passerelle qui n'accepte pas les blocs tool_reference de la recherche d'outils : la requête est renvoyée une fois sans recherche d'outil, et la session se souvient
  • Correction de l'échec des connexions TLS avec UNABLE_TO_GET_ISSUER_CERT lorsque le magasin de certificats système détient un certificat racine renouvelé qui est signé de manière croisée avec son prédécesseur.
  • Correction des serveurs MCP qui fonctionnent également sans connexion affichant « nécessite une authentification » après que leur connexion stockée a cessé de fonctionner ; ils sont maintenant utilisés déconnectés
  • Correction du succès du rapport claude mcp logout lorsque la connexion MCP n'était pas supprimée, par exemple lorsque le trousseau macOS est verrouillé via SSH
  • Correction des renouvellements de connexion supplémentaires lorsque plusieurs sessions partagent une connexion de profil Anthropic et que le verrouillage des informations d'identification est occupé
  • Correction de claude ultrareview et claude remote-control posant la question trust de l'espace de travail dans un travail CI doté d'un terminal ; avec CI défini, ils refusent désormais immédiatement un dossier non rusted
  • Correction des paramètres TLS trust d'un administrateur dans les paramètres gérés qui n'étaient pas appliqués dans les sessions Claude Desktop
  • Correction du changement de modèle refusé sur les machines avec des paramètres de plugin gérés lorsque l'un de vos propres plugins --plugin-dir ou --plugin-url avait un manifeste brisé ou ne pouvait pas être téléchargé.
  • Correction de l'offre de mise à niveau des modèles Bedrock et Vertex qui revenait à chaque démarrage lorsque les paramètres gérés épinglent le modèle
  • Correction de forceRemoteSettingsRefresh défini uniquement dans les paramètres gérés à distance ne s'appliquant plus une fois la copie stockée expirée, ce qui permettait aux sessions de démarrer sans politique lorsque le serveur ne pouvait pas être atteint
  • Correction de "Continuer automatiquement à la limite d'utilisation" se poursuivant plus de trois fois sans invite de votre part lorsqu'une tâche redémarrait d'elle-même entre les attentes (un enregistrement / goal, une tâche en arrière-plan ou planifiée)
  • Correction des sessions en arrière-plan et cloud démarrées avec Ultracode le réactivant à son prochain démarrage après avoir été éteint
  • Correction de la dernière réponse interrompue et de ses invites de nouvelle tentative restant dans la conversation après que Claude ait abandonné un appel d'outil qui n'a pas pu être analysé
  • Correction d'un crochet PreCompact avec un rendement très important qui faisait échouer ou répéter le compactage ; la sortie de chaque hook est désormais réduite à 10 000 caractères
  • Correction de l'actualisation des différences en arrière-plan prenant brièvement le verrouillage de l'index du référentiel, ce qui pouvait faire échouer une commande git exécutée au même moment avec "Impossible de créer '.git/index.lock' : le fichier existe"
  • Correction des tableaux de démarques sautant entre les mises en page en grille et empilées sur des lignes à moitié tapées pendant la diffusion, et les longs tableaux retombant sur des tuyaux bruts
  • Correction du sélecteur /resume affichant le texte de CLAUDE.md ou CLAUDE.local.md comme titre d'une session lorsque la session exécutait uniquement des commandes slash
  • Correction de /btw répondant à partir de la conversation principale lorsqu'on lui demandait depuis la transcription ouverte d'un sous-agent
  • Correction du collage d'une image via SSH sur une machine Linux ne faisant rien en silence ; l'invite indique maintenant de copier le fichier et de coller son chemin
  • Correction des sessions claude remote-control qui ne parvenaient pas à démarrer lorsque le service de session était lent pendant un moment : l'enregistrement du travailleur est désormais retenté avec des attentes croissantes
  • Correction du modèle qui passe à la télécommande et qui prend plus de 8 secondes pour obtenir une erreur "toujours en attente" au lieu du résultat final
  • Correction de la description du paramètre sandbox.excludedCommands indiquant que les commandes répertoriées s'exécutent toujours en dehors du bac à sable ; il dit maintenant que chaque commande d'un appel doit correspondre à une entrée
  • Correction des appels shell et MCP qui bloquaient le mode automatique, une règle de refus ou un hook PreToolUse, ou qui ne fonctionnaient pas autrement, se lisant comme s'ils s'exécutaient dans un groupe d'outils réduit.
  • Correction des protections sandbox ne s'appliquant pas à un arbre de travail entré par claude -p --resume ou --continue
  • Correction des hooks correspondant à Bash qui ne s'exécutaient pas sur les commandes shell lancées par l'outil Monitor ; ces hooks peuvent bloquer ou demander, mais pas approuver ou réécrire ces commandes
  • Correction d'un fichier de paramètres exclu avec --setting-sources fournissant toujours certains paramètres, tels que les règles du mode automatique et les consentements d'autorisation enregistrés
  • Correction du mode automatique signalant un appel comme bloqué et le répertoriant dans /permissions, lorsque son contrôle de sécurité ne donnait aucun verdict
  • Correction d'un blocage en amont de la passerelle d'applications Claude Vertex pendant quelques minutes lorsqu'un point de terminaison de jeton Google accepte la connexion et ne répond jamais
  • Correction de l'avertissement de démarrage de la passerelle des applications Claude pour une clé Claude Desktop obsolète indiquant qu'elle sert toujours comme écrit en disant "cesse d'être acceptée" après la date de fin de la clé
  • Correction de /upgrade ouvrant le navigateur et démarrant une nouvelle connexion pour les forfaits facturés via l'App Store ou Google Play ; il dit maintenant où changer le plan
  • Correction de --resume, et retour en arrière après un passage à un autre modèle après un refus, déplacement d'une session sur un nom de modèle que Claude Code ne reconnaît pas vers un autre modèle
  • Correction des requêtes échouant lorsqu'une passerelle ou un fournisseur cloud refuse nommément l'un des en-têtes bêta de Claude Code : la requête est renvoyée sans celui-ci
  • Correction des identifiants de modèle orthographiés avec un point derrière une passerelle LLM, tels que claude-opus-4.8, étant traités comme un modèle plus ancien avec une fenêtre de contexte, une limite de sortie, un effort, un mode de réflexion et un coût incorrects.
  • Correction de la télécommande clients affichant une ligne parasite "Compacté (ctrl+o pour voir le résumé complet)" après /compact
  • Correction de l'astuce des sessions cloud et de l'avis d'inactivité du contrôle à distance indiquant lorsque la politique d'une organisation désactive ces fonctionnalités
  • Correction d'une reprise de la session cloud claude.ai effectuant un appel modèle que personne n'a demandé lorsque le travailleur précédent s'est arrêté juste après avoir reçu les fichiers d'un nouveau chat
  • Correction de WebFetch dans les sessions cloud Cowork, laissant tomber silencieusement le texte d'un PDF au-delà de 100 000 caractères ; il indique maintenant combien de choses n'ont pas été lues et où continuer à lire
  • Correction du message indiquant à Claude qu'une commande avait été supprimée après que vous l'ayez arrêtée avec Esc ou Stop dans une session cloud ou dans l'EDI ; il entend maintenant également que la commande a peut-être été exécutée
  • Correction des lignes vides en haut d'un bloc de code disparaissant lorsque le bloc de code ouvre un devis
  • Correction d'une ligne vide apparaissant au-dessus de certaines lignes ⎿ dans la vue transcription (Ctrl+O)
  • Correction du mode vim dw, dW, yw et yW continuant au-delà de la fin de la ligne, et arrêt de w et W sur des lignes vides
  • Correction de x et Entrée dans le panneau de l'agent agissant parfois sur le mauvais agent lorsqu'un autre agent commençait ou terminait
  • Correction du texte collé et des fichiers glissés perdus dans la boîte de dialogue de questions de Claude à moins que la ligne "Autre" n'ait le focus
  • Correction du texte collé étant perdu lorsqu'une ligne dans le pied de page de l'invite était sélectionnée
  • Correction du mode vim p sur une sélection de caractères ignorant si le texte extrait était constitué de lignes entières
  • Correction des modes vim aw et iw prenant le saut de ligne en fin de ligne
  • Correction de la sélection des éléments de pied de page masqués par le ? le menu d'aide, la liste des commandes ou une astuce de collage
  • Correction de l'Esc sur le panneau de commande, tel que /btw, interrompant également le sous-agent dont la transcription est ouverte
  • Correction de l'en-tête de bienvenue en mode plein écran affichant le modèle de la session lors de l'affichage d'un sous-agent ou d'un coéquipier qui s'exécute sur un modèle différent
  • Correction de la transcription en plein écran qui restait au milieu de la conversation après "Restaurer la conversation" dans le menu de rembobinage lors du défilement vers le haut
  • Correction d'un cas rare où une session supprimée pouvait réapparaître dans la liste de reprise sous la forme d'une entrée presque vide
  • Correction des invites contenant des balises telles que <bash-stdout> ou <local-command-stdout> qui n'étaient pas reconnues par un hôte local stream-json
  • Correction des sessions restant sans titre lorsque la première invite échouait (par exemple sur une limite d'utilisation) et que la conversation se poursuivait par la suite
  • Correction de l'observateur de fichiers de compétences vérifiant chaque compétence supprimée conservée dans ~/.claude/skills/.trash, ce qui ajoutait une charge au système de fichiers qui augmentait à chaque suppression.
  • Correction du nom de session de /rename disparaissant lorsque Claude demande la permission ou une décision de plan, afin que les sessions côte à côte restent identifiables
  • Correction des sessions en arrière-plan qui ne parvenaient pas à être signalées comme binaire de démon supprimé lorsque le binaire est toujours sur le disque
  • Correction de l'astuce et du rappel d'inactivité concernant les notifications push apparaissant lorsque les paramètres push dans /config sont masqués ou que votre organisation a désactivé le contrôle à distance.
  • Correction de la croissance sans limite de ~/.claude/skills/.trash et ~/.claude/plugins/.trash : chacun contient désormais environ 1024 entrées, quoi que dise cleanupPeriodDays
  • Correction du diff d'édition Bash répertoriant un fichier entier comme modifié lorsqu'un fichier CRLF sous la conversion de fin de ligne de git était réenregistré sans modification ou qu'une ligne était modifiée
  • Coureur auto-hébergé : correction d'une session inactive se déplaçant vers un autre coureur au lieu de faire une pause lorsque la demande de pause du coureur perdait sa connexion avant qu'Anthropic ne réponde
  • Utilisation améliorée de la mémoire dans les longs tours sans tête et SDK qui exécutent de nombreux sous-agents : la session parent ne conserve plus les résultats d'outil de chaque sous-agent jusqu'à la fin du tour
  • Historique des invites amélioré : Ctrl+R fait désormais correspondre le texte à l'intérieur des pilules [Pasted text] réduites
  • Amélioration de l'invite de téléchargement du /design-sync pour afficher le dossier, le projet et les fichiers qu'il va télécharger ou supprimer
  • Onglet de révision /permissions amélioré, désormais appelé Récemment bloqué : le pied de page indique ce que Esc fera avec les lignes marquées
  • Amélioration des appels bloqués en mode automatique : les messages nomment la commande, disent que Claude peut réessayer et le mode automatique vérifie à nouveau, et pointent vers /permissions pour vérifier
  • Invites d'autorisation améliorées : un motif long prend moins de lignes, ce qui fait sortir la commande en cours d'approbation de l'écran sur moins de terminaux
  • Amélioration de l'erreur de session cloud affichée lorsqu'une demande refusée pour votre connexion claude.ai est toujours en cours de tentative : elle suggère désormais également claude auth login
  • Amélioration du comportement des connexions claude.ai, Team et Enterprise stockées lorsque les paramètres MDM et distants diffèrent sur l'URL de base ou apiKeyHelper
  • Amélioration de /config dans la vue agent pour indiquer comment arrêter l'ouverture de la vue agent par défaut
  • Titres automatiques de session améliorés : une session qui commence par une compétence ou une commande basée sur une invite telle que /security-review en obtient désormais un titre au lieu de rester sans titre
  • Amélioration de la vitesse du --resume et de l'utilisation de la mémoire sur les transcriptions endommagées
  • Amélioration de la vitesse du /context dans les sessions avec dix mille outils MCP ou plus
  • Exécuteur auto-hébergé : amélioration de l'erreur affichée lorsque la branche d'une session n'est pas sur la télécommande git : elle couvre désormais une branche jamais poussée, indique comment résoudre chaque cas et ne suggère plus de réessayer
  • Mise à jour de la compétence /claude-api : sa configuration Datadog pour le traçage API envoie désormais l'en-tête dd-llmobs-enabled: true, comme le fait la console, et ses instructions d'installation ant suppriment l'étape obsolète macOS xattr
  • Mise à jour de la compétence de visualisation de données intégrée pour conseiller d'imprimer les étiquettes de graduation sur l'axe Y au complet en dessous de 10 000 et les étiquettes horizontales au complet en dessous d'un million là où elles correspondent
  • Mise à jour de la compétence de visualisation de données intégrée pour répondre aux demandes de diagrammes en forme de beignet et de camembert avec des barres classées ou une barre segmentée qui imprime ses valeurs
  • Modification des outils de fichiers de Claude pour qu'ils demandent avant de modifier la copie locale des paramètres gérés par le serveur de votre organisation, comme c'est le cas pour vos fichiers de paramètres.
  • Modification de /ultrareview pour vérifier l'espace de travail trust avant d'exécuter git, comme le fait claude ultrareview
  • Modification du shell de l'outil Bash pour effacer tout alias ou fonction which hérité et pour arrêter de transmettre les fonctions which/unsetenv exportées aux commandes, donc which est la commande système ou zsh intégré
  • Modification de /permissions Récemment bloqué pour refuser d'approuver un appel que vous ne pouvez pas lire en entier, y compris un appel que le terminal est trop court pour afficher
  • Modification du mode automatique dans les sessions cloud Cowork : l'autorisation d'un hook pour un appel à un outil MCP compte désormais comme une non-réponse, donc le classificateur ou une invite d'autorisation décide
  • Modification des conditions du hook if telles que Monitor(tail *) pour correspondre aux commandes shell de l'outil Monitor, car Bash(tail *) correspond à celles de Bash.
  • Modification de la compétence claude-api pour demander de lire le flux de travail d'une exécution de workflow d'agents gérés avant de modifier l'agent afin d'améliorer cette exécution.
  • Modification des demandes signalées pour réessayer sur un autre modèle, ne se terminant pas par un refus, lorsque ANTHROPIC_DEFAULT_OPUS_MODEL, availableModels ou deniedModels ne quittent qu'un ancien modèle Opus, ou aucun
  • Modification du compactage inactif pour qu'il s'exécute également pour les abonnés dont la télémétrie est désactivée et sur les passerelles Bedrock, Vertex, Foundry et LLM une fois le cache d'invite d'une heure activé.
  • Modification de FORCE_HYPERLINK=false (également no et off) pour désactiver les hyperliens au lieu de les activer
  • macOS : modification de git grep dans la plupart des commandes exécutées par Claude pour utiliser la locale C, afin d'éviter une fuite de mémoire signalée dans la bibliothèque regex de macOS sur des fichiers qui ne sont pas UTF-8 valides
  • [VSCode] Correction de "Effacer l'authentification" pour les serveurs MCP signalant le succès lorsque la connexion enregistrée ne pouvait pas être supprimée
  • [VSCode] Correction du spinner manquant et du bouton Stop pendant l'exécution des hooks d'un message en file d'attente
  • [VSCode] Correction des modifications du groupe de session qui ne peuvent pas être enregistrées, telles qu'une suppression, échouant silencieusement ; une notification d'erreur apparaît maintenant
  • [VSCode] Correction de Cmd+F / Ctrl+F n'ouvrant pas le widget de recherche dans l'onglet d'aperçu du plan
  • [VSCode] Correction du raccourci de dictée vocale (Ctrl+D) qui ne faisait rien sous les claviers non latins tels que le russe, le grec ou l'hébreu.
  • [VSCode] Correction des tâches planifiées enregistrées une fois manquées et supprimées sans demander quand l'extension s'ouvrait sans chat
  • [VSCode] Modification de CLAUDE_CODE_DISABLE_CFC_PROMPT pour arrêter également l'extension ajoutant les instructions Claude dans Chrome aux messages d'une session ; les outils du navigateur restent disponibles
  • [Sessions Cloud] Ajout d'un bouton Inclure les tâches terminées à la page Tâches planifiées lorsque les tâches ponctuelles terminées sont les seules masquées, afin que vous puissiez les afficher sans ouvrir le menu Trier.
  • [Sessions Cloud] Correction des environnements auto-hébergés récemment utilisés n'apparaissant jamais parmi les environnements récents sur la nouvelle carte de session
  • [Sessions cloud] Correction des sessions cloud signalant des modifications non validées à chaque tour après que Claude ait déplacé une branche vers une validation qu'elle avait poussée depuis un autre arbre de travail.
  • [Sessions cloud] Correction de la boîte de dialogue des détails de l'environnement auto-hébergé dans les paramètres d'administration, rendant son contenu invisible dans des fenêtres très courtes ou avec un zoom élevé ; la boîte de dialogue défile maintenant
  • [Sessions cloud] Correction du sélecteur de mode d'autorisation restant sur Auto après qu'une session cloud ou de contrôle à distance en cours d'exécution ait refusé le changement ; il affiche maintenant le mode utilisé et vous indique
  • [Sessions Cloud] Tâches planifiées améliorées : les exécutions dans le cloud d'Anthropic chargent désormais les plugins activés sur votre compte claude.ai -[Sessions cloud] Connexion de test améliorée pour GitHub Enterprise dans les paramètres d'administration pour vous connecter également comme le font les sessions cloud et pour vous avertir lorsque ce deuxième test échoue
  • [Sessions cloud] Transcriptions de sessions cloud améliorées : une ligne de renommage nomme désormais le nouveau titre, et les listes de référentiels et d'environnements s'affichent sous forme de tableau au lieu d'une seule ligne de JSON. -[Sessions cloud] Modification des sessions cloud des applications Web, de bureau et mobiles pour qu'elles démarrent même lorsqu'un script de configuration se termine avec une erreur, au lieu d'échouer.
  • [Télécommande] Correction du bouton de mode d'autorisation dans les sessions de contrôle à distance affichant le mauvais mode jusqu'à ce que vous tapiez ; pendant que votre ordinateur est en ligne, il affiche maintenant le mode réel à l'ouverture
  • [Claude Tag] Ajout d'un lien pouvant être ignoré vers les documents Claude Tag API dans les onglets Bundles et Canaux dans les paramètres d'administration, pour les organisations d'entreprise avec Slack connectées.
  • [Claude Tag] Correction de l'abandon de @Claude !restart après un échec de vérification d'espace de travail dans les canaux partagés entre les espaces de travail Enterprise Grid ; il réessaye maintenant, puis vous demande de le réexécuter
  • [Claude Tag] Correction d'un deuxième DM de confirmation et d'une note de chaîne lorsque vous connectez votre compte Claude depuis Slack deux fois à partir du même lien en quelques minutes
  • [Claude Tag] Correction des messages de suivi dans Slack ne montrant aucun signe de progression pendant que la session de Claude attend un coureur auto-hébergé ; Claude publie maintenant un avis d'attente dans le fil de discussion
  • [Claude Tag] Correction de Claude qui ne répondait parfois pas à un tag dans son propre fil de discussion dans les canaux Slack Connect où les deux organisations ont installé Claude
  • [Claude Tag] Correction d'une nouvelle tentative sur les pages de plugins et de compétences dans les paramètres d'administration de Claude Tag, supprimant les modifications d'accès non enregistrées après un échec de chargement ; vos modifications restent désormais en place
  • [Claude Tag] Correction du contrôle des référentiels dans les paramètres d'administration de Claude Tag affichant deux fois la même action ; son menu répertorie désormais uniquement ce que le bouton ne fait pas déjà
