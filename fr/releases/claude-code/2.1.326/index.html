Qu'est-ce qui a changé

  • Ajout de la prise en charge de l'activation du mode Code lorsque les équipes d'agents sont activées ; si vous l'avez déjà activé, les sessions avec les équipes activées démarrent désormais en mode Code
  • Ajout d'un avertissement de démarrage lorsqu'une valeur --allowedTools, --disallowedTools ou --tools a une entrée qui ne ressemble pas à une règle complète

  • Ajout de Ctrl+O pour afficher les notifications de démarrage masquées
  • Ajout d'un indice dans l'invite vide indiquant quoi faire après l'échec d'une requête
  • Ajout d'un indice de pied de page esc to stop dans la vue d'un sous-agent où Esc l'arrêterait
  • Ajout de OTEL_RESOURCE_INCLUDE_HOST pour inclure host.name et host.id dans les attributs de ressources OpenTelemetry (désactivé par défaut)
  • Ajout de overflowX="scroll" sur le Box d'un mod, et maxLines et wrap="clip" sur son Text

  • Modification de l'outil PowerShell pour demander avant quelques commandes supplémentaires ; les exécutions sans surveillance les refusent à moins qu'une règle d'autorisation, un mode automatique ou un mode de contournement des autorisations ne les autorise
  • Modification de l'outil PowerShell pour demander des commandes supplémentaires, même en mode contourner les autorisations, et en refuser certaines
  • Modification de certaines commandes PowerShell mal formées pour qu'elles soient refusées
  • Modification de certaines commandes de l'outil PowerShell qui définissent une fonction nommée comme une commande intégrée à refuser, afin que Claude puisse la renommer
  • Modification du mode automatique pour ignorer certaines règles d'autorisation du shell générique, telles que celles qui ne nomment aucun programme ou qui commencent par $HOME, afin que le contrôle de sécurité décide de ces commandes.
  • Modification du mode automatique pour évaluer les règles d'autorisation générique dont le programme est un chemin de barre oblique inverse de Windows, afin que ces appels puissent être bloqués ; les règles exactes gardent leur permis ; nous prévoyons de restaurer les règles commençant par .\
  • Modification d'une liste autoMode.environment gérée sans "$defaults" pour remplacer également chaque entrée intégrée dans les applications Claude Desktop et Agent SDK ; ajoutez "$defaults" ou copiez les cibles sensibles
  • Modification de --add-dir et /add-dir dans les sessions de terminal local pour afficher l'invite trust pour un dossier que vous n'avez pas encore utilisé avec trust ; claude --bg refuse un tel dossier
  • Modification des coureurs auto-hébergés sous --trust-workspace false pour ignorer davantage de paramètres de référentiel ; définir de telles valeurs dans les paramètres utilisateur ou gérés
  • Modification de la façon dont les réponses aux autorisations via le contrôle à distance et sur les coureurs auto-hébergés enregistrent les choix "Toujours autoriser"
  • Modification des plugins activés qui étaient refusés pour un champ d'affichage plugin.json malformé : ils se chargent désormais, avec leurs hooks et serveurs MCP ; les administrateurs doivent vérifier les plugins qu'ils déploient
  • Modification de la façon dont allowedHttpHookUrls et httpHookAllowedEnvVars s'appliquent aux hooks à partir des paramètres gérés
  • Modification des hooks HTTP pour ignorer Content-Length et Transfer-Encoding dans leur paramètre headers ; la longueur de la requête vient de son corps
  • Modification de la désinstallation du plugin pour supprimer également les fichiers extraits des bundles MCP du plugin (.mcpb, .dxt), sauf si un autre plugin utilise le même bundle
  • Modification de certaines sessions d'arbre de travail pour ignorer certains paramètres du plugin ; un avis nomme ce qui a été ignoré
  • Modification de la désinstallation de /plugin, de la suppression et du basculement des questions vers les listes répondues avec les touches fléchées et Entrée, ou Echap pour annuler ; y, n et u n'y répondent plus
  • Modification du compactage automatique en mode plan pour utiliser le modèle qui vous répond, comme Opus avec opusplan, donc ça peut coûter plus cher
  • Modification des sessions cloud Cowork pour conserver l'exportation OpenTelemetry d'une organisation jusqu'au premier tour ; une session qui ne reçoit aucun message n'envoie plus rien, donc claude_code.session.count peut tomber
  • Modification des messages de Claude vers une session sur une autre machine pour qu'ils soient refusés lorsque votre session utilise une clé API, un jeton d'authentification, un profil ou une identité de charge de travail à côté d'une connexion claude.ai enregistrée
  • Modification des sessions --bare sur une clé API non approuvée : en déplacer une en arrière-plan est désormais refusé dans la plupart des configurations, et claude --bare --bg se termine avec une erreur si le service en arrière-plan n'a pas la clé
  • Modification de "Continuer automatiquement à la limite d'utilisation" pour arrêter avec un avis, sans rien envoyer, lorsque votre connexion change ou se termine pendant l'attente
  • Contrôle à distance : modification de la façon dont il se connecte via un proxy : les requêtes utilisent désormais un tunnel CONNECT, donc un proxy qui refuse CONNECT arrête le contrôle à distance avec une erreur
  • Contrôle à distance : Modification des journaux de débogage de session écrits sous --verbose pour passer à ~/.claude/child-logs/
  • Exécuteur auto-hébergé : modifications des sessions Linux et macOS sans gh pour obtenir un gh api intégré par défaut, via Anthropic, qui ajoute leur connexion GitHub, le cas échéant ; --use-anthropic-gh false l'éteint
  • Modification de la vue de l'agent afin que quitter avec Ctrl+C deux fois, Ctrl+D deux fois ou /exit après avoir appuyé sur ← dans une conversation vide mette fin à cette session, au lieu de la laisser fonctionner pendant 5 minutes.
  • Modification de --await-initialize pour qu'il soit refusé par --bg ou --worktree --tmux, qui ne lisent jamais la requête d'initialisation, au lieu de démarrer sans les champs qu'elle transporte
  • Modification de la création de l'arbre de travail, des extractions /teleport et IDE pour exécuter git avec un PATH plus strict ; un filtre ou un assistant git peut avoir besoin de son chemin complet
  • Modification de la carte d'approbation du plan d'un sous-agent en deux choix, "Oui, et passer à la valeur par défaut (demander à chaque fois) pour cette session" et "Non", choisis avec les touches fléchées et Entrée (le texte saisi se déplace vers Non)
  • Modification de la compétence /claude-api pour créer des agents sur des agents gérés par défaut, sauf si vous souhaitez héberger vous-même la boucle d'agent
  • Modification du /usage en mode plein écran pour afficher les barres de limite du plan avant le coût de la session pour les abonnés ; /cost démarre toujours avec le coût
  • Modification du libellé de certains messages imprimés par les sous-commandes claude ; La sortie du JSON est inchangée
  • Modification de la configuration de première exécution pour présélectionner le thème "Auto (match terminal)" au lieu du mode sombre
  • Modification du mode plein écran /cd pour refuser "Oui" alors que son invite trust ne rentre pas, avec une ligne disant d'agrandir la fenêtre
  • Suppression de la notification tmux indiquant que la molette de la souris a besoin de set -g mouse on en plein écran ; la roue défile sans elle
  • Suppression de la pointe du spinner qui suggérait /clear 30 minutes après un virage en cours
  • [VSCode] Ajout d'un paramètre claudeCode.promptSuggestions qui désactive les suggestions d'invite
  • [VSCode] Correction de "Rewind code to here" dans une conversation fourchue, annulant parfois un tour de trop et supprimant les fichiers créés à ce tour
  • [VSCode] Correction de la boîte de dialogue Sandbox créant des fichiers et des dossiers vides dans le répertoire personnel et le dossier .git du projet lorsque le bac à sable est désactivé
  • [VSCode] Correction de la perte de connexion enregistrée sur certains réseaux
  • [VSCode] Correction de la fin de la connexion lorsqu'un code de vérification, une adresse Web ou un code provenant d'une autre tentative de connexion est collé ; le panneau indique maintenant quoi coller à la place
  • [VSCode] Correction de l'écran de connexion affichant brièvement chaque fois qu'un panneau ou une fenêtre s'ouvrait alors que vous étiez connecté à la console sans clé API.
  • [VSCode] Correction du bouton "Demander plus" de la bannière de limite d'utilisation pour les membres de l'équipe et de l'entreprise revenant après chaque appui sans rien envoyer, après vous être reconnecté au cours d'une session
  • [VSCode] Correction de /ide dans une deuxième session Claude Code, perdant silencieusement la connexion de l'éditeur à la première session ; la connexion la plus récente l'emporte désormais et la session déplacée montre comment revenir en arrière
  • [VSCode] Correction des mémoires enregistrées n'étant pas répertoriées dans la boîte de dialogue Mémoire, ou de l'utilisation de la RAM croissante sans fin, lorsque le dossier mémoire contenait des boucles de liens symboliques, et d'un blocage lorsqu'il contenait un canal nommé
  • [VSCode] Correction de la sortie en direct d'une commande en cours d'exécution s'arrêtant après un échec de lecture
  • [VSCode] Correction de "Ouvrir dans le terminal" affichant uniquement l'erreur du shell lorsque claude ne pouvait pas être démarré : dans bash, zsh, fish et Git Bash, une notification explique désormais pourquoi et des liens vers le guide d'installation
  • [VSCode] Correction du panneau n'affichant aucun lien "Ouvrir l'artefact" après que Claude ait publié un artefact
  • [VSCode] Correction de la suggestion d'invite masquant l'indice « Joindre le texte sélectionné » lorsque le panneau de discussion n'est pas ciblé.
  • [VSCode] Correction des boutons sans bordure visible dans les thèmes à contraste élevé et de l'illustration de bienvenue sombre sur l'écran de connexion en Light High Contrast
  • [VSCode] Vitesse d'édition et d'écriture améliorée : pas d'attente pour de nouveaux problèmes sur les fichiers qui ne sont pas ouverts dans un onglet lorsque l'éditeur n'en a signalé aucun pour ces fichiers
  • [VSCode] Modification de la sortie en direct d'une commande en cours d'exécution dans le chat pour qu'elle ressemble à la ligne OUT de la carte de commande
  • [VSCode] Modification du texte des erreurs d'extension dans les écouteurs d'événements, les vues et l'activation pour rester en dehors de la télémétrie des erreurs de l'éditeur.
