claude-code v2.1.321

Correctif Publié9 nov. 2026 Sourceanthropics/claude-code Anglais original

Cette page est traduite automatiquement. Le texte anglais original fait foi.

code-claude v2.1.321

Qu'est-ce qui a changé

  • Ajout de Claude Fable 5.2 (claude-fable-5-2), désormais le modèle Fable par défaut — contexte 1M, 8 $/40 $ par Mtok avec lectures de cache $0.20/Mtok
  • Ajout de --settings <file> à claude remote-control, qui applique un fichier de paramètres à chaque session démarrée ; si le fichier change, aucune nouvelle session ne démarre jusqu'à ce que vous redémarriez claude remote-control
  • Correction des requêtes MCP OAuth envoyant des secrets tels que des jetons d'actualisation à un autre hôte lorsqu'un serveur les redirigeait
  • Correction d'un cas où une commande Bash en lecture seule s'exécutait en dehors du bac à sable sans invite d'autorisation
  • Correction d'un cas où les contrôles d'autorisation Bash jugeaient l'écriture d'un fichier à partir du mauvais dossier et ne provoquaient pas d'invite.
  • Correction des règles de refus et des invites de fichiers protégés ne s'appliquant pas au fichier qu'un cp ou un mv écrit dans un répertoire
  • Correction de la note « Tirages sur les crédits d'utilisation » qui s'affichait après un passage à Fable sur les sièges Enterprise dont le forfait inclut Fable
  • Correction du modèle de secours déclining une requête ou mentionnant une réponse arrêtée lorsque le premier modèle était bloqué avant de répondre
  • Correction de claude mcp login imprimant un avertissement d'émetteur SEP-2352 à chaque fois que vous vous reconnectez à un serveur sur lequel Claude Code s'est enregistré.
  • Correction de NotebookEdit supprimant ou écrasant la première cellule d'un notebook lorsque l'appel ne nommait aucune cellule, sur les chemins réseau (partages UNC, dossiers WSL, montages /net)
  • Correction de l'édition modifiant la première de plusieurs correspondances, remplaçant un fichier entier sur un old_string vide, ou éditant un bloc-notes sous forme de texte, sur les chemins réseau (partages UNC, dossiers WSL, montages /net)
  • Correction de /config affichant Manuel comme mode d'autorisation par défaut lorsque de nouvelles sessions démarrent en mode automatique ; appuyer sur Espace sur "Auto (par défaut)" enregistre désormais Ne pas demander, pas planifier
  • Windows : correction des hooks FileChanged s'arrêtant pour les chemins définis via watchPaths après la première commande shell, lorsque le répertoire de travail de la session avait une lettre de lecteur minuscule
  • Correction de --plugin-dir . et --plugin-dir ./builtin écrivant les fichiers de type générés pour les plugins intégrés de Claude Code dans un dossier builtin
  • Correction des estimations d'utilisation du contexte surcomptant les définitions d'outils lorsque le nombre exact de jetons n'est pas disponible
  • Correction de /compact affichant deux fois dans Remote Control sur le Web et sur mobile
  • Correction des mises à jour automatiques du plugin et des mises à jour du marché /plugin en téléchargeant à nouveau un plugin pour chaque arbre de travail ou dossier d'un référentiel
  • Correction du mode automatique perdant le rapport d'un sous-agent en arrière-plan qui avait commencé un tour lorsque la conversation était compactée avant que Claude n'y réponde
  • Correction des compétences, commandes et agents du projet restant manquants après la suppression de leur dossier et leur retour en cours de session, comme avec git stash, y compris après avoir entré un arbre de travail
  • Correction de claude -p indiquant parfois à Claude que les commandes en arrière-plan durent 30 minutes lorsqu'elles sont arrêtées après 10 minutes.
  • Correction de pkill, pgrep et pidwait dans les sessions cloud correspondant aux propres processus parents de la session
  • Correction de Claude dans Chrome et les processus du serveur utilisant l'ordinateur restaient en vie après la sortie de leur parent derrière un proxy qui bloquait les connexions
  • Correction d'une grande sortie de hook pointant Claude vers un fichier contenant la sortie d'un autre hook du même appel d'outil
  • Correction des applications qui intègrent Claude Code obtenant la raison ask de leur propre hook PreToolUse au lieu de celle d'un autre hook lorsque les deux le demandent
  • Correction du ask d'un hook PreToolUse étant perdu lorsque le defer d'un autre hook terminait en premier et ne pouvait pas être honoré
  • Correction d'un crash rare sur les invites d'autorisation et les tâches en arrière-plan
  • Correction des compétences de projet, des commandes et des agents disparaissant du menu dans SDK et des sessions de bureau après que Claude soit entré dans un arbre de travail
  • Correction de /desktop sur macOS indiquant que Claude Desktop n'est pas installé alors qu'il est dans ~/Applications
  • Correction des attributs du référentiel OpenTelemetry (vcs.*) manquant dans les sessions Claude Desktop qui démarrent sur un processus pré-démarré
  • Correction de WebFetch transmettant "Aucune réponse du modèle" à Claude comme contenu de la page lorsque le modèle lisant la page ne renvoyait aucun texte ; l'appel échoue maintenant avec une erreur claire
  • Correction du mode lecteur d'écran retardant l'invite au démarrage lorsque l'horloge système reculait pendant le démarrage de Claude Code
  • Correction du panneau d'une commande qui ne revenait parfois pas après la fermeture d'une boîte de dialogue, ne laissant aucun panneau ni invite à l'écran jusqu'à la prochaine refonte
  • Correction du serveur MCP d'un projet étant déconnecté après le premier message dans une session de l'onglet Claude Desktop Code lorsque l'application de bureau dispose d'un serveur MCP ou d'une extension du même nom
  • Correction d'un tour se terminant par « Erreur API : EPROTO : Échec de la négociation TLS » lorsque la connexion était interrompue à mi-chemin d'une réponse ; la réponse partielle est conservée ou la demande est retentée, comme avant 2.1.302
  • Correction d'une utilisation élevée de la mémoire lors de longues sessions qui lisaient à plusieurs reprises des lignes uniques à partir de fichiers volumineux
  • Correction du mode rapide qui perdait les réponses, changeait de modèle ou réessayait pendant quelques minutes lorsque le service rapide était limité, surchargé ou défaillant ; il essaie maintenant d'abord la vitesse standard sur le même modèle
  • Correction d'une requête comportant beaucoup plus de rapports d'agent en arrière-plan que prévu après l'arrêt de Claude alors que plusieurs attendaient
  • Correction des messages d'une session de l'onglet Claude Desktop Code vers vos autres sessions restant en pause après avoir tapé pendant que Claude travaillait encore
  • Correction de claude agents ignorant --permission-mode, --dangerously-skip-permissions, --model, --effort ou --agent tapés avant agents lorsqu'un drapeau tel que --verbose était également sur la ligne
  • Correction d'un cas où le contrôle à distance s'affichait avec « connexion expirée » dans l'application de bureau alors que sa connexion était toujours active, car l'application était brièvement incapable de remettre un jeton de connexion.
  • Correction d'un message de télécommande envoyé avec "File d'attente pour plus tard" atteignant Claude au milieu du tour en cours
  • Correction du statut git donné à Claude au début de la session comme étant propre lorsque le statut git échouait ; il est maintenant indiqué comme indisponible
  • Correction du statut git donné à Claude au début de la session affichant le premier fichier répertorié comme mis en scène lorsque ses modifications n'étaient pas mises en scène
  • Correction d'un blocage ou d'un crash de mémoire insuffisante lorsqu'un connecteur dans une session cloud répertorie les ressources avec des noms très longs
  • Correction de la télécommande affichant comme connectée après la fermeture définitive de sa connexion alors que l'historique de la session était toujours en cours de téléchargement
  • Correction du mode lecteur d'écran qui se désactive lorsque vous revenez à une conversation depuis la vue agent
  • Correction des questions du mode lecteur d'écran o/n prenant pour oui un "y" parasite à la fin du texte tapé à l'ouverture de la question
  • Correction des sessions cloud indiquant à Claude qu'un hôte n'est probablement pas autorisé alors qu'il est autorisé et que le proxy réseau ne pouvait pas s'y connecter
  • Correction d'un serveur MCP apparaissant parfois comme connecté sans outils après sa reconnexion ou lorsque le répertoire de la session était modifié alors que ses outils étaient encore en cours de chargement
  • Correction des commandes Bash s'exécutant parfois dans le mauvais dossier lorsque Claude en envoyait plusieurs à la fois et qu'une précédente changeait de dossier
  • Correction des fichiers que Claude envoie depuis les sessions cloud et de contrôle à distance qui échouent immédiatement lorsqu'un téléchargement reçoit un HTTP 507 d'un proxy ; le téléchargement fait maintenant l'objet d'un deuxième essai
  • Correction des nouveaux messages qui n'étaient pas enregistrés et des sessions claude -p, SDK et VS Code suspendues, lorsque la mémoire était épuisée pendant la lecture de la transcription.
  • Correction de la connexion, de l'actualisation du jeton et de la déconnexion en attente indéfinie lorsque quelque chose sur le réseau accepte la connexion mais ne répond jamais à la poignée de main TLS
  • Correction d'un fichier envoyé apparaissant sous un nom différent dans les applications Claude lorsque son nom cachait la direction du texte ou les caractères de contrôle ; Claude refuse désormais d'envoyer un tel dossier
  • Correction des résumés de progression des sous-agents exécutant une requête jusqu'à sa fin après que le modèle ait répondu avec un appel d'outil
  • Correction de lectures Bash telles que grep -r foo "$PWD/src" demandant l'autorisation lorsque la même commande avec le chemin tapé s'exécute sans demander la permission.
  • Correction de la passerelle des applications Claude refusant de démarrer lorsqu'un paramètre desktop contient un champ plus récent que la passerelle, comme le oauth.omitResource d'un serveur MCP géré ; il le prévient maintenant et le sert
  • Correction des commandes Bash revenant vides pour les utilisateurs zsh dont .zshrc définit KSH_OPTION_PRINT
  • macOS : Correction de "Impossible de lire les paramètres de stratégie gérés" au démarrage lorsqu'un profil MDM valide était lent à lire : la lecture est réessayée une fois et un délai d'attente est désormais signalé comme un délai d'attente.
  • Correction de la vue d'agent effaçant le texte d'entrée enregistré d'une autre vue d'agent lors du redémarrage pour une mise à jour sans rien saisir.
  • Correction des sessions à distance ne donnant aucune réponse après un redémarrage lorsqu'un hook UserPromptSubmit bloquait une réponse d'autorisation rejouée ; ces hooks ne fonctionnent plus sur cette rediffusion
  • Correction de claude remote-control acceptant un y tapé sans Entrée lors de sa première question à la fin de la saisie du terminal
  • Correction de Claude Desktop n'affichant pas les avertissements de limite de dépenses derrière une passerelle d'applications Claude dont la politique n'a pas de règles code:
  • Correction des sessions plein écran avec certains plugins se terminant par une erreur lorsqu'un résultat d'outil devenu plus court défilait en haut de l'écran
  • Correction des suggestions d'invite faisant des requêtes API supplémentaires lorsque le modèle répondait avec un appel d'outil
  • Correction des hooks PreToolUse mcp_tool sur les serveurs stdio et HTTP MCP étant ignorés lorsque leur réponse dépassait 16 Mo ; l'appel de l'outil est désormais refusé
  • Correction des noms de compétences et de commandes contenant une lettre Bamum que certaines polices dessinent en blanc : elles sont désormais refusées
  • Correction de claude -p sous Linux quittant 0 en silence lorsqu'une exportation NFS complète ou un quota NFS épuisé perdait des lignes de transcription : il imprime désormais une erreur et, dans le texte et la sortie json, quitte 1
  • Correction des agents en arrière-plan signalés comme arrêtés par l'utilisateur et refusant de reprendre lorsqu'un service interrompait une session cloud et que personne n'appuyait sur Stop.
  • Correction de NotebookEdit signalant le succès aux hooks et à la télémétrie lorsque la modification échouait, par exemple lorsque le bloc-notes changeait alors que l'invite d'autorisation était ouverte
  • Correction d'un écran vide ou d'aucune réponse au démarrage et d'une sortie claude mcp list vide, lorsqu'un enregistrement de connexion MCP stocké était nul
  • Correction de l'outil Artefact demandant à Claude d'ajouter des filtres lorsque la collection de base de données d'un artefact est trop grande pour être triée ; il dit maintenant de lire la collection page par page et de trier les résultats
  • Correction d'une session cloud redémarrée laissant tomber un message avec une grande image lorsque le redémarrage intervenait avant la première réponse de Claude
  • Correction d'une session cloud redémarrée laissant sans réponse le message d'un sous-agent dans la conversation principale
  • Correction de Claude qui n'est pas informé lorsque vous arrêtez ou mettez en pause un workflow en cours, donc il n'indique plus que le workflow est toujours en cours d'exécution
  • Amélioration du sélecteur /model : "Plus de modèles" est désormais une rangée non numérotée en dessous les unes des autres, et les anciens modèles s'ouvrent en dessous sans renuméroter le reste
  • Passerelle : amélioration des limites de dépenses sur une réplique occupée, qui saute désormais moins de contrôles et enregistre les dépenses plus tôt
  • Amélioration des messages de limite de connexion de la passerelle des applications Claude dans Claude Code et sur la page /device : ils ne nomment plus les paramètres de la passerelle, que le propre journal de la passerelle nomme toujours
  • Amélioration de claude install et des scripts d'installation : ils se terminent 2 à 4 secondes plus tôt
  • Amélioration de la rapidité avec laquelle une session de contrôle à distance dont le processus s'est écrasé peut récupérer un nouveau message
  • Windows : amélioration du temps de démarrage et de première commande en recherchant des programmes sur PATH sans démarrer de processus d'assistance
  • Mode automatique amélioré dans les sessions sans tête, l'application de bureau et VS Code : les rapports des sous-agents en arrière-plan qui attendent ensemble reçoivent une réponse dans un seul appel modèle, comme dans le terminal
  • Amélioration de la ligne de la vue agent pour une session claude --bg --worktree qui n'a pas pu configurer son arbre de travail : elle affiche désormais l'erreur depuis son début, et non une balise interne ni ses 200 derniers caractères
  • Amélioration des messages affichés lorsqu'un artefact se trouve dans une autre organisation : /login n'est proposé que s'il s'agit de l'une des vôtres, et Claude indique désormais où une copie peut se trouver après un déplacement de compte
  • Sessions améliorées avec plus d'images que ne peut en contenir une seule requête : Claude est informé s'il a déjà vu une image supprimée, et les lectures répétées d'une image inchangée sont limitées.
  • Amélioration des messages de claude remote-control pour une première question sans réponse : chacun dit désormais quoi faire ensuite
  • Temps de démarrage amélioré en chargeant plus rapidement les certificats TLS trusted
  • Amélioration des messages d'erreur de la passerelle des applications Claude pour afficher l'adresse de la passerelle sans nom d'utilisateur ni mot de passe
  • Amélioration de l'erreur de limite de dépenses de la passerelle des applications Claude : la réinitialisation s'affiche désormais à votre heure locale, par exemple "réinitialise 16h (Amérique/Los_Angeles)".
  • Windows : temps de démarrage amélioré avec une installation standard de Git pour Windows en ne vérifiant plus quel git.exe exécuter à chaque lancement
  • Mise à jour du message de retour de session et de la description du paramètre allowedProviders pour nommer Ultra aux côtés de Pro et Max, ainsi que de la description forceLoginMethod pour couvrir tous les forfaits Claude payants.
  • Mise à jour de la compétence de visualisation de données groupée pour suggérer une liste de mètres, une ligne par élément, pour plusieurs ratios qui ont chacun leur propre limite
  • Mise à jour des options « Mise à niveau vers Max » pour indiquer « Mise à niveau vers Max ou Ultra »
  • Mods modifiés que Claude écrit pour s'allumer sans demander en modes auto et bypass, même avec allowUnsandboxedCommands: false ou allowManagedDomainsOnly géré, et ne pas charger en mode dontAsk
  • Modification des propres appels d'outils des mods ($.tool.call, $.mcp.call) pour ne générer aucune invite d'autorisation, même selon vos propres règles de demande ou dans les exécutions dontAsk et -p ; Les règles de refus et la politique de l'organisation s'appliquent toujours.
  • Modification des choix de modèles Fable 5.1 enregistrés pour passer au fable : sur les forfaits Pro et Max à la fois, sur les forfaits Team et Enterprise une fois que votre organisation le permet ; utilisez /model claude-fable-5-1 pour revenir en arrière
  • Modification des étiquettes du mode rapide dans /fast, /config et /model pour nommer votre modèle actuel lorsqu'il prend en charge le mode rapide, et suppression de "(Opus uniquement)" de la ligne VS Code
  • Modification du chargement des compétences imbriquées : les dossiers .claude/skills dans ~/.claude/plugins ne se chargent plus lorsque Claude y travaille sur des fichiers
  • Exécuteur auto-hébergé : modification d'un exécuteur à la demande que le serveur refuse car il n'est pas nécessaire (session terminée ou suspendue, ordre de travail remplacé) pour quitter 0 au lieu de 1
  • Windows : modification de la façon dont Claude Code trouve les programmes qu'il démarre lui-même, tels que git, pour ignorer les entrées et les liens relatifs et UNC PATH sur un partage réseau, et pour récupérer les modifications de PATH à partir des paramètres.
  • Modification des événements de hook OpenTelemetry dans les sessions non interactives pour laisser deux hooks intégrés hors de num_hooks et num_success après les appels Bash et PowerShell
  • Modification du nombre de messages qu'une session de l'onglet Claude Desktop Code peut envoyer à vos autres sessions avant d'attendre que vous tapiez à nouveau de 10 à 20
  • Modification de AskUserQuestion dans les sessions claude -p et SDK pour refuser la réponse d'autorisation d'un hôte qui définit le champ de saisie afkTimeoutMs non documenté
  • Modification du extraKnownMarketplaces géré : un nom déclaré ne peut pas être ajouté depuis une autre source, une entrée provenant d'ailleurs est masquée et les plugins des listes de places de marché déclarées sont réinstallés à partir de celui-ci.
  • Modification des outils Claude dans Chrome fournis par une application exécutant Claude Code, tels que l'onglet Code de l'application de bureau Claude, pour suivre la politique Claude dans Chrome de votre organisation.
  • Modification de policy_mode: layered dans la passerelle des applications Claude : les serveurs MCP gérés s'additionnent désormais sur chaque stratégie correspondante, match: {} inclus, donc une passerelle déjà présente sert davantage après la mise à niveau
  • Passerelle : modification en amont de Bedrock, Vertex et Foundry pour ignorer les variables ANTHROPIC_*_BASE_URL dans l'environnement de la passerelle. Définissez base_url en amont pour utiliser un autre point de terminaison
  • Modification des sessions sans tête pour recharger les mods dans .claude/skills lorsque leurs fichiers changent ; réglez CLAUDE_CODE_PLUGIN_DIR_WATCH=0 pour désactiver cette fonction
  • Modification de la phrase du programme de vérification de cybersécurité sur un bloc de cybersécurité pour utiliser les mêmes mots que claude.ai
  • Modification des sessions cloud Cowork : un hook PostToolUse ne peut plus remplacer la réponse à AskUserQuestion ou le plan dans le résultat d'ExitPlanMode ; Claude lit les originaux
  • Modification de cp et mv orthographiés par un chemin, tel que /bin/cp, pour obtenir les mêmes vérifications de chemin que cp et mv
  • Modification des notifications de commandes en arrière-plan et des résultats de TaskStop pour afficher à Claude uniquement le début et la fin d'une commande de plus de 1 000 caractères, ce qui enregistre le contexte
  • Modification des directives de conception d'artefacts pour traiter Inter et Space Grotesk comme de bonnes polices de caractères par défaut
  • Modification de la vérification des e-mails du compte pour refuser uniquement une commande shell qui contient votre e-mail et nomme un agent utilisateur, sans le demander, afin que les autres commandes et exécutions planifiées ne s'arrêtent plus à son invite.
  • Modification des sessions de contrôle à distance pour conserver le dossier dans lequel elles ont été démarrées : un client connecté ne peut plus déplacer une session vers un autre dossier
  • Modification des reprises gérées de extraKnownMarketplaces à partir d'une source non déclarée : les données enregistrées sont réservées à cleanupPeriodDays, et les options et secrets jusqu'à claude plugin restore-set-aside
  • [VSCode] Ajout d'un avertissement au-dessus de la boîte de dialogue lorsqu'un jeton d'authentification et une clé API sont définis, correspondant à l'avertissement de démarrage du terminal
  • [VSCode] Correction de la demande d'autorisation d'un plugin affichant un nom avec des caractères masqués : il lit désormais "un plugin"
