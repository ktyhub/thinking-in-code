siège d'incubateur v2.0.0

Sortie du Seata 2.0.0

Seata est une solution de transaction distribuée open source, facile à utiliser et hautes performances.

La version est mise à jour comme suit :

fonctionnalité :

  • [#5165] optimise la structure TCC, prenant en charge l'accès API. ajoutez un module de couche d'intégration (seata-integration-tx-api) pour la définition du processus de transaction et l'amélioration du proxy.
  • [#5352] ajouter l'analyseur Jackson json et l'analyseur Gson json pour le contexte d'action commerciale TCC
  • [#5377] fait en sorte que AbstractHttpExecutor.class prenne en charge http put
  • [#5396] Métrique d'ajout de journal TC
  • [#5118] prend en charge l'exécution de notifications simultanées en deux étapes
  • [#5529] L'image docker prend en charge l'injection de paramètres JVM
  • [#3887] ajoute le support de la base de données SQL Server en mode AT
  • [#4033] ajoute la prise en charge de SQLServer pour le mode de stockage Server DB
  • Fonctionnalité [#5600] : prise en charge du suivi du lien de transaction en fonction du XID
  • Fonctionnalité [#5357] : intégration de console saga-statemachine-designer
