siège d'incubateur v1.7.0

Seata 1.7.0 est sorti.

Seata est une solution de transaction distribuée open source, facile à utiliser et hautes performances.

La version est mise à jour comme suit :

fonctionnalité :

  • [#5476] premier support native-image pour seata-client
  • [#5495] intégration de console saga-statemachine-designer
  • [#5668] compatible avec les configurations file.conf et Registry.conf dans la version 1.4.2 et inférieure

Correction de bug :

  • [#5682] correction du contexte de relecture du mode saga perdu startParams
  • [#5671] correction de l'exception de conversion du mode saga serviceTask inputParams json autoType
  • [#5194] correction d'un mauvais ordre des mots clés pour Oracle lors de la création d'une table
  • [#5021] Correction de l'échec de la réflexion JDK pour le proxy d'origine Spring dans JDK17
  • [#5023] correction du conflit transitif de dépendance seata-core dans seata-dubbo
  • [#5224] correctif du script d'initialisation d'Oracle index_name est en double
  • [#5233] corrige les noms d'éléments de configuration incohérents liés à LoadBalance
  • [#5266] la console du serveur de correctifs a interrogé le verrou libéré
  • [#5245] corrige la dépendance incomplète du module de distribution
  • [#5239] correction de getConfig qui lance ClassCastException lors de l'utilisation du proxy JDK
  • [#5281] le handle de requête parallèle lance IndexOutOfBoundsException
  • [#5288] correction de l'auto-incrémentation des colonnes pk dans Oracle en mode AT
  • [#5287] correction de l'auto-incrémentation des colonnes pk dans PostgreSQL en mode AT
  • [#5299] correction de la suppression de GlobalSession lors d'une nouvelle tentative de restauration ou d'une nouvelle tentative de validation.
  • [#5307] corrige le fait que les mots-clés n'ajoutent pas de caractères d'échappement
  • [#5311] supprime les sessions RollbackRetryTimeout pendant la récupération du stockage de fichiers
  • [#4734] vérifie si le méta-cache de la table doit être actualisé en mode AT
  • [#5316] correction du paramètre G1 jvm dans jdk8
  • [#5321] correctif Lorsque la logique de restauration côté TC renvoie RollbackFailed, le FailureHandler personnalisé n'est pas exécuté
  • [#5332] correction des bugs trouvés dans les tests unitaires
  • [#5145] correctif, la session globale démarre toujours en mode saga
  • [#5413] correction d'un mauvais fichier de configuration de service et d'un échec de compilation
  • [#5415] correction du délai d'expiration de la transaction côté client qui n'exécute pas le hook et FailureHandler
  • [#5447] Correction du mode Oracle XA qui ne peut pas être utilisé par la même base de données
  • [#5472] correctif si vous utilisez @GlobalTransactional dans RM, ShouldNeverHappenException sera lancé
  • [#5535] corrige le chemin du fichier journal mal chargé
  • [#5538] correction d'une exception d'avalement de transaction terminée lors de la validation
  • [#5539] corrige le problème d'analyse de table complète avec la condition 'setDate' dans Oracle 10g
  • [#5540] correctif GlobalStatus=9 ne peut pas être effacé en mode de stockage DB
  • [#5552] correction de l'échec de la restauration de MariaDB
  • [#5583] correction du problème de dissociation xid de l'intercepteur grpc
  • [#5602] correction du journal dans le rôle de transaction du participant
  • [#5645] correction de l'échec de l'annulation de l'insertion d'Oracle
  • [#5659] corrige le problème de respect de la casse dans la base de données après l'ajout de caractères d'échappement aux mots-clés
  • [#5663] corrige le délai d'attente qui est nul lorsque la connexion connectionProxyXA est réutilisée
  • [#5675] corrige la compatibilité entre les éléments de configuration xxx.grouplist et grouplist.xxx
  • [#5690] correction de l'impression de la console unauthorized error
  • [#5711] correctif, l'élément de configuration d'obtention contient une erreur soulignée

optimiser :

  • [#5208] optimise à nouveau getCause jetable
  • [#5212] optimiser le niveau des messages du journal
  • [#5237] optimisation de l'impression des messages du journal des exceptions (EnhancedServiceLoader.loadFile#cahtch)
  • [#5089] optimise la vérification de la valeur du délai de la tâche de nettoyage du journal de clôture TCC
  • [#5243] optimiser kryo 5.4.0 optimiser la compatibilité avec jdk17
  • [#5153] Uniquement en mode AT, essayez d'obtenir une chaîne avec une autre application
  • [#5177] Si server.session.enable-branch-async-remove est vrai, supprimez la branche de manière asynchrone et déverrouillez-la de manière synchrone.
  • [#5273] optimise la configuration de compilation du plug-in protobuf-maven-plugin pour résoudre le problème des lignes de commande trop longues dans les versions supérieures.
  • [#5303] supprime le script de démarrage de la configuration -Xmn
  • [#5325] ajouter des informations de journal sur le mode magasin, le type de configuration et le type de registre
  • [#5315] optimiser le log de SPI
  • [#5323] ajouter des informations de temps pour le journal global des délais d'expiration des transactions
  • [#5414] optimiser le gestionnaire d'échec de transaction
  • [#5537] optimiser le journal des transactions côté client
  • [#5541] optimise la sortie du journal du serveur
  • [#5548] mettre à jour la clé gpg d'expiration et publier le workflow
  • [#5638] optimiser : définir le niveau de transaction du serveur sur READ_COMMITTED
  • [#5646] refactoriser ColumnUtils et EscapeHandler
  • [#5648] optimiser l'impression des journaux du serveur
  • [#5647] prend en charge les attributs sensibles à la casse pour les métadonnées des tables et des colonnes
  • [#5678] optimise le caractère d'échappement pour le cas des noms de colonnes
  • [#5684] optimise les actions github pour CodeQL, skywalking-eyes et checkout
  • [#5700] optimisation du journal de verrouillage distribué

sécurité :

  • [#5172] corrige certaines failles de sécurité
  • [#5683] ajouter le sérialiseur hessien WhiteDenyList
  • [#5696] corrige plusieurs vulnérabilités de sécurité du node.js

  • [#5380] correctif UpdateExecutorTest a échoué
  • [#5382] correction du test de version multi-ressorts échoué
