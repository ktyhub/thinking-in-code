orque v1.4.257

Version précédente : 1.4.256 — Configuration plus simple de la dictée sur l'appareil et améliorations antérieures des performances des discussions longues.

De longues discussions plus fluides, des commentaires enregistrés et une meilleure dictée ✨

Orca 1.4.257 réduit les blocages lorsque plusieurs longues conversations de l'interface utilisateur de chat sont diffusées en même temps. Si vous laissez plusieurs agents travailler dans des conversations avec un historique important, cette mise à jour réduit le travail effectué par Orca à mesure que leurs réponses arrivent.

  • 🌐 Conservez les commentaires de votre navigateur lors des redémarrages : Les notes textuelles non envoyées sur les pages du navigateur d'Orca reviennent désormais après un rechargement ou un redémarrage. La fermeture d'un onglet contenant des notes non envoyées demande avant de les supprimer, afin que vous puissiez laisser des commentaires et y revenir plus tard. Les agents exécutés sur votre bureau peuvent lire ces notes avec orca tab annotations avant d'appuyer sur Envoyer.
  • 🎙️ Donnez-vous le temps de réfléchir pendant que vous dictez : Dans Paramètres → Voix → Saisie → Arrêter après silence, choisissez 30 secondes, une minute, deux minutes ou Désactivé. La dictée peut attendre une pause plus longue pendant que vous rédigez un message ou une commande de terminal. La même page de paramètres ajoute un bouton Test pour enregistrer et lire votre microphone, avec une transcription lorsque votre modèle vocal est prêt.
  • ⌨️ Coller pendant qu'un terminal se connecte : Une commande collée dans un terminal qui démarre ou se reconnecte attend désormais son shell au lieu d'être supprimée. Cela couvre les terminaux locaux, SSH et distants pour les pâtes jusqu'à 64 Ko ; les pâtes plus grosses nécessitent toujours un terminal connecté.
  • 🗂️ Automatiser les routines de l'espace de travail de dossier : Les scripts de configuration configurés s'exécutent désormais lorsque vous créez un espace de travail de dossier, y compris via le CLI. Les scripts d'archive sont exécutés avant la suppression. Utilisez-les pour préparer le projet et exécuter sa routine de nettoyage ; ces scripts fonctionnent dans le dossier de projet partagé.

Faits saillants

  • Trouver ce qui appartient à un volet divisé : Appuyez sur / dans un volet divisé vide pour rechercher un agent ou un fichier. Utilisez les touches fléchées et Entrée pour ouvrir votre sélection sans quitter le clavier.
  • Conservez le modèle Claude que vous avez choisi : Le sélecteur de l'interface utilisateur de chat conserve votre dernière sélection lorsque les réponses d'un tour précédent arrivent, plutôt que de revenir à leur modèle.
  • Voir les images que vous avez demandé au Codex de créer : Les images générées restent visibles une fois le tour terminé, sans développer les détails de son outil. Pour les discussions à distance, mettez à jour l'hôte et client pour obtenir ce comportement.
