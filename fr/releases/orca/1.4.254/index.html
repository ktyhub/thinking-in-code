orque v1.4.254

Git Graph, dictée au téléphone et questions annexes dans le chat ✨

  • 🌳 Voir l'intégralité du référentiel : Un nouvel onglet Git Graph affiche les branches et balises locales et distantes, avec les détails de chaque commit et les fichiers modifiés. Les espaces de travail de dossiers bénéficient désormais du contrôle de source, avec une carte pour chaque dépôt attaché, et le nom de la branche dans le contrôle de source change ou crée une branche en place.
  • 💬 Demandez sans faire dérailler un chat : Dans l'interface utilisateur du chat, /btw pose une question secondaire dans un fork à côté du chat pendant que l'original continue de s'exécuter, et /fork part de la dernière réponse. Les discussions qui s'ouvrent ou poussent vers une pull request affichent une ligne courte lorsque son CI réussit ou échoue.
  • 🎙️ Dictez de n'importe où : Les téléphones peuvent transformer la parole en texte sur l'appareil (iPhone sur iOS 26 ou version ultérieure et Android), avec l'ordinateur comme solution de secours. L'ordinateur, les téléphones et le Web client peuvent dicter en même temps, et la dictée sur l'appareil s'exécute selon son propre processus, de sorte qu'un crash ou un blocage du moteur vocal ne fait plus tomber Orca.
  • 📱 Un téléphone qui conserve votre travail : Le chat envoie une file d'attente lorsque le bureau est inaccessible et s'éteint à son retour. Les brouillons de discussion, les pièces jointes, les modifications de fichiers non enregistrées et les brouillons d'automatisation survivent à la suppression de l'application et les écrans rouvrent à partir de ce que le téléphone possède déjà.
  • ⌨️ Plus de décalage de frappe depuis les comptes Codex : La frappe pouvait prendre du retard sur Orca lorsqu'elle reliait l'historique du Codex entre les comptes. Ce travail ne bloque plus l'application. Les terminaux distants envoient également immédiatement une seule frappe et lisent la sortie compressée des hôtes distants.
  • 🔐 Couplage plus sûr et trust : Un code de couplage cesse de fonctionner une fois que l'appareil qui l'a utilisé enregistre sa propre connexion, le bureau et les connexions du CLI aux serveurs distants utilisent le cryptage le plus récent, et orca serve refuse les connexions à partir d'adresses Internet publiques, sauf s'il y a une raison de les autoriser. Orca demande une fois par nouveau dépôt avant de le trust pour les agents.
  • 🎨 Faites vôtre Orca : Importez votre propre icône d'application, laissez les plugins de thème lire une vidéo d'arrière-plan en boucle et expédier leurs propres polices, et lisez les paramètres dans les cartes intitulées. Claude Code peut correspondre au thème de votre terminal Orca si vous dites oui.
  • 🤖 Meilleure prise en charge des agents : Les chats antigravité peuvent s'exécuter sur le propre compte de l'hôte, y compris les chats à accès complet, et Muse affiche son quota d'abonnement dans la barre d'état.

Faits saillants

  • Chat : /btw pose une question secondaire dans un fork et /fork fourche à partir de la dernière réponse, avec une flèche pendant que le fork s'ouvre. Les discussions affichent les résultats CI pour les demandes d'extraction qu'ils ont ouvertes ou poussées, et chaque message, commande et direction en attente se trouve désormais dans une file d'attente ordonnée que vous pouvez déplacer, supprimer ou envoyer.
  • Téléphone : Envoyez lorsque le bureau est hors ligne, conservez les brouillons, les pièces jointes, les modifications de fichiers et les brouillons d'automatisation lors des suppressions d'applications, et consultez la liste de l'espace de travail, les onglets de session et la révision de la mémoire pendant leur actualisation. Les dossiers volumineux chargent 500 entrées à la fois avec Rechercher tout, Révision pré-extrait le fichier suivant et précédent, et une fine ligne sous l'en-tête indique quand les données mises en cache sont actualisées.
  • Dictée : Les téléphones peuvent transcrire sur l'appareil, et chaque appareil peut dicter en même temps. Sur le bureau, le modèle vocal se charge avant votre première dictée (un nouveau paramètre choisit quand le décharger), la dictée s'arrête après une minute de silence et conserve ce que vous avez dit, le texte dicté est précédé d'un espace et le texte qui ne peut pas être inséré est copié à la place. Le Web client couplé peut dicter via l'hôte.
  • Contrôle et éditeur de source : Git Graph, contrôle de source pour les espaces de travail de dossiers et un sélecteur de branche sur place dans l'en-tête de contrôle de source. Les fichiers entièrement nouveaux et supprimés affichent une teinte nette, Markdown conserve ses couleurs de syntaxe sous les thèmes du plugin, les aperçus HTML s'ouvrent dans le propre groupe d'onglets de l'éditeur et copient comme le dit PNG lorsqu'une image est trop grande au lieu de prétendre qu'elle a été copiée.
  • Agents et comptes : Le décalage de saisie de l'historique des comptes Codex est corrigé. Les discussions Antigravity peuvent s'exécuter sur l'agy de l'hôte lorsqu'il est connecté, les sessions Antigravity dans AI Vault peuvent révéler leur dossier d'artefacts, et Muse affiche son quota et maintient les volets fonctionnels pendant que les sous-agents en arrière-plan s'exécutent. Le menu de lancement du nouvel onglet est plus simple, le sélecteur d'agent trouve des modèles dans ses sous-menus et, après un redémarrage, les agents sont invités à terminer la tâche d'origine.
  • Hôtes distants : Les terminaux distants répondent plus tôt aux frappes au clavier, les discussions de bureau sur les hôtes distants diffusent uniquement le nouveau texte et l'interrogation ralentit lorsque la fenêtre Orca est visible mais n'est pas ciblée. Les serveurs SSH gérés récupèrent après une connexion ProxyCommand lente et dans davantage de cas de serveur mort, et les automatisations pour un hôte SSH géré sont transférées sur son propre serveur Orca.
  • Aspect et convivialité : Importez une icône d'application personnalisée, utilisez des menus thématiques et des commandes segmentées plus claires, et utilisez des polices Web et des vidéos d'arrière-plan en boucle à partir de plugins. Les plugins de thème peuvent également styliser le texte et la sélection du chat, qui sont désormais plus faciles à lire en mode sombre. Les onglets des fichiers et du navigateur correspondent à leurs titres, donc plus adaptés avant que la bande d'onglets défile.

Notes de compatibilité et de mise à niveau

  • Correspondance du thème Claude Code : Orca peut désormais faire correspondre le thème de Claude Code au thème de votre terminal Orca. C'est ouvert à tout le monde, y compris aux nouveaux profils. La prochaine fois que Claude Code se présente, Orca demande une fois pour porter un toast. Rien dans ~/.claude/settings.json ne change sauf si vous l'acceptez, et vous pourrez le modifier ultérieurement dans Paramètres > Apparence > Terminal.
  • Raccourci de recherche : Les nouveaux profils Mac ouvrent la recherche avec Cmd+K et n'ont pas de raccourci par défaut pour effacer le terminal. Les nouveaux profils Windows et Linux utilisent Ctrl+K. Les profils existants conservent leurs raccourcis, y compris ceux personnalisés et désactivés.
  • Dossier d'agent trust : La première fois que vous démarrez un agent dans un nouveau dépôt, Orca vous demande s'il faut trust le dépôt ou laisser chaque agent demander lui-même. Les dépôts que vous utilisez déjà continuent de fonctionner comme avant, sans invite. Vous pouvez modifier la réponse dans les paramètres du dépôt.
  • Codes de couplage à usage unique : Lorsqu'un téléphone, un navigateur ou un Orca mis à jour s'associe à un ordinateur de bureau mis à jour, il passe à sa propre connexion et le code QR ou le lien qu'il a utilisé cesse de fonctionner. Les appareils dotés d'applications plus anciennes continuent de fonctionner et les paramètres marquent les appareils qui utilisent toujours le code de couplage d'origine ou un cryptage plus ancien afin que vous sachiez lesquels mettre à jour.
  • orca serve et adresses publiques : orca serve accepte les connexions localhost, LAN et Tailscale par défaut et n'accepte les adresses Internet publiques que lorsqu'il y a une raison de le faire. Les configurations existantes continuent de se connecter.
  • Mémoire du modèle vocal : Lorsque la voix est activée, Orca charge désormais le modèle vocal sur l'appareil avant votre première dictée. Utilisez le nouveau paramètre Décharger le modèle vocal dans Paramètres > Voix pour libérer cette mémoire plus tôt. La dictée sur ordinateur s’arrête désormais d’elle-même après une minute de silence.
  • Épaisseur de la police du terminal Windows : Le texte du terminal sous Windows utilise désormais l'épaisseur de la police Regular par défaut au lieu de Medium, que Windows a dessiné comme SemiBold. macOS et Linux sont inchangés.
  • Menu de lancement du nouvel onglet : Les autorisations et les arguments ne figurent plus dans le menu de lancement de l'agent du nouvel onglet. Ils proviennent toujours des paramètres de l'agent.
  • Intégration : Le bouton d'installation d'Antigravity lors de l'intégration a disparu. Antigravity a le même lien d’instructions d’installation que tous les autres agents.
