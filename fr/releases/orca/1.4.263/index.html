orque v1.4.263

Version précédente : 1.4.262 — Changement de chat plus rapide, utilisation réduite de la mémoire et blâme git.

Démarrage de chat plus léger, Hermes dans Chat et panneaux latéraux d'extension de navigateur ✨

Rouvrez des espaces de travail remplis de discussions en utilisant moins de mémoire et moins de travail de démarrage. Les interfaces de discussion restaurées se chargent lors de leur première affichage et Orca ne réécrit plus chaque conversation enregistrée au lancement. Les discussions ouvertes conservent leurs brouillons et leur position de défilement à votre retour.

  • 💬 Continuer les conversations Hermes dans le chat : Démarrez Hermes à partir du menu Nouvel onglet, ou choisissez Reprendre dans un nouveau chat sur une entrée de l'historique de session pour poursuivre une conversation de terminal dans son espace de travail et son profil d'origine.
  • 🌐 Gardez les extensions à côté de votre page : Les extensions Chrome qui utilisent des panneaux latéraux peuvent désormais s'ouvrir dans un panneau redimensionnable dans le navigateur d'Orca. Clicochez le bouton de la barre d'outils de l'extension pour utiliser son panneau lors de la navigation ; les fenêtres contextuelles d'extension acceptent également Coller, Copier et Sélectionner tout.
  • 🖥️ Atteignez votre travail à distance : Les ports SSH gérés disposent désormais d'un bouton Suivant. Sous Windows, les projets ouverts via une lettre de lecteur WSL mappée peuvent être déplacés vers l'hôte WSL de leur distribution.
  • ⌨️ Gardez la sortie du terminal visible après un redémarrage : Sous macOS et Linux, un terminal dont le shell s'est arrêté peut restaurer sa sortie enregistrée avec la nouvelle invite en dessous. Windows conserve son comportement de restauration existant.

Faits saillants

  • Connectez Linear depuis la ligne de commande : orca linear connect accepte une clé API via stdin et connecte l'hôte que vous ciblez, y compris un serveur sans tête. Chaque hôte conserve sa propre connexion. Les listes de problèmes et de projets linéaires renvoient désormais tous les résultats lorsque vous omettez --limit.
  • Configurer des agents sous Windows : Les chats Claude et Codex proposent Installer lorsque l'agent est manquant, puis Vérifier à nouveau pour détecter l'installation. orca agent installed répertorie également les agents CLI activés sur l'hôte actuel pour les scripts et la configuration de lancement.

Notes de compatibilité et de mise à niveau

  • Hermes : Chat nécessite Hermes 0.23.0 ou version ultérieure sur la machine exécutant l'espace de travail. Les importations très longues affichent les messages récents tandis qu'Hermès conserve l'intégralité de la conversation. Le chat n'est pas disponible pour les espaces de travail SSH ; un serveur Orca couplé le prend en charge. La première conversation après l'arrêt de la passerelle Hermès peut prendre une minute pour démarrer.
  • Identité du navigateur : Natif est désormais la valeur par défaut, corrigeant la boucle de vérification Cloudflare vue avec la valeur par défaut précédente. Les choix d'identité explicites sont préservés ; modifiez le vôtre dans Paramètres → Navigateur → Identité du navigateur.
  • Mises à jour du téléphone : Les modifications de l'interface utilisateur du téléphone répertoriées ci-dessous nécessitent une version mobile correspondante. Cette mise à jour du bureau ne met pas à jour les applications Android ou iOS.

Problèmes connus

  • Veillez plutôt l'espace de travail : L'option peut échouer lorsqu'un autre onglet de cet espace de travail exécute un processus.
  • orca agent installed --worktree : Erreurs de commande sur les espaces de travail SSH et sur serveurs couplés.
