lama-index-agent-agentmesh [0.1.0]

  • [Intégration] AgentMesh : couche Trust pour les agents LlamaIndex (#20644)

lama-index-core [0.14.15]

  • Prise en charge des opérations de base pour les types multimodaux (#20640)

  • Ajout de nouvelles tentatives et de gestion des erreurs à BaseExtractor (#20693)
  • s'assurer qu'au moins un bloc de message/contenu est renvoyé par l'ancienne mémoire (#20729)

lama-index-embeddings-ibm [0.6.0.post1]

  • corvée : suppression du support du paramètre persistent_connection, mise à jour (#20714)
  • documentation : mettre à jour la documentation IBM (#20718)

lama-index-llms-anthropique [0.10.9]

  • Ajout du Sonnet 4-6 (#20723)

lama-index-llms-bedrock-converse [0.12.10]

  • correctif (bedrock-converse) : assurez-vous que thinking_delta est renseigné dans tous les modes de discussion (#20664)
  • feat(bedrock-converse) : Ajout du support pour Claude Sonnet 4.6 (#20726)

lama-index-llms-ibm [0.7.0.post1]

  • corvée : suppression du support du paramètre persistent_connection, mise à jour (#20714)
  • documentation : mettre à jour la documentation IBM (#20718)

lama-index-llms-mistralai [0.10.0]

  • Rrubini/mistral azur sdk (#20668)

lama-index-llms-oci-data-science [1.0.0]

  • Ajout de la prise en charge du nouveau point de terminaison OCI DataScience /predictWithStream pour le cas d'utilisation du streaming (#20545)

lama-index-observability-otel [0.3.0]

  • améliorer la sérialisation des données de l'hôtel en aplatissant les dicts (#20719)
  • exploit : prise en charge du processeur span personnalisé ; refactor : utilisez lama-index-instrumentation au lieu de lama-index-core (#20732)

lama-index-program-evaporate [0.5.2]

  • Exécution de code généré par Sandbox LLM dans EvaporateExtractor (#20676)

lama-index-readers-bitbucket [0.4.2]

  • correctif : remplace l'argument mutable par défaut dans load_all_file_paths (#20698)

lama-index-readers-github [0.10.0]

  • exploit : améliorez GitHubRepoReader avec la récupération et la déduplication sélectives de fichiers (numéro 20471) (#20550)

lama-index-readers-layoutir [0.1.1]

  • exploit : Ajouter l'intégration du lecteur LayoutIR (#20708)
  • fix(layoutir) : correctif pour le crash du répertoire_sortie et l'extraction de blocs (suivi #20708) (#20715)
  • correctif (layoutir) : restreindre require-python à >=3.12 pour correspondre à la dépendance layoutir (#20733)

lama-index-readers-microsoft-sharepoint [0.8.0]

  • Ajout de la prise en charge de la pagination pour les appels Microsoft Graph API dans le lecteur SharePoint (#20704)

lama-index-readers-whatsapp [0.4.2]

  • correctif : Mettre à jour WhatsAppChatLoader pour récupérer DataFrame au format pandas (#20722)

lama-index-tools-mcp [0.4.7]

  • exploit : propager partial_params vers les utils get_tools_from_mcp (#20669)

lama-index-vecteur-magasins-faiss [0.5.3]

  • Remplacer eval() par json.loads dans la persistance FaissMapVectorStore (#20675)

lama-index-vecteur-magasins-milvus [1.0.0]
