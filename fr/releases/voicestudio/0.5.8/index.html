Points forts

  • OmniVoice GGUF utilise les GPU AMD, Intel et NVIDIA via Vulkan sous Windows et Linux, et les GPU Intel Arc exécutent OmniVoice
  • L'installation revient à une version de processeur plus petite lorsque les téléchargements PyTorch échouent, et l'application revient au processeur lorsque le GPU échoue
  • Windows charge les modèles un fichier à la fois, et un crash moteur en nomme la cause et propose un redémarrage sur le processeur
  • Le clonage vocal dots.tts fonctionne sous Windows via audio.cpp, sans configuration Python
  • Convert peut conserver votre livraison et prend des vidéos ; Le doublage exporte d'abord les sous-titres et déplace les lignes entre les enceintes

OmniVoice utilise désormais votre GPU AMD, Intel ou NVIDIA, et VoiceStudio devient beaucoup plus difficile à casser. OmniVoice GGUF fonctionne sur n'importe quel GPU Vulkan sous Windows et Linux, dimensionne son modèle en fonction de votre carte et peut rester chargé entre les requêtes (opt-in, Paramètres → Performances), et les GPU Intel Arc exécutent également OmniVoice. En cas de problème, l'application continue désormais : l'installation propose une version de processeur beaucoup plus petite lorsque le téléchargement de PyTorch continue d'échouer, réessaye les téléchargements bloqués et VoiceStudio passe au processeur avec une notification en cas de panne du GPU. Sous Windows, les modèles chargent un fichier à la fois pour éviter un crash au premier lancement, et un crash du moteur nomme la bibliothèque derrière et propose un redémarrage sur le processeur.

Cette version apporte également le clonage vocal dots.tts sur Windows sans configuration Python, Convert qui conserve votre diffusion et prend la vidéo, un doublage qui exporte d'abord les sous-titres et déplace les lignes entre les haut-parleurs, une commande de terminal voicestudio, des mises à jour en arrière-plan, une nouvelle fenêtre d'installation macOS et des centaines de correctifs pour le doublage, la configuration, les livres audio et les applications téléphoniques.

La nouvelle fenêtre d'installation de macOS (#4001).

Mise à jour depuis 0.5.7 : Effectuez la mise à jour intégrée à l'application proposée par 0.5.7 ou installez-la par-dessus votre application existante ; les voix, les projets et les décors sont conservés. Lors du premier lancement, le runtime local met à jour ses packages, y compris la mise à jour de sécurité PyTorch 2.10 (#3884)

Mise à jour à partir d'un 0.5.8 bêta : Rien à faire : le canal Bêta avance automatiquement sur 0.5.8. Pour ne plus recevoir de versions bêta, passez à Stable dans Paramètres → Mises à jour → Mettre à jour le canal.

Exécutant à partir des sources : La démo Gradio et la formation du modèle ne sont plus installées par défaut ; ajoutez le ui ou le train supplémentaire si vous les utilisez (#4027)
