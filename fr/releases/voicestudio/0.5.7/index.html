#VoiceStudio v0.5.7

Tout d'abord, des excuses. Cette version a pris beaucoup plus de temps qu'elle n'aurait dû. Des problèmes familiaux urgents m'ont tenu à l'écart pendant un moment, et je suis désolé pour l'attente et pour les problèmes restés sans réponse entre-temps. Merci pour votre patience et pour chaque signalement, correction et mot gentil entre-temps.

Bienvenue Shimul Debnath (velixio) dans l'équipe principale. Shimul aide désormais à maintenir VoiceStudio - en examinant les demandes d'extraction, en triant les problèmes et en faisant avancer les versions - afin que le projet n'attende plus une seule personne.

VoiceStudio fonctionne désormais sur votre téléphone et sur les PC sans GPU, et l'ensemble de l'application est plus calme. Les applications de prévisualisation iOS et Android exécutent des modèles sur le téléphone lui-même, les ordinateurs sans GPU bénéficient de la petite version CPU PyTorch et la barre latérale, les pages Modèles, Doublage, Histoires et Flux de travail ont été repensées autour de contrôles moins nombreux et plus clairs.

Cette version ajoute également un canal de mise à jour bêta opt-in, un lecteur inférieur pour les prises, un panneau d'accélération GPU avec des rapports Radeon honnêtes et l'agent Ask VoiceStudio, ainsi que des centaines de correctifs pour le clonage, le doublage, les livres audio, les téléchargements et la dictée.

Mise à niveau : Installez sur votre application Electron existante ; les voix, les projets et les décors sont conservés. Si le programme d'installation vous le demande, choisissez Installer le runtime local pour actualiser ses dépendances.

  • Les appareils de calcul à distance, les travailleurs à distance et le partage de GPU ont été déplacés vers VoiceStudio Pro et ne sont plus dans l'application open source ; les projets, les voix et les paramètres enregistrés ne sont pas affectés (#2748)
  • Les modèles sans licence clairement commerciale, y compris le modèle OmniVoice par défaut, vous demandent d'accepter leur licence une fois dans le catalogue de modèles ; en attendant, les requêtes API et MCP qui les utilisent renvoient une erreur de licence (#2689)
  • L'accès Docker, LAN ou proxy inverse par un nom d'hôte, sans clé ni session API, nécessite ce nom dans OMNIVOICE_ALLOWED_HOSTS ; Les adresses IP, localhost, *.ts.net et host.docker.internal fonctionnent comme avant.
  • Les importations d'URL à partir de serveurs sur votre propre réseau nécessitent OMNIVOICE_ALLOW_PRIVATE_URL_IMPORTS=1.
  • Où définir ces variables : une ligne dans ~/.config/omnivoice/env (macOS, Linux) ou %USERPROFILE%\.config\omnivoice\env (Windows) pour l'application de bureau, -e pour Docker.

** Passer de Tauri :** Fermez l'application, sauvegardez son répertoire de données, installez Electron et vérifiez vos voix et vos projets avant de supprimer Tauri. Suivez le guide de migration. Tauri v0.5.3 reste la dernière version de Tauri ; son programme de mise à jour ne peut pas installer Electron.

Installateur trust : Les installateurs macOS sont signés. Les installateurs Windows ne sont pas encore signés par code, donc SmartScreen peut avertir ; le tableau Signature de l'installateur ci-dessus montre le résultat de chaque plate-forme. Consultez le [guide d'installation] (https://github.com/debpalash/VoiceStudio/blob/v0.5.7/docs/install/troubleshooting.md).
