#MoneyPrinterTurbo v1.3.6

Français | 中文

<h2 id="fr-v1.3.6">Points forts</h2>
  • Ajout de la génération vidéo native Volcano Engine Ark Seedance pour générer la source clips directement à partir de segments de script.
  • Ajout de la prise en charge texte-vidéo multimodèle OFox, permettant à Seedance, Wan et d'autres modèles de partager une clé API.
  • Ajout de la prise en charge texte-vidéo Metaso MiniMax H3 avec sortie 768P/2K, clips de 4 à 15 secondes et formats d'image 9:16, 16:9 et 1:1.
  • Ajout d'une source de matériel texte-image compatible OpenAI pour les relais cloud et les passerelles locales.
  • Ajout d'OpenRouter et APIMart en tant que fournisseurs LLM compatibles OpenAI.
  • Ajout d'un onglet de paramètres de publication automatique WebUI pour Upload-Post, avec des conseils plus clairs sur la configuration de la clé API et du compte.
  • Ajout du mode manifeste par lots CLI et application des paramètres WebUI enregistrés comme valeurs par défaut de CLI lorsque les valeurs de ligne de commande sont omises.
  • Ajout des modes d'ajustement de la source configurable clip : cover remplit le cadre en recadrant les bords en excès, tandis que contain préserve la source complète avec le letterboxing.
  • Ajout de traductions complètes de WebUI en français et en coréen.
  • Paramètres de source de matériel réorganisés, sources vidéo regroupées par capacité et informations d'identification centralisées du fournisseur de vidéo AI dans les paramètres WebUI.

Sécurité

  • Accès restreint du navigateur API d'origine croisée aux requêtes de même origine par défaut. Les interfaces de navigateur autonomes Trusted peuvent être activées explicitement avec CORS_ALLOWED_ORIGINS.
  • Ajout des attestations de provenance et SBOM aux images de conteneurs publiées.

Correctifs et améliorations

  • Durée de narration mesurée à partir du fichier audio généré au lieu de s'appuyer uniquement sur les indices de sous-titres.
  • Ancrage de la chronologie des sous-titres SiliconFlow à la durée audio complète.
  • Garantie que les ressources AudioFileClip sont fermées dans les chemins ElevenLabs, Chatterbox et Fish Audio.
  • Empêche le nettoyage du script de supprimer avidement le texte entre crochets ou entre parenthèses sans rapport.
  • Suppression d'un avertissement de nouvelle tentative trompeur après la dernière tentative LLM.
  • Correction des URL Redis lorsqu'aucun mot de passe n'est configuré.
  • Enregistrements de journaux préservés lorsque la racine du projet et la destination du journal se trouvent sur des supports différents.
  • Correction de la sortie de la console Unicode après une génération réussie de CLI sous Windows.
  • Ajout de noms de fichiers de téléchargement sûrs et portables, y compris des citations compatibles RFC et une protection contre les noms réservés Windows.
  • Amélioration du comportement de prévisualisation de WebUI sur les serveurs sans tête en revenant à la lecture et au téléchargement du navigateur.
  • Configuration Upload-Post découplée de la publication automatique afin que les paramètres puissent être enregistrés sans activer les téléchargements.
  • Gestion renforcée des images compatibles OpenAI : 200 réponses malformées ignorent désormais uniquement le mot-clé concerné, tandis que les pannes de stockage local arrêtent les demandes payantes supplémentaires.

Notes de mise à niveau

  • L'accès au navigateur API est désormais par défaut sur les requêtes de même origine. Les interfaces Web autonomes doivent déclarer leurs origines trust via CORS_ALLOWED_ORIGINS ; Les clients côté serveur tels que curl, Postman et n8n ne sont pas affectés.
  • Les commandes CLI héritent désormais des paramètres WebUI enregistrés pour les options omises. Les arguments explicites CLI et les valeurs du manifeste de lot sont toujours prioritaires.

<h2 id="cn-v1.3.6">重点更新</h2>
  • 新增火山引擎方舟 Seedance 原生视频生成服务，可根据脚本片段直接生成视频素材。
  • La clé OFox est basée sur Seedance, Wan et API Key.
  • Les modèles MiniMax H3 sont conçus pour fonctionner, pour les modèles 768P/2K, 4～15 pouces, pour les modèles 9:16, 16:9 et 1:1.
  • Il s'agit d'une application OpenAI basée sur OpenAI.
  • Il s'agit d'OpenRouter et de APIMart OpenAI.
  • WebUI 新增 Upload-Post 自动发布设置，并完善 API Key 和账号名称的申请、配置指引。
  • CLI est doté d'une interface utilisateur WebUI et d'une interface WebUI.
  • cover cover contain保留完整素材并在比例不同时增加黑边。
  • L'application WebUI est basée sur WebUI.
  • Les applications d'intelligence artificielle et d'IA WebUI设置中管理。

安全性

  • API API API API API API API显式配置可信来源。
  • 发布的容器镜像新增构建来源证明和 SBOM 软件物料清单证明。

修复与改进

  • 改为从真实生成的音频文件测量旁白时长，不再仅依赖字幕时间轴。
  • Il s'agit de SiliconFlow.
  • Les logiciels ElevenLabs, Chatterbox et Fish Audio sont AudioFileClip.
  • 修复脚本文本清理可能贪婪删除多组括号内容的问题。
  • « 正在重试 » 日志.
  • Le Redis est équipé d'un système d'exploitation de type Redis.
  • 修复项目目录和日志目录位于不同挂载点时日志记录丢失的问题。
  • Les versions Unicode de Windows sont compatibles avec CLI.
  • Les versions ultérieures de Windows sont compatibles avec Windows.
  • 无图形桌面的服务器环境下，WebUI 会回退到浏览器播放和下载视频。
  • 将 Upload-Post 配置与自动发布开关解耦，允许用户保存配置但不立即启用上传。
  • Version OpenAI d'OpenAI : HTTP 200返回损坏图片时仅跳过当前关键词，本地存储失败时则停止后续付费请求。

升级说明

  • API API API CORS_ALLOWED_ORIGINS curl、Postman、n8n 等服务端调用不受影响。
  • Lorsque CLI ne transmet pas explicitement de paramètres, il héritera des paramètres enregistrés par le WebUI ; les paramètres explicitement transmis dans les paramètres CLI et les champs de liste de lots ont toujours une priorité plus élevée.
