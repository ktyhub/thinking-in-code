laitue 7.7.0.RELEASE

L'équipe Lettuce est heureuse d'annoncer la version mineure de Lettuce 7.7.0 !

✨ Faits saillants

Lettuce 7.7.0 introduit la prise en charge des nouvelles fonctionnalités de la [version Redis OSS 8.10] (https://github.com/redis/redis/releases/tag/8.10.0), telles que :

  • Nouvelle commande : HIMPORT - insertion en masse de hachage compact à haut débit - guide utilisateur
  • Nouvelles commandes : LMOVEM, BLMOVEM - déplacez plusieurs éléments entre les listes
  • Nouvelle commande : SUNIONCARD - récupère la cardinalité de l'union de plusieurs ensembles
  • Nouvelle commande : SDIFFCARD - récupère la cardinalité de la différence entre les ensembles
  • XREAD, XREADGROUP - nouveaux arguments MAXCOUNT et MAXSIZE pour limiter les entrées et la taille des réponses cumulées
  • Nouvelle commande : FT.ALIASLIST - récupère tous les alias de l'index
  • Prise en charge de Stemmer pour les langues malais et tagalog

Prise en charge des fonctionnalités pour les structures de données probabilistes dans Redis :

  • Bloom filter
  • Count-min sketch
  • Cuckoo filter
  • t-digest
  • Haut-K

Lettuce 7.7.0 prend en charge Redis 2.6+ jusqu'à Redis 8.x. En termes d'exécution Java, Lettuce nécessite au moins Java 8 et fonctionne avec Java 24. Le pilote est testé avec Redis 8.10, Redis 8.8, Redis 8.6, Redis 8.4, Redis 8.2, Redis 8.0, Redis 7.4 et Redis 7.2.

Merci à tous les contributeurs qui ont rendu Lettuce 7.7.0.RELEASE possible.

📗 Liens Documentation de référence : https://lettuce.io/core/7.7.0.RELEASE
