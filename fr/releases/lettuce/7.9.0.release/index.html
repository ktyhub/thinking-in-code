laitue 7.9.0.RELEASE

L'équipe Lettuce est heureuse d'annoncer la version mineure de Lettuce 7.9.0 !

Lettuce 7.9.0 prend en charge Redis 2.6+ jusqu'à Redis 8.x. En termes d'exécution Java, Lettuce nécessite au moins Java 8 et fonctionne avec Java 24. Le pilote est testé avec Redis 8.10, Redis 8.8, Redis 8.6, Redis 8.4, Redis 8.2, Redis 8.0, Redis 7.4 et Redis 7.2.

Merci à tous les contributeurs qui ont rendu la laitue 7.9.0.RELEASE possible.

📗 Liens Documentation de référence : https://lettuce.io/core/7.9.0.RELEASE

  • Correction de la validation de l'argument de destination GEODIST par @codingkiddo dans https://github.com/redis/lettuce/pull/3934

  • RedisPublisher ne doit pas générer d'erreur lorsque l'état change simultanément #3942 par @zenios dans https://github.com/redis/lettuce/pull/3943
  • MultiOutput interrompu pour les valeurs booléennes par @Dgramada dans https://github.com/redis/lettuce/pull/3932
  • Analyse JSON.NUMINCRBY interrompue pour RESP2 par @Dgramada dans https://github.com/redis/lettuce/pull/3933
