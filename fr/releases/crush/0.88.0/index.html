écraser v0.88.0

#.crushrc est là ! Hé! J'espère que tout le monde a passé une bonne semaine. Nous avons été plutôt productifs chez Charm et nous publions des trucs sympas aujourd'hui.

Configuration Bash ! (.crushrc)

Oui, .crushrc est arrivé ! Votre configuration JSON existante fonctionne toujours, mais nous venons de commencer à migrer vers quelque chose de beaucoup plus flexible ! Un exemple expliquant pourquoi c'est cool : si vous gérez la configuration Crush dans un dépôt dotfiles, vous pouvez toujours avoir des remplacements spécifiques à la machine en utilisant source pour appeler un fichier séparé qui sera dans votre .gitignore. Je suis sûr qu'il existe de nombreux autres cas d'utilisation. Pour lire la documentation complète à ce sujet, lire ce document. Regardez une capture pour avoir une idée de son apparence :

# Add Ollama.
provider add ollama --type ollama --base-url "http://localhost:11434/v1"

# Register a model on Ollama.
model add ollama/llama3.3 --name "Llama 3.3" --context-window 128000

# Auto-approve some tools.
permissions allow view edit

# Add an MCP server
mcp add github \
  --type http \
  --url "https://api.githubcopilot.com/mcp/" \
  --header Authorization "Bearer $GITHUB_TOKEN"

# Load some extra config
source "$XDG_CONFIG_HOME/squid-config.sh"

# Change config based on the machine you're on.
if [[ $HOSTNAME == "babysquid" ]]; then
    option skill-path "$HOME/squid-skills"
fi

Vous souhaitez donner votre avis ? Rejoignez la chaîne #crush sur [Discord] (https://charm.land/discord).

Meilleure prise en charge d'AWS Bedrock SSO

@jan-xyz a fait un excellent travail pour donner vie à celui-ci ! Lors de l'utilisation d'AWS Bedrock via SSO, les jetons expirent avec le temps et doivent être actualisés. Crush dispose désormais d'une configuration et d'une UX appropriées pour l'authentification, et il apparaîtra chaque fois que les jetons doivent être actualisés. Pour en savoir plus, voir #2886. <img width="572" height="231" alt="Capture d'écran 2026-07-31 à 18 04 21" src="https://github.com/user-attachments/assets/993034d2-89d2-42f4-ba9c-30b01a1debd6" />

Récupération d'agent plus fiable

@sven2718 a contribué à de meilleures tentatives de recherche lorsqu'elles ne fonctionnent pas du premier coup. Les recherches seront désormais plus fiables, en particulier lorsque vous en effectuez plusieurs sur une courte période de temps.

Correction pour Fable 5

@ sven2718 a également contribué à un correctif pour Fable 5. Lorsqu'Anthropic décide de rejeter votre invite pour des raisons de sécurité, nous afficherons désormais un message d'erreur approprié dans Crush. Avant, Crush s'arrêtait simplement sans expliquer pourquoi.

Crush compile désormais sur IlluminOS

Vous n'avez jamais entendu parler d'IllumiOS ? Ni aucun d'entre nous chez Charm, mais @timotheosh a ajusté le code pour s'assurer qu'il y est compilé maintenant ! Go compile dans de nombreux environnements, et c'est toujours amusant de voir Crush travailler sur plus de systèmes d'exploitation ! Au fait, savez-vous que vous pouvez utiliser Crush sur Android ? :robot:

MCP OAuth amélioré

Dans la dernière version, nous avons fourni la prise en charge de l'authentification OAuth pour les MCP. @BrunoKrugel a apporté quelques correctifs pour que davantage de MCP nécessitant OAuth fonctionnent comme prévu.

Correctifs agents

De nombreuses corrections ont également été apportées à Crush en tant qu'agent. Certains d'entre eux ont été réalisés sur Fantasy et apportés à Crush.

Nouveaux modèles Hyper

Non moins important, nous continuons à apporter des mises à jour à Hyper, qui est plus stable que jamais et propose désormais Minimax M3 et Qwen3.7-Flash.

Il s'est passé beaucoup de choses cette semaine ! Nous espérons que vous apprécierez et continuez à écraser :tm: ! Charme ##Changelog
