écraser v0.102.0

Canaux, invites personnalisées et renforcement du serveur

Il y a tellement de bonnes choses dans cette version et nous en sommes vraiment fiers. Continuez à lire pour en savoir plus.

Invites BYO

Enfin, vous pouvez remplacer les invites du système par… ce que vous voulez. Et pas seulement l'agent principal, mais aussi des invites pour les sous-agents, la planification, le compactage, les titres de session et crush init :

option prompt coder ~/.config/crush/prompts/coder.md.tpl
option prompt summary prompts/summary.md

Vous pouvez définir l'invite dans la configuration globale, remplacer par projet dans la configuration locale ou remplacer l'invite avec --prompt name=path. Pour en savoir plus sur les invites, consultez [la documentation] (https://github.com/charmbracelet/crush/blob/main/docs/config/README.md#option-prompt).

Rouler dans la nuit

Crush est désormais livré avec un thème KITT inspiré de Knight Rider, gracieuseté de @cdancy. Rosé Pine Classic, Moon et Dawn sont désormais également disponibles.

<p><img width="730" height="528" alt="image" src="https://github.com/user-attachments/assets/2c139b67-92a3-4600-9278-761c813699ed" /></p> ## Nerd dehors avec les polices Nerd Enfin des polices nerd ! Le support est détecté automatiquement, donc ils ne casseront jamais votre terminal non plus ! Crush utilise désormais leurs icônes, le statut LSP et Git inclus. Notez que si vous exécutez Crush via SSH, vous devrez activer les polices Nerd `option ui nerd-fonts true`. ```bash # Hate nerd fonts? You can turn 'em off, too. option ui nerd-fonts false ``` ## Chaînes [Channels](https://code.claude.com/docs/en/channels-reference) sont une fonctionnalité MCP expérimentale de Claude, désormais disponible dans Crush grâce à l'excellent travail de @joestump. En bref, les canaux permettent aux serveurs MCP de transmettre des événements dans votre session au fur et à mesure qu'ils se produisent. ```bash crush --channels server:webhook --channels server:signal ``` Ou allumez-en un en permanence dans votre `crushrc` : ```bash # crushrc mcp add webhook \ --type http \ --url https://example.com/mcp \ --channel true ``` Crush utilise le même protocole que [Claude Channels](https://code.claude.com/docs/en/channels-reference), donc les serveurs de canaux existants devraient simplement fonctionner™. ## Renforcement du serveur Le mode serveur Client est désormais plus robuste que jamais. Il est maintenant plus sécurisé et comporte une tonne de petites améliorations, des correctifs de correction et des corrections de bugs, en particulier sous Windows. ## Et bien plus encore - Le mode Sysadmin n'est plus un <kbd>shift+tab</kbd> après yolo. - Les invites en file d'attente apparaissent dans la pilule au moment où vous les soumettez. - Le modèle peut utiliser `sudo`, vous pouvez donc approuver avec Touch ID. - Les refus de contenu sont retentés automatiquement. - Des séances que Claude ne cessait de refuser de travailler à nouveau. - Les modèles Ollama qui ne peuvent pas appeler d'outils n'apparaissent plus dans la liste des modèles. - Les commandes qui laissent les processus enfants derrière ne se bloquent plus. - Les minuteries fonctionnent ensemble et les minuteries des outils en cours d'exécution continuent jusqu'à ce que l'outil réponde. - Changer de thème ne restitue plus l'intégralité de la conversation. - Supprimer une session conserve votre place dans la liste. - Les messages rejoués conservent leurs espaces et les cartes de plan s'alignent correctement.
