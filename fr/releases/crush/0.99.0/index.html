crush v0.99.0

écraser v0.99.0

Crochets, Catwalk v3 !

Un gros ! Crush fonctionne désormais sur Catwalk v3, les hooks peuvent voir chaque partie d'une course et les éditeurs qui hébergent Crush disposent d'un tout nouvel ensemble d'outils pour se sentir comme chez eux.

Des crochets, partout 🪝

Les crochets ne sont plus seulement une question d’outils. Ils peuvent désormais suivre l'intégralité de la course : sessions, tours, autorisations et bien plus encore !

Les hooks peuvent désormais également intervenir après l’exécution d’un outil. Supprimez les secrets de la sortie avant que le modèle ne les voie, ajoutez une note ou arrêtez le tour. Si l'outil a déjà fait quelque chose qu'il n'aurait pas dû faire, votre hook peut indiquer au modèle "vous avez commis sans exécuter les tests".

hook add TurnEnd --name "ding" --command 'afplay /System/Library/Sounds/Glass.aiff'

Vous pouvez en savoir plus ici

Client/mode serveur

Si vous créez quelque chose qui exécute Crush à l'intérieur, cette version est faite pour vous :

  • Thèmes hôtes : l'application hôte peut thématiser le TUI sur le serveur API, afin que Crush corresponde à vos applications.
  • Contexte de l'hôte : l'hôte peut indiquer à Crush ce qui est visible, comme les fichiers ouverts, et ces fichiers apparaissent dans les complétions.
  • Ajouter à l'invite suivante : clients peut ajouter le texte que l'agent lit avec l'invite suivante, sans démarrer une exécution ni encombrer le chat.
  • Visualisation partagée : les clients peuvent voir quelle session les autres clients consultent.
  • Autorisations canalisées : définissez CRUSH_PERMISSIONS_PIPED=1 et l'hôte répond aux invites d'autorisation, de sorte qu'on ne vous le demande pas deux fois.
  • Les adresses http:// fonctionnent comme un alias pour tcp:// lors du démarrage du serveur.

Serveur plus stable

  • SIGHUP recharge désormais la config au lieu d'arrêter le serveur.
  • La fermeture du terminal ou l'arrêt de Crush via un gestionnaire de services s'arrête désormais correctement, de sorte que le travail en cours est enregistré au lieu de rester bloqué.

Petit aperçu de [Catwalk v3][catwalk] :

Crush parle désormais [Catwalk v3][catwalk]. Le fournisseur type décrit le format API utilisé par un fournisseur, et non son créateur :

  • completions : API compatibles OpenAI
  • responses : OpenAI, ou tout ce qui passe par celui-ci
  • messages : API compatibles anthropiques

Votre configuration est migrée automatiquement lors de son chargement, donc openai, openai-compat et anthropic continuent de fonctionner. Aucune modification nécessaire.

Les drapeaux provider add et model add se succèdent :

crush provider add deepseek \
  --type completions \
  --base-url "https://api.deepseek.com/v1" \
  --api-key "$DEEPSEEK_API_KEY"

crush model add deepseek/deepseek-chat --thinking toggleable --max-attachments 5
  • --can-reason est maintenant --thinking always|never|toggleable
  • --max-attachments N est nouveau
  • Les niveaux de raisonnement affichent des noms conviviaux dans le sélecteur, comme "X-High".

[passerelle] : https://github.com/charmbracelet/catwalk/releases/tag/v3.0.0

C'est tout pour l'instant ! Charme XX 💫

<summary>Vérification des artefacts</summary>

Tout d'abord, téléchargez les fichiers Fichier checksums.txt et Fichier checksums.txt.sigstore.json, par exemple avec wget :

wget 'https://github.com/charmbracelet/crush/releases/download/v0.99.0/checksums.txt'
wget 'https://github.com/charmbracelet/crush/releases/download/v0.99.0/checksums.txt.sigstore.json'

Ensuite, vérifiez-le en utilisant cosign :

cosign verify-blob \
  --certificate-identity-regexp '^https://github.com/charmbracelet/crush/\.github/workflows/(release|nightly)\.yml@' \
  --certificate-oidc-issuer 'https://token.actions.githubusercontent.com' \
  --bundle 'checksums.txt.sigstore.json' \
  ./checksums.txt

Si le résultat est Verified OK, vous pouvez l'utiliser en toute sécurité pour vérifier les sommes de contrôle d'autres artefacts que vous avez téléchargés à partir de la version à l'aide de sha256sum :

sha256sum --ignore-missing -c checksums.txt

C'est fait ! Vos artefacts sont maintenant vérifiés !
