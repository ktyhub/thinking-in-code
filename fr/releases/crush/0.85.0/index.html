Si vous avez des questions, nous avons des réponses

Cette version nous apporte (enfin !) un outil de questions ainsi qu'un tas de corrections de bugs et de subtilités. Allons-y!

L'outil de questions

Alors ! Crush est désormais livré avec un outil de questions de première classe, utile lorsque les LLM veulent vous griller. L'outil de questions se présente sous de nombreuses formes, comme un choix unique, un choix multiple, un texte sous forme libre et oui/non. Les questions peuvent également être regroupées pour créer un formulaire.
