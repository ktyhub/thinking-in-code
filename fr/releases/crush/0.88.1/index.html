écraser v0.88.1

Il est temps de procéder à une correction de bugs

Cette version est axée sur la stabilité et la qualité de vie avec de nombreux correctifs autour de MCP, du serveur client et de bricoles. Voici ce qu'il y a à l'intérieur :

  • UX : Taper clear dans la commande correspondra à Summarize ; merci, @joestump !
  • LSP : @piakdev a corrigé un cas où LSP pouvait paniquer
  • MCP : Les MCP à chargement lent peuvent bloquer l'envoi des messages : nous réduisons le délai d'expiration par défaut
  • Serveur-Client : MCP OAuth ne fonctionnait pas en mode serveur-client ; maintenant c'est le cas
  • Serveur-Client : Les Clients dans le même espace de travail pouvaient s'entre-tuer : plus maintenant
  • Server-Client : Lorsque le serveur fonctionne sur TCP, les frappes au clavier n'atteignent plus le serveur et ne ralentissent plus
  • Hyper : Ajout de diverses petites améliorations pour une meilleure UX Merci d'utiliser Crush. Bon week-end ! Charme 💌 ##Changelog
