spring-integration v7.2.0-M1

Pré-version Publié20 août 2026 Sourcespring-projects/spring-integration Anglais original

Cette page est traduite automatiquement. Le texte anglais original fait foi.

intégration à ressort v7.2.0-M1

:star: Nouvelles fonctionnalités

  • JdbcMetadataStore.putIfAbsent() renvoie null pour une ligne existante avec un METADATA_VALUE nul #11248
  • Correction des dépréciations liées à RestTemplate dans le module HTTP #11234
  • Options permettant d'utiliser de simples confirmations d'éditeur dans les points de terminaison sortants AMQP #11194
  • Conserver les en-têtes d'origine dans DefaultErrorMessageStrategy #11160

## :lady_beetle : corrections de bugs

  • CVE-2026-47856 : JsonToObjectTransformer résout l'en-tête de message json__TypeId__ en une classe arbitraire sans liste verte #11350
  • CVE-2026-47859 : allocation de mémoire illimitée dans RFC6587SyslogDeserializer (cadrage par octets) – DoS distant #11349
  • CVE-2026-47862 : ZipTransformer utilise l'en-tête file_name pour créer le chemin workDirectory sans désinfection #11348
  • CVE-2026-47864 : Désérialisation Java non sécurisée dans SerializingHttpMessageConverter — exécution de code à distance #11347
  • CVE-2026-59324 : Correction d'une fuite d'en-tête de message croisé dans fluxTransform() sous concurrence #11346
  • CVE-2026-59321 : Correction de AbstractScriptExecutor pour les moteurs non thread-safe #11345
  • CVE-2026-59322 : remplacez la valeur par défaut d'EmbeddedHeadersJsonMessageMapper par aucun en-tête #11344
  • CVE-2026-59311 : Empêcher les transformateurs zip d'écrire des fichiers temporaires dans un lien symbolique #11343
  • CVE-2026-59292 : Ajouter un contrôle des autorisations des fichiers du magasin de métadonnées #11342
  • CVE-2026-59307 : JdbcMessageStore : nouveau mapper sur setBeanClassLoader #11341
  • CVE-2026-59293 : définissez la version par défaut de SMB sur SMB202 #11339
  • CVE-2026-59274 : Ajout d'options de contrainte de taille à UnzipTransformer #11336
  • CVE-2026-47880 : Ignorer les propriétés par défaut dans toHeaders #11331
  • CVE-2026-47861 : l'adaptateur UDP envoie un accusé de réception à l'hôte : port fourni par l'attaquant analysé à partir du corps du paquet, même lorsque l'accusé de réception = faux [#11328] (https://github.com/spring-projects/spring-integration/issues/11328)
  • FileWritingMessageHandler : la création automatique simultanée du même répertoire de destination échoue avec "Le répertoire de destination [...] n'a pas pu être créé." #11253
  • Correction de l'isolation des tests ZookeeperLockRegistry et de la gestion des interruptions #11244
  • JdbcMetadataStore putIfAbsent peut rester bloqué dans la boucle while sur la base de données MySQL. #10847
