intégration à ressort v7.2.0-RC1

:star: Nouvelles fonctionnalités

  • Ajout de l'implémentation de l'adaptateur de canal sortant MQTT #11530
  • Faire SerializingHttpMessageConverter pour exiger allowedPatterns de son cteur #11480
  • Ajout d'un adaptateur de canal entrant pour MQTT basé sur hivemq #10989
  • Spring Integration JMS DefaultJmsHeaderMapper n'a pas de fonctionnalité pour définir les OutboundHeaderNames et InboundHeaderNames [INT-4412] #8337
  • Fournir un filtre Bean Validation (JSR 303) [INT-4068] #8009
  • Ajout de la prise en charge du proxy à DefaultFtpSessionFactory [INT-2505] #6485
  • FeedEntryMessageSource échoue si les champs de date d'entrée sont nuls [INT-1810] #5797

## :lady_beetle : corrections de bugs

  • Supprimer la trace de pile cassée des erreurs HttpRequestHandlingController #11515
  • Rejeter les messages non convertibles dans les points de terminaison entrants AMQP 1.0 #11500
  • PropertiesPersistingMetadataStore ne réessaye pas de vider après une IOException #11495

## :notebook_with_decorative_cover : Documentation

  • Améliorer la documentation pour les problèmes de sécurité du SerializingHttpMessageConverter #11455
  • Correction de fautes de frappe dans la documentation et XSD #11454
