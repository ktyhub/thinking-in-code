spring-framework v7.0.4

Correctif Publié12 févr. 2026 Sourcespring-projects/spring-framework Anglais original

Cette page est traduite automatiquement. Le texte anglais original fait foi.

cadre à ressort v7.0.4

:star: Nouvelles fonctionnalités

  • Annotations de méthode de cache dans MethodParameter et AnnotatedMethod #36307
  • Prise en charge cohérente de @Lazy en tant que méta-annotation à des profondeurs arbitraires #36306
  • Prise en charge cohérente de @Validated en tant que méta-annotation à des profondeurs arbitraires #36305
  • Laisser les développeurs désactiver les enregistrements par défaut dans HttpMessageConverters #36303
  • Enregistrez quel HandlerInterceptor a lancé l'exception #36281
  • Améliorer les performances des calculs de hashcode pour les mappages de requêtes #36279
  • Améliorer les performances de recherche du bean HandlerMethod #36278
  • Améliorer les performances du mappage de versions #36276
  • Améliorer les performances des mappages de requêtes de modèle unique #36275
  • Améliorer les performances de détermination des groupes de validation #36274
  • Ajouter la méthode de configuration setPackagesToScan à LocalEntityManagerFactoryBean #36270
  • Supprimer la substitution obsolète GraalVM #36257
  • Introduire le rappel beforeRetry avec l'argument RetryState #36245
  • Optimisez NamedParameterUtils#buildValueArray en récupérant paresseusement SqlParameter #36230
  • Autoriser la personnalisation du ProxyFactory dans HttpServiceProxyFactory utilisé pour créer des proxys de service HTTP #36225
  • Fermez systématiquement les flux via try-with-resources dans FileCopyUtils #36223
  • Utiliser les utilitaires Java Files dans FileCopyUtils #36221
  • SqlBinaryValue et SqlCharacterValue devraient prendre en charge le contenu InputStream de longueur indéterminée #36219
  • Prise en charge de la configuration de JtaTransactionManager et SpringBeanContainer sur HibernateJpaVendorAdapter #36216
  • Ajout du wrapper TaskCallback/Callable/Runnable pour les tâches réessayables #36208
  • Affiner YamlProcessor pour autoriser différentes valeurs vides #36207
  • Anticiper la correction de l'avertissement de compilation Kotlin 2.3 #36203
  • Autoriser les processeurs YAML à créer une carte aplatie avec des valeurs nulles incluses #36197
  • Utilisez Reader.transferTo dans FileCopyUtils #36196
  • DataBufferUtils.write() avec NettyDataBuffer sur JDK 25 se bloque indéfiniment #36184
  • Rendre SendToMethodReturnValueHandler et SubscriptionMethodReturnValueHandler personnalisables, pour permettre le transfert des en-têtes de message #36179
  • Présentation de RestClient.ResponseSpec#requiredBody #36173
  • Rendre la portée entièrement configurable dans BeanRegistry/BeanRegistrar #36171
  • ConcurrencyThrottleSupport et interruption du thread #36167
  • Ajoutez des méthodes sendAndReceive surchargées à JmsTemplate pour utiliser la file d'attente de réponses explicites #36162
  • Les attributs WebClient (Reactor) sur le canal Netty ne s'effacent pas après la libération de la connexion #36158
  • Prise en charge de HttpEntity sur ContentRequestMatchers.multipartData #36154
  • Réintroduire WebLogicJtaTransactionManager dans Spring Framework 6.2.x #36151
  • L'interruption pour DefaultMessageListenerContainer n'est pas appliquée de manière cohérente en cas d'échec de la configuration de l'écouteur #36143
  • Prise en charge anticipée de JPA 4.0 EntityAgent (câblage automatique d'un proxy partagé) #36025
  • Compatibilité précoce avec JPA 4.0 et Hibernate ORM 8.0 #35705

## :lady_beetle : corrections de bugs

  • L'argument HttpEntity Controller résolu ne reflète pas les en-têtes HTTP mutés #36298
  • Évitez l'encombrement des verrous dans ConcurrentReferenceHashMap #36293
  • AbstractMessageConverter ne prend pas en charge les caractères génériques dans les types MIME pris en charge #36285
  • Faire fonctionner LocalEntityManagerFactoryBean#setDataSource sur Hibernate ainsi que EclipseLink #36271
  • StompBrokerRelayMessageHandler ne parvient pas à redémarrer en raison d'une pause du contexte de test #36266
  • Un blocage peut se produire lors de l'appel de System.exit au démarrage (contre plusieurs hooks d'arrêt) #36260
  • Indice de ressource manquant pour BeanRegistrar implémentant ImportAware #36242
  • Comportement incohérent avec @Retryable sur les interfaces annotées #36233
  • Netty4HeadersAdapter.remove renvoie une liste vide au lieu de null pour une clé inexistante #36226
  • Le type générique dans AsyncTaskExecutor.submit(Callable<T>) doit être @Nullable #36191
  • EclipseLinkConnectionHandle peut échouer en raison d'une condition de concurrence critique pour l'isolation des transactions #36165

## :notebook_with_decorative_cover : Documentation

  • Supprimer le code obsolète dans la section Redirecting to a resource #36284
  • Correction du formatage dans la documentation sur la conversion des messages HTTP Web MVC #36250
  • Supprimer la documentation obsolète pour spring.context.annotated-bean-reader.create #36241
  • Document @SpringExtensionConfig dans le manuel de référence #36240
  • Correction de la syntaxe JSON dans la documentation de présentation de STOMP #36229
  • Réviser la documentation sur le support JSR-330 dans le manuel de référence #36222
  • Correction des liens vers le guide de l'utilisateur JUnit #36217
  • Correction de la définition des coroutines #36209
  • Correction du javadoc LocalContainerEntityManagerFactoryBean#setPersistenceUnitName #36205
  • Mise à jour de la documentation sur la gestion des barres obliques finales où le niveau de type @GetMapping("/base") est combiné avec le niveau de méthode @GetMapping("/") #36198
  • Mise à jour de la documentation sur le MediaType utilisé pour ProblemDetail #36192
  • Extraire les extraits de DispatcherServlet #36175
  • Remplacez getErrors() par getBindingResult() dans les exemples #36170
  • Affiner la documentation CORS pour correspondre aux dernières modifications #36156
