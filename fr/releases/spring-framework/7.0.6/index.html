:avertissement : Attention requise

  • Tirer parti de ResourceHandlerUtils dans ScriptTemplateView #36458
  • Restaurer ScriptTemplateViewTests #36456
  • Correction du message du journal dans ConfigurationClassBeanDefinitionReader #36453
  • DefaultResponseErrorHandler - setMessageConverters() non appelé via RestClient #36434

  • Invoquez resolveContextLoader() une seule fois dans AbstractTestContextBootstrapper #36425
  • Aligner davantage l'annotation synthétisée toString() avec les JDK modernes #36417
  • Introduire setDefaultCharset() dans AbstractResourceBasedMessageSource #36413
  • Prise en charge du mode de rinçage JPA 4.0 "explicite" #36401
  • Prise en charge du paramètre defaultHtmlEscape à l'échelle de l'application dans WebFlux RequestContext #36400

  • Évitez les vidages en double dans les implémentations de HttpMessageConverter #36383
  • Ajout de la prise en charge d'OutputStream sans vidage à StreamUtils #36382
  • Faciliter l'obtention d'InputStream depuis RestClient #36380
  • RuntimeHintsWriter doit être conforme à reachability-metadata-schema-v1.2.0.json #36379
  • Facilitez la création d'un HttpExchangeAdapter personnalisé #36374

  • Autoriser l'enregistrement des métadonnées lambda sérialisées via RuntimeHints #36339
  • Refactoriser calculateHashCode dans RequestMappingInfo #36325

## :lady_beetle : corrections de bugs

  • MetadataReader ne contient pas le nom de classe pour les classes imbriquées Kotlin avec Java 24+ #36451
  • Protégez-vous contre les valeurs d'identifiant/d'événement non valides dans les événements envoyés par le serveur #36440
  • L'analyse des composants échoue avec le type d'annotation non chargeable avec un tableau d'énumérations sur Java 25 #36432
  • En-têtes ServletServerHttpRequest en double #36418
  • Message de débogage incomplet dans ConfigurationClassBeanDefinitionReader #36410
  • État ApplicationEventMulticaster incohérent après la suppression de ApplicationListener implémenté par FactoryBean #36404
  • Propager la longueur maximale de la trame à la session WebSocket #36370
  • Arrêt progressif de SimpleAsyncTaskExecutor #36362
  • En-têtes de réponse en double avec la méthode de contrôleur ResponseEntity<Mono<T>> (ou fonction de suspension Kotlin) #36357
  • HttpServiceProxyFactory renvoie LinkedHashMap au lieu du type cible pour la méthode avec un type de retour générique #36326
  • HttpMediaTypeException levée lors du calcul des types de médias compatibles #36300

  • Documenter des astuces pour éviter les problèmes liés à la configuration du contexte par défaut ignorée dans les tests #36392
  • Exemples d'opérateurs SpEL polonais dans les documents de référence #36367
