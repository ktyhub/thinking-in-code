:star: Nouvelles fonctionnalités

  • Évitez trop de tentatives d'accès aux personnages dans AntPathMatcher #36886
  • Suivre les opérations lors de l'évaluation de l'expression SpEL #36887
  • Assurez-vous que les getters ont des types de retour non nuls dans SpEL #36888
  • Exposer ClassLoader de DefaultDeserializer #36839
  • Affiner la résolution du nom de vue par défaut #36794
  • Affiner les convertisseurs Jackson JMS #36792
  • Améliorer les vérifications des règles ABNF dans RfcUriParser #36788
  • Détecter les instances NullValue désérialisées personnalisées dans AbstractValueAdaptingCache #36728
  • Avertir contre les emplacements de ressources statiques dangereux dans MVC et WebFlux #36693
  • Compatibilité constante avec Woodstox comme alternative à Xerces #36683

## :lady_beetle : corrections de bugs

  • Les données sont perdues pour le DataBuffer joint dans DataBufferUtils #36874
  • CronExpression saute des jours pendant l'intervalle d'heure d'été de minuit #36873
  • Problème de concurrence avec le champ de cookie partagé dans CookieLocaleResolver#setLocaleContext #36870
  • L'événement envoyé par le serveur ne prend pas en charge les commentaires sur plusieurs lignes #36867
  • Régression dans 6.2.0+ : ConfigurationClassParser supprime incorrectement le bean analysé par les composants lorsque la même classe est également enregistrée sous un nom différent via XML #36849
  • Bean Background Bootstrap et Lazy Init #36847
  • Correction du traitement des balises JSP #36798
  • Correction des capacités de traitement des scripts #36796
  • Échec de l'analyse du type MIME avec les valeurs de paramètres citées #36734
  • La dépendance circulaire entre les beans créés par le fournisseur est ignorée en silence au démarrage #36732
  • "Jeton de corps non attendu" non déterministe dans org.springframework.http.codec.multipart.PartGenerator #36722
  • Régression sur la gestion des paramètres de classe de valeur #36720
  • Collisions de cache dans CachingResourceResolver #36718
  • Suppression inattendue d'un élément de chemin lors de la résolution de ressources versionnées #36699
