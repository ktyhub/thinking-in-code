openai-agents-python v0.22.0

Changements clés

La version 0.22.0 est une version mineure car elle ajoute un renforcement substantiel du temps d'exécution et renforce un contrat de configuration de fournisseur existant. Les applications qui combinent un openai_client explicite avec organization ou project doivent déplacer ces valeurs vers AsyncOpenAI client.

Points forts :

  • Supprime la sortie de l'outil de fonction du terminal rejetée par les garde-fous de sortie de l'agent à partir de l'état SDK rejouable et persistant.
  • Lève ModelBehaviorError pour les réponses sans streaming avec le statut de terminal failed ou incomplete.
  • Rejette les options de fournisseur conflictuelles lorsque OpenAIProvider reçoit un client explicite.
  • Isole la comptabilité d'utilisation entre les points de contrôle RunState indépendants tout en préservant l'agrégation des agents imbriqués.
  • Développe les agents enregistrés via handoff(agent) dans les graphiques générés.
  • Clarifie le comportement de copie superficielle existant de Agent.clone() et RealtimeAgent.clone().
