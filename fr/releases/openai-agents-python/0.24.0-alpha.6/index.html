openai-agents-python v0.24.0-alpha.6

Installer l'aperçu

Utilisez la norme CPython 3.10–3.14 dans un environnement virtuel. Ces roues incluent le runtime natif ; aucune chaîne d'outils Rust ou génération de sources n'est nécessaire. Cet aperçu est distribué via les versions GitHub, et non via PyPI.

Exécutez la commande pour votre plateforme :

Linux x86_64 (glibc 2.39 ou plus récent)

python -m pip install "https://github.com/openai/openai-agents-python/releases/download/v0.24.0-alpha.6/openai_agents-0.24.0a6-cp310-abi3-manylinux_2_39_x86_64.whl"

macOS 11 ou version ultérieure sur Apple Silicon

python -m pip install "https://github.com/openai/openai-agents-python/releases/download/v0.24.0-alpha.6/openai_agents-0.24.0a6-cp310-abi3-macosx_11_0_arm64.whl"

Windows x64

python -m pip install "https://github.com/openai/openai-agents-python/releases/download/v0.24.0-alpha.6/openai_agents-0.24.0a6-cp310-abi3-win_amd64.whl"

Les roues ne sont pas fournies pour les Mac Intel, ARM Linux, ARM Windows, Alpine/musl, PyPy ou Python à filetage libre. Les noms de fichiers cp310-abi3 prennent également en charge la norme CPython 3.11 – 3.14.

Vérifiez la version installée et le module natif :

python -c "from importlib.metadata import version; import agents._native; print(version('openai-agents'))"

Attendez-vous à 0.24.0-alpha.6 ou à son orthographe d'emballage équivalente Python, 0.24.0a6. SHA256SUMS contient des sommes de contrôle pour les trois roues.

Release note

Changements depuis 0.24.0-alpha.5. Cet aperçu étend le contrôle des conversations, la récupération d'état et les stratégies d'outils, et inclut les modifications publiques de API.

Ajouté

  • Contrôle des travaux soumis via un Turn capturé, avec get_result(), events() passif, traitement manuel des demandes, pilotage et annulation. Mettez en file d'attente les invites avec Session.submit(..., if_busy="queue") ou dirigez le virage actif avec if_busy="steer".
  • Ajoutez LocalStorage pour rouvrir les conversations à partir d'un profil local et étendez la capture et la récupération portables SessionState. Ajoutez des fourches inactives, des résumés de compactage fournis par l'appelant et des vérifications de la prise en charge des fonctionnalités et de l'état de préparation des points de contrôle. Les profils LocalStorage ne peuvent pas exporter de points de contrôle portables.
  • Ajout de NativeOutput pour une sortie stricte native et PromptedOutput pour JSON validé dans Python. Le max_retries en option effectue des corrections limitées sans outils ni relecture de la tâche. LocalStorage nécessite max_retries=0.
  • Gérez les demandes d'outils manuels en direct et reprenez les demandes en attente prises en charge à partir des points de contrôle. Ajoutez une récupération expérimentale de tâches externes via agents.experimental.deferred et un adaptateur de tâches MCP en option.
  • Sélectionnez des outils pour chaque étape de soumission ou de modèle dans les autorisations d'ouverture de la session. Ajoutez une recherche Web native, des listes de contrôle pour les enfants natifs et des objectifs natifs pour les sessions de stockage local.
  • Validez les annotations de retour de l'outil Python et ajoutez des politiques d'outil pour inspecter les arguments et les résultats. Étendez la prise en charge native de MCP avec le remplacement d'arguments, les transformations de résultats et les interactions de formulaire et d'URL gérées par l'application sur les chemins HTTP, stdio et WebSocket de modèle pris en charge.
  • Ajoutez NetworkPolicy pour les commandes natives sur les exécuteurs Linux et macOS pris en charge, sous réserve des limites du réseau et des sockets Unix de chaque plate-forme. Gérez la durée de vie de l'exécuteur distant via un Environment fourni lors de l'ouverture d'une session ou de l'exécution d'un agent.
  • Activez les approbations d'enfants natifs et les demandes de formulaires avec NativeAgents(interactions=True). Les enfants continuent de partager les outils et le contexte d'application de la session.
  • Configurez l'exportation native OpenTelemetry et inspectez les observations saisies. NativeError expose désormais les codes d'état des fournisseurs, les codes d'erreur, les ID de demande et les catégories d'échec disponibles.
  • Testez de vraies sessions SDK et des outils Python par rapport aux réponses scriptées locales avec agents.testing.ScriptedResponses, sans modèle live ni clé API.

Modifications de API

  • Utilisez Agent.run() ou Agent.run_sync() pour les appels ponctuels ; les alias Runner redondants ont été supprimés.
  • Remplacez Turn.wait() et Session.wait() par Turn.get_result() sur le tour capturé.
  • Remplacez Session.interrupt() par Turn.cancel() pour un tour racine ou Session.cancel_all() pour toute la session.
  • Renommez Subagent.submit() en Subagent.start(). Unifiez les rappels Python et les outils manuels sous FunctionTool ; supprimez la déclaration ManualTool distincte.
  • Les déclarations d'agent sont immuables. Créez un nouvel agent pour modifier les valeurs par défaut, utilisez with_output_type() pour une variante de type de sortie ou utilisez les mises à jour de session inactives prises en charge pour une conversation ouverte.
  • La sélection d'outils et les mises à jour de session ne peuvent pas étendre les autorisations capturées lors de l'ouverture de la session. Les sessions restaurées utilisent les outils d'application, les informations d'identification et les politiques actuels.

Corrigé

  • Gardez le résultat de chaque tour capturé stable dans les pilotages acceptés, les continuations natives et les soumissions ultérieures. Préservez les points de contrôle manuels ponctuels, les réponses d’interaction correspondantes et l’état de réparation des sorties au-delà des limites de sauvegarde et de restauration prises en charge.
  • Améliorer l'annulation des enfants natifs et le nettoyage de session. Arrêtez le travail natif lorsque les stratégies de résultats expirent et préservez les raisons d’échec des stratégies lors de la communication des résultats racine et enfants.
  • Rejetez les enveloppes de résultats mal formées de l'outil Python et préservez les erreurs du serveur grâce aux transformations de résultats MCP. Prend en charge les formulaires d'extension OpenAI imbriqués et l'exportation de télémétrie HTTP avec les certificats client.

Documentation et exemples

  • Déplacez la source d'aperçu vers le référentiel public. Recentrer les instructions d'installation sur les roues prédéfinies et déplacer les instructions de construction du SDK vers le CONTRIBUTING.md.
  • Ajoutez des exemples pour les applications de navigateur, le streaming AG-UI, les tâches différées, l'évaluation, l'observabilité et les tâches d'application courantes. Supprimez les guides de migration de la documentation préliminaire.
