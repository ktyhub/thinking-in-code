openai-agents-python v0.20.0

Changements clés

La version 0.20.0 est une version mineure car elle modifie le modèle implicite par défaut et inclut une migration de dépendance MCP potentiellement révolutionnaire pour les applications avec des transports HTTP locaux personnalisés. MCP v1 reste pris en charge et les applications concernées peuvent migrer vers httpx2 ou épingler mcp<2.

Points forts :

  • Le modèle par défaut est désormais gpt-5.6-luna ; les modèles explicites, les remplacements de niveau d'exécution et OPENAI_DEFAULT_MODEL continuent de prévaloir.
  • Les connexions MCP locales prennent en charge MCP Python SDK v1 et v2 sur les transports HTTP stdio, SSE et Streamable.
  • Les applications utilisant l'authentification HTTP MCP personnalisée ou les usines client doivent utiliser les types HTTP appartenant à la version majeure de MCP installée, ou la broche mcp<2.
  • RunState.add_input() peut organiser une entrée utilisateur durable avant la reprise d'un appel de modèle, avec prise en charge du garde-corps, de la persistance et de la sérialisation.
  • La validation de montage Sandbox ajoute des accusés de réception explicites d'exposition des informations d'identification et préserve les contrats d'erreur rédigés sans sérialiser l'autorité d'identification.
  • La transcription d'entrée en temps réel prend en charge les paramètres de transcription GA pour gpt-live-transcribe, gpt-transcribe et gpt-realtime-whisper.
