composer v5.7.0

Ce qui a changé

ℹ️ Avertissement pour les utilisateurs de Compose en tant que bibliothèque : Up exécute désormais ses phases de création et de démarrage comme un plan unique sur un seul instantané de démon, pour up -d (#14290) et up interactif (#14305), comme scale, regardez les reconstructions et start le font déjà (#14291, #14296). Le CLI se comporte comme avant. Si vous appelez api.Compose.Up depuis votre propre programme :

  • Up valide désormais ses options en premier, avec les mêmes règles que les flags CLI : UpOptions.Validate() renvoie un *api.IncompatibleOptionsError (errors.Is(err, api.ErrIncompatibleOptions)) pour Start.Wait combiné avec Start.Attach, et pour un Up détaché (pas de Start.Attach) combiné avec OnExit, ExitCodeFrom ou Watch. Ces combinaisons étaient auparavant ignorées en silence (#14306).
  • Up travaille sur le projet qui lui est donné et ignore StartOptions.Project.
  • Le démon n'est plus observé entre les deux phases : un conteneur qui se ferme après la construction du plan n'est pas redémarré, et un conteneur supprimé entre les deux fait échouer son démarrage au lieu d'être ignoré. Une erreur de planification de la phase de démarrage échoue désormais avant la création d'un conteneur.
  • Un Up au premier plan donne désormais à un service use_api_socket son /run/secrets/docker/config.json, comme le fait up -d, et affiche la sortie des hooks pre_start.
  • Le menu clavier d'un up interactif n'est plus construit par la bibliothèque : définissez NavigationMenu: true et passez une implémentation avec compose.WithNavigationMenu(...), sinon aucun menu ne s'affiche et un avertissement le dit (#14324).

Autres changements apportés à la surface de la bibliothèque dans cette version : DownOptions.Images est désormais un api.ImagePruneMode (les constantes non typées sont toujours compilées, une variable string nécessite une conversion) et une valeur non valide est rejetée avant que Down ne supprime quoi que ce soit (#14149) ; compose.ServiceHash, compose.NetworkHash et compose.VolumeHash ne sont plus exportés, les helpers ayant migré vers un package interne (#14405) ; api.Compose est désormais assemblé à partir de six interfaces plus petites, avec le même ensemble de méthodes (#14322) ; PushOptions.IgnoreMissing est ajouté.
