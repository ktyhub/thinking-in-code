#kubeflow v1.9.0

Cette version a été coupée pour la version 1.9.0 de Kubeflow Platform.

REMARQUE : les release note suivants sont uniquement pour les composants du référentiel kubeflow/kubeflow.

Changements importants

Tableau de bord central

  • Nettoyer la page d'accueil et les liens de la barre latérale du groupe Kubeflow Pipelines : https://github.com/kubeflow/kubeflow/pull/7583
  • Gérer les contributeurs pour tous les espaces de noms détenus : https://github.com/kubeflow/kubeflow/pull/7582

Carnets Kubeflow

  • Mettre à jour les packages par défaut (Jupyter, VSCode, RStudio, PyTorch, Tensorflow, CUDA, etc) : https://github.com/kubeflow/kubeflow/pull/7590
  • Autoriser les notebooks à s'exécuter avec des contextes de sécurité de pod restreints : https://github.com/kubeflow/kubeflow/pull/7622
