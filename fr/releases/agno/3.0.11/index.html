agno v3.0.11

#Changelog

Nouvelles fonctionnalités :

  • Pipeline de récupération de connaissances : Knowledge.search() exécute désormais un pipeline de récupération de niveaux de connaissances qui peut élargir le pool de candidats avant qu'un reclasseur ne le réorganise, de sorte que les reclasseurs n'ont plus besoin d'être implémentés par base de données vectorielle.
  • MMR Reranker : ajout de MMRReranker (Maximal Marginal Pertinence) en tant que stratégie de récupération qui équilibre la pertinence et la diversité afin que les morceaux quasi-dupliqués n'évincent pas l'ensemble de résultats.
  • Relocalisation de la source de la page : ajout de Knowledge.inspect_page_source / ainspect_page_source et migrate_page_source / amigrate_page_source protégé pour déplacer une source de documentation indexée vers un nouveau nom d'hôte. La migration est un essai à sec par défaut.
  • Recency Reranker : Ajout de RecencyReranker, qui mélange le score de recherche avec une décroissance exponentielle sur un horodatage afin que les révisions les plus récentes dépassent celles remplacées. Construit sur le pipeline de niveau de connaissance, axé sur pgvector.
  • Résultats de l'outil de page typée : ajout de PageCommandResult et PageFileSystem.run_command_result / arun_command_result avec des métadonnées explicites d'erreur, d'exhaustivité et de troncature. Knowledge.get_tools(page_results=True) renvoie les objets SearchResult classés, y compris sous forme de sortie structurée MCP.
  • Y-API : Ajout de YAPI en tant que fournisseur de modèles compatible OpenAI.
  • Étape d'annulation : ajout d'un cancellation_stage lisible par machine (PENDING, EXECUTING, INTERRUPTED ou inconnu) à RunOutput, TeamRunOutput, WorkflowRunOutput et aux schémas d'exécution API, de sorte que clients ne correspondent plus au texte du message d'annulation.
  • OpenAIResponses : Ajout de use_previous_response_id afin que store=True ne force plus le chaînage automatique de previous_response_id.

Améliorations :

  • Schémas des outils MCP : chaque argument des outils AgentOS MCP comporte désormais une description dans son inputSchema, et get_sessions limite limit et page à un minimum de 1.
  • Détection de raisonnement : les ID de modèle en mode réflexion DeepSeek sont reconnus comme des modèles de raisonnement lorsqu'ils sont servis via n'importe quel fournisseur OpenAILike tel que DashScope.
  • Outils : suppression des entrées fantômes Args des docstrings d'outils et correction des noms de paramètres de docstring de streaming dans deux classes de modèles.

Corrections de bugs :

  • Tool Hooks : les hooks de synchronisation qui renvoient function_call(**arguments) fonctionnent désormais dans le chemin d'exécution asynchrone. Auparavant, la chaîne traitait la coroutine non attendue comme le résultat de l'outil et le corps de l'outil ne fonctionnait jamais.
  • Carte serveur MCP : Le mcp=True nu installe désormais la même couche de routage que le MCPConfig, de sorte que la vérification de l'hôte et le préfixe de montage s'appliquent aux deux orthographes. Suppression des en-têtes CORS ETag / If-None-Match non implémentés.
  • Outils MCP : la découverte d'outils sur un ClientSession brut collecte désormais chaque page tools/list au lieu de seulement la première.
  • AG-UI : prend en charge ag-ui-protocol 1.0, y compris le contenu des résultats de l'outil valorisé par liste lors de la reprise.
  • Workflows sur WebSocket : les soumissions épinglées par version ne sont plus mises en file d'attente sans leur code PIN, la propriété de la session est vérifiée sur le chemin d'écriture et un identifiant de session manquant crée une nouvelle session comme HTTP.
  • JSONReader : préserve les racines scalaires de JSON.
  • CSVReader : lit les flux de texte, pas seulement les flux d'octets.
  • CSVReader & FieldLabeledCSVReader : validez page_size avant de lire, afin que les valeurs nulles ou négatives génèrent ValueError au lieu de ne renvoyer silencieusement aucun document.
  • Analyse de sortie structurée : ignorez les accolades fermantes sans correspondance dans la prose lors de l'extraction d'objets JSON de la sortie du modèle.
  • GoogleDriveTools : lisez le texte à l'intérieur de formes groupées et respectez les sauts de ligne lors de l'extraction du texte .pptx.
  • Fichiers UTF-8 : read_yaml_file / write_yaml_file, AntigravityTools et AirflowTools lisent et écrivent désormais des fichiers au format UTF-8, quels que soient les paramètres régionaux.
  • DuckDbTools : échappe aux délimiteurs CSV.
  • TavilyTools : options d'extraction avant.
  • Cookbooks & Docs : Remplacement des liens morts dans les sources de connaissances et correction d'un mot dupliqué dans le guide de migration V3. Ajout d'exemples de mémoire Inspeximus et d'observabilité Confident AI.

Dépréciations :

  • Vector DB Reranker : Le paramètre reranker sur les bases de données vectorielles est obsolète au profit du reranker sur Knowledge, qui s'applique à chaque base de données vectorielle et prend en charge l'async.
