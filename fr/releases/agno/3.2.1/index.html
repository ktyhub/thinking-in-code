#agno v3.2.1 #Changelog

Nouvelles fonctionnalités :

  • Compactages de session : GET /sessions/{session_id}/compactions répertorie les compactages d'une session sur SqliteDb et PostgresDb, le plus récent en premier, avec le nombre de messages chacun remplacé et le nombre de jetons avant et après.
  • Fichiers d'entreprise : les fichiers d'une tâche et les notes partagées peuvent désormais être lus sur le API avec GET /company/tasks/{task_id}/files et GET /company/notes, chacun avec une route /{path} pour lire un fichier. Voir livre de recettes.

Améliorations :

  • LinearTools, DiscordTools et ModelsLabTools : prenez maintenant un timeout (30 secondes par défaut, 120 pour ModelsLab) qui s'applique à chaque requête.
  • ExaTools : prend désormais include_text, exclude_text, user_location, moderation, highlights et subpages.
  • MCPTools : connect() renvoie désormais True lorsqu'il est connecté et False lorsqu'il ne l'est pas.
  • Qdrant : async_insert prend désormais batch_size, comme insert.
  • WebSearchTools et DuckDuckGoTools : les erreurs de recherche reviennent désormais sous la forme d'un résultat JSON.
  • Compétences : les instructions de compétences, les références et les sorties de script en chinois et dans d'autres langues non-ASCII atteignent désormais le modèle sous forme de caractères lisibles.
  • AntigravityTools et AntigravityAgent : désormais par défaut antigravity-preview-09-2026.
  • Slack : default_role donne aux membres Slack qui ne font pas partie de users= les autorisations d'un rôle géré. Chaque membre est toujours enregistré comme lui-même.

Corrections de bugs :

  • SQLTools : Un db_engine que vous transmettez est désormais toujours utilisé, même lorsque les champs de connexion sont également fournis, et run_sql_query renvoie désormais l'erreur de la base de données lors de l'échec de la lecture des lignes de résultat.
  • OpenRouter, Perplexity et Requesty : Les réponses utilisent désormais la propre limite de sortie du modèle lorsque max_tokens n'est pas défini, donc les réponses longues reviennent complètes.
  • OpenRouterResponses : les métriques d'exécution et de message incluent désormais le cost signalé par OpenRouter pour chaque requête.
  • Traces : GET /traces compte désormais les pages à partir de 1, comme les autres itinéraires de trace, et JsonDb et GcsJsonDb appliquent limit lorsqu'aucun page n'est donné.
  • WebSearchTools et DuckDuckGoTools : max_results=0 ne renvoie désormais aucun résultat et search_news applique le modifier.
  • ExaTools : livecrawl atteint désormais Exa, et les résumés et faits saillants d'Exa atteignent désormais le modèle.
  • PostgresDb : si la création d'une table échoue sur PostgresDb ou AsyncPostgresDb, la même instance de base de données la crée désormais lors du prochain appel une fois la cause corrigée.
  • MCPTools : Un connect() en échec ou annulé ferme désormais la connexion et tout serveur stdio qu'il a démarré.
  • Qdrant : insert(batch_size=...) envoie désormais des documents par lots de cette taille.
  • CodexAgent : les demandes d'autorisation et les questions natives fonctionnent désormais avec openai-codex 0.163.0 et versions ultérieures.
  • DaytonaTools : agno[daytona] installe désormais un Daytona SDK pris en charge par DaytonaTools (daytona<1), et l'erreur d'importation nomme cette version.
  • Mistral : agno[mistral] ignore désormais httpx2 2.16.1, donc MistralChat et MistralEmbedder importent proprement.
  • FileTools et Workspace : read_file renvoie désormais un fichier entier contenant exactement les lignes max_file_lines.
  • PageMarkdownChunking : les titres qui se terminent par un # littéral, comme C#, le conservent désormais dans le fil d'Ariane et dans la ligne de contexte de la page.
  • DocxReader et PPTXReader : les fichiers Word et PowerPoint lus à partir d'un flux temporaire, comme le UploadFile.file de FastAPI, renvoient désormais leur contenu.
  • ModelsLabTools : L'attente des médias générés s'arrête désormais à max_wait_time.
  • Sambanova : La valeur par défaut est désormais Meta-Llama-3.3-70B-Instruct, donc cela fonctionne sans définir id.
  • Slack : Super Agent démarre désormais sous AgentOS(authorization=...) sans users= ; les membres qui ne font pas partie de users= peuvent discuter et les actions nécessitant une autorisation sont refusées à moins que default_role ne l'accorde.
