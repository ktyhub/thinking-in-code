<summary>Release Note</summary>

Cherry Studio 2.2.1 - Tâches à distance, fournisseurs de recherche et correctifs d'agent

✨ Nouvelles fonctionnalités

  • [Tâches] Les clients distants peuvent découvrir les conversations sur les résultats des tâches planifiées et interroger les planifications des tâches, l'historique des exécutions et les résumés limités. Les conversations de tâches restent détectables une fois les enregistrements d'exécution nettoyés.
  • [Modèles] Rapid-MLX est disponible en tant que fournisseur local intégré sans clé.
  • [Recherche Web] Ajout des fournisseurs de recherche par mot-clé SerpKite et StepFun, et Exa peut désormais récupérer le contenu d'une URL via son contenu API.
  • [Fichiers] Déposer un fichier Markdown (.md, .markdown, .mdx) sur la fenêtre de l'application l'ouvre dans l'aperçu en lecture seule.
  • [Agent] Les installations du système et des packages globaux demandent désormais une approbation dans les modes normaux et s'exécutent en accès complet, au lieu d'être bloquées dans tous les modes.
  • [Agent] Les agents et les assistants peuvent utiliser une image téléchargée comme avatar, affichée dans les catalogues, les sélecteurs, les conversations, les en-têtes de message et les icônes de l'onglet Travail. Les avatars emoji existants restent inchangés.
  • [Agent] L'espace de travail et les groupes d'agents peuvent être épinglés dans la section épinglée supérieure tandis que leurs tâches restent extensibles.
  • Les appels [Agent] Utilisation de l'ordinateur affichent les applications qu'ils ont utilisées et les détails de la session affichent les mêmes icônes d'application.
  • Les appels de sous-agent [Agent] peuvent nommer à la fois un fournisseur et un modèle, et la ligne de sous-tâche affiche le modèle demandé.
  • [Composer] Avec le rendu d'entrée Markdown activé, Markdown est prévisualisé en direct lors de la saisie dans Chat, Agent et dans la barre de composition de sélection ; les marqueurs apparaissent lorsque le curseur les atteint et le texte envoyé reste inchangé.
  • [Composer] Dans l'aperçu Markdown, le texte sélectionné peut être mis en gras, en italique ou en code en ligne avec Cmd/Ctrl+B, Cmd/Ctrl+I et un backtick.
  • [Composer] Dans l'aperçu Markdown, les blocs de code clôturés s'affichent sous la forme d'une région de code en surbrillance, avec Entrée insérant une nouvelle ligne, une indentation de tabulation, un appariement automatique entre crochets et des variables ou des raccourcis restant littéraux à l'intérieur de la clôture.
  • [Navigateur] Les nouveaux onglets du navigateur intégré peuvent démarrer à partir d'une page vierge, de la dernière page ouverte ou d'une URL personnalisée.
  • [Connaissances] Les fichiers OpenDocument (.odt, .odp, .ods) et RTF (.rtf) peuvent être ajoutés comme sources de connaissances. -[API Gateway] Les modèles d'abonnement CherryAI sont disponibles pour les clients externes et Code Mate via la passerelle en utilisant le quota du compte connecté.

💄 Améliorations

  • [Agent] Pi et Pi Durable utilisent le compactage natif de leurs environnements d'exécution et conservent les détails des erreurs du fournisseur.
  • Les détails de la session [Agent] répertorient les applications qu'un agent contrôle, avec leur statut et une action d'arrêt.
  • [Chat] La carte de branche localise le nœud de branche actif et peut être parcourue lors du défilement.
  • [Modèles] Le curseur d'effort de raisonnement suit le glissement en douceur, s'installe sur les niveaux d'effort et respecte les paramètres de mouvement réduit.
  • [Modèles] Les noms de modèles tronqués dans le sélecteur de modèle affichent le nom complet en survol, et la carte de détails du modèle ne les clips.
  • [Tâches planifiées] La navigation par ancre reste alignée pendant le chargement de l'historique, et les résumés d'exécution ayant échoué affichent les détails de l'erreur dans une info-bulle.
  • [Fichiers] Les listes et grilles de fichiers affichent le chemin source de chaque fichier dans l'info-bulle du nom afin que les fichiers du même nom puissent être distingués.
  • [Prompt Polish] Affiche le modèle par défaut avec un lien vers ses paramètres et distingue les délais d'attente, les modèles manquants, les réponses vides et les échecs du fournisseur.
  • [Commentaires] Joindre des diagnostics à un rapport de problème est désormais facultatif.
  • [macOS] Le programme d'installation de DMG a un nouvel arrière-plan et une disposition de glisser-vers-applications plus grande et centrée.
  • [Assistant] L'assistant anglais par défaut s'appelle désormais "Cherie".
  • [UI] Les piles de notifications étendues ne clip n'affichent plus leurs ombres.

🐛 Corrections de bugs

  • [Agent] Les résultats des outils de shell, de fichiers et d'artefacts imbriqués dans les modes de code Pi et Pi Durable sont à nouveau affichés, y compris après la réouverture d'une conversation.
  • Les commandes [Agent] Pi Shell sans délai d'attente explicite n'attendent plus indéfiniment.
  • [Agent] La fermeture d'une session interrompt d'abord le travail de Claude, et les tours de code de Claude interrompus n'affichent plus le message "Aucune réponse demandée". espace réservé.
  • [Agent] Fork et Edit & Resend fonctionnent après une limite /compact, et fork ne rejette plus une session Claude saine avec des lignes de cadrage vierges.
  • [Agent] Le panneau Étape n'affiche plus un tour terminé comme en cours et les tâches supprimées par l'agent quittent la liste.
  • [Agent] La barre supérieure de l'agent conserve le nom de l'espace de travail et l'action d'ouverture du répertoire après le premier message.
  • La sortie [Agent] du sous-agent et la suite de l'agent principal apparaissent dans le bon ordre dans la conversation ouverte.
  • [Agent] Les objectifs sont terminés lorsque le modèle de vérification enveloppe son verdict dans un bloc de code ou un texte supplémentaire.
  • [Agent] Les échecs de modification des messages de l'agent affichent des explications complètes et persistantes avec des diagnostics copiables.
  • [Agent] Le panneau d'utilisation contextuelle affiche les noms de serveur MCP configurés au lieu des ID.
  • [Agent] Les cartes de session inter-agents nomment l'agent cible. - Les réponses de [Agent] Assistant dans les conversations professionnelles ne proposent plus la fonction Supprimer, car leur suppression ne peut pas supprimer la transcription d'exécution.
  • [Agent] La modification d'un message demande une confirmation avant de remplacer ultérieurement l'historique des conversations.
  • Les artefacts [Agent] Markdown peuvent être prévisualisés à partir d'une conversation d'agent même lorsque l'espace de travail est vide.
  • [Agent] Les icônes de l'onglet Travail sont mises à jour lorsque l'avatar de l'agent change alors que l'onglet est masqué.
  • [Chat] Les liens dans les messages envoyés peuvent être sélectionnés en douceur, sans navigation accidentelle.
  • [Chat] La modification d'un message ne supprime plus les caractères saisis juste après clicking Edit.
  • [Chat] Une erreur enregistrée deux fois dans les anciens messages affiche désormais une carte d'erreur.
  • [Chat] Les réponses API vides ou mal formées affichent un diagnostic clair avec des conseils de nouvelle tentative au lieu d'une erreur inconnue.
  • [Chat] L'avertissement de changement de branche "Le message est toujours en cours de synchronisation" est localisé.
  • [Notes] La coloration syntaxique du code ne disparaît plus sous l'éditeur.
  • [Raccourcis] Les raccourcis des numéros de conversation continuent de fonctionner après le premier changement sans recentrer la fenêtre.
  • [Navigateur] Les échecs de chargement de page utilisent un message générique au lieu de suggérer qu'un serveur local s'est arrêté.
  • [Mini applications] Les fenêtres contextuelles de connexion aux mini-applications du site Web restent dans leur session persistante.
  • [Connaissances] Les éléments de connaissances ayant échoué affichent la raison de l'échec et les messages d'extraction vides sont localisés.
  • [Tâches planifiées] Les délais d'attente Cron fonctionnent avec les environnements d'exécution compatibles Gemini et la suppression d'une tâche comportant plus de 32 000 sessions environ n'échoue plus.
  • [Fournisseurs] Les requêtes n'échouent plus lorsqu'un outil client a un nom vide.
  • [Claude] Claude Code crée son dossier d'exécution avant d'effectuer un téléchargement, afin que les installations n'échouent plus sur un dossier manquant.
  • [Peintures] Les requêtes d'image SiliconFlow MOSS n'échouent plus lorsqu'aucune taille d'image n'est sélectionnée.
  • [Code] Codex CLI conserve la fenêtre de contexte et la limite de compactage du modèle sélectionné lorsque sa configuration est reconstruite.
  • [UI] Les détails de la session de l'agent n'encombrent plus son contenu ou ne chevauchent plus l'aperçu du fichier.

⚡ Performances

  • [Agent] Le changement de branche et l'édition des messages sont plus rapides lors des longues sessions.
