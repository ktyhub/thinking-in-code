Cherry Studio 2.2.2 - Approbations des agents, correctifs du fournisseur et polissage

✨ Nouvelles fonctionnalités

  • [Utilisation de l'ordinateur] L'utilisation de l'ordinateur est désormais activée par défaut et demande avant d'accéder à chaque application. Choisissez Toujours, Approuver pour la session ou Rejeter, et gérez les approbations enregistrées dans Paramètres. Le mode Contournement ignore ces invites sans enregistrer les autorisations. (action requise : désactivez-la dans Paramètres si vous ne le souhaitez pas.)
  • [Compétences] Ajout d'un switch "Exporter les compétences vers des agents externes" dans Paramètres → Compétences. Il est désactivé par défaut pour les nouvelles installations, le répertoire de compétences partagé n'est donc plus créé sans un opt-in explicite ; les installations déjà exportées le conservent et sa désactivation supprime uniquement les liens créés par Cherry Studio.
  • [Agent] Les agents sur les modèles DeepSeek affichent désormais une courte ligne d'intention au-dessus de chaque appel d'outil. Les sessions d'agent maintiennent les étapes de l'outil étendues par défaut et suppriment les appels répétés du même type.
  • [Application] Ajout de la prise en charge de la langue polonaise.

💄 Améliorations

  • [MCP] QVeris prend désormais en charge la connexion au navigateur OAuth comme identifiant principal, avec QVERIS_API_KEY comme solution de secours facultative, afin qu'il puisse être activé sans clé API.
  • [Fichiers] Les tailles de fichiers utilisent un format cohérent dans toute l'application.
  • [Agent] Typographie raffinée des détails de la session, alignement des icônes, espacement et espace réservé sans espace de travail.

🐛 Corrections de bugs

  • [Modèles] Les requêtes de l'outil CherryIN Claude Sonnet 4.5 n'échouent plus avec une erreur de validation du paramètre Bedrock.
  • [Modèles] Les requêtes Claude Opus 5.5 sur AWS Bedrock utilisent désormais le raisonnement adaptatif.
  • [Modèles] SiliconFlow utilise la saisie manuelle des touches API ; la connexion OAuth obsolète a été supprimée (action requise si vous vous êtes connecté avec OAuth).
  • [Chat] Les erreurs « L'entrée dépasse la limite de contexte » sont désormais reconnues comme des rejets de longueur de contexte, de sorte que les instructions de récupération existantes apparaissent.
  • [Chat] Les liens vers les fichiers Markdown locaux s'ouvrent désormais à partir des surfaces de discussion qui ne fournissent pas d'aperçu d'artefact.
  • [Chat] Correction de la perte de l'activation de la première barre d'outils du compositeur lors du chargement, et la navigation par onglets internes ne bloque plus l'interaction.
  • [Agent] Correction de la carte AskUserQuestion manquante lorsqu'une demande d'approbation diffusée arrive avant la source de son outil.
  • [Agent] Correction du blocage du bouton Passer sur la dernière question AskUserQuestion lorsque toutes les questions sont ignorées.
  • [Agent] L'extension d'un appel à l'outil de lecture Pi Durable n'affiche plus les détails du fichier vide.
  • [Agent] Les agents Pi Durable chargent désormais automatiquement les fichiers d'instructions de l'espace de travail tels que AGENTS.md.
  • [Agent] Les outils MCP ordinaires peuvent être découverts via la recherche d'outils dans le runtime Pi Durable au lieu de renvoyer « Aucun outil correspondant trouvé ».
  • [Agent] Le guide des outils d'agent traite désormais les outils différés comme disponibles via la découverte et utilise les noms d'outils exacts de la session, de sorte que les agents arrêtent de signaler les outils disponibles comme manquants.
  • [Agent] Lorsque le raisonnement épuise le budget de réponse, vous obtenez désormais des conseils précis sur la limite de jeton de sortie, et la capacité Flash de DeepSeek V4.1 est résolue correctement pour les ID de modèle versionnés. -[API Gateway] Les résultats de Claude Code MCP ToolSearch ne sont plus supprimés pour les modèles tiers.
  • Le sélecteur de modèles de passerelle unifiée de [Code] Code Mate répertorie désormais les modèles Cherry Cloud qui sont disponibles uniquement pour les agents.
  • [Doctor] Doctor ne signale plus une clé API manquante ou une liste de modèles indisponibles pour CherryAI et Cherry Cloud ; pour Cherry Cloud, il vous indique désormais quand vous devez vous connecter.
  • [UI] Les favicons du site Web restent visibles en mode sombre avec une plaque arrière gris clair tout en conservant leurs couleurs d'origine.
  • [Mise à jour] Les Release note dans la boîte de dialogue de mise à jour suivent désormais la langue résolue de l'application, y compris lorsque l'application suit la langue du système.

</détails>
