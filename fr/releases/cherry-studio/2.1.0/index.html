<summary>Anglais</summary> Cherry Studio 2.1.0 - System Doctor, contrôle du navigateur et transformation Office ✨ Nouvelles fonctionnalités - [Docteur] Ajoutez System Doctor avec diagnostic IA, vérifications du système, correctifs guidés, exportation de diagnostics et commentaires. Les vérifications couvrent l'installation, les autorisations, le stockage, les fournisseurs, MCP, les outils gérés et les erreurs récentes. Diagnostiquez les discussions individuelles ou les sessions d'agent séparément des rapports complets du système ; l'ouverture des commentaires ou l'exportation ne démarre pas un contrôle de santé. - [Navigateur] Les agents et les assistants de chat peuvent utiliser le navigateur intégré, avec un pointeur animé affichant les actions de l'agent. Les agents peuvent rechercher des éléments de page, les récupérer après les mises à jour des pages, inspecter l'activité de la console et du réseau et utiliser les outils WebMCP du site Web. Prend également en charge la recherche dans l'historique de navigation, l'importation des données du navigateur et la suppression de l'historique ou du cache séparé. - [Office] Ajoutez la compétence Office-Transform : les agents peuvent extraire des plages de feuilles de calcul, des paragraphes de documents, des pages PDF et des formes de diapositives dans de nouveaux fichiers. - [Sélection] Activez « Sélectionner une région » pour sélectionner une plage de feuille de calcul, un paragraphe Word, une page PDF ou une diapositive et la citer comme référence structurelle précise. - [Recherche Web] Ajoutez Serply en tant que fournisseur de recherche Web. - [Modèles] Ajoutez le modèle Flash DeepSeek V4.1 avec contrôle de l'effort de raisonnement et prise en charge de la recherche sur le Web. - [Agent] Les agents peuvent désactiver l'attribution des commits Claude Code dans Paramètres → Général. - [Barre latérale] Épinglez les applications, les mini-applications, les agents, les assistants, les bases de connaissances, les sujets, les sessions d'agent, les fichiers et les outils Code CLI comme raccourcis. - [Chat] Ajoutez des menus contextuels de lien de conversation à ouvrir dans un navigateur intégré ou externe. - [Historique] Ajoutez Ctrl+A/Cmd+A tout sélectionner, la sélection de plage Shift-click et un indicateur de sélection partielle. - Les connexions des appareils [Mobile] sont désormais visibles pour tous les utilisateurs disposant d'une carte de téléchargement d'application mobile localisée. - [Corbeille] La suppression de sujets, d'agents, d'assistants ou de fichiers les déplace désormais vers Paramètres → Données → Corbeille pour restauration ou suppression permanente. - [Markdown] Les blocs de code LaTeX affichent désormais les aperçus des formules par défaut. - [Markdown] Les chemins d'accès aux fichiers et dossiers locaux dans les réponses de l'assistant sont désormais clickable. - [Journaux] Ajoutez un paramètre de conservation des journaux (7/14/30/90 jours) avec nettoyage automatique. 🐛 Corrections de bugs - [Code Block] Correction des modifications enregistrées dans un mauvais bloc de code ou perdues ; la barre d'outils reste visible lors du défilement. - [Composer] Correction du collage silencieux qui ne faisait rien lorsque le fichier ne pouvait pas être lu. - [Composer] Préserve le focus d'entrée lors de l'envoi de messages. - [Liste des conversations] Afficher plus développe désormais toutes les conversations restantes. - [Historique] Gardez l'historique ouvert après la suppression de conversations. -[Markdown] Empêche les messages bruts de clignoter lors d'un chargement paresseux. - [Markdown] Correction du rendu mathématique de l'affichage sur les lignes vides. - [Windows] Correction des avertissements répétés « fsync(dir) failed » dans le journal. - [Modèles] Activer la recherche sur le Web pour les modèles LMStudio/Ollama compatibles avec les outils. - [Modèles] Répertoriez les modèles LM Studio à partir de /api/v0/models. - [Fournisseur] Limiter la sortie de DeepSeek V4 à 384 000 jetons ; corriger les limites du GLM-5.3 et du MiMo V2.5. - [DSH] Lancez DSH avec Bun fourni ; conserver les en-têtes de session OpenCode. - [DSH] Échec rapide sur la maison DSH mise à niveau incompatible. - [Erreur] Classifier les échecs de transport Chromium net::ERR_* ; préserver les messages structurés d’échec du fournisseur. - [Image] Restaurer la compatibilité des images de référence HDR ; correction du retournement de rotation de l'image. - [Migration] Conservez l'enregistrement du serveur MCP mal formé en cas d'abandon de la migration v2. - [Raccourcis] Avertir lorsque le raccourci entre en collision avec le raccourci du processus principal. - [Chat] Restaurer le suivi du bas après l'envoi ; préserver l’état de la barre latérale lors du changement d’onglet. - [Chat] Afficher la barre de défilement multi-modèles au survol ; empêcher le rebond du défilement. - [Connaissances] Afficher les barres de défilement du lecteur de fichiers. - [Smooth Stream] Vider le texte mis en mémoire tampon à la fin. - [Claude Code] Traitez les liens symboliques pendants comme des fuites d'espace de travail ; préserver le bus de session de bureau Linux. -
