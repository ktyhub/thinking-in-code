skywalking v9.7.0

Mineure Publié1 déc. 2023 Sourceapache/skywalking Anglais original

Cette page est traduite automatiquement. Le texte anglais original fait foi.

marche en parachute v9.7.0

Télécharger

https://skywalking.apache.org/downloads/

Avis

Ne téléchargez pas les codes sources à partir de cette page. Veuillez suivre build document, si vous souhaitez créer des codes sources par vous-même.

Mode sombre

Le mode de style par défaut passe au mode sombre et le mode clair est toujours disponible.

Nouvelle vue du journal de conception

Une nouvelle conception pour la vue du journal est actuellement disponible. Plus facile de localiser les journaux et plus d'espace pour le texte brut.

Projet

  • Transférez l'agent Java vers 9.1-dev dans les tests e2e.
  • Augmentez netty en 4.1.100.
  • Mettez à jour Groovy 3 vers 4.0.15.
  • Prise en charge du packaging du projet dans JDK21. La source et la cible du compilateur restent dans JDK11.

Serveur OAP

  • ElasticSearchClient : Ajouter deleteById API.
  • Réparer Les règles d'alarme personnalisées sont écrasées par 'resource/alarm-settings.yml'
  • Prise en charge de la surveillance Kafka.
  • Prise en charge de la surveillance du serveur Pulsar et du serveur BookKeeper.
  • [Changement de rupture] Le stockage Elasticsearch fusionne tous les index de données de gestion en un seul index management, y compris ui_template，ui_menu，continuous_profiling_policy.
  • Ajouter un mécanisme de libération pour les fenêtres d'alarme lorsqu'elles sont expirées en cas de MOO.
  • Correction de la réponse du récepteur de trace Zipkin : créez le code d'état HTTP de 200 à 202.
  • Mettez à jour BanyanDB Java Client vers 0.5.0.
  • Correction de la requête getInstances dans le DAO de métadonnées BanyanDB.
  • BanyanDBStorageClient : ajoutez keepAliveProperty API.
  • La table de correctifs existe, vérifiez dans le plug-in de stockage JDBC.
  • Améliorer l'extensibilité de la bibliothèque du serveur HTTP.
  • Ajustez la longueur de la colonne AlarmRecord alarmMessage à 512.
  • Correction de l'événement de construction EventHookCallback : construisez la couche à partir de Service's Layer.
  • Correction de AlarmCore doAlarm : interceptez une exception pour chaque rappel pour éviter toute interruption.
  • Optimisez queryBasicTraces dans TraceQueryEsDAO.
  • Correction de WebhookCallback qui envoie des messages incorrects, ajoute une exception catch pour chaque rappel HTTP Post.
  • Correction de la validation de l'expression AlarmRule : ajoutez des données fictives de métriques étiquetées pour vérification.
  • Prise en charge de la collecte des métriques du pool de mémoire ZGC.
  • Ajoutez un ID de composant pour Netty-http (ID=151).
  • Ajoutez un ID de composant pour la fibre (ID=5021).
  • BanyanDBStorageClient : ajoutez define(Property property, PropertyStore.Strategy strategy) API.
  • Corrigez le format de fichier et corrigez les fautes de frappe dans les noms de fichiers pour surveiller les tests e2e de Kafka.
  • Prise en charge de l'extraction de l'horodatage à partir d'une chaîne datetime à motifs dans LAL.
  • Prise en charge des paramètres clés de sortie dans les journaux de démarrage.
  • Le correctif ne peut pas interroger les traces Zipkin avec le paramètre annotationQuery dans le stockage associé à JDBC.
  • Le correctif limit ne fonctionne pas pour findEndpoint API dans le stockage ES.
  • Isolez le cache MAL CounterWindow par nom de métrique.
  • Correction de l'ordre des requêtes du journal JDBC.
  • Modifiez la stratégie DataCarrier IF_POSSIBLE pour utiliser l'implémentation d'ArrayBlockingQueue.
  • Modifiez la politique de la file d'attente (DataCarrier) dans le travailleur d'agrégation métrique L1 en mode IF_POSSIBLE.
  • Ajoutez la métrique d'auto-observabilité metrics_aggregator_abandon pour compter le nombre de métriques d'abandon.
  • Prise en charge de la surveillance Nginx.
  • Correction de BanyanDB Metadata Query : faire en sorte que l'instance/le processus unique de la requête renvoie des balises complètes pour éviter le NPE.
  • Remplacez go2sky E2E par l'agent GO.
  • Remplacez le protocole Metrics v2 par MQE dans les modèles d'interface utilisateur et le test E2E.
  • Correction des règles d'hôtel de métriques apisix incorrectes.
  • Supporte Scratch The OAP Config Dump.
  • Prise en charge de la fonction increase/rate dans le langage de requête MQE.
  • Regroupez les points de terminaison de service dans _abandoned lorsque les points de terminaison ont un niveau élevé cardinalité.

interface utilisateur

  • Ajouter un nouveau menu pour la surveillance kafka.
  • Correction de la durée du widget indépendant.
  • Correction de la hauteur d'affichage de l'arborescence des liens.
  • Remplacez le nom par shortName sur le widget de service.
  • Refactor : mettre à jour le style de pagination. Aucun changement de style de visualisation.
  • Appliquez MQE sur les modèles d'interface utilisateur de couche K8.
  • Correction de l'affichage des icônes dans l'arborescence des traces.
  • Correctif : mettez à jour le style de l'info-bulle pour prendre en charge la vue défilante de plusieurs métriques dans un graphique de métriques.
  • Ajoutez un nouveau widget pour afficher les détails du pool de mémoire jvm.
  • Correctif : évitez d'interroger des données avec des paramètres vides.
  • Ajoutez un titre et une description pour les segments de trace.
  • Ajoutez l'icône Netty pour le plugin HTTP Netty.
  • Ajouter les fichiers i18n du menu Pulsar.
  • Vue des journaux de refactorisation.
  • Implémentez le thème sombre.
  • Modifiez les modèles d'interface utilisateur pour les widgets de texte.
  • Ajouter le menu Nginx i18n.
  • Correction de la hauteur du widget de trace.
  • Style de liste polonaise.
  • Correction du journal associé à Trace.
  • Améliorer la mise en page du widget Topologie cassé.
  • Correction de la métrique des appels avec le type d'appel pour le widget Topologie.
  • Correction de la modification de la configuration des métriques pour le widget Topologie.
  • Correction des itinéraires pour le widget Tab.
  • Supprimez les modèles d'interface utilisateur relatifs et l'élément de menu OpenFunction (couche FAAS).
  • Correction : changez les couleurs pour qu'elles correspondent au thème sombre pour le profilage réseau.
  • Supprimez la description d'OpenFunction dans l'interface utilisateur i18n.
  • Réduisez les morceaux de composants pour améliorer le temps de chargement des ressources.

Documentation

  • Séparez les documents de stockage en différents fichiers et ajoutez un calendrier estimé pour BanyanDB (fin 2023).
  • Ajouter la configuration de la topologie dans la documentation UI-Grafana.
  • Ajoutez les métriques manquantes à la documentation OpenTelemetry Metrics.
  • Documents polonais de Concepts and Designs.
  • Correction des notes incorrectes de slowCacheReadThreshold.
  • Mettre à jour la documentation de configuration OAP et du coordinateur de cluster pour expliquer le nouveau tableau des paramètres de démarrage dans les journaux et comment configurer mode cluster.

Tous les problèmes et demandes d'extraction sont [ici] (https://github.com/apache/skywalking/milestone/193?closed=1)
