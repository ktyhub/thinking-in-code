Projet

  • Prise en charge de l'exécution Java 21.

  • Mettez à niveau la version OTEL collector vers 0.92.0 dans tous les tests e2e.
  • Basculez le coureur CI macOS vers m1.
  • Mettez à niveau le pilote PostgreSQL vers 42.4.4 pour corriger CVE-2024-1597.
  • Supprimez CLI(swctl) de l'image.
  • Supprimez la variable CLI_VERSION de la version Makefile.
