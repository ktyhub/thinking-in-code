skywalking v9.6.0

Mineure Publié3 sept. 2023 Sourceapache/skywalking Anglais original

Cette page est traduite automatiquement. Le texte anglais original fait foi.

marche en parachute v9.6.0

Télécharger

https://skywalking.apache.org/downloads/

Avis

Ne téléchargez pas les codes sources à partir de cette page. Veuillez suivre build document, si vous souhaitez créer des codes sources par vous-même.

Nouveau noyau d'alerte

  • MQE (Metrics Query Expression) et un nouveau mécanisme de notification sont pris en charge.

Prise en charge de Loki LogQL

  • Prise en charge nouvellement ajoutée de Loki LogQL et Grafana Loki Dashboard pour les journaux collectés SkyWalking

AVERTISSEMENT

  • Les tests relatifs au stockage du ElasticSearch 6 sont supprimés. Cela a fonctionné et n'est pas officiellement promis en raison de la fin de vie.

Projet

  • Augmentez Guava en 32.0.1 pour éviter la bibliothèque répertoriée comme vulnérable en raison de CVE-2020-8908. Ce API n'est jamais utilisé.
  • L'artefact Maven skywalking-log-recevier-plugin est renommé skywalking-log-receiver-plugin.
  • Passez de la version cli 0.11 à 0.12.
  • Augmentez la version du pom parent ASF vers la v30.
  • Rendre les builds reproductibles pour les versions automatiques CI.

Serveur OAP

  • Ajoutez la langue de l'ID du composant Neo4j (112) : Python.
  • Ajoutez le registre Istio ServiceEntry pour résoudre les adresses IP inconnues dans ALS.
  • Enveloppez deleteProperty API dans le BanyanDBStorageClient.
  • [Modification avec rupture] Supprimez matchedCounter de HttpUriRecognitionService#feedRawData.
  • Supprimez les modèles de HttpUriRecognitionService#feedRawData et ajoutez au maximum 10 candidats d'URI bruts pour chaque modèle.
  • Ajoutez l'ID de composant pour WebSphere.
  • Correction de l'uri du pipeline AI mettant en cache les exceptions NullPointer et IllegalArgument.
  • Correction de NPE dans la requête de métriques lorsque la métrique n'existe pas.
  • Supprimez les tests E2E pour Istio < 1.15, ElasticSearch < 7.16.3, ils peuvent toujours fonctionner mais ne sont pas pris en charge comme prévu.
  • Faites défiler tous les résultats dans le stockage ElasticSearch et refactorisez les logiques de défilement, y compris le service, l'instance, le point de terminaison, Processus, etc
  • Améliorer le coordinateur Kubernetes pour supprimer les pods OAP Terminating du cluster.
  • Supporte SW_CORE_SYNC_PERIOD_HTTP_URI_RECOGNITION_PATTERN et SW_CORE_TRAINING_PERIOD_HTTP_URI_RECOGNITION_PATTERN pour contrôler la période de formation et synchroniser les modèles de reconnaissance HTTP URI. Et réduisez la période par défaut à 10 s pour synchronisation et 60s pour l'entraînement.
  • Correction du bug du scroller ElasticSearch.
  • Ajoutez l'ID du composant pour Aerospike (ID=149).
  • Les packages portant le nom recevier sont renommés en receiver.
  • BanyanDBMetricsDAO gère storeIDTag dans multiGet pour BanyanDBModelExtension.
  • Corrigez la logique liée au regroupement des points de terminaison et améliorez les performances de récupération de PatternTree.
  • Correction de la sauvegarde du cache de session métrique après l'insertion par lots lors de l'utilisation de mysql-connector-java.
  • Prise en charge de la requête de menu dynamique de l'interface utilisateur.
  • Ajoutez un commentaire pour docker/.env pour expliquer l'utilisation.
  • Correction du mauvais nom de variable d'environnement SW_OTEL_RECEIVER_ENABLED_OTEL_RULES à droite SW_OTEL_RECEIVER_ENABLED_OTEL_METRICS_RULES.
  • Correction de la requête d'instance dans l'implémentation JDBC.
  • Définissez la valeur par défaut du SW_QUERY_MAX_QUERY_COMPLEXITY sur 3000 (au lieu de 1000).
  • Acceptez la valeur du paramètre length=4000 de l'événement. C'était en 2000.
  • Tolérer la valeur du paramètre au format illégal JSON.
  • Mettre à jour BanyanDB Java Client vers 0.4.0
  • Prise en charge de l'agrégat Labeled Value Metrics dans MQE.
  • [Changement radical] Modifiez le nom de l'étiquette par défaut dans MQE de label à _.
  • Passez la version grpc à 1.53.0.
  • [Modification radicale] Suppression des symboles '&' des scripts shell pour éviter que le processus du serveur OAP ne s'exécute en arrière-plan.
  • Annuler une partie de #10616 pour corriger les changements inattendus : s'il n'y a pas de données, nous devrions renvoyer un tableau avec des 0, mais dans #10616, un tableau vide est renvoyé.
  • Cachez toutes les entités de service en mémoire pour les requêtes.
  • Augmentez la version Jackson en 2.15.2.
  • Augmentez la taille de la mémoire par défaut pour éviter le MOO.
  • Passez graphql-java à 21.0.
  • Ajouter la langue de l'ID du composant Echo (5015) : Golang.
  • Correction de index out of bounds exception dans la fonction aggregate_labels MQE.
  • Prise en charge de la surveillance du serveur/cluster MongoDB optimisée par OTEL.
  • N'imprimez pas les valeurs de configuration dans les journaux pour éviter la fuite d'informations sensibles.
  • Déplacer créé le dernier index avant de récupérer les index par alias pour éviter l'exception 404. Cela évite simplement certaines interférences liées aux opérations manuelles.
  • Ajoutez plus de métriques Go VM, en tant que nouvel agent skywalking-go fourni depuis sa version 0.2.
  • Ajoutez l'ID du composant pour Lock (ID=5016).
  • [Changement de rupture] Ajustez la structure des crochets dans le alarm-settings.yml. Prend en charge plusieurs configurations pour chaque type de hook et spécifie les hooks dans la règle d'alarme.
  • Augmentez Armeria à 1.24.3.
  • Correction de BooleanMatch et BooleanNotEqualMatch effectuant une comparaison booléenne.
  • Prise en charge des requêtes HTTP LogQL API.
  • Ajouter la langue de l'ID du composant du serveur Mux (5017) : Golang.
  • Supprimez ElasticSearch 6.3.2 de nos tests de bibliothèque client.
  • Augmentez le serveur ElasticSearch 8.8.1 en 8.9.0 pour les derniers tests e2e. 8.1.0, 7.16.3 et 7.17.10 sont toujours testés.
  • Ajoutez OpenSearch 2.8.0 à nos tests de bibliothèque client.
  • Utilisez le mode d'écoute pour l'implémentation Apollo de la configuration dynamique.
  • Ajoutez la fonction view_as_seq dans MQE pour répertorier les métriques dans la séquence prioritaire donnée.
  • Corrigez la mauvaise valeur par défaut de k8sServiceNameRule si elle n'est pas explicitement définie.
  • Améliorez PromQL pour permettre plusieurs opérations métriques au sein d'une seule requête.
  • Correction de l'opération binaire MQE entre les métriques étiquetées et un autre type de résultat de valeur.
  • Ajoutez l'ID du composant pour Nacos (ID=150).
  • Prise en charge de Compare Operation dans MQE.
  • Correction du cache de ressources Kubernetes non actualisé.
  • Correction d'un mauvais chemin de classe pouvant provoquer un MOO au démarrage.
  • Améliorez le serviceRelation dans MAL en ajoutant des paramètres pour les champs delimiter et component.
  • [Changement radical] Prise en charge de MQE dans les alertes. La configuration des règles d'alarme (alarm-settings.yml), ajoutez le champ expression, supprimez les champs metrics-name/count/threshold/op/only-as-condition et supprimez la configuration composite-rules.
  • Vérifiez les résultats dans ALS en aval/en amont plutôt que par journal.
  • Correction de la requête GraphQL listInstances n'utilisant pas la requête endTime
  • Ne démarrez pas le serveur et le consommateur Kafka en mode init.
  • Ajoutez l'ID du composant Iris (5018).
  • Ajoutez la prise en charge du traçage OTLP en tant qu'entrée de trace Zipkin.

interface utilisateur

  • Correction du nom de la métrique browser_app_error_rate dans le tableau de bord Browser-Root.
  • Correction du nom d'affichage de endpoint_cpm pour la liste des points de terminaison dans le tableau de bord General-Service.
  • Implémenter des menus personnalisés et une page de marché.
  • Correction des types minTraceDuration et maxTraceDuration.
  • Correction de minTime d'initialisation à Infinity.
  • Bump les dépendances pour corriger les vulnérabilités.
  • Ajoutez des variables scss.
  • Corrigez le titre de la liste d'instances et les avis dans le profilage continu.
  • Ajoutez un lien pour expliquer l'expression métrique, ajoutez des unités dans le widget de profilage continu.
  • Calculez la largeur de la chaîne pour définir la largeur du nom des onglets.
  • [Modification radicale] Suppression des symboles « & » des scripts shell pour éviter que le processus du serveur d'applications Web ne s'exécute en arrière-plan.
  • Réinitialiser l'étiquette du graphique.
  • Correction des instances des associés de service.
  • Supprimez le nœud-sass.
  • Correction d'une erreur de validation sous Windows.
  • Appliquez MQE sur les modèles d'interface utilisateur de couche MYSQL, POSTGRESQL, REDIS, ELASTICSEARCH et DYNAMODB.
  • Appliquer MQE sur les modèles d'interface utilisateur de la couche Virtual-Cache
  • Appliquez MQE sur les modèles d'interface utilisateur des couches APISIX, AWS_EKS, AWS_GATEWAY et AWS_S3.
  • Appliquez MQE sur les tableaux de bord RabbitMQ.
  • Appliquer MQE sur les modèles d'interface utilisateur de la couche Virtual-MQ
  • Appliquer MQE sur les modèles d'interface utilisateur de la couche Infra-Linux
