Nouvelles fonctionnalités du package

  • Un nouveau modèle de reconnaissance chinoise pour les scénarios de documents, traitant de certains caractères chinois rares, prend en charge un nombre de caractères supérieur à 15 000. L'utilisation du CLI est la suivante :
paddleocr --image_dir xxx.png --lang ch_doc

De même, dans le Python API, il vous suffit de modifier le paramètre lang en ch_doc.
