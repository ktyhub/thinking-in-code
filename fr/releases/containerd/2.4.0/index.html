conteneur v2.4.0

Bienvenue dans la version v2.4.0 de containersd !

containersd 2.4 est une version standard (non LTS) avec une fenêtre de support plus courte, destiné aux utilisateurs qui souhaitent adopter de nouvelles fonctionnalités plus tôt. Comme la sortie après le 2.3 LTS, c'est le point du cycle de publication où auparavant les fonctionnalités obsolètes peuvent être supprimées, cette version peut donc inclure des ruptures changements; vérifiez les notes ci-dessous et effacez tout avertissement de dépréciation de votre version actuelle avant la mise à niveau.

Les utilisateurs qui privilégient la stabilité et un cycle de vie de support plus long doivent rester connectés. Version 2.3 LTS.

Faits saillants

Interface d'exécution du conteneur (CRI)

  • Activer le gestionnaire de montage pour les montages d'images dans CRI (#13542)
  • Exporter l'image sandbox et la configuration du répertoire CNI dans les informations du plugin CRI (#13940)
  • Définissez runtimeFeatures.UserNamespacesHostNetwork par défaut sur true (#13162)
  • Prise en charge de l'introspection des fonctionnalités d'exécution OCI pour les environnements d'exécution non runc (#13504)

Distribution des images

  • Appliquer le renforcement pour supprimer les en-têtes d'authentification sensibles lors de la récupération des URL de descripteur (#12889)
  • Prise en charge de la propagation des en-têtes d'avertissement HTTP 299 des registres vers le résolveur (#12698)
  • Utilisez klauspost/compress pour la décompression de la couche gzip (#13560)

Stockage d'images

  • Ajoutez des options client pour récupérer tout le contenu des couches lors du décompression, même lorsque des instantanés existent (#14126) * Inclure le type de média dans les événements de création de contenu (#13833)
  • Ajouter des références avancées au contexte de collection GC (#13634)

Interface de ressources de nœud (NRI)

  • Exposez le nom de l'image du conteneur, le résumé et le résumé de configuration aux plugins NRI (#13960)
  • Émettre des avertissements de dépréciation pour les plugins utilisant des interfaces NRI obsolètes (#13916)

Durée d'exécution

  • Masquer /proc/interrupts et les chemins sysfs de limitation thermique du processeur dans les conteneurs Linux par défaut (#14090)
  • Ajoutez UpdateSandbox RPC pour propager les mises à jour du contrôleur sandbox au shim (#14105)
  • Évitez de redémarrer immédiatement les conteneurs avec la stratégie restart=always après leur arrêt explicite (#13993)
  • Passer le contexte de traçage de la cale au runc et aux crochets (#14036)
  • Correction des échecs de recherche d'utilisateurs et de groupes dans les rootfs de conteneurs contenant un lien symbolique /etc/passwd ou /etc/group (#13818)
  • Implémentation du serveur de canal nommé Windows et prise en charge du streaming de journaux dans pkg/shim (#13948)
  • Activer le nettoyage des journaux par défaut sous Windows (#13837)
  • Autoriser la spécification du répertoire de point de contrôle parent lors du point de contrôle avec runc (#13699)

Instantanés

  • Ajoutez des métriques Prometheus pour le cache de contenu de la couche d'instantané EROFS (#13941)
  • Prise en charge du cache d'images chaudes pour l'instantané erofs (#13813)
  • Ajouter une étiquette de taille maximale pour les instantanés (#13520)

Rupture

  • Supprimez les options de configuration obsolètes du CRI et du traçage :
    • Supprimez enable_cdi dans la configuration d'exécution CRI (CDI est désormais toujours activé)
    • Supprimez bin_dir dans la configuration CRI CNI (utilisez bin_dirs)
    • Supprimez endpoint, protocol et insecure dans la configuration du processeur de traçage OTLP (utilisez les variables d'environnement OTLP standard)
    • Supprimez service_name et sampling_ratio dans la configuration de traçage interne (utilisez les variables d'environnement standard OpenTelemetry) (#14166)
  • Supprimer la restauration dans CreateContainer (#13871)

Dépréciations

  • Déprécier l'annotation shim containersd.io/runtime-allow-mounts en faveur de l'extension d'amorçage MountCapabilities (#14002)
  • Supprimer le shim.Command obsolète du paquet (#13991)
  • Déprécier les champs d'adresse et de version de la tâche API dans les options d'exécution et les déplacer vers CreateTaskRequest (#13360)

Veuillez essayer les versions binaires et signaler tout problème à https://github.com/containerd/containerd/issues.
