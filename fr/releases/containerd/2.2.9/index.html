conteneur v2.2.9

Bienvenue dans la version v2.2.9 de containersd !

La neuvième version du correctif pour conteneurd 2.2 contient divers correctifs et des mises à jour comprenant un correctif de sécurité.

Mises à jour de sécurité

  • conteneur
    • CVE-2026-53493

Faits saillants

Interface d'exécution du conteneur (CRI)

  • Correction d'un bug où la création du conteneur échouait lorsque le réétiquetage SELinux n'était pas pris en charge par le système de fichiers (#14210)
  • Activer le gestionnaire de montage pour les montages d'images dans CRI (#14148)

Stockage d'images

  • Assurez-vous que toutes les couches sont récupérées lorsque plusieurs manifestes dans un index partagent un descripteur de configuration (#14140)

Durée d'exécution

  • Masquer /proc/interrupts et les chemins sysfs de limitation thermique du processeur dans les conteneurs Linux par défaut (#14182)

Veuillez essayer les versions binaires et signaler tout problème à https://github.com/containerd/containerd/issues.

Modifications des dépendances

Cette version n'a aucun changement de dépendance

La version précédente peut être trouvée sur v2.2.8

Quel fichier dois-je télécharger ?

  • containerd-<VERSION>-<OS>-<ARCH>.tar.gz : ✅Recommandé. Lié dynamiquement avec la glibc 2.35 (Ubuntu 22.04).
  • containerd-static-<VERSION>-<OS>-<ARCH>.tar.gz : lié statiquement. Devrait être utilisé sur les distributions Linux qui n'utilisent pas la glibc >= 2.35. Non indépendant de la position.

En plus de containersd, vous devrez généralement installer runc et plugins CNI depuis leurs sites officiels également.
