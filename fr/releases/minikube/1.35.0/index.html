Release Note

Version 1.35.0 - 2025-01-15

Caractéristiques :

  • Ajout de la prise en charge des GPU AMD via --gpus=amd #19749
  • Utiliser les actifs Github comme nouveau basculement pour l'image de base kic #19464
  • Prise en charge du dernier Kubernetes v1.32.0 #20091
  • Ajoute la prise en charge de kubeadm.k8s.io/v1beta4 (disponible depuis k8s v1.31) #19790

Améliorations :

  • Fusionnez nvidia-gpu-device-plugin et nvidia-device-plugin. #19545
  • kicbase : Mettre à jour les packages nvidia #19738
  • Cil : supprimez appArmorProfile pour k8s<v1.30.0 #19888
  • Pause automatique : redémarrer le service après la configuration #19900
  • Annuler "Modifier la logique MINIKUBE_HOME" #20045
  • ne pollue pas la liste des profils minikube avec des erreurs si le code de sortie est absent #19728
  • Requête d'état unifiée du cluster minikube #18998
  • Pilote Vfkit : correction de l'échec de TestMachineType sur macOS #19726
  • Plus de restriction arch sur nerdctld #19730
  • Correspondance d'adresse MAC plus robuste #19750
  • Ajoutez des instructions pour résoudre l'erreur de contexte docker #19197

Corrections de bugs :

  • Correction de l'échec de --wait à fonctionner sur les pods coredns #19748
  • Correction de la panique lorsqu'aucun service dans l'espace de noms avec --all spécifié #19957
  • Correction du délai d'attente lors de l'arrêt de la machine KVM avec le runtime du conteneur CRI-O #19758
  • Correction des longues lignes dans lastStart.txt qui n'apparaissaient pas dans les sorties de journaux #19740
  • Correction d'une détection erronée de l'arche kicbase comme étant incorrecte #19664

Changements majeurs :

  • supprimer arm64 kvm #19985 #20062
  • supprimer le module complémentaire barre franche #19636

Langues :

  • Ajouter plus de traductions chinoises #19490 #19508 #19718 #19962 #19772
  • Améliorer la traduction française #19654 #19978
