#minikube v1.38.0

📣😀 Veuillez remplir notre enquête rapide en 5 questions afin que nous puissions savoir comment et pourquoi vous utilisez minikube, et quelles améliorations nous devrions apporter. Merci! 💃🎉

Release Note

Version 1.38.0 - 2026-01-28

Points forts

  • Aucun Sudo requis pour vfkit/krunkit sur macOS 26+ (nécessite le dernier vmnet-helper)
  • Aucun Sudo requis pour exécuter [AI Playground sur les GPU Macos utilisant minikube] (https://minikube.sigs.k8s.io/docs/tutorials/ai-playground/)
  • vfkit : ajout de la prise en charge de Rosetta pour le déploiement d'images amd64 sur du silicium Apple (#22140)

Fonctionnalités

  • Ajout de la prise en charge de Kubernetes v1.35.0 (#21650)(#22015)(#22119)(#22328)
  • VM Drivers: add support for NVMe-oF/TCP block devices (#22464)
  • Pilotes VM : activez les symboles de débogage BTF pour prendre en charge les outils eBPF en ISO (#21800)
  • Ajout d'une option pour télécharger les préchargements depuis github au lieu de GCS via --preload-source (#22221)
  • Pilotes Vfkit/Krunkit : ajout de la possibilité d'exécuter vmnet-helper en tant qu'utilisateur non privilégié sur macOS 26+ (#22501)
  • ajouter une option pour ajouter des modules complémentaires basés sur la barre (#21847)
  • préchargement : téléchargement depuis github lorsque gcs n'est pas disponible (#21605)

Avertissements et dépréciations

  • UI : ajout d'un avertissement lors du changement du runtime par défaut en "containerd" dans la prochaine version (v1.39.0) (#22508)
  • hyperkit : supprimez les versions de pilotes et avertissez les utilisateurs de changer (#21946)
  • Supprimer la prise en charge du minikube pour les architectures 32 bits (#22401)

Améliorations

  • UI : colorée en fonction du statut (liste de profils, liste d'addons) (#22418)
  • Ignorer les binaires de mise en cache lorsque --no-kubernetes est défini (#21139)
  • Améliorer les journaux de tentatives pour imprimer moins de lignes en double (#22232)
  • améliorer la copie des fichiers de certificat par SSH Runner (#21923)
  • vmnet: Skip validation in download-only mode (#21635)
  • Améliorer le certificat Windows dans kubeconfig : normaliser les chemins de certificat générés pour les barres obliques (#21845)
  • Add cgroup v2 freezer check for API server status (#22249)
  • Définir l'option kubelet FailCgroupV1 pour kubenetes 1.35+ si cgroup v1 (#22319)
  • containersd : réessayez sur les erreurs EOF transitoires pour le chargement de l'image (#22310)
  • cri : augmente le délai d'attente par défaut de 2 s pour les commandes crictl (#22214)
  • crio: verify images are deleted after "image rm" (#22243)
  • Runtime docker : utiliser CRI pour la fonction ListImages (#22263)
  • image save: Add retry logic for local image in case of EOF (#22072)
  • HA (multi-control plane): Update kube-vip from v1.0.0 to v1.0.3 (#21699)(#21960)(#22258)

Pilotes

  • Pilotes : introduisez WaitForSSHAccess et corrigez les tests de fumée Macos (#22179)
  • Pilote hyperkit : correction des fuites de descripteur de fichier dans l'état (#22524)
  • kvm: fix minikube on Fedora/RHEL with SELinux (#21550)
  • kvm: remove dependency on external driver (#21625)
  • Marquer l'ancien pilote parallèle comme obsolète (#22379)
  • none driver: Fix "stop" with containerd runtime (#22275)
  • Mettre à jour les pilotes de la machine minikube (#22369)
  • vérifiez que les pilotes auxiliaires sont correctement installés et quittez correctement sinon (#21576)
  • vfkit : ajout de la prise en charge de Rosetta pour le déploiement d'images amd64 sur du silicium Apple (#22140)
  • VM : activez le groupe de contrôle v2 en utilisant le "pilote de groupe de contrôle systemd" pour Kubernetes… (#22320)

Corrections de bugs

  • Pilotes KIC : corrigez le pilote docker avec le runtime crio : installez dbus (#21724)
  • fix: correctly detect nested VMs on macOS and remove timeout multiplier (#22277)
  • Correctif : Augmenter le délai d'attente pour la liste d'images conteneur (#22558)
  • correctif : module complémentaire kubevirt en supprimant la dépendance curl (#22557)
  • fix: return non-zero exit code when status unavailable (#22494)
  • crio: fix ingress by enabling hostNetwork and ClusterFirstWithHostNet (#22239)
  • crio : correction du préchargement écrasant les images utilisateur (#22246)
  • Correction du montage Podman sur macOS en ajoutant le support host.containers.internal (#22451)
  • Correction du script de mise à niveau de la version cri-dockerd (#22358)
  • Correction de l'option de configuration de kubelet FailCgroupV1 à failCgroupV1 (#22325)
  • Addon Registry-Creds : Correction d'un défaut de segmentation sans fichier de configuration (#21786)
