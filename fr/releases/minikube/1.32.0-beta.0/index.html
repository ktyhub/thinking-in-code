Release Note

Version 1.32.0-beta.0 - 2023-10-27

Caractéristiques :

  • Prise en charge du GPU NVIDIA avec le nouvel indicateur --gpus=nvidia pour le pilote docker #15927 #17314 #17488
  • Nouveau module complémentaire kubeflow #17114
  • Nouveau module complémentaire local-path-provisioner #15062
  • Kicbase : Ajouter l'option no-limit aux drapeaux --cpus et --memory #17491

Améliorations mineures :

  • Hyper-V : ajout d'une validation de mémoire pour les nombres impairs #17325
  • QEMU : amélioration du type de processeur et de la détection IP #17217
  • Masquer le mot de passe http(s)_proxy à partir de la sortie de démarrage #17116
  • --delete-on-faliure recrée également le cluster pour les échecs de kubeadm #16890
  • Pause automatique du module complémentaire : configurez les intervalles à l'aide de --auto-pause-interval #17070
  • --kubernetes-version vérifie GitHub pour la validation de la version et une sortie d'erreur améliorée pour les versions non valides #16865

Bogues :

  • QEMU : correction des modules complémentaires ne parvenant pas à activer #17402
  • Correction du téléchargement des mauvaises images kubeadm pour les versions k8s après la sortie de minikube #17373
  • Correction de l'activation et de la désactivation des modules complémentaires avec un cluster inexistant #17324
  • Correction de la suppression si le runtime du conteneur n'existe pas #17347
  • Correction du réseau introuvable non détecté sur les nouvelles versions de Docker #17323
  • Le registre du module complémentaire ne suit pas la configuration du nom de domaine DNS Minikube (--dns-domain) #15585

Mises à niveau des versions :

  • Bump Kubernetes version par défaut : v1.28.3 et dernière version : v1.28.3 #17463
  • Module complémentaire cloud-spanner : mettre à jour l'image de l'émulateur/émulateur cloud-spanner de 1.5.9 à 1.5.11 #17225 #17259
  • Lampe frontale complémentaire : mettre à jour l'image de la lampe frontale-k8s/phare de v0.19.0 à v0.20.1 #17135 #17365
  • Entrée du module complémentaire : mettre à jour l'image d'entrée-nginx/contrôleur de v1.8.1 vers v1.9.3 #17223 #17297 #17348 #17421
  • Module complémentaire Inspektor-gadget : mettre à jour l'image Inspektor-gadget de v0.19.0 vers v0.21.0 #17176 #17340
  • Addon istio-provisioner : mettre à jour l'image istio/opérateur de 1.12.2 vers 1.19.3 #17383 #17436
  • Addon kong : Mettre à jour l'image kong de 3.2 vers 3.4.2 #17485
  • Registre complémentaire : mettre à jour l'image du registre de 2.8.1 vers 2.8.3 #17382 #17467
  • CNI : Mettre à jour Calico de v3.26.1 vers v3.26.3 #17363 #17375
  • CNI : mise à jour de la flanelle de v0.22.1 à v0.22.3 #17102 #17263
  • CNI : mettre à jour kindnetd de v20230511-dc714da8 vers v20230809-80a64d96 #17233
  • Kicbase/ISO : mise à jour du buildkit de v0.11.6 vers v0.12.2 #17194
  • Kicbase/ISO : Mettre à jour le conteneur de v1.7.3 vers v1.7.7 #17243 #17466
  • Kicbase/ISO : Mettre à jour le crictl de v1.21.0 vers v1.28.0 #17240
  • Kicbase/ISO : mise à jour du docker de 24.0.4 vers 24.0.6 #17120 #17207
  • Kicbase/ISO : mettre à jour nerdctl de 1.0.0 vers 1.6.2 #17145 #17339 #17434
  • Kicbase/ISO : mise à jour du runc de v1.1.7 vers v1.1.9 #17250
  • Kicbase : Bump ubuntu:jammy de 20230624 à 20231004 #17086 #17174 #17345 #17423 Pour un changelog plus détaillé, voir CHANGELOG.md.
