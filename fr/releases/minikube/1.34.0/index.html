#minikube v1.34.0

📣😀 Veuillez remplir notre enquête rapide en 5 questions afin que nous puissions savoir comment et pourquoi vous utilisez minikube, et quelles améliorations nous devrions apporter. Merci! 💃🎉

Release Note

Version 1.34.0 - 2024-09-04

Changements majeurs :

  • Remplacer la version minimale de Podman par 4.9.0 #19457
  • Interdire l'utilisation de Docker Desktop 4.34.0 #19576

Caractéristiques :

  • Remplacer la version par défaut du Kubernetes par le v1.31.0 #19435
  • Ajouter un nouveau pilote pour macOS : vfkit #19423
  • Ajout de la prise en charge du pilote Parallels pour Darwin/arm64 #19373
  • Ajouter un nouveau module complémentaire de volcan #18602
  • Addons ingress-dns : ajout de la prise en charge de toutes les architectures #19198
  • Prise en charge des ports privilégiés sur WSL #19370
  • Les pilotes de machine virtuelle avec l'environnement d'exécution du conteneur docker utilisent désormais docker-buildx pour la création d'images #19339
  • Prise en charge de l'exécution de QEMU x86 sur arm64 #19228
  • Ajouter l'option -o json pour la commande addon images #19364

Améliorations :

  • ajoutez un raccourci -d pour --driver #19356
  • ajoutez le raccourci -c pour --container-runtime #19217
  • kvm2 : Ne supprimez pas le réseau libvirt "par défaut" #18920
  • Mettre à jour l'utilisation de MINIKUBE_HOME #18648
  • CNI : autorisations mises à jour pour prendre en charge les politiques réseau sur kindnet #19360
  • GPU : définissez NVIDIA_DRIVER_CAPABILITIES sur all lorsque le GPU est activé #19345
  • Amélioration du message d'erreur lors de la tentative d'utilisation de mount sur un système manquant 9P #18995
  • Amélioration du message d'erreur lors de l'activation des modules complémentaires KVM sur un cluster non KVM #19195
  • Ajout d'un avertissement lors du chargement d'une image avec une mauvaise arche #19229
  • profile list --output json gère le dossier de configuration vide #16900
  • Vérifiez la connectivité à l'extérieur du minikube en cas de problème de connectivité #18859

Bogues :

  • Correction de la création du tunnel du serveur API pour QEMU avec réseau intégré #19191
  • Correction de l'attente de la saisie de l'utilisateur lors du déblocage du pare-feu lorsque --interactive=false #19531
  • Correction de la vérification des nouvelles tentatives du réseau lorsque le sous-réseau est déjà utilisé pour podman #17779
  • Correction d'une archive tar vide lors de la génération d'une sauvegarde d'image #19312
  • Correction de l'autorisation manquante pour le compte kong-service #19002

Mises à niveau des versions :

  • Module complémentaire cloud-spanner : mettre à jour l'image de l'émulateur/émulateur cloud-spanner de 1.5.17 à 1.5.23 #19341 #19501
  • Lampe frontale complémentaire : mettre à jour l'image de la lampe frontale-k8s/phare de v0.23.2 à v0.25.0 #18992 #19152 #19349
  • Addon kong : Mettre à jour l'image kong de 3.6.1 vers 3.7.1 #19046 #19124
  • Module complémentaire kubevirt : mettre à jour l'image bitnami/kubectl de 1.30.0 vers 1.31.0 #18929 #19087 #19313 #19479
