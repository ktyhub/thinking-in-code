Version 1.36.0 - 2025-05-22

Caractéristiques

  • Prise en charge de la version Kubernetes v1.33.1 #20784
  • Nouvel indicateur "-f" pour permettre de transmettre un fichier de configuration pour la commande addon configure. #20255
  • vfkit : accédez au pilote préféré sur MacOs #20808

  • vfkit vmnet : prise en charge de l'exécution sans configuration sudoers #20719
  • Annuler "correction de l'échec de --wait à fonctionner sur les pods coredns" #20313
