#minikube v1.39.0

📣😀 Veuillez remplir notre enquête rapide en 5 questions afin que nous puissions savoir comment et pourquoi vous utilisez minikube, et quelles améliorations nous devrions apporter. Merci! 💃🎉

Release Note

Version 1.39.0 - 2026-09-01

Faits saillants

  • Ajout de la prise en charge de Kubernetes v1.36 et v1.37 (par défaut : v1.37.0)
  • L'environnement d'exécution du conteneur par défaut est désormais conteneurd
  • Ajouter un module complémentaire d'entrée basé sur Traefik Helm
  • Le pilote VirtualBox prend désormais en charge Apple Silicon (VirtualBox 7.1+)

Fonctionnalités

  • Ajout de la prise en charge de Kubernetes v1.36 et v1.37 (par défaut : v1.37.0) (#23567, #23596)
  • Ajouter un module complémentaire basé sur Traefik Helm (#23225)
  • Ajouter Helm à l'ISO du minikube (#23420)
  • Mettre à niveau Helm invité par défaut client vers Helm 4 (#23383)
  • Ajouter des serveurs DNS configurables pour les pilotes de VM (#23069)
  • Ajoutez l'indicateur --mdns pour activer mDNS à chaque démarrage de VM (#22964, #23208)
  • pilotes : utilisez des adresses MAC déterministes (#23172)
  • vfkit : sélection automatique du réseau partagé par vmnet lorsqu'il est disponible (#23040)
  • virtualbox : prend en charge Darwin/arm64 avec VirtualBox 7.1+ (#22861)
  • ISO : ajout de systemd-coredump pour les traces de pile de crash (#23064)
  • ISO : Activer les nftables du noyau (CONFIG_NF_TABLES) pour les consommateurs de knftables (#23518)
  • ISO : activer les services de sécurité pour Calico 3.32.2 (#23592)
  • ISO : inclut le module de noyau openvswitch pour aarch64 (#23151)
  • ISO : activez CONFIG_TASK_IO_ACCOUNTING et les options du noyau associées (#23271)
  • infra : Téléchargez les préchargements du GitHub par défaut et du GCS en cas de basculement (#23087)

Performances

  • pilotes : démarrer les pilotes de VM en parallèle (#23112)
  • Ajouter l'indicateur de démarrage --vmnet-offloading pour le pilote krunkit (#22962)
  • ssh : préférez les chiffrements AES-GCM pour le SSH externe client (#23125)
  • ssh : évitez toute mise en veille inutile lorsque vous attendez le serveur SSH (#23001)

Corrections de bugs

  • Modules complémentaires : correction de l'échec de la vérification Helm dans les machines virtuelles invitées (#23253, #23329)
  • Correction de kubectl exec avec cri-dockerd sur Kubernetes v1.36+ en désactivant ExtendWebSocketsToKubelet (#22921)
  • Correction de --extra-config=etcd.* produisant une configuration kubeadm invalide (#23051)
  • Correction de la logique pour l'avertissement CNI multi-nœuds. (#22779)
  • Correction de SSHRunner ExitCode renvoyant toujours 0 pour les commandes SSH (#23364)
  • Correction de la chaîne d'utilisation pour les commandes de nœud minikube. (#22775)
  • kvm : Vérifiez l'appartenance au groupe libvirt avant d'exécuter virsh (#23369)
  • Correction de la balise de conservation pour les références de registre avec un port (#23228)
  • Utilisez des canaux mis en mémoire tampon pour éviter les fuites de goroutines en cas d'expiration du délai d'état (#23215)
  • Correction d'un avertissement contre virtualbox uniquement lorsque l'indicateur est explicite (#22960)
  • chargement d'image : Correction d'un échec silencieux lors du chargement d'une image utilisée par un conteneur (#23034)
  • ajout de nœud : utilisez suggestMemoryAllocation au lieu de 2 200 Mo codés en dur (#23305)
  • proxy : parcourez les wrappers RoundTripper pour supprimer le proxy sur le *http.Transport interne (#22910)
  • vmnet : correction du chemin d'installation de Brew sur les Mac Intel et prise en charge du chemin de Brew Bin (#23039)
  • mount : clarifier la nécessité de règles de pare-feu bidirectionnelles (#20442)
  • pilotes : gestion des baux DHCP dédupliqués sur macOS (#23084)
  • hack/mise à jour : suivi du module complémentaire de registre sur la balise majeure (#23586)
  • hack/mise à jour : mettre à jour la balise d'image kong à 3 (#23585)
  • ISO : remplacez les espaces par des tabulations dans les fichiers du package nerdctl-bin Buildroot (#23438)
  • ISO : tentative de correction des échecs de construction ISO (#22879)
  • ISO : correction de la fiabilité du script de build ISO et de la gestion des erreurs (#23218)
  • ISO : prise en charge de la création de l'ISO arm64 sur un hôte arm64 (#22862)
  • ISO : utilisez les binaires pour le buildx docker au lieu de construire à partir des sources (#22942)

Modifications cassantes

  • Remplacez le runtime du conteneur par défaut par containersd (#23562)
  • ISO/KIC : limiter la prise en charge de cri-dockerd à x86 et arm64 et migrer cri-dockerd vers les binaires GitHub précompilés (#22922)
