#minikube v1.37.0

📣😀 Veuillez remplir notre enquête rapide en 5 questions afin que nous puissions savoir comment et pourquoi vous utilisez minikube, et quelles améliorations nous devrions apporter. Merci! 💃🎉

Release Note

Version 1.37.0 - 2025-09-09

Mettre en surbrillance

Exécutez des charges de travail IA sur le GPU de Macbook dans Kubernetes à l'aide du nouveau krunkit driver. Commencez avec notre Tutoriel AI Playground

Fonctionnalités

  • Ajout du support pour Kubernetes v1.34.0 (#21439)
  • Ajouter le pilote krunkit prenant en charge l'accélération GPU sur macOS (#20826) Tutoriel
  • ajoutez l'abréviation -m pour --memory (#20854)
  • Ajout de la prise en charge du runtime docker pour l'accès OCI aux GPU NVIDIA (#20959)
  • Ajouter l'indicateur --disable-coredns-log pour supprimer les journaux coredns (#20992)
  • nouvel add-on : kubetail (#20345)
  • pilotes : ajout de la prise en charge des montages Virtiofs pour vfkit et krunkit (#21149)

Améliorations

  • Améliorer le module complémentaire ingress-dns pour ipv4 et Windows v0.0.4 (#21449)
  • iso : désactiver le délai d'attente de grub pour accélérer le démarrage de la machine virtuelle de 5 secondes (#20895)
  • améliorer la fiabilité du service docker, mettre à jour les fichiers systemd docker (#21174)
  • Ne nécessite pas les deux --mount pour utiliser --mount-string et supprime la chaîne de montage par défaut (#21250)
  • Mettre à jour les plus anciennes versions Kubernetes prises en charge (#21490)
  • licence cmd : n'échouez pas si le répertoire de sortie n'existe pas et téléchargez d'abord à partir des ressources github (#21206)
  • Supprimer l'indicateur obsolète proxy-refresh-interval v2 etcd (#21278)
  • vmnet : prise en charge du déchargement pour krunkit (#20831)
  • N'appelez pas startKicServiceTunnel pour les pilotes non-kic (#20863)
  • krunkit : désactivez le déchargement pour une mise en réseau plus rapide (#21341)
  • HA (plan multi-contrôle) : mise à jour de kube-vip de v0.9.1 vers v1.0.0 (#20999)(#21228)

Dépréciation

  • Déprécier le pilote HyperKit avec avertissement (#21024)

Corrections de bugs

  • Correction d'une version de commit sale (#21062)
  • Correction du chargement de l'image minikube sur Windows (#20529) (#20921)
  • Correction du montage dans le même dossier provoquant une erreur d'entrée/sortie (#21077)
  • Correction : problème d'erreur d'échappement de fichier YAML affectant les modules complémentaires (#20904)
  • iso : Correction de minikube stop avec les pilotes vfkit et krunkit (#21089)
  • iso : Correction de la console pour vfkit/krunkit (#20832)

Modules complémentaires

  • Module complémentaire nvidia-device-plugin : mise à jour de l'image nvidia/k8s-device-plugin de v0.17.2 vers v0.17.3 (#21225)
  • Module complémentaire cloud-spanner : mettre à jour l'image de l'émulateur/émulateur cloud-spanner de 1.5.34 à 1.5.41 (#20976)(#21040)(#21243)(#21287)(#21359)(#21512)
  • Lampe frontale complémentaire : mettre à jour l'image de la lampe frontale de v0.28.0 à v0.34.0 (#21238)(#21508)
  • Ingress du module complémentaire : mettre à jour l'image ingress-nginx/controller de v1.12.2 vers v1.13.2 (#20909)(#21232)(#21353)(#21458)
  • Module complémentaire Inspektor-gadget : mettre à jour l'image Inspektor-gadget de v0.40.0 vers v0.44.1 (#20873)(#21038)(#21240)(#21462)(#21510)(#21358)
  • Addon kong : Mettre à jour l'image kong de 3.9.0 vers 3.9.1 (#20966)(#21503)
  • Addon kong : mise à jour de l'image du contrôleur d'entrée kong/kubernetes de 3.4.5 vers 3.5.1 (#20908)(#20969)(#21034)(#21282)
  • Module complémentaire kubevirt : mettre à jour l'image bitnami/kubectl de 1.33.1 vers 1.33.4 (#20911)(#20939)(#21235)(#21283)(#21414)
  • Module complémentaire metrics-server : mettre à jour l'image metrics-server/metrics-server de v0.7.2 vers v0.8.0 (#21033)
  • Registre complémentaire : mettre à jour l'image du registre de 3.0.0 vers 3.0.0 (#21242)
  • Addon Volcano : mettre à jour les images du volcan de v1.11.2 vers v1.12.2 (#20868)(#21351)
  • Module complémentaire kubetail : mise à jour de la version 0.13.3 (#21244)

versions CNI

  • CNI : Mise à jour de Calico de v3.30.0 vers v3.30.3 (#20871)(#20971)(#21416)
  • CNI : Mettre à jour le cil de v1.17.4 vers v1.18.1 (#20968)(#21226)(#21349)

Versions des images de base

  • Refactoriser la bibliothèque spinner et masquer les sous-étapes après la rotation (#21215)
  • ne pas afficher deux fois "créer un problème github" si l'initialisation de kubeadm échoue (#21263)
