LightRAG v1.4.0

Remarques importantes

  • Après la mise à niveau, veuillez vider les documents et le cache, puis réindexer vos documents pour que la fonction de suppression de documents fonctionne correctement. N'oubliez pas de sélectionner l'option « Vider le cache simultanément » lors de la suppression des documents. Si la fonctionnalité de suppression de documents n’est pas immédiatement requise, il n’est pas nécessaire de réindexer les documents.
  • Cette mise à niveau inclut des modifications des paramètres QueryParam. Si vous avez déjà intégré LightRAG à l'aide de QueryParam, veuillez mettre à jour la transmission de vos paramètres conformément au dernier API. Reportez-vous aux paramètres du point de terminaison /query sur la page API de l'interface utilisateur Web.
  • L'intégration de Reranker dans cette version améliore considérablement les performances des requêtes mixtes. Nous vous recommandons d'utiliser le mode de requête mixte par défaut lorsque Reranker est activé.
