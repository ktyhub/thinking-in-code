LightRAG v1.5.6

Remarques importantes

Présentation de PGTableGraphStorage, un nouveau backend de stockage de graphiques basé sur les tables PostgreSQL natives. En éliminant la dépendance à Apache AGE, il simplifie non seulement le déploiement, mais offre également des performances de stockage graphique nettement supérieures avec une empreinte de stockage réduite. Il remplacera le PGGraphStorage basé sur AGE en tant que solution de stockage de graphiques préférée pour PostgreSQL. Cela fait de PostgreSQL la base de données principale tout-en-un incontournable pour LightRAG, permettant à une seule base de données de couvrir les quatre types de stockage.
