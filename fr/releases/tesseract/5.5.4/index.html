tesseract 5.5.4

Ce qui a changé

Cette version corrige 17 avis de sécurité et plusieurs problèmes mineurs. De plus, il fournit quelques mises à jour et améliorations mineures :

  • correction de la version de l'outil de formation sur Windows avec VS2022 : par @zdenop dans https://github.com/tesseract-ocr/tesseract/pull/4590
  • arch,viewer : ajoutez les <cstdlib> et <string> manquants par @tachalorah dans https://github.com/tesseract-ocr/tesseract/pull/4592
  • Correction de l'initialisation statique récursive dans SIMDDetect::GetDetector() par @stweil avec @Copilot dans https://github.com/tesseract-ocr/tesseract/pull/4598
  • exporte GetDetector() à partir de la DLL tesseract, afin que l'éditeur de liens puisse le résoudre. par @zdenop dans https://github.com/tesseract-ocr/tesseract/pull/4602
  • Correction de deux noms \param qui font référence au membre, pas à l'argument de @darkdi dans https://github.com/tesseract-ocr/tesseract/pull/4594
  • Ajouter un nouveau workflow GitHub qui vérifie les commits dans une pull request de @stweil dans https://github.com/tesseract-ocr/tesseract/pull/4604
  • Construire des tests unitaires sans outils de formation par @stweil dans https://github.com/tesseract-ocr/tesseract/pull/4596
  • Docs : mise à jour du lien vers les documents de formation Dead Tesseract par @yzxcj797 dans https://github.com/tesseract-ocr/tesseract/pull/4605
  • Correction de plusieurs problèmes de priorité élevée et moyenne signalés par Coverity Scan par @stweil dans https://github.com/tesseract-ocr/tesseract/pull/4597
  • Correction des avertissements de couverture par @stweil dans https://github.com/tesseract-ocr/tesseract/pull/4606
  • Évitez l'analyse du redémarrage des paragraphes quadratiques par @ilkecan dans https://github.com/tesseract-ocr/tesseract/pull/4599
  • Bump actions/checkout de 4 à 7 par @dependabot[bot] dans https://github.com/tesseract-ocr/tesseract/pull/4607
