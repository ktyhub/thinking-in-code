Spring AI 1.1.5 Release Note

🎯 Points forts

Cette version comprend 9 corrections de bugs, 3 améliorations de la documentation, 11 autres améliorations.

⚠️ Notes de mise à niveau

  • Le modèle Pixtral 12B a été supprimé et Pixtral Large est obsolète. Mettez à jour la configuration de votre modèle pour utiliser les modèles Pixtral actuellement recommandés afin d'éviter des problèmes dans les versions futures. 447d2a4

📢Remarquable

  • Le modèle Pixtral 12B a été supprimé et le modèle Pixtral Large est désormais obsolète. Les tests d'intégration ont été mis à jour pour utiliser les modèles de remplacement recommandés. Les utilisateurs qui s'appuient sur ces modèles doivent migrer vers les alternatives recommandées. 447d2a4

🪲 Corrections de bugs

  • Correction de la méthode doDelete du magasin de vecteurs CosmosDB pour paramétrer correctement les requêtes, empêchant ainsi les vulnérabilités potentielles d'injection SQL et améliorant l'exactitude. 6039e57
  • Correction d'un problème où conversationId n'était pas correctement appliqué dans le filtre VectorStoreChatMemoryAdvisor, ce qui pouvait entraîner une récupération de mémoire incorrecte dans les conversations. 3cccfdf
  • Correction de la gestion des clés dans le convertisseur d'expression de filtre du magasin vectoriel pour garantir que les expressions de filtre sont correctement évaluées. 01386e2
  • Résolution du non-déterminisme des tests dans les tests d'utilisation des jetons de streaming BedrockConverse, améliorant ainsi la fiabilité des tests. 4747a3c
  • Correction du nom de la classe de test pour appliquer correctement le suffixe du test d'intégration, garantissant ainsi une catégorisation et une exécution correctes des tests. #5853
  • Correction de la logique d'analyse de chaîne pour le champ toolChoice dans OpenAiSdkChatModel afin de garantir une gestion correcte des configurations de choix d'outils. aeb33b0 via #5735
  • Correction d'un problème où le paramètre extra_body était incorrectement inclus dans les requêtes OpenAI API sortantes, ce qui pouvait provoquer un comportement inattendu. 4c0120c
  • Résolution de problèmes de génération et de configuration Javadoc pour garantir que la documentation API est correctement produite. 0a71804
  • Correction de la condition de contournement des tests afin que les tests d'intégration soient correctement ignorés lorsque les clés API requises ne sont pas configurées dans l'environnement. bc26dc1

📓Documentation

  • Mise à jour du README pour inclure une note sur les exigences d'architecture du processeur ou des informations de compatibilité. a21e988
  • Ajout d'une documentation expliquant comment les serveurs MCP peuvent republier les outils de MCP clients, clarifiant le modèle de propagation des outils dans les configurations multi-serveurs. #5778
  • Documentation améliorée pour clarifier l'utilisation et le comportement prévus du paramètre extra_body dans les requêtes OpenAI API. 3d4d75b

🔨 Mises à niveau des dépendances

  • Mise à jour de la dépendance Spring Boot vers la version 3.5.14, intégrant les dernières corrections de bugs et améliorations de l'équipe Spring Boot. eb4c9a5
  • Mise à jour de la dépendance Spring Boot vers la version 3.5.13 en tant que mise à niveau intermédiaire. 9b902f8
  • Dépendances d'analyse de documents mises à jour : Apache Tika mis à niveau vers 3.3.0, jsoup vers 1.22.1 et Apache PDFBox vers 3.0.7 pour des capacités de traitement de documents améliorées et des corrections de bugs. f25fc52

🔩 Créer des mises à jour

  • Mise à jour des dépendances du workflow GitHub Actions vers leurs dernières versions pour améliorer la fiabilité et la sécurité CI/CD. 9b70b38
  • Modification du flux de travail de vérification des relations publiques pour utiliser le package mvn au lieu de mvn test pour une validation plus efficace des demandes d'extraction. 7d2e455
  • Les tests d'intégration sont désormais ignorés dans le pipeline CI pour améliorer les performances de build, et le workflow de génération release note a été supprimé. #5688
  • Le projet a été repoussé vers la prochaine version de développement 1.1.5-SNAPSHOT après la sortie. 400dc42

🔐 Sécurité

  • Renforcement du répertoire de cache par défaut utilisé pour les modèles de transformateur afin d'empêcher tout accès non autorisé ou toute falsification des fichiers de modèle mis en cache. aac6b80
  • Correction d'une vulnérabilité potentielle de déni de service où un PDF mal formé pouvait provoquer une allocation de mémoire excessive lors de l'analyse du document. b61ac6a
