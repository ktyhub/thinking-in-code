modifier 1.12.0

🚀 Nouvelles fonctionnalités : Index récapitulatif

Nous lançons Summary Index, une puissante amélioration de notre système de récupération de base de connaissances qui améliore considérablement la précision de la recherche en générant des résumés alimentés par l'IA pour les morceaux de documents.

Contexte

La recherche vectorielle traditionnelle repose sur des intégrations de blocs bruts, qui peuvent manquer de nuances sémantiques et de contexte lors de la correspondance avec les requêtes des utilisateurs. Cela est particulièrement difficile pour les documents longs ou les contenus complexes où les informations clés peuvent être dispersées sur plusieurs morceaux. Summary Index résout ce problème en créant des résumés concis et sémantiquement riches pour chaque morceau de document, qui sont ensuite vectorisés et utilisés comme couche de récupération supplémentaire.

Capacités clés

  • Résumé alimenté par l'IA : génère automatiquement des résumés concis pour les morceaux de documents à l'aide de modèles LLM configurables, capturant les informations sémantiques essentielles dans un format compact.
  • Prise en charge multimodale : Lors de l'utilisation de LLM compatibles avec la vision (par exemple, GPT-4V, Claude-3), le système peut générer des résumés intégrant à la fois du texte et des images à partir de morceaux de documents, offrant ainsi une compréhension plus riche du contexte.
  • Précision de récupération améliorée : Les vecteurs de résumé servent de couche de récupération supplémentaire, améliorant la précision des recherches dans la base de connaissances en faisant correspondre les requêtes au contenu original et aux résumés générés par l'IA.
  • Configuration flexible : Prend en charge les invites de résumé par défaut, vous permettant d'adapter le style de résumé en fonction des exigences spécifiques à votre domaine.
  • Traitement asynchrone : La génération de résumés s'exécute de manière asynchrone, garantissant que l'indexation des documents reste rapide et non bloquante.
  • Édition manuelle des résumés : vous permet de modifier et d'affiner manuellement les résumés générés par l'IA pour mieux les aligner sur le contenu original du bloc, garantissant ainsi que les résumés reflètent avec précision la terminologie et le contexte spécifiques au domaine.
  • Compatibilité de la structure d'index : Fonctionne à la fois avec les modes de segmentation générale et de segmentation parent-enfant, avec une gestion intelligente des relations hiérarchiques entre les documents.
  • Intégration d'index de haute qualité : Disponible exclusivement pour les ensembles de données utilisant la technique d'indexation "high_quality", garantissant des performances optimales pour les bases de connaissances de production.

Autres améliorations

  • Prise en charge multimodale de l'application Agent : L'application Agent prend désormais en charge de manière native les entrées multimodales (images/fichiers).
  • Recherche en texte intégral Qdrant : Implémentation d'une recherche en texte intégral avec prise en charge de plusieurs mots-clés pour la base de données vectorielles Qdrant.
  • Améliorations du flux de travail :
    • Ajout de la prise en charge de l'enregistrement et de la lecture du contexte dans les flux de travail.
    • Ajout du support OpenTelemetry pour les exécutions uniques.
  • Système de plugin : Ajout d'une option pour supprimer ou conserver les clés API lors de la désinstallation d'un plugin.
  • Aperçu du modèle avant la création : ajout d'un aperçu détaillé du modèle d'application avec des graphiques de flux de travail ou des configurations d'application par type d'application.

🐞 Corrections de bugs et mises à jour de sécurité

  • Sécurité :
    • Correctif de sécurité Logstore : résolution d'une injection SQL potentielle, de problèmes de sérialisation et d'une initialisation optimisée.
    • Correction d'une vulnérabilité SSRF dans le téléchargement d'URL WordExtractor.
    • Mise à niveau de tanstack devtools pour corriger la vulnérabilité du séroval RCE.
    • Mises à jour de sécurité pour pdfminer.six, authlib, werkzeug, aiohttp et pycryptodome.
  • Flux de travail et moteur graphique :
    • Correction de problèmes où les nœuds d'itération unique ou de boucle ne pouvaient pas s'exécuter.
    • Correction du crash de NextStep lorsque le nœud cible est manquant.
  • Correction du problème d'analyse de type Union ToolInvokeMessage.
  • API et back-end :
    • Correction du modèle de ressource CORS pour les routes /console/api.
    • Correction de la recherche hybride IRIS ne renvoyant aucun résultat.
    • Correction de problèmes de suppression de compte de facturation.
    • Correction de la commande vdb-migrate pour la migration du segment parent-enfant.
  • Front-end :
    • Correction du bouton "Développer tous les morceaux" qui ne fonctionnait pas.
    • Correction du support de défilement vertical pour les éléments flottants.
    • Correction d'une erreur de validation lors du téléchargement d'images avec des valeurs d'URL Aucune.

⚙️ Modifications de configuration

  • SANDBOX_EXPIRED_RECORDS_CLEAN_TASK_LOCK_TTL : définit le TTL de verrouillage pour la tâche de nettoyage des enregistrements expirés du bac à sable (par défaut : 90000).
  • SMTP_LOCAL_HOSTNAME : remplacement facultatif du nom d'hôte local utilisé lors de SMTP HELO/EHLO.
  • PLUGIN_MODEL_SCHEMA_CACHE_TTL : définit la durée de vie du cache pour les schémas de modèle de plugin (par défaut : 3600).
  • ENABLE_TRIAL_APP : active l'application d'essai (par défaut : false).
  • ENABLE_EXPLORE_BANNER : active la bannière d'exploration (par défaut : false).

Guide de mise à niveau

Déploiements de composition Docker

  1. Sauvegardez votre fichier docker-compose YAML personnalisé (facultatif)

    cd docker
cp docker-compose.yaml docker-compose.yaml.$(date +%s).bak

  2. Obtenez le dernier code de la branche principale

    git checkout main
git pull origin main

  3. Arrêtez le service. Veuillez exécuter dans le répertoire docker

    docker compose down

  4. Sauvegarder les données

    tar -cvf volumes-$(date +%s).tgz volumes

  5. Services de mise à niveau

    docker compose up -d
