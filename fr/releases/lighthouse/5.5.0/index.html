#5.5.0 (2019-10-02)

Changements notables

  • La mise en œuvre préliminaire de la métrique Largest Contentful Paint a atterri (limitation devtools et provided uniquement) et peut être trouvée dans l'audit metrics caché dans le LHR brut JSON (#9706).
  • La création de tâches du thread principal à partir d'une trace est désormais plus robuste. Cela devrait réduire considérablement l'apparition du problème #7764, "Fatal trace logic error - expected start event, got X" (#9491).
  • L'élément <script> id a été ajouté à l'artefact ScriptElements (#9718)

Nouveaux contributeurs !

Merci à @LarsKumbier, @TimvdLippe et @uchoudh pour leurs premières contributions !

Noyau

  • enregistreur réseau : suppression de la solution de contournement terminée par demande rapide (#9744)
  • enregistreur réseau : optimise la détection d'inactivité du réseau (#9712)
  • règles CSS inutilisées : plus d'économies à l'infini (#9731)

Clients

  • devtools : exposer registerLocaleData au travailleur (#9645)
  • devtools : mettre à jour les références à Runtime.cachedResources (#9758)

Documents

  • nouvelle documentation pour exécuter Lighthouse sur pages authentifiées (#9628, #9705)
  • pointez plus de liens de documentation vers web.dev (#9540, #9711, #9761)
  • Lisez-moi : ajoutez d'autres projets associés (#9716, #9743)
  • release : ajout d'un calendrier, plus de tests d'intégration (#9695)
  • ajouter des liens vers plus d'informations sur la limitation et la variabilité (#9734)
  • Mettre à jour le lien du calculateur de notation vers la v5 (#9729) ## Tests
  • ajouter le script dogfood Lighthouse CI à travis (#9677, #9745)
  • rapport : mise à jour de la vérification de utm_medium pour les liens web.dev (#9737)
  • fumoir : ajoutez un chèque pour tout runWarnings (#9732)
  • essayez de télécharger l'ensemble de traces de test de lanterne à plusieurs reprises (#9766)

Divers

  • devtools : supprime le remplacement de version pour les attentes (#9702)
  • supprimer les retours inutiles dans Promise (#9703) * actifs : mettre à jour le logo (#9694) Changelog complet
