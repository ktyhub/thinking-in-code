lighthouse v8.0.0

Majeure Publié2 juin 2021 SourceGoogleChrome/lighthouse Anglais original

Cette page est traduite automatiquement. Le texte anglais original fait foi.

phare v8.0.0

Changelog complet We expect this release to ship in the DevTools of Chrome 93, and is already in PageSpeed Insights!

Changements notables

  • The Performance Category had a number of scoring changes to align with other performance tools and to better reflect the state of the web.
    • The Performance Score has been reweighted (#12577)
    • The TBT and FCP score curves have been updated (#12576, #12556)
    • CLS a été mis à jour vers son nouveau format fenêtré définition (#12554) See the v8.0 Performance FAQ for more detail. <a href="https://github.com/GoogleChrome/lighthouse/blob/master/docs/v8-perf-faq.md"><img width="500" alt="the new metric weightings in the Lighthouse score calculator" src="https://user-images.githubusercontent.com/39191/120410971-de337100-c308-11eb-9fb6-368a33c0855e.png"></a>
  • Le rapport inclut un nouveau filtre de métrique. Pick a metric to focus on the opportunities and diagnostics most relevant to improving just that metric: <img width="350" alt="the new metric filter in the lighthouse report" src="https://user-images.githubusercontent.com/316891/120384128-61de6500-c2eb-11eb-9d15-5b92981d897e.png">
  • The Lighthouse Treemap is now available across all the major Lighthouse clients. Si votre site expose des cartes sources à Lighthouse, recherchez le bouton « Afficher le Treemap » pour voir une répartition de votre JavaScript expédié, filtrable par taille et couverture en cours de chargement.

🆕 Nouveaux audits

  • The new audit csp-xss has been added to Best Practices to evaluate Content Security Policies and suggest ways of making them more secure. Cet audit peut être difficile à réussir en fonction de l'environnement d'hébergement et du contenu de la page. Pour l'instant, il n'est pas noté (#12514, #12551).

🤖💥 Breaking changes for programmatic users

  • Les anciennes métriques estimated-input-latency et first-cpu-idle sont obsolètes, non pondérées et masquées depuis Lighthouse 6. Elles ont maintenant été supprimées (#12553).
  • À partir de Node 13, Node est construit avec full-icu par défaut, donc le très gros polyfill intl a été supprimé des dépendances de Lighthouse. See the readme FAQ if you're stuck with small-icu but need localization support (#12426)
  • L'audit de longue durée uses-webp-images a un nouvel identifiant, modern-image-formats. WebP est désormais plutôt courant, ce qui permet à l'audit de commencer à inclure des détails sur d'autres formats d'image de pointe à l'avenir (#12535)
  • The image-elements artifact has been restructured for clarity (#12568)

🧱 Noyau

  • navigate: only observe longtasks in PerfObserver (#12545)
  • script-treemap-data: do not create nodes with blank names (#12569)

⛏️👷 Roche Fraggle

Support for auditing user flows (#11313)

  • add settings to gather context (#12574)
  • fix usage of distributed conditional type (#12565)
  • Prise en charge du rassembleur inspector-issues (#12530)
  • Prise en charge du rassembleur tags-blocking-first-paint (#12527)
  • Prise en charge du rassembleur response-compression (#12508)
  • align navigation-runner with legacy gather-runner (#12478)

📔 Rapport

  • improve accessibility of metric filter (#12552)
  • treemap: add placeholder, gist, and file upload features (#12511)
  • treemap: support passing gzipped data in url (#12509, #12519)
  • Visionneuse : correction de l'icône générale (#12505)

👥 Clients

  • fix main session OOPIF checks for devtools (#12533)
  • render treemap button in all clients (#12516, #12570, #12590)
  • backport proto formatting fixes (#12566)

🌍i18n

📋Tests

  • synchroniser les tests Web des outils de développement (#12578)
  • treemap : réduire debug.json (#12555)

🕸️ Déps
