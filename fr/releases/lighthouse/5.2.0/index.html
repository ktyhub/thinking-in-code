phare v5.2.0

#5.2.0 (2019-07-24) Sortie prévue de DevTools dans Chrome 77 (septembre 2019)

Nouveaux audits

  • Utilisation tierce, un nouveau diagnostic de performances qui affiche une répartition des ressources tierces dans la page et le temps/octets nécessaires à leur chargement (#9067)
  • Total Blocking Time, une nouvelle mesure expérimentale qui sert de compagnon au TTI pour aider à prioriser le déblocage du thread principal. Puisqu'il est actuellement expérimental, l'audit n'est pas noté et apparaît uniquement dans le LHR brut JSON, pas dans le rapport HTML. (#8975, #9409)

Changements notables

  • tracehouse : le traitement de trace des performances a été déplacé vers son propre répertoire dans lib/tracehouse/ pour servir de bibliothèque plus autonome (9f80524, 1af2edd, 7ba6776, ddff3d6)
  • Les erreurs de sécurité des certificats ne sont plus une erreur Lighthouse fatale, bien que la page d'erreur Chrome renvoie toujours quelques résultats dans le rapport par défaut. Voir [la documentation] (https://github.com/GoogleChrome/lighthouse/blob/82835eb6e4bcece5ac1ce9c575a8d2d9ecd995d1/docs/readme.md#testing-on-a-site-with-an-untrusted-certificate) pour tester une page dans cette situation. (#8865)
