#4.2.0 (2019-03-06) Changelog complet Nous nous attendons à ce que cette version soit livrée dans les DevTools de Chrome 74.

Nouveaux contributeurs !

@pra85, @tgfjt, @gidztech et @jburger424. Merci!

Nouveaux audits

* cibles tactiles : vérifiez que les cibles tactiles sont de bonne taille et distinctes (#5846)

Rapport

  • réorganiser les groupes d'audit a11y (#7129)
  • clip URL exceptionnellement longues dans l'en-tête (#6858)
  • moteur de rendu de détails : utiliser de nouveaux types de détails d'audit (#7192)

Noyau

  • fid : ajoutez le FID potentiel maximum à JSON (#5842)
  • artefacts : unifiez AnchorElements en un seul collecteur (#7101)
  • artefacts : inclure les scripts en ligne dans l'artefact Scripts (#7065)
  • artefacts : créer un artefact calculé ViewportMeta (#7264)
  • artefacts : ajoutez l'artefact de base TestedAsMobileDevice (#7280)
  • Temps de démarrage : meilleure attribution (#7059)
  • Efficacité en octets : utilisez des ratios GZIP plus optimistes (#7210)
  • cache-headers : correction d'une faute de frappe dans must-revalidate (#7189)
  • moteur de rendu de détails : ajout d'un moteur de rendu de détails d'extrait (#6999)
  • diagnostics : ajouter des audits de diagnostic (#7052)
  • pilote : ajout du délai d'attente waitForFCP (#7356)
  • pilote : collecte les requêtes réseau des iframes hors processus (#6922)
  • pilote : ajoutez ' Chrome-Lighthouse' à l'agent utilisateur (#7297)
  • émulation : déplacer l'agent utilisateur Chrome vers m74 (#7211)
  • fcp-3g : supprimez les i18n inutilisés pour la compatibilité LR (#7103)
  • font-display : suivez plus précisément les spécifications CSS (#7191)
  • éléments d'image : limiter le temps de récupération en taille naturelle (#7274)
  • lanterne : ajout d'une configuration pour l'analyse de réseau précalculée (#7239)
  • lhr : inclure resourceSize dans l'audit des requêtes réseau (#7056)
  • manifest : supprime l'artefact Manifest au profit du nouveau WebAppManifest (#7078)
  • métriques : n'échouent pas si TTI échoue (#7132)
  • analyse de réseau : définissez le RTT supplémentaire sur 0 et non sur NaN (#7156)
  • network-recorder : les redirections démarrées par le script sont définies comme initiateurs (#7352)
  • plugins : ajout du support pour les groupes (#7304)
  • SEO : supprimer l'audit manuel adapté aux mobiles (#7223)
  • seo : ajout d'un test rel=canonical pour auditer une racine de domaine (#7228)
  • Tap-targets : désactivez la taille de la police et appuyez sur l'audit des cibles sur le bureau (#7393)
  • Tap-targets : rendre les échecs des cibles tactiles plus visibles (#7373)
  • tsc : correction de la hiérarchie des types de détails d'audit (#7177), #7154, #7285)
  • unused-css : changer le titre Différer -> Supprimer (#7235)
  • donne une solution de secours pour le tri des détails de test défectueux dans le nœud 11 (#7216)
  • supprimer le délai d'expiration du protocole pour le bug du manifeste de l'application dans LR (#7184)
  • optimiser l'audit des cibles tap-cibles (#7130)
  • supprimer NO_ERROR runtimeError lorsqu'il n'y a pas d'erreur (#7358) ##CLI
  • rédiger un rapport dans runLighthouse avant de quitter Chrome (#7339)

Dépôts

  • snyk : mettre à jour l'instantané snyk (#7277, (#7233, #7167), #7116)
  • mises à jour pour éliminer les vulnérabilités transitives (#7319)
  • mettre à jour cssstyle pour analyser davantage de couleurs nommées, couleurs CSS4 (#7283)

Documents

  • contribute.md : correction de fautes de frappe (#7170)
  • Correction du commentaire sur le taux de limitation et ajustement de la bande passante Comcast (#7374)
  • améliorer les explications sur l'extension et l'utilisation des fichiers de configuration (#7354)
  • Mettre à jour les documents de limitation vers la version publique (#7332)
  • readme : ajoutez Lighthouse-keeper aux intégrations (#7399)
  • Docs (projets associés) ajoutent React-Lighthouse-Viewer (#7262)
  • readme : Ajoutez Fluxguard à la liste des intégrations (#7249)
  • variabilité : ajouter un document de variance dédié (#7175)

I18n

  • Correction de la description du FID potentiel maximum (#7353)
  • Correction de la syntaxe ICU (#7320)
  • chaînes de référencement préparées pour i18n (#6860)
  • traduire les chaînes dans l'audit des cibles tap-targets (#7111)
  • Titre et description de la catégorie a11y (#7113)
  • importer les messages d'accessibilité et d'erreur lh traduits (#7008) ## Tests
  • Pilote refactor, plus de tests gotoURL (#7270, #7242, #7212)
  • exécuter le nœud 11 dans CI (#7230)
  • remplacer les instantanés non volatils par des littéraux en ligne (#7217)
  • Smokehouse : refactoriser pour activer Smokerider (#7284)
  • fumoir : +/- opérateur (#7343)
  • Smokehouse : test gzip pour affirmer la taille des transferts et des ressources (#7286)
  • Smokehouse : échec en cas de non-concordance de finalUrl/errorCode (#7227)

Divers

  • tap-targets : supprime les lignes avec des espaces de fin (#7105)
  • nettoyer node_modules/.cache avant que Travis ne crée son cache (#7388)
  • convertir les commentaires Flags en jsdoc pour une meilleure intellisense (#7359)
  • exporter les chaînes UA depuis emulation.js (#7318)
  • Correction d'une faute de frappe dans le commentaire (#7296)
