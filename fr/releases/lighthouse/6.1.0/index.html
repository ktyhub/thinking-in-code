phare v6.1.0

#6.1.0 (2020-06-25) Changelog complet Nous prévoyons que cette version sera livrée à DevTools dans [Chrome ~85~ 86] (https://chromiumdash.appspot.com/schedule) et à PageSpeed Insights dans un délai de 2 semaines.

Nouveaux contributeurs

Merci à nos nouveaux contributeurs 👽🐷🐰🐯🐻 !

  • Loftie Ellis @lpellis *Marvin Frachet @mfrachet *Matt Hobbs @Nooshu
  • Peter Marshall @psmarshall

Changements notables

  • Si une page contient des cartes sources JavaScript accessibles au public, Lighthouse les collectera pour améliorer l'audit unused-javascript. Dans les futures versions de Lighthouse, les cartes sources seront utilisées pour des audits entièrement nouveaux (#10990).
  • Le rapport utilise désormais KiB au lieu de KB. Il s'agit simplement d'un changement d'étiquette ; la valeur était et est toujours égale à 1024 bytes (#10870). <img src="https://i.imgur.com/1gSdPw5.png" alt="JavaScript inutilisé avec cartes sources" width="800px">

Nouveaux audits

  • tâches longues : un nouveau diagnostic de performances qui affiche les tâches bloquant le thread principal les plus longues pendant le chargement (#10736)
  • crawlable-anchors : un nouvel audit SEO qui vérifie que les ancres renvoient à des URL résolubles (#10662)

Noyau

  • inutilisé-javascript : augmenter le seuil à 20 Ko (#10906)
  • layout-shift-elements : contribution CLS de surface par élément décalé (#10968)
  • émulation : versions bump chrome (#10787)
  • sensible à la taille de l'image : quantifier les DPR (#10801)
  • tâches longues : ajoutez la propriété startTime (#10942)
  • améliorer la résilience des collecteurs dépendants de nodeId (#10877)
  • median-run : ajoutez computationMedianRun à la lib (#10859)
  • préchargement : ignorer les requêtes cross-frame (#10847)
  • nouveau collecteur de problèmes d'inspecteur pour les événements Audit.IssueAdded (#10664)
  • Refactoriser la subRow, renommer en subItem (#10867, #10978)

Expérimental

  • Legacy-javascript : correction de la détection core-js 3 (#10852)
  • Legacy-javascript : utiliser un site Web tiers pour la notation (#10849)
