<summary>Veuillez utiliser le déploiement du code source pour les systèmes MacOS/Linux</summary>

  1. Installez les dépendances :

    # macOS
brew install libsndfile git

brew tap homebrew-ffmpeg/ffmpeg
 
brew install homebrew-ffmpeg/ffmpeg/ffmpeg

# Ubuntu/Debian
sudo apt-get install ffmpeg libsndfile1-dev

  2. Installez UV :

    curl -LsSf https://astral.sh/uv/install.sh | sh

  3. Clonez et démarrez :

    git clone https://github.com/jianchang512/pyvideotrans.git
cd pyvideotrans
uv sync
uv run sp.py

Remarques sur la décompression :

  • Décompressez le package compressé 7z. Après décompression, recherchez le fichier sp.exe et double-cliquez pour démarrer le logiciel. Vous ne pouvez pas double-cliquer pour l'exécuter dans le package compressé.
  • N'extrayez pas le logiciel dans un dossier nécessitant des droits d'administrateur tel que Program Files sur le bureau ou le lecteur C.
  • Évitez les erreurs de chemin : n'incluez pas de caractères chinois, d'espaces ou de symboles spéciaux dans le chemin de décompression.
  • Si une erreur se produit lors de l'utilisation du logiciel 7zip pour décompresser, veuillez essayer d'utiliser Bandizip ou 360 Compression Software pour décompresser.
