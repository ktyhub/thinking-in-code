hyperframes v0.9.59

HyperFrames v0.9.59

Sorti le 2026-11-16.

Le lecteur d'aperçu obtient un bouton plein écran, et un rendu échoué indique maintenant pourquoi. Renders, Studio et le CLI s'en tiennent aux fichiers propres du projet et aux hôtes médiatiques publics.

Fonctionnalités

  • CLI : Diff --hide note le calque d'un projet en fonction de ce qu'il ajoute (e6d5c699b, #7972).
  • Lecteur : Ajoutez un bouton plein écran au lecteur d'aperçu (5be6c1580, #7726).
  • Core : Les réponses Describe portent l'étiquette d'élément du sélecteur et le studio exporte standInHandle (51ae92510, #7936).

Correctifs

  • Les fichiers cachés et d'identification restent en dehors de Studio, de l'historique et des peluches (c68c78445, #7979).
  • Core : Une page marquée pour un autre site donne uniquement la lecture à ce site (c4d607c7f, #7980).
  • Studio Server : Aucune route d'écriture ne touche les fichiers exécutés par d'autres outils ou trust (2a28e4368, #7964).
  • CLI : La vérification de mise à jour des compétences ne lit jamais la configuration git d'un projet (e368db138, #7975).
  • Lint : Exécutez Studio et Producer Lint à partir du propre thread de l'hôte (778a00564, #7974).
  • Producteur : Paramètres par défaut des médias de sous-composition de sonde (95e4e7f88, #7550).
  • CLI : Validez et les images clés impriment le texte du projet avec des caractères de contrôle comme échappements visibles (ce8d55d30, #7958).
  • Vérifiez : Une source multimédia dont le chargement a échoué n'est pas signalée comme un délai d'attente (5e0c3db12, #7954).
  • CLI : L'aide affiche une fois la valeur par défaut de chaque option (d7f8d77fb, #7953).
  • CLI : Render --json donne à chaque outil manquant, un emplacement occupé et un ancien nœud son propre code (47d007e5b, #7842).
  • Sdk Playground : La configuration Vite se charge sur le nœud 22 avant 22.18 (c7876f333, #7805).
  • Vérifiez : Marquez un résultat de contraste par sa gravité et citez son texte (ec5a4e2a1, #7752).
  • Lecteur : Le correctif pour le gel de l'aperçu lorsque plusieurs clips partagent un long enregistrement est extrait de cette version, car il a empêché une application intégrant l'aperçu d'afficher une modification (42508c1ef, #7795 ; annulé par 33e1a36a3, #7978).
  • L'instantané ignore les fichiers privés, aucun démultiplexeur d'art de texte, le texte d'avertissement échappé (8959deb00, #7943).
  • CLI : Capture nomme le port de son serveur de pages local dans l'entrée de contournement (a9b0371c8, #7965).
  • CLI : Un rendu qui échoue indique pourquoi, même en cas de crash ou de sortie silencieuse (2623ded13, #7957).
  • Studio : Un long fichier audio provenant de l'extérieur du projet n'est jamais décodé pour sa forme d'onde (c77cd301c, #7961).
  • Publier : Téléchargez uniquement ce que npm lit comme coché ; les balises publient uniquement les commits principaux, suivants ou alpha (5f4637977, #7959).
  • Moteur : Les lectures d'URL multimédia atteignent uniquement les hôtes publics dans un réseau de pages restreint (994fbbde2, #7946).
  • Cli,engine : Épinglez l'hôte direct du serveur de pages sur un port explicite et la propre origine du Studio (dbc9c1826, #7945).
  • Producteur : Un rendu en attente sur un long mixage audio indique qu'il traite l'audio (df698a029, #7952).
  • Core : Une page de capture charge un clip sans longueur définie uniquement lorsqu'il est dû (9e5048772, #7938).
  • Studio : L'analyse des battements ne sélectionne jamais un enregistrement plus long qu'une chanson (87955b890, #7944).
  • CLI : Propre répertoire de verrouillage de l'emplacement de rendu ; refuser les fichiers de cache que d'autres comptes peuvent écrire (071a2da0b, #7951).
  • CLI : N'écrivez jamais d'enregistrements de projet via des liens symboliques sous .hyperframes (061ff5bbb, #7950).

Documents et exemples

  • Changelog : Résumé hebdomadaire 2026-11-09-2026-11-16 (af873924d, #7969).
  • Publier : Supposons que la publication n'attende aucune approbation et que seuls les administrateurs envoient des balises de version préliminaire (a707e4737, #7960).

Catalogue

  • CLI : Caractères de contrôle d'échappement dans le texte du projet, de la page et du registre (6f88be394, #7913).
  • Mcp : Exécutez la publication du registre MCP dans l'environnement de registre mcp (45ff3526c, #7966).
  • Ci : Une exécution de publication de catalogue dont le principal a dépassé se termine correctement au lieu d'échouer (77e675574, #7816).
