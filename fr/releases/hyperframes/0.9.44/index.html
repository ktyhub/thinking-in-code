hyperframes v0.9.44

HyperFrames v0.9.44

Sorti le 2026-11-14.

Check avertit désormais lorsque le texte quitte les zones de sécurité d'une vidéo sociale de 9h16. Les aperçus libèrent le décodeur d'un clip une fois que la tête de lecture le quitte, et un fondu audio annulé ne fait plus planter la page. Définissez HYPERFRAMES_OWNER pour indiquer quelle exécution a démarré un navigateur restant.

Fonctionnalités

  • CLI : Nommez l'identifiant du propriétaire d'un appelant sur les navigateurs et vérifiez à chaud qu'il démarre (798c241e4d0cf, #7687).
  • CLI : Check avertit lorsque le texte quitte les zones de sécurité sociale de 9h16 (45882027bd284, #7680).

Correctifs

  • Studio : Modifier clips ajouté à un projet en dehors de Studio (cb072eb047efa, #7686).
  • Core : Empêche une enveloppe audio annulée de faire planter la page (49623307ce86c, #7682).
  • Core : Libérez un aperçu du décodeur du clip lorsque la tête de lecture le quitte (f7b49f12078e1, #7679).

Performances

  • Core : Une vidéo d'aperçu rechargée se resynchronise uniquement elle-même (92816ed56bde0, #7684).

Catalogue

  • CLI : Signaler un type de catalogue non valide comme erreur d'utilisation (affa03b60fb08, #7678).
  • Publiez le MCP HyperFrames hébergé dans le registre MCP officiel (0f6ed7d57bc9c, #7676).
