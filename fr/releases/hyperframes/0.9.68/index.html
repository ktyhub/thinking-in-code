hyperframes v0.9.68

HyperFrames v0.9.68

Sorti le 2026-11-18. Un rendu dont la page Chrome a été fermée lors de l'ouverture la rouvre maintenant ou indique pourquoi il ne peut pas le faire. Les aperçus scellés conservent la taille propre d'une vidéo non dimensionnée et affichent des valeurs animées, et les rendus peuvent envoyer tout leur trafic via un proxy sortant.

Fonctionnalités

  • Engine : Les rendus envoient du trafic de page via le proxy de sortie dans HYPERFRAMES_CAPTURE_PROXY (a2830467e, #8196).

Correctifs

  • Core : Une vidéo sans taille propre conserve la taille de son fichier dans l'aperçu (e9eac3f9d, #8211).
  • Moteur : Rouvrez une page de rendu dont l'onglet Chrome s'est fermé lors de l'ouverture, ou indiquez pourquoi elle ne peut pas (d205e5948, #8188).
  • Studio : Un redimensionnement scellé enregistre son ancre sur l'itinéraire par lequel GSAP le déplace (f149d76ed, #8193).
  • Compétences : L'étage du lanceur est 0.9.67 (855ad35c2, #8205).
  • Studio Server : Le proxy rejoint les éléments de la liste par leur nom ; un verrou postdaté ne peut pas retenir les serveurs (fadad3f12, #8204).
  • Studio : Une suppression de timeline refusée conserve l'état du serveur dans son message (11cc1a519, #8171).
  • Studio : Le panneau de propriétés affiche les valeurs animées d'un aperçu scellé (f6c9d09de, #8203).
  • CLI : Échapper au projet restant et au texte de connexion, ignorer les rappels sans état (e83ddaed2, #8177).
  • Studio : La copie, la duplication et les mises à jour des voies audio fonctionnent dans un aperçu scellé (30d4cd26c, #8192).
  • Studio : Un aperçu scellé s'arrête à la pression et rouvre la sélection d'un lien (e5566b3dc, #8135).
  • CLI : Rejeter les valeurs --timeout et --needed de mauvaise facturation en tant qu'erreurs d'utilisation (559499453, #7910).
  • Producteur : Les CV et les jointures proxy réutilisent uniquement les éléments créés par cette installation (43582dcb7, #8089).
  • CLI : Un rendu qui a échoué sur un fichier vidéo demande de vérifier le fichier, de ne pas essayer Docker (72cb2bd9b, #8083).
  • Vérifiez : Un nombre avec un séparateur compte pour un mot dans le temps de lecture d'une ligne (7a63b10d7, #8084).
  • Studio : Une modification de valeur ou d'image clé s'affiche dans un aperçu scellé (a1ee40094, #8151).

Interne

  • Core : Les tests de recherche de polices lisent uniquement leurs propres polices de luminaire, pas celles de la machine (284b28bfc, #8200).
