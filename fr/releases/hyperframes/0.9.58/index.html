hyperframes v0.9.58

HyperFrames v0.9.58

Sorti le 2026-11-16.

Studio exporte les lectures et les remplacements d'éléments cochés d'un aperçu scellé, et les rendus, la sculpture et le moteur audio restent dans les propres fichiers du projet. Cette version contient également tout ce qui est préparé sous le nom de v0.9.57, qui n'a jamais atteint npm.

Fonctionnalités

  • Studio : Une image d'aperçu scellée transmet les clés de lecture de Studio (b741ecf13, #7844).
  • CLI : Afficher et ouvrir la page pour gérer ou annuler un forfait payant (b2e6076b7, #7784).
  • Studio : Exportez les lectures et les remplacements d'éléments cochés d'un aperçu scellé (a0848ad35, #7918).

Correctifs

  • CLI : Les vérifications et informations ne sondent jamais les URL de médias distants d'une composition (78648113d, #7942).
  • CLI : Open démarre l'application de bureau dans le dossier de départ, et non dans le dossier dans lequel elle s'exécute (a2e7306b2, #7937).
  • CLI : Miniatures Studio et nettoyage Ctrl-C sous un réseau de pages restreint (707e20f18, #7941).
  • Studio Server : Un hôte qui a créé une page sur le générateur de build peut quitter (e8f1fff5f, #7939).
  • CLI : Les commandes qui ouvrent une composition honorent PRODUCER_RESTRICT_PAGE_NETWORK (49e9424ba, #7935).
  • Moteur,producteur,cli : Les entrées multimédia refusent les formats qui ouvrent d'autres fichiers (ead110aab, #7931).
  • Moteur : Vérifiez également l'adresse résolue d'un téléchargement restreint sous Bun (04b690361, #7860).
  • Parseurs : Expansion totale liée dans la ligne de temps GSAP (aed28486f, #7930).
  • Les .hyperframes imbriqués restent privés, le serveur de page de capture vérifie l'hôte, le projet manifeste le code PIN n° CLI (d5f0b1a5b, #7927).
  • Studio Server : Les aperçus de sous-composition s'appuient sur le fil de requête dans un délai (d159ec51c, #7857).
  • Publier : Une première tentative de publication n'échoue plus lors de la recherche d'un artefact qu'une nouvelle tentative réutiliserait (9f85cf0a2, #7929).
  • Lecteur : La vérification audio de Safari ne s'écaille plus lors d'une lecture propre de dix prises (916bcc83a, #7685).
  • Core : Lecture en fondu et en effacement d'une vidéo étalonnée en couleurs en aperçu et en exportation (889143eac, #7756).
  • Utilisation des médias : Le bundle carve exporte analyseCarveDynamics, donc carve s'exécute à nouveau (94e499d8c, #7893).
  • Parseurs : Au-delà de 10 000 éléments identiques, chaque identifiant est toujours unique (472909914, #7919).
  • Producteur : La copie du plan vérifie chaque entrée de projet, quel que soit son nom (7aaeb9371, #7906).
  • Producer : La compilation de rendu n'intègre jamais les fichiers de projet privés nommés par @font-face (209477b65, #7925).
  • Studio : L'image d'aperçu prend la taille de sa boîte dans le même cadre, mis à l'échelle ou non (1e040f6fe, #7907).
  • Moteur, producteur : Les lecteurs multimédias de rendu ignorent les fichiers de projet privés et les entrées d'art textuel (6411df4e3, #7928).
  • Utilisation des médias : Carve exécute sa propre copie de l'analyse du noyau, jamais celle du projet (25c603521, #7926).
  • Studio : Un hôte qui affiche une image fixe obtient un rechargement d'aperçu avec une page à la fois (dab8dc807, #7905).
  • Avertissements selon lesquels les fichiers de projet de nom impriment des caractères de contrôle sous forme d'échappements visibles (d42bbd67f, #7863).
  • Studio : Les brouillons de récupération sont conservés par le serveur de chaque projet, jamais par le navigateur (2be03408d, #7904).
  • Utilisation des médias : Le moteur audio lit et écrit uniquement dans le dossier du projet (c2c6d8c59, #7897).
  • CLI : Les sorties par lots d'un modèle qui commence par un espace réservé restent dans le dossier de travail (cf44c60cd, #7868).

Documents et exemples

  • Compétences : L'échantillonnage de style extrait le modèle à chaque fois, donc une copie reçue est vérifiée en premier (d796fd59e, #7924).

Interne

  • Compétences : Lisez le jeton ClawHub à partir de l'environnement clawhub principal uniquement (5d5e2c062, #7923).
  • Studio Server : Give teste le plafond de 20 s du CLI afin qu'un exécuteur CI occupé arrête de les expirer (8ec98be29, #7933).
  • Moteur : Les tests du pool de navigateurs ne démarrent jamais le Chrome mis en cache de l'hôte (cadcdb955, #7759).
  • Publier : Publier uniquement les archives tar npm lit comme le fait la vérification (dac0468f7, #7922).
  • Publier : Lier les tentatives de version Lambda aux artefacts d'exécution immuables (8e8eeb205, #7920).
  • Publier : La version conserve uniquement les broches npm des actifs Lambda ou cette exécution construite (11a7d2749, #7880).
