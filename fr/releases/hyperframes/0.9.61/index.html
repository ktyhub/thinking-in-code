hyperframes v0.9.61

HyperFrames v0.9.61

Sorti le 2026-11-17.

Les projets reçus et les fichiers qu'ils atteignent restent dans leur propre dossier dans le rendu, l'aperçu et Studio, et un aperçu scellé se recharge en une fraction de seconde. Cette version comporte également toutes les modifications répertoriées pour 0.9.60. Cette version n'a jamais atteint npm : sa publication a été refusée car elle a été exécutée à partir de la référence de fusion de la version PR, et depuis #8020, une version stable est publiée à partir du push vers main qui la fusionne.

Fonctionnalités

  • Moteur : La télémétrie de rendu indique pourquoi une page ne peut pas réutiliser des images fixes (c8df284b2, #7993).
  • Studio : Les animations analysées par la source d'un élément font partie du API de Studio (efc91fc87, #8061).
  • Producteur : Appliquez les dimensions de sortie attendues avant la capture (8a13b2caf, #7871).

Correctifs

  • Producteur, Analyseurs : La compilation de rendu ne recherche jamais les ressources d'une scène sur un autre ordinateur (524ea46bf, #8063).
  • CLI : Refuser les copies multimédia-proxy demandées par un autre site en jeu et le serveur statique (f97e28905, #8058).
  • Producteur : Les lecteurs revérifient les compositions liées à l'extérieur, et le refus nomme une étape que chaque surface peut franchir (4721739ee, #8034).
  • CLI : Laissez les fichiers extérieurs au projet hors des téléchargements de sites Lambda et Cloud Run (39347da9d, #8060).
  • CLI : Un hôte peut nommer les projets dont les fichiers reçus sont attendus ou tous reçus (5ea86450a, #8025).
  • Core : Seules les pages d'aperçu de Studio obtiennent le port d'édition et l'annulation définit uniquement les attributs sûrs (55291c00c, #8057).
  • Lint : Correspond littéralement à la balise de fermeture d'un wrapper chronométré (3e01f691d, #8028).
  • Studio : Chaque glissement s'affiche comme sa propre étape d'annulation une fois sa sauvegarde effectuée (647bdd4d7, #8033).
  • CLI : Un démarrage inversé refusé indique si HeyGen a envoyé le refus (53080581c, #8053).
  • Producteur : Limiter l'expansion totale de la sous-composition d'un rendu (b29e40d70, #8045).
  • Inspecteur : Le Chrome de l'inspecteur démarre en tant que root ou dans un conteneur (f91bbf0da, #8050).
  • Refuser les chemins multimédias que le démultiplexeur image2 de ffmpeg lirait comme un modèle (fe93f9cd4, #8047).
  • CLI : Une clé de fournisseur .env de projet cède la place aux propres informations d'identification de la personne (14c4e4c26, #8041).
  • CLI : Échapper à la sortie audio et à l'utilisation multimédia, épingler les fichiers de modèle (c4439890c, #8013).
  • Producteur : Gardez les pré-vérifications multimédias de l'étage de sonde linéaires en termes de taille de page (e21f56dca, #8044).
  • Studio : L'étalonnage des couleurs fonctionne dans un aperçu scellé (d7d416124, #7999).
  • Moteur : Lié la pré-vérification de l'hôte proxy au délai d'expiration du téléchargement (06b632017, #8048).
  • Moteur : Les lancements GPU, host-ceiling et HDR conservent le bac à sable là où l'hôte le permet (7b27fbc84, #8038).
  • Studio Server : Les lectures du cache ne suivent jamais un lien fourni par le projet (70820b386, #8039).
  • Moteur : Vérifiez les hôtes de téléchargement proxy ; garder les téléchargements GIF bruts privés (5fcce21a6, #8040).
  • Compétences : Locate.mjs lit la police système en place, pas une copie /tmp partagée (5b2990fc1, #8042).
  • Studio : L'édition des sous-titres fonctionne dans un aperçu scellé (915021265, #8002).
  • Producteur : Bouchez l'encodeur logiciel sur les noyaux de capture qui laissent libres (f89f6d3d4, #8019).
  • Studio : Le rechargement d'un aperçu scellé s'affiche en une fraction de seconde, pas après 8 s (9daa7e876, #8015).
  • Compétences : Exécutez les assistants TTS fournis à partir du dossier de compétences, et non du répertoire de travail (6115945cf, #8035).
  • Un enregistrement de fichiers reçus suit les renommages, déplacements et suppressions de Studio, et un enregistrement imbriqué ne peut pas être déplacé hors de portée (f5bb3e551, #7989).
  • Studio Server : Une page de bouclage sans métadonnées de récupération est marquée à moins que l'application ne l'ait encadrée (b6e1e8dda, #8017).
  • Studio : La commande de rendu copiée ne contient aucun texte de composition qu'un shell peut exécuter (19743ea09, #8012).
  • Les rendus de dev Studio suivent la règle du projet reçu, et les clés .env d'un projet reçu ne remplacent jamais celles de la personne (8239fe470, #8004).
  • Producteur : Les rendus Trusted refusent les compositions liées à l'extérieur à moins que --include-outside-files (00d03a412, #8024).
  • Studio Server : Les décodages audio sont limités, s'arrêtent lorsque personne n'attend et leur cache est plafonné (5f6995fe7, #7991).
  • Studio : Un modal ouvert depuis un popover ou un menu se ferme en premier sur Escape (c8235f123, #7976).
  • Moteur : La sonde GPU, la capture HDR et la sonde de plafond hôte conservent un bac à sable requis (fb5f9e52c, #8018).
  • CLI : Render --docker applique la règle du projet reçu sur l'hôte (e58fb3249, #8016).
  • Studio : Une annulation sur un aperçu scellé s'affiche sur place, pas après un rechargement (fee03bfbe, #8009).
  • CLI : Les fichiers extérieurs au projet ne sont téléchargés qu'une fois approuvés (22b615f1a, #7995).
  • CLI : Comparer et les images clés --shot ne servent que les fichiers portant des noms de fichiers HTML simples (346579b6b, #8006).
  • La préparation de l'image d'aperçu ne lit aucun HEIC ou GIF en dehors du projet, sauf si le rendu le ferait (f880693cf, #8001).
  • Moteur : La vérification du dossier de playlist lit les noms de deux-points, de requêtes et de fragments au fur et à mesure que ffmpeg les résout (38aaad1b2, #8014).
  • Studio Server : Aperçu des images fixes lié et conservation du travail proxy sur les propres pages du Studio (bffe8d598, #8007).
  • Producteur : Les rendus locaux excluent les scripts extérieurs au projet, sauf s'ils sont inclus (581a43bb6, #7998).
  • CLI : Seule l'origine propre du Studio peut encadrer la page Studio (02c1fb48e, #8000).
  • Producteur : Vérification des médias par sonde linéaire et rendu des compositions HTML de refus de plus de 16 Mo (d53b6059b, #7992).
  • Studio Server : Les écritures et les revendications de l'historique suivent la règle d'écriture de Studio (32fe10a8b, #7988).
  • CLI : Les boîtes d'erreur et les lignes d'échec de commande impriment les caractères de contrôle sous forme d'échappements visibles (5979991d5, #7987).

Interne

  • Publier : Une version stable nécessite l'approbation d'un responsable, pas celle d'un compte (4807799c4, #8062).
  • Augmenter le budget compact du producteur à 936 000 octets (909a9b183, #8054).
  • Publier une release stable à partir du push qui fusionne sa release PR (5f6007ffc, #8020).
  • Publier : Une balise de version préliminaire est publiée uniquement sur une balise de distribution autorisée (9fae4ffd8, #7963).
  • CLI : L'aperçu d'un projet reçu convertit toujours une photo à l'intérieur (0ad24ba83, #8021).
