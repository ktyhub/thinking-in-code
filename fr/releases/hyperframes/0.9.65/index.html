hyperframes v0.9.65

HyperFrames v0.9.65

Sorti le 2026-11-17. L'aperçu scellé de Studio dessine désormais des trajectoires de mouvement, lit les images clés et maintient un calque déplacé en place lorsque vous ajoutez une image clé. Les événements d'erreur et d'analyse de Studio ne contiennent plus votre texte d'erreur, vos chemins de fichiers ou vos sélecteurs.

Fonctionnalités

  • Studio Server : Laissez un hôte compter les requêtes refusées par le API avec 403 (078e54d00, #8049).

Correctifs

  • Studio : Les événements d'erreur envoient une classe, une forme et les propres images de Studio, pas les mots de l'erreur (195aa2f0c, #8114).
  • Studio : L'ajout d'une image clé sur un aperçu scellé maintient un calque déplacé en place (ce3decb6b, #8117).
  • CLI : Le passage facial de Check lit uniquement les médias que la page peut charger (c4a4167aa, #8116).
  • Studio : Un aperçu scellé se déplace et enregistre un calque que son animation déplace (7a9d78e69, #8105).
  • Studio : Analytics envoie des faits sur le chemin et le sélecteur, pas les chemins et les sélecteurs (d87285387, #8109).
  • Studio : La trajectoire de mouvement est dessinée et peut être créée dans un aperçu scellé (373d987e3, #8108).
  • Compétences : Sélectionnez les versions autonomes de CLI via le lanceur (414adffb8, #8102).
  • Figma : Écrivez les sorties .media et composants sans suivre les liens (a765c9379, #8111).
  • Studio : Le banc d'édition attend la fin de l'échange d'aperçu une fois qu'un élément simple gagne des images clés (ba62d7748, #8113).
  • CLI : Le nettoyage et les lectures de processus de Windows Chrome ne transmettent plus le texte de la commande PowerShell (b930c4d2d, #8085).
  • Release : La vérification du pusher sans compte lit son fichier directement, sans tube (740796888, #8095).
  • Producteur : Lié la vérification du sélecteur de média statique à la page qu'il parcourt (435dd0e68, #8091).
  • Studio : Un élément sélectionné reste dessiné et déplaçable après le rechargement d'un aperçu scellé (1bf629c1d, #8081).
  • Studio : Un click après deux recherches rapides ajoute l'image clé dans un aperçu scellé (93622154e, #8103).
  • Version : Répertoriez le serveur MCP sous com.heygen/hyperframes, signé par la clé de heygen.com (88ba1b4d7, #8106).
  • Utilisation des médias : Les scripts audio jugent un .env reçu selon la règle du CLI (bc5259d2d, #8086).
  • Utilisation des médias : Écrivez la sortie du générateur local dans des dossiers privés par exécution (ac33c1f2b, #8030).
  • Studio : Les lectures d'images clés et de valeurs GSAP fonctionnent dans un aperçu scellé (133965e4f, #8003).
  • CLI : Conserver les fichiers reçus que l'enregistrement conservé par un hôte répertorie toujours (183bf2a41, #8100).
  • CLI : Supposons qu'un fichier reçu répertorié ait disparu et supprimez la ligne d'un fichier multimédia lors du changement de nom (4a59fef2d, #8098).

Catalogue

  • Surveillez le registre MCP toutes les heures pour le serveur de listes HeyGen. json n'a jamais été détenu (0b0108f2f, #8107).
  • Registre : Utilisez le lanceur installé dans les guides de blocs (1c99314a6, #8101).

Interne

  • Github : L'analyse secrète ignore le manifeste de compétences généré (06578d941, #8115).
  • Studio : La vérification de réponse GSAP partage l'enregistrement de trame et gère les vérifications (53a493edc, #8104).
