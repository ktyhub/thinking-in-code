hyperframes v0.9.53

HyperFrames v0.9.53

Sorti le 2026-11-15.

Les pages contenant de nombreux caractères chinois, japonais ou coréens chargent désormais leurs polices en quelques petites requêtes, de sorte qu'elles s'affichent au lieu d'expirer. Le rendu cloud ne refuse plus un fichier qui ne contient que des noms de page inutilisés, et les téléchargements répertorient désormais tous les fichiers qu'ils transportent en dehors du projet.

Fonctionnalités

  • CLI : Les téléchargements répertorient tous les fichiers qu'ils transportent depuis l'extérieur du projet (e426ce4eb, #7831).

Correctifs

  • Producteur : Les transitions de shader se fondent dans Node lorsque la page ne peut pas les composer (fb1a383bd, #7840).
  • CLI : Le test de coupure de téléchargement cesse d'échouer sur les exécuteurs Windows occupés (2ea78c0ab, #7843).
  • Moteur : Les téléchargements restreints appliquent la règle d'adresse du proxy de capture (125a9446b, #7839).
  • Les aperçus de l'hôte LAN et les pages de lecture refusent les autres sites sans récupérer les métadonnées (2ceb682f9, #7836).
  • CLI : Benchmark conserve la règle des fichiers reçus ; une clé .env reçue ne remplace jamais un login (a7266e4c8, #7837).
  • CLI : Le rendu cloud ne refuse plus un fichier uniquement les noms de pages inutilisés (45cc331e5, #7812).
  • Core : Les pages contenant de nombreux caractères CJK récupèrent les polices dans plusieurs requêtes (6a8f4b5b4, #7823).
  • CLI : L'audio Hyperframes ne recherche jamais de média sur le partage d'un autre ordinateur (eaf33bc65, #7826).
  • CLI : Les téléchargements omettent les scripts extérieurs ; .ts compte comme vidéo uniquement lorsqu'il en est un (04202e8a4, #7818).
  • CLI : Jouez et présentez, vérifiez l'aperçu de l'hôte ; le rendu local laisse de côté les fichiers extérieurs pour une composition reçue (ac0247410, #7792).
  • Les routes multimédias du studio refusent le chargement inter-sites, CLI échappe au texte du terminal, les sorties par lots restent dans leur dossier (c4d60c347, #7779).
  • CLI : Découvrez les scènes montées dans les modèles (a75e61f31, #7822).
  • Studio Server : Les enregistrements de verrouillage de l'historique sont remplacés, jamais écrits via des liens (0248ea033, #7821).
  • Producteur : Gardez le serveur de rendu local à moins qu'un jeton ne le protège (f667111d1, #7814).
  • Engine,cli : La vérification du dossier de playlist lit HLS comme le fait ffmpeg ; snapshot l'exécute également (797a622be, #7810).
  • Engine,producter : Le paramètre de réseau de rendu se lit comme un commutateur ; les sondes de rendu-service restent sur les entrées vérifiées (be740d021, #7807).
  • CLI : Les commandes Windows imprimées lisent littéralement les noms de dossiers dans chaque shell (a07d4cf73, #7769).
  • CLI : Les enregistrements reçus imbriqués s'ajoutent uniquement ; un .env reçu ne sélectionne jamais le compte ; les noms de polices restent en dehors des fichiers d'agent (80b09cc94, #7808).
  • Les rendus Cloud Run atteignent uniquement les adresses publiques ; le dossier de cache de trames est privé pour son utilisateur (55b514709, #7777).
  • Deps : Actualisez zod, smol-toml, aws-cdk-lib et les résolutions associées dans bun.lock (28d4ba50f, #7741).
  • Deps : Bump @mcp-b/global sur 6.1.0 pour effacer les avis @modelcontextprotocol/server (beeb17e85, #7742).
  • Engine : Une capture parallèle ayant échoué nomme le travailleur qui a échoué, et non les homologues qu'il a arrêtés (db6b7478a, #7803).
  • Moteur : Les refus de rendu nomment l'adresse portée par un hôte mappé IPv6 ou NAT64 (04ee926d9, #7802).
  • Producteur : Acceptez les requêtes du navigateur uniquement sous bouclage, IP ou noms d'hôte répertoriés (03e6a1a18, #7798).
  • Parseurs : Ne recherchez jamais de média sur le partage d'un autre ordinateur (2de5c027f, #7797).
  • CLI : Les archives téléchargées omettent toujours les fichiers d'environnement et les enregistrements privés (477a3aea1, #7796).
  • Moteur : Téléchargements multimédias distants liés par taille, encodage et débit (5111cf384, #7786).
  • CLI : Démarrez les programmes d'assistance uniquement à partir des dossiers trusted PATH sur chaque plate-forme (83eae240f, #7787).

Performances

  • Lint : Analyse les références URL CSS en temps linéaire (bcf3d177d, #7829).
  • Les analyses d'URL CSS, @import, @font-face, de style et de commentaires s'exécutent en temps linéaire (ded5e3eec, #7809).

Catalogue

  • CLI : Ajouter des fichiers de listes à partir du registre d'une configuration reçue tels que reçus (6a7b4df7c, #7820).
  • Catalogue : La vérification de la charge utile traite le caption-overrides.json facultatif comme absent et non échoué (b7c26ff84, #7813).
  • Registre : Les mots-clés de légende, les emoji et les répliques fonctionnent pour les mots en dehors de a-z (8dbbc1d37, #7804).
  • Docs : Vérifiez les valeurs des liens du catalogue et conservez-les hors des commandes copiées (7c7ff6d89, #7783).
