hyperframes v0.9.64

HyperFrames v0.9.64

Sorti le 2026-11-17. Les captures de survol et de vignettes n'attendent plus sur la copie d'aperçu d'un clip 4K. Dans un aperçu scellé, le nettoyage lit la piste musicale et les lignes de la chronologie connaissent leur élément. hyperframes check trouve du texte sur un visage. Le proxy de Studio refuse les demandes sans signal du même site. Une version stable a désormais besoin d'un deuxième responsable en plus de son approbateur.

Fonctionnalités

  • CLI : check trouve du texte sur un visage, measure coupe les noms des prises reprises et measure rapporte les mains (820d63d7f, #8074).

Correctifs

  • Core : Les captures de survol et de vignettes n'attendent jamais la copie d'aperçu d'un clip 4K (f1f8ca31c, #8079).
  • Studio : Les lignes de la chronologie dans un aperçu scellé connaissent leur élément, leur fichier source et leur groupe audio (cda94eb0f, #8078).
  • Studio : Le fait de parcourir la tête de lecture lit la piste musicale dans un aperçu scellé (a56fa2caf, #8082).
  • CLI, Studio Server : Refuser ?hf-proxy lorsqu'une requête ne transporte aucun signal du même site (4bea3e79c, #8066).
  • CLI : Une clé de fournisseur de projet .env imprime une note lorsqu'elle est utilisée (90de9b619, #8056).
  • CLI : Les caractères de contrôle d'échappement dans la ligne de saut d'adoption d'utilisation multimédia (2749aafb3, #8087).
  • Core, Lint, Parsers : Affinez la règle de fichier privé pour les fichiers cachés, créez la sortie et les lint (f5ccfcc96, #7990).
  • Lint : Dérivez la durée racine avec le lecteur de synchronisation de l'analyseur (401991669, #8032).
  • Lint : Lit le timing d'un montage de sous-composition via l'analyseur (c84c30fd8, #8037).
  • Core : Supprimez l'état de flou de mouvement sur __hfRuntimeTeardown (9797faea0, #7996).
  • CLI : Conserver une page reçue supprimée répertoriée dans l'enregistrement des fichiers reçus (e099c7d0c, #8090).

Documents et exemples

  • Docs : Les exportations de bureau sur votre ordinateur sont illimitées sur tous les forfaits (94cc7558e, #8093).

Interne

  • GitHub : Les workflows, les actions et les scripts de publication nécessitent un examen par le responsable (4f2eaaac4, #8092).
  • Publier : Comptez chaque pousseur d'une version, avez besoin d'un deuxième responsable et datez les approbations (b22ca1a58, #8076).
