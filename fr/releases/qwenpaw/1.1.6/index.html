QwenPaw v1.1.6

✨ Ajouté

Système d'agent

  • Diagnostics Windows : qwenpaw doctor vérifie désormais les problèmes d'environnement spécifiques à Windows, notamment la prise en charge des chemins longs, le mode de langage PowerShell et la longueur du chemin du répertoire de travail (#4032).
  • Statut de l'agent API : nouvel état d'exécution de l'agent de reporting de point de terminaison GET /agents/{agentId}/agent-status, nombre de tâches en cours d'exécution et horodatage des tâches (#4107)
  • Isolement de session Cron : les tâches Cron prennent désormais en charge une option share_session — lorsqu'elle est désactivée, chaque exécution planifiée crée un contexte de session isolée avec un ID de tâche cron (#4117).
  • GPT Image 2 Plugin : Nouveau plugin d'outil pour générer des images via GPT Image 2 API d'OpenAI (#3911)
  • Nom de l'agent basé sur la configuration : utilisez le nom du profil d'agent configuré au lieu d'un nom par défaut codé en dur (#4140). Chat et console
  • Saisie vocale chuchotée : remplacement de la parole Web native du navigateur API par une transcription chuchotée côté serveur pour une saisie vocale plus fiable entre navigateurs (#3574)
  • Titres de session générés par LLM : les sessions de discussion sont désormais automatiquement intitulées par le LLM en arrière-plan après le premier message. Configurable via la bascule « Générer automatiquement les titres de session » dans Agent Config (#3829)
  • Tendances d'utilisation des jetons : ajout de graphiques linéaires de tendance par modèle et par type de jeton à la page des paramètres d'utilisation des jetons pour visualiser l'utilisation au fil du temps (#4080, #4094).
  • Opérations de compétences par lots : ajout de boutons Activer et Désactiver à la barre d'outils des opérations par lots de compétences avec rapport d'erreurs par compétence (#4091)
  • Rendu de diagramme de sirène : les blocs de code Markdown avec la balise de langage mermaid sont désormais rendus sous forme de diagrammes interactifs dans les aperçus de chat et de fichiers (#4146).
  • Portugais brésilien (pt-BR) : ajout de la prise en charge complète des paramètres régionaux pt-BR pour l'interface utilisateur de la console et les paramètres de langue du backend (#4009, #4143) Fournisseurs
  • Volcano Engine Provider : ajout de Volcano Engine en tant que fournisseur intégré compatible OpenAI avec des points de terminaison standard et Coding Plan (#3994)
  • Sélection de région DashScope : l'URL de base de DashScope peut désormais être modifiée à partir des points de terminaison de région prédéfinis (#4074).
  • Fournisseur de plan de jetons Aliyun : ajout du plan de jetons Aliyun en tant que fournisseur intégré (#4122)
  • Anthropic Default Max Tokens : augmentation du max_tokens par défaut pour les modèles compatibles Anthropic à 16 384 (#4054) Chaînes
  • Cartes d'approbation interactives Feishu : les demandes d'approbation de Tool-guard dans Feishu sont désormais affichées sous forme de cartes de boutons interactives qui se mettent à jour sur place lors de l'approbation/du refus, avec un indice de lien de documentation lorsque le rappel d'action de la carte n'est pas abonné (#3941, #3982).
  • Partage de session de groupe WeCom : ajout de la bascule share_session_in_group pour contrôler si les membres du chat de groupe partagent une seule session ou obtiennent une isolation par membre (#3948)
  • Contexte de l'expéditeur Feishu : le surnom de l'expéditeur Feishu est désormais transmis au contexte de l'environnement de l'agent (#4098)
  • Cartes d'approbation interactives WeCom : les demandes d'approbation Tool-guard dans WeCom sont désormais affichées sous forme de cartes modèles interactives (#4112) Sécurité
  • Protection contre la traversée de chemin de fichier statique : le service de fichiers statiques de la console rejette désormais les chemins absolus pour empêcher le contournement de la traversée de chemin (#3973)
  • Refus automatique au niveau des règles : des règles de sécurité individuelles peuvent désormais être configurées pour refuser automatiquement les appels d'outils (#4046) Compétences et CLI
  • Skill Test CLI : Nouvelle commande qwenpaw skills test pour valider le contenu des compétences et exécuter des analyses de sécurité (#3999)
  • Installation/Désinstallation de compétences CLI : Nouvelles commandes qwenpaw skills install et qwenpaw skills uninstall pour gérer les compétences à partir de la ligne de commande, prenant en charge les installations d'espace de travail au niveau du pool et par agent (#4053)

⚡Performances

  • Rendu de la console : suppression des rendus en double en stabilisant les comparaisons d'état des interrogations d'approbation et en mémorisant les options d'exécution du chat (#4052, #4110, #4153)
  • Navigation dans l'historique des discussions : ignorez la recherche dans l'historique des discussions pour les touches non fléchées et mettez en cache les listes de messages utilisateur pour éviter des analyses répétées à chaque frappe (#4130).
  • QR Polling Cleanup : arrêtez immédiatement l'interrogation du code QR et effacez les indicateurs d'état à la fin de l'authentification ou à l'expiration du code (#4148)

🐛 Corrigé

Chaînes

  • WeCom Stream Keepalive : conservez le flux d'espace réservé "Thinking..." en vie avec des actualisations périodiques pour éviter le blocage des indicateurs d'état dans WeCom (#3950)
  • WeCom Reconnect Race : correction de la planification de double reconnexion et de la déconnexion entre boucles d'événements dans la gestion de WeCom WebSocket (#3963)
  • Telegram Network Retry : ajout d'une interruption exponentielle et d'une reconnexion contrôlée pour les erreurs réseau Telegram transitoires au lieu de mourir silencieusement (#4039)
  • WeChat Cron Buffer Flush : vider immédiatement le tampon de fusion WeChat pour les envois cron/proactifs qui contournent le chemin d'achèvement normal (#4106)
  • Partage du tableau de démarques : préservez la structure du tableau de démarques dans les morceaux de message en répétant les lignes d'en-tête et de séparation dans chaque fragment (#4119) Système d'agent
  • Délai d'expiration de l'agent externe : ajout d'un délai d'expiration par défaut sécurisé (60 s) pour delegate_external_agent afin d'éviter des blocages indéfinis (#3928)
  • Agent Config Reload : les modifications apportées au fichier de configuration de l'agent déclenchent désormais un rechargement progressif avec épuisement des tâches au lieu d'une réinstanciation légère (#4064).
  • Persistance de la configuration de l'agent : correction de l'éditeur de configuration de l'agent de console supprimant les paramètres imbriqués lors de la sauvegarde en préservant la structure de configuration complète (#4157) MCP
  • Délai d'expiration d'exécution MCP : utilisez sse_read_timeout comme délai d'expiration de l'outil MCP au lieu du délai d'expiration de connexion HTTP plus court (#4058, #4061).
  • Fuite de cycle de vie MCP Client : correction d'une fuite de tâche de cycle de vie où close() pouvait ignorer l'arrêt d'une tâche de reconnexion en arrière-plan (#4152) Console et interface utilisateur
  • Sécurité de substitution SSE : évitez le crash du flux SSE sur un texte de substitution mal formé en nettoyant le contenu non codable avant la sérialisation (#3553)
  • CodeMirror Line Wrapping : correction du retour à la ligne dans les blocs d'entrée/sortie d'appel d'outil (#3960)
  • Nom d'affichage de l'agent par défaut : respectez le nom personnalisé de l'agent par défaut dans toutes les surfaces de l'interface utilisateur (#4073)
  • Chemins d'aperçu des fichiers : correction de la suppression des préfixes d'URL redondants dans les chemins d'aperçu des fichiers qui pouvait entraîner des URL cassées (#4089). Infrastructures
  • Restauration de sauvegarde Docker : restaurez correctement les secrets sur les points de montage du volume Docker en échangeant le contenu du répertoire au lieu de le renommer (#3916)
  • Chemins de blocs audio : renvoie le chemin du système de fichiers résolu pour les blocs audio d'URL file:// et supprime le code de gestion de fichiers redondant (#4021, #4048)
  • Rotation des journaux : utilisez RotatingFileHandler pour la rotation des journaux sur toutes les plateformes (#4076)
  • Loopback Proxy Bypass : contourner les variables d'environnement du proxy pour les vérifications de l'état du bouclage API afin d'éviter les échecs de connexion derrière les proxys d'entreprise (#4092)
  • Conda Packaging : restaurez les outils d'empaquetage conda avant d'exécuter conda-pack pour éviter une rupture du pipeline d'empaquetage (#4093)

📝Documentation

  • FAQ WSL2 Timeout : Ajout d'une entrée FAQ pour la gestion de APITimeoutError lors de l'exécution en mode WSL2 NAT (#4005)
  • Mise à jour de la documentation : documentation du site Web mise à jour pour refléter les nouvelles fonctionnalités (#4013)

🧪 Tests et CI

  • Tests unitaires de la console : ajout de la configuration Vitest avec des tests unitaires et de composants couvrant Chat, la couche API et les composants partagés (#3559, #4121)
  • Tests de fumée d'intégration : ajout de tests de fumée de démarrage de l'application et de paramètres/variables d'environnement (#4081)
