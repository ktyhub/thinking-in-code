QwenPaw v1.1.7

✨ Ajouté

Outils et MCP

  • Utilisation du navigateur — Actions par lots : exécutez plusieurs étapes du navigateur (navigation, click, saisie, capture d'écran, etc.) en un seul appel d'outil (#4139)
  • Utilisation du navigateur – Téléchargement de fichiers : téléchargez des fichiers en cli en cliquant sur des éléments de page ou en récupérant directement des URL (#4261).
  • Images de référence GPT Image 2 : prise en charge du téléchargement de 1 à 16 images de référence via une URL ou un chemin local dans le plugin GPT Image 2 (#4194).
  • Exécution asynchrone d'agent externe : delegate_external_agent prend en charge le streaming asynchrone avec liste de tâches et requêtes d'état et délai d'expiration configurable (#4197)
  • Shell Executable Configuration : Choisissez quel shell exécute les commandes via l'option de configuration (#4215)
  • OAuth 2.1 pour les serveurs MCP distants : authentifier les serveurs MCP distants via OAuth 2.1 avec PKCE (#4256) Plugins
  • Gestion des plugins de console : installez et désinstallez les plugins à partir de l'interface utilisateur des paramètres via un chemin local, un téléchargement ZIP ou une URL (#4214, #4266).
  • Plugins Qwen-Image & Wan 2.7 : Nouveaux plugins pour la génération/édition d'images et la génération de vidéos (#4248)
  • Plugin HTTP API Router : les plugins peuvent enregistrer des points de terminaison HTTP API personnalisés (#4255) Chat et console
  • Pièces jointes multiples : la saisie de chat prend désormais en charge la sélection de plusieurs fichiers dans un seul message (#4206).
  • Langue indonésien : prise en charge complète des paramètres régionaux Bahasa Indonesia pour l'interface utilisateur de la console et le backend (#4219)
  • Boîte de réception : Nouvelle boîte de réception centralisée avec onglets Approbations et Messages push pour gérer les approbations de Tool-Guard et afficher les résultats d'exécution cron avec des traces (#4210, #4305)
  • Amélioration des tâches Cron : les tâches Cron prennent désormais en charge l'exécution planifiée unique, une vue de calendrier pour visualiser les exécutions à venir, des modèles intégrés pour une création rapide, un historique d'exécution par tâche avec des traces d'exécution détaillées et une livraison enregistrée dans la boîte de réception (#4210). Chaînes
  • Feishu Voice Bubbles : les fichiers audio envoyés via Feishu s'affichent désormais sous forme de bulles vocales natives (#4202)
  • Messages cités DingTalk : les réponses avec des messages cités dans DingTalk incluent désormais le texte et les médias cités dans le contexte de l'agent (#4209).
  • Création de bot Feishu QR Code : créez un bot Feishu/Lark en scannant un code QR dans l'interface utilisateur de configuration des chaînes (#4236)
  • WeCom Streaming Output : réponses en streaming facultatives pour le canal WeCom avec livraison de messages en temps réel et prise en charge de l'indicateur de raisonnement (#4271)

🔄 Modifié

  • Refonte du sélecteur de modèle : remplacement de la liste déroulante de survol par une liste plate consultable regroupée par fournisseur (#3876)
  • Bouton de discussion flottant : la navigation dans la discussion a été déplacée du menu de la barre latérale vers un bouton collant à côté du sélecteur d'agent (#4240, #4273).
  • Découverte de session de statistiques d'agent : recherche simplifiée de fichiers de session en parcourant directement les sous-répertoires du canal (#4250)

⚡Performances

  • Dépendances asynchrones FastAPI : dépendances du gestionnaire de modèles et de fournisseurs converties en asynchrone, éliminant la répartition inutile du pool de threads (#4229)
  • Limite de taille de lecture de fichier : taille maximale de lecture de fichier réduite à 200 Mo (au lieu de 1 Go) avec pré-allocation basée sur la taille réelle du fichier (#4272, #4276).
  • Keyring Timeout : les opérations de trousseau de clés ont désormais un délai d'attente de 10 secondes pour empêcher les blocages du gestionnaire d'informations d'identification de bloquer le démarrage (#4263).

🐛 Corrigé

Fournisseurs et modèles

  • ID de modèle Volcengine : ID de modèle corrigés pour correspondre aux points de terminaison réels du API et indicateurs de capacité mis à jour (#4169)
  • Provider Meta Preservation : les métadonnées du fournisseur ne sont plus supprimées lors de la récupération des informations sur le fournisseur (#4200).
  • Filtrage d'utilisation d'outils mal formés : l'analyseur de streaming filtre désormais les blocs d'utilisation d'outils avec des ID nuls ou des noms vides (#4234) Chaînes
  • Opérateur de carte d'approbation WeCom : les cartes d'approbation résolues affichent désormais le nom de l'opérateur (#4233)
  • Feishu WebSocket Keepalive : Détecter et récupérer après une perte de connexion WebSocket silencieuse (#4241) Console et interface utilisateur
  • Routage de l'historique de session : correction de la disparition de l'historique de session et des messages acheminés vers de mauvaises sessions (#4203)
  • Mode sombre du panneau Plan : contraste du texte amélioré en mode sombre du panneau Plan (#4190)
  • Barre latérale mobile : la barre latérale se réduit automatiquement sur les écrans étroits (#4225)
  • Nouvelles lignes de message utilisateur : les messages utilisateur conservent désormais les sauts de ligne (#4231)
  • Étiquettes de date d'utilisation des jetons : les étiquettes de graphique affichent désormais le préfixe de l'année lorsque la plage de dates traverse une limite d'année (#4268).
  • Liens externes du bureau : les liens s'ouvrent désormais correctement dans les versions de bureau (#4270)
