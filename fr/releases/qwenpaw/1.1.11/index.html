✨ Ajouté

Fournisseurs

  • Modèle OAuth gratuit : modèles gratuits sans configuration avec authentification OAuth à un click (#5049)
  • Fournisseur Xiaomi MiMo : ajoutez le plan de jetons Xiaomi MiMo en tant que fournisseur intégré (#4722)
  • Extra Body Routing : acheminez les generate_kwargs non standard vers extra_body (#4689) Console
  • Plugin Market : ajout de l'onglet Plugin Market avec l'intégration de la plateforme AgentScope (#5023)
  • Infrastructure d'extension de plugin : infrastructure d'extension de plugin pour console (#4997)
  • Système de plug-in de cartes outils : système de plug-in de cartes outils (#5046)
  • Suggestions de commandes Slash : ajoutez des compétences d'agent actuel aux suggestions de commandes Slash avec des optimisations de l'interface utilisateur (#4810)
  • Navigation par URL externe : prise en charge du champ href sur MenuItem pour la navigation par URL externe (#5071) MCP
  • Liste blanche des outils : ajout d'une liste blanche des outils MCP par serveur avec une interface utilisateur à bascule frontale (#5002) Plugins
  • Registre de section d'invite : Autoriser les plugins à injecter des blocs d'invite système à des points d'ancrage définis (#4804)
  • Uninstall Hooks : ajoutez des hooks de désinstallation, corrigez les importations du validateur, exposez le fournisseur de compétences API (#4794)
  • CloudPaw Agent Import : prise en charge de l'importation d'agents depuis AgentHub et amélioration des capacités A2A (#5033) Compétences
  • Création de compétences auto-évolutives : flux de création de compétences amélioré pour prendre en charge la création de compétences auto-évolutives (#4857)
  • Téléchargement par lots de tags de compétences : ajout d'un téléchargement par lots de tags de compétences (#4969)
  • Pool de compétences multi-chemins : ajout de la prise en charge multi-chemins pour le pool de compétences (#4891) Chaînes
  • Telegram Tool Guard : approbation de l'outil interactif via le clavier en ligne (#4737)
  • Partage de groupe Feishu : Ajouter le mode de partage de session de groupe (#4821)
  • Feishu Interactive Cards : prise en charge de l'extraction du contenu des cartes interactives et de l'analyse des messages de refactorisation (#4879)
  • QQ QR Code Auth : Ajoutez une autorisation de code QR pour la chaîne QQ (#4848)
  • DingTalk Inline Media : activez l'aperçu d'image en ligne et la carte de lecture vidéo via webhook (#5073)
  • Indicateur de saisie Yuanbao : Ajouter un indicateur de saisie via le battement de coeur API (#5020)
  • Nom d'utilisateur de contrôle d'accès : ajoutez le nom d'utilisateur de l'expéditeur au contrôle d'accès avec une structure d'informations utilisateur unifiée (#4897) Navigateur
  • Coordonnées de page Click : Ajouter la prise en charge des coordonnées de page click au contrôle_navigateur (#4905) ACP
  • Améliorations ACP : annonces de commandes, erreurs de surface, paramètres d'outils, méta agent/modèle, liens de fichiers (#4949) Coureur
  • Stream Query Timestamp : remplacez stream_query pour définir l'horodatage actuel des réponses (#4892)

🔄 Modifié

  • Cron Push Bubbles : Désactiver les bulles push pour les tâches cron de type 'agent' (#4803)
  • Console Media Handling : Simplifiez la gestion des messages multimédias dans le canal de console (#5077)
  • Annuler le panneau de session : annuler "l'intégration de la liste des sessions de l'historique dans le panneau de droite" (#5076)

🐛 Corrigé

Fournisseurs et configuration

  • ProviderManager Fallback : ajoutez une solution de repli ProviderManager à get_model_max_input_length (#4827)
  • Compaction Fix : Résoudre /compact en ignorant max_input_length du modèle lorsque active_model n'est pas défini (#5021) Mode de codage
  • Navigation des lecteurs Windows : prise en charge de la navigation sur tous les lecteurs sous Windows (#4906)
  • Session Switch & Header : correction de l'échec du commutateur de session en mode de codage et du débordement d'en-tête (#5011) Console
  • Session List Spinner : correction de la liste des sessions qui continuait de tourner (#4929)
  • Scrollbar Flickering : Supprimez la transformation du survol pour empêcher le scintillement de la barre de défilement (#4766)
  • Icône et tableau de bouclier : Centrez l'icône du bouclier et ajustez la largeur des colonnes du tableau de règles (#4765)
  • Icône de basculement de thème : change l'icône de basculement du thème du système de l'ordinateur au soleil (#5050) Bureau
  • Liens externes Tauri : correction des liens externes du bureau Tauri (#4683) Agent et mémoire
  • Broadcast Coroutine : Attendez la coroutine inattendue dans _broadcast_to_subscribers (#5048)
  • Skip Auto Memory : Ignorer la mémoire automatique d'automatisation (#4348)
  • Dream Workspace : Dream doit utiliser l'espace de travail de cron runner, et non le répertoire d'instance obsolète (#4936).
  • Traitement des blocs multimédias : gérer les objets source non-dict dans le traitement des blocs multimédias (#4933) MCP
  • Tool Name Regex : noms d'outils de réécriture d'alias rejetés par les regex de style OpenAI (#4958)
  • Accumulation de sous-processus : empêcher l'accumulation de sous-processus lors des redémarrages (#5014) Chaînes
  • Fusion des messages DingTalk : empêche la fusion des messages entre utilisateurs lorsque le suffixe conversation_id entre en collision (#4932)
  • OneBot Port Conflict : dégradation progressive du conflit de port lors du rechargement (#5010)
  • ACL Sender ID : conservez acl_sender_id lors de la fusion de la charge utile native sur tous les canaux (#4925) Navigateur
  • Délai d'expiration et profil CDP : ajout d'un paramètre de délai d'expiration CDP et d'une isolation du profil de navigateur pour la commutation entre navigateurs (#4944) Fichier et session
  • Async File Writes : utilisez des fichiers aio pour les écritures de fichiers non bloquantes (#4954)
  • Atomic State Write : écriture atomique de l'état de la session (#4706)
  • Taille et délai d'expiration du téléchargement : limite de taille de téléchargement + résilience du délai d'expiration du chargeur de plugin (#4940)
  • Taille du téléchargement zip : augmente la taille du fichier de téléchargement zip (#4941) Sécurité
  • Restriction de l'aperçu des fichiers : restreindre l'aperçu des fichiers à WORKING_DIR et bloquer les fichiers sensibles (#4981) Forfaits
  • Yuanbao Proto JSON : Inclut les fichiers Yuanbao Proto JSON dans les données du package (#4899)
