QwenPaw v2.0.0

Ce qui a changé

✨ Ajouté

Architecture de base

  • Runtime 2.0 : Refactorisez le noyau basé sur AgentScope 2.0 (#5078, #4846, #5018, #5552)
  • Agent OS Driver : gestion unifiée des connexions MCP/A2A/ACP, stockage des informations d'identification cryptées et politique d'approbation par appel (#5067)
  • Loop Engineering : Nouvelle conception de porte de boucle avec trois modèles de boucle : Mode normal / Mode mission / Mode objectif (#5665, #5727)
  • Gouvernance et Sandbox : moteur de stratégie avec règles d'autorisation/refus/demande, détecteurs ToolGuard fusionnés en un seul chemin d'évaluation de stratégie et modèle de gouvernance généralisé pour les plugins (#5088, #5546, #5301) Gestion du contexte
  • Contexte de défilement : historique de travail basé sur SQLite (history.db) avec recherche en texte intégral FTS5, index d'expulsion, persistance au niveau du tour et un recall_history_python REPL en bac à sable pour le rappel à la demande des tours plus anciens. Rétention par défaut de 30 jours, importe automatiquement les sessions existantes au démarrage (#5321)
  • Compression native : refactoriser à l'aide de la stratégie de compression de contexte intégrée d'AgentScope 2.0 (#5309) Mémoire à long terme
  • Backend ReMe v0.4.0 : remplacez la mémoire d'exécution interne par ReMe v0.4.0 — le stockage de vecteurs, le suivi automatique et la récupération sont désormais gérés par la bibliothèque ReMe v0.4.0 (#5349)
  • Suivi tour par tour : les écritures de mémoire s'effectuent désormais tour à tour via un middleware, et ne sont plus liées à la fermeture de la session (#5540)
  • Recherche adaptée à l'utilisation : la recherche de mémoire prend désormais en compte la récence et la fréquence ; Sélection de modèle d'intégration spécifique au backend ajoutée à l'interface utilisateur de configuration (#5820)
  • Mode ADBPG REST : le backend de mémoire ADBPG est passé en REST uniquement, avec recherche automatique (#5296)
  • Simplification de l'interface utilisateur de recherche : affichage de recherche en mémoire plus propre, champs de métadonnées réduits à l'essentiel (#5482)
  • 'aucun' backend : option de configuration pour désactiver complètement le système de mémoire pour les déploiements légers (#5732) Interface utilisateur du terminal (TUI)
  • TUI plein écran : une application de chat de terminal basée sur du texte (qwenpaw tui) — sortie en streaming, rendu d'appel d'outil, barre d'état et gestion de session, le tout dans le terminal (#5032)
  • Sessions à l'échelle du projet : TUI peut lancer une session en mode de codage limitée à un répertoire de projet spécifique (#5448)
  • Barre d'utilisation contextuelle : indicateur d'utilisation du jeton/contexte en direct dans la barre d'état TUI (#5673)
  • Commandes ACP dans TUI : commandes d'approbation en ligne /approve, /deny + améliorations du panneau de transcription (#5443, #5714) Console et interface utilisateur
  • Carte d'approbation : boutons d'action plus grands, aperçu des différences plus clair, approbation/refus d'un click (#5855)
  • Téléchargement de texte long : collez ou téléchargez de gros blocs de texte directement dans l'entrée du chat (#5854)
  • Approbation de l'outil au niveau de la session : remplacer la stratégie globale de l'outil par session (#5685, #5832)
  • Bannière non-propriétaire : afficher la bannière « affichage uniquement » lors de l'affichage de l'onglet de session de quelqu'un d'autre (#5664)
  • Mise en page mobile : CSS réactif + navigation basée sur des tiroirs pour toutes les pages de la console (#5444–#5470)
  • Vue fractionnée de la page Outils : outils activés et disponibles affichés dans des colonnes séparées ; bascule prenant en compte la configuration par outil (#5509, #5604)
  • Améliorations du marché des compétences : nombre d'étoiles/téléchargements, répartition activée/désactivée, synchronisation automatique à partir du CDN (#5521, #5706, #5639)
  • Double présentation de la page des chaînes : chaînes activées en haut, disponibles ci-dessous (#5504)
  • Mode de codage partagé 50/50 : le panneau de discussion occupe la moitié de la fenêtre d'affichage (#5473)
  • Dossiers cachés dans le navigateur du projet : répertoires préfixés . désormais sélectionnables (#5828)
  • Tiroir de sessions : sessions groupées par dates avec recherche en ligne (#5728)
  • Popover d'utilisation des jetons : graphique en anneau montrant l'utilisation des jetons/contexte par tour, restauré pour le Runtime 2.0 (#5493, #5544)
  • Filtres de boîte de réception : filtrez les notifications push par type de source (#5522)
  • Ancres de message : navigateur d'accès direct au message pour les tours de l'utilisateur (#5515)
  • Délai d'expiration de la demande : délai d'expiration HTTP configurable + propagation AbortSignal pour les appels backend (#5764) Fournisseurs de modèles
  • OpenAI Response API : Nouveau fournisseur pour le format OpenAI Response API (#5519)
  • Mises à jour DashScope : Qwen3.7 + DeepSeek V4 ajoutés à la liste des modèles intégrés ; Passage extra_body pour generate_kwargs ; bascule de relais de réflexion par modèle (#5646, #5491, #5687, #5730)
  • Modèles GitHub : migrez vers le nouveau point de terminaison API ; prendre en charge les PAT à granularité fine (#5735)
  • URL de base personnalisée Telegram : configuration api_base_url pour les serveurs Telegram Bot API auto-hébergés (#5651) Chaînes
  • Matrix streaming : streaming avec édition sur place, n'envoie plus de nouveau message par fragment (#5585)
  • Canaux enregistrés dans le plugin : les plugins peuvent enregistrer des types de canaux personnalisés avec un schéma JSON qui génère automatiquement l'interface utilisateur de configuration (#4693).
  • Bascule anti-rebond par canal : indicateur no_text_debounce pour que les canaux rapides ne regroupent pas les messages (#5617)
  • Slack : implémentation de canal complet avec pièces jointes multimodales, réponses aux fils de discussion et streaming (#5193)
  • Déploiement privé DingTalk : configuration api_endpoint pour les instances DingTalk sur site (#5111)
  • Canal Azure Bot : canal Azure Bot ajouté en tant que plug-in, avec prise en charge i18n/custom-icon/doc_url pour les canaux de plug-in (#5849)
  • Pièces jointes Discord : téléchargement sur media_dir local, diffusion via une route de fichier statique (#5468) Bureau
  • Migration Tauri : version de bureau déplacée d'Electron vers Tauri — binaire plus petit, vue Web native, programme d'installation NSIS sur Windows (#5734, #4669, #4041)
  • Environnement d'exécution ACP intégré : environnement d'exécution Node.js + modules ACP livrés dans le package de bureau pour la communication d'agent prête à l'emploi (#5814, #5794)
  • Geste DevTools : 8× logo click ouvre Chromium DevTools pour le débogage (#5805) Sécurité et bac à sable
  • bac à sable Windows AppContainer : exécution de code isolée via AppContainer natif Windows API (#5525)
  • Bac à sable Linux bubblewrap : Montez l'isolation de l'espace de noms via bwrap pour l'exécution de code Linux (#5310)
  • Bascule de sécurité des outils Cron : indicateur par tâche pour exiger/ignorer l'approbation de l'outil pour les tâches planifiées (#5847)
  • Détection de commandes dangereuses : ToolGuard détecte find -delete et les modèles de shell destructeurs similaires (#5843)
  • Politique d'accès : règles déclaratives d'autorisation/refus/demande évaluées par appel de fonctionnalité Plugins
  • Hooks middleware AgentScope : les plugins peuvent enregistrer un middleware compatible AgentScope avec la gestion des versions Semver (#5221)
  • Catalogue limité par version : le marché des plugins et le CDN affichent uniquement les plugins compatibles avec la version en cours d'exécution de QwenPaw (#5661)
  • Hooks de cycle de vie : hook on_uninstall, correctifs du validateur et fournisseur de compétences public API pour les auteurs de plugins (#5008) Outils
  • web_search et web_fetch : outils de recherche et de récupération Web intégrés avec identité de produit (#5890)
  • Option grep_search show_file : Ajoutez l'indicateur show_file pour afficher le contenu du fichier correspondant (#5840)
  • Transmission d'erreur d'outil : état d'erreur du résultat de l'outil transmis au frontend pour une meilleure expérience utilisateur (#5912) CLI
  • cron update : Modifier la planification/l'invite/la configuration des tâches cron existantes sans supprimer ni recréer (#5210) Observabilité
  • Langfuse 2.0 : regroupement de traces restauré via l'intégration de hook ; chaque boucle d'agent est un span de génération Langfuse (#5511)

🔄 Modifié

  • relay_reasoning : preserve_thinking renommé relay_reasoning ; la valeur par défaut est désactivée pour DashScope afin d'éviter un raisonnement en double dans la sortie (#5876)
  • Limitation de débit : limitation de débit multidimensionnelle (IP + utilisateur + point de terminaison) avec fenêtres configurables (#5738)
  • Cycle de vie de la mémoire : commande /compact retravaillée ; nouvelle commande /system_prompt ; état de recherche simplifié pour éviter les intégrations obsolètes (#5450, #5815)
  • Composant SessionItem : tous les moteurs de rendu de session regroupés en un seul composant SessionItem (#5754)
  • Skill UI : composants SkillPool/SkillMarket refactorisés ; CSS mort supprimé (#5753, #5532)
  • Plan Mode supprimé : la configuration de l'agent n'inclut plus plan_mode ; Références d'interface utilisateur nettoyées (#5605, #5618)
  • Conservation de la version du plugin : anciennes versions du plugin conservées sur le disque après la mise à jour ; état d'échec de chargement nettoyé au prochain démarrage (#5695)
