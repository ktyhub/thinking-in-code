QwenPaw v2.0.1

Ce qui a changé

✨ Ajouté

Plateforme PawApp

  • PawApp SDK & Kanban App : Une nouvelle plate-forme de mini-applications qui permet aux plugins de créer de riches interfaces utilisateur interactives sur QwenPaw. Livré avec une application de tableau de tâches Kanban intégrée pour la gestion de projet (#6150) Modes d'agent personnalisés
  • Mode agent modifiable par l'utilisateur : créez et modifiez des modes de boucle d'agent personnalisés directement depuis la console — définissez les limites d'itération, les conditions d'arrêt et les portes d'approbation sans toucher au code (#6270)
  • Oh-My-Paw Plugin : cinq boucles d'agent prêtes à l'emploi (UltraQA, Ralph, Ultrawork, Autopilot, Team) pour la collaboration multi-agents et les tâches de longue durée (#5882) Mémoire et observabilité
  • Maintenance de l'index ReMe Light : reconstruction explicite de l'index via le bouton de la console ou API, auto-réparation améliorée au démarrage et segmentation Markdown optimisée pour les documents volumineux (#6235)
  • Améliorations de la fiabilité ReMe : inspection des statistiques de mémoire d'exécution, sécurité de l'intégration CJK et arrêt progressif du résumé en arrière-plan (#6098)
  • Protections d'indexation ReMe : validation de configuration et stabilité d'indexation améliorées (#6153)
  • Enrichissement des traces Langfuse : les traces portent désormais l'ID utilisateur, l'ID de session et la version du package pour un meilleur filtrage et analyse (#5922)
  • Configuration de rétention de l'historique : jours de rétention du contexte de défilement désormais configurables depuis la console (#6214) Console et ordinateur de bureau
  • Archivage des discussions : archivez les anciennes conversations pour garder la liste des sessions propre (#6078)
  • Téléchargement de fichiers par glisser-déposer : déposez les fichiers directement dans la zone de saisie du chat de l'application de bureau (#6327).
  • Tri du marché des plugins : trier les plugins par téléchargements, heure de mise à jour ou favoris (#6349)
  • Copie de configuration d'agent One-click : dupliquez une configuration d'agent avec un seul click (#6262)
  • Rotation des journaux configurable : définissez les limites de rotation des fichiers journaux à partir de la configuration (#6183) Sécurité et gouvernance
  • Bac à sable à jetons restreints Windows : exécution de code isolée via des jetons restreints Windows pour une option de bac à sable supplémentaire (#5931)
  • Règles de gouvernance : nouvelles définitions de règles de gouvernance pour un contrôle d'accès plus fin (#6215)
  • Détection de fichiers sensibles : davantage de types de fichiers détectés comme sensibles ; les lectures de fichiers globales sont désormais autorisées par défaut pour les chemins non sensibles (#6067) Exécution et multi-agent
  • Contrôle de démarrage multi-agent : concurrence de démarrage limitée avec indicateur de préparation partielle dans la console (#6198)
  • Livraison cron silencieuse : les tâches planifiées peuvent fournir des résultats silencieusement sans notifications (#6080)
  • Préservation des métadonnées d'événement : les métadonnées des plugins et des extensions sont désormais transmises via des enveloppes de sortie en temps réel (#6224)
  • Sonde de préparation : nouveau point de terminaison /api/healthz pour la vérification de l'état et l'orchestration des conteneurs (#6028)
  • Authentification proxy Trusted : Vérifiez les proxys trusted et résolvez les adresses IP réelles client pour les déploiements derrière des équilibreurs de charge (#6030). CLI
  • gh CLI autorisé dans la gouvernance : Les commandes GitHub CLI sont désormais autorisées par la politique de gouvernance (#6031)

🔄 Modifié

  • La boucle ReAct par défaut est désormais modélisée comme un DefaultMode de première classe, donnant à chaque mode la propriété explicite de son cycle de vie et de ses portes (#6210)
  • Commandes slash ACP découplées du noyau, contrôles de sécurité extraits dans un module autonome et flux d'amorçage unifié (#5796)
  • L'appel d'outil de canal et l'affichage du résultat de l'outil ont désormais des commandes à bascule séparées (#6233)
  • Les règles de détection ToolGuard sont désormais intégrées au moteur de politique de gouvernance pour une évaluation unifiée (#6390)
  • La synchronisation automatique de DEFAULT_USER_RULES ne nécessite plus de liste blanche manuelle (#6025)
  • Le bouton d'approbation de l'outil utilise désormais toolSource au lieu de executionLevel pour le contrôle "Toujours autoriser" (#6095)
  • Raisonnement des agents optimisé pour réduire les boucles de réflexion redondantes et les invocations d'outils en double (v2.0.0.post4)

🐛 Corrigé

Bureau

  • L'application de bureau arrête désormais correctement le backend avant de quitter, évitant ainsi la perte de mémoire et un nettoyage incomplet (#6225)
  • Les liens Markdown sur le bureau s'ouvrent désormais dans le navigateur système au lieu de naviguer dans la fenêtre de l'application (#6300)
  • L'éditeur de Monaco se charge à partir d'un bundle local pour un aperçu du codage hors ligne (#6291)
  • WKWebView n'épingle plus une version obsolète de l'interface de console (#6107)
  • Mises à jour de Tauri limitées aux versions OSS uniquement (#6071) Exécution et agents
  • Le contenu de raisonnement tourne désormais correctement sur les nouveaux blocs de raisonnement pendant la diffusion (#6310)
  • Les arguments d'appel d'outil sont diffusés de manière incrémentielle au lieu de mettre en mémoire tampon la réponse complète (#6343)
  • Les approbations des sous-agents sont désormais acheminées et résolues correctement à partir de la session racine (#6295).
  • Correction des échecs de validation des entrées qui bloquaient les flux de travail parallèles Oh-My-Paw (#6395)
  • Les tâches arrêtées attendent désormais un nettoyage approprié avant de signaler la fin (#6347)
  • Les discussions en arrière-plan sont correctement enregistrées ; ancien coureur supprimé (#6272)
  • Les segments de sortie de raisonnement et d'outil sont désormais correctement alignés (#6280)
  • Le remplacement du modèle par demande est désormais correctement honoré (#5731)
  • Une entrée d'appel d'outil mal formée est transmise au modèle pour une auto-correction (#5761)
  • Seuils de boucle Doom affinés pour réduire les faux positifs (#6184)
  • Utilisez max_completion_tokens pour les modèles de raisonnement (#6015)
  • Les espaces dans les deltas de réflexion/texte en streaming sont correctement préservés (#6166)
  • Les images ne sont plus supprimées pour les modèles multimodaux lorsque la recherche d'informations sur le modèle échoue (#6154, #6217). Console et interface utilisateur
  • La copie de sortie de l'outil fonctionne dans tous les contextes de navigateur, y compris non-HTTPS (#6275)
  • La liste des compétences s'actualise automatiquement après l'installation depuis le marché (#6296)
  • L'approbation unique de l'outil est désormais prioritaire sur les paramètres au niveau de la session (#6357).
  • Le badge de la boîte de réception indique le nombre de toutes les approbations en attente, pas seulement celles élevées/critiques (#6391)
  • Les erreurs d'aperçu des médias obsolètes sont effacées ; images de chemin relatif gérées correctement (#6385)
  • Contraste du texte en mode sombre amélioré pour les modèles de boucles et l'historique des discussions (#5975)
  • Le remplissage automatique du navigateur ne se déclenche plus lors de la saisie d'une recherche de fournisseur (#6011)
  • La file d'attente des messages de discussion s'efface correctement lorsqu'une session est supprimée (#6045)
  • Le chargement du défilement de la page de compétences ne s'arrête plus après le premier lot (#5968) Gouvernance et sécurité
  • La journalisation d'audit désactivée est désormais correctement prise en compte (#6369).
  • Les outils du plugin ne sont pas enregistrés lors du déchargement ; Les contrôles de sécurité ToolGuard sont partagés correctement entre les contextes (#6311)
  • Isolation du mode de flux de travail Oh-My-Paw renforcée avec des instances par espace de travail et des correctifs de porte fork/deny-all (#6317)
  • Actualisation par défaut des outils du plugin lors de l'inscription ; validation du type d'outil ajoutée (#6313)
  • Enregistrement automatique des outils via @tool_descriptor et PluginApi (#6190)
  • L'état du bac à sable en mode OFF obsolète a été correctement effacé (#6122)
  • Les règles de protection des outils frontaux sont désormais intégrées à l'analyse approfondie des politiques (#6063).
  • Sandbox préserve venv PATH lors de l'exécution du shell (#6081)
  • Commutateur sandbox_enabled honoré dans le chemin sandbox en mode OFF (#6109)
  • Les commandes Sudo demandent désormais correctement l'autorisation à l'utilisateur (#6079) Mémoire
  • Mémoire automatique limitée aux requêtes des utilisateurs externes uniquement (#6120)
  • auto_memory_interval peut être réglé sur 0 pour désactiver la mémoire automatique (#6135)
  • Ajout d'une bascule d'horaire de rêve (#6171)
  • Historique des tâches récapitulatives de la mémoire correctement délimité (#6206)
  • Codage d'ID de session sécurisé Windows pour le stockage de fichiers ReMe (#6022) MCP
  • Les en-têtes ${VAR} ont migré vers les références d'informations d'identification d'environnement lors de la migration du pilote (#6091)
  • Migration MCP héritée effectuée en une seule fois via un filigrane de schéma (#6133)
  • Les mises à jour des règles d'accès MCP s'appliquent immédiatement (#5949)
  • Le démarrage de l'espace de travail n'est plus bloqué par le délai d'expiration de la connexion MCP (#6174)
  • Espace de noms de secours dans le nom de l'outil MCP nettoyé pour la conformité OpenAI (#6209) CLI et chaînes
  • cron update préserve désormais les champs d'exécution et de requête intacts (#6236)
  • État des canaux SIP, Matrix et Slack correctement délimité pour éviter les fuites de mémoire (#6207)
  • L'interrogation des télégrammes n'entre plus dans la boucle de conflit 409 (#6005)
  • État du canal limité et suivi des tâches de déclenchement et d'oubli pour éviter les fuites de mémoire (#6168)
  • Correction d'un crash de TUI lorsque cli enregistrait la sortie de streaming (#6069) Observabilité
  • Les ID de trace Langfuse utilisent désormais un format hexadécimal valide (#6277) Autre
  • Le remplacement de l'emplacement du modèle passe correctement via le canal de la console vers l'usine du modèle (#6304)
  • Contrôle du modèle local GGUF adapté au changement de clé ModelScope SDK (#6290)
  • Le point d'entrée Tauri utilise des importations absolues (#6234)
  • La vérification de la référence du fichier ne plante plus sur OSError (#6247)
  • Session périmée nettoyée après l'achèvement de l'objectif (#6086)
  • Réinitialisation des portes d'arrêt sur les commandes /new et /clear (#6094)
  • Limites de contexte renforcées avec le compactage des résultats de l'outil récupérable (#6123)
  • Compatibilité de l'encodage GBK dans l'exécution de commandes sous Windows (#6140)
  • Défense de message de résultat d'outil orphelin multicouche (#5989)
  • Raccourcis Regex dans les modèles de schéma d'outils étendus pour la compatibilité GBNF (#6216)
  • L'utilisation du navigateur a désormais un temps d'attente maximum pour éviter des blocages indéfinis (#6170)
  • Le cache d'utilisation des jetons ne persistait plus lorsqu'il n'était pas amorcé (#6220)
  • Correction d'une fuite de mémoire liée au Skill-Hub (#6208)
  • Sonde nvidia-smi redondante supprimée de la détection VRAM (#6204)
  • Les lanceurs sans tête Windows VBS restent sans fenêtre avec une élévation UAC conditionnelle (#6127)
  • URI file:// dans DataBlock résolus en chemins locaux avant le formatage (#6191)
  • Réponses JSON codées en Gzip gérées dans le catalogue de téléchargement (#6106)

⚡Performances

  • Les fragments d'arguments d'appel d'outil sont joints une seule fois au lieu d'un réassemblage par jeton (#6346)
  • Les opérations d'E/S synchrones ne bloquent plus la boucle d'événements asynchrones (#6378)
  • La migration de l'historique de session écrit par lots pour un démarrage plus rapide (#6021)

🧪 Tests

  • E2E : cas d'agents adaptés à la refonte des actions (#6333)
  • E2E : sélecteurs adaptés aux refontes de l'interface utilisateur du v2.0.0 (#6185)
  • Intégration : couverture du contrôle d'accès, du fork, du mode de codage et du statut d'agent (#6213)
  • Tests de régression runtime/sécurité/installation (#5813)
  • Console vitest avec couverture en balayage complet nocturne (#6194)

🏗️Infrastructures
