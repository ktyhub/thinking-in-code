Avec "ENABLE_FORWARD_USER_INFO_HEADERS" activé et la recherche hybride activée, les demandes de reclassement portent désormais les en-têtes de l'utilisateur connecté lorsqu'un chat recherche des connaissances jointes, lorsqu'un modèle utilise l'outil de recherche de connaissances intégré et lorsque la requête de collection API s'exécute, là où seules les demandes d'intégration de la même recherche les possédaient. #32061, #32060
  • 🪢 Adresses Web simples dans le chat. Les adresses Web écrites sans texte de lien affichent désormais "&" au lieu de "&", et les adresses écrites entre crochets ouvrent l'adresse telle qu'elle est écrite, où elles pointaient vers une adresse différente avec les mauvais paramètres. Commettre, #31902
  • 🗺️ Serveurs MCP sans découverte OAuth. La connexion à un serveur MCP via OAuth 2.1 fonctionne désormais lorsque le serveur ne publie aucun document de découverte, en utilisant les adresses standard /authorize, /token et /register sur le propre domaine du serveur, où la connexion a été refusée car aucune adresse de connexion n'a pu être trouvée. Commettre, #26647
  • 🧹 Les chats supprimés quittent leur dossier. La suppression du chat ouvert avec le raccourci clavier Supprimer le chat le supprime désormais également de son dossier dans la barre latérale, où il y restait répertorié jusqu'à ce que la page soit rechargée. Commettre, #31321
  • 👀 Qui a ajouté des discussions à un dossier que vous partagez. Dans un dossier que vous possédez et partagez avec d'autres, les discussions qu'ils ajoutent affichent désormais la photo de profil de leur propriétaire dans la barre latérale, comme dans les dossiers partagés avec vous. Engager
  • 🎟️ Les serveurs d'outils utilisant votre jeton de connexion après son renouvellement. Les serveurs d'outils MCP et OpenAPI configurés pour utiliser le jeton OAuth de l'utilisateur connecté récupèrent désormais le jeton actuel pour chaque appel et réessayent une fois lorsqu'il était renouvelé entre-temps, où les appels d'outils continuaient à envoyer l'ancien jeton après une actualisation et échouaient, et les serveurs MCP obtiennent désormais également le jeton dans les automatisations et les requêtes API sans session de navigateur. Commettre, #31863
  • 🧯 Les réponses non diffusées avec les appels d'outils se terminent. Avec Stream Chat Response désactivé, une réponse dans laquelle le modèle appelle un outil est maintenant enregistrée et marquée comme terminée, où le chat a continué à l'afficher comme étant toujours généré jusqu'à ce que la page soit rechargée. #32083
  • 🩹 Chats juste après un redémarrage du Redis. Après le redémarrage ou la fermeture de ses connexions du Redis, Open WebUI se reconnecte désormais et réessaye l'appel une fois, de sorte que les demandes de chat n'échouent plus avec une erreur 500 et les onglets nouvellement ouverts reçoivent à nouveau des mises à jour en direct dès que le Redis est de retour. #31619
  • 🧊 Coller du texte volumineux ne gèle plus le navigateur. Les zones de texte utilisant l'éditeur de texte enrichi, comme la saisie de chat et l'éditeur de texte de connaissances, ne convertissent désormais leur contenu que lorsqu'il change réellement, où chaque déplacement ou sélection du curseur convertit à nouveau tout le texte et coller une grande quantité pourrait geler la page. Commettre, #12087
  • 💭 Réponses qui mentionnent une balise de réflexion. Lorsqu'un modèle envoie son raisonnement séparément, comme via Ollama, une réponse qui contient le texte "<think>" n'y est plus coupée, le reste étant caché dans un deuxième bloc de réflexion. Commettre, #31540
  • 📦 Résultats structurés des outils MCP. Lorsqu'un outil MCP renvoie des données structurées à côté de son texte, le modèle reçoit désormais également ces données, là où seule la partie texte l'atteignait et les outils qui mettaient leur résultat réel dans la partie structurée semblaient vides. Commettre, #28926
  • 🌍 Dates et heures dans votre langue. Les dates, heures, heures relatives telles que "il y a 2 heures" et les calendriers d'automatisation pour les analyses, les évaluations, les fonctions, les utilisateurs, les discussions, les notes, les fichiers, la recherche, les canaux et le calendrier suivent désormais la langue de l'interface, où beaucoup d'entre eux étaient toujours affichés en anglais. "DEFAULT_LOCALE" est désormais la langue de départ pour tous ceux qui n'en ont pas choisi, devant la langue du navigateur. #32131, Commettre
  • 🗓️ Jours du calendrier d'un autre mois. CliLe fait de sélectionner un jour du mois précédent ou suivant dans le calendrier charge désormais également les événements de ce mois, où la vue changeait de mois et restait vide. Commettre, #30972
  • 🧮 Valeurs de variable de chat profondément imbriquées. Une propriété de variable de chat dont la valeur est profondément imbriquée JSON est désormais conservée sous forme de texte brut, où elle pourrait faire échouer la requête. #30389
  • 🔂 Sous-agents et minuteurs sans instructions répétées. Les sous-agents, les minuteurs et les réponses qui suivent le résultat d'un sous-agent en arrière-plan reconstruisent désormais leurs instructions à partir du chat d'origine, où ils ont réutilisé l'invite système terminée du chat, de sorte que le modèle a reçu deux fois son invite système, ses compétences, sa liste de connaissances et ses instructions d'outil et de terminal. Les compétences mentionnées dans le message d'origine et les variables du chat sont désormais également conservées. #31568, Commettre
  • 🚨 Modifications de texte de connaissances qui n'ont pas été indexées. L'enregistrement du texte modifié d'un fichier de connaissances affiche désormais une erreur lorsque le texte n'a pas pu être traité ou qu'une base de connaissances utilisant le fichier n'a pas pu être mise à jour, l'éditeur ayant signalé un succès alors que les recherches ont conservé l'ancien texte. Commettre
  • 📥 Téléchargement de fichiers dont le téléchargement a disparu. Le téléchargement d'un fichier dont le téléchargement d'origine est absent du stockage donne désormais son texte extrait sous forme de fichier texte, là où le téléchargement a échoué sans être trouvé. Commettre
  • 📜 Détails de la compétence lus à partir de SKILL.md. L'éditeur de compétence lit désormais le nom et la description d'une compétence à partir de son en-tête SKILL.md comme YAML approprié, donc les valeurs entre guillemets, les valeurs contenant un deux-points et les descriptions réparties sur plusieurs lignes se remplissent correctement, là où elles sont sorties coupées ou avec des guillemets parasites. Commettre
  • 🗃️ ** Précédent et Suivant entre les pages du dossier. ** Revenir en arrière ou en avant d'une page de dossier à une autre affiche désormais le dossier nommé dans la barre d'adresse, où la page continuait d'afficher le dossier qu'il vous restait. #32146, #32144
  • 📏 Étiquettes de menu longues dans d'autres langues. Les menus tels que le menu Actions dans les modèles d'espace de travail, le menu + dans la saisie du chat et les menus dans les automatisations, les discussions archivées, la personnalisation et les commentaires s'élargissent désormais pour s'adapter aux étiquettes traduites plus longues et les maintiennent alignées à gauche, où les étiquettes longues sont enroulées sur la ligne suivante ou affichées centrées. #32151, #32150
