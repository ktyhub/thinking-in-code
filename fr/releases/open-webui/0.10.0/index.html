open-webui v0.10.0

Ajouté

  • 🤝 Partagez des dossiers avec votre équipe. Vous pouvez désormais partager un dossier et les discussions qu'il contient avec des utilisateurs, des groupes ou tout le monde spécifiques, avec un accès en lecture ou en écriture ; les personnes avec lesquelles vous partagez voient les dossiers partagés dans leur barre latérale et ouvrent les discussions en lecture seule lorsqu'elles n'en sont pas le propriétaire, et les administrateurs contrôlent qui est autorisé à partager des dossiers avec une nouvelle autorisation « Partage de dossiers » désactivée par défaut. Commit, Commit, Commit, Commit, Commit, Commit, Commit, Commit
  • 🗜️ Compactage automatique du contexte pour les longues discussions. Les conversations qui dépassent un seuil de jeton configurable peuvent désormais être résumées automatiquement afin qu'elles restent dans la fenêtre contextuelle d'un modèle, avec une notification affichée pendant qu'elles se produisent ; les administrateurs peuvent l'activer, définir le seuil, personnaliser l'invite de résumé et réduire le seuil par modèle. Il est désactivé par défaut. Commit, Commit, Commit, #19594
  • 🖥️ Prise en charge de l'agent Open WebUI Computer. Open WebUI peut désormais se connecter à Open WebUI Computer via sa passerelle compatible OpenAI, permettant aux chats d'exécuter des sessions d'agent complètes sur votre propre machine avec un accès aux fichiers, terminaux, git et Web. GitHub
  • 🚀 Recherche hybride beaucoup plus rapide sur les grandes bases de connaissances. La recherche hybride s'exécute désormais de manière native dans la base de données sur les configurations pgvector au lieu de charger une collection entière en mémoire, ce qui rend l'interrogation de grandes bases de connaissances considérablement plus rapide. Commettre, #20737
  • 🗂️ Bases de connaissances externes. Les bases de connaissances peuvent désormais être sauvegardées par une source de récupération externe via des connexions de connaissances externes configurables, de sorte que vous pouvez rechercher un système externe existant à partir du chat au lieu uniquement du magasin intégré d'Open WebUI. Commettre
  • 🧠 Système de mémoire retravaillé. Commit, Commit, Commit, Commit, Commit, Commit, Commit, Commit, Commit, Commit
  • 🧩 Nouvelle primitive de plugin : la fonction Event. Là où les fonctions de canal, de filtre et d'action s'exécutent toutes dans une conversation, la nouvelle fonction Event est la première primitive qui s'accroche au système lui-même : elle exécute votre propre Python en réponse aux événements émis dans l'ensemble de l'application : inscriptions, modifications de configuration, téléchargements de fichiers, changements de rôle, suppressions, démarrage et arrêt, et plus encore. Cela rend possible une nouvelle classe de comportement directement dans Open WebUI, de l'intégration et du contrôle d'accès à l'audit, à l'automatisation du cycle de vie et aux intégrations externes. Livré avec un passe-partout de démarrage dans l'éditeur de fonctions. Commit, Documents
  • 🔔 Nouveau système d'événements avec webhooks. Open WebUI émet désormais des événements pour un large éventail d'activités du système : connexions, modifications de configuration, démarrage et actions dans les discussions, les connaissances, les fichiers, etc. Les administrateurs peuvent les envoyer sous forme de webhooks sortants, les acheminer vers des utilisateurs ou des groupes spécifiques et gérer quels événements vont où à partir d'une nouvelle page d'administration des paramètres d'événement. Commit, Commit, Commit, Commit, Commit, Commit, Commit, Commit, Commit, #1240, #16426

  • 🛡️ Avis de sécurité : cette version inclut des correctifs de sécurité et de contrôle d'accès. Nous vous recommandons de mettre à jour les déploiements de production dès que possible. Tous les correctifs de sécurité de cette version ne peuvent pas être énumérés dans la section des correctifs : certains peuvent être retenus pendant une courte période pour donner aux administrateurs le temps de procéder à la mise à niveau. Avis
  • 🔐 Accès en écriture à la base de connaissances appliqué lors du téléchargement. Joindre un fichier téléchargé à une base de connaissances nécessite désormais le même accès en écriture que le reste de la connaissance API, de sorte que les utilisateurs sans accès en écriture ne peuvent plus ajouter de fichiers à une collection en référençant son ID. #26001
  • 🗝️ Autorisation de clé API appliquée sur tous les points de terminaison de clé. L'affichage et la suppression des clés API respectent désormais l'autorisation des clés API, correspondant à la protection déjà appliquée à la création de clé. #25992
  • 🔊 Autorisation de synthèse vocale appliquée sur le point de terminaison vocale. Le proxy vocal OpenAI honore désormais l'autorisation de synthèse vocale, il ne peut donc plus être utilisé par des personnes qui ne sont pas autorisées à utiliser cette fonctionnalité. #25993
  • 🎲 Accès au modèle appliqué lors du repli de l'arène. Atteindre un modèle indirectement via un modèle d'arène sur les demandes d'arrière-plan et de tâches applique désormais les règles d'accès de ce modèle, fermant un chemin qui pourrait autrement les contourner. #26046
  • ⏰ Les automatisations planifiées s'arrêtent pour les comptes désactivés. Les automatisations planifiées revérifient désormais le statut et les autorisations du compte du propriétaire avant chaque exécution, de sorte qu'elles s'arrêtent lorsqu'un compte est désactivé ou que l'accès aux automatisations est révoqué. #26047
  • 🚧 Chemins fortement codés rejetés derrière le proxy. Les chemins de requête qui restent codés après un décodage répété sont désormais rejetés au lieu d'être transmis, empêchant ainsi un parcours de chemin qui pourrait autrement passer inaperçu. #26050
  • 🌐 La récupération des URL d'image est renforcée contre la rereliure DNS. La récupération des URL d'image fournies par l'utilisateur revérifie désormais l'adresse de destination au moment de la connexion, fermant un chemin qui pourrait être utilisé pour atteindre des adresses internes derrière un nom d'hôte public. #25960

  • 🗑️ L'annulation du partage nettoie les lignes orphelines. L'annulation du partage d'une discussion gère désormais les enregistrements de discussion partagés restants, évitant ainsi les entrées obsolètes. #25632
  • 🔎 Les résultats de la recherche Web atteignent le modèle avec la récupération activée. Les résultats de la recherche Web sont désormais transmis au modèle même lorsque l'intégration et la récupération sont activées, au lieu d'être laissés de côté. #25600
  • 🔢 Le nombre de groupes suit la recherche. Le nombre de groupes reflète désormais les résultats de recherche filtrés au lieu de la liste complète. #25689
  • ␣ La touche Espace fonctionne lors du renommage. Appuyer sur l'espace tout en renommant un fichier ou un dossier ne l'ouvre plus, vous pouvez donc saisir des espaces dans les noms. #25627
  • 🩹 Le modèle d'intégration local manquant ne bloque plus le démarrage. Un modèle d'intégration local manquant apparaît désormais comme une erreur différée au lieu d'empêcher le démarrage du serveur. #25683
  • 🔤 Étiquette de paramètres cohérente capitalization. Les étiquettes à bascule dans les paramètres utilisent désormais une casse de titre cohérente. #25765
  • ♿ Meilleures étiquettes de lecteur d'écran sur les bascules. Les bascules d'intégration et de commutation exposent désormais les étiquettes d'accessibilité appropriées et l'état enfoncé pour les lecteurs d'écran. #25258, #25230
  • 📜 Les listes déroulantes longues défilent. Les sélections déroulantes défilent désormais lorsque leur liste est longue, afin que toutes les options restent accessibles. Commettre, #25608
  • 🔽 Les sections pliables n'ont pas de ratés lors du chargement. Les sections pliables ne déclenchent plus leur action de modification lors du premier rendu, évitant ainsi les basculements involontaires lors du chargement de la page. Commettre, #25229
  • ➗ Les expressions mathématiques volumineuses ne bloquent plus le rendu. L'analyse des délimiteurs mathématiques ne déborde plus sur des entrées très volumineuses ou profondément imbriquées, donc les messages avec un rendu mathématique lourd au lieu d'échouer. #25845
  • 🗄️ Les morceaux surdimensionnés n'interrompent plus l'indexation Milvus. Les morceaux de texte trop longs sont désormais coupés avant d'être envoyés à Milvus, de sorte qu'un seul gros morceau ne peut plus faire échouer l'ensemble du lot et laisser un fichier sans intégration. #25857, #25858
  • 📝 L'éditeur de code reste ouvert lorsqu'il est vide. Le tiroir de l'éditeur de code ne s'effondre plus lorsque son contenu est vide. #25855
  • 💽 Les paramètres ne sont plus perdus après un redémarrage. La configuration de l'administrateur est désormais stockée de manière plus fiable, corrigeant les cas où les connexions externes et les paramètres du modèle pourraient être perdus après le redémarrage du serveur. Commit, Commit, Commit, #24743, #25911, #25959
  • 📜 Barre de défilement de discussion visible. La zone de discussion affiche désormais une barre de défilement, ce qui facilite le défilement des réponses longues. Commettre, #25833
  • 🎚️ Les paramètres de modèle par défaut s'appliquent aux requêtes. Les paramètres de modèle par défaut sont désormais appliqués aux requêtes sortantes, de sorte que les paramètres tels que la température et la fenêtre contextuelle prennent effet tels que configurés. Commit, Commit, #24930, #26209
  • 🟢 Indicateur de modèle chargé Ollama restauré. L'indicateur indiquant quel modèle Ollama est chargé dans la VRAM fonctionne à nouveau après les modifications récentes. #25586, #25732
  • 🪪 Les connecteurs MCP statiques récupèrent les détails OAuth manquants. Les connecteurs MCP configurés avec des informations d'identification OAuth statiques remplissent désormais une portée ou une ressource manquante à partir des métadonnées publiées du serveur, afin qu'ils se connectent correctement au lieu d'échouer lorsque ces valeurs ont été omises. Commettre, #25898
  • 📊 Les statistiques d'utilisation et de coût des jetons ne sont plus effacées par les tâches en arrière-plan. L'utilisation et le coût des jetons d'une réponse sont désormais préservés lorsque les tâches en arrière-plan telles que le titre, la balise et la génération de suivi s'exécutent sur le même chat, au lieu d'être écrasées. Commettre
  • 🔗 Lien de partage de modèle mis à jour. Le partage d'un modèle ouvre désormais la page de publication actuelle de la communauté, corrigeant le lien qui pointait vers l'ancien point de terminaison. #25801

Modifié

  • ⚠️ Migrations de bases de données : Cette mise à jour contient des migrations de bases de données. Assurez-vous de sauvegarder votre base de données avant la mise à jour, car la rétrogradation après la migration n'est pas prise en charge.
  • 🔔 Les événements système se déclenchent désormais automatiquement. Avec le nouveau système d'événements, Open WebUI émet des événements pour des activités telles que le démarrage, les connexions et les modifications de configuration, de sorte que tout webhook que vous avez déjà configuré peut commencer à recevoir des appels pour ces événements nouvellement émis après la mise à niveau. Vérifiez les paramètres de vos événements et de votre webhook après la mise à jour afin de recevoir uniquement les événements souhaités. Commettre
  • 🔀 L'appel d'outil natif est désormais le mode par défaut. Chaque conversation et modèle qui n'avait pas explicitement choisi un mode d'appel d'outil exécute désormais Native, qui s'appuie sur la prise en charge d'outils intégrés d'un modèle, tandis que l'ancien comportement a été renommé « Legacy » et a fait l'objet d'une désinscription explicite ; si vos modèles dépendent de l'approche précédente, vous devez les remettre en "Legacy" par chat, par modèle ou globalement dans les paramètres de votre modèle par défaut pour préserver leur comportement. Commettre
  • 🗂️ Les paramètres d'authentification ont été déplacés vers leur propre page. LDAP, OAuth et les paramètres d'authentification associés ont été déplacés de la page Paramètres généraux vers une page d'authentification dédiée dans le panneau d'administration. Commettre
  • 🎓 Plusieurs fonctionnalités ne sont plus en version bêta. Les mémoires, les notes, les canaux et le mode contraste élevé sont sortis de la version bêta et ne portent plus d'étiquette bêta. Commettre
  • 🔧 Paramètre de récupération Web local renommé. La variable d'environnement "ENABLE_RAG_LOCAL_WEB_FETCH" est désormais "ENABLE_LOCAL_WEB_FETCH", ce qui indique qu'elle s'applique au-delà de la récupération ; l'ancien nom fonctionne toujours comme un alias obsolète. Commettre
  • 🔧 Clé de recherche You.com renommée. La recherche Web You.com préfère désormais la variable d'environnement "YDC_API_KEY", l'ancienne "YOUCOM_API_KEY" étant toujours acceptée comme solution de secours. Commettre, #26316
  • 🧪 Client-side Python s'exécute désormais en bac à sable. Client-side Python (Pyodide) s'exécute désormais dans une iframe d'origine opaque et en bac à sable par défaut, isolant le code exécuté de votre session, des cookies, du stockage local et des propres points de terminaison de l'application, tandis que l'accès complet aux Python, JavaScript et au réseau externe est conservé. travailler. Le code qui reposait sur l'atteinte des points de terminaison Open WebUI de même origine à partir de Pyodide ne pourra plus le faire, et Pyodide est désormais marqué comme héritage dans les paramètres d'exécution de code de l'administrateur. Commit, Commit, Commit, Commit, Commit
