open-webui v0.12.3

Ajouté

  • 🔐 Chats cryptés de bout en bout. Les messages directs et les canaux de groupe privés peuvent désormais organiser un chat crypté temporaire de bout en bout : un membre sélectionne Chat crypté dans le menu de la chaîne, les autres membres voient "Chat crypté en cours" avec un lien Rejoindre, les messages jusqu'à 16 Ko sont cryptés dans le navigateur avec MLS et ne transitent que par le serveur sans être enregistrés, les participants peuvent se vérifier mutuellement en comparant les codes et voir quand les autres tapent, et le chat est effacé lorsque vous quittez. ou recharger et se termine lorsque l'adhésion à la chaîne ou l'accès change. Les administrateurs l'activent sous Paramètres d'administration > Général > Canaux cryptés ou avec "ENABLE_ENCRYPTED_CHANNELS" et lui accordent la nouvelle autorisation Canaux cryptés, désactivée par défaut ou définie avec "USER_PERMISSIONS_FEATURES_ENCRYPTED_CHANNELS", et il nécessite des connexions Websocket avec déconnexion du serveur Websocket et HTTPS en production. Commettre, Commettre, Commettre, Commettre
  • 📡 Streaming beaucoup plus léger avec Redis. Avec Redis, une réponse en streaming est désormais stockée sous sa propre clé et un nouveau texte y est ajouté au lieu de réécrire l'intégralité de la réponse dans un hachage partagé à chaque mise à jour, et les réponses démarrées sur des instances plus anciennes sont toujours lues lors d'une mise à niveau ; avec les canaux de salle activés, chaque instance ne s'abonne désormais qu'aux salles des personnes qui y sont connectées, donc Redis ne lui envoie plus de mises à jour en direct pour les chats qu'elle ne dessert pas. Commit Commit #32478
  • 🔍 Comparer les options d'affichage et annuler. La vue Comparer les révisions dispose d'un menu d'options de comparaison pour ignorer les espaces, ignorer les marqueurs d'accentuation ou afficher uniquement les modifications avec les lignes inchangées repliées, un bouton Annuler qui revient en arrière dans vos modifications dans les deux volets dans l'ordre et les lignes modifiées qui sont maintenant alignées par leur texte correspondant. Commit, Commit, Commit, Commit
  • 📝 Aperçus de fichiers Markdown plus riches. Les fichiers Markdown ouverts dans le navigateur de fichiers du terminal s'affichent désormais avec le même moteur de rendu que les réponses de chat, y compris les mathématiques, les notes de bas de page, les blocs de code en surbrillance, les alertes et les diagrammes Mermaid, ainsi que les blocs HTML mélangés avec Markdown, présentés sous forme de document compact, et les cases à cocher de la liste de tâches dans un fichier modifiable peuvent être cochées pour enregistrer la modification dans le fichier. Commettre Commettre Commettre #32514
  • 👀 Collaborateurs en direct dans les chats partagés. La barre supérieure d'un chat affiche désormais les photos des autres personnes qui ont le même chat ouvert à ce moment-là, jusqu'à trois et un compte pour le reste, avec une liste de collaborateurs qui ouvre leurs cartes de profil. Commettre, Commettre, Commettre
  • ✏️ Modifier et régénérer dans les discussions partagées avec réponses. Dans une discussion à partir d'un dossier partagé autorisant les réponses, les personnes autorisées à modifier les messages peuvent désormais modifier une invite pour démarrer une nouvelle branche et régénérer n'importe quelle réponse, pas seulement les réponses à leurs propres messages, et les autres personnes consultant la discussion restent sur la branche qu'elles ont sélectionnée. Valider, Valider
  • 🗄️ Accès aux dossiers dans l'éditeur de dossiers. Le partage d'un dossier s'effectue désormais via un bouton Accès dans la boîte de dialogue Modifier le dossier au lieu d'un élément Partager dans le menu des dossiers, le mode de partage peut être défini avant que quelqu'un ne soit ajouté, et les sous-dossiers notent que l'accès accordé aux dossiers parents s'applique également à eux. Valider, Valider
  • 🔎 Recherche dans l'espace de travail. La fenêtre de recherche recherche désormais vos discussions, les discussions dans des dossiers partagés avec vous, les discussions partagées avec vous, les chaînes et les messages directs et les notes en un seul endroit, avec des filtres pour le type de contenu, un dossier ou une chaîne, et si quelque chose a été créé par vous ou partagé avec vous, les correspondances en surbrillance, un aperçu de chaque résultat avec Ctrl/Cmd + Entrée, Copier le lien et les résultats de la chaîne qui ouvrent le fil de discussion défilent jusqu'au message correspondant. Commettre, Commettre, Commettre
  • 💭 Commentaires dans les aperçus des documents. Les fichiers Word, Excel, PowerPoint et PDF ouverts dans le navigateur de fichiers du terminal affichent désormais leurs commentaires et réponses, marqués à leur place dans le document et ouverts en survolant ou en appuyant sur un marqueur, et les anciennes feuilles de calcul .xls peuvent désormais également être prévisualisées. Commettre
  • 🧹 Raccourci Effacer les sélections d'entrée. Effacer le remplacement du modèle, les outils et filtres sélectionnés ainsi que les bascules de recherche sur le Web, de génération d'images et d'interpréteur de code à partir de l'entrée du chat est désormais un raccourci que vous pouvez modifier dans Paramètres > Raccourcis, toujours Échapper par défaut. Commettre
  • 🙋 Renseignez-vous sur un fichier depuis le navigateur de fichiers. La sélection de texte dans un fichier ouvert dans le navigateur de fichiers du terminal affiche désormais une boîte "Demander ou modifier…" qui envoie votre demande au modèle avec le fichier joint et la sélection citée, afin qu'il puisse répondre ou modifier ce fichier dans le même terminal ; les modifications non enregistrées peuvent être enregistrées avant l'envoi, et les demandes envoyées pendant qu'une réponse est en cours d'attente dans la file d'attente. Commettre
  • ☁️ Accès à Google Drive limité aux fichiers sélectionnés. Le sélecteur Google Drive demande désormais uniquement l'accès aux fichiers sélectionnés par l'utilisateur au lieu d'un accès en lecture à l'ensemble de son Drive, de sorte que les installations auto-hébergées n'ont plus besoin de la vérification à portée restreinte de Google et les utilisateurs ne voient plus l'avertissement « Google n'a pas vérifié cette application ». #32531 Commit #29537
  • 📜 Texte intégral des longues lignes d'état. Les lignes d'état au-dessus d'une réponse, comme un résumé d'utilisation du jeton envoyé par une fonction, peuvent désormais être clickées pour afficher leur texte intégral, et avec plusieurs lignes d'état, l'historique affiche chaque entrée dans son intégralité. #32532 Commit #30056
  • 📏 Limites de lecture des compétences. Les administrateurs peuvent définir le nombre de caractères d'une compétence que le modèle lit à la fois et la durée de l'aperçu des instructions plus longues, sous Paramètres d'administration > Général avec « Limite de lecture des compétences » et « Longueur de l'aperçu des compétences » ou les variables d'environnement « SKILL_CONTENT_MAX_CHARS » et « SKILL_PREVIEW_MAX_CHARS », qui sont par défaut 20 000 et 5 000. [Commit] (https://github.com/open-webui/open-webui/commit/92e64c1d59cdd99b5f33a108186a1d368daab964)
  • 🔄 Améliorations générales. Diverses améliorations ont été mises en œuvre dans l'application pour améliorer les performances, la stabilité et la sécurité.
  • 🌐 Mises à jour des traductions. Les traductions du portugais (Brésil), du chinois (traditionnel), de l'arabe, du bengali, de l'hébreu, du géorgien, du pendjabi, du slovaque, du serbe, de l'ourdou, de l'ouzbek et du vietnamien ont été améliorées et élargies. #32440, #32482, #32501

Corrigé

  • 🧾 Requêtes d'en-tête de clé API dans le journal d'audit. Les requêtes authentifiées avec une clé API dans l'en-tête x-api-key, telles que les SDK Anthropiques l'envoient, ou dans un en-tête défini avec "CUSTOM_API_KEY_HEADER" apparaissent désormais dans le journal d'audit sous le propriétaire de la clé, et les tentatives infructueuses avec une clé incorrecte sont enregistrées sans utilisateur, où ces demandes manquaient dans le journal d’audit. #32443, Commettre
  • 📚 Le partage de connaissances est conservé lors du changement de nom. Un collaborateur disposant d'un accès en écriture qui modifie le nom ou la description d'une base de connaissances partagée ne désactive plus le partage qu'il n'a pas pu définir lui-même, comme Public. #32450, Commit, #32449
  • 🤝 Partage d'invites et d'outils conservé lors de l'enregistrement. Un collaborateur disposant d'un accès en écriture qui enregistre une invite ou un outil partagé ne le rend plus privé pour tout le monde ; le partage qu'ils n'ont pas pu définir eux-mêmes est désormais conservé. #32493, Commit, #32492
  • 📄 Exportation PDF de longues notes et discussions. Les longues notes et discussions sont désormais téléchargées au format PDF, là où Firefox a échoué avec "Le canevas dépasse la taille maximale" et Chrome a enregistré un PDF noir. #32459, Commit, #18334, #26373, #19583
  • ⏩ Continuer la réponse avec plusieurs modèles. Continuer la réponse continue désormais la réponse sous laquelle elle était cli, où dans une discussion avec plusieurs modèles, il pourrait étendre la réponse d'un autre modèle. #32456, Commit, #32455
  • 🏷️ Balises des chats importés. Les chats importés affichent désormais leurs balises et les balises apparaissent dans les suggestions de balises, où les balises manquantes dans le compte n'ont pas été créées lors de l'importation. #32454, Commit, #32453
  • 🔖 Tags des discussions archivées. La recherche dans la barre latérale d'un tag dont les chats sont tous archivés ne supprime plus le tag, qui a perdu son nom d'origine lors de la désarchivage des chats. #32452, Commit, #32451
  • ⌨️ Méthodes de saisie dans les canaux. Appuyer sur Entrée pour confirmer un mot lors de la saisie avec une méthode de saisie, comme pour le japonais, le chinois ou le coréen, n'envoie et n'efface plus un message de canal avant que le mot ne soit entré. Commit
  • 🖱️ Erreur de défilement après avoir quitté une discussion. Faire défiler une discussion juste avant d'ouvrir Notes n'enregistre plus une TypeError dans la console du navigateur. #32458, Commit, #32457
  • 📐 Premier tour stable dans les nouvelles discussions. Le dernier message et la réponse dans une nouvelle discussion conservent désormais leur hauteur réelle lorsque la discussion est enregistrée et que la liste des messages se recharge, de sorte que la vue ne saute plus au premier tour. Commettre
  • 💬 Envoi dans les chaînes. Votre propre message de chaîne reste désormais en place lorsque le serveur le confirme au lieu d'être redessiné, et la chaîne défile jusqu'à votre nouveau message au fur et à mesure que vous l'envoyez, où il pourrait sauter ou conserver l'ancienne position de défilement. Commettre
  • 📂 Dossier du terminal dans les nouvelles discussions. Dans une nouvelle discussion, les fichiers que vous joignez sont téléchargés dans le dossier ouvert dans le navigateur de fichiers du terminal et le navigateur de fichiers reste dans ce dossier une fois la discussion créée, où les téléchargements peuvent aller vers le dossier par défaut et le navigateur y revient. Commettre
  • 📁 Paramètres et accès au dossier partagé. La modification des modèles, de l'invite système ou des fichiers d'un dossier partagé ne réinitialise plus son mode de partage, et un sous-dossier dans un dossier partagé avec accès en écriture reste accessible en écriture lorsqu'il est également partagé directement avec un accès en lecture. Valider, Valider
  • 🔑 Actualisation du jeton OAuth avec client_secret_basic. Lorsque "OAUTH_TOKEN_ENDPOINT_AUTH_METHOD" est client_secret_basic, l'actualisation du jeton envoie désormais les informations d'identification client dans l'en-tête Basic comme le fait la connexion, où les fournisseurs qui acceptent uniquement Basic ont rejeté l'actualisation et Open WebUI a supprimé les jetons OAuth de l'utilisateur, rompant ainsi modéliser les connexions et les serveurs d’outils qui les utilisent jusqu’à la prochaine connexion. #32507, Commit, #32506
  • 🛠️ Outils OAuth après la connexion. Un outil OAuth MCP reste désormais activé après sa redirection de connexion lorsque le modèle dispose d'outils par défaut et que les liens avec ?tools= activent les outils répertoriés. #32488, Commit, #32476
  • 🔤 Police par défaut de l'administrateur conservée. Enregistrement des paramètres > L'interface ne stocke plus la police par défaut de l'administrateur et la taille de compression de l'image comme vos propres paramètres, donc les modifications ultérieures de ces valeurs par défaut vous parviennent toujours. #32497, Commit, #32496
  • 🔊 Lire à haute voix avec une parole lente. La lecture à haute voix ne s'arrête plus après la première phrase lorsque le moteur vocal met plus de temps à produire la suivante que la lecture actuelle. #32484, Commit, #32446
  • 🖼️ Aperçus HTML en ligne sur les terminaux de chat. Les aperçus HTML en ligne dans les réponses trouvent désormais le fichier dans le propre espace de travail du terminal de chat lorsque le contexte de chat Open Terminal est Par chat, où ils affichaient "Fichier introuvable". #32485, Commit, #32477
  • 🧵 Réponses dans les fils de discussion. Une réponse lancée dans un fil de discussion de canal ne se répercute plus sur le fil de discussion suivant que vous ouvrez, où les messages pourraient citer un message de l'autre fil de discussion. #32490, Commit, #32489
  • 📑 Aperçus PDF numérisés. La prévisualisation d'un PDF numérisé sans calque de texte dans la visionneuse de la base de connaissances ne fait plus défiler la page vers le haut et met l'en-tête et la barre d'outils hors de portée. #32487, Commit, #32481
  • ↩️ Listes de droite à gauche. Les puces, les chiffres et les cases à cocher des listes Markdown se trouvent désormais du bon côté pour le texte de droite à gauche dans les réponses et les aperçus de fichiers. Commettre, #32444
  • 🔁 Régénérer dans les discussions partagées clonées. La régénération fonctionne désormais dans une discussion que vous avez clonée ou dérivée du partage de quelqu'un d'autre, où elle a échoué avec "Vous ne pouvez régénérer que vos propres messages". #32508, Commit, #32505
  • 🗑️ Supprimer masqué pour les répondeurs dans les chats partagés. Les personnes répondant dans un chat partagé ne voient plus de bouton Supprimer que le serveur refuse, ce qui faisait revenir une réponse supprimée au rechargement ; Supprimer les émissions pour le propriétaire du chat et les administrateurs lorsque "ENABLE_ADMIN_CHAT_ACCESS" est activé. #32480, Commit, #32479
  • 🎛️ Les fonctionnalités par défaut du modèle peuvent être désactivées. Un modèle peut désormais désactiver une fonctionnalité par défaut, telle que l'interpréteur de code, que l'administrateur a activée dans les préférences du modèle, où elle est réactivée lors de la réouverture et dans de nouvelles discussions. #32500, Commit, #32498
  • 🧰 Les outils intégrés réactivés restent activés. Un outil intégré tel que la mémoire qui est désactivé dans les paramètres par défaut du modèle reste désormais activé après qu'un modèle l'a rallumé et est enregistré. #32504, Commettre, #32503
  • 🏠 Actualiser avec le mode Landing Page défini sur Chat. L'actualisation d'une nouvelle discussion lorsque le mode Landing Page est Chat ne masque plus le champ de message et ouvre le menu modèle dans le coin supérieur gauche. #32510, Commettre, #32509
  • 🗜️ Le compactage pendant l'exécution de l'outil empêche les sources d'entrer. Le compactage du contexte lors d'une longue série d'appels d'outils résume désormais votre propre message sans que les connaissances et le contenu du fichier y soient ajoutés, et ce contenu est ensuite restitué au modèle. Commettre, #32491
  • 🧩 Outils intégrés avec un paramètre d'outils personnalisé. Un modèle avec un paramètre personnalisé nommé outils, comme celui qui active la recherche Web native d'un fournisseur, conserve désormais ses outils intégrés, ses outils attachés et son contexte de fichier, et ses outils personnalisés sont envoyés avec eux. #32530 Commettre #32528
  • 🔌 Les serveurs d'outils sont de retour après une panne. Avec Redis, les outils des serveurs d'outils OpenAPI reviennent désormais une fois que les serveurs sont à nouveau accessibles, où une liste vide mise en cache alors que chaque serveur était en panne les maintenait manquants jusqu'à un redémarrage ou une sauvegarde dans les paramètres du serveur d'outils. #32533 Commettre #29573
  • 📥 Liens PDF lus comme des documents. Les PDF provenant de sites qui bloquent les clients inconnus, tels que Wikimedia, et les liens arXiv comme arxiv.org/pdf/1706.03762 vont désormais à l'extraction de documents, où le modèle a obtenu les octets PDF bruts. #32523 Commettre #32524 Commettre

Modifié

  • 🎯 Les compétences du modèle chargent désormais leurs instructions complètes. Avec l'outil intégré Compétences activé, les compétences attachées à un modèle dans l'éditeur de modèle, que chaque nouveau chat présélectionne, et les compétences sélectionnées dans le menu de saisie du chat envoient désormais leurs instructions complètes avec chaque message, où elles n'étaient répertoriées que par nom et description pour que le modèle soit chargé avec view_skill ; les déploiements qui attachaient des compétences à des modèles uniquement pour les rendre disponibles devraient les supprimer du modèle pour éviter la longueur supplémentaire de l'invite, puisque chaque compétence que l'utilisateur peut lire est de toute façon répertoriée pour le modèle. Commettre
  • 📮 Autorisations Redis pour les canaux de salle. Avec "WEBSOCKET_REDIS_ROOM_CHANNELS" activé, l'utilisateur Redis a désormais besoin des autorisations PUBLISH, SUBSCRIBE, UNSUBSCRIBE et PING et de l'accès aux canaux "&socketio" et "&socketio#*", tandis que PSUBSCRIBE n'est plus utilisé ; une autorisation manquante est enregistrée avec la manière de la corriger. Commettre
