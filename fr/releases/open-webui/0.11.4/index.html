  • 🗄️ Prise en charge de la base de données Slim. L'image slim s'exécute sur SQLite, sa valeur par défaut, ou sur PostgreSQL ; pointé sur MySQL, MariaDB ou un autre moteur, ou démarré avec les connexions AWS RDS IAM activées, il s'arrête avec une erreur au lieu de démarrer, et ces déploiements ont besoin de l'image standard. Commettre
  • 📁 Stockage de fichiers mince. L'image mince conserve les fichiers sur le stockage local, sa valeur par défaut ; configuré pour un bucket S3, Google Cloud ou Azure, il s'arrête avec une erreur au lieu de démarrer, et ces déploiements nécessitent l'image standard. Commettre
  • 🧮 Recherches Slim uniquement via pgvector. La recherche de connaissances sur l'image slim nécessite PostgreSQL avec pgvector, et configurée pour un autre magasin de vecteurs, l'instance démarre toujours et l'échec arrive la première fois que quelque chose est recherché plutôt qu'au démarrage. Valider, Valider
  • 🧠 Exigences d'intégration minces. L'image mince ne comporte aucun modèle d'intégration ou de reclassement, les connaissances nécessitent donc des intégrations OpenAI, Ollama ou Azure OpenAI et un reclasseur externe, revenant à une notation cosinus simple où aucun n'est défini. Commettre
  • ✂️ Fractionnement de document mince. Le fractionnement d'un document le long d'un tokenizer téléchargé n'est pas disponible sur l'image mince, ce qui laisse le fractionnement par caractère ou par nombre de jetons. Commettre
  • 📃 Lecteurs de documents minces. L'image mince lit les fichiers texte, Markdown, CSV, HTML et XML tels qu'ils sont ; le téléchargement d'un PDF, d'un fichier Word ou d'une présentation échoue à moins que l'un des extracteurs de documents externes ne soit configuré. Commettre
  • 🎙️ Exigences vocales minces. L'image mince ne contient ni chuchotement local ni voix locales, donc la parole en texte et la synthèse vocale nécessitent un moteur externe avant de fonctionner. Engager
  • 🕸️ Récupération de page Web mince. L'image mince ne comporte pas de navigateur sans tête, donc une page Web est récupérée via HTTP simple ou via un chargeur externe, et une page qui se dessine avec JavaScript revient avec moins de contenu que sur l'image standard. Valider, Valider
  • 🔎 Slim laisse de côté DDGS. DDGS, le fournisseur de métarecherche qui n'a pas besoin de clé propre, n'est pas présent dans l'image slim, donc la recherche sur le Web a besoin d'un fournisseur avec une clé. Commettre
  • 📥 Packages d'interpréteur de code Slim. L'image slim laisse de côté les packages de l'interpréteur de code, donc le navigateur récupère numpy, pandas, matplotlib, scikit-learn et le reste de "cdn.jsdelivr.net" et l'interpréteur cesse de fonctionner là où cela est bloqué. Commettre
  • 🧰 Exigences Slim git. L'image slim ne porte plus git, donc un outil ou une fonction dont les exigences pointent vers une adresse "git+https://" ne parvient pas à s'installer et a besoin de l'image standard ou d'un package publié. Engager
  • 🧺 Suppression de la communauté LangChain. Les lecteurs de texte, HTML, Word, CSV, PDF et Azure Document Intelligence sont désormais écrits ici plutôt que extraits de "langchain-community", qui n'est plus installé ; un outil ou une fonction qui l'importe doit désormais le nommer dans ses propres exigences. Commettre
  • 🧾 Importations de packages non déclarées. Les packages qui se trouvaient dans l'image uniquement par accident, parmi lesquels nltk, pymongo, le Google Drive client et le Gemini SDK, ne sont plus installés, donc un outil ou une fonction qui en importe un doit le nommer dans ses propres exigences. #29725, #29726, Commit
  • 🆔 Model ID whitespace. Un modèle d'espace de travail dont l'ID contient un espace ou une tabulation est désormais refusé dans l'éditeur, via le API et à l'import ; celui déjà stocké continue de répondre mais ne peut pas être enregistré à nouveau tant qu'il n'est pas recréé. Engager
  • 🖇️ Rendu du schéma de liens. Un lien dans une réponse, une citation ou un résultat de recherche sur le Web est désormais rendu uniquement là où il pointe vers une adresse Web, une adresse e-mail, un numéro de téléphone ou quelque part dans cette instance ; tout le reste, une adresse "ftp://" ou un lien d'application tel que "obsidian://" ou "vscode://" parmi eux, est affiché sous forme de texte. Deux vieilles bizarreries l'accompagnent : une source écrite sous la forme "HTTP://" devient désormais un lien, et un nom de fichier contenant simplement les lettres http ne devient plus un nom qui ne mène nulle part. #29890
  • 🧲 L'onglet Intégrations est facultatif. L'onglet Intégrations dans les paramètres personnels, où vos propres connexions aux outils et aux terminaux sont gérées, est désormais masqué jusqu'à ce qu'un administrateur active les intégrations directes sous Intégrations ou définisse "ENABLE_DIRECT_INTEGRATIONS", et le masquer laisse les connexions existantes fonctionner. Valider, Valider
  • 📡 Point de terminaison de vérification de connexion d'image. Le point de terminaison qui vérifie une connexion de génération d'image a été déplacé et prend désormais la connexion à tester dans la requête elle-même, donc tout ce qui appelle l'ancienne adresse doit être mis à jour. S'engager
