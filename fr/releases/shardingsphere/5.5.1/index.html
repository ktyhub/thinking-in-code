shardingsphere 5.5.1

Correctif Publié22 oct. 2024 Sourceapache/shardingsphere Anglais original

Cette page est traduite automatiquement. Le texte anglais original fait foi.

sphère de partage 5.5.1

API Modifications

  1. Autorité : marquer le fournisseur de privilèges ALL_PERMITTED comme obsolète et sera supprimé à l'avenir
  2. DistSQL : suppression du paramètre facultatif utilisationCount de l'affichage des unités de stockage
  3. Fractionnement en lecture-écriture : remplacez dataSources par dataSourceGroups pour YAML

Nouvelles fonctionnalités

  1. Noyau : ajout d'un nouveau module d'analyseur Doris, Hive et Presto SQL et d'un nouveau type de base de données

Améliorations

  1. DistSQL : vérifiez les privilèges lors de l'enregistrement ou de la modification de l'unité de stockage
  2. DistSQL : vérifiez les nœuds de données réels en double lors de la création ou de la modification d'une règle de table de partitionnement
  3. DistSQL : ajouter une prise en charge similaire pour afficher les unités de stockage
  4. DistSQL : restauration en cas d'échec de la configuration de la base de données d'importation
  5. DistSQL : ajouter un type de table à l'ensemble de résultats des tables logiques d'affichage
  6. Analyseur SQL : prend en charge la réplication des modifications MySQL sans identifiant de serveur
  7. Analyseur SQL : prend en charge les alias de ligne et de colonne MySQL avec ON DUPLICATE KEY UPDATE
  8. Analyseur SQL : prend en charge MySQL CALL sql avec le préfixe mysql
  9. Analyseur SQL : prend en charge MySQL pour créer une fonction chargeable, renvoie int/dec
  10. Analyseur SQL : prise en charge de l'analyse syntaxique de MySQL CREATE TABLESPACE/TABLE dans Mysql-8
  11. Analyseur SQL : prise en charge de l'analyse syntaxique de MySQL CREATE INDEX avec ENGINE_ATTRIBUTE
  12. Analyseur SQL : prise en charge de l'analyse des données de chargement de MySQL avec la variable @
  13. Analyseur SQL : prise en charge de l'analyse de l'instruction MySQL START REPLICA
  14. Analyseur SQL : prise en charge de l'analyse de la fonction de table MySQL json
  15. Analyseur SQL : ajouter la colonne MySQL non nulle à l'analyse SQL
  16. Analyseur SQL : ajouter l'analyse SQL du jeu de caractères MySQL
  17. Analyseur SQL : améliorer le résultat de l'instruction de visite de la fonction mysql json
  18. Analyseur SQL : prend en charge les mots-clés PostgreSQL COLLATION et CONSTRAINT
  19. Analyseur SQL : prend en charge PostgreSQL, la table de fonctions openGauss et la mise à jour à partir de l'analyse
  20. Analyseur SQL : prend en charge CTE avec PostgreSQL et openGauss
  21. SQL Parser : optimisez la prise en charge du fuseau horaire de PostgreSQLDateValueParser.
  22. Analyseur SQL : prend en charge la limite PostgreSQL et le décalage comme nul
  23. Analyseur SQL : améliorez l'instruction de mise à jour Oracle en tant qu'analyse d'alias et ajout d'un scénario de test
  24. Analyseur SQL : prend en charge l'analyse SQL de type unité de longueur de colonne Oracle
  25. Métadonnées : collectez le type de table pour PostgreSQL
  26. Noyau : prise en charge de l'extraction d'indices SQL lorsque SQL contient un commentaire d'indice dbeaver
  27. Noyau : ajouter un extrait combiné, sélection à gauche dans la méthode extractFromSelectStatementWithoutProjection
  28. Noyau : ajout d'un nœud assisté pour créer et supprimer des bases de données
  29. Transaction : utilisez le même type de transaction dans une transaction dans l'adaptateur JDBC
  30. Transaction : prise en charge du changement de type de transaction
  31. Fédération SQL : prend en charge la fonction bit_count de la fédération SQL pour mysql
  32. Fédération SQL : amélioration des fonctions SQL atan et anan2 pour mysql
  33. Fédération SQL : prend en charge la fonction bin des requêtes fédérées mysql
  34. Fédération SQL : prise en charge de l'opérateur NOT de requête fédérée
  35. Proxy : Organisez les résultats des tableaux d'affichage dans l'ordre
  36. Proxy : déclenchez la collecte de métadonnées lors de la création et de la suppression d'une base de données et d'une table
  37. Proxy : optimiser l'agent pour prendre en charge la collecte de données de métriques à partir de plusieurs sources de données lorsqu'il est utilisé avec Driver
  38. Proxy Native : ajoutez plus de métadonnées d'accessibilité graalvm pour le cache de caféine
  39. Sharding : révisez tous les index locaux pour la table de partitionnement et ajoutez le niveau d'unicité de l'objet spi pour contrôler le générateur de jetons d'index.
  40. Sharding : ajoutez NullsOrderType.LOW et NullsOrderType.HIGH pour gérer l'ordre NULL via la fonction de partitionnement
  41. Sharding : ajoutez des algorithmes de partitionnement en ligne correspondant à la vérification réelle des nœuds de données
  42. Chiffrer : ajouter une vérification non prise en charge pour l'instruction combine avec les colonnes de chiffrement
  43. Chiffrer : prise en charge de la réécriture de chiffrement distincte (colonne) et de la refactorisation de la logique de construction SubstitutableColumnNameToken
  44. Chiffrer : prise en charge de la réécriture de l'instruction concat imbriquée concat avec fonction de chiffrement
  45. Pipeline : ajoutez SHARDING_TOTAL_COUNT impl de JobExecutorServiceHandler pour améliorer les exigences en matière de cœur de processeur
  46. Pipeline : requête de page de support pour le dumper d'inventaire et requête de streaming de cohérence des données
  47. Pipeline : utilisez des identifiants insensibles à la casse pour améliorer le chargeur de métadonnées de table
  48. Pipeline : prise en charge de la commande des colonnes de clé primaire pour le chargeur de métadonnées de table de pipeline standard

Corrections de bugs

  1. DistSQL : correction d'une erreur de chargement d'une table unique après la création d'une source de données logique
  2. DistSQL : correction de l'échec aléatoire de la définition de l'unité de stockage à table unique par défaut
  3. DistSQL : échec de la définition de l'unité de stockage à table unique par défaut sur la source de données logique
  4. DistSQL : correction de NPE lors de l'importation de métadonnées
  5. Analyseur SQL : prise en charge de PostgreSQL, action de conflit sans rien faire
  6. Analyseur SQL : correction de la fonction Oracle nvl et de l'erreur d'analyse des heures d'intervalle
  7. Métadonnées : conserver le nœud de stockage utilisé lors de la désinscription de l'unité de stockage
  8. Métadonnées : correction du problème d'unité de stockage manquante lors de l'enregistrement de l'unité de stockage
  9. Noyau : remplacez ThreadLocal par TransmittableThreadLocal dans HintManager pour prendre en charge l'utilisation de plusieurs threads.
  10. Noyau : utilisez ConnectionPropertiesParser spi pour analyser jdbcUrl afin de résoudre l'erreur d'analyse d'URL Oracle.
  11. Noyau : correction de l'exception d'affirmation du nombre de colonnes provoquée par le juge de table système postgresql
  12. SQL Binder : ajoutez l'interface TableAvailable pour CloseStatementContext, MoveStatementContext, FetchStatementContext et corrigez le scénario de test de réécriture SQL
  13. Transaction : correction de l'invocation de la méthode setSavepoint qui ne se nettoie pas
  14. Transaction : correction du gestionnaire de points de sauvegarde non nettoyé dans les transactions distribuées
  15. Transaction : correction du contexte de transaction non nettoyé lorsqu'une transaction xa est validée
  16. Transaction : corrigez le problème selon lequel le curseur n'est pas réécrit
  17. Fédération SQL : correction de la conversion LocalDateTime des requêtes fédérées
  18. Fédération SQL : correction de l'erreur d'exécution de SQL lorsque SQL contient un caractère chinois avec la fédération SQL
  19. Fédération SQL : correction de la requête de données de type binaire de requête de fédération
  20. Fédération SQL : correction du résultat nul dans la requête fédérée pour une seule colonne projetée
  21. Fédération SQL : correction d'une exception de type inconnu de fédération SQL causée par un type de résultat incorrect en calcite avec bigint
  22. Proxy : prend en charge la valeur booléenne de type binaire dans PostgreSQL
  23. Proxy : prend en charge les paramètres préparés de type tableau dans PostgreSQL
  24. Proxy : prend en charge la valeur du protocole binaire pour le tableau de texte dans PostgreSQL
  25. Proxy : correction des résultats en double lors de l'interrogation de information_schema.SCHEMATA
  26. Proxy : corrigez les résultats incorrects lors de l'interrogation de information_schema.SCHEMATA.
  27. Proxy : corrigez NPE lors de l'exécution de l'affichage de l'état de la table
  28. Proxy : Correction d'une exception de sélection de base de données lors de l'affichage des tables de la base de données.
  29. Proxy : corrigez l'erreur selon laquelle le processus ne se termine pas après l'échec du démarrage du proxy.
  30. Proxy : corrigez l'erreur selon laquelle les métadonnées système persistantes n'étaient pas effacées après la suppression de la base de données dans le scénario PostgreSQL.
  31. Proxy : correction d'une exception d'absence de base de données sélectionnée dans la requête SQL
  32. JDBC : résolvez le problème de « fichier zip fermé » dans les versions antérieures à SpringBoot 2.3.
  33. JDBC : corrigez le NPE lorsqu'il ne contient pas de base de données logique spécifiée dans le pilote.
  34. Sharding : correction de la colonne Sharding non suivie via des alias
  35. Sharding : correction de l'exception de modification de la vue lors de la règle de partitionnement de configuration et de la règle de table de liaison
  36. Sharding : le correctif nécessite d'accumuler la logique
  37. Sharding : correction de l'erreur d'insensibilité à la casse du nom de la colonne de clé générée
  38. Chiffrer : correction du résultat incorrect de l'affichage de la table de création avec chiffrement lorsque le type de données contient un flottant
  39. Chiffrer : corrigez le problème de mise à jour d'une table non chiffrée et d'utilisation d'une sous-requête sur une table chiffrée.
  40. Chiffrer : ajouter une réécriture de sélection d'insertion pour le chiffrement
  41. Pipeline : InventoryTaskSplitter compatible avec la clé primaire BigInteger
  42. Pipeline : correction de la source de données par défaut perdue lors de la création d'une tâche de migration
