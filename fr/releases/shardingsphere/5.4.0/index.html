shardingsphere 5.4.0

Mineure Publié8 juil. 2023 Sourceapache/shardingsphere Anglais original

Cette page est traduite automatiquement. Le texte anglais original fait foi.

sphère de partage 5.4.0

API Modifications

  1. Métadonnées : remplacez les tables de diffusion de partitionnement par des tables de diffusion globales
  2. JDBC : supprimez le point d'exclamation (!) pour les règles globales
  3. DistSQL : simplifiez les mots-clés ASSISTED_QUERY, LIKE_QUERY dans le chiffrement DistSQL
  4. DistSQL : optimiser la syntaxe des règles SQL_PARSER
  5. Chiffrer : Ajustez le chiffrement yaml API pour faire la distinction entre les configurations de chiffrement, de like et de requête assistée.
  6. Chiffrer : supprimez la configuration de la colonne simple et de la requêteAvecCipherColumn dans la fonction de chiffrement
  7. Fractionnement en lecture-écriture : Refactoriser le fractionnement en lecture/écriture api
  8. Proxy : Supprimer la configuration de type d'instance de proxy
  9. Proxy : supprimez la propriété proxy-backend-executor-suitable
  10. Proxy : Supprimez la propriété proxy-mysql-default-version
  11. Mise à l'échelle : refactoriser le commit rollback streaming pour abandonner le streaming
  12. Sharding : fusionner ShardingCacheRule dans ShardingRule (expérimental)

Nouvelles fonctionnalités

  1. DistSQL : Nouvelle syntaxe pour gérer la règle SQL_FEDERATION
  2. Proxy : prise en charge du socket de domaine Unix

Améliorations

  1. Mise à l'échelle : CDC prend en charge le mode incrémentiel pur
  2. Mise à l'échelle : CDC prend en charge l'exportation de données par transaction
  3. Mise à l'échelle : CDC prend en charge MySQL et PostgreSQL
  4. Mise à l'échelle : CDC prend en charge une seule table
  5. Mise à l'échelle : CDC prend en charge tous les types de données openGauss
  6. Mise à l'échelle : CDC prend en charge la reconnexion par réplication
  7. Mise à l'échelle : supprimer DataConsistencyCalculateAlgorithmChooser
  8. Mise à l'échelle : améliorez les performances de la répartition des données d'inventaire des tables de clés uniques en nombres entiers
  9. Mise à l'échelle : ajustez la valeur par défaut de la configuration du processus pour réduire la consommation de ressources
  10. Mise à l'échelle : actualisation automatique des métadonnées de la table pour la migration
  11. Mise à l'échelle : compatible avec la réutilisation des emplacements de réplication existants d'OpenGauss lorsque la base de données n'existe pas
  12. Mise à l'échelle : afficher le résultat de la vérification de la cohérence des données doit être vide lorsqu'il n'est pas terminé
  13. Mise à l'échelle : activer la correspondance CRC32 simultanée sur la source et la cible
  14. Mise à l'échelle : travail de pipeline compatible avec la stratégie d'audit des règles de partitionnement
  15. Métadonnées : refactoriser la structure de persistance des métadonnées
  16. Métadonnées : optimisez le processus de chargement des métadonnées d'une seule table
  17. Métadonnées : prise en charge des requêtes vides des tables système MySQL/PostgreSQL/openGauss
  18. DistSQL : ajout de la prise en charge de transactionalReadQueryStrategy pour la règle de fractionnement en lecture/écriture
  19. DistSQL : vérification améliorée des propriétés de l'algorithme
  20. Transaction : Ajouter un contrôle de privilège
  21. Transaction : supprimez le TransactionTypeHolder et créez uniquement le gestionnaire de transactions actuel.
  22. Analyseur : prend en charge les instructions MySQL LOAD DATA et LOAD XML avec une table unique ou une table de diffusion.
  23. Analyseur : améliore la prise en charge de l'analyse des instructions SQL haute priorité dans les résultats des tests du programme de test MySQL
  24. Analyseur : l'analyseur de dialectes Oracle prend désormais en charge la virgule chinoise
  25. Chiffrer : prise en charge de la requête de la colonne de chiffrement dans la sous-requête de projection lors de l'utilisation de la fonction de chiffrement
  26. Noyau : ajoute une vérification des métadonnées d'existence de table pour les instructions INSERT, DELETE, UPDATE et SELECT
  27. JDBC : implémenter l'exécution par lots pour ShardingSphereStatement
  28. Proxy : Frontend prend en charge SSL/TLS
  29. Proxy : prend en charge le message Flush pour le proxy PostgreSQL/openGauss.
  30. Proxy : prend en charge le bit de type de données, bool pour le proxy PostgreSQL.

Corrections de bugs

  1. Mise à l'échelle : correction de la persistance et de l'utilisation de l'état d'échec des tâches du pipeline
  2. Mise à l'échelle : correction de l'événement CDC DELETE Record.beforeList est nul
  3. Mise à l'échelle : correction du problème de guillemet unique du plug-in de décodage openGauss mppdb
  4. Mise à l'échelle : correction du moteur d'exécution non fermé après l'arrêt du travail
  5. Mise à l'échelle : correction de l'arrêt du travail avant le démarrage de la tâche
  6. Métadonnées : correction d'un problème sensible à la casse lors du chargement des métadonnées du schéma avec la base de données H2
  7. Métadonnées : correction de l'exception "objet introuvable" lors de la configuration du nom de schéma PostgreSQL/openGauss comme nom de base de données
  8. DistSQL : correction du résultat erroné de check_table_metadata_enabled lors de l'exécution de SHOW DIST VARIABLE
  9. Chiffrer : correction de l'exception de réécriture SQL lors de l'utilisation de la fonctionnalité de chiffrement PostgreSQL/openGauss
  10. Sharding : prise en charge de la transmission des conditions de partitionnement nulles à l'algorithme de partitionnement pour permettre à l'utilisateur de contrôler l'itinéraire de valeur nulle
  11. Analyseur : prise en charge de l'analyse des expressions ENTRE ET dans la projection MySQL
  12. Masque : correction du mauvais résultat du masque lors de la configuration de la même valeur de-x et to-y avec KEEP_FROM_X_TO_Y
  13. Infra : une correction de ClassNotFoundException peut se produire en cas de pgjdbc manquant
  14. Proxy : correction du paquet MySQL hors service lorsque client envoie des requêtes de pipeline
