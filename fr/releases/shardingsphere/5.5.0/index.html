shardingsphere 5.5.0

Mineure Publié30 avr. 2024 Sourceapache/shardingsphere Anglais original

Cette page est traduite automatiquement. Le texte anglais original fait foi.

sphère de partage 5.5.0

API Changement

  1. Proxy : supprimez la configuration obsolète du nom de schéma du proxy.
  2. Noyau : supprimez la configuration sqlCommentParseEnabled dans la règle SQL Parser pour réduire la complexité du code.
  3. SQL Parser : envisagez de supprimer la configuration sqlCommentParseEnabled dans la règle SQLParser
  4. Fédération : ajoutez la configuration allQueryUseSQLFederation pour la fédération SQL

Correction de bugs

  1. Pipeline : la tâche de migration de validation/annulation n'abandonne pas la tâche de vérification de cohérence associée lorsque la tâche de vérification n'est pas terminée
  2. Pipeline : correction de l'affichage de l'état de vérification de la cohérence stop_time
  3. Proxy : restaurer le nom de la base de données d'origine dans la session de connexion après la monodiffusion
  4. Proxy : le correctif show tables peut être exécuté sans utiliser la base de données
  5. Proxy : corrigez la base de données actuelle incorrecte après le routage unicast
  6. Proxy : corrigez le problème selon lequel les tables d'affichage peuvent être exécutées avant d'utiliser la base de données
  7. Fractionnement en lecture-écriture : correction d'une exception de vérification lors de l'utilisation d'une source de données fantôme
  8. Gouvernance : correction du problème de blocage des threads lors de la création d'une base de données logique pour le centre de registre Etcd
  9. Gouvernance ： Corrigez l'enregistrement des unités de stockage et créez un échec des règles de fonctionnalité lors de l'utilisation du mode autonome
  10. Métadonnées : le schéma du système de base de données n'est pas construit lors de la création de la base de données
  11. Métadonnées : correction du NPE de la règle de création de schéma système
  12. Analyseur SQL : correction de PostgreSQL NPE lors de l'analyse de columnRef
  13. SQL Parser : correction de la cause npe en analysant l'instruction de sélection de fenêtre MySQL
  14. Sharding : Correction d'une erreur de routage lors de la jointure de tables en majuscules
  15. Sharding : correction de l'exception de suppression de la table de partitionnement lorsque le nom de la table est en majuscule
  16. Sharding : correction de la clé générée avec le nom de la colonne en majuscules
  17. Fédération : Correction de l'exception de l'objet 'DUAL' introuvable lors de l'exécution de la sélection 1 de dual avec la fédération SQL
  18. Transaction : correction de la validation automatique xa dansexecuteQuery
  19. Proxy : corrige les instructions multiples avec le nom de base de données spécifié

Amélioration

  1. Pipeline : Améliorer la stabilité et les performances du CDC
  2. Pipeline : MemoryPipelineChannel prend en charge une taille de file d'attente nulle configurable pour réduire la consommation de mémoire.
  3. Pipeline : Afficher une erreur dédiée lorsque le type de mode n'est pas Cluster
  4. Autorité : ajouter l'option isSuper pour l'utilisateur
  5. Pipeline : ignorer le message d'erreur dans l'état du résultat DistSQL lors de l'annulation de la tâche
  6. DistSQL : utilisez le format JSON pour générer des accessoires dans RQL
  7. DistSQL : optimiser la logique de REFRESH DATABASE METADATA
  8. DistSQL : SHOW COMPUTE NODES prend en charge les nœuds JDBC
  9. DistSQL : optimiser la syntaxe de REFRESH DATABASE METADATA
  10. DistSQL : optimiser la sortie de SHOW TABLE METADATA
  11. Proxy : ajoutez la vérification des paramètres précompilés MySQL pour éviter d'activer rewriteBatchedStatements=true lorsque BenchmarkSQL se connecte au proxy, provoquant une exception ArrayIndexOutOfBoundsException lorsque le nombre de paramètres du proxy dépasse 65 535.
  12. SQL Parser : ajoutez EOF pour lever une exception lors de l'analyse de l'instruction de migration de restauration distsql
  13. Analyseur SQL : prend en charge davantage d'analyses d'instructions plsql et ajoute une logique d'assertion d'analyse plsql
  14. SQL Parser : prise en charge de l'indice d'analyse de l'index
  15. Analyseur SQL : prend en charge l'opération de combinaison d'intersection mysql, analyse SQL
  16. SQL Parser : Supoort analyse les espaces blancs chinois pour Oracle
  17. Analyseur SQL : correction de l'analyse de la fonction mysql TimeStampDiff
  18. SQL Parser : correction de l'analyse abrégée non qualifiée de sqlServer
  19. Analyseur SQL : prend en charge l'analyse de mots sans réserve de sqlServer SEARCH
  20. Analyseur SQL : ajouter le mot non réservé MEMBRE du serveur SQL
  21. Binder : ajouter la logique ParameterMarkerSegmentBinder pour Oracle MergeStatementBinder
  22. Fédération : prise en charge de l'instruction de jointure croisée mysql pour la fédération SQL
  23. Transaction : ajouter un message de conseil dans XATransactionCheckPrivilegeFailedException
  24. Sharding : valider les nœuds de données réels du partitionnement en double
  25. Sharding : prise en charge du routage à valeur de condition nulle
  26. Proxy : correction de l'option d'instructions multiples mysql client dans le protocole

Nouvelle fonctionnalité

  1. DistSQL : nouvelle syntaxe pour l'implémentation du plugin de requête (SPI)
  2. DistSQL : Nouvelle syntaxe de gestion de la règle SQL_TRANSLATOR

Refactoriser

  1. JDBC : fusionner shardingsphere-jdbc-core avec le module shardingsphere-jdbc
  2. Proxy : renommez server.yaml en global.yaml, configuration en base de données et restez compatible avec l'ancienne configuration
  3. Proxy : Renommez config-xxx.yaml en database-xxx.yaml
  4. Proxy : optimiser la logique MySQLComStmtPrepareExecutor
  5. Chiffrer : refactoriser l'interface de chiffrement et ajouter des métadonnées de l'algorithme de chiffrement
  6. Infra : Créez un nouveau module d'algorithme dans l'infra et déplacez le flocon de neige, uuid vers ce module
  7. Infra : modifier la méthode unmarshal pour renvoyer un objet par défaut lorsque yaml est vide
  8. Infra : optimiser la logique StandardParameterBuilder
