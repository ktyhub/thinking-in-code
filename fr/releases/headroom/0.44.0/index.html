⚠ CHANGEMENTS DE RUPTURE

  • emballage : gardez les extras PyTorch à l'écart (#4067)

Fonctionnalités

  • pipeline : indique à qui appartient la demande d'un OutcomeSnapshot (#4698) (a2bcbd1)
  • fournisseurs : ajoutent la prise en charge du wrapper d'agent Hermes (#934) (7877241)
  • proxy/model-router : ajouter le mode ombre (HEADROOM_MODEL_ROUTER_LOG_ONLY) (#2395) (861ef95)

  • proxy : expose le coût_usd par requête dans /stats recent_requests (#1079) (#1565) (84cedbf)
  • proxy : expose la disponibilité du magasin Redis partagé dans /health et /metrics (#4578) (602ca65)
  • proxy : donne aux turn hooks un identifiant de conversation par conversation client (#4496) (94a99ed)
  • proxy : signale DeepSeek comme son propre fournisseur dans le tableau de bord (#2565) (9ad16a7)
  • proxy : affiche les métadonnées /stats par requête aux appelants authentifiés par jeton (#4168) (9b2dec5)
  • proxy : routage multi-amont unifié pour Anthropic Cloud et oMLX local (#4597) (f896161)
  • économies : portent les jetons de sortie réels cumulés dans les points de contrôle de l'historique (#2921) (8388ff5)
  • wrap : ajoutez headroom wrap droid pour Factory Droid (#4143) (bb8d18a)
  • wrap : activez l'activation du MCP à mémoire de code Serena (#4509) (2649835)

Corrections de bugs

  • asgi: arrête la mise en mémoire tampon lorsque le client se déconnecte (GHSA-mc2f-vg4v-2fh4) (#4701) (c6d7081)
  • balise : applique la liste blanche sous les clés de niveau supérieur (#4691) (456288d)
  • binaires : échec de fermeture sur HEADROOM_BINARIES_ALLOW_UNVERIFIED=0/false (#3218) (da6d973)
  • cache : enregistre les observations TTL avec des noms de fichiers relatifs (#4711) (51d9dc5)
  • cache : arrondit les limites supérieures du TTL appris jusqu'à des secondes entières (#4710) (13347e3)
  • cache : enregistre l'état du suivi des préfixes lorsque le signal de sortie arrive (#4715) (3ba4223)
  • ccr : minuscule le hachage dans les enregistreurs de feedback en streaming (#2313) (3912c04)
  • ci : garder le jeton de publication npm en dehors des étapes d'installation et de construction (#4690) (8f6366c)
  • cli : résout le port proxy actif pour les commandes de lecture (#3522) (02c4e92)
  • content-router : trust détection HTML fiable sur heuristiques de contenu mixte (#3627) (f50db67)
  • Tableau de bord : métriques de durée de vie et actualisation (#2374) (eb9932a)
  • doctor : reconnaît le bouclage IPv6 et les URL de routage proxy insensibles à la casse (#3255) (2b0315b)
  • installer : décoder la sortie XML du Planificateur de tâches Windows avant l'analyse (#3969) (#4064) (b78e07d)

  • langchain : vérifier la disponibilité de l'intégration facultative (#4042) (cde584d)
  • apprendre : renforcer l'analyse de l'analyseur JSON contre une sortie LLM malformée (#2471) (12864fc)
  • apprendre : prise en charge du schéma de session opencode v2 dans le scanner d'apprentissage (#4199) (c05466a)
  • sans perte : pliez uniquement les listes de chemins purs, jamais de balisage (#4716) (0ccd559)
  • mémoire : se dégrade gracieusement lors des erreurs de recherche de contexte et d'initialisation (#3251) (#4049) (00d4f44)
  • métriques : limitez les lignes saving_by_source et pliez le reste dans d'autres (#4257) (2038fb2)
  • emballage : gardez les extras PyTorch à l'écart (#4067) (a890521)
  • proxy : ajoutez l'indicateur --no-ccr-response-handling pour contourner la mise en mémoire tampon des réponses (#3082) (#3100) (ce14271)
  • proxy : lié à l'étiquette du modèle Bedrock Prometheus (#4694) (d70a8b7)
  • proxy : supprime les en-têtes nommés par Connection lors du transfert des réponses (#4674) (3871b36)
  • proxy : conserve le raisonnement du tour à froid afin que le prochain tour à chaud réutilise le préfixe mis en cache (#4592) (3544cf5)
  • proxy : conserve le fournisseur d'informations d'identification Bedrock en cas d'échec de la résolution de démarrage (#4705) (5438f00)
  • proxy : actualisez les informations d'identification Bedrock AWS avant leur expiration (#4696) (adc6724)
  • proxy : renommez la métrique leaked_threads en timed_out_workers_total (#3908) (bd164a2)
  • proxy : suit les événements d'élément avec préfixe de réponse et de partie de contenu dans l'état SSE des réponses (#4695) (8f4122f)
  • routeur : compresse les blocs tool_result dans une fenêtre mutable avec des messages de fin (#4717) (0511bcd)
  • routeur : ignore les opérateurs shell à l'intérieur des arguments cités dans la détection de lecture (#4646) (8cdce17)
  • scripts : ignorez ci-precheck dans le hook de pré-push lorsqu'un push supprime uniquement les références (#4702) (cbcf8d8)
  • sdk : conserve les types de sortie de résultat de l'outil Vercel AI SDK via la compression (#4670) (ce42754)
  • search_compressor : conserve les lignes conservées octet par octet et dans l'ordre de saisie (#3982) (a538740)
  • smart-crusher : conserve les lignes de dict à tableau mixte et le nombre exact de chutes avec factor_out_constants (#4692) (ced2685)
  • smart-crusher : conserve la ligne avec les noms des questions (#4713) (e6e2ebb)
  • stockage : renvoie le dernier instantané de JSONLStorage.get (#4675) (b25c45b)
  • tabulaire : divise les lignes de largeur fixe sur les limites des colonnes, et non sur des espaces doubles (#4541) (b80245e)
  • tag-protector : ne traite pas une barre oblique dans un attribut non cité comme une fermeture automatique (#4681) (d5644cb)
  • tag-protector : garde la balise englobante ouverte après une fermeture imbriquée en mode marqueur (#4682) (385d487)
  • télémétrie : conserver l'ID d'installation sans état (#3542) (27bba79)
  • tokenizers : résolvent les alias chatgpt-4o-* en o200k_base (#4672) (9648d2d)
  • tokenizers : déballez BatchEncoding dans HuggingFaceTokenizer.count_messages (#2447) (9eed58f)
  • sommet : expliquez les échecs de Vertex dans la bande, corrigez la matrice modèle/région (#2640) (0ddaa56)
  • wrap : acheminez le mode Bedrock de Claude Code via Headroom (#4316) (aa2093b)
