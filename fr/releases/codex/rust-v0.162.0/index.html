codex rust-v0.162.0

Nouvelles fonctionnalités

  • Ajoutez des outils pour créer et répertorier les arbres de travail Git gérés à partir de projets locaux trusted lorsque la fonctionnalité des arbres de travail est activée. (#50148)
  • Épinglez les tâches dans le centre de commande de l'agent avec p et conservez-les dans un groupe épinglé partagé lorsqu'elles sont prises en charge par le serveur. (#51500)
  • Parcourez et copiez les blocs de transcription avec /copy, utilisez Ctrl+Insert pour copier les sélections et réglez le défilement de la molette de la souris avec tui.mouse_scroll_speed. (#50434, #50215, #50209)
  • Rendre les URL clickables dans les en-têtes d'approbation, les questions, les invites MCP, les avertissements, les bannières et les invites de vérification, y compris lorsque les liens traversent des lignes. (#51439, #51449, #51450, #51451, #51452, #51458)
  • Configurez l'accès Web en direct et les capacités de compactage à distance pour les fournisseurs de modèles personnalisés compatibles avec les réponses. (#50459)
  • Ajoutez les assistants JavaScript pour diffuser les résultats des promesses au fur et à mesure qu'ils se règlent, ainsi que la recherche d'outils classés par option en mode Code. (#51126, #51209)
