codex rust-v0.169.0

Nouvelles fonctionnalités

  • L'espace de travail du terminal opt-in prend en charge plusieurs onglets de discussion latéraux. Basculez entre eux avec le clavier ou la souris et rouvrez les discussions secondaires locales enregistrées après le redémarrage du Codex. (#59784, #60152, #60181)
  • Recherchez des tâches plus anciennes à partir du centre de commande de l'agent par nom, aperçu de l'invite ou répertoire de travail. (#60286)
  • Activez Réduire les détails du tour dans la transcription en plein écran pour replier l'activité terminée sous chaque invite tout en gardant les réponses visibles et la sortie de l'outil consultable. (#60554, #60555, #60556, #60557)
  • Ajoutez ou modifiez des fournisseurs de modèles personnalisés depuis le terminal. Lorsque l'intégration de passerelle personnalisée est activée, vous pouvez créer un fournisseur lors de la connexion et utiliser un code d'appareil pour les passerelles prises en charge via SSH ou sans navigateur local. (#59779, #60009, #60186, #60486, #60662)
  • Appuyez sur Ctrl+S dans l'éditeur de rapport du terminal pour enregistrer localement un ZIP de diagnostic, même lorsque les téléchargements sont désactivés. (#60542)
  • Avec la connexion Cloud opt-in sur macOS et Linux, envoyez des images, choisissez un modèle et un effort de raisonnement, et archivez ou restaurez les conversations Cloud depuis le terminal. (#59828, #60061, #60635, #60651)

Corrections de bugs

  • codex exec maintient la configuration du projet et les serveurs MCP désactivés dans les répertoires non rust, même avec --sandbox workspace-write. Utilisez --trust avec codex exec ou codex review pour enregistrer explicitement le projet trust. (#60041)
  • Oui, contexte clair et mise en œuvre transmet désormais le plan entièrement approuvé à la nouvelle session et maintient la session en cours ouverte si le transfert échoue. (#60763)
  • Correction de la gestion du sandbox Windows pour les chemins cmd.exe cités et pour les sessions PowerShell dont le répertoire de travail a un parent illisible. (#60624, #60647)
  • Les images collées sur macOS conservent leur orientation prévue et utilisent les données natives PNG ou JPEG clipboard lorsqu'elles sont disponibles. (#60455)
  • Le terminal ne reste plus occupé à attendre des serveurs MCP qu'un serveur d'application partagé n'a pas signalé. (#60280, #60622)
  • Les tours interrompus se ferment désormais proprement, et les abandons retardés ou les annulations d'approbation de fichiers n'interrompent plus un tour ultérieur. (#59910, #60700) ##Documents
  • Mise à jour de la compétence openai-docs pour se concentrer sur les questions de travail Codex et ChatGPT et sur la première configuration de API, avec des conseils dédiés à la configuration du Codex au sein d'une équipe. (#59944, #59949)
  • Documenté sur la manière dont le serveur d'applications clients peut répertorier les modèles ou autoriser une passerelle pour un fournisseur configuré sans modifier le fournisseur par défaut. (#59776, #59819)
