envoyé v1.39.4

Résumé des modifications :

  • Corrections de bugs :
  • aws : correction d'une course où la configuration au niveau de la route de l'AWS la signature des demandes et les filtres AWS Lambda pourraient être détruits sur un travailleur thread lorsqu'une mise à jour RDS a remplacé la configuration de la route.
  • composite : correction d'une course où la configuration au niveau de l'itinéraire du le filtre composite pourrait être détruit sur un thread de travail lorsqu'un RDS la mise à jour a remplacé la configuration de l'itinéraire.
  • Dynamic_modules : correction d'un bug où le crochet de destruction de la configuration par route pourrait s'exécuter sur un thread de travail et le module pourrait y être déchargé, lorsqu'une mise à jour RDS a remplacé la configuration de l'itinéraire.
  • filter_chain : correction d'une course où la configuration au niveau de la route du le filtre de chaîne de filtres pourrait être détruit sur un thread de travail lorsqu'un RDS la mise à jour a remplacé la configuration de l'itinéraire.
  • local_ratelimit : correction d'une course dont le gestionnaire du fournisseur de partage était propriétaire par une limite de débit locale, la configuration au niveau de l'itinéraire pourrait être détruite sur un fil de travail.
  • sds : correction d'une course où un fournisseur de secrets génériques partageait avec un travailleur les threads pourraient être détruits sur un thread de travail.
  • stats : correction d'un bug introduit dans 1.38.0 qui exportait Prometheus Le compartiment d'histogramme natif indexe un compartiment trop bas, ce qui amène les consommateurs à décoder les observations dans des plages de valeurs inférieures et sous-estimer les quantiles.
