nanobot v0.1.4.post3

🐈 Le nanobot v0.1.4.post3 vient de sortir — 33 PR fusionnés, 16 nouveaux contributeurs ! Vous êtes imparables les gars 🔥 Cette version vise à rendre l'agent plus intelligent en voyant moins de fichiers inutiles : un contexte plus propre, un historique de session renforcé et moins de messages fantômes. Moins de bruit à l’entrée → moins d’hallucinations à la sortie. Plus un tout nouveau canal Matrix et un mode de pensée expérimental.

Faits saillants

  • Agent Loop Hardening — Les messages vides de l'assistant (pas de contenu, pas d'appels d'outil) sont désormais filtrés au lieu du contexte d'empoisonnement ; Les réponses aux erreurs LLM ne sont plus enregistrées dans l'historique, évitant ainsi les boucles permanentes de 400 erreurs ; suppression de l'outil de message limitée au même canal uniquement (#1314, #1198, #1206)
  • Context Noise Reduction — Métadonnées d'exécution (heure, canal, ID de chat) séparées dans une couche non rust et exclues de l'historique de session, afin que l'agent ne voie que ce qui compte : moins de jetons, moins de confusion, moins d'hallucinations (#1126, #1222)
  • Sécurité des sessions — Images Base64 supprimées de l'historique pour éviter tout débordement de contexte ; les réponses nulles ne corrompent plus les tours futurs (#1191, #1314)
  • Matrix Channel — Prise en charge du canal de discussion Full Matrix (Element) avec E2EE, téléchargements de médias et indicateurs de saisie (#420, #1239)
  • Compatibilité des fournisseurs — tool_call_id alphanumérique court pour Mistral ; les arguments de l'outil de type liste sont gérés avec élégance ; sélection explicite du fournisseur dans la configuration (#1293, #1294, #1214, #1316)
  • Mode de réflexion (expérimental) — La nouvelle configuration reasoning_effort permet le raisonnement LLM pour les modèles pris en charge ; l'historique de session préserve reasoning_content et thinking_blocks à travers les tours (#1351, #1330, #1074)
  • Améliorations des sous-agents — /stop annule les sous-agents générés ; l'invite simplifiée élimine le code mort et réutilise ContextBuilder (#1180, #1347)
  • Feishu — Correction de l'extraction de texte de carte interactive, emoji de réaction configurable, autorisations de robot corrigées (#1323, #1257, #1317, #1348)
  • DingTalk — Images et médias envoyés sous forme de types de messages appropriés au lieu de liens en texte brut (#1337)
  • Telegram — Groupes de médias regroupés en un seul message entrant (#1258)
  • QQ — Correction des autorisations de réponse C2C, journal de fichiers désactivé sur les systèmes de fichiers en lecture seule (#1307, #1346)
  • WhatsApp — La déduplication des messages empêche le traitement redondant des agents (#1325)
  • Shell et sécurité — Analyse complète du chemin Windows dans Workspace Guard ; path_append configurable pour le sous-processus PATH (#1286, #1083)
  • Mémoire et concurrence — WeakValueDictionary pour les verrous de consolidation élimine les conditions de concurrence critique et le nettoyage manuel (#1326)
  • Workspace — La synchronisation automatique des modèles restaure les fichiers critiques au démarrage (#1253)
