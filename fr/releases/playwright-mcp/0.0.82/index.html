playwright-mcp v0.0.82

dramaturge-mcp v0.0.82

✨ Points forts

  • 🎬 Vidéos fluides à 60 ips, stylables — browser_start_video (opt-in via --caps=devtools) prend fps, donc fps: 60 enregistre des vidéos fluides à 60 ips au lieu des 25 par défaut, et cursor: true affiche un curseur de souris animé qui se déplace vers chaque point d'action et reste visible entre les actions. browser_video_show_actions prend un style avec les déclarations CSS point, highlight et title ; le marqueur de point d'action et la surbrillance de la cible ne sont désormais affichés que lorsqu'ils sont stylisés. (microsoft/playwright#42752, microsoft/playwright#42758)
  • 🧰 Les outils WebMCP deviennent de véritables outils MCP — les outils qu'une page enregistre via le WebMCP API apparaissent désormais directement dans la liste d'outils sous le nom de webmcp_<tool>, avec le propre schéma d'entrée et les annotations de la page, afin qu'un agent puisse les appeler directement et laisser la page faire le travail au lieu de piloter son interface utilisateur. La liste suit l'onglet actuel et les clients reçoivent une notification tools/list_changed lorsqu'elle change. Cela remplace browser_webmcp_list / browser_webmcp_call de v0.0.81, qui ne sont plus exposés sur MCP. Les noms d'outils, les descriptions, les schémas et les résultats proviennent de la page, alors traitez-les comme une entrée non rust. Passez --no-webmcp (config webmcp: false, env PLAYWRIGHT_MCP_WEBMCP=false) pour vous désinscrire. WebMCP est expérimental, voir WebMCP dans Chrome pour savoir comment l'activer. (microsoft/dramaturge#42671)
  • 🌗 Basculer entre les couleurs claires et foncées (microsoft/playwright#42243) — un agent travaillant sur un thème sombre n'avait aucun moyen de le voir en cours de session. Le nouvel outil browser_emulate_media émule les fonctionnalités média à la volée : colorScheme, reducedMotion, forcedColors, contrast et le type media (sérigraphie/impression). Les paramètres omis restent inchangés, null efface un remplacement. (microsoft/dramaturge#42668)
  • 📁 Chemins absolus dans les résultats (microsoft/playwright#42497) — les liens vers les instantanés, les captures d'écran, les journaux de la console et les téléchargements sont relatifs à la racine de l'espace de travail, qu'un client sans celui-ci ne peut pas résoudre. Passez --file-paths=absolute (config filePaths: "absolute", env PLAYWRIGHT_MCP_FILE_PATHS=absolute) pour obtenir les chemins absolus à la place. (microsoft/dramaturge#42673)

🐛 Correctifs

  • fix(mcp): keep upload modal and reject bad headers — un browser_file_upload défaillant (par exemple un fichier manquant) signale l'erreur et maintient le sélecteur de fichier ouvert afin qu'il puisse être réessayé, et browser_route (opt-in via --caps=network) renvoie une erreur pour un en-tête qui n'est pas dans le formulaire Name: Value au lieu de définir un en-tête nommé "". (microsoft/dramaturge#42713)
  • fix(chromium): bypass service workers on the storage state page — browser_storage_state (opt-in via --caps=storage) n'exécute plus les propres scripts du site, ou échoue lorsqu'ils redirigent, pour les origines avec un service worker actif (microsoft/playwright#42656). (microsoft/playwright#42664, microsoft/playwright#42741)

📦 Mise à niveau

Les configurations qui utilisent @playwright/mcp@latest récupèrent cette version au prochain redémarrage de client. Pour l'épingler :

npx @playwright/mcp@0.0.82
