playwright-mcp v0.0.85

dramaturge-mcp v0.0.85

✨ Points forts

  • 🌙 Gardez le navigateur en arrière-plan (microsoft/playwright#42973) — la connexion via l'extension a activé l'onglet et focalisé la fenêtre du navigateur, prenant l'écran de l'application dans laquelle vous travailliez. Passez --background à côté de --extension (config background: true, env PLAYWRIGHT_MCP_BACKGROUND=1) pour laisser l'onglet connecté inactif et sa fenêtre floue, et pour ouvrir le client. nouveaux onglets en arrière-plan. Avec PLAYWRIGHT_MCP_EXTENSION_TOKEN défini, la page de connexion s'ouvre également en arrière-plan (Chrome 158.0.8127.2 ou version ultérieure, avec le navigateur déjà en cours d'exécution). Nécessite l'extension 0.5.0 ou version ultérieure. Chrome limite les minuteries et les images d'animation dans les onglets d'arrière-plan. (microsoft/dramaturge#43864)
  • 🗂️ Laissez les onglets en dehors du groupe d'onglets Playwright (microsoft/playwright#43038) — l'extension déplaçait toujours les onglets contrôlés par un client dans son propre groupe d'onglets. Passez --no-tab-group à côté de --extension (config tabGroup: false, env PLAYWRIGHT_MCP_NO_TAB_GROUP=1) pour conserver l'onglet sélectionné et les onglets ouverts par le client dans leurs groupes existants, le cas échéant. L'approbation de la connexion est inchangée, chaque onglet contrôlé appartient toujours à un client et la page d'état de l'extension répertorie les onglets contrôlés. Nécessite l'extension 0.5.0 ou version ultérieure. (microsoft/dramaturge#43814)
  • 👁️ Faire correspondre uniquement les éléments visibles (microsoft/playwright#43855) — un localisateur pourrait se résoudre en un élément masqué, ou échouer car un doublon caché correspondait également. Définissez browser.contextOptions.locateOnlyVisible: true dans le fichier de configuration pour restreindre les localisateurs aux éléments visibles, à la fois dans le target des outils d'éléments tels que browser_click et dans browser_run_code_unsafe, comme si .filter({ visible: true }) terminait chacun d'eux. Un localisateur qui se termine par son propre filtre de visibilité le conserve. Désactivé par défaut. (microsoft/dramaturge#43903)
  • 🏷️ Conserver les noms des conteneurs dans les instantanés (microsoft/playwright#43809) — les boîtes de dialogue, les points de repère et les tableaux pouvaient apparaître sans nom même lorsque leur en-tête ou leur légende était visible. browser_snapshot conserve désormais les noms d'identification sur les conteneurs et les en-têtes de table lorsque le texte fournissant le nom apparaît également parmi leurs enfants. (microsoft/dramaturge#43810)
  • 🎯 Rechercher des contrôles de formulaire personnalisés par étiquette (microsoft/playwright#43898) — les associations natives <label> ont été ignorées pour les éléments personnalisés associés au formulaire. Les outils d'éléments reconnaissent désormais ces contrôles via des cibles telles que getByLabel('City'), et les noms accessibles utilisent également les étiquettes associées. Les attributs for et les étiquettes imbriquées sont pris en charge. (microsoft/dramaturge#43900)

🐛 Correctifs

  • fix(aria): restore snapshot visibility rules for inert and modal content — le filtrage annoncé dans v0.0.84 est inversé : browser_snapshot ne masque plus le contenu uniquement parce qu'il est inerte ou en dehors d'une boîte de dialogue modale. Click, les actions de remplissage et de sélection attendent toujours que les cibles explicitement inertes deviennent non inertes (microsoft/playwright#43792). (microsoft/playwright#43850, microsoft/playwright#43851)
  • fix(mcp): preserve non-JSON evaluation results — browser_evaluate renvoie des représentations lisibles de valeurs telles que BigInt, NaN, Infinity, undefined et des objets circulaires au lieu de perdre des valeurs ou d'échouer la sérialisation JSON. Les résultats compatibles JSON conservent leur format existant (#1838). (microsoft/dramaturge#43973)
  • fix(mcp): resolve config file paths relative to their source — chemins de profil, exécutable, état de stockage, sortie et autres fichiers dans une configuration résolus par rapport au répertoire de ce fichier ou au répertoire de sa cible pour un lien symbolique. CLI et les chemins d'environnement restent relatifs au répertoire de travail. Les connexions d'extension respectent également la configuration fusionnée du chemin d'exécution (#1836). (microsoft/dramaturge#43970)
  • fix(extension): report lost tab instead of crashing — les réponses de l'outil signalent lorsqu'une page se ferme avant que son instantané puisse être capturé. Les connexions d'extension expliquent également que Chrome a peut-être détaché le débogueur en raison d'une image non prise en charge, plutôt que de faire planter le rendu des réponses (microsoft/playwright#43230). (microsoft/dramaturge#43863)
  • fix(mcp): bound settle waits when page timers cannot run — les appels d'outils ne se bloquent plus pendant leur délai de stabilisation lorsque les minuteurs de page sont limités, mis en pause ou incapables de s'exécuter (microsoft/playwright#43752). (microsoft/dramaturge#43767)
  • fix(mcp): report event listener exceptions as console errors — les exceptions des écouteurs de page et de contexte installés via browser_run_code_unsafe apparaissent dans les réponses de l'outil et browser_console_messages au lieu de escaping en tant qu'erreurs non gérées (microsoft/playwright#43770). (microsoft/dramaturge#43686)
  • fix(mcp): validate device names and preserve device descriptors — les valeurs --device inconnues produisent une erreur explicite et les remplacements par client ne modifient plus les préréglages de périphérique partagés (#1834). (microsoft/playwright#43971)
  • fix(mcp): report one-based console source lines — les emplacements sources dans browser_console_messages et les entrées de console dans les réponses de l'outil utilisent désormais des numéros de ligne de style éditeur commençant à 1 (#1839). (microsoft/dramaturge#43975)
  • fix(mcp): clarify screenshot actions with vision tools — la description du browser_take_screenshot n'exclut plus d'agir sur une capture d'écran. browser_snapshot reste la valeur par défaut pour les actions ; avec --caps=vision, la description pointe vers les outils de souris basés sur les coordonnées pour les éléments que l'instantané n'expose pas, tels que le contenu du canevas (#1816). (microsoft/playwright#43857)
  • fix(aria): match mixed-case selected options in accessible names — les instantanés et les localisateurs de rôle incluent le texte de l'option sélectionnée lorsqu'une zone de liste personnalisée utilise une valeur à casse mixte telle que aria-selected="TRUE" (microsoft/playwright#43785). (microsoft/playwright#43787)
  • fix(chromium): preserve fonts when connecting with noDefaults — les connexions d'extension n'écrasent plus les paramètres de police du navigateur existant, évitant ainsi les modifications inattendues du rendu des pages (microsoft/playwright#43715). (microsoft/dramaturge#43773)
  • fix(chromium): honor Linux config directories for channel connections — la recherche de profil d'extension respecte CHROME_USER_DATA_DIR, CHROME_CONFIG_HOME et XDG_CONFIG_HOME. Les connexions --cdp-endpoint basées sur les canaux utilisent également le chemin WebSocket annoncé dans DevToolsActivePort (microsoft/playwright#43880). (microsoft/dramaturge#43884)
  • fix(chromium): preserve HTTP navigations across HTTPS upgrade modes — dans les navigateurs lancés par le serveur, browser_navigate conserve les URL HTTP sur HTTP au lieu que Chrome les mette automatiquement à niveau vers HTTPS (microsoft/playwright#43871). (microsoft/playwright#43877)
  • fix(chromium): account for tabs and toolbar in the new headless mode — avec --headless, Chrome et Edge dimensionnent désormais leur fenêtre pour l'adapter à la fenêtre d'affichage située sous la bande d'onglets et la barre d'outils, de sorte que les vidéos de browser_start_video (opt-in via --caps=devtools) ne perdent plus le bas de la page. (microsoft/dramaturge#43904)
  • fix(screenshot): support full-page SVG documents — browser_take_screenshot avec fullPage: true fonctionne sur des documents SVG autonomes au lieu d'attendre un corps HTML inexistant (microsoft/playwright#43962). (microsoft/playwright#43972)
