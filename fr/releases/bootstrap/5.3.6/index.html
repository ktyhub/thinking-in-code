#amorçage v5.3.6

Faits saillants

  • Nous avons porté les documents de Hugo vers Astro pour notre propre santé mentale !
  • Ajout de documents d'utilisation pour Accordion JavaScript
  • Empêcher les enfants débordants de .visually-hidden de devenir focalisables
  • Limiter les sélecteurs .card-group aux enfants immédiats pour résoudre certains problèmes d'héritage
