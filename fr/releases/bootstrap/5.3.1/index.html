#amorçage v5.3.1

Faits saillants

  • Modes couleur :
    • Augmentation du contraste des couleurs pour le mode sombre en remplaçant $gray-500 par $gray-300 pour la couleur du corps
    • Ajout de notre sélecteur de mode couleur JavaScript à nos exemples de téléchargement ZIP
  • Composants :
    • Style désactivé amélioré pour tous les .nav-link, fournissant .disabled et :disabled à utiliser avec des ancres et des boutons
    • Ajout de la prise en charge des touches Home et End pour naviguer dans les onglets au clavier
    • Ajout d'un style de base pour basculer les boutons lorsqu'aucune classe de modificateur n'est présente
    • Correction des couleurs du carrousel en mode sombre
  • Formulaires :
    • Correction de la couleur du texte désactivée pour l'étiquette flottante
  • Utilitaires :
    • Les utilitaires .text-bg-* utilisent désormais des variables CSS
  • Sass :
    • Ajouter une nouvelle variable $navbar-dark-icon-color Sass
    • Suppression des variables Sass $alert en double
    • Ajout d'une nouvelle variable pour $vr-border-width afin de personnaliser la largeur de l'assistant de règle verticale
  • Documentation :
    • Ajout de la recherche à notre page d'accueil
    • Amélioration du comportement réactif sur l'exemple de tableau de bord
    • Rendu en mode sombre amélioré des exemples de Cheatsheet
