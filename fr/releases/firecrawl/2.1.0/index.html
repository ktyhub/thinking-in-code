firecrawl v2.1.0

Mineure Publié29 août 2025 Sourcefirecrawl/firecrawl Anglais original

Cette page est traduite automatiquement. Le texte anglais original fait foi.

feu d'artifice v2.1.0

Firecrawl v2.1.0 est là !

✨ Nouvelles fonctionnalités

  • Catégories de recherche : filtrez les résultats de recherche par catégories spécifiques à l'aide du paramètre categories :
    • github : recherche dans les référentiels GitHub, le code, les problèmes et la documentation
    • research : Recherche sur sites académiques et de recherche (arXiv, Nature, IEEE, PubMed, etc.)
    • Plus à venir bientôt
  • Extraction d'images : Ajout de la prise en charge de l'extraction d'images au point de terminaison de scrape v2.
  • Attribut de données Scraping : Prend désormais en charge l'extraction des attributs data-*.
  • Routage basé sur le hachage : Les points de terminaison d'analyse gèrent désormais les itinéraires basés sur le hachage.
  • Amélioration de Google Drive Scraping : Ajout de la possibilité de récupérer des fichiers TXT, PDF et Sheets à partir de Google Drive.
  • Améliorations PDF : Extrait les titres PDF et les affiche dans les métadonnées.
  • Améliorations du API :
    • Le point de terminaison de la carte prend en charge jusqu'à 100 000 résultats.
  • Graphique Helm : Graphique Helm initial ajouté pour le déploiement de Firecrawl.
  • Sécurité : Protection améliorée contre l'usurpation d'identité XFF.

🛠 Correctifs

  • Correction de l'encodage UTF-8 dans le grattoir de recherche Google.
  • Statut d'exploration restauré en mode aperçu.
  • Correction des méthodes manquantes dans Python SDK.
  • Correction de la gestion des réponses JSON pour la recherche v2 avec scrapeOptions.formats.
  • Correction de la population de champs pour credits_billed dans le scrape v0.
  • Amélioration de la superposition des champs de document dans la recherche v2.
