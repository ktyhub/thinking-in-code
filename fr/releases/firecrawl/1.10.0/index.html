firecrawl v1.10.0

Mineure Publié3 juin 2025 Sourcefirecrawl/firecrawl Anglais original

Cette page est traduite automatiquement. Le texte anglais original fait foi.

feu d'artifice v1.10.0

Nous sommes ravis d'annoncer le lancement de notre nouveau point de terminaison Search API qui combine la recherche Web avec les puissantes fonctionnalités scraping de Firecrawl.

Fonctionnalités de recherche :

  • Recherchez sur le Web et obtenez le contenu complet des résultats en un seul appel API
  • Choisissez des formats de sortie spécifiques (markdown, HTML, liens, captures d'écran)
  • Personnaliser les paramètres de recherche (langue, pays, plage horaire, nombre de résultats)
  • Prise en charge complète de SDK pour Python et Node.js

Plus de fonctionnalités

  • Proxy en mode automatique pour scraping (scrapeURL, js-sdk) #1551, #1602
  • Améliorations de la gestion des délais d'attente et du type de contenu pour scrapeURL/pdf #1570, #1604, #1592
  • Améliorations du Redis : prise en charge séparée du Redis sans expulsion #1600
  • Améliorations de la recherche : ignoreBlockedURLs, ignorer la limite de concurrence #1580, #1617
  • Nouveau point de terminaison /cclog pour la journalisation simultanée #1589
  • L'extraction de métadonnées inclut désormais les attributs itemprop #1624
  • Auto-hébergé : image Playwright déployable #1625

Corrections et améliorations

  • Meilleure gestion des sous-domaines pour LLMs.txt + option de contournement #1557
  • Amélioration de la validation des URL et de la gestion des caractères spéciaux #1547
  • Nettoyage des travailleurs zombies + gestion TTL pour l'état de l'extrait #1575, #1599
  • Correction de la logique de file d'attente simultanée et du remplacement du limiteur de débit #1595, #1593
  • Meilleure journalisation pour la pagination de recherche et la récupération robuste #1572, #1588
  • Corrections mineures : og:locale:alternate, bascule adblock, logique Playwright uniquement, tableaux de métadonnées mal formés #1597, #1616, #1574

Tests et documents

  • Ajouter la documentation sur les variables d'environnement MAX_RAM et MAX_CPU #1581
  • Améliorations de l'infrastructure de test #1623
