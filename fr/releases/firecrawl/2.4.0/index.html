Firecrawl v2.4.0

##v2.4.0

Nouvelles fonctionnalités

  • Nouvelle catégorie de recherche PDF - Vous pouvez désormais rechercher uniquement des fichiers PDF via nos points de terminaison v2/search en spécifiant la catégorie .pdf
  • Gemini 2.5 Flash CLI Image Editor — Créez et modifiez des images directement dans le CLI à l'aide de Firecrawl + intégration Gemini 2.5 Flash (#2172)
  • x402 Search Endpoint (/v2/x402) — Ajout d'une recherche de nouvelle génération API avec une précision et une vitesse améliorées (#2218)
  • RabbitMQ Event System — Les tâches Firecrawl prennent désormais en charge la communication basée sur les événements et la prélecture à partir de Postgres (#2230, #2233).
  • Statut d'exploration amélioré API — Rapports d'état d'exploration plus précis et en temps réel à l'aide du nouveau RPC crawl_status_2 (#2239)
  • Avertissements relatifs aux résultats faibles et au fichier Robots.txt — Les utilisateurs reçoivent désormais des commentaires clairs lorsque les analyses sont limitées par le fichier robots.txt ou donnent peu de résultats (#2248).
  • Enhanced Tracing (OpenTelemetry) — Traçage distribué grandement amélioré pour une meilleure observabilité entre les services (#2219)
  • Metrics & Analytics — Ajout de métriques au niveau de la requête pour les points de terminaison Scrape et Search (#2216)
  • Prise en charge des webhooks auto-hébergés — Les webhooks peuvent désormais être diffusés vers des adresses IP privées pour les environnements auto-hébergés (#2232)

Améliorations

  • Taille d'image Docker réduite — Taille de l'image du service Playwright réduite de 1 Go en installant uniquement Chromium (#2210)
  • Améliorations de Python SDK — Ajout de correctifs pour la gestion de l'état des tâches "cancelled" et les intervalles d'interrogation (#2240, #2265)
  • Délai d'expiration plus rapide du nœud SDK — Les délais d'attente Axios se propagent désormais correctement, améliorant ainsi la fiabilité sous de lourdes charges (#2235).
  • Aperçus améliorés des paramètres d'analyse – Invites et validation améliorées pour les aperçus des paramètres d'analyse (#2220)
  • Zod Schema Validation — Validation plus stricte des paramètres API avec rejet des champs supplémentaires (#2058)
  • Meilleure gestion des tâches du Redis — Cas de bord fixes dans getDoneJobsOrderedUntil pour une récupération plus stable du Redis (#2258)
  • Corrections Markdown et YouTube — Correction des bugs du cache YouTube et du résumé des démarques vides (#2226, #2261)
  • Documents et métadonnées mis à jour — Mises à jour README et nouveaux champs de métadonnées ajoutés au JS SDK (#2250, #2254)
  • Configuration améliorée du port API — Le API respecte désormais les ports définis par l'environnement (#2209)

Correctifs

  • Correction des cas extrêmes de validation de schéma récursive $ref (#2238)
  • Correction des tableaux d'énumérations incorrectement convertis en objets (#2224)
  • Correction des délais d'attente du faisceau et des problèmes de docker-compose.yaml auto-hébergé (#2242, #2252).
