Firecrawl v2.0.0

Présentation du v2.0.0

Améliorations clés

  • Plus rapide par défaut : les requêtes sont mises en cache avec maxAge par défaut sur 2 jours, et les valeurs par défaut sensibles telles que blockAds, skipTlsVerification et removeBase64Images sont activées.

  • Nouveau format de résumé : Vous pouvez désormais spécifier "summary" comme format pour recevoir directement un résumé concis du contenu de la page.

  • Extraction JSON mise à jour : L'extraction JSON et le suivi des modifications utilisent désormais un format d'objet : { type: "json", prompt, schema }. L'ancien format "extract" a été renommé "json".

  • Options de capture d'écran améliorées : utilisez le formulaire d'objet : { type: "screenshot", fullPage, quality, viewport }.

  • Nouvelles sources de recherche : recherchez dans "news" et "images" en plus des résultats Web en définissant le paramètre sources.

  • Exploration intelligente avec invites : passez un prompt en langage naturel à explorer et le système dérive automatiquement les chemins/limites. Utilisez le nouveau point de terminaison crawl-params-preview pour inspecter les options dérivées avant de démarrer une tâche.

Liste de contrôle de migration rapide

  • Remplacez l'utilisation de la v1 client par la v2 clients : *JS : const firecrawl = new Firecrawl({ apiKey: 'fc-YOUR-API-KEY' }) *Python : firecrawl = Firecrawl(api_key='fc-YOUR-API-KEY')
    • API : utilisez les nouveaux points de terminaison https://api.firecrawl.dev/v2/.
  • Formats de mise à jour :
    • Utilisez "summary" si nécessaire
    • Mode JSON : utilisez { type: "json", prompt, schema } pour l'extraction JSON
    • Capture d'écran et capture d'écran@fullPage : utilisez le format d'objet de capture d'écran lors de la spécification des options
  • Adoptez des flux asynchrones standardisés dans les SDK :
    • Crawls : startCrawl + getCrawlStatus (ou serveur crawl)
    • Lot : startBatchScrape + getBatchScrapeStatus (ou serveur batchScrape)
    • Extrait : startExtract + getExtractStatus (ou serveur extract)
  • Cartographie des options d'exploration (voir ci-dessous)
  • Vérifiez l'exploration prompt avec crawl-params-preview

Formats et options de scraping

  • Utilisez les formats de chaîne pour les bases : "markdown", "html", "rawHtml", "links", "summary".
  • Au lieu de parsePDF, utilisez parsers: [ { "type": "pdf" } | "pdf" ]. * Utilisez les formats d'objet pour le JSON, le suivi des modifications et les captures d'écran :

###Format JSON

 curl -X POST https://api.firecrawl.dev/v2/scrape \
     -H 'Content-Type: application/json' \
     -H 'Authorization: Bearer YOUR_API_KEY' \
     -d '{
       "url": "https://docs.firecrawl.dev/",
       "formats": [{
         "type": "json",
         "prompt": "Extract the company mission from the page."
       }]
     }'

Format de capture d'écran

  curl -X POST https://api.firecrawl.dev/v2/scrape \
      -H 'Content-Type: application/json' \
      -H 'Authorization: Bearer YOUR_API_KEY' \
      -d '{
        "url": "https://docs.firecrawl.dev/",
        "formats": [{
          "type": "screenshot",
          "fullPage": true,
          "quality": 80,
          "viewport": { "width": 1280, "height": 800 }
        }]
      }'

Mappage des options d'exploration (v1 → v2)

| v1 | v2 | | ----------------------- | ---------------------------------------------------- | | allowBackwardCrawling | (supprimé) utilisez crawlEntireDomain | | maxDepth | (supprimé) utilisez maxDiscoveryDepth | | ignoreSitemap (booléen) | sitemap (par exemple, "only", "skip" ou "include") | | (aucun) | prompt |
