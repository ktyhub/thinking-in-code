dubbo-spi-extensions v3.2.0

Ce qui a changé

Référence

  • Compatible avec Apache Dubbo 3.2.x

Amélioration

  • [dubbo-cluster-specify-address-dubbo2] Prise en charge de l'accès IP dynamique pour les clusters non locaux dans dubbo-cluster-specify-address-dubbo2 par @wxbty dans https://github.com/apache/dubbo-spi-extensions/pull/179
  • [extension Polaris] Ajoutez les extensions Polaris pour permettre à Dubbo2.7.x d'accéder à Polaris par @andrewshan dans https://github.com/apache/dubbo-spi-extensions/pull/184
  • [dubbo-filter-polaris-dubbo2] séparez les filtres de disjoncteur et de limite de débit, pour le rendre plus décomposable aux développeurs par @andrewshan dans https://github.com/apache/dubbo-spi-extensions/pull/187
  • [dubbo-gateway-extensions] ajoute l'extension du mode Gateway par @wxbty dans https://github.com/apache/dubbo-spi-extensions/pull/205
  • [polaris] prend en charge la capacité du disjoncteur Polaris par @chuntaojun dans https://github.com/apache/dubbo-spi-extensions/pull/212
  • [Cross thread] tag corss thread par annotation dans dubbo-cross-thread-extensions par @carlvine500 dans https://github.com/apache/dubbo-spi-extensions/pull/215
  • [tag subnets] ajouter une balise par sous-réseaux pour le quasi-rpc par @carlvine500 dans https://github.com/apache/dubbo-spi-extensions/pull/216
  • [Sérialisation] ajoute le cadre de sérialisation Fury à Dubbo par @chaokunyang dans https://github.com/apache/dubbo-spi-extensions/pull/226
  • [dubbo-serialization-jackson] Ajout de l'extension de sérialisation Jackson par @aofall dans https://github.com/apache/dubbo-spi-extensions/pull/231
  • [dubbo-xds] Importez l'implémentation de Kubernetes et xDS depuis Dubbo 3.2 par @AlbumenJ dans https://github.com/apache/dubbo-spi-extensions/pull/251

Correction de bugs

  • Correction de la description de l'erreur de rétablissement par @wxbty dans https://github.com/apache/dubbo-spi-extensions/pull/209
  • Correction du déplacement du fichier de recours vers le chemin actuel dans dubbo-serialization-jackson par @aofall dans https://github.com/apache/dubbo-spi-extensions/pull/233
  • Correction du problème de sérialisation de ServiceConfigURL dubbo 3.0 : les paramètres publics tels que l'application, la version ne sont pas transférés et ServiceConfigURLDelegate pour protostuff par @zrlw dans https://github.com/apache/dubbo-spi-extensions/pull/67
  • Correctif (#207) : le registre Dubbo Redis prend en charge certaines bases de données par @aofall dans https://github.com/apache/dubbo-spi-extensions/pull/247
  • Correction[#267] du type protobuf perdant le champ lors de la copie profonde dans JvmInvoker… par @vio-lin dans https://github.com/apache/dubbo-spi-extensions/pull/268

Doc

  • Appeler explicitement hessian-rpc n'est pas stable par défaut par @raboof dans https://github.com/apache/dubbo-spi-extensions/pull/196
  • Document sur l'arbre de code de génération automatique par @songxiaosheng dans https://github.com/apache/dubbo-spi-extensions/pull/224 * : mémo : Mise à jour du fichier Readme par @songxiaosheng dans https://github.com/apache/dubbo-spi-extensions/pull/235
