spring-integration v7.2.0-M1

Pre-release Publicado20 ago 2026 Fuentespring-projects/spring-integration original en inglés

integración de resorte v7.2.0-M1

:star: Nuevas funciones

  • JdbcMetadataStore.putIfAbsent() devuelve null para una fila existente con un METADATA_VALUE nulo #11248
  • Se corrigieron las obsolescencias relacionadas con RestTemplate en el módulo HTTP #11234
  • Opciones para usar confirmaciones simples del editor en puntos finales de salida AMQP #11194
  • Preservar los encabezados originales en DefaultErrorMessageStrategy #11160

:lady_beetle: Corrección de errores

  • CVE-2026-47856: JsonToObjectTransformer resuelve el encabezado del mensaje json__TypeId__ en una clase arbitraria sin una lista de permitidos #11350
  • CVE-2026-47859: Asignación de memoria ilimitada en RFC6587SyslogDeserializer (encuadre contado de octetos): DoS remoto #11349
  • CVE-2026-47862: ZipTransformer usa el encabezado file_name para crear la ruta del directorio de trabajo sin desinfección #11348
  • CVE-2026-47864: Deserialización de Java no segura en SerializingHttpMessageConverter: ejecución remota de código #11347
  • CVE-2026-59324: Se corrigió la fuga del encabezado de mensajes cruzados en fluxTransform() bajo concurrencia #11346
  • CVE-2026-59321: Corrección de AbstractScriptExecutor para motores que no son seguros para subprocesos #11345
  • CVE-2026-59322: Cambiar el valor predeterminado de EmbeddedHeadersJsonMessageMapper a sin encabezados #11344
  • CVE-2026-59311: Impide que los transformadores zip escriban archivos temporales en enlaces simbólicos #11343
  • CVE-2026-59292: Agregar control de permisos de archivos de almacén de metadatos #11342
  • CVE-2026-59307: JdbcMessageStore: nuevo mapper en setBeanClassLoader #11341
  • CVE-2026-59293: Establezca la versión predeterminada de SMB en SMB202 #11339
  • CVE-2026-59274: Agregar opciones de restricción de tamaño a UnzipTransformer #11336
  • CVE-2026-47880: omitir propiedades de forma predeterminada en toHeaders #11331
  • CVE-2026-47861: el adaptador UDP envía una confirmación al host proporcionado por el atacante: puerto analizado desde el cuerpo del paquete, incluso cuando reconoce = falso [#11328] (https://github.com/spring-projects/spring-integration/issues/11328)
  • FileWritingMessageHandler: la creación automática simultánea del mismo directorio de destino falla con "No se pudo crear el directorio de destino". #11253
  • Se corrigió el aislamiento de prueba de ZookeeperLockRegistry y el manejo de interrupciones #11244
  • JdbcMetadataStore putIfAbsent puede bloquearse en el bucle while de la base de datos MySQL. #10847
