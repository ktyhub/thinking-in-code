gpt4free v8.8.11

Changelog completo: https://github.com/xtekky/gpt4free/compare/v8.8.10...v8.8.11

Opciones de descarga

Paquete Python: -PyPI: pip install g4f==v8.8.11

Ejecutables (g4f-go, autónomos con Python integrado): -Windows amd64: g4f-go-v8.8.11-windows-amd64.zip -Linux x64: g4f-go-v8.8.11-linux-amd64.zip -Linux ARM64: g4f-go-v8.8.11-linux-arm64.zip

  • macOS x64: g4f-go-v8.8.11-darwin-amd64.zip
  • macOS ARM64: g4f-go-v8.8.11-darwin-arm64.zip -FreeBSD amd64: g4f-go-v8.8.11-freebsd-amd64.zip

Lanzador independiente de sandbox (Docker/Podman, imagen extraída bajo demanda): -Windows amd64/arm64: g4f-sandbox-v8.8.11-windows-<arch>.zip

  • Linux amd64/arm64: g4f-sandbox-v8.8.11-linux-<arch>.zip
  • macOS amd64/arm64: g4f-sandbox-v8.8.11-darwin-<arch>.zip
  • Termux/Android arm64: g4f-sandbox-v8.8.11-android-arm64.zip (nativo Python API, no Docker)
  • El valor predeterminado es la imagen pequeña solo API (latest-slim); --desktop extrae la imagen completa del escritorio sólo cuando es necesario.

Aplicación de Android:

  • APK de Android: g4f-v8.8.11.apk

Extensión del navegador (Chrome/Edge):

  • g4f-browser-extension-v8.8.11.zip (descomprimirlo y luego cargarlo descomprimido mediante chrome://extensions)

Paquetes de sistema:

  • WinGet: winget install gpt4free

Docker:

  • docker pull hlohaus789/g4f:v8.8.11
  • docker pull hlohaus789/g4f:v8.8.11-slim
  • docker pull hlohaus789/g4f:v8.8.11-sandbox-desktop

Conjuntos de herramientas de IA en espacio aislado Docker (una instalación de click, más de 100 herramientas de IA diferentes):

  • docker pull hlohaus789/g4f:v8.8.11-sandbox-desktop: un escritorio Xfce completo (TigerVNC + noVNC) con g4f API y un menú "Instalar y abrir" de un click para más de 100 herramientas de IA diferentes: agentes de codificación (OpenCode, Copilot CLI, Hermes, Aider,…), interfaces de usuario de chat, herramientas de imagen/audio/video y puertas de enlace.
  • Escritorio + API: http://localhost:8080/desktop/ — API: http://localhost:8080
  • Monte su propia aplicación en /app/gpt4free y mantenga la configuración del agente: 
    docker run -d --name g4f-sandbox-desktop \  -p 8080:8080 -p 5900:5900 --shm-size="2gb" \  -v ${PWD}:/app/gpt4free \  -v ${PWD}/sandbox-home/.config:/home/pn/.config \  -v ${PWD}/sandbox-home/.local:/home/pn/.local \  hlohaus789/g4f:v8.8.11-sandbox-desktop
  • Documentos: docker/sandbox-menu/README.md
