#AstrBot v4.29.0

[4.29.0] - 2026-10-14

Esta versión incluye todos los cambios de v4.29.0-beta.1 y v4.29.0-beta.2, además de los cambios desde v4.29.0-beta.2. El rango de lanzamiento completo comienza en v4.28.0.

Adiciones importantes

  • Uso de la computadora: se agregó soporte de zona de pruebas específica del sistema operativo para el entorno de ejecución local, disponible en macOS con Seatbelt y Linux solo con bubblewrap. Consulte: https://docs.astrbot.app/use/astrbot-agent-sandbox.html (#9472)
  • ChatUI: se agregó historial de chat y paginación de sesiones en la barra lateral, borradores de entrada persistentes, selección de modelo por sesión y enfoque automático de entrada al cambiar de proyecto. (#9667, #10279, #10247, #10301)
  • ChatUI: se agregaron filtros de fuente de proveedores y grupos fijos para la selección de modelos, además de búsqueda en las páginas Habilidades y MCP. (#10084, #10217)
  • Las configuraciones de texto a imagen se movieron de Configuración a Perfiles de configuración → Extensiones y ahora se configuran por separado para cada perfil.
  • Las configuraciones de administrador y lista blanca se han movido de Perfiles de configuración → Plataforma a Perfiles de configuración → Control de acceso. (#10321)
  • WebUI: se agregó un selector de directorio de espacio de trabajo y progreso de descarga de actualizaciones en la aplicación de escritorio. (#10222, #10227, #10050)
  • Escritorio: se agregaron efectos de vidrio esmerilado de macOS a la barra lateral y a la barra superior de WebUI. (#10222, #10227, #10050)
  • Principal: Se agregaron recordatorios de presupuesto de pasos del agente, límites heredados migrados, aumento del límite de pasos del agente predeterminado y esperas de sesión de shell extendidas. (#10131, #10133)
  • Principal: se agregó el encabezado de ID de conversación x-astrbot-conversation-id a las solicitudes del proveedor. (#10218, #10237)
  • WebUI: se agregaron accesos directos a la configuración del modelo junto a los modelos seleccionados y en los menús de modelo/alternativo. Los cambios se guardan inmediatamente para cada perfil de configuración que utiliza ese modelo. (#10321)
  • WebUI: se agregó búsqueda de registros de consola y resaltado de palabras clave, insignias de origen para habilidades, vistas previas de imágenes preparadas en ChatUI y se recordó la última pestaña de Datos y registros abierta. (#10327, #10339, #10376, #10251)
  • WebUI: edición de perfil de configuración agregada en un cajón lateral desde el editor de bot. (#10310)
  • Docker: Incluye el astrbot CLI para restablecimiento de contraseña dentro de contenedores. (#10442)
  • Registros: se agregó filtrado combinado de nivel, fuente, complemento, plataforma y palabras clave, una opción para ocultar los registros de chat de los usuarios y controles de tamaño de fuente de 8 a 16 píxeles (12 píxeles de forma predeterminada, en pasos de 2 píxeles). Los selectores de complementos muestran nombres para mostrar con ID como subtítulos. (#10514)

Optimizaciones importantes

  • WebUI: se perfeccionó la barra lateral y la barra superior, reduciendo su huella vertical para mostrar más información. (#10222, #10227, #10050)
  • Vistas previas de datos de conversación mejoradas en la página Datos y registros. (#10021, #10020, #10023, #10108)
  • Se agregaron cargas fragmentadas reanudables con uso de memoria limitado, recursos estáticos del panel comprimido y recursos de diagramas y fuentes agrupados reducidos. (#10123, #10187, #10034)
  • Se mejoró el desplazamiento del panel de razonamiento y respuesta transmitida, se conservó la posición de desplazamiento al cargar el historial y se fusionó el desplazamiento automático por cuadro de animación. (#10219, #10221, #10243, #10253, #10257, #10271)
  • Preparación mejorada de la imagen de entrada del modelo, geometría de imagen preservada, tamaños de imagen codificados limitados y conversión de animación a fotograma explicada a modelos. (#9703, #10071, #10120, #10119)
  • Representación de registros de consola por lotes, diálogos de proveedores optimizados y actualizaciones de seguimiento, y eliminación de sesiones innecesarias y trabajo con límite de velocidad. (#9990, #10007, #10270, #10273, #10274)
  • WebUI: reducción significativa de la sobrecarga de carga inicial y velocidad de carga mejorada mediante la carga diferida de VAD, Monaco, traducciones y ApexCharts, y habilitando respuestas gzip. (#10413)
  • WebUI: se mantuvieron fijos los bordes y las esquinas del contenido mientras se desplazaba, se agregaron espacios de 6 píxeles en la parte derecha/inferior del escritorio y se fijaron encabezados de configuración/configuraciones y navegación de secciones mientras se desplaza el panel de contenido. (#10480)
  • Uso de la computadora: se aclararon los modos de acceso a permisos locales, se mantuvieron visibles los controles de ejecución y acceso a archivos cuando el aislamiento local no está disponible y se vinculó la guía de configuración a la guía consolidada de Agent Sandbox. (#10444, #10445, #10487)
  • Documentos: complemento actualizado en chino e inglés y guías de IA integradas con flujos de trabajo actuales, solución de problemas y capturas de pantalla localizadas; Instrucciones de configuración actualizadas de Slack and Lark/Feishu. (#10487, #10353, #10400)
  • Registros: se agregaron metadatos estructurados de fuente, complemento, plataforma y categoría para el filtrado en memoria. Los nuevos registros siguen automáticamente cuando se desplazan hacia la parte inferior y conservan la posición de lectura al ver entradas más antiguas. (#10514)
  • Agente: se movió el contexto de la tarea programada por ejecución después del historial de conversaciones para mantener estable el aviso del sistema y preservar la reutilización del caché de avisos. (#10549)

中文

本正式版本包含 v4.29.0-beta.1、v4.29.0-beta.2 的全部变更，以及 v4.29.0-beta.2 之后的变更；完整变更范围从v4.28.0 开始。

主要新增

  • 电脑使用:本地执行环境新增按操作系统适配的沙箱隔离,目前支持 macOS Seatbelt y Linux bubblewrap.参考:https://docs.astrbot.app/use/astrbot-agent-sandbox.html (#9472)
  • ChatUI:新增聊天历史和侧边栏会话分页、输入草稿持久化、按会话记忆所选模型,以及切换项目时自动聚焦输入框. (#9667, #10279, #10247, #10301)
  • ChatUI: 模型选择器新增来源筛选和吸顶分组, Habilidades 与 MCP 页面新增搜索。 (#10084, #10217)
  • 现在 “文本转图片” 相关配置已从 “设置” 迁移到 “配置文件” -> “扩展功能”，并按配置文件隔离。
  • 现在 “管理员”、“白名单” 相关配置已从 “配置文件” -> “平台” 迁移到 “配置文件” -> “访问控制”。 (#10321)
  • 日志：支持按级别、来源、插件、平台和关键词组合筛选，可隐藏用户对话日志；新增 8–16px字号控制，默认 12px，按 2px 步长调整。插件筛选器显示插件名称，并以 ID 作为副标题。 (#10514)
  • Actualización: WebUI compatible con macOS (#10222, #10227, #10050)
  • Núcleo: 新增 Agente 剩余步数提醒，迁移旧版步数限制，提高默认步数上限，并延长 Shell 会话等待时间。 (#10131, #10133)
  • Núcleo: 为模型提供商请求新增 x-astrbot-conversation-id 会话 ID 请求头。 (#10218, #10237)
  • WebUI:模型选择器旁及模型、回退模型菜单内新增设置入口,修改后立即影响引用该模型的所有配置文件. (#10321)
  • WebUI: 新增控制台日志搜索与关键词高亮, Habilidades 来源标识, ChatUI (#10327, #10339, #10376, #10251)
  • WebUI: 支持在机器人编辑器的侧边抽屉中编辑配置文件。 (#10310)
  • Docker：镜像内包含 astrbot CLI，可在容器中重置密码。 (#10442)
  • WebUI: 桌面端新增工作区目录选择器及更新下载进度。 (#10222, #10227, #10050)
