#AstrBot v4.26.5

[4.26.5] - 2026-07-07

Agregado

  • Se agregó soporte para configurar una ID de bot personalizada al crear una plataforma escaneando un código QR. (#9067)
  • Se agregaron espacios de trabajo del proyecto ChatUI. (#9066)
  • Se agregó una visualización mejorada de archivos adjuntos de ChatUI. (#9134)
  • Se agregó saneamiento de nombres de llamadas de herramientas con formato incorrecto en ToolLoopAgentRunner. (#9144)
  • Se agregaron metadatos del modelo en selectores y un indicador de uso de token de chat. (#9161)
  • Se agregaron diagnósticos de bucle de eventos y documentación de diagnóstico ampliada. (#9168)
  • Se agregó documentación para compatibilidad multiplataforma y compatibilidad con la versión Python.
  • Se agregó cobertura de prueba para la preservación de la raíz del URI del archivo POSIX. (#8906)

Cambiado

  • Registrar el inicio del mecanismo de vigilancia del bucle de eventos en el nivel de información.
  • Mantenga los metadatos del modelo separados de los proveedores. (#9161)
  • Estilo de snack bar polaco en la WebUI. (#9173)

Fijo

  • Habilitado solo servidores ModelScope MCP sincronizados. (#9084)
  • Se mejoró el manejo de inicio y apagado de MCP client para evitar el funcionamiento inactivo y limpiar errores, tiempos de espera y cancelaciones. (#9070)
  • Se reemplazó el error de coincidencia de nombre duplicado de la frágil base de conocimientos con una verificación previa. (#9121)
  • Resiliencia mejorada de recuperación de la base de conocimientos en fallas por base de conocimientos y selección de cambio de rango. (#9122)
  • Se limpiaron los registros KBMedia sobre la eliminación de documentos y se corrigieron las actualizaciones de estadísticas de la base de conocimientos. (#9120)
  • Se alineó el contrato CRUD API de la base de conocimientos con kb_name, campos de carga útil canónicos y tipos OpenAPI. (#9000)
  • Rutas de espacio de trabajo personalizadas restringidas y rutas de espacio de trabajo personalizadas absolutas preservadas.
  • Conmutación por error de clave API de búsqueda web mejorada.
  • Propiedad impuesta al leer sesiones de ChatUI. (#9141)
  • Puesta en escena temporal de actualización segura del proyecto. (#9083)
  • Se mejoró el comportamiento de reintento oficial de QQ cuando el envío de websocket devuelve None. (#8977)
  • Contexto del mensaje citado oficial de QQ conservado. (#9164)
  • Se eliminaron los ID de respuesta oficiales de QQ en respaldo proactivo para que las respuestas pasivas de gran tamaño puedan tener éxito mediante el envío proactivo. (#9169)
  • Se adaptó MiMo STT a los modelos V2.5 y se rechazaron cargas útiles de audio que no sean WAV. (#9118)
  • Marcas de tiempo serializadas del historial de chat web como cadenas ISO compatibles con UTC. (#9159)
  • Estado de activación del complemento sincronizado activado en la WebUI. (#9156)
  • Se salieron de los contextos MCP anyio en la tarea del ciclo de vida al desactivarlos. (#9132)
  • Se corrigió el manejo de la pila de salida de SSE filtrada que podría causar que MCP epoll esté ocupado y espere. (#8307) [4.26.5]: https://github.com/AstrBotDevs/AstrBot/compare/v4.26.4...v4.26.5
