#AstrBot v4.23.0

  • Registro de actualización (chino simplificado)
  • Changelog(inglés) <a id="chino"></a>

¿Qué ha cambiado?

Nuevo

  • Admite lectura de archivos (lectura), escritura (escritura), edición (editar), búsqueda Grep (ripgrep) y espacio de trabajo aislado por sesión para capacidades de uso de la computadora. (#7402)
  • El adaptador de cuenta personal WeChat admite el análisis de mensajes de referencia. (#7380)
  • Se agregó la herramienta de búsqueda web Brave Search y se eliminó la antigua implementación de búsqueda web predeterminada. (#6847)
  • Se agregó compatibilidad con el adaptador de plataforma Mattermost. (#7369)
  • Se agregó el proveedor de reclasificación de NVIDIA. (#7227)
  • Se agregó el proveedor LongCat LLM. (#7360)
  • Se agregó soporte para los modos de entrada de audio OpenAI y Gemini, y se solucionaron problemas relacionados con la grabación de ChatUI. (#7378)
  • La plataforma Discord agrega una nueva configuración de filtrado de mensajes de Bot, que le permite controlar si desea recibir mensajes de otros Bots. (#6505)
  • Se agregó la capacidad de LLM para guiar llamadas repetidas a herramientas para reducir la situación en la que el modelo cae en llamadas repetidas a herramientas. (#7388)
  • El API oficial de QQ agrega un mecanismo de reintento para la carga de archivos para mejorar la estabilidad del envío de archivos. (#7430)

Optimización

  • Reconstruir el estilo ChatUI, la representación de mensajes y la experiencia de entrada para mejorar la mantenibilidad general y la coherencia de la interacción de la interfaz de chat. (#7485)
  • Fusione herramientas relacionadas con Cron en una herramienta de administración unificada y agregue capacidades de edición de tareas de Cron. (#7445)
  • Reconstruir la lógica de gestión de herramientas integradas para mejorar el mantenimiento del registro y la llamada de herramientas integradas de AstrBot. (#7418)
  • Se eliminó la mayoría de los comandos integrados de baja frecuencia e integró las funciones de comando, se movieron estos comandos al complemento [extensión-comando-integrada] (https://github.com/AstrBotDevs/builtin_commands_extension) y se actualizó la documentación. (#7478)
  • Se eliminó la implementación de búsqueda web predeterminada y se reemplazó con un nuevo enlace de herramienta de búsqueda. (#7416)
  • Se eliminaron las dependencias de lxml y beautifulsoup4 para reducir el tamaño de la instalación y la complejidad de las dependencias. (#7449)
  • Se agregó verificación de configuración estándar de MCP para reducir las fallas de inicio y los costos de solución de problemas causados por configuraciones no válidas. (#7477)
  • Docker Habilite no-new-privileges en la configuración en ejecución para mejorar la seguridad predeterminada del contenedor. (comprometer)
  • Reduzca la frecuencia de sondeo del estado del servidor MCP y reduzca la sobrecarga de solicitudes en segundo plano. (#7399)
  • Los comandos de ayuda ignoran los comandos internos válidos como dashboard_update para reducir el ruido de la lista de ayuda. (comprometer)
  • Se corrigió el ejemplo de empalme de rutas en el documento para evitar que los documentos de almacenamiento de desarrollo de complementos engañen a los usuarios. (#7448)
  • Se complementaron las constantes de la plataforma Matrix, los íconos de la plataforma y la documentación relacionada. (#7368)

Arreglar

  • Se solucionó un problema por el cual el proveedor STT o TTS aún se podía usar cuando estaba deshabilitado en la configuración. (#7363)
  • Se solucionó el problema de que la salida del modelo vacío de Gemini desencadenara accidentalmente un procesamiento de errores. (#7377)
  • Se solucionó un problema por el cual el campo id no admitido en Gemini FunctionResponse causaba que la solicitud fallara. (#7386)
  • Se solucionó el problema por el cual todavía se pasaba FunctionCallingConfig cuando solo había herramientas nativas presentes. (#7407)
  • Se solucionó un problema por el cual las afirmaciones de resultados de las herramientas eran inconsistentes con los umbrales dinámicos. (comprometer)
  • Se solucionó el problema de compatibilidad del formato de devolución de Bailian Rerank para diferentes puntos finales de URL. (#7250)
  • Se solucionó el problema de la limpieza incompleta del proceso de cierre del WebSocket oficial de QQ. (#7395)
  • Se solucionó el problema de recuperación del sondeo después de una anomalía en la red de Telegram y se agregaron pruebas relacionadas. (#7468)
  • Se solucionó el problema por el cual el segmento final de un mensaje largo de Telegram era demasiado largo. (#7432)
  • Se solucionó el problema por el cual Telegram sendMessageDraft enviaba texto vacío causando que el error 400 vaciara la pantalla. (#7398)
  • Se solucionó el problema por el cual el controlador de complementos no estaba en star_map, lo que provocaba KeyError cuando Telegram recopila comandos. (#7405)
  • Se solucionó el problema por el cual Discord Slash Command no se retrasaba en el tiempo causando 10062 Unknown interaction. (#7474)
  • Se corrigió el mensaje de advertencia cuando el adaptador de cuenta personal de WeChat carece de token de contexto. (comprometer)
  • Se solucionó el problema por el cual group_icl_enable no usaba la configuración de enlace UMO al procesar mensajes. (#7397)
  • Se solucionó el problema por el cual la ruta del módulo de la herramienta de función del complemento no coincide con la ruta del módulo principal del complemento. (#7462)
  • Se corrigió la compatibilidad de la lógica de verificación de versiones del complemento para versiones preliminares. (comprometer)
  • Se solucionó el problema por el cual los caracteres que no son ASCII se escapan en la respuesta de la ejecución del comando Shell JSON. (#7475)
  • Se solucionó un problema por el cual la carga de dependencias del complemento de escritorio de Windows no era segura o fallaba. (#7446)
  • Se solucionó el problema por el cual faiss se importaba prematuramente durante la fase de inicio, lo que provocaba que algunos entornos no se iniciaran. (#7400)
  • Se corrigió la representación en modo oscuro de WebUI y múltiples problemas de interacción. (#7173)
  • Se corrigieron las constantes faltantes del proyecto ChatUI y se agregaron casos de prueba relacionados. (#7414)
  • Se solucionó el problema de los botones flotantes que saltaban al cambiar de página. (#7214)
  • Se solucionó el problema por el cual faltaba la dependencia de la página de administración de diálogo MessageList.vue, lo que provocaba que el panel del entorno Linux no se compilara. (comprometer)
  • Se solucionó el problema de visualización causado por el ícono de llamada de herramienta usando el ícono faltante del subconjunto MDI. (comprometer)
  • Se solucionó el problema de uso del tipo de defineStore en la tienda Dashboard. (#7490)
  • Se corrigió el error de nombre de imagen Docker en el archivo de redacción. (#7488) <a id="inglés"></a>
