#AstrBot v4.28.0

4.28.0 - 2026-09-08

El paisaje en las cuatro estaciones es diferente y la alegría es infinita.

Cada estación trae su propia belleza y la alegría es infinita.

📢 Debido a la optimización de algunos archivos de configuración, la degradación después de la actualización provocará que se restablezca parte del contenido de la configuración. Tenga cuidado al degradar después de actualizar. Debido a optimizaciones estructurales en el archivo de configuración, la degradación después de una actualización resultará en el restablecimiento de parte del contenido de la configuración. Tenga cuidado al bajar de categoría después de una actualización.

Adiciones importantes

  • Rediseñé las páginas de WebUI para proveedores de modelos, bots y perfiles, y consolidé registros, seguimientos, gestión de conversaciones y datos en la página Datos y registros. Se eliminó el Agent Runner de los proveedores de modelos e incorporó su configuración en cada perfil. (#9820, #9825, #9821, #9883, #9846)
  • Rediseñado el renderizado T2I local y predeterminado. (#9803)
  • Metadatos de grupo unificados enriquecidos en todos los adaptadores de plataformas de mensajería. (#9851)
  • Registre automáticamente nombres legibles para orígenes de mensajes unificados (UMO), como nombres de grupos y usuarios, haciéndolos más fáciles de encontrar en la WebUI. (#9909)
  • Se agregaron campos secretos enmascarados para valores confidenciales en la WebUI y las configuraciones de complementos. (#9824)
  • Se agregó eliminación por lotes a la página de administración de habilidades de WebUI. (#9906)
  • Se agregó AnySearch como proveedor de búsqueda web integrado. (#9767)
  • Se agregó soporte para campos de configuración de complementos de estilo contraseña y campos de perfil confidenciales enmascarados de forma predeterminada. (#9824)

Optimizaciones importantes

  • Se mejoró la forma en que los administradores de contraseñas del navegador reconocen la página de inicio de sesión de WebUI. (#9830)
  • Iconos de proveedores de modelos adaptados para el modo oscuro. (#9647)
  • Manejo de contexto mejorado para agentes de tareas futuras. (#9818)
  • Se hizo que el cuadro de diálogo del editor de habilidades respondiera en pantallas más pequeñas. (#9873)
  • Estabilizó el orden del esquema de herramientas OpenAI ordenando las herramientas alfabéticamente por nombre. (#9798)

Correcciones importantes

  • Se solucionó un problema por el cual DingTalk podía permanecer en un estado CREATING desconocido después de escanear el código QR, lo que impedía que continuara la creación de la aplicación. (#9808)
  • Se solucionó un problema por el cual los comandos en los grupos de Lark no se activaban cuando la mención del bot aparecía antes del comando. (#9872)
  • Límites de tarifas aislados por origen de mensaje unificado (UMO). (#9814)
  • Manejo de URL base antrópico API alineado con OpenAI API; /v1 ahora debe estar incluido en la URL configurada. (#9802)
  • Se corrigió la contabilidad del uso de tokens en caché para Anthropic y Gemini. (#9880, #9881)
  • Se aplicó la configuración max_agent_step a agentes de tareas programadas y de tareas en segundo plano. (#9801)
  • Texto conservado en mensajes mixtos de texto e imagen de Lark. (#9841)
  • Se muestra el botón de creación de carpeta en el administrador de personas móvil. (#9812)

Principales novedades

  • Rediseñar la página del proveedor del modelo, la página del robot y la página del archivo de configuración de WebUI, e integrar las páginas de registro, seguimiento, gestión de conversaciones y datos en la página "datos y registro". Se eliminó el "Agente ejecutor" del proveedor del modelo y lo incorporó en cada archivo de configuración. (#9820, #9825, #9821, #9883, #9846)
  • Efectos de renderizado T2I nativos y predeterminados rediseñados. (#9803)
  • Enriquecer metadatos de grupo unificados para cada adaptador de plataforma de mensajería (#9851)
  • Registre automáticamente el nombre legible (como nombre de grupo, nombre de usuario) de la fuente de mensajería unificada (UMO) para facilitar la consulta en la WebUI. (#9909)
  • Se agregó un campo de clave de máscara para valores confidenciales en WebUI y configuración de complementos. (#9824)
  • Se agregó la función de eliminación por lotes a la página de administración de habilidades de WebUI. (#9906)
  • Se agregó el proveedor de servicios de búsqueda web integrado AnySearch. (#9767)
  • Admite elementos de configuración de complementos para usar campos con efectos de contraseña y usar efectos de contraseña para campos confidenciales en archivos de configuración de forma predeterminada. (#9824)

Optimización principal

  • Mejorar la lógica de reconocimiento de la función de memoria automática de contraseñas del navegador para la página de inicio de sesión de WebUI. (#9830)
  • Adaptar el ícono del proveedor de modelos al modo oscuro. (#9647)
  • Optimizar el contexto de futuras tareas de los Agentes. (#9818)
  • Adaptar el cuadro de diálogo del editor de habilidades a pantallas pequeñas. (#9873)
  • Estabilizar el orden del esquema de herramientas OpenAI en el orden del diccionario de nombres de herramientas. (#9798)

Correcciones importantes

  • En algunos casos en DingTalk, aparece un estado CREANDO desconocido después de escanear el código QR, lo que imposibilita continuar creando. (#9808)
  • Se solucionó el problema en el Grupo Feishu donde el comando no se podía activar cuando el robot estaba al frente y el comando estaba atrás. (#9872)
  • Aislar la limitación actual mediante el origen de mensajería unificada (UMO). (#9814)
  • Hacer que la lógica de URL base de Anthropic API sea consistente con OpenAI API, requiriendo la entrada de /v1. (#9802)
  • Se corrigieron las estadísticas de uso de Anthropic y Gemini con respecto a los tokens de caché. (#9880, #9881)
  • Aplicar la configuración max_agent_step a las tareas programadas y a los agentes de tareas en segundo plano. (#9801)
  • Conservar texto en mensajes de texto e imágenes mixtos de Feishu. (#9841)
  • Mostrar un botón de nueva carpeta en el administrador de personalidad del móvil. (#9812)
