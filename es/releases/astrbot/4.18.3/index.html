#AstrBot v4.18.3

¿Qué ha cambiado?

Nuevo

  • Se agregó la capacidad de puente de actualización universal de escritorio para facilitar el acceso al proceso de actualización en el cliente (#5424).

Arreglar

  • Se solucionó el problema por el cual el adaptador de línea no se muestra en el cuadro de diálogo de la nueva plataforma.
  • Se solucionó el problema por el cual Telegram no podía enviar video (#5430).
  • Se solucionó un problema por el cual las dimensiones vectoriales no se podían reconocer automáticamente al crear un proveedor de incrustación (#5442).
  • Se solucionó el problema por el cual el campo de rebajas no se limpiaba al enviar mensajes multimedia en la plataforma oficial de QQ (#5445).
  • Se solucionó el problema de la pérdida del emparejamiento de llamada/respuesta de herramienta cuando la política de administración de contexto -> truncamiento de contexto (#5417).
  • Se solucionó el problema de que persona_id se sobrescribiera durante la actualización de la sesión y se mejoró la lógica de análisis de personas.
  • Se solucionó el problema de visualización anormal de la dirección proxy GitHub en WebUI (#5438).
  • Se solucionó el problema de la copia fallida después de crear una nueva clave de desarrollador API en la página de configuración (#5439).
  • Se solucionó el problema de compatibilidad del formato de mensajes de voz de Telegram con OpenAI STT (usando OGG) (#5389).

Optimización

  • Optimice el proceso de recuperación de la base de conocimientos, cambie a metadatos de consultas por lotes y solucione el problema de rendimiento de las consultas N+1 (#5463).
  • Optimice la capacidad de aislamiento de sesiones de Cron para la ejecución futura de tareas y mejore la estabilidad de la concurrencia.
  • Optimice la interacción de la página del complemento WebUI.

Qué ha cambiado (ES)

Nuevas funciones

  • Se agregó useExtensionPage componible para la gestión unificada del estado de la página de extensión del complemento.
  • Se agregó un puente de actualización de aplicaciones de escritorio genérico para admitir flujos de trabajo de actualización en la aplicación (#5424).

Corrección de errores

  • Se corrigió que el adaptador de línea no apareciera en el cuadro de diálogo "Agregar plataforma".
  • Se corrigieron problemas de envío de videos de Telegram (#5430).
  • Se corrigieron errores de verificación de tipo estático de Pyright (#5437).
  • Se corrigió la detección automática de dimensiones de incrustación al crear proveedores de incrustación (#5442).
  • Se corrigieron campos de rebajas obsoletos al enviar mensajes multimedia a través de la plataforma oficial QQ (#5445).
  • Se corrigió la pérdida de emparejamiento de llamada/respuesta de herramienta durante el truncamiento del contexto (#5417).
  • Se corrigió la sobrescritura de persona_id durante las actualizaciones de la conversación y se mejoró la lógica de resolución de personas.
  • Se corrigió la visualización incorrecta del proxy GitHub en WebUI (#5438).
  • Se corrigió el error de copia de la clave API después de crear una nueva clave en la configuración (#5439).
  • Se corrigió la compatibilidad del formato de voz de Telegram con OpenAI STT mediante el uso de OGG (#5389).

Mejoras

  • Recuperación de la base de conocimientos mejorada al agrupar consultas de metadatos para eliminar el patrón de consulta N+1 (#5463).
  • Aislamiento de sesión mejorado para futuras tareas cron para aumentar la estabilidad en concurrencia.
  • Interacciones mejoradas en la página del complemento WebUI.
