#AstrBot v4.27.3

[4.27.3] - 2026-08-13

Y luego salimos nuevamente a ver las estrellas. Salimos de allí y volvimos a ver las estrellas.

Agregado

  • AstrBot Desktop ahora utiliza sesiones sin contraseña y abre la WebUI directamente sin necesidad de iniciar sesión. (#9585)
  • Se agregó la hora efectiva de AstrBot a la configuración y los trabajos cron heredaron la zona horaria configurada. (#9579, #9581)
  • Cargas ampliadas de WebChat mediante arrastrar y soltar en toda el área de chat. (#9564)
  • Se agregó una opción one-click para restaurar los valores predeterminados de configuración del complemento. (#9599)
  • Se agregó compatibilidad con PowerShell 7 para el shell local de Windows. (#9622)
  • Se agregó clasificación por recuento de descargas al mercado de complementos. (#9570)
  • Se agregaron cargas de archivos fragmentados para QQ Official para admitir archivos grandes de manera más confiable. (#9646)
  • Se utilizaron favicons como ícono de complemento predeterminado y se mejoró el contraste del texto del tema oscuro. (#9547, #9643)

Cambiado

  • Se migraron SharedPreferences y acceso a preferencias de configuración a rutas asincrónicas y sin bloqueo, mejorando el rendimiento en los flujos afectados y reduciendo el riesgo de aparentes congelaciones y bloqueos. (#9582, #9584, #9649)
  • Búsqueda estabilizada de documentos en la base de conocimientos, distinción de errores de carga de resultados vacíos, restauración de resultados de recuperación completos y respaldo de UUID compatible al resolver bases de conocimientos por nombre. (#9577, #9578, #9618, #9636)
  • Configuración del proveedor en memoria actualizada después de la eliminación y estado de habilidad del complemento sincronizado en todo el Panel. (#9568, #9596)
  • Se evitó que aparecieran sesiones transitorias del proyecto en ChatUI y se restauraron las sesiones de WebChat faltantes. (#9587, #9607)
  • Se desinfectaron los nombres de las herramientas MCP para LLM API y se trataron los esquemas de configuración vacíos como si no tuvieran elementos configurables. (#9534, #9619)
  • Advierte cuando una distribución WebUI configurada explícitamente está obsoleta. (#9518)
  • Se registraron las horas de finalización del agente antes de publicar las estadísticas y se cancelaron las ejecuciones del agente detenido inmediatamente. (#9597, #9602)
  • Se utilizaron miniaturas estáticas para stickers animados de Telegram y se convirtieron notas de video de Telegram en componentes de video. (#9610, #9627)
  • Se propagaron fallas en la carga de medios QQ en lugar de continuar silenciosamente. (#9644)

Mantenimiento

  • Se actualizaron las dependencias de acciones GitHub agrupadas, se mejoró la escritura del programador de canalizaciones y se estabilizaron las pruebas OpenAI HTTP client. (#9620, #9621)

chino

Nuevo

  • El escritorio AstrBot implementa un mecanismo sin inicio de sesión y puede ingresar directamente a la WebUI sin iniciar sesión. (#9585)
  • El shell nativo de Windows agrega compatibilidad con PowerShell 7. (#9622)
  • El robot oficial de QQ ha agregado la carga de archivos segmentados para solucionar el problema de que los archivos grandes no se pueden enviar normalmente. (#9646)
  • Área de carga de WebChat ampliada mediante arrastrar y soltar a toda el área de chat. (#9564)
  • Se agregó la función de un clic para restaurar los valores predeterminados de configuración del complemento. (#9599)
  • Muestra la hora efectiva real de AstrBot en la configuración y hace que las tareas programadas hereden la zona horaria configurada. (#9579, #9581)
  • Las nuevas incorporaciones al mercado de complementos se clasifican por volumen de descarga. (#9570)
  • Utilice favicon como icono predeterminado del complemento y mejore el contraste del texto en temas oscuros. (#9547, #9643)

Arreglar

  • Se mejoró parte del rendimiento y se redujeron posibles animaciones suspendidas y situaciones de interbloqueo (se migraron las preferencias compartidas y el acceso a preferencias de configuración a rutas asíncronas y sin bloqueo). (#9582, #9584, #9649)
  • Estabilice la búsqueda de documentos en la base de conocimientos, distinga errores de carga de resultados vacíos, restaure resultados de búsqueda completos y admita el respaldo de UUID al buscar bases de conocimientos por nombre. (#9577, #9578, #9618, #9636)
  • Actualizar el estado de la memoria después de eliminar la configuración del proveedor y sincronizar el estado de las habilidades del complemento en el Panel. (#9568, #9596)
  • Evite que aparezcan sesiones de proyectos temporales en la lista de sesiones de ChatUI y restaure las sesiones de WebChat faltantes. (#9587, #9607)
  • Limpiar los nombres de las herramientas MCP enviados a LLM API y tratar correctamente los esquemas de configuración vacíos como si no fueran elementos de configuración. (#9534, #9619)
  • Advierte cuando los archivos de versión de WebUI configurados explícitamente están desactualizados. (#9518)
  • Registre la hora de finalización del Agente antes de publicar las estadísticas y cancele las ejecuciones del Agente detenido inmediatamente. (#9597, #9602)
  • Los stickers dinámicos de Telegram se reemplazan por miniaturas estáticas y los mensajes de video de Telegram se convierten en componentes de video. (#9610, #9627)
  • Cuando falla la carga de medios QQ, el error se transmite correctamente hacia arriba y ya no continúa en silencio. (#9644)

Mantenimiento

  • El escritorio AstrBot utiliza Cloudflare R2 como fuente de actualización.
  • Se actualizó el grupo de dependencia de Acciones GitHub, se mejoró la anotación del tipo de programador de canalización y se estabilizó la prueba del cliente HTTP OpenAI. (#9620, #9621)
