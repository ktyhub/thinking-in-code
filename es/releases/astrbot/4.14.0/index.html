#AstrBot v4.14.0

Qué ha cambiado: VERSIÓN GRANDE Y HERMOSA

Si usó Skill en la versión anterior, deberá reconfigurar las opciones relacionadas con Skill Runtime después de esta actualización.

Nuevo

  • 🔥 Se agregó el sistema de tareas futuras. Asigne tareas futuras a AstrBot para que AstrBot pueda activarse automáticamente en un momento determinado para ayudarlo a completar la tarea. Consulte Tarea activa para obtener más detalles. (Experimental) (#4697)
  • 🔥 Se agregó el orquestador SubAgent. (Experimental)(#4697)
  • 🔥 Actualmente, AstrBot puede enviar imágenes/archivos a los usuarios directamente llamando a la herramienta, lo que mejora enormemente el efecto de interacción.
  • Se agregó la configuración de tiempo de ejecución de uso de computadora para fusionar las configuraciones de Skill y Sandbox (#4831)
  • Función de personalización de tema agregada, puede configurar el color principal y el color auxiliar
  • Admite la edición de personalidad en el cuadro de diálogo de personalidad en la página de configuración (#4826)
  • Función de "rastreo" del interruptor de soporte; admite la configuración de si se deben escribir registros en el archivo de registro en la configuración del sistema (#4822)

Arreglar

  • ‼️ Solucionar problemas de informes de errores relacionados con missing 2 required positional arguments: 'filter1' and 'filter2' introducidos en versiones recientes.
  • ‼ ️ Solucione el problema de visualización anormal de imágenes, pensamientos, etc. de ChatUI.
  • ‼️Se solucionó el problema de que la Skill no se descomprimiera automáticamente después de ser cargada en Sandbox, lo que provocaba que el Agente no pudiera leerla.
  • ‼ ️ Soluciona el problema por el cual las herramientas MCP se filtran al configurar un conjunto de complementos específico (#4825)
  • ‼ ️ Elimine el mensaje que viene con ChatUI para permitir que LLM finalmente haga la pregunta (#4824)
  • ‼ ️ Se corrigió el error por el cual WebUI todavía muestra un mensaje de éxito después de no poder cargar la habilidad (#4768)
  • Se solucionó el problema por el cual no se podía cambiar el nombre del servidor MCP (#4766)
  • Se solucionó el problema por el cual la herramienta de complemento no podía ver la fuente en el comportamiento de administración de WebUI (#4776)
  • ‼ ️ Solucionar el problema de no llamar a la herramienta en el modo de herramienta similar a una habilidad (#4775)

Optimización

  • Optimización general del efecto de la interfaz de usuario de WebUI
  • Algunos estilos de títulos de diálogo están unificados.

Qué ha cambiado (ES)

Nuevas funciones

  • Introducir el sistema CronJob con tareas únicas y gestión de panel mejorada
  • Agregue personalización del tema con opciones de color primario y secundario
  • Agregar configuración de tiempo de ejecución de uso de computadora para la ejecución de la zona de pruebas de habilidades (#4831)
  • Agregar botón de edición al cuadro de diálogo del selector de persona (#4826)
  • Agregar interfaz de usuario de configuración y alternancia de registro de seguimiento (#4822)
  • Agregue capacidad de mensajería proactiva con el disparador de herramienta cron
  • Implementar el orquestador SubAgent con políticas de gestión de herramientas configurables.
  • Admite la resolución de rutas de archivos sandbox y la descarga automática cuando sea necesario
  • Agregue estilos de imagen y audio incrustados en MessagePartsRenderer
  • Introducir la base i18n
  • Persistir el historial de interacción del agente
  • Agregar notificaciones de usuario para el éxito o eliminación de la descarga de archivos

Corrección de errores

  • Mejorar la precisión de la detección de complementos fantasmas
  • Agregar manejo de errores para evitar fallas del complemento fantasma
  • Evitar que el paquete de habilidades sobrescriba archivos existentes
  • Se corrigió el error de descomprimir el paquete de habilidades dentro de la zona de pruebas.
  • Se corrigió que las herramientas MCP se filtraran cuando se configuraba un conjunto de complementos específico (#4825)
  • Fusionar la ventana emergente de persona de ChatUI con la persona predeterminada (#4824)
  • Arreglar el estilo del bloque de razonamiento.
  • Agregue la coma que falta en la sugerencia truncate_and_compress
  • Se corrigió que la interfaz aún mostrara un mensaje de éxito (#4768)
  • Se corrigió la imposibilidad de cambiar el nombre del servidor MCP (#4766)
  • Eliminar el manejo sobrante del tiempo de ejecución del sandbox en la carga de habilidades (#4798)
  • Se corrigió la construcción de la ruta del módulo del controlador (#4776)
  • Se corrigió el error de invocación de herramienta similar a una habilidad (#4775)

Mejoras

  • Sugerencias en tiempo de ejecución y interfaz de usuario refinada en la gestión de habilidades
  • Mejoras de rendimiento y UX en la página de trabajos cron
  • Aumento general del rendimiento de la WebUI
  • Agrupar herramientas por complemento en el menú desplegable
  • Títulos de diálogo consistentes con estilos de texto y relleno.
  • Formato de código unificado (formato ruff)
  • Versión mejorada a 4.13.2

Otros

  • Eliminar el código de recordatorio obsoleto
  • Extraer el módulo del agente principal para una mejor arquitectura.
  • Fusionar cambios en la rama AstrBot_skill
