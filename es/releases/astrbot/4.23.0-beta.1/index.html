#AstrBot v4.23.0-beta.1

  • Registro de actualización (chino simplificado)
  • Changelog(inglés) <a id="chino"></a>

¿Qué ha cambiado?

Nuevo

  • Admite lectura de archivos (lectura), escritura (escritura), edición (editar), búsqueda Grep (ripgrep) y espacio de trabajo aislado por sesión para capacidades de uso de la computadora. (#7402)
  • Se agregó la herramienta de búsqueda web Brave Search para reemplazar la antigua implementación de búsqueda web predeterminada. (#6847)
  • Se agregó compatibilidad con el adaptador de plataforma Mattermost. (#7369)
  • Se agregó el proveedor de reclasificación de NVIDIA. (#7227)
  • Se agregó soporte para los modos de entrada de audio OpenAI y Gemini, y se solucionaron problemas relacionados con la grabación de ChatUI. (#7378)
  • La plataforma Discord agrega una nueva configuración de filtrado de mensajes de Bot, que le permite controlar si desea recibir mensajes de otros Bots. (#6505)
  • Se agregó la capacidad de LLM para guiar llamadas repetidas a herramientas para reducir la situación en la que el modelo cae en llamadas repetidas a herramientas. (#7388)

Optimización

  • Fusione herramientas relacionadas con Cron en una herramienta de administración unificada y agregue capacidades de edición de tareas de Cron. (#7445)
  • Reconstruir la lógica de gestión de herramientas integradas para mejorar el mantenimiento del registro y la llamada de herramientas integradas de AstrBot. (#7418)
  • Se eliminó la implementación de búsqueda web predeterminada y se reemplazó con un nuevo enlace de herramienta de búsqueda. (#7416)
  • Se eliminaron las dependencias de lxml y beautifulsoup4 para reducir el tamaño de la instalación y la complejidad de las dependencias. (#7449)
  • Reduzca la frecuencia de sondeo del estado del servidor MCP y reduzca la sobrecarga de solicitudes en segundo plano. (#7399)
  • Se corrigió el ejemplo de empalme de rutas en el documento para evitar que los documentos de almacenamiento de desarrollo de complementos engañen a los usuarios. (#7448)

Arreglar

  • Se solucionó un problema por el cual la carga de dependencias del complemento de escritorio de Windows no era segura o fallaba. (#7446)
  • Se solucionó el problema por el cual el segmento final de un mensaje largo de Telegram era demasiado largo. (#7432)
  • Se solucionó un problema por el cual Telegram sendMessageDraft causaba un error 400 al enviar texto vacío. (#7398)
  • Se solucionó el problema por el cual el controlador del complemento no estaba en star_map, lo que provocaba KeyError cuando Telegram recopila comandos. (#7405)
  • Se solucionó el problema de la limpieza incompleta del proceso de cierre del WebSocket oficial de QQ. (#7395)
  • Se solucionó un problema por el cual el campo id no admitido en Gemini FunctionResponse causaba que la solicitud fallara. (#7386)
  • Se solucionó el problema de que la salida del modelo vacío de Gemini desencadenara accidentalmente un procesamiento de errores. (#7377)
  • Se solucionó el problema por el cual todavía se pasaba FunctionCallingConfig cuando solo había herramientas nativas presentes. (#7407)
  • Se corrigieron las constantes faltantes del proyecto ChatUI y se agregaron casos de prueba relacionados. (#7414)
  • Se corrigió la representación en modo oscuro de WebUI y múltiples problemas de interacción. (#7173)
  • Se solucionó el problema de los botones flotantes que saltaban al cambiar de página. (#7214)
  • Se solucionó el problema por el cual faiss se importaba prematuramente durante la fase de inicio, lo que provocaba que algunos entornos no se iniciaran. (#7400)
  • Se corrigió el mensaje de advertencia cuando el adaptador de cuenta personal de WeChat carece de token de contexto. (comprometer)
  • Se solucionó un problema por el cual las afirmaciones de resultados de las herramientas eran inconsistentes con los umbrales dinámicos. (comprometer) <a id="inglés"></a>

Qué ha cambiado (ES)

Nuevas funciones

  • Se agregaron herramientas del sistema de archivos de uso de computadora local, que incluyen lectura, escritura, edición de archivos, búsqueda Grep y soporte de espacio de trabajo por sesión. (#7402)
  • Se agregó la herramienta de búsqueda web Brave Search, reemplazando la antigua implementación de búsqueda web predeterminada. (#6847)
  • Se agregó soporte para la plataforma Mattermost. (#7369)
  • Se agregó el proveedor de reclasificación de NVIDIA. (#7227)
  • Se agregó soporte de entrada de audio entre proveedores y se solucionaron problemas de grabación de ChatUI. (#7378)
  • Se agregó filtrado de mensajes de bots de Discord configurable, incluido el soporte para recibir mensajes de otros bots. (#6505)
  • Se agregó guía LLM para llamadas repetidas a herramientas para reducir los bucles repetitivos de llamadas a herramientas. (#7388)

Mejoras

  • Se fusionaron las herramientas de Cron en una herramienta de administración unificada y se agregó la edición de tareas de Cron. (#7445)
  • Gestión de herramientas integrada refactorizada para mejorar el registro y el mantenimiento. (#7418)
  • Se eliminó la antigua implementación de búsqueda web predeterminada a favor del nuevo flujo de herramientas de búsqueda. (#7416)
  • Se eliminaron las dependencias de lxml y beautifulsoup4 para reducir el peso de las dependencias y la complejidad de la instalación. (#7449)
  • Se redujo la frecuencia de sondeo del estado del servidor MCP para reducir la sobrecarga de solicitudes en segundo plano. (#7399)
  • Se corrigió un ejemplo de concatenación de rutas en los documentos de almacenamiento del complemento. (#7448)
  • Se actualizó el logotipo README. (comprometer)

Corrección de errores

  • Se corrigió la carga de dependencia de complementos de escritorio más segura en Windows. (#7446)
  • Se corrigieron segmentos de mensajes finales de Telegram demasiado largos. (#7432)
  • Se corrigió el spam de Telegram sendMessageDraft 400 causado por texto vacío. (#7398)
  • Se corrigió un KeyError en la colección de comandos de Telegram cuando faltaba un controlador de complemento en star_map. (#7405)
  • Se limpió el manejo de apagado de QQ Official WebSocket. (#7395)
  • Se eliminó el campo id no compatible de las cargas útiles de Gemini FunctionResponse. (#7386)
  • Se corrigió el manejo de salida del modelo vacío que podía fallar al usar Gemini. (#7377)
  • Se omitió FunctionCallingConfig cuando solo hay herramientas nativas presentes. (#7407)
  • Se agregaron constantes faltantes del proyecto ChatUI y pruebas relacionadas. (#7414)
  • Se corrigió la representación en modo oscuro de WebUI y múltiples errores de interacción. (#7173)
  • Se evitó que los botones flotantes saltaran durante las transiciones de página. (#7214)
  • Importaciones diferidas de faiss durante el inicio para evitar fallas de inicio en algunos entornos. (#7400)
  • Se mejoró el mensaje de advertencia de token de contexto faltante en el adaptador Weixin OC. (comprometer)
  • Afirmaciones de resultados de herramientas actualizadas para que coincidan con los valores de umbral dinámicos. (comprometer)
