#AstrBot v4.23.5

  • Registro de actualización (chino simplificado)
  • Changelog(inglés) <a id="chino"></a>

¿Qué ha cambiado?

Nuevo

  • WebUI ChatUI agrega soporte para la reedición de mensajes, generación de respuestas de IA desde la regeneración, panel de consulta de sucursales (puede verlo seleccionando el contenido de la respuesta de IA) y punto de control de sesión. (#7673)
  • WebUI ChatUI se adapta al modo de llamada de herramientas al pensar y fusiona automáticamente el proceso Loop en un panel de barra lateral independiente y lo presenta en una línea de tiempo, lo que mejora enormemente la experiencia del usuario. (#7742)
  • El procesamiento de archivos adjuntos de WebUI ChatUI agrega vista previa y verificación de dedup, mejora la identificación de los archivos adjuntos y la experiencia de visualización antes de cargarlos, y soluciona el problema de que las burbujas de mensajes del usuario no pueden mostrar las imágenes correctamente. (comprometer)
  • Se agregó soporte EPUB para cargar documentos de la base de conocimientos y se agregó análisis EPUB, lectura de archivos y pruebas relacionadas. (#7594)
  • Agent Loop sin transmisión agrega una nueva herramienta intermedia para llamar a la función de plegado y envío del proceso de mensajes. (#7627)
  • Se reconstruyó el comando /provider para admitir la gestión y visualización de información relacionada con el proveedor a través de comandos. (#7691)
  • Se agregó la capacidad de "mostrar en la parte superior cuando hay nuevas versiones disponibles" en la página del complemento y admite guardar esta preferencia. (#7665)

Optimización

  • Optimice la descripción de FileReadTool, aclare la imagen, la compatibilidad con PDF y DOCX y mejore la capacidad modal de verificación de los resultados de la herramienta. (#7506)
  • Unifique múltiples enlaces de documentos y corrija las entradas de documentos en CLI, configuración, Panel de control y páginas de base de conocimientos. (#7709)

Arreglar

  • Se solucionó un problema por el cual las configuraciones de algunos proveedores de modelos compatibles con OpenAI/Anthropic nacionales o personalizados no estaban disponibles debido a diferencias en las capacidades de la cadena de certificados TLS, el proxy o la lista de modelos. (#7685)
  • Se solucionó un problema por el cual las respuestas normales podían perderse cuando la respuesta del modelo contenía contenido de razonamiento. (#7715)
  • Se solucionó el problema de falla en la solicitud del oficial API de QQ debido a la falta de reintentos bajo DNS o excepciones transitorias de conexión. (#7718)
  • Se solucionó el problema de que RegexFilter no podía aceptar str y re.Pattern al mismo tiempo. (#7633)
  • Se solucionó el problema por el cual el importador de respaldo tenía el riesgo de cruzarse. (#7681)
  • Se solucionó un problema que puede afectar la migración FTS de la base de conocimientos cuando permanece la versión anterior de la tabla documents_fts. (#7706)
  • Se solucionó el problema del bloqueo directo del proveedor del plan de tokens MiniMax cuando el modelo configurado no está en la lista codificada y se cambió a un mensaje de advertencia. (#7692)
  • Se solucionó el problema por el cual el campo no válido required en el esquema MCP no estaba normalizado, lo que provocaba una excepción en el esquema de la herramienta. (#6077)
  • Se solucionó el problema de procesamiento cuando se envían archivos adjuntos de video a LLM y se agregaron pruebas relacionadas. (#7679) <a id="inglés"></a>

Qué ha cambiado (ES)

Nuevas características

  • Se agregó edición de mensajes en línea, regeneración de un mensaje seleccionado, un panel de hilo y soporte de punto de control de conversación a la página de chat de WebUI. (#7673)
  • Se agregaron vistas previas de archivos adjuntos de chat y verificaciones de firmas de archivos en WebUI para mejorar el reconocimiento y visualización de archivos adjuntos antes de cargarlos. (comprometer)
  • Se agregaron mensajes intermedios almacenados en búfer para el Agent Loop sin transmisión, lo que permite que mensajes de proceso, como llamadas a herramientas, aparezcan en escenarios sin transmisión. (#7627)
  • Se reintrodujo /provider como un comando integrado para ver y administrar información relacionada con el proveedor. (#7691)
  • Se agregó una opción para fijar complementos instalados con actualizaciones disponibles en la parte superior de la página del complemento, con almacenamiento de preferencias persistente. (#7665)
  • Se agregó compatibilidad con EPUB para cargar documentos de la base de conocimientos, incluido el análisis de EPUB, compatibilidad con lectura de archivos y pruebas. (#7594)

Mejoras

  • Se actualizó la descripción de FileReadTool para mencionar la compatibilidad con imágenes, PDF y DOCX, y se mejoraron las comprobaciones de modalidad para los resultados de las herramientas. (#7506)
  • Enlaces de documentación unificada en las páginas de salida, configuración, panel de control y base de conocimientos del CLI. (#7709)

Corrección de errores

  • Se corrigieron las respuestas normales faltantes cuando la salida del modelo contiene contenido de razonamiento. (#7715)
  • Se agregaron reintentos para DNS transitorios y errores de conexión en el flujo QQ Official API. (#7718)
  • Se corrigió RegexFilter para que acepte tanto str como re.Pattern. (#7633)
  • Se corrigió una vulnerabilidad de recorrido de ruta en el importador de respaldo. (#7681)
  • Se eliminaron las tablas documents_fts heredadas cuando estaban presentes para evitar problemas de migración de FTS de la base de conocimientos. (#7706)
  • Se corrigieron fallas de configuración para algunos proveedores de modelos nacionales o personalizados compatibles con OpenAI/Anthropic causados por cadenas de certificados TLS, manejo de proxy o diferencias en la capacidad de la lista de modelos. (#7685)
  • Se modificó el comportamiento del proveedor de planes de tokens MiniMax para advertir en lugar de bloquear cuando un modelo configurado no está en la lista de modelos codificados. (#7692)
  • Se normalizaron indicadores required no válidos en esquemas MCP para evitar errores en el esquema de herramientas. (#6077)
  • Se corrigió el manejo de archivos adjuntos de video para solicitudes de LLM y pruebas relacionadas agregadas. (#7679)
