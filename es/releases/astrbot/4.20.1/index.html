AstrBot v4.20.1

Parche Publicado16 mar 2026 FuenteAstrBotDevs/AstrBot original en inglés

Esta página está traducida automáticamente. El texto original en inglés es la referencia.

#AstrBot v4.20.1

¿Qué ha cambiado?

Nuevo

  • Proveedor MiniMax suplementado. (#6318)
  • Se agregó la función de eliminación por lotes de sesiones en la página WebUI ChatUI. (#6160)
  • Se agregó la configuración de WebUI ChatUI que envía la tecla de acceso directo. (#6272)

Optimización

  • Optimizar la compatibilidad del procesamiento UMO. (#5996)
  • Refactor _extract_session_id para mejorar el procesamiento de ramas de tipo chat. (#5775)
  • Optimice el comportamiento del componente de chat y utilice shiki para la representación de bloques de código. (#6286)
  • Optimice la combinación de colores y la experiencia visual del tema WebUI. (#6263)
  • Optimice el posprocesamiento del componente OneBot @ para evitar problemas de espacio en el análisis del texto del mensaje. (#6238)

Arreglar

  • Se solucionó el problema por el cual providers_config no se sincronizaba después de crear un nuevo proveedor. (#6388)
  • Se corrigió TypeError cuando API devolvió null choices. (#6313)
  • Se solucionó el problema del reintento de devolución de llamada de QQ Webhook que se activaba repetidamente. (#6320)
  • Se solucionó el problema por el cual delta se convertía en None en modo de transmisión, lo que provocaba un error al llamar a la herramienta. (#6365)
  • Se corrigió el error de texto en la descripción del enlace del servicio del modelo. (#6296)
  • Se solucionó un problema por el cual la IA no podía enviar medios cuando el modo de llamada de herramientas estaba configurado en skills-like. (#6317)
  • Se solucionó un problema por el cual los GIF se convertían incorrectamente en imágenes estáticas en el adaptador de Telegram. (#6329)
  • Reemplace la fuente del ícono del proveedor con la dirección CDN de jsDelivr para solucionar problemas de carga de íconos en algunos entornos. (#6340)
  • Se solucionó el problema por el cual los mensajes de emoticones oficiales de QQ no se analizaban en texto legible. (#6355)
  • Se solucionó el problema por el cual la página de resultados de transmisión fallaba cuando la cola de WebChat era anormal. (#6123)
  • Se solucionó el problema por el cual la herramienta de transferencia de subagente se perdía durante el filtrado de complementos. (#6155)
  • Se solucionó el problema de los espacios faltantes en el texto del mensaje Cron y la advertencia de obsolescencia de utcnow(). (#6192)
  • Se corrigió el problema de fluctuación/posicionamiento de navegación hash de la barra lateral cuando se inicia WebUI. (#6159)
  • Se corrigió un error al eliminar ValueError con la clave API eliminada durante el reintento de inicio. (#6193)
  • Se corrigió la referencia del comando de inicio README actualizada a astrbot run. (#6189)
  • Se solucionó el problema por el cual los espacios en blanco se perdían cuando se mencionaba Plain.toDict() en la escena @. (#6244)
  • Se solucionó el problema de la definición repetida de dependencia del proveedor. (#6247)
  • Se solucionó un problema en Telegram por el cual las respuestas ordinarias se juzgaban erróneamente como hilos. (#6174)

Otros

  • Ajuste la configuración de astrbot.service y CI, actualice la versión de acciones GitHub.

Qué ha cambiado (ES)

Nuevas funciones

  • Se agregó un adaptador de proveedor de finalización de chat OpenRouter con soporte para encabezados personalizados (#6436).
  • Proveedor MiniMax agregado (#6318).
  • Se agregó la eliminación de conversaciones por lotes en WebChat (#6160).
  • Se agregaron configuraciones de acceso directo de envío y soporte de localización para la entrada de WebChat (#6272).
  • Se agregó enlace de directorio temporal local en la configuración de YAML (#6191).

Mejoras

  • Compatibilidad de procesamiento UMO mejorada (#5996).
  • _extract_session_id refactorizado para manejo de tipos de chat (#5775).
  • Se mejoró el comportamiento del componente de chat y se utiliza shiki para la representación de bloques de código (#6286).
  • Se mejoró el color del tema WebUI y el comportamiento visual (#6263).
  • Manejo mejorado del espaciado de componentes de OneBot @ (#6238).
  • Mensajes de cierre y validación de la lista de verificación de relaciones públicas mejorados.

Corrección de errores

  • Se corrigió la sincronización faltante de providers_config después de crear nuevos proveedores (#6388).
  • Se corrigió TypeError cuando API devuelve opciones nulas (#6313).
  • Se corrigieron los reintentos de llamada repetidos del webhook QQ (#6320).
  • Se corrigió el manejo de delta nulo de transmisión de llamadas de herramientas para evitar AttributeError (#6365).
  • Se corrigió la redacción del enlace del servicio del modelo en docs/config (#6296).
  • Se corrigió la falla en el envío de medios AI cuando el modo de llamada de herramientas estaba configurado en skills-like (#6317).
  • Se corrigió el envío de GIF como imagen estática en el adaptador de Telegram (#6329).
  • Se reemplazaron las URL de registro de npm con jsDelivr CDN para íconos de proveedores (#6340).
  • Se corrigió el análisis del mensaje facial oficial de QQ en texto legible (#6355).
  • Se corrigió la falla del resultado de la transmisión de WebChat en errores de cola (#6123).
  • Herramientas de transferencia de subagente preservadas durante el filtrado de complementos (#6155).
  • Se corrigió el espaciado de mensajes cron y el uso obsoleto de utcnow() (#6192).
  • Se corrigió la navegación hash inestable de la barra lateral al iniciar (#6159).
  • Se corrigió ValueError en el ciclo de reintento al eliminar una clave API ya eliminada (#6193).
  • Comando de inicio actualizado a astrbot run en archivos README (#6189).
  • Espacio en blanco conservado en Plain.toDict() para @ menciones (#6244).
  • Se eliminaron entradas de dependencias duplicadas (#6247).
  • Se corrigió que la respuesta normal de Telegram se tratara como un hilo de tema (#6174).

Documentación

  • Documentación de acceso/copia de seguridad actualizada de rainyun (#6427).
  • Se actualizaron package.md y documentos de plataforma, incluida la documentación del bot Matrix y Wecom AI.
  • Se corrigió el enlace de invitación de Discord en los documentos de la comunidad.

Tareas

  • Plantillas de relaciones públicas actualizadas/flujo de trabajo de lista de verificación, configuración del servicio de repositorio y comprobaciones automatizadas.
  • Se actualizó la automatización del repositorio y el mantenimiento del formato, y se eliminaron los scripts changelog obsoletos.
