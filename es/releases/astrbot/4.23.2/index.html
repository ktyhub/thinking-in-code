#AstrBot v4.23.2

  • Registro de actualización (chino simplificado)
  • Changelog(inglés) <a id="chino"></a>

¿Qué ha cambiado?

Nuevo

  • Se agregó soporte para SQLite FTS5 en la fase de recuperación escasa de la base de conocimientos, optimizando en gran medida el retraso significativo en la recuperación causado por la fragmentación de 10 000 a 100 000 niveles. (#7648)
  • La plataforma KOOK ha agregado soporte para menciones de roles, incluida la grabación de roles, análisis de eventos, tipo API y pruebas relacionadas. (#7626)
  • Proveedor de plan de token MiniMax agregado. (#7609)
  • Se agregaron enlaces de eventos de complementos on_agent_begin, on_using_llm_tool, on_llm_tool_respond, on_agent_done y se actualizó la documentación de desarrollo de complementos. (#7540)
  • Se habilitó el resaltado de código Shiki para plantillas t2i y se agregaron plantillas de estilo VitePress. (#7501)

Optimización

  • Optimice el procesamiento EmptyModelOutputError, ya no aplique estrictamente la verificación de si el nombre generado por la herramienta del modelo coincide con el conjunto de herramientas y utilice un método guiado para permitir que el modelo genere la llamada de herramienta correcta. (#7375)
  • Optimice el problema por el cual la herramienta SendMessageToUserTool resuelve rutas de archivos relativas dentro de la raíz del espacio de trabajo local. (#7668)

Arreglar

  • Se solucionó el problema de Can not decode content-encoding: br cuando la búsqueda de Bocha devuelve contenido comprimido de Brotli. (#7655)
  • Se solucionó el problema por el cual context_token no persistía al enviar Cron activamente a la cuenta personal de WeChat. (#7595)
  • Se solucionó un problema por el cual el max_tokens predeterminado del Anthropic Provider era demasiado pequeño, lo que provocaba una gran cantidad de truncamientos cuando la herramienta llama a la operación del archivo de salida. (#7593)
  • Se solucionó el problema por el cual Cron last_run_at no se muestra según la zona horaria local en el Panel. (#7625)
  • Se solucionó el problema de continuar silenciosamente cuando falla la programación de la herramienta Cron y devolver un error claro al modelo cuando falla. (#7513)
  • Se solucionó el problema por el cual los grupos de medios de Telegram se tragaban de manera anormal y silenciosa. (#7537)
  • Se solucionó un problema por el cual IndexError puede activarse cuando el recuento del límite de sesión es 0. (#7635)
  • Se corrigió el manejo de errores de carga de la base de conocimientos y las indicaciones de error para mejorar la capacidad de diagnóstico de fallas. (#7534, #7536)
  • Se solucionó el problema 401 del archivo adjunto del chat del Panel. (#7569)
  • Se solucionó el problema por el cual el cuadro de entrada del número del Panel de control se restablecía a 0 fuera de foco cuando no se editaba. (#7560)
  • Solucione el problema de transferencia en modo oscuro de los bloques de código en los elementos de la lista del Panel de control y elimine el valor predeterminado inyectado en ThemeAwareMarkdownCodeBlock. (#7667, confirmar)
  • Se solucionó el problema de que la solicitud del actualizador no admite el proxy SOCKS y se agregaron pruebas relacionadas. (#7615)
  • Corrección de advertencia de importación SCSS de reversión para evitar problemas de compatibilidad relacionados. (#7616) <a id="inglés"></a>

Qué ha cambiado (ES)

Nuevas funciones

  • Se agregó compatibilidad con SQLite FTS5 a la etapa de recuperación dispersa de la base de conocimientos, lo que reduce en gran medida la latencia de recuperación para bases de conocimientos con decenas de miles a cientos de miles de fragmentos. (#7648)
  • Se agregó compatibilidad con menciones de roles KOOK, incluidos registros de roles, análisis de eventos, tipos API y pruebas. (#7626)
  • Se agregó el proveedor del plan de token MiniMax. (#7609)
  • Se agregaron enlaces de eventos de complementos para on_agent_begin, on_using_llm_tool, on_llm_tool_respond y on_agent_done, con documentos de desarrollo de complementos actualizados. (#7540)
  • Se habilitó el resaltado de Shiki para plantillas t2i y se agregó una plantilla estilo VitePress. (#7501)

Mejoras

  • Se mejoró el manejo de EmptyModelOutputError al no exigir estrictamente si los nombres de salida de las herramientas del modelo coinciden con el conjunto de herramientas y, en su lugar, guiar el modelo hacia llamadas de herramientas válidas. (#7375)
  • Resolución de ruta de archivo relativa mejorada dentro de la raíz del espacio de trabajo local para SendMessageToUserTool. (#7668)

Corrección de errores

  • Se corrigieron fallas de búsqueda de Bocha causadas por respuestas comprimidas de Brotli que informaban Can not decode content-encoding: br. (#7655)
  • Se corrigió la persistencia de context_token para envíos Cron proactivos en el adaptador Weixin OC. (#7595)
  • Se aumentó el valor max_tokens predeterminado de Anthropic Provider para evitar un truncamiento excesivo durante la salida de llamadas de herramientas para operaciones de archivos. (#7593)
  • Se mostró Cron last_run_at en la zona horaria local en Dashboard. (#7625)
  • Se devolvieron errores explícitos al modelo cuando falla la programación de la herramienta Cron en lugar de continuar en silencio. (#7513)
  • Se evitó que las excepciones del grupo de medios de Telegram se tragaran silenciosamente. (#7537)
  • Se corrigió un IndexError cuando la sesión rate_limit_count es 0. (#7635)
  • Manejo de errores de carga de la base de conocimientos y mensajes de error mejorados para un mejor diagnóstico. (#7534, #7536)
  • Se corrigieron los errores 401 del archivo adjunto del chat del Panel. (#7569)
  • Se corrigieron las entradas numéricas que se restablecían a 0 en caso de desenfoque cuando el valor no se editaba. (#7560)
  • Se corrigió la propagación del modo oscuro para bloques de código dentro de los elementos de la lista del Panel y se eliminó el valor predeterminado inyectado de ThemeAwareMarkdownCodeBlock. (#7667, confirmar)
  • Se agregó soporte de proxy SOCKS para solicitudes de actualización y pruebas relacionadas. (#7615)
  • Se revirtió la corrección de advertencia de importación SCSS para evitar problemas de compatibilidad relacionados. (#7616)
