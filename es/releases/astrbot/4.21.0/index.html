AstrBot v4.21.0

#AstrBot v4.21.0

¿Qué ha cambiado?

Nuevo

  • Se agregaron filtros de categorías y componentes de interfaz optimizados para el mercado de complementos. (#6762)
  • Se agregó el proveedor del plan de codificación Kimi (compatible con Anthropic API). (#6559)
  • Archivos unificados y renombrados skill.md a SKILL.md. (#6757)
  • Se agregó el interruptor del modo de pensamiento de Ollama. (#5941)
  • Se agregó el proveedor Xiaomi MiMo TTS y STT. (#6643)
  • Se agregaron capacidades de conteo de tokens de contexto multimodal (imágenes, audio y cadenas de pensamiento). (#6596)
  • Se agregó la capacidad de instalar complementos por nombre de metainformación y verificar identificadores importables. (#6530)

Optimización

  • Se redujo kook_type en StrEnum a (str, Enum) para compatibilidad con la versión anterior Python. (#6512)
  • Optimice el procesamiento de mensajes de WebChat: guarde los mensajes con anticipación y mejore la finalización de la transmisión. (#6698)
  • Optimice el diseño del selector de personas móviles en el Panel de control. (#5907)
  • Optimice el Panel, reduzca el rango de fuentes de los íconos MDI y hospede automáticamente las fuentes de Google. (#6532)
  • Utilice Pydantic para reconstruir el modelo de datos del adaptador KOOK para mejorar el rendimiento de verificación y análisis de la estructura de mensajes. (#5719)
  • Ajustar la terminología y expresiones del documento (cambiar "plataforma de mensajes" por "robot", etc.) y optimizar y actualizar el texto de descripción. (#6568)

Arreglar

  • Se solucionó el problema por el cual las funciones del sistema deshabilitadas en las herramientas de búsqueda web no surtían efecto correctamente. (#6584)
  • Omita los lotes de incrustación de bases de conocimientos vacías para evitar cálculos innecesarios. (#6106)
  • Se solucionó un problema por el cual los archivos de obra de Feishu no se convertían correctamente en escenarios STT de Whisper API. (#6078)
  • Se corrigió el proceso de creación y reanudación de la tarjeta Lark cuando se interrumpe la llamada a la herramienta. (#6743)
  • Se solucionó el problema de compatibilidad de codificación de archivos de habilidades en el entorno de Windows. (#6058)
  • Se solucionó un problema por el cual las respuestas HTML renderizadas por separado por WebChat se mostraban incorrectamente. (#6074)
  • Se solucionó el problema de que faltaba el campo items en el esquema de matriz Gemini. (#6051)
  • Se solucionó un problema con las habilidades que usaban rutas de espacio de trabajo codificadas y, en su lugar, usaban rutas reales de la zona de pruebas en el caché. (#6331)
  • Se corrigió el tiempo de espera de llamada de la herramienta subagente, se corrigió tool_call_timeout y se aumentó el tiempo de espera predeterminado de 60 segundos a 120 segundos. (#6713)
  • Se solucionó el problema por el cual la descripción de la imagen no se inyecta cuando falta extra_user_content_parts en skills-like. (#6710)
  • Se solucionó el problema de continuar procesando mensajes de seguimiento posteriores después de /stop. (#6704)
  • Se corrigió el comportamiento del proceso central que interrumpía la espera de la herramienta subagente cuando se detenía. (#5850)
  • Se solucionó el problema de la falta del servicio stdio MCP PATHEXT en la plataforma Windows. (#5822)
  • Se corrigió el mecanismo de reinicio del sondeo de Telegram para reanudar automáticamente el ciclo cuando falla. (#6648)
  • Se solucionó el problema por el cual el estado de seguimiento después de /stop no se borraba, lo que provocaba que los activadores posteriores siguieran ejecutándose. (#6656)
  • Se corrigió el registro de configuración de OpenAI para mejorar la legibilidad y las capacidades de resolución de problemas del agente y API Base. (#6669)
  • Se solucionó el problema de la lógica de truncamiento que eliminaba accidentalmente el único mensaje del usuario en llamadas largas a la herramienta. (#6198)
  • Se solucionó el problema por el cual el truncador eliminaba mensajes de usuario únicos, lo que provocaba que algunos proveedores devolvieran 400. (#6581)
  • Se solucionó el problema por el cual el texto de copia del mensaje no estaba claro cuando la lista blanca de ID estaba vacía. (#6611)
  • Se solucionó el problema de uso del token OpenAI que faltaba en el API oficial de MoonshotAI. (#6618)
  • Mejore la legibilidad y la velocidad de la transmisión de Wecom AI Bot (procesamiento limitador actual) y mejore la experiencia de visualización y retraso. (#6610) -Se solucionó el problema de que desaparecía la respuesta de conexión larga de Wecom. (#6606)
  • Se corrigió el problema de configuración del entorno de compilación nativo/pip durante el tiempo de ejecución del empaquetado de Windows. (#6575)
  • Se corrigió que solo se aprobara la incorporación de dimensions cuando se configura explícitamente para evitar interferencias de parámetros no válidos. (#6432)
  • Se corrigió NameError causado por el decorador register_agent. (#5765)
  • Se solucionó el problema de falla en la consulta del subagente en el escenario de persona predeterminado. (#5672)
  • Se solucionó el problema de falla en la lectura de habilidades en Windows. (#6490)
  • Se corrigió el problema de análisis de frontmatter multilínea de SKILL.md. (#6460)
  • Se solucionó el problema de SQLite database is locked y se agregó procesamiento de tiempo de espera ocupado. (#6474)
  • Se corrigió la restricción del flujo de trabajo que solo permite escenarios de error desencadenados por almacenes ascendentes. (#6531)

Qué ha cambiado (ES)

Nuevas funciones

  • Se agregó filtrado de categorías para complementos del mercado y componentes de interfaz de usuario mejorados.
  • Archivos normalizados y renombrados skill.md a SKILL.md.
  • Se agregó una opción para desactivar el modo de pensamiento en Ollama.
  • Se agregaron proveedores Xiaomi MiMo TTS y STT.
  • Se agregó el proveedor del plan de codificación Kimi con compatibilidad con Anthropic API.
  • Se agregó soporte de recuento de tokens de contexto para contenido multimodal (imágenes, audio y cadena de pensamiento).
  • Se agregó instalación de complementos por nombre de metadatos e identificadores importables validados.

Mejoras

  • Se refactorizó StrEnum a (str, Enum) en kook_type para compatibilidad con versiones anteriores.
  • Manejo mejorado de mensajes de WebChat con guardado proactivo y finalización de transmisión.
  • Diseño simplificado del selector de personas del panel para pantallas móviles.
  • Subconjunto de fuentes de iconos MDI y fuentes de Google autohospedadas en el panel.
  • Implementé modelos de datos de Pydantic para el adaptador KOOK para una mejor recuperación y validación de esquemas.
  • Redacción de la documentación actualizada para terminología de actualizaciones incompletas.

Corrección de errores

  • Se corrigieron funciones del sistema deshabilitadas en las herramientas de búsqueda web.
  • Se omitieron lotes de incrustación de bases de conocimientos vacíos.
  • Archivos de obra Feishu convertidos para Whisper API STT.
  • Creación y renovación de tarjetas Lark diferidas en caso de pausa en la llamada de herramientas.
  • Se agregó un respaldo para las codificaciones de archivos de habilidades de Windows.
  • Respuestas HTML independientes renderizadas como código en WebChat.
  • Los esquemas de matriz Gemini garantizados siempre incluyen items.
  • Se corrigió la resolución de la ruta de habilidades para usar la ruta de la zona de pruebas en caché en lugar de la raíz del espacio de trabajo codificada.
  • Se pasó tool_call_timeout a tareas de subagente sin intervención/cron/en segundo plano y se aumentó el tiempo de espera predeterminado a 120 segundos.
  • Se corrigió que faltara extra_user_content_parts al volver a consultar skills-like, lo que causaba que el título de la imagen no se inyectara.
  • Mensajes de seguimiento rechazados después de la solicitud /stop.
  • La herramienta subagente interrumpida espera hasta detenerse.
  • PATHEXT conservado para servidores stdio MCP en Windows.
  • Se agregó reinicio automático para el ciclo de sondeo de Telegram en caso de falla.
  • Se corrigió la lógica de persistencia de seguimiento después del disparo /stop.
  • Registro base de proxy OpenAI/API mejorado.
  • Se evitó que la lógica de truncamiento eliminara el único mensaje del usuario en conversaciones largas sobre llamadas a herramientas.
  • Se corrigió el truncamiento eliminando el único mensaje de usuario y devolviendo 400 para algunos proveedores.
  • Se actualizó la redacción de sugerencias de configuración vacía de la lista blanca de ID.
  • Se corrigió el uso de tokens con el API oficial de MoonshotAI.
  • Se mejoró la legibilidad y velocidad de transmisión de Wecom AI Bot mediante aceleración.
  • Se evitó que desaparecieran las respuestas de conexión larga de Wecom AI Bot.
  • Establecer el entorno de compilación de tiempo de ejecución de Windows empaquetado para compilaciones nativas de pip.
  • Pase únicamente dimensiones de incrustación cuando se configure explícitamente.
  • Se corrigió el decorador register_agent NameError.
  • Se corrigió el error de búsqueda de subagente cuando se usaba la persona predeterminada.
  • Se corrigieron las habilidades de lectura en Windows.
  • Se corrigió el análisis de frontmatter multilínea en SKILL.md.
  • Se corrigió SQLite database is locked con tiempo de espera de ocupado.
  • Flujos de trabajo restringidos al repositorio ascendente.
