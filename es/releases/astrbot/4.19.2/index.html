AstrBot v4.19.2

#AstrBot v4.19.2

¿Qué ha cambiado?

Nuevo

  • Adaptador de plataforma KOOK integrado (#5658).
  • Se agregó compatibilidad con Emoji de reacción previa de Discord (#5609).
  • Se agregó soporte de Telegram para sendMessageDraft que transmite la salida en tiempo real API (#5726)
  • Admite la capacidad de seguimiento de mensajes cuando el Agente se está ejecutando y los mensajes de seguimiento se inyectan en el Agente en tiempo real (#5484).
  • Integre DeerFlow Agent Runner y optimice la transmisión (#5581).
  • Se agregó un nuevo shell, herramienta ipython que contiene información del sistema operativo para mejorar la tasa de éxito de las llamadas a herramientas en Windows (#5677).
  • Compatibilidad con Sandbox para Shipyard-neo - Compatibilidad con la autoiteración de habilidades (#5028).
  • Se agregó la selección del modo de transmisión ChatUI WebSocket, OpenAPI Chat API admite conexión WebSocket (#5410).
  • Mensaje de respuesta de error personalizado y lógica evasiva de Persona de soporte (#5547).
  • Empaquetar archivos estáticos de WebUI en Wheel y reemplazar los registros de astrbot CLI con inglés (#5665).
  • Interfaz de chat mejorada y experiencia de respuesta móvil (#5635).
  • Optimice la lógica de manejo de fallas del complemento y la experiencia de interacción de lista extendida (#5535).

Arreglar

  • Se corrigió la falta de coincidencia de las palabras clave del parámetro de tiempo de espera de inicialización de MCP (#5743).
  • Se corrigió la condición de carrera de la herramienta MCP que causaba el error "No se puede analizar la finalización" (#5534).
  • Se solucionó el problema de la transmisión transparente directa de URL que no son HTTPS en el adaptador LINE (#5697).
  • Se solucionó el problema del estado personalizado inestable de la barra lateral de WebUI (#5670).
  • Se solucionó el problema por el cual el adaptador KOOK generaba registros de depuración redundantes al recibir mensajes y respuestas de latidos.
  • Se solucionó un problema por el cual la variable de entorno DEMO_MODE no se analizaba correctamente como un valor booleano (#5676).
  • Se solucionó el problema de que el sub-Agente no podía recibir correctamente la ruta de la imagen local (imagen de referencia) (#5579).
  • Se corrigió el comando /model que causaba un comportamiento engañoso al cambiar a un modelo de proveedor diferente (#5578).
  • Se solucionó un problema en los registros de conversaciones donde no se manejaba el desplazamiento de la zona horaria UTC, lo que provocaba excepciones de marca de tiempo (#5580).
  • Se solucionó un problema por el cual las estadísticas duplicadas de la plataforma causaban excepciones al importar copias de seguridad (#5594).
  • Se corrigió que la configuración de max_agent_step no se aplicara a los agentes secundarios (#5608).
  • Se corrigió la lógica de filtrado de búsqueda y clasificación de la lista de complementos (#5559).
  • Se solucionó el problema por el cual no se requería el entorno Node.js al usar uv sync.

Qué ha cambiado (ES)

Nuevas funciones

  • Adaptador de plataforma KOOK integrado (#5658).
  • DeerFlow Agent Runner integrado con soporte de transmisión optimizado (#5581).
  • hazaña (telegrama): admite sendMessageDraft API (#5726)
  • Capacidad integrada de autoiteración de habilidades Neo con gestión del ciclo de vida completo (candidato, lanzamiento, eliminación) a través del sandbox de Shipyard Neo (#5028).
  • Se agregó compatibilidad con emojis de reconocimiento previo de Discord (#5609).
  • Se agregó la selección del modo de transporte WebSocket para la interfaz de chat (#5410).
  • Se agregó información del sistema operativo a las descripciones de herramientas con cobertura de prueba unitaria (#5677).
  • Se agregó manejo de mensajes de seguimiento en ToolLoopAgentRunner (#5484).
  • Se agregó soporte para mensajes de respuesta de error personalizados de persona con lógica alternativa (#5547).
  • Se incluyeron archivos estáticos de WebUI en el paquete wheel y se reemplazaron los registros de astrbot CLI con inglés (#5665).
  • Rendimiento de E/S asíncrono optimizado y cobertura de referencia agregada (#5737).
  • Creación de claves API refactorizada y pruebas unitarias agregadas para rutas API abiertas.
  • Mensajes de error mejorados para fallas de ejecución de IA en corredores de agentes.
  • Interfaz de chat mejorada y capacidad de respuesta móvil (#5635).
  • Manejo de fallas de complementos mejorado y lista de extensiones UX (#5535).

Corrección de errores

  • Se corrigió la falta de coincidencia de palabras clave en el tiempo de espera de inicialización de MCP (#5743).
  • Se corrigió la condición de carrera de las herramientas MCP que causaba el error completion 无法解析 (#5534).
  • Se corrigió el adaptador LINE que permitía el paso directo de URL que no son HTTPS (#5697).
  • Se corrigió el estado de personalización de la barra lateral inestable en WebUI (#5670).
  • Se corrigió el registro de depuración excesivo en el adaptador KOOK para mensajes recibidos y respuestas de latidos.
  • Se corrigió que la variable de entorno DEMO_MODE no se analizara correctamente como booleana (#5676).
  • Se corrigió que el subagente no recibiera correctamente las rutas de la imagen local (imagen de referencia) (#5579).
  • Se corrigió el comportamiento engañoso del comando /model al cambiar a un modelo de un proveedor diferente (#5578).
  • Se corrigió el desplazamiento de la zona horaria UTC no controlado que causaba marcas de tiempo incorrectas en los registros de conversaciones (#5580).
  • Se corrigió un error en la importación de copias de seguridad debido a entradas duplicadas de estadísticas de la plataforma (#5594).
  • Se corrigió que la configuración de max_agent_step no se aplicara a los subagentes (#5608).
  • Se corrigió la lógica de filtrado de búsqueda y clasificación de la lista de complementos (#5559).
  • Se corrigió el requisito de entorno Node.js que faltaba durante uv sync.
