#AstrBot v4.26.8

[4.26.8] - 2026-07-28

Debemos cultivar nuestro jardín. Debemos cultivar nuestros propios jardines.

Hemos lanzado un nuevo mercado de complementos: AstrBot Cloud. Los desarrolladores y usuarios de complementos pueden utilizar esta plataforma para cargar, administrar y explorar complementos de AstrBot. Los datos de los complementos de AstrBot WebUI se redireccionarán a este mercado. Para obtener más detalles, lea: Documentos AstrBot | Publicación del complemento

Hemos lanzado un nuevo sistema de mercado de complementos [AstrBot Cloud] (https://cloud.astrbot.app), una plataforma donde los desarrolladores y usuarios de complementos pueden cargar, administrar y explorar complementos. Los datos para el mercado de complementos dentro de AstrBot WebUI se sincronizarán desde la plataforma. Para obtener más información, vaya a Documentación de AstrBot | Lanzamiento del complemento.

Agregado

  • Se agregaron controles de nivel de registro por complemento al panel y al complemento API. (#9342)
  • Se agregó soporte de configuración de modelo para el proveedor FishAudio TTS. (#9381)
  • Se agregó categorización de registros de plataforma y un conmutador de consola para ocultar las entradas de chat de los usuarios. (#9165)
  • Se agregó un proveedor de integración DashScope con soporte de modelo multimodal. (#9137)
  • Se agregó un explorador de archivos del espacio de trabajo a ChatUI (solo proyectos). (#9432)

Cambiado

  • Citas de respuesta parcial respetadas en mensajes de Telegram. (#9236)
  • Uso de CPU del proceso informado sin bloquear el bucle de eventos. (#9367)
  • Se agregó la asignación de valores predeterminados para los campos de configuración del diccionario. (#9414)

Fijo

  • Se corrigió el acceso a FAISS en rutas de Windows que contienen caracteres que no son ASCII, se restauraron las importaciones diferidas para evitar bloqueos en el inicio y se rechazaron dimensiones no válidas para nuevos índices. (#8323, #9350, #9385)
  • Marcas de tiempo actualizadas mientras se mantiene el bloqueo relevante y el estado del programador cron desacoplado de la sincronización de la base de datos para que los trabajos persistentes siempre se carguen. (#9349, #9419)
  • Se conservaron los puntos de control después de solicitudes fallidas de LLM, se mantuvo el orden de los resultados del lote integrado y se utilizó el proveedor actual al regenerar mensajes. (#9358, #9359, #9241, #9402)
  • Se revisó el texto citado para garantizar la seguridad del contenido, se respetaron los límites del analizador directo de valor cero y se eliminaron los separadores finales de los esquemas de los mensajes. (#9232, #9394, #9390)
  • Se resolvieron conflictos de filtro de fechas de Tavily, opciones de finalización de OpenAI anidadas e incompatibilidades del protocolo de reclasificación de Bailian. (#9234, #9386, #9413)
  • Se manejaron errores de comandos de DingTalk y menciones de texto enriquecido, se devolvieron tipos MIME de imágenes de WebChat correctos y se corrigió la validación del comando de barra diagonal de Discord. (#9389, #9319, #9411)
  • Se muestra el progreso de guardado de la configuración del complemento, se evita el cierre accidental del cuadro de diálogo de persona, se eliminan las barras de desplazamiento duplicadas y se evita que se cuelguen las cargas de complementos locales. (#9327, #9238, #9382, #9406)
  • Se mejoró el rendimiento de la lista de conversaciones y se evitaron actualizaciones asincrónicas obsoletas. (#9226)
  • Se actualizó el modelo MiMo TTS predeterminado a mimo-v2.5-tts. (#9428)
  • Se ignoraron las variables de proxy del sistema cuando no se configuró ningún proxy, lo que impidió que se interceptaran las solicitudes API locales. (#8897)
  • Se conservaron rangos de recuperación dispersos por base de conocimiento durante la fusión de rangos para evitar ordenamiento distorsionado en índices FTS5 independientes. (#9426)
  • La extensión C protegida se recarga para evitar fallas en el proceso. (#9148)

Documentación

  • Se actualizaron los banners README y se recomendó la integración oficial del bot QQ.
  • Se agregó una guía de implementación del escritorio Windows Docker. (#9339)
  • Se ampliaron las guías de publicación de complementos en inglés y chino. (#9415)

Mantenimiento

  • Se actualizaron las dependencias de acciones agrupadas de GitHub y docker/login-action. (#9333, #9416)
  • Fijó a Ruff en 0.15.22. (#9369)
  • Se evitó que las pruebas de ruta del actualizador crearan directorios perdidos. (#9376)

chino

Nuevo

  • Se agregó la capacidad de ajustar los niveles de registro por complemento en la consola y el complemento API. (#9342)
  • Se agregó soporte de configuración de modelo para el proveedor FishAudio TTS. (#9381)
  • Se agregaron categorías de registro de plataforma y un interruptor para ocultar los registros de chat de los usuarios en la consola. (#9165)
  • Se agregó el proveedor DashScope Embedding que admite modelos multimodales. (#9137)
  • Se agregó un explorador de archivos del espacio de trabajo a ChatUI (solo proyectos). (#9432)

Cambiar

  • Los mensajes de Telegram admiten la conservación de referencias de respuesta parcial. (#9236)
  • Las estadísticas de uso de CPU del proceso ya no bloquean el bucle de eventos. (#9367)
  • Complementar la asignación de valores predeterminados para los campos de configuración de tipo diccionario. (#9414)

Arreglar

  • Corrija la lectura y escritura de FAISS en rutas no ASCII de Windows, restaure la importación retrasada para evitar congelaciones en el inicio y rechace configurar dimensiones no válidas para nuevos índices. (#8323, #9350, #9385)
  • Actualizar la marca de tiempo durante el período de bloqueo y desacoplar el estado del programador Cron del estado de sincronización de la base de datos para garantizar que las tareas persistentes siempre estén cargadas. (#9349, #9419)
  • Preservar los puntos de control después de fallas en las solicitudes de LLM, mantener el orden de resultados por lotes integrado y utilizar el proveedor actual al regenerar mensajes. (#9358, #9359, #9241, #9402)
  • Realice comprobaciones de seguridad del contenido en el texto citado, maneje correctamente los límites de análisis directo con un valor de cero y elimine los delimitadores al final del resumen del mensaje. (#9232, #9394, #9390)
  • Se corrigió el conflicto de parámetros del filtro de fecha de Tavily, las opciones de finalización de OpenAI anidadas y los problemas de compatibilidad del protocolo de reordenamiento de Bailian. (#9234, #9386, #9413)
  • Se corrigieron errores de comandos de DingTalk con manejo de menciones de texto enriquecido, tipos MIME de imágenes de WebChat y validación de nombres de comandos de barra diagonal de Discord. (#9389, #9319, #9411)
  • Muestra el progreso de guardado de la configuración del complemento para evitar cerrar accidentalmente la ventana emergente de edición de personalidad, eliminar barras de desplazamiento duplicadas y evitar que la carga del complemento local se atasque. (#9327, #9238, #9382, #9406)
  • Mejore el rendimiento de la lista de sesiones y evite actualizaciones obsoletas causadas por solicitudes asincrónicas. (#9226)
  • Modelo predeterminado MiMo TTS actualizado a mimo-v2.5-tts. (#9428)
  • Ignore las variables del proxy del sistema cuando no esté configurado ningún proxy para evitar que se intercepten las solicitudes API locales. (#8897)
  • Preservar clasificaciones de búsqueda dispersas de cada base de conocimiento durante la fusión de clasificaciones para evitar la distorsión del orden de los resultados entre índices FTS5 independientes. (#9426)
  • Se agregó protección para la sobrecarga de la extensión C para evitar fallas en el proceso. (#9148)

Documentación

  • Se actualizó el banner README y se recomendó el uso del acceso oficial al robot QQ.
  • Se agregó la guía de implementación del escritorio Windows Docker. (#9339)
  • Guía de lanzamiento de complementos ampliada en chino e inglés. (#9415)

Mantenimiento

  • Grupo de dependencia de acciones GitHub actualizado y docker/login-action. (#9333, #9416)
  • Se corrigió Ruff a 0.15.22. (#9369)
  • Evite las pruebas de ruta del actualizador que crean directorios residuales. (#9376) [4.26.8]: https://github.com/AstrBotDevs/AstrBot/compare/v4.26.7...v4.26.8
