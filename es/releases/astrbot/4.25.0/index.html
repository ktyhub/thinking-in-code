#AstrBot v4.25.0

  • Registro de actualización (chino simplificado)
  • Changelog(inglés) <a id="chino"></a>

¿Qué ha cambiado?

Arreglar

  • Se solucionó el problema por el cual no se reconocía el audio Tencent SILK con el prefijo \x02, lo que provocaba que fallara la conversión ffmpeg posterior. (#8009)
  • Se solucionó el problema por el cual el error no se exponía hacia arriba cuando no se podía enviar el mensaje multimedia personal de WeChat. (#8175)
  • Se corrigió el error de llamada a la herramienta de Claude API al devolver el parámetro None a una herramienta sin parámetros. (#8136) -Se solucionó el problema de que register_platform_adapter_type y register_permission_type no transmitían correctamente **kwargs de forma transparente. (#8141)
  • Se solucionó un problema que podía causar un bloqueo en la inicialización cuando la configuración del peso de la madera MiniMax TTS estaba vacía o era ilegal JSON.

Nuevas funciones

  • Se agregaron adaptadores de proveedor Ollama Embedding y NVIDIA NIM Embedding. (#8104)
  • Se agregó la capacidad de crear creaciones con un solo clic escaneando el código QR de Feishu. (#8191)
  • Se agregó la capacidad de creación con un solo clic escaneando el código QR en DingTalk. (#8198)
  • Se agregó un nuevo proceso de inicio de sesión con código QR al crear WeChat personal. Después de seleccionar WeChat personal, el código QR se mostrará directamente en la ventana emergente de creación. Después de iniciar sesión correctamente, se guardará la configuración del robot. (#8196)

Optimización

  • Optimice el procesamiento del estado de inicio de sesión personal de WeChat: limpie el estado de inicio de sesión anterior cuando la interfaz devuelva el tiempo de espera de la sesión para evitar continuar con sesiones no válidas de alta frecuencia. (#8196)
  • Optimice la calidad de conversión de audio AMR y reutilice la lógica de conversión de audio común para simplificar la implementación de la conversión de Opus. (#8153)
  • Optimice la lógica de selección de recursos de WebUI: cuando la versión del Panel de control en data/dist es anterior a la versión principal actual, se da prioridad al uso del Panel de control integrado en el paquete para evitar problemas de compatibilidad causados por recursos de front-end antiguos. (#8172)
  • El panel agrega compatibilidad con fuentes Noto Sans para mejorar el efecto de visualización del texto en varios idiomas, como el texto cirílico. (#8015)
  • Optimice la sincronización automática del estado de desplazamiento de la consola, para que pueda restaurarse y sincronizarse correctamente con el componente de visualización del registro después de la actualización. (#8186)
  • Documentos actualizados de Feishu, DingTalk y de la plataforma personal WeChat, instrucciones de inicio de sesión/creación de códigos QR complementadas, recordatorio de activación de permisos de Feishu y proceso de creación de nueva versión personal de WeChat.
  • Se actualizó la documentación de desarrollo del complemento AI para aclarar que context.register_llm_tool() ha quedado obsoleto y se agregaron requisitos de análisis de parámetros de cadena de documentación de la herramienta LLM. (#8178) <a id="inglés"></a>

Qué ha cambiado (ES)

Nuevas características

  • Se agregó la configuración QR one-click para Feishu / Lark. Al crear un bot, los usuarios pueden elegir Feishu China o Lark Global, escanear el código QR y completar automáticamente app_id, app_secret y la configuración del dominio. AstrBot también recupera el nombre del bot para la visualización del ID de configuración generado. (#8191)
  • Se agregó la configuración QR one-click para DingTalk. Los usuarios pueden crear o vincular una aplicación DingTalk escaneando un código QR, completando automáticamente ClientID y ClientSecret, mientras la configuración manual permanece disponible. (#8198)
  • Se agregó inicio de sesión QR durante la creación del bot personal WeChat. El cuadro de diálogo de creación ahora muestra el código QR de inicio de sesión directamente y permite guardarlo después de iniciar sesión correctamente. (#8196)
  • Se agregaron adaptadores de proveedor Ollama Embedding y NVIDIA NIM Embedding. (#8104)

Mejoras

  • Se mejoró el manejo del estado de inicio de sesión de WeChat personal al borrar el estado de inicio de sesión obsoleto cuando el API informa el tiempo de espera de la sesión, evitando solicitudes repetidas contra una sesión no válida. (#8196)
  • Calidad de conversión de audio AMR mejorada y conversión de Opus simplificada al reutilizar la ruta de conversión de audio compartida. (#8153)
  • Selección de recursos de WebUI mejorada: cuando data/dist contiene un Panel anterior a la versión principal actual, AstrBot ahora prefiere el Panel incluido para evitar problemas de compatibilidad de frontend obsoletos. (#8172)
  • Se agregó compatibilidad con Noto Sans al Panel para una mejor representación del texto cirílico y multilingüe. (#8015)
  • Sincronización mejorada del estado de desplazamiento automático de la consola para que la preferencia restaurada se aplique al componente de visualización del registro después de la actualización. (#8186)
  • Documentos actualizados de la plataforma Feishu/Lark, DingTalk y Personal WeChat con instrucciones de configuración/inicio de sesión de QR, recordatorios de permisos de Feishu y el nuevo flujo de creación de Personal WeChat.
  • Se actualizó la guía de desarrollo del complemento AI para aclarar que context.register_llm_tool() está obsoleto y para documentar el formato de argumento de cadena de documentación de la herramienta LLM requerido. (#8178)

Corrección de errores

  • Se corrigió el audio Tencent SILK con un byte \x02 inicial que no se detectaba, lo que podría causar fallas en la conversión de ffmpeg. (#8009)
  • Se corrigieron fallas en el envío de medios personales de WeChat que no aparecían correctamente. (#8175)
  • Se corrigió el error en las llamadas a herramientas cuando Claude API devuelve argumentos None para herramientas sin parámetros. (#8136)
  • Se corrigió que register_platform_adapter_type y register_permission_type no reenviaran **kwargs correctamente. (#8141)
  • Se corrigió que la inicialización de MiniMax TTS fallara cuando la configuración de peso de la madera estaba vacía o era JSON no válida.
