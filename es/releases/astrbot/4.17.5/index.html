#AstrBot v4.17.5

¿Qué ha cambiado?

Nuevo

  • Admite la plataforma de robot oficial QQ para enviar mensajes Markdown para mejorar las capacidades de presentación de mensajes de texto enriquecidos (#5173).
  • Se agregó la capacidad de integrar recomendaciones de complementos aleatorias en el mercado de complementos (#5190).
  • Se agregó un gancho de error de complemento para admitir el procesamiento de enrutamiento de errores personalizado para facilitar el control unificado de excepciones mediante complementos (#5192).

Arreglar

  • Se solucionó el problema de mostrar repetidamente mensajes de error cuando todos los proveedores de LLM no logran reducir la interferencia redundante de informes de errores (#5183).
  • Se solucionó un problema por el cual se mostraban archivos de configuración incorrectos cuando la ventana emergente se cerraba directamente después de ingresar a la administración de configuración desde "Seleccionar archivo de configuración" (#5174).

Optimización

  • Reconstruir la lógica alternativa de telegrama Voice_messages_forbidden, extraerla en un método auxiliar compartido e introducir excepciones escritas BadRequest para mejorar la coherencia en el manejo de excepciones (#5204).

Otros

  • Contenido de documentación relacionado con README actualizado.
  • Realizar formateo de código ruff format.

Qué ha cambiado (ES)

Nuevas funciones

  • Se agregó un gancho de error de complemento para el enrutamiento de errores personalizado, lo que permite el manejo unificado de excepciones en los complementos (#5192).
  • Se agregó soporte de envío de mensajes Markdown para qqofficial para mejorar la entrega de texto enriquecido (#5173).
  • Se agregó el componente MarketPluginCard y se integraron recomendaciones de complementos aleatorios en el mercado de extensiones (#5190).
  • Se agregó soporte para el proveedor aihubmix.
  • Se agregaron notas de soporte de LINE a archivos README multilingües.

Correcciones

  • Se corrigieron mensajes de error duplicados cuando todos los proveedores de LLM fallan, lo que reduce la salida de errores ruidosos (#5183).
  • Se corrigió el perfil mostrado incorrecto después de abrir la administración de configuración desde la selección de perfil y cerrar el cuadro de diálogo directamente (#5174).

Mejoras

  • Se refactorizó la lógica alternativa de Voice_messages_forbidden en un asistente compartido y se introdujo una excepción BadRequest escrita para un manejo de errores más consistente (#5204).

Otros

  • Documentación README actualizada.
  • Formato de código ruff format aplicado.

  • solución: corrija el archivo de configuración incorrecto que se muestra al seleccionar un archivo de configuración para ingresar a la ventana emergente de administración del archivo de configuración y cierre directamente la ventana emergente con @SnowNightt en https://github.com/AstrBotDevs/AstrBot/pull/5174
