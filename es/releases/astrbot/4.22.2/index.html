#AstrBot v4.22.2

¿Qué ha cambiado?

Nuevo

  • Personal WeChat agrega la capacidad de controlar el estado de "La otra parte está escribiendo...". (#6977)
  • La página de gestión de configuración admite copiar y generar nuevas configuraciones a partir de configuraciones existentes, lo que reduce los costos de creación duplicada. (#6785)

Optimización

  • La interfaz text_chat del proveedor de chat agrega el parámetro tool_choice e introduce EmptyModelOutputError unificado y una lógica de reintento mejorada para respuestas vacías del modelo para mejorar la estabilidad en el modo de llamada de herramientas "similar a habilidades". (#7101, #7104)
  • Regresar automáticamente al modo no SSL cuando la configuración del certificado SSL es incorrecta, en lugar de que el programa salga directamente. (#7102)

Arreglar

  • Se solucionó el problema de compatibilidad entre el WeChat Bot personal que no podía enviar archivos multimedia y direcciones de carga CDN y la adaptación al nuevo formato de devolución upload_full_url. #7066)
  • Se solucionó el problema que causaba directamente que la instancia del adaptador WeChat se cerrara después de un tiempo de espera/interrupción de la conexión personal de WeChat y se mejoró el mecanismo de reintento. (#7041
  • Se corrigió el procesamiento de carga de habilidades de WebUI de paquetes zip de múltiples habilidades, lo que permite que un solo paquete zip contenga múltiples habilidades. (#7070)
  • Se solucionaron problemas relacionados con el procesamiento de la interfaz del modelo integrado OpenAI. #7026)
  • El robot QQ no responde al enviar archivos de voz o audio (#7007)
  • ChatUI cambia a una determinada sesión y salta incorrectamente a la última sesión después de actualizar (#6535)
  • Solucionar el problema de compatibilidad de la carga útil de solicitud con Bailian qwen3-rerank e ignorar los parámetros de return_documents no compatibles. (#6222)
  • Se solucionó el problema por el cual LLM se activaba varias veces después de enviar el prefijo de activación en QQ. (#6893)
  • Se corrigieron los problemas de construcción del encabezado de autenticación y del método de llamada GSVI TTS, y se agregaron los valores de configuración predeterminados para adaptarse al nuevo /infer_single API. (#7083)
  • Se solucionó el problema de la falta de dependencia del proxy httpx SOCKS y se restauró la compatibilidad con el proxy SOCKS. (#7093)
  • Se solucionó el problema por el cual el servicio al cliente empresarial de WeChat no podía recurrir a la interfaz de mensajes normal cuando fallaba el envío. (#7012)
  • Se solucionó el problema por el cual no se podía desplazar la página de detalles de administración de conversaciones de WebUI. #6972)
  • Se solucionó el problema de que faltaba el título del mensaje adjunto de Telegram. (#7020)

Qué ha cambiado (ES)

Nuevas funciones

  • Se agregó tool_choice a Tool Loop Agent Runner y se introdujo EmptyModelOutputError con un manejo de reintentos más sólido, lo que mejora la estabilidad para flujos de trabajo de llamada de herramientas "similares a habilidades". (#7101、#7104）
  • Se agregó resolución y validación de configuración SSL para el Panel de control, con retorno automático al modo no SSL cuando la configuración del certificado no es válida. (#7102)
  • Se agregó la capacidad de crear una nueva configuración copiando una existente en la página de administración de configuración. (#6785)
  • Se actualizó el adaptador oficial de QQ para admitir el análisis de mensajes asincrónicos y la preparación de archivos adjuntos. (#7007)
  • Se agregó control de estado de escritura ("el usuario está escribiendo...") para el adaptador Weixin OC.（#6977）

Mejoras

  • Diseño y enrutamiento de la interfaz de usuario del chat refactorizados para que el modo de la interfaz de usuario esté controlado por URL y el estado relacionado tenga como alcance sessionStorage.（#6535）
  • Se mejoró el pulido de la interfaz de usuario web al centrar las sugerencias de la página de extensión y hacer que los bloques de código sean más legibles en modo oscuro. (#6043、#7014）

Corrección de errores

  • Se corrigió el manejo del instalador de habilidades para que un único archivo zip pueda contener múltiples habilidades. (#7070)
  • Se corrigió la compatibilidad de la carga útil de Bailian qwen3-rerank y se ignoraron los parámetros no compatibles de return_documents.（#6222）
  • Se corrigió la activación de la canalización y el flujo de solicitudes en mensajes vacíos. (#6893)
  • Se corrigió la invocación GSVI TTS y la construcción del encabezado de autorización, y se agregaron valores de configuración predeterminados más seguros. (#7083)
  • Se corrigió la dependencia del proxy httpx SOCKS que faltaba para restaurar la compatibilidad con el proxy SOCKS. (#7093)
  • Se corrigió el comportamiento de reintento de sondeo entrante de Weixin OC y la compatibilidad de carga de CDN con el nuevo campo de respuesta upload_full_url. (#7041、#7066）
  • Se corrigió el comportamiento de reserva de WeCom para que el envío pueda volver a intentarse a través del mensaje normal API cuando el KF API devuelva 40096.（#7012）
  • Se corrigieron los subtítulos de los archivos adjuntos que faltaban en los mensajes de Telegram. (#7020)
  • Recuperación reforzada de archivos adjuntos OpenAI y corrección del recorte de sufijos de URL incrustados para evitar fallas de recuperación y eliminación accidental de caracteres de URL. (#7004、#7026）
  • Se corrigieron las regresiones del Panel de control en torno al mapeo de etiquetas de opciones de lista, íconos faltantes y manejo de la rueda del mouse en el contenedor de vista previa. (#6844、#6970、#6972）
