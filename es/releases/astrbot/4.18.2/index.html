#AstrBot v4.18.2

¿Qué ha cambiado?

Nuevo

  • Se agregó la capacidad de detener la sesión del Agente y se optimizó el proceso de procesamiento de solicitudes de detención para admitir el comando /stop para finalizar la ejecución del Agente e intentar no perder los resultados de la ejecución. (#5380).
  • Se agregó soporte para herramientas de uso de computadora en el escenario de transferencia de SubAgent (#5399).
  • Se agregó la capacidad de mostrar los resultados de las llamadas a las herramientas durante la ejecución del Agente para mejorar la observabilidad del proceso de ejecución (#5388).
  • Se agregó un gancho de carga/descarga de complementos para ampliar las capacidades del ciclo de vida de los complementos (#5331).
  • Se agregó capacidad de recarga en caliente después de una falla en la carga del complemento para mejorar el desarrollo del complemento y la eficiencia de recuperación (#5334).
  • Se agregó compatibilidad con la entrada de URL/ruta local de imagen de SubAgente (#5348).
  • Se agregó un elemento configurable de URL de base de salto de publicación en el panel (#5330).

Arreglar

  • Se corrigió el tiempo de espera de 6 segundos codificado para solicitudes de Tavily.
  • Se corrigió que el adaptador OneBot v11 aún se conectara después de apagarlo (#5412).
  • Se corrigió el procesamiento de registros cuando falta la plataforma en la sesión de contexto, se agregaron advertencias y se mejoró la información de solución de problemas.
  • Se solucionó el problema por el cual las dimensiones incrustadas no se transmitían de forma transparente al proveedor API (#5411).
  • Se corrigió la lógica de procesamiento del componente de archivo y se mejoró la compatibilidad de la ruta de la capa del controlador OneBot (#5391).
  • Se solucionó el problema por el cual la herramienta de transferencia de archivos sandbox carecía de verificación de permisos de administrador (#5402).
  • Se corrigió el problema de dependencia circular causado por la canalización y from ... import * (#5353).
  • Se corrigió el problema de análisis cuando el archivo de configuración contiene UTF-8 BOM (#5376).
  • Se solucionó el problema de la ruta de reversión de la copia faltante y el mensaje de error poco claro en ChatUI (#5352).
  • Se corrigió la lógica de procesamiento de conservar el directorio de complementos para evitar un comportamiento anormal del directorio de complementos (#5369).
  • Se solucionó el problema por el cual los segmentos de mensajes del archivo ChatUI no se pueden conservar (#5386).
  • Se solucionó el problema de que .dockerignore excluyera por error el directorio changelogs.
  • Se solucionó el problema por el cual qq-botpy reportaba un error debido a una versión desactualizada de aiohttp (#5316).

Optimización

  • Se completó la internacionalización de la página de diseño del SubAgente y se agregó soporte en varios idiomas (#5400).
  • Se agregaron pruebas relacionadas con el procesamiento de eventos de mensajes y se mejoró la cobertura de accesorios/simulacros del marco de prueba (#5355, #5354).

Qué ha cambiado (ES)

Nuevas funciones

  • Se agregó soporte para herramientas de uso de computadora en escenarios de transferencia de subagente (#5399).
  • Se agregó soporte para mostrar los resultados de las llamadas a herramientas durante la ejecución del agente para una mejor observabilidad (#5388).
  • Se agregaron ganchos de carga/descarga de complementos para extender las capacidades del ciclo de vida del complemento (#5331).
  • Se agregó soporte de recarga en caliente cuando falla la carga del complemento, lo que mejora la recuperación durante el desarrollo del complemento (#5334).
  • Se agregó soporte de entrada de URL de imagen/ruta local para subagentes (#5348).
  • Se agregó control de detención para sesiones de agentes activos y manejo mejorado de solicitudes de detención (#5380).
  • Se agregó una URL base configurable para redirecciones de lanzamiento del panel (#5330).

Correcciones

  • Se corrigió el comportamiento de registro cuando falta información de la plataforma en sesiones de contexto, con advertencias y diagnósticos más claros.
  • Se corrigieron las dimensiones de incrustación faltantes que se pasaban al proveedor APIs (#5411).
  • Se corrigieron problemas de estabilidad de apagado en el adaptador aiocqhttp (#5412).
  • Se corrigió el manejo de componentes de archivos y se mejoró la compatibilidad de rutas en la capa del controlador OneBot (#5391).
  • Se corrigió la falta de protección de administrador para las herramientas de transferencia de archivos sandbox (#5402).
  • Se corrigieron problemas de importación circular relacionados con la canalización y el uso de from ... import * (#5353).
  • Se corrigieron problemas de análisis de configuración cuando los archivos contienen lista de materiales UTF-8 (#5376).
  • Se corrigió la ruta de reversión de copia faltante y mensajes de error poco claros en ChatUI (#5352).
  • Se corrigió el manejo del directorio de complementos reservado para evitar un comportamiento anormal en la ruta del complemento (#5369).
  • Se corrigieron problemas de persistencia de segmentos de archivos ChatUI (#5386).
  • Se corrigió la exclusión accidental del directorio changelogs en .dockerignore.
  • Se corrigieron problemas de compatibilidad causados ​​por un tiempo de espera de 6 segundos codificado en las solicitudes de Tavily.
  • Se corrigieron errores de tiempo de ejecución de qq-botpy causados ​​por versiones demasiado nuevas de aiohttp (#5316).

Mejoras

  • Internacionalización completada para la página de orquestación de subagente (#5400).
  • Se agregó una cobertura de prueba de eventos de mensajes más amplia y accesorios/simulacros mejorados en el marco de prueba (#5355, #5354).
  • Contenido README actualizado y limpieza de formato aplicada en todo el repositorio (formato ruff) (#5375).
