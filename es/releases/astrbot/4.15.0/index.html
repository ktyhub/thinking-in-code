#AstrBot v4.15.0

¿Qué ha cambiado?

⚠️ Recordatorio para los usuarios de v4.14.8: debido al error de la versión v4.14.8, si no está utilizando la aplicación de escritorio Electron AstrBot, se le dirigirá por error a la página de lanzamientos de Github a través del cuadro de diálogo WebUI. Aparece un cuadro de diálogo similar al siguiente: <img ancho="400" alto="710" alt="imagen" src="https://github.com/user-attachments/assets/e9a0e3e1-d41d-42c5-b36c-6b9efe298dac" /> Si este es el caso, no descargue ni instale el paquete de instalación a continuación. Tienes dos formas de actualizar:

  1. Es posible que necesite volver a implementar AstrBot manualmente para actualizar. (Puedes ignorar este recordatorio si puedes abrir la página de actualización para cambiar a la nueva versión)
  2. Descargue [este archivo] (https://github.com/AstrBotDevs/AstrBot/releases/download/v4.15.0/AstrBot-v4.15.0-dashboard.zip), descomprímalo y colóquelo en el directorio de datos de AstrBot, reemplace el directorio dist, luego actualice la interfaz WebUI y haga clic en el botón actualizar nuevamente para restaurar el cuadro de diálogo de actualización original.

Nuevo

  • El robot inteligente empresarial WeChat admite la inserción activa de mensajes y agrega soporte para videos, archivos y otros tipos de mensajes (#4999)
  • La aplicación WeChat empresarial admite la inserción activa de mensajes y optimiza el proceso de procesamiento de audio de la aplicación WeChat empresarial, la cuenta pública de WeChat y el servicio al cliente de WeChat (#4998)
  • El adaptador DingTalk admite la inserción de mensajes activos y agrega soporte para imágenes, videos, audio y otros tipos de mensajes (#4986)
  • Se agregó un botón de eliminación en la ventana emergente de administración de personalidad (#4978)

Arreglar

  • Se solucionaron problemas relacionados con la deduplicación de la herramienta SubAgentes (#4990)
  • Mejorar la lógica de procesamiento de mensajes de streaming de WeCom AI Bot para mejorar la estabilidad de la segmentación y las respuestas de streaming (#5000)
  • Estabilice el comportamiento de instalación de pip en el código fuente y el entorno de empaquetado de Electron, y solucione el problema de activar accidentalmente el cuadro de diálogo de salto al hacer clic en el botón de actualización de WebUI en escenas que no son de Electron (#4996)
  • Se solucionó el problema de recopilación de datos de certificados al crear el backend de escritorio (#4995)
  • Se corrigió el problema de ejecución de instalación de pip en tiempo de ejecución congelado (#4985)
  • Aprovisione OpenSSL a través de vcpkg para Windows ARM64, solucione problemas de preparación de compilación relacionados

Optimización

  • Actualización de la versión dependiente de pydantic (#4980)
  • Ajustar la configuración de CI del espacio de nombres GHCR

Qué ha cambiado (ES)

Nuevas funciones

  • Gestión de herramientas de persona mejorada y localización de interfaz de usuario mejorada para la orquestación de subagentes (#4990)
  • Se agregó envío de mensajes proactivo para WeCom AI Bot, con soporte para videos, archivos y más tipos de mensajes (#4999)
  • Se agregó envío de mensajes proactivo para la aplicación WeCom y manejo de audio mejorado para la aplicación WeCom, la cuenta oficial de WeChat y el servicio al cliente de WeCom (#4998)
  • Adaptador Dingtalk mejorado con inserción proactiva y soporte para tipos de mensajes de imagen, video y audio (#4986)
  • Se agregó un botón de eliminación al cuadro de diálogo de administración de personas para una mejor usabilidad (#4978)

Correcciones

  • Manejo mejorado de mensajes de transmisión en WeCom AI Bot para una mejor estabilidad de respuesta segmentada y de transmisión (#5000)
  • Se estabilizó el comportamiento de instalación de pip en entornos empaquetados de origen y Electron, y se corrigió el cuadro de diálogo de redireccionamiento inesperado cuando clicking actualizaba la WebUI en modo no Electron (#4996)
  • Se corrigió la recopilación de datos de certificados en la compilación de backend de escritorio (#4995)
  • Se corrigió la ejecución de instalación de pip en tiempo de ejecución congelado (#4985)
  • Preparé OpenSSL a través de vcpkg para el flujo de compilación de Windows ARM64.

Mejoras

  • Versión de dependencia pydantic actualizada (#4980)
  • Configuración de CI actualizada para el espacio de nombres GHCR
