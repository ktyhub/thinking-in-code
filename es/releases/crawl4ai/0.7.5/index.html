#crawl4ai v0.7.5

🚀 Crawl4AI v0.7.5: Ganchos Docker y actualización de seguridad

🎯 Novedades

🔧 Sistema de ganchos Docker

Inyecte funciones Python personalizadas en 8 puntos clave de canalización para autenticación, optimización del rendimiento y procesamiento de contenido.

API basado en funciones con soporte IDE:

from crawl4ai import hooks_to_string

async def on_page_context_created(page, context, **kwargs):
    """Block images to speed up crawling"""
    await context.route("**/*.{png,jpg,jpeg,gif,webp}", lambda route: route.abort())
    return page

hooks_code = hooks_to_string({"on_page_context_created": on_page_context_created})

8 puntos de gancho disponibles: on_browser_created, on_page_context_created, before_goto, after_goto, on_user_agent_updated, on_execution_started, before_retrieve_html, before_return_html

🤖 Integración LLM mejorada

  • Parámetro de temperatura personalizado para el control de la creatividad.
  • Soporte multiproveedor (OpenAI, Gemini, puntos finales personalizados)
  • configuración base_url para modelos autohospedados
  • Integración mejorada de Docker API

🔒 Preservación HTTPS

La nueva opción preserve_https_for_internal_links mantiene protocolos seguros durante el rastreo, algo fundamental para sesiones autenticadas y aplicaciones preocupadas por la seguridad.

🛠️ Correcciones de errores importantes

  • Procesamiento de URL: Se corrigió la preservación del signo '+' en los parámetros de consulta (#1332)
  • Autenticación JWT: problemas de validación JWT Docker resueltos (#1442)
  • Dramaturgo Sigilo: Se corrigió la integración de funciones de sigilo (#1481)
  • Configuración de proxy: análisis mejorado con la nueva estructura proxy_config
  • Gestión de memoria: Se corrigieron fugas en sesiones de larga duración.
  • Serialización Docker: errores de codificación JSON resueltos (#1419)
  • Proveedores de LLM: Se corrigió la integración de proveedores personalizados para el rastreador adaptativo (#1291)
  • Rendimiento: fallos resueltos en la estrategia de retroceso (#989)

📦 Instalación

PyPI: instalación de pip crawl4ai == 0.7.5

Docker: docker extrae código tío/crawl4ai:0.7.5 docker extrae tíocode/crawl4ai:último

Plataformas compatibles: Linux/AMD64, Linux/ARM64 (Apple Silicon, AWS Graviton)

⚠️ Cambios importantes

  1. Python 3.10+ Requerido (actualizado desde 3.9)
  2. Parámetro de proxy obsoleto: use la nueva estructura proxy_config
  3. Nueva dependencia: se agregó cssselect para un mejor manejo de CSS
