Notas

Esta nueva versión candidata de Maven 4 se lanza para obtener comentarios de los usuarios. Maven 4 tiene algunas cosas restringidas en comparación con Maven 3, así que asegúrese de ejecutar la herramienta mvnup antes de intentar proyectar con Maven 4.

Error de configuración del Bean

Se ha encontrado un error en el sistema de configuración del bean donde el estado de accesibilidad del campo se almacena en caché globalmente. Esto puede provocar que falle la inyección de configuración del complemento cuando se accede al mismo campo de configuración varias veces o en diferentes contextos durante una compilación. Esto afecta particularmente a las pruebas unitarias del complemento.

Esto se solucionará con el número 11433 en la próxima versión.

Problema de concurrencia en v4 API

Se encontró un problema de concurrencia en Maven 4 API (aún en modo de vista previa) y se solucionará en el n.° 11428 en la próxima versión.

embalaje de lista de materiales

Se ha encontrado otro error en la forma en que se procesan los proyectos de BOM. Cuando un proyecto utiliza paquetes de BOM, el POM del consumidor no se convierte correctamente al paquete de POM estándar y, en algunos casos, se podrían perder las versiones de dependencia.

Esto se solucionará con el n.° 11427 en la próxima versión.

macOS: Gatekeeper puede bloquear la biblioteca nativa JLine en el primer uso

En macOS (especialmente Apple Silicon), es posible que la primera invocación de mvn no cargue la biblioteca del terminal nativo JLine con un error como:

java.lang.UnsatisfiedLinkError: .../libjline-native/Mac/arm64/libjlinenative.jnilib: dlopen(...): code signature ... not valid for use in process: library load disallowed by system policy

Esto ocurre cuando la distribución binaria se descarga a través de un navegador web, que aplica el atributo com.apple.quarantine extended.

Solución alternativa (solución única):

xattr -r -d com.apple.quarantine /path/to/apache-maven-4.0.0-rc-5/lib/jline-native

Método de descarga recomendado (evita el problema por completo):

curl -L -O https://archive.apache.org/dist/maven/maven-4/4.0.0-rc-5/binaries/apache-maven-4.0.0-rc-5-bin.tar.gz
tar -xzf apache-maven-4.0.0-rc-5-bin.tar.gz

Este es un problema conocido #10747 y se solucionará en una versión futura.
