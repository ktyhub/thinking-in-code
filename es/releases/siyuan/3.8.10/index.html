siyuan v3.8.10

Descripción general

Esta versión agrega títulos de documentos enriquecidos, subelementos de bases de datos y vistas relacionadas, memoria a largo plazo con IA a nivel de espacio de trabajo y un editor Markdown liviano incorporado.

Los árboles de documentos manejan directorios grandes de manera más eficiente, mientras que los documentos unificados y las rutas de navegación en bloque hacen que la navegación sea más consistente. Otras mejoras incluyen hojas inferiores móviles, solicitudes HTTP en plantillas, tamaños de página PDF personalizados, selección de direcciones de sincronización LAN y filtrado de compatibilidad de bazar.

Changelog

A continuación se detallan los cambios en esta versión.

Mejora

  • Soporta documentos unificados y bloquea migas de pan
  • Admite títulos de documentos enriquecidos y conserva barras diagonales en los nombres de los cuadernos
  • Mejorar el rendimiento de navegación del árbol de documentos y el acceso a directorios grandes
  • Admite visibilidad y orden del botón de ruta de navegación en perfiles de apariencia
  • Soporte para convertir bloques incrustados en bloques regulares o referencias de bloques
  • Soporte para configurar una clave Exa API para búsqueda web integrada
  • Subelementos de la base de datos de soporte
  • Soporta solicitudes HTTP en plantillas
  • Soporta memoria a largo plazo a nivel de espacio de trabajo para IA
  • Mejorar el tamaño, la alineación y los colores de la entrada del resumen del mapa mental
  • Mejorar la adaptación de la barra de navegación de extremo a extremo de Android
  • Mejorar la capacidad de respuesta al cambio de tamaño de la ventana flotante
  • Mejorar la búsqueda de palabras clave para texto que contenga apóstrofes
  • Admite tamaños de página PDF personalizados
  • Mejorar el acceso móvil para deshacer y rehacer a través del menú Más
  • Soporte para configurar la visibilidad de la barra del muelle flotante
  • Soporta reproducción en bucle para bloques de vídeo
  • Admite un editor Markdown ligero incorporado
  • Soporte para desactivar el proxy de puerto fijo con una opción de línea de comandos
  • Mejorar la creación de encabezados de tablas de varias filas
  • Mejorar la coherencia del diálogo móvil con las hojas inferiores
  • Mejorar la eliminación de etiquetas con la eliminación opcional de las entradas de la base de datos recopiladas automáticamente
  • Admite vistas de bases de datos relacionadas en los detalles de entrada
  • Mejorar la selección de dirección de sincronización LAN en entornos VPN y de interfaz múltiple
  • Soporte para filtrado y clasificación de compatibilidad de paquetes de bazar por primera fecha de lanzamiento

Refactorizar

  • Migrar el proceso principal de Electron de escritorio a módulos estrictos TypeScript

Desarrollo

  • Admite la apertura de menús de documentos y cuadernos mediante el complemento API
