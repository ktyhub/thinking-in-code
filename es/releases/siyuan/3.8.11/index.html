siyuan v3.8.11

Aviso de actualización

Formatos de base de datos

  • Texto enriquecido de clave principal (formatos 15 y 16). El texto enriquecido en línea guardado en formato 15 en versiones preliminares anteriores sigue siendo legible. Al guardar un nuevo bloque de texto enriquecido en una clave principal, incluido texto con imágenes, se actualiza la base de datos al menos al formato 16. Compatibilidad con clave principal
  • Imágenes en línea en campos de texto ordinarios (formato 17). Guardar la primera imagen en línea en un campo de texto ordinario actualiza esa base de datos al formato 17. Compatibilidad de campos de texto El simple hecho de abrir una base de datos no activa estas actualizaciones. La versión 3.8.10 admite formatos de bases de datos hasta 14. Un client solo puede abrir bases de datos en los formatos que admite. Actualice todos los dispositivos que sincronicen o accedan a los mismos datos antes de usar los nuevos formatos. Haga una copia de seguridad de su espacio de trabajo de antemano. Para revertir, restaure una instantánea completa previa a la actualización.

Otros cambios de compatibilidad

  • Memoria a largo plazo con IA. La restauración de una instantánea del espacio de trabajo ahora revierte tanto los registros de memoria como su estado de revocación. Restaurar una instantánea anterior a que se olvidara un recuerdo puede hacer que esté disponible nuevamente si aún pasa las comprobaciones de validez habituales. Memoria a largo plazo
  • Kernel API. Las solicitudes JSON manejadas por contratos API tienen un límite de cuerpo de 32 MiB, con un límite de 64 KiB para loginAuth. Las solicitudes que exceden estos límites devuelven el código -1. Contratos API

Descripción general

Esta versión agrega texto enriquecido y edición de bloques en las claves primarias de la base de datos, un selector de fecha incorporado, edición de color unificada y exploración y restauración de instantáneas de complementos. Los mapas mentales admiten estilos personalizados de nodos y conectores y conexiones de forma libre entre nodos. El editor de Markdown independiente agrega buscar y reemplazar, mientras que macOS obtiene vistas previas de Markdown Quick Look sin conexión. Vea la descripción general del lanzamiento: YouTube

Changelog

A continuación se detallan los cambios en esta versión.

Mejora

  • Admite un selector de fecha integrado y mejora la edición de fecha y hora
  • Admite edición de color unificada con HEX, RGB y un selector nativo
  • Admite texto enriquecido y edición de bloques en claves primarias de bases de datos
  • Admite vistas previas de Markdown Quick Look sin conexión en macOS
  • Soporte para elegir si restaurar las posiciones de lectura de documentos
  • Soporta navegación y restauración de instantáneas de complementos
  • Mejorar la visualización del icono del proceso del kernel en Linux
  • Admite controles de íconos de entrada separados para claves primarias de bases de datos y campos de relación/resumen
  • Soporta detección de proxy del sistema KDE en Linux
  • Admite estilos y formas de conectores por nodo en mapas mentales
  • Reducir la sangría del árbol de documentos para mejorar la legibilidad
  • [Admite relaciones de mapas mentales de forma libre con rutas configurables y patrones de líneas] (https://github.com/siyuan-note/siyuan/issues/21384)
  • Soporte para ignorar reglas para la limpieza de activos no utilizados
  • Conservar el contexto del documento al seguir referencias a bloques visibles
  • Mejorar el arrastre de la hoja inferior del móvil
  • Soporte para buscar y reemplazar en el editor Markdown independiente
  • Soporta expandir o contraer resultados de búsqueda agrupados de forma predeterminada

Corrección de errores

  • La recopilación automática de bloques continúa después de eliminar el bloque de la base de datos
  • Los archivos adjuntos HTML locales integrados se abren en un navegador externo en iOS
