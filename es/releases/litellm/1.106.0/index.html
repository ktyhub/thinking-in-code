Verificar firma de imagen Docker

Todas las imágenes LiteLLM Docker están firmadas con cosign. Cada versión está firmada con la misma clave introducida en commit 0112e53. Verifique usando el hash de confirmación fijado (recomendado): Un hash de confirmación es criptográficamente inmutable, por lo que esta es la forma más sólida de garantizar que está utilizando la clave de firma original:

cosign verify \
  --key https://raw.githubusercontent.com/BerriAI/litellm/0112e53046018d726492c814b3644b7d376029d0/cosign.pub \
  ghcr.io/berriai/litellm:v1.106.0

Verifique usando la etiqueta de lanzamiento (conveniencia): Las etiquetas están protegidas en este repositorio y se resuelven con la misma clave. Esta opción es más fácil de leer pero se basa en reglas de protección de etiquetas:

cosign verify \
  --key https://raw.githubusercontent.com/BerriAI/litellm/v1.106.0/cosign.pub \
  ghcr.io/berriai/litellm:v1.106.0
