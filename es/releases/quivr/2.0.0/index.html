quivr v2.0.0

##Quivr 2.0.0

Quivr es un motor de código abierto para contenido que sigue llegando. Su aplicación, o las fuentes de Quivr (RSS, buzones de correo de Microsoft 365, listas X), le envían documentos. Quivr guarda todas las versiones de cada documento y permite realizar búsquedas en cuestión de segundos, por palabras clave, por significado o ambos. También compara cada documento nuevo con sus alertas guardadas. Quivr no tiene interfaz de usuario: su aplicación se comunica con él a través de HTTP API y los agentes de IA lo usan a través de quivr mcp.

2.0.0 es la primera versión estable del Quivr reescrito. Los alfas eran para evaluación. A partir de esta versión, Quivr hace promesas que puede aprovechar.

Lo que promete 2.0

  • Un API estable. El HTTP API mantiene la ruta /v0 para cada versión 2.x. Una versión 2.x solo agrega: nuevos puntos finales, campos opcionales, campos de respuesta y valores de enumeración. Un cambio que podría interrumpir el funcionamiento de un client espera hasta la próxima versión importante.
  • Actualizaciones que conservan sus datos. Una actualización de una versión 2.x a otra ejecuta quivr migrate, luego ejecuta el trabajador y el API, con sus datos en su lugar.
  • Complementos que verifican su compatibilidad. Un complemento declara las versiones del complemento API que admite y Quivr se niega a activar una que no puede ejecutar.
  • Borrar estado de cada característica. Todo lo que aparece en la documentación es estable en 2.x, excepto una breve lista de características experimentales, cada una marcada en su página: herramientas de medición de búsqueda, reclasificación de Jev y alertas juzgadas por Jev, el host vectorial dedicado y el binario quivr-autoscaler.

Versiones y compatibilidad tiene los detalles. Límites conocidos enumera lo que 2.0 aún no hace: busca solo texto, no tiene OCR, no tiene cuentas de usuario y tiene límites de tamaño por documento y por búsqueda.

Empezar

  • Pruébelo localmente: clone el repositorio, ejecute make dev, luego siga el Inicio rápido, aproximadamente quince minutos.
  • Instálelo en un servidor a partir de las imágenes de lanzamiento firmadas (linux/amd64): consulte Ejecutar Quivr en una máquina o Implementar y configurar Quivr para Railway y Kubernetes.
  • Comprendalo primero: Conceptos básicos y Cómo funciona Quivr.

Procedente de un 2.0.0 alfa

No se admite la actualización de una instalación alfa existente. Inicie una nueva instalación de 2.0.0 o exporte sus documentos desde la versión alfa y envíelos a la nueva.

Desde 2.0.0-alpha.7

  • Seguridad:
    • Quivr y sus imágenes están construidas con Go 1.27.3, para CVE-2026-111943;
    • golang.org/x/net, certifi, pillow y curl y brotli de la imagen SeaweedFS están parcheados.
  • La búsqueda se recupera después de reiniciar la base de datos, con sus buffers restaurados y su trabajo de hidratación limitado.
  • Importaciones:
    • los recuentos de colas permanecen disponibles durante las importaciones continuas;
    • el escalador automático agrega trabajadores en masa para las importaciones de conectores.
  • Documentación:
    • reescrito para los recién llegados, con nuevas páginas: Cómo funciona Quivr, un glosario, Versiones y compatibilidad, y Límites conocidos;
    • Las advertencias de "etapa de evaluación" desaparecieron.

La lista completa de cambios desde la primera versión alfa se encuentra en CHANGELOG.md.
