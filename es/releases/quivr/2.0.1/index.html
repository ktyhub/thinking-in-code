quivr v2.0.1

Quivr 2.0.1

2.0.1 es una versión de seguridad. No cambia ningún API, ninguna configuración ni datos almacenados. Actualice cualquier instalación de 2.0.0.

Correcciones de seguridad

  • Weaviate 1.39.13 reemplaza a 1.39.10 como base de datos de búsqueda. Rechaza las cadenas de certificados TLS basadas en los ocho certificados intermedios eMudhra filtrados (CVE-2026-111943). Weaviate utiliza TLS para copias de seguridad, OIDC y módulos modelo.
  • Python 3.12.16 reemplaza a 3.12.15 en las imágenes de incrustación del núcleo, el complemento y la CPU (CVE-2026-115557).
  • libbrotli1 1.0.9-2+deb12u1 ahora está en la imagen de incrustación de TEI (CVE-2026-111497).

Actualización desde 2.0.0

  1. Haga una copia de seguridad del volumen de la base de datos de búsqueda, como antes de cualquier actualización de la base de datos.
  2. Implemente las imágenes 2.0.1 y el nuevo pin Weaviate de deploy/infrastructure.json. Para una instalación en una sola máquina, utilice el paquete de composición 2.0.1 adjunto a esta versión.
  3. Mantenga el mismo volumen de Weaviate.

Weaviate 1.39.10 a 1.39.13 es una actualización de parche dentro de una versión menor, por lo que los datos almacenados permanecen como están: sin reindexación ni migración de Quivr. La prueba que actualiza un volumen 1.37.15 a través de 1.38.20 a 1.39.13, luego verifica la búsqueda léxica, semántica e híbrida, pasa en esta versión.

Las imágenes de lanzamiento están firmadas y contienen SBOM, como se describe en [Versiones de seguridad de Quivr] (https://docs.quivr.thevibecompany.co/run-quivr/security).

Corrección de errores

  • implementar: pin Weaviate 1.39.13 para CVE-2026-111943 (#3973) (191d35f)
  • imágenes: rebase en Python 3.12.16 y parche brotli en TEI (#3974) (84e5c4e)
