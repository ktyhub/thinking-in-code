spring-ai-alibaba v1.1.2.0

Parche Publicado2 feb 2026 Fuentealibaba/spring-ai-alibaba original en inglés

Esta página está traducida automáticamente. El texto original en inglés es la referencia.

primavera-ai-alibaba v1.1.2.0

Resumen

Esta versión actualiza Spring AI a 1.1.2, agrega compatibilidad con Agent Skills para Agent Framework, agrega ejecución paralela de subagente para agentes de flujo de trabajo (LlmRouting, Supervisor), extiende el gráfico con bordes condicionales paralelos, estrategia de agregación paralela (allOf y anyOf), ejecución de herramientas asíncronas y retorno directo de herramientas. También incluye correcciones de serialización y MergeStrategy, correcciones de administración/UI y actualizaciones de documentación.

Consulte la <a href="https://java2ai.com/docs/versions/" target="_blank">documentación</a> para obtener más detalles.

Características

Agente

  • <a href="https://java2ai.com/docs/frameworks/agent-framework/tutorials/skills" target="_blank">Habilidades del agente en ReactAgent</a> (#3975): capacidades de habilidades integradas en ReactAgent, admite habilidades y divulgación demasiado progresiva.
  • Soporte de patrón multiagente integrado: admite enrutamiento, supervisor, supervisor (agente como herramienta), transferencias, habilidades, etc., patrones de multiagente; Se agregó soporte de ejecución paralela para patrones de enrutamiento y supervisor.
  • Compatibilidad con ganchos de agente de flujo (#3983): todos los agentes de flujo (enrutamiento, supervisor, bucle, secuencial, etc.) admiten ganchos personalizados.
  • Nuevo agente API (#4031) — Nuevo streamMessages API para transmisión de mensajes simplificada; Nuevos métodos de sobrecarga invoke y call para entradas adicionales.
  • Ejecución de herramientas asíncronas y paralelas (#4037): admite la ejecución de herramientas en paralelización y ejecución de herramientas asincrónicas.
  • Tool returnDirect (#4139) — Compatibilidad con el comportamiento de la herramienta returnDirect.
  • ToolContextHelper (n.° 4163): clase auxiliar para el acceso a metadatos en el contexto de la herramienta (correcciones n.° 3110).

Gráfico

  • Bordes condicionales paralelos (#4027): los bordes condicionales admiten la ejecución paralela (correcciones #3917).
  • Estrategia de agregación para sucursales paralelas (#4028) — Nueva estrategia de agregación (AllOf y AnyOf) para sucursales paralelas.
  • AddEdge por lotes para ramas paralelas (#3938) — Métodos addEdge por lotes convenientes para la definición de ramas paralelas en StateGraph.
  • interruptAfter gancho (#3864) — InterruptableAction admite el gancho interruptAfter (corrige #3447, #3904).
  • Ejecución de herramienta asíncrona para AgentToolNode (#4037 / #3988) — Soporte de ejecución de herramienta asíncrona para AgentToolNode.
  • Salida completa para el nodo de transmisión (#3941): los nodos de transmisión ahora emiten una salida completa, incluido _FINISHED OutputType.

Zona de pruebas y estudio

  • SAA Sandbox (#4069): nuevo módulo SAA Sandbox que proporciona ejecución de herramientas segura y aislada.
  • RenderTemplate integrado (#3935): implementación personalizada integrada de RenderTemplate.
  • Studio CORS opcional (#4154): la configuración de CORS ahora es opcional en Studio.

Correcciones

DashScopeChatModelo

  • Restablecimiento de conexión informado en #3942 (spring-ai-alibaba/spring-ai-extensions#140): configure el HTTP client predeterminado para DashScopeApi para administrar mejor las conexiones y evitar el problema de restablecimiento de la conexión cuando el servidor modelo cierra la conexión.

Gráfico

  • Serialización (#3969) — Se corrigió el error class en la serialización (corrige #3895, #3931).
  • MergeStrategy (n.° 4129): se corrigió el manejo de Optional y se aplicaron controles de tipo estrictos en MergeStrategy (correcciones n.° 3909).

Agente

  • Instrucción (#3974) — Manejo de instrucciones agregado; CI fijo y pruebas.
  • Opciones de modelo AgentLlmNode (#3986): evita que AgentLlmNode anule las opciones de modelo predeterminadas; asegúrese de que internalToolExecution(false) esté configurado para ChatOptions (correcciones #3903).
  • selectorModel (n.° 4045): se agregó compatibilidad con selectorModel (corrige el n.° 4026).
  • systemPrompt (#4067) — Se corrigió el manejo de los mensajes del sistema.
  • ParallelAgent maxConcurrency (#4053): se garantiza que se implemente la función maxConcurrency de ParallelAgent.
  • jumpTo (#4081): se aseguró de que jumpTo funcione correctamente.
  • Mensaje del sistema del generador ModelRequest (#4138): el generador ModelRequest ya no pierde systemMessage.
  • NacosReactAgentBuilder (#4093) — Se corrigió NacosReactAgentBuilder para fusionar correctamente las herramientas locales.
  • Devoluciones de llamada de herramienta AgentLlmNode (#4112): se corrigió la lógica de filtrado de devoluciones de llamada de herramienta en AgentLlmNode.

Administrador y interfaz de usuario

  • Cambio de nombre del paquete de administración (#3977): se cambió el nombre de @agentscope-ai/flow a @spark-ai/flow (correcciones #3949).
  • Inicio/compilación del administrador (#4123) — Se corrigieron problemas de inicio y compilación de spring-ai-alibaba-admin.
  • CustomInputsControl (#4106): se agregó el accesorio variableList a CustomInputsControl.

Dependencias

  • Versión Spring AI — Spring Ai actualizado a 1.1.2
  • Spring AI Versión de extensiones de Alibaba — Spring Ai Extensiones de Alibaba actualizadas a 1.1.2.1

Notas de actualización

  • Spring AI: esta versión utiliza Spring AI 1.1.2. Alinee la versión Spring AI de su proyecto en consecuencia.
  • Admin: si usa la interfaz de usuario del flujo de administración, actualice la dependencia de @agentscope-ai/flow a @spark-ai/flow.
