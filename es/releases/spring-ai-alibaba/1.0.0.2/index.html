primavera-ai-alibaba v1.0.0.2

¡Nos complace anunciar el lanzamiento de Spring AI Alibaba 1.0.0.2, la primera versión GA! Construido sobre Spring AI y profundamente integrado con Bailian, Spring AI Alibaba admite el desarrollo de aplicaciones ChatBot, flujo de trabajo y multiagente.

Características clave

1. Integración integral del marco

  • Integración con Alibaba Cloud: conéctese sin problemas a los servicios de Alibaba, incluido Dashscope de Bailian, que admite varios modelos de IA convencionales como Qwen y Deepseek.

2. Marco multiagente

  • Marco de trabajo multiagente basado en gráficos: inspirado en Langgraph, Spring AI Alibaba Graph facilita la creación de flujos de trabajo y aplicaciones multiagente.

3. Soluciones de agentes de IA listas para la empresa

  • Registro MCP de Nacos
    • Descubrimiento de MCP distribuido y equilibrio de carga.
    • Proxy dinámico API a MCP
  • NL2SQL para transformar consultas en lenguaje natural en sentencias SQL.
  • Observabilidad

Experiencia del desarrollador

Guía de inicio rápido

Inicie su primera aplicación de IA con Spring AI Alibaba agregando la siguiente dependencia a su proyecto Spring Boot:

<dependencyManagement>
    <dependencies>
        <dependency>
            <groupId>com.alibaba.cloud.ai</groupId>
            <artifactId>spring-ai-alibaba-bom</artifactId>
            <version>1.0.0.2</version>
            <type>pom</type>
            <scope>import</scope>
        </dependency>
    </dependencies>
</dependencyManagement>

<dependencies>
    <dependency>
        <groupId>com.alibaba.cloud.ai</groupId>
        <artifactId>spring-ai-alibaba-starter-dashscope</artifactId>
    </dependency>
</dependencies>

Spring Boot Arrancadores

  • spring-ai-alibaba-starter-dashscope - Adaptación del servicio de modelo integrado
  • spring-ai-alibaba-graph-core - Componentes principales del marco AI Graph
  • spring-ai-alibaba-starter-nl2sql - Componente de conversión de lenguaje natural a SQL
  • spring-ai-alibaba-starter-memory - Componente de memoria de sesión
  • primavera-ai-alibaba-starter-nacos-mcp-client - Nacos MCP client; Versión recomendada: Nacos 3.0.1. Para usuarios de Nacos 2 Server, utilice la versión anterior (spring-ai-alibaba-starter-nacos2-mcp-client).
  • spring-ai-alibaba-starter-nacos-mcp-server - Servidor Nacos MCP; Versión recomendada: Nacos 3.0.1. Para usuarios de Nacos 2 Server, utilice la versión anterior (spring-ai-alibaba-starter-nacos2-mcp-server).
  • spring-ai-alibaba-starter-nacos-prompt - Gestión rápida de Nacos
  • spring-ai-alibaba-starter-arms-observation - Observabilidad de ARMS
  • Componentes comunitarios
    • spring-ai-alibaba-starter-tool-calling-* - Componente de llamada de herramienta
    • spring-ai-alibaba-starter-document-reader-* - Componente de lectura de documentos
    • spring-ai-alibaba-starter-vector-store-* - Componente de tienda de vectores

Proyectos de ejemplo

La comunidad oficial ha desarrollado un [ejemplo de Playground] (https://github.com/springaialibaba/spring-ai-alibaba-examples/tree/main/spring-ai-alibaba-playground) que incluye una interfaz de usuario frontal y un backend completos basados en Spring AI Alibaba. Playground permite a los usuarios experimentar todas las capacidades centrales del marco, como chat, observabilidad, conversaciones de múltiples rondas, generación de imágenes, multimodalidad, llamada de herramientas, MCP y RAG.

Para conocer más casos de uso, consulte Spring AI Repositorio de ejemplos de Alibaba.
