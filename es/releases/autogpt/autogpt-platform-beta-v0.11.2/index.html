Nuevas funciones

  • #16308 - Primera prueba del plan: tareas iniciales y expertos en el muro de pago, paso de contratación eliminado, equipo contratado al inicio de la prueba, Inicio comienza con tareas clasificadas propiedad de expertos (por @itsababseh)

  • #16698 - Envía un evento PostHog cada vez que un límite de uso rechaza o pausa el trabajo (SECRT-3411) (por @kcze)
  • #16269 - Continuar con Microsoft, con la oferta de Microsoft 365 como paso de incorporación móvil (por @ntindle)
  • #16348 - Agregar mensajes de comentarios en la aplicación (por @0ubbe)

  • #16471 - Crear ID de volcado de cerebro sin crypto.randomUUID (por @posthog-eu[bot])

  • #16703 - Falla de inmediato con un mensaje claro cuando una solicitud de LLM es demasiado grande para el proveedor (por @Bentalbro)
  • #16704 - Otto ya no dice que una cuenta MCP iniciada no está conectada cuando el servidor responde 403 (por @Bentlybro)
  • #16684 - Una ejecución experta con un paso fallido informa que falló y no se completó (por @Bentalbro)
  • #16707 - Marcar Exa Create Research como una acción externa (por @0ubbe)
  • #16713 - Trate las claves SDK de la plataforma (Firecrawl, DataForSEO, Tavily, ...) como credenciales del sistema en todas partes (por @Torantulino)
  • #16745 - El borrado de cuenta elimina los chats de la cuenta (SECRT-2854) (por @kcze)
  • #16706 - Permitir que una ejecución deje una entrada en blanco cuando Avanzado esté activado (por @0ubbe)
  • #16710 - Decir cuando un campo JSON contiene un número demasiado largo para conservarlo (por @0ubbe)
