AutoGPT plataforma-autogpt-beta-v0.11.1

🔥 ¿Qué hay de nuevo?

⚠️ Cambios importantes

  • #16416 - Instalaciones autohospedadas: .env.default ya no incluye un par de claves Web Push (VAPID) y el backend ya no envía notificaciones push con el par anterior enviado. Ejecute make init-env para generar un par para su instalación; la imagen de contenedor único genera la suya propia en el primer arranque. Reemplazar el par invalida las suscripciones push existentes. NEXT_PUBLIC_VAPID_PUBLIC_KEY puede permanecer en blanco y el frontend usa la clave del backend (por @ntindle)

Nuevas funciones

  • #11220 - Admite nodos de entrada junto con nodos de activación (por @Pwuts)
  • #14991 - Ejecute habilidades como comandos / con argumentos en el chat del copiloto (por @ntindle)
  • #16582 - Haz que las subtareas en segundo plano sean un trabajo real que regresa al chat (por @ntindle)
  • #16506 - Avisar pruebas canceladas 3 días y 1 día antes de que finalice el acceso (por @Torantulino)
  • #16622 - Hacer que el correo electrónico de aprobación del cambio de correo electrónico sea claro para ambas direcciones (por @Torantulino)
  • #15488 - Rediseño de las pruebas de carga de k6 en torno a cargas de trabajo de usuarios reales (por @ntindle)
  • #16605 - Agregue Tencent Hy4 al catálogo LLM (por @ntindle)

Nuevos bloques

  • #16561 - Agregar bloques de herramientas de datos de Firecrawl Alexandria (por @Torantulino)
  • #16395 - Actualice la integración de Exa con el API actual de Exa (por @Torantulino)

Mejoras
