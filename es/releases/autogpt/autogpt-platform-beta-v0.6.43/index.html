🔥 ¿Qué hay de nuevo?

Nuevas funciones

  • #11458 - Agregar tutorial interactivo para la nueva interfaz del constructor (por @Abhi1992002)

  • #11782 - Agregar herramientas de búsqueda de chat y reclasificación de BM25 (por @Swiftyos)
  • #11781 - Agregar herramientas de generación de agentes para el copiloto de chat (por @Swiftyos)
  • #11707 - Agregar sistema de generación automática de documentación en bloque (por @ntindle)
  • #11756 - Agregar opciones explícitas de modo seguro para HITL y acciones sensibles (por @majdyz)
  • #11726 - Nueva interfaz de usuario del selector LLM (por @kcze)

Nuevos bloques

  • #11567 - Agregar bloque ConcatenateLists (por @mewaeltsegay)

Mejoras

  • #11770 - Ocultar elementos secundarios de campos de objetos y matrices conectados (por @Abhi1992002)
  • #11771 - Agregar representación especial para el tipo de interfaz de usuario NOTA en FieldTemplate (por @Abhi1992002)
  • #11779 - Mejorar el manejo de errores de validación de gráficos y la navegación de nodos (por @Abhi1992002)
  • #11780 - Mejore GoogleDrivePickerField con soporte para modo de entrada y espaciado de campos de matriz (por @Abhi1992002)
  • #11808 - Mejore los componentes RunGraph y RunInputDialog con estados de carga y una interfaz de usuario mejorada (por @Abhi1992002)
  • #11760 - Agregar credenciales predeterminadas perdidas (por @ntindle)
  • #11759 - Agregue el campo endAt y corrija las marcas de tiempo de análisis de ejecución (por @majdyz)
  • #11803 - Mejorar el rastreo de Langfuse con patrones SDK v3 y decoradores @observe (por @Swiftyos)

Mejoras en UI/UX

  • #11763 - Mejoras en las credenciales del agente (por @0ubbe)
  • #11801 - Refactorización de la entrada de credenciales con el componente unificado CredentialsGroupedView (por @Abhi1992002)

Corrección de errores

  • #11764 - Centralice las llamadas increment_runs y haga que add_graph_execution sea más sólido (por @Pwuts)
  • #11786 - Mejorar el seguimiento del historial y el manejo de errores (por @Abhi1992002)
  • #11775 - Hacer que la conexión Redis sea diferida en el módulo de caché (por @majdyz)
  • #11790 - Se corrigieron pruebas de actividad de agentes inestables apuntando al agente correcto (por @ntindle)
  • #11795 - Hacer que la selección del tipo de credenciales de chat sea determinista (por @ntindle)
  • #11805 - Usar calificación de esquema explícita para tipos de pgvector (por @majdyz)
  • #11812 - Manejar valores nulos en la validación de GraphSettings (por @majdyz)
  • #11815 - Seleccionar automáticamente las credenciales correctamente en el generador anterior (por @0ubbe)
  • #11817 - Hacer que el bus de eventos Redis maneje correctamente los fallos de conexión (por @majdyz)
  • #11818 - Utilice un tipo de vector no calificado para consultas de pgvector (por @majdyz)

Documentación

  • #11757 - Actualización de desarrollo desde gitbook (por @ntindle)
