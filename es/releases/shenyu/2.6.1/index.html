shenyu v2.6.1

##2.6.1

Nuevas funciones

  1. Agregar análisis de anotaciones dubbo para el controlador de ingreso shenyu
  2. Admite el ciclo de vida del complemento
  3. Soporte shenyu-sdk-client por openFeign
  4. Agregar un complemento Motan y Spring Cloud al controlador de ingreso shenyu
  5. Aviso de alerta de soporte
  6. Shenyu client agrega el centro de registro de descubrimiento
  7. Agregue el controlador de ingreso del complemento de ruta de contexto shenyu
  8. Agregue el controlador de ingreso del complemento shenyu grpc
  9. Agregue el controlador de ingreso del sofá shenyu
  10. Agregue nacos, etcd, eureka como servicio de descubrimiento
  11. Agregue un nuevo complemento: autenticación básica
  12. Agregue el complemento shenyu logging-rabbitmq
  13. Selector de enlaces por shenyu-discovery

API Cambios

  1. Refactorizar la estructura de datos de sincronización de Shenyu

    plugin.list ["plugin.sign", "plugin.dubbo", "plugin.pluginName"]
-> plugin.sign
-> plugin.dubbo
-> plugin.pluginName

examples data:
selector.key1.list ["selector.key1.value1", "selector.key1.value2", "selector.key1.value3"]
-> selector.key1.value1
-> selector.key1.value2
-> selector.key1.value3

selector.key2.list ["selector.key2.value1", "selector.key2.value2", "selector.key2.value3"]
-> selector.key2.value4
-> selector.key2.value5
-> selector.key2.value6

  2. Admite NettyClient como httpclient predeterminado

  3. Refactorizar admin-listener para admitir la sincronización de datos de administrador

  4. Elimine los soportes de brpc, incluido el complemento brpc, el ejemplo de brpc y la prueba integrada de brpc.

  5. Elimine la dependencia de Apollo para admitir Java 17 (agregue el jar usted mismo)

  6. Eliminar el registro de middleware shenyu client
