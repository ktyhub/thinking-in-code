dubbo-ir v3.3.1

##3.3.1

Resumen

Esta versión presenta importantes mejoras al protocolo Triple, mejoras en los centros de configuración y registro (Nacos, Apollo, Zookeeper) y una extensa refactorización de los módulos principales para mejorar la estabilidad y el rendimiento. Esta versión también actualiza la compatibilidad con Go 1.24.

Nuevas funciones

  • Admite comodines de grupo y versión para una coincidencia exacta de la interfaz. #3080
  • Soporte para inyectar dubbo.tag en los metadatos del servicio. #3069
  • Exponer API relacionados con el enrutador. #3066
  • Actualizar compatibilidad con la versión Go para Go 1.24 y eliminar el uso obsoleto de rand.seed. #3046
  • Introducir una herramienta de formateo de importaciones e integrarla en las comprobaciones de CI. #3019
  • Añadir capacidad de configuración de recarga en caliente. #2992
  • Soporte para ejecutar servidores HTTP/2 y HTTP/3 simultáneamente. #2972
  • Agregar la opción WithInterface para la inicialización de client. #2946
  • Agregar soporte de herramientas para generar documentación OpenAPI para servicios triples. #2951
  • Añadir compatibilidad experimental con HTTP/3 para el protocolo Triple. #2916
  • Rediseñar TLS API y agregar nueva configuración TLS para protocolo triple. #2852 #2891
  • Soporte Modo no IDL en la nueva implementación Triple. #2858
  • Agregar soporte para Apollo como centro de configuración. #2857
  • Soporte para la decodificación de Hessian a partir de flujos para mejorar el rendimiento en transmisiones de paquetes grandes. #2841
  • Agregar soporte de llamadas genéricas para el nuevo protocolo Triple. #2818

Corrección de errores

  • Solucionar falla de cancelación del registro de Nacos durante el apagado. #3108
  • Evitar el pánico al recuperar metadatos de proveedores de Java. #3092
  • Ajustar el nivel de registro de Error a Advertir cuando los parámetros de la aplicación están vacíos en Tag Router. #3035
  • Corregir la desreferencia del puntero nulo en múltiples módulos. #3071
  • Resolver pérdida de parámetros de URL en el método SetParams. #3022
  • Manejar errores de creación de extensiones de clúster en lugar de entrar en pánico. #3021 #3064
  • Corregir rutas de rotación de registros incorrectas para evitar la pérdida de archivos. #3014
  • Corregir la lógica de disminución del contador en caso de error. #3013
  • Solucionar fallas de recuperación de metadatos causadas por errores meta-v y parámetros de almacenamiento remoto vacíos. #2952 #2953
  • Reparar la carga de la configuración del proveedor en dubbo.Load(). #2941
  • Solucionar problemas de transferencia de archivos adjuntos desde el servidor a client en protocolo triple. #2928 #2854
  • Reparar La configuración de peso de Nacos no tiene efecto. #2937
  • Reducir la latencia en la percepción del nodo Zookeeper client. #2930
  • Corregir errores de lectura de prefijo EOF en la capa de comunicación. #2912
  • Solucionar problemas de sobrescritura de instancias de Nacos. #2882
  • Resolver problemas lógicos de bucle infinito. #2879
  • Solucionar problemas de suscripción de Nacos donde no se detectaban servicios recién registrados. #2859
  • Reparar la lógica de configuración de la opción de peso de Nacos. #2843
  • Reparar la propagación de errores en marshalRequest. #2817
  • Solucionar el manejo de errores de contexto adjunto en llamadas de transmisión triple. #2810

Mejoras en el código

  • Refactor: Desacoplamiento de configuración. Dependencias desacopladas del paquete config para resolver dependencias circulares entre módulos de registro, filtro y TLS.
  • Optimizar el rendimiento precompilando patrones de expresiones regulares. #3067
  • Mejorar RoundRobin ponderado agregando el campo lastUpdate al almacenamiento de estado. #3053
  • Corregir importaciones de paquetes múltiples en la generación de código triple. #3052
  • Abordar las pérdidas de memoria relacionadas con la gestión de rutinas, identificadores de archivos y cachés de extensiones. #3023
  • Refactorizar el módulo de registro y agregar pruebas unitarias integrales. #2838 #2993
  • Reescribir Makefile para mejorar la coherencia de la compilación y la experiencia del desarrollador. #2975
  • Utilice errgroup para mejorar el manejo de errores durante el cierre ordenado. #2973
  • Reemplazar operaciones CAS obsoletas con CompareAndSwap. #2962
  • Harden Triple manejo de errores openServer para errores de configuración. #2945
  • Agregar control de tiempo de espera para un apagado elegante en el protocolo triple. #2943
  • Migrar interface{} a any en todo el código base para compatibilidad con Go 1.18+. #2848

Observabilidad

  • Agregar registro para el ciclo de vida del registro del servicio. #3043
  • Alinear los nombres de los ámbitos de seguimiento con las especificaciones OpenTelemetry. #3041
  • Agregar la opción Insecure a la configuración de seguimiento. #3028
  • Actualizar dependencias de OpenTelemetry a v1.21.0. #2971

Documentación y CI

  • Agregar el comando make check-fmt a la canalización de CI. #3055
  • Actualizar información de contacto LÉAME y corregir enlaces no válidos en README_CN. #3020
  • Integrar importa el formateador y las comprobaciones del encabezado de licencia en CI. #2961 #2957
  • Resolver varios falsos positivos de SonarQube/SonarCloud y advertencias de bots de IA. #2902
