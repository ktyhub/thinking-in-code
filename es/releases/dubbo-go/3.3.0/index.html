dubbo-ir v3.3.0

Resumen

Esta versión presenta múltiples correcciones de errores, nuevas características y mejoras de código para mejorar la estabilidad y funcionalidad de Apache Dubbo-Go. Las mejoras clave incluyen resolver varios problemas relacionados con el registro y el descubrimiento de servicios, abordar las pérdidas de memoria y mejorar el manejo de errores y la estabilidad de la biblioteca de comunicación subyacente. Además, se han implementado nuevas funciones como enrutamiento basado en scripts, compatibilidad mejorada con Java, mantenimiento de protocolo triple y compatibilidad con MetadataService basado en Protobuf.
