bookkeeper release-4.15.5

Versión Publicado19 dic 2023 Fuenteapache/bookkeeper original en inglés

Esta página está traducida automáticamente. El texto original en inglés es la referencia.

liberación del contable-4.15.5

La versión 4.15.5 incluye múltiples correcciones de errores y mejoras, también tenemos algunas actualizaciones de dependencias.

Se recomienda a los usuarios de Apache BookKeeper que actualicen a 4.15.5 si están utilizando 4.15.x. Los detalles técnicos de esta versión se resumen a continuación.

Destacados

La versión anterior utiliza la compilación de la plataforma ARM, lo que significa que las bibliotecas JNI solo están presentes para MacOS. y esto provocará una degradación del rendimiento (por ejemplo: las bibliotecas CRC) o no funcionará (en caso de afinidad de CPU).

La plataforma de construcción ahora está etiquetada con linux/amd64 por este PR #4060

Errores

  • No se corrigieron casas de apuestas conocidas después de restablecer los racks para todos los BK PR #4128
  • Se corrigió el registro de excepciones de cierre de AutoCloseableLifecycleComponent PR #4042
  • Se corrigió NoSuchElementException al volver a replicar libros de contabilidad vacíos PR #4039
  • Se corrigió el recuento de libros mayores eliminados PR #4026
  • Se corrigió la pérdida de solicitud de lectura y escritura cuando el ejecutor lanza RejectedExecutionException PR #4024
  • Recicle LongWrapper finalmente para evitar pérdidas de memoria PR #4007
  • Arreglar el disparador GC no funciona PR #3998
  • Soluciona la vulnerabilidad de carga de archivos arbitrarios con httpServerEnabled PR #3982
  • Borrar canal cuando el canal está inactivo PR #3966
  • Se corrige npe cuando se itera pendienteLedgersUpdates y pendienteDeletedLedgers. PR #3955
  • Se corrigieron algunas métricas generadas por prometheus client sin información de tipo PR #3927
  • Se corrigió el proceso de desmantelamiento del corredor de apuestas de bloques fallidos replicados en el libro mayor PR #3917
  • Reciclar descartando solicitudes de lectura y escritura cuando ocurrieron varias excepciones PR #3912
  • SingleDirectoryDbLedgerStorage#flushMutex no libera el bloqueo en todas las rutas de excepción PR #3909
  • Solucionar el problema incorrecto de estadísticas de ReclaimedSpaceViaDeletes. PR #3906
  • Se corrige la fuga de claves en EntryLocationIndex cuando ledgersToDelete está vacío PR #3903
  • Se corrigió la recolección de basura bloqueada por una excepción de tiempo de ejecución PR #3901
  • Devuelve activeLogChannel si se crea una nueva PR #3894
  • Modificar la configuración incorrecta de rocksDB level_compaction_dynamic_level_bytes a CFOptions PR #3860
  • Arreglar ReadEntryProcessor v2 SchedulingDelayStats PR #3758
  • Corregir datos perdidos al configurar varios directorios del libro mayor PR #3329

Mejoras

  • Problema 4126: Se solucionó un cierre lento del subproceso gc al compactar PR #4127
  • Elimine los registros no utilizados en CleanupLedgerManager.recordPromise PR #4121
  • Ignore el perRegionPlacement vacío cuando RegionAwareEnsemblePlacementPolicy#newEnsemble PR #4106
  • Imprimir progreso de compactación PR #4071
  • Forzar el uso de linux/amd64 para compilar la versión PR #4060
  • Eliminar devolución de llamada de replicación insuficiente PR #4058
  • Permitir establecer números máximos de operaciones en un solo lote de rocksdb PR #4044
  • Cambiar los LedgersDeletedLedgers pendientes como ConcurrentHashSet PR #3989
  • Evite la compactación para desencadenar descargas adicionales DbLedgerStorage PR #3959
  • Admite omitir registro de diario no válido en la etapa de diario de respuesta PR #3956
  • Optimizar getEntryLogMetadata PR #3948
  • eliminar argumento de formato de entrada no válido del comando de shell PR #3938
  • Habilite PCBC completeObjects autoShrink para reducir el uso de memoria y gc PR #3913
  • Evitar el tránsito al modo de escritura cuando el modo forceReadOnly está activo PR #3881
  • Hacer que la solicitud de entrada de lectura sea reciclable PR #3842
  • Se corrigió la selección de pivote en el grupo de clasificación rápida PR #3800
  • Ejecutar índices limpios finalmente PR #3772
  • Agregar verificación de archivos pequeños en la recolección de basura PR #3631

Actualizaciones de dependencia

  • Actualizar la dependencia de Jetty PR #4141
  • Versión de guayaba mejorada de 31.0.1-jre a 32.0.1-jre PR #4008
  • Actualice snappy-java para abordar múltiples CVE PR #3993
  • Actualice grpc y protobuf para abordar CVE-2023-32732 PR #3992
  • Bajar de categoría grpc y protobuf para evitar introducir cambios importantes PR #4001
  • Se solucionó el problema con la compatibilidad binaria con versiones anteriores de grpc en tiempo de ejecución en client PR #3997
  • Actualice la versión del embarcadero a 9.4.51.v20230217 PR #3937
  • Actualice la imagen base de docker para resolver CVE-2023-0286 PR #3916

  • Optimizar la dependencia de log4j en Bookkeeper PR #3892
