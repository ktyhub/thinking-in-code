bookkeeper release-4.16.7

Versión Publicado3 jul 2025 Fuenteapache/bookkeeper original en inglés

Esta página está traducida automáticamente. El texto original en inglés es la referencia.

liberación del contable-4.16.7

La versión 4.16.7 incluye múltiples correcciones de errores y algunas actualizaciones de dependencias.

Se recomienda a los usuarios de Apache BookKeeper que actualicen a 4.16.7 si están utilizando 4.16.x. Los detalles técnicos de esta versión se resumen a continuación.

Destacados

Errores

  • Solucionar el problema de pérdida de datos causado por el encabezado de registro de entrada incorrecto PR #4607
  • Se corrige el volcado de núcleo que ocurre al llamar a KeyValueStorageRocksDB.count después de que se haya cerrado rocksdb PR #4581
  • Corregir y mejorar la ubicación de los archivos de configuración de RocksDB PR #4560
  • [solución] Escritura bloqueada debido a una devolución de llamada de adición pendiente por parte de varios subprocesos PR #4557
  • Se corrigió que los archivos SST no se limpiaran en la carpeta de ubicaciones PR #4555
  • Se corrigió la acción tune-runner-vm para que se ejecute correctamente en la imagen ubuntu-24.04 PR #4536
  • [cli] Solución: el comando de recuperación no acepta el parámetro de límite de velocidad PR #4535
  • corregir los Ledgers eliminados pendientes no elimina el error del libro mayor PR #4525
  • Se corrigió la dosis de peso del disco de la política de ubicación según la región que no se actualiza. PR #4522
  • Se solucionó el problema de pérdida de memoria de entrada fallida de verificación de lectura. PR #4513
  • [solución] eliminar en dirección2Región mientras el corredor de apuestas se fue para obtener la información correcta del rack PR #4504
  • solución: instale netcat-openbsd en lugar de netcat en la compilación de la imagen de prueba PR #4476
  • [fix][ci] Repara la descarga de la verificación de dependencia de OWASP usando la clave NVD API PR #4473
  • corregir[rocksdb]: corrige el error de configuración predeterminada de rocksdb para CFOptions PR #4466
  • [solución] Se corrigieron los datos perdidos después de escribir el libro mayor y eliminarlo al ejecutar la concurrencia PR #4462
  • [BugFix] Corrección para evitar fugas de recursos en 3 clases PR #4449
  • Corregir RackawareEnsemblePlacementPolicyImpl defaultRack cuando el corredor de apuestas no esté disponible. PR #4439
  • Solucionar el problema de fuga de objetos de finalización. PR #4285

Mejoras

  • Ajustar la caducidad de la caché de DNS en las pruebas para reducir las fallas en el tiempo de espera de las pruebas PR #4586
  • Cambiar el nuevo registro de conjunto al nivel de información PR #4566
  • Agregar documentación a bk_server.conf sobre la configuración de RocksDB PR #4561
  • Reducir la contención de metadataLock en LedgerHandle PR #4549
  • [mejorar] cuando rackaware no pudo elegir un corredor de apuestas, imprima la lista del conjunto. PR #4482
  • Asegúrese de que formatVersion esté especificado para todas las bases de datos de RocksDB PR #4559
  • Establezca format_version predeterminado en 5 para las bases de datos RocksDB PR #4480
  • [mejorar] Optimizar reorderReadSequence para verificar WriteSet PR #4478
  • Actualizar instrucciones de script de lanzamiento y scripts de publicación Python PR #4458
  • Habilite ZooKeeper client para establecer conexión en modo de solo lectura PR #4244
  • Mejorar el registro de ruido de recuperación automática cuando algún corredor de apuestas falla. PR #4118
  • El asignador admite la configuración exitOnOutOfMemory. PR #3984

Actualizaciones de dependencia

  • Actualice Jetty a 9.4.57.v20241219 para mitigar CVE-2024-6763 PR #4600
  • Actualice Netty a 4.1.121.Final PR #4597
  • Actualice Netty a 4.1.119, tcnativo a 2.0.70 e io_uring a 0.0.26 PR #4584
  • Actualizar las bibliotecas de Apache Commons a versiones compatibles PR #4582
  • Cambie vertx.version de 4.5.7 a 4.5.11 para abordar CVE-2024-8391 PR #4545
  • Actualice a Netty 4.1.115.Final para abordar CVE-2024-47535 PR #4524
  • Actualice Zookeeper a 3.9.3 para abordar CVE-2024-51504 PR #4523
  • Actualice protobuf a 3.25.5 para abordar CVE-2024-7254 PR #4508
  • Actualice a Netty 4.1.113.Final y netty-tcnative 2.0.66.Final PR #4502
