d2 v0.7.0

#d2v0.7.0

Características 🚀

  • Iconos:
    • las conexiones pueden incluir iconos #12
  • Sintaxis:
    • suspend/unsuspend para definir modelos y crear instancias de ellos #2394
  • Globos:
    • soporte para filtrado de bordes basado en propiedades de nodos de punto final (por ejemplo, &src.style.fill: blue) #2395
    • Filtro level implementado #2473
  • Renderizar:
    • Markdown, látex y código se pueden utilizar como etiquetas de objetos #2204
    • shape: c4-person para representar la forma de una persona como la que prescribe el modelo C4 #2397
  • Iconos:
    • el radio del borde debería funcionar en el ícono #2409
  • Varios:
    • Se implementan leyendas de diagramas #2416

Mejoras 🧹

-CLI: - Admite el comando validate. #2415 - El modo de vigilancia ignora los archivos de copia de seguridad (por ejemplo, archivos creados por ciertos editores como Helix). #2131 - Soporte para la bandera --omit-version. #2377 - Se ignoran las mayúsculas y minúsculas para los nombres de complementos #2486

  • Compilador:
    • Los link se pueden configurar en la ruta raíz, p. /xyz. #2357
    • Al importar un archivo, primero intente resolver las sustituciones en el alcance del archivo importado #2482
    • validar las paradas de color del degradado. #2492
  • Analizador:
    • imponer la longitud máxima de la clave. Es casi seguro que sea un error si una identificación es demasiado larga, p. comillas faltantes #2465
  • Renderizar:
    • Se agregó relleno horizontal para las etiquetas de conexión #2461

Corrección de errores ⛑️

  • Compilador:
    • corrige el pánico cuando el valor de la forma sql_shape tenía una carcasa mixta #2349
    • corrige el pánico al importar desde un archivo con sustituciones extendidas en vars #2427
    • corrige la compatibilidad con center en d2-config #2360
    • soluciona el pánico cuando aparecen líneas de comentarios en matrices #2378
    • corrige inconsistencias cuando los objetos estaban entre comillas dobles #2390
    • corrige los globos que no se aplican a las sustituciones de diferenciales #2426
    • corrige el pánico cuando las clases se mezclaban con capas incorrectamente #2448
    • corrige el pánico cuando se usan colores degradados en el modo boceto #2481
    • corrige el pánico usando filtros globales con valores compuestos #2489
    • corrige el filtro de hoja comercial cuando se usa con importaciones #2494
  • Formateador:
    • corrige sustituciones entre comillas rodeadas de texto #2462 -CLI:
    • recuperar y renderizar imágenes remotas de flujo de octetos tipo mime correctamente #2370
  • Composición:
    • Los escenarios/pasos de importación extendidos no se heredaban correctamente #2460
    • los campos importados no se fusionaban con los campos/bordes actuales #2464
  • Rebaja:
    • corrige las sustituciones de var anidadas que no funcionan #2456

Para conocer los últimos cambios de d2.js, consulte changelog por separado.
