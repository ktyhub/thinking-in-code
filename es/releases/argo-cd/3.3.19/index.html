#argo-cd v3.3.19

[!IMPORTANTE] AVISO DE FIN DE VIDA ÚTIL

Este es el lanzamiento final de la serie de lanzamientos v3.3. A partir del 3 de noviembre de 2026, esta versión llegó al final de su vida útil y ya no recibirá correcciones de errores ni actualizaciones de seguridad.

Acción requerida: actualice a una versión compatible (v3.4.13, v3.5.7 o v3.6.0).

Inicio rápido

Sin HA:

kubectl create namespace argocd
kubectl apply -n argocd --server-side --force-conflicts -f https://raw.githubusercontent.com/argoproj/argo-cd/v3.3.19/manifests/install.yaml

ja:

kubectl create namespace argocd
kubectl apply -n argocd --server-side --force-conflicts -f https://raw.githubusercontent.com/argoproj/argo-cd/v3.3.19/manifests/ha/install.yaml

Firmas de autorización y procedencia

Todas las imágenes del contenedor de CD de Argo están firmadas por cofirmante. Se genera una procedencia para imágenes de contenedor y binarios CLI que cumplen con las especificaciones SLSA Nivel 3. Consulte la documentación sobre cómo verificar.

Publicación de blog de Release Note

Para obtener un desglose detallado de los cambios y mejoras clave de esta versión, consulte la publicación del blog oficial

Actualización

Si actualiza desde una versión menor diferente, asegúrese de leer la documentación de actualización.
