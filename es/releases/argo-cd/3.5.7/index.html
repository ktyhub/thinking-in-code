#argo-cd v3.5.7

Inicio rápido

Sin HA:

kubectl create namespace argocd
kubectl apply -n argocd --server-side --force-conflicts -f https://raw.githubusercontent.com/argoproj/argo-cd/v3.5.7/manifests/install.yaml

ja:

kubectl create namespace argocd
kubectl apply -n argocd --server-side --force-conflicts -f https://raw.githubusercontent.com/argoproj/argo-cd/v3.5.7/manifests/ha/install.yaml

Firmas de autorización y procedencia

Todas las imágenes del contenedor de CD de Argo están firmadas por cofirmante. Se genera una procedencia para imágenes de contenedor y binarios CLI que cumplen con las especificaciones SLSA Nivel 3. Consulte la documentación sobre cómo verificar.
