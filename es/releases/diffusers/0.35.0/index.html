difusores v0.35.0

Esta versión incluye nuevos canales de generación y edición de imágenes, un nuevo canal de videos, nuevos guiones de capacitación, mejoras en la calidad de vida y mucho más. Lea el resto de los release note en su totalidad para no perderse las cosas divertidas.

Nuevos oleoductos 🧨

Le damos la bienvenida a nuevas canalizaciones en esta versión: -Wan 2.2

  • Contexto Flux
  • Qwen-Imagen
  • Qwen-Imagen-Editar

Wan 2.2 📹

Esta actualización de Wan proporciona mejoras significativas en la fidelidad del vídeo, la adherencia rápida y el estilo. Consulte el [documento oficial] (https://huggingface.co/docs/diffusers/main/en/api/pipelines/wan) para obtener más información.

Flux-Kontext 🎇

Flux-Kontext es un transformador de flujo rectificado de 12 mil millones de parámetros capaz de editar imágenes basándose en instrucciones de texto. Consulte el [documento oficial] (https://huggingface.co/docs/diffusers/main/en/api/pipelines/flux#kontext) para obtener más información al respecto.

Qwen-Imagen 🌅

Después de una serie exitosa de entrega de modelos de lenguaje y modelos de visión-lenguaje, el equipo de Qwen está de regreso con un modelo de generación de imágenes, ¡que tiene licencia Apache-2.0! Logra avances significativos en la representación de texto complejo y la edición precisa de imágenes. Para obtener más información sobre este poderoso modelo, consulte nuestros docs. Gracias a @naykun por contribuir con Qwen-Image y Qwen-Image-Edit a través de [este PR] (https://github.com/huggingface/diffusers//issues/12055) y [este PR] (https://github.com/huggingface/diffusers/pull/12164/).

  • Entrenador Qwen-Imagen

Implementaciones de modelado de un solo archivo

Siguiendo la 🤗 filosofía de Transformers de implementaciones de modelado de un solo archivo, hemos comenzado a implementar código de modelado en archivos únicos y autónomos. El transformador de flujo [código] (https://github.com/huggingface/diffusers/blob/baa9b582f348e52aa2fc245e366611f454e1082b/src/diffusers/models/transformers/transformer_flux.py) es un ejemplo de esto.

Refactorización de atención

Hemos refactorizado masivamente cómo prestamos atención en los modelos. Esto nos permite brindar soporte para diferentes backends de atención (como scaled_dot_product_attention nativo de PyTorch, Flash Attention 3, SAGE atención, etc.) en la biblioteca sin problemas. Tener la atención apoyada de esta manera también nos permite integrar diferentes mecanismos de paralelización, en los que estamos trabajando activamente. Siga este PR si está interesado. Los usuarios no deberían verse afectados en absoluto por estos cambios. Abra un problema si tiene algún problema.

Compilación regional

La compilación regional reduce la latencia de arranque en frío al compilar solo los bloques pequeños y repetidos con frecuencia de un modelo (generalmente una capa de transformador) y permite reutilizar artefactos compilados para cada aparición posterior. Para muchas arquitecturas de difusión, esto ofrece las mismas aceleraciones de tiempo de ejecución que la compilación de gráficos completos y reduce el tiempo de compilación entre 8 y 10 veces. Consulte este documento para obtener más información. Gracias a @ anijain2305 por contribuir con esta función en [este PR] (https://github.com/huggingface/diffusers/pull/11705). También hemos escrito una serie de publicaciones que se centran en el uso de torch.compile. Puedes consultarlos en los siguientes enlaces:

  • Presentación de Flux Fast: Cómo hacer que Flux funcione mejor en los H100
  • torch.compile y difusores: una guía práctica para alcanzar el máximo rendimiento
  • Inferencia rápida LoRA para flujo con difusores y PEFT

Carga de canalización más rápida ⚡️

Los usuarios ahora pueden cargar tuberías directamente en un dispositivo acelerador, lo que permite tiempos de carga significativamente más rápidos. Esto se hace particularmente evidente cuando se cargan grandes canalizaciones como Wan y Qwen-Image.

from diffusers import DiffusionPipeline
import torch 

ckpt_id = "Qwen/Qwen-Image"
pipe = DiffusionPipeline.from_pretrained(
-    ckpt_id, torch_dtype=torch.bfloat16
- ).to("cuda")
+    ckpt_id, torch_dtype=torch.bfloat16, device_map="cuda"
+ )

Puede acelerar la carga aún más habilitando la carga en paralelo de fragmentos de dictado de estado. Esto es particularmente útil cuando se trabaja con modelos grandes como Wan y Qwen-Image, donde los dictados de estado del modelo generalmente están divididos en varios archivos.

import os
os.environ["HF_ENABLE_PARALLEL_LOADING"] = "yes"

Mejor integración de GGUF

@ Isotr0py contribuyó con soporte para kernels nativos GGUF CUDA en [este PR] (https://github.com/huggingface/diffusers/pull/11869). Esto debería proporcionar una mejora de aproximadamente el 10% en la velocidad de inferencia. También hemos trabajado en una herramienta para convertir puntos de control regulares a GGUF, permitiendo a la comunidad compartir fácilmente sus puntos de control GGUF. Obtenga más información aquí. Ahora admitimos la carga de puntos de control GGUF en formato Difusor. Puede obtener más información sobre todo esto en nuestros [documentos oficiales de GGUF] (https://huggingface.co/docs/diffusers/main/en/quantization/gguf).

Difusores Modulares (Experimental)

Difusores Modulares es un sistema para construir tuberías de difusión con *bloques de tuberías individuales. Es altamente personalizable, con bloques que se pueden mezclar y combinar para adaptarse o crear una canalización para un flujo de trabajo específico o múltiples flujos de trabajo.
El API se encuentra actualmente en desarrollo activo y se lanza como una característica experimental. Obtenga más información en nuestros docs.
