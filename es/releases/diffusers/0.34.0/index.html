difusores v0.34.0

📹 Nuevas canalizaciones de generación de vídeos

Wan VACE

Wan VACE admite varias técnicas de generación que logran una generación de vídeo controlable. Viene en dos variantes: un modelo 1.3B para iteración y creación de prototipos rápidas, y un modelo 14B para generación de alta calidad. Algunas de las capacidades incluyen:

  • Control de vídeo (profundidad, pose, boceto, flujo, escala de grises, garabato, diseño, cuadro de límites, etc.). Biblioteca recomendada para preprocesar vídeos para obtener vídeos de control: huggingface/controlnet_aux
  • Imagen/Video a Video (primer cuadro, último cuadro, comenzando clip, finalizando clip, aleatorio clips)
  • Pintura interior y exterior
  • Sujeto a Vídeo (rostros, objetos, personajes, etc.)
  • Composición de vídeo (haga referencia a cualquier cosa, anime cualquier cosa, intercambie cualquier cosa, expanda cualquier cosa, mueva cualquier cosa, etc.) Los fragmentos de código disponibles en this solicitud de extracción muestran algunos ejemplos de cómo se pueden generar vídeos con señales de controlabilidad. Consulte los docs para obtener más información.

Cosmos Predict2 Video2World

Cosmos-Predict2 es una rama clave del ecosistema Cosmos World Foundation Models (WFMs) para la IA física, que se especializa en la predicción de estados futuros a través de modelos mundiales avanzados. Ofrece dos potentes capacidades: generación de texto a imagen para crear imágenes de alta calidad a partir de descripciones de texto y generación de vídeo a mundo para producir simulaciones visuales a partir de entradas de vídeo. El modelo Video2World viene en una variante 2B y 14B. Consulte los docs para obtener más información.

LTX 0.9.7 y Destilado

LTX 0.9.7 y sus variantes destiladas son los últimos de la familia de modelos lanzados por Lightricks. Consulte los docs para obtener más información.

Paquete de marcos de vídeo de Hunyuan y F1

Framepack es un método novedoso para permitir la generación de vídeos largos. Hay dos variantes publicadas de Hunyuan Video entrenadas con esta técnica. Consulte los docs para obtener más información.

FusiónX

La [familia de modelos FusionX y LoRA] (https://huggingface.co/vrgamedevgirl84/Wan14BT2VFusioniX), construida sobre Wan2.1-14B, ya debería ser compatible. Para cargar el modelo, utilice from_single_file():

from diffusers import WanTransformer3DModel

transformer = WanTransformer3DModel.from_single_file(
    "https://huggingface.co/vrgamedevgirl84/Wan14BT2VFusioniX/blob/main/Wan14Bi2vFusioniX_fp16.safetensors",
    torch_dtype=torch.bfloat16
)

Para cargar los LoRA, utilice load_lora_weights():

pipe = DiffusionPipeline.from_pretrained(
    "Wan-AI/Wan2.1-T2V-14B-Diffusers",
    torch_dtype=torch.bfloat16
).to("cuda")
pipe.load_lora_weights(
    "vrgamedevgirl84/Wan14BT2VFusioniX", weight_name="FusionX_LoRa/Wan2.1_T2V_14B_FusionX_LoRA.safetensors"
)

AccVideo y CausVid (solo LoRA)

AccVideo y CausVid son dos técnicas de destilación novedosas que aceleran el tiempo de generación de modelos de difusión de video preservando la calidad. Los difusores admiten la carga de sus LoRA extraídos con sus respectivos modelos.

🌠 Nuevas canalizaciones de generación de imágenes

Cosmos Predict2 Texto2Imagen

Modelos de texto a imagen de la versión Cosmos-Predict2. Los modelos vienen en una variante 2B y 14B. Consulte los docs para obtener más información.

Croma

Chroma es un modelo de parámetros 8.9B basado en FLUX.1-schnell. Tiene licencia completa Apache 2.0, lo que garantiza que cualquiera puede usarlo, modificarlo y construir sobre él. Consulte los docs para obtener más información ¡Gracias a @Ednaordinary por contribuir en [este PR] (https://github.com/huggingface/diffusers/pull/11698)!

VisualCloze

[VisualCloze: un marco universal de generación de imágenes a través del aprendizaje visual en contexto] (https://huggingface.co/papers/2504.07960) es un marco innovador de generación de imágenes universal basado en un marco de aprendizaje en contexto que ofrece capacidades clave:

  1. Soporte para diversas tareas en el dominio.
  2. Generalización a tareas invisibles mediante el aprendizaje en contexto
  3. Unifique varias tareas en un solo paso y genere tanto la imagen de destino como resultados intermedios.
  4. Admitir condiciones de ingeniería inversa a partir de imágenes de destino Consulte los docs para obtener más información. ¡Gracias a @lzyhha por contribuir con esto en [este PR] (https://github.com/huggingface/diffusers/pull/11377)!

Mejor soporte para torch.compile

Hemos trabajado con el equipo de PyTorch para mejorar la forma en que brindamos compatibilidad con torch.compile() en toda la biblioteca. Más específicamente, ahora probamos los modelos ampliamente utilizados como Flux para detectar cualquier problema de recompilación y ruptura de gráficos que pueda obstaculizar el aprovechamiento total de los beneficios de torch.compile(). Consulte los siguientes enlaces para obtener más información:

  • https://github.com/huggingface/diffusers/pull/11085
  • https://github.com/huggingface/diffusers/issues/11430 Además, los usuarios pueden combinar la descarga con la compilación para obtener una mejor relación entre velocidad y memoria. A continuación se muestra un ejemplo: <detalles>

import torch

    ckpt_id,

)

    ckpt_id,
    subfolder="transformer",
    quantization_config=dit_quant_config,
    torch_dtype=torch_dtype,
)

    ckpt_id,
    transformer=transformer,
    text_encoder_2=text_encoder_2,
    torch_dtype=torch_dtype,

pipe.enable_model_cpu_offload()

    prompt="An astronaut riding a horse on Mars",
    guidance_scale=3.5,
    height=768,
    width=1360,
    num_inference_steps=28,

## Descarga grupal con disco
En la [versión anterior](https://github.com/huggingface/diffusers/releases/tag/v0.33.0), incluimos la "descarga grupal" que le permite descargar bloques/nodos dentro de un modelo, optimizando su consumo de memoria. También le permite superponer esta descarga con el cálculo, lo que proporciona una buena compensación entre velocidad y memoria, especialmente en entornos con poca VRAM.
Sin embargo, aún necesita una cantidad considerable de RAM del sistema para que la descarga funcione de manera efectiva. Por lo tanto, los entornos con poca VRAM y poca RAM aún no funcionarían. 
A partir de esta versión, los usuarios tendrán además la opción de descargar al disco en lugar de a la RAM, lo que reducirá aún más el consumo de memoria. Configure el `offload_to_disk_path` para habilitar esta función.
```python
pipeline.transformer.enable_group_offload(
    onload_device="cuda", 
    offload_device="cpu", 
    offload_type="leaf_level", 
    offload_to_disk_path="path/to/disk"
)

Consulte estas dos tablas para comparar las compensaciones entre velocidad y memoria.
