Stirling-PDF v3.0.2

Esta página está traducida automáticamente. El texto original en inglés es la referencia.

Stirling-PDF_0.33.1 Docker movimiento del cubo a Stirlingtools v3.0.2

Esta versión contiene correcciones de errores y varias otras mejoras. Mejoras:

  • agregar soporte para recorte selectivo de páginas
  • mejor recomendación de herramientas basada en el uso del usuario
  • agregar comentarios visuales durante el reordenamiento de la página

Errores solucionados:

  • faltan traducciones
  • Ciertos idiomas no se cargan correctamente
  • El procesador no se carga correctamente en ciertas versiones de la aplicación.
  • Latest-fat tiene problemas con la carga de archivos
  • El modo predeterminado como visor/lector no funciona correctamente
