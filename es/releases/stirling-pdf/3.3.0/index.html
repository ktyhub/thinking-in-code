Stirling-PDF_0.33.1 Docker movimiento del cubo a Stirlingtools v3.3.0

Se ha actualizado Stirling Office Convert (aún beta). Ahora también puede elegirlo como convertidor en muchas otras herramientas como correo electrónico, HTML, Markdown y libros electrónicos a PDF, además de PDF a HTML/Markdown/XML/EPUB/AZW3 y PDF/A. ¡Compárelo con el convertidor existente y háganoslo saber!

Nuestra hoja de ruta es activar Office Convert de forma predeterminada la próxima semana y luego, si no se requieren cambios, eliminar por completo LibreOffice y otras dependencias la semana siguiente. Así que ahora es el mejor momento para probarlo e informar (y enviar archivos de ejemplo) cualquier conversión que no parezca correcta.

Otros cambios son:

  • El inicio de sesión automático SSO ahora funciona incluso cuando el inicio de sesión con nombre de usuario/contraseña está habilitado (los administradores aún pueden acceder al formulario de contraseña a través de /login?all)
  • Actualización y compatibilidad con JPDFium y compatibilidad con Windows ARM64. Esta actualización también ofrece una mejor redacción, mejoras en la fusión/división y menor memoria en archivos grandes
  • Escaneo móvil más rápido y preciso, sin más OpenCV de 9 MB incluidos
  • Solicitudes más rápidas con muchas menos lecturas de bases de datos y almacenamiento en caché de nuevas entidades
  • Registros de inicio y tiempo de ejecución más silenciosos
  • Imagen base Spring Boot, Docker y muchas otras actualizaciones de dependencia
  • Traducciones actualizadas para todos los idiomas.

También solucionamos algunos errores, incluidos

  • Convertir el envío de cargas de archivos múltiples o mixtos a una conversión incorrecta
  • Configuración del libro electrónico restableciendo el formato de salida seleccionado
  • "Incluir todos los destinatarios" no controla CC/BCC en correo electrónico a PDF
  • Incrustación de fuentes PDF/UA, lo que hace que los campos del formulario ya no se puedan completar
  • Firma de certificado que rechaza claves PEM PKCS#8 no cifradas
  • El espectador se aleja de su página después de agregar un marcador
  • Se ofrece extracción de archivos para archivos que no son zip

Esta versión también incluye varias mejoras de seguridad y estabilidad, por lo que recomendamos a los usuarios que actualicen cuando sea posible. Nota: la antigua y obsoleta edición de texto PDF API se ha eliminado en favor del nuevo editor de texto. ¡Esperamos agregar pronto un nuevo editor de texto API!
