agentes-openai-python v0.21.0

Cambios clave

Esta versión menor no introduce ningún cambio importante conocido en el comportamiento de SDK. El aumento de la versión menor es para las nuevas pruebas neutrales del proveedor API y la actualización de compatibilidad OpenAI Python v3.

Aspectos destacados:

  • Se agregaron las utilidades agents.testing, agents.realtime.testing y agents.voice.testing para pruebas deterministas de flujo de trabajo de agente, sandbox, tiempo real y voz sin solicitudes del proveedor.
  • Se actualizó la compatibilidad del proveedor OpenAI con openai>=3.0.0,<4, incluida la solicitud, la respuesta, el transporte y el manejo de excepciones compatibles con HTTPX2.
  • Instantáneas de interrupción de RunState reforzadas, aprobaciones recursivas de herramientas de agente, finalización de turno máximo, limpieza de transmisión y redacción de errores sensibles.
  • Se mejoró el aislamiento de instantáneas del ciclo de vida de MCP y se agregaron límites máximos de reintento configurables.
  • Se agregó soporte para secretos existentes de Sandbox Runloop y se reforzaron las concesiones de ruta de visualización de imágenes.
  • Se agregó una validación de voz más estricta para canales no válidos, velocidades de cuadro, cuadros multicanal incompletos y velocidades de audio no finitas.
