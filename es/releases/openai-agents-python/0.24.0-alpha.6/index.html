agentes-openai-python v0.24.0-alpha.6

Instalar la vista previa

Utilice el estándar CPython 3.10–3.14 en un entorno virtual. Estas ruedas incluyen el tiempo de ejecución nativo; no se necesita ninguna cadena de herramientas Rust ni compilación de código fuente. Esta vista previa se distribuye a través de versiones GitHub, no de PyPI.

Ejecute el comando para su plataforma:

Linux x86_64 (glibc 2.39 o posterior)

python -m pip install "https://github.com/openai/openai-agents-python/releases/download/v0.24.0-alpha.6/openai_agents-0.24.0a6-cp310-abi3-manylinux_2_39_x86_64.whl"

macOS 11 o posterior en Apple Silicon

python -m pip install "https://github.com/openai/openai-agents-python/releases/download/v0.24.0-alpha.6/openai_agents-0.24.0a6-cp310-abi3-macosx_11_0_arm64.whl"

Windows x64

python -m pip install "https://github.com/openai/openai-agents-python/releases/download/v0.24.0-alpha.6/openai_agents-0.24.0a6-cp310-abi3-win_amd64.whl"

No se proporcionan ruedas para Intel Mac, ARM Linux, ARM Windows, Alpine/musl, PyPy o Python de subproceso libre. Los nombres de archivo cp310-abi3 también admiten el estándar CPython 3.11–3.14.

Verifique la versión instalada y el módulo nativo:

python -c "from importlib.metadata import version; import agents._native; print(version('openai-agents'))"

Espere 0.24.0-alpha.6 o su ortografía de empaquetado equivalente Python, 0.24.0a6. SHA256SUMS contiene sumas de comprobación para las tres ruedas.

Release note

Cambios desde 0.24.0-alpha.5. Esta vista previa amplía el control de conversaciones, la recuperación de estado y las políticas de herramientas, e incluye cambios públicos de API.

Agregado

  • Controlar el trabajo enviado a través de un Turn capturado, con get_result(), events() pasivo, manejo manual de solicitudes, dirección y cancelación. Haga cola con indicaciones con Session.submit(..., if_busy="queue") o dirija el giro activo con if_busy="steer".
  • Agregue LocalStorage para reabrir conversaciones desde un perfil local y amplíe la captura y recuperación portátil de SessionState. Agregue bifurcaciones inactivas, resúmenes de compactación proporcionados por las personas que llaman y verifique la compatibilidad de funciones y la preparación de los puntos de control. Los perfiles LocalStorage no pueden exportar puntos de control portátiles.
  • Agregue NativeOutput para salida estricta nativa y PromptedOutput para JSON validado en Python. El max_retries opcional realiza correcciones limitadas sin herramientas ni repetición de la tarea. LocalStorage requiere max_retries=0.
  • Manejar solicitudes de herramientas manuales en vivo y reanudar solicitudes pendientes admitidas desde puntos de control. Agregue recuperación experimental de trabajos externos a través de agents.experimental.deferred y un adaptador de tareas MCP opcional.
  • Seleccionar herramientas para cada paso de envío o modelo dentro de los permisos de apertura de la Sesión. Agregue búsqueda web nativa, listas de verificación secundarias nativas y objetivos nativos para sesiones de almacenamiento local.
  • Validar las anotaciones de retorno de la herramienta Python y agregar políticas de herramientas para inspeccionar argumentos y resultados. Amplíe el soporte nativo de MCP con reemplazo de argumentos, transformaciones de resultados e interacciones de URL y formularios administrados por aplicaciones a través de rutas HTTP, stdio y WebSocket modelo compatibles.
  • Agregue NetworkPolicy para comandos nativos en ejecutores compatibles con Linux y macOS, sujeto a la red de cada plataforma y los límites de socket Unix. Administre la vida útil de los ejecutores remotos a través de un Environment suministrado al abrir una sesión o ejecutar un agente.
  • Habilite aprobaciones de niños nativos y solicitudes de formularios con NativeAgents(interactions=True). Los niños continúan compartiendo las herramientas de la sesión y el contexto de aplicación.
  • Configurar la exportación nativa de OpenTelemetry e inspeccionar las observaciones escritas. NativeError ahora expone códigos de estado de proveedores, códigos de error, ID de solicitud y categorías de error disponibles.
  • Pruebe sesiones reales de SDK y herramientas Python con respuestas escritas localmente con agents.testing.ScriptedResponses, sin un modelo en vivo o clave API.

cambios API

  • Utilice Agent.run() o Agent.run_sync() para llamadas únicas; Se han eliminado los alias redundantes Runner.
  • Reemplace Turn.wait() y Session.wait() con Turn.get_result() en el Turno capturado.
  • Reemplace Session.interrupt() con Turn.cancel() para un turno raíz o Session.cancel_all() para toda la sesión.
  • Cambie el nombre de Subagent.submit() a Subagent.start(). Unifique las devoluciones de llamada y las herramientas manuales de Python en FunctionTool; elimine la declaración ManualTool separada.
  • Las declaraciones de agentes son inmutables. Cree un nuevo Agente para cambiar los valores predeterminados, use with_output_type() para una variante de tipo de salida o use actualizaciones de sesión inactiva admitidas para una conversación abierta.
  • La selección de herramientas y las actualizaciones de la sesión no pueden ampliar los permisos capturados cuando se abrió la sesión. Las sesiones restauradas utilizan herramientas, credenciales y políticas de aplicaciones actuales.

Fijo

  • Mantenga estable el resultado de cada giro capturado en la dirección aceptada, las continuaciones nativas y los envíos posteriores. Conserve los puntos de control manuales de un solo disparo, las respuestas de interacción coincidentes y el estado de reparación de salida a través de los límites de guardado y restauración admitidos.
  • Mejorar la cancelación de niños nativos y la limpieza de sesiones. Detenga el trabajo nativo cuando caduquen las políticas de resultados y conserve los motivos de falla de las políticas al informar los resultados raíz y secundarios.
  • Rechace los sobres de resultados de la herramienta Python con formato incorrecto y preserve los errores del servidor mediante transformaciones de resultados de MCP. Admite formularios de extensión OpenAI anidados y exportación de telemetría HTTP con certificados client.

Documentación y ejemplos

  • Mover la fuente de vista previa al repositorio público. Vuelva a centrar la guía de instalación en las ruedas prefabricadas y mueva las instrucciones de construcción de SDK a CONTRIBUTING.md.
  • Agregue ejemplos para aplicaciones de navegador, transmisión AG-UI, trabajos diferidos, evaluación, observabilidad y tareas comunes de aplicaciones. Elimine las guías de migración de la documentación de vista previa.

Comprobaciones de construcción e instalación

Fuente: 2808233a56c32c9d7bb8b4f3bc739fe86e5fc282. Las ruedas provienen de la [Prueba de ejecución] exitosa (https://github.com/openai/openai-agents-python/actions/runs/41606126874).
