códice rust-v0.170.0

Nuevas funciones

  • Se agregó negociación WebRTC para llamadas de voz en tiempo real en la TUI. (#61172)
  • Se agregaron encabezados de autenticación actualizados automáticamente para los exportadores HTTP OpenTelemetry. (#61028)
  • Se agregó soporte experimental para el uso de servidores MCP con nombres idénticos en todos los entornos. (#60905)

Corrección de errores

  • Las solicitudes de WebSocket de gran tamaño ahora recurren a HTTP sin reintentos innecesarios. (#60840, #60841)
  • Se corrigieron las carreras de credenciales de MCP OAuth durante la cancelación, el inicio de sesión y el cierre de sesión. (#60849, #60981)
  • Reconexión automática mejorada para conversaciones en la nube y turnos de recuperación activos conservados cuando clients se vuelven a conectar. (#60969, #61014)
  • Se corrigió el reemplazo de archivos de Windows, la preservación de permisos de zona de pruebas y la recuperación del registro de tiempo de ejecución. (#60872, #60943, #60944)
  • Se corrigieron las actualizaciones de permisos y los subprocesos secundarios que perdían las restricciones existentes de la zona de pruebas. (#60936, #61134)
  • Se eliminaron resultados de búsqueda de archivos duplicados y se corrigieron fragmentos de búsqueda de hilos para consultas que contienen espacios en blanco. (#60845, #60846)
