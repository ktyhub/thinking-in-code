códice rust-v0.163.0

Nuevas funciones

  • Abra /config para buscar preferencias en todas las categorías, cambiar las configuraciones admitidas inmediatamente y ver qué cambios requieren un reinicio. (#52990, #53429)
  • Enviar un seguimiento mientras el Codex responde para orientarlo de inmediato. Interrumpir un giro también detiene las celdas activas del modo de código y sus llamadas de herramientas anidadas. (#51812, #51835)
  • Configurar una clave líder en /keymap. El valor predeterminado es Ctrl+X, las sugerencias de atajos permanecen abiertas hasta que elijas o canceles, y el silencio de voz pasa a F9. (#52273)
  • Reinicie un servidor en segundo plano administrado desde /daemon. Codex advierte sobre el trabajo que el reinicio podría interrumpir y luego se vuelve a conectar automáticamente. (#53173)
  • Codex puede ejecutar herramientas independientes de solo lectura en paralelo, incluidas búsquedas de habilidades, memoria e historial de conversaciones. (#52245)
  • Daybreak está habilitado de forma predeterminada para cuentas elegibles. codex exec también puede seleccionarlo con una clave OpenAI API cuando el servidor ofrece acceso. (#53701, #53717)

Corrección de errores

  • Al reanudar un hilo guardado se restauran sus permisos y aprobaciones de red, respetando al mismo tiempo las anulaciones explícitas y la política administrada actual. (#53150, #53419, #53424)
  • El proxy de red ahora verifica el permiso antes de una búsqueda de DNS, rechaza encabezados Host duplicados y evita que los alias de credenciales pasen por alto los ganchos de inspección. (#51650, #52661, #53506)
  • Regresar a una conversación secundaria existente con /side después de cambiar de hilo. Las respuestas a las preguntas pendientes también regresan al hilo que preguntó. (#52184, #53436)
  • En Windows, Ctrl+V y Shift+Insert pegan texto e imágenes. En WSL, los pegados repetidos reutilizan el lector clipboard y los intentos de copia se agotan en lugar de colgarse. (#53224, #52967, #53453)
  • Los comandos locales finalizan rápidamente cuando un niño mantiene abierta una tubería de salida. Los comandos remotos preservan los resultados que llegan tarde para que la encuesta final aún pueda recopilarlos. (#52652, #53331, #53622)
  • codex exec ya no vuelve a imprimir el mismo archivo diff después de un comando no relacionado. (#53444)

Documentación

  • Se actualizó la guía de OpenAI Docs incluida para las migraciones a la familia GPT-6, incluido el razonamiento específico del modelo, el uso de herramientas y las consideraciones de residencia de datos. (#51768)
  • Se aclaró cómo el entorno limitado de Linux utiliza bubblewrap para el aislamiento del sistema de archivos y seccomp para el filtrado de llamadas al sistema. (#52610)

Tareas

  • Se redujo el tamaño del paquete de lanzamiento de Linux y macOS al eliminar los símbolos de los archivos binarios empaquetados y al mismo tiempo conservarlos en los resultados de la compilación original.
