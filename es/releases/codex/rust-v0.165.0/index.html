códice rust-v0.165.0

Nuevas funciones

  • Se agregó un proveedor de IA de Google Cloud Vertex integrado, configurado con model_provider = "gcp". (#56265)
  • Se agregó GPT-6.1 Terra a los catálogos de modelos. (#57337)
  • Se agregó un filtro de repositorio al selector de sesiones y a la agrupación de directorios en el centro de comando del agente, lo que facilita la navegación por sesiones a través de árboles de trabajo vinculados. (#56308)
  • Se agregaron bifurcaciones de subprocesos adjuntos experimentales al servidor de aplicaciones API. (#56351)
  • Se habilitaron cambios en el esfuerzo de razonamiento durante una conversación de forma predeterminada para los modelos compatibles. (#56163)
  • Se habilitó la memoria v2 de forma predeterminada para perfiles nuevos y se agregó soporte para importar memorias de agentes externos. (#56211, #56414)

Corrección de errores

  • Se corrigieron nuevas sesiones de TUI para honrar al revisor de aprobación predeterminado del servidor cuando no se proporciona una anulación explícita. (#56090)
  • Se mantuvieron las preferencias de TUI editables y aplicables inmediatamente cuando la configuración de ejecución no es válida. (#56091)
  • Se cancelaron las solicitudes de herramientas MCP remotas cuando se descartaron sus futuros de respuesta local. (#56132)
  • Se evitó que los mensajes del agente en cola reiniciaran el trabajo después de una interrupción o un cambio al modo Plan. (#56330)
  • Se dejó de reintentar cuando un proveedor informa que no se encontró un modelo, conservando su mensaje de error. (#56445)
  • Se cerró una brecha de validación de URL del mercado que podría permitir a Git conectarse a un host diferente al que se verificó con los patrones permitidos. (#56263) ##Changelog Completo Changelog: https://github.com/openai/codex/compare/rust-v0.164.0...rust-v0.165.0
