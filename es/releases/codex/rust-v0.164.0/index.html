códice rust-v0.164.0

Nuevas funciones

  • Guarde indicaciones reutilizables y comandos de barra diagonal en diez espacios /presets numerados, con un menú de teclado para un acceso rápido. (#54380, #54381)
  • Establezca perfiles de modelo, esfuerzo de razonamiento, velocidad y permisos directamente con argumentos /model y /permissions en línea. (#54378, #54383)
  • Vista previa de las imágenes vistas y generadas en la transcripción de pantalla completa en terminales compatibles con gráficos Kitty o Sixel. (#54216)
  • Autenticar conexiones MCP empresariales mediante concesiones de cuentas Codex elegibles o inicio de sesión dedicado, incluidos OAuth clients que requieren secretos. (#55334, #55859, #56001)
  • Enmascare las credenciales durante los comandos Bash remotos admitidos y las sesiones de instantáneas Zsh, incluidas las credenciales de proveedores personalizados. (#54309, #54432, #56049)
  • El asistente de configuración de Amazon Bedrock ahora está habilitado de forma predeterminada, con la entrada de clave API agrupada junto con otros métodos de inicio de sesión de AWS cuando se detectan credenciales. (#56033, #56023)

Corrección de errores

  • La compactación fallida ya no deja resúmenes parciales en el historial de conversaciones, y las fallas de compactación en segundo plano retroceden sin entrar en pánico. (#53932, #55581)
  • Al reanudar sesiones ahora se encuentran historiales comprimidos y se restauran las configuraciones de subprocesos guardadas en lugar de reemplazarlas con valores predeterminados globales. (#54008, #55923)
  • Las conexiones Windows HTTPS y WebSocket ahora manejan los desafíos de autenticación de proxy utilizando las credenciales Negotiate o NTLM del usuario que inició sesión. (#55994, #56000)
  • Las anulaciones de configuración de CLI se conservan cuando -c o --config aparecen en múltiples niveles de subcomando. (#56022)
  • Los mensajes en cola ahora esperan a que se resuelvan las selecciones de permisos pendientes antes de continuar. (#55682)
  • La zona de pruebas reforzada comprueba las rutas de metadatos con variantes entre mayúsculas y minúsculas en macOS y enlaces simbólicos reemplazables utilizados para localizar ejecutables. (#54273, #55384)
