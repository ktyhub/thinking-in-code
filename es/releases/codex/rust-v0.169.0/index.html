códice rust-v0.169.0

Nuevas funciones

  • El espacio de trabajo del terminal de suscripción admite múltiples pestañas de chat lateral. Cambie entre ellos con el teclado o el mouse y vuelva a abrir los chats secundarios locales guardados después de reiniciar Codex. (#59784, #60152, #60181)
  • Busque tareas anteriores desde el centro de comando del agente por nombre, vista previa del mensaje o directorio de trabajo. (#60286)
  • Active Contraer detalles del turno en la transcripción de pantalla completa para plegar la actividad completada debajo de cada mensaje mientras se mantienen las respuestas visibles y los resultados de la herramienta se pueden buscar. (#60554, #60555, #60556, #60557)
  • Agregar o editar proveedores de modelos personalizados desde la terminal. Con la incorporación de puerta de enlace personalizada habilitada, puede crear un proveedor durante el inicio de sesión y usar un código de dispositivo para puertas de enlace compatibles a través de SSH o sin un navegador local. (#59779, #60009, #60186, #60486, #60662)
  • Presione Ctrl+S en el editor de informes del terminal para guardar un ZIP de diagnóstico localmente, incluso cuando las cargas están deshabilitadas. (#60542)
  • Con la conexión a la nube opcional en macOS y Linux, envíe imágenes, elija un modelo y un esfuerzo de razonamiento y archive o restaure conversaciones en la nube desde la terminal. (#59828, #60061, #60635, #60651)

Corrección de errores

  • codex exec mantiene la configuración del proyecto y los servidores MCP deshabilitados en directorios no rust, incluso con --sandbox workspace-write. Utilice --trust con codex exec o codex review para guardar explícitamente el proyecto trust. (#60041)
  • Sí, contexto claro e implementación ahora entrega el plan aprobado completo a la nueva sesión y mantiene abierta la sesión actual si falla la transferencia. (#60763)
  • Se corrigió el manejo de la zona de pruebas de Windows para las rutas cmd.exe citadas y para las sesiones de PowerShell cuyo directorio de trabajo tiene un padre ilegible. (#60624, #60647)
  • Las imágenes pegadas en macOS conservan su orientación prevista y utilizan datos nativos PNG o JPEG clipboard cuando están disponibles. (#60455)
  • El terminal ya no permanece ocupado esperando servidores MCP que un servidor de aplicaciones compartido no informó. (#60280, #60622)
  • Los turnos interrumpidos ahora se cierran limpiamente y los abortos retrasados o las cancelaciones de aprobación de archivos ya no interrumpen un turno posterior. (#59910, #60700)

Documentación

  • Se actualizó la habilidad openai-docs para centrarse en las preguntas de trabajo de Codex y ChatGPT y la configuración inicial de API, con orientación dedicada para configurar Codex en un equipo. (#59944, #59949)
  • Se documentó cómo el servidor de aplicaciones clients puede enumerar modelos o autorizar una puerta de enlace para un proveedor configurado sin cambiar el proveedor predeterminado. (#59776, #59819)
