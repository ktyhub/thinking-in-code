dify 1.12.0

🚀 Nuevas funciones: índice resumido

Presentamos Summary Index, una potente mejora de nuestro sistema de recuperación de la base de conocimientos que mejora significativamente la precisión de la búsqueda al generar resúmenes impulsados por IA para fragmentos de documentos.

Fondo

La búsqueda vectorial tradicional se basa en incrustaciones de fragmentos sin procesar, que pueden pasar por alto matices semánticos y contexto al hacer coincidir las consultas de los usuarios. Esto es especialmente desafiante para documentos extensos o contenido complejo donde la información clave puede estar dispersa en varios fragmentos. Summary Index aborda esto mediante la creación de resúmenes concisos y semánticamente ricos para cada fragmento de documento, que luego se vectorizan y se utilizan como una capa de recuperación adicional.

Capacidades clave

  • Resumen impulsado por IA: Genera automáticamente resúmenes concisos para fragmentos de documentos utilizando modelos LLM configurables, capturando información semántica esencial en un formato compacto.
  • Soporte multimodal: Cuando se utilizan LLM con capacidad de visión (por ejemplo, GPT-4V, Claude-3), el sistema puede generar resúmenes que incorporan texto e imágenes de fragmentos de documentos, lo que proporciona una comprensión del contexto más rica.
  • Precisión de recuperación mejorada: Los vectores de resumen sirven como una capa de recuperación adicional, lo que mejora la precisión de las búsquedas en la base de conocimientos al hacer coincidir las consultas con el contenido original y los resúmenes generados por IA.
  • Configuración flexible: Admite mensajes de resumen predeterminados, lo que le permite personalizar el estilo de resumen para que coincida con los requisitos específicos de su dominio.
  • Procesamiento asincrónico: La generación de resumen se ejecuta de forma asincrónica, lo que garantiza que la indexación de documentos siga siendo rápida y sin bloqueos.
  • Edición manual de resúmenes: Le permite editar y refinar manualmente los resúmenes generados por IA para alinearse mejor con el contenido original, garantizando que los resúmenes reflejen con precisión la terminología y el contexto específicos del dominio.
  • Compatibilidad de estructura de índice: Funciona con modos de fragmentación general y de fragmentación padre-hijo, con manejo inteligente de relaciones jerárquicas de documentos.
  • Integración de índices de alta calidad: Disponible exclusivamente para conjuntos de datos que utilizan la técnica de indexación de "alta calidad", lo que garantiza un rendimiento óptimo para las bases de conocimiento de producción.

Otras mejoras

  • Compatibilidad multimodal de la aplicación del agente: La aplicación del agente ahora admite de forma nativa entradas multimodales (imágenes/archivos).
  • Búsqueda de texto completo de Qdrant: Se implementó la búsqueda de texto completo con soporte para múltiples palabras clave para la base de datos de vectores Qdrant.
  • Mejoras en el flujo de trabajo:
    • Se agregó soporte para registrar y leer contexto en flujos de trabajo.
    • Se agregó soporte OpenTelemetry para ejecuciones individuales.
  • Sistema de complementos: Se agregó una opción para eliminar o conservar las claves API al desinstalar un complemento.
  • Vista previa de la plantilla antes de crear: se agregó una vista previa detallada de la plantilla de la aplicación con gráficos de flujo de trabajo o configuraciones de la aplicación por tipo de aplicación.

🐞 Corrección de errores y actualizaciones de seguridad

  • Seguridad:
    • Corrección de seguridad del almacén de registros: se solucionó la posible inyección de SQL, problemas de serialización e inicialización optimizada.

    • tanstack devtools actualizado para corregir la vulnerabilidad seroval RCE.
    • Actualizaciones de seguridad para pdfminer.six, authlib, werkzeug, aiohttp y pycryptodome.
  • Motor de flujo de trabajo y gráficos:
    • Se solucionaron problemas por los que no se podían ejecutar nodos de iteración única o de bucle.
    • Se corrigió el fallo de NextStep cuando faltaba el nodo objetivo.
  • Se solucionó el problema de análisis del tipo de unión ToolInvokeMessage.

    • Se corrigió el patrón de recursos CORS para rutas /console/api.

⚙️ Cambios de configuración

  • SANDBOX_EXPIRED_RECORDS_CLEAN_TASK_LOCK_TTL: establece el TTL de bloqueo para la tarea de limpieza de registros caducados del sandbox (predeterminado: 90000).
  • SMTP_LOCAL_HOSTNAME: Anulación opcional del nombre de host local utilizado durante SMTP HELO/EHLO.
  • PLUGIN_MODEL_SCHEMA_CACHE_TTL: establece el TTL de caché para esquemas de modelo de complemento (predeterminado: 3600).
  • ENABLE_TRIAL_APP: Habilita la aplicación de prueba (Predeterminado: false).
  • ENABLE_EXPLORE_BANNER: Habilita explorar banner (Predeterminado: false).

Guía de actualización

Docker Redactar implementaciones

  1. Haga una copia de seguridad de su archivo personalizado docker-compose YAML (opcional)

    cd docker
cp docker-compose.yaml docker-compose.yaml.$(date +%s).bak

  2. Obtenga el código más reciente de la rama principal.

    git checkout main
git pull origin main

  3. Detenga el servicio. Ejecute en el directorio docker

    docker compose down

  4. Hacer una copia de seguridad de los datos

    tar -cvf volumes-$(date +%s).tgz volumes

  5. Servicios de actualización

    docker compose up -d
