dify 1.14.0

🚀 ¿Qué hay de nuevo en v1.14.0?

Colaboración

<img width="2632" height="1190" alt="img_v3_02117_67a67218-1ae5-4d68-a45b-3ada592f87fg" src="https://github.com/user-attachments/assets/1d4a3660-8a6a-4b29-9766-4d5b5fd9a51b" />

La colaboración permite a los miembros del espacio de trabajo editar juntos el mismo flujo de trabajo, con actualizaciones de gráficos sincronizadas, presencia en línea y visibilidad compartida de quién trabaja y dónde.

En implementaciones autohospedadas, la colaboración está desactivada de forma predeterminada. Habilítelo configurando:

ENABLE_COLLABORATION_MODE = true
SERVER_WORKER_CLASS = geventwebsocket.gunicorn.workers.GeventWebSocketWorker
NEXT_PUBLIC_SOCKET_URL = your deployment’s WebSocket URL (e.g., wss://dify.example.com)

Para obtener más detalles, consulte Documentación completa

Humano informado (HITL)

  • Servicio API para HITL: soporte programático para flujos humanos en el circuito junto con el comportamiento de la consola existente.

MCP y complementos

  • Metadatos de la herramienta MCP: se actualiza después de las actualizaciones para que la interfaz de usuario permanezca sincronizada.
  • URL del servidor MCP: corrige el doble /v1 que podría interrumpir OAuth y la autorización (404).
  • Descubrimiento de MCP OAuth: maneja de forma segura JSON con formato incorrecto.
  • Publicación de esquemas MCP: asigna los tipos checkbox y json_object correctamente.
  • Complementos: persistencia de la estrategia de actualización automática, instalador local y comportamiento de entrada de archivos, alcance del inquilino para la búsqueda interna del usuario final del API.

Mercado y OAuth

  • Marketplace y OAuth: correcciones específicas para los flujos del mercado y el inicio de sesión de OAuth (incluidos casos extremos como correo electrónico nulo en GitHub OAuth).

Kit de interfaz de usuario y plataforma front-end

  • @langgenius/dify-ui: primitivas compartidas (por ejemplo, PreviewCard, Meter), tokens de diseño y migración amplia desde web/base/ui ad-hoc hacia el paquete.
  • Accesibilidad: selectores de fecha y hora, selector de estrategia de actualización automática, barras de desplazamiento en selectores de complementos y modelos, y mejoras relacionadas.
  • Ir a cualquier cosa: elementos recientes, comando /go, subsecciones de aplicaciones más profundas; corrección para Cmd+K (se eliminó la importación dinámica problemática).
  • Editor de mensajes: filtrado de variables activado por barra diagonal; teclado arriba/abajo en listas de variables.
  • Preguntas de seguimiento: configuración mejorada y límites de tokens para preguntas sugeridas.
  • Modales: ApiKey, configuración del proveedor y otros refactorizados hacia un patrón de Diálogo compartido con pruebas.

Observabilidad y análisis

  • Langfuse: informes opcionales de tiempo hasta el primer token (TTFT).
  • Explorar: seguimiento de impresiones de banner; Seguimiento de eventos de vista previa de la aplicación en tarjetas.

Facturación y cuotas

  • Integración Quota v3 en el stack de productos.
  • IU de facturación: presentación de uso basada en medidores; limpieza más resistente cuando falla la facturación de los API.
  • Carga de archivos: comportamiento de facturación y actualizaciones de copia.

Datos, RAG y conocimiento

  • Índice resumido y Weaviate: correcciones de compatibilidad al utilizar el índice resumido con Weaviate.
  • Proyección vectorial: incluya is_summary y original_chunk_id en la proyección predeterminada cuando sea relevante.
  • Conjuntos de datos externos y vinculados: controles más estrictos de los inquilinos sobre los conocimientos API.

Infraestructura y operaciones

  • Docker Redactar: controles de estado para api, worker y worker_beat; Actualizaciones de ejemplo de plantilla y entorno (por ejemplo, estilo de dirección S3).
  • Apio: trabajador predeterminado concurrencia elevada a 4; falta solución de cola.
  • PostgreSQL: conexiones máximas predeterminadas más altas (200) para la ruta de base de datos de la aplicación actualizada.
  • Redis — prefijo de clave configurable; Lógica de reintento para operaciones Redis.
  • TiDB: compatibilidad con puntos finales y migración de enlaces de autenticación relacionados (punto final Qdrant en enlaces de autenticación TiDB).
  • Markdown: variable de entorno opcional ALLOW_INLINE_STYLES para permitir CSS en línea en Markdown renderizado cuando sea necesario.

Seguridad

  • Flujo de cambio de correo electrónico: manejo más estricto de tokens vinculados a fases (GHSA-4q3w-q5mc-45rq).
  • Refuerzo IDOR: validación de inquilinos en el enlace de fuente de datos; conjunto de datos y comprobaciones de propiedad de API donde se encontraron lagunas.

Rendimiento

  • Rendimiento optimizado de la inicialización de gráficos.

API y elementos internos de la plataforma

  • Graphon: actualice a Graphon 0.2.2 independiente (reemplazando el nombre y el empaquetado del dify_graph en el árbol).
  • OpenAPI — script para generar OpenAPI v2 JSON y puntero de documentación.
  • Desuso: algunas consolas heredadas API se marcaron como obsoletas en favor de patrones más nuevos.
  • Gran migración de SQLAlchemy 2.0 select(), Pydantic BaseModel para muchas respuestas de consola y servicio, y pruebas de estabilidad basadas en testcontainers.
