aplastar v0.74.1

parche del viernes

Terminando la semana con algunos arreglos.

Corrección para la herramienta bash

@taigrr ayudó con una solución para evitar que la herramienta bash se cuelgue cuando el modelo intenta ejecutar comandos interactivos como git rebase -i y otros.

Corrección de OpenCode + Qwen 3.7

Qwen3.7-Max a través de OpenCode no funciona. OpenCode requiere Anthropic Messages API para este modelo.

Client-servidor

Aún más correcciones para la arquitectura experimental del servidor client. Actualmente, regístrese a través de CRUSH_CLIENT_SERVER=1. ¡Eso es todo por esta semana! Encanto :destellos: ##Changelog
