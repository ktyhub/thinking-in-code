aplastar v0.91.2

Se corrigieron las correcciones de GitHub MCP + UI

Un pequeño parche con un par de correcciones.

Corregido GitHub MCP

El MCP GitHub dejó de funcionar en Crush en los últimos días, pero ahora vuelve a funcionar. Sabemos "sessionless": true (o --sessionless true) que algunos MCP podrían necesitar para funcionar correctamente. Para GitHub MCP, lo habilitaremos automáticamente para que funcione sin configuración adicional para usted.
