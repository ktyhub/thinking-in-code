aplastar v0.97.0

¡Aplastarlo!

¡Esta versión presenta muchas características nuevas que mejoran enormemente la calidad de vida! ¡Presentado por Charm y nuestros colaboradores favoritos!

Alternar MCP

Gracias al fantástico @BrunoKrugel, ahora puedes desactivar los servidores MCP desde la interfaz de usuario, de forma global o local.

<p><img width="600" height="2160" src="https://github.com/user-attachments/assets/9fb0304c-89aa-4b52-8fb4-f8016408a20c" /></p>

Ramas de Git

Por fin: @taciturnaxolotl y @Gustave-241021 han llevado la visualización de ramas de Git a Crush, lo cual es muy útil.

<p><img width="600" height="2160" src="https://github.com/user-attachments/assets/16c378cb-a8e1-4970-a38a-139e0ec815eb" /></p>

Más cambios en la interfaz de usuario y la calidad de vida:

  • ChatGPT OAuth ahora se actualiza con Catwalk
  • Claude Channels, parte 2/3 por @joestump
  • Activa y desactiva la barra lateral con <kbd>ctrl+b</kbd> por @andreynering
  • Salir de las mejoras en el diálogo y la compatibilidad con el mouse por @meowgorithm

¡Arreglado!

  • Se corrigió el informe falso del tablero clipboard de copias exitosas por parte de @taciturnaxolotl.
  • Cuente los tokens de creación de caché antrópicos por @ yanyukang2003-ux *Resolver correctamente el directorio de datos del proyecto en sesión y estadísticas por @devYRPauli

¡Esta versión está llena de mejoras! ¡Lea más a continuación!

Hasta la próxima, Encanto XX 🔆

Primero, descargue los archivos archivo checksums.txt y archivo checksums.txt.sigstore.json, por ejemplo, con wget:

wget 'https://github.com/charmbracelet/crush/releases/download/v0.97.0/checksums.txt'
wget 'https://github.com/charmbracelet/crush/releases/download/v0.97.0/checksums.txt.sigstore.json'

Luego, verifíquelo usando cosign:

cosign verify-blob \
  --certificate-identity 'https://github.com/charmbracelet/meta/.github/workflows/goreleaser.yml@refs/heads/main' \
  --certificate-oidc-issuer 'https://token.actions.githubusercontent.com' \
  --bundle 'checksums.txt.sigstore.json' \
  ./checksums.txt

Si el resultado es Verified OK, puede usarlo de forma segura para verificar las sumas de verificación de otros artefactos que descargó de la versión usando sha256sum:

sha256sum --ignore-missing -c checksums.txt
