aplastar v0.88.0

¡#.crushrc ya está aquí! ¡Ey! Espero que todos hayan tenido una gran semana. Fuimos bastante productivos en Charm y hoy lanzaremos algunas cosas interesantes.

¡Configuración de bash! (.crushrc)

¡Sí, .crushrc ha llegado! Su configuración JSON existente todavía funciona, ¡pero acabamos de comenzar a migrar a algo mucho más flexible! Un ejemplo de por qué esto es genial: si administra la configuración de Crush en un repositorio dotfiles, aún puede tener anulaciones específicas de la máquina usando source para llamar a un archivo separado que estará en su .gitignore. Estoy seguro de que hay muchos otros casos de uso. Para leer la documentación completa sobre esto, lea este documento. Mira un recorte para que tengas una idea de cómo se ve:

# Add Ollama.
provider add ollama --type ollama --base-url "http://localhost:11434/v1"

# Register a model on Ollama.
model add ollama/llama3.3 --name "Llama 3.3" --context-window 128000

# Auto-approve some tools.
permissions allow view edit

# Add an MCP server
mcp add github \
  --type http \
  --url "https://api.githubcopilot.com/mcp/" \
  --header Authorization "Bearer $GITHUB_TOKEN"

# Load some extra config
source "$XDG_CONFIG_HOME/squid-config.sh"

# Change config based on the machine you're on.
if [[ $HOSTNAME == "babysquid" ]]; then
    option skill-path "$HOME/squid-skills"
fi

¿Quieres dar tu opinión? Únase al canal #crush en Discord.

Mejor soporte de SSO de AWS Bedrock

¡@jan-xyz hizo un gran trabajo al darle vida a este! Cuando se utiliza AWS Bedrock a través de SSO, los tokens caducan con el tiempo y es necesario actualizarlos. Crush ahora tiene una configuración y UX adecuados para la autenticación, y aparecerá cada vez que sea necesario actualizar los tokens. Para leer más al respecto, consulte el n.° 2886. <img width="572" height="231" alt="Captura de pantalla 2026-07-31 a las 18 04 21" src="https://github.com/user-attachments/assets/993034d2-89d2-42f4-ba9c-30b01a1debd6" />

Recuperación de agentes más confiable

@sven2718 contribuyó con mejores reintentos en las búsquedas cuando no funcionan en el primer intento. Las búsquedas serán más fiables ahora, especialmente cuando se hacen muchas en un corto período de tiempo.

Solución para Fable 5

@sven2718 también contribuyó con una solución para Fable 5. Cuando Anthropic decida rechazar su mensaje por razones de seguridad, ahora aparecerá un mensaje de error adecuado en Crush. Antes, Crush simplemente se detenía sin dar contexto sobre por qué.

Crush ahora se compila en IlluminOS

¿Nunca has oído hablar de IllumiOS? ¡Ninguno de nosotros en Charm, pero @timotheosh ajustó el código para garantizar que se compila allí ahora! Go compila en muchos entornos y siempre es divertido ver a Crush funcionando en más sistemas operativos. Por cierto, ¿sabes que puedes usar Crush en Android? :robot:

MCP OAuth mejorado

En la última versión, incluimos compatibilidad con la autenticación OAuth para MCP. @BrunoKrugel hizo algunas correcciones para que más MCP que requieren OAuth funcionen como se esperaba.

Correcciones agentes

También se hicieron bastantes correcciones en Crush como agente. Algunos de estos se hicieron en Fantasy y se llevaron a Crush.

Nuevos modelos Hyper

No menos importante, seguimos trayendo actualizaciones a Hyper, que es más estable que nunca y ahora tiene Minimax M3 y Qwen3.7-Flash disponibles.

¡Pasaron muchas cosas esta semana! Esperamos que lo disfrutes y sigas aplastando :tm:! encanto ##Changelog
