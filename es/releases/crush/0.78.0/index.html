Modo explosión

"¿Qué es el modo explosión?" preguntas. Por qué es simplemente una buena manera de permitirle ejecutar comandos Bash directamente en una sesión. Es genial para aprovechar el caparazón sin salir de Crush. Para ingresar al modo bang, simplemente escriba !. Para salir, presione la tecla de retroceso.

<p><img width="600" height="1137" alt="Demostración del modo Bang" src="https://github.com/user-attachments/assets/710fadc0-dd14-4e42-b2a5-16ec62add197" /></p> <!-- <p> <img ancho="223" alto="102" src="https://github.com/user-attachments/assets/1111b58c-dff9-4978-a884-5faf1b37d44e" /> </p> <p> <img ancho="216" alto="80" src="https://github.com/user-attachments/assets/99f2a26a-a299-4601-b5db-373c1d0c8302" /> </p> --> Por supuesto, lo mejor del modo explosión es que el modelo también puede ver la salida, por lo que si ejecutas un comando puedes chatear con el modelo al respecto. <!-- <p> <img ancho="225" alto="88" src="https://github.com/user-attachments/assets/a639ada9-da25-458f-97c0-ca371e42eeb3" /> </p> --> <p> <img ancho="542" alto="357" src="https://github.com/user-attachments/assets/14cb91a1-4629-4ce6-a17a-a3b6f766651e" /> </p> Un agradecimiento especial a @taigrr por la implementación inicial a @taciturnaxolotl por mejorarlo varios niveles, con algunas sugerencias de @nobilelucifero. ¡Disfrútelo y háganos saber si tiene algún comentario! ## Descubrimiento automático del modelo local @taciturnaxolotl _ama_ las modelos locales. Lo que no le gustaba era agregarlos manualmente al Crush y, como un verdadero devoto del código abierto, tomó el asunto en sus propias manos. **Crush ahora puede descubrir automáticamente modelos locales** para un punto final determinado para que no tengas que declararlos manualmente. ```jsonc { // Look Ma, no manual model definitions! "providers": { "ollama": { "name": "Ollama", "base_url": "http://localhost:11434/v1/", "type": "ollama" } } } ``` Esto funciona para MLX, LMStudio, LiteLLM y Ollama. [Más información en el README](https://github.com/charmbracelet/crush#local-models). (¿Es genial o qué? ¡Que alguien le regale a @taciturnaxolotl un Strix Halo!) ## La placa cli: ahora cli más elegante que nunca Mejoramos a lo grande la forma en que funciona la placa cli en Crush, particularmente en X11 y Wayland: ¡`xclip` y `xsel` ya no son necesarios! También puede pegar archivos TIFF (usuarios de WeChat, ¡regocíjense!) y <kbd>super+v</kbd> (sí, <kbd>⌘+v</kbd>, gente de macOS) ahora también pegará imágenes. ## fuegos artificiales Por demanda popular, Crush ahora admite un nuevo proveedor: [Fireworks](https://fireworks.ai/). Toma tu llave API, elige un modelo en Fireworks y ve a la ciudad. ## Gracias ¡Como siempre, mantén la buena vibra y sigue aplastándola!
