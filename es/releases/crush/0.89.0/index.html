aplastar v0.89.0

Un par de ventajas de calidad de vida

Estamos lanzando algunas mejoras en la calidad de vida :tm: para usted. Son simples, pero estas mejoras simples se combinan con el tiempo para hacer que Crush sea cada vez mejor.

Consejo para salir de Crush

Al salir de Crush, verá una pantalla de presentación con un mensaje sobre cómo continuar rápidamente desde la sesión que dejó. <img width="468" height="351" alt="Captura de pantalla 2026-08-12 a las 16 41 43" src="https://github.com/user-attachments/assets/1b483466-f784-4176-9622-d3e4ca269839" />

Resaltado de sintaxis de la herramienta Bash

Al mostrar lo que Crush está ejecutando usando la herramienta Bash, el comando de shell ahora tendrá resaltado de sintaxis. Es una pequeña adición, pero definitivamente mejora la legibilidad.

Moo :vaca:

<img width="862" height="561" alt="Captura de pantalla 2026-08-12 a las 16 47 25" src="https://github.com/user-attachments/assets/9a8a4523-7a50-4b27-a63c-fb96406f8c9b" />

Ctrl+fin para saltar al final + seguir

Si desea saltar rápidamente al final del chat, ahora puede simplemente presionar <kbd>ctrl+end</kbd>. Esto también garantizará que Crush siga el chat a medida que lleguen nuevos mensajes.

Mejoras en MCP

Mejoramos cosas para hacerlo más estable y solucionamos un par de errores extremos. Eso es todo por hoy. ¡Nos vemos en el próximo lanzamiento! Encanto 💌 ##Changelog
