Banner de salida compacto

Ahora es posible configurar el banner de salidas para que sea más compacto, si así lo desea. .crushrc:

option ui exit-banner compact
option ui exit-banner none
option ui exit-banner default  # default

crush.json:

{
  "options": {
    "tui": {
      "exit_banner": "compact"
    }
  }
}
