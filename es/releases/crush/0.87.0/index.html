aplastar v0.87.0

MCP OAuth, rendimiento y más

¡Feliz viernes a todos! Estamos lanzando algunas funciones interesantes para que puedas disfrutar de tu vibecodificación de fin de semana. (¡O no, quédate afuera :sun_with_face: y regresa a Crush el lunes! :smiley:).

MCP OAuth

¡Eso es todo, finalmente está aquí! Algunos de vosotros habéis estado pidiendo esto desde hace mucho tiempo. Esto es necesario para que algunos MCP funcionen. ¿Quieres saber cómo configurarlo? Consulte esta sección en el archivo README. Gracias a @joestump y su agente @joestump-agent por esta contribución. Y por supuesto, nuestro @taciturnaxolotl favorito también ayudó.

Extensión MCP de Claude Channels

@joestump (y su agente) también agregaron una implementación inicial para admitir la [extensión MCP de Claude Channels] (https://code.claude.com/docs/en/channels-reference), lo que significa que los MCP ahora pueden enviar notificaciones a Crush cuando ocurren ciertos eventos. Pruébelo si está interesado y cuéntenos qué tan bien funciona para usted.

Mensajes de MCP restaurados

Los avisos de MCP se desactivaron involuntariamente en una versión anterior, ¡pero ahora se volvieron a agregar!

Aumento del rendimiento de LSP

Otra contribución interesante fue la de @TheJhyeFactor, quien mejoró enormemente el uso de CPU y memoria en el manejo de servidores LSP en repositorios grandes. ° 3370 para obtener una explicación más detallada de las optimizaciones.

Aumento del rendimiento del modo Bang

@TheJhyeFactor también mejoró el rendimiento de la transmisión de salida cuando se ejecuta el comando en modo bang. Consulte el n.° 3381 para ver algunas evaluaciones comparativas. ##/etc/crush/crush.json ¡Lo leíste bien! Gracias a @Muttaqin86 ahora puedes tener una configuración Crush para todo el sistema en /etc/crush/crush.json. La motivación para esto fue mejorar la compatibilidad con NixOS.

Copiloto fijo + GPT-5.6

Los tres modelos GPT-5.6 (Sol, Terra y Luna) ahora están arreglados cuando se ejecutan mediante el copiloto GitHub. ¡Felicitaciones a @nghiant03 por esto! Eso fue mucho, pero es realmente divertido ver cuánto está involucrada la comunidad con Crush dev. ¡Sigue aplastando! :tm: encanto ##Changelog
