aplastar v0.99.0

Ganchos, Pasarela v3!

¡Uno grande! Crush ahora se ejecuta en Catwalk v3, los ganchos pueden ver cada parte de una ejecución y los editores que alojan Crush obtienen un conjunto completamente nuevo de herramientas para sentirse como en casa.

Ganchos, por todos lados 🪝

Los ganchos ya no son sólo herramientas. ¡Ahora pueden seguir toda la carrera: sesiones, turnos, permisos y más!

Los ganchos ahora también pueden intervenir después de que se ejecuta una herramienta. Redacte secretos del resultado antes de que el modelo los vea, agregue una nota o detenga el turno. Si la herramienta ya hizo algo que no debería haber hecho, su gancho puede decirle al modelo "usted se comprometió sin ejecutar las pruebas".

hook add TurnEnd --name "ding" --command 'afplay /System/Library/Sounds/Glass.aiff'

Puedes leer más aquí

Client/modo servidor

Si crea algo que ejecuta Crush en su interior, esta versión es para usted:

  • Temas de host: la aplicación de host puede crear temas para la TUI en el servidor API, por lo que Crush coincide con sus aplicaciones.
  • Contexto del host: el host puede decirle a Crush lo que está a la vista, como archivos abiertos, y esos archivos aparecen en las terminaciones.
  • Agregar al siguiente mensaje: clients puede agregar texto que el agente lee en el siguiente mensaje, sin iniciar una ejecución ni saturar el chat.
  • Visualización compartida: clients puede ver qué sesión están viendo otros clients.
  • Permisos canalizados: establezca CRUSH_PERMISSIONS_PIPED=1 y el anfitrión responderá las solicitudes de permiso, para que no se le solicite dos veces.
  • Las direcciones http:// funcionan como alias para tcp:// al iniciar el servidor.

Servidor más estable

  • SIGHUP ahora recarga la configuración en lugar de detener el servidor.
  • Cerrar la terminal o detener Crush a través de un administrador de servicios ahora se cierra correctamente, por lo que el trabajo en progreso se guarda en lugar de quedar atascado.

Pequeña descripción general de Catwalk v3:

Crush ahora habla Catwalk v3. El proveedor type describe el formato API que utiliza un proveedor, no quién lo creó:

  • completions: API compatibles con OpenAI
  • responses: OpenAI, o cualquier cosa enrutada a través de él.
  • messages: API compatibles con antrópicos

Su configuración se migra automáticamente cuando se carga, por lo que openai, openai-compat y anthropic siguen funcionando. No se necesitan modificaciones.

A continuación aparecen las banderas provider add y model add:

crush provider add deepseek \
  --type completions \
  --base-url "https://api.deepseek.com/v1" \
  --api-key "$DEEPSEEK_API_KEY"

crush model add deepseek/deepseek-chat --thinking toggleable --max-attachments 5
  • --can-reason ahora es --thinking always|never|toggleable
  • --max-attachments N es nuevo
  • Los niveles de razonamiento muestran nombres descriptivos en el selector, como "X-High"

¡Eso es todo por ahora! Encanto XX 💫
