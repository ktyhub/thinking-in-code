aplastar v0.102.0

Canales, mensajes personalizados y refuerzo del servidor

Hay muchas cosas buenas en esta versión y estamos muy orgullosos de todas ellas. Siga leyendo para obtener más información.

Avisos BYO

Por fin, puedes reemplazar las indicaciones del sistema con… lo que quieras. Y no solo el agente principal, sino también solicitudes de subagentes, planificación, compactación, títulos de sesión y crush init:

option prompt coder ~/.config/crush/prompts/coder.md.tpl
option prompt summary prompts/summary.md

Puede configurar el mensaje en la configuración global, anular por proyecto en la configuración local o anular el mensaje con --prompt name=path. Para obtener más información sobre las indicaciones, consulte los documentos.

Montar en la noche

Crush ahora viene con un tema KITT inspirado en Knight Rider, cortesía de @cdancy. Rosé Pine Classic, Moon y Dawn ahora también están disponibles.

<p><img width="730" height="528" alt="image" src="https://github.com/user-attachments/assets/2c139b67-92a3-4600-9278-761c813699ed" /></p> ## Nerd con fuentes nerd ¡Por fin, fuentes nerd! ¡El soporte se detecta automáticamente, por lo que nunca dañarán tu terminal también! Crush ahora usa sus íconos, estado LSP y Git incluido. Tenga en cuenta que si está ejecutando Crush a través de SSH, deberá habilitar las fuentes Nerd `option ui nerd-fonts true`. ```bash # Hate nerd fonts? You can turn 'em off, too. option ui nerd-fonts false ``` ## Canales [Canales](https://code.claude.com/docs/en/channels-reference) son una función MCP experimental de Claude, ahora disponible en Crush gracias al excelente trabajo de @joestump. En resumen, los canales permiten a los servidores MCP enviar eventos a su sesión a medida que ocurren. ```bash crush --channels server:webhook --channels server:signal ``` O enciende uno permanentemente en tu `crushrc`: ```bash # crushrc mcp add webhook \ --type http \ --url https://example.com/mcp \ --channel true ``` Crush utiliza el mismo protocolo que [Claude Channels](https://code.claude.com/docs/en/channels-reference), por lo que los servidores de canales existentes deberían funcionar™. ## Refuerzo del servidor El modo de servidor Client es ahora más resistente que nunca. Ahora es más seguro y tiene un montón de pequeñas mejoras, correcciones de corrección y correcciones de errores, especialmente en Windows. ## Y mucho más - El modo Sysadmin ya no es un <kbd>shift+tab</kbd> después de yolo. - Las indicaciones en cola aparecen en la píldora en el momento en que las envías. - El modelo puede usar `sudo`, por lo que puedes aprobar con Touch ID. - Los rechazos de contenido se reintentan automáticamente. - Las sesiones que Claude siguió rechazando volvieron a funcionar. - Los modelos de Ollama que no pueden llamar a herramientas ya no aparecen en la lista de modelos. - Los comandos que dejan atrás los procesos secundarios ya no se bloquean. - Los temporizadores funcionan juntos y los temporizadores de las herramientas en ejecución continúan hasta que la herramienta responde. - Cambiar de tema ya no reproduce toda la conversación. - Eliminar una sesión mantiene tu lugar en la lista. - Los mensajes reproducidos mantienen sus espacios en blanco y las tarjetas de planes se alinean correctamente.
