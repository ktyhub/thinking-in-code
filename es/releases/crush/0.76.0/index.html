aplastar v0.76.0

parche del viernes

Envío de un par de cositas para los que seguiréis aplastando durante el fin de semana.

Corrección de permisos UX

Hicimos un cambio para evitar interacciones accidentales cuando se muestra el cuadro de diálogo de permiso. Crush ahora ignorará las pulsaciones de teclas hasta 350 ms después de que se muestre el cuadro de diálogo. Esto evitará que aceptes o rechaces algo por error mientras escribes cuando aparece el cuadro de diálogo.

Corrección crush models

crush models no mostrará todos los modelos, y no sólo los configurados.

Más servidor client

Y cada vez se fusionan más correcciones para la arquitectura experimental del servidor client. ¡Esto permitirá a Crush hacer cosas realmente buenas una vez terminado! Eso es para esta semana. ¡Disfruta tu fin de semana! Encanto ✨ ##Changelog
