v0.6.0 — Búsqueda semántica, ventajas SIMILAR_TO e inteligencia entre idiomas

Más de 85 confirmaciones desde v0.5.7. Lanzamiento importante que agrega búsqueda semántica basada en vectores, detección estructural de casi clones, resolución de importación en varios idiomas y mejoras significativas en la calidad de vida en todas las plataformas.

Búsqueda semántica e incrustaciones de vectores

  • Herramienta semantic_query: búsqueda vectorial basada en palabras clave en todo el gráfico base de código mediante la función SQL cbm_cosine_i8
  • Incrustaciones de código de inserción de nomic: 40.000 vectores de token previamente entrenados (768d int8), destilados de nomic-ai/nomic-embed-code con atención simulada
  • Puntuación combinada de 11 señales: TF-IDF, indexación aleatoria reflectante, firmas API/tipo/decorador, perfiles estructurales AST, flujo de datos aproximado, métricas Halstead-lite, MinHash, proximidad de módulo, difusión de gráficos
  • Bordes SEMANTICALLY_RELATED: conecta funciones con vocabulario que no coincide pero con un propósito similar (puntuación >= 0.80, máximo 10 por nodo, solo en el mismo idioma)
  • La puntuación de coseno mínimo por palabra clave reemplaza el promedio de vectores combinados para una mejor precisión
  • Fijación de puntuación en [0,1]: el multiplicador de proximidad ya no eleva las puntuaciones por encima de 1.0
  • Deduplicación de clones: SIMILAR_TO pares con Jaccard >= umbral omitir SEMANTICALMENTE_RELACIONADO

SIMILAR_TO Bordes (detección de casi clones)

  • Huellas dactilares MinHash: firmas de 64 hash de tokens AST de solo hoja con ponderación estructural
  • Índice LSH: hash sensible a la localidad basado en bandas para la recuperación de candidatos O(1)
  • Puntuación paralela: el grupo de trabajadores consulta LSH, califica a los candidatos y emite ventajas
  • La puerta de trigrama única filtra funciones trivialmente cortas
  • Bordes SIMILAR_TO con similitud de Jaccard y bandera del mismo archivo en propiedades

Búsqueda de texto completo

  • Búsqueda de texto completo BM25 a través de FTS5 con tokenizador cbm_camel_split (conforme a camelCase/snake_case)
  • Reconstrucción incremental de FTS5 en actualizaciones de índice

Nuevos tipos de bordes y detección

  • Bordes EMITS / LISTENS_ON para Socket.IO, EventEmitter y patrones de canales genéricos
  • Resolución constante: const EVENT = "foo"; emit(EVENT) resuelve nombres de canales a través de tablas constantes por archivo
  • Bordes IMPORTS con resolución de ruta relativa para JS/TS (./foo, ../bar), Python (.helpers, ..utils), Ruby
  • DATA_FLOWS bordes con mapeo de argumento a parámetro + cadenas de acceso a campos
  • Descubrimiento de comunicación entre servicios + indexación incremental de RAM primero
  • Registro de ruta basado en AST que reemplaza la infraestructura de preescaneado
  • Extracción de enlaces de infraestructura HCL + corrección de falso positivo del decorador de prefijo
  • Registro de ruta generalizada + puente vinculante de infraestructura.

Mejoras en herramientas y consultas de gráficos

  • 6 parámetros previamente ignorados conectados: filtro min_degree, max_degree, exclude_entry_points, include_connected, aspects, since para detect_changes
  • Parámetro include_tests en trace_path: marca los archivos de prueba en los resultados de BFS
  • risk_labels en trace_path para seguimiento de rutas sensibles a la seguridad
  • Marca --progress CLI para comentarios de indexación en tiempo real
  • CBM_CACHE_DIR env var para directorio de base de datos configurable
  • Modo de índice moderate agregado al esquema de la herramienta (entre completo y rápido)
  • Exposición de propiedades de esquema para param_names, param_types, decorators
  • Solución include_connected: BFS entrante+saliente se ejecuta por separado (se fusionaba incorrectamente)

Calidad de vida

  • Soporte anidado para .gitignore: el subdirectorio gitignores ahora se respeta durante la indexación; es fundamental para monorepos (#178)
  • Consolidación de habilidades: 4 habilidades separadas fusionadas en 1 con divulgación progresiva
  • Actualización inteligente: skip update when already on latest version
  • Detección binaria en tiempo de ejecución en el comando de instalación (ya no está codificado)
  • Soporte de submódulo Git en el observador: detecta estado sucio dentro de los submódulos
  • Rápido→detección de cambio de modo completo + UI habilitada automáticamente para binario de variante de interfaz de usuario
  • Punto final de diseño: mapeo de bordes O(n*e) reemplazado con búsqueda binaria
  • Diseño JSON: maneja UTF-8 y NaN no válidos en la serialización

Correcciones de plataforma

  • Windows: rutas de configuración de Zed/VS Code/KiloCode, delimitador de RUTA, verificación S_IXUSR, detección de agente usando rutas relativas a home_dir, prueba de configuración de usuario basada en APPDATA
  • Linux portátil: compatibilidad con Alpine musl, auditorías de seguridad agregadas a las pruebas de humo, XDG_CONFIG_HOME en ambiente de humo
  • Ensamblaje de blobs vectoriales multiplataforma: condicionales de preprocesador para macOS Mach-O / Linux ELF / Windows COFF
  • Corrección SEGV de C++: deref NULL en el solucionador de tipo LSP en archivos de encabezado grandes

Calidad del código y pelusa

  • 337 advertencias de linter resueltas en 16 archivos (constantes con nombre, extracción de complejidad cognitiva)
  • Umbral de complejidad cognitiva establecido en el valor predeterminado de la industria (25), 168 funciones divididas
  • División de función divina cbm_write_db (569 → 325 líneas)
  • Se eliminaron todas las supresiones de NOLINTNEXTLINE, caminantes AST iterativos
  • Corrección de fugas de ASan en el corpus semántico token_map

CI/CD y seguridad

  • Puerta de seguridad desacoplada: seguridad estática + CodeQL se ejecuta de forma independiente, no bloquea la tubería de prueba/construcción/fuma
  • Auditorías de seguridad en TODAS las variantes binarias (estándar + UI): anteriormente, los binarios de UI no estaban auditados
  • Vocabulario de tokens seguro para AV: 11 palabras de activación heurística eliminadas de las incrustaciones de Nomic
  • CI dividida en componentes de flujo de trabajo reutilizables
  • Mejoras en la dependencia del proveedor: SQLite 3.51.3, Mongoose 7.21, mimalloc 3.2.8
  • Acciones eliminadas: descargar-artefacto v8.0.1, attest-sbom v2, cosign v4.1.1, msys2 v2.31.0, checkout v6.0.2, caché v5.0.4, cargar-artefacto v7.0.0, attest-build-procedencia v4.1.0, codeql-action v4.35.1
