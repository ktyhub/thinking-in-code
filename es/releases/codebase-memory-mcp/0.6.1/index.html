v0.6.1: 89 nuevos idiomas, inteligencia entre repositorios, artefacto gráfico compartido en equipo, distribución npm+PyPI

Más de 50 confirmaciones desde v0.6.0. Agrega 89 gramáticas de cuidado de árboles (66 → 155 idiomas), introduce inteligencia entre repositorios con bordes CROSS_*, envía artefactos gráficos compartidos por el equipo (.codebase-memory/graph.db.zst), presenta contenedores de distribución completos (npm/PyPI/Homebrew/Scoop/Winget/Chocolatey/AUR/Go) con npm + PyPI ahora con publicación automática como parte del proceso de lanzamiento e implementa seguridad integral del instalador. endurecimiento.

Idiomas y análisis — 66 → 155

  • Se venden 89 nuevas gramáticas cuidadoras de árboles, con tokenización limpia de vocabulario y script de auditoría de seguridad gramatical
  • Cobertura de especificaciones de idioma completada para 114 idiomas con tipos de nodos adecuados: Go (func_literal), JS (do_statement, case_clause fijo y obsoleto), importaciones de C#/Python, matrices compartidas
  • 77 nuevas pruebas de mapeo de extensiones que cubren los nuevos idiomas
  • C#, Rust, gramáticas de Scala actualizadas a la última versión
  • Refactorización lang_specs: inicializadores designados + puntero de fábrica

Inteligencia entre repositorios

  • CROSS_ tipos de borde* para dependencias entre repositorios y relaciones arquitectónicas
  • gRPC / GraphQL / tRPC detección de servicio con extracción de ruta protobuf
  • Detección de código auxiliar gRPC en resolución de llamadas + extracción de llamadas encadenadas
  • Diseño de interfaz de usuario multigalaxia + vista resumida de arquitectura entre repositorios

Artefacto gráfico compartido en equipo

  • .codebase-memory/graph.db.zst: gráfico de conocimiento comprimido con zstd que se puede enviar al repositorio. Los compañeros de equipo arrancan desde el artefacto en lugar de ejecutar una reindexación completa desde cero.
  • Zstd 1.5.7 suministrado (fusionado, ~52K LOC) para compresión 8–13:1
  • Exportación de dos niveles: zstd -9 + eliminación de índices + VACUUM INTO para índices explícitos (mejor relación); zstd -3 para vigilancia/actualizaciones automáticas incrementales (baja latencia)
  • Ruta de importación: descomprimir → verificación de integridad → recrear índices automáticamente
  • Auto-bootstrap en index_repository: cuando no existe una base de datos local pero el artefacto está presente, importe primero y luego ejecute la indexación incremental
  • Crea automáticamente .gitattributes con merge=ours para evitar conflictos de fusión en el artefacto binario

Importaciones y canales

  • Resolución genérica de paquete/módulo para IMPORTACIONES en 10 idiomas (resuelve especificadores básicos como @myorg/pkg, github.com/foo/bar, use my_crate::foo mediante escaneo de manifiesto: package.json, go.mod, Cargo.toml, pyproject.toml, composer.json, pubspec.yaml, pom.xml, build.gradle, mix.exs, *.gemspec)
  • Detección de canales ampliada de JS/TS a 8 idiomas

Distribución

Ahora instalable directamente desde registros de paquetes públicos:

npm install -g codebase-memory-mcp     # npm
pip install codebase-memory-mcp         # PyPI
go install github.com/DeusData/codebase-memory-mcp/pkg/go@latest   # Go
  • npm + PyPI auto-publicación integrada en el proceso de lanzamiento (trabajo publish-registries después de verify, luego el atómico publish-final anula el borrador de la versión GitHub solo después de que ambos registros se realicen correctamente; no hay estado medio enviado)
  • paquete npm usa --provenance (certificaciones de compilación OIDC de GitHub visibles en npmjs.com)
  • Envoltorios de distribución completos en pkg/ para: npm, PyPI, Homebrew, Scoop, Winget, Chocolatey, AUR, Go

Refuerzo de la seguridad

  • Instalador de PyPI: reforzado contra ataques de confusión de esquemas y deslizamiento de tar (PR #248 por @dLo999, cierra #246)
  • instalador npm: verificación de suma de comprobación, redirecciones solo HTTPS, sin inyección de shell
  • Refuerzo entre instaladores: se eliminó Unblock-File, se agregó validación de URL solo HTTPS
  • vite pasó a 6.4.2 — corrige CVE GHSA-4w7w-66w2-5vf9 y GHSA-p9ff-h696-f583
  • Auditoría de seguridad gramatical agregada al canal de proveedores
  • LÉAME: enlaces de escaneo VirusTotal (hashes binarios), insignia SLSA, sección Seguridad y Trust, descargo de responsabilidad de transparencia, invitación de divulgación responsable
  • Insignia de papel arXiv + cita

Estabilidad y calidad

  • get_graph_schema ahora expone definiciones de propiedades por etiqueta de nodo
  • páginas de desbordamiento de sqlite_writer: corrige SIGBUS en registros grandes (#139)
  • Reclamación RSS después de delete_project: mem_collect explícito + purga inmediata
  • Herramientas MCP / CLI: manejo de errores, diagnóstico y cancelación mejorados
  • Extracción seleccionada y mejoras de Cypher del PR #162

Integración de editor/agente

  • Soporte de Kiro CLI (#96)

Correcciones de plataforma

  • Windows: pass_pkgmap ahora usa cbm_strndup (mingw clang carece de POSIX strndup)
  • test_watcher: utiliza GIT_AUTHOR_* / GIT_COMMITTER_* env vars en lugar de mutar la configuración global de git

CI / Humo

  • Análisis de prueba de humo JSON arreglado: el modo predeterminado CLI desenvuelve el sobre MCP; Smoke ahora analiza el JSON interno directamente
  • Lista permitida de auditoría de cadenas binarias: el esquema URI telnet de la primera gramática está documentado como una coincidencia benigna conocida

Colaboradores

Gracias a todos los que contribuyeron a este lanzamiento:

  • @dLo999 — Refuerzo del instalador de PyPI (#248)
