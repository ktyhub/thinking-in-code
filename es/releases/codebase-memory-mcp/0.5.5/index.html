codebase-memory-mcp v0.5.5

código base-memoria-mcp v0.5.5

Seguridad

  • CodeQL SAST: análisis estático con modo de compilación manual (100% de cobertura de fuente), puerta de alertas cero abiertas
  • Eliminación de inyección de shell: se reemplazaron las llamadas system() con cbm_exec_no_shell() (fork+execvp), no llegan datos contaminados al shell
  • correcciones de desbordamiento de snprintf — Se corrigieron 11 vulnerabilidades de desbordamiento del búfer (compensación de abrazadera después de cada adición)
  • Correcciones de raza TOCTOU — permisos de archivos atómicos, patrón abrir y luego fstat
  • 31 pruebas de defensa de seguridad: inyección de shell, autorizador SQLite, inyección SQL mediante Cypher, contención de ruta, ejecutivo sin shell
  • Prueba Fuzz: JSON-RPC aleatorio/mutado + entradas Cypher en cada compilación
  • Análisis antivirus nativo: Windows Defender, ClamAV (Linux + macOS) en cada versión
  • Puerta de tolerancia cero VirusTotal: todos los archivos binarios de lanzamiento escaneados por más de 70 motores antes de su publicación.
  • Procedencia SLSA + Sigstore cosign + SBOM (SPDX 2.3) + Sumas de comprobación SHA-256
  • GitHub Acciones fijadas a SHA con Dependabot

Prevención de falsos positivos antivirus

Se agregó escaneo AV multicapa al proceso de compilación para detectar y evitar falsos positivos antes de que lleguen a los usuarios. Se eliminaron las cadenas de seguimiento de resolución de DLL que activaron la detección heurística. Cada binario de esta versión ha sido verificado como limpio por más de 70 motores antivirus a través de VirusTotal. (Correcciones #89)

Nuevas funciones

  • Transporte enmarcado de longitud de contenido: compatibilidad con OpenCode
  • Detección de 10 agentes — Compatibilidad con OpenClaw + VS Code
  • Ubicación de configuración de MCP dual — ~/.claude/.mcp.json + ~/.claude.json

Corrección de errores

  • Arreglar la extracción de llamadas Swift: 0 bordes de LLAMADAS (#43)
  • Corregir falsos positivos de ruta de Laravel: alcance de extensión + filtro de ruta (PR #65)
  • Puerto FastAPI Depende() seguimiento de bordes (PR #66)
  • Mantener el modo de diario WAL durante la escritura masiva (PR #72)
  • Arreglar la compatibilidad con VS Code (PR #79)
  • Eliminar el seguimiento de resolución de DLL (falso positivo de Windows Defender)

Colaboradores

Gracias a @halindrome, @bingh0, @mariomeyer, @kingchenc por sus contribuciones de código y a @Maton-Nenoso por informar el número 89 que condujo a la infraestructura integral de escaneo AV en esta versión.
