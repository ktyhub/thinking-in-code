#JecgBoot v3.9.0

Hora de lanzamiento: v3.9.0 | 2025-12-01

Descarga del código fuente

  • Dirección Github: https://github.com/jeecgboot/JeecgBoot
  • Dirección del alojamiento: https://gitee.com/jeecg/JeecgBoot

Registro de actualización

Esta actualización actualiza langchain4j a 1.3.0, fortalece las funciones de IA, agrega MCP y compatibilidad con complementos, permite operaciones comerciales de estilo chat (como "crear usuario en una oración") y amplía las capacidades de orquestación de procesos y chat de IA. Integre modelos de razonamiento y búsqueda de red Anthropic (Claude) para mejorar las capacidades de pensamiento profundo del sistema. Se completó la actualización de POI a la versión 5 y se optimizaron las funciones de administración del sistema, como usuarios, departamentos e inquilinos. A partir de v3.9.0+, se detendrá la actualización simultánea a Spring Boot versión 2.

Mejora de la función AI
  • Actualice langchain4j a la versión 1.3.0.
  • Las aplicaciones de IA agregan soporte para MCP y complementos.
  • La función de chat AI admite MCP y extensiones de complementos.
  • La orquestación de procesos de IA agrega compatibilidad con MCP y complementos.
  • Admite chat de IA para hacer negocios (por ejemplo: crear un usuario en una oración)
  • Se agregó soporte para proveedores de modelos Anthropic (Claude).
  • El chat de IA admite modelos de razonamiento para mejorar las capacidades de pensamiento en profundidad.
  • El proceso de IA admite funciones de exportación e importación
  • El nodo de secuencia de comandos AI admite la escritura en lenguaje Python
  • El chat AI integra el modelo Qianwen y admite la función de búsqueda en línea
  • Admite más de 2000 vectores dimensionales, la versión de pgvector debe ser mayor que 0.7
Actualización de la arquitectura funcional
  • A partir de la versión v3.9.0+, la versión Spring Boot 2 ya no se actualizará simultáneamente.
  • Eliminar registros de modificación en lotes para mejorar la legibilidad del código.
  • PDI actualizado a la versión 5.
  • Actualice el número de versión menor del paquete dependiente en package.json
  • El informe del bloque de construcción se actualizó a la última versión v2.2.0.
  • Building Block BI se ha actualizado a la última versión v2.2.0, con una nueva función de cambio de pantalla múltiple y el diseño de pantalla grande admite exportación e importación.
  • Integrar vite-plugin-pwa para implementar Aplicaciones Web Progresivas (PWA), mejorando significativamente la velocidad de carga de la primera pantalla.
  • Los recursos del sistema se cargan de forma asincrónica y los menús responden más rápido.
  • La contraseña de inicio de sesión se transmite mediante cifrado AES para evitar la transmisión de texto claro y mejorar la seguridad.
  • Admite configurar el período de validez de las sesiones de inicio de sesión de la APLICACIÓN y la PC por separado.
  • Admite configuración flexible de reglas de inicio de sesión:
  • Si se permite iniciar sesión en la misma cuenta desde varios lugares al mismo tiempo.
  • Si se debe habilitar el recordatorio de inicio de sesión con contraseña predeterminada.
  • Si se debe habilitar la verificación del código de verificación de inicio de sesión.
  • Los usuarios que inician sesión admiten reglas de inicio de sesión diferenciadoras (distinguiendo entre PC y APLICACIÓN) y registran información del dispositivo terminal para facilitar la implementación de la función push de la APLICACIÓN.
  • La gestión de departamento ha agregado la función de visualizar a los jefes de departamento.
  • La gestión del departamento admite el ajuste de arrastrar y soltar de las relaciones superior-subordinado del departamento para mejorar la conveniencia operativa.
  • Las posiciones de los usuarios se ajustan a una estructura de tabla relacional para optimizar la gestión de asociación de datos.
  • La interfaz de mi inquilino ha sido revisada para mejorar la experiencia general del usuario.
  • Optimice las reglas de contraseña predeterminadas para mejorar la seguridad.
  • Admite ocultar la información de contacto del usuario para proteger la privacidad.
  • Optimización del editor de texto enriquecido: las imágenes de los artículos copiados de blogs se descargan y cargan automáticamente en el almacenamiento en la nube
  • Se agregó la función de selección de departamento a la página de inicio de sesión.
  • La página de lista BasicTable admite la especificación de columnas de exportación al exportar a Excel
  • La función push uniapp admite mensajes en línea y fuera de línea (ya conectados a los anuncios del sistema)
  • El nivel de registro se ajusta desde información hasta depuración para reducir la cantidad de salida del registro.
  • Optimice algunas fallas funcionales causadas por la carga retrasada y corrija la falla de anotación ignorada del token.
  • Los códigos generados se exportan uniformemente al formato xlsx
  • Mis mensajes admite la eliminación por lotes de mensajes leídos
  • Actualice shardingsphere-jdbc a 5.5.0 para simplificar la configuración de la fuente de datos de ShardingSphere
  • La gestión de usuarios admite la consulta de usuarios por estructura organizativa (admite selección múltiple)
  • Se agregan nuevos campos de clasificación a la gestión de usuarios y funciones como componentes de selección de personas y libretas de direcciones se muestran según los campos de clasificación.
Función de optimización en línea
  • Se agregó soporte de tipo largo para complementar el soporte de tipo largo que falta para el tipo db en línea
  • Agregue capacidades SQL generadas por IA para informes en línea
  • Admite la función de generar datos de prueba a partir de tablas maestras y subtablas, y mejora la generación de datos de prueba de IA en línea
  • Se corrigieron errores graves en los formularios en línea, que afectaban todas las funciones del formulario relacionadas con consultas de configuración y se optimizaron las mejoras de Java.
  • Después de editar la subtabla uno a uno, los datos en la página de detalles no se actualizan en tiempo real.
  • Después de hacer clic en la consulta en el componente avanzado superQuery, la ventana emergente no se cerró automáticamente.
  • Se solucionó el problema de que la consulta de enlace de formulario en línea no puede desdibujar las opciones de búsqueda y se agregó la función de búsqueda del componente de enlace desplegable para implementar
  • Se solucionó el problema por el cual el valor original se muestra en la página de detalles del campo de tipo de control de cambio en el desarrollo de formularios en línea (el estado del cambio se muestra al ver la página de detalles)
  • Se solucionó el problema de no tener permiso para acceder al expandir los detalles de la lista de temas de subtabla incrustados (uno a muchos)
  • Se solucionó el problema del evento onChange no válido de la ventana emergente en la ventana emergente mejorada de JS.
  • Optimice el contenido y el estilo de la ventana emergente de confirmación de la operación de eliminación para mejorar la experiencia del usuario.
  • Se solucionó el problema de la barra de desplazamiento en la tabla principal en línea de estilo ERP cuando la cantidad de elementos de datos es 5.
  • Limite la altura fija de la mesa principal de estilo ERP en línea para evitar anomalías en la altura
  • Ya no se muestra información sobre herramientas al generar datos de prueba.
  • Se solucionó el problema de inconsistencia entre el título y el contenido de la página de programación del tema TAB del formulario en línea.
  • La vista previa del código admite la función de arrastre hacia la izquierda y hacia la derecha
  • Se corrigió la visualización anormal de múltiples imágenes en el control de imágenes del formulario en línea.
  • La ventana emergente mejorada de JS admite el paso de accesorios del componente basicModal
  • Se solucionó el problema de que la página de detalles del cuadro de búsqueda desplegable en línea no podía leer el diccionario de datos correctamente.
  • Se solucionó el problema del informe de errores al exportar datos después de vincular el cuadro de búsqueda desplegable al diccionario de datos.
  • Resuelva el problema del error de importación causado por la exportación de datos de tipo doble con punto decimal ".0" en el estilo incrustado de los formularios en línea.
  • Se solucionó el problema de que el control de campo de tipo de fecha generado por la creación de tablas en línea es un cuadro de entrada
  • Resuelva el error que después de actualizar mybatisPlus, la paginación de SqlServer debe tener clasificación al usar OFFSET
  • En la generación de código en línea, los elementos de configuración se pasan para admitir la mejora de JS y el código lógico de mejora de Java.
  • Optimice la estética de la barra de desplazamiento de la lista en la interfaz de configuración del informe en línea
  • Agregar indicaciones de operación al generar código
  • Después de que el código genera directamente el proyecto front-end, la función de recordatorio se actualiza automáticamente
