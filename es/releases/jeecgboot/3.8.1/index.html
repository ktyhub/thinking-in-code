#JecgBoot v3.8.1

Registro de actualización

Lanzó una serie de nuevas funciones; Las funciones de la plataforma de aplicaciones de IA son estables; admite aplicaciones de escritorio de Electron; Función OpenAPI basada en autenticación AK y SK; la importación de usuarios admite la importación de departamentos y roles; La generación de código admite controles de registro asociados, mejoras de js y botones personalizados, etc.

Nuevas funciones
  • [Actualización importante] La función del módulo de aplicación de IA se ha estabilizado y ha alcanzado los estándares en línea.
  • [Nueva función] Admite el empaquetado de aplicaciones de escritorio electrónicas, utilizando Vite+Vue3+Electron para crear aplicaciones de escritorio cliente (admite tres plataformas principales: Windows, Linux y macOS)
  • [Nueva función] "Función OpenAPI basada en autenticación y autenticación AK y SK" para resolver las necesidades de API externo
  • [Nueva función] La importación de usuarios admite la importación de departamentos y roles
  • [Nueva función] Proporciona una plantilla de generador de código para la nueva versión de uniapp
  • [Nuevas funciones] La generación de código admite controles de registro asociados, mejora de js y métodos vacíos de generación de botones personalizados;
  • [AI] El cuadro de diálogo AI admite terminal móvil
  • [Optimización] Admite nueva versión de la lógica de inicio de sesión de DingTalk
  • [Optimización] Uso simplificado de funciones multiinquilino
  • [Nueva función] Proporciona ejemplos de AI OCR
  • Gestión de mi departamento, permitiendo agregar y eliminar subdepartamentos.
  • Elimina el código jsqlparse y migralo a minidao. La actualización ya no se ve afectada por la compatibilidad con jsqlparse.
  • [AI] Compatible con jdk21, por lo que se puede iniciar el programa, pero indica que no se puede utilizar la orquestación de procesos de IA
  • Proceso [AI], los campos requeridos en los parámetros de entrada no se verifican
  • [AI] Cuando el proceso habilita el arrendamiento múltiple, la llamada de la interfaz indica que el proceso no existe.
  • [AI] La interfaz del proceso de llamada se ha cambiado para que no requiera inicio de sesión.
  • Actualice JVxetable a la nueva versión 4.13.31
  • Actualice jsqlparser a 4.9
  • Se agregaron anotaciones de permisos para funciones relacionadas con aplicaciones de IA.
