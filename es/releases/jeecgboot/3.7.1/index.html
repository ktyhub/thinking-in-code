#JecgBoot v3.7.1

Versión actual: v3.7.1 | 2024-09-12

Registro de actualización

Aspectos destacados de esta versión: el generador de código está muy optimizado para admitir la generación de subpaquetes con múltiples directorios y más detalles, la última versión del informe de bloques de construcción admite la función de informes, el panel se actualiza a una nueva versión, la configuración de la puerta de enlace de microservicio se simplifica, se actualizan varios componentes subyacentes, optimización de funciones en línea, etc. [Con SQL actualizado] (https://github.com/jeecgboot/JeecgBoot/blob/master/jeecg-boot/jeecg-module-system/jeecg-system-start/src/main/resources/flyway/sql/mysql/V3.7.1__all_upgrade.sql)

Nuevas funciones

  • Se actualizó el informe del bloque de construcción a la última versión, con la función de diseño y llenado de formularios.
  • Actualice el panel de control del bloque de construcción a la última versión
  • Actualice nacos a 2.3.2, que admite la base de datos nacional Dameng de forma predeterminada.
  • Actualice xxl-job a la versión 2.4.1 para evitar CVE-2024-24113
  • Actualice autopoi a la última versión 1.4.11
  • Se agregó inicio de docker con un solo clic para front-end y back-end único y de microservicio
  • Configuración simplificada de la puerta de enlace de microservicio, admite replicación, eliminación lógica y papelera de reciclaje.
  • Optimización de los detalles de la interfaz de funciones del sistema.
  • La modificación de los permisos del usuario actualmente conectado tendrá efecto directamente sin cerrar sesión y volver a iniciarla.
  • Actualizar datos provinciales y municipales.
  • La interfaz de inicio de sesión de la sucursal sas se adapta al inicio de sesión de la sucursal principal del front-end original y acorta la longitud del token
  • Cambiar el permiso de administración de la lista blanca para solicitar el método de anotación
  • websocket siempre se rompe, cambia la forma de escribir
  • Optimizar la función de desensibilización de datos.

Optimización del generador de código

  • La generación de código admite directorios multinivel de subpaquetes
  • La generación de código admite la generación de instrucciones de permisos de front-end v-auth
  • La generación de código admite el nuevo control del diccionario JPopupDict
  • El control de rango de condiciones de consulta generado por el código ha sido reemplazado con hermosos efectos: rango de fechas, rango de números, rango de cantidades, etc.
  • Los componentes de usuario y departamento se configuran de acuerdo con el campo de almacenamiento en línea y el campo de visualización al generar el código.
  • El formulario nativo no pasó la verificación y no pasó a los campos que no pasaron la verificación.
  • El formulario no nativo no pasó la verificación y no pasó a los campos que no pasaron la verificación.
  • La página de detalles activó una solución de verificación.
  • Las columnas de operación de subtabla de estilo ERP no son flotantes
  • Cuando el tipo de control de página es un cuadro desplegable, el código vue de front-end generado tiene comas adicionales.
  • El código genera condiciones de consulta para campos de tipo int, que no se representan en cuadros de entrada numérica.
  • Ya sea ERP nativo o no nativo, cuando no se selecciona la tabla principal, la subtabla se exporta directamente y se exportan todos los datos.
  • El ERP uno a muchos también se puede cambiar para seleccionar una fila haciendo clic en ella
  • Un par de embellecimiento estilo Tab
  • Soporte de valor predeterminado de nuevo control de generación de código para año, mes, semana y trimestre
  • No se genera el diccionario emergente de subtablas de uno a muchos

  • Configuración de permisos de datos en línea, reparación de errores de expresión de variables del sistema
  • La exportación de imágenes en línea cambió a exportación de texto y las imágenes ya no se exportarán.
