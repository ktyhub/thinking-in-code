#iotdb v1.3.2

Funciones y mejoras

  • Módulo de Almacenamiento: Mejora del rendimiento en la interfaz insertRecords para escritura
  • Módulo de consulta: se agregó una nueva declaración de explicación y análisis (monitoreo del tiempo dedicado a cada etapa de una única ejecución de SQL)
  • Módulo de consulta: se agregó un nuevo marco UDAF (función agregada definida por el usuario)
  • Módulo de consulta: se agregaron nuevas funciones MaxBy/MinBy, que admiten la recuperación de valores máximos/mínimos junto con las marcas de tiempo correspondientes.
  • Módulo de Consultas: Mejora del rendimiento en consultas de filtrado de valores
  • Sincronización de datos: la coincidencia de rutas admite el patrón de ruta
  • Sincronización de datos: admite la sincronización de metadatos (incluidas series de tiempo y atributos relacionados, permisos, etc.)
  • Procesamiento de flujo: se agregó la declaración Alter Pipe, que admite actualizaciones en caliente de complementos para tareas de Pipe
  • Módulo del sistema: las estadísticas de recuento de puntos de datos del sistema ahora incluyen estadísticas para los datos importados al cargar TsFile
  • Scripts y herramientas: se agregó una nueva herramienta de copia de seguridad de actualización local (copia de seguridad de los datos originales a través de enlaces físicos)
  • Scripts y herramientas: se agregaron nuevos scripts de exportación/importación de datos, que admiten la exportación de datos en formatos CSV, TsFile o declaraciones SQL.
  • Scripts y herramientas: el entorno Windows ahora permite distinguir ConfigNode, DataNode y Cli por el nombre de la ventana. ...

Errores

  • Optimice el mensaje de error cuando se produce una excepción NullPointerException (NPE) debido a un tiempo de espera al eliminar una base de datos.
  • Agregar registros para notifyLeaderReady, notifyLeaderChanged y el trabajador de procedimientos.
  • Agregar manejo de compatibilidad para datos erróneos existentes durante la fusión de archivos.
  • Solucionar el problema de interbloqueo causado por el vaciado de archivos vacíos durante la consulta.
  • Solucionar el problema por el cual Ratis deja de responder durante las operaciones de lectura, escritura y eliminación.
  • Corrige el error concurrente en las operaciones de carga y fusión.
  • Se solucionó el problema por el cual la relación de compresión del sistema se registra como un número negativo en el archivo para ciertos escenarios.
  • Se solucionó el problema de ConcurrentModificationException durante la estimación de memoria para tareas de combinación.
  • Solucionar posibles bloqueos que pueden ocurrir al escribir, crear y eliminar bases de datos automáticamente al mismo tiempo. ...
