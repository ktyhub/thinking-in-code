diseño de hormiga 6.5.3

  • Entrada
    • 🐞 Se corrigió Input.OTP usando type="text" cuando mask es una cadena y al mismo tiempo se conservan los valores explícitos de type. #58835 @QDyanbing
    • 🐞 Se corrigió que Input.OTP mostrara el valor original cuando mask es true. #58805 @cyphercodes
    • 💄 Arreglar el cambio de tamaño de Input.TextArea que maneja la representación como un punto en dispositivos táctiles. #58812 @pupuking723
  • Tipografía
    • ⚡️ Mejorar el rendimiento de la información sobre herramientas de elipsis de tipografía en listas grandes. #58806 @lkxdsb
    • 🐞 Corrija el tamaño de fuente del área de texto editable de tipografía que no coincide con el contenido editado. #58551 @gaurav0107
  • 🐞 Se corrigió DatePicker.RangePicker que presentaba valores parciales no confirmados en desenfoque al usar showTime y allowEmpty. #58803 @zombieJ
  • 🐞 Reparar Form.Item useStatus que devuelve errores obsoletos y advertencias cuando el estado de validación permanece sin cambios. #58815 @afc163
  • 🐞 Se corrigió el control deslizante que activaba las devoluciones de llamada onFocus y onBlur varias veces. #58711 @QDyanbing
  • 🐞 Se corrigió que los indicadores independientes de Spin estuvieran mal colocados cuando estaban anidados en otro Spin. #58801 @QDyanbing
  • 🐞 Arreglar las selecciones desplegables de filtros controlados por tabla que no se actualizan mientras están abiertas. #58816 @afc163
  • 🐞 Corregir cargar enlaces de descarga predeterminados que permiten que las pestañas recién abiertas accedan a la página de apertura. #58817 @afc163
  • 💄 Corrige estilos base de iconos incompletos cuando las capas theme.zeroRuntime o CSS están habilitadas. #58763 @QDyanbing
  • 💄 Reparar íconos de sufijo seleccionados y contenido seleccionado que se superponen al ícono transparente con colores de tema personalizados. #58581 @QDyanbing
  • 💄 Arreglar los iconos <svg> de terceros de las pestañas que no se alinean verticalmente con las etiquetas. #58847 @mohamedkhaled4053
  • Entrada
  • 🐞 Solucione el problema por el cual Input.OTP todavía usa type="text" cuando usa la cadena mask y conserva la configuración explícita de type. #58835 @QDyanbing
  • 🐞 Se solucionó el problema por el cual el valor original aún se muestra cuando mask de Input.OTP es true. #58805 @cyphercodes
  • 💄 Solucione el problema por el cual los controladores de cambio de tamaño de Input.TextArea aparecen como pequeños puntos en los dispositivos táctiles. #58812 @pupuking723
  • Tipografía
  • ⚡️ Rendimiento de renderizado optimizado de tipografía omitió sugerencias en listas grandes. #58806 @lkxdsb
    • 🐞 Se solucionó el problema por el cual el tamaño de fuente del cuadro de texto editable Tipografía no coincide con el contenido editado. #58551 @gaurav0107
  • 🐞 Se solucionó el problema por el cual DatePicker.RangePicker enviaba valores parciales no confirmados cuando se usaba showTime y allowEmpty fuera de foco. #58803 @zombieJ
  • 🐞 Se solucionó el problema por el cual Form.Item useStatus devolvía un error antiguo y contenido de advertencia cuando el estado de verificación no había cambiado. #58815 @afc163
  • 🐞 Se solucionó el problema por el cual las devoluciones de llamada onFocus y onBlur de Slider se activaban repetidamente. #58711 @QDyanbing
  • 🐞 Se solucionó el problema del posicionamiento incorrecto de los indicadores de carga independientes de giro cuando se usaban anidados. #58801 @QDyanbing
  • 🐞 Se solucionó el problema por el cual los elementos seleccionados no se actualizaban sincrónicamente cuando el panel de filtrado controlado por tabla permanecía abierto. #58816 @afc163
  • 🐞 Se solucionó el problema por el cual se podía acceder a la página de origen cuando la nueva página abierta mediante Subir se descargaba de forma predeterminada. #58817 @afc163
  • 💄 Se solucionó el problema del estilo básico del ícono incompleto cuando theme.zeroRuntime o la capa CSS están habilitados. #58763 @QDyanbing
  • 💄 Se solucionó el problema por el cual el ícono de sufijo o el contenido seleccionado se superponía con el ícono de borrar debajo de Seleccionar color de tema personalizado. #58581 @QDyanbing
  • 💄 Se solucionó el problema de que el ícono <svg> de terceros en las pestañas no está alineado verticalmente con el texto de la etiqueta. #58847 @mohamedkhaled4053
