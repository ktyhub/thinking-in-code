guayaba v33.4.8

Guava 33.4.8 soluciona un problema que presentamos al comenzar a migrar guava-android de Unsafe en 33.4.7.

Incluso si no está actualizando desde Guava 33.4.0 o una versión anterior, lea los release note para Guava 33.4.1. Esos release note contienen información sobre los efectos de Guava 33.4.5 y superiores en el sistema de módulos.

</dependency>

Changelog

  • util.concurrent: Se eliminó nuestro código VarHandle de guava-android. Si bien el código nunca se usó en tiempo de ejecución en Android, estaba causando [problemas con el complemento Gradle de Android] (https://github.com/google/guava/issues/7769) con un minSdkVersion por debajo de 26. Para continuar evitando sun.misc.Unsafe bajo JVM, guava-android ahora siempre usará AtomicReferenceFieldUpdater cuando se ejecute allí. (75da92419a)
