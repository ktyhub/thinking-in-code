Paquete de nuevas funciones

  • Un nuevo modelo de reconocimiento chino para escenarios de documentos, que aborda algunos caracteres chinos raros, admite un recuento de caracteres superior a 15 000. El uso de CLI es el siguiente:
paddleocr --image_dir xxx.png --lang ch_doc

De manera similar, en el Python API, solo necesita cambiar el parámetro lang a ch_doc.
