PaddleOCR v2.7.1

Nuevos proyectos

  • Agregar modelo de reconocimiento Parseq. (#10836)
  • Agregar función de reconocimiento de texto para devolver coordenadas de un solo carácter. (#10515)

Nuevas características

  • Agregue la opción de guardar archivo para guardar los resultados de salida de OCR. (#10628)
  • Agregar más opciones de preprocesamiento de datos a ppocr.py.(#10217)
  • Una sola imagen dañada no afecta la inferencia del conjunto de datos. (#10216) *Compatible con la versión fitz. (#10181)
  • Compatible con la actualización Pillow10.0. (#10405)
  • Agregar archivo de diccionario finlandés. (#10850)
  • Onnxruntime admite GPU. (#10668)
  • TIPC admite XPU y NPU. (#10658, #10460)
  • Agregar inferencia en dispositivos mlu. (#10249)

Corrección de errores

  • Se corrigió el error de no encontrar la biblioteca cuando se empaqueta en exe en Windows. (#10502)
  • Se corrigió el error de reconocer la página que se ve afectado por la cantidad máxima de archivos PDF cuando se reconocen varios archivos PDF. (#10290)
  • Se solucionó el problema de falla de inicio de PPOCRLabel causado por una falta de coincidencia en el número de canal. (#10847)
  • Solucionar el problema de pérdida de memoria de la inferencia de cpp. (#10441)
  • Modificar el error de DSR causado por la mejora de datos. (#10662)
  • Solucionar el problema de las semillas de entrenamiento. (#10614)
  • Soluciona el error tipc de table_master. (#10514)
  • Se solucionó el problema del informe de errores cuando ppocr.py usa wandb. (#10251)
  • Reparar pérdida de memoria en predict_rec.py. (#10688)
  • Se solucionó el problema por el cual dis e iou no se podían calcular correctamente debido al error de índice de Structure_boxes en la función PaddleStructure::rebuild_table. (#10810)
  • Compatible con paleta de salida de fluido 2.5. (#10391)
  • Solucionar el problema de rendimiento de Tensor.numpy con calma. (#10773)
  • Adapte el tamaño de ABINet durante la exportación al tamaño de ABINetRecResizeImg. (#10892)
  • Error de entrenamiento de ABINet. (#10744)
  • Corrige KeyError en ch_PP-OCRv4_rec_distill.yml. (#10761)

Corrección de documentación

  • Solucionar problemas de documentos de algoritmo_kie_vi_layoutxlm_en.md, kie_datasets_en.md, README.md, algoritmo_overview.md, how_to_do_kie_en.md. (#10717)
  • Actualizar problemas de documentación con setup.py. (#10749)
  • Agregue la biblioteca pyyaml ​​en requisitos.txt. (#10653)
