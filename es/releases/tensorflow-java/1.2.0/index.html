tensorflow-java v1.2.0

Cambios

Esta versión actualiza el componente nativo a TensorFlow 2.21, fusiona tensorflow-ndarray nuevamente en este proyecto y agrega pequeñas correcciones al sistema de gradiente. Debido a la falta de compilaciones disponibles de TensorFlow, deja de ser compatible con Windows x86.

La documentación actualizada de TensorFlow-Java ya está disponible en tensorflow.github.io/java y se mantendrá con este proyecto. Las páginas de documentación antiguas en tensorflow.org/jvm y tensorflow.org/api_docs/java/org/tensorflow/package-summary ya no se mantienen, pero no podemos eliminarlas en este momento.
