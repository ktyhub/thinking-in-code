🧬 Autoevolución

CowAgent presenta Self-Evolution, lo que permite al agente ir más allá de completar una sola tarea y seguir mejorando a través de la colaboración diaria con usted:

  • Revisión automática después de inactiva: una vez que una conversación queda inactiva, el agente la revisa en segundo plano para solucionar los problemas expuestos por una habilidad en uso, crear nuevas habilidades reutilizables, realizar un seguimiento de las tareas no terminadas y registrar información importante en la memoria y en la base de conocimientos.
  • Silencioso de forma predeterminada, notificación a pedido: informa lo que cambió solo cuando realmente realizó un cambio y, de lo contrario, permanece en silencio.
  • Seguro y reversible: cada revisión tiene una copia de seguridad de antemano y se puede deshacer en cualquier momento. Las habilidades integradas están protegidas y todas las lecturas y escrituras permanecen dentro del espacio de trabajo.

Habilitado de forma predeterminada para nuevas instalaciones. Los usuarios existentes pueden activarlo con un solo click en la consola web en Configuración → Configuración del agente.

💬 Actualizaciones de la consola web

La experiencia de chat de Web Console recibe varias mejoras:

  • Gestión de mensajes: edite, elimine y regenere mensajes de usuario y de bot; Los bloques de código ahora incluyen etiquetas de idioma y un botón de copia de un solo click.
  • Sesiones paralelas: ejecuta varias sesiones al mismo tiempo sin interferencias, y la transmisión en vivo se reanuda automáticamente cuando vuelves a una sesión.
  • Refinamientos: arrastre y suelte archivos en cualquier lugar de la vista de chat; cambiar automáticamente a una sesión entre hermanos después de eliminar la activa

Gracias @core-power (#2865)

🧩 Mejoras de MCP multiplataforma

  • Solución de compatibilidad con Windows: Se corrigió el error de comunicación de stdio en Windows y se hizo que el tiempo de espera del servidor fuera configurable a través de mcp.json.
  • Llamadas simultáneas: los transportes sse y streamable-http ahora admiten llamadas simultáneas entre sesiones para respuestas multiherramienta más rápidas.

Gracias @xliu123321 (#2859)

Documentación: Herramientas MCP

🤖 Nuevos modelos y mejoras

  • MiniMax-M3: agregado y configurado como modelo predeterminado, con la serie M2.7 mantenida como opción. Gracias @octo-patch (#2855)
  • Qwen3.7-plus: soporte agregado para conversaciones multimodales
  • Modelo ASR seleccionable: la consola web ahora puede seleccionar y conservar el modelo ASR (reconocimiento de voz). Gracias @nightwhite (#2857)
  • Menú de instalación simplificado: el script de instalación de una línea simplifica el menú del modelo y agrega la opción Xiaomi MiMo

Documentación: Descripción general de modelos

🛠 Mejoras y correcciones

  • Soporte Python 3.13: Instalación fija y compatibilidad de dependencias en Python 3.13
  • Internacionalización: la lista de canales ahora está ordenada por idioma de la interfaz; refinó el retroceso automático del idioma en el modo auto
  • Cancelación más confiable: Se corrigieron casos en los que no se podía interrumpir una respuesta de transmisión
  • CLI: cow status ahora muestra la ruta del proyecto actual
  • Seguridad de implementación reforzada: el bloque de archivos de credenciales se reduce a ~/.cow/.env para que otros directorios ya no se vean afectados (Gracias @orbisai0security #2863); la cuenta oficial de WeChat ahora rechaza solicitudes de webhook cuando wechatmp_token está vacío
  • Complemento del tablero de tareas grupales: se agregó la fuente del complemento del tablero de tareas grupales. Gracias @Wyh-max-star (#2853)

📦 Actualizar

Las implementaciones de código fuente pueden ejecutar cow update para una actualización de un click, o extraer el código más reciente y reiniciar manualmente. Consulte la Guía de actualización para obtener más detalles.
