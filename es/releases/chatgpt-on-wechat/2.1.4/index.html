🖥 Escritorio Client

Después del escritorio client lanzado en la versión anterior, esta versión mejora aún más las capacidades del navegador, la compatibilidad del sistema y la experiencia general:

  • Compatibilidad con herramientas de navegador: el client agrupa las capacidades del navegador y prefiere reutilizar el Chrome/Edge instalado en el sistema, con un inicio del navegador y un rendimiento de acceso optimizados.
  • Pulido de la interfaz de usuario: imágenes e interacciones refinadas para la vista de chat, burbujas de mensajes, pasos de llamada de herramientas y páginas de canales.
  • Firma de código de Windows: los instaladores de Windows ahora están firmados con código, lo que reduce las advertencias de seguridad durante la instalación.
  • Soporte de Windows 7/8: se agregó soporte client para sistemas heredados como Windows 7/8, cubriendo más entornos.
  • Corrección del enlace de la base de conocimientos: se corrigieron los enlaces en el documento en la base de conocimientos del escritorio que no podían navegar.
  • Inicio de sesión con contraseña: el client de escritorio admite la configuración de una contraseña de inicio de sesión y soluciona un problema por el cual la ventana no se cargaba después de establecer una contraseña.

🔌 Autorización MCP OAuth

Los servidores MCP remotos ahora admiten autorización OAuth. Al conectarse a servidores MCP de terceros que requieren inicio de sesión, la autenticación se puede completar a través del flujo estándar de OAuth, sin necesidad de configurar ni mantener tokens manualmente.

Documentos: Herramientas MCP

⏰ Tareas programadas

  • Modo silencioso: cree tareas programadas que se ejecuten de forma silenciosa y que se ejecuten en segundo plano sin enviar mensajes, ideal para escenarios sin interrupciones, como la organización de datos o el archivado periódico. (#2954)
  • Ejecución manual: activa manualmente una tarea existente para que se ejecute inmediatamente desde la consola, sin esperar la siguiente programación. (#2958)
  • Preservar configuración al editar: se solucionó un problema por el cual al editar una tarea en la consola web se podían eliminar campos ocultos, como el tipo de modo. (#2959)
  • Comando de tarea entre canales: se agregó el comando de administración /tasks, compatible entre canales. (#2965)

Gracias @AaronZ345

Documentos: Tareas programadas

💬 Mejoras en el canal Feishu

El canal Feishu obtiene una serie de mejoras de interacción y visualización de mensajes para una mejor experiencia.

  • Pulido de tarjetas de transmisión: las tarjetas de transmisión agregan paneles plegables que muestran el proceso de pensamiento, las llamadas a herramientas y el tiempo de ejecución. (#2963)
  • Formato Markdown: para respuestas que no son de transmisión y envíos programados, los mensajes que contienen Markdown se representan como tarjetas para una visualización más clara. (#2962)
  • Tarjetas de programación: el comando /tasks se presenta como tarjetas, con la capacidad de habilitar o deshabilitar tareas directamente desde la tarjeta. (#2961)
  • Contexto del mensaje citado: cuando un usuario cita un mensaje, el contenido citado se agrega automáticamente al contexto enviado al Agente. (#2966)
  • Representación remota de imágenes: los enlaces de imágenes remotas ahora se pueden representar dentro de las tarjetas Feishu. (#2967)
  • Cancelar al recuperar el mensaje: al recuperar un mensaje Feishu se cancela automáticamente su correspondiente tarea en ejecución o en cola. (#2978)

Gracias @AaronZ345

Documentos: Feishu

💾 Copia de seguridad y restauración de datos

Se agregaron los comandos cow backup y cow restore para exportar y restaurar datos locales (configuración, base de conocimientos, memoria y más) con un solo comando, lo que facilita la migración y la copia de seguridad. Gracias @AaronZ345 (#2957)

Documentos: Copia de seguridad de datos

🤖 Nuevos Modelos

  • Se agregó soporte para kimi-k3
  • Se agregó soporte para gpt-5.6-luna, gpt-5.6-terra y gpt-5.6-sol.

Documentos: Modelos

🛠 Mejoras y correcciones

  • Dirección de tareas activas: se agregó el comando /steer para inyectar nuevas instrucciones durante la ejecución de la tarea, guiando o redirigiendo la tarea en ejecución sobre la marcha. Gracias @AaronZ345 (#2977)
  • Edición de archivos: se solucionó un problema por el cual las coincidencias aproximadas podían ubicar la posición incorrecta al editar archivos. Gracias @weijun-xia (#2945)

📦 Cómo actualizar

  • Implementación de origen: ejecute cow update para una actualización de un click, o extraiga el código más reciente y reinicie. Consulte la guía de actualización.
  • Escritorio client: busque actualizaciones y actualice con un click dentro del client, ​​u obtenga la última versión desde la página de descarga.
