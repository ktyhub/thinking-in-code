chatgpt-en-wechat 2.1.3

🌐 Inglés | 中文

🖥 Escritorio Client

Presentamos CowAgent Desktop client para macOS y Windows: su súper asistente de IA local, realmente listo para usar desde el primer momento.

Descargar: Escritorio CowAgent

<img width="750" src="https://cdn.jsdelivr.net/gh/zhayujie/cowagent-assets@main/screenshots/en/desktop-chat-demo-en.png" alt="CowAgent Desktop client" />

Aspectos destacados:

  • Listo para usar: se incluye el tiempo de ejecución completo del Agente: se inicia inmediatamente después de la instalación, no es necesario configurar Python u otras dependencias.
  • Experiencia de chat completa: transmisión de respuestas, gestión de sesiones, visualización de pasos de llamada de herramientas, renderizado Markdown, además de envío y vista previa de imágenes/vídeos/archivos.
  • Gestión visual: la configuración, los modelos, la base de conocimientos, las tareas programadas, las habilidades y las páginas de memoria reflejan la consola web, todo gestionable en la interfaz de usuario nativa.
  • Incorporación de canales: conecta canales de mensajería escaneando un código QR directamente dentro de la aplicación
  • Actualización automática: comprobaciones automáticas de versiones y actualizaciones one-click, con velocidad de descarga optimizada en todas las regiones
  • Experiencia nativa: incorporación de primera ejecución, seguimiento del idioma del sistema e interacciones de ventana adaptables a la plataforma

📚 Base de conocimientos

  • Crear e importar documentos: cree nuevos documentos o importe documentos externos directamente desde la interfaz de usuario
  • Mantenimiento automático del índice: el índice de la base de conocimientos se reconstruye automáticamente a partir del árbol de directorios real, lo que evita la deriva del índice o la pérdida de documentos.
  • Solución de vectorización: el índice ahora reutiliza el proveedor de incrustación unificado, lo que garantiza vectores semánticos reales en lugar de recurrir a la búsqueda de palabras clave.

Gracias @yangziyu-hhh

Documentos: Base de conocimientos

🔌 Recuperación de herramientas MCP bajo demanda

Para abordar la sobrecarga de contexto cuando hay muchas herramientas MCP conectadas, agregamos recuperación de herramientas bajo demanda: las herramientas MCP relevantes se cargan bajo demanda a través de la búsqueda de vectores RAG según la tarea actual, lo que reduce el contexto ocupado por herramientas irrelevantes.

Gracias @fengyl07

Documentos: Herramientas MCP

🌏 Soporte chino tradicional

La consola web, los registros y la documentación ahora admiten chino tradicional (zh-Hant); El idioma de la interfaz puede seguir el sistema o cambiarse manualmente.

Gracias @anomixer (#2935)

🤖 Nuevos Modelos

  • Se agregó soporte para claude-sonnet-5 y claude-fable-5
  • Se agregó soporte para doubao-seed-2-1-pro y doubao-seed-2-1-turbo

Documentos: Modelos

🔒 Refuerzo de la seguridad

  • Protección de lectura de archivos confidenciales: acceso reforzado a credenciales y otros archivos confidenciales para evitar lecturas omitidas. Gracias @fengyl07 (#2936)
  • Protección de acceso al navegador: bloquea las solicitudes del navegador dirigidas a la red interna y a los puntos finales internos del servidor en la nube, lo que reduce el riesgo de ser engañado para llegar a los servicios internos. Gracias @Jiangrong-W
  • Análisis de configuración más seguro: el contenido de la configuración se analiza de una manera más segura para evitar posibles riesgos de ejecución de código. Gracias @shunfeng8421

🛠 Mejoras y correcciones

  • Soporte de proveedor personalizado: los modelos de visión e incrustación ahora pueden utilizar proveedores personalizados; También solucionó un problema de consulta de memoria en Windows. Gracias @HnBigVolibear
  • Edición de archivos más confiable: conserva mejor la sangría original y la coincidencia aproximada ya no toca contenido no relacionado. Gracias @weijun-xia (#2942)
  • Corrección de codificación de salida de comando: se corrigieron caracteres chinos confusos cuando un comando produce una salida grande. Gracias @weijun-xia (#2941)
  • Correcciones de Azure OpenAI: salida de transmisión fija y problemas de configuración relacionados para Azure OpenAI. Gracias @Tunello
  • WeCom Smart Bot: se agregaron documentos de canal para el modo webhook (devolución de llamada). Gracias @6vision
  • Alternar Deep Dream: se agregó un interruptor deep_dream_enabled dedicado para habilitar o deshabilitar la destilación de Deep Dream de forma independiente.
  • Estabilidad: conexión mejorada recycling en el servicio web y se solucionaron varios problemas de autoevolución (#2924 Gracias @santipongth, #2904 Gracias @YLChen-007)

📦 Cómo actualizar

  • Escritorio client: obtenga la última versión desde la página de descargas.
  • Implementación de origen: ejecute cow update para una actualización de un click, o extraiga el código más reciente y reinicie. Consulte la guía de actualización.
