🤝 Equipos multiagente

CowAgent es ahora un marco multiagente. Puede crear varios Agentes, cada uno con su propia función, para formar un equipo y colaborar en tareas complejas dentro de una sola sesión. Compatible con la consola web, el escritorio client y las integraciones de canales:

  • Gestión de equipos: cree y mantenga Agentes, configure el nombre, las responsabilidades, el modelo predeterminado, las habilidades y los conocimientos, y copie la configuración de un Agente existente.
  • Aislamiento de recursos: cada Agente tiene su propio espacio de trabajo, memoria y sesiones; la base de conocimientos y las habilidades se pueden compartir o mantener de forma independiente.
<Marco> <img src="https://cdn.jsdelivr.net/gh/zhayujie/cowagent-assets@main/screenshots/en/team-overview.png" alt="Equipo de agentes" width="800" /> </Marco>
  • Colaboración grupal: agregue varios Agentes a una sesión y use @ para dirigir un mensaje a un miembro específico, con cada Agente usando su propio modelo configurado.
  • Delegación de tareas: un chat grupal tiene un Agente principal que puede asignar una tarea al miembro más adecuado según sus responsabilidades, con soporte para delegación multinivel y alcance, profundidad y tiempo de espera configurables.
<Marco> <img src="https://cdn.jsdelivr.net/gh/zhayujie/cowagent-assets@main/screenshots/en/agent-group-chat-demo.png" alt="Grupo-equipo-agente" width="800"/> </Marco>
  • Instancias de múltiples canales: un canal de mensajería instantánea del mismo tipo ahora puede ejecutar múltiples instancias, cada una vinculada a un único Agente o a un equipo de Agentes. Compatible con WeChat, robots inteligentes de WeCom, Feishu, DingTalk, QQ, Telegram, Slack, Discord y más.

⏰ Actualizaciones de tareas programadas

Las tareas programadas ahora se pueden crear y administrar desde la consola, con destinatarios de canal y registros de ejecución agregados:

  • Creación manual de tareas: cree, edite y ejecute tareas directamente en la página de tareas y seleccione la instancia del canal y el destinatario.
  • Gestión de destinatarios de canal: mantenga destinatarios trusted por instancia de canal, de modo que una tarea pueda entregarse a un destinatario designado en lugar de solo al canal donde se creó. Gracias @dajiaohuang (#3043)
  • Registros de ejecución: una nueva página de registros de ejecución le permite revisar la lista del historial y los detalles de cada ejecución. Gracias @mengluo04 (#3107)
  • Solución de actualización simultánea: se corrigieron las tareas que se perdían en las actualizaciones simultáneas (Gracias @Whxuan0701 #3062).

📊 Visualización de uso del contexto

El consumo de contexto ahora es visible y controlable, lo que facilita la gestión del costo de los tokens:

  • Vista de uso del contexto: una vista de anillo reemplaza el botón anterior para borrar el contexto y muestra un desglose completo de lo que constituye el contexto.
  • Acciones de contexto: debajo de la vista del anillo puede activar la compactación inteligente, borrar el contexto o establecer el tamaño máximo del contexto.
  • Cálculo de contexto: el desglose del uso se deriva automáticamente del uso informado del modelo, con agent_max_context_tokens disponible como límite de costo configurable por el usuario.

Gracias @chimyves (#3087), @sufan721 (#3079)

🤖 Capacidades del modelo

  • Nuevos modelos: se agregaron deepseek-flash (DeepSeek V4.1 Flash), gpt-6-astra, claude-fable-5-1, qwen3.8-flash, glm-5.3-flash, gemini-3.8-flash y el modelo de visión deepseek-v4-flash-vision-exp (Gracias @a1094174619 #3094).
  • Reserva del modelo: configure un modelo de reserva en Configuración del modelo > Modelo principal, que se hace cargo automáticamente cuando falla el modelo principal, evitando interrupciones debido a una única interrupción del proveedor. Gracias @alanyz106 (#3099)
  • Seis nuevos proveedores de búsqueda:
    • AnySearch (admite modo anónimo). Gracias @WangPan59 (#3083)
    • Serply (Google/Bing SERP API). Gracias @googio (#3071)
    • Búsqueda paralela. Gracias @georgeatparallel (#3116)
    • Tavily (búsqueda API optimizada para LLM). Gracias @1printf (#3124)
    • SearXNG (motor de búsqueda autohospedado, solo se requiere la URL de la instancia). Gracias @1printf (#3124)
    • Keenable (admite modo anónimo, no se requiere clave API). Gracias @ilya-bogin-keenable (#3122)

📝 Edición de archivos del espacio de trabajo

Los archivos de espacio de trabajo, los documentos de memoria a largo plazo y las definiciones de habilidades ahora se pueden editar y guardar directamente en la consola web y en el escritorio client:

  • Edición in situ: los archivos de texto en el espacio de trabajo, la memoria y los módulos de habilidades (Markdown, código, CSV, HTML, texto sin formato y más) se pueden editar directamente, con atajos de teclado para que Ctrl+S guarde, Esc para salir y Tab para sangrar.
  • Guardado seguro: el guardado comprueba si hay conflictos con la hora de modificación del archivo cuando se abrió; Si el Agente cambió el archivo mientras tanto, se le preguntará primero en lugar de sobrescribirlo. Al cerrar el panel, cambiar de archivo, cambiar de sesión o cambiar de espacio de trabajo, se solicita confirmación sobre los cambios no guardados.

Gracias @zkjqd (#3076)

🛠 Mejoras y correcciones

  • Correcciones de habilidades:
    • extracción de archivos tar reforzados (Gracias @Whxuan0701 #3063)
    • resolver la rama predeterminada de un repositorio en lugar de usar main de forma predeterminada al instalar una habilidad (Gracias @aniruddhaadak80 #3080)
  • Mejoras de MCP:
    • prefijos de nombres de herramientas de soporte (Gracias @georgeatparallel #3116)
    • recuperar sesiones HTTP Streamable caducadas (Gracias @yiheng-kkk ad1f686)
    • reutilice el subproceso y elimine registros de carga duplicados cuando varios agentes compartan el mismo mcp.json
  • Generación de imágenes:
    • Se corrigió el error de ModelScope IMAGE_CREATE debido a una falta de coincidencia de parámetros (Gracias @Anai-Guo #3097)
    • Se corrigieron datos base64 vacíos que se detectaban erróneamente y producían un archivo de imagen vacío (Gracias @c020627 #3133, @justinguo7777 #3131)
  • Corrección del subagente: se corrigió un subagente que borraba la configuración alternativa de la sesión principal (Gracias @alanyz106 #3111).
  • Fragmentación estructurada: la memoria de Markdown y los documentos de conocimiento se fragmentan por estructura de encabezado, con un mensaje para reconstruir cuando la versión fragmentada está desactualizada. Gracias @alanyz106 (#3115)
  • Solución de error de transmisión: se corrigieron siete robots modelo que generaban un NameError en errores de transmisión porque el generador se cerró sobre la variable de excepción ya borrada, enmascarando el error ascendente real (Gracias @Anai-Guo #3128).
  • Corrección del índice de memoria: se corrigieron fragmentos de texto en blanco que causaban errores en las incrustaciones API y fallaba toda la creación del índice de memoria, recurriendo a la búsqueda de palabras clave (Gracias @6vision #3121).
  • Detección de interrupciones: pase stop_reason al bucle del Agente para distinguir un modelo que termina por sí solo de ser cortado por el límite de salida (Gracias @6vision #3074).
  • Detección de archivos adjuntos: haga coincidir las URL de los archivos adjuntos de palabras clave con la ruta resuelta (Gracias @Whxuan0701 #3061).
  • Atribución de puerta de enlace: agregue atribución de fuente a las solicitudes de puerta de enlace de OrcaRouter (Gracias @Marc-oss-hub #3058).
  • Representación de proxy: configure el tipo de contenido en /chat para que la consola se represente correctamente detrás de un proxy inverso con nosniff (Gracias @alanyz106 #3110).
  • Manejo de avatar: se corrigió el error en la carga del avatar debido a la decodificación de texto, ahora lee bytes sin formato (Gracias @mengluo04).
  • Herramienta de evaluación: se agregó un flujo mínimo de evaluación de la trayectoria del Agente. Gracias @yanzhiliaoliao (#3100)
  • Canal DingTalk: desactiva el proxy en las conexiones de streaming y retrocede al volver a conectarte, eliminando errores recurrentes.
  • Windows client: se corrigió una instalación de actualización que rompía el acceso directo.
  • Escritorio client: se corrigió la configuración numérica del agente, como los tokens de contexto máximos, que no se pueden borrar (Gracias @zkjqd #3130).
  • Copia de seguridad y restauración: las copias de seguridad ahora incluyen todos los espacios de trabajo de los Agentes, con correcciones para el archivado anidado, el diseño de restauración y la compatibilidad de versiones en configuraciones de múltiples Agentes.
  • Documentos:
    • Se agregó una entrada en chino tradicional al selector de idioma de documentos japoneses (Gracias @c020627 #3072)
    • Se agregaron enlaces relacionados con Kimi (Gracias @oriengy #2885)

📦 Cómo actualizar

  • Implementación de origen: ejecute cow update para una actualización de un click, o extraiga el código más reciente y reinicie. Consulte la guía de actualización.
  • Escritorio client: busque actualizaciones y actualice con un click dentro del client, ​​u obtenga la última versión desde la página de descarga.
