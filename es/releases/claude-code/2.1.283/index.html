código-claude v2.1.283

¿Qué ha cambiado?

  • Se agregó x-claude-code-prompt-id a los encabezados de sugerencias de la puerta de enlace para que las puertas de enlace LLM puedan agrupar las solicitudes que atienden un mensaje de usuario; registrarse con CLAUDE_CODE_GATEWAY_HINT_HEADERS=1
  • Configuración administrada availableModelsMatch agregada: con "exact", una entrada availableModels permite solo la versión del modelo que nombra, por lo que las nuevas versiones permanecen bloqueadas hasta que se enumeran
  • Se agregó la configuración administrada deniedModels para bloquear modelos específicos, incluso cuando availableModels los permite.
  • Se agregó la herramienta MCP, salidas WebFetch y WebSearch al evento de intervalo tool.output OpenTelemetry cuando OTEL_LOG_TOOL_CONTENT=1
  • Se agregó /doctor prompt-audit (también /checkup prompt-audit) para auditar sus archivos, habilidades, agentes y comandos CLAUDE.md para generar patrones escritos para modelos más antiguos.
  • Se agregó click-to-expand para mensajes truncados de sus otras sesiones en modo de pantalla completa
  • Se agregaron entradas de falla de carga path a --plugin-dir en la secuencia-json system/init plugin_errors, nombrando el directorio que no se cargó.
  • Se agregó un bloque de suscripción load_test_mode a la configuración de la puerta de enlace de aplicaciones de Claude: las solicitudes se crean y firman, pero no se envían en sentido ascendente, y los clients obtienen una respuesta predeterminada, por lo que se puede probar la carga de una implementación.
  • Se agregó un proveedor ascendente mantle a la puerta de enlace de aplicaciones de Claude para el punto final Mantle de Amazon Bedrock.
  • Se corrigió que las sesiones SDK perdieran una llamada de herramienta diferida o el resultado de una herramienta terminada cuando un turno finalizaba antes de tiempo, un mensaje de aprobación retenido después de un reinicio del trabajador y un result.usage de reserva sin transmisión.
  • Se corrigieron las notificaciones de progreso de MCP que se descartaban una vez que una llamada de herramienta de larga duración pasaba a segundo plano; la tarea en segundo plano ahora muestra el último progreso
  • Se corrigió que los servidores stdio MCP se dejaran en ejecución cuando la sesión finalizaba mientras aún estaban iniciando.
  • Se corrigió un breve HTTP 404 de un servidor MCP remoto sin estado (por ejemplo, un proxy en medio de una nueva implementación) que dejaba ese servidor inutilizable por el resto de la sesión mientras aún se mostraba como conectado.
  • Se corrigió el inicio de sesión de MCP para un servidor sin una URL válida que fallaba con un error opaco SDK; /mcp ya no ofrece autenticación para dichos servidores
  • Se corrigió el límite semanal de Fable que no aparecía en /usage y los medidores de uso de VS Code cuando la telemetría estaba desactivada.
  • Se corrigió que /model aceptara Sonnet 4.6 o Sonnet 5 con [1m] cuando la identificación llevaba una fecha o el sufijo -v1:0, en los casos en que se rechazaba la identificación simple.
  • Se corrigió el selector de /model que mostraba una versión y precio de Haiku codificados cuando ANTHROPIC_DEFAULT_HAIKU_MODEL fijaba un modelo diferente.
  • Se corrigieron los flujos de trabajo dinámicos iniciados durante un modelo alternativo ejecutando cada agente en el modelo alternativo en lugar de volver a intentar el modelo configurado.
  • Se corrigió que DISABLE_PROMPT_CACHING_HAIKU no tuviera efecto cuando Haiku es el modelo principal de la sesión.
  • Se corrigió claude plugin validate que decía que Claude Code acepta un complemento o nombre de mercado que no puede instalar; tales nombres en marketplace.json ahora fallan en la validación
  • Se corrigieron los complementos de paso claude plugin validate cuyas rutas outputStyles, themes, monitors o lspServers faltan o apuntan fuera del directorio del complemento.
  • Se corrigió claude plugin details que mostraba 0 servidores MCP para complementos que declaran sus servidores en plugin.json.
  • Se corrigió que claude plugin marketplace remove no dijera qué complementos instalados desinstaló con el mercado; ahora los enumera
  • Se corrigió que claude plugin uninstall eliminara el otro de los dos complementos instalados cuyas identificaciones difieren solo en el caso, con sus opciones y secretos, cuando el mencionado no tenía una entrada enabledPlugins en ese alcance.
  • Se corrigieron los complementos que declaraban que no había ninguna versión restaurada silenciosamente en la confirmación más reciente de su fuente, no en la instalada, cuando faltaban sus archivos en caché.
  • Se corrigieron los complementos y mercados instalados por el usuario que no se cargaban con "cache-miss" después de que se movía el directorio de inicio o de configuración, por ejemplo, en contenedores de desarrollo montados en enlaces.
  • Se corrigió installed_plugins.json que no mostraba complementos cuando tenía un registro con una identificación de complemento no válida; dicho archivo se carga de nuevo
  • Se corrigió que installed_plugins.json se reescribiera y perdiera registros, cuando contiene un registro que esta versión no puede leer; Los comandos claude plugin ahora nombran el registro y dicen cómo recuperarlo.
  • Se corrigieron los cuadros de diálogo de permisos en el modo de lector de pantalla que leen los comandos y rutas entre comillas como si fueran el propio texto del cuadro de diálogo.
  • Se corrigió /context sin contar las instrucciones del servidor MCP: ahora aparecen como su propia fila y cuentan para el total.
  • Se corrigieron los enlaces de rebajas en la representación del terminal Warp como texto sin formato en lugar de hipervínculos clickable
  • Se corrigió que claude mcp add, add-json y remove informaran correctamente cuando el usuario o el archivo de configuración local no se podían escribir, por ejemplo, dentro de un sandbox.
  • Se corrigió que las primeras palabras de una respuesta en una sesión en la nube a veces aparecieran tarde en lugar de transmitirse cuando Claude las escribe.
  • Se corrigió la guía de combinaciones de teclas incorporada de Claude que decía que los acordes se agotan después de 1 segundo en lugar de 3, y llama a cmd un alias de meta, lo que podría producir atajos de cmd+ que la mayoría de los terminales nunca envían.
  • Se corrigió que keybindings.json aceptara silenciosamente un modificador mal escrito como ctl+k; ahora advierte en el registro de depuración y sugiere la solución
  • Se corrigieron las sugerencias en el pie de página que aún decían "Entrar para ver" después de que footer:openSelected fuera rebotado o desatado en keybindings.json.
  • Se corrigió que las claves escritas rápidamente juntas (escritura anticipada, repetición de clave, ráfagas a través de ssh o tmux) a veces se manejaran en estado obsoleto.
  • Se corrigieron las comprobaciones del árbol de trabajo que fallaban en la verificación del certificado (por ejemplo, en descargas de Git LFS) cuando el certificado de CA se pasa a git como pares de entorno GIT_CONFIG_COUNT.
  • Se corrigió el git en el espacio aislado que pedía a los asistentes de credenciales que almacenaran el inicio de sesión del proxy del espacio aislado, que imponía "no se pudo almacenar".
  • Se corrigió que la configuración administrada de sandbox se ignorara por completo cuando un valor anidado no era válido; el valor no válido ahora falla y el resto del bloque aún se aplica
  • Se corrigió que las ediciones de Claude en sus propias notas de memoria automática se bloquearan como escrituras de archivos confidenciales cuando Claude Code se iniciaba en un subdirectorio de un repositorio git.
  • Se corrigió que el control remoto no estuviera disponible en planes pagos cuando la telemetría estaba desactivada con DISABLE_TELEMETRY o DO_NOT_TRACK.
  • Se corrigió el menú /remote-control que cortaba su pista de código QR a mitad de palabra en terminales angostos.
  • Se corrigió que el modo vim . soltara una nueva línea Shift+Enter, dejara el cursor dentro de una letra acentuada y repitiera un cambio anterior después de 3J o el modo visual J en la última línea.
  • Se corrigió la ubicación del cursor en el modo vim: al recuperar un mensaje de más de 10,000 caracteres en el modo normal ya no se deja el cursor más allá del final, y V y luego p ahora aterrizan en el primero que no está en blanco.
  • Se corrigió el modo vim J que unía líneas con espaciado diferente al de Vim (como un espacio antes de ) o después de una pestaña), y 3J o el modo visual J en la última línea sin mover el cursor como lo hace Vim.
  • Windows: Se corrigió la herramienta PowerShell que permitía a cmd /c rd, rmdir, del o erase eliminar las raíces de las unidades, la carpeta de inicio y otras carpetas que Remove-Item rechaza.
  • Se mejoró la lista de herramientas /mcp: muestra más herramientas a la vez, se desplaza con las teclas de página y el mouse y marca las herramientas que su organización bloqueó con un ícono de advertencia.
  • Resultados de la herramienta MCP mejorados: las imágenes devueltas por las herramientas MCP ahora también se guardan en un archivo, para que Bash, Read y otras herramientas puedan abrirlas
  • /tasks mejorado: las filas muestran un ícono de estado, el nombre y los datos completos, el título y las sugerencias clave permanecen en la pantalla con muchas tareas, y la lista gana teclas de paginación, la rueda del mouse y clicks
  • Listas mejoradas en /help, /hooks, /copy, /chrome, /memory, /ide, /release-notes, /rewind, /diff, /remote-env, /plugin y otros selectores con teclas de página, rueda del mouse y clicks.
  • Listas mejoradas al lado de un cuadro de búsqueda, como /skills y /artifacts, para dibujar su puntero atenuado mientras el cuadro de búsqueda tiene las teclas, de modo que solo se resalta un puntero
  • Se mejoró el control giratorio de compactación: su cronómetro ahora comienza cuando comienza la compactación y cuenta los tokens del resumen a medida que se transmiten, reemplazando la barra de porcentaje.
  • Se mejoró la página del navegador que se muestra después de iniciar sesión en un servidor MCP: diseño centrado, modo oscuro y nuevas ilustraciones.
  • Se mejoró la respuesta de la herramienta de habilidades cuando una habilidad pertenece a un complemento que no se pudo cargar, por lo que Claude le dice que el complemento no se pudo cargar en lugar de llamar a la habilidad como desinstalada.
  • prompt-audit mejorado en la configuración de Claude Code: rutas obsoletas, comandos obsoletos y archivos de instrucciones contradictorios ahora encabezan el informe y las palabras clave que se conservan en los documentos de Claude Code
  • Recuperación mejorada de un installed_plugins.json que no se puede leer en absoluto: su contenido se guarda en un archivo al lado antes de que se reconstruya, y claude plugin list nombra ese archivo
  • Lecturas mejoradas de la base de datos de artefactos: una consulta ordenada que devuelve una página completa ahora dice que es una página y cómo leer el resto.
  • Latencia de primera respuesta mejorada: un paso de compilación de patrones que se ejecutaba al final de la primera respuesta de una sesión ahora se ejecuta mientras la respuesta llega
  • Latencia de primera solicitud mejorada al reutilizar la conexión API preconectada
  • Inicio mejorado: claude -p y Claude Code Remote ya no cargan la interfaz de usuario interactiva, y las reglas del clasificador de modo automático y la herramienta Artifact se cargan en el primer uso en lugar de en el inicio.
  • Inicio mejorado para cuentas claude.ai cuyas características de la herramienta Artifact aún no se conocen, como en una primera ejecución: el mensaje ya no espera hasta 1.5 s para verificarlas; el primer mensaje espera si es necesario
  • Se cambiaron las sesiones interactivas en proveedores externos o con la telemetría desactivada para iniciar en modo automático cuando no se configura ningún modo de permiso; permissions.defaultMode todavía lo anula
  • Se modificó el cuadro de diálogo de inicio de /ultrareview para indicar que la revisión de una sucursal local puede cargar cambios no confirmados en los archivos rastreados.
  • Se cambió la fila Opus del selector /model y el nombre del modelo predeterminado para soltar "(contexto 1M)" donde Opus ya tiene una ventana de contexto 1M; la ventana no ha cambiado
  • Se cambiaron las sugerencias de avisos en la terminal para que aparezcan con menos frecuencia después de que 20 seguidos no se utilicen; usar uno los trae de vuelta
  • Se cambiaron --system-prompt y --append-system-prompt para aceptar su texto y formularios -file juntos; el texto del archivo va primero
  • Se cambiaron las reglas de denegación de Skill(anthropic-skills:<name>) para bloquear también esa habilidad cuando Claude Desktop la entrega como un complemento, y Skill(skill:<name>) se niega a coincidir con el alias y el nombre para mostrar de la habilidad.
  • Se cambiaron las listas /rewind y /diff para moverse con las mismas acciones de combinación de teclas que cualquier otra lista (select:*); Las reenlazaduras de messageSelector:*/diff:* siguen funcionando
  • Se cambió la lista de ejecución de /workflows para que tenga el mismo tamaño que otras listas: la mitad del terminal en línea y mantiene su título en la pantalla cuando se muestra el siguiente mensaje.
  • Se modificó claude plugin eval para requerir git 2.31 o posterior cuando se instala git; se rechaza una ejecución en un git anterior con un mensaje que nombra la versión
  • Vigilancia de artefactos modificada: una vigilancia que se armó automáticamente (no una que usted solicitó) ahora finaliza después de las horas 3.5 sin actividad; publicar o ver el artefacto nuevamente lo rearma
  • Ejecutor autohospedado: se modificó el git de los ganchos del ciclo de vida para omitir el gancho Git LFS pre-push de un repositorio, ignorar un sistema de escritura core.hooksPath y no firmar confirmaciones sin --configure-git.
  • Corredor autohospedado: se cambiaron GIT_SSL_CAINFO y GIT_SSL_NO_VERIFY en git administrado por Anthropic: el propio git del corredor siempre verifica la ruta de git de Anthropic, y las líneas de advertencia dicen qué se aplica y dónde
  • Se revirtió la reserva 2.1.282 del nombre claude-ai: habilidades, comandos, flujos de trabajo y habilidades y mensajes de los servidores MCP llamados se cargan nuevamente, y las reglas Skill(claude-ai:*) son reglas de prefijo ordinarias.
  • [VSCode] Se corrigió el indicador de modo de permiso que mostraba Predeterminado mientras la sesión seguía ejecutándose en modo automático o de derivación después de que fallara un cambio automático; el interruptor ahora se vuelve a intentar hasta que aterriza
  • [VSCode] Se corrigió una sesión teletransportada desde la web que dejaba caer los mensajes enviados mientras Claude estaba trabajando.
  • [VSCode] Se corrigió que una sesión web permaneciera oculta de la lista de sesiones y se abriera un chat vacío en su lugar, cuando una versión anterior había guardado una copia local vacía de la misma.
  • [VSCode] Se corrigió una sesión reabierta que dividía un turno en un mensaje que Claude recibió a mitad del turno, como una continuación automática.
  • [VSCode] Se corrigió una sesión recargada que mostraba un giro rebobinado, o solo las filas antes de una compactación.
  • [VSCode] Se corrigió que la píldora de agentes del pie de página dibujara su ícono descentrado, con el punto de estado contra el borde, en paneles estrechos.
  • [VSCode] Se corrigió la entrada del chat que muestra su texto ligeramente debajo del cursor y la selección después de pegar líneas que terminan con un salto de línea en un mensaje largo.
  • [Sesiones en la nube] Se mejoró al agregar un repositorio a una sesión en la nube en ejecución: un repositorio privado que su cuenta GitHub puede leer pero no enviar ahora se adjunta para lectura
  • [Sesiones en la nube] Se corrigieron sesiones en la nube que ocasionalmente rehacían un paso ya finalizado, como publicar un comentario duplicado o un push, después de recuperarse de un reinicio del lado del servidor.
  • [Sesiones en la nube] Se cambiaron los nuevos horarios de rutina para que se establezcan de forma predeterminada unos minutos después de la hora, con una nota de que las rutinas establecidas exactamente a la hora pueden comenzar varios minutos tarde.
  • [Etiqueta de Claude] Se agregó una configuración de administración "Canales que Claude puede buscar" que limita la búsqueda de Claude en Slack a los canales públicos a los que se agregó, configurados por organización, espacio de trabajo o canal.
  • [Etiqueta de Claude] Se agregó un botón Volver a Slack en la página que se muestra después de conectar tu cuenta de Claude, lo que te regresa al hilo desde el que empezaste.
  • [Claude Tag] Se corrigió la página de configuración de un canal que no mostraba conectores ni complementos cuando el canal obtiene su paquete de acceso a través de una regla adjunta; Ahora se muestran los paquetes con reglas adjuntas.
  • [Claude Tag] Se corrigió la búsqueda de repositorios del paquete de acceso que faltaban en las instalaciones de la aplicación GitHub que están limitadas a una lista grande de repositorios seleccionados.
  • [Etiqueta de Claude] Se corrigió que Claude ocasionalmente publicaba la misma respuesta dos veces cuando un nuevo mensaje la interrumpía a mitad de respuesta.
  • [Claude Tag] Se corrigieron las rutinas de canal que dejaban de ejecutarse en canales privados más antiguos cuyo ID de canal de Slack cambió, por ejemplo, después de compartir Slack Connect.
  • [Claude Tag] Se corrigieron las conversaciones en un canal configurado como "Solo canal", todas terminaban cuando un miembro no invitado se unía y Slack tardaba en confirmar su membresía.
  • [Revisión de código] Se corrigió que las solicitudes de "revisión @claude" se silenciaran cuando GitHub no devolvía la solicitud de extracción: la solicitud se reintenta una vez y un comentario explica si aún falla
  • [Revisión de código] Se corrigió la facturación de una revisión que se detuvo en su límite de tiempo sin nada verificado: ahora se muestra como incompleta, no se cobra y se vuelve a intentar una vez.
