código-claude v2.1.329

¿Qué ha cambiado?

  • Se agregó una advertencia de diálogo trust que dice dónde se declaran los ganchos de una carpeta.
  • Se agregó una advertencia en la conversación, en Claude Desktop y otros hosts no interactivos, cuando los enlaces en la configuración administrada no se cargan.
  • Se agregaron las tareas programadas de esta sesión, los despertares de /loop, el objetivo y las bifurcaciones de esta conversación a /tasks; x se detiene después de preguntar
  • Se agregó una fila de "Mensaje del servidor" a la página de un servidor en /mcp que muestra el mensaje de error JSON-RPC de un servidor HTTP MCP remoto que rechaza la conexión.
  • Se agregó una fila de "Actualización automática del mercado" a /status que nombra los mercados administrados que no reciben actualizaciones automáticas y por qué.
  • Se agregó soporte para activar el Modo Código mientras los eventos y métricas OpenTelemetry están habilitados; cada llamada a la herramienta que realiza el código envía sus eventos; el rastreo todavía lo mantiene apagado
  • Se corrigió que ~/.claude.json a veces se restableciera a los valores predeterminados cuando una falla de la red o un bloqueo de archivo lo hacía ilegible y se borraba durante un guardado.
  • Se corrigieron cierres de sesión repetidos en macOS cuando Claude Code podía leer el llavero pero no guardarlo. Esa sesión ahora se detiene cuando expira y dice por qué, y otras sesiones permanecen iniciadas
  • Se corrigió que /terminal-setup corrompiera la configuración de VS Code o los archivos de combinaciones de teclas alrededor de los comentarios de bloque, y reportara éxito mientras se perdía el enlace Shift+Enter donde keybindings.json tiene una cadena abierta
  • Se corrigió que los archivos aceptados a través del IDE diff se guardaran sin su última nueva línea y perdieran su marca de orden de bytes (BOM) cuando se aceptaba una edición al guardar el diff en VS Code.
  • Se corrigió la selección de una sesión en la nube en /teleport que reemplazaba su conversación abierta: la selección ahora inicia una nueva sesión, como lo hace /clear, y /resume recupera la anterior.
  • Se corrigió que /usage-credits pedía a los usuarios Pro y Max que iniciaran sesión nuevamente después de abrir el navegador, y el enlace desaparecía después de 8 segundos si el navegador no se abre y una tarea se detiene para obtener créditos de uso.
  • Se corrigió que /usage dijera que los créditos de uso estaban cancelados cuando se habían agotado o habían alcanzado el límite mensual, y /model no les decía a los usuarios Pro y Max cuando ese límite bloquea un modelo que funciona con créditos de uso.
  • Se corrigió el menú de límite de gasto que muestra su gasto como límite mensual y envuelve sus filas debajo del puntero en ventanas estrechas.
  • Se corrigió un script de línea de estado que se imprime sin parar, congelando el mensaje y usando gigabytes de memoria.
  • Se corrigió una pantalla vacía y congelada después de aprobar la configuración administrada mientras el selector --resume, el cuadro de diálogo trust u otra pantalla de configuración estaban esperando
  • Se corrigió la elección de Predeterminado en /model reemplazando su modelo guardado con el predeterminado de su organización cuando la fila Predeterminada ya mostraba su modelo guardado.
  • Se corrigió que un servidor MCP iniciara sesión nuevamente después de borrar su autenticación mientras se ejecutaba una actualización del token.
  • Se corrigieron las tareas de MCP en segundo plano que se detenían después de una reconexión lenta: Claude Code ahora vuelve a conectar la mayoría de los servidores HTTP MCP por sí solo cuando uno se deja en una versión de protocolo anterior.
  • Se corrigieron los archivos PDF, imágenes y archivos .docx, .xlsx o .pptx que los servidores o sitios web MCP envían como application/octet-stream y se guardan como .bin, lo que impedía que Claude leyera los archivos PDF y las imágenes.
  • Se corrigió que /code-review <pr number> a veces revisara la rama desprotegida en lugar de la solicitud de extracción sin decirlo: ahora lee la solicitud de extracción con gh pr diff, o dice cuando no puede.
  • Se corrigió que /code-review se detuviera ante una solicitud de permiso, en la mayoría de los modelos, para buscar un ~/.claude/CLAUDE.md que no existe.
  • Ejecutor autohospedado: Se corrigió que --push-outcome-on-release a veces eliminara la rama de una sesión en el host git.
  • Se corrigió el modo de código que ocultaba las ediciones terminadas de un script y el comando detenido después de Esc, y los perdía al salir.
  • Se corrigió un bucle fuera de control en el modo Código que llenaba la memoria de la máquina; ahora está detenido en un límite
  • Se corrigió un agente en segundo plano que se ejecutaba cuando se detenía mientras se reanudaba.
  • Se corrigieron los comandos de shell en segundo plano que usaban memoria para la conversación anterior hasta que salían.
  • Se corrigió el control remoto usando memoria para la conversación anterior después de una compactación o /clear en sesiones ejecutadas por Claude Desktop, IDE o SDK.
  • Se corrigió el problema de no finalizar una solicitud en las sesiones de Claude Desktop en Bedrock mientras espera un proceso de credencial_de_AWS colgado o una llamada de inicio de sesión.
  • Se corrigió que Claude a veces no pudiera enviarte un archivo en su primer intento en Opus 4.8 y Opus 5.
  • Se corrigió que a Claude no se le dijera que las herramientas de un servidor MCP conectado no se podían cargar y lo tomara por un servidor sin herramientas, en sesiones con búsqueda de herramientas.
  • Se corrigieron claude mcp login y /mcp que decían que un servicio no acepta inicios de sesión de Claude Code cuando el registro client del servicio se había retirado (HTTP 410 desaparecido).
  • Se corrigió otro caso en el que los enlaces de complementos sincronizados con claude.ai fallaban con "El directorio de complementos no existe" mientras una sesión aún se estaba ejecutando en macOS.
  • Se corrigió el modo automático que solicitaba aprobación manual para rm, un enlace simbólico que apunta fuera del directorio de trabajo o hacia sí mismo.
  • Se corrigió /sandbox en Linux que enumeraba las entradas allowUnixSockets como permitidas: no abren esos sockets allí, y /sandbox ahora lo dice.
  • Se corrigió presionar Esc dos veces para borrar un código mal escrito que finalizaba el inicio de sesión en /install-github-app.
  • Control remoto: Se corrigió que las sesiones regresaran a su primer nivel de esfuerzo después de reiniciar mientras la aplicación aún mostraba el nivel que elegiste (aún no para las sesiones que comienzan en Ultracode)
  • Se corrigió que el servidor MCP de un complemento eliminado permaneciera conectado en sesiones sin cabeza después de reload_plugins o cuando la lista de complementos de la cuenta lo elimina.
  • Se corrigió que las herramientas del conector Claude Docs desaparecieran cuando un complemento o servidor MCP en la misma dirección no se conectaba y el error sugería erróneamente /login.
  • Se corrigió que una nueva carpeta de habilidades, comandos o agentes se perdiera cuando --add-dir nombra el directorio de trabajo o Claude Code comienza en la carpeta de inicio.
  • Las sesiones fijas comenzaron a partir de un proceso precalentado ignorando la configuración autoCompactWindow en el .claude/settings.json del proyecto.
  • Se corrigió que CLAUDE_AUTOCOMPACT_PCT_OVERRIDE permaneciera vigente en una sesión en ejecución después de que se eliminara de la configuración.json
  • Se corrigió que el parámetro effort de la herramienta Agente se ignorara para los compañeros de equipo nombrados en los equipos de agentes.
  • Se corrigió que /auto-mode-setup ignorara las denegaciones recientes del modo automático cuando escanea un proyecto en busca de reglas para sugerir; ahora puede ofrecer reglas de permiso de ellos, y usted revisa cada una antes de guardarla
  • Se corrigió una advertencia falsa "No se pudo guardar este cambio" después de agregar una regla o directorio de permiso en una subcarpeta o árbol de trabajo cuyo propio .claude/settings.local.json es ilegible o está mal formado.
  • Se corrigieron las sesiones en la nube que le indicaban a Claude que ejecutara una verificación de proxy de red después de una solicitud fallida, que luego bloqueaba el modo automático.
  • Se corrigió el rebobinado y la bifurcación sin cabeza mientras un mensaje enviado justo después de un cambio de modelo aún estaba esperando.
  • Se corrigió que a Claude no se le avisara cuando se detenía una tarea en segundo plano mientras se reiniciaba una sesión en la nube.
  • Se corrigió /team-onboarding que informaba que una guía se compartía en los planes Team y Enterprise cuando el servidor rechazaba la carga.
  • Se corrigieron los paneles y las preguntas que se cortaban cuando se les indicaba en pantalla completa, /help, la búsqueda del historial y la lista de tareas en segundo plano perdían filas o títulos en ventanas cortas y tablas que se ajustaban en cuadros de diálogo.
  • Se corrigieron las sesiones reanudadas que mostraban "Rechazado" o "Declined" para ediciones, preguntas y planes que se cortaron cuando finalizó la sesión.
  • Se corrigió /passes que mostraba la cantidad incorrecta de pases después de un error del servidor y ofrecía créditos de uso para compartir cuando no quedaban pases de invitado.
  • Se corrigió que la salida claude --help se interrumpiera cuando se canalizaba a otro programa.
  • Se corrigió que /terminal-setup activara "Usar opción como tecla Meta" en Terminal.app en macOS 27, y sugerencias que sugerían Opción+Entrar en lugar de Mayús+Entrar.
  • Ejecutor autohospedado: se corrigió el error de configuración en los repositorios Git LFS clonados a través de git administrado por Anthropic; Las sesiones ahora comienzan en archivos de puntero y git lfs pull recupera el contenido.
  • Se corrigieron sesiones en entornos autohospedados que no se iniciaban desde un control remoto de git con un alias de host SSH, certificados SSH GitHub o un usuario SSH de GHE.com; El error de un alias no resuelto proporciona dos comandos de git.
  • Se corrigieron servidores MCP remotos en sesiones de ejecución autohospedadas que permanecían sin herramientas o (a través de https) desconectados, después de un tiempo de espera o un error de red.
  • Se corrigió que las sesiones de corredor autohospedadas mostraran que habían dejado de responder mientras Claude Code aún estaba iniciando.
  • Se corrigió el modo de código que mantenía en la memoria cada archivo de texto grande que se leía con el código y la memoria aumentaba cada vez que se activaba un subagente en segundo plano.
  • Modo de código fijo que detenía un script en su límite de diez minutos mientras un formulario MCP, un mensaje de enlace MCP o un mensaje que siempre pregunta estaba esperando una respuesta.
  • Se corrigieron los scripts del modo de código que recibían un mensaje "movido a segundo plano" como datos de la mayoría de las llamadas de MCP durante dos minutos: el script ahora espera hasta diez minutos y luego recibe un error.
  • Modificaciones fijas que enumeran solo algunas herramientas que desactivan silenciosamente el Modo Código; un mod de este tipo ya no lo mantiene apagado, así que use la configuración administrada para eso
  • Se corrigió el modo de código que ignoraba la solicitud de una herramienta MCP para finalizar el turno cuando la herramienta era llamada desde un script que Claude estaba esperando.
  • Se corrigió el let x; de un script en modo de código manteniendo el valor que un script anterior le dio a x.
  • Se corrigió la llamada de un script en modo de código sin ningún argumento que fallaba con un error de parámetro faltante en herramientas que no necesitaban ninguno.
  • Se corrigieron los scripts del modo de código que perdían el acceso a las herramientas a través de tools en sesiones con más de 4,096 herramientas.
  • Se corrigió que la tarjeta de resultados del /code-review a menudo mostrara "alto" para una revisión que se ejecutaba en medio, en la mayoría de los modelos.
  • Se corrigieron sugerencias clave en solicitudes de permiso, preguntas, /model y /rewind ignorando keybindings.json.
  • Se corrigió el desplazamiento automático, la insignia de estado de PR, la advertencia de autocompacto y la etiqueta de ultracódigo que no seguían los interruptores /config que los controlan en una sesión en ejecución.
  • Se corrigió una tecla de cancelación personalizada que no funcionaba en los comentarios de /add-dir, /tui y en el formulario de flujo de trabajo para guardar.
  • Se corrigieron las teclas de flecha en el formulario para guardar el flujo de trabajo, moviendo la selección en la vista del flujo de trabajo detrás de ella.
  • Se corrigió que /config no dijera nada o estuviera "descartado" después de cambiar muchas configuraciones.
  • Se corrigieron las menciones de lectura y @ que mostraban una línea de más para archivos que terminan en una nueva línea.
  • Se corrigió que /status no nombrara el modelo que usan opusplan y haiku en el modo plan.
  • Se corrigió claude doctor que aconsejaba desbloquear un llavero dentro de un entorno limitado de macOS, donde el desbloqueo no podía ayudar.
  • Se corrigió que la píldora "Saltar al final" permaneciera oculta después de copiar texto y desplazarse, la fila debajo se quedaba en blanco cuando cambiaba su etiqueta y las pulsaciones rápidas de Re Pág se desplazaban demasiado en pantalla completa.
  • Se corrigió una actualización de pantalla que a veces se omitía cuando había poca memoria.
  • Se corrigieron bloques de código largos que perdían una línea en blanco y repetían otra en el desplazamiento hacia atrás.
  • Se corrigieron las sugerencias de mensajes que a veces mostraban texto de marcador de posición como _(no suggestion)_.
  • Se corrigió la línea sobre mensajes anteriores en el currículum que culpaban a un archivo dañado cuando el archivo estaba intacto.
  • Se corrigieron los caracteres que desaparecían del mensaje cuando el texto contenía un código de color que establece varios estilos y se resaltaba una palabra clave o comando.
  • Se corrigieron los títulos de gancho /rename y UserPromptSubmit en sesiones claude remote-control que no se mostraban en claude.ai y dispositivos móviles.
  • Se corrigió la diferencia de Control remoto que enumeraba un archivo dos veces cuando la rama le cambiaba el nombre y luego se editaba.
  • Se mejoró la limpieza automática de sesiones antiguas en computadoras con configuración administrada.
  • Se mejoraron /tui y otros reinicios locales para esperar brevemente a que se actualice el inicio de sesión, por lo que es menos probable que cierren sesión.
  • Uso de memoria mejorado en sesiones largas que editan muchos archivos y en sesiones largas de Claude Desktop en macOS y Linux con muchos resultados de herramientas MCP grandes.
  • Windows: inicio mejorado y primera búsqueda en PC donde el programa de búsqueda de Claude Code se inicia lentamente
  • Se mejoró el manejo del modo automático de una respuesta breve como "sí" a la pregunta de Claude cuando la telemetría está desactivada, detrás de una puerta de enlace al Anthropic API o en Microsoft Foundry.
  • Uso de memoria mejorado en sesiones inactivas de Claude Desktop y SDK después de un turno largo y después de --resume o --continue de una sesión que contiene capturas de pantalla o resultados de herramientas grandes.
  • Se mejoró la rapidez con la que una sesión de Claude Desktop Code con el control remoto activado está lista para el siguiente mensaje después de una respuesta.
  • Sesiones en la nube mejoradas para reintentar complementos que no se pudieron descargar al inicio
  • Modo de código mejorado: el terminal se congela durante mucho menos tiempo después de que un script realiza miles de llamadas a herramientas
  • Modo de código mejorado: después de iniciar un subagente, Claude ahora recibe la misma orientación sobre la espera que fuera del modo de código.
  • Se actualizó el uso de la computadora en macOS con reglas de seguridad más nuevas, por lo que algunas acciones se rechazan y algunas aplicaciones tienen menos acceso
  • Se cambiaron las tareas programadas guardadas: en las nuevas sesiones iniciadas, la mayoría guardadas en versiones anteriores necesitan ser programadas nuevamente, aunque el --resume de su propia sesión aún las ejecuta
  • Se modificó /code-review sin objetivo en la mayoría de los modelos para revisar toda la rama con la rama predeterminada, y se arregló que perdiera la diferencia en ramas de múltiples confirmaciones.
  • Se cambió el modo automático para ejecutar git status con menos frecuencia, de modo que la mayoría de las solicitudes esperen menos en repositorios grandes; un comando git que descarta cambios puede bloquearse hasta que se verifique el árbol de trabajo
  • Se cambiaron /code-review <pr number> --fix y /code-review con una URL de solicitud de extracción para que se detengan sin revisar cuando gh pr diff se rechaza o falla.
  • Se cambió 'Salir y detener tareas' para finalizar las tareas programadas de esta sesión para que no se ejecuten nuevamente al reanudar, a menos que salga mientras Claude está respondiendo.
  • Se cambiaron algunos paneles de compañeros de equipo para que comiencen a través de /bin/sh, por lo que es posible que no lean los archivos de inicio del shell.
  • Se modificó el uso de la computadora en macOS para abandonar el inicio de una aplicación que no finaliza después de 30 segundos.
  • Puerta de enlace: se cambió la advertencia de inicio que se muestra mientras access_control.allow_cidrs está vacío a un aviso en cada inicio, encuadrado en registros de texto: nunca exponga la puerta de enlace a la Internet pública
  • Ejecutor autohospedado: se cambió el clon de un segundo nombre de host del mismo propietario/nombre para que vaya a _repos/clones/<host>/ en la carpeta base; sin movimientos clonados
  • Ejecutor autohospedado: se cambiaron los repositorios con caracteres inusuales en su ruta de dirección para clonarlos nuevamente en una nueva carpeta; Las reglas y los volúmenes que nombran el anterior dejan de aplicarse y el clon anterior permanece en su lugar.
  • Ejecutor autohospedado: se modificó --repository-folder para tomar la mayoría de las carpetas en la carpeta base en --capacity 1 (arriba de 1, una allí detiene el inicio); Se rechaza la sesión de otro repositorio que se superpone a una.
  • Se cambió el modo de código para que un gancho PreToolUse que los errores ya no rechace la llamada a la herramienta de un script, como fuera del modo de código; configure "onFailure": "block" en un comando, enlace de herramienta HTTP o MCP que debe rechazar
  • Se modificó el modo de código para rechazar la lectura de un script de un rango de líneas de más de 256 MiB, lo que podría usar gigabytes de memoria, y se corrigió el tiempo de espera de las lecturas de líneas muy largas.
  • Se modificó el modo de código para que también comience cuando la telemetría, el tráfico no esencial o las banderas de funciones estén desactivadas; un administrador puede mantenerlo desactivado en la configuración administrada
  • Se modificó el modo de código para ejecutar un script que declara su propio log, preview o sleep, que solía rechazar
  • Se modificó la renovación de inicio de sesión de macOS para probar el llavero con un elemento Claude Code-write-check.
  • Se cambió el encabezado /tasks y el recuento de fondo del pie de página a un número que cubre shells, monitores, llamadas MCP, agentes, flujos de trabajo y tareas programadas.
  • Se cambiaron los ganchos Stop y SubagentStop para enumerar el script de un monitor como monitor, no shell, en background_tasks.
  • Se eliminó el reintento automático de 2.1.326 en el límite indicado en un error de max_tokens; detrás de una puerta de enlace cuyo modelo requiere menos tokens de salida, establezca CLAUDE_CODE_MAX_OUTPUT_TOKENS en ese límite
  • [VSCode] Se agregó una línea encima del cuadro de mensaje después de decline el mensaje trust, con Review trust para recuperar el mensaje sin recargar la ventana.
  • [VSCode] Se corrigió el cierre de sesión de Claude Code en cada ventana y terminal cuando el servidor de inicio de sesión tardaba entre 10 y 30 segundos en responder a la actualización del token de la extensión.
  • [VSCode] Se corrigieron las teclas presionadas mientras un método de entrada (IME) estaba componiendo, moviendo el foco o decliniendo un mensaje de permiso, ejecutando filas de menú y cerrando cuadros de diálogo (anthropics/claude-code#106358)
  • [VSCode] Se corrigió la solicitud de permiso para Bash, Editar, Escribir y otras herramientas integradas que no mostraban por qué se solicita una verificación de seguridad.
  • [VSCode] Se corrigió que un comentario del plan a medio escribir se perdiera o se moviera a otro pasaje, y un método de entrada Enter enviaba el comentario, finalizaba una sesión, cambiaba el nombre o seleccionaba un archivo @mencionado.
  • [VSCode] Se corrigió el banner de límite que no decía cuándo los créditos de uso están en uso y la encuesta de sesión cubría ese banner y el uso de la tarjeta de crédito.
  • [VSCode] Se corrigió que los lectores de pantalla no anunciaran una solicitud de permiso que llegaba mientras el cuadro de diálogo Cuenta y uso estaba abierto hasta que se cerraba ese cuadro de diálogo.
  • [VSCode] Se corrigió una pestaña de diferencias de edición propuesta que permanecía abierta, con un botón Aceptar que no hacía nada, después de que se desconectaba la sesión de Claude Code en su terminal.
  • [VSCode] Se corrigieron las entradas y salidas de herramientas cortas cortadas en el borde del panel sin forma de leer el resto (ahora se abren en una pestaña del editor), y al arrastrar para seleccionar texto también se abre uno.
  • [VSCode] Se corrigió la tecla Arriba que colocaba un mensaje anterior sobre el texto que un método de entrada (IME) está componiendo en el cuadro de mensaje (anthropics/claude-code#101294)
  • [VSCode] Se corrigió la caída de una carpeta del Explorador en el chat sin insertar nada en VS Code 1.103 a 1.139 o en una ventana de chat flotante, y el resaltado de caída desaparecía con una sugerencia falsa de "Mantener presionada la tecla Mayús".
  • [VSCode] Se corrigió un mensaje de permiso que alejaba el foco del teclado de los detalles en los que se estaba desplazando mientras sus botones se encendían.
  • [VSCode] Se corrigieron los enlaces de archivos en una pestaña de Claude que se abre en otro grupo de editores cuando claudeCode.lockEditorGroups está desactivado (anthropics/claude-code#108884)
  • [VSCode] Se corrigieron los rangos escritos con una sola tilde (3~5 … 7~10) que perdían sus tildes y mostraban texto tachado entre ellas; sólo ~~text~~ está tachado ahora
  • [VSCode] Se corrigieron errores de dictado que se agrupaban en una columna estrecha, la ruleta giraba mientras esperaba una tarjeta de preguntas y un símbolo NUL después de cada letra en la salida de un comando UTF-16 fallido.
  • [VSCode] Se cambió hacia abajo para detenerse en el último elemento de una solicitud de permiso en lugar de ajustarse a Sí.
  • [VSCode] Se modificó la salida del comando para mostrar caracteres ocultos y secuencias de control distintas de los colores simples como símbolos, por lo que el texto en persa, jemer, laosiano, cingalés y malayalam puede verse roto o desordenado.
