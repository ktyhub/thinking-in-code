código-claude v2.1.330

¿Qué ha cambiado?

  • Se agregó inicio de sesión a organizaciones administradas en la Consola de administración empresarial de Anthropic: después de claude auth login, Claude Code aplica la configuración de la organización y usa su proveedor de nube o puerta de enlace.
  • Se agregó caballete, un mod incorporado que dibuja gráficos cuando se le solicita y según los resultados de las métricas de MCP, en Pro, Max y, cuando esté disponible, Team y Enterprise en macOS y Linux; desactivar los gráficos automáticos en /config
  • Se agregó CLAUDE_CODE_FULL_SIGN_IN_LINK=1 para imprimir el enlace de inicio de sesión completo, si el corto muestra un error o si un script lee valores del mismo.
  • Ejecutor autohospedado: se agregó --start-dir / SELF_HOSTED_RUNNER_START_DIR para que Claude comience su trabajo en una carpeta de un repositorio, mientras que las configuraciones y los enlaces se cargan como sin él.
  • Se agregó un aviso en las sesiones de ejecución en la nube y autohospedadas cuando no se puede recuperar un mercado de complementos porque su repositorio no es uno de los de la sesión.
  • Ejecutor autohospedado: se agregó un aviso cuando git administrado por Anthropic rechaza el repositorio propio de un complemento, nombrando el complemento y qué hacer.
  • Se agregó commandPrinted a los resultados de claude plugin install --json, verdadero cuando el comando de instalación del complemento se escribió en stderr y commandFailed cuando salió con un error, se eliminó o se agotó el tiempo de espera.
  • Se agregó claude_code_self_hosted_runner_order_to_registered_seconds al /metrics del corredor autohospedado: segundos desde la orden de trabajo emitida hasta el registro aceptado, en corredores generados por el orquestador.
  • Se agregó claude_code_self_hosted_runner_order_to_first_session_seconds al /metrics del corredor autohospedado: segundos desde la orden de trabajo hasta la primera sesión entregada, en corredores iniciados para una sesión
  • Se corrigió que Claude Code se congelara por hasta varios minutos justo después de compactar una conversación muy larga.
  • Se corrigió que WebFetch congelara la sesión durante minutos en algunas páginas y devolviera un resultado vacío en otras.
  • Se corrigió ExitWorktree y el cuadro de diálogo de salida del árbol de trabajo que eliminaba un árbol de trabajo en el que estaba trabajando otra sesión de Claude Code en ejecución.
  • Se corrigieron los cambios en la configuración del usuario que se perdían cuando varios procesos de Claude Code los guardaban al mismo tiempo.
  • Se corrigió que --continue y --resume abrieran una sesión vacía o fallaran cuando el último mensaje guardado tenía una marca de tiempo faltante o no válida.
  • Se corrigió el primer mensaje después de un sueño de dos minutos o más esperando tres minutos en una conexión que había muerto, en Linux y WSL.
  • Se corrigieron errores en los giros con "El esquema JSON no es válido" y los archivos de sesión crecían en muchos megabytes, cuando muchas herramientas MCP tienen un esquema de entrada que el API rechaza.
  • Linux: Se corrigieron los comandos Bash que esperaban segundos y no mostraban diferencias de archivos durante el resto de una sesión en repositorios lentos con carpetas grandes ignoradas como node_modules.
  • Windows: Se corrigió que los comandos de Bash se ejecutaran más lentamente durante el resto de una sesión después de que Git Bash tardara entre 10 y 60 segundos en iniciarse, en máquinas sin archivos de inicio personalizados.
  • Se corrigió que /rewind a veces restaurara una versión anterior de un archivo cuando dos indicaciones en cola o habilidades apiladas se ejecutaban juntas justo después de un turno que lo cambiaba.
  • Se corrigió que el texto y las imágenes agregados al aprobar una solicitud de permiso se eliminaran cuando el comando o herramienta aprobado fallaba
  • Se corrigieron los recursos MCP de los conectores claude.ai y los servidores de complementos que no se adjuntaban cuando se mencionaba con @ en el cuadro de aviso del terminal.
  • Se corrigió un servidor MCP que los subagentes declaraban estar cerrado cuando uno de ellos terminaba, mientras otros subagentes o la sesión todavía lo estaban usando.
  • Se corrigió que Claude en Chrome permaneciera "no conectado" después de un breve problema de conexión, a pesar de que Chrome estaba abierto e iniciado sesión.
  • Se corrigieron las sesiones de terminal en Amazon Bedrock (Mantle) que comenzaban sin ningún modelo seleccionado, ignorando un modelo Opus anclado y aún llamando a un modelo predeterminado no disponible después de anunciar un respaldo.
  • Se corrigió que el resto de lo que estabas escribiendo se perdiera cuando llegaba un plan en modo de pantalla completa.
  • Se corrigieron los conectores claude.ai con diferentes nombres que se eliminaban cuando compartían la URL de un servidor (anthropics/claude-code#101856)
  • Se corrigieron los complementos que desaparecían de la lista instalada cuando se ejecutaban varios comandos claude plugin al mismo tiempo.
  • Se corrigieron las dependencias de tareas y la pérdida de metadatos cuando se ejecutaban varias actualizaciones de tareas al mismo tiempo.
  • Se corrigieron copias de seguridad incompletas de ~/.claude.json que se mantenían y desplazaban las buenas cuando el disco estaba lleno.
  • Se corrigió una pausa larga en el modo de código después de que el código leyera cientos de archivos en proyectos con reglas de alcance de ruta o reglas de denegación de lectura.
  • Se corrigió que la herramienta de gráficos integrada fallara cuando Claude la llamaba en modo Código.
  • Modo de código fijo que ignora la solicitud de una herramienta MCP para finalizar el turno desde un script en los modos automático y de omisión de permisos.
  • Se corrigió el modo de código en el modo automático, eliminando el pensamiento anterior y reescribiendo el caché de mensajes cuando un mod agregaba una nota después de que un script cargaba una habilidad.
  • Se corrigió el modo de código que no restauraba un archivo que un script había leído después de Esc y /compact.
  • Se corrigieron las herramientas del sistema de conteo insuficiente de /context en el modo Código antes de la primera respuesta de Claude.
  • Se corrigió que un subagente en segundo plano detenido a veces no permaneciera detenido
  • Se corrigió que Claude todavía estuviera esperando un agente en segundo plano que se detenía justo cuando finalizaba, en sesiones ejecutadas por una aplicación o el SDK.
  • Se corrigió que las sesiones en segundo plano a veces se despertaran en su modo de permiso anterior después de aprobar un plan.
  • Control Remoto: Se corrigió la nota sobre agentes en segundo plano terminada por una Parada desde un teléfono o la web que se muestra en el terminal como si lo hubieras escrito
  • Control remoto: se corrigieron las aplicaciones móviles que ocultaban los botones Diff y Pull Request, o mostraban una sesión detenida como funcionando, después de encenderla en mitad de una conversación.
  • Se corrigieron las variables de entorno escritas por un gancho SessionStart que se perdían con claude -p --continue
  • Se corrigió que claude -p saliera de 0 sin mensaje cuando su salida iba a un archivo en un disco lleno: ahora imprime un error y sale de 1, aunque una exportación NFS completa puede pasar desapercibida.
  • Se corrigió el mensaje del sistema que mantenía las instrucciones del modelo anterior cuando el modelo se cambiaba después de /context pero antes del primer mensaje.
  • Se corrigió que Claude a veces respondiera a su recordatorio de atribución de compromiso y terminara el turno temprano después de que el modelo cambiara a mitad del turno; Todavía puede suceder cuando la configuración administrada establece la línea de atribución de relaciones públicas.
  • Se corrigió que Esc no finalizara una llamada a la herramienta LSP que estaba esperando un servidor de idioma lento o atascado.
  • Se corrigieron errores en las llamadas y diagnósticos de la herramienta LSP cuando llegaban varias llamadas o ediciones mientras un servidor de idiomas aún se estaba iniciando.
  • Se corrigió la lista de servidores de complementos /mcp como integrados: ahora se encuentran en "Complementos MCP", --mcp-config y los servidores integrados en "Otros MCP", y la página de un servidor nombra su complemento.
  • Se corrigió una advertencia de "Servidor MCP bloqueado por la política empresarial: caballete" que se muestra en cada inicio cuando una lista permitida o denegada de MCP excluye la herramienta de gráficos incorporada, que permanece bloqueada.
  • Se corrigió /stats que contaba la nueva actividad en días UTC en lugar de su zona horaria local.
  • Se corrigió el error de /ultrareview o la revisión del código incorrecto después de que el shell se movió a otro repositorio: ahora se detiene y nombra ambas carpetas.
  • Se corrigió que Grep no informara coincidencias cuando el patrón contenía un salto de línea sin modo multilínea; ahora informa el patrón rechazado
  • Se corrigieron los cuadernos de Jupyter guardados con una marca de orden de bytes que las herramientas de lectura y NotebookEdit informaban como JSON no válido.
  • Se corrigieron las definiciones de referencia de enlaces que se eliminaban de CLAUDE.md y los archivos de memoria que contienen un comentario HTML.
  • Se corrigió que los monitores en ejecución mantuvieran la conversación anterior en la memoria hasta que finalicen.
  • Se corrigieron algunas sesiones de Claude Desktop en proveedores externos, además de las tareas programadas, que finalizaban un turno con "El mensaje es demasiado largo" cuando un PDF más grande que la ventana contextual seguía a una conversación larga.
  • Se corrigió la elección entre dos archivos de usuario o agente de proyecto que declaraban el mismo nombre dependiendo del orden en que los enumeraba la búsqueda de archivos.
  • Se corrigió que claude daemon logs nunca saliera dentro de un repositorio git cuando no había un archivo de registro.
  • Se corrigió la reducción que ocultaba uno o dos caracteres después del texto en negrita o cursiva cuando una barra invertida aparecía antes de un emoji más adelante en el párrafo.
  • Se corrigió la edición que rechazaba algunos comandos de enlace válidos en los archivos de configuración de Claude.
  • Se corrigió Read con un rango de páginas que mostraba ambas mitades de una extensión de dos páginas escaneada en cada una de sus páginas.
  • Se corrigieron los saltos de línea y los estereotipos de clase que faltaban en los diagramas de sirena en los artefactos HTML.
  • Se corrigió el selector de instrucciones del proyecto en /config que muestra solo una de sus cuatro opciones en una ventana de pantalla completa de 24 filas.
  • Se corrigieron los propios subagentes y bifurcaciones de un subagente que se ejecutaban en el modelo en modo plan en modo plan bajo opusplan o haiku.
  • Se corrigieron los resúmenes de páginas de WebFetch que ignoraban el nivel /effort cuando una puerta de enlace rechaza el modelo pequeño y rápido.
  • Se corrigió claude -p en la plataforma de agentes de Google Cloud ignorando --settings '{"fastMode":true}' cuando el modelo proviene de ANTHROPIC_MODEL o un archivo de configuración; tales carreras ahora se facturan al precio del modo rápido
  • Se corrigió que el inicio bajo forceLoginOrgUUID fuera rechazado después de un error temporal del servidor o una conexión interrumpida.
  • Se corrigió que claude mcp remove no permitiera avanzar para un conector claude.ai: ahora dice que lo apagues en /mcp o lo elimines en claude.ai.

  • Se corrigió que los corredores autohospedados ignoraran una sesión hasta que salían, después de que se perdía el informe de fallas o la sesión se devolvía al mismo corredor.

  • Ejecutor autohospedado: se corrigieron las llamadas de herramientas detrás de un mensaje de permiso que desaparecían sin resultado cuando un nuevo corredor se hacía cargo del mensaje, en sesiones con la telemetría desactivada.
  • Se corrigieron las sesiones de ejecución autohospedadas reanudadas que comenzaban sin su trabajo enviado en repositorios grandes cuando se configura --push-outcome-on-release
  • Se corrigió que las sesiones de corredor autohospedadas mostraran que funcionaban cuando Claude Code se bloquea en cada inicio y --startup-timeout-min es de 2 a aproximadamente 6.
  • Se corrigió pkill -f en sesiones de ejecutor autohospedadas en Linux que terminaban su propio shell con el código de salida 144, o el ejecutor (necesita un pkill con --ignore-ancestors)
  • Se corrigieron las tareas programadas en los corredores autohospedados que no tenían una herramienta para notificar a su propietario cuando la telemetría estaba desactivada o se utiliza un proveedor externo.
  • Corredor autohospedado: se corrigió un gancho lento de spawn-runner que impedía que el orquestador reclamara sesiones para sus espacios libres; ahora sondea cada 4 a 6 segundos mientras hay un espacio libre
  • Ejecutor autohospedado: se corrigió un 403, como una lista de IP permitidas, registrado como un secreto incorrecto o token: la mayoría de estas líneas ahora comienzan con el motivo del servidor, por lo tanto, actualice las alertas de registro que coincidan con las palabras antiguas.
  • Se corrigió el modo de advertencia de los corredores autohospedados para la configuración del repositorio que se detenía ante el primer hallazgo de la mayoría de los tipos: ahora continúa, hasta 50 por sesión, y dice si se detiene antes
  • Ejecutor autohospedado: ejecutores fijos que comienzan en un disco lleno tomando sesiones y fallando; ahora esperan por espacio y salen 1 después de un minuto sin sesión, a menos que comiencen desde una orden de trabajo
  • Ejecutor autohospedado: se corrigió un inicio fallido que sugería un reintento cuando la máquina del ejecutor no tenía credenciales de git; el error ahora dice a quién preguntar y qué hacer si el repositorio está mal
  • Se corrigió la lectura last_poll_age_seconds del corredor autohospedado mientras el corredor nunca había realizado una encuesta exitosa.
  • Se corrigió el aviso sobre una tarea programada omitida que no nombra ninguna organización: ahora dice iniciar Claude Code con --resume, porque /resume dentro de una sesión en ejecución no ejecuta la tarea.

  • Se corrigió que /design-sync eliminara un archivo que acababa de cargar cuando Claude Design almacenó ese archivo con un nombre cambiado.
  • Se revirtió la eliminación del reintento automático de 2.1.329 cuando max_tokens excede el límite de un modelo o puerta de enlace.
  • Se mejoró el enlace de inicio de sesión de claude.ai que se muestra en /login, claude auth login y claude setup-token: ahora es mucho más corto
  • Windows: velocidad mejorada de Grep y Glob al no iniciar más un host de consola para cada búsqueda ripgrep incorporada en una ruta local
  • Se mejoró la velocidad de las diferencias de archivos.
  • Búsqueda /config mejorada: la mayoría de las configuraciones cuyo nombre comienza con lo que escribes aparecen primero, "esfuerzo" busca el modelo y "oscuro" o "claro" busca el tema
  • /resume mejorado: las sesiones en las que solo abriste una pantalla como /model y saliste ya no aparecen en la lista
  • Reconexión mejorada en /mcp y /plugin: la página de un servidor ahora permanece abierta, con la causa a la vista, cuando el servidor aún falla o necesita iniciar sesión
  • Se mejoró el error en macOS cuando las listas de denegación de sandbox son demasiado largas: ahora nombra las listas largas y cómo acortarlas.
  • /plugin mejorado en modo de pantalla completa: la página de un complemento con errores ahora comienza con esos errores
  • Se mejoró la confirmación de costos de /ultrareview en los planes Team y Enterprise: ahora dice cuánto de su límite de gasto mensual queda cuando es menos de lo que normalmente cuesta una revisión.
  • Sesiones de corredor autohospedadas mejoradas en Amazon Bedrock o la plataforma de agentes de Google Cloud para indicarlo cuando comienzan en otro modelo predeterminado porque su cuenta rechazó el primero.
  • Windows: se mejoró el error cuando la carpeta de una sesión está en una unidad que Claude Code no puede verificar: dice por qué y si volver a intentarlo puede ayudar
  • Modo de código mejorado: ahora se le dice a Claude cómo mirar imágenes y archivos PDF.
  • Modo de código mejorado: después de Esc, "Interrumpido" ahora se muestra debajo del comando detenido en lugar de un error rojo
  • Modo de código mejorado: el terminal se congela durante mucho menos tiempo después de que el script de un subagente realiza miles de llamadas a herramientas
  • Se cambiaron las tareas programadas recurrentes y /loop para que se ejecuten hasta 30 días en lugar de 7 mientras la sesión continúa ejecutándose y dicen cuándo finalizan; Las tareas realizadas antes de esta versión aún finalizan a los 7 días.
  • Se cambiaron más comandos rm dirigidos a la raíz, al inicio, a una carpeta de nivel superior o a la carpeta de trabajo para solicitar aprobación; donde nadie puede responder, son rechazados
  • Se cambiaron las entradas de nombre deniedMcpServers para ocultar solo el conector claude.ai con nombre, no otros en su URL; para bloquearlos a todos, niega su URL exacta
  • Se modificó claude --teleport en algunas configuraciones para imprimir los comandos de git para cambiar de rama en lugar de ejecutarlos; con -p sale 1 hasta que cambias
  • Se cambiaron los nombres de modelos no reconocidos que contienen "soneto" o "haiku" para usar el mensaje del sistema más corto, como otros nombres no reconocidos; CLAUDE_CODE_SIMPLE_SYSTEM_PROMPT=0 le da a cada modelo el modelo completo
  • Se cambiaron las habilidades que Claude ejecuta con una configuración model, distintas de las habilidades context: fork, para dejar subagentes, horquillas, compactación y /recap en el modelo de la sesión.
  • Se cambió el modelo de respaldo de un subagente para transferirlo: los agentes sin modelo y se bifurcan, luego comienzan a ejecutarse en el respaldo, y los agentes que comienzan a usar su región Bedrock.
  • Ejecutor autohospedado: se cambiaron los ganchos spawn-runner para que se inicien mientras los anteriores aún se ejecutan, hasta --hook-concurrency por orquestador (4 de forma predeterminada); configúrelo en 1 si el suyo no puede correr al lado de otro
  • Ejecutor autohospedado: se cambiaron los comandos de Bash para omitir la diferenciación del archivo cuando nada lo necesita, por lo que las transcripciones pueden carecer de él; establezca bashEditDiffEnabled en verdadero en la configuración administrada para obtener todas las diferencias
  • Se cambiaron los corredores autohospedados para detener el inicio de una sesión de inmediato, sin intentarlo con otros corredores, cuando un gancho de pago sale con el estado 108.
  • Se cambiaron los ganchos de aviso para aceptar alias de modelos como haiku o sonnet en su campo model.
  • Se modificó la versión alternativa del Storybook de referencia de /design-sync para usar solo un Storybook instalado en el proyecto.
  • Se modificaron los resúmenes de progreso de los subagentes en las sesiones de terminal iniciadas en una puerta de enlace de aplicaciones de Claude para que se escriban a partir de notas breves en lugar de toda la conversación, utilizando muchos menos tokens.
