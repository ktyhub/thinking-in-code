código-claude v2.1.307

¿Qué ha cambiado?

  • Se agregó /claude-api api-version para mover el código Claude API a la versión API 2026-10-21.
  • Se agregó el evento claude_code.safety_event OpenTelemetry para cada herramienta que llama a una regla de permiso, modo automático, verificación de seguridad, gancho o sandbox detenido, solicitado o devuelto.
  • Se corrigió que las solicitudes fallaran con un error de modelo no encontrado cuando se configura CLAUDE_CODE_DISABLE_1M_CONTEXT y el modelo es un alias con el sufijo [1m], como opus[1m].
  • Se corrigió el encabezado beta de prompt-caching-scope que se enviaba detrás de puertas de enlace ANTHROPIC_BASE_URL personalizadas y en Foundry, donde no tiene ningún efecto.
  • Se corrigieron los servidores MCP que mostraban "necesita autenticación" en claude -p en macOS mientras el llavero de inicio de sesión estaba bloqueado; ahora dicen por qué, y la siguiente ejecución después de un desbloqueo se conecta sin un nuevo inicio de sesión
  • Se corrigió que los servidores MCP se informaran como agotados y permanecieran fallando en ejecuciones sin cabeza, cuando una computadora macOS o Linux entraba en modo de suspensión mientras se estaban conectando.
  • Se corrigieron las llamadas a la herramienta HTTP MCP que se enviaban dos veces cuando la conexión se cerraba a mitad de la llamada; Ahora sólo se reintentan las herramientas de sólo lectura o idempotentes.
  • Se corrigió un problema que a veces comenzaba sin las últimas herramientas del servidor MCP SDK cuando se estaba ejecutando una tarea en segundo plano.
  • Se corrigieron algunos errores de "Autocompact is thrashing" en turnos que leían muchas páginas PDF, imágenes u otros resultados de herramientas grandes.
  • Se corrigió /autocompact en sesiones en la nube volviendo a la ventana predeterminada después de reiniciar la sesión.
  • Se corrigió una conversación borrada con /clear que a veces regresaba cuando se reiniciaba una sesión de corredor autohospedada o en la nube.
  • Se corrigió que CLAUDE_STREAM_FIRST_BYTE_TIMEOUT_MS se ignorara en las sesiones de puerta de enlace de aplicaciones de Claude.
  • Se corrigió el rechazo de la telemetría de las sesiones de Claude Desktop detrás de una puerta de enlace de aplicaciones de Claude cuando se configura OTEL_EXPORTER_OTLP_HEADERS.
  • Se corrigió /permissions > Recientemente denegado no mostrar el comando de shell denegado, y el clasificador local del modo automático ignoraba una aprobación desde allí cuando verifica un comando reintentado; aprobar una fila ahora nombra el comando, no su descripción
  • Se corrigió que /help y el menú de comando / mostraran descripciones largas orientadas al modelo para habilidades incluidas como /claude-api en lugar de sus descripciones breves.
  • Se corrigieron las transcripciones de subagente que registraban el uso de tokens de marcador de posición y un motivo de parada vacío para las respuestas transmitidas.
  • Se corrigió el cambio de modelo a través del setModel() del Agente SDK y las aplicaciones creadas en él, siendo rechazado cuando el API tardó más de 5 segundos en confirmar el modelo; Claude Code ahora espera hasta 15 segundos
  • Se corrigió un comando en segundo plano detenido a través de una aplicación conectada (como la aplicación de escritorio que archiva una sesión inactiva) que se informaba a Claude como detenido por el usuario; el aviso ahora nombra su archivo de salida
  • Se corrigió WebFetch en sesiones de nube de Cowork que informaban un error de herramienta cuando un sitio respondía con un estado 4xx o un rechazo de robots.txt; Ahora es un resultado normal, como en las sesiones locales.
  • Se corrigieron las herramientas de escritura en un servidor MCP GitHub configurado directamente que mostraba un formulario que se cerraba sin crear nada en la pestaña Código de la aplicación de escritorio.
  • Se corrigió que la herramienta Artifact fallara al restablecer la conexión cuando el servidor había cerrado una conexión reutilizada.
  • Ejecutor autohospedado: Se corrigieron sesiones con --use-anthropic-git-proxy que confirmaban un .claude/settings.local.json dejado en el clon por una sesión anterior.
  • Corredor autohospedado: se corrigió el archivado o la puesta en cola de una sesión, o la detención del corredor, durante su gancho de pago, dejando los procesos del gancho en ejecución y la ranura del corredor retenida.
  • Recuperación mejorada de llamadas de herramientas no analizables: Claude Code ahora reintenta la llamada hasta dos veces antes de finalizar el turno con un error.
  • Subagentes de bifurcación mejorados lanzados juntos: ahora a cada uno se le dice qué lanzamiento es el suyo, por lo que es mucho menos probable que las bifurcaciones intenten iniciar el trabajo de los demás.
  • Inicio de sesión en el navegador mejorado: la página de éxito ahora aparece tan pronto como se completa el inicio de sesión, sin esperar a que se cargue el perfil de su cuenta.
  • Errores de búsqueda web mejorados en sesiones de ejecución en la nube y autohospedadas: una búsqueda rechazada con un 403 que da un motivo ahora muestra ese motivo en lugar de un "Error de autenticación" genérico
  • Se mejoró el tiempo hasta la primera respuesta en sesiones en la nube cuando uno de los servidores MCP de la aplicación de escritorio no se puede conectar.
  • Tiempo de conexión de control remoto mejorado para sesiones cuya transcripción contiene imágenes pegadas de gran tamaño o lecturas de PDF
  • Se modificó el aviso que recibe Claude cuando se agota el presupuesto de WebSearch para indicarle también que no consulte los motores de búsqueda en un navegador o mediante el uso de una computadora.
  • Se cambió la configuración de axScreenReader y CLAUDE_AX_SCREEN_READER en un bloque de configuración env para aplicar solo desde la configuración del usuario, administrada o --settings (desde 2.1.305)
  • Ejecutor autohospedado: se cambiaron los ganchos de pago para que se detengan después de 30 minutos de forma predeterminada, lo que falla en la configuración de la sesión; Si el tuyo necesita más tiempo, aumenta --checkout-hook-timeout-min o configúralo en 0.
  • Ejecutor autohospedado: se modificó el archivo de certificado creado para git administrado por Anthropic para filtrar sus certificados trusted como lo hace el CLI; una línea [runner:warn] proporciona el número omitido
  • [VSCode] Se agregó un aviso en el botón del micrófono cuando el dictado de voz se detiene por sí solo (15 segundos sin voz reconocida, o el límite de 2 minutos), diciendo por qué y que el texto hasta el momento se mantiene.
  • [VSCode] Se corrigió un mensaje largo ampliado con Mostrar más que cubre todo el panel de chat: un mensaje fijado ahora tiene un límite del 40% del panel y se desplaza
  • [VSCode] Se corrigió parte de un elemento de lista o celda de tabla con pegado matemático LaTeX como una nueva lista o tabla en editores de texto enriquecido
  • [VSCode] Se corrigió el error de dictado detrás de un proxy de inspección TLS cuando NODE_EXTRA_CA_CERTS está configurado solo en ~/.claude/settings.json; ahora también sigue a CLAUDE_CODE_CERT_STORE
  • [VSCode] Se modificó el aviso "aún abierto en otro lugar" para cubrir también un proceso de Claude que queda del reinicio de una extensión, que generalmente finaliza solo en aproximadamente 10 minutos.
  • [VSCode] Se cambió el dictado de voz para filtrar sus certificados trusted como lo hace el CLI.
  • [VSCode] Se cambiaron las solicitudes propias de la extensión para filtrar sus certificados trusted como lo hace el CLI, y a trust el archivo NODE_EXTRA_CA_CERTS nombrado en el entorno o en la configuración del usuario.
  • [Sesiones en la nube] Se corrigió el selector de repositorio que decía "No hay coincidencias de repositorios" mientras aún se estaba ejecutando una búsqueda; ahora muestra "Buscando..." hasta que lleguen los resultados
  • [Sesiones en la nube] Se corrigió el estado "Esperando a un corredor" en entornos autohospedados que se cortaban; con los corredores bajo demanda ahora cuenta desde su último mensaje y muestra los intentos fallidos
  • [Revisión de código] Se agregó @claude review stop (también off y pause) a la revisión de código, finalizando una suscripción a @claude review always en una solicitud de extracción sin iniciar una nueva revisión.
