código-claude v2.1.326

¿Qué ha cambiado?

  • Se agregó soporte para activar el Modo Código mientras los equipos de agentes están habilitados; Si ya lo activó, las sesiones con equipos ahora comienzan en modo Código
  • Se agregó una advertencia de inicio cuando un valor --allowedTools, --disallowedTools o --tools tiene una entrada que no parece una regla completa.
  • Se agregó un mensaje que explica por qué los servidores MCP dejan de cargarse cuando un administrador agrega managed-mcp.json durante una sesión.
  • Se agregó una fila a /status que indica cuándo su proveedor o una variable de entorno como DISABLE_TELEMETRY desactiva las funciones.
  • Se agregó una nota en /plugin y claude plugin list cuando se ignora un campo plugin.json con formato incorrecto, como author o homepage.
  • Se agregó Ctrl+O para mostrar avisos de inicio ocultos.
  • Se agregó una pista en el mensaje vacío que dice qué hacer después de que falla una solicitud.
  • Se agregó una sugerencia de pie de página esc to stop en la vista de un subagente donde Esc lo detendría.
  • Se agregó OTEL_RESOURCE_INCLUDE_HOST para incluir host.name y host.id en los atributos de recursos de OpenTelemetry (desactivado de forma predeterminada)
  • Se agregó overflowX="scroll" en el Box de un mod, y maxLines y wrap="clip" en su Text.
  • Se corrigió cp de un archivo rechazado cuando solo su fuente estaba cubierta por una regla de denegación Edit
  • Se corrigieron los comandos Bash que eliminaban o sobrescribían archivos (find -delete, cat a > b, sort -o) que se resumían en la transcripción como una búsqueda o una lectura.
  • Se corrigió una advertencia engañosa de "Operación rm peligrosa" en el mensaje de permiso de Bash en algunos comandos sin rm que Claude Code no puede leer de manera confiable
  • Se corrigió que las sesiones en segundo plano perdieran la puerta de enlace LLM que su shell exportaba después de un bloqueo, después de volver a abrir desde otra carpeta o cuando el servicio en segundo plano carece de ella: ahora se detienen antes de cualquier solicitud de modelo.
  • Se corrigió el servicio en segundo plano que finalizaba sus propios procesos, como un inicio de sesión SSH, cuando un número de proceso en su lista había sido reutilizado por el proceso de otro usuario.
  • Se corrigieron las reglas agregadas en /permissions o en el mensaje de la herramienta de conversación principal, y las carpetas /add-dir, que parecían guardadas cuando no se podía escribir el archivo de configuración; el terminal ahora avisa y le pone nombre
  • Se corrigió un MCP headersHelper fallido, o uno que no se ejecutó en una carpeta untrusted, lo que hacía que otras sesiones comenzaran sin ese servidor, para la mayoría de los servidores sin token de actualización de OAuth almacenado.
  • Se corrigió la configuración administrada con ciertos nombres clave que impedían que Claude Code se iniciara o afectara otros archivos administrados.
  • Se corrigieron archivos de configuración con valores anidados en miles de niveles que bloqueaban Claude Code o se aplicaban solo algunas veces; Los valores superiores a 64 niveles ahora se eliminan con una advertencia.
  • Se corrigió un archivo de configuración guardado con un error a mitad de sesión que se omitía silenciosamente; una advertencia ahora nombra el archivo
  • Se corrigió el modelo de subagente establecido en la configuración administrada que no se aplicaba en la pestaña Código de Claude Desktop; ahora anula el suyo, como en una terminal, a menos que esas configuraciones también elijan un proveedor o puerta de enlace

  • Se cambió la verificación de permisos de Bash para preguntar sobre algunos comandos con valores muy largos que no puede terminar de verificar, o para rechazarlos cuando se puede aplicar una regla de denegación o nadie puede responder.
  • Se cambiaron los subagentes aislados en un árbol de trabajo para rechazar, en cualquier repositorio, algunos comandos git en Bash que pueden reescribir ramas compartidas con su pago; las sesiones no se ven afectadas
  • Se modificó ExitWorktree para rechazar la eliminación de un árbol de trabajo mientras aún se puede ejecutar un subagente en segundo plano o un comando de shell en él, a menos que Claude pase discard_changes.
  • Se modificó el uso de la computadora en el panel de permisos de macOS para ignorar j y k; las teclas de flecha y Ctrl+P/Ctrl+N aún mueven la selección
  • Se cambió la herramienta PowerShell para preguntar antes de algunos comandos más; las ejecuciones desatendidas las rechazan a menos que una regla de permiso, el modo automático o el modo de omitir permisos las permitan
  • Se modificó la herramienta PowerShell para preguntar sobre algunos comandos más, incluso en el modo de omitir permisos, y rechazar algunos de ellos.
  • Se cambiaron algunos comandos de PowerShell con formato incorrecto para que sean denegados.
  • Se cambiaron algunos comandos de la herramienta PowerShell que definen una función denominada como un comando integrado para ser rechazada, para que Claude pueda cambiarle el nombre.
  • Se modificó el modo automático para ignorar algunas reglas de permiso del shell comodín, como las que no nombran ningún programa o que comienzan con $HOME, de modo que la verificación de seguridad decida esos comandos.
  • Se modificó el modo automático para juzgar las reglas que permiten comodines cuyo programa es una ruta de barra invertida de Windows, de modo que esas llamadas se puedan bloquear; las reglas exactas mantienen su permiso; planeamos restaurar las reglas que comienzan con .\
  • Se cambió una lista administrada de autoMode.environment sin "$defaults" para reemplazar cada entrada integrada en las aplicaciones Claude Desktop y Agent SDK también; agregue "$defaults" o copie los de objetivos sensibles
  • Se cambiaron --add-dir y /add-dir en sesiones de terminal local para mostrar el mensaje trust para una carpeta en la que aún no se ha trust; claude --bg rechaza dicha carpeta
  • Se cambiaron los ejecutores autohospedados en --trust-workspace false para ignorar más configuraciones del repositorio; establecer dichos valores en la configuración de usuario o administrada
  • Se modificó la forma en que las respuestas de permiso en el control remoto y en los corredores autohospedados guardan las opciones de "permitir siempre"
  • Se modificaron los complementos habilitados que fueron rechazados por un campo de visualización plugin.json con formato incorrecto: ahora se cargan, con sus ganchos y servidores MCP; Los administradores deben verificar los complementos que implementan.
  • Se modificó la forma en que allowedHttpHookUrls y httpHookAllowedEnvVars se aplican a los enlaces desde la configuración administrada.
  • Se cambiaron los enlaces HTTP para ignorar Content-Length y Transfer-Encoding en su configuración headers; la longitud de la solicitud proviene de su cuerpo
  • Se modificó la desinstalación del complemento para eliminar también los archivos extraídos de los paquetes MCP del complemento (.mcpb, .dxt), a menos que otro complemento use el mismo paquete.
  • Se cambiaron algunas sesiones del árbol de trabajo para omitir algunas configuraciones de complementos; un aviso nombra lo que se omitió
  • Se modificó la desinstalación, eliminación y cambio de preguntas de /plugin a listas respondidas con las teclas de flecha y Enter o Esc para cancelar; y, n y u ya no les contestan
  • Se modificó la compactación automática en modo plan para usar el modelo que le responde, como Opus con opusplan, por lo que puede costar más.
  • Se cambiaron las sesiones de nube de Cowork para mantener la exportación OpenTelemetry de una organización hasta el primer turno; una sesión que no recibe ningún mensaje ahora no envía nada, por lo que claude_code.session.count puede caer
  • Se cambiaron los mensajes de Claude a una sesión en otra máquina para que se rechacen cuando su sesión use una clave API, un token de autenticación, un perfil o una identidad de carga de trabajo junto a un inicio de sesión guardado en claude.ai.
  • Se cambiaron las sesiones de --bare en una clave API no aprobada: ahora se rechaza mover una a segundo plano en la mayoría de las configuraciones, y claude --bare --bg sale con un error si el servicio en segundo plano carece de la clave.
  • Se modificó "Continuar automáticamente al límite de uso" para detener con un aviso, sin enviar nada, cuando su inicio de sesión cambia o finaliza durante la espera.
  • Control remoto: se modificó la forma en que se conecta a través de un proxy: las solicitudes ahora usan un túnel CONNECT, por lo que un proxy que rechaza CONNECT detiene el control remoto con un error
  • Control remoto: se cambiaron los registros de depuración de sesión escritos en --verbose para ir a ~/.claude/child-logs/
  • Ejecutor autohospedado: Se cambiaron las sesiones de Linux y macOS sin gh para obtener un gh api integrado de forma predeterminada, a través de Anthropic, que agrega su inicio de sesión GitHub, si lo hubiera; --use-anthropic-gh false lo apaga
  • Se cambió la vista del agente para que al salir con Ctrl+C dos veces, Ctrl+D dos veces o /exit después de presionar ← en una conversación vacía finalice esa sesión, en lugar de dejarla ejecutándose durante 5 minutos.
  • Se modificó --await-initialize para que se rechace con --bg o --worktree --tmux, que nunca leen la solicitud de inicialización, en lugar de comenzar sin los campos que contiene.
  • Se modificó la creación del árbol de trabajo, /teleport y las comprobaciones de IDE para ejecutar git con un PATH más estricto; un filtro o ayudante de git puede necesitar su ruta completa
  • Se cambió la tarjeta para aprobar el plan de un subagente a dos opciones, "Sí, y cambiar al valor predeterminado (preguntar cada vez) para esta sesión" y "No", elegidas con las teclas de flecha y Enter (el texto escrito se mueve a No)
  • Se modificó la habilidad /claude-api para crear agentes en agentes administrados de forma predeterminada, a menos que desee alojar el bucle del agente usted mismo.
  • Se modificó /usage en modo de pantalla completa para mostrar las barras de límite del plan antes del costo de la sesión para los suscriptores; /cost todavía comienza con el costo
  • Se modificó la redacción de algunos mensajes que imprimen los subcomandos claude; La salida JSON no cambia
  • Se modificó la configuración de primera ejecución para preseleccionar el tema "Auto (terminal de partido)" en lugar del modo oscuro.
  • Se cambió /cd de pantalla completa para rechazar "Sí" mientras el mensaje trust no encaja, con una línea que dice "hacer la ventana más alta"
  • Se eliminó el aviso de tmux que decía que la rueda del mouse necesita set -g mouse on en pantalla completa; la rueda se desplaza sin ella
  • Se eliminó la punta giratoria que sugería /clear después de 30 minutos de un giro en carrera.
  • [VSCode] Se agregó una configuración claudeCode.promptSuggestions que desactiva las sugerencias rápidas
  • [VSCode] Se corrigió "Rebobinar código hasta aquí" en una conversación bifurcada que a veces deshacía un giro de más y eliminaba archivos creados en ese turno.
  • [VSCode] Se corrigió el cuadro de diálogo Sandbox que creaba archivos y carpetas vacíos en el directorio de inicio y la carpeta .git del proyecto mientras el sandbox estaba desactivado.
  • [VSCode] Se corrigió que el inicio de sesión guardado se perdiera en algunas redes.
  • [VSCode] Se corrigió el final del inicio de sesión cuando se pega un código de verificación, una dirección web o un código de otro intento de inicio de sesión; el panel ahora dice qué pegar en su lugar
  • [VSCode] Se corrigió la pantalla de inicio de sesión que se mostraba brevemente cada vez que se abría un panel o ventana mientras se iniciaba sesión en la consola sin una clave API.
  • [VSCode] Se corrigió el botón "Solicitar más" del banner de límite de uso para los miembros del Equipo y Empresa que regresaban después de cada pulsación sin enviar nada, después de iniciar sesión nuevamente durante una sesión.
  • [VSCode] Se corrigió /ide en una segunda sesión de Claude Code perdiendo silenciosamente la conexión del editor a la primera sesión; la conexión más nueva ahora gana y la sesión desplazada muestra cómo volver a cambiar
  • [VSCode] Se corrigió que los recuerdos guardados no aparecieran en el cuadro de diálogo Memoria, o que el uso de RAM creciera sin fin, cuando la carpeta de memoria contenía bucles de enlaces simbólicos y se bloqueaba cuando contenía una tubería con nombre.
  • [VSCode] Se corrigió que la salida en vivo de un comando en ejecución se detuviera después de una lectura fallida.
  • [VSCode] Se corrigió "Abrir en Terminal" que mostraba solo el error del shell cuando no se podía iniciar claude: en bash, zsh, fish y Git Bash, ahora hay un aviso que explica por qué y enlaces a la guía de instalación.
