claude-code v2.1.288

código-claude v2.1.288

¿Qué ha cambiado?

  • Se agregó $.ui.selection() para modificaciones: devuelve el texto que seleccionó por última vez en modo de pantalla completa y, cuando la selección se encuentra dentro de una fila de transcripción, esa fila
  • Se agregó un gh api integrado a las sesiones en la nube cuya imagen no tiene GitHub CLI y se corrigieron los caracteres de control de envío integrados de nombres de archivos, filtros jq o errores de GitHub al terminal.
  • Se agregó recuperación para un mensaje borrado con Ctrl+C: al presionar Arriba en el mensaje vacío se recupera el borrador, incluidos el texto y las imágenes pegados.
  • Se agregó un mensaje de reautenticación cuando un servidor MCP solicita más alcance de OAuth durante una llamada de herramienta.
  • Se agregó --max-findings <n>|all a /code-review para informar más o menos hallazgos que el límite habitual; la elección se reutiliza hasta que pase --max-findings default
  • Se agregó Ctrl+F para buscar una sesión por nombre y Alt+ ↑/↓ para saltar entre grupos en la vista de agentes; ambos, y cambiar el nombre, se pueden recuperar mediante combinaciones de teclas.json
  • Se agregó un anuncio en modo lector de pantalla del nuevo modo de permiso cuando apruebas un plan, incluso con Shift+Tab
  • Se corrigieron los tiempos de espera a mitad de respuesta de API que fallaban en el turno: las sesiones no interactivas y los subagentes ahora continúan desde la respuesta parcial y se reintentan las respuestas de solo pensamiento.
  • Se corrigieron conversaciones largas que fallaban con "El mensaje es demasiado largo" en lugar de autocompactar cuando la última respuesta reportaba cero uso de token.
  • Se corrigió que --resume a veces dejara caer archivos y otros contextos que una compactación acababa de restaurar.
  • Se corrigió que una sesión reanudada a veces no guardara la última respuesta de un turno, por lo que el siguiente --resume mostraba el mensaje sin respuesta.
  • Se corrigió que el currículum ocasionalmente cargaba una transcripción interrumpida cuando la misma sesión reescribía el archivo durante la carga.
  • Se corrigió la reanudación de una conversación iniciada en 2.1.286 o antes, dejando caer el pensamiento anterior del modelo.
  • Se corrigieron los títulos de sesión, la recuperación de memoria y los enlaces de aviso que fallaban en Mantle o detrás de puertas de enlace que rechazan salidas estructuradas; Se agregó CLAUDE_CODE_DISABLE_STRUCTURED_OUTPUTS para desactivar las salidas estructuradas.
  • Se corrigieron las denegaciones del modo automático que señalaban a Claude una regla de permiso de Bash cuando la herramienta bloqueada no era Bash.
  • Se corrigió el modo automático en Bedrock y Mantle que cambiaba al clasificador local durante el resto de la sesión después de una solicitud a un modelo anterior, como un resumen WebFetch o un subagente sonnet.
  • Se corrigieron las sesiones en la nube que se reiniciaban en un modelo recién elegido respondiendo con ese modelo después de que el servidor lo rechazaba.
  • Se corrigió que las sesiones en la nube de Cowork permanecieran marcadas como en espera de entrada después de que una solicitud de permiso de WebFetch para una URL no aprobada no tuviera respuesta durante cinco minutos.
  • Se corrigieron sugerencias de mensajes que no aparecían en un teléfono que se unía a una sesión de nube de Cowork iniciada en otro dispositivo.
  • Se corrigió que el botón de un mod a veces ejecutara la acción de un botón diferente cuando se presionaba en una vista dibujada antes de que Claude Code se reiniciara.
  • Se corrigió el panel de un complemento que no mostraba nada cuando un elemento Code tenía una diferencia que no se analiza; ahora se dibuja como código simple
  • Se corrigió que los servidores LSP del complemento recibieran marcadores de posición literales ${user_config.*} y ${CLAUDE_PLUGIN_ROOT} en initializationOptions y settings en lugar de valores sustituidos o valores predeterminados manifiestos.
  • Se corrigió el gancho tool.call de un complemento que hacía que Bash fallara y las búsquedas de archivos leyeran la carpeta incorrecta en los subagentes que se ejecutan en un árbol de trabajo.
  • Se corrigió el error de instalación del complemento git-subdir, o el almacenamiento en caché de un complemento incompleto, en git más antiguo (antes de 2.39, por ejemplo, 2.34 de Ubuntu 22.04).
  • Se corrigieron los complementos cargados con --plugin-dir que no mostraban "Opciones de configuración" en /plugin.
  • Se corrigieron las sesiones en segundo plano que terminaban cuando un complemento se recargaba o deshabilitaba mientras uno de sus temporizadores o lecturas aún estaba ejecutándose.
  • Se corrigieron los heredocs en el espacio aislado con un delimitador sin comillas (python3 <<EOF) que pedían aprobación en cada ejecución bajo el permiso automático del espacio aislado cuando el cuerpo solo contiene texto sin formato y referencias $VAR simples.
  • Se corrigió la verificación de permisos de la herramienta Bash para aparecer antes de una asignación BASHPID cuyo valor el shell evaluaría como aritmético, en lugar de permitirlo silenciosamente.
  • Se corrigieron las sesiones de pantalla completa que salían con un "error de interfaz irrecuperable" al abrir el cuadro de diálogo de tareas en segundo plano mientras un complemento o mod mostraba filas encima del mensaje.
  • Se corrigió que Claude informara un mensaje a otra sesión como entregado cuando esa sesión lo retenía: el aviso ahora dice que no fue entregado y nombra la sesión, y en las sesiones SDK, Claude ahora puede enterarse de ello a mitad de turno.
  • Se corrigieron los intervalos de OpenTelemetry claude_code.tool.blocked_on_user que informan la fuente o decisión de unknown en las sesiones -p y SDK y para las aprobaciones de gancho PreToolUse.
  • Se corrigieron las solicitudes de permiso que terminaban sin respuesta, en -p o en un turno interrumpido, no emitiendo ningún evento tool_decision.
  • Se corrigió la edición y reintento en sesiones de nube de Cowork que rechazaban un mensaje enviado antes de /compact a pesar de que su historial aún estaba guardado.
  • Se corrigieron sesiones desatendidas (CLAUDE_CODE_RETRY_WATCHDOG) que se reintentaban durante horas después de que fallara un flujo de respuesta muy largo; Claude Code ahora se transmite nuevamente y se rinde después de tres tiempos de espera
  • Se corrigió el informe /login "Inicio de sesión exitoso" cuando las credenciales no se podían guardar en un almacenamiento seguro; ahora muestra el error y ofrece un reintento cuando el nuevo inicio de sesión no tuvo efecto (anthropics/claude-code#73861)
  • Se corrigió una parada durante la búsqueda de credenciales de Bedrock que a veces movía la sesión a un modelo alternativo en lugar de finalizar la solicitud.
  • Se corrigió una segunda apertura de inicio de sesión en el navegador gcpAuthRefresh/awsAuthRefresh cuando una computadora portátil sale del modo de suspensión mientras otro proceso de Claude Code está iniciando sesión.
  • Equipos de agentes fijos: un agente definido por complemento generado por nombre ahora se ejecuta con su propio mensaje, herramientas, herramientas no permitidas y esfuerzo en lugar de los valores predeterminados.
  • Se corrigieron sesiones sin cabeza (-p / SDK) que ocasionalmente ignoraban SIGTERM cuando un supervisor como timeout o systemd envía SIGCONT junto con él.
  • Se corrigieron sesiones en la nube reiniciadas que restauraban un modelo que la lista de modelos obligatorios de la organización rechaza.
  • Se corrigieron las llamadas a la herramienta MCP que a veces se ejecutaban dos veces cuando el resultado de un servidor remoto superaba los 16 MB o no se podía analizar.
  • Se corrigió que los subagentes en la pestaña Código de Claude Desktop no obtuvieran ninguna de las herramientas de un servidor MCP configurado por el usuario llamado memory.
  • Se corrigió que Claude en Chrome preguntara antes de cada captura de pantalla y página leída en un sitio que permitiste cuando el modo automático no está disponible (como con disableAutoMode o un modelo anterior); mecanografía, navegación y JavaScript todavía preguntan
  • Se corrigió la falla de claude plugin install para complementos de origen GitHub en máquinas macOS y Linux sin clave SSH GitHub: el clon ahora recurre a HTTPS e imprime un aviso
  • Se corrigieron las entradas de sandbox.credentials.files en los archivos de configuración de git que no surtían efecto mientras permissions.blockReadsOutsideWorkingDirectories estaba activado.
  • Se corrigió que Claude omitiera los sistemas de diseño de su organización al iniciar diapositivas o un diseño con la herramienta Artifact en planes o máquinas Team y Enterprise con configuraciones administradas.
  • Se corrigió que el teclado no funcionara en Windows después de que Claude Code se reinicia (primer inicio de sesión en una puerta de enlace de aplicaciones de Claude, configuración del proveedor, /tui)
  • Se corrigió un problema al iniciar un agente cuyo tools: enumera muchas entradas Agent(...).
  • Se corrigieron sesiones en Claude 3 Opus y Claude 3 Sonnet que fallaban en cada turno después de que un PDF completo ingresaba a la conversación.
  • Se corrigió el error en el informe del actualizador automático de npm cuando el binario nativo de la plataforma no se podía descargar y solo se instalaba el marcador de posición claude.
  • Se corrigió la limpieza del control remoto que archivaba una sesión que todavía estaba conectada o que acababa de volver a conectarse mediante otro proceso de Claude Code.
  • Se corrigieron los mercados de complementos owner/repo que mostraban solo el error del segundo intento cuando fallaban la recuperación de SSH y HTTPS; Ahora se muestran ambos errores, con el transporte probado primero en la parte superior.
  • Se corrigieron los archivos .claude/rules con alcance de ruta y CLAUDE.md anidados que no se cargaban cuando Escribir o Editar crea o cambia un archivo en su alcance (anteriormente solo los cargaba Leer)
  • Se corrigió un rm peligroso (como uno en / o el directorio de inicio) dentro de un script bash -c o sh -c que se ejecuta sin aviso en el modo bypassPermissions o bajo una regla de permiso de shell (anthropics/claude-code#96300)
  • Se corrigieron las llamadas de la herramienta LSP que se bloqueaban indefinidamente cuando un servidor de idioma utiliza el registro de capacidad dinámica o deja de responder; las solicitudes ahora vencen después de los 60 segundos (por servidor requestTimeout)
  • Se corrigieron los ganchos de notificación idle_prompt que se activaban mientras los agentes en segundo plano aún se estaban ejecutando (anthropics/claude-code#93672)
  • Se corrigieron los ganchos PreToolUse y PermissionRequest que se omitían cuando fallaban al emparejarlos o la entrada de la herramienta no se podía serializar en JSON; la llamada ahora esta bloqueada
  • Se corrigió la primera solicitud en un entorno nuevo o después de un cambio de modelo usando el límite de salida integrado y la ventana autocompacta, no la del servidor; esa solicitud ahora puede esperar hasta 1.5 segundos
  • Se corrigió el problema "¿Qué debería hacer Claude en su lugar?" sugerencia que se muestra en la fila Interrumpida después de enviar mensajes en cola con Ctrl+Intro
  • Se corrigió /login en una sesión --bare que ejecutaba un inicio de sesión que la sesión nunca lee, lo que podría reemplazar su inicio de sesión guardado; ahora dice qué credenciales funcionan
  • Se corrigió el gancho de InstruccionesLoaded que omitía agent_id y agent_type cuando el acceso a archivos de un subagente carga una regla o CLAUDE.md anidado; Las reglas y los archivos CLAUDE.md anidados cargados en el acceso a archivos ahora también informan sobre el esfuerzo.
  • Se corrigió la herramienta Agente en claude mcp serve que siempre informaba que no había agentes disponibles y rechazaba todos los tipos de subagente.
  • Se corrigió que el cursor del terminal no siguiera el texto escrito en la búsqueda del visor de transcripciones en pantalla completa y en la búsqueda de color personalizada de /theme.
  • Se corrigió /permissions en el modo lector de pantalla: al escribir el número de una regla ahora se selecciona en lugar de abrir el cuadro de búsqueda.
  • Modo automático mejorado: cuando una conversación se hace demasiado larga para que la revise el clasificador de seguridad del lado opuesto cli, ahora se compacta en lugar de solicitar o fallar en cada llamada de herramienta.
  • Modo de lector de pantalla mejorado: los anuncios cortos, como una palabra eliminada, ahora permanecen en la pantalla hasta que presione la próxima tecla o hasta que cambie algo encima de ellos en la pantalla.
  • Modo lector de pantalla mejorado: las preguntas respondidas en los cuadros de diálogo de preguntas ahora dicen "respondido" al lado de su cuadro
  • Se mejoró el mensaje /usage-credits que se muestra a los miembros del equipo y de la empresa cuya organización ha desactivado las solicitudes de crédito de uso.
  • Sesiones en la nube mejoradas: el primer turno de una nueva conversación ya no espera a un servidor stdio MCP cuya configuración establece alwaysLoad: false
  • Notas "Usted debe saber" mejoradas para decir "nosotros", "el agente principal" o "usted", dependiendo de quién fue responsable de una decisión
  • Se mejoró el error de escritura de base de datos de artefacto rechazada en el límite de tamaño de la base de datos: ahora indica el límite y lo que se libera espacio.
  • Se mejoraron las solicitudes de permiso de Bash para dar un motivo más breve cuando parte de un comando no se puede verificar antes de ejecutarse.
  • Ejecutor autohospedado: se mejoró el gh api integrado: un comando gh rechazado ahora imprime su equivalente gh api, --paginate sigue cada página de las listas de un repositorio y un claude anidado ya no lo elimina
  • Recuperación mejorada del control remoto de una credencial de servidor caducada: las sesiones permanecen conectadas durante la renovación y se conservan si se da por vencido después de una interrupción del servidor.
  • Se cambió el límite de tiempo del comando en segundo plano para que se aplique solo en sesiones desatendidas (-p, Agente SDK, CI, nube); Las sesiones de terminal, aplicación de escritorio y VS Code no tienen límite
  • Se cambió el clasificador de modo automático del lado opuesto cli para ignorar un pin ANTHROPIC_DEFAULT_SONNET_MODEL que nombra Claude Sonnet 5.5 u Opus 5.5 y usar Claude Sonnet 5 en su lugar.
  • Se cambió claude project purge a claude purge; el antiguo nombre todavía funciona e imprime un aviso
  • Se modificó el filtro n: de la vista de agentes (y la búsqueda Ctrl+F) para que Enter abra la sesión cuyo nombre coincida mejor en lugar de la fila superior.
  • Se modificó /autocompact para guardar la ventana autocompacta por modelo, de modo que cada modelo mantenga su propia configuración cuando cambia
  • Se cambiaron las indicaciones de URL de MCP de los servidores que no pueden informar cuando haya terminado para esperar a "Terminé, continuar" antes de que continúe la llamada de la herramienta, para que pueda terminar primero en el navegador.
  • [VSCode] Se corrigió un conector claude.ai que permanecía en "Necesita autenticación" después de autorizarlo: el cuadro de diálogo de servidores MCP ahora ofrece Verificar conexión
  • [VSCode] Se corrigió el acceso directo de nueva conversación (Cmd/Ctrl+N) que iniciaba una conversación en cada vista visible de Claude en lugar de solo en la que estás.
  • [VSCode] Se corrigió la vista de chat que reanudaba la siguiente sesión guardada después de archivar la que muestra; ahora comienza una nueva conversación
  • [Sesiones en la nube] Se corrigió que el interruptor de sesiones en la nube en la configuración de administración de Claude Code permaneciera bloqueado mientras se cargaba una configuración de seguridad no relacionada o no se cargaba.
  • [Sesiones en la nube] Se corrigió que presionar Detener mientras un corredor autohospedado aún estaba comenzando no cancelaba el mensaje en cola, que luego podría ejecutarse una vez que el corredor estuviera activo.
  • [Claude Tag] Se corrigió la configuración de administración de Claude Tag que ofrecía la opción "Eliminar este alcance", que siempre fallaba, en canales cuyas configuraciones se crearon automáticamente.
  • [Etiqueta de Claude] Se mejoró que Claude también siga un hilo de Slack relacionado en otro canal que solo lee, de modo que las actualizaciones lleguen a la conversación que depende de ellas.
  • [Claude Tag] Errores de guardado mejorados en la página Configurar de un canal: las instrucciones de canal demasiado largas ahora dicen que se deben acortar, y un guardado rechazado por pérdida de acceso ya no dice que se intente nuevamente
  • Se corrigieron los mods de informes claude plugin test que se apagaban de forma remota cuando solo había leído una configuración guardada desactualizada.
