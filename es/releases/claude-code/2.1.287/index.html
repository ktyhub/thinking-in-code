código-claude v2.1.287

¿Qué ha cambiado?

  • Se agregaron Claude Mods: los complementos ahora pueden modificar un comportamiento más profundo
  • Se agregó Deberías saber, un mod incorporado en el que un agente secundario te cuida las espaldas y señala cosas que tú o Claude podrían pasar por alto. Actívelo con /plugin enable cc-plugin-you-should-know@builtin (para sesiones propias con telemetría activada)
  • Se agregó un filtro n:<text> a la vista de agentes que coincide con los nombres de las sesiones y las tareas; un filtro ahora muestra coincidencias en secciones contraídas y Enter abre la primera coincidencia
  • Se agregó prompt_text al evento OpenTelemetry user_prompt, una copia de prompt para backends que anidan teclas de puntos; suéltelo o enmascúrelo dondequiera que deje caer o enmascare prompt (anthropics/claude-code#70763)
  • Se agregaron indicaciones de URL de los servidores MCP en el protocolo 2025-11-25, por ejemplo para iniciar sesión. Si un servidor ya no se conecta después de esta actualización, agregue "bareElicitationCapability": verdadero a su entrada de configuración de MCP
  • Windows: se agregó una advertencia de inicio cuando se niega la herramienta Bash y también se desactiva la herramienta PowerShell, por lo que Claude no tiene ninguna herramienta de shell.
  • Ejecutor autohospedado: se agregó un gh api integrado (solo REST) para sesiones que usan git administrado por Anthropic en máquinas macOS y Linux donde GitHub CLI no está instalado
  • Se corrigió que el modo rápido permaneciera apagado en sesiones remotas propiedad de un agente sin cuenta de usuario, incluso cuando la organización lo permite.
  • Se corrigió que el control remoto no recibiera mensajes durante minutos seguidos cuando una solicitud de reconexión no obtenía respuesta; ahora se da por vencido después de 30 segundos y lo vuelve a intentar
  • Se corrigieron los ganchos configurados con asyncRewake que despertaban a Claude una y otra vez con notificaciones de "problemas encontrados" cuando faltaba el archivo de script del gancho; el anzuelo roto ahora se informa una vez
  • Se corrigieron los latidos de la herramienta que no llegaban a los hosts SDK mientras el flujo de respuesta del modelo se detenía sin llegar datos.
  • Se corrigieron las comprobaciones del modelo de inicio de Bedrock y Vertex que ignoraban una lista obligatoria de availableModels, lo que podía colapsar /model en una fila de Opus.
  • Se corrigió el selector del navegador Claude en Chrome que mostraba un error de análisis JSON cuando no se podía acceder a Chrome.
  • Se corrigió la selección de Fable en /model al iniciar sesión en claude.ai guardando la identificación de la versión actual, por lo que su valor predeterminado guardado ahora sigue la Fable más nueva como lo hacen Opus y Sonnet.
  • Se corrigió el cambio entre Opus 5.5 y Sonnet 5.5 (/model, opusplan) que reescribía anuncios anteriores de la herramienta MCP, lo que podría eliminar el pensamiento extendido anterior.
  • Se corrigieron los bloques de Amazon Bedrock Guardrails que llegaban a mitad de respuesta y terminaban el turno con un error API en lugar del mensaje de la barandilla cuando la respuesta comenzaba con el pensamiento.
  • Se corrigió que un rm peligroso (como uno en / o el directorio de inicio) perdiera su protección de siempre preguntar cuando el mismo comando también redirigía la salida a un ~ o una ruta comodín.
  • Se corrigieron las sesiones claude -p y SDK que repetían un modelo alternativo en cada mensaje posterior después de que se cambiaba el modelo mientras se ejecutaba una respuesta.
  • Se corrigió que CLAUDE.md de una carpeta se adjuntara por segunda vez después de reanudar una sesión o después de una compactación.
  • Se corrigieron sesiones en segundo plano que no se podían volver a abrir desde claude agents después de que el agente saliera y eliminara el árbol de trabajo en el que se inició la sesión.
  • Se corrigieron las comprobaciones de emparejamiento de /advisor: Sonnet 5.5 ahora puede avisar a Opus 4.7 y 4.8, y los asesores que el API rechazaría se marcan desde el principio en lugar de eliminarse silenciosamente.
  • Se corrigieron los mensajes de permiso de Bash que mostraban nombres de analizadores internos como "Contiene expansión_simple" en lugar de una explicación simple.
  • Se corrigió una causa por la cual las sesiones de pantalla completa en máquinas lentas u ocupadas salían con "Claude Code salió después de un error de interfaz irrecuperable" mientras se mantenía presionada una tecla de desplazamiento en una conversación larga.
  • Se corrigieron los límites de permisos por herramienta de la organización que se eliminaban silenciosamente para una herramienta MCP llamada __proto__.
  • Se corrigió que a Claude se le dijera que paginara resultados de MCP grandes guardados como JSON con el desplazamiento y el límite de lectura, que no pueden dividir una línea larga.
  • Se corrigió el recordatorio de atribución de confirmación que se entregaba dentro del resultado de una herramienta después de una compactación.
  • Se corrigió el modo de lector de pantalla que dejaba el cursor alejado del texto escrito en los cuadros de búsqueda (como /resume y /permissions) y campos de código de inicio de sesión.
  • Se corrigió el modo de lector de pantalla que rechazaba ingresar sin escribir nada en las opciones de resumen de /rewind, cuyo contexto agregado es opcional.
  • Se corrigió el modo de lector de pantalla que mostraba una sugerencia de "Tab para modificar" en las solicitudes de aprobación, donde Tab no hace nada.
  • Se corrigió el modo de lector de pantalla que enumera las teclas de flecha que no hacen nada en /permissions y /mcp, y dice "Seleccionar con números" en menús vacíos o mientras un cuadro de búsqueda tiene las teclas
  • Se corrigió el modo de lector de pantalla que omitía las líneas modificadas en las solicitudes de aprobación de edición de archivos y otras diferencias.
  • Se corrigió el modo de lector de pantalla que envía la pantalla de progreso de claude --teleport y un campo de formulario MCP mientras se verifica al lector de pantalla nuevamente en cada cuadro giratorio.
  • Se corrigió que CLAUDE_CODE_DISABLE_EXPERIMENTAL_BETAS no eliminara el formato de salida estructurada de las solicitudes de título de sesión y enlace de aviso, que las puertas de enlace respaldadas por Bedrock rechazan.
  • Se corrigió el modo de lector de pantalla que omitía las líneas superiores de un segundo mensaje de aprobación, una fila /config modificada o la línea del plan rechazado cuando la pantalla anterior era más alta que la ventana del terminal.
  • Se corrigió que --include-partial-messages enviara una respuesta breve message_stop tarde o nunca, para que las aplicaciones pudieran mostrar la respuesta como aún en progreso.
  • Se corrigió que claude agents a veces no mostrara el mensaje de permiso que estaba esperando una sesión en segundo plano.
  • Se corrigió que /ultrareview brindara consejos sobre .git/info/attributes cuando la carga se detiene en un .gitattributes comprometido que no puede leer, como uno guardado como UTF-16.
  • Se corrigió que claude remote-control no pudiera registrarse detrás de un proxy HTTP con un error engañoso "Verifique los permisos de su organización" (anthropics/claude-code#97352)
  • Se corrigieron los comandos Bash sandbox en Linux que heredan un identificador abierto en el ejecutable de Claude Code.
  • Se corrigió el punto de la herramienta de ejecución y tres ruedas giratorias que aún se movían con la configuración "Reducir movimiento" activada y la pantalla de confirmación de /rebobinado actualizaba su tiempo "hace" mientras escribes una nota.
  • Los tiempos fijos en claude agents cambian cada segundo en el modo lector de pantalla; ahora cambian como máximo cada 10 segundos
  • Se corrigió un inicio de sesión revocado en claude.ai que mostraba un API Error: 401 genérico en lugar de "token OAuth revocado"; en el modo -p el error ahora comienza con "Error al autenticar"
  • Se corrigieron los rechazos de carga de /ultrareview que le aconsejaban copiar una variable nombrada por el archivo de configuración de un repositorio en su propia configuración de usuario.
  • Se corrigió que --output-format stream-json y SDK no transmitieran los turnos de una habilidad context: fork ejecutada al escribir /<skill> como mensaje, como lo hacen con la bifurcación de la herramienta Habilidad.
  • Se corrigieron /comentarios y /error: el problema GitHub precargado ya no incluye los mensajes de error recientes y la pantalla de confirmación ahora los enumera como parte del informe.
  • Se corrigió el error de instalación de los complementos claude plugin marketplace add --sparse y git-subdir con "transporte 'http' no permitido" cuando el repositorio se sirve a través de http simple.
  • Se corrigieron sesiones en la nube que a veces perdían la conversación anterior cuando la sesión se reiniciaba mientras se estaba compactando.
  • Se corrigió una recarga del complemento que se superponía a la descarga de inicio de --plugin-url y corrompía la copia en caché de la sesión del archivo del complemento.
  • Se corrigió que /desktop citara una salida parcial cuando se agotaba el tiempo de espera para abrir Claude Desktop o se imprimía demasiada salida; el error ahora nombra la causa
  • Se corrigió una llamada de la herramienta del conector MCP que ocasionalmente se ejecutaba dos veces, o que las llamadas del conector fallaban hasta que se reiniciaba, cuando su servidor cambiaba la versión del protocolo MCP que admite.
  • Se corrigieron los enlaces SessionStart de los complementos sincronizados que no se ejecutan en nuevas sesiones en la nube.
  • Se corrigió el resumen "N ganchos ejecutados" de la transcripción y el recuento detallado de ganchos coincidentes del registro de depuración, incluidas las devoluciones de llamadas internas de Claude Code, por lo que un gancho configurado ya no se muestra como dos.
  • Se corrigieron los archivos que Claude envía desde la nube y las sesiones de control remoto que fallaban cuando la carga finalizaba justo después del tiempo de espera de 30 segundos; ahora espera 35 segundos
  • Se corrigieron los repositorios agregados a mitad de sesión en la nube y las sesiones SDK que no cargaban sus habilidades y complementos, y cargaban CLAUDE.md tarde, después de que Claude cambiara de directorio.
  • Se corrigieron imágenes PNG, JPEG y WebP de más de 8000 píxeles en un lado que no se podían enviar desde una sesión remota; Claude envía ahora una copia reducida
  • Se corrigieron los mensajes enviados desde las aplicaciones de Claude con 17 a 20 archivos adjuntos que entregaban solo los primeros 16
  • Se corrigieron sesiones sin cabeza que informaban que un servidor MCP necesitaba autenticación después de una llamada rechazada, aunque las llamadas posteriores tuvieran éxito.
  • macOS: Se corrigieron las sesiones de control remoto que comenzaban con claude remote-control deteniéndose a mitad de turno cuando la Mac entraba en modo de suspensión inactiva.
  • Windows: Se corrigió que el claude interactivo se colgara o fallara con "El modo sin formato no es compatible" cuando su entrada se canaliza o redirige; ahora dice por qué y sale (use -p para entrada canalizada)
  • Bedrock, Vertex, Mantle: Se corrigieron las comprobaciones de disponibilidad del modelo en CLAUDE_CODE_SKIP_*_AUTH que enviaban un encabezado Authorization diferente al de las solicitudes reales cuando ANTHROPIC_CUSTOM_HEADERS lo repite.
  • /config mejorado: las configuraciones que muestran en ciclo ‹ › y avanzan en ambos sentidos con ←/→, los terminales estrechos apilan cada valor debajo de su etiqueta y PgUp/PgDn pagina la lista
  • Errores de mercado de complementos mejorados para decir en palabras sencillas por qué se ignoró o rechazó un mercado y qué hacer
  • Listados de complementos mejorados para observar cuando las dependencias de un complemento no estaban instaladas, y al actualizar un complemento ahora se reintenta una instalación que no finalizó
  • Se mejoró el error de la puerta de enlace de aplicaciones de Claude cuando Amazon Bedrock rechaza una ID de modelo: los desarrolladores ahora ven qué modelo no está disponible y el registro de la puerta de enlace nombra la ID que se envió.
  • Sesiones SDK mejoradas para que un mensaje enviado con prioridad "ahora" ya no cancele una búsqueda web en ejecución; sigue cargando en segundo plano
  • /memory mejorado: las teclas de flecha izquierda y derecha ahora activan/desactivan sus configuraciones, como la memoria automática
  • Nombres /skill mejorados escritos a mitad del mensaje: ahora se le dice a Claude que son habilidades, incluidas las disable-model-invocation.
  • Se mejoró el contraste del borde de entrada del mensaje en temas claros y del ❯ antes de los mensajes anteriores.
  • Entrega mejorada de archivos que Claude envía desde sesiones en la nube y control remoto: una carga que falla por tiempo de espera, un error de red o un 502, 503 o 504 ahora se reintenta una vez
  • Se mejoró lo que dice Claude cuando un archivo no se puede enviar por un motivo que puede ser temporal: ahora menciona que puedes volver a solicitar el archivo en unos minutos.
  • Se mejoró la solicitud de un mensaje retenido de otra sesión para mostrar el mensaje entre líneas discontinuas, coincidiendo con otras solicitudes de permiso
  • MCP mejorado y otras indicaciones de permisos de herramientas para mostrar la llamada de la herramienta entre líneas discontinuas, coincidiendo con las indicaciones de edición de archivos.
  • Inicio de MCP mejorado en modo sin cabeza: un servidor remoto cuya primera conexión falla transitoriamente ahora se reintenta sin esperar a que el servidor más lento termine de conectarse
  • Archivos mejorados que Claude envía desde una sesión remota: los archivos grandes ahora se transmiten desde el disco en lugar de leerse en la memoria, y un archivo que supera el límite de tamaño se rechaza con el límite del servidor denominado
  • Se mejoró la explicación que da Claude cuando el servidor rechaza un archivo que envía desde un control remoto o una sesión en la nube, como una imagen de gran tamaño.
  • Manejo mejorado de resultados de herramientas MCP de gran tamaño: menos memoria, archivos de sesión más pequeños y sin carga adicional para contar tokens para resultados muy por encima del límite
  • Windows: velocidad mejorada de la herramienta Bash al eliminar un subshell que se ejecutaba antes de cada comando
  • Se cambió una escritura de shell a través de un enlace simbólico confirmado por repositorio en un archivo confidencial o fuera del árbol de trabajo para nombrar dónde aterriza y esperar a una persona, en líneas con un objetivo ~ también.
  • Se modificó Opus 4.7+ y Fable para usar una ventana de contexto de 1M de forma predeterminada en Bedrock, Vertex, Foundry y la puerta de enlace de aplicaciones Claude, sin el sufijo [1m] (CLAUDE_CODE_DISABLE_1M_CONTEXT=1 mantiene 200K).
  • Se cambiaron las respuestas de claude agents para que lleguen como mensajes en cola; Los comandos de barra diagonal distintos de /stop enviados mientras se ejecuta un turno ahora se ejecutan cuando termina
  • Se cambiaron las reglas de permiso de toda la herramienta Bash y los ganchos que permiten solicitar, no ejecutar, escrituras de shell en archivos que las herramientas de archivos de Claude Code rechazan por completo (el almacén de perfiles Anthropic, el archivo de credenciales del host)
  • Se cambió el pegado derecho-click en Windows y Linux, y el pegado medio-click en Linux, para que suceda cuando se suelta el botón; alejar el puntero antes de soltarlo lo cancela
  • Se cambió el servidor MCP alwaysLoad: false para posponer todas las herramientas de ese servidor detrás de la búsqueda de herramientas.
  • Se cambió el modo de lector de pantalla para escribir líneas nuevas o modificadas sin pausar primero con el cursor al comienzo de la línea; configure CLAUDE_AX_PREPARK_MS=50 para restaurar la pausa
  • Se cambiaron los cambios automáticos de modelo después de un mensaje marcado para mantener su nivel de esfuerzo actual en lugar del predeterminado del nuevo modelo.
  • Se cambiaron las indicaciones de permiso de espera para mostrar las más antiguas primero, por lo que una nueva solicitud ya no cubre la que estás leyendo (las indicaciones con una cuenta regresiva aún están abiertas en la parte superior)
  • [VSCode] Se agregó "Ejecutar en segundo plano" a un comando o subagente en ejecución, para moverlo al fondo y seguir trabajando.
  • [VSCode] Se agregó la salida de shells y monitores en segundo plano a sus tarjetas en el mapa del agente.
  • [VSCode] Se corrigieron los cuadros de diálogo de configuración que culpaban al tiempo de espera cuando la respuesta de Claude Code era demasiado larga para confirmar un guardado.
  • [VSCode] Se corrigió la reapertura de una sesión en la nube que la barra lateral ya traía a esta máquina abriéndola nuevamente en una nueva pestaña; en su lugar se muestra la barra lateral
  • [VSCode] Se corrigió que la pestaña Web de la barra lateral no enumerara las sesiones en la nube iniciadas después de cargar la ventana; una carga fallida ahora dice "El servidor remoto no está conectado" en lugar de "Aún no hay sesiones web"
  • [VSCode] Se corrigió una pestaña restaurada después de una recarga que iniciaba un segundo proceso de Claude en una conversación que la barra lateral ya tenía abierta; ahora muestra el aviso "aún abierto en otro lugar"
  • [VSCode] Se corrigieron los enlaces de archivos de fila de herramientas, enlaces de lista de sesiones y dos sugerencias que se muestran en texto sin formato.
  • [VSCode] Se corrigió que el comando aún en ejecución de un agente en segundo plano se mostrara como fallido una vez que finalizaba el turno principal.
  • [VSCode] Se corrigió el comando /usage o /context del usuario que abría el cuadro de diálogo de la extensión en lugar de ejecutarse cuando se seleccionaba desde el menú de comandos.
  • [VSCode] Se corrigieron los enlaces de archivos en la pestaña de vista previa del plan que no hacían nada cuando clicked; Ahora abren el archivo como enlaces en las respuestas del chat.
  • [VSCode] Se corrigió el error al abrir la entrada o salida de una herramienta en una pestaña del editor con "Tiempo de espera de espera después de 1000 ms" en hosts remotos como WSL cuando la pestaña tarda en aparecer.
  • [VSCode] Se mejoró el cuadro de diálogo Administrar complementos: una falla al agregar, eliminar o actualizar el mercado ahora dice qué salió mal
  • [VSCode] Se cambió el interruptor "Habilitado de forma predeterminada" de Claude en Chrome para conectar también las sesiones propias del editor, que aún preguntan antes de las acciones del navegador.
  • [Sesiones en la nube] Se corrigieron fallas ocasionales al recuperar o enviar a GitHub cuando GitHub rechazó brevemente un token de acceso recién emitido.
  • [Etiqueta de Claude] Se corrigió que Claude publicara una advertencia de falla, como un aviso de límite de gasto, en un hilo de Slack cuando un evento en segundo plano como la actividad GitHub lo despertaba y nadie estaba esperando una respuesta.
  • [Claude Tag] Se corrigió la página de límites de gasto de Claude Tag en la configuración de administración, dejando de lado los canales privados y creados recientemente en organizaciones con muchos canales.
  • [Etiqueta de Claude] Se mejoró la lista de tareas de Claude en hilos largos de Slack: el trabajo en segundo plano ya no se vuelve a publicar como un mensaje nuevo por sí solo, por lo que las personas que siguen el hilo no reciben notificaciones.
  • [Revisión de código] Se corrigieron los comentarios de búsqueda y el texto "Por qué se marcó esto" que se detenía a mitad de la oración; ahora terminan en una oración completa
  • [Revisión de código] Se corrigió que la revisión de código omitiera una solicitud de extracción después de un nuevo envío cuando su revisión había fallado dos veces en la confirmación anterior; ahora revisa el último compromiso
  • [Revisión de código] Se mejoró la tarjeta de revisión fallida en una solicitud de extracción cuya conversación está bloqueada: ahora dice que el bloqueo bloqueó la revisión y que no se publicó ni se cobró nada.
