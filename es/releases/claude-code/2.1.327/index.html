¿Qué ha cambiado?

  • Se agregó una confirmación antes de que /install-github-app cambie un repositorio.
  • Se agregó claude mcp add-json <name> - para leer el JSON del servidor desde la entrada estándar, de modo que los tokens puedan permanecer fuera de la línea de comando; no disponible dentro de una sesión de Claude Code

  • Se cambió el primer subagente de un modelo para que espere hasta 1.5 segundos (10 en claude -p) para la configuración de ese modelo desde Anthropic, en lugar de comenzar sin ellos.
  • Se cambiaron los subagentes en segundo plano reiniciados y los giros que se inician solos para esperar a que se carguen los complementos.
  • Se modificó el historial de mensajes para omitir la mayoría de los mensajes de inicio de sesiones iniciadas por otra sesión de Claude Code, como claude --bg ejecutada por Claude.
  • Se modificaron los resúmenes de progreso de los subagentes en las sesiones de terminal en Amazon Bedrock, Google Vertex AI y Microsoft Foundry para que se escriban a partir de notas breves, no de toda la conversación, utilizando muchos menos tokens.
  • Se cambió el modo no interactivo (-p) para ejecutar menos comandos de git antes de la primera solicitud.
  • Se modificó la configuración de primera ejecución para omitir la configuración del terminal en sesiones remotas de VS Code, Cursor y Devin Desktop, donde no se puede cambiar la configuración.
  • Se cambió la selección de texto en pantalla completa para omitir el glifo de sistema, pensamiento y líneas de mensajes entrantes.
  • Se cambiaron las sesiones en la nube alojadas en Anthropic para ignorar más configuraciones de entrega de complementos y banderas de un repositorio; su CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC ahora actúa como máximo como DISABLE_TELEMETRY
  • [VSCode] Se agregó "Claude Code: Agregar al chat" al menú derecho-click del Explorador, que @-menciona los archivos y carpetas seleccionados en el chat.
  • [VSCode] Se corrigió el mensaje de permiso que no muestra el motivo que da un gancho PreToolUse cuando solicita confirmación (anthropics/claude-code#85950)
  • [VSCode] Se corrigieron los nombres largos de herramientas y archivos que se cortaban en el título de una solicitud de permiso.
  • [VSCode] Se corrigió la diferencia de una sesión de terminal que mostraba la edición propuesta anterior después de que la escribiste y Claude editó el mismo archivo nuevamente.
  • [VSCode] Se corrigió que Escape también detuviera la respuesta de Claude cuando cerraba el cuadro de diálogo de comentarios o "Crear un estilo personalizado", el menú de mención @, el modelo, modo o menú "+", u otra ventana emergente.
  • [VSCode] Velocidad mejorada cuando Claude realiza varias ediciones seguidas: las ediciones en cola comparten una espera para nuevos problemas; Es posible que se informe de un problema en una edición posterior.
  • [VSCode] Velocidad de búsqueda de archivos @-mention mejorada en espacios de trabajo grandes cuando rg está en su PATH; Los resultados ahora se clasifican de forma muy parecida a la del terminal, con menos tolerancia a los errores tipográficos.
  • [VSCode] Inicio mejorado: el selector de modelo está listo de inmediato en las carpetas abiertas por primera vez, ventanas vacías y árboles de trabajo, excepto en proveedores de terceros
  • [VSCode] Se cambió la diferencia de una edición de chat para permanecer abierta y seguir solicitando aprobación cuando una sesión de terminal en la misma ventana envía un mensaje.
  • [VSCode] Se eliminaron las herramientas no utilizadas de la conexión IDE (openFile, saveDocument, getOpenEditors y relacionadas)
