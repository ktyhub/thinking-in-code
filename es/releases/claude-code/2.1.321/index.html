claude-code v2.1.321

código-claude v2.1.321

¿Qué ha cambiado?

  • Se agregó Claude Fable 5.2 (claude-fable-5-2), ahora el modelo predeterminado de Fable: contexto de 1 millón, $8/$40 por Mtok con lecturas de caché de $0.20/Mtok.
  • Se agregó --settings <file> a claude remote-control, que aplica un archivo de configuración a cada sesión que inicia; si el archivo cambia, no se inicia ninguna nueva sesión hasta que reinicie claude remote-control
  • Se corrigieron las solicitudes de MCP OAuth que enviaban secretos, como tokens de actualización, a otro host cuando un servidor los redirigía.
  • Se corrigió un caso en el que un comando Bash de solo lectura se ejecutaba fuera del sandbox sin una solicitud de permiso.
  • Se corrigió un caso en el que las comprobaciones de permisos de Bash juzgaban que un archivo se había escrito desde la carpeta incorrecta y no aparecían.
  • Se corrigieron las reglas de denegación y los mensajes de archivos protegidos que no se aplicaban al archivo que escribe un cp o mv en un directorio.
  • Se corrigió la nota "Retiros de créditos de uso" que se mostraba después de cambiar a Fable en asientos Enterprise cuyo plan incluye Fable.
  • Se corrigió el modelo alternativo que a veces declinizaba una solicitud o mencionaba una respuesta detenida cuando el primer modelo estaba bloqueado antes de responder.
  • Se corrigió que claude mcp login imprimiera una advertencia del emisor SEP-2352 cada vez que inicias sesión nuevamente en un servidor en el que Claude Code se registró.
  • Se corrigió que NotebookEdit eliminara o sobrescribiera la primera celda de una computadora portátil cuando la llamada no nombraba ninguna celda, en rutas de red (compartimientos UNC, carpetas WSL, montajes /net)
  • Se corrigió la edición cambiando la primera de varias coincidencias, reemplazando un archivo completo en un old_string vacío o editando un cuaderno como texto, en rutas de red (compartimientos UNC, carpetas WSL, montajes /net)
  • Se corrigió /config que mostraba Manual como el modo de permiso predeterminado cuando se inician nuevas sesiones en modo automático; Al presionar Espacio en "Automático (predeterminado)" ahora se guarda No preguntar, no Planificar
  • Windows: Se corrigieron los ganchos FileChanged que se detenían en las rutas establecidas a través de watchPaths después del primer comando de shell, cuando el directorio de trabajo de la sesión tenía una letra de unidad en minúscula.
  • Se corrigió que --plugin-dir . y --plugin-dir ./builtin escribieran archivos de tipos generados para los complementos integrados de Claude Code en una carpeta builtin.
  • Se corrigió el uso del contexto que estima el exceso de definiciones de herramientas cuando los recuentos exactos de tokens no están disponibles.
  • Se corrigió que /compact se mostrara dos veces en Control remoto en la web y en dispositivos móviles.
  • Se corrigieron las actualizaciones automáticas de complementos y las actualizaciones del mercado /plugin que descargaban un complemento nuevamente para cada árbol de trabajo o carpeta de un repositorio.
  • Se corrigió que el modo automático perdiera el informe de un subagente en segundo plano que había iniciado un turno cuando la conversación se compactaba antes de que Claude la respondiera.
  • Se corrigieron las habilidades, comandos y agentes del proyecto que permanecían perdidos después de que su carpeta fuera eliminada y volviera a mitad de la sesión, como con git stash, incluso después de ingresar a un árbol de trabajo.
  • Se corrigió que claude -p a veces le dijera a Claude que los comandos en segundo plano duran 30 minutos cuando se detienen después de 10.
  • Se corrigieron pkill, pgrep y pidwait en sesiones en la nube que coincidían con los procesos principales de la sesión.
  • Se corrigió que Claude en Chrome y los procesos del servidor de uso de la computadora permanecieran activos después de que su padre saliera detrás de un proxy que detiene las conexiones.
  • Se corrigió una salida de gancho grande que apuntaba a Claude a un archivo que contenía la salida de otro gancho de la misma llamada de herramienta.
  • Se corrigieron las aplicaciones que incrustan Claude Code obteniendo su propio motivo ask del gancho PreToolUse en lugar de otro gancho cuando ambos preguntaban.
  • Se corrigió que el ask de un gancho PreToolUse se perdiera cuando el defer de otro gancho terminaba primero y no podía ser respetado.
  • Se corrigió un fallo poco frecuente en solicitudes de permiso y tareas en segundo plano.
  • Se corrigieron las habilidades, comandos y agentes del proyecto que desaparecían del menú en SDK y de las sesiones de escritorio después de que Claude ingresara a un árbol de trabajo.
  • Se corrigió /desktop en macOS que decía que Claude Desktop no está instalado cuando está en ~/Applications.
  • Se corrigieron los atributos del repositorio OpenTelemetry (vcs.*) que faltaban en las sesiones de Claude Desktop que se inician en un proceso iniciado previamente.
  • Se corrigió que WebFetch pasara "Sin respuesta del modelo" a Claude como contenido de la página cuando el modelo que leía la página no devolvía texto; la llamada ahora falla con un error claro
  • Se corrigió el modo de lector de pantalla que retrasaba el mensaje al inicio cuando el reloj del sistema retrocedía mientras se iniciaba Claude Code.
  • Se corrigió que el panel de un comando a veces no regresara después de cerrar un cuadro de diálogo, sin dejar ningún panel o mensaje en la pantalla hasta el próximo rediseño.
  • Se corrigió que el servidor MCP de un proyecto se desconectara después del primer mensaje en una sesión de la pestaña Claude Desktop Code cuando la aplicación de escritorio tiene un servidor MCP o una extensión del mismo nombre.
  • Se corrigió un turno que terminaba con "Error API: EPROTO: Falló el protocolo de enlace TLS" cuando la conexión se interrumpía a mitad de una respuesta; se mantiene la respuesta parcial o se vuelve a intentar la solicitud, como antes 2.1.302
  • Se corrigió el uso elevado de memoria en sesiones largas que leían repetidamente líneas individuales de archivos grandes
  • Se corrigió el modo rápido que perdía respuestas, cambiaba de modelo o reintentaba durante minutos cuando el servicio rápido tenía una velocidad limitada, estaba sobrecargado o fallaba; Ahora prueba primero la velocidad estándar en el mismo modelo.
  • Se corrigió una solicitud que contenía muchos más informes de agentes en segundo plano de los previstos después de que Claude fuera detenido mientras varios estaban esperando.
  • Se corrigieron los mensajes de una sesión de la pestaña Código de escritorio de Claude a sus otras sesiones que permanecían en pausa después de escribir mientras Claude todavía estaba trabajando.
  • Se corrigió que claude agents ignorara --permission-mode, --dangerously-skip-permissions, --model, --effort o --agent escritos antes de agents cuando un indicador como --verbose también estaba en la línea.
  • Se corrigió un caso en el que el control remoto aparecía apagado con "inicio de sesión caducado" en la aplicación de escritorio mientras su conexión aún estaba activa, porque la aplicación no pudo entregar brevemente un token de inicio de sesión.
  • Se corrigió un mensaje de control remoto enviado con "Cola para más tarde" que llegaba a Claude en medio del turno de carrera.
  • Se corrigió el estado de git dado a Claude al inicio de la sesión leyendo como limpio cuando el estado de git fallaba; ahora se lee como no disponible
  • Se corrigió el estado de git otorgado a Claude al inicio de la sesión, mostrando el primer archivo listado como preparado cuando sus cambios no estaban preparados.
  • Se corrigió un bloqueo o falla por falta de memoria cuando un conector en una sesión en la nube enumera recursos con nombres muy largos.
  • Se corrigió que el control remoto se mostrara como conectado después de que su conexión se cerrara definitivamente mientras el historial de la sesión aún se estaba cargando.
  • Se corrigió que el modo de lector de pantalla se apagara cuando regresas a una conversación desde la vista del agente.
  • Se corrigió el modo de lector de pantalla y/n en las preguntas que tomaban como sí una "y" perdida al final del texto escrito cuando se abría la pregunta.
  • Se corrigieron las sesiones en la nube que le decían a Claude que un host probablemente no esté permitido cuando sí está permitido y que el proxy de la red no pudo conectarse a él.
  • Se corrigió que un servidor MCP a veces apareciera como conectado sin herramientas después de volver a conectarse o que el directorio de la sesión cambiara mientras sus herramientas aún se estaban cargando.
  • Se corrigieron los comandos de Bash que a veces se ejecutaban en la carpeta incorrecta cuando Claude enviaba varios a la vez y uno anterior cambiaba de carpeta.
  • Se corrigieron los archivos que Claude envía desde la nube y las sesiones de control remoto fallaban al mismo tiempo cuando una carga obtenía un HTTP 507 de un proxy; la carga ahora tiene un segundo intento
  • Se corrigieron mensajes nuevos que no se guardaban y que las sesiones de claude -p, SDK y VS Code se bloqueaban cuando se agotaba la memoria mientras se leía la transcripción.
  • Se corrigió el inicio de sesión, la actualización del token y el cierre de sesión esperando indefinidamente cuando algo en la red acepta la conexión pero nunca responde al protocolo de enlace TLS.
  • Se corrigió un archivo enviado que se mostraba con un nombre diferente en las aplicaciones de Claude cuando su nombre ocultaba la dirección del texto o los caracteres de control; Claude ahora se niega a enviar dicho archivo.
  • Se corrigieron los resúmenes de progreso de los subagentes que ejecutaban una solicitud hasta su final después de que el modelo respondiera con una llamada de herramienta.
  • Se corrigieron lecturas de Bash como grep -r foo "$PWD/src" pidiendo permiso cuando el mismo comando con la ruta escrita se ejecuta sin preguntar
  • Se corrigió que la puerta de enlace de aplicaciones de Claude se negara a iniciarse cuando una configuración desktop contiene un campo más nuevo que la puerta de enlace, como el oauth.omitResource de un servidor MCP administrado; ahora avisa y lo sirve
  • Se corrigieron los comandos Bash que regresaban vacíos para los usuarios de zsh cuyo .zshrc configura KSH_OPTION_PRINT.
  • macOS: se corrigió "No se pueden leer las configuraciones de políticas administradas" al inicio cuando un perfil MDM válido tardaba en leerse: la lectura se reintenta una vez y un tiempo de espera ahora se informa como tiempo de espera
  • Se corrigió que la vista del agente borrara el texto de entrada guardado de otra vista del agente cuando se reiniciaba para una actualización sin escribir nada.
  • Se corrigieron sesiones remotas que no daban respuesta después de un reinicio cuando un gancho UserPromptSubmit bloqueaba una respuesta de permiso reproducida; Estos ganchos ya no se ejecutan en esa repetición.
  • Se corrigió que claude remote-control aceptara un y escrito sin Enter en su pregunta de primera ejecución cuando finalizó la entrada del terminal.
  • Se corrigió que Claude Desktop no mostrara advertencias de límite de gasto detrás de una puerta de enlace de aplicaciones de Claude cuya política no tiene reglas code:.
  • Se corrigieron sesiones de pantalla completa con algunos complementos que terminaban con un error cuando el resultado de una herramienta que se había acortado se desplazaba fuera de la parte superior de la pantalla.
  • Se corrigieron las sugerencias de mensajes que hacían solicitudes API adicionales cuando el modelo respondía con una llamada de herramienta.
  • Se corrigieron los enlaces PreToolUse mcp_tool en servidores stdio y HTTP MCP que se omitían cuando su respuesta superaba los 16 MiB; la llamada a la herramienta ahora es rechazada
  • Se corrigieron los nombres de habilidades y comandos que contienen una letra Bamum que algunas fuentes dibujan en blanco: ahora se rechazan.
  • Se corrigió que claude -p en Linux saliera de 0 en silencio cuando una exportación NFS completa o una cuota NFS agotada perdía líneas de transcripción: ahora imprime un error y, en texto y salida json, sale 1
  • Se corrigió que los agentes en segundo plano fueran reportados como detenidos por el usuario y rechazaban una reanudación cuando un servicio interrumpía una sesión en la nube y nadie presionaba Detener.
  • Se corrigió que NotebookEdit informara el éxito de los enlaces y la telemetría cuando fallaba la edición, por ejemplo, cuando el cuaderno cambiaba mientras la solicitud de permiso estaba abierta.
  • Se corrigió una pantalla en blanco o ninguna respuesta al inicio, y una salida claude mcp list vacía, cuando un registro de inicio de sesión de MCP almacenado era nulo
  • Se corrigió la herramienta Artefacto que le decía a Claude que agregara filtros cuando la colección de la base de datos de un artefacto es demasiado grande para ordenarla; ahora dice leer la colección página por página y ordenar los resultados
  • Se corrigió una sesión en la nube reiniciada que arrojaba un mensaje con una imagen grande cuando el reinicio se produjo antes de la primera respuesta de Claude.
  • Se corrigió una sesión en la nube reiniciada que dejaba sin respuesta el mensaje de un subagente en la conversación principal.
  • Se corrigió que a Claude no se le dijera cuando detenías o pausabas un flujo de trabajo en ejecución, por lo que ya no dice que el flujo de trabajo aún se está ejecutando.
  • Se mejoró el selector /model: "Más modelos" ahora es una fila sin numerar debajo de la otra, y los modelos más antiguos se abren debajo sin volver a numerar el resto.
  • Puerta de enlace: límites de gasto mejorados en una réplica ocupada, que ahora omite menos comprobaciones y registra el gasto antes
  • Se mejoraron los mensajes de límite de inicio de sesión de la puerta de enlace de aplicaciones de Claude en Claude Code y en la página /device: ya no nombran la configuración de la puerta de enlace, que el propio registro de la puerta de enlace todavía nombra
  • claude install y scripts de instalación mejorados: finalizan de 2 a 4 segundos antes
  • Se mejoró la rapidez con la que una sesión de Control remoto cuyo proceso falló puede recibir un nuevo mensaje.
  • Windows: inicio mejorado y tiempo del primer comando al encontrar programas en PATH sin iniciar un proceso auxiliar
  • Modo automático mejorado en sesiones sin cabeza, la aplicación de escritorio y VS Code: los informes de los subagentes en segundo plano que esperan juntos se responden en una llamada de modelo, como en la terminal
  • Se mejoró la fila de la vista del agente para una sesión claude --bg --worktree que no pudo configurar su árbol de trabajo: ahora muestra el error desde el principio, no una etiqueta interna ni sus últimos 200 caracteres.
  • Se mejoraron los mensajes que se muestran cuando un artefacto está en otra organización: /login se ofrece solo si es uno suyo, y Claude ahora dice dónde puede estar una copia después de mover una cuenta.
  • Sesiones mejoradas con más imágenes de las que caben en una solicitud: se le dice a Claude si ya ha visto una imagen eliminada y las lecturas repetidas de una imagen sin cambios son limitadas.
  • Se mejoraron los mensajes de claude remote-control para una pregunta de primera ejecución sin respuesta: ahora cada uno dice qué hacer a continuación.
  • Tiempo de inicio mejorado al cargar los certificados TLS trusted más rápido
  • Se mejoraron los mensajes de error de la puerta de enlace de aplicaciones Claude para mostrar la dirección de la puerta de enlace sin ningún nombre de usuario ni contraseña.
  • Se mejoró el error de límite de gasto de la puerta de enlace de aplicaciones de Claude: el restablecimiento ahora se muestra en su hora local, como "se reinicia a las 4 p.m. (América/Los_Angeles)"
  • Windows: tiempo de inicio mejorado con una instalación estándar de Git para Windows al no verificar qué git.exe ejecutar en cada inicio
  • Se actualizó el mensaje de comentarios de la sesión y la descripción de la configuración allowedProviders para nombrar Ultra junto con Pro y Max, y la descripción forceLoginMethod para cubrir todos los planes pagos de Claude.
  • Se actualizó la habilidad de visualización de datos incluida para sugerir una lista de metros, una fila por elemento, para varias proporciones, cada una de las cuales tiene su propio límite.
  • Se actualizaron las opciones de "Actualizar a Max" para que digan "Actualizar a Max o Ultra".
  • Modificaciones modificadas que Claude escribe para encender sin preguntar en los modos automático y bypass, incluso con allowUnsandboxedCommands: false o allowManagedDomainsOnly administrados, y no para cargar en modo dontAsk
  • Se cambiaron las llamadas de herramientas propias de los mods ($.tool.call, $.mcp.call) para que no generen ningún mensaje de permiso, incluso bajo sus propias reglas de solicitud o en ejecuciones de dontAsk y -p; Las reglas de denegación y la política de la organización aún se aplican.
  • Se cambiaron las selecciones de modelos guardadas de Fable 5.1 para pasar a fable: en los planes Pro y Max a la vez, en los planes Team y Enterprise una vez que su organización lo permita; use /model claude-fable-5-1 para volver
  • Se cambiaron las etiquetas del modo rápido en /fast, /config y /model para nombrar su modelo actual cuando admite el modo rápido y se eliminó "(solo Opus)" de la fila de Código VS.
  • Se modificó la carga de habilidades anidadas: las carpetas .claude/skills dentro de ~/.claude/plugins ya no se cargan cuando Claude trabaja en archivos allí
  • Ejecutor autohospedado: se cambió un ejecutor bajo demanda que el servidor rechaza porque no es necesario (sesión finalizada o pausada, orden de trabajo reemplazada) para salir 0 en lugar de 1.
  • Windows: se modificó la forma en que Claude Code encuentra programas que inicia él mismo, como git, para omitir entradas y enlaces relativos y UNC PATH en un recurso compartido de red, y para recoger los cambios de PATH desde la configuración.
  • Se cambiaron los eventos de enlace OpenTelemetry en sesiones no interactivas para dejar dos enlaces integrados fuera de num_hooks y num_success después de las llamadas a Bash y PowerShell.
  • Se modificó la cantidad de mensajes que una sesión de la pestaña Claude Desktop Code puede enviar a sus otras sesiones antes de esperar a que escriba nuevamente de 10 a 20.
  • Se modificó AskUserQuestion en las sesiones claude -p y SDK para denegar la respuesta de permiso del host que establece el campo de entrada afkTimeoutMs no documentado.
  • extraKnownMarketplaces administrado modificado: no se puede agregar un nombre declarado desde otra fuente, una entrada de otro lugar está oculta y los complementos que las listas del mercado declarado se reinstalan desde allí.
  • Se cambiaron las herramientas de Claude en Chrome que proporciona una aplicación que ejecuta Claude Code, como la pestaña Código de la aplicación de escritorio Claude, para seguir la política de Claude en Chrome de su organización.
  • Se modificó policy_mode: layered en la puerta de enlace de aplicaciones de Claude: los servidores MCP administrados ahora se suman sobre cada política coincidente, incluido match: {}, por lo que una puerta de enlace que ya está disponible sirve más después de la actualización.
  • Puerta de enlace: Se cambiaron los canales ascendentes de Bedrock, Vertex y Foundry para ignorar las variables ANTHROPIC_*_BASE_URL en el entorno de la puerta de enlace. Configure base_url en el sentido ascendente para usar otro punto final
  • Se cambiaron las sesiones sin cabeza para recargar mods en .claude/skills cuando sus archivos cambian; configure CLAUDE_CODE_PLUGIN_DIR_WATCH=0 para desactivar esto
  • Se cambió la oración del Programa de Verificación Cibernética en un bloque de salvaguarda cibernética para usar las mismas palabras que claude.ai.
  • Sesiones de nube de Cowork modificadas: un enlace PostToolUse ya no puede reemplazar la respuesta a AskUserQuestion o el plan en el resultado de ExitPlanMode; Claude lee los originales.
  • Se cambiaron cp y mv escritos por una ruta, como /bin/cp, para obtener las mismas comprobaciones de ruta que cp y mv.
  • Se cambiaron las notificaciones de comandos en segundo plano y los resultados de TaskStop para mostrarle a Claude solo el inicio y el final de un comando de más de 1000 caracteres, lo que ahorra contexto.
  • Se modificó la guía de diseño de artefactos para tratar a Inter y Space Grotesk como buenos tipos de letra predeterminados.
  • Se cambió la verificación de correo electrónico de la cuenta para rechazar solo un comando de shell que contiene su correo electrónico y nombra un agente de usuario, sin preguntar, de modo que otros comandos y ejecuciones programadas ya no se detengan cuando se le solicite.
  • Se cambiaron las sesiones de control remoto para mantener la carpeta en la que se iniciaron: un client conectado ya no puede mover una sesión a otra carpeta
  • Se modificaron las adquisiciones gestionadas de extraKnownMarketplaces de una fuente no declarada: los datos guardados se reservan para cleanupPeriodDays y las opciones y secretos hasta claude plugin restore-set-aside.
  • [VSCode] Se agregó una advertencia encima del cuadro de aviso cuando se configuran tanto un token de autenticación como una clave API, que coincide con la advertencia de inicio del terminal.
  • [VSCode] Se corrigió la solicitud de permiso de un complemento que mostraba un nombre con caracteres ocultos: ahora dice "un complemento"
