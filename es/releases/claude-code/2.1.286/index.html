claude-code v2.1.286

código-claude v2.1.286

¿Qué ha cambiado?

  • Se agregó un recuento como "2 de 5" a la solicitud de permiso cuando se acumulan varias solicitudes de permiso.
  • Se agregó compatibilidad con el mouse para las filas "N más" de listas en modo de pantalla completa: click uno para saltar a ese final de la lista, con estados de desplazamiento y presionado
  • Se corrigieron varios procesos de Claude Code y extensiones IDE, cada uno de los cuales abría un navegador de inicio de sesión cuando caducaban las credenciales de gcpAuthRefresh o awsAuthRefresh.
  • Se corrigió que claude --resume y --continue a veces perdieran cada turno después de un lote de llamadas de herramientas paralelas cuando la sesión anterior fallaba o se cancelaba.
  • Se corrigieron errores API 400 después de que una herramienta o gancho devolviera un objeto, número o valor booleano en lugar de texto, incluso en sesiones reanudadas.
  • Se corrigieron sesiones en la nube con historiales muy grandes que nunca se activaban porque el contenedor se detenía mientras la transcripción aún se estaba cargando.
  • Se corrigió el precio del medidor de gasto de la puerta de enlace de aplicaciones de Claude, escrituras de caché de aviso de 1 hora a la tarifa más económica de 5 minutos y contando solo los tokens de entrada de la primera llamada del modelo en turnos transmitidos que ejecutan una herramienta del lado del servidor, como la búsqueda web.
  • Se corrigió que las sesiones de macOS aún mostraran "No iniciado sesión" o "El inicio de sesión expiró" después de que /login tuviera éxito en otra ventana de Claude Code cuando existe un ~/.claude/.credentials.json sobrante.
  • Se corrigió que cada turno fallara cuando el Anthropic API rechaza el modelo predeterminado o un alias de modelo al que se resuelve: Claude Code ahora reintenta una vez en el modelo anterior del mismo nivel.
  • Se corrigió que las sesiones de Control remoto (incluido claude remote-control) permanecieran conectadas después de que la política de su organización desactivara el Control remoto; ahora se desconectan con un aviso
  • Se corrigió el rechazo y los reintentos --fallback-model que fallaban cuando el modelo alternativo no podía ejecutarse rápidamente; ahora funcionan a velocidad estándar, con un aviso único en sesiones interactivas
  • Se corrigieron las sesiones sin cabeza que repetían el recordatorio "Los servidores MCP requieren autenticación" después de una reautenticación exitosa cuando el caché de descubrimiento de MCP está habilitado.
  • Se corrigió que claude auth status informara que la clave API almacenada de un inicio de sesión en la consola era claude.ai; ahora informa api_key y la extensión VS Code trata esa sesión como una sesión clave API
  • Se corrigió que /status incluyera un perfil antrópico al lado de una clave API como si ambos estuvieran vigentes; el perfil ahora está marcado como no en uso
  • Se corrigió que a Claude no se le avisara cuando un archivo adjunto a un mensaje enviado a través de Control remoto no llegaba, y a veces un archivo tardaba solo 10 segundos en su último intento de descarga.
  • Se corrigió un mensaje de control remoto que llegaba mientras Claude Code salía y se marcaba como entregado y luego nunca respondía; ahora permanece en cola para la próxima ejecución de la sesión
  • Se corrigieron mensajes de error de MCP que mostraban el valor de una credencial cuando "Portador" o "Básico" venían antes de su nombre de clave.
  • Se corrigió que los tokens portadores codificados por porcentaje estuvieran solo parcialmente enmascarados en los mensajes de error.
  • Se corrigieron registros y transcripciones redactados que mostraban un secreto cuyo nombre clave tenía un carácter invisible en su interior, como un espacio de ancho cero.
  • Se corrigieron registros y transcripciones que mostraban parte de una contraseña de URL que contiene puntuación como ), comillas, ], & o un segundo @, o que pasa de un / a un host entre corchetes como [::1] en una URL ssh.
  • Se corrigió la transcripción de la sesión en el zip que /feedback guarda en el disco y que contenía líneas JSON no válidas después de la redacción secreta.
  • Se corrigieron los conectores MCP que no mostraban herramientas hasta un día después de que su servidor eliminara el protocolo de enlace MCP anterior.
  • Se corrigió una solicitud repetida de inicio de sesión de MCP por parte de Claude que reemplazaba el enlace de inicio de sesión pendiente, lo que podía impedir que ese enlace funcionara.
  • Se corrigió que /usage no acreditara a un servidor MCP por una llamada de herramienta realizada mientras ese servidor aún se estaba conectando o acababa de conectarse, como justo después de un reinicio.
  • Se corrigieron los complementos habilitados en claude.ai que ocasionalmente desaparecían de Claude Code para una sesión después de un error transitorio del servidor.
  • Se corrigió un mensaje escrito en un subagente en ejecución que se mostraba dos veces en su transcripción después de que el subagente lo leyera.
  • Se corrigieron los mensajes de devolución del subagente que mostraban una identificación de tarea sin procesar en lugar del nombre del agente cuando el subagente no tenía un nombre registrado.
  • Se corrigió que a los subagentes en primer plano a veces les faltaran las herramientas de seguimiento de tareas (TaskCreate/Get/Update/List, TodoWrite) en sesiones que las tienen habilitadas.
  • Se corrigieron los subagentes generados con el aislamiento del árbol de trabajo al cargar el proyecto CLAUDE.md y sus importaciones por segunda vez desde la copia del árbol de trabajo en su primera lectura del archivo.
  • Se corrigió que los subagentes de la herramienta de flujo de trabajo se reiniciaran desde su mensaje original cuando una conexión se detenía durante unos minutos a mitad de la respuesta.
  • Se corrigió que /compact, /clear y /rewind se escribieran mientras se veía la transcripción de un agente en segundo plano o de un compañero de equipo que actuaba silenciosamente en la conversación principal: un cuadro de diálogo ahora nombra el objetivo y pregunta primero.
  • Se corrigieron los trabajos en segundo plano que se mostraban realizados mientras se esperaba su aprobación.
  • Se corrigió que el recordatorio de atribución de confirmación se reenviara dentro de la salida de la herramienta cuando el retroceso del modelo dura solo un turno.
  • Se corrigió un click en el espacio entre palabras de una fila contraída (como "Pensamiento para 4") resaltando la fila sin expandirla en modo de pantalla completa.
  • Se corrigió una fila sin detalles, como una fila de acción con un nombre largo, empujando los detalles de cada dos filas hacia la derecha en las pantallas de lista.
  • Se corrigieron archivos con nombres muy largos que no llegaban a una sesión en la nube cuando se adjuntaban a ella.
  • Se corrigieron errores de complemento para un mercado que Claude Code se niega a cargar: ahora dicen por qué y cómo solucionarlo en lugar de "no encontrado".
  • Se corrigió la pestaña Descubrir de /plugin que mostraba un nombre de mercado sin comillas en su línea "Buscando... nuevos complementos" cuando sus filas ya mostraban ese nombre entre comillas.
  • Guía de confirmación mejorada: cuando su proyecto o habilidades de usuario incluyen uno llamado verify, ahora se le indica a Claude que lo ejecute justo antes de confirmar, excepto para confirmaciones de solo documentos y solo pruebas.
  • Envío mejorado ahora (ctrl+enter) en la vista de un subagente: ahora mueve el comando en ejecución del subagente a un segundo plano para que su mensaje se lea de inmediato
  • Respuestas mejoradas de agentes en segundo plano a tus mensajes para que ya no se abran con un resumen separado de lo que dijiste.
  • Lecturas mejoradas del enlace del artefacto claude.ai: WebFetch ahora hace las mismas preguntas que la lectura de la herramienta Artifact (no hay mensajes de artefacto mientras el acceso a la red de la sesión está activado, uno por artefacto mientras está desactivado), y un modo automático sí ya no cuenta donde solo usted puede responder
  • Búsqueda mejorada, habilidad, lectura de archivos, red sandbox, Claude en Chrome, script de flujo de trabajo y mensajes de permiso de edición del cuaderno para que coincidan con el aspecto de los mensajes de edición de archivos.
  • Mensajes de permiso mejorados de Bash, PowerShell y Monitor para mostrar el comando entre líneas discontinuas, coincidiendo con los mensajes de edición de archivos.
  • Barras de desplazamiento de lista mejoradas en modo de pantalla completa: en la mayoría de las listas, la barra ya no se desplaza cuando las filas "N más" van y vienen, y ahora tiene flechas ↑/↓ que puedes click o mantener presionadas para desplazarte.
  • Se mejoró el editor externo (Ctrl+G): los editores que toman un número de línea ahora se abren en la línea en la que se encuentra el cursor en el mensaje.
  • Se mejoró la capacidad de respuesta de las sugerencias de comandos de barra diagonal al escribir cuando se instalan muchas habilidades o comandos de complementos; Las descripciones de los comandos ahora coinciden por prefijo de palabra.
  • Se mejoró el selector de estilos de salida: ahora se abre en su estilo actual en lugar de Predeterminado, con la descripción de cada estilo en la línea debajo de su nombre; Las teclas numéricas ya no eligen un estilo.
  • /hooks mejorado: la línea de cierre de la pantalla de detalles de un gancho ahora dice "este gancho" en lugar de "eso"
  • Se mejoró el aviso de reserva del modelo y el error de autocompact-thrashing para indicar cuando una reserva redujo la ventana de contexto de 1 millón a 200 mil tokens.
  • Capacidad de respuesta mejorada de las sesiones SDK y -p cuando un host reenvía una habilitación de servidor MCP para un servidor que ya está conectado
  • Se mejoró la página de protocolo que sirve una puerta de enlace de aplicaciones de Claude en /protocol: ahora dice no rechazar entradas desconocidas y coincide con lo que Claude Code envía hoy.
  • Se cambiaron las indicaciones enviadas mientras no hay nada en ejecución o en cola para que se muestren en el color de texto normal de inmediato en lugar de gris.
  • Se modificó la forma en que se reintentan las solicitudes API fallidas: un límite ahora cubre una llamada de modelo completa, por lo que con la configuración de reintento predeterminada, una llamada fallida envía como máximo 14 solicitudes
  • Se modificó --bare para conectar solo los servidores MCP nombrados en la línea de comando, no enviar al modelo recordatorios del sistema y no iniciar tareas en segundo plano; bajo --bare, un comando de shell que alcanza su tiempo de espera ahora se detiene en lugar de pasar al fondo
  • Se cambió la tecla enviar ahora (ctrl+enter) para mover el comando de shell propio de una habilidad al fondo en lugar de finalizarlo.
  • Se modificó el error de WebFetch para una verificación de seguridad de dominio con velocidad limitada para indicarle a Claude que no lo vuelva a intentar en un bucle.
  • Se cambiaron las instalaciones de complementos para rechazar fuentes npm que sean carpetas o repositorios de git, y para instalar dependencias de complementos solo desde paquetes de registro.
  • Se cambiaron las pantallas de lista (/artifacts, /mcp, /skills, /hooks y otras) para alinear siempre los detalles de cada fila en una columna después de los nombres.
  • Se cambiaron las filas desbordadas de las listas para que digan " ↑ N más " / "↓ N más " en lugar de " N más arriba " / " N más abajo "
  • Se modificó /hooks para abrir en una lista de sus enlaces configurados agrupados por evento, por lo que para ver un enlace se necesita un Intro en lugar de tres.
  • Se cambió el selector de temas a una lista de desplazamiento que se adapta a su terminal en lugar de sacar la vista previa de la pantalla; Las teclas numéricas ya no eligen un tema.
  • Se modificó el árbol de trabajo Eliminar de /exit para que se ejecute después de que Claude Code detenga los servidores y shells que inició allí, lo que en Windows podría evitar que la carpeta se elimine.
  • Se cambiaron los ejemplos de agentes administrados de la habilidad claude-api para crear entornos con redes limitadas.
  • Se eliminó el enlace del navegador de la salida /ultrareview y claude ultrareview.
  • Windows: Se corrigió claude --bg y la vista de agentes rechazaba una carpeta que claude ya era trust cuando su registro trust se guardó con letras mayúsculas diferentes.
  • [VSCode] Se agregaron marcadores: guarde las respuestas de Claude y manténgalas a la vista en un panel lateral de Marcadores
  • [VSCode] Se agregaron las preguntas que hace Claude y sus respuestas a la conversación: después de responder una tarjeta de preguntas, una fila de Preguntas muestra cada pregunta con sus selecciones.
  • [VSCode] Se agregaron vistas previas de opciones a las tarjetas de preguntas en el panel de chat: la maqueta o el fragmento de la opción resaltada se muestran al lado o debajo de las opciones.
  • [VSCode] Se agregaron filas debajo de un mensaje que se abren en la salida del terminal, la pestaña del navegador, las instrucciones del navegador y el código seleccionado enviado con él.
  • [VSCode] Se corrigió una segunda copia de una conversación que se abría en una pestaña cuando ya estaba abierta en la barra lateral; la barra lateral ahora cambia a ella
  • [VSCode] Se corrigieron los cuadros de diálogo de configuración que informaban un guardado fallido, sin volver a verificar, cuando Claude Code imprimió más de 1 MB de salida
  • [VSCode] Se corrigió una rueda interminable de "Sesión de teletransporte..." cuando la extensión deja de responder
  • [VSCode] Se mejoró el cuadro de diálogo Administrar complementos: indica cuando un complemento desactivado todavía está activado debido a otras configuraciones y explica un conflicto de carpetas de complementos.
  • [VSCode] Se cambió Detener y Escape para finalizar solo el turno actual; Los agentes en segundo plano siguen ejecutándose y se pueden detener uno por uno desde el mapa de agentes.
  • [VSCode] Se cambió el elemento de la barra de estado "✻ Claude Code" para que se muestre en cada ventana, de modo que puedas abrir Claude cuando no haya ningún archivo abierto.
  • [Sesiones en la nube] Se corrigió una tarjeta de pregunta respondida o una llamada de herramienta aprobada que no obtenía respuesta cuando la sesión había quedado inactiva después de que Claude enviara un mensaje.
  • [Sesiones en la nube] Se corrigió la eliminación del script de configuración del entorno de una organización en la configuración de administrador, lo que dejaba que las nuevas sesiones en la nube siguieran ejecutando el script anterior.
  • [Sesiones en la nube] Se corrigió que el menú de acciones del Runner en la página de administración de entornos autohospedados se cerrara solo unos segundos después de abrirse.
  • [Sesiones en la nube] Se corrigieron ejecuciones de rutinas cuya sesión en la nube nunca comenzó a mostrarse como exitosa en el panel Ejecuciones, la página de la rutina y la barra lateral; ahora se muestran como fallidos
  • [Sesiones en la nube] Se corrigió cli al bloquear un archivo de audio o video en la tarjeta Salidas de una sesión en la nube, abriendo una búsqueda de archivos vacía en lugar de reproducir el archivo.
  • [Sesiones en la nube] Se cambió la página de una rutina para que diga "Vence" con la hora programada, en lugar de una siguiente hora de ejecución en el pasado, cuando una ejecución programada llega tarde y no ha comenzado.
  • [Claude Tag] Se agregó un botón Agregar canal a la página de límites de gasto de Claude Tag en la configuración de administración, por lo que se puede establecer un límite en cualquier canal, incluido uno privado, desde su ID de canal o enlace de Slack.
  • [Claude Tag] Se corrigió la recuperación de memoria al no encontrar nada en organizaciones que no pueden usar el modelo Sonnet predeterminado.
  • [Etiqueta de Claude] Se corrigió que un canal de Slack perdiera su configuración de Claude cuando un administrador de Enterprise Grid lo movía a otro espacio de trabajo y la primera publicación posterior no menciona a Claude.
  • [Etiqueta de Claude] Se corrigió que Claude en un hilo de Slack ocasionalmente comenzaba de nuevo en una máquina nueva, perdiendo trabajo que no había enviado, cuando su respuesta respondía una pregunta que acababa de hacer.
  • [Claude Tag] Se corrigieron los nombres de los canales públicos en la página de límites de gasto de Claude Tag en la configuración de administración que se muestran como ID de Slack sin procesar en organizaciones más grandes.
  • [Claude Tag] Se mejoraron los títulos de las sesiones iniciadas desde Slack como se muestra en claude.ai: ahora se leen como las palabras que usted escribió, sin ID de usuario de Slack ni códigos de escape.
