aider v0.83.0

Menor Publicado9 may 2025 FuenteAider-AI/aider original en inglés

Esta página está traducida automáticamente. El texto original en inglés es la referencia.

ayudante v0.83.0

  • Se agregó soporte para los modelos gemini-2.5-pro-preview-05-06.
  • Se agregó soporte para los modelos qwen3-235b.
  • Se agregó soporte de mapa de repositorio para archivos de interfaz OCaml y OCaml, por Andrey Popp.
  • Se agregó una animación giratoria mientras se espera que el LLM comience a transmitir su respuesta.
  • Se actualizó la animación del spinner al estilo Knight Rider.
  • Se introdujo la opción --attribute-co-authored-by para agregar un avance del coautor para confirmar mensajes, por Andrew Grigorev.
  • Se actualizaron los alias del modelo Gemini (por ejemplo, gemini, gemini-2.5-pro) para que apunten a las versiones preliminares de 05-06.
  • Los modelos de vista previa de Gemini 2.5 Pro marcados como overeager de forma predeterminada.
  • El mensaje de confirmación especifica el idioma del usuario.
  • Se actualizó el modelo débil predeterminado para los modelos Gemini 2.5 Pro a gemini/gemini-2.5-flash-preview-04-17.
  • Se corrigió la configuración del modelo gemini-2.5-pro-exp-03-25 para reflejar su falta de soporte para thinking_budget.
  • Se aseguró que los prefijos de avisos del sistema específicos del modelo se coloquen en una nueva línea antes del aviso principal del sistema.
  • Se agregó seguimiento del total de tokens enviados y recibidos, ahora incluido en las estadísticas de referencia.
  • Recupera automáticamente los parámetros del modelo (ventana contextual, precios) para los modelos OpenRouter directamente desde su sitio web, por Stefan Hladnik.
  • Se habilitó el soporte para los parámetros thinking_tokens y reasoning_effort para los modelos OpenRouter.
  • Cálculo de costos mejorado usando litellm.completion_cost cuando esté disponible.
  • Se agregaron configuraciones de modelo para openrouter/google/gemini-2.5-pro-preview-03-25.
  • Se agregó la bandera --disable-playwright para evitar las indicaciones de instalación y el uso de Playwright, por Andrew Grigorev.
  • La herramienta de línea de comandos aider scrape ahora utilizará Playwright para web scraping si está disponible, de Jon Keys.
  • Se corrigió la ejecución del comando linter en Windows mediante la adopción de oslex para citar argumentos, por Titusz Pan.
  • Visualización multiplataforma mejorada de comandos de shell mediante el uso de oslex para citar argumentos sólidos, por Titusz Pan.
  • Modo /ask mejorado para indicarle al LLM que omita el código que no cambia en sus respuestas.
  • Web scraping garantizado en la GUI también respeta la disponibilidad de Playwright y la bandera --disable-playwright.
  • Visualización mejorada de nombres de archivos en el encabezado del mensaje utilizando formato de texto enriquecido.
  • reasoning_effort habilitado para los modelos Gemini 2.5 Flash.
  • Se agregó un argumento --shell-completions para generar scripts de finalización de shell (por ejemplo, para bash, zsh).
  • Los indicadores --attribute-author o --attribute-committer explícitos ahora anulan el comportamiento predeterminado cuando se usa --attribute-co-authored-by, lo que permite un control más preciso sobre la atribución de confirmación, por Andrew Grigorev.
  • Se solucionó un problema por el cual algunos comandos no conservaban correctamente el estado de solo lectura de los archivos (por ejemplo, /drop después de agregar un archivo de solo lectura).
  • La utilidad aider-args (o python -m aider.args) ahora imprime de forma predeterminada una configuración de muestra de YAML si no se proporcionan argumentos.
  • Se muestra el progreso del recuento de tokens y el nombre del archivo o identificador que se procesa durante las actualizaciones del mapa de repositorio.
  • Se amplió el control giratorio de espera para mostrar también las respuestas que no son de transmisión y se mejoró aún más su animación con clipping de ancho de consola, ocultación del cursor y una apariencia más continua.
  • Se eliminó el soporte para Python 3.9.
  • Aider escribió el 55% del código en esta versión. release note completos: https://aider.chat/HISTORY.html
