lechuga 7.6.0.RELEASE

¡El equipo de Lettuce se complace en anunciar el lanzamiento menor de Lettuce 7.6.0!

✨ Destacados

Lettuce 7.6.0 presenta soporte para las nuevas funciones de versión Redis OSS 8.8, como:

  • la nueva estructura de datos Array
  • INCREX: un limitador de tasa de contador de ventana que combina INCR, INCRBY, INCRBYFLOAT, límites y vencimiento
  • XNACK: un nuevo comando de transmisiones: permite a los consumidores publicar mensajes pendientes de forma explícita
  • ZUNION, ZINTER, ZUNIONSTORE, ZINTERSTORE: nuevo agregador COUNT
  • JSON.SET: nuevo argumento FPHA para especificar el tipo de FP para matrices de FP homogéneas

Lettuce 7.6.0 admite Redis 2.6+ hasta Redis 8.x. En términos de tiempo de ejecución de Java, Lettuce requiere al menos Java 8 y funciona con Java 24. El controlador se prueba con Redis 8.8, Redis 8.6, Redis 8.4, Redis 8.2, Redis 8.0, Redis 7.4 y Redis 7.2.

Gracias a todos los contribuyentes que hicieron posible Lettuce 7.6.0.RELEASE.

📗 Enlaces Documentación de referencia: https://lettuce.io/core/7.6.0.RELEASE
