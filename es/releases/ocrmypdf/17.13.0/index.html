#OCRmyPDF v17.13.0

Cambios

  • PDF/A realizado sin Ghostscript (conversión "especulativa") ahora está validado con soporte PDF/A de pikepdf (pikepdf.pdfa) en lugar de veraPDF, y el El resultado final se valida nuevamente después de los pasos de optimización y metadatos. veraPDF is no longer used, so the Ghostscript-free path is available whether or not veraPDF is installed, including in the Docker image. Archivos the validator does not approve go to Ghostscript as before; ejecutar con -v1 para ver por qué.
  • Speculative conversion now supports PDF/A-1b, and repairs common problems that previously always sent a file to Ghostscript: it replaces other output intents with sRGB, removes image interpolation flags, sets the Print flag on annotations, adds the /CIDSet PDF/A-1 requires, and removes XMP properties and hidden annotations that PDF/A does not permit.
  • Nueva opción --pdfa-backend {auto,ghostscript,internal} (API: pdfa_backend=). auto, the default, tries OCRmyPDF's own conversion and luego Ghostscript. internal never uses Ghostscript, so JPEGs pass through sin cambios; if the result is not approved, the pdfa output types fail with código de salida 10 y --output-type auto genera un PDF normal. ghostscript siempre usa Ghostscript. Opciones que solo implementa Ghostscript (--pdfa-image-compression, --ghostscript-jpeg-quality, --ghostscript-jpeg-maxdpi y --color-conversion-strategy CMYK, Gray or UseDeviceIndependentColor) now select Ghostscript under auto y son un error con internal.
  • OCRmyPDF now requires pikepdf[pdfa] 10.15 or later. El extra pdfa brings in jsonschema, referencing and fonttools, all packaged by Debian y RedHat.
  • --force-ocr now keeps hyperlinks, moving link annotations onto the página rasterizada; también lo hacen --deskew y --clean-final. el nuevo modo --mode force-ocr-no-links mantiene el comportamiento anterior. {issue}605
  • When Ghostscript substitutes fonts that are not embedded, it now always uses its own fonts (-dNONATIVEFONTMAP), so output is the same on every plataforma; on macOS, native font lookup could embed tens of megabytes of fuentes del sistema. OCRmyPDF warns when fonts other than the standard 14 are substituted, or when a substitute loses bold or italic styling. {issue}1369
  • A creation date without a time zone is now taken to be local time, and the Las fechas de salida obtienen esa zona, con una advertencia. Configure TZ para elegir otro zona.
  • In the default mode, a page that already has text now stops OCRmyPDF straight after the initial scan, instead of after OCRing the pages before eso. El error nombra la página. {issue}613
  • The check of the output file is much faster: each stream is checked in the forma más barata para su compresión en lugar de ser completamente decodificado, y un Se muestra la barra de progreso. JPEG 2000 and CCITT images are now checked too, but JPEGs that are corrupt without being truncated are no longer detected. {issue}1570
  • OCRmyPDF now ships a PyInstaller hook, so apps that use it can be bundled sin opciones adicionales. Tesseract and Ghostscript must still be installed. {issue}1024
  • New PageInfo.has_visible_text, which excludes invisible text such as an Capa OCR. has_text no ha cambiado.

Correcciones

  • --force-ocr on a scan that already had an invisible OCR layer rasterized it at no less than 400 dpi, as if the text were visible, which could multiplica el tamaño del archivo. {issue}961
  • Los trabajadores de proceso (use_threads=False en Windows y macOS) fallaron en todos página con 'OcrOptions' object has no attribute 'tesseract'. {issue}1757
  • ocrmypdf.ocr() rechazó nombres de métodos de umbralización como tesseract_thresholding='adaptive-otsu'. {issue}1460
  • --rotate-pages --tesseract-timeout 0 detectó la orientación de la página pero no lo hizo. rotar las páginas. El libro de cocina ahora recomienda esta combinación para rotar o corregir sin OCR. {issue}778
  • Con --output-type auto y --force-ocr, la salida se etiquetó como PDF/A sin ser validado ni recibir las declaraciones PDF/A cuando veraPDF fue no instalado, como en la imagen Docker. {issue}1751
  • La conversión PDF/A de Ghostscript eliminó la mayoría de los hipervínculos (aquellos sin el Imprimir bandera). Las anotaciones ocultas, que PDF/A no permite, ahora están eliminado antes de que se ejecute Ghostscript, con la misma advertencia que el especulativo conversión, en lugar de hacerlo en silencio. {issue}605
  • Texto en fuentes sin /ToUnicode, que los espectadores extraen mediante glifos nombres, se confundió o se perdió cuando Ghostscript creó el PDF/A. {issue}1297
  • Metadatos XMP sin equivalente de información de documento, como dc:contributor y dc:subject, se perdió cuando Ghostscript creó el PDF/A. es ahora copiado con todo su valor, incluidos todos los idiomas de un multilingüe propiedad. {issue}1220
  • Las imágenes en archivos PDF de iText y pdftk se recomprimieron sin su Flate predictor, aumentando la producción en aproximadamente un 30%. {issue}1620
  • Texto copiado de líneas verticales japonesas y otras líneas OCR verticales o rotadas Tenía espacios espurios y caracteres fuera de orden. {issue}1244
  • Texto configurado en la fuente alternativa sin glifos, usado cuando no hay una fuente instalada cubre un script (por ejemplo, CJK), caracteres perdidos al seleccionarlos o copiarlos en Chrome y otros visores basados en pdfium.
  • Se rasterizó una página formada por imágenes de página completa con diferentes resoluciones en una resolución promedio ponderada en lugar de la más alta. {issue}948
  • El idioma del documento (/Lang) no se configuró para los códigos de idioma de Tesseract. como deu, fra y ces. Los idiomas sin código de dos letras ahora obtienen su código de tres letras. {issue}1749
  • Algunos archivos PDF LaTeX con números mal formados en un flujo de contenido, como 0.000-50131235, OCRmyPDF detenido. Ahora advierte y continúa, como los espectadores. hacer. {issue}1054
  • Un /Rotate almacenado como número real, o un operador cm con un número no numérico operando, bloqueó el escaneo de la página.
  • --force-ocr --ocr-engine none fallaba en páginas sin imágenes.
  • Cuando el propio PDF/A de OCRmyPDF no pasó su verificación final, el respaldo de Ghostscript podría fallar con FileExistsError; en Windows siempre fue así.
  • Con el --output-type auto predeterminado, la explicación de un archivo que creció ahora apunta a la conversión PDF/A. {issue}1369
  • El título de Ghostscript 10.08, 'Untitled' (con comillas) para archivos sin título es eliminado nuevamente.
  • El servicio web de la imagen Docker no pudo encontrar su script Streamlit. el Docker Se actualiza la documentación del servicio web. {issue}1753
  • El observador Docker ya no apaga deskew indicado en OCR_JSON_SETTINGS cuando OCR_DESKEW no está configurado.
