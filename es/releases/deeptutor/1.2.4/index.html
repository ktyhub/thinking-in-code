#DeepTutor v1.2.4

DeepTutor v1.2.4 Release Note

Fecha de lanzamiento: 2026.04.25

Destacados

Admite más formatos de archivos adjuntos en el chat

El canal de archivos adjuntos de documentos v1.2.3 se ha ampliado más allá de los archivos de Office. Los archivos adjuntos de chat ahora aceptan los mismos formatos de texto que el enrutador de ingesta de la base de conocimientos: Markdown, texto sin formato, registros, JSON/YAML/TOML, CSV/TSV, LaTeX/BibTeX, HTML/XML/SVG, hojas de estilo, scripts y archivos de código fuente comunes (.py, .js, .ts, .tsx, .java, .cpp, .go, .rs, .sql, .sh y más).

  • Paridad de backend con enrutamiento de KB: deeptutor/utils/document_extractor.py importa FileTypeRouter.TEXT_EXTENSIONS, por lo que los archivos adjuntos de chat y las cargas de KB comparten una fuente de confianza para los formatos de texto/código. FileTypeRouter.decode_bytes() centraliza la cadena de respaldo UTF-8 / UTF-8-BOM / GBK / GB18030 / Latin-1 / CP1252.
  • SVG como fuente legible: .svg se agregó al conjunto de extensiones de texto RAG y se trata como un documento adjunto en lugar de una imagen de visión, lo que permite que el LLM inspeccione la fuente XML mientras la interfaz aún muestra una vista previa en miniatura segura.
  • UX del archivo adjunto mecanografiado: web/lib/doc-attachments.ts ahora expone OFFICE_EXTS, TEXT_LIKE_EXTS, detección de SVG, respaldo de extensión/MIME más rico e íconos específicos de categoría para código, shell, JSON, configuración, datos, marcado, hojas de estilo, texto sin formato, documentos de Office y SVG.
  • Copia de Composer actualizada: la sugerencia de arrastrar y soltar ahora anuncia "Imágenes, documentos de Office, código y texto" en lugar de la lista anterior solo de Office.

Tour de configuración con un solo comando

scripts/start_tour.py ha pasado de ser un asistente de configuración puro a una ruta de instalación nueva de 7 pasos que puede detectar el entorno local, instalar dependencias y luego guiar la configuración del proveedor.

  • Paso de instalación de dependencia: el recorrido verifica Python, uv, Node.js y npm; instala los requisitos del backend, instala DeepTutor en modo editable y ejecuta el frontend npm install con salida de terminal en vivo.
  • Compatibilidad con uv pip (n.º 376): la instalación de la dependencia Python ahora prefiere uv pip cuando está disponible y vincula --python <current-interpreter> para que los paquetes lleguen al intérprete que ejecuta el recorrido en lugar de un .venv/$VIRTUAL_ENV no relacionado.
  • Detección de npm de Windows (#381): las invocaciones de npm usan npm.cmd en Windows, corrigiendo comprobaciones de versión e instalación de comandos en sistemas donde npm está expuesto como un ajuste de comando en lugar de un ejecutable.
  • Opciones de LLM basadas en el registro de proveedores: el asistente ahora lee el registro completo de PROVIDERS, agrupa a los proveedores por modo, resalta los servicios comunes e incluye opciones más nuevas como custom_anthropic, OpenRouter, SiliconFlow, proveedores de codificación Volcengine/BytePlus, GitHub Copilot, OpenAI Codex, llama.cpp, OVMS, MiniMax, Mistral, Qianfan, Step Fun y Xiaomi MiMo.
  • Sugerencias de búsqueda y configuración: Serper está disponible en la lista de proveedores de búsqueda; Las indicaciones de la versión Azure/API y del proxy ahora muestran orientación en línea en inglés y chino.
  • UX de terminal de lista larga: scripts/_cli_kit.py presenta menús de selección largos dentro de una ventana de desplazamiento con indicadores "más arriba/abajo", lo que evita filas de terminales obsoletas cuando la lista de proveedores excede la altura de la pantalla.

Exportación de rebajas de chat

La página de chat ahora tiene una acción Descargar Markdown junto a "Guardar en Notebook" y "Nuevo chat". web/lib/chat-export.ts serializa la conversación actual como Markdown con un título, marca de tiempo de exportación ISO, encabezados de funciones, etiquetas de capacidad y metadatos de archivos adjuntos, luego la descarga con un nombre de archivo desinfectado con fecha. Esto brinda a los usuarios una ruta de exportación local liviana para compartir, archivar o mover una conversación a notas externas.

Interfaz de usuario de gestión de la base de conocimientos en polaco

La página de Conocimiento se ha mejorado para una gestión diaria más densa:

  • Las zonas de creación y carga ahora son tarjetas discontinuas más simples con resúmenes concisos de políticas de carga en línea.
  • Las tarjetas KB se trasladaron de cuatro grandes paneles de estadísticas a filas compactas que muestran el recuento de documentos, la preparación del índice, la hora de la última actualización, el proveedor, el modelo de incrustación, el progreso en vivo y la ruta de almacenamiento.
  • Las acciones predeterminadas/eliminar se simplificaron visualmente, lo que redujo la altura de la tarjeta y facilitó el escaneo de listas de KB grandes.

Actualización de documentación y localización

La familia README se actualizó para que coincida con la nueva historia de instalación y superficie del proveedor:

  • LEADME en polaco: assets/README/README_PL.md agrega una traducción completa al polaco del proyecto README (#379).
  • Documentos de configuración: los archivos README principales y multilingües ahora describen la visita guiada como la ruta de clonación nueva recomendada: cree un entorno Python, ejecute python scripts/start_tour.py y luego use python scripts/start_web.py para el lanzamiento diario.
  • Documentos del proveedor: se actualizaron las tablas de proveedores para el registro de proveedores v1.2.3, incluido custom_anthropic, los puntos finales canónicos de MiniMax, los proveedores de planes de codificación, los proveedores locales y notas de autenticación aclaradas para OpenAI Codex/GitHub Copilot.
  • Secciones de lanzamiento/noticias: los archivos README multilingües ahora incluyen resúmenes de v1.2.2 y v1.2.3, una guía de contribución y el hito de la comunidad de 20.000 estrellas.

Correcciones de UI y temas

  • Ventanas emergentes basadas en temas: los menús de capacidades/herramientas/referencias/habilidades del compositor ahora usan --popover más desenfoque de fondo en lugar de --card, lo que mejora el contraste en el tema Glass y los contextos emergentes oscuros.
  • Sugerencias de combinación de colores nativos: las raíces de los temas claro, oscuro, Nieve y Vidrio declaran el color-scheme correcto, lo que mejora los controles nativos y las superficies renderizadas en el navegador.
  • Hidratación de desplazamiento suave: el desplazamiento suave global ahora está controlado detrás de html[data-scroll-behavior="smooth"], con el atributo establecido por el diseño raíz para evitar su aplicación involuntaria.
  • Tamaño del logotipo de la barra lateral: las imágenes del logotipo de la barra lateral ahora fijan clases de ancho/alto renderizadas explícitamente para evitar pequeños cambios en el diseño.

Limpieza

Se eliminó el puntero del submódulo nanobot obsoleto y el código auxiliar scripts/extract_numbered_items.sh obsoleto del repositorio. El código base v1.2.x ahora se basa en la extracción de documentos en el árbol y en las rutas de enrutamiento RAG en lugar de ese asistente heredado.

Expansión del conjunto de pruebas

  • Extracción de documentos backend: tests/utils/test_document_extractor.py ahora cubre texto sin formato, fuente Python, JSON, CSV, Markdown, entrada UTF-8-BOM, decodificación alternativa GBK y extracción de fuente SVG.
  • Clasificación de archivos adjuntos de interfaz: web/tests/doc-attachments.test.ts ahora cubre la aceptación de texto/código, enrutamiento de SVG como documento, detección de nombres de archivos SVG que no distinguen entre mayúsculas y minúsculas y las nuevas categorías de íconos para código, JSON, configuración, shell, datos, marcado, hojas de estilo y SVG.
