#DeepTutor v1.0.3

DeepTutor v1.0.3 Release Note

Fecha de lanzamiento: 2026.04.13

Destacados

Cuaderno de preguntas: sistema unificado de revisión de cuestionarios

Se reemplazó la "Nota de respuesta incorrecta" de propósito único con un Cuaderno de preguntas completo que almacena cada pregunta del cuestionario (correcta e incorrecta) con metadatos enriquecidos: tipo de pregunta, opciones, explicación y dificultad. Cada entrada admite marcadores y etiquetado de categoría para una revisión organizada. Una nueva página dedicada a /notebook proporciona filtrado (todo/marcado/incorrecto), administración de categorías (crear, cambiar nombre, eliminar) y enlaces directos a la sesión de origen. El componente QuizViewer ahora integra controles de categorías y marcadores en línea para que los usuarios puedan organizar preguntas sin salir del flujo del cuestionario.

Compatibilidad con el diagrama de sirena en Visualize

Se amplió la capacidad de visualización con un tercer tipo de renderizado: Sirena. El agente de análisis ahora elige entre svg, chartjs y mermaid, prefiriendo Mermaid para diagramas estructurados (diagramas de flujo, diagramas de secuencia, diagramas de clases, mapas mentales, etc.). El generador de código y los agentes de revisión recibieron las actualizaciones correspondientes, y la interfaz VisualizationViewer representa diagramas de sirena a través de un componente <Mermaid> dedicado.

Incrustación de detección de discrepancias en el modelo

Las bases de conocimiento ahora registran el modelo de incrustación y la dimensión utilizados en el momento del índice. Durante la carga, el sistema compara las huellas dactilares almacenadas con el modelo de incrustación actualmente configurado; Las KB que no coinciden se marcan con embedding_mismatch y needs_reindex. El proceso de búsqueda de RAG muestra una advertencia cuando se consulta una base de conocimiento que no coincide, y la página de conocimiento muestra una insignia de alerta para que los usuarios sepan que deben volver a indexar.

Fusión de mensajes del sistema para compatibilidad Qwen/vLLM

Se consolidaron múltiples mensajes del sistema en un solo mensaje del sistema combinado tanto en AgenticChatPipeline como en ChatAgent, lo que solucionó la compatibilidad con los modelos Qwen servidos a través de vLLM que rechazan conversaciones de mensajes de múltiples sistemas. El generador de contexto ahora filtra los mensajes duplicados del sistema del historial almacenado para evitar la redundancia.

Soporte de proveedores de LM Studio y llama.cpp

Se agregaron entradas ProviderSpec de primera clase para LM Studio (localhost:1234) y llama.cpp (localhost:8080) con detección automática de URL base y el backend openai_compat, además de mapeo de alias de proveedor de incrustación.

Tema de cristal

Se presentó un nuevo tema Glass con superficies de tarjetas de vidrio esmerilado, fondos degradados y botones con detalles brillantes. El selector de temas ahora alterna entre claro → oscuro → vidrio.

Resiliencia del agente de informes de investigación profunda

Se extrajo un asistente _call_llm_json compartido con lógica de reintento configurable en el agente de informes, reemplazando tres bloques LLM de llamada y luego análisis en línea idénticos para la introducción, el cuerpo de la sección y la generación de conclusiones.

Migración de documentación

Se eliminó la carpeta heredada de VitePress docs/; La documentación se ha migrado al sitio web del proyecto.
