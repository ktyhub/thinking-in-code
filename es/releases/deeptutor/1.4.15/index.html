#DeepTutor v1.4.15

DeepTutor v1.4.15 Release Note

Fecha de lanzamiento: 2026.06.30 Una pequeña versión además de v1.4.14: los socios obtienen un canal Mattermost nativo, las preguntas de opción múltiple de aprendizaje guiado persisten y se califican correctamente, y se respeta una superposición de fragmentos cero configurada al indexar. Sin cita previa, sin migraciones.

¿Qué hay de nuevo?

Canal nativo de Mattermost

Los socios ahora pueden conectarse a un servidor Mattermost autohospedado a través de su propio WebSocket v4 + REST API en lugar de enrutarlo a través del shim de compatibilidad Slack de Mattermost. Establezca la URL del servidor de una cuenta de bot y el token de acceso en la pestaña Canales del socio; las respuestas se procesan con Markdown nativo y los chats grupales responden con @-mention o con cada mensaje según group_policy. Reutiliza el transporte httpx + websockets existente, por lo que no se necesita una nueva dependencia (problema n.º 590).

Las opciones de aprendizaje guiado persisten y califican correctamente

Las preguntas de opción múltiple en Mastery Path ahora registran cada cuerpo de opciones completo con mastery_quiz, no solo las etiquetas A/B/C, de modo que el motor califica de manera determinista y la entrada guardada del Banco de preguntas muestra las opciones reales junto con la respuesta correcta. Las rutas creadas antes de esta versión recuperan el texto de opción de la tarjeta ask_user original al momento de calificar.

Se respeta la superposición de fragmentos cero configurada

La configuración de chunk_overlap (o chunk_size) de una base de conocimientos en 0 en el motor LlamaIndex se reemplazó silenciosamente con el valor predeterminado de 50 antes de la indexación. Ahora se conserva un 0 explícito, por lo que una estrategia de fragmentación sin superposición indexa exactamente como está configurada.

Notas de actualización

Acceso directo desde v1.4.14: pip install -U deeptutor; Los usuarios de Docker extraen ghcr.io/hkuds/deeptutor:latest. Sin migraciones ni cambios de comportamiento: las bases de conocimiento, los socios y las rutas de dominio existentes siguen funcionando tal como están. Changelog completo: https://github.com/HKUDS/DeepTutor/compare/v1.4.14...v1.4.15
