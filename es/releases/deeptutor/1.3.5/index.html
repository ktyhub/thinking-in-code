#DeepTutor v1.3.5

DeepTutor v1.3.5 Release Note

Fecha de lanzamiento: 2026.05.02 v1.3.5 se centra en hacer que la configuración local y el chat de la base de conocimientos sean más confiables. el El lanzador ahora sigue la misma configuración de tiempo de ejecución que los usuarios configuran en la aplicación web. Las llamadas a la herramienta RAG son más estrictas con respecto a las consultas de búsqueda reales y la incrustación local Los servidores ya no reciben encabezados de autenticación de marcador de posición.

Destacados

Lanzamiento local más fluido

  • El recorrido de configuración escribe los puertos de inicio: el instalador guiado ahora registra el backend y puertos frontend en data/user/settings/env.json, por lo que los lanzamientos posteriores pueden usar las mismas opciones.
  • start_web.py lee primero la configuración del tiempo de ejecución - puertos backend/frontend y UI El idioma proviene de la configuración web cuando esté disponible, con .env mantenido como alternativa.
  • Manejo de procesos más limpio: el iniciador registra los procesos iniciados, detecta conflictos de puerto, espera a que esté listo y expone scripts/stop_web.py para limpieza de procesos backend/frontend registrados.
  • Los requisitos de configuración son más claros - El archivo README y los ejemplos de entorno ahora están alineados alrededor de Node.js 20.9+, instalar perfiles, completar la incorporación de URL de terminales y almacenamiento de archivos adjuntos opcional.

Llamadas a herramientas RAG más confiables

  • Las consultas RAG no deben estar vacías - esquemas de herramientas, indicaciones y comprobaciones integradas ahora rechace consultas en blanco anticipadamente en lugar de pasar entradas vacías a la recuperación.
  • El respaldo del lado del chat es más seguro - cuando un modelo omite la consulta RAG, el agente La canalización puede reutilizar la pregunta real del usuario como consulta de recuperación.
  • Las llamadas ReAct aceptan entradas de cadenas simples - Acciones rag que proporcionan una La cadena está normalizada a {"query": ...}, lo que reduce las fallas frágiles en las llamadas a herramientas.

Compatibilidad de incrustación local

  • No hay clave API falsa para proveedores de incrustación locales - ya no hay configuración de tiempo de ejecución inyecta sk-no-key-required para servidores de integración locales.
  • Las claves de marcador de posición no se envían como encabezados de autenticación - Compatible con OpenAI Las solicitudes de incrustación suprimen Authorization y api-key cuando están configurados. La clave es el marcador de posición local, que ayuda a LM Studio, Ollama, vLLM y similares. servidores.
  • Los ejemplos de incrustación son más fáciles de seguir - Entorno de muestra en inglés y chino Los archivos ahora explican que EMBEDDING_HOST es el punto final exacto al que llama DeepTutor.

Web UX polaco

  • El menú desplegable de proveedores en modo oscuro es legible - el selector de proveedores de configuración ahora usa el token de fondo del tema, arreglando el popover desplegable nativo blanco informó sobre Edge/Chromium.
  • Los controles de configuración son más consistentes - seleccione campos y configure el recorrido El comportamiento del foco se ajustó para una experiencia de configuración más estable.
  • Las cargas útiles de referencias de libros se normalizan de forma más defensiva - libro seleccionado Las referencias mantienen el mismo comportamiento con un filtrado y deduplicación más limpios.

Pruebas

  • Se agregaron pruebas de configuración de inicio para la prioridad de la configuración del tiempo de ejecución, respaldo de .env, y manejo de puertos no válidos.
  • Se agregaron pruebas start_web.py para traducción, persistencia de estado y grabación. emparejamiento de procesos.
  • Se agregó cobertura del recorrido de configuración para perfiles de dependencia, selección de Math Animator, Validación de la versión Node.js y puertos de lanzamiento guardados.
  • Se agregaron pruebas RAG/herramienta para esquemas de consulta no vacíos, rechazo de consultas en blanco y comportamiento de consulta alternativa.
  • Se agregó tiempo de ejecución integrado y pruebas de adaptadores para proveedores locales, marcador de posición API. claves y supresión de encabezados de autenticación.

Notas de actualización

  • Las instalaciones web locales ahora requieren Node.js 20.9 o más reciente.
  • start_web.py y los asistentes de configuración prefieren data/user/settings/env.json y interface.json sobre .env; editar la página de configuración web o volver a ejecutar start_tour.py al cambiar de puerto de lanzamiento.
  • Los servidores de incrustación locales compatibles con OpenAI deben usar una clave API vacía a menos que Se requiere una clave real. Evite confiar en sk-no-key-required como transmisión credencial.
  • Las personas que llaman RAG personalizadas siempre deben proporcionar un query que no esté vacío; consultas en blanco ahora fallar rápidamente por diseño. Changelog completo: https://github.com/HKUDS/DeepTutor/compare/v1.3.4...v1.3.5
