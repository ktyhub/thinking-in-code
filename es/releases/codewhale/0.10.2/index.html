Código ballena v0.10.2

¿Qué hay en v0.10.2?

Codewhale v0.10.2 agrega una vista de mascota animada (/pet on), un trabajo de Terminal en vivo muelle, colores del compositor por chat (/color) y una nota única en el primer comience después de una actualización que dice lo que cambió. Cierra tres sesiones rutas de pérdida de datos y fuga de sesión codewhale web; agrega el tiempo de ejecución predeterminado ubicaciones de sockets de demonios en la lista de denegación de la zona de pruebas; sostiene un curl o wget que carga un credencial; rechaza comandos de shell que contengan Unicode invisible; mantiene el La zona de pruebas de Linux funciona cuando un directorio de credenciales oculto es un enlace simbólico; y Reduce el trabajo de redibujado de TUI inactivo. /undo recupera un todo solicitud, incluidas indicaciones largas y de varias líneas. exec --auto explica su Acceso completo predeterminado, respeta una zona de pruebas explícitamente más estricta y guarda ejecuciones habilitadas por herramientas y sus recibos de falla. Los tiempos de ejecución locales aparecen durante incorporación, /diff funciona fuera de un repositorio Git, ruta de respuestas de DeepSeek ya no rechaza el historial de herramientas reproducido y las correcciones de los contribuyentes mejoran el token contabilidad, listas de modelos de retransmisión, respuestas localizadas y lanzador de Windows orientación. El trabajo delegado continúa sin límites de tiempo o turnos inventados por el modelo, y los pasos del flujo de trabajo independientes pueden continuar después de que otro niño falle.

Instalar

Recomendado: lanzamiento oficial de GitHub

Nueva instalación de macOS/Linux (archivos binarios con suma de comprobación de esta versión):

curl -fsSL https://codewhale.net/install.sh | CODEWHALE_VERSION="v0.10.2" sh
"$HOME/.local/bin/codewhale" --version

Para Windows, utilice el instalador o archivo correspondiente a continuación. Para un existente instalación directa, ejecute codewhale update; imprime la ruta ejecutable y mantiene construcciones más nuevas. Si el directorio de instalación está ocupado por una compilación diferente, utilice la migración de directorio nuevo en [la guía de instalación] (https://github.com/codewhale-hq/CodeWhale/blob/main/docs/INSTALL.md).

Embalaje secundario: npm y carga

npm install -g codewhale
# or build from source
cargo install codewhale-cli --locked

El contenedor descarga los recursos de comando codewhale y codew coincidentes. de esta versión. Ambos contienen el mismo tiempo de ejecución compilado.

Docker / GHCR

docker run --rm -it \
  -e DEEPSEEK_API_KEY="$DEEPSEEK_API_KEY" \
  -v codewhale-home:/home/codewhale/.codewhale \
  ghcr.io/codewhale-hq/codewhale:v0.10.2

La imagen muestra el mismo tiempo de ejecución que codewhale y codew. el La etiqueta latest también se actualiza en el momento del lanzamiento.

Carga (Linux / macOS)

cargo install codewhale-cli --locked

El paquete Cargo instala codewhale. Cargo no puede crear un segundo comando alias de un objetivo binario; los usuarios que quieran una ortografía más corta pueden agregar una Enlace simbólico codew a ese ejecutable instalado. El npm, Homebrew, archivo, El instalador de shell y los canales de contenedor instalan ambos nombres de comando directamente.

Descarga manual: archivos de plataforma (recomendado)

Cada archivo a continuación contiene el mismo tiempo de ejecución bajo codewhale y Nombres de los comandos codew, además de un script de instalación:

| Plataforma | Archivo | Instalar script | |---|---|---| | Linux x64 | codewhale-linux-x64.tar.gz | install.sh | | Linux ARM64 | codewhale-linux-arm64.tar.gz | install.sh | | Android ARM64 (Termux) | codewhale-android-arm64.tar.gz | install.sh | | MacOS x64 | codewhale-macos-x64.tar.gz | install.sh | | BRAZO macOS | codewhale-macos-arm64.tar.gz | install.sh | | Windows x64 (instalador) | CodeWhaleSetup.exe | Configuración de NSIS | | Ventanas x64 | codewhale-windows-x64.zip | install.bat | | Windows x64 (portátil) | codewhale-windows-x64-portable.zip | — | | Ventanas ARM64 | codewhale-windows-arm64.zip | install.bat | | Windows ARM64 (portátil) | codewhale-windows-arm64-portable.zip | — |

Unix (Linux/macOS):

tar xzf codewhale-<platform>.tar.gz
cd codewhale-<platform>
./install.sh

Windows:

  • Para la ruta del instalador, ejecute CodeWhaleSetup.exe; se instala codewhale.exe, codew.exe y codewhale.bat bajo %LOCALAPPDATA%\Programs\CodeWhale\bin, agrega ese directorio al RUTA del usuario actual y crea un acceso directo al menú Inicio que prefiere Terminal de Windows (wt.exe) cuando esté instalado.
  • Extraiga el archivo para su máquina: codewhale-windows-x64.zip o codewhale-windows-arm64.zip
  • Doble click codewhale.bat (no el .exe sin formato) para iniciar
  • Ejecute install.bat para copiar los binarios y el iniciador a %USERPROFILE%\bin
  • Añade %USERPROFILE%\bin a tu RUTA

El archivo portátil de Windows omite el script de instalación: extraiga y ejecute codewhale.bat desde cualquier directorio. El instalador de NSIS actualmente no está firmado y puede activar Windows SmartScreen hasta que se conecte un certificado de firma al proceso de lanzamiento.

Cada plataforma también tiene codewhale-<platform> desnudo y sin archivar y Activos codew-<platform>. Los siete nombres de archivos codewhale-tui-<platform> adjuntas a v0.9.5 son copias de compatibilidad de bytes idénticos que se utilizan únicamente para permitir v0.9.4 clients ya instalado descubre y cruza este binario único transición; Los instaladores actuales no exponen un tercer tiempo de ejecución. El legado de la npm El paquete deepseek-tui está en desuso y no se vuelve a publicar. Para la migración de los nombres binarios heredados v0.8.x, consulte docs/REBRAND.md.

Verificar (recomendado)

Descargue los manifiestos de suma de comprobación de esta versión y verifique:

# Linux — archive bundles
sha256sum -c codewhale-bundles-sha256.txt --ignore-missing

# Linux — individual binaries
sha256sum -c codewhale-artifacts-sha256.txt --ignore-missing

# macOS
shasum -a 256 -c codewhale-bundles-sha256.txt --ignore-missing
shasum -a 256 -c codewhale-artifacts-sha256.txt --ignore-missing
