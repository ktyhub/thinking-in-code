Código ballena v0.8.67

CodeWhale es el proyecto canónico, el comando, el paquete npm y nombre del activo de liberación. El paquete npm heredado deepseek-tui es está en desuso y no recibe más versiones. Usuarios provenientes de Los nombres deepseek / deepseek-tui heredados de v0.8.x deben migrar con docs/REBRAND.md.

Instalar

Recomendado: npm (un comando, ambos binarios)

npm install -g codewhale

El contenedor descarga los archivos binarios de tiempo de ejecución coincidentes de esta versión y los coloca en el mismo directorio.

Docker / GHCR

docker run --rm -it \
  -e DEEPSEEK_API_KEY="$DEEPSEEK_API_KEY" \
  -v ~/.deepseek:/home/codewhale/.deepseek \
  ghcr.io/hmbown/codewhale:v0.8.67

La imagen incluye el despachador codewhale, la cuña codew y el tiempo de ejecución codewhale-tui. La etiqueta latest también se actualiza en el momento del lanzamiento.

Carga (Linux / macOS)

cargo install codewhale-cli codewhale-tui --locked

Se requieren ambas cajas: codewhale-cli produce el despachador codewhale y la cuña codew, mientras que codewhale-tui produce el tiempo de ejecución interactivo en el que delega el despachador. La instalación de solo una caja fallará en tiempo de ejecución con un error MISSING_COMPANION_BINARY.

Descarga manual: archivos de plataforma (recomendado)

Cada archivo a continuación contiene el despachador codewhale, el shim codew y el tiempo de ejecución codewhale-tui, además de un script de instalación: | Plataforma | Archivo | Instalar script | |---|---|---| | Linux x64 | codewhale-linux-x64.tar.gz | install.sh | | Linux ARM64 | codewhale-linux-arm64.tar.gz | install.sh | | MacOS x64 | codewhale-macos-x64.tar.gz | install.sh | | BRAZO macOS | codewhale-macos-arm64.tar.gz | install.sh | | Windows x64 (instalador) | CodeWhaleSetup.exe | Configuración de NSIS | | Ventanas x64 | codewhale-windows-x64.zip | install.bat | | Windows x64 (portátil) | codewhale-windows-x64-portable.zip | — | Unix (Linux/macOS):

tar xzf codewhale-<platform>.tar.gz
cd codewhale-<platform>
./install.sh

Windows:

  • Para la ruta del instalador, ejecute CodeWhaleSetup.exe; instala codewhale.exe, codew.exe y codewhale-tui.exe en %LOCALAPPDATA%\Programs\CodeWhale\bin y agrega ese directorio a la RUTA del usuario actual.
  • Extracto codewhale-windows-x64.zip
  • Ejecute install.bat (copias a %USERPROFILE%\bin)
  • Añade %USERPROFILE%\bin a tu RUTA El archivo portátil de Windows omite el script de instalación: extráigalo y ejecútelo desde cualquier directorio. El instalador de NSIS actualmente no está firmado y puede activar Windows SmartScreen hasta que se conecte un certificado de firma al proceso de lanzamiento. Cada plataforma también tiene binarios básicos y sin archivar adjuntos a continuación (codewhale-<platform>, codew-<platform> y codewhale-tui-<platform>): el contenedor npm y el codewhale update en la aplicación descargan los binarios de tiempo de ejecución coincidentes, mientras que los archivos .tar.gz / .zip anteriores son la descarga manual recomendada y, además, incluyen un script de instalación. El paquete npm heredado deepseek-tui está obsoleto y no se vuelve a publicar. Para la migración desde nombres binarios heredados v0.8.x, consulte docs/REBRAND.md.

  • Endurecimiento de MCP client: cerró un SSRF de punto final SSE, limitó el HTTP cuerpo de respuesta a través de Content-Length en lugar de una lectura en streaming, stdio limitado lecturas de línea para evitar la denegación de servicio de OOM, se corrigió un tiempo de espera inactivo y eliminó un búfer ilimitado.
  • Se hicieron las reglas execpolicy deny/trust conscientes del segmento, cerrando una cadena de comandos derivación.
  • Derivaciones cerradas de la ley de repos y del piso de seguridad encontradas mediante revisión contradictoria: Las invariantes protegidas ahora se aplican como mecanismo, la brecha del destructor en el piso de seguridad está cerrado, una herramienta presente en el catálogo sin ruta de ejecución ahora falla cerrado, web_run abierto/click se clasifica como destructivo, y la lista de permitidos obtuvo comodines y manejo de casos.
  • Se rechazaron directorios de reglas con enlaces simbólicos para evitar el escape del espacio de trabajo a través de reglas descubiertas. Contribuido por arce (@yekern).
  • Salida del trabajador del sub-agente de Bounded Fleet para que la distribución no pueda agotar la memoria de TUI (#3882) y se conservó el margen de evento para el progreso. Contribuido en parte por @cyq1017.
  • Se agregó una puerta de borrador de constitución no trust con procedencia de autoría para que las constituciones redactadas como modelo requieren una ratificación humana explícita.

Eliminado

  • Se eliminaron los ayudantes de registro de modelos no utilizados. Cosechado del n.° 3872 por @ cyq1017.
  • Se eliminaron los metadatos de ajuste de solicitudes no utilizados. Cosechado del n.° 3871 por @ cyq1017.
  • Se eliminaron los ayudantes de tareas de flota muertos (#3894 por @cyq1017), los no utilizados contenedor de caché de aprobación (#3845) y metadatos de control de calidad de localización (ambos por @nightt5879), el subsistema de colaboración de pestañas inactivo (#3838), el legado enrutador automático flash (#3839), el cargador obsoleto de project_doc (#3840), ignorado marcadores de posición LLM simulados (#3841), ayudantes de catálogo de modelos muertos (#3842), el módulo de modificación de execpolicy no utilizado y ayudantes de reintento MCP/client inactivos.
  • Se eliminó el respaldo de contexto WHALE.md en desuso (#3798).
