Código ballena v0.9.6

Codewhale es el producto público de Shannon Labs. El codewhale Los nombres de comando, paquete npm y activos de lanzamiento permanecen en minúsculas técnicas identificadores. El paquete npm heredado deepseek-tui está en desuso y no recibe más comunicados. Usuarios provenientes del legado v0.8.x deepseek / Los nombres deepseek-tui deben migrar con docs/REBRAND.md.

Instalar

Recomendado: npm (un comando, ambos puntos de entrada)

npm install -g codewhale

El contenedor descarga los recursos de comando codewhale y codew coincidentes. de esta versión. Ambos contienen el mismo tiempo de ejecución compilado.

Docker / GHCR

docker run --rm -it \
  -e DEEPSEEK_API_KEY="$DEEPSEEK_API_KEY" \
  -v codewhale-home:/home/codewhale/.codewhale \
  ghcr.io/hmbown/codewhale:v0.9.6

La imagen muestra el mismo tiempo de ejecución que codewhale y codew. el La etiqueta latest también se actualiza en el momento del lanzamiento.

Carga (Linux / macOS)

cargo install codewhale-cli --locked

El paquete Cargo instala codewhale. Cargo no puede crear un segundo comando alias de un objetivo binario; los usuarios que quieran una ortografía más corta pueden agregar una Enlace simbólico codew a ese ejecutable instalado. El npm, Homebrew, archivo, El instalador de shell y los canales de contenedor instalan ambos nombres de comando directamente.

Descarga manual: archivos de plataforma (recomendado)

Cada archivo a continuación contiene el mismo tiempo de ejecución bajo codewhale y Nombres de los comandos codew, además de un script de instalación:

| Plataforma | Archivo | Instalar script | |---|---|---| | Linux x64 | codewhale-linux-x64.tar.gz | install.sh | | Linux ARM64 | codewhale-linux-arm64.tar.gz | install.sh | | Android ARM64 (Termux) | codewhale-android-arm64.tar.gz | install.sh | | MacOS x64 | codewhale-macos-x64.tar.gz | install.sh | | BRAZO macOS | codewhale-macos-arm64.tar.gz | install.sh | | Windows x64 (instalador) | CodeWhaleSetup.exe | Configuración de NSIS | | Ventanas x64 | codewhale-windows-x64.zip | install.bat | | Windows x64 (portátil) | codewhale-windows-x64-portable.zip | — | | Ventanas ARM64 | codewhale-windows-arm64.zip | install.bat | | Windows ARM64 (portátil) | codewhale-windows-arm64-portable.zip | — |

Unix (Linux/macOS):

tar xzf codewhale-<platform>.tar.gz
cd codewhale-<platform>
./install.sh

Windows:

  • Para la ruta del instalador, ejecute CodeWhaleSetup.exe; se instala codewhale.exe y codew.exe bajo %LOCALAPPDATA%\Programs\CodeWhale\bin y agrega ese directorio al RUTA del usuario actual.
  • Extraiga el archivo de su máquina: codewhale-windows-x64.zip o codewhale-windows-arm64.zip
  • Ejecute install.bat (copias a %USERPROFILE%\bin)
  • Añade %USERPROFILE%\bin a tu RUTA

El archivo portátil de Windows omite el script de instalación: extráigalo y ejecútelo desde cualquier directorio. El instalador de NSIS actualmente no está firmado y puede activar Windows SmartScreen hasta que se conecte un certificado de firma al proceso de lanzamiento.

Cada plataforma también tiene codewhale-<platform> desnudo y sin archivar y Activos codew-<platform>. Los siete nombres de archivos codewhale-tui-<platform> adjuntas a v0.9.5 son copias de compatibilidad de bytes idénticos que se utilizan únicamente para permitir v0.9.4 clients ya instalado descubre y cruza este binario único transición; Los instaladores actuales no exponen un tercer tiempo de ejecución. El legado de la npm El paquete deepseek-tui está en desuso y no se vuelve a publicar. Para la migración de los nombres binarios heredados v0.8.x, consulte docs/REBRAND.md.

¿Qué hay en v0.9.6?

Codewhale v0.9.6 es una versión sustractiva: menos guardias de tiempo de ejecución, uno estable terminaciones de proveedor rápidas y confiables, y una ruta de compactación más pequeña que preserva la caché del proveedor. Los cambios se basaron en el Terminal-Bench 2.1 combinado corre contra Pi 0.8.41 y mediante compactación manual repetida mediante prueba automática.

Agregado

  • web_search tiene como valor predeterminado Firecrawl Cloud sin una clave API; solicitudes sin llave no tienen encabezado y están limitados por cuotas, mientras que una clave de usuario opcional aumenta los límites.
  • Las compilaciones web ecológicas en main ahora emiten un recordatorio de implementación manual procesable, por lo que Los cambios en el sitio no pueden aparecer silenciosamente mientras Cloudflare todavía ofrece un servicio. revisión anterior.
  • Mistral AI es una ruta de proveedor de primera clase, incluidos los modelos Codestral, soporte de razonamiento propio, autenticación, entradas de selector y alias.
  • El Bash sin cabeza puede transferir servicios Unix persistentes solicitados explícitamente fuera de una ejecución ejecutiva, con recibos de propiedad y limpieza.
  • /remote-env abre el trabajo alojado desde la sugerencia de sucursal actual GitHub o CNB y indica exactamente qué estado no activado, sucio, ignorado, secreto y de sesión permanece locales.
  • La versión Linux ARM64 y los activos nocturnos son compilaciones estáticas y nativas controles de lanzamiento.
  • Los mantenedores pueden informar las instalaciones activas diarias observadas desde el mismo anónimo, conjunto de datos de telemetría agregados; no se recopilan datos adicionales de client.
  • Miembros enviados por flotas ahora bajo un límite de evidencia de solo lectura (sin red) mantener las acciones search y fetch de solo lectura de la herramienta Web: paridad con un explorador ordinario, mientras que cada superficie de alcance (web.run, fetch_url, github, MCP) permanece denegado y el sobre de capacidad respaldado por centinela sigue siendo el respaldo cerrado ante fallos.
  • /fleet setup puede mostrar un modelo a seguir opcional, determinista y no ratificado. aviso creado solo a partir de rutas listas configuradas. Aceptar, editar y rechazar todos permanecen dentro del límite de guardado del perfil existente revisado por humanos; el El aviso nunca lanza una flota ni escribe una segunda configuración.
  • /update busca una versión más reciente de Codewhale y la instala desde adentro la TUI, mientras que tui_help brinda a los agentes el mismo comando y mapa de claves que ven los usuarios.
  • Las rutas de los archivos Markdown se representan como enlaces OSC 8 cuando el terminal las admite. y cada fila de agente puede abrir la transcripción de ese agente directamente.
  • Las sesiones del editor ACP pueden ejecutar archivos de múltiples rondas, búsqueda, Git, parches y Habilitó explícitamente las llamadas a la herramienta Shell a través del registro de tiempo de ejecución compartido. El acceso al Shell requiere tanto la capacidad del terminal del client como la de Codewhale. la suscripción sin cabeza del shell y la cancelación detiene una herramienta en vuelo antes de que retornos de turno (#5225 por @rafaelcavalheri).
  • read en minúsculas devuelve resultados PNG, JPEG, GIF y WebP con tipos acotados a Rutas de chat, respuestas, antrópicas y ACP con capacidad de imagen. Rutas de solo texto recibir un recibo de omisión explícita; Los bytes de imagen nunca se derraman en lo normal. transcribir, exportar, compactar o retransmitir texto.

Cambiado

  • El recuento de uso anónimo está activado de forma predeterminada para instalaciones nuevas y se divulga en un modal nativo de Codewhale de primera ejecución con opción de exclusión inmediata. Antes declines permanecer apagado. Codewhale no recopila conversaciones, códigos, indicaciones, archivos, nombres de repositorios o sucursales, credenciales, contenido del modelo o actividad por turno líneas de tiempo.
  • Los terminales anchos utilizan un lienzo oceánico responsivo de pantalla completa con modestos Canalones: la prosa mantiene una medida legible mientras que las herramientas, diferenciales, superficies de trabajo, el compositor y el estado de Chrome pueden usar el ancho disponible. Giro y mayor Las costuras de actividad respiran sin rellenar cada llamada dentro de un grupo de herramientas.
  • La ayuda raíz CLI describe las acciones del producto directamente en lugar de exponer información interna. TUI/capas de tiempo de ejecución.
  • Bash action="wait" ahora bloquea de forma predeterminada cuando se solicita una espera; personas que llaman aún puede solicitar una instantánea sin bloqueo y propiedad persistente del servicio sigue siendo explícito.
  • La compactación es una solicitud de resumen estable en caché seguida de una confirmada. resumen de reemplazo y una cola de mensajes recientes acotada. Sesiones guardadas más antiguas todavía restaurar.
  • Preguntar, Trabajar, Revisión automática y Acceso completo comparten un mensaje base estable. Modos continúan diferenciándose a través de los permisos y el catálogo de herramientas en vivo; el primero La etiqueta de acto ahora es Funciona en todo el producto y en las ubicaciones de envío.
  • Acceso total ahora aprueba automáticamente herramientas que no se pueden omitir de manera consistente, y el La opción predeterminada que se muestra en las tarjetas de aprobación ordinarias es configurable.
  • Informe de recibos de generación de modelo, ventana de contexto, nombre de envío y agente anidado la ruta y los límites realmente utilizados en lugar de sustituir silenciosamente una identidad adivinada.
  • El agente infantil lanza un recibo de ruta inmutable antes de la admisión y conservarlo a través del estado, interrupción, finalización, reanudación, gráfico de trabajo, y proyecciones del libro mayor, para que la atribución de proveedor/modelo no pueda variar (#5305).
  • Las carreras de objetivos ya no se detienen debido a una continuación interna, una brecha repetida o guardias con preguntas sin respuesta. Límites de usuario explícitos y estados de objetivos terminales seguir siendo autoritario.
  • El control remoto /rc de propiedad de la cuenta ahora mantiene la propiedad exclusiva y un diario de entrega recuperable por fallas hasta que el servidor reconozca la terminal, aprobación, falla y estado de la instantánea.
  • todo_write es una superficie de progreso opcional en lugar del modelo requerido ceremonia.
  • Los nuevos turnos utilizan una caja de herramientas pequeña y estable: read, write, edit, bash, agent, todo_write y tool_search. La herramienta de progreso opcional permanece visible como memoria de trabajo familiar; nativo especializado, web, MCP, complemento, las herramientas de memoria, tareas y verificación están filtradas por políticas y permiten realizar búsquedas; los esquemas activados permanecen en una caché limitada por conversación. Cada subagente mantiene su propia búsqueda y caché, incluida la investigación web permitida por políticas, mientras El contexto bifurcado y las activaciones de los padres siguen siendo comienzos en caliente en lugar de listas permitidas.
  • Los esquemas de archivo directo y shell siguen el contrato deliberadamente pequeño de Pi: lecturas de línea completa limitadas, escrituras sin hash, edición múltiple inequívoca con Preservación de BOM/CRLF y coincidencia difusa conservadora, y un primer plano Comando bash con cola de salida cronológica acotada. Los modos cambian autoridad de ejecución, no esos nombres primitivos.
  • Codewhale ya no vuelve a indicar la lista de tareas pendientes al modelo. El modelo aprende lo que está en la lista del resultado de la herramienta devolvió su propia llamada todo_write, que es el historial de conversación ordinario, de la misma manera que funciona Pi's To-do. el bloque transitorio <codewhale:work_state> que solía montar la cola de cada El bucle de giro principal y la solicitud de paso del subagente desaparecieron, junto con el estable. El prefijo del sistema se ve afectado por cambios en la lista. Una instantánea todavía se muestra una vez, donde una persona lo pidió: el <codewhale:fork_state> bloquea un recién bifurcado se entrega el subagente, las instrucciones de transferencia /relay y la tarjeta de agente. el La tarea pendiente completa permanece visible en la interfaz de usuario. Una prueba estructural afirma que es real Los organismos de solicitud de proveedores salientes no llevan la lista.
  • Scout y Reviewer nombran los roles de investigador de solo lectura. Ambos exponen exactamente un punto de entrada al shell: minúscula canónica bash, delimitada por el estricto clasificador de solo lectura, y el alias heredado Bash permanece denegado en el catálogo y al momento del envío. Anteriormente, una coincidencia de nombre que no distinguía entre mayúsculas y minúsculas permitía que una llamada se deletreara Bash se ejecuta a través de esa exclusión, devolviendo el shell sin formato a una función de solo lectura.

Fijado

  • Ahora se mueve el envío de más contexto mientras se ejecuta un comando bash en minúsculas. el comando a /jobs y devuelve un recibo de ejecución exitosa en lugar de informar falsamente Command exited with code -1; el proceso sigue funcionando y su finalización aún llega a través del evento de tiempo de ejecución normal.

  • La divulgación de uso de primera ejecución ahora se abre como un modal nativo de Codewhale en lugar de un cuestionario de shell antes del inicio de la aplicación. La telemetría sigue desarmada hasta que se realiza la elección nativa y una opción de Desactivación en memoria gobierna la sesión actual incluso cuando su preferencia no se puede guardar.

  • Los resultados de finalización, error, en cola, duplicado y buzón de /compact son recibos de transcripciones duraderos en lugar de brindis de corta duración. Una terminal perdida El evento ya no puede dejar todas las compactaciones posteriores estancadas como si ya estuvieran en ejecución.

  • La compactación ahora sigue la forma de transcripción simple del Codex: contexto de usuario reciente seguido de un punto de control de historia ordinario. Nunca agrega el resumen, la lista de tareas pendientes o el estado volátil de shell/trabajador en el indicador permanente del sistema; Las recargas migran el operador persistente de nuevo a exactamente un elemento del historial.

  • La compactación automática utiliza un porcentaje de la ventana de contexto real, sujeta a el techo gastable de la ruta. La presión proviene de la ruta principal actual. facturación inmediata, no acumulativa, ni uso de modelo infantil.

  • Compactación, revisión, verificación, enrutamiento, configuración, flota, MCP, RLM, visión, traducción, y las llamadas de subagente heredan la salida normal de la ruta resuelta, muestreo y política de razonamiento. Ya no hay límites de tokens de tareas internas pequeñas truncar rutas de pensamiento o proveedores individuales de casos especiales.

  • Las respuestas incompletas del proveedor fallan verdaderamente en los turnos normales y en cada Consumidor del modelo interno. El texto parcial permanece interrumpido, las llamadas a herramientas pendientes sí lo hacen no se ejecuta y se conserva el uso facturado.

  • Los marcadores de posición (reasoning omitted) de solo transporte ya no ingresan nuevos transcripciones y se filtran de las sesiones restauradas. Razonamiento expandir/colapsar las acciones permanecen adjuntas a la celda renderizada exacta, incluso después del reemplazo, restaurar, filtrar y cambiar el tamaño (#5291).

  • El agotamiento del presupuesto de pasos es una falla escrita y no puede liberar un pendiente. servicio persistente. La cancelación después del uso de la terminal aún cobra el turno.

  • Las herramientas diferidas ahora conservan un resultado completo cuando un proveedor reutiliza su ID de llamada de herramienta en el turno de reintento, lo que evita que se realicen llamadas exitosas al complemento. entrando en un ciclo de ejecución repetido.

  • Configuración del sitio web, proveedor, diagnóstico, flota y reclamos de tiempo de ejecución único ahora coincide con el candidato fuente.

  • Abrir el registro de subagente ya no oculta la lista de tareas pendientes: los Agentes El panel muestra el registro completo y la lista de verificación duradera juntos, y el El encabezado del registro es una puerta de dos vías que regresa a Tareas en un segundo click.

  • El acorde de detalles ⌥V / Alt+V abre la propia fila de la superficie de trabajo seleccionada. inspector en lugar de la celda de herramienta más cercana de la transcripción, por lo que una La fila de tareas pendientes muestra su propio contenido en lugar del razonamiento más reciente.

  • La divulgación de uso de primera ejecución ahora plantea una pregunta clara: "Ayude a mejorar ¿Código ballena?" — con un claro "Sí, mantener recuentos anónimos" / "No, apagar opciones de seguimiento" en cada lugar de envío y establece la opción de exclusión persistente comando. La semántica del consentimiento no ha cambiado: la telemetría permanece desarmada hasta que se se hace la elección.

  • Las capturas de pantalla de macOS a las que se hace referencia en un mensaje se copian a un directorio de archivos adjuntos estables en el momento en que se recibe el mensaje, y el La referencia se reescribe en la ruta estable, por lo que la imagen todavía existe cuando el agente lo lee. Sólo archivos bajo una captura de pantalla "Elementos temporales" se toca el directorio; Las copias son idempotentes y una copia fallida mantiene la referencia original.

  • El manual /compact durante un giro activo ahora se pone en cola incluso cuando el motor está El buzón de operaciones delimitado está saturado. La solicitud difiere client-side, reintenta como las ranuras del buzón están libres y no se pueden cerrar porque ya se están ejecutando después de que se asiente.

  • Se conservan las rutas de selección interactivas /load, inicio --resume y /resume la identidad persistente del proveedor, el punto final y el modelo; currículum del selector también deja un recibo de transcripción duradero.

  • Los valores relativos de mcp_config_path ya no dependen del directorio de inicio o cargar silenciosamente un grupo de servidores vacío: Codewhale advierte y recurre al configuración MCP global de usuario. Los caminos absolutos explícitos siguen teniendo autoridad.

  • Alibaba Model Studio qwen3.8-max y qwen3.8-max-preview aún se transmiten su razonamiento actual, pero ya no reproduce el histórico reasoning_content que esas rutas no aceptan. La repetición del razonamiento histórico ahora está controlada por el contrato exacto del proveedor/API/modelo, por lo que se desconocen los parecidos del *-thinking falla cerrada mientras están documentados Qwen, Kimi, DeepSeek, Mistral, Anthropic y Las reglas de continuidad de las respuestas permanecen intactas.

  • Las llamadas de archivo/parche de compatibilidad conservan protectores de hash de contenido opcionales cuando la persona que llama los proporciona. Los nuevos esquemas directos write y edit no exponen hachís o ceremonia de lectura previa.

  • Las vistas previas de Shell retienen secuencias UTF-8 incompletas en lugar de emitirlas los caracteres de reemplazo y los recibos de compactación informan deltas de tokens.

  • Los agentes anidados pueden reducir, pero nunca ampliar, su presupuesto de profundidad heredado. (#5317 por @ousamabenyounes).

  • La publicación de contenedores ahora ensambla imágenes AMD64 y ARM64 en paralelo en corredores nativos de los binarios de versión estática ya verificados, luego publica y verifica un manifiesto de arquitectura múltiple. Ya no se reconstruye ambos objetivos a través del único trabajo QEMU de larga duración que perdió a su corredor.

Eliminado

  • La estrategia de guardia sin progreso, guardia de lectura repetida y error de herramienta inyectada entrenamiento. Encuestas productivas, inspecciones repetidas y recuperación de propiedad del modelo ya no son interrumpidos por las heurísticas del tiempo de ejecución.
  • Tarjeta de decisión, combinación de teclas, desplazamiento, ejecución de shell, funcionamiento del motor y Las rutas de script de lanzamiento se eliminaron para que el tiempo de ejecución admitido tenga una ruta para cada conducta.
