código ballena v0.9.3

Codewhale es el producto público de Shannon Labs. El codewhale Los nombres de comando, paquete npm y activos de lanzamiento permanecen en minúsculas técnicas identificadores. El paquete npm heredado deepseek-tui está en desuso y no recibe más comunicados. Usuarios provenientes del legado v0.8.x deepseek / Los nombres deepseek-tui deben migrar con docs/REBRAND.md.

Instalar

Recomendado: npm (un comando, los tres puntos de entrada)

npm install -g codewhale

El contenedor descarga los codewhale, codew y codewhale-tui coincidentes. binarios de esta versión y los coloca en el mismo directorio.

Docker / GHCR

docker run --rm -it \
  -e DEEPSEEK_API_KEY="$DEEPSEEK_API_KEY" \
  -v codewhale-home:/home/codewhale/.codewhale \
  ghcr.io/hmbown/codewhale:v0.9.3

La imagen incluye el despachador codewhale, la cuña codew y el tiempo de ejecución codewhale-tui. La etiqueta latest también se actualiza en el momento del lanzamiento.

Carga (Linux / macOS)

cargo install codewhale-cli codewhale-tui --locked

Se requieren ambas cajas: codewhale-cli produce el despachador codewhale y la cuña codew, mientras que codewhale-tui produce el tiempo de ejecución interactivo en el que delega el despachador. La instalación de solo una caja fallará en tiempo de ejecución con un error MISSING_COMPANION_BINARY.

Descarga manual: archivos de plataforma (recomendado)

Cada archivo a continuación contiene el despachador codewhale, el shim codew y el tiempo de ejecución codewhale-tui, además de un script de instalación: | Plataforma | Archivo | Instalar script | |---|---|---| | Linux x64 | codewhale-linux-x64.tar.gz | install.sh | | Linux ARM64 | codewhale-linux-arm64.tar.gz | install.sh | | Android ARM64 (Termux) | codewhale-android-arm64.tar.gz | install.sh | | MacOS x64 | codewhale-macos-x64.tar.gz | install.sh | | BRAZO macOS | codewhale-macos-arm64.tar.gz | install.sh | | Windows x64 (instalador) | CodeWhaleSetup.exe | Configuración de NSIS | | Ventanas x64 | codewhale-windows-x64.zip | install.bat | | Windows x64 (portátil) | codewhale-windows-x64-portable.zip | — | | Ventanas ARM64 | codewhale-windows-arm64.zip | install.bat | | Windows ARM64 (portátil) | codewhale-windows-arm64-portable.zip | — | Unix (Linux/macOS):

tar xzf codewhale-<platform>.tar.gz
cd codewhale-<platform>
./install.sh

Windows:

  • Para la ruta del instalador, ejecute CodeWhaleSetup.exe; instala codewhale.exe, codew.exe y codewhale-tui.exe en %LOCALAPPDATA%\Programs\CodeWhale\bin y agrega ese directorio a la RUTA del usuario actual.
  • Extraiga el archivo para su máquina: codewhale-windows-x64.zip o codewhale-windows-arm64.zip
  • Ejecute install.bat (copias a %USERPROFILE%\bin)
  • Añade %USERPROFILE%\bin a tu RUTA El archivo portátil de Windows omite el script de instalación: extráigalo y ejecútelo desde cualquier directorio. El instalador de NSIS actualmente no está firmado y puede activar Windows SmartScreen hasta que se conecte un certificado de firma al proceso de lanzamiento. Cada plataforma también tiene binarios básicos y sin archivar adjuntos a continuación (codewhale-<platform>, codew-<platform> y codewhale-tui-<platform>): el contenedor npm y el codewhale update en la aplicación descargan los binarios de tiempo de ejecución coincidentes, mientras que los archivos .tar.gz / .zip anteriores son la descarga manual recomendada y, además, incluyen un script de instalación. El paquete npm heredado deepseek-tui está en desuso y no se vuelve a publicar. Para la migración desde nombres binarios heredados v0.8.x, consulte docs/REBRAND.md.

Verificar (recomendado)

Descargue los manifiestos de suma de comprobación de esta versión y verifique:

# Linux — individual binaries
sha256sum -c codewhale-artifacts-sha256.txt --ignore-missing

# macOS
shasum -a 256 -c codewhale-bundles-sha256.txt --ignore-missing
shasum -a 256 -c codewhale-artifacts-sha256.txt --ignore-missing

¿Qué hay en v0.9.3?

Este es el candidato fuente Codewhale v0.9.3. No es un comunicado publicado. hasta que existan la etiqueta, los paquetes, las sumas de verificación y los activos de versión coincidentes. DeepSeek V4 Flash es ahora una ruta Codewhale de primera clase, y el agente La superficie de la herramienta se ha reducido a las herramientas de acción canónicas que actualmente los modelos realmente necesitan. Esta versión también refuerza las credenciales, la autorización, durabilidad, compactación y límites del proveedor de archivos macOS al eliminar tiempo de ejecución obsoleto y superficie de dependencia.

Agregado

  • Compatibilidad nativa con deepseek-v4-flash sobre Responses API de DeepSeek, incluido repetición de elementos de razonamiento sin estado, eventos terminales SSE semánticos, estructurados llamadas y salidas de funciones, apply_patch y formato de cable compatible con el modelo selección. Los ID de Flash actuales exactos utilizan Respuestas; futuro directo Los ID del modelo deepseek-vN-* heredan esa ruta de manera conservadora, mientras que los personalizados Los puntos finales compatibles con DeepSeek conservan las finalizaciones de chat a menos que se configuren de lo contrario.
  • Una transferencia codewhale auth print-api-key de solo tubería para seleccionados explícitamente proveedores. Comparte la autoridad de credenciales de ámbito interno de Codewhale, pero se niega salida del terminal y evita que los marcadores de posición centinela se activen credenciales.
  • Aplicación de max_tool_calls por turno en la puerta de admisión del motor, además de un alcance de escritura de archivos con nombre con una costura de lectura separada. El tiempo de ejecución ahora rechaza llamadas por encima del presupuesto antes de la ejecución y mantiene el límite de escritura del operador explícito (#4415).
  • Trinquetes de contrato de tiempo de ejecución, estructura de fuente y acumulación de persistencia que deriva de nombres en lugar de permitir que grandes superficies de propiedad crezcan silenciosamente (#3921, #4785).

Cambiado

  • Las funciones integradas visibles en el modelo ahora utilizan los canónicos Bash, File y Run. esquemas de acción. apply_patch sigue estando disponible como personalizado directo herramienta de edición compatible con DeepSeek Responses. El flujo de trabajo incluido para detener el envío, Los accesorios de flota, los atajos de shell y las pruebas de motor utilizan el mismo canónico vocabulario.
  • Las solicitudes canónicas File { action: "write" } ahora pasan por el mismo verificaciones semánticas de leyes de repositorio como la ruta de escritura anterior. Aprobación, acceso completo, y la ejecución del flujo de trabajo no puede eludir el piso de seguridad del repositorio eligiendo El esquema canónico.
  • La resolución del hogar de Codewhale se comparte entre CLI, TUI, estado y secreto tiendas. doctor está fuera de línea de forma predeterminada, distingue la fuente de credenciales de disponibilidad e informa una instantánea de ruta coherente.
  • Las escrituras duraderas de eventos en tiempo de ejecución se serializan en procesos simultáneos. las esperas del historial de bloqueo desplazan a los trabajadores asíncronos y el agotamiento de la cuota del proveedor permanece escrito y reintentable mediante compactación (#4522).
  • El descubrimiento de habilidades almacena en caché el catálogo fusionado detrás de la validación del tiempo observado; Grandes bloques de pruebas de habilidades, motores, subagentes, UI y ambiente-océano ahora se encuentran en Costuras de prueba propias.
  • Los resúmenes de razonamiento permanecen en el idioma del usuario, medusas completas. las siluetas se reubican alrededor del texto de la transcripción y los marcos oceánicos almacenados en caché incluyen su identidad de paleta (#4807).
  • El contrato de autorización-orden ahora documenta y prueba cómo los modos, ganchos, reglas de permisos, pisos de seguridad, ley de repos, aprobaciones y sandboxing componen (PR #4980).

Fijo

  • Las extensiones de zona de pruebas de macOS cubren espacios de trabajo de CloudStorage/File Provider sin ampliar caminos no relacionados; gracias @Watcher24 por el informe #4085 y reproducción.
  • El estado del caparazón en primer plano se separa antes de girar, por lo que se interrumpe el comando. no puede seguir siendo propietario del compositor (PR #4979).
  • Fallas a nivel de aplicación MCP y sobres de error con formato incorrecto no se cierran en lugar de parecer un resultado de herramienta exitoso.
  • Las fallas de PDF opcionales son veraces y la clasificación de PDF ya no falla entradas admitidas.
  • Los contenidos pegados entre corchetes se eliminan de los seguimientos y los diagnósticos de credenciales. Nunca trate a los centinelas marcadores de posición como claves utilizables.

Eliminado

  • Los alias invocables heredados exec_shell, run_shell_command, read_file, write_file, list_dir, grep_files, file_search y el duplicado Altas de obra/RLM. La transcripción histórica y la semántica de las políticas permanecen legible, pero los nuevos modelos reciben solo la superficie de acción canónica.
  • La cadena de dependencia del analizador de PDF incluida, reemplazándola por la más pequeña Límite de extracción opcional rastreado por #4382.
