Código ballena v0.9.9

Codewhale es el producto público de Shannon Labs. El codewhale Los nombres de comando, paquete npm y activos de lanzamiento permanecen en minúsculas técnicas identificadores. El paquete npm heredado deepseek-tui está en desuso y no recibe más comunicados. Usuarios provenientes del legado v0.8.x deepseek / Los nombres deepseek-tui deben migrar con docs/REBRAND.md.

Instalar

Recomendado: npm (un comando, ambos puntos de entrada)

npm install -g codewhale

El contenedor descarga los recursos de comando codewhale y codew coincidentes. de esta versión. Ambos contienen el mismo tiempo de ejecución compilado.

Docker / GHCR

docker run --rm -it \
  -e DEEPSEEK_API_KEY="$DEEPSEEK_API_KEY" \
  -v codewhale-home:/home/codewhale/.codewhale \
  ghcr.io/hmbown/codewhale:v0.9.9

La imagen muestra el mismo tiempo de ejecución que codewhale y codew. el La etiqueta latest también se actualiza en el momento del lanzamiento.

Carga (Linux / macOS)

cargo install codewhale-cli --locked

El paquete Cargo instala codewhale. Cargo no puede crear un segundo comando alias de un objetivo binario; los usuarios que quieran una ortografía más corta pueden agregar una Enlace simbólico codew a ese ejecutable instalado. El npm, Homebrew, archivo, El instalador de shell y los canales de contenedor instalan ambos nombres de comando directamente.

Descarga manual: archivos de plataforma (recomendado)

Cada archivo a continuación contiene el mismo tiempo de ejecución bajo codewhale y Nombres de los comandos codew, además de un script de instalación:

Unix (Linux/macOS):

tar xzf codewhale-<platform>.tar.gz
cd codewhale-<platform>
./install.sh

Windows:

  • Para la ruta del instalador, ejecute CodeWhaleSetup.exe; se instala codewhale.exe y codew.exe bajo %LOCALAPPDATA%\Programs\CodeWhale\bin y agrega ese directorio al RUTA del usuario actual.
  • Extraiga el archivo de su máquina: codewhale-windows-x64.zip o codewhale-windows-arm64.zip
  • Ejecute install.bat (copias a %USERPROFILE%\bin)
  • Añade %USERPROFILE%\bin a tu RUTA

El archivo portátil de Windows omite el script de instalación: extráigalo y ejecútelo desde cualquier directorio. El instalador de NSIS actualmente no está firmado y puede activar Windows SmartScreen hasta que se conecte un certificado de firma al proceso de lanzamiento.

Cada plataforma también tiene codewhale-<platform> desnudo y sin archivar y Activos codew-<platform>. Los siete nombres de archivos codewhale-tui-<platform> adjuntas a v0.9.5 son copias de compatibilidad de bytes idénticos que se utilizan únicamente para permitir v0.9.4 clients ya instalado descubre y cruza este binario único transición; Los instaladores actuales no exponen un tercer tiempo de ejecución. El legado de la npm El paquete deepseek-tui está en desuso y no se vuelve a publicar. Para la migración de los nombres binarios heredados v0.8.x, consulte docs/REBRAND.md.

¿Qué hay en v0.9.9?

Codewhale v0.9.9 es una versión de verdad y resiliencia: la herramienta Shell ya no puede ya no bloquea una sesión cuando el host se queda sin disco o descriptores, Las ventanas de contexto no verificadas y los límites de salida están etiquetados honestamente en cada superficie, DeepSeek V4 tiene un precio según los niveles publicados de horas punta/fuera de horas pico, SSE UTF-8 falla al cerrarse en todos los dialectos, el seguimiento de la flota es visible, bwrap se activa Elementos esenciales del contenedor y raíces adicionales, la piel dsh monta el paquete perfil, el esquema de la herramienta agent tiene hasta 12 campos y README/sitio web los locales crecen a 18 y 8.

Fijo

  • La herramienta minúscula bash ya no se calza cuando se derrama su salida completa No se puede crear el archivo: un volumen temporal completo o una tabla de descriptores agotada. solía fallar cada llamada - echo ok incluido - con el arnés interno "Error al crear la salida del shell de transmisión" y nunca se recupera hasta que El host fue limpiado. El derrame ahora es el mejor esfuerzo (la cola acotada es todavía se devuelve y el aviso de truncamiento dice por qué la ruta de salida completa es falta), y cualquier falla de generación/transmisión restante nombra a los agotados recurso (disco, descriptores de archivos, memoria) y dice que la próxima llamada es segura para volver a intentarlo (#5465; la cuña que eliminó la sesión 0.9.9 del propietario).
  • Una ruta concreta/límite de producción de oferta ahora supera al conservador Estimación de compatibilidad de 8192 tokens para un modelo no catalogado. Rutas que publicar sin límite de producción permanecer cerrado ante fallas, los límites de modelo documentados permanecen autoritativo, y un límite de ruta nunca puede aumentar el límite solicitado (#5460).
  • Honestidad de la ventana de contexto en cada superficie (#5239, #5441): el Los peldaños model-name hint y fallback de la escalera de la ventana de contexto son conjeturas, y cada superficie que lo representa ahora lo dice: la línea de estado, /status, /config, el mensaje de presión contextual, los chips selectores de modelo, y el inventario de enrutador automático. Las ventanas no verificadas todavía generan presupuestos reales (activador de compactación, medidor de contexto, reserva de salida); simplemente se detienen Leyendo como capacidades cualquiera comprobó. Una ventana analizada desde un _Nk El sufijo del nombre del modelo (qwen3-32b-256k → 256K) ahora es propio model-name hint está por debajo de catalog, porque es más bien optimista. que conservador: un catálogo o un valor informado por el proveedor lo supera. el La anulación de [providers.<name>] context_window sigue siendo la solución difícil y se representa como configured sin marcador.
  • Honestidad del techo de producción (#5440): un modelo de familia antrópica que el catálogo incluye no describir mantiene el piso de mensajes de 64K como su abrazadera y ChatGPT/ La ruta Codex OAuth mantiene su política 4K, pero OutputCeilingSource obtuvo una Sonda unverified para ambos, por lo que los recibos del flujo ejecutivo y el selector de modelo etiquételos unverified/"piso supuesto" en lugar de documented. Abrazadera los valores no cambian.
  • La telemetría predeterminada está visible (#5441): codewhale doctor La sección runtime-posture ganó una fila de estilo telemetry=on (default) con la fuente que lo decidió (cli | env | config | default), y codewhale config get telemetry informa el consentimiento resuelto con su source en lugar de key not found en una máquina cuyos lotes se envían. verdad cambiar solamente; la resolución y el comportamiento permanecen intactos.
  • Flota: la separación del caparazón de solo lectura de un explorador (#5428) ahora es respetada por ambos. la puerta de postura y la envolvente de ejecución, por lo que git log, find | head, npm view y los otros comandos limitados de solo lectura se ejecutan in situ de ser rechazado como "Ejecutado" (#5426). La delegación todavía nunca se amplía autoridad: la prueba de aislamiento de roles y docs/SUBAGENTS.md fijan que un niño no puede exceder la postura de sus padres (#5426, #5435).
  • /rename y /title ahora se aplican a mitad del primer turno: el archivo de sesión sí lo hace. no existe hasta el primer autoguardado, por lo que el cambio de nombre fracasó No encontrado; la ruta compartida ahora prefiere el punto de control por sesión y reconstrucciones desde el estado de la aplicación, con una prueba de regresión PTY a través del vivo bucle de eventos (#5430).
  • integrations dsh plan ya no rechaza el valor predeterminado de DeepSeek Ruta de dialecto de respuestas (deepseek-v4-flash); Respuestas y Las rutas de Mensajes Antrópicos se llevan a través de pi-ai openai-responses / anthropic-messages en lugar de ser aproximado o rechazado; solo se siguen rechazando las URL base con credenciales, con un error que nombra proveedor y modelo (#5434).
  • El costo de la sesión ya no se ubica en unverified_live_pricing cuando el precio está en vivo. no se puede verificar (plano de control 503, solo capacidades de Models.dev) superposiciones): tarifas de respaldo incluidas en documentos de proveedor para DeepSeek V4 familia en Fireworks / OpenCode Zen restaura una figura utilizable, en vivo las filas por proveedor aún ganan y kimi-k3 permanece sin precio hasta que se la tasa publicada existe (#5241; extraída de #5402).
  • Liberar activos: las comprobaciones de actualización de activos release.yml se comparan con las libere el propio started_at del trabajo, por lo que las reejecuciones a nivel de trabajo del paso npm no son Ya no está envenenado por cargas anteriores (#5429).
  • macOS CI: la prueba de recibo de revisión automática agent_focus_pty esperó en un trabajador que ya había completado y corrido el foco del riel; ahora se mantiene el resumen del niño y espera una disputa en vivo resuelta (refs #5056, #5403).
  • Los precios de DeepSeek V4 siguen los niveles publicados de horas pico y valle (pico 01:00–04:00 y 06:00–10:00 UTC; temporada baja es la mitad de la temporada pico) para deepseek-v4-flash y deepseek-v4-pro en USD y CNY, resueltos desde el tiempo registrado de cada turno; las obsoletas filas de un solo nivel subestimaron el costo a ~4×. Porque ahora todas las tarifas directas propias de DeepSeek son ventana de tiempo, el cuadro de mando falla cerrado (missing_recorded_time) en un turno de DeepSeek sin fecha en lugar de adivinar un nivel (#5470; #5241 seguimiento, verificado contra api-docs.deepseek.com el 2026-08-17).
  • SSE UTF-8 dividido en tramas de DATOS HTTP/2 ahora falla al cerrarse en cada dialecto de transmisión: un decodificador estricto compartido, cola de descarga y La propagación decode_failed (InvalidSseUtf8) reemplaza el por dialecto aproximaciones, con pruebas de decodificador de fragmentos de bytes (#5374; reemplaza el borrador #5404). -CI: release_four_read_only_fleet_roles_launch_with_canonical_prompts respondieron los niños de Fleet con SSE mientras llaman a la ruta de bloqueo JSON; Se volvió a intentar el error de análisis y se contó dos veces al trabajador en macOS lento. corredores (#5471; refs #5056).
  • Contexto: cada superficie de herramienta web (Web, web_search, web.run, fetch_url) ahora usa el límite suave de resultados ruidosos, por lo que las recuperaciones grandes son compactado como la salida de shell en lugar de consumir el límite rígido ordinario (#5474, gracias @h3c-hexin).
  • Enrutamiento: un selector guardado en minúsculas como glm-5.2 se resuelve contra el poseer la fila del catálogo Z.ai / DeepSeek (repliegue de mayúsculas y minúsculas, solo cuando exactamente una identificación de cable propiedad del proveedor coincide) en lugar de clasificarse como otro modelo básico del proveedor (#5475, gracias @h3c-hexin; diagnóstico por @asto18089 en Pinvou/CodeWhale#14).
  • Catálogo de modelos actualizado a partir del 2026-08-17 contra el oficial páginas de precios: tarifas gpt-5.6-terra / gpt-5.6-luna, claude-sonnet-5 mantiene $2/$10 (el aumento anunciado en septiembre fue retirado), claude-opus-5 agregado, kimi-k3 y kimi-k2.7-code-highspeed, MiniMax-M2.7-highspeed, Filas propias de Mistral, xAI grok-4.5 / grok-4.3 con contexto largo niveles, límites de Gemini y Qwen, y la vista previa de dots3-note de RedNote como Fila OpenRouter (aún no existe ningún API propio): cada número lleva su fuente y una prueba fijada (#5485).
  • Sitio web: copia en codewhale.net reescrita en oraciones declarativas sencillas. una idea por oración, números de los hechos generados, sin autonarración — con una hoja de voz en docs/design/WEB_VOICE.md (#5483).
  • CI: los flujos de trabajo de lanzamiento ya no restauran los cachés npm/cargo después comprobar un SHA proporcionado por la persona que llama: los máximos de envenenamiento de caché de CodeQL #88–#107 se cierran con una prueba de contrato sobre los archivos de flujo de trabajo (#5463).
  • Las filas TUI compactas por debajo de 60 columnas ya no reservan métricas de sesión ocultas tira, por lo que los terminales estrechos recuperan la fila en lugar de clipping la transcripción (#5486).
  • El campo submarino de color verdadero de Ghostty ahora utiliza un sistema sincronizado dedicado. Línea de 60 FPS en lugar del límite de compatibilidad heredado de 30 FPS, con continuidad Los desvanecimientos cáusticos reemplazan los cambios de color visiblemente escalonados.
  • La acción Space:expand anunciada del razonamiento en vivo ahora se ejecuta antes del Se mantiene el pegado-ráfaga del primer carácter del compositor, mientras que los espacios en un pegado activo siguen siendo carga útil. La vista previa del razonamiento más reciente también es realmente gratuita filas de la ventana gráfica antes de truncar en lugar de detenerse en la fila fija de 10/12 respaldo en terminales espaciosos.
  • Las compilaciones estrictas de cargo doc ya no fallan en las URL simples en los comentarios de rustdoc; los enlaces restantes son objetivos de Markdown explícitos (#5489).

Cambiado

  • La herramienta agent orientada al modelo anuncia exactamente 12 campos: action, prompt, type, profile, name, agent_id, message, until, detached, worktree, write_roots, resume_from: en vez de 33 (#5324, referencias #5123). Presupuestos (max_steps, wall_time_secs, max_depth), anulaciones de enrutamiento (model, model_strength, thinking), ruta del árbol de trabajo perillas, los campos deliberar/spawn-contrato y los campos de espera/estado/interrupción los extras se alejaron del esquema anunciado. Cada campo eliminado permanece analizado y respetado sin cambios (mismo contrato que token_budget), por lo que transcripciones guardadas, ACP/MCP clients y configuraciones de flota se reproducen tal cual; el Las abrazaderas de contención #5426/#5435 están intactas. Los presupuestos infantiles ahora se resuelven desde los valores predeterminados de rol (60/120 giros, tiempo de pared de 1800 s, abrazaderas sin cambios) y nuevas teclas [subagents] default_max_steps / default_wall_time_secs. Porque el catálogo de herramientas es parte del prefijo de solicitud fijado por sesión (docs/CACHE.md), la actualización rellena el prefijo KV una vez por sesión.
  • Prosa TUI (mensajes de usuario, respuestas del asistente y razonamiento/pensamiento) ahora se ajusta a todo el ancho del contenido en terminales anchos, coincidiendo celdas de herramienta/estado, en lugar de detenerse en un riel de 105 columnas que dejaba un margen derecho muerto en pantallas ultraanchas (#5436).
  • Las indicaciones de habilidades configuradas son estables en todas las raíces de la sesión y en funcionamiento. sistemas: sólo las raíces configuradas a medida ocultan su ruta física, las ordinarias espacio de trabajo/habilidades globales mantienen un camino reconocible y seguro para la privacidad, advertencia los reemplazos tienen en cuenta los límites (incluidas las rutas Unix que no son UTF-8), y Los separadores de Windows se representan como /. El mensaje de habilidades también tiene 50 bytes. más eficiente sin aumentar el límite máximo del contrato de tiempo de ejecución (#5492, #5473).
  • Las solicitudes del clasificador de enrutador automático aceptan [auto.router] timeout_secs, mientras que preservando el valor predeterminado existente cuando la clave está ausente (#5494).
  • Cada trabajo ci.yml ahora tiene un tiempo de espera explícito de 10 a 90 minutos apropiado para su carga de trabajo, limitando los corredores asignados obsoletos en lugar de heredar Valor predeterminado de seis horas de GitHub (#5495).
  • El shell de documentos y los componentes web compartidos ahora enrutan la copia localizada a través de el lomo del diccionario mecanografiado; estas son dos fases incrementales del n.° 5337, no completar la epopeya completa (#5488, #5490).
  • Dependencia: rusqlite 0.40.2 (#5391).
  • Documentación: referencias obsoletas de nivel A/B/C, valores predeterminados del proveedor, módulo Las descripciones y los anclajes de línea ahora coinciden con el código actual (#5481).
