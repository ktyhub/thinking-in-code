  • [Pausa] Cambios importantes contra v5.6.0:
  • Se ha cambiado el tema predeterminado, incluido el estilo visual y la configuración de ubicación predeterminada de componentes y series. Por ejemplo, la posición predeterminada de la leyenda ahora está en la parte inferior del lienzo. La nueva configuración predeterminada es más razonable, pero si afecta el uso existente, use echarts/theme/v5.js para restaurar el estilo visual y la configuración de ubicación antiguos. Consulte #20865.
    • La versión 5 echarts/src/theme/light.ts ahora se migra a echarts/theme/rainbow.js.
    • La posición de los ejes cartesianos puede cambiar ligeramente si los nombres o etiquetas de los ejes previamente desbordaron el lienzo o se superpusieron, ya que el mecanismo anti-desbordamiento y anti-ejeLabel-axisName-overlap están habilitados de forma predeterminada. En la mayoría de los casos, esos cambios serán imperceptibles a simple vista. Pero si se produce algún cambio irrazonable, puede usar la opción grid.outerBoundsMode: 'none' para deshabilitar el mecanismo anti-desbordamiento y/o usar la opción xAxis/yAxis.axisLabel.nameMoveOverlap: false para deshabilitar el mecanismo anti-superposición de nombres de ejes y etiquetas. Consulte #21059.
    • Se cambia la base porcentual de la opción center (como la base de '33%') en geo, series.map, series.graph y series.tree. La base porcentual anterior es incorrecta. Pero si necesita restaurar, configure legacyViewCoordSysCenterBase: true (en el nivel raíz de una opción echarts). Consulte #19807#issuecomment-2974437299.
    • Ahora los estilos de etiquetas enriquecidos (fontStyle, fontWeight, fontSize, fontFamily, textShadowColor, textShadowBlur, textShadowOffsetX, textShadowOffsetY) se modifican para heredar los estilos de etiquetas simples. Puede usar richInheritPlainLabel: false (en el nivel raíz de una opción echarts, o en el mismo nivel de las opciones de estilo de etiqueta) para restaurarlo. Ver #20977
