#echarts 5.4.1

  • [Función] [i18n] Agregar traducción al húngaro (hu_HU). #17978 (ifjkovacsik)
  • [Característica] [svg] Admite gradientes y patrones para el color de fondo en el renderizador SVG. #959 (corazón sencillo)
  • [Característica] [candelabro] Proporciona la opción borderColorDoji para un color doji personalizado. #17717 (Ovilia)
  • [Característica] [sankey] Soporte edgeLabel. #16767 (susiwen8)
  • [Función] [gráfico] Haga que el nodo gráfico se pueda arrastrar en el diseño none y circular. #15428 (kongmoumou)
  • [Característica] [util] Utilice Map nativo si está disponible. #965 (JonasBa)
  • [Función] [tipo] Exportar ECElementEvent para TypeScript. #17892 (keita-determinado)
  • [Solución] [i18n] Cambiar el nombre del código de idioma ucraniano a UK. #17812 (striezel)
  • [Fix] [pie] El porcentaje de corrección no se actualiza después de cambiar la leyenda. #17734 (corazón sencillo)
  • [Fix] [pie] Se corrige el posible acceso nulo a labelLine cuando se configura minShowLabelRadian. #17715 (corazón sencillo)
  • [Fix] [pie] Fix center puede no convertirse al punto correcto cuando se especifica el sistema de coordenadas. #17920 (sencillo corazón)
  • [Reparar] [mapa de calor] La etiqueta del mapa de calor reparada puede superponerse cuando dataZoom está habilitado. #17876 (corazón sencillo)
  • [Solución] [animación] Se corrigió dataGroupId incorrecto para elementos de datos antiguos en universalTransition. #17559 (tyn1998)
  • [Reparación] [dataZoom] Retroceso al inicio/final de la extensión cuando el valor o el porcentaje no son válidos. #17934 (corazón sencillo)
  • [Solución] [línea de tiempo] El gráfico de corrección no puede funcionar cuando no se muestra la línea del eje. #17647 (corazón sencillo)
  • [Reparar] [información sobre herramientas] Arreglar la flecha de información sobre herramientas puede cubrir el contenido cuando el borde es ancho. #17875 (sencillo corazón)
  • [Solución] [marcador] La solución markArea no se muestra cuando se usa el píxel x/y pero coord no está definido. #17217 (jiawulin001)
  • [Solución] [marcador] markArea de la serie de barras ahora cubre categorías completas especificadas. #17098 (jiawulin001)
  • [Solución] [leyenda] La leyenda de corrección inverse no funciona si los datos de la serie tienen el mismo nombre. #17510 (caiwukun)
  • [Fijar] [indicador] Renderiza sectores de indicador en el orden de la opción "en el sentido de las agujas del reloj". #17691 (ZeekoZhu)
  • [Fijar] [ssr] Corrige la expresión incorrecta para extraer el tamaño de fuente. #968 (corazón sencillo)
  • [Reparación] [svg] La forma reparada puede desaparecer después de finalizar la animación de transformación en el renderizador SVG. (corazón sencillo)
  • [Reparar] [tipo] Reparar el error de tipo EChartsInitOpts sobre alto y ancho. #17727 (Hou principal)
  • [Reparar] [tipo] Agregue la propiedad overflow a la interfaz AxisLabelBaseOption. #17808 (breizh24)
  • [Reparar] [tipo] Agregue el tipo string y number en la opción center de la serie circular. #17917 (corazón sencillo)
  • [Solucionar] [tipo] Agregue devolución de llamada function faltante en lineStyle.color para series de líneas. #17780 (corazón sencillo)
