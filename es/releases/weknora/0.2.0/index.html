WeKnora v0.2.0

WeKnora v0.2.0 Release Notes

Fecha de lanzamiento: 2025-12-05 Esta es una actualización importante de funciones que presenta el modo ReACT Agent, el sistema de gestión de modelos, la base de conocimientos de preguntas frecuentes y más.

🚀 Características principales

Modo de agente ReACT

  • Nuevo modo ReACT Agent con herramientas integradas para la recuperación de la base de conocimientos
  • Soporte para herramientas MCP configuradas por el usuario y herramientas de búsqueda web para acceder a servicios externos
  • Múltiples iteraciones y reflexión para proporcionar informes resumidos completos.
  • Soporte de recuperación de bases de conocimientos cruzados, lo que permite la selección de múltiples bases de conocimientos.

Sistema de gestión de modelos

  • Gestión centralizada de la configuración del modelo.
  • Se agregó selección de modelo en la página de configuración de la base de conocimientos.
  • Funcionalidad integrada para compartir modelos entre múltiples inquilinos
  • Los inquilinos pueden usar modelos compartidos, pero no pueden editar ni ver los detalles del modelo.

Soporte de base de conocimientos de varios tipos

  • Soporte para la creación de preguntas frecuentes y tipos de bases de conocimientos de documentos.
  • Funcionalidad de importación de carpetas
  • Funcionalidad de importación de URL
  • Sistema de gestión de etiquetas
  • Capacidad de entrada de conocimientos en línea

Preguntas frecuentes Base de conocimientos

  • Nueva base de conocimientos tipo preguntas frecuentes
  • Funcionalidad de importación y eliminación por lotes
  • Entrada de preguntas frecuentes en línea
  • Capacidad de prueba de preguntas frecuentes en línea

Configuración de la estrategia de conversación

  • Soporte para configurar modelos de Agente y modelos de modo normal
  • Umbrales de recuperación configurables
  • Configuración de avisos en línea
  • Control preciso sobre el comportamiento de conversaciones de varios turnos y los métodos de ejecución de recuperación.

Integración de búsqueda web

  • Soporte para motores de búsqueda web extensibles.
  • Motor de búsqueda DuckDuckGo incorporado

Integración de la herramienta MCP

  • Soporte para ampliar las capacidades del Agente a través de MCP
  • Herramientas de inicio uvx y npx MCP integradas
  • Soporte para tres métodos de transporte: Stdio, HTTP Streamable y SSE

🎨 Mejoras en UI/UX

  • REDISEÑADO: Interfaz de conversación con cambio de modo Agente/modo normal
  • REDISEÑADO: UI de la página de inicio de sesión
  • MEJORADO: Lista de sesiones con agrupación ordenada por tiempo
  • NUEVO: área de acciones rápidas con efectos visuales de interfaz de usuario unificados
  • MEJORADO: Tarjetas de lista de la base de conocimientos que muestran el tipo, el recuento de conocimientos y el estado de la compilación.
  • NUEVO: Navegación con ruta de navegación en las páginas de preguntas frecuentes y lista de documentos
  • REDISEÑADO: página de configuración de la base de conocimientos con configuración independiente para tipo, modelos, métodos de fragmentación y configuración avanzada
  • NUEVO: página de configuración global para la configuración de permisos
  • MEJORADO: página de flujo de conversación con visualización del proceso de ejecución de llamadas a herramientas

⚡ Actualizaciones de infraestructura

  • NUEVO: gestión de tareas asíncronas basada en MQ que garantiza la integridad de las tareas después del reinicio del servicio
  • NUEVO: Migración automática de bases de datos que admite la migración de esquemas y datos durante las actualizaciones de versión.
  • NUEVO: Modo de desarrollo rápido con docker-compose.dev.yml para un inicio rápido del entorno de desarrollo
  • MEJORADO: optimización de la estructura de registro
  • NUEVO: Mecanismo de publicación y suscripción de eventos Changelog completo: CHANGELOG.md
