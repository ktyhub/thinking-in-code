WeKnora v0.1.6

WeKnora v0.1.6 Release Notes

Fecha de lanzamiento: 2025-11-24

🚀 Nuevas funciones

Mejoras en el analizador de documentos

  • NUEVO: Se agregó soporte para el análisis de archivos CSV, XLSX y XLS
    • Capacidades mejoradas de procesamiento de documentos con soporte para hojas de cálculo
    • Extracción de datos mejorada de formatos tabulares.
  • NUEVO: implementación del analizador de páginas web
    • Se agregó una clase de análisis de contenido web dedicada.
    • Soporte de codificación de imágenes optimizado para contenido web.
    • Gestión de dependencia mejorada para el análisis web

Mejoras en el procesamiento de documentos

  • NUEVO: Se introdujo MarkdownTableUtil para optimizar el formato de la tabla
    • Se redujeron los espacios en blanco innecesarios en las tablas de rebajas.
    • Mejora de la legibilidad y coherencia de la tabla.
  • NUEVO: Implementación de clase de modelo de documento
    • Se agregaron modelos de documentos estructurados para una mejor seguridad tipográfica.
    • Configuración optimizada y lógica de análisis.
  • ACTUALIZADO: analizador de documentos mejorado para Docx2Parser
    • Manejo de tiempo de espera mejorado
    • Mejor lógica de procesamiento de imágenes.
    • Gestión de backend de OCR optimizada

🌍 Internacionalización

  • NUEVO: Soporte multilingüe (inglés y ruso)
    • Se agregó dependencia de vue-i18n para la internacionalización.
    • Se reemplazaron mensajes codificados con funciones de traducción.
    • Mensajes de error actualizados, resultados de la consola y texto de la interfaz de usuario.
    • Documentación multilingüe mejorada con gráfico de conocimiento y guías de configuración de MCP

🐛 Corrección de errores

  • SOLUCIONADO: Problemas de integración de componentes de menú
  • CORREGIDO: Error de expresión regular de verificación de memoria del sistema Darwin (macOS)
    • Se resolvió el problema de salida vacía al verificar el uso de memoria en macOS.
  • CORREGIDO: Lógica de verificación de disponibilidad del modelo
    • Lógica de verificación de modelo unificada en diferentes interfaces
    • Se agregó la etiqueta automática ":latest" para modelos sin versiones especificadas.
    • Se evitó la repetición de llamadas de modelo API debido a falsos negativos.
  • CORREGIDO: Vulnerabilidad de seguridad en la configuración de redacción de Docker
    • Se solucionó el problema de seguridad del servicio del sistema de archivos grabable.

🔧 Refactorización y optimización

  • REFACTORADO: Registro del analizador y lógica de verificación API
    • Manejo de excepciones simplificado
    • Informe de errores y depuración mejorados.
  • REFACTORADO: Procesamiento de fragmentos
    • Se eliminó el manejo innecesario de encabezados.
    • Ejemplo de uso actualizado para mayor claridad.
  • REFACTORED: Organización del módulo
    • Archivos del módulo docreader reorganizados para una mejor estructura.
    • Rutas de importación de proto y client actualizadas
    • Configuración de compilación ajustada de Docker.
    • Rutas de importación de módulos unificadas para importaciones absolutas

📚 Actualizaciones de documentación

  • ACTUALIZADO: Documentación de adquisición de claves API
    • Se cambió al método de registro web y recuperación de la página de la cuenta.
  • ACTUALIZADO: Guía de configuración de inicio de Docker Compose
    • Se agregaron instrucciones de configuración completas
    • Configuración ajustada de docker-compose.yml
  • ACTUALIZADO: Documentación multilingüe
    • Se agregó una guía de configuración del gráfico de conocimiento.
    • Documentación de configuración de MCP mejorada
    • Documentación actualizada de la estructura del directorio.
  • ELIMINADO: Búsqueda híbrida en desuso Documentación API

🧹 Limpieza de código

  • ELIMINADO: Parámetros de compilación Docker redundantes
  • ACTUALIZADO: reglas .gitignore para una mejor higiene del repositorio
  • OPTIMIZADO: Importa declaraciones y escribe sugerencias
  • LIMPIADO: Registros y comentarios redundantes

🔄 Mejoras de CI/CD

  • AÑADIDO: Nuevas ramas de activación para la canalización de CI/CD
  • AÑADIDO: Control de concurrencia para procesos de construcción
  • AÑADIDO: Automatización de limpieza de espacio en disco
