mempalace v3.1.0

Primer corte de PyPI desde v3.0.0 el 6 de abril de 2026: 39 RP fusionados. Esta versión cierra la deriva de la versión de pip/complemento (n.° 290, n.° 296) y ofrece las correcciones comunitarias de la primera semana.

🔒 Seguridad

  • #387 Validación de entrada en los puntos de entrada de MCP, corrección de inyección de shell en el enlace de guardado, protección del tamaño del archivo + omisión de enlace simbólico, corrección de fugas de conexión SQLite, seguimiento de auditoría WAL, permisos de archivos reforzados
  • #141 Desinfectar SESSION_ID en el gancho para guardar
  • #139 Desinfecta las respuestas de error de MCP, elimina sys.exit del código de la biblioteca

🐛 Corrección de errores (aspectos destacados)

  • #399 Los argumentos nulos de MCP se bloquean, recursividad infinita cmd_repair, protección OOM de 500 MB
  • #270 Empaquetado del complemento Claude + Codex: instalación en un solo paso (cierra el n.° 187)
  • #137 Límite de seguridad de 10K en recuperaciones ilimitadas de metadatos de ChromaDB (cierra #180)
  • #129 Solución de fallos de Windows Unicode (cierra el n.° 47)
  • #123 El indicador --yes omite todos los mensajes de inicio (cierra el número 179)
  • #78 Respetar las reglas anidadas de .gitignore durante la minería (cierra #233)
  • #236 Telemetría Silence ChromaDB + configuración predeterminada de Apple Silicon CoreML (cierra el n.° 163)
  • #324 Negociar la versión del protocolo MCP en lugar de codificar
  • #145 La detección de salas compara las palabras clave con las rutas de las carpetas.
  • #136 Modo SQLite WAL + LÍMITE consistente en la línea de tiempo de KG
  • #66 Lecturas por lotes de ChromaDB para evitar el límite de variables de SQLite
  • #140 Upsert + ID deterministas evitan el estancamiento de datos
  • Y más: consulte el registro de confirmación completo

✨ Características

  • #61 Normalizador OpenAI Codex CLI JSONL (primero en el formato de importación #59)
  • #223 Conjunto de pruebas comparativas de escala (106 pruebas)
  • #135 Cache ChromaDB PersistentClient: gran ganancia de rendimiento

📊 Puntos de referencia (la versión honesta)

  • #147 Estadísticas AAAK honestas (estimador de tokens basado en palabras, etiquetas con pérdida)
  • Se eliminó el titular recall_any@5; consulte la corrección README de aa10f8f y los hilos de metodología en curso en los números 27, 29, 39, 214 y 168.

📦 Embalaje

  • #142 Rango cromadb ajustado (>=0.5.0,<0.7) + marcador py.typed
  • #281 Cobertura de prueba 30 % → 85 % + correcciones de codificación de Windows
  • #131 Pruebas migradas a uv, 20 → 92 pruebas
  • #16 Informes unificados de paquetes y versiones de MCP

🙏 Gracias

Muchas gracias a todos los que realizaron auditorías, detectaron errores reales y enviaron relaciones públicas limpias durante la primera semana, especialmente @lhl, @dial481, @gizmax, @rohithzr, @hugooconnor, @anthonyonazure, @fubak, @fuzzymoomoo, @vanachterjacob, @SethRosenthal100, @cktang88, @adv3nt3, @slapglif. @skuznetsov, @rusel95, @M0nkeyFl0wer, @EndeavorYen, @bobmatnyc, @kpulik, @kevgathuku, @mvalentsev, @mvanhorn, @jonashertner. Cierra los números 290 y 296.

📥 Instalar

pip install --upgrade mempalace
