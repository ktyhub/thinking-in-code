gpt-investigador v3.7.0

Contexto más inteligente, no se requieren incrustaciones

GPT Researcher ahora elige el contexto que envía al LLM por utilidad, no por similitud. Every passage scraped for a research question is scored by Jev on how useful it is for answering that question, and only the passages that help are kept.

On a benchmark of 28 research tasks replayed on identical sources:

<img width="3200" height="1800" alt="image-1790437831580" src="https://github.com/user-attachments/assets/c2a7b305-2e60-4709-ad9c-8af09e297f9f" />

Nothing is required. With TYPESAFE_API_KEY set, Jev is used. Sin uno, o si un Jev llama fails, GPT Researcher falls back to local keyword (BM25) ranking, so you no longer need an Proveedor de incrustaciones para investigación estándar. El chat de informes utiliza el mismo filtro.

  • Documentos: https://docs.gptr.dev/docs/gpt-researcher/gptr/context-filter
  • Benchmark, método y código: evals/context_filter/

⚠️ Cambios a tener en cuenta

  • Ahora se requiere Python 3.12+.
  • Filtro de contexto predeterminado: sin una clave TypeSafe, el valor predeterminado ahora es la clasificación de palabras clave en lugar de incrustaciones. It matched or beat embeddings on every measure in the benchmark. Para mantener lo viejo comportamiento, establezca CONTEXT_FILTER=embeddings.

También en esta versión

  • Complementos de recuperación: envíe un proveedor de búsqueda como su propio paquete a través del punto de entrada gpt_researcher.retrievers (#2154)
  • Se corrigió el WebSocket frontal que abría una segunda conexión en una nueva ejecución de investigación (#2159)
  • Las secciones de múltiples agentes ya no repiten el contenido de cada una (#2158)
  • Activos de interfaz autohospedados, sin CDN de terceros (#2082)
  • 25+ community fixes across retrievers, scrapers and deep research
  • Docs: redesigned homepage, current model hallucination leaderboard, fixed builds on fresh installs

Instalar: pip install -U gpt-researcher (0.16.0)
