Agentes comerciales v0.2.5

Resumen

TradingAgents v0.2.5 incluye Sentiment Analyst conectado a tierra, soporte de doble región Qwen/GLM/MiniMax, configurabilidad de env-var `TRADINGAGENTS_*` con detección automática de clave API, soporte remoto de Ollama, puntos de referencia alfa configurables para tickers fuera de EE. UU. y una solución de recorrido de ruta de ticker.

Analista de sentimiento

El Sentiment Analyst renombrado ahora lee datos reales de Yahoo News, StockTwits y Reddit antes de generar su informe, reemplazando el flujo anterior que podría fabricar publicaciones sociales bajo presión inmediata. El nuevo nombre fluye a través del menú desplegable CLI, el panel de estado y los informes finales; `AnalystType.SOCIAL = "social"` se mantiene para la retrocompatibilidad de la configuración guardada.

Cobertura del proveedor

  • MiniMax con el catálogo M2.x completo (contexto 204K), además de región dual Global (`MINIMAX_API_KEY`) y China (`MINIMAX_CN_API_KEY`).
  • Qwen y GLM de doble región con claves separadas por región (`DASHSCOPE_`, `ZHIPU_`), elegidas mediante un mensaje de región secundaria para que el menú desplegable del proveedor principal permanezca limpio.
  • Actualización del catálogo en todos los proveedores: GPT-5.5 frontier, Claude Opus 4.7, Gemini 3.1 Flash-Lite GA, Grok 4.20, Qwen 3.6 line. Solo identificaciones versionadas; Los alias de cambio automático se movieron a la opción "ID de modelo personalizado".
  • La salida estructurada ahora funciona en DeepSeek V4 / Reasoner y MiniMax M2.x: esos proveedores rechazan `tool_choice`; el flujo de enlace ahora lo omite automáticamente.

Configuración a través del entorno

`TRADINGAGENTS_*` env vars anula las claves `DEFAULT_CONFIG` con coerción con reconocimiento de tipo (string / int / bool): `llm_provider`, ID de modelo profundo/rápido, `backend_url`, `output_language`, recuentos de rondas de debate, el indicador de punto de control y el ticker de referencia. Cuando falta la clave API de un proveedor seleccionado, el CLI la solicita y conserva el valor en `.env` para que la ejecución continúe sin reiniciar.

##Ollama

`OLLAMA_BASE_URL` hace que el `ollama-serve` remoto sea de primera clase tanto para el CLI como para los usuarios programáticos. El CLI imprime el punto final resuelto después de seleccionar Ollama y advierte sobre entradas comunes con formato incorrecto. Una nueva opción "ID de modelo personalizado" permite a los usuarios elegir cualquier modelo que hayan obtenido a través de `ollama pull`.

Reflexión

Alpha ahora se calcula con respecto a un punto de referencia regional para tickers fuera de EE. UU.: `.NS` (^NSEI), `.T` (^N225), `.HK` (^HSI), `.L` (^FTSE), `.TO` (^GSPTSE), `.AX` (^AXJO), `.BO` (^BSESN), SPY para listados de EE. UU. Elimina la deriva del tipo de cambio que domina la cifra alfa para cotizaciones distintas al USD. `benchmark_ticker` anula el mapa de sufijos cuando se establece explícitamente.

Los parámetros de búsqueda de noticias (límite de artículo por ticker, límite de titulares de macro, ventana retrospectiva, consultas de búsqueda de macro) ahora se exponen a través de `DEFAULT_CONFIG` para un ajuste específico de la estrategia.

Varios idiomas

`output_language` ahora se propaga a todos los agentes que interactúan con el usuario (investigadores, debatientes de riesgos, gerentes de investigación y comerciantes), poniendo fin a los informes anteriores de localización parcial donde solo los analistas y el administrador de cartera respetaban el entorno.

Correcciones

  • Seguridad: validación de recorrido de ruta de ticker en cada sitio de ruta del sistema de archivos.
  • Las instalaciones de `pip install .` ahora seleccionan el proyecto `.env` cuando se ejecuta CLI como script de consola.
  • Los informes se guardan de un extremo a otro: los fragmentos transmitidos anteriormente se eliminaban de `complete_report.md`.
  • El mensaje de teletipo conserva los sufijos de intercambio (`.SH`, `.SZ`, `.SS`, `.HK`, `.T`, etc.).
  • Errores de permisos Docker ya no bloquean la escritura de primera ejecución en `~/.tradingagents/`.
  • El estado de configuración ya no se filtra entre ejecuciones cuando se modifican los subdictados.
  • La configuración `max_recur_limit` realmente se aplica al propagador.
  • Error de clave faltante-API nombra la var de entorno exacta a configurar.
  • Inicio más silencioso: se suprimió la ruidosa advertencia de desuso del punto de control de langgraph ascendente.

Consulte CHANGELOG.md para obtener la lista completa por elemento con referencias de relaciones públicas/problemas.
