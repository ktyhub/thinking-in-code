Cherry Studio 2.2.2: aprobaciones de agentes, correcciones de proveedores y pulido

✨ Nuevas funciones

  • [Uso de la computadora] El uso de la computadora ahora está activado de forma predeterminada y pregunta antes de acceder a cada aplicación. Elija Siempre, Aprobar para sesión o Rechazar y administre las aprobaciones guardadas en Configuración. El modo de omisión omite estas indicaciones sin guardar permisos. (Acción requerida: desactívela en Configuración si no la desea).
  • [Habilidades] Se agregó un interruptor "Exportar habilidades a agentes externos" en Configuración → Habilidades. Está desactivado de forma predeterminada para nuevas instalaciones, por lo que el directorio de habilidades compartido ya no se crea sin una suscripción explícita; las instalaciones que ya exportaron lo mantienen activado y al desactivarlo se eliminan solo los enlaces creados por Cherry Studio.
  • [Agente] Los agentes en los modelos DeepSeek ahora muestran una línea de intención corta encima de cada llamada de herramienta. Las sesiones de agente mantienen los pasos de la herramienta expandidos de forma predeterminada y eliminan las llamadas repetidas del mismo tipo.
  • [Aplicación] Se agregó soporte para el idioma polaco.

💄 Mejoras

  • [MCP] QVeris ahora admite el inicio de sesión del navegador OAuth como credencial principal, con QVERIS_API_KEY como respaldo opcional, por lo que se puede habilitar sin una clave API.
  • [Archivos] Los tamaños de archivos usan un formato consistente en toda la aplicación.
  • [Agente] Se pulió la tipografía de los detalles de la sesión, la alineación de los íconos, el espaciado y el marcador de posición sin espacio de trabajo.

🐛 Corrección de errores

  • [Modelos] Las solicitudes de herramientas CherryIN Claude Sonnet 4.5 ya no fallan con un error de validación de parámetros de Bedrock.
  • Las solicitudes [Modelos] Claude Opus 5.5 en AWS Bedrock ahora utilizan razonamiento adaptativo.
  • [Modelos] SiliconFlow utiliza la entrada de clave manual API; se eliminó el inicio de sesión obsoleto de OAuth (se requiere acción si inició sesión con OAuth).
  • [Chat] Los errores "La entrada excede el límite de contexto" ahora se reconocen como rechazos de longitud del contexto, por lo que aparece la guía de recuperación existente.
  • [Chat] Los enlaces de archivos locales de Markdown ahora se abren desde superficies de chat que no proporcionan una vista previa de los artefactos.
  • [Chat] Se corrigió que la primera activación de la barra de herramientas del compositor se perdiera durante la carga y la navegación de pestañas internas ya no bloquea la interacción.
  • [Agente] Se corrigió la tarjeta AskUserQuestion que faltaba cuando una solicitud de aprobación transmitida llega antes de su fuente de herramienta.
  • [Agente] Se corrigió que el botón Omitir se atascara en la pregunta AskUserQuestion final cuando se omitían todas las preguntas.
  • [Agente] Al expandir una llamada a la herramienta de lectura Pi Durable ya no se muestran detalles del archivo en blanco.
  • [Agente] Los agentes Pi Durable ahora cargan automáticamente archivos de instrucciones del espacio de trabajo como AGENTS.md.
  • [Agente] Las herramientas MCP ordinarias se pueden descubrir mediante la búsqueda de herramientas en el tiempo de ejecución de Pi Durable en lugar de devolver "No se encontraron herramientas coincidentes".
  • [Agente] La guía de herramientas del agente ahora trata las herramientas diferidas como disponibles a través del descubrimiento y utiliza los nombres exactos de las herramientas de la sesión, por lo que los agentes dejan de informar que faltan herramientas disponibles.
  • [Agente] Cuando el razonamiento agota el presupuesto de respuesta, ahora obtiene una guía precisa de límite de token de salida y la capacidad de DeepSeek V4.1 Flash se resuelve correctamente para los ID de modelo versionados.
  • [API Gateway] Los resultados de Claude Code MCP ToolSearch ya no se eliminan para modelos de terceros.
  • [Código] El selector de modelos de Unified Gateway de Code Mate ahora enumera los modelos de Cherry Cloud que están disponibles solo para agentes.
  • [Doctor] Doctor ya no informa que falta una clave API o una lista de modelos no disponibles para CherryAI y Cherry Cloud; para Cherry Cloud ahora te indica cuándo debes iniciar sesión.
  • [UI] Los favicons del sitio web permanecen visibles en modo oscuro con una placa posterior de color gris claro suave y mantienen sus colores originales.
  • [Actualizador] Los Release note en el cuadro de diálogo de actualización ahora siguen el idioma resuelto de la aplicación, incluso cuando la aplicación sigue el idioma del sistema.
</detalles>
