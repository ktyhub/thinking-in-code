<summary>Release Note</summary> Cherry Studio 2.1.4: nuevos modelos, conexiones de dispositivos y corrección de errores ✨ Nuevas características - [Conexiones de dispositivos] Conéctese a través de LAN accesible o redes VPN configuradas externamente con soporte IPv4/IPv6, priorización automática de direcciones y selección manual mediante interfaz de red. Acción requerida: actualice a una aplicación móvil compatible para guardar y verificar direcciones adicionales y escanear códigos de emparejamiento que contengan más de 16 direcciones. - [Mensajes] Agregar exportación a la barra de acciones de selección múltiple: exporte los mensajes seleccionados como Markdown, Word o Notion/Yuque/Obsidian/Joplin/Siyuan. - [Modelos] Agregue compatibilidad con GPT-6.1 Sol para OpenAI y OpenAI Codex, incluida la configuración de precios y razonamiento. - [Modelos] Agregue Claude Sonnet 5.5 y Opus 5.5 con controles de pensamiento y elegibilidad de herramientas web nativas. - [Modelos] El proveedor Claude Code ahora ofrece Claude Opus 5.5 (con modo rápido) y Claude Fable 5.1. - [Modelos] Agregue MiniMax M3.1 Flash Preview con cinco niveles de esfuerzo de razonamiento. - [ComfyUI] Agregue el proveedor de imágenes ComfyUI local: elija flujos de trabajo guardados como modelos y genere desde la página de pinturas. - [Launchpad] Los mosaicos de aplicaciones integrados ahora usan superficies de tarjetas con reconocimiento de temas. 🐛 Corrección de errores - [Agente] Se corrigió que las sesiones del Agente se volvieran inutilizables cuando el proceso anterior de Claude Code tardaba en salir. - [Agente] Soluciona conflictos de mensajes repetidos y títulos obsoletos en sesiones de Agente remoto recién creadas. - [Agente] Se corrigió el mensaje de error del punto de control al editar y reenviar; ahora explica el problema claramente. - [Agente] Repara los mensajes de sesión del Agente que permanecen en la lista después de una eliminación exitosa. - [Tareas del agente] Recuperar espacios de trabajo de latidos no utilizados junto con programaciones huérfanas. - [Chat] Arreglar Regenerar usando el proveedor incorrecto: ahora usa la selección del compositor. - [Chat] Se corrigió el reintento del grupo multimodelo usando el modelo predeterminado del asistente en lugar del modelo propio de la respuesta. - [Chat] Repara conversaciones restauradas a través del archivo y deshacer que saltan cuando se abren. - [Chat] Se corrigieron los paneles de llamada de herramientas que no usaban la misma altura de ventana gráfica que el panel de pensamiento. - [Chat] Los chats de temas ya no incorporan esquemas de herramientas del navegador, lo que reduce la sobrecarga de miles de tokens. - [Chat] Trate solo el bloque de etiquetas que abre una respuesta como razonamiento en línea: las etiquetas literales en las respuestas ya no truncan el contenido. - [Conocimiento] Arreglar las instalaciones del paquete MCP (DXT/MCPB) con rutas que difieren solo en caso o formato Unicode. - [Conocimiento] Se corrigieron instantáneas de URL capturadas nombradas con porcentajes de escape cuando la ruta de la página no es ASCII. - [Conocimiento] Recuerde la última base de conocimientos utilizada por el cuadro de diálogo de guardar. - [Habilidades] Se corrigieron las instalaciones de skills.sh para repositorios que almacenan habilidades en .gemini/skills/, .claude/skills/ o .agents/skills/. - [Habilidades] Se corrigieron las importaciones ZIP de habilidades con rutas que difieren solo en mayúsculas y minúsculas o en formato Unicode. - [Traducir] Se corrigió que los diagramas de sirena no se conservaran ni se representaran durante la traducción. - [Vista previa del archivo] Se corrigió la vista previa del archivo que muestra fragmentos de ruta como idioma para archivos en directorios con puntos o sin extensiones. - [Vista previa del archivo] Se corrigió la vista previa del PDF que no representaba texto chino/CJK que utiliza fuentes CID no incrustadas. - [Icono de archivo] Se corrigieron los íconos de archivos para las rutas de Windows: las tarjetas de artefactos ahora muestran el ícono correcto. - [Markdown] Se corrigió que los SVG en el chat se renderizaran con tamaños medidos para SVG renderizados previamente. - [Lista de modelos] Mantenga los nombres de grupos numéricos en el orden de los modelos mientras esté activo un filtro de búsqueda. - [Editor de texto enriquecido] El formato aplicado desde la barra de herramientas ahora se guarda en la nota. - [Navegador] Restaura el cambio de tamaño en toda la altura del separador de la barra lateral del navegador. - [Diseño de chat] Utilice el valor predeterminado más estrecho de 280 px para los paneles de archivos y artefactos en la primera ejecución. - [Diagnóstico] Se corrigió el informe de verificación de estado "No hay clave API configurada" para el proveedor basado en Claude Code CLI. - [Diagnóstico] Muestra el enlace de estado, el estado de procesamiento y el historial local para informes de diagnóstico. - [Asistente de selección] Se corrigieron los bloques de código de resultados que no se ajustaban en anchos estrechos. - [Asistente de selección] Se corrige la pantalla negra después de cerrar la ventana de acción mientras se está en pantalla completa de macOS. - [Captura de pantalla] Se corrigió la captura de pantalla de Windows en diseños de varios monitores con DPI mixtos. - [Búsqueda web] Se corrigió la rotación de claves API que nunca llega a otras claves cuando existe una entrada duplicada. - [OpenClaw] Se corrigió el error engañoso de “binario incompatible” cuando la sonda del esquema de configuración era simplemente lenta. - [Copilot] Se corrigió el enrutamiento del modelo GitHub Copilot GPT-6 seleccionando las Respuestas API para la familia GPT-6. - [DSH] Se corrigió la limpieza del directorio temporal DSH administrado de Windows y se actualizó a 0.2.0-rc.2. - [Agente Claude] Actualice Claude Agent SDK a 0.3.284 con instrucciones conservadas en el currículum. - [Creación de agente] Eliminar DeepSeek Harness de las opciones de tiempo de ejecución del nuevo agente; Los agentes existentes siguen siendo compatibles. - [Sistema de archivos] Se corrigió la herramienta `ls` que informaba un directorio vacío en lugar de un error por rutas faltantes o que no eran de directorio. - [API] Se corrigió la transmisión compatible con OpenAI que eliminaba el campo `arguments` requerido para herramientas sin parámetros. - [Vista previa HTML] Se corrigió el salto de texto cuando la barra de desplazamiento aparece/desaparece en el umbral del tamaño del contenido. - [Tareas programadas] Mantenga compactas las selecciones de varias horas y admita expresiones Cron editables y validadas. - [Compositor] Las celdas copiadas de Excel ahora se pegan como texto cuando hay texto enriquecido junto a una imagen. - [Configuración del proveedor] Aclare que los modelos Doubao usan Volcengine Ark con la URL base API compatible. - [macOS] Se corrigió que la ventana principal no se volviera a abrir en el primer Dock click después de cerrarla con el botón rojo. - [Proveedor] Mantener la posición de la lista de proveedores del modelo activada/desactivada; mostrar nuevos proveedores en la parte superior. </detalles> ## ¿Qué ha cambiado? * hazaña (compositor):
