<summary>Release Note</summary> Cherry Studio 2.1.5: accesorios remotos, canales y mejoras importantes ✨ Nuevas características - [Acceso remoto] Cargue imágenes y archivos a sesiones remotas del Agente desde su dispositivo móvil vinculado, con transferencias reanudables de hasta 1 GiB por archivo. - [Canales] Agregue canales WeCom y DingTalk con configuración QR, conversaciones de agentes, transmisión de respuestas, notificaciones y archivos adjuntos. - [MCP] Compatibilidad con MCP SDK v2 con solicitudes interactivas, formularios validados, cancelación y resultados estructurados en tiempos de ejecución de chat y agentes. - [Agente] Actualice el tiempo de ejecución de Pi a 1.0 con modo de código nativo en espacio aislado y compatibilidad con MCP. Acción requerida: actualice los scripts Pi personalizados al modo de código nativo API. - [Doctor] System Doctor obtiene una sección de análisis de IA que lee informes de diagnóstico y propone correcciones limitadas que puedes aplicar y deshacer. - [Conexiones de dispositivos] Mejore la incorporación de dispositivos móviles con descargas específicas de la plataforma, progreso recordado y vistas previas móviles automáticas. - [Pinturas] Minimiza el acoplamiento de mensajes después de generar, amplía las imágenes generadas con la rueda del mouse y abre el visor de imágenes compartido en click. - [Modelos] Agregue compatibilidad con Claude Haiku 5.5 con controles de razonamiento, límites de tokens actualizados, precios y disponibilidad de Claude Code. - [Compositor] Resalte el acceso directo de la barra de herramientas de MCP cuando las herramientas de MCP estén habilitadas para el chat actual o la sesión del agente. - [Búsqueda web] Agregue Crawl4AI autohospedado como proveedor de recuperación de URL con host API configurable y token de portador opcional. - [Windows] Use botones de subtítulos nativos en ventanas principales y separadas mientras conserva las barras de título personalizadas y la adaptación del tema. - [Actualizaciones] Habilite las descargas diferenciales nativas para reducir el tamaño de las actualizaciones cuando esté disponible un instalador en caché compatible. - [Vista previa de archivos] Mejore las vistas previas de documentos con zoom táctil, diapositivas de PowerPoint resistentes y opciones de límite de tamaño más claras. Agregue compatibilidad con WebView para la integración móvil. - [Archivo] Restaurar un agente ahora también restaura sus sesiones, y las filas de tareas/temas archivados muestran su agente o asistente propietario. 🐛 Corrección de errores - [Agente] Corrige los tiempos de espera de la herramienta del navegador al cambiar de sesión o cerrar pestañas durante una tarea activa. - [Agente] Se corrigieron los motivos de denegación de herramientas que se confundían con la salida de la herramienta (ahora se atribuyen explícitamente como palabras del usuario). - [Chat] Soluciona fallas a mitad de respuesta al descartar contenido ya transmitido; ahora se conserva junto con el error. - [Chat] Se corrigió que el progreso de la compresión del contexto no apareciera dentro del mensaje del asistente. - [Chat] Se corrigieron las respuestas horizontales de múltiples modelos que bloqueaban el desplazamiento hacia arriba al historial de chat anterior. - [ComfyUI] Corrige los flujos de trabajo con semillas aleatorias que representan la misma imagen en cada ejecución. - [ComfyUI] Se corrigieron los nodos asociados (API) que fallaban sin la clave API del proveedor; ahora se envió correctamente. - [ComfyUI] Se corrigió que los flujos de trabajo se convirtieran con valores incorrectos o fallaran con no_prompt_node. - [Notificaciones] Se corrigieron las notificaciones de finalización para mostrar el tema o nombre de la sesión y la oración final. - [Notificaciones] Borre la insignia del Dock de macOS cuando todas las preferencias de notificación estén desactivadas. - [Markdown] Dejar de vincular ejecuciones de barra diagonal de un solo segmento (como `/jX_s`) como rutas de archivo. - [WebView] Limite el agente de usuario nativo al inicio de sesión de Google, preservando la UA limpia para AI Studio y otras solicitudes. - [Respuestas abiertas] Se corrigieron las conversaciones que fallaban cuando las puertas de enlace compatibles emitían deltas de mantenimiento de actividad SSE marcadas. - [Copia de seguridad] Se corrigió el error de las copias de seguridad locales cuando el destino es la raíz de una unidad de Windows. - [Canales] Corrige la configuración de los canales que genera errores causados ​​por ID de usuario mal formados en las credenciales de WeChat guardadas. - [Herramientas] Se corrigió la clasificación errónea de herramientas de línea de comandos personalizadas denominadas constructor o toString como código integrado CLI. </detalles> ## ¿Qué ha cambiado? * corrección (notas de la versión): conciliar los cambios finales
