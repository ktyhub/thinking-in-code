<summary>Release Note</summary> Cherry Studio 2.1.3: nuevas funciones, rendimiento y confiabilidad ✨ Nuevas características - Conexiones de dispositivos [Remotos]: empareje un client móvil compatible para importar proveedores y usar agentes de escritorio a través de una conexión LAN cifrada, con recuperación de reconexión, fallas de ejecución, aprobaciones y preguntas. Acción requerida: los dispositivos heredados deben volver a emparejarse para el nuevo protocolo basado en identidad. - [Documento] Admite el análisis de documentos MinerU 4 autohospedados manteniendo la compatibilidad con servidores Open MinerU heredados. - [Captura de pantalla] Utilice el OCR del sistema en macOS y Windows para seleccionar y copiar el texto de la captura de pantalla sin descargar un modelo local. - [Modelos] Agregue Claude Opus 5.5 al chat de API con límites de modelo actualizados, precios, controles de razonamiento y elegibilidad de herramientas web. - [Modelos] Agregue metadatos del catálogo GPT-6 Sol y Luna, elegibilidad de búsqueda web OpenAI y entradas de modelo OpenAI Codex. - [Modelos] Agregue Grok 4.7 al catálogo de modelos (xAI, OpenRouter, Vercel AI Gateway, OpenCode, Copilot) con el mayor esfuerzo de razonamiento; Grok CLI ahora incluye Grok 4.6, Grok 4.7 y Grok 4.7 Fast; Grok 4.6 obtiene el mayor esfuerzo de razonamiento. - [Modelos] Agregue Xiaomi MiMo V2.6 Flash, Pro y Pro-UltraSpeed ​​al catálogo de modelos para los proveedores MiMo, OpenRouter, Vercel AI Gateway y OpenCode, con el interruptor de encendido/apagado pensado. - [Habilidades] Agrega guardado automático de archivos protegido y actualizaciones remotas manuales para las habilidades instaladas desde rutas exactas admitidas. - [Habilidades] Agrega páginas de detalles de habilidades dedicadas, etiquetas de origen, eliminación más segura e inicio one-click en una sesión de Agente. - [Configuración] Agregue una configuración de "Idioma de respuesta del agente" (predeterminado: seguir el idioma de la conversación) con valores preestablecidos y personalizados, además de una anulación por agente con una vista previa del idioma efectivo, para que los usuarios puedan fijar el idioma en el que responden los agentes. - [Atajos] En macOS, Comando+W ahora cierra la pestaña activa en lugar de la ventana; cerrar la ventana se movió a Comando+Mayús+W. 🐛 Corrección de errores - [Configuración] Restaure el desplazamiento de la lista de modelos de proveedores desde fuera de la lista y permita que los encabezados de grupo se desplacen con la página. - [Configuración] Los términos de búsqueda en inglés ahora encuentran la configuración de estilo de conversación V2. - [Configuración] Verifique y habilite proveedores automáticamente después de agregar modelos y evite que los cuadros de diálogo de selección de modelos salten cuando se cargan listas grandes. - [Proxy] Se corrigieron servicios locales como DeepSeek Harness que no se conectaban cuando las solicitudes de bucle invertido IPv4 o IPv6 se enrutaban a través de un proxy. - [Proxy] Se corrigió el error de sincronización de la lista de modelos detrás de un proxy corporativo o con un certificado TLS interceptado, que anteriormente fallaba a pesar de que el proveedor trabajaba para el chat. - [Proxy] Corrija las reglas de omisión de proxy escritas como literales IPv6 simples (`::1`, `fe80::1`, `2001:db8::1`) que nunca coinciden y haga coincidir las direcciones IPv6 por valor para que se reconozcan las notaciones equivalentes. - [Agente] Las tareas programadas ahora se pueden editar en el lugar a través de la herramienta cron, con controles de reutilización de sesiones y una guía más clara sobre conflictos de nombres. - [Agente] La guía de herramientas Cherry incluida ahora describe cuándo está disponible la herramienta de notificación y cómo las tareas programadas llegan a sus destinatarios de notificación. - [Agente] Se corrigió que las sesiones del agente tipo dsh fallaran en redes solo de proxy al heredar el proxy configurado en el proceso de ejecución del agente. - [Agente] Mantenga las solicitudes de múltiples agentes en una sola respuesta hasta que finalice todo el trabajo, con listas de subtareas compactas y navegación confiable por tareas anidadas. - [Agente] Se corrigieron los chips de enlace de mensajes enviados y las vistas previas de sitios web que abren pestañas separadas en lugar de usar el panel del navegador de la conversación del Agente. - [Chat] Mejore la altura del panel de pensamiento, el desplazamiento y la legibilidad del texto para contenido de razonamiento extenso. - [Chat] Mantenga las respuestas AskUserQuestion no enviadas al cambiar de conversación, de modo que volver a una pregunta pendiente se reanude donde la dejó el usuario. - [Chat] Se corrigió el uso del token que no se calcula ni se muestra para algunos modelos después de la actualización del mensaje. - [Chat] Se corrigió que los mensajes de chat no permanecieran en la parte inferior después de desplazarse hacia abajo con la rueda del mouse o arrastrar la barra de desplazamiento. - [Chat] Se corrigieron las continuaciones de respuestas que enviaban un UUID como ID de elemento de entrada y eran rechazadas porque la ID debía comenzar con rs o msg. - [Chat] Corrige imágenes administradas migradas que aún apuntan a un directorio de datos antiguo. - [Habilidades] Se corrigió la importación ZIP de habilidades que rechazaba una habilidad dentro del límite porque el archivo del repositorio a su alrededor excedía los límites anteriores compartidos; Los paquetes de habilidades ahora pueden contener hasta 20.000 archivos. - [Habilidades] Se corrigió el error en la instalación de habilidades de ClawHub porque el límite de tamaño de descarga no estaba definido. - [Habilidades] Las instalaciones de habilidades desde Claude Plugins y skills.sh ahora descargan solo el directorio de habilidades en lugar de todo el repositorio, y la instalación de una habilidad más grande desde un enlace GitHub ya no caduca. - [Habilidades] Mejore la legibilidad de los nombres en el diseño de configuración de dos columnas manteniendo el tamaño de la tarjeta y muestre nombres completos y descripciones en la información sobre herramientas. - [Habilidades] Se corrigieron los menús de comandos de barra y Habilidades al editar mensajes y después de cancelar ediciones. - [Habilidades] Se corrigieron las tarjetas CLI atascadas en “Instalando…” cuando en realidad no se estaba ejecutando ninguna instalación; el estado ahora se concilia con operaciones en vivo en lugar de eliminar los marcadores sobrantes. - [Captura de pantalla] Se corrigió que la barra de herramientas de captura de pantalla se desplazara parcialmente fuera de la pantalla cuando la selección estaba cerca del borde izquierdo de una pantalla. - [Archivo] Se corrigió que los árboles de archivos del espacio de trabajo se detuvieran después de un error transitorio del observador de bloqueo de archivos de Windows. - [Archivo] Preserva el estado del directorio en cambios breves de página sin mantener la página activa. - [AI] Se corrigió que las solicitudes de Gemini fallaran con errores 400 de campo desconocido cuando un esquema de herramienta contiene nombres de propiedades o palabras clave de propiedades adicionales. - [AI] Muestra mensajes claros de error de solicitud HTTP 400 y conserva los códigos de estado HTTP de Claude Agent SDK para una clasificación precisa de los errores. - [AI] Explique las fallas de solicitud del agente HTTP 413 y sugiera reducir el tamaño de la carga útil antes de volver a intentarlo. - [Windows] Se corrigió un bloqueo de inicio de Windows cuando el control de la aplicación bloquea el controlador de apagado nativo. - [Linux] Linux AppImages ya no requiere la biblioteca libfuse2 del sistema. - [Mini aplicaciones] Corrija el ancho del cuadro de diálogo Agregar mini aplicación para que el contenido de la instalación permanezca dentro del cuadro de diálogo. - [Historial] El historial de chat y agente ahora usa íconos y etiquetas de archivo que describen con precisión sus acciones de archivo recuperables. - [UI] Se corrigió que el contenido de la información sobre herramientas a veces permaneciera fijado en la esquina superior izquierda después de cli seleccionar una ruta de archivo en las sesiones del agente. - [UI] Se corrigió la información sobre herramientas que persistía en la esquina superior izquierda de la ventana después de cambiar los paneles del panel derecho. - [UI] Mantenga accesibles los mensajes, las conversaciones y las acciones claras en dispositivos sin soporte para desplazarse, incluidas tabletas Windows con teclados independientes. - [Error] El error de renderizado se produce como texto en lugar de HTML para una visualización más segura. - [Citas] Las fuentes del panel de citas ahora se abren en la barra lateral del navegador a la izquierda click y
