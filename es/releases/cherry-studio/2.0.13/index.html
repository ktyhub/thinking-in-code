<detalles> <summary>inglés</summary> Cherry Studio 2.0.13: nuevas funciones, correcciones y mejoras ✨ Nuevas características - [Modelos] Agregue compatibilidad con GPT-6 Astra con límites de contexto, controles de razonamiento, modo rápido, búsqueda web nativa, precios escalonados y el ícono del modelo oficial. - [Modelos] Agregue TokenDance como proveedor de modelo integrado con autorización de clave API basada en navegador. - [Tareas programadas] Los ajustes preestablecidos diarios, entre semana y semanales ahora admiten varias horas al día (por ejemplo, 09:00 y 18:00). - [Chat] Muestra títulos de temas y sesiones, cambia de rama desde el encabezado y exporta ramas individuales como Markdown. - [Habilidades] Agregue filtros de fuente de habilidades instaladas y un interruptor de diseño de columna simple/doble en la configuración de Habilidades. - [Panel rápido] Las acciones de administración ahora permanecen en un pie de página accesible en indicaciones, habilidades, MCP, notas, base de conocimientos y personalización de la barra de herramientas. - [Compositor] Agregue un atajo Ctrl+I / Cmd+I configurable para enfocar la entrada. - [Exportación de imágenes] La exportación de imágenes de mensajes ahora utiliza el compositor de Chromium para obtener resultados con píxeles perfectos que coincidan con lo que ves en la pantalla. - [Traducir] Renderice la salida transmitida con formato Markdown enriquecido. 🐛 Corrección de errores - [Modelos] Se corrigieron los proveedores de modelos personalizados que rechazan los encabezados de atribución automática de Cherry Studio. - [Modelos] Se corrigieron las solicitudes de Moonshot Kimi K2.5+ que fallaban cuando la configuración de muestreo personalizada estaba habilitada. - [Modelos] Se corrigieron las solicitudes de Kimi K3 que fallaban cuando se seleccionaba un esfuerzo de razonamiento no respaldado. - [Modelos] Retiró el proveedor Yi (01.AI) luego del cierre de su servicio. - [Modelos] Los perfiles migrados desde la versión 1 ahora conservan el acceso a todos los proveedores y modelos, independientemente de la edición instalada. - [Chat] Se corrigió un tema que fallaba permanentemente con un error 400 después de una llamada a la herramienta cuando el proveedor devolvía una identificación de artículo no estándar. - [Chat] Se corrigió el cambio entre respuestas multimodelo mientras se transmite una respuesta. - [Chat] Corrige errores normales de autenticación de chat que no se pueden vincular a la configuración del proveedor después de reintentos automáticos. - [Chat] Las citas de búsqueda web nativas devueltas por los proveedores ahora se muestran en las respuestas del chat. - [Chat] Las sesiones de agente completadas ahora muestran el uso de tokens no disponibles en lugar de un cero engañoso. - [Chat] Las fallas de autenticación de certificados del agente client ahora muestran una guía de recuperación de proxy y SSL. - [Chat] Los errores de inicio de sesión del Agente de Claude Code ahora se vinculan a la configuración del proveedor necesaria para la recuperación. - [Chat] Agregue una acción de recuperación de la configuración del proveedor a errores HTTP 400 genéricos. - [Chat] Arreglar las citas de mensajes que se dirigen a la ventana incorrecta. - [Tareas programadas] Se corrigió que el registro de ejecución de tareas perdiera su enlace "ver sesión" cuando la ejecución de un agente programado fallaba, se agotaba el tiempo de espera o se cancelaba. - [Agente] Se corrigió que los agentes sin tareas desaparecieran de la lista de agentes cuando las sesiones se muestran a la derecha. - [Agente] Repara fallas de la herramienta Bash etiquetadas como errores en lugar de salida de comando. - [Agente] Se corrigieron las llamadas a herramientas para que los argumentos reparados y reproducidos mantengan su forma esperada JSON. - [Agente] Restaura la protección de bucle de repetición de comandos de Claude Code cuando RTK reescribe comandos Bash. - [Agente] Evite que los agentes modifiquen archivos SQLite de datos de usuario de Cherry Studio a través de herramientas nativas. - Las fallas del proceso de [Agente] Claude Code ahora muestran una causa procesable y una referencia de diagnóstico. - [Agente] El indicador de uso del contexto ahora avanza en vivo durante una tarea en lugar de solo al finalizar. - [DeepSeek] Las sesiones web de DeepSeek Harness ahora se inician correctamente cuando el tiempo de ejecución requiere su URL autenticada mediante token. - [Pi] Reanudar las tareas de Pi después de respuestas de longitud limitada por el contexto con un intento limitado de compactación y reintento. - [OpenCode] Los títulos de conversaciones automáticas de OpenCode Go ahora conservan la identidad de la sesión. - [Contexto] Se corrigió el selector del modelo de compresión de contexto para que los usuarios puedan volver a "Seguir el modelo actual". - [Configuración] Se corrigió la lista de modelos de proveedores que congelaba la aplicación cuando un proveedor tiene muchos modelos. - [Configuración] Arreglar la configuración del Asistente que interrumpe el guardado automático con valores de tokens Max inseguros. - [Configuración] La incorporación de la edición China ahora vuelve a utilizar el inicio de sesión CherryIN de forma predeterminada. - [Configuración] AMD GPU Cloud ya no muestra mensajes promocionales "Gratis" o de crédito diario. - [Asistente rápido] Se corrigió la selección integrada de acciones rápidas para llamar a las herramientas MCP cuando se configura un QuickAssistant con MCP. - [Traducir] Se corrigió el botón de copiar que mostraba sus comentarios en el panel incorrecto. - [Traducir] Se corrigió que el historial de traducción comience a abrir detalles en lugar de alternar cuando se la copia de seguridad, restauración, administración y limpieza de retención de Qiniu Cloud S3 cuando se usan puntos finales regionales. - [Región] El enrutamiento dependiente de la región ahora recurre a puntos finales globales cuando falla la detección de la región IP en lugar de tratar el error como China continental. - [Región] Se corrigió la detección de región al reutilizar una
