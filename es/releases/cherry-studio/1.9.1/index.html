estudio-cereza v1.9.1

Cherry Studio 1.9.1 - Agente CherryClaw y sistema de habilidades ⚠️ Cambios importantes

  • [Agentes] El sistema "Complementos" cambió de nombre a "Habilidades". El mercado de complementos ha sido reemplazado por una interfaz unificada de gestión de habilidades ✨ Nuevas funciones
  • [Agentes] Agregue el agente autónomo CherryClaw: sistema de personalidad, tareas programadas, integración multicanal (Telegram, Discord, Feishu, Slack, WeChat, QQ) y zona de pruebas del sistema de archivos
  • [Agentes] Agregue Cherry Assistant integrado: ayuda a diagnosticar problemas, navegar por páginas, recopilar preguntas frecuentes y enviar informes de errores
  • [Agentes] Visualización de resultados de herramientas mejorada con resaltado de sintaxis, visor de diferencias, números de línea e íconos de tipo de archivo
  • [ErrorHandling] Agregue diagnóstico de errores basado en IA con clasificación instantánea y sugerencias de solución paso a paso
  • [MCP] Agregue flomo como servidor MCP integrado para capturar notas e ideas
  • [MCP] Agregue MCPWorld (mcpworld.com) como un nuevo mercado de servidores MCP
  • [Temas] Admite fijar temas en la parte superior de la lista
  • [Modelos] Agregar opción de punto final para proveedor exclusivo y actualizar modelos predeterminados 🔒 Correcciones de seguridad
  • [Seguridad] Solucionar posibles problemas de seguridad con el manejo de URL externos y las operaciones de archivos
  • [Seguridad] Se corrigió la vulnerabilidad XSS en la descripción de MCP y los resultados de búsqueda. 🐛 Corrección de errores
  • [Modelos] Agregue compatibilidad con el formato Ollama gemma4 para la detección de capacidad del modelo Gemma 4
  • [Modelos] Se corrigió que el proveedor new-api ignorara el host configurado para solicitudes de formato antrópico
  • [Modelos] Se corrigió que el proveedor Poe no pudiera cargar modelos dinámicamente
  • [Modelos] Se corrigió el error de búsqueda web de Google Gemini
  • [Modelos] Se corrigió la detección de modelos para las series Qwen3.5–3.9 y GPT.
  • [Modelos] Se corrigieron los parámetros de razonamiento del proveedor NVIDIA para los modelos Qwen/DeepSeek/Kimi/Zhipu.
  • [Modelos] Repara el comportamiento de alternancia de pensamiento/no pensamiento de Xiaomi MiMo
  • [Agentes] Reparar los procesos secundarios de Claude Code que ignoran la configuración del proxy de la aplicación (incluido el proxy SOCKS)
  • [Agentes] Se corrigió que Cherry Assistant ignorara el idioma del usuario y siempre respondiera en inglés.
  • [MCP] Se corrigieron las llamadas a la herramienta MCP en modo Hub que truncaban silenciosamente las respuestas de estilo lista
  • [Conocimiento] Solucionar el error de incrustación de archivos epub
  • [Notas] Corrija la corrupción de la fórmula KaTeX al alternar los modos de editor
  • [Notas] Se corrigió el estado de búsqueda y el desplazamiento del editor de notas.
  • [Pensamiento] Se corrigió la visualización del tiempo de pensamiento que muestra valores incorrectos
  • [MiniApps] Se corrigió la reaparición silenciosa de miniaplicaciones fijadas eliminadas
  • [Herramientas de código] Soluciona el fallo de kimi-cli cuando uv no está instalado
  • [Compilación] Se corrigen los archivos de habilidades integrados (.md) que faltan en la aplicación empaquetada
  • [Chat] Solucionar la pérdida de datos al seleccionar el modelo mediante el método abreviado de teclado
  • [UI] Se corrigió el desbordamiento de altura de mover al submenú
  • [UI] Se corrigió la alineación del semáforo de macOS en la barra de título personalizada ⚡ Rendimiento
  • [Copia de seguridad] Copias de seguridad más rápidas con archivos de menor tamaño
  • [Agente] Mejorar la experiencia de cambio de sesión
