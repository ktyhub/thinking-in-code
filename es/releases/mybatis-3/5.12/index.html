mybatis-3 mybatis-3.5.12

"La gran limpieza"

Cambios impactantes para el usuario

  • #2703 La referencia al parámetro de colección por nombre no se soluciona #2693

  • #2709 Se corrige una condición de carrera causada por otros subprocesos que llaman a métodos del asignador mientras se construyen las tablas asignadas.

  • #2727 Habilitar la capacidad de proporcionar configuración personalizada a XMLConfigBuilder

  • #2731 La adición del mapeador podría fallar bajo JPMS

  • #2741 Agregar el atributo 'affectedData' a @Select, @SelectProvider y <select />

  • #2767 Resolver resultType por espacio de nombres e id cuando no se proporcionan resultType y resultMap

  • #2804 Buscar propiedad legible al resolver el tipo de argumento del constructor por nombre

  • Corrección menor: 'booleano' nunca puede ser nulo (primativo)

  • Actualizaciones generales de la biblioteca.

  • Utiliza la opción de parámetros para el compilador ahora (necesaria para spring boot 3) (para necesidades de reflexión)

limpieza de código

  • #2816 Utilice la reescritura abierta para limpiar parcialmente el código Java
  • #2817 Agregar constructores privados por reescritura abierta
  • #2819 Agregar final cuando corresponda por reescritura abierta
  • #2825 Limpieza si la declaración se rompe / lógica de retorno
  • #2826 Eclipse limpieza basada

construir

  • #2820 Eliminar el perfil del grupo ci de prueba a favor de un uso más directo en GH-Actions y actualizar el surefire obsoleto junto con la descripción general en README.md
  • Los ajustes para construir ognl y javassist sombreados ya no arrojan advertencias
  • Construya también con jdk 21-ea ahora
  • Varias pruebas de limpieza, actualizaciones y adiciones.
  • Active el formato automático de todo el código Java, incluida una nota para los contribuyentes en el archivo Léame para omitir el formato cuando sea necesario en los bloques de código.
  • Las pruebas pueden usar jdk 11 ahora manteniendo el tiempo de ejecución de jdk 8
  • Limpieza de pom/mejor aclaración de parámetros.

Documentación

  • Varias actualizaciones de documentación.

Para contribuyentes:

  • Mybatis ahora utiliza el formato automático del código base. Si la contribución necesita un formato especial, como anotaciones o javadocs específicos que entran en conflicto con las reglas de formato, use // @formatter:off y // @formatter:on alrededor del bloque de código que se ignorará al formatear. Si está dentro de un javadoc, dado que es un tipo de comentario, todo se ve afectado, así que simplemente envuelva esto alrededor de todo el javadoc. Intente asegurarse de que el código dentro del bloque sin formato tenga el formato adecuado para facilitar la lectura.
