Cambios notables

La categoría Rendimiento en el informe Lighthouse ahora muestra auditorías de información sobre el rendimiento de forma predeterminada; lea más aquí.

Núcleo

  • incluir siempre encabezados incluso para tablas vacías (#16534)
  • exponer pila de errores, artefacto en runtimeError (#16524)
  • cache-insight: corrige el valor incorrecto que se utiliza para el tamaño de transferencia (#16562)
  • config: arroja un error si un filtro es una matriz vacía (#15118)
  • anclajes rastreables: permite elementos de anclaje de marcador de posición (#16292)
  • recopilar: agregar artefacto base DPR del host (#16559)
  • recopilar: desaprobar ejecuciónContext.evaluateAsync (#16518)
  • insights: muestra ahorros estimados en ms (#16563)
  • inspector-issues: cambiar el nombre a elementAccessibilityIssue (#16561)
  • texto de enlace: use lang para buscar solo términos localizados (#16526)
  • network-dependency-tree-insight: agregar consejos de preconexión (#16557)
  • complementos: admite paquetes npm con alcance (#16550)
  • render-blocking-resources: cambiar la etiqueta de la columna a Duración (#16519)
  • resumen de tiempos: suprime los errores esperados (#16520)
  • elementos de seguimiento: elimina la depuración centinela para nodos impactados no válidos (#16523)

Informe

  • mostrar auditorías de rendimiento de información de forma predeterminada (#16552)
  • Se corrige la casilla de verificación del filtro 3p para auditorías de información (#16564)
  • ocultar resaltador durante la impresión (#16544)
  • eliminar estilos de contorno de enfoque personalizados (#16531)
  • aumentar el ancho máximo del menú de 3 puntos (#16530)
  • ocultar mapa de árbol, ver botones de seguimiento al imprimir (#16529)

Departamentos

  • actualizar trace_engine a 0.0.56 (#16565)
  • departamentos de actualización (#16555)
  • actualizar el almacén de configuración a 7.0.0 (#16148)
  • actualizar paquetes de broma a 29.7.0 (#16147)
  • centinela: actualización a v9 (#16541)

Documentos

  • recetas: dar órdenes explícitas para construir el primer faro (#16527)

Pruebas

  • paralelizar las pruebas de la base de datos de Lantern (#16545)

Varios

  • tarea: usar sangría "Nota" en el archivo Léame (#16533)
  • tarea: reformatear para reducir las nuevas líneas falsas (#16038)
  • tarea: cambiar el nombre de traceEngineData a parsedTrace (#16270)
  • ci: corrige la lógica para el cron de publicación nocturna (#16556)
  • ci: evita la publicación nocturna si no hay cambios en el último día (#16547)
  • departamentos: actualización a eslint 9 (#16327)
