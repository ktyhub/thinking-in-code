faro v6.1.0

#6.1.0 (25/06/2020) Changelog completo Esperamos que esta versión se envíe a DevTools en Chrome ~85~ 86 y a PageSpeed Insights dentro de 2 semanas.

Nuevos contribuyentes

¡Gracias a nuestros nuevos colaboradores 👽🐷🐰🐯🐻!

  • Loftie Ellis @lpellis
  • Marvin Frachet @mfrachet
  • Matt Hobbs @Nooshu *Peter Marshall @psmarshall

Cambios notables

  • Si una página tiene mapas fuente JavaScript de acceso público, Lighthouse los recopilará para mejorar la auditoría unused-javascript. En versiones futuras de Lighthouse, los mapas fuente se utilizarán para auditorías completamente nuevas (#10990).
  • El informe ahora utiliza KiB en lugar de KB. Esto es simplemente un cambio de etiqueta; el valor era y sigue siendo igual a 1024 bytes (#10870). <img src="https://i.imgur.com/1gSdPw5.png" alt="JavaScript sin usar con mapas de origen" width="800px">

Nuevas auditorías

  • tareas largas: un nuevo diagnóstico de rendimiento que muestra las tareas de bloqueo del hilo principal más largas durante la carga (#10736)
  • anclajes rastreables: una nueva auditoría SEO que verifica que los anclajes enlacen a URL resolubles (#10662)

Núcleo

  • sin usar-javascript: aumenta el umbral a 20 KB (#10906)
  • layout-shift-elements: contribución de CLS de superficie por elemento desplazado (#10968)
  • emulación: versiones cromadas (#10787)
  • sensible al tamaño de la imagen: cuantificar los DPR (#10801)
  • tareas largas: agregue la propiedad startTime (#10942)
  • mejorar la resiliencia de los recolectores dependientes de nodeId (#10877)
  • ejecución media: agregue ComputeMedianRun a la biblioteca (#10859)
  • precarga: ignorar solicitudes entre fotogramas (#10847)
  • nuevo recopilador de problemas del inspector para eventos Audit.IssueAdded (#10664)
  • refactorizar subRow, cambiar el nombre a subItem (#10867, #10978)

Experimental

Funciones ocultas detrás de la bandera --preset=experimental.

  • Legacy-javascript: reduce los polyfills, corrige la importación de core-js en la prueba (#10937)
  • Legacy-javascript: utiliza lenguaje prescriptivo en el título (#10850)
  • Legacy-javascript: corrige la detección de core-js 3 (#10852)
  • Legacy-javascript: utilice una web de terceros para la puntuación (#10849)
  • duplicado-javascript: muestra el tamaño de transferencia (#10701)

Departamentos

  • axe-core: actualización a 3.5.5 (#10986)
  • actualizar chrome-launcher@0.13.3 (#10911)
  • snyk: actualiza la instantánea de snyk (#10840, #10940, #10980, #11010)
  • eliminar tamaño del paquete (#10999)
  • actualización a lhci 0.4.0 (#10828)

Informe

  • métricas: utilice la cuadrícula css para que las métricas estén alineadas (#10789)
  • no atenúe los enlaces de anclaje de exención de responsabilidad (#10981)
  • utilice acrónimos y métricas redondas para una URL de cálculo más corta (#10954)
  • enlace de actualización para auditoría de presupuestos (#10944)
  • agregar barra diagonal a los enlaces de web.dev (#10967)
  • corrige el ancho del menú de 3 puntos en la barra superior (#10855)
  • Escritura de firma de método actualizada para eliminar focusevent cast (#10858)
  • ajustar la descripción del elemento LCP (#11018)
  • renderizador: corrige Util.i18n nulo en el renderizador PSI (#10822)
  • psi: muestra descargo de responsabilidad y calclink (#10936)

Documentos

  • agregar nota sobre el repositorio de git requerido para el uso de @lhci/cli (#11006)
  • contribución: agregue sugerencias para los RP de auditoría y recolectores (#10690)
  • Léame: actualizar la receta de uso programático (#10878)
  • Léame: agregar integraciones nuevas y actualizadas (#10838, #10901, #10826, #10818)

Pruebas

  • agregar pruebas clave de encabezado (#10746)

Varios
