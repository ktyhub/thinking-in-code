#5.2.0 (2019-07-24) Lanzamiento esperado de DevTools en Chrome 77 (septiembre de 2019)

Nuevas auditorías

  • Uso de terceros, un nuevo diagnóstico de rendimiento que muestra un desglose de los recursos de terceros en la página y el tiempo/bytes necesarios para cargarlos (#9067)
  • Tiempo total de bloqueo, una nueva métrica experimental que sirve como complemento de TTI para ayudar a priorizar el desbloqueo del hilo principal. Dado que actualmente es experimental, la auditoría no tiene puntuación y aparece solo en el LHR JSON sin procesar, no en el informe HTML. (#8975, #9409)

Cambios notables

  • tracehouse: el procesamiento de seguimiento de rendimiento se ha movido a su propio directorio en lib/tracehouse/ para que funcione como una biblioteca más independiente (9f80524, 1af2edd, 7ba6776, ddff3d6)
  • Los errores de seguridad de certificados ya no son un error fatal de Lighthouse, aunque la página de error de Chrome seguirá arrojando pocos resultados en el informe de forma predeterminada. Consulte los documentos para probar una página en esta situación. (#8865)
