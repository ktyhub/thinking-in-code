Clients

  • devtools: script de compilación de refactorización (#7421, #7567)
  • lr: utilice siempre transferSize del encabezado X-TotalFetchedSize (#7478)
  • lr: recopila números de sincronización de red de los encabezados (#7888)
  • lr: agregar soporte de configuración personalizada (#7613)

Pruebas

  • mejor cobertura de errores fatales de lógica de seguimiento (#7959)
  • arreglar la generación de cobertura de prueba (#7475)
  • terminar de quitar el mocha (#7429)
  • actualizar jest para arreglar la compilación actual del nodo 11 (#7413)
  • humo: elimina usos triviales de rawValue de las expectativas (#7780)
  • humo: establece el tipo de contenido para los archivos servidos por static-server.js (#7612, #8015, #8078)

Varios

  • tarea: eliminar el antiguo departamento postinstalación-prepare (#7647)
  • eliminar typedef no utilizado (#8075)
  • especificar tipos para algunos objetos de opciones de gráfico de dependencia (#7962)
  • simplificaciones en simulador/grupo de conexiones (#7894)
  • limpieza de código drive-by en BaseNode (#7723)

  • recopilar: actualizar comentario sobre: copia de ClientRect (#7785)
