faro v4.2.0

#4.2.0 (2019-03-06) Changelog completo Esperamos que esta versión se envíe en DevTools de Chrome 74.

¡Nuevos colaboradores!

@pra85, @tgfjt, @gidztech y @jburger424. ¡Gracias!

Nuevas auditorías

  • objetivos táctiles: verifique que los objetivos táctiles sean de buen tamaño y distintos (#5846)

Informe

  • reorganizar todos los grupos de auditoría (#7129)
  • clip URL excepcionalmente largas en el encabezado (#6858)
  • procesador de detalles: utiliza nuevos tipos de detalles de auditoría (#7192)

Núcleo

  • fid: agregue FID potencial máximo a JSON (#5842)
  • artefactos: unifica AnchorElements en un solo recolector (#7101)
  • artefactos: incluye scripts en línea en el artefacto Scripts (#7065)
  • artefactos: crear artefacto calculado ViewportMeta (#7264)
  • artefactos: agregue el artefacto base TestedAsMobileDevice (#7280)
  • tiempo de arranque: mejor atribución (#7059)
  • eficiencia de bytes: utilice proporciones GZIP más optimistas (#7210)
  • encabezados de caché: corrige el error tipográfico en must-revalidate (#7189)
  • procesador de detalles: agrega el procesador de detalles del fragmento (#6999)
  • diagnóstico: agregar auditorías de diagnóstico (#7052)
  • controlador: agregue tiempo de espera de waitForFCP (#7356)
  • controlador: recopila solicitudes de red de iframes fuera de proceso (#6922)
  • controlador: agregue 'Chrome-Lighthouse' a useragent (#7297)
  • emulación: pasar el agente de usuario de Chrome a m74 (#7211)
  • fcp-3g: elimina i18n no utilizado para compatibilidad con LR (#7103)
  • visualización de fuentes: sigue con mayor precisión las especificaciones CSS (#7191)
  • elementos de imagen: límite de tiempo de recuperación de tamaño natural (#7274)
  • linterna: agregar configuración para análisis de red precalculado (#7239)
  • lhr: incluye ResourceSize en la auditoría de solicitudes de red (#7056)
  • manifiesto: elimina el artefacto del manifiesto a favor del nuevo WebAppManifest (#7078)
  • métricas: no fallar si TTI falla (#7132)
  • análisis de red: establezca RTT adicional en 0, no en NaN (#7156)
  • grabador de red: las redirecciones iniciadas por script se configuran como iniciadores (#7352)
  • complementos: agrega soporte para grupos (#7304)
  • seo: eliminar auditoría manual compatible con dispositivos móviles (#7223)
  • seo: agregar rel=prueba canónica para auditar la raíz de un dominio (#7228)
  • tap-targets: deshabilita el tamaño de fuente y la auditoría de objetivos de toque en el escritorio (#7393)
  • tap-targets: hace que las fallas de tap target sean más visibles (#7373)
  • tsc: corrige la jerarquía de tipos de detalles de auditoría (#7177), #7154, #7285)
  • css no utilizado: cambiar título Aplazar -> Eliminar (#7235)
  • dar orden de reserva para detalles de prueba rotos en el nodo 11 (#7216)
  • suprimir el tiempo de espera del protocolo para el error del manifiesto de la aplicación en LR (#7184)
  • optimizar la auditoría de objetivos de toque (#7130)
  • eliminar NO_ERROR runtimeError cuando no hay error (#7358) ##CLI
  • escribir informe en runLighthouse antes de salir de Chrome (#7339)

Departamentos

  • snyk: actualiza la instantánea de snyk (#7277, (#7233, #7167), #7116)
  • actualizaciones para eliminar vulnerabilidades transitivas (#7319)
  • actualiza cssstyle para analizar más colores con nombre, colores CSS4 (#7283)

Documentos

  • Contribuir.md: corregir errores tipográficos (#7170)
  • corrige la tasa de limitación de comentarios y modifica el ancho de banda de comcast (#7374)
  • mejorar las explicaciones sobre cómo extender y usar archivos de configuración (#7354)
  • actualizar los documentos de limitación a la versión pública (#7332)
  • Léame: agregar farero a las integraciones (#7399)
  • documentos (proyectos relacionados) agregar reaccionar-faro-visor (#7262)
  • Léame: Agregar Fluxguard a la lista de integraciones (#7249)
  • variabilidad: agregar documento de variación dedicado (#7175)

I18n

  • corrige la descripción del FID potencial máximo (#7353)
  • Corrección de sintaxis de la UCI (#7320)
  • cadenas de SEO preparadas para i18n (#6860)
  • traducir cadenas en la auditoría de objetivos de toque (#7111)
  • título y descripción de la categoría a11y (#7113)
  • importar mensajes traducidos de accesibilidad y error lh (#7008)

Pruebas

  • controlador de refactorización, más pruebas de gotoURL (#7270, #7242, #7212)
  • ejecutar el nodo 11 en CI (#7230)
  • reemplazar instantáneas no volátiles con literales en línea (#7217)
  • ahumadero: refactor para habilitar Smokerider (#7284)
  • ahumadero: +/- operador (#7343)
  • ahumadero: prueba de gzip para afirmar los tamaños de transferencia y recursos (#7286)
  • ahumadero: error en URL final/código de error no coincidentes (#7227)

Varios

  • tap-targets: elimina líneas con espacios en blanco al final (#7105)
  • limpiar node_modules/.cache antes de que travis construya su caché (#7388)
  • convertir los comentarios de Flags a jsdoc para obtener un mejor intellisense (#7359)
  • exportar cadenas UA desde emulación.js (#7318)
  • corregir error tipográfico en el comentario (#7296)
