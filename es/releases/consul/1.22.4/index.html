cónsul v1.22.4

⚠️ Aviso importante

Hemos identificado un problema en la versión de parche de febrero de Consul y Consul Enterprise (1.22.4, 1.22.4-ent, 1.21.10-ent, 1.18.20-ent) que requiere una versión de parche correctivo.

Recomendamos que los clientes eviten el uso de estas versiones en entornos de producción y esperen el próximo lanzamiento del parche.

Los clientes que hayan actualizado a estas versiones deben volver temporalmente a la versión estable anterior mientras preparamos una actualización corregida.

Se espera una nueva versión parcheada para finales de este mes.

Se compartirán más actualizaciones una vez que la nueva versión esté disponible. Lamentamos las molestias y agradecemos su paciencia.

1.22.4 (18 de febrero de 2026)

SEGURIDAD:

  • seguridad: actualice la versión go a 1.25.7 [GH-23204]
  • Archivo docker: la compilación del Cónsul. Ir a la imagen base a alpine3.23 [GH-23194]
  • conectar: migrar a aws-sdk-go-v2 desde aws-sdk-go (v1). También se actualizaron las dependencias de cónsul-awsauth y go-secure-stdlib/awsutil a sus versiones v2. [GH-23109]
  • seguridad: configure los tiempos de espera del servidor HTTP para evitar ataques de denegación de servicio de Slowloris en los puntos finales HTTP del agente y en los puntos finales pprof. [GH-22739]

MEJORAS:

  • api-gateway: Se corrigieron errores de "coincidencia duplicada" en Envoy cuando se usan múltiples certificados de sistema de archivos en un único oyente TLS. Los certificados ahora están consolidados en una única cadena de filtros, lo que permite a Envoy seleccionar el correcto. [GH-23212]
  • agente: Se solucionó el error del proveedor de bóveda al firmar la CA intermedia con isCA=true en CSR [GH-23202]
  • cli: Se agregó el indicador --aws-iam-endpoint al comando consul login para que el método de autenticación de AWS IAM admita la configuración personalizada del punto final de IAM [GH-23109]
  • api: Cancelar la verificación de contexto para la recuperación de caché de relojes para detener la ejecución cuando el administrador cancela el registro del reloj. [GH-23157]
