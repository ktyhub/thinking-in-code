cónsul v2.0.3

2.0.3 (7 de agosto de 2026)

SEGURIDAD:

  • Actualice brace-expansion para abordar GHSA-rgw5-rvv9-x895 (DoS a través de matrices intermedias ilimitadas). [GH-23786]
  • Actualice fast-uri para abordar GHSA-7p8r-x3mc-p8w7 (Host Confusion mediante el introductor de autoridad de barra invertida). [GH-23786]
  • Actualice golang.org/x/text a v0.39.0 para dirigirse a GO-2026-5970. [GH-23761]
  • Actualice google.golang.org/grpc a v1.82.1 para abordar GHSA-hrxh-6v49-42gf. [GH-23761]
  • Actualice socket.io-parser para abordar CVE-2026-69185 (agotamiento de la memoria sin archivos adjuntos). [GH-23786]
  • Actualice para usar Go 1.26.5. Esto resuelve las vulnerabilidades. GO-2026-4970 (os). GO-2026-5856 (crypto/tls). [GH-23761]
  • agente: Se corrigió una vulnerabilidad de denegación de servicio donde GET /v1/agent/connect/ca/roots y POST /v1/agent/connect/authorize usó el caché del lado del agente incondicionalmente, incluso cuando el operador configuró http_config { use_cache = false }. Una persona que llama remotamente podría omitir esta configuración y hacer crecer la caché del agente sin estar obligado a variar la solicitud Token ACL. Ambos puntos finales ahora omiten el caché y emiten un RPC directo cuando use_cache está discapacitado. (SECVULN-50292, SECVULN-50293) [GH-23797]
  • agente: Se corrigió un pánico de desreferencia de puntero nulo en ShadowServiceRouterConfigEntry.CheckEnt cuando una entrada de configuración del enrutador de servicio contenía una ruta con un Destination nulo. Un elaborado Un mensaje de replicación o restauración de instantáneas que contenga dicha entrada podría bloquear el FSM. ruta de decodificación. La guardia nula ahora trata un destino faltante como datos no empresariales y continúa decodificando de forma segura. (SECVULN-50291) [GH-23797]
  • agente: Se corrigió una omisión de seguridad donde un oyente público proporcionado por el usuario (envoy_public_listener_json) con un filtro de Administrador de conexión HTTP omitiría el de Consul Valores predeterminados de normalización de solicitudes entrantes. Un atacante podría aprovechar la ruta no normalizada para omitir las reglas deny de intención L7 utilizando equivalentes de ruta codificados por porcentaje. Cónsul ahora inyecta normalización de ruta (habilitada de forma predeterminada, a menos que la opción de configuración de malla InsecureDisablePathNormalization está configurado) en cada cadena de filtros HCM en la configuración proporcionada por el usuario. oyentes públicos antes de que se aplique la aplicación de la intención L7. (SECVULN-50295) [GH-23797]
  • agente: Se corrigió una vulnerabilidad de denegación de servicio no autenticada donde PUT /v1/agent/check/update/:id, PUT /v1/agent/check/register, PUT /v1/agent/service/register y POST /v1/agent/connect/authorize cuerpos de solicitud JSON ilimitados decodificados antes de resolver la ACL de la persona que llama ficha. Una persona que llama no autenticada podría retener varios decodificadores JSON grandes buffers simultáneamente dentro del proceso Consul antes de que se enviara cada solicitud. rechazado con HTTP 403, lo que provoca un crecimiento del montón controlado por el atacante. los cuatro Los puntos finales ahora limitan el cuerpo de la solicitud a 512 KiB antes de que se produzca cualquier decodificación. devolviendo HTTP 413 para cuerpos de gran tamaño. Este límite se aplica a fragmentos codificación de transferencia así como Content-Length declarado. (SECVULN-50418) [GH-23796]
  • agente: Se corrigió una vulnerabilidad de denegación de servicio no autenticada donde el gRPC externo y los oyentes gRPC-TLS aceptaron un número ilimitado de conexiones TCP por IP de origen antes de que pueda ocurrir cualquier procesamiento de solicitud, verificación de ACL o limitación de velocidad. Un atacante remoto podría agotar los descriptores de archivos del agente, las rutinas y la memoria al abrir muchas conexiones y retener el protocolo de enlace gRPC o TLS. Ahora está disponible un nuevo limitador de conexión por-client-IP aplicado antes de que el servidor gRPC observe la conexión, controlado por el nuevo Opción de configuración limits.grpc_max_conns_per_client (por defecto 100). El apretón de manos gRPC El tiempo de espera también se ha reducido del valor predeterminado de la biblioteca de 120 segundos a 20 segundos. (SECVULN-50294) [GH-23797]

MEJORAS:

  • interfaz de usuario: migrar las pruebas de aceptación de yadda/Gherkin a QUnit nativo (aprovechar, intenciones/crear, componentes, configuraciones) [GH-23741]
  • xds: agregue dos nuevas claves ProxyDefaults.spec.config opcionales para controlar el encabezado de respuesta server en los oyentes HTTP de la puerta de enlace API: envoy_suppress_envoy_headers (elimina el encabezado por completo) y envoy_server_header_name (le cambia el nombre a un valor personalizado). Si ambos están configurados, la supresión tiene prioridad. [GH-13027]

CORRECCIÓN DE ERRORES:

  • agente: Deje de registrar el token ACL sin procesar en registros de tipo de contenido a nivel de depuración. [GH-23731]
  • Puerta de enlace api: se corrigió una regresión que causaba que una puerta de enlace HTTP API rechazara su configuración con un error de "protocolos inconsistentes" (lo que resultaba en 503 intermitentes) cuando el service-router de un servicio backend compuso una ruta a un destino en un servicio, espacio de nombres o partición diferente durante la síntesis de la cadena de descubrimiento. [GH-23793]
  • siervo: corrige la unión por inundación de WAN para ignorar los miembros de destino no activos (abandonados/izquierdos/fallidos), permitiendo que los servidores reincorporados se recuperen y vuelvan a estar activos en la membresía de WAN. [GH-23709]
  • xds: Adición de encabezados XFCC a la solicitud GPRC similar a la solicitud HTTP para el oyente entrante de proxy de conexión [GH-23744]
