cónsul ent-changelog-1.22.0

1.22.0+ent (24 de octubre de 2025)

Esta versión se creó para compartir Consul Enterprise changelog y notificar a los consumidores sobre la disponibilidad. La fuente y los recursos adjuntos no incluyen el código de Consul Enterprise y no deben usarse en lugar de imágenes o archivos binarios oficiales de Docker.

SEGURIDAD:

  • conectar: actualice la versión Envoy incluida de Consul a 1.35.3 y elimine la compatibilidad con 1.31.10. Esta actualización también incluye una solución para evitar fallas de inicio de Envoy (v1.35+) configurando solo el socket de transporte TLS cuando el paquete CA está presente. [GH-22824]
  • seguridad: Agregar advertencia cuando se habilitan las comprobaciones de secuencias de comandos remotas/locales sin habilitar las ACL [GH-22877]
  • seguridad: validación mejorada del encabezado Content-Length en el punto final de Consul KV para evitar posibles ataques de denegación de servicioCVE-2025-11374 [GH-22916]
  • seguridad: agregar una longitud de contenido máxima en el punto final del evento para corregir ataques de denegación de servicio (DoS). Esto resuelve CVE-2025-11375. [GH-22836]
  • seguridad: cambio importante: agregar una validación de nombre de clave en el punto final clave/valor junto con la configuración DisableKVKeyValidation para deshabilitarla/habilitarla para corregir ataques transversales de ruta en políticas de ACL mal configuradas o faltantes. [GH-22850]

CARACTERÍSTICAS:

  • Se agregó soporte para registrar un servicio en cónsul con múltiples puertos [GH-22769]
  • agente: Se agregó la función de utilidad IsDualStack para detectar si el agente está configurado para IPv4 e IPv6 (modo de doble pila) en función de su dirección de enlace recuperada de "agente/auto" API. [GH-22741]
  • instalar: información de licencia actualizada que se muestra durante la postinstalación
  • ipv6: adición de cambios de ip6tables para ipv6 y soporte de doble pila [GH-22787]
  • oidc: agrega autenticación client usando la aserción JWT y PKCE. PKCE predeterminado está habilitado. [GH-22732]

MEJORAS:

  • seguridad: actualice golang a 1.25.3. [GH-22926]
  • ui: corrige problemas de anulación de propiedades calculadas que ocurren actualmente y, en algunos casos, de forma preventiva, ya que esto ha quedado obsoleto en ember v4 [GH-22947]
  • ui: elimina instancias de acción de envío como parte de https://deprecations.emberjs.com/id/ember-component-send-action/ [GH-22938]
  • ui: reemplazó los parciales de ember con componentes como un paso incremental para actualizar a ember v4 [GH-22888]
  • api: Se agregó un nuevo API (/v1/operator/utilization) para admitir API empresarial para informes instantáneos manuales [GH-22837]
  • cmd: se agregó un nuevo subcomando consul operator utilization [-today-only] [-message] [-y] para generar un paquete con una instantánea de utilización del censo. El flujo principal se implementa en cónsul-empresa. http: Se agregó un nuevo controlador API para /v1/operator/utilization. Funcionalidad principal que se implementará en cónsul-enterprise agente: Siempre habilitada la recopilación de métricas del censo con opción configurable para exportarla a Hashicorp Reporting [GH-22843]
  • cli: snapshot agent ahora admite la autenticación en Azure Blob Storage mediante Azure Managed Service Identities (MSI). [GH-11171]
  • comando: conecte los valores predeterminados del bootstrap del enviado a 127.0.0.1 en un entorno solo IPv4 y a ::1 en un entorno IPv6/DualStack. [GH-22763]
  • conectar: dirección upstream.local_bind_address predeterminada a ::1 para la dirección de enlace del agente IPv6 [GH-22773]
  • proxy: proxy.local_service_address predeterminado en ::1 para la dirección de enlace del agente IPv6 [GH-22772]
  • ui: Funciones de accesibilidad mejoradas en la interfaz de usuario de Consul para mejorar la usabilidad para usuarios con discapacidades [GH-22770]
  • ui: Reemplazar hilo con pnpm para gestión de paquetes [GH-22790]
  • ui: los valores de configuración del método de autenticación estaban desbordados. Este PR soluciona el problema y agrega saltos de palabra para elementos de tabla con contenido grande. [GH-22813]

CORRECCIÓN DE ERRORES:

  • ui: permite que FQDN se muestre en la interfaz web de Consul. [GH-22779]
  • interfaz de usuario: soluciona el problema por el cual los espacios de nombres desaparecían y aparecía la pantalla Bienvenido al espacio de nombres después de cambiar de pestaña [GH-22789]
  • ui: soluciona el problema por el cual, al eliminar múltiples tokens o políticas, los tres puntos en el lado derecho dejan de responder después de la primera eliminación. [GH-22752]
  • cmd: corrige consul operator utilization --help para mostrar solo las opciones disponibles sin parámetros adicionales. [GH-22912]
