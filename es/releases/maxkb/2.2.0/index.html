#MaxKBv2.2.0

Release Note para MaxKB v2.2.0 Edición comunitaria

En MaxKB v2.2.0 Community Edition, con respecto a Aplicaciones: Las aplicaciones de orquestación avanzada han agregado nodos de bucle, nodos de reconocimiento de intención, nodos de texto a video y nodos de imagen a video. Las aplicaciones simples ahora admiten MCP y funciones de llamada de herramientas, y tienen capacidades de generación de mensajes recientemente agregadas. Para Herramientas: MaxKB ha lanzado una nueva Tienda de herramientas, que permite a los usuarios seleccionar las herramientas necesarias directamente sin desarrollo propio. En términos de Modelos: MaxKB ha agregado soporte para modelos de texto a video e imagen a video de Alibaba Cloud BaiLian y Volcano Engine.
Para el Paquete de mejora X-Pack: MaxKB admite la configuración del método de inicio de sesión predeterminado, lo que permite a los administradores personalizar los canales de inicio de sesión predeterminados del sistema (por ejemplo, inicio de sesión con contraseña de cuenta, inicio de sesión de terceros, etc.) según las necesidades de la empresa; También admite recientemente la configuración para habilitar la verificación de captcha después de N intentos fallidos de inicio de sesión.

Nuevas características

  • Herramientas: Almacén de herramientas agregado;
  • Aplicaciones: Nodo de bucle agregado, Nodo de interrupción y Nodo de continuación;
  • Aplicaciones: Nodo de reconocimiento de intención agregado;
  • Aplicaciones: Nodo de texto a video agregado;
  • Aplicaciones: Nodo de imagen a video agregado;
  • Aplicaciones: las aplicaciones simples ahora admiten MCP y funciones de llamada de herramientas;
  • Aplicaciones: se agregó soporte para la generación de mensajes;
  • Aplicaciones: Se agregó la configuración del interruptor "Salida MCP/Proceso de ejecución de herramientas";
  • Aplicaciones: los nodos de asignación de variables ahora admiten el tipo de datos bool al asignar valores;
  • Aplicaciones: la información de configuración de MCP admite el análisis de variables;
  • Aplicaciones: los usuarios de conversación admiten la configuración para habilitar la verificación de captcha después de un número específico de intentos fallidos de inicio de sesión en la cuenta (X-Pack);
  • Base de conocimientos: admite la configuración de parámetros para modelos que manejan tareas de generación de preguntas;
  • Modelos: el proveedor Alibaba Cloud BaiLian ha agregado soporte para los modelos de texto a video e imagen a video;
  • Modelos: el proveedor Volcano Engine ha agregado soporte para modelos de texto a video e imagen a video;
  • Modelos: los modelos de reconocimiento de voz admiten la configuración de parámetros del modelo;
  • Iniciar sesión: se agregó la configuración del método de inicio de sesión predeterminado (X-Pack);
  • Iniciar sesión: configuración agregada para habilitar la verificación de captcha después de un número específico de intentos fallidos de inicio de sesión del usuario (X-Pack);
  • Iniciar sesión: se actualizó el captcha de inicio de sesión a un mecanismo de autenticación con funcionalidad de aislamiento de usuario.

Optimizaciones de funciones

  • Página de preguntas y respuestas: se agregó una operación de acceso directo "Volver al final";
  • Base de conocimientos: la lista de preguntas admite la configuración de opción "Mostrar 1000 elementos";
  • Aplicaciones: se optimizó el estilo de visualización de "Agregar componente" para aplicaciones de orquestación avanzada;
  • Aplicaciones: se optimizaron las descripciones de los mensajes del sistema y del usuario;
  • Gestión de recursos: Se agregó soporte para filtrar por tipo en las opciones de filtro de la lista de recursos (X-Pack).

Corrección de errores

  • Base de conocimientos: se solucionó el problema por el cual la exportación de una base de conocimientos expiraba y reportaba un error cuando la base de conocimientos contenía una gran cantidad de datos (#3995);
  • Aplicaciones: Se solucionó el problema por el cual el proceso de pensamiento no regresaba al usar la interfaz de la aplicación API para conversaciones (#4084);
  • Aplicaciones: se solucionó el problema por el cual el orden de visualización de los métodos de inicio de sesión en Restricciones de acceso no estaba ordenado por categoría (#4049);
  • Aplicaciones: se solucionó el problema por el cual la configuración de la opción "Límite de preguntas por Client" en Restricciones de acceso no surtía efecto (#4042);
  • Página de preguntas y respuestas: se solucionó el problema por el cual el botón de enviar no se mostraba en algunos navegadores del sistema iOS;
  • Página de preguntas y respuestas: se solucionó el problema por el cual al actualizar el navegador en la página de preguntas y respuestas se abría la página de lista de aplicaciones después de configurar los parámetros de la interfaz de preguntas en la configuración de la aplicación (#4076);
  • Página de preguntas y respuestas: se solucionó el problema por el cual el estilo de fuente del proceso de pensamiento era incorrecto (#2792);
  • Modelos: se solucionó el problema por el cual la configuración de parámetros para el modelo de síntesis de voz del proveedor Silicon Flow no surtía efecto.
