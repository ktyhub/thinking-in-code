MaxKB v2.8.0

Menor Publicado10 abr 2026 Fuente1Panel-dev/MaxKB original en inglés

Esta página está traducida automáticamente. El texto original en inglés es la referencia.

#MaxKBv2.8.0

Nuevas funciones

  • Herramientas: Se agregaron herramientas de tipo flujo de trabajo;
  • Herramientas: generación automática de código Python compatible;
  • Base de conocimientos: admite la importación y exportación de todos los metadatos de la base de conocimientos;
  • Agente: admitió la selección de modelos y bases de conocimiento durante la conversación;
  • Agente: selección por lotes admitida para mover a otras carpetas o realizar eliminación por lotes;
  • Agente: Se agregaron configuraciones de alternancia del proceso de pensamiento para los nodos "Comprensión de imágenes" y "Comprensión de videos" en agentes avanzados;
  • Base de conocimientos: selección por lotes admitida para mover a otras carpetas o realizar eliminación por lotes;
  • Herramientas: selección por lotes admitida para mover a otras carpetas o realizar eliminación por lotes;
  • Modelos: Se agregó soporte para reclasificar modelos del proveedor Baidu Qianfan (#4927);
  • Sistema: unificó todos los campos de visualización de nombres de usuario en el sistema para mostrar el nombre completo del usuario;
  • Agente: el nodo "Agregación de variables" en agentes avanzados ahora admite la agregación en variables de tipo dict (#4904);
  • Agente: Optimizado el componente de expresión dividida del nodo "División de variables" en agentes avanzados (#4961).

Corrección de errores

  • Agente: se corrigió un error en las preguntas de los usuarios al usar modelos vLLM con indicaciones del sistema y herramientas de Habilidades/MCP en el nodo Conversación de IA;
  • Agente: se solucionó el problema de incompatibilidad entre los modelos vLLM y el campo de razonamiento;
  • Agente: Se corrigieron resultados de recuperación incorrectos al usar el nodo de recuperación de etiquetas de documentos (#4942);
  • Agente: se solucionó el problema por el cual no se guardaba el estado colapsado de los nodos de bucle en la orquestación avanzada (#4996);
  • Agente: se corrigió un error en el nodo Comprensión de imágenes durante conversaciones de varios turnos cuando las imágenes no se envían a mitad de camino y luego se envían nuevamente (#4999);
  • Agente: Se corrigieron problemas de representación en blanco al usar ECharts (#4966);
  • Agente (X-Pack): se solucionó el problema por el cual las imágenes enviadas a través de WeChat Work no se podían abrir después de descargarlas desde los registros de conversación de MaxKB;
  • Agente (X-Pack): se solucionó el problema por el cual la autenticación no se realizaba durante las conversaciones después de habilitar la autenticación de identidad para subagentes en agentes avanzados;
  • Base de conocimientos: Se corrigió la descripción inexacta de "Permitir vista previa en fuentes de conocimiento" en la base de conocimientos del sitio web;
  • Modelos: se corrigieron los mensajes de error que faltaban cuando se excede el límite de tokens o el saldo es insuficiente para los modelos de reclasificación de Alibaba Cloud Bailian (#4928);
  • Modelos (X-Pack): Se corrigió el error de permiso cuando los usuarios regulares click en modelos compartidos;
  • Roles (X-Pack): se solucionó el problema por el cual otros permisos se verificaban automáticamente al personalizar el permiso "Acerca de" para usuarios normales (#4954);
  • Administración de recursos (X-Pack): se solucionó el problema por el cual los roles de usuario no se mostraban al autorizar recursos en la administración de recursos.

Correcciones de vulnerabilidades de seguridad

  • Seguridad: Se corrigió la vulnerabilidad SSRF que omitía el enlace sandbox connect() a través de socket.sendto()+MSG_FASTOPEN para evitar el acceso a servicios internos restringidos (#CVE-2026-39418);
  • Seguridad: Se corrigió la vulnerabilidad de ejecución remota de código para el escape de la zona de pruebas a través de env -i LD_PRELOAD para borrar las variables de entorno (#CVE-2026-39420);
  • Seguridad: Se corrigió la vulnerabilidad de omisión de la zona de pruebas para la suplantación de resultados a través de sys.exit(0) para omitir la verificación de resultados de la zona de pruebas (#CVE-2026-39419);
  • Seguridad: Se corrigió una vulnerabilidad crítica de ejecución remota de código para el escape de la zona de pruebas a través de ctypes y SYS_pkey_mprotect desenganchado (#CVE-2026-39421);
  • Seguridad: Se corrigió la vulnerabilidad de ejecución remota de código para la inyección de comandos Shell a través de una configuración maliciosa debido a la falta de validación de la configuración del servidor MCP (#CVE-2026-39417);
  • Seguridad: Se corrigió la vulnerabilidad general almacenada de secuencias de comandos entre sitios (XSS) y se fortaleció la validación de seguridad de las entradas del usuario en todos los escenarios (#CVE-2026-39422);
  • Seguridad: Se corrigió la vulnerabilidad XSS almacenada en iframe_render causada por la entrada del usuario sin filtrar (#CVE-2026-39426);
  • Seguridad: Se corrigió la vulnerabilidad XSS almacenada en Markdown al representar html_rander debido a etiquetas HTML sin filtrar (#CVE-2026-39425);
  • Seguridad: Se corrigió la vulnerabilidad XSS almacenada en el componente echarts_rander mediante la inyección de código malicioso Eval (#CVE-2026-39423);
  • Seguridad: Se corrigió la vulnerabilidad de inyección de CSV causada por caracteres especiales sin escape al exportar registros de chat de aplicaciones a CSV (variante de CVE-2025-4546) (#CVE-2026-39424).
