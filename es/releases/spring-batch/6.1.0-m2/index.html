spring-batch v6.1.0-M2

Pre-release Publicado24 sept 2026 Fuentespring-projects/spring-batch original en inglés

Esta página está traducida automáticamente. El texto original en inglés es la referencia.

lote de primavera v6.1.0-M2

:star: Nuevas funciones

  • Permitir usar Mongo JobRepository con cualquier PlatformTransactionManager #5508
  • Agregar un constructor para ResourcesItemReader con soporte para especificar recursos mediante un patrón #5487
  • Presentar BatchConstants #5190
  • Nombre de lector/escritor predeterminado para el nombre del bean #5149
  • Soporte para especificar ubicaciones de recursos usando un patrón en MultiResourceItemReaderBuilder #5056
  • Se agregó soporte para el prefijo de colección personalizado en el repositorio de trabajos de MongoDB #4980
  • Agregar seguridad en tiempo de compilación para métodos de creación mutuamente excluyentes #4888
  • Agregar ubicaciones de esquema a DatabaseType para evitar errores tipográficos en la ruta de cadena de las tablas de metadatos #4586

:lady_beetle: Corrección de errores

  • Los métodos de recuento a nivel de repositorio/DAO no pueden validar correctamente la existencia del trabajo/paso #5544
  • Los métodos @OnSkipInRead/@OnSkipInProcess/@OnSkipInWrite son ignorados por ChunkOrientedStepBuilder#listener(Object) #5531
  • El fragmento revertido se cuenta como escrito y el paso COMPLETADO en ChunkOrientedStep (reintento tolerante a fallos de OptimisticLockException) #5509
  • TransientTransactionError en MongoSequenceIncrementer durante ejecuciones de trabajos en paralelo #5507
  • Se corrigió la deserialización de QName en JacksonExecutionContextStringSerializer #5502
  • El modo de escaneo ChunkOrientedStep pasa el fragmento procesado a ChunkListener#beforeChunk y descarta silenciosamente los elementos de escaneo cuando el oyente lanza #5493
  • ChunkOrientedStep no vuelve a invocar ItemProcessor durante el escaneo de fragmentos, a diferencia de FaultTolerantChunkProcessor #5490
  • Falta la verificación nula de JpaCursorItemReader.doClose() en el administrador de entidad #5486
  • Se corrigió el contrato de nulidad incorrecto para la codificación en StaxEventItemReader #5483
  • JsonFunctionalTests falla en Windows debido a CRLF #5481
  • @OnChunkError nunca se invoca en un paso orientado a fragmentos #5468
  • Las devoluciones de llamadas de escucha de interfaz se invocan dos veces cuando un controlador de elementos también tiene una anotación de escucha #5466
  • spring.batch.job.launch.count falta silenciosamente: el JobOperator mantiene ObservationRegistry.NOOP en la mayoría de las rutas de configuración #5463
  • Manejo inconsistente del tipo JobParameter entre el almacenamiento y la recuperación en Spring Batch 6.x #5455
  • Los métodos @BeforeStep/@AfterStep son ignorados por ChunkOrientedStepBuilder#listener(Object) #5451
  • Reemplace jetbrains @NotNull con jspecify @NonNull #5443
  • SimpleJobOperator.restart(JobExecution) enmascara el motivo real del fallo con un mensaje engañoso que dice "la ejecución del trabajo ya se está ejecutando" #5439
  • Faltan sugerencias de tiempo de ejecución GraalVM para las clases y recursos del modelo de persistencia de MongoDB #5435
  • Se corrigió JsonFileItemWriter para producir JSON válido cuando se permite agregar con devolución de llamada personalizada de encabezado/pie de página #5432
  • El nombre del paso es nulo cuando el paso no está definido como un bean y no tiene asignado un nombre #5278
  • Clasificación forzada mediante el método sorts() al compilar con MongoCursorItemReaderBuilder y consulta #4860
  • Orden de invocación incorrecto del escucha de ejecución de trabajos en la partición remota #4133
  • La implementación de fragmentación remota no admite ejecuciones paralelas del mismo trabajo #1372

:cohete: Mejoras

  • Eliminar métodos redundantes que son idénticos al método predeterminado #5516
  • Nombre del método de creación incoherente: MultiResourceItemReaderBuilder.setStrict() #5512
  • Mejorar DefaultJobParametersConverter y JsonJobParametersConverter #5457
  • Reemplace isAssignableFrom() con isInstance() cuando sea posible #5427
  • Eliminar la importación ClassUtils no utilizada de JdbcPagingItemReader #5407
  • Agregar @FunctionalInterface a StepInterruptionPolicy #5402
  • Se corrigió el mensaje de estado del registro de trabajo SimpleJobOperator #5369
  • Reemplace el obsoleto Jackson2JsonMessageConverter con JacksonJsonMessageConverter #5350
  • Reemplace System.getProperty("line.separator") con System.lineSeparator() #5341
  • Eliminar verificación nula innecesaria contra createTime de ejecución #5304
  • Mensaje de excepción inexacto al intentar iniciar un trabajo en ejecución #5280
  • Mejorar JacksonExecutionContextStringSerializer #5233
  • Reemplazar convertidores personalizados con DefaultFormattingConversionService #5186
  • Mover el procesamiento asíncrono API a spring-batch-core #5185
  • Reemplace CopyOnWriteArrayList con ArrayList en JdbcPagingItemReader y JpaPagingItemReader para mejorar el rendimiento y la corrección #5112
  • Agregar soporte de descarga en RepositoryItemWriter #5073

:notebook_with_decorative_cover: Documentación

  • Corregir Javadoc #5545
  • Documentación inexacta de muestras de fragmentación y partición remota relacionadas con encabezados JMS #5513
  • Corregir errores tipográficos en los comentarios de Javadoc #5511
  • Aclarar la compatibilidad de lecturas reintentables con semántica de solo avance #5510
  • Aclarar el contrato SkipListener y los documentos de referencia sobre el alcance de la transacción #5494
  • El ejemplo de seguimiento de la documentación de referencia registra un controlador que no crea intervalos y falla el trabajo #5475
  • Se corrigió el error tipográfico en Javadoc de JobOperator.start() #5434
  • Ejemplo incorrecto en Registering ItemStream with a Step #5429
  • Se corrigió la referencia incorrecta de Javadoc en JobExecution.isStopped() #5414
  • Se corrigió javadoc en SqlPagingQueryUtils #5403
  • Se corrigió el error tipográfico en EnableBatchProcessing Javadoc #5375
  • JavaDoc inexacto de BatchStatus.isLessThanOrEqualTo #5285
  • Mejorar la documentación sobre cómo aprovechar IteratorItemReader para reutilizar los API de desplazamiento de Spring Data #4484

:hammer: Tareas

  • Utilice constantemente el sufijo .version para las propiedades de la versión en pom.xml #5506
  • Actualice el ID de grupo de Apache Artemis a org.apache.artemis #5482
  • Actualice la versión Groovy a 5.1.2 #5327
  • Desaprobar los captadores de conveniencia JobExecution para la identificación de JobInstance #5533
  • Desaprobar setRepository en RepositoryItemWriter #5473
  • Desaprobar setRepository y setSorts en RepositoryItemReader #5472
  • Desaprobamos el soporte de Derby ya que Apache Derby está retirado #5254
  • Desaprobar JobInstance::getInstanceId para eliminarlo y eliminar la redundancia #5244
  • Desaprobar los captadores de conveniencia StepExecution para la identificación y los parámetros de JobExecution #5142
  • Desaprobar setEntityManagerFactory en lectores/escritores de elementos JPA #5101
