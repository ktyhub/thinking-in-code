spring-batch v6.0.0

Mayor Publicado19 nov 2025 Fuentespring-projects/spring-batch original en inglés

Esta página está traducida automáticamente. El texto original en inglés es la referencia.

lote de primavera v6.0.0

Spring Batch 6.0 es una versión importante que viene con varias características nuevas, mejoras y correcciones de errores. Esta versión presenta una serie de cambios importantes y obsolescencias de API. Consulte la guía de migración para obtener la lista completa de cambios.
