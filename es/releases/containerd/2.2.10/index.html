contenedor v2.2.10

¡Bienvenido al lanzamiento v2.2.10 de Containerd!

La décima versión del parche para 2.2 en contenedor contiene varias correcciones y actualizaciones, incluidos parches de seguridad.

Destacados

Interfaz de ejecución de contenedor (CRI)

  • Aplicar protección para no seguir enlaces simbólicos para archivos de registro de contenedores (#14300)

Distribución de imágenes

  • Evite bloqueos y corrupción de datos durante la recuperación de imágenes de varias partes (#14316)
  • Aplicar endurecimiento para rechazar referencias de imágenes con componentes de ruta ".." (#14280)

Tiempo de ejecución

  • Aplicar refuerzo a los dominios de socket de la lista permitida en el perfil seccomp predeterminado (#14249)

Instantáneas

  • Aplicar refuerzo para filtrar etiquetas de asignación de ID de anotaciones de imágenes durante el descomprimido (#14269)

Pruebe los binarios de lanzamiento e informe cualquier problema en https://github.com/containerd/containerd/issues.

Cambios de dependencia

Esta versión no tiene cambios de dependencia.

La versión anterior se puede encontrar en v2.2.9

¿Qué archivo debo descargar?

  • containerd-<VERSION>-<OS>-<ARCH>.tar.gz: ✅Recomendado. Vinculado dinámicamente con glibc 2.35 (Ubuntu 22.04).
  • containerd-static-<VERSION>-<OS>-<ARCH>.tar.gz: Vinculado estáticamente. Se espera que se use en distribuciones de Linux que no usan glibc >= 2.35. No independiente de la posición.

Además del contenedor, normalmente tendrás que instalar runc y [complementos CNI] (https://github.com/containernetworking/plugins/releases) también de sus sitios oficiales.

Consulte también la documentación Cómo comenzar.
