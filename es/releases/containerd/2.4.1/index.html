contenedor v2.4.1

¡Bienvenido al lanzamiento v2.4.1 de Containerd!

La primera versión del parche para 2.4 en contenedor contiene varias correcciones y actualizaciones que incluyen un parche de seguridad.

Actualizaciones de seguridad

  • contenedor
    • CVE-2026-53493

Destacados

Interfaz de ejecución de contenedor (CRI)

  • Se corrigió el error por el cual la limpieza de inicio fallido del contenedor filtraba tareas e impedía la eliminación del contenedor (#14223)
  • Se corrigió el error por el cual fallaba la creación del contenedor cuando el sistema de archivos no admitía el reetiquetado de SELinux (#14212)

Distribución de imágenes

  • Solucionar fallas en la carga de contenido al volver a intentar recuperar contenido después de alcanzar el EOF (#14197)

Instantáneas

  • Aplicar refuerzo para filtrar etiquetas de asignación de ID de anotaciones de imágenes durante el descomprimido (#14200)

herramienta de desarrollo ctr

  • Se corrigió el error por el cual los argumentos después de "-" se eliminaban en "exportación de imágenes ctr" (#14219)
  • Se corrigió el error por el cual los argumentos del comando del contenedor se analizaban como indicadores en "ctr run", "ctr contenedores create", "ctr task exec" y "containerd oci-hook" (#14215)
  • Se corrigió el error por el cual los valores de las banderas separados por comas se dividían incorrectamente en los subcomandos ctr (#14188)

Pruebe los binarios de lanzamiento e informe cualquier problema en https://github.com/containerd/containerd/issues.

¿Qué archivo debo descargar?

  • containerd-<VERSION>-<OS>-<ARCH>.tar.gz: ✅Recomendado. Vinculado dinámicamente con glibc 2.35 (Ubuntu 22.04).
  • containerd-static-<VERSION>-<OS>-<ARCH>.tar.gz: Vinculado estáticamente. Se espera que se use en distribuciones de Linux que no usan glibc >= 2.35. No independiente de la posición.

Además del contenedor, normalmente tendrás que instalar runc y [complementos CNI] (https://github.com/containernetworking/plugins/releases) de sus sitios oficiales también.

Consulte también la documentación Cómo comenzar.
