contenedor v2.0.14

¡Bienvenido al lanzamiento v2.0.14 de Containerd!

La decimocuarta versión del parche para 2.0 en contenedor contiene varias correcciones y actualizaciones que incluyen un parche de seguridad.

Actualizaciones de seguridad

  • contenedor
    • GHSA-hc94-p972-ch66

Destacados

Interfaz de ejecución de contenedor (CRI)

  • Aplicar protección para no seguir enlaces simbólicos para archivos de registro de contenedores (#14299)

Tiempo de ejecución

  • Aplicar refuerzo a los dominios de socket de la lista permitida en el perfil seccomp predeterminado (#14251)

Instantáneas

  • Aplicar refuerzo para filtrar etiquetas de asignación de ID de anotaciones de imágenes durante el descomprimido (#14270)

Cambios de dependencia

Esta versión no tiene cambios de dependencia.

La versión anterior se puede encontrar en v2.0.13

¿Qué archivo debo descargar?

  • containerd-<VERSION>-<OS>-<ARCH>.tar.gz: ✅Recomendado. Vinculado dinámicamente con glibc 2.31 (Ubuntu 20.04).
  • containerd-static-<VERSION>-<OS>-<ARCH>.tar.gz: Vinculado estáticamente. Se espera que se utilice en distribuciones de Linux que no sean glibc. No independiente de la posición.

Además del contenedor, normalmente tendrás que instalar runc y [complementos CNI] (https://github.com/containernetworking/plugins/releases) de sus sitios oficiales también.

Consulte también la documentación Cómo comenzar.
