mlflow v3.15.0

MLflow 3.15.0 incluye varias características y mejoras importantes

Nuevas características importantes

  • 🧩 Registro MCP: un catálogo centralizado para registrar, controlar versiones y compartir servidores de protocolo de contexto modelo, con configuraciones con versiones semánticas, alias promocionables, etiquetas, herramientas descubiertas automáticamente e instrucciones de conexión listas para usar para Claude Code y .mcp.json. ¡Gestionelo desde la interfaz de usuario, REST API o Python!
  • 🤖 Mejoras en MLflow Assistant: el asistente de IA en la aplicación ahora admite múltiples proveedores de LLM (Claude Code, Codex y puntos finales compatibles con OpenAI/Gateway) elegidos desde una única página de configuración, muestra el uso de tokens por sesión en vivo y el costo estimado en el compositor, y es más fácil de configurar: mlflow agent setup puede habilitarlo en un solo mensaje, con las claves API almacenadas de forma segura en las conexiones LLM de Gateway.
  • 🗂️ Vistas de tabla compartibles: guarde vistas con nombre de la tabla Ejecuciones (capturando columnas, orden, anchos, filtros y clasificación) y compártalas por URL.
  • ⚡ Carga/descarga de artefactos sin proxy a través de URL prefirmadas: las transferencias de artefactos grandes ahora pueden omitir el servidor de seguimiento y comunicarse directamente con el almacenamiento en la nube (por ejemplo, S3) a través de URL prefirmadas, lo que reduce la carga del servidor y los tiempos de espera en archivos grandes. Recurrimos a la transferencia proxy automáticamente para lograr compatibilidad con versiones anteriores.
  • 🖼️ Archivos adjuntos multimodales en jueces LLM: los jueces {{ trace }} creados con make_judge() ahora pueden ver imágenes capturadas en tramos de seguimiento a través de una nueva herramienta get_span_image, que recupera archivos adjuntos como URL de datos base64 y los pasa a modelos multimodales (antrópico, gemini y compatible con OpenAI a través de litellm), lo que permite la evaluación de tareas de visión, capturas de pantalla y otro contenido visual.
