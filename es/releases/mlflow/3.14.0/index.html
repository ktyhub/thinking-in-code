mlflow v3.14.0

MLflow 3.14.0 incluye varias características y mejoras importantes

Nuevas características importantes

  • 🚀 Incorporación de agente de un solo comando con mlflow agent setup: instale MLflow, configure el seguimiento y entregue a su agente de codificación favorito (Claude Code, OpenAI Codex u OpenCode) las habilidades de MLflow para instrumentar su aplicación, todo desde un solo comando.
  • ⚡ Seguimiento duradero y de baja latencia para Claude Code: implemente el seguimiento de Claude Code en todo un equipo con confianza: un registro de escritura anticipada evita que ralentice al agente, sobrecargue el servidor de seguimiento o pierda rastros en una falla o caída de la red.
  • 📝 Colas de revisión para seguimientos: asigne seguimientos a revisores (o agentes) y recopile comentarios estructurados y anotaciones reales en la interfaz de usuario, escritas directamente en el seguimiento para que se puedan utilizar de inmediato para la evaluación.
  • 🗂️ UI de conjunto de datos de evaluación renovada: explore, inspeccione, edite y administre de forma masiva registros de conjuntos de datos de evaluación directamente en la interfaz de usuario, con click hasta el seguimiento de origen.
  • 🧪 Integración de Pytest para pruebas de regresión: escriba pruebas de regresión GenAI como funciones simples de pytest con el marcador @mlflow.test, contéctelas en CI y revise el historial de pruebas y los resultados de los jueces por aserción en la interfaz de usuario.
  • 🎛️ LLM Playground: itere las indicaciones en el navegador con sus puntos finales de AI Gateway y las versiones de Registro de indicaciones, con configuraciones, herramientas, resultados estructurados y variables de plantilla.

Cambios importantes

  • [Modelos] Cambie el valor predeterminado de mlflow.sklearn serialization_format de cloudpickle a skops (#23987, @copilot-swe-agent)
  • [Modelos] Cambie el valor predeterminado de serialization_format a "pt2" para mlflow.pytorch.log_model y mlflow.pytorch.save_model (#23988, @copilot-swe-agent)
  • [Modelos] Cambie el valor predeterminado de serialization_format a "skops" en mlflow.lightgbm log_model/save_model (#23986, @copilot-swe-agent)
