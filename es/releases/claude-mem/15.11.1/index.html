claude-mem v15.11.1

El inicio de sesión profesional vuelve a funcionar

Iniciar sesión en cmem.ai Pro desde el complemento arrojó un error 500 en cada instalación nueva del complemento. La instalación del complemento no incluyó better-auth y sus tablas nunca se crearon. El complemento ahora incluye better-auth y @better-auth/api-key como dependencias y crea las tablas de autenticación la primera vez que se necesitan (#5455, gracias @0xABCD01).

Correcciones

  • Trabajador: cuando una ejecución se detiene después de un transporte, límite de velocidad o un aborto similar, ahora libera sus reclamos, por lo que la sesión pausada ya no tiene trabajo pendiente que nunca puede caducar (#5457, gracias @akashpandey).
  • Trabajador: una respuesta condensada que excede el presupuesto se fija en el presupuesto en lugar de desecharse (#5452, gracias @xunguangzlj-cloud).
  • Trabajador: reintento sin razonamiento ahora reconoce la redacción del error "no se puede representar" de OpenCode Go (#5439, gracias @akashpandey).
  • Ganchos: el gancho Stop lee last_assistant_message de Claude Code directamente y omite la lectura de la transcripción (#5449, gracias @xunguangzlj-cloud).
  • Contexto: la sugerencia de OAuth y el aviso de reserva de la puerta de enlace se reservan antes de que se ajuste el contexto, por lo que el contexto de SessionStart permanece por debajo del límite de 10 000 caracteres de Claude Code (#5441, gracias @liuyinchu).
  • Codex: los procesos secundarios obsoletos del servidor de aplicaciones se reciclan en la sonda de recuperación de autenticación (#5438, gracias @akashpandey).
  • Instalador: la configuración de Goose YAML está escrita de forma atómica, por lo que una instalación o desinstalación interrumpida ya no puede dejar una configuración truncada.yaml (#5442, gracias @DeryFerd).
  • Pruebas: la matriz de sincronización espera el cuerpo de la página antes de leerla, lo que soluciona una carrera de preparación del navegador (#5448).

También en esta versión

  • Mi trabajo: el intervalo de verificación de actualización programado ahora es una configuración (#5437, gracias @weirui828).
  • Documentos: una historia en el README y los documentos: su agente de codificación se olvida entre sesiones, recuerda Claude-Mem (#5447).
  • Documentos: Las traducciones README mantienen intactos los ejemplos de código delimitado y los enlaces entre comillas simples (#5458, gracias @Afloat16).
