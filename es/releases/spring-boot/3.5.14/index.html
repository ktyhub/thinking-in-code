:lady_beetle: Corrección de errores

  • ApplicationPidFileWriter no maneja enlaces simbólicos correctamente #50173

  • Las anotaciones como @Ssl no funcionan en los métodos @Bean cuando se usa @ServiceConnection #50033
  • Los valores de números enteros se ignoran al configurar los valores esperados mínimos y máximos y los límites de SLO para un medidor de resumen de distribución #50021
  • El punto final de enlaces de WebFlux Cloud Foundry incluye una cadena de consulta de la solicitud recibida en enlaces resueltos #50008
  • Respuesta 500 del punto final env cuando el patrón proporcionado no es válido #49942
  • El método HTTP se pierde al configurar exclusiones en EndpointRequest #49885
  • Docker La compatibilidad con Compose no funciona con la imagen de Apache/artemis #49865
  • Respetar HttpMethod para rutas de puntos finales adicionales reactivas #49864
