bota de resorte v4.0.9

:star: Nuevas funciones

  • Agregue TWENTY_SEVEN a la enumeración JavaVersion #51422

:lady_beetle: Corrección de errores

  • Los JWT se rechazan cuando el uri emisor está vacío y el uri jwk-set está configurado #52249
  • Faltan atributos de manifiesto de paquete para archivos jar anidados sin entradas de directorio #52244
  • OriginTrackedPropertiesLoader elimina propiedades cuyo nombre comienza con # o ! #52207
  • OriginTrackedResource no implementa iguales correctamente #52205
  • El cierre ordenado de Tomcat o Jetty puede devolver la llamada con REQUESTS_ACTIVE cuando se llama a detener inmediatamente después de cerrarGracefully en un servidor inactivo #52195
  • La propiedad del sistema vacía en TestPropertyValues se borra en lugar de restaurarse a su valor vacío #52125
  • MongoDB no puede conectarse cuando las credenciales contienen un espacio #52121
  • La detención de NettyWebServer puede bloquearse cuando se llama inmediatamente después de cerrarGracefully #52119
  • La autenticación falla cuando la contraseña configurada en spring.elasticsearch.uris contiene dos puntos #52047
  • El registro se puede perder cuando el marco de contexto de prueba pausa un contexto #51959
  • Docker La compatibilidad con Compose para MongoDB no se puede conectar cuando las credenciales contienen un carácter que requiere codificación URL #51939
  • Jersey no utiliza el punto final ObjectMapper cuando el actuador se ejecuta en un puerto separado #51937
  • BasicJsonParser maneja mal los caracteres de escape en listas y mapas anidados #51907
  • La conversión del valor de semana cero falla con la excepción 'intValue no se puede extraer de SEMANAS' #51892
  • La aplicación no se inicia cuando se utilizan DevTools y se configura manualmente JDBC o R2DBC sin spring-boot-jdbc o spring-boot-r2dbc #51872
  • Docker El soporte de redacción reconoce incorrectamente MARIADB_ALLOW_EMPTY_PASSWORD en lugar de MARIADB_ALLOW_EMPTY_ROOT_PASSWORD #51870
  • La personalización del códec JSON de serialización Kotlinx configurada automáticamente no se aplica #51842
  • Se puede generar NullPointerException cuando se usan uber jars debido a una condición de carrera en NestedJarFileResources #51744
  • DevTools no detecta un entorno web reactivo #51708
  • La conexión falla cuando el servicio de redacción Rabbitmq Docker está configurado para usar SSL #51666
  • Cuando server.reactive.session.cookie.same-site no está configurado, las cookies de sesión no tienen el atributo SameSite #51636
  • El servidor de recursos OAuth2 ignora el delimitador de reclamos de autoridades cuando se configura por sí solo #51619
  • En una aplicación web reactiva, la integración de seguridad de Cloud Foundry devuelve un 500 en lugar de un 503 cuando la URL del controlador de la nube no está disponible #51613
  • Algunos mensajes de aserción nombran el parámetro incorrecto #51568
  • Faltan atributos de manifiesto relacionados con SBOM en las guerras empaquetadas con Maven #51551
  • Docker La integración de Compose para RabbitMQ omite las reservas de credenciales cuando una variable de entorno no tiene valor #51546
  • Los comandos de las herramientas jarmode imprimen stacktrace en lugar de un mensaje de error #51540
  • El archivo temporal de capa no se elimina cuando falla la creación de la capa #51519
  • NestedByteChannel.read(ByteBuffer) devuelve incorrectamente 0 cuando no se pudo llenar el búfer #51515
  • Las comprobaciones nulas del personalizador en los constructores HTTP client afirman el atributo incorrecto #51509
  • Las configuraciones developmentOnly y testAndDevelopmentOnly no especifican ningún atributo que cause posibles problemas de resolución #51492
  • La integración de SQL Server Docker Compose puede duplicar el parámetro de cifrado de la URL de JDBC #51467
  • Las personalizaciones de la configuración del host SSL pueden perderse durante la inicialización de Tomcat #51466
  • OAuth2ClientProperties no están disponibles cuando se proporciona un bean ClientRegistrationRepository definido por el usuario #51447
  • La fuente no se cierra consistentemente por todos los evaluadores de mariscal JSON #51417
  • JmsHealthIndicator pierde subprocesos de vigilancia si el inicio falla inmediatamente #51412
  • El identificador de archivo en SpringBootJoranConfigurator debe estar cerrado #51398
  • La validación del obsoleto io.buildpacks.stack.id es demasiado agresiva #51390
  • Las personalizaciones de la configuración del host SSL se pierden al recargar paquetes SSL #51290
  • Docker Compose ProcessRunner puede bloquear o dejar procesos huérfanos #50963
  • Las descripciones de las propiedades de configuración pueden perderse al compilar de forma incremental con Gradle #50489
