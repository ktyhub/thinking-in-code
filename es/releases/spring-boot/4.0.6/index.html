bota de resorte v4.0.6

:lady_beetle: Corrección de errores

  • La seguridad predeterminada está mal configurada cuando spring-boot-actuator-autoconfigure está presente y spring-boot-health no está #50188
  • La configuración automática de Elasticsearch Rest5Client configura incorrectamente el HTTP client subyacente #50187
  • ApplicationPidFileWriter no maneja enlaces simbólicos correctamente #50185
  • RandomValuePropertySource no es adecuado para secretos #50183
  • La configuración automática de Cassandra configura incorrectamente CqlSessionBuilder #50180
  • ApplicationTemp no maneja correctamente los enlaces simbólicos #50178
  • Remote DevTools realiza la comparación incorrectamente #50176
  • spring.rabbitmq.ssl.verify-hostname se aplica de manera inconsistente #50174
  • Los valores de números enteros se ignoran al configurar los valores esperados mínimos y máximos y los límites de SLO para un medidor de resumen de distribución #50077
  • A los iniciadores clásicos les faltan varios módulos #50071
  • Falta el módulo spring-boot-resttestclient en spring-boot-starter-test-classic #50069
  • Las anotaciones como @Ssl no funcionan en los métodos @Bean cuando se usa @ServiceConnection #50064
  • EnversRevisionRepositoriesRegistrar debería reutilizar @EnableEnversRepositories en lugar de configurar la contraparte JPA #50039
  • El punto final de enlaces de WebFlux Cloud Foundry incluye una cadena de consulta de la solicitud recibida en enlaces resueltos #50017
  • Las importaciones en una clase de prueba contenedora se ignoran cuando una clase anidada tiene importaciones #50012
  • Con spring.jackson.use-jackson2-defaults establecido en verdadero, FAIL_ON_UNKNOWN_PROPERTIES está habilitado #49951
  • Respuesta 500 del punto final env cuando el patrón proporcionado no es válido #49946
  • El iniciador reactivo de MongoDB tiene una dependencia transitiva del controlador sincrónico de MongoDB #49945
  • El método HTTP se pierde al configurar exclusiones en EndpointRequest #49943
  • Respetar HttpMethod para rutas de puntos finales adicionales reactivas #49880
  • Docker La compatibilidad con Compose no funciona con la imagen de Apache/artemis #49869
  • Docker La compatibilidad con Compose no funciona con la imagen de Apache/activemq #49866
  • PathPatternRequestMatcher.Builder de Spring Security no se configura automáticamente cuando se utiliza WebMvcTest y spring-boot-security-test #49854
  • La estrategia de ruta de control de versiones API debe aplicarse en último lugar, ya que no está destinada a producir #49800

:notebook_with_decorative_cover: Documentación

  • Actualizar documentos para fomentar los fundamentos de Java para principiantes que prefieren aprender de esa manera #50146
  • La interfaz de servicio HTTP Clients aún documenta que el control de versiones de API se puede configurar mediante propiedades #50126
  • El enlace a la sección de observabilidad de la documentación de Lettuce está roto #50097
  • Javadoc para StaticResourceLocation.FAVICON no describe la ubicación de los iconos #50085
  • A MySamlRelyingPartyConfiguration le falta una muestra de Kotlin #50024
  • Valor predeterminado incorrecto para management.httpexchanges.recording.include en los metadatos de configuración #50019
  • Enlace a la documentación de Kubernetes cuando se analizan las sondas de inicio #50015
  • Error tipográfico en el Javadoc JdbcSessionAutoConfiguration #49873
  • Aclarar que los valores predeterminados de las propiedades de configuración no están disponibles a través del Entorno #49851
  • Documentar la necesidad de iniciadores Liquibase y Flyway #49839
  • La documentación de Kafka hace referencia a las clases de serializador y deserializador JSON en desuso #49826
