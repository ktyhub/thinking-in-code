bota de resorte v4.1.0

Los release note completos para Spring Boot 4.1 están disponibles en la wiki.

:star: Nuevas funciones

  • Agregar constructor público a InvalidConfigurationPropertyValueException que acepta una causa #50211
  • Reducir el consumo de memoria al llamar repetidamente a WritableJson.toByteArray #49428

:lady_beetle: Corrección de errores

  • La configuración automática de MailSender no permite la verificación del nombre de host #50747
  • La configuración automática de Artemis utiliza una ubicación predeterminada predecible para los datos del broker integrado #50745
  • SSL LDAP integrado no debe habilitarse cuando su paquete está vacío #50700
  • InetAddressFilter.externalAddresses no excluye direcciones de propósito especial de RFC 6890 #50668
  • NullPointerException en reactor-netty SniProvider y paquete SSL no asignado con RSocket #50645
  • SSL no debe habilitarse cuando un paquete SSL se reemplaza por una cadena vacía #50635
  • La configuración automática de prueba ya no integra Spring Security con HtmlUnitDriver #50633
  • Los metadatos de propiedades de configuración incluyen referencias de clases incorrectas #50632
  • Docker La compatibilidad con Compose no restaura el indicador de interrupción de subproceso al detectar InterruptedException #50618
  • RabbitProperties habilita SSL incluso cuando spring.rabbitmq.ssl.bundle se reemplaza por una cadena vacía #50612
  • NullPointerException en reactor-netty SniProvider cuando el paquete SSL usa client-auth o el servidor truststore sin server-name-bundles #50610
  • SpringJtaPlatform debería haber quedado obsoleto desde 4.1.0-M3 #50592
  • La capa escrita fuera de la ubicación de salida de la excepción '//' se genera cuando se utilizan capas de extracción en el directorio raíz #50510
  • ConfigurationPropertiesReportEndpoint expone los componentes internos del proxy AOP #50417
  • Las instancias de StackTracePrinter creadas no tienen acceso al entorno #50414
  • MappingsEndpoint informa el ID propio del contexto como parentId cuando existe un padre #50412
  • El módulo Buildpack no valida conversiones de largo a int #50410
  • La compatibilidad con Gradle gRPC falla si se utiliza la dependencia de protobuf-java en lugar de protobuf-java-util #50405
  • La compatibilidad con GraphQL WebSocket no configura los orígenes permitidos #50394
  • El cargador Spring Boot no admite archivos firmados RSA y EC #50298
  • Los registros de medidores no se eliminan del registro global cuando se cierra el contexto #50287
  • DataSourceBuilder no puede derivar un origen de datos de un proxy de conexión diferida #50271
  • Las anotaciones que aceptan valores NULL de AbstractErrorController.getErrorAttributes no están alineadas con la implementación #50266
  • Las definiciones de Bean se pueden agregar con un inicializador antes de llamar a setAllowBeanDefinitionOverriding #50264
  • El comparador de enlaces EndpointRequest coincide innecesariamente con métodos HTTP distintos de GET #50261
  • El punto final '/cloudfoundryapplication' del actuador no funciona si se proporciona una configuración CORS restrictiva mediante un bean llamado corsConfigurationSource #50258
  • ThreadPoolTaskScheduleBuilder pierde precisión innecesariamente al configurar el tiempo de finalización de espera #50234
  • NimbusJwtDecoder acepta silenciosamente valores desconocidos para spring.security.oauth2.resourceserver.jwt.jws-algorithms #50228
  • Falta la gestión de dependencias para spring-boot-web-server-test #50224
  • La compatibilidad con Spring Batch para módulos MongoDB no está incluida en la gestión de dependencias #50223
  • Aplicar HTML escaping al atributo de marca de tiempo en la página de error Whitelabel #50216
  • GrpcServerHealthScheduler no se inicia en entornos de servlet #50209
  • Configurar server.servlet.session.cookie.partitioned=true no tiene ningún efecto cuando se usa Tomcat #50204

:notebook_with_decorative_cover: Documentación

  • Recarga de documentos SSL con Let's Encrypt #50630
