  • Los registros micrométricos fijan el contexto de la aplicación #51136
  • El archivo temporal no se elimina cuando falla la construcción de ExportedImageTar #51133
  • spring.grpc.server.health.include-overall-health no se tiene en cuenta #51106
  • El procesador de anotaciones de metadatos ignora el nivel de captador @NestedConfigurationProperty para los registros #51099
  • spring-boot-h2-console extrae el servlet-api como dependencia transitiva #51096
  • PropertiesLauncher no registra rutas de archivos anidados #51090
  • Los métodos que devuelven el resultado de Map#remove no se declaran con un tipo de retorno @Nullable #51088
  • NativeImageResourceProvider aplana las rutas de migración de Flyway en subdirectorios #50965
  • Se corrigió el orden de Kotlinx Serialization CodecCustomizer #50962
  • JarFile no se cierra al encontrar la clase principal del archivo #50960

  • Eliminar referencia a la configuración automática de InfluxDB eliminada #51177
