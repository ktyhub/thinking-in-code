:lady_beetle: Corrección de errores

  • spring.http.clients.cookie-handling no tiene ningún efecto cuando se utiliza un client reactivo respaldado por un conector HttpComponents #51767
  • Se puede generar NullPointerException cuando se usan uber jars debido a una condición de carrera en NestedJarFileResources #51746
  • La conexión falla cuando el servicio de redacción Rabbitmq Docker está configurado para usar SSL #51668
  • Faltan atributos de manifiesto relacionados con SBOM en las guerras empaquetadas con Maven #51652
  • Cuando server.reactive.session.cookie.same-site no está configurado, las cookies de sesión no tienen el atributo SameSite #51640
  • El servidor de recursos OAuth2 ignora el delimitador de reclamos de autoridades cuando se configura por sí solo #51631
  • Las configuraciones developmentOnly y testAndDevelopmentOnly no especifican ningún atributo que cause posibles problemas de resolución #51624
  • En una aplicación web reactiva, la integración de seguridad de Cloud Foundry devuelve un 500 en lugar de un 503 cuando la URL del controlador de la nube no está disponible #51615
  • ReactiveOAuth2ResourceServerWebSecurityAutoConfiguration anotado con una condición incorrecta #51588
  • WritableJson.toByteArray() puede dañar caracteres suplementarios #51586
  • El archivo temporal de capa no se elimina cuando falla la creación de la capa #51582
  • Docker La integración de Compose para RabbitMQ omite las reservas de credenciales cuando una variable de entorno no tiene valor #51579
  • Algunos mensajes de aserción nombran el parámetro incorrecto #51575
  • OAuth2ResourceServerProperties.Jwt tiene un definidor que no coincide con su captador #51566
  • Los comandos de las herramientas jarmode imprimen el seguimiento de pila en lugar de un mensaje de error #51548
  • Docker Compose ProcessRunner puede bloquear o dejar procesos huérfanos #51539
  • NestedByteChannel.read(ByteBuffer) devuelve incorrectamente 0 cuando no se pudo llenar el búfer #51521
  • Las comprobaciones nulas del personalizador en los constructores HTTP client afirman el atributo incorrecto #51514
  • Las personalizaciones de la configuración del host SSL pueden perderse durante la inicialización de Tomcat #51512
  • La integración de SQL Server Docker Compose puede duplicar el parámetro de cifrado de la URL de JDBC #51482
  • Las personalizaciones de la configuración del host SSL se pierden al recargar paquetes SSL #51458
  • OAuth2ClientProperties no están disponibles cuando se proporciona un bean ClientRegistrationRepository definido por el usuario #51451
  • LdapHealthIndicator informa DESCONOCIDO en lugar de ARRIBA cuando el servidor LDAP no expone una versión del protocolo #51442
  • JmsHealthIndicator pierde subprocesos de vigilancia si el inicio falla inmediatamente #51434
  • Respetar el desenvolvimiento de un contenedor al resolver la fuente de datos raíz #51420
  • La fuente no se cierra consistentemente por todos los evaluadores de mariscal JSON #51419
  • El identificador de archivo en SpringBootJoranConfigurator debe estar cerrado #51416
  • La validación del obsoleto io.buildpacks.stack.id es demasiado agresiva #51401
