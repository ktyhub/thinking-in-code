  • Faltan atributos de manifiesto relacionados con SBOM en las guerras empaquetadas con Maven #51651

  • El servidor de recursos OAuth2 ignora el delimitador de reclamos de autoridades cuando se configura por sí solo #51630

  • El archivo temporal de la capa no se elimina cuando falla la creación de la capa #51581

  • Las personalizaciones de la configuración del host SSL pueden perderse durante la inicialización de Tomcat #51511
  • La integración de SQL Server Docker Compose puede duplicar el parámetro de cifrado de la URL de JDBC #51481
  • WritableJson.toByteArray() puede dañar caracteres suplementarios #51464
  • Las personalizaciones de la configuración del host SSL se pierden al recargar paquetes SSL #51457
  • OAuth2ClientProperties no están disponibles cuando se proporciona un bean ClientRegistrationRepository definido por el usuario #51450
  • LdapHealthIndicator informa DESCONOCIDO en lugar de ARRIBA cuando el servidor LDAP no expone una versión del protocolo #51441
  • JmsHealthIndicator pierde subprocesos de vigilancia si el inicio falla inmediatamente #51433
  • La fuente no se cierra consistentemente por todos los evaluadores de mariscal JSON #51418
  • El identificador de archivo en SpringBootJoranConfigurator debe estar cerrado #51415
  • Respetar el desenvolvimiento de un contenedor al resolver la fuente de datos raíz #51410
  • La validación del obsoleto io.buildpacks.stack.id es demasiado agresiva #51400
  • ReactiveOAuth2ResourceServerWebSecurityAutoConfiguration anotado con una condición incorrecta #50778
