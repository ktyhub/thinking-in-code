spring-boot v4.1.1

Esta página está traducida automáticamente. El texto original en inglés es la referencia.

bota de resorte v4.1.1

:advertencia: Se requiere atención

  • El complemento Gradle de Spring Boot ya no configura automáticamente gRPC cuando se aplica el complemento Protobuf. Este comportamiento causó problemas a quienes usaban Protobuf sin gRPC. Para optar por la configuración de gRPC, configure la extensión protobuf con el complemento grpc usando un bloque vacío. El complemento Spring Boot Gradle configurará automáticamente el uso de protoc-gen-grpc-java como antes. #50822

  • Los registros micrométricos fijan el contexto de la aplicación #51135

  • Alto número de conexiones debido al indicador de estado de Mongo #50852
  • Manejo inconsistente de valores de cadenas vacías de spring.security.oauth2.resourceserver.jwt issueser-uri y jwk-set-uri #50849
  • La capacidad de nulidad del tipo de retorno de los métodos getBean de ApplicationContextAssert no indica que el bean pueda ser nulo #50845

  • JpaBaseConfiguration#entityManagerConfiguration puede provocar un bucle de dependencia en los beans que declaran AsyncTaskExecutor #50801

  • La versión administrada de Prometheus Client no está alineada con el registro de micrómetros-prometheus de Micrometer #50780
  • Las propiedades del mapa enlazadas desde cadenas vacías fallan con ConverterNotFoundException #50773
  • Protobuf Common Protos no debería ser una dependencia administrada #50772
