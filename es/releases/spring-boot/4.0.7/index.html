bota de resorte v4.0.7

:lady_beetle: Corrección de errores

  • La configuración automática de MailSender no permite la verificación del nombre de host #50746
  • La configuración automática de Artemis utiliza una ubicación predeterminada predecible para los datos del broker integrado #50744
  • NullPointerException en reactor-netty SniProvider y paquete SSL no asignado con RSocket #50640
  • SSL no debe habilitarse cuando un paquete SSL se reemplaza por una cadena vacía #50634
  • Docker La compatibilidad con Compose no restaura el indicador de interrupción de subproceso al detectar InterruptedException #50617
  • RabbitProperties habilita SSL incluso cuando spring.rabbitmq.ssl.bundle se reemplaza por una cadena vacía #50611
  • NullPointerException en reactor-netty SniProvider cuando el paquete SSL usa client-auth o el servidor truststore sin server-name-bundles #50609
  • La configuración automática de prueba ya no integra Spring Security con HtmlUnitDriver #50602
  • La capa escrita fuera de la ubicación de salida de la excepción '//' se genera cuando se utilizan capas de extracción en el directorio raíz #50509
  • ConfigurationPropertiesReportEndpoint expone los componentes internos del proxy AOP #50416
  • Las instancias de StackTracePrinter creadas no tienen acceso al entorno #50413
  • MappingsEndpoint informa el ID propio del contexto como parentId cuando existe un padre #50411
  • El módulo Buildpack no valida conversiones de largo a int #50409
  • La compatibilidad con GraphQL WebSocket no configura los orígenes permitidos #50393
  • Los metadatos de propiedades de configuración incluyen referencias de clases incorrectas #50375
  • El cargador Spring Boot no admite archivos firmados RSA y EC #50297
  • Los registros de medidores no se eliminan del registro global cuando se cierra el contexto #50286
  • Las anotaciones que aceptan valores NULL de AbstractErrorController.getErrorAttributes no están alineadas con la implementación #50265
  • El comparador de enlaces EndpointRequest coincide innecesariamente con métodos HTTP distintos de GET #50260
  • El punto final '/cloudfoundryapplication' del actuador no funciona si se proporciona una configuración CORS restrictiva mediante un bean llamado corsConfigurationSource #50257
  • ThreadPoolTaskScheduleBuilder pierde precisión innecesariamente al configurar el tiempo de finalización de espera #50233
  • NimbusJwtDecoder acepta silenciosamente valores desconocidos para spring.security.oauth2.resourceserver.jwt.jws-algorithms #50227
  • Aplicar HTML escaping al atributo de marca de tiempo en la página de error Whitelabel #50215
  • Configurar server.servlet.session.cookie.partitioned=true no tiene ningún efecto cuando se usa Tomcat #50201
