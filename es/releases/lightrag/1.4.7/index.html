LightRAG v1.4.7

Notas importantes

  • La función de filtrado de fragmentos basada en ID de documento se elimina del almacenamiento vectorial PostgreSQL.
  • Se actualizó la plantilla de aviso, lo que invalida todos los cachés de LLM
  • El valor predeterminado de la variable de entorno FORCE_LLM_SUMMARY_ON_MERGE se ha cambiado de 4 a 8. Este ajuste reduce significativamente la cantidad de llamadas de LLM durante la fase de indexación de documentación, acortando así el tiempo total de procesamiento de documentos.
  • Se agregó soporte para múltiples proveedores de reclasificación (Cohere AI, Jina AI, Aliyun Dashscope). Si la reclasificación se habilitó previamente y se debe configurar una nueva var de entorno para habilitar la reclasificación nuevamente:
RERANK_BINDING=cohere
  • Se introdujo una nueva variable de entorno, LLM_TIMEOUT, para controlar específicamente el tiempo de espera del modelo de lenguaje grande (LLM). La variable TIMEOUT existente ahora gestiona exclusivamente el tiempo de espera del trabajador Gunicorn. El tiempo de espera predeterminado de LLM está establecido en 180 segundos. Si anteriormente confiaba en la variable TIMEOUT para la configuración del tiempo de espera de LLM, actualice su configuración para usar LLM_TIMEOUT en su lugar:
LLM_TIMEOUT=180
  • Agregue configuraciones integrales de variables de entorno para enlaces OpenAI y Ollama Large Language Model (LLM). La variable de entorno genérica TEMPERATURA para el control de temperatura LLM ha quedado obsoleta. En cambio, la temperatura LLM ahora se configura mediante variables de entorno específicas del enlace:
# Temperature setting for OpenAI binding
OPENAI_LLM_TEMPERATURE=0.8

# Temperature setting for Ollama binding
OLLAMA_LLM_TEMPERATURE=1.0

Para mitigar los bucles de salida interminables y evitar la decodificación codiciosa de Qwen3, establezca el parámetro de temperatura en un valor entre 0.8 y 1.0. Para desactivar el modo "Pensamiento" del modelo, consulte la siguiente configuración:

### Qwen3 Specific Parameters depoly by vLLM
# OPENAI_LLM_EXTRA_BODY='{"chat_template_kwargs": {"enable_thinking": false}}'

### OpenRouter Specific Parameters
# OPENAI_LLM_EXTRA_BODY='{"reasoning": {"enabled": false}}'

Para obtener una lista completa de opciones de soporte, use el siguiente comando:

lightrag-server --llm-binding openai --help
lightrag-server --llm-binding ollama --help
lightrag-server --embedding-binding ollama --help
  • Una lista completa de nuevas variables de entorno agregadas o nuevos valores predeterminados:
# Timeout for LLM requests (seconds)
LLM_TIMEOUT=180

# Timeout for embedding requests (seconds)
EMBEDDING_TIMEOUT=30

### Number of summary segments or tokens to trigger LLM summary on entity/relation merge (at least 3 is recommended)
FORCE_LLM_SUMMARY_ON_MERGE=8

### Max description token size to trigger LLM summary
SUMMARY_MAX_TOKENS = 1200

### Recommended LLM summary output length in tokens
SUMMARY_LENGTH_RECOMMENDED=600

### Maximum context size sent to LLM for description summary
SUMMARY_CONTEXT_SIZE=12000

### RERANK_BINDING type:  null, cohere, jina, aliyun
RERANK_BINDING=null

### Enable rerank by default in query params when RERANK_BINDING is not null
# RERANK_BY_DEFAULT=True

### chunk selection strategies
###     VECTOR: Pick KG chunks by vector similarity, delivered chunks to the LLM aligning more closely with naive retrieval
###     WEIGHT: Pick KG chunks by entity and chunk weight, delivered more solely KG related chunks to the LLM
###     If reranking is enabled, the impact of chunk selection strategies will be diminished.
KG_CHUNK_PICK_METHOD=VECTOR

### Entity types that the LLM will attempt to recognize
ENTITY_TYPES=["person", "organization", "location", "event", "concept"]
