incubadora-seata v1.6.0

Lanzamiento del Seata 1.6.0.

Seata es una solución de transacciones distribuidas de código abierto, fácil de usar y de alto rendimiento.

La versión se actualiza de la siguiente manera:

característica:

  • [#4863] admite Oracle y clave principal múltiple postgresql
  • [#4649] el servidor seata admite registros múltiples
  • [#4779] soporte Apache Dubbo3
  • [#4479] El modo TCC admite la anotación tcc marcada tanto en la interfaz como en la clase de implementación
  • [#4877] seata client soporte jdk17
  • [#4914] admite la actualización mysql y se une a sql
  • [#4542] admite tipos de marcas de tiempo de Oracle
  • [#5111] admite la ruta contextual de Nacos
  • [#4802] dockerbrazo soporte archivos64

corrección de errores:

  • La solución [#4780] no puede publicar el evento TimeoutRollbacked después de una reversión exitosa del tiempo de espera.
  • [#4954] corrige la expresión de salida que arroja incorrectamente npe
  • [#4817] corrección en la propiedad springboot de versión alta no estándar
  • [#4838] solución cuando el uso Statement.executeBatch() no puede generar el registro de deshacer
  • [#4533] corrige el evento de reversión repetido y el estado de algunos eventos no es correcto
  • [#4912] corrige que el caso de la columna InsertOnDuplicateUpdate de mysql es diferente y no puede coincidir
  • [#4543] corrección de compatibilidad con tipos de ncob de Oracle
  • La solución [#4915] no pudo obtener las propiedades de recuperación del servidor
