incubadora-seata v1.7.0

Lanzamiento del Seata 1.7.0.

Seata es una solución de transacciones distribuidas de código abierto, fácil de usar y de alto rendimiento.

La versión se actualiza de la siguiente manera:

característica:

  • [#5476] primer soporte native-image para seata-client
  • [#5495] integración de consola saga-statemachine-designer
  • [#5668] compatible con las configuraciones file.conf y registro.conf en la versión 1.4.2 y anteriores

corrección de errores:

  • [#5682] arregla la pérdida del contexto de repetición del modo saga startParams
  • [#5671] corrige la excepción de conversión de tipo automático de entrada de tarea de servicio en modo saga Params json
  • [#5194] corrige el orden incorrecto de las palabras clave para Oracle al crear una tabla
  • [#5021] corrige el error de JDK Reflection para el proxy de origen Spring en JDK17
  • [#5023] soluciona el conflicto transitivo de dependencia de seata-core en seata-dubbo
  • [#5224] corrige el script de inicialización de Oracle index_name está duplicado
  • [#5233] corrige los nombres de elementos de configuración inconsistentes relacionados con LoadBalance
  • [#5266] arregla que la consola del servidor haya consultado el bloqueo liberado
  • [#5245] corrige la dependencia incompleta del módulo de distribución
  • [#5239] corrige getConfig y lanza ClassCastException cuando se usa el proxy JDK
  • [#5281] lanzamiento de identificador de solicitud paralelo IndexOutOfBoundsException
  • [#5288] corrige el incremento automático de columnas pk en Oracle en modo AT
  • [#5287] corrige el incremento automático de columnas pk en PostgreSQL en modo AT
  • [#5299] corrige la eliminación de GlobalSession al reintentar la reversión o reintentar el tiempo de espera de confirmación
  • [#5307] corrige que las palabras clave no agregan caracteres de escape
  • [#5311] elimina las sesiones RollbackRetryTimeout durante la recuperación del almacenamiento de archivos
  • [#4734] comprueba si la metacaché de la tabla debe actualizarse en modo AT
  • [#5316] corrige el parámetro G1 jvm en jdk8
  • [#5321] corrección Cuando la lógica de reversión en el lado TC devuelve RollbackFailed, el FailureHandler personalizado no se ejecuta
  • [#5332] corrige errores encontrados en las pruebas unitarias
  • [#5145] corrige que la sesión global siempre comienza en modo saga
  • [#5413] repara el archivo de configuración del servicio incorrecto y el error de compilación
  • [#5415] corrige el tiempo de espera de la transacción en el lado client, no se ejecuta el gancho y el errorHandler
  • [#5447] corrige que el modo Oracle xa no se puede utilizar en la misma base de datos
  • [#5472] solución si se usa @GlobalTransactional en RM, se lanzará ShouldNeverHappenException
  • [#5535] corrige que la ruta del archivo de registro se cargó incorrectamente
  • [#5538] corrige la excepción de trago de transacción finalizada al confirmar
  • [#5539] soluciona el problema del escaneo completo de la tabla con la condición 'setDate' en Oracle 10g
  • [#5540] solución GlobalStatus=9 no se puede borrar en el modo de almacenamiento de base de datos
  • [#5552] se corrigió el error de reversión de mariadb
  • [#5583] soluciona el problema de desvinculación del interceptor xid grpc
  • [#5602] corrige el registro en el rol de transacción del participante
  • [#5645] corrigió el error de deshacer la inserción de Oracle
  • [#5659] soluciona el problema de la aplicación de distinción entre mayúsculas y minúsculas en la base de datos después de agregar caracteres de escape a las palabras clave
  • [#5663] corrige que el tiempo de espera es nulo cuando se reutiliza la conexión ConnectionProxyXA
  • [#5675] corrige la compatibilidad entre los elementos de configuración xxx.grouplist y grouplist.xxx
  • [#5690] arregla la impresión de la consola unauthorized error
  • [#5711] corrige que el elemento de configuración de obtención contenga un error subrayado

optimizar:

  • [#5208] optimiza getCause arrojable una vez más
  • [#5212] optimizar el nivel de mensajes de registro
  • [#5237] optimizar la impresión de mensajes de registro de excepciones (EnhancedServiceLoader.loadFile#cahtch)
  • [#5089] optimizar la verificación del valor de retraso de la tarea de limpieza del registro de cerca del TCC
  • [#5243] optimizar kryo 5.4.0 optimizar la compatibilidad con jdk17
  • [#5153] Solo el modo AT intenta obtener el canal con otra aplicación
  • [#5177] Si server.session.enable-branch-async-remove es verdadero, elimine la rama de forma asincrónica y desbloquéela de forma sincrónica.
  • [#5273] optimiza la configuración de compilación del complemento protobuf-maven-plugin para resolver el problema de las líneas de comando demasiado largas en versiones superiores.
  • [#5303] elimina el script de inicio y la configuración -Xmn
  • [#5325] agregar modo de tienda, tipo de configuración e información de registro de tipo de registro
  • [#5315] optimizar el registro de SPI
  • [#5323] agrega información de tiempo para el registro de tiempo de espera de transacciones globales
  • [#5414] optimizar el controlador de errores de transacciones
  • [#5537] optimizar el registro de transacciones en el lado client
  • [#5541] optimizar la salida del registro del servidor
  • [#5548] actualiza la clave gpg de caducidad y publica el flujo de trabajo
  • [#5638] optimización: establezca el nivel de transacción del servidor en READ_COMMITTED
  • [#5646] refactoriza ColumnUtils y EscapeHandler
  • [#5648] optimizar la impresión de registros del servidor
  • [#5647] admite atributos que distinguen entre mayúsculas y minúsculas para metadatos de tablas y columnas
  • [#5678] optimiza el carácter de escape para el caso de nombres de columna
  • [#5684] optimiza las acciones de github para CodeQL, skywalking-eyes y checkout
  • [#5700] optimizar el registro de bloqueo distribuido

seguridad:

  • [#5172] soluciona algunas vulnerabilidades de seguridad
  • [#5683] agregar WhiteDenyList del serializador de Hesse
  • [#5696] soluciona varias vulnerabilidades de seguridad de node.js

prueba:

  • [#5380] corrige el error UpdateExecutorTest
  • [#5382] corrigió el error en la prueba de versión de múltiples resortes
