incubadora-seata v1.4.0

Lanzamiento del Seata 1.4.0.

Seata es una solución de transacciones distribuidas de código abierto, fácil de usar y de alto rendimiento.

La versión se actualiza de la siguiente manera:

característica:

  • [#2380] admite configuración yml
  • [#3191] admite jdbc tipo nclob
  • [#2676] admite el equilibrio de carga menos activo
  • [#3198] Soporte spring boot para configuración personalizada y tipo de registro
  • [#2806] admite la configuración del tiempo de espera de transacción global predeterminadoMillis
  • [#2941] agregar configuración de clave secreta de Apollo
  • [#2080] admite ConsistentHashLoadBalance
  • [#2950] admite el bloqueo reentrante en el módulo redis
  • [#2913] El modo proxy de fuente de datos se puede seleccionar como AT o XA
  • [#2856] soporte para deshacerLog usando la serialización Fst
  • [#3076] verifica el bloqueo en TC cuando se usa @GlobalLock
  • [#2825] admite enviar mensaje de autenticación
  • [#2962] @GlobalTransactional y @GlobalLock pueden admitir la configuración personalizada de reintento de bloqueo

corrección de errores:

  • [#3214] corrige que 'RootContext.DEFAULT_BRANCH_TYPE' es incorrecto en algunos casos

  • [#3129] prohíbe ejecutar SQL que actualice el valor pk
