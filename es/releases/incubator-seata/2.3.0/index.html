incubadora-seata v2.3.0

Apache Seata (incubando) 2.3.0 Lanzado.

Apache Seata (en incubación) es una solución de transacciones distribuidas de código abierto, de alto rendimiento y fácil de usar.

La versión se actualiza de la siguiente manera:

característica:

  • [#6904] agrega compatibilidad con el serializador fastjson2
  • [#6876] admite kingbase
  • [#6881] admite grpc
  • [#6864] admite la base de datos shentong
  • [#6974] admite el analizador de deshacer registros fastjson2
  • [#6992] admite serializador grpc
  • [#6973] admite anotaciones de saga
  • [#6926] admite comunicación SSL para nodos de balsa

corrección de errores:

  • [#6899] corrige el error de lectura de file.conf después del paquete
  • [#6890] corrige el diseñadorJson al estándarJson: subStateMachine compensarEl estado no puede ser reconocido
  • [#6907] soluciona el problema por el cual Codecov no genera informes
  • [#6923] Mejorar el manejo de errores 401 actualizando el token
  • [#6925] soluciona el problema en el modelo Raft que la caída de un seguidor puede provocar al uso continuo de tokens caducados
  • [#6932] al habilitar transacciones locales, la contención de bloqueo la falla en el modo de archivo y balsa no sale, lo que genera un bloqueo persistente
  • [#6940] Arreglar el comportamiento de búsqueda de NacosRegistry transactionServiceGroup está vacío provocando un error de NPE
  • [#6943] corrige el error de conversión de convertBranchSession en entorno concurrente.
  • [#6948] Solucionar el problema de compilación de CI en la plataforma ARM64
  • [#6947] corrige npe para el registro de nacos al buscar la dirección
  • [#6984] admite la creación de la imagen docker en openjdk23
  • [#6994] soluciona el problema de generar la excepción deshacerLog cuando actualizar unirse no actualiza los datos
  • [#7005] soluciona el problema de Raft NPE causado por la simultaneidad de dos fases
  • [#7010] corrige el error mientras el "contexto" es la palabra clave en DM8 cuando eliminar deshacer registro
  • [#7022] corrige la propiedad store.mode en application.raft.example.yml
  • [#7025] corrige que vGroupMappingManager NO está iniciado
  • [#7044] corrige la actualización de meta de la tabla después del cierre
  • [#7117] prefijo de corrección: seata.server.raft.ssl no debe ser nulo
  • [#7127] soluciona el error de decodificación del servidor BranchType

optimizar:

  • [#6826] eliminar la operación de registro de sucursal de la XA transacción de solo lectura
  • [#6874] modifica la versión a 2.3.0-SNAPSHOT
  • [#6892] actualiza la versión de npmjs en el módulo de consola
  • [#6883] eliminar objeto de solo escritura
  • [#6892] actualización de la versión npmjs
  • [#6889] Corregir errores ortográficos de palabras
  • [#6898] actualiza la versión de npmjs en el módulo saga
  • [#6879] soluciona el problema de discrepancia en los argumentos del registro
  • [#6902] optimizar los documentos Léame
  • [#6807] dividir MergedWarpMessage mejora el servidor capacidad de procesamiento paralelo
  • [#6905] elimina licencias incompatibles en el momento de la compilación
  • [#6906] La dependencia h2 agrega alcance de prueba
  • [#6911] corrige algunos errores tipográficos en el proyecto
  • [#6918] Utilice la imagen openjdk de eclipse-temurin como base imagen
  • [#6938] Actualizar la información del chat en línea en README.md
  • [#6950] Eliminar el parámetro app.id de JVM
  • [#6959] actualiza el nombre y la descripción de el módulo seata-http-jakarta
  • [#6991] gRPC serialización predeterminada en Protobuf
