incubadora-seata v2.0.0

Lanzamiento del Seata 2.0.0

Seata es una solución de transacciones distribuidas de código abierto, fácil de usar y de alto rendimiento.

La versión se actualiza de la siguiente manera:

característica:

  • [#5165] optimiza la estructura TCC, admitiendo el acceso API. agregue el módulo de capa de integración (seata-integration-tx-api) para la definición del proceso de transacciones y la mejora del proxy.
  • [#5352] agregue el analizador jackson json y el analizador gson json para el contexto de acción empresarial de tcc
  • [#5377] hace que AbstractHttpExecutor.class admita http put
  • [#5396] Métrica del agregador de registro de TC
  • [#5118] admite la ejecución de notificaciones simultáneas en dos etapas
  • [#5529] La imagen docker admite la inyección de parámetros JVM
  • [#3887] agregar soporte de base de datos SQL Server en modo AT
  • [#4033] agrega compatibilidad con SQLServer para el modo de almacenamiento de base de datos del servidor
  • Característica [#5600]: admite rastrear el enlace de la transacción según el XID
  • Característica [#5357]: integración de consola saga-statemachine-designer
  • [#5717] compatible con las configuraciones file.conf y registro.conf en la versión 1.4.2 y anteriores
  • [#5842] agregando metainformación a la imagen docker
  • [#5902] admite IPv6
  • [#5907] admite polardb-x 2.0 en modo AT
  • [#5932] admite la base de datos Dameng
  • [#5946] agrega la adaptación de sqlserver a la interfaz de paginación de la consola
  • [#5226] admite grupo de balsas y modo tienda
