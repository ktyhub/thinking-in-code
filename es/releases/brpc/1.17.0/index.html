#brpc1.17.0

Apache bRPC 1.17.0 es una versión de funciones centrada en la optimización del rendimiento, destacada por la introducción de SingleIOBuf para una serialización/deserialización eficiente de FlatBuffers. Esta versión también amplía las capacidades de protocolo y transporte con compatibilidad nativa con el canal Redis Cluster, una nueva capa de transporte para extensiones de protocolo de comunicación y compatibilidad con RDMA ECE. Las mejoras adicionales incluyen políticas de solicitud de respaldo con velocidad limitada, umbral de tasa de error para atenuación de castigo y soporte de cola de prioridad bthread. La versión ofrece además correcciones de errores críticos para problemas de uso después de la liberación, visibilidad de la memoria ARM y compatibilidad con Protobuf, junto con múltiples mejoras de estabilidad y pruebas de fuzz.
