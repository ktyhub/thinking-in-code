#jadxv1.5.2

Características principales

Núcleo:

  • Implementación de lector zip personalizado para combatir la manipulación
  • Agregue plantillas de exportación de Gradle, admita aplicaciones/lib de Android y Java simple
  • Soporte inicial para DEX v41 (#2128)

GUI:

  • Agregar cuadro de diálogo de exportación con opciones (PR #2378)
  • Una búsqueda de uso de estructura de árbol (PR #2498)
  • Agregar tema de editor de código dinámico desde el tema de la interfaz de usuario (PR #2471)
  • Agregar función de pestaña Vista previa (PR #2474)
  • Nuevo HexViewer (PR #2469)

Complementos:

  • Agregar compatibilidad con APKM (PR #2379)
  • Analizar y usar Kotlin SourceDebugExtension con SMAP para cambiar el nombre de clases y paquetes (PR #2389)

API:

  • Agregar método de 'descarga' a JadxPlugin (#2463)
  • Método para agregar una entrada al menú emergente para los nodos del árbol (#2412)
  • Agregar método para obtener íconos jadx-gui por nombre
  • Agregar método para abrir el diálogo de uso
