nacos 3.0.3

#nacos 3.0.3 Esta versión se centra principalmente en la expansión del ecosistema MCP y la optimización del rendimiento, al mismo tiempo que equilibra la experiencia del desarrollador y la solidez del sistema. Y solucione muchos errores de la versión anterior. En cuanto a las nuevas funciones de registro de MCP, Nacos agregó administración dinámica de herramientas de MCP (búsqueda automática durante la creación/actualización), admitió la importación de herramientas de transferencia HTTP a través de archivos Swagger API y definiciones de esquema de seguridad mejoradas y cli de interacción de IA del lado occidental API. Y se introdujo el índice de memoria para optimizar el rendimiento de la consulta de ID/nombre de MCP, admite la configuración de IP de escucha personalizada de gRPC y se agregó frontEndpointConfig para una integración frontend optimizada. Para las mejoras del sistema y la experiencia, Nacos refactorizó la interfaz de usuario de administración de MCP, optimizó las sugerencias de configuración del puerto Docker, mejoró los flujos de trabajo de creación de servicios y fortaleció las validaciones (por ejemplo, verificaciones de nombre de usuario/contraseña, verificación de existencia de tablas previas a la eliminación). Y también se mejoraron la lógica de consulta del servidor MCP y los registros de errores, las respuestas API de preparación estandarizadas y se garantizó la coherencia de SDK en la devolución de ID de MCP.
