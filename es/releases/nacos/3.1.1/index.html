nacos 3.1.1

Parche Publicado26 nov 2025 Fuentealibaba/nacos original en inglés

Esta página está traducida automáticamente. El texto original en inglés es la referencia.

#nacos 3.1.1 Esta versión se centra en mejorar las capacidades MCP y A2A (Agente a Agente) de Nacos, mejorar la estabilidad del sistema y perfeccionar la gestión de la seguridad y la configuración. Las adiciones clave incluyen soporte para el registro por lotes de puntos finales de agentes, fusión de versiones durante la importación del servidor MCP y flexibilidad mejorada en la actualización de servidores MCP con una opción overrideExisting. El lanzamiento también presenta compatibilidad con la configuración de seguridad predeterminada para las comunicaciones entrantes y salientes, sentando las bases para interacciones seguras con los agentes de IA. Los cambios detallados en esta versión se enumeran a continuación:

Característica

[#13867] Admite anular la configuración existente al actualizar el servidor MCP. [#13922] Agregar configuración del grupo de subprocesos para permitir el tiempo de espera de los subprocesos principales. [#13946] Refactorice el modelo AgentEndpoint y agregue nuevos campos para admitir consultas y protocolos avanzados. [#13953] Agregue soporte para configuraciones de seguridad predeterminadas, incluida la selección y configuración de esquemas de seguridad entrantes y salientes. [#13957] Admite el registro por lotes de puntos finales de agentes. [#13951] Agregar filtro CORS configurable para el módulo de consola.

Mejora/Refactorización

[#13822] Separe las responsabilidades entre el ejecutor de client y el ejecutor programado de inicio de sesión para evitar el agotamiento del grupo de subprocesos. [#13863] Optimice el script Shutdown.sh para combinar múltiples PID en una sola línea para una terminación más limpia del proceso. [#13911] Mejore importToolsFromMcp API para admitir servidores de protocolo de transmisión. [#13914] Actualice la versión del complemento checkStyle para mejorar el código y la facilidad de mantenimiento. [#13945] Admite la combinación de versiones al importar especificaciones del servidor MCP. [#13963] Refactorización de la lista de configuración api para admitir etiquetas de configuración de retorno y desc.

Corrección de errores

[#13140] Se corrigió el manejo consistente del espacio de nombres para ConfigChangeNotifyRequest cuando el espacio de nombres client está vacío. [#13860] Se corrigió el posible riesgo de excepción de puntero nulo en ConfigMigrateService. [#13866] Se corrigió la imposibilidad de editar servidores MCP importados en la consola. [#13869] Se corrigió el error al crear el bean 'consoleHealthController' debido a que faltaba una inyección de dependencia. [#13877] Se solucionó el problema de namespaceId en McpRemoteHandler que causaba una propagación de contexto incorrecta. [#13882] Se corrigió el bloqueo de sincronización y se agregó una palabra clave volátil para TpsControlManager para garantizar la seguridad de los subprocesos. [#13884] Se corrigió el error de análisis JSON en la validación del servidor MCP API durante la importación. [#13902] Se corrigen las advertencias de escaneo de paquetes Log4j2 en desuso actualizando la lógica de inicialización del registrador. [#13948] Se solucionó el error al actualizar la tarjeta del agente a través de la interfaz de la consola. [#13959] Corrección La actualización de contraseña falla cuando se implementa con una consola/servidor independiente. [#13964] Se soluciona cuando nacos.extension.ai.enabled es falso y falla el inicio de nacos.

Dependencias

[#13879] Agregar pruebas unitarias para componentes relacionados con la IA. [#13881] Agregar la utilidad APIs para fines de desarrollo y prueba.
