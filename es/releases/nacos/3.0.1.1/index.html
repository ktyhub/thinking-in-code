nacos 3.0.1.1

#nacos 3.0.1.1 Esta versión solucionó el problema de bloqueo n.° 13430. Otros cambios de versión, consulte 3.0.1 Los siguientes registros de cambios provienen de 3.0.1: Esta versión se basa en la versión 3.0.0 e introduce soporte para las capacidades de administración de múltiples espacios de nombres y de múltiples versiones de MCP. La comunidad de Nacos ha contribuido al estándar MCP Registry API y es la primera en implementar el estándar MCP Registry API. Al implementar Nacos 3.0.1, el Registro MCP estándar API se puede habilitar configurando el parámetro nacos.ai.mcp.registry.enabled=true, y el parámetro nacos.ai.mcp.registry.port (9080 predeterminado) especifica el puerto para el Registro MCP API. Dado que el Registro MCP API requiere puertos y recursos adicionales, permanece deshabilitado de forma predeterminada en las configuraciones estándar.

Debido a cambios en el estándar oficial del Registro MCP API, se actualizaron las definiciones de metadatos para el servidor MCP, lo que genera posibles cambios en la estructura de datos incompatibles. La actualización de la versión 3.0.0 a 3.0.1 puede provocar que la consola no pueda leer datos de servidores MCP anteriores. La comunidad de Nacos ha proporcionado una herramienta de migración que reubica los servidores MCP existentes en el espacio de nombres público predeterminado después de la ejecución. Las instrucciones detalladas para usar la herramienta de migración mcp-migration-tool.jar están disponibles en documentación. Con el Registro MCP API ahora finalizado, la estructura de datos del Servidor MCP se ha estabilizado, lo que garantiza la compatibilidad con versiones anteriores en futuras versiones. Además de las nuevas funciones, esta versión optimiza las solicitudes de contraseña iniciales y los scripts de inicio para sistemas Windows, al mismo tiempo que corrige varios errores presentes en la versión 3.0.0. [#13273] Se corrigió la creación de clúster client, ​​no se usa la configuración nacos.remote.client.grpc. [#13321] Reparar métricas de prometheus api no puede aceptar el problema. [#13345] Corrección apiClient readTimeout debe ser cero. [#13368] La solución no puede eliminar el espacio de nombres en el problema de la interfaz de usuario de la consola. [#13405] Se solucionó el problema de configuración de escucha con el espacio de nombres predeterminado. [#13413] Solucionar el problema de sugerencias para el servidor mcp stdio.
