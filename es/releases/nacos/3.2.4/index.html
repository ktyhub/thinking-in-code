#nacos 3.2.4

Nacos 3.2.4 es principalmente una versión de corrección de errores, refuerzo de seguridad y mejora de la experiencia para la serie 3.2.

Esta versión se centra en:

  • Fortalecimiento de JRaft, autorización HTTP/gRPC, base de datos integrada, inicio de sesión, verificación de estado activo y seguridad de importación de MCP.
  • Solucionar problemas de consola independiente, visibilidad de mensajes, historial de configuración, estado del oyente y autenticación de la herramienta MCP.
  • Mejora de la usabilidad de la página de historial, edición y detalles de configuración.

Para operadores de clúster y API, esta versión también:

  • Agrega autenticación de identidad del servidor al tráfico nativo de JRaft gRPC con aplicación de actualización continua.
  • Deshabilita de forma predeterminada los AI API v3 obsoletos seleccionados y proporciona un interruptor de compatibilidad temporal.
  • Agrega una política de lista permitida para importaciones de herramientas MCP desde objetivos privados o locales.

Cambios detallados en esta versión:

Característica

  • #15687 Agregue autenticación de identidad del servidor al tráfico nativo JRaft gRPC con aplicación de actualización continua.

Mejora/Refactorización

  • #14817 Agregue una puerta de compatibilidad compartida y deshabilitada de manera predeterminada para los API de importación de MCP y Pipeline obsoletos.
  • #15661 Refuerza la resolución de resultados de bases de datos integradas distribuidas para tipos escalares admitidos y asignadores de filas registrados.
  • #15688 Refactorización del análisis de URI de ruta de contexto del controlador para una coincidencia de ruta consistente.
  • #15695 Mejore los detalles de configuración, la edición y los diseños del historial con metadatos compactos y una vista de contenido en pantalla completa.
  • #15712 Fortalezca las comprobaciones de estado activas validando las direcciones de destino y deshabilitando las opciones inseguras de MySQL JDBC.
  • #15749 Agregue control de acceso saliente configurable para importaciones de herramientas MCP, permitiendo objetivos públicos y objetivos privados o locales incluidos en la lista de permitidos.

Corrección de errores

  • #15475 Se corrigió el reenvío de identidad de la persona que llama desde una consola independiente para que el servidor aplique RBAC específico de la persona que llama.
  • #15476 Se corrigió la aplicación de visibilidad rápida para listas, detalles, versiones, descargas y rutas de lectura de Client.
  • #15560 Se corrigió la pérdida de la autenticación de paso a través de la herramienta MCP después de publicar desde la consola.
  • #15634 #15563 Se corrigieron los metadatos de autorización y el análisis de recursos en Admin, HTTP/gRPC, Prometheus y AgentSpec API.
  • #15660 Se corrigió la falla de inicio de la consola independiente causada por la falta de un bean comprobador de permisos de clonación de configuración.
  • #15682 Evite la enumeración de nombres de usuario normalizando las respuestas de error de inicio de sesión.
  • #15701 Se corrigieron las consultas del siguiente registro del historial de configuración en Derby y se aplicó el filtrado de nombres grises correctamente.
  • #15724 Preservar el filtro de espacio de nombres al agregar el estado de escucha por IP entre los miembros del clúster.

Aviso de cambio importante

Nacos 3.2.4 cambia el comportamiento predeterminado de los AI API obsoletos y las importaciones de herramientas MCP privadas, e introduce una transición irreversible de aplicación de la autenticación JRaft.

Usuarios afectados:

  • Los usuarios que llaman a la lista/detalle de canalización en desuso o al MCP heredado importan API. Estos API ahora devuelven HTTP 410 Gone de forma predeterminada.
  • Operadores de consola que importan herramientas MCP desde direcciones privadas o locales. Estos objetivos ahora requieren una lista de permitidos administrada por el administrador.
  • Clústeres que intentan una degradación progresiva de versiones mixtas después de que todos los miembros hayan habilitado la aplicación de autenticación JRaft.

Ruta de actualización recomendada:

  • Migrar al Pipeline canónico y /v3/console/ai/import/* API. Si se requiere tiempo de migración adicional, configure temporalmente nacos.core.api.compatibility.enabled=true.
  • Configure nacos.console.ai.mcp.import.allowed-private-addresses en cada instancia de la consola y reinicie la consola cuando se requieran objetivos privados.
  • Antes de actualizar, verifique que nacos.core.auth.server.identity.key y nacos.core.auth.server.identity.value estén configurados de manera idéntica en cada miembro del clúster. Nacos usa estos valores para autenticar las solicitudes JRaft gRPC pero no las sincroniza en todo el clúster.
  • No confíe en una degradación progresiva de versiones mixtas después de que la autenticación JRaft haya entrado en modo forzado.

Los usuarios que ya utilizan AI API canónicos, puntos finales MCP públicos e identidades de servidor consistentes no se ven afectados por estos cambios de compatibilidad.
