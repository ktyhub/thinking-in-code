nacos 3.1.2

#nacos 3.1.2 Nacos 3.1.2 es una versión de parche centrada en mejoras de estabilidad, correcciones de seguridad y mejoras del módulo de IA. Los aspectos más destacados incluyen:

  • Seguridad: Spring Boot actualizado a 3.4.10 para abordar CVE-2025-55752, además de actualizaciones de dependencia log4j y gRPC
  • AI/MCP: se corrigieron problemas de inconsistencia de la caché de MCP y se agregó compatibilidad con parámetros de versión para consultas de tarjeta de agente
  • Consola: experiencia de implementación distribuida mejorada con sincronización automática de miembros del servidor y solución de múltiples problemas de ruta de contexto
  • Client: Se eliminó la pérdida de memoria de descarga de clases durante la recarga de configuración y se solucionó el problema de paso de UUID en la escucha difusa.
  • Config: publicación de metadatos de configuración mejorada con registros de auditoría y notificaciones

Característica

  • [#13996] Agregar publicación de eventos para operaciones de agente y punto final MCP
  • [#13999] Agregar registros de auditoría y notificaciones para la publicación de metadatos de configuración
  • [#14120] Agregar compatibilidad con parámetros de versión al método Obtener tarjeta de agente del mantenedor SDK

Mejora/Refactorización

  • [#14000] Elimina la pérdida de memoria de descarga de clases durante la recarga de configuración usando Configuration.initialize()
  • [#14062] Prevenir el riesgo potencial de modificación de datos en client ServiceInfoHolder
  • [#14099] Agregar validación para serviceName y groupName en SubscribeServiceRequestHandler
  • [#14449] Eliminar ThreadLocal ineficaz en MD5Utils
  • [#14454] Lanzar la excepción adecuada cuando los parámetros del formulario exceden el límite de tamaño

Corrección de errores

  • [#13770] Se corrigió la ruta de contexto que faltaba en importToolsFromMcp y otros API relacionados con la IA
  • [#14009] Se solucionó el problema de paso de UUID en la configuración de escucha difusa que provocaba que se filtraran los eventos de inicialización.
  • [#14016] Se corrigió la sincronización automática de miembros del servidor de la consola en una implementación distribuida
  • [#14020] Falta el arreglo '?' marcador de posición en la consulta de la base de datos
  • [#14024] Se corrigió la inconsistencia del índice de caché de MCP al recrear el servidor MCP con el mismo nombre.
  • [#14028] Se corrigió la selección del servidor remoto para usar nodos en buen estado durante las operaciones de importación/exportación.
  • [#14063] Solucionar error en el complemento de control
  • [#14104] Corregir errores de ruta de contexto AI API en la consola
  • [#14114] Se corrigió la detección incorrecta de grayRule en ConfigMigrateService
  • [#14121] Se corrigió el restablecimiento de la paginación de la interfaz de usuario de la consola a 0 en lugar de 1 en el error API
  • [#14210] Se corrigió MainLayout para manejar los cambios de idioma y obtener avisos sobre la actualización
  • [#14401] Se corrigió el campo creado incorrecto devuelto por ConfigRowMapperInjector
  • [#14402] Se corrigió la consulta LIKE MySQL escaping para evitar confusión con guiones bajos y guiones.
  • [#14442] Se corrigió la consulta LIKE de Derby y MySQL con manejo de escape adecuado
  • [#14450] Se corrigió la ruta contextual del servidor remoto de la consola para el mantenedor-client
  • [#14635] Se corrigió el método de actualización del estado de salud para manejar correctamente las instancias persistentes

Dependencias

  • [#14006] Actualice Spring Boot a 3.4.10 para abordar CVE-2025-55752
  • [#14055] Pasar org.apache.logging.log4j:log4j-core de 2.24.3 a 2.25.3
  • [#14714] Actualice la versión gRPC a 1.78.0

Implementación requerida
