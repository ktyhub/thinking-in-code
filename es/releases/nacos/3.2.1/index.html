#nacos 3.2.1 Nacos 3.2.1 es una versión de parche centrada en correcciones de errores críticos y mejoras de funciones para problemas descubiertos en 3.2.0. Esta versión ofrece mejoras significativas en la funcionalidad del Registro AI, la compatibilidad de la base de datos, la seguridad y la experiencia del usuario de la consola. Los aspectos más destacados incluyen:

  • Madurez del registro de IA: gestión completa del ciclo de vida de Prompt con interfaz de usuario, compatibilidad con el protocolo A2A AgentCard v1, filtrado de bizTag de habilidades y almacenamiento de especificaciones de recursos para servidores MCP
  • Mejoras de seguridad: se corrigió la vulnerabilidad de omisión de autenticación LDAP, se agregó soporte de inicio de sesión SSO OIDC/OAuth2 para ambas consolas
  • Compatibilidad de bases de datos: correcciones integrales de PostgreSQL, Oracle, MySQL y Derby, incluidos problemas de paginación determinista y marca de tiempo de esquema
  • Actualizaciones de dependencia: Spring Boot 3.5.13, MCP SDK 0.17.0 y log4j-core 2.25.4
  • Concurrencia y confiabilidad: se eliminaron las condiciones de carrera en el canal de publicación de IA, el módulo de nombres, la conmutación por error client y las operaciones de exportación de configuración.
  • UX de consola: se corrigieron errores de edición de configuración, validación de ID de espacio de nombres, importación por lotes, manejo de vencimiento de tokens y errores de UI en las consolas heredadas y próximas.

⚠️ Cambios importantes y notas de migración

Actualizaciones del esquema de la base de datos (críticas)

Acción requerida: Esta versión incluye correcciones críticas para los esquemas PostgreSQL, Oracle, MySQL y Derby, particularmente en torno a los valores de marca de tiempo predeterminados y las cláusulas ORDER BY para paginación determinista. Antes de actualizar:

  1. Haga una copia de seguridad de su base de datos existente
  2. Aplique el script de esquema actualizado: conf/schema.sql (para su tipo de base de datos)
  3. Reinicie el servidor Nacos después de la migración del esquema Bases de datos afectadas:
  • PostgreSQL: Correcciones de marcas de tiempo predeterminadas, compatibilidad con persistencia de recursos de IA
  • Oracle: Correcciones de marcas de tiempo predeterminadas
  • MySQL: Mejoras en la precisión de las consultas de paginación
  • Derby: Adiciones a la cláusula ORDER BY, correcciones de fugas de recursos JDBC Si no se aplican los cambios de esquema, se puede producir lo siguiente:
  • Fallos en el inicio de la base de datos (PostgreSQL)
  • Resultados de paginación inconsistentes
  • Fugas de recursos JDBC
  • Contaminación de la versión de recursos de IA

Configuración de SSO de OIDC/OAuth2

Esta versión agrega soporte de inicio de sesión SSO OIDC/OAuth2 para consolas heredadas y próximas. Para habilitar:

# OIDC Configuration
nacos.auth.oidc.enabled=true
nacos.auth.oidc.issuer-uri=<your-oidc-issuer-uri>
nacos.auth.oidc.client-id=<your-client-id>
nacos.auth.oidc.client-secret=<your-client-secret>
nacos.auth.oidc.redirect-uri=${domain}/v3/console/login
