Spring AI 1.1.5 Release Note

🎯 Destacados

Esta versión incluye 9 correcciones de errores, 3 mejoras en la documentación y 11 mejoras más.

⚠️ Notas de actualización

  • Se eliminó el modelo Pixtral 12B y Pixtral Large está obsoleto. Actualice la configuración de su modelo para utilizar los modelos Pixtral recomendados actualmente para evitar problemas en futuras versiones. 447d2a4

📢 Destacado

  • Se eliminó el modelo Pixtral 12B y el modelo Pixtral Large ahora está obsoleto. Las pruebas de integración se han actualizado para utilizar los modelos de reemplazo recomendados. Los usuarios que dependen de estos modelos deben migrar a las alternativas recomendadas. 447d2a4

🪲 Corrección de errores

  • Se corrigió el método doDelete del almacén de vectores CosmosDB para parametrizar adecuadamente las consultas, evitando posibles vulnerabilidades de inyección SQL y mejorando la corrección. 6039e57
  • Se solucionó un problema por el cual el ID de conversación no se aplicaba correctamente en el filtro VectorStoreChatMemoryAdvisor, lo que podía causar una recuperación de memoria incorrecta entre las conversaciones. 3cccfdf
  • Se corrigió el manejo de claves en el conversor de expresiones de filtro del almacén de vectores para garantizar que las expresiones de filtro se evalúen correctamente. 01386e2
  • Se resolvió el no determinismo de prueba en las pruebas de uso del token de transmisión de BedrockConverse, mejorando la confiabilidad de la prueba. 4747a3c
  • Se corrigió el nombre de la clase de prueba para aplicar correctamente el sufijo de prueba de integración, asegurando la categorización y ejecución adecuada de la prueba. #5853
  • Se corrigió la lógica de análisis de cadenas para el campo toolChoice en OpenAiSdkChatModel para garantizar el manejo adecuado de las configuraciones de elección de herramientas. aeb33b0 vía #5735
  • Se solucionó un problema por el cual el parámetro extra_body se incluía incorrectamente en las solicitudes salientes de OpenAI API, lo que podía causar un comportamiento inesperado. 4c0120c
  • Se resolvieron problemas con la generación y configuración de Javadoc para garantizar que la documentación de API se produzca correctamente. 0a71804
  • Se corrigió la condición de omisión de prueba para que las pruebas de integración se omitan correctamente cuando las claves API requeridas no están configuradas en el entorno. bc26dc1

📓 Documentación

  • Se actualizó el archivo README para incluir una nota sobre los requisitos de arquitectura de la CPU o información de compatibilidad. a21e988
  • Se agregó documentación que explica cómo los servidores MCP pueden volver a publicar herramientas de MCP clients, aclarando el modelo de propagación de herramientas en configuraciones de múltiples servidores. #5778
  • Documentación mejorada para aclarar el uso previsto y el comportamiento del parámetro extra_body en solicitudes OpenAI API. 3d4d75b

🔨 Actualizaciones de dependencia

  • Se actualizó la dependencia Spring Boot a la versión 3.5.14, incorporando las últimas correcciones de errores y mejoras del equipo Spring Boot. eb4c9a5
  • Se actualizó la dependencia Spring Boot a la versión 3.5.13 como actualización intermedia. 9b902f8
  • Dependencias de análisis de documentos actualizadas: Apache Tika se actualizó a 3.3.0, jsoup a 1.22.1 y Apache PDFBox a 3.0.7 para mejorar las capacidades de procesamiento de documentos y corregir errores. f25fc52

🔩 Actualizaciones de compilación

  • Se actualizaron las dependencias del flujo de trabajo de GitHub Actions a sus últimas versiones para mejorar la confiabilidad y seguridad de CI/CD. 9b70b38
  • Se cambió el flujo de trabajo de verificación de relaciones públicas para usar el paquete mvn en lugar de mvn test para una validación de solicitudes de extracción más eficiente. 7d2e455
  • Las pruebas de integración ahora se omiten en el proceso de CI para mejorar el rendimiento de la compilación y se eliminó el flujo de trabajo de generación de release note. #5688
  • El proyecto pasó a la siguiente versión de desarrollo 1.1.5-SNAPSHOT después del lanzamiento. 400dc42

🔐 Seguridad

  • Se fortaleció el directorio de caché predeterminado utilizado para los modelos de transformadores para evitar el acceso no autorizado o la manipulación de los archivos de modelos almacenados en caché. aac6b80
  • Se corrigió una posible vulnerabilidad de denegación de servicio donde un PDF con formato incorrecto podría causar una asignación excesiva de memoria durante el análisis del documento. b61ac6a
