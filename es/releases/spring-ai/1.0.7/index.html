Spring AI 1.0.7 Release Note

🎯 Destacados

Esta versión incluye cinco correcciones de errores y otras seis mejoras.

⏪ Cambios importantes

  • Los asesores de memoria de chat ahora requieren que se proporcione una ID de conversación explícita. Anteriormente, es posible que se haya utilizado una identificación predeterminada o implícita, lo que podría causar un alcance de memoria incorrecto en las conversaciones. Las personas que llaman ahora deben proporcionar explícitamente un ID de conversación. be48f06

⚠️ Notas de actualización

  • Si está utilizando PromptChatMemoryAdvisor, migre al asesor de reemplazo. Todos los asesores de memoria de chat ahora requieren que se proporcione un conversationId explícito: actualice su código para pasar una ID de conversación al crear o invocar asesores de memoria de chat. be48f06

🪲 Corrección de errores

  • Se corrigió la cadena escaping en el método doDelete del almacén de vectores Milvus al manejar listas de ID, evitando posibles errores de consulta durante las operaciones de eliminación. 864ef81
  • Se resolvió una mala configuración del ObjectMapper en el servidor MCP, asegurando un comportamiento adecuado de serialización y deserialización del JSON. 436c765
  • Se corrigieron problemas de configuración automática que afectaban al servidor MCP y la configuración del servidor Spring WebMvc. Se revirtió una solución incorrecta anterior y se reemplazó con la resolución adecuada. 4b21612
  • Pruebas de integración actualizadas para ChatClientAdvisor para proporcionar una ID de conversación explícita, alineándose con el nuevo requisito de ID explícitas en los asesores de memoria de chat. a5fb397
  • Se resolvió una falla en la prueba de integración client del chat antrópico para devoluciones de llamadas de funciones que invocan métodos. daa1b68

🔨 Actualizaciones de dependencia

  • Se actualizó el Protocolo de contexto del modelo (MCP) SDK mediante un salto de versión significativo (0.10.0 → 0.18.2), incorporando muchas mejoras, nuevas capacidades y actualizaciones de compatibilidad. #5958

🔩 Actualizaciones de compilación

  • La compilación del proyecto ahora utiliza JDK 17.0.19, lo que garantiza la alineación con la última versión del parche LTS para mejorar la seguridad y la estabilidad en el entorno de compilación. 1badb6f
  • Los módulos de inicio Spring AI se han reubicado en un directorio de inicio dedicado, mejorando la estructura y organización del directorio del proyecto. 36df6b9
  • La versión del proyecto avanzó a 1.0.7-SNAPSHOT para comenzar el siguiente ciclo de desarrollo después del lanzamiento de 1.0.6. 82848f2
