QwenPaw v1.1.6

✨ Agregado

Sistema de agentes

  • Diagnóstico de Windows: qwenpaw doctor ahora comprueba problemas del entorno específicos de Windows, incluida la compatibilidad con rutas largas, el modo de idioma PowerShell y la longitud de la ruta del directorio de trabajo (#4032)
  • Estado del agente API: Nuevo estado de tiempo de ejecución del agente de informes de terminal GET /agents/{agentId}/agent-status, recuento de tareas en ejecución y marcas de tiempo de las tareas (#4107)
  • Aislamiento de sesión cron: las tareas cron ahora admiten una opción share_session: cuando está deshabilitada, cada ejecución programada crea un contexto de sesión aislado con un ID de tarea cron (#4117)
  • Complemento GPT Image 2: Nuevo complemento de herramienta para generar imágenes a través de GPT Image 2 API de OpenAI (#3911)
  • Nombre del agente basado en configuración: use el nombre del perfil del agente configurado en lugar de un valor predeterminado codificado (#4140) Chat y consola
  • Entrada de voz Whisper: Se reemplazó Web Speech nativo del navegador API con transcripción Whisper del lado del servidor para una entrada de voz más confiable en todos los navegadores (#3574)
  • Títulos de sesiones generados por el LLM: las sesiones de chat ahora las titula automáticamente el LLM en segundo plano después del primer mensaje. Configurable mediante la opción "Generar títulos de sesión automáticamente" en Configuración del agente (#3829)
  • Tendencias de uso de tokens: se agregaron gráficos de líneas de tendencia por modelo y por tipo de token a la página de configuración de uso de tokens para visualizar el uso a lo largo del tiempo (#4080, #4094)
  • Operaciones de habilidades por lotes: se agregaron botones Activar y Desactivar a la barra de herramientas de operaciones por lotes de habilidades con informes de errores por habilidad (#4091)
  • Representación de diagramas de sirena: los bloques de código Markdown con la etiqueta de idioma mermaid ahora se representan como diagramas interactivos en el chat y en las vistas previas de archivos (#4146)
  • Portugués brasileño (pt-BR): se agregó compatibilidad total con la configuración regional pt-BR para la interfaz de usuario de la consola y la configuración de idioma del backend (#4009, #4143) Proveedores
  • Proveedor de Volcano Engine: se agregó Volcano Engine como proveedor integrado compatible con OpenAI con puntos finales estándar y del plan de codificación (#3994)
  • Selección de región de DashScope: la URL base de DashScope ahora se puede modificar desde puntos finales de región preestablecidos (#4074)
  • Proveedor del plan de token Aliyun: se agregó el plan de token Aliyun como proveedor integrado (#4122)
  • Tokens máximos predeterminados de Anthropic: se aumentó el max_tokens predeterminado para los modelos compatibles con Anthropic a 16,384 (#4054) Canales
  • Tarjetas de aprobación interactivas de Feishu: las solicitudes de aprobación de protección de herramientas en Feishu ahora se representan como tarjetas de botones interactivas que se actualizan en el lugar al aprobar/rechazar, con una sugerencia de enlace de documentación cuando la devolución de llamada de acción de la tarjeta no está suscrita (#3941, #3982)
  • Compartir sesión grupal de WeCom: se agregó la opción share_session_in_group para controlar si los miembros del chat grupal comparten una sola sesión u obtienen aislamiento por miembro (#3948)
  • Contexto del remitente Feishu: el apodo del remitente Feishu ahora se pasa al contexto del entorno del agente (#4098)
  • Tarjetas de aprobación interactivas de WeCom: las solicitudes de aprobación de protección de herramientas en WeCom ahora se representan como tarjetas de plantilla interactivas (#4112) Seguridad
  • Protección transversal de rutas de archivos estáticos: el servicio de archivos estáticos de la consola ahora rechaza rutas absolutas para evitar la omisión de cruce de rutas (#3973)
  • Denegación automática a nivel de regla: ahora se pueden configurar reglas de seguridad individuales para denegar automáticamente las llamadas a herramientas (#4046) Habilidades y CLI
  • Prueba de habilidades CLI: nuevo comando qwenpaw skills test para validar el contenido de las habilidades y ejecutar análisis de seguridad (#3999)
  • Instalación/desinstalación de habilidades CLI: nuevos comandos qwenpaw skills install y qwenpaw skills uninstall para administrar habilidades desde la línea de comandos, admitiendo instalaciones de espacio de trabajo por agente y a nivel de grupo (#4053)

⚡ Rendimiento

  • Representación de consola: se eliminaron reproducciones duplicadas al estabilizar las comparaciones de estados de sondeo de aprobación y memorizar las opciones de tiempo de ejecución del chat (#4052, #4110, #4153)
  • Navegación del historial de chat: omita la búsqueda del historial de chat para teclas que no sean de flecha y almacene en caché las listas de mensajes de usuario para evitar exploraciones repetidas en cada pulsación de tecla (#4130)
  • Limpieza de sondeo QR: detenga inmediatamente el sondeo de códigos QR y borre los indicadores de estado al completar la autenticación o expirar el código (#4148)

🐛 Fijo

Canales

  • WeCom Stream Keepalive: mantenga activo el flujo de marcador de posición "Pensando..." con actualizaciones periódicas para evitar indicadores de estado bloqueados en WeCom (#3950)
  • WeCom Reconnect Race: Se corrigió la programación de doble reconexión y la desconexión de bucle entre eventos en el manejo de WeCom WebSocket (#3963)
  • Reintento de red de Telegram: se agregó un retroceso exponencial y una reconexión controlada para errores transitorios de la red de Telegram en lugar de morir silenciosamente (#4039)
  • WeChat Cron Buffer Flush: Vacíe el búfer de combinación de WeChat inmediatamente para envíos cron/proactivos que omiten la ruta de finalización normal (#4106)
  • División de tablas de rebajas: preserva la estructura de la tabla de rebajas en los fragmentos de mensajes repitiendo las filas de encabezado y separador en cada fragmento (#4119) Sistema de agentes
  • Tiempo de espera del agente externo: Se agregó un tiempo de espera predeterminado seguro (60 s) para delegate_external_agent para evitar bloqueos indefinidos (#3928)
  • Recarga de configuración del agente: los cambios en el archivo de configuración del agente ahora activan una recarga elegante con drenaje de tareas en lugar de una reinstalación ligera (#4064)
  • Persistencia de la configuración del agente: se corrigió que el editor de configuración del agente de la consola eliminara las configuraciones anidadas al guardar, preservando la estructura de configuración completa (#4157) MCP
  • Tiempo de espera de ejecución de MCP: use sse_read_timeout como tiempo de espera de ejecución de la herramienta MCP en lugar del tiempo de espera de conexión HTTP más corto (#4058, #4061)
  • Fuga del ciclo de vida de MCP Client: Se corrigió una fuga de tarea de ciclo de vida donde close() podía omitir la detención de una tarea de reconexión en segundo plano (#4152) Consola y interfaz de usuario
  • Seguridad del sustituto de SSE: evite la falla de la transmisión de SSE en texto sustituto con formato incorrecto desinfectando el contenido no codificable antes de la serialización (#3553)
  • Ajuste de línea CodeMirror: ajuste de línea fijo en bloques de entrada/salida de llamada de herramienta (#3960)
  • Nombre para mostrar del agente predeterminado: respete el nombre personalizado para el agente predeterminado en todas las superficies de la interfaz de usuario (#4073)
  • Rutas de vista previa de archivos: Se corrigió la eliminación de prefijos de URL redundantes en las rutas de vista previa de archivos que podrían causar URL rotas (#4089) Infraestructura
  • Restauración de copia de seguridad Docker: restaure correctamente los secretos en los puntos de montaje del volumen Docker intercambiando el contenido del directorio en lugar de cambiar el nombre (#3916)
  • Rutas de bloqueo de audio: devuelve la ruta del sistema de archivos resuelta para los bloques de audio URL file:// y elimina el código de manejo de archivos redundante (#4021, #4048)
  • Rotación de registros: use RotatingFileHandler para la rotación de registros en todas las plataformas (#4076)
  • Omisión de proxy de bucle invertido: omita las variables de entorno del proxy para las comprobaciones de estado del bucle invertido API para evitar fallas de conexión detrás de los servidores proxy corporativos (#4092)
  • Conda Packaging: restaure las herramientas de empaquetado de Conda antes de ejecutar conda-pack para evitar roturas en el proceso de empaquetado (#4093)

📝 Documentación

  • Preguntas frecuentes sobre el tiempo de espera de WSL2: se agregó una entrada de preguntas frecuentes para manejar APITimeoutError cuando se ejecuta en modo WSL2 NAT (#4005)
  • Actualización de documentación: documentación del sitio web actualizada para reflejar nuevas funciones (#4013)

🧪 Pruebas y CI

  • Pruebas unitarias de consola: se agregó la configuración de Vitest con pruebas unitarias y de componentes que cubren Chat, capa API y componentes compartidos (#3559, #4121)
  • Pruebas de humo de integración: Se agregaron pruebas de humo de variables de entorno y configuración y inicio de la aplicación (#4081)
