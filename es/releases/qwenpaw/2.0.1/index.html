QwenPaw v2.0.1

¿Qué ha cambiado?

✨ Agregado

Plataforma PawApp

  • PawApp SDK y aplicación Kanban: una nueva plataforma de miniaplicaciones que permite a los complementos crear interfaces de usuario interactivas ricas sobre QwenPaw. Se envía con una aplicación de tablero de tareas Kanban incorporada para la gestión de proyectos (#6150) Modos de agente personalizados
  • Modo de agente editable por el usuario: cree y edite modos de bucle de agente personalizados directamente desde la consola: defina límites de iteración, condiciones de parada y puertas de aprobación sin tocar el código (#6270)
  • Complemento Oh-My-Paw: cinco bucles de agentes listos para usar (UltraQA, Ralph, Ultrawork, Autopilot, Team) para colaboración entre múltiples agentes y tareas de larga duración (#5882) Memoria y observabilidad
  • Mantenimiento del índice ReMe Light: reconstrucción explícita del índice mediante el botón de la consola o API, autorreparación de inicio mejorada y fragmentación de Markdown optimizada para documentos grandes (#6235)
  • Mejoras en la confiabilidad de ReMe: inspección de estadísticas de memoria en tiempo de ejecución, seguridad de incorporación de CJK y cierre ordenado del resumen en segundo plano (#6098)
  • Protección de indexación de ReMe: validación de configuración mejorada y estabilidad de indexación (#6153)
  • Enriquecimiento de seguimiento de Langfuse: los seguimientos ahora llevan el ID de usuario, el ID de sesión y la versión del paquete para un mejor filtrado y análisis (#5922)
  • Configuración de retención del historial: los días de retención del contexto de desplazamiento ahora se pueden configurar desde la consola (#6214) Consola y escritorio
  • Archivo de chat: Archiva conversaciones antiguas para mantener limpia la lista de sesiones (#6078)
  • Carga de archivos con arrastrar y soltar: suelte los archivos directamente en el área de entrada del chat en la aplicación de escritorio (#6327)
  • Clasificación del mercado de complementos: ordena los complementos por descargas, tiempo de actualización o favoritos (#6349)
  • Copia de configuración del agente One-click: duplicar la configuración de un agente con un solo click (#6262)
  • Rotación de registros configurable: establece límites de rotación de archivos de registro desde la configuración (#6183) Seguridad y Gobernanza
  • Zona de pruebas con token restringido de Windows: ejecución de código aislada mediante tokens restringidos de Windows para una opción de zona de pruebas adicional (#5931)
  • Reglas de gobernanza: nuevas definiciones de reglas de gobernanza para un control de acceso más detallado (#6215)
  • Detección de archivos confidenciales: se detectan más tipos de archivos como confidenciales; Las lecturas de archivos globales ahora se permiten de forma predeterminada para rutas no confidenciales (#6067) Tiempo de ejecución y multiagente
  • Control de inicio de múltiples agentes: simultaneidad de inicio limitada con indicador de preparación parcial en la consola (#6198)
  • Entrega cron silenciosa: las tareas programadas pueden entregar resultados de forma silenciosa y sin notificaciones (#6080)
  • Preservación de metadatos de eventos: los metadatos de complementos y extensiones ahora se transmiten a través de sobres de salida en tiempo real (#6224)
  • Sonda de preparación: nuevo punto final /api/healthz para verificación de estado y orquestación de contenedores (#6028)
  • Autenticación de proxy Trusted: Verifique los servidores proxy trusted y resuelva las IP client reales para implementaciones detrás de balanceadores de carga (#6030) CLI
  • gh CLI permitido en la gobernanza: los comandos GitHub CLI ahora están permitidos por la política de gobernanza (#6031)

🔄 Cambiado

  • El bucle ReAct predeterminado ahora está modelado como un DefaultMode de primera clase, otorgando a cada modo propiedad explícita de su ciclo de vida y puertas (#6210)
  • Comandos de barra ACP desacoplados del núcleo, comprobaciones de seguridad extraídas en un módulo independiente y flujo de arranque unificado (#5796)
  • La llamada de herramienta de canal y la visualización de resultados de herramienta ahora tienen controles de alternancia separados (#6233)
  • Las reglas de detección de ToolGuard ahora están conectadas al motor de políticas de gobernanza para una evaluación unificada (#6390)
  • La sincronización automática de DEFAULT_USER_RULES ya no requiere una lista blanca manual (#6025)
  • El botón de aprobación de herramientas ahora usa toolSource en lugar de executionLevel para el control "Permitir siempre" (#6095)
  • Razonamiento del agente optimizado para reducir los bucles de pensamiento redundantes y las invocaciones de herramientas duplicadas (v2.0.0.post4)

🐛 Fijo

Escritorio

  • La aplicación de escritorio ahora cierra correctamente el backend antes de salir, evitando la pérdida de memoria y una limpieza incompleta (#6225)
  • Los enlaces de Markdown en el escritorio ahora se abren en el navegador del sistema en lugar de navegar por la ventana de la aplicación (#6300)
  • El editor Monaco se carga desde un paquete local para obtener una vista previa de la codificación sin conexión (#6291)
  • WKWebView ya no fija una versión obsoleta de la interfaz de la consola (#6107)
  • Actualizaciones de Tauri restringidas solo a compilaciones OSS (#6071) Tiempo de ejecución y agentes
  • El contenido de razonamiento ahora rota correctamente en nuevos bloques de razonamiento durante la transmisión (#6310)
  • Los argumentos de llamada a la herramienta se transmiten de forma incremental en lugar de almacenar en el búfer la respuesta completa (#6343)
  • Las aprobaciones de subagente ahora se enrutan y resuelven correctamente desde la sesión raíz (#6295)
  • Se corrigieron fallas de validación de entrada que bloqueaban los flujos de trabajo paralelos de Oh-My-Paw (#6395)
  • Las tareas detenidas ahora esperan una limpieza adecuada antes de indicar su finalización (#6347)
  • Los chats en segundo plano están debidamente registrados; corredor heredado eliminado (#6272)
  • La salida de razonamiento y los segmentos de herramientas ahora están correctamente alineados (#6280)
  • La anulación del modelo por solicitud ahora se respeta correctamente (#5731)
  • La entrada de llamada de herramienta con formato incorrecto se muestra en el modelo para su autocorrección (#5761)
  • Umbrales de Doom Loop ajustados para reducir los falsos positivos (#6184)
  • Utilice max_completion_tokens para modelos de razonamiento (#6015)
  • Los espacios en blanco en los deltas de texto/pensamiento de transmisión se conservan correctamente (#6166)
  • Las imágenes ya no se eliminan para modelos multimodales cuando falla la búsqueda de información del modelo (#6154, #6217) Consola y interfaz de usuario
  • La copia de resultados de la herramienta funciona en todos los contextos del navegador, incluidos los que no son HTTPS (#6275)
  • La lista de habilidades se actualiza automáticamente después de la instalación desde el mercado (#6296)
  • La aprobación única de la herramienta ahora tiene prioridad sobre la configuración a nivel de sesión (#6357)
  • La insignia de la bandeja de entrada muestra el recuento de todas las aprobaciones pendientes, no solo las altas/críticas (#6391)
  • Se eliminan los errores de vista previa de medios obsoletos; imágenes de ruta relativa manejadas correctamente (#6385)
  • Se mejoró el contraste del texto en modo oscuro para las plantillas de bucle y el historial de chat (#5975)
  • La función de autocompletar del navegador ya no se activa al ingresar la búsqueda del proveedor (#6011)
  • La cola de mensajes de chat se borra correctamente cuando se elimina una sesión (#6045)
  • La carga de desplazamiento de la página de habilidades ya no se detiene después del primer lote (#5968) Gobernanza y seguridad
  • El registro de auditoría deshabilitado ahora se respeta correctamente (#6369)
  • Las herramientas complementarias se cancelan del registro al descargarlas; Comprobaciones de seguridad de ToolGuard compartidas correctamente en todos los contextos (#6311)
  • Aislamiento del modo de flujo de trabajo Oh-My-Paw reforzado con instancias por espacio de trabajo y correcciones de puerta de bifurcación/negación total (#6317)
  • Los valores predeterminados de la herramienta de complemento se actualizan al registrarse; Se agregó validación de tipo de herramienta (#6313)
  • Registro automático de herramientas a través de @tool_descriptor y PluginApi (#6190)
  • El estado obsoleto del entorno de pruebas en modo APAGADO se borró correctamente (#6122)
  • Las reglas de protección de herramientas de frontend ahora se unen al análisis profundo de políticas (#6063)
  • Sandbox conserva la RUTA de venv en la ejecución del shell (#6081)
  • El interruptor sandbox_enabled se respeta en la ruta del entorno de pruebas en modo APAGADO (#6109)
  • Los comandos Sudo ahora solicitan permiso al usuario correctamente (#6079) Memoria
  • Memoria automática restringida solo a consultas de usuarios externos (#6120)
  • auto_memory_interval se puede configurar en 0 para desactivar la memoria automática (#6135)
  • Se agregó la opción de alternar el horario de ensueño (#6171)
  • Historial de tareas de resumen de memoria correctamente delimitado (#6206)
  • Codificación de ID de sesión segura de Windows para almacenamiento de archivos ReMe (#6022) MCP
  • Los encabezados ${VAR} se migraron a las referencias de credenciales de entorno durante la migración del controlador (#6091)
  • La migración de MCP heredado se realizó de una sola vez a través de una marca de agua de esquema (#6133)
  • Las actualizaciones de la política de acceso de MCP se aplican de inmediato (#5949)
  • El inicio del espacio de trabajo ya no está bloqueado por el tiempo de espera de conexión de MCP (#6174)
  • Espacio de nombres alternativo en el nombre de la herramienta MCP desinfectado para cumplir con OpenAI (#6209) CLI y canales
  • cron update ahora conserva el tiempo de ejecución y los campos de solicitud intactos (#6236)
  • Estado de los canales SIP, Matrix y Slack correctamente delimitados para evitar pérdidas de memoria (#6207)
  • El sondeo de Telegram ya no entra en el bucle de conflicto 409 (#6005)
  • Estado de canal delimitado y seguimiento de tareas de activar y olvidar para evitar pérdidas de memoria (#6168)
  • Se solucionó el fallo de TUI cuando cli interrumpía la salida de streaming (#6069) Observabilidad
  • Los ID de seguimiento de Langfuse ahora utilizan un formato hexadecimal válido (#6277) Otro
  • La anulación de la ranura del modelo pasa correctamente a través del canal de la consola hasta la fábrica del modelo (#6304)
  • Comprobación GGUF del modelo local adaptado al cambio de clave ModelScope SDK (#6290)
  • El punto de entrada de Tauri utiliza importaciones absolutas (#6234)
  • La verificación de referencia de archivos ya no falla en OSError (#6247)
  • Sesión obsoleta limpiada después de completar el objetivo (#6086)
  • Restablecer puertas de parada en los comandos /new y /clear (#6094)
  • Límites de contexto reforzados con compactación recuperable de resultados de herramientas (#6123)
  • Compatibilidad de codificación GBK en la ejecución de comandos en Windows (#6140)

  • El uso del navegador ahora tiene un tiempo de espera máximo para evitar bloqueos indefinidos (#6170)
  • La caché de uso de tokens ya no persistía cuando no se sembraba (#6220)

  • La migración del historial de sesiones se escribe por lotes para un inicio más rápido (#6021)
