QwenPaw v1.1.10

¿Qué ha cambiado?

✨ Agregado

Sistema de agentes

  • Spawn Subagent: Nueva herramienta spawn_subagent para la ejecución efímera de subagente en el espacio de trabajo (#4806) Modo de codificación
  • Open Directory: Nueva pestaña "Open Directory" para hacer referencia a proyectos locales sin copiar archivos en el espacio de trabajo (#4762) Canales
  • Canal Tencent Yuanbao: nueva integración de canal para el bot Tencent Yuanbao (#4856)
  • Respuesta del hilo de Feishu: los agentes ahora pueden responder dentro de los hilos de mensajes de Feishu (#4708) Proveedores
  • Atribución de OpenRouter: se agregaron encabezados de atribución de aplicaciones para la visibilidad de clasificación de OpenRouter (#4809) Consola y carga
  • Límite de carga dinámica: el límite de tamaño de carga ahora se puede configurar en la consola y los canales (#4734) Pruebas
  • Migración de prueba E2E: migré python_e2e a CoPaw con infraestructura simulada (#4464)
  • Expansión de la prueba de integración: cobertura ampliada con escenarios de datos iniciales (#4745)

🔄 Cambiado

  • Sistema de tarjetas Feishu: sistema de tarjetas reestructurado para que coincida con el patrón wecom/qq y tarjeta resuelta fija en modo de transmisión (#4742)

🐛 Fijo

Escritorio y CLI

  • Escritorio incluido CLI: Se agregó qwenpaw CLI incluido para la aplicación de escritorio Tauri (#4779)
  • Consola Git de Windows: Ocultar las ventanas de la consola Git de Windows en modo de codificación (#4696) Consola
  • Entrada de chat móvil: entrada de chat adaptada para área segura y teclado virtual en el móvil (#4751)
  • Borrador de entrada de chat: borrar el borrador de entrada de chat después de enviar el mensaje (#4755)
  • Entrada de chat: se corrigieron problemas adicionales de entrada de chat (#4862)
  • Código de chat: Se corrigieron problemas de visualización del código de chat (#4805)
  • Antd Deprecation: se limpiaron las advertencias de desuso de antd 5.29 y se corrigió el ícono AllowNoAuthHosts (#4790) Canales
  • OneBot WebSocket: reinicio automático del servidor WebSocket en caso de pérdida de conexión a través de la sonda de estado TCP (#4793) Agente
  • Contenido de razonamiento: conservar reasoning_content en todos los bloques de archivos en los mensajes del asistente (#4728)
  • Marca de tiempo del mensaje: manejo mejorado de la marca de tiempo con compatibilidad con la zona horaria del usuario (#4763) Habilidades
  • Estabilidad de la actualización de habilidades: conservar la etiqueta, habilitar/deshabilitar y la configuración del canal durante las actualizaciones de habilidades (#4847)
  • Manejo de habilidades obsoletas: ignora las habilidades obsoletas con el prefijo ~ durante las operaciones de pip (#4851) Mascota
  • ** Dependencias de instalación automática **: instale automáticamente las dependencias que faltan para resolver el error de inicio en v1.1.9 (#4801) Sitio web
  • Estilo de encabezado: estilo de encabezado fijo y video de continuación automática agregado (#4812)

🏗️ Infraestructura

  • Limpieza de CI: Se eliminó el flujo de trabajo unit-tests.yml redundante (#4748)
  • Datos de contribuyentes: mantener automáticamente contributors_data.json a través de acciones GitHub en la fusión de relaciones públicas (#4692)
