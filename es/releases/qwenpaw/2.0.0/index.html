QwenPaw v2.0.0

¿Qué ha cambiado?

✨ Agregado

Arquitectura central

  • Tiempo de ejecución 2.0: Refactorizar el kernel basado en AgentScope 2.0 (#5078, #4846, #5018, #5552)
  • Controlador del sistema operativo del agente: administración unificada de conexiones MCP/A2A/ACP, almacenamiento de credenciales cifradas y política de aprobación por llamada (#5067)
  • Ingeniería de bucle: Nuevo diseño de puerta de bucle con tres plantillas de bucle: modo normal/modo misión/modo objetivo (#5665, #5727)
  • Gobernanza y Sandbox: motor de políticas con reglas de permitir/denegar/preguntar, detectores ToolGuard fusionados en una única ruta de evaluación de políticas y un patrón de gobernanza generalizado para complementos (#5088, #5546, #5301) Gestión del contexto
  • Contexto de desplazamiento: historial de trabajo respaldado por SQLite (history.db) con búsqueda de texto completo FTS5, índice de desalojo, persistencia de nivel de turno y un REPL recall_history_python en espacio aislado para recuperación bajo demanda de turnos anteriores. Retención predeterminada de 30 días, importa automáticamente las sesiones existentes al inicio (#5321)
  • Compresión nativa: Refactorización utilizando la estrategia de compresión de contexto incorporada de AgentScope 2.0 (#5309) Memoria a largo plazo
  • Backend de ReMe v0.4.0: reemplace el tiempo de ejecución de la memoria interna con ReMe v0.4.0; el almacenamiento de vectores, el seguimiento automático y la recuperación ahora son manejados por la biblioteca ReMe v0.4.0 (#5349)
  • Seguimiento por turnos: las escrituras en la memoria ahora se realizan por turno a través del middleware y ya no están vinculadas al cierre de la sesión (#5540)
  • Búsqueda basada en el uso: la búsqueda de memoria ahora considera la actualidad y la frecuencia; Selección de modelo de incrustación específica del backend agregada a la interfaz de usuario de configuración (#5820)
  • Modo REST ADBPG: el backend de memoria ADBPG cambió a solo REST, con búsqueda automática (#5296)
  • Simplificación de la interfaz de usuario de búsqueda: visualización de búsqueda de memoria más limpia, campos de metadatos reducidos a lo esencial (#5482)
  • backend 'none': opción de configuración para desactivar completamente el sistema de memoria para implementaciones ligeras (#5732) Interfaz de usuario de terminal (TUI)
  • TUI de pantalla completa: una aplicación de chat de terminal basada en texto (qwenpaw tui): salida de streaming, representación de llamadas de herramientas, barra de estado y administración de sesiones, todo en el terminal (#5032)
  • Sesiones con ámbito de proyecto: TUI puede iniciar una sesión de modo de codificación con ámbito de un directorio de proyecto específico (#5448)
  • Barra de uso de contexto: indicador de uso de contexto/token en vivo en la barra de estado de TUI (#5673)
  • Comandos ACP en TUI: comandos de aprobación en línea /approve, /deny + mejoras en el panel de transcripción (#5443, #5714) Consola y interfaz de usuario
  • Tarjeta de aprobación: botones de acción más grandes, vista previa de diferencias más clara, aprobación/rechazo one-click (#5855)
  • Carga de texto largo: pegue o cargue bloques de texto grandes directamente en la entrada del chat (#5854)
  • Aprobación de herramienta a nivel de sesión: Anular la política de herramienta global por sesión (#5685, #5832)
  • Banner de no propietario: muestra un banner de "solo lectura" cuando se ve la pestaña de sesión de otra persona (#5664)
  • Diseños móviles: CSS responsivo + navegación basada en cajones para todas las páginas de la consola (#5444–#5470)
  • Vista dividida de la página de herramientas: las herramientas habilitadas frente a las disponibles se muestran en columnas separadas; Alternancia con reconocimiento de configuración por herramienta (#5509, #5604)
  • Mejoras en el mercado de habilidades: recuento de estrellas/descargas, división habilitada/deshabilitada, sincronización automática desde CDN (#5521, #5706, #5639)
  • Diseño dual de la página de canales: canales habilitados en la parte superior, disponibles debajo (#5504)
  • Modo de codificación dividido 50/50: el panel de chat ocupa la mitad de la ventana gráfica (#5473)
  • Carpetas ocultas en el navegador de proyectos: ahora se pueden seleccionar directorios con el prefijo . (#5828)
  • Cajón de sesiones: sesiones agrupadas por fecha con búsqueda en línea (#5728)
  • Ventana emergente de uso de token: gráfico circular que muestra el uso de token/contexto por turno, restaurado para Runtime 2.0 (#5493, #5544)
  • Filtros de bandeja de entrada: filtrar notificaciones push por tipo de fuente (#5522)
  • Anclajes de mensajes: navegador de salto a mensajes para turnos de usuario (#5515)
  • Tiempo de espera de solicitud: Tiempo de espera HTTP configurable + propagación de AbortSignal para llamadas de backend (#5764) Proveedores modelo
  • OpenAI Response API: nuevo proveedor para el formato OpenAI Response API (#5519)
  • Actualizaciones de DashScope: Qwen3.7 + DeepSeek V4 agregado a la lista de modelos integrados; Paso extra_body para generate_kwargs; alternancia de relé de pensamiento por modelo (#5646, #5491, #5687, #5730)
  • Modelos GitHub: migrar al nuevo terminal API; admite PAT detalladas (#5735)
  • URL base personalizada de Telegram: configuración api_base_url para servidores Telegram Bot API autohospedados (#5651) Canales
  • Transmisión matricial: transmisión de edición in situ, ya no envía un mensaje nuevo por fragmento (#5585)
  • Canales registrados en complementos: los complementos pueden registrar tipos de canales personalizados con un esquema JSON que genera automáticamente la interfaz de usuario de configuración (#4693)
  • Alternancia de rebote por canal: marca no_text_debounce para que los canales rápidos no agrupen mensajes (#5617)
  • Slack: implementación de canal completo con archivos adjuntos multimodales, respuestas a hilos y streaming (#5193)
  • Implementación privada de DingTalk: configuración api_endpoint para instancias de DingTalk locales (#5111)
  • Canal Azure Bot: canal Azure Bot agregado como complemento, con soporte i18n/custom-icon/doc_url para canales de complementos (#5849)
  • Adjuntos de Discord: Descargar a media_dir local, servir a través de ruta de archivos estáticos (#5468) Escritorio
  • Migración de Tauri: compilación de escritorio trasladada de Electron a Tauri: binario más pequeño, vista web nativa, instalador NSIS en Windows (#5734, #4669, #4041)
  • Tiempo de ejecución de ACP incluido: tiempo de ejecución Node.js + módulos ACP se envían dentro del paquete de escritorio para comunicación con el agente lista para usar (#5814, #5794)
  • Gesto de DevTools: logotipo 8× click abre Chromium DevTools para depurar (#5805) Seguridad y zona de pruebas
  • Windows AppContainer sandbox: ejecución de código aislada a través del AppContainer nativo de Windows API (#5525)
  • Linux bubblewrap sandbox: montar el aislamiento del espacio de nombres mediante bwrap para la ejecución de código de Linux (#5310)
  • Alternancia de seguridad de herramienta cron: indicador por trabajo para requerir/omitir aprobación de herramienta para tareas programadas (#5847)
  • Detección de comandos peligrosos: ToolGuard detecta find -delete y patrones de shell destructivos similares (#5843)
  • Política de acceso: reglas declarativas de permitir/denegar/preguntar evaluadas por llamada de capacidad Complementos
  • Ganchos de middleware de AgentScope: los complementos pueden registrar middleware compatible con AgentScope con control de versiones semver (#5221)
  • Catálogo controlado por versión: el mercado de complementos y la CDN solo muestran complementos compatibles con la versión de QwenPaw en ejecución (#5661)
  • Enganches del ciclo de vida: gancho on_uninstall, correcciones del validador y proveedor de habilidades públicas API para autores de complementos (#5008) Herramientas
  • web_search y web_fetch: herramientas de búsqueda y recuperación web integradas con identidad de producto (#5890)
  • Opción show_file grep_search: agregue el indicador show_file para mostrar el contenido del archivo coincidente (#5840)
  • Paso de error de herramienta: estado de error de resultado de herramienta reenviado a la interfaz para una mejor experiencia de usuario (#5912) CLI
  • cron update: Editar programación/mensaje/configuración de trabajos cron existentes sin eliminar+recrear (#5210) Observabilidad
  • Langfuse 2.0: agrupación de seguimiento restaurada mediante integración de gancho; cada bucle de agente es un lapso de generación de Langfuse (#5511)

🔄 Cambiado

  • relay_reasoning: preserve_thinking renombrado a relay_reasoning; El valor predeterminado es desactivado para DashScope para evitar razonamientos duplicados en la salida (#5876)
  • Limitación de velocidad: limitación de velocidad multidimensional (IP + usuario + punto final) con ventanas configurables (#5738)
  • Ciclo de vida de la memoria: comando /compact reelaborado; nuevo comando /system_prompt; estado de búsqueda simplificado para evitar incrustaciones obsoletas (#5450, #5815)
  • Componente SessionItem: todos los renderizadores de sesión consolidados en un componente SessionItem (#5754)
  • Skill UI: componentes SkillPool/SkillMarket refactorizados; CSS muerto eliminado (#5753, #5532)
  • Modo de plan eliminado: la configuración del agente ya no incluye plan_mode; Se limpiaron las referencias de la interfaz de usuario (#5605, #5618)
  • Retención de la versión del complemento: las versiones antiguas del complemento se mantienen en el disco después de la actualización; estado de carga fallida limpiado en el siguiente arranque (#5695)
