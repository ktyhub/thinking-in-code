QwenPaw v1.1.12

¿Qué ha cambiado?

✨ Agregado

Consola

  • Revisión de la página de modelos: agregación de proveedores, interfaz de usuario de tarjeta unificada y rediseño del diseño (#5203)
  • Modo simple: agregue modo simple con navegación plana y lista de sesiones ordenadas por hora actualizada (#5222)
  • Alternancia de modo amplio: agregue alternancia de modo amplio para un diseño de chat ampliado (#5212)
  • Uso de token por turno: agregar token por turno y ventana emergente de uso de contexto (#5130)
  • Cola de entrada de usuario: Agregar cola de entrada de usuario (#5158)
  • Filtro de sesión por título: Agregar filtro de sesión por título (#5178)
  • Resaltado de sintaxis: agregue resaltado de sintaxis para bloques de código en todas las vistas (#5219)
  • Idioma vietnamita: agregue compatibilidad completa con el idioma de la interfaz vietnamita (vi) (#5186)
  • Mensaje de reserva: muestra el mensaje de reserva cuando la salida de respuesta está vacía (#5232) Habilidades
  • Actualización del mercado de habilidades: actualiza el mercado de habilidades, incluye la plataforma QwenPaw, mejora la interfaz de usuario (#5123)
  • Skill Slash Inject: Mejora la habilidad-slash-inject y la visualización (#5146) Canales
  • Mensajes citados de Yuanbao: admite mensajes citados y unifica el proceso de descarga de medios (#5160)
  • Filtrado de bots de Yuanbao: agregue filtrado de mensajes de bot y compatibilidad con variables de entorno (#5150)
  • Descarga sin bloqueo: Descarga sin bloqueo con regulación adaptativa para todos los canales (#5215)
  • DingTalk Liveness Watchdog: agrega un dispositivo de vigilancia de vida para recuperar la transmisión después de la suspensión del sistema (#5224) Escritorio
  • Persistencia del puerto: persistir el puerto backend durante los reinicios para preservar el almacenamiento local (#5051)
  • Configuración de puerto: compatibilidad con la configuración del puerto de escritorio (#5272) Archivos
  • Vista previa de archivos: mejore el manejo de errores de vista previa de archivos y use FileResponse (#5115) CI
  • Puerta de verificación de lanzamiento: Agregar puerta de verificación de lanzamiento entre la compilación y la publicación (#5121) Observabilidad
  • Langfuse Agent Loop: Agrupa observaciones de Langfuse por bucle de agente (#5128)

🔄 Cambiado

  • Solicitar transformaciones de carga útil: Solicitar transformaciones de carga útil (#5188)
  • Estilo de búsqueda de memoria: refactoriza el estilo de resultado de la herramienta de búsqueda de memoria (#5154)
  • Xiaoyi Dual WebSocket: Refactorizar la conexión a un WebSocket dual y reparar el canal inutilizable (#5274)
  • Agrupación de fechas del calendario: use fechas del calendario para agrupar las fechas de la lista de sesiones (#5257)

🐛 Corregido

Seguridad

  • Clave maestra del llavero: Aislar la clave maestra del llavero por instalación (#5028) Escritorio
  • Caída de la consola de Windows: protección contra caídas de la consola de Windows y comandos de autoeliminación (#5192)
  • Tauri Windows CI: Reforzar Tauri Windows CI contra fallas de recuperación de crates.io (#5125)
  • Dependencia del complemento: reparar la dependencia del complemento instalado en el sidecar Tauri (#5260)
  • Nombre de archivo de sesión: Resolver la duplicación de nombres de archivo de sesión y errores de llamadas entre agentes del escritorio (#5036) Consola
  • Redireccionamiento de sesión: Se corrigió el redireccionamiento de sesión al cambiar el modo de código (#5147)
  • Contraer panel renderizado: fuerza el renderizado Contraer paneles para evitar la pérdida de configuración de memoria (#5144)
  • Desbordamiento del comando de aprobación: ajuste el texto del comando de aprobación con un salto de palabra para evitar el desbordamiento horizontal (#5176)
  • Carga de tarjeta de herramientas: control giratorio de carga de tarjetas de herramientas para comandos de shell y herramientas no registradas (#5141)
  • Autocompletar del navegador: deshabilita la función de autocompletar del navegador en la entrada de búsqueda del proveedor (#5112)
  • Dream Cron: Mantenga el dream_cron vacío para desactivar el trabajo de sus sueños (#5256) Proveedores y configuración
  • Proveedores locales en la pestaña PRO: muestra proveedores locales (ollama/lmstudio) en la pestaña PRO de ModelSelector (#5113)
  • Caché de copia profunda: garantiza una copia profunda de las configuraciones del agente en caché (#5229) Contexto y agente
  • Empty Msg Guard: Protege la lista de mensajes vacíos en LightContextManager.pre_reply (#5038)
  • Mission Crash: Evitar el bloqueo del agente en loop_config.json / prd.json (#5000) Modelos locales
  • Versión Llama.cpp: Analizar la versión del servidor llama.cpp sin segmento de ancho fijo (#5035) MCP
  • OAuth IndexError: Evite IndexError en servidores de autorización vacíos en el descubrimiento de OAuth (#5194) Memoria
  • Chromadb Async Probe: agregue una sonda de tiempo de ejecución asíncrona para enlaces chromadb Rust (#5271) Géminis
  • Desinfectar esquemas de herramientas: desinfectar esquemas de herramientas para evitar 400 INVALID_ARGUMENT en la llamada a funciones (#5226) Herramientas
  • Decodificación sin formato: use raw_decode para silenciar advertencias falsas de "datos adicionales" en llamadas a herramientas sin parámetros (#5220)
  • Generación de títulos: use el formateador para generar títulos y optimizar habilidades para admitir todos los proveedores de modelos (#5228) Instalar
  • Predeterminado de PyPI estable: predeterminado para versiones estables de PyPI únicamente (#5269) Paquete
  • OpenSSL Pin: Ancle openssl<3.5.7 para solucionar el error de inicio del escritorio (#5100)

⚡ Rendimiento

  • Eliminar copia innecesaria: eliminar operaciones de copia profunda innecesarias en la configuración del agente (#5240)

🏗️ Infraestructura

  • Lista de verificación de tareas de liberación: Lista de verificación de tareas de liberación de tareas (#5105)
  • Truncar título de tarjeta de herramienta: truncar títulos de tarjeta de herramienta en una sola línea con puntos suspensivos (#5119)
  • Menú del agente Datapaw: actualiza el menú del agente Datapaw al cambiar de agente (#5114)

🧪 Pruebas

  • Pruebas de Sprint 2.4: agregue la ejecución cron de Sprint 2.4 y la herramienta de pruebas API (#5201)

📖 Documentos

  • README vietnamita: Agregar archivo README vietnamita (README_vi.md) (#5245)
  • Actualización de la hoja de ruta: actualizar la hoja de ruta (#5277)
