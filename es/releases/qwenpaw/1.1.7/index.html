QwenPaw v1.1.7

✨ Agregado

Herramientas y MCP

  • Uso del navegador: acciones por lotes: ejecute varios pasos del navegador (navegar, click, escribir, captura de pantalla, etc.) en una sola llamada de herramienta (#4139)
  • Uso del navegador — Descarga de archivos: descargue archivos cli seleccionando elementos de la página o obteniendo URL directamente (#4261)
  • Imágenes de referencia de GPT Image 2: admite la carga de 1 a 16 imágenes de referencia a través de URL o ruta local en el complemento GPT Image 2 (#4194)
  • Ejecución asíncrona del agente externo: delegate_external_agent admite transmisión asíncrona con listado de tareas y consultas de estado y tiempo de espera configurable (#4197)
  • Configuración ejecutable de Shell: elija qué shell ejecuta comandos a través de la opción de configuración (#4215)
  • OAuth 2.1 para servidores MCP remotos: autenticar servidores MCP remotos a través de OAuth 2.1 con PKCE (#4256) Complementos
  • Administración de complementos de consola: instale y desinstale complementos desde la interfaz de usuario de configuración mediante la ruta local, carga ZIP o URL (#4214, #4266)
  • Complementos Qwen-Image & Wan 2.7: Nuevos complementos para generación/edición de imágenes y generación de videos (#4248)
  • Enrutador HTTP API del complemento: los complementos pueden registrar puntos finales HTTP API personalizados (#4255) Chat y consola
  • Varios archivos adjuntos: la entrada de chat ahora admite la selección de varios archivos en un solo mensaje (#4206)
  • Idioma indonesio: compatibilidad total con la configuración regional de Bahasa Indonesia para la interfaz de usuario de la consola y el backend (#4219)
  • Bandeja de entrada: Nueva bandeja de entrada centralizada con pestañas de Aprobaciones y Mensajes push para administrar las aprobaciones de protección de herramientas y ver los resultados de la ejecución cron con seguimientos (#4210, #4305)
  • Mejora de trabajos cron: los trabajos cron ahora admiten la ejecución programada única, una vista de calendario para visualizar las próximas ejecuciones, plantillas integradas para una creación rápida, historial de ejecución por trabajo con seguimientos de ejecución detallados y entrega de guardado en la bandeja de entrada (#4210) Canales
  • Burbujas de voz de Feishu: los archivos de audio enviados a través de Feishu ahora se muestran como burbujas de voz nativas (#4202)
  • Mensajes citados de DingTalk: las respuestas con mensajes citados en DingTalk ahora incluyen texto y medios citados en el contexto del agente (#4209)
  • Creación de bot de código QR Feishu: cree un bot Feishu/Lark escaneando un código QR en la interfaz de usuario de configuración de canales (#4236)
  • Salida de transmisión de WeCom: respuestas de transmisión opcionales para el canal WeCom con entrega de mensajes en tiempo real y compatibilidad con indicadores de razonamiento (#4271)

🔄 Cambiado

  • Rediseño del selector de modelo: se reemplazó el menú desplegable al pasar el mouse por una lista plana con capacidad de búsqueda agrupada por proveedor (#3876)
  • Botón de chat flotante: la navegación del chat se movió del menú de la barra lateral a un botón adhesivo al lado del selector de agentes (#4240, #4273)
  • Descubrimiento de sesión de estadísticas del agente: búsqueda de archivos de sesión simplificada recorriendo los subdirectorios del canal directamente (#4250)

⚡ Rendimiento

  • Dependencias Async FastAPI: dependencias del administrador de proveedores y modelos convertidas a asíncronas, eliminando el envío innecesario de grupos de subprocesos (#4229)
  • Límite de tamaño de lectura de archivos: tamaño máximo de lectura de archivos reducido a 200 MB (de 1 GB) con asignación previa basada en el tamaño real del archivo (#4272, #4276)
  • Tiempo de espera del llavero: las operaciones del llavero ahora tienen un tiempo de espera de 10 segundos para evitar que el administrador de credenciales bloquee el inicio (#4263)

🐛 Fijo

Proveedores y modelos

  • ID de modelo Volcengine: ID de modelo corregidos para que coincidan con los puntos finales API reales y los indicadores de capacidad actualizados (#4169)
  • Preservación de metadatos del proveedor: los metadatos del proveedor ya no se eliminan al recuperar la información del proveedor (#4200)
  • Filtrado de uso de herramientas con formato incorrecto: el analizador de transmisión ahora filtra bloques de uso de herramientas con ID nulos o nombres vacíos (#4234) Canales
  • Operador de tarjeta de aprobación de WeCom: las tarjetas de aprobación resueltas ahora muestran el nombre del operador (#4233)
  • Feishu WebSocket Keepalive: Detectar y recuperarse de una pérdida silenciosa de conexión WebSocket (#4241) Consola y interfaz de usuario
  • Enrutamiento del historial de sesiones: Se corrigió que el historial de sesiones desapareciera y los mensajes se enrutaran a sesiones incorrectas (#4203)
  • Modo oscuro del Panel del plan: contraste de texto mejorado en el modo oscuro del Panel del plan (#4190)
  • Barra lateral móvil: la barra lateral se contrae automáticamente en pantallas estrechas (#4225)
  • Nuevas líneas de mensajes de usuario: los mensajes de usuario ahora conservan saltos de línea (#4231)
  • Etiquetas de fecha de uso de token: las etiquetas de los gráficos ahora muestran el prefijo de año cuando el rango de fechas cruza el límite de un año (#4268)
  • Enlaces externos de escritorio: los enlaces ahora se abren correctamente en las versiones de escritorio (#4270)
