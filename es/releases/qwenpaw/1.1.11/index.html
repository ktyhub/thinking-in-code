QwenPaw v1.1.11

¿Qué ha cambiado?

✨ Agregado

Proveedores

  • Modelo gratuito OAuth: modelos gratuitos de configuración cero con autenticación OAuth one-click (#5049)
  • Proveedor Xiaomi MiMo: agregue el plan Xiaomi MiMo Token como proveedor integrado (#4722)
  • Enrutamiento de cuerpo adicional: enruta generar_kwargs no estándar a extra_body (#4689) Consola
  • Mercado de complementos: Agregar pestaña Mercado de complementos con integración de plataforma AgentScope (#5023)
  • Infraestructura de extensión de complemento: Infraestructura de extensión de complemento para consola (#4997)
  • Sistema de complementos de tarjetas de herramientas: Sistema de complementos de tarjetas de herramientas (#5046)
  • Sugerencias de comandos de barra diagonal: agregue habilidades del agente actual para reducir las sugerencias de comandos con optimizaciones de la interfaz de usuario (#4810)
  • Navegación de URL externa: admite el campo href en MenuItem para navegación de URL externa (#5071) MCP
  • Lista blanca de herramientas: agregue una lista blanca de herramientas MCP por servidor con interfaz de usuario de alternancia en la interfaz (#5002) Complementos
  • Registro de sección de avisos: permite que los complementos inyecten bloques de avisos del sistema en puntos de anclaje definidos (#4804)
  • Desinstalar ganchos: agregar ganchos de desinstalación, corregir importaciones de validadores, exponer el proveedor de habilidades API (#4794)
  • Importación de agentes de CloudPaw: admite la importación de agentes desde AgentHub y mejora las capacidades A2A (#5033) Habilidades
  • Creación de habilidades autoevolutivas: flujo de creación de habilidades mejorado para respaldar la creación de habilidades autoevolutivas (#4857)
  • Descarga por lotes de etiquetas de habilidades: Agregar descarga por lotes de etiquetas de habilidades (#4969)
  • Grupo de habilidades de rutas múltiples: agregue soporte de rutas múltiples para el grupo de habilidades (#4891) Canales
  • Telegram Tool Guard: aprobación de herramientas interactiva a través del teclado en línea (#4737)
  • Feishu Group Sharing: agrega el modo de compartir sesión grupal (#4821)
  • Tarjetas interactivas Feishu: admite extracción de contenido de tarjetas interactivas y análisis de mensajes de refactorización (#4879)
  • Autenticación de código QR QQ: agregue autorización de código QR para el canal QQ (#4848)
  • DingTalk Inline Media: habilite la vista previa de imágenes en línea y la tarjeta de reproducción de video a través de webhook (#5073)
  • Indicador de escritura Yuanbao: Agregar indicador de escritura mediante latido del corazón API (#5020)
  • Nombre de usuario de control de acceso: agregue el nombre de usuario del remitente al control de acceso con una estructura de información de usuario unificada (#4897) Navegador
  • Coordenada de página Click: agregue compatibilidad con la coordenada de página click a browser_control (#4905) ACP
  • Mejoras de ACP: comandos de publicidad, errores superficiales, parámetros de herramientas, metadatos de agente/modelo, enlaces de archivos (#4949) Corredor
  • Marca de tiempo de consulta de transmisión: anule stream_query para establecer la marca de tiempo actual en las respuestas (#4892)

🔄 Cambiado

  • Cron Push Bubbles: deshabilita las burbujas push para trabajos cron de tipo 'agente' (#4803)
  • Manejo de medios de la consola: simplifica el manejo de mensajes multimedia en el canal de la consola (#5077)
  • Revertir panel de sesión: Revertir "incrustar la lista de sesiones del historial como panel del lado derecho" (#5076)

🐛 Fijo

Proveedores y configuración

  • Reserva de ProviderManager: agregue la reserva de ProviderManager a get_model_max_input_length (#4827)
  • Solución de compactación: resolver /compact ignorando max_input_length del modelo cuando active_model no está configurado (#5021) Modo de codificación
  • Navegación de unidades de Windows: admite la exploración de todas las unidades en Windows (#4906)
  • Cambio de sesión y encabezado: corrige la falla del cambio de sesión del modo de codificación y el desbordamiento del encabezado (#5011) Consola
  • Spinner de lista de sesiones: la lista de sesiones de reparación seguía girando (#4929)
  • Parpadeo de la barra de desplazamiento: elimina la transformación al pasar el cursor para evitar el parpadeo de la barra de desplazamiento (#4766)
  • Icono y tabla de escudo: centrar el icono de escudo y ajustar el ancho de las columnas de la tabla de reglas (#4765)
  • Icono de alternancia de tema: cambia el ícono de alternancia de tema del sistema de computadora a sol (#5050) Escritorio
  • Enlaces externos de Tauri: Reparar enlaces externos de escritorio de Tauri (#4683) Agente y Memoria
  • Corrutina de transmisión: espera de rutina no esperada en _broadcast_to_subscribers (#5048)
  • Omitir memoria automática: omitir memoria automática de automatización (#4348)
  • Espacio de trabajo de Dream: Dream debe usar el espacio de trabajo de cron runner, no el directorio de instancia obsoleto (#4936)
  • Procesamiento de bloques de medios: maneja objetos de origen que no son dict en el procesamiento de bloques de medios (#4933) MCP
  • Expresión regular del nombre de la herramienta: nombres de herramientas de reescritura de alias rechazados por la expresión regular de estilo OpenAI (#4958)
  • Acumulación de subprocesos: evita la acumulación de subprocesos entre reinicios (#5014) Canales
  • Fusión de mensajes de DingTalk: evita la fusión de mensajes entre usuarios cuando el sufijo de id_conversación colisiona (#4932)
  • Conflicto de puerto OneBot: degradación gradual en conflicto de puerto durante la recarga (#5010)
  • ACL Sender ID: conservar acl_sender_id durante la combinación de carga útil nativa en todos los canales (#4925) Navegador
  • Perfil y tiempo de espera de CDP: agregue el parámetro de tiempo de espera de CDP y el aislamiento del perfil del navegador para cambiar entre navegadores (#4944) Archivo y sesión
  • Escrituras de archivos asíncronas: use aiofiles para escrituras de archivos sin bloqueo (#4954)
  • Escritura de estado atómico: escribe el estado de la sesión de forma atómica (#4706)
  • Tamaño de carga y tiempo de espera: límite de tamaño de carga + resistencia al tiempo de espera del cargador de complementos (#4940)
  • Tamaño de descarga zip: aumenta el tamaño del archivo de descarga zip (#4941) Seguridad
  • Restricción de vista previa de archivos: restringe la vista previa de archivos a WORKING_DIR y bloquea archivos confidenciales (#4981) Paquetes
  • Yuanbao Proto JSON: Incluir archivos yuanbao proto JSON en package-data (#4899)

⚡ Rendimiento

  • Inicio de backend: desbloquea el bucle de eventos y paraleliza el inicio (#5074)
  • Cobertura de CI: cambiar la recopilación de cobertura de py3.10 a py3.13 (#4952)

🏗️ Infraestructura

  • E2E CI Pipeline: proceso de CI de integración E2E completo: inicio de backend, cobertura, correcciones de prueba (#5054)
  • Limpieza de CI: Elimina el flujo de trabajo de pruebas de canal redundante (#5056)
  • Dependencias: actualice la dependencia de reme-ai a la versión 0.3.1.10 (#4935)
  • Componente de chat: actualice @agentscope-ai/chat a 1.1.68 (#5072)

🧪 Pruebas

  • Pruebas unitarias de frontend: hito completo de las pruebas unitarias de frontend: constantes, contextos, diseños, tipos de api, componentes (#4332)
  • Pruebas de ejecutor y enrutador: Agregar pruebas de unidad + contrato para ejecutor y enrutadores (#4852)
  • Pruebas P0 con alcance del agente: Cobertura de contrato P0 con alcance del agente (+55 casos) (#4945)
  • Pruebas de página de agente: Página de agente + pruebas unitarias de módulos API + trinquete de cobertura (#5012)
  • Pruebas de proveedores y utilidades: agregue pruebas unitarias para modelos_locales, proveedores, túneles y utilidades (#4973)
  • Pruebas de capa de canal: Capa de canal + pruebas de integración de gestión multiagente (#5058)
  • Uso de token E2E: Se corrigió la detección de estado vacío en la prueba de uso de token en un entorno limpio (#5068)

📖 Documentos

  • Actualización de la hoja de ruta: actualiza la hoja de ruta (#4942)
  • Documentos del complemento de interfaz: consolide los documentos del complemento de interfaz en las páginas del sitio web (#5066)
