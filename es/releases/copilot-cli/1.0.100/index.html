copiloto-cli v1.0.100

2026-10-19

  • Agregue el indicador --disable-client-telemetry para desactivar las cargas de telemetría client desde CLI
  • Agregue la carpeta --trust para sesiones únicas en modo de aviso iniciadas con -p o stdin canalizado
  • Instale habilidades y complementos verificados desde los enlaces de instalación de GitHub mediante la instalación del complemento copiloto "ghapp://air/install?..."
  • Abrir / compartir sin argumentos para ver un menú de acciones en pantalla completa para compartir la sesión actual
  • El tráfico de reglas de host de Sandbox ahora respeta HTTPS_PROXY y HTTP_PROXY cuando no se configura ningún proxy de Sandbox.
  • El dictado por voz ya no inserta marcadores de idioma como <en-US> en el texto de la transcripción.
  • Los complementos administrados actualizan la activación en sesiones existentes cuando cambia la política administrada
  • Las sesiones ya no se detienen durante minutos cuando un servidor MCP se bloquea mientras se cargan herramientas.
  • Las llamadas a la herramienta Gemini ya no fallan cuando los parámetros de la matriz definen valores de enumeración.
  • Los chats de Gemini ya no fallan después de que los resultados de herramientas anteriores no contienen contenido legible.
  • Los comandos de shell en zona de pruebas ahora explican las fallas del certificado de proxy de credencial trust y pueden ofrecer una repetición aprobada fuera de la zona de pruebas.
  • Mantenga los comentarios de revisión /diff guardados al volver a abrir una diferencia sin cambios en la misma sesión, con una acción de descarte explícita.
  • Las acciones de habilitar, deshabilitar, actualizar y desinstalar complementos ahora se enrutan de manera confiable después de que se actualiza el inventario de complementos.
  • Las respuestas de token máximo de solo razonamiento ya no se repiten indefinidamente y ahora terminan con un error claro cuando no se logra ningún progreso.
  • Muestre una advertencia clara y mantenga sincronizada la visualización del modelo activo cuando un modelo guardado se reemplace automáticamente en la reanudación.
  • Los comandos aislados en Linux se inician de manera más confiable sin fallas intermitentes en la configuración del loopback
  • Los detalles del recurso de regreso de MCP permanecen en la lista durante las actualizaciones de metadatos en vivo
  • Los chats nativos pueden comenzar y finalizar mientras las descargas de complementos administrados opcionales continúan en segundo plano.
  • Doble Ctrl+C sale inmediatamente incluso cuando la interfaz de usuario del CLI está ocupada
  • La búsqueda en el catálogo informa los requisitos de autenticación de proxy para los desafíos de proxy CONNECT
  • HydraFusion mantiene un pase expandido mientras se ejecuta la revisión, los pases que no se mantuvieron permanecen expandibles hasta que cambie de sesión o los reanude, y los pases de un turno abortado indican si se mantuvieron
  • Las advertencias sobre la política de cuenta administrada y el modo de omisión se mantienen precisas después de cambiar de cuenta, incluso cuando ocurre una falla en el caché de la política.
  • Evite el agotamiento del contexto falso y el rechazo de la sustitución cuando se difieren las definiciones de herramientas
  • Los agentes personalizados que declaran los alias de herramientas documentados search, web o todo, o el nombre github-mcp-server/web_search, ahora reciben las herramientas coincidentes.
  • Los indicadores de ayuda y versión de CLI salen de manera confiable después de imprimir su salida.
  • Los permisos de solicitud administrados por la empresa en modo asistido ahora permiten acciones seguras sin mensajes de confirmación innecesarios.
  • Mantenga fijada su cuenta Microsoft Entra seleccionada durante el inicio de sesión y la renovación del token
  • Las acciones del encabezado de la barra lateral desde las sesiones pasan a la última sesión visible
  • Las insignias de modo de plan, piloto automático y shell permanecen visibles mientras se cargan los componentes de inicio y el agente funciona. La insignia reemplaza el sufijo de modo que solía seguir el texto de la actividad (Working - plan) y la fila de inicio Loading: ahora trunca sus diagnósticos para mantener la fila de estado en una sola línea.
  • Los comandos de espacio aislado pueden escribir paquetes y crear cachés cuando el acceso a las herramientas de desarrollador está habilitado.
  • Los comandos Git de Windows CLI ahora se recuperan de fallas de inicio de acceso denegado a subprocesos.
  • Una regla de habilidad allowed-tools mantiene comas dentro de sus argumentos en lugar de dividirse. Cuando la estructura de una lista es ambigua, sus reglas sin alcance ahora solicitan en lugar de otorgarse.
  • El panel de recursos de MCP permanece interactivo mientras se actualizan los adaptadores de inventario
  • Reintentar solicitudes de respuestas con imágenes con límites de carga útil más pequeños cuando los proveedores rechazan cuerpos de gran tamaño
  • Los informes de uso completos ya no muestran estados parciales o gastos fantasmas no atribuidos después de reanudarlos cuando se completan los datos de facturación.
  • Los permisos asistidos envían comandos anidados de PowerShell y bash -c que solo expanden las variables de entorno de datos simples, PowerShell entre comillas simples y variables y alias de PowerShell al juez de permisos en lugar de requerir una aprobación manual innecesaria.
  • Los archivos de instrucciones de ruta específica en la raíz del repositorio .github/instrucciones ahora se aplican automáticamente cuando el agente lee o edita un archivo coincidente.
  • Inicie git, comandos de shell y servidores MCP en Windows cuando falla la enumeración de subprocesos de instantáneas del proceso
  • Utilice el navegador de sesiones unificado de forma predeterminada para /sessions, /session y /resume.
  • La exploración de sesiones ahora limita el descubrimiento de cuentas a 500 registros y respeta las sugerencias de reintento posterior para el tiempo de actualización automática.
  • Solicitud de actualización de la autoridad de certificación del proxy de la zona de pruebas cuando cambian los hosts enmascarados
  • Muestra un aviso claro cuando la configuración administrada por el administrador anula el modelo seleccionado
  • Habilite la búsqueda de código semántico de forma predeterminada para sesiones en línea.
  • Mejore /login para Microsoft Entra al permitirle elegir una cuenta en caché o iniciar sesión explícitamente con una cuenta diferente.
  • Git en espacio aislado en github.com puede usar su GITHUB_TOKEN configurado desde credenciales.envVars
  • /sandbox puede mantener el sandboxing habilitado para la sesión actual sin habilitarlo globalmente
  • Los complementos del repositorio Trusted se instalan y actualizan automáticamente antes de que se ejecute el chat.
  • Cambie el nombre del complemento del navegador integrado a uso del navegador y mantenga funcionando las preferencias del complemento del navegador existente después de la actualización.
  • Sandbox permite el acceso a la red local de forma predeterminada para que los comandos puedan llegar a los servicios de red privada y localhost.
