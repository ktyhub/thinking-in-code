#qdrant v1.19.0

Características :point_up:

  • https://github.com/qdrant/qdrant/milestone/50 - TurboQuant de 4 bits como tipo de datos de almacenamiento vectorial primario. Almacene únicamente vectores cuantificados de 4 bits y espacio libre en disco en los vectores originales. [docs]
  • https://github.com/qdrant/qdrant/pull/9669, https://github.com/qdrant/qdrant/pull/9684, https://github.com/qdrant/qdrant/pull/9950: definición unificada de estrategia de uso de memoria para componentes de colección. Utilice "memory": "cold" / "cached" / "pinned" para definir el comportamiento de la memoria para cada componente de colección individual. Permite un control más detallado sobre el uso y el rendimiento de la memoria. [docs]
  • https://github.com/qdrant/qdrant/pull/9683: permite que "match": {"prefix": "..."} en filter coincida con palabras clave por prefijo; debe habilitarse en el índice de palabras clave. [docs]
  • https://github.com/qdrant/qdrant/pull/9661: corpus IDF por consulta para búsqueda de vectores dispersos [docs]
  • https://github.com/qdrant/qdrant/pull/9899 - Condición de filtrado de sectores: desplazamiento en sectores/muestreo determinista [docs]
  • https://github.com/qdrant/qdrant/pull/10035 - Cuota global API [docs]
  • https://github.com/qdrant/qdrant/pull/9338: agregue token de enrutamiento para rutas de lectura deterministas [docs]
