qdrant v1.18.0

Cambiar registro

Funciones 🏎️

  • hito!48 - Agregue la variante de cuantificación TurboQuant, compresión vectorial 8x sin el impuesto de recuperación
  • https://github.com/qdrant/qdrant/pull/8605 - Agregue API para crear y eliminar vectores con nombre en la colección existente
  • https://github.com/qdrant/qdrant/pull/8606: informes de memoria profunda, muestra el desglose del uso de memoria para los componentes de almacenamiento
  • https://github.com/qdrant/qdrant/pull/8714: agregue el modo de memoria baja, fuerce la apertura de todo en el disco para minimizar la falla de memoria al iniciar
  • https://github.com/qdrant/qdrant/pull/8715: agrega un parámetro de modo estricto para rechazar actualizaciones cuando el uso de memoria es alto (max_resident_memory_percent)

Mejoras 📏

  • https://github.com/qdrant/qdrant/pull/8790, https://github.com/qdrant/qdrant/pull/8769: utiliza un grupo de CPU dinámico para los trabajadores de búsqueda y mejora el rendimiento de la búsqueda cuando hay una gran espera de E/S
  • https://github.com/qdrant/qdrant/pull/8526, https://github.com/qdrant/qdrant/pull/8656: utilice lotes basados en el tamaño de la operación en transferencias de fragmentos para lograr un mayor rendimiento
  • https://github.com/qdrant/qdrant/pull/8673: reduce el uso de memoria del índice geográfico inmutable en 7 veces
  • https://github.com/qdrant/qdrant/pull/8529: Elimina completamente el soporte de RocksDB, simplificando el manejo del almacenamiento.
  • https://github.com/qdrant/qdrant/pull/8768 - No detener la cola de actualización cuando se esperan puntos diferidos
  • https://github.com/qdrant/qdrant/pull/8944: utilice el tiempo de espera predeterminado de 60 segundos para actualizar solicitudes y limpiar solicitudes de actualización de larga duración.
  • https://github.com/qdrant/qdrant/pull/8767: cuando la actualización de la colección activa la recreación del optimizador, borre cualquier error del optimizador para permitir la recuperación sin reiniciar
  • https://github.com/qdrant/qdrant/pull/8784: use transferencias de fragmentos basadas en instantáneas para una recuperación mucho más rápida si no se puede resolver el delta de WAL
  • https://github.com/qdrant/qdrant/pull/8782: en la transferencia de instantáneas, primero borre los datos del fragmento en el receptor para evitar que el disco se bloquee.
  • https://github.com/qdrant/qdrant/pull/8689: limpie los directorios temporales antes de cargar colecciones, puede evitar que el disco se bloquee durante la recuperación.
  • https://github.com/qdrant/qdrant/pull/8830: no mantenga presionado el bloqueo del soporte de fragmentos durante la búsqueda para evitar bloquear otras operaciones
  • https://github.com/qdrant/qdrant/pull/8626, https://github.com/qdrant/qdrant/pull/8635: registra la ruta del método API en los eventos del registro de auditoría
  • https://github.com/qdrant/qdrant/pull/8402 - ID de seguimiento de informes en eventos de registro de auditoría
  • https://github.com/qdrant/qdrant/pull/8636 - Configuración del registro de auditoría de informes y tamaño de los datos en telemetría y métricas
  • https://github.com/qdrant/qdrant/pull/8640 - Optimiza la normalización del coseno en CPU ARM (SIMD)
  • https://github.com/qdrant/qdrant/pull/8571: omitir el registro de auditoría en puntos finales de telemetría
  • https://github.com/qdrant/qdrant/pull/8693 - Hacer que la construcción del subgráfico HNSW sea determinista
  • https://github.com/qdrant/qdrant/pull/8712, https://github.com/qdrant/qdrant/pull/8708, https://github.com/qdrant/qdrant/pull/8706: informa varias estructuras en orden determinista
  • https://github.com/qdrant/qdrant/pull/8932 - Enlace a habilidades de agente en el mensaje de inicio

Corrección de errores 🪺

  • https://github.com/qdrant/qdrant/pull/8728 - Se corrigió que las palabras vacías siempre estuvieran en minúsculas sobre gRPC incluso si estaban deshabilitadas.
  • https://github.com/qdrant/qdrant/pull/8719 - Se corrigió el análisis de fecha y hora para el formato YYYY-MM-DDTHH:MM
  • https://github.com/qdrant/qdrant/pull/8734 - Se corrige la condición IsEmpty en un índice nulo recién reconstruido
  • https://github.com/qdrant/qdrant/pull/8939 - Se corrige MatchTextAny anidado que no usa el índice de texto completo
  • https://github.com/qdrant/qdrant/pull/8646 - Se corrigieron las comprobaciones de límite de hash del círculo geográfico
  • https://github.com/qdrant/qdrant/pull/8938 - Se corrigió la coincidencia de frases que cruzaban los límites de los elementos de la matriz de cadenas
  • https://github.com/qdrant/qdrant/pull/8762: corrige el pánico cuando hay múltiples errores de validación
  • https://github.com/qdrant/qdrant/pull/8194 - No permitir vectores dispersos con un nombre vacío
  • https://github.com/qdrant/qdrant/pull/8832 - Se corrigió que la GPU no se usara para HNSW sin el gráfico principal
  • https://github.com/qdrant/qdrant/pull/8691 - Se corrigió el bucle infinito en la construcción del subgráfico HNSW
  • https://github.com/qdrant/qdrant/pull/8577: soluciona el pánico cuando la ruta de la instantánea contiene caracteres que no son UTF-8
  • https://github.com/qdrant/qdrant/pull/8293: corrige el pánico grave en el archivo de alias de colección corrupto; en su lugar, devuelve un error
  • https://github.com/qdrant/qdrant/pull/8574 - Se corrigió que la E/S del disco no siempre se midiera en el índice del mapa.
  • https://github.com/qdrant/qdrant/pull/8645: corrige la reserva de capacidad de fragmentos para asignarla de manera más eficiente
  • https://github.com/qdrant/qdrant/pull/8651: corrige los descargadores de índice de carga útil que absorben cancelaciones como errores
  • https://github.com/qdrant/qdrant/pull/8474 - Repara archivos de instantáneas que no se limpiaron al fallar la restauración de instantáneas
  • https://github.com/qdrant/qdrant/pull/8654 - Se corrigió que borrar el caché de la página no fuera confiable, agregar candidatos faltantes
  • https://github.com/qdrant/qdrant/pull/8542 - Se corrigió el índice del mapa que enumera el archivo modificado como inmutable
  • https://github.com/qdrant/qdrant/pull/8847: se corrigió la carrera de datos que causaba que el observador del disco no se activara y provocaba tiempos de espera
  • https://github.com/qdrant/qdrant/pull/8789, https://github.com/qdrant/qdrant/pull/8917: hace que las operaciones de fragmentación sean idempotentes y corrige la corrupción del estado del clúster en caso de falla.
  • https://github.com/qdrant/qdrant/pull/8831: corrige el registro de solicitudes lento para operaciones de lectura con errores de nivel de fragmento
  • https://github.com/qdrant/qdrant/pull/8756: no asigne trabajadores de búsqueda asíncronos, no utilizamos, lo que reduce el número de subprocesos.
  • https://github.com/qdrant/qdrant/pull/8596: no escriba en fragmentos antiguos al volver a fragmentarlos después de escribir la confirmación de hashring; corrija los errores de fragmentos faltantes
  • https://github.com/qdrant/qdrant/pull/8543 - Se corrige el pánico de búsqueda de vectores dispersos en los bordes en el posprocesamiento de partituras
  • https://github.com/qdrant/qdrant/pull/8588 - Corrige varios errores de corrección del consenso de Raft en sentido ascendente

##Seguridad 🕵️

  • https://github.com/qdrant/qdrant/pull/8676: aplica la clave API/autenticación JWT en puntos finales internos gRPC
  • https://github.com/qdrant/qdrant/pull/8628: agregue la opción de configuración para deshabilitar la restauración de instantáneas desde la URL
  • https://github.com/qdrant/qdrant/pull/8619 - Mejora las dependencias de TLS para resolver vulnerabilidades de seguridad
