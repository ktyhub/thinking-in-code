shardingsphere 5.2.1

Parche Publicado18 oct 2022 Fuenteapache/shardingsphere original en inglés

Esta página está traducida automáticamente. El texto original en inglés es la referencia.

fragmentación de esfera 5.2.1

Nueva característica

  1. Agregue la base de datos del sistema predeterminada ShardingSphere para admitir la gestión global de metadatos
  2. Admite la verificación de coherencia de datos asincrónica
  3. Se agregó soporte para el centro de gobierno del cónsul.
  4. Se agregó soporte para el centro de gobernanza de Nacos.
  5. Se agregó soporte para la función de vista en el centro de gobierno.

Mejora

  1. El motor de Federación SQL agrega un ejecutor AVANZADO y se adapta a la base de datos openGauss
  2. Admite el inicio de ShardingSphere Proxy después de deshabilitar la división de lectura y escritura de la base de datos de lectura
  3. SQL HINT admite la ruta de fragmentación forzada
  4. Mostrar soportes de lista de procesos que muestran conexiones Proxy (suspensión, activa)
  5. Mensaje de error de configuración de fuente de datos ShardingSphere-JDBC optimizada
  6. ShardingSphere-JDBC admite la versión SpringBoot 3.x
  7. Admite la carga de metadatos de visualización de MySQL, PostgreSQL, openGauss y SQLServer
  8. Actualice Snakeyaml a 1.33 y abra el límite de 3 MB de YAML
  9. Reutilice las conexiones en caché tanto como sea posible cuando realice fragmentación de unidifusión
  10. Soporte para analizar ALTER ROLE en Oracle
  11. Agregar soporte de ALTER RESOURCE COST para Oracle
  12. Admite el análisis de Drop Materialized View en Oracle
  13. Admite el análisis de DROP LIBRARY en Oracle
  14. Admite el análisis de DROP JAVA en Oracle
  15. Admite el análisis de DROP PLUGGABLE DATABASE en Oracle
  16. Admite el análisis de DROP INDEX TYPE en Oracle
  17. Admite el análisis de ALTER PACKAGE en openGauss
  18. Admite el desplazamiento de selección de openGauss, el análisis de declaraciones de recuento y la eliminación de sintaxis inútil en la gramática PostgreSQL
  19. Agregue max_size a la sintaxis de openGauss
  20. Optimice la lógica de análisis de alterar vista/eliminar vista y corrija el error de actualización de alterar vista
  21. Agregue detalles de error del analizador SQL a ParseCancellationException
  22. Agregue soporte para analizar OptOnConflict para postgres
  23. Mejorar la compatibilidad con ALTER TABLE y ALTER VIEW en PostgreSQL
  24. Agregue una palabra clave que falta en PostgreSQL Declaración de declaración
  25. Agregue compatibilidad con la función json al analizador mysql
  26. ShardingSphere-Proxy se adapta automáticamente a los límites de memoria del grupo c en el entorno Docker
  27. Mostrar el estado de la migración DistSQL responde a la nueva columna error_message agregada
  28. Mostrar el estado de la migración y responder a la nueva columnaprocess_records_count agregada
  29. Admite autenticación MySQL 8 caching_sha2_password en volcado incremental
  30. Mejorar la configuración del proceso de canalización de caída
  31. Admite la migración de tablas de claves únicas
  32. Admite migrar tabla a una nueva tabla de nombres
  33. Mejorar el uso del grupo de subprocesos en la tarea y el ejecutor de la canalización.
  34. Admite verificación de coherencia de datos cancelables
  35. DistSQL: al crear o modificar la regla de división de lectura y escritura, verifique los recursos de lectura o escritura duplicados
  36. DistSQL: Agregar verificación de validez para ALTER SHARDING BINDING TABLE RULES
  37. El modo independiente H2 admite metadatos persistentes
  38. Se corrigió la ejecución del cursor openGauss en la transacción xa.
  39. Se agregaron excepciones relacionadas con transacciones

Corrección de errores

  1. Genere un marcador de posición adecuado para PostgreSQL al reescribir
  2. Solucionar la excepción de análisis del conjunto de actualizaciones de opengauss
  3. Se corrige la excepción de análisis al ejecutar una instrucción de inserción con valor negativo
  4. Corrija el connectDescriptorUrlPattern incorrecto en OracleDataSourceMetaData
  5. Se corrigió la inserción de SQL confusa después de reescribir la fragmentación en reglas especiales
  6. Solucionar la excepción al ejecutar select * de information_schema.tables
  7. Solucionar la excepción al ejecutar alterar el cambio de nombre de la vista
  8. Se corrigió PostgreSQL para verificar el permiso de la fuente de datos al usar rolsuper
  9. DistSQL: arregla NPE para REFRESH TABLE METADATA cuando no hay recurso
  10. Corregir los metadatos de la tabla no modificados al modificar las reglas.
  11. Arreglar el descubrimiento de bases de datos
  12. El algoritmo MySQL.NORMAL_REPLICATION no puede encontrar el nodo principal"
  13. Se corrigió el uso de etcd para crear un evento de clúster que no era consciente
  14. Se corrigió la NPE cuando no se crea la administración de transacciones
  15. Se corrigió la excepción de enrutamiento que ocurre cuando el valor de fragmentación del algoritmo InlineShardingAlgorithm excede el número entero.

API Cambios

  1. El formato de sintaxis SQL HINT se ajusta al formato de estilo SQL
  2. DistSQL: Eliminar la sintaxis COUNT DATABASE RULES
  3. El modo ShardingSphere elimina la configuración de sobrescritura
  4. Agente: Optimice la configuración de agent.yaml

Registro de cambios

  1. HITO
