shardingsphere 5.5.1

Parche Publicado22 oct 2024 Fuenteapache/shardingsphere original en inglés

Esta página está traducida automáticamente. El texto original en inglés es la referencia.

fragmentaciónesfera 5.5.1

API Cambios

  1. Autoridad: marcar el proveedor de privilegios ALL_PERMITTED como obsoleto y se eliminará en el futuro.
  2. DistSQL: elimine el uso de parámetros opcionales de las unidades de almacenamiento del programa
  3. División de lectura y escritura: cambie fuentes de datos a grupos de fuentes de datos para YAML

Nuevas funciones

  1. Kernel: agregue un nuevo tipo de base de datos y módulo analizador sql doris, hive y presto

Mejoras

  1. DistSQL: verifique el privilegio al registrar o modificar la unidad de almacenamiento
  2. DistSQL: verifique los nodos de datos reales duplicados al crear o modificar la regla de la tabla de fragmentación
  3. DistSQL: agregue soporte similar para mostrar unidades de almacenamiento
  4. DistSQL: revertir si falla la configuración de la base de datos de importación
  5. DistSQL: agregue el tipo de tabla al conjunto de resultados de mostrar tablas lógicas
  6. Analizador SQL: admite replicación de cambios MySQL sin ID de servidor
  7. Analizador SQL: admite alias de filas y columnas MySQL con ON DUPLICATE KEY UPDATE
  8. Analizador SQL: admite MySQL CALL sql con prefijo mysql
  9. Analizador SQL: admite MySQL para crear devoluciones de funciones cargables int/dec
  10. Analizador SQL: admite el análisis de MySQL CREATE TABLESPACE/TABLE en Mysql-8
  11. Analizador SQL: admite el análisis de MySQL CREATE INDEX con ENGINE_ATTRIBUTE
  12. Analizador SQL: admite el análisis de MySQL LOAD DATA con la variable @
  13. Analizador SQL: admite el análisis de la declaración MySQL START REPLICA
  14. Analizador SQL: admite el análisis de la función de tabla MySQL json
  15. Analizador de SQL: agregue la columna MySQL que no es un análisis de SQL nulo
  16. Analizador SQL: agregue el análisis SQL del juego de caracteres MySQL
  17. Analizador SQL: mejora del resultado de la declaración de visita de la función mysql json
  18. Analizador SQL: admite palabras clave PostgreSQL COLLATION y CONSTRAINT
  19. Analizador SQL: admite PostgreSQL, tabla de funciones openGauss y actualización desde análisis
  20. Analizador SQL: admite CTE con PostgreSQL y openGauss
  21. Analizador SQL: optimice la compatibilidad con la zona horaria de PostgreSQLDateValueParser.
  22. Analizador SQL: admite límite PostgreSQL y compensación como nulo
  23. Analizador SQL: mejore la declaración de actualización de Oracle como análisis de alias y agregue un caso de prueba
  24. Analizador SQL: admite el análisis SQL del tipo de unidad de longitud de columna de Oracle
  25. Metadatos: tipo de tabla recopilada para PostgreSQL
  26. Kernel: admite extracto de sugerencia de sql cuando sql contiene un comentario de sugerencia de dbeaver
  27. Kernel: Agregar extracto, combinar, seleccionar a la izquierda en el método extractFromSelectStatementWithoutProjection
  28. Kernel: agregue un nodo asistido para crear y eliminar bases de datos
  29. Transacción: use el mismo tipo de transacción en una transacción en el adaptador JDBC
  30. Transacción: soporte para cambiar tipos de transacciones
  31. Federación SQL: admite la función bit_count de federación SQL para mysql
  32. Federación SQL: mejorar la función sql atan y anan2 para mysql
  33. Federación SQL: admite la función bin mysql de consulta federada
  34. Federación SQL: soporte para consulta federada NO operador
  35. Proxy: haga que los resultados de las tablas de espectáculos se muestren en orden
  36. Proxy: activa la recopilación de metadatos al crear y eliminar bases de datos y tablas
  37. Proxy: Optimice el Agente para admitir la recopilación de datos de métricas de múltiples fuentes de datos cuando se usa con Driver
  38. Proxy nativo: agregue más metadatos de accesibilidad de graalvm para caché de cafeína
  39. Fragmentación: revise todos los índices locales para la tabla de fragmentación y agregue el nivel de unicidad del objeto spi para controlar el generador de tokens de índice.
  40. Fragmentación: agregue NullsOrderType.LOW y NullsOrderType.HIGH para manejar el orden NULL mediante la función de fragmentación
  41. Fragmentación: agregue algoritmos de fragmentación en línea que coincidan con la verificación de los nodos de datos reales
  42. Cifrar: agregue una verificación no admitida para la declaración combinada con columnas cifradas
  43. Cifrar: admite selección de cifrado distinto (columna), reescritura y refactorización de la lógica de compilación de SubstitutableColumnNameToken
  44. Cifrar: admite la reescritura de declaraciones concat anidadas concat con función de cifrado
  45. Canalización: agregue SHARDING_TOTAL_COUNT impl de JobExecutorServiceHandler para mejorar los requisitos del núcleo de la CPU
  46. Canalización: consulta de página de soporte para volcado de inventario y consulta de transmisión de coherencia de datos
  47. Canalización: utilice identificadores que no distingan entre mayúsculas y minúsculas para mejorar el cargador de metadatos de la tabla
  48. Canalización: admite el orden de columnas de clave principal para el cargador de metadatos de tablas de canalización estándar

Corrección de errores

  1. DistSQL: corrige el error de carga de una sola tabla después de crear una fuente de datos lógica
  2. DistSQL: Se corrigió el error de establecer la unidad de almacenamiento de tabla única predeterminada en aleatoria
  3. DistSQL: Error en la reparación de la unidad de almacenamiento de tabla única predeterminada en la fuente de datos lógica
  4. DistSQL: corrige NPE al importar metadatos
  5. Analizador SQL: admite acción de conflicto sin hacer nada con PostgreSQL
  6. Analizador SQL: corrige el error de análisis de la función Oracle nvl y del intervalo de hora
  7. Metadatos: mantener el nodo de almacenamiento utilizado al cancelar el registro de la unidad de almacenamiento
  8. Metadatos: se solucionó el problema de la unidad de almacenamiento faltante al registrar la unidad de almacenamiento.
  9. Kernel: reemplace ThreadLocal con TransmittableThreadLocal en HintManager para admitir el uso cruzado de subprocesos
  10. Kernel: use ConnectionPropertiesParser spi para analizar jdbcUrl y resolver el error de análisis de URL de Oracle
  11. Kernel: Se corrigió la excepción de afirmación del recuento de columnas causada por el juez de la tabla del sistema postgresql
  12. Carpeta SQL: agregue la interfaz TableAvailable para CloseStatementContext, MoveStatementContext, FetchStatementContext y solucione el caso de prueba de reescritura de SQL
  13. Transacción: Se corrigió que la invocación del método setSavepoint no se limpiara
  14. Transacción: Arreglar el administrador de puntos de guardado que no se limpia en transacciones distribuidas
  15. Transacción: se corrigió el contexto de la transacción que no se limpió cuando se confirma la transacción xa.
  16. Transacción: solucione el problema por el cual el cursor no se reescribe
  17. Federación SQL: corrección de la conversión de LocalDateTime de consulta federada
  18. Federación SQL: se corrige el error de ejecución de SQL al presionar hacia abajo cuando SQL contiene caracteres chinos con la federación SQL
  19. Federación SQL: corrección de consulta de datos de tipo binario de consulta de federación
  20. Federación SQL: corrige el resultado nulo en una consulta federada para una única columna proyectada
  21. Federación SQL: se corrigió la excepción de tipo desconocido de la federación SQL causada por un tipo de resultado incorrecto de calcita con bigint
  22. Proxy: admite valor bool de tipo binario en PostgreSQL
  23. Proxy: admite parámetros preparados de tipo de matriz en PostgreSQL
  24. Proxy: admite valor de protocolo binario para matriz de texto en PostgreSQL
  25. Proxy: corrige resultados duplicados al consultar information_schema.SCHEMATA
  26. Proxy: corrige resultados incorrectos al consultar information_schema.SCHEMATA
  27. Proxy: corrige NPE al ejecutar mostrar estado de tabla
  28. Proxy: corrige que no se produce ninguna excepción seleccionada en la base de datos cuando se muestran tablas desde la base de datos
  29. Proxy: corrige el error que indica que el proceso no sale después de que falla el inicio del proxy
  30. Proxy: corrija el error de que los metadatos persistentes del sistema no se borraron después de que se eliminó la base de datos en el escenario PostgreSQL
  31. Proxy: corrige ninguna excepción de base de datos seleccionada en la consulta SQL
  32. JDBC: resuelva el problema por el cual el "archivo zip se cerraba" en versiones anteriores a SpringBoot 2.3.
  33. JDBC: corrige el NPE cuando no contiene una base de datos lógica especificada en el controlador.
  34. Fragmentación: Arreglar la columna Fragmentación que no se rastrea a través de alias
  35. Fragmentación: se corrige la excepción de alteración de vista al configurar la regla de fragmentación y la regla de tabla vinculante
  36. Fragmentación: la solución es necesaria para acumular lógica
  37. Fragmentación: corrija el error de insensibilidad entre mayúsculas y minúsculas del nombre de la columna de clave generada
  38. Cifrar: corrige el resultado incorrecto de mostrar crear tabla con cifrado cuando el tipo de datos contiene flotante
  39. Cifrar: solucione el problema al actualizar una tabla no cifrada y utilizar una subconsulta en una tabla cifrada.
  40. Cifrar: agregar insertar, seleccionar reescribir para cifrar
  41. Pipeline: InventoryTaskSplitter compatible con la clave principal BigInteger
  42. Canalización: corrige la fuente de datos predeterminada perdida al crear el trabajo de migración
