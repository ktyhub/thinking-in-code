API Cambiar

  1. Rediseñar la sintaxis DistSQL relacionada con el descubrimiento de bases de datos.
  2. En DistSQL, la palabra clave GENERATED_KEY se ajusta a KEY_GENERATE_STRATEGY
  3. El proveedor de autoridad nativa está marcado como obsoleto y se eliminará en una versión futura.
  4. Escalado: mueva la configuración de escalado de server.yaml a config-sharding.yaml
  5. Escalado: cambie el nombre del clusterAutoSwitchAlgorithm SPI al parámetro de método de refactorización y detector de finalización
  6. Escalado: verificación de coherencia de datos, cambio de nombre del método API y cambio de tipo de retorno
  7. Refactorización del módulo de descubrimiento de bases de datos API
  8. La división de lectura y escritura admite configuración estática y dinámica
  9. Shadow DB elimina la configuración de habilitación
  10. Tipo de algoritmo de sombra modificado

Mejora

  1. Mejorar el rendimiento de la carga de varias tablas individuales
  2. Eliminar el orden agregado automáticamente por cláusula de clave principal
  3. Optimice la lógica de ruta de la tabla de enlace sin fragmentar la columna en la condición de unión
  4. Admite la actualización de la clave de fragmentación cuando el resultado del enrutamiento de fragmentación se mantiene igual
  5. Optimice el rendimiento del motor de reescritura
  6. Admite declaraciones de sindicato seleccionado/unión todos... por motor de federación
  7. Admite la inserción en la columna de fragmentación de actualización de clave duplicada cuando el contexto de la ruta se mantiene igual
  8. Utilice union all para fusionar unidades de ruta SQL para una selección simple y mejorar el rendimiento.
  9. Admite la confirmación automática en ShardingSphere-Proxy
  10. ShardingSphere openGauss Proxy admite el método de autenticación sha256
  11. Elimine la propiedad java.net.preferIPv4Stack=true del script de inicio del Proxy
  12. Eliminar la verificación de reglas nulas para JDBC
  13. Optimice el rendimiento de la ejecución del enlace por lotes de openGauss
  14. Deshabilite el detector de fugas de recursos Netty de forma predeterminada
  15. Los soportes describen la declaración preparada en PostgreSQL/openGauss Proxy
  16. Optimice el rendimiento de la ejecución de inserciones por lotes PostgreSQL
  17. Agregue instancia_id al resultado de MOSTRAR LISTA DE INSTANCIAS
  18. Soporte para usar instancia_id para realizar operaciones al habilitar/deshabilitar una instancia de proxy
  19. Admite algoritmo creativo automático cuando CREATE SHARDING TABLE RULE, lo que reduce los pasos para crear reglas
  20. Admite la especificación de un generador de claves existente al CREAR REGLA DE TABLA DE COMPARTIMIENTO
  21. DROP DATABASE admite la opción SI EXISTE
  22. DATANODES en SARDING TABLE RULE admite expresiones en línea enumeradas
  23. CREAR/ALTERAR LA REGLA DE TABLA DE COMPARTIMIENTO admite algoritmos de fragmentación complejos
  24. MOSTRAR NODOS DE TABLA COMPARTIDA admite escenarios no en línea (rango, tiempo, etc.)
  25. Cuando solo hay una fuente de datos de lectura en la regla de división de lectura y escritura, no se permite deshabilitarla.
  26. Escalado: agregue soporte básico para la verificación de coherencia de datos de transmisión fragmentados
  27. Optimización de la lógica de decisión del algoritmo de sombra para mejorar el rendimiento

Refactorizar

  1. Refactorizar la lógica de la tabla de escaneo del motor de federación
  2. Evite el análisis TCL SQL duplicado al ejecutar una declaración preparada en Proxy
  3. Escalado: agregue módulos de canalización para rediseñar el escalado
  4. Escalado: refactorizar varias estructuras de configuración de trabajos
  5. Escalado: precalcule la división de tareas y persista en la configuración del trabajo
  6. Escalado: agregue soporte básico para la reutilización de código central de canalización para trabajos de cifrado
  7. Escalado: agregue soporte básico para la ejecución combinada de trabajos de escalado y trabajos de cifrado.
  8. Escalado: agregue la configuración input y output, incluidos workerThread y rateLimiter
  9. Escalado: Mueva blockQueueSize a streamChannel
  10. Escalado: cambie el tipo de ID de trabajo de entero a texto
  11. Optimice JDBC para cargar solo el esquema especificado
  12. Optimice la estructura de metadatos del centro de registro.
  13. Cambie el nombre del algoritmo de sombra de notas a algoritmo de sombra de PISTA
