ragflow v0.27.1

Parche Publicado28 ago 2026 Fuenteinfiniflow/ragflow original en inglés

Esta página está traducida automáticamente. El texto original en inglés es la referencia.

flujo de trapo v0.27.1

Nuevas funciones

  • Nuevo conector Azure DevOps para orígenes de datos (#18715)
  • Nuevo proveedor de búsqueda web de You.com para chat y agente (#18478)
  • Nuevo proveedor de búsqueda web Serply para chat (#18475)

Soporte de modelo

  • Nuevo proveedor de modelos Synthorai (#18830)
  • Se agregaron modelos de DeepSeek faltantes (#18678)
  • Soporte de autenticación de clave AWS Bedrock API (#18301)

Mejoras

  • La recuperación API expone rerank_candidates_count, knn top_k y num_candidates (#18768, #18737)
  • Filtros de metadatos bajados al índice de metadatos para una recuperación más rápida (#18219)
  • La configuración del chat se desplaza automáticamente a la ubicación del error al guardar (#18811)
  • La página de búsqueda valida las bases de conocimiento eliminadas (#18522)

Corrección de errores

  • Se corrigió el error de análisis de PDF en el chat (#18860)
  • Se corrigió la compilación de wiki que aceptaba respuestas de error de LLM (#18857)
  • Se corrigió la estabilidad de renderizado de MinerU, la visibilidad de errores y el análisis de bloques de código (#18617)
  • Se corrigió que los conjuntos de datos de 0 fragmentos no se mostraran, lo que impedía desplazarse para buscar más conjuntos de datos (#18810)
  • Se corrigió que el analizador de control de calidad de Excel dejara caer filas cuya respuesta es cero (#17902)
  • Se corrigió el analizador ingenuo que trataba una carga vacía como un binario faltante (#18826)
  • Se corrigió la detección de codificación que descartaba los resultados de detección confiables (#15793)
  • Se corrigió el chat habilitado para razonamiento que ignoraba el mensaje del sistema de diálogo (#18842)
  • Se corrigió la compilación de conocimientos utilizando el LLM del inquilino predeterminado en lugar del LLM de canalización (#18572)
  • Se corrigió que el servicio de búsqueda de redes de chat no pudiera ser nulo (#18791)
  • Se corrigió el desplazamiento automático del chat de Firefox que no estaba fijado en la parte inferior (#18736)
  • Se corrigió el desplazamiento automático del chat que no seguía las respuestas transmitidas (#18570)
  • Se corrigió el progreso del análisis no visible después de seleccionar la carga (#18741)
  • Se corrigió que el conector de BigQuery construyera consultas SQL incorrectamente (#17500).
  • Se corrigieron errores de listado de WebDAV que no se propagaban, lo que causaba la pérdida de datos de eliminación (#18694)
  • Se corrigió la colisión de ID de documento entre KB en la sincronización de la fuente de datos (#18244)
  • Se corrigió el descubrimiento del modelo GPUStack y la compatibilidad con audio (#18599)
  • Se corrigió la temperatura de Kimi K3 (#18564)
  • Se corrigió la pérdida de texto OCR cuando no se configura ningún modelo image2text (#18012)
  • Se corrigió la navegación jerárquica de temas de Wiki (#18721)
