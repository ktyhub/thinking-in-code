flujo de trapo v1.0.0-rc2

1.0.0-rc2 es la segunda versión candidata de v1.0.0. Esta versión soluciona varios problemas en rc1 e introduce nuevas funciones y soporte ampliado.

Destacados

  1. Se introdujo el modo Agentic para el chat, reemplazando los niveles de pensamiento Bajo, Medio, Alto y Ultra.
  2. Compatibilidad preservada con los datos v1.0.0-rc1 existentes, lo que permite actualizaciones directas.
  3. Se agregó soporte para compartir Equipo/Yo.
  4. Se agregó soporte para los proveedores de modelos DemonRoute y Opper, las herramientas de búsqueda web Firecrawl y Search1API, y el modelo MinerU 4.
  5. Se agregó soporte de recuperación para checo y eslovaco.
  6. Unificó los 12 analizadores de documentos integrados con los analizadores de Pipeline.
  7. Se agregaron imágenes Docker para la arquitectura arm64.
