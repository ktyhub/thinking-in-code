ragflow v0.25.1

Parche Publicado30 abr 2026 Fuenteinfiniflow/ragflow original en inglés

Esta página está traducida automáticamente. El texto original en inglés es la referencia.

flujo de trapo v0.25.1

Resumen

Mejoras

  • Refactorización y unificación de API: estandariza los API web según convenciones RESTful en todos los puntos finales, unificando la creación de documentos y los flujos de indexación mientras se mantiene la compatibilidad con versiones anteriores.
  • Optimizaciones de análisis: agrega el backend de PDF OpenDataLoader. #14097
  • Introduce carga diferida y análisis fragmentado para archivos PDF grandes (>50 páginas), lo que reduce significativamente el uso de memoria. #14385

Fuente de datos

Permite sincronizar archivos eliminados en Bitbucket, Gmail, Google Drive y Airtable.

Soporte de modelo

  • Búsqueda profunda v4

Proveedores de modelos

  • UCloud

Corrección de errores

  • Problemas de visibilidad de metadatos durante las actualizaciones de v0.24.0 a v0.25.0.
  • Salida de chat duplicada.
