ragflow v1.0.0

Mayor Publicado6 nov 2026 Fuenteinfiniflow/ragflow original en inglés

Esta página está traducida automáticamente. El texto original en inglés es la referencia.

flujo de trapo v1.0.0

Después de tres lanzamientos candidatos, nos complace anunciar el lanzamiento oficial de RAGFlow 1.0, ya listo para producción. Construida a partir de una reescritura completa en Go, esta versión reduce significativamente la sobrecarga de implementación y tiempo de ejecución e introduce una experiencia de Agentic Chat completamente nueva. Alentamos a todos los usuarios a actualizar para mejorar la estabilidad, el rendimiento y la respuesta a preguntas.

Destacados

  • Reescrito en Go para una implementación más ligera: las imágenes Docker son aproximadamente 10 veces más pequeñas y el inicio es aproximadamente 10 veces más rápido.
  • Aproximadamente 100 veces más simultaneidad, con mejoras sustanciales en la latencia de consultas, el uso de memoria y la velocidad de análisis de documentos.
  • Chat Agentic completamente nuevo: permite el razonamiento de varios pasos y respuestas a preguntas complejas mediante recuperación iterativa, llamadas de herramientas y evaluación de suficiencia de evidencia.

Chat y agentes

  • Se agregó el modo Agentic Chat, que reemplaza los niveles de pensamiento anteriores Bajo, Medio, Alto y Ultra.
  • Se introdujo el modelo de decisión de Jev en el ciclo de llamada de herramientas del agente para determinar si la evidencia disponible es suficiente para responder una pregunta.
  • Se agregó soporte para el modelo de decisión Jev en el componente Categorizar agente.
  • Se agregó almacenamiento y visualización de indicaciones, uso de tokens y tiempo de ejecución en el historial de chat.

Ingestión y recuperación de documentos

  • Unificó los 12 analizadores de documentos integrados con los analizadores de canalización.
  • Se agregó soporte para múltiples versiones DSL de canalización de ingesta.

Arquitectura e implementación

  • Se migró la cola de mensajes de Redis a NATS.
  • Se adoptó Kvrocks para almacenamiento en caché y puntos de control.
  • Se agregaron imágenes Docker para la arquitectura arm64.
  • Reimplementado el RAGFlow CLI en Go.

Estabilidad

  • Se corrigieron múltiples errores críticos reportados por la comunidad y problemas identificados durante la fase de lanzamiento candidato, mejorando aún más la estabilidad del tiempo de ejecución.

Puntos de referencia

  • Se logró una precisión del 91 % en el punto de referencia de respuesta a preguntas de múltiples saltos de FRAMES utilizando RAGFlow Agentic Chat con MiniMax M3.

Actualización

  • Desde v1.0.0-rc1, rc2 o rc3: los datos existentes son totalmente compatibles. Puedes actualizar directamente.
  • Desde v0.27.2: Puede actualizar directamente a v1.0.0. La migración de datos se ejecuta automáticamente cuando se inicia el contenedor RAGFlow Docker.
  • Desde versiones anteriores a v0.27.2: siga la guía de migración para completar las actualizaciones intermedias requeridas antes de actualizar a v1.0.0.
  • Haga una copia de seguridad de todos los datos antes de actualizar. La migración de datos de v0.27.2 a v1.0.0 es irreversible. Si la migración falla, restaure la copia de seguridad completa previa a la actualización antes de volver a intentarlo.

Compatibilidad y limitaciones

  • Los alias API obsoletos ya no son compatibles.
  • El Python SDK no se ve afectado.
  • Actualmente, DeepDoc solo admite entornos de CPU.

Referencias relativas

  • Guía de copia de seguridad y actualización: https://ragflow.io/docs/migration_overview
  • Eliminados API: https://ragflow.io/docs/http_api_reference#removed-api-aliases
