ragflow v0.26.4

Parche Publicado7 jul 2026 Fuenteinfiniflow/ragflow original en inglés

Esta página está traducida automáticamente. El texto original en inglés es la referencia.

flujo de trapo v0.26.4

Resumen

Publicado el 7 de julio de 2026.

Nuevas funciones

  • PNL/Tokenización: agrega un lematizador Snowball compatible con 16 idiomas, integra el parámetro del conjunto de datos language en todo el proceso de tokenización y agrega holandés a la interfaz. #14140

Corrección de errores

  • El sistema fallaba con un ValueError al analizar los nombres de los modelos de LM-Studio que contenían un símbolo '@'. #16467
  • El servidor MCP falló porque la función list_chats esperaba una lista del /chats API pero en su lugar recibió un diccionario paginado. #16639
  • El analizador Docling eliminó silenciosamente fórmulas matemáticas de los documentos en lugar de extraerlas. #16645
  • El sistema no pudo conservar las ediciones en línea realizadas en los valores de metadatos en el backend. #16655
  • El sistema eliminó los enlaces existentes al vincular archivos de forma masiva a conjuntos de datos. #16587
  • El filtro no pudo usar chino. #16673
  • El sistema no hizo cumplir que los pesos de las etiquetas deben ser mayores que cero. #16657
  • El diseño del menú desplegable del mensaje del agente se muestra incorrectamente. #16653
  • El fragmentador de leyes clasificó incorrectamente las referencias cruzadas de números con puntos como títulos. #16626
  • El sistema no pudo evitar que los usuarios guardaran nombres de servidores MCP duplicados durante el proceso de edición. #16588
  • El sistema permitía a los usuarios exportar una selección de servidor MCP vacía. #16589
