flujo de trapo v1.0.0-rc1

RAGFlow v1.0.0-rc1 es una versión preliminar de v1.0.0. Esta versión marca una reescritura integral de RAGFlow in Go, que ofrece una reducción sustancial en el consumo de recursos del sistema y reemplaza el modelo de implementación pesado anterior con una arquitectura liviana.

Cambios de arquitectura

  • Cola de mensajes: Migrado de Redis a NATS.
  • Caché y puntos de control: Kvrocks ahora sirve como almacén de respaldo tanto para el caché como para los puntos de control.

Actualización de datos

Al iniciar el contenedor, RAGFlow inicia automáticamente el proceso de actualización de datos, migrando los datos existentes de v0.27.2 a v1.0.0-rc1. Tenga en cuenta que esta actualización es irreversible: una vez completada, los datos no se pueden revertir a v0.27.2.

Prerrequisitos y precauciones de actualización

  1. Haga una copia de seguridad de todos los datos antes de actualizar.
  2. Asegúrese de que su implementación existente ya esté en v0.27.2 antes de continuar.
  3. Si la actualización falla, restaure su sistema desde la copia de seguridad y envíe un informe que detalla la falla.

Compatibilidad

  1. RAGFlow CLI: Reimplementado en Go, reemplazando la versión anterior Python.
  2. Compatibilidad con API: API obsoletos ya no son compatibles con la implementación de Go.
  3. Compatibilidad con SDK: El Python SDK no se ve afectado.

Problemas conocidos

  1. Actualmente, DeepDoc solo admite entornos de CPU.
  2. La zona de pruebas local ya no es compatible.
  3. El modelo de permiso Equipo/Yo aún no es compatible.
