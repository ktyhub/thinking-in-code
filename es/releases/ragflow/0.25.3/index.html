ragflow v0.25.3

Parche Publicado13 may 2026 Fuenteinfiniflow/ragflow original en inglés

Esta página está traducida automáticamente. El texto original en inglés es la referencia.

flujo de trapo v0.25.3

Resumen

Nuevas funciones

  • Fuente de datos y análisis: se agregó control semántico/metadatos a nivel de columna para el analizador de archivos de hoja de cálculo; introdujo la optimización ETag para la sincronización incremental de fuentes de datos S3 para evitar transferencias de archivos innecesarias.
  • Permite asignar roles específicos como contenido, metadatos y clave principal a las columnas de la tabla. #13710

Mejoras

  • Refactorización y seguridad de API
    • Continúa la transición de los API web a convenciones RESTful, lo que garantiza la compatibilidad con versiones anteriores para todos los puntos finales heredados.
    • Vincula el user_id en POST /api/v1/messages al principal JWT autenticado. #14745
    • Protege el ejecutor de la zona de pruebas contra omisiones de ejecución de código dinámico e indirecto. #14690
    • Control de tiempo de espera de solicitud de LLM
    • Grupo de subprocesos de llamadas de bloqueo de alta concurrencia
  • Reduce el tiempo de arranque del servidor de ingesta. #14894

Corrección de errores

  • Las imágenes en libros de Excel de varias hojas no estaban delimitadas por hoja, lo que provocaba que las imágenes se atribuyeran incorrectamente en diferentes hojas de trabajo. #14120
  • Paso de alias de elemento de iteración
  • Análisis de plantilla de parámetros de herramienta
  • Salida del archivo adjunto de ejecución de código
  • Se corrigió la adición del modelo de volcán.
