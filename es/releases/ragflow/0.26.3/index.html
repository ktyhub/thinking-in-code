ragflow v0.26.3

Parche Publicado2 jul 2026 Fuenteinfiniflow/ragflow original en inglés

flujo de trapo v0.26.3

Resumen

Publicado el 2 de julio de 2026.

Nuevas funciones

  • Conector de fuente de datos: presenta Google BigQuery como conector de fuente de datos para la ingesta de documentos y la sincronización incremental. #15871
  • MCP: agrega dos herramientas MCP ragflow_list_datasets y ragflow_list_chats al servidor RAGFlow MCP. #15384
  • Ingestión de archivos
    • Integra el analizador SoMark OCR con reconocimiento de diseño en el sistema para extraer e indexar elementos de documentos complejos como tablas y figuras. #16482
    • API: expone el punto final Ingesta de documentos para procesar documentos mediante una canalización personalizada. #16395

Mejoras

  • Backend: introduce el manejo de éxito parcial para cargas de documentos por lotes, lo que garantiza que un solo archivo fallido ya no haga que se descarte todo el lote. #16438
  • UI/UX: refactoriza el encabezado global para cambiar dinámicamente entre una barra de navegación de escritorio completa y un cajón lateral apto para dispositivos móviles según el espacio disponible en la pantalla, resolviendo problemas superpuestos y mejorando significativamente la experiencia del usuario móvil. #15984

Corrección de errores

  • Después de configurar el proveedor de Ollama, el sistema devolvió el error: 'Error al acceder al modelo (nombre) usando esta clave api'. #16519
  • Al eliminar un par de mensajes de chat de usuario/asistente se eliminó por error la referencia del turno de conversación anterior debido a una desalineación del índice. #16436
