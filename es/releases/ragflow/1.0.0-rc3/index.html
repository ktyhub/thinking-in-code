flujo de trapo v1.0.0-rc3

1.0.0-rc3 es la tercera y última versión candidata antes del lanzamiento oficial de v1.0.0. Soluciona varios problemas encontrados en rc2 e introduce nuevas funciones y mejoras.

Actualizaciones clave:

  1. Se introdujo el modelo de decisión para el juicio de suficiencia de evidencia dentro del ciclo de herramientas agentes y el componente Categorizar para agentes.
  2. Se agregó soporte para múltiples versiones de DSL de canalización de ingesta.
  3. El historial de chat ahora almacena y muestra indicaciones, uso de tokens y tiempo de ejecución.
  4. Compatible con el esquema v1.0.0-rc2 existente, lo que permite una actualización directa.
