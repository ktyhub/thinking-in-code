ragflow v0.26.1

Parche Publicado17 jun 2026 Fuenteinfiniflow/ragflow original en inglés

Esta página está traducida automáticamente. El texto original en inglés es la referencia.

flujo de trapo v0.26.1

Resumen

Nuevas funciones

  • Proveedor de modelo: permite a los usuarios modificar el tipo de modelo de las configuraciones de modelo existentes. #16029
  • Canal de chat: permite a los usuarios implementar asistentes RAGFlow como chatbots dentro de plataformas de mensajería externas como Discord y Feishu. #15850
  • Observabilidad: agrupa los seguimientos de chat de varios turnos por sesión dentro de Langfuse para facilitar la depuración y reproducción de la conversación. #15679

i18n

  • Agrega ~70 claves de traducción faltantes para la interfaz de usuario en francés. #15983

Corrección de errores

  • Proveedor de modelo: corrige la facturación de tokens inexacta, corrige los límites de truncamiento incorporados para evitar fallas de indexación y refactoriza el manejo de errores para sacar a la luz las causas raíz del error. #15424
  • API: agrega un modo heredado al punto final /chat/completions para restaurar la salida <think> estilo v0.23.0 para compatibilidad con versiones anteriores. #16014 Consulte también Conversar con el asistente de chat.
