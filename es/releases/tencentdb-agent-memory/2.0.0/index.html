TencentDB-Agente-Memoria v2.0.0

[2.0.0] - 2026-08-03

Se lanza la versión oficial de v2.0.0. En comparación con beta.1, nueva habilidad de archivado forzado, sincronización programada con CodeGraph, El panel tiene características como gestión de activos de administrador/cambio en chino e inglés, y se han mejorado el proceso de implementación y la documentación de acceso.

Posicionamiento del producto: permita que la experiencia, los documentos y el código del Agente se conviertan en activos reutilizables para el próximo Agente Leer archivos directamente. Consulte README_CN.md para obtener más detalles.

🧠 Cuatro activos de memoria · Código completamente abierto por primera vez

Se depositan automáticamente cuatro tipos de activos a partir de "rastreos de conversación/trabajo":

  • Memoria de chat — Extrae capa por capa el registro original L0 → hecho L1 → escena L2 → L3 de la conversación Cognición a largo plazo; conservar preferencias, decisiones e historial de interacciones entre sesiones.
  • Habilidad: extraiga SOP reutilizables de tareas completadas, con versiones/archivos de recursos/límites de activación/ Pasos de ejecución/reglas de validación. Nuevo Se agrega la función de archivo forzado para garantizar que no se pierdan habilidades clave.
  • Wiki: convierta documentos en páginas estructuradas + gráfico de enlaces (inspirado en la base de conocimientos LLM de Karpathy). práctica).
  • CodeGraph: indexa símbolos/archivos/relaciones de llamadas/rutas de influencia del almacén, el agente cambia el código Primero haga un análisis de impacto. Nuevo Sincronice automáticamente la función base del código a intervalos regulares, no es necesario hacerlo manualmente después de cambiar el almacén. desencadenar.

🎛️ Memory Hub · Consola orientada al equipo

Panel de gestión (imagen agentmemory/memory-hub, incluido Panel + Servicio de conocimiento):

  • Cree equipo/agente y administre activos de manera uniforme por propietario/versión/estado/visibilidad
  • Visibilidad de nivel 3: private/team/restricted (Usuario/Rol/Agente ACL), Conjunto direccional Plus agent
  • Equipamiento del agente: vincule diferentes activos a diferentes agentes, ajuste las prioridades y los métodos de uso
  • El taller Wiki + CodeGraph está integrado en el Hub y se puede crear automáticamente importando la biblioteca de códigos/documentación.
  • Nuevo administrador (administrador del sistema) también puede utilizar la función de gestión de activos
  • Nuevo panel totalmente compatible con el cambio entre chino e inglés; estilo de diseño de página unificado, interacción de lista optimizada y experiencia de paginación

🔀 Proxy de memoria · El agente cuelga el canal de memoria

agentmemory/memory-proxy permite que agentes de codificación como Claude Code utilicen directamente la memoria del equipo:

  • Protocolo dual Antrópico/OpenAI: /claude-code/<spaceId>/v1/messages y /v1/chat/completions todos aceptados
  • Arranque de primera ronda: sessionInit permite a los usuarios seleccionar equipo/agente/a través de AskUserQuestion tarea, proxy recuerda enlace
  • Inyección en cada ronda: Inyecta la memoria L2/L3 del agente, habilidad coincidente, wiki/código gráfico Ingrese el mensaje del sistema y reenvíe el LLM ascendente
  • Autenticación: x-tdai-user-key → kernel /v3/meta/auth/verify reemplazado por user_id, Controlar la visibilidad de los activos por dimensión del usuario

🚀 Método de implementación

| Método | Descripción | |------|------| | Juego de tres piezas Docker | agentmemory/memory-core / agentmemory/memory-hub / agentmemory/memory-proxy, marco múltiple (linux/amd64 + linux/arm64), pull-up start-all.sh con un solo clic. Inicie el init-admin automático por primera vez y genere .admin-key. Después de que start-all.sh pase la autoprueba, imprime el comando de inicio copiable de claude | | Ejecución del código fuente | Referencia INSTALL_CN.md / INSTALL.md |

stop-all.sh --purge puede limpiar completamente la tecla de volumen + administración para facilitar el restablecimiento del entorno.
