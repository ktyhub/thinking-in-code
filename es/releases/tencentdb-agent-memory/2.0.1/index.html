TencentDB-Agente-Memoria v2.0.1

[2.0.1] - 2026-08-25

Posicionamiento del producto: permita que la experiencia, los documentos y el código del Agente se conviertan en activos reutilizables para el próximo Agente Leer archivos directamente. Consulte README_CN.md para obtener más detalles.

🚀 Apoye a más clientes agentes

Ahora, no importa qué agente de codificación utilices, puedes conectarte directamente a la memoria del equipo:

  • Se agregó acceso de cliente OpenCode
  • Se agregó acceso a DeepSeek Harness (dsh) - Arnés de agente oficial de DeepSeek Las sesiones de la interfaz de usuario web se pueden conectar directamente al Proxy para obtener automáticamente la inyección de memoria/habilidades/conocimientos del equipo.
  • Se agregó acceso Codex CLI
  • Se agregó acceso de cliente WorkBuddy, listo para usar de inmediato.
  • La primera experiencia de inicio y reinicio de múltiples clientes sigue siendo consistente, lo que hace que el cambio sea más fluido.

🤖 Dar comandos directamente dentro de la sesión

No necesita cambiar al panel, puede completar operaciones comunes en el diálogo:

  • Restablecimiento de enlaces con un solo clic a mitad de sesión (equipo de cambio/agente de cambio/tarea de cambio)
  • Crear/actualizar tareas directamente dentro de la conversación
  • Respuesta más rápida a los comandos, menos esperas

🧠 El arranque en frío funciona desde el primer momento

  • Cree un equipo o usuario y se generará automáticamente un Agente predeterminado, no se requiere configuración manual
  • Los administradores pueden personalizar la plantilla de Agente predeterminada y los nuevos usuarios la aplicarán automáticamente durante el inicio en frío.
  • Admite la importación con un solo clic de activos de agentes existentes en el IDE para un inicio rápido
  • Las tareas están vinculadas de forma predeterminada después del acceso y se pueden utilizar desde el primer momento

🔄 El enlace de sesión es más estable

  • El enlace de sesión se guarda de forma persistente y no se perderá después de reiniciar
  • Después de cambiar de agente, la memoria y las habilidades se cambiarán correctamente y ya no aparecerán en escena.
  • Se solucionó un problema por el cual algunas reproducciones del historial del cliente se juzgaban mal.

🧰 Mejora de la experiencia de habilidades

  • Las nuevas habilidades creadas en la sesión se pueden recuperar inmediatamente y ya no existe una "zona muerta de búsqueda". -Restaurar la visualización del ID de habilidad y copiar con un solo clic -Habilidades compatibles con la edición en línea.
  • Nueva habilidad del asistente de acceso: siga la guía para configurar paso a paso o complete automáticamente el acceso Proxy con un comando

🎛️ Panel del concentrador de memoria

  • Nueva página de inicio de sesión, que agrega un efecto dominó de matriz de puntos
  • El portal de edición/eliminación de equipos está integrado en el conmutador de equipos para facilitar la operación y corregir anomalías en el cambio.
  • Los administradores pueden personalizar User_Key al crear una cuenta
  • Nueva búsqueda de memoria de conversación: recuperación semántica y de palabras clave entre sesiones, control preciso del rango visible según los permisos; Admite sobrescritura y modificación directa de memoria de una sola capa
  • Los ID de los activos se muestran directamente y se pueden copiar; la lista está completamente cargada y se soluciona el problema de visualización incompleta debido al truncamiento de la paginación.

⚙️ Mejora de implementación con un solo clic

  • El script de inicio admite la configuración interactiva y verifica previamente automáticamente el canal LLM y la ocupación del puerto para evitar problemas de implementación.
  • La dirección de acceso del cliente se puede copiar con un clic y resolverse automáticamente en la dirección del host en una implementación independiente. Los clientes externos pueden conectarse directamente.

⚡ Optimización del rendimiento

  • La lista de la base de conocimientos se carga más rápido y las rutas utilizadas con frecuencia responden más rápido
  • Las páginas wiki se crean simultáneamente, los errores de una sola página se reintentan automáticamente y el tiempo de importación de grandes lotes de documentos se reduce considerablemente.

📚 Documentación

  • Dividir documentos de acceso independientes por cliente, cada agente tiene una guía de acceso clara
  • Se agregó un nuevo panel y documentación de uso de API.
  • Capturas de pantalla del panel en inglés complementadas y actualizaciones README

🐛 Arreglar

  • Se solucionó el problema de recuperación de memoria vacía en escenarios de múltiples agentes.
  • Se solucionó el problema por el cual la desvinculación de activos no surte efecto y las pestañas de memoria se pierden cuando hay muchos activos.
  • Se corrigió la confusión de tiempo en sesiones históricas importadas y se restauró la línea de tiempo original.
  • Se solucionó un problema por el cual parte del contenido se expandía repetidamente al editar una escena.
  • Se corrigieron problemas de compatibilidad con scripts de implementación en macOS
  • Se corrigieron errores de instalación causados por dependencias faltantes. -Se solucionó el problema de compatibilidad del primer formulario de inicio de algunos clientes en versiones anteriores.
  • Se agregó la función de borrar la memoria de la conversación y admite la eliminación por lotes.
