Scrapling v0.4

Desguace v0.4

La mayor versión de Scrapling hasta el momento: presenta el marco Spider, la rotación de proxy y mejoras importantes en el analizador

Esta versión trae un marco de araña/rastreo totalmente asíncrono, administración inteligente de proxy y cambios significativos en API que hacen que Scrapling sea más poderoso y consistente. Revise atentamente la sección de cambios importantes antes de actualizar.

🕷️ Marco de araña

Un nuevo marco de rastreo asíncrono creado sobre anyio para scraping estructurado a gran escala:

from scrapling.spiders import Spider, Response

class MySpider(Spider):
  name = "demo"
  start_urls = ["https://example.com/"]

  async def parse(self, response: Response):
      for item in response.css('.product'):
          yield {"title": item.css('h2::text').get()}

MySpider().start()
  • Spider tipo Scrapy API: Defina arañas con start_urls, devoluciones de llamada asíncronas parse, objetos Request/Response y cola de prioridad.
  • Rastreo simultáneo: límites de simultaneidad configurables, limitación por dominio y retrasos en la descarga.
  • Soporte multisesión: interfaz unificada para solicitudes HTTP y navegadores sigilosos sin cabeza en una sola araña: enrute solicitudes a diferentes sesiones por ID. Admite la inicialización diferida de sesiones.
  • Pausar y reanudar: persistencia de rastreo basada en puntos de control. Presione Ctrl+C para cerrar con gracia; luego reinicie para continuar desde donde lo dejó.
  • Modo de transmisión: transmita elementos extraídos a medida que llegan a través de async for item in spider.stream() con estadísticas en tiempo real, ideal para UI, canalizaciones y rastreos de larga duración.
  • Detección de solicitudes bloqueadas: Detección automática y reintento de solicitudes bloqueadas con lógica personalizable.
  • Exportación incorporada: exporte resultados a través de ganchos y su propio canal o el JSON/JSONL integrado con result.items.to_json() / result.items.to_jsonl() respectivamente.
  • Ganchos del ciclo de vida: on_start(), on_close(), on_error(), on_scraped_item() y más ganchos para un control total sobre el ciclo de vida del rastreo.
  • Estadísticas de rastreo detalladas: seguimiento de solicitudes, respuestas, bytes, códigos de estado, servidores proxy, desgloses por dominio/sesión, recuentos de niveles de registro y más.
  • soporte de uvloop: pase use_uvloop=True a spider.start() para una ejecución asíncrona más rápida cuando esté disponible.

🔄 Rotación de apoderados

  • Nueva clase ProxyRotator con rotación segura para subprocesos. Funciona con todos los recuperadores y sesiones: 
    from scrapling import ProxyRotatorrotator = ProxyRotator(["http://proxy1:8080", "http://proxy2:8080"])Fetcher.get(url, proxy_rotator=rotator)
  • Estrategias de rotación personalizadas: cree su propia lógica de rotación de proxy
  • Anulación de proxy por solicitud: pase proxy= a cualquier llamada individual get()/post()/fetch() para anular el proxy de sesión para esa solicitud.

🌐 Mejoras en el buscador del navegador

  • Bloqueo de dominio: Nuevo parámetro blocked_domains en DynamicFetcher/StealthyFetcher para bloquear solicitudes a dominios específicos (los subdominios coinciden automáticamente).
  • Reintentos automáticos: los buscadores del navegador ahora reintentan en caso de falla con los parámetros retries (predeterminado: 3) y retry_delay (predeterminado: 1s). Incluye detección de errores con reconocimiento de proxy.
  • Metadatos de respuesta: Response.meta dict almacena automáticamente el proxy utilizado y fusiona los metadatos de la solicitud.
  • Response.follow(): Crea objetos Request de seguimiento con flujo de referencia automático, diseñados para el sistema araña.
  • Sin reproducción automática: las sesiones del navegador ahora bloquean el contenido de reproducción automática, lo que antes causaba problemas.
  • Velocidad: sigilo y velocidad mejorados ajustando las banderas del navegador.

🔧 Mejoras y correcciones de errores

  • Optimización del analizador: optimizó el analizador para operaciones repetidas, mejorando el rendimiento.
  • Páginas con errores: Se corrigió un error que causaba que el navegador no se cerrara cuando las páginas daban errores.
  • Cuerpo vacío: Maneja respuestas con cuerpo vacío.
  • Bucle de Playwright: solución del problema al dejar abierto el bucle de Playwright cuando falla la conexión CDP
  • Seguridad de tipos: se corrigieron todos los errores mypy y se agregaron sugerencias de tipo en los cuerpos de funciones sin tipo. Se agregaron mypy y pyright al flujo de trabajo de CI.

⚠️ Cambios importantes

  • css_first/xpath_first eliminado: utilice css('.selector').first, css('.selector')[0] o css('.selector').get() en su lugar.
  • Toda selección ahora devuelve Selectors: css('::text'), xpath('//text()'), css('::attr(href)') y xpath('//@href') ahora devuelven Selectors (ajustando nodos de texto en objetos Selector con tag="#text") en lugar de TextHandlers. Esto hace que el API sea consistente en todos los métodos de selección y sugerencias de tipo.
  • Response.body es siempre bytes: Anteriormente podía ser str o bytes, ahora siempre devuelve bytes.
  • Comportamiento de get()/getall(): En Selector: get() devuelve TextHandler (HTML serializado o valor de texto), getall() devuelve TextHandlers. Alias: extract_first = get, extract = getall. Se elimina el antiguo get_all() en Selectors.
  • Selectors.first/.last: descriptores de acceso seguros que devuelven Selector | None en lugar de generar IndexError.
  • Constantes internas renombradas: DEFAULT_FLAGS → DEFAULT_ARGS, DEFAULT_STEALTH_FLAGS → STEALTH_ARGS, HARMFUL_DEFAULT_ARGS → HARMFUL_ARGS, DEFAULT_DISABLED_RESOURCES → EXTRA_RESOURCES.

🔨 Otros cambios

  • Cambios de dependencia: se reemplazó tldextract por tld, se eliminó el _html_utils.py interno a favor de w3lib.html.replace_entities y se agregó typing_extensions como requisito estricto.
  • Revisión de documentos: cambio completo de MkDocs a Zensical, nueva sección de documentación de araña, actualización de todas las páginas existentes y adición de nuevas referencias de API.
