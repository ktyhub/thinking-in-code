Scrapling v0.3.2

Esta página está traducida automáticamente. El texto original en inglés es la referencia.

Desguace v0.3.2

Release Note para v0.3.2

🚀 Cosas nuevas

  • Dependencias de buscadores opcionales: todos los buscadores ahora forman parte de grupos de dependencias opcionales, lo que reduce el tamaño del paquete principal. Entonces, el módulo base scrapling ahora es solo el analizador, y para usar los buscadores o las opciones de línea de comandos, debe hacer: pip install "scrapling[fetchers]". Consulte las instrucciones de instalación detalladas desde aquí
  • Configuración por página en sesiones: las clases de sesión para buscadores de navegador ahora admiten la configuración individual por página en sesiones. Todos los parámetros de nivel de recuperación ahora se validan como los de nivel de sesión. Más detalles en el sitio web de documentación aquí <br>Ejemplo: 
    with StealthySession(headless=True, solve_cloudflare=True) as session:    page = session.fetch('https://nopecha.com/demo/cloudflare', google_search=False)
  • Recuperadores mejorados basados en navegador
    • Una nueva opción para controlar si esperar a que finalice la ejecución de JavaScript en páginas o no (ahora está habilitada de forma predeterminada, como estaba antes) 
      with DynamicSession(headless=True, disable_resources=False, network_idle=True) as session:   page = session.fetch('https://quotes.toscrape.com/', load_dom=False)
    • El modo Stealth ahora es más confiable en DynamicFetcher y sus clases de sesión.
    • Tanto DynamicFetcher como StealthyFetcher ahora usan menos recursos (buscando y cerrando automáticamente la pestaña predeterminada abierta por contextos persistentes en Playwright API)
    • Se corrigió un error lógico vital en la rotación de páginas de los buscadores basados en navegador: las páginas anteriores ahora se reemplazan por otras nuevas. (Las pestañas que se reutilizan en rotación posiblemente estén contaminadas por configuraciones anteriores utilizadas en ellas)
    • StealthyFetcher y sus clases de sesión ahora son ligeramente más rápidas (5%)
  • Propiedad .body mejorada: ahora devuelve el contenido pasado tal cual sin procesarlo, lo que permite la descarga de archivos y el manejo de solicitudes que no son HTML. A continuación se muestra un ejemplo de cómo descargar una foto: 
    from scrapling.fetchers import Fetcherpage = Fetcher.get('https://raw.githubusercontent.com/D4Vinci/Scrapling/main/images/poster.png')with open(file='poster.png', mode='wb') as f:   f.write(page.body)

🐛 Corrección de errores

  • Problemas de codificación resueltos: se corrigieron múltiples problemas de codificación que ocurrían con algunos sitios web en el analizador, el modo mcp y los comandos de extracción (también resuelve los números 80 y 81).
  • Análisis más rápido: debido a muchos cambios aquí y allá, la biblioteca ahora es más rápida y se refleja en los puntos de referencia actualizados.

🔨 Varios

  • Parámetros de referencia actualizados: Puntos de referencia de rendimiento actualizados para comparar las mejoras de velocidad actuales con las últimas versiones de bibliotecas similares
  • Refactoricé gran parte del código y reemplacé el código inactivo con mejores implementaciones: menos código, código más limpio, mantenimiento más fácil
  • Video de YouTube agregado: contenido de video incluido para la documentación de MCP.
  • Una nueva plantilla de problemas: nueva plantilla sencilla para usuarios que no pueden usar las plantillas actuales.
  • Optimización del flujo de trabajo de CI: el flujo de trabajo de pruebas ahora omite las ejecuciones cuando solo se modifica la documentación o los archivos que no son de código.
  • Dependencias actualizadas: se aumentaron varias dependencias a las últimas versiones.
  • Mejoras en el estilo del código: se aplicaron nuevas reglas de ruff en todos los archivos.
  • Ganchos de confirmación previa: configuración de confirmación previa actualizada.

🎯 Cambios importantes

  • Se eliminó el parámetro max_pages de sincronización StealthySession para que coincida con DynamicSession (no tiene sentido tenerlo en la versión sincronizada) 🙏 Un agradecimiento especial a nuestra [comunidad de Discord] (https://discord.gg/EMgGbDceNQ) por todas las pruebas y comentarios continuos
