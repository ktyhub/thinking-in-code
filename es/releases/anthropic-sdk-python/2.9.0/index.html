antrópico-sdk-python v2.9.0

Características

  • api: agregue códigos fuente y de error a los puntos finales de lectura del rol RBAC
  • api: agregue el paquete de actualización, que establece las instrucciones de un paquete Claude Tag y devuelve instrucciones en el paquete

Corrección de errores

  • credenciales: escriba el archivo de credenciales en Windows con Python 3.12 y versiones anteriores
  • herramientas: compara nombres de directorios exactamente al limitar la herramienta de archivos y cargar rutas en Windows
  • herramientas: resuelve completamente las rutas de herramientas de archivos que pasan a través de un enlace simbólico colgante
  • herramientas: ignora los archivos de configuración de ripgrep en la herramienta grep del conjunto de herramientas del agente
  • herramientas: mantiene un directorio de habilidades existente cuando falla la descarga o extracción que lo reemplazaría
  • herramientas: mantiene en ejecución la cuenta regresiva max_idle del ejecutor de la herramienta de sesión cuando finaliza un hilo de sesión Si el corredor no puede leer el historial de eventos de la sesión después de una reconexión, una terminación que luego llega al flujo del evento aún cancela la cuenta regresiva, hasta la siguiente lectura inactiva o exitosa.
  • herramientas: deje enlaces simbólicos que apunten fuera de /recuerdos fuera de los listados
  • herramientas: busque ripgrep solo en entradas absolutas PATH en la herramienta grep del conjunto de herramientas del agente La herramienta ya no ejecuta un rg desde una entrada PATH relativa o vacía o, en Windows, desde el directorio actual. En Windows busca rg.exe, por lo que ya no se utiliza un rg.cmd, rg.bat o rg.com. Sin ningún otro rg en PATH, la herramienta utiliza su búsqueda incorporada.
  • herramientas: pasa un rg dentro de los directorios que las herramientas de archivos del conjunto de herramientas del agente pueden escribir grep pasa por encima de un rg que se resuelve en algún lugar dentro de workdir o allowed_roots, cualquiera que sea la letra mayúscula de los nombres. Utiliza el siguiente rg en PATH, o la búsqueda incorporada cuando no hay ninguna. Con un workdir que contiene todos los rg del host, como el /, cada búsqueda es una búsqueda integrada. rg ya no obtiene las variables ANTHROPIC_* del proceso, como el shell de bash.
  • herramientas: lee archivos de memoria solo a través de la ruta que fue validada
  • herramientas: lee solo archivos normales en la búsqueda integrada de la herramienta grep La búsqueda incorporada de grep pasa por un FIFO o un dispositivo en el directorio que recorre, como lo hace ripgrep. Leer uno podría bloquear la búsqueda y el bucle de eventos con ella para siempre.
  • herramientas: impide que EnvironmentWorker ejecute herramientas para una sesión finalizada Para una sesión terminada, el trabajador ahora fuerza la detención del elemento de trabajo justo después de recuperar la sesión, antes de descargar habilidades o almacenes de memoria. Ya no genera SessionMemoryError para dicha sesión. El API informa una sesión archivada como terminated.
  • herramientas: detenga la herramienta grep después de 30 segundos de tiempo de CPU cuando ripgrep no esté instalado
  • herramientas: impide que el ejecutor de la herramienta de sesión ejecute las llamadas a la herramienta de un subproceso de sesión finalizado El corredor tampoco cede estas llamadas, incluida una llamada denegada (confirmation="deny") y una llamada a una herramienta que no le pertenece. La única excepción es una llamada cuya herramienta ya se está ejecutando cuando finaliza el hilo: el corredor lo entrega con posted=False y no publica ningún resultado.

Tareas

  • api: desaprobar los valores de encabezado beta antiguos El API todavía acepta estos valores, pero una versión posterior los elimina de los SDK. Elimine prompt-caching-2024-07-31, pdfs-2024-09-25, token-counting-2024-11-01, token-efficient-tools-2025-02-19, extended-cache-ttl-2025-04-11, cache-diagnosis-2026-04-07 y ce-user-management-2026-07-13 de sus solicitudes. files-api-2025-04-14 y skills-2025-10-02 seleccionan las formas de respuesta beta, así que siga las guías de migración de Archivos API y Habilidades antes de eliminarlas. En C#, los miembros de la enumeración AnthropicBeta tienen números nuevos, por lo que el código compilado con una versión anterior de SDK envía un valor beta diferente, sin errores, hasta que lo reconstruya.
  • api: dejar de enviar un encabezado beta antiguo en solicitudes por lotes beta.messages.batches ya no envía message-batches-2024-09-24, que el API no necesita. Si su client establece un encabezado anthropic-beta predeterminado, estas solicitudes ahora lo envían, mientras que en algunos SDK el valor anterior lo reemplazó. El API todavía acepta el valor anterior. Si lo configura usted mismo, elimínelo: una versión posterior lo eliminará de los SDK.
  • docs: agregue un valor de ejemplo para el nombre del espacio de trabajo
  • docs: aclarar cuándo la política de permiso automático niega una llamada a una herramienta
  • docs: aclarar a qué espacios de trabajo se puede adjuntar una clave externa
  • docs: recomienda multiagent_20261001 sobre el tipo de coordinador
  • docs: indica cuándo se requiere Organization_id en las lecturas del complemento
  • pruebas: permitir que los trabajadores de pruebas inactivos realicen pruebas en cola
