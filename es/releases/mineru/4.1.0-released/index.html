#MinerU mineru-4.1.0-released

chino

  • Plataformas principales y aceleración automática de GPU: la instalación predeterminada admite CPU que se ejecuta en Windows, Linux y macOS, así como aceleración de inferencia de gráficos integrada o independiente compatible con Intel, AMD, NVIDIA y Apple Silicon. Selecciona automáticamente la GPU o CPU adecuada; Los escenarios de inferencia central representativos son aproximadamente de 2 a 3 veces más rápidos que la CPU.
  • Interfaz asincrónica de Tareas unificadas: reemplace los antiguos flujos de trabajo /v1/uploads y /v1/parse/jobs con /v1/tasks, que admite lista de archivos, entrada de URL, transmisión sin caché, ejecución archivo por archivo y descarga de resultados, así como consultas de estado unificadas y operaciones de cancelación. Consulte Descripción de la interfaz de tareas para obtener más detalles.
  • Servicio de análisis sincrónico restaurable: el file-parse-server independiente proporciona /v1/file_parse, que admite la carga de un solo archivo y la devolución de archivos adjuntos, consultas después del tiempo de espera y recuperación de tareas conocidas mediante ID de solicitud. Consulte [descripción de la interfaz de análisis de archivos] (https://github.com/opendatalab/MinerU/blob/mineru-4.1.0-released/docs/zh/usage/file_parse.md) para obtener más detalles.
  • Diagnóstico de hardware y recomendación de equipo: se agregaron mineru-kit hardware detect y hardware info para ayudar a seleccionar el equipo de servicio apropiado y ver el equipo, el entorno operativo y la información de calibración.

Consejos de actualización: El rango de soporte de Python se ajusta a 3.11–3.14. Esta vez contiene cambios destructivos en la interfaz HTTP. Coordine la actualización del servidor, enrutador, SDK y cliente. Para obtener más información, consulte las Instrucciones de migración 4.1.

inglés

  • Aceleración automática en las principales plataformas y GPU: La instalación predeterminada admite la inferencia de CPU en Windows, Linux y macOS, además de la inferencia acelerada en GPU compatibles Intel, AMD, NVIDIA y Apple Silicon, incluidos los gráficos integrados. MinerU selecciona automáticamente la ejecución de GPU o CPU adecuada; Las cargas de trabajo de inferencia central representativas se ejecutan a aproximadamente 2–3 veces la velocidad de la CPU.
  • Tareas asíncronas unificadas API: /v1/tasks reemplaza el flujo de trabajo anterior /v1/uploads y /v1/parse/jobs, admitiendo manifiestos de archivos, entradas de URL, reutilización de cargas en caché, ejecución y descargas por archivo, consultas de estado y cancelación. Consulte la Referencia de tareas API.
  • Análisis de archivos sincrónicos recuperables: El file-parse-server independiente proporciona /v1/file_parse para cargas de archivos únicos y respuestas de archivos adjuntos, con consultas después de tiempos de espera e ID de solicitud para recuperar tareas conocidas. Consulte la [referencia de análisis de archivos API] (https://github.com/opendatalab/MinerU/blob/mineru-4.1.0-released/docs/en/usage/file_parse.md).
  • Diagnóstico de hardware y recomendaciones de niveles: Los nuevos comandos mineru-kit hardware detect y hardware info ayudan a seleccionar un nivel de servicio adecuado e inspeccionar dispositivos, versiones de tiempo de ejecución e información de calibración.

Nota de actualización: Las versiones compatibles de Python ahora son 3.11–3.14. Esta versión incluye cambios importantes en HTTP API; actualice servidores, enrutadores, SDK y clients juntos. Consulte la guía de migración 4.1.

Changelog completo: https://github.com/opendatalab/MinerU/compare/mineru-4.0.12-released...mineru-4.1.0-released
