Agente Hermes v0.20.2 (v2026.8.16)

Fecha de lanzamiento: 16 de agosto de 2026

Lanzamiento del parche. Esta etiqueta agrupa los ~397 RP fusionados desde v0.20.1 en una versión etiquetada estable para consumidores posteriores (imágenes de Docker, implementaciones alojadas, instalaciones nuevas).

Acerca de esta versión

Desde v0.20.1 (v2026.8.13, etiquetado el 13 de agosto), esta ventana arrojó ~967 confirmaciones en ~1,279 archivos (+128,522 / −7,622) — ~397 PR combinados de correcciones y mejoras que abarcan la aplicación de escritorio (registro de Connections de múltiples puertas de enlace, actualizaciones de perfil, comprobaciones de estado de MCP y enlaces profundos), CLI (actualización de Windows). sondas, protocolo de teclado Kitty, refuerzo de chat -c), la puerta de enlace (rutas de modelo persistentes, finalización de /loop, temas de DM de Telegram), almacenamiento en caché de avisos para LiteLLM Claude en el cable OpenAI, refuerzo de cron, resolución de autenticación a través de alcances de perfil y solidez del instalador tanto en Linux como en Windows. Los release note completamente seleccionados para esta ventana se enviarán con v0.21.0, que documentará todo desde v0.20.0 en adelante: aspectos destacados, áreas destacadas y créditos completos de los contribuyentes. No se omite nada en esta ventana.
