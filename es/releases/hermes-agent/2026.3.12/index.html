agente-hermes v2026.3.12

Agente Hermes v0.2.0 (v2026.3.12)

Fecha de lanzamiento: 12 de marzo de 2026

Primer lanzamiento etiquetado desde v0.1.0 (la fundación inicial prepública). En poco más de dos semanas, Hermes Agent pasó de ser un pequeño proyecto interno a una plataforma de agente de IA con todas las funciones, gracias a una explosión de contribuciones de la comunidad. Esta versión cubre 216 solicitudes de extracción fusionadas de 63 contribuyentes y resuelve 119 problemas.

✨ Destacados

  • Puerta de enlace de mensajería multiplataforma: plataformas Telegram, Discord, Slack, WhatsApp, Signal, correo electrónico (IMAP/SMTP) y Home Assistant con gestión de sesiones unificada, archivos adjuntos multimedia y configuración de herramientas por plataforma.
  • MCP (Protocolo de contexto modelo) Client: compatibilidad con MCP nativo con transportes stdio y HTTP, reconexión, descubrimiento de recursos/indicaciones y muestreo (solicitudes LLM iniciadas por el servidor). (#291 — @0xbyt4, #301, #753)
  • Ecosistema de habilidades: más de 70 habilidades incluidas y opcionales en más de 15 categorías con un centro de habilidades para el descubrimiento de la comunidad, activación/desactivación por plataforma, activación condicional basada en la disponibilidad de la herramienta y validación de requisitos previos. (#743 — @teyrebaz33, #785 — @teyrebaz33)
  • Enrutador de proveedor centralizado: el call_llm()/async_call_llm() API unificado reemplaza la lógica del proveedor disperso en visión, resumen, compresión y guardado de trayectoria. Todos los consumidores auxiliares se enrutan a través de una única ruta de código con resolución automática de credenciales. (#1003)
  • Servidor ACP: integración del editor VS Code, Zed y JetBrains a través del estándar Agent Communication Protocol. (#949)
  • CLI Skin/Theme Engine: personalización visual basada en datos: pancartas, elementos giratorios, colores, marca. 7 máscaras integradas + máscaras personalizadas YAML.
  • Git Worktree Isolation: hermes -w lanza sesiones de agente aisladas en git worktrees para un trabajo paralelo seguro en el mismo repositorio. (#654)
  • Puntos de control y reversión del sistema de archivos: instantáneas automáticas antes de operaciones destructivas con /rollback para restaurar. (#824)
  • 3289 pruebas: desde una cobertura de prueba casi nula hasta un conjunto de pruebas integral que cubre agente, puerta de enlace, herramientas, cron y CLI.
