agente-hermes v2026.5.16

Agente Hermes v0.14.0 (v2026.5.16)

Fecha de lanzamiento: 16 de mayo de 2026 Desde v0.13.0: 808 confirmaciones · 633 RP fusionados · 1393 archivos modificados · 165,061 inserciones · 545 números cerrados (12 P0, 50 P1) · 215 contribuyentes de la comunidad (incluidos coautores)

La versión Foundation: Hermes se instala y ejecuta en cualquier lugar, se envía con las cosas que realmente desea usar y deja de enviar las cosas que no desea. xAI Grok llega como proveedor de SuperGrok OAuth con grok-4.3 elevado a una ventana de contexto de 1M. Un nuevo proxy local compatible con OpenAI convierte a cualquier proveedor Hermes autorizado por OAuth (Claude Pro, ChatGPT Pro, SuperGrok) en un punto final al que Codex/Aider/Cline/Continue puede acceder. x_search aterriza como una herramienta de búsqueda X (Twitter) de primera clase con autenticación de clave OAuth o API. La pila de Microsoft Teams está conectada de un extremo a otro (autenticación de gráfico + escucha de webhook + tiempo de ejecución de canalización + entrega saliente). Una ola de desinflación hace que las instalaciones sean dramáticamente más livianas: los backends pesados ​​ahora se instalan de manera diferida en el primer uso, los extras [all] eliminan todo lo cubierto por lazy-deps y una instalación por niveles retrocede cuando una rueda rechaza su plataforma. pip install hermes-agent funciona desde PyPI. La ola de arranque en frío reduce ~19 segundos el lanzamiento de hermes. Las llamadas CDP del navegador son 180 veces más rápidas. Dos nuevas plataformas de mensajería (LINE + SimpleX Chat) elevan el total a 22. Almacenamiento en caché de avisos de Claude de 1 hora entre sesiones, /handoff que realmente transfiere sesiones en vivo, interfaz de usuario de botón nativo para clarify en Telegram y Discord, reabastecimiento del historial del canal de Discord, diagnóstico semántico LSP en cada escritura, un video_generate unificado conectable, un backend de cua-driver computer_use que finalmente funciona con proveedores no antrópicos. cli URL accesibles en cualquier terminal, integración del Registro Zed ACP a través de uvx, versión beta nativa de Windows, 9 nuevas habilidades opcionales, enrutador OpenRouter Pareto Code, huggingface/skills como un toque predeterminado trusted. 12 cierres P0 + 50 P1.

✨ Destacados

  • xAI Grok a través de SuperGrok OAuth — y grok-4.3 salta a una ventana contextual de 1M — Si paga por SuperGrok, ahora puede usar Grok dentro de Hermes iniciando sesión con su cuenta xAI; sin clave API, sin facturación por separado. La conexión también lleva grok-4.3 a una ventana de contexto de token de 1 millón, por lo que puede colocar bases de código completas o corpus de investigación en un solo mensaje. Incluye un manejo adecuado de los errores de derechos y una página de documentos de SSH a túnel para cuando esté conectado a SSH en una caja remota y necesite completar el flujo de OAuth. (#26534, #26664, #26644, #26592)
  • Proxy local compatible con OpenAI para proveedores de OAuth: ejecute hermes proxy y obtendrá un punto final http://localhost:port que habla OpenAI API pero que está respaldado por cualquier proveedor de OAuth en el que haya iniciado sesión: Claude Pro, ChatGPT Pro, SuperGrok. Ahora, cualquier herramienta que espere un punto final compatible con OpenAI (Codex CLI, Aider, Cline, Continuar, sus scripts personalizados) simplemente funciona con su suscripción existente, no se requiere clave API. Una suscripción, cada herramienta. (#25969)
  • x_search: herramienta de búsqueda de X (Twitter) de primera clase: el agente ahora puede buscar X directamente sin instalar una habilidad ni conectar una integración personalizada. Busque en la línea de tiempo, encuentre hilos y muestre publicaciones específicas, directamente desde el chat. Autentíquese con su inicio de sesión X OAuth o con una clave API, la que tenga. (#26763)
  • Microsoft Teams, de un extremo a otro: Hermes ahora puede leer mensajes de Teams y publicarlos. La pila completa de Microsoft Graph aterriza en conjunto: base auth + client, ​​un oyente de webhook que recibe eventos de Teams, un tiempo de ejecución de complemento de canalización y entrega saliente. Conecte el bot una vez y luego charle con su agente desde cualquier canal, DM o grupo de Teams. (rescates de #21408–#21411) (#21922, #21969, #22007, #22024)
  • Ola de desinflación: instalaciones más ligeras, menos cosas que no usas: se utiliza un pip install hermes-agent limpio para eliminar todo: cada adaptador de mensajería SDK, cada generación de imágenes SDK, cada proveedor de voz/TTS, ya sea que los hayas usado o no. Ahora, esos backends pesados ​​(adaptadores Slack / Matrix / Feishu / DingTalk, retrospectiva client, ​​servidor de aplicaciones codex, Pixverse / Camofox / image-gen SDK, proveedores de voz/TTS) se instalan automáticamente la primera vez que los usa. Los extras de [all] eliminan todo lo cubierto por Lazy Deps, el instalador retrocede a través de niveles cuando una rueda no se ajusta a su plataforma y un verificador de asesoramiento de la cadena de suministro escanea cada instalación en busca de versiones inseguras. Instalaciones más rápidas, menor espacio en disco, menos vulnerabilidades transitivas. (#24220, #24515, #25014, #25038, #25766, #21818)
  • pip install hermes-agent && hermes — Hermes Agent ahora es un paquete PyPI real. Ya no es necesario clonar el repositorio ni ejecutar instaladores de shell: un comando pip y listo. La rueda se envía con el paquete Ink TUI y el lanzador de proyectiles, por lo que la experiencia completa sale de la caja. (rescate de #26350) (#26593, #26148)
  • Caché de aviso de Claude de 1 hora entre sesiones: cuando usa Claude a través de Anthropic, OpenRouter o Nous Portal, el prefijo de aviso (mensaje del sistema, habilidades, memoria) ahora se almacena en caché durante una hora en todas las sesiones. Inicie una sesión /new y la primera respuesta será más rápida y económica porque el caché aún está activo desde su última sesión. La revisión de la memoria en segundo plano también llega al caché, por lo que no paga el precio completo en cada turno. (#23828, #25434, #24778)
  • Evaluaciones de browser_console 180 veces más rápidas: cuando el agente usa la herramienta del navegador para inspeccionar una página o ejecutar JavaScript, esas llamadas ahora comparten una conexión persistente a Chrome en lugar de generar una nueva sesión de DevTools cada vez. La diferencia es enorme: cosas que antes tomaban un par de segundos por llamada regresan en milisegundos. Las interacciones con páginas del mundo real se sienten instantáneas. (#23226)
  • Ola de rendimiento de arranque en frío: ~19 segundos antes del lanzamiento de hermes: ejecutar hermes solía hacerte esperar durante una gran cantidad de gastos generales de importación y llamadas de red antes de ver un mensaje. Ahora la ruta de lanzamiento es en su mayor parte diferida: los adaptadores pesados ​​solo se cargan cuando los usa, los catálogos de modelos provienen primero del caché del disco, las comprobaciones médicas se ejecutan en paralelo y chat -q se salta el banner de bienvenida por completo. La pantalla para todas las plataformas del hermes tools por sí sola cayó de 14 segundos a menos de los segundos del 1.5. (#22138, #22120, #22681, #22790, #22808, #22831, #22859, #22904, #22766, #25341)
  • Dos nuevas plataformas de mensajería: LINE + SimpleX Chat: LINE es enorme en Japón, Corea y Taiwán, y ahora Hermes se ejecuta de forma nativa en LINE Messaging API. SimpleX Chat es el mensajero descentralizado centrado en la privacidad sin ID de usuario, y también conectado como una plataforma de primera clase. Esto eleva a Hermes a 22 plataformas de mensajería en total, por lo que dondequiera que usted y su equipo hablen, el agente puede estar allí. (#23197, #26232)
  • /handoff en realidad transfiere la sesión en vivo: cambiar de modelo o personalidad en mitad de una conversación solía significar perder el contexto o empezar de nuevo. Ahora /handoff mueve su sesión activa (cada mensaje, cada llamada de herramienta, cada fragmento de contexto) al modelo, persona o perfil objetivo, en vivo, sin perder nada. A mitad de la depuración, pase de un modelo rápido a uno de razonamiento profundo, o pase una sesión entre perfiles para diferentes partes de una tarea. (#23395)
  • IU del botón nativo para clarify en Telegram y Discord: cuando el agente usa la herramienta clarify para hacerle una pregunta de opción múltiple, ahora muestra botones reales nativos de la plataforma en Telegram y Discord en lugar de pedirle que vuelva a escribir el número de opción. Toque el botón y el agente recibe su respuesta. Especialmente agradable en dispositivos móviles. (#24199, #25485)
  • Relleno del historial del canal de Discord (predeterminado activado): cuando Hermes se une a un canal o hilo de Discord por primera vez, ahora lee el historial de mensajes recientes para saber lo que se ha dicho antes de responder. No más "¿de qué estamos hablando?" — el agente tiene el contexto que ya está en pantalla para todos los demás. (#25984)
  • vision_analyze devuelve píxeles a modelos con capacidad de visión: cuando apunta al agente a una imagen con vision_analyze y el modelo activo realmente puede ver (GPT-5, Claude, Gemini, Grok-vision), Hermes ahora pasa los píxeles sin procesar directamente al modelo en lugar de convertirlos primero en una descripción de texto. Obtiene el razonamiento visual real del modelo en lugar de un resumen de texto degradado de ida y vuelta. (#22955)
  • Pie de página del verificador de mutación de archivos por turno: después de cada turno en el que se escribieron o editaron archivos, el agente ahora obtiene un pie de página breve que resume exactamente lo que cambió en el disco: las rutas de los archivos, el recuento de líneas, el delta real. Eso significa que el agente detecta sus propios errores cuando una escritura no se realizó o se sobrescribió silenciosamente, en lugar de decirle con confianza "Agregué la función" cuando el archivo en realidad no se guardó. (#24498)
  • Diagnóstico semántico LSP en cada escritura: cuando el agente usa write_file o patch, Hermes ahora ejecuta un servidor de lenguaje real en el archivo editado y muestra cualquier error nuevo al agente antes del siguiente turno. Errores tipográficos, símbolos no definidos, importaciones faltantes: detectados de inmediato. Va mucho más allá del linting básico Python/JSON/YAML/TOML de v0.13.0 porque es un análisis semántico real. (#24168, #25978)
  • video_generate unificado con backends de proveedores conectables: una herramienta, cualquier modelo de vídeo. Hermes ya viene con los backends obvios, pero puedes incluir un nuevo proveedor de video como complemento sin tocar el núcleo. Entonces, cuando llegue un nuevo modelo de video el próximo mes, puede ser un complemento de un solo archivo en lugar de una bifurcación. (#25126)
  • Backend cua-driver computer_use: ahora funciona con modelos que no son Anthropic — El uso de la computadora (el agente que controla el mouse y el teclado para controlar las aplicaciones GUI) solía estar bloqueado en el SDK de Anthropic. El nuevo backend cua-driver también funciona con proveedores no antrópicos, tiene operaciones seguras de enfoque adecuadas y se actualiza en hermes update. Ahora cualquier modelo con capacidad de visión puede controlar su escritorio. (rescate de #16936) (#21967, #24063)
  • CliURL URL accesibles en cualquier terminal: los enlaces en la salida del agente ahora son hipervínculos OSC8 reales con resaltado al pasar el mouse en cualquier terminal que los admita. Click para abrir en su navegador: no más copiar, pegar y recortar URL largas de la transcripción. Simplemente funciona en iTerm2, Kitty, Ghostty, Terminal Windows moderno, etc. (@OutThisLife) (#25071, #24013)
  • Registro Zed ACP: instalación de uvx en un click: Hermes ahora figura en el registro del protocolo Agent Client de Zed, por lo que los usuarios de Zed pueden instalarlo con un click. La ruta de instalación usa uvx, por lo que no hay dependencia de npm. hermes acp --setup-browser inicia las herramientas del navegador para instalaciones basadas en el registro. (rescate de #25908) (#26079, #26120, #26234)
  • Enrutador OpenRouter de código Pareto con perilla min_coding_score: el enrutador "Pareto" de OpenRouter selecciona automáticamente el modelo más barato que cumple con un estándar mínimo de calidad. La nueva configuración min_coding_score le permite establecer ese listón para tareas de codificación específicamente: Hermes dirige al modelo más asequible que sea al menos tan bueno en código. Deje de pagar por modelos de primer nivel cuando uno de nivel medio sería suficiente. (#22838)
  • NovitaAI como nuevo modelo de proveedor: NovitaAI se une a la línea de proveedores, brindándole otra opción para alojamiento de modelos de código abierto (Llama, Qwen, DeepSeek, etc.) con sus precios y límites de tarifas. (salvamento #7219) (@kshitijk4poor) (#25507)
  • Tiempo de ejecución del servidor de aplicaciones Codex para modelos OpenAI/Codex: un tiempo de ejecución opcional que impulsa el Codex CLI de OpenAI bajo el capó cuando se utilizan rutas OpenAI o Codex. Obtiene la reutilización de sesiones, el retiro automático de sesiones bloqueadas y una clasificación adecuada de actualización de OAuth: el tipo de sistema que evita que las ejecuciones de agentes largas no fallen. (#24182, #25769)
  • huggingface/skills como toque predeterminado trusted: el índice de habilidades de la comunidad alojado en huggingface.co/skills ahora está conectado al Centro de habilidades de forma predeterminada. Entonces, cuando alguien publica una habilidad útil allí, puedes instalarla desde tu propio navegador hermes skills sin ninguna configuración adicional. (cierra #2549) (#26219)
  • 9 nuevas habilidades opcionales — Hyperliquid (perp + comercio al contado a través de SDK y REST API), Yahoo Finance (datos de mercado en vivo, fundamentos, históricos), pruebas api (REST + recetas de depuración GraphQL), EVM multicadena unificada (una habilidad cubre Ethereum + L2s + Base), darwinian-evolver (indicador evolutivo/ajuste de habilidades), osint-investigation (recetas OSINT para personas/dominios/organizaciones), pinggy-tunnel (exponer servicios locales a la Internet pública), observadores (encuestas RSS/HTTP JSON/GitHub a través del modo cron no_agent para detección de cambios) y una revisión completa de Notion para la plataforma de desarrolladores de mayo de 2026. (#23582, #23583, #23590, #25299, #26760, #26729, #26765, #21881, #26612)
  • El servidor API expone eventos de aprobación de ejecución: si está ejecutando Hermes mediante programación a través de HTTP API, las ejecuciones de ejecución prolongada ya no se bloquean silenciosamente cuando el agente presiona un comando que requiere aprobación. La solicitud de aprobación ahora aparece en la transmisión de API para que su client pueda avisar al usuario y responder: no más paradas silenciosas. (salvamento de #20311) (#21899)
  • Los complementos pueden ejecutar cualquier llamada de LLM a través de ctx.llm + reemplazar las herramientas integradas a través de tool_override: si está escribiendo un complemento de Hermes, ahora obtiene acceso de primera clase para realizar llamadas de LLM a través del proveedor activo y las credenciales, sin cableado manual de client. El nuevo indicador tool_override permite que un complemento intercambie limpiamente una herramienta incorporada con su propia implementación. Los autores de complementos obtienen el mismo enrutamiento de modelos y el mismo sistema de autenticación que utiliza el agente principal. (cierra #11049) (#23194, #26759)
  • Brave Search (nivel gratuito) + DuckDuckGo (DDGS) como proveedores de búsqueda web: dos nuevos backends de búsqueda web gratuitos se unen a Tavily, SearXNG y Exa. Brave Search tiene un generoso nivel gratuito; DDGS es el raspador DuckDuckGo que no necesita ninguna llave. Elija el que se ajuste a su presupuesto y necesidades de límite de tarifas. (#21337)
  • Bloque de fuerza bruta de Sudo + 3 omisiones de comandos peligrosos cerradas + desinfección de errores de herramientas: la puerta de aprobación ahora bloquea los intentos de fuerza bruta sudo -S y clasifica las invocaciones de sudo alimentadas con estándar o sin contraseña como PELIGROSAS. Se cierran tres desvíos conocidos de detección de comandos peligrosos (inspirados en el trabajo de detección de comandos de Claude Code). Y las cadenas de error de las herramientas ahora se desinfectan antes de reinyectarse en el contexto del modelo, por lo que un archivo malicioso o un servicio remoto no puede pasar instrucciones a su agente a través de la salida de error. (#23736, #26829, #26823)
  • /subgoal: criterios agregados por el usuario agregados a un /goal activo: cuando tiene un /goal en ejecución (el objetivo persistente de Ralph-loop donde el agente continúa hasta que se cumplen los criterios), ahora puede usar /subgoal <text> para aplicarle criterios de éxito adicionales a mitad de ejecución. El juez tiene en cuenta sus nuevos criterios en la decisión de hacer o continuar sin reiniciar el ciclo. (#25449)
  • Cambio de nombre del proveedor: Alibaba Cloud → Qwen Cloud: el proveedor de Alibaba Cloud pasa a llamarse Qwen Cloud en el selector y la configuración para que coincida con lo que el resto del mundo lo llama. Las claves de configuración existentes aún funcionan, sin cambios importantes, pero la interfaz de usuario ahora coincide con la marca real. (#24835)
  • Soporte nativo de Windows (beta temprana): Hermes ahora se ejecuta de forma nativa en cmd.exe y PowerShell sin WSL. Un instalador completo de PowerShell maneja la instalación automática de MinGit, la detección de código auxiliar de Microsoft Store python y el baile Ctrl+C en primer plano. Todavía hay asperezas (este es el sello de "beta temprana"): ~40 correcciones de seguimiento solo para Windows ya llegaron a la ventana, pero el bucle básico funciona de un extremo a otro en una caja limpia de Windows. (#21561)
