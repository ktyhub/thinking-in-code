agente-hermes v2026.3.23

Agente Hermes v0.4.0 (v2026.3.23)

Fecha de lanzamiento: 23 de marzo de 2026

La versión de expansión de la plataforma: servidor API compatible con OpenAI, 6 nuevos adaptadores de mensajería, 4 nuevos proveedores de inferencia, administración del servidor MCP con OAuth 2.1, referencias de contexto @, almacenamiento en caché de avisos de puerta de enlace, transmisión habilitada de forma predeterminada y un amplio pase de confiabilidad con más de 200 correcciones de errores.

✨ Destacados

  • Servidor API compatible con OpenAI: expone Hermes como un punto final /v1/chat/completions con un nuevo /api/jobs REST API para la gestión de trabajos cron, reforzado con límites de entrada, listas blancas de campos, persistencia de respuesta respaldada por SQLite y protección de origen CORS (#1756, #2450, #2456, #2451, #2472)
  • 6 nuevos adaptadores de plataforma de mensajería: los adaptadores Signal, DingTalk, SMS (Twilio), Mattermost, Matrix y Webhook se unen a Telegram, Discord y WhatsApp. La puerta de enlace reconecta automáticamente plataformas fallidas con retroceso exponencial (#2206, #1685, #1688, #1683, #2166, #2584)
  • @ referencias de contexto — Inyección de contexto @file y @url estilo Claude Code con terminaciones de tabulación en CLI (#2343, #2482)
  • 4 nuevos proveedores de inferencia: GitHub Copilot (OAuth + validación de token), Alibaba Cloud / DashScope, Kilo Code y OpenCode Zen/Go (#1924, #1879 de @mchzimm, #1673, #1666, #1650)
  • Administración del servidor MCP CLI: comandos hermes mcp para instalar, configurar y autenticar servidores MCP con flujo completo de OAuth 2.1 PKCE (#2465)
  • Almacenamiento en caché de avisos de puerta de enlace: almacena en caché las instancias de AIAgent por sesión, preservando el caché de avisos de Anthropic en todos los turnos para una reducción drástica de costos en conversaciones largas (#2282, #2284, #2361)
  • Revisión de la compresión de contexto: resúmenes estructurados con actualizaciones iterativas, protección final de presupuesto de token, punto final de resumen configurable y compatibilidad con modelos alternativos (#2323, #1727, #2224)
  • Transmisión habilitada de forma predeterminada: transmisión de CLI activada de manera predeterminada con visualización adecuada del progreso de la herramienta/hilador durante el modo de transmisión, además de extensas correcciones de saltos de línea y concatenación (#2340, #2161, #2258)
