agente-hermes v2026.4.3

Agente Hermes v0.7.0 (v2026.4.3)

Fecha de lanzamiento: 3 de abril de 2026

La versión de resiliencia: proveedores de memoria conectables, rotación del grupo de credenciales, navegador antidetección Camofox, vistas previas de diferencias en línea, refuerzo de la puerta de enlace en las condiciones de carrera y enrutamiento de aprobación, y correcciones de seguridad profundas en 168 RP y 46 problemas resueltos.

✨ Destacados

  • Interfaz de proveedor de memoria conectable: la memoria ahora es un sistema de complemento extensible. Los backends de memoria de terceros (Honcho, almacenes de vectores, bases de datos personalizadas) implementan un proveedor ABC simple y se registran a través del sistema de complementos. La memoria incorporada es el proveedor predeterminado. La integración de Honcho se restauró a la paridad total como complemento de referencia con resolución de host/par con alcance de perfil. (#4623, #4616, #4355)
  • Grupos de credenciales del mismo proveedor: configure varias claves API para el mismo proveedor con rotación automática. La estrategia least_used segura para subprocesos distribuye la carga entre claves y las fallas 401 activan la rotación automática a la siguiente credencial. Configure mediante el asistente de configuración o la configuración credential_pool. (#4188, #4300, #4361)
  • Backend del navegador antidetección Camofox: nuevo backend del navegador local que utiliza Camoufox para una navegación sigilosa. Sesiones persistentes con descubrimiento de URL de VNC para depuración visual, omisión de SSRF configurable para backends locales, instalación automática a través de hermes tools. (#4008, #4419, #4292)
  • Vistas previas de diferencias en línea: las operaciones de parcheo y escritura de archivos ahora muestran diferencias en línea en la fuente de actividad de la herramienta, lo que le brinda una confirmación visual de lo que cambió antes de que el agente continúe. (#4411, #4423)
  • Continuidad de sesión del servidor API y transmisión de herramientas: el servidor API (integración Open WebUI) ahora transmite eventos de progreso de la herramienta en tiempo real y admite encabezados X-Hermes-Session-Id para sesiones persistentes entre solicitudes. Las sesiones persisten en la SessionDB compartida. (#4092, #4478, #4802)
  • ACP: servidores MCP proporcionados por Client: las integraciones de editores (VS Code, Zed, JetBrains) ahora pueden registrar sus propios servidores MCP, que Hermes utiliza como herramientas de agente adicionales. El ecosistema MCP de su editor fluye directamente hacia el agente. (#4705)
  • Reforzamiento de la puerta de enlace: importante paso de estabilidad en las condiciones de carrera, entrega de medios fotográficos, control de inundaciones, sesiones estancadas, rutas de aprobación y espirales mortales de compresión. La puerta de enlace es sustancialmente más fiable en la producción. (#4727, #4750, #4798, #4557)
  • Seguridad: bloqueo de exfiltración secreta: las URL del navegador y las respuestas de LLM ahora se analizan en busca de patrones secretos, bloqueando los intentos de exfiltración mediante codificación de URL, base64 o inyección rápida. Las protecciones del directorio de credenciales se ampliaron a .docker, .azure, .config/gh. La salida del entorno limitado de Execute_code está redactada. (#4483, #4360, #4305, #4327)
