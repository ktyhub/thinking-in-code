agente-hermes v0.22.2

Agente Hermes v0.22.2

Fecha de lanzamiento: 15 de octubre de 2026

v0.22.1 se creó a partir de una confirmación incorrecta. Envió un trabajo de puerta de enlace inédito y la aplicación Microsoft Store podría permanecer en "Conectando". 0.22.2 es la versión que debía ser 0.22.1.

Problema conocido: Las sesiones que se ejecutaron bajo la puerta de enlace 0.22.1 no se pueden eliminar en 0.22.2.

<!-- HERMES_BUILDS_TABLE -->

Destacados

  • La puerta de enlace se inicia después de reiniciar nuevamente. Después de un reinicio, Linux puede entregar un PID temprano a un proceso no relacionado, y la puerta de enlace podría confundirlo con una puerta de enlace en ejecución, por lo que una puerta de enlace supervisada (systemd, launchd, Docker) se negó a iniciarse. Hermes ahora registra el inicio en el que comenzó y, cuando no puede saberlo, solicita el bloqueo del host, que solo posee una puerta de enlace activa. (#138594, corrige #133744)
  • Los turnos largos del modelo local sobreviven en las computadoras portátiles. Las solicitudes locales siempre se transmiten con un progreso de lectura rápida (que se muestra en la línea de estado), los temporizadores de parada omiten el tiempo que la máquina estuvo inactiva, un servidor local recuperado recibe otro intento en lugar de un interruptor que falló en cada mensaje posterior, y la compresión ya no se agota mientras el servidor todavía está leyendo una conversación larga. En máquinas con memoria unificada de Windows, el lanzamiento del modelo y la caché de mensajes se dimensionan para liberar memoria. (#138560)

A continuación se muestra todo lo que hay en la línea de lanzamiento de 0.22 desde v0.22.0: las correcciones que 0.22.1 debía enviar, más las dos anteriores. Trabajo que solo se encuentra en main y se envía con v0.23.0.
