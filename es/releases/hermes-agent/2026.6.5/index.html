agente-hermes v2026.6.5

Agente Hermes v0.16.0 (v2026.6.5)

Fecha de lanzamiento: 5 de junio de 2026 Desde v0.15.2: 874 confirmaciones · 542 PR fusionados · 1962 archivos modificados · 205,216 inserciones · 46,217 eliminaciones · 399 problemas cerrados (2 P0, 62 P1, 16 con etiquetas de seguridad) · 170 contribuyentes de la comunidad (incluidos coautores)

The Surface Release. Hermes te encuentra dondequiera que trabajes. Una nueva aplicación de escritorio nativa, creada con 100 relaciones públicas y 159 confirmaciones en una sola semana, le ofrece Hermes como una aplicación real para macOS/Linux/Windows: instalación one-click, actualización automática en la aplicación, arrastrar y soltar archivos en el chat, un selector de modelo en línea en la barra de estado, sesiones simultáneas de múltiples perfiles, una traducción completa al chino simplificado y la capacidad de conectarse a una puerta de enlace remota de Hermes a través de OAuth o nombre de usuario/contraseña. Junto a él, el panel web desarrolló un panel de administración completo basado en navegador (catálogo MCP, canales de mensajería, credenciales, webhooks, memoria, OIDC conectable / inicio de sesión con nombre de usuario y contraseña) y la configuración por primera vez obtuvo una ruta de "Configuración rápida a través de Nous Portal" que lo lleva desde la instalación hasta el primer mensaje en segundos. El conjunto de habilidades predeterminado se redujo a lo que realmente necesitas, NVIDIA/skills se unió a los toques de trusted Skills Hub, el selector de modelo ahora se puede realizar con búsquedas difusas en todas partes (escritorio, web, TUI, CLI) y /undo finalmente te permite recuperar los últimos N turnos. Se llevan 2 cierres P0 y 62 P1, además de una ronda de seguridad (pin Starlette CVE-2026-48710, endurecimiento fuera de bucle SSRF, eliminación de credenciales de subproceso).

✨ Destacados

  • Hermes Desktop: una aplicación nativa real, no un contenedor de terminal: este es el titular. Ahora existe una aplicación apps/desktop/ Electron que se instala como cualquier otra aplicación de escritorio en macOS, Linux y Windows, se actualiza desde dentro de la aplicación y le brinda una GUI pulida para todo lo que hace Hermes. Obtiene una ventana de chat adecuada con transmisión, una lista de sesiones que puede archivar y buscar, arrastrar y soltar archivos en cualquier lugar del área de chat, pegar imágenes en el tablero cli, una paleta de comandos Cmd+K y un selector de modelo directamente en la barra de estado. Si les ha estado diciendo a sus amigos "es un agente CLI" y ​​ha visto sus ojos vidriosos, ahora puede enviarles un instalador. Nada de esto existía hace una semana. (#20059, #35607, #37099, #37379, #38631 — @OutThisLife, @jquesnelle, @ethernet8023, @austinpickett, @benbarclay)
  • Ejecute la aplicación de escritorio en un Hermes remoto: inicie sesión con OAuth o nombre de usuario/contraseña: la aplicación de escritorio no tiene que ejecutar Hermes localmente. Apunte a una puerta de enlace remota de Hermes (su laboratorio doméstico, una caja alojada, el servidor de un compañero de equipo) y se conectará a través de un WebSocket seguro, autenticándose con OAuth o un inicio de sesión con nombre de usuario/contraseña, sin necesidad de manipular indicadores --insecure ni tokens de sesión copiados a mano. Cada perfil puede apuntar a su propio host remoto y usted puede ejecutar sesiones simultáneas en múltiples perfiles en una ventana con enlaces @session entre perfiles. La versión práctica: su computadora portátil ejecuta una GUI delgada, el agente pesado se ejecuta dondequiera que su API clave y calcule en vivo. (#37888, #38851, #39330, #39778 — @benbarclay, @OutThisLife, @teknium1)
  • El panel web ahora es un panel de administración completo: configure todo desde el navegador — El panel pasó de "ver sus sesiones" a una superficie de administración completa. Hay una página de Canales que configura cada plataforma de mensajería de puerta de enlace (Telegram, Discord, Slack, etc.) desde el navegador, un panel de administración para el catálogo de MCP con opciones para habilitar/deshabilitar, administración de credenciales, creación de webhooks y enlaces, configuración de memoria, controles de puerta de enlace y una página de Sistema con verificación antes de actualizar y un recurso compartido de depuración one-click. Ya no es necesario ingresar mediante SSH y editar config.yaml para conectar un nuevo canal de mensajería o servidor MCP; ahora todo es apuntar y click. (#36704, #36736, #37211, #38205, #38600 — @teknium1)
  • Hermes Desktop habla chino simplificado: 简体中文 completo en la GUI del chat: la aplicación de escritorio ahora incluye una traducción completa al chino simplificado (简体中文) en todas las superficies de la interfaz de usuario: la ventana de chat en sí, la barra lateral, la configuración, el centro de comando, el cron, la mensajería, los perfiles, las habilidades, los agentes, todo. El inglés sigue siendo el predeterminado; cambie el idioma en la configuración de Apariencia y la elección persiste en su configuración (display.language). Está construido sobre una capa i18n escrita correctamente, por lo que agregar más idiomas desde aquí es sencillo. (#38241 — @JimLiu)
  • Conjunto de habilidades predeterminado más reducido: Hermes ofrece solo lo que realmente necesitas: el conjunto de habilidades incluido se recortó deliberadamente. Las habilidades que eran redundantes o muertas han desaparecido (spotify, reemplazada por las 7 herramientas del complemento nativo de Spotify; linear, reemplazada por hermes mcp install linear; kanban-codex-lane, debugging-hermes-tui-commands, un huérfano domain obsoleto y varios marcadores de categoría vacíos). Las habilidades más pesadas o de nicho pasaron de estar incluidas a ser opcionales (el conjunto creativo Baoyu, dspy, subagent-driven-development, minecraft-modpack-server, pokemon-player, hermes-s6-container-supervision), todavía a un hermes skills install de distancia, pero no cargados de forma predeterminada. Y una nueva puerta de relevancia environments: mantiene las habilidades específicas del contexto (kanban, docker/s6) fuera del índice de habilidades para los usuarios que nunca las usarán, mientras las carga bajo solicitud explícita. El resultado: una lista de habilidades predeterminadas más pequeña y nítida, menos ruido en el selector y un mensaje más ligero. El curador ahora también puede eliminar las habilidades integradas no utilizadas (no solo las creadas por agentes), con un seguimiento del uso de cada habilidad. (#39028, #36701, #36228 — @teknium1)
  • NVIDIA/skills ahora es un toque de habilidades trust incorporado: NVIDIA/skills se une a OpenAI, Anthropic y HuggingFace como un toque trusted predeterminado en Skills Hub: detectable, navegable, con capacidad de búsqueda y actualización automática a través del mismo canal. Las habilidades verificadas de NVIDIA para CUDA-X, AIQ, cuOpt y el resto de su pila de productos están a una instalación de distancia, con etiquetas de categoría reales del sidecar skills.sh.json del repositorio. (#34333 — @teknium1)
  • Configuración rápida a través de Nous Portal: desde la instalación hasta el primer mensaje en segundos: la configuración inicial se redujo a dos caminos claros: Configuración rápida (inicie sesión en Nous Portal, obtenga un selector de modelo, comience a chatear inmediatamente) o Configuración completa (el asistente detallado para usuarios avanzados). hermes portal es ahora el alias legible por humanos que ejecuta el flujo completo de configuración rápida de Nous. El menú de primera ejecución explica la diferencia en línea para que los recién llegados no tengan que adivinar. El objetivo: un usuario nuevo no debería necesitar leer documentos para enviar su primer mensaje. (#35723, #36227, #38449, #38465 — @teknium1, @kshitijk4poor)
  • Selector de modelo difuso, en todas partes: escriba algunas letras, encuentre su modelo: el selector de modelo ahora realiza búsquedas difusas en la aplicación de escritorio, el panel web, TUI y CLI. Superficies tipo "v4fl" y deepseek-v4-flash; Los proveedores de múltiples puntos finales se agrupan en una fila en lugar de saturar la lista con duplicados, y cada fila lleva una descripción para que sepa lo que está eligiendo. El catálogo se actualiza cada hora en lugar de diariamente, por lo que los nuevos modelos aparecen el mismo día de su lanzamiento. Nueva esta ventana: deepseek-v4-flash, MiniMax-M3 con contexto 1M, qwen3.7-plus. (#36928, #35227, #35756, #35659, #36214 — @kshitijk4poor, @teknium1)
  • /undo [N] — recuperar los últimos N turnos — ¿Dijo algo incorrecto o envió al agente por un mal camino? /undo realiza una copia de seguridad de N turnos de usuario, completa previamente su último mensaje para que pueda editarlo y reenviarlo, y elimina temporalmente los turnos intermedios. Funciona en CLI, TUI y en todas las plataformas de mensajería (Telegram, Discord, etc.) con total paridad. Cierra una solicitud de larga data (#21910). (#36229, #36699 — @teknium1)
  • Elija su interfaz predeterminada: cli o tui: ahora puede configurar si hermes chat lo lleva al CLI clásico o al Ink TUI de forma predeterminada, con un indicador --cli para anular por invocación. La TUI también obtuvo un único comando /model unificado y una superposición de sesiones para cambiar entre sesiones en vivo. Utilice la interfaz que realmente le guste. (#37782, #37112 - @OutThisLife)
