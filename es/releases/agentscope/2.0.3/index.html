agentescopio v2.0.3

Nuevas características importantes

Módulo RAG

  • Se introdujo un módulo RAG (generación aumentada de recuperación) nativo con soporte completo para servicios RAG distribuidos, multiinquilino y multisesión, lo que mejoró significativamente las capacidades de recuperación de conocimientos. Middleware de memoria a largo plazo
  • Se agregó un middleware de memoria a largo plazo respaldado por mem0, que permite a los agentes retener memoria persistente entre sesiones. Middleware de control presupuestario
  • Se presentó BudgetControlMiddleware para hacer cumplir los límites de presupuesto de tokens, lo que ayuda a los equipos a administrar y controlar los costos de API de manera efectiva. Middleware cebolla a nivel de herramienta
  • ToolBase ahora admite middleware estilo cebolla a nivel de herramienta, lo que permite inyectar una lógica flexible de pre y posprocesamiento en torno a la ejecución de la herramienta.
