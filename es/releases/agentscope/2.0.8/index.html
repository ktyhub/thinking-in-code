agentescopio v2.0.8

Resaltar

  • Agente de voz en tiempo real: se presentó un agente de voz en tiempo real con backends DashScope y soporte de transporte local.
  • Compatibilidad con el protocolo A2A: se agregó la clase A2AAgent al módulo de agente, lo que permite la comunicación de agente a agente.
  • Nuevo módulo de canalización: se agregó un nuevo módulo de canalización con una clase GoalPipeline para flujos de trabajo de agentes basados ​​en objetivos.
  • Compresión de contexto impulsada por el agente: se introdujo una herramienta de compresión de contexto que permite a los agentes administrar su propia ventana de contexto.
  • LLM Rerank para RAG: se agregó soporte de reranking basado en LLM para mejorar la calidad de recuperación de RAG.
  • Modelo Volcengine Ark: Se agregó soporte para el modelo de chat Volcengine Ark.
  • Mejoras de MCP: admite encabezados de MCP en tiempo de ejecución en espacios de trabajo Docker y limpieza de conexiones de MCP mejorada.
  • Web UI Polish: mejoras en la experiencia de chat, incluido el nombramiento automático de sesiones, el almacenamiento en caché de consultas y una mejor compatibilidad con el modo oscuro.
