hipercuadros v0.9.65

#HyperFrames v0.9.65 Publicado el 17/11/2026. La vista previa sellada de Studio ahora dibuja rutas de movimiento, lee fotogramas clave y mantiene una capa movida en su lugar cuando agrega un fotograma clave. Los eventos de error y análisis de Studio ya no incluyen el texto de error, las rutas de archivo ni los selectores.

Características

  • Studio Server: Deje que un host cuente las solicitudes que el API rechaza con 403 (078e54d00, #8049).

Correcciones

  • Studio: Los eventos de error envían una clase, una forma y los marcos propios de Studio, no las palabras del error (195aa2f0c, #8114).
  • Studio: Agregar fotograma clave en una vista previa sellada mantiene la capa movida en su lugar (ce3decb6b, #8117).
  • CLI: El pase facial de verificación lee solo los medios que la página puede cargar (c4a4167aa, #8116).
  • Studio: Una vista previa sellada se mueve y guarda una capa en la que se mueve su animación (7a9d78e69, #8105).
  • Estudio: Analytics envía datos de ruta y selector, no las rutas y los selectores (d87285387, #8109).
  • Estudio: La ruta de movimiento se dibuja y se puede crear en una vista previa sellada (373d987e3, #8108).
  • Habilidades: Seleccione versiones independientes de CLI a través del iniciador (414adffb8, #8102).
  • Figma: Escriba salidas .media y componentes sin seguir los enlaces (a765c9379, #8111).
  • Estudio: El banco de edición espera el intercambio de vista previa una vez que un elemento simple obtiene fotogramas clave (ba62d7748, #8113).
  • CLI: La limpieza de Windows Chrome y las lecturas de proceso ya no pasan el texto del comando de PowerShell (b930c4d2d, #8085).
  • Versión: La verificación del empujador sin cuenta lee su archivo directamente, sin canalización (740796888, #8095).
  • Productor: Vincula el check del selector de medios estáticos por la página que recorre (435dd0e68, #8091).
  • Studio: Un elemento seleccionado permanece dibujado y se puede arrastrar después de que se recarga una vista previa sellada (1bf629c1d, #8081).
  • Estudio: Un click después de dos búsquedas rápidas agrega el fotograma clave en una vista previa sellada (93622154e, #8103).
  • Versión: Enumere el servidor MCP como com.heygen/hyperframes, firmado por la clave de heygen.com (88ba1b4d7, #8106).
  • Uso de medios: Los guiones de audio juzgan un .env recibido según la regla del CLI (bc5259d2d, #8086).
  • Uso de medios: Escriba la salida del generador local en carpetas privadas por ejecución (ac33c1f2b, #8030).
  • Estudio: Las lecturas de valores y fotogramas clave de GSAP funcionan en una vista previa sellada (133965e4f, #8003).
  • CLI: Conservar los archivos recibidos que el registro mantenido de un host todavía enumera (183bf2a41, #8100).
  • CLI: Digamos que un archivo recibido en la lista desapareció y suelte la línea de un archivo multimedia al cambiar el nombre (4a59fef2d, #8098).

Catálogo

  • Mire el registro de MCP cada hora para el servidor de listados de HeyGen. json nunca se mantuvo (0b0108f2f, #8107).
  • Registro: Utilice el iniciador instalado en guías de bloques (1c99314a6, #8101).

Interno

  • Github: El escaneo secreto omite el manifiesto de habilidades generado (06578d941, #8115).
  • Studio: La verificación de respuesta de GSAP comparte el registro de trama y las comprobaciones de identificador (53a493edc, #8104).
