hipercuadros v0.9.66

#HyperFrames v0.9.66 Publicado el 18-11-2026. La vista previa sellada de Studio ahora realiza ediciones de propiedades, recorta, cambia el tamaño y reproduce escenas de presentaciones de diapositivas. Una vista previa ya no se almacena en el almacenamiento intermedio cuando un clip deja de descargarse y el reproductor puede llevar su propia marca.

Características

  • Reproductor: Añade marcas personalizables al reproductor de vista previa (a9b4745f1, #7718).

Correcciones

  • AWS Lambda: Haga coincidir el shell con su propio pin, envíe solo archivos hash, rechace el ZIP del shell en CDK y SAM (61d65e717, #8173).
  • AWS Lambda: Fijar la ruta ZIP del shell, bloquear el espacio libre del ZIP, hacer coincidir las fuentes arm64 con x86 (ed3f05a05, #8170).
  • Studio: Las ediciones de atributos y estilo del panel de propiedades se muestran en una vista previa sellada (b525686e7, #8149).
  • Compilador: Rebase las rutas de los activos de composición del archivo leído y cargue lo que agregan (bb55c1ea7, #8166).
  • CLI: Los comandos de Figma imprimen el texto del manifiesto y de la carpeta con escapes visibles (420f14d15, #8126).
  • CLI: Muestra caracteres de control en nombres impresos como escapes visibles (3e788fb15, #8008).
  • Habilidades: El piso del lanzador es 0.9.65, la versión más antigua de Desktop (140b70140, #8159).
  • AWS Lambda: Chrome-headless-shell 158 en la imagen de video arm64, sparticuz 153 en el ZIP x86 (81d73d227, #8155).
  • Productor: Inserta una fuente local solo mientras la página se mantiene dentro de su límite de tamaño (3b79b1858, #8152).
  • Estudio: Las lecturas de elementos de una vista previa sellada están limitadas y un marco sin ningún agente responde a la vez (e623031f3, #8055).
  • Núcleo: Cada edición de client toma su propio puerto, por lo que una vista previa sellada responde nuevamente a Studio (e95cdf7d7, #8154).
  • Núcleo: Mantenga el cambio de nombre de identificación de SVG lineal en el tamaño de la página y dentro del límite de tamaño de renderizado (5bd3e3242, #8147).
  • Studio: Verifique cada archivo que una carpeta mueve o elimina (7ea012953, #8143).
  • Estudio: Una vista previa sellada toma el tamaño de la película del reproductor (d574ded1e, #7967).
  • Core: Mantener los estilos de una composición cuyo id contenga $ patrones (12a2f83c4, #8141).
  • Compilador: Estilos variables de composición enlazada y fuentes de medios variables (c6e3f30be, #8144).
  • Núcleo: Un clip que deja de descargarse ya no mantiene la vista previa en el almacenamiento en búfer para siempre (01331014d, #8138).
  • Reproductor: Sigue reproduciendo el vídeo cuando saltas a otro momento (3ee095bde, #7719).
  • CLI: Ejecute actualizaciones globales desde el directorio de inicio (e99cd75b4, #8131).
  • Uso de medios: Caracteres de control de escape en las líneas restantes de resolución y validación de cubos (9a096d72f, #8059).
  • Medios: Mantenga cada fila de index.md en una línea y muestre los caracteres de control como escapes (ebddc4248, #8127).
  • CLI: Las pruebas leen opencv.js desde una caché de CI, nunca una CDN a mitad de prueba (e6cee094b, #7968).
  • Estudio: Recortar y cambiar el tamaño del trabajo en una vista previa sellada (c569417bb, #8005).
  • Núcleo: Los administradores de paquetes de archivos de tratamiento se ejecutan de forma predeterminada como herramienta-trusted (5f06e1b0a, #8129).
  • Habilidades: El lanzador nunca inicia un CLI más antiguo que su piso de seguridad (63c8f8ef6, #8125).
  • CLI: Indica cuándo el pase facial de verificación detuvo una fuente en su límite de tiempo (59fbb22eb, #8122).
  • CLI: Los scripts de uso de medios leen la copia de registro guardada del host como lo hace el CLI (c27adb35f, #8119).
  • Estudio: Las escenas de presentación de diapositivas, el apilamiento de bloques, el desglose y los accesos directos funcionan en una vista previa sellada (80bf6a9dd, #8118).
  • CLI: Un cambio de nombre mantiene el registro de archivos recibidos que enumera el archivo movido (cb2b51525, #8112).

Documentos y ejemplos

  • Ci: Digamos que el entorno npm-publish necesita la aprobación de un revisor (d94aa5e30, #8123).

Interno

  • Productor: El detalle de renderizado del archivo faltante agregado en este ciclo se eliminó nuevamente antes del lanzamiento y regresa en uno posterior (cfea8cfff, #7955, eb7dc14e8, #8146, 94d06663b, #8174).
  • Player: Una ejecución colgada de Safari ya no falla en todas las ejecuciones de Safari posteriores (9acf26868, #8169).
  • Estudio: Comparte un marco de vista previa sellado que muestra mensajes como un navegador (640cb3792, #8165).
  • Chrome: Fija chrome-headless-shell 158.0.8127.36 dondequiera que lo instale el repositorio (793052502, #8145).
  • Lint: Error cuando se crea una expresión regular a partir de texto que no tiene escape (dcdd34071, #8128).
