hipertramas v0.9.53

#HyperFrames v0.9.53

Publicado el 15/11/2026.

Las páginas con muchos caracteres chinos, japoneses o coreanos ahora cargan sus fuentes en unas pocas solicitudes pequeñas, por lo que se procesan en lugar de agotarse. El renderizado en la nube ya no rechaza un archivo que solo tiene un nombre de página no utilizado, y las cargas ahora enumeran todos los archivos que transportan desde fuera del proyecto.

Características

  • CLI: Las cargas enumeran todos los archivos que transportan desde fuera del proyecto (e426ce4eb, #7831).

Correcciones

  • Productor: Las transiciones de sombreado se combinan en Node cuando la página no puede componerlas (fb1a383bd, #7840).
  • CLI: La prueba de corte de carga deja de fallar en ejecutores de Windows ocupados (2ea78c0ab, #7843).
  • Motor: Las descargas restringidas aplican la regla de dirección del proxy de captura (125a9446b, #7839).
  • Las vistas previas del servidor LAN y las páginas de reproducción rechazan otros sitios sin obtener metadatos (2ceb682f9, #7836).
  • CLI: Benchmark mantiene la regla de archivos recibidos; una clave .env recibida nunca reemplaza un inicio de sesión (a7266e4c8, #7837).
  • CLI: El renderizado en la nube ya no rechaza un archivo solo los nombres de páginas no utilizados (45cc331e5, #7812).
  • Principal: Las páginas con muchos caracteres CJK obtienen fuentes en varias solicitudes (6a8f4b5b4, #7823).
  • CLI: El audio de Hyperframes nunca busca medios en el recurso compartido de otra computadora (eaf33bc65, #7826).
  • CLI: Las cargas omiten los scripts externos; .ts cuenta como video solo cuando es uno (04202e8a4, #7818).
  • CLI: Reproduce y presenta la vista previa del Host como vista previa; El renderizado local omite archivos externos para una composición recibida (ac0247410, #7792).
  • Las rutas de medios de Studio rechazan la carga entre sitios, CLI escapa del texto del terminal, las salidas por lotes permanecen en su carpeta (c4d60c347, #7779).
  • CLI: Descubre escenas montadas dentro de plantillas (a75e61f31, #7822).
  • Studio Server: Los registros de bloqueo del historial se reemplazan, nunca se escriben a través de enlaces (0248ea033, #7821).
  • Productor: Mantenga el servidor de renderizado local a menos que un token lo proteja (f667111d1, #7814).
  • Motor,cli: La verificación de la carpeta de la lista de reproducción lee HLS como lo hace ffmpeg; La instantánea también lo ejecuta (797a622be, #7810).
  • Motor,productor: La configuración de red de renderizado se lee como un interruptor; Las sondas de servicio de procesamiento permanecen en las entradas marcadas (be740d021, #7807).
  • CLI: Los comandos impresos de Windows leen los nombres de las carpetas literalmente en cada shell (a07d4cf73, #7769).
  • CLI: Solo se agregan registros recibidos anidados; un .env recibido nunca selecciona la cuenta; los nombres de fuentes no aparecen en los archivos del agente (80b09cc94, #7808).
  • Los renderizados de Cloud Run llegan solo a direcciones públicas; La carpeta de caché de cuadros es privada para su usuario (55b514709, #7777).
  • Deps: Actualizar zod, smol-toml, aws-cdk-lib y resoluciones relacionadas en bun.lock (28d4ba50f, #7741).
  • Deps: Pase @mcp-b/global a 6.1.0 para borrar los avisos de @modelcontextprotocol/server (beeb17e85, #7742).
  • Motor: Una captura paralela fallida nombra al trabajador que falló, no a los pares que detuvo (db6b7478a, #7803).
  • Motor: Los rechazos de procesamiento nombran la dirección que lleva un host NAT64 o mapeado IPv6 (04ee926d9, #7802).
  • Productor: Acepte solicitudes del navegador solo bajo loopback, IP o nombres de host listados (03e6a1a18, #7798).
  • Analizadores: Nunca busque medios en el recurso compartido de otra computadora (2de5c027f, #7797).
  • CLI: Los archivos cargados siempre omiten los archivos env y los registros privados (477a3aea1, #7796).
  • Motor: Descargas de medios remotas vinculadas por tamaño, codificación y rendimiento (5111cf384, #7786).
  • CLI: Inicie programas auxiliares solo desde las carpetas PATH trusted en cada plataforma (83eae240f, #7787).

Rendimiento

  • Lint: Escanea referencias de URL CSS en tiempo lineal (bcf3d177d, #7829).
  • Los escaneos de URL CSS, @import, @font-face, estilos y comentarios se ejecutan en tiempo lineal (ded5e3eec, #7809).

Catálogo

  • CLI: Agregar archivos de listas del registro de una configuración recibida tal como se recibió (6a7b4df7c, #7820).
  • Catálogo: La verificación de carga útil trata el caption-overrides.json opcional como ausente, no fallido (b7c26ff84, #7813).
  • Registro: Las palabras clave de subtítulos, emoji y réplica funcionan para palabras fuera de a-z (8dbbc1d37, #7804).
  • Documentos: Verifique los valores de los enlaces del catálogo y manténgalos fuera de los comandos copiados (7c7ff6d89, #7783).
