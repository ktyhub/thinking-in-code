opentelemetry-java v1.66.0

API

  • Se corrigió Baggage.fromContext() y Baggage.fromContextOrNull() para manejar un contexto null (#8667)
  • No codifique porcentualmente los metadatos de equipaje del W3C (#8682)
  • Se corrigió ArrayIndexOutOfBoundsException en OtelEncodingUtils para caracteres hexadecimales no válidos (#8748)

SDK

Rastros

  • Registre los tramos procesados antes de que se complete la exportación y rechace nuevos tramos al apagar la instrumentación de autoobservabilidad SpanProcessor (#8735)

Métricas

  • Mejorar el rendimiento de contención de histograma de depósito explícito (#8717)

Registros

  • Registre los registros procesados antes de que se complete la exportación y rechace los nuevos registros al apagar en la instrumentación de autoobservabilidad LogRecordProcessor (#8698)

Exportadores

  • OTLP: Respetar Retry-After en remitentes HTTP OTLP (#8633)
  • OTLP: agregue la opción setEnabledProtocols a los creadores de exportadores HTTP OTLP (#8610)
  • OTLP: Rechazar mezclar keyManager y sslContext en TlsConfigHelper (#8710)
  • OTLP: Corrige OkHttpGrpcSender mTLS cuando se utiliza la tienda trust predeterminada de la plataforma (#8758)
  • OTLP: Suprime la instrumentación de solicitudes de exportador en JdkHttpSender (#8757)
  • OTLP: Acepte nombres de host RFC 1123 en EndpointUtil.validateEndpoint para remitentes OkHttp (#8746)
  • OTLP: incluya la cantidad de elementos afectados en el registro de errores del exportador (#8780)
  • OTLP: Agregar toString a OtlpJsonLogging{Span,Metric,LogRecord}Exporter (#8725)
  • Perfiles OTLP: Mejore el ejemplo de exportación JFR y alinee el manejo de elementos nulos LinkData con la especificación (#8349)
  • Prometheus: Elimina la advertencia de registro de host predeterminada en PrometheusHttpServerBuilder (#8679)
  • Prometheus: Alinear las conversiones de unidades de bytes UCUM con la tabla de especificaciones (#8752)

Extensiones

  • ÚLTIMA HORA Configuración declarativa: cambie el nombre de los configuradores POJO del modelo generado de with<Prop> a set<Prop> (#8742)
  • Configuración declarativa: resuelve propiedades experimentales en API estables en POJO modelo generado (#8654)
  • Configuración declarativa: corrige los indicadores scope_info_enabled y target_info_enabled invertidos en el proveedor de componentes Prometheus (#8750)
  • Configuración declarativa: admite output_stream en otlp_file/development (#8676)
  • Incubadora: Agregue toString a ComposableAnnotatingSampler (#8645)

Herramientas del proyecto

  • Corregir los hallazgos de zizmor en los flujos de trabajo de acciones de GitHub (#8592)
