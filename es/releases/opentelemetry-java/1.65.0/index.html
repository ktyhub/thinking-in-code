opentelemetry-java v1.65.0

NOTA: El artefacto opentelemetry-exporter-zipkin dejó de publicarse. Quedó obsoleto en una versión anterior. Los usuarios deben migrar a OTLP o utilizar un exportador de recopiladores compatible con Zipkin.

API

  • Ignorar claves de equipaje vacío en ImmutableBaggage.put (#8658)
  • Utilice NumberFormatException en el decodificador de equipaje (#8593)
  • Se corrigió TraceStateBuilder.remove que corrompía el generador cuando se elimina la misma clave dos veces (#8613)

Incubando

  • Agregue instrumentos enlazados API (BoundLongCounter, BoundDoubleCounter, BoundLongHistogram, BoundDoubleHistogram, BoundLongUpDownCounter, BoundDoubleUpDownCounter, BoundLongGauge, BoundDoubleGauge) a las métricas de la incubadora API (#8527)

Extensiones

  • Propagadores de seguimiento: corrige la distinción entre mayúsculas y minúsculas en el encabezado de equipaje JaegerPropagator (#8496)
  • Propagadores de seguimiento: no sobrescriba el equipaje existente con equipaje vacío en JaegerPropagator (#8632)
  • Propagadores de seguimiento: omitir claves de equipaje vacías en el extracto OtTracePropagator (#8631)
  • Propagadores de seguimiento: dejar de analizar un encabezado jaeger-baggage después de 64 tokens, incluidos los tokens con formato incorrecto (#8702)

SDK

  • Actualización de la implementación de atributos SDK (AttributesMap) para aplicar la semántica de último valor ganador basada en el valor de cadena de AttributeKey.getKey() (#8548)

Rastros

  • Agregar ciclo de vida de apagado de Sampler: Sampler ahora extiende Closeable y expone un shutdown() predeterminado que se invoca cuando se apaga el SdkTracerProvider; JaegerRemoteSampler lo implementa para detener su ejecutor de sondeo (#8574)

Métricas

  • Métricas de autoobservabilidad de Gate PeriodicMetricReader mediante versión de telemetría interna (#8597)
  • Registro error.type en colecciones fallidas en PeriodicMetricReader (#8650)
  • Pruebas: Corrección LongExemplarAssert.hasFilteredAttributesSatisfyingExactly para imponer la coincidencia exacta de atributos (#8518)

Registros

  • Se corrigió el getObservedTimestampEpochNanos predeterminado de ReadWriteLogRecord que devuelve la marca de tiempo del registro (#8504)

Perfiles

  • Se corrigió el nombre del parámetro de recuento de atributos del modelo de datos de perfiles y la unidad de documento de marca de tiempo (#8514)

Exportadores

  • ADVERTENCIA Zipkin: Eliminar opentelemetry-exporter-zipkin; el artefacto ya no está publicado (#8677)
  • OTLP: use cuerpos de respuesta de error HTTP en los registros de advertencia HttpExporter (#8428)
  • OTLP: Corrige OkHttpHttpSender mTLS cuando se utiliza la tienda trust predeterminada de la plataforma (#8565)
  • OTLP: Se corrigió la extensión de signo en los indicadores LogRecord en el analizador de registros de baja asignación (#8493)
  • OTLP: estandariza el apagado de OkHttpHttpSender, JdkHttpSender y UpstreamGrpcSender para esperar la terminación del ejecutor/canal (#8495, #8627, #8624)
  • OTLP: registra la excepción/ion subyacente cuando un marco de respuesta gRPC no es válido (#8626)
  • OTLP: Evite el codificador de cadenas inseguro en Android (#8637)
  • Prometheus: Fusionar valores de etiquetas Prometheus en colisión (#8364)
  • Prometheus: Se corrigió PrometheusHttpServer.toBuilder() eliminando el controlador predeterminado configurado (#8619)
  • Registro: nombre del evento de salida en SystemOutLogRecordExporter (#8609)
  • Registro: Incluir temporalidad de agregación en LoggingMetricExporter toString (#8623)

Extensiones

  • Configuración automática: evite exponer los valores de configuración en mensajes de error (#8669)
  • Configuración declarativa: Se corrigió la configuración del intervalo de sondeo del muestreador Jaeger (#8668)
  • Configuración declarativa: eliminar el solucionador getStringList duplicado en DeclarativeConfigPropertyUtil (#8572)
  • Configuración declarativa: Reemplace jsonschema2pojo con un generador POJO hecho a mano (#8600)
  • Incubadora: Restaura el cumplimiento entre el código de muestreadores compuestos y la especificación (#8450)

Cuñas

  • DEPRECATION Desaprobar la corrección pública de OpenCensus API (#8674)
  • OpenCensus: Preservar la descripción del estado de OpenCensus al convertir a OpenTelemetry (#8511)
  • OpenCensus: agregue enlaces al intervalo OpenTelemetry en lugar de registrar una advertencia y eliminarlos (#8635)
  • OpenTracing: Devuelve null del extracto TracerShim cuando el operador no tiene contexto de extensión (#8505)
  • OpenTracing: Devuelve el SpanContext extraído cuando se muestrea pero no es válido (#8634)

Herramientas del proyecto

  • Fijar la línea base japicmp en version.gradle.kts (#8591)
  • Actualización de la guía de contribución en respuesta a los comentarios (#8655)
