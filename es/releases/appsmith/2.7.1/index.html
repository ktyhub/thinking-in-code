appsmith v2.7.1

⚠️ Notas importantes de actualización

  • Incrustar lista blanca: APPSMITH_ALLOWED_FRAME_ANCESTORS debe ser una lista de expresiones fuente de CSP frame-ancestors. Un valor guardado que no esté en ese formato se entrega como 'self' después del siguiente reinicio. Al guardar la configuración se rechaza un valor no válido. (#42622)
  • Nombres de páginas de Git: Git no confirmará una aplicación mientras el nombre de cualquier página no sea un segmento de ruta único. Cambie el nombre de esa página primero. Se rechaza la creación o el cambio de nombre de una página con ese nombre. (#42633) Si está actualizando desde una versión anterior a v2.7.0
  • Gráfico de timón: si configura algunas teclas probes, las teclas que no configuró ahora tomarán los nuevos valores predeterminados (período de 10 s, tiempo de espera de 5 s). Si sintonizó failureThreshold para el antiguo período de los 60 s, configure también periodSeconds: 60. Los valores de sonda que no son enteros positivos ahora fallan en helm install y helm upgrade. Los números citados como "5" todavía funcionan. (#42571)
  • navigateTo a un nombre de página que ya no existe ahora falla con "Ingrese una URL o nombre de página válido", incluso cuando el valor de un parámetro contiene un punto. Antes, abría el nombre como una dirección web, como https://OldPage?file=report.pdf. Un host de una palabra como intranet con un parámetro de puntos ahora también falla. Utilice una URL completa en su lugar. (#42513)

🔐 Seguridad

  • Las descargas de tablas CSV ya no permiten que una celda se ejecute como una fórmula de hoja de cálculo. La celda se guarda como texto. Las descargas de Excel no cambian. (#42569)
  • Cambiar quién puede usar una fuente de datos mientras se validan acciones ahora requiere permiso para crear acciones en esa fuente de datos. Crear o actualizar una sola acción ya requería esto. (#42601)
  • La configuración frame-ancestros acepta solo expresiones fuente CSP. Un valor guardado no válido se presenta como 'self'. (#42622)
  • Git escribe y elimina dentro del repositorio de esa aplicación. El nombre de una página debe ser un único segmento de ruta. (#42633)
  • La actualización del mapa de dependencia de una página ahora requiere permiso para editar esa página. (#42642)

🛠️ Confiabilidad

  • El inicio de sesión con código de autorización OAuth2 ahora utiliza el certificado autofirmado de la fuente de datos para el intercambio de tokens. Antes, ese paso ignoraba la configuración y el inicio de sesión fallaba cuando la URL del token usaba un certificado privado. (#42605)
  • Al importar una aplicación ya no se elimina una nueva fuente de datos o biblioteca JS cuando se crean varias al mismo tiempo. (#42612)
  • MCP mantiene una consulta actualizada sobre su propia integración. Ya no mueve la consulta a una fuente de datos de un tipo diferente. (#42620)
  • MCP no agrega valores a las consultas en Redshift o Snowflake, porque esas fuentes de datos no vinculan parámetros. (#42617)

✨ Nuevas funciones y mejoras

  • El cuadro de diálogo de carga de Filepicker sigue el lenguaje HTML de la aplicación. Un idioma vacío o no admitido permanece en inglés. (#42572)
  • El SQL estructurado de MCP puede agrupar fechas por día, semana, mes, trimestre o año en PostgreSQL y Redshift, devolver hasta seis agregados y seleccionar filas distintas. (#42608)
  • El SQL estructurado de MCP puede unir tablas y usar CASE y CON. (#42619)
  • MCP puede copiar una consulta SQL o REST almacenada a otra página o a otra aplicación. El texto de la consulta permanece en el servidor. (#42624)
  • MCP puede crear una consulta de correo electrónico en una fuente de datos SMTP existente. El JavaScript creado por MCP puede formatear una fecha y escribir una entrada de registro. (#42638)

🎨 Mejoras en la interfaz de usuario y los widgets

  • El ingreso de divisas suma el rublo bielorruso (BYN), el bolívar venezolano (VES) y el kwacha zambiano (ZMW). Los códigos más antiguos BYR, VEF y ZMK permanecen en la lista. (#42445)
  • Un grupo de botones con un botón mantiene su radio de esquina en cada esquina. (#42250)
  • Los controles de botón de icono y vídeo en una celda de tabla vuelven a tener 30 píxeles de alto, sin relleno vertical adicional, por lo que el número seleccionado de filas aún cabe. (#42615)
  • Al presionar Enter en un formulario JSON que tiene un campo de texto y ningún botón de envío, ya no se recarga la página. El botón Enviar funciona como antes. (#42607)
  • En un formulario JSON, el botón Radio del borde y los controles de sombra del cuadro resaltan la opción que se guarda. (#42292)
  • Configuración de administrador → La marca ya no ofrece SVG para el logotipo de la instancia. Se aceptan PNG y JPG, que es lo que permite el servidor. (#42637)
