appsmith v2.3

🗑️ Eliminación de funciones - 30 de septiembre de 2026 - EOL

<img width="1213" height="306" alt="imagen (2)" src="https://github.com/user-attachments/assets/5630ce25-4c46-48b8-8fe1-cd8c315d7d77" />

Después de actualizar a la versión 2.3, ya no podrá agregar nuevas conexiones o consultas de fuentes de datos de Appsmith AI. Cualquiera que tenga actualmente seguirá funcionando hasta el 30 de septiembre de 2026. Después de ese tiempo, cualquier fuente de datos de Appsmith AI dejará de funcionar, ya sea que haya actualizado o no.

✨ Nuevas funciones y mejoras

  • Copilot de IA nativo para widgets personalizados: se agregaron capacidades de copiloto de AI nativo a los widgets personalizados. (#42063)
  • Ask AI para la edición comunitaria: trajo el asistente Ask AI a la edición comunitaria. (#42065). https://docs.appsmith.com/build-apps/how-to-guides/use-ask-ai
  • Widget de tarjeta: se agregó un nuevo widget de tarjeta para mostrar entidades con un lienzo de cuerpo componible. (#42026). Puede encontrar más información https://docs.appsmith.com/reference/widgets/card
  • Estilo de etiqueta del widget de botón: se agregaron opciones de estilo de etiqueta al widget de botón. (#41998)
  • Navegación con teclado: se agregó una propiedad tabOrder compartida en los widgets estándar para mejorar la navegación con pestañas del teclado. (#41895)
  • Atributo de lenguaje HTML: se agregó soporte para personalizar el atributo HTML lang. (#41593)
  • Comprobaciones del repositorio de Git: se agregaron comprobaciones de integridad para los repositorios de Git almacenados en Redis. (#41970)

🤖 Mejoras en IA y asistente

  • Tiempo de espera del Asistente de IA: aumentó el tiempo de espera del proveedor del Asistente de IA para mejorar la confiabilidad. (#42096)
  • Comentarios de IA de widgets personalizados: comentarios mejorados y manejo de errores para el Asistente de IA de widgets personalizados. (#42095)
  • Ask AI CE Hardening: se fortaleció la implementación de Ask AI Community Edition luego de la revisión de CodeRabbit. (#42092)
  • Desuso de Appsmith AI: se bloqueó la creación de nuevas fuentes de datos de Appsmith AI y se agregó un banner de desuso. (#42015)

🔐 Seguridad

  • Omisión de autorización de fuente de datos: se corrigió una vulnerabilidad que podría permitir que se reutilicen fuentes de datos ocultas durante las operaciones de importación y bifurcación de aplicaciones. (#42066)
  • Git Import Path Traversal: se evitó el recorrido de ruta basado en enlaces simbólicos durante las importaciones de Git que podría provocar lectura/escritura de archivos arbitrarios. (#41993)
  • Seguridad del grupo de permisos: límites del espacio de trabajo aplicados al asignar grupos de permisos. (#42023)
  • Autorización de fuente de datos: autorización de creación/actualización de acción fija para evitar que los usuarios expongan la fuente de datos privada de otro espacio de trabajo para una ejecución no autenticada. (#42018)
  • Acceso a la red de la fuente de datos: acceso restringido a la fuente de datos a la dirección de red propia de la instancia. (#41985)
  • Seguridad de Frame Ancestors: se eliminó el comodín predeterminado frame-ancestors para evitar políticas de incrustación demasiado permisivas. (#42012)
  • Seguridad del correo electrónico previa a la autenticación: respuestas estandarizadas de puntos finales de correo electrónico de autenticación previa y rutas no utilizadas eliminadas. (#41996)
  • Tenant Endpoint Security: se eliminaron los detalles de configuración interna de las respuestas de los inquilinos para usuarios anónimos. (#42001)
  • Redireccionamiento abierto de inicio de sesión: se evitaron los redireccionamientos abiertos causados por encabezados Origin falsificados durante el inicio de sesión. (#41995)
  • Seguridad del actuador: se evitó la autenticación básica del actuador cuando la contraseña interna no está configurada. (#41964)
  • Verificación SMTP TLS: verificación SMTP TLS mejorada al validar el nombre de host mientras se mantiene la conexión a la dirección validada por SSRF. (#42060)
  • Limitación de velocidad de Caddy: limitación de velocidad mejorada mediante el uso de IP trusted client y la restricción de proxies trusted. (#42071)
  • CVE de servidor y complemento: vulnerabilidades JAR de servidor y complemento identificadas mediante análisis de Docker Scout. (#42074)
  • Actualización de seguridad de npm: npm actualizado a 11.18.0 para abordar la vulnerabilidad crítica DoS node-tar (CVE-2026-59873). (#42064)
  • Actualización de seguridad tar: se actualizó la resolución tar a ^7.5.19 para abordar CVE-2026-59873. (#42034)
  • Actualizaciones de seguridad de dependencia: actualizaciones de dependencia aplicadas que abordan múltiples vulnerabilidades reportadas. (#42091, #42051, #42049, #41969, #41965)

🔧 Git y control de versiones

  • Mensajes de error de Git mejorados: se actualizó el manejo de errores de Git para mostrar la causa real de las fallas en lugar de mostrar un mensaje genérico. (#42053)
  • Optimización de importación de Git: importaciones limitadas de entidades de sucursales hermanas solo a los campos requeridos durante la importación. (#41972)
  • Estabilidad de la versión de Git: se eliminó un controlador Git heredado huérfano que causaba problemas de versión. (#41974)

🎨 Mejoras en la interfaz de usuario y los widgets

  • Permisos de temas de aplicaciones: permiso de edición requerido al leer temas de aplicaciones en modo de edición. (#42090)
  • Posicionamiento del banner: se corrigió el desplazamiento del banner. (#42073)
  • Copiar a la aplicación: se corrigió el desplazamiento desplegable y se mejoró la visibilidad de las notas de la fuente de datos en el modo de copia. (#42007)
  • Widget de tabla: se corrigió el ancho de la columna del botón de menú. (#41948)
  • Enlaces de widgets de texto: se corrigieron los enlaces mailto:, tel: y ftp: que se modificaban incorrectamente. (#41997)

🛠️ Confiabilidad, pruebas y experiencia del desarrollador

  • Interceptaciones Cypress API: se corrigieron los ganchos de intercepción consolidados API que fallaban debido a cy.log. (#42069)
  • Evaluación de Filepicker: parámetros hermanos conservados cuando los datos binarios de Filepicker se pasan a una ejecución de acción. (#42021)
  • Validación de MSSQL: nombres de bases de datos MSSQL rechazados que contienen separadores de cadenas de conexión. (#42077)
  • Intl Linting: se corrigió un error de pelusa falso Intl is not defined. (#42080)
  • Confiabilidad de JDBC: se agregó Hikari keepalive y tiempos de espera de socket limitados para conexiones JDBC. (#41851)
  • Pruebas de configuración de correo electrónico: confiabilidad de la prueba mejorada al esperar el cuerpo HTML del correo electrónico antes de continuar. (#41893)
  • Client Build CI: se evitaron errores de "Lista de argumentos demasiado larga" al determinar los archivos modificados. (#42050)
  • Manejo de errores de MongoDB: manejo mejorado de errores repetidos del conjunto de réplicas de MongoDB al esperar a que se borre el sistema existente antes de volver a verificar. (#41963)

🏢 Permisos y configuración

  • Autorización de confirmación automática: se agregaron comprobaciones de autorización antes de leer la configuración de Auto Commit Pro para los artefactos de destino. (#42083)
  • Seguimiento anónimo: garantizó que la bandera block-anonymous-tracking se respete constantemente tanto en el client como en el servidor. (#41973)
  • Seguimiento de uso: se conserva el ID de usuario anónimo para el seguimiento de uso cuando el segmento está bloqueado para usuarios anónimos. (Número PR no proporcionado)
