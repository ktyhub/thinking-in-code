appsmith v2.4.1

🔐 Seguridad

  • Conexiones JDBC de Databricks: URL de origen de datos de Databricks validadas y conectadas directamente a través del controlador de Databricks, por lo que se rechazan las URL de JDBC que no son de Databricks. (#42244)
  • Se actualizó netty-handler de 4.1.136 a 4.1.137 para abordar CVE-2026-75595. (#42217)
  • Se validaron los nombres de columnas de la cláusula WHERE en el filtrado UQI para que los identificadores untrusted no se puedan usar como nombres de columnas SQL. (#42224)
  • Se utilizó el constructor WebClient reforzado en complementos de IA y Google Sheets. (#42177)
  • Se actualizaron client y las dependencias del servidor para abordar las vulnerabilidades reportadas. (#42214, #42173, #42218)

🛠️ Confiabilidad

  • Se evitó que los complementos OpenAI, Anthropic y Google AI cargaran una copia conflictiva de spring-webflux. Ese fallo podría eliminar las consultas de IA y dañar la conexión compartida Redis. (#42240)
  • Reducción de llamadas redundantes del segmento API. (#42216)

✨ Nuevas funciones y mejoras

  • Se agregó appsmithctl restore no interactivo para la automatización. (#42147)

🎨 Mejoras en la interfaz de usuario y los widgets

  • Se dejó de presentar solicitudes de Anvil bajo "Agentes AI" y se les cambió el nombre a "responsive". (#42219)

🔧 Git, implementación y configuración

  • El servidor MCP ahora prefiere APPSMITH_DB_URL sobre APPSMITH_MONGODB_URI cuando ambos están configurados. (#42239)
  • La imagen base apt se instala resistente a fallas transitorias del espejo. (#42221)
