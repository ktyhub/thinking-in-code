appsmith v2.7.0

⚠️ Notas importantes de actualización

  • Gráfico de timón: si configura algunas teclas probes, las teclas que no configuró ahora tomarán los nuevos valores predeterminados (período de 10 s, tiempo de espera de 5 s). Si sintonizó failureThreshold para el antiguo período de 60 s, configure también periodSeconds: 60. Los valores de sonda que no son números enteros positivos ahora fallan en helm install y helm upgrade. Los números citados como "5" todavía funcionan. (#42571)
  • navigateTo a un nombre de página que ya no existe ahora falla con "Ingrese una URL o nombre de página válido", incluso cuando el valor de un parámetro contiene un punto. Antes, abría el nombre como una dirección web, como https://OldPage?file=report.pdf. Un host de una palabra como intranet con un parámetro de puntos ahora también falla. Utilice una URL completa en su lugar. (#42513)

🔐 Seguridad

  • Dependencias empaquetadas actualizadas para abordar una vulnerabilidad reportada. (#42502)
  • Leer las bibliotecas JS personalizadas de una aplicación ahora requiere acceso de lectura a esa aplicación. (#42431)
  • Activar Hacer que la aplicación se pueda bifurcar ahora requiere permiso de exportación en la aplicación. Los usuarios con acceso de edición aún pueden desactivarlo y realizar otros cambios. (#42411)
  • Las fuentes de datos compatibles con S3 y DynamoDB ahora siguen la política de host restringido que ya cubre REST, GraphQL, Elasticsearch, Redis y SMTP. Una fuente de datos cuyo host de punto final está bloqueado no se puede guardar, probar o ejecutar con Host not allowed. (#42527)

🛠️ Confiabilidad

  • La eliminación de una aplicación conectada a Git regresa tan pronto como se elimina la aplicación. La limpieza del repositorio local se ejecuta después, por lo que un disco lento ya no hace que se agote el tiempo de eliminación y deja la tarjeta de la aplicación en su lugar. (#42519)
  • MCP read_pages devuelve un layoutId para cada página. La verificación de token ya no rechaza las lecturas de páginas paralelas, una lectura fallida se reintenta una vez y una página que aún falla informa el motivo. (#42360, #42529)
  • MCP rechaza entradas que solían dar resultados defectuosos o incorrectos. Ejemplos: llaves desequilibradas en argumentos de llamada de wire_event, una página de otra aplicación en herramientas de diseño y un filtro SQL estructurado en una columna denominada como una palabra clave SQL. (#42536, #42537)
  • Las actualizaciones del diseño de MCP se rechazan cuando la página cambió después de que el agente la leyó. (#42538)

✨ Nuevas funciones y mejoras

  • Altura automática de la tabla: establezca la Altura de la tabla en Altura automática (o Altura automática con límites) y elija Filas por página. La tabla crece para ajustarse a esas filas y la página se desplaza en lugar de la tabla. Las tablas existentes permanecen Fijas. (#42489, #42585)
  • Configuración de la aplicación → Navegación tiene los botones Mostrar compartir y Mostrar todas las aplicaciones para ocultar esos botones en la aplicación publicada. Ambos están activados de forma predeterminada. Los permisos para compartir no cambian. (#42487)
  • La exportación de página (menú de página → Exportar) tiene Seleccionar todo en cada sección: objetos JS, bases de datos, consultas y bibliotecas personalizadas. (#42453)
  • Los botones del grupo de botones pueden mostrar información sobre herramientas, como lo hace el widget de botón. (#42583)
  • El formulario JSON tiene una configuración de Color de fuente del título en Estilo → Color. (#42565)
  • El SQL estructurado de MCP puede mostrar un valor alternativo para una columna NULL con coalesce. (#42497)
  • El SQL estructurado de MCP puede filtrar grupos agregados con having. (#42503)
  • El SQL estructurado de MCP puede dividir una columna delimitada y contar cada elemento, en PostgreSQL. (#42504)
  • MCP get_action devuelve el SQL de una consulta que escribió MCP, siempre que nadie la haya cambiado en el editor. (#42505)
  • La nueva herramienta MCP set_page_visibility oculta o muestra una página. La página de inicio no se puede ocultar. (#42506)
  • Los eventos de navegación de MCP pueden pasar parámetros de URL, como la identificación de la fila seleccionada. (#42507)
  • La eliminación de widgets a través de MCP ahora necesita la aprobación del usuario (prepare_remove_widgets, confirm_remove_widgets), como ya lo requiere la eliminación de una página o consulta. (#42509)
  • Los objetos MCP JS pueden ordenar, cortar, sumar, promediar y agrupar filas, y agrupar fechas por día, semana o mes. (#42511)
  • MCP puede crear formularios condicionales: valores predeterminados y límites que dependen de una elección, matemáticas de fecha, campos mostrados o requeridos en un caso, un botón de envío deshabilitado hasta que el formulario sea válido y el nombre o correo electrónico del usuario que inició sesión. (#42540)
  • MCP puede leer objetos JS escritos en el editor. Cuando se configura la aprobación, puede reemplazarlos después de que el usuario los apruebe. (#42538)
  • MCP escribe objetos JS como código formateado y legible. (#42549)
  • Las consultas estructuradas de MCP producen un cuerpo ejecutable en Oracle y utilizan valores estrictos en las consultas de MongoDB. (#42538)

🎨 Mejoras en la interfaz de usuario y los widgets

  • Las descargas de tablas CSV y Excel escriben texto sin formato para columnas HTML, no HTML sin formato. (#42557)
  • Los controles de botón de ícono, botón de menú y video en las celdas de la tabla se ajustan a la altura de la fila, por lo que las tablas paginadas ya no necesitan una barra de desplazamiento para llegar a la última fila. (#42570)
  • Desactivar el desplazamiento infinito en una tabla ya no activa Permitir agregar una fila, buscar, filtrar y ordenar. Permanecen apagados hasta que los enciendes. (#42573)
  • El campo Desactivado de la columna Guardar/Descartar de tabla muestra su enlace completo nuevamente. Editarlo ya no permite Guardar/Descartar en cada fila. (#42589)
  • Restablecer un formulario JSON mantiene vacío un campo de matriz vacío, por lo que el formulario sigue siendo válido. (#42226)
  • Un campo de fecha obligatorio en el formulario JSON muestra su error solo después de que el usuario lo toca, al igual que otros campos. (#42514)
  • El selector de logotipo del espacio de trabajo ya no ofrece SVG, que el servidor siempre rechazaba. Ahora se pueden seleccionar archivos JPG. (#42594)
  • El editor oculta la fuente de datos de Appsmith AI retirada y sus consultas. El servicio se detuvo el 30 de septiembre de 2026. Ask AI no se ve afectado. (#42559)

🔧 Git, implementación y configuración

  • Las sondas de estado del gráfico de timón ahora se ejecutan cada 10 s con un tiempo de espera de 5 s. El inicio permite que se inicien 600 s, la actividad reinicia el contenedor después de 180 s de falla y la preparación marca el pod como no listo después de 30 s. Guardar la configuración de administrador que reinicia el servidor ya no elimina el contenedor. (#42571)
  • Las copias de seguridad pueden omitir las colecciones de MongoDB enumeradas en APPSMITH_BACKUP_EXCLUDE_COLLECTIONS (separadas por comas). (#42581)
  • El servidor registra por qué rechaza un token MCP, como una clave caducada o revocada. Nunca registra el secreto. (#42593)
