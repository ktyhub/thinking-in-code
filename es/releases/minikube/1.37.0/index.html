Release Note

Versión 1.37.0 - 2025-09-09

Resaltar

Ejecute cargas de trabajo de IA en la GPU de Macbook en Kubernetes usando el nuevo krunkit driver. Comience con nuestro tutorial AI Playground

Características

  • Agregar soporte para Kubernetes v1.34.0 (#21439)
  • Agregue el controlador Krunkit que admite aceleración de GPU en macOS (#20826) Tutorial
  • agregue la abreviatura -m para --memory (#20854)
  • Se agregó soporte al tiempo de ejecución docker para acceso OCI a las GPU NVIDIA (#20959)
  • Agregar el indicador --disable-coredns-log para suprimir los registros de coredns (#20992)
  • nuevo complemento: kubetail (#20345)
  • controladores: agregue soporte para montajes Virtiofs para vfkit y krunkit (#21149)

Mejoras

  • Mejorar el complemento ingress-dns para ipv4 y windows v0.0.4 (#21449)
  • iso: deshabilita el tiempo de espera de grub acelerando el inicio de vm en 5 segundos (#20895)
  • mejorar la confiabilidad del servicio docker, actualizar los archivos systemd de docker (#21174)
  • No requiere ambos --mount para usar --mount-string y eliminar la cadena de montaje predeterminada (#21250)
  • Actualizar las versiones más antiguas compatibles de Kubernetes (#21490)
  • cmd de licencia: no falle si el directorio de salida no existe y descargue primero desde los recursos github (#21206)
  • eliminar el indicador etcd de proxy-refresh-interval v2 obsoleto (#21278)
  • vmnet: soporte de descarga para krunkit (#20831)
  • No llame a startKicServiceTunnel para conductores que no son kic (#20863)
  • krunkit: Desactiva la descarga para una conexión en red más rápida (#21341)
  • HA (avión multicontrol): Actualización de kube-vip de v0.9.1 a v1.0.0 (#20999)(#21228)

Depreciación

  • Desaprobar el controlador HyperKit con advertencia (#21024)

Corrección de errores

  • corrige la versión de confirmación sucia (#21062)
  • Se corrigió la carga de imágenes de minikube en Windows (#20529) (#20921)
  • Se corrigió el montaje en la misma carpeta que causaba un error de entrada/salida (#21077)
  • solución: problema de error de escape de archivo YAML que afecta a los complementos (#20904)
  • iso: Reparar minikube stop con controladores vfkit y krunkit (#21089)
  • iso: Arreglar consola para vfkit/krunkit (#20832)

Complementos

  • Complemento nvidia-device-plugin: actualice la imagen nvidia/k8s-device-plugin de v0.17.2 a v0.17.3 (#21225)
  • Complemento cloud-spanner: actualice la imagen del emulador/emulador de nube-spanner de 1.5.34 a 1.5.41 (#20976)(#21040)(#21243)(#21287)(#21359)(#21512)
  • Faro adicional: actualice la imagen del faro de v0.28.0 a v0.34.0 (#21238)(#21508)
  • Ingreso adicional: actualice la imagen de ingreso-nginx/controlador de v1.12.2 a v1.13.2 (#20909)(#21232)(#21353)(#21458)
  • Complemento inspektor-gadget: actualice la imagen de inspektor-gadget de v0.40.0 a v0.44.1 (#20873)(#21038)(#21240)(#21462)(#21510)(#21358)
  • Complemento Kong: actualice la imagen de Kong de 3.9.0 a 3.9.1 (#20966)(#21503)
  • Complemento Kong: actualice la imagen del controlador de ingreso kong/kubernetes de 3.4.5 a 3.5.1 (#20908)(#20969)(#21034)(#21282)
  • Complemento kubevirt: actualice la imagen bitnami/kubectl de 1.33.1 a 1.33.4 (#20911)(#20939)(#21235)(#21283)(#21414)
  • Complemento metrics-server: Actualizar metrics-server/imagen del servidor de métricas de v0.7.2 a v0.8.0 (#21033)
  • Registro adicional: actualice la imagen del registro de 3.0.0 a 3.0.0 (#21242)
  • Complemento Volcán: actualice las imágenes del volcán de v1.11.2 a v1.12.2 (#20868)(#21351)
  • Complemento kubetail: versión de actualización 0.13.3 (#21244)

Versiones CNI

  • CNI: Actualización de calico de v3.30.0 a v3.30.3 (#20871)(#20971)(#21416)
  • CNI: Actualización del cilio de v1.17.4 a v1.18.1 (#20968)(#21226)(#21349)
  • CNI: Actualización de franela de v0.26.7 a v0.27.0 (#20907)(#21230)(#21504)

Versiones de la imagen base

  • iso: Actualización del kernel a largo plazo a 6.6.95 (#20995)
  • iso: habilite VirtioFS para x86_64 y aarch64 (#21147)
  • iso: mejorar la configuración de compilación y limpieza (#20991)
  • Kicbase/ISO: Actualización de complementos cni de v1.7.1 a v1.8.0 (#21517)
  • Kicbase/ISO: Actualización de crun de 1.19 a 1.23.1 (#21198)(#21330)
  • Kicbase/ISO: Actualización docker de 28.0.4 a 28.4.0 (#21053)(#21248)(#21488)
  • Kicbase: Bump ubuntu:jammy de 20250415.1 a 20250819 (#21233)(#21413)(#21505)

interfaz de usuario

  • rehacer la "lista de perfiles de minikube" para mover los detalles detallados a --det… (#20544)
  • mejorar la descripción larga del indicador de configuración (#21515)
  • Refactorizar la biblioteca de giradores y ocultar los subpasos después de girar (#21215)
  • No mostrar "crear problema github" dos veces si falla kubeadm init (#21263)
  • Representación de tabla de refactorización (#20893)

UI/Traducciones

  • Agregar traducción griega
  • Agregar más traducciones al coreano (#21467)(#21465)
