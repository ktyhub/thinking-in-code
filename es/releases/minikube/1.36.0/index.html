Release Note

Versión 1.36.0 - 2025-05-22

Características

  • Compatible con Kubernetes versión v1.33.1 #20784
  • Nuevo indicador "-f" para permitir pasar un archivo de configuración para el comando de configuración del complemento. #20255
  • vfkit: pasar al controlador preferido en macOS #20808
  • vfkit: nueva opción de red "--network vment-shared" para el controlador vfkit #20501

Corrección de errores:

  • corrige la comprobación de bootpd en macOS >= 15 #20400
  • Corrige error al analizar servidores proxy con guiones #20648
  • Se corrigió la espera de que todos los pods que tienen etiquetas especificadas estén listos #20315
  • solución: imagen final incorrecta que afecta la descarga de activos del formulario kic github #20316
  • corrección: hace referencia a archivos faltantes en el esquema (Cierra #20752) #20761 Mejoras:
  • Comprobaciones adicionales para compatibilidad con 9p #20288
  • vfkit: Apagado elegante al detenerse #20504
  • vfkit: Gestión de estado más robusta #20506
  • vfkit vmnet: admite ejecución sin configuración de sudoers #20719
  • Revertir "corrección: el error de espera no funciona en los pods de Coredns" #20313
