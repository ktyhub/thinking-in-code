Release Note

Versión 1.34.0 - 2024-09-04

Cambios importantes:

  • Mejora la versión mínima de podman a 4.9.0 #19457
  • No permitir el uso de Docker Desktop 4.34.0 #19576

Características:

  • Mejora la versión predeterminada de Kubernetes a v1.31.0 #19435
  • Agregar nuevo controlador para macOS: vfkit #19423
  • Agregue compatibilidad con el controlador Parallels para darwin/arm64 #19373
  • Agregar nuevo complemento de volcán #18602
  • Complementos ingress-dns: soporte agregado para todas las arquitecturas #19198
  • Admite puertos privilegiados en WSL #19370
  • Los controladores de VM con tiempo de ejecución de contenedor docker ahora usan docker-buildx para la creación de imágenes #19339
  • Admite la ejecución de x86 QEMU en arm64 #19228
  • Agregue la opción -o json para el comando addon images #19364

Mejoras:

  • agregar -d abreviatura para --driver #19356
  • agregar -c abreviatura para --container-runtime #19217
  • kvm2: No elimine la red libvirt "predeterminada" #18920
  • Actualizar el uso de MINIKUBE_HOME #18648
  • CNI: Permisos actualizados para admitir políticas de red en kindnet #19360
  • GPU: establezca NVIDIA_DRIVER_CAPABILITIES en all cuando la GPU esté habilitada #19345
  • Mensaje de error mejorado al intentar usar mount en el sistema donde falta 9P #18995
  • Mensaje de error mejorado al habilitar complementos KVM en un clúster que no es KVM #19195
  • Se agregó advertencia al cargar una imagen con el arco incorrecto #19229
  • profile list --output json maneja la carpeta de configuración vacía #16900
  • Verifique la conectividad fuera del minikube cuando la conectividad esté en uso #18859

Errores:

  • Se corrigió que no se creaba el túnel del servidor API para QEMU con red incorporada #19191
  • Se corrigió la espera de la entrada del usuario en el desbloqueo del firewall cuando --interactive=false #19531
  • Se corrigió la verificación de reintento de red cuando la subred ya estaba en uso para podman #17779
  • Se corrigió el tarball vacío al generar la imagen guardada #19312
  • Se corrigió el permiso faltante para la cuenta de servicio kong #19002
