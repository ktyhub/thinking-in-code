Release Note

Versión 1.35.0 - 2025-01-15

Características:

  • Agregue soporte para GPU AMD a través de --gpus=amd #19749
  • Utilice los recursos Github como nueva conmutación por error para la imagen base de kic #19464
  • Compatible con el último Kubernetes v1.32.0 #20091
  • Agrega soporte para kubeadm.k8s.io/v1beta4 (disponible desde k8s v1.31) #19790

Mejoras:

  • Fusionar nvidia-gpu-device-plugin y nvidia-device-plugin. #19545
  • kicbase: Actualizar paquetes de nvidia #19738
  • cilio: elimina appArmorProfile para k8s<v1.30.0 #19888
  • pausa automática: reinicia el servicio después de la configuración #19900
  • Revertir "Cambiar lógica MINIKUBE_HOME" #20045
  • no contamine la lista de perfiles de minikube con errores si el código de salida está ausente #19728
  • consulta de estado del clúster minikube unificado #18998
  • Controlador Vfkit: corrige el error TestMachineType en macOS #19726
  • No más restricciones de arco en nerdctld #19730
  • Coincidencia de direcciones MAC más sólida #19750
  • Agregar instrucciones para resolver el error de contexto docker #19197

Corrección de errores:

  • corrección: el error de espera no funciona en los pods de coredns #19748
  • Soluciona el pánico cuando no hay servicios en el espacio de nombres con --todos especificados #19957
  • corrige el tiempo de espera al detener la máquina KVM con el tiempo de ejecución del contenedor CRI-O #19758
  • Se corrigieron líneas largas en lastStart.txt que no aparecían en las salidas de registro #19740
  • Se corrigió la detección errónea del arco kicbase como incorrecto #19664

Cambios importantes:

  • quitar arm64 kvm #19985 #20062
  • eliminar el complemento helm-tiller #19636

Idiomas:

  • Agregar más traducciones al chino #19490 #19508 #19718 #19962 #19772
  • Mejorar la traducción al francés #19654 #19978
