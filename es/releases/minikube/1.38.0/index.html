#minikube v1.38.0

Release Note

Versión 1.38.0 - 2026-01-28

Destacados

  • No se requiere Sudo para vfkit/krunkit en macOS 26+ (requiere la última versión de vmnet-helper)
  • No se requiere Sudo para ejecutar AI Playground en GPU Macos usando minikube
  • vfkit: agregue compatibilidad con Rosetta para implementar imágenes amd64 en Apple Silicon (#22140)

Características

  • Agregue soporte para Kubernetes v1.35.0 (#21650)(#22015)(#22119)(#22328)
  • Controladores VM: agregue soporte para dispositivos de bloque NVMe-oF/TCP (#22464)
  • Controladores de VM: habilite los símbolos de depuración BTF para admitir herramientas eBPF en iso (#21800)
  • Agregar opción para descargar precargas desde github en lugar de GCS a través de --preload-source (#22221)
  • Controladores Vfkit/Krunkit: agregue la capacidad de ejecutar vmnet-helper como usuario sin privilegios en macOS 26+ (#22501)
  • agregar opción para agregar complementos basados en helm (#21847)
  • precarga: descargar desde github cuando gcs no esté disponible (#21605)

Advertencias y obsolescencias

  • UI: agregue una advertencia sobre el cambio del tiempo de ejecución predeterminado a "containerd" en la próxima versión (v1.39.0) (#22508)
  • hiperkit: elimina compilaciones de controladores y advierte a los usuarios que cambien (#21946)
  • Elimina el soporte de minikube para arquitecturas de 32 bits (#22401)

Mejoras

  • UI: colorida según el estado (lista de perfiles, lista de complementos) (#22418)
  • Omitir archivos binarios de caché cuando se establece --no-kubernetes (#21139)
  • mejorar los registros de reintentos para imprimir menos líneas duplicadas (#22232)
  • mejorar la copia de archivos de certificados de ssh runner (#21923)
  • vmnet: omitir validación en modo de solo descarga (#21635)
  • Mejorar el certificado de Windows en kubeconfig: normalizar las rutas de certificado generadas con barras diagonales (#21845)
  • Agregar verificación del congelador cgroup v2 para verificar el estado del servidor API (#22249)
  • Configure la opción de kubelet FailCgroupV1 para kubenetes 1.35+ si cgroup v1 (#22319)
  • contenedor: reintentar errores EOF transitorios para la carga de imágenes (#22310)
  • cri: aumenta el tiempo de espera predeterminado de 2 segundos para los comandos crictl (#22214)
  • crio: verificar que las imágenes se eliminen después de "image rm" (#22243)
  • Tiempo de ejecución docker: use CRI para la función ListImages (#22263)
  • Guardar imagen: agregue lógica de reintento para la imagen local en caso de EOF (#22072)
  • HA (avión multicontrol): Actualice kube-vip de v1.0.0 a v1.0.3 (#21699)(#21960)(#22258)

Conductores

  • controladores: introduzca WaitForSSHAccess y corrija las pruebas de humo de macOS (#22179)
  • controlador de hiperkit: corrige fugas de descriptores de archivos en el estado (#22524)
  • kvm: arregla minikube en Fedora/RHEL con SELinux (#21550)
  • kvm: elimina la dependencia del controlador externo (#21625)
  • Marcar el controlador paralelo heredado como obsoleto (#22379)
  • ningún controlador: corrige "detener" con tiempo de ejecución en contenedor (#22275)
  • Actualización de los controladores de la máquina minikube (#22369)
  • verificar que los controladores auxiliares estén instalados correctamente y salir correctamente si no es así (#21576)
  • vfkit: agregue compatibilidad con Rosetta para implementar imágenes amd64 en Apple Silicon (#22140)
  • VM: Habilite cgroup v2 usando el "controlador systemd cgroup" para Kubernetes… (#22320)

Corrección de errores

  • Controladores KIC: corrija el controlador docker con crio runtime: instale dbus (#21724)
  • solución: detecta correctamente las máquinas virtuales anidadas en macOS y elimina el multiplicador de tiempo de espera (#22277)
  • solución: aumentar el tiempo de espera para la lista de imágenes contenidas (#22558)
  • solución: complemento kubevirt eliminando la dependencia de curl (#22557)
  • solución: devuelve un código de salida distinto de cero cuando el estado no está disponible (#22494)
  • crio: corrige el ingreso habilitando hostNetwork y ClusterFirstWithHostNet (#22239)
  • crio: corrige la precarga que sobrescribe las imágenes del usuario (#22246)
  • Se corrigió el montaje de Podman en macOS agregando soporte para host.containers.internal (#22451)
  • Se corrigió el script de actualización de la versión cri-dockerd (#22358)
  • corrige la opción de configuración de kubelet FailCgroupV1 a failCgroupV1 (#22325)
  • complemento de registro-creds: corrige el error de segmentación sin el archivo de configuración (#21786)

interfaz de usuario

  • Agregue soporte para el idioma kurdo a través de LANGUAGE=ku (#22512)

  • Agregue soporte para el idioma ucraniano a través de LANGUAGE=uk (#21624)

  • alinear los parámetros del comando para la corrección del patio de juegos de ai (#21583)
