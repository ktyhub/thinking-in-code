Release Note

Versión 1.33.0-beta.0 - 2024-03-26

Características:

  • Admite plano de control múltiple: clústeres HA --ha #17909
  • Complemento gvisor: Agregue soporte para arm64 #18063 #18453
  • Nuevo complemento: YAKD - Complemento de panel de control Kubernetes #17775

Mejoras menores:

  • Pausa automática del complemento: elimina la pérdida de memoria y agrega un intervalo configurable #17936
  • creación de imágenes: agregue docker.io/library a los nombres cortos de imágenes #16214
  • cp: Crear directorio si no está presente #17715
  • Mover los errores al obtener registros a la salida del registro #18007
  • Agregar sysctls predeterminados para permitir puertos privilegiados sin capacidades #18421
  • Incluir atributos extendidos en archivos tar precargados #17829
  • Aplicar etiqueta kubeadm.applyNodeLabels a todos los nodos #16416
  • Limitar la verificación del estado del conductor a 20 segundos #17553
  • Incluir registros de journalctl si el servicio systemd no se inicia #17659
  • ISO: Agregar CONFIG_DM_MULTIPATH #18277
  • ISO: Agregar CONFIG_QFMT_V2 para arm64 #17991
  • ISO: Agregar CONFIG_CEPH_FS para arm64 #18213
  • ISO: Agregar CONFIG_BPF para arm64 #17206

Errores:

  • Corrección "Error al habilitar el tiempo de ejecución del contenedor: sudo systemctl restart cri-docker" #17907
  • Se corrigió la descarga de imágenes existentes en contenedores al inicio #17671
  • Se corrigió que kvm2 no detectaba la precarga en contenedor #17658
  • Se corrigió la modificación de la configuración binfmt de Docker #17830
  • Se corrigió el complemento de pausa automática #17866
  • Se solucionó el problema de no usar la precarga con el controlador de almacenamiento overlayfs #18333
  • Se corrigió que los repositorios de imágenes no permitieran subdominios con números #17496
  • Se corrigió la detención del clúster al usar kvm2 con contenedor #17967
  • Se corrigió el inicio de más de un clúster en kvm2 arm64 #18241
  • Se corrigió el inicio de clústeres kvm2 usando Linux en arm64 Mac #18239
  • Se corrigió el error de visualización al eliminar un clúster no existente #17713
  • Se corrigió que no se respetara el límite al reiniciar #17598
  • Se corrigió que no se aplicaba la etiqueta kubeadm.applyNodeLabels a los nodos agregados después del inicio inicial #16416
  • Se corrigió la salida del delimitador de registros #17734

Actualizaciones de versión:

  • Mejora la versión predeterminada de Kubernetes: v1.29.3 y la más reciente: v1.30.0-beta.0 #17786
  • Complemento cloud-spanner: actualice la imagen del emulador/emulador de cloud-spanner de 1.5.11 a 1.5.15 #17595 #17847 #18165 #18431
  • Complemento gcp-auth: actualice la imagen k8s-minikube/gcp-auth-webhook de v0.1.0 a v0.1.2 #18222 #18384
  • Faro adicional: actualice la imagen del faro-k8s/faro de v0.20.1 a v0.23.0 #17586 #17846 #18320
  • Ingreso adicional: actualice la imagen del controlador/nginx de v1.9.4 a v1.10.0 #17848 #18166 #18284
  • Complemento inspektor-gadget: actualice la imagen inspektor-gadget/inspektor-gadget de v0.22.0 a v0.26.0 #17740 #17885 #18169 #18358
  • Complemento istio-provisioner: actualice la imagen de istio/operador de 1.19.3 a 1.21.0 #17651 #17777 #17957 #18168 #18429
  • Complemento Kong: actualice la imagen de Kong de 3.4.2 a 3.6.1 #17605 #18200 #18350
  • Complemento kubevirt: actualice la imagen bitnami/kubectl de 1.24.7 a 1.29.3 #18170 #18187 #18427
  • Complemento metrics-server: Actualizar metrics-server/imagen del servidor de métricas de v0.6.4 a v0.7.0 #18051
  • Complemento nvidia-device-plugin: actualice la imagen nvidia/k8s-device-plugin de v0.14.2 a v0.14.5 #17623 #18171 #18283
  • Registro de complementos: actualice la imagen k8s-minikube/kube-registry-proxy de 0.0.5 a 0.0.6 #18454
