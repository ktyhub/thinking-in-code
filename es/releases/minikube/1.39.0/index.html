Release Note

Versión 1.39.0 - 2026-09-01

Destacados

  • Agregue soporte para Kubernetes v1.36 y v1.37 (predeterminado: v1.37.0)
  • El tiempo de ejecución del contenedor predeterminado ahora está en contenedor
  • Agregar complemento de ingreso basado en Traefik Helm
  • El controlador VirtualBox ahora es compatible con Apple Silicon (VirtualBox 7.1+)

Características

  • Agregue soporte para Kubernetes v1.36 y v1.37 (predeterminado: v1.37.0) (#23567, #23596)
  • Agregar complemento basado en Traefik Helm (#23225)
  • Agregar Helm al minikube ISO (#23420)
  • Actualice el invitado predeterminado Helm client a Helm 4 (#23383)
  • Agregar servidores DNS configurables para controladores de VM (#23069)
  • Agregue el indicador --mdns para habilitar mDNS en cada inicio de VM (#22964, #23208)
  • controladores: utilice direcciones MAC deterministas (#23172)
  • vfkit: selección automática de red compartida vmnet cuando esté disponible (#23040)
  • virtualbox: Soporta darwin/arm64 con VirtualBox 7.1+ (#22861)
  • ISO: agregue systemd-coredump para seguimientos de pila de fallas (#23064)
  • ISO: habilite kernel nftables (CONFIG_NF_TABLES) para consumidores de knftables (#23518)
  • ISO: Habilitar seguridad para Calico 3.32.2 (#23592)
  • ISO: Incluye módulo de kernel openvswitch para aarch64 (#23151)
  • ISO: habilite CONFIG_TASK_IO_ACCOUNTING y las opciones del kernel relacionadas (#23271)
  • infra: descargue precargas de GitHub de forma predeterminada y GCS como conmutación por error (#23087)

Rendimiento

  • controladores: inicia los controladores de VM en paralelo (#23112)
  • Agregar indicador de inicio --vmnet-offloading para el controlador krunkit (#22962)
  • ssh: Prefiere cifrados AES-GCM para SSH externo client (#23125)
  • ssh: evita el modo de suspensión innecesario cuando se espera el servidor SSH (#23001)

Corrección de errores

  • complementos: soluciona el error de verificación de Helm dentro de las máquinas virtuales invitadas (#23253, #23329)
  • Se corrigió kubectl exec con cri-dockerd en Kubernetes v1.36+ deshabilitando ExtendWebSocketsToKubelet (#22921)
  • Se corrigió --extra-config=etcd.* que generaba una configuración de kubeadm no válida (#23051)
  • Se corrigió la lógica para la advertencia CNI de múltiples nodos. (#22779)
  • Se corrigió SSHRunner ExitCode que siempre devolvía 0 para los comandos SSH (#23364)
  • Se corrigió la cadena de uso para los comandos del nodo minikube. (#22775)
  • kvm: Verifique la membresía del grupo libvirt antes de ejecutar virsh (#23369)
  • Se corrigió la etiqueta de preservación para las referencias de registro con un puerto (#23228)
  • Utilice canales almacenados en búfer para evitar fugas de rutina en el tiempo de espera del estado (#23215)
  • Se corrigió la advertencia contra virtualbox solo cuando la bandera es explícita (#22960)
  • carga de imagen: soluciona un fallo silencioso al cargar una imagen utilizada por un contenedor (#23034)
  • agregar nodo: use sugerenciaMemoryAllocation en lugar de 2200 MB codificados (#23305)
  • proxy: recorra los envoltorios de RoundTripper para eliminar el proxy en el interior *http.Transport (#22910)
  • vmnet: corrige la ruta de instalación de la preparación en Mac Intel y admite la ruta de la bandeja de preparación (#23039)
  • montaje: Aclarar la necesidad de reglas de firewall bidireccionales (#20442)
  • controladores: gestión de concesión de DHCP deduplicada en macOS (#23084)
  • pirateo/actualización: seguimiento del complemento de registro en la etiqueta principal (#23586)
  • piratear/actualizar: actualizar la etiqueta de imagen de kong a 3 (#23585)
  • ISO: Reemplazar espacios con tabulaciones en los archivos del paquete Buildroot nerdctl-bin (#23438)
  • ISO: intento de corregir fallas de compilación ISO (#22879)
  • ISO: Corrige la confiabilidad del script de compilación ISO y el manejo de errores (#23218)
  • ISO: Compatibilidad con la creación de ISO arm64 en un host arm64 (#22862)
  • ISO: use binarios para docker buildx en lugar de compilar desde el código fuente (#22942)

Cambios importantes

  • Cambiar el tiempo de ejecución predeterminado del contenedor a contenedor (#23562)
  • ISO/KIC: limite el soporte para cri-dockerd a x86 y arm64 y migre cri-dockerd a archivos binarios precompilados GitHub (#22922)
