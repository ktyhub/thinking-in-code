Release Note

Versión 1.32.0 - 2023-11-08

Características:

  • Compatibilidad con GPU NVIDIA con el nuevo indicador --gpus=nvidia para el controlador docker #15927 #17314 #17488
  • desarraigado: compatible con --container-runtime=docker #17520
  • Nuevo complemento kubeflow #17114
  • Nuevo complemento local-path-provisioner #15062
  • Kicbase: Agregue la opción no-limit a las banderas --cpus y --memory #17491

Mejoras menores:

  • Hyper-V: Agregar validación de memoria para números impares #17325
  • QEMU: Mejora el tipo de CPU y la detección de IP #17217
  • Enmascarar la contraseña http(s)_proxy de la salida de inicio #17116
  • --delete-on-faliure también recrea el clúster para errores de kubeadm #16890
  • Pausa automática del complemento: configure intervalos usando --auto-pause-interval #17070
  • --kubernetes-version verifica GitHub para validar la versión y mejorar la salida de errores para versiones no válidas #16865
  • Instalar el kit de herramientas del contenedor NVIDIA durante la creación de imágenes (soporte sin conexión) #17516

Errores:

  • QEMU: Se corrigieron los complementos que no podían habilitarse #17402
  • Se corrigió la descarga de imágenes de kubeadm incorrectas para las versiones de k8s después del lanzamiento de minikube #17373
  • Se corrigió la habilitación y deshabilitación de complementos con un clúster no existente #17324
  • Se corrigió la eliminación si el tiempo de ejecución del contenedor no existe #17347
  • Se corrigió que la red no encontrada no se detectara en las nuevas versiones de Docker #17323
  • El registro del complemento reparado no sigue la configuración del nombre de dominio DNS de Minikube (--dns-domain) #15585
  • Se corrigió la opción sin límite para la validación de configuración #17530

Actualizaciones de versión:

  • Mejora la versión predeterminada de Kubernetes: v1.28.3 y la más reciente: v1.28.3 #17463
  • Complemento cloud-spanner: actualice la imagen del emulador/emulador de nube-spanner de 1.5.9 a 1.5.11 #17225 #17259
  • Faro adicional: actualice la imagen del faro-k8s/faro de v0.19.0 a v0.20.1 #17135 #17365
  • Ingreso adicional: actualice la imagen del controlador/nginx de v1.8.1 a v1.9.4 #17223 #17297 #17348 #17421 #17525
  • Complemento inspektor-gadget: actualiza la imagen de inspektor-gadget de v0.19.0 a v0.22.0 #17176 #17340 #17550
  • Complemento istio-provisioner: actualice la imagen de istio/operador de 1.12.2 a 1.19.3 #17383 #17436
  • Complemento Kong: actualice la imagen de Kong de 3.2 a 3.4.2 #17485
  • Complemento kong: actualice la imagen del controlador de ingreso kong/kubernetes de 2.9.3 a 2.12.0 #17526
  • Registro adicional: actualice la imagen del registro de 2.8.1 a 2.8.3 #17382 #17467
  • Complemento nvidia-device-plugin: actualice la imagen nvidia/k8s-device-plugin de v0.14.1 a v0.14.2 #17523
  • CNI: Actualización calico de v3.26.1 a v3.26.3 #17363 #17375
  • CNI: Actualización franela de v0.22.1 a v0.22.3 #17102 #17263
  • CNI: Actualización de kindnetd de v20230511-dc714da8 a v20230809-80a64d96 #17233
  • Kicbase/ISO: Actualización del kit de compilación de v0.11.6 a v0.12.3 #17194 #17486
  • Kicbase/ISO: Actualización en contenedor de v1.7.3 a v1.7.8 #17243 #17466 #17527
  • Kicbase/ISO: Actualizar crictl de v1.21.0 a v1.28.0 #17240
  • Kicbase/ISO: Actualización docker de 24.0.4 a 24.0.7 #17120 #17207 #17545
  • Kicbase/ISO: Actualizar nerdctl de 1.0.0 a 1.6.2 #17145 #17339 #17434
  • Kicbase/ISO: Actualización de runc de v1.1.7 a v1.1.9 #17250
  • Kicbase: Bump ubuntu:jammy de 20230624 a 20231004 #17086 #17174 #17345 #17423
