Release Note

Versión 1.33.1 - 2024-05-13

Errores:

  • Corregir errores DNSSEC validation failed #18830
  • Corregir errores too many open files #18832
  • CNI cilio: Se corrigieron las cápsulas de cilio que no se iniciaban #18846
  • Ingreso de complemento: Se corrigió el error de habilitación en máquinas arm64 usando el controlador de VM #18779
  • Complemento kubeflow: corrige algunos componentes a los que les faltan imágenes arm64 #18765

Actualizaciones de versión:

  • Complemento cloud-spanner: actualice la imagen del emulador/emulador de nube-spanner de 1.5.15 a 1.5.17 #18773 #18811
  • Faro adicional: actualice la imagen del faro-k8s/faro de v0.23.1 a v0.23.2 #18793
  • Ingreso adicional: actualice la imagen de ingreso-nginx/controlador de v1.10.0 a v1.10.1 #18756
  • Complemento istio-provisioner: actualice la imagen de istio/operador de 1.21.1 a 1.21.2 #18757
  • Complemento kubevirt: actualice la imagen bitnami/kubectl de 1.29.3 a 1.30.0 #18711 #18771
  • Complemento nvidia-device-plugin: actualice la imagen nvidia/k8s-device-plugin de v0.14.5 a v0.15.0 #18703
  • CNI cilio: Actualización de v1.15.1 a v1.15.3 #18846
  • Alta disponibilidad: actualice kube-vip de 0.7.1 a v0.8.0 #18774
  • Kicbase/ISO: Actualización docker de 26.0.1 a 26.0.2 #18706
  • Kicbase: Bump ubuntu:jammy de 20240227 a 20240427 #18702 #18769 #18804

Para obtener un changelog más detallado, consulte CHANGELOG.md.
