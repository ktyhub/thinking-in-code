análisis_de_stock_diario v3.16.0

Aspectos destacados de la versión

  • Ventaja: la página de inicio web ha agregado una nueva entrada de activación "Revisión de disco grande", sondeo de tareas y un informe una vez finalizada; el primer estado de configuración de inicio puede generar un espacio y guiarlo a la configuración del sistema.
  • Característica: se agregó una nueva estrategia de enrutamiento de notificaciones, que permite limitar las notificaciones a canales específicos presionando informe, alerta y error del sistema; la página de configuración web admite pruebas con un solo clic de los canales de notificación.
  • Característica: se agregan un nuevo portal de ayuda para elementos de configuración y una infraestructura de redacción de ayuda en varios idiomas a la página de configuración del sistema. El primer lote cubre acciones opcionales, modelo principal de LLM, canal de LLM, Feishu Webhook y dirección de escucha WebUI.
  • mejorar: API, CLI y Bot comparten la ruta de ensamblaje build_market_review_runtime durante la revisión a gran escala, y se completan las instrucciones de reversión de claves heredadas y litellm_model / llm_model_list.
  • mejorar: Se recomienda combinar soporte/presión, volumen, chips y calibración del flujo de capital principal para las operaciones de informes de acciones individuales para reducir el cambio violento de compra/venta y fortalecer la toma de decisiones del Agente.
  • mejorar: la imagen Docker admite la ejecución de usuarios no root y las restricciones de dependencia de LiteLLM se relajan para las versiones posteriores de reparación de seguridad 1.x.
  • solución: Corrija la clasificación incorrecta de Model disabled, proveedor bloqueado, etc. en la prueba del canal LLM para evitar ser reportados falsamente como anomalías de la red.
  • solución: la línea diaria de las acciones de Hong Kong omite la fuente de datos históricos incorporada que no respalda las acciones de Hong Kong; el prefijo BJ de North Exchange y la verificación del código de sufijo .BJ son consistentes.
  • solución: la observabilidad del botón de revisión del mercado web, la detección del proceso de bloqueo de respaldo de Windows y la visualización de pistas catalíticas son más sólidas.
  • documentos: Centro de documentación agregado e instrucciones de mantenimiento de ayuda de configuración, instrucciones de sincronización de documentos/PR temporales limpiadas en README, guía completa y guía de configuración.
