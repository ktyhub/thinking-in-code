análisis_de_stock_diario v3.10.1

Nuevas funciones

  • 🔔 Interruptor de notificación push de análisis del lado web (#808) - Se agrega una nueva casilla de verificación "Notificación push" junto al botón de análisis de la página de inicio, que está marcado de forma predeterminada; cuando no está marcada, Telegram/Enterprise WeChat y otras notificaciones push no se enviarán para este análisis. API POST /api/v1/analysis/analyze Se agregó el campo notify (bool, predeterminado true), el comportamiento cuando no se transmite es el mismo que antes de la modificación, el Bot y las tareas programadas no se ven afectadas.

Mejoras

  • 🖥️ Diseño de página de Chat/Backtest y optimización colaborativa del shell: unifique el contenedor de la página de Chat/Backtest, comparta el estado de la interfaz de usuario y siga la ruta de interacción de preguntas y respuestas, elimine algunas restricciones de altura codificadas y haga que el comportamiento de llenado y desplazamiento en el marco de navegación sea más consistente.
  • 🎨 Las imágenes globales y los componentes compartidos continúan convergiendo: el tema claro presenta un sistema de sombra HSL dinámico, unifica el estado de activación de la barra lateral, el contraste del componente de alarma y el estilo de burbuja de chat, y cierra algunos estilos en línea dispersos en variables CSS semánticas para mejorar la coherencia y la mantenibilidad.

Arreglar

  • 🖼️ Recuperación de selección de archivos de importación inteligente de configuración del sistema: se solucionó el problema por el cual los dos botones "Seleccionar imagen/Seleccionar archivo" en el módulo "Configuración del sistema > Configuración básica > Importación inteligente" dejaban de responder cuando se hacía clic.
  • 🖥️ Desplazamiento del terminal móvil y reparación del nivel de interacción: resuelva el conflicto del índice z donde el menú de cambio de tema está bloqueado por el contenido principal del terminal móvil y restaure el desplazamiento vertical normal en el escenario de informe largo en la página de inicio, sin afectar el comportamiento de desplazamiento existente de otras páginas.
  • 🧾 Mejora de limpieza de copia de texto sin formato con Markdown: mejora el algoritmo de exportación de texto sin formato. Al copiar informes de análisis, los rastros de Markdown, como los separadores de tablas, se eliminarán de manera más estable, lo que mejorará la pureza del contenido compartido y archivado.
  • 🧠 La inyección de filosofía comercial cubre el enlace completo del legado + Agente (#810) - GeminiAnalyzer, el modo de agente único y las indicaciones basadas en habilidades ahora comparten el mismo conjunto de estados de inyección de estrategia; Las antiguas indicaciones basadas en tendencias se conservan solo cuando se recurre implícitamente al valor predeterminado bull_trend incorporado, y la selección de estrategia explícita o las habilidades predeterminadas personalizadas ya no se superponen secretamente con la línea de base alcista MA5>MA10>MA20.
  • 🛠️ Estabilización del enlace de instalación de dependencia de CI de backend (#835) - Divida la etapa de puerta de backend, agregue reintentos para la instalación de dependencias y ajuste la fuente de instalación litellm utilizada por CI a la fuente más estable GitHub para reducir fallas ocasionales de puerta de backend causadas por la fluctuación de la resolución de dependencia.
  • 🪟 La versión de escritorio de Windows restaura la compatibilidad de instalación de LiteLLM — scripts/build-backend.ps1 ahora filtrará el paquete fuente LiteLLM GitHub en requirements.txt, luego descargará el zipball con la etiqueta correspondiente y lo instalará localmente después de eliminar el directorio ascendente opcional enterprise/, evitando la falla causada por confundir el directorio con el empaquetado de archivos cuando Poetry construye la rueda en Windows runner; y también agrega la verificación del código de salida pip install para evitar que las fallas de instalación de dependencias queden expuestas como errores secundarios solo en la fase de verificación posterior de python-multipart.

Prueba

  • 🧪 Finalización de la cobertura de preguntas/pruebas retrospectivas/regresión de importación inteligente: actualice sincrónicamente las expectativas de humo de E2E, complemente DashboardStateBlock, la página de chat, la selección inteligente de archivos de importación y las afirmaciones de regresión interactivas relacionadas para garantizar que la ruta crítica después de los ajustes recientes de la interfaz de usuario aún pueda pasar de manera estable.
