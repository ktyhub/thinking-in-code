daily_stock_analysis v3.7.0

análisis_de_stock_diario v3.7.0

Nuevas funciones

  • 💼 Gestión de posiciones P0 completamente funcional en línea (#677, correspondiente al Issue #627)
    • Libro mayor central y bucle cerrado de instantáneas: agregue nuevas cuentas, transacciones, flujo de efectivo, comportamiento corporativo, caché de posiciones, instantáneas diarias y otros modelos de datos centrales y puntos finales API; admite reproducción con método de coste dual FIFO/AVG; el orden de los eventos del mismo día se fija en 现金 → 企业行为 → 交易; La escritura de instantáneas de posición utiliza transacciones atómicas.
    • Importación de CSV de corredor: admite el primer lote de adaptaciones de Huatai/CITIC/China Merchants, incluida la compatibilidad de alias de listado; interfaz de dos etapas (vista previa del análisis + envío de confirmación); Prioridad trade_uid, deduplicación idempotente de hash de campo clave; Los principales códigos de stock cero se conservan por completo.
    • Informe de riesgo de cartera: riesgo de concentración (posiciones principales + calibre del sector de acciones A), monitoreo de retroceso histórico (admite el relleno de instantáneas faltantes), advertencia de aproximación de stop loss; conversión unificada de múltiples monedas al calibre CNY; cuando la extracción falla, recurra al tipo de cambio exitoso más reciente y marque obsoleto.
    • Página web de posiciones (/portfolio): descripción general de la cartera, detalles de la posición, gráfico circular de concentración, resumen de riesgos, cambio de cartera completa/cuenta única; entrada manual de transacciones/flujos de capital/comportamiento corporativo; entrada de creación de cuenta integrada; Análisis CSV + envío de circuito cerrado y selector de corretaje.
    • Herramienta de posición del agente: se agregó la herramienta de datos get_portfolio_snapshot, resumen compacto predeterminado, detalles de posición opcionales y datos de riesgo.
    • Consulta de evento API: Se agregaron GET /portfolio/trades, GET /portfolio/cash-ledger, GET /portfolio/corporate-actions, que admiten filtrado de fechas y paginación.
    • Registro de analizador extensible: registro compartido a nivel de aplicación, admite el registro en tiempo de ejecución de nuevos corredores; Interfaz de descubrimiento GET /portfolio/imports/csv/brokers recién agregada.
  • 🎨 Sistema de diseño front-end y biblioteca de componentes atómicos (#662)
    • Introducción de una arquitectura progresiva de doble tema (token de diseño variable HSL), limpiando el CSS heredado histórico; refactorización de más de 20 componentes principales como Botón/Tarjeta/Insignia/Plegable/Entrada/Seleccionar, etc.; agregar herramientas de fusión de nombres de clases clsx + tailwind-merge; mejorando la legibilidad del historial, la configuración de LLM y otras páginas.
  • ⚡ Análisis del contrato asíncrono API y optimización de inicio (#656)
    • Estandarizar el contrato de devolución de solicitud asincrónica POST /api/v1/analysis/analyze; optimizar la lógica auxiliar de inicio del servicio; solucione el problema de alineación entre la definición conjunta del tipo de informe de front-end y la respuesta de back-end.

Arreglar

  • 🔔 Compatibilidad con versiones anteriores de variables de entorno de Discord (#659): Se agregó lectura alternativa de DISCORD_CHANNEL_ID → DISCORD_MAIN_CHANNEL_ID durante el tiempo de ejecución; los usuarios de la configuración histórica pueden restaurar las notificaciones de Discord Bot sin modificaciones; todos los documentos relacionados están alineados con .env.example.
  • 🔧 Actualización del Nodo 24 de acciones GitHub (#665): actualice todas las acciones oficiales de GitHub a versiones compatibles con el Nodo 24, eliminando la advertencia de obsolescencia de Node.js 20 en el registro de CI (afecta la ventana de actualización forzada del 2026-06-02).
  • 📅 Localización de la fecha predeterminada en la página de posición: la fecha predeterminada en el formulario de entrada manual se cambia a la hora local (getFullYear/Month/Date) para solucionar el problema de desplazamiento de fecha para los usuarios en la zona horaria UTC-N en la tarde del mismo día.
  • 🔁 Refuerzo de la lógica de deduplicación de importación CSV: el hash de deduplicación incorpora el número de serie de la fila como factor distintivo para garantizar que las transacciones legales separadas en el mismo campo no estén mal plegadas; al mismo tiempo, el hash también persiste cuando existe trade_uid para evitar la escritura repetida desde fuentes mixtas.

Cambiar

  • POST /api/v1/portfolio/trades devuelve 409 cuando trade_uid entra en conflicto dentro de la misma cuenta.
  • Se agrega un nuevo campo sector_concentration a la respuesta al riesgo de posición (expansión incremental) y el campo original concentration permanece sin cambios.
  • Analizar la documentación del contrato de comportamiento asíncrono de la interfaz API analyze; Actualización conjunta del tipo de informe front-end.

Prueba

  • Se agregaron nuevas pruebas de servicio central de posición (venta parcial FIFO/AVG, secuencia de eventos el mismo día, devolución 409 trade_uid repetida, contrato instantáneo API).
  • Se agregó idempotencia de importación de CSV, deduplicación legal de transacciones divididas, límite de deduplicación, límite de umbral de riesgo y pruebas de comportamiento de degradación del tipo de cambio.
  • Se agregó la prueba de llamada a la herramienta Agent get_portfolio_snapshot.
  • Se agregó análisis de la prueba de regresión de contrato asíncrona API.
