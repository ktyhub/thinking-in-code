open-webui v0.10.2

Agregado

  • 💭 Visualización de razonamiento transmitido. Los modelos que emiten pensamientos o razonamientos ahora muestran ese contenido a medida que se transmite y se representa correctamente en la descripción general del chat y en las conversaciones exportadas. Confirmar, Confirmar, Confirmar, Confirmar
  • 🗂️ Carga de carpetas a bases de conocimientos. Al arrastrar una carpeta a una base de conocimientos o sincronizarla, ahora se recrea su estructura de subcarpetas en lugar de aplanarlo todo en archivos sueltos. #26130, Confirmar
  • 🧠 Alternancia de contexto del sistema de memoria. Los administradores ahora pueden mantener las herramientas de memoria disponibles mientras eligen no agregar recuerdos almacenados al contexto del sistema, usando la nueva opción 'Contexto del sistema de memoria' en la configuración de administrador. Confirmar
  • 🧹 Recuerdos automáticos más ordenados. Los recuerdos guardados automáticamente ahora se centran en detalles duraderos como preferencias y objetivos y omiten cosas puntuales como comidas, eventos rutinarios o estados de ánimo pasajeros, a menos que solicites recordarlos. Confirmar
  • 🎙️ Formato de solicitud de voz a texto. La conversión de voz a texto compatible con OpenAI ahora puede enviar audio como una carga de varias partes o base64 JSON, seleccionable en la configuración de audio del administrador. Confirmar
  • 🧰 Configuraciones API a través del entorno. Los administradores ahora pueden establecer configuraciones de Ollama y OpenAI API por conexión a través de las variables de entorno "OLLAMA_API_CONFIGS" y "OPENAI_API_CONFIGS". Confirmar
  • 📡 Eventos de falla del proveedor. Las solicitudes fallidas de proveedor compatible con Ollama y OpenAI ahora emiten un evento estructurado que describe el tipo de error, el proveedor y el estado, lo que brinda a los administradores una visibilidad más clara de las fallas ascendentes. Confirmar
  • 🏟️ Modelos de arena a través del entorno. Los administradores ahora pueden definir modelos de arena de evaluación a través de la variable de entorno "EVALUATION_ARENA_MODELS". #26174
  • ♿ Selección de barra lateral de alto contraste más clara. Con el modo de alto contraste habilitado, el chat seleccionado actualmente en la barra lateral ahora se destaca con colores más fuertes, lo que facilita saber qué chat está activo. #26469, Confirmar
  • 🔄 Mejoras generales. Se implementaron varias mejoras en toda la aplicación para mejorar el rendimiento, la estabilidad y la seguridad.
  • 🌐 Actualizaciones de traducción. Se mejoraron y ampliaron las traducciones para tailandés, portugués (Brasil), catalán y español.

Fijo

  • 🛡️ Aviso de seguridad: esta versión incluye correcciones de seguridad y control de acceso. Recomendamos actualizar las implementaciones de producción lo antes posible. Es posible que no todas las correcciones de seguridad de esta versión se enumeren en la sección corregida; es posible que algunas se retengan durante un breve período para que los administradores tengan tiempo de actualizar. Avisos
  • 🔐 Menos cierres de sesión inesperados. Una sola solicitud que devuelve un error de autorización ya no cierra la sesión mientras su sesión aún es válida, ya que la aplicación ahora confirma el estado de la sesión antes de redirigir para iniciar sesión. Confirmar
  • 🔒 Filtrado de dominios de búsqueda web. Las reglas de permiso y bloqueo de dominios para los resultados de búsqueda web ahora se comparan con el host, cerrando una brecha donde algunas URL podrían pasar el filtro. Confirmar
  • 🕵️ Privacidad del registro de avisos de imágenes. Los flujos de trabajo de generación de imágenes ya no se escriben en los registros del servidor en el nivel de registro predeterminado, lo que mantiene el contenido de avisos creado por el usuario fuera de los registros visibles para el operador. #26400, Confirmar
  • 🗄️ Actualizaciones de bases de datos más seguras. La actualización de una base de datos SQLite existente ya no falla durante la migración de la tabla de usuarios ni corrompe la configuración de usuario guardada, lo que resuelve fallas que podrían bloquear el inicio o interrumpir el inicio de sesión después de una actualización. #26403, Confirmar
  • ⚙️ Guardar la configuración como no administrador. Los usuarios que no son administradores pueden volver a guardar la configuración de su interfaz, como el modelo y el tema predeterminados, que anteriormente fallaron con un error del servidor mientras la interfaz informaba incorrectamente que se había realizado correctamente. #26627, Confirmar
  • 🕒 Marcas de tiempo del chat de la barra lateral. Los chats en la barra lateral ahora muestran cuándo estuvieron activos por última vez en lugar de cuándo se crearon, por lo que la etiqueta de tiempo coincide con su posición en la lista y se actualiza después de cada mensaje nuevo. #26454, #26451
  • 🎯 Modelo predeterminado después de la actualización. El modelo seleccionado ya no se borra cuando recargas la página, ya que la selección del modelo ahora espera a que la lista de modelos termine de cargarse. Confirmar
  • ⏳ Los cuadros de diálogo de herramientas ya no se bloquean. Al descartar un cuadro de diálogo de entrada de función o herramienta mediante clicking fuera de él, ahora se cancela la solicitud pendiente en lugar de dejar el chat girando indefinidamente. #26417, Confirmar
  • 🐍 Carga de ejecución de código confiable. La ejecución de código Python en el chat ahora carga su tiempo de ejecución de manera confiable, solucionando fallas de inicio de sandbox que interrumpieron la ejecución del código y el visor de archivos Pyodide en versiones recientes. #26625, #26390
  • 🤖 Modelos con capacidades nulas. Chatear con un modelo cuyas capacidades no están configuradas ya no falla con un error cuando la función de memoria o las automatizaciones están involucradas. #26412, Confirmar, Confirmar
  • 🔎 Respuestas que se pueden buscar. La búsqueda de chat vuelve a encontrar mensajes del asistente cuyo texto se almacena como salida estructurada, que se omitieron anteriormente. #26405
  • 🔔 Vistas previas de notificaciones de chat. Las notificaciones y los brindis de finalización del chat en segundo plano ahora muestran una vista previa de respuesta limpia en lugar de aparecer en blanco para los mensajes almacenados como salida estructurada. Confirmar
  • 💾 Inicio de banner y configuración. Configurar configuraciones como "WEBUI_BANNERS" ya no provoca un error de inicio, ya que los valores de configuración del administrador ahora se almacenan correctamente independientemente de su tipo de datos. #26431, Confirmar
  • 📑 Visibilidad de la plantilla RAG. El editor de plantillas RAG ahora permanece visible en la configuración de documentos de administración incluso cuando está habilitado Omitir incrustación y recuperación, ya que la plantilla aún se aplica al contenido del documento en ese modo. #26126, Confirmar
  • 🧬 Edición de modelos derivados. La edición de un modelo de espacio de trabajo ya no borra su modelo base, incluso cuando esa base es un ajuste preestablecido o el modelo en sí. Confirmar, Confirmar
