Nota de instalación de macOS

La aplicación aún no está firmada con un ID de desarrollador de Apple, por lo que macOS puede llamar a un compilación descargada "dañada": es la cuarentena de Gatekeeper, no un archivo malo. Después de mover la aplicación a Aplicaciones, borre la marca una vez y luego ábrala normalmente:

xattr -dr com.apple.quarantine "/Applications/OpenHands Agent Canvas.app"

La firma y la notarización se rastrean en OpenHands/OpenHands#16774.
