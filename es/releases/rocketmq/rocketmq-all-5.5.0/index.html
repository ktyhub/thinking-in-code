rocketmq rocketmq-todos-5.5.0

Esta versión presenta el Modo Lite, un mecanismo de suscripción liviano diseñado para escenarios de IA, junto con mejoras en los componentes Broker, Proxy y client.

Nueva característica (modo Lite)

Se introdujo un modo de suscripción liviano (Modo Lite) que ofrece mensajería más eficiente con un consumo de recursos reducido. Este modo proporciona gestión completa del ciclo de vida, envío de eventos, registro de suscripción, procesamiento de mensajes y monitoreo de métricas. Con el procesador de mensajes Lite recientemente agregado, el servicio de sondeo prolongado, el controlador de control y el soporte de protocolo correspondiente, establece un mecanismo de suscripción de mensajes liviano y eficiente diseñado para escenarios de IA.

  • [RIP-83] Tema Lite: Un nuevo modelo de mensaje de @f1amingo en https://github.com/apache/rocketmq/pull/9800
