bootstrap v5.3.3

Parche Publicado20 feb 2024 Fuentetwbs/bootstrap original en inglés

Esta página está traducida automáticamente. El texto original en inglés es la referencia.

arranque v5.3.3

Destacados

  • Se corrigió un cambio importante introducido con los modos de color donde era necesario importar manualmente variables-dark.scss al compilar Bootstrap con Sass. Ahora, _variables.scss importará automáticamente _variables-dark.scss. Si ya estaba importando _variables-dark.scss manualmente, debe seguir haciéndolo ya que no romperá nada y será el camino a seguir en v6.
  • Se corrigió una regresión en el motor de selección que ya no podía manejar múltiples ID.

Modos de color

  • Las insignias ahora utilizan las utilidades de texto .text-bg-* para garantizar que el texto sea siempre legible (especialmente cuando los colores personalizados son diferentes en los modos claro y oscuro).
  • Se corrigió nuestro script color-modes.js para manejar el caso en el que el sistema operativo está configurado en modo claro y se usa el modo de color automático en el sitio web. Si copió el script de nuestros documentos, debe aplicar este cambio a su propio script.
  • Se corrigió la descripción de los esquemas de color en la documentación de modos de color para mostrar que color-scheme() solo acepta valores light y dark como parámetros.

Varios

  • Permitidos <dl>, <dt> y <dd> en el sanitizador.
  • Se redujo la distribución uniforme de elementos para encabezados modales y fuera del lienzo.
  • Se corrigieron los selectores CSS de acordeón para evitar problemas de herencia al anidar acordeones.
  • Se corrigió la sombra del cuadro de enfoque para los controles de formulario indicados de validación.
  • Se corrigió el anillo de enfoque en los botones marcados enfocados.
  • Se corrigió el alternador de barra de navegación móvil de ejemplo de producto.
  • Se modificó el procesamiento RTL de los íconos de control del carrusel.
