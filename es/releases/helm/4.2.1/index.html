timón v4.2.1

Helm v4.2.1 es una versión de parche. Se anima a los usuarios a actualizar para obtener la mejor experiencia.

¡La comunidad sigue creciendo y nos encantaría verte allí!

  • Únase a la discusión en Kubernetes Slack:
    • para preguntas y simplemente para pasar el rato
    • para discutir relaciones públicas, código y errores
  • Pasa el rato en la convocatoria pública para desarrolladores: jueves a las 9:30 hora del Pacífico a través de Zoom
  • Probar, depurar y contribuir con gráficos: ArtifactHub/paquetes

Cambios notables

  • Se corrigió la carrera de datos detectada por el indicador -race cuando las rutinas simultáneas (actualizar + revertir, instalar + desinstalar) llaman a GetWaiterWithOptions en la misma instancia FailingKubeClient #31925
  • Se corrigieron los mensajes de éxito del comando de timón que se escribían en stderr en lugar de stdout. Ahora se envía correctamente a la salida estándar #32056
  • Se corrigió que Helm 4 emitiera "no se puede encontrar la versión exacta" cuando se usaban restricciones de rango de versión #31757
  • Se corrigió una condición de carrera en WaitForDelete donde el observador de estado cancelaba la vigilancia demasiado pronto, causando fallas intermitentes al ejecutar un conjunto de pruebas completo #32081
  • Se cambió golang.org/x/net a v0.55.0 para dirigirse a GO-2026-5026 #32153
  • Se corrigieron errores de SDK al actualizar las dependencias: cli-utils 1.2.1, controlador-runtime 0.24.1 y k8s 1.36.1 #32128
  • Actualizaciones de dependencia
