timón v4.1.3

Helm v4.1.3 es una versión de parche. Se anima a los usuarios a actualizar para obtener la mejor experiencia. Tenga en cuenta que no hubo ninguna versión de 4.1.2 debido a un problema de automatización de versiones. ¡La comunidad sigue creciendo y nos encantaría verte allí!

  • Únase a la discusión en Kubernetes Slack:
    • para preguntas y simplemente para pasar el rato
    • para discutir relaciones públicas, código y errores
  • Pasa el rato en la llamada pública para desarrolladores: jueves a las 9:30 hora del Pacífico a través de Zoom
  • Probar, depurar y contribuir con gráficos: ArtifactHub/paquetes

Cambios notables

  • Se corrigió un error por el cual --dry-run=server no respetaba generateName #31563
  • Se corrigió un error por el cual los recursos CRD vacíos causaban un bloqueo. Ahora imprime un error #31578
  • Se corrigió un error por el cual las referencias OCI con etiqueta+resumen fallaban con el error #31601 de "byte no válido"
  • Se corrigió un error por el cual el valor nulo proporcionado por el usuario no se conservaba cuando el gráfico tenía un mapa vacío o no tenía un valor predeterminado para una clave #31644
  • Se corrigió una regresión desde Helm 3.18.0 donde fallaba la extracción de gráficos de repositorios OCI que usan un índice para almacenar imágenes de contenedor y gráficos de Helm bajo la misma etiqueta #31776
  • Se corrigió una regresión de Helm 4 donde el recorte de espacios en blanco de gotemplate directamente después de los separadores de documentos YAML, cuando estaban presentes después de la posprocesamiento, causaba corrupción del archivo YAML #31868
  • Se corrigió un error por el cual FailedStatus se trataba como un estado terminal, lo que provocaba que las actualizaciones fallaran prematuramente cuando los escaladores automáticos del clúster necesitaban tiempo para aprovisionar los nodos o cuando los pods se eliminaban durante las actualizaciones continuas #31897
  • Se corrigió la compatibilidad con versiones anteriores del indicador obsoleto --atomic en el comando de instalación #31901.
  • SDK: se corrigió un error de 'Acceso definido' de Windows si varios procesos intentaban descargar la misma versión del gráfico al mismo tiempo #31128
  • SDK: Se corrigió un error por el cual los usuarios no recibían ningún registro del camarero, lo que causaba confusión ya que podían pasar varios minutos sin comentarios del usuario #31717
  • SDK: se corrigió un error por el cual los valores predeterminados de aplicación del lado del servidor no siempre coincidían con los valores predeterminados de CLI #31732
  • SDK: se solucionó un problema de importación de Go cuando las herramientas posteriores intentaban enviarse al proveedor helm.sh/helm/v4/pkg/kube #31852
