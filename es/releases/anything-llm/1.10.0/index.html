<img width="2560" height="700" alt="v1 10 0 (1)" src="https://github.com/user-attachments/assets/39285372-787a-4b2d-b493-06e9d8044932" /> ## Cambios destacados ### ¡AnythingLLM Desktop Assistant está disponible! Ahora, AnythingLLM Desktop es un reemplazo directo de herramientas pagas como Granola, Otter, Fireflies y más. - Se ejecuta completamente en su dispositivo, puede grabar reuniones sin unirse o resumir archivos arbitrarios - Desarrollado por la orquestación en el dispositivo de NVIDIA Parakeet + AnythingLLM - ¡Puede llamar a cualquier herramienta de agente, MCP o cualquier otra cosa que ya use con AnythingLLM! - Plantillas de resumen personalizadas, chat con la transcripción e incluso identificación del orador. - Notificación de escritorio "Reunión unida" para iniciar una nueva grabación con un click. Para cualquier software de reuniones (Zoom, Slack, Discord, Teams, etc.) - **Sin límites de tarifas, límites de uso ni restricciones** https://github.com/user-attachments/assets/355ad2fc-cca1-4e9d-8f08-4a1a08dac48d ### AnythingLLM Mobile está disponible en Google Play La [aplicación móvil Android AnythingLLM] (https://play.google.com/store/apps/details?id=com.anythingllm) ya está disponible en Google Play. Esto se sincroniza con las versiones de escritorio y de nube/autohospedado de AnythingLLM. https://github.com/user-attachments/assets/e4232dfa-e42e-4d15-af9e-d58f2f0245f9 ## Otros cambios notables - Se eliminó la página de incorporación "Crear espacio de trabajo" -> ahora va directamente a inicio con un nuevo espacio de trabajo en el idioma nativo del usuario. - Selector de archivos del espacio de trabajo refactorizado para que tenga más rendimiento - Migré Azure OpenAI a `v1` api unificado con soporte completo para agentes. - Se corrigió el error de paginación en paperless-ngx. - Se solucionó el problema por el cual el YouTube API indocumentado cambiaba y rompía el raspador de YT. - Implementé `Cohere` como agente proveedor. - Un aumento de la dependencia. - Se corrigió el error por el cual los archivos XSLX arrastrados y soltados en el chat no eran "visibles" para el modelo. - Correcciones de MCP para rutas en máquinas que no son Windows - Mejoras y parches de imagen Docker para una puntuación Scout saludable (B) - Se agregó un límite de error a la interfaz de usuario para evitar fallas en las páginas blancas. ## ¿Qué ha cambiado? * Mejora la versión del parche
