cualquier cosa-llm v1.16.1

Revisión de la actividad y la cadena de pensamiento

<img width="3680" height="2212" alt="image" src="https://github.com/user-attachments/assets/34e52190-51e3-40b5-baeb-d1936319cb4a" />

Revisamos nuestra interfaz de usuario para tareas de agencia de largo plazo que muestran múltiples pensamientos y llamadas de herramientas para ahora agruparlas en un único elemento de interfaz de usuario limpio y plegable.

Esto le brinda más espacio en pantalla para la respuesta real y, al mismo tiempo, mantiene la pila de llamadas importantes y los pensamientos que produce el modelo en un formato fácil de leer.

Advertencia de navegación

<img width="3680" height="2212" alt="image" src="https://github.com/user-attachments/assets/dfa98c30-4bde-4321-86cc-eb0bcd7b9873" />

Recientemente, agregamos señales de cancelación verdaderas en todos los LLM admitidos para que cuando cancele la inferencia o abandone la página, detengamos la inferencia para ahorrarle costos de computación.

Sin embargo, esto tuvo el efecto secundario no deseado de cancelar la inferencia al salir de un chat, lo que impidió que se completara en segundo plano. Ahora te avisamos antes de abortar la respuesta.

Elemento de la hoja de ruta: Tenemos la intención de hacer que este usuario sea configurable para que pueda personalizar este comportamiento y permitir la inferencia en segundo plano para aquellos con configuraciones más potentes o de alta concurrencia donde son factibles múltiples sesiones de inferencia paralelas.

Foundry Local Embedded (solo escritorio)

<img width="1280" height="720" alt="image" src="https://github.com/user-attachments/assets/d43ba423-83a8-4150-8b62-606ffb6c8882" />

FoundryLocal es un motor de inferencia creado por Microsoft que está preinstalado y disponible en Windows 11 (versión 24H2, compilación 26100 o posterior).

Esto utiliza WinML para cargar modelos para su CPU, GPU o NPU en cualquier configuración de hardware de Windows. Es una excelente opción para configuraciones de hardware para las que no tenemos soporte explícito. Tenga en cuenta que la disponibilidad del modelo puede ser limitada ya que FoundryLocal aún se está implementando. Los modelos Vision no están disponibles actualmente.

Nos asociamos con Microsoft para esto, si tiene errores o problemas podemos ayudarlo a remitirlos al equipo de FoundryLocal

GenieX para Snapdragon (solo escritorio)

<img width="1280" height="720" alt="image" src="https://github.com/user-attachments/assets/866a7cc2-e3e7-4189-af56-6a29c030aab5" />

[!NOTA] Esto reemplaza nuestro motor Snapdragon NPU anterior. Todos los modelos anteriores del motor anterior se eliminan con la actualización y deberá volver a descargar estos modelos optimizados. Debería ver un aumento significativo en el rendimiento de los modelos NPU y GGUF normales.

Recomendamos encarecidamente utilizar únicamente modelos GGUF para este motor. Los modelos exclusivos de Qualcomm NPU tienen ventanas de contexto 4K y darán como resultado una mala experiencia para el agente.

GenieX es un motor de inferencia de código abierto creado por Qualcomm (anteriormente NexaAI) que ejecuta de manera eficiente modelos GGUF y Qualcomm AI Hub en NPU para dispositivos X y X2 Elite.

AnythingLLM ofrece soporte totalmente administrado e integrado seleccionando el proveedor "AnythingLLM GenieX" en el menú desplegable. Tanto los modelos GGUF como los que solo cuentan con NPU pueden aprovechar la NPU, brindándole la eficiencia energética y la inteligencia de ambos.

Nos asociamos con Qualcomm para esto, si tiene errores o problemas, podemos ayudarlo a remitirlos al equipo de GenieX o puede generar un problema en su GitHub. s/o @zhiyuan8, @alexchen4ai y @alanzhuly

Nuevas características

  • [x] Native Foundry Local SDK en Windows (x64/ARM64): el proveedor de Foundry ahora es completamente autónomo y ya no requiere una instalación independiente de Foundry Local, con variantes de modelo optimizadas para GPU/NPU expuestas en el catálogo.
  • [x] Compatibilidad con el tiempo de ejecución GenieX para dispositivos Windows ARM64
  • [x] Compatibilidad con perfiles de inferencia entre regiones de AWS Bedrock: los ID de perfil con prefijo geográfico (us., eu., global.) ahora aparecen en el menú desplegable del modelo y se enrutan correctamente, además de la entrada manual de regiones para regiones fuera de la lista preestablecida (GovCloud, particiones especializadas)
  • [x] LocalAI agregado como proveedor de generación de imágenes, enumerando solo modelos con capacidad de imagen de su servidor
  • [x] Detección automática de la ventana de contexto LocalAI: las ventanas de contexto se leen por modelo desde la configuración de su servidor, y la configuración manual ahora es una anulación opcional
  • [x] Indicadores de instalación y desinstalación silenciosa/sin cabeza para el instalador de Windows; consulte los documentos de instalación de Windows

Mejoras

  • [x] La cadena de pensamiento y la actividad del agente ahora son un único componente plegable: una línea cuando está colapsada, un paso por pensamiento con un riel conectado cuando está expandido y el pensamiento en vivo se muestra en el encabezado durante la transmisión.
  • [x] El nuevo resumen de la cadena de pensamiento ahora se refleja en el Panel Asistente
  • [x] Dejar un hilo o alejarse en medio de una inferencia ahora te avisa antes de que se pierda la respuesta, en lugar de matar silenciosamente a la generación.
  • [x] Foundry Local ya no solicita configuración cuando se utiliza el tiempo de ejecución integrado y carga automáticamente los modelos mediante detección de capacidad.
  • [x] Incorporación de estilo de modo de luz y una interfaz de usuario de selección de LLM rediseñada
  • [x] Beacon ahora representa correctamente los bloques de pensamiento y el formato de rebajas durante la transmisión, con pensamiento plegable y una solución para el desbordamiento del texto de detalle del modelo.
  • [x] El instalador de Windows ahora incluye una imagen del panel de la barra lateral
  • [x] Los borradores de entrada rápida ahora persisten entre la navegación

Corrección de errores

  • [x] Se corrigió un bloqueo de Gemini causado por una discrepancia en la longitud del encabezado del contenido en versiones de undici no fijadas; ahora es compatible con v6 y v7
  • [x] Se corrigió un bloqueo al cancelar una respuesta antrópica (o Bedrock Anthropic) a mitad de camino en el modo chat y luego enviar un seguimiento.
  • [x] Se corrigió una pérdida de memoria de los oyentes de transmisión de abortos filtrados, lo que también provocó que se pausara una respuesta para borrar todo el chat.
  • [x] Se corrigió un error al crear un nuevo espacio de trabajo.
  • [x] Se corrigieron las llamadas a la acción de configuración faltantes en los modales introducidos por el nuevo componente modal uniforme - Configuración de habilidades de trabajo programado en las vistas de categoría y herramienta, clave de conexión de Community Hub y el botón de rechazar funciones experimentales
  • [x] Se corrigió que el cargador intermedio fuera demasiado alto mientras se esperaba una respuesta de capacidad del agente.
  • [x] Se corrigió el borde perdido alrededor del botón Eliminar en Workspace Chats
  • [x] Se corrigió que el razonamiento se atascara en "pensar" cuando un modelo nunca cierra su etiqueta de pensar.
  • [x] Se corrigió que el websocket del agente enviara disparos mientras la conexión aún se estaba abriendo.
