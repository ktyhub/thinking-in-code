nanobot v0.1.4.post2

Parche Publicado24 feb 2026 FuenteHKUDS/nanobot original en inglés

Esta página está traducida automáticamente. El texto original en inglés es la referencia.

#nanobot v0.1.4.post2 🐈 nanobot v0.1.4.post2 está aquí: ¡32 RP fusionados, 14 nuevos contribuyentes! La comunidad está en llamas 🔥 Esta versión se centra en la confiabilidad: un latido completamente rediseñado, almacenamiento en caché rápido para costos más bajos de API, compatibilidad reforzada con proveedores y docenas de correcciones a nivel de canal. Menos sorpresas, más estabilidad.

Destacados

  • Heartbeat Overhaul: se reemplazó la detección de tokens frágiles con un mecanismo de decisión de llamada de herramienta virtual; Los latidos del corazón ahora son verdaderamente silenciosos cuando están inactivos (#1102, #1054, #1039, #1036)
  • Optimización de caché de aviso: el contexto dinámico (hora, sesión) se movió del mensaje del sistema al mensaje del usuario, lo que permite aciertos de caché de aviso persistentes (#1115)
  • Confiabilidad del agente: restricciones de comportamiento, historial completo de herramientas en contexto y sugerencias de errores procesables (#1046)
  • Slack: sesiones aisladas de subprocesos, posprocesamiento de mrkdwn para artefactos en negrita/encabezado, manejo de errores de socket (#1048, #1107, #957)
  • Feishu — Extracción de imágenes de texto enriquecido en mensajes de publicación, descarga de archivos, corrección API (#1090, #986)
  • Correo electrónico: envío proactivo de trabajo incluso cuando la respuesta automática está desactivada, desalojo de deduplicación más inteligente (#1077, #959)
  • Correcciones del proveedor: normalización de DeepSeek reasoning_content, filtrado de bloques de contenido vacío, recarga en caliente de la clave API a través de @property (#947, #955, #949, #1071, #1098)
  • Seguridad — Prevención de cruce de ruta usando relative_to() en lugar de startswith() (#956)
  • MCP: tiempos de espera configurables para evitar que el agente se cuelgue, se eliminaron los valores predeterminados conflictivos para el transporte HTTP (#950, #1062)
  • Memoria: se corrigió el error de tipo cuando LLM devuelve argumentos de dictado durante la consolidación (#1061)
  • Discord: interrumpe el ciclo del indicador de escritura en caso de falla HTTP persistente (#1029)
  • CLI — DingTalk, QQ y correo electrónico agregados a la salida nanobot status (#982)
  • Embalaje: plantillas de espacio de trabajo trasladadas a nanobot/templates/ para un empaquetado de pip adecuado (#1043)
  • Documentos — guía de implementación del servicio de usuario systemd (#968)
