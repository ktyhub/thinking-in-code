nanobot v0.1.4

Parche Publicado18 feb 2026 FuenteHKUDS/nanobot original en inglés

Esta página está traducida automáticamente. El texto original en inglés es la referencia.

#nanobot v0.1.4 🎉 Otro gran lanzamiento de la 🐈 comunidad de nanobots: ¡gracias a todos los contribuyentes, especialmente a los 18 nuevos! Esta versión agrega compatibilidad con el servidor de herramientas MCP, transmisión de progreso en tiempo real para que los usuarios vean realmente lo que está haciendo el agente y una ola de nuevos proveedores (compatible con OpenAI personalizado, GitHub Copilot, OpenAI Codex, SiliconFlow). Los canales también recibieron mucho amor: Telegram ahora maneja cargas de medios y mensajes largos, Slack obtuvo mrkdwn y respuestas de hilos adecuados, Feishu admite texto enriquecido. También agregamos Docker Compose para implementación con un solo comando, sesiones con alcance en el espacio de trabajo y cambiamos a json_repair para un análisis de respuesta LLM a prueba de balas. Menos silencio, más proveedores, mejores canales: ese es el estilo de los nanobots.

Destacados

  • Soporte MCP: conecte servidores de herramientas externos a través del protocolo de contexto del modelo (#554)
  • Transmisión de progreso: el agente muestra lo que está haciendo durante la ejecución de la herramienta de varios pasos (#802)
  • Nuevos proveedores: puntos finales personalizados compatibles con OpenAI, GitHub Copilot, OpenAI Codex, SiliconFlow (#786, #720, #312, #151, #630)
  • Mejoras del canal: carga de medios de Telegram y división de mensajes, respuestas de hilos de Slack y mrkdwn, texto enriquecido de Feishu (#747, #694, #717, #784, #629, #593)
  • Docker Compose: implementación con un solo comando (n.º 765)
  • Sesiones con ámbito de espacio de trabajo: las sesiones ahora se realizan dentro del espacio de trabajo con migración heredada (#713)
  • Análisis robusto de JSON — json_repair para manejar respuestas LLM con formato incorrecto (#664)
