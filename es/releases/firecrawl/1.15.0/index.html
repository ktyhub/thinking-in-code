fuegocrawl v1.15.0

¡Firecrawl v1.15.0 ya está aquí!

  • SSO para empresas
  • Fiabilidad scraping mejorada
  • Parámetros de búsqueda agregados a los registros de actividad.
  • Ejemplo de FireGEO
  • Y más de 50 RP fusionados para errores y mejoras 🔥

Mejoras

  • Soporte OMCE en scrapeURL y transformador HTML
  • Registro mejorado (parámetros de búsqueda, antigüedad de la caché)
  • Nuevo campo created_at en la respuesta /crawl/active
  • Comprobaciones del protocolo URL que no distinguen entre mayúsculas y minúsculas
  • filterLinks portado a Rust

Correcciones

  • Estabilidad del transformador HTML (árabe, etiqueta base, pánico)
  • Error de índice scrapeURL y espera para exclusión
  • Error de facturación de PDF con parsePDF=false
  • El rastreo devuelve solo 1 resultado (caso límite)
  • Error sin secciones del rastreador
  • Nomenclatura del método de registrador
  • Manejo del tiempo de espera en API
  • Resiliencia crawl-status para trabajos expulsados

SDK e infrarrojos

  • Corrección de parámetros de encabezado SDK y manejo de errores asíncronos
  • Puerto Express ahora configurable a través de env var
  • Exención temporal de vencimiento de rastreo

Documentos

  • Actualización de configuración Kubernetes
