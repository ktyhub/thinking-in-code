fuegocrawl v1.12.0

¡Firecrawl v1.12.0 ya está aquí!

  • Nuevo sistema de concurrencia: especifique la concurrencia máxima mediante solicitud para un mejor control. Ver documentos.
  • Rastrear el parámetro de dominio completo: siga los enlaces internos a las URL principales o hermanas, no solo las rutas secundarias (anteriormente enableBackwardLinks). Ver documentos.
  • Google Docs Scraping - Ahora admitimos oficialmente archivos scraping de Google Docs
  • Registros de actividad mejorados - Mejor soporte para solicitudes de FIRE-1. Vea sus registros aquí.
  • /search Playground mejorado - Se agregaron parámetros de ubicación. Mira el patio de juegos.
  • Ejemplo de Firestarter: plataforma de creación de chatbot de código abierto. Repositorio aquí.
  • Además de toneladas de mejoras de rendimiento y correcciones de errores. 

PD ¿Tiene comentarios o ideas para v1.13.0? Pulsa responder y háznoslo saber. Siempre estamos escuchando a nuestra comunidad para crear las funciones que más necesita.

  • hazaña (índice): almacenar títulos y descripciones breves (FIR-2356) de @mogery en https://github.com/mendableai/firecrawl/pull/1677

  • hazaña (estado de rastreo): refactor para que funcione después de un lavado redis (FIR-2271) por @mogery en https://github.com/mendableai/firecrawl/pull/1664
  • corrección (scrape): registra correctamente los créditos FIRE-1 facturados en caso de fallas (FIR-2331) por @mogery en https://github.com/mendableai/firecrawl/pull/1682
