fuegocrawl v2.0.0

Presentamos v2.0.0

Mejoras clave

  • Más rápido de forma predeterminada: las solicitudes se almacenan en caché con maxAge de forma predeterminada en 2 días, y los valores predeterminados sensibles como blockAds, skipTlsVerification y removeBase64Images están habilitados.

  • Nuevo formato de resumen: ahora puede especificar "summary" como formato para recibir directamente un resumen conciso del contenido de la página.

  • Extracción JSON actualizada: La extracción JSON y el seguimiento de cambios ahora utilizan un formato de objeto: { type: "json", prompt, schema }. El antiguo formato "extract" ha cambiado de nombre a "json".

  • Opciones de captura de pantalla mejoradas: utilice el formulario de objeto: { type: "screenshot", fullPage, quality, viewport }.

  • Nuevas fuentes de búsqueda: busque en "news" y "images" además de los resultados web configurando el parámetro sources.

  • Rastreo inteligente con indicaciones: pase un prompt en lenguaje natural para rastrear y el sistema derivará rutas/límites automáticamente. Utilice el nuevo punto final de vista previa de parámetros de rastreo para inspeccionar las opciones derivadas antes de comenzar un trabajo.

Lista de verificación de migración rápida

  • Reemplace el uso de v1 client con v2 clients:
    • JS: const firecrawl = new Firecrawl({ apiKey: 'fc-YOUR-API-KEY' })
    • Python: firecrawl = Firecrawl(api_key='fc-YOUR-API-KEY')
    • API: utiliza los nuevos puntos finales https://api.firecrawl.dev/v2/.
  • Formatos de actualización:
    • Utilice "summary" cuando sea necesario
    • Modo JSON: Utilice { type: "json", prompt, schema } para extracción JSON
    • Captura de pantalla y Captura de pantalla@fullPage: use el formato de objeto de captura de pantalla al especificar opciones
  • Adopte flujos asíncronos estandarizados en los SDK:
    • Rastreos: startCrawl + getCrawlStatus (o crawl camarero) *Lote: startBatchScrape + getBatchScrapeStatus (o camarero batchScrape) *Extracto: startExtract + getExtractStatus (o extract camarero)
  • Mapeo de opciones de rastreo (ver más abajo)
  • Verifique el rastreo prompt con crawl-params-preview

Formatos y opciones de scrape

  • Utilice formatos de cadena para lo básico: "markdown", "html", "rawHtml", "links", "summary".
  • En lugar de parsePDF utilice parsers: [ { "type": "pdf" } | "pdf" ].
  • Utilice formatos de objetos para JSON, seguimiento de cambios y capturas de pantalla:

Formato JSON

 curl -X POST https://api.firecrawl.dev/v2/scrape \
     -H 'Content-Type: application/json' \
     -H 'Authorization: Bearer YOUR_API_KEY' \
     -d '{
       "url": "https://docs.firecrawl.dev/",
       "formats": [{
         "type": "json",
         "prompt": "Extract the company mission from the page."
       }]
     }'

Formato de captura de pantalla

  curl -X POST https://api.firecrawl.dev/v2/scrape \
      -H 'Content-Type: application/json' \
      -H 'Authorization: Bearer YOUR_API_KEY' \
      -d '{
        "url": "https://docs.firecrawl.dev/",
        "formats": [{
          "type": "screenshot",
          "fullPage": true,
          "quality": 80,
          "viewport": { "width": 1280, "height": 800 }
        }]
      }'
