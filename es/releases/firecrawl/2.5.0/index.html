v2.5.0 - Los mejores datos web del mundo API

Ahora tenemos los datos web API más completos y de mayor calidad disponibles gracias a nuestro nuevo índice semántico y nuestra pila de navegador personalizada.

Vea los puntos de referencia a continuación:

<img width="1200" height="675" alt="image" src="https://github.com/user-attachments/assets/96a2ba36-0c7f-4fa3-829e-d6ac91b53705" />

Nuevas características

  • Implementado scraping para archivos .xlsx (Excel).
  • Se introdujo una nueva arquitectura de rastreo y un sistema de seguimiento de concurrencia NUQ.
  • Límite de simultaneidad por propietario/grupo + cálculo de simultaneidad dinámica.
  • Se agregó manejo del trabajo pendiente del grupo y se mejoraron las operaciones del grupo.
  • Se agregó la actualización de precios de /search.
  • Se agregó la bandera del equipo para omitir la verificación del país.
  • Complete siempre las métricas NUQ para mejorar la observabilidad.
  • Nueva aplicación de sitio de prueba para pruebas de CI mejoradas.
  • Extraiga metadatos del encabezado del documento para obtener resultados más ricos.

Mejoras y mejoras

  • Carga de lista de bloqueo mejorada y mensajes de error de sitios no compatibles.
  • Versión x402-express actualizada.
  • Manejo mejorado de includePaths para subdominios.
  • Búsqueda autohospedada actualizada para usar DuckDuckGo.
  • JS y Python SDK ya no requieren la clave API para implementaciones autohospedadas.
  • Mejoras en el manejo del tiempo de espera de Python SDK.
  • Rust client ahora usa tracing en lugar de print.
  • Reducción del ruido en las notificaciones de Slack de recarga automática.

Correcciones

  • Se aseguró que las advertencias de rastreo de robots.txt aparezcan de manera confiable.
  • Se resolvieron puntos muertos de concurrencia y manejo de trabajos duplicados.
  • Se corrigieron los valores predeterminados de los países de búsqueda y los errores de lógica de precios.
  • Se corrigieron conflictos de puertos en entornos de arnés.
  • Se corrigió la compatibilidad con las dimensiones de la ventana gráfica y el comportamiento de las capturas de pantalla en Playwright.
  • Se resolvió la inestabilidad de las pruebas de CI (caché de dramaturgos, pruebas de producción).
