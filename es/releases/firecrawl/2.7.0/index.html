fuegocrawl v2.7.0

¡Firecrawl v2.7.0 ya está aquí!

  • Soporte de búsqueda ZDR para clientes empresariales.
  • Formato de marca mejorado con mejor detección.
  • Integraciones de socios API ahora en versión beta cerrada.
  • Capturas de pantalla más rápidas y precisas.
  • Mejoras autohospedadas

Y muchas más mejoras, ¡compruébalo a continuación!

Nuevas funciones

  • Extracto de marca mejorado
    Mejor detección de logotipos y colores para obtener resultados de extracción de marca más precisos.

  • Sistema de raspado NOQ (experimental)
    Nuevo proceso de scrape con estabilidad mejorada y controles de concurrencia integrados.

  • Manejo de redireccionamiento mejorado
    Las URL ahora se resuelven antes del mapeo, con una detección de cadena de redireccionamiento más segura y nuevos tiempos de espera de cancelación.

  • Parámetros de búsqueda empresarial
    Nuevas opciones de nivel empresarial disponibles para el terminal /search.

  • Creación de usuarios basada en integración
    Ahora se pueden crear usuarios automáticamente cuando provienen de integraciones de referencia.

  • Parámetro de raspado minAge
    Permite exigir una antigüedad mínima en caché antes de volver a escribir aping.

  • Extraer créditos de facturación
    Los trabajos de extracción ahora utilizan el mismo sistema de facturación de crédito que otros puntos finales.

  • Autohospedaje: simultaneidad de rastreo configurable
    Las implementaciones autohospedadas ahora pueden establecer límites de simultaneidad personalizados.

  • Mejoras de Centinela
    Se agregó integración de Vercel AI, velocidades de muestreo configurables y filtrado de excepciones mejorado.

  • ID UUIDv7
    Todos los recursos nuevos utilizan UUIDv7 ordenable lexicográficamente.

Mejoras API

  • Los errores de resolución de DNS ahora devuelven 200 para un manejo de fallas más consistente.
  • Lógica de mapeo de URL mejorada que incluye correcciones de mapas de sitio maxAge, compatibilidad con mapas de sitios recursivos, normalización de enrutadores Vue/Angular y omisión de lógica de subdominio para direcciones IP.
  • Resultados parciales de la búsqueda de múltiples fuentes en lugar de fallar en todas las fuentes.
  • Metadatos de simultaneidad agregados para eliminar las respuestas de los trabajos.
  • Métricas mejoradas que incluyen tiempo de espera total, uso de LLM y detalles de formato.
  • Actualizaciones de raspado por lotes
    • Se agregó el punto final /v2/batch/scrape/:jobId/errors que faltaba
    • Se corrigió el error de paginación uno por uno.
  • Manejo de errores más sólido para motores de documentos/PDF, análisis pydantic, validación Zod, validación de URL y casos extremos de facturación.

Mejoras SDK

JavaScript SDK

  • Devuelve ID de trabajo de métodos sincrónicos.
  • Manejo mejorado del evento WebSocket document.
  • Se corrigieron tipos, Deno WS y se agregó soporte para ignoreQueryParameter.
  • Versión de tope con limpieza interna.

Python SDK

  • Se agregaron campos de metadatos adicionales.
  • Manejo mejorado de validación de lotes.

Calidad y rendimiento

  • Tamaño del archivo de registro reducido y limpieza de archivos tmp mejorada.
  • Versión Express actualizada y paquetes vulnerables parcheados.
  • Conversión de rebajas deshabilitada para raspados de mapas del sitio para mejorar el rendimiento.
  • Mejor registro y formateo previo al rastreo.
  • Omitir la reescritura de URL para Google Docs publicados.
  • Evitar encabezados de cookies vacíos durante las devoluciones de llamadas de webhooks.

Mejoras autohospedadas

  • Aplicación de límite de simultaneidad deshabilitada para el modo autohospedado.
  • Las credenciales de PostgreSQL ahora se pueden configurar mediante variables de entorno.
  • Se corrigieron las instrucciones de compilación de composición de Docker.
