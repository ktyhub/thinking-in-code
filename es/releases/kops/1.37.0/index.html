kops v1.37.0

Consulte el kOps 1.37 release notes completo para obtener más detalles, incluidos los cambios importantes y las obsolescencias.

Destacados

  • Soporte Kubernetes 1.37, con etcd 3.7.3 como valor predeterminado para los clústeres Kubernetes 1.37
  • Repositorios de activos privados en almacenamiento de objetos en la nube: URL de s3://, gs:// y azureblob:// para KOPS_BASE_URL y spec.assets.fileRepository, con nodos que se autentican a través de su identidad de instancia
  • Arranque de nodo más pequeño y resistente: la descarga del nodo cae de aproximadamente 120 MB a menos de 10 MB, a través de una compresión binaria y xz más pequeña, y los reintentos de arranque fallan en las tareas
  • Tiempo de ejecución del contenedor: 2.3.6 en contenedor y runc 1.5.1 de forma predeterminada, con configuración en contenedor versión 4; Las versiones en contenedor anteriores a 2.1.0 ya no son compatibles.
  • Expansión de Karpenter: Karpenter v1.15.1, manejo de interrupciones administrado por kOps (cola SQS y reglas de EventBridge), configuración de volumen raíz en EC2NodeClass, compatibilidad con instanceRequirements y grupos de instancias mixtos con y sin GPU
  • Permisos de AWS IAM más limitados para los roles de instancia (Route 53, KMS, EC2, SQS) y sin políticas integradas para roles que no necesitan permisos
  • cambios en etcd-manager: imágenes etcd empaquetadas montadas como volúmenes de imágenes y compatibilidad con versiones personalizadas de etcd a partir de una imagen proporcionada por el usuario en nuevos clústeres
  • Redes: Calico v3.32.3 con el cambio a ClusterNetworkPolicy, compatibilidad con políticas de red para AWS VPC CNI, kube-router v2.12.0 con un backend de políticas de red experimental de nftables y kindnet v1.0.3
  • Azure: solicitudes de arranque autenticadas con metadatos de instancia firmados, detección kops rolling-update cluster de máquinas virtuales obsoletas y dos réplicas de administrador-controlador de nube en planos de control de alta disponibilidad.
  • Akamai (Linode): el proveedor experimental ahora administra claves SSH, redes, subredes, instancias y volúmenes de almacenamiento en bloque.
  • Actualizaciones de componentes: etcd-manager v3.0.20261022 con etcd 3.5.35/3.6.16/3.7.3, Cilium v1.18.16, AWS VPC CNI v1.23.2, CoreDNS v1.15.0, AWS Load Balancer Controller v3.6.2, cert-manager v1.21.3, cluster-autoscaler v1.37.0
  • Eliminado: compatibilidad con Kubernetes 1.31, Gossip DNS (y protokube), AWS Classic Load Balancers para API y redes Kopeio. Migre con kOps 1.36 antes de la actualización
