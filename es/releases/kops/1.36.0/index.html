kops v1.36.0

Consulte los kOps 1.36 release notes completos para obtener más detalles, incluidos los cambios importantes y las obsolescencias.

Destacados

  • Soporte Kubernetes 1.36 y finalización del alejamiento de los proveedores de nube dentro del árbol
  • Administración de complementos reelaborada: kops-channels ahora se ejecuta como un módulo estático en nodos del plano de control; el binario independiente channels ya no se distribuye
  • Arranque híbrido para clústeres de chismes: los trabajadores arrancan directamente contra el balanceador de carga API, lo que facilita la migración del DNS de chismes, que está en desuso.
  • Actualización de Karpenter: Karpenter v1.13.0 con objetos EC2NodeClass y NodePool administrados por kOps por grupo de instancias
  • mejoras de etcd-manager: recuperación de miembros con discos de datos reemplazados, cambios de membresía resistentes a miembros inalcanzables, una imagen sin distribución y un inicio de clúster de un solo miembro más rápido
  • Soporte de Azure ampliado: administrador de controlador de nube, controlador CSI de Azure Disk y destino Terraform experimental
  • Soporte de Hetzner Cluster Autoscaler y trabajo preliminar para Linode (Akamai) como nuevo proveedor de nube
  • Actualizaciones de componentes: contenedor v2.2.4, etcd-manager v3.0.20260707 con etcd 3.5.31/3.6.12, controlador AWS Load Balancer v3.3.0, Cilium tunables, CoreDNS v1.14.2, cluster-autoscaler v1.36.0
  • Eliminado: soporte para Kubernetes 1.30, etcd 3.4, Amazon Linux 2, Ubuntu 20.04 y Debian 10
