Bienes y procedencia

Binarios para 8 objetivos más el paquete de modelos XERJ Query-1:

  • xerj-1.0.0-rc.101-<target>.tar.gz / .zip (+ .sha256), .deb para los dos destinos Linux-gnu.
  • xerj-model-bundle-v1-v1.0.0-rc.101.tar.gz (+ .sha256): el paquete XERJ Query-1 (candidate_a_s47, FP16, sirvió como int8 en la CPU). Habilitar con xerj --facts-model-dir <DIR>; sin la bandera el nodo es rc.100. Instale ambos en un solo paso: curl -fsSL https://xerj.org/get | sh -s -- --with-model.

Procedencia: los archivos binarios de esta versión se crearon a partir de un árbol privado (main público en 3f6aefa8 + las líneas de almacenamiento/ingesta/hechos de XERJ-R + las cajas modelo patentadas xerj-infer/xerj-serve/xerj-exec, que se envían como binario + paquete únicamente y no están en este repositorio). Los seis recursos x86_64/macOS/Windows se crearon de forma cruzada mediante el flujo de trabajo del lanzamiento; Los dos activos de Linux aarch64 se crearon de forma nativa en un host aarch64 a partir de la misma etiqueta después de que los ejecutores de compilación cruzada ARM de GitHub se cerraran a mitad del trabajo dos veces. Cada activo lleva su SHA-256. Limitaciones conocidas (medidas): el conteo se refiere únicamente a hechos que contienen subject_id y cubre conteos establecidos, no sumas; un conteo cuenta el conjunto coincidente y no verifica el sustantivo de la pregunta (una pregunta de cantidad sobre una relación de la que carece la tienda puede servir como un conteo de miembros); el modelo over-declines (383 de 1.600 artículos de evaluación estándar). Detalles: docs/FACTS_API.md, docs/XERJ_QUERY_1.md.

Problema conocido (opción de almacenamiento opcional): con source_ref habilitado, una búsqueda que lee texto de un archivo fuente editado puede devolver el texto antiguo en lugar del error "archivo cambiado" cuando la edición mantiene el mismo tamaño del archivo (intermitente, 2 de 3 ejecuciones aisladas). El diseño predeterminado almacena texto en el índice y no se ve afectado. Seguimiento para rc.102.
