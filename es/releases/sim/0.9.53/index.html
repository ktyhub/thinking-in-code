sim v0.9.53

Características

  • hazaña (credenciales): configure credenciales sin llave desde v2 API, CLI y Sim MCP (#9875)
  • hazaña (credenciales): Snowflake sin llave, solo aplicación de Microsoft y sin llave de Google, tokens GitHub y Bitbucket, DocuSign JWT (#9869)
  • hazaña (mistral): extrae imágenes PDF como archivos y expone el formato de tabla en Mistral Parser (#9856)
  • Hazaña (api): ejecuta una versión de implementación fijada y expone los puntos de ejecución en pausa en v2 (#9854)
  • hazaña(api-keys): claves API de solo lectura y caducidad en el momento de la creación (#9855)
  • Hazaña (api): salud y habilitación del activador del flujo de trabajo a través de la versión 2 API (#9853)
  • hazaña (red): respetar HTTP_PROXY, HTTPS_PROXY y NO_PROXY para solicitudes protegidas, AWS SDK clients y exportación OTLP (#9851)
  • hazaña (credenciales): credenciales guardadas para 21 bloques de token y host en una fábrica de cheques compatible con el host (#9849)
  • Hazaña (api): administra los miembros del espacio de trabajo a través de v2 API (#9852)
  • hazaña (credenciales): credenciales guardadas para 17 bloques más, tokens GitLab y refuerzo sin llave (#9840)
  • hazaña (búsqueda): administrar permisos de origen a través de un API y CLI compartido (#9845)
  • Hazaña (búsqueda): actualice los archivos CSV de permisos GitLab a través de API (#9841)
  • hazaña (biblioteca): Empresa de desarrollo de agentes de IA versus construcción interna: cómo decidir (#9844)
  • hazaña (biblioteca): Las mejores plataformas de agentes de IA que admiten el protocolo A2A en 2026 (n.º 9843)
  • hazaña (biblioteca): creadores de agentes de IA con herramientas de investigación y búsqueda web integradas en 2026 (n.º 9842)
  • hazaña (credenciales): credenciales guardadas y versiones de bloques de solo credenciales, con OIDC de AWS/Databricks sin llave (#9763)

Mejoras

  • mejora (api): seguimientos de auditoría de lanzamiento para análisis de miembros v2, middleware de acceso al flujo de trabajo y documentos (#9858)
  • mejora (búsqueda): devuelve una ventana de lectura en vivo más larga cuando un MCP client solicita más fragmentos (#9823)

Corrección de errores

  • corrección (credenciales): corrija las instrucciones de configuración sin llave y aplique el contrato de credenciales guardadas en cada bloque de credenciales (#9878)
  • corrección (mistral): digamos que V3 analiza un PDF cargado o referenciado y vincula el máximo de imágenes a 100 (#9872)
  • corrección (lanzamiento): host_not_allowed para hosts rechazados, liberación secreta interna solo de JWT y limpiezas de auditoría de liberación final (#9870)
  • corrección (sim-setup): impide que doctor --fix convierta las referencias de ${VAR} en literales (#9868)
  • corrección (credenciales): informar un host rechazado como entrada del usuario, persistir los identificadores de cuenta normalizados, limitar las lecturas de Databricks (#9859)
  • solución (versión): unicidad de sujeto sin clave, NO_PROXY IPv6/CIDR, secreto de arranque mediante proxy y seguimientos de auditoría restantes (#9866)
  • solución (lanzamiento): pequeñas limpiezas de auditoría de lanzamiento (#9863)
  • solución (lanzamiento): reutilice solo claves de delegación de acceso completo y trate una profundidad de rastreo en blanco como no configurada (#9857)
  • solución (seguridad): fortalece las rutas de credenciales guardadas, salida de proxy y menta sin llave desde la auditoría de lanzamiento (#9865)
  • solución (versión): redactar claves de implementación, verificar herramientas respaldadas por operaciones en el contrato de credenciales guardadas y eliminar copia SDK (#9864)
  • corrección (lanzamiento): ejecuta versiones asíncronas fijadas en sus propias variables, asigna errores de creación de claves CLI, muestra tokens GitLab como el bloque actual (#9862)
  • corrección (sim-setup): cita los valores env que contienen $ para que dotenv, Bun y Compose no los expandan (#9861)
  • solución (versión): limita las respuestas http simples con proxy, cuenta la profundidad de Firecrawl desde la URL de inicio y elimina el caché de ruta obsoleto al actualizar (#9860)
  • corrección (firecrawl): respuesta v2 completa y compatibilidad profunda (#9847)
  • corrección (cli): vincula los contenedores de sim-setup al loopback, corrige el reinicio y las cotizaciones env, retira el simstudio heredado CLI (#9830)
  • solución (docker): mantiene la capacidad de escritura en cachés de listas de sufijos e ISR en una raíz de solo lectura (#9829)

Otros cambios

  • prueba (api-keys): use un nombre de rol de base de datos neutral en el dispositivo de error interno (#9877)
  • prueba (credenciales): use un dispositivo GitHub sin forma de token para que el escaneo secreto permanezca silencioso (#9876)
  • documentos (versión): corrige la nota de la lista de permitidos de Discord, el nombre de la imagen de Mistral y la referencia NO_PROXY (#9874)
  • Documentos (habilidades): nombrerechazarUnsafeTypedUrl en los pasos para agregar credenciales de token de integración (#9873)
  • tarea (sdk): use una familia de lanzamientos en vivo como elemento de lanzamiento no relacionado de la fuente de escritorio (#9850)
  • tarea (sdk): retire los TypeScript y Python SDK (#9848)
  • tarea (departamentos): tome vitest 5.1, shiki 4.6, react-hook-form 7.91, MCP SDK 2.4 y pequeñas actualizaciones dentro del rango (#9846)
  • tarea (departamentos): actualizar pi a 1.5.0 (#9826)
  • ci: desplaza el grupo de acciones en 2 directorios con 7 actualizaciones (#9839)
