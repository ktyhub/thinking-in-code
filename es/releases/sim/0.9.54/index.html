sim v0.9.54

Características

  • Hazaña (aws-marketplace): incluya Enterprise en la licencia de contenedor de AWS Marketplace y agregue el perfil de instalación de EKS (#9917)
  • hazaña (credenciales): correcciones de auditoría y autenticación no OAuth para CrowdStrike, Datadog, Gong, PlanetScale, SailPoint, ServiceNow, Zendesk, ZoomInfo, Shopify, Atlassian, Linear y Twilio (#9911)
  • Hazaña (api): bloqueo fallido en ejecuciones sondeadas, esquema de entrada implementado, lista de ejecuciones en pausa y límites aplicados (#9906)
  • Hazaña (api): esquema del flujo de trabajo, lista de cronogramas del espacio de trabajo, errores v2 más claros y tipos de valores del catálogo (#9905)
  • Hazaña (api): identidad del agente en meta v2, claves de emparejamiento CLI con alcance y cambio de nombre del espacio de trabajo v2 (#9904)
  • Hazaña (tabla): agregue columnas para regresar a las filas de consulta del bloque de tabla heredado (#9887)
  • hazaña (biblioteca): Los mejores agentes de inteligencia artificial para análisis de hojas de cálculo en Excel y Google Sheets (#9886)
  • hazaña (biblioteca): Los mejores agentes de IA para solicitudes de extracción, clasificación de problemas y revisión de código de GitHub (#9884)
  • hazaña (biblioteca): Las mejores plataformas de agentes de IA para equipos de recursos humanos que responden a las preguntas de los empleados (n.º 9883)

Mejoras

  • refactor(credenciales): resuelve tokens Vanta a través del solucionador coordinado de tokens client (#9919)
  • mejora (tabla): documenta que una selección de columna que no coincide con ninguna columna devuelve datos de fila vacía (#9915)

Corrección de errores

  • corrección (credenciales): desalojo del token age-gate 403 y ordenación de las rutas de credenciales client (#9918)
  • corrección (api): atribuye el error de una ejecución encuestada solo al bloque que la causó (#9916)
  • corrección (credenciales): coincide con JSON 403 sin distinguir entre mayúsculas y minúsculas y rechaza un token de acceso ZoomInfo con formato incorrecto (#9914)
  • solución (seguridad): rechaza una barra diagonal adicional después de https:// en las URL base escritas (#9913)
  • corrección (api): seguimientos de auditoría de lanzamiento para el trabajo del agente API (#9910)
  • corrección (http): siga desenvolviendo sobres de éxito heredados para flujos de trabajo existentes (#9909)
  • corrección (selectores): redactar segmentos de ruta de correo electrónico de los registros de fallas del proveedor; Guía correcta sobre el tiempo de espera de la tabla (#9908)
  • solución (flujos de trabajo): rechazar ediciones de operaciones que sobrescribirían un cambio simultáneo (#9902)
  • corrección (chat): vuelve a poner en línea el chat de un flujo de trabajo restaurado cuando se reinicia (#9888)
  • corrección (http): dejar de tratar 200 cuerpos con claves de estado y datos como respuestas proxy (#9889)
  • corrección (tablas): muestra errores de filtro rechazados en la cuadrícula y completa las importaciones hasta el límite de filas (#9881)
  • corrección (errores): tiempos de espera de lectura de tablas procesables, 409 para herramientas personalizadas duplicadas, revocación de Instagram, registros de fallas del selector (#9880)

Otros cambios

  • tarea(deps): comentarios ordenados y anulación del orden del barrido de dependencias (#9907)
  • docs(api): guía para crear y ejecutar flujos de trabajo con API (#9901)
  • tarea (departamentos): actualizar dependencias menores y de parches más allá de la fecha de lanzamiento (#9894)
  • tarea (departamentos): subir el turbo a 2.11.10 (#9903)
  • tarea (departamentos): pasar AWS SDK a 3.1162.0, OpenTelemetry a 0.223.0/2.12.0 y @daytona/sdk a 0.227.3 (#9900)
  • tarea (departamentos): actualizar docx a 9.15.2 (#9895)
  • tarea (departamentos): pasar mdast-util-to-markdown a 2.2.2 (#9899)
  • tarea (deps): pase tiptap a 3.32.2 y mantenga los encabezados que abren un elemento de la lista (#9898)
  • tarea (deps): corte de golpe a 6.44.1 (#9896)
  • tarea (departamentos): avance hacia 2.7.1 (#9897)
  • tarea (departamentos): pasar el generador de electrones a 26.18.0 (#9893)
  • tarea (departamentos): actualizar monaco-editor a 0.57.0 (#9892)
  • tarea (departamentos): actualizar cronstrue a 3.38.0 (#9891)
  • documentos (biblioteca): actualizar postgres-mcp-server-ai-agents (#9885)
  • documentos (biblioteca): actualización de best-ai-agents-sales-crm-automation (#9882)
  • tarea (teclas api): elimina el indicador de solo lectura de clave api ahora que las claves de solo lectura están activas (#9879)
