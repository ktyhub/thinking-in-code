skywalking v9.6.0

caminata aérea v9.6.0

Descargar

https://skywalking.apache.org/downloads/

Aviso

No descargue códigos fuente de esta página. Siga [documento de compilación] (https://github.com/apache/skywalking/tree/master/docs/en/guides/How-to-build.md#build-from-github) si desea crear códigos fuente usted mismo.

Nuevo kernel de alertas

  • Se admiten MQE (Metrics Query Expression) y un nuevo mecanismo de notificación.

Soporte Loki LogQL

  • Soporte recientemente agregado para Loki LogQL y Grafana Loki Dashboard para registros recopilados de SkyWalking

ADVERTENCIA

  • Se eliminan las pruebas relativas al almacenamiento de ElasticSearch 6. Funcionó y no está prometido debido al final de su vida útil oficialmente.

Proyecto

  • Aumente Guava a 32.0.1 para evitar que la biblioteca aparezca como vulnerable debido a CVE-2020-8908. Este API nunca se utiliza.
  • El artefacto Maven skywalking-log-recevier-plugin pasa a llamarse skywalking-log-receiver-plugin.
  • Aumente la versión cli de 0.11 a 0.12.
  • Actualice la versión de ASF parent pom a v30.
  • Hacer que las compilaciones sean reproducibles para lanzamientos automáticos de CI.

Servidor OAP

  • Agregue el idioma ID del componente Neo4j (112): Python.
  • Agregue el registro Istio ServiceEntry para resolver IP desconocidas en ALS.
  • Envuelva deleteProperty API en BanyanDBStorageClient.
  • [Cambio importante] Elimina matchedCounter de HttpUriRecognitionService#feedRawData.
  • Elimine patrones de HttpUriRecognitionService#feedRawData y agregue un máximo de 10 candidatos de URI sin procesar para cada patrón.
  • Agregar ID de componente para WebSphere.
  • Se corrigió el almacenamiento en caché de uri de AI Pipeline NullPointer y las excepciones de argumentos ilegales.
  • Se corrigió NPE en la consulta de métricas cuando la métrica no existe.
  • Elimine las pruebas E2E para Istio < 1.15, ElasticSearch < 7.16.3; es posible que aún funcionen, pero no son compatibles según lo previsto.
  • Desplácese por todos los resultados en el almacenamiento ElasticSearch y refactorice las lógicas de desplazamiento, incluidos Servicio, Instancia, Punto final, Proceso, etc
  • Mejorar el coordinador Kubernetes para eliminar los pods OAP Terminating del clúster.
  • Soporte SW_CORE_SYNC_PERIOD_HTTP_URI_RECOGNITION_PATTERN y SW_CORE_TRAINING_PERIOD_HTTP_URI_RECOGNITION_PATTERN para controlar el período de entrenamiento y sincronizar patrones de reconocimiento de URI HTTP. Y acorte el período predeterminado a 10 segundos para sincronización y 60 para entrenamiento.
  • Se corrigió el error del desplazamiento ElasticSearch.
  • Agregar ID de componente para Aerospike (ID = 149).
  • Los paquetes con el nombre recevier pasan a llamarse receiver.
  • BanyanDBMetricsDAO maneja storeIDTag en multiGet para BanyanDBModelExtension.
  • Corrija la lógica relacionada con la agrupación de puntos finales y mejore el rendimiento de la recuperación de PatternTree.
  • Se corrigió el guardado de caché de sesión métrica después de la inserción por lotes cuando se usa mysql-connector-java.
  • Admite consulta de menú de interfaz de usuario dinámica.
  • Agregue un comentario para docker/.env para explicar el uso.
  • Corrija el nombre de variable de entorno incorrecto SW_OTEL_RECEIVER_ENABLED_OTEL_RULES al derecho SW_OTEL_RECEIVER_ENABLED_OTEL_METRICS_RULES.
  • Corregir consulta de instancia en la implementación de JDBC.
  • Establezca el valor predeterminado del SW_QUERY_MAX_QUERY_COMPLEXITY en 3000 (antes era 1000).
  • Aceptar el valor del parámetro length=4000 del evento. Era el año 2000.
  • Tolerar el valor del parámetro en formato ilegal JSON.
  • Actualice BanyanDB Java Client a 0.4.0
  • Admite el agregado Labeled Value Metrics en MQE.
  • [Cambio importante] Cambie el nombre de etiqueta predeterminado en MQE de label a _.
  • Mejora la versión grpc a 1.53.0.
  • [Cambio importante] Se eliminaron los símbolos '&' de los scripts de shell para evitar que el proceso del servidor OAP se ejecute como un proceso en segundo plano.
  • Revertir parte del n.° 10616 para corregir los cambios inesperados: si no hay datos, debemos devolver una matriz con 0, pero en el n.° 10616, se devuelve una matriz vacía.
  • Almacenar en caché todas las entidades de servicio en la memoria para realizar consultas.
  • Mejora la versión de Jackson a 2.15.2.
  • Aumente el tamaño de memoria predeterminado para evitar OOM.
  • Aumente Graphql-Java a 21.0.
  • Agregue el idioma del ID del componente Echo (5015): Golang.
  • Reparar index out of bounds exception en la función aggregate_labels MQE.
  • Admite monitoreo de servidor/clúster MongoDB impulsado por OTEL.
  • No imprima valores de configuración en registros para evitar que se filtre información confidencial.
  • Move creó el último índice antes de recuperar los índices mediante alias para evitar la excepción 404. Esto simplemente evita algunas interferencias de las operaciones manuales.
  • Agregue más métricas de Go VM, como lo proporcionó el nuevo agente skywalking-go desde su lanzamiento 0.2.
  • Agregar ID de componente para Lock (ID=5016).
  • [Cambio importante] Ajuste la estructura de los ganchos en el alarm-settings.yml. Admite múltiples configuraciones para cada tipo de enlace y especifica los enlaces en la regla de alarma.
  • Sube Armeria a 1.24.3.
  • Se corrigió BooleanMatch y BooleanNotEqualMatch haciendo una comparación booleana.
  • Admite consultas HTTP LogQL API.
  • Agregue el idioma del ID del componente Mux Server (5017): Golang.
  • Elimina ElasticSearch 6.3.2 de nuestras pruebas de biblioteca client.
  • Aumente el servidor ElasticSearch 8.8.1 a 8.9.0 para las últimas pruebas e2e. 8.1.0, 7.16.3 y 7.17.10 todavía están en prueba.
  • Agregue OpenSearch 2.8.0 a nuestras pruebas de biblioteca client.
  • Utilice el modo de escucha para la implementación de configuración dinámica en Apollo.
  • Agregue la función view_as_seq en MQE para enumerar métricas en la secuencia priorizada dada.
  • Se corrige el valor predeterminado incorrecto de k8sServiceNameRule si no está configurado explícitamente.
  • Mejorar PromQL para permitir múltiples operaciones métricas dentro de una sola consulta.
  • Se corrigió la operación binaria de MQE entre métricas etiquetadas y otro tipo de resultado de valor.
  • Agregar ID de componente para Nacos (ID = 150).
  • Soporta Compare Operation en MQE.
  • Arreglar el caché de recursos Kubernetes no actualizado.
  • Se corrigió el classpath incorrecto que podría causar OOM en el inicio.
  • Mejore el serviceRelation en MAL agregando configuraciones para los campos delimiter y component.
  • [Cambio importante] Admite MQE en las alertas. La configuración de reglas de alarma (alarm-settings.yml), agregue el campo expression y elimine los campos metrics-name/count/threshold/op/only-as-condition y elimine la configuración composite-rules.
  • Verifique los resultados en ALS según aguas abajo/ascendentes en lugar de por registro.
  • Se corrigió la consulta GraphQL listInstances que no usaba la consulta endTime
  • No inicie el servidor ni el consumidor de Kafka en modo de inicio.
  • Agregue el ID del componente Iris (5018).
  • Agregue soporte de seguimiento OTLP como entrada de seguimiento Zipkin.

  • Se corrigió el nombre para mostrar de endpoint_cpm para la lista de puntos finales en el panel de General-Service.
  • Implementar menús personalizados y página de mercado.

  • [Cambio importante] Se eliminaron los símbolos '&' de los scripts de shell para evitar que el proceso del servidor de aplicaciones web se ejecute como un proceso en segundo plano.
  • Restablecer etiqueta del gráfico.
  • Corregir instancias de asociados de servicio.
  • Eliminar nodo-sass.
  • Corregir error de confirmación en Windows.

  • Aplicar MQE en plantillas de UI de capa de caché virtual
  • Aplique MQE en las plantillas de interfaz de usuario de capas APISIX, AWS_EKS, AWS_GATEWAY y AWS_S3.
  • Aplicar MQE en los paneles de RabbitMQ.

  • Aplicar MQE en plantillas de interfaz de usuario de capa Infra-Linux
