caminata aérea v10.1.0

Descargar

https://skywalking.apache.org/downloads/

Aviso

No descargue códigos fuente de esta página. Siga [documento de compilación] (https://github.com/apache/skywalking/tree/master/docs/en/guides/How-to-build.md#build-from-github) si desea crear códigos fuente usted mismo.

Una versión de RENDIMIENTO

  • Gran mejora en el rendimiento de la interfaz de usuario. Las consultas de widgets de métricas se agrupan aprovechando las capacidades de GraphQL.
  • Soporte de consultas paralelas en el motor GraphQL. Mejorar el rendimiento de las consultas.
  • Mejorar significativamente el rendimiento del controlador de métricas de OTEL. Reducir costos de CPU y GC en procesos de métricas de OTEL.
  • Con la adopción de BanyanDB 0.7, se mejoran el rendimiento y la estabilidad de la base de datos nativa.

Proyecto

  • E2E: mejora la versión del colector opentelemetry a 0.102.1.
  • Envíe la imagen docker del generador de datos instantáneos a ghcr.io.
  • Mejora skywalking-infra-e2e para evitar que GHA elimine docker-compose v1.
  • Mejora las acciones de CodeQL GitHub.
  • Se corrigió la fase incorrecta del complemento delombok para reducir las advertencias de compilación.
  • Utilice una revisión compatible con ci para configurar la versión del proyecto.

Servidor OAP

  • Corregir índices incorrectos en los modelos relacionados con perfiles eBPF.
  • El soporte excluye el tráfico de espacios de nombres específicos en el receptor del registro de acceso eBPF.
  • Agregue Golang como idioma admitido para Elasticsearch.
  • Eliminar registros de vaciado innecesarios de BanyanDB (información).
  • Aumentar SW_CORE_GRPC_MAX_MESSAGE_SIZE a 50 MB.
  • Soporte para consultar métricas de relación a través de PromQL.
  • Admite consultas de seguimiento MQE para depuración.
  • Agregue ID de componente (158) para el marco Solon.
  • Se corrigió la etiqueta de métricas en el controlador HTTP del complemento del receptor del navegador.
  • Aumente la longitud de la columna alarm_record#message de 200 a 2000.
  • Eliminar la indexación de columnas alarm_record#message.
  • Agregue Python como idioma admitido para Pulsar.
  • Crear depósitos de histogramas más adecuados para el persistence_timer_bulk_prepare_latency, Métricas persistence_timer_bulk_execute_latency y persistence_timer_bulk_all_latency en PersistenceTimer.
  • [Cambio importante] Actualice la versión de Nacos a 2.3.2. El servidor Nacos 1.x no puede servir como coordinador de clúster ni servidor de configuración.
  • Admite consultas de seguimiento de seguimiento (SkyWalking y Zipkin) para depuración.
  • Se corrigió la consulta de métricas de BanyanDB: se usó el tipo Downsampling incorrecto para encontrar el esquema.
  • Admite la recuperación del flujo de cilium para monitorear el tráfico de red entre los servicios de cilium.
  • Admite la función labelCount en el motor OAL.
  • Admite el seguimiento de ejecución de consultas de medidas internas de BanyanDB.
  • Configuración de BanyanDB client: aumente el valor predeterminado maxBulkSize a 10000, agregue flushTimeout y establezca el valor predeterminado en 10 segundos.
  • Lógica de creación de esquema y grupo polaco de BanyanDB para solucionar el problema de falla en la creación de esquema en condiciones de carrera distribuida.
  • Admite consultas de topología de seguimiento para depuración.
  • Se corrigió la expresión del gráfico Current QPS en el tablero MySQL.
  • Admite consultas de registros de seguimiento para depuración.
  • BanyanDB: corrige la consulta y el almacenamiento de datos de autocompletar etiquetas.
  • Admite operadores de agregación en consultas PromQL.
  • Actualice la unidad fuente de métricas relacionadas con la latencia HTTP kubernetes de ns a ms.
  • Admite el seguimiento de ejecución de consultas de flujo interno de BanyanDB.
  • Corrige errores tipográficos y expresiones faltantes en los paneles de control de Elasticsearch, MySQL y RabbitMQ.
  • BanyanDB: el módulo Zipkin establece el servicio como entidad para mejorar el rendimiento de la consulta.
  • MQE: verifique el valor de las métricas antes de realizar la operación binaria para mejorar la solidez.
  • Reemplace la solución alternativa con la ruta de contexto compatible nativa de Armeria.
  • Agregue un contenedor de punto final http para verificación de estado.
  • Refuerzo de Armería y dependencias transitivas.
  • BanyanDB: si la columna del modelo ya es @BanyanDB.TimestampColumn, configure @BanyanDB.NoIndexing en ella para reducir los índices.
  • BanyanDB: secuencia de consultas time ordenadas por secuencias, utiliza series de tiempo internas en lugar de index para mejorar el rendimiento de las consultas.
  • Aumente Graphql-Java a 21.5.
  • Agregue un nodo desconocido cuando la dirección del par Kubernetes no esté presente en el clúster actual.
  • Se corrigió el aumento concurrente de CounterWindow que causaba NPE por PriorityQueue
  • Se corrigió el formato del nombre del punto final con una cadena vacía.
  • Admite consultas asíncronas para la consulta GraphQL compuesta.
  • Obtener el orden de la lista de puntos finales por descripción de marca de tiempo.
  • Admite consultas de clasificación sobre métricas generadas por el receptor eBPF.
  • Se corrigió la compatibilidad con Grafana 11 cuando se usan variables de consulta label_values.
  • Nacos como servidor de configuración y coordinador de clúster admite la configuración contextPath.
  • Actualice el formato del nombre del punto final a <Method>:<Path> en eBPF Access Log Receiver.
  • Agregar métricas de autoobservabilidad para el receptor OpenTelemetry.
  • Las métricas de nivel de servicio de soporte se agregan cuando falta el contexto del pod en el receptor de registro de acceso de eBPF.
  • Se corrigió la excepción de lanzamiento de la consulta getGlobalTopology cuando no se encontraba ningún servicio en la capa dada.
  • Corrige el resultado del análisis anterior que falta en el analizador ALS k8s-mesh.
  • La consulta Fix findEndpoint requiere keyword cuando se usa BanyanDB.
  • Soporte para analizar la dirección IP asignada de ztunnel y el modo mTLS en el receptor de registro de acceso eBPF.
  • Adaptación de BanyanDB Java Client 0.7.0.
  • Agregue el panel de autoobservabilidad del Agente Java SkyWalking.
  • Agregue ID de componente (5022) para el marco GoFrame.
  • Aumentar las dependencias de protobuf java a 3.25.5.
  • BanyanDB: admite el uso de búsqueda de términos nativos para keyword en las consultas findEndpoint y getAlarm.
  • BanyanDB: admite conexión y configuración TLS.
  • Servicio PromQL: consulta API compatible con el formato de hora RFC3399.
  • Mejorar el rendimiento del manejador de métricas de OTEL.
  • Servicio PromQL: repara el resultado de que falta el indicador rangeExpression de los operadores.
  • BanyanDB: use TimestampRange para mejorar la consulta de "eventos" para BanyanDB.
  • Optimice la tabla network_address_alias para reducir el número del índice.
  • Servicio PromQL: admite operador de paréntesis.
  • Consulta de soporte Etiqueta de mensaje de alarma para autocompletar.

interfaz de usuario

  • Resalte las palabras clave del registro de búsqueda.
  • Agregar URL de error en el registro del navegador.
  • Agregue un ícono de SolonMVC.
  • Agregar ícono de cilio e i18n para el menú.
  • Corrija la discrepancia entre la unidad y el cálculo del widget "Uso de ancho de banda de red" en el Panel de servicios de Windows.
  • Realice un máximo de 20 entidades por consulta en los widgets de lista de servicios/instancias/puntos finales.
  • Nodos de error polacos en el widget de seguimiento.
  • Introducir gráfico de llama al perfil de traza.
  • Corregir servicios e instancias al cambiar números de página.
  • Mejorar las consultas de métricas para que la apertura de páginas sea más rápida.
  • Aumentar las dependencias para arreglar CVE.
  • Agregar una vista de carga para la página de inicialización.
  • Se corrigió un error para los selectores al cli hacer clic en el ícono de actualización.
  • Se corrigió el control de estado del backend de OAP.
  • Agregue el reenviador de tablero Service, ServiceInstance, Endpoint a las topologías Kubernetes.
  • Corregir paginación para widgets de lista de servicios/instancias.
  • Agregar consultas para etiquetas de alarma.
  • Agregue el menú de autoobservabilidad del agente Java de Skywalking.

Documentación
