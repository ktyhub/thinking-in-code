caminata aérea v9.7.0

Descargar

https://skywalking.apache.org/downloads/

Aviso

No descargue códigos fuente de esta página. Siga [documento de compilación] (https://github.com/apache/skywalking/tree/master/docs/en/guides/How-to-build.md#build-from-github) si desea crear códigos fuente usted mismo.

Modo oscuro

El modo de estilo moderno se cambia al modo oscuro y el modo claro aún está disponible.

Nueva vista de registro de diseño

Actualmente está disponible un nuevo diseño para la vista de registro. Más fácil de localizar los registros y más espacio para el texto sin formato.

Proyecto

  • Pasar el agente Java a 9.1-dev en las pruebas e2e.
  • Aumente netty a 4.1.100.
  • Actualice Groovy 3 a 4.0.15.
  • Soporte para empaquetar el proyecto en JDK21. El origen y el destino del compilador permanecen en JDK11.

Servidor OAP

  • ElasticSearchClient: Añadir deleteById API.
  • Arreglar Las reglas de alarma personalizadas se sobrescriben con 'resource/alarm-settings.yml'
  • Admite monitoreo Kafka.
  • Admite monitorización del servidor Pulsar y del servidor BookKeeper.
  • [Cambio importante] El almacenamiento Elasticsearch fusiona todos los índices de datos de administración en un índice management, incluyendo ui_template，ui_menu，continuous_profiling_policy.
  • Agregar un mecanismo de liberación de ventanas de alarma cuando expire en caso de OOM.
  • Corrige la respuesta del receptor de seguimiento Zipkin: convierte el código de estado HTTP de 200 a 202.
  • Actualice BanyanDB Java Client a 0.5.0.
  • Se corrigió la consulta getInstances en el DAO de metadatos de BanyanDB.
  • BanyanDBStorageClient: Agregar keepAliveProperty API.
  • Existe una tabla de corrección en el complemento de almacenamiento JDBC.
  • Mejorar la extensibilidad de la biblioteca del servidor HTTP.
  • Ajuste la longitud de la columna del mensaje de alarma AlarmRecord a 512.
  • Arreglar el evento de construcción EventHookCallback: construir la capa desde Service's Layer.
  • Arreglar AlarmCore doAlarm: detectar excepción para cada devolución de llamada para evitar interrupciones.
  • Optimizar queryBasicTraces en TraceQueryEsDAO.
  • Arreglar WebhookCallback enviar mensajes incorrectos, agregar excepción de captura para cada publicación HTTP de devolución de llamada.
  • Se corrigió la validación de la expresión AlarmRule: se agregaron datos simulados de métricas etiquetadas para verificar.
  • Soporte para recopilar métricas del grupo de memoria ZGC.
  • Agregue una ID de componente para Netty-http (ID=151).
  • Agregue una ID de componente para Fibra (ID=5021).
  • BanyanDBStorageClient: Agregar define(Property property, PropertyStore.Strategy strategy) API.
  • Corrija el formato del archivo y corrija errores tipográficos en los nombres de los archivos para monitorear las pruebas e2e de Kafka.
  • Admite extraer marca de tiempo de una cadena de fecha y hora con patrón en LAL.
  • Admite parámetros clave de salida en los registros de arranque.
  • La solución no puede consultar los rastros de zipkin con el parámetro annotationQuery en el almacenamiento relacionado con JDBC.
  • La solución limit no funciona para findEndpoint API en el almacenamiento ES.
  • Aislar la caché MAL CounterWindow por nombre de métrica.
  • Corregir el orden de consulta del registro JDBC.
  • Cambie la estrategia DataCarrier IF_POSSIBLE para usar la implementación ArrayBlockingQueue.
  • Cambiar la política de la cola (DataCarrier) en el trabajador agregado de métrica L1 al modo IF_POSSIBLE.
  • Agregue la métrica de autoobservabilidad metrics_aggregator_abandon para contar la cantidad de métricas de abandono.
  • Admite monitoreo de Nginx.
  • Corrección BanyanDB Metadata Query: hacer que la consulta de una sola instancia/proceso devuelva etiquetas completas para evitar NPE.
  • Reemplace go2sky E2E por el agente GO.
  • Reemplazar el protocolo Metrics v2 con MQE en plantillas de UI y prueba E2E.
  • Corregir reglas de hotel de métricas apisix incorrectas.
  • Soporte Scratch The OAP Config Dump.
  • Admite la función increase/rate en el lenguaje de consulta MQE.
  • Agrupe los puntos finales de servicio en _abandoned cuando los puntos finales tengan un nivel alto. cardinalidad.

interfaz de usuario

  • Agregar nuevo menú para monitoreo de Kafka.
  • Corregir la duración del widget independiente.
  • Corregir la altura de visualización de la estructura del árbol de enlaces.
  • Reemplace el nombre por nombre corto en el widget de servicio.
  • Refactor: actualiza el estilo de paginación. Sin cambios de estilo de visualización.
  • Aplicar MQE en plantillas de UI de capa K8.
  • Se corrigieron los íconos que se muestran en el diagrama de árbol de seguimiento.
  • Solución: actualice el estilo de información sobre herramientas para admitir la vista de desplazamiento de múltiples métricas en un gráfico de métricas.
  • Agregue un nuevo widget para mostrar los detalles del grupo de memoria jvm.
  • Solución: evite consultar datos con parámetros vacíos.
  • Agregue un título y una descripción para los segmentos de seguimiento.
  • Agregue el ícono Netty para el complemento HTTP Netty.
  • Agregar archivos i18n del menú Pulsar.
  • Vista de registros de refactorización.
  • Implementar el Tema Oscuro.
  • Cambiar plantillas de interfaz de usuario para widgets de texto.
  • Agregar menú Nginx i18n.
  • Corrige la altura del widget de seguimiento.
  • Estilo de lista polaco.
  • Reparar el registro asociado con Trace.
  • Mejorar el diseño del widget de topología roto.
  • Corregir métrica de llamadas con tipo de llamada para el widget de topología.
  • Se corrigió el cambio de configuración de métricas para el widget de topología.
  • Corregir rutas para el widget Tab.
  • Eliminar las plantillas de interfaz de usuario relativas y el elemento de menú de OpenFunction (capa FAAS).
  • Solución: cambie los colores para que coincidan con el tema oscuro para la creación de perfiles de red.
  • Eliminar la descripción de OpenFunction en la interfaz de usuario i18n.
  • Reducir los fragmentos de componentes para mejorar el tiempo de carga de los recursos de la página.

  • Separe los documentos de almacenamiento en diferentes archivos y agregue un cronograma estimado para BanyanDB (finales de 2023).
  • Agregar configuración de topología en el documento UI-Grafana.
  • Agregue métricas faltantes al documento OpenTelemetry Metrics.
  • Documentos polacos de Concepts and Designs.
  • Corregir notas incorrectas de slowCacheReadThreshold.
