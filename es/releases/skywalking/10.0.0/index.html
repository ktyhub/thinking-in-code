Ejecutar con BanyanDB 0.6 en modo clúster

Proyecto

  • Admite el tiempo de ejecución de Java 21.
  • Admite imagen oap-java21 para el tiempo de ejecución de Java 21.
  • Actualice la versión OTEL collector a 0.92.0 en todas las pruebas e2e.
  • Cambie el corredor CI macOS a m1.
  • Actualice el controlador PostgreSQL a 42.4.4 para corregir CVE-2024-1597.
  • Elimina CLI(swctl) de la imagen.
  • Eliminar la variable CLI_VERSION de la compilación Makefile.
  • Agregue BanyanDB al inicio rápido de composición de docker.
  • Mejora Armeria, jackson, netty, jetcd y grpc para arreglar CVE.
  • Aumente BanyanDB Java Client a 0.6.0.

Servidor OAP

  • Agregue el parámetro layer a la consulta GraphQL de topología global.
  • Agregue la función is_present en MQE para verificar si las métricas de la lista tienen un valor o no.
  • Eliminar configuraciones predeterminadas irrazonables para el ejecutor de subprocesos gRPC.
  • Eliminar la configuración gRPCThreadPoolQueueSize (SW_RECEIVER_GRPC_POOL_QUEUE_SIZE).
  • Permitir excluir ServiceEntries en algunos espacios de nombres al buscar ServiceEntries como método de resolución final de metadatos del servicio.
  • Configure la longitud de los ID de origen y destino en las entidades de relación de servicio, instancia, punto final y proceso en 250 (antes 200).
  • Admite la creación de jerarquía de servicios/instancias y consultas.
  • Cambie el campo de cadena en el almacenamiento Elasticsearch del tipo palabra clave al tipo texto si establece una longitud superior a 32766.
  • [Cambio importante] Cambie el campo de configuración de ui_template y ui_menu en el almacenamiento Elasticsearch del tipo palabra clave a texto.
  • Admite coincidencia automática de jerarquía de servicios, agregue relaciones de capas de coincidencia automática (superior -> inferior) de la siguiente manera:
    • MALLA -> MESH_DP
    • MALLA -> K8S_SERVICE
    • MESH_DP -> K8S_SERVICE
    • GENERAL -> K8S_SERVICE
  • Agregue el sufijo namespace para K8S_SERVICE_NAME_RULE/ISTIO_SERVICE_NAME_RULE y metadata-service-mapping.yaml de forma predeterminada.
  • Permitir el uso de un puerto dedicado para el receptor ALS.
  • Corregir consulta de registro por traceId en JDBCLogQueryDAO.
  • Admite el protocolo de registro de acceso eBPF del controlador.
  • Corrige la función de error SumPerMinFunctionTest.
  • Eliminar anotaciones y funciones innecesarias de las funciones del medidor.
  • Agregue funciones max y min para muestreo descendente MAL.
  • Se corrigió un error crítico de costo de memoria incontrolado de las estadísticas de TopN. Cambie la clave del grupo topN de StorageId a entityId + timeBucket.
  • Agregue relaciones de capas de coincidencia automática de jerarquía de servicios (superior -> inferior) de la siguiente manera:
    • MYSQL -> K8S_SERVICE
    • POSTGRESQL -> K8S_SERVICE
    • SO11Y_OAP -> K8S_SERVICE
    • BASE_DATA_VIRTUAL -> MYSQL
    • BASE_DATOS_VIRTUAL -> POSTGRESQL
  • Agregue Golang como idioma admitido para AMQP.
  • Soportar capas de servicio disponibles en la topología.
  • Agregar función de agregación count para MAL
  • Agregue relaciones de capas de coincidencia automática de jerarquía de servicios (superior -> inferior) de la siguiente manera:
    • NGINX -> K8S_SERVICE
    • APISIX -> K8S_SERVICE
    • GENERAL -> APISIX
  • Agregue Golang como idioma compatible con RocketMQ.
  • Admite monitoreo del servidor Apache RocketMQ.
  • Agregue relaciones de capas de coincidencia automática de jerarquía de servicios (superior -> inferior) de la siguiente manera:
    • ROCKETMQ -> K8S_SERVICE
    • VIRTUAL_MQ -> ROCKETMQ
  • Arreglar la consulta ServiceInstance in.
  • Simulacro de /api/v1/status/buildinfo para PromQL API.
  • Existe una tabla de corrección en el complemento de almacenamiento JDBC.
  • Se corrigió la estrategia de rango de tiempo de rotación de tablas basadas en días en el almacenamiento JDBC.
  • Agregue la configuración maxInboundMessageSize (SW_DCS_MAX_INBOUND_MESSAGE_SIZE) para cambiar el tamaño máximo de mensaje entrante de DCS.
  • Se corrigió la capa de servicio al crear eventos en EventHookCallback.
  • Agregue Golang como idioma admitido para Pulsar.
  • Agregue relaciones de capas de coincidencia automática de jerarquía de servicios (superior -> inferior) de la siguiente manera:
    • RABBITMQ -> K8S_SERVICE
    • VIRTUAL_MQ -> CONEJOTMQ
  • Eliminar el mecanismo de función Column# en el kernel.
  • Realizar la consulta readMetricValue siempre devuelve el valor promedio de la duración.
  • Agregue relaciones de capas de coincidencia automática de jerarquía de servicios (superior -> inferior) de la siguiente manera:
    • KAFKA -> K8S_SERVICE
    • VIRTUAL_MQ -> KAFKA
  • Admite monitoreo del servidor ClickHouse.
  • Agregue relaciones de capas de coincidencia automática de jerarquía de servicios (superior -> inferior) de la siguiente manera:
    • CLICKHOUSE -> K8S_SERVICE
    • BASE_DATA_VIRTUAL -> CLICKHOUSE

    • PULSAR -> K8S_SERVICE
    • VIRTUAL_MQ -> PULSAR
  • Agregue Golang como idioma compatible con Kafka.
  • Admite la visualización de los servicios del puerto que se escuchan desde OAP y UI durante el inicio del servidor.
  • Refactorizar el generador de datos para respaldar la generación de métricas.
  • Arreglar el nombre heredado de AvgHistogramPercentileFunction.
  • [Cambio importante] Las métricas etiquetadas admiten varias etiquetas.
    • Almacenamiento: almacena todos los nombres y valores de las etiquetas en lugar de solo los valores. -MQE:
      • Admite consultas mediante varias etiquetas (nombre y valor) en lugar de utilizar _ como nombre de etiqueta anónima.
      • La función aggregate_labels admite agregados mediante etiquetas específicas.
      • La función relabels requiere etiqueta de destino y cambiar el nombre y el valor de la etiqueta. -PromQL:
      • Admite consultas mediante varias etiquetas (nombre y valor) en lugar de utilizar lables como nombre de etiqueta anónima.
      • Eliminación de etiquetas generales Función labels/relabels/label.
      • API /api/v1/labels y /api/v1/label/<label_name>/values admiten la devolución de etiquetas de métricas coincidentes.
    • OAL:
      • Desaprobar la función percentile e introducir en su lugar la función percentile2.
  • Mejora Kafka para arreglar CVE.
  • Reparar NullPointerException en el registro ServiceEntry de Istio.
  • Elimina componentIds innecesario como ID de serie en las entidades ServiceRelationClientSideMetrics y ServiceRelationServerSideMetrics.
  • Se corrigió el error de no arrojar cuando parte de la expresión no coincidía con ningún nodo de expresión en MQE y PromQL. *Eliminar kafka-fetcher/default/createTopicIfNotExist` ya que la creación es automática desde #7326 (v8.7.0).
  • Corregir métricas de servicio nginx inexactas.
  • Arreglar/Cambiar el nombre de las métricas de Windows (Intercambiar -> Memoria virtual)
    • memory_swap_free -> memory_virtual_memory_free
    • memory_swap_total -> memory_virtual_memory_total
    • memory_swap_percentage -> memory_virtual_memory_percentage
  • Corregir/cambiar la configuración de inicio de la interfaz de usuario para Windows Swap -> Memoria virtual
  • Se corrigió la pantalla Memory Swap Usage/Virtual Memory Usage con inicio de interfaz de usuario (Linux/Windows)
  • Corregir métricas APISIX inexactas.
  • Corregir métricas de MongoDB inexactas.
  • Admite monitoreo del servidor Apache ActiveMQ.
  • Agregue relaciones de capas de coincidencia automática de jerarquía de servicios (superior -> inferior) de la siguiente manera:
    • ACTIVEMQ -> K8S_SERVICE
  • Calcular la latencia HTTP del servicio Nginx por MQE.
  • Consulta MQE: hacer que los metadatos no devuelvan null.
  • Operación binaria de métricas etiquetadas de MQE: devuelve un valor vacío si las etiquetas no coinciden en lugar de informar un error.
  • Se corrigió la jerarquía inexacta de las métricas de monitoreo del servidor RabbitMQ.
  • Se corrigieron métricas inexactas de MySQL/MariaDB, Redis, PostgreSQL.
  • Admite DoubleValue, IntValue, BoolValue en los atributos de métricas de OTEL.
  • [Cambio importante] El exportador de métricas gGRPC unificó el tipo de valor de métrica y admite métricas etiquetadas.
  • Agregar definición de componente (ID = 152) para c3p0 (conexión JDBC3 y agrupación de declaraciones).
  • Arreglar la consulta global MQE top_n.
  • Corregir métricas inexactas de Pulsar y Bookkeeper.
  • MQE admite funciones sort_values y sort_label_values.
