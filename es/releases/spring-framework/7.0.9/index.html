marco-primavera v7.0.9

:advertencia: Se requiere atención

  • En Spring Framework, 7.0.9, ForwardedHeaderFilter (Spring MVC) y ForwardedHeaderTransformer (WebFlux), cada uno proporciona un argumento de constructor booleano sobre si se debe utilizar el encabezado estándar "Reenviado" o los encabezados alternativos "X-Reenviado". Una propiedad independiente activa y desactiva el uso de "X-Forwarded-Prefix". Si bien el constructor predeterminado conserva el comportamiento existente, recomendamos utilizar el nuevo constructor para especificar explícitamente qué encabezados reenviados usar para que el procesamiento sea más determinista y alineado con lo que se espera del proxy. Consulte la sección actualizada Consideraciones de seguridad para obtener más detalles. En 7.1 con #37072, el constructor predeterminado está obsoleto y marcado para su eliminación. #37090
  • En Spring Framework 7.0.9, SimpleEvaluationContext ya no admite la compilación de expresiones de forma predeterminada, independientemente del modo de compilación configurado a través de SpelParserConfiguration o la propiedad del sistema spring.expression.compiler.mode o la propiedad Spring. Las aplicaciones que usan intencionalmente SimpleEvaluationContext con expresiones trusted y requieren compilación por razones de rendimiento pueden optar por llamar a withCompilationSupported() en el generador SimpleEvaluationContext. Se debe tener cuidado al optar por la compilación, ya que al hacerlo se eliminan las protecciones de seguridad aplicadas durante la evaluación interpretada. #37035
