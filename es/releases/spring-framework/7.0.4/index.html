marco-primavera v7.0.4

:star: Nuevas funciones

  • Anotaciones del método de caché en MethodParameter y AnnotatedMethod #36307
  • Admite constantemente @Lazy como metaanotación en profundidades arbitrarias #36306
  • Admite constantemente @Validated como metaanotación en profundidades arbitrarias #36305
  • Permitir que los desarrolladores deshabiliten los registros predeterminados en HttpMessageConverters #36303
  • Registre qué HandlerInterceptor lanzó la excepción #36281
  • Mejorar el rendimiento de los cálculos de código hash para asignaciones de solicitudes #36279
  • Mejorar el rendimiento de la búsqueda de beans HandlerMethod #36278
  • Mejorar el rendimiento del mapeo de versiones #36276
  • Mejorar el rendimiento de las asignaciones de solicitudes de patrón único #36275
  • Mejorar el rendimiento de la determinación de grupos de validación #36274
  • Agregar el método de configuración setPackagesToScan a LocalEntityManagerFactoryBean #36270
  • Eliminar la sustitución obsoleta GraalVM #36257
  • Introducir devolución de llamada beforeRetry con el argumento RetryState #36245
  • Optimice NamedParameterUtils#buildValueArray recuperando lentamente SqlParameter #36230
  • Permitir la personalización del ProxyFactory en HttpServiceProxyFactory utilizado para crear servidores proxy HTTP #36225
  • Cerrar secuencias consistentemente mediante prueba con recursos en FileCopyUtils #36223
  • Utilice las utilidades de archivos Java en FileCopyUtils #36221
  • SqlBinaryValue y SqlCharacterValue deberían admitir contenido InputStream con longitud indeterminada #36219
  • Admite la configuración de JtaTransactionManager y SpringBeanContainer en HibernateJpaVendorAdapter #36216
  • Agregar contenedor TaskCallback/Callable/Runnable para tareas reintentables #36208
  • Refinar el procesador Yaml para permitir diferentes valores vacíos #36207
  • Anticipe la corrección de la advertencia de compilación de Kotlin 2.3 #36203
  • Permitir que los procesadores YAML creen un mapa aplanado con valores nulos incluidos #36197
  • Utilice Reader.transferTo en FileCopyUtils #36196
  • DataBufferUtils.write() con NettyDataBuffer en JDK 25 se bloquea indefinidamente #36184
  • Hacer que SendToMethodReturnValueHandler y SubscriptionMethodReturnValueHandler sean personalizables para permitir el paso de encabezados de mensajes #36179
  • Presentar RestClient.ResponseSpec#requiredBody #36173
  • Hacer que el alcance sea totalmente configurable en BeanRegistry/BeanRegistrar #36171
  • ConcurrencyThrottleSupport e interrupción de subprocesos #36167
  • Agregue métodos sendAndReceive sobrecargados a JmsTemplate para usar la cola de respuestas explícita #36162
  • Los atributos WebClient (Reactor) en el canal Netty no se borran después de liberar la conexión #36158
  • Soporte HttpEntity en ContentRequestMatchers.multipartData #36154
  • Reintroduzca WebLogicJtaTransactionManager en Spring Framework 6.2.x #36151
  • El retroceso para DefaultMessageListenerContainer no se aplica de manera consistente en caso de falla en la configuración del oyente #36143
  • Soporte inicial para JPA 4.0 EntityAgent (conexión automática de un proxy compartido) #36025
  • Compatibilidad temprana con JPA 4.0 e Hibernate ORM 8.0 #35705

:lady_beetle: Corrección de errores

  • El argumento resuelto del controlador HttpEntity no refleja encabezados HTTP mutados #36298
  • Evitar la congestión de bloqueo en ConcurrentReferenceHashMap #36293
  • AbstractMessageConverter no admite comodines en los tipos MIME admitidos #36285
  • Hacer que LocalEntityManagerFactoryBean#setDataSource funcione en Hibernación así como en EclipseLink #36271
  • StompBrokerRelayMessageHandler no se reinicia debido a una pausa en el contexto de la prueba #36266
  • Puede ocurrir un punto muerto al llamar a System.exit al inicio (contra múltiples ganchos de apagado) #36260
  • Falta una pista de recursos para BeanRegistrar que implementa ImportAware #36242
  • Comportamiento inconsistente con @Retryable en interfaces anotadas #36233
  • Netty4HeadersAdapter.remove devuelve una lista vacía en lugar de null para una clave no existente #36226
  • El tipo genérico en AsyncTaskExecutor.submit(Callable<T>) debe ser @Nullable #36191
  • EclipseLinkConnectionHandle puede fallar contra la condición de carrera de aislamiento de transacciones #36165

:notebook_with_decorative_cover: Documentación

  • Eliminar código obsoleto en la sección Redirecting to a resource #36284
  • Se corrigió el formato en la documentación de conversión de mensajes HTTP de Web MVC #36250
  • Eliminar documento obsoleto para spring.context.annotated-bean-reader.create #36241
  • Documento @SpringExtensionConfig en el manual de referencia #36240
  • Se corrigió la sintaxis de JSON en la documentación de descripción general de STOMP #36229
  • Revisar la documentación sobre soporte JSR-330 en el manual de referencia #36222
  • Se corrigieron enlaces a la Guía del usuario de JUnit #36217
  • Se corrigió la definición de corrutinas #36209
  • Corrección del javadoc LocalContainerEntityManagerFactoryBean#setPersistenceUnitName #36205
  • Actualización de la documentación sobre el manejo de barras diagonales donde el nivel de tipo @GetMapping("/base") se combina con el nivel de método @GetMapping("/") #36198
  • Actualizar la documentación sobre el tipo de medio utilizado para ProblemDetail #36192
  • Extraer fragmentos de DispatcherServlet #36175
  • Reemplace getErrors() con getBindingResult() en los ejemplos #36170
  • Refinar la documentación de CORS para que coincida con los últimos cambios #36156

:hammer: Actualizaciones de dependencia

  • Actualice a Apache POI 5.5 #36174
  • Actualice a ASM 9.9.1 y Objenesis 3.5 #36243
  • Actualice al micrómetro 1.6.3 #36287
  • Actualización al reactor 2025.0.3 #36288
