🎉 Características

  • agregar una función de utilidad para verificar localhost. (#2454) (c5ebf9e)
  • Agregar la herramienta MCP get_heapsnapshot_object_details (#2374) (8432cb9)
  • Emitir contextos nativos en resumen de instantáneas (#2375) (f78a911)
  • Filtrar objetos de instantáneas del montón por contexto nativo (#2377) (76fd242)
  • telemetría: registrar datos de devtools. (#2460) (df2c753)
  • telemetría: registra is_devtools_open con cada llamada a la herramienta. (#2445) (6f60eab)
  • telemetría: informa si la llamada a la herramienta se realiza en localhost. (#2455) (6398b7e)
  • actualizar faro a 13.4.1 (#2398) (745ffe7)

🛠️ Correcciones

  • retención de solicitudes de red por navegación vinculada (#2435) (b08c73c)
  • cli: validar ID de sesión (#2475) (5ca9121)
  • cli: advierte sobre una discrepancia de versión entre cli y el demonio (#2461) (3afc44d)
  • daemon: conserva los indicadores del navegador con guiones en la serialización de argumentos y el inicio diferido del demonio (#2405) (d79f3ba)
  • eliminar trabajadores de instantáneas del montón en el desmontaje del contexto (#2428) (f245c76)
  • no lanzar sincrónicamente cuando una sesión CDP finaliza (#2466) (ba4fe3e)
  • no tirar si se manejó el diálogo (#2437) (574c320)
  • capturas de pantalla reducidas de la ventana gráfica cuando no se emula ninguna ventana gráfica (#2380) (39c4140)
  • mejorar el ciclo de vida del demonio (#2360) (3ee6a27)
  • mejorar la escritura de archivos (#2447) (1da4bb0)
  • incluir la identificación de la pestaña en la respuesta de texto de get_tab_id (#2381) (dcbaf49)
  • memoria: desecha el trabajador de instantáneas del montón cuando falla la carga (#2449) (744738d)
  • rendimiento: restablecer el indicador de ejecución de seguimiento cuando falla la configuración de start_trace (#2420) (40240c0)
  • regresión después del #2443 (#2462) (4c80ce4)
  • cambiar el nombre de la columna maxRetainedSize (#2402) (75c7048)
  • captura de pantalla: eliminar el identificador del elemento después de tomar_pantalla (#2422) (fffb40e)
  • alternar carga diferida para mapas fuente. (#2486) (8028bfe)
  • espera: evita el bloqueo del mutex de 180 cuando se abre un cuadro de diálogo durante una acción (#2427) (b4e8f74)

📄 Documentación

  • Agregue las instrucciones de instalación devin cli a README (#2361) (45262c0)
  • corregir la documentación del directorio de datos del usuario (#2473) (5ddbffd)

  • actualizar seguridad.md (#2362) (5012b07)
