1.10.0 (23/09/2026)

🎉 Características

  • agregar clase de formateador css (#2707) (f0b5fa4)
  • agregar la herramienta get_css_style (#2612) (4454ae0)
  • rendimiento: analizador de búfer de seguimiento fragmentado para grabaciones grandes (#2721) (23b9a48)
  • establece el tamaño de página y el Idx de página predeterminados para la herramienta get_css_styles (#2799) (dc9d14d)
  • archivo de configuración de soporte (#2661) (314a5fa)
  • telemetría: fecha persistente de la última llamada a la herramienta. (#2705) (c54a493)
  • telemetría: grabación de una versión desinfectada del nombre client (#2757) (55fbc57)
  • telemetría: informar el uso de hermes client. (#2703) (fb47e6c)
  • actualizar la clase de formateador CSS para agregar AtRule, PositionTryRule, PropertyRule, FunctionRule (#2717) (d4a0620)
  • actualizar la clase de formateador CSS para agregar reglas heredadas (#2715) (3d7e7bb)
  • actualizar la clase de formateador CSS para agregar reglas coincidentes (#2713) (8c8616f)
  • actualizar la clase de formateador CSS para agregar pseudoelemento (#2716) (df1469a)
  • actualizar el formateador CSS para agregar reglas de fotogramas clave (#2718) (cdc365c)

🛠️ Correcciones

  • Retención vinculada de ConsoleCollector por navegación (#2773) (e98a3ca)
  • cli: reenviar opciones falsas explícitas al inicio (#2702) (d9a8cb6)
  • config: preservar los valores sin procesar para la coerción de configuración (#2747) (906c83b)
  • no registre los registros de Puppeteer en el archivo a menos que se solicite (#2743) (4fbfbc4)
  • explica los fallos de inicio causados por ejecutar como root (#2634) (9d29223)
  • manejar los cuadros de diálogo JavaScript abiertos durante las acciones de la herramienta de entrada (#2794) (266112b)
  • rendimiento: evita la pérdida de memoria determinando el alcance del modelo del motor de seguimiento por análisis (#2720) (d05cbc0)
  • preservar el historial de la consola en navegaciones del mismo documento (#2676) (aa25562)
  • preservar el mensaje de error subyacente en las acciones de la herramienta de entrada (#2792) (6e47dbb)
  • establece emulatedUserAgent y usa finalDisplayedUrl en lighthouse_audit (#2795) (941f82a)
  • tiempo de espera en WaitForHelper.ts (#2772) (dc1d055)

📄 Documentación

  • agregar configuración FLUJO client (#2690) (65a679e)
  • Corregir categorías que no se configuran correctamente (#2807) (2250cdc)
  • corrige los valores predeterminados para valores no booleanos (#2744) (342d243)
  • actualizar el nombre de la opción de enrutamiento de la página (#2748) (8939965)
  • actualice SKILL para chrome-devtools para usar la herramienta get_css_styles (#2760) (421011e)

🏗️ Refactorizar

  • deshabilitar herramientas en lugar de no registrarlas (#2636) (b455469)
  • extraer el navegador en una clase BrowserManager (#2787) (3228f44)
  • migrar el MCP SDK a v2 (#2408) (da3c406)
  • mover el formato de comentarios a la clase CommentFormatter (#2719) (e3cded0)
  • prepararse para SDK v2 (#2771) (61780c7)
  • simplificar nuestros scripts de generación (#2793) (5068584)
  • unificar el tipo de llamada y garantizar la seguridad de tipos (#2659) (882f93e)
