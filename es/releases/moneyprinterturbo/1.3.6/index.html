Inglés | 中文

<h2 id="es-v1.3.6">Aspectos destacados</h2>
  • Se agregó generación de video nativo Volcano Engine Ark Seedance para generar la fuente clips directamente a partir de segmentos de script.
  • Se agregó soporte de texto a video multimodelo de OFox, lo que permite que Seedance, Wan y otros modelos compartan una clave API.
  • Se agregó soporte de texto a video Metaso MiniMax H3 con salida 768P/2K, clips de 4 a 15 segundos y relaciones de aspecto 9:16, 16:9 y 1:1.
  • Se agregó una fuente de material de texto a imagen compatible con OpenAI para retransmisiones en la nube y puertas de enlace locales.
  • Se agregaron OpenRouter y APIMart como proveedores de LLM compatibles con OpenAI.
  • Se agregó una pestaña de configuración de publicación automática de WebUI para cargar y publicar, con una clave API más clara y una guía de configuración de cuenta.
  • Se agregó el modo de manifiesto por lotes CLI y se aplicaron configuraciones de WebUI guardadas como valores predeterminados de CLI cuando se omiten los valores de la línea de comandos.
  • Se agregaron modos de ajuste de fuente configurables clip: cover llena el marco recortando los bordes sobrantes, mientras que contain preserva la fuente completa con formato tipo formato letterbox.
  • Se agregaron traducciones completas de WebUI en francés y coreano.
  • Configuración de fuente de material reorganizada, fuentes de video agrupadas por capacidad y credenciales de proveedor de video de IA centralizadas en la configuración de WebUI.

Seguridad

  • Acceso restringido del navegador entre orígenes API a solicitudes del mismo origen de forma predeterminada. Las interfaces de navegador independientes Trust se pueden habilitar explícitamente con CORS_ALLOWED_ORIGINS.
  • Se agregaron certificaciones de procedencia y SBOM a las imágenes de contenedores publicadas.

Correcciones y mejoras

  • Duración de la narración medida a partir del archivo de audio generado en lugar de depender únicamente de las señales de los subtítulos.
  • Se ancló la línea de tiempo de los subtítulos de SiliconFlow a la duración completa del audio.
  • Se aseguró que los recursos AudioFileClip estén cerrados en las rutas de ElevenLabs, Chatterbox y Fish Audio.
  • Se evitó que la limpieza de secuencias de comandos eliminara con avidez el texto entre corchetes o paréntesis no relacionado.
  • Se eliminó una advertencia de reintento engañosa después del último intento de LLM.
  • Se corrigieron las URL de Redis cuando no se configura ninguna contraseña.
  • Registros de registro conservados cuando la raíz del proyecto y el destino del registro están en montajes diferentes.
  • Se corrigió la salida de la consola Unicode después de una generación exitosa de CLI en Windows.
  • Se agregaron nombres de archivos de descarga portátiles y seguros, incluidas citas compatibles con RFC y protección contra nombres reservados de Windows.
  • Se mejoró el comportamiento de vista previa de WebUI en servidores sin cabeza al recurrir a la reproducción y descarga del navegador.
  • Configuración de carga y publicación desacoplada de la publicación automática para que la configuración se pueda guardar sin habilitar las cargas.
  • Manejo de imágenes reforzado compatible con OpenAI: 200 respuestas con formato incorrecto ahora omiten solo la palabra clave afectada, mientras que las fallas de almacenamiento local detienen más solicitudes pagas.

Notas de actualización

  • El acceso al navegador API ahora tiene como valor predeterminado solicitudes del mismo origen. Las interfaces web independientes deben declarar sus orígenes trusted a través de CORS_ALLOWED_ORIGINS; Los clients del lado del servidor como curl, Postman y n8n no se ven afectados.
  • Los comandos CLI ahora heredan la configuración de WebUI guardada para las opciones omitidas. Los argumentos CLI explícitos y los valores del manifiesto por lotes siguen teniendo prioridad.

<h2 id="cn-v1.3.6">重点更新</h2>
  • 新增火山引擎方舟 Seedance 原生视频生成服务，可根据脚本片段直接生成视频素材。
  • 新增 OFox 多模型文生视频服务,一个 API Key 即可调用 Seedance、Wan 等模型.
  • El MiniMax H3 está diseñado para ser compatible con 768P/2K, 4～15, 9:16, 16:9 y 1:1.
  • 新增适用于云端中转和本地网关的 OpenAI 兼容文生图素材源.
  • Incluye OpenRouter y APIMart OpenAI, que son compatibles con OpenRouter.
  • WebUI 新增 Upload-Post 自动发布设置，并完善 API Key 和账号名称的申请、配置指引。
  • CLI 新增批量清单模式；未显式传入命令行参数时,可以继承 WebUI 已保存的默认设置.
  • cover contain保留完整素材并在比例不同时增加黑边.
  • 新增完整的法语和韩语 WebUI 翻译.
  • Interfaz de usuario web UI设置中管理。

安全性

  • API API API CORS_ALLOWED_ORIGINS CORS_ALLOWED_ORIGINS显式配置可信来源。
  • 发布的容器镜像新增构建来源证明和 SBOM 软件物料清单证明.

修复与改进

  • 改为从真实生成的音频文件测量旁白时长,不再仅依赖字幕时间轴.
  • 将 SiliconFlow 字幕时间轴末尾与完整音频时长对齐.
  • Empresas ElevenLabs, Chatterbox y Fish Audio, empresas AudioFileClip.
  • 修复脚本文本清理可能贪婪删除多组括号内容的问题.
  • 移除大语言模型最后一次重试结束后误导性的“正在重试”日志.
  • Redis 未配置密码时生成错误鉴权片段的问题.
  • 修复项目目录和日志目录位于不同挂载点时日志记录丢失的问题.
  • Compatible con Windows, compatible con Unicode, CLI, compatible con Windows.
  • Windows 保留名称保护.
  • 无图形桌面的服务器环境下, WebUI 会回退到浏览器播放和下载视频.
  • 将 Subir-publicar 配置与自动发布开关解耦，允许用户保存配置但不立即启用上传。
  • 加强 OpenAI 兼容文生图异常处理: HTTP 200返回损坏图片时仅跳过当前关键词,本地存储失败时则停止后续付费请求.

升级说明

  • API API CORS_ALLOWED_ORIGINS CORS_ALLOWED_ORIGINS配置可信来源；curl、Postman、n8n 等服务端调用不受影响。
  • Cuando CLI no pasa parámetros explícitamente, heredará la configuración guardada por WebUI; los parámetros pasados ​​explícitamente en CLI y los campos de lista de lotes aún tienen mayor prioridad.
