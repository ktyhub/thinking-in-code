MoneyPrinterTurbo v1.3.5

Inglés | 中文

<h2 id="es-v1.3.5">Aspectos destacados</h2>
  • Se agregaron proveedores de texto a voz MiniMax y Fish Audio, se mejoró el punto final regional MiniMax y la compatibilidad con la selección de voz, se sincronizaron las voces de Gemini con el catálogo oficial y se agregaron vistas previas automáticas de voz en la WebUI.
  • Se agregó Anthropic Claude como proveedor nativo de LLM.
  • Se agregaron fuentes de material de texto a video de Shengsuan AI y WaveSpeed.
  • Se agregaron configuraciones de generación de WebUI reutilizables e importación/exportación preestablecidas, incluida la copia de seguridad y restauración de la clave API opcional.
  • Se agregaron subtítulos sociales generados por LLM para cada plataforma de publicaciones cruzadas admitidas, en lugar de limitarlos a YouTube.
  • Se agregó una traducción de WebUI al italiano y un archivo README en japonés.

Seguridad

  • Se agregó autenticación de clave API opcional para puntos finales /api/v1 y archivos de tareas generados. Las instalaciones existentes siguen siendo compatibles con versiones anteriores mientras app.api_key esté vacío.
  • Entradas de audio personalizadas restringidas a ubicaciones permitidas para evitar el cruce de rutas.
  • Se evitó el acceso a los archivos de tareas generados a través de enlaces simbólicos escaping.
  • Cargas de material local reforzadas con validación de rutas y archivos más estricta.
  • Identificadores de solicitud desinfectados proporcionados por client antes de usarlos en el procesamiento de tareas.

Correcciones y mejoras

  • Se corrigió que la última línea de subtítulo fuera cli para algunas combinaciones de texto y fuentes, incluidos subtítulos multilínea y texto sin descendentes.
  • Se agregó un error de inicio procesable cuando FFmpeg no está disponible.
  • Se corrigieron los reintentos de instalación de la dependencia Docker para que las fallas persistentes del paquete detuvieran la compilación en lugar de ser ignoradas silenciosamente.
  • Revertir el estado de la tarea cuando falla la programación en segundo plano, evitando que las tareas permanezcan estancadas en un estado incorrecto.
  • Se mejoraron los esquemas de respuesta de API y se migró la configuración del modelo a Pydantic v2 ConfigDict.
  • Se registró el enrutador de verificación de estado de ping.
  • Se conservaron los límites de los párrafos en las respuestas normalizadas de LLM.
  • Distinguidas las plataformas Kimi API soportadas en configuración y WebUI.
  • Archivos de configuración manejados que contienen marcadores BOM UTF-8 repetidos.
  • Descubrimiento de voz MiniMax mejorado y audio generado validado antes de reemplazar un archivo de salida existente.

Notas de actualización

  • No se requiere autenticación de forma predeterminada. Para proteger V1 API y los archivos de tareas generados, configure app.api_key en config.toml y envíe el mismo valor en el encabezado de solicitud x-api-key.
  • Las exportaciones de configuraciones preestablecidas pueden contener credenciales de proveedor cuando la copia de seguridad de la clave API está habilitada. Almacene los archivos preestablecidos exportados de forma segura y no los envíe al control de código fuente.
  • Fish Audio, MiniMax, Anthropic Claude, WaveSpeed ​​y Shengsuan AI requieren sus respectivas credenciales de proveedor antes de poder usarse.

Se agregó el proveedor de servicios de modelo de lenguaje grande nativo Anthropic Claude. - Se agregaron fuentes de material de video de Shengsuan AI y WaveSpeed ​​​​AI Wensheng. - WebUI agrega configuraciones de generación de video reutilizables y funciones de importación y exportación preestablecidas, y admite copias de seguridad y recuperación selectivas de API Key. - Todos los canales de publicación multiplataforma compatibles ahora pueden usar modelos de lenguaje grandes para generar textos de redes sociales, y ya no se limitan a YouTube. - Se agregó traducción de WebUI al italiano y documento README en japonés. ## Seguridad - Agregue autenticación de clave API opcional a la interfaz `/api/v1` y a los archivos de tareas generados; cuando `app.api_key` permanece vacío, las instalaciones y los clientes existentes pueden seguir utilizándose sin modificaciones. - Restrinja la lectura de archivos de audio personalizados desde directorios permitidos para evitar el cruce de rutas. - Evitar el acceso a archivos fuera del directorio de tareas mediante enlaces simbólicos. - Verificación mejorada del tipo de archivo, ruta y nombre de archivo para cargas de material local. - Limpiar y normalizar el ID de solicitud pasado por el cliente para evitar afectar la ruta del archivo de la tarea y el flujo de procesamiento. ## Correcciones y mejoras - Detiene inmediatamente el inicio cuando falta FFmpeg en el sistema y proporciona un mensaje de error claro y ejecutable. - Se corrigió la lógica de reintento de instalación de la dependencia Docker para garantizar que la compilación finalice cuando el paquete continúa sin poder instalarse, en lugar de ignorar silenciosamente el error. - Revertir automáticamente el estado de la tarea cuando falla la programación de tareas en segundo plano para evitar que las tareas permanezcan en un estado de error. - Se mejoró el modelo de respuesta API y se migró la configuración de Pydantic relacionada a Pydantic v2 `ConfigDict`. - Registrar correctamente la interfaz de verificación de estado de Ping. - Preservar la estructura de párrafos y saltos de línea en respuestas de modelos de lenguaje grandes. - Clara distinción entre diferentes plataformas Kimi API en configuración y WebUI. - Admite la lectura de archivos de configuración que contienen múltiples etiquetas BOM UTF-8. - Mejore el descubrimiento y selección de parches MiniMax y verifique que el audio recién generado sea válido antes de reemplazar los archivos de audio existentes. ## Instrucciones de actualización - La autenticación API no estará habilitada de forma predeterminada y los usuarios existentes no se verán afectados después de la actualización. Para proteger V1 API y los archivos de tareas generados, configure `app.api_key` en `config.toml` y pase el mismo valor en la solicitud a través del encabezado de solicitud `x-api-key`. - Después de activar la copia de seguridad de la clave API, la configuración predeterminada de la WebUI exportada puede contener credenciales del proveedor de servicios.
