MoneyPrinterTurbo v1.2.9

¿Qué ha cambiado?

Nuevas funciones

  • Se agregaron configuraciones de script avanzadas en WebUI:
    • recuento de párrafos del guión
    • requisitos de secuencia de comandos personalizados
    • Aviso de sistema personalizado completo opcional para usuarios avanzados
  • Se agregó soporte para proveedores Xiaomi MiMo LLM.
  • Se agregó compatibilidad con el proveedor Xiaomi MiMo TTS.
  • Manejo mejorado de URL base predeterminada de Ollama para entornos Docker.

Correcciones y mejoras

  • Se corrigió el manejo de rutas de BGM personalizadas para flujos WebUI y API.
  • Se corrigió la solidez del iniciador de Windows WebUI.
  • Se corrigió webui.sh para vincular/abrir 127.0.0.1 de forma predeterminada en lugar de abrir 0.0.0.0.
  • Se corrigió el manejo del modo concat de video de cadena en descargas.
  • Se corrigió el ajuste de subtítulos para textos largos.
  • Formato de velocidad cero con signo TTS de borde fijo.
  • Se agregaron claves de traducción turcas faltantes.
  • Se corrigió la barrera del código README-en ImageMagick.

Pruebas

  • Se agregó cobertura de regresión para el comportamiento del proveedor de LLM, rutas de tareas de video/TTS locales, manejo del modo concat de video y configuración avanzada de mensajes de script.
  • Configuración de guiones avanzada verificada de un extremo a otro con generación de guiones reales, TTS, descarga de material de Pexels, generación de subtítulos y síntesis de vídeo final.
