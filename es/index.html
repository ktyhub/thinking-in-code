Método

Cómo STAGS recopila, normaliza y publica release note.

Ver →
01 Recolectar Un trabajo programado consulta las versiones GitHub API para cada repositorio rastreado, omitiendo borradores, cuerpos vacíos y versiones preliminares a menos que se configure lo contrario.
02 Normalizar Cada lanzamiento se reduce a un registro estable: proyecto, versión semántica, fecha de publicación, canal de lanzamiento y un resumen de una línea extraído del cuerpo.
03 Publicar Las notas se almacenan como Markdown en el repositorio y se representan como páginas estáticas en cada inserción, por lo que el sitio se mantiene rápido y cada entrada tiene una URL estable.
