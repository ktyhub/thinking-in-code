sherpa-onnx v2.0.0

シェルパオンクス v2.0.0

何が変わったのか

  • https://github.com/k2-fsa/sherpa-onnx/pull/3948 で @csukuangfj による dart パッケージのリリースを修正
  • https://github.com/k2-fsa/sherpa-onnx/pull/3952 の @Nathan-Roll1 によるオフライン Python の例で NeMo トランスデューサーをサポート
  • https://github.com/k2-fsa/sherpa-onnx/pull/3949 の @XDcobra により kotlin-api に OfflineDiacritization を追加
  • https://github.com/k2-fsa/sherpa-onnx/pull/3895 の @josephomills によるストリーミング NeMo トランスデューサー モデルのホットワードを使用して、modified_beam_search をサポートします。
  • https://github.com/k2-fsa/sherpa-onnx/pull/3950 の @XDcobra により GetEmbedding を SpeakerEmbeddingManager に追加
  • 修正(スーパートニック): https://github.com/k2-fsa/sherpa-onnx/pull/3958 で @utrumo による「na」言語タグを許可します
  • https://github.com/k2-fsa/sherpa-onnx/pull/3954 に @marwanelamami による 7M Kokoro 蒸留器 (アラビア語 + 英語) の変換スクリプトを追加
  • https://github.com/k2-fsa/sherpa-onnx/pull/3966 に @csukuangfj による kokoro multi lang tts の wasm デモを追加
  • https://github.com/k2-fsa/sherpa-onnx/pull/3965 の @paoloantinori によるウィスパー/コヒーレ認識プログラムにおけるバイトレベル BPE トークンの文字損失を修正
  • https://github.com/k2-fsa/sherpa-onnx/pull/3957 の @Ranjan-Bhagat による sherpa_onnx_windows Flutter パッケージで arm64 ライブラリを出荷します
  • C、CXX、JNI/Kotlin/Java、および WASM API でオフライン CTC モデルの HLG デコードをサポート (https://github.com/k2-fsa/sherpa-onnx/pull/3951 の @baszczewski により作成)
  • https://github.com/k2-fsa/sherpa-onnx/pull/3967 の @csukuangfj による Windows arm64 のダーツを修正
  • Canary: モデルの語彙から lang2id を導出し、静かに英語にフォールバックする代わりに警告します (https://github.com/k2-fsa/sherpa-onnx/pull/3962 の @paoloantinori 氏)
  • https://github.com/k2-fsa/sherpa-onnx/pull/3972 の @csukuangfj による Qwen3 ASR の字幕生成 Python API の例を追加
  • ドキュメント: Android ライブラリ (AAR) の再現可能な F-Droid ビルド (@paoloantinori 著、https://github.com/k2-fsa/sherpa-onnx/pull/3963)
  • 密造酒 v2 を修正: デコーダー encoder_attention_mask を生のオーディオ長でフィード (https://github.com/k2-fsa/sherpa-onnx/pull/3976 の @paoloantinori による)
  • https://github.com/k2-fsa/sherpa-onnx/pull/3977 の @codeachange により、online-websocket-server に --input-sample-rate オプションを追加
  • https://github.com/k2-fsa/sherpa-onnx/pull/4019 の @rokrokss による「Sherpa-onnx を使用したプロジェクト」に Recly を追加
  • Doubao ASR の字幕生成 Python API の例を追加しました。 @csukuangfj 著、https://github.com/k2-fsa/sherpa-onnx/pull/4027
  • README を更新して、@csukuangfj による China Unicom を https://github.com/k2-fsa/sherpa-onnx/pull/4028 に含めます
  • README を更新して @csukuangfj による China Life を https://github.com/k2-fsa/sherpa-onnx/pull/4029 に追加
  • README を更新して @csukuangfj によるディープシークハーネスを https://github.com/k2-fsa/sherpa-onnx/pull/4030 に含める
  • jni: 認識機能/句読点コンストラクターの C++ 例外を Java 例外に変換 (https://github.com/k2-fsa/sherpa-onnx/pull/3988 の @paoloantinori によって)
  • https://github.com/k2-fsa/sherpa-onnx/pull/4045 の @csukuangfj による Qwen3 ASR の Flutter VAD+ASR の例を修正
  • c-api: SherpaOnnxCreate* で C++ 例外をキャッチし、https://github.com/k2-fsa/sherpa-onnx/pull/4044 の @Cassian433 によって NULL を返す
  • Python の例のストリーミング パラフォーマーのエンドポイントでの沈黙のパッド 1 (ミラー C++ 動作、#1373) (https://github.com/k2-fsa/sherpa-onnx/pull/4052 の @Virtuoso461 による)
  • https://github.com/k2-fsa/sherpa-onnx/pull/4005 の @kyo-zzz によるオフライン認識機能 Swift ラッパー ビルド (ctc_fst_decoder_config の欠落) を修正
  • https://github.com/k2-fsa/sherpa-onnx/pull/4059 の @lfgranja により、zip ビルドの依存関係を v9 に更新 (RUSTSEC-2026-0367/0368/0369 をクリア)
  • https://github.com/k2-fsa/sherpa-onnx/pull/4055 の @csukuangfj によって sherpa-onnx から espeak-ng とpiper-phonemize を削除
  • https://github.com/k2-fsa/sherpa-onnx/pull/4054 に @eliandoran による Windows arm64 用の Node.js アドオン (sherpa-onnx-win-arm64) を追加
  • 速度 > 1 での短いテキストの ZipVoice ヒープ オーバーフローを修正 (https://github.com/k2-fsa/sherpa-onnx/pull/4051 の @Cassian433 により)
  • KeywordSpotter.create_stream() が https://github.com/k2-fsa/sherpa-onnx/pull/4049 の @ANDROIDHASSAN によってキーワードをエンコードできない場合に ValueError を発生させる
  • Windows arm64 npm パッケージのテストを @csukuangfj による https://github.com/k2-fsa/sherpa-onnx/pull/4069 に追加
  • https://github.com/k2-fsa/sherpa-onnx/pull/4040 の @beasaltfish による「Sherpa-onnx を使用したプロジェクト」に bot-reborn を追加
  • alsa: https://github.com/k2-fsa/sherpa-onnx/pull/3995 の @dime-online によってモノラル サンプル カウントをリサンプラーに渡します
  • 3 つの sherpa-onnx-sys build.rs の失敗を修正: カスタム Cargo プロファイル、Android 後の iOS、iOS デバイスとシミュレーター by @jameswinegar (https://github.com/k2-fsa/sherpa-onnx/pull/3991)
  • README: https://github.com/k2-fsa/sherpa-onnx/pull/3992 の @pratikgx によるデシブリ統合ガイドのリンクを修正
  • https://github.com/k2-fsa/sherpa-onnx/pull/4009 の @MohammadHijjawi97 により、generate-subtitles.py 内の不正な SRT タイムスタンプを修正
  • https://github.com/k2-fsa/sherpa-onnx/pull/4001 の @olerast67 による「Sherpa-onnx を使用したプロジェクト」に Suflyor を追加
  • https://github.com/k2-fsa/sherpa-onnx/pull/4010 の @antonsoo による、切り詰められた UTF-8 シーケンスの末尾を超えた SplitUtf8 の読み取りを修正
  • https://github.com/k2-fsa/sherpa-onnx/pull/4012 の @hulkbig によるストリームごとの FunASR Nano プロンプト オプションをサポート
  • https://github.com/k2-fsa/sherpa-onnx/pull/4016 の @dxhome により sherpa-onnx を使用してプロジェクトに SmartVoice を追加
  • https://github.com/k2-fsa/sherpa-onnx/pull/4017 の @hulkbig によるオンラインおよびオフラインの認識結果の JSON escaping を修正
  • https://github.com/k2-fsa/sherpa-onnx/pull/4018 の @hulkbig による特別なトークンのフィルタリング後のオフライン CTC タイムスタンプを修正
  • https://github.com/k2-fsa/sherpa-onnx/pull/4039 の @GeiserX による「Sherpa-onnx を使用したプロジェクト」に akou を追加
  • jni: BMP 外の文字の TTS を修正 (https://github.com/k2-fsa/sherpa-onnx/pull/4062 の @Trinorae により)
  • Linux armv7 用のビルド ホイールをリファクタリング (https://github.com/k2-fsa/sherpa-onnx/pull/4071 の @csukuangfj による)
  • プロバイダ設定キーを https://github.com/k2-fsa/sherpa-onnx/pull/3985 の @losewayy によって CUDA 実行プロバイダ (#3982) に転送します
  • jni: https://github.com/k2-fsa/sherpa-onnx/pull/4064 の @Trinorae によって BMP 以外の文字について Java に返される文字列を修正
  • ドキュメント: https://github.com/k2-fsa/sherpa-onnx/pull/4041 の @eborges78 による sherpa-onnx を使用して VocaRead をプロジェクトに追加します
  • プロジェクト内のタイプミスを修正します。 @csukuangfj 著、https://github.com/k2-fsa/sherpa-onnx/pull/4073
  • https://github.com/k2-fsa/sherpa-onnx/pull/4050 の @ANDROIDHASSAN により、vad-microphone.py および vad-alsa.py で VAD に一度に 1 つのウィンドウをフィードします。
  • https://github.com/k2-fsa/sherpa-onnx/pull/4043 の @ANDROIDHASSAN による 400 サンプル未満の入力で中止される全言語 ASR を修正
  • https://github.com/k2-fsa/sherpa-onnx/pull/4048 の @ANDROIDHASSAN による Python SpeakerEmbeddingManager メソッドで埋め込みサイズを確認してください
  • https://github.com/k2-fsa/sherpa-onnx/pull/3999 の @kyo-zzz による NeMo メル機能には NeMo の加法的ログゼロ ガードを使用します
  • GIL をリリースする前にスピーカーの埋め込み寸法を検証 (https://github.com/k2-fsa/sherpa-onnx/pull/4077 の @ANDROIDHASSAN)
  • https://github.com/k2-fsa/sherpa-onnx/pull/4075 の @csukuangfj による辞書 TTS での単語境界、OOV 単語、および Unicode 処理を修正
  • https://github.com/k2-fsa/sherpa-onnx/pull/4078 の @csukuangfj による macOS 用の Flutter APP の構築を修正
  • Python 3.15 用のホイールを @csukuangfj (https://github.com/k2-fsa/sherpa-onnx/pull/4080) によって作成
  • ロングストリーム SIGSEGV を修正するために、VAD サンプル位置を int64_t に広げます。 @csukuangfj 著、https://github.com/k2-fsa/sherpa-onnx/pull/4079
  • https://github.com/k2-fsa/sherpa-onnx/pull/4081 の @sunerpy による「Sherpa-onnx を使用したプロジェクト」に Voltip を追加
  • ドキュメント: https://github.com/k2-fsa/sherpa-onnx/pull/4074 の @DR1N0 による sherpa-onnx を使用してプロジェクトに大音量キャプションを追加
  • https://github.com/k2-fsa/sherpa-onnx/pull/4083 に @csukuangfj による Doubao ASR のタウリの例を追加
  • https://github.com/k2-fsa/sherpa-onnx/pull/4089 の @csukuangfj による Ascend CI を修正
  • @csukuangfj による v2.0.0 を https://github.com/k2-fsa/sherpa-onnx/pull/4090 でリリース
