シェルパオンクス v1.13.5

何が変わったのか

  • nemotron-3.5-asr-streaming-0.6b を https://github.com/k2-fsa/sherpa-onnx/pull/3732 の @csukuangfj によって ONNX に再エクスポートします
  • https://github.com/k2-fsa/sherpa-onnx/pull/3733 で @csukuangfj による Android KWS デモの構築を修正
  • https://github.com/k2-fsa/sherpa-onnx/pull/3734 の @csukuangfj による nemotron-3.5-asr-streaming-0.6b の ONNX エクスポート スクリプトをリファクタリング
  • https://github.com/k2-fsa/sherpa-onnx/pull/3736 の @csukuangfj により、QNN SDK 環境をセットアップするための docker イメージを構築します
  • nemotron-3.5-asr-streaming-0.6b を https://github.com/k2-fsa/sherpa-onnx/pull/3741 の @csukuangfj によって QNN にエクスポートします
  • https://github.com/k2-fsa/sherpa-onnx/pull/3739 の @willwade により Android 共有リンクのサポートを sherpa-onnx-sys に追加
  • https://github.com/k2-fsa/sherpa-onnx/pull/3742 での @csukuangfj によるビルド警告を修正
  • https://github.com/k2-fsa/sherpa-onnx/pull/3744 の @ekenberg により、Scale > 1 の場合に一時停止間隔を超えて ScaleSilence がコピーされる問題を修正
  • https://github.com/k2-fsa/sherpa-onnx/pull/3745 の @ekenberg による無効な沈黙スケールに対する ScaleSilence のガード
  • https://github.com/k2-fsa/sherpa-onnx/pull/3747 の @ekenberg により、Validate() と ScaleSilence の間の無音スケール範囲を調整します
  • Moonshine ASR モデルを https://github.com/k2-fsa/sherpa-onnx/pull/3756 の @csukuangfj によって QNN にエクスポートします
  • https://github.com/k2-fsa/sherpa-onnx/pull/3758 の @csukuangfj により、Qualcomm NPU の QNN を使用した Moonshine ASR の C++ ランタイムを追加
  • https://github.com/k2-fsa/sherpa-onnx/pull/3763 の @csukuangfj によって vits-piper-pt_BR-cadu-medium を Huggingface にアップロードします
  • https://github.com/k2-fsa/sherpa-onnx/pull/3774 で @csukuangfj による Piper TTS モデルのアップロードを修正
  • https://github.com/k2-fsa/sherpa-onnx/pull/3749 で @ekenberg による espeak-ng が音声を拒否したときのプロセスの中止を修正 (例: 無効な --kokoro-lang)
  • https://github.com/k2-fsa/sherpa-onnx/pull/3750 の @ 参考までに、Supertonic TTS テキスト フロントエンドで削除された発音記号を修正しました。
  • https://github.com/k2-fsa/sherpa-onnx/pull/3775 の @ 参考までに、「sherpa-onnx を使用したプロジェクト」に Fono を追加しました。
  • FireRedASR デコーダ KV キャッシュを最大値ではなく推定必要量で割り当てます…by @Kn0688 in https://github.com/k2-fsa/sherpa-onnx/pull/3777
  • @csukuangfj による Java API の Maven サンプルを https://github.com/k2-fsa/sherpa-onnx/pull/3783 に追加
  • https://github.com/k2-fsa/sherpa-onnx/pull/3784 に @csukuangfj による Gradle を使用した Java API の例を追加
  • https://github.com/k2-fsa/sherpa-onnx/pull/3785 の @csukuangfj による Nemo ストリーミング トランスデューサーの貪欲検索デコードを修正
  • Java API のリファクタリングとテスト (https://github.com/k2-fsa/sherpa-onnx/pull/3786 の @csukuangfj による)
  • https://github.com/k2-fsa/sherpa-onnx/pull/3787 の @Kn0688 によりハードコーディングされたキャッシュ長を持つモデルのアダプティブ KV キャッシュを修正
  • https://github.com/k2-fsa/sherpa-onnx/pull/3778 の @sportiz91 によりファイルから無音部分を削除する ten-vad Rust API の例を追加
  • ドキュメント (rust): @stantheman0128 による FunASR Nano オフライン ASR サンプル (#3210) を https://github.com/k2-fsa/sherpa-onnx/pull/3772 に追加
  • https://github.com/k2-fsa/sherpa-onnx/pull/3781 の @kecoco16 による非同期 TTS 進行コールバックの use-after-free を修正
  • Pyannote セグメンテーション ウィンドウのシフトを https://github.com/k2-fsa/sherpa-onnx/pull/3769 の @JulianPscheid によって設定可能にします
  • https://github.com/k2-fsa/sherpa-onnx/pull/3768 の @JulianPscheid によるデバッグ モードでのオフライン スピーカー ダイアライゼーションのステージごとのタイミングを出力します。
  • https://github.com/k2-fsa/sherpa-onnx/pull/3793 の @kecoco16 により sherpa-onnx を使用するプロジェクトに Domia を追加
  • SessionConfig. というプレフィックスが付いたプロバイダー構成キーを、https://github.com/k2-fsa/sherpa-onnx/pull/3792 の @kecoco16 によって Ort::SessionOptions::AddConfigEntry に転送します
  • https://github.com/k2-fsa/sherpa-onnx/pull/3794 の @LauraGPT による macOS リリース コード署名を修正
  • https://github.com/k2-fsa/sherpa-onnx/pull/3796 の @Kn0688 による高速スピーチのために、FireRedASR デコード キャップを 6 トークン/秒から 8 トークン/秒に引き上げます。
  • https://github.com/k2-fsa/sherpa-onnx/pull/3799 の @Kn0688 によって、FireRedASR のデフォルトの max_token_per_second を 8 に設定します
  • Java api の例の build.gradle.kts を簡略化します。 @csukuangfj 著、https://github.com/k2-fsa/sherpa-onnx/pull/3788
  • Windows arm64 での Java API のテスト (https://github.com/k2-fsa/sherpa-onnx/pull/3801 の @csukuangfj による)
  • https://github.com/k2-fsa/sherpa-onnx/pull/3806 の @x6prl による UB を修正

  • https://github.com/k2-fsa/sherpa-onnx/pull/3808 の @csukuangfj により Inflect TTS モデルを sherpa-onnx にエクスポート
