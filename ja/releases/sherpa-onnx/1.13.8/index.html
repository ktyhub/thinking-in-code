sherpa-onnx v1.13.8

パッチ 公開日2026年9月10日 出典k2-fsa/sherpa-onnx 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

シェルパオンエックス v1.13.8

何が変わったのか

  • https://github.com/k2-fsa/sherpa-onnx/pull/3911 での @csukuangfj によるリリースを修正
  • https://github.com/k2-fsa/sherpa-onnx/pull/3912 の @fra-shipper による FunASR-Nano および Qwen3-ASR オフライン レコグナイザーの共有 PRNG でのデータ競合を修正
  • Android デバイス上の termux ターミナル内でのビルドのサポート (https://github.com/k2-fsa/sherpa-onnx/pull/3916 の @csukuangfj による)
  • Android 上の Termux で Python を使用した sherpa-onnx をサポート (https://github.com/k2-fsa/sherpa-onnx/pull/3922 の @csukuangfj により)
  • https://github.com/k2-fsa/sherpa-onnx/pull/3932 の @csukuangfj による Windows 用 CI の Go API テストを修正
  • https://github.com/k2-fsa/sherpa-onnx/pull/3928 に @kroryan によるココロ v1.0 em_santa の声を追加
  • Kokoro ランタイム用の Nabra-82M アラビア語 TTS 変換スクリプトを @marwanelamami による https://github.com/k2-fsa/sherpa-onnx/pull/3898 に追加
  • https://github.com/k2-fsa/sherpa-onnx/pull/3924 の @kyo-zzz による無音音声での Cohere Transcribe の幻覚文章を修正
  • https://github.com/k2-fsa/sherpa-onnx/pull/3923 の @kyo-zzz による無音音声での Moonshine v2 の幻覚テキストを修正
  • https://github.com/k2-fsa/sherpa-onnx/pull/3921 の @kyo-zzz によるサイレントオーディオ上の FunASR-Nano 幻覚テキストを修正
  • 最初にデコードされたトークンが eos の場合の Canary の空のトランスクリプトを修正 (https://github.com/k2-fsa/sherpa-onnx/pull/3920 の @kyo-zzz による)
  • https://github.com/k2-fsa/sherpa-onnx/pull/3910 の @jacob-vincent-mink による OpenVINO を介した Intel NPU サポートを追加
  • https://github.com/k2-fsa/sherpa-onnx/pull/3881 の @matiaslin による OfflineSpeakerDiarization のセグメントごとの信頼計算を追加
  • nabra 82M アラビア語 TTS int8 モデルを @csukuangfj によって https://github.com/k2-fsa/sherpa-onnx/pull/3933 にアップロード
  • https://github.com/k2-fsa/sherpa-onnx/pull/3934 に @csukuangfj による Windows arm64 用の Go API を追加
  • https://github.com/k2-fsa/sherpa-onnx/pull/3936 の @matiaslin による OfflineSpeakerDiarization 信頼度計算用の Go バインディングを追加
  • 修正（nemo/qnn/parakeet-ctc）：wrapper.py は、https://github.com/k2-fsa/sherpa-onnx/pull/3937 の @Anai-Guo により未定義の feat_dim で NameError を発生させます
  • https://github.com/k2-fsa/sherpa-onnx/pull/3940 の @csukuangfj による CI テストを修正
  • https://github.com/k2-fsa/sherpa-onnx/pull/3935 の @csukuangfj により、onnxruntime を v1.28.2 に更新
  • https://github.com/k2-fsa/sherpa-onnx/pull/3941 の @csukuangfj により、すべてのテスト スクリプトに堅牢なダウンロード再試行ロジックを追加
  • https://github.com/k2-fsa/sherpa-onnx/pull/3942 の @csukuangfj による Android 内の termux での Rust API サンプルの実行をサポート
  • 話者ダイアライゼーションの信頼度計算サポートを JNI に追加します。 @csukuangfj 著、https://github.com/k2-fsa/sherpa-onnx/pull/3943
  • 修正(python-tests): https://github.com/k2-fsa/sherpa-onnx/pull/3944 の @Anai-Guo による test_fast_clustering の意図された ValueError の代わりに UnboundLocalError
  • https://github.com/k2-fsa/sherpa-onnx/pull/3946 の @csukuangfj による、uv を使用した sherpa-onnx のインストールのテスト
  • @csukuangfj による v1.13.8 を https://github.com/k2-fsa/sherpa-onnx/pull/3945 でリリース

  • @kroryan が https://github.com/k2-fsa/sherpa-onnx/pull/3928 に初めて投稿しました
