#メンパレスv3.12.0

MemPalace 3.12 は、ソース テキストとバイトをそのまま保持し、中断された再マイニングを回復可能にし、大規模な宮殿の維持に必要な作業を削減します。タイムスタンプとプロジェクト ウィングは、ツールとフック全体で同じルールに従います。 Antigravity にはビジュアルな Palace エクスプローラーが追加され、最終リリース レビューではグラフ ID の衝突、同時チェックポイントの重複、ドキュメント フィルタリング、および最新から順のページネーションが修正されています。

アップグレードに関する注意事項

  • Python 3.10 以降が必要です。 Python 3.9 はサポートされなくなりました。ネイティブ ホイールは Python 3.10+ ABI を使用します。
  • 次の鉱山では、対象となる各ソースを 1 回再読み込みします。 正規化バージョン 3 では、解析とバイト保存の修正が行われます。テキストが変更されていないドロワーは、保存されているベクトルを再利用します。変更されていないファイルには、クローゼットと AAAK サマリーが保持されます。ディスク上に存在しないソースは、既存のドロワーを保持します。アップグレードする前に大きな宮殿をバックアップし、この最初のパスに時間をかけてください。 (#2813)
  • 最初の廊下書き込み時に廊下は SQLite に移行します。 hallways.json はトランザクション的に hallways.sqlite3 にインポートされ、.imported-* 名で保持されます。古いバージョンでは古い JSON ファイルが書き込まれるため、パレスを共有するすべてのインストールをアップグレードしてください。ダウングレード後、mempalace hallways --rebuild を使用して派生廊下を再構築します。 (#2895)
  • 新しいタイムスタンプには明示的な UTC オフセットが含まれます。 従来の単純なタイムスタンプは、書き込まれたときの現地時間として読み取られます。既存のメタデータは書き換えられません。日付のみのフィルターは、依然として現地の暦日を意味します。プロジェクト ウィングでは、CLI、MCP、マイニング、フック全体で 1 つのスラッグ ルールも使用します。フィルタは、保存されている従来のスペルを引き続き検索します。 (#2851、アップグレードの詳細)
  • **ローカル HTTP ハブはトークンなしで実行できます。 ** プレーン ループバック バインドはデフォルトでトークンレスのままで、ブラウザーの起点、ホスト、およびプロキシ ヘッダーのチェックが行われます。プロキシまたはトンネルがトラフィックをハブに転送するたびにトークンを構成します。すべての POST /mcp には Content-Type: application/json が必要になりました。
  • closet_llm 環境変数の名前を、LLM_ENDPOINT、LLM_MODEL、LLM_KEY から MEMPALACE_LLM_ENDPOINT、MEMPALACE_LLM_MODEL、MEMPALACE_LLM_KEY に変更します。外部 LLM エンドポイントには明示的な同意が必要です。 mempalace.dedup と mempalace.onboarding は削除されます。エンベッダーのセットアップには mempalace init --embedding-model ... を使用します。 (#2773)
  • PQL 検索フィルターでは大文字のキーワードが使用されます。 FIND auth IN backend と記述します。小文字の in、limit、source、since、before は検索テキストの一部として残ります。 mempalace_search では、デフォルトの距離カットオフも削除されます。必要な場合は、明示的に max_distance を渡します。 (#2725、完全なアップグレードノート)

ソースの忠実性と回復可能な書き込み

  • 会話マイニングでは、ユーザーのターンが書かれたとおりに保存されます。 スペル修正はデフォルトでオフになっています。 ChatGPT インポートはアクティブな会話ブランチに従い、エクスポートを繰り返すと各ソース ファイルの下にドロワーが保持され、クロード メッセージは空白行が保持され、Gemini テキスト パーツは clients の意図どおりに結合されます。コンテンツを削除または変更する解析ステップは、transforms メタデータに記録されます。 (#2790、#2796、#2800)
  • 非 UTF-8 ソース バイトはマイニングおよびエクスポートに耐えます。 メタデータのエンコーディングにより正確な再構築が可能になります。 MCP client は JSON 互換の表示テキストを受け取りますが、mempalace_get_drawer と include_source_bytes: true は正確なドロワー ソース バイトを Base64 として返します。 NUL 文字と単独のサロゲートはストレージを往復します。 (#2802)
  • 再マイニングは、古いドロワーを削除する前に、代替ドロワーを書き込みます。 書き込みが失敗すると回復可能なテキストが残り、次のマイニングで中断された公開が完了します。日記の取り込みでも同じ順序が使用されます。読めない採掘状態は、空の宮殿と間違われるのではなく、実行を停止するようになりました。 (#2798)
  • ドロワーの更新では、置換されるテキストが保持されます。 以前のテキストとメタデータは置換前に追加され、drawer_revisions.jsonl に同期されます。リビジョンの書き込みが失敗すると、元のドロワーはそのまま残ります。削除すると、対応するリビジョン履歴が削除されます。 PQL ドロワーとダイアリーの書き込みでは、リテラルのエスケープ、スペース、数値に見えるコンテンツも保持されます。 (#2866、#2772)
  • mempalace export <dir> は翼と部屋をマークダウンとしてエクスポートします。 バックエンドの移行と修復では、グラフ データ、クローゼット、サイドカーが保存されます。 (#2779)

パフォーマンスと大きな宮殿

  • sqlite_exact 書き込みは、フルテキスト インデックスのスキャンを停止します。 測定された 336,000 行のパレスでは、50 個のドロワーを追加すると、約 10 秒から 10 ミリ秒に短縮されました。既存のパレスは、次回書き込み可能なオープン時に、不一致のフルテキスト行 ID を 1 回修復します。 (#2744)
  • 廊下の更新により、影響を受ける翼が変更され、記録が変更されます。 830,000 の廊下を備えたコピーされた 228,000 の引き出しの宮殿では、測定された翼のリマイニングは約 20 秒から 1 ～ 4 秒に低下し、ピーク メモリは 3.8 GB から約 150 MB に減少しました。 JSON を初めて輸入する場合でも、一度限りの費用がかかります。 (#2895)
  • インデックス付きの最新順読み取りにより、ウェイクアップとブラウジングが高速化します。 測定された 150,000 ドロワーの sqlite_exact パレスでは、2,000 ドロワーのリーセンシー読み取りが 1.5 秒から 80 ミリ秒に、または翼にスコープを設定した場合は 5 秒から 60 ミリ秒に低下しました。 SQLiteExact および Qdrant メタデータの反復により、オフセット スキャンの繰り返しも回避されます。
  • フォアグラウンドでのフックの消費時間が短縮されます。 ストップフック ダイアリー セーブはバックグラウンドで実行され、ウェイクアップにより、必要になるまで検索スタックのインポートが回避され、stdio MCP サーバーは、変更呼び出しのたびにピア ライター リースを解放して、別のセッションが書き込みできるようにします。 (#2769、#2909)

反重力宮殿の探検家

  • バンドルされた Aux Pane 拡張機能により、Recall、Palace、Graph、Logstream ビューが Antigravity に提供されます。 翼、部屋、トンネルを閲覧し、引き出しを逐語的に検査し、アクティブおよび歴史的な KG の事実を探索し、調整イベントや日記を追跡します。 Recall は、語彙検索、ハイブリッド検索、およびベクトル検索をサポートしており、チャットで引用およびファイルを開くアクションを備えています。 (#2983)
  • 正規プラグイン バンドルは plugins/mempalace にあります。 これには、MCP 設定、リコール ルールとスキル、さらにクロスプラットフォーム Node.js 保存フックとウェイクアップ フックが含まれています。 agy plugin install ./plugins/mempalace を使用してチェックアウトからインストールします。 Python パッケージは依然として前提条件です。 反重力ガイドを参照してください。 (#2984)

リリースレビューによる正確性の修正

  • レガシー グラフのインポートはエンティティのアイデンティティを保持します。 プレビューと適用で正規名を比較し、依存するサブジェクトとオブジェクトの参照を一貫して再マップし、未解決の競合とスキップされたファクトをレポートします。 O'Brien / OBrien および my_project / my project の衝突ケースには、再オープン後の永続性を含む回帰テストがあります。 (#2985)
  • 同時チェックポイントは、互いの重複決定を無効にすることはできません。 重複チェックとドロワーのパブリケーションはシリアル化されたままとなり、埋め込み中に同じメモリが異なるルームに 2 回保存されるのを防ぎます。制御された同時保存回帰が競合をカバーします。 (#2985)
  • Chroma ドキュメント フィルターは元のテキストを評価します。 エスケープされたストレージは、一致する Windows パスを非表示にしたり、エンコード マーカーに一致を作成したりすることがなくなりました。フィルタリングでは、ベクトルクエリの順序が保持され、デコードされたテキストをチェックした後にページネーションが適用されます。 (#2985)
  • Palace ビューア ページは結果セット全体で最新順のままです。 選択されたページは要求された順序でハイドレートされ、Chroma フォールバックはスライスする前に一致するすべてのメタデータを読み取ります。回帰テストは、最適化されたリーダーが使用できないかロックされている場合に、提供されたページネーションのケースと 1,501 個の個別のドロワーの両方をカバーします。 (#2992)
  • Chroma 警告リグレッションは、無関係なクリーンアップ警告を無視します。 CI プローブは、カテゴリおよびメッセージごとに意図された警告をチェックします。 (#2987)

その他の修正とセキュリティ

  • ナレッジ グラフ ツールは 1 つのパス リゾルバーを共有します。 読み取りがサイレントにグラフを切り替えたり、空のグラフを作成したりすることはなくなりました。 mempalace kg import-legacy は明示的なインポートをプレビューし、それを --yes で適用します。 --from はソースを選択します。新しいエンティティ ID では句読点が保持され、エンティティを再追加するとプロパティがマージされ、同一の履歴アサーションの重複が削除されます。 (#2850、#2770、#2605)
  • 新しい Codex ロールアウトが再びマイニングされます。ハブがライター リースを所有している間、ハブ ルートのダイアリー チェックポイントが機能し、完了したフック マイニングは PID スロットを解放します。修復再構築により、FTS5 の整合性が検証され、調整ログが保存されます。 (#2947、#2625、#2943、#2738)
  • モデル プロバイダーは、現在の推論モデル パラメーターを処理します。 人間の呼び出しでは、拒否されたデフォルトの温度が省略されます。 OpenAI 互換の推論は、拒否されたパラメーターなしで再試行を呼び出し、必要な完了トークン フィールドを使用します。 (#2964、#2924)
  • フック、デーモンの子、および serve は、作業ディレクトリのインポートを除外します。 プロジェクト構成の書き込みでは、シンボリック リンクが拒否され、制限された複雑さの一致が無視され、状態ファイルは Windows セーフな再試行で新しい一時ファイルを介して公開されます。
  • 資格情報はリダイレクトと診断テキストから除外されます。 HTTP clients は資格情報を含むリダイレクトを拒否し、エンドポイントのユーザー情報と機密のクエリ パラメーターはマスクされ、外部モデルの呼び出しには明示的な同意が必要です。 (#2858、#2959)
  • MCP と同期の境界により、意図したチェックが強制されます。 ライト サーバー アクションは許可リストに登録され、デーモン ツール ジョブはディスパッチャー ゲートを使用し、ピア イベントとアーティファクトは保存前に検証されます。 Windows ハブはポートを排他的に予約しており、ライターもまた、さまざまなホーム ディレクトリにわたって宮殿に隣接するロックを争っています。
  • ロックされた依存関係は、urllib3、Pillow、pydantic-settings、virtualenv などのアドバイザリ修正を受け取ります。パッケージの要件は変わりません。 (#2960)

インストール/アップグレード

pip install --upgrade mempalace==3.12.0
# or: uv tool upgrade mempalace / pipx upgrade mempalace

オプションの EmbeddingGemma 2 とメディア検索は、mempalace[embeddinggemma2] および mempalace[multimodal] を通じて引き続き利用できます。ネイティブ ホイールとスタンドアロン実行可能ファイルは、リリース ワークフローによって構築されます。 ネイティブ インストール ガイド を参照してください。 以下にリストされている 18 人の初めての貢献者を含む、コード、バグ レポート、リリース レビューに貢献してくれたすべての人に感謝します。このリリースには 163 のマージされたプル リクエストが含まれています。リリースレビューとページネーションパッチを提供してくれた @milla-jovovich に感謝します。
