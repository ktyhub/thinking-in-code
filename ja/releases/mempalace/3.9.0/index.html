mempalace v3.9.0

#メンパレスv3.9.0

v3.9.0 — 各エージェントに 1 つのハブ

1 つのハブがすべてのエージェントに対応するようになりました。 CLI 検索では、別のマルチギガバイトの HNSW コピーをロードする代わりにライブ パレス インデックスが再利用され、同時検索により相互のブロックが停止され、スキル優先の調整とオプトイン リリースの認識により、共有ブレイン フリートの安全な運用が容易になります。

共有ハブと検索

  • mempalace search は健全なライブ ハブを再利用します。 報告された 4.99-million-vector 宮殿では、2 回の直接 CLI 検索により、約 18.6 GB のプライベート RSS が保持されました。転送可能な検索では、フィルター、ランキング、出力、認証、構成ネゴシエーション、安全なフォールバック動作を維持しながら、ハブ コレクションを再利用できるようになりました。 (#2379)
  • ハブの読み取りは同時に実行されます。 検索は 1 つの排他的な HTTP ディスパッチ ロックの背後でシリアル化されなくなりました。読み取りは書き込み優先ロックを共有しますが、ミューテーションは排他的のままです。 (#2398)
  • 検索結果がより明確になり、より迅速に強化されます。 パブリック類似度は生のベクトル スコアであり、クローゼット ブーストは効果的なランキングに残り、ソース ルックアップはインデックス付けされ、重複した強化されたパッセージは削除されます。 (#2399、#2143)
  • プライベート クエリやコーパス テキストを公開せずに製品検索を評価するためのプライベート パレス ベンチマークが含まれています。 (#2400)

エージェントの調整と運用

  • スキルファーストのセットアップとタスクのハンドオフ。 ガイド付きセットアップ スキルは、プライベートまたは共有ブレイン インストールのブートストラップ、正規ルールのレンダリング、安定したフリート ID の割り当て、ログストリームの準備状況の検証を行うことができます。タスク作成では、制御された起動の前に、不変のベースコミットと完了の完全な定義が記録されるようになりました。 (#2374、#2361)
  • リリースの認識は明示的でオプトインです。 エージェントは、ブロック、自動インストール、またはネットワーク チェックをサイレントに有効にすることなく、キャッシュされたアップデートの状態を表示し、正確なアップグレード プランを準備できます。 (#2376)
  • Logstream はトピック ルーティングと逆ページネーションを備え、追加専用カーソルの保証を弱めることなく、集中的な調整と最新から順の検査を実用化します。 (#2397)

正確性とリソースの安全性

  • 読み取り不可能な構成は決して上書きされません。 無効なファイルは保持され、書き込みは可能な限りアトミックに行われ、シンボリックリンクはそのまま残り、UTF-8 プロジェクト構成は一貫して処理されます。 (#2357、#2353、#2369)
  • ドロワーの変更により、古いクローゼット エントリが削除され、 単一の会話ファイルが実行中のハブを通じて正しくマイニングされ、不在の SQLite データベースによって誤ったクリーン整合性の判定が報告されなくなりました。 (#2355、#2282、#2291)
  • Qdrant の制限付き読み取りはコレクション全体のスキャンを停止します。メモリに制約のあるハードウェア上の長いドロワーでは、EmbeddingGemma の内部バッチを削減できます。 (#2384、#2383)

ご協力いただいた皆様に心より感謝申し上げます。このリリースには、29 のマージされた PR と 7 人の初貢献者が含まれています。

インストール: pip install -U mempalace==3.9.0
