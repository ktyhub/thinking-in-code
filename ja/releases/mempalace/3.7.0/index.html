#メンパレスv3.7.0

v3.7.0 — エージェント ログストリーム、整合性スパイン、およびプラグイン可能な埋め込み

このリリースの見出しは、エージェント ログストリームの調整です。追加専用のローカル ファースト イベント レイヤーにより、別のマシン上のエージェントが、人間がメッセージを中継することなく、MemPalace ハブを介して作業を委任し、応答を待ち、パッチを交換し、ハンドオフを確認できるようになります。 3.7.0 のその他すべては、ローカルファーストのデフォルトを変更することなく、マルチセッション負荷の下で長寿命のパレスを強化し (単一ライターの所有権、より安全な修復/再マイニング、MCP ライフサイクル)、埋め込み/検索オプション (OpenAI 互換の埋め込み、検索日付ウィンドウ) を拡張します。

機能

  • エージェント ログストリーム調整 (RFC 003)。 マルチエージェント作業用の追加専用イベント レイヤー: 永続的なタスク パケット、待機/ACK ハンドオフ、パッチおよびファイル アーティファクト、MCP HTTP ハブ (GET /logstream/stream SSE) を介したライブ テーリング。 MCP ツールには、mempalace_event_append / list / wait / ack、アーティファクトの挿入/取得、およびパッチの送信が含まれます。 CLI mempalace logstream は、コア動詞を反映しています。イベントとアーティファクトはローカルにそのまま保持され、引き出し宮殿 (logstream.sqlite3) から分離されます。共有頭脳/複数マシンのエージェント フリートでは、ホスト間でステータスを中継するために人間が必要なくなります。 (#2162、フェーズ 1 ～ 5)
  • ログストリーム マルチマスター同期基盤 (RFC 004 ステップ 0)。 エステート レベルのログストリーム レプリケーション フックにより、調整されたエージェントが宮殿のレプリカ間で調整レイヤーを共有できるようになります。これは、複製された共有頭脳のストレージ ステップです。 (#2162、ログ同期)
  • OpenAI 互換の埋め込み。 オプトイン embedding_model: "openai-compat" は、stdlib urllib 経由で任意の /v1/embeddings エンドポイント (LM Studio、llama.cpp、vLLM、Ollama の OpenAI シム、または自己ホスト型サーバー) と通信します。新しい依存関係はありません。 Config vars と env vars は URL、モデル、キーを設定します。モデル ID はエンベッダー名の一部であるため、モデルを変更するとインデックスの再作成が強制されます。デフォルトの MiniLM/ONNX パスは変更されません。 (#1671、#1559)
  • 日付検索ウィンドウ。 mempalace_search および mempalace search は、since / before (filed_at では [since, before)) を受け入れ、mempalace.date_window を介して list_drawers と共有します。日付のないドロワーは、バインドがアクティブな間は除外されます。ベクトル候補プールはフィルターの下で拡張され、プールがいっぱいになると切り捨てを報告します。 (#2000、#463)
  • Hermes メモリ プロバイダー (コア)。 パッケージ内の Hermes MemoryProvider ファイルは file_conversation_exchange() を介してライブ ターンされるため、メタデータはコンボ マイニングと一致し、バックグラウンド ワーカーによってエージェント ループがブロックされることはありません。インストール/バックフィル/ドキュメントは引き続きフォローアップとして積み重ねられています。 (#1915、#2215)
  • 私の場合は RFC 002 ソース アダプタ。 mempalace mine <source> --source <adapter> は登録されたアダプタを解決し、完全な取り込みのためのパレス ライター リースを保持し、ドライランを不活性に保ちます。レガシー --mode パスは変更されません。 (#2068、#2062)
  • デーモンを介して書き込みルーティングをフックします。 バックグラウンド フックの保存とマイニングは共有書き込みルーティング ポリシーを尊重できるため、マルチセッション セットアップは 1 人のローカル オーナーを通じて変更をシリアル化します。 (#2030、#1963)

パフォーマンス

  • EmbeddingGemma は、サブバッチ化する前にドキュメントをサイズ別にグループ化します。ベクトルの意味を変えることなく、長いスイープでのパディングされたトークンの作業を削減します。 embedding_model: embeddinggemmaのみに適用されます。 (#2104)
  • HNSW キャパシティ プローブはキャッシュされ、パレス ファイル署名によって無効化されるため、繰り返されるステータス/分類パスが呼び出しのたびにネイティブ セグメントを再スキャンすることがなくなりました。 (#2051、#1471)
  • chunk_text の行番号付けは O(N) で、大規模なソースでの数秒間のハングを修正します。 (#2054、#2055)

バグ修正

  • マイニングはデフォルトの Chroma バックエンドで再び機能します。 明示的な埋め込み書き込みでは、normalize_embeddings が拒否する Chroma np.float32 スカラーを処理しなくなります。 (#2187)
  • ChatGPT データのエクスポートは会話として解析されます。生の JSON 配列としては保存されません。 (#2160)
  • ローカル バックエンドでは、プロセス存続期間中、単一ライターの所有権が強制されます。 ファイルでバックアップされたパレスには、プロセス存続期間中に 1 人のライター所有者が必要です。読み取り専用の MCP は共存できます。リモート バックエンドはマルチプロセスのままです。 (#2079、#2045)
  • MCP は、再起動せずにアップグレードした後、提供されるライブラリがドリフトすると書き込みを拒否します (バックエンドがアクティブな場合は mempalace、および chromadb)。 MEMPALACE_MCP_ALLOW_STALE_LIBRARY でオプトアウトします。 (#2081、#899)
  • Chroma HNSW 書き込みのデフォルトは chromadb (batch_size=100 / sync_threshold=1000) と一致し、古い 2/2 ブロート ガードは廃止されます。 (#2107、#2106)
  • 競合下では修復とリカバリがより安全です。 アーカイブ前にマインロックし、スワップ失敗時に一時コレクションを保存し、切り捨てられたページネーションで大音量で失敗します。ドライランは、レガシー モードと from-sqlite モードの両方での真のプレビューです。バックアップはソケット/パイプ/デバイス ノードをスキップするため、ライブ パレス ソケットが修復/移行を中止することはなくなりました。 (#2109、#2086、#2087、#2133、#2144、#2207、#2212)
  • rebuild_index は、スナップショット→再構築/スワップ サイクル全体のパレス ライター リースを保持します。 (#2195)
  • 孤立したソースごとの鉱山ロックが刈り取られます (年齢 + ブロックされていない群れ)、15 分に 1 回に制限されます。宮殿レベルの水門は手つかずのままです。 (#2200)
  • HNSW ダイバージェンスは、鉱山、重複排除、移行、修理、宮殿ヘルパーを横断して残りの count() 墜落現場に到達する前にプリフライトされます。 (#2093)
  • 再マイニングと会話の取り込みでドロワーが失われたり重複したりすることはなくなりました。 コンテンツ ハッシュの重複除去、スイーパー パージ スコープ、検索時のラウンドトリップ可能な drawer_id。クロード コード subagents/ はデフォルトでスキップされます (オプトインするには --include-subagents)。 (#2050、#2125、#2090、#1330、#1217)
  • MCP とデーモンのライフサイクルにより、マルチエージェントの使用が強化されます。 読み取り専用は、config/checkpoint-ack ホストの変更を拒否します。標準出力は EOF で終了します。デーモンはロックが拒否されたジョブを延期します。プロトコル ストリームを復元できない場合、Windows の標準出力キャプチャはフォールバックするかフェールクローズされます。 (#2126、#2072、#2029、#2211、#2210)
  • エンコーディングと Windows ロケールの強化。 設定/方言で UTF-8 を固定すると開きます。 mojibake 修復により、きれいなポルトガル語/ベトナム語/トルコ語の散文が破壊されなくなりました。修復エンコーディング CLI は標準入出力を再構成します。 GBK コンソール用に非 ASCII CLI シンボルが置き換えられました。 (#2098、#2208、#2194、#1104、#1034、#2193)
  • 小さな正確性の修正。 エンティティ候補 ReDoS ガード。病的なchunk_overlapを拒否します。ワークツリー cwd はプロジェクト ウィングにマップされます。値下げの強調は感情ではありません。サービス エントリポイントは MEMPALACE_PALACE_PATH を復元します。 systemd Restart=always とアイドル状態のウォッチドッグのドキュメント。有効な docker-compose.yml 環境キー。 (#2127、#2056、#2206、#2199、#2192、#2203、#2204、#2188)

ドキュメント

  • エージェント ログストリームのコンセプト ページ、調整プロトコル、共有ブレイン フリート ガイド、および RFC 003/004。 (#2162)
  • オペレーターの書き込みルーティング/シングルライターのリカバリに関するメモ。 (#2079)
  • リモートサーバーのアイドルウォッチドッグと読み取り専用セマンティクス。 (#2126、#2204)
  • README Docker セクションには、公開された画像と実際のマウント/許可の落とし穴が記載されています。 (#2196)
  • MX3 public-shim の例と COTRIBUTING Discussions のクリーンアップ。 (#597、#555)

内部

  • Docker パブリッシュは、実際のスモーク スクリプト (Compose 解析、鉱山、MCP ハンドシェイク) に基づいてゲートされます。 (#2189)
  • 空のバッチ/プレーンシーケンス回帰テストの埋め込み。 HNSW のデフォルト アサーション。 (#2191、#2159) このリリースに貢献してくださった皆様に心より感謝いたします。貢献者および初めての貢献者は以下にクレジットされます。
