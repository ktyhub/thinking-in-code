#メンパレスv3.4.1

v3.4.1 — カーソルと反重力 IDE のサポート

現在、さらに 2 つのエディターがサポートされています。ネイティブ フックを備えた Cursor プラグインと、ファーストクラスの Google Antigravity サポートです。どちらも、MemPalace の自動保存、セッション開始リコール、および逐語的トランスクリプト マイニングを、すでにクロード コードとコーデックスに提供されているのと同じ標準に引き上げます。 2 つの信頼性に関する修正がこのサイクルを締めくくります。embeddinggemma は大規模な再埋め込みを OOM キルしなくなり、migrate / repair バックアップはディスクがいっぱいになるまで蓄積を停止します。

機能

  • カーソル IDE プラグイン (.cursor-plugin/)。 mempalace-mcp サーバー、5 つのスラッシュ コマンド (/mempalace-help、/mempalace-init、/mempalace-mine、/mempalace-search、/mempalace-status)、およびモデル呼び出し可能なスキルを自動登録します。手動での ~/.cursor/mcp.json 編集は必要ありません。今すぐローカル クローンからインストールするか、公開されたら Cursor マーケットプレイスからインストールします。 (#1632)
  • カーソル IDE フック (stop / preCompact / sessionStart)。 N エージェント ターンごとのバックグラウンド自動保存、カーソルが圧縮される前の同期トランスクリプト マイニング、およびワークスペース ウィングに範囲を限定したセッション開始メモリの呼び出し。 hooks/cursor/install.sh (--scope user|project、--variant full|minimal、--dry-run、--uninstall) の 1 つのコマンド インストーラー — 冪等で依存関係がありません。
  • ファーストクラスの Antigravity (Google) IDE サポート。 新しい .antigravity-plugin/ パッケージと、MemPalace を Antigravity プラグインとして登録する冪等インストーラー — MCP サーバー、スキル、および 2 つのライフサイクル フック (Stop でのバックグラウンド マイニング、最初のモデル呼び出しでの逐語的メモリ インジェクション)。 bash 3.2 / macOS 互換で、Claude Code / Codex / Cursor フックと同じ ~/.mempalace/hook_state/ ディレクトリを共有し、既存のキル スイッチをすべて尊重します。 (#1633、#1771)
  • フックのゼロ設定インタープリタ解決 フックは、python3 にフォールバックする前に、mempalace-mcp コンソール スクリプト シバンから Python を解決するようになり、システム python3 が mempalace をインポートできない uv tool install / pipx レイアウトでのサイレントノーオペレーション マイニングを修正しました。

バグ修正

  • embeddinggemma は一括再埋め込みを OOM キルしなくなりました。 ONNX エンベッダーは入力全体に対して単一パスを実行したため、修復規模のバッチ (約 5,000 ドキュメント) が利用可能な RAM をはるかに超えるアテンション バッファを割り当て、カーネルがサイレントにプロセスを強制終了しました。埋め込みは 32 個のドキュメントのサブバッチで実行されるようになりました。ドキュメントごとのベクトルは変更されません。 (#1770)
  • 無制限のディスク使用を防ぐためのバックアップ保持 mempalace migrate と mempalace repair max-seq-id は、実行のたびに新しいフルサイズのバックアップを作成し、クリーンアップすることはありませんでした。ある宮殿では、数百 MB のライブ データの横に数百 GB の古いバックアップが存在することが見つかりました。新しい max_backups 設定 (デフォルトは 10、0 はすべて保持) により、新しいバックアップが書き​​込まれるたびに最も古いものが削除されるようになりました。 (#1697) このサイクルに貢献してくださった皆様に多大な感謝を申し上げます。IDE の統合とこれらの修正のいくつかは、多くの初めての貢献者を含むコミュニティから提供されました。全員が以下にクレジットされています。
