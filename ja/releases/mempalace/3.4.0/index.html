mempalace v3.4.0

#メンパレスv3.4.0

v3.4.0 — プラグイン可能なバックエンド、Docker、および信頼性の修正

機能

  • プラグ可能なベクター バックエンド — デフォルトの ChromaDB に加えて、Qdrant、pgvector、および sqlite_exact が MEMPALACE_BACKEND / --backend 経由で選択可能です。
  • MCP サーバーおよび CLI の Docker イメージ (CPU + GPU)。
  • mempalace migrate-wings — 従来のウィング名 (先頭/末尾の区切り文字を削除) を正規化する 1 回限りの移行により、アップグレード前の宮殿が引き続き検出可能になります。 docs/recovery/wing-name-migration.mdを参照してください。
  • 既知システム辞書 は、エンティティ検出において複数の単語の製品名をアトミックに保ちます。

修正

  • embeddinggemma (デフォルト モデル) が ChromaDB 1.5.x で動作するようになりました — 新規インストールではセマンティック検索がサイレントに失敗していました。
  • drawer_id ハッシュ衝突によるサイレント データ損失を防ぎます。
  • mcp_server をインポートしても、~/.mempalace は再作成されなくなりました (プライバシー キルスイッチを尊重)。
  • diary_write は content エイリアスを受け入れ、欠落しているパラメーターの診断を復元します。
  • 明示的ベクター バックエンドは単一ドキュメント入力を正しく処理します。

インフラストラクチャ

  • GitHub アクション Trusted Publishing (OIDC) を介した PyPI 公開、手動承認によってゲートされます。
