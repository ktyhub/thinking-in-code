#メンパレスv3.6.0

v3.6.0 — 安全なリモート サービス、時間的事実、復元力のあるリカバリ

このリリースでは、単一のローカル プロセスを超えて MemPalace の運用が大幅に容易になると同時に、長寿命の宮殿を保護する保証が強化されます。新しいデフォルトでセキュアな mempalace serve パスは、TLS と読み取り専用の強制による認証されたリモートおよびチームの展開をサポートします。オプトインの Milvus バックエンドにより、組み込み、セルフホスト、および管理されたストレージの選択肢が追加されます。そして、アトミックな知識グラフのスーパーセッションは、変化する事実に正確な時間的境界を与えます。会話の年表、マイニングされたセッションのグラフの導出、プロジェクトの除外、LaTeX のカバレッジにより取り込みが深まり、起動、メタデータ、回復作業により大規模な宮殿がより高速かつ安全になります。 MCP サーフェスは 36 個のツールで構成されています。

機能

  • ターンキーの安全なリモート/チーム サーバー。 mempalace serve は安全なデフォルトで HTTP 経由で完全な MCP サーフェスを公開します。非ループバック バインドにはベアラー トークンが必要で、生成されたトークンは制限されたアクセス許可で保存され、argv ではなく子環境を通過します。ネイティブ TLS 1.2+ がサポートされ、--read-only は変更ツールの非表示と拒否の両方を行います。 Docker Compose、systemd、および環境テンプレートが含まれています。 (#1877、#1897、#1900)
  • Milvus ストレージ バックエンド。 新しいオプトイン milvus バックエンドは、COSINE ベクトル検索、新しいコレクションのネイティブ BM25 字句検索、名前空間の分離、ターゲット不一致保護、およびオプションの依存関係追加機能を備えた、Milvus Lite、セルフホスト型 Milvus、および Zilliz Cloud をサポートします。 (#1899)
  • アトミック ナレッジ グラフ ファクト置換 supersede() / mempalace_kg_supersede は、共有された 1 つの瞬間にオープン ファクトを閉じ、後続のファクトを開きます。テンポラル クエリでは、日付のみのファクトについては終日のセマンティクスを維持しながら、タイムスタンプ精度で半開間隔を使用します。 (#1913)
  • 会話の時系列は保持されます。 ドロワーはトランスクリプト時間を authored_at として保持し、検索結果でそれが明らかになり、正確なハイブリッド スコアの関係により最近作成されたコンテンツが優先され、冪等のドライランファースト バックフィルにより、再埋め込みを行わずに既存のパレスが更新されます。 mempalace_list_drawers は since / before 境界も獲得します。 (#1890、#1891)
  • マイニングされたセッションは、連想グラフに追加されます。 精度に偏った構造エクストラクターは、コード シンボル、URL、パス、および修飾された識別子をドロワー エンティティとして記録します。会話マイニングはそれらから廊下を派生し、新しい mempalace hallways CLI コマンドによって公開されます。 (#1894、#1895)
  • 修正された --limit セマンティクスを変更せずに、mempalace.yaml の exclude_patterns による プロジェクトごとのマイニング除外。 (#1213、#1953)
  • .tex および .bib 散文ソースの LaTeX プロジェクト カバレッジ。 (#1901)
  • 共有デーモン書き込みルーティング ポリシーは、書き込み可能な client をローカル デーモンにルーティングするための 1 つの一貫したポリシー シームを提供します。 (#2027)
  • チェックポイント作成者の属性は、すべてのチェックポイント ドロワーを checkpoint としてハードコーディングするのではなく、申請代理人を保持するようになりました。 (#2023、#2034)

パフォーマンス

  • MCP の初期化は、パレス全体の整合性作業を待たなくなりました。 スタートアップ プリフライトがバックグラウンドで実行されている間、標準出力は initialize に即座に応答します。同時実行ツールは、作業を複製するのではなく、同じ判定に参加します。大規模な宮殿のスタートアップ SQLite プローブは制限されていますが、修復プリフライトは引き続き厳格です。 (#1911、#1987)
  • Qdrant メタデータのカウントでは、すべてのレコードをフェッチして集計する代わりに、サーバー側のファセットを使用します。埋め込みラッパーは、ファセットおよびバルク メタデータ機能を正しく転送します。 (#1868、#1898)
  • pgvector メタデータのみのフェッチではドキュメント ペイロードが省略されるため、転送とデコードの作業が軽減されます。 (#1892)

バグ修正

  • クロマ リカバリにより、派生インデックスの損傷とデータ損失が区別されます。 有効な全レイヤ 0 HNSW セグメントは繰り返し隔離されなくなりました。分離された FTS5 破損は、修復中およびマイニング後に無傷のコンテンツから再構築されます。埋め込まれた NUL バイトは、ChromaDB に到達する前にサニタイズされます。 (#1716、#1872、#1878、#1927、#1928)
  • SQLite リカバリは制限付き、アトミック、かつ正直です。 整合性チェックは一時的なライターの競合を待ちます。リカバリアーカイブはアトミックな名前変更を使用します。 repair --mode from-sqlite は FTS5 を再構築し、バキュームし、クリーンな最終的な PRAGMA quick_check を必要とします。クリーンアップに失敗すると、偽の成功を出力するのではなく、ゼロ以外の値が返されます。 (#1945、#2015、#2017)
  • CLI 検索は、ChromaDB を開く前に HNSW の相違をチェックします。正常なバックエンドと非 Chroma バックエンドを通常のパスに残したまま、損傷したパレスを直接 SQLite BM25 にルーティングします。 (#2016)
  • ライター リースは、サーバーを読み取り専用で停止させるのではなく回復します。 拒否されたライターは、ピアの終了後に再試行および昇格します。ステータスはライターのリースを取得できません。リエントラント保持者は中断を越えて解放されます。 checkpoint および delete_by_source は突然変異として正しく分類されます。 (#1923、#1930、#1934、#1960、#1970、#1971)
  • ステータス レポートは、実際に実行されたチェックのみをレポートします。 非 Chroma バックエンドは、Chroma SQLite 整合性を適用外としてマークします。 (#1931、#1946)
  • 会話のトランスクリプトは変更可能として扱われます。 追加または書き換えられたセッションは変更時間によってパージされ、再ファイルされますが、クロード コード tool-results/ サイドカーはスキャンから除外されます。 (#1957、#2010)
  • 明示的な宮殿選択スコープはグラフ状態を導き出すため、採掘廊下とトンネルは選択された --palace の横に残ります。 (#2018)
  • リモートおよびローカル サーバーの強化。 非ループバック HTTP では、明示的にオーバーライドしない限りトークンが必要です。プロバイダー プローブは、選択前にアンビエント外部キーを再利用できません。フックのトランスクリプトとファイルのコピー/修復パスはより厳密な検証を受けます。 MCP をインポートしても root ログが破壊されなくなりました。 HTTP 書き込みは安全に宮殿ロックに再び入ります。ルーチンの切断ではトレースバックが発行されなくなりました。 (#1859、#1860、#1864、#1885、#2003、#2004)
  • マイニングと構成の正確性。 サイズが大きすぎるファイルは視覚的に警告し、構成された ~ パスは一貫して拡張され、ウィング スラッグは特殊文字を処理し、Windows バックグラウンド プロセスはコンソールのフラッシュを回避します。 (#923、#1852、#1857、#1863、#1865)
  • Windows .gitignore 処理では明示的に UTF-8 を使用し、ロケールに依存するエラーを回避します。 (#1648)
  • L1 ウェイクアップでは、重要性が一致する最新の瞬間が優先されます。 (#1630)
  • バックエンドの検出には SQLite マジック ヘッダーが必要です。これにより、無関係なファイルが宮殿と間違われるのを防ぎます。 (#1893、#1896)

ドキュメント

  • ストレージ バックエンド構成リファレンス、リモート/チーム サーバー展開ガイド、authored_at 移行ガイダンスを追加し、完全な 36 ツール MCP サーフェスの OpenClaw 統合を更新しました。 (#1719、#1877、#1890、#1904、#1905)

内部

  • WAL のクラッシュ セーフティ、冪等性、および編集パスの対象範囲を拡大しました。 GitHub アクションとラフを更新。 Ruff 0.15.20 および Python 3.9 依存関係マーカーの uv.lock ドリフトを修復しました。 (#1869) このリリースに貢献してくださった皆様に心より感謝いたします。貢献者および初めての貢献者は以下にクレジットされます。
