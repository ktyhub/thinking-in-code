herdr v0.9.2

パッチ 公開日2026年9月29日 出典herdrdev/herdr 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#ヘルドラv0.9.2

重大な変更

  • Herdr 固有のペイン グラフィック API はなくなりました。 pane.graphics.info、set、clear、および stream は unknown_method を返すようになりました。アプリは、標準の Kitty グラフィックを端末に書き込むことによって画像を表示します。Herdr はそれをネイティブにレンダリングします。 (#4561)

追加

  • エージェントは独自の再開コマンドを報告できます。 Herdr は、サーバーの再起動後に、組み込みの統合を必要とせずに、正確なセッションを再度開きます。自己報告エージェントは、ペインがアイドル シェルに戻るとクリアされます。新しい エージェントに Herdr サポートを追加する ガイドでは、エージェント作成者向けの状態、再開、リリースについて説明しています。 (#4687)
  • 複数のプレフィックス キーを使用します: prefix = ["ctrl+space", "ctrl+s"]。すべてのエントリは同じプレフィックス モードに入り、prefix+? はそれらすべてをリストします。 (#4653、ありがとう @JJLiebig)
  • [移動] では、すべてのエージェントと端末が、ワークスペースごとにグループ化された独自の行として、そのステータスとパスとともに表示されます。左右にワークスペース間を移動します。 (#4384)
  • keys.clear_pane をバインドすると、フォーカスされたペインの画面がクリアされ、現在のプロンプト行を維持したままスクロールバックします。デフォルトではバインドされておらず、Vim などの全画面アプリはそのままになります。 (#4383)
  • herdr machine status はプロンプトを表示せずに保存されたマシンをチェックします。 herdr machine reconnect は、端末で MFA を含む SSH 認証を完了します。 Open clients は障害が発生したマシンを 30 秒ごとに再チェックするため、接続を修復した後に再起動する必要はありません。 (#3763)
  • インタラクティブ machine add は、ホスト上ですでに実行されている Herdr セッションを検索し、1 つ選択できます。 --label はオプションです。マシンの名前は、SSH ホストにちなんで付けられます。 (#4204、#4678、@JJLiebig と @dhh に感謝)
  • terminal session control は terminal.mouse イベントを受け入れるため、ブリッジ client はマウス レポートを有効にするアプリのボタンを click できます。 (#4685)
  • 復元されたエージェントは、デフォルトでは一度にすべてではなく、100 ミリ秒の間隔で 1 つずつ起動します。 [session] startup_per_agent_delay_msで間隔を変更します。 (#4102、ありがとう@JJLiebig)

変更されました

  • 画像のレンダリングがより高速かつ確実に行われます。ローカルの Ghostty は、端末出力ではなく一時ファイルを通じて画像データを受け取ります。ポップアップと通知では、画像を非表示にするのではなく、周囲の画像をトリミングします。スクロールして表示されなくなった画像は読み込まれたままになるため、スクロールバックしても再送信されなくなりました。 (#4561、#4652、#4686)
  • SSH 接続は圧縮を要求します。低速リンクでは、スクロール後にリモート ペインがほんの少しの時間で追いつきます。 (#4340)
  • 保存されたマシン上で出力をスクロールすると、変更された行のみが送信され、ビルド ログとストリーミング エージェントの帯域幅が削減されます。古い client とサーバーは引き続き以前の形式で動作します。 (#4711)
  • 新しいペイン セット TERM_PROGRAM=herdr および TERM_PROGRAM_VERSION。 iTerm2 などの端末セッション ID や、サーバーを起動した端末からのクロード コード セッション マーカーを継承しなくなりました。 (#4104)
  • Windows ペインは、インストール時にデフォルトで PowerShell 7 (pwsh) になり、Windows PowerShell に戻ります。明示的な default_shell が依然として有効です。 (#4297、ありがとう@JJLiebig)
  • ワークスペースの最後のタブを閉じると確認を求められるようになりました。 (#4379、#4409、ありがとう @minatoaquaMK2)
  • イベント サブスクリプションはバーストを完全に配信します。リーダーが遅れすぎると、イベントを黙ってスキップするのではなく、events_lost エラーが発生するようになりました。 (#4178、#4225、ありがとう @minatoaquaMK2)
  • Unix では、SIGWINCH を Herdr client に送信すると、ホスト端末の色が再読み取りされるため、明暗通知なしで色を変更するテーマ スイッチャーはペインを更新できます。 (#4349、ありがとう@dhh)

修正済み

  • 保存されたレイアウトは、ホストのシャットダウンや復元の失敗後も存続します。 Linux では、logind を使用すると、Herdr はシステムがシャットダウンする前に保存します。すべてのプラットフォームは、手動リカバリのために最大 48 個のレイアウト スナップショットを session-snapshots/ に保存します。 (#4320)
  • Cli ペインをロックしても、作業中のエージェントを中断する迷走エスケープが送信されなくなりました。 (#3480)
  • エージェントの最初のタスクは、プロンプトで開始された場合でも完了としてカウントされるようになりました。起動、セッションの復元、および Pi の /new は、誤った完了通知を発行しなくなりました。フックによって報告されたステータスはライブハンドオフ後も存続します。 (#3338、#3990、#3916)
  • 多くのペインが表示されると、サーバーははるかに少ない CPU を使用します。ナビゲータ、ペイン分割、および名前付きターゲットは大規模なセッションでも高速に動作し、外部イベントのバーストによってレンダリングが停止することはなくなりました。 (#4506、#4546、#4426、#4669、#4670、#4671、#4672、@JJLiebig と @minatoaquaMK2 に感謝します)
  • 同期出力を使用するアプリでは、入力中に壊れたフレームが表示されなくなりました。 Windows 上でステータスの再描画中にカーソルがちらついたり、アイドル状態の Codex の周りをジャンプしたりすることがなくなりました。 (#2968、#4303、ありがとう @JJLiebig)
  • API ソケットは一時的なエラーの後も接続を受け入れ続けるため、サーバーの実行中に CLI コマンドとライブ ハンドオフが失敗することがなくなりました。 (#4601)
  • ワークツリー検索中に遅い Git 操作が入力をフリーズすることがなくなりました。 (#4492、ありがとう@JJLiebig)
  • worktree open はリポジトリ自体のワークスペースを引き継がなくなり、ワークツリーを削除してもワークスペースが閉じなくなりました。 (#4293)
  • 転送された SSH エージェントは、再接続後もリモート ペインで動作し続けます。 --machine コマンドを繰り返し実行しても、開かれる SSH 接続ははるかに少なくなります。 (#1931、#4252)
  • OpenCode V1 ペインは、サブエージェントの実行中は動作し続けるかブロックされます。 tui.jsonc を再生成する代わりに、tui.json の既存の登録が尊重されます。 (#1362、#4240)
  • Codex はアクティブな出力中にアイドル状態であると報告されなくなり、言及ポップアップが認識され、再マップされた割り込みキーが検出を中断しなくなりました。 (#4507、#4196、@JJLiebig と @unmanbearpig に感謝)
  • Kiro の承認プロンプトがブロックされていると報告されます。 Grok アイドル ペインは、カスタムまたは無効になった OSC タイトルで解決されます。 (#4203、#4372、#4333、ありがとう @vinayshah1998)
  • Droid のスクロールバック クリアが尊重されるため、そのウェルカム ヘッダーと古いトランスクリプトが繰り返されなくなりました。 (#4432、ありがとう @factory-ain3sh)
  • 出力が継続し、移動キーが押されている間、コピー モードはアクティブなままになります。 (#3812、#4281、ありがとう @marcomayer)
  • 拡張キーボード入力が有効になっていないペインでは、Ctrl+Shift+文字が Shift を保持するため、Ctrl+Shift+C が Ctrl+C として表示されなくなりました。 (#4581、#4597、ありがとう @factory-ain3sh)
  • SSH にフォーカスを切り替えた後、複数の読み取りに分割されたマウス レポートがシェルに漏れなくなりました。 (#4630)
  • Windows: クロード コードへの複数行の貼り付けは最初の改行で送信されなくなり、Shift+Enter キーは保持されます。マウス キャプチャはフォーカスの変更やサイズ変更の後も存続し、Ctrl+Win で ctrl+space プレフィックスのプレフィックス モードが開かなくなり、リモート clipboard イメージの貼り付けが再び機能します。 (#4251、#4284、#4470、#4314、ありがとう @JJLiebig)
  • Windows: npm でインストールされた OMP と、強化されたランタイムを通じて起動されたエージェントが検出されます。 Windows ホストに対する machine add が「保存されたマシンの準備ができていません」として失敗することがなくなりました。 (#4313、#4579、#4309、ありがとう @JJLiebig)
  • ナビゲート モード ワークスペースのハイライトは、theme = "terminal" で表示されます。セッション ナビゲーターの検索は、単語を個別に照合します。サイドバーには、cycling またはショートカットによって選択されたエージェントが表示されます。 (#4300、#4408、#4273、#4535、#4355、ありがとう @minatoaquaMK2)
  • 端末を使用しない session attach は、新しいセッションを実行したままにするのではなく、問題を説明します。 (#4393)
  • ソケット エラー応答では、サブスクリプション セットアップ エラーを含め、元のリクエスト ID が保持されます。 (#4344)
  • plugin install は、リポジトリの前にオプションを受け入れます。 (#4446)
  • Windows ペインはホスト端末の明るい色または暗い色を最初から認識するため、明るい端末内ではアプリがデフォルトでダーク モードに設定されなくなりました。 (#1530、#4369)
  • herdr update の後、Herdr は、実行中のサーバーが古いバージョンのままであることをリストし、各サーバーを再起動するための正確なコマンドを示し、保存された SSH マシンを更新するよう通知します。
