herdr v0.9.4

パッチ 公開日2026年10月13日 出典herdrdev/herdr 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#ヘルドラv0.9.4

追加

  • herdr plugin update は、GitHub からインストールされたプラグインを一度に、または名前によって更新します。実行中のプラグイン ペインは古いファイルで動作し続け、新しい実行では構成を再ロードせずに更新を取得します。ローカルにリンクされたプラグインはそのまま残されます。 (#4245、ありがとう@JJLiebig)
  • Windows 通知は通知センターに残ります。 Click をクリックすると、そのペインにジャンプし、ターミナル ウィンドウが前に表示されます。 (#4773、#4803、ありがとう @JJLiebig)

変更されました

  • 昇格された Windows サーバーは、デフォルトで管理者 clients のみを受け入れるようになりました。同じアカウントからの通常の client を許可するには、[server] allow_unelevated_clients = true を設定するか、--allow-unelevated-clients でサーバーを起動します。アクセス許可エラーにはその修正方法が表示されるようになり、アクセスできないセッションは停止せずに使用不可として表示されます。 (#4717、#4769、#4777、#4779、ありがとう @JJLiebig)
  • Linux および macOS では、Herdr を起動したシェルを閉じてもサーバーが停止しなくなりました。 SIGHUP で Herdr を停止したスクリプトでは、herdr server stop または SIGTERM を使用する必要があります。サーバー ログには、サーバーが停止した理由が示されます。 (#4920、#4965)
  • マウス キャプチャがオンの場合、リンクを click するときにリンクを処理するプラグインが最初に選択されます。 macOS の Command-click など、端末独自のリンク ショートカットを使用するには、キャプチャをオフにします。 (#4874、#5064、ありがとう @JJLiebig)
  • Antigravity と Grok は、自身のバックグラウンド タスクやサブエージェントがまだ実行中であっても、プロンプトに戻るとアイドル状態としてカウントされます。 (#3530、#4735、#4959)
  • Ctrl+Shift+文字は、Alacritty や WezTerm のように、Ctrl キーとしてプレーン シェルに到達します。スーパー、ハイパー、メタのショートカットは、それらを読み取れないアプリにジャンクなエスケープコードを入力しなくなりました。 (#4356、#5017)

修正済み

  • Mac を再起動するか Windows をシャットダウンしても、エージェントのセッションは維持されます。 Herdr はシステムがアプリを終了し始める前に保存するため、エージェントは元の場所に戻ります。 (#4414、#5013、#5057、#5092、ありがとう @JJLiebig)
  • セッションの保存は、古いファイルを置き換える前にディスクに書き込まれるため、クラッシュや電源切断によって保存が読み取れなくなることはありません。 (#5150、#5152、ありがとう @JJLiebig)
  • マシンのプロセスまたはスレッドがなくなっても、すべてのペインがダウンするのではなく、サーバーは実行を続けます。 (#3324、#4958)
  • 範囲外のワークスペース番号は、サーバーをクラッシュさせるのではなく、workspace_not_found を返します。 (#5096、#5171)
  • Ctrl+Z でエージェントを一時停止し、fg で元に戻すと、その名前と保存された会話が保持されます。 (#1647、#4964)
  • チェックアウトの Git データが遅いか欠落している場合でも、セッションの復元は応答性を維持します。ワークツリー グループは、一時的に利用できなくなったチェックアウト後も存続し、同じリポジトリを 2 回開いても、一方のワークスペースがもう一方のワークスペース内にネストされることはなくなりました。 (#4926、#4736、#4945、#4770、#4772、@minatoaquaMK2 と @JJLiebig に感謝します)
  • ワークスペースの唯一のペインを閉じると、最後のタブがすでに閉じているのと同様に、最初に確認が行われます。 ui.confirm_close = falseでこれをオフにします。 (#5143、#5173)
  • Ctrl+W などの Ctrl ショートカットは、ロシア語、ギリシャ語、ヘブライ語などの非ラテン語キーボード レイアウトでも機能します。ラテン語レイアウトと AltGr 文字は通常の意味を保ちます。 (#1079、#4961)
  • アクセント キーと AltGr ショートカットは Windows で機能します。 (#4688、#5021、ありがとう @JJLiebig)
  • Shift+Enter およびその他の拡張キーは、外部ターミナルがリセットされた後 (たとえば、VS Code のリロード ウィンドウ後) も機能し続けます。 (#4985、#5088)
  • クイック エスケープ タップは、WezTerm の Kitty キーボード モードを使用して macOS 上で動作します。 (#1266、#5089)
  • Kitty キーボード アプリはキー リリースと F1、F2、F4 を正しく取得し、端末が Ctrl+H を送信すると Backspace が機能します。 (#4184、#4403、#3244、#5017)
  • キーボードと端末の色の応答によって、ペインの入力に迷子文字が漏れることはなくなり、中途半端な色の応答によって入力がフリーズすることもなくなりました。 (#4856、#4025、#5052、#5017、#5087)
  • ペインのサイズを変更するときに、Fish がプロンプト フラグメントを繰り返さなくなりました。 zsh と Powerlevel10k に関する同じ問題はまだ解決されておらず、Ghostty の修正を待っています。 (#3672、#4977)
  • ピクセル マウスの座標を要求するアプリはそれらを取得し、click はセルのみを報告する端末上の適切な場所に配置されます。 (#4750、#3675、#5017、#4971)
  • Kitty グラフィックをオフにすると、ペインで画像サポートの広告が停止されるため、アプリはテキストに戻ります。 (#4978、#4979)
  • 特に PowerShell での入力が速くなります。 (#4884、#5149、ありがとう @JJLiebig)
  • 大規模なセッションでは、ビジーなエージェントやアイドル状態のシェルで使用する CPU が少なくなり、非表示のペインで使用されるメモリが少なくなり、Windows ペインで必要なスレッドが少なくなります。 (#4506、#5083、#4845、#4847、#4849、#4850、#4873、#5085、#5091、ありがとう @JJLiebig)
  • 新しいワークスペース、タブ、分割は、別のペインのサイズを借用するのではなく、適切なサイズでシェルを開始します。 (#4419、#4873)
  • 転送された SSH エージェントは毎秒接続されなくなり、最終的に SSH および Git 認証が中断される可能性があります。 (#4931、#4962)
  • サイドバーの幅、折りたたまれたグループ、およびリモート マシン上のエージェントの並べ替えは、再接続後も存続します。マシンの変更中にワークスペースをすばやく切り替えると、キャンセルされなくなりました。 (#4364、#5019、#4536、#5061、@minatoaquaMK2 と @JJLiebig に感謝)
  • エージェント リストにスクロールバーがある場合、サイドバーの折りたたみボタンは clickable のままになります。 (#4692、#4734、ありがとう @minatoaquaMK2)
  • ようこそ画面には、設定されたプレフィックスが表示されます。 (#4745、#4747、ありがとう @JJLiebig)
  • Ctrl+[ ワークスペースナビゲーションを終了します。 (#1431、#2340、ありがとう @qaz74107410)
  • + を使用するキーバインドは設定のリロード後も存続し、/ は Shift が必要なレイアウトで Go To 検索を開きます。 (#4960、#4963、#4983、#5090、ありがとう @minatoaquaMK2)
  • Windows 上の WezTerm からリモート ペインに貼り付けると、エンコードされたキー データが入力されなくなりました。コピーしても重複した clipboard 履歴エントリが追加されなくなり、ペインを閉じるときに保留中の Enter でハングすることもなくなりました。 (#4725、#4730、#4709、#4872、ありがとう @JJLiebig)
  • Scoop または 32 ビット ラッパーを通じて起動された Windows シェルは、再起動後も新しいタブに作業ディレクトリを保持します。 (#4472、#4749、#5062、ありがとう @JJLiebig)
  • Windows ARM64 マシンは、ベストエフォート ベースで、x64 ビルドを通じてリモート ホストとして使用できます。 (#4752)
  • --no-daemon で起動すると、Codex は統合を通じてターン終了を報告し、起動更新画面がブロックされていると表示され、Codex と Pi のステータスが認識されることが多くなります。 (#4507、#4811、#4756、#5174、ありがとう @JJLiebig)
  • 反重力の許可、質問、およびワークスペース - trust ダイアログはブロックされていると表示され、思考スピナーは機能していると表示されます。 (#3871、#3419、#3530、#4959)
  • Python インストーラーを通じて起動された Hermes は認識され、その統合をインストールまたは削除しても、YAML プラグイン リストはそのまま維持されます。 (#4910、#4909、#4911、#4984、ありがとう @minatoaquaMK2)
  • macOS では、pane run および agent start は、まだ起動中のシェルに対して長すぎるコマンドを、黙って切断するのではなく拒否します。 (#4950、#4988、ありがとう @minatoaquaMK2)

削除されました

  • 実験的な HERDR_WINDOWS_INPUT_BACKEND=crossterm 設定はなくなりました。 Windows は常にネイティブのコンソール入力を使用します。 (#5017)
