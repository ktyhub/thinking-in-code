herdr v0.8.2

パッチ 公開日2026年8月19日 出典herdrdev/herdr 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#ヘルドラv0.8.2

追加

  • CLI ヘルプは、コーディング エージェントに Herdr のプレーンテキスト ガイド、ドキュメント インデックス、および組み込みのコントロール スキルを示すようになりました。
  • アイドル状態、作業状態、およびユーザー確認状態の Qwen コード検出と、オプションのネイティブ セッションの復元を追加しました。 (#2730、#2743)
  • Herdr は、ui.window_title を通じて外側のターミナル ウィンドウのタイトルをセッションと同期させるようになりました。そのため、ウィンドウ マネージャーとターミナルのタブ バーには、アクティブなワークスペースとペインが実際に実行されているホストが表示されます。 (#2627、ありがとう@dhh)
  • デスクトップのタブ バーには、ズーム状態、ホスト名、日付/時刻、リテラル テキスト、および非同期的に更新されるコマンド出力の構成可能な右揃えのステータス エントリが表示されます。
  • オプションの keys.move_tab_previous および keys.move_tab_next バインディングは、アクティブなタブを所定の位置で並べ替え、どちらかの端で折り返すようになりました。 (#2561、ありがとう@dhh)
  • オプションの keys.resize_pane_left、keys.resize_pane_down、keys.resize_pane_up、および keys.resize_pane_right バインディングでは、サイズ変更モードに入らなくても、フォーカスされたペインのサイズを 1 回のキーストロークで変更できるようになりました。 (#2558、ありがとう@dhh)
  • Windows clients は、herdr --remote を使用して Linux および macOS 上の Herdr サーバーに接続できるようになりました。 (#2329)
  • Cursor Agent CLI、MastraCode、Hermes Agent、および Grok CLI の統合が Windows にインストールされ、ネイティブに実行されるようになりました。
  • ペインは、ペイン メニュー、herdr pane input、pane.input.set、または pane split --right-click pane 起動オプションを通じて、通常の右 click ジェスチャをマウス報告アプリケーションにルーティングできるようになりました。
  • ui.pane_outer_borders は、内部の仕切りとは別に、分割ペインの境界線の外側の端を保持または非表示にできるようになりました。 (#2535、ありがとう@dhh)
  • theme.custom.sidebar_bg は、組み込みテーマのデフォルトを変更せずに、デスクトップ サイドバーに独自の背景を与えることができるようになりました。
  • 設定と ui.status_indicators = "symbols" は、ブロック、動作、完了、アイドル、不明のエージェントの状態に個別の静的形状を使用できるようになりました。 (#2260)
  • ナビゲート モードの選択行では、theme.custom.selection_bg 経由でカスタマイズ可能なテーマごとの専用のカーソル色が使用されるようになりました。そのため、カーソルはアクティブなスペースおよびエージェントのハイライトと区別できます。
  • コピー モードは、空白で区切られたビッグ ワード上の B、E、および W モーションをサポートするようになりました。 (#2270、ありがとう@jplew)
  • プラグイン マーケットプレイスは、リポジトリのルートとサブディレクトリで有効なマニフェストを検出し、各リポジトリの下に複数のプラグインをグループ化し、それらのバージョンと正確なデフォルト ブランチ コミットを公開するようになりました。

変更されました

  • Windows サポートは現在、安定版リリースを通じて一般提供されており、デフォルトで安定版アップデート チャネルを使用します。既存のプレビュー インストールは、明示的に切り替えられるまでプレビューのままになります。
  • ヘッドレス サーバーは、client が接続されていない場合、80×24 の代わりに構成可能な 120×40 の仮想ターミナルを使用するようになり、新しく作成されたペインに実用的なデフォルト サイズが与えられます。 (#2828)
  • デスクトップ タブのラベルがタブの中央に配置されるようになったため、アクティブ タブのハイライトには対称的なパディングが含まれます。 (#2570、ありがとう@dhh)
  • 実験的ペインのグラフィックスは、境界付き名前付きレイヤー、監査済みローカル端末上の承認されたフル RGBA プライマリ レイヤー ダイレクト ファイル フレーム、所有された BGRA フォールバック、正確なピクセル マウス入力、および配置のみのサイズ変更再生をサポートするようになりました。

修正済み

  • Unix CLI コマンドは、下流のパイプが閉じたときに、出口 101 でパニックするのではなく、静かに終了するようになりました。 (#2994)
  • ターミナル テーマでは、展開されたサイドバーと折りたたまれたサイドバーの両方で、Navigate カーソルがその上に着いたときに、アクティブなスペース行の塗りつぶしが表示されたままになります。 (#2987)
  • ビジーなマルチペイン セッションでは、冗長な非表示ペイン ウェイクアップとペインスケール パスでの完全なターミナル状態のフォーマットが回避され、高速バックグラウンド出力、スクロールバー、および拡張キーボード モードによる CPU の回帰が防止されます。 (#2550、#2901、#2962)
  • フォーカスされたアプリケーションが印刷可能なキーリリース イベントを要求すると、中国語 IME コミットが macOS 上のペインに到達するようになりました。 (#2924)
  • Windows は、キー レコードを制御文字としてデコードするのではなく、Ctrl+1 から Ctrl+9 までのキーバインドを認識するようになりました。 (#2910)
  • PowerShell ペインは、プロセスが報告する作業ディレクトリをシェルの論理的な場所と同期した状態に保つようになりました。 (#2879、ありがとう@Pimpmuckl)
  • フォアグラウンドでの入力が、非表示のタブのペインからの出力によって消費されるレンダリング リズムの後に待機することがなくなりました。 (#2890)
  • Windows ARM64 インストーラーは、x64 エミュレーションが検証済みの実行可能ファイルをリリースするのを待ってから、ダウンロードされたリリースをアクティブ化するようになりました。 (#2916)
  • Unix では、Ctrl-click URL オープナーが終了後に取得されるようになり、無効になった子プロセスが長時間実行されているサーバーに蓄積されるのを防ぎます。 (#2903)
  • Windows アップデートでは、検証済みのローカル パッケージのみが再利用されるようになり、チェックサム検証を維持しながらセキュリティ ツールのダウンロード ブロックが回避されます。 (#2751、#2816、ありがとう @Pimpmuckl)
  • Herdr は、WSL で完全な OSC 4 パレット クエリ バーストを送信しなくなり、応答フラグメントが ConPTY を通じてシェルに漏洩するのを防ぎます。 (#2440)
  • Qwen コード ペインは、ロケールに依存しない端末タイトルの状態とローカライズされた確認フォールバックを使用するようになり、アクティブまたはブロックされたターンがアイドル状態に見えるのを防ぎます。 (#2756)
  • クロード コード ペインは、すべての半円タイトル スピナー フレームを認識して削除するようになり、アクティブなターンがアイドル状態に表示されるのを防ぎ、タイトルをクリーンに保ちます。 (#2707、#2709、#2760、#2762)
  • コパイロット プロンプトは、入力を送信する前にターゲット ペインにフォーカスするようになりました。そのため、バックグラウンド ペインがプロンプトを表示せずにドロップすることはありません。 (#1698、#2734、ありがとう @xkrogen)
  • エージェント フックは、PATH に最初に表示されるバイナリではなく、実行中の Herdr バイナリを呼び出すようになりました。 (#2722、ありがとう @Pimpmuckl)
  • リモート セッションが存続している間、herdr --remote を実行している端末を閉じてもローカル client コア ダンプが生成されなくなりました。 (#2424)
  • アクティブ スペースとエージェントの行は、ホスト端末の背景が選択した Herdr テーマと一致する場合に表示されたままになる専用のテーマ カラーを使用するようになりました。 (#2792)
  • agent prompt は、テキストや Enter を送信せずに、agent_blocked との承認または質問ダイアログですでに待機しているエージェントを拒否するようになりました。 (#2788)
  • agent start は、新しいペイン シェルと初回実行エージェント プロンプトの準備が整うまで、それらを競合したり、時期尚早の準備完了を報告したりするのを待つようになりました。 (#2410、#2537、#2773、#2774、ありがとう @Pimpmuckl)
  • prefix+e は、エディターでソフトラップされたスクロールバックを開いたときに論理行を保持するようになりました。 (#2733)
  • 代替画面ペインの読み取りにより、不必要な ANSI フォーマット作業が回避され、TUI エージェントの読み取り遅延が短縮されます。 (#2387、#2426)
  • ネイティブのフルスクリーンで Ghostty を使用する場合、タブ バー click が適切に登録されるようになりました。 (#796、#2736、ありがとう @Hack Attack)
  • プレフィックス キーバインドにより、レイアウトを考慮したシフトされた句読点が明確になり、同じキーが両方の文字を生成するキーボード レイアウト上でシフトされた \ が prefix+| をトリガーすることがなくなりました。 (#2674)
  • リモート client は、完全な ANSI フレームがトランスポート制限を超えたときにフリーズするのではなく、非常に大きな端末サイズで再描画を続行するようになりました。 (#2670)
  • Windows Git ステータスの更新では、WSL リポジトリのセキュリティ スキャンを繰り返しトリガーするのではなく、リポジトリ設定が再利用されるようになりました。 (#2643、#2688、ありがとう @Pimpmuckl)
  • Windows アイドル エージェント検出により、ペイン間でプロセス スナップショットが共有されるようになり、多くの Git Bash ペインを使用するセッションでの CPU 使用率が削減されます。 (#2459、#2494、#2642、#2651、ありがとう @Pimpmuckl)
  • 埋め込まれたベア リポジトリは、正しいリポジトリ名とワークツリーの場所を取得するようになりました。 (#2657、#2660)
  • ルート リポジトリ ワークスペースは、更新を再開しても保存されたラベルを保持するようになりました。 (#2594、#2727)
  • 昇格された Windows ペインで、PowerShell の管理者の装飾が端末のタイトルとして表示されなくなりました。 (#2632、ありがとう@Pimpmuckl)
  • モーダル名の入力により、ホスト IME カーソルがダイアログの背後のペインではなくテキスト フィールドに固定されるようになりました。 (#1755、#2569、ありがとう@kataokatsuki)
  • セッション ナビゲーターの移動は、無関係なペイン入力を消費するのではなく、変更された j、k、および矢印キーを無視します。 (#1981、#2377、ありがとう @atomsbaza)
  • OpenCode ペインは、接続された client からのアクティビティを採用せずに、ネイティブ復元のために独自の TUI で選択されたルート会話を追跡するようになりました。 (#2450)
  • サーバー停止要求はペインと API トラフィックをバイパスするようになり、ビジー セッションがシャットダウンをブロックしたり、シャットダウンの保留中に client を許可したりするのを防ぎます。 (#2612)
  • 従来の Alt プレフィックス付き制御バイトが両方の修飾子でデコードされた後、Fish Ctrl+Alt キーバインドがペインで機能するようになりました。 (#2514)
  • Windows の最近の履歴の読み取りでは、冗長なスナップショットが実行されなくなり、読み取りコストを削減しながら recent 出力が復元されます。 (#962、#2474、ありがとう @Pimpmuckl)
  • Windows インストーラーは、アトミック ディレクトリ スワップを使用してリリースをアクティブ化するようになり、更新が中断されて空のリリース ディレクトリが残されるのを防ぎます。 (#2356、#2530、ありがとう @Pimpmuckl)
  • herdr config check は、未知の組み込みテーマ名を黙って受け入れるのではなく、報告するようになりました。 (#2452)
  • macOS herdr --remote clients は、受け入れられたブリッジ ソケットのブロックを維持し、プロトコル ハンドシェイク後の即時の切断を防ぎます。 (#2478、ありがとう @mathijshenquet)
  • WezTerm Kitty キーボード モードでプレフィックス キーバインドが Shift を保持するようになりました。そのため、config reload などのコマンドは、シフトされていないアクションをトリガーしなくなりました。 (#2435)
  • ペイン アプリケーションは、リリースのドロップや Ctrl+Tab シーケンスのリークなしで、modifyOtherKeys リリースとシフトされた代替レポートを受信できるようになりました。 (#2296、#2302、#2303)
  • 切り離すとホストのキーボード レポートが復元され、Herdr の終了後に強化されたキーボード シーケンスがシェルに漏れるのを防ぎます。 (#2393、#2395)
  • デフォルトのマウス レポートは、エスケープ バイトをフォーカスされたペインに漏らす代わりにデコードされます。 (#2309、#2312)
  • ペイン プログラムによって発せられる BEL 文字が外部端子に到達するようになり、その可聴ベル設定と視覚ベル設定が反応できるようになりました。 (#2453)
  • 安定した直接インストール、自己更新、およびリモート ヘルパーのダウンロードでは、GitHub リリース アセットごとに公開されている SHA-256 ダイジェストが必要になり、検証されるようになりました。
  • pane read および pane wait-output は、ペイン ID の前後で --flag=value およびオプションを受け入れるようになりました。 (#2183、ありがとう @KyleCo76)
  • pane current、pane get、および pane layout --current は、別の client のフォーカスされたペインの代わりに呼び出しペインを解決するようになりました。 (#2297、#2298)
  • 廃止された Herdr が作成した ui.agent_panel_scope 設定を含む構成は、アップグレード後にそれを不明なキーとして報告しなくなりました。 (#2292)
  • Enter to confirm · Esc to cancel を使用するクロード コード確認プロンプトは、idle ではなく blocked を報告するようになりました。 (#2268)
  • Kiro CLI プロンプトは、不明な状態のままではなく、肯定的なアイドル状態を検出するようになりました。 (#2301、ありがとう@smileynet)
  • カーソルの Run Everything フッターが誤ってブロックされた状態を生成しなくなりました。 (#1763、#2220、ありがとう @Nagi-ovo)
  • python3.13 などのバージョン付き Python エージェント ラッパーが検出されるようになりました。 (#2188、ありがとう@plarson)
  • Pi 状態レポートでは、対話型 TUI セッションではない RPC、JSON、および印刷モード ヘルパー プロセスが無視されるようになりました。 (#2159、ありがとう@rhjoh)
  • 折りたたまれたワークスペースとエージェント行では、10 個以上のワークスペースを含め、ステータスとアクティブなインジケーターが表示されたままになります。 (#2216、#2239、#2382、ありがとう @ianks)
  • 異なるサイズの client が同じセッションに接続されている場合、サイドバー エージェント リストがスクロールし続けます。 (#2255、ありがとう @aiworkflowpro)
  • セッション ナビゲータは、名前が変更された単一タブのラベルを検索するようになりました。 (#2320)
  • 新しい分割は、開いた元のペインにフォーカスを戻します。 (#2266、ありがとう@jondkinney)
  • 半角カタカナの濁点および半濁点が正しいセルに表示されるようになりました。 (#2257、ありがとう@kazunari-kamata)
  • Ctrl-cli で URL をロックしても、ブラウザがホスト フォーカスを取得した後はそのリリースが転送されなくなり、タブの重複が防止されます。 (#2290、#2291、ありがとう@kataokatsuki)
  • OSC 4 パレット オーバーライドは、パレット インデックスを転送するのではなく、要求された色でレンダリングされるようになりました。 (#2162、ありがとう @hamidi-dev)
  • フォーカスが戻ったときにホスト端末の外観が再クエリされ、自動の明るいテーマと暗いテーマが最新の状態に保たれます。 (#2416、#2417)
  • バンドルされインストール可能な Herdr エージェント スキルが、この安定版リリースの CLI およびライフサイクル動作と一致するようになりました。 (#2847)
  • pane send-keys および agent send-keys は、shift+tab を送信するときに Shift を保持するようになり、エージェントの権限モードをプログラムで切り替えることができるようになりました。 (#1561、ありがとう @keinstn と @tomohira)
