herdr v0.9.0

マイナー 公開日2026年9月7日 出典herdrdev/herdr 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#ヘルドラv0.9.0

追加

  • 統合されたエージェント リスト、マシン スコープのナビゲーション、通知、自動再接続を使用して、1 つの Herdr ウィンドウからローカルおよび保存された SSH マシンを管理します。 herdr machine を使用して接続を追加および管理します。切断されたマシンが他のマシンに割り込むことはありません。 (#3670)
  • 複数の client が異なるワークスペースとタブを個別に表示できるようになりました。表示する client に応じて異なるタブが表示されます。 client がタブを共有する場合、最後に操作したタブがそのサイズを制御します。 (#3526)
  • アイドル、作業、承認、および質問の状態に対する Muse エージェントの検出を追加しました。 (#2489、ありがとう@ohk)
  • サイドバーのテキストとメタデータのトークンは、順序付けされたテキストまたは数値ルールを使用して、その値に基づいて色、太字、および淡色を変更できるようになりました。 (#3693)
  • テーマの自動切り替えが有効になっている場合、カスタム テーマで明るい色と暗い色のオーバーライドを個別に定義できるようになりました。 (#2324、ありがとう@aneym)
  • 外側の境界線が有効な場合、ui.pane_borders = "always" は単一ペインをフレーム化できるようになりました。 "auto" は分割専用の境界線を保持し、"off" は境界線を非表示にし、既存のブール値は引き続き機能します。 (#3234、ありがとう @rsmdt)

変更されました

  • Client アップデートにより、互換性のあるサーバーとその実行中のエージェントをそのまま残すことができるようになりました。サーバー機能が不足している場合、接続は妨げられず、影響を受けるアクションのみが無効になります。エンドポイント第 1 世代より古いサーバーは、1 回限りのアップグレードが必要です。リモート サーバーを交換すると、そのペイン プロセスを停止する前に尋ねられます。デフォルトの答えは [いいえ] です。実験的なハンドオフはオプトインのままです。 (#3509)
  • ターミナル UI が各 client で実行されるようになり、多忙な複数の client セッションでの再描画作業が軽減され、テーマ、メニュー、コピー モード、およびその他のプレゼンテーション設定が表示マシンのローカルに維持されます。 (#3487)
  • アイドル状態のターミナルのスクロールバックでは、保持される履歴を減らしたり、読み取りを変更したり、サイズを変更したりすることなく、使用するメモリが少なくなりました。 (#3556)
  • ペイン イメージとグラフィック API が、互換性のある端末でデフォルトで有効になるようになりました。それらを無効にするには、terminal.kitty_graphics = false を設定します。古い experimental.kitty_graphics 設定は引き続き受け入れられます。
  • 開いているワークツリー ワークスペースを持つプライマリ ワークスペースを閉じるには、明示的なグループ インテント (workspace close --group または workspace.close と close_group: true) が必要になりました。それ以外の場合は、グループ全体が開いたままになります。 (#2874)
  • 新しいライフサイクル イベント サブスクリプションは、保持された履歴を再生するのではなく、ライブ イベントから開始されるようになりました。 API clients は、変更の欠落を避けるために、最初のスナップショットを取得する前にサブスクライブする必要があります。 (#1270)

修正済み

  • 自動コピーが無効になっている場合も含め、ターミナル出力が継続している間、マウス選択は表示され、コピー可能な状態を維持するようになりました。 Ctrl+C および Cmd+C は、マウスを離す前でも選択内容をコピーし、コピーの失敗によってエージェントが中断されることはなくなりました。ホストカラーが使用できない場合でも、選択範囲のハイライトは表示されたままになります。 (#3100、#2708、#3684、@moret と @Pimpmuckl に感謝)
  • Wayland clipboard のコピーは、wl-copy が選択を提供している間、Herdr をフリーズしなくなりました。 (#3014)
  • ライブ ハンドオフでは、実行中のペイン アプリケーションのマウス転送が保持されるようになりました。 (#3000、ありがとう @xkrogen)
  • ホストのシャットダウン中にペインが中断されて終了しても、保存されたセッションが空のセッションまたは新しいデフォルトのワークスペースに置き換えられなくなりました。 (#3415)
  • ターミナルが消える SSH clients は、実行中のペインのサイズをフォールバック サイズに変更して高価な履歴リフローをトリガーするのではなく、切り離されるようになりました。 (#3519)
  • ワークスペースにフォーカスすると、サイドバーがスクロールして表示されたままになるようになりました。 (#3554)
  • バックグラウンド ワークツリー ワークスペースを削除しても、フォーカスがその親に変更されなくなりました。 Windows ワークツリーは、エージェント ペインの実行中に、置換シェルがチェックアウトを再度ロックすることなく削除することもできます。 (#3098、#3532)
  • Worktree コマンドは、グローバル Git 構成を変更することなく、--trust-repository を使用した 1 つのリクエストに対して検証済みリポジトリ (別の SID が所有するアクセス可能な Windows リポジトリを含む) を trust できるようになりました。 (#3044)
  • 特大のキティ画像によって小さい画像が表示されることが妨げられなくなり、画像の置換が一度に 1 行ずつ再描画されたり消えたりすることがなくなりました。直接グラフィックスは、それを所有する client にバインドされたままになります。 (#3033、#3166、#3549、ありがとう@kataokatsuki)
  • ペイン アプリケーションが SGR マウス レポートを再アサートしても、ピクセル マウスの座標は正しいままです。 (#3295)
  • prefix+| などのプレフィックス バインディングは、macOS オプションおよびカスタム キーボード レイアウトによって生成された文字を認識するようになりましたが、正確なコードが優先されます。矢印ナビゲーションは、Alacritty などの端末が特殊キー レポートにテキストを添付する場合にも機能します。 (#3079、#3328、ありがとう @vlcinsky)
  • 直接ターミナル接続は ui.mouse_capture を尊重し、各行を個別に送信するのではなく、複数行のペーストを 1 つのペーストとして保存するようになりました。 (#2992、#3054)
  • agent prompt は、送信の成功を報告する前にプロンプトと Enter を確実に送信するようになりました。 --wait では、動作していないエージェントに送信されるプロンプトには、監視された動作またはブロックされたアクティビティが必要であるため、無関係な状態の変化によって待機を完了することはできません。ターミナルが終了すると、保留中の送信は正常に失敗します。 (#3506、#3685)
  • Windows 上の長い Codex プロンプトは、テキストが到着するまで十分な時間待機してから Enter を送信するようになりました。キューに登録された期限切れの送信は、入力が開始される前に拒否されます。 (#3187)
  • 最近のペインの読み取りには、空のテキストを返すのではなく、まだビューポートからスクロールされていない出力が含まれるようになりました。 (#3444)
  • pane report-agent および pane report-agent-session は、ペイン ID および --option=value 引数の前にオプションを受け入れるようになりました。 (#2926)
  • herdr agent explain --file は、読み取り不可能なファイルを生の Rust エラーではなく、構造化された JSON として報告するようになりました。 (#3022)
  • 実行中の名前付きサーバーは、再起動を必要とせずに、別のサーバーによってダウンロードされた検出マニフェストを取得できるようになりました。 (#2711)
  • 起動時に端末のタイトルまたは進行状況を一度設定するエージェントは、最初に認識されたときにその検出信号を失わなくなりました。 (#3326、ありがとう@aneym)
  • Claude Code は、端末タイトルが利用できないときに目に見えるターンとバックグラウンド エージェントのアクティビティを認識するようになり、バックグラウンド MCP タスクが継続している間も動作し続けます。バックグラウンド シェルのみが実行されているアイドル プロンプトは動作しなくなりました。 (#1630、#3090、#3414)
  • Claude Code MCP の質問と Bash 承認プロンプトは、さまざまなオプション レイアウトやカーソル位置を含む、回答を待っている間ブロックされたままになります。 (#3283、#3383、#2650、#3615、ありがとう @caner-akca)
  • クロード コード フックはカーソルのクロード互換イベントを無視するようになり、カーソル セッションがクロード セッションとして保存されなくなりました。 (#2832)
  • 以前の出力では確認プロンプトが引用されているため、Codex はブロックされているようには見えなくなり、起動更新ダイアログではブロックされたことが正しく報告されるようになりました。明示的に再開されたセッションは最初のプロンプトが表示される前に保存されるため、サーバーの再起動後も存続します。 (#3301、#3632、#3517)
  • GitHub コパイロット CLI は、バックグラウンド エージェントを待機している間も動作し続けるようになりました。 (#3291、#3403、ありがとう @LaneBirmingham)
  • Oh My Pi は、一時的にアイドル状態を報告して agent wait を早期に終了するのではなく、すでにスケジュールされた継続作業を継続するようになりました。 (#2851、#3122、@caner-akca と @taoeffect に感謝)
  • OpenCode の子エージェントの権限と質問プロンプトにより、作業を続行した後に親ペインがブロックされたままになることがなくなりました。 (#3669、ありがとう @markjaquith)
  • フォアグラウンド作業ディレクトリの読み取りは、子孫ではなくフォアグラウンド プロセス グループ リーダーに従い、新しいペインを目的のディレクトリに保持するようになりました。 (#3270、#3386、ありがとう @caner-akca)
  • サイズが大きすぎる、または読み取り不可能な Git ref ファイルによって、重いステータス読み取りが繰り返されたり、ワークスペースで古い ref データが使用されたりすることがなくなりました。 (#3343、#3373、ありがとう @caner-akca)
  • タブ バーのステータス コマンドで、迷走する ANSI エスケープ フラグメントが表示されなくなり、ホスト パレットの応答が一緒に適用されて、冗長な更新が回避されます。 (#3001、#3580)
  • Unix プラグイン ペインは、明示的にオーバーライドされない限り、PWD を要求された作業ディレクトリに合わせて維持するようになりました。 Windows プラグイン ペインは、プラグイン ルートからの相対コマンドを解決し、起動パスを正しく処理するようになりました。 (#2984、#3024)
  • プラグイン リンク ハンドラーは、一致する OSC 8 file:// clicks を受信するようになりました。ファイルリンクが一致しない場合でも、システム URL オープナーは起動しません。 (#2941)
  • Windows ペインは、キティ キーボード アプリケーションの非 US シフト テキスト、物理的に変更されたキー、Ctrl+/、デッド キーの合成を保持するようになりました。 (#3045、#2954、#3546、#3503)
  • Windows OpenSSH セッションは、レポートがドロップされたり、フラグメントがペインに漏れたりすることなく、マウス入力を確実に受信できるようになりました。リモートおよび LF のみの複数行ペーストでは、改行と順序が保持されます。 (#2810、#3459、#3209、#3172)
  • Windows ペインはカーソルおよびバンドルされた Pi 起動を検出したままにし、PowerShell エージェント シムはネイティブ引数を受け入れます。 Codex は、再開中に過度の再描画やスクロール ジャンプを引き起こす Windows Terminal ID を継承しなくなりました。 (#3032、#3205、#3455、#3127、ありがとう @Pimpmuckl)
  • Antigravity フックは Windows 上で正しく実行されるようになり、Devin 統合セットアップでは正しい Windows config ディレクトリが使用されます。 (#3348、#2724)
  • Windows インストールでは、Visual C++ ランタイムを個別にインストールする必要がなくなりました。インストーラー パスは OpenSSH セッションで引き続き検出可能であり、不正な形式で継承された環境値は安全に拒否されます。 (#3089、#3611、#3430)
  • エンドポイント セキュリティによりファイルレス PowerShell インストールがブロックされている Windows ユーザーは、チェックサム検証されたダウンロードを使用してローカル install.cmd ブートストラップを使用できます。 (#2751)
  • WSL リモート セッションで、Windows clipboard から画像を貼り付けることができるようになりました。 (#3376)
  • Nix インストールは静的 CDN 経由でクレートを取得するようになり、以前のエンドポイントからのダウンロードの失敗を回避します。 (#3505)
  • Unix インストーラーは、そこで実行できない Linux バイナリをインストールするのではなく、Android/Termux がサポートされていないことを説明するようになりました。 (#3571)

削除されました

  • シングルプロセス --no-session モードを削除しました。すべてのターミナル UI の起動はバックグラウンド サーバーに接続されるようになりました。 detach はペインを実行したままにし、server stop はセッションを終了します。
