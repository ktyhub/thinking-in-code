herdr v0.9.1

パッチ 公開日2026年9月16日 出典herdrdev/herdr 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#ヘルドラv0.9.1

追加

  • herdr --machine <label-or-id> を使用して、保存された SSH マシン上のエージェント、ペイン、ワークスペース、およびワークツリーを制御します。コマンドは、Herdr ウィンドウを開く必要がなく、保存されたマシンのセッションを使用します。 CLI 転送を使用するように両方のマシンの Herdr を更新します。失敗したリモート コマンドがローカルにフォールバックすることはありません。 (#3918)
  • Linux、macOS、または Windows から Windows SSH ホストに接続します。対話型セットアップでは、確認後に完全な Windows パッケージをインストールまたは更新できます。バックグラウンドで再接続すると、更新プログラムがインストールされません。 (#3651、#3701、#3661、#3687、ありがとう @JJLiebig)
  • 名前、フィルターを編集し、末尾だけでなくカーソル位置でテキストを検索します。 Herdr 入力は、文字と単語の移動、Home/End、削除、および Unicode テキストを含む使い慣れた Ctrl+A/E/K/U/W/Y ショートカットをサポートするようになりました。 (#1803、#3698、@markjaquith に感謝)
  • Letta コードの検出と、デフォルトの会話を含むネイティブ会話の復元が追加されました。その実験的な統合は、設定統合リストや JSON 統合 API ではなく、herdr integration install letta を通じてインストールされます。 (#3106、#3107、ありがとう @just-cameron)
  • リンクを開く前に、Ctrl キーを押したままリンクを強調表示します。ラップされた URL と OSC 8 リンクは、先頭または末尾がビューポートの外にある場合でも、clickable のままです。 (#1282)
  • サイドバーのトークン ルールで、hide = true を使用して一致するトークンとその区切り文字を非表示にできるようになりました。トークンがなくなると行は消えます。 (#3925)

変更されました

  • ワークスペースのキーボード ナビゲーションは、サイドバーの順序で接続されているマシンにまたがるようになり、Enter でマシンが切り替わる前にハイライトが表示されます。折りたたまれたマシンおよびワークツリー グループは、誤って間違ったマシンにアクションを送信することなく、ナビゲート可能な状態を維持します。 (#3754)
  • 実験的なライブ ハンドオフでは、送信サーバーにこのアップデートが含まれている場合、64 を超えるペインを転送できるようになりました。実行中の古いサーバーには、最初のアップグレードに対する古い制限がまだ残っています。これにより、アップデートのインストール順序が変更されたり、ライブ ハンドオフが非実験的になったりすることはありません。 (#3393、#3411、ありがとう@kataokatsuki)
  • Linux および macOS では、出力の受け入れを停止したターミナル オブザーバーは、書き込みが進行せずに 30 秒後に切断されます。これらのペインと他の client は実行を続けます。中断されたストリームは、最終的なクローズ記録なしで終了する可能性があります。 (#3612)
  • Windows ターミナルのクリーンアップで、マウス レポート モードが明示的にリセットされるようになりました。 #3748 にある残りのスタンドアロン Git Bash 切り離しレポートはまだ調査中です。このリリースをそのレポートに対する確認済みの修正として扱わないでください。 (#4055、ありがとう@JJLiebig)

修正済み

  • リモートでの入力、切り替え、ポップアップ操作で、小さな変更を加えてもペイン画面全体が再送信されなくなりました。ビジー状態の SSH セッションでは使用する帯域幅が少なくなり、接続されているアイドル状態の client により不必要な再描画作業が回避されます。 (#3769、#3745、#3822)
  • ストールした SSH マシンがローカルから client をトラップしなくなりました。 Cliローカル ワークスペースまたはエージェントをロックすると、未完了のリモート切り替えがキャンセルされ、回復されたリモート ワークスペースは、アウェーアンドバックの選択なしで更新されます。再接続前の古い画面は再利用されません。 (#3903、#3842)
  • アイドル状態の SSH 接続では、最終出力を失うことなく CPU 使用量が削減されます。繰り返される接続障害は、rapidly に再接続する代わりにバックオフされ、サポートされているアイドル状態のブリッジはリモート ペインを停止することなくクリーンアップされます。 (#3728、#4083)
  • 大量のペーストによって出力キュー エラーが発生して client が切断されることがなくなりました。 (#3833)
  • SSH セットアップでは、ハングしたように見えたり、接続が失われたことだけを報告したりするのではなく、認証手順と、Tailscale ログイン URL やホスト キーの失敗などの有用なエラーが表示されるようになりました。 machine add は、SSH ターゲットの前のオプションも受け入れます。 (#3606、#3731、#3883)
  • 選択したワークスペースを変更せずに、マシンとワークツリーのグループが正しく折りたたまれます。サイドバーはワークスペース行のギャップを尊重し、サイズ変更中も安定し、新しくフォーカスされたワークスペースを表示します。 (#3778、#3738、#3817)
  • マシンを切り替えても、エージェントリストのスクロール位置は維持されます。現在のワークスペース フィルターと現在のタブ フィルターは、異なるマシン上の同一の ID を区別します。 (#3937、#4101、#3732、ありがとう @minatoaquaMK2)
  • バックグラウンドでマシンをアクティブ化しても、別の client のフォーカスされたペインのサイズが変更されなくなりました。ウィンドウ タイトルは、別の client の選択ではなく、各 client 独自のビューに従います。 (#3744、#4091、#4130、ありがとう @JJLiebig)
  • agent focus および pane move --focus は、接続された client を要求されたペインに移動するようになりました。フォーカスなしで移動しても、削除されたタブやその後の無関係なフォーカスの変更に続いて client が残されることはなくなりました。 (#3760、#4153、#4171、ありがとう @minatoaquaMK2)
  • ワークツリーを作成すると、その新しいワークスペースが再びフォーカスされます。部分的に失敗したワークツリーの削除は再試行でき、サブモジュールを含むワークツリーでは、回復アクションなしで失敗するのではなく、明示的な強制削除の選択肢が提供されます。 (#3766、#3314、#1797)
  • 一時的なワークツリー アクション エラー バナーは、画面上に無期限に残るのではなく、期限切れになります。 (#1827、#4063、ありがとう @JJLiebig)
  • タブ ストリップがオーバーフローしても、最後のタブは完全に表示されたままになり、セッション ナビゲーターは接続されたツリー ブランチを再度描画します。 (#4151、#3843)
  • ミュートされたサイドバーとタブのラベルは、Windows ターミナルを含むダーク テーマでも読みやすいままです。 (#2692、#4062、ありがとう @JJLiebig)
  • マウス ドラッグとコピー モードの選択は、選択の一部がビューポートの外にある場合でも、出力が続行されている間アクティブなままになります。コピーでは、選択した範囲内の現在のテキストが使用されます。選択範囲を再描画すると、マウスの動きのバックログが蓄積することも避けられます。 (#3841、#3895)
  • ダブル click の選択は、自動コピーが無効になっても表示されたままになります。 2 番目の click を押したままドラッグすると単語全体が拡張され、トークンの選択は CJK 句読点で停止します。ホスト選択の色は、透明な背景でも表示されたままになります。 (#3847、#1836、#3706、#3798)
  • Neovim などの全画面アプリケーションで、スクロールしても不一致の端末スナップショットが結合されたり、ラップされた行が古くなったりしなくなりました。代替画面履歴読み取りでは、ヘッダーやスクロールバーが変化してもコンテンツが保持されます。 (#3900、#3329、#3979)
  • ローカルキティグラフィックスは、最初の画像の後に直接トランスポートを維持します。ポップアップと通知は、重なっている画像の配置のみを非表示にします。カバーされていない画像は表示されたままになります。 (#3785、#4081)
  • ピクセル マウスの座標は画像レンダリングとは独立して動作し、端末の整数セル サイズを使用するため、click が画面上をドリフトするのを防ぎます。 (#3295、#4140、ありがとう @JJLiebig)
  • ファンクション キー F1 ～ F12 は Kitty キーボード レポートで認識され、F1 ～ F4 はフットなどの端末からのパラメータ化されたレポートでも機能します。 (#1809、#2378、#4067、@ashokDevs と @JJLiebig に感謝)
  • WezTerm のコントロール キー レポートでは、Enter、Backspace、Tab、および Escape が保持されるようになりました。 Cmd/Super 修飾された入力は、修飾子がそのままの状態でペイン アプリケーションに到達します。変更された Enter は、拡張キー エンコーディングを要求していないペインとの互換性を維持します。 (#3589、#3710、#4103、#4110、ありがとう @minatoaquaMK2)
  • 遅延読み取り全体に分割されたマウス レポートで、末尾のバイトがペイン入力に漏れなくなりました。 Clients は、端末の再接続後にマウスのレポートを再アサートします。 (#3911、#4079、ありがとう @JJLiebig)
  • ロードできない保存されたセッションは、サイレントに上書きされるのではなく、置換前に保存されます。リカバリ コピーは session-backups/ に保存されます。保存に失敗すると、オリジナルがそのまま残ります。 (#4125)
  • セッションを削除するには、大文字と小文字を区別しないファイルシステム上で、大文字と小文字を含む正確な名前が必要になりました。ハイフンで始まる名前は、-- の後に渡すことができます。 (#3819、#4233、#3220、ありがとう @minatoaquaMK2)
  • 新しく起動した macOS サーバーは、ログアウトしてもユーザー検索と DNS へのアクセスを保持します。影響を受ける既存のサーバーはセッションを完全に再起動する必要があります。ライブ ハンドオフでは、継承されたサービス コンテキストを修復できません。 (#4100)
  • Linux プロセス検出は、スタックした WSL エージェントに関して応答性を維持し、成長し続けるプロセス ツリーを繰り返しスキャンすることを回避します。 (#2179、#3621、#3674、@dark2momo と @caner-akca に感謝)
  • Linux デスクトップ通知は、Herdr をソースとして識別します。 (#3638)
  • ターゲットのない pane split は、Herdr 内で呼び出されたときに、別の client のフォーカスされたペインではなく、呼び出しペインを分割するようになりました。明示的なターゲットは既存の動作を維持します。 (#4123)
  • アクティブ エージェント名は、アクティブ エージェントを名前でアクセスできないままにするのではなく、一時的なプロセス検出の不確実性を維持します。 (#3225、#3574、ありがとう @caner-akca)
  • Windows Codex プロンプトは、長いプロンプトを含め、Enter キーを失うことなく、テキストを貼り付けた後に確実に送信されます。 (#3187、#3961、ありがとう @JJLiebig)
  • OpenCode V2 は、会話を表示しているペインからライフサイクル状態を報告するため、共有サーバーがペインを混同することはありません。完了および中断されたターンはアイドル状態に戻りますが、保留中のパーミッション、フォーム、および失敗した実行はブロックされたままになります。 V1 は引き続きサポートされます。更新された統合をインストールした後、OpenCode を再起動します。 (#3757、ありがとう @markjaquith)
  • Codex は、静的なタイトル、無効なアニメーション、およびキューに入れられたフォローアップで動作し続けます。 Composer の輝きと古い確認テキストにより、アイドル状態のペインがブロックされているように見えなくなりました。 (#4092、#4099、#3988、ありがとう @minatoaquaMK2)
  • Claude Code の Unicode アクティビティ スピナーと Pi の作業境界線が正しく認識されます。 Cline ランチャーの検出とアイドル状態のレポートの信頼性が向上しました。 (#3949、#3629、#2396)
  • Pi は Windows 上のネイティブ セッション パスを記録します。ネストされた OMP プロセスは親ペインの再開可能なセッションを置き換えなくなり、Windows Kim npm shims が認識されます。 (#3726、#2593、#3994、#3317、#4053、ありがとう @JJLiebig)
  • Grok は /new の後に復元参照を更新し、インポートされた Claude 互換フックはその参照を上書きしなくなりました。クロード統合を再インストールして、より狭いフックマッチングを採用します。 (#2681、#4018)
  • 統合構成の更新では、書き込みが失敗した場合でも既存のファイルが保持されます。有効なプラグインがインライン リストを使用する場合、Hermes インストールでは有効な YAML も保持されます。 (#3970、#3839、#4056、ありがとう @JJLiebig)
  • プラグイン レジストリの書き込みではシンボリック リンクが保持されます。プラグインは、client のみの更新後も実行中のサーバーの互換性のあるバイナリを使用し続け、手動ペイン ナビゲーションによってフォーカス イベントが再び発行されます。 (#3922、#3824、#4077)
  • UTF-8 BOM を含む構成ファイルは正しくロードされ、保存されます。デフォルトの設定では、ui.accent が右側のテーブルに配置されます。 (#3678、#3962、#2697、ありがとう @JJLiebig)
  • Windows ローカルおよび SSH 入力では、キーのドロップやガベージの挿入の代わりに、Alt の組み合わせ、Ctrl+S、および拡張されたキーボード テキストが保持されます。リモートデッドキー入力で余分な基本文字が追加されなくなりました。 (#3702、#3910、#3932、#3948、#4133、#4148、ありがとう @JJLiebig)
  • Windows マウス キャプチャでは、過去の列 95 を含む SGR 座標が保存され、再接続するとマウス レポートが復元されます。従来の SSH マウス レポートは、ファントム文字を生成したり、後続の入力をブロックしたりしなくなりました。 (#4155、#3735、#4080、ありがとう @JJLiebig)
  • Git Bash SSH 接続は、ユーザーの SSH 構成からのホスト エイリアスを尊重します。 (#3947、#4054、ありがとう @JJLiebig)
  • Windows ログイン モード ペインは、構成されたシェルを尊重し、PowerShell 作業ディレクトリ レポートを最新の状態に保ちます。ペインの起動パスでは、一貫したディレクトリの大文字と小文字が使用されます。 (#1445、#4060、#4065、#4199、ありがとう @JJLiebig)
