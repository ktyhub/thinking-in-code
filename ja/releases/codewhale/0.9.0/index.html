コードホエール v0.9.0

Codewhale は Shannon Labs の公開製品です。 codewhale コマンド、npm パッケージ、リリースアセット名は技術的に小文字のままです 識別子。従来の npm パッケージ deepseek-tui は非推奨になりました。 今後のリリースは受け付けません。 v0.8.x レガシー deepseek からのユーザー / deepseek-tui 名は docs/REBRAND.md とともに移行する必要があります。

インストール

推奨 — npm (1 つのコマンド、両方のバイナリ)

npm install -g codewhale

ラッパーは、一致するランタイム バイナリをこのリリースからダウンロードし、同じディレクトリに配置します。

Docker / GHCR

docker run --rm -it \
  -e DEEPSEEK_API_KEY="$DEEPSEEK_API_KEY" \
  -v codewhale-home:/home/codewhale/.codewhale \
  ghcr.io/hmbown/codewhale:v0.9.0

このイメージには、codewhale ディスパッチャ、codew シム、および codewhale-tui ランタイムが同梱されています。 latest タグもリリース時に更新されます。

カーゴ (Linux / macOS)

cargo install codewhale-cli codewhale-tui --locked

両方のクレートが必要です。codewhale-cli は codewhale ディスパッチャーと codew シムを生成し、codewhale-tui はディスパッチャーが委任する対話型ランタイムを生成します。クレートを 1 つだけインストールすると、実行時に MISSING_COMPANION_BINARY エラーが発生して失敗します。

手動ダウンロード — プラットフォーム アーカイブ (推奨)

以下の各アーカイブには、codewhale ディスパッチャー、codew シム、codewhale-tui ランタイムに加えて、インストール スクリプトが含まれています。 |プラットフォーム |アーカイブ |スクリプトをインストールする | |---|---|---| | Linux x64 | codewhale-linux-x64.tar.gz | install.sh | | Linux ARM64 | codewhale-linux-arm64.tar.gz | install.sh | | Android ARM64 (Termux) | codewhale-android-arm64.tar.gz | install.sh | | macOS x64 | codewhale-macos-x64.tar.gz | install.sh | | macOS ARM | codewhale-macos-arm64.tar.gz | install.sh | | Windows x64 (インストーラー) | CodeWhaleSetup.exe | NSIS セットアップ | | Windows x64 | codewhale-windows-x64.zip | install.bat | | Windows x64 (ポータブル) | codewhale-windows-x64-portable.zip | — | Unix (Linux / macOS):

tar xzf codewhale-<platform>.tar.gz
cd codewhale-<platform>
./install.sh

  • codewhale-windows-x64.zip の抽出
  • install.bat を実行します (%USERPROFILE%\bin にコピー)
  • %USERPROFILE%\bin を PATH に追加します ポータブル Windows アーカイブはインストール スクリプトをスキップし、任意のディレクトリから抽出して実行します。 NSIS インストーラーは現在署名されていないため、署名証明書がリリース パイプラインに組み込まれるまで Windows SmartScreen をトリガーする可能性があります。 各プラットフォームには、ベア、アーカイブされていない バイナリ (codewhale-<platform>、codew-<platform>、および codewhale-tui-<platform>) が以下に添付されています。npm ラッパーとアプリ内 codewhale update は一致するランタイム バイナリをダウンロードしますが、上記の .tar.gz / .zip アーカイブは推奨される手動ダウンロードであり、さらにインストール スクリプトがバンドルされています。従来の npm パッケージ deepseek-tui は非推奨となり、再公開されません。 v0.8.x のレガシー バイナリ名からの移行については、docs/REBRAND.md を参照してください。

確認する (推奨)

# Linux — individual binaries

# macOS

shasum -a 256 -c codewhale-artifacts-sha256.txt

  • codewhale fleet run およびインタラクティブな進行中のフリートの打ち上げは、 単に記録するのではなく、プロファイルに固定されたプロバイダー/モデル ルート 領収書。ヘッドレスワーカーは非機密の --provider および --model を受け取ります ペア。 TUI ワーカーは、プロセス中の同じ明示的なルートを解決します。資格情報 依然としてワーカーの環境から取得され、プロバイダーは決してワーカーの環境から推論されません。 モデル ID と固定解除されたワーカーは引き続き実行ルートを継承します (#4093、 #4193)。

  • フリート プロファイルの保存は、フリート プロファイルを固定するときに明確なメッセージが表示されて失敗するようになりました。 資格情報が設定されていないプロバイダーは、同じものを使用します モデルピッカーが使用する構成プロバイダーをチェックします (#4093)。
  • ワークフローの正確さ: 完了ポーリングは、代わりに失敗して閉じられます。 サブエージェントが端末ステータスを報告しない場合に成功を捏造する。キャンセル JS VM を中断し (ハンドルのキャンセル + 中止)、それ以降の生成をブロックします。 budget.spent() は、常に 0 ではなく実際のマネージャー スコープの使用状況を報告します。
  • サブエージェントの生成は、ディスパッチ前にモデル ↔ プロバイダーのペアを検証します。 継承された高速ルートは、外部モデルをプロバイダーのカタログに再マッピングします。 デフォルトで、明示的なピンは、診断ではなく診断で高速に失敗します。 上流モデルが見つからないエラー。
  • TUI の安定性: エンジン イベント ドレインは 8 ～ 16 イベント / 8 ミリ秒ごとに中断されます。 入力ライブ (#1830、#2317、#1198);端末入力ポンプはその後再起動します macOS/Linux でもストール回復。起動時の raw モード プローブは廃止されました タイムアウト時に raw モードをリークします。リカバリスナップショットは 45 秒ごとに保持されます。 ターンが長く、プッシュするたびにオフライン キューが持続します (#1830)。 ストリーミング中のキュー/ステア パス サーフェス トースト (#2317、#1338)。そして モーダル送信エラーは、モーダルを飲み込むのではなく再度開きます (#1198)。
  • コア/状態: 一時停止されたジョブは、再起動しても一時停止されたままになります。アーカイブを解除する メモリ内キャッシュを更新します。ツールのディスパッチにはタイムアウトがあります。 MCP 通知は応答を受信しなくなります。破損したチェックポイントが表面化 空の状態をロードする代わりにエラーが発生します。代わりにセッションインデックスが圧縮されます 際限なく成長すること。スレッド目標の使用状況を記録しなくなりました 状態ストアを自己デッドロックします。
  • 実行時圧縮の概要が /v1 スレッド レコードに保存されるようになりました。 エンジンのリロードと再起動では、圧縮されたコンテキストが保持されます。寄稿者 MXAntian (@MXAntian) (#4091)。
  • マウス キャプチャが無効になっている場合、TUI は xterm 代替スクロール モードをオフのままにします。 ライトテーマ/マウスキャプチャなしでネイティブ端末のテキスト選択を保持する セッション。 Nightt (@nightt5879) による投稿 (#4088、#4026)。

セキュリティ

  • /v1/chat/completions にはベアラー認証が必要です。トークンを比較します。 一定時間、正確な 4xx/5xx ステータスを返す、バインドされたリクエスト本文および SSE フレームを削除し、stdio config get からシークレットを編集し、ランタイムを確実に取得します。 シャットダウン中の子供。
