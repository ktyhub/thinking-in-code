コードホエール v0.9.6

Codewhale は Shannon Labs の公開製品です。 codewhale コマンド、npm パッケージ、リリースアセット名は技術的に小文字のままです 識別子。従来の npm パッケージ deepseek-tui は非推奨になりました。 今後のリリースは受け付けません。 v0.8.x レガシー deepseek からのユーザー / deepseek-tui 名は docs/REBRAND.md とともに移行する必要があります。

インストール

推奨 — npm (1 つのコマンド、両方のエントリポイント)

npm install -g codewhale

ラッパーは、一致する codewhale および codew コマンド アセットをダウンロードします。 このリリースから。どちらにも同じコンパイル済みランタイムが含まれています。

Docker / GHCR

docker run --rm -it \
  -e DEEPSEEK_API_KEY="$DEEPSEEK_API_KEY" \
  -v codewhale-home:/home/codewhale/.codewhale \
  ghcr.io/hmbown/codewhale:v0.9.6

このイメージは、codewhale と codew の両方と同じランタイムを公開します。の latestタグもリリース時に更新されます。

カーゴ (Linux / macOS)

cargo install codewhale-cli --locked

Cargo パッケージには codewhale がインストールされます。 Cargo は 2 番目のコマンドを作成できません 1 つのバイナリ ターゲットからのエイリアス。スペルを短くしたいユーザーは、 codew は、インストールされた実行可能ファイルへのシンボリックリンクです。 npm、Homebrew、アーカイブ、 シェルインストーラーとコンテナー チャネルは、両方のコマンド名を直接インストールします。

Windows:

  • インストーラー パスの場合は、CodeWhaleSetup.exe を実行します。インストールします codewhale.exe および codew.exe の下 %LOCALAPPDATA%\Programs\CodeWhale\bin を実行し、そのディレクトリを 現在のユーザーのパス。

このリリースからチェックサム マニフェストをダウンロードし、次のことを確認します。

# Linux — archive bundles
sha256sum -c codewhale-bundles-sha256.txt --ignore-missing

# Linux — individual binaries
sha256sum -c codewhale-artifacts-sha256.txt --ignore-missing

# macOS
shasum -a 256 -c codewhale-bundles-sha256.txt --ignore-missing
shasum -a 256 -c codewhale-artifacts-sha256.txt --ignore-missing

  • インタラクティブ /load、起動 --resume、および /resume ピッカー パスが保持されます。 永続化されたプロバイダー、エンドポイント、およびモデル ID。ピッカー履歴書も 耐久性のある転写領収書を残します。

  • mcp_config_path の相対値は、起動ディレクトリまたは 空のサーバー プールをサイレントにロードする: Codewhale は警告し、サーバー プールにフォールバックします。 ユーザーグローバル MCP 設定。明示的な絶対パスは引き続き権限を持ちます。

  • Alibaba Model Studio qwen3.8-max および qwen3.8-max-preview は引き続きストリーミングを行っています 彼らの現在の推論は、歴史的な reasoning_content を再現しなくなりました。 これらのルートは受け入れられません。歴史的推論のリプレイは、次によってゲートされるようになりました。 正確なプロバイダー/API/モデル契約のため、不明な *-thinking の類似品 Qwen、Kimi、DeepSeek、Mistral、Anthropic、および 応答継続性ルールはそのまま残ります。

  • 互換性ファイル/パッチ呼び出しでは、オプションのコンテンツ ハッシュ ガードが保持されます。 呼び出し側がそれらを提供します。新しい直接 write および edit スキーマは、 ハッシュまたは事前読み取り式。

  • シェルのプレビューは、不完全な UTF-8 シーケンスを出力する代わりに抑制します。 置換文字と圧縮レシートはトークン デルタを報告します。

  • ネストされたエージェントは狭くなる可能性がありますが、継承された深さバジェットを広げることはできません (#5317 by @ousamabenyounes)。

  • コンテナ公開では、AMD64 イメージと ARM64 イメージを並行してアセンブルするようになりました。 検証済みの静的リリース バイナリからのネイティブ ランナー、その後 1 つのマルチアーキテクチャ マニフェストを公開してチェックします。もう再構築はされない 両方のターゲットは、ランナーを失った単一の長時間実行 QEMU ジョブを通じて実行されます。

削除されました

  • 無進行ガード、反復読み取りガード、および挿入されたツールエラー戦略 コーチング。生産的なポーリング、繰り返しの検査、モデル所有のリカバリ 実行時のヒューリスティックによって中断されることはなくなりました。
  • 配線不要のディシジョンカード、キーバインド、ホバー、シェル実行、エンジン操作、 release-script パスが削除されたため、サポートされているランタイムには 1 つのルートが存在します。 それぞれの行動。
