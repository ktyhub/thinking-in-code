コードホエール v0.8.67

CodeWhale は正規のプロジェクト、コマンド、npm パッケージであり、 リリースアセット名。従来の npm パッケージ deepseek-tui は 非推奨となり、今後のリリースはありません。からのユーザー v0.8.x レガシー deepseek / deepseek-tui 名は移行する必要があります docs/REBRAND.md で。

インストール

推奨 — npm (1 つのコマンド、両方のバイナリ)

npm install -g codewhale

ラッパーは、一致するランタイム バイナリをこのリリースからダウンロードし、同じディレクトリに配置します。

Docker / GHCR

docker run --rm -it \
  -e DEEPSEEK_API_KEY="$DEEPSEEK_API_KEY" \
  -v ~/.deepseek:/home/codewhale/.deepseek \
  ghcr.io/hmbown/codewhale:v0.8.67

このイメージには、codewhale ディスパッチャ、codew シム、および codewhale-tui ランタイムが同梱されています。 latest タグもリリース時に更新されます。

カーゴ (Linux / macOS)

cargo install codewhale-cli codewhale-tui --locked

両方のクレートが必要です。codewhale-cli は codewhale ディスパッチャーと codew シムを生成し、codewhale-tui はディスパッチャーが委任する対話型ランタイムを生成します。クレートを 1 つだけインストールすると、実行時に MISSING_COMPANION_BINARY エラーが発生して失敗します。

手動ダウンロード — プラットフォーム アーカイブ (推奨)

以下の各アーカイブには、codewhale ディスパッチャ、codew シム、codewhale-tui ランタイムに加えて、インストール スクリプトが含まれています。 |プラットフォーム |アーカイブ |スクリプトをインストールする | |---|---|---| | Linux x64 | codewhale-linux-x64.tar.gz | install.sh | | Linux ARM64 | codewhale-linux-arm64.tar.gz | install.sh | | macOS x64 | codewhale-macos-x64.tar.gz | install.sh | | macOS ARM | codewhale-macos-arm64.tar.gz | install.sh | | Windows x64 (インストーラー) | CodeWhaleSetup.exe | NSIS セットアップ | | Windows x64 | codewhale-windows-x64.zip | install.bat | | Windows x64 (ポータブル) | codewhale-windows-x64-portable.zip | — | Unix (Linux / macOS):

tar xzf codewhale-<platform>.tar.gz
cd codewhale-<platform>
./install.sh

Windows:

  • インストーラー パスの場合は、CodeWhaleSetup.exe を実行します。 codewhale.exe、codew.exe、および codewhale-tui.exe を %LOCALAPPDATA%\Programs\CodeWhale\bin の下にインストールし、そのディレクトリを現在のユーザーの PATH に追加します。
  • codewhale-windows-x64.zip の抽出
  • install.bat を実行します (%USERPROFILE%\bin にコピー)
  • %USERPROFILE%\bin を PATH に追加します ポータブル Windows アーカイブはインストール スクリプトをスキップし、任意のディレクトリから抽出して実行します。 NSIS インストーラーは現在署名されていないため、署名証明書がリリース パイプラインに組み込まれるまで Windows SmartScreen をトリガーする可能性があります。 各プラットフォームには、ベア、アーカイブされていない バイナリ (codewhale-<platform>、codew-<platform>、および codewhale-tui-<platform>) が以下に添付されています。npm ラッパーとアプリ内 codewhale update は一致するランタイム バイナリをダウンロードしますが、上記の .tar.gz / .zip アーカイブは推奨される手動ダウンロードであり、さらにインストール スクリプトがバンドルされています。従来の npm パッケージ deepseek-tui は非推奨となり、再公開されません。 v0.8.x のレガシー バイナリ名からの移行については、docs/REBRAND.md を参照してください。

確認する (推奨)

このリリースからチェックサム マニフェストをダウンロードし、次のことを確認します。

# Linux — archive bundles
sha256sum -c codewhale-bundles-sha256.txt

# Linux — individual binaries
sha256sum -c codewhale-artifacts-sha256.txt

# macOS
shasum -a 256 -c codewhale-bundles-sha256.txt
shasum -a 256 -c codewhale-artifacts-sha256.txt

  • サブエージェントの状態は、長引くのではなく、.codewhale/ まで持続するようになりました。 ブランド変更前の .deepseek/ パス (#3864)。 Stime (@yekern) による寄稿。
  • /plugin enable|disable は再起動後も持続するようになりました (#3918)。 プラグイン コマンドはルートのスラッシュ メニューから非表示になり、その後正規に保たれます。 スキャナーのマージ。ナイト (@nightt5879) による投稿。
  • /config ask-rules は、改善された診断機能を備えた ask ルール アクションを表示するようになりました。 テスト中のファイルルールアクションの優先順位を使用します。 @greyfreedom からの寄稿。
  • フリート/サブエージェント: 絶対的な再帰深さの上限を強制し、拡大しました task-id エントロピー。各アトミック状態に一意の一時パスを書き込み、保持されます。 親パリティ (#3836) にサブエージェント ツール カタログがあり、エージェントが作成されました。 サイドバーはサブエージェントの完了とキャンセルをライブで調整します (#3837)。
  • apply_patch の改行のマングリングを修正し、デフォルトのファズを 3 に設定し、書き込みを行った 原子;緊急圧縮時にピンを保持するための固定圧縮、硬化 概要フォールバック、およびイメージ トークンのカウント。バックトラック境界を修正、 チェックポイントのクリア順序付け、プルーン ガード、永続的な名前変更。
  • 最終フレームをフラッシュし、複数行のデータ フィールドを結合するように SSE client を修正しました。 ネットワーク読み取り全体でマルチバイト UTF-8 分割が破損するのを防ぎます。
  • レビュー専用を維持すると読み取り専用になり、エイリアス付きの auto モードがエージェント ポリシーに設定されます。 モード由来の安全性ポリシーをステータスに示しました (@cyq1017 による寄稿)、 そして、耐久性審査フロアがルーチンのYOLO作業を開催するのをやめました (#3883)。
  • 正確なバイナリ リリース アセットを優先するように自己更新を修正しました。寄稿者 @LI-Jialu。
  • UI の洗練: 構成とフリート プロファイル モデルのドラフトを停止 イベント ループをフリーズし、コンテキスト メニューの背景をポップアップに範囲設定しました。 長方形、狭いモーダルに積み上げられたモデルピッカー ペイン、統一された表示幅 1 つの契約のヘルパー (#3924)、誤解を招く成功のトーストを削除、 問題番号のリーク、行き止まりの空の状態、およびオンボーディングを修復しました trust および api キー。
  • オンボーディング Trust ステップを修正し、単純な Enter キーがサイレントに許可されなくなりました ワークスペース trust;ユーザーは明示的に trust または終了キーを選択する必要があります。
  • 同じルートのスキル名の衝突が静かにシャドウされる問題を修正しました。重複 正規化されたスキル名は、検出の決定性を維持しながら警告するようになりました (#3919)。
  • 検出されたスキル名を正規化し、強制されていない trust コピーを削除しました。 プロンプトでゲート憲法のオーバーライドが表面化しました。
  • 1 つのテストがプロセス全体に及ぶ並列 subagent:: スイート フレークを修正しました Retry-After の一時停止により、関係のない予算の上限に達した従業員が足止めされる可能性があります。 完全に古いウィンドウ。リクエストは、制限されたスライスでグローバル一時停止を再ポーリングするようになりました レート制限テストにより、ドロップ時にウィンドウがクリアされます。
  • サブエージェントとフリートの信頼性は空で失敗し、ステップが制限され、 予算が枯渇した子どもたちに、沈黙の代わりに明確な診断を与える Completed (no output) 成功。予算が枯渇しても部分的な生産は維持されますが、 worktree: true は、ハーネス ディレクトリから 1 レベルのネストされたリポジトリを検出します。 開始前完了デリゲート イベントは、代わりに名前付き行に回復されます。 省略記号のみの ID (#4050、#4051、#4052、#4053)。
  • 目標モードの執筆および調査タスクは次の手順で完了できます。 verification.status = "not_applicable" 継続トリガーなし ループ (#4054)。
  • 初回実行オンボーディングでは、選択したプロバイダー、セットアップを通じて API キーをルーティングします。 ウィザード本体は PageUp/PageDown でスクロールし、出荷されたロケール パックは元に戻ります。 en.json zh-Hant とのパリティは明示的に部分的であり、安定した機能フラグはそのままです Experimental の外、モデル/プロバイダーの行には現在の LongCat と 調達価格のヒント (#4056、#4057、#4058、#4062、#4063)。
  • 単一の前景ツールがアクティブな間、実行中のツール行がアニメーション化されます。 ワークフローのレシートでは、一行または null 成功の出力 (#4059)。
  • モデル側のターン メタデータには、コンパクトな git ワークスペース スナップショットが含まれるようになりました。 TUI と同じしきい値でコンテキスト プレッシャーを高め、エージェントを支援します 範囲が狭いか、切り捨ての前にコンパクトになります (#4071、#4073)。
  • 子サブエージェントが正常に完了すると、子の EVIDENCE ブロックがインライン化されます。 完了見張りの前に、保護者は子供の所見を何も言わずに引用できます。 ツールを再実行します (#4072)。
  • 遅延ツールは、元のツールがハイドレートされ、同じバッチで実行されます。 引数は有効であり、[tools].always_load は設定された MCP ツールを保持するようになりました。 最初の呼び出しの再試行を強制する代わりにアクティブになります。 @SparkofSpike に感謝します ホットパス MCP レポート (#4074、#4027)。
  • 新しいコミット範囲の共同作成者チェックにより、新しくプッシュされたボット/ツール トレーラーが拒否されます コミットします。過去のリリース範囲のクリーンアップは別個のメンテナンスのまま 懸念があります (#4075)。
  • ファジー edit_file マッチングを修正し、マルチバイト UTF-8 で始まるものと一致するようにしました。 CJK テキストを含む文字は、文字境界ではなく文字境界上を進みます。 パニックになっている。 Nightt (@nightt5879) による投稿、Taixin Guo による報告 (@taixinguo) (#3971、#4045)。
  • 早期終了パイプの下での Unix ディスパッチャ/TUI 出力を修正しました。 codewhale doctor | head (以前のデフォルトの SIGPIPE ハンドラーを復元する) 信号の印刷と伝播は静かに終了します。 @aznikline による寄稿、 @BrathonBai (#4030、#4043) によって報告されました。
  • 未使用のプラグイン レジストリ モジュールでの Dead_code 警告が抑制されました。 コマンドグループファイル全体のフォーマットを修正しました。パウロ・アボイムによる寄稿 ピント（@aboimpinto）です。
  • Web サイトのコミュニティ ナビゲーション リンクをコミュニティ ハブに指定しました。

セキュリティ

  • MCP client の強化: SSE エンドポイント SSRF を閉じ、HTTP を制限しました ストリーミング読み取りの代わりに Content-Length を介した応答本文、制限された stdio OOM サービス拒否を防ぐための行読み取り、デッド タイムアウトの修正、および 無制限のバッファを削除しました。
  • execpolicy Deny/trust ルールをセグメント対応にし、コマンド チェーンを閉じました バイパスします。
  • 敵対的レビューによりクローズド・レポ法と安全フロアのバイパスが判明: 保護された不変条件がメカニズムとして強制されるようになりました。 セーフティフロアは閉じており、実行パスのないカタログ存在ツール フェイルクローズされるようになり、web_run open/click は破壊的として分類され、 ホワイトリストにはワイルドカードと大文字小文字の処理が追加されました。
  • ワークスペースのエスケープを防ぐために、シンボリックリンクされたルール ディレクトリを拒否しました。 発見された法則。メイプル (@yekern) からの投稿。
  • 制限されたフリートのサブエージェント ワーカー出力により、ファンアウトで TUI メモリを使い果たすことができません (#3882)、進行のためのイベントのヘッドルームを保存しました。一部寄稿 @cyq1017。
  • untrusted 憲法草案ゲートを作成元とともに追加しました。 モデル的に起草された憲法には、人間による明示的な批准が必要です。
