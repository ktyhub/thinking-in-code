インストール

推奨 — 公式 GitHub リリース

新しい macOS/Linux インストール (このリリースのチェックサム済みバイナリ):

curl -fsSL https://codewhale.net/install.sh | CODEWHALE_VERSION="v0.9.12" sh
"$HOME/.local/bin/codewhale" --version

Windows の場合は、以下の対応するインストーラーまたはアーカイブを使用してください。既存の 直接インストールして、codewhale update を実行します。実行可能パスを出力し、 新しいビルドを維持します。インストール ディレクトリが別のビルドによって占有されている場合、 インストール ガイド の新しいディレクトリの移行を使用してください。

npm install -g codewhale

  • アカウントセッションは macOS キーチェーンを読み取らなくなりました。未署名または再構築 codewhale バイナリは毎回新しいキーチェーン ACL プリンシパルであったため、 codewhale web と TUI は起動時にパスワード ダイアログを表示します。セッション 現在、同じストアの ~/.codewhale/secrets/secrets.json (モード 0600) を使用しています プロバイダーキーとして。 #5632 の Keychain-retirement の半分から抜粋。

  • ディスパッチャ側の設定解析を同じ方法で強化しました: ConfigStore ロードとプロジェクト構成の解析により、ConfigToml がデシリアライズされるようになりました。 専用の 16 MiB スタック スレッド (ガイド付きセットアップの保存パスがオーバーフローする可能性がある) TUI の ConfigFile 解析と同じ方法で 2 MiB のワーカー スタック)、および #5585 セットアップ確認トースト テストは、同じサイズのランタイムで実行されます。 デフォルトの libtest スタックをオーバーフローさせる代わりにスレッドを実行します。

  • 親の後にワーカーの使用状況を報告する分離された対話型エージェントを修正しました セッション/ライブ /cost 合計から使用量が欠落した状態でターンが終了する (#5597): インタラクティブターンは所有者スコープのランタイム使用リースを取得します。 遅延使用量は、シールされたセッションを再度開かずにセッション コスト プールに入ります。 メールボックスとワーカー/セッション/リロード アカウンティングは 1 つのハッシュされた応答を共有します ID を使用するため、再試行された配信は 1 回限りになります。

  • サブエージェントの失敗クラスを修正しました: ワークスペース内の絶対 git -C はなくなりました コヒーレントな境界ゲートを使用して読み取り専用の子シェル ゲートをトリップします (#5595)。 ターンエンドパークは、黙ってキャンセルするのではなく、ターン所有の子供たちを再開します それら (#5596)、古い書き込み要求は座標を使用して liveness によって解放されます。 リリース (#5562) であり、検証者の役割の説明は実際のものと一致します 表面 (#5562)。

  • ワークフローの応答スキーマ障害処理を修正 (#5583): 制限付き修復 入力されたレシート (種類 + 試行)、生出力レシートはアーティファクトとして保持される 再ロードしても生き残るため、null 成功ではなく失敗が表面化します (#5528)。 劣化した所有者のスナップショットは、通常の完了した実行として投影されなくなりました (#5582)、型指定されたタスク エラーの種類により、フェイルファスト並列/パイプラインが有効になります (R9)。 /workflow confirm は、メッセージがインターリーブされているにもかかわらず、ドラフトを見つけます。

  • 842k/1M で自動圧縮されなかった DeepSeek セッションを修正しました (#5577): 正確なbilled_842k_on_a_1m_window_compacts_despite_a_small_estimate 回帰はトリガーを固定します。

  • サンドボックスエスケープと権限ギャップを修正: ワークスペース書き込みツールで解決 書き込み前のファイルのハードリンク (S2、#5569)、オプトイン読み取り拒否リスト 任意の状態 (S1、#5568) でフルディスク読み取りを制限し、セッション許可が一致します ツール全体を拡張するのではなく、コマンド ファミリーを拡張します (R2)。

  • プロバイダートランスポートの堅牢性を修正: 非ストリーミング HTTP リクエストは制限されます 読み取りタイムアウト (R4)、およびチャット完了の途中でエラー フレームが表面化することによって ぶら下げる代わりに（R3）。 MCP OAuth の有効期限が、名前付きの 401/403 に反応するようになりました。 壊れたサーバーのように見えるのではなく、回復パスとログインヒントを表示します (T4、 #5572)。

  • フリートのライフサイクルギャップを修正しました: 孤立した労働者は、マネージャーが作業を行うときに刈り取られます 終了し (R7)、タスクごとのウォールクロック タイムアウトが強制されます (R5)。地元の フリート ホストは非 Unix ターゲットでコンパイルします。分離されたスキーマの修復は内部にとどまります 実行時の予算。

  • プロンプト キャッシュの正確性を修正しました。ツール カタログはフィンガープリントされます。 プロバイダー ワイヤー順序 (C1)、リクエスト間でのプレフィックスの変更は常に行われます。 宣言 (C5) — 新たに命名されたミッドターン change:tool_surface を含む 延期されたツールの承認、ツール検索のアクティブ化、およびランタイム MCP の理由 ツールの到着 — そして推論のみの応答は出力制限で停止しました のみ可能なリクエストを再発行するのではなく、正直にターンを失敗します。 停止を再現します。

  • ドキュメント/パブリックサーフェスのドリフトを修正: REBRAND.md は存在しなくなりました 中国フォールバックとしての api.deepseeki.com (#5564)、および Web の事実/ツール カウントはリポジトリと一致します。

  • 大量のプル リクエストは、次の実際の Linux ワークスペース、doctest、および グリーンを報告する代わりに、GitHub アクションでファイル レーンを直接ロックします。 ブランチ固有の CNB ミラーを待機中のプレースホルダー (#5547)。

  • 選択したフリートのフリート名簿メンバーが、目に見える編集アフォーダンスを公開するようになりました。 および直接の m モデルピッカー ショートカット (コーディネーター行はそのまま) 読み取り専用 (#5604、#5589 をカバー)。

  • コンテキストインスペクターは、制限されたツールスキーマのコストを組み込みに帰属させるようになりました。 プロンプトアセンブリを変更せずにカタログと検出された各 MCP サーバーを変更するか、 キャッシュの動作 (#5553)。

  • 目標継続沈黙期間 ([goal] continuation_delay_seconds、 #5508 で追加) がすべてのディスパッチ パスに適用されるようになりました。以前は、 ターン内ディスパッチフックは次の継続プロンプトを即座に起動します 目標がアクティブなままモデル ステップが終了するたびに、CLI-再開し、 ホスト管理のセッションでは、設定された遅延 (測定値) が観察されませんでした。 300 秒の遅延が設定されている場合、エンドツースタートのギャップは約 9 秒です)。今すぐ待機 goal_continuation_message_if_needed内で無条件に実行されます。 キャンセル可能な状態のままであり、一時停止/クリア/端末 update_goal 通話は引き続き可能です 保留中のパスをキャンセルします (#5534)。

  • 2 つの単体テストは、プロセスのグローバル環境の状態に依存しなくなりました。 兄弟テストは同時に変化します。 route_budget::tests::v4_trigger_uses_window_percent_when_it_fits_spendable_input 読み取り中にアサートされたオーバーライドなしの出力バジェット値 CODEWHALE_MAX_OUTPUT_TOKENS / DEEPSEEK_MAX_OUTPUT_TOKENS なし lock_test_env() を保持しているため、同時ライターが値を反転できる ミッドアサーション（順序に依存するフルスイートフレーク）。 prompts::tests::system_prompt_prefix_never_leaks_private_content を読んでください HOME/USERPROFILE経由の実際のホームなので、 ~/.codewhale/instructions.md はその絶対パスをプロンプトに漏洩し、 兄弟の一時的な HOME を除いて、no-private-paths アサーションに失敗しました。 たまたま警備員が生きていた。どちらのテストも env バリアを保持し、 変数 (ルート予算テストではオーバーライドが削除され、プロンプト テストでは HOME/USERPROFILE はスクラッチ ディレクトリにあります)。アサーションは変更されていません。

  • TUI セッションは、明示的にのみ微妙な OSC 12 カーソル アクセントを適用するようになりました。 サポートされている端末と、通常、パニック、 および信号クリーンアップ パス (#5554)。
