ruflo v3.75.0

マイナー 公開日2026年11月10日 出典ruvnet/ruflo 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#ルーフロv3.75.0

このリリースでは、@sparkling と Dream Cycle によって報告された 25 件の問題が修正されています。

修正

  • アトミック書き込みはすべてのバイトを書き込みます (#4888、#4909)。 writeFileAtomic は 1 つの writeSync 呼び出しをチェックするために使用されます。短い書き込みでは、切り詰められたファイルの名前が変更され、それでも成功が報告されました。
  • 失敗したパターン保存が報告されます (#4880、#4913)。 flushToDisk() は、書き込みが失敗した場合に false を返し、パターンを未保存としてマークしたままにして、永続ステータスに lastFlushError を記録します。
  • memory_search_unified (#4876、#4913):
    • どの名前空間が失敗したかを報告します (namespaceErrors)。
    • searchTime は検索にかかった時間を表します。
    • ランキングは変更されずに、一度に最大 4 つの名前空間を検索します。
  • パターン検索 (#4714、#4916)。何も見つからない検索では、degraded: false と単純な「一致なし」が返されます。失敗した読み取りは、空の結果としてではなく、エラーとして報告されるようになりました。
  • aidefence_learn (#4862、#4914)。個人データ (PII) に関するフィードバックは、プロンプト挿入の失敗として記録されなくなりました。 retract: true は、記録されたミスを 1 つだけ削除します。
  • AIDefence CORE-005 (#4715、#4915; @claude-flow/aidefence 3.1.2)。 「…今いるところ」で文が終わる散文。ロール切り替えとしてフラグが立てられなくなりました。偽装フォームは依然として捕らえられています。
  • ツール スキーマには実際の制限が記載されています (#4886、#4892、#4887、#4912):
    • aidefence_scan.input および agentdb_hierarchical-store.value は、UTF-16 コード単位が 10000 に制限されています。
    • hooks_post-task 識別子フィールドに、許可される文字と長さが記載されるようになりました。
  • agent_spawn の正確なモデル ID (#3215、#4917)。 5 つの組み込みエイリアスだけでなく、正確なプロバイダー モデル ID を受け入れます。
  • 設定された埋め込みモデルが使用されます (#2305、#4919)。メモリには.claude-flow/embeddings.jsonと表示されます。すでにベクトルを保持しているストアは、その次元を維持します。
  • 永続状態はプロジェクト ルートに従います (#2633、#4928; @claude-flow/cli-core 3.7.7)。サブディレクトリからコマンドを実行すると、メモリ、オートパイロット、ニューラル、およびメトリクスの状態がプロジェクト ルートに解決されます。
  • クイーンコーディネーター (#4902、#4908; @claude-flow/swarm 3.0.5)。現在では、enableFailover および maxDelegationAttempts が尊重されます。
  • LearningBridge (#4884、#4924; @claude-flow/memory 3.3.0)。統合後にアクセスされた洞察は新しい軌道を開始するため、学習シグナルに貢献し続けます。
  • 生成された AGENTS.md (#3153、#4918)。登録されている MCP ツールのみを指定します。テストではすべてのテンプレートをチェックします。

新しい

  • ruflo start all (#1177、#4918)。必要に応じてプロジェクトの初期化を実行し、次にメモリの初期化を実行し、デーモンが実行されていない場合はデーモンを起動してから、セッションを開始します。
  • ruflo plugins host install|update|uninstall|enable|disable|sync|status (#2854、#4921)。 Claude Code と Codex プラグインを一緒に管理します。シェルを介して実行されることはなく、--dry-run は正確な argv を出力します。
  • デュアル初期化 (#2638、#2640、#4925; @claude-flow/codex 3.0.8):
    • AGENTS.md は共有セクションの単一ソースであり、CLAUDE.md はそれをインポートします。
    • init は、インストールされている ruflo プラグインがすでに提供しているものをスキップします。すべてをコピーするには、--full を渡します。
  • メモリ スコープ (#1227、#4923)。オプションの scope (project、local、user) のメモリ保存、取得、検索、および memory_list_scopes ツール。
  • インベントリ ツール:
    • agentdb_hierarchical-list および agentdb_hierarchical-get (#4712、#4924) は、5,000 エントリ キャッシュ以降を含む永続ストアをページングします。
    • agentdb_pattern-list、agentdb_skill-list、agentdb_skill-get、agentdb_hierarchical-stats (#4707、#4926)。
  • 自動メモリ (#4851、#4852、#4922):
    • フックは、新しいワークツリー内で @claude-flow/memory を単独で検索します。
    • 重複したエントリを持つキーには、一致する ID がリストされるようになりました。
    • 新しい read --all、read-id、dedupe コマンド。 dedupe は、--apply を渡さない限り、プレビューのみを表示します。
  • プラグイン PII トグル (#4861、#4920)。フェデレーション、インテリジェンス、およびコンソールには個別の piiGuard オプションがあるため、機密スクリーニングをオンのままにして個人データの拒否をオフにすることができます。

も含まれています

  • クレーム、フック、および 12 個の v3 プラグインにわたる zod ^4.6.7 (#4904)。
  • 未登録のオプションの依存関係がプラグインから削除されました (#4901)。

この列車でリリースされたパッケージ

@claude-flow/memory 3.3.0、@claude-flow/cli-core 3.7.7、@claude-flow/aidefence 3.1.2、@claude-flow/swarm 3.0.5、@claude-flow/codex 3.0.8、agentdb 3.7.7 (#3175: ネイティブの better-sqlite3 ロード失敗は、緑色の成功行を出力する代わりに警告を表示するようになりました)。
