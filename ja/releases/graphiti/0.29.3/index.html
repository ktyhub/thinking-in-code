graphiti v0.29.3

パッチ 公開日2026年7月27日 出典getzep/graphiti 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#グラフィティv0.29.3

何が変わったのか

  • chore(deps-dev): https://github.com/getzep/graphiti/pull/1561 の @dependabot[bot] により、redis 要件を <8 から <9 に更新します
  • chore(deps-dev): https://github.com/getzep/graphiti/pull/1562 の @dependabot[bot] によって、/mcp_server の Azure-identity 要件を >=1.21.0 から >=1.25.3 に更新します
  • chore(deps-dev): https://github.com/getzep/graphiti/pull/1563 の @dependabot[bot] により、/mcp_server の google-genai 要件を >=1.72.0 から >=2.8.0 に更新します
  • chore(deps): https://github.com/getzep/graphiti/pull/1565 の @dependabot[bot] により、/mcp_server 内のgraphiti-core 要件を >=0.29.1 から >=0.29.2 に更新します
  • chore(deps-dev): https://github.com/getzep/graphiti/pull/1566 の @dependabot[bot] により、/mcp_server の pytest-asyncio 要件を >=1.3.0 から >=1.4.0 に更新します
  • chore(deps): https://github.com/getzep/graphiti/pull/1564 の @dependabot[bot] により、/mcp_server の openai 要件を >=1.91.0 から >=2.41.0 に更新します
  • ci(サーバー): ライブエンドツーエンド回帰テスト + PR チェック (https://github.com/getzep/graphiti/pull/1560 の @danielchalef による)
  • ci: ライブテスト ワークフロー (MCP バックポート + 診断) での exit-5 処理を強化 (https://github.com/getzep/graphiti/pull/1567 の @danielchalef による)
  • 雑用(deps): https://github.com/getzep/graphiti/pull/1599の@danielchalefによるすべてのDependabotセキュリティアラートを修正
  • 修正(docker): procps を削除し、https://github.com/getzep/graphiti/pull/1628 の @irresi によって結合された FalkorDB イメージが trixie 上にビルドされるようにします
  • 修正(docker): https://github.com/getzep/graphiti/pull/1630 で @dpersek によるホスト PATH 補間を回避
  • 修正(falkordb): https://github.com/getzep/graphiti/pull/1590 で @aasc77 によるすべてのトークンがストップワードだった場合のショートサーキット全文クエリ
  • 修正(mcp): https://github.com/getzep/graphiti/pull/1530 の @he-yufeng による FalkorDB URI ユーザー名を保存
  • 修正: https://github.com/getzep/graphiti/pull/1475 の @Maanik23 による FalkorDB フルテキスト検索でのバッククォート トークンと空のクエリの処理
  • fix(falkordb): https://github.com/getzep/graphiti/pull/1670 の @Solaris-star による単一の group_id 検索を一致するグラフにルーティングします。
  • ドキュメント: https://github.com/getzep/graphiti/pull/1665 の @jackaldenryan による README にある Zep 独自のコンテキスト グラフ エンジンに注意してください。
  • ドキュメント: @danielchalef による Cursor Cloud 開発環境のセットアップ手順を https://github.com/getzep/graphiti/pull/1677 に追加
  • https://github.com/getzep/graphiti/pull/1678 の @danielchalef による Claude GitHub アクション ワークフローを無効にします
  • fix(falkordb): ルート名前空間/ops get_by_group_ids は、https://github.com/getzep/graphiti/pull/1675 の @spencer2211 によってグループのグラフを読み取ります
  • 修正 (mcp): https://github.com/getzep/graphiti/pull/1105 の @husniadil によるコンテナーの再起動後に検索が空の結果を返す
  • 修正: https://github.com/getzep/graphiti/pull/1636 の @nandanadileep による Neo4jDriver および FalkorDriver の初期タスク参照のキャプチャ + クローズ時のキャンセル
  • 修正(mcp): https://github.com/getzep/graphiti/pull/1637 の @winklemad によるハードコーディングされた OpenAI の代わりにプロバイダーからクロスエンコーダーを構成
  • fix(communities): https://github.com/getzep/graphiti/pull/1658 の @Saltasm によって再構築されている group_ids に、remove_communities のスコープを設定します。
  • fix(mcp): https://github.com/getzep/graphiti/pull/1619 の @xiaoyaner0201 による汎用構造化出力モードを公開
  • fix(edges): https://github.com/getzep/graphiti/pull/1605 の @ly-wang19 によるエンティティ エッジ読み取りクエリの Reference_time を返す
  • 修正(検索): https://github.com/getzep/graphiti/pull/1653 の @kramerica-inc-dev により、edge_bfs_search で bfs 関係のヒットを直接消費します
  • https://github.com/getzep/graphiti/pull/1681 の @paul-paliychuk によるソケット ファイアウォールの強制を CI とリリースに追加
  • 修正: get_by_node_uuid で関係の方向を保持し、https://github.com/getzep/graphiti/pull/1663 で @6or7 による BFS エッジ検索を保存
  • @prasmussen15 による重複するバックエンド修正を https://github.com/getzep/graphiti/pull/1695 に統合
  • https://github.com/getzep/graphiti/pull/1696 の @prasmussen15 によりグラファイトコアを 0.29.3 にバンプ
