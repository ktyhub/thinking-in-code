#ゴーイーサリアムv1.17.4

<!-- フレキシブルポリマーケーシング (v1.17.4) -->

これはバグ修正と改善が蓄積されたメンテナンス リリースであり、すべてのユーザーに推奨されます。また、今後のアムステルダム ハードフォークの実装作業も継続します。

強調すべき点が 1 つあります。

  • 音部記号は削除されました。 スタンドアロン clef 署名者は https://github.com/ethereum/clef (#35097) に移動しました。

フォークの実装 (アムステルダム)

  • EIP-7928: ブロックレベルのアクセス リスト: ブロック アクセス リストは、eth/71 BAL メッセージのサービス側が実装されて、ブロックの実行中に構築および検証されるようになりました (#34652、#34803、#34879、#34957、#34967、#34972、#34977、#35110)
  • EIP-8189: ブロックレベルのアクセス リストに基づく新しい状態同期プロトコルである snap/2 が追加されました (#34626、#34807、#35098、#35155、#35158、#35163、#35178、#35180、#35181)
  • EIP-8037: 状態生成ガスのコスト増加が実装されました (#33601)
    • トレース システムは、多次元ガス用の新しい OnGasChangeV2 フックを提供します (#34946)
  • engine_newPayloadWithWitnessV5 が追加され、証人形式では正規の仕様フィールド順序が使用されるようになりました (#35009)
  • evm t8n ツールがアムステルダム用に更新され、BAL およびスロット番号のサポートとバイナリ トライ リーフ エクスポートが追加されました (#34843、#35025)
  • EIP-7843 の場合、スロット番号はアムステルダム後の保留ブロックに設定されるようになりました (#34792、#35036)

ゲス

  • キャッシュのサイズは、cgroup メモリ上限 (例: Docker --memory) が設定されている場合に設定されるようになりました (#34947)
  • 多数の小さなコマンドライン フラグとログの問題が修正されました (#33880、#34732、#34943、#34948、#35011、#35104、#35116、#35136)
  • 長い間非推奨となっていた多くのコマンドライン フラグが削除されました (#35021)

RPC

  • eth_baseFee が追加され、次のブロックの基本料金が返されます (#34904、#35023)

  • eth_capabilities が追加され、clients がノードが提供できる履歴データを発見できるようになりました (#33886)

  • トランザクション プールをクリアするための debug_clearTxpool が追加されました (#33347、#35130)

  • 状態読み取りメソッド (eth_getBalance、eth_getCode、eth_getStorageAt など) は、省略された場合、ブロック パラメーターをデフォルトで latest に設定するようになりました (#35100)

  • eth_simulateV1 の修正: 誤った「基本料金が低すぎます」エラー コードと上海出金前の回帰 (#34951、#34939)

  • debug_setHead は、巻き戻しエラーを黙って無視するのではなく、伝播するようになりました (#35001)

  • nil To アドレスを持つ EIP-7702 トランザクションは拒否されるようになりました (#35094)

  • HTTP RPC 応答は常に Content-Length に設定されるようになり、WebSocket ハンドシェイクのステータス コードのバグが修正されました (#35072、#35111)

  • client は、traceparent ヘッダーを介してトレース コンテキストの伝播を構成できるようになり、応答の書き込みがトレースされるようになりました (#35132、#35049)

グラフQL

  • GraphQL リクエストボディが 5 MiB に制限されるようになりました (#35034)
  • begin > 0 および end == 0 を使用したログ範囲クエリが拒否されるようになりました (#35032)
  • Block.raw リゾルバーは、ブロック本体が欠落している場合に空のバイトを返すようになりました (#35027)

コア

  • JUMPDEST ビットマップのグローバル キャッシュにより EVM の実行が高速化 (#34850)
  • EVM スタック操作が適切な場所で計算されるようになり、オペランドごとのコピーが回避されます (#35156)
  • 新しいコードキャッシュのヒット/ミスメーターが追加されました (#34821)
  • スナップショット生成時のシャットダウン競合が修正されました (#33540)

エンジン API とブロブ

  • エンジン API JSON の大きな BLOB ペイロードのエンコードが最適化され、エンジン API では gzip が無効になりました (#33969、#35057)
  • engine_hasBlobs が追加され、engine_getBlobs は実際に利用可能な BLOB のみをカウントするようになりました (#34859、#35028)
  • GetBlobs リクエストのキャッシュにより、エンジン API のレイテンシが短縮され、OTEL トレースが GetBlobs エンドポイントに追加されました (#35124、#35026)
  • 再編成された v0 BLOB サイドカー トランザクションは変換されずに削除されるようになりました (#35099)
  • testing_commitBlockV1 が testing_buildBlockV1 の書き込みコンパニオンとして追加されました (#34995)
  • 同期ステータスに関係なく、新しいペイロードが生成時にインポートされるようになりました (#32673)

ネットワーキング

  • NAT STUN 検出が IPv6 サーバーで失敗しなくなりました (#35084)
  • いくつかのスナップ同期の堅牢性の修正: カバーされていない状態は再開前に削除され、キャッチアップ ストールが修正され、必要な BAL が利用できない場合に同期が再開され、状態のダウンロードが完了するとピボットがフリーズします (#35159)

変更の完全な概要については、Geth 1.17.4 リリース マイルストーンを参照してください。

以前のすべてのリリースと同様に、次のものが見つかります。

  • ダウンロード ページ にあるすべてのプラットフォーム用のビルド済みバイナリ。
  • ethereum/client-go で公開された Docker イメージ (「stable」タグを使用)。
  • Launchpad PPA リポジトリ の Ubuntu パッケージ。
  • Homebrew Tap リポジトリ の macOS パッケージ。
