#ゴーイーサリアムv1.17.3

<!-- 酵素インジェクター (v1.17.3) -->

これは、アムステルダム フォーク実装の継続的な進歩を伴うメンテナンス リリースです。また、現在ネットワーク上で稼働している ETH/70 も紹介されています。

API のトレース (debug_trace*)、特に structLog (opcode) トレーサーに関する重大な変更。次の応答フィールドは、新しく確立された client 全体の仕様 (ethereum/execution-apis#762) に従い、reexec はトレース構成から削除されました。

  • memory: 単語には 0x の接頭辞が付けられ、32 バイトに埋め込まれます。
  • storage: キーと値の先頭には 0x が付きます
  • error: 空の場合は省略されます (以前は "" としてシリアル化されていました)

ゲス

  • blsync のチェックポイント初期化の再試行メカニズムを追加 (#33966)
  • オフラインバイナリツリー変換用のサブコマンドを追加 (#33740)
  • DB エクスポート用のコード エクスポーターを追加 (#34696)

コア

  • アムステルダムフォークの更新:
    • EIP-7928 の前提条件: ブロックレベルのアクセス リスト (#34064、#34644、#34726、#34776、#34799、#33737)
    • EIP-8037 の前提条件: 状態作成ガスのコスト増加 (#34691、#34712、#34841)
    • EIP-7976: コールデータ フロア コストの増加 (#34748)
    • EIP-7981: アクセス リストのコストの増加 (#34755)
    • EIP-7610: ストレージが空でない場合、コントラクトの作成を拒否する (#34718)
    • 状態テストを更新 (#34671)
  • スタックアリーナの実装 (#33960)
  • EIP-7975 の実装: eth/70 部分ブロック受信リスト (#33153)
  • snap/2 プロトコルの前提条件 (#34083、#34649、#34654、#34874)
  • パスモードアーカイブノードに履歴インデックスプルーナーを実装 (#33999)
  • Hoodi 用のプラハ チェーン セグメント プルーニング ポイントを追加 (#34714)
  • ePBS で 32 ブロック以内でヘッドを親に再編成できるようにします (#34767)
  • データが利用できない場合、チェーン セグメント リクエストの処理を停止する (#34787)
  • 無効なボディまたはレシートを送信するピアをドロップする (#34745、#34870)
  • kzg4844セル関連関数を追加 (#34766)
  • 状態データベースのリファクタリング (#33102、#34700、#34763、#34724)
  • バイナリトライの改善 (#34055、#34110、#34670、#34676、#34680、#34690、#34754、#34758、#34777、#34794)
  • すべてのシステム コールの EIP-4762 アクセス イベントをマージする (#34637)
  • パスデータベース内の重複レイヤーを拒否する (#34642)
  • 空の slotNumber を省略し、Amsterdam エンジン以前の API ペイロードのブロック値コレクションを修正しました (#34704)
  • EIP-8024 エラー メッセージにオペランドを含める (#34635)
  • vmodule のダウングレードを修正し、詳細度の変更を派生ロガーに反映します (#33111)
  • インデックス ファイルの切り捨てに関する誤った fsync 順序を修正 (#34728)
  • フリーザー エラー パスでのファイル記述子のリークを修正 (#34735)
  • パスデータベースのサイズ計算を修正 (#34828)
  • BLOB プールのギャップのあるキュー サイズの上限を修正 (#34831)
  • 読み取り専用ロックを使用して txpool の保留中の同時実行性を改善 (#32924)
  • 非推奨の TypeMux をフィードに置き換えます (#32585)
  • 個々のセルプルーフの抽出が失敗した場合でも BLOB の取得を続行 (#34891)
  • ガス計算を高速化するためにコア メッセージで uint256 を使用する (#34934)

ネットワーキング

  • 期限切れのマッチャーを削除する際のタイムアウト ループの早期終了を修正しました (#34743、#34878)
  • 未処理の読み取りエラーの前に検出バッファをコピーすることでデータ競合を防止 (#34888)
  • テーブルミューテックスからnodeFeedを切り離すことで、discover waitForNodesデッドロックを修正しました(#34898)

暗号化

  • nocgo署名検証でハッシュ長を検証する (#33839)

RPC

  • structLog JSON 出力形式を修正し、トレース設定から reexec を削除 (#34093)
  • eth_estimateGas でブロック オーバーライド (gasLimit、blobBaseFee) を適用 (#34081)
  • eth_call のヘッダーにブロック オーバーライドを適用 (#34842)
  • MaxUsedGas を eth_simulate の通話結果に追加 (#34820)
  • トライノード履歴インデックス作成の進行状況を eth_syncing に統合 (#34633)
  • ブロック範囲制限を超えた場合、ログ RPC (eth_getLogs、eth_getFilterLogs、…) から -32602 を返します (#34647)

その他

  • EIP-7702 でクリアされたコードと変更されていないコードを区別するための prestate トレーサーを修正しました (#34675)
  • EIP-7708 ETH バーンイントレーサーのログを出力 (#34623)
  • マルチプレクサトレーサを介して V2 ステートフックを転送する (#34869)
  • client 切断時に WebSocket クローズ フレームを送信 (#33909)
  • RPC フィルターリクエストで空のアドレス/トピックフィールドを省略する (#33884)
  • イベント署名の不一致に対するパッケージレベルのエラーを追加 (#34076、#34868)
  • OTLP トレースエクスポート用に gRPC トランスポートを追加 (#33941)
  • t8n コマンドにシステムコールトレースを追加 (#34862)
  • t8n alloc 出力をストリーミングしてメモリ使用量を削減 (#34785)
  • Linux/arm64 で fsnotify ウォッチャーを有効にする (#34834)
  • FreeBSD ビルドを修正 (#34784)
  • RLPx ping の切断デコードを修正 (#34781)
  • discv5 findnode 結果のハイブ テストを修正 (#34043)
  • 音部記号の開き括弧の切り詰めを修正 (#33702)

変更の完全な概要については、Geth 1.17.3 リリース マイルストーンを参照してください。

以前のすべてのリリースと同様に、次のものが見つかります。

  • ダウンロード ページ にあるすべてのプラットフォーム用の事前構築済みバイナリ。
  • ethereum/client-go で公開された Docker イメージ (「stable」タグを使用)。
  • Launchpad PPA リポジトリ の Ubuntu パッケージ。
  • Homebrew Tap リポジトリ の macOS パッケージ。
