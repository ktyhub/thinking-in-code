#ゴーイーサリアムv1.17.6

<!-- 無機潤滑剤 (v1.17.6) -->

これは、ブロック処理と初期同期のパフォーマンスが多数向上したメンテナンス リリースであり、すべてのユーザーに推奨されます。

強調すべき点がいくつかあります。

  • アムステルダムのハードフォークは、タイムスタンプ 1791294816 (2026 年 10 月 6 日、13:53:36 UTC) にセポリア テストネットでスケジュールされています。 Sepolia ノードのオペレーターは、それまでにアップグレードする必要があります。
  • ネットワークがサポート終了になったため、Holesky テストネットは削除されました。
  • Go 1.24 はサポートされなくなりました。リリース バイナリと Docker イメージは Go 1.27 でビルドされるようになりました。

フォークの実装

  • セポリアのアムステルダム分岐点をスケジュールする (#35734)
  • EIP-7610 実装を削除 (#35581)
  • EIP-2780 および EIP-8038 ガスパラメータを更新 (#35454、#35497)
  • EIP-7997 決定論的工場契約を更新 (#35458)
  • EIP-8037 を更新し、子フレームを吸収した後、最初に未払いのガス負債を返済します (#35633)
  • ブロックレベルのアクセスリストによる並列ブロック実行の実装 (#35264、#35441、#35443、#35459、#35461、#35465、#35575、#35693)
  • EIP-8037 (#35457、#35486) に一致するように、「通常のガス」の名前を「実行ガス」に変更しました。

コア

  • Holesky テストネット (#35591) を削除します。
  • engine_newPayload などの大きなリクエストの JSON デコードを最適化します (#35518)
  • 実行と同時にブルーム構築とルート計算のレシートを処理する (#35738)
  • プリフェッチャー、ブロック処理、マイナー間で共有されるプリコンパイル結果キャッシュを導入 (#35388、#35473、#35526、#35578、#35753)
  • 実行後のコミットでチェーンデータと状態の書き込みを並列化します (#35595)
  • データベースエラーが発生した場合にブロックをシールしない (#35427)
  • REORG がレンダリングされたブロックへのチェーンを短くしたときのログ インデクサーのパニックを修正しました (#35619)
  • EVM レベルのトレース フックの ExecuteConfig.EnableTracer を尊重します (#35512)
  • 従量制 LRU キャッシュ バリアントを追加 (#33719)
  • 不良ブロックと並行してブロックレベルのアクセスリストを保持する (#35423)
  • 各トランザクションの終了時にブロックレベルのアクセスリストの設定を解除する (#35498)
  • BLOB キャッシュの初期化を修正 (#35509)
  • 分岐した尾部グループの下の頭部の切り詰めを修正 (#35551)
  • いくつかの防御操作を追加して BLOB フェッチャーを改善しました (#35572)
  • eth/70 で部分受信を再リクエストする際のデッドロックを修正 (#35537)
  • eth/70 で空の部分受信応答を拒否する (#35593)
  • スパース BLOB プール内のブロックされた BLOB トランザクションの合計サイズを制限する (#35367)
  • eth/72 での Cells/GetCells RLP エンコーディングを修正 (#35428)
  • 回復された BLOB を BLOB プールにキャッシュして、pre-eth/72 ピアの処理を高速化します (#35543)
  • 状態遷移におけるトランザクションタイプのフォーク検証を追加 (#35588)
  • レガシーピアへのスパース BLOB TX のアナウンスを回避する (#35589)
  • eth/71 (EIP-8159) テストを追加 (#35389)
  • ガストレーサーフックとガス測定を修正 (#35646)
  • eth/72 BLOB バッファーは合計 128 MiB、ピアあたり 16 MiB に制限されています (#35766)

同期

  • 応答処理を並列化して状態同期を最適化 (#35533)
  • ブロックレベルのアクセスリストのベストエフォート型ダウンロードを実装 (#35386、#35493)
  • 同期中の本文とレシートの取得のスケジュールを再調整する (#35680)
  • チェーンセグメントのダウンロードとスナップ同期の進行状況に関するメトリクスを追加 (#35678、#35689)
  • スナップ v2 のさまざまな修正と改善 (#35299、#35316、#35463、#35477、#35705、#35722)

ネットワーキング

  • アナウンスされた BLOB トランザクション サイズをアナウンサーのプロトコル バージョンと比較して検証します (#35524)
  • devp2p に discv5 ハイブ カバレッジをさらに追加 (#34770)
  • eth/72 テストとアムステルダム テストデータを devp2p に追加 (#35368、#35637、#35647、#35648、#35687)
  • 単一の UDP ソケットで discv4 と discv5 を提供するために devp2p discovery listen を追加 (#35254)

暗号化

  • KZG リカバリを行わずにデータ セルから直接 BLOB を再構築する (#35528)
  • 完全なデータ セルの高速パスを使用して BLOB の完全なセル セットを回復する (#35529)
  • アップストリームと同期することで bn256 ライブラリの G2.Neg を修正 (#35686)

エンジン API

  • オプションの TargetGasLimit のサポートを追加し、システム コントラクト コード チェックを強制します (#35514)
  • headBlock を finalized まで再編成できるようにしました (#35519)
  • engine_forkchoiceUpdatedWithWitnessV3/V4 のフォークゲートを修正 (#35719)
  • testing_buildBlockV1 に targetGasLimit を渡す (#35501)
  • ハイブの障害を修正 (#35580、#35664)
  • BLOB モード キャッシュ エントリに対して null セルを返す engine_getBlobsV4 を修正 (#35439)

RPC

  • 必須引数の null を拒否する (#35576)
  • メッセージ解析時に JSON オブジェクト キーをエスケープ解除する (#35587)
  • fromBlock の前に toBlock がある eth_getLogs 範囲を拒否する (#35070)
  • eth_config で次のフォークを計算するときに未構成のフォークをスキップする (#35553)
  • pending および eth_getHeaderByNumber 内の解決できないタグに対して null を返します (#35627)
  • eth_simulateV1 でマージ後の難易度オーバーライドを操作なしとして扱う (#35672)
  • to のない BLOB および setcode 呼び出し引数を拒否する (#35695)
  • eth_createAccessList (#35698) の許可に基づくガスガードを取り外します
  • アムステルダム以降の単純な移動見積もりのために実際に使用されたガスを返します (#35592)
  • debug_traceCallのブロックパラメータをオプション化(#35583)
  • slotNumber を GraphQL ブロック スキーマに追加 (#35469)
  • ethclientでブロックトランザクション数がnilの場合、NotFoundを返す(#35605)
  • ethclient のヘッダー ルートに対して引き出しリストを検証する (#35610)

ゲスとツール

  • 状態サイザーツールを非推奨にする (#35520)
  • abigen v2 バインディングのカスタム エラーにはオリジナルの Solidity 名を使用する (#35332)
  • イベント サブスクリプション ストリームを終了するのではなく、イベント サブスクリプション ストリームから予期しないログをフィルターで除外します (#35701)
  • 構造体ロガー OnEnter/OnExit フックで設定されたログ制限を尊重します (#35360)
  • 欠落しているロンドンの基本料金設定に対する t8n テストを追加 (#35636)

ビルドする

  • Go 1.24 のサポートを削除し、Go 1.27 のサポートを追加 (#35573)
  • -dlgo ブートストラップ Go バージョンを 1.27.1 (#35656) にアップグレードします。
  • Fedora COPR 用の RPM パッケージをビルドする (#35557)
  • パッケージアップロードの再試行メカニズムを追加 (#35510)

変更の完全な概要については、Geth 1.17.6 リリース マイルストーンを参照してください。

以前のすべてのリリースと同様に、次のものが見つかります。

  • [ダウンロード ページ] (https://geth.ethereum.org/downloads/) のすべてのプラットフォーム用の事前構築済みバイナリ
  • ethereum/client-go で公開された Docker イメージ (「stable」タグを使用)
  • Launchpad PPA リポジトリ の Ubuntu パッケージ
  • Homebrew Tap リポジトリ の macOS パッケージ
