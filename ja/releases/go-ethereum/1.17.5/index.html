#ゴーイーサリアムv1.17.5

<!-- 重力トルク パッド (v1.17.5) -->

これはバグ修正と改善が蓄積されたメンテナンス リリースであり、すべてのユーザーに推奨されます。今後のアムステルダム ハードフォークの実装作業を継続します。

強調すべき点がいくつかあります。

  • デフォルトの GOGC が 20 から 50 に変更され、より高いメモリ ピークと引き換えに GC オーバーヘッドが削減されました。古い動作を維持するには、--gogc=20 を設定します。
  • Pebble v2 がキー/値ストア バックエンドとしてサポートされるようになりました。 Pebble v2 は、Geth が最初からブートストラップされる場合に使用され、既存のデータベースの場合は Pebble v1 にフォールバックします。 geth db pebble-upgrade を実行して、従来の Pebble v1 データベースを v2 に明示的にアップグレードします。

フォークの実装

  • いくつかのアムステルダム EIP が実装または更新されました。
    • EIP-2780: リソースベースの固有トランザクション ガス (#35212、#35318)
    • EIP-8037: 状態作成ガスのコスト増加 (#35173、#35318、#35301、#35342、#35279)
    • EIP-8038: 国家アクセスガスコストの更新 (#35216)
    • EIP-8246: SELFDESTRUCT バーンを削除 (#35219)
    • EIP-8282: ビルダー実行リクエスト (#35175、#35341)
    • EIP-7997: 決定論的な工場契約 (#35223、#35285)
    • EIP-7954: 最大コントラクト サイズを増やす (#35217)
    • EIP-7928: ブロックレベルのアクセス リスト (#35260、#35281、#35261、#35348、#35279)
  • アムステルダムフォークテストのカバレッジを改善 (#35364)
  • --override.amsterdam フラグの導入 (#35213)
  • BPO スケジュールから名前付きハードフォークを削除 (#35029)
  • チェーン構成にボゴタ フォークを導入 (#34057)

コア

  • スパース BLOB プールを導入して BLOB トランザクション プールのメモリ使用量を削減する (#34047)
  • 起動時に従来の BLOBPOOL リンボ エントリを新しいセルベースのサイドカー形式に移行する (#35209)
  • blobpool での v0 blob サイドカーのサポートを削除 (#35191)
  • パフォーマンスの低下を修正するためのインラインガス控除 (#35203)
  • 誤ってピアを切断する eth/71 ブロックアクセスリストの空のマーカーのデコードを修正 (#35286)
  • ピボット ブロックがコミットされたらスナップ同期モードを無効にする (#35402、#35405)
  • debug_setHead を高速化し、回復不可能なターゲットを拒否する (#35252)
  • 正規ハッシュ マッピングが欠落しているブロックのバックフィルに失敗するスナップ同期を修正しました (#35190)
  • ペイロード構築時にチェーンの JUMPDEST キャッシュを再利用 (#35378)
  • データベース バックエンドとして Pebble v2 をサポート (#34009)
  • 元号ストアでの .ere ファイルのサポート (#34978)
  • trie.UpdateBatch API (#32448) の紹介
  • クリーンでないシャットダウン後に新しく追加された空のテーブルでのフリーザー切り捨てエラーを修正しました (#35258)
  • 同期ステータスを考慮して状態回復可能性レポートを改善しました (#35400)
  • 存在しないアカウントに対するアカウントのプリフェッチを修正 (#35256)
  • スナップ v2 のさまざまな修正 (#35321、#35323)
  • ブロック検証の最適化 (#35403)
  • さまざまな割り当ての改善 (#35234、#35237、#35232)
  • バイナリトライ開発を継続する (#34772)
  • TX サイズ計算を修正 (#35406)

ネットワーキング

  • トランザクションに含まれる統計に基づいて、価値の高いピアをランダムなドロップから保護する (#34702)
  • 無効なノードや到達不能なノードを DNS 検出ツリーから遠ざける (#35312)
  • devp2p でデュアルスタック検出リスナーをサポートし、関連するいくつかの修正 (#35220、#35298、#35243、#35206)

RPC

  • HTTP リクエスト本文の最大サイズを設定するための --rpc.http-body-limit フラグを導入しました (#35224)
  • authorizationList と組み合わせると gasPrice を拒否 (#35320)
  • 数値もハッシュも含まないブロックパラメータを拒否する (#35271)
  • 大文字と小文字を区別せずに認証スキームを照合する (#35022)

トレース

  • 構造体ロガーで設定されたログ制限を尊重する (#35349)
  • EIP-2780 方式でトレース フレームを出力する (#35396)
  • ERC-7562 トレーサー出力にログ インデックスを含めます (#35200)
  • ログ トレーサーでの callcode 転送の誤ったキャプチャを停止 (#35248)

エンジン API

  • TargetGasLimit をエンジン API 経由で通過 (#35372)
  • 最大 REORG 深さを構成可能にします (#35335、#35373、#35391)
  • engine_getPayloadBodiesV2 からブロック アクセス リストを返す (#35347)
  • マイナー設定の MaxBlobsPerBlock をプロトコル制限に制限する (#35295)

ゲスとツール

  • --gogc フラグを導入し、デフォルトの GOGC を 50 に引き上げます (#35363、#34851)
  • geth export でのブロックレベルのアクセス リストの書き込み (#35369)
  • = を含むメトリクス タグ値を保持する (#35168)
  • うなぎのテストを v20.0.0 に更新 (#35283)

アカウントと ABI

  • BLOB の料金上限を外部署名者に転送する (#35167)
  • abigen v2 で生成されたコントラクト バインディングに GetABI() メソッドを導入 (#35221)
  • ライブラリの依存関係のデプロイメントを処理するために abigen v1 バインディングを修正しました (#32164)

ビルドする

  • ckzg 依存関係を更新 (#35336)
  • -dlgo ブートストラップ Go バージョンを 1.25.12 (#35317) にアップグレードします。

変更の完全な概要については、Geth 1.17.5 リリース マイルストーンを参照してください。

以前のすべてのリリースと同様に、次のものが見つかります。

  • [ダウンロード ページ] (https://geth.ethereum.org/downloads/) のすべてのプラットフォーム用の事前構築済みバイナリ
  • ethereum/client-go で公開された Docker イメージ (「stable」タグを使用)
  • Launchpad PPA リポジトリ の Ubuntu パッケージ
  • Homebrew Tap リポジトリ の macOS パッケージ
