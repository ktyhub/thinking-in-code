OCRmyPDF v17.13.0

OCRmyPDF v17.13.0

変更点

  • Ghostscript (「投機的」変換) を使用せずに作成された PDF/A が検証されるようになりました。 veraPDF の代わりに pikepdf の PDF/A サポート (pikepdf.pdfa) を使用し、 最終出力は、メタデータと最適化の手順の後に再度検証されます。 veraPDF は使用されなくなったため、Ghostscript フリーのパスが利用可能になりました veraPDF がインストールされているかどうか (Docker イメージを含む)。ファイル バリデーターは以前のように Ghostscript への移動を承認しません。 -v1で実行 その理由を見てみましょう。
  • 投機的変換で PDF/A-1b がサポートされ、一般的な問題が修正されました 以前は常にファイルを Ghostscript に送信していました。他の出力を置き換えます。 sRGB を使用したインテント、画像補間フラグを削除し、印刷フラグをオンに設定します。 注釈、PDF/A-1 に必要な /CIDSet の追加、および XMP プロパティの削除 PDF/A では許可されていない非表示の注釈。
  • 新しいオプション --pdfa-backend {auto,ghostscript,internal} (API: pdfa_backend=)。デフォルトの auto は、OCRmyPDF 独自の変換を試み、 次にゴーストスクリプト。 internal は Ghostscript を使用しないため、JPEG はパススルーします。 変化なし。結果が承認されない場合、pdfa 出力タイプは失敗し、 終了コード 10 および --output-type auto は通常の PDF を出力します。 ghostscript 常に Ghostscript を使用します。 Ghostscript のみが実装するオプション (--pdfa-image-compression、--ghostscript-jpeg-quality、 --ghostscript-jpeg-maxdpi、--color-conversion-strategy、CMYK、 Gray または UseDeviceIndependentColor)、auto の下の Ghostscript を選択します。 と は internal のエラーです。
  • OCRmyPDF には pikepdf[pdfa] 10.15 以降が必要になりました。 pdfa エクストラ jsonschema、referencing、fonttools を導入し、すべてパッケージ化されています。 Debian と Red Hat。
  • --force-ocr はハイパーリンクを保持し、リンクの注釈を ラスタライズされたページ。 --deskew と --clean-final も同様です。新しいモード --mode force-ocr-no-links は古い動作を維持します。 {issue}605
  • Ghostscript が埋め込まれていないフォントを置き換える場合、常に使用されるようになりました。 独自のフォント (-dNONATIVEFONTMAP) を使用するため、出力はすべてのフォントで同じになります。 プラットフォーム。 macOS では、ネイティブ フォント ルックアップにより数十メガバイトの システムフォント。 OCRmyPDF は、標準の 14 以外のフォントが使用されている場合に警告します。 代替された場合、または代替が太字または斜体のスタイルを失った場合。 {issue}1369
  • タイムゾーンのない作成日は現地時間とみなされ、 出力の日付はそのゾーンを取得し、警告が表示されます。 TZ を設定して別のものを選択します ゾーン。
  • デフォルト モードでは、すでにテキストが含まれているページで OCRmyPDF が停止するようになりました。 前のページを OCR した後ではなく、最初のスキャンの直後 それ。エラーはページに名前を付けます。 {issue}613
  • 出力ファイルのチェックが大幅に高速化されます。各ストリームは 完全にデコードする代わりに圧縮するための最も安価な方法。 プログレスバーが表示されます。 JPEG 2000 および CCITT 画像もチェックされるようになりましたが、 切り詰められずに破損した JPEG は検出されなくなりました。 {issue}1570
  • OCRmyPDF には PyInstaller フックが同梱されるようになり、それを使用するアプリをバンドルできるようになりました 追加のオプションなしで。 Tesseract と Ghostscript は引き続きインストールする必要があります。 {issue}1024
  • 新しい PageInfo.has_visible_text。 OCR層。 has_textは変更ありません。

修正

  • すでにラスタライズされた非表示の OCR レイヤーを持つスキャン上の --force-ocr テキストが表示されているかのように、400 dpi 以上で表示されます。 ファイルサイズを倍増します。 {issue}961
  • プロセス ワーカー (Windows および macOS の use_threads=False) がすべてのサーバーで失敗しました 'OcrOptions' object has no attribute 'tesseract'のページ。 {issue}1757
  • ocrmypdf.ocr() は、次のようなしきい値処理方法名を拒否しました。 tesseract_thresholding='adaptive-otsu'。 {issue}1460
  • --rotate-pages --tesseract-timeout 0 はページの向きを検出しましたが、検出しませんでした ページを回転させます。クックブックでは、この組み合わせをローテーションに推奨しています。 または OCR を使用しないデスキュー。 {issue}778
  • --output-type auto および --force-ocr では、出力には PDF/A というラベルが付けられました。 veraPDF が有効であったときに、検証または PDF/A 宣言が行われていなかった Docker の画像のように、取り付けられていません。 {issue}1751
  • Ghostscript の PDF/A 変換により、ほとんどのハイパーリンク ( フラグを印刷します)。 PDF/A では許可されていない非表示の注釈が追加されました。 Ghostscript が実行される前に削除され、投機的と同じ警告が表示されます。 黙って変換するのではなく、変換します。 {issue}605
  • /ToUnicode を含まないフォントのテキスト。閲覧者はグリフを通じて抽出します。 Ghostscript が PDF/A を作成するときに、名前が文字化けするか失われます。 {issue}1297
  • dc:contributor など、同等のドキュメント情報を持たない XMP メタデータ および dc:subject は、Ghostscript が PDF/A を作成したときに失われました。それは今です 多言語のすべての言語を含む、値全体をコピーします。 財産。 {issue}1220
  • iText および pdftk の PDF 内の画像が Flate なしで再圧縮されました。 予測子により、出力が約 30% 増加します。 {issue}1620
  • 縦書き日本語およびその他の縦書きまたは回転した OCR 行からコピーされたテキスト 偽のスペースや文字の順序が乱れていました。 {issue}1244
  • グリフレスフォールバックフォントで設定されたテキスト。フォントがインストールされていない場合に使用されます。 スクリプト (CJK など)、選択またはコピー時に失われた文字をカバーします。 Chrome およびその他の pdfium ベースのビューア。
  • 異なる解像度のフルページ画像で構成されるページは、次の解像度でラスタライズされました。 最高解像度ではなく加重平均解像度。 {issue}948
  • ドキュメント言語 (/Lang) が Tesseract の言語コードに設定されていませんでした deu、fra、cesなど。 2 文字コードのない言語は、 彼らの 3 文字のコード。 {issue}1749
  • コンテンツ ストリームに不正な数値が含まれる一部の LaTeX PDF。 0.000-50131235、OCRmyPDFを停止しました。現在、視聴者として警告し続けています する。 {issue}1054
  • 実数として格納された /Rotate、または数値以外の cm 演算子 オペランドにより、ページ スキャンがクラッシュしました。
  • --force-ocr --ocr-engine none は画像のないページでクラッシュしました。
  • OCRmyPDF 自身の PDF/A が最終チェックに失敗した場合、Ghostscript フォールバック FileExistsError で失敗する可能性があります。 Windows では常にそうなっていました。
  • デフォルトの--output-type autoで、大きくなったファイルの説明 ここでは PDF/A 変換を指します。 {issue}1369
  • Ghostscript 10.08 の無題ファイルのタイトル 'Untitled' (引用符付き) 再び削除されました。
  • Docker イメージの Web サービスは、Streamlit スクリプトを見つけることができませんでした。の Web サービスの Docker ドキュメントが更新されました。 {issue}1753
  • Docker ウォッチャーは、指定された deskew をオフにしなくなりました。 OCR_DESKEW が設定されていない場合は、OCR_JSON_SETTINGS。
