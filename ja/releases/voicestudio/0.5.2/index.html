VoiceStudio v0.5.2

#ボイススタジオv0.5.2

ハイライト

  • Supertonic-3 と PocketTTS はライセンスの [同意する] ボタンを再度表示し、有効にできるようになります (#2017)
  • プラットフォーム上で実行できないエンジンは、インストールするよう指示するのではなく、その旨を表示します (#2018)
  • MOSS-TTS-v1.5、Confucius4-TTS、dots.tts、Supertonic-3、PocketTTS が 1 つの click にインストールされ、それぞれ独自の環境にインストールされるため、エンジンを切り替えたり戻したりしても動作中のエンジンが壊れることはありません (#2015、#2016)
  • 保存されているがまだ適用されていない発音エントリは、一致しないように見えるのではなく、そのように表示されます (#1949)
  • ベア 500 レポートではバックエンド エラー クラスに名前が付けられるようになり、無関係な 2 つの障害が同じ問題を報告することがなくなりました (#1773)
  • 拒否された吹き替えソース言語には、拒否されたコードに名前が付けられるようになりました (#1960)
  • 初回実行のインストール ログは、セットアップ画面とともに消えるのではなく、ディスク上に保持されます (#1847)
  • bun run desktop は、起動を拒否するのではなく、アプリ自体が実行されたままになっているバックエンドからポート 3900 を再利用します (#1974)
  • 別のアプリが既に所有しているディクテーション ショートカットが、黙って何もしないのではなく、そのように表示されるようになりました (#1858)
  • Windows での終了は、次回の起動時にクラッシュとして報告されなくなりました (#1898)
  • システム全体を変更せずに静寂を保つために、設定の「モーションを減らす」スイッチ (#1857)
  • 明るいテーマとシステム オートは、暗いままではなく、ライト モード OS に従うようになりました (#1973) — CoDe-ReDz に感謝します。
  • 1 文字の入力から生成すると、畳み込みエラーを引用するのではなく、入力が短すぎると表示されるようになりました (#1826)
  • 最初の実行では、インストール後ではなく、インストール前にテキスト サイズについて尋ねられます (#1849)
  • 参照なしのクローン作成 clip では、設定できないライブラリ パラメータに名前を付ける代わりに、そのように表示されるようになりました (#1879)
  • RTX 50 シリーズ カードのトーチをアップグレードすると、起動時のクラッシュが別の起動時にクラッシュすることがなくなり、アップグレードが文書化されます (#1931)
  • 生成タイムアウトは、環境変数ではなく設定のコンピューティング時間バジェットを指すようになりました (#1808)
  • インストールされていないエンジンは、チェックの失敗を報告する代わりに、その旨を表示するようになりました (#1866)
  • アクセシビリティ プロンプトは、許可するまで初回実行セットアップや他のすべてのアプリに表示されなくなりました (#1845、#1886)
  • 最後のオンボーディング ステップでは、何もインストールされていない場合に 3 回失敗する代わりに、Speech-to-Text モデルをインストールすることを提案します (#1856)
  • フォルダーがマウント ポイントの背後にあるためにダウンロードが失敗する Windows ではその旨が表示され、どこに移動するか (#1957)
  • 空きメモリが不足しているだけの GPU は、ドライバーを再インストールするように指示されなくなりました (#1812) — michaelhuamanflores に感謝します!
  • ブラウザ拡張機能によってスローされたエラーは、Chromium (#1901) だけでなく、Safari と macOS アプリでもフィルタリングされます。Chang-Jin-Lee に感謝します。
  • 中国ミラーを選択すると、依存関係の各ステップでネットワークが再競合することがなくなり、ブロックされた接続で 1 ステップあたり数秒かかることになります (#1892) — yuezheng2006 に感謝します。
  • バックエンド ログ パネルは、静かに表示する代わりに、読み取れないログを報告します (#1847) — Chang-Jin-Lee に感謝します。
  • フローティングディクテーションバブルにより、一時停止、再開、停止、閉じる、および複数行プレビューが追加されます (#1952)
  • 転写はモデルの準備状況をチェックし、インライン ダウンロードとショートカット ヒントを提供します (#1952)
  • Transcriptions の欠落モデル プロンプトには、精度と遅延、言語、サイズごとにすべてのディクテーション モデルがリストされるため、適合するモデルをインストールするか、すでにディスク上にあるモデルに切り替えることができます (#1952)
  • [エンジン] メニューの [文字起こし] タブで、Sherpa-ONNX のディクテーション モデルが選択され、その選択によって Sherpa 文字起こしも行われるようになりました (#1952)
  • ステージが接続されていない失敗は、別のステージのアドバイスを借用しなくなり、テキスト読み上げエラーがビデオ サーバーがダウンロードをドロップしたことを通知しなくなりました (#1943)
  • アプリが分類できない生成エラーにはバックエンド エラー クラスが付けられるようになり、無関係な 2 つのエラーが同じ優先順位付け不可能なレポートとして到着しなくなります (#1800)
  • 文字起こしディクテーションはデスクトップ レコーダーを起動し、コンテキストに応じた開始アクションを 1 つ提示し、マイク アイコンをラベルの中央に配置します (#1902)
  • Colab の文字起こしとダビングには、明示的な ASR モデルのセットアップ ステップ (#1922) が含まれるようになりました — nidhi-singh02 に感謝します!
  • Apple Silicon は、自動衝突防止サイドカー ランタイムを維持しながら、エンジン ピッカーに標準的な OmniVoice の選択肢を 1 つ表示するようになりました (#1913)
  • ホストされたランナーの標準アカウントで現在のユーザーの Windows インストーラーを検証する (#1883)
  • モデルのダウンロードは、ゼロから再開するのではなく、不安定な接続でも存続します (#1940)
  • bun run dev はタスク マネージャーを要求する代わりに Windows で回復します (#1941)
  • デスクトップ アプリがビルドされ、新しいクローンから再び開きます (#1818) — flutterkage2k に感謝します!
  • エンジンが必要とする VRAM よりも少ない VRAM を搭載した GPU は、CPU が取得する計算時間の半分の予算を取得できなくなりました (#1806) — VishvakR に感謝します!
  • ギャラリーの音声プレビューが再び再生されます — 品質ガードが良好なレンダリングをサイレントとして拒否していました (#1819) — flutterkage2k に感謝します!
  • チルダで区切られた数値範囲は、エンドポイントを一緒に実行しなくても明確に読み上げられます (#1821) — flutterkage2k に感謝します!
  • 音声モードでは、スクロール フォームの下に [合成] と [変換] が固定されたテーマ タブを使用します (#1823)
  • 現在のユーザーの Windows インストーラーの検証とネストされたリソースのクリーンアップを修正 (#1873)
  • 現在のユーザーの Windows インストーラーを構築する際に、生成されたフロントエンド アセットを利用可能な状態に保ちます (#1881)
  • 音声クローン作成は、アップロードか録音かの明確な選択から開始され、必要な場合にのみ録音と参照の詳細が表示され、プロダクション オーバーライドの下でサンプリング制御が維持されるようになりました (#1817)
  • 初回実行のウェルカム ラインは、OmniVoice および VoiceDesign エンジン (#1861) で受け入れられる命令を使用しています — psiberfunk に感謝します。
  • audio.cpp が、Breeze-TTS-2 のオプトイン CPU バックエンドとしてエンジン ラインナップに加わりました (英語 + 中国語、クローン + 音声デザイン、明示的なモデル カタログのインストール、Python venv なし) (#1891)
  • audio.cpp は、インストールされたネイティブ CUDA、HIP、Metal、および Vulkan プロバイダーを使用し、リモート ワーカー間のデバイス ルーティングを保持します (#1926)
  • 推定および測定されたモデル、依存関係、キャッシュ、および一時ディスクのコストをエンジン カタログに表示します (#1718)
  • リリース後の自動バージョン バンプが無効になっている場合でも、プレビュー ビルドは安定版よりも新しいままになるようになりました (#1762)
  • CosyVoice セットアップ ガイダンスは、エンジンを利用可能にするランタイムからダウンロードされたモデル ファイルを分離するようになりました (#1761)
  • MCP ツールは、ファイルを返し、ベースパス限定のファイル入力を受け入れることで、エージェントのコンテキストから音声を遮断できるようになりました (#1760) — agudmund に感謝します。
  • 入力時にダブラインが聞こえます — 編集済みセグメント (#1769) のオプトイン ライブ プレビュー ストリーム TTS — ありがとう、mvanhorn!
  • Studio に Convert メソッドが追加されました: 保存した音声の 1 つで clip を再発話、音声変換、完全ローカル (#1765) — ありがとう、mvanhorn!
  • Hardsub ビデオのエクスポートにオプトインのカラオケ単語ハイライト キャプション スタイルが追加されました (#1764) — mvanhorn に感謝します!
  • バッチ キューでフォルダーを視聴できるようになりました。フォルダーにドロップされた新しいビデオは自動的にダビングされます (#1768) — ありがとう、mvanhorn!
  • オーディオブック プレーヤーに章のテキストが表示され、ナレーションされている単語が強調表示されるようになりました (#1766) — ありがとう、mvanhorn!
  • 吹き替えエディターがキャスティング ボードを獲得: ボイス チップをスピーカーにドラッグし、ドロップダウンは同期を保ちます (#1767) — ありがとう、mvanhorn!

変更されました

  • 更新されたプラグイン (ダイアログ、アップデーター、ログ、オープナー、ポジショナー、単一インスタンス) を備えた Tauri 2.11.5、React 19.3、TanStack Query 5.102、lucide 1.43、posthog-js 1.428、および現在のマイナーの npm ワークスペースの残りの部分。 jsdom 30、jest-dom 7、同時 10、taze 21 (#1952)
  • eslint は src-tauri/ を無視するため、ローカルの Tauri ビルドは生成されたアセットからの解析エラーで lint:hooks を溢れさせなくなりました (#1952)
  • キャストでは、レスポンシブな SVG 音声カードと、周囲のパネルの上に表示される検索可能なスピーカー メニューを使用します (#1823)
  • ダビングにより出力設定が調整され、レビューのステータスが前倒しされ、トランスクリプトと用語集の編集が簡素化されます。 Launchpad ファイルと音声がレスポンシブ グリッドにリフローされる (#1823)
  • トランスクリプト セグメントは、テキスト、タイミング/ステータス、および音声コントロール用に 3 つの読み取り可能な行を使用し、折り返しに適応する高さを備えています (#1823)
  • click がまだシークしている間、波形をドラッグすると水平にパンし、時間指定されたトランスクリプトを整列させます (#1823)
  • 一括セグメント編集では、検索可能な音声と言語のメニュー、判読可能な言語名、応答性の高い選択ツールバーを使用します (#1823)
  • ダビングはビデオ上に再生コントロールをオーバーレイし、波形とトランスクリプトをコンパクトなタイムラインに結合し、ヘッダー/アクションの背景の塗りつぶしを削除します (#1823)
  • ダビングでは、編集のための余地を残すために、応答性の高い行を備えたコンパクトなキャスト、翻訳、出力コントロールを使用します (#1823)
  • エクスポートでは、グループ化された形式設定、テーマ別のトラック メニューとスイッチを使用し、固定されたファイル名の概要とダウンロード アクションを使用します (#1823)
  • ダビング出力設定では、アイコンラベルのスイッチ、テーマ別のトラックとスピーカーのメニュー、およびより明確なタイミング/転写コントロールを使用します (#1823)
  • キャスト音声メニューでは、ネイティブ ドロップダウンの代わりに SVG プリセット アイコンを使用した検索可能なテーマ オプションを使用します (#1823)
  • 読みやすいラベル、SVG アイコン、検索可能なメニュー、コンパクトなタイムライン間隔を備えたダビング グループのキャストおよび翻訳コントロール (#1823)
  • プロダクション オーバーライドでは、読み取り可能なアイコン ラベルのコントロールとアクセス可能なノイズ除去/ポストプロセス スイッチを使用します (#1823)
  • 拡張されたナビゲーションでは、微妙な静的な波のグラデーションを持つテーマのアクセントの色合いを使用します (#1823)
  • グループのソースオーディオ、ターゲットボイス、タイミングオプションをより明確なコントロールに変換します。デザインの選択肢には、テーマに合わせた SVG アイコンが含まれます (#1823)
  • 展開可能なサイドバーには、アクティブ状態が制限されたワークスペース ラベルが表示されます。言語メニューが広い画面上の複数の列に適応する (#1823)
  • 音声デザインと録音では、より明確な間隔とラベルを備えた、テーマに沿ったキーボードからアクセス可能なセレクターを使用します (#1823)
  • 音声タブとアップロード/録音コントロールには微妙な SVG モーションがあります。テキストが clipboard ペーストを追加し、アップロード領域が利用可能な高さを埋めます (#1823)
  • タイトル バーのラベルは、アクティブな音声、文字起こし、および LLM エンジンを循環します。バンドルされたモデルのラベルには正しく OmniVoice と表示されています (#1823)
  • トップバーのエンジンパネルは、コンパクトなメモリコントロールと重複ピッカーなしで、音声、文字起こし、LLM の選択肢をタブにグループ化します (#1823)
  • 音声デザインの簡素化: 12 行のきめの細かいブロックが 5 フィールドのエディターで 1 つの概要行に折りたたまれ、英語のアクセントと中国語の方言が 1 つのフィールドにマージされ、開始点のチップにはオーバーフロー トグルで 5 が表示されるようになりました (#1793)

追加

  • オーディオブックの結果は、同期された歌詞プレーヤーになりました。チャプター テキストは、現在の単語がハイライト表示され、click-to-seek で再生に続き、カラオケ スタイルの均等分割でレンダリング自体のチャプターの長さからタイミングを計られます — ASR パスなし、完全にローカル (#1766) — mvanhorn に感謝します!
  • ダブ CAST ストリップは、プロジェクト レベルのキャスティング ボードに拡張されます。音声チップ (クローン プロファイル、デザイン プリセット、デフォルト) をスピーカーの行にドラッグします。またはキーボードのリストボックスから選択して、既存のドロップダウン (#1767) と同じスピーカーごとのキャスト フィールドを書き込みます。mvanhorn に感謝します。
  • Studio の新しい Convert メソッドは、ドロップまたは録音された clip を、オプションのソース長マッチング (#1765) を使用して、既存の音声プロファイルの音声に変換します。mvanhorn に感謝します。
  • バッチ キューで監視フォルダーをオプトイン: ディレクトリを一度選択すると、新しいビデオが最後のキューに追加の設定で自動的にキューに入れられ、一時停止/停止制御とコピー中保護が行われます — ファイルはバイトとしてアップロードされ、パスはアプリから離れることはありません (#1768) — mvanhorn に感謝します!
  • Hardsub エクスポートでカラオケの単語ハイライト キャプションを書き込むことができるようになりました: オプトインカラオケ コントロールは、古いジョブと翻訳されたトラックの均等分割フォールバック、さらに GET /dub/ass/{job_id} サイドカー (#1764) を使用して、文字起こし時に保持されたタイミングからワードタイミングの ASS スイープをレンダリングします。mvanhorn に感謝します。
  • Windows リリースには、昇格なしでインストールおよびアンインストールできる、独立して更新可能なユーザーごとの MSI が含まれるようになりました (#1713)
  • 翻訳された行を編集しながら、ダブ セグメントでライブ TTS をストリーミングできるようになりました — オプトイン トグル、既存の /ws/tts ソケット、共有生成アドミッション、エクスポートは引き続きフル品質でレンダリングされます (#1769) — mvanhorn に感謝します!
  • エンジンのステータスと診断バンドルは、ロードされた実行プロバイダー、デバイス、精度、フォールバック ステージ、アクセラレータ ID、ランタイム バージョン、および親プロセス メモリの可視性を記録するようになりました (#1717)

修正済み

  • One-click エンジンのインストールは VoiceStudio 独自の PyTorch ピンを継承しなくなり、MOSS-TTS-v1.5 と Confucius4 をインストールできなくなりました (#2024)
  • 翻訳エンジンをアンインストールしても、VoiceStudio または別のエンジンがまだ必要とするパッケージは削除されなくなりました (#2019)

  • ディクテーション キャプチャは、Webview リスナーがアンマウントまたはリロードされるたびにネイティブ イベントを誰にも発行するのではなく、キューに入れるようになりました (#1707)
  • デスクトップに含まれるバックエンドは、古いポート 3900 プロセスとして存続するのではなく、所有するアプリが消滅すると終了するようになりました (#1707)
