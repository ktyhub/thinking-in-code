VoiceStudio v0.5.4

パッチ 公開日2026年9月21日 出典debpalash/VoiceStudio 英語原文

#VoiceStudiov0.5.4

動作するエンジン、よりスムーズな長文オーディオ、便利なローカル統合。 CosyVoice はランタイムを修復し、新しい Transformers で音声コンテキストを保持します。ストーリーとオーディオブックでは、よりクリーンなオーディオ結合、より優れたスクリプト制御、より信頼性の高い EPUB インポートが実現します。 Electron のセットアップと診断により、ダウンロードしたモデルや既存のプロジェクトを破棄することなく、障害から簡単に回復できます。

ダウンロード

|プラットフォーム |インストーラー | | --- | --- | | Windows x64 | インストーラー | | macOS Appleシリコン | DMG | | macOS インテル | DMG | | Linux x64 | AppImage · デブ |

すでに Electron を使用していますか?既存のアプリを上書きインストールしてデータを保持します。プロンプトが表示されたら、[ローカル ランタイムのインストール] を選択して依存関係を更新します。タウリからの移動ですか？アプリを閉じた状態でデータ ディレクトリをバックアップし、Electron をインストールして、Tauri を削除する前に音声とプロジェクトを確認します。 移行ガイドに従ってください。 Tauri v0.5.3 は、Tauri の最終リリースのままです。そのアップデーターは Electron をインストールできません。

ハイライト

  • ダウンロードしたモデルを削除せずに CosyVoice 生成といくつかのエンジン インストール パスを修復します (#2258、#2240、#2243)
  • よりクリーンなストーリーとオーディオブックの結合、スクリプト コントロール、EPUB インポート (#2259、#2216、#2203、#2228)
  • ローカルの n8n 音声ワークフローをエクスポートし、MCP を介してクロード コードまたはカーソルを構成します (#2261、#2257)
  • より信頼性の高い Electron セットアップ、ディクテーション、実用的なクラッシュ レポート (#2221、#2245、#2123、#2262)
  • 吹き替えと字幕のインポートを通じてダイアログ、タイミング、背景音声を保存 (#2222、#2224、#2242)

変更されました

  • メインのサイドバー (ナビゲーション、音声ライブラリ、ステータス) は、別のパネルに交換されるのではなく、設定上の所定の位置に残ります。設定セクションはその横の列に配置されるようになりました (#2209) — @jaketame に感謝します!
  • メイン ナビゲーションはサイドバー ヘッダーの直下、音声ライブラリの上に配置されるため、ライブラリの高さに合わせて移動しなくなりました (#2210) — @jaketame に感謝します。

追加

  • クロード コードとカーソルの統合ページでは、現在のバックエンドの MCP セットアップが提供され、重複したカタログ ルートが統合されます (#2257)

  • [設定] → [外観] → [サイドバーを展開したままにする]: プロジェクト、Transcribe、ツール、または別のワークスペースが狭いウィンドウで独自のパネルを開いたときに、サイドバーがレールに合わせて縮小するのを停止します (#2211) — @jaketame に感謝します。

  • ストーリーとオーディオブック: スクリプトのクリア ボタンは、一度に 1 つのゴミ箱アイコンではなく、確認済みの 1 ステップでスクリプト全体 (インポートまたは入力されたすべての行と章) を空にします。キャストは維持されます (#2203) — @jaketame に感謝します!

  • ストーリーの貼り付けと分割は、文、段落 (新しいデフォルト)、または章全体ごとに分割できるようになりました。そのため、1 人のナレーターが文ごとに 1 テイクに分割されることがなくなりました (#2217) — @jaketame に感謝します!

  • CosyVoice は、欠落しているランタイム依存関係を修復し、新しい Transformers (#2096) で音声コンテキストを保持します — @martinezpl に感謝します!

  • Electron ネイティブ クラッシュ レポートは、障害のあるスレッドを長いスタックや拡張リストの背後に失わずに保持します (#2262)

  • Electron セットアップは、明示的なオーバーライドとローカルホストの除外を維持しながら、Windows プロキシ アドレスを正規化します (#2114)

  • Web API 参照リカバリでは、選択されたバックエンドと資格情報が保持されます。 AudioSeal の埋め込みと検出により、エクスポートされたオーディオのサイズを変更せずにモデルのサンプル レートが正規化されます (#2252) — @joseedson18jc に感謝します!

  • LM Studio ディスカバリーは選択されたモデルを尊重し、ディクテーション改良ではサポートされていない推論オプションを処理しながらリテラル テキストが保持されます (#2252) — @joseedson18jc に感謝します!

  • CosyVoice は、CUDA を使用せずに一致する float32 の重みと入力を使用し、CUDA の精度を維持しながらワーカー スレッドの dtype エラーを防止します (#2096)

  • Source Electron の起動は、起動タイムアウト内で依存関係をダウンロードする代わりに、準備された Python ランタイムを再利用します (#2184)

  • クローン、ストーリー、オーディオブックは、宣言された言語リストを持つエンジンでサポートされていない出力言語の選択を無効にします (#2104)
