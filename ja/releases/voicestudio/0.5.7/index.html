#ボイススタジオv0.5.7

最初にお詫びを申し上げます。 このリリースには予定よりも大幅に時間がかかりました。家族の緊急の用事があり、しばらく私を遠ざけていました。お待たせしたことと、その間解決されなかった問題について申し訳ありませんでした。しばらくお待ちいただき、また、ご報告、修正、温かいお言葉をいただきましてありがとうございます。

Shimul Debnath (velixio) をコア チームにようこそ。 Shimul は現在、VoiceStudio の保守 (プル リクエストのレビュー、問題のトリアージ、リリースの継続) を支援しています。そのため、プロジェクトはもはや 1 人で待つ必要はありません。

VoiceStudio は携帯電話および GPU のない PC 上で実行できるようになり、アプリ全体がより穏やかになりました。 プレビュー iOS および Android アプリは携帯電話自体でモデルを実行し、GPU のないコンピューターには小型 CPU の PyTorch ビルドが搭載され、サイドバー、モデル、吹き替え、ストーリー、およびワークフローのページは、より少ない、より明確なコントロールを中心に再設計されました。

このリリースでは、オプトイン ベータ アップデート チャネル、テイクのボトム プレーヤー、正直な Radeon レポートを備えた GPU アクセラレーション パネルと Ask VoiceStudio Agent が追加され、さらにクローン作成、ダビング、オーディオブック、ダウンロード、ディクテーションに対する数百もの修正が加えられています。

アップグレード: 既存の Electron アプリを上書きインストールします。音声、プロジェクト、設定は保持されます。セットアップで尋ねられたら、[ローカル ランタイムのインストール] を選択して依存関係を更新します。

  • リモート コンピューティング デバイス、リモート ワーカー、GPU 共有は VoiceStudio Pro に移行され、オープンソース アプリには含まれなくなりました。保存されたプロジェクト、ボイス、設定は影響を受けません (#2748)
  • デフォルトの OmniVoice モデルを含む、明白な商用ライセンスのないモデルは、モデル カタログで一度ライセンスに同意するよう求められます。それまでは、API およびそれらを使用する MCP リクエストはライセンス エラーを返します (#2689)
  • Docker、API キーまたはセッションを使用しない、ホスト名による LAN またはリバース プロキシ アクセスには、OMNIVOICE_ALLOWED_HOSTS にその名前が必要です。 IP アドレス localhost、*.ts.net、host.docker.internal は以前と同様に機能します。
  • 独自のネットワーク上のサーバーからの URL インポートには OMNIVOICE_ALLOW_PRIVATE_URL_IMPORTS=1 が必要です。
  • これらの変数を設定する場所: デスクトップ アプリの場合は ~/.config/omnivoice/env (macOS、Linux) または %USERPROFILE%\.config\omnivoice\env (Windows) の行、Docker の場合は -e。

Tauri からの移行: Tauri を削除する前に、アプリを閉じ、データ ディレクトリをバックアップし、Electron をインストールし、音声とプロジェクトを確認します。 移行ガイドに従ってください。 Tauri v0.5.3 は、Tauri の最終リリースのままです。そのアップデーターは Electron をインストールできません。

インストーラー trust: macOS インストーラーは署名されています。 Windows インストーラはまだコード署名されていないため、SmartScreen が警告する場合があります。上記の インストーラー署名 の表は、各プラットフォームの結果を示しています。 インストールガイドを参照してください。
