#トランスフォーマーv5.18.0

新しいモデルの追加

Nemotron 3 ダイアライゼーション

<img width="1680" height="900" alt="image" src="https://github.com/user-attachments/assets/fe735cb3-9e5b-43ad-8f60-9dec8425aec7" />

Nemotron 3 Diarization は、現実世界のオーディオで「誰がいつ話したか」を特定するために設計された、オープンウェイトのストリーミング スピーカー ダイアライゼーション モデルです。ストリーミングとオフライン推論の両方をサポートし、最大 8 つのスピーカーを処理し、各スピーカーが入力オーディオに最初に到着するまでにスピーカー出力を順序付けします。

このモデルは、Arrival-Order Speaker Cache (AOSC) 1 と、Streaming Sortformer 1、2 に導入された FIFO キューを使用します。単一のチェックポイントは、80 ミリ秒の入力バッファから 30.4 のオフライン スタイル バッファまでの設定可能な遅延プロファイルと、10 ミリ秒の倍数で設定可能な出力フレーム解像度をサポートします。チャンク推論では、音声の最大継続時間は制限されません。

NemotronH オムニ

NemotronH Omni は、NemotronH ハイブリッドを組み合わせた NVIDIA のマルチモーダル推論モデルです。 RADIO ビジョン エンコーダーとオプションの Parakeet ベースのサウンド エンコーダーを備えた Mamba-Transformer 言語モデル。 画像 (およびビデオ) パッチは、RADIO タワーとピクセル シャッフル MLP を通じて言語モデルに投影されます。 <image> / <video> コンテキスト トークンの位置にスペースを埋め込みます。オーディオ clips は、同じ方法で投影されます。 <audio> の位置。その結果、テキスト、画像、ビデオ、およびデータを統合して推論する単一の自己回帰モデルが得られます。 音。

HyperCLOVAX ビジョン V2

HyperCLOVAX Vision V2 は、NAVER によって開発されたマルチモーダル ビジョン言語モデルです。 HyperClovaX 言語モデル バックボーンと Qwen2.5-VL ビジョン エンコーダーを組み合わせています。このモデルはテキスト、画像、ビデオ入力をサポートしており、組み込みの思考トークン (<think>...</think>) を介して思考連鎖推論が可能です。

GTE

GTE は、mGTE: Generalized Long-Context Text Representation and Reranking Models for Multilingual Text Retrieval で、Xin Zhang、Yanzhao Zhang、Dingkun Long、Wen Xie、Ziqi Dai、Jialong Tang、Huan Lin、Baosong Yang、Pengjun Xie、Fei Huang、Meishan Zhang、Wenjie Li、Min Zhang によって提案されました。

GTE は BERT スタイルの双方向エンコーダで、絶対位置埋め込みを RoPE に置き換え、ゲート MLP を使用し、各残りの接続の後に層正規化を適用します。同じアーキテクチャが、Alibaba の gte-*-v1.5、gte-multilingual-*、gte-en-mlm-* チェックポイントと、Snowflake の snowflake-arctic-embed-m-v2.0 をサポートしています。
