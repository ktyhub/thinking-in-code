browser-use 0.13.8

ブラウザ用 0.13.8

何が変わったのか

  • Cerebras モデル ID と https://github.com/browser-use/browser-use/pull/5323 の @ryanl-cerebras によるデフォルトを更新
  • https://github.com/browser-use/browser-use/pull/5330 の @ElayGelbart によってモデルがその呼び出しをテキストとしてシリアル化するときに、Anthropic ツールの引数を回復します
  • ドキュメント: https://github.com/browser-use/browser-use/pull/5332 の @Hardik180704 による壊れたプロファイル同期リンクを置き換えます
  • 修正(エージェント): https://github.com/browser-use/browser-use/pull/5103 の @itxaiohanglover による空のアクション リストに対して last_action() をガード
  • 修正 (エージェント): https://github.com/browser-use/browser-use/pull/5107 の @itxaiohanglover による ZeroDivisionError に対する _inject_budget_warning のガード
  • 修正（ブラウザ）：https://github.com/browser-use/browser-use/pull/5114 で @itxaiohanglover によって一時ディレクトリを作成するときに validate_user_data_dir からパスを返す
  • https://github.com/browser-use/browser-use/pull/5309 の @Ghraven によるエージェント ファイルの書き込みには UTF-8 を使用します
  • fix(dom): https://github.com/browser-use/browser-use/pull/5175 の @Diwak4r による末尾の改行の最終チャンク char_end を len(content) にクランプします。
  • 修正 (レジストリ): https://github.com/browser-use/browser-use/pull/5204 の @abhay-codes07 による空の URL でのドメイン制限されたアクションを公開しない
  • fix(agent): https://github.com/browser-use/browser-use/pull/5205 の @abhay-codes07 により、各 MessageManager に独自の状態 (変更可能なデフォルト引数) を与える
  • fix(dom): https://github.com/browser-use/browser-use/pull/5104 の @itxaiohanglover による stackingContexts アクセス タイプの不一致を修正
  • 修正: @Karunasagar12 による文書化された LLM チャット モデルを https://github.com/browser-use/browser-use/pull/5182 でエクスポート
  • https://github.com/browser-use/browser-use/pull/5089 の @Gaurav0807 による Element.click() エラー処理の変数シャドウイングを修正
  • 修正 (ダウンロード): https://github.com/browser-use/browser-use/pull/5264 の @sergioperezcheco によるリモート ブラウザー ダウンロードの完全なコールバックを起動する
  • fix(llm): https://github.com/browser-use/browser-use/pull/5240 の @VenkateswarluNagineni による Groq ツール呼び出しモデルのツール呼び出しから構造化出力を読み取る
  • https://github.com/browser-use/browser-use/pull/5233 の @chuenchen309 による空のresponse.content リストの ChatAnthropicBedrock.ainvoke() IndexError を修正
  • 修正（非同期）: https://github.com/browser-use/browser-use/pull/5285 の @GautamSharma99 によるタスク コールバック エラーの再発生を回避
  • 修正 (ブラウザ): https://github.com/browser-use/browser-use/pull/5262 で @ayaangazali によってメモリ内辞書として渡されたときに storage_state Cookie を適用する
  • 修正 (ツール): https://github.com/browser-use/browser-use/pull/5318 の @LHMQ878 による SearchGoogleAction の逆互換エイリアスを復元
  • https://github.com/browser-use/browser-use/pull/5231 の @chuenchen309 により、明示的な x=0/y=0 をビューポートの中心にサイレントにリダイレクトする Mouse.scroll() を修正しました。
  • DOMTreeSerializer がペイント オーダーで遮蔽されたテキストを LLM にリークする問題を修正 (https://github.com/browser-use/browser-use/pull/5225 の @chuenchen309 により)
  • fix(mcp): https://github.com/browser-use/browser-use/pull/5246 の @ayaangazali による readOnlyHint アノテーションで読み取り専用 MCP ツールをマークする
  • 修正(mcp): https://github.com/browser-use/browser-use/pull/5235 の @chuenchen309 による失敗した ActionResult として CallToolResult.isError を表示
  • 修正 (エージェント): https://github.com/browser-use/browser-use/pull/5105 の @itxaiohanglover によるリソース リークを防ぐために、GIF 作成後に PIL 画像を閉じます
  • 修正: 座標 click に例外の詳細を含め、https://github.com/browser-use/browser-use/pull/5379 に @shotsan による欠落しているエラー ログを追加
  • ドキュメント: https://github.com/browser-use/browser-use/pull/5388 の @Alezander9 による Cloud v4 を使用したオープンソースとクラウドのプロットを更新します
  • ドキュメント: https://github.com/browser-use/browser-use/pull/5394 の @Alezander9 による README でホストされたエージェント API コールを表示します。
  • fix(utils): https://github.com/browser-use/browser-use/pull/5211 の @santhreal による redact_sensitive_string カスケード破損を防止
  • https://github.com/browser-use/browser-use/pull/5326 の @sauravpanda による aiohttp および pypdf セキュリティ ピンのバンプ
  • 修正 (エージェント): https://github.com/browser-use/browser-use/pull/5401 で @wesleyzhangwq によるゼロ メッセージ圧縮しきい値を尊重する
  • fix(mcp): https://github.com/browser-use/browser-use/pull/5448 の @scemii による非推奨の Bedrock Claude モデル識別子を更新
  • ドキュメント: @MagMueller による README デモ ビデオ (https://github.com/browser-use/browser-use/pull/5463) をトリミング
  • ドキュメント: https://github.com/browser-use/browser-use/pull/5464 で @MagMueller によるソーシャル ビデオ プレビューを復元する
  • feat(llm): デフォルトの ChatBrowserUse で bu-2-0-mini-preview by @sauravpanda (https://github.com/browser-use/browser-use/pull/5465)
  • 修正 (deps): https://github.com/browser-use/browser-use/pull/5477 の @MagMueller によるリッチ 14.3.3 で OpenHands のブロックを解除
  • 功績: @MagMueller によるファーストパーティの OpenClaw スキル サポートを https://github.com/browser-use/browser-use/pull/5476 に追加
  • 0.13.8 とブラウザ ハーネス 0.1.9 を @gregpr07 により https://github.com/browser-use/browser-use/pull/5481 でリリース
