ブラウザ用 0.13.11

このリリースには、browser_use.integrations.toolsets_for_claude で入手可能なクロード用のブラウザ使用ツールセットが含まれています。統合には、anthropic.tools.browser を含む Anthropic SDK リリースが必要です。現在公開されている Anthropic SDK にはまだ含まれていません。

ドキュメント: https://docs.browser-use.com/open-source/customize/integrations/toolsets-for-claude

PyPI の公開は保護されたリリース ワークフローを通じて実行され、個別のレビュー担当者の承認が必要です。

何が変わったのか

  • 雑務: https://github.com/browser-use/browser-use/pull/5669 の @MagMueller によるワークフロー ツールチェーンの公開をピン留めする
  • ファイルシステム: write_file は、https://github.com/browser-use/browser-use/pull/5280 の @MagMueller によるアップロード フロー用の小さなバイナリ イメージ (png/gif/jpg/webp) を作成できます
  • 修正 (エージェント): https://github.com/browser-use/browser-use/pull/5662 の @Mohil-Ahuja により、保存された履歴のリスト境界の下にネストされた機密データを編集します
  • 修正（人為的）: https://github.com/browser-use/browser-use/pull/5636 の @leilei3167 によるデータ URL スキームとメディア タイプの大文字と小文字を区別せずに処理
  • fix(llm): https://github.com/browser-use/browser-use/pull/5664 の @Mohil-Ahuja による Gemini リクエストでのシステム メッセージのドロップを停止
  • 修正 (llm): https://github.com/browser-use/browser-use/pull/5673 の @nina-mir による廃止された Mistral pixtral-large エイリアスを再マップします
  • 修正 (aws): https://github.com/browser-use/browser-use/pull/5676 の @VedanthB による Bedrock 画像 URL のクエリ文字列をサポート
  • fix(dom): https://github.com/browser-use/browser-use/pull/5640 の @y4ho0 により、大文字と小文字を区別せずに隠しコード スタイルと一致します。
