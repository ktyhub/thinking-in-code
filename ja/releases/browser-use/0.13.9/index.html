ブラウザ用 0.13.9

何が変わったのか

  • 修正 (llm): bu-2-0 を ChatBrowserUse のデフォルトに戻し、https://github.com/browser-use/browser-use/pull/5488 で @sauravpanda によるミニ オプトインを維持します
  • ci: https://github.com/browser-use/browser-use/pull/5491 の @sauravpanda によるデッドなcloud_evalsイメージビルドトリガーを削除
  • 修正(ファイルシステム): https://github.com/browser-use/browser-use/pull/5498 の @uczltw6 による replace_file でターゲット テキストが欠落していることを報告
  • 修正 (ファイルシステム): https://github.com/browser-use/browser-use/pull/5502 の @primorLee によって生成された PDF 内のプレーン テキストをエスケープする
  • ドキュメント: https://github.com/browser-use/browser-use/pull/5551 の @MagMueller による再実行可能なクラウド スクリプトのハイライト
  • ドキュメント (クラウド): https://github.com/browser-use/browser-use/pull/5553 の @MagMueller による CLI 3.0 の更新ツール ガイド
  • 修正 (deps): https://github.com/browser-use/browser-use/pull/5382 の @sauravpanda による依存関係のバージョンをバンプする
  • 修正: https://github.com/browser-use/browser-use/pull/5563 の @DipsyHou により DeepSeek のデフォルト モデルを deepseek-v4-flash に更新
  • 修正(llm): https://github.com/browser-use/browser-use/pull/5561 の @official-burak による Ollama オプション内にフォーマット/ストリームを入れるのをやめました
  • fix(deps): https://github.com/browser-use/browser-use/pull/5526 の @green3sf により脆弱な Click、MCP、pypdf ピンを更新
  • 修正（ブラウザ）: https://github.com/browser-use/browser-use/pull/5562 の @MrLeit によるネットワークではなく、ストレージ ドメイン経由で Cookie をクリアします
  • 修正 (ファイルシステム): PDF エクスポートでのマークダウン強調のレンダリング (https://github.com/browser-use/browser-use/pull/5540 の @leilei3167 による)
  • fix(llm): https://github.com/browser-use/browser-use/pull/5545 の @ECD5A による空の推論モデル パターンを無視する
  • fix(dom): https://github.com/browser-use/browser-use/pull/5541 の @UniversePeak による clickable 要素の画像コンテキストを公開
  • ビルド: https://github.com/browser-use/browser-use/pull/5507 の @MagMueller によるブラウザ ハーネス 0.1.10 が必要です
  • 修正 (レジストリ): https://github.com/browser-use/browser-use/pull/5570 の @LambIessz によるタプル パラメータ内の機密プレースホルダーを置き換えます。
  • https://github.com/browser-use/browser-use/pull/5373 の @Soundcreates による再接続ウィンドウ中の WebSocket ドロップを修正
  • ドキュメント (クラウド): https://github.com/browser-use/browser-use/pull/5578 の @MagMueller により、廃止された V1 API の例を V4 に置き換えます。
  • https://github.com/browser-use/browser-use/pull/5588 の @sauravpanda により datamodel-code-generator を 0.75.1 にアップグレード
  • 修正: https://github.com/browser-use/browser-use/pull/5576 で @aniketwaghh によってタスク テキストから抽出された URL の末尾括弧のバランスを保つ
  • ドキュメント: https://github.com/browser-use/browser-use/pull/5583 の @MagMueller によるリモート ブラウザ スキルを CLI 3.0 に移行
  • 修正: https://github.com/browser-use/browser-use/pull/5577 で @MagMueller による pydantic 2.13 を許可
  • ドキュメント: https://github.com/browser-use/browser-use/pull/5602 の @MagMueller による正しいクラウド サインアップ クレジット
  • 修正 (ブラウザ): https://github.com/browser-use/browser-use/pull/5475 の @jiffyaneesh による BrowserProfile (#5420) の BROWSER_USE_HEADLESS を尊重します
  • 修正 (llm/google): https://github.com/browser-use/browser-use/pull/5597 で @aniketwaghh によって include_system_in_user が設定されている場合、最初のユーザー メッセージを保持する
  • ドキュメント: https://github.com/browser-use/browser-use/pull/5601 の @MagMueller による正しいクラウド ブラウザ セッション価格
  • ドキュメント (クラウド): @MagMueller による API v4 スキル リファレンスを https://github.com/browser-use/browser-use/pull/5591 に追加
  • fix(llm): https://github.com/browser-use/browser-use/pull/5605 の @MagMueller によるスキーマ キーワード フィールド名を保持
  • 修正(llm): https://github.com/browser-use/browser-use/pull/5348 の @cosin2077 による Anthropic Bedrock の max_retries をゼロに保つ
  • 修正 (エージェント): https://github.com/browser-use/browser-use/pull/5493 の @JayLay0310 による URL 否定を単語全体として照合
  • 修正 (エージェント): https://github.com/browser-use/browser-use/pull/5453 の @oysz によってダウンロードされたファイル パスの順序を保持する
  • 修正 (ブラウザ): https://github.com/browser-use/browser-use/pull/5359 の @r266-tech により、永続ストレージ状態を UTF-8 として読み取る
  • 修正（ブラウザ）: https://github.com/browser-use/browser-use/pull/5621 の @MagMueller によるデフォルトの Chrome 引数の順序を保持
  • https://github.com/browser-use/browser-use/pull/5451 の @XiaoHuo888-hue により OrcaRouter を名前付き LLM プロバイダーとして追加します
  • fix(openrouter): client と https://github.com/browser-use/browser-use/pull/5599 の @MagMueller による応答入力を検証します
  • https://github.com/browser-use/browser-use/pull/5650 の @MagMueller によってエージェントへの事前入力入力のライブ値を表示します
  • 修正 (ツール): https://github.com/browser-use/browser-use/pull/5500 の @Faseeh06 によるサイレント成功ではなく、失敗したタブ切り替えをエラーとして報告する
  • 修正（ブラウザ）: https://github.com/browser-use/browser-use/pull/5582 の @IENVYshanks による send_keys のリテラル プラスをサポート
  • 修正 (dom): https://github.com/browser-use/browser-use/pull/5586 の @r266-tech による clickable 画像の画像コンテキストを直接公開
  • 修正: https://github.com/browser-use/browser-use/pull/4599 の @octo-patch により、_wait_for_cdp_url の早期にブラウザー プロセス終了を検出
  • 修正 (ブラウザ): https://github.com/browser-use/browser-use/pull/5230 で @lisa0314 によってイベント バスがリセットされた後にセッション ハンドラーを復元
  • 雑用: https://github.com/browser-use/browser-use/pull/5666 の @MagMueller によるブラウザ ハーネス 0.1.12 を備えた 0.13.9 のリリース
