ブラウザ用 1.0.0

<img src="https://github.com/browser-use/browser-use/releases/download/1.0.0/browser-use-1.0-vs-0.x-bench.png" alt="ブラウザ使用 1.0 vs 0.x: スコアが高く、安く、速く、コードが 80% 少ない" width="100%">

−136,866 行。ライブラリの 80% が削除されました。

最初からやり直しました。エージェントは、Chrome DevTools プロトコル上で 1 つの永続 REPL に Python を直接書き込むようになりました。 DOM シリアライザーもアクション スキーマも、その間に何もありません。シンプルさが勝り、最先端の Web エージェント になりました。

  ● task
  │
  ● model writes a cell          new_tab(url); bu.click(41); js(...)
  │
  ● REPL runs it on Chrome (CDP) → output back to the model
  │
  ✓ finish(result)

同じモデル: 最大 33 ポイント高く、2.7 は 5.2 倍安く、2 ～ 3 倍高速です。

uv add 'browser-use==1.0.0'
export BROWSER_USE_API_KEY=bu_...    # cloud.browser-use.com/new-api-key

from browser_use import Agent

print(Agent('Find the number of stars of the browser-use repo').run_sync().final_result())

==でピン留めします。こちらから迅速に発送いたします。

デフォルトでの変更点

| | 0.x | 1.0 | |---|---|---| |モデル (llm=None) |必須 |ブラウザ上の bu-fast ゲートウェイを使用する | |ブラウザ (Browser()) |ローカルクロム |ブラウザ クラウドブラウザを使用します。ローカルの場合は Browser('chromium') | |キー |プロバイダーごとに 1 つ | 1 つのブラウザ使用キー (BROWSER_USE_API_KEY または browser-use login) | |モード | | bu-fast / bu-ultrafast の ultrafast (アクセシビリティ ツリー ID)。 mode='default' はオプトアウトします | | run() 制限 | max_steps=500 | max_steps=100、timeout=1700 |

独自のモデル: ChatOpenAI、ChatAnthropic、ChatGoogle、または任意の Pydantic AI モデル文字列 (llm='groq:llama-3.3-70b-versatile')。

0.x からのアップグレード

まず MIGRATING.md を読んでください。すべての 0.x オプションとその 1.0 の答えがリストされています。

  • オプション 1.0 が受け入れられない場合、ブラウザが起動する前、または何かが請求される前に、そのオプションに名前を付ける TypeError が発生します。サイレントノーオペレーションはありません。 0.x チューニング ノブ 1.0 は (use_vision=True、flash_mode、max_failures など) の警告を 1 回だけ表示しても無視されます。
  • 削除されたすべての 0.x インポート (0.1 から 0.13 までのすべてのモジュール パス、および保持されているモジュール 1.0 のすべてのパブリック名) は、置き換えに名前を付けて MIGRATING.md をリンクする ImportError を生成します。 except ImportError フォールバックは引き続き機能します。
  • ActionResult(include_in_memory=...) は警告しますが無視されます。すべてのツールの結果は会話に残ります。
  • 構成チェックに合格すると、run() は発生しません。拒否されたキーまたはモデル、起動に失敗したブラウザ (cloud create 402/5xx/timeout)、および実行内部のエラーはすべて status='error' と result.error を返し、起動したブラウザは停止されます。キーが欠落していても、何かが作成される前に発生します。

確認すべき動作の変更点

  • Browser()はクラウドブラウザです。ローカルホストまたはプライベート IP 上のタスクには Browser('chromium') が必要です (警告の 1 つにはそう書かれています)。
  • Browser(local=True) は Browser('chromium') を意味します。あなたが開いている Chrome は Browser('chrome') です。
  • Browser('chrome') は、ライブ DevToolsActivePort が自分のプロファイル ディレクトリにあるブラウザにのみ接続されます。 127.0.0.1:9222 の回答には関連付けられなくなりました。
  • run(max_steps=...) のデフォルトは 100 (以前は 500) です。 1 ステップが 1 つのモデル リクエストです。
  • エージェントが評決を下さなかった場合、is_successful() は None になります。 0.x のデフォルトには r.is_done() and r.success is not False を使用します。
  • errors() は、実行を終了したエラーのみを返します。回復されたセル エラーは result.messages にあります。 ・result.partialはcheckpoint(..., partial=True)のみ設定となります。これを取得するには、タスク内のフラグに次の名前を付けます。「各ページの後で、チェックポイントを使用してタイトルを保存します('titles.json', タイトル、partial=True)」。
  • result.cost_usd は、クラウド ブラウザーやそのプロキシではなく、モデル料金と Web 検索料金をカバーします。
  • ワークスペース (デフォルト: 新しい一時ディレクトリ browser-use-*) は実行後も保持されます。 workspace= パスは指定されたとおりに使用される (絶対パスになり、シンボリックリンクは解決されない) ため、result.downloads[0].relative_to(workspace) は機能します。
  • prohibited_domains=['example.com'] はそのサブドメインもブロックします。ドメイン ルールを設定すると、すべての file: URL がブロックされます。 BROWSER_USE_ALLOWED_DOMAINS は読み込まれません: Browser() は設定されている間発生します。
  • 0.x ゲートウェイ モデル (bu-2-0、bu-1-0、bu-latest など) は拒否されます。 BROWSER_USE_LLM_URL は読み取れません。ChatBrowserUse(base_url=...) を使用してください。
  • LangChain チャット モデルは TypeError を発生させます。 Azure は AZURE_OPENAI_API_KEY (AZURE_OPENAI_KEY ではない) を読み取り、OPENAI_API_VERSION を必要とします。
  • browser-use --mcp は非推奨通知を出力し、--cli-mcp ツール (browser_exec、browser_screenshot、browser_login) を提供します。 browser-use initを取り外しました。
  • bu および browser コンソール スクリプトはなくなりました (他のツールと並んで uv tool install が壊れました)。 browser-use または browseruse を使用してください。
  • 追加の aws、oci、video、examples、eval、core、openai-tools、cli-oci がなくなりました (pip は警告を出し、それらなしでインストールされます)。 anthropic、google、mcp、cli、all は引き続き解決されます。 Anthropic、Google、MCP は中心的な依存関係です。

こちらも新作

  • 入力結果: Agent(task, output_model_schema=MyModel)、次に result.structured_output。
  • ローカルおよびクラウド ブラウザでの アップロードとダウンロード: workspace= からの入力、workspace/downloads および result.downloads でのダウンロード。エージェントは、指定したファイルをアップロードしますが、作成したり上書きしたりすることはありません。
  • 秘密: sensitive_data= は type_secret() で入力され、セル出力、チェックポイント、ツールの結果、結果から編集されました。サンドボックスではありません。 MIGRATING.md の trust モデルを参照してください。
  • ドメイン制限 (allowed_domains、prohibited_domains、block_ip_addresses) と 0.x パターン (すべてのブラウザ モード)。
  • Web 検索 (web_search=True)、ブラウザ使用キーへの検索ごとに請求され、ZZPH100​​ZZ に追加されます。
  • CLI および MCP: browser-use は Python をブラウザ ハーネスにパイプします。 browser-use --cli-mcp は MCP サーバーを実行します。 browser-use skill installはエージェントスキルを登録します。
  • Docker: browseruse/browseruse:1.0.0 および ghcr.io/browser-use/browser-use:1.0.0。すべてのイメージ ビルドは、CI の amd64 および arm64 でスモーク テストされ、プル リクエストでもテストされます。

信頼性

  • ストリーミングされた応答。 すべての OpenAI Response リクエスト (ブラウザ使用ゲートウェイおよび api.openai.com) がストリーミングされます。ストリーミングされたターンは最初のイベントまでに 300 秒かかり、その後イベントが流れるまで実行され、最大 930 秒かかります。 bu-smart の長いターンが 300 秒で終了しなくなりました。
  • 一時的な再試行が 1 回。 HTTP 200 内で報告される障害 (server_error、overloaded、request_timeout、upstream_stream_failed)、または 429 や 5xx など、最終イベントが実行ごとに 1 回再試行される前に終了するストリーム。
  • 圧縮。 コンテキスト ウィンドウ上の応答リクエストは一度圧縮され、再度送信されます。ウィンドウが小さいモデル (gpt-4o、128k) は、オーバーフローする前に圧縮されます。ストリームされた圧縮アイテムは、非ストリーム応答がそれを運ぶのとまったく同じように送り返され、それに 400 が付けられると、アイテムなしでリクエストが 1 回再送信されます。
  • 1 つのプロセス内の多数のエージェント。 Agent は、ソフト オープン ファイルの下限を min(hard limit, 10240) に引き上げます (macOS のデフォルトは 256)。接続エラーは、その原因を特定するようになりました。 ModelConnectionError: Connection error. (OSError: [Errno 24] Too many open files)。
  • プロキシされた gpt-6-luna. ChatOpenAI('gpt-6-luna', base_url=...) は任意のホスト上で reasoning_effort='none' を取得するため、ツールはプロキシの背後で動作します。
  • ワーカーを含むページ。 wait_for_network_idle() は、Web ワーカー スクリプトとクロスサイト iframe を待機しなくなり、10 秒の上限まで実行されました。
  • ダイアログ beforeunload プロンプトで保持されるナビゲーション、または JS ダイアログが開いているスクリーンショットでは、数秒以内にダイアログに名前が付けられます。
  • keep_alive. ブラウザ デーモンが停止した後の実行は、about:blank ではなくエージェントのタブで続行されます。

ベンチマーク

BU ベンチ v2、60 タスク x 3 担当者、クラウド ブラウザー、2026 年 11 月 9 日。

|エージェント |スコア [95% CI] | $/タスク | s/タスク | |---|---|---|---| |ブラウザ使用 1.0 (mode='ultrafast'、bu-fast が使用するモード) | 62.5 [58.3、66.5] | 0.070 | 650 | |ブラウザ Pi (e7007f2) を使用、同じウィンドウ | 56.3 [50.2、62.4] | 0.082 | 743 | OpenAI の停止がこのウィンドウに発生しました。 Pi はプロバイダー エラーにより 180 回の実行中 18 回を失い、1.0 は 1 回を失いました (1 回の再試行で 14 回中 13 回が回復しました)。したがって、生のギャップは品質を誇張します。プロバイダー エラーが除外され、1.0 から Pi を引いたペア: スコア +1.1 [-3.2, +5.7] (有意差なし)、コスト -$0.013/タスク [-0.024, -0.004]、時間 -114 秒/タスク [-202, -31]。同じ品質で、より安く、より速く。

api.openai.com では両腕とも gpt-6-luna を実行し、gpt-5.6-luna (xhigh) によって判断されました。ブラウザ使用ゲートウェイのデフォルトの bu-fast モデルは、この実行には含まれていませんでした。 95% のタスククラスター化ブートストラップ間隔。

既知の問題

  • すべての依存関係が正確に固定され (==)、ロックファイルがコミットされます。これはサプライ チェーン ポリシーです。つまり、CI でテストされたバージョンを正確に取得できます。コスト: 別のバージョンの pydantic、pydantic-ai-slim、mcp、google-genai、pillow、または別の固定パッケージを必要とするプロジェクトでは、その隣に 1.0 をインストールできません。どのピンがブロックされているか教えてください。
  • google-genai は 3 未満のままです: 3.0.0 は v1 で Gemini API を呼び出し、ツールを拒否します。 Pydantic AI がサポートすると、この問題はなくなります。
  • ビューポート エミュレーションはクラウド ブラウザではまだ機能しません。別のビューポートには Browser('chromium') を使用します。

https://github.com/browser-use/browser-use/issues で問題を報告してください
