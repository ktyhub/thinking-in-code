kubeflow v1.9.0

マイナー 公開日2024年7月16日 出典kubeflow/kubeflow 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#クベフローv1.9.0

このリリースは、Kubeflow Platform バージョン 1.9.0 用にカットされました。

注: 次の release note は、kubeflow/kubeflow リポジトリ内のコンポーネントの only です。

重大な変更

中央ダッシュボード

  • ホームページとグループ Kubeflow Pipelines サイドバー リンクをクリーンアップ: https://github.com/kubeflow/kubeflow/pull/7583
  • 所有されているすべての名前空間の寄稿者を管理: https://github.com/kubeflow/kubeflow/pull/7582

Kubeflow ノートブック

  • デフォルトのパッケージを更新します (Jupyter、VSCode、RStudio、PyTorch、Tensorflow、CUDA など): https://github.com/kubeflow/kubeflow/pull/7590
  • ノートブックが制限されたポッド セキュリティ コンテキストで実行できるようにします: https://github.com/kubeflow/kubeflow/pull/7622

特徴

中央ダッシュボード

  • 特技(ダッシュボード): https://github.com/kubeflow/kubeflow/pull/7138 の @MGSousa による externalLinks での {ns} テンプレートの使用を許可します
  • 功績: https://github.com/kubeflow/kubeflow/pull/7582 の @thesuperzapper による投稿者管理ページの大きな更新
  • 功績: https://github.com/kubeflow/kubeflow/pull/7583 の @thesuperzapper によるダッシュボードのスタイルとリンクの更新

ノートブックの画像

  • 修正: https://github.com/kubeflow/kubeflow/pull/7407 の @thesuperzapper による jupyterlab ランタイム ボリュームのアクセス許可
  • 修正: S6_CMD_WAIT_FOR_SERVICES_MAXTI を増やす… by @mishraprafful (https://github.com/kubeflow/kubeflow/pull/7496)
  • 功績: https://github.com/kubeflow/kubeflow/pull/7590 の @thesuperzapper によるノートブック サーバー イメージの更新
  • 修正: https://github.com/kubeflow/kubeflow/pull/7622 の @thesuperzapper による非ルート SecurityContext を含むノートブック サーバー イメージ

Jupyter Web アプリ

  • https://github.com/kubeflow/kubeflow/pull/6529 の @haoxins によってカスタム Jupyter 画像文字列をトリミングします。

プロファイルコントローラー

  • https://github.com/kubeflow/kubeflow/pull/7310 の @kimwnasptd によりプロファイル コントローラーでプリンシパルを動的にします

TensorBoard コントローラー

  • 特技: https://github.com/kubeflow/kubeflow/pull/6902 の @punkerpunker による Istio VirtualServices のノートブック/テンソルボード コントローラーで ISTIO_HOST の設定を許可します。

PVC ビューア

  • 功績: pvcviewer istio ゲートウェイを https://github.com/kubeflow/kubeflow/pull/7351 の @TobiasGoerke によって構成可能にしました

修正

中央ダッシュボード

  • 中央ダッシュボード: 投稿者の管理画面 (#7188) に All namespaces を表示しない (@utumi-fj による https://github.com/kubeflow/kubeflow/pull/7242)
  • 修正: https://github.com/kubeflow/kubeflow/pull/7578 の @thesuperzapper により中央ダッシュボードを NodeJS 16 に更新
  • 修正: https://github.com/kubeflow/kubeflow/pull/7264 内の @hhk7734 による DASHBOARD_LINKS_CONFIGMAP 環境変数の誤った参照
  • 修正: https://github.com/kubeflow/kubeflow/pull/7597 での @mishraprafful によるプロファイル作成の電子メール検証パリティ

ノートブックコントローラー

  • spawner_ui_config.yaml は 10 分に 1 回のみロードします。 #7259 by @boarder7395 (https://github.com/kubeflow/kubeflow/pull/7260) を閉じる
  • fix(notebook-controller): https://github.com/kubeflow/kubeflow/pull/7305 の @LiaoSirui によるタイプミスを修正
  • 修正 (ノートブック): https://github.com/kubeflow/kubeflow/pull/7495 の @mishraprafful による空のイメージとコンテナーの CRD 検証を追加
  • 修正: https://github.com/kubeflow/kubeflow/pull/7589 の @mishraprafful による golang バージョン形式を回避するために envtest バージョンを指定

プロファイルコントローラー

  • 修正: https://github.com/kubeflow/kubeflow/pull/7279 の @Linchin による CreationTimestamp 行を削除
  • 修正: https://github.com/kubeflow/kubeflow/pull/7378 の @DnPlas により環境変数から余分な ) を削除
  • https://github.com/kubeflow/kubeflow/pull/7591 の @kimwnasptd によるプロファイル コントローラーのピン env-test

Jupyter Web アプリ

  • 修正: https://github.com/kubeflow/kubeflow/pull/7320 の @DnPlas によってデフォルトの GPU ベンダー リストを設定
  • 修正: https://github.com/kubeflow/kubeflow/pull/7335 の @TobiasGoerke による KF 1.8 の KeyError
  • wa(front): https://github.com/kubeflow/kubeflow/pull/7341 の @kimwnasptd により、すべての Web アプリの背景を白にします
  • 修正: https://github.com/kubeflow/kubeflow/pull/7375 の @TobiasGoerke によるローカル変数シャドウイング インポート
  • ノード容量が定義されていない場合のエッジケースを適切に処理します。 #7280を閉じます。 @boarder7395 著、https://github.com/kubeflow/kubeflow/pull/7281
  • 修正: :label: ユーザー名が get_username によって https://github.com/kubeflow/kubeflow/pull/7457 の @pashtet04 によって文字列として返されるようにする
  • fix(crud-web-apps/jupyter): https://github.com/kubeflow/kubeflow/pull/7485 の @mishraprafful による node.status.capacity の辞書変数参照
  • 修正 (ノートブック): https://github.com/kubeflow/kubeflow/pull/7585 の @kimwnasptd による status.containerState メッセージを正しく処理

PVC ビューア

  • 修正: viewer-spec.yaml と @TobiasGoerke によるトリガー ビルド (https://github.com/kubeflow/kubeflow/pull/7230)
  • https://github.com/kubeflow/kubeflow/pull/7244 の @dfince によるプロファイル コントローラーの README ファイルとサンプル ファイルを修正
  • 修正: ファイルブラウザを v2.23.0 にダウングレード (https://github.com/kubeflow/kubeflow/pull/7247 の @TobiasGoerke による)
  • 修正: @TobiasGoerke による pvcviewer テスト (https://github.com/kubeflow/kubeflow/pull/7292)
  • 雑務: https://github.com/kubeflow/kubeflow/pull/7390 の @TobiasGoerke によるデフォルトのファイルブラウザのバージョンの更新
  • 修正: https://github.com/kubeflow/kubeflow/pull/7350 の @TobiasGoerke による pvcviewer ステータスなしで待機状態を返す

TensorBoard Web アプリ

  • 修正: https://github.com/kubeflow/kubeflow/pull/7274 の @hhk7734 による TWA_APP_SECURE_COOKIES 設定内の誤ったスペースを削除

  • 修正: https://github.com/kubeflow/kubeflow/pull/7353 の @DnPlas による ~kubeflow/styles/fonts.scss をポイントする
