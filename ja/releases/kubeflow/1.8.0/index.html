#クベフローv1.8.0

このリリースは、Kubeflow Platform バージョン 1.8.0 用にカットされました。

注: 次の release note は、kubeflow/kubeflow リポジトリ内のコンポーネントの only です。

特徴

  • セントラルダッシュボードのマルチアークの CI に linux/ppc64le のサポートを追加… by @amitmukati-2604 (https://github.com/kubeflow/kubeflow/pull/6923)

  • 中央ダッシュボード: https://github.com/kubeflow/kubeflow/pull/6958 の @elenzio9 による kwa のすべての名前空間オプションを許可
  • cdb(フロント): https://github.com/kubeflow/kubeflow/pull/6953 の @orfeas-k によって左側のサイドバーのリンクを取得します

  • https://github.com/kubeflow/kubeflow/pull/7050 の @beliaev-maksim によるrequirements.txtの更新
