feign 13.15

マイナー 公開日2026年9月9日 出典OpenFeign/feign 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#13.15を装う

何が変わったのか

  • https://github.com/OpenFeign/feign/pull/3527 の @velo による述語を使用してマルチエンコーダーをマスターにポートします
  • https://github.com/OpenFeign/feign/pull/3531 の @velo によってターゲットの下で平坦化された feign-bom POM を生成します
  • https://github.com/OpenFeign/feign/pull/3528 の @velo による応答ごとにデコーダーを選択するために MultiDecoder を追加
  • https://github.com/OpenFeign/feign/pull/3534 の @velo によってレビュー フィードバックをマルチエンコーダーおよびマルチデコーダー サーフェスに適用します
  • mvnd ラッパーを 1.0.6 にバンプして、https://github.com/OpenFeign/feign/pull/3557 の @velo による壊れた 1.0.2 ダウンロード URL を修正します
  • kotlin.Unit のサスペンド戻り値を https://github.com/OpenFeign/feign/pull/3558 の @velo によって null ではなく Unit.INSTANCE にデコードします
  • https://github.com/OpenFeign/feign/pull/3535 の @tanvir-ux によるランタイム クラスを使用して Gson リクエスト本文をエンコードします
