feign 13.18

マイナー 公開日2026年11月10日 出典OpenFeign/feign 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#13.18を装う

何が変わったのか

  • JDK Simple JSON API (JEP 540) に feign-jdk-json コーデックを追加し、https://github.com/OpenFeign/feign/pull/3620 の @velo による dependabot 自動マージを修正
  • https://github.com/OpenFeign/feign/pull/3613 の @hutiefang76 によるフィールド クエリ マップから静的フィールドを除外
  • https://github.com/OpenFeign/feign/pull/3612 の @hutiefang76 による実行時の HeaderMap 値をリテラルとして扱う
  • ドキュメント: https://github.com/OpenFeign/feign/pull/3659 の @hamidzr によるドキュメントのタイプミスを修正
  • https://github.com/OpenFeign/feign/pull/3628 の @hutiefang76 によって他の Content-Type パラメーターの後に応答文字セットを読み取ります
  • https://github.com/OpenFeign/feign/pull/3611 の @klay によって FormEncoder で引用符で囲まれた大文字と小文字が混合された文字セット パラメーターを読み取ります
  • Logger が https://github.com/OpenFeign/feign/pull/3544 の @ChrisJr404 によるワイヤー リクエストではなく、Feign のリクエストを反映していることを示す文書
  • https://github.com/OpenFeign/feign/pull/3658 の @havefunatcode による QueryMap POJO フィールドとゲッターに @Param エクスパンダを適用します
  • https://github.com/OpenFeign/feign/pull/3546 で @henriquejsza によるオプトイン ターゲット ホストとポート監視タグを追加します
  • feign-kotlin: ノンブロッキング WebClient AsyncClient を追加し、https://github.com/OpenFeign/feign/pull/3645 の @ggoowlgns によるコルーチン サポートを改善
  • プライベートと Vary をスキップ: * https://github.com/OpenFeign/feign/pull/3610 の @alhudz による HttpCacheInterceptor での応答
  • https://github.com/OpenFeign/feign/pull/3462 の @goutamadwant による Java 11 応答本文のタイムアウトを強制する
  • feign-mock: https://github.com/OpenFeign/feign/pull/3661 の @lxcxjxhx によるサブセットによるリクエスト ヘッダーの一致を許可します
  • https://github.com/OpenFeign/feign/pull/3633 で @hutiefang76 による URI フラグメント置換とターゲット エスケープを修正
  • https://github.com/OpenFeign/feign/pull/3627 の @hutiefang76 によるエスケープされていない URI 値の予約文字フラグを尊重します
  • Java11 応答ヘッダー値の順序と、https://github.com/OpenFeign/feign/pull/3638 の @hutiefang76 による重複を保持します。
  • リテラルのクエリ値を保持し、https://github.com/OpenFeign/feign/pull/3624 の @hutiefang76 によって配列パラメータを展開します
  • https://github.com/OpenFeign/feign/pull/3665 の @wozhenbang2004 により、大文字と小文字を区別せずに HTTP URI スキームを認識します
  • Java11 client でのゼロ接続および読み取りタイムアウトを尊重 (https://github.com/OpenFeign/feign/pull/3637 の @hutiefang76 による)
  • https://github.com/OpenFeign/feign/pull/3634 の @hutiefang76 によるボディのない冪等リクエストに対する Apache HTTP4 の再試行を復元します
  • デリゲートが https://github.com/OpenFeign/feign/pull/3630 の @hutiefang76 によってエラーをスローすると、非同期 client 先物が完了します
  • https://github.com/OpenFeign/feign/pull/3674 の @hutiefang76 によるフォーム エンコーダーと引用符対応の文字セット解析を共有します
  • チャンク化されたボディが https://github.com/OpenFeign/feign/pull/3673 の @velo によって最後まで読み取られない場合は、DefaultClient キープアライブ接続を再利用します。
