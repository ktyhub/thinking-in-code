feign 13.14

#13.14を装う

何が変わったのか

  • https://github.com/OpenFeign/feign/pull/3419 の @seonwooj0810 による Http2Client (#2975) の jdk.httpclient.allowRestrictedHeaders を尊重します
  • https://github.com/OpenFeign/feign/pull/3417 の @alhudz によるマルチパート Content-Disposition ヘッダー内の crlf と引用符をエスケープします
  • https://github.com/OpenFeign/feign/pull/3427 の @alhudz による無効な content-type charset については utf-8 にフォールバックします
  • https://github.com/OpenFeign/feign/pull/3422 の @seonwooj0810 による式の最大長を構成可能にする (#2916 を修正)
  • https://github.com/OpenFeign/feign/pull/3382 の @seonwooj0810 によるマルチパート パラメーターのデリゲート コンテンツ タイプを保持
  • https://github.com/OpenFeign/feign/pull/3431 の @alhudz によって Http2Client で int に狭める前の Content-Length をキャップします
  • https://github.com/OpenFeign/feign/pull/3429 の @alhudz によって SecureRandom からマルチパート境界を生成します
  • https://github.com/OpenFeign/feign/pull/3432 の @alhudz によってマルチパート Content-Type ヘッダーから crlf を削除します
  • https://github.com/OpenFeign/feign/pull/3415 の @seonwooj0810 による errorReading (#2618) からの FeignException で応答本文を返す
  • https://github.com/OpenFeign/feign/pull/3437 の @alhudz により、無効な式の値修飾子をリテラルとして扱います
  • https://github.com/OpenFeign/feign/pull/3436 の @alhudz によって URL コード化されたフォーム本体でコレクション値をエンコードします
  • https://github.com/OpenFeign/feign/pull/3433 の @alhudz によって設定された文字セットを使用して SOAP リクエスト本文をエンコードします
  • https://github.com/OpenFeign/feign/pull/3492 の @renechoi による GoogleHttpClient および DefaultClient の負の Content-Length をキャップします
  • https://github.com/OpenFeign/feign/pull/3463 の @hutiefang76 による空の GET ボディの POST への変換を避ける
  • https://github.com/OpenFeign/feign/pull/3464 の @kmdy7991 による HC5 でのデフレート リクエスト エンコーディングをサポート
  • https://github.com/OpenFeign/feign/pull/3468 の @hutiefang76 により JavaLogger ファイル ハンドラーを閉じる
  • https://github.com/OpenFeign/feign/pull/3453 の @alhudz による StringDecoder の応答文字セットを尊重します
  • https://github.com/OpenFeign/feign/pull/3447 の @alhudz による、gson および jackson イテレータ デコーダの応答文字セットを優先する
  • https://github.com/OpenFeign/feign/pull/3446 の @hutiefang76 により、機能が応答インターセプターを提供できるようにします
  • https://github.com/OpenFeign/feign/pull/3444 の @alhudz によって解決されたヘッダー テンプレート値から crlf を削除します
  • https://github.com/OpenFeign/feign/pull/3442 の @alhudz により、プラットフォームのデフォルトではない utf-8 で文字列リクエスト本文をエンコードします
  • https://github.com/OpenFeign/feign/pull/3441 の @alhudz によって okhttp 応答本文リーダーで要求された文字セットを尊重します
  • https://github.com/OpenFeign/feign/pull/3448 の @hutiefang76 による DefaultClient での重複した Content-Length 処理を修正
  • https://github.com/OpenFeign/feign/pull/3454 に @kumarprabhashand による HTTP QUERY メソッドのサポート (RFC 10008) を追加
  • https://github.com/OpenFeign/feign/pull/3445 の @alhudz による gzip/deflate デコード後の応答本文の長さをクリア
  • https://github.com/OpenFeign/feign/pull/3449 の @hutiefang76 によるクローン ビルダーの Fluent メソッドを修正
  • https://github.com/OpenFeign/feign/pull/3512 の @velo により、graphql-transport-ws に対する GraphQL サブスクリプション サポートを追加
  • https://github.com/OpenFeign/feign/pull/3507 の @seonwooj0810 による空の本文を持つ POST/PUT/PATCH でのデフォルトの Content-Type を回避します
  • インポートが https://github.com/OpenFeign/feign/pull/3508 の @kalayciburak による消費者の依存関係管理をオーバーライドしないように、feign-bom をフラット化します。
  • https://github.com/OpenFeign/feign/pull/3526 の @velo による GraphQL 操作のすべてのルート フィールドをデコードします
  • https://github.com/OpenFeign/feign/pull/3451 の @alhudz による DefaultClient の Content-Length ヘッダーの重複を回避します
  • https://github.com/OpenFeign/feign/pull/3519 の @arimu1 によってアンマーシャラーを作成するときに JAXB ファクトリ プロパティを適用します
  • コントラクト解析でブリッジ メソッドをスキップし、https://github.com/OpenFeign/feign/pull/3517 の @AzazelSensei によるディスパッチ用にマップします。
