eigent v0.0.89

パッチ 公開日2026年3月25日 出典eigent-ai/eigent 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#エイジェントv0.0.89

新機能

サーバー リファクタリング v1 (#1509)

サーバーのコードベースは、保守性と拡張性を向上させるために ドメイン駆動アーキテクチャ に再構築されました。 API エンドポイントまたはデータベース スキーマは変更されませんでした。 app/component/ → app/core/ | app/controller/ → app/domains/*/api/ | app/service/ → app/domains/*/service/

その他の変更点

  • デフォルトのサンプルスキルとしてセキュリティ監査人を追加します
  • タスクとプロジェクトの合計を示すツールチップを使用して、チャットヘッダーのトークンの使用状況を明確にします
  • ChatBoxタスクカードからはみ出す長いタスクテキストを修正
  • スキルクリエーターのアップデート

⚠️ アップグレードに関するお知らせ (ローカル展開ユーザー)

このリリースには、サーバーの 重大な変更 が含まれています。ローカル展開を実行している場合は、次のアクションを実行する必要があります**。 Docker ユーザー:

cd server
docker-compose up --build -d

Docker 以外のユーザー: 最新のコードを取得した後、サーバー プロセスを再起動します。 Electron アプリ ユーザー: アプリケーションを再起動するだけです。
