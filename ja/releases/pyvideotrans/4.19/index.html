v4.19 Win10/11 プレパッケージ版ダウンロード

<詳細>

<summary>MacOS/Linux システムにはソース コードのデプロイメントを使用してください</summary>

  1. 依存関係をインストールします。

    # macOS
brew install libsndfile git

brew tap homebrew-ffmpeg/ffmpeg
 
brew install homebrew-ffmpeg/ffmpeg/ffmpeg

# Ubuntu/Debian
sudo apt-get install ffmpeg libsndfile1-dev

  2. UV をインストールします。

    curl -LsSf https://astral.sh/uv/install.sh | sh

  3. クローンを作成して開始します。

    git clone https://github.com/jianchang512/pyvideotrans.git
cd pyvideotrans
uv sync
uv run sp.py

</詳細>

解凍に関する注意事項:

  • 7z 圧縮パッケージを解凍します。解凍後、sp.exe ファイルを見つけてダブルクリックしてソフトウェアを起動します。圧縮パッケージではダブルクリックして実行することはできません。 ・デスクトップやCドライブ上のProgram Filesなどの管理者権限が必要なフォルダーには解凍しないでください。
  • パス エラーを避ける: 解凍パスに漢字、スペース、または特殊記号を含めないでください。 ・7zipソフトでの解凍時にエラーが発生する場合は、「Bandizip」(https://bandisoft.com/bandizip/)または「360圧縮ソフト」(https://yasuo.360.cn)での解凍をお試しください。
