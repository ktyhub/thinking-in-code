v4.18 Win10/11 プレパッケージ版ダウンロード

<詳細>

<summary>MacOS/Linux システムにはソース コードのデプロイメントを使用してください</summary>

  1. 依存関係をインストールします。

    # macOS
brew install libsndfile git

brew tap homebrew-ffmpeg/ffmpeg
 
brew install homebrew-ffmpeg/ffmpeg/ffmpeg

# Ubuntu/Debian
sudo apt-get install ffmpeg libsndfile1-dev

  2. UV をインストールします。

    curl -LsSf https://astral.sh/uv/install.sh | sh

  3. クローンを作成して開始します。

    git clone https://github.com/jianchang512/pyvideotrans.git
cd pyvideotrans
uv sync
uv run sp.py

</詳細>

何が変わったのか

  • 偉業(翻訳者): @heydryft による Runcrate 翻訳チャンネルを https://github.com/jianchang512/pyvideotrans/pull/1240 に追加
  • 功績(翻訳者): @mrhy7176 による CloudGPU 翻訳チャネルを https://github.com/jianchang512/pyvideotrans/pull/1242 に追加
  • feat(mainwin): TTS チャンネルがターゲット言語をサポートしていない可能性がある場合、開始前に尋ねます (https://github.com/jianchang512/pyvideotrans/pull/1243 の @Venius24)
  • fix(align): https://github.com/jianchang512/pyvideotrans/pull/1244 の @tanishqbaweja により、失敗した行のサイレント プレースホルダーを 48 kHz ステレオで書き込みます
  • 修正(吹き替え): https://github.com/jianchang512/pyvideotrans/pull/1245 の @tanishqbaweja による字幕吹き替えの音量設定を適用
  • 修正(tts): Doubao 2.0 オーディオを他のチャンネルと同様に 48 kHz ステレオに変換 (https://github.com/jianchang512/pyvideotrans/pull/1246 の @tanishqbaweja による)
  • 修正(tts): https://github.com/jianchang512/pyvideotrans/pull/1247 の @tanishqbaweja により Doubao 2.0 のモノラル PCM を両方のチャンネルに書き込む
  • 修正（翻訳者）: https://github.com/jianchang512/pyvideotrans/pull/1248 の @tanishqbaweja により、省略記号で終わる行が次の行に結合しないようにしました。
  • テスト(tts): Doubao 2.0 チャンネルが @tanishqbaweja によって https://github.com/jianchang512/pyvideotrans/pull/1249 に保存されるモノラル wav を期待します
  • fix(translator): https://github.com/jianchang512/pyvideotrans/pull/1250 の @tanishqbaweja による翻訳を読む前に複数行の <think> ブロックを削除
  • fix(align): ビデオの速度低下で、https://github.com/jianchang512/pyvideotrans/pull/1252 の @tanishqbaweja によってビデオが終了する最後のスロットを終了します。
  • 修正（吹き替え）: マルチロール吹き替えで [speaker] タグなしで字幕をインポートする (https://github.com/jianchang512/pyvideotrans/pull/1253 の @tanishqbaweja により再度)
  • fix(ui): ドロップされたファイルを URL から取得し、https://github.com/jianchang512/pyvideotrans/pull/1255 の @tanishqbaweja によってその名前をリストします。
  • 修正(準備): https://github.com/jianchang512/pyvideotrans/pull/1254 で @tanishqbaweja によって [Name] タグを削除するときにスピーカー名をエスケープする
  • fix(ui): インポートされたターゲット言語の .ass ファイルを SRT に変換 (https://github.com/jianchang512/pyvideotrans/pull/1258 の @tanishqbaweja により)
  • fix(params): https://github.com/jianchang512/pyvideotrans/pull/1256 の @tanishqbaweja により、削除されたバンドルされたリファレンス オーディオを毎回開始時に追加し直すのを停止
  • 修正(srt): https://github.com/jianchang512/pyvideotrans/pull/1259 で @tanishqbaweja によって GBK または UTF-16 として保存された .ass ファイルをインポートしてダビングします
  • 修正 (ui): マルチスピーカーのダビングを、https://github.com/jianchang512/pyvideotrans/pull/1260 の @tanishqbaweja によって選択されたフォルダーに一度保存します。
  • 修正（ダビング）: https://github.com/jianchang512/pyvideotrans/pull/1261 の @tanishqbaweja による、mp3/m4a 出力または 1 回のリクエスト Edge-TTS で同名のファイルを上書きしないでください。
  • 修正（吹き替え）: https://github.com/jianchang512/pyvideotrans/pull/1262 の @tanishqbaweja による別のビデオからキャッシュされたクローン吹き替えを再利用しないでください。
  • 修正(tts): @tanishqbaweja によってプリセット音声で再吹き替えられた Qwen3-TTS のセリフを https://github.com/jianchang512/pyvideotrans/pull/1264 に保存
  • 修正(tts): https://github.com/jianchang512/pyvideotrans/pull/1263 の @tanishqbaweja により、内蔵チャンネルで再ダビングするときにピーク正規化と無音設定を適用します
  • fix(ui): OpenRouter、DeepSeek、MiniMax ウィンドウでチャンネル独自の params キーを使用 by @tanishqbaweja (https://github.com/jianchang512/pyvideotrans/pull/1265)
  • 修正 (認識): https://github.com/jianchang512/pyvideotrans/pull/1266 の @tanishqbaweja により、whisper.cpp および Whisper.NET モデルを再度リストします。
  • 修正 (onlyone): メイン ウィンドウの無音状態からダビング校正パネルを開始し、https://github.com/jianchang512/pyvideotrans/pull/1267 の @tanishqbaweja による選択を同期します
  • fix(ui): OpenRouter ウィンドウで保存された TTS モデルを選択 (https://github.com/jianchang512/pyvideotrans/pull/1268 の @tanishqbaweja により)
  • 修正(tts): https://github.com/jianchang512/pyvideotrans/pull/1269 の @tanishqbaweja によって設定ウィンドウで選択された Index-TTS および VoxCPM バージョンを再度使用します。
  • 修正(tts): Piper で音声速度を正しく適用し、https://github.com/jianchang512/pyvideotrans/pull/1271 で @tanishqbaweja による GPT-SoVITS api.py リクエストを適用しました。
  • 修正(srt): https://github.com/jianchang512/pyvideotrans/pull/1272 で @tanishqbaweja によって GBK として保存された .srt および .txt ファイルのインポート、ダビング、翻訳
  • 修正（翻訳者）: https://github.com/jianchang512/pyvideotrans/pull/1273 の @tanishqbaweja により「SRT の送信」がオンになっている場合に翻訳キャッシュを再利用
