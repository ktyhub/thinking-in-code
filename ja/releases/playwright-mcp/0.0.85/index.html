playwright-mcp v0.0.85

パッチ 公開日2026年11月9日 出典microsoft/playwright-mcp 英語原文

#劇作家-mcp v0.0.85

✨ ハイライト

  • 🌙 ブラウザーをバックグラウンドで維持 (microsoft/playwright#42973) - 拡張機能を介して接続すると、タブがアクティブになり、ブラウザー ウィンドウにフォーカスがあり、作業していたアプリの画面が取得されます。 --background を --extension (config background: true、env PLAYWRIGHT_MCP_BACKGROUND=1) と一緒に渡すと、接続されているタブが非アクティブになり、そのウィンドウがフォーカスされないままになり、client の新しいタブがバックグラウンドで表示されます。 PLAYWRIGHT_MCP_EXTENSION_TOKEN を設定すると、接続ページがバックグラウンドでも開きます (Chrome 158.0.8127.2 以降、ブラウザがすでに実行されている場合)。拡張子0.5.0以降が必要です。 Chrome は、バックグラウンド タブのタイマーとアニメーション フレームを調整します。 (microsoft/playwright#43864)
  • 🗂️ Playwright タブ グループからタブを残す (microsoft/playwright#43038) - 拡張機能は常に、client コントロールのタブを独自のタブ グループに移動しました。 --no-tab-group を --extension (config tabGroup: false、env PLAYWRIGHT_MCP_NO_TAB_GROUP=1) と一緒に渡して、選択したタブと、client が既存のグループ内で開くタブ (存在する場合) を保持します。接続の承認は変更されず、各制御対象タブは引き続き 1 つの client に属し、拡張機能のステータス ページには制御対象タブがリストされます。拡張子0.5.0以降が必要です。 (microsoft/playwright#43814)
  • 👁️ 表示されている要素のみを一致させる (microsoft/playwright#43855) - ロケーターは非表示の要素に解決されるか、非表示の重複も一致するために失敗する可能性があります。 browser_click などの要素ツールの target と browser_run_code_unsafe の両方で、あたかも .filter({ visible: true }) がそれぞれの要素を終了したかのように、ロケーターを表示要素に制限するには、構成ファイルで browser.contextOptions.locateOnlyVisible: true を設定します。独自の可視性フィルターで終わるロケーターがそれを保持します。デフォルトではオフです。 (microsoft/playwright#43903)
  • 🏷️ スナップショットにコンテナー名を保持する (microsoft/playwright#43809) - 見出しやキャプションが表示されている場合でも、ダイアログ、ランドマーク、テーブルが名前なしで表示されることがありました。 browser_snapshot は、名前を提供するテキストがその子にも表示される場合、コンテナーとテーブル ヘッダー上で識別名を保持するようになりました。 (microsoft/playwright#43810)
  • 🎯 ラベルでカスタム フォーム コントロールを検索 (microsoft/playwright#43898) - ネイティブ <label> の関連付けは、フォームに関連付けられたカスタム要素では無視されました。要素ツールは、getByLabel('City') などのターゲットを通じてこれらのコントロールを認識し、アクセス可能な名前も関連付けられたラベルを使用するようになりました。 for 属性とネストされたラベルの両方がサポートされています。 (microsoft/playwright#43900)

🐛 修正

  • fix(aria): restore snapshot visibility rules for inert and modal content — v0.0.84 で発表されたフィルタリングは元に戻ります。browser_snapshot は、コンテンツが不活性であるかモーダル ダイアログの外側にあるという理由だけでコンテンツを非表示にすることはなくなりました。 Click、fill、select アクションは、明示的に不活性なターゲットが非不活性になるまで待機します (microsoft/playwright#43792)。 (microsoft/playwright#43850、microsoft/playwright#43851)
  • fix(mcp): preserve non-JSON evaluation results — browser_evaluate は、値を失ったり JSON シリアル化に失敗したりする代わりに、BigInt、NaN、Infinity、undefined、循環オブジェクトなどの値の読み取り可能な表現を返します。 JSON 互換の結果は、既存の形式 (#1838) を維持します。 (microsoft/playwright#43973)
  • fix(mcp): resolve config file paths relative to their source — 構成内のプロファイル、実行可能ファイル、ストレージ状態、出力およびその他のファイル パスは、そのファイルのディレクトリ、またはシンボリックリンクのターゲット ディレクトリに対して解決されます。 CLI および環境パスは、作業ディレクトリを基準とした相対パスのままです。拡張接続では、マージされた実行可能パス構成 (#1836) も尊重されます。 (microsoft/playwright#43970)
  • fix(extension): report lost tab instead of crashing — スナップショットがキャプチャされる前にページが閉じられたとき、ツールの応答がレポートします。拡張機能の接続では、応答レンダリングのクラッシュではなく、サポートされていないフレームが原因で Chrome がデバッガーを切断した可能性があることも説明されています (microsoft/playwright#43230)。 (microsoft/playwright#43863)
  • fix(mcp): bound settle waits when page timers cannot run — ページ タイマーが調整されたり、一時停止されたり、その他の理由で実行できない場合に、ツール呼び出しが整定遅延中にハングしなくなりました (microsoft/playwright#43752)。 (microsoft/playwright#43767)
  • fix(mcp): report event listener exceptions as console errors — browser_run_code_unsafe を通じてインストールされたページ リスナーとコンテキスト リスナーからの例外は、未処理エラーとして escaping ではなくツール応答および browser_console_messages に表示されます (microsoft/playwright#43770)。 (microsoft/playwright#43686)
  • fix(mcp): validate device names and preserve device descriptors — 不明な --device 値は明示的なエラーを生成し、client ごとのオーバーライドによって共有デバイス プリセットが変更されなくなりました (#1834)。 (microsoft/playwright#43971)
  • fix(mcp): report one-based console source lines — browser_console_messages のソースの場所とツール応答のコンソール エントリでは、1 から始まるエディター スタイルの行番号が使用されるようになりました (#1839)。 (microsoft/playwright#43975)
  • fix(mcp): clarify screenshot actions with vision tools — browser_take_screenshot の説明では、スクリーンショットに対する操作が除外されなくなりました。 browser_snapshot はアクションのデフォルトのままです。 --caps=vision では、説明はキャンバス コンテンツ (#1816) など、スナップショットでは公開されない要素に対する座標ベースのマウス ツールを指します。 (microsoft/playwright#43857)
  • fix(aria): match mixed-case selected options in accessible names — カスタム リストボックスで aria-selected="TRUE" (microsoft/playwright#43785) などの大文字と小文字が混合された値を使用する場合、スナップショットとロール ロケーターには、選択されたオプションのテキストが含まれます。 (microsoft/playwright#43787)
  • fix(chromium): preserve fonts when connecting with noDefaults — 拡張機能接続は既存のブラウザーのフォント設定を上書きしなくなり、ページ レンダリングへの予期しない変更を回避します (microsoft/playwright#43715)。 (microsoft/playwright#43773)
  • fix(chromium): honor Linux config directories for channel connections — CHROME_USER_DATA_DIR、CHROME_CONFIG_HOME、XDG_CONFIG_HOME を考慮した拡張プロファイル ルックアップ。チャネルベースの --cdp-endpoint 接続では、DevToolsActivePort (microsoft/playwright#43880) でアドバタイズされる WebSocket パスも使用します。 (microsoft/playwright#43884)
  • fix(chromium): preserve HTTP navigations across HTTPS upgrade modes — サーバーによって起動されたブラウザーでは、Chrome が HTTP URL を自動的に HTTPS にアップグレードするのではなく、browser_navigate が HTTP URL を HTTP 上に保持します (microsoft/playwright#43871)。 (microsoft/playwright#43877)
  • fix(chromium): account for tabs and toolbar in the new headless mode — --headless では、Chrome と Edge がタブ ストリップとツールバーの下のビューポートに合わせてウィンドウのサイズを調整するようになり、browser_start_video (--caps=devtools 経由でオプトイン) からのビデオがページの下部を失うことがなくなりました。 (microsoft/playwright#43904)
  • fix(screenshot): support full-page SVG documents — browser_take_screenshot と fullPage: true は、存在しない HTML 本文を待つ代わりに、スタンドアロン SVG ドキュメントで動作します (microsoft/playwright#43962)。 (microsoft/playwright#43972)
