 09/28
v0.0.83 パッチ MT

browser_find は、応答の代わりにファイル名を取得して、一致をファイルに保存します (microsoft/playwright#42077)。 (マイクロソフト/プレイライト#42968)

 09/18
v0.0.82 パッチ MT

🎬 スムーズな 60 fps、スタイル可能なビデオ — browser_start_video (--caps=devtools によるオプトイン) は fps を取得するため、fps: 60 はデフォルトの 25 の代わりにスムーズな 60 fps ビデオを記録し、cursor: true はアニメーション化されたマウス カーソルをレンダリングします。

 09/14
v0.0.81 パッチ MT

browser_webmcp_list / browser_webmcp_call — WebMCP API を通じてページが登録するツールを一覧表示して呼び出し、UI を駆動する代わりにページに作業を実行させます。

 09/01
v0.0.80 パッチ MT

browser_start_recording / browser_stop_recording (--caps=devtools によるオプトイン) — ユーザーがブラウザで手動で実行するアクションを記録し、Playwright コードとして返します。

 08/06
v0.0.79 パッチ MT

browser_take_screenshot — WebP 形式 — 画像形式 (png、jpeg、または webp) を選択する新しいタイプ オプション。設定されていない場合、形式はファイル名の拡張子から推測されます (#41152)

 07/09
v0.0.78 パッチ MT

browser_find — 現在のページのアクセシビリティ スナップショットでテキストまたは正規表現を検索します。一致するスナップショット ノードを周囲のコンテキスト (検索スニペットなど) の数行とともに返します。これは安価です…

 06/29
v0.0.77 パッチ MT

browser_take_screenshot — スケール オプション — CSS ピクセルのスクリーンショット (小さい、デバイスと一致) とデバイス ピクセルのスクリーンショット (高解像度) のどちらかを選択します (#41465)

 06/10
v0.0.76 パッチ MT

browser_video_show_actions / browser_video_hide_actions — 記録されたビデオにアクションの注釈をオーバーレイするか、再度非表示にします (#40914)

 05/07
v0.0.75 パッチ MT

--isorated モードで共有ブラウザの起動をシリアル化する (#40709) · 拡張モードでブラウザレベルの CDP コマンドを転送する (#40706)

 05/06
v0.0.74 パッチ MT

この拡張機能は、 --extension とともに使用した場合に複数のタブの管理をサポートするようになりました (#40678)
