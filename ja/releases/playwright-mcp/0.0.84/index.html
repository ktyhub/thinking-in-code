playwright-mcp v0.0.84

パッチ 公開日2026年10月31日 出典microsoft/playwright-mcp 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#劇作家-mcp v0.0.84

✨ ハイライト

  • 👥 1 つのブラウザでセッションを分離 — Cookie やストレージを共有せずに複数のアカウントで作業します。 browser_tabs と action: "new" は isolatedContext: "<name>" を受け入れるようになりました。同じ名前のタブはコンテキストを共有しますが、異なる名前は分離されたままになります。省略するか、デフォルトのコンテキストとして "default" を使用します。 Cookie およびストレージ ツールは、現在のタブのコンテキストで動作します。 (microsoft/playwright#43087)
  • 🙈 URL の実行時値を編集 (#1791) - 実行時に作成されたセッション値と許可値を事前にシークレット ファイルにリストすることはできません。 --redact-url-params=access_token,code (config redactUrlParams、env PLAYWRIGHT_MCP_REDACT_URL_PARAMS) は、ツール応答内の名前付きクエリおよびフラグメント パラメーター値を <redacted> に置き換えます。 secrets と同様、これは利便性を高めるための機能であり、セキュリティ機能ではありません。また、拡張機能は、接続ページ URL を読み取った後、接続トークンを削除します。 (microsoft/playwright#43258)
  • 🔎 バインドされた検索結果 (microsoft/playwright#42077) - 一般的な検索用語ですべての一致を応答に入力する必要がなくなりました。 browser_find は正の整数 maxResults を受け入れ、最初に一致した項目とそのコンテキストを返し、合計一致数を報告します。すべての一致を返し続ける場合は省略します。祖先パスは変更されません。 (microsoft/playwright#42947)
  • 🌐 ナビゲーション全体でのリクエストの検査 (microsoft/playwright-cli#479) - フローがナビゲートするとすぐに、前のページからのリクエストが失われることがなくなりました。 browser_network_requests は、保持された履歴を含める all: true を受け入れ、以前のナビゲーションからのリクエストを最大 200 件保持します。 browser_network_request のリクエスト インデックスはナビゲーション間で安定しています。 browser_console_messages は、既存の all オプションと一致するカウントも報告します。 (microsoft/playwright#43526)
  • 🎯 言語でロケーターを使用する (#1797) - browser_click などの要素ツールは、target の JavaScript、Python、Java および C# ロケーターを、スナップショット参照および CSS セレクターと同様に受け入れるようになりました。無効なターゲットには、button [ref=e5] ではなく裸の参照を渡すよう通知するなど、対処可能なエラーが表示されます。 (microsoft/playwright#43539)
  • 📂 サポートされていないワークスペース ルート リクエストをスキップ (#1798) - ルートをアドバタイズするものの、roots/list に応答できない client は、最初のツール呼び出しを停止させる可能性があります。 --ignore-roots (config ignoreRoots: true, env PLAYWRIGHT_MCP_IGNORE_ROOTS=true) を渡すと、そのリクエストをスキップし、サーバーの現在の作業ディレクトリをワークスペース ルートとして使用します。 (microsoft/playwright#43532)
  • 🍪 ドメインとパスごとに Cookie を削除します — 名前で Cookie を削除しても、その名前を持つすべての Cookie を削除する必要がなくなりました。 browser_cookie_delete (--caps=storage によるオプトイン) は、オプションの domain フィルターと path フィルターを受け入れて、他のドメインとパスをそのまま残します。 (microsoft/playwright#43319)

🐛 修正

  • fix(mcp): allow combining time, text and textGone in browser_wait_for — テキスト条件と組み合わせた場合、time はタイムアウト (30 秒に制限) であり、チェックするまでの遅延ではありません。 text と textGone の両方を指定すると、両方を順番に指定するのではなく、最初の条件が発生するまで待機するようになりました。 (microsoft/playwright#43011)
  • fix(mcp): allow loopback hosts by default for all bind addresses — HTTP client は、バインド アドレスに関係なく、localhost、127.0.0.1、または [::1] 経由で接続できます。他のホストでは依然として --allowed-hosts が必要です。 0.0.0.0 にバインドすると、使用可能なローカルホスト URL が出力されます。 (microsoft/playwright#42993)
  • fix(mcp): pass credentials from --proxy-server as proxy username/password — プロキシ URL に埋め込まれた資格情報が、プロキシ認証設定としてブラウザに渡されるようになりました。 (microsoft/playwright#43071)
  • fix(mcp): race browser_navigate_back against modal states — browser_navigate_back は、タイムアウトではなく、履歴ナビゲーション中に開かれたダイアログを報告します。 (microsoft/playwright#43252)
  • fix(mcp): normalize bare host URLs and loopback IP addresses — browser_navigate はポートを備えたスキームレス ホストを処理し、127.0.0.1:3000 や [::1]:3000 などのループバック アドレスに HTTP を使用します。 (microsoft/playwright#43264)
  • fix(mcp): do not close the browser twice when the client disconnects — stdio 切断により、ブラウザは 2 回目の終了要求によってブラウザを強制終了するのではなく、正常に終了します。親が離れると、ダッシュボードの注釈プロセスも終了します。 (microsoft/playwright#43174)
  • fix(mcp): give each isolated client its own idle timer — HTTP トランスポートと --isolated を使用すると、別の client が共有ブラウザをビジー状態にしている間でも、アイドル状態の client のコンテキストが期限切れになるようになりました。 (microsoft/playwright#43527)
  • fix(mcp): apply route headers without bypassing origin filters — browser_route (--caps=network 経由でオプトイン) は、追加されたリクエスト ヘッダー名を大文字と小文字を区別せずに照合し、モック化された応答にカスタム ヘッダーを含め、リクエスト ヘッダーを変更するときに送信元フィルターとその他のルートを保持します。 (microsoft/playwright#43227、microsoft/playwright#43244、microsoft/playwright#43637)
  • fix(mcp): correct cookie filtering and missing-domain errors — browser_cookie_list (--caps=storage 経由でオプトイン) は、notexample.com や /apiary などの無関係な名前ではなく、ドメインとパスの境界に一致します。 browser_cookie_set は、現在のページにホスト名 (about:blank など) がない場合、明示的な domain を要求します。 (microsoft/playwright#43316、microsoft/playwright#43368、microsoft/playwright#43318)
  • fix(mcp): accept Windows paths in browser_resume location — browser_resume (--caps=devtools 経由でオプトイン) は、Windows のドライブ文字のコロンを行番号区切り記号と間違えなくなりました。 (microsoft/playwright#43349)
  • fix(mcp): report run-code route handler exceptions once and verbatim — browser_run_code_unsafe は、ルート ハンドラーのスローされた値を複製したり、エラー以外の値を別のエラーでラップしたりせずに報告します。 (microsoft/playwright#43203)
  • fix(extension): release debugger when attach completes after connection close — browser_tabs が新しいタブに接続しているときに切断しても、そのタブは拡張機能のデバッガに接続されたままになりません。 (microsoft/playwright#43025)
  • fix(chromium): close pages that crashed before connecting over CDP — --cdp-endpoint 経由での接続が、すでにクラッシュまたは破棄されたページで停止することはなくなりました。それらのページはタブ リストから除外されます。 (microsoft/playwright#43075)
  • fix(aria): skip text nodes that are not rendered — browser_snapshot およびアクセス可能な名前では、スロットなしのシャドウ ホスト テキストや閉じた <details> 内に直接あるテキストなど、レンダリングされていないテキストが省略されます。 (microsoft/playwright#43150)
  • fix(a11y): treat inert elements and content outside of modal dialogs as hidden — スナップショットでは、不活性なコンテンツと最上位のモーダル <dialog> の外側のコンテンツが除外されます。 Click および fill アクションは、静かに誤爆するのではなく、ターゲットが不活性になるのを待ちます。 (microsoft/playwright#43211)
  • fix(aria): do not count whitespace-only contributors as name sources — 非表示のアイコンの周囲の空白により名前が消えた場合でも、スナップショットにはボタン名が保持されます。 (microsoft/playwright#43317)
  • fix(aria): resolve label references consistently — スナップショットとロール ロケーターは、タブまたは改行で区切られたラベル ID と、ariaLabelledByElements を通じて割り当てられたラベルを認識しますが、古いブラウザーでは属性ベースのラベルは保持されます。 (microsoft/playwright#43361、microsoft/playwright#43577、microsoft/playwright#43722)
  • fix(aria): quote ~, .inf and .nan in aria snapshots — YAML のような名前は、null または特殊な浮動小数点値として解析されず、文字列のままになります。 (microsoft/playwright#43469)
  • fix(aria): preserve iframe snapshots with fallback text — iframe 要素にフォールバック テキストも含まれている場合、スナップショットは iframe の内容を保持します。 (microsoft/playwright#43635)
  • fix(aria): match mixed-case roles and states — スナップショットとロール ロケーターは、大文字と小文字が混在する role および ARIA 状態値 (チェックされた状態、押された状態、展開された状態を含む) を認識します。 (microsoft/playwright#43727)
