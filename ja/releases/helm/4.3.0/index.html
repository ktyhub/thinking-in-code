#ヘルムv4.3.0

Helm v4.3.0 は機能リリースです。最高のエクスペリエンスを得るために、ユーザーはアップグレードすることをお勧めします。

コミュニティは成長を続けていますので、ぜひお会いしましょう!

  • Kubernetes Slack のディスカッションに参加してください:
    • 質問したり、ただ話したりするため
    • PR、コード、バグについて議論するため
  • 公開開発者コールに参加しましょう: 太平洋時間木曜日、9:30 Zoom 経由
  • チャートのテスト、デバッグ、提供: ArtifactHub/パッケージ

注目すべき変更点

  • 功績: @aeroyorch による継続時間関数を https://github.com/helm/helm/pull/31695 に追加
  • feat(engine): https://github.com/helm/helm/pull/32205 の @ogulcanaydogan によりルックアップが空を返した場合のデバッグ ログを追加
  • 特技: 実行中にリソースを削除する前に所有権の検証を追加…by @banjoh in https://github.com/helm/helm/pull/31584
  • 功績: https://github.com/helm/helm/pull/32162 の @lohitkolluri によるチャート アーカイブの SOURCE_DATE_EPOCH に敬意を表します
  • feat(rollback): https://github.com/helm/helm/pull/31580 の @biagiopietro によるロールバック理由を提供する --description フラグを追加
  • 修正 (内部/プラグイン): https://github.com/helm/helm/pull/32134 の @lexfrei によるプラグイン名のコメントからゼロ幅スペースを削除
  • 修正 (ローダー): https://github.com/helm/helm/pull/32525 の @locker95 による 4096 バイト境界で終わる値ファイルを削除しない
  • fix(chart): StampModTimes タイムスタンプを UTC/truncate に正規化 + Chart.lock 再現性テスト (https://github.com/helm/helm/pull/32485 で @Mentigen による)
  • 修正 (来歴): https://github.com/helm/helm/pull/32281 の @ruslan-shaydullin による GnuPG キーボックス (pubring.kbx) キーリングをサポート
  • fix(template): regression - レジストリ メッセージをテンプレートの stderr にルーティングし、https://github.com/helm/helm/pull/32217 で @amarkdotdev によって表示します
  • リファクタリング: https://github.com/helm/helm/pull/31944 の @AustinAbro321 により再同期期間が 1 時間から 3 分に短縮されました
  • perf: https://github.com/helm/helm/pull/32043 の @mapleeit による複数分の遅延を防ぐために同時ステータス計算を有効にします。
  • chore(deps): k8s-io グループを 0.37.0 にバンプします - #32598

次は何ですか

  • 4.3.1 および 3.22.1 は、2026 年 10 月 14 日に予定されている次のパッチ リリースです。
  • 4.4.0 は、2027 年 1 月 13 日に予定されている次のマイナー リリースです。これ以上の Helm 3 マイナー リリースはありません (https://helm.sh/blog/helm-v3-end-of-life を参照)
