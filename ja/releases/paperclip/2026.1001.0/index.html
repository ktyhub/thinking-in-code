#ペーパーclip v2026.1001.0

リリース日: 2026-10-01

Paperclip v2026.1001.0 は、2026.921.0-beta.1 から昇格した 77 のコミットを保持します。見出しは信頼性です。ネイティブ ランナーに対する徹底的な強化パスとチャットの回復 (レースの承認と停止、セッションの継続性、サンドボックスの再接続とクリーンアップ) とともに、アプリ全体にわたるエージェントのペルソナ、アニメーション化されたオンボーディング キャラクター、再構築された Slack セットアップなど、より親しみやすい顔つきです。これらの点については、エージェントがスケジュールされたレビュー ボットとして GitHub プル リクエストをレビューできること、Railway が管理された展開ツールを使用してコネクタ カタログに参加していること、アクティブな実行中にバウンスではなく承認と回答がキューに追加されていること、実行ハーネスがデフォルトで全自動になったことです。

重大な変更

  • 従来の Composio ブローカーは廃止されました。 API キー カタログ メソッド、ブローカー clients、セッション作成、アカウント同期、子ライフサイクルとツールキット ルート、および [サービス] タブはすべて削除されました。既存のレガシー Composio 接続は動作を停止し、自動移行は行われません。実験的な MCP アグリゲーター コネクタ (下記) が後継パスです。手動手順については、アップグレード ガイドを参照してください。ヴェルセルの出自はそのままです。 (#13758)
  • 実行ハーネスはデフォルトで全自動になりました。 ネイティブは、デフォルトの Claude/ACPX を approve-all に、OpenCode を allow に、Codex を承認とサンドボックスのバイパスに実行します。レガシー アダプターは同じポリシーに従います (プロバイダー ツールと接続ツールが含まれます)。明示的に設定された制限モードは保持され、Paperclip 独自の承認決定によりコントローラー権限が強制されます。 デフォルトのみが変更されます。制限的なプロバイダー ゲートを継承する未設定のエージェントに依存するオペレーターは、明示的モードを設定する必要があります。 (#13686、#13693)

ハイライト

  • エージェントが顔を取得 — 静的なペルソナ画像は、リスト、サイドバー、組織図、タスク、コメント、セレクター、アクティビティ、ダッシュボード全体のエージェント アイコンを置き換え、エージェント ヘッダー内の 1 つのアニメーション ポインター追従キャラクター (モーションの短縮とタッチ フォールバックを含む) と、エージェントの作成に組み込まれたペルソナの公開 (#13171) を使用します。オンボーディングは、ClipLab の眠くて目覚めるヒーローから始まります。キャラクターはセットアップ中はグレーで居眠りし、レビューではフルパレットで目覚めます (#13629)。 Slack セットアップでは、セットアップと設定の両方からエージェントのアバターをボット ID の PNG としてダウンロードできます (#13740)。
  • エージェントがプル リクエストをレビューします — ガイド付きセットアップにより、Paperclip エージェントが GitHub レビュー ボットに変わります。コピー可能な Claude/Codex プロンプトが、インスタンスの生成元 (#13717) とともにアプリのインストール、レビューのスケジュール設定、およびオプションで必要なチェックを実行します。 GitHub MCP 接続には、既存および新規接続用のアクション ツールセット (ワークフローの検出とディスパッチ) も追加されています (#13553)。
  • アクティブな実行中の承認と回答キュー — エージェントの実行途中での質問または承認への応答はバウンスしなくなりました。解決されたカードは不変の応答として実行キューに投影され、明示的な click は応答を互換性のあるネイティブ ターン (または新しいセッションの割り込み) に誘導し、型指定されたコンテキストは割り込みやクリーンアップの後も存続します (#13539)。
  • Slack セットアップ、再構築 — オンボーディングは、生成された作成リンクと読み取り専用マニフェスト、資格情報の検証、ライブ アカウント リンク ステータス、メンションベースのメッセージ テストを含む 6 つの clickable ステップに分割されます (#13638)。企業は、ターンごとのリマインダーなしで会話をタスクに導き (#13760)、クラウド プロキシの背後で正常性レポートを正しくコールバックする Slack 接続にコミュニケーション ガイダンスを添付できます (#13694)。
  • コネクタ カタログの拡大 — Railway には、OAuth セットアップと管理された展開ツールが付属しています。これには、サービスと展開のステータス、制限されたログ、ワークスペースで検証されたアクセスを備えた再展開/再起動/ロールバックが含まれます (#13415)。実験的な MCP アグリゲーター (Zapier、Arcade、Composio Connect、Executor) は、デフォルトでオフの enableMcpAggregators フラグの背後にあり、既存のボールト、許可、およびポリシー モデルを再利用します (#13755)。 You.com 検索は、サインイン、API キー、およびキーレスの無料枠 (#13555) を使用してセルフサービス カタログに参加し、CreateOS サンドボックス プロバイダー プラグインは、CreateOS HTTP API (#13434) に対して完全な環境ライフサイクルを実装します。
  • ルーチンで安全な Webhook を取得 — 運用トリガー ウィザードでは、スケジュールと Webhook の選択、ワンタイム認証情報、テスト配信受信、および元に戻せる削除 (#13637) が追加され、警告バナーは、ローカルホスト、プライベート ネットワーク、HTTP、Tailscale のサーブとファネルなど、パブリックにアクセスできない可能性がある Webhook URL にフラグを立てます。 (#13684)。
  • 業務および新人研修用のスキル - ランナー ツールは、完了したタスクの学習内容を会社のスキルに変換し、既存のスキル ポリシー (#13538) によって検証および管理されます。最初のオンボーディング タスクは、Claude と Codex でネイティブに呼び出される専用のスキルを通じて実行されます (#13517)。評価ガイドとスキル作成スキルがドキュメントに追加されています (#13535)。
  • プラグインはイメージ カタログを読み込みます — コードをインポートする前に、カタログ ID、限定パス、パッケージ バージョン、およびバンドル ハッシュが検証されます。イメージの選択は、削除とロールバックを伴う永続的なインストールに適用されます。永続的なアプリケーション オーバーレイは両方の UI シェルにマウントされます (#13646)。

修正

  • タスクの会話と UI — チャット コンポーザーは、一時停止ステータスのチェックが保留されている間、デスクトップで無効な状態で開始されることがなくなりました (安定版として早期に出荷されました 2026.916.1; #13562)。単一選択オプションを選択すると、ページが自動的に進むことなく質問に回答します (#13602)、すべてのコピー ボタンは、clipboard の書き込みが成功した後でのみ確認されるようになります (#13603)、再試行の開始を待機している間、タスク履歴は表示されたままになります (#13597)、最後に失敗した試行は後で自動で再試行可能です再試行はキャンセルされ (#13765)、接続サインイン画面ではファントム ステップの追加が停止されます (#13601)。
  • ランナーとネイティブ実行の信頼性 — ネイティブ ランナー全体にわたる広範な強化パス: 承認レースと停止レースはクリーンアップ中に正しく解決されます (#13750)、停止が認識される前に保留中の起動が待機されるため、遅いハンドルはプロバイダー ターンを送信できません (#13741)、プロバイダー セッションは同じ実行で完了する質問と承認の継続でターンをまたいで持続します。 (#13655)、タスク応答とウォーム プロセスの継続性は重複排除とヘルパー スレッド ノイズに耐えます (#13738)、エージェント チャットの回復はウェイク コメントの ID を維持し、古い再試行を拒否します (#13678)。サンドボックス操作もより堅牢になりました。コントローラーの再起動後にデイトナ セッションが PID 再利用防止採用チェックで再接続 (#13691)、フェンスで囲まれたクリーンアップ試行によるブリッジ損失後も終了が進行し続けます (#13287)、再起動によってアクティブになったリースがスイープされ (#13515)、継承された環境が検証され、古いサンドボックス バイナリが置き換えられ (#13677)、カタログ ランタイムとグレーディング境界が修復され (#13676)、補完ツールの拒否により欠落しているフィールドに名前が付けられ (#13682)、サーバー検証された割り当てファクトと狭い範囲のレビュー担当者ツールでネイティブ レビューの引き継ぎが完了します。 (#13581)。また、プラグイン ワーカーは課題ツリーの再開 (#13757) に達し、ワークスペース設定のないプロジェクトはオペレーターの分離のデフォルトを尊重します (#13636)、マネージド Git ランチャーはサンドボックス プロジェクトで動作します (#13588)、空の GROK_HOME はローカル Grok 実行のホスト ログインをマスクしなくなりました。 (#13570)、クロード ACP クォータ分類とリセット時間はアダプター境界まで存続します (#13651)。
  • 接続と通知の回復 - 認証とブラウザーの接続エラーが回復します。CONNECT_TIMEOUT は再試行ポリシーに参加し、WebSocket コンストラクターの失敗が処理され、会社のソケットがダウンしている間、表示されるクエリが 15 秒ごとにポーリングされます (#13724)。完了した実行の失敗により、再接続のたびに再通知が停止され (#13739)、管理されたセッションの再利用が維持されている間、チャットの遅延が低下します (#13710)。
  • サーバーの正確性 - PostgreSQL は、キューに入れられたクエリをウェッジするのではなく (#13643)、トランザクション接続が閉じられた後に回復します。不正な形式の JSON リクエストは、送信されたバイトをエラーやクラッシュ レポートにエコーする代わりに定数セーフ 400 を取得します (#13660)。データベース検索の前にハートビート実行 ID が検証されます。 (#13657)、エージェント チャット ビューはタスクのみのコネクタ読み取りをスキップします (#13654)、追いついたログ リーダーは過去 EOF 範囲エラー (#13592) ではなく空の読み取りを取得します。セントリー エラーはサーバーとブラウザの両方にロードされたソース リリースに起因します(#13719)。
  • クラウド インスタンス URL の正確性 — 外部チャットに渡されるタスク リンクは正確なパブリック URL (#13699) であり、チャットのセットアップ、テレグラム登録、および GitHub Webhook リカバリはすべて、自己ホスト型構成の優先順位が保持された、主張されたクラウド オリジンを使用します (#13680)。
  • CLI とローカル ログイン — オンボーディング ウィザードは、表示される空の入力を拒否する代わりにプロンプ​​トのデフォルトを受け入れ (#13520)、認証情報ファイルが見つからない場合は、macOS の分離されたクロード ログインがサフィックス付きのキーチェーン項目から読み取られます (#13519)。

改善点

  • 継続プロンプトは、正規の記述子 (#13574) 内に存在する質問ツールのガイダンスを使用して、レガシーおよびネイティブ ランナーの場合は短くなります。コネクタ設定コピーには「組織」と書かれています (#13589);チャット コネクタの UX 規則は、プロバイダー作成者向けに文書化されています (#13675)。 DeepWiki は 30 ページの寄稿者ハンドブックとして構成されています (#13745)。また、データベース パッケージは過去の霧雨スナップショットなしで出荷されます (#13687)。

アップグレード ガイド

  • 移行 0280 ～ 0283 はアップグレード時に実行されます (エージェント ペルソナ、ルーチン Webhook、Slack コミュニケーション ガイダンス、GitHub レビュー ボット)。
  • レガシー Composio 接続は削除され、自動移行は行われません (#13758)。実験的な enableMcpAggregators フラグを有効にすると、置換用の Composio Connect カタログ エントリが公開されるだけであり、既存の認証情報、許可、またはアクセス ルールは引き継がれません。 Composio を利用した統合を維持するには、フラグを有効にし、新しい Composio Connect MCP 接続を作成して承認し、そのアクセス ルールを再選択して、廃止された各レガシー接続レコードを削除します。それが完了するまで、エージェントは廃止されたツールにアクセスできなくなります。
  • 実行のデフォルトが完全自動に変更されました (#13686、#13693): プロバイダー側​​の承認ゲートを維持する必要があるエージェントに明示的な制限モードを設定します。
  • 他の構成や API の変更にアクションは必要ありません。
