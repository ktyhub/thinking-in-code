#ペーパーclip v2026.720.0

#紙clip v2026.720.0

リリース日: 2026-07-20

ハイライト

  • スキル スタジオとスキルの構成 - サンドボックス化されたテスト実行を備えた 3 ペインのスキル IDE により、Paperclip から離れることなくスキルを作成、編集、試用できます。スキルは、専用の「マイ スキル」ビューを備えたネストされたフォルダーに整理されるようになり、プロジェクトからスキルを直接インポートできるようになり、企業のスキル ポリシーはデフォルトでオープンになり、コア UX を強化して強化されます。会社のスキルフォークは着地前に事前チェックを実行し、マークダウン編集は適切なダーティトラッキングを受けて保存されます。 (#9241、#9235、#9356、#9633、#9620、#9564)
  • アテンション キューと決定 — 新しいアテンション キューと決定サーフェスにより、入力が必要なすべてが 1 か所にまとめられ、スクロールが速くなり、読みやすくモバイル対応の決定行が表示されます。 (#9380、#9468、#9472)
  • 検索の向上 — 検索には、コマンド パレットと同等のフィルター、並べ替え、演算子が追加されているため、どこでも同じ方法で問題やエンティティを検索できるほか、新しい一括抽出エンドポイントも追加されています。 (#9327、#9507)
  • より厳しい自己修復実行 - 再起動回復の実行、ワークスペースの自己修復、クォータを意識した再試行、失敗した実行のメトリクスにより、インスタンスは問題が発生する前にさらに努力することになります。復旧は障害の原因によってルーティングされるようになり、プロバイダーのクォータのリセットを待機し、シリアルの繰り返しを調整し、レート アラートで可観測性メトリクスをレポートします。計画承認の継続と外部待機の活性は、ウェイクが失敗しても持続し、解決されたブロッカーは、それらに依存するタスクを確実にウェイクアップします。 (#9183、#9331、#9373、#9229、#9634、#9635、#9651、 #9644)

改善点

  • サンドボックス実行 — ACP セッションは、Grok ローカル アダプターのサンドボックス サポート、構成テストと保存全体に適用されるカスタム イメージ スナップショット、および長時間実行作業用に 4 時間に引き上げられたサンドボックスの実時間バックストップにより、サンドボックス実行ターゲットで実行できるようになりました。 (#9390、#9338、#9385、#9232)
  • 問題モニターはどこでも表示可能 — 外部サービスと問題モニターがタスク サーフェイス全体および問題プロパティに表示されるようになったため、タスクが何を待機しているのかが一目でわかります。 (#9783)
  • シート内エージェント アクセスを備えたシークレット ダイアログの再加工 — シークレット ダイアログが再加工され、シート内でエージェントごとにシークレット アクセスを直接付与できるようになりました。 (#9797)
  • エージェントは受信ボックスを安全に整理できる — エージェントは、管理された受信ボックス アーカイブ アクセス ポリシーに基づいてユーザーの受信ボックスをアーカイブして整理できるようになりました。 (#9724、#9658、#9654)
  • アクティブな PR ガーデニング ワークフロー — 新しい PR ガーデニング ワークフローにより、オープンなプル リクエストが継続的に実行されます。 (#9510)
  • 安定したワークスペース サービス コントロール - ワークスペース サービス コントロール バーが安定し、開始/停止/再起動コントロールが予測どおりに動作するようになりました。 (#9705)
  • アクティビティ ログの責任ユーザーの帰属 - アクティビティ ログに責任ユーザーのスタンプが押されるようになり、問題の帰属が明示されます。 (#9731)
  • ブロックされた問題のより明確なメッセージ — メッセージがブロックされた問題を再度オープンしない場合、UI でその理由が説明されるようになりました (ルール C)。 (#9417)
  • キューに登録された実行の中断可能 — キューに登録された課題の実行を待機するのではなく、中断できるようになりました。 (#9725)
  • タスク レベルのモデル オーバーライドの明確化 — 課題のプロパティでタスク レベルのモデル オーバーライドが明確になりました。 (#9710)
  • デザイン システムの収束 — 単一ソースのデザイン トークン、ビジュアル回帰スイート、再調整されたテーマに加え、広範なカード/バッジの採用、乗算半径ラダー、および統合されたリスト サーフェス。タスク ステータスのグリフで Lucide アイコンが使用されるようになりました。 (#9134、#9240、#9395)
  • アクティビティ ゲート ルーチン — スケジュールされた実行は外部アクティビティに基づいてゲートできるため、実行すべき実際の作業がある場合にのみルーチンが起動されます。 (#9436)
  • ACP はローカル アダプタのデフォルト エンジンです - ローカル コーディング アダプタはデフォルトで ACP を通じて実行されるようになり、ローカル コーディング プロセスは安全のために制限され、Claude ACP client が更新されました。 (#9238、#9504、#9484)
  • 支出とコストのテレメトリ - ACP レーンの使用量とコストが支出テレメトリに取り込まれるようになり、価格のない CLI の使用量が記録され、資格情報の健全性の保持が文書化されます。 (#9471、#9505、#9248、@nickyleach)
  • 永続的な実行ログ — 実行ログは、永続的なオブジェクト ストレージを使用したストアにミラーリングされるようになりました。 (#8984、@stubbi)
  • コーデックスとモデルの更新 - Codex アダプター GPT-5.6 のデフォルトを更新し、Codex/OpenCode の選択に gpt-5.4-mini を追加しました (さらに OpenCode に openai/gpt-5.5)。 (#9352、#4357、@supertaz)
  • エージェント ランタイム イメージでの ripgrep の配布 - rg は、基本エージェント イメージですぐに使用できるようになりました。 (#8976、@stubbi)
  • 冗長ウェイクの削減 — 冗長な問題の再ウェイクが抑制され、実行コントラクトが新しいハートビートごとに 1 回挿入されるため、重複したトークンの消費が削減されます。 (#9470、#9469)
  • 未リリースのビルドのソース SHA を表示 — 正式リリースではないビルドでは、Git メタデータがなくても保存されたソース SHA が表示されるようになりました。 (#9508、#9638)
  • エージェント命令用の散文エディタ — マークダウン エージェントの命令では、散文エディタが使用されるようになりました。 (#9332)
  • ヘルスゲート型開発サービス — Paperclip 開発サービスは、開始する前にヘルスへの準備が整っている必要があります。 (#9269)
  • 環境の削除が強化されました — 環境の削除が強化され、削除の爆発範囲が表示されるようになりました。 (#9250、@nickyleach)
  • より高速なリリース検証 — リリース検証ワークフローは並列化され、npm レジストリ バージョン クエリはバッチ処理されます。 (#9168、#9202)

実験的

これらの機能は実験的な設定の背後でゲートされて出荷されます。実験的な設定でそれらを試すことができます。

  • MCP ツール ゲートウェイとアプリ — モデル コンテキスト プロトコル ツールに接続するための、第一級の管理された方法。名前付き MCP ゲートウェイがすべてのツール呼び出しを仲介し、管理されたアクセス コントラクトとツール アクセス ポリシーによって、どのエージェントとプロファイルがどのツールを使用できるかを決定します。また、新しいツール、プロファイル、およびアプリのサーフェスにより、UI から接続の配線、インストール、およびスモーク テストが可能になります。 (#9556、#9557、#9558、#9559、#9560、#9561、#9562、 #9563)
  • 組み込みのサマライザーとサマリー スロット - 組み込みのサマライザー エージェントとサマリー スロットにより、簡潔で常に最新のサマリーが UI に表示されます。 (#9713)
  • 意思決定トレーニング - 新しい意思決定トレーニング ライブラリとインスペクターを使用すると、意思決定のスナップショットをキャプチャし、視覚的なコンテキストを使用した意思決定のためのスナップショット基盤と画像ギャラリーに裏付けられた、エージェントが時間の経過とともにどのように意思決定を行うかをレビューできます。 (#9702、#9779、#9532)
  • Cases — 新しいファーストクラスの Case オブジェクトは、リリースやソーシャル スレッドなどの構造化されたドキュメントに裏付けされた記録を提供します。 (#9198)

修正

  • クロステナントの存在オラクルのクローズ — API は 403 ではなく 404 を返すようになり、別のテナントのリソースが存在するかどうかをリークしなくなりました。 (#3967、@stubbi)
  • より強力なパブリック招待 — 招待トークンのエントロピーが拡大され、パブリック招待エンドポイントのレートが制限されます。 (#8979、@stubbi)
  • apiCompression で認証が破損しなくなりました — gzip clients が破損したり、Better Auth 応答がドロップされたりする問題を修正しました。 (#9381)
  • React パフォーマンス トラックのメモリ リーク — 有効期間の長いタブでメモリ リークが発生していた React 19.2 パフォーマンス トラックの対策を達成しました。 (#9827)
  • 重複タスクや回復ループは不要 - 重複したタスクの作成と回復ループが防止され、繰り返し作成される重複が排除され、キャンセルされた生産性レビュー ループが停止されます。 (#9648、#9650、#5210、@YanisThePie)
  • 信頼性の高いホット リスタート - ホット リスタート実行の採用が復元され、ホット リスタート シャットダウンのデッドロックが修正されます。 (#9647、#9670)
  • 永続的な継続 - 受け入れられたインタラクション継続の回復は制限され、孤立した回復継続は復元され、ライブ継続中は古いハンドオフ アラームが抑制されます。 (#9656、#9630、#9695)
  • Codex 認証の強化 — 更新認証の失敗は分類され、ホストで使用できない Codex 認証のマージは失敗して閉じられ、Codex モデルは起動時に構成され、出力非アクティビティ タイムアウトは 30 分に延長され、生の子出力はアクティビティとしてカウントされ、シャドウされたサンドボックス認証にはフラグが付けられます。 Codex 認証マージ スクリプトは、アウトバウンド コピーバック ホームアセット リストア パスを使用してアダプターに移動されました。 (#9598、#9276、#9700、#9699、#9632、#9259、#9785、 #9787、#9788、@nickyleach)
  • AWS シークレットの失敗の説明 — AWS シークレットの作成の失敗は、サイレントに失敗するのではなく、UI で説明されるようになりました。 (#9645)
  • 定期的なキャッチアップの結合 — 1 時間未満のキャッチアップの実行は結合されるため、バックログが急増することはありません。 (#9649)
  • ワークツリー ポートの競合 - 再発するワークツリー ポートの競合が防止され、ランタイム環境が権限を維持しながらアダプタ環境がローカル エージェントに転送されます。 (#9642、#9617)
  • 検索と PR ガーデニングの強化 — 抽出一致制限が尊重され、PR ガーデニング候補の検出が強化されます。 (#9652)
  • 会社のスキルは責任ユーザーの許可を尊重します — 会社のスキル アクセスは責任ユーザーの許可を尊重するようになりました。 (#9571)
  • 意思決定カードは機械のコメントに存続します — 機械が作成したコメントは意思決定カードに優先しなくなりました。 (#9015、@nsolllazzo)
  • アダプターの PID 永続性 - onSpawn は、Hermes アダプターとプロセス アダプターに転送されるため、PID は永続化されます。 (#8722、@machjesusmoto)
  • 信頼性の高いプロセスのティアダウン — runChildProcess は、child.killed の trust ではなく、ライブネスに関する SIGKILL にエスカレーションされるようになりました。 (#8598、@justinltodd)
  • システム コメントが「あなた」として表示される — システムが作成したコメントが「Paperclip」ではなく「あなた」として表示されるようになりました。 (#6330、@BorClaw)
  • ハートビート アクティビティの属性を修正 - ハートビートの呼び出し/再開では、アクティビティ ログに run.id が使用されるようになりました。 (#3424、@tmartin2113)
  • プレフィックスを認識するエクスポート/インポート リンク — 会社のエクスポート/インポート リンクは、パス プレフィックスの背後で再びプレフィックスを認識します。 (#6648、@qbamca)
  • 空のプロファイル名を許容する — プロファイル/セッションの解析で空の文字列のユーザー名が壊れなくなりました。 (#8986、@stubbi)
  • ワークツリー修復 - ダーティおよび外部ブランチ実行ワークツリーが修復され、修復前にターゲットの認証が必要で、ワークツリーの実行はアクティブ化後にのみ開始されます。 (#9297、#9414、#9374)
  • ワークスペース ブランチ調整 - 自動転送実行ワークスペース ブランチ調整とそのルートを追加し、承認されたプランのワークスペース ブランチが子実現前にフリーズすることを回避しました。 (#9172、#9170、#9233、@nickyleach)
  • リクエスト ストームとポーリングの修正 — リクエスト ストームのポーリング ループ、問題リストの合体、共有ポーリング キャッシュの制限、会社のライブ実行リストのイベント ソース化、タブ メモリを増大させるライブ更新のチャーンの削減を修正しました。 (#9190、#9406、#9627、#9701、#9624)
  • ライブ実行の可読性とメモリ - ライブ実行のストリーミング テキストがより読みやすくなり、ライブ エージェント実行のトランスクリプト バッファーがバインドされたタブ メモリに制限され、マークダウン メンション オブザーバーがレンダリングごとに再作成されなくなりました。 (#9330、#9569、#3809、@LeonSGP43)
  • スレッドは固定されます — 閲覧中に問題のスレッドが最新のコメントにジャンプすることがなくなりました。 (#9354)
  • マークダウン レンダリングの修正 — レンダリングされたマークダウン リスト マーカーは表示されたままになり、番号付きリストの左側が切れなくなりました。 (#9359)
  • 受信箱とリストの洗練 — 受信箱の未読バッジで行がインデントされなくなり、未読バッジの位置が修正され、リストの形状が変更されても受信箱のホバーが j/k キーボードの選択と同期したままになります。エージェント名はモバイル エージェント インデックスに表示されたままになり、受信トレイ/タスク リストのネスト、ホバー パフォーマンス、およびルーチンの詳細が整理されました。 (#9767、#9685、#9680、#9236、#9317、#9383)
  • 環境の編集はルーティングされたページです — 環境の編集は独自のルートになり、ドラフトの損失を防ぐ詳細な未保存変更バナーが表示されます。 (#9386、#9391)
  • 実験の自動回復ダイアログ — 実験を有効にしても、UI が淡色表示になったりロックされたままになることはなくなりました。 (#9513)
  • カスタム イメージのセットアップ - カスタム イメージのセットアップでは適切な企業コンテキストが取得され、カスタム イメージのスナップショットはプローブに適用されたままになり、保存されます。 (#9028、#9385)
  • Reflection Coach と組み込みアセット - Reflection Coach アセットが見つからない場合でも起動がクラッシュすることはなくなり、組み込みエージェント アセットはサーバー ビルドに保持されます。 (#9351、#9339)
  • スキル ルートのユーザー シークレットの解決をスキップ — スキル ルートはユーザー シークレットの解決を試行しなくなりました。
  • タイムアウトは自己記述型 — acpx_local タイムアウトは自己記述型になりました。 (#9232)
  • サンドボックス ネットワークの回復力 - 停止した Daytona Git ネットワーク コマンドが高速で失敗するようになりました。

アップグレード ガイド

  • このリリースでは、新しい MCP ツール ゲートウェイ、ツール アクセス ポリシー、OAuth 状態、接続インストール、Smoke Lab、意思決定トレーニング スナップショット、サマリー スロット、受信箱アーカイブ ポリシー、および監査/アクティビティ属性のための追加的なデータベース移行の大規模なバッチが追加されています。移行は起動時に自動的に実行されます。手動での操作は必要ありません。
  • MCP ツール ゲートウェイ、ケース、意思決定トレーニング、組み込みのサマライザー、およびサンドボックスの実行は、実験設定の背後でゲートされています。実験的な設定で有効にして試してください。
