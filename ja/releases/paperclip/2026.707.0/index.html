#ペーパーclip v2026.707.0

#ペーパーclip v2026.707.0

リリース日: 2026-07-07

このリリースでは、8 人の寄稿者から 89 件のコミットが行われました。

ハイライト

  • ユーザー固有のランタイム シークレット - シークレットの範囲を会社だけでなく、人間のオペレーター個人に限定できるようになりました。ユーザー固有のシークレット定義を定義し、ユーザーごとの値を保存し、それらを環境にバインドします。さらに、新しい責任ユーザー実行属性のおかげで、Paperclip は、実行の背後にある人間が実行がディスパッチされる前に、実行に必要な値を実際に提供したかどうかを決定的にチェックします。これは、マルチユーザーおよびクラウドを安全に実行するための真の前提条件です。 (#8825、@cryppadotta)
  • 作業タイムライン - 会社を対象とした新しい作業タイムライン ページでは、エージェントがいつ作業したか、引き継ぎがどのように行われたか、作業が重複している場所を示すコンパクトなガント スタイルの SVG ビューが表示されます。そのため、実行を 1 つずつ開く代わりに、会社全体にわたる複数のエージェントの実行を一目でスキャンできます。タイムラインは、強化されたセキュリティ フィルターを備えた専用の企業エンドポイントによって支えられています。 (#8938、#8880、#8875、#8923、@cryppadotta)
  • 組み込みの SSH ターミナルを備えたカスタム サンドボックス イメージ - 再利用可能なカスタム サンドボックス イメージを構築し、ブラウザを離れることなくセットアップします。組み込みの SSH ターミナルにより、パッケージをインストールし、環境構成フローから直接イメージを準備できるようになり、カスタム イメージのスコープがインスタンス環境に限定されるようになりました。 SSH コマンドを外部端末にコピーする必要はもうありません。 (#8911、#8794、#8850、@devinfoley)
  • 再設計された環境変数エディタ - 従来の env-var エディタは、環境変数が設定されているすべての場所 (エージェント、プロジェクト、ルーチン、企業環境) で使用される単一の再利用可能なエディタに置き換えられました。テキスト値、シークレット参照、下書き行、および機密値の警告を一貫して処理し、プレーンな値をシークレット参照に変換するためのより明確なアフォーダンスを提供します。 (#8930、@cryppadotta)
  • 分岐した作業に対する 1 つの click リカバリ - リカバリ カードは、タスクのブランチがそのベースから分岐した場合に診断し、1 つの click 分離再発行を提供するようになりました。これにより、Git 状態を手動で解きほぐすことなく、スタックまたは競合した作業をリカバリできます。 (#9136、@nickyleach)
  • サイドバーのスター付きリソース - 最も頻繁に触れるプロジェクト、エージェント、タスクをサイドバーの専用のスター付きセクションに固定して、1 つの click アクセスを実現します。 (#9085、@cryppadotta)

改善点

  • オプションの Ramp スキル - 新しいオプションのカタログ スキルは、エージェントを Ramp の財務セットアップ プレイブック (アカウントのオンボーディング、カード、支出管理) に結び付け、すべてのアクションを Paperclip の承認ゲートとフェールクローズされたホスト許可リストに従属させます。企業はオプトインすることができ、レビュー担当者は、出荷された 1 つのカタログ エントリでソース モデルと安全ルールを確認できます。 (#9157、@cryppadotta)
  • 問題の詳細の読み込みが高速化 - 問題の詳細とアクティビティ台帳の応答は、ビューが実際に必要とするフィールドにトリミングされ、大規模な埋め込みプロジェクト、ワークスペース、ランタイム メタデータ ペイロードが削除されます。ワークスペースに関するアクティブな問題は、基礎となる永続モデルを変更することなく、著しく高速に読み込まれるようになりました。 (#9125、@cryppadotta)
  • ⌘K コマンド パレットでのプロジェクトの先行入力 - 一致するプロジェクトがコマンド パレットのタスクの上にランクされるようになりました。そのため、プロジェクト名を入力すると、タスクの下に埋もれるのではなく、そのプロジェクトに直接ジャンプし、プロジェクト名が常に行に表示されます。 (#8773、@scottong)
  • Gemini 3.1 Pro モデル - gemini-local アダプターは Gemini 3.1 Pro モデルを追加します。 (#1602、@woosal1337)
  • 実行ログ内のライブ ハートビートの進行状況 - ライブ エージェント実行ビューアーは、ハートビートの進行状況イベントをシステム ログ行としてレンダリングするようになりました。そのため、別のイベントが到着するまで非表示のままではなく、長時間の操作中に有用な進行状況テキストが表示されます。 (#8965、@devinfoley)
  • サンドボックス実行中のライブ フィードバックの向上 - サンドボックス実行では、実行中のエージェントのライブ フィードバックがより明確になります。 (#8915、@devinfoley)
  • 受信箱の行の子孫のライブ ステータス - 受信箱の行に子孫の作業のライブ ステータスが表示されるようになり、親タスクは子が実際に行っている内容を反映します。 (#8876、@cryppadotta)
  • オペレーターの問題のワークフローの洗練 - オペレーター向けの問題のワークフロー UI は、より明確なステータスと次のステップのアフォーダンスのためにクリーンアップ パスを取得しました。 (#9091、@cryppadotta)
  • よりクリーンな問題のプロパティ ペイン - 問題のプロパティ ペインはクリーンアップ パスを取得し、問題のメディア添付ギャラリーがサーフェス全体で統合されました。 (#8941、#8785、@cryppadotta)
  • パイプライン オートメーションのタイトル テンプレート - パイプライン オートメーションはタイトル テンプレートをサポートしているため、生成された問題には一貫したテンプレート化されたタイトルが付けられます。 (#8787、@cryppadotta)
  • 重複排除されたパイプライン自動化の健全性警告 - パイプライン自動化の健全性警告は重複排除されるため、同じ問題が複数回報告されることはありません。 (#9090、@cryppadotta)
  • 重複排除されたウォッチドッグ レビュー ウェイク - オープン ウォッチドッグ レビュー ウェイクは重複排除されるため、1 つのレビューによって繰り返しウェイクがトリガーされることはありません。 (#9148、@cryppadotta)
  • バンドルされた UI Web フォント - アプリは、実行時に UI Web フォントを取得するのではなく、UI Web フォントをバンドルするようになりました。そのため、インターフェイスは、オフラインまたはロックダウンされたネットワークでも一貫したタイポグラフィでレンダリングされます。 (#9020、@cryppadotta)
  • 読み取り専用診断エンドポイント - 新しい読み取り専用診断エンドポイントは、問題サブツリー、問題ブロッカー、およびワークスペース ブランチ祖先の状態を公開し、何も変更せずに作業が停止している理由を簡単に検査できるようにします。 (#9135、#9114、#9117、@nickyleach)
  • ブランチの一貫性の喪失の抑制 - マネージド ワークスペースは、ブランチの一貫性のない状況をカスケードさせるのではなく包含するようになりました。そのため、単一の不正なブランチの状態が下流の実行を妨げることはありません。 (#9131、@nickyleach)
  • より高速なアップグレード - 遅い問題コメントのアトリビューション バックフィルは、高速な冪等の移行に再配置されたため、アップグレードはより迅速かつ安全に再実行されます。 (#9108、@nickyleach)
  • チェックボックスの選択は継続ウェイクに引き継がれます - チェックボックスの選択は継続ウェイクに含まれるようになったため、タスクを再開するエージェントはユーザーが行った選択を保持します。 (#8893、@cryppadotta)
  • プラン レビュー コンテキストはウェイク後も保持されます - プラン レビュー コンテキストは、エージェントがウェイクアップされたときに保持されるため、長時間実行される計画作業のスレッドが失われることはありません。 (#8649、@cryppadotta)
  • 依存関係ウェイクの調整バックストップ - 調整バックストップにより、依存関係によるウェイクの信頼性が高まるため、ブロッカーが解決されたときにブロックされたタスクが立ち往生することがなくなります。 (#8943、@nickyleach)
  • ユーザーへの質問は置き換えられると期限切れになります - 保留中のユーザーへの質問は、後のコメントによって置き換えられると期限切れになるため、古いプロンプトが残ることはありません。 (#8799、@cryppadotta)
  • 正規化されたアダプター表示ラベル - アダプターの表示ラベルは、UI 全体で一貫した外観を保つために正規化されています。 (#8913、@devinfoley)
  • テレメトリ データ コントラクト - このリリースでは、文書化されたテレメトリ データ コントラクト、生成された client テレメトリ タイプ、およびインタラクション解決されたテレメトリ信号が追加されます。これは、より信頼性が高く、適切に型指定された匿名化された使用状況に関する洞察のための基礎となります。 (#8886、#8818、#8824、@nickyleach)
  • アクセシビリティの改善 - 課題ビューの切り替えボタンと目標ツリー展開ボタンは適切な ARIA 属性とツールチップを取得し、日付プリセット ボタンと曜日切り替えボタンは aria-pressed を公開するようになりました。 (#1937、#1939、#1913、@bluzername)

修正

  • 作業タイムラインのアクター アバター - アクター アバターは、欠落している画像や間違った画像を表示するのではなく、作業タイムライン上で正しくレンダリングされるようになりました。 (#9152、@cryppadotta)
  • iOS の受信トレイ アーカイブ ジェスチャ - 受信トレイのスワイプからアーカイブ コントロールは、行間で 1 つの保留状態ゲートを共有しなくなりました。そのため、モバイルで 1 つのアイテムをアーカイブしても、他の受信トレイ アーカイブ ジェスチャがスタックしていると感じることがなくなりました。 (#9154、@cryppadotta)
  • アダプターに依存しない構成キーの重複が解消されました - アダプターに依存しない構成キーは重複しなくなり、アダプターを切り替えてもエージェント構成はクリーンなままになります。 (#9058、@nickyleach)
  • アダプター タイプを切り替えてもスキル選択が保持される - エージェントのアダプター タイプを変更しても、すでに行ったスキル選択が削除されなくなりました。 (#8975、@fengwuqingchen)
  • 責任ユーザー移行の強化 - 責任ユーザー移行パスに対する一連の修正: 受信箱の再表示バックフィルが適切に修正され、移行タイムスタンプが修復され、ハートビート実行識別子の参照が正しく移行されます。そのため、アップグレード後に受信箱に古い作業が再表示されません。 (#9111、#9146、#9107、@cryppadotta、@nickyleach)
  • DB バックアップの健全性アラート - データベース バックアップの健全性アラートは、正常なバックアップを誤って報告するのではなく、再び正しく起動されます。 (#9147、@cryppadotta)
  • プロジェクトのないワークツリー ワークスペースは高速に失敗します - プロジェクトのない Git ワークツリー ワークスペースは、成功できない実行を開始するのではなく、ハートビートのセットアップ中に失敗するようになりました。 (#9118、@nickyleach)
  • ウェイク診断の編集 - ウェイク診断は、低 trust 識別子参照を編集し、untrusted 識別子が診断出力に漏洩するのを防ぎます。 (#9133、@nickyleach)
  • ソース インストールのバージョン レポート - ソース インストールは git メタデータからバージョンをレポートするようになったため、タグ付きビルド以外では実行中のバージョンが正確になります。 (#9103、@nickyleach)
  • OpenClaw ゲートウェイ プロトコル バージョン - OpenClaw ゲートウェイ アダプターは、ゲートウェイと一致するように PROTOCOL_VERSION を 4 に上げ、バージョンの不一致ハンドシェイクを修正します。 (#5984、@sparkeros)
  • UI でのクリーンなターミナル出力 -Hermes ターミナル出力では、UI パーサーの ANSI エスケープ コードが取り除かれているため、ログは生のエスケープ シーケンスを表示するのではなく、クリーンにレンダリングされます。 (#8731、@neerajdad123-バイト)
  • エージェント作成のコメントが正しく帰属される - エージェント作成のコメントは、「ボード」として表示されるのではなく、エージェントに帰属されるようになりました。 (#8833、@scottong)
  • アクセントバブルのマークダウンコントラスト - アクセント色のチャットバブル上にレンダリングされる低コントラストのマークダウンテキストを修正しました。 (#8689、@aronpris)
  • ワークスペースの再利用とブランチの一貫性 - 一連のマネージド ワークスペースの修正: 継承されたワークスペースの再利用は正しくフォールバックし、ファイナライズ時にクリーンなブランチ ドリフトが復元され、ブランチの一貫性回復が修正され、ワークスペースが再利用される前に実行構成が更新されるため、古い設定から実行が開始されません。 (#8963、#8914、#8826、#8797、@devinfoley)
  • サンドボックスの信頼性 - サンドボックス ブリッジの認証情報とレビューの回復の停止が修正され、サンドボックスの復元の失敗により適切な診断が行われるようになり、サンドボックス化されたクロードとコーデックスのプローブ動作が修正されました。 (#8844、#8903、#8775、@devinfoley)
  • アクティブなハートビートの実行 reaping - アクティブなハートビートの実行が誤って取得されることがなくなりました。 (#8776、@devinfoley)
  • 問題の作成応答関係概要 - 問題を作成すると、応答で正しい関係概要が返されるようになりました。 (#8901、@nickyleach)
  • ウォッチドッグ プロパティ ペインのキャッシュ - ウォッチドッグ プロパティ ペインの古いキャッシュを修正しました。 (#8786、@cryppadotta)
  • 古いサーバー情報デバッグ メタデータ - 古いサーバー情報デバッグ メタデータをクリアしました。 (#8753、@devinfoley)
