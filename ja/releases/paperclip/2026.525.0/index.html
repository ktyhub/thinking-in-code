paperclip v2026.525.0

#ペーパーclip v2026.525.0

#v2026.525.0

リリース日: 2026-05-25

ハイライト

  • モーダル サンドボックス プロバイダーはファーストパーティ プラグインになりました - Paperclip にはモーダル サンドボックス プロバイダー プラグインが同梱されているため、企業は E2B、Cloudflare、Daytona と並んでモーダルのマネージド サンドボックス上でエージェントを実行でき、CI 公開とコールドスタート対応のプローブ タイムアウトが組み込まれています。 (#6245、#6289、 #6290、@devinfoley)
  • ワークスペース差分は、第一級のビューア プラグインです - 新しいワークスペース差分プラグインは、分割/統合ペイン、スティッキー ヘッダー、および信頼性の高いデフォルトのベース参照を使用して、ホスト サービスとプラグイン スロットを通じて、ステージングされた変更、ステージングされていない変更、ヘッド変更、名前変更された変更、バイナリ変更、オーバーサイズ変更、および追跡されていない変更をレンダリングします。 (#6071、#6383、@cryppadotta)
  • ルーチンは独自のシークレットを保持できます - ルーチンの環境は、ログやアクセス イベントでシークレット値を公開することなく、永続的なリビジョン、agent < project < routine 優先順位、およびルーチン UI/履歴内の安全なシークレット メタデータを使用してランタイム コントラクトを通過するようになりました。 (#6212、@cryppadotta)
  • ローカル クラウド アップストリーム同期が含まれています - 新しいクラウド アップストリーム フローには、共有タイプ、サーバー ルート、永続化された実行スキーマ、CLI 同期ヘルパー、ボード UI、および設定エントリ ポイントが同梱されているため、オペレーターはプレビュー、競合の解決、ローカルからクラウドへの同期のアクティブ化を行うことができます。 (#6548、@cryppadotta)
  • ACPX-Claude アダプターは追加設定なしでシームレスに動作します - acpx_local アダプターは、ベア クロード モデル ID を解決し、不透明な「内部エラー」ログの代わりに実際の診断の詳細を表示し、ユーザーの ~/.claude/settings.json 権限を尊重するため、最初に実行されるクロード ローカル ACPX エージェントが立ち往生することはありません。 (#6590、@devinfoley)

改善点

  • スコープ指定されたエージェントのアクセス許可と割り当て制御 - 問題とエージェントの割り当ての変更は、保護された割り当ての強制、企業設定スロットとポリシー/許可管理用のプラグイン SDK/ホスト API、ブロックされた問題に対する今すぐ再試行するアフォーダンス、増分プリンシパル アクセス互換性バックフィルを備えた実際の承認サービスを通じて実行されるようになりました。 (#6386、@cryppadotta)
  • AWS プロバイダー ボールトのセットアップはオペレーターに優しい - シークレット ページでは、プレフィル、削除フロー、Storybook カバレッジを備えた AWS プロバイダー ボールトの検出が提供されるようになったため、外部ボールトの設定でメタデータを手入力する必要がなくなりました。 (#6381、@cryppadotta)
  • SecretBindingPicker はプラグイン設定フォームに接続されています - JSON-schema Secret-ref フィールド (E2B、Modal、Cloudflare、Daytona など) は、プレーンなパスワード入力の代わりに正規のシークレット ピッカーをレンダリングするようになったため、保存されたシークレットをバインドする際に UUID をコピー＆ペーストする必要がなくなりました。 (#6339、@devinfoley)
  • 外部エージェントの招待がエージェント追加モーダルに移動 - 自分のエージェントのオンボーディングが、OpenClaw 固有の企業招待設定の背後に隠れるのではなく、エージェント指向のプロンプト結果ビューと [戻る] ナビゲーションを備えたローカル/管理対象エージェント作成の隣に表示されるようになりました。 (#6183、@aronprins)
  • モバイル ボード フローがよりスムーズに感じられます - モバイルの新規発行ダイアログの高さ、優先度のオーバーフロー、会社設定のナビゲーション、プラグイン ルートのサイドバーの選択、ホーム画面アプリ モードのブラウザ コントロール、およびタッチ ターゲット/メニュー スクロールの小さなバグがすべて洗練されています。 (#6550、#6384、@cryppadotta)
  • プラグインのランタイムの範囲が会社に厳しくなりました - プラグインのワーカーからホストへの呼び出しはホスト所有の呼び出しコンテキストを伝播するようになり、performAction は認証されたアクター コンテキストを伝達し、会社の呼び出しスコープはブリッジ呼び出しに適用され、プラグインの操作の問題は通常の問題の表面から外れます。 (#6547、@cryppadotta)
  • ランタイムおよびテナントのインポート パスの信頼性が向上しました - 埋め込み Postgres は、CLI/サーバー/テストの起動前にネイティブ ランタイムをブートストラップするようになり、非同期テナント インポート ジョブの検証は遅延され、trusted クラウド テナントのインポートは、正規のサーバー間トラフィックに対するブラウザー起点のガードに失敗しなくなりました。 (#6549、#6378、@cryppadotta)
  • コントロール プレーンの状態遷移がより緊密になりました - 更新された問題リストでページネーションがきれいに並べ替えられ、スケジュールされた再試行コメントが動作し、保留中のプラグイン移行がホット リロード時に再適用され、プラグイン スキーマ ワークツリー シードが安全に復元され、ユーザーのコメント後に古いリクエストの確認が期限切れになり、データベース利用不可ループが発生することなくフィードバック エクスポートのシャットダウン ドレインが発生します。 (#6380、@cryppadotta)
  • チープ リカバリ モデルは実際の作業から隔離されています - ステータスのみのリカバリは明示的なガード コンテキストを保持するようになり、ルート ガードはチープ実行中の成果物の変更をブロックし、チープ プロファイルのヒントは通常のソース作業の再試行に漏れなくなりました。 (#6371、@cryppadotta)
  • 5 月 17 日のブランチ ランドからの招待フロー、プロジェクト、およびワークスペースの洗練 - 招待ランディングでは共有企業クエリ ヘルパーが再利用され、既存メンバーの招待動作とコピー フォールバックが復元され、再利用可能なワークスペース選択が正しく選択され、ワークツリー認証と静的 SPA フォールバックが修正され、マークダウン ラッピングとプラグイン スロット登録が強化され、プロジェクト ページの並べ替えが行われます。 (#6604、#6210、@cryppadotta)
  • サンドボックス プロバイダー プラグインがインスタンス設定を乱雑にしなくなりました - ドライバーのみのプラグイン (E2B、exe.dev、Modal) は、独自の設定ページがなく、すでに環境にリダイレクトされているため、プラグインごとのサイドバー グループから非表示になります。 (#6341、@devinfoley)
  • 受信箱の行がすっきりしました - 黄色の「計画中」の丸文字が IssueRow から削除されました。プランニング モード自体、コンポーザーの切り替え、および作業モードの契約は変更されません。 (#6269、@cryppadotta)
  • プラグイン作成ガイドは管理リソースを反映しています - プラグイン作成ドキュメントは現在の管理機能モデルに合わせて更新されているため、プラグイン作成者は古いガイダンスに反して作成していません。 (#6261、@cryppadotta)

修正

  • E2B ハートビートは 5/11 分で失敗しなくなる - ワークスペース tar アップロードでは、Linux 上で GNU tar が拒否した macOS LIBARCHIVE.xattr.* PAX ヘッダーが削除され、timeoutMs/sleepAfter が実行ごとに更新されるため、E2B および Cloudflare サンドボックスがハートビート間で期限切れになりません。 (#6560、@devinfoley)
  • サインイン後に招待ページが空白にならなくなりました - CompanyProvider と招待ランディング ページが単一企業のクエリ形状を共有するようになり、React Query のキーとキーの衝突による companiesQuery.data?.some is not a function のクラッシュが修正されました。 (#6433、@aronpris)
  • 会社の作成はラップされたプレフィックス衝突に耐えます - 再試行検出器は、companies_issue_prefix_idx 一意制約の Drizzle 0.45.x エラー原因チェーンをたどるようになり、500 回の代わりに生成されたプレフィックス衝突が再試行されます。 (#6423、@aronpris)
  • オートコンプリートは新規発行ダイアログ内で動作します - 本体レベルのポータルを通じてレンダリングされるフローティング オートコンプリート メニューは、許可されたダイアログ外部 UI としてマークされるようになりました。そのため、ポインタ イベントが食べられることなく、Radix Dialog 内で補完項目を選択できます。 (#6311、@cryppadotta)
  • paperclip worktree init --force は <repo>/.paperclip/worktrees/ をワイプしなくなりました - init パスは、<repo>/.paperclip/ ディレクトリ全体を再帰的に削除することを停止し、config.json と .env のみを書き換えるようになりました。 (#6240、@devinfoley)
  • 新しいシークレット フォームは長い値でも引き続き使用可能 - 共有 Textarea プリミティブは min-w-0 max-w-full を適用するようになり、長い解読不可能なシークレットによって [作成/キャンセル] ボタンが画面外に押し出されることがなくなりました。 (#6222、@devinfoley)
  • コールド スタート サンドボックス プローブがタイムアウトしなくなりました - environmentProbe ワーカー RPC タイムアウトが 120 秒に引き上げられるため、モーダル (および他のコールド スタート プロバイダー) はプローブが失敗する前に起動を完了します。 (#6289、@devinfoley)
  • Docker ビルドは link-plugin-dev-sdk.mjs を検出します - Dockerfile deps ステージは、pnpm install の前にスクリプトをコピーするようになりました。そのため、plugin-workspace-diff ポストインストール フックは Cannot find module で失敗しません。 (#6338、@devinfoley)
