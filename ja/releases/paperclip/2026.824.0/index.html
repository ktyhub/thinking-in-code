#ペーパーclip v2026.824.0

#紙clip v2026.824.0

リリース日: 2026-08-24

Paperclip v2026.824.0 は 2026.817.0 の後継であり、カナリア→ナイトリー→ベータ→安定したハッピーパスをエンドツーエンドで歩き、昇進前に 2026.818.0-beta.1 として浸った最初の安定版です。これには 172 のコミットが含まれています。チャット スタイルのタスクが実験からデフォルトのエクスペリエンスに移行し、マネージド ランタイム プレビューが Tailscale HTTPS 経由でアクセス可能になり、サンドボックスの実行で検証済みのプロバイダー機能契約が取得され、製品内から Claude と Codex にサインインできるようになり、大企業のインポートは接続が切断されても存続し、長年のコミュニティが修正した土地の大規模なバッチが含まれています。

重大な変更

これらはいずれも、通常のインストールではアクションを必要としませんが、アップグレードする前に必ず読んでください。

  • チャット スタイルのタスクがデフォルトです。 「チャット スタイル タスク」実験のトグルはなくなりました。タスクの詳細ページが全員の会話ビューになりました。新しい「クラシック タスク インターフェイス」設定 (enableClassicTaskInterface、インスタンス設定の enableTaskChatRedesign を置き換える) では、チャット前ページ (ページ レベルのヘッダー、プレーンなコメント スレッド、固定プロパティ サイドバー) が復元されますが、そこではチャットのみの機能は利用できません。 (#11101)
  • サンドボックス セッション出力ストリーミングは機能主導になり、3 つのオペレーター フラグがなくなりました。 サーバーの streamAgentSessionOutput 設定と Daytona プラグインの useSessions および useLogStream キーは存在しなくなりました。検証されたプロバイダー機能のスナップショットが唯一のストリーミング決定であり、自動ポーリング フォールバックが行われます。削除されたキーがまだ残っている保存された設定は正常にロードされます。キーは単に不活性なだけです。 (#11463、#11557)
  • マネージド開発ランタイムは、デフォルトで Tailscale HTTPS プレビューになりました。 ホスト ブローカーが利用可能な場合、対象となる Paperclip マネージド ワークツリー ランタイムは、ループバック HTTP ではなく tailscale_https として公開されます。 PAPERCLIP_MANAGED_RUNTIME_HTTPS=off を設定して古い動作を維持するか、force を設定してブローカーが見つからない場合にフェールクローズします。マネージド ランタイム制御ルートも 2 つの新しい 409 応答 (workspace_runtime_control_in_progress、workspace_runtime_lease_conflict) を取得しました。制御が常に開始されると想定していた呼び出し元は、競合を処理する必要があります。 (#11524、#11525)
  • 新しいインタラクションのインタラクション リゾルバー ポリシーのデフォルトは anyone です。 すべてのインタラクションの種類は、有効なエージェントをブロックするルートごとのルールではなく、来歴が記録された 1 つのリゾルバー ポリシー エバリュエーターを通過するようになりました。移行 0218 は、すでに保留中のものを意図的に拡張しません**。既存の行は古い制限を新しい名前で保持します (board_or_agents → not_creator、board_only → human_only)。 (#11376)
  • 意思決定トレーニング サーフェスが意思決定デスクから削除されます (トレーニング ライブラリ ルート、行アクション、ドロワー)。バックエンド スナップショット コントラクトは変更されず、データ移行は実行されません。 (#11225)

ハイライト

  • チャット スタイルのタスク、現在はデフォルトのエクスペリエンス — 前回のリリースの実験的な会話ビューは、すべてのタスクの動作方法になりましたが、途中で成長しました。よりクリーンなメッセージ間隔とエージェントのバブル、プロパティ ペインの検索可能な割り当てとサブタスク ツリー、横のガターにドッキングされたドキュメント コメント、およびすべての課題ドキュメントとエージェント アーティファクトを表示するチャット サイドバー。ブロックされたタスクには、そのブロッカーがライブの、順序付けられたブロッカー作業とのリンクとしてスレッド内で表示され、ライブ実行に関する問題には、誤ったアラームではなく、穏やかな進行中の通知が表示されます。オンボーディングもチャットファーストです。ウィザードを完了すると、最初のタスクの会話に直接進みます。そこでエージェントが挨拶し、明確な質問をし、項目ごとに承認する計画を提案します。 (#11101、#11263、#11226、#11456、#11487、#11423)
  • Tailscale 経由のマネージド ランタイムの HTTPS プレビュー - マネージド ランタイム サービスはプレーン ループバック HTTP でリッスンしていたため、エージェントのブランチ プレビューは電話や 2 台目のコンピューターからアクセスできませんでした。 Paperclip は、テールネット上の実際の HTTPS URL でそれを公開できるようになりました。これは、3 つの意図的なレイヤーで構築されています。すべてのマッピング (ピア資格情報、固定ポート範囲、保護ポートの拒否、追加のみの監査) を許可する個別の最小特権ホスト ブローカー、永続的な問題所有のランタイム リースと制限付きコントロールの回復による公開ライフサイクル (孤立したコントロールがレーンを永遠にブロックすることがないようにします)、および単一のポート ペア メディエーターにより起動が不可能になります。別の問題のサービスと衝突する、または別の問題のサービスを採用する — すべての不一致は解決されず、競合に名前が付けられます。 (#11524、#11525、#11526)
  • Paperclip 内からクロードとコーデックスにサインイン — 新しいエージェント ページでは、エージェントを作成する前に両方のテスト レーンでクロード サブスクリプション ログインが提供されるようになりました。診断は編集されたサーバー ログに保存され、ログイン URL は許可リストに登録された Anthropic ホストに正規化されます。内部では、保護されたセットアップ トークン フローが、所有者バインド セッションと 1 回限りのトークン配信を使用してサンドボックス擬似端末を介して claude setup-token を駆動し、Codex アダプターは同等のサンドボックス デバイス ログインを取得します。このサンドボックス デバイス ログインは、準備状況チェック後にのみ資格情報を昇格し、その後一時サンドボックスを削除します。 TLS 終端プラットフォーム エッジ (Railway、Render、Fly など) の背後にある展開では、CLAUDE_LOGIN_EDGE_TLS_TERMINATED=true を宣言できるため、トランスポート ガードがユーザーへの HTTPS 接続に関する警告を停止し、昇格されたデバイス ログイン資格情報が管理対象ホームの再シード後に存続するようになりました。 (#11347、#11286、#11237、#11579、#11578)
  • サンドボックス プロバイダー向けの実際の機能契約 — 前回のリリースでは、デイトナ用のライブ出力ストリーミングと永続セッションが導入されました。このリリースでは、これらの動作が設定されたものではなく証明可能になっています。プロバイダーはマニフェストで機能を宣言し、ライブ ワーカーがそれを検証し、サーバーは宣言、検証、構成の交差としてフェールクローズされた有効なセットを解決します。宣言された機能は、ワーカーが証明していないメソッドを許可することはできません。ストリーミングおよび永続セッションは、検証されたスナップショットが許可する場所であればどこでも有効になり、自動ポーリング フォールバックが使用され、それらをゲートするために使用されていた 3 つのオペレーター フラグがなくなりました (重大な変更を参照)。 (#11463、#11557)
  • 分割された再開可能な企業インポート — 前回のリリースでは、インポートの上限が 1 GB に引き上げられました。このリリースにより、移転する価値があります。接続が 90% で切断されると、アップロード全体が最初からやり直されていました。インポートは、耐久性のある実行台帳を使用してディスクにスプールされた ~32 MB の部分が検証済みとして移動されるようになりました。そのため、中断された転送は (切断された接続、ページの更新、サーバーの再起動をまたいで) アップロード済みの部分から再開され、ピーク時のアップロード メモリは 1 つの部分に減ります。インポート ページと CLI には再開可能なアップロードとチャンク プレビューが追加され、バンドルはエクスポート/インポートを通じてタスクのタイムスタンプと階層を保持するようになり、インポートされたエージェントは宛先の CEO アダプターに強制されるのではなく独自のアダプターを保持し、新しくインポートされたタスクは生産性レビュー スイープの下で静止したままになります。 (#11223、#11224、#11193、#11192、#11191)

改善点

  • オンボーディングはどこでも対応 — エージェントがいない企業は自動的にオンボーディングに送られ、適切なステップで開始されます。企業にすでにミッション ステップが存在する場合はミッション ステップはスキップされ、既存のミッションがウィザードに引き継がれ、ステップは途中の顧客の下にジャンプするのではなく一度決定されます。ウィザードのエージェントと接続モデルのステップがチャットファースト フロー用に作り直され、非表示の無効なアダプターが選択されたままになることがなくなり、装飾パネルがテーマに従います。 (#11352、#11416、#11429、#11371、#11379)
  • Paperclip クラウド オンボーディング シード — インスタンスは、Paperclip クラウドのサインアップ中に収集されたミッション、最初のエージェント、および最初のタスクを受信し、アクティベーション時に適用できるようになりました。これにより、シードされたスタックが開き、再度要求することなく作業できるようになります。 (#11098)
  • マネージド サンドボックス デプロイメント - テナントは、プラットフォームで管理されたサンドボックス環境 (およびそれだけ) で環境変数を編集できます。また、マネージド サンドボックス専用モードでは、実行選択がフェール クローズされてローカル実行が完全に隠蔽されます。バンドルされたプロバイダーの文書化された資格情報環境変数 (DAYTONA_API_KEY など) がプラグイン ワーカーに到達し、合成の「ローカル」デフォルト オプションがモードを尊重するようになりました。 (#11200、#11244)
  • アーカイブされた作業をその場で再度開く — アーカイブされた分離実行ワークスペースは、マネージド チェックアウト プロジェクトのアーカイブされた git ワークツリーを含め、元の場所から再度開くことができます。アーカイブされた企業の URL にコールドで到着した場合は、1-click Unarchive を使用してクリアなページにバウンスされます。 (#11322、#11395、#11302)
  • レビュー ガバナンス — レビュー ポリシーの評決はシリアル化され、トランザクション化されます。評決はダウングレードによってポリシーをバイパスできなくなり、要求者はアトミックに永続化され、承認を制約するものである場合、UI はレビュー ポリシーにバッジを付けます。 (#11405、#10938)
  • エージェントは名前でシークレットを検索できます — 読み取り専用の /secrets/catalog エンドポイントは、環境バインディングをワイヤリングするエージェントの ID にシークレット名をマップします — 値やプロバイダー設定はありません。問題文書の注釈もエージェントのレビューコンテキストに含まれるため、文書に残されたフィードバックは文書に対応するエージェントに届きます。 (#9530、#11332)
  • 拡張性のある検索 — 親問題ピッカーは、読み込まれたページではなくサーバー上で検索し、問題リスト API は updatedSince フィルターを取得しました。 (#11334、#9050)
  • 可観測性 - ホスト側の stage.sync ステップが計測され、エージェント プロセス スパンが正しくホーム設定され、前回のリリースのサンドボックス起動トレース作業が継続されます。 (#11301)
  • paperclipai channels でチャンネルを表示 — 新しいコマンドは、すべてのリリース レーン (安定版、ベータ版、夜間版、カナリア版)、それぞれが現在解決されているバージョン、およびインストールが従うバージョンを表示します。 (#11210)

修正

  • 認証プロキシの背後でのデプロイメントはエンドツーエンドで動作します — ライブ イベント WebSocket は、クラウド プロキシ ブラウザを認証するようになりました (以前は、認証終了プロキシを介して接続することはできませんでした)。Service Worker のフェッチ フォールバックは常に空のページではなく実際の Response で応答し、Web アプリ マニフェストは資格情報とともにフェッチされ、UI はコールド バックエンドに対する最初のロードに耐えます。リダイレクト ループでセッションをトラップする可能性のあるアーカイブされた会社選択ピンポンはなくなりました。 (#11290、#11292、#11245、#11246、#11300)
  • すべてのスコープはサインインしたアカウントに限定されます — 招待メンバーシップのチェック、会社の選択、およびクエリ キャッシュはすべて実際にサインインしているアカウントにキー設定され、キャッシュはサインアウト時にクリアされ、保存されている会社は会社の要求が失敗しても削除されずに存続します。オンボーディング ドラフトでは、このセッションで取得されたリストに対して所有権が検証され、ユーザーが所有していない会社のウィザード状態は決して復元されません。 (#11417、#11430、#11380、#11477、#11382、#11370)
  • セキュリティ強化 - ツールのアクセス ルートはクロステナント ID オラクルを漏らさなくなり、ルーチンの Webhook は HMAC リプレイを拒否し、ルーチンの詳細応答は担当者構成を除外し、ページ公開アップローダーの資格情報の範囲は公開ヘルパーに限定され、実行ワークスペースの概要は分離され、アクセス可能なワークスペース ファイルのリンクのみが強調表示され、ハートビート フォールバック コメントは生のトランスクリプトを公開できず、ユーザーに表示される CLI ガイダンスは安全な場所を通過します。 npx形式。 (#9589、#9994、#9818、#10894、#10790、#11090、#10143、 #11343、#11400)
  • 実行はコンテキストを保持します - エージェント セッションは実行ハンドオフ間で再利用され、問題のコメント間で保持されます。コメントウェイクの決定は挿入後の問題の状態を読み取り、完了した問題での古いクロージャ コメントのウェイクアップは停止し、成功した実行のハンドオフ リカバリではリカバリ アクション主導の実行とプラグイン管理の実行がスキップされ、ACP 実行ライフサイクル修正によって障害が解決され、ワークスペースが元に同期され、リースが適切にクリーンアップされます。 (#9917、#10111、#10068、#8656、#9010、#9047、#11454)
  • サンドボックスの配管復元力 — サンドボックスの stdin ファイル レースはアトミック書き込みとフォールト トレラント ポーラーで閉じられ、stdin 書き込みはプロセス セッション ブリッジで順序付けされ、コールバック ブリッジのポーリング ループには反復ごとのタイムアウトとウォッチドッグがあり、ブリッジ トラフィックはローカルのリッスン起点に転送され、エージェント雇用スキルのルートはコールバック ブリッジを通過し、プロバイダー ワーカーの再起動ウィンドウに達した実行はセットアップに失敗する代わりに再試行されます。 Daytona liveness 呼び出しは呼び出しごとに制限されており、syncOut は bsdtar tarball リストを受け入れます。 (#11235、#11406、#11341、#10017、#8978、#10212、 #11408、#11289)
  • アダプターの信頼性 - クロード ローカルは標準入力経由で印刷プロンプトをパイプし、root のみの権限スキップに失敗しなくなりました。 Codex ローカルは、フォールバック エラーを導出するときに無害な stderr 警告をスキップします。 OpenCode は、一時的な競合が発生した場合にモデルのプリフライトを再試行し、可用性プローブを致命的ではないものとして扱います。 Grok は、ハードコードされたゼロではなく、実際のトークンの使用量とコストを報告します。カーソル クラウドは、到達不能な API コールバックをドロップします。インスタンスが実行できないアダプターへの採用は拒否されます。アダプターは Windows にロードされます (動的インポートの前は pathToFileURL)。 (#9500、#9463、#10003、#9225、#10294、#10433、#8546、 #10256、#4287)
  • サーバーの正確性 - DELETE /api/issues/:id は依存関係の問題 (コメントと状態読み取りカスケード。コストと財務レコードは問題の参照がクリアされた状態で保持されます)、非 UUID 企業参照は 500 ではなく 404 を返し、パッケージ間 Zod エラーが認識され、PATCH 内の配線ブロッカーがブロックされた問題を暗黙的に再開しなくなり、未署名の ask-first リクエストがキャンセルされずにレビュー キューの外に留まり、ターミナル ワークスペースreaper は最も古い候補での枯渇を停止し、エージェント実行 JWT のデフォルト TTL は文書化された 48 時間に調整されるため、サスペンドされたラップトップの実行は期限切れの資格情報で起動しなくなります。明示的な PAPERCLIP_API_URL は run env の派生ランタイム URL をオーバーライドし、ベース URL ポートはループバック ホストに対してのみ書き換えられ、Hermes フロー サーフェスでサイレント非ゼロ終了は失敗として終了します。 (#11331、#9959、#10168、#10269、#11338、#11238、 #10176、#10339、#10258、#10107)
  • ワークスペース Git スキャンは制限されています — 1 つの制限付きスケジューラーが、すべての高価なワークスペース Git スキャン (かつてはリクエスト ストームにより最大 270 の同時 git status プロセスが発生し、ヘルス チェックが不足していました) を結合して制限し、ブラウザはファイル パネルが開いて表示されている場合にのみスキャンを開始します。 (#11572)
  • UI ペーパー カット - キューに入れられたメッセージの割り込みアクションが復活し、エージェント シークレット アクセスが検索可能なシークレット タブに移動され、ダイアログ内のスラッシュ オートコンプリート スクロール、受信トレイ アーカイブでアンドゥ トーストが取得され、折りたたまれたサブタスクが記憶され、受信トレイ ルーティングで明示的なターゲットの保存ポリシーが尊重され、委員会の承認散文がマークダウンとしてレンダリングされ、作成ダイアログ バッジで実際の問題のプレフィックスが使用され、問題ドキュメントのディープ リンクが正しくルートされ、切り詰められた問題の説明にフラグが付けられ、招待リンクが生成されます。公開ベース URL が優先され、選択された実行ライフサイクルとログは最新のままになり、モバイル タスク チャットにはブロッカー アクションが追加され、コンポーザーはスレッドと連携し、新しいタスク ダイアログはキーボードの上に表示されます。 (#11374、#11283、#11222、#11220、#11069、#11221、 #9817、#8550、#11551、#4771、#7619、#10169、#11282、 #11296、#11281)
  • 奇数と終了 — スキル同期はプロジェクト フォルダーを置き換えるのではなくその場で更新し、ボード キーによる問題の書き込みは担当者に関係なく機能し、環境シークレット バインディングは最初の保存時に会社のコンテキストを解決し、埋め込み Postgres データ ディレクトリが OS 一時ディレクトリにある場合はワークツリー モードの開発インスタンスが警告します。 (#11066、#9025、#11291、#8283)

アップグレード ガイド

  • 移行: このリリースでは 11 のデータベース移行 (0212 ～ 0222) が追加され、会社ごとに 1 つのオンボーディングの最初のタスク (0212)、再開可能な会社の転送実行 (0213)、アダプター デバイスのログイン セッション (0214、0215)、クラウド オンボーディング シード (0216)、発行と削除の外部キー ポリシーが含まれます。 (0217)、インタラクション リゾルバー ポリシーのデフォルトと来歴 (0218)、ランタイム公開状態 (0219)、実行ワークスペースのランタイム リース (0220)、クロード セットアップ トークン セッション (0221)、および環境の削除後も存続する環境リース参照 (0222)。移行は起動時に自動的に実行されます。手動での操作は必要ありません。テーブルを削除したり、データを削除したりすることはありません。 0218 は既存の保留中のインタラクションのリゾルバー ポリシー値を (保守的に - 「重要な変更」を参照) 書き換え、0217/0222 は削除時に依存する行の処理を変更することに注意してください。
  • 新しいオプションの環境変数 (すべてに適切なデフォルト値があり、必要な場合にのみ設定します):
    • PAPERCLIP_MANAGED_RUNTIME_HTTPS — auto (デフォルト)、off、または force。マネージド ランタイム プレビューの Tailscale HTTPS のデフォルトを制御します (重大な変更を参照)。 PAPERCLIP_TAILSCALE_BROKER_SOCKET および PAPERCLIP_TAILSCALE_DNS_NAME は、ブローカー ソケット パスとテールネット DNS 名をオーバーライドします。 PAPERCLIP_VITE_HMR_PROTOCOL (ws/wss) は、開発プレビュー HMR プロトコルを固定します。 (#11524、#11525)
    • CLAUDE_LOGIN_TRUSTED_PROXIES — クロード ログイン トランスポート ガードのホワイトリストに登録されたプロキシ ピア。 CLAUDE_LOGIN_EDGE_TLS_TERMINATED=true — プロキシ アドレスが不明な管理プラットフォーム上でプラットフォーム エッジ TLS 終端を宣言します。 (#11286、#11579)
    • PAPERCLIP_ONBOARDING_SEED_ADAPTER_TYPE — クラウド オンボーディング シードによって作成されたエージェントのアダプター タイプ。 (#11098)
    • SANDBOX_ORPHAN_CLEANUP_SPOOL_DIR — 耐久性のあるサンドボックス クリーンアップ レコードがスプールされます。 PAPERCLIP_PROCESS_SESSION_STDIN_MAX_RETRIES — サンドボックス標準入力ポーラーの上限を再試行します。 (#11347、#11235)
  • 設定キーの削除: streamAgentSessionOutput (サーバー) および useSessions / useLogStream (Daytona プラグイン) は何もしなくなりました。保存された設定から好きなときに削除してください。それらはロードされますが、不活性です。 (#11557)
  • エージェント実行 JWT TTL: サーバーのデフォルトは、文書化された 48 時間 (PAPERCLIP_AGENT_JWT_TTL_SECONDS=172800) と一致するようになりました。以前の暗黙的な 1 時間の有効期限に依存していた場合は、変数を明示的に設定します。 (#10176)
  • HTTPS プレビュー: 使用するには、ホストに Tailscale をインストールし、新しいブローカーを実行します (@paperclipai/tailscale-https-broker README を参照)。オプトアウトするには、PAPERCLIP_MANAGED_RUNTIME_HTTPS=off を設定します。アンマネージド サービスまたはカスタム サービスの場合、他に何も変更はありません。
