#ペーパーclip v2026.529.0

#v2026.529.0

リリース日: 2026-05-29

ハイライト

  • インライン文書の注釈とコメント - 問題文書は、コメントと安定したアンカー スナップショットを備えたインラインのリビジョン対応注釈スレッドをサポートするようになりました。そのため、エージェントとオペレーターは、切り離された問題コメントを残したり、文書全体を編集したりする代わりに、特定の文章について話し合うことができます。 (#6733、@cryppadotta)
  • 企業スキル CLI とカタログ管理 - スキルは最上級になりました。新しい CLI とボード UI を使用して、企業スキルのインストール、リセット、監査、エクスポート、割り当てを行うことができます。これは、パッケージ化されたスキル カタログと、バンドル、カタログ、ランタイム、アダプター提供のスキルにわたる明確な来歴モデルに裏付けられています。 (#6782、@cryppadotta)
  • サイドバーからプロジェクトとエージェントを非表示にする - ユーザー スコープのリソース メンバーシップにより、各ユーザーはサイドバーを乱雑にしたくないプロジェクトとエージェントを離れることができ、同時にすべてのリソースにアクセスできる状態を維持できます。企業スコープのメンバーシップ API と、よりクリーンでスキャンしやすいプロジェクト リストに支えられています。 (#6677、@cryppadotta)
  • 新しいセルフホスト展開の最初の管理者の要求フロー - プライベートの要求されていない展開 (LAN 上の Umbrel インストールなど) は 1 回限りのブラウザー要求を取得できるようになりました。これにより、オペレーターは招待が存在する前に最初の管理者を作成できますが、パブリックな展開とアクティブな招待のあるインストールでは、既存の招待のみのモデルが維持されます。 (#6755、@cryppadotta)
  • ライブ クロード モデル検出 - クロード ローカル アダプターは、UI からその Anthropic モデル カタログを更新できるようになりました。そのため、新しくリリースされたクロード モデルは、コードのリリースを待たずに表示されます。静的フォールバック リストはセーフティ ネットとして最新に保たれます。 (#6953、@cryppadotta)

改善点

  • バンドルされたプラグインがプラグイン マネージャーに表示されるようになりました - [インスタンス設定] → [プラグイン マネージャー] には、インストールされている外部プラグインと一緒に組み込みのバンドル プラグインがリストされるため、利用可能なプラグインの完全なセットが 1 か所で表示されます。 (#6734、@cryppadotta)
  • より厳格なワークスペース ライフサイクル保証 - ワークスペースのファイナライズ ゲートと非リモート Git 強制により、ワークツリー コントラクトの穴が塞がれます。担当者間でのサイレント環境の再利用はなくなり、ファイナライズが完了する前に依存する問題のウェイクが発火することはなくなり、issue.interaction.accept はファイナライズを待機します。そのため、依存する問題は一貫したワークツリーを確実に認識できます。 (#6969、@devinfoley)

修正

  • 承認された計画は 1 回だけ分解されます - 承認された計画のリビジョンは、重複する実行で複数回分解できないように保護されるようになり、エージェントがレビューの決定から目覚めて分離されたワークスペースを再利用したときに発生する可能性のある重複サブタスクのファンアウトが修正され、さらに明確な計画分解 UI 状態が修正されました。 (#6831、@devinfoley)
