#ペーパーclip v2026.831.0

#紙clip v2026.831.0

リリース日: 2026-08-31

Paperclip v2026.831.0 は 2026.828.0-beta.0 として浸され、175 のコミットを保持します。企業のスキル ライブラリが実行時にエージェントに実際に届くようになり、Kimi Code がアダプターのラインナップに加わり、他のユーザーのために Paperclip をホストするオペレーターがユーザーに表示される設定サーフェイスを実際に制御できるようになり、サンドボックス コールバック ブリッジが境界付き HTTP/2 トランスポート上に再構築され、オンボーディングはミッション ステップを省略して、エージェントの最前線および中央との短い円弧を実現します。また、Node.js フロアも 24 に引き上げられます。ソース インストールを更新する前に、アップグレード ガイドをお読みください。

重大な変更

  • Node.js 24.11.0 以降が必要です。 すべてのパッケージ マニフェストは新しいフロアを宣言し、Docker イメージはノード 24 に出荷されます。古いノードでは管理インストール (paperclipai install) のみが完全に拒否されます。 npm がインストールされ、ノード 22/23 で直接起動されたサーバーは、サポートされていないバージョンの警告を出力して続行します。警告はサポートされていません。このリリースを使用する前にノードをアップグレードしてください。 (#11792、#11890)
  • 無効なエージェント資格情報は、ダウングレードされずに拒否されます。 検証に失敗したベアラー トークンは、匿名のローカル ユーザー アクターに黙って到達するのではなく、原因 (期限切れ、検証不能、終了したエージェント、間違った会社など) を示す 401 を返すようになりました。そのフォールスルーに依存していた統合では 401 が発生し始めます。そのフォールスルーがバグでした。 (#11589)
  • 会社のブランドの色と会社ごとの添付ファイルのサイズ制限がなくなりました。 会社の全般ページ、API の作成/更新、および移植性マニフェストからフィールドが削除されました。移行 0229 は列を削除します。古いフィールドを含むエクスポート バンドルは引き続きインポートされます。値は無視されます。 (#12291)
  • サイレント ラン検出は、独自のアクションを実行しなくなりました。 出力サイレンスは、UI のアクティブ ラン サマリーで依然として疑わしい/重大なレベルとして表示されますが、評価の問題、回復アクション、コメント、またはウェイク リクエストは作成されなくなりました。孤立したタスクのリカバリも同様に自動テイクオーバーを停止します。使い果たされ安全でないリカバリは、作業を単独で再割り当てするのではなく、ボード所有のアクションにルーティングされるようになりました。 (#12242、#11961)
  • エージェントの思考テキストは自動問題コメントには含まれません。 ACPX 実行サマリーは最終出力セグメントに限定され、従来の完全なサマリー設定は意図的に無視されるため、構成は封じ込めをバイパスできません。 (#11801、@nearfolk)
  • Grok はデフォルトで --permission-mode を dontAsk に設定しなくなりました。 アダプターは、明示的に構成されていない限り、許可モード フラグを渡しません。 --always-approve は無人ポリシーのままです。 (#11898)

ハイライト

  • スキル ライブラリがエージェントに届くようになりました — スキルは以前はインストールして期待していたものでした。現在、すべてのエージェントの実行には、会社のスキル ライブラリの決定的なマニフェストが指示に含まれており、エージェントは MCP を介してスキルをリストでき、新しく採用された CEO はデフォルトで 5 つのコア Paperclip スキルを取得し、スキルをインストールすると、スキルを備えたすべてのエージェントを事前に選択する「エージェントを有効にする」ステップが提供されます。スキルの実現に失敗すると、スキルが静かに消滅するのではなく、その失敗が原因とともに実行出力に表示され、レガシー ランナーは正規の運用スキルに固定されます。 (#12147、#12138、#12136、#12146、#12225)
  • キミ コードはファーストクラスのアダプターです — kimi_local は、デフォルトで共有 ACP エンジン上で Moonshot の キミ コード CLI を実行します。ライブ ストリーミング トランスクリプト、ツール呼び出しライフサイクル、Claude、Codex、Gemini と同じ機構です。ACP の前提条件が欠落している場合は、自動的にヘッドレス CLI フォールバックが行われます。 (#9967、@hawikk)
  • オペレーターはユーザーに表示される内容を形作ることができます — 他のユーザーのために Paperclip をホストしている人向け: PAPERCLIP_HIDDEN_SETTINGS は、キーごとに設定画面を非表示にします。インスタンス ページ、個々の実験フラグ、メンバー、招待、シークレット、エクスポート、インポートなどの会社ページ、さらにはプロバイダー ボールトやプロポーザルなどの個別のタブです。 company.import を非表示にすると、API もフロアになり、クラウド管理インスタンスは無条件でインポートされます。 PAPERCLIP_SETTING_DEFAULTS は、選択したインスタンス設定のスキーマのデフォルトを何も永続化せずにオーバーライドし、マネージドサンドボックス専用モードはホストパスと実行エンジンの表面を完全に非表示にします。 (#11823、#12199、#12284、#12285、#12293)
  • フォールオーバーしないように再構築されたサンドボックス コールバック ブリッジ — サンドボックス エージェントが Paperclip にコールバックできるようにするブリッジは、制限付きノード HTTP/2 二重トランスポートを優先し、ファイル ポーリング リレーをソフトで非推奨のフォールバックに降格します。バイトはエンドツーエンドでバイナリのままで、すべてのリソース ディメンションはプロセス所有のバイト台帳 (ルート データ、ブローカー転送、デコーダ バッファ、保留中) によって割り当てられます。書き込み）、サンドボックス内ゲートウェイは準備が整った後は障害を生き延びますが、その前に大きな障害が発生し、実行中に二重チャネルが停止すると失敗し、書き込みが失われ「正常に」終了するのではなく実行が閉じられます。廃止された v1 トランスポートは完全に削除されます。 (#12120、#11769、#12003、#12060、#11966、#12171)
  • オンボーディングが要点に達します — ミッションのステップは終わりました。ウィザードはエージェントの作成時に開きますが、名前だけを求められます (すべてのオンボーディング採用は general ロールで始まります)。ステップは、ブランドの錠剤が挟まれた状態で 1 枚のカード上に再構築されます (セットアップ中は休止状態ですが、確認すると有効になります)。また、認証ページには新しいブランドのロックアップが適用されます。アイドル状態の「環境をテストする」カードもなくなりました。プローブは引き続き Connect 上で実行され、失敗した雇用をブロックします。 (#11935、#11905、#12274、#12074)

改善点

  • Sentry によるオプトイン エラー監視 - SENTRY_DSN を設定し、オプションの @sentry/node ピアをインストールして、サーバー側のエラー キャプチャを取得します。 DSN は認証されたセッション応答に乗るため、ブラウザーも React エラー境界の背後で報告します。すべてがフェールオープンです。DSN もパッケージも Sentry も問題ありません。 (#12190、#12249、#12270)
  • 企業の輸入がより良く着陸できるようになりました — 前回のリリースにより、大規模な輸入が再開可能になりました。このリリースにより、到着が楽しくなります。インポートされた企業の名前は重複除去され、インポート済みのバンドルにはランディングされた企業の名前が付けられ、すべてのインポート結果はダッシュボードの CTA で終了します。インポートによって一時停止されたエージェントには、スレッド内に表示される通知と再開ボタンを備えた専用の一時停止理由が表示されます。インポートされたエージェントが一時停止している間、ダッシュボードには「すべて再開」のバナーが表示されます。 (#12145、#12144、#12143、#12140、#12142)
  • 設定、統合 — 会社とインスタンスの設定は 1 つのナビゲーションを共有します。インスタンスの一般コントロールは会社の「一般」ページにあります。招待はメンバーページのタブに移動されました。個別のインスタンスのハートビート ページはなくなりました。ユーザー向けのコピーには、以前は「会社」と表示されていたものが「組織」と表示されるようになりました。ホストされているテナントは、名前変更後に組織名から派生した発行プレフィックスも取得します。 (#11789、#12289、#12282、#12243、#12292)
  • 実際に管理できる環境 — 環境を削除すると、その手順が表示されるようになりました。エージェントは同じアクションで再割り当てされ、リース所有者がリストされ、再利用可能なサンドボックスの破棄は同意ラベル付きの別個の選択肢となります。カスタム イメージ テンプレートはブート関連のドリフトを属性付きで報告し、1 つの click で再リンクでき、管理されたデフォルト環境はドライバー キーではなく名前 (「Paperclip Computer」) で表示されます。 (#12053、#11751、#11641、#11838)
  • サンドボックス ファイルの移動の高速化 — 受信ワークスペース、アセット、および参照プロジェクトの同期は、プロバイダーがオプトインする場合に並行して実行され、デイトナ ファイルのアップロードは、生のフォールバックを使用して透過的に zstd 圧縮されます。参照プロジェクトはステージング中に最終的に .gitignore を尊重し、報告された転送バイト数は実際のものです。 (#11736、#12271、#12184、#12180)
  • 管理されたワークスペースは再起動後も持続します — リース ハートビートと ID チェックを備えた共有ポート レジストリにより、コントロール プレーンの再起動後もランタイムの信頼性が維持されます。劣化した組み込みデータベースは検出され、制限付き再起動監視によって置き換えられます。クローン化されたワークツリーは、オリジナルと競合するのではなく、コピーされたサービスを隔離します。遅延データベース シードは、検証済みの証拠を備えた最上級の操作であり、ワークスペース ログインのハンドオフは、実際の準備状況に応じてゲートされた署名付きの使い捨てチケットです。 macOS ワークツリーもポート所有者を採用できるようになりました。 (#11740、#11651、#11653、#11706、#11671、#11763、@tf00185077)
  • ウェイクとリカバリがより正確になりました — 質問の回答は専用の配信台帳を通じて永続的に配信され、ブロッカーが解決されたウェイクはレベルでトリガーされ、サイクルを認識するため、ターミナルのリセットによって依存関係が取り残されることはありません。リカバリの再試行は制限されたリネージでの再起動後も存続し、失敗したルーチンの実行は作業が再開されると一時的に自動的にクリアされ、エージェントの再開は直接許可を通じて許可されます。 (#12307、#11732、#11979、@zach-hermes、#11817、#9689、#12047)
  • 生活の質 - 「エージェント モード」は、モード チップに完全なラベルが付けられた「自動モード」になり、すべての受信トレイ アイテムをアーカイブでき、ハード リフレッシュが行われるまで古い UI を提供するのではなく、保留中のブラウザ タブで 1 時間以内に新しいリリースが取得され、開発ランナーは --data-dir 分離を尊重します。 (#11866、#11636、#12198、#12193)
  • 基礎、意図的にオフ — ネイティブ Codex 実行ランナー (アダプター paperclip_runner) は、永続性コントラクトとトランスポートとともに、デフォルトでオフの enableNativeRunner インスタンス フラグの背後に配置されました。雇用を拒否し、旗が消えている間は走ります。既存のアダプターについては何も変わりません。 (#12188、#12169、#12176)

修正

  • サインアップとサインインは Better Auth 1.7 で動作します - アップグレードには Better Auth が期待する issuer 列が必要でした。移行 0230 はそれを追加してバックフィルします。 (#11886、#12396)
  • リッチ テキスト エディターが再度レンダリングされます — 古いオーバーライドからの 2 番目の語彙コピーにより、ノードのアイデンティティが壊れました。ツリーは 1 つのピン留めされたコピーに戻り、山かっこを含む散文によってリッチ エディターから追い出されることがなくなりました。 (#12317、#12290)
  • Docker 孤児が刈り取られる — tini はサーバー イメージの PID 1 であるため、親の終了後に採用されたプロセスはゾンビとして蓄積されるのではなくクリーンアップされます。 CI の動作プローブがそれを維持します。 (#12137、@zannis)
  • アダプター — Hermes は、プレースホルダー (#9237, @harjothkhara) の代わりに、reasoning.available イベントからの実際の推論テキストを表示します。 Grok は、デフォルトのモデル センチネルが検出されたリストにない場合、警告を停止します (#12062)。 Claude/Codex/Gemini ACP アダプターは 1 つのワークスペース復元ティアダウン (#12196) を共有します。アダプターのテスト レーンは、デフォルトで拒否されたプローブ環境を使用して、すべてのクロード ACP ターゲットの認証を検証します。 (#11810)
  • プラグイン - エラーが発生したプラグインは停止したままではなく起動時に再試行され、プラグインの詳細タブのディープ リンクはリロード後も存続し、プラグイン バンドルはホストの実際の JSX ランタイムを取得します。 (#12054、#11826)
  • タスク チャット — コンポーザーは送信した瞬間にクリアされ (失敗すると下書きが復元されます)、ライブ テールには「トランスクリプトを待っています...」の代わりに実行の実際のステータスが表示され、キャレットが並びます。 (#11772、#11802)
  • Git ワークスペースの同期 - 共通の祖先を持たないインポートされた履歴は実行に失敗する代わりに移植され、同期によって作成されたマージ コミットには決定的な ID が保持され、PR の準備は既存のブランチに触れることなくアタッチできます。 (#11638、#11637、#11703)
  • サーバーの正確性 — イメージ アップロードの名前空間は、トラバーサルが完全に拒否されたアイデンティティ プロバイダー文字を受け入れ、セットアップ トークンの開始ガードは提供されるアダプターに固定され、サンドボックス ドライバー環境はホスト プロビジョニング コマンドをスキップし、レンダリングされたマークダウン コード ブロックはアクティブなテーマに従い、ワークスペース リーパーはターミナル ワークスペースのワークツリーを収集する前に構成可能なクールダウンを取得しました。 (#12288、#12179、#11626、#11591、#11642)

この範囲のオンボーディング サービス修正 (クラッシュ ループ バックグラウンド サービスを残すオンボード npx、重複したフォアグラウンド開始プロンプト、ダッシュボードを開かないでオンボーディングが終了する) は、v2026.824.1 として安定したユーザーにすでに出荷されています。

アップグレード ガイド

  • Node.js: 最小値は 24.11.0 になりました。 Docker ユーザーは、イメージ付きのノード 24 を取得します。ソース インストールとカスタムのベース イメージを最初にアップグレードする必要があります。古いノードでは管理インストールがエラーで拒否されます。 npm インストールとノード 22/23 での直接サーバー起動では、警告と続行が行われます。これはサービス ログで見逃されがちです。警告に頼るのではなく、アップグレードする前に node --version を確認してください。
  • 移行: このリリースでは、8 つのデータベース移行 (0223 から 0230) が追加されます: シークレット提案 → インタラクション リンク (0223)、クロード固有のテーブルを置き換える統合アダプター認証セッション (0224、0225)、処分修復重複インデックス (0226)、ネイティブ ランナー コントラクト テーブル - フラグがオフの間は不活性 (0227)、永続的質問応答配信 (0228)、会社ブランドカラーおよび添付ファイル制限列 (0229) の削除、およびバックフィル付きの Better Auth issuer 列 (0230) が削除されました。これらは起動時に自動的に実行されます。 0229 のみがデータを破棄し、これら 2 つの削除されたフィールドのみを破棄します。
  • 新しいオプションの環境変数 (デフォルトでは現在の動作が維持されます):
    • PAPERCLIP_HIDDEN_SETTINGS — Paperclip をホストしているオペレーター向けに、非表示にするコンマ区切りの設定を表示します。 company.import を隠すと、輸入品 API も隠れます。 (#11823、#12199)
    • PAPERCLIP_SETTING_DEFAULTS — 選択したインスタンス設定のスキーマのデフォルトをオーバーライドする JSON オブジェクト。 (#12285)
    • SENTRY_DSN — エラー監視をオプトインします。サーバー側キャプチャ用のオプションのピア @sentry/node@10.71.0 もインストールします。 (#12190)
    • PAPERCLIP_WORKSPACE_REAPER_COOLDOWN_DAYS — ワークツリーが取得される前にターミナル ワークスペースが放置される日数 (デフォルトは 7、0 はクールダウンを無効にします)。 (#11642)
  • API フィールドの削除: brandColor と attachmentMaxBytes は、会社の API の作成/更新/ブランド化および移植性マニフェストから削除されました。 Cliそれでも送信すると検証エラーが発生します。これらを含むエクスポートされたバンドルは正常にインポートされます。
  • 注意すべき動作の変更: 不正なエージェント ベアラー トークンは 401 になり (「重要な変更」を参照)、サイレント ランや孤立したタスクは自動回復アクションをトリガーしなくなり、Grok の暗黙的な --permission-mode dontAsk はなくなりました。
