#紙clip v2026.916.0

リリース日: 2026-09-16

Paperclip v2026.916.0 には 503 のコミットが含まれており、同日公開された 2026.916.0-beta.0 から昇格されました。見出しは Connections トレインです。AI ランタイム資格情報 (Claude および Codex のサブスクリプション、API キー、共有アカウント) は、他のすべてのアカウントと同じ付与と権限の境界の下で Connections 内に存在し、雇用とタスクの実行を通じて責任者を追跡し、必要なタスクからインラインで接続または修復できます。その周辺: エージェントは AgentMail を通じて自分の電子メール アドレスを取得し、実験的なチャット コネクタは Slack、Discord、Telegram、Microsoft Teams、および (Photon 経由で) iMessage の会話をタスクに組み込み、GitHub アクセスは 1 つの共有トークンではなく耐久性のある個人ごとの ID になり、アナウンスはネイティブのアプリ内カードとして到着し、実験的な Paperclip Runner は前回のリリースの基礎から完全な実行エンジンに成長し、自己ホスト型でデフォルトでゲートが開くようになりました。明示的に構成されたエージェントをインストールします。

重大な変更

  • 安価なモデル プロファイルが削除されました。 安価なモデルでリカバリとオーバーライドを実行できる 2 番目の実行モードが、アダプター メタデータ、エージェント ランタイム構成、タスク オーバーライド、リカバリ ルール、API、およびボード UI から削除されました。移行 0236 は、保存されている modelProfiles ブロックをエージェント構成から削除します。通常の作業と回復作業のためのモデル選択パスが 1 つになりました。 (#12683)
  • エージェント API はプレーンテキストの資格情報を返さなくなりました。 エージェントをシリアル化するすべてのエンドポイント (詳細の読み取り、会社のエージェント リスト、および作成/更新/ライフサイクル ルート) は、格納された adapterConfig.env をエコーしていたので、plain バインディング (API キー、トークン) は、GET /api/agents/me 経由のエージェント自体を含む、エージェントを読み取ることができる呼び出し元にそのまま返されていました。 3 つの応答ファミリーはすべて、1 つの編集プレゼンターを介してルーティングされるようになりました。これらの応答からライブ認証情報を収集した統合は機能しなくなります。これが漏洩でした。 (#9860、@glovario)
  • 自動生産性レビューは廃止されました。 実行数、コメント数、経過時間を管理レビュー タスクに変換していた検出機能は、継続保留とともに削除されました。インフラストラクチャの障害により、そのルールと製造作業が満たされる可能性があります。期限付きの回収、予算、明示的な阻害要因、および通常のレビュー段階はすべて残ります。既存のタスク レコードは読み取り可能で変更されないままになります。 (#13263)
  • X-Forwarded-Host は trusted プロキシからのみ受け入れられます。 同一オリジン ガードは、任意の直接 client から転送されたホストを受け入れ、呼び出し元が自身のヘッダーを trusted-origin セットにプロモートできるようにしていました。転送されたホストは、直接ピアがオペレーターの TRUST_PROXY 設定を渡した場合にのみカウントされるようになりました。リバース プロキシの背後に展開する場合は、TRUST_PROXY が設定されていることを確認する必要があります。そうでない場合、プロキシの転送ホストは生の Host ヘッダーを優先して無視されます。 (#12832)
  • Anthropic の従来の REST 接続オプションは廃止され、REST ツール接続は REST として検証されます。 サポートされている AI アカウント フローを優先して、廃止された REST セットアップ パスが削除され、stdio 検証ではサポートされていない REST 接続が通過 (または誤解を招く templateId エラーで失敗) できなくなりました。サポートされていない既存の接続は正確に拒否されるようになりました。 (#13346)

ハイライト

  • AI 資格情報が Connections 内に存在するようになりました — プロバイダーのサインインは、エージェントごとの構成を停止し、所有権、付与、およびアクセス許可を持つ管理対象アカウントになります。 Connections はすでに適用されています: エージェントは担当ユーザーのアカウントまたは許可された共有アカウントを再利用し、モデル/ハーネスの選択は資格情報の選択から独立しており、レガシー エージェントは管理対象接続を明示的に採用するまで既存の認証を保持します (#13247)。 2 番目のログイン ウィザード (#13248) の代わりに、同じサインイン コンポーネントがオンボーディング、エージェント構成、およびコネクタ ページ全体で再利用されます。雇用されたエージェントは雇用エージェントのプロバイダー認証情報の参照を継承するため、委任されたチームメイトは最初の実行から認証でき (#13268)、接続はレガシー ランナーとネイティブ ランナー間での雇用に続きます。アカウントが見つからない場合はタスクが一時停止され、失敗する代わりに接続フォームがインラインで提供されます (#13438)。責任のある各ユーザーはプロバイダーごとのデフォルトを取得するため、あるユーザーのサブスクリプションと別のユーザーの API キー (#13351) で同じエージェントを実行できます。列車は着陸と同時に強化されました。サブスクリプションのサインインは、サーバー オペレーターの CLI アカウントを公開することなく、認証された自己ホスト型インスタンスで機能します (#13344)、資格情報のリースは、架空の「接続ビジー」を報告する代わりにトランザクション プーリングを存続します (#13347)、1 つの Anthropic サブスクリプション接続は同時実行をサポートします (ファイルバックアップのみ)認証情報は引き続きシリアル化され (#13445)、接続プローブ、保存されたアカウントの再利用、およびタスクのハンドオフは信頼性パスを取得します (#13404、#13161)。
  • エージェントは独自の電子メールを取得 — AgentMail 接続 (実験的) はエー​​ジェントに専用の受信箱を与えます。受信電子メールはタスク内で割り当てられた作業となり、送信は Paperclip を通じて認証される明示的なエージェントのアクションであり、内部タスクのコメントが誤って送信メールとして漏洩することはありません。プロバイダー キーはサーバー ボールトに保存され、ボードはタスクの電子メール カードからの各会話を追跡します。 (#13256)
  • チャット ツールからエージェントに連絡 — 実験的なネイティブ チャット コネクタは、Slack、Discord、Telegram、Microsoft Teams、または GitHub ボット ID を 1 つのエージェントにバインドし、許可された各外部会話を 1 つのタスクにバインドします。これには、耐久性のある会話ごとのキュー、質問、進行状況、ファイル、配信確認が含まれます。 — ボードのコメントは、チャンネルに明示的に送信されない限り内部に留まり、生の推論、ログ、資格情報はまったく送信されません(#13100、#13038)。 iMessage は実験的な Photon チャネルを通じて参加します。共有 Pro DM または専用番号、写真が含まれており、Paperclip がタスクの所有権と承認権限を保持します (#13299)。アプリ自体では、実験的なエージェント チャットにより、並列チャット ストアではなく、実際のタスクと通常のガバナンスに裏付けられた各エージェントとの永続的な会話がすべてのユーザーに提供され、検索可能なピッカー (#13284、#13420) を介してチャット サイドバーからすべての企業エージェントにアクセスできます。
  • GitHub アクセスは共有トークンではなく ID になります — GitHub 永続的な更新、リポジトリ アクセス チェック、Webhook 配信を備えたアプリベースの ID は、アドホック トークンを置き換え、既存の管理された接続と暗号化された許可に基づいて構築されます (#12843)。複数の担当者が 1 つのエージェントを操作する場合、マネージド Git、gh、および GitHub ツールは、受け入れられた指示に従って責任者の資格情報を解決します。永続的な継続ルールとチームメイトのアクセスへのフォールバックはありません (#13005)。また、その ID はサンドボックス ランナーにも投影されます (#12907)。コア周辺: 組織全体でのリポジトリ アクセスの参照 (#12998)、プロジェクトごとに複数のソース リポジトリの選択 (#13010)、同じ GitHub アカウントへの重複接続はきれいに解決 (#13022)、サインイン状態と接続されたリポジトリへのアクセスは UI で表示および簡素化されます。 (#12993、#13047、#12893)。
  • アナウンスはアプリに到着します — ネイティブ アナウンス カードは、ネイティブ コンポーネント (ヒーローは静止画像または独立した HTML/CSS アニメーションにすることができます) を使用して検証済みの JSON フィードをレンダリングするため、カードの公開または取り消しにアプリをリリースする必要はありません。削除はインスタンス上のアカウントごとに持続します。クローズされたカードは企業やブラウザを超えてクローズされたままになります。また、名前付きステージング フィードにより、作成者は本番前にコンテンツをテストできます。ホストされたフィードに対してデフォルトでオン。アップグレード ガイドにはオプトアウトがあります。 (#13403)
  • オンボーディングは作業エージェントに直接アクセスします — 接続ステップは、プロバイダー サインインが組み込まれたモデル ソースの質問として開きます。単一カード上の 1 つの連続シーケンス、API キー入力が含まれており、貼り付けられたログイン コードが画面上に保持され、すぐに回答されます (#12440、#12863、#12801、 #12820、#12613、#13193)。最初のタスクは、勝手に実行されるのではなく、あなたの回答を待つ首席補佐官とのチャットとして開始され、首席補佐官の雇用は確実です (#13068、#13317)。後でエージェントを作成すると、構成ページが再構成された簡略化されたウィザードで同じ接続コントロールが借用され (#13011)、保存されたモデル接続はセットアップ中に再サインインを求められることなく再利用されます (#13161)。

改善点

  • アプリとコネクタ カタログの成長 — アプリは実験的なゲートを離れ、接続セットアップは短縮され、管理された Google アクセスは安全なデフォルトのオリジン (#12728) を使用したクリーンなセルフホスト インストールで機能します。その下: 接続許可と委任された ID (#12341)、マネージド外部 MCP コネクタ (#12346)、安全なリモート MCP および PostHog セットアップ (#12339)、Composio および Gmail コネクタ (#12342)、拡張インテントベースのセットアップ (#12344、#12347、#12345)、洗練された Postman フローと Shopify フロー (#12357)、および統合コネクタ管理 (#12684) を備えたセルフサービス カタログ。 Google Workspace の設定は後にエンドツーエンドで修復されました。カタログと作成では同じ可用性ルールが使用され、所有権の選択は機能の変更にも影響されません。また、Paperclip は、1 リンク離れたカスタム OAuth によるデフォルトの Google 認証方法です (#13289、#12619、#12623)。エージェントは、タスクからレビューされた接続アクションを使用して、ネイティブ タスク フィードから新しいサービス接続を要求することもできます (#13058、#13063)。
  • モデルとプロバイダーの更新 - Claude Fable 5.1 は、直接 Anthropic 推論プロファイル ID と Bedrock 推論プロファイル ID の両方を備えた Claude アダプターで選択可能です (#12730)。 Codex は、モデル固有のコントロール (#12851) を備えた GPT-6 Astra を獲得しました。 unset クロード モデルはどこでも Opus 5 に解決され、デフォルトはエージェント設定に表示されます (#13055)。 Grok は、プライベートの企業スコープの資格情報ホームを使用してサンドボックス デバイス ログイン パネルに参加し、リモート サブスクリプションの実行に厳選され、更新された資格情報がホストにコピーされます (#12469、#12618、#12696)。各 Codex アカウントは独自のホーム シークレットとパス シークレットを取得し、エージェントは会社のデフォルト (#12709、#13067) 以外の Codex ログインにバインドできます。
  • ネイティブの Paperclip ランナーがすべての仕事を行うようになりました — そしてセルフホスト型インストールではデフォルトでゲートが開きます — 前回のリリースの基盤は、enableNativeRunner フラグの背後にある完全な実験的な実行エンジンとなり、現在はデフォルトで セルフホスト型インスタンスに対してオンになっています (クラウド管理インスタンスではオフのままです) (#13068): ネイティブ Codex 実行と Claude ACPXランタイムと認定された OpenCode ランタイム (#12616、#12590、#12588、#12691)、マネージド プロバイダー バックエンド (#12699)、安全なトランスポートを備えたリモート実行基盤(#12638、#12639)、管理と観察可能性 (#12641)、タスク チャットに投影されるネイティブ ターン (#12617)。このコントロールは、すべてのセットアップ パス (#12656、#12666) をゲートする 1 つの統合フラグです。オープンなデフォルトはゲートのロックを解除するだけです。明示的に構成されたローカル Codex、OpenCode、および認定された ACPX エージェントはランナーを使用でき、オンボーディングは従来のアダプターに留まり、自動的に何も切り替わらず、実験設定で enableNativeRunner をオフにすると再び閉じられます。
  • オペレーター向けの制御 — マネージド実験フラグ enableIsolatedWorkspacesByDefault により、独自のポリシーのないすべてのプロジェクトで、分離されたタスクごとの git ワークツリーが使用されるため、フリートのデフォルトは各プロジェクトを手動で編集することを意味しなくなります (#13444)。新しい標準 trust エージェントはデフォルトで他のエージェントを雇用できます。低 trust エージェントは無効なデフォルトのままです (#12814)。 Sentry モニタリングは SENTRY_DSN_FRONTEND と SENTRY_DSN_BACKEND に分割され、古い SENTRY_DSN は引き続きフォールバックとして機能します (#12678)。実験設定ページでは、無効なコントロールとグループ開発者ツール (#12681) が削除され、PAPERCLIP_HIDDEN_SETTINGS は実稼働スイッチャー メニューでも尊重されます (#12788)。
  • タスク サーフェス、更新 - 洗練されたタスクおよびワークスペース サーフェス、一貫したホバー/ポップオーバー/スペース動作、実際にスキャンできるコンパクトなダッシュボードとライブラン カード (#12746、#12747、#12748、 #12854、#12793、#13269)。作業成果物には、タスクの [成果物] タブ (#12717) にリッチ カードと実行成果物インベントリが表示されます。viewer=full ドキュメントのディープ リンクにより、外部通知から直接最大化されたサイド ペインが開きます (#12812)。コンポーザーは、簡略化されたタスク コントロール、ステータス バッジ、およびインライン ブロッカーの削除を備えた停止コントロールを取得します。 (#13104、#13097)、単一選択の質問は選択に進みます (#13234)、ランナーのアクティビティは、ライブ ビューと保存されたビューで共有されるグループごとのローリング概要に凝縮されます (#13255、#13274、 #13421)、タスクから作成されたタスクはプロジェクトごとに表示されます (#13241)、長時間のタスク チャットはストリーミング中に応答性を維持します (#13229、#13228)、モバイルでは実際のエンティティ ピッカー シート、全幅のタスク ツリー、およびスペース パスが取得されます。 (#13343、#13250、#13304、#13122)。
  • タスクを見つけるタスク検索 — 完全かつ迅速な検索は、明示的な関連性バンドと保守的なタイプミスの回復を備えた PostgreSQL 用語カバレッジを中心に統合し、スコア付けされたコーパスに照らして判断されます。 (#13335)
  • データに手を触れずに試してみる — フォアグラウンド専用の test-drive CLI コマンドは、独自のデータ ディレクトリとプロバイダー支援の CEO を持つ分離されたインスタンスを起動します。再利用保護機能と復元された資格情報入力 (#12894、#12898) を使用します。明示的に要求されない限り、サーバーの起動時にブラウザが開かなくなりました (#12435)。
  • サンドボックスの実行がより速く、より堅牢になりました — ウォーム デイトナ ワークスペースはターンを超えて持続し、ホスト ワークスペースは耐久性境界を維持し (#12904、#12901)、HTTP/2 サンドボックス ブリッジはバイナリ ボディとアタッチメント ルートを運びます (#12923)、選択されたスキルがリモート クロード ACP 実行にステージされます。 (#13196)、サンドボックス制御チャネルが失われた場合、ターンはハングする代わりに高速で失敗します (#13158)。

修正

  • サーバーのセキュリティと正確性 - 特権サーバーの境界が強化され (#12776)、プロジェクトの目標 ID が存在し、会社に属していることが検証されます (#12779)、listComments は非 UUID で 500 秒を使用しなくなりました afterCommentId (#8695 @Maxxsong7)、Docker クイックスタートは PAPERCLIP_ALLOWED_HOSTNAMES を (#6846、@rsclafani) に渡します。
  • データベース プールはウェッジではなく修復されます — アイドル状態の接続が取得され、プールに名前が付けられ、シャットダウン時に終了します — PostgreSQL がすべてのブートを拒否するまでバックエンドを蓄積していた再起動ループを閉じます (#12956, @stubbi) — そして、リサイクルされたプールされた接続でソケットの書き込みが失敗したクエリは、要求が失敗する代わりに再実行されます(#13417)。
  • オンボーディング接続ステップで動作が表示される — オンボーディング中のプロバイダーのサインインは、ハングしたように見えるのではなく (#13499)、次に進む前に検証の進行状況を表示してサブスクリプションを確認するようになり、マシン上の古いまたは期限切れのクロード資格情報ファイルは、サインインを中断する代わりにトークンを読み取るときにスキップされます (#13505)。
  • 接続の信頼性の向上 - 個人 MCP 認証検出のブロックが解除され (#13497)、1 つの OpenAI または xAI サブスクリプション接続がエージェントの同時実行をサポートし、このリリースの Anthropic 修正に一致します (#13452)。
  • リカバリとウェイク — 隠された問題は、停止したリカバリと継続ウェイクから除外されます (#5648、@im0xMagnus)、ブロックされたウェイクは繰り返し実行を生成せずに待機します (#13236)、古い継続ウェイクは拒否されます (#13173)、実行の停止中に送信したメッセージは保存されます消滅するのではなく回復後に配信されます (#13327、#13270、#13405)、ユーザー メッセージは停止したネイティブ タスクを続行できます (#13239)、再試行枯渇イベントによってアテンション フィード メモリが使い果たされなくなりました。 (#13451)、開始実行は重複するデプロイメントでも存続し (#13285)、実行ポーリングとワークスペース検査の増幅は減少します (#13174)。
  • サンドボックスとワークスペース - スタックしたサンドボックス プラグインのブロックが目に見えて実行され、エラーが発生したバンドル プラグインが起動時に再度有効になり (#12957、@stubbi)、停止したサンドボックスの起動がセットアップを待たずにキャンセルされ (#13352)、ワークスペースのセットアップが回復して再試行されます。 (#13353)、従来の Daytona 起動エラーはタスクと受信トレイから回復します (#13272)、プロジェクトのすべてのリポジトリはローカル タスクとサンドボックス タスク用にプロビジョニングされます (#13442)、一時的なワークスペース ブートストラップ スキャンは実行に失敗する代わりに回復します(#13481)、サンドボックス ファイルはレガシー ランナーとネイティブ ランナーの両方で公開され (#13493)、実行イベント ペイロードは NUL 文字を保持します (#13325)。
  • Web アプリ — Service Worker にはビルドごとの ID がスタンプされるため、デプロイは実際にパーク タブ (#12725) に到達し、ワークスペース対応の通知はエージェント バブル (#12716) ではなくコンパクトなシステム通知としてレンダリングされ、フィード カードは完全に clickable です。 (#13294)、タスク ページのアーカイブ ショートカットが戻ってきました (#13253)、エージェントの指示が誤って保存されなくなりました (#12502)、会社のナビゲーションはアクセス可能なメンバーに限定されました (#13039)、最近のタスクでタブ間でのストレージ フィードバックのエコーが停止されました(#13402)、プランから自動への移行はプランの確認時にのみ発生します (#12695)。
  • アダプター - 修飾子のないクロード使用制限メッセージがクォータ分類で検出され (#12475)、Codex サインインと環境テストで実行に使用される資格情報が一致します (#13064)、Codex 起動 trust、履歴読み取り、および使用再開が修正されます。 (#13110)、Grok はホスト ディレクトリから環境テストを実行し、ワークスペースが存在しなくても存続します (#13416)。また、使用可能なランタイムのデフォルトを維持しながら、意図しないエンジンのフォールバックが防止されます (#13105)。

アップグレード ガイド

  • 新しいプラットフォーム要件はありません: v2026.831.0 の Node.js 24.11.0 フロアは変更されていません。
  • 移行: このリリースでは、49 個のデータベース移行 (0231 ～ 0279) が追加されています。これらは起動時に自動的に実行されます。トレインによる: 冗長な自動作成アプリ接続ツール プロファイル行のクリーンアップ (0231)、接続許可と委任された ID (0232)、マネージド外部 MCP コネクタ (0233)、ネイティブ ランナー プロバイダー トレース、実行イベントの一意性、バックエンド、セッション回復、セッション目標 (0234 ～ 0235、0237 ～ 0238、 0248)、保存されている安価なモデルのプロファイルの削除 (0236)、耐久性のある GitHub ID と個人ごとの実行 ID コンテキスト (0239 ～ 0245)、サービスの接続とタスクからの接続アクションの確認 (0246 ～ 0247、0249)、永続的なタスクの回復 (0250 ～ 0254)、チャット プロバイダーとデータ基盤(0255 ～ 0270)、エージェントごとの Codex ログイン バインディング (0271)、AgentMail 受信ボックス (0272)、展開安全な開始実行 (0273)、エージェント チャット (0274)、iMessage Photon (0275)、AI 接続およびユーザーごとのプロバイダーのデフォルト (0276 ～ 0277)、アナウンス解除状態(0278 ～ 0279)。 0231 と 0236 のみがデータを破棄します。冗長ツール プロファイルにはそれぞれ行と削除された安価なモデル プロファイルが含まれます。それ以外はすべて加算です。
  • 新しいオプションの環境変数:
    • SENTRY_DSN_FRONTEND / SENTRY_DSN_BACKEND — ブラウザーとサーバーの個別のエラー監視。従来の SENTRY_DSN は、どちらのフォールバックとしても機能します。 (#12678)
    • PAPERCLIP_ANNOUNCEMENTS_ENABLED — アプリ内アナウンスは デフォルトでオンになっています。オプトアウトするには、false に設定します。 PAPERCLIP_ANNOUNCEMENTS_FEED_URL はフィード (デフォルト https://pages.paperclip.ing/announcements/v1/current.json) をオーバーライドします。 (#13403)
    • PAPERCLIP_TOKEN_BROKER_ALLOWED_HOSTS — リモート MCP セットアップ用に、サンドボックス トークン ブローカーが到達できるカンマ区切りの追加ホスト (デフォルト: なし)。 (#12339)
    • PAPERCLIP_DISABLE_CWD_ENV_FILE — サーバーが作業ディレクトリから .env ファイルをロードしないようにするには、true に設定します (デフォルト: ロードします)。 (#12894)
  • API サーフェスの削除: modelProfiles はアダプターのメタデータ、エージェントのランタイム構成、およびタスクのオーバーライドから削除されました (#12683)。エージェント応答の平文 env 値は編集されます (#9860)。 Anthropic の従来の REST 接続セットアップ オプションは削除されました (#13346)。
  • 注意すべき動作変更: 実験的な Paperclip ランナー ゲート enableNativeRunner は、セルフホスト型インスタンスに対してデフォルトでオンになりました。明示的に構成されたエージェントのみで、自動的に何も切り替わらず、クラウド管理インスタンスはオフのままです (#13068)。新しい標準 - trust エージェントはデフォルトで他のエージェントを雇用できます (#12814)、設定を解除したクロード モデルは Opus 5 に解決されます (#13055)、アプリは実験的なゲートの向こう側ではなくなり (#12728)、X-Forwarded-Host にはプロキシ trust が必要です (速報を参照)変更）。
