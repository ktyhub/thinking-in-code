#ペーパーclip v2026.817.0

#紙clip v2026.817.0

リリース日: 2026-08-17

Paperclip v2026.817.0 は、2026.722.0 以来の最初の安定版リリースであり、新しい Canary → Nightly → Beta → Stable リリース チャネルを通じて公開された最初の安定版です。この正確なビルドはカナリアとして出荷され、スモーク テストされ、ナイトリーに昇格され、2026.811.0-beta.0 としてソークされてから、安定版に昇格されました。これには、一流の意思決定ワークフロー、完全に忠実な企業インポート/エクスポート、マネージド CLI インストール ライフサイクル、チャット スタイルのタスク ビュー、および修正とパフォーマンス作業の長いリストにわたる 311 件のコミットが含まれています。

重大な変更

これらはいずれも、通常のインストールではアクションを必要としませんが、アップグレードする前に必ず読んでください。

  • Docker :latest は安定を意味します。 以前は、:latest はすべてのマスター マージを追跡していました。その動作に依存していた場合は、:canary (またはスモークゲート毎日の場合は :nightly) に切り替えてください。安定したイメージには :YYYY.MDD.P バージョン タグも取得され、正確な固定のためにすべてのイメージには :sha-<short-sha> が取得されます。 (#11006)
  • 実験的なクラウド同期は削除されました。 ホスト間の同期トランスポート (以前はフラグゲート型) はなくなりました。 company インポート/エクスポートは、サポートされている単一のデータ移動パスです。移行 0196 は古い同期状態テーブルを削除します。会社のデータは変更されません。実験用輸送機関自身の簿記のみが削除されます。 (#10507)
  • 標準 trust エージェントは、会社に表示される問題に書き込むことができます。 コメント、問題の更新、子タスクの作成、および割り当ては、チャネルごとの所有権の付与ではなく、問題の可視性に基づいた 1 つのデフォルトのオープン ルールに従うようになりました。会社、ユーザー、trust スコープ、および実行ライフサイクルの制御は引き続き適用され、問題間の副作用は抑制され、原因が特定されます。 (#10804、#10837)
  • アーカイブされたプロジェクトは、デフォルトのプロジェクト リスト ルートから除外されます。 それらを含めるには、明示的なフィルターを渡します。 (#10146)

ハイライト

  • リリース チャネル: カナリア → ナイトリー → ベータ → 安定版 — Paperclip は現在 4 つのチャネルで出荷されています。 canary は、マージのたびにマスターにパブリッシュします。 nightly は、最新の Green Canary を毎晩 1 回再公開しますが、完全なリリースのスモーク スイート (本物の Docker コンテナ、ブラウザ駆動のオンボーディング) が正確に公開されたアーティファクトに対して合格した後にのみ再公開します。 beta は、承認ゲートの後ろで毎晩メンテナによって昇格され、公開後に再スモークされます。そして、どの厩舎も最初に少なくとも 3 日間はベータ馬として浸漬しなければなりません。 npx paperclipai@latest (安定)、@beta、@nightly、または @canary で取り付けるか、ghcr.io/paperclipai/paperclip:latest / :beta / :nightly / :canary を引っ張って取り付けます。 Docker :latest は 安定 を意味します。上記の重大な変更を参照してください。詳細はdoc/CHANNELS.mdで。 (#11006、#11008)
  • 意思決定: 一流の提案/決定ワークフロー — エージェントは複数のオプションのアクションを実行する代わりに提案できるようになり、管理された監査可能な画面から人間が決定します。 Decisions v1 では、提案モード自体 (入力されたオプションと入力、古いターゲットの検出、監査された効果の実行)、優先順位が付けられ、現在ランク付けされたアテンション フィードを備えた永続的な意思決定キュー、トリアージ コントロール、エージング シェルフ、および可逆的な保持を備えた意思決定デスクが追加されています。完了したターゲットの決定は自動的に廃止され、ターゲットにリンクされます。 (#10010、#10651、#10672、#10785、#10474、#10892)
  • 完全忠実度の会社インポート/エクスポートが Cloud Sync を置き換えます — 実験的なホスト間の Cloud Sync トランスポートは廃止されました。インポート/エクスポートは現在、企業をインスタンス間 (セルフホスト ↔ クラウド、またはプレーン バックアップ) に移動する唯一の方法であり、到達可能性やインスタンス間の認証要件はありません。バンドル (スキーマバージョン 6) には、ラベル、ブロッカー、発行ドキュメント、作業成果物、モニター、およびすべての添付ファイルが、単一行が書き込まれる前に検証されたコンテンツアドレス指定の sha256 BLOB として含まれるようになりました。インポートはバッチ挿入と整合性ガードを備えた耐久性のある非同期ジョブとして実行され、パッケージは圧縮 zip としてアップロードされ、アップロードの上限は 1 GB になり、PAPERCLIP_IMPORT_ZIP_MAX_BYTES を介してオペレーターが構成できるようになりました。 (#10507、#10523、#10531、#10538、#11184)
  • CLI の管理されたインストール、更新、およびサービス ライフサイクル - paperclipai CLI は、一時的な npx プロセスではなく、永続的な自己更新サービスとして Paperclip をインストールできるようになりました。ユーザーごとのペイロード ストアと安定したコマンド シムを使用した管理インストール、更新前のバックアップと保持されたロールバック状態による並列更新、さらにservice、uninstall、doctor、およびブートストラップ インストーラーは、Linux、macOS、コンテナー、および WSL にわたってサポートされます。管理された更新では、env ファイルと拡張子が保存されます。 (#10045、#10980、#11005)
  • 「誰が何を変更したか」を 1 つのアクティビティ ページに表示 - 基本的なアクティビティ リストと個別の監査ページが、監査フィードに基づいて構築された 1 つの充実したアクティビティ ページに統合されました。完全な履歴、フィルター、すべてのアクターとエージェントのアクションのみの範囲の切り替え、およびエージェントの詳細に関するエージェントごとの監査タブが含まれます。特権コントロールは監査権限のないメンバーには隠されており、タスク間エージェントの書き込みには帰属、監査受領書、およびアクション可能な拒否メッセージが付属するようになりました。 (#10838、#10831、#9744、#10843)

改善点

  • マルチプロジェクト ワークスペースの同期、デフォルトでオン — 複数のプロジェクトを参照する実行では、参照されているすべてのプロジェクトがデフォルトでワークスペースに同期され、実行準備時にプロジェクトごとの承認が解決され、実行時に部分同期警告が表示されます。 @ で言及されたプロジェクトは、限定されたトランスポートを介してリモートのサンドボックスにもステージングされます。 (#10473、#10469、#10380、#10564)
  • 共有ワークスペースの同時実行制御 - 共有ワークスペースでの課題の実行は、制限されたビジー延期によってシリアル化され、同時実行の制限はワークスペース ポリシー エディターから構成できます。 (#10699、#10759、#10771)
  • 人間が承認した秘密の提案 — 作業中に資格情報に遭遇したエージェントは、それを不活性提案として Paperclip に渡すことができます。権限のある人間が審査して承認するまでは、何も生きた秘密や拘束力はありません。秘密の詳細も、外部値とディープ リンクのライトスルー編集によって取得されました。 (#9934、#10196)
  • エージェント間のガバナンス サーフェス — 発行スレッドの対話は、管理されたエージェントの宛先をサポートするため、サーバー側の承認、取り消し、および端末発行の有効期限を使用して、あるエージェントが別のエージェントに明示的に応答を送信できます。エージェントは、明示的なレビュー判定ポリシーに基づいてレビュー確認を解決でき、レビュー ラウンドは責任者にエスカレーションされた使い果たされたレビューで終了し、オープン祖先の作成者に戻る委任サイクルは拒否され、一時停止中のエージェントへの割り当ては拒否されます (エスカレーション パスが一時停止中のマネージャーにルーティングされる場合は警告が表示されます)。 (#10252、#10251、#10939、#10931、#10650、#10658、#10648、 #10657)
  • 制限された実行に対するタスク スコープの出力許可 — Kubernetes 制限では、GitHub またはパッケージ レジストリを正当に必要とするタスクは、オペレーターが名前空間全体にわたる広範な出力を有効にする代わりに、実行ラベルで選択されたネットワーク ポリシーとなる、狭い問題スコープの出力許可を要求できます。拒否されたリクエストには、管理ポリシーと助成金のリクエスト方法が説明されています。 (#10155)
  • キャッシュ調整された実行コスト - アダプターは、プロンプト キャッシュの割引後にプロバイダーに請求されたコストをレポートできるため、キャッシュを多く使用する実行がコスト台帳で誤って価格設定されることがなくなります。 (#10349)
  • ルーチン: アクティビティ ゲート実行ポリシー - ルーチンは、エディターと API の両方を通じて公開される最近のアクティビティに対する高度な実行をゲートでき、ルーチンはフォルダー名ごとにグループをリストします。 (#10225、#9438、#10201)
  • モデル カタログの更新 - Claude Opus 5 および Claude Sonnet 5 が Claude アダプターの静的モデル フォールバックに加わり、GPT-5.6 モデル メタデータが Codex のソースで解決されます。新しいエージェントでは、安価なモデルのプロファイルがデフォルトで無効になりました。アダプターの cheap プロファイルでは、エージェントの作成時に明示的なオペレーターのオプトインが必要になり、Codex の安価なプロファイルはデフォルトでハードコーディングされたモデルではなくなりました (既存のエージェントは変更されません)。 (#10327、#10280、#9780、#10019)
  • デイトナ サンドボックスの改善 — エージェント出力ストリームはデイトナ サンドボックスからライブで配信され (ホスト出力ポーリングは不要)、セッションは単純なコマンド ディスパッチで永続化され、機能プローブを備えたアドバイザリー bwrap ラッパーにより実行が強化されます。 app-home の所有権は、特権が削除される前に確保されます。 (#11049、#10941、#10541、#10554、#10805、#10530)
  • より静かで明確なシステム メッセージング — リカバリ通知は、オンデマンドの証拠を含むコンパクトな行に構造化および人間化され、リカバリ更新は全体的に静かになり、リカバリとブロック通知のコピーは平易な言語で書き換えられ、ワークスペース対応のコメントはコンパクトなシステム通知としてレンダリングされます。 (#11075、#10542、#10065、#10636)
  • UI のクオリティ オブ ライフ - タスク チャット コンポーザのドラフトはナビゲーション全体で保持され、タスク リストは最新の区切り記号を取得し、コピーとフィードバック アクションはエージェントのバブル フッターに返され、タスクの識別子はタスク詳細のブレッドクラムに表示され、ページ読み込みではアニメーションの Paperclip ローダーが取得されました。タスク優先度コントロールは UI から非表示になります (データ モデル、API、検索 DSL は完全にそのままです)。 (#11076、#10454、#11025、#10933、#10456、#11024)
  • ユーザーごとのドキュメントにスターを付ける — 他の人に影響を与えることなく、自分自身のドキュメントにスターを付けます。 (#9952)
  • 高速な定常状態サーバー — ダッシュボードの定常状態 DB ホット パス、アテンション、および生産性スイープが削減され、アテンション フィード クエリが厳密に順次ではなく並列で実行され (Postgres がネットワーク接続されている場合に大きな利点)、新しいインデックスがリカバリ スイープ ルックアップをカバーします。 (#10992、#10795、#10969)
  • サンドボックスの起動の高速化 — サンドボックスは、全体的にラウンド トリップを実行します。git-workspace ステージングは 1 つの限定された同期に結合され、デッド スタート ラウンド トリップは折り畳まれ、2 つのブリッジ セットアップは並行して実行され、開始されたサンドボックス ハンドルはリースごとにキャッシュされ、リモート スクリプトの書き込みはコンテンツ ハッシュの一致でスキップされ、ステージングはリモート セッションごとに 1 回行われ、exec ラッパーはオプトインのプロファイルなしの高速パスで nvm ソーシングを削除します。 (#10488、#10485、#10334、#10335、#10377、#10089、 #10443、#10352)
  • よりスムーズな UI ナビゲーション — 問題の詳細ナビゲーションが click よりも先にウォームアップされています。 (#10416)
  • 可観測性 — サンドボックスの起動と実行は、詳細な OpenTelemetry スパン (プロバイダーのラウンド トリップ、パック/転送、キャッシュ ヒット フラグ、ステップごとのタイミング アトリビューション) を出力し、手動スパンが正しくエクスポートされるようになりました。 (#10758、#10764、#10999、#10204、#10565)

実験的

これらは実験的な設定の切り替えの後に出荷されます。

  • チャット スタイルのタスク ビュー — オプトインの「チャット スタイル タスク」実験により、問題の詳細ページが会話に変わります。スレッドが先頭に立ち、コンポーザーが最後に留まり、ライブ ツールのアクティビティがコンパクトな概要に折りたたまれ、プロパティ/プラン/成果物がヘッダー タブに移動します。 2 回目の反復では、添付チップ、ライブターン ナレーション、モバイル レイアウトを備えたリッチテキスト コンポーザーが追加されました。 (#10606、#10707)
  • アプリと接続 - Notion は、PKCE および動的な client 登録を使用した MCP OAuth 経由で接続します。手動での OAuth 資格情報の設定は必要ありません。企業は、隔離されたアクションについての明示的なレビュー決定により、同じプロバイダーへの複数の接続を保持できます。 (#11009、#11060、#11040)
  • ステータス カード - 試験的なステータス カード ビューは、エージェントが生成する単一プロンプトのステータス更新をコンパイルし、概要で言及された問題を監視セットに結合します。 (#10101、#10202、#10205)
  • 簡体字英語のインタラクション — 試験的なフラグにより、カタログ内のオプションの /simplified-english スキルを使用して、エージェントのインタラクションが簡体字英語でレンダリングされます。 (#10934、#10410)

修正

  • あらゆる場所に実際のバージョン番号 — 公開された Docker イメージには、package.json プレースホルダーの代わりに実際のビルド バージョンがスタンプされ、ビルド コミットがベイクインされ、認証されていない正常性応答で実行中のコミットが公開されるようになりました。そのため、--version、UI、および /health は、実行している内容について最終的に一致します。 (#10257、#10566、#10563)
  • 構成の保存 — 管理された構成修復は拡張機能を保持し、無効な修復を保護します。管理された環境のドリフトは起動後も存続し、スキルの同期/パッケージのインポートはオペレーターのスキル選択をサイレントに置き換えなくなりました。置き換えには明示的なマージ モードが必要になりました。 (#11005、#10979、#10978)
  • 受信箱の正確性 — 人間のユーザーによって完了したタスクは適切にアーカイブされ、パッシブな問題ビューは自分の外に留まり、あなたがアーカイブしたアイテムはアーカイブされたままになり、受信箱の再並べ替えは注意の境界に従うため、アイテムが読み取り中にジャンプすることはなくなり、空の検索セクションは非表示になり、外部オブジェクトの概要が受信箱に漏れることはなくなりました。 (#10668、#10581、#10623、#10700、#10020)
  • ワークスペースの回復力 — 記録されたブランチが存在しなくなった実行ワークスペースは自己修復し、ベース CLI が壊れたときに分離ワークスペース プロビジョニングが自己修復します。サンドボックス git コピーバック バンドルがマージ ベースに対して行われるため、分岐またはリセットされたワークスペースは引き続きインポートされ、配信されたワークスペースは認識され、ターミナル ワークツリーが取得され、分離セットアップはランタイムの開始まで延期されます。 (#10578、#10574、#10601、#10908、#10653)
  • Codex アダプターの信頼性 — ターン途中のハーネス クラッシュは構造的に再試行可能なインフラストラクチャ エラーとして分類され、サイレント アクティブ ビルドは保持され、サンドボックス実行ではコントロール プレーン アクセスが保持され、サンドボックス実行ではサンドボックス イメージ独自の Codex ログインを使用でき、重複した --skip-git-repo-check フラグ インジェクションがなくなりました。 (#10210、#10153、#10152、#10582、#10595)
  • プラグイン ランタイム修正 - プラグイン エージェント セッションのターンと応答が確実に配信され、新しく開始されたプラグイン ワーカーは保存された設定を受け取り、プロアクティブなワーカーからホストへの呼び出しにより会社のスコープが解決されます。 (#10137、#10092、#10103)
  • バックアップ保持期間は暦月を考慮 — 毎月のバックアップ プルーニングでは、固定の近似 30 日ではなく暦月の境界が使用されるようになったため、有効な月末のバックアップが早期に削除されなくなりました。分離されたワークツリー開発インスタンスは、独自の冗長バックアップ ストリームのスケジュール設定も停止します。 (#3718、#10520)
  • サーバーの強化 — 企業エクスポートの YAML は大企業でのスタック オーバーフローを停止するために反復的にレンダリングされ、起動時に PAPERCLIP_DECISION_SIGNING_SECRET は不要になり (存在しない場合は安全な永続インスタンス キーが使用されます)、組み込みエージェントの重複が防止され自己修復され、ルーチン チェックアウトの競合で 409 が返され、適切なタイマー間隔がアトミックに要求されます。 (#10854、#10594、#10223、#3790、#10584)
  • UI ペーパー カット - ライト モードのチャット バブル上の白地に白のテキスト、ライブ バッジと作業中のシマー生存タスクのティアダウン、マークダウン エディターのブロッククォートが \> としてエスケープされる、プレーン HTTP 経由の clipboard コピー、プラン ペインにプランが表示されない、終了後に残るエージェントの詳細、および選択された完全なタイムライン ウィンドウが読み込まれない問題はすべて修正されています。 (#10952、#10985、#10466、#10875、#10930、#10451、 #9576)

アップグレード ガイド

  • 移行: このリリースでは、意思決定、ステータス カード、ドキュメント メンバーシップ、インタラクション ガバナンス、および新しいインデックスをカバーする 28 のデータベース移行 (0184 ～ 0211) が追加されています。移行は起動時に自動的に実行されます。手動での操作は必要ありません。 0196 は、削除された実験用 Cloud Sync トランスポートに属するテーブルを削除することに注意してください (重大な変更を参照)。
  • 新しいオプションの環境変数 (すべてに適切なデフォルト値があり、必要な場合にのみ設定します):
    • PAPERCLIP_IMPORT_ZIP_MAX_BYTES — 会社のインポート zip アップロードの上限 (デフォルトは 1 GB)。 (#11184)
    • DATABASE_PREPARED_STATEMENTS、DATABASE_POOL_MAX、DATABASE_IDLE_TIMEOUT_SECONDS、DATABASE_CONNECT_TIMEOUT_SECONDS — DB client チューニング。トランザクション モード プーラー (pgbouncer、Supervisor、Neon プールされたホスト) 経由で接続する場合は、DATABASE_PREPARED_STATEMENTS=false を設定します。 (#10795)
    • RUN_LOG_S3_INFLIGHT_MIRROR_SECONDS — 正常なシャットダウン フラッシュによる、飛行中の実行ログの S3 への調整されたミラーリングをオプトインします。 unset は変更しないことを意味します。 (#10512)
    • PAPERCLIP_DECISION_SIGNING_SECRET — 決定署名のオプションのオーバーライド。存在しない場合、安全な永続インスタンス キーが自動的に使用されます。 (#10594)
  • Docker ユーザー: 希望するチャンネルを決定します。マスター ビルドの :latest を追跡した場合、そのレーンは :canary になります。 :latest は今後、安定版リリースでのみ動作します。
  • チャネル間でのダウングレード (例: 毎晩安定版に戻す) は、データが作成されたときよりも古いスキーマを実行することを意味する可能性があります。ダウングレードを復元と同様に扱い、最初にデータ ディレクトリをバックアップします。
