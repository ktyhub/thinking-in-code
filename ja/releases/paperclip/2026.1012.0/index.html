#ペーパーclip v2026.1012.0

#紙clip v2026.1012.0

リリース日: 2026-10-12

Paperclip v2026.1012.0 は、2026.1006.0-beta.0 から昇格された 130 のコミットを保持します。見出しは、外部アシスタントがチームに参加できるようになったというものです。Claude Code、Codex、OpenCode、および任意の MCP client は、サインインしたユーザーとして Paperclip に接続し、作業をレビューし、タスクを委任できます。これらはすべて実験設定の背後で行われます。その周辺: チャットは会話の横に各エージェントのタスクと成果物を表示してナビゲーションを導き、接続カタログは Composio と Arcade で既にリンクしたアカウントを取り込み、接続には使用方法の説明が記載されており、エージェントに自動的に届きます。Claude Sonnet 5.5 および GPT-6.1 Sol には更新されたハーネスが付属しており、エージェントは会社のスキルを安全に更新できます。その下では、Codex はサーバーの再起動やモデル容量エラーに耐えて実行され、ワー​​クスペースの復元ロックはクラッシュセーフな SQLite ファイル ロックに移行し、デフォルトのエージェント命令は以前のサイズの数分の一に縮小されます。

重大な変更

  • ワークスペースの復元ロックはプロトコルを変更します。アップグレードする前に古いプロセスをすべて停止してください。 復元ロックとエージェント ファイル コレクション ロックは、プロセスがクラッシュしたときにカーネルによって解放される、<instance root>/locks/directory-merge/ に基づく OS 支援の SQLite ファイル ロックになりました。古いバージョンと新しいバージョンが同時に同じインスタンス ルートに書き込んではなりません。アップグレードまたはロールバックする前に、すべての古いサーバーおよびワーカー プロセス (他のホストまたはコンテナを含む) をドレインして停止し、残っているレガシー <hash>.lock/ ディレクトリをスクラッチの場所に移動します。新しい .lock.sqlite ファイルを削除したり移動したりしないでください。 doc/workspace-restore-locks.mdを参照してください。 (#14869)
  • ストアされたツールの許可は、記載されたとおりに適用されます。 scope.allow リストがツール、接続、またはアプリケーションと一致しない許可は、より広範なポリシーに適用されなくなりました。不明なセレクターまたは不正な制限を含む許可は、アクセスを拒否するようになりました。エージェントが以前に使用していたツールを紛失した場合は、アップグレード後にカスタム許可を確認してください。 (#14915)

ハイライト

  • アシスタントが MCP 経由でチームに参加 — Connections の新しい「アシスタント接続 (MCP)」カードにより、Claude Code、Codex、OpenCode、および汎用 MCP client がブラウザー OAuth またはデバイス コード同意を通じて Paperclip に接続し、サインイン ユーザーとして機能します: タスクの読み取りと検索、作業の作成と委任、人間によるコメントの残し、ドキュメントと成果物の読み取り、署名されたイベント Webhook を介した結果の追跡(#14846)。同意は client と組織を示し、書き込みアクセスはオプトアウトでき、リクエストは 1 つの会社に固定でき、paperclip mcp CLI デバイス ログインはローカル stdio client をブリッジします。 [設定] → [実験的] → [アシスタント接続 (MCP)] でデフォルトではオフになっており、HTTPS PAPERCLIP_PUBLIC_URL (#14933) が必要です。
  • チャットが先導 — 合理化された UI (デフォルトのシェル) でエージェント チャットが有効になっている場合、チャットは作業ナビゲーションの最初の行にあり、チャット レールには対象となるすべてのエージェントがリストされ、サイド パネルにはそのエージェントの最近のタスクと成果物が表示されます。新しい実験的な「受信トレイ + タスク リストの結合」設定は、受信トレイをビューとしてタスクに折り畳みます (#15100)。 「合理化された UI」をオフに切り替えたインスタンスでは従来のナビゲーションが維持され、これらの変更は表示されません。チャット エントリでは、最後にアクセスした会話 (#14848) が再開され、チャット ヘッダーにはエージェントのアバター (#14726) が表示されます。
  • アカウントごとに 1 つのカタログ — Connections アプリ カタログは、Composio、Arcade、およびサポートされている Executor ゲートウェイですでにアップストリームに接続されているアカウントを検出し、ソース チップ、検索、ページネーションを備えた 1 つのアプリ カードの下でネイティブ アカウントにグループ化します (#15254)。 AgentMail はエージェント チャットのインライン セットアップ カードとのデフォルト接続 (#14772)、Neon は OAuth または API キー サインインでカタログに参加します (#14980)、Asana はデフォルトの「Asana でサインイン」で再び動作し (#14756)、AI アカウントは「チェック」を取得します。 Codex、Claude、Grok、および OpenRouter の現在のプロバイダー制限を読み取る「使用法」アクション (#14936)。
  • 接続にはエージェントへの指示が含まれます - 接続には、ネイティブ ランナー、レガシー アダプター、および HTTP/プロセス コントラクト全体にわたるすべての認可されたエージェント ターンに配信される、編集可能な使用説明を保持できます。 Honcho、Mem0、Zep、Supermemory、および Cognee の出荷時のデフォルトでは、エディターがセットアップと [権限] パネルに表示され、エージェントの指示に読み取り専用の「接続から」セクションが表示されます (#15216)。
  • 新しいモデル、更新されたハーネス - Claude Sonnet 5.5 は、Low から Max までの作業量の Claude Code エージェントに対して選択可能であり、認定された Claude ランタイムは Claude Code 2.1.286 (#14993) に移行します。 GPT-6.1 Sol は高速モードとウルトラ エフォートで Codex アダプターに加わり、Bedrock は Sonnet 5.5 を獲得し、共有ピンは Codex 0.160.0 と OpenCode 1.18.34 (#14942) に移動します。 Claude および Codex のモデル メニューには、Claude および ChatGPT アプリ (#14917、#14918) と同じ順序でモデルがリストされるようになりました。
  • エージェントは会社のスキルを維持 — ネイティブ ランナー エージェントは、バージョン チェックと安全な再試行によって会社のスキルを書き換える update_skill ツールを取得し、バージョン履歴と監査ログに記録されます。スキル ファイル API には、オプションの expectedVersionId フィールドと idempotencyKey フィールド (#15049) が追加されます。新しく作成されたエージェントはデフォルトの設定許可セットを受け取るため、手動による権限作業を行わずにエージェント、ツール、スキル、タスクのセットアップを完了できます (#15283)。
  • 再起動と容量制限に耐える Codex の実行 — サーバーの再起動によって強制終了されたネイティブ Codex ターンは、古いプロセスがなくなったことが証明されると、同じ会話で再開されます (#15297)。容量に達したモデルには「容量に達したモデル」カードが表示され、1 分後、2 分後に自動的に再試行されます (#15347)。 ChatGPT アカウントが使用できないモデルには、一般的な回復ではなく、ガイダンスとともに「モデルが使用できません」と表示されます (#15299、#15304)。 Codex はストックベースのプロンプトを維持し、Paperclip のコンテキストを追加の開発者指示として受け取ります (#14920)。
  • 再構築された新しいタスク ダイアログ - このダイアログは、プロジェクトとワークツリー バー、記憶された担当者、プロジェクト、および作業量、および提案でのタスクの言及を備えた共有タスク コンポーザー上に構築されています。ステータス、レビュー担当者、承認者、およびウォッチドッグのコントロールはダイアログからタスクのプロパティに移動し、新しいタスクのデフォルトは最後に使用された担当者になります (#15091)。タイトルなしで作成されたタスクには、クリーンなプレーンテキストの仮タイトルが付けられます (#15047)。
  • はるかに短いデフォルトの指示 — 新しい企業と新入社員は、手順マニュアルの代わりに役割の説明を受け取ります。デフォルトの CEO 指示は約 1,900 ワードから 20 ワード (#14985) に減り、CEO 以外の新入社員は 1 文のデフォルトマニュアル (#14948) を受け取り、バンドルされた計画スキルは合わせて約 400 ワードに縮小され、強制的な指示はなくなります。子タスク行列 (#15296)。既存の保存されたマニュアルとカスタム バンドルは変更されません。

修正

  • ネイティブ ランナーとセッション - 最終回答は保存されたものの、シャットダウンに失敗した実行は正しい最終ステータスに達し、エージェント list_projects ツールはコマンド制限をオーバーフローする代わりにページ化された概要を返します (#15217)。古いビルドでのネイティブ準備中に停止したタスクは再試行して新しいメッセージを受け入れます (#15020、#15022)。キュー実行レビュー ゲートによってキャンセルされた継続は、不明な実行の保留ではなくレビュー待機として扱われます (#15024)。再試行と保存されたメッセージのリカバリは SQL_ASCII データベースで機能します (#15033)。ユーザーが継続してタイムアウトになった従来の実行は、自動的に再試行できます (#14987)。その後、命令ファイルのクリーンアップがタイムアウトになったときに、完了した実行で「実行に失敗しました」と報告されなくなり (#14945)、そのクリーンアップによってリースの解放がブロックされなくなりました (#14866)。 write_document およびその他のセマンティック ツールの呼び出しは、ドキュメントが資格情報についてのみ説明している場合 (#14937)、または資格情報と思われるテキストが含まれている場合 (#15301) に失敗しなくなりました。長く接続されている MCP ツール名はプロバイダーの制限に合わせてエイリアス化されており、回復通知には、続行オプションで実行がキャンセルされた理由が説明されています (#14951)。タスク中にツール接続が変更された場合、エージェントはタスク コンテキストを保持します (#14963)。ネイティブ MCP ゲートウェイは、所有者以外のエージェントからの実行トークンを拒否します (#14914)。また、Codex ランナーの「無関係なプロバイダー情報が無視されました」という警告は、チャットではなく実行ログに残ります (#14929)。
  • サンドボックスとワークスペース — エージェントがブランチをリベースまたは修正した後、サンドボックスの実行が workspace_restore_failed で失敗しなくなりました (#15268)。 Daytona ドライバーは、サイレントになったログ ソケットから出力を回復します (#14889)。ブリッジ制御コマンドは 30 秒に制限されており、アクティブな実行には 5 分間沈黙が続くと疑わしいとフラグが立てられ、15 分が経過するとクリティカルとしてフラグが立てられます (#14979)。マルチリポジトリ プロジェクトは、SSH 実行環境でラウンドトリップ コミットを実行します (#14782)。 Paperclip リポジトリ自体の分離ワークツリー タスクは、ローカル シード構成なしで設定されています (#14810)。また、標準の Docker イメージにはリモート プロバイダー パックがバンドルされているため、リモート OpenCode と ACPX の実行が runner_remote_provider_artifact_incompatible で失敗することはなくなりました (#14854)。
  • チャットとタスク UI - ステアリングと割り込みはメッセージをすぐに表示し、モデルや作業量が変更された後でもアクティブな実行に配信し、停止したネイティブ スタートアップは再試行を提供します (#15015)。ネイティブ実行が失敗した後に送信されるメッセージはハングしなくなり、正確に 1 回配信されます (#14857)。古い「実行失敗」、「停止」、および「再開待ち」マーカーは、後の試行によって置き換えられると消えます (#14874)。却下されたエージェントの質問はタスク フィードに残り、回答可能なままになります (#15229)。確認カードには、ソース ワークスペースの準備ができるまで、click (#14893) でエラーが発生するのではなく、「承認を準備中…」と表示されます。保存されていないエージェント チャットは、3 秒ごとにブラウザ パネルにドラフト ID をポーリングしなくなりました (#15298)。スレッドは古い送信またはキャンセル アクションを呼び出さなくなりました (#14863)。モバイルタスクページには、不透明なフッター、より安定したスクロール、フルハイトのドキュメントパネル、およびインプレースドキュメントリンク (#15228) が追加され、新しい出力はコンポーザーの上に留まります (#15282)。完了した作業キャレットはラベルの横にあり (#15048)、コンポーザー ラベルは利用可能な幅を使用し (#15050)、リモート リンクのないブランチ アーティファクトはその旨を示します (#15051)、ダッシュボードには各タスクが 1 回表示され (#14847)、選択された保存済みタスクが表示されます。サブスクリプションは、プロバイダー タイル (#14996) を cli ロックせずに使用できます。
  • 接続とアクセス - エージェント設定により、利用できない個人 AI アカウントを適切な場所に再接続でき、新しく接続されたアカウントがユーザーのデフォルトになります (#14916)。汎用 MCP OAuth は、トークンの有効期限が切れてもアクセスできるように、提供されたときに offline_access を要求します (#14950)。 MCP ツールの検出は、メモリの一部を使用して大規模なカタログに対してクエリを実行し、負荷がかかると同時リストを tool_discovery_busy 503 で制限し、ステートレス エンドポイントでの GET に対する応答は 405 (#14864) になります。 low-trust エージェントは、許可されたスコープ内で自己割り当ての作業を作成し、所有者のチャット (#14870) から自分の管理対象 AGENTS.md を更新し、取り込み境界外で所有者のダイレクト メッセージと人間が割り当てたタスクを受け入れることができます (#14775)。サーバー管理のプロジェクト チェックアウトからの会社スキルのインポートが skill_workspace_boundary_denied (#10329) で失敗しなくなりました。また、管理対象 git/gh ランチャーは、管理対象資格情報なしで続行する前に、失敗した資格情報ブローカー要求を再試行します (#14856)。
  • サーバーの回復力 — ダッシュボードの読み取り (#14873)、スコープ付き読み取りクエリ (#15248)、およびタスク実行リスト (#15300) が再試行され、要求が失敗する代わりに一時的な PostgreSQL が切断され、ルーチン ルートが不正な形式の ID に対して 404 を返します。データベースエラー (#15313) の代わりに。

改善点

  • 実験的な AI 接続プールは、デフォルトでオフになっている enableAiConnectionRouters 設定とルーター プラグイン (#14967) の背後で、各タスクがそのアカウントに固定されたままで、保存された AI アカウント間で新しいタスクをローテーションします。 exe.dev サンドボックス プロバイダーは、ベア VM を作成する代わりに、準備された「ソース VM」のクローンを作成できます (#14975)。ネイティブ ランナー デーモンは任意の --listen-port を受け入れるため、複数のリッスン ランナーがホストを共有できます (#15353)。サーバーは、エージェントの雇用、一時停止、再開、終了イベントの永続的なライフサイクル ジャーナルを保持し、プラグイン フックの基礎としてイベントの作成と更新をプロジェクトします (#15280、#15306)。 Slack、GitHub、MCP、招待状、ルーチン、ハンドオフ プロンプトは 1 つのアニメーション化された「コピー プロンプト」コントロール (#14862) を共有し、Slack セットアップ プロンプトは現在のフロー (#14965) と一致します。アクションごとのテスト ダイアログは、MCP 結果を読み取り可能なテーブルとカードとしてレンダリングします (#14859)。エージェントは、単一の正規質問セット (#14946) から質問カードを作成し、Codex、Claude、OpenCode (#14961) 全体で同一の補完ツール ガイダンスを受け取ることができます。手順テキストの繰り返しは少なく、write_document (#15151) からの正規リンクも含まれます。失敗したリストアと停止タイムアウトは、失敗したステージとその理由を実行結果と Sentry コンテキストに記録します (#15005、#15291、#14990、#14986)。

アップグレード ガイド

  • 移行 0294 ～ 0305 はアップグレード時に実行されます。0294 は tool_mcp_gateway_tokens 有効期限インデックスを追加します。 0295 および 0296 は、アグリゲーター アカウントのスナップショットと同期テーブルを追加します。 0297 は resource_lifecycle_events を追加し、0300 はそのアクション チェック制約を書き換えます。 0298 は tool_connections.agent_instructions を追加し、既存の Honcho、Mem0、Zep、Supermemory、および Cognee 接続のデフォルト命令をバックフィルします。 0299 は AI 接続プール、ルーター カーソル、タスク ピン テーブルに加えて company_secrets.ai_session_epoch を追加します。 0301 ～ 0305 は、パブリック MCP OAuth client、許可、トークン、レシート、イベント サブスクリプション、デバイス フロー、およびアドミッション テーブルを追加します。すべては付加的なものです。 0298 は既存の行を更新する唯一の行です。
  • アップグレードする前に古いプロセスをすべて停止してください (#14869): 新しい SQLite 復元ロック プロトコルは、古いディレクトリ ロックと共存できません。インスタンス ルートに書き込むすべてのサーバーとワーカーをドレインし、残ったレガシー <hash>.lock/ ディレクトリを <instance root>/locks/directory-merge/ から移動してから、新しいバージョンを開始します。ロールバックについても同様です。
  • カスタム ツールの許可を確認する (#14915): 不明なスコープ セレクターまたは不正な制限を持つ許可は、失敗するのではなく拒否されるようになりました。
  • 新しい実験的設定、デフォルトではすべてオフ: 「アシスタント接続 (MCP)」 (enablePublicMcp) はパブリック MCP エンドポイントを公開し、PAPERCLIP_PUBLIC_URL が HTTPS オリジンである必要があります (#14933)。 「受信トレイ + タスク リストの結合」(enableCombinedInboxTasks) は、受信トレイをタスクに折りたたんで、「合理化された UI」がオンになっている間のみ有効になります (#15100)。 enableAiConnectionRouters は接続プールをオンにし、UI 切り替えはありません (#14967)。
  • カスタム アダプターの接続手順 (#15216): HTTP アダプターは、リクエスト本文の最上位 connectionInstructions フィールド (命令が適用されない場合は { text, digest } オブジェクトまたは null のいずれか) を受け取ります。プロセス アダプターは、同じ { text, digest } オブジェクトを保持するプライベート JSON ファイルへのパスである PAPERCLIP_CONNECTION_INSTRUCTIONS_FILE を受け取り、命令が適用されない場合、変数は空の文字列 (パスではない) に設定されます。アダプターは、オブジェクトを渡すのではなく、オブジェクトの text をモデル プロンプトに追加する必要があります。内蔵ハーネスを変更する必要はありません。
  • ハーネス ピンを Codex 0.160.0、Claude Agent SDK 0.3.286 (クロード コード 2.1.286)、および OpenCode 1.18.34 (#14942、#14993) に移動しました。 2.1.284 より古いクロード コードで構築されたカスタム サンドボックス イメージは、Sonnet 5.5 が CLI パスで動作する前に再構築する必要があり、新しいピンでサンドボックス イメージをプロモートする前にコントローラーとランナーをデプロイする必要があります。リモート Codex は、0.161.0 を除く 0.149.0 を受け入れるようになりました。
  • 新しいデフォルト: 新しく作成された標準エージェントはデフォルトの構成許可を受け取りますが、既存のエージェントは変更されません (#15283)。ランナーの --listen-port は依然としてデフォルトの 43127 (#15353) です。サイレント アクティブ実行には、1 時間と 4 時間ではなく 5 分と 15 分後にフラグが立てられ、自動キャンセルは行われません (#14979)。
  • 他の構成や API の変更にアクションは必要ありません。
