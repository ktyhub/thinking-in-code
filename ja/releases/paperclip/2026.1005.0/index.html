#ペーパーclip v2026.1005.0

#紙clip v2026.1005.0

リリース日: 2026-10-05

Paperclip v2026.1005.0 には、2026.1002.0-beta.0 から昇格された 179 のコミットが含まれています。見出しはエージェントがより多くのものを持ち運ぶというものです。Grok Build はネイティブ ランナー上で実行され、エージェントはタスク間で独自のファイルを保持し、会社のスキルは GitHub リポジトリから同期され、ブラウザ使用クラウドはエージェントに人々が監視してタスクを引き継ぐことができるライブ ブラウザを提供します。これらの点を中心に、ほとんどのコネクタはデフォルトで MCP アグリゲータがオンになった 1 つの click にセットアップされ、Slack 会話はボードとスレッドの間で往復し、エージェント チャットは独自のナビゲーションを取得し、完了した作業は会話に戻され、タスク コンポーザーはメッセージごとにモデルと作業量を選択します。その下では、長い信頼性パスにより、ネイティブ ランナー、サンドボックス トランスポート、およびハートビート スケジューラが強化されます。これには、キューに入れられた実行が永続的に拒否されることによって引き起こされるサーバー クラッシュ ループの修正が含まれます。

重大な変更

  • オペレーター UI スニペットの挿入は削除されました。 PAPERCLIP_CLOUD_UI_SNIPPET および PAPERCLIP_CLOUD_UI_SNIPPET_B64 設定では、静的ページまたは開発ページに HTML が挿入されなくなりました。これらに依存しているオペレーターは、アップグレードする前に、統合をプラグイン UI コントリビューションに移動する必要があります。 (#13789)
  • キーボード ショートカットは常にオンになり、その設定は失われます。 インスタンス全体の一般切り替えとユーザーごとのプロファイル設定は両方とも、GET/PATCH /api/auth/preferences ルートとともに削除されます。 PATCH /api/instance/settings/general は keyboardShortcuts を受け入れなくなりました。サインインしているすべてのユーザーのショートカットが有効になりました。 (#14141、#14643)
  • エージェントを @ メンションしても実行が開始されなくなりました。 タスク コメント内のメンションは担当者のコンテキストとして保持されます。明示的な割り当てとレビューのリクエストのみが作業を開始します。メンションを使用して 2 番目のエージェントをタスクに引き込んだワークフローでは、代わりにレビューを割り当てるかリクエストする必要があります。 (#14577)

ハイライト

  • ネイティブ ランナー上の Grok ビルド — Grok Build は、ローカル実行と Daytona 実行の両方で ACP を介して Paperclip ランナーに参加し、別個のサブスクリプション ログインおよび API キー資格情報パスと管理ツールを使用します (#13882)。インストール時にダウンロードするのではなく、サンドボックス所有のバイナリとともにパブリック インストールで出荷されます (#14024)。共有ハーネス ランタイムは Codex 0.156.0、Claude Agent SDK 0.3.280、OpenCode 1.18.32 (#13838) に移行し、モデル カタログと推論コントロールが Claude、Codex、Grok、Gemini、Cursor、Kimi、OpenCode アダプター全体で更新されます。 (#13829)、リモート ネイティブ Codex は、1 つの正確なピン (#13853) の代わりに、0.149.0 からの互換性のあるリリースを受け入れます。
  • エージェントは独自のファイルを保持 — エージェントのディレクトリ (AGENTS.md およびそのサポート ファイル) はタスクおよびセッション全体で保持され、指示エディターと共有されるようになりました。同時実行では、変更されたファイルのみが適用され、新しい保存では、競合プリフライト (#14416) を備えた新しいプレーン ディレクトリ同期トランスポートに加えて、リビジョン履歴 (#14420) が作成されなくなります。ウォーム ネイティブ Codex セッションは、各ターン後に変更されたファイルのみをチェックポイントすることにより、管理ファイルの収集を存続させます (#14735)。
  • GitHub から同期されたスキル — スキルには [ソース] タブが表示されます。既存の GitHub 接続を通じてリポジトリを選択し、インポートするスキル フォルダーを選択し、オンデマンドで更新します。スナップショットがインストールされているため、エージェントは実行中に GitHub をフェッチすることがなく、更新に失敗すると最後の正常なバージョンがそのまま残ります (#14713)。
  • ブラウザー使用クラウド、タスク内で有効 — 新しいブラウザー使用クラウドコネクタにより、エージェントはブラウザー自動化を管理でき、タスクにはインタラクティブなブラウザータブが表示され、人々はそこに沿って進み、ページを引き継ぎ、実行終了後にブラウザーを保持し、実行に対してコストが記録されます (#14627)。
  • 1 つの click で設定された接続 - コネクタの設定はデフォルトを示す 1 つの画面に折りたたまれ、残りは [変更] と [権限] タブの後ろに隠れます (#14811)。 Zapier、Arcade、Composio Connect、および Executor MCP アグリゲータは、実験用トグルが削除された状態でデフォルトでオンになっており (#13964)、インライン タスク カード (#13879) から構成できます。接続検索ではネイティブ アプリが優先され、セットアップ前にユーザーに外部プロバイダーの選択を要求し (#13941)、自然言語クエリを理解します (#14725)。カタログの新機能: サマリー対応ルーチン (#13890) を備えた Fireflies、デフォルトでオフの enableMemoryConnectors 設定の背後にある 5 つの実験的メモリ プロバイダー (Mem0、Zep、Supermemory、Cognee、Honcho)、さらにリモートのネイティブ Codex に配信される割り当てられた MCP ツール (#13942)、および独自のカードとしての GitHub コード レビュー ボットGitHub ツール (#14750) から。貼り付けられた個人の資格情報は、セットアップ、ヘルスチェック、呼び出し時に同じ方法で検証され、新しい接続ではアクションに必要な書き込みスコープが要求されます (#14739)。
  • Slack は双方向に機能します — ボードに入力された返信はリンクされた Slack スレッドに到達し、同じ会話が再開され、割り当てられたエージェントは通常のタスクやスケジュールされたルーチン中に Slack ツールを取得します (#13920)。 Slack 起源のタスクには、周囲のディスカッションを読み、フォローアップを作成し、招待ボット (#13828) を通じて共同作業するための管理されたツールが提供され、応答された会話は進行中 (#13809) のままではなくアイドル状態に落ち着きます。
  • エージェント チャットの成長 — 二次チャット サイドバーとランディング ページが会話に独自のホームを提供します (#14706)。チャットから委任されたタスクは、その完了を永続的にチャットに返します (#14408)。チャットに明確な承認が入力されると保留中のカードが解決され、未回答の質問は履歴に移動され、後で回答できるようになります (#14613)。ネイティブ ワーカーが失われた後もチャットは続行されます (#13813)。
  • 実行を選択するコンポーザー — タスク コンポーザーは、選択されたエージェントに従い、その上に保留中のカードを表示し続け、モバイルでも動作する、メッセージごとのモデルとエフォート ピッカーを取得します (#14322)。エフォート オプションは、ネイティブ ランナーの Codex (#14568、#14576) など、各アダプターが実際に実行する内容と一致します。タスクはプロンプトのみから作成でき、割り当てられたエージェントがタスクに名前を付けます (#14761)。アーティファクトには、プレビュー付きの豊富なカード (#14469)、全行リンク付きの画像とビデオ ギャラリー (#13825)、マークダウンとテキストの添付ファイルがタスク タブで開き、レンダリングされたビュー、生のビュー、およびダウンロード ビューが表示されます (#14297)。
  • 管理された API ツール、デフォルトで有効 - ネイティブ ランナーの search_api および call_api ツールは、環境変数 (#14186) なしで有効になります。大きな API 応答は最大 1 GiB までディスクにストリーミングされ、保存されたテキストは境界付きページで読み取ることができます (#14301)。また、割り当てられたアプリ カタログがツール コントラクトの制限を超えた場合でも、エージェントは検索と呼び出しを通じてそれらのツールにアクセスします (#14218)。

修正

  • ネイティブ ランナーとセッション - ツールの結果は、誤った障害を記録するのではなく、シャットダウンおよび再起動しても存続します (#14734)。失敗したウォーム セッションはサンドボックスが停止する前にリタイアされ (#14747)、回復されたクリーンアップは実行の最終結果を尊重します (#14767)。タスクをウォーム ライフサイクルに切り替えると、再利用可能なリースが取得されます (#14187)。 OpenCode イベント ストリームはターンをまたいで開いたままになり (#14582)、シャットダウン決済を実行します (#14668)。 Codex アカウントの通知でターンが中止されなくなりました (#13902)。クロードおよびコーデックスのクォータ枯渇は、適切なバックオフに分類されます (#13831、#13945)。 ACP 端末の障害は編集されたプロバイダー診断 (#14573) を保持し、ID ガードは失敗したチェックに名前を付けます (#14481)。ネイティブ ジャーナルの読み取り制限はどこでも 256 MiB です (#14711)。受け入れられた結果の保留中のファイナライズは、古いロック スイープ (#14219) から保護されます。アダプターは、ワークスペースの復元前に検証済みのプロバイダー停止を公開します (#14311)。ウォーム セッションは管理された GitHub アクセスの下で実行され続けます (#13815)。また、実行時にプロバイダー認証エラーが発生すると、タスク内でインライン接続カードが提供されるため、ユーザーは修復して続行できます (#14629)。
  • サンドボックスとワークスペース — Daytona コマンドはログ ソケットが閉じた後も存続し (#14799)、リースを再開するときにコンテナの損失が認識されることが確認され (1f3ff75d)、失敗した割り当てはクリーンアップされ (#13979)、プロバイダー取得タイムアウトはドライバーのデフォルトに従います。 (#14097)。 ACP 入力配信はゲートウェイ 502 後に入力を複製せずに再試行 (#14485)、特大の起動ペイロードと複製されたウェイク コンテキストが E2BIG で失敗しなくなりました (#13793、#13891)、リモート終了後にプロセス プロキシが閉じられます(#13777)、セカンダリ リポジトリ内の相対シンボリックリンクは保持されます (#13953)。ワークスペースのエクスポートはファイナライズされ、安全に回復します (#14402)、復元の失敗はアダプターの結果を保持し、何が失敗したかを記録します (#14035、#14064)、大きな Git スナップショットは 1 MiB の出力制限に達する代わりにディスク マニフェストを介してストリーミングされます (#14194、 #14253)、準備状況チェックはより大きなステータス出力を受け入れます (#14414)、バックグラウンド スキャンは Git インデックスの更新を停止します (#14666)、部分的なタスク オーバーライドはプロジェクト セットアップ コマンドを保持します (#14502)、リポジトリ フリーの低 trust タスクは取得されます。プライベート ディレクトリ (#14766)。
  • スケジューラとリカバリ - 要求が永久に拒否されたキューに入れられた実行は、サーバーをクラッシュ ループさせる代わりにキャンセルされます (#14738)。ドレイン中に到着したウェイクはキューに留まり、中断された修正実行は一時的な再試行を取得します (#14028)。実行が再試行バジェットを使い果たした問題は、永久にスキップされるのではなく、目に見えるブロック状態にエスカレートされます (#14046)。継続バジェットと再試行バジェットは永続化状態 (#13888) を使用します。タスクの所有権は、キューに入れられた実行によってアトミックに要求されます (#13973)。古い継続はディスパッチ前にキャンセルされます (#13761)。ステータス応答にブロッキング作業がリストされているため、タスクは続行されます (#14626)。完了タスクとキャンセルされたタスクは、担当者を解放したままにします (#14561)。インタラクションの継続はそのタスクに限定され (ded156a9)、質問の受信者は派生および検証されます (#14742)。レビュー パスを失った Slack および Discord 起源のタスクは、回復承認チェックに失敗するのではなく、メッセージ バインディングをそのままにして回復します (#13818)。リモート Grok 実行は、キューに入れられたメッセージが続行される前に停止します (#14100)。 run-identity ロックが監査挿入でデッドロックしなくなりました (#14478)。また、あいまいなデータベース切断は再生されなくなりました (#14773)。
  • 接続とアプリ - OAuth サインイン チャレンジと再接続状態は、クラッシュとして報告されるのではなく、422 を返します (#13786、#13794)。 MCP OAuth セットアップで失敗またはキャンセルされた同意が説明されます (#13855)。無効化された Slack MCP アプリは実用的なセットアップ手順を取得します (a7d3b17a)。ブローカーと AgentMail の障害では、許可リストに登録された理由コード (#14098、#14768) が保持されます。 Google Chat とドキュメント、スプレッドシート、スライド、カレンダーのプロファイルは、より少ないスコープを要求します (#13820、#14740)。作業成果物は、実行ワークスペース参照 (#14063) を検証します。不正な形式の CLI 認証チャレンジ ID は 400 (#14095) を返します。
  • ボード UI — ボードはサーバーの再起動中に接続メッセージを表示して再試行し、開いているエディターをマウントしたままにし (#14560)、React が開始する前にアプリが失敗した場合には再試行画面を表示します (#13970)。 Lezer バージョンの不一致でコードのハイライト表示がクラッシュしなくなりました (a3749aac)、破壊的な確認ボタンがライト テーマで読み取れるようになりました (#14328)、モバイル ピッカーがキーボードの上に表示され、タッチでスクロールします (#14022、#14249、 #14250、#14599)、新しいドラフトはレシートのクリーンアップに残ります (#14332)、他のユーザーの失敗した実行は Mine から除外されます (#14572)、「リカバリが必要」は「リカバリ中」とは区別されます(#14326)、リカバリがブロックされたときに誤解を招く再試行が表示されなくなりました (#13775)、新しいアーティファクトはパネルを開かずにタブを登録します (#14193)、タスクパネルには祖先が表示されます (#13823)、並列サーバー読み取りによりタスクの内容がより早く表示されます。 (#14727)。また、プロパティ アイコンはアバターと一致し (#13319)、ランナーのコメントは返信と一致し (#14716)、プロジェクト保存インジケーターはラベルの下にスタックされ (#14765)、企業のアーカイブは移動します (#13846)、実験的な設定は次のとおりです。空のグループが非表示になっている状態でアルファベット順に並べられており (#13905)、カーソル アダプターはトレース通知 (#14636) よりも実際のエラーを選択します。
  • 可観測性 — ブラウザー エラーには、SENTRY_ENVIRONMENT (#13784) および境界付きコンポーネント コンテキスト (#13904) が含まれます。実行エラーは後の例外から分離され、実行時機能ヘッダーは編集されます (#13826)。実行失敗レポートには、終了の詳細、スタック、原因、実行時アクティビティ、およびリストア分類 (#14575、#14585、#14665、#14639、#14787) が保持されます。

改善点

  • アカウント メニューはヘッダー リンクのプロフィール行を削除し、招待ショートカットを取得します (#14480)。プラグインは組織スイッチャー (#13832、#13854) を提供できます。 PAPERCLIP_HIDDEN_SETTINGS は名前付き例外を持つワイルドカードを受け入れるため、新しい実験的フラグは自動的に非表示のままになり (#13980)、workspaces.isolation キーは分離コントロールを非表示にします (#13907)。ネイティブ ランナーは、今後の Cursor、GitHub Copilot、Pi プロバイダー (#14430) 用の共有リッチ ACP トランスポート基盤を獲得します。ネイティブ エージェントは、閉じられた許可リスト (#13852) から呼び出し元のランタイム構成を継承する管理された hire_agent アクションを通じてチームメイトを雇用できます。調整スキルは、エージェントに誰が行動できるかを尋ねるのではなく、マネージャーを通じてエスカレーションするように指示することはなくなりました (#14188)。ワークツリーのシードソースの障害は、サポートされているセットアップを説明します (#14795)。 Google OAuth 検証が保留中の間、Google Workspace コネクタは [接続] ページで一時的に非表示になり、保存された接続とランタイム アクセスは変更されません (#14774)。また、README が最新のハーネス、ガイド リンク、npx-first クイックスタート (#14741、#14744) で更新されます。

アップグレード ガイド

  • 移行 0284 ～ 0293 はアップグレード時に実行されます。0284 はユーザーごとの keyboard_shortcuts 列を追加し、0289 は削除します。 0285 は assets.byte_size を bigint に拡張します。 0286 は、API 応答キャプチャ予約を追加します。 0287 は、永続エージェント ファイルのエージェント命令ヘッド、リビジョン、および作業コピーを追加します。 0288 は、チャット完了配信とタスクの引き継ぎを追加します。 0290 は、ブラウザー使用クラウド セッション、実行、およびブラウザーを追加します。 0291 ～ 0292 は企業スキルのソースとエントリを追加し、0291 は github.com からインポートされた既存のスキルも採用します (リポジトリおよび追跡参照ごとに 1 つのソース、スキルごとに 1 つのエントリ、および各スキルのメタデータに legacySkillSourceId / skillSourcePath がスタンプされます。GitHub エンタープライズ ホストからインポートされたスキル、バンドルされたスキル、およびカタログ スキルはそのまま残され、プロバイダーのリクエストやコンテンツの書き換えは行われません)起こる）; 0293 は issues.title_needs_generation を追加します。
  • オペレーター UI スニペットが削除されました (#13789): PAPERCLIP_CLOUD_UI_SNIPPET および PAPERCLIP_CLOUD_UI_SNIPPET_B64 は無視されます。アップグレードする前に、統合をプラグイン UI コントリビューションに移動してください。
  • キーボード ショートカット設定が削除されました (#14643): /api/auth/preferences を呼び出すか、keyboardShortcuts を一般設定ルートに送信するオートメーションを削除します。
  • エージェントがディスパッチしなくなったと言及 (#14577): 割り当てまたはレビュー リクエストを使用して、別のエージェントをタスクに参加させます。
  • 新しいデフォルト: PAPERCLIP_RUNNER_API_TOOLS_ENABLED が true 以外に設定されていない限り、ネイティブ ランナーの API ツールは有効になります。 PAPERCLIP_RUNNER_API_TOOLS_COMPANY_IDS は依然としてそれらを絞り込みます (#14186)。 MCP アグリゲーターは、以前の enableMcpAggregators フラグ (#13964) なしで使用できます。
  • 新しい環境変数、すべてオプション: PAPERCLIP_RUNNER_API_COMPANY_CAPTURE_MAX_BYTES は、企業ごとにキャプチャされた API 応答バイト数を制限します (デフォルトは 20 GiB、最小 1 GiB; #14301)。 PAPERCLIP_WORKSPACE_GIT_SNAPSHOT_TIMEOUT_MS はワークスペースのスナップショット時間 (デフォルトは 30 分、最大 24 時間) を制限し、PAPERCLIP_WORKSPACE_MANIFEST_MIN_FREE_BYTES はスナップショット マニフェスト用の空きディスク予約を設定します (デフォルトは 256 MiB、最小は 64 MiB; #14253)。 Codex ACP の実行では、OPENAI_API_KEY (#14322) の代わりに CODEX_API_KEY を受け入れます。
  • ハーネス ピンを Codex 0.156.0、Claude Agent SDK 0.3.280、OpenCode 1.18.32 (#13838) に移動しました。共有インストールでは、プロバイダー CLI を更新して一致させる必要があります。
  • 他の構成や API の変更にアクションは必要ありません。
