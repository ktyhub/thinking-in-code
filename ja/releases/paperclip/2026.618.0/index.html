#ペーパーclip v2026.618.0

#ペーパーclip v2026.618.0

リリース日: 2026-06-18

ハイライト

  • スキル ストア - 専用のアプリ内ストアからエージェント スキルを参照、インストール、管理できるため、ファイルを手動で接続することなくエージェントに新しい機能を提供できます。スキルは、インストール数と企業範囲のカタログを備えた最上級のインストール可能なユニットになりました。 (#7990、@cryppadotta)
  • セルフホスト可能なサンドボックス実行 - クラウド/サンドボックス エージェントの実行が成熟: セルフホスト可能な Kubernetes サンドボックス プロバイダー プラグインが、サーバー側の Kubernetes 実行統合と強化されたエージェント ランタイム イメージ、および新しい Novita サンドボックス プロバイダーと並んで導入されます。独自のインフラストラクチャまたはクラウド プロバイダー上の分離されたサンドボックスでエージェントを実行します。 (#5790、#7938、#7934、@stubbi; #7595、@Alex-yang00)
  • 企業ごとのマルチテナント分離 - 共有およびクラウド展開のための主要なセキュリティ基盤: 各企業は独自の JWT 署名キーを取得し、クラウド テナントは厳密に企業スコープ (インスタンス管理者ではない) になり、プラグイン テーブルには company_id 外部キーが含まれるため、プラグイン データはテナントごとに分離されます。 (#5864、#7525、#5865、@stubbi)
  • ワークスペース ファイル ビューアとアーティファクト リンク - エージェントが問題から直接生成したファイルを検査します。組み込みのワークスペース ファイル ビューアとアーティファクト リンクにより、スレッドを離れることなく作業成果物を開くことができます。 (#7681、@cryppadotta)
  • ローカル アダプターの環境主導型ゲートウェイ ルーティング - codex、pi、opencode、および gemini ローカル アダプターは、環境構成 (カスタム プロバイダー、小型/安価なモデルの選択、リモートのすべて許可) を介してカスタム プロバイダーとゲートウェイを経由してルーティングできるようになりました。これは、独自のモデル ゲートウェイを実行するための重要な前提条件です。 (#7919、#7920、#7837、#7918、@stubbi)

改善点

  • より強力なエージェント - ハートビート、リカバリ、および実行ロックの修正の大規模なバッチにより、インスタンスの回復力が向上します。実行ロックはエージェント間の再割り当て時に解放され、古い executionRunId/checkoutRunId はリリース、再割り当て、チェックアウト、および実行のファイナライズ (バックストップ スイーパーを使用) 時にクリアされ、実行がファイナライズされると孤立した実行ロックがクリアされ、古いチェックアウト実行の所有権が安全に採用されます。 (#5110, @vbalko-claimate; #2482, @alcylu; #6008, @nicorodrigues; #4318, @AyeletMorris-ShieldFC; #5413, @ivasuy)
  • よりスマートなリカバリ - 行き詰まった問題のリカバリでは、保留中のウェイク インタラクションの問題がスキップされ、担当者が最近の目に見える進捗を示した場合はエスカレーションが免除されるようになりました。これにより、エージェントがアクティブに行っている作業が中断されることがなくなりました。 (#4854、@ming0627; #5213、@sunghere)
  • ルーチンの詳細ページ - ルーチンの詳細ページには、サブサイドバーのレイアウトが再設計され、さらに洗練されたフォローアップが追加され、繰り返しのルーチンを読みやすく、調整しやすくなっています。 (#7848、#7858、@cryppadotta)
  • システム テーマに従ってください - 初めての訪問者はデフォルトで OS prefers-color-scheme を使用するようになり、非認証認証ページにテーマの切り替えが表示されます。 (#5873、#5874、@stubbi)
  • OpenTelemetry 自動インスツルメンテーション - サーバーはオプトイン OpenTelemetry 自動インスツルメンテーションをサポートしているため、Paperclip を既存の可観測性スタックに接続できます。 (#3735、@stubbi)
  • プロキシ対応の trust 構成 - TRUST_PROXY は CIDR リストと名前付きサブネットを受け入れるようになり、ロード バランサーやリバース プロキシの背後で正しい ZZPH100​​ZZent-IP 処理を構成するのがはるかに簡単になりました。 (#5872、@stubbi)
  • Codex local 用 GPT-5.5 - GPT-5.5 が codex_local アダプターのモデル オプションで利用できるようになりました。 (#5575、@Buywatermelon)
  • 自動ビルドされたバンドル プラグイン - バンドルされたプラグインはインストール時に自動的にビルドされるため、手動でビルドする必要がなく、すぐに機能します。 (#8254、@devinfoley)
  • 昇格された権限を持たない読み取り専用エージェント構成 - 読み取り専用エージェント構成とスキル エンドポイントには agents:create 権限が必要なくなり、権限の低いプリンシパルでも構成を検査できます。 (#3725、@stubbi)
  • 承認されたレビュー コメントの自動補完 - 承認されたレビュー コメントが自動補完されるようになり、レビュー ループから手動ステップが削除されます。 (#5839、@tommypoltev)
  • 秘密はログに残らない - HTTP エラー ログ行でパスワードとトークンが編集されるようになったので、資格情報がログに漏洩することはありません。 (#8013、@devinfoley)
  • アカウント メニューのフィードバック ショートカット - アカウント フライアウト メニューにフィードバック項目が追加され、コンテキストに沿った迅速なフィードバックが可能になりました。 (#7854、@scottong)
  • Hermes カスタム プロバイダー - Hermes アダプタはカスタム プロバイダーを引数として渡すようになりました。そのため、プロバイダー設定が尊重されます。 (#8231、@cryppadotta)

修正

  • エージェント設定保存トースト - エージェント設定を保存すると成功トーストが表示されるようになり、変更が適用されたことを明確に確認できます。 (#1931、@bluzername)
  • 追加の引数フィールドでカンマが破損しなくなりました - 追加の引数フィールドにより、入力中にカンマ区切りの値が破損することがなくなりました。 (#2125、@tvskart)
  • デスクトップ シェルは固定されたままになります - scrollIntoView が本体の前を通り過ぎても、デスクトップ シェルはウィンドウ スクロールしなくなり、コメント送信時に固定されたままになります。 (#8071、@devinfoley; #8041、@dosthcpp)
  • ルーチン変数の検出 - アンダースコアがマークダウンエスケープされている場合でも、ルーチン変数が検出されるようになりました。 (#8056、@devinfoley)
  • 鉄道の互換性 - 鉄道の互換性のために、VOLUME キーワードが画像から削除されました。 (#2619、@br-creative)
  • 既に正しいユーザーの場合は gosu をスキップ - プロセスがターゲット ユーザーとして既に実行されている場合、起動は gosu をスキップします。 (#2908、@stubbi)
  • OpenClaw Gateway - OpenClaw Gateway の統合が完了し、安定しました。 (#2322、@DissidentAI)
  • ウォッチドッグ ノイズ - ソース発行がブロックされている場合、または評価がボードクローズされている場合、ウォッチドッグは繰り返しのアラートを抑制するようになりました。 (#5942、@dbezar)
  • アダプター/モデル スワップ全体でのセッションの継続性 - アダプター スワップ間またはエージェントのモデルが変更された場合に、ハートビートは古いランタイム sessionId を再利用しなくなり、セッション ID は --resume より前の UUID として検証されます。 (#4109、@kengraversen; #4195、@nirarazi; #1742、@nydamon)
  • アダプター セッションの自己修復 - ローカル アダプターはより適切に回復します。gemini_local はトークン オーバーフローを新しいセッション信号として扱い、claude_local は汚染された previous_message_id 400 から回復し、再開中にクロード「イメージを処理できませんでした」400 秒で自動再試行を実行します。 (#4932、@sherifkozman; #5972、@redmutex; #3276、@nullEFFORT)
  • Codex ローカル認証処理 - codex_local は、準備時に古い auth.json コピーをシンボリックリンクに置き換え、デフォルト モデルを省略して、CLI が認証モードごとに選択するようにし、EEXIST シンボリックリンク レースのテスト カバレッジが追加されています。 (#5240、@HKTITAN; #7971、@devinfoley; #5269、@abhishekgahlot2)
  • ゾンビの実行はもうありません - ゾンビの実行合体が防止され、ハートビート タイマーが作動する前にスタートアップ リープが完了します。 (#1731、@carmandale)
  • セルフコメントの再開ガード - 同一実行のセルフコメントはスキップされ、最終的な問題は担当者のセルフコメントによって再開されないように保護されます。 (#4973、@roy493; #4346、@NiViGaHo)
  • 新しいセッションのウェイクを延期する - 同じ問題の強制フレッシュ セッションのウェイクは、現在の実行を中断するのではなく、フォローアップの実行に延期されます。 (#4080、@xidui)
  • ステータス フィルターは配列を受け入れます - 問題リスト エンドポイントは配列形式の ?status= フィルターを受け入れるようになり、キーを繰り返してもクラッシュしなくなりました。 (#4890、@Lempkey)
  • ボード メンバーの可視性アクション - ボード メンバーは、エージェントがすでに持っていたヌルマップされた可視性アクションを実行できるようになりました。 (#7935、@HKTITAN)
  • Cron 分ステッパーのパフォーマンス - Intl.DateTimeFormat は、cron 分ステッパーのタイムゾーンごとにキャッシュされるようになり、ティックごとのオーバーヘッドが削減されます。 (#8034、@aronprins)
  • マネージド サンドボックスの重複排除 - 部分的な一意のインデックスによってマネージド サンドボックスの行が重複排除され、Kubernetes プロバイダーはサンドボックス ポッドを正確な名前で解決します。サンドボックス ワークスペースは、所有されていないターゲット ディレクトリでの EPERM を回避するために、エントリごとに tar が適用されます。 (#8247、@devinfoley; #7982、#7836、@stubbi)
  • オーファン スイープ回帰 - スイーパーが適切な問題を対象とするように、オーファン スイープの null 担当者フィルター回帰を修正しました。 (#8018、@devinfoley)
