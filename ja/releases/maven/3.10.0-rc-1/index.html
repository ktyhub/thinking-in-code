maven 3.10.0-rc-1

プレリリース 公開日2026年7月13日 出典apache/maven 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#maven maven-3.10.0-rc-1

<!-- オプション: ここにリリースの概要を追加します -->

:boom: 重大な変更

  • スーパー POM からリリース プロファイルを削除 (#11999) @slawekjaranowski
  • スーパー POM から非推奨のプラグイン管理を削除 (#11986) @slawekjaranowski

🚀 新機能と改善点

  • フィーチャー: Maven 3.10.x と 4.0.x を揃える (#12442) @cstamas
  • 機能: CP の順序を Maven 4 と調整する (#12327) @cstamas
  • 機能: 最新のリゾルバー 2.0.19 の変更を適用 (#12246) @cstamas
  • フィーチャー: Maven 3.10.x super POM (#12032) @cstamas
  • 失敗したビルドでリアクターの概要を失敗したモジュールのみに制限 (#11977) @slawekjaranowski
  • Maven スタートアップ バナーにタイム ゾーンを追加 (#11972) @slawekjaranowski
  • 機能: バージョン範囲フィルターと (#11955) @cstamas
  • 機能: サイトのライフサイクルを無効にする機能 (#11970) @cstamas
  • MavenSimpleLogger でのログ レベルのレンダリングの最適化 (#11969) @slawekjaranowski
  • 機能: CLI (#11948) @cstamas によるリゾルバー 2.x 更新ポリシー制御
  • JavaToolchain での Java バージョンの昇格 (#11968) @slawekjaranowski
  • フィーチャー: Transitive dep マネージャー (#11939) @cstamas
  • 3.10.x slf4j を 2.0.17 (#11880) @olamy にアップグレードします
  • MD のダウンロードを常に強制しないでください (#11908) @cstamas
  • 機能: ユーザー再配置バックポート (#11937) @cstamas
  • 機能: バージョン範囲フィルタリング (#11936) @cstamas
  • 補間とプロファイルのアクティブ化のために project.rootDirectory を昇格 (#11930) @slawekjaranowski
  • フィーチャー: 新しいアーティファクト ハンドラー: fatjar (#11928) @cstamas
  • 機能: コアを JSR330 に移行 (#11916) @cstamas
  • JAnsi から JLine に移行し、MessageBuilderFactory を導入します (#11874) @slawekjaranowski
  • 機能: session.topDirectory と session.rootDirectory を昇格 (#11779) @cstamas
  • フィーチャー: Maven 3.x とリゾルバー 2.x (#11778) @cstamas
  • 機能: Maven 3.x 拡張機能の処理を一般化 (#11777) @cstamas

🐛 バグ修正

  • [#12288] バックポート: settings.xml activeByDefault プロファイルを LRM に設定 (#12333) @ascheman
  • JDK 11 での不正な反射アクセス警告を修正 (修正 #12167) (#12339) @gnodet
  • 問題 #12188 ログ出力のファイルへのリダイレクトがすべてをリダイレクトしない (#12189) @olamy
  • 完全な Apache ライセンス 2.0 テキスト (#12063) @slawekjaranowski を使用してバイナリ配布ライセンスを更新します
  • バグ: RSS はシードされましたが公開されませんでした (#12033) @cstamas
  • リゾルバー api 2.x からスコープ パッケージをエクスポート (#12023) @slawekjaranowski
  • MavenProject#getPluginManagement が null を返さないようにします (#12010) @slawekjaranowski
  • 設定モデルから冗長な必須属性を削除 (#12005) @slawekjaranowski
  • Maven モデルから冗長な必須属性を削除 (#11985) @slawekjaranowski
  • バグ: 設定の補間と厳密な解析 (#11776) @cstamas
  • スペースで囲まれた入力を受け入れるように threadConfiguration をトリム (#11851) @pzygielo

📝 ドキュメントの更新

  • スキャナーの検出可能性のための AGENTS.md + SECURITY.md セキュリティ モデル ポインターを追加 (#12444) @potiuk
  • デフォルトのプラグインのバージョンを文書化 (#12382) @hboutemy
  • Maven 3.10.x サイト (#12370) @cstamas
  • [[ISSUE-10329] - ](https://issues.apache.org/jira/browse/ISSUE-10329) - UrlNormalizer (バックポート) のドキュメント動作 (#12294) @gnodet
  • Maven-jline の Maven deps ダイアグラムを更新 (#12068) @Will-thom
  • サポートされている唯一の値を文書化します: 4.0.0 (#11859) @slawekjaranowski

👻メンテナンス

  • Apache-Maven サブプロジェクトのソース + バイナリのプッシュ to ATR プロファイル (#12450) @hboutemy
  • スキャナーの検出可能性のための AGENTS.md + SECURITY.md セキュリティ モデル ポインターを追加 (#12444) @potiuk
  • 非推奨のメソッドを削除するには (#12328) @cstamas を使用します
  • def セッションビルダーにインターフェイス (#11967) @cstamas を持たせる
  • 機能: Maven JAR マニフェストに自動モジュール名を追加 (#11921) @cstamas
  • 3.10.x ブランチ (#11834) の CI を構成します @slawekjaranowski
