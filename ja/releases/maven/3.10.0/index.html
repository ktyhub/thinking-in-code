maven 3.10.0

#maven maven-3.10.0

<!-- オプション: ここにリリースの概要を追加します -->

🚀 新機能と改善点

  • Maven 3.10.x は Maven 3.1 検証を厳密モードで使用する必要があります (#1542) @gnodet
  • maven-resolver-supplier-mvn3 (#13266) @cstamas に依存しないでください。
  • [MNG-6797] - Maven モデルの問題が発生したかどうかを思い出してください。 (#298) @wilx
  • 偉業:relativePath 検証を追加 (#12742) @cstamas
  • Plexus ベースのプラグインの依存関係注入の検証を追加 (#12651) @slawekjaranowski
  • 検証コントロールの導入 (#12549) @cstamas
  • リゾルバー 2.0.21 への更新 (#12504) @cstamas
  • [MNG-5913] - settings.xml で既存のサーバー構成のエイリアスを定義できるようにします (#12475) @slawekjaranowski

🐛 バグ修正

  • 問題 #13265: 設定サーバーに、その資格情報が (#13275) @slawekjaranowski で使用できるリポジトリの起点を宣言させます
  • バックポート #13040: リアクター BOM インポートを ProjectSorter エッジとして扱うため、-am にそれらが含まれます (#13263) @gnodet
  • [MNG-8174] - プラグイン構成でプロパティがそれ自体を参照する場合の NPE を修正 (バックポート #12932) (#12936) @elharo
  • 修正 #13200: MavenProject.getArtifacts (#13204) @gnodet から完全なセットを公開する
  • 修正 #13135: リアクターの概要、特権の完全性を保証します… (#13173) @rmannibucau
  • [3.10.x] 修正 #13084: 外部モデル ビルドのサンドボックス プロファイル アクティベーション コンテキスト (#13114) @gnodet
  • 修正 #13100: 正当にアクティブな外部モデル プロファイルからリポジトリを優先する (#13116) @gnodet
  • jvm.config に MAVEN_PROJECTBASEDIR 置換のサポートを追加 (3.10.x への MNG-8598 のバックポート) (#13115) @gnodet
  • サーバー資格情報のスコープを設定し、従来の再配置座標を検証します (#12954) @slachiewicz
  • 設定されたポリシーを尊重し、レガシー互換パス (#12978) @gnodet 上の入力を検証します
  • フォークされた実行における #12600 null-guard の単体テストを追加 (#12923) @gnodet
  • 修正: 並列ビルドに対して ProjectIndex をスレッドセーフにする (バックポート #12832) (#12927) @gnodet
  • 誤って設定されたプラグイン要求のツールチェーンで失敗する (#12616) @wilx
  • Maven 3.x のリアクターから分類された POM アーティファクトを解決 (#12659) @wilx
  • [3.10.x] bin/mvn の MSYS2 および jvm.config プレースホルダーのパスを変換 (#12567) @gnodet
  • プラグイン アーティファクトの依存関係スコープを保持 - #12497 (#12503) を修正 @slawekjaranowski

📝 ドキュメントの更新

  • ドキュメント: ドキュメント plugin.xml V4 と V3 (#13261) @gnodet
  • [maven-3.10.x] サイトのドキュメントを APT から Markdown に移植します (#12712) @slachiewicz
  • 非推奨のプラグイン記述子の要件に関するドキュメントを改善 (#12555) @hboutemy
  • Plexus XML についての言及を削除 (#12482) @cstamas

👻メンテナンス

  • [3.10.x] メンテナンス: プロファイルの使用を調整 (#13274) @cstamas
  • Rat ディレクトリ展開からバージョンを削除 (#13046) @slawekjaranowski
  • 配布パッケージの NOTICE ファイルを更新 (#13044) @slawekjaranowski
  • リポジトリで解決されたモデルがビルドに寄与するものを制限する (#12953) @slachiewicz
  • アーティファクト解決中の座標とリポジトリの優先順位を検証する (#12952) @slachiewicz
  • [MNG-8129] - 相対パス検証コメント (#12966) @gnodet を明確にします
  • [12811] plexus-cipher を 2.0 に保持: POM メモ (#12879) @slachiewicz
  • [3.10.x] try-with-resources を使用する (#12845) @slachiewicz
  • embedder-test-project フィクスチャを JUnit 5 (#12717) @slachiewicz に移行します。
  • [maven-3.10.x] サイトのドキュメントを APT から Markdown に移植 (#12712) @slachiewicz
  • Maven Embedder テストでレガシー プラグインの Javadoc アノテーションを移行 (#12708) @wilx
  • 依存関係の解決でカスタム GraphLogger を DependencyGraphDumper に置き換えます (#12639) @slawekjaranowski
  • UTを修正: チェックアウトを直接使用しないでください (#12483) @cstamas

🔧 ビルド

  • nicoulaj チェックサム プラグインを maveniverse チェックサム プラグイン (#13053) @slawekjaranowski に置き換えます。
  • 3.10.x JDK 25 によるビルド、JDK をビルド内の最小および最大 LTS に制限 (#12848) @slawekjaranowski
  • GH 構成で Maven バージョンを 3.10.0-rc-1 に更新 (#12847) @slawekjaranowski
