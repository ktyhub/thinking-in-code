#maven maven-4.0.0-rc-7

このリリース候補は、コミュニティからのフィードバックを待って、Maven 4.0.0 GA リリース前の最後のリリースとなる予定です。今後数週間以内に公開する予定です。

🚀 新機能と改善点

  • API の機能強化と Mojo MDC (#12690) @gnodet を記録します。
  • リアクターのソートと位相比較器のパフォーマンスを最適化 (#12901) @gnodet
  • AsyncDrainWriter を追加して、PrintWriter のロック競合を排除します (#12892) @gnodet
  • Plexus ベースのプラグインの依存関係注入の検証を追加 (#12649) @slawekjaranowski
