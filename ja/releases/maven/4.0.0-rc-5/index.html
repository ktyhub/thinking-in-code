注意事項

Maven 4 のこの新しいリリース候補は、ユーザーからのフィードバックを得るためにリリースされました。 Maven 4 には Maven 3 と比較していくつかの制限があるため、Maven 4 で投影する前に必ず mvnup ツールを実行してください。

Bean 設定のバグ

フィールドのアクセシビリティ状態がグローバルにキャッシュされる Bean 設定システムにバグが見つかりました。これにより、ビルド中に同じ構成フィールドに複数回アクセスしたり、異なるコンテキストでアクセスしたりすると、プラグイン構成の挿入が失敗する可能性があります。これは特にプラグインの単体テストに影響します。

これは次のリリースの #11433 で修正される予定です。

v4 API の同時実行性の問題

Maven 4 API (まだプレビュー モード) で同時実行の問題が見つかり、次のリリースの #11428 で修正される予定です。

BOM のパッケージ化

BOM プロジェクトの処理方法で別のバグが見つかりました。プロジェクトで BOM パッケージ化が使用されている場合、コンシューマ POM は標準 POM パッケージ化に適切に変換されず、場合によっては依存関係のバージョンが失われる可能性があります。

これは次のリリースの #11427 で修正される予定です。

macOS: JLine ネイティブ ライブラリは、最初の使用時に Gatekeeper によってブロックされる可能性があります

macOS (特に Apple Silicon) では、mvn の最初の呼び出しが次のようなエラーで JLine ネイティブ端末ライブラリのロードに失敗する場合があります。

java.lang.UnsatisfiedLinkError: .../libjline-native/Mac/arm64/libjlinenative.jnilib: dlopen(...): code signature ... not valid for use in process: library load disallowed by system policy

これは、com.apple.quarantine extended 属性を適用するバイナリ配布が Web ブラウザ経由でダウンロードされるときに発生します。

回避策 (1 回限りの修正):

xattr -r -d com.apple.quarantine /path/to/apache-maven-4.0.0-rc-5/lib/jline-native

推奨されるダウンロード方法 (問題を完全に回避します):

curl -L -O https://archive.apache.org/dist/maven/maven-4/4.0.0-rc-5/binaries/apache-maven-4.0.0-rc-5-bin.tar.gz
tar -xzf apache-maven-4.0.0-rc-5-bin.tar.gz

これは既知の問題 #10747 であり、将来のリリースで解決される予定です。
