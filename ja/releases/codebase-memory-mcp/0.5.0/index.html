コードベースメモリ mcp v0.5.0

C への書き換えを完了する

v0.5.0 は、完全に C から構築された最初のリリースです。パイプライン、ストア、MCP サーバー、CLI、ウォッチャーなどのコードベース全体が Go から C に書き直され、CGo 経由でコンパイルされたツリーシッター文法が 64 言語すべてでベンダーの C ソースに置き換えられました。

これにより何が可能になるか

  • RAM ファースト パイプライン: すべてのインデックス作成はメモリ内で実行されます (LZ4 HC 圧縮読み取り、メモリ内 SQLite、最後に単一ダンプ)。一括ロードから最終書き込みまでのディスク I/O はゼロです。
  • Aho-Corasick マルチパターン マッチングの融合: 呼び出し解決では、AST 上の単一パスを使用し、すべてのパターンを同時にロードし、逐次的な関数ごとの grep を置き換えます。
  • C/C++ ハイブリッド LSP リゾルバー: テンプレート置換、スマート ポインター チェーン、オーバーロード スコアリング、ラムダ/decltype 推論、仮想ディスパッチ -- 700 以上の専用テスト。
  • mimalloc グローバル アロケータ: すべての割り当て (グローバル オーバーライドを介した C + C++) を追跡し、ワーカーごとの正確なメモリ割り当てを可能にします。
  • CGo 境界オーバーヘッドなし: すべてのツリーシッター解析は純粋な C で行われ、ファイルごとの CGo ホップはありません。

パフォーマンス

Linux カーネルのインデックス作成 (28M LOC、75K ファイル):

  • フルモード: 210万ノード、5分33秒(Apple M3 Pro)
  • 高速モード: 1.88M ノード、1 分 12 秒 (Apple M3 Pro)

新機能: グラフ視覚化 UI

v0.5.0 は 2 つのバリエーションで出荷されます。

  • 標準 -- MCP サーバーのみ (より小さいバイナリ)
  • ui -- MCP サーバー + 埋め込み 3D グラフ視覚化 UI を有効にします。 ```バッシュ codebase-memory-mcp --ui=true --port=9749 ``` 次に、http://localhost:9749 を開いてナレッジ グラフを視覚的に探索します。 UI はローカルホスト上でバックグラウンド スレッドとして実行され、埋め込みフロントエンド アセットを提供し、読み取り専用 SQLite 接続にクエリをプロキシします。

セッションの自動検出 + 自動インデックス

MCP サーバーは、セッション開始時に作業ディレクトリからプロジェクト ルートを検出するようになりました。構成ストアと組み合わせると、次のようになります。 ```バッシュ codebase-memory-mcp config set auto_index true ``` 有効にすると、最初の MCP 接続時に新しいプロジェクトのインデックスが自動的に作成され、ウォッチャーはそれらを継続的な git ベースの変更検出用に登録します。以前にインデックス付けされたプロジェクトは、この設定に関係なく常にウォッチャーに登録されます。 構成 CLI は、`list`、`get <key>`、`set <key> <value>`、`reset <key>` をサポートします。

マルチエージェントのインストール (8 つのコーディング エージェント)

`codebase-memory-mcp install` は インストールされているすべてのコーディング エージェントを自動検出し、MCP サーバー エントリ、命令ファイル、およびサポートされているプレツール フックを使用して各エージェントを構成するようになりました。 |エージェント | MCP 構成 |説明書 |フック | |------|-----------|---------------|------| |クロード・コード | .claude/.mcp.json | 4 スキル（指示パターン） | PreToolUse on Grep/Glob/Read | |コーデックスCLI | .codex/config.toml | .codex/AGENTS.md | -- | |ジェミニ CLI | .gemini/設定.json | .gemini/GEMINI.md | grep/read の BeforeTool | |ゼッド |設定.json (JSONC) | -- | -- | |オープンコード |オープンコード.json | .config/opencode/AGENTS.md | -- | |反重力 | mcp_config.json | .gemini/antigravity/AGENTS.md | -- | |エイダー | -- |規約.md | -- | |キロコード | mcp_設定.json | ~/.キロコード/ルール/ | -- |

エージェントの動作の改善

エージェントはコード検出に grep/glob/read よりも MCP ツールを積極的に好むようになりました。

  • ディレクティブ スキルの説明 は ~100% の自動アクティベーションを達成します (古い説明パターンでは ~37% から増加)
  • PreToolUse / BeforeTool フック エージェントが組み込みの検索ツールに到達したときにアドバイスのリマインダーを印刷します
  • キーワードが豊富な MCP ツールの説明 により、Claude のツール検索の発見が向上します
  • 指示ファイルには、すべてのエージェントに対する具体的な例と明示的なフォールバック ガイダンスが含まれています
  • スタートアップアップデートチェックは、新しいリリースが利用可能かどうかを最初のツール呼び出し時に通知します これらの改善は、コミュニティのレポートと貢献によって推進されました。

クロスプラットフォームのサポート

ASan + LeakSanitizer + UBSan を使用してすべてのプラットフォームで完全にテスト済み: |プラットフォーム |テスト |ビルド | |----------|------|----------| | macOS arm64 | 2030年が過ぎた | OK | | macOS amd64 | OK | OK | | Linux arm64 | 2012年が過ぎました | OK | | Linux amd64 | OK | OK | | Windows amd64 | OK | OK (CLANG64) | ベンダーの依存関係 (システム ライブラリ要件なし): sqlite3、mimalloc、tree-sitter ランタイム、yyjson、zlib、TRE 正規表現 (Windows のみ)。
