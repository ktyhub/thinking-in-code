codebase-memory-mcp v0.5.5

パッチ 公開日2026年3月21日 出典DeusData/codebase-memory-mcp 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

コードベースメモリ mcp v0.5.5

セキュリティ

  • CodeQL SAST — ビルドモード手動による静的解析 (100% ソース カバレッジ)、ゼロ オープン アラート ゲート
  • シェル インジェクションの削除 - system() 呼び出しを cbm_exec_no_shell() (fork+execvp) に置き換え、汚染されたデータがシェルに到達しないようにしました。
  • snprintf オーバーフローの修正 — 11 件のバッファ オーバーフローの脆弱性が修正されました (各追加後のクランプ オフセット)
  • TOCTOU 競合修正 — アトミック ファイル パーミッション、open-then-fstat パターン
  • 31 のセキュリティ防御テスト — シェル インジェクション、SQLite オーソライザー、Cypher 経由の SQL インジェクション、パスの封じ込め、シェルフリー実行
  • ファズテスト — すべてのビルドでランダム/変異した JSON-RPC + 暗号入力
  • ネイティブウイルス対策スキャン — すべてのビルドで Windows Defender、ClamAV (Linux + macOS)
  • VirusTotal ゼロ トレランス ゲート — すべてのリリース バイナリは公開前に 70 以上のエンジンによってスキャンされます
  • SLSA 来歴 + Sigstore 署名 + SBOM (SPDX 2.3) + SHA-256 チェックサム
  • GitHub アクションは、Dependabot で SHA に固定されています

ウイルス対策誤検知防止

マルチレイヤー AV スキャンをビルド パイプラインに追加して、ユーザーに届く前に誤検知を検出して防止します。削除された DLL は、ヒューリスティック検出をトリガーした追跡文字列を解決します。このリリースのすべてのバイナリは、VirusTotal を介して 70 以上のウイルス対策エンジンによってクリーンであることが検証されています。 (修正 #89)

新機能

  • Content-Length フレーム化トランスポート — OpenCode との互換性
  • 10 エージェント検出 — OpenClaw + VS Code のサポート
  • デュアル MCP 構成の場所 — ~/.claude/.mcp.json + ~/.claude.json

バグ修正

  • Swift コール抽出を修正: 0 CALLS エッジ (#43)
  • Laravel ルートの誤検知を修正: 拡張スコープ + パス フィルター (PR #65)
  • ポート FastAPI depends() エッジ トラッキング (PR #66)
  • 一括書き込み中に WAL ジャーナル モードを維持する (PR #72)
  • VS Code の互換性を修正 (PR #79)
  • DLL 解決追跡を削除 (Windows Defender の誤検知)

貢献者

コードの貢献については @halindrome、@bingh0、@mariomeyer、@kingchenc、そしてこのリリースの包括的な AV スキャン インフラストラクチャにつながった #89 のレポートについては @Maton-Nenoso に感謝します。

ネイティブ ウイルス対策スキャン - このリリースが作成される前に、すべてのバイナリがこれらのスキャンに合格しました (検出によってリリースがブロックされていた可能性があります):

  • Windows: ML ヒューリスティックを備えた Windows Defender (エンド ユーザーが実行するのと同じエンジン)
  • Linux: ClamAV と毎日のシグネチャ更新
  • macOS: ClamAV と毎日のシグネチャ更新 SBOM — ソフトウェア部品表 (sbom.json) には、ベンダーの依存関係がすべてリストされています。 詳細については、SECURITY.md を参照してください。
