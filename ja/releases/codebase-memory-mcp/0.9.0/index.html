コードベースメモリ mcp v0.9.0

コードベースメモリ mcp v0.9.0

v0.8.1 以来の大規模な堅牢性とプラットフォーム サポートのリリース - ファーストクラスの Windows サポート、インデックス作成パフォーマンスとメモリ安全性の大幅な向上、多くの言語にわたる広範な抽出精度の修正、および大幅に改善されたグラフ UI。

ハイライト

  • ファーストクラスの Windows サポート - エンドツーエンドの非 ASCII パス処理、インストーラー/ランタイムの信頼性修正、UI ハング修正、およびネイティブ windows-arm64 ビルド + スモーク パイプライン。
  • インデックス作成のパフォーマンスと回復力 - カーネル規模のキャンペーンにより、確定的な出力でインデックス作成の実行時間が最大 61% 削減されました。さらに、実行全体を中止するのではなく、不良ファイルを隔離し、残りのファイルにインデックスを作成するクラッシュ/ハング スーパーバイザー が追加されました。
  • 大規模なリポジトリでのメモリの安全性 - 正確な Linux RSS アカウンティング、ピーク対ライブの調整、低 RAM マシン向けの制限付き並列保持、およびクロススレッド スラブ解放での解放後の使用修正。
  • グラフ UI — スケールされたレンダリングとコントラスト制御、デッドコード フィルタリング、ノード コード プレビュー、GitHub ディープリンク、URL ルーティング、およびオフライン ラベル レンダリング (リモート フォント フェッチなし) を備えた、最大 1,000 万ノードまでの構成可能なノード バジェット。
  • 抽出精度 — C/C++、Python、Go、PHP、Kotlin、Java、TypeScript/JavaScript、Rust などにわたる多くの CALLS / IMPORTS / ルート抽出の正確性が修正されました。

何が変わったのか

Windows サポート

エンドツーエンドの非 ASCII パスのサポート (_wfopen、wide-argv + CreateProcessW、エスケープ/NUL 終了ワーカー コマンド ライン)。インストーラーの信頼性と Mark-of-theWeb ドキュメント。 UI デッドロックを解決する git-spawn ハンドル継承の修正。フックオーグメンターでのドライブレターの処理。大型.dbサイズの取り扱い。 Windows 永続性エクスポートが失敗した場合の実際のエラー。そして完全なネイティブ Windows-arm64 ビルド + スモーク パイプライン。

インデックス作成、パフォーマンス、メモリの安全性

確定的な出力によるカーネルスケールのインデックス作成が最大 61% 高速化。並列のみのクラッシュ リカバリを備えた TypeScript の大規模カスケード修正。原因ファイルを隔離するクラッシュ/ハングスーパーバイザ。 Linux 上の正確な /proc RSS。 RSS のピーク時とライブ時の調整。低 RAM ピーク RSS に対する制限付きソースキャップ付き並列保持。バックグラウンド自動インデックス/ウォッチャーのための監視サブプロセス RSS 分離。 O(1) 整列ページのクロススレッド スラブフリー修正 (解放後使用)。グラフバッファのアップサートコントラクトとメモリバジェットの修正。ホスト階層化された RAM バジェット。ファイルごとのインデックス作成の失敗は、サイレントに失敗するのではなく、skipped[] + ログファイル経由で報告されるようになりました。

LSP / 抽出精度

CALLS エッジの正確性 (文字列ディスパッチ エッジ、C/C++ 囲み関数の属性、受信者を意識した自己再帰、py/go/php/kotlin の再帰深さの上限、Python 指数再評価ハングのメモ化されたガード)。ルート/HTTP 抽出 (ファイルシステム パスを拒否して、client ルートがサーバー ルートに参加し、パラメータ化されたパス、Kotlin コントローラー上の Spring ルート、Django REST @action を正規化)。インポート/解決 (ローカル名でキー設定された IMPORTS、非ファイルのようなターゲットを拒否、tsconfig エイリアス ../ climbs、混合 Java/Kotlin コールグラフ エッジ、安定した Java USAGE 所有権)。さらに、Class.lines の精度、次数でカウントされる INHERITS/IMPLEMENTS、深いファイルでのスタック オーバーフローを修正するヒープ割り当て walk_defs フレーム スタック、および 5 プラットフォーム ボードによる再現優先バグ スイート。

グラフUI

スケーリングされたレンダリングとコントラスト制御により最大 10M のノード バジェット。オフラインラベルレンダリング (リモート CDN フォントなし)。デッドコード フィルタリング、ノード コード プレビュー、GitHub ディープリンク。 URL ルーティング、フィルター パネル UX、カメラ フライトゥ。すべてがフィルタリングされても、フィルタ サイドバーは表示されたままになります。インデックス ピッカーでの Windows フォルダー ナビゲーション。インデックス作成ジョブの失敗が、静かに完了するのではなく表面化しました。 UI で監視されていないプロジェクトは削除されます。一致点に対する有界八分木再帰。

MCP サーバー & CLI

構造化されたツールのメタデータ。 CLI は、フラグ、標準入力、およびツールごとの --help を含む --args-file を受け入れます。内部名 + ゴースト DB フィルタリングおよび project_name エイリアスによるプロジェクト解決。 trace_path は、異なる同名の関数を混同しなくなり、CROSS_* エッジに従います。非 UTF-8 ソースに対する有効な UTF-8 スニペット。正しい JSON 制御文字 escaping;暗号ラベルでフィルターされたトラバーサルは 10 で切り捨てられなくなり、WITH を通じてノードのプロパティを保持します。 get_architecture 概要サブセット。 detect_changes は since を尊重します。

ディスカバリー、ウォッチャー、ライフサイクル

.git/info/exclude、グローバル core.excludesFile、およびリンクされたワークツリーを尊重し、ソースを無視します。 pkgmap/path-alias/envscan ウォークでの除外を尊重します。 .cbmignore の否定では、セーフティ コア ディレクトリのスキップを解除できなくなりました。 deploy/ dirs は二重インデックス化されなくなりました。スコープ検索はスペースを含むリポジトリ パスを処理します。ルートが欠落したままになっているプロジェクトをプルーニングします。 auto_watch 構成ゲート。ワークツリーとサブディレクトリ プロジェクトの正しい canonical_root。完全な再インデックスにわたる ADR の保持。

文法、ビルド、ドキュメント

ベンダーの InterSystems ObjectScript 文法と Mojo パーサー。 SBOM は文法カウントを計算し、非 MIT ライセンスの概要を完成させます。置き換えられた実行のキャンセルによる PR の完全な検証パイプライン。問題トリアージボット。マトリックス崩壊/偽グリーンを修正するレッグごとのスモーク ゲート。 gcc-15 および Nix-on-macOS ビルドの修正。構成ファイルのリファレンスと extra_extensions のドキュメント。
