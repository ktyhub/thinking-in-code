codebase-memory-mcp v0.8.1

コードベースメモリ mcp v0.8.1

v0.8.0を重点的にフォローアップ。

ファーストパーティの HTTP サーバー

グラフ UI Web サーバーは、無駄のない社内モジュールとして最初から再実装されました。これは、バイナリから最後のサードパーティ サーバー ライブラリを削除するリファクタリングです。新しいトランスポート (src/ui/httpd.c) は、UI が実際に必要とするものに特化して構築されています。

  • 構築によりローカルホストのみ — すべての OS でプラットフォームに適したソケット オプションを使用して、127.0.0.1 を排他的にバインドします。
  • 厳密な HTTP/1.1 解析 - ハード リクエスト キャップ (16 KB ヘッド / 1 MB ボディ)、厳格な CRLF 処理、生のパス マッチング、および接続ごとの受信期限。
  • 設計がシンプル — 接続ごとに 1 つのリクエスト (Connection: close)。キープアライブ ステート マシンやチャンク エンコーディングはありません。

新しい 28 のテスト トランスポートおよびルーティング スイートは、エッジ ケースの解析、CORS ポリシー、RPC ディスパッチ、およびシャットダウン動作をカバーします。すべてのルート、ステータス コード、および localhost-only CORS ポリシーは、以前とまったく同様に動作します。

このリリースにも含まれています

  • よりスリムな文法セット — nim 文法 (66 MB のこれまでで最大のベンダー文法) が削除されました。 158 言語は引き続きサポートされます。
  • すべてのアーカイブに属性バンドル — リリース アーカイブには、ベンダーが提供するすべてのコンポーネントのライセンス テキストを含む統合ファイルである THIRD_PARTY_NOTICES.md が含まれるようになりました。 Homebrew と AUR のインストールでは、バイナリと一緒に配置されます。
  • より豊富な SBOM — バイナリにコンパイルされたすべてのコンポーネントごとのライセンスとバージョンのメタデータ。
  • テスト スイート: 5,604 テスト (v0.8.0 に対して +27)。
