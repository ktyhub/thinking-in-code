コードベースメモリ mcp v0.10.8

#v0.10.8

v0.10.7 に関する注意: このリリースは、リリース パイプラインに失われた v0.10.7 に代わるものです。 公開エラー (v0.10.7 ではなく 0.10.7 タグで公開; パッケージ インストーラー) v 接頭辞の付いたタグを解決し、不変性を解放すると名前が回復不能になります)。 npm そして、PyPI 0.10.7 パッケージはその理由で非推奨/ヤンクされています - それらのバイナリは問題ありませんでしたが、 ダウンロード URL はそうではありませんでした。 v0.10.8 は、同一のコード内容とパイプラインを伝送します。 再発を防ぐ硬化。

コミュニティ重視のパッチ リリース: v0.10.6 以降、19 件のプル リクエストがマージされ、そのほとんどが 貢献者。皆さんありがとうございました！

グラフの正確性

  • Cypher 集計はアンダーカウントされなくなりました (#1196)。両方の切り捨てメカニズムは修正されています。 ラベルのないスキャンは、集計が実行される「前」に max_rows で候補の収集を停止しました (#1323、@Enferlain)、関係拡張バッファーに上限が設定されていたため、集計は行われませんでした 内部増加制限を超える行が見られました (#1698)。 count()/collect() は、 完全な一致セット。 max_rows は、文書に記載されているように、返される行のみを制限します。
  • インポートからエイリアス化された Python は実際の定義に解決されます (#1371、@Joseph-MingEn)。 from .gate import execute as bridge_execute は execute への CALLS エッジを生成するようになりました。 呼び出しを失うのではなく、それ自体を呼び出し、エイリアス化された基本クラスのインポートが実際のクラスに着陸します。 ノード。 Django ベンチマークでは、26 個の INHERITS エッジと 42 個の OVERRIDE エッジがゼロで回復されました。 損失は他の場所で発生し、TypeScript グラフはバイト同一です。
  • 修飾名検索のための 言語間のサフィックス マッチング (#1647、@rudi193-cmd)。
  • search_graph はセマンティックのみのゴーストを返さなくなります — 結果は、 類似性エッジは、明確な一致であるかのように表面化されなくなりました (#1319、@JJordan0C)。
  • リスト値フィールドは、最初の要素に折りたたまれるのではなく、正しく抽出されます (#1325、@Enferlain)。
  • インデックス レスポンスは継続的なカバレッジを真実に報告します (#1326、@Enferlain): 記録された解析ギャップのあるファイルを再訪問しない増分実行はレポートされなくなりました それらのギャップは消えました - 応答はスキップされた/解析された部分的な要約を構成します 保存されたカバレッジ状態から、読み取りが失敗した場合にのみ実行ごとのデータにフォールバックします。

Windows

  • 非 ASCII 検索コンテンツは ? に劣化しなくなりました (#1704)。 search_code の生のスキャン PowerShell 出力をパイプし、PowerShell 5.1 がコンソール OEM でそのパイプをエンコードします。 コードページ — キリル文字、CJK、またはアクセント付きのコンテンツは、コードページに応じて疑問符に変わります。 サーバーが継承したコンソール。パイプは無条件に UTF-8 に固定されるようになりました。
  • search_code は UTF-8 出力パスを理解し、一致するコンテキスト列を取得します (#1253、@anfedoro)。
  • コード検索は制限されており、キャンセル可能 — クエリを放棄しても、クエリが残らないようになりました。 孤立したスキャンが実行中 (#1608、@ertankucukoglu)。

プラットフォームとツール

  • FreeBSD サポート (#1467、@PR9000)。
  • list_projects ページネーション: リーンなデフォルト応答にオフセット/制限を加えたもの フルビューの include_details (#1181、@tmonestudio)。
  • 拡張機能のないシバン スクリプトは言語を検出します (#1203、@ibaldr89)。
  • インデックス モード機能の再構築 (#1263、@astandrik)。
  • tests/ ディレクトリの is_test 検出 (#1308) および diff-aware Clang-Tidy フック (#1310、両方 @Yyunozor)。

リリース パイプライン (v0.10.7 レッスン、強化)

  • キャンセルされたジョブのリリース ゲートはフェール クローズされます。タイムアウトしたゲートはカスケードできなくなります。 サイレントにスキップされたテスト行列 (#1719)。
  • 不正なバージョンの入力はプリフライトで拒否されます。v プレフィックスのない裸のバージョンは決して拒否されません。 解決できないタグを再度公開します (#1719)。

内部

  • テスト ハーネスは分離されたデーモン ランタイムを使用するため、スイートの実行がアカウントに影響を与えることはできません デーモン (#1695、@astandrik);シェル エントリポイントと git フックの LF チェックアウト コントラクト (#1314 @mlandolfi90、#1699 with @xumian520);標準ゲート回帰テストは廃止されました 引数なしのツール (#1704) を出荷するレジストリに依存します。
