コードベースメモリ mcp 0.8.0

📦 アーカイブされたリリース ページ — このバージョンのバイナリは公開されなくなりました。 最新リリース を入手してください。

見出し: 3 つの新しい型認識 LSP エンジン。 Java、Kotlin、および Rust は完全なハイブリッド LSP 解決を実現します。クラス階層による型認識呼び出し解決、アノテーション/属性リンク、シグネチャ認識オーバーロード マッチング、ジェネリックス処理、ファイル間型推論を C/C++、Python、TypeScript/JavaScript、Go、C#、および PHP と統合して、 ハイブリッド LSP では 9 言語。

アーキテクチャインテリジェンス

  • ライデン コミュニティの検出: get_architecture は、マルチレベルのライデン コミュニティ (単一レベルの Louvain に代わって) を表示するようになりました。これは、カーネルサイズのグラフ上の実際のモジュール境界であり、数分ではなく数秒で計算されます。
  • クエリ可能な計算ボトルネック メトリクス: 関数は、グラフ内の複雑さ、ループ深さ、およびスキャン パターン メトリクスを伝達します。コードベースで独自のアルゴリズム ホットスポットを Cypher クエリできるようになりました。 (私たちはまさにこれを使用して、独自のものをいくつか見つけて修正しました。以下を参照してください。)
  • Helm サポート: チャート テンプレート、include 呼び出しリンケージ、および Chart.yaml 依存関係エッジ。 HCL ブロック ラベルはノード名に組み込まれます。 C/C++ プリプロセッサ マクロは、ファーストクラスのマクロ ノードになりました (Linux カーネル内に 230 万個)。

安定性 — これまでで最大の強化策

このリリース フリートでは、データベース レベルの検証ゲートを使用して、Linux カーネル (480 万ノード)、elasticsearch、kubernetes、TypeScript コンパイラー、ビットコイン、zig、symfony など、16 の大規模 OSS リポジトリをエンドツーエンドでインデックス付けします。この調査と優れたコミュニティ レポートにより、クラッシュの長いリストが終わりました。

  • C++/テンプレート コード クラッシュ ファミリを削除: 初期化されていないテンプレート引数配列、範囲外のパラメーター ルックアップ、無制限の解決再帰、式評価の爆発 — #424、#427/#428/#432、#312、#322/#323、#336、#344、#355、#360、#385 で報告されます。
  • アロケータの統合 (#424): バイナリ全体 (ベンダーが提供するツリーシッター、SQLite、libgit2) が 1 つのアロケータの下で実行されるようになり、複雑な C++ でのクロスアロケータ ヒープ破損のクラスが終了しました。
  • 起動時のクラッシュ ループが修正されました (#235、#439): プロジェクト リスト エラー パスのスタック バッファー オーバーフローにより、すべての プロジェクトのサーバーが SIGABRT される可能性がありました。 1 つの破損したキャッシュ DB がすべてのセッションをダウンさせることはなくなりました。
  • データベースの整合性、エンドツーエンド: オーバーサイズのインデックス キーがオーバーフロー ページに正しく書き込まれるようになりました。JSON のすべてのプロパティがエスケープされ、プロデューサーで検証されます。url_path インデックスは常にその生成された列と一致し、WAL ファイルは閉じる/起動時にチェックポイントが作成されます (#387)。 16 リポジトリのすべてのデータベースは PRAGMA integrity_check クリーンに合格します。
  • サーバーのライフサイクル: stdio サーバーはデス ウォッチドッグを介して親とともに終了します (#406)、MCP ping がサポートされます (#354)、JSON-RPC 文字列 ID は保持されます (#253)、ログ レベルは CBM_LOG_LEVEL 経由で構成可能です (#413)。
  • Windows: 非 ASCII パスのワイド文字 API (#386)、cmd.exe 互換の git 履歴パス (#324)、PATHEXT プローブ (#221)、パッケージング ウォークのハング修正 — Windows では完全なテスト スイートが緑色です。
  • さらに: ファントム gRPC ルート (#294)、除外されたディレクトリを含む moderate モードのサイレント ドロップ サブツリー (#411) がインデックス作成結果、バリデーターセーフなプロジェクト名 (#349)、UI フラグ診断 (#350) で報告されるようになりました。

カーネルスケールでのパフォーマンス

  • メモリのリワーク: ストリーミング SQLite ダンプ ライター、文字列インターニング、アロケーター ページの再利用、および抽出バック プレッシャー — 限られたメモリ バジェット内で、ラップトップ上で最大 4 分で完全な Linux カーネル インデックスを作成します。 cgroup 対応の CPU/メモリ検出と CBM_WORKERS オーバーライド (#364/#365) により、コンテナーの動作が予測可能になります。
  • 二次ホット パスが排除されました。そのいくつかは、C/C++ クロス LSP オーバーロード解決 (#410)、PHP/Python/Java/Kotlin リゾルバーでのレジストリ構築とルックアップ パス、アーキテクチャ境界計算など、独自のコードベースで新しいボトルネック メトリックを指定することによって見つかりました。大規模な PHP および Java モノリポジトリでは、完全なインデックスが桁違いに高速になります (symfony 35x、elasticsearch 9x とこのサイクルの初期ビルドと比較)。
  • これらの修正によりグラフの品質が向上しました。サポートされているすべての言語で解像度カバレッジとエッジ忠実度が向上しました。

クエリレイヤー

  • Cypher: WHERE の EXISTS {} 述語、COUNT(DISTINCT) (#239)、ラベル変更 (n:A|B) (#242)、WHERE のラベル テスト (#241)、WITH DISTINCT (#238)、文字列/スカラー/エンティティ イントロスペクション関数、複数引数スカラー - サポートされていない構文は、返される代わりに大声で失敗するようになりました。サイレントエンプティ (#373)。
  • search_code: 空の結果ではなく無効な正規表現エラー (#283)、パスの &、応答のタイミング、サブ文字列としてのワイルドカードなしの file_pattern (#200)、インデックス付きの .mjs/.cjs/.mts/.cts (#197)、マッピングされたブレード テンプレート (#258)、R box::use()/library()インポート (#218/#219)。

より大きなセーフティネット

  • 新しい 159 文法すべてにわたる文法ごとの回帰スイートに加え、抽出、エッジ作成、LSP 解決のためのプローブ スイート - このスイートは現在、厳格なスキップなしポリシー (スキップはハード エラーです) の下で 5,500 以上のテストを実行します。
  • クラッシュの再現は、終了信号アサーションを使用してサブプロセス分離テストとして実行されます。 ASan/LSan はスイート全体を実行します。 macOS Intel ビルドレッグがブロックされているため、darwin-amd64 が常に出荷されます。

配布と統合

  • 公式 MCP レジストリ および Glama ディレクトリ に公開されます。すべてのインストール/更新パス上のポータブル静的 Linux バイナリ。
  • 構成変更前の install --plan 機械可読レシート (#388)、カーソル IDE 検出 (#222)、フィッシュネイティブ PATH 処理 (#319)、$CLAUDE_CONFIG_DIR 尊重 (#321)、Codex、Gemini CLI、および Antigravity 用の SessionStart フック (#330)、MCP ツールと UI 間で統合された ADR ストレージ (#256)。
