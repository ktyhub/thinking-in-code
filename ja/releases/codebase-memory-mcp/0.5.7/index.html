コードベースメモリ mcp v0.5.7

v0.5.7 — 安定性、設置、耐久性テストのオーバーホール

53 件のコミット、3 件のマージ PR、10 件のバグがクローズされました。 Go→C の書き換え以来、最も重要な安定性リリース。

データベース同時実行性の修正 (重要)

  • 根本原因が見つかりました: 3 つのスレッド (MCP ハンドラー、自動インデックス、ウォッチャー) がデータベースを破損する可能性があります — オープン SQLite 接続上の rename(.db.tmp, .db) により 48K 以上のガベージ行が生成されました
  • アーキテクチャの変更: rename() は完全に削除されました。インデックス作成は直接書き込み、再インデックス作成は最初に古い DB を削除し、増分更新/挿入は変更されません
  • パイプライン ロックは同時実行をシリアル化します。破損した DB が自動的に検出され、クリーニングされる

インストールとアップデート

  • install.sh + install.ps1 は、--skip-config フラグを持つすべてのリリース アーカイブに含まれます (#145)
  • 古い MCP サーバーを強制終了し、macOS 隔離を削除し、バイナリにアドホック署名します。
  • 更新のたびに 10 個のエージェント構成をすべて更新します
  • メモリ内 zip 抽出 — Windows では unzip は必要ありません
  • Windows .exe パス処理がインストール、アップデート、アンインストール全体で修正されました

Windows パスの正規化 (PR #146)

  • すべてのエントリ ポイントでスラッシュに正規化された混合パス区切り文字
  • cbm_normalize_path_sep() はすべてのプラットフォームで動作します (クロスプラットフォーム DB ファイル)

ソークテストスイート (新規)

  • クイック ソーク (10 分)、ASan ソーク (15 分)、毎週の耐久性 (4 時間) — すべてプラットフォームごと
  • RSS トラッキング、FD ドリフト、クエリ レイテンシ、クラッシュ リカバリ (kill -9 + クリーン リスタート)
  • すべてのソーク層はリリース ゲートです - 通過せずにリリースは行われません

バグ修正

  • #139 自動インデックスのスタック オーバーフロー — 8MB のデフォルト スレッド スタック (スタック アドレス、頻度テーブル、および回避策を含む詳細なクラッシュ レポートを提供してくれた @theron-sapp に感謝します!)
  • #140 index_repository が Windows で失敗する — @Flipper1994 によるこのレポートにより、同時実行アーキテクチャの完全な見直しが行われました。
  • #137 detect_changes はスペースを含むパスで失敗します (12 個のツールは機能したが 1 個は機能しなかったという鋭い観察をしてくれた @shekthesnek に感謝します!)
  • #135 macOS Gatekeeper はバイナリをブロックします (徹底した xattr/spctl/codesign 分析を行ってくれた @heraque に感謝します!)
  • #133 search_code は Windows のバックスラッシュを拒否します (根本原因を特定してくれた @ckelly8 に感謝します!)
  • #130 O(N²) インポート エクストラクターが大きなファイルでハングします (問題と PR #131 の修正の両方について @halindrome に感謝します!)
  • #127 接続が常に閉じられました - すべてのクラッシュ パスが修正されました (@kingofthebongo2008 に感謝します!)
  • #145 インストール スクリプトでエージェント構成をスキップ (@sherif-fanous に感謝 — 同日実装されました!)
  • アリーナ バッファ オーバーフロー、テスト検出ギャップ、メモリ リーク、CodeQL TOCTOU、taskkill セルフキル、MSYS2 python3 パス変換、ベンダー tre ssize_t

テスト

  • 2586 単体テスト (2042 から増加)、ゼロスキップ、ゼロメモリリーク
  • アリーナ、FQN、グラフ バッファ、MCP ディスパッチ、パイプライン、ストア、YAML、ウォッチャーをカバーする 480 以上の新しいテスト
  • Windows を含むすべてのプラットフォーム上の 15 フェーズ スモーク スイート
  • リリースゲートとしてのソークテスト - 毎回のリリース前に耐久性を検証

セキュリティ

  • バイナリと一緒に VirusTotal スキャンでスクリプトをインストールします (120 分のタイムアウト、すべてのファイルが通過する必要があります)
  • すべての製品コードから system() を削除
  • ベンダーの依存関係整合性チェックサムの強制
