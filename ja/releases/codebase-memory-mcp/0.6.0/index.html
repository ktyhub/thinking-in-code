コードベースメモリ mcp 0.6.0

📦 アーカイブされたリリース ページ — このバージョンのバイナリは公開されなくなりました。 最新リリース を入手してください。

v0.6.0 — セマンティック検索、SIMILAR_TO エッジ、および言語を超えたインテリジェンス

v0.5.7 以来 85 以上のコミット。ベクトルベースのセマンティック検索、構造的クローンに近い検出、言語を超えたインポート解決、およびすべてのプラットフォームにわたる大幅な生活の質の向上を追加するメジャー リリース。

セマンティック検索とベクトル埋め込み

  • semantic_query ツール: cbm_cosine_i8 SQL 関数を使用した、コードベース グラフ全体にわたるキーワード ベースのベクトル検索
  • Nomic nomic-embed-code 埋め込み: シミュレートされたアテンションを使用して nomic-ai/nomic-embed-code から抽出された 40K の事前トレーニング済みトークン ベクトル (768d int8)
  • 11 信号の複合スコアリング: TF-IDF、反射型ランダムインデックス、API/タイプ/デコレーター署名、AST 構造プロファイル、近似データフロー、Halstead-lite メトリクス、MinHash、モジュール近接性、グラフ拡散
  • SEMANTICALLY_RELATED エッジ: 語彙は一致しないが目的が似ている関数を接続します (スコア >= 0.80、ノードごとに最大 10、同じ言語のみ)
  • 精度を向上させるために、キーワードごとの最小コサイン スコアリングがマージされたベクトル平均化に置き換わります。
  • スコアを [0,1] にクランプ — 近接乗数がスコアを 1.0 を超えないようにする
  • クローン重複排除: Jaccard >= しきい値スキップ SEMANTICALLY_RELATED を持つ SIMILAR_TO ペア

SIMILAR_TO エッジ (ニアクローン検出)

  • MinHash フィンガープリント: 構造的重み付けを備えたリーフのみの AST トークンからの 64 ハッシュ署名
  • LSH インデックス: O(1) 候補検索のためのバンドベースの局所性依存ハッシュ
  • 並列スコアリング: ワーカー プールが LSH をクエリし、候補をスコアリングし、エッジを出力します
  • 独自のトライグラム ゲート フィルターで関数を簡単に短縮
  • Jaccard の類似性とプロパティ内の同一ファイル フラグを備えた SIMILAR_TO エッジ

全文検索

  • cbm_camel_split トークナイザーを使用した FTS5 経由の BM25 全文検索 (キャメルケース/スネークケース対応)
  • インデックス更新時の増分 FTS5 再構築

新しいエッジ タイプと検出

  • Socket.IO、EventEmitter、および汎用チャネル パターンの EMITS / LISTENS_ON エッジ
  • 定数解決: const EVENT = "foo"; emit(EVENT) はファイルごとの定数テーブルを通じてチャンネル名を解決します。
  • IMPORTS エッジ (JS/TS (./foo、../bar)、Python (.helpers、..utils)、Ruby の相対パス解決)
  • DATA_FLOWS 引数からパラメータへのマッピング + フィールド アクセス チェーンを備えたエッジ
  • サービス間通信の検出 + RAM ファースト増分インデックス作成
  • プレスキャンインフラストラクチャを置き換えるASTベースのルート登録
  • HCL インフラストラクチャ バインディング抽出 + プレフィックス デコレータの誤検知修正
  • 汎用ルート登録+インフラバインディングブリッジ

グラフクエリとツールの改善

  • 以前に無視された 6 つのパラメータが接続されました: min_degree、max_degree、exclude_entry_points、include_connected、aspects フィルター、 detect_changes 用の since
  • **trace_path の include_tests パラメータ — BFS 結果でテスト ファイルをマークします
  • セキュリティ重視のパス トレース用の trace_path 上の risk_labels
  • リアルタイムのインデックス作成フィードバック用の **--progress CLI フラグ **
  • CBM_CACHE_DIR 環境変数 (構成可能なデータベース ディレクトリ用)
  • moderate インデックス モード がツール スキーマに追加されました (フルと高速の間)
  • param_names、param_types、decorators のスキーマ プロパティの公開
  • include_connected 修正: BFS インバウンドとアウトバウンドが別々に実行される (誤ってマージされていた)

生活の質

  • ネストされた .gitignore サポート: インデックス作成中にサブディレクトリ gitignore が考慮されるようになりました — モノリポジトリにとって重要 (#178)
  • スキルの統合: 4 つの個別のスキルが 1 つに統合され、段階的に開示されます。
  • スマートアップデート: skip update when already on latest version
  • インストール コマンドの ランタイム バイナリ検出 (ハードコーディングされなくなりました)
  • ウォッチャーでの Git サブモジュールのサポート: サブモジュール内のダーティな状態を検出します
  • 高速→フルモード変更検出 + ui-variant バイナリの UI を自動有効化
  • レイアウトエンドポイント: O(n*e) エッジマッピングが二分探索に置き換えられました
  • レイアウト JSON: シリアル化で無効な UTF-8 と NaN を処理する

プラットフォームの修正

  • Windows: Zed/VS Code/KiloCode 構成パス、PATH 区切り文字、S_IXUSR チェック、home_dir 相対パスを使用したエージェント検出、APPDATA ベースの userconfig テスト
  • Linux ポータブル: Alpine musl との互換性、スモーク テストにセキュリティ監査を追加、スモーク環境での XDG_CONFIG_HOME
  • クロスプラットフォーム ベクター BLOB アセンブリ: macOS Mach-O / Linux ELF / Windows COFF のプリプロセッサ条件
  • C++ SEGV 修正: 大きなヘッダー ファイルの LSP タイプ リゾルバーでの NULL deref

コードの品質とリンティング

  • 16 個のファイルにわたって 337 個のリンター警告を解決 (名前付き定数、認知的複雑さの抽出)
  • 認知複雑性のしきい値を業界のデフォルト (25) に設定、168 の機能を分割
  • cbm_write_db神機能分割(569→325行)
  • すべての NOLINTNEXTLINE 抑制が排除され、反復的な AST ウォーカーが削除されました
  • セマンティックコーパス token_map の ASan リークを修正

CI/CD とセキュリティ

  • 分離されたセキュリティ ゲート: security-static + CodeQL は独立して実行され、テスト/ビルド/スモーク パイプラインをブロックしません
  • すべてのバイナリ バリアントに対するセキュリティ監査 (標準 + UI) - 以前は UI バイナリは監査されていませんでした
  • AV セーフ トークン語彙: Nomic 埋め込みからヒューリスティックをトリガーする 11 個の単語を削除
  • CI を再利用可能なワークフロー コンポーネントに分割
  • ベンダーの依存関係バンプ: SQLite 3.51.3、Mongoose 7.21、mimalloc 3.2.8
  • アクションがバンプされました: download-artifact v8.0.1、attest-sbom v2、cosign v4.1.1、msys2 v2.31.0、チェックアウト v6.0.2、キャッシュ v5.0.4、アップロード アーティファクト v7.0.0、attest-build-provenance v4.1.0、codeql-action v4.35.1
