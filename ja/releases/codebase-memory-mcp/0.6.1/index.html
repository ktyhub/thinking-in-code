コードベースメモリ mcp 0.6.1

📦 アーカイブされたリリース ページ — このバージョンのバイナリは公開されなくなりました。 最新リリース を入手してください。

v0.6.1 — 89 の新しい言語、クロスリポジトリ インテリジェンス、チーム共有グラフ アーティファクト、npm+PyPI ディストリビューション

v0.6.0 以来 50 以上のコミット。 89 のツリーシッター文法 (66 → 155 言語) を追加し、CROSS_* エッジによるクロスリポジトリ インテリジェンスを導入し、チーム共有グラフ アーティファクト (.codebase-memory/graph.db.zst) を出荷し、npm + PyPI を使用した完全なディストリビューション ラッパー (npm/PyPI/Homebrew/Scoop/Winget/Chocolatey/AUR/Go) を導入し、リリース パイプラインの一部として自動公開され、包括的なインストーラー セキュリティを展開します。硬化。

言語と解析 — 66 → 155

  • 89 の新しいツリーシッター文法 がベンダー化され、語彙がクリーン化されたトークン化と文法セキュリティ監査スクリプトが付属
  • 言語仕様カバレッジ は、適切なノード タイプを備えた 114 言語に対応 — Go (func_literal)、JS (do_statement、古い case_clause を修正)、C#/Python インポート、共有配列
  • 新しい言語をカバーする 77 の新しい拡張子マッピング テスト
  • C#、Rust、Scala 文法 を最新のアップストリームに更新
  • lang_specs リファクタリング: 指定されたイニシャライザ + ファクトリ ポインタ

クロスリポジトリインテリジェンス

  • リポジトリ間の依存関係とアーキテクチャ上の関係のための CROSS_ エッジ タイプ*
  • gRPC / GraphQL / tRPC サービス検出 (protobuf ルート抽出による)
  • 通話解決 + 連鎖通話抽出における gRPC スタブ検出
  • マルチギャラクシー UI レイアウト + クロスリポジトリ アーキテクチャの概要ビュー

チーム共有グラフ アーティファクト

  • .codebase-memory/graph.db.zst — リポジトリにコミットできる zstd 圧縮されたナレッジ グラフ。チームメイトは、最初から完全なインデックスの再作成を実行するのではなく、アーティファクトからブートストラップします。
  • ベンダー製 zstd 1.5.7 (統合、~52K LOC) 8 ～ 13:1 圧縮用
  • 2 層エクスポート: 明示的なインデックスの場合は zstd -9 + インデックス ストリッピング + VACUUM INTO (最良の比率)。 zstd -3 ウォッチャー/増分自動更新 (低遅延)
  • インポート パス: 解凍 → 整合性チェック → インデックスの自動再作成
  • index_repository の 自動ブートストラップ: ローカル DB が存在しないがアーティファクトが存在する場合、最初にインポートしてから増分インデックス作成を実行します。
  • merge=ours を使用して .gitattributes を自動作成し、バイナリ アーティファクトでのマージ競合を防止します

インポートとチャネル

  • 10 言語にわたる IMPORTS エッジの汎用パッケージ/モジュール解決 (マニフェスト スキャン経由で @myorg/pkg、github.com/foo/bar、use my_crate::foo などの裸の指定子を解決します: package.json、go.mod、Cargo.toml、pyproject.toml、composer.json、pubspec.yaml、pom.xml、build.gradle、 mix.exs、*.gemspec)
  • チャネル検出が JS/TS から 8 言語に拡張されました

配布

パブリック パッケージ レジストリから直接インストールできるようになりました。

npm install -g codebase-memory-mcp     # npm
pip install codebase-memory-mcp         # PyPI
go install github.com/DeusData/codebase-memory-mcp/pkg/go@latest   # Go
  • npm + PyPI 自動公開 がリリース パイプラインに統合されました (verify の後の publish-registries ジョブ、その後、両方のレジストリが成功した後にのみアトミック publish-final が GitHub リリースのドラフトを解除します - 半分出荷された状態はありません)
  • npm パッケージ は --provenance を使用します (GitHub OIDC ビルド証明書は npmjs.com で参照できます)
  • pkg/ の完全なディストリビューション ラッパー: npm、PyPI、Homebrew、Scoop、Winget、Chocolatey、AUR、Go

セキュリティ強化

  • PyPI インストーラー: タールスリップおよびスキーム混乱攻撃に対する強化 (@dLo999 による PR #248、クローズ #246)
  • npm インストーラー: チェックサム検証、HTTPS のみのリダイレクト、シェル インジェクションなし
  • クロスインストーラーの強化: Unblock-File を削除し、HTTPS のみの URL 検証を追加しました。
  • vite が 6.4.2 に変更されました — CVE GHSA-4w7w-66w2-5vf9 および GHSA-p9ff-h696-f583 を修正します
  • 文法セキュリティ監査 がベンダー パイプラインに追加されました
  • README: VirusTotal スキャン リンク (バイナリ ハッシュ)、SLSA バッジ、セキュリティと Trust セクション、透明性の免責事項、責任ある開示の招待状
  • arXiv 紙バッジ + 引用

安定性と品質

  • get_graph_schema はノード ラベルごとにプロパティ定義を公開するようになりました
  • sqlite_writer オーバーフロー ページ — 大きなレコードの SIGBUS を修正 (#139)
  • delete_project 後の RSS 再利用: 明示的な mem_collect + 即時パージ
  • MCP ツール / CLI: エラー処理、診断、およびキャンセルの改善
  • PR #162 からの厳選された抽出と Cypher の改善

エディター/エージェントの統合

  • Kiro CLI サポート (#96)

プラットフォームの修正

  • Windows: pass_pkgmap は cbm_strndup を使用するようになりました (mingw Clang には POSIX strndup がありません)
  • test_watcher: グローバル git 構成を変更する代わりに、GIT_AUTHOR_* / GIT_COMMITTER_* 環境変数を使用します

CI / 煙

  • スモーク テスト JSON 解析 修正 - CLI のデフォルト モードは MCP エンベロープをアンラップします。スモークは内部の JSON を直接解析するようになりました
  • バイナリ文字列監査許可リスト — 最初の文法からの telnet URI スキームは既知の無害な一致として文書化されています

貢献者

このリリースに貢献してくれた皆さんに感謝します。

  • @dLo999 — PyPI インストーラーの強化 (#248)
