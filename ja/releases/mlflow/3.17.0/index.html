#mlflowv3.17.0

MLflow 3.17.0 には、いくつかの主要な機能と改善が含まれています。

主な新機能

  • 評価、ゲートウェイ、トレースにわたる Jev Decisions: 組み込みのスコアラーとカスタム ジャッジで TypeSafe モデルを使用し、型指定されたブール値またはカテゴリのフィードバックを使用します。 (#26100、@B-Step62)
  • 共有リソースに対するきめ細かなアクセス許可: ワイルドカード許可と明示的な DENY を使用して、実行、トレース、バージョンなど、含まれるリソース タイプへのアクセスを制御します。 (#26157、@rrrkharse)
  • 大規模なトレース データセットの高速分析: オプトインの日次サマリーと生のクエリ フォールバックにより、SQL 分析クエリのオーバーヘッドを削減します。 (#25991、@HumairAK)
  • より明確な評価結果: ログに記録された集計モデル評価メトリクスを、それを生成した管理データセットと関連付けます。 (#25927、@joshuawong-db)
  • 共有サーバーのアシスタントの改善: 保存された会話のスコープをサインイン ユーザーに限定し、アカウントが変更されたときにアクティブなセッションをリセットします。 (#26009、@クリスコン-db)

データベースのアップグレード: SQL ベースのサーバーでは、日次ロールアップが無効になっている場合でも、すべてのライターを停止した状態で調整されたスキーマのアップグレードと復元可能なバックアップが必要です。新しい MLflow バージョンですべてのレプリカを再起動する前に、mlflow db upgrade <database-url> を実行します。混合バージョンのローリング アップグレードはサポートされていません。 データベースのアップグレード手順 に従ってください。
