#mlflowv3.16.0

MLflow 3.16.0 には、いくつかの主要な機能と改善が含まれています

主な新機能

  • 🎨 カスタム トレース ビュー: わかりやすい英語で独自のトレース UI をデザインします。必要なビューを記述すると、MLflow アシスタント がそれを構築し、構成ファイルやカスタム コードを使用せずに、関心のあるフィールドを正確にレイアウトします。実験ごとにビューを保存、名前付け、再利用できるため、チーム全体がトレース上で同じレンズを共有できます。
  • 🔭 再設計されたトレース エクスペリエンス (現在はデフォルト): トレース エクスプローラーは根本から再構築され、現在はデフォルトになっています。行密度が強化され、ナビゲーションがわかりやすくなり、スパン ツリー ビューが再設計されています。 列を並べ替え、任意のトレース タグまたはメタデータ フィールドから 構成可能なカスタム列を追加し、セッション グループ化を介して複数ターンの会話をインラインで検索します。
  • 🔗 スパン リンク: スパンが単独で存在することはほとんどありません。 MLflow 3.16.0 はファーストクラス スパン リンクを追加するため、スパン間の関係 (取得ステップ、ツール呼び出し、ダウンストリーム トレース) がキャプチャされ、ナビゲート可能になります。 SDK にリンクを記録すると、トレース エクスプローラーによって専用の [リンク] タブにリンクが表示され、目的のスパンに直接ジャンプします。
