#mlflowv3.15.0

MLflow 3.15.0 には、いくつかの主要な機能と改善が含まれています

主な新機能

  • 🧩 MCP レジストリ: モデル コンテキスト プロトコル サーバーの登録、バージョン管理、共有のための一元化されたカタログ。セマンティック バージョン管理された構成、プロモート可能なエイリアス、タグ、自動検出ツール、およびクロード コードと .mcp.json 用の既製の接続手順が含まれます。 UI、REST API、または Python から管理します。
  • 🤖 MLflow アシスタントの機能強化: アプリ内 AI アシスタントは、単一の設定ページから選択された複数の LLM プロバイダー (Claude Code、Codex、および OpenAI 互換/ゲートウェイ エンドポイント) をサポートするようになり、セッションごとのトークン使用量と推定コストがコンポーザーにライブで表示され、セットアップがより簡単になりました。mlflow agent setup は、ゲートウェイの LLM 接続に安全に保存された API キーを使用して、1 つのプロンプトでそれを有効にできます。
  • 🗂️ 共有可能なテーブル ビュー: Runs テーブルの名前付きビュー (列、順序、幅、フィルター、並べ替えをキャプチャ) を保存し、URL で共有します。
  • ⚡ 署名付き URL を介したプロキシレス アーティファクトのアップロード/ダウンロード: 大規模なアーティファクトの転送では、トラッキング サーバーをバイパスし、署名付き URL を通じてクラウド ストレージ (S3 など) と直接通信できるようになり、サーバーの負荷と大きなファイルのタイムアウトが削減されます。下位互換性を確保するために、自動的にプロキシ転送に戻ります。
  • 🖼️ LLM ジャッジのマルチモーダル添付ファイル: make_judge() で作成された {{ trace }} ジャッジは、新しい get_span_image ツールを介してトレース スパンでキャプチャされた画像を「見る」ことができるようになりました。このツールは添付ファイルを Base64 データ URL としてフェッチし、マルチモーダル モデル (litellm を介して Anthropic、Gemini、および OpenAI 互換) に渡します。これにより、ビジョン タスク、スクリーンショット、およびその他のビジュアル コンテンツの評価が可能になります。
