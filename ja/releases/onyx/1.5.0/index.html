onyx v1.5.0

マイナー 公開日2026年11月10日 出典onyx-dot-app/onyx 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#オニキス cli/v1.5.0

変更点

  • feat(cli): onyx-cli 検索と document-sets コマンドに --document-set フィルターを追加 (#17504) (34d4307fe7)
  • 特技(チャット): CODE_MODE_ENABLED の背後にあるコード モードを有効にする (#17339) (a9b8dfb4a9)
  • feat(search): LLM 呼び出しを行わない検索用に POST /search/raw を追加 [#17035 の編集] (#17261) (2ab9f2a3d3)
  • 機能 (コネクタ): イベント ソースの登録シームを追加 (#16992) (e4ddc15ccf)
  • 偉業(slack): Slack クラウドを GovSlack 用に構成可能にする (#16985) (c92ceadd0c)
  • 機能 (コネクタ): Azure Data Lake Storage のアクセス許可とグループ同期 (#16887) (d9377907d9)
  • 特技(デプロイメント): Webhook サーバー プロセスを追加します (#16915) (d8bcf60363)
  • 修正 (チャット): サポートされている client 間でセッションの準備が整うまで待機する (#16773) (da1343ce29)
  • feat(log-export): Kubernetes 上のすべてのポッドの標準出力、クラッシュ、イベントを収集 (#16836) (62e283e0da)
  • 雑用(コードインタープリター): 0.4.10 (#16780) (146f19ed12) にバンプします。
  • chore(ci): CI、テスト、デフォルトを gpt-4o/gpt-5 から gpt-6 モデルに移動 (#16643) (556f83e488)
  • 修正 (perm-sync): 経過時間ではなく、進行状況が停止した場合にドキュメント権限の同期を停止する (#16635) (4332f041ab)
  • feat(craft): アプリから静的 HTML プレビューを開く (#16573) (ae8fb04ef2)
  • 修正 (デプロイメント): 新規 Compose インストール時に MinIO とそのコピー サービスを停止したままにする (#16429) (ec1ed831c0)
  • 機能 (インデックス作成): 新しい埋め込みモデルとアップグレード専用モデルの選択を追加 (#15351) (b86caa7332)
  • ドキュメント (デプロイメント): v5 からロールバックする前にスキーマをダウングレードする (#16424) (2f9ed2517e)
  • 修正 (デプロイ): Compose の手動アップグレードで MinIO にファイルが残る場合に警告する (#16375) (fd996261f9)
  • 特技(インデックス作成): 古いチャンカーによってインデックス付けされた表形式ドキュメントを再チャンクする (#16153) (e6772d6f41)
  • feat(youtrack): 許可同期 (#16136) (b16c1019a9)
  • chore(permissions): 権限とグループ同期の Redis 状態を削除 (#15977) (308ad098e4)
  • feat(permissions): 実行中のパーミッション同期の進行状況をレポートする (#15974) (d3e304e2b8)
  • 特技(インデックス作成): タイトルのみでスプレッドシートにインデックスを付けるために SKIP_SPREADSHEET_CONTENT を追加 (#16075) (81b2e2bed8)
  • 修正 (devtools): ローカル ツールによるシンボリック リンクによる書き込みとフォーク フックの実行を停止 (#15992) (bcb5ff9fc9)
  • feat(craft): Community Edition で Craft のビジネス アップセルを表示 (#15901) (777b9bf1f7)
  • 特技(展開): docker compose でデフォルトで MCP サーバーを実行する (#15963) (8ce6fab7c5)
  • feat(hubspot): HubSpot のレコード ビューアーからの権限同期 (#15788) (c4522a5262)
  • feat(linear): 権限同期 (#15783) (0d5a7f8cf2)
  • feat(llm): ONYX_AIRGAPPED の背後にあるゲート リリース ノートのフェッチ (#15691) (2feffd6efa)
  • feat(llm): メインのライブ モデル カタログを優先し、ベンダーのテーブルをオフライン フロアとして優先します (#15684) (55f866e90b)
  • 特技(クラフト): IPv6 専用 Docker サンドボックスをサポート (#15677) (a1b8669c5c)
  • feat(zoom): 録音許可を定期的に同期する (#15020) (2d78a8cd9e)
  • feat(zoom): アカウント名簿からドメイン グループを同期 (#15019) (cb0509d748)
  • 雑務: デプロイ、ODS、CI、テストから 2 つの EE 環境変数を削除 (#15645) (54155760fd)
  • chore(deps): golang ベースイメージダイジェストを更新 (#14934) (5c67b8e339)
  • 修正(ci): テスト ランナー上の OpenSearch ディスクウォーターマーク フレークを停止 (#15628) (232c99fa2b)
  • 雑務 (コード インタプリタ): 0.4.9 (#15506) (24812944ef) にバンプします。
  • 雑務: Vespa を削除し、ドキュメント インデックス インターフェイスを統合 (#15336) (8ced9bc01f)
  • feat(cli): インストールとアップグレードをオブジェクト ストアに移動 (#15251) (8d31e4bc93)
  • feat(file-store): MinIO のファイルをオブジェクト ストアにコピーし、それを廃止します (#15250) (bf98589c22)
  • feat(file-store): 両方のストアに書き込み、移動中に MinIO にフォールバックする (#15249) (cfe73b7a72)
  • 偉業(デプロイ): MinIO の横に SeaweedFS オブジェクト ストア サービスを追加 (#15248) (6df60263f7)
  • 特技: OneDrive 権限の同期 (#14848) (ace1683109)
  • feat(code-interpreter): コード インタープリター 0.4.8 をアドミッション再試行と統合 (#15131) (817f41fc79)
  • 雑務 (展開): テンプレートで SharePoint ファイル サイズの上限を公開 (#15144) (c056a20b67)
  • feat(config): 環境上書き可能な権限同期およびドキュメント同期ロック TTL (#15063) (df0f68b427)
  • 修正 (エンタープライズ設定): オニキス ブランドの非表示トグル (#15112) を削除 (f61e05131f)
  • 修正 (展開): 弊社独自の Docker ハブ ミラーから MinIO をプル (#15086) (9987d2b9f9)
  • 修正(cli): ワンショット質問後のチャット セッションのタイトル (#15059) (706cfa212b)
  • 修正 (ツール): open_url 応答本文をバインドし、IPv6 IMDS をブロック (#14990) (695d024fd9)
  • 修正(cli): リモート サーブ セッションをホスト構成から切り離す (#14986) (49530ec121)
  • 機能 (コネクタ): 添付ファイル オプションの背後にある Teams チャネルに投稿されたインデックス ファイル (#14851) (16c43a9032)
  • リファクタリング(cli): パディングを削除する構造体フィールドの順序 (#14872) (a49fd0214b)
  • 修正 (コネクタ): ダウンロードを制限し、一時認証情報を保護 (#14821) (92aee9f4b4)
  • 機能 (コネクタ): メールボックス所有者とイベント参加者からの Outlook アクセス許可を同期する (#14752) (a23baa4355)
  • 機能 (コネクタ): Outlook 添付ファイルのインデックスを作成し、証明書の資格情報を受け入れる (#14736) (adbdd89fed)
  • feat(ods): ods release cli と ods release ods を追加 (#14724) (4190ba91c4)
  • ビルド: ホイール ビルド環境をピン留めし、1.27.1 (#14719) (16247eec9d) に移動してアップグレードします。
  • 修正 (メトリクス): コレクションが停止している間に古いデータを提供し、Redis ソケット期限を追加 (#14643) (0fed336c6b)
