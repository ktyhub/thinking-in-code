#結果論v1.0.0

何が変わったのか

  • 修正 (ドキュメント): 概要ヒーローがワイド スクリーンでウィンドウの端に到達する (https://github.com/vectorize-io/hindsight/pull/5440 の @nicoloboschi による)
  • ドキュメント: changelog および https://github.com/vectorize-io/hindsight/pull/5435 の @nicoloboschi による v0.10.3 のブログ投稿
  • ドキュメント: https://github.com/vectorize-io/hindsight/pull/5441 の @nicoloboschi によるホームページのリンク プレビューを修正
  • ドキュメント (ブログ): https://github.com/vectorize-io/hindsight/pull/5460 の @nicoloboschi による、説明のサブタイトルと署名行を含むプレーンな投稿タイトル
  • fix(ui): https://github.com/vectorize-io/hindsight/pull/5450 の @cdbartholomew により、エンティティ ラベルのルート レベルで no-op '+field' ボタンを非表示にしました
  • refactor(openclaw)!: https://github.com/vectorize-io/hindsight/pull/5462 の @nicoloboschi によるagent-sdk パッケージとagent_knowledge_* ツールを削除します。
  • 修正(api): https://github.com/vectorize-io/hindsight/pull/5463 で @cdbartholomew が銀行全体に対して応答した操作でタグ スコープの呼び出し元を拒否する
  • ドキュメント (grok-bot): マーケットプレイスのリストは、https://github.com/vectorize-io/hindsight/pull/5465 の @benfrank241 によってまだ承認されていません。
  • ブログ: Grok Bot Can Read What Your Other AI Tools Already Learned by @benfrank241 (https://github.com/vectorize-io/hindsight/pull/5461)
  • chore(deps): https://github.com/vectorize-io/hindsight/pull/5482 の @cdbartholomew による eliza 統合でハンドルバーを 4.7.10 にバンプ
  • chore(deps): https://github.com/vectorize-io/hindsight/pull/5483 の @cdbartholomew による pydantic-ai 統合で pydantic-ai-slim を 1.107.7 にバンプします
  • chore(deps): https://github.com/vectorize-io/hindsight/pull/5484 の @cdbartholomew による llamaindex 統合でバンクを 2.5.1 にバンプする
  • chore(deps): https://github.com/vectorize-io/hindsight/pull/5481 の @cdbartholomew によるルート ロックファイル内のハンドルバーを 4.7.10 にバンプします
  • 修正 (統合): クロード コード チャンク ロス + タイムスタンプ、カーソル Windows フック、https://github.com/vectorize-io/hindsight/pull/5506 の @nicoloboschi による ZED ネイティブ MCP URL
  • fix(coding-agents): Windows フックとスポーン、pi セッション cwd、https://github.com/vectorize-io/hindsight/pull/5511 の @nicoloboschi による git ログ解析
  • 修正 (openclaw): BankMission スキーマのデフォルトを削除し、https://github.com/vectorize-io/hindsight/pull/5512 の @nicoloboschi によるバンク ミッションの上書きを停止します。
  • 修正 (コーディング エージェント): セッション開始サーベイ/リフレクト ゲーティング、共有バンク ページ スコープ、https://github.com/vectorize-io/hindsight/pull/5510 の @nicoloboschi によるイニシアチブ マーカー
  • 修正(コーディングエージェント): 長いプロンプトでのメモリインジェクション、空の最初のリコール、dsh の繰り返し、および Grok Build (https://github.com/vectorize-io/hindsight/pull/5514 の @nicoloboschi による)
  • 修正(openclaw): プラグインのコピーから保持 OpenClaw が https://github.com/vectorize-io/hindsight/pull/5517 の @nicoloboschi によって起動されなかった
  • fix(control-plane): https://github.com/vectorize-io/hindsight/pull/5518 の @nicoloboschi によるエンティティ ラベル エディターの次のビルド タイプ エラーを修正
  • fix(coding-agents): 保持されたセッション全体を保持します (pi の実行、失敗した操作、終了、ところでセッション、コーデックスの起動) by @nicoloboschi (https://github.com/vectorize-io/hindsight/pull/5508)
  • fix(openclaw): https://github.com/vectorize-io/hindsight/pull/5522 の @nicoloboschi による session_end で OpenClaw のリーダーを通じて終了したトランスクリプトを読み取ります
  • 修正 (api): 統合検出プローブ、メンタルモデル編集レース、https://github.com/vectorize-io/hindsight/pull/5513 の @nicoloboschi による LlamaParse v2
  • docs(hermes): https://github.com/vectorize-io/hindsight/pull/5521 の @nicoloboschi による構成リファレンスを完成および修正
  • feat(統合): すべての統合は、https://github.com/vectorize-io/hindsight/pull/5466 の @nicoloboschi により、独自のユーザー エージェントでそれ自体を識別します。
  • 修正(clients,cli): https://github.com/vectorize-io/hindsight/pull/5515 の @nicoloboschi による前方互換性のあるデコードと制限付きエクスポート ポーリング
  • fix(coding-agents): ドレイン、リフレクト、ページ ラッチ、追加プローブ、https://github.com/vectorize-io/hindsight/pull/5509 の @nicoloboschi によるロング リフレクトでの HTTP エラー処理
  • 修正 (hermes): 動作変更を必要としない 6 つのプラグインのバグ (https://github.com/vectorize-io/hindsight/pull/5523 の @nicoloboschi による)
  • テスト(保持): https://github.com/vectorize-io/hindsight/pull/5525 の @nicoloboschi によるファクト タイプをカウントする代わりに、エージェント エクスペリエンスの分類を判断します。
  • 修正 (openclaw): message_received で受信 ID をキャプチャし、https://github.com/vectorize-io/hindsight/pull/5530 で @nicoloboschi によって目標を開始できるようにする
  • docs(meta-muse): https://github.com/vectorize-io/hindsight/pull/5533 の @nicoloboschi による統合ページから changelog をリンクします。
  • 修正 (openclaw): https://github.com/vectorize-io/hindsight/pull/5532 の @nicoloboschi による logLevel と logsummaryIntervalMs を尊重します。
  • 修正(保持): https://github.com/vectorize-io/hindsight/pull/5529 の @nicoloboschi により、新しいドキュメントに追加された JSON 配列を 1 つの配列にマージします
  • 修正 (hermes): https://github.com/vectorize-io/hindsight/pull/5534 の @nicoloboschi による #4662 からの小さなプラグインのバグのバッチ
  • feat(openclaw): https://github.com/vectorize-io/hindsight/pull/5535 の @nicoloboschi によって OpenClaw のネイティブ メモリ プロバイダーとして登録
  • 修正(api): 散文「事実がありません」を保持、クロードコード JSON 修復、コーデックス ストリーム エラー、プロバイダー スパン、https://github.com/vectorize-io/hindsight/pull/5516 の @nicoloboschi によるクロードコード ToS ドキュメント
  • 修正(api): https://github.com/vectorize-io/hindsight/pull/5527 の @nicoloboschi により、リクエストをシェッドするストアは 500 ではなく 503 + Retry-After に応答します。
  • 修正 (hermes): cron の実行をスキップし、HINDSIGHT_BANK_ID を尊重し、reflect_tags を追加し、https://github.com/vectorize-io/hindsight/pull/5538 の @nicoloboschi によって到達不能なサーバーを再調査します
  • test(worker): https://github.com/vectorize-io/hindsight/pull/5537 の @nicoloboschi による同時要求テストで排出されるまでポーリングします。
