hindsight v1.2.1

パッチ 公開日2026年11月10日 出典vectorize-io/hindsight 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#結果論v1.2.1

何が変わったのか

  • ドキュメントは、https://github.com/vectorize-io/hindsight/pull/6284 の @nicoloboschi による 0.9 をドロップします
  • ドキュメント: https://github.com/vectorize-io/hindsight/pull/6285 の @nicoloboschi によるナビゲーションバーの下の進行状況バーの読み取り
  • 修正 (管理者): 後知恵管理クラウドが https://github.com/vectorize-io/hindsight/pull/6286 の @nicoloboschi による --help にリストされています。
  • 修正(api): バンク、エイリアス、メンタル モデルに対する 1 つの ID ルール。 @nicoloboschi によるバインドされたページ max_tokens (https://github.com/vectorize-io/hindsight/pull/6282)
  • fix(coding-agents): 調査はすべてのホストから再度開始されます。 https://github.com/vectorize-io/hindsight/pull/6287 の @nicoloboschi によってターミナル マネージャーの環境コードとカラー コードが表示されないようにする
  • ドキュメント(changelog): https://github.com/vectorize-io/hindsight/pull/6288 の @nicoloboschi によるコーディング エージェントの 0.8.5 修正を正確に説明します。
  • 修正 (hermes): 1.x hindsight-client および @nicoloboschi による https://github.com/vectorize-io/hindsight/pull/6290 による hindsight-embed を受け入れる
  • 修正(hermes): https://github.com/vectorize-io/hindsight/pull/6291 で @nicoloboschi が追加するたびにセッションのメモリを書き換えないようにしました。
  • 修正 (hermes): https://github.com/vectorize-io/hindsight/pull/6292 の @nicoloboschi によって hindsight_client がインポートできない場合にプロバイダーが利用できないことを報告
  • 修正 (hermes): https://github.com/vectorize-io/hindsight/pull/6296 の @nicoloboschi によるコントロール プレーン プロキシの背後にあるサーバー バージョンを見つける
  • fix(memories): ファクトのエンティティは、リストと https://github.com/vectorize-io/hindsight/pull/6294 で @nicoloboschi によって読み取られた単一の両方で名前でソートされて戻ってきます。
  • 修正 (エルメス): https://github.com/vectorize-io/hindsight/pull/6297 の @nicoloboschi による古いキープアライブ接続のリコールを再試行します
  • fix(hermes): https://github.com/vectorize-io/hindsight/pull/6299 の @nicoloboschi によって、起動されたデーモンにユーザーのデータベースの場所を通知します
  • ドキュメント: changelog および https://github.com/vectorize-io/hindsight/pull/6281 の @nicoloboschi による v1.2.0 のブログ投稿
  • 修正（保持）：store_document_text がオフになっているストア所有の銀行は、https://github.com/vectorize-io/hindsight/pull/6301 の @nicoloboschi によるチャンク テキストを保持しません
  • 修正 (バンク): クローン、インポート、名前変更でバンクがエイリアス (#6280) を引き継ぐことができなくなりました (https://github.com/vectorize-io/hindsight/pull/6318 の @nicoloboschi による)
  • ci: Gemma 4 (Hindsight Inference Dev) で CI の LLM を実行し、https://github.com/vectorize-io/hindsight/pull/6289 で @nicoloboschi を通過するようにプロンプト修正を加えます。
  • perf(db): JIT をオフにしてすべてのプール接続を実行するため、リコールは https://github.com/vectorize-io/hindsight/pull/6317 の @nicoloboschi による監視ルックアップ (#6306) のコンパイルを停止します。
  • fix(worker): 削除された銀行の実行中のジョブの再作成を停止 (#6344) by @nicoloboschi (https://github.com/vectorize-io/hindsight/pull/6346)
  • fix(retain): 追加は、次の追加が本体を再チャンクする方法と同じ方法で本体をチャンクします (#6293) by @nicoloboschi (https://github.com/vectorize-io/hindsight/pull/6354)
  • ドキュメント(モデル): https://github.com/vectorize-io/hindsight/pull/6363 の @nicoloboschi による OpenRouter ホスト ルーティングの説明
  • ドキュメント: Intel Mac で Hindsight を実行する方法 by @nicoloboschi (https://github.com/vectorize-io/hindsight/pull/6364)
  • 修正(ローカルモデル): Windows 上の OS にも解放されたヒープ ページを返す (#5478) by @nicoloboschi (https://github.com/vectorize-io/hindsight/pull/6365)
  • fix(migrations): テナント拡張機能が https://github.com/vectorize-io/hindsight/pull/6366 の @nicoloboschi によってリストされていない場合、起動時にベース スキーマを移行します。
  • ドキュメント: https://github.com/vectorize-io/hindsight/pull/6367 の @nicoloboschi による、reflect_default_options がメンタルモデルの更新に達しない
  • 修正 (知識ベース): Python の検索スニペットをカットして SQL_ASCII データベースが 500 にならないように (https://github.com/vectorize-io/hindsight/pull/6368 の @nicoloboschi により)
  • chore(engine): https://github.com/vectorize-io/hindsight/pull/6369 の @nicoloboschi による到達不能な merge_bank_mission を削除
  • 修正（リコール）: https://github.com/vectorize-io/hindsight/pull/6373 の @nicoloboschi により、行ごとにではなく、検索ごとに VectorChord BM25 クエリを 1 回構築します
  • 修正（統合）: https://github.com/vectorize-io/hindsight/pull/6374 の @nicoloboschi による返信でスキーマが欠落している場合、エラーを含めて一度再質問します
  • fix(coding-agents): ホスト自身の CLI の下でのみコードベース調査を実行 (https://github.com/vectorize-io/hindsight/pull/6378 の @nicoloboschi により)
  • ドキュメント(changelog): https://github.com/vectorize-io/hindsight/pull/6383 の @nicoloboschi によって修正されたコーディング エージェント 0.8.6 を正確に説明します。
  • 修正 (メンタルモデル): 一時的な障害と LLM スロット待機によって自動更新が一時停止されなくなりました (#6140) by @nicoloboschi (https://github.com/vectorize-io/hindsight/pull/6385)
  • fix(retain): https://github.com/vectorize-io/hindsight/pull/6370 の @nicoloboschi によって埋め込みバックエンドが認識されている場合、LLM パスをスキップします
  • feat(db): HINDSIGHT_API_DATABASE_CONNECT_HOOK により、プールは https://github.com/vectorize-io/hindsight/pull/6376 の @nicoloboschi によってローテーションされた認証情報を取得します
  • 修正(スクリプト): 相対的な core.hooksPath を設定して、ワークツリーが https://github.com/vectorize-io/hindsight/pull/6381 の @nicoloboschi によって共有されないようにする
  • feat(拡張機能): https://github.com/vectorize-io/hindsight/pull/6386 の @nicoloboschi による更新されたメンタル モデル ページを操作バリデーターが拒否できるようにします。
  • feat(stats): 自動更新が一時停止されているメンタル モデルをカウントする (#6077) by @nicoloboschi (https://github.com/vectorize-io/hindsight/pull/6375)
  • 修正: 脆弱なテストと CI フレーク (9 件) by @nicoloboschi (https://github.com/vectorize-io/hindsight/pull/6371)
  • 偉業(cli): @nicoloboschi による各リリースにネイティブ Windows x64 バイナリを https://github.com/vectorize-io/hindsight/pull/6382 で同梱
  • 修正 (ワーカー): SIGTERM はすぐに要求を停止し、ドレインは猶予期間に適合します (#6021) by @nicoloboschi (https://github.com/vectorize-io/hindsight/pull/6377)
  • feat(llm): https://github.com/vectorize-io/hindsight/pull/6384 の @nicoloboschi による型付きバッチ コントラクトを使用した、クラスパスによるカスタム LLM プロバイダー
  • fix(mcp): https://github.com/vectorize-io/hindsight/pull/6392 の @nicoloboschi によって、各マルチバンク ツールの結果を 2 回ではなく 1 回送信します。
  • feat(管理者): サーバーが実行され続けている間に、新しい埋め込みモデルでスキーマを再埋め込み (https://github.com/vectorize-io/hindsight/pull/6372 の @nicoloboschi により)
  • feat(recall): 意思決定モデルが失敗した場合のリランカーへのオプトイン フォールバック by @nicoloboschi (https://github.com/vectorize-io/hindsight/pull/6389)
  • perf(knowledge): https://github.com/vectorize-io/hindsight/pull/6398 の @nicoloboschi により、ノードごとにバンクを再スキャンせずにフォルダーを削除します
  • 修正(バンク): https://github.com/vectorize-io/hindsight/pull/6333 の @nicoloboschi により、再作成されたバンクには削除されたバンクのキャッシュされた統計が表示されなくなりました。
  • fix(llm): オプションのツール引数を型リスト (#6321、#6305) ではなく、anyOf として書き込みます (https://github.com/vectorize-io/hindsight/pull/6401 の @nicoloboschi による)
  • perf(retain): https://github.com/vectorize-io/hindsight/pull/6402 の @nicoloboschi によるスコープ付き保持のために既存のドキュメントのタグを一度に読み取ります
  • perf(observations): スコープをソートする前に同一のタグリストをカウントする (#6328) by @nicoloboschi (https://github.com/vectorize-io/hindsight/pull/6404)
  • perf(consolidation): バンクをカウントせずに保留中の作業をチェック by @nicoloboschi (https://github.com/vectorize-io/hindsight/pull/6403)
  • feat(embeddings): https://github.com/vectorize-io/hindsight/pull/6380 の @nicoloboschi による個別のクエリとパッセージのエンベッダー
  • feat(拡張機能): @nicoloboschi によって https://github.com/vectorize-io/hindsight/pull/6400 に保存される前に、抽出されたメモリと統合書き込みをレビューします。
  • perf(consolidation): https://github.com/vectorize-io/hindsight/pull/6406 の @nicoloboschi による ID でリコールされた観測値を検索します。
  • 修正(統合): https://github.com/vectorize-io/hindsight/pull/6399 での @nicoloboschi による観察に関する最新の 3 つの以前の状態のメモのみを保持する
  • perf(staleness): ページごとに 1 回ではなく、フィルターを共有するページに 1 回確認する (#6325) by @nicoloboschi (https://github.com/vectorize-io/hindsight/pull/6407)
  • chore(deps): https://github.com/vectorize-io/hindsight/pull/6311 の @cdbartholomew による system-evals で pyasn1 を 0.6.5 にバンプします
  • chore(deps): https://github.com/vectorize-io/hindsight/pull/6310 の @cdbartholomew により、スーパーエージェントで pypdf を 6.21.4 にバンプします
  • chore(deps): https://github.com/vectorize-io/hindsight/pull/6309 の @cdbartholomew により、google-adk で joserfc を 1.7.7 に、pyasn1 を 0.6.5 にバンプします
  • chore(deps): https://github.com/vectorize-io/hindsight/pull/6308 の @cdbartholomew によって pyasn1 を 0.6.5 にバンプします
  • chore(deps): https://github.com/vectorize-io/hindsight/pull/6307 の @cdbartholomew によるバンプフォローリダイレクトと 1.16.2 および joi の 17.13.9
  • perf(entities): スコープ付きの名前検索または詳細は、要求するエンティティのみを読み取ります (#6330) by @nicoloboschi (https://github.com/vectorize-io/hindsight/pull/6410)
  • 修正(転送): https://github.com/vectorize-io/hindsight/pull/6408 の @nicoloboschi によるマージではなく、同じ新しいバンクに別のリストアを競合させると拒否される
  • 修正(転送): 銀行全体のエクスポートとインポートのアーカイブを銀行のストレージ プレフィックスの下に保持 (https://github.com/vectorize-io/hindsight/pull/6409 の @nicoloboschi による)
  • perf(recall): リコールごとに各ソース ファクトのトークンを 1 回カウントします (#6329) (https://github.com/vectorize-io/hindsight/pull/6405 の @nicoloboschi による)
  • fix(retain): 同じコンテンツを 2 つ同時に保持すると、各ファクトが 1 回保存されます (#6337) by @nicoloboschi (https://github.com/vectorize-io/hindsight/pull/6433)

  • 修正（リコール）: https://github.com/vectorize-io/hindsight/pull/6464 の @nicoloboschi による dateparser 1.5.0 時間検索 (#6359) をサポート

  • fix(graph-maintenance): 同じバンクのライターをコンボイするキュー行ロックを停止 (#6417) by @nicoloboschi (https://github.com/vectorize-io/hindsight/pull/6472)
  • fix(llm): ツール呼び出しの応答をその関数に対してチェックし、一度修正します (#6420、#6302) by @nicoloboschi (https://github.com/vectorize-io/hindsight/pull/6469)

  • fix(retain): 大規模な更新をバッチで保存するため、中断された更新でも進行状況が維持されます (#6394) by @nicoloboschi (https://github.com/vectorize-io/hindsight/pull/6484)
  • リファクタリング!: https://github.com/vectorize-io/hindsight/pull/6477 の @nicoloboschi により、Knowledge Pages の名前が Pages に変更されました (古い名前は 2.x まで非推奨でした)
  • fix(coding-agents): https://github.com/vectorize-io/hindsight/pull/6491 で @nicoloboschi によってリコール/反映される前に、ホストによって挿入されたタグをプロンプトから削除します
  • 修正(添付ファイル): 毎日のスイープにより、https://github.com/vectorize-io/hindsight/pull/6474 の @nicoloboschi によって失敗した保持 (#6350) の添付ファイルが削除されます。
