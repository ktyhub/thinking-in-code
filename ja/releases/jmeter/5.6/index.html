jmeter v5.6

jmeter rel/v5.6

回帰

次の回帰は 5.6.1 で解決されます。

  • ThreadGroups が非 GUI モードで際限なく実行される https://github.com/apache/jmeter/issues/6008
  • Java Request サンプラーを無効にすると、再度有効にすることはできません https://github.com/apache/jmeter/issues/6004

何が変わったのか

  • ドキュメント: https://github.com/apache/jmeter/pull/718 の @vlsi によるオープン モデル スレッド グループのドキュメントに負荷プロファイルのサンプルを追加
  • https://github.com/apache/jmeter/pull/722 の @pjfanning によるマスター テスト
  • .asf.yaml を追加し、https://github.com/apache/jmeter/pull/728 の @vlsi による GitHub の問題を有効にします
  • https://github.com/apache/jmeter/pull/5710 の @vlsi による GitHub 問題テンプレートを追加
  • doc: https://github.com/apache/jmeter/pull/5711 の @vlsi によるドキュメント内の <issue> マークアップを処理します
  • https://github.com/apache/jmeter/pull/725 の @kaola89 によるオープン モデル スレッド グループの簡体字中国語翻訳を追加
  • 同期タイマーテスト | https://github.com/apache/jmeter/pull/726 の @SampathKumarAmex により一貫性を保つために Junit 5 アサーションを使用しました
  • https://github.com/apache/jmeter/pull/691 の @SampathKumarAmex により grgit を 4.1.1 (4.1.0 から) に更新
  • https://github.com/apache/jmeter/pull/5713 の @vlsi により Spock を 2.2-groovy-3.0 (2.1-groovy-3.0 から) に更新
  • https://github.com/apache/jmeter/pull/5719 の @vlsi によって ASF が Travis CI から離れるため、Travis CI 構成を削除します
  • https://github.com/apache/jmeter/pull/5722 の @vlsi による v3 へのアクション/チェックアウトのバンプ
  • Bugzilla を更新 -> https://github.com/apache/jmeter/pull/5712 の @vlsi による貢献ドキュメントの GitHub の問題
  • UPPER は、https://github.com/apache/jmeter/pull/5731 の @orimarko による ChangeCase のデフォルトのケースです
  • checksum-dependency-plugin を 1.86 にバンプすることで、公開 pgp キーを https://github.com/apache/jmeter/pull/5760 の @vlsi によるソース管理下に保存できるようになります
  • https://github.com/apache/jmeter/pull/5763 の @vlsi により、Gradle を 7.3 から 7.6 に更新します ※アサートから変更。アサーションに。 @milamberspace 著、https://github.com/apache/jmeter/pull/5813
  • バグ #5807 - HTTP パラメーターの ArrayIndexOutOfBoundsException を修正… by @milamberspace (https://github.com/apache/jmeter/pull/5812)
  • start_no_timers に KeyStroke を追加 (一時停止なしで開始: CRTL+SHIFT+n) (https://github.com/apache/jmeter/pull/5792 の @dgetzlaf による)
  • 雑務: https://github.com/apache/jmeter/pull/5814 の @vlsi によって Gradle を 8.1.1 にバンプする
  • 雑務: https://github.com/apache/jmeter/pull/5828 の @vlsi によってリリース バージョンをビルドする場合にのみ verifyReleaseDependency を呼び出します
  • https://github.com/apache/jmeter/pull/5870 の @FSchumacher によるテストスイートのデッドロック
  • https://github.com/apache/jmeter/pull/5874 の @FSchumacher により Argument オブジェクト内の変数名をトリミング
  • [66139] オープン モデル スレッド グループが https://github.com/apache/jmeter/pull/717 の @vlsi によって構成要素を 1 回だけ初期化するようにする
  • https://github.com/apache/jmeter/pull/5873 に @vlsi によるエラーが発生しやすい検証を追加
  • https://github.com/apache/jmeter/pull/5901 の @milamberspace により、プロキシ設定パネルでカウンターが空であるか数字ではない場合の NumberFormatException を修正
  • https://github.com/apache/jmeter/pull/5899 の @vlsi によってスレッド間で共有される要素 (NoThreadClone を実装する要素) のrecoverRunningVersion をスキップすることで、CPU バウンドのテストを高速化します。
  • https://github.com/apache/jmeter/pull/5876 の @FSchumacher によってループ数に JMeterProperty#intValue を直接使用します
  • HTTP ヘッダーのキャッシュには、https://github.com/apache/jmeter/pull/5911 の @vlsi による commons-collections4 LRUMap の代わりに Caffeine を使用します
  • 特技: https://github.com/apache/jmeter/pull/5909 の @vlsi による commons-collections4 LRUMap の代わりに、JSR223 サンプラーでコンパイルされたスクリプトをキャッシュするために Caffeine を使用する
  • 偉業: https://github.com/apache/jmeter/pull/5910 の @vlsi による commons-collections4 LRUMap の代わりに TestBeanGUI でカスタマイザーをキャッシュするために Caffeine を使用する
  • 特技: https://github.com/apache/jmeter/pull/5885 の @vlsi で jar 内のクラスを検索する代わりに、ServiceLoader を使用して実装を検索します。
  • 特技: https://github.com/apache/jmeter/pull/5788 の @vlsi による FunctionProperty キャッシュを無効にするプロパティを追加
  • ci: https://github.com/apache/jmeter/pull/693 の @vlsi によるテスト カバレッジを向上させるためにランダム化行列を追加します。
  • スタイル: https://github.com/apache/jmeter/pull/5927 の @vlsi によるプライベートおよび静的メソッドに境界付きワイルドカードを使用する
  • https://github.com/apache/jmeter/pull/5787 の @raboof によりウェブサイトの著作権年を 2023 年に更新
  • perf: https://github.com/apache/jmeter/pull/5934 の @vlsi による __time 関数のキャッシュ日時フォーマッタ
  • リセット検索用のショートカット キー イベントを追加しました - 66053 by @rollno748 (https://github.com/apache/jmeter/pull/710)
  • perf: https://github.com/apache/jmeter/pull/5952 の @vlsi によって HTTP サンプラーから過剰な BufferedInputStream を削除
  • perf: https://github.com/apache/jmeter/pull/5953 の @vlsi による HTTPJavaImpl の String.replaceAll を回避する
  • perf: https://github.com/apache/jmeter/pull/5954 の @vlsi による HTTPHC4.HttpClientKey での文字列連結を回避します。
  • 修正: PropertyIterator.remove は、https://github.com/apache/jmeter/pull/5958 の @vlsi によって TestElement の両方のコレクションからプロパティを削除する必要があります
  • 雑用: https://github.com/apache/jmeter/pull/5962 の @vlsi によるビルドに Xmx1500m を割り当てる
  • テスト: https://github.com/apache/jmeter/pull/5960 の @vlsi により、JMeter コードでマイクロベンチマークを作成するための OpenJDK JMH を追加
  • https://github.com/apache/jmeter/pull/5959 の @vlsi によって TestElement インターフェイスを Kotlin に移行します
  • 雑用: https://github.com/apache/jmeter/pull/5965 の @vlsi によるビルド ログの冗長性を軽減
  • https://github.com/apache/jmeter/pull/5869 の @FSchumacher によってサンプラー名を計算するためにテンプレートに変数を追加します
  • ドキュメント: https://github.com/apache/jmeter/pull/5936 の @vlsi により次のバージョンを 5.6 に更新します
  • 特技: https://github.com/apache/jmeter/pull/5944 の @vlsi によるチェックボックス コントロールの ${...} 式の使用を有効にする
  • 雑用: https://github.com/apache/jmeter/pull/5972 の @vlsi によって vlsi-release-plugins を 1.89 にバンプする
  • 雑務: https://github.com/apache/jmeter/pull/5975 の @vlsi によるすべてのテスト クラスに依存する代わりに、testFixtures ソースセットを使用します。
  • perf: https://github.com/apache/jmeter/pull/5985 の @vlsi によって空のコレクションを反復処理するときに PropertyIteratorImpl.EMPTY_ITERATOR を追加します
  • 修正: 要素コンストラクターが https://github.com/apache/jmeter/pull/5984 の @vlsi によってデフォルト以外のプロパティ値を追加した場合、AbstractTestElement#clone が同一でないクローンを生成する可能性がある
  • https://github.com/apache/jmeter/pull/678 の @vlsi によるプログラムによるテスト計画生成用の DSL
  • 修正: https://github.com/apache/jmeter/pull/5988 の @vlsi による下位互換性のために、パブリック静的最終文字列参照をリテラルに復元
  • 修正: https://github.com/apache/jmeter/pull/5987 の @vlsi によって HTTP サンプラーでファイルを送信するときにファイル名内の Unicode 文字をエンコードする
