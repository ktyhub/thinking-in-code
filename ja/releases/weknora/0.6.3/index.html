WeKnora v0.6.3

#WeKnora v0.6.3

何が変わったのか

  • 偉業(docker): フロントエンドのビルドプロセスを合理化し、https://github.com/Tencent/WeKnora/pull/1642 の @lyingbug によって Docker 構成を更新します
  • スタイル(フロントエンド): https://github.com/Tencent/WeKnora/pull/1648 の @lyingbug により、AgentList、Chat、KnowledgeBaseList コンポーネントのレイアウトを改善するためにパディングとマージンを調整します。
  • feat(ui): https://github.com/Tencent/WeKnora/pull/1649 の @lyingbug による最初のセクションのサポートにより、ナレッジ ベースの作成を強化します。
  • https://github.com/Tencent/WeKnora/pull/1650 の @lyingbug により、アクティブなナレッジ ファイル タイプのパーサー ルール表示を調整します
  • 特技(メニュー): https://github.com/Tencent/WeKnora/pull/1655 の @lyingbug による検索ボタンとトグル ボタンでサイドバーの機能を強化
  • feat(menu): https://github.com/Tencent/WeKnora/pull/1661 の @lyingbug による新しいチャット機能とローカリゼーションの更新により、メニュー コンポーネントを強化します。
  • リファクタリング(設定): https://github.com/Tencent/WeKnora/pull/1662 の @lyingbug により、設定ビュー全体で空の状態の処理を統合します。
  • https://github.com/Tencent/WeKnora/pull/1669 で @jack-wang-176 によって設定された 1646 欠落エラーを修正
  • feat(im): サイドバー ソース フィルター、コンテンツ タイトル、および https://github.com/Tencent/WeKnora/pull/1659 の @voidkey による飛行中の返信の回復
  • 修正 (データソース): https://github.com/Tencent/WeKnora/pull/1652 の @langcaiye による編集が同期しないことを明確にしました。
  • 修正: https://github.com/Tencent/WeKnora/pull/1568 で @kshitijshresth による同期ログ制限パラメーターを検証
  • 修正(tcvdb): https://github.com/Tencent/WeKnora/pull/1575 の @langcaiye によるコレクションの互換性を改善
  • 修正 (wiki): https://github.com/Tencent/WeKnora/pull/1666 の @langcaiye による削除時に古い引用チャンクをクリア
  • feat(embed): サポート将智能体以 iframe / 浮窗形式嵌入第三方网站 (#1657) by @lyingbug in https://github.com/Tencent/WeKnora/pull/1673
  • 偉業(フロントエンド): https://github.com/Tencent/WeKnora/pull/1684 の @lyingbug によるナレッジ ベースのデータソース設定 UI の洗練
  • 修正 (wiki): https://github.com/Tencent/WeKnora/pull/1681 の @FFFFFFpy による UUID/パスの破損を防ぐために、LLM の前に画像 URL をマスクします。
  • 修正: @MaoMengww による https://github.com/Tencent/WeKnora/pull/1654 の埋め込み API リクエストでディメンションが送信されない問題を修正
  • 修正(認証): https://github.com/Tencent/WeKnora/pull/1685 の @lyingbug によるログアウト時のセッション リソース キャッシュのクリア
  • https://github.com/Tencent/WeKnora/pull/1686 の @lyingbug による埋め込みディメンション オーバーライドのサポートを追加
  • feat(im): https://github.com/Tencent/WeKnora/pull/1690 の @lyingbug による IMChannelPanel コンポーネントと SettingDrawer コンポーネントの強化
  • feat(バックエンド): チャンクのマージ、画像情報のマッチング、および https://github.com/Tencent/WeKnora/pull/1691 の @lyingbug による RAG 進行イベント
  • feat(エージェント): リランクしきい値、ツール永続トリミング、https://github.com/Tencent/WeKnora/pull/1692 の @lyingbug による Langfuse トレース
  • feat(チャット): https://github.com/Tencent/WeKnora/pull/1693 の @lyingbug によるマークダウン レンダリングと引用ポップオーバーの共有
  • 成果 (チャット): エージェント ストリームのリファクタリング、ツールの結果、および UX のレイアウト (https://github.com/Tencent/WeKnora/pull/1694 の @lyingbug による)
  • 功績: https://github.com/Tencent/WeKnora/pull/1695 の @FFFFFFpy による EPUB および MHTML ドキュメントのサポートを追加
  • 修正 (wiki): 回避するには、保護されたプロバイダー イメージにプレースホルダー src を使用します…by @FFFFFFpy in https://github.com/Tencent/WeKnora/pull/1697
  • feat(docreader): https://github.com/Tencent/WeKnora/pull/1702 の @lyingbug による opendataloader パーサーのクイック可用性プローブを追加
  • 修正 (フロントエンド): https://github.com/Tencent/WeKnora/pull/1701 の @adawang1210 によるマニュアル ナレッジ エディターで書き込み可能な共有 KB をリストします。
  • 修正: https://github.com/Tencent/WeKnora/pull/1699 の @langcaiye による再試行が尽きた後のナレッジ削除失敗のマーク付け
  • fix(chunker): https://github.com/Tencent/WeKnora/pull/1700 の @adawang1210 により、深いサブ見出しのコンテキストを大きなセクションのチャンクに運びます
  • 偉業(wiki): https://github.com/Tencent/WeKnora/pull/1705 の @adawang1210 によるプレフィックス キャッシュのチャンク引用プロンプトのフロントロード静的ルール
  • perf(サンドボックス): https://github.com/Tencent/WeKnora/pull/1710 の @adawang1210 によってコマンド置換正規表現を 1 回コンパイルします
  • perf(common): https://github.com/Tencent/WeKnora/pull/1711 の @adawang1210 によって LLM-JSON コードフェンス正規表現を 1 回コンパイルします
  • 偉業(wiki): ページ階層/カテゴリメタデータを追加し、https://github.com/Tencent/WeKnora/pull/1703 の @lyingbug による API を取得します。
  • feat(wiki): Wiki ブラウザにカテゴリ階層とナビゲーションを表示 by @lyingbug (https://github.com/Tencent/WeKnora/pull/1704)
  • feat(wiki): https://github.com/Tencent/WeKnora/pull/1715 の @lyingbug によるアンカー フォームのポップアップと国際化の更新を強化
  • 修正 (docreader): https://github.com/Tencent/WeKnora/pull/1714 の @FFFFFFpy による epub および mhtml パーサーの登録を復元
  • fix(vectordb): https://github.com/Tencent/WeKnora/pull/1668 の @cctv549681 による質問データの修正と方向量データベースの ID 映射问题
  • 功績: @langcaiye によるテナント ワークスペース削除 UI を https://github.com/Tencent/WeKnora/pull/1706 に追加
  • 修正 (テナント): 削除時にメンバーシップをパージし、https://github.com/Tencent/WeKnora/pull/1718 の @lyingbug によって古いスイッチャー行をフィルターします
  • perf(utils): https://github.com/Tencent/WeKnora/pull/1708 の @adawang1210 による呼び出しごとではなく、SQL 検証正規表現を 1 回コンパイルします
  • 修正 (docreader): https://github.com/Tencent/WeKnora/pull/1717 の @JojaCola312 による PDF JPEG 品質のデフォルト アサーションを調整
  • 機能 (フロントエンド): https://github.com/Tencent/WeKnora/pull/1724 の @lyingbug による手動ナレッジ エディターとチャット引用レンダリングを改善しました。
  • [コーデックス] ポーランド語のチャットの提案、引用、引き出し (https://github.com/Tencent/WeKnora/pull/1728 の @lyingbug による)
  • style(frontend): https://github.com/Tencent/WeKnora/pull/1730 の @lyingbug により、ホバー状態とアクティブ状態を改善するために ListSpaceSidebar スタイルを更新します。
  • 機能 (フロントエンド): https://github.com/Tencent/WeKnora/pull/1744 の @lyingbug によるシマー エフェクトとフェード テールでチャット ストリーミング ビジュアルを強化します。
  • 特技(フロントエンド): ディレクトリ ビューの切り替えを追加し、https://github.com/Tencent/WeKnora/pull/1745 の @lyingbug によってローカリゼーションを改善しました。
  • 修正（フロントエンド）: UploadconfirmDialog z-index を下げて、https://github.com/Tencent/WeKnora/pull/1737 の @hiasky によって設定モーダルがその上に表示されるようにしました
  • 修正（フロントエンド）: https://github.com/Tencent/WeKnora/pull/1732 の @hiasky によるモーダル設定がビューポートからオーバーフローするのを防止
  • 機能 (フロントエンド): Wiki ツールのサポートを追加し、https://github.com/Tencent/WeKnora/pull/1746 の @lyingbug によるエージェント ツール アイコン マッピングを強化しました。
  • 修正 (フロントエンド): https://github.com/Tencent/WeKnora/pull/1747 の @lyingbug によって開始区切り文字を正しく処理できるように、repairFlankingEmphasis を強化しました。
  • 特技(フロントエンド): MCP 設定セクションを追加し、https://github.com/Tencent/WeKnora/pull/1749 の @lyingbug によってモーダル ナビゲーション スタイルを統一します。

  • 修正 (docparser): https://github.com/Tencent/WeKnora/pull/1752 の @lyingbug による組み込みのシャドウイングを避けるために close 変数の名前を変更

  • 修正(api): https://github.com/Tencent/WeKnora/pull/1754 の @lyingbug により、GET 互換性を維持しながらハイブリッド検索用の POST (#1727) を追加
  • 修正 (docparser): PaddleOCR-VL HTML テーブルを正規化し、https://github.com/Tencent/WeKnora/pull/1755 の @lyingbug によるトークンの無駄とチャンクの断片化を削減します。

  • 偉業(データソース): https://github.com/Tencent/WeKnora/pull/1757 の @lyingbug により、遅延ロードされたピッカーで既存の選択を明らかにします
  • 修正(組織): https://github.com/Tencent/WeKnora/pull/1761 で @hiasky によって組織を作成した後のフェッチ キャッシュを無効にする

  • feat(mcp): https://github.com/Tencent/WeKnora/pull/1764 の @lyingbug により、MCP サービス ダイアログにカスタム ヘッダー機能を追加
  • 偉業(データソース): https://github.com/Tencent/WeKnora/pull/1769 の @lyingbug によるフルテキスト取り込みを備えた RSS フィード コネクタを追加
