WeKnora v0.1.5

パッチ 公開日2025年10月20日 出典Tencent/WeKnora 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#WeKnora v0.1.5 概要

  • この統合には、バックエンド サービス、フロントエンド インターフェイス、イメージ構築および展開スクリプトなどのモジュールをカバーする、いくつかの機能強化、UI/UX の改善、セキュリティ修正およびバグ修正が含まれます。
  • 主な目標: マルチナレッジ ベースのサポート、テナント/アカウントの強化、初期化プロセスの最適化、フロントエンドのセキュリティとエクスペリエンスの向上、DevOps スクリプトと Docker イメージ ビルドの堅牢性の向上。 ハイライト
  • マルチナレッジベースは、複数のデータソースによる検索の最適化をサポートします (フロントエンドとバックエンドの共同改善)。
  • テナント情報ページと API キー管理機能が強化されました (API キーの生成とコピーの対話を含む)。
  • 初期化ウィザードの構造が最適化され、より完全な検証とマルチモーダル (VLM) 構成検証が追加されました。
  • フロントエンドのセキュリティの改善: XSS を修正し、UI の API キーなどの機密情報を非表示にします。
  • Docker/CI: イメージ ビルド スクリプトとクロスプラットフォーム検出が改善され、ビルド情報の挿入が強化されました (VERSION / COMMIT / BUILD_TIME / GO_VERSION)。 機能と拡張機能
  • マルチナレッジベースの操作サポートと管理 (UI とバックエンド ロジック) を追加しました。
  • テナント情報管理の強化、テナント ページの追加、ストレージ クォータと使用量の表示がより分かりやすくなりました (TenantInfo.vue を参照)。
  • 初期化ウィザードの改善: より厳密なフォーム検証、VLM/OpenAI 互換 URL 検証、マルチモーダル ファイル アップロードのプレビューと検証 (InitializationContent.vue を参照)。
  • バックエンド: API キーの自動生成および更新ロジック (types.Tenant および tenantService.UpdateTenant を参照)。 UI/UX
  • 設定ページと初期化ページのレイアウトを再構築し、ボタンのステータス、読み込みとプロンプト情報を最適化し、アップロード/プレビューのエクスペリエンスを改善します。
  • メニュー コンポーネントの強化: アップロード前の複数のナレッジ ベースの切り替えと検証ロジック (menu.vue を参照)。
  • 機密情報 (API キーなど) を非表示/保護し、コピー操作プロンプトを追加します (TenantInfo.vue を参照)。 セキュリティ修正
  • フロントエンドの潜在的な XSS 脆弱性を修正し、入力検証とコンテンツ セキュリティ ポリシーを強化します。
  • UI は API キーを非表示にし、コピー動作プロンプトを改善して情報漏洩保護を強化します。 バグ修正
  • OCR/AVX サポート関連の問題と画像解析の同時実行エラーを修正しました。
  • フロントエンド ルーティング/ログイン ジャンプの問題とファイル ダウンロード コンテンツ エラーを修正しました。
  • Docker サービスのヘルスチェックとモデルのプリフェッチに関する問題を修正しました。 DevOps/ビルド
  • イメージ ビルド スクリプトを改善し、プラットフォーム/アーキテクチャ検出 (amd64/arm64) を強化し、ビルド中にバージョン情報を挿入します (get_version.sh および build_images.sh を参照)。
  • Makefile とビルド プロセスが改善され、LDFLAGS の CI インジェクションが容易になりました (Makefile を参照)。
  • スクリプトと移行ツール (移行) の使用法とドキュメントが改善されました (移行.sh を参照)。 ドキュメント
  • README および多言語ドキュメント (EN/CN/JA) およびリリース/CHANGELOG を更新しました (詳細については、CHANGELOG.md および README.md を参照)。
  • MCP サーバーの使用手順とインストールを補足しました (mcp-server/INSTALL.md を参照)。 開発者/内部の API の変更 (参照可能)
  • バックエンド システム情報応答構造体: handler.GetSystemInfoResponse を追加/変更しました。
  • JSON ストレージ フィールドを含むテナント データ構造: types.Tenant。
