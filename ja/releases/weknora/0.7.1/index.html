WeKnora v0.7.1

#WeKnora v0.7.1

何が変わったのか

  • 特技(チャット): https://github.com/Tencent/WeKnora/pull/2109 の @lyingbug によるセッション ヘッダー アクションとマークダウン エクスポートを追加
  • 偉業(トレース): https://github.com/Tencent/WeKnora/pull/2099 の @lordk911 により、langfuse client を OTLP/OTel ワイヤ プロトコルに移行
  • 修正(トレース): Langfuse 終了メタデータをマージし、https://github.com/Tencent/WeKnora/pull/2111 の @lyingbug によって自動ルート スパンをエクスポート
  • スタイル(チャット): https://github.com/Tencent/WeKnora/pull/2114 の @lyingbug により、会話コンテンツ領域を 800px から 960px に拡大
  • 修正 (wiki): https://github.com/Tencent/WeKnora/pull/2106 の @014-code による取り込みタイムアウト後の保留中のタスクが古くならないようにする
  • 修正: https://github.com/Tencent/WeKnora/pull/2091 の @KKtwo によるトップ K の取得順序を安定化
  • リファクタリング: https://github.com/Tencent/WeKnora/pull/2130 の @lyingbug による Neo4j ベースの会話メモリ機能を削除
  • feat(web-search): https://github.com/Tencent/WeKnora/pull/2115 の @lyingbug による Zhipu AI Web 検索プロバイダーのサポートを追加
  • feat(セッション): 管理者 API セッション バケットを追加し、https://github.com/Tencent/WeKnora/pull/2151 の @lyingbug によってサイドバー フィルターを安定させます。
  • 修正（フロントエンド）: https://github.com/Tencent/WeKnora/pull/2153 の @lyingbug による古いホストの互換性のために、ダイジェストによって nginx ベースイメージをピン留め
  • 修正(api-keys): https://github.com/Tencent/WeKnora/pull/2154 の @lyingbug によるスコープ指定されたファイルの提供とバッチ ルートの取り込みを許可します
  • 修正 (フロントエンド): @jacentsao による完全な TDesign スタイルを https://github.com/Tencent/WeKnora/pull/2148 にロード
  • 功績: https://github.com/Tencent/WeKnora/pull/2147 の @KKtwo による Volcengine のリランクをサポート
  • 修正(再ランク): https://github.com/Tencent/WeKnora/pull/2155 の @lyingbug による、API ドキュメント制限を超えるバッチ Volcengine 再ランク リクエスト
  • feat(セッション): https://github.com/Tencent/WeKnora/pull/2156 の @lyingbug により、管理者の背後で IM/embed/API チャネル セッションをゲートします
  • 修正 (埋め込み): crypto.randomUUID の浏览器および http请要求モードをサポートしません (https://github.com/Tencent/WeKnora/pull/2159 の @hbh112233abc による)
  • 修正（タイプ）: https://github.com/Tencent/WeKnora/pull/2157 の @steptian による Message.KnowledgeReferences で正しい GORM タグ区切り文字を使用する
  • 修正(再ランク): https://github.com/Tencent/WeKnora/pull/2160 の @draix によってデフォルトで vLLM truncate_prompt_tokens の送信を停止
  • feat(im): https://github.com/Tencent/WeKnora/pull/2149 に @jacentsao による Yunzhijia 統合を追加
  • feat(compose): 環境変数をコードと調整 + https://github.com/Tencent/WeKnora/pull/2164 の @Greenplumwine による Helm GraphRAG バグを修正
  • fix(compose): PDF レンダリングの並列処理を、https://github.com/Tencent/WeKnora/pull/2168 の @lyingbug による CPU 対応コードのデフォルトに従うようにしました
  • 修正 (feishu): 回復力のある大規模 Wiki 同期 — https://github.com/Tencent/WeKnora/pull/2166 の @voidkey による再試行、ストリーミング再開、障害の可視性
  • feat(api-keys): https://github.com/Tencent/WeKnora/pull/2165 の @lyingbug による、コントロール プレーン自動化のためのプラットフォーム スコープの API キーを追加
  • 修正（知識）: https://github.com/Tencent/WeKnora/pull/2169 の @lyingbug による KB クローン同期用のマルチセット AminusB
  • 修正 (フロントエンド): https://github.com/Tencent/WeKnora/pull/2172 の @lyingbug により、運用ビルドでカスタム テーマ トークンを保持する
  • feat(im): https://github.com/Tencent/WeKnora/pull/2180 で @jacentsao による Yunzhijia の返信をマークダウンとしてレンダリング
  • 修正（知識）: https://github.com/Tencent/WeKnora/pull/2183 の @lyingbug によるクローン上のチャンク コンテンツ画像 URL を書き換える
  • 修正（知識）: https://github.com/Tencent/WeKnora/pull/2188 の @lyingbug によるグローバル パスを介して親テキスト チャンク画像 URL を書き換える
  • 修正: https://github.com/Tencent/WeKnora/pull/2182 の @wangkeee2002 による修复IM问応答無法读取セッションの问题
  • 修正(cli): https://github.com/Tencent/WeKnora/pull/2178 の @yuefanxiao による現在の CLI 契約に対する修理受付 e2e
  • 修正（知識）: https://github.com/Tencent/WeKnora/pull/2191 の @lyingbug により、埋め込まれたチャンク画像をエクスポート名前空間にコピー
  • 修正 (チャット): https://github.com/Tencent/WeKnora/pull/2193 の @lyingbug により、エージェント タイムラインにインラインでモデル推論を表示
  • 修正: https://github.com/Tencent/WeKnora/pull/2171 の @lyingbug により、API キーの有効期限タイムスタンプを UTC (#2137) に正規化
  • 修正 (知識): https://github.com/Tencent/WeKnora/pull/2195 の @lyingbug により、非同期削除で表示/ゾンビ行が残らないようにする (#2192)
  • 修正: https://github.com/Tencent/WeKnora/pull/2190 の @ttommybot による正しいグラフとマルチモーダル処理トレース
  • 偉業(wiki): https://github.com/Tencent/WeKnora/pull/2196 の @lyingbug によるドキュメントの撤回後に空のフォルダーを整理する
  • 修正(開発): nc 兼容BSD netcat by @hbh112233abc in https://github.com/Tencent/WeKnora/pull/2205
  • 修复跨工作空间共享知识库原始文档预览失败 by @chang30519-art in https://github.com/Tencent/WeKnora/pull/2200
  • 修正 (wiki): https://github.com/Tencent/WeKnora/pull/2209 の @wolfkill による SQLite での孤立カウントをサポート
  • 偉業(知識): https://github.com/Tencent/WeKnora/pull/2198 の @lyingbug によるスコープ付きアクティビティ監査証跡を追加
  • 修正 (埋め込み): https://github.com/Tencent/WeKnora/pull/2201 の @March-77 による SSRF 安全な HTTP トランスポートを再利用
  • リファクタリング (http): https://github.com/Tencent/WeKnora/pull/2213 の @lyingbug により、モデル clients 全体で SSRF 安全なトランスポートを共有します
  • 修正: https://github.com/Tencent/WeKnora/pull/2212 で @ttommybot によるレビュー後に保留中の参加リクエスト数を更新
  • 修正(検索): https://github.com/Tencent/WeKnora/pull/2203 の @March-77 によるハイブリッド検索クエリ テキストを検証します。
  • 修正(タスク): https://github.com/Tencent/WeKnora/pull/2202 の @March-77 による削除されたナレッジ ベースのデキュー作業
  • 修正(タスク): https://github.com/Tencent/WeKnora/pull/2215 の @lyingbug によるリクエスト ctx からの KB 削除キューのクリーンアップの切り離し
  • feat(im): https://github.com/Tencent/WeKnora/pull/2214 で @jacentsao による Yunzhijia WebSocket イメージ メッセージをサポート
  • 修正 (IM): https://github.com/Tencent/WeKnora/pull/2216 の @lyingbug による #2214 以降の Yunzhijia 画像ダウンロードを強化
  • fix(task-inspector): https://github.com/Tencent/WeKnora/pull/2218 の @LHYintheCode による遅延キューが見つからないエラーを処理
  • fix(mcp): https://github.com/Tencent/WeKnora/pull/2227 の @lyingbug による OAuth トークンの更新と認可ポーリングを調整します
  • 修正: https://github.com/Tencent/WeKnora/pull/2225 の @ttommybot によって API キーに所有者の役割が割り当てられないようにする
  • ドキュメント: https://github.com/Tencent/WeKnora/pull/2224 の @ttommybot によるワークスペース所有者のカーディナリティーの明確化
  • 偉業(ランタイム): https://github.com/Tencent/WeKnora/pull/2233 の @lyingbug によるアーカイブされたキュー タスクと chat_attachment i18n を一括パージ
  • feat(llm): https://github.com/Tencent/WeKnora/pull/2236 の @lyingbug によるプロンプト キャッシュの可観測性と Wiki キャッシュに適したプロンプトを追加
  • 特技(チャット): https://github.com/Tencent/WeKnora/pull/2239 の @lyingbug により、Wiki ツールの結果を参照ドロワーに表示します
  • 修正(モデル): https://github.com/Tencent/WeKnora/pull/2240 の @lyingbug により、モデル デバッグのアップロード制限をグローバル MAX_FILE_SIZE に合わせます
  • 機能 (フロントエンド): https://github.com/Tencent/WeKnora/pull/2245 の @lyingbug による共有スペース設定を磨き、プレビュー UI に参加
  • 偉業 (フロントエンド): https://github.com/Tencent/WeKnora/pull/2249 の @lyingbug による組織スペース UI と共有スペース パネルを洗練しました。
  • 修正（知識）: https://github.com/Tencent/WeKnora/pull/2250 の @lyingbug によりソース ファイルのダウンロードをエディター以上に制限
  • 修正: https://github.com/Tencent/WeKnora/pull/2268 で @ttommybot による書き込み後に組織の状態を同期する
  • 修正（フロントエンド）: https://github.com/Tencent/WeKnora/pull/2269 の @lyingbug によるレビューと詳細ロード後の楽観的な組織状態を修正
  • 修正 (エージェント): https://github.com/Tencent/WeKnora/pull/2253 の @jack-wang-176 による提案された質問の制限パラメーターを尊重します
  • 修正: https://github.com/Tencent/WeKnora/pull/2271 の @lyingbug による組織設定ポップアップでの TDesign テキストエリアの自動サイズ クラッシュを防止
  • 修正 (組織): 共有スペースの用語の曖昧さを解消し、https://github.com/Tencent/WeKnora/pull/2273 の @lyingbug による招待検索を強化
  • 修正（ドリス）: https://github.com/Tencent/WeKnora/pull/2276 の @lyingbug による SSRF セーフ client でストリーム ロード HTTP を強化
  • 修正 (wiki): https://github.com/Tencent/WeKnora/pull/2280 の @lyingbug により、取り込みパスとエージェント書き込みパスにわたるスラッグの整合性を強化
  • 雑用(リリース): https://github.com/Tencent/WeKnora/pull/2286の@lyingbugによるv0.7.1の準備
