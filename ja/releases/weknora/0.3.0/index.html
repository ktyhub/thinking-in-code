WeKnora v0.3.0

マイナー 公開日2026年2月9日 出典Tencent/WeKnora 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#WeKnora v0.3.0

何が変わったのか

  • 修正: https://github.com/Tencent/WeKnora/pull/607 の @manx98 による SSE トランスポート タイプで接続が失われた後、MCP Client 接続状態がクローズとしてマークされない
  • session.md を更新 | 会議停止 by @dragon8git (https://github.com/Tencent/WeKnora/pull/604)
  • feat(web_fetch): DNS ピンニングと検証により Web フェッチ ツールを強化します… by @lyingbug (https://github.com/Tencent/WeKnora/pull/611)
  • リファクタリング: https://github.com/Tencent/WeKnora/pull/614 の @begoniezhao による正しいチャンクのマージのためのルーン処理のリファクタリング
  • 功績: https://github.com/Tencent/WeKnora/pull/615 の @chengjoey による Bing 検索プロバイダーの追加
  • 修正: https://github.com/Tencent/WeKnora/pull/617 の @ChenRussell によるナレッジ ベースに再入力するときにタグの選択状態をクリア
  • 特技: https://github.com/Tencent/WeKnora/pull/623 で @begoniezhao による切り捨てを埋め込むには、truncate の代わりに num_ctx を使用します。
  • 功績: https://github.com/Tencent/WeKnora/pull/625 の @begoniezhao による env 経由で構成可能なグローバル ログ レベルを追加
  • ドキュメント: https://github.com/Tencent/WeKnora/pull/627 の @MEKXH により、Air インストール コマンドを cosmtrek/air から air-verse/air に更新します。
  • 修正(チャット): https://github.com/Tencent/WeKnora/pull/628 の @MEKXH が出力したモデルから思考内容を削除
  • 偉業(redis): https://github.com/Tencent/WeKnora/pull/626 の @Dounx による Redis ACL の REDIS_USERNAME サポートを追加
  • https://github.com/Tencent/WeKnora/pull/621 の @voidkey による特技/エージェント スキル
  • 偉業(redis): https://github.com/Tencent/WeKnora/pull/630 の @lyingbug による Redis ACL 設定用の REDIS_USERNAME 環境変数を追加
  • 功績: エージェント スキルのサンドボックス構成と可用性を強化 (https://github.com/Tencent/WeKnora/pull/631 の @lyingbug による)
  • 功績: Docker でサンドボックス サービス構成を更新 https://github.com/Tencent/WeKnora/pull/632 で @lyingbug によってファイルを作成
  • ドキュメント: https://github.com/Tencent/WeKnora/pull/633 内の @liweijie0812 による api リンクを修正
  • https://github.com/Tencent/WeKnora/pull/634 の @CodeMarker0 によるセット比較の Jaccard 関数を最適化
  • 雑用: https://github.com/Tencent/WeKnora/pull/660 の @ChenRussell による ChunkExtracter のタイプミス (ChunkExtractor) を修正
  • 修正: https://github.com/Tencent/WeKnora/pull/663 の @voidkey による以前のコミットでのタイプミス
  • 修正: https://github.com/Tencent/WeKnora/pull/662 の @hobostay によるメインおよび回復ミドルウェアの標準ログを構造化ロガーに置き換えました。
  • 機能: https://github.com/Tencent/WeKnora/pull/665 の @lyingbug によるセキュリティのための MCP ツール名と説明の処理を強化
  • 特技(フロントエンド): https://github.com/Tencent/WeKnora/pull/666 の @Dounx による構成可能なバックエンド ホストとポートを許可します。
  • 功績: https://github.com/Tencent/WeKnora/pull/667 の @Dounx による asyncq client の REDIS_USERNAME サポートを追加
  • https://github.com/Tencent/WeKnora/pull/661 の @lyingbug による共有スペースと KB/エージェントの共有

新しい貢献者

  • @manx98 が https://github.com/Tencent/WeKnora/pull/607 に初めて投稿しました
  • @dragon8git が https://github.com/Tencent/WeKnora/pull/604 で最初の貢献をしました
