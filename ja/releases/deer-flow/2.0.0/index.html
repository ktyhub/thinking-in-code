鹿流 v2.0.0

#ディアフロー2.0.0

DeerFlow 2.0 は、「スーパー エージェント」ハーネスを中心とした 根本的な書き直しです。 サブエージェント、永続メモリ、サンドボックス実行、を調整します。 そして拡張可能なスキル/ツール システム。 1.x ラインとコードを共有していません。 main-1.x ブランチ に存在します。

このリリースで 2.0.0 マイルストーン は終了します 最初の 2.0 マイルストーン タグ以来、182 のマージされた PR が含まれています。

📖 全メモ: CHANGELOG.md · 中文版

⚠️重大な変更

  • ハイドレーションを実行 — RunStore からハイドレーションを実行し、interrupted を継続します。 ステータス。キャンセルには実行を所有するワーカーが必要になりました。クロスワーカー キャンセルすると、成功したように表示されるのではなく、409 が返されます。 ([#2932])

✨ ハイライト

  • 自身を更新するカスタム エージェント - エージェントは編集内容を保持できます。 通常のチャットからの独自の SOUL.md / config.yaml (ユーザーごとの完全なチャット) 孤立。 ([#2713])
  • ユーザー所有の IM チャネル接続 — ユーザーは独自の Slack をバインドできます。 Telegram、Discord、Feishu/Lark、DingTalk、WeChat、および WeCom アカウントを上位に追加 オペレーターが設定したボットの数。 ([#3487])
  • その他のモデルとコミュニティ検索 — StepFun および MiMo 推論モデル、 画像/ビデオ/ポッドキャスト スキルと新しい音楽生成スキルのための MiniMax、 Brave Search / SearXNG / Browserless / Serper Google 画像ツール。 ([#3461]、[#3298]、[#3437]、[#3528]、[#3451]、[#3575])
  • 豊富なチャンネル — Discord はメンションオンリー モード、スレッド ルーティング、 タイピングインジケーター。 Telegram はプレースホルダーを編集して返信をストリームします メッセージをその場で。 ([#2842]、[#3534])
  • 設定可能なループ検出、ツールごとの周波数オーバーライドと 遅延警告インジェクション。 ([#2586]、[#2711]、[#2752])
  • サブエージェント トークンの使用量は、スパンを使用してリアルタイムでヘッダーにストリーミングされます 親スレッドの Langfuse トレースに起因します。 ([#2882]、[#3611])
  • トレースの洗練 — クリーンな lead_agent / カスタム エージェント トレース名。 session_id
    • user_id が Langfuse に伝播されました。非 ASCII メモリ トレースはエスケープされなくなりました。 ([#3101]、[#2944]、[#3104])
  • デフォルトでトークン使用量の追跡が有効、表示モードと使用法が洗練されています 実際のモデルに起因します。 ([#2841]、[#2329]、[#3658])
  • 柔軟なメモリと提案 — 制限付きの tiktoken をオプトアウトします memory.token_counting 経由のネットワーク。 AI によるフォローアップの提案をオプションにします。 ([#3465]、[#3591])

🚀 パフォーマンス

  • スレッドのメタデータ フィルターを SQL にプッシュします。 ([#2865])
  • インデックスは RunManager の thread_id によって実行され、O(n) スキャンが排除されます。 ([#3499])
  • MemoryRunEventStore のメッセージにインデックスを付けて、O(n) スキャンを排除します。 ([#3531])
  • クラスごとに Base.to_dict 列のリフレクションをキャッシュします。 ([#3654])
  • glob/grep サンドボックス ウォークでの should_ignore_name を高速化します。 ([#3657])

🔒 セキュリティ

  • Linux および Windows でシンボリックリンクされたアップロード先を拒否します。 ([#2623]、[#2794])
  • MCP 設定応答内の機密値をマスクします。エンドポイントを強化します。 ([#2667]、[#3425])
  • クロスサイト認証 POST を拒否します。 ([#2740])
  • キャップスキルアーティファクトプレビュー解凍（ジップボム防御）。 ([#2963])
  • ホスト Docker ソケットは、aio (DooD) サンドボックス モードでのみマウントします。 ([#3517])
  • デフォルトではホスト CLI 認証ディレクトリをバインドマウントしません。 ([#3521])

🐛 注目すべき修正

  • メモリは、短期間のイベント ループではなく永続的なイベント ループで実行されます。 asyncio.run();キューに入れられた更新はエージェントごとに分離されます。ラップされた JSON 応答 正しく解析されました。 ([#2627]、[#2941]、[#3252])
  • ゲートウェイの再起動後に永続ストアからハイドレートを実行し、戻ります ISO 8601 タイムスタンプと冪等キャンセル機能を備えています。 ([#2989]、[#2599]、[#3058])
  • サブエージェント は親実行のチェックポイント作成者から分離されます。タイムアウト端子 状態アトミック。ツール/ミドルウェアのモデル オーバーライドを尊重します。 ([#3559]、 [#2583]、[#2641])
  • サンドボックス 準備ポーリングはイベント ループをブロックしなくなりました。 /mnt/user-data 契約は API 境界で施行されます。 PVC データのスコープ ユーザー。 Windows/Git Bash MSYS パス変換が無効になっています。 ([#2822]、[#2881]、 [#2973]、[#2766])
  • Auth 自動生成された JWT シークレットは再起動後も保持されます。セットアップステータス 429 の代わりにキャッシュされた応答を使用します。 ([#2933]、[#2915])
  • フロントエンドは、飲み込まれた最初のメッセージ、ログインのちらつき/サイズ変更オブザーバーを修正します。 ループ、楽観的なメッセージの重複、深くネストされたリストのレンダリングのクラッシュ、 新しいチャットでのスレッドの分離。 ([#2731]、[#2954]、[#3002]、[#3393]、[#3570]、 [#3508])
  • チャネル - ユーザー所有の IM には、バインドされた ID、スコープ ファイル、および 所有者にヘルパー コマンドを送信し、プロバイダーの状態を権限のあるものにし、 接続フローは決定的であり、共有再試行ヘルパーと 運用可能なガードレール。 ([#3578]、[#3579]、[#3580]、[#3581]、[#3582]、 [#3583]、[#3584])
  • ストリーミングと履歴 - 割り込みは、SSE 値イベントを通じて伝播します。 LangGraph SDK、および Base64 画像ペイロードはストリーミングおよび UI の応答性を維持するための履歴応答。 ([#3605]、[#3631]、[#3535])
  • フロントエンド (詳細) — ワークスペースのチャット リストが 50 スレッドを超えるとページ分割されます。 SSR 認証プローブがゲートウェイに到達できない場合でも対話型を維持し、 モバイルフレンドリーなレイアウト。 ([#3485]、[#3495]、[#3646])

📦 導入と運用

  • Docker ゲートウェイのデフォルトは単一ワーカーです (マルチワーカーの破損)。 ([#3475])
  • Docker nginx はリクエスト時にアップストリーム名を解決します。 ([#2717])
  • パッケージングでは、ストア/チェックポインター サポート用に postgres が追加されます。 ([#2584])
  • スクリプト は、make dev の再起動後も uv の追加機能を保持します。地元を掃除する nginx が停止中。ゲートウェイのリロードからランタイム状態を除外します。 ([#2767]、[#3005]、 [#3426])
