spring-boot v4.1.0

マイナー 公開日2026年6月10日 出典spring-projects/spring-boot 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

スプリングブーツ v4.1.0

完全な Spring Boot 4.1 の release note は wiki で入手できます。

:star: 新機能

  • 原因を受け入れるパブリック コンストラクターを InvalidConfigurationPropertyValueException に追加 #50211
  • WritableJson.toByteArray #49428 を繰り返し呼び出すときのメモリ消費量を削減します。

:lady_beetle: バグ修正

  • MailSender の自動構成ではホスト名検証が有効になりません #50747
  • Artemis 自動構成は、組み込みブローカーのデータに予測可能なデフォルトの場所を使用します #50745
  • バンドルが空の場合、組み込み LDAP SSL を有効にしないでください #50700
  • InetAddressFilter.externalAddresses は、RFC 6890 #50668 から特殊目的のアドレスを除外しません。 -actor-netty SniProvider および RSocket のマップされていない SSL バンドルでの NullPointerException #50645
  • SSL バンドルが空の文字列にオーバーライドされる場合、SSL を有効にしないでください #50635
  • テスト自動構成は Spring Security を HtmlUnitDriver と統合しなくなりました #50633
  • 構成プロパティのメタデータに不正なクラス参照が含まれている #50632
  • Docker Compose サポートは、InterruptedException をキャッチしたときにスレッド割り込みフラグを復元しません #50618
  • spring.rabbitmq.ssl.bundle が空の文字列にオーバーライドされる場合でも、RabbitProperties は SSL を有効にします #50612
  • SSL バンドルがサーバー名バンドルなしで client-auth またはサーバー truststore を使用する場合、reactor-netty SniProvider で NullPointerException が発生する #50610
  • SpringJtaPlatform は 4.1.0-M3 #50592 以降非推奨になっているはずです
  • ルート ディレクトリで抽出レイヤーを使用すると、「//」の出力場所の外に書き込まれたレイヤーで例外がスローされる #50510
  • ConfigurationPropertiesReportEndpoint は AOP プロキシ内部を公開します #50417
  • 作成された StackTracePrinter インスタンスは環境にアクセスできません #50414
  • MappingsEndpoint は、親が存在する場合、コンテキスト自身の ID をparentId として報告します #50412
  • Buildpack モジュールは、long から int へのキャストを検証しません #50410
  • protobuf-java-util の代わりに protobuf-java 依存関係が使用されている場合、Gradle gRPC サポートが失敗する #50405
  • GraphQL WebSocket サポートでは、許可されたオリジンが構成されません #50394
  • Spring Boot ローダーは RSA および EC 署名付き jar #50298 をサポートしていません
  • コンテキストが閉じられたときにメーター レジストリがグローバル レジストリから削除されない #50287
  • DataSourceBuilder は遅延接続プロキシから DataSource を派生できません #50271
  • AbstractErrorController.getErrorAttributes からの Null 許容アノテーションが実装と一致していません #50266
  • setAllowBeanDefinitionOverriding が呼び出される前に、初期化子を使用して Bean 定義を追加できる #50264
  • EndpointRequest リンク マッチャーが GET 以外の HTTP メソッドと不必要に一致する #50261
  • corsConfigurationSource #50258 という名前の Bean を使用して制限的な CORS 構成が提供されている場合、アクチュエーターの「/cloudfoundryapplication」エンドポイントが機能しません
  • ThreadPoolTaskScheduleBuilder は、終了待機時間を構成するときに不必要に精度を失います #50234
  • NimbusJwtDecoder は spring.security.oauth2.resourceserver.jwt.jws-algorithms の不明な値をサイレントに受け入れます #50228
  • spring-boot-web-server-test の依存関係管理が欠落している #50224
  • MongoDB モジュールの Spring Batch サポートは依存関係管理に含まれていません #50223
  • ホワイトラベル エラー ページのタイムスタンプ属性に HTML escaping を適用 #50216
  • GrpcServerHealthScheduler がサーブレット環境で起動しない #50209
  • Tomcat を使用する場合、server.servlet.session.cookie.partitioned=true の設定は効果がありません #50204

:notebook_with_decorative_cover: ドキュメント

  • モジュール交換に関する Gradle ドキュメントへの参照を修正 #50647
  • Let's Encrypt による SSL リロードのドキュメント #50630
  • Data Neo4j リポジトリの例からオプションの使用を削除 #50622
  • ドキュメントのタイプミスを修正 #50620
  • Bean Validation サポートの依存関係要件を明確化 #50614
  • AOT キャッシュの Java 25 要件を文書化 #50485
  • Java CAS Client Spring Boot Starter #50285 へのリンクを追加
  • 既知のテストコンテナのライフサイクルの問題を文書化 #50220
  • Jetty 用の複数のコネクタを追加するドキュメント #50218
  • ポーランド語の InvalidConfigurationPropertyValueException コンストラクター javadoc #50214
  • Spring Security OAuth2 client 登録ドキュメントのタイプミスを修正 #50199
