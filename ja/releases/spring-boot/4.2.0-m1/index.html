spring-boot v4.2.0-M1

プレリリース 公開日2026年8月20日 出典spring-projects/spring-boot 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

スプリングブーツ v4.2.0-M1

:star: 新機能

  • Jetty サーバーの転送ヘッダー構成を調整 #51148
  • テストで Micrometer グローバル レジストリをデフォルトで無効にする #51142
  • Jetty #51128 の正常なシャットダウンを調整するには、StatisticsHandler ではなく GracefulHandler を使用します。
  • RestTemplate サポートの廃止 #51118
  • Reactor Netty の変更に適応するように転送されたヘッダーのプロパティを更新 #51031
  • Spring Framework の変更に適応するように転送ヘッダーのプロパティを更新 #51030
  • 4.2 #50955 で削除が推奨されなかった API を削除
  • イメージベースのビルド キャッシュのサポートを追加 #50899
  • Hibernate-maven-plugin のプラグイン管理を提供する #50892
  • RetryPolicySettings でタイムアウト オプションをサポート #50891
  • ApplicationContextAssertProvider に自己参照を追加 #50500
  • Kafka Streams に LeaveGroupOnClose の構成プロパティを追加 #50432
  • ApplicationHome および ApplicationTemp でパス ゲッターを公開する #50194
  • RabbitMQ AMQP 1.0 client サポート #49857 の導入
  • 汎用 AMQP 1.0 client サポートを導入 #49678
  • spring-boot-amqp の名前を spring-boot-rabbitmq に変更 #49677
  • AMQP 1.0 #49619 のサポートを追加
  • TestRestTemplate を廃止し、RestTestClient #46632 を採用
  • spring-boot.run.useTestClasspath が有効な場合、ターゲット/テストクラスを考慮する #36115

:lady_beetle: バグ修正

  • 構造化ログ: JSON エンコードが失敗すると、同じスレッドに書き込まれる次のログ イベントが破損します #51371
  • Kafka コンシューマ固有のセキュリティ プロトコルは考慮されません #51370
  • gRPC が存在しない場合、gRPC テスト サーバー ポートの公開はバックオフする必要があります #51291
  • マイクロメーター レジストリはアプリケーション コンテキストを固定します #51136
  • ExportedImageTar の構築が失敗しても一時ファイルが削除されない #51133
  • spring.grpc.server.health.include-overall-health は考慮されません #51106
  • メタデータ アノテーション プロセッサは、レコードのゲッター レベル @NestedConfigurationProperty を無視します #51099
  • spring-boot-h2-console は、servlet-api を推移的な依存関係としてプルします #51096
  • PropertiesLauncher がネストされたアーカイブ パスをログに記録しない #51090
  • Map#remove の結果を返すメソッドが @Nullable 戻り型で宣言されていません #51088
  • NativeImageResourceProvider はサブディレクトリ内の Flyway 移行パスを平坦化します #50965
  • Kotlinx シリアル化 CodecCustomizer の順序を修正 #50962
  • アーカイブからメインクラスを検索するときに JarFile が閉じられない #50960

:notebook_with_decorative_cover: ドキュメント

  • spring.graphql.websocket.connection-init-timeout の説明がリファレンス ガイドで正しく表示されない #51364
  • spring.profiles.group には「spring-profile-name」ヒントプロバイダーが必要です #51285
  • 削除された InfluxDB 自動構成への参照を削除 #51177
  • Kafka Streams ドキュメントで JacksonJsonSerde を使用する #51162
  • HttpMessageConverters の代替案を文書化 #51130
  • OTLP ロギング トランスポート メタデータの古いタイプ参照を修正 #51126
  • spring.test.mockmvc.htmlunit.url のメタデータが間違った型を宣言しています #51116
  • キャッシュに関するドキュメントでは、4.0 以前のパッケージ #51114 による AutoConfigureCache を参照しています。
  • メタデータ形式ドキュメントの章の例を修正 #51103
  • AOT キャッシュのハウツー ガイドの発見性を向上 #51001
