spring-boot v4.0.7

パッチ 公開日2026年6月10日 出典spring-projects/spring-boot 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

スプリングブーツ v4.0.7

:lady_beetle: バグ修正

  • MailSender の自動構成ではホスト名検証が有効になりません #50746
  • Artemis 自動構成は、組み込みブローカーのデータに予測可能なデフォルトの場所を使用します #50744 -actor-netty SniProvider および RSocket のマップされていない SSL バンドルでの NullPointerException #50640
  • SSL バンドルが空の文字列にオーバーライドされる場合、SSL を有効にしないでください #50634
  • Docker Compose サポートは、InterruptedException をキャッチしたときにスレッド割り込みフラグを復元しません #50617
  • RabbitProperties は、spring.rabbitmq.ssl.bundle が空の文字列にオーバーライドされる場合でも SSL を有効にします #50611
  • SSL バンドルがサーバー名バンドルなしで client-auth またはサーバー truststore を使用する場合、reactor-netty SniProvider で NullPointerException #50609
  • テスト自動構成は Spring Security を HtmlUnitDriver と統合しなくなりました #50602
  • ルート ディレクトリで抽出レイヤーを使用すると、「//」の出力場所の外に書き込まれたレイヤー例外がスローされる #50509
  • ConfigurationPropertiesReportEndpoint は AOP プロキシ内部を公開します #50416
  • 作成された StackTracePrinter インスタンスは環境にアクセスできません #50413
  • MappingsEndpoint は、親が存在する場合、コンテキスト自身の ID をparentId として報告します #50411
  • Buildpack モジュールは、long から int へのキャストを検証しません #50409
  • GraphQL WebSocket サポートでは、許可されたオリジンが構成されません #50393
  • 構成プロパティのメタデータに不正なクラス参照が含まれている #50375
  • Spring Boot ローダーは RSA および EC 署名付き jar #50297 をサポートしていません
  • コンテキストが閉じられたときにメーター レジストリがグローバル レジストリから削除されない #50286
  • AbstractErrorController.getErrorAttributes からの Null 許容アノテーションが実装と一致していません #50265
  • EndpointRequest リンク マッチャーが GET 以外の HTTP メソッドと不必要に一致する #50260
  • corsConfigurationSource #50257 という名前の Bean を使用して制限的な CORS 構成が提供されている場合、アクチュエーターの「/cloudfoundryapplication」エンドポイントが機能しない
  • ThreadPoolTaskScheduleBuilder は、終了待機時間を構成するときに不必要に精度を失います #50233
  • NimbusJwtDecoder は spring.security.oauth2.resourceserver.jwt.jws-algorithms の不明な値をサイレントに受け入れます #50227
  • ホワイトラベル エラー ページのタイムスタンプ属性に HTML escaping を適用 #50215
  • Tomcat を使用する場合、server.servlet.session.cookie.partitioned=true の設定は効果がありません #50201

:notebook_with_decorative_cover: ドキュメント

  • モジュール交換に関する Gradle ドキュメントへの参照を修正 #50646
  • Let's Encrypt を使用した SSL リロードのドキュメント #50629
  • Data Neo4j リポジトリの例からオプションの使用を削除 #50621
  • ドキュメントのタイプミスを修正 #50619
  • Bean Validation サポートの依存関係要件を明確にする #50613
  • AOT キャッシュの Java 25 要件を文書化 #50484
  • Java CAS Client Spring Boot Starter #50281 へのリンクを追加
  • 既知のテストコンテナのライフサイクルの問題を文書化 #50219
  • Jetty 用の複数のコネクタを追加するドキュメント #50217
  • ポーランド語の InvalidConfigurationPropertyValueException コンストラクター javadoc #50213
  • Spring Security OAuth2 client 登録ドキュメントのタイプミスを修正 #50198
