spring-boot v4.1.1

パッチ 公開日2026年8月20日 出典spring-projects/spring-boot 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

スプリングブーツ v4.1.1

:警告: 注意が必要です

  • Spring Boot の Gradle プラグインは、Protobuf プラグインが適用されるときに gRPC を自動的に構成しなくなりました。この動作により、gRPC を使用せずに Protobuf を使用している場合に問題が発生しました。 gRPC の構成をオプトインするには、空のブロックを使用して grpc プラグインで protobuf 拡張機能を構成します。 Spring Boot Gradle プラグインは、以前と同様に protoc-gen-grpc-java の使用を自動的に構成します。 #50822

:lady_beetle: バグ修正

  • Kafka コンシューマ固有のセキュリティ プロトコルは考慮されません #51369
  • 構造化ログ: JSON エンコードが失敗すると、同じスレッドに書き込まれる次のログ イベントが破損します #51156
  • マイクロメーター レジストリはアプリケーション コンテキストを固定します #51135
  • ExportedImageTar の構築が失敗しても一時ファイルが削除されない #51132
  • メタデータ アノテーション プロセッサは、レコードのゲッター レベル @NestedConfigurationProperty を無視します #51098
  • spring-boot-h2-console は、servlet-api を推移的な依存関係としてプルします #51095
  • PropertiesLauncher がネストされたアーカイブ パスをログに記録しない #51089
  • Map#remove の結果を返すメソッドが @Nullable 戻り型で宣言されていません #51087
  • NativeImageResourceProvider はサブディレクトリ内の Flyway 移行パスを平坦化します #50964
  • Kotlinx シリアル化 CodecCustomizer の順序を修正 #50961
  • アーカイブからメインクラスを検索するときに JarFile が閉じられない #50959
  • アプリケーション管理の JUL ブリッジ ハンドラーは、インストールされている場合にのみ削除する必要があります #50950
  • CloudFoundry のリアクティブ自動構成では、WebClient.Builder Bean を定義する必要はありません #50944
  • spring-boot-health なしで Actuator を使用すると、リアクティブ Cloud Foundry でコンテキストの更新が失敗する #50942
  • ビルダーにまだ存在しないイメージを解決するときにリソースがクリーンアップされない #50941
  • GraphQlWebMvcAutoConfiguration はカスタマイザーを順番に適用する必要があります #50914
  • spring.threads.virtual.enabled が true の場合、自動構成された RedisMessageListenerContainer は仮想スレッドを使用しません #50884
  • spring-boot-health を使用せずにジャージ上でアクチュエータを使用すると、コンテキストの更新が失敗する #50872
  • Spring-boot-health なしで Actuator を使用すると、Cloud Foundry でコンテキストの更新が失敗する #50871
  • 値の型がワイルドカードであるマップを含む @Validated クラスにプロパティをバインドするときに IllegalStateException が発生する #50856
  • Mongo ヘルス インジケーター #50852 による接続数の増加
  • spring.security.oauth2.resourceserver.jwt issuer-uri と jwk-set-uri の空の文字列値の処理に一貫性がない #50849
  • ApplicationContextAssert の getBean メソッドの戻り値の型が null である可能性は、Bean が null である可能性を示しません #50845
  • PropertiesWebClientHttpServiceGroupConfigurer の優先順位が最も高く、他のコンフィギュラーが優先されることを防ぎます #50843
  • gRPC が存在しない場合、gRPC テスト サーバー ポートの公開はバックオフする必要があります #50825
  • JpaBaseConfiguration#entityManagerConfiguration は、AsyncTaskExecutor #50801 を宣言する Bean で依存関係ループを引き起こす可能性があります
  • spring.grpc.server.health.include-overall-health は考慮されません #50799
  • 「server.servlet.session.cookie.partitioned」を false に設定しても、「Partitioned」Cookie 属性が出力されます #50790
  • Prometheus Client の管理対象バージョンが Micrometer の micrometer-registry-prometheus #50780 と一致していません
  • 空の文字列からバインドされたマップ プロパティが ConverterNotFoundException で失敗する #50773
  • Protobuf Common Protos は管理依存関係であってはなりません #50772
  • Reactor がクラスパス上にあるが WebFlux が存在しない場合、spring-boot-security-oauth2-resource-server に依存するアプリケーションは ClassNotFoundException で起動に失敗する場合がある #50764
  • W3CHeaderParser のデコードは RFC 3986 #50650 に準拠していません

:notebook_with_decorative_cover: ドキュメント

  • spring.graphql.websocket.connection-init-timeout の説明がリファレンス ガイドで正しく表示されない #51348
  • spring.profiles.group には「spring-profile-name」ヒントプロバイダーが必要です #51284
  • 削除された InfluxDB 自動構成への参照を削除 #51176
  • Kafka Streams ドキュメントで JacksonJsonSerde を使用する #51161
  • HttpMessageConverters の代替案を文書化 #51129
  • OTLP ロギング トランスポート メタデータの古いタイプ参照を修正 #51119
  • spring.test.mockmvc.htmlunit.url のメタデータが間違った型を宣言しています #51115
  • キャッシュに関するドキュメントでは、4.0 以前のパッケージ #51113 による AutoConfigureCache を参照しています。
  • メタデータ形式ドキュメントの章の例を修正 #51102
  • AOT キャッシュのハウツー ガイドの発見性を向上 #51000
  • 自動構成された HealthIndicators の表に、MongoHealthIndicator #50940 の間違ったキーがリストされています
  • OpenTelemetryResourceAttributes ドキュメントを更新 #50874
  • 外部設定ドキュメントの @Value プレースホルダー構文を修正 #50873
  • ポーランド語 gRPC ドキュメント #50863
  • ドキュメント内の重複した単語のタイプミスを修正 #50850
  • クラウド展開ドキュメントの転送ヘッダー プロパティを修正 #50848
  • 非推奨の spring-boot-starter-web #50847 ではなく、 spring-boot-starter-webmvc を参照してください。
  • ドキュメントの不一致を修正 #50800
  • Spring gRPC プロパティを共通アプリケーション プロパティのリファレンスに追加 #50789
  • OTLP SSL サービス接続の文書化 #50782
  • オプションのプロパティ バインディングと JPA リポジトリのブートストラップ モードへの変更についてドキュメントを更新 #50759
