spring-boot v4.2.0-M2

プレリリース 公開日2026年9月24日 出典spring-projects/spring-boot 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

スプリングブーツ v4.2.0-M2

:star: 新機能

  • AppOptics は廃止されたため非推奨 #51810
  • jar の作成および抽出時のクラスパス エントリの検索パフォーマンスを向上させました #51787
  • spring.kafka.listener.await-async-results-on-stop プロパティを追加 #51774
  • KafkaProperties の外で Kafka 構成を合理化する #51769
  • 自動構成された DefaultMeterObservationHandler オプトインでアクティブな Observation LongTaskTimer を作成します #51762
  • GraphQL トランスポートで許可される HTTP メソッドを構成する #51732
  • 任意の PlatformTransactionManager で Mongo JobRepository を使用できるようにします #51725
  • デフォルト値をバインディングするコンストラクター内のプロパティ プレースホルダーを解決する #51661
  • OpenTelemetry タグ フィールドに自動構成された BaggageTaggingSpanProcessor を追加 #51656
  • レイヤーインデックス作成のパフォーマンスを改善 #51654
  • 階層化されたjarを抽出する際のレイヤー検索を高速化 #51653
  • Tomcat のサーブレット固有のプロパティを server.tomcat.servlet の下に移動 #51603
  • SPRING_APPLICATION_JSON の null 値と空の値の処理を YAML 処理と調整します #51583
  • Janino の依存関係管理を削除 #51567
  • SBOM を印刷/エクスポートするための jarmode ツール コマンドを追加 #51505
  • テストクラスのすべての @TypeExcludeFilters アノテーションを取得 #51489
  • ユーザー提供の AbstractResourceBasedMessageSource への MessageSourceProperties のマッピングを容易にします #51484
  • マルチセグメントの追加のヘルス エンドポイント パスをサポート #51470
  • 組み込み LDAP サーバーの spring.ldap.* プロパティを尊重する #51465
  • 認証を必要とする組み込み LDAP 操作タイプを構成するための構成プロパティを追加 #51461
  • JavaVersion 列挙型に TWENTY_SEVEN を追加 #51427
  • Spring Boot で構築されたアーカイブから追加の構成メタデータを自動的にフィルタリング #51386
  • SSL バンドルのサポートを LDAP 自動構成に追加 #51382
  • server.tomcat.use-relative-redirects のデフォルトを Tomcat のデフォルト #51173 に合わせます。
  • マイクロメーター トレーシング MDC キーの設定を許可 #50595
  • エンドポイント、圧縮、ヘッダーに共通の OTLP 設定を追加 #50461
  • プローブ正常性グループの他のプロパティを構成するときにプローブのデフォルトを保持する #50296
  • WebFlux Cloud Foundry エンドポイント応答にセキュリティ エラー本文を含める #50256
  • Micrometer から OpenTelemetry セマンティック規則に切り替えるための構成プロパティを提供します #49241
  • リスナーとテンプレート固有の Kafka 管理プロパティをサポート #38830

:lady_beetle: バグ修正

  • HttpComponents コネクタ #51767 をサポートするリアクティブ client を使用する場合、spring.http.clients.cookie-handling は効果がありません。
  • NestedJarFileResources の競合状態により、uber jar を使用すると NullPointerException がスローされる場合がある #51746
  • Rabbitmq Docker Compose サービスが SSL を使用するように構成されている場合、接続が失敗する #51668
  • SBOM 関連のマニフェスト属性が Maven パッケージの war から欠落している #51652
  • server.reactive.session.cookie.same-site が設定されていない場合、セッション Cookie には SameSite 属性がありません #51640
  • OAuth2 リソース サーバーは、独自に設定されている場合、authority-claim-delimiter を無視します #51631 -developmentOnly 構成と testAndDevelopmentOnly 構成では、潜在的な解決の問題を引き起こす属性が指定されていません #51624
  • リアクティブ Web アプリケーションでは、クラウド コントローラー URL が利用できない場合、Cloud Foundry セキュリティ統合は 503 ではなく 500 を返します #51615
  • ReactiveOAuth2ResourceServerWebSecurityAutoConfiguration に間違った条件のアノテーションが付けられました #51588
  • WritableJson.toByteArray() は補助文字を破損する可能性があります #51586
  • レイヤーの作成が失敗してもレイヤー一時ファイルが削除されない #51582
  • Docker RabbitMQ の Compose 統合は、環境変数に値がない場合に認証情報のフォールバックをスキップします #51579
  • 一部のアサーション メッセージで間違ったパラメーターが指定される #51575
  • OAuth2ResourceServerProperties.Jwt には、ゲッターと一致しないセッターがあります #51566
  • jarmode ツール コマンドは、エラー メッセージの代わりにスタックトレースを出力します #51548
  • Docker Compose ProcessRunner がハングしたり、孤立したプロセスを残したりする可能性がある #51539
  • バッファーを埋めることができなかった場合、NestedByteChannel.read(ByteBuffer) が誤って 0 を返す #51521
  • HTTP client ビルダーでのカスタマイザーの null チェックが間違った属性をアサートする #51514
  • Tomcat の初期化中に SSL ホスト構成のカスタマイズが失われる場合がある #51512
  • SQL Server Docker Compose 統合により、JDBC URL の暗号化パラメータが重複する場合がある #51482
  • SSL バンドルをリロードすると、SSL ホスト構成のカスタマイズが失われる #51458
  • ユーザー定義の ClientRegistrationRepository Bean が提供されている場合、OAuth2ClientProperties は使用できません #51451
  • LDAP サーバーがプロトコル バージョンを公開していない場合、LdapHealthIndicator が UP ではなく UNKNOWN を報告する #51442
  • 開始がすぐに失敗すると、JmsHealthIndicator がウォッチドッグ スレッドをリークする #51434
  • ルート データソースを解決するときにラッパーのラップ解除を尊重する #51420
  • すべての JSON マーシャル テスターによってソースが一貫して閉じられていない #51419
  • SpringBootJoranConfigurator のファイル ハンドルを閉じる必要があります #51416
  • 非推奨の io.buildpacks.stack.id の検証が積極的すぎる #51401

  • spring.test.database.replace の文書化されたデフォルトを修正 #51729
  • Testcontainers ドキュメントの ActiveMQContainer Javadoc リンクを修正 #51723

  • Spring Data Geode #51565 への参照を削除
  • サービスコンテナのjavadocとリファレンスドキュメントのタイプミスを修正#51446
