spring-boot v4.2.0-RC2

マイナー 公開日2026年11月5日 出典spring-projects/spring-boot 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

スプリングブーツ v4.2.0-RC2

:star: 新機能

  • LDAP SSL リロード サポートを削除 #52365
  • Reactor Netty #52316 で X-Forwarded-Prefix のサポートを追加

:lady_beetle: バグ修正

  • Management.observations.conventions を open-telemetry に設定すると、どちらのセマンティック規約も無効になります #52619
  • コンテキストが閉じているときに PushGatewayTaskScheduler がタスク スケジューラを正しくシャットダウンしない #52591
  • ClearCachesApplicationListener が継承された clearCache() メソッドを見つけられません #52589
  • BatchDataMongoAutoConfiguration によって作成された MongoTransactionManager は TransactionManagerCustomizers によってカスタマイズされません #52572
  • 構成プロセッサーは、完全修飾された既知の型を処理しません #52571
  • 無効な AMQP Rabbit ホストが間違った値で報告される #52568
  • 期間をマイクロ秒に変換する際の早期オーバーフローを回避する #52561
  • 同じ要素タイプのコレクションが同じ構成ツリーからバインドされた後、構成ツリーからの値のバインドが失敗する #52559
  • usingPairs が名前付きメンバーで使用されている場合、JsonWriter は無効な JSON を書き込みます #52549
  • ログバック GELF 構造化ログは、ログ メッセージが null の場合、null short_message を書き込みます #52547
  • 自動構成された KafkaTransactionManager は TransactionManagerCustomizers によってカスタマイズされません #52542
  • Gradle プラグインのカスタム レイヤーに、除外されたコンテンツが除外されるのではなく含まれる #52540
  • SSL が有効な場合、ポートのない RabbitMQ アドレスは AMQP ポートを使用します #52538
  • BasicJsonParser は \b、\f、\n、\r、\t、\uXXXX のエスケープ シーケンスをデコードしません #52534
  • jar にコメントがない場合、NestedJarFile.getComment() が EOFException で失敗する #52513
  • プレーン テキストのスレッド ダンプは、Object.wait() 内のスレッドを Java 19 以降のパーキングとして報告します #52511
  • spring-boot-amqp-rabbitmq と spring-boot-rabbitmq の両方を使用すると、後者のヘルス情報が失われます #52506
  • JSON 解析エラーによって DockerOutputParseExceptions #52500 が生成されなくなりました
  • ECS 構造化ログは空のサービスと service.node オブジェクトを書き込みます #52497
  • 複数のエンドポイントが同じ ID を共有する場合、ConfigurationMetadataAnnotationProcessor は反復不可能な出力を生成します #52494
  • 正常なシャットダウンは、Tomcat または Jetty の再起動後にアクティブなリクエストを待機しません #52490
  • SSL バンドルが設定されている場合、RabbitMQ はデフォルトで間違ったポートを使用します #52488
  • 自動構成された R2dbcTransactionManager は TransactionManagerCustomizers によってカスタマイズされません #52485
  • JsonWriter は NaN および無限値を無効な JSON #52483 として書き込みます
  • ZipEndOfCentralDirectoryRecord は、zip コメント内のレコード署名を検索します #52481
  • LLDAP_LDAP_USER_DN が設定されている場合、LLdap Docker Compose サポートが接続に失敗する #52475
  • ZipContent.Entry hasNameStartingWith は、仮想化されたネストされたディレクトリ名のオフセットを無視します #52464
  • ZipContent は、中央ディレクトリ レコードの終了後にデータを含む zip を開けません #52461
  • アーカイブにプレフィックス付きのデータがある場合、ZipContent は間違った位置から zip コメントを読み取ります #52459
  • ルート ロガー構成を取得できず、Log4j2 #52455 で構成されたレベルがありません
  • Docker Compose OTLP 統合では、HTTP のみを使用する場合に gRPC と HTTP ポートを公開する必要があります #52451
  • Spring Batch JDBC 自動構成は、起動時にデータベースに接続してタイプを検出しますが、構成する方法はありません #52449
  • OnAvailableEndpointCondition キャッシュは、環境を通じて閉じられたアプリケーション コンテキストを保持します #52447
  • DataSourceTransactionManagerAutoConfiguration は、サポートされなくなった古いプロパティを使用して例外変換を制御します #52445
  • Tomcat の新しい 'maxLocaleCount' プロパティは簡単に設定できません #52443
  • DevTools は再起動に失敗するたびにファイル監視スレッドをリークします #52441
  • SSL バンドル暗号と有効なプロトコルは、基盤となるコンポーネントがその構成をサポートしていない場合、警告なしに無視されることがあります #52438
  • AMQP 1.0 は、デフォルトで ANONYMOUS を使用する資格情報を設定すべきではありません #52435
  • SSL バンドルが設定されている場合、RabbitMQ AMQP 1.0 ポートを 5671 にデフォルト設定 #52432
  • JMX が有効な状態で遅延接続フェッチが使用されると、Hikari は独自の MBean を登録しません #52426
  • SSL バンドル暗号と有効なプロトコルは RabbitMQ によって無視されます。 clients #52416
  • SSL バンドル暗号と有効なプロトコルは Kafka によって無視されます clients #52413
  • ヘルスエンドポイントが不明な中間セグメントを持つパスの内部エラーで失敗する #52411
  • JWT と不透明トークンの両方のリソース サーバー プロパティが設定されている場合、サーブレット アプリケーションの起動に失敗する #52409
  • 起動時にアプリケーションコンテキストが閉じられた後にランナーを呼び出すことができます #52408
  • @ConfigurationProperties Bean を同時にバインドすると、BoundConfigurationProperties が破損し、バインドが失敗する可能性があります #52406
  • 自動構成された JavaMailSender は、SSL バンドル暗号または有効なプロトコルを適用しません #52404
  • #52246 #52402 以降の実行可能 jar ではクラス パス ルートを解決できません
  • JSON-B が唯一の JSON コンバータである場合、Kotlin シリアル化はバックオフしません #52389
  • WebMvc または WebFlux を使用すると、マトリックス パラメーターが残りのすべてのセレクターに一致するように渡される値を歪めます #52378
  • 大文字のサーバー名を含むサーバー名 SSL バンドルは、Netty #52364 では使用されません。
  • パス内に括弧が含まれる構成データの場所が正しくロードされない #52360
  • ヒカリプールの一時停止が有効になっている場合、コンテキストを閉じるとハングすることがある #52359
  • OriginTrackedPropertiesLoader は、バックスラッシュで終わるコメントに続く行を削除します #52357
  • 子コンテキストを閉じるとキープアライブ スレッドが停止します #52344
  • DEFAULT の MimeMappings コピーが空で、イコールが非対称です #52342
  • StringHttpMessageConverter は HTTP メッセージ コンバータ カスタマイザでオーバーライドできません #52336
  • ConfigurationPropertyName は、名前の末尾に左角かっこを誤って受け入れます #52334
  • jarmode ツール抽出によって作成されたディレクトリにより、Docker レイヤーが再現不能になります #52330
  • クラスターが spring.data.redis.cluster プロパティを使用して構成されていない場合、レタスクラスターの更新プロパティは無視されます #52328
  • BasicJsonParser が文字列値内の括弧を誤って処理する #52326
  • MessageSourceMessageInterpolator が不均衡な閉じ中括弧を誤って処理する #52324
  • BasicJsonParser はリストの要素の周囲の空白を無視しません #52318
  • ZipContent はマルチバイト文字を含むネストされたディレクトリ名を処理しません #52315
  • RabbitMQ AMQP 1.0 はデフォルトで空の交換を設定すべきではありません #52305
  • マスター/レプリカ ノードの構成時に spring.data.redis.database が無視される #52189

:notebook_with_decorative_cover: ドキュメント

  • スターター親の再パッケージ実行とメインクラスをカスタマイズする方法を文書化 #52556
  • gRPC ドキュメントのタイプミスと壊れた参照を修正 #52543
  • 自動構成された ReactiveHealthIndicators の表に R2DBC インジケーターがリストされていない #52424
  • 一部のヘルスインジケーターが有効なプロパティのメタデータが欠落しています #52422
  • テスト client が観察されないことを示す文書 #52418
  • 古い構成メタデータのヒントを修正 #52386
  • テストドキュメントの壊れた外部参照を修正 #52384
