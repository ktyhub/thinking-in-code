spring-boot v4.0.9

パッチ 公開日2026年10月22日 出典spring-projects/spring-boot 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

スプリングブーツ v4.0.9

:star: 新機能

  • JavaVersion 列挙型に TWENTY_SEVEN を追加 #51422

:lady_beetle: バグ修正

  • issuer-uri が空で jwk-set-uri が設定されている場合、JWT は拒否されます #52249
  • ディレクトリエントリのないネストされたjarのパッケージマニフェスト属性がありません #52244
  • OriginTrackedPropertiesLoader は、名前が # または ! で始まるプロパティを削除します。 #52207
  • OriginTrackedResource は、equals を正しく実装していません #52205
  • Tomcat または Jetty の正常なシャットダウンは、アイドル状態のサーバー上で shutDownGraceful の直後に stop が呼び出される場合、REQUESTS_ACTIVE でコールバックされる場合があります #52195
  • TestPropertyValues の空のシステム プロパティが空の値に復元されるのではなくクリアされる #52125
  • 認証情報にスペースが含まれている場合、MongoDB は接続に失敗します #52121
  • NettyWebServer stop は、shutDownGraceful の直後に呼び出すとハングすることがある #52119
  • spring.elasticsearch.uris に設定されたパスワードにコロンが含まれる場合、認証が失敗する #52047
  • テスト コンテキスト フレームワークによってコンテキストが一時停止されると、ロギングが失われる可能性があります #51959
  • Docker 認証情報に URL エンコードを必要とする文字が含まれている場合、MongoDB の Compose サポートが接続に失敗する #51939
  • アクチュエーターが別のポートで実行されている場合、Jersey はエンドポイント ObjectMapper を使用しません #51937
  • BasicJsonParser がネストされたリストおよびマップ内のエスケープ文字を誤って処理する #51907
  • ゼロ週値の変換が「intValue を WEEKS から抽出できません」例外で失敗する #51892
  • DevTools を使用し、spring-boot-jdbc または spring-boot-r2dbc を使用せずに JDBC または R2DBC を手動で構成すると、アプリの起動に失敗する #51872
  • Docker Compose サポートは、MARIADB_ALLOW_EMPTY_ROOT_PASSWORD ではなく MARIADB_ALLOW_EMPTY_PASSWORD を誤って認識します #51870
  • 自動構成された Kotlinx シリアル化 JSON コーデックのカスタマイズが適用されない #51842
  • NestedJarFileResources の競合状態により、uber jar を使用すると NullPointerException がスローされる場合がある #51744
  • DevTools がリアクティブ Web 環境を検出しない #51708
  • Rabbitmq Docker Compose サービスが SSL を使用するように構成されている場合、接続が失敗する #51666
  • server.reactive.session.cookie.same-site が設定されていない場合、セッション Cookie には SameSite 属性がありません #51636
  • OAuth2 リソース サーバーは、独自に設定されている場合、authority-claim-delimiter を無視します #51619
  • リアクティブ Web アプリケーションでは、クラウド コントローラー URL が利用できない場合、Cloud Foundry セキュリティ統合は 503 ではなく 500 を返します #51613
  • 一部のアサーション メッセージでは、間違ったパラメーターの名前が付けられています #51568
  • SBOM 関連のマニフェスト属性が Maven パッケージの war から欠落している #51551
  • Docker RabbitMQ の Compose 統合は、環境変数に値がない場合に認証情報のフォールバックをスキップします #51546
  • jarmode ツール コマンドは、エラー メッセージの代わりにスタックトレースを出力します #51540
  • レイヤーの作成が失敗してもレイヤー一時ファイルが削除されない #51519
  • バッファーを埋めることができなかった場合、NestedByteChannel.read(ByteBuffer) が誤って 0 を返す #51515
  • HTTP client ビルダーでのカスタマイザーの null チェックが間違った属性をアサートする #51509 -developmentOnly 構成と testAndDevelopmentOnly 構成では、潜在的な解決の問題を引き起こす属性が指定されていません #51492
  • SQL Server Docker Compose 統合により、JDBC URL の暗号化パラメータが重複する場合がある #51467
  • Tomcat の初期化中に SSL ホスト構成のカスタマイズが失われる場合がある #51466
  • ユーザー定義の ClientRegistrationRepository Bean が提供されている場合、OAuth2ClientProperties は使用できません #51447
  • すべての JSON マーシャル テスターによってソースが一貫して閉じられていない #51417
  • 開始がすぐに失敗すると、JmsHealthIndicator がウォッチドッグ スレッドをリークする #51412
  • SpringBootJoranConfigurator のファイル ハンドルを閉じる必要があります #51398
  • 非推奨の io.buildpacks.stack.id の検証が積極的すぎる #51390
  • SSL バンドルをリロードすると、SSL ホスト構成のカスタマイズが失われる #51290
  • Docker Compose ProcessRunner がハングしたり、孤立したプロセスを残したりする可能性がある #50963
  • Gradle を使用して段階的にビルドすると、構成プロパティの説明が失われる場合がある #50489

:notebook_with_decorative_cover: ドキュメント

  • Javadoc のアクチュエーター エンドポイント プロパティ名を修正 #51869
  • リファレンスドキュメントから外部 Javadoc へのリンク切れを修正 #51815
  • 廃止されたため、リファレンス ガイドの AppOptics への参照を削除 #51807
  • 壊れたリンクを修正 #51791
  • Spring Framework 参照リンクを更新 #51750
  • Maven プラグインのドキュメントでリモート再起動プロパティが誤って参照されている #51743
  • testcontainers javadoc リンクを更新 #51739
  • spring.test.database.replace の文書化されたデフォルトを修正 #51709
  • Jackson 3 Javadoc リンクを修正 #51660
  • 非推奨の Pushgateway ベース URL プロパティのメタデータのタイプミスを修正 #51627
  • Spring Data Geode #51563 への参照を削除
  • サービスコンテナのjavadocとリファレンスドキュメントのタイプミスを修正#51431
  • Java 27 のドキュメント サポート #51424
  • WebFlux セキュリティ ドキュメントで SAML2 バックオフをドキュメント #51421
  • 削除された SpringBootWebSecurityConfiguration への参照を削除 #51411
