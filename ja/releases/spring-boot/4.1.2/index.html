spring-boot v4.1.2

パッチ 公開日2026年10月22日 出典spring-projects/spring-boot 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

スプリングブーツ v4.1.2

:star: 新機能

  • JavaVersion 列挙型に TWENTY_SEVEN を追加 #51426

:lady_beetle: バグ修正

  • OriginTrackedResource は、equals を正しく実装しません #52267
  • OriginTrackedPropertiesLoader は、名前が # または ! で始まるプロパティを削除します。 #52265
  • issuer-uri が空で jwk-set-uri が設定されている場合、JWT は拒否されます #52260
  • ディレクトリエントリのないネストされたjarのパッケージマニフェスト属性がありません #52258
  • Logback ColorConverter は、すべてのログ イベントのオプションを不必要に解析します #52228
  • TestPropertyValues の空のシステム プロパティが空の値に復元されるのではなくクリアされる #52208
  • Tomcat または Jetty の正常なシャットダウンは、アイドル状態のサーバー上で shutDownGraceful の直後に stop が呼び出される場合、REQUESTS_ACTIVE でコールバックされることがあります #52197
  • NettyWebServer stop は、shutDownGraceful の直後に呼び出すとハングすることがある #52196
  • gRPC client 'grpc' ロード バランシングは、子ポリシーが設定されていない場合、NullPointerException でバインドに失敗します #52193
  • gRPC client プロパティがユーザーのカスタマイズをオーバーライドしないようにしました #52175
  • 認証情報にスペースが含まれる場合、MongoDB は接続に失敗します #52168
  • spring.elasticsearch.uris に設定されたパスワードにコロンが含まれている場合、認証が失敗する #52166
  • テスト コンテキスト フレームワークによってコンテキストが一時停止されると、ロギングが失われる可能性があります #52088
  • Docker 資格情報に URL エンコードを必要とする文字が含まれている場合、MongoDB の Compose サポートが接続に失敗する #52084
  • アクチュエーターが別のポートで実行されている場合、Jersey はエンドポイント ObjectMapper を使用しません #51982
  • gRPC サービス構成期間を設定するときに、秒の小数部分が正しく処理されない #51957
  • Gradle を使用して段階的にビルドすると、構成プロパティの説明が失われる場合がある #51925
  • BasicJsonParser がネストされたリストおよびマップ内のエスケープ文字を誤って処理する #51908
  • ゼロ週値の変換が「intValue を WEEKS から抽出できません」例外で失敗する #51894
  • DevTools を使用し、spring-boot-jdbc または spring-boot-r2dbc を使用せずに JDBC または R2DBC を手動で構成すると、アプリの起動に失敗する #51890
  • Docker Compose サポートは、MARIADB_ALLOW_EMPTY_ROOT_PASSWORD ではなく MARIADB_ALLOW_EMPTY_PASSWORD を誤って認識します #51888
  • 自動構成された Kotlinx シリアル化 JSON コーデックのカスタマイズが適用されない #51877
  • NestedJarFileResources の競合状態により、uber jar を使用すると NullPointerException がスローされる場合がある #51745
  • DevTools がリアクティブ Web 環境を検出しない #51730
  • Spring.http.clients.cookie-handling は、HttpComponents コネクターによってサポートされるリアクティブ client を使用する場合には効果がありません #51724
  • Rabbitmq Docker Compose サービスが SSL を使用するように構成されている場合、接続が失敗する #51667
  • SBOM 関連のマニフェスト属性が Maven パッケージの war から欠落している #51651
  • server.reactive.session.cookie.same-site が設定されていない場合、セッション Cookie には SameSite 属性がありません #51639
  • OAuth2 リソース サーバーは、独自に設定されている場合、authority-claim-delimiter を無視します #51630 -developmentOnly 構成と testAndDevelopmentOnly 構成では、潜在的な解決の問題を引き起こす属性が指定されていません #51623
  • リアクティブ Web アプリケーションでは、クラウド コントローラー URL が利用できない場合、Cloud Foundry セキュリティ統合は 503 ではなく 500 を返します #51614
  • レイヤーの作成が失敗してもレイヤー一時ファイルが削除されない #51581
  • Docker RabbitMQ の Compose 統合は、環境変数に値がない場合に認証情報のフォールバックをスキップします #51578
  • 一部のアサーション メッセージでは、間違ったパラメーターの名前が付けられています #51574
  • OAuth2ResourceServerProperties.Jwt には、ゲッターと一致しないセッターがあります #51562
  • jarmode ツールのコマンドは、エラー メッセージの代わりにスタックトレースを出力します #51547
  • Docker Compose ProcessRunner がハングしたり、孤立したプロセスを残したりする可能性がある #51538
  • バッファーを埋めることができなかった場合、NestedByteChannel.read(ByteBuffer) が誤って 0 を返す #51520
  • HTTP client ビルダーでのカスタマイザーの null チェックが間違った属性をアサートする #51513
  • Tomcat の初期化中に SSL ホスト構成のカスタマイズが失われる場合がある #51511
  • SQL Server Docker Compose 統合により、JDBC URL の暗号化パラメータが重複する場合がある #51481
  • WritableJson.toByteArray() は補助文字を破損する可能性があります #51464
  • SSL バンドルをリロードすると、SSL ホスト構成のカスタマイズが失われる #51457
  • ユーザー定義の ClientRegistrationRepository Bean が提供されている場合、OAuth2ClientProperties は使用できません #51450
  • LDAP サーバーがプロトコル バージョンを公開していない場合、LdapHealthIndicator が UP ではなく UNKNOWN を報告する #51441
  • 開始がすぐに失敗すると、JmsHealthIndicator がウォッチドッグ スレッドをリークする #51433
  • すべての JSON マーシャル テスターによってソースが一貫して閉じられていない #51418
  • SpringBootJoranConfigurator のファイル ハンドルを閉じる必要があります #51415
  • ルート データソースを解決するときにラッパーのラップ解除を尊重する #51410
  • 非推奨の io.buildpacks.stack.id の検証が積極的すぎる #51400
  • ReactiveOAuth2ResourceServerWebSecurityAutoConfiguration に間違った条件のアノテーションが付けられました #50778

:notebook_with_decorative_cover: ドキュメント

  • gRPC テスト ドキュメントのタイプミスを修正 #52181
  • サーブレットベースの gRPC サーバーの Gradle サンプルを修正 #51956
  • Javadoc のアクチュエーター エンドポイント プロパティ名を修正 #51886
  • プロキシ サーバーに関する InetAddressFilter の制限を文書化 #51863
  • Java 27 のドキュメント サポート #51825
  • リファレンスドキュメントから外部 Javadoc へのリンク切れを修正 #51820
  • 廃止されたため、リファレンス ガイドの AppOptics への参照を削除 #51808
  • 壊れたリンクを修正 #51802
  • Spring Framework リファレンス リンクを更新 #51771
  • testcontainers javadoc リンクを更新 #51765
  • Maven プラグインのドキュメントでリモート再起動プロパティが誤って参照されている #51747
  • spring.test.database.replace の文書化されたデフォルトを修正 #51728
  • Jackson 3 Javadoc リンクを修正 #51663
  • 非推奨の Pushgateway ベース URL プロパティのメタデータのタイプミスを修正 #51632
  • gRPC #51597 を介した手荷物の伝播を文書化する
  • Spring Data Geode #51564 への参照を削除
  • サービスコンテナのjavadocとリファレンスドキュメントのタイプミスを修正#51445
  • WebFlux セキュリティドキュメントで SAML2 バックオフをドキュメント化 #51435
  • 削除された SpringBootWebSecurityConfiguration への参照を削除 #51413
