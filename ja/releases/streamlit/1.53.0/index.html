ストリームリット 1.53.0

何が変わったのか

重大な変更 🛠

  • [feat] https://github.com/streamlit/streamlit/pull/13518 の @sfc-gh-bnisco により CCv2 の isolate_styles パラメータを移動
  • [feat] https://github.com/streamlit/streamlit/pull/13515 の @sfc-gh-bnisco により一部の外部 CCv2 タイプの名前を変更

新機能 🎉

  • https://github.com/streamlit/streamlit/pull/13094 の @jensonjohnathon によるメトリクス値とデルタ パラメーターのマークダウンのサポート
  • デフォルトのサイドバー幅を https://github.com/streamlit/streamlit/pull/12154 の @jose-mindwayai によって構成可能にする
  • [機能] チャット入力 UI を更新し、https://github.com/streamlit/streamlit/pull/13088 の @sfc-gh-nbellante によるレイアウトとスタイルを改善しました。
  • https://github.com/streamlit/streamlit/pull/13153 の @lukasma such によるカラー パレットからのメトリック デルタ カラーの設定のサポートを追加
  • https://github.com/streamlit/streamlit/pull/13193 の @lukasma such による st.metric の format の構成をサポート
  • https://github.com/streamlit/streamlit/pull/12960 の @jensonjohnathon による select_slider オプションでのマークダウンのサポート
  • https://github.com/streamlit/streamlit/pull/13222 の @lukasmauch によるロゴ click のホームページに移動します
  • https://github.com/streamlit/streamlit/pull/12816 の @rishabhjain1712 によって max_upload_size パラメータを file_uploader と chat_input に追加
  • https://github.com/streamlit/streamlit/pull/13228 の @lukasma such による st.data_editor の行の追加または削除のみを許可します
  • https://github.com/streamlit/streamlit/pull/13150 の @SiddhantSadangi によりボタンのようなコンポーネントの icon_position サポートを追加
  • [機能] @sfc-gh-bnisco によるHeadingFontSize1-6 およびHeadingFontWeight1-6 CSS カスタム プロパティを https://github.com/streamlit/streamlit/pull/13268 に追加
  • [機能] https://github.com/streamlit/streamlit/pull/13223 の @sfc-gh-nbellante によるファイル チップと再試行機能の改善により、st.chat_input ファイル アップロード UI を強化
  • https://github.com/streamlit/streamlit/pull/13244 の @KaranPradhan266 によりダイアログにアイコンのサポートを追加
  • key が https://github.com/streamlit/streamlit/pull/13383 の @lukasma such によって提供されている場合、セレクトボックス オプションの動的な変更を許可します。
  • https://github.com/streamlit/streamlit/pull/13113 の @lukasma such による st.json 値 click にパス ツールチップを追加
  • https://github.com/streamlit/streamlit/pull/13348 の @lukasmauch によるデータフレームのような構造としての pydantic オブジェクトのリストの受け渡しをサポート
  • [feat] a11y の実践を改善するための AGENTS ルールの更新 (https://github.com/streamlit/streamlit/pull/13411 の @sfc-gh-bnisco による)
  • [feat] https://github.com/streamlit/streamlit/pull/13412 の @sfc-gh-bnisco による a11y サポートを改善するために eslint ルールを更新
  • https://github.com/streamlit/streamlit/pull/12044 の @velocy による OIDC トークンの公開
  • https://github.com/streamlit/streamlit/pull/13392 の @lukasma such による format または st.slider の事前定義形式をサポート
  • st.cache_resource に on_release を追加します。 @sfc-gh-jkinkead 著、https://github.com/streamlit/streamlit/pull/13439
  • https://github.com/streamlit/streamlit/pull/13345 の @sfc-gh-tteixeira により、st.container/columns/space の xxsmall、xsmall、xlarge、xxlarge のギャップとサイズを追加
  • https://github.com/streamlit/streamlit/pull/13414 の @vdonato による新しい session_duration_seconds_total 統計を追加
  • セッションのスコープをキャッシュに追加します。 @sfc-gh-jkinkead 著、https://github.com/streamlit/streamlit/pull/13482
  • [feat] https://github.com/streamlit/streamlit/pull/13364 の @sfc-gh-nbellante による基本構成の単一行レイアウトでチャット入力 UI を簡素化
  • セッションスコープの接続サポートを追加します。 @sfc-gh-jkinkead 著、https://github.com/streamlit/streamlit/pull/13506
  • [機能] CCv2 でオプションの js、css、および html パラメータを許可 (https://github.com/streamlit/streamlit/pull/13511 の @sfc-gh-bnisco による)
  • https://github.com/streamlit/streamlit/pull/13512 の @lukasmauch による st.number_input の最小値、最大値、およびステップの動的変更を許可します。
  • https://github.com/streamlit/streamlit/pull/13375 の @lukasmauch による Starlette で Streamlit を実行するためのオプションのサポートを追加
  • SnowflakeCallersRightsConnection を追加します。 @sfc-gh-jkinkead 著、https://github.com/streamlit/streamlit/pull/13538
  • key が https://github.com/streamlit/streamlit/pull/13448 の @lukasma such によって提供されている場合、複数選択オプションの動的な変更を許可します。
  • 修正(複数選択): https://github.com/streamlit/streamlit/pull/13384 の @kakawa0710 による項目を削除するときにスクロール位置を保持する
  • https://github.com/streamlit/streamlit/pull/13537 の @lukasma such による高度なサーバー構成のための実験的な ASGI アプリ エントリ ポイントを追加
  • https://github.com/streamlit/streamlit/pull/12251 の @velocy により、OAuth redirect_uri が現在のポートを参照できるようにします
  • https://github.com/streamlit/streamlit/pull/12693 の @velocy によって OIDC 構成 (V2) で提供されている場合、st.logout で end_session_endpoint を使用するようにします
  • [feat] https://github.com/streamlit/streamlit/pull/13546 の @sfc-gh-nbellante による st.chat_input の動的レイアウト切り替えを追加

バグ修正 🐛

  • [修正] https://github.com/streamlit/streamlit/pull/13206 の @sfc-gh-lwilby による幅/高さのエラー メッセージを「正の整数」と表示するように改善しました。
  • https://github.com/streamlit/streamlit/pull/13226 で @lukasmauch によるトップ ナビゲーションのロゴが予期せず縮小する問題を修正
  • [修正] https://github.com/streamlit/streamlit/pull/13227 で @sfc-gh-bnisco によってトップ ナビゲーションが有効になっている場合、サイドバー ナビゲーションをレンダリングしない
  • https://github.com/streamlit/streamlit/pull/12826 の @kmcgradiy による一時的なスピナーの実装
  • [修正] https://github.com/streamlit/streamlit/pull/13266 の @sfc-gh-bnisco による CCv2 インスタンスのキーにデフォルトを含める
  • [修正] https://github.com/streamlit/streamlit/pull/13264 の @sfc-gh-bnisco による Shadow DOM の要素に対してキー ダウン ターゲットが機能することを確認します
  • https://github.com/streamlit/streamlit/pull/13309 で @lukasma such によって空の列から開始するときのデータ エディターの回帰を修正
  • st.dialog が https://github.com/streamlit/streamlit/pull/13297 の @lukasma such による前のダイアログの要素を表示しないようにします
  • https://github.com/streamlit/streamlit/pull/13333 の @lukasma such による依存関係の更新によって引き起こされる認証関連の問題を修正
  • [修正] https://github.com/streamlit/streamlit/pull/13306 の @mayagbarnes によるリロード後のテーマ設定の永続性
  • [修正] https://github.com/streamlit/streamlit/pull/13240 の @sfc-gh-bnisco による CCv2 での未定義のテーマ プロパティの処理
  • [修正] https://github.com/streamlit/streamlit/pull/13376 の @sfc-gh-bnisco によって、crossOrigin 属性が CCv2 スタイルシートに適切に設定されていることを確認します。
  • https://github.com/streamlit/streamlit/pull/13388 の @lukasmauch によるスピナー時間のテキストの配置を修正
  • [修正] https://github.com/streamlit/streamlit/pull/13365 の @sfc-gh-lwilby によるヘルプで改行を伴うツールチップ テキストのリーク
  • [修正] https://github.com/streamlit/streamlit/pull/13378 の @sfc-gh-bnisco によって Markdown ヘッダーのアンカー リンクがキーボードからアクセスできるようにする
  • [修正] https://github.com/streamlit/streamlit/pull/13379 の @sfc-gh-bnisco がヘルプ ツールチップにアクセスできるようにする
  • [修正] st.html は、https://github.com/streamlit/streamlit/pull/13437 で @mayagbarnes によるリストのインデントを処理します
  • [修正] セッション状態を介して設定された st.selectbox は、https://github.com/streamlit/streamlit/pull/13438 の @mayagbarnes による初期値を復元しません
  • [修正] vconcat および hconcat を含む Altair チャート (https://github.com/streamlit/streamlit/pull/13423 の @mayagbarnes による)
  • https://github.com/streamlit/streamlit/pull/13498 で @ranmocy によって embed_options で埋め込まれた場合のカスタム テーマを修正
  • https://github.com/streamlit/streamlit/pull/13484 の @mayagbarnes により st.number_input の精度を向上
  • https://github.com/streamlit/streamlit/pull/13166 の @kmcgradiy によってスクリプトが実行されるときに一時ノードをクリアする機能を追加
  • [修正] https://github.com/streamlit/streamlit/pull/13557 の @sfc-gh-nbellante による Icon styled-components の justifyContents を justifyContent に修正
  • [修正] st.chat_input でのドラッグ アンド ドロップと削除後のアップロード ボタンの機能を修正 (https://github.com/streamlit/streamlit/pull/13556 の @sfc-gh-nbellante による)
