ストリームリット 1.62.0

<!-- 1.62.0 の .github/release.yml の構成を使用して生成された Release note -->

何が変わったのか

重大な変更 🛠

  • [雑用] https://github.com/streamlit/streamlit/pull/15787 の @lukasma such による非推奨の st.cache API を削除
  • [雑用] https://github.com/streamlit/streamlit/pull/16450 の @lukasma such による st.pyplot の savefig kwargs を非推奨にする
  • [雑務] https://github.com/streamlit/streamlit/pull/16464 の @lukasmauch による st.pyplot のグローバル図サポートを削除

新機能 🎉

  • [機能] https://github.com/streamlit/streamlit/pull/16275 の @lukasma such による完全に型指定された選択状態の戻り値を提供します
  • [機能] https://github.com/streamlit/streamlit/pull/15714 の @lukasma such により、client 側検証を st.text_input に追加します
  • [機能] @lukasmauch によるパブリック streamlit.typing 名前空間を https://github.com/streamlit/streamlit/pull/16295 に追加
  • [機能] https://github.com/streamlit/streamlit/pull/16325 の @lukasmauch によるラベルの折り返しを制御するために、ボタンのような要素に wrap パラメーターを追加します
  • [機能] https://github.com/streamlit/streamlit/pull/16351 の @lukasma such による streamlit.typing で DataEditorState を公開する
  • https://github.com/streamlit/streamlit/pull/16396 の @mayagbarnes によるテーマ設定での 50 ステップ フォント ウェイトのサポートを追加
  • https://github.com/streamlit/streamlit/pull/16357 の @mayagbarnes によるライト/ダーク/サイドバーのチャート テーマ構成サポートを拡張
  • [機能] https://github.com/streamlit/streamlit/pull/16385 の @lukasmauch により、電子メール / URL / 電話 / 検索タイプを st.text_input に追加します
  • https://github.com/streamlit/streamlit/pull/16460 の @mayagbarnes により DateInput の BaseWeb を削除
  • [機能] https://github.com/streamlit/streamlit/pull/16484 の @lukasmauch による水平 st.container へのラップ コントロールを追加
  • https://github.com/streamlit/streamlit/pull/16501 の @mayagbarnes による DateTimeInput の BaseWeb を削除
  • [機能] https://github.com/streamlit/streamlit/pull/16470の@lukasmauchによりst.checkboxとst.toggleにwrapパラメータを追加
  • [機能] st.columns に wrap パラメーターを追加して、https://github.com/streamlit/streamlit/pull/16367 の @lukasma such による応答性を無効にします
  • https://github.com/streamlit/streamlit/pull/16502 の @mayagbarnes による TimeField を DateTimeInput カレンダー ポップオーバーに追加
  • [機能] @sfc-gh-nbellante によるエラー インストール スキル コールアウトを https://github.com/streamlit/streamlit/pull/15693 に追加
  • [機能] https://github.com/streamlit/streamlit/pull/16509 の @lukasma such による st.multiselect へのラップ パラメーターの追加

バグ修正 🐛

  • [修正] https://github.com/streamlit/streamlit/pull/16288 の @sfc-gh-dbyttow によって alt.Chart.from_json (#6269) を介して構築されたチャートのインライン データセットを保持する
  • [修正] 再実行時に見出しテキストが変更されるときに見出しアンカーを再導出する (#8793) @sfc-gh-dbyttow (https://github.com/streamlit/streamlit/pull/16286)
  • [修正] 外部コンテナーの st.status がアプリを空にする (https://github.com/streamlit/streamlit/pull/16316 の @sfc-gh-bnisco による)
  • [修正] https://github.com/streamlit/streamlit/pull/16315 の @sfc-gh-bnisco による Windows でのポート自動インクリメントの復元
  • [修正] https://github.com/streamlit/streamlit/pull/16327 の @lukasmauch によるホスト メッセージ ガードで同じウィンドウの自己投稿を受け入れる
  • [修正] https://github.com/streamlit/streamlit/pull/16342 の @lukasmauch による 1.4.0 の下のスターレットをピン留め
  • [修正] st.pyplot の format='svg' をサポート (#11489) by @sfc-gh-dbyttow (https://github.com/streamlit/streamlit/pull/16283)
  • [修正] https://github.com/streamlit/streamlit/pull/16314 の @sfc-gh-dbyttow により、キューに入れられた祖先 (#10719) によってすでに再レンダリングされたネストされたフラグメントを再実行しないでください。
  • [修正] 狭い/埋め込まれたビューポートで完全なポップオーバー コンテンツを表示する (#9340) by @sfc-gh-dbyttow (https://github.com/streamlit/streamlit/pull/16173)
  • [修正] https://github.com/streamlit/streamlit/pull/16324 の @lukasma such による FIPS 限定 blake2b の MD5 フォールバックを追加
  • [リファクタリング] 内部 Starlette API への依存を取り除くための GZip ミドルウェア (https://github.com/streamlit/streamlit/pull/16344 の @lukasma such による)
  • https://github.com/streamlit/streamlit/pull/16401 内の @mayagbarnes による派生 codeBackgroundColor および dataframeHeaderBackgroundColor を修正
  • [修正] https://github.com/streamlit/streamlit/pull/16284 の @sfc-gh-dbyttow によって、cache_data ハッシュ サンプル シードを構成可能にする (#14622)
  • [修正] https://github.com/streamlit/streamlit/pull/16392 の @sfc-gh-bnisco によるトレースバックをリークする代わりに、不正な形式の BackMsg で WebSocket を閉じる
  • [修正] https://github.com/streamlit/streamlit/pull/16393 の @sfc-gh-bnisco によるserver.enableCORS=false 起動警告を修正
  • [雑務] 不安定な data_editor 番号のセルのパフォーマンス テストを安定化する (https://github.com/streamlit/streamlit/pull/16467 の @lukasma such による)
  • [修正] フロントエンド番号範囲 (#16474) に対してタイムライク st.slider 境界を検証します (https://github.com/streamlit/streamlit/pull/16475 の @sfc-gh-dbyttow による)
  • [修正] https://github.com/streamlit/streamlit/pull/16498 で @lukasma such によって st.rerun() が st.toast に続くときにトーストを保存する
  • [修正] https://github.com/streamlit/streamlit/pull/16541 の @lukasma such によるダイアログでのカラー ピッカー インタラクションを復元する
  • [修正] https://github.com/streamlit/streamlit/pull/16543 の @lukasma such による空のチャート データの後にメトリック スパークラインを復元する
  • [修正] 狭いコンテナーでの date_input および datetime_input のオーバーフロー スタイルと、https://github.com/streamlit/streamlit/pull/16565 の @mayagbarnes による今日のインジケーター

その他の変更点

  • [雑用] https://github.com/streamlit/streamlit/pull/16317 の @github-actions[bot] による絵文字/マテリアル アイコンの更新
  • [雑用] https://github.com/streamlit/streamlit/pull/16329 の @github-actions[bot] による v1.61.0 をリリース
  • [雑用] https://github.com/streamlit/streamlit/pull/16343 の @github-actions[bot] による v1.61.1 をリリース
  • https://github.com/streamlit/streamlit/pull/16397 の @mayagbarnes による st.table フォント サイズ変更
  • [リファクタリング] https://github.com/streamlit/streamlit/pull/16422 の @lukasma such によって、無効な値の API 例外を StreamlitValueError に統合します
  • [ドキュメント] https://github.com/streamlit/streamlit/pull/16471 の @lukasma such による streamlit.typing インポートをユーザーに案内します
  • https://github.com/streamlit/streamlit/pull/16529 の @dependabot[bot] により、/lib 内の pyarrow 要件を <25,>=7.0 から >=7.0,<26 に更新します
  • [雑務] https://github.com/streamlit/streamlit/pull/16497 の @lukasma such によるテナシティ依存関係を内部再試行ヘルパーに置き換えます
  • [雑用] https://github.com/streamlit/streamlit/pull/16546 の @github-actions[bot] による絵文字/マテリアル アイコンの更新
  • [リファクタリング] https://github.com/streamlit/streamlit/pull/16462 で @lukasmauch による Starlette 1.5 ネイティブ gzip メディア/範囲処理を使用する
