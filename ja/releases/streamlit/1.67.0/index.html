何が変わったのか

新機能 🎉

  • [機能] https://github.com/streamlit/streamlit/pull/17450 の @mayagbarnes によるデフォルトのライトとダークの名前付きテーマ カラーを更新します

  • [機能] https://github.com/streamlit/streamlit/pull/17553の@sfc-gh-lwilby-1によるserver.maxCacheDataSizeキャッシュバジェットを追加
  • [機能] https://github.com/streamlit/streamlit/pull/17495 の @mayagbarnes による不透明なデフォルトテーマのクロムとデフォルトでの境界線
  • [機能] https://github.com/streamlit/streamlit/pull/17666 の @sfc-gh-lwilby-1 によってジェスチャーが終了したときに Vega-Lite の選択内容を送信します
  • [機能] エージェント API を公開して、https://github.com/streamlit/streamlit/pull/17731 の @lukasmauch によって HTTP 経由でアプリを駆動します
  • [機能] https://github.com/streamlit/streamlit/pull/17248 の @sfc-gh-gwatters による st.connection のサーバーのデフォルト TTL を追加します
  • [機能] https://github.com/streamlit/streamlit/pull/17676 の @lukasma such により required パラメータを st.selectbox に追加
  • [機能] https://github.com/streamlit/streamlit/pull/17678 の @lukasma such によって st.echarts_chart データフレームを Arrow として送信します
  • [機能] https://github.com/streamlit/streamlit/pull/17708 の @lukasma such による st.echarts_chart のデータ テーブルを表示します
  • [機能] https://github.com/streamlit/streamlit/pull/17850 の @lukasma such により st.selectbox に icon パラメータを追加
  • [機能] https://github.com/streamlit/streamlit/pull/17807 の @lukasma such によるナビゲーション ツールチップのヘルプを st.Page に追加します
  • [機能] エージェントがアクセス可能なアプリの MCP エンドポイント (https://github.com/streamlit/streamlit/pull/17510 の @lukasma such による)
  • [機能] https://github.com/streamlit/streamlit/pull/17800 の @lukasma such によるレスポンシブ グリッド レイアウト用の st.grid を追加
