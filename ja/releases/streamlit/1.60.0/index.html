何が変わったのか

重大な変更 🛠

  • [機能] https://github.com/streamlit/streamlit/pull/15804 の @lukasma such による server.maxWidgetStateSize 設定オプションを追加
  • [修正] https://github.com/streamlit/streamlit/pull/15803 の @lukasma such による client 提供のクエリ文字列のサイズとフィールド数の制限
  • [修正] https://github.com/streamlit/streamlit/pull/15800 の @lukasma such による子フレームおよびスクリプトからのなりすましホスト メッセージを拒否する

新機能 🎉

  • [機能] https://github.com/streamlit/streamlit/pull/15806 の @lukasma such により、vega-lite チャート アクションをネイティブ ツールバーに移動します
  • [機能] https://github.com/streamlit/streamlit/pull/15850 の @sfc-gh-dbyttow による gap パラメーター (#13005) の整数ピクセル値をサポートします
  • [機能] https://github.com/streamlit/streamlit/pull/15884 の @lukasma such による num_rows="fixed" の場合、key を st.data_editor のメイン ID として使用します
  • [機能] https://github.com/streamlit/streamlit/pull/15847 の @sfc-gh-dbyttow により、st.tabs (#12217) に height パラメータを追加
  • [機能] https://github.com/streamlit/streamlit/pull/15910 で @lukasma such によるデータフレーム データのエクスポートを無効にする
  • [機能] https://github.com/streamlit/streamlit/pull/15790 の @lukasma such による st.metric のゼロデルタのニュートラル処理
  • [機能] https://github.com/streamlit/streamlit/pull/16020 で @lukasma such による並べ替え時に st.dataframe の行選択を保持します

バグ修正 🐛

  • [修正] https://github.com/streamlit/streamlit/pull/15799 の @lukasmauch による URL パラメータから非有限浮動小数点値を拒否する
  • [修正] https://github.com/streamlit/streamlit/pull/15819 の @lukasmauch による危険な Graphviz リンク URL をサニタイズ
  • [修正] https://github.com/streamlit/streamlit/pull/15870 の @lukasma such によるセレクトボックス ドロップダウン オプション リストを仮想化
  • [修正] https://github.com/streamlit/streamlit/pull/15875 の @lukasma such による狭い画面でダイアログの周囲にビューポートの余白を維持する
  • [修正] https://github.com/streamlit/streamlit/pull/15864 の @lukasma such による追加認証の Surface 欠落 httpx エラー
  • [修正] https://github.com/streamlit/streamlit/pull/15865 の @lukasma such による st.App プログラム シークレットで Expose_tokens を尊重する
  • [修正] https://github.com/streamlit/streamlit/pull/15876 での @lukasma such による React Aria ダイアログ オーバーレイのスタッキングを修正
  • [修正] https://github.com/streamlit/streamlit/pull/15894 で @lukasma such によってウィジェットが再実行された後にスタックされる st.tabs パネル
  • [修正] https://github.com/streamlit/streamlit/pull/15889 で @lukasmauch による不安定な送信ボタンの欠落警告を削除
  • [修正] https://github.com/streamlit/streamlit/pull/15820 の @lukasmauch による pydeck チャートのツールチップ補間で HTML をエスケープする
  • [修正] https://github.com/streamlit/streamlit/pull/15912 の @sfc-gh-lwilby-1 によるフラグメントごとの run_every 自動再実行タイマーの重複排除
  • [修正] https://github.com/streamlit/streamlit/pull/15928 の @sfc-gh-lwilby-1 によりファイル アップローダーのドロップゾーンから冗長なキーボード タブ ストップを削除
  • [修正] https://github.com/streamlit/streamlit/pull/15947 で @lukasma such による PyArrow 25 スレッド初期化クラッシュを回避
  • RuntimeError を修正: https://github.com/streamlit/streamlit/pull/15949 の @chang-pro による Ctrl+C の _io.BufferedWriter 内の再入呼び出し
  • https://github.com/streamlit/streamlit/pull/15971 の @eeshsaxena により 1 京以上の値に対する simplify_number の IndexError を修正
  • [修正] https://github.com/streamlit/streamlit/pull/15851 の @lukasmauch による危険な st.link_button および st.image URL をサニタイズする
  • [修正] https://github.com/streamlit/streamlit/pull/15948 の @lukasmauch によるサーバー依存関係のメジャー バージョンの制限
  • [修正] https://github.com/streamlit/streamlit/pull/15932 の @sfc-gh-lwilby-1 によるフラグメント削除時の自動再実行を停止する
  • [修正] https://github.com/streamlit/streamlit/pull/15967 の @lukasma such によるスタイル選択ボックスの「結果なし」の空の状態
  • [修正] ポップオーバー内のオーバーレイ: https://github.com/streamlit/streamlit/pull/15961 の @sfc-gh-lwilby-1 によるスタックと解除
  • [修正] https://github.com/streamlit/streamlit/pull/15996 の @sfc-gh-lwilby-1 による st.selectbox の type-to-search を復元する
  • [修正] https://github.com/streamlit/streamlit/pull/15907 の @lukasma such による st.metric 面グラフの塗りつぶしベースラインを修正
  • [修正] https://github.com/streamlit/streamlit/pull/15951 の @lukasmauch による Windows ドライブ パスでのファイル ウォッチャーのクラッシュを防止
  • [修正] https://github.com/streamlit/streamlit/pull/15963 で @lukasma such によって生成された gitignore スニペット内のスキルのシンボリックリンクを無視する
  • [修正] selectbox filter_mode=None のモバイル キーボードを抑制 (https://github.com/streamlit/streamlit/pull/15962 の @lukasma such による)
  • [修正] https://github.com/streamlit/streamlit/pull/16013 の @lukasmauch によってフォームに最初に入力された数値入力値を送信します
  • [修正] https://github.com/streamlit/streamlit/pull/16040 の @lukasma such によるハッシュ フォールバック警告メッセージを改善
  • [修正] スキルのメタスキルをホイールにバンドルします。ローカルにインストールします (GitHub のダウンロードはありません) by @sfc-gh-nbellante (https://github.com/streamlit/streamlit/pull/16026)
  • [バグ修正] https://github.com/streamlit/streamlit/pull/16068 の @sfc-gh-dbyttow による st.echo 出力にデコレータを含める
  • [バグ修正] https://github.com/streamlit/streamlit/pull/16060 の @sfc-gh-dbyttow による列内の水平コンテナーのチェックボックスのマージンの不一致を修正 (#13162)
  • [バグ修正] https://github.com/streamlit/streamlit/pull/16067 の @sfc-gh-dbyttow によって、ダイアログ内のポップオーバー内のウィジェットが clickable にならない問題を修正

その他の変更点

  • [雑務] https://github.com/streamlit/streamlit/pull/15860 の @github-actions[bot] による絵文字/マテリアル アイコンの更新
  • [雑用] https://github.com/streamlit/streamlit/pull/15983 の @github-actions[bot] による絵文字/マテリアル アイコンの更新
  • [雑務] https://github.com/streamlit/streamlit/pull/16014 の @lukasmauch によるキャッシュツールを内部 TTLCache に置き換えます
