streamlit 1.54.0

ストリームリット 1.54.0

<!-- 1.54.0 の .github/release.yml の構成を使用して生成された Release note -->

何が変わったのか

重大な変更 🛠

  • https://github.com/streamlit/streamlit/pull/13142 の @lukasma such による実験的なクエリ パラメータを削除
  • https://github.com/streamlit/streamlit/pull/13626 の @lukasma such による非推奨の st.experimental_user コマンドを削除
  • https://github.com/streamlit/streamlit/pull/13628 の @lukasma such によって、add_rows の非推奨警告がブラウザに表示されるように設定します

新機能 🎉

  • https://github.com/streamlit/streamlit/pull/13558 で @lukasma such が選択した st.dataframe のメイン ID として key を使用します
  • https://github.com/streamlit/streamlit/pull/13559 で @lukasma such が選択した vega チャートのメイン ID として key を使用します
  • https://github.com/streamlit/streamlit/pull/13581 に @mayagbarnes による chartDivergingColors テーマ設定オプションを追加
  • https://github.com/streamlit/streamlit/pull/13549 の @lukasma such による st.date_input の最小値と最大値の動的変更を許可します
  • key が https://github.com/streamlit/streamlit/pull/13620 の @lukasma such によって提供されている場合、st.datetime_input の min_value と max_value を動的に変更できるようにします
  • パンダの 3.0 互換性を https://github.com/streamlit/streamlit/pull/13630 の @lukasma such によって準備します
  • key が https://github.com/streamlit/streamlit/pull/13611 の @lukasma such によって提供されている場合、st.radio オプションへの動的な変更を許可します
  • config.toml が https://github.com/streamlit/streamlit/pull/13625 で @lukasma such によって作成された場合の自動再実行をサポート
  • MultiselectColumn および ListColumn での錠剤のテキストの選択を許可 (https://github.com/streamlit/streamlit/pull/13663 の @lukasma such による)
  • ウィジェットをバインドしてパラメータをクエリするための準備 - パート 1 (@mayagbarnes 著、https://github.com/streamlit/streamlit/pull/13681)
  • feat(ロゴ): https://github.com/streamlit/streamlit/pull/13416 の @rahuld109 による st.logo にマテリアル アイコンと絵文字のサポートを追加
  • key が https://github.com/streamlit/streamlit/pull/13696 の @lukasma such によって提供されている場合、st.select_slider オプションへの動的な変更を許可します
  • https://github.com/streamlit/streamlit/pull/13472 に @karubian による「client.showErrorLinks` 設定オプション (#11238)」を追加
  • key が https://github.com/streamlit/streamlit/pull/13703 の @lukasma such によって提供される場合、st.pydeck_chart パラメーターへの動的な変更を許可します
  • https://github.com/streamlit/streamlit/pull/13739 の @mayagbarnes によるチャートのテーマ カラー構成への解決をサポート

バグ修正 🐛

  • https://github.com/streamlit/streamlit/pull/13590 の @sfc-gh-kmcgradiy による均一な列値による棒グラフのエラーを修正
  • [修正] https://github.com/streamlit/streamlit/pull/13589 の @sfc-gh-nbellante による st.chat_input のアップロード ファイルの最大幅を増やす
  • [修正] https://github.com/streamlit/streamlit/pull/13612 の @sfc-gh-bnisco によるマニフェスト スキャナーに防御チェックを追加
  • https://github.com/streamlit/streamlit/pull/13571 の @lukasmauch による Starlette の新しい認証機能のサポート
  • https://github.com/streamlit/streamlit/pull/13623 の @sfc-gh-dmatthews により、toolbarMode="viewer" の場合に開発者向けオプションを非表示にします
  • https://github.com/streamlit/streamlit/pull/13652 の @sfc-gh-kmcgradiy によるパラメータを含めるように SnowflakeConnection.query() キャッシュ キーを修正
  • https://github.com/streamlit/streamlit/pull/13659 の @sfc-gh-kmcgradiy によるスピナー コンテキストでのコンテナ要素のクラッシュを修正
  • https://github.com/streamlit/streamlit/pull/13665 で @lukasma such によってスノーフレーク接続が閉じられるという回帰を修正
  • https://github.com/streamlit/streamlit/pull/13674 で @kmcgradiy に置き換えたときに TransientNode が BlockNode をアンカーとしてキャプチャしない問題を修正
  • https://github.com/streamlit/streamlit/pull/13648 の @lukasma such によるカスタム オブジェクトの選択ボックスと複数選択のクリア選択を修正
  • https://github.com/streamlit/streamlit/pull/13695 で @lukasma such によって溶けた棒グラフ データを並べ替えるときの KeyError を修正しました。
  • https://github.com/streamlit/streamlit/pull/13653 の @sfc-gh-kmcgradiy によって cli ポータル要素を結合するときにモバイルでサイドバーが折りたたまれる問題を修正
  • [修正] https://github.com/streamlit/streamlit/pull/13720 の @sfc-gh-nbellante により、ワイルドカード アドレスを URL のローカルホストとして表示します

その他の変更点

  • [雑務] v1.53.0 を @github-actions[bot] によって https://github.com/streamlit/streamlit/pull/13588 でリリース
  • [雑用] https://github.com/streamlit/streamlit/pull/13676 の @github-actions[bot] による v1.53.1 をリリース

新しい貢献者

  • @sfc-gh-kmcgradiy が https://github.com/streamlit/streamlit/pull/13590 に初めて貢献しました
  • @rahuld109 が https://github.com/streamlit/streamlit/pull/13416 に初めて投稿しました
  • @rishi-kumar0612 が https://github.com/streamlit/streamlit/pull/13004 に初めて投稿しました
  • @karubian が https://github.com/streamlit/streamlit/pull/13472 に初めて投稿しました
