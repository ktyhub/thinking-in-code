langfuse v4.78.0

#ラングヒューズv4.78.0

何が変わったのか

機能

  • feat(web): EmptyState と @AbdallahAHO によるイラスト (https://github.com/langfuse/langfuse/pull/19864)
  • feat(ウェブ): @AbdallahAHO による怠惰な製品シーンを含む LangfuseIllustration (https://github.com/langfuse/langfuse/pull/19865)
  • feat(トピックス): https://github.com/langfuse/langfuse/pull/19947 の @LysanderKie によるトピック設定フローのフィルター トレース
  • feat(rbac): https://github.com/langfuse/langfuse/pull/19263 の @marksalpeter によるロール割り当てにメンバーシップをミラーリングします。
  • feat(rbac): https://github.com/langfuse/langfuse/pull/19517 の @marksalpeter によってユーザーおよびキー ポリシーに対して評価された USER api キー スコープを追加します。
  • feat(web): AI Gateway ナビゲーションを組織レベルで常に表示し、https://github.com/langfuse/langfuse/pull/19977 の @wochinge によってプロジェクトからリンクします。
  • feat(events-dispatch): 読み取り設定を所有し、https://github.com/langfuse/langfuse/pull/19894 の @LysanderKie による 60 秒の読み取りを許可します
  • feat(web): https://github.com/langfuse/langfuse/pull/19969 の @nimarb により、新しいプロジェクトと新しい組織のアクションをスイッチャー ヘッダーに移動
  • 偉業(実験): https://github.com/langfuse/langfuse/pull/18213 の @marliessophie による実験リスト ビューの行とツールヒントをクリーンアップ
  • feat(evals): https://github.com/langfuse/langfuse/pull/20001 の @wochinge による外部 HTTP コード eval ディスパッチャーを追加
  • 偉業(ai-gateway): Bedrock をあらゆる環境で利用できるようにする by @wochinge (https://github.com/langfuse/langfuse/pull/19999)
  • feat(スキル): https://github.com/langfuse/langfuse/pull/19996 の @tobi12345 による SKILL.md フロントマター キーでスキル リストをフィルタリングします。
  • feat(トピックス): https://github.com/langfuse/langfuse/pull/20008 の @LysanderKie による非一時的なトピックのセットアップ モデル テストの失敗をログに記録します。
  • 偉業(トピック): 各ルールのマップを連続マップとして毎晩再調整し、手動実行をスナップショットとして保持 (https://github.com/langfuse/langfuse/pull/19675 の @LysanderKie による)
  • feat(prompts): https://github.com/langfuse/langfuse/pull/20009 の @tobi12345 によるリクエスト スパンのタグ プロンプト キャッシュ結果
  • feat(スコア): https://github.com/langfuse/langfuse/pull/19997 の @marliessophie によるスコア追加メニューからスコア設定の詳細を表示します
  • feat(ai-gateway): どこでもカスタム モデルを提供し、https://github.com/langfuse/langfuse/pull/20014 の @wochinge によって接続を選択します。

修正

  • 修正 (Web): https://github.com/langfuse/langfuse/pull/19975 の @wochinge によって v4 移行バナーが点滅しないように、セッションからの Force-v3 フラグを解決します。
  • 修正 (ai-gateway): https://github.com/langfuse/langfuse/pull/19985 で @marcklingen によって切り詰められるのではなく、起動バナーの説明をラップする
  • 修正 (Web): https://github.com/langfuse/langfuse/pull/19988 の @nmtrang29 によるダッシュボード ウィジェットのギャップとページ パディングの一致
  • 修正 (Web): https://github.com/langfuse/langfuse/pull/19987 の @nmtrang29 により、複製されたダッシュボード上のウィジェットから Langfuse バッジをドロップしました
  • 修正(Web): https://github.com/langfuse/langfuse/pull/19989 の @nmtrang29 によってタイトルの後ろに山形のセクションを移動
  • 修正 (external-media-storage): IAM ロール認証をアップグレードとして表示し、https://github.com/langfuse/langfuse/pull/19992 の @wochinge による許可リストを尊重します
  • 修正 (Web): ゲートウェイ専用メンバーに AI ゲートウェイから抜け出す方法を提供 (https://github.com/langfuse/langfuse/pull/19995 の @wochinge)
  • fix(scores): https://github.com/langfuse/langfuse/pull/18852 で無効な保存行が @marliessophie によってフィルターされた場合に警告する
  • 修正 (トピック): https://github.com/langfuse/langfuse/pull/19972 の @hassiebp によるカスタム ベース URL を使用して、max_completion_tokens を OpenAI 接続に送信します
  • 修正(トピック): https://github.com/langfuse/langfuse/pull/20003 の @LysanderKie による自動ファセット サマリーにトレース名を保存
  • fix(query-ast): https://github.com/langfuse/langfuse/pull/19971 の @niklassemmler によるいくつかのリレーションを持つ SELECT 内の修飾されていない列を拒否する

パフォーマンス

  • perf(annotation-queues): https://github.com/langfuse/langfuse/pull/19949 の @marliessophie によるソートカバーインデックスの最初の ID によるページキューアイテム

雑用

  • 修正(deps): https://github.com/langfuse/langfuse/pull/19973 の @nimarb により undici を 7.30.2 にバンプ
  • 修正 (deps): AG-UI をアップグレードし、https://github.com/langfuse/langfuse/pull/19974 の @nimarb による Provider-utils を削除
  • chore(query-ast): https://github.com/langfuse/langfuse/pull/19807 の @niklassemmler による、より低いメタデータ条件とイベント述語の自由テキスト検索
  • 雑務(価格設定): https://github.com/langfuse/langfuse/pull/20000 の @langfuse-bot による Claude Fable 5.2 と Mythos 5.2 のデフォルト価格を追加
  • ci: https://github.com/langfuse/langfuse/pull/19970 で @niklassemmler によって SQL 同等のゴールデン テストをブロックする

フル Changelog: https://github.com/langfuse/langfuse/compare/v4.77.0...v4.78.0
