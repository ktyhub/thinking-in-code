langfuse v4.80.0

#ラングヒューズv4.80.0

何が変わったのか

機能

  • feat(clickhouse): https://github.com/langfuse/langfuse/pull/20049 の @Steffen911 により、デフォルトでリクエスト本文でクエリ パラメーターを送信します
  • feat(ai-gateway): https://github.com/langfuse/langfuse/pull/20086 の @wochinge により Google AI Studio をゲートウェイ プロバイダーとして追加します
  • feat(ai-gateway): https://github.com/langfuse/langfuse/pull/20112 の @wochinge により、名前を「接続とモデル」に変更し、接続がない場合は「モデル」タブを非表示にしました
  • feat(in-app-agent): Halo のセッション メニューに「セッション リンクのコピー」を追加し、HIPAA でセッション リンクを非表示にします (https://github.com/langfuse/langfuse/pull/20103 の @nimarb により)
  • 特技(ネイティブ): https://github.com/langfuse/langfuse/pull/19955 の @sumerman によるドキュメント ツリーなしで型付き OTLP エンベロープをデコードします
  • 特技(スキル): スキルのサイズとファイル数の制限を https://github.com/langfuse/langfuse/pull/20119 の @tobi12345 によって構成可能にします
  • feat(ネイティブ): https://github.com/langfuse/langfuse/pull/19956 の @sumerman により、ClickHouse スキーマから所有されている OTEL 行を導出します。
  • feat(トピックス): https://github.com/langfuse/langfuse/pull/19120 の @LysanderKie によりトレース テーブルをトピックでフィルターし、トピックを列として表示します
  • 特技(スキル): 未保存のスキルドラフトをセッションストレージに保存 (https://github.com/langfuse/langfuse/pull/20122 の @tobi12345 による)
  • feat(prompts): API および https://github.com/langfuse/langfuse/pull/20126 の @tobi12345 による MCP を介してプロンプト バージョンからラベルを削除できるようにします
  • feat(ai-gateway): https://github.com/langfuse/langfuse/pull/20085 の @wochinge により Microsoft Azure をゲートウェイ プロバイダーとして追加します
  • feat(課金): https://github.com/langfuse/langfuse/pull/19948 の @marliessophie によるカットオフからの修正スコアをカウントします
  • feat(native): https://github.com/langfuse/langfuse/pull/19957 の @sumerman による OTEL メタデータと評価属性の正規化
  • feat(ai-gateway): https://github.com/langfuse/langfuse/pull/20135 の @wochinge によるゲートウェイ キー作成ダイアログを再設計
  • feat(ai-gateway): 接続ダイアログのフッターに接続テストのステータスを表示 by @wochinge (https://github.com/langfuse/langfuse/pull/20127)
  • feat(トピックス): https://github.com/langfuse/langfuse/pull/20083 の @LysanderKie によってレンダリングされたトピック テキストからのすべてのトピック パスを要約します。
  • feat(native): https://github.com/langfuse/langfuse/pull/19958 の @sumerman による、ツール定義と所有 OTEL 値の呼び出しを正規化します。
  • 機能 (モニタリング): ウィンドウ、プロジェクト サイズ、アクションごとのタグ クエリとキューのレイテンシ メトリクス (https://github.com/langfuse/langfuse/pull/19980 の @marksalpeter による)
  • feat(トピックス): デフォルトの空のライブスキャンへの新しいスキャン (https://github.com/langfuse/langfuse/pull/20160 の @LysanderKie による)
  • feat(ai-gateway): https://github.com/langfuse/langfuse/pull/20170 の @wochinge による OpenRouter 接続のカスタム ベース URL をサポート
  • feat(ai-gateway): https://github.com/langfuse/langfuse/pull/20139 の @wochinge によりゲートウェイ キーをモデル パターンに制限します
  • 功績: https://github.com/langfuse/langfuse/pull/20151 の @jordibosch20 により UX に API キー マスキングを追加
  • 偉業(トピックス): https://github.com/langfuse/langfuse/pull/20152 の @nimarb によるリストおよびツリーマップ ビューのサイズ変更可能な分割
  • feat(ai-gateway): https://github.com/langfuse/langfuse/pull/20142 の @wochinge による既存のゲートウェイ キーの名前、メタデータ、モデルを編集します
  • 特技(スキル): スキルを作成、編集、改善するための Halo エントリ ポイントを追加 (https://github.com/langfuse/langfuse/pull/20179 の @tobi12345 による)

修正/改善

  • fix(auth): https://github.com/langfuse/langfuse/pull/20078 の @Steffen911 によって発行されたユーザー ID にセッションをバインドします。
  • 修正(ai-gateway): https://github.com/langfuse/langfuse/pull/20123 で @wochinge によってコピーされる前に、「+ 追加」図ラベルを削除し、カスタム バッジを表示します。
  • fix(evals): TypeSafe デシジョンモデル client のレート制限でフェイルファーストする (https://github.com/langfuse/langfuse/pull/20125 の @wochinge による)
  • 修正 (トピック): https://github.com/langfuse/langfuse/pull/20118 の @LysanderKie により、一致するすべてのルールのマップに新しい概要を割り当てます
  • 修正（トピック）: https://github.com/langfuse/langfuse/pull/20113 の @LysanderKie によるライブマップの空の状態ではなく、1 回限りのスキャン独自の状態を表示
  • style(evals): https://github.com/langfuse/langfuse/pull/20089 の @marliessophie によるエバリュエーター設定画面をクリーンアップ
  • 修正(トピック): https://github.com/langfuse/langfuse/pull/20128 の @LysanderKie によるトレース ID の代わりにトピック フィルターを使用してトレースでトピックを開く
  • 修正 (認証): SSO ドメイン ユーザーを招待から SSO に送信し、https://github.com/langfuse/langfuse/pull/19705 で @Steffen911 によってサインアップする
  • fix(worker): データセット内のストリーム行は、https://github.com/langfuse/langfuse/pull/20131 の @Steffen911 によってアイテム バックフィル挿入を実行します
  • 修正 (ウェブ): https://github.com/langfuse/langfuse/pull/20144 の @nkabardin によるサイドバー組織スイッチャー プラン バッジのレンダリング ループを停止
  • 修正 (ダッシュボード): 分析結果に上限を設け、https://github.com/langfuse/langfuse/pull/20143 の @sumerman による SSE バックプレッシャーを尊重する
  • 修正（トピック）: https://github.com/langfuse/langfuse/pull/20147 の @LysanderKie による任意のワーカーからのシード ルール設定トレース
  • 修正（実験）: https://github.com/langfuse/langfuse/pull/20148 の @marliessophie により、結果セルを常に JSON としてレンダリングする
  • 修正(トピック): https://github.com/langfuse/langfuse/pull/20129 の @LysanderKie によるすべてのルールの割り当ての概要行をフィルターします。
  • 修正（トピック）: https://github.com/langfuse/langfuse/pull/20161 の @LysanderKie が受け入れるフィルター演算子のライブ スキャンのみを提供
  • 修正 (トピック): ルール設定シードを 60 秒以上分散する (https://github.com/langfuse/langfuse/pull/20168 の @LysanderKie による)
  • 修正 (ワーカー): https://github.com/langfuse/langfuse/pull/20138 の @wochinge によるバッチ観察の評価をページングして再開します
  • 修正 (トピック): https://github.com/langfuse/langfuse/pull/20153 の @nimarb によるトレース トピック カード内の質問が長いトピック名で覆われないようにします。
  • 修正 (ウェブ): アカウント削除に 30 秒のトランザクション予算を与える (https://github.com/langfuse/langfuse/pull/20105 の @nimarb による)

雑用

  • test(mcp): https://github.com/langfuse/langfuse/pull/20116 の @wochinge による evalDefaultModel:CUD なしのデフォルト評価モデルの書き込みを拒否します
  • test(evals): https://github.com/langfuse/langfuse/pull/20132 の @wochinge による実験データセット ルールのテナントとスコープ ネガをカバーします。
  • refactor(query-ast): https://github.com/langfuse/langfuse/pull/20070 の @niklassemmler によって AST を通じてビルドされたダッシュボード v2 観察をコンパイルします。
  • ci: minio ヘルスチェックを強化し、https://github.com/langfuse/langfuse/pull/19805 の @nkabardin による golang-移行ダウンロード
  • テスト(クエリ): ダッシュボードの SQL キーワード アサーションの大文字と小文字を区別しないようにします (https://github.com/langfuse/langfuse/pull/20146 の @niklassemmler により)
  • 雑用(deps): https://github.com/langfuse/langfuse/pull/20167の@github-actions[bot]により@hono/node-serverを2.1.6にバンプ
  • テスト (ai-gateway): OpenRouter カスタム エンドポイントでのプライベート ネットワークの拒否をカバー (https://github.com/langfuse/langfuse/pull/20177 の @wochinge による)
  • test(query): https://github.com/langfuse/langfuse/pull/20176 の @niklassemmler によってイベント テーブル クエリ ビルダーのサーバーテストを再度実行します。
