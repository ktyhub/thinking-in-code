#ラングヒューズv4.79.0

何が変わったのか

機能

  • feat(ai-gateway): https://github.com/langfuse/langfuse/pull/20002 の @wochinge により、OpenRouter をプレリリース ゲートウェイ プロバイダーとして追加
  • 功績: https://github.com/langfuse/langfuse/pull/19981 の @marksalpeter によりモニターに SUBSTITUTE_OK ノーデータ モードを追加
  • feat(ai-gateway): https://github.com/langfuse/langfuse/pull/20004 の @wochinge により xAI をプレリリース ゲートウェイ プロバイダーとして追加
  • feat(audit-logs): https://github.com/langfuse/langfuse/pull/19759 の @Steffen911 による MCP ツールの読み取りアクセス イベントを記録します。
  • 功績: https://github.com/langfuse/langfuse/pull/19582 の @jordibosch20 による isAdmin フラグを削除
  • feat(audit-logs): https://github.com/langfuse/langfuse/pull/20024 の @Steffen911 による、自己ホスト型エンタープライズ インストールの監査イベントをステージングしてリレーする
  • feat(ai-gateway): https://github.com/langfuse/langfuse/pull/20020 の @wochinge により、Vercel AI Gateway をプレリリース ゲートウェイ プロバイダーとして追加します
  • feat(ai-gateway): OpenRouter、xAI、Vercel AI Gateway を https://github.com/langfuse/langfuse/pull/20028 の @wochinge によって一般公開します
  • feat(web): プロジェクトが https://github.com/langfuse/langfuse/pull/19911 の @annabellscha によって作成されるときに、デフォルトのスコア構成をシードします。
  • feat(ai-gateway): https://github.com/langfuse/langfuse/pull/20030 の @wochinge によりカスタムベース URL を一般公開
  • feat(ai-gateway): https://github.com/langfuse/langfuse/pull/20058 の @wochinge により、すべてのデプロイメントで追加のヘッダーを利用できるようにします
  • feat(ai-gateway): OpenAI Decisions を独自の api 形式としてルーティング (https://github.com/langfuse/langfuse/pull/20027 の @wochinge による)
  • feat(mcp): https://github.com/langfuse/langfuse/pull/20032 の @wochinge によるデフォルトの評価モデルを管理するツールを追加
  • feat(worker): https://github.com/langfuse/langfuse/pull/20011 の @AbdallahAHO によるコア データ エクスポートへの設定と機能テーブルのエクスポート
  • feat(ai-gateway): OpenAI Decisions を Vercel 経由でルートする (https://github.com/langfuse/langfuse/pull/20069 の @wochinge による)
  • 功績(トピックス): https://github.com/langfuse/langfuse/pull/19889 の @nimarb による LLM コストの表示の改善
  • feat(prompts): https://github.com/langfuse/langfuse/pull/20075 の @tobi12345 によるページネーションとフィルターを使用したタグ リスト エンドポイント スパン
  • feat(価格設定): https://github.com/langfuse/langfuse/pull/20062 の @wochinge による、trafficType サービス層を介した Vertex AI Flex PayGo Gemini 通話の価格
  • feat(evals): https://github.com/langfuse/langfuse/pull/20006 で @marliessophie によるトレース トランスクリプト評価をスケジュールする
  • feat(ai-gateway): API 形式で接続モデルをフィルタリングし、https://github.com/langfuse/langfuse/pull/20074 の @wochinge でツールバーを整理します
  • 機能 (トピック): 複数のライブ ルール、1 回限りの分析、マップ ピッカー、リスト ビュー (https://github.com/langfuse/langfuse/pull/19991 の @nmtrang29 による)
  • feat(ai-gateway): https://github.com/langfuse/langfuse/pull/20033 の @wochinge により OpenAI Embeddings を独自の api 形式としてルーティングします
  • feat(ネイティブ): https://github.com/langfuse/langfuse/pull/19951 の @sumerman により、JavaScript JSON 値セマンティクスを Rust に保持
  • feat(native): https://github.com/langfuse/langfuse/pull/19954 で @sumerman によって OTLP 属性を所有値に変換します
  • 偉業(トピック): トレース ディスパッチと https://github.com/langfuse/langfuse/pull/20093 の @LysanderKie による夜間の再調整ジョブを通じてルールの最初のマップを構築する

修正/改善

  • 修正(ai-gateway): https://github.com/langfuse/langfuse/pull/20025 の @wochinge による削除ダイアログの再生にプロバイダー名が表示されないようにする
  • fix(experiments): https://github.com/langfuse/langfuse/pull/19942 の @wochinge によってデータセットをスコープとするすべての評価ルールをロードします
  • fix(filters): https://github.com/langfuse/langfuse/pull/20029 の @niklassemmler による null フィルターの値をオプションにします
  • fix(trace-dispatch): https://github.com/langfuse/langfuse/pull/20047 の @LysanderKie によって記録開始が 1 年以上経過しているトレースを除外します。
  • 修正(ai-gateway): https://github.com/langfuse/langfuse/pull/20056 で @hassiebp による資格情報の代わりにプロバイダー設定接続を呼び出す
  • 修正 (ai-gateway): distrust で https://github.com/langfuse/langfuse/pull/20038 の @maxdeichmann によって emSign 証明書パスが侵害されました
  • fix(datasets): https://github.com/langfuse/langfuse/pull/20060 の @marliessophie による ID によって最新の開いているデータセット項目を返します
  • fix(ai-gateway): https://github.com/langfuse/langfuse/pull/20067 の @hassiebp によってキー所有者の組織ロールが変更されたときに、キャッシュされた解決コンテキストを削除します
  • perf(prompts): https://github.com/langfuse/langfuse/pull/20043 の @tobi12345 による 1 つのクエリでプロンプトの依存関係を取得します
  • 修正 (deps): https://github.com/langfuse/langfuse/pull/20071 の @nimarb により、nodemailer を 10.4.1 に、fast-xml-parser を 5.12.0 にバンプします
  • 修正 (ai-gateway): https://github.com/langfuse/langfuse/pull/20072 の @nimarb による既存の取り込みプロジェクトの前に「the」を使用します
  • fix(ai-gateway): モデル カタログ キャッシュのバージョンを変更し、https://github.com/langfuse/langfuse/pull/20073 の @wochinge による意思決定テストの質問に名前を付けます
  • fix(sessions): https://github.com/langfuse/langfuse/pull/19847 の @nimarb による最後の行のサイドバー行ホバー サイズと一致する
  • fix(sec-dependabot): https://github.com/langfuse/langfuse/pull/20076 の @nimarb によるコード スキャン時に 1 日 2 回実行されます。
  • 修正 (ウェブ): AI 機能のロック アイコンをスイッチの横に配置 (https://github.com/langfuse/langfuse/pull/20077 の @nimarb による)
  • fix(evals): https://github.com/langfuse/langfuse/pull/20082 の @wochinge による正規アウトバウンド URL パーサーを使用して外部コード評価エンドポイントを解析します
  • 修正(api): https://github.com/langfuse/langfuse/pull/19883 の @nkabardin によるフィルターを含むトレースの完全なメタデータを読み取る
  • fix(web): https://github.com/langfuse/langfuse/pull/19994 の @marksalpeter によって空のフィルター パラメーターがデフォルトのビューに置き換えられないようにする
  • 修正 (ダッシュボード): https://github.com/langfuse/langfuse/pull/20115 の @Steffen911 によるスコア名フィルターでブール値のスコア名を提案
  • 修正 (Web): 組織スイッチャーをサイドバーの上部に移動し、https://github.com/langfuse/langfuse/pull/20012 の @nmtrang29 によって両方のスイッチャーを整理します。

雑用

  • docs(api): フィルター条件は、同じフィールドのクエリ パラメーターのみを https://github.com/langfuse/langfuse/pull/18845 の @HardMax71 に置き換えます。
  • chore(deps): https://github.com/langfuse/langfuse/pull/19830 の @dependabot[bot] により、rust 依存関係グループの /ai-gateway で 1 つのディレクトリにある uuid を 1.28.0 から 1.29.0 にバンプします
  • ci(deploy): https://github.com/langfuse/langfuse/pull/20017 の @Steffen911 による静的キーの代わりに、GitHub OIDC を介して AWS デプロイ ロールを引き受けます。
  • refactor(query-ast): v2 観測ビューを AST 式として入力します (https://github.com/langfuse/langfuse/pull/19908 の @niklassemmler による)
  • docs(api): v2 観測フィルターのドキュメントを、https://github.com/langfuse/langfuse/pull/20026 の @niklassemmler によるサーバーの動作と調整します。
  • chore(deps): https://github.com/langfuse/langfuse/pull/20039 の @maxdeichmann による 11.0.1 へのミニマッチのバンプ
  • chore(deps): https://github.com/langfuse/langfuse/pull/20041 の @maxdeichmann による 16.4.5 の隣のバンプ
  • chore(deps): https://github.com/langfuse/langfuse/pull/20042 の @maxdeichmann による 14.0.3 へのバンプ グロブ
  • chore(worker): https://github.com/langfuse/langfuse/pull/19950 の @sumerman による OTEL インジェストの遅延評価スケジューリングを共有
  • test(trace-dispatch): https://github.com/langfuse/langfuse/pull/20048 の @LysanderKie によるディスパッチャのイベント ディスパッチ キュー パスをカバーします
  • 雑務(価格設定): GPT-6 Cyber、GPT-5.6 Cyber、GPT-5 Search API、および GPT Audio の価格を追加 (https://github.com/langfuse/langfuse/pull/20015 の @hassiebp により)
  • chore(deps): https://github.com/langfuse/langfuse/pull/20031 の @maxdeichmann により、@google-cloud/storage を 8.4.0 に、dockerode を 5.0.1 にバンプします
  • refactor(ai-gateway): https://github.com/langfuse/langfuse/pull/20063 の @wochinge による応答ごとにプロバイダー要求 ID を 1 回読み取ります
  • リファクタリング(ai-gateway): https://github.com/langfuse/langfuse/pull/20064 の @wochinge による ApiFormat でのキー使用法の投影
  • chore(deps-upgrader): https://github.com/langfuse/langfuse/pull/20095 の @nimarb によるセキュリティ メンテナー構成とトレースを更新します
  • refactor(query-ast): https://github.com/langfuse/langfuse/pull/19983 の @niklassemmler による AST を介してイベント行選択をコンパイルします。
  • 雑務 (価格設定): claude-mythos-5 と claude-mythos-5-1 の拡張 Bedrock matchPatterns by @langfuse-bot (https://github.com/langfuse/langfuse/pull/20109)
  • chore(deps): https://github.com/langfuse/langfuse/pull/20104 の @nimarb による 19.3.1 とその隣の 16.4.6 に反応します。
