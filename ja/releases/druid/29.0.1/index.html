#ドルイド 29.0.1

Apache Druid 29.0.1 は、Druid 29.0.0 リリースのいくつかの問題を修正するパッチ リリースです。

バグ修正

  • 文字列と文字列配列が混在していないことを検証するために、INSERT と REPLACE の型検証を追加しました #15920
  • 同時置換 により、スーパーバイザー #15995 を使用して保留中の Peon セグメントをアップグレードできるようになりました。
  • データソースの名前を含む文字列を返すように targetDataSource 属性を変更しました。これにより、Druid 29.0.0 で INSERT および REPLACE MSQ クエリに導入された重大な変更が元に戻されます #16004 #16031 ※配信Docker画像#15968のサイズを縮小しました
  • CSV、TSV、JSON の文字列値フィールドなどからの文字列入力が、LONG または BIGINT として入力された場合に null 値として取り込まれるという SQL ベースの取り込みの問題を修正しました #15999
  • Web コンソールで生成された Kafka スーパーバイザー仕様の flattenSpec が間違った場所にある問題を修正しました #15946
  • null 値を null 以外の値に変換する式で、場合によっては値が null と誤ってみなされる式仮想列インデックスのフィルターの問題を修正しました #15959
  • 受信データを解析できない場合にデータ ローダーがクラッシュする問題を修正しました #15983
  • Web コンソールでの DOUBLE 型検出を改善 #15998
  • Web コンソールで生成されたクエリは、配列の使用を明示的にオプトインした場合にのみコンテキスト パラメーター arrayIngestMode を array に設定するようになりました #15927
  • Web コンソールには、EXTERN 関数 #15969 を通じて外部宛先に書き込む MSQ クエリの結果が表示されるようになりました。

互換性のない変更

EXPLAIN クエリの targetDataSource への変更

Druid 29.0.1 には、targetDataSource の動作を 28.0.0 以前の状態に戻す重大な変更が含まれています。これは、Druid 29.0.0 および 29.0.0 とは異なります。 29.0.0 では、targetDataSource はデータソース名を含む JSON オブジェクトを返します。他のすべてのバージョンでは、targetDataSource はデータソースの名前を含む文字列を返します。

29.0.0 以外のバージョンからアップグレードする場合、動作に変更はありません。

29.0.0 からアップグレードする場合、これは互換性のない変更です。

#16004

依存関係の更新

  • PostgreSQL JDBC ドライバーのバージョンを 42.7.2 #15931 に更新しました
