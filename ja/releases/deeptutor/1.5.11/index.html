#ディープチューター v1.5.11

ディープチューター v1.5.11 Release Notes

発売日: 2026.08.10 v1.5.10 は、リクエストが保留されている下のパスに関するものでした。これは、答えがまだ書かれている間に何が起こるかについてです。ツール呼び出しとラウンドを共有する散文はトレースに消え、切り捨てられた世代は終了したと判断するモデルとして読み取られ、ローカル インデックス作成は他の必要なものすべてをイベ​​ント ループ上に置きました。また、設定ストリップは、[モデル] ページで既に表示されている内容の再説明を停止し、他には何も行われていない 1 つの数値、つまり DeepTutor が実際にメモリに費やしている数値を表示し始めます。ドロップイン — 移行や再インデックスの必要はありません。

新機能

ツール呼び出しの周囲のテキストが失われることはなくなりました

DeepSeek の Anthropic 互換エンドポイントは、ユーザー向けの散文と DSML ツール呼び出しマークアップを単一のコンテンツ ストリームにインターリーブします。以前の処理はオール・オア・ナッシングでした。ラウンドのコンテンツ チャネルに DSML マークアップが表示されると、そのラウンドの残りの部分は思考チャネルに転送されるため、モデルがその呼び出しに関して記述した説明は回答から消えます。ストリーミング フィルターは、DSML エンベロープと invoke ブロックのみを段階的に削除するようになりました。通話前、通話中、通話後のテキストがストリーミングされ、応答の一部として保持されます。不完全な呼び出しは飲み込まれるのではなくフラッシュ時に逐語的に解放され、512 文字の上限は、通常の散文の迷走 < によってライブ ストリームが閉じ括弧を永遠に待たせることができないことを意味します。

DSML 配列とオブジェクト引数が正しくデコードされる

DeepSeek は基本的に、含まれるすべての DSML パラメーター string="true"、JSON 配列およびオブジェクトをマークするため、コンテナー引数は JSON の文字列としてツールに届きます。パラメーターのデコードでは、宣言されたツール スキーマが参照されるようになりました。スキーマの型が array または object であるパラメーターは、ペイロードが実際に一致するときに解析され、それ以外の場合はプロバイダーの文字列コントラクトが優先されます。スキーマ カタログは、プロバイダーがネイティブ tools を拒否し、ループが DSML にフォールバックする場合でも保持されます。これはまさにパーサーがスキーマ カタログを必要とするときです。

切り捨てられた世代は継続を要求します

length フィニッシュは不完全な生成であり、モデルが停止を選択したわけではありません。しかし、フィニッシュとして扱われたため、返信は文の途中で終了しました。ループは表示されているプレフィックスを保持して継続を要求し、組み立てられた応答はプレフィックスを永続性と SDK に伝えます。これを安全にするためにラウンドの予算が再構成されました。つまり、探査ラウンド、次に小さな境界のある決済ウィンドウ、そして単一の工具を使用しないハード仕上げです。そのため、繰り返される切り捨てと不正な工具サイクルは、exploration + 4 という 1 つの絶対的な上限を共有します。

設定でのライブメモリ使用量

設定ステータス ストリップには、バックエンド、LLM、埋め込み、および検索が含まれていました。そのうち 3 つは、モデル ページとチャット ページがすでに所有しているものを再表示しました。設定ページには表示されない 2 つの実行時事実が表示されるようになりました。バックエンドが起動しているかどうか、および DeepTutor プロセス ツリー全体 (バックエンド、Next.js サーバー、および生きているサンドボックスやサブエージェント CLI など) にわたる常駐メモリです。プロセスごとのインライン分割と、制限の 3 分の 2 を超えるとオレンジ色に変わる圧力ドットが表示されます。新しい GET /api/v1/system/memory によって提供されます。 psutil はツリーを読み取り、/proc フォールバックで遅延インポートされるため、ホイールが欠落しているとアプリではなくストリップにコストがかかります。非管理者およびツリーを読み取れないプラットフォームでは、{available: false} が取得され、ストリップは取得されません。

ローカル LightRAG インデックス作成により、他のすべての機能が停止することがなくなります

RAG-Anything のローカル ストレージ バックエンドは、非同期メソッド内から同期グラフ マージと JSON シリアル化を実行するため、サービス イベント ループでドキュメントのインデックスを作成すると、その期間中、無関係な API および LLM の動作がフリーズしました。インデックス作成は、ワーカー スレッド独自のイベント ループで実行されるようになりました。LLM、ビジョン、埋め込みコールをリクエストのループに転送する狭いブリッジを使用して、呼び出し元のコンテキストのコピーを保持するため、リクエストのローカル モデルとユーザー設定が表示されたままになります。リモートの LightRAG サーバーは影響を受けません。

マスタリーはモデルの再話ではなく、持続的な質問から機能します

提示された質問は、プロンプト、タイプ、オプションのラベル/本文マップなどの小さな公開契約に投影され、登録、プレゼンテーション、採点によって共有され、期待される回答はサーバー側に留まります。 ask_user は、モデルが再作成したデータを表示するのではなく、その永続化された状態をレンダリングするため、学習者に表示される選択肢が採点対象の選択肢となります。登録では、矛盾するものを黙って受け入れるのではなく、クイズの形状を検証します。欠落しているタイプはペイロードから推測され、short/open の質問はオプションを拒否し、選択質問には裸の A/B/C ラベルの代わりに実際のオプション本体が含まれている必要があります。

各種詰め合わせ

  • 接続されたナレッジ ベースは、ローカル ファイルについて正直に回答します。 リンクされた外部リソースには、DeepTutor が管理する raw/ ディレクトリがありません。そのファイルをリストすると、コレクションを作成する代わりに空のコレクションが返され、ローカル ファイルを必要とするエンドポイントは明示的な 409 を返します。
  • 生成された出力アーティファクトはリクエスト スコープで提供されます。 新しい /api/outputs エンドポイントは 1 回の操作でパスを解決して承認し、リクエスト ユーザーがいない場合は 404 でフェールクローズされるため、認証コンテキスト回帰によって管理者のアーティファクトを通常のリクエストに渡すことができません。
  • iframe の拡大と縮小を視覚化 - 高さブリッジは、ホストがすでに伸ばしたルートの高さの代わりにボディの内容を測定し、レポートを 1 つのアニメーション フレームに結合します。
  • チャット ページのモデル リストは 1 回フェッチされます。 オプションの読み込みはシングルフライト重複除外を備えたフックに移動されたため、同時マウントとタブ フォーカスの更新で同一のリクエストがスタックされなくなりました。

アップグレードに関する注意事項

pip install -U deeptutor; Docker ユーザーは ghcr.io/hkuds/deeptutor:latest を引きます。スキーマの変更、インデックスの再作成、移行は必要ありません。

  • psutil は新しい依存関係であり、アップグレードとともにインストールされます。これは、/proc フォールバックの背後で遅延的にインポートされます。環境がそれを提供できない場合、メモリ ストリップは非表示のままで、他には何も変更されません。 フル Changelog: https://github.com/HKUDS/DeepTutor/compare/v1.5.10...v1.5.11
