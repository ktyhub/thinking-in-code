DeepTutor v1.6.0

ディープチューター v1.6.0

#ディープチューター v1.6.0 Release Notes 発売日: 2026.08.27 v1.5.17 はパートナーを個人化し、ナレッジ ベースで GitHub を追跡できるようにしました。 v1.6.0 は、ソースに忠実な読書、コースとリトル チューター スレッド、質問モード、限定された Web ソース同期、読者の学習状態を共有せずに共有される書籍など、学習ワークスペースの残りの部分を接続します。既存のデータはそのまま残ります。マルチユーザー管理者は、必要な場合にブックへのアクセスを許可するだけで済みます。

新機能

Immersive Reading が完全な読書家になる

EPUB は、形式を認識したアウトラインと保存された読み取り位置を備えた、ソースに忠実なビューで PDF を結合します。 W3C テキスト セレクターはリフローを通じてハイライトを付加したままにし、Recogito は注釈をレンダリングし、抽出されたテキスト ビューは永続的なタイポグラフィとカラー コントロールを取得し、インストールされた読み取り拡張機能は、制限されたプロトコルを通じて検証された表示テキストまたは選択内容のみを受け取ります。

コース、小さな家庭教師、質問する

ラーニング スペースでは、固定、アーカイブ、移動、フィルター、およびネストされた講師スレッド コントロールを使用して、会話をコースに編成できるようになりました。会話内のテキストを選択すると、親の下に留まりコースを継承する、ソースに基づいた独立した Little Tutor スレッドが開きます。 質問する は、コンテキストを認識した説明カードから始まり、回答から元のリクエストを完了します。

ナレッジベースはドキュメントサイトを追跡します

GitHub リポジトリに加えて、KB は明示的なクロール深度とページ数制限を備えたドキュメント URL を登録できます。オンデマンド同期のハッシュ差分により、インデックスを再作成する前にページが追加、変更、削除されました。 Serply は Web、ニュース、学者の検索モードを追加し、互換性のある OpenAI Responses モデルはネイティブのサーバー側 Web 検索を使用できます。

共有ブックで学習をプライベートに保ちます

管理者は、正規のブックをユーザーごとに none、read、または共同 edit として共有したり、個人のブックの作成を個別に制御したり、削除を管理者のみに限定したりできます。進行状況、ブックマーク、クイズの試行、ページ チャットのリンク、およびレビュー可能なラーニング キャプチャの受信箱は、読者ごとに非公開のままです。共有編集ではリビジョン チェックが使用されるため、共同編集者を上書きするのではなく、古いエディターが更新されます。

読書、個別指導、長時間セッションの信頼性

リーダーのアウトラインと順次ナビゲーションは、形式が正しくない、またはタイムアウトしても、その場所を維持します。 読み取り拡張機能は分離されたままで、注釈アンカーは見出しやリフローに耐えます。選択講師のグラウンディングとクイズのフォローアップは継続的に行われます。 Mastery はプレーンテキストのクイズのフォールバックを拒否し、説明と回答を区別します。会話の圧縮は制限された予算内に収まり、デコードされた非表示の Unicode コントロールが表示に漏れることはなくなりました。

プロバイダーとプラットフォームの強化

llama.cpp は実際のコンテキスト ウィンドウを報告し、Kimi コーディング モデルは互換性のあるパラメーターを受け取り、LightRAG は非対称埋め込みコンテキストを保持し、Codex TLS 障害はフェールクローズされたままになります。 Windows ランナー、ツール、パス、テストの互換性が広範囲にわたってクリーンアップされました。リリース ワークフローは、最新の安定リリースを置き換える前に、誤解を招くタグやバージョン以外のタグを拒否するようになりました。

アップグレードに関する注意事項

pip install -U deeptutor; Docker ユーザーは ghcr.io/hkuds/deeptutor:latest を引きます。手動での移行やインデックスの再作成は必要ありません。

  • 共有管理ブックのデフォルトはアクセス権なしです。 既存の個人ブックは非公開のままで変更されません。マルチユーザー展開では、/admin/users を開いてユーザーを展開し、読み取りまたは編集する必要がある管理書籍に対してのみ 書籍アクセス を構成します。
  • 共有編集は楽観的です。 別の編集者が最初にブックの改訂を進めた場合は、ブックを更新して変更を再度適用します。 DeepTutor は新しいリビジョンをサイレントに上書きしません。
  • Web ソースと GitHub ソースはオプトインのままです。 ソースを登録して同期を実行するまで、既存のナレッジ ベースは変更されません。
  • 検索はオプションのままです。 deeptutor init 中に Serply を選択するか、後で 設定 → モデル → 検索 で設定します。既存の検索設定は引き続き機能します。
  • 英語と中国語のガイドを deeptutor.info でまとめて更新しました。 フル Changelog: https://github.com/HKUDS/DeepTutor/compare/v1.5.17...v1.6.0
