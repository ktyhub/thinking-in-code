DeepTutor v1.5.6

#ディープチューター v1.5.6

ディープチューター v1.5.6 Release Notes

発売日: 2026.07.29 v1.5.5 のフォローアップで、開始されたものは完了します。出荷された Codex サインインは、リモートまたはコンテナ化された展開で実際に完了し、パートナーや管理者以外のユーザーも対象になります。それに加えて、知識ベースは Tencent IMA に既に保存されているライブラリを指すことができ、会話で生成されたファイルはトランスクリプトに隠れなくなり、日本の本には中国語のクイズが含まれなくなります。ドロップイン - 移行はありません。

新機能

Tencent IMA ライブラリを接続する

ナレッジ ベースは、DeepTutor が構築するインデックスではなく、Tencent IMA でキュレーションするライブラリへのポインタになることができます。これは lightrag-server の形に正確に従います。何もコピーされず、ローカルに保存されません。ドキュメントは IMA に追加され、取得は IMA の OpenAPI を呼び出し、チャット ループは引き続き応答を書き込みます。資格情報 (client_id + api_key) とライブラリ ID は KB ごとに有効であるため、共有展開では、各ユーザーは 1 つのグローバル キーではなく自分の IMA アカウントを介して取得し、接続は自己完結型であり、最初に入力する設定画面はありません。接続するとライブラリが 1 回プローブされるため、ID の入力ミスは、その後のクエリごとにサイレントに実行されるのではなく、接続時に失敗します。

生成されたファイル。再度見つけることができます。

家庭教師が作成したファイルには、それを作成した 1 つのアシスタント バブルを介してのみアクセスできるため、デッキやスプレッドシートを再び見つけるには、トランスクリプトをスクロールする必要がありました。 [アクティビティ] パネルでは、会話が アップロードしたものから *生成されたものを分割するようになりました。生成されたファイルには、添付ファイルの上に独自のカードが表示され、ファイルがデータ ルートの下にある場所を示すサイズとホバー タイトルが表示されます。行は既存のビューアで開くパスを再利用します。

リモート Codex サインインが完了しました

v1.5.5 は、リモート ボックスでは代わりにサーバーからサインインするという警告付きで OpenAI Codex OAuth を出荷しました。その警告はなくなりました。ブラウザの localhost とサーバーの localhost は異なるマシンであるため、リバース プロキシだけではコールバックを実行できません。 DeepTutor は、Web オリジンを介して状態検証ブローカーに正確なコールバック パスのみを転送するようになり、設定カードと CLI は、実際のコールバック アドレス、SSH トンネル コマンド、明示的な承認アクション、およびページのリロード後も存続するカウントダウンを出力します (#716)。 2 つのフォローアップにより、展開上の他の全員が機能するようになります。コールバックは、リクエストのユーザーではなく、OAuth state (このプロセスが 1 回のログインに対して作成したシークレットであり、一定時間で比較されます) によって配信されます。これは、ブラウザーが独自のトンネルを通って到着し、セッション Cookie を持たないためです。これを行わないと、リモート サインインは管理者以外のすべてのユーザーに対して login_not_active を返しました。また、パートナー ターンは、Codex 資格情報をパートナーの合成ワークスペースではなく所有者のルートに解決するようになりました。そのため、パートナーとのチャットが「このモデルを使用する前に Codex にサインインしてください」で失敗しなくなりました (#713)。 リスナーはループバックにバインドされたままで、ポート 1455 および 1457 は公開されず、コールバック応答がコードや状態をエコーすることはなく、PKCE とトークン交換は変更されません。

すべての言語は独自の言語のままです

parse_language() は裸の return "zh" で終わったので、ja/ko/fr/de/ru/ar はすべて中国語に解決されました。これが、日本の本に中国語のクイズが付いてきた理由です (#712)。これにより、既存のノーマライザーに委任されて未知のコードが渡され、答えが zh または en であると想定した 2 つのフォールバック チェーンがそれに倣い、プロンプトが [code, base locale, "en"] を試行するため、zh-tw は中国語ファイルを再利用し、ja は中国語ではなく英語に到達します。

さまざまな修正

  • ブックの作成とブロックの再生成は、プロキシがタイムアウトする可能性があるリクエストの代わりに WebSocket 上で実行され、スパイン合成と Visualize の分析ステージでは非ストリーミング呼び出しが使用されるため、単一章のフォールバックや切り捨てられたコード ブロックは発生しません (#707)。 3 つすべてがエージェント シームを介してルーティングされるようになり、イメージ添付ファイル、トレース メタデータ、および直接ファクトリー コールが削除されていたエージェントごとのルーティングが復元されます。
  • 新しいソース チェックアウトでの deeptutor start は、モジュール不足エラー (#710) でクラッシュする代わりに、web/node_modules をインストールします。
  • 管理者ユーザー管理、サインアウト、確認ダイアログ、およびトーストがローカライズされているため、UI を中国語に切り替えても、アカウント管理が英語のままになることはなくなりました (#718)。
  • サービスの遅延ローダーは、リテラル インポート パス (#717) を使用します。つまり動作中立ですが、モジュール グラフを静的に分析可能にします。

アップグレードに関する注意事項

v1.5.5 からのドロップイン: pip install -U deeptutor; Docker ユーザーは ghcr.io/hkuds/deeptutor:latest を引きます。移行やスキーマや構成の変更はありません。

  • リモート Codex サインインは SSH トンネルを使用するようになりました。サーバー上で deeptutor provider login openai-codex を実行するという v1.5.5 アドバイスが唯一のパスではなくなりました。 DeepTutor は、正確な ssh -N -L … コマンドを出力します。報告されるコールバック ポートに一致するものだけを実行します。このコマンドの 3782 は例であることに注意してください。実際に SSH ホストのループバックをリッスンしている Web ポートに置き換えてください。
  • Tencent IMA ナレッジ ベースには、ima.qq.com/agent-interface の client_id および API キーとライブラリ ID が必要です。ドキュメントは DeepTutor ではなく IMA で追加されます。 フル Changelog: https://github.com/HKUDS/DeepTutor/compare/v1.5.5...v1.5.6
