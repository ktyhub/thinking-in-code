DeepTutor v1.0.1

#ディープチューター v1.0.1 #ディープチューター v1.0.1 Release Notes 発売日: 2026.04.10

ハイライト

Chart.js/SVG レンダリング パイプラインを使用して機能を視覚化する

自然言語データ記述をインタラクティブな Chart.js またはインライン SVG ビジュアライゼーションに変換する新しい Visualize 機能が追加されました。バックエンドは、バイリンガル プロンプト サポート (en/zh) を備えた 3 段階のエージェント パイプライン (分析 → コード生成 → レビュー) を実行します。フロントエンドには、ワークスペースのホームページとチャット コンポーザーに組み込まれた 2 つの新しいコンポーネント (リクエスト構成用の VisualizeConfigPanel とレンダリング用の VisualizationViewer) が同梱されています。

Chat Composer の明示的な参照ピッカー

チャット コンポーザー ツールバーに、既存の [ツール] ドロップダウンと並んで、明示的な [参照] ドロップダウン ボタンを追加しました。ユーザーは、@ Reference ボタンを直接 click して、ノートブック レコードまたはチャット履歴セッションをコンテキストとして添付できるようになりました。入力フィールドに隠された @ トリガーを見つける必要はありません。ドロップダウンにはカテゴリごとの選択数と合計バッジが表示され、どの程度のコンテキストが関連付けられているかが一目でわかります。元の @ キーボード ショートカットは、パワー ユーザーの代替手段として引き続き機能します。

クイズの重複防止と生成履歴

会話 history_context からきれいに分離された、ジェネレーター パイプラインを通じて専用の previous_questions パラメーターを導入することで、繰り返されるクイズの質問を修正しました。 MAX_PREVIOUS_QUESTIONS=20 キャップによりプロンプトのサイズが制限され、言語ラベルは YAML テンプレートに移動され、ロケール間での言語の混合を回避します。

o4-mini および将来の o シリーズ モデルのサポート

LLM 設定の o シリーズ正規表現を拡張して、o4-mini および将来の o シリーズ モデル識別子を認識し、サポートされていない max_tokens パラメーターの代わりに max_completion_tokens が正しく設定されるようにしました (#274 を閉じます)。

サーバーログの改善

  • サーバー出力を乱雑にするノイズの多い uvicorn WebSocket 接続/切断ログを抑制しました。
  • 200 以外の応答のみをログに記録する選択的 HTTP アクセス ログ ミドルウェアを追加し、実用的なエラーの可視性を維持しながらログ ノイズを削減します。
  • 構造化出力をサポートしないプロバイダー用に MiniMax モデル オーバーライド (supports_response_format: false) を追加しました。
