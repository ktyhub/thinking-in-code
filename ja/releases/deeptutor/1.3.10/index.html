DeepTutor v1.3.10

パッチ 公開日2026年5月10日 出典HKUDS/DeepTutor 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#ディープチューター v1.3.10 #ディープチューター v1.3.10 Release Notes 発売日: 2026.05.10 v1.3.10 は、v1.3.9 の後に報告された問題に焦点を当てた信頼性リリースです。 よりスムーズなリモート Docker アクセスが復元され、自己署名 LLM エンドポイントが機能するようになります。 SDK がサポートするプロバイダー全体で一貫して、コード スニペットを引用から保護します 書き換えて、Matrix E2EE を明示的なオプトイン依存関係に分割します。

ハイライト

リモート Docker および CORS リカバリ

  • リモート シングルユーザー Docker は箱から出してすぐに再び動作します - とき AUTH_ENABLED=false、DeepTutor は HTTP/HTTPS 経由でブラウザのオリジンを受け入れるようになりました。 LAN またはリモートサーバーのフロントエンドが v1.3.8/v1.3.9 CORS にヒットしなくなりました #463 で報告された回帰。
  • 認証されたデプロイメントは明示的なまま - AUTH_ENABLED=true、CORS の場合 依然として CORS_ORIGIN または CORS_ORIGINS による具体的な許可リストが必要です。 認証認証の安全境界を維持します。
  • 複数のデプロイメント起点がサポートされています - CORS_ORIGINS はカンマを受け入れます または改行で区切られた値。両方の Docker Compose ファイルが設定を渡します。 バックエンドコンテナまで。
  • 設定でネットワーク フラグが削除されなくなりました - CORS_ORIGIN、CORS_ORIGINS、および DISABLE_SSL_VERIFY は、正規の .env 書き込み順序の一部です。

プロバイダー TLS とレンダリングの修正

  • DISABLE_SSL_VERIFY が OpenAI SDK パスに到達するようになりました - OpenAI 互換、 Azure OpenAI、executor、TutorBot、および従来の埋め込み SDK clients はすべて受信します フラグが有効な場合の共有 httpx.AsyncClient(verify=False)、修正 #464 で報告された自己署名 HTTPS LLM エンドポイント。
  • 運用環境では依然として安全でない TLS バイパスがブロックされています - ENVIRONMENT=prod または ENVIRONMENT=production は DISABLE_SSL_VERIFY を拒否し、警告が 1 つ発生します 非本番環境でログインした場合。
  • コード ブロックは配列インデックスをそのまま維持します - マークダウン引用のリンクが可能になりました 参照を書き換える前にフェンスされたコードとインライン コードをマスクするため、values[0] はそのまま残ります #references 引用リンク (#468) になる代わりにコードを追加します。

マトリックス インストールの互換性

  • Matrix はデフォルトで E2EE をインストールしなくなりました - 標準の matrix 追加および requirements/matrix.txt はプレーン matrix-nio を使用するようになり、 macOS Python 3.14 および Apple で見られる python-olm / libolm ビルドの失敗 クラン 21 (#462)。
  • 暗号化されたルームは明示的なアドオンです - deeptutor[matrix-e2e] をインストールします または、E2EE サポートが必要で libolm が必要な場合は requirements/matrix-e2e.txt 利用可能です。
  • 実行時のエラーがより明確になります - マトリックスのデフォルトは非 E2EE モードであり、 暗号依存関係なしで E2EE を有効にすると、実用的なインストールが発生するようになりました インポート時に失敗するのではなく、メッセージが表示されます。

マルチユーザー ランタイムの互換性

  • デフォルトのワークスペース パスはユーザー スコープ外でも安定しています - 現在のパスがない場合 マルチユーザー コンテキストがアクティブであり、パス解決はデフォルト データにフォールバックします。 管理スコープを強制するのではなく、ワークスペースを使用します。
  • レガシー テストとモンキーパッチ フックは引き続き利用可能 - セッションと設定 ルーターは、テストや古い統合で使用される互換性シムを保持します。
  • ローカル エージェント アーティファクトは無視されます - .claude/ は Git から除外されるようになりました。 ローカルのワークツリーとエージェントのメタデータが誤ってリリースに入力されることはありません。

テスト

  • 未認証のリモート オリジンと認証済みのリモート オリジンに対する CORS 設定テストを追加しました 明示的な許可リスト。
  • プロバイダーコア、Azure、 エグゼキュータ、TutorBot、および埋め込みアダプタ。
  • 散文引用、フェンスで囲まれたコード、インライン コード、 明示的なバッククォート引用。
  • デフォルトのインストールを維持するために、マトリックス依存関係分割テストを追加しました。 matrix-nio[e2e]。
  • ターゲットを絞った Python テスト、Web ノード テスト、Ruff チェック、および diff ホワイトスペースを再実行しました。 リリースパッチの検証。

アップグレードに関する注意事項

  • リモート Docker を AUTH_ENABLED=false とともに実行する場合、追加の CORS 設定はありません。 通常の HTTP/HTTPS ブラウザのオリジンに必要です。
  • AUTH_ENABLED=true を使用して共有または認証された展開を実行する場合は、次のように設定します。 CORS_ORIGIN または CORS_ORIGINS をフロントエンドの正確な起点に、たとえば https://learn.example.com。
  • DISABLE_SSL_VERIFY=true は、ローカル、自己署名、またはエアギャップ テストにのみ使用します。 LLM エンドポイント。 ENVIRONMENT=prod でブロックされたままになり、 ENVIRONMENT=production。
  • Matrix インストールはデフォルトで非 E2EE になりました。暗号化されたマトリックス ルームの場合、 .[matrix-e2e] または requirements/matrix-e2e.txt をインストールし、libolm が確実に 存在し、マトリックス チャネル構成で e2ee_enabled=true を設定します。
  • 暗号化されていないマトリックスを取得するためだけに .[matrix] を以前にインストールした場合 メッセージング、このリリース後の再インストールではネイティブは必要なくなります libolm ビルド ツール。 フル Changelog: https://github.com/HKUDS/DeepTutor/compare/v1.3.9...v1.3.10
