DeepTutor v1.5.17

パッチ 公開日2026年8月24日 出典HKUDS/DeepTutor 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#ディープチューターv1.5.17 #ディープチューター v1.5.17 Release Notes 発売日: 2026.08.25 v1.5.16 は MarginNote ライブラリに接続し、一連のゲートウェイ障害を解消しました。これにより、パートナー が誰に属するかが変更されます。パートナーは、管理者のみがアクセスできる展開全体のリソースではなくなり、各メンバーが構築、所有し、プライベートな会話を行うものになります。管理者は引き続き助成金を通じて自分のリソースを貸し出します。その周りには、GitHub リポジトリ、Antigravity CLI を追跡するナレッジ ベース (My Agents の下)、ログ ファイルの代わりにブラウザに描画された WeChat QR コード、および宣言したオプションのエクストラを保持するコンテナが配置されています。既存のパートナーは業務を継続し、自ら移行します。 1 つの動作変更は、管理者以外のユーザーに限定されており、以前は非管理者にアクセスできなかった パートナー ページが表示されるようになりました。

新機能

パートナーはデプロイメントではなく人々に属します

すべての /api/v1/partners ルートはブランケット管理ゲートの後ろに位置していたので、メンバーは管理者が割り当てたパートナーとのみ会話できました。代わりに、管理 (作成者と管理者) がソウル、チャネル、モデル、アセット、ライフサイクル、および削除をカバーする 3 つの権限がネストされるようになりました。 use は、管理者が割り当てたユーザーを追加し、会話を行うことを意味します。他の人はパートナーの存在を確認できません。所有されていないパートナーも目に見えないパートナーも同様に応答するため、ID を列挙することはできません。 会話はパートナーではなく人間に従っています。同じ仲間と会話している 2 人がお互いのスレッドを見ることはなく、それぞれの側が独自のアカウントで Web アプリを読み戻します。助成金はまだ存在し、形は変わっていませんが、現在は 管理者が管理する パートナーのみを提供しています。誰かが自分のために構築したものは、共有するかどうかは別ですが、その SOUL.md は通常個人的に書かれているためです。

チャット アカウントは DeepTutor ID を伝えることができます

QQ または Telegram 経由で接続したパートナーは、チャネルローカルの送信者 ID しか知らなかったので、すべての受信メッセージは匿名でした。メッセージは共有スレッド プールに到達し、パートナーは送信者自身のライブラリではなく管理ワークスペースから応答しました。 Web アプリでパートナーにコードを要求し、接続したいチャット アカウントから /link <code> を送信すると、それ以降、送信者はあなたになります。会話はあなたのアカウントにプライベートに保たれ、ブラウザーで読み取ることができ、パートナーは Web ターンと同じようにあなたの知識、ノート、記憶を読み取ります。

2 人のパートナーがチャンネルを共有できます

チャネルの実行時状態 (ボット トークン、ロング ポーリング カーソル、会話参照、E2EE デバイス ストア) は、パートナーごとではなく、チャネル ごとに 1 つのディレクトリに存在するため、同じチャネル上に構成された 2 つのパートナーが互いの資格情報を読み取り、互いのカーソルを上書きします。オンラインになれるのはそのうちの 1 つだけです。状態は現在 data/partners/<id>/channels/<channel>/ の下にあり、所有者が確実な場合、古いツリーは最初の起動時にコピーされます。保存されたトークンが 1 つのパートナーの構成済みトークンと一致するか、または 1 つのパートナーのみがそのチャネルを有効にしています。本物のネクタイは、他人のアカウントを渡されるのではなく、一度再認証されます。

個人 WeChat はブラウザからサインインします

QR コード交換は常に機能していましたが、チャネル自体の start() から実行され、サーバーの標準出力にコードが描画されただけでした。これは、どのコンテナ デプロイメントにおいても、パートナーを構成する担当者がアクセスできない監視ログです (#951)。同じ交換が Web アプリに対しても実行されます。パートナーのチャネル ページで [スキャンして接続] を押し、スキャンすると、ボット トークンがチャネル構成サーバー側に書き込まれます。ステータス応答には、ログインが成功したかどうかが示されますが、ログインによって何が生成されたかは示されません。端末は依然としてフォールバックとしてコードを出力します。

ナレッジ ベースは GitHub リポジトリを追跡できます

リポジトリ、ブランチ、グロブを GitHub ソースとして登録すると、そのマークダウンが KB に取り込まれ、オンデマンドで再同期されるため、従うドキュメントは再アップロードしなくても最新の状態に保たれます。 #903 として投稿しました。ダウンロード先は KB の raw/ ディレクトリ内に含まれます。これは、.. セグメントまたはツリー エントリ内の絶対パスがベースの外に書き込まれ、削除ブランチ上では削除されるためです。

Antigravity CLI が私のエージェントに加わりました

Google は 6 月に Gemini CLI を廃止し、ユーザーに Antigravity CLI を提供したため、Google AI Pro/Ultra または Gemini Code Assist プランを利用しているユーザーは、検出する CLI を持たない gemini バックエンドを使用することになりました (#828)。 agy は独自のバックエンドになりました。接続し、ターンの途中で参照し、会話を再開します。 Gemini CLI バックエンドは残ります。Gemini API キーを保持しているユーザーに対しては引き続き実行され、アップグレード時に動作中の接続が切断されることはありません。

deeptutor doctor

「このワークスペースはセッションを開始する準備ができていますか?」という質問に答えるコマンドが 1 つあります。 — 設定、プロバイダー、依存関係、ポート。 --online は、構成されたモデル プロバイダーに小さなリクエストも送信します。 --format json は、スクリプトまたはエージェントに対して同じレポートを出力します。 #959として投稿しました。

コンテナには、宣言したエクストラが保持されます

コンテナは使い捨てであるため、docker exec … pip install ".[partners]" は次の compose down (#762) まで正確に存続します。代わりにデプロイメントでそれらを宣言します (システム ライブラリの場合は DEEPTUTOR_EXTRAS: "math-animator,partners" および DEEPTUTOR_APT_PACKAGES)。これにより、そこから起動されるすべてのコンテナーがそれらを再適用します。ウォーム コンテナは要件ごとに 1 つのメタデータ ルックアップを支払い、pip キャッシュはデータ ボリューム上に存在します。ホイールが欠落していると、デプロイメントがダウンするのではなく、その 1 つの機能が利用できなくなります。

埋め込みはレート制限のあるプロバイダーでも生き残る

低 RPM プロバイダーに対して大規模なライブラリのインデックスを再作成すると、何時間も消費され、その後 429 で停止していました。変更された点は 3 つあります。キー プールはキーごとのクールダウンで provider × model 全体でローテーションするため、1 つのスロットルされたキーによって実行が妨げられることはなくなりました。再試行バジェットは、スライディング ウィンドウで使い果たすのではなく、Retry-After まで待機します。また、プロセス全体のスロットルにより、同時再インデックス間で間隔とポストがシリアル化されます。これにより、手動で成功したリクエストがアプリ内で失敗します。 #962として投稿しました。

ウィンドウ

MinerU の解析は、プラットフォームのデフォルト (zh-CN インストールの GBK) でサブプロセス出力をデコードし、最初の非 ASCII バイトで停止しました。マルチスレッドの PDF レンダラーが個別にヒープを破損しました。どちらも修正されており、レンダー ガードのスコープは Windows のみです (#844)。アトミック書き込みは、ターゲットを保持するウイルス対策またはインデクサーからの一時的な PermissionError を再試行するようになり、コードの実行は Windows ホスト上で機能します (#964)。

各種詰め合わせ

  • 推論の作業は会話ごとに行われます。 v1.5.9 のモデルレベルの制御を単一のチャットに対してオーバーライドできるようになりました (#641、#958 として提供)。
  • インデックス作成は、ハングするのではなく、制限付きで失敗します。 埋め込みリクエストを受け入れ、完了しないプロバイダーは、実行プログラムの将来を永久に停止させます。ハートビート ガードは、進行状況が存在しない制限されたウィンドウの後に発生するようになりました (#946)。
  • MinerU ページ レイアウト ブロックはコンテンツとしてインデックス付けされなくなります。 ヘッダー、フッター、ページ番号は取り込まれる前にフィルターされます。認識されないブロック タイプは実行全体が失敗するのではなくインデックスが作成されるため、ブロック タイプを追加する MinerU リリースではインデックス作成が中断されません (#949)。
  • 音声文字起こしは Chrome の記録を受け入れます。 audio/webm;codecs=opus は、不明な形式 (#945) として拒否されるのではなく、ワイヤー境界で一度正規化されます。
  • マスタリー クイズ カードがスクロールせずに見える範囲に表示されなくなりました。 ポストストリーム スクロール ウィンドウが閉じた後にビューアがマウントされ (#960)、オプションがラベルまたは回答を繰り返すクイズは、回答できないカードとして表示されるのではなく、登録時に拒否されます (#956)。
  • ラーニング パスはその名前を維持します。 3 つのサーフェスはそれぞれ最初のモジュールから派生したため、マップを再構築するとパスの名前が変更され、3 つのサーフェスが一致しない可能性があります。 1 つの関数が現在応答しており、導出はフォールバックであり、記録ではありません。
  • ラウンドの動作内容を変更するツールが最初に実行されます。 ラウンドの途中でマスタリー パスを切り替えると、他の呼び出しはラウンドが開始された状態にバインドされたままになります。ディスパッチャは再バインド ツールを実行し、他のすべてを再バインドしてから、最後に一時停止ツールを実行します。
  • ローカル LightRAG の回答はソースを引用しています (#754)、ローカル LlamaIndex パイプラインはインポート時に進行状況バーの決定をフリーズしなくなりました (#864)。
  • Azure OpenAI は、ポータルが提供するエンドポイントを受け入れます。 従来の …/openai/deployments/<name>/chat/completions URL は /openai/v1 サーフェスに縮小されるため、設定プローブが通過する間、チャットは 404 Resource not found に応答しなくなります。
  • Gemini は、モデルがサポートする画像を埋め込みます。エンドポイントが拒否する部分をポストするのではなく、サポートしていない画像については contents を拒否します (#814)。
  • ページでは、機能がインストールされているかどうかを尋ねることができます。 ウィスパー練習室などのプラグインで提供される機能は、それらを尊重できない標準インストールによって提供され、順番は Unknown capability (#963) に戻りました。
  • スタンドアロンの CLI パッケージは、実際にインポートするものを宣言します (#954)。

アップグレードに関する注意事項

pip install -U deeptutor; Docker ユーザーは ghcr.io/hkuds/deeptutor:latest を引きます。インデックスの再作成や手動による移行は必要ありません。

  • 管理者以外のユーザーにはパートナー ページが表示されます。 マルチユーザー展開では、メンバーが独自のパートナーを作成および管理できるようになり、どのパートナーとの会話も自分のアカウントにプライベートに公開されます。既存のパートナーには owner_id がないため、管理者が管理するものとして読み取られます (まさにそのとおりです)。そのため、設定したものは何も変更されません。
  • チャネル状態は、コピーによってパートナーごとに移動します。 最初の開始時に、所有者が明確であれば、data/partners/<channel>/ の状態が data/partners/<id>/channels/<channel>/ にコピーされます。レガシー ツリーはそのまま残されるため、悪い結果は手動で回復できます。所有権があいまいなパートナーは、一度再認証するだけです。
  • 現在、管理者が管理するパートナーのみがリストに付与されています。 メンバーが自分用に構築したパートナーは、割り当て可能なプールには表示されません。
  • コンテナー エクストラはオプトインです。 Compose ファイルで DEEPTUTOR_EXTRAS を設定するまでは何も変わりません。 python scripts/install_extras.py --dry-run "<name>" を使用してプレビューします。
  • Gemini CLI 接続は引き続き機能します。 Antigravity は追加のバックエンドであり、代替品ではありません。 フル Changelog: https://github.com/HKUDS/DeepTutor/compare/v1.5.16...v1.5.17
