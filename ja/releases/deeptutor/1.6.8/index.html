DeepTutor v1.6.8

パッチ 公開日2026年9月14日 出典HKUDS/DeepTutor 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#ディープチューターv1.6.8 #ディープチューター v1.6.8 Release Notes 発売日: 2026.09.14 v1.6.8 は 22 のコミュニティ プル リクエストとその背後にあるレポートを一掃します。 v1.6.7 が隠れた思考に費やされたトークン予算を追跡したのに対し、これは主に別の苦情に答えています: 私が何かをしたのにアプリは静かに何もしませんでした。 戻る方法のない削除されたチャット、本の代わりにライブラリを開いた本のリンク、モデルが言及しなかった添付ファイル、まだ起動中に終了したバックエンド。ごみ箱、履歴検索、独自のナレッジ ベースを検索するツールという 3 つの新しいサーフェスが同時に追加されます。ドロップイン - 移行はありません。

新機能

削除されたチャットは復元可能です

会話の削除は以前は最終的なものでした。チャットはごみ箱 (サイドバーの折りたたみ可能なセクション) に移動され、そこでチャットを復元したり永久に削除したりできるようになります。添付ファイル、マスタリー状態、およびチャットの残りのアーティファクトは旅行中に存続し、一緒に戻ってきます。ディスクから何も削除されるのは明示的なパージのみです。

会話履歴全体を検索する

履歴ピッカーは、タイトルだけでなくメッセージ テキストも検索するようになりました。一致した内容にはヒットの前後の短い抜粋が表示されるため、どちらかを開く前に 2 つの類似した会話を区別できます。リテラルで大文字と小文字が区別されず、クエリと抜粋の両方に制限されます。

ナレッジベースを超えて検索するツール

knowledge_frontier はナレッジ ベースを読み、そこに「含まれていない」ものを探します。同じテーマに関する最近の研究で、答えではなく出発点として表面化したものです。ターンに KB があると、rag および kb_files の隣に自動的にマウントされます。

deeptutor run chat "Find recent work beyond this material" --kb textbook --tool knowledge_frontier

思考の途中で停止していた推論モデルがそう言うようになりました

隠された推論に予算全体を費やし、何も返さなかったラウンドは、不透明な失敗でターンを終了するために使用されていました。そのシーンの 2 つの読み取りが連続して実行されるようになりました。明らかに上限に達したラウンドは、それを証明するカウンター (ラウンド、推理キャラクター、完了トークン) で失敗します。これは、それがアクション可能な構成であるためです。答えずに推論した他のものは、それがどの種類の空であったかを告げてターンを終了します。再生されたラウンドは、それを送信するプロバイダーの推論を維持し、先頭の <think> ブロックがその後の JSON を飲み込むことはなくなりました。

指示した場所で読書と本が開きます

ディープブック URL によってライブラリが開かれ、ユーザーは自分で本を見つけることができました。素材がメディアではなくドキュメントになると、アウトラインは実際に閲覧していたページを追跡しなくなりました。読み込みが開始される前のビート中に、読み物が「開くことができません」と表示されました。 3つとも固定されています。 macOS が再圧縮した EPUB も同様です。Finder のアーカイブは書籍をディレクトリにラップしますが、これまで DeepTutor は __MACOSX/._* エントリを章として扱っていました。

モデルが実際に見ることができるアタッチメント

以前のターンの画像が再送信されるため、画像に関するフォローアップの質問には画像が残り、キャップは定数ではなく設定になりました。また、テキスト抽出によって何も生成されなかったファイル (通常はスキャンされた PDF) は、何も言わずにスキップされるのではなく、その理由とともにリストされるため、モデルはファイルに名前を付けて、再度アップロードするように求めるのではなく、ファイルに名前を付けて、そのファイルを引用できない理由を説明できます。

設定、起動、および静かに失敗していたもの

何も変更しない設定を適用すると、ランタイムごとに client がリセットされていました。 5 つの呼び出しサイトがそれぞれ独自の方法で決定するのではなく、1 つの場所がそれを決定するようになりました。ランチャーは、まだ起動しているだけのバックエンドを強制終了しなくなりました。イベント ループから記録された取得の進行状況は、消えるのではなく届きます。機能は、それを消費するターンが停止するとキャンセルされ、GraphRAG ワーカーは開始前に古い Arrow 登録を修復し、リバース プロキシの背後でアクセス ログにプロキシではなく実際の client が記録されます。

名前を付ける価値のある小さな修正

ask_user カードは、表示されるテキストが別のオプションと重複するオプションをドロップします。テンプレートなしで返されたクイズ計画は、黙って何も生み出さない代わりに失敗します。明示的な retryable: false は、ステータス コードによってオーバーライドされるのではなく尊重されます。 read_skill は失われたファイルを適切に回復します。デッドターンによって保持されたセッションは自動的にクリアされます。推論プローブのバジェットは以前の異常値ではなくなり、すべての LLM バジェットが agents.yaml に存在し、ステージごとに 1 つのエントリが存在します。

アップグレードに関する注意事項

pip install -U deeptutor を実行します。 Docker ユーザーは ghcr.io/hkuds/deeptutor:latest を引きます。何も移行する必要はありません。

  • チャットの削除は元に戻せるようになり、「削除」の意味が変わります。 削除は論理的に削除します。行は、ごみ箱から削除するまで残ります。読み物を削除しても、以前と同じ方法でセッションが削除されます。
  • agents.yaml はすべての LLM バジェットを所有します。 ステージ レベルの max_tokens エントリはステージごとに 1 つずつそこに移動されます。すでに設定した値は引き続き読み取られます。エントリのなかったステージにエントリが追加されました。
  • 前のイメージの再注入キャップは構成可能です。 これはハードコードされた 4 でした。現在はシステム設定にあり、0 はこの機能をオフにします。 フル Changelog: https://github.com/HKUDS/DeepTutor/compare/v1.6.7...v1.6.8
