DeepTutor v1.2.5

#ディープチューター v1.2.5 #ディープチューター v1.2.5 Release Notes 発売日: 2026.04.25

ハイライト

添付ファイル ストアとファイル プレビュー ドロワー

チャットの添付ファイルは、メッセージ行内のインライン Base64 BLOB としてのみ存在するのではなく、ファーストクラスのセッション アーティファクトとして保持されるようになりました。 Turn ランタイムは、アップロードされたすべてのファイルをドキュメント抽出前に新しい添付ファイル ストアに書き込み、メッセージに安定した URL を記録し、永続化されたチャット履歴からかさばる Base64 ペイロードを削除します。

  • バックエンド添付ファイル ストア - deeptutor/services/storage/attachment_store.py では、プラグ可能な AttachmentStore プロトコルと、data/user/workspace/chat/attachments をルートとするデフォルトの LocalDiskAttachmentStore が導入されています。パスは .env.example で説明されている CHAT_ATTACHMENT_DIR でオーバーライドできます。
  • 安全な添付ファイルの提供 - 新しい /api/attachments/{session_id}/{attachment_id}/{filename} ルーターは、トラバーサル安全なパス解決、アップロード時のアトミック書き込み、インライン Content-Disposition、UTF-8 ファイル名の処理、およびプライベート キャッシュなしヘッダーを使用して保存されたファイルを提供します。
  • 安定した添付ファイル メタデータ - Attachment には id と extracted_text が含まれるようになりました。 TurnRuntimeManager は、欠落している ID を生成し、元のバイトを保持し、プレビュー URL を保存し、Office/テキスト ドキュメントから抽出されたテキストを保持するため、アシスタントが読み取った内容を UI に正確に表示できます。
  • 右側のプレビュー ドロワー — FilePreviewDrawer は、チャット ファイル用のクロード スタイルのサイド パネルを追加します。デスクトップではチャット列が圧迫されます。小さい画面ではオーバーレイされます。シェルは即座に開閉できるようにマウントされたままですが、重いプレビュー ボディはジャンクを避けるためにスライド アニメーションが終わるまで延期されます。
  • プレビュー レンダラ - PDF はブラウザ ビューアでレンダリングされ、画像と SVG はネイティブ <img> でレンダリングされ、Markdown はメインの Markdown レンダラを再利用し、コード/テキスト ファイルは構文強調表示付きの RichCodeBlock を使用し、Office ファイルはバックエンドで抽出されたプレーン テキストを表示し、サポートされていない/レガシー ファイルはダウンロード カードにフォールバックされます。
  • 添付アクション - 保留中のコンポーザー チップと送信されたメッセージ カードは click 可能で、キーボード フォーカス リング、ダウンロード、リンクのコピー、エスケープして閉じる、および古いセッションに対する優雅な「レガシー ファイルが保存されていません」メッセージングを備えています。

より広範なコードとテキスト添付ファイルの対象範囲

v1.2.4 テキスト/コード添付ファイルのサポートが大幅に拡張され、バックエンド RAG ルーター、チャット エクストラクター、フロントエンド アップロード許可リスト、アイコン、およびプレビュー ハイライターの調整が維持されました。

  • より多くの受け入れ形式 - FileTypeRouter.TEXT_EXTENSIONS および TEXT_LIKE_EXTS には、JSONC/JSON5、MJS/CJS/MTS/CTS、Vue/Svelte、Kotlin スクリプト、Groovy/Gradle、C#/Zig/Nim、Objective-C、Perl/Lua/Julia/Dart、 Haskell/Clojure/Elixir/Erlang/OCaml/F#、Lisp/Scheme/Racket、Solidity、fish/vim、GraphQL/protobuf、CMake/Makefile、Terraform/HCL、nginx config、および Dockerfile スタイル ファイル。
  • 中央構文マッピング — web/lib/code-languages.ts は、拡張子と特殊なファイル名 (Dockerfile、Makefile、CMakeLists.txt、ドットファイルなど) を Prism 言語名にマップするため、プレビュー分類とコードのハイライトの同期が保たれます。
  • フロントエンド ヘルパーがエクスポートされました - extOf() がプレビュー パイプライン用に web/lib/doc-attachments.ts からエクスポートされるようになり、ドキュメント アイコン/カテゴリが新しい拡張セットに一致するように拡張されました。

アタッチメントを認識する高度な機能

アップロードされた添付ファイルは、デフォルトのチャット ステージだけでなく、より多くのエージェント パイプラインに流入するようになりました。

  • ベース エージェント パリティ - 非ビジョン モデルのイメージ ストリッピング/ロギングなど、添付ファイルが存在する場合、非ストリーミング LLM コールはストリーミング コールと同じ prepare_multimodal_messages() パスを使用するようになりました。
  • ディープソルブ - 最初の画像 URL のみを抽出する代わりに、DeepSolveCapability は、MainSolver を介して画像添付ファイルをプランナー、ソルバー、および再計画の呼び出しに転送するため、マルチモーダルな問題は Plan-ReAct-Write ループ全体にわたって表示されたままになります。
  • 深い質問 - トピックの生成とフォローアップの回答により、添付ファイルが基礎となるエージェントに渡されます。アップロードされた PDF が既に抽出され、base64 ストレージから削除されている場合、ミミック モードで [Attached Documents] テキストを直接使用できるようになりました。
  • ディープリサーチ – 研究計画は添付ファイルを受け入れ、それを最初の計画 LLM 呼び出しに転送します。言い換えまたは分解のいずれであっても、後の計画ターンで同じ画像/ファイルコンテキストを複製することはありません。
  • 視覚化 - 視覚化分析でチャットの添付ファイルを受信できるようになり、図やスクリーンショットがレンダリング タイプの選択やデータ抽出に影響を与えることができるようになりました。

TutorBot のエクスポートとノートブックのキャプチャ

TutorBot チャット セッションには、通常のチャットと同じキャプチャ パスが含まれるようになりました。

  • エージェント チャット ページでは、ヘッダーに ノートブックに保存 および マークダウンのダウンロード アクションが追加されます。
  • SaveToNotebookModal、notebook-api、バックエンド ノートブック リクエスト タイプ、および RecordType は、新しい tutorbot レコード タイプを認識するようになりました。
  • ナレッジ ページには、独自の紫色のバッジとボット アイコンが付いた TutorBot ノートブックのエントリが表示されます。
  • 復元された TutorBot チャット履歴は、複数のフレームにわたって下部に再スナップされるようになりました。そのため、最初のペイント後の Markdown/KaTeX の増加により、ユーザーが最新のメッセージの上に残らないようになります。

ツアー診断のセットアップと堅牢性のインストール

ガイド付きセットアップ ツアーでは、サイレントに失敗するのではなく、依存関係の失敗について説明するようになりました。

  • ブートストラップ依存関係のインストールでは、stdout/stderr がキャプチャされ、実際の pip エラーと手動の再試行コマンドが出力されます。
  • uv 解決では、インストールを試行する前に一般的なインストール場所 (~/.local/bin、~/.cargo/bin、Homebrew パス) をチェックし、uv が正常にインストールされても PATH にインストールされていない場合は、明確な次の手順を報告します。
  • uv のインストール失敗時に、Python ホイールの可用性、古いシェル PATH、PyPI ミラーの問題、および直接インストーラー オプションに関するローカライズされた英語/中国語のヒントが表示されるようになりました。
  • Node.js/npm バージョン チェックは、--version を実行する前に shutil.which() を通じて実行可能ファイルを解決し、Python サブプロセス強化後の Windows .cmd/.bat の互換性を向上させます。

チャットとナレッジの UX の修正

  • 自動スクロールの信頼性 - useChatAutoScroll は、ミューテーション オブザーバーをアタッチする前にメッセージ コンテンツを待機するようになり、メッセージ コンテナーが最初に空だったセッションを再度開くときに欠落していた下部スクロール動作が修正されました。
  • プレビュー アニメーションの洗練 — globals.css は chat-preview-shell トランジションを追加し、引き出しのスライドとチャット列の絞り込みが同じ 220 ミリ秒のタイミングで一緒に動くようにします。
  • ナレッジ アップロード ピッカー - KB ファイル入力は、一部のシステムで有効なファイルを非表示にする可能性があるブラウザ/OS accept フィルターに依存しなくなりました。アプリ内検証では、選択後もサポートされるファイル ポリシーが適用されます。
  • ローカライズされたプレビュー コピー - プレビューの読み込み、リンクのコピー、使用できないプレビュー、従来のファイル、添付ファイルの削除、Office 抽出テキストの説明用に英語と中国語の文字列が追加されました。

テストスイートの拡張

  • 添付ファイル転送機能 - tests/core/test_capabilities_runtime.py は、抽出されたドキュメント テキストによる模倣モードを含む、Deep Solve、Deep Question、Deep Research、および Visualize 添付ファイル伝播のカバレッジを追加します。
  • 研究計画のエッジ ケース — tests/agents/research/test_research_pipeline_rag.py は、リフレーズが有効になっているときに添付ファイルが転送されて分解されることを検証しますが、反復はゼロで、最初の実際の計画 LLM 呼び出しでアップロードされたコンテキストが確実に参照されるようにします。 フル Changelog: https://github.com/HKUDS/DeepTutor/compare/v1.2.4...v1.2.5
