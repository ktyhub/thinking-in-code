DeepTutor v1.4.5

パッチ 公開日2026年6月13日 出典HKUDS/DeepTutor 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#ディープチューター v1.4.5 #ディープチューター v1.4.5 Release Notes 発売日: 2026.06.14 v1.4.4 を中心としたリリース: ガイド付き学習は 他のすべてを駆動する同じチャット エージェント ループ上に再構築され、 チャット ループを拡張可能にする新しいループ プラグイン フレームワーク。パートナー 会話をエクスポートしてノートブックに保存できるようになり、すべてのチャットが切り替わるようになりました ビートが早く終了します。ドロップイン、移行なし。

ガイド付き学習の動作は異なりますが、進捗状況は引き継がれます。 古い固定ステージの流れは、熟練した講師によるチャットに置き換えられます 門。既存の学習の進行状況は変更されずに読み込まれます。移行するものは何もありません。 アクションが必要です。唯一の操作上の変更点は Windows の場合です。 スクリプトは scripts/ に移動されました (アップグレードに関する注意事項を参照)。

新機能

チャットループ上に再構築されたガイド付き学習

オーダーメイドのステージマシン（診断→説明→クイズ→ファインマン）はなくなりました。 マスタリー パスは、タイプごとのハードな学習を推進する 1 対 1 の講師チャットになりました。 マスタリーゲートがあり、クリアするまで目標を超えて進むことはできません。

  • 記憶/手順の目標はインタラクティブなカードでクイズされ、 サーバー側で採点 — 予想される回答は質問とともに保存され、 モデル内を往復することはありません。その後、一定の間隔で繰り返すようにスケジュールされます。 レビュー。
  • コンセプト/デザインの目的は、アイデアを説明することで習得できます あなた自身の言葉で。講師が判定し結果を記録します。
  • /learning ページは ダッシュボード になりました: ゲートが決定した次のステップ さらに、各目標 (新規/学習/習得) のステータス マップも表示されます。

拡張可能なチャット ループ

新しいループ プラグイン フレームワーク (deeptutor/loop_plugins/) により、 そのツール、システム プロンプト ブロック、およびサーバー所有のツールを提供する チャット パイプラインでハードコーディングせずにターンに引数を追加できます。ガイド付き 学習は最初のプラグインです。ループは context-checkpoint も学習しました 折りたたみ — ツールは、長時間作業しているコンテキストをチェックポイントまで折りたたむことができます。 加えてターンの途中で概要を追加します。目に見えない日常。それはシームフューチャーモードです に差し込みます。

パートナー: ノートブックにエクスポートして保存

パートナーの チャット および アーカイブ の会話を次の場所にエクスポートできるようになりました。 マークダウンしてノートブックに保存 - 同じコントロール製品 チャット済み があり、現在は 1 つの共有シリアライザーによってサポートされています。

よりスムーズなターン完了

チャットの順番が変わるたびに、回答が保存された瞬間に done が通知されるようになりました。 コンポーザーのロックが解除され、デュレーションクロックがすぐに停止します。の 自動生成されたセッション タイトルはターンを保持せずにビートの後に続きます 開いた。

アップグレードに関する注意事項

  • v1.4.4 からのドロップイン: pip install -U deeptutor; Docker ユーザーがプルします ghcr.io/hkuds/deeptutor:latest。移行なし - 既存の学習 進行状況はそのままロードされます。
  • Windows 起動スクリプトが scripts/ に移動されました: run scripts\start_backend.bat / scripts\start_frontend.bat。 フル Changelog: https://github.com/HKUDS/DeepTutor/compare/v1.4.4...v1.4.5
