#ディープチューター v1.7.1

ディープチューター v1.7.1 Release Notes

発売日: 2026.11.01

v1.7.0 に基づいて構築された v1.7.1 では、Open DeepTutor デスクトップ プレビュー、より広範なローカリゼーション、チャット、レッスン、アカウント、プロバイダー、ドキュメント処理の大幅な改善が導入されています。既存のランタイム データはそのまま残ります。手動での移行は必要ありません。

新機能

DeepTutor デスクトップ プレビューを開く

Open DeepTutor は、Python、Node.js、および完全な学習ワークスペースを Apple Silicon Mac、Intel Mac、および Windows x64 用のデスクトップ アプリにバンドルします。プレビュー ビルドは、macOS の場合は DMG ダウンロード、Windows の場合はセットアップまたはポータブル ZIP オプションを使用して、デスクトップ リリース ワークフローから入手できます。

より多くの言語とアカウント制御

ベトナム語、日本語、トルコ語、ブラジル系ポルトガル語がインターフェイスと返信言語オプションに加わり、拡張翻訳、地域の日付形式、右から左への表示も追加されました。アカウント スコープの学習テキスト コントロールは、フォント サイズと行間隔を調整します。ユーザーはプロファイルからパスワードを変更できますが、管理者が割り当てた一時パスワードをまだ使用しているアカウントには変更プロンプトが表示されます。

あなたの仕事とソースを一緒に保つチャット

未送信の作曲家のドラフトはナビゲーション後も残り、会話形式の作成のドラフトは初期の作業を保持します。メッセージ レベルの Little Tutor スレッドは、周囲の会話を失うことなく、ソース アンカーを回復、移動、またはクリアできます。生成されたファイルには一貫したオープンおよびダウンロードの制御が得られ、メッセージの編集または再送信には現在のモデルと返信言語が使用されます。

チェック済みのレッスンとポータブル教材

ビデオ レッスンは、Edge フォールバックを使用して構成された Text-to-Speech プロバイダーを通じてナレーションを行い、ブラウザーのレイアウトをチェックし、対象を絞った修復を実行します。 Math Animator には、ジオメトリのドライラン チェックとタスク モデルの修復が追加されています。ノートブックのフラッシュカードは Anki にエクスポートされ、カレンダー イベントは外部カレンダー アプリ用の iCalendar ファイルとしてエクスポートされます。

さらに多くのモデル、検索プロバイダー、およびエージェントのオプション

Claude Code の統合により、公式 SDK モデル検出とソース画像転送が可能になりました。プロバイダーの対象範囲は、xAI モデル、Mistral 埋め込みと音声、You.com とセルフホスト型 Google ブラウザ検索に加え、CloudGPU、LLMTR、Runcrate ゲートウェイによって拡大されます。タスク モデルは、バックグラウンド ヘルパーだけでなく、ターゲットを絞った Math Animator およびビデオ レッスンの修復も処理できるようになりました。

検索と文書の忠実性

PageIndex インデックス作成では構成されたタスク モデルを使用できますが、LlamaIndex フォルダー同期では 1 つの一貫したバージョンが公開されます。 MinerU は参照リストを保持し、ハイブリッド検索ではスコア 0 の BM25 ヒットを除外します。 Office および DOCX のフォールバックでは、方程式、画像、スライドの順序、スプレッドシートのまばらな列、およびグループ化された数学用語がより適切に保存されます。

実行時全体にわたる信頼性

このリリースでは、アーカイブ抽出、Unicode ファイル名の処理、キャンセルのクリーンアップ、音声転写とオーディオ変換、講師スレッドの回復、ワークスペースの下書き保存、デスクトップ署名と公証も強化されています。これらの修正により、部分的なエラーが軽減され、操作が完了できない場合でも既存のデータが保存されます。

英語と中国語のガイドは、deeptutor.info でこのリリースと同期されています。

アップグレードに関する注意事項

  • 完全なアプリ: DeepTutor を停止し、ランタイム ホームをバックアップしてから、python -m pip install --upgrade "deeptutor[full]==1.7.1" を実行します。同じ DEEPTUTOR_HOME を維持し、python -m pip check と deeptutor module list を実行してから再起動します。
  • レガシー インストール: 1.6.15 以前からのアップグレードでは、新しいパッケージ ファミリをインストールする前にレガシー deeptutor-cli パッケージをアンインストールする必要があります。 v1.7.0 の移行コマンドに従います。 runtime-home データは、インストールされたパッケージとは分離されたままになります。
  • ソースのインストール: requirements/full.txt、次に python -m pip install -e . --no-deps をインストールします。コアホイールとフィーチャーホイールは一致するバージョンを使用する必要があります。モジュールを変更する前にアクティブなサーバーを停止し、CLI を回転させます。
  • Docker: ghcr.io/hkuds/deeptutor:1.7.1 または :latest をプルし、既存のデータ ボリュームでコンテナーを再作成します。
  • デスクトップ プレビュー: dev で実行された成功したデスクトップ リリース ワークフローから一致するアーティファクトをダウンロードします。 GitHub サインインが必要で、アーティファクトは 7 日後に期限切れになります。 Windows プレビュー ビルドは署名されていないため、SmartScreen 警告が表示される場合があります。
  • ビデオ レッスン: バックエンドには Node.js 22+ と npm が必要です。ナレーションは、利用可能な場合は構成された音声プロバイダーを使用し、インストールされている場合は Edge を使用します。ナレーションなしでキャプションが残り、レッスンは静かに再生されます。
