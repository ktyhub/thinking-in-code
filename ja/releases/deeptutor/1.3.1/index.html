DeepTutor v1.3.1

パッチ 公開日2026年4月28日 出典HKUDS/DeepTutor 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#ディープチューター v1.3.1 #ディープチューター v1.3.1 Release Notes 発売日: 2026.04.28 v1.3.1 は、v1.3.0 の後の安定性リリースです。より安全な RAG ルーティングに焦点を当てています。 より強力な埋め込み検証、より信頼性の高い Docker/TutorBot の再起動、および 小さいながらも重要な Web UX の修正セット。

ハイライト

より安全な RAG とナレッジ ベース ルーティング

  • 選択された KB は trusted システム状態になりました - チャット RAG 呼び出しでは、 LLM は kb_name を作成またはオーバーライドします。モデルは query と DeepTutor のみを認識します UI/セッションで選択された KB にルーティングします。
  • RAG に KB がない場合、サイレント フォールバックはありません - RAG は有効だが KB がない場合 選択すると、ターンは KB の取得をスキップし、代わりに明確な進行状況メッセージが表示されます。 誤って古い/デフォルト状態をクエリしてしまう可能性があります。
  • デフォルトの KB エイリアスは一貫して処理されます - default、current、 selected および同等の中国語は、設定されたデフォルトの KB に解決されます。 ツールの呼び出し、ファイルの一覧表示、API のインデックスの再作成、default という名前の実際の KB まだエイリアスに勝っています。
  • サービス レイヤーを使用した増分ドキュメントの追加 - ファイルの追加が可能になりました RAGService.add_documents まで、追加/検索/再インデックス動作を維持 同じプロバイダーとインデックス バージョン パス。
  • RAG 内部の保守が容易になりました - LlamaIndex パイプラインが分割されました ロード、埋め込み、ストレージ、エラー、オーケストレーションに特化したモジュールに分割します。 スマート マルチクエリ検索は SmartRetriever に組み込まれました。

埋め込みとインデックスの信頼性

  • 埋め込み応答は使用前に検証されます - DeepTutor は拒否されるようになりました ドロップされたベクトル、NULL 値、非数値、非有限値、および LlamaIndex に到達する前の寸法の不一致。
  • 接続テストはバッチ動作を調査します - 埋め込みスモーク テストでは、 小さなバッチ、1 つのベクトルまたは変更のみを返すプロバイダーをキャッチ 入力間の寸法。
  • 不正なインデックスは実用的なメッセージで失敗します - null ベクトルまたは形状の不一致 取得失敗時に低レベルを公開するのではなく、再インデックスのヒントが返されるようになりました。 NoneType * float スタイル エラー。
  • 書き込み中のインデックス ステータスのノイズが少なくなります - 空の進行中のバージョン ディレクトリは新しい KB を needs_reindex としてマークしなくなり、空で失敗しました 可能な場合は、バージョン フォルダーがクリーンアップされます。
  • 埋め込み例が明確になりました - services/embedding/.env.example 完全なエンドポイント URL セマンティクスと具体的なプロバイダーの例を文書化しました。 OpenAI、SiliconFlow、Ollama、Cohere、Jina、vLLM、Azure OpenAI、DashScope、および OpenAI-SDK スタイルのゲートウェイ。

Docker、メモリ、および TutorBot ランタイム

  • Docker 画像はアプリのバージョンを公開する可能性があります - APP_VERSION はパススルーされます バックエンドとフロントエンドの両方のランタイム環境変数に。
  • 共有メモリには独自の Docker ボリュームがあります - 作成ファイルがマウントされるようになりました ./data/memory:/app/data/memory; README 永続性ドキュメントが更新されました。
  • メモリの移行はより安全です - 従来の SUMMARY.md および PROFILE.md ファイルは、 ターゲット ディレクトリが既に存在する場合でも、data/memory にコピーされます。 既存のターゲット ファイルは保存されます。
  • メモリのリフレッシュはシリアル化されます - プロファイル/サマリーの同時書き換えが可能になりました 書き込みの競合を避けるために、ロックの下で実行します。
  • TutorBot の再起動意図は保持されます - サーバーの正常なシャットダウンにより、 ボットの auto_start フラグは、手動での次回の Docker/ホストの再起動までそのままです。 停止しても自動起動は無効になります。
  • TutorBot は長期メモリを共有します - 開始されたボット エージェントは、 共有メモリディレクトリなしで実行するのではなく、共有メモリディレクトリを使用します。

Web およびオーサリング UX の修正

  • IME セーフなメッセージ送信 - Enter キーを押すとチャット コンポーザーが送信されなくなりました。 中国語/日本語/韓国語の IME 候補を確認するために使用されます。
  • チャットではナレッジ リストが最新のまま - チャット ページでは KB メタデータが再ロードされます。 フォーカス、ページ表示、可視性が変更されるため、KB が新しく作成または再インデックスされる 完全に更新せずに表示されます。
  • Markdown プレビューは疑似タグを保護します - 未知の HTML のようなタグ <think> はソース行数を維持しながら表示用にエスケープされます。 エディター/プレビューの同期。
  • 共同作成者の出力ストリップ推論タグ - クローズド、エイリアス付き、属性付き、および 閉じられていない <think> / <thinking> ブロックは最終編集出力から削除されます。
  • ハイドレーションの前にテーマの初期化が実行されます - テーマのスクリプトがレンダリングされます サーバーから取得されるため、React がハイドレートする前に、暗い/明るい設定が適用されます。
  • ナレッジ UI フィードバックがより明確になりました - インデックス バージョン チップのラベルが明確になり、 失敗した空のアクティブなインデックスについて説明し、新しい UI と古い UI からの 404 について説明します。 Docker バックエンドは、コンテナーのプル/再作成を提案するようになりました。
  • メモリ ページのフィードバックがより明確になりました - リフレッシュ呼び出しは「チェック済み、いいえ」を区別します。 実際の失敗からの長期アップデート」。

起動と Windows の堅牢性

  • CLI/サーバー ストリームはレガシー コード ページを許容します - 起動スクリプトと API ランナーは、Windows での Unicode クラッシュを回避するために置換安全なテキスト ストリームを使用します。 GBK/CP936 などのロケール。
  • 子プロセスはより安全なエンコーディングを継承 - Web/ツアーの起動パスが設定されています PYTHONIOENCODING=utf-8:replace。
  • 生成されたフロントエンド環境ファイルは UTF-8 - start_web.py は次のように書き込みます。 明示的な UTF-8 エンコーディングを使用した web/.env.local。
  • GHCR compose はより新鮮な画像を取得します - docker-compose.ghcr.yml は現在、 掲載画像はpull_policy: alwaysです。
  • ドキュメント/ロケールが更新されました - README 永続メモが更新されました。 ポーランド語の README リンクが追加され、英語/中国語の UI コピーが欠落しました 知識、記憶、TutorBot の魂のテンプレート、および共同執筆者の下書きのラベル。

テスト

  • チャット RAG KB ルーティング、デフォルトの KB エイリアス、ナレッジの範囲を追加/更新しました ファイル/再インデックス API、埋め込みバッチ検証、LlamaIndex 無効ベクトル 障害、進行中のインデックス バージョン ステータス、増分追加ストレージ レイアウト、 TutorBot 自動起動/共有メモリ、メモリ移行、Windows CLI エンコーディング、 IME キーボードの処理、マークダウン タグ escaping、および推論タグのクリーンアップ。

アップグレードに関する注意事項

  • Docker ユーザーは、Web UI とバックエンドが機能するようにコンテナーをプルして再作成する必要があります。 知識 API は同期を保ちます。
  • 壊れた埋め込みプロバイダーまたは変更された埋め込みプロバイダーで KB のインデックスが作成された場合は、次を使用します。 埋め込み設定を修正した後、ナレッジ ページから インデックスを再作成します。
  • データを手動で永続化する場合は、新しい共有メモリ マウントを追加します。 ./data/memory:/app/data/memory。 フル Changelog: https://github.com/HKUDS/DeepTutor/compare/v1.3.0...v1.3.1
