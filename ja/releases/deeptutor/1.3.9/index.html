DeepTutor v1.3.9

パッチ 公開日2026年5月8日 出典HKUDS/DeepTutor 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#ディープチューター v1.3.9 #ディープチューター v1.3.9 Release Notes 発売日: 2026.05.09 v1.3.9 は、より広範な TutorBot を備えた v1.3.8 マルチユーザー基盤上に構築されています 導入オプション、思考モデルのためのより安全なプロバイダー ルーティング、よりスムーズな ウェブオンボーディングパス。 Zulip と NVIDIA NIM サポートを追加し、起動を改善します 人間工学に基づいており、前回のリリース後に報告された主要な問題の修正が組み込まれています。

ハイライト

TutorBot チャネルとプロバイダーの拡張

  • Zulip は TutorBot チャンネルになりました - ボットはプライベート メッセージを聞くことができ、 トピックをストリームする、allow_from を強制する、メンションのみまたはオープン ストリームを選択する 応答し、Zulip のイベント キューを非同期 TutorBot バスにブリッジします。
  • Zulip での数学とファイルの動作が向上 - LaTeX は Zulip に適したものに変換されます KaTeX マークアップ、アップロード/ダウンロード呼び出しでは、構成可能な再試行動作が使用されます。 添付ファイルのファイル名には、衝突を避けるためにアップロード パスのダイジェストが含まれています。
  • Zulip トピックで会話を分離 - ストリーム トピックが一部になる チャット/セッション キーの、空のトピックに対する安定した (no topic) フォールバック。
  • TutorBot は NVIDIA NIM をサポートしています - TutorBot では nvidia_nim が利用可能です プロバイダー構成とレジストリー検出 (NIM のストリーミング動作を含む) これにより、サポートされていない stream_options が省略されます。

モデルと実行時の信頼性

  • 設定されたコンテキスト ウィンドウが尊重されます - 安全上限は次のように引き上げられます。 1,000,000 トークン、大規模モデルのフォールバックは 65,536 のままなので、明示的です 128K スタイルのモデル設定はサイレント クランプされなくなりました。
  • Qwen 視覚検出は修正されました - Qwen VL モデルは次のように扱われます。 DashScope 全体のビジョン対応、OpenAI 互換、カスタム バインディング。
  • 最小限の思考モードはプロバイダーセーフです - DeepSeek、DashScope、VolcEngine、 BytePlus と MiniMax は拒否されたトップレベルを受信しなくなりました reasoning_effort=minimal; DeepTutor はプロバイダー固有の無効化を送信します 代わりに信号を送ります。
  • DeepSeek v4 のコストは追跡されます - リサーチ トークン アカウンティングが含まれます deepseek-v4-flash および deepseek-v4-pro の価格エントリ。

Web および CLI ポーランド語

  • deeptutor start は完全な Web スタックを起動します - CLI は次に委任します。 scripts/start_web.py なので、バックエンドとフロントエンドを 1 つから開始できます コマンドとランチャーの失敗は CLI 終了コードを通じて伝播します。
  • サイドバーのオンボーディングがより明確になりました - プライマリ ナビゲーション アイコンが表示されるようになりました 説明とキーボード フォーカスのサポートを含む、範囲が限定され、ローカライズされたツールチップ。
  • 複数行のユーザー メッセージは読みやすいまま - チャット メッセージのレンダリングは維持されます Shift+Enter 改行、コード ブロックと構造化プロンプトを修正 以前は 1 行に折りたたまれていました。
  • 割り当てられたリソースが理解しやすくなりました - モデル選択の概要 読み取り専用のナレッジベース アクションでは、より明確なラベルが表示されるようになりました。 非管理者、許可スコープのセッション。

マルチユーザーとセッション ストアのパリティ

  • 割り当てられたモデル オプションはセレクター コントラクトと一致します - 管理者以外の LLM の選択 プロファイル名、モデル名、ラベル、アクティブ/デフォルトのメタデータを返すようになりました。 Web モデル セレクターで予期されるのと同じ形状。
  • PocketBase セッションはより多くのチャット フローをサポート - メッセージのメタデータは 永続的で、最後のメッセージの検索が可能で、メッセージの削除は PocketBase 文字列 ID と SQLite 整数 ID。
  • 再生成はストレージニュートラルのまま - 再試行ロジックを回すと最後のデータが削除される可能性があります バッキング セッション ストアが整数を使用することを前提としないアシスタント メッセージ 主キー。

テスト

  • 構成解析、権限チェック、重複のための Zulip チャネル カバレッジを追加しました フィルタリング、メンション、ストリームトピックのスコープ設定、添付ファイルの抽出、再試行 動作、LaTeX 変換、入力ステータス、送信、アップロード、および起動 失敗。
  • レジストリ検出、スキーマ用の TutorBot NVIDIA NIM プロバイダー テストを追加しました 受け入れ、およびストリーミングリクエストの互換性。
  • Qwen ビジョン機能、明示的なコンテキスト ウィンドウ用の LLM 回帰テストを追加しました 予算、そして最小限の思考を持ったプロバイダーのkwargs。
  • deeptutor start がランチャー終了コードを伝播するように、CLI カバレッジを追加しました。
  • DeepSeek v4 モデル エントリにリサーチ トークン価格の適用範囲を追加しました。

アップグレードに関する注意事項

  • .[tutorbot] エクストラ、または requirements/tutorbot.txt をインストールまたはリフレッシュして、 Zulip ボットを有効にする前に、新しい zulip>=0.8.0,<1.0.0 依存関係を含めてください。
  • Zulip ボットを site、email、apiKey、allowFrom、および groupPolicy;より安全なストリーム展開には mention を使用し、open のみを使用します すべてのストリーム メッセージがボットに到達するタイミング。
  • LLM_REASONING_EFFORT=minimalをDeepSeek、DashScopeで使用する場合、 VolcEngine、BytePlus、または MiniMax の場合は、設定をそのままにしておきます。 v1.3.9 が翻訳します 正しいプロバイダー固有の無効ペイロードに変更します。
  • 設定された大きなコンテキスト ウィンドウが制限される代わりに受け入れられるようになりました。 トークンは 65,536 個なので、プロバイダーの制限と予想されるプロンプト コストの動作を確認してください。
  • オプションの PocketBase 展開では、messages コレクションに 再生成/セッションメタデータに依存する前の metadata_json JSON フィールド パリティ。

何が変わったのか

  • 修正: context_window の上限を引き上げ、https://github.com/HKUDS/DeepTutor/pull/442 の @wedone による qwen ビジョンのサポートを追加
  • 修正: https://github.com/HKUDS/DeepTutor/pull/447 の @Starfie1d1272 によりモデル価格表に deepseek-v4-flash と deepseek-v4-pro を追加
  • fix(llm): https://github.com/HKUDS/DeepTutor/pull/453 の @Starfie1d1272 によって拒否されるプロバイダーに、トップレベルのパラメーターとしてreasoning_effort=minimal を送信するのを停止します。
  • 功績: バックエンドとフロントエンドを一緒に起動する Deeptutor start コマンドを追加 (https://github.com/HKUDS/DeepTutor/pull/445 の @Starfie1d1272 により)
  • 修正(Web): https://github.com/HKUDS/DeepTutor/pull/449 の @kagura-agent によるユーザー チャット メッセージ内の改行を保持する
  • feat(tutorbot): https://github.com/HKUDS/DeepTutor/pull/452 で @wedone による Zulip チャンネルのサポートを追加
  • 功績: https://github.com/HKUDS/DeepTutor/pull/457 の @philliplagoc によるサイドバーのツールチップ
  • 修正: https://github.com/HKUDS/DeepTutor/pull/455 の @Bortlesboat による TutorBot NVIDIA NIM プロバイダーのサポートを追加
