DeepTutor v1.5.12

パッチ 公開日2026年8月13日 出典HKUDS/DeepTutor 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#ディープチューター v1.5.12 #ディープチューター v1.5.12 Release Notes 発売日: 2026.08.13 v1.5.11 は、回答の作成中に何が起こるかについてのものでした。これはその素材がどこから来たのかについてです。 Web 検索レイヤーは 1 つのテーブル上に再構築され、結果に密かに影響を及ぼしていた 3 つの欠陥が発見された方法です。その上に 6 つのプロバイダーが追加され、そのほとんどは中国本土からアクセス可能でした。 6 番目の文書解析エンジンが起動し、資格情報をローテーションした MCP サーバーは、本当の原因を除外する 1 つの説明で応答する代わりに、再接続します。ドロップイン — 移行や再インデックスの必要はありません。

新機能

Web 検索が再構築され、6 つの新しいプロバイダーが追加されました

プロバイダーのリストは、バックエンド レジストリ、ランタイム構成、設定ルーター、CLI ウィザード、フロントエンド カタログ、i18n、テストの 7 つの場所にコピーされており、それらはバラバラになっていました。フロントエンドは Serper を非推奨とマークしましたが、バックエンドは依然として Serper を提供していました。 7 つすべてが 1 つの SEARCH_PROVIDERS スペック テーブルから派生するようになりました。それを統合すると、3 つのサイレント欠陥が表面化しました。Serper の num は API に到達しなかったため、max_results は何もしませんでした。 Serper はプロキシ構成を削除しました。そしてジナには結果数の制限がまったくありませんでした。 このテーブルには、Doubao、Bocha、Zhipu、Firecrawl、Baidu Qianfan、Aliyun IQS の 6 つのプロバイダーが参加しています。これらは、仕様から派生した資格情報フィールドとともに [設定] → [カタログ] → [検索] に表示され、deeptutor init もそれらを提供します。 Doubao はリンクだけではなく回答を返します。 Firecrawl では全ページ抽出が追加されます。 Baidu は、公式 Qianfan API で qianfan として戻ります。古い baidu キーは復活せず、非推奨のままです。

探索に失敗してもターンが失敗することはなくなりました

ターン全体を終了するために使用されたレート制限、タイムアウト、または到達不能なホスト。リクエストは他の資格情報のある検索プロファイルをたどって、最後に DuckDuckGo をたどり、最上位の search_fallback キーで試行した内容を記録するため、トレースにはダウングレードが非表示ではなく表示されます。プロキシはリクエストとともに移動するため、フォールバックは引き続きリクエストの背後から機能します。 API キーの欠落は逆の種類の問題として扱われ、6 つの新しいプロバイダーでは依然として即時に失敗します。そのうち 5 つは中国でホストされており、DuckDuckGo はこれらのネットワークではアクセスできません。サイレントにダウングレードすると、「キーが構成されていません」というメッセージが別の場所で原因不明のタイムアウトに変わります。

LiteParse が解析エンジンに加わりました

6 番目のドキュメント解析エンジン。Text-only、MinerU、Docling、markitdown、PyMuPDF4LLM と並んで、[設定] → [ナレッジベース] で選択できます。軽量で、ローカル モデルのダウンロードは必要ありません。 pip install deeptutor[parse-liteparse]と一緒に取り付けます。

MCP サーバーは資格情報が変更されると再接続します

保存された認証情報をローテーションすると、ライブ接続はそのまま残ります。保存された設定には ${secret:...} 参照が保持されていたため、そのフィンガープリントはバイト同一であり、リロード差分では何も変更されていないと判断されました。接続は 解決された 構成に対してフィンガープリントされるため、アカウントは設定したばかりのキーを使用して再接続します。これとは別に、ツール呼び出し (ほとんどの場合は認証) 中のトランスポート エラーが SDK 自身のタスク グループ内で発生し、呼び出し元が完全なツール タイムアウトになるまで待機したままとなり、除外された 1 つの原因が報告されました。通話中に接続が監視されるようになったため、実際のエラーは、にかかった秒間にモデルとユーザーに通知されることになります。サーバーはクエリ パラメーターで資格情報を保持できるため、URL はこれらのメッセージから編集されます。

CodeBuddy と OrcaRouter

さらに 2 つのモデル プロバイダー: CodeBuddy/WorkBuddy (CodeBuddy SDK 認証を検証し、必要に応じてブラウザーのサインインを開始します)、および OrcaRouter (チャットと埋め込みの両方に使用できる OpenAI 互換の名前付きゲートウェイ)。

Codex は推論の努力を続けており、次のことを確認できます。

管理された推論努力のオーバーライドは、セッション間でリセットされるのではなく持続するようになり、OpenAI Codex はビジョン対応としてマークされているため、画像はドロップされずに到達します。 reasoning_effort="none" を拒否する Gemini 3 と 2.5 Pro は、デフォルトで minimal (これらのファミリが受け入れる最低レベル) になりました。

各種詰め合わせ

  • RAG 引用は構造化されたペイロードを読み取ります。 引用抽出では、テキスト形式の回答の解析よりも ToolResult.metadata["sources"] が優先されますが、通常は出典がまったく得られません。解析は古いトレースのフォールバックのままです。
  • 応答ツール呼び出しはクロスディスパッチではなくなりました。 欠落している出力項目 ID にリテラル fc_0 が入力され、ID として登録されたため、ID を省略した次の呼び出しは前の呼び出しのバッファーに解決され、その名前と引数で実行されました。プレースホルダーはエイリアスではなくなりました。
  • マスタリー パスはチャット セッションから独立しているため、パスを開いても、参加していたセッションが妨げられることはなくなりました。
  • チャット履歴は、スクロール中に表示されるのではなく、読み込み後に下部に表示されます。
  • アシスタント出力は、モデルがマーカー内の浮遊スペースを放出する場合、**bold** を正しくレンダリングします。
  • 古い Typer エクストラは両方のパッケージング マニフェストから削除されました。

アップグレードに関する注意事項

pip install -U deeptutor; Docker ユーザーは ghcr.io/hkuds/deeptutor:latest を引きます。スキーマの変更、インデックスの再作成、移行は必要ありません。

  • GET /api/v1/settings/provider-choices の形状が変更されました。 search 配列の各エントリは requires_api_key、requires_base_url、soft_fallback、および status になり、配列は exa、baidu、openrouter と status: "deprecated" を また 返すようになりました。これは、意図的に、client が名前のスペルミスから古い構成を区別できるようにするためです。 DeepTutor 独自の UI フィルターは status にあります。配列を直接レンダリングする他のコンシューマーは、同じことを行うまで、3 つの非推奨のオプションを表示します。
  • get_providers_info() エントリが requires_base_url になり、deeptutor config show および /api/v1/system 診断に達します。
  • 認識されない検索プロバイダー名は、呼び出されずに DuckDuckGo にフォールバックされるようになりました。以前は、exa、baidu、および openrouter のみがダウングレードされ、その他の不明な名前はすべて上げられました。明示的な none は依然として発生します。これは、検索がオフになっていることを意味するためです。
  • get_available_providers() は、以前よりも多くの内容を返します。 以前は各プロバイダーをインスタンス化し、資格情報エラーを飲み込んでいたため、アクティブなプロバイダーと、キーを必要としない 2 つのプロバイダーのみを事実上報告していました。認証情報が完了しているすべてのプロファイルをレポートするようになりました。
  • Brave には、CLI 診断で Brave Search ではなく Brave というラベルが付いています。UI にはすでに短い名前が表示されています。 フル Changelog: https://github.com/HKUDS/DeepTutor/compare/v1.5.11...v1.5.12
