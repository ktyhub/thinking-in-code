#ディープチューター v1.2.4

ディープチューター v1.2.4 Release Notes

発売日: 2026.04.25

ハイライト

チャットでより多くの添付ファイル形式をサポート

v1.2.3 ドキュメント添付パイプラインは、Office ファイルを超えて拡張されました。チャット添付ファイルは、ナレッジ ベース インジェスト ルーターと同じテキスト形式を受け入れるようになりました: マークダウン、プレーン テキスト、ログ、JSON/YAML/TOML、CSV/TSV、LaTeX/BibTeX、HTML/XML/SVG、スタイルシート、スクリプト、一般的なソース コード ファイル (.py、.js、.ts、.tsx、.java、 .cpp、.go、.rs、.sql、.sh など)。

  • KB ルーティングとのバックエンド パリティ - deeptutor/utils/document_extractor.py は FileTypeRouter.TEXT_EXTENSIONS をインポートするため、チャットの添付ファイルと KB アップロードはテキスト/コード形式に関する 1 つの信頼できる情報源を共有します。 FileTypeRouter.decode_bytes() は、UTF-8 / UTF-8-BOM / GBK / GB18030 / Latin-1 / CP1252 フォールバック チェーンを一元化します。
  • 読み取り可能なソースとしての SVG - .svg が RAG テキスト拡張セットに追加され、ビジョン画像ではなくドキュメント添付ファイルとして扱われるため、フロントエンドが安全なサムネイル プレビューをレンダリングしながら、LLM が XML ソースを検査できるようになります。
  • 入力された添付ファイルの UX - web/lib/doc-attachments.ts は、OFFICE_EXTS、TEXT_LIKE_EXTS、SVG 検出、より豊富な MIME/拡張子のフォールバック、およびコード、シェル、JSON、構成、データ、マークアップ、スタイルシート、プレーン テキスト、Office ドキュメント、および SVG のカテゴリ固有のアイコンを公開するようになりました。
  • Composer のコピーが更新されました — ドラッグ アンド ドロップのヒントに、古い Office のみのリストではなく、「画像、Office ドキュメント、コード、テキスト」が表示されるようになりました。

ワンコマンドセットアップツアー

scripts/start_tour.py は、純粋な構成ウィザードから、ローカル環境を検出し、依存関係をインストールし、プロバイダー構成をガイドできる 7 ステップの新規インストール パスに進化しました。

  • 依存関係のインストール手順 — ツアーでは Python、uv、Node.js、および npm をチェックします。バックエンド要件をインストールし、編集可能モードで DeepTutor をインストールし、ライブ端末出力でフロントエンド npm install を実行します。
  • uv pip の互換性 (#376) — Python 依存関係のインストールでは、利用可能な場合は uv pip が優先され、--python <current-interpreter> がバインドされるため、無関係な .venv / $VIRTUAL_ENV ではなく、ツアーを実行しているインタープリターにパッケージが配置されます。
  • Windows npm 検出 (#381) — npm 呼び出しは Windows で npm.cmd を使用し、バージョン チェックを修正し、npm が実行可能ファイルではなくコマンド shim として公開されているシステムにコマンドをインストールします。
  • プロバイダー レジストリ主導の LLM 選択 - ウィザードは完全な PROVIDERS レジストリから読み取り、モードごとにプロバイダーをグループ化し、共通サービスを強調表示し、custom_anthropic、OpenRouter、SiliconFlow、Volcengine / BytePlus コーディング プロバイダー、GitHub Copilot、OpenAI Codex、llama.cpp、OVMS、MiniMax、Mistral、 Qianfan、Step Fun、Xiaomi MiMo。
  • 検索と構成のヒント — Serper は検索プロバイダー リストで利用できます。 Azure/API バージョンとプロキシ プロンプトには、英語と中国語の両方でインライン ガイダンスが表示されるようになりました。
  • 長いリストの端末 UX — scripts/_cli_kit.py は、スクロール ウィンドウ内に「さらに上/下」インジケーターを備えた長い選択メニューを表示し、プロバイダー リストが画面の高さを超えたときに端末の行が古くならないようにします。

チャット マークダウン エクスポート

チャット ページには、[ノートブックに保存] と [新しいチャット] の横に マークダウンをダウンロード アクションが追加されました。 web/lib/chat-export.ts は、現在の会話をタイトル、ISO エクスポート タイムスタンプ、ロール見出し、機能ラベル、添付ファイル メタデータを含むマークダウンとしてシリアル化し、サニタイズされた日付スタンプ付きのファイル名を付けてダウンロードします。これにより、会話を共有、アーカイブ、または外部メモに移動するための軽量のローカル エクスポート パスがユーザーに提供されます。

ナレッジベース管理 UI の洗練

ナレッジ ページは、日々の管理をより緻密にするために強化されました。

  • 作成およびアップロードのドロップ ゾーンは、簡潔なインライン アップロード ポリシーの概要を含む、よりシンプルな破線カードになりました。
  • KB カードは、4 つの大きな統計パネルから、ドキュメント数、インデックスの準備状況、最終更新時刻、プロバイダー、埋め込みモデル、ライブの進行状況、およびストレージ パスを示すコンパクトな行に移動しました。
  • デフォルト/削除アクションが視覚的に簡略化され、カードの高さが減り、大きな KB リストのスキャンが容易になりました。

ドキュメントとローカリゼーションの更新

README ファミリは、新しいインストールのストーリーとプロバイダーの内容に合わせて更新されました。

  • ポーランド語の README - assets/README/README_PL.md は、プロジェクトの README (#379) の完全なポーランド語翻訳を追加します。
  • セットアップ ドキュメント - メイン README および多言語 README では、推奨されるフレッシュ クローン パスとしてガイド付きツアーが説明されています。Python 環境を作成し、python scripts/start_tour.py を実行し、毎日の起動に python scripts/start_web.py を使用します。
  • プロバイダー ドキュメント - custom_anthropic、MiniMax の正規エンドポイント、コーディング プラン プロバイダー、ローカル プロバイダーを含む、v1.2.3 プロバイダー レジストリのプロバイダー テーブルが更新され、OpenAI Codex / GitHub Copilot の認証メモが明確になりました。
  • リリース/ニュース セクション - 多言語の README には、v1.2.2 および v1.2.3 の概要、貢献ガイドのコールアウト、および 20,000 スター コミュニティのマイルストーンが含まれています。

UIとテーマの修正

  • テーマ対応のポップオーバー - コンポーザーの機能/ツール/リファレンス/スキル メニューで、--card の代わりに --popover と背景ブラーが使用されるようになり、Glass テーマとダーク ポップオーバー コンテキストのコントラストが向上しました。
  • ネイティブ カラー スキームのヒント - ライト、ダーク、スノー、ガラス テーマのルートは正しい color-scheme を宣言し、ネイティブ コントロールとブラウザーでレンダリングされたサーフェスを改善します。
  • スムーズ スクロール ハイドレーション - グローバル スムーズ スクロールは、意図せず適用されることを避けるためにルート レイアウトによって設定された属性を使用して、html[data-scroll-behavior="smooth"] の背後でゲートされるようになりました。
  • サイドバーのロゴのサイズ設定 — サイドバーのロゴ画像は、レイアウトの小さな変更を防ぐために、明示的にレンダリングされた幅/高さのクラスを固定するようになりました。

クリーンアップ

古い nanobot サブモジュール ポインターと非推奨の scripts/extract_numbered_items.sh スタブをリポジトリから削除しました。 v1.2.x コードベースは、従来のヘルパーではなく、ツリー内ドキュメント抽出と RAG ルーティング パスに依存するようになりました。

テストスイートの拡張

  • バックエンド ドキュメント抽出 - tests/utils/test_document_extractor.py は、プレーン テキスト、Python ソース、JSON、CSV、Markdown、UTF-8-BOM 入力、GBK フォールバック デコード、および SVG ソース抽出をカバーするようになりました。
  • フロントエンド添付ファイル分類 - web/tests/doc-attachments.test.ts は、テキスト/コードの受け入れ、ドキュメントとしての SVG ルーティング、大文字と小文字を区別しない SVG ファイル名検出、およびコード用の新しいアイコン カテゴリ、JSON、構成、シェル、データ、マークアップ、スタイルシート、および SVG をカバーするようになりました。
