DeepTutor v1.6.11

パッチ 公開日2026年9月24日 出典HKUDS/DeepTutor 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#ディープチューターv1.6.11 #ディープチューター v1.6.11 Release Notes 発売日: 2026.09.24 v1.6.10 に基づいて構築された v1.6.11 は、幅広いリリースです。フランス語とウクライナ語がインターフェイスに加わり、没入型読書でフォルダー、図、チャット内の選択アクションが取得され、Office ファイルが実際のページとしてプレビューされ、ナレッジ ベースは同期を保つ方法を学習します。移行は追加的であり、最初の起動時に実行されます。 Docker イメージは大きくなり (LibreOffice)、/app/data が書き込み可能でない場合、コンテナーは起動を拒否するようになりました。

新機能

4 つのインターフェース言語、14 の応答言語

このインターフェースは現在、設定 → 一般 の選択から英語、中国語、フランス語、ウクライナ語で出荷されています。ウクライナ語は完成です。まだ翻訳されていないフランス語の文字列は英語にフォールバックされます。モデルの返信は 14 の言語に設定でき、コンポーザーの新しい /language コマンドは、アカウントのデフォルトを変更することなく、1 つの会話に対して返信言語を固定します。

没入型読書、再構成

読書コレクションは、ファイルと会話用の独自のページを備えた色付きのフォルダーになり、全画面学習 モードではアプリの残りの部分が非表示になります。文章を選択し、説明、翻訳、またはガイドを選択すると、引用を添付した通常のメッセージが読書チャットに投稿されるため、やり取りは会話履歴に残ります。 このページでクイズを実行 では、会話モードを切り替えることなく、開いているページで 3 つの質問からなるクイズが実行されます。 EPUB には表示コントロール (フォント、線幅、テーマ、見開き 2 ページ) が備わっており、組み込みアクションが学習者の年齢に適応し、資料が改訂されると注釈が再固定されます。

写真や図がモデルに届く

DOCX、PPTX、PDF に埋め込まれた画像が抽出され、元の位置に表示され、チャットの添付ファイルからビジョン モデルに転送されます (ドキュメントごとに最大 12 個)。ベクトルとして描画されたページはラスター化されるため、モデルは図を表示でき、図のキャプションはオプトイン解析設定として利用できます。既存のマテリアルは自動的に再抽出されません。「アップグレードに関する注意事項」を参照してください。

Office ファイルをページとしてプレビューする

チャット ビューアとナレッジベース ファイル プレビューは、従来の形式を含む Word、PowerPoint、Excel ファイルを、LibreOffice を通じてページ化された PDF としてレンダリングします。 LibreOffice がないと、DOCX と XLSX はブラウザ内のレンダラーにフォールバックし、他の形式でテキストを抽出します。ビューアには、新しいタブ ランチャーと、よりスムーズな開閉アニメーションも追加されました。

最新の状態を保つナレッジベース

ドキュメント サイトのソースは、ジョブ履歴を使用して永続的なスケジュール (デフォルトでは 24 時間ごと、ソースごとに 1 ～ 168 時間) で再同期され、キャンセルして再試行されます。リンクされたローカル フォルダーには、追跡されたファイルと、新しいファイルと変更されたファイルを選択する 今すぐ同期 アクションが表示されます。 .bib ファイルにはインデックスを付けることができ、新しい zotero_search ツールは Zotero ライブラリにクエリを実行し、画像のみでスキャンされた PDF はローカル OCR にフォールバックし、LightRAG は LLM タイムアウトを公開します。空のナレッジ ベースは、すべてのローカル エンジンの最初のアップロード時にブートストラップするようになりました。

学習の進捗状況

新しい [設定] → [学習の進行状況] ページには、各教材をどこまで読んだか、アカウントを対象とした最近の学習アクションが表示されます。マスタリーレビュー計画では、パスごとのリコール目標を設定します。

プロバイダー、エージェント、輸入業者

プロバイダー リストに統一的に参加し、Grok CLI は My Agents のライブ サブエージェントに参加し、インポート ウィザードは公式 ChatGPT データ エクスポートから conversations.json を受け入れます。レート制限されたリクエストは、設定されているすべての API キーを試行するようになり、temperature を拒否するクロード モデルはどのルートでも受信しなくなり、Codex モデル カタログは現在の Codex client バージョンを追跡します。

アカウントと展開

管理者は、CSV からユーザーをインポートし、バッチでユーザーを削除できます。プライベート/パブリックの分割展開では、プライベート ホストへのパスワード サインインを制限し、有効期間の短いハンドオフ リンクを介してパブリック デバイスをペアリングできます。 [設定] には、認証情報不要でレビュー可能な 4 つのプリセットが用意されています。 Docker はバインド マウント (Unraid) で PUID / PGID を尊重し、スタンドアロン ビルドは静的アセットをパッケージ化し、パートナー QR オンボーディングはプレーン インストールで機能します。

チャット、音声、パートナー

失敗したターンは保存されたリクエストから再送信でき、拒否された再生成では前の回答が保持されます。音声は LaTeX を単語として読み上げます (数学音声、デフォルトでオン)。オプションの Google Web リスク フィルタリングにより、フラグ付きの検索引用が削除されます。 Feishu パートナーはスレッドで返信し、ダイレクト メッセージで /model でモデルを切り替えます。Telegram の返信は元のトピックに着陸し、解決されたグループ ディスカッションは Markdown としてエクスポートされ、ブラウザーの同期 によりパートナーの会話がブラウザー間で転送されます。

修正

任意の JSON ファイルを上書きする可能性があるノートブックのパストラバーサルのバグは解決されました。許可ファイルはアトミックに書き込まれ、破損した場合はフェイルクローズされ、学習者は明示的なナレッジベースの読み取りセットに限定され、再インデックスの進行状況がワーカー間で漏洩することはなくなり、IMA は空の検索の引用を報告しなくなり、使用料金はモデルの正確な一致を優先します。

アップグレードに関する注意事項

pip install -U deeptutor を実行します。 Docker ユーザーは ghcr.io/hkuds/deeptutor:latest を引きます。

  • Docker: 画像には LibreOffice フォントと CJK フォントが含まれるようになり、著しく大きくなりました。エントリポイントはコンテナ ユーザーを PUID / PGID (デフォルト 1000) に再マップし、/app/data が書き込み可能でない場合は起動時に停止します。後で失敗するのではなく、バインド マウントの所有権を修正するか、PUID / PGID を設定します。
  • ソースのインストール: ページングされた Office プレビューを取得するには、soffice を PATH に置きます。これがないと、プレビューは上記のようにフォールバックします。
  • Web ソースは自動同期を開始します。 既存のドキュメント サイト ソースは、アップグレード後にデフォルトで 24 時間のスケジュールに設定されます。オフにするか、ナレッジ ベース ページでソースごとの間隔を変更します。
  • 古い読み物資料は抽出されたままです。 すでに取り込まれている資料に図 (およびオプションのキャプション) を追加するには、python scripts/reading_refresh_figures.py --all --yes を実行します (キャプションには --caption を追加します)。注釈は保存されます。
  • 削除: 読み取り「オープナー」エンドポイント (/reading/workspaces/{id}/openers) とその 読み取りオープナー タスク モデル。保存されたピンは自動的に削除されます。
  • 新しいオプションのキー: UNIFICALLY_API_KEY; auth.private_login_hosts / AUTH_PRIVATE_LOGIN_HOSTS および AUTH_TRUSTED_FRONTEND_PROXY_IPS は分割展開用。 tools.web_search.source_filtering.use_web_riskとGOOGLE_WEB_RISK_API_KEY。 フル Changelog: https://github.com/HKUDS/DeepTutor/compare/v1.6.10...v1.6.11
