DeepTutor v1.6.5

パッチ 公開日2026年9月6日 出典HKUDS/DeepTutor 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#ディープチューター v1.6.5 #ディープチューター v1.6.5 Release Notes 発売日: 2026.09.06 v1.6.5 は、DeepTutor に作業用の独自のフォルダーを提供します。ディレクトリーを指定すると、アシスタントはそこにあるものを参照、読み取り、検索することができ、生成されたものはすべて予測可能な 1 つの場所に配置されます。その場所から出るものは最初に承認が必要です。そのあたりでは、コードの実行が 1 つのツールに集約され、マスタリー パスが教育と再設計がいつ許可されるかを学習し、設定では最終的に「未構成」と「壊れた」を区別します。ローカルインストール用のドロップイン。 Docker ユーザーは、以下のワークスペース マウントに関する注意事項を読む必要があります。

新機能

選択したコンテンツ ワークスペース

DeepTutor で任意のフォルダーを指定すると、それがセッション全体の作業ディレクトリになります。アシスタントはその内容を一覧表示、読み取り、検索できるため、何もアップロードせずに独自の素材を利用できます。生成されたファイルは outputs/ に配置され、ファイルを outputs/ から残りのフォルダーに移動することは、静かに行われる作業ではなく、明示的なユーザー承認の手順です。 [設定] から管理するか、deeptutor workspace show、set、reset を使用して管理します。

1 つのツールでコードを実行

code_execution と exec は 1 つの役割を担う 2 つのツールでした。これらは現在、Python、C、C++、またはシェルを使用する単一の exec です。ターン内のすべての呼び出しは 1 つの作業ディレクトリと 1 つの依存関係環境を共有するため、後の呼び出しでは、最初からやり直すのではなく、前の呼び出しで書き込まれたファイルを再度開いて修正できます。

マスタリー パスは自分がどのモードにあるかを認識します

研究目標は、アウトラインの設計、作業の進め方、レビューの 3 つのモードの間で移動し、利用可能なツールもそれに続きます。マップを変更できるのは outline だけであるため、講師はレッスン中に黙ってあなたの計画を書き直すことはできません。 study と review のみがあなたを調査することができ、実際に概要が合意されるまではどちらも開始されません。提示された質問はターンを終了するカードとして届くため、答えることは意図的な行為です。

設定は「セットアップされていない」と「壊れている」を区別します

概要では、すべての機能がブロッカー、警告、または提案としてランク付けされ、各行にインストールが本当にその機能に依存しているかどうかが記録されます。設定していないオプションのビデオ モデルは、障害として報告されなくなりました。あなたが選択したパーサーが機能しません。マトリックスには ID、ブール値、および理由コードのみが含まれます。プロバイダー URL、モデル名、資格情報、および例外テキストはサーバー上に残り、モデル プロバイダーがそれを構築するために呼び出されることはありません。

質問は作成中に表示されます

ask_user カードは、散文で紹介されてから数秒後に一斉に届くものでした。カードはイントロとともに表示され、モデルが書き込むにつれてそのオプションが増えていくため、カードが何かを尋ねた瞬間にターンが沈黙することはなくなりました。

継続できるビデオ学習

接続された Invidious アカウントは独自のアダプターを取得し、再生が進んでもトランスクリプト キューが表示されたままになり、タイムスタンプ付きのメモが Markdown にエクスポートされます。視覚的な学習ボードには、セッションで生成された内容が収集されます。

ナレッジベースはインデックスモデルを固定します

LightRAG ナレッジ ベースは、どのモデルがインデックスを作成したかを記録し、ベースごとにそれらのモデルを固定できるため、インデックスを再作成しても、既存のインデックスの背後にある埋め込みが暗黙的に変更されることはありません。

ネットワーク上のサブエージェント

強化されたリモートの Herme バックエンドがローカルのサブエージェントのハーネスに接続されるため、相談されたエージェントはこのマシン以外の場所で実行できます。

修正

Chinese Markdown はストリーミング中に生のコンテンツを保持します。安全でない Web 検索のタイトルとスニペットはフィルタリングされます。 DeepSeek 推論リプレイ 応答ターンからの 400 は、ターンに失敗するのではなくフォールバックします。設定は独自のペイン内でスクロールします。従来の Mastery /study URL は /sessions にリダイレクトされます。クイズカードのテキストは Unicode エスケープをデコードします。復元された読み物は遅延してロードされます。更新時にソースのチェックアウトが正しく検出されます。

アップグレードに関する注意事項

pip install -U deeptutor を実行します。 Docker ユーザーは ghcr.io/hkuds/deeptutor:latest を引きます。設定、書籍、セッション、学習データを手動で移行する必要はありません。

  • code_execution ツールは廃止されました - その機能は exec に移動されました。 code_execution という名前のカスタム プロンプト、スキル、またはプラグインは、代わりに language を使用して exec を呼び出す必要があります。
  • Docker ワークスペース マウント。 コンテナーは、安定したパス /workspace にコンテンツ ワークスペースがあることを期待するようになりました。ホスト フォルダーを選択するには、python scripts/docker_compose.py up -d の前に DEEPTUTOR_WORKSPACE_HOST=/absolute/host/folder を設定します。省略すると./data/user/workspaceのままとなります。ヘルパーはフォルダーとその outputs/ を作成するため、バインド マウントは root 所有ではありません。
  • サンドボックス ランナーの認識が低下します。 data/users はマウントされなくなりました。読み取り専用の /workspace と書き込み可能な /workspace/outputs を受信し、DEEPTUTOR_RUNNER_ALLOWED_WORKDIRS によって制限されます。実行されたコードは、別のアカウントの設定、チャット履歴、ナレッジ ベースにアクセスできなくなります。
  • マルチユーザー展開では、マウントされたワークスペースが共有されます。 DEEPTUTOR_WORKSPACE_ROOT が設定されている場合 (提供されるすべての Compose ファイルによって設定されます)、その 1 つのフォルダーがすべてのアカウントのコンテンツ ワークスペースとなり、パスは設定でロックされているとして表示されます。ユーザーごとのワークスペースを維持するには、未設定のままにしておきます。
  • deeptutor.config.schema、.defaults、.accessors、または .constants をインポートする拡張機能は、公開設定画面に移動する必要があります。それらのモジュールは削除されました。
  • 英語と中国語のガイドを deeptutor.info でまとめて更新しました。 フル Changelog: https://github.com/HKUDS/DeepTutor/compare/v1.6.4...v1.6.5
