#ディープチューター v1.7.0 Release Notes

発売日: 2026.10.28

v1.6.15 をベースにした v1.7.0 は、モジュール式インストール、更新された学習ワークスペース、Dito を使用したブロックベースのノートブック、およびナレーション付きビデオ レッスンを提供します。フルアプリのアップグレードでは deeptutor[full] が使用されるようになりました。既存のランタイム データは、インストールされたパッケージとは分離されたままになります。

新機能

使用するパーツを取り付けます

deeptutor はコア チャット、CLI、および SDK を提供するようになりました。 deeptutor[full] は、Web アプリと標準機能モジュールを選択します。 deeptutor-cli パッケージは互換性エイリアスになります。 deeptutor module list を使用して、インストール済み、有効化、準備完了の状態を検査し、アプリの停止中にモジュールを有効化、無効化、インストール、または削除します。依存関係チェックにより必要なモジュールが保護され、削除によりユーザー データが保持されます。

学習を中心に構成されたワークスペース

モダン レイアウトとクラシック レイアウトでは、異なるナビゲーション配置が提供されます。ホームには、チャット、タスクボード、学習ノート、カレンダーがまとめられています。学習とリソースにより、学習活動や教材にアクセスできるようになります。チャット モード、コントロール、開始プロンプトをカスタマイズしたり、新しい学習ページに表示される学習方法を選択したりできます。会話とリソースのナビゲーションは、ワークスペースの境界を維持します。

Dito が横にあるノートブック ページ

Learning ノートブックは、以前の Co-Writer エディターをページ、サブページ、およびブロックに置き換えます。 Word 文書をインポートし、お気に入りからソース レコードを挿入し、Dito と一節について話し合い、提案された編集を承認する前に確認します。ページを Markdown または Word としてエクスポートします。お気に入りには保存されたソース レコードが保持されます。ノートのページには、あなた自身の書き込みと理解が保存されます。

ビデオレッスンと無料の読み聞かせ

[ビデオ レッスン] を選択すると、キャプションとオプションの Microsoft Edge ナレーション付きでブラウザーで直接再生されるレッスンが生成されます。フレーム チェックは、バインドされた WebAssembly インタープリター内で生成されたコードを実行します。 Dockerは不要です。 Microsoft Edge も読み上げプロバイダーに加わり、iOS での応答再生の信頼性が向上しました。

より信頼性の高い個別指導とインデックス作成

互換性のある中断された LlamaIndex の再構築は、完了した埋め込みチェックポイントを再開できます。ナレッジベースの作成では同じ名前のドキュメントが保持され、1 つのキャプション グループが失敗しても取り込み全体が中止されることがなくなりました。チャットはワーカーの失敗をより一貫して回復し、完了した人間的思考は履歴再生から除外され、プロンプト キャッシュではより安定した会話プレフィックスが使用されます。 Guided Learning では、引用をチェックする際に数学的意味が保持され、レビュー作業がその適格性の範囲内に留まります。

英語と中国語のガイドは、deeptutor.info でこのリリースと同期されています。

アップグレードに関する注意事項

  • 完全なアプリ: DeepTutor を停止し、ランタイム ホームをバックアップしてから、python -m pip install --upgrade "deeptutor[full]==1.7.0" を実行します。同じ DEEPTUTOR_HOME で再起動する前に、python -m pip check と deeptutor module list を実行します。ベア deeptutor はコアのみを選択するようになりました。
  • レガシー CLI パッケージ: 最初に python -m pip uninstall deeptutor-cli を実行し、次に新しいコアまたはフル プロファイルをインストールします。必要に応じて、互換性エイリアスとして deeptutor-cli==1.7.0 を再インストールします。古い CLI は共有 Python ファイルを所有しているため、同じトランザクションでアップグレードすると、新しいコアに必要なファイルが削除される可能性があります。パッケージを削除すると、ランタイムホームのデータはそのまま残ります。
  • ソースのインストール: requirements/full.txt、次に python -m pip install -e . --no-deps をインストールします。オプションのソース依存関係には python scripts/install_extras.py <extra> を使用します。ソース チェックアウト サポート モジュールの有効化/無効化。パッケージのインストール/アンインストールにはホイール環境が必要です。
  • Docker: ghcr.io/hkuds/deeptutor:1.7.0 または :latest をプルし、既存のデータ ボリュームでコンテナーを再作成します。
  • ビデオ レッスン: バックエンドには Node.js 22+ と npm が必要です。最初に、固定されたレンダリング パッケージをダウンロードして使用します。ナレーション用にedge-ttsを追加インストールします。ナレーションが利用できない場合、レッスンはキャプションを維持し、無音で再生されます。
  • モジュール バージョン: コア ホイールとフィーチャー ホイールは一致する必要があります。モジュールを変更する前に、アクティブなサーバーと CLI を停止してください。実行中のアプリの下にあるパッケージをアンインストールするのではなく、依存関係ブロッカーを検査します。 モジュールのインストールと移行 を参照してください。
