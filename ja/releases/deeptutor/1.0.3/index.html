DeepTutor v1.0.3

#ディープチューターv1.0.3 #ディープチューター v1.0.3 Release Notes 発売日: 2026.04.13

ハイライト

質問ノートブック — 統合クイズレビューシステム

単一目的の「誤答ノート」を完全な 質問ノート に置き換えました。このノートブックには、すべてのクイズの問題 (正解および不正解) が豊富なメタデータ (質問の種類、選択肢、説明、難易度) とともに保存されます。各エントリは、整理されたレビューのために ブックマーク と カテゴリのタグ付け をサポートしています。新しい専用の /notebook ページでは、フィルタリング (すべて/ブックマーク済み/間違っている)、カテゴリ管理 (作成、名前変更、削除)、元のセッションへの直接リンクが提供されます。 QuizViewer コンポーネントにはインライン ブックマークとカテゴリ コントロールが統合され、ユーザーはクイズ フローから離れることなく質問を整理できるようになりました。

Visualize での人魚図のサポート

3 番目のレンダリング タイプ Mermaid を使用して Visualize 機能を拡張しました。分析エージェントは svg、chartjs、mermaid のいずれかを選択し、構造図 (フローチャート、シーケンス図、クラス図、マインドマップなど) には Mermaid を優先します。コード ジェネレーターとレビュー エージェントは対応するプロンプト更新を受け取り、フロントエンド VisualizationViewer は専用の <Mermaid> コンポーネントを介してマーメイド図をレンダリングします。

埋め込みモデルの不一致の検出

ナレッジ ベースには、インデックス時に使用される埋め込みモデルとディメンションが記録されるようになりました。ロード時に、システムは保存されているフィンガープリントを現在構成されている埋め込みモデルと比較します。不一致の KB には、embedding_mismatch および needs_reindex のフラグが立てられます。 RAG 検索パイプラインでは、不一致の KB をクエリすると警告が表示され、ナレッジ ページにはアラート バッジが表示されるので、ユーザーはインデックスを再作成する必要があることがわかります。

Qwen / vLLM 互換性のためのシステム メッセージのマージ

AgenticChatPipeline と ChatAgent の両方で複数のシステム メッセージを 1 つのマージされたシステム メッセージに統合し、複数システム メッセージの会話を拒否する vLLM 経由で提供される Qwen モデルとの互換性を修正しました。コンテキスト ビルダーは、冗長性を避けるために、保存された履歴から重複したシステム メッセージをフィルター処理するようになりました。

LM Studio および llama.cpp プロバイダーのサポート

LM Studio (localhost:1234) および llama.cpp (localhost:8080) に、自動ベース URL 検出と openai_compat バックエンド、さらに埋め込みプロバイダー エイリアス マッピングを備えたファーストクラス ProviderSpec エントリが追加されました。

ガラスのテーマ

すりガラスのカード表面、グラデーションの背景、グロー アクセント ボタンを備えた新しい Glass テーマが導入されました。テーマスイッチャーは、ライト→ダーク→ガラスと循環するようになりました。

ディープリサーチレポートエージェントの回復力

レポート エージェントで構成可能な再試行ロジックを備えた共有 _call_llm_json ヘルパーを抽出し、導入、セクション本文、および結論生成用の 3 つの同一のインライン LLM-call-then-parse ブロックを置き換えました。

ドキュメントの移行

従来の VitePress docs/ フォルダーを削除しました。ドキュメントはプロジェクト Web サイトに移行されました。
