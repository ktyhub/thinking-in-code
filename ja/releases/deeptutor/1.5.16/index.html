DeepTutor v1.5.16

パッチ 公開日2026年8月21日 出典HKUDS/DeepTutor 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#ディープチューター v1.5.16 #ディープチューター v1.5.16 Release Notes 発売日: 2026.08.22 v1.5.15 はブック リーダーの下にキャプチャ受信ボックスを追加し、そうすることでページがめくれなくなりました。この問題は、新しい接続されたナレッジ ソース (独自のアドオンが埋め込む MarginNote 4 ライブラリ) と並行して修正され、特定のゲートウェイ経由でのみ到達できた一連の障害 (プロバイダーが拒否するまで増加するツール呼び出し ID、意図的に省略したパラメーターに対する拒否された埋め込み、および適切なバインディングに名前を付けた場合にのみ適用される温度制限) が修正されました。ドロップイン — 移行や再インデックスの必要はありません。

新機能

知識ベースとしての MarginNote 4

ライブラリを接続すると、MN4 アドオンがメモ、抜粋、カード、マインドマップ ノードをライブラリにプッシュします。アップロードやインデックスはなく、MarginNote からは何もコピーされません。ライブラリの デバイス タブからデバイスをペアリングし、ワンタイム トークンをアドオンに貼り付けると、DeepTutor が所有するストアに同期が段階的に到着します。 このライブラリを有効にすると、rag ではなく、独自の 7 つのツールで実行されます。抜粋テキストとメモ テキストの検索、単一オブジェクトの読み取り、タイプ別のリスト、ドキュメントの子の探索、リンクの追跡、タグによるフィルター、マインドマップ カードの読み取りです。チャット ループは、Obsidian Vault の場合と同様に、それらに順番を渡します。インデックスを保持していないライブラリには、チャンク化するための検索用のものが何もないためです。 @evan188199-tech により #931 として投稿されました。これはフェーズ 1、つまり読み取り専用ナビゲーションです。ライトバックが予定されています。

本のページがまためくられる

キャプチャ受信トレイは、リーダーのフレックス行をフレックス列にせずに、リーダーのフレックス行の 2 番目の子として配置されたため、PageReader の h-full は auto に折りたたまれました。つまり、本文のスクロールが停止し、ページめくりのフッターが完全に表示されなくなりました。一行レイアウトの修正。ここには型やテストには何も表示されないため、実行したすべてのゲートは回帰によって緑色でした。

ストリーミングされたツール呼び出し ID の増加が停止する

OpenAI 互換プロバイダーの前にあるルーターは、デルタ チャンクごとにツール呼び出し id 全体を再送信する場合があります。 3 つのコア サイトがそれを割り当てる代わりに追加したため、ID はチャンクごとに 1 コピーずつ増加し、#937 では 47,241 文字が表示され、プロバイダーの 64 文字の上限を超えると、すべてのラウンドが Invalid 'messages[i].tool_calls[0].id': string too long で終了し、「モデル出力から有用な応答を生成できませんでした」ことが表面化しました。 name には両方のサイトで同一の欠陥があり、そのゲートウェイでは潜在的であり、その名前を繰り返すゲートウェイでは致命的でした。 3 つのサイトは 1 つのアキュムレータを共有するようになりました。id と name は全体として到着して割り当てられ、arguments は断片として到着して連結されます。

モデルの制限はルートではなくモデルに従います

Kimi モデルはサーバー側で温度をロックし、HTTP 400 で明示的な値を拒否します。そのオーバーライドは v1.5.5 より前から存在していましたが、設定されたバインディング 仕様から解決されました。そのため、普通のことをして Moonshot で binding="openai" を指定した #938 に対しては起動されませんでした。ルートは制限を強制するものではないため、ルートは決定しません。モデルについて何かを述べている場合は設定された仕様が優先され、それ以外の場合はモデル自体のベンダー仕様が答えます。すべてのモデル固有のオーバーライドは、ジェネリック バインディングの背後で同じように失われていました。

encoding_format を要求するゲートウェイから埋め込みを回復します

ModelScope は、欠落している encoding_format を '' として読み取り、要求を拒否します (#934)。 SiliconFlow は、フィールドが present の場合にはそれを拒否するため、フィールドを省略します。同じ Qwen3-Embedding 重みがその不一致の両側で提供されるため、両方を満たすデフォルトとモデルファミリー ルールは存在しません。ハッピー パスはバイト同一です (フィールドはまだ省略されています)。送信しようとしているパラメータと値の両方を指定する 400 では、encoding_format="float" で 1 回の再試行が行われます。

インデックス内の画像は並列して説明されます

LlamaIndex パイプラインは、抽出された画像を一度に 1 つずつ記述しました。これらは、画像ごとのタイムアウトと進捗ラインと同時に実行されるようになり、image_description_concurrency (デフォルト 4) および image_description_timeout_seconds (デフォルト 60) で調整可能です。画像を受け入れないことが判明したモデルは、画像なしでは再試行されなくなりました。画像はそこにある質問であり、その周囲のテキストから発明された説明が事実としてインデックスに登録されます。 #933として投稿しました。

LightRAG はハングせずに収束します

LightRAG ベースに対するトランスポートの失敗は、再試行される前に分類されるようになりました。再試行可能な HTTP ステータスは、制限付き Retry-After で最大 3 回の制限付き試行が可能ですが、それ以外のものはすぐに失敗し、2 つの再試行レイヤーは増加しません。キャンセルはリークではなくクリーンアップされ、Codex トランスポートの障害は飲み込まれるのではなく伝播します。 #940として投稿しました。

各種詰め合わせ

  • インデックス作成の進行状況ラインは翻訳可能です。 22 人のプロデューサー全員が、ハードコードされた英語をログ ボックスに送信しました。ワイヤにはテンプレートとその値が含まれており、フロントエンドはそれを言語でレンダリングします。 i18n を持たない消費者 (ログ、スナップショット、CLI) は、以前に読み取ったものを正確に読み取ります。
  • 削除されたナレッジ ベースはセッションに取り残されなくなります。 その名前は各セッションのコンテキスト チップに残ります (#936)。
  • 開発用 Docker イメージには、再びフロントエンドがあります。 そのスーパーバイザーは、ソース、構成、scripts/ を含まない実稼働スタンドアロン バンドルに対して node scripts/dev.mjs を実行したため、docker compose -f docker-compose.dev.yml up は無効になりました (#906)。ステージには、ビルダーの web/ ツリー全体が含まれます。製品イメージにはまったく影響がありませんでした。
  • プロバイダーの拒否本文は、ログに到達する前に制限されます。 このログはバグ レポートに deeptutor.jsonl を添付できるように存在し、一部のプロバイダーは拒否された要求 (スキーマ、場合によってはメッセージ) をエコーし​​てログに戻します (#930)。
  • 2 つの MarginNote ライブラリは 1 つのストアを要求できなくなりました。 "My Lib" と "My/Lib" は両方とも My_Lib.db を派生します。登録では名前による衝突が拒否されるようになり、ライブラリを削除すると、そのライブラリ用に作成したストアも削除されます。
  • MN4 デバイス ブリッジは最初に資格情報をチェックします。 /sync と /heartbeat はトークンを検証する前にストアを解決したため、認証されていない POST によって個別のヘッダー値ごとにデータベースが作成され、デバイス パスがデフォルトのパスを読み取る間にペアリングが呼び出し元のワークスペースに書き込まれ、すべての同期が永久に 403 になる可能性があります。

アップグレードに関する注意事項

pip install -U deeptutor; Docker ユーザーは ghcr.io/hkuds/deeptutor:latest を引きます。スキーマの変更、インデックスの再作成、移行は必要ありません。

  • MarginNote 4 ライブラリは空から始まります。 接続し、デバイス タブからデバイスをペアリングし、ワンタイム トークンを MN4 アドオンに貼り付けます。トークンは 1 回だけ表示され、そのハッシュのみが保持されます。ストアは data/user/marginnote4/<name>.db にあり、ライブラリとともに削除されます。 MarginNote 自体には何も触れられていません。
  • MarginNote ライブラリは rag によってスイープされません。 Obsidian Vault と同様、独自のツールを通じてのみアクセスできるため、Book と rag_search は空の結果を報告する代わりにライブラリをスキップします。
  • 新しい画像説明ノブは、次の質問ではなく、次のインデックス構築に適用され、設定 → ナレッジベースに表示されます。 フル Changelog: https://github.com/HKUDS/DeepTutor/compare/v1.5.15...v1.5.16
