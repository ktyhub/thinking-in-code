DeepTutor v1.4.0

#ディープチューター v1.4.0 #ディープチューター v1.4.0 Release Notes 発売日: 2026.05.22 v1.4.0はv1.4ラインのGAカットです。 v1.4.0-beta の全範囲を搭載 (自動モード、3 層メモリ ワークベンチ、エージェントのディープ リサーチ / ディープ ソルブ / 質問、LlamaIndex チャット リファクタリング、統合機能インフラストラクチャ + i18n、Visualize/Animator のマージ、新しいチャット ツール、設定の分割、マルチユーザー 絶縁強化、および deeptutor start / deeptutor init ランチャー) さらに、エージェント エンジンとランタイム強化修正の集中セットをその上に追加します。 ベータ版の全範囲については、v1.4.0-beta を参照してください。

v1.4.0-beta 以降の新機能

推論の労力 + プロバイダーの思考フラグ

エージェント エンジンは、プロバイダー間の「推論作業」を 1 つに正規化するようになりました。 各パイプラインがそれを再導出する代わりに、配置します。

  • build_provider_extra_kwargs (deeptutor/core/agentic/client.py) reasoning_effort を provider_registry に対して解決し、minimal / をマップします。 minimum を正しいワイヤ形状に変更 (DashScope は minimum を使用)、およびルート プロバイダーの思考スタイルの切り替えによるオン/オフの意図 — thinking_type (ディープシーク)、enable_thinking (Qwen スタイル)、または reasoning_split。既知の推論モデルのデフォルトは high です。の deepseek-v4-flash シェイプはデフォルトで思考が無効になります。
  • LLMClientConfig.reasoning_effort はエンドツーエンドで配管されています。 4つすべて パイプライン — エージェントチャット、質問、調査、解決 — バインディングを渡す + build_completion_kwargs への取り組みにより、単一のユーザーレベル設定 機能全体にわたる推論動作を制御します。

厳格なプロバイダー向けのツール スキーマ フォールバック

一部の OpenAI 互換プロバイダーは、次のようなネイティブ関数呼び出しスキーマを拒否します。 非標準エラー。 run_labeled_step はそのケースを検出し、ストリップします。 リクエストからの tools / tool_choice を 1 回再試行し、警告を発行します progress イベントにより、通話がツール不要の散文モードで実行されたことがユーザーにわかります。 ツール スキーマを通常どおり受け入れるプロバイダーの動作は変わりません。

再起動安全なターン ランタイム

サーバーまたはコンテナの再起動は、データベース行を一定期間残すために使用されます。 飛行中のターンが running でスタックし、その中の次のメッセージがブロックされます セッションが発生し、UI がイベント ストリームにハングしたままになります。 完了しました。

  • 孤立検出 — TurnRuntimeManager は、これが存在するかどうかをチェックするようになりました。 プロセスは依然としてターンのメモリ内ランナーを所有しています。そうでない場合、永続的な ターンは failed とマークされており、「ターンはサーバーの再起動により中断されました。 メッセージを再試行してください。"`
  • start_turn は、以前のセッションの古いアクティブ ターンをスイープします 新しいターンが作成されるため、ユーザーは再起動後にすぐに再試行できます。
  • subscribe_turn は、端末 error + done イベントを合成します。 フロントエンドがストリーミング状態をきれいに閉じるための孤立したターン 無限に待つ代わりに。

フロントエンド API ベース — Docker プレースホルダーの強化

web/lib/api.ts は、完全一致検出から部分文字列トークン検出に切り替えられました。 NEXT_PUBLIC_API_BASE プレースホルダー、isApiBasePlaceholder() を公開します 再利用のために。これは、Docker プレースホルダー形状への小さな変更を反映します。 以前はすり抜けて、空白の設定ページが生成され、何も表示されませんでした。 目に見えるエラー。に同梱されている未使用の自動生成 web/.env.local ベータ版は削除されます。

LLM 構成プローブ — より明確なステータス コピー

/settings/llm プローブは、明示的な「基本 LLM 完了」を発行するようになりました。 成功しました。チャットはストリーミングとプロバイダー ツールをさらに検証します 実行時の互換性。」スモークの完了後にラインが表示されるため、ユーザーはそれを認識できます。 プローブは、ストリーミング/ツール呼び出しパスを意図的にカバーしません。 チャットの練習。

CLI チャット REPL — ドキュメントと合わせた設定画面

deeptutor chat REPL 表面を引き締めて一般向けにマッチ ドキュメントは deeptutor.info にあります。

  • deeptutor chat --config key=value および --config-json '<json>' シード 最初に REPL を入力せずに初期設定を実行します。
  • /config set key value と /config set key=value は両方とも受け入れられます。 JSON 値 ([…]、{…}) は、shlex を介して正しく解析されます。
  • バックスラッシュ継続により、複数行のプロンプトを 1 回のターンで送信できます。
  • /refs は、構造化された状態のスナップショット (セッション、機能、ツール、 単一の薄暗い線の代わりに、KB、履歴、ノートブック、言語、構成）が表示されます。
  • deeptutor plugin info <name> は cli_aliases も返すようになりました。 能力 availability ブロック。

リポジトリとドキュメントの衛生管理

  • パブリック ドキュメント サイトの新しい問題テンプレート (.github/ISSUE_TEMPLATE/docs.yml)。
  • AGENTS.md は自動モード、ツール ゲート、および 現在の能力段階。
  • .gitignore は .playwright-cli/ をカバーします。古い .playwright-cli/ キャプチャ、.env.example_CN、および DeepTutor.code-workspace が削除されました。

テスト

  • をカバーする新しい tests/core/test_agentic_client_provider_kwargs.py 推論-労力 + プロバイダーの思考スタイルのマトリックス。
  • 新しい tests/core/test_labeled_step_tool_fallback.py を実行 スクリプト化された client に対するツール スキーマのエンドツーエンドの再試行パス。
  • tests/services/session/test_turn_runtime_subscribe.py はカバレッジを追加します submit と start_turn の両方での孤立した実行ターンの回復用。
  • tests/cli/test_chat_cli.py は、REPL 構成/バックスラッシュ テストと プラグイン情報契約チェック。
  • 新しい tests/cli/test_docs_contract.py はパブリック サイトのドキュメントを保存します CLI サーフェスと同期します (リンク + deeptutor … の例)。
  • tests/scripts/test_docker_compose.py + web/tests/api-resolve-base.test.ts 新しいプレースホルダーの検出について説明します。

アップグレードに関する注意事項

  • v1.4.0-beta から: ドロップイン。 PyPI は pip install -U deeptutor でインストールされます (PyPI は 1.4.0 を 1.4.0b0 よりも正規化します)。 Docker ユーザーがプルします ghcr.io/hkuds/deeptutor:latest。
  • 推論努力 が LLMConfig.reasoning_effort から読み取られるようになりました。もし 以前に extra_body でプロバイダー思考フラグを手動で設定しました。 エージェントは引き続きそれらを尊重しますが、推奨されるパスは次のとおりです。 reasoning_effort を指定し、エンジンにマッピングさせます。
  • 再起動回復は自動的に行われます。アップグレード後、既存の 以前のクラッシュにより running でスタックしたデータベース行は、 次回セッションが開かれたときに完了します。
  • ベータ版アーティファクトのクリーンアップ: web/.env.local は、 従来のランチャーなので不要になりました。フロントエンドを再構築した場合 そのファイルを手動で使用する場合は、次のビルドの前に削除してください。 フル Changelog: https://github.com/HKUDS/DeepTutor/compare/v1.4.0-beta...v1.4.0
