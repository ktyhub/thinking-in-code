DeepTutor v1.1.0

マイナー 公開日2026年4月14日 出典HKUDS/DeepTutor 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#ディープチューター v1.1.0 #ディープチューター v1.1.0 Release Notes 発売日: 2026.04.15

ハイライト

LaTeX ブロック数学解析のオーバーホール

緩いブロック計算を正しく処理するように normalizeEditorMdInlineMath パイプラインを書き直しました。コンテンツは、別々の行で単一の $ 区切り記号で囲まれています (例: $\n\\frac{a}{b}\n$)。新しい looksLikeLatexBlock ヒューリスティックは、LaTeX 固有のトークン (\\command、\\\\、_、^、&) の囲まれた行をスキャンし、必要に応じて区切り文字を $$…$$ にプロモートしますが、LaTeX 以外のドル記号の使用はそのままにします。また、1 行の $$…$$ 正規表現を厳格化し、末尾に $ アンカーを必要とし、過剰なマッチングを防止しました。

LLM 診断プローブ — agents.yaml 構成

LLM プローブの max_tokens 設定を LLM_TEST_MAX_TOKENS 環境変数から agents.yaml の diagnostics.llm_probe.max_tokens に移動し、既存のエージェント パラメーター システムと調整しました。 env-var アプローチとその Docker/.env.example エントリは、統合設定ローダー (get_agent_params("llm_probe")) を優先して削除されました。

LLM ファクトリでの追加ヘッダーの転送

llm_complete と llm_stream はどちらも、呼び出し元が指定した extra_headers を kwargs 経由で受け入れ、それらをサイレントにドロップしたり二重渡ししたりするのではなく、プロバイダー レベルのヘッダーとマージするようになりました。これにより、エージェント (NotebookSummarizeAgent など) がカスタム ゲートウェイ ヘッダーを転送したときの TypeError: multiple values for keyword argument 'extra_headers' クラッシュが修正されます。

SaveToNotebookModal UUID の修正

モーダルは、listCategories() (従来の質問ノートブック API からの整数のカテゴリ ID) ではなく、/api/v1/notebook/list (UUID ベース) からノートブックを取得するようになりました。これにより、数値カテゴリ ID がどのノートブック UUID とも一致しないために、Co-Writer およびその他の非クイズの保存がサイレントに失敗するという問題 #301 が解決されます。

Docker + ローカル LLM ガイダンス

.env.example、.env.example_CN、docker-compose.yml、および docker-compose.ghcr.yml に、LLM/組み込みサーバーがホスト マシン上で実行されている場合の host.docker.internal の使用法を説明する目立つドキュメント ブロックを追加しました。これには、macOS/Windows Docker デスクトップおよび Linux LAN-IP / --network=host の代替手段が含まれています。

テストスイートの拡張

LaTeX 区切り文字変換とブロック数学プロモーション (web/tests/latex.test.ts)、ノートブック ルーター UUID 検証 (tests/api/test_main_notebook_router.py)、NotebookSummarizeAgent 追加ヘッダー転送 (tests/agents/notebook/)、LLM プローブ agents.yaml 統合 (tests/services/config/test_llm_probe_config.py)、および extra_headers をカバーする 5 つの新しいテスト モジュール (153 + 107 + 114 + 193 + 102 行) を追加しました。 LLM ファクトリ (tests/services/llm/test_factory_provider_exec.py) での重複排除/マージ。
