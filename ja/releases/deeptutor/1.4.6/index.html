#ディープチューターv1.4.6

ディープチューター v1.4.6 Release Notes

発売日: 2026.06.17 注意: ドキュメントはまだこのリリースに追いついていないため、一部の ページには以下のすべてがまだ反映されていない可能性があります。 v1.4.5 に加えて整理された広範な統合リリース 触れる 4 つの表面の周りで、学習空間 が現実になります。 ダッシュボード、ナレッジ センター には新しい検索エンジンと外部の検索エンジンが追加されました。 マウントし、設定でドキュメントの解析、音声、およびメディアの生成を開きます。 そしてプラットフォームはユーザーごとのアクセスを強化します。ドロップイン アップグレード — データ移行は不要です。

新機能

学習スペース

スペースは、あなたの仕事をまとめる学習ダッシュボードになりました。 周囲の表面が成長しました。

  • 私のエージェント — ローカルのクロード コード/コーデックス チャット履歴を 会話を続けることができる再開可能なエージェント (/space/agents)。参照された 成績証明書には客観的な説明と第三者による枠組みが与えられるため、講師は あなたとしてロールプレイングするのではなく、それをナレーションします。
  • メモリは、代わりに独自の最上位の宛先 (/memory) にプロモートされます。 L1/L2/L3 ビューはそのままで、ワークスペースに埋め込まれます。
  • パートナーの会話がチャットと同じパイプラインのメモリに流れるようになりました。
  • EduHub からコミュニティ スキルを /space/skills にインラインでインストールします。

ナレッジセンター

/knowledge は ナレッジ センター コンソールとして再構築されています。エンジン カードは 純粋なエントリ ポイントと構成はエンジンごとの詳細ページに移動します。

  • 新しい検索エンジンが LlamaIndex に加わりました: GraphRAG (microsoft/graphrag)、 PageIndex (クラウド推論検索)、および組み込みの LightRAG バックエンド — ナレッジベースごとに選択されます。
  • リンクされた KB — すでに構築されているインデックス フォルダーにナレッジ ベースをポイントします。 読み取り専用マウントで、取り込みを完全にスキップします。
  • Obsidian — エージェントのナレッジ機能としてライブ ボールトを接続します。 メモを直接読み書きします。

設定

新しい構成可能なサービス。それぞれに独自の設定ページがあり、次の期限まですべてオフになります。 あなたがそれらを設定します:

  • ドキュメント解析 — プラグイン可能な解析レイヤー (MinerU、Docling、MarkItDown) コンテンツアドレス指定キャッシュ (/settings/document-parsing) を使用します。 MinerU が追加 クラウド/ローカル デュアル バックエンド (/settings/mineru) と質問タイプを抽出するようになりました。 難易度、そして答え。
  • 音声 — 返信用の 3 つの状態の自動再生 (TTS) を備えたスピーカー ボタン ディクテーション用作曲家マイク (STT)、/settings/tts および /settings/stt。
  • 画像とビデオの生成 — チャットに接続された構成可能なモデル カタログ ツール (/settings/image、/settings/video)。
  • 拡張されたサーフェスを中心に再構築された設定ナビゲーション。

その他

  • ユーザーごとのアクセス ゲーティング — LLM 機能は、権限のないユーザーに対してロックされます。 割り当てられたモデル、サイドバーのロックとサーバー側のゲートが常にオンになっている 合意。
  • 解決は、ステップごとのゲートを備えたチャット ループの機能として再構築されています 実行途中の障害によるフォールバックにより、代わりに正常な終了が強制されます。 ターン全体で失敗します。
  • ログイン はユーザー名 (電子メールだけでなく) を受け入れ、不正なログイン エラーを表示します サイレントリロードの代わりにインラインで実行し、NEXT_PUBLIC_AUTH_ENABLED を修正します。 旗。
  • CLI が deeptutor skill コマンドを取得 — ブラウザーのログインと公開/更新 自分のスキルのために。
  • コンテキスト ピッカーは、ライブ プレビューを備えた共有シェル上に洗練されており、 引用前の数学レンダリングの修正により、$…$ が引用によって壊れるのを防ぎます リンク化。

アップグレードに関する注意事項

  • v1.4.5 からのドロップイン: pip install -U deeptutor; Docker ユーザーがプルする ghcr.io/hkuds/deeptutor:latest。移行なし - 既存のデータがそのままロードされます。
  • 各ユーザーにモデルを割り当てて、各ユーザーの機能を解放します。管理者がこれを管理します モデルカタログより。
  • 新しいエンジンとサービスはオプトインです: GraphRAG には追加の機能が必要です (pip install 'deeptutor[graphrag]')、ドキュメントの解析が必要です deeptutor[parse]、音声/画像/動画は機種カタログが必要です 設定されています。 フル Changelog: https://github.com/HKUDS/DeepTutor/compare/v1.4.5...v1.4.6
