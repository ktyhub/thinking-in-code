ディープチューター v1.6.2

ディープチューター v1.6.2 Release Notes

発売日: 2026.08.31 v1.6.2 は、没入型の YouTube 学習とプラグイン駆動のビジュアライザー カタログを追加し、読書、ナレッジ、パートナー、アップデート、およびマイ エージェントを強化します。互換性の変更は、廃止された Playground API および Gemini CLI 接続のみです。

新機能

同期されたビデオを見ながら学ぶ

YouTube URL を貼り付けて、講師の横でプライバシーを強化した再生を開き、タイムスタンプにバインドされたトランスクリプト証拠を保持し、現在のキューを説明し、後で進行状況を再開します。管理者は、マテリアルを再構築せずに、セルフホスト型の Invidious オリジンを選択できます。ネイティブ再生は、オプションのパブリック キャプション アダプターなしでも機能します。

拡張可能なカタログを通じて視覚化して参照する

Visualize は、共有エージェント ループと、SVG、Mermaid、Chart.js、インタラクティブ HTML、Manim、およびオプションの GeoGebra 用にインストールされたビジュアライザー カタログを使用するようになりました。宣言型のブラウザー専用ビジュアライザー ZIP は、サンドボックス化された iframe で実行されます。 My Agents は、6 つの既存のローカル ハーネスに加えて、Hermes Agent、OpenClaw、および DeepSeek ハーネスを追加します。

ホーム、読書、更新のパスがより緊密になりました

ホームは、通常のワークスペース、読み取りワークスペース、マスタリーワークスペース、および監視ワークスペース全体でのチャット動作を統合します。 Web ソースは安全なバージョン管理されたスナップショットになり、ターンのマテリアルに対して検証された場合にのみ引用リンクを読み取り、LaTeX の選択は固定されたままになり、「設定」→「バージョン情報」で対象となる PyPI アップデートを確認、分類し、安全に適用できます。

より明確な知識とパートナーの運用

MinerU は、PDF に加えて、一般的なラスター イメージと DOCX、PPTX、XLSX を受け入れるようになりました。 Knowledge Center は、準備プリフライトを使用してライブラリをローカル、サーバー、クラウド、外部エンジンから分離します。パートナー チャネル カードは、日常的な診断をログに送信するのではなく、ブラウザの QR オンボーディングを含むライブ接続/セットアップ状態を報告します。

アップグレードに関する注意事項

pip install -U deeptutor を実行します。 Docker ユーザーは ghcr.io/hkuds/deeptutor:latest を引きます。既存のデータ、ナレッジ インデックス、ビデオの進行状況、およびスナップショットの読み取りには移行の必要はありません。

  • 公共キャプション付き個別指導はオプションです。 pip install -U 'deeptutor[video-learning]' をインストールすると、トランスクリプトに基づいたビデオ説明が可能になります。 YouTube/Invidid の再生は、これなしでも機能します。
  • Gemini CLI は、My Agents ハーネスとして廃止されました。 既存の gemini 設定はそのまま残されますが、登録されなくなりました。古い設定ルートは Antigravity にリダイレクトされます。代わりに、Antigravity、Hermes Agent、OpenClaw、または DeepSeek ハーネスを接続します。
  • Web プレイグラウンドと /api/v1/plugins/* テスター API は削除されました。 deeptutor plugin list/info は引き続きランタイム ツールと機能を検査します。ブラウザ ビジュアライザは、/api/v1/visualizers および宣言型ビジュアライザ パッケージを使用するようになりました。
  • 英語と中国語のガイドを deeptutor.info でまとめて更新しました。 フル Changelog: https://github.com/HKUDS/DeepTutor/compare/v1.6.1...v1.6.2
