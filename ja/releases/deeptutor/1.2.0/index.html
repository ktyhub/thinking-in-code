DeepTutor v1.2.0

#ディープチューター v1.2.0 #ディープチューター v1.2.0 Release Notes 発売日: 2026.04.20

ハイライト

ブック エンジン — マルチエージェント「リビング ブック」コンパイラー

ユーザー入力 (チャット履歴、ノートブック、知識ベース、自由形式のインテント) を構造化されたブロックベースのインタラクティブな「生きた本」にコンパイルする、まったく新しい ブック エンジン (deeptutor/book/) を導入しました。エンジンは ChatOrchestrator と並列に配置され、5 段階のマルチエージェント パイプラインを駆動します。

  1. アイデア — LLM は、ユーザーの意図とソース資料から本の概要を提案します。
  2. ソース探索 — SourceExplorer エージェントは、詳細な RAG 検索と知識ベースのヘルス チェック (kb_health.py) を実行して、最も関連性の高いパッセージを明らかにします。
  3. スパイン合成 — SpineSynthesizer エージェントは、提案を調査済みのソースと結合して章/ページ ツリー (Spine → Chapter → Page) にします。
  4. ページ計画 — PagePlanner エージェントは、各ページを型付きブロックの順序付けされたシーケンスとして設計します。
  5. ブロック コンパイル — BookCompiler は各ブロックを専用のジェネレーターにディスパッチします。 フェーズ 1 には、テキスト、コールアウト、クイズ、フラッシュ カード、コード、図、詳細、アニメーション、インタラクティブ、タイムライン、コンセプト グラフ、セクション、ユーザー ノート、およびコンパイル中のブロックのプレースホルダーの 14 種類のブロックがフェーズ 1 で出荷されます。各ジェネレーターには独自のバイリンガル (en/zh) YAML プロンプトがあり、根拠のあるコンテンツの RAG ヘルパーを呼び出すことができます。 Web UI (web/app/(workspace)/book/) には、BookCreator ウィザード (意図 → 提案 → 背表紙の確認)、ドラッグ アンド ドロップで章の順序を変更するための SpineEditor、アウトライン ナビゲーション レールとブロックごとのレンダラーを備えた PageReader (インタラクティブな力指向図としてレンダリングされるコンセプト グラフ、インライン採点付きのクイズ、フリップ アニメーション付きのフラッシュ カードなど)、リアルタイムのコンパイル追跡用の BookProgressTimeline、コンテキスト内の Q&A 用の BookChatPanel、および基礎となる KB が異常な場合に警告する BookHealthBanner。ブックごとの WebSocket ストリームは、接続されているすべての client にコンパイル イベントをファンアウトします。 バックエンド: POST /api/v1/book/create、POST /confirm-proposal、POST /confirm-spine、POST /compile-page、GET /list、GET /{book_id}、DELETE /{book_id}、および WS /ws/{book_id}。 CLI: deeptutor book create、deeptutor book list、deeptutor book show、deeptutor book delete。

従来のガイド付き学習は削除されました

deeptutor/agents/guide/ モジュール (ガイド マネージャー、4 つのエージェント、8 つのプロンプト YAML) および /guide Web UI 全体 (コンポーネント、フック、タイプ、API ルーター - 約 5,300 行) が削除されました。ブック エンジンは、より豊富で拡張可能なアーキテクチャを備えたガイド付き学習に取って代わります。

マルチドキュメント共同作成者ワークスペース

Co-Writer は単一ドキュメントのスクラッチパッドではなくなりました。各ドキュメントは、アトミック マニフェスト書き込み (CoWriterStorage) を使用して、data/user/workspace/co-writer/documents/ の下に独自の永続ディレクトリを取得するようになりました。 Web UI はドキュメントごとのページ (/co-writer/[docId]) にルーティングされ、サイドバーには迅速にアクセスできるように CoWriterRecent セクションが表示されます。新しい API エンドポイントは、完全なドキュメント CRUD (GET /list、POST /create、GET /{doc_id}、PATCH /{doc_id}、DELETE /{doc_id}) を処理します。

インタラクティブな HTML ビジュアライゼーション

Visualize 機能は、svg、chartjs、mermaid と並ぶ 4 番目のレンダリング タイプ html をサポートするようになりました。 LLM は、ユーザー リクエストに「ユーザー インタラクション + 状態変更 + テキスト/グラフィックの混合」(例: ドラッグ可能なデモ、段階的なウォークスルー、clickable 演習) が必要であると判断すると、iframe 内でレンダリングされる自己完結型の単一ファイル HTML ページを生成します。ローカル検証パス (is_valid_html_document) は、提供する前に出力をチェックします。モデルがレンダリング不可能なものを返した場合、代わりにスタイル付きのフォールバック テンプレートが挿入されます。 HTML ページでは LLM レビュー ステージがスキップされます (品質の低下は無視できる程度で 30 ～ 60 秒の遅延が節約されます)。新しい figure 制約モードは、LLM を svg/chartjs/mermaid のみに制限します。これは、ブック エンジンの Figure ブロックによって内部的に使用されます。

チャットでの質問バンクの @-メンション

新しい QuestionBankPicker コンポーネントにより、ユーザーはチャット コンポーザーで個々の質問バンクのエントリを直接 @-メンションできるようになります。選択されたエントリは、ターン ランタイム (_build_question_bank_context) によって構造化された Markdown コンテキスト (質問テキスト、オプション、ユーザー/参照の回答、説明を含む) に解決され、ノートブックおよび履歴参照とともに挿入されるため、LLM は特定の過去のクイズのパフォーマンスを推論できます。

迅速な外部化 — フェーズ 2

ハードコーディングされた LLM 文字列の編集可能な YAML ファイルへの移行を継続しました。

  • answer_now - question、research、solve、および visualize 機能は、高速パス プロンプトを prompts/{en,zh}/answer_now.yaml からロードするようになりました。
  • ノートブック エージェント - analysis_agent および summarize_agent プロンプトは YAML に移動しました。 Python モジュールはプロンプト マネージャーに委任されるようになりました。
  • 機能モジュール (_answer_now.py、deep_question.py、deep_research.py、deep_solve.py、visualize.py) もそれに応じてスリム化されました。

共同執筆者モジュールの再構成

deeptutor/agents/co_writer/ を deeptutor/co_writer/ (トップレベルのサービス モジュール) に移動して、deeptutor/book/ と並んでスタンドアロンの性質を反映しました。

サイドバーのオーバーホール

  • 「ガイド付き学習」ナビゲーション エントリが 書籍 (ライブラリ アイコン) に置き換えられました。
  • 項目ごとのナビゲーションを備えた BookRecent および CoWriterRecent サイドバー セクションを追加しました。
  • サイドバーの折りたたみ/展開状態が AppShellContext に引き上げられ、ルート遷移全体で持続するようになりました。
  • 洗練された折りたたまれたサイドバー: ホバー表示と重ねられたロゴ + 展開トグル、円形の「新しいチャット」ボタン、微妙な仕切り、一貫した間隔。

機能と設定パネルの更新

新しい機能オプション (html レンダリング モード、拡張ロケール キーなど) に合わせて、Quiz、Research、Visualize、Math Animator 全体で共有タイプ定義と構成パネルを更新しました。チャット UI の TracePanels では、レイアウトとスタイルが改善されました。

README とローカリゼーションの更新

ローカライズされた 9 つの README ファイル (AR、CN、ES、FR、HI、JA、PT、RU、TH) がすべて更新され、ブック エンジン、マルチ ドキュメント Co-Writer、およびその他の v1.2.0 機能が反映されました。

バグ修正

  • チャネル マネージャーのインポート時のクラッシュ - loguru.logger がモジュール スコープでインポートされ、TutorBot の依存関係が存在しない場合に ImportError が発生しました。遅延 _logger() ファクトリー関数に置き換えられました。
  • 廃止された test_app_facade.py — 削除されたコード パスを参照する古いテスト モジュールを削除しました。
  • テスト パッケージに __init__.py がない — インポート解像度を修正するために、tests/agents/、tests/api/、tests/cli/、tests/knowledge/、tests/scripts/、tests/services/llm/、tests/services/memory/、tests/services/search/、tests/services/session/、tests/tools/ 全体に init ファイルを追加しました。

テストスイートと CI

  • CI は requirements/tutorbot.txt をインストールし、サーバー/cli 要件と一緒にキャッシュするようになりました。
  • 廃止された test_app_facade を CI テスト マニフェストから削除しました。
  • RAG パイプライン テスト用に conftest.py を更新しました。再構築されたインポートに一致するように、プロンプト パリティ、機能ランタイム、LLM プローブ構成、ファクトリ プロバイダー、モデル カタログ、構成ローダー、およびノー​​トブック サービス テストが更新されました。
  • PWA メタデータ用の favicon および apple-touch-icon アセットを追加しました。 フル Changelog: https://github.com/HKUDS/DeepTutor/compare/v1.1.2...v1.2.0
