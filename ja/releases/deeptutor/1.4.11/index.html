DeepTutor v1.4.11

パッチ 公開日2026年6月23日 出典HKUDS/DeepTutor 英語原文

#ディープチューター v1.4.11 #ディープチューター v1.4.11 Release Notes 発売日: 2026.06.23 v1.4.10 の修正と洗練のフォローアップ: ネイティブ ツールの呼び出し中 すべてのクラウド OpenAI 互換プロバイダーで点灯し、管理ユーザー ページが表示されます。 再構築され、クイズ オプションが LaTeX をレンダリングし、コンテナ ストーリーが構成可能になりました ホストバインディング。ドロップイン - 移行はありません。

新機能

すべてのクラウド OpenAI 互換プロバイダーで呼び出すネイティブ ツール

専用の機能エントリが不足していたクラウド プロバイダー — SiliconFlow、Gemini、 Zhipu、Qianfan、NVIDIA NIM、Volc/BytePlus コーディング プラン - ネイティブを使用するようになりました 静かに散文に戻るのではなく、 関数を呼び出します。関数呼び出しは OpenAI 互換の API 契約の一部であるため、登録されたクラウド プロバイダーはすべて 明示的にオプトアウトしない限り、ツールが使用可能であるとみなされます。これにより、KB 取得および機能ツールは実際にそれらのプロバイダー上で起動します。ローカルサーバー (Ollama、vLLM、LM Studio、llama.cpp、Lemonade など) は依然として散文に戻ります。 そこでのツールのサポートは、ロードされたモデルによって異なります。

ユーザー管理ページの再設計

管理者 ユーザー ページは、アバター、ユーザー名検索ボックス、スケルトンを備えて再構築されています。 ロード状態、および破壊的なアクションの前のスタイル付き確認ダイアログの代わりに 生のブラウザプロンプト。

クイズオプションの LaTeX

回答の選択肢でマークダウンと数学がレンダリングされるようになり、$…$ と数式が 質問文で既に行ったのと同じ方法でオプションを選択します。

構成可能なコンテナー ホスト バインディング

BACKEND_HOST と FRONTEND_HOST は環境設定可能になりました。Linux では ホスト ネットワーキングでは、両方のサービスをループバック (127.0.0.1) 上に維持できます。 すべてのインターフェースでそれらを公開します。 supervisord が root として実行されるようになり、サービスが開始されます root 状態の Docker および無効な gosu / libcap2-bin インフラストラクチャの下で正しく動作します。 がなくなった — コンテナは単一の root-supervisord モデルに従います。参照 コンテナ化.md。

正直なセッション読み込みオーバーレイ

会話を開くと、シミュレートされた進行状況バーが低下し、偽の 99% まで上昇します 約 24 秒にわたって、代わりに正直な不確定なスピナーが表示されます。の フェッチが解決された瞬間に会話が表示され、「まだ読み込み中…」というメッセージが表示されるようになりました。 8秒後にヒント。

アップグレードに関する注意事項

v1.4.10 からのドロップイン: pip install -U deeptutor; Dockerユーザープル ghcr.io/hkuds/deeptutor:latest。移行や構成の変更は必要ありません。その人 動作変更はネイティブ ツール呼び出しであり、クラウドのデフォルトでオンになっています OpenAI 互換 プロバイダー - KB の取得と 機能ツールが起動します。 フル Changelog: https://github.com/HKUDS/DeepTutor/compare/v1.4.10...v1.4.11
