#ディープチューター v1.6.14 Release Notes

発売日: 2026.10.08

v1.6.13 に基づいて構築された v1.6.14 は、オリジナル ソースのビジュアル プラクティス、回復可能な知識ベースのインデックス作成、科学研究ツール、およびマネージド プラグインを提供します。ビデオ学習は現在、Reading にあります。既存の監視会話は、再度開かれたときに移行されます。

新機能

オリジナルの図、ページ、視覚的な練習

添付のナレッジベースで正確な図、表、または PDF ページについて質問してください。 DeepTutor は、ドキュメントの ID とソース リンクを維持しながら、元の画像を取得するか、選択したページまたは領域をレンダリングします。ファイル ビューでは、欠落している抽出や未検証の抽出を含む、ソースの視覚的な範囲が公開されます。ガイド付き学習では、この証拠を視覚的な質問に使用し、説明、支援された練習、および独立した習得を区別します。アクセスできない、または不確実な証拠は等級付けされないままになります。

回復可能なインデックス作成

ナレッジベースの詳細には、永続的なインデックス作成の進行状況、個々のソースの結果、およびリカバリ情報が表示されます。再試行では、互換性のある完了した解析と検証された MinerU クラウド スライスが再利用されます。キャンセルは安全な境界で有効になります。 LlamaIndex は、リロード、ベクトル検証、取得プローブが成功した後にのみ新しいバージョンを公開し、再構築が失敗した場合でも以前のクエリ可能なバージョンを保持します。取得では、ハイブリッドからベクターへのフォールバックと不完全な IMA 証拠も報告します。

読書にはビデオ学習が含まれます

YouTube と Bilibili メディアは、タイムスタンプに基づいたディスカッションとネイティブ再生を備えた Reading ワークスペースを共有しています。前 会話、位置、メモの監視は、従来のメディアやノートブックのレコードを変更せずにインポートできます。読書パネルは独立してサイズ変更され、フォーカスのプリセットが提供され、狭い画面でも使用可能なページネーションと選択のコントロールが保持されます。

追跡可能な証拠を伴う研究

科学的リクエストと Deep Research は、バージョン管理された arXiv 論文とオリジナル ページを読み取り、固定された GitHub リビジョンに対して論文の主張をチェックし、文献証拠マトリックスを構築するためのツールを獲得します。 MCP カタログに alphaXiv が追加されました。管理者は、アカウント所有の調査接続に対して正確なプライベート ネットワーク MCP 起点を承認でき、ツールの実行時に承認が再度チェックされます。

プラグインのライフサイクルを確認しました

プラグイン CLI は、検査、インストール、権限の承認、有効化/無効化、ロールバック、アンインストールをサポートします。マネージド ホイールは、アーティファクト チェックと取り消し可能なランタイム ゲートを備えた別の環境で実行されます。公式カタログ形式はレビュー済みパッケージをサポートしています。このリリースでは空のカタログが出荷されるため、新しいサードパーティ コードは自動的にインストールされません。

学習の継続と日々の修正

スペースは、現在のミッション、最後のセッションの引き継ぎ、確認された学習記録を示すワークスペース学習ジャーナルを取得します。チャットは確認応答を失った後に元の会話を再試行し、保留された質問はリロード後も存続し、未送信の下書きは回復可能なままになります。ブランチ ナビゲーション、メモリ アカウントの分離、ランチャーの回復、およびエラー レポートが改善されます。 Visualize は Mermaid マインドマップも取得します。

プロバイダーとセットアップ

GitHub Copilot はデバイス ログインと所有者ごとの資格情報を使用し、セットアップ中に推論がチェックされます。 Opper は LLM および埋め込みプロバイダーに参加し、Y-API は LLM プロバイダーに参加します。プロバイダー設定により、より明確な追加フロー、プロトコル対応のデフォルト エンドポイント、およびプロバイダー音声検出が提供されます。ローカル埋め込みサービスは API キーがなくても機能しますが、埋め込みの同時実行性と Qwen3-Instruct の思考処理は修正されています。

更新された英語と中国語のドキュメントは、deeptutor.info でのリリースに付属しています。

アップグレードに関する注意事項

pip install -U deeptutor を実行します。 Docker ユーザーは ghcr.io/hkuds/deeptutor:latest をプルします。

  • ビデオ学習: 新しいビデオ セッションには Reading を使用します。スタンドアロン immersive_watching 機能と watching / watch CLI エイリアスは廃止されました。既存の Watching リンクは互換性の移行に入ります。既存のアプリケーション データを利用可能な状態に保ちます。従来のビデオが失われた場合、その会話は通常のチャットとしてアクセスできるままになります。
  • GitHub Copilot: 以前に外部 Copilot/nanobot トークン ファイルに依存していた場合は、deeptutor provider login github-copilot を再度実行します。各アカウントは個別にサインインします。コパイロット プロファイルは、モデル許可を通じて共有できません。
  • 音声: モデル設定で音声を明示的に選択します。新しいプロファイルは、ハードコーディングされたデフォルトの音声を受け取りません。
  • OrcaRouter: 組み込みプロバイダーのプリセットが削除されます。そのサービスを引き続き使用する場合は、明示的な互換性のあるエンドポイントとモデルを使用してカスタム接続を構成します。
  • ナレッジベース: 新しく抽出された図レコードを取得するには、古いインデックスを再解析してインデックスを再作成する必要があります。正確な PDF ページ検査では、元のドキュメントを直接使用できます。再試行では、互換性のある有効なチェックポイントのみが再利用されます。ドキュメントの途中で中断されたローカル MinerU 推論は再開されません。
  • プラグイン: 管理パッケージを承認する前に、要求された権限を確認します。プラグインの世代が変わったら DeepTutor を再起動し、レビューされたコードがロードされるようにします。承認を無効にするか取り消すと、それ以降の通話がブロックされます。
  • systemd インストール: サービスを停止し、Python 環境で DeepTutor をアップグレードし、サービスを再起動します。
