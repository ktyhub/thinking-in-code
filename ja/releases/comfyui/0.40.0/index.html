#快適UI v0.40.0

何が変わったのか

  • [Server.py] https://github.com/Comfy-Org/ComfyUI/pull/15565 の @S0yKaf による blob: および data: を許可するように CSP を更新します
  • https://github.com/Comfy-Org/ComfyUI/pull/16806 の @comfyanonymous により、残りのモデルに comfy_attention と AttendanceTensorContainer のサポートを追加
  • アセット エクスポート API をローカル (CORE-454) で実装 (https://github.com/Comfy-Org/ComfyUI/pull/16578 の @jtydhr88 による)
  • https://github.com/Comfy-Org/ComfyUI/pull/16200 の @jtydhr88 により、すべての 3D ノードからの 3D モデルを標準 3D 出力アイテムとしてレポートします
  • feat(camera-info): CreateCameraInfo ノード + CameraInfoState ウィジェット (https://github.com/Comfy-Org/ComfyUI/pull/14964 の @jtydhr88 によって入力)
  • 特技(アセット): https://github.com/Comfy-Org/ComfyUI/pull/15180 の @jtydhr88 による取り込みとスキャン時にビデオ メタデータを system_metadata に抽出します
  • プロンプトの WebSocket メッセージにメタデータを添付する方法を追加します。 @christian-byrne 著、https://github.com/Comfy-Org/ComfyUI/pull/16763
  • 修正: https://github.com/Comfy-Org/ComfyUI/pull/16377 で @jaeone94 による動的入力検証と遅延実行を保持
  • リファクタリング: https://github.com/Comfy-Org/ComfyUI/pull/16811 の @jaeone94 による安定化中に DynamicGroup を内部に保持
  • 偉業: https://github.com/Comfy-Org/ComfyUI/pull/16251 の @jtydhr88 による、camera_info とショット プロンプト出力を含む CameraAngle ノードを追加します。
  • [パートナー ノード] feat(Google): @bigcat88 による Nano Banana 2.1 モデルを https://github.com/Comfy-Org/ComfyUI/pull/16822 に追加
  • https://github.com/Comfy-Org/ComfyUI/pull/16823 の @comfyui-wiki によりワークフロー テンプレートを v0.11.77 に更新
  • https://github.com/Comfy-Org/ComfyUI/pull/16820 の @rattus128 による qwen 3.5 LLM の低 VRAM パフォーマンスを改善
  • https://github.com/Comfy-Org/ComfyUI/pull/16726 の @tvukovic-amd によって L2 に収まらない場合、gfx1151 で SDPA の前に k/v を連続させます。
  • https://github.com/Comfy-Org/ComfyUI/pull/16816 の @rattus128 によるプロローグ/エピローグ フュージョン パスを含むリニア フォワード API を統合
  • プロンプトのプレビュー画像フレームにもメタデータを添付します。 @christian-byrne 著、https://github.com/Comfy-Org/ComfyUI/pull/16809
  • https://github.com/Comfy-Org/ComfyUI/pull/16167 の @guill によるカスタム ノードのガバナンス適用を追加
  • モデル ファイル内の comfy_attention 設定でキッチン ソル アテンションを使用できるようになりました。 @comfyanonymous 著、https://github.com/Comfy-Org/ComfyUI/pull/16831
  • https://github.com/Comfy-Org/ComfyUI/pull/16736 の @comfy-pr-bot によって comfyui-frontend-package を 1.55.14 にバンプします
  • [パートナー ノード] 特技 (Quiver): モデルごとの入力を持つ V2 SVG ノードを追加し、https://github.com/Comfy-Org/ComfyUI/pull/16775 の @bigcat88 によってオリジナルを非推奨にします
  • [パートナー ノード] feat(Vidu): Vidu Q4 モデルのノードを追加 by @bigcat88 (https://github.com/Comfy-Org/ComfyUI/pull/16849)
  • [パートナー ノード] feat(ClarityAI): @bigcat88 による Crystal Upscaler ノードを https://github.com/Comfy-Org/ComfyUI/pull/16817 に追加
  • [パートナー ノード] feat(Kling): @bigcat88 による Kling Virtual Try-On ノードを https://github.com/Comfy-Org/ComfyUI/pull/16844 に追加
  • https://github.com/Comfy-Org/ComfyUI/pull/16851 の @comfyui-wiki によりワークフロー テンプレートを v0.11.78 に更新
  • https://github.com/Comfy-Org/ComfyUI/pull/16861 の @rattus128 によるリニア呼び出しの関数ラッパーを使用するようにモデル コードを変更
  • バイパス lora と融合パスの問題を修正。 @comfyanonymous 著、https://github.com/Comfy-Org/ComfyUI/pull/16862
  • 保存を高速化するには、GLB テクスチャに PNG 圧縮レベル 4 を使用します (https://github.com/Comfy-Org/ComfyUI/pull/16867 の @kijai により)
  • Comfy Aimdo 0.5.6 + 低 VRAM 条件での qwen 2.1 不正行為の修正 (https://github.com/Comfy-Org/ComfyUI/pull/16870 の @rattus128 による)
  • https://github.com/Comfy-Org/ComfyUI/pull/16877 の @rattus128 による Qwen3.5 MTP 埋め込みオフロードを修正
  • Loras は、モデル上のレイヤーごとのアテンション設定を置き換えることができるようになりました。 @comfyanonymous 著、https://github.com/Comfy-Org/ComfyUI/pull/16880
  • https://github.com/Comfy-Org/ComfyUI/pull/16769 の @christian-byrne による CodeRabbit レビューの関連リポジトリにリンクします。
  • 功績: ネイティブ LoRA スタック ローダー ノード (CORE-186) を追加 (@jaeone94 による https://github.com/Comfy-Org/ComfyUI/pull/16309)
  • アセット システムはデフォルトでオンになります。 @synap5e による --disable-assets を追加 (https://github.com/Comfy-Org/ComfyUI/pull/16884)
  • [パートナー ノード] feat(HeyGen): https://github.com/Comfy-Org/ComfyUI/pull/16876 の @bigcat88 により、HeyGen ビデオ 1.0 ノードに 2K 解像度を追加
  • LatentOperationBlend と開始/終了パーセントを LatentApplyOperatio に追加… by @comfyanonymous (https://github.com/Comfy-Org/ComfyUI/pull/16923)
  • 出力資産のスキャンを無効にします。 @comfyanonymous 著、https://github.com/Comfy-Org/ComfyUI/pull/16926
  • Qwen3.5 で画像を使用した MTP を有効にする (https://github.com/Comfy-Org/ComfyUI/pull/16922 の @kijai により)
  • https://github.com/Comfy-Org/ComfyUI/pull/16881 の @kijai による clip の最初の潜在として MiniMax H3 単一イメージをデコードします
  • fix(assets): https://github.com/Comfy-Org/ComfyUI/pull/16810 の @synap5e によるファイルの mtime によるスキャンされたアセットの日付
  • 保存された EXR の圧縮を有効にします。 @comfyanonymous 著、https://github.com/Comfy-Org/ComfyUI/pull/16948
  • pyav によるハーフフロートファイルのロードに関する問題を修正。 @comfyanonymous 著、https://github.com/Comfy-Org/ComfyUI/pull/16949
  • https://github.com/Comfy-Org/ComfyUI/pull/16920 の @christian-byrne によってリンクされたリポジトリの結果に焦点を当てたままにしておく
  • いくつかの古いコードを削除します。 @comfyanonymous 著、https://github.com/Comfy-Org/ComfyUI/pull/16960
  • --enable-assets を除いてアセットをオフにし、https://github.com/Comfy-Org/ComfyUI/pull/16929 の @synap5e によって出力フォルダーを再度スキャンします。
  • https://github.com/Comfy-Org/ComfyUI/pull/16928 の @synap5e による Windows スタンドアロン ビルドのアセット システムをオンにします
  • ARM64 nvidia ポータブルを追加します。 @comfyanonymous 著、https://github.com/Comfy-Org/ComfyUI/pull/16985
  • 暗号化パッケージの依存関係を削除します。 @comfyanonymous 著、https://github.com/Comfy-Org/ComfyUI/pull/16988
  • https://github.com/Comfy-Org/ComfyUI/pull/16981 の @comfyui-wiki により埋め込みドキュメントを v0.5.14 に更新
  • [パートナーノード] feat(Higgsfield): 幻術モーション転送ノード by @bigcat88 in https://github.com/Comfy-Org/ComfyUI/pull/16913
  • feat(assets): EXR アセットのプレビュー。https://github.com/Comfy-Org/ComfyUI/pull/16898 の @synap5e による出力用に SaveImageAdvanced によって作成されました。
  • [パートナーノード] feat(FishAudio): @bigcat88 による Drama 3 モデルを https://github.com/Comfy-Org/ComfyUI/pull/16999 に追加
  • https://github.com/Comfy-Org/ComfyUI/pull/17001 の @comfyui-wiki によりワークフロー テンプレートを v0.11.82 に更新
  • https://github.com/Comfy-Org/ComfyUI/pull/17004 の @AustinMroz により comfyui-frontend-package を 1.55.17 にバンプ
