#快適UI v0.45.0

何が変わったのか

  • https://github.com/Comfy-Org/ComfyUI/pull/17442 の @comfy-pr-bot によって comfyui-frontend-package を 1.58.5 にバンプします
  • ピクセルスペース VAE が誤って選択された場合のエラーを追加しました。 @comfyanonymous 著、https://github.com/Comfy-Org/ComfyUI/pull/17518
  • https://github.com/Comfy-Org/ComfyUI/pull/17508 の @kijai により、SeedVR2 VAE スライス長を空きメモリに適応させる
  • [パートナー ノード] feat(Pika): @bigcat88 による Pika H3 Flex ノードを https://github.com/Comfy-Org/ComfyUI/pull/17509 に追加
  • [パートナー ノード] feat(Pika): @bigcat88 による Pika サウンドトラック、SFX、音楽ノードを https://github.com/Comfy-Org/ComfyUI/pull/17328 に追加
  • [パートナー ノード] feat(Tencent): @bigcat88 による Tencent HY LLM ノードを https://github.com/Comfy-Org/ComfyUI/pull/17534 に追加
  • https://github.com/Comfy-Org/ComfyUI/pull/17540 の @dante01yoon により、local_web_sso と Partner_node_token をデフォルトでオンにします
  • https://github.com/Comfy-Org/ComfyUI/pull/17541 の @comfyui-wiki によりワークフロー テンプレートを v0.11.102 に更新
  • https://github.com/Comfy-Org/ComfyUI/pull/17542 の @comfyanonymous により、comfy-kitchen のバージョンを 0.2.41 に更新
  • 潜在的なクラッシュを修正。 @comfyanonymous 著、https://github.com/Comfy-Org/ComfyUI/pull/17543
  • qwen 3.x のパフォーマンスの改善 (パート 4) - https://github.com/Comfy-Org/ComfyUI/pull/17361 の @rattus128 による並列線形重みの結合
  • https://github.com/Comfy-Org/ComfyUI/pull/17454 の @christian-byrne による、agent_requirements.txt (CORE-692) にバージョンを含まない comfy-agent という名前
  • https://github.com/Comfy-Org/ComfyUI/pull/17531 の @kijai によるインポートされたメッシュの Remesh Mesh を修正
  • https://github.com/Comfy-Org/ComfyUI/pull/17511 の @kijai による RelayVSR (CORE-701) をサポート
  • [パートナー ノード] feat(Kling): https://github.com/Comfy-Org/ComfyUI/pull/17536 の @bigcat88 により、Kling 4.0 フラッシュ モデルとオリジナルのオーディオ オプションを Kling 4.0 ノードに追加します。
  • [パートナー ノード] feat(OpenAI): @bigcat88 による GPT イメージ 2.6 モデルを https://github.com/Comfy-Org/ComfyUI/pull/17558 に追加
  • [パートナー ノード] feat(Qwen): Qwen Image ノードを Comfy Router に移動 by @bigcat88 (https://github.com/Comfy-Org/ComfyUI/pull/17527)
  • https://github.com/Comfy-Org/ComfyUI/pull/17563 の @comfyui-wiki によりワークフロー テンプレートを v0.11.103 に更新
  • [パートナー ノード] feat(Gemini): https://github.com/Comfy-Org/ComfyUI/pull/17560 の @bigcat88 により、Omni Flash 1.2 を Omni ビデオ ノードに追加します。
  • https://github.com/Comfy-Org/ComfyUI/pull/17555 の @GACLove による解像度セレクターの megapixel 精度を修正
  • https://github.com/Comfy-Org/ComfyUI/pull/17569 の @alexisrolland による api-node.md の更新
  • run_cpu ポータブル スクリプトを ./advanced に移動 (https://github.com/Comfy-Org/ComfyUI/pull/17571 の @comfyanonymous によって)
  • パートナー ノード チーム コードを https://github.com/Comfy-Org/ComfyUI/pull/17575 の @comfyui-wiki によって comfy_api_nodes の所有者にします
  • [パートナー ノード] feat(ByteDance): https://github.com/Comfy-Org/ComfyUI/pull/17579 の @bigcat88 により Seedance 2.5 に 4K 解像度を追加
  • ポータブル高速 fp16 スクリプトを ./advanced に移動 (https://github.com/Comfy-Org/ComfyUI/pull/17570 の @comfyanonymous により)
  • https://github.com/Comfy-Org/ComfyUI/pull/17582 の @kijai により Qwen 3.x にビデオ入力サポートを追加
  • https://github.com/Comfy-Org/ComfyUI/pull/17497 の @kijai により、スプラットからメッシュを抽出するソリッド モードを追加
  • 潜在的なデータベースの問題を修正します。 @comfyanonymous 著、https://github.com/Comfy-Org/ComfyUI/pull/17602
  • ビデオ コンポーネントの取得: https://github.com/Comfy-Org/ComfyUI/pull/17562 の @synap5e によって、デコードされたフレームを 2 回ではなく 1 回保持します。
  • UNetSelfAttendanceMultiply ノード使用時のクラッシュを修正。 @comfyanonymous 著、https://github.com/Comfy-Org/ComfyUI/pull/17603
  • [パートナー ノード] feat(OpenAI): https://github.com/Comfy-Org/ComfyUI/pull/17591 の @bigcat88 により GPT 画像 V3、GIF、SVG ノードを追加
  • [パートナー ノード] chore(Grok): https://github.com/Comfy-Org/ComfyUI/pull/17532 の @bigcat88 による廃止されたイメージ モデルの価格とツールチップを更新
  • テキスト生成時に qwen fp8 がクラッシュする問題を修正。 @comfyanonymous 著、https://github.com/Comfy-Org/ComfyUI/pull/17620
  • 功績: WeVisOne-VL (CORE-690) をサポート (https://github.com/Comfy-Org/ComfyUI/pull/17632 の @kijai により)
  • https://github.com/Comfy-Org/ComfyUI/pull/17625 の @rattus128 による結合リニアのプリフェッチ使用と非プリフェッチ使用の混合を避ける
  • https://github.com/Comfy-Org/ComfyUI/pull/17635 の @kijai による貪欲デコードに反復/プレゼンス ペナルティを適用
  • 功績: https://github.com/Comfy-Org/ComfyUI/pull/17636 の @kijai によるテクスチャのリベイクを追加し、UltraTex (CORE-606) をサポート
  • https://github.com/Comfy-Org/ComfyUI/pull/17650 の @comfyanonymous による README の画像編集モデルを更新
  • [パートナー ノード] feat(Breeze): https://github.com/Comfy-Org/ComfyUI/pull/17611 の @bigcat88 による Breeze TTS 2 音声およびテキスト読み上げノードを追加します。
  • [パートナー ノード] feat(ByteDance): @bigcat88 による Seedream 5.5 モデルを https://github.com/Comfy-Org/ComfyUI/pull/17631 に追加
  • 特技: https://github.com/Comfy-Org/ComfyUI/pull/17655 の @kijai による MiniMax-H3-image (CORE-708) のサポート
  • https://github.com/Comfy-Org/ComfyUI/pull/17658 の @comfyui-wiki によりワークフロー テンプレートを v0.11.105 に更新
