#快適UI v0.38.0

  • https://github.com/Comfy-Org/ComfyUI/pull/16429 の @rattus128 により qwen 2.1 KV キャッシュの場所のロジックを改善

  • torchaudio の依存関係を削除します。 @comfyanonymous 著、https://github.com/Comfy-Org/ComfyUI/pull/16457
  • エースステップ 1.5 自己回帰モデル上の Cuda グラフ + メモリ コンパイラ。 @comfyanonymous 著、https://github.com/Comfy-Org/ComfyUI/pull/16461
  • https://github.com/Comfy-Org/ComfyUI/pull/16436 の @kijai により、合成された隣接タイルに対して H3 VAE タイルをブレンドします

  • lumina ファミリー モデルのメモリ使用量の削減と .comfy_attention のサポート。 @comfyanonymous 著、https://github.com/Comfy-Org/ComfyUI/pull/16515
