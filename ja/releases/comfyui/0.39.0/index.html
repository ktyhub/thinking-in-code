ComfyUI v0.39.0

マイナー 公開日2026年10月5日 出典comfyanonymous/ComfyUI 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#快適UI v0.39.0

何が変わったのか

  • https://github.com/Comfy-Org/ComfyUI/pull/16657 の @kijai による LynnReal light Minimax-H3 vae をサポート
  • https://github.com/Comfy-Org/ComfyUI/pull/16618 の @comfyui-wiki により埋め込みドキュメントを v0.5.13 に更新
  • ビデオ保存エンコーディングには高品質のデフォルトを使用します。 @comfyanonymous 著、https://github.com/Comfy-Org/ComfyUI/pull/16663
  • 功績: @jaeone94 による https://github.com/Comfy-Org/ComfyUI/pull/16260 入力の DynamicGroup ウィジェットを追加
  • 修正（アセット）: リストに掲載できないモデル カテゴリによって、https://github.com/Comfy-Org/ComfyUI/pull/16658 の @synap5e によるスキャンが中止されないようにしました。
  • 修正(資産): https://github.com/Comfy-Org/ComfyUI/pull/16646 の @synap5e によるハッシュオフでドライブが戻ってきたときにレコードを回復する
  • https://github.com/Comfy-Org/ComfyUI/pull/16667 の @comfyanonymous による qwen イメージ 2.1 で int8 または int4 キャッシュを選択するとクラッシュする問題を修正
  • [パートナーノード] feat(Anthropic): @bigcat88 による Sonnet 5.5 モデルを https://github.com/Comfy-Org/ComfyUI/pull/16647 に追加
  • [パートナーノード] feat(Ideogram): @bigcat88 による Ideogram 4.5 モデルのノードを https://github.com/Comfy-Org/ComfyUI/pull/16689 に追加
  • minimax vae オフロードの問題を修正。 @comfyanonymous 著、https://github.com/Comfy-Org/ComfyUI/pull/16698
  • [パートナー ノード] feat(HeyGen): https://github.com/Comfy-Org/ComfyUI/pull/16695 の @bigcat88 による HeyGen ビデオ 1.0 モデルのノードを追加します。
  • https://github.com/Comfy-Org/ComfyUI/pull/16693 の @comfyui-wiki によりワークフロー テンプレートを v0.11.73 に更新
  • Save EXR に 16 ビット浮動小数点数のサポートを追加。 @comfyanonymous 著、https://github.com/Comfy-Org/ComfyUI/pull/16706
  • https://github.com/Comfy-Org/ComfyUI/pull/16456 の @comfy-pr-bot によって comfyui-frontend-package を 1.53.10 にバンプします
  • https://github.com/Comfy-Org/ComfyUI/pull/16677 の @Tokha233 による、ブロックの前に圧縮された MiniMax H3 埋め込み一時ファイルをリリース
  • 「exr」オプションのデフォルトのビット深度を 16 ビット浮動小数点に更新します。 @comfyanonymous 著、https://github.com/Comfy-Org/ComfyUI/pull/16715
  • 功績: --offline および --disable-partner-nodes を追加し、https://github.com/Comfy-Org/ComfyUI/pull/16672 の @deepme987 により --disable-api-nodes を非推奨にしました
  • [パートナー ノード] feat(BFL): https://github.com/Comfy-Org/ComfyUI/pull/16716 に @bigcat88 による FLUX 3 Image ノードを追加
  • [パートナー ノード] feat(Grok): @bigcat88 による grok-imagine-video-1.5-lite モデルを https://github.com/Comfy-Org/ComfyUI/pull/16721 に追加
  • https://github.com/Comfy-Org/ComfyUI/pull/16724 の @purzbeats によりワークフロー テンプレートを v0.11.74 に更新
  • fix(assets): バッチ プレフィックス フィルターにより、スキャンが多くのモデル フォルダーで機能するようになります (https://github.com/Comfy-Org/ComfyUI/pull/16645 の @synap5e による)
  • https://github.com/Comfy-Org/ComfyUI/pull/16738 の @comfyanonymous により、comfy-kitchen のバージョンを 0.2.37 に更新
  • [パートナーノード] chore(Luma): https://github.com/Comfy-Org/ComfyUI/pull/16741 の @bigcat88 により Ray 2 ノードを非推奨にしました
  • https://github.com/Comfy-Org/ComfyUI/pull/16739 の @comfyui-wiki によりワークフロー テンプレートを v0.11.76 に更新
  • https://github.com/Comfy-Org/ComfyUI/pull/16746 の @rattus128 により、統合された GPU で固定メモリを自動的に無効にします
  • feat(assets): スキャンの CPU と一時停止時間をレポートし、https://github.com/Comfy-Org/ComfyUI/pull/16719 の @synap5e によってスキャンの失敗を分類します。
  • fix(assets): アセットがオフのときにデータベース ロックを取得しません。 https://github.com/Comfy-Org/ComfyUI/pull/16742 で @synap5e によって保持されている場合に警告します
  • https://github.com/Comfy-Org/ComfyUI/pull/16636 で @jtydhr88 による境界ボックスの作成の背景を UI プレビューとしてエコーします
  • perf(assets): https://github.com/Comfy-Org/ComfyUI/pull/16659 の @synap5e によるライブパス インデックスの部分的なライブパス検索を提供します。
  • [パートナー ノード] 偉業(イレブンラボ): https://github.com/Comfy-Org/ComfyUI/pull/16737 の @bigcat88 による イレブン v4 および v4 ターボ モデルを追加
  • [パートナー ノード] 修正 (OpenAI): https://github.com/Comfy-Org/ComfyUI/pull/16744 の @bigcat88 による GPT 画像 2 の透明な背景を削除
  • fix(assets): https://github.com/Comfy-Org/ComfyUI/pull/16696 の @synap5e によって保存がロックアウトされないように、プルーンとオフライン マーキングを短いバッチで書き込む
  • https://github.com/Comfy-Org/ComfyUI/pull/16762 の @comfyanonymous により、AGENTS.md に新しい注意とコンパイラ要素を追加
  • comfy_attention と AttendanceTensorContainer のサポートをより多くのモデルに追加します。 @comfyanonymous 著、https://github.com/Comfy-Org/ComfyUI/pull/16766
  • 修正（アセット）: 短いトランザクションでスキャン挿入を書き込み、アップロードと出力保存がロックアウトされないように + https://github.com/Comfy-Org/ComfyUI/pull/16748 の @synap5e による WAL synchronous=NORMAL を使用
  • 修正(資産): https://github.com/Comfy-Org/ComfyUI/pull/16765 の @synap5e によってプロンプト キューが空になったらバックグラウンド スキャンを再開します
  • 修正（アセット）: https://github.com/Comfy-Org/ComfyUI/pull/16764 の @synap5e により、フォルダーのウォークとファイルの統計中にスタートアップ スキャンを一時停止します。
  • 修正(アセット): https://github.com/Comfy-Org/ComfyUI/pull/16722 の @synap5e により、宛先が別のボリュームにある場合にアップロードを所定の場所にコピーします
