何が変わったのか

機能

  • 機能 (設定): https://github.com/OpenHands/OpenHands/pull/16772 の @keeltrace によってサポートされている LLM プロバイダーを選択します
  • 功績: https://github.com/OpenHands/OpenHands/pull/16656 の @georgeglarson による Linux デスクトップ インストーラー ビルド (CI + deb メンテナー修正) を追加
  • feat(オートメーション): https://github.com/OpenHands/OpenHands/pull/16740 の @aartem1 による実行のライブフェーズを表示します。
  • 特技(設定): https://github.com/OpenHands/OpenHands/pull/16441 の @georgeglarson によりエージェント設定で LLM 切り替えトグルを公開
  • 特技(スキル): https://github.com/OpenHands/OpenHands/pull/16860 の @VascoSch92 によるオールオン スキル カタログを明示的な許可リストに置き換えます。
  • 功績: チャット ファイル パスをファイル ドロワーにリンク (https://github.com/OpenHands/OpenHands/pull/16181 の @SashwatXD により)
  • 功績: https://github.com/OpenHands/OpenHands/pull/16868 の @hieptl により、お気に入りのサイドバー ページをホーム ルートとして固定します
  • 特技: ユーザーが追加したローカル バックエンドに使用可能な LLM がある場合、オンボーディングをスキップ (https://github.com/OpenHands/OpenHands/pull/16931 の @VascoSch92 による)
  • 功績: https://github.com/OpenHands/OpenHands/pull/16922 の @neubig によるデフォルト モデルと無料モデルを修正
  • 偉業: Canvas Extensions フロントエンド (ページのロード、サイドバー、カスタマイズ) を @hieptl によって https://github.com/OpenHands/OpenHands/pull/16895 に着陸させました。

バグ修正

  • 修正: https://github.com/OpenHands/OpenHands/pull/16106 の @harish-chandramowli によってセルフホスト (ローカル) バックエンドで VSCode ボタンをレンダリングする
  • 修正: https://github.com/OpenHands/OpenHands/pull/16796 の @neubig によるローカル会話テレメトリと Canvas ID の関連付け
  • fix(ci): https://github.com/OpenHands/OpenHands/pull/16595 の @ump45nose による準備チェックで囲まれた見出しを無視する
  • 修正: https://github.com/OpenHands/OpenHands/pull/16812 の @jdlake によってバックエンドがそれらを除外するように、disabled_skills をagent_context に転送しました。
  • 修正 (ci): 準備ができていない問題で問題準備ワークフローが失敗するのを防ぐ (https://github.com/OpenHands/OpenHands/pull/16514 の @KHARSHAVARDHAN-eng による)
  • fix(ci): https://github.com/OpenHands/OpenHands/pull/16828 の @neubig による開発準備完了チェックの再現手順を使用
  • 修正 (acp): Docker/クラウド (#15643) で '認証情報が設定されました' バナー状態を表示 (https://github.com/OpenHands/OpenHands/pull/16145 の @georgeglarson による)
  • fix(ci): https://github.com/OpenHands/OpenHands/pull/16591 の @VascoSch92 によって配置されたモック LLM E2E PR コメントを編集します
  • 修正 (プロバイダー): next_page_id に従い、クラウドがデフォルトのページ サイズを超えるサーフェスを選択するようにします (https://github.com/OpenHands/OpenHands/pull/16758 の @georgeglarson による)
  • fix(ci): https://github.com/OpenHands/OpenHands/pull/16830 で @neubig によってラベルが追加されたときに準備コメントを更新
  • 修正 (デスクトップ): https://github.com/OpenHands/OpenHands/pull/16381 の @Telov により Windows 上にバンドルされたノードの npm を出荷
  • fix(agent-canvas): https://github.com/OpenHands/OpenHands/pull/16759 の @enyst により、working_dir のスコープをデフォルトのローカル バックエンドにベイクしました
  • 修正: https://github.com/OpenHands/OpenHands/pull/16280 の @georgeglarson による SIGHUP 上の dev:extra-backend Agent-server をクリーンアップ
  • 修正: https://github.com/OpenHands/OpenHands/pull/16279 の @georgeglarson による SIGHUP の dev:minimal サービスをクリーンアップ
  • 修正: https://github.com/OpenHands/OpenHands/pull/16863 の @tofarr によるクラウド上の OpenHands プロバイダーの API キーを非表示にしました
  • fix(home): https://github.com/OpenHands/OpenHands/pull/16881 の @tofarr によるローカル ワークスペース モードの選択を記憶する
  • 修正: https://github.com/OpenHands/OpenHands/pull/16867 の @hieptl によるバインドされたオートメーションの実行履歴のファンアウトとサイドバーのポーリングの一時停止
  • 修正: https://github.com/OpenHands/OpenHands/pull/16840 の @JatinJain703 によるバックエンド接続ステップを進める前に api キーを検証する
  • 修正: https://github.com/OpenHands/OpenHands/pull/16966 の @jpelletier1 によるクラウド バックエンドでの会話タイトルの名前を変更

ドキュメント

  • ドキュメント: https://github.com/OpenHands/OpenHands/pull/16807 の @kris3984 による AGENTS.md の new-conversation-button.tsx への壊れた参照を修正 (#16783)
  • ドキュメント: https://github.com/OpenHands/OpenHands/pull/16832 の @neubig による受け入れ基準レビュー チェックリストが必要です
  • ドキュメント: https://github.com/OpenHands/OpenHands/pull/16834 の @neubig による OpenHands リポジトリ境界の文書化
  • ドキュメント: https://github.com/OpenHands/OpenHands/pull/16310 の @all-hands-bot による AGENTS.md ガイダンスを更新
  • ドキュメント: https://github.com/OpenHands/OpenHands/pull/16923 の @all-hands-bot による AGENTS.md ガイダンスを更新
  • ドキュメント: https://github.com/OpenHands/OpenHands/pull/16942 の @enyst による PR テンプレート エージェント セクションを明確にしました
  • ドキュメント: https://github.com/OpenHands/OpenHands/pull/16941 の @enyst による Canvas コード レビュー ガイドラインを更新

メンテナンス

  • 雑用: https://github.com/OpenHands/OpenHands/pull/16935 の @smolpaws による未使用のランダムチップコードを削除
  • 雑用: SDK deps (software-agent-sdk 1.44.0、自動化 1.9.0、拡張機能 0.19.0) を @hieptl で https://github.com/OpenHands/OpenHands/pull/16968 でバンプ
