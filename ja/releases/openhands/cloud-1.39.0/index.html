  • 功績: @HeyItsChloe による会話制限の強制 (https://github.com/OpenHands/OpenHands/pull/14168)
  • 特技(APP-2136): https://github.com/OpenHands/OpenHands/pull/14688 の @erisful によってすべてのユーザーにオートメーション メニュー項目を公開
  • feat(jira-dc): https://github.com/OpenHands/OpenHands/pull/14650 の @ak684 によるリゾルバー会話でのユーザーごとの OAuth トークンの永続化と挿入
  • feat(jira-dc): https://github.com/OpenHands/OpenHands/pull/14697 の @ak684 による対象となる会話で、リンクされた OAuth トークンを共有します

  • 偉業: PLTF-2956 https://github.com/OpenHands/OpenHands/pull/14821 の @aivong-openhands による get_suggested_tasks で GitHub GraphQL クエリを並列化
  • 特技: https://github.com/OpenHands/OpenHands/pull/14883 の @ak684 により、カスタム サンドボックス イメージのエージェントとサーバーの SDK が一致しない場合に明らかなエラーが表示されます。

  • 功績: エージェント コンテキストで Slack 添付ファイルをサポート (https://github.com/OpenHands/OpenHands/pull/14934 の @malhotra5 により)
