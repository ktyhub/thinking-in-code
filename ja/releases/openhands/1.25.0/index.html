何が変わったのか

機能

  • 功績: https://github.com/OpenHands/OpenHands/pull/17587 の @errmakov による設定サブページの戻るナビゲーション コントロールの概要
  • 機能 (設定): プロバイダー モデルを LLM プロファイルとして一括追加 (https://github.com/OpenHands/OpenHands/pull/16426 の @georgeglarson による)
  • 功績: @juanmichelini によるダイレクト プロンプト モデル ルーター設定を https://github.com/OpenHands/OpenHands/pull/16147 に追加
  • feat(canvas): イベント ID によってストリーミング スロットを廃止し、https://github.com/OpenHands/OpenHands/pull/17465 の @VascoSch92 によってテキスト マッチング リコンサイラーを削除します。
  • 特技(アプリ): https://github.com/OpenHands/OpenHands/pull/17736 の @VascoSch92 により、インストールされたキャンバス アプリの更新アクションを追加
  • 機能 (設定): 接続ごとに LLM プロファイルを一括追加 (https://github.com/OpenHands/OpenHands/pull/17723 の @juanmichelini による)
  • 功績: https://github.com/OpenHands/OpenHands/pull/17797 の @juanmichelini によるモデルルーター「会話開始時に実行」トグルを追加
  • 機能 (自動化): クラウド バックエンドでテンプレートを表示し、https://github.com/OpenHands/OpenHands/pull/17830 の @hieptl によるネイティブ Git 統合を提供します。
  • 特技(チャット): https://github.com/OpenHands/OpenHands/pull/17804 の @VascoSch92 によるチャット入力にオプションの音声ディクテーションを追加します。
  • feat(automations): https://github.com/OpenHands/OpenHands/pull/17814 の @henriquehirako による作成者別にオートメーション ダッシュボードをフィルターします。
  • 機能: 最初のルーターが https://github.com/OpenHands/OpenHands/pull/17840 で @juanmichelini によって作成されたときに、「最初のメッセージで実行」を自動有効化
  • 偉業(会話): https://github.com/OpenHands/OpenHands/pull/17612 の @errmakov によるドロワー タブ ストリップに実際のタブ セマンティクスを与える
  • feat(canvas): https://github.com/OpenHands/OpenHands/pull/17877 の @VascoSch92 により、キャンバス拡張機能のマニフェストで宣言された SVG アイコンをレンダリングします。
  • 機能 (自動化): https://github.com/OpenHands/OpenHands/pull/17868 の @hieptl による発行から PR テンプレートの前に組み込みの統合を提供します。
  • feat(agent-profiles): サーバーのカタログからすべてのツールを選択します。 SDK 1.53.0 ピン (https://github.com/OpenHands/OpenHands/pull/17516 の @simonrosenberg 作)
  • feat(agent-profiles): プロフィールに独自のペルソナまたは追加の指示を与える (https://github.com/OpenHands/OpenHands/pull/17843 の @simonrosenberg による)
  • feat(files): https://github.com/OpenHands/OpenHands/pull/17869 の @kr1shna-exe によるワークスペース ファイルの検出を構成します

バグ修正

  • 修正（フロントエンド）: https://github.com/OpenHands/OpenHands/pull/17592 の @FOWEPJF255 により狭い画面でもプラグイン検索を使用できるようにする
  • 修正（フロントエンド）: https://github.com/OpenHands/OpenHands/pull/17469 の @shinji00222 により、丸めがそれに達したときにコンパクト トークン カウントを次のユニットにプロモートします。
  • fix(model-selector): https://github.com/OpenHands/OpenHands/pull/17464 の @Harsh23Kashyap による Perplexity Provider キーのスペルミスを修正
  • 修正: https://github.com/OpenHands/OpenHands/pull/17152 の @jabrailkhalil によるディレクトリ修飾パスから Dockerfile 言語を検出
  • 修正(チャット): https://github.com/OpenHands/OpenHands/pull/16116 で @KXHXK によって長い /btw 応答をスクロール可能にする
  • fix(tests): LLMModel フィクスチャに、https://github.com/OpenHands/OpenHands/pull/17750 の @simonrosenberg によってタイプが現在必要としているフィールドを与えます
  • 修正: https://github.com/OpenHands/OpenHands/pull/17007 の @neubig により、ローカル セッション キーを外部から到達可能なリスナーから遠ざけるようにしました。
  • 修正: https://github.com/OpenHands/OpenHands/pull/17211 の @neubig によるオンボーディング中に正規 LLM 設定を保持する
  • 修正 (フロントエンド): オンボーディング中に https://github.com/OpenHands/OpenHands/pull/17212 で @neubig によるチャットが開始されるときに進行状況を表示する
  • fix(canvas): https://github.com/OpenHands/OpenHands/pull/17387 の @neubig によるスコープ指定されたランタイム clients とワークスペース機能を尊重します。
  • 修正: タイトルの生成では、実行中のエージェント プロファイルと同じ LLM が使用されます (https://github.com/OpenHands/OpenHands/pull/16886 の @juanmichelini による)
  • 修正: https://github.com/OpenHands/OpenHands/pull/17835 の @juanmichelini によってプロファイルが存在しないときに作成されるようにルーター分類子モデルを事前選択
  • 修正: https://github.com/OpenHands/OpenHands/pull/16976 の @malhotra5 による同意を意識した Web サイト PostHog ハンドオフを消費する
  • 修正（子会話）: https://github.com/OpenHands/OpenHands/pull/17842 の @lilagrc によりクラウドの子をエージェント キャンバスにリンク
  • 修正（自動化）: リストをオフセットでページングするため、https://github.com/OpenHands/OpenHands/pull/17839 の @henriquehirako による 100 を超えた作品をさらにロードします
  • 修正 (ルーター): Flash テンプレート プロンプトを完成させ、https://github.com/OpenHands/OpenHands/pull/17860 の @juanmichelini によるモデル テーブルを挿入
  • 修正: https://github.com/OpenHands/OpenHands/pull/17984 の @tofarr によるクラウド レート制限をトリップする再フェッチ オン フォーカス バーストをバックオフして停止する
  • 修正 (WebSocket): フォアグラウンドで再接続し、モバイル バックグラウンドできれいに切断 (https://github.com/OpenHands/OpenHands/pull/17982 の @tofarr)
  • 修正: https://github.com/OpenHands/OpenHands/pull/17866 で @hieptl によってクラウド ホストにロックされている場合、非表示のキャンバス設定ページをブロックする
  • 修正 (自動化): https://github.com/OpenHands/OpenHands/pull/17971 の @qingshungLI によるプリセット アクションのエージェント プロファイルを非表示にしました
  • 修正: https://github.com/OpenHands/OpenHands/pull/17279 の @simonrosenberg による名前付きエージェント プロファイルにランタイム サービスを提供
  • 修正 (フロントエンド): https://github.com/OpenHands/OpenHands/pull/17719 の @Harsh23Kashyap によるインラインおよびプロファイル起動用に保存されたプロンプト サフィックスを保持する
  • 修正 (設定): https://github.com/OpenHands/OpenHands/pull/18008 の @enyst により、エージェント キャンバスの更新ダイアログを電話ビューポート内に維持します
  • 修正 (エージェント プロファイル): 委任ツールを使用して task_tracker を保存 (SDK#5519 の回避策) by @simonrosenberg (https://github.com/OpenHands/OpenHands/pull/18001)
  • fix(a11y): 1 つの設定メインランドマーク、aria-current のカスタマイズ、https://github.com/OpenHands/OpenHands/pull/18012 の @enyst による同期された HTML 言語
  • 修正(設定): https://github.com/OpenHands/OpenHands/pull/18020 の @awss1i によるルーター テンプレートの「プロファイルを作成しない」を維持します
  • fix(conversations): https://github.com/OpenHands/OpenHands/pull/18009 での @enyst による無効な応答ではなく、null バッチ エントリを見つからないものとして扱います
  • 修正 (設定): https://github.com/OpenHands/OpenHands/pull/18013 の @enyst によるモデル ルーター リスト テキストにテーマ コントラスト インクを使用
  • 修正（チャット）: https://github.com/OpenHands/OpenHands/pull/18015 の @enyst により、コンポーザーのオーバーフロー メニューが狭い幅で開いたままになる
  • 修正 (自動化): https://github.com/OpenHands/OpenHands/pull/18011 の @enyst により、削除の確認をエスケープで閉じるモーダル ダイアログにします
  • fix(llm-profiles): https://github.com/OpenHands/OpenHands/pull/18017 の @enyst によるモデルに従って自動入力されたプロファイル名を維持します
  • 修正(スキル): https://github.com/OpenHands/OpenHands/pull/18016 の @enyst による「スキルの使用」と「オートメーションの作成」からホーム コンポーザーを事前に入力
  • 修正(チャット): https://github.com/OpenHands/OpenHands/pull/18014 の @enyst による「ここから分岐」の後のコンポーザー内のメッセージ テキストを保持する
