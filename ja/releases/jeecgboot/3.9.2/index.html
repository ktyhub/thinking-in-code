#JecgBoot v3.9.2

アップグレードログ

**v3.9.2 は、AI ルートが開始されて以来、JecgBoot の最も重要なバージョン アップグレードです。 ** ローコードが再び進化し、正式に v2.0 時代に入りました。「ドラッグ アンド ドロップ」から「自然言語の文」まで、スキルの完全なサポートにより、一文でビジネスを構築でき、手動構成は過去のものになります。ローコードはもはや「ドラッグ アンド ドロップして CRUD を生成する」だけではありません。一文で大画面を作成、一文で OA 承認を構築、一文でシステム全体を生成することが JeecgBoot で実現しました。このアップグレードでは、ローコード開発エクスペリエンスも包括的に磨き上げられ、フォーム、チャート、大画面、セキュリティ、フロントエンドのパフォーマンスの体系的な最適化をカバーし、同時にオンライン フロントエンド ソース コードを開き、新しいオンライン チャート モジュールを追加しました。

✨ このリリースの「高さ」

1. スキル: AI を真の開発パートナーにしましょう
  • Claude Code Skills はロー コードに接続: コード生成、オンライン フォーム、レポート、大画面、およびプロセスは Claude Skills に完全に統合されており、コード ジェネレーターを手動で操作する必要はありません。 - AI は、一文でコードを生成し、一文でシステム全体を生成し、一文でオンライン フォームを作成し、一文でオンライン レポートを作成し、一文で大画面をデザインし、一文で辞書を構成し、メニューを作成して認証を完了し、すべてを指先で実行します。
2. AI アプリケーションの最適化
  • Chat2BI / Chart2BI ドッキング オンライン フォーム: ページ分割されたテーブル、レポート、グラフ構成を 1 文で生成し、データ分析リンク全体を開きます。
  • AI プロセス オーケストレーション機能が爆発的に: 新しい変数の読み取りと書き込み、メモリの取得、ループ変数、構造化された JSON 出力、プロンプト ワード リストの関連付け、ファイル アップロード開始ノードなどを備えた AiFlow は、完全なビジュアル エージェント オーケストレーション プラットフォームに進化しました。
  • AI アプリケーション ツールのホワイトリスト + クロステナント分離: 機能の開放と権限制御の両方が実装され、SaaS マルチテナントのセキュリティ境界がしっかりと確立されます。
  • サポートする AI アシスタント ネットワーク検索 と AI プロセス検索エンジン ノード が起動され、AI プロセスは「ツールの使い方を知る」だけでなく、「情報の調べ方を知る」こともできます。
  • Langchain4j 1.12.2 アップグレード: Java AI アプリケーション機能の境界を再定義 - AI アシスタントは手動のプロンプト ワード ブラインド調整インターフェイスに依存しなくなり、ビジネス機能を自動的に選択して呼び出すためのスキル メタデータもサポートします。
3. AI マルチモーダル生産性 (画像 / 音声 / ビデオ / 着替え)
  • 実際の AI が生成した オーディオ/ビデオ/画像、デモは不要
  • AI着せ替えが写真と動画を同時に出力
  • Google 画像生成モデル、ローカル音声合成、混合画像サンプルがすべて揃っています
  • モデル マトリックスの補完: VLLM / Xinference / LMStudio / qwen-vl-ocr / qwen3.5-plus / Tongyi Qianwen / Qianfan
4. オンライン 3 点セット (フォーム/レポート/グラフ) の 1 回限りの最適化
  • オンライン モジュールのフロントエンド ソース コードは完全にオープン ソースです。 AI時代ではユーザーは自由かつ柔軟に拡張でき、二次開発にも敷居がありません。
  • 新しいオンライン チャート モジュールが追加され、チャート パネルを迅速に構成し、より多くの視覚化オプションをユーザーに提供します。
  • 新しい LongText フィールド タイプ および link_table / link_table_field タイプ (Vue3 の 1 対多の関連レコード、クロステーブル フィールド参照)
  • サブテーブルは分類辞書ツリーとカスタム辞書ツリーをサポートし、階層データ構成をより柔軟にします
  • 長年の永続的な問題の解決: オンライン設定の遅れ (QQYUN-14177)、オンラインを開くのが遅い、小さな画面フィールドの位置が表示されない、およびその他のエクスペリエンスの問題点が完全に修復されました。
  • 新しいオンライン フォーム スキーマ仕様ドキュメントが追加され、AI がオンライン メタデータを深く理解するための強固な基盤が築かれました。
5. 完全なオンデマンド読み込み、フロントエンドのスリム化
  • antd / unplugin-icons / Jvxetable / Vxetable / TinyMCE / JEasyCron / codemirror / チャット モジュールはすべてオンデマンドでロードされます
  • 最初の画面のサイズと読み込み速度が大幅に短縮され、AI アシスタントがオンラインでビジネス ページにアクセスできるようになりました。
6. セキュリティ強化
  • AI ポスター SSRF (#9579)、AI 添付ファイル パス トラバーサル (#9519)、AiragApp クロステナント書き込み (#9462)、トークン不正アクセス (#9518)、RCE #9335、およびその他の多くの高リスク脆弱性が集中的な方法で修正されました。
  • MCP / 基盤となる機密ツールの包括的な権限検証

🎯 ローコード v2.0 時代とは何を意味しますか?

スキルを使用すると、ローコード プラットフォームに蓄積されたフォーム、プロセス、レポート、大画面が自動的に AI によって直接呼び出せるビジネス機能になることができます。手書きのツールや二次開発は必要なく、自然言語によってビジネス プロセスの完全なセットの自動実行を推進でき、さらにはシステム全体を 1 つの文で生成することもできます。 |寸法 | v3.9.1以前(ドラッグアンドドロップ時代) | v3.9.2（一文時代） | |---|---|---| |ローコードの位置付け |フォーム/プロセス/コード生成/レポートと大画面デザイン | AI ネイティブ ビジネス機能のエクスポート | |インタラクティブモード |ドラッグ アンド ドロップ + 手動設定 | 自然言語の 1 文で、すべてを実行できます | |ビジネス構築 |コンポーネントを手動でドラッグし、フィールドを構成し、プロセスをセットアップする | 帳票設計と描画処理を一文で/レポート/大画面/メニュー | | AIの活用 |完全な手動構築: 手動でフォームを構成し、プロセスを描画し、関連付けを作成し、メニューを構成し、ステップバイステップの認証を行います。 AI は、フォームの構築、プロセスの描画、関連付け、メニューの作成、承認を 1 つの文ですべて 1 つのステップで実行できます | | AI へのビジネス アクセス |手書きツールの二次開発が必要 | オンライン フォーム/プロセス ノード = 自然なスキル | |マルチモーダル |テキストのみ | テキスト/画像/オーディオ/ビデオ/スキルの完全なモーダルカバレッジ | |セキュリティ |分散型脆弱性修復 | 特化した脆弱性修復 + 権限制御 + テナントの隔離と強化 |

スキル機能モジュール (新しい独立した倉庫 jeecgboot/skills)

v3.9.2 のメイン バージョンと同時にリリースされた新しい独立したウェアハウス jeecgboot/skills - クロード コードに基づく AI スキルのコレクションであり、自然言語によって駆動され、コード、フォーム、プロセス、レポート、チャート、大画面、およびダッシュボードを一文で生成します。

  • jeecg-onlreport: オンライン レポート ジェネレーター - SQL 駆動のデータ レポート
  • jeecg-desform: デザイナー フォーム ジェネレーター - フォームを生成するスクリーンショット認識をサポート JSON
  • jeecg-onlchart: オンライン チャート ジェネレーター - データ視覚化チャートを自動的に生成します
  • jeecg-bpmn: BPM プロセス ジェネレーター - Flowable BPMN XML 承認プロセスを自動生成します
JimuReport 3つのスキル
  • jimureport: ビルディング ブロック レポート ジェネレーター - マルチタイプ レポート + スクリーンショットの認識と生成
  • jimubi-bigscreen: 大画面ジェネレーター - 1920×1080 のフルスクリーン データ視覚化
  • jimubi-dashboard: ダッシュボード ジェネレーター - 24 列のグリッド レイアウト データ ダッシュボード
