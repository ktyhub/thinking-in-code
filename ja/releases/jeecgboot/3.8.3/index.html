#JecgBoot v3.8.3

発売時期: v3.8.3 | 2025-10-09

ソースコードのダウンロード

  • Github アドレス: https://github.com/jeecgboot/JeecgBoot
  • 宛先アドレス: https://gitee.com/jeecg/JeecgBoot

アップグレードログ

このバージョンでは、組織構造と職務レベルを中心に徹底的な変革が行われ、子会社構造、職務の上司と部下、および職務レベルの設定がサポートされ、部門の人員維持とユーザーのメインおよびパートタイムの職位管理が最適化され、組織管理の柔軟性と明確性が向上しました。同時に、ホームページ構成は多次元のパーソナライズされたカスタマイズを実現し、テナント管理がより使いやすくなり、パッケージコンセプトがより明確になります。

  • 基盤となるアーキテクチャに関しては、Spring Boot 3.5.5、Spring Cloud 2025.0.0、Spring Cloud Alibaba 2023.0.3.3 にアップグレードし、Tomcat コンテナーに戻し、起動速度を最適化し、遅延読み込みをサポートします。コード生成はフロントエンドとバックエンドの個別のパス構成をサポートし、メニュー SQL は Flyway ディレクトリに自動的に同期されるため、開発効率が向上します。
  • さらに、このバージョンでは、フロントエンド コンポーネントとバックエンド機能における多数の重要な問題が修正され、分散トランザクションのサポートが改善され、データベース ドライバーがアップグレードされ、システムの安定性とパフォーマンスが向上します。 AIアプリケーションやローコードプラットフォームの機能も強化され、よりスムーズでスマートな体験をユーザーに提供します。
  • 特別な注意事項: デフォルトのトランクは Spring Boot 3 に切り替えられ、Java 21 エコシステムを完全に採用し、システムのパフォーマンスとセキュリティが向上します。 v3.8.3 は Spring Boot 2 の最後のバージョンになります。将来的にはバージョン Spring Boot 3 のみがリリースされる予定です。バージョン Spring Boot 2 はアップグレードおよび保守されなくなります。ユーザーは事前にアップグレードの準備をすることをお勧めします。
主要な組織変更
    1. 組織体制を大幅に再編し、子会社、役職、部門機能を明確化（部門の右側に人材維持機能を追加）
    1. 役職は「上司と部下」の設定と「階級」の設定をサポートします。新しいランクレポート関係が追加されました
    1. 職位変換、元の人員配置の「職位」機能が無効になり、「部門職位レベル」に変更されます。
    1. ユーザーがメインポジションとパートポジションの設定をサポートします
    1. ホームページ構成を大幅に刷新し、役割やユーザーによるパーソナライズされたホームページの多面的な設定をサポートします。
    1. テナント様にとって使いやすい大規模リニューアル（パッケージコンセプトの明確化）
    1. 新しいパッケージを作成し、「ユーザーを自動的に割り当てる。その場合、新しいユーザーとリクエスト ユーザーはデフォルトでパッケージに関連付けられます。」という属性を追加します。
    1. [マイ テナント] の下に、[テナントのポジション] および [テナントの部門] メニューを追加します。
    1. [My Tenants] で、[My Tenants] が表示ページに変更されます。
大きな変化
  • Tomcat に戻し、undertow を非推奨にする
  • バックグラウンド起動速度を最適化し、遅延初期化による遅延読み込み起動をサポート (大規模なプロジェクトと遅い起動の問題を解決)
  • JeecgBoot動作環境pythonチェックスクリプトを提供
  • springboot3 ブランチ、spring-boot を 3.5.5 に、spring-cloud を 2025.0.0 に、spring-cloud-alibaba を 2023.0.3.3 にアップグレードします。
  • springboot3 バージョン、jdk17、jdk21、jdk24 をサポート
  • コード生成フロントエンド コードはフロントエンド プロジェクトへの直接生成をサポートしており、メニュー SQL は開始プロジェクトの flyway ディレクトリに自動的に生成されます。
  • コード生成はフロントエンドとバックエンドに対応する 2 つのパスで構成可能 · 問題 #7197

  • ログインとログアウトの速度を最適化します。
