#JecgBoot v3.7.1

現在のバージョン: v3.7.1 | 2024-09-12

アップグレードログ

このバージョンのハイライト: コード ジェネレーターは、複数のディレクトリと詳細を含むサブパッケージの生成をサポートするために大幅に最適化されています。最新バージョンのビルディング ブロック レポートはレポート機能をサポートし、ダッシュボードは新しいバージョンにアップグレードされ、マイクロサービス ゲートウェイ構成は簡素化され、いくつかの基礎となるコンポーネントがアップグレードされ、オンライン機能の最適化などが行われます。 アップグレードされた SQL を使用

新機能

  • ビルディングブロックレポートを最新バージョンにアップグレードし、フォームデザインと入力機能を追加しました。
  • ビルディング ブロック ダッシュボードを最新バージョンにアップグレードします
  • nacos を 2.3.2 にアップグレードします。これはデフォルトで国内の Dameng データベースをサポートします。
  • CVE-2024-24113 を回避するには、xxl-job をバージョン 2.4.1 にアップグレードします。
  • オートポイを最新バージョン 1.4.11 にアップグレードします。
  • シングルおよびマイクロサービスのフロントエンドおよびバックエンド用のワンクリック docker スタートアップを追加しました
  • 簡素化されたマイクロサービス ゲートウェイ構成、レプリケーション、論理削除、ごみ箱をサポート
  • システム機能インターフェースの詳細の最適化
  • 現在ログインしているユーザーの権限の変更は、ログアウトして再度ログインすることなく直接有効になります。
  • 州および地方自治体のデータを更新する
  • sas ブランチ ログイン インターフェイスは、元のフロントエンドのメイン ブランチ ログインに適応し、トークンの長さを短縮します。
  • アノテーションメソッドをリクエストするホワイトリスト管理権限を変更する
  • WebSocket が必ず壊れる、書き方を変更する
  • データ非感作機能の最適化

コードジェネレーターの最適化

  • コード生成はサブパッケージの複数レベルのディレクトリをサポートします
  • コード生成は、フロントエンド許可命令 v-auth の生成をサポートします。
  • コード生成は新しいコントロール JPopupDict 辞書をサポートします
  • コードによって生成されたクエリ条件範囲コントロールは、日付範囲、数値範囲、金額範囲などの美しい効果に置き換えられました。
  • ユーザーおよび部門コンポーネントは、コード生成時にオンライン ストレージ フィールドと表示フィールドに従って構成されます。
  • ネイティブ フォームは検証に失敗し、検証に失敗したフィールドにロールされませんでした。
  • 非ネイティブ フォームは検証に失敗し、検証に失敗したフィールドにロールされませんでした。
  • 詳細ページで検証修正がトリガーされました
  • ERP スタイルのサブテーブル操作列はフローティングではありません
  • ページ コントロール タイプがドロップダウン ボックスの場合、生成されるフロントエンド VUE コードには余分なカンマが含まれます。
  • このコードは、数値入力ボックスには表示されない int 型フィールドのクエリ条件を生成します。
  • ネイティブ ERP、非ネイティブ ERP を問わず、メインテーブルが選択されていない場合は、サブテーブルが直接エクスポートされ、すべてのデータがエクスポートされます。
  • 1 対多の ERP は、行をクリックして選択するように変更することもできます。
  • タブスタイルの美化のペア
  • コード生成の新しいコントロールの年、月、週、四半期のデフォルト値のサポート
  • 1対多のサブテーブルポップアップ辞書は生成されません

オンライン モジュール アップグレード

  • オンライン許可によりバッチ有効化ボタンが追加されました
  • オンライン圃場メンテナンス、圃場を素早く見つける機能を追加
  • オンライン フィールド クエリ設定は、デフォルトのファジー クエリの設定をサポートします
  • 高度なクエリでは、空と空でないという 2 つの条件が追加されます。
  • オンラインデータ権限設定、システム変数式エラー修復
  • オンライン画像エクスポートがテキスト エクスポートに変更され、画像はエクスポートされなくなります。
