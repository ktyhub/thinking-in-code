#JecgBoot v3.7.3springboot3sas

何が変わったのか

  • Spring Boot3 および JDK 17 (@EightMonth 著、https://github.com/jeecgboot/JeecgBoot/pull/5563)
  • https://github.com/jeecgboot/JeecgBoot/pull/5566 の @EightMonth によって jeecg-boot-starter3 の依存関係を変更
  • https://github.com/jeecgboot/JeecgBoot/pull/5567 の @EightMonth による jeecg-boot-starter3 依存関係を更新
  • ビルディング ブロック レポートを更新、Minidao は https://github.com/jeecgboot/JeecgBoot/pull/5698 の @EightMonth による Springboot3 バージョンをサポート
  • https://github.com/jeecgboot/JeecgBoot/pull/5704 の @EightMonth による jeecg 3.6.1 バージョンのアップグレード
  • fastjson を 2.0.43 にアップグレードし、https://github.com/jeecgboot/JeecgBoot/pull/5716 の @EightMonth により Tomcat を undertow に置き換えます。
  • https://github.com/jeecgboot/JeecgBoot/pull/5730の@EightMonthにより自動生成されるインターフェースドキュメントのスコープを変更
  • springboot3 #5741 の問題を修正: hiro は spring boot 3.X に付属する jedis を使用できません。https://github.com/jeecgboot/JeecgBoot/pull/5767 の @hoperunChen によってバージョンをダウングレードします
  • springboot3 の問題を修正 #5742: https://github.com/jeecgboot/JeecgBoot/pull/5766 の @hoperunChen によるコード生成中にスキーマ アノテーション パラメーターを変更する
  • springboot3 #5723 の問題を修正: jaxb-runtime バージョンを指定し、https://github.com/jeecgboot/JeecgBoot/pull/5765 の @hoperunChen による変更レコードを追加
  • https://github.com/jeecgboot/JeecgBoot/pull/5761 の @EightMonth による Spring 認証サーバーのアップグレード
  • メイン ブランチのバージョン コードを同期し、https://github.com/jeecgboot/JeecgBoot/pull/5782 の @EightMonth によって jedis を 3.8.0 にアップグレードします。
  • 第三者ログインを開放し、https://github.com/jeecgboot/JeecgBoot/pull/5819 の @EightMonth によって hiro を削除します
  • https://github.com/jeecgboot/JeecgBoot/pull/5934 の @EightMonth によるデフォルト設定として springboot3 を修正
  • https://github.com/jeecgboot/JeecgBoot/pull/5935 の @EightMonth による spring boot3 のデフォルト設定を修正
  • トークン検証、クライアント便利ツールを追加、テナント情報のログイン不足を修正、強制ログアウト機能の失敗 (https://github.com/jeecgboot/JeecgBoot/pull/5965 の @EightMonth による)
  • 不十分な権限例外スタックを削除し、https://github.com/jeecgboot/JeecgBoot/pull/5995 の @EightMonth によるキャッシュへの権限読み込みを追加 *https://github.com/jeecgboot/JeecgBoot/pull/6014 の @EightMonth によるトークンの手動生成をサポート
  • https://github.com/jeecgboot/JeecgBoot/pull/6037 の @EightMonth による #5936 を修正
  • マスター変更をマージし、https://github.com/jeecgboot/JeecgBoot/pull/6036 の @EightMonth によって 3.6.3 をアップグレードします ※https://github.com/jeecgboot/JeecgBoot/pull/6081の@EightMonthによるdruid1.2.22バージョン互換処理をアップグレード
  • https://github.com/jeecgboot/JeecgBoot/pull/6092の@EightMonthによるアップグレードドルイドv1.2.22バージョン互換処理
  • https://github.com/jeecgboot/JeecgBoot/pull/6091の@EightMonthによるアップグレードドルイドv1.2.22バージョン互換処理
  • https://github.com/jeecgboot/JeecgBoot/pull/6173 の @EightMonth による #6127 #6130 を修正
  • https://github.com/jeecgboot/JeecgBoot/pull/6182 の @EightMonth によるオンライン同期データベースの修復
  • #6150を修正し、https://github.com/jeecgboot/JeecgBoot/pull/6194の@EightMonthでオンラインフォームをロードできない問題も修正
  • https://github.com/jeecgboot/JeecgBoot/pull/6200 の @EightMonth による #6169 を修正
  • https://github.com/jeecgboot/JeecgBoot/pull/6199 の @EightMonth による #6168#6169\websocket 接続の問題を修正
  • https://github.com/jeecgboot/JeecgBoot/pull/6201 に @EightMonth によるバグ修正コメントを追加
  • https://github.com/jeecgboot/JeecgBoot/pull/6243の@EightMonthによるSAS互換のシロ処理
  • SAS は、https://github.com/jeecgboot/JeecgBoot/pull/6646 の @EightMonth によるログイン不要のアノテーションを実装します
  • https://github.com/jeecgboot/JeecgBoot/pull/6660 の @EightMonth による redis のデシリアライゼーション時間の問題を修正
  • https://github.com/jeecgboot/JeecgBoot/pull/6878 の @EightMonth によってダッシュボードにアクセスするときの 401 問題を修正
  • https://github.com/jeecgboot/JeecgBoot/pull/6879 の @EightMonth によるダッシュボード 401 へのアクセスを修正
  • トークンの長さを短縮し、https://github.com/jeecgboot/JeecgBoot/pull/6899 の @EightMonth によるメイン ブランチのフロントエンド ページのログインに適応します。
  • https://github.com/jeecgboot/JeecgBoot/pull/7317 の @EightMonth により、docker イメージ ベースを JDK17 に変更します
  • https://github.com/jeecgboot/JeecgBoot/pull/7327の@EightMonthによるredisのシリアル化認証情報の問題を修正
  • https://github.com/jeecgboot/JeecgBoot/pull/7329 の @EightMonth による「redis シリアル化認証情報の問題を修正」を元に戻す
  • https://github.com/jeecgboot/JeecgBoot/pull/7332の@EightMonthによるredisのシリアル化認証情報の問題を修正
  • https://github.com/jeecgboot/JeecgBoot/pull/7379 の @EightMonth による分散トランザクションのデモ修復
  • 分散トランザクションのデモ修復 (https://github.com/jeecgboot/JeecgBoot/pull/7378 の @EightMonth による)
  • https://github.com/jeecgboot/JeecgBoot/pull/7797 の @EightMonth によって vue-router のバージョン番号が修正されました
  • https://github.com/jeecgboot/JeecgBoot/pull/7796 の @EightMonth によって vue-router のバージョン番号が修正されました
  • キー交換スキャンの問題は、https://github.com/jeecgboot/JeecgBoot/pull/7564 の @EightMonth によって修正されました #6918 #6876
  • https://github.com/jeecgboot/JeecgBoot/pull/7875 の @EightMonth による #7613 を修正
  • 重大なバグを解決し、War パッケージにデプロイし、https://github.com/jeecgboot/JeecgBoot/pull/7950 の @EightMonth によってサービス開始時のエラーを報告します *jeewx-api は https://github.com/jeecgboot/JeecgBoot/pull/8005 の @EightMonth によって weixin4j に変更されました
  • https://github.com/jeecgboot/JeecgBoot/pull/8007 の @EightMonth による CVE-2023-6378 を修正
