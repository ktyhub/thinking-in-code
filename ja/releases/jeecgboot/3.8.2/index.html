JeecgBoot v3.8.2

#JecgBoot v3.8.2

アップグレードログ

このアップグレードは、オンライン機能の強化に重点を置き、AI インテリジェント テーブル作成、AI テスト データ、AI レポート自動生成機能を追加し、データ処理効率を大幅に向上させます。同時に、コード ジェネレーターは包括的に強化され、カスタム ボタンと JS 拡張コード生成をサポートします。さらに、APPのバージョン管理、許可ホームページのカスタマイズ、新しい通知およびアナウンスシステムなどの実用的な機能が追加されました。このアップグレードにはデータベース構造の調整が含まれることに注意してください。アップグレードをスムーズに行うために、必ずデータをバックアップし、事前にテストして検証してください。

問題を修正
  • [アーキテクチャのアップグレード] mybatis-plus を 3.5.12 にアップグレードし、jsqlparser を 4.9 にアップグレードします。
  • [アーキテクチャのアップグレード] jimureport を v2.1.1 にアップグレードします。
  • [アーキテクチャのアップグレード] jimubi を v2.1.0 にアップグレードします
  • [アーキテクチャのアップグレード] オンラインで 3.8.2-GA にアップグレードします
  • [アーキテクチャのアップグレード] mybatisPlus をアップグレードした後、SQL サーバーのページングで OFFSET に切り替わる問題を修正しました。 ROWS FETCH NEXT により、オンライン レポートで並べ替えられていないエラーが報告される
  • [新機能] oracle、SqlServer、PostgreSQL に対応する yml 設定およびデータベース初期化スクリプトをデフォルトで提供
  • [フルアップグレード] トランク springboot2、ブランチ springboot3、springboot3sas の同期アップグレード
  • [新機能] 設定を変更する必要はなく、ワンクリックで docker 単一起動スクリプト start-docker-compose.bat を提供します。
  • [新機能] 構成を変更する必要はなく、ワンクリックで docker マイクロサービス起動スクリプト start-docker-compose-cloud.bat を提供します。
  • [重大なバグ] xxljob と jeecg-boot-starter の xxl-job のバージョンが一致せず、スケジュールされたタスクが実行されてもタスクが終了しません。
  • [重大なバグ] Swagger で選択されたインターフェイスが実際のインターフェイス #8665 に対応していません
  • [新機能] 通知とアナウンスが全面的に見直して最適化され、アナウンスの詳細スタイルが最適化され、印刷がサポートされています。
  • [新機能] tinymce リッチ テキスト エディターのスタイルの最適化
  • [新機能] バックグラウンドプッシュメッセージを受け入れるようにデスクトップアプリケーションを最適化します。
  • [新機能] オンラインレポートは権限制御をサポートします
  • [新機能] オンライン レポートはテナントの分離をサポートします
  • [新機能] APPバージョン管理機能、アプリの自動パッチアップグレードをサポート
  • [新機能] 独立したポータル設定メニュー、役割とユーザーの 2 つの側面からカスタマイズされたホームページをサポート
  • [新機能] オンラインレポートはAI生成レポートをサポート
  • [新機能] オンライン機能テストはモックデータをサポートします
  • [新機能] オンラインフォームがAIフォーム作成をサポート
  • [新機能] オンラインフォームビューで削除をサポート
  • [新機能] オンラインで生成されたメニューSQLにより、コンポーネント名が自動的に取得されます。
  • [オンラインフォーム] 高度なクエリ、複数選択クエリをサポート
  • [オンライン強化] ページ読み込みコールをサポート
  • docker-compose は jeecg-boot-pgvector を追加します
  • dockerシステムログの中国語文字化け問題を修正
  • データベースに openapi マイクロサービス ゲートウェイ構成がありません
  • XXL-JOB (2.4.0 以降) が削除され、シャーディング パラメーターの取得方法が変更されました。
  • [スワガー ドキュメント] application/json は application/x-www-form-urlencoded になります
  • democloud サービスの開始時に循環依存関係エラーが発生する #8573
  • [issues/8548] コードによって生成された高度なクエリの日付/月コントロールが正常に表示されません。
  • [issues/8163] 新しく追加された関連レコードが失われる
  • [issues/8575] ERP はデフォルトで最初のテーブルを選択し、メイン テーブルが選択されていない場合、サブテーブルはクエリされません。
  • [issues/8168] ID でソートされたデータが重複しています。
  • [issues/888] オンライン ツリー テーブルのサブノード検索が有効にならず、警告が表示されます。
  • redis キャッシュ拡張機能ユーザーはキャッシュをカスタマイズできます
  • redis リスナー ハンドル リマインダー ログをカスタマイズし、プロンプトを 1 回のみに変更します
  • [issues/8265] デフォルトのモデルはタイムアウト設定をサポートしています
  • jeecg-boot-vue3 フロントエンド ビルド エラーの解決策 · 問題 #8497
  • フォームフォーム、ラベルをクリックするとフォームクエリ条件の入力ボックスにフォーカスされます · 問題 #8484
