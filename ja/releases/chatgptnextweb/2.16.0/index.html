#ChatGPTNextWeb v2.16.0

何が変わったのか

  • chore(deps-dev): https://github.com/ChatGPTNextWeb/NextChat/pull/5807 の @dependabot によって @testing-library/jest-dom を 6.6.2 から 6.6.3 にバンプします
  • 修正: 現在のセッション ID を使用して、https://github.com/ChatGPTNextWeb/NextChat/pull/5812 の @Dogtiti による再レンダリングをトリガーする
  • https://github.com/ChatGPTNextWeb/NextChat/pull/5815 の @LovelyGuYiMeng によるキーワードに一致するビジュアル モデルを更新
  • アーティファクトは、https://github.com/ChatGPTNextWeb/NextChat/pull/5816 の @OPChips による SVG をサポートします
  • https://github.com/ChatGPTNextWeb/NextChat/pull/5819 の @DDMeaqua によるジェミニの概要を修正
  • 修正: https://github.com/ChatGPTNextWeb/NextChat/pull/5827 の @OPChips によってコード ブロックが小さなコード ブロックに埋め込まれている場合のレンダリング エラー
  • 功績: https://github.com/ChatGPTNextWeb/NextChat/pull/5821 の @Sherlocksuper による、よりユーザーフレンドリーなスクロールをサポート
  • https://github.com/ChatGPTNextWeb/NextChat/pull/5861 の @code-october によって gpt-4o と gemini-exp の新しいモデルを更新します
  • https://github.com/ChatGPTNextWeb/NextChat/pull/5850 の @code-october による o1 を修正
  • 🎨 スタイル(設定): カスタムモデルの入力を別の行に配置します。 @frostime 著、https://github.com/ChatGPTNextWeb/NextChat/pull/5879
  • マスクの「テキストを含む画像の検索」が「AI テキストベースの画像」に変更され、微調整されたプロンプトにより画像生成がより安定し、透かしがなくなりました (https://github.com/ChatGPTNextWeb/NextChat/pull/5936 の @InitialXKO による)
  • chore(deps-dev): https://github.com/ChatGPTNextWeb/NextChat/pull/5940 の @dependabot により、@testing-library/react を 16.0.1 から 16.1.0 にバンプします
  • Google モデルを更新して、https://github.com/ChatGPTNextWeb/NextChat/pull/5932 の @fengzai6 による gemini-2.0 を追加します
  • https://github.com/ChatGPTNextWeb/NextChat/pull/5959 の @dupl により gemini-exp-1206、gemini-2.0-flash-thinking-exp-1219 を追加
  • 功績: https://github.com/ChatGPTNextWeb/NextChat/pull/5919 の @Yiming3 によるビジョン対応モデルのランタイム構成
  • https://github.com/ChatGPTNextWeb/NextChat/pull/5976 の @Leizhenpeng による README.md を更新
  • https://github.com/ChatGPTNextWeb/NextChat/pull/5883 の @code-october によるモデル リークの問題を修正
  • 修正: https://github.com/ChatGPTNextWeb/NextChat/pull/5994 での @Dogtiti による単体テストの失敗
  • https://github.com/ChatGPTNextWeb/NextChat/pull/5996 の @Dogtiti による機能/cogview
  • 修正: https://github.com/ChatGPTNextWeb/NextChat/pull/5993 の @xixici によるプラグイン ストア アドレスの URL を修正
  • 問題 #5964 を修正: https://github.com/ChatGPTNextWeb/NextChat/pull/5965 の @zmhuanf による gemini-2.0-flash-thinking-exp-1219 応答での文字損失を防止します
  • https://github.com/ChatGPTNextWeb/NextChat/pull/5920 の @fishshi による DISCOVERY には i18n を使用します
  • 機能: https://github.com/ChatGPTNextWeb/NextChat/pull/5997 の @Dogtiti による glm-4v のサポート
  • コードをより簡潔にするために正規表現を使用します。 @dupl 著、https://github.com/ChatGPTNextWeb/NextChat/pull/5998
  • #5984 以降、DeepSeek を新しい ModelProvider (ディープシークチャットとディープシークコーダーモデルを含む) として追加し、ユーザーが異なる api URL とキーで openai とディープシークを同時に使用できるようにします (https://github.com/ChatGPTNextWeb/NextChat/pull/5989 の @bestsanmao による)
  • ドキュメント: https://github.com/ChatGPTNextWeb/NextChat/pull/6001 の @bestsanmao による README に DEEPSEEK_API_KEY と DEEPSEEK_URL を追加
  • 問題 #6009 を修正し、https://github.com/ChatGPTNextWeb/NextChat/pull/6016 の @bestsanmao によるディープシークの設定項目を追加
  • dockerの実行フェーズ中にVISION_MDOELSが有効にならない問題をhttps://github.com/ChatGPTNextWeb/NextChat/pull/6010の@code-octoberで修正
  • 功績: #5422 コンテキストをクリアするショートカット キー (@DDMeaqua 著、https://github.com/ChatGPTNextWeb/NextChat/pull/5468)
  • https://github.com/ChatGPTNextWeb/NextChat/pull/6034 の @dupl による user-manual-cn.md のタイプミスを修正
  • 修正: https://github.com/ChatGPTNextWeb/NextChat/pull/6033 で @lvguanjun によって一意の ID を生成することで、フォークされたセッション間のメッセージ同期を防止
  • https://github.com/ChatGPTNextWeb/NextChat/pull/5974 の @Leizhenpeng による MCP(WIP) をサポート
  • 修正: https://github.com/ChatGPTNextWeb/NextChat/pull/6075 で @Kadxy による欠落している useMobileScreen フックのインポートを追加
  • https://github.com/ChatGPTNextWeb/NextChat/pull/6082 の @Leizhenpeng による README_CN.md の更新
  • 修正: https://github.com/ChatGPTNextWeb/NextChat/pull/6084 で @Kadxy によるビルドに必要な mcp_config.json ファイルが欠落していました
  • バグ修正 (mcpPrompt について) と @bestsanmao による deepseek-reasoner の追加 (https://github.com/ChatGPTNextWeb/NextChat/pull/6087)
  • https://github.com/ChatGPTNextWeb/NextChat/pull/6116 の @Kadxy による DeepSeek API ストリーミング推論コンテンツをサポート
  • 修正: https://github.com/ChatGPTNextWeb/NextChat/pull/6118 の @Kadxy による意図しない変更を元に戻す
  • https://github.com/ChatGPTNextWeb/NextChat/pull/6119 の @Leizhenpeng による README.md を更新
  • feat(モデル): https://github.com/ChatGPTNextWeb/NextChat/pull/6121 の @Kadxy による OpenAI o3-mini モデルのサポートを追加
  • https://github.com/ChatGPTNextWeb/NextChat/pull/6127 の @dupl により gemini-2.0-flash-thinking-exp、gemini-2.0-flash-thinking-exp-01-21 を追加
  • 修正: https://github.com/ChatGPTNextWeb/NextChat/pull/6134 の @zcong1993 によるバイトダンス モデルの isModelNotavailableInServer ロジックを修正
  • https://github.com/ChatGPTNextWeb/NextChat/pull/6132 の @RetiredQQ による o3-mini の一時的な修正 *雑用: @MonadMonAmi による o1 と o3 の知識の締め切り日を https://github.com/ChatGPTNextWeb/NextChat/pull/6129 に追加
  • 新しいプロバイダー SiliconFlow とその最新の DeekSeek モデル @jackalcooper (https://github.com/ChatGPTNextWeb/NextChat/pull/6141)
  • 功績: https://github.com/ChatGPTNextWeb/NextChat/pull/6144 の @Eric-2369 による llm アイコンをさらに追加
  • 修正: env のシリコンベース フローの環境変数を補足します。 https://github.com/ChatGPTNextWeb/NextChat/pull/6168 の @xiexin12138 によるシリコンベースのフローでサポートされる 2 つの有料モデルを追加
  • https://github.com/ChatGPTNextWeb/NextChat/pull/6158 の @dupl によって最新の Gemini モデルを更新します
  • 修正: ダーク モードでの色の反転を防ぐために OpenAI/MoonShot/Grok SVG に一貫した塗りつぶし色を設定 (https://github.com/ChatGPTNextWeb/NextChat/pull/6164 の @ZhangYichi-ZYc による)
  • https://github.com/ChatGPTNextWeb/NextChat/pull/6185 の @jackalcooper による SiliconFlow のタイムアウトの拡大

  • https://github.com/ChatGPTNextWeb/NextChat/pull/6172 の @bestsanmao によるいくつかのバグを修正
  • https://github.com/ChatGPTNextWeb/NextChat/pull/6188 の @Leizhenpeng によるライセンスの更新
  • https://github.com/ChatGPTNextWeb/NextChat/pull/6194 の @jackalcooper による SiliconFlow での VLM のサポート
  • エクスポート メッセージ プレビューのアバターと、https://github.com/ChatGPTNextWeb/NextChat/pull/6189 で @bestsanmao によって保存された画像を修正しました
  • @jackalcooper による SiliconFlow のモデル一覧 (https://github.com/ChatGPTNextWeb/NextChat/pull/6193)
  • https://github.com/ChatGPTNextWeb/NextChat/pull/6190 の @jackalcooper による SiliconFlow のモデル アイコンを修正
