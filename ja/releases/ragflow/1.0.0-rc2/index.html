#ラグフローv1.0.0-rc2

1.0.0-rc2 は、v1.0.0 の 2 番目のリリース候補です。このリリースでは、rc1 のいくつかの問題が修正され、新機能と拡張サポートが導入されています。

ハイライト

  1. チャットにエージェントティック モードを導入し、低、中、高、超の思考レベルを置き換えました。
  2. 既存の v1.0.0-rc1 データとの互換性が維持され、直接アップグレードが可能。
  3. チーム/ミー共有のサポートを追加しました。
  4. モデル プロバイダーの DemonRoute および Opper、Web 検索ツール Firecrawl および Search1API、および MinerU 4 モデルのサポートを追加しました。
  5. チェコ語とスロバキア語の検索サポートを追加しました。
  6. 12 個の組み込みドキュメント パーサーをパイプライン パーサーと統合しました。
  7. arm64 アーキテクチャ用の Docker イメージを追加しました。
