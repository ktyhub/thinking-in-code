#ラグフローv0.25.2

概要

改善点

  • API のリファクタリングと統合: Web API の RESTful 規約への移行を継続し、すべてのレガシー エンドポイントに対する下位互換性を確保します。

データソース

  • Moodle、DingTalk AI Table、RSS を含む 8 つのデータ ソース間で削除されたファイルを同期するための軽量スナップショット メカニズムを導入し、すべてのリモート データ ソースを忠実に反映します。 #14362#14499

バグ修正

  • v0.24.0 から v0.25.0 へのアップグレード中のメタデータの可視性の問題。
  • チャット出力が重複します。
  • メタデータのフィルタリングは、Elasticsearch を利用するのではなくメモリ内で処理されるため、パフォーマンスのボトルネックが発生しました。 #14576
