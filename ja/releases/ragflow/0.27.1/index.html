#ラグフローv0.27.1

新機能

  • データ ソース用の新しい Azure DevOps コネクタ (#18715)
  • チャットおよびエージェント用の新しい You.com Web 検索プロバイダー (#18478)
  • チャット用の新しい Serply Web 検索プロバイダー (#18475)

モデルのサポート

  • 新しい Synthorai モデルプロバイダー (#18830)
  • 欠落していた DeepSeek モデルを追加 (#18678)
  • AWS Bedrock API キー認証のサポート (#18301)

改善点

  • API の取得により、rerank_candidates_count、knn top_k、および num_candidates が公開されます (#18768、#18737)
  • メタデータ フィルターがメタデータ インデックスにプッシュダウンされ、取得が高速化されました (#18219)
  • チャット設定フォームは、保存時にエラーの場所まで自動スクロールします (#18811)
  • 検索ページは削除されたナレッジ ベースを検証します (#18522)

バグ修正

  • チャットでの PDF 解析エラーを修正 (#18860)
  • LLM エラー応答を受け入れる Wiki コンパイルを修正しました (#18857)
  • MinerU のレンダリングの安定性、エラーの可視性、コード ブロックの解析を修正しました (#18617)
  • 0 チャンクのデータセットが表示されず、スクロールしてさらにデータセットを取得できない問題を修正しました (#18810)
  • QA Excel パーサーが答えがゼロの行を削除する問題を修正しました (#17902)
  • 空のアップロードを欠落バイナリとして扱う単純なパーサーを修正しました (#18826)
  • 確実な検出結果を破棄するエンコード検出を修正しました (#15793)
  • ダイアログ システム プロンプトを無視する推論対応チャットを修正しました (#18842)
  • パイプライン LLM の代わりにデフォルトのテナント LLM を使用するナレッジ コンパイルを修正しました (#18572)
  • チャット ネットワーク検索サービスを null にすることができない問題を修正しました (#18791)
  • Firefox チャットの自動スクロールが一番下に固定されない問題を修正 (#18736)
  • ストリーミングされた回答に従わないチャットの自動スクロールを修正しました (#18570)
  • アップロードを選択した後に解析の進行状況が表示されない問題を修正 (#18741)
  • SQL クエリを誤って構築する BigQuery コネクタを修正しました (#17500)
  • WebDAV リスト エラーが伝播されず、プルーン データ損失が発生する問題を修正しました (#18694)
  • データ ソース同期におけるクロス KB ドキュメント ID の衝突を修正しました (#18244)
  • GPUStack モデルの検出とオーディオのサポートを修正 (#18599)
  • キミ K3 の温度を修正 (#18564)
  • image2text モデルが設定されていない場合に失われる OCR テキストを修正しました (#18012)
  • 階層型 Wiki トピック ナビゲーションを修正しました (#18721)
