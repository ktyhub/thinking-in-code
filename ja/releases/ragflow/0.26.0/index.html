#ラグフローv0.26.0

概要

新機能

  • モデルプロバイダー
    • 複数のプロバイダーに対して自動入力されるモデル リストを実装し、モデル名を手動で入力する必要を排除します。この機能は現在、Ollama、OpenRouter、vLLM、OpenAI-API-Compatibility、LM-Studio、VolcEngine、Xinference、LocalAI、BaiduYiyan、GPUStack、および Fish Audio をサポートしています。
    • 同じモデルプロバイダーに対して複数の API キーを構成できます。 #14595
    • 現在利用可能なモデルをリモート モデル プロバイダーから直接取得することにより、UI のモデル選択ドロップダウンに動的に入力します。 #15711
  • データ ソース コネクタ: Outlook、OneDrive、Microsoft Teams、Slack、SharePoint、Salesforce、および Azure Blob Storage 用の新しいデータ ソース コネクタを実装します。 #15333#15330#15332#15188#15190#15462#15466
  • データセット - GraphRAG インデックス作成パイプラインの最も高価で時間のかかる部分である、コミュニティ抽出とエンティティ解決のためのチェックポイントと再開機能を実装します。 #15518#15523

改善点

  • <think> テキスト バッファリングを削除し、推論可能なモデルが対話中により速く、より透明に感じられるようにします。 #15891
  • MySQL 移行を適用済みとしてマークします。 #15504

モデルのサポート

  • 4 つの新しい SiliconFlow モデル #15383 ●MiniMax-M3モデル #15513
  • 最新の人外モデル #15516 ●Voyage 4 モデルファミリー #15516
  • Cohereモデルリスト。 #15576

i18n

  • 韓国語の翻訳を完了します。 #15863
  • イタリア語の翻訳を完了します。 #15729

バグ修正

  • MiniMax モデルの思考モードが正しく有効になっていませんでした。 #15496
  • Qwen3.5 および Qwen3.6 モデルで思考モードが有効になっていると、無限ループが発生しました。 #15101
  • OpenAI 互換のチャット補完 API エンドポイントを使用すると、ストリーミングされた回答が複製されていました。 #15286#15443
  • NaN (非数値) や Inf (無限大) などの無効な数値スコアが JSON エンコーダーに渡された場合、チャットの完了中にシリアル化エラーが発生しました。 #15245#15266
  • 認識されない内部構成パラメーターが外部 API に到達する前にフィルターで除外されなかったため、LiteLLM プロバイダーを使用したチャットの完了が失敗していました。 #15427#15432
  • OpenAI 互換のチャット完了 API は、デフォルトでストリーミング応答になっていました。 #15356#15394
  • メタデータのフィルタリング中に、空の AND 結果が誤って削除されました。 #15477
  • ヘッダーやフッターなどの反復的なページ クロムが、MinerU パーサーによってメイン テキストとして誤って抽出されました。 #15335#15387
  • DeepDoc モジュールでのドキュメント抽出中に英語のグラフ タイトルが欠落していました。 #15481
  • json および chunks アップストリーム フォーマットの TitleChunker によって空の出力が返されました #14247#15396
  • .tsv ファイルのアップロード試行が失敗した場合、エラー メッセージが表示されませんでした。 #15284
  • API トークンにベータ値が欠落していると、トークン取得エラーが発生しました。 #15405
  • 大規模なクエリによるシステムのクラッシュや速度低下を修正するために、最大ページ サイズを制限します。 #15292
  • Client エラーは、OpenAI 互換のチャット完了 API が誤ってデフォルトでストリーミング応答を設定することが原因で発生しました。 #15356#15394
  • ユーザーがストレージ バックエンドから不足しているファイルをダウンロードしようとすると、標準の 4xx client エラーではなく、HTTP 500 内部サーバー エラーがトリガーされました。 #15369#15371
  • GraphRAG エンティティのランキングが壊れていました。 #15795#15797
