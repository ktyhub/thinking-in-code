#ラグフローv1.0.0-rc1

RAGFlow v1.0.0-rc1 は v1.0.0 のプレビュー リリースです。このリリースは、Go での RAGFlow の包括的な書き直しをマークし、システム リソースの消費量を大幅に削減し、以前の重量のあるデプロイメント モデルを軽量のアーキテクチャに置き換えます。

アーキテクチャの変更

  • メッセージ キュー: Redis から NATS に移行されました。
  • キャッシュとチェックポイント: Kvrocks は、キャッシュとチェックポイントの両方のバッキング ストアとして機能するようになりました。

データのアップグレード

コンテナーの起動時に、RAGFlow はデータ アップグレード プロセスを自動的に開始し、既存のデータを v0.27.2 から v1.0.0-rc1 に移行します。このアップグレードは元に戻すことができないことに注意してください。完了すると、データを v0.27.2 にロールバックすることはできません。

アップグレードの前提条件と注意事項

  1. アップグレードする前に、すべてのデータをバックアップします。
  2. 続行する前に、既存の展開がすでに v0.27.2 上にあることを確認してください。
  3. アップグレードが失敗した場合は、バックアップからシステムを復元し、失敗の詳細を説明する問題を送信してください。

互換性

  1. RAGFlow CLI: Go で再実装され、以前の Python バージョンが置き換えられました。
  2. API の互換性: 非推奨の API は、Go 実装ではサポートされなくなりました。
  3. SDK の互換性: Python SDK は影響を受けません。

既知の問題

  1. DeepDoc は現在 CPU 環境のみをサポートしています。
  2. ローカル サンドボックスはサポートされなくなりました。
  3. Team/Me 権限モデルはまだサポートされていません。
