#ラグフローv0.25.1

概要

改善点

  • API のリファクタリングと統合: Web API をすべてのエンドポイントにわたって RESTful 規約に標準化し、下位互換性を維持しながらドキュメント作成とインデックス付けのフローを統合します。
  • 解析の最適化: OpenDataLoader PDF バックエンドを追加します。 #14097
  • 大きな PDF (>50 ページ) の遅延読み込みとチャンク解析を導入し、メモリ フットプリントを大幅に削減します。 #14385

データソース

Bitbucket、Gmail、Google Drive、Airtable で削除されたファイルの同期を有効にします。

モデルのサポート

  • ディープシーク v4

モデルプロバイダー

  • ユークラウド

バグ修正

  • v0.24.0 から v0.25.0 へのアップグレード中のメタデータの可視性の問題。
  • チャット出力が重複します。
