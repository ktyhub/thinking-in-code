#ラグフローv0.26.3

概要

2026 年 7 月 2 日に発売されました。

新機能

  • データ ソース コネクタ: ドキュメントの取り込みと増分同期のためのデータ ソース コネクタとして Google BigQuery を導入します。 #15871
  • MCP: 2 つの MCP ツール ragflow_list_datasets および ragflow_list_chats を RAGFlow MCP サーバーに追加します。 #15384
  • ファイルの取り込み
    • レイアウトを認識する SoMark OCR パーサーをシステムに統合し、表や図などの複雑な文書要素を抽出してインデックス付けします。 #16482
    • API: カスタマイズされたパイプラインを使用してドキュメントを処理するための ドキュメントの取り込み エンドポイントを公開します。 #16395

改善点

  • バックエンド: バッチ ドキュメント アップロードの部分的な成功処理を導入し、単一の失敗したファイルによってバッチ全体が破棄されることがなくなりました。 #16438
  • UI/UX: グローバル ヘッダーをリファクタリングして、利用可能な画面スペースに基づいて完全なデスクトップ ナビゲーション バーとモバイル フレンドリーなサイド ドロワーを動的に切り替え、重複する問題を解決し、モバイル ユーザー エクスペリエンスを大幅に向上させます。 #15984

バグ修正

  • Ollama プロバイダーをセットアップした後、システムは「この api キーを使用してモデル (名前) にアクセスできませんでした」というエラーを返しました。 #16519
  • ユーザー/アシスタントのチャット メッセージのペアを削除すると、インデックスの不整合により、前の会話ターンの参照が誤って削除されました。 #16436
