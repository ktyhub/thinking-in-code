#ラグフローv0.25.3

まとめ

新機能

  • データ ソースと解析: スプレッドシート ファイル パーサーに列レベルのセマンティック/メタデータ制御を追加しました。不必要なファイル転送を回避するために、S3 データ ソースの増分同期のための ETag 最適化が導入されました。
  • コンテンツ、メタデータ、主キーなどの特定の役割をテーブル列に割り当てることができます。 #13710

改善点

  • API リファクタリングとセキュリティ
    • Web API の RESTful 規約への移行を継続し、すべてのレガシー エンドポイントに対する下位互換性を確保します。
    • POST /api/v1/messages の user_id を認証された JWT プリンシパルにバインドします。 #14745
    • 動的および間接的なコード実行バイパスからサンドボックス エグゼキュータを保護します。 #14690
    • LLMリクエストのタイムアウト制御
    • 同時実行性の高いブロッキング呼び出しスレッド プール
  • インジェストサーバーの起動時間を短縮します。 #14894

バグ修正

  • マルチシート Excel ワークブック内の画像の範囲がシートごとに設定されていないため、異なるワークシート間で画像が誤って属性付けされることがありました。 #14120
  • 反復項目のエイリアス渡し
  • ツールパラメータテンプレートの解析
  • コード実行添付出力
  • 火山モデルの追加修正
