#ラグフローv0.26.1

概要

新機能

  • モデル プロバイダー: ユーザーが既存のモデル構成のモデル タイプを変更できるようにします。 #16029
  • チャット チャネル: ユーザーは、Discord や Feishu などの外部メッセージング プラットフォーム内にチャットボットとして RAGFlow アシスタントを展開できます。 #15850
  • 可観測性: Langfuse 内のセッションごとにマルチターン チャット トレースをグループ化し、会話のデバッグと再生を容易にします。 #15679

i18n

  • フランス語 UI に欠落していた最大 70 個の翻訳キーを追加します。 #15983

バグ修正

  • モデル プロバイダー: 不正確なトークンの請求を修正し、インデックス作成の失敗を防ぐために埋め込みの切り捨て制限を修正し、根本的なエラーの原因を明らかにするためにエラー処理をリファクタリングします。 #15424
  • API: /chat/completions エンドポイントにレガシー モードを追加して、下位互換性のために v0.23.0 スタイルの <think> 出力を復元します。 #16014 チャット アシスタントと会話する も参照してください。
