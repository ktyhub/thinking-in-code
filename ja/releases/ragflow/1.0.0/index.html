#ラグフローv1.0.0

3 つのリリース候補を経て、現在生産準備が整っている RAGFlow 1.0 の正式リリースを発表できることを嬉しく思います。 Go で完全に書き直されて構築されたこのリリースでは、展開と実行時のオーバーヘッドが大幅に削減され、まったく新しいエージェント チャット エクスペリエンスが導入されています。安定性、パフォーマンス、質問応答を向上させるために、すべてのユーザーにアップグレードすることをお勧めします。

ハイライト

  • より軽量な展開のために Go で書き直されました: Docker イメージは約 10 倍小さくなり、起動は約 10 倍速くなりました。
  • 同時実行性が約 100 倍向上し、クエリの遅延、メモリ使用量、ドキュメントの解析速度が大幅に向上しました。
  • まったく新しいエージェント チャット: 反復的な検索、ツール呼び出し、証拠十分性評価を通じて、複数ステップの推論と複雑な質問への回答を可能にします。

チャットとエージェント

  • 以前の低、中、高、超の思考レベルを置き換えるエージェント チャット モードが追加されました。
  • 入手可能な証拠が質問に答えるのに十分であるかどうかを判断するために、エージェント ツール呼び出しループに Jev 意思決定モデルを導入しました。
  • Categorize エージェント コンポーネントに Jev 意思決定モデルのサポートが追加されました。
  • チャット履歴にプロンプ​​ト、トークン使用量、実行時間の保存と表示が追加されました。

ドキュメントの取り込みと取得

  • 12 個の組み込みドキュメント パーサーをパイプライン パーサーと統合しました。
  • 複数の取り込みパイプライン DSL バージョンのサポートが追加されました。

アーキテクチャと展開

  • メッセージ キューを Redis から NATS に移行しました。
  • キャッシュとチェックポイントのストレージに Kvrocks を採用。
  • arm64 アーキテクチャ用の Docker イメージを追加しました。
  • Go で RAGFlow CLI を再実装しました。

安定性

  • コミュニティによって報告された複数の重大なバグと、リリース候補段階で特定された問題を修正し、ランタイムの安定性をさらに向上させました。

ベンチマーク

  • MiniMax M3 で RAGFlow Agentic Chat を使用した FRAMES マルチホップ質問応答ベンチマークで 91% の精度を達成しました。

アップグレード

  • v1.0.0-rc1、rc2、または rc3 以降: 既存のデータは完全に互換性があります。直接アップグレードできます。
  • v0.27.2 から: v1.0.0 に直接アップグレードできます。データ移行は、RAGFlow Docker コンテナーの起動時に自動的に実行されます。
  • v0.27.2 より前のバージョンから: v1.0.0 にアップグレードする前に、移行ガイドに従って必要な中間アップグレードを完了してください。
  • アップグレードする前にすべてのデータをバックアップしてください。 v0.27.2 から v1.0.0 へのデータ移行は元に戻すことはできません。移行が失敗した場合は、再試行する前にアップグレード前の完全なバックアップを復元してください。

互換性と制限事項

  • 非推奨の API エイリアスはサポートされなくなりました。
  • Python SDK は影響を受けません。
  • DeepDoc は現在 CPU 環境のみをサポートしています。
