#ラグフローv1.0.0-rc3

1.0.0-rc3 は、正式な v1.0.0 リリース前の 3 番目で最後のリリース候補です。 rc2 で見つかったいくつかの問題が修正され、新しい機能と拡張機能が導入されています。

主要な更新:

  1. エージェントツールループ内に証拠十分性を判断するための意思決定モデルと、エージェント向けの分類コンポーネントを導入しました。
  2. 複数のバージョンの取り込みパイプライン DSL のサポートを追加しました。
  3. チャット履歴にプロンプ​​ト、トークン使用量、および実行時間が保存および表示されるようになりました。
  4. 既存の v1.0.0-rc2 スキーマと互換性があるため、直接アップグレードできます。
