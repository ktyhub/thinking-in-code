#ラグフローv0.26.4

概要

2026年7月7日発売。

新機能

  • NLP/トークン化: 16 言語をサポートする言語対応の Snowball ステマーを追加し、トークン化パイプライン全体でデータセット language パラメーターを統合し、フロントエンドにオランダ語を追加します。 #14140

バグ修正

  • 「@」記号を含む LM-Studio モデル名を解析すると、システムが ValueError でクラッシュしました。 #16467
  • list_chats 関数が /chats API からのリストを予期していましたが、代わりにページ分割された辞書を受け取ったため、MCP サーバーがクラッシュしました。 #16639
  • Docling パーサーは、文書から数式を抽出するのではなく、黙って削除しました。 #16645
  • システムは、メタデータ値に対して行われたインライン編集をバックエンドに保持できませんでした。 #16655
  • ファイルをデータセットに一括リンクするときに、システムは既存のリンクを削除しました。 #16587
  • フィルターで中国語を使用できませんでした。 #16673
  • システムは、タグの重みがゼロより大きくなければならないことを強制できませんでした。 #16657
  • エージェント プロンプト ドロップダウン メニューのレイアウトが正しく表示されませんでした。 #16653
  • Laws チャンカーは、ドット付き数字の相互参照を見出しとして誤って分類しました。 #16626
  • システムは、編集プロセス中にユーザーが重複する MCP サーバー名を保存できないようにすることができませんでした。 #16588
  • このシステムでは、ユーザーは空の MCP サーバー選択をエクスポートできました。 #16589
