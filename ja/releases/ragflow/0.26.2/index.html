#ラグフローv0.26.2

概要

2026 年 6 月 29 日発売。

新機能

  • チャットチャンネル:
    • QR コード スキャンを介して WhatsApp を統合します。 #16238
    • ボット API 認証情報を介して DingTalk を統合します。 #16183
    • WebSocket 接続を介して WeCom を統合します。 #16175
  • ファイル解析: PP-OCRv6 および同様のテキスト認識モデルのフォールバック ロジックを追加し、PaddleOCR パイプライン内に画像解析を統合します。 #16150

改善点

  • データセット
    • ファイル取り込みロジックにエッジケース チェックを追加して、空のフォルダーをデータセットに安全にリンクします。 #16296
    • get_flatted_meta_by_kbs() メソッドにページネーションを追加して、10,000 を超えるドキュメントを含むデータセットに関連する CRUD エラーを防ぎます。 #16095
  • チャット チャネル: エンドユーザーの会話履歴は再起動後も保持されますが、チャネルが新しいダイアログにバインドされると分離されたままになります。 #16274

i18n

  • i18n の対象範囲を拡大し、韓国語 UI の翻訳を改良しました。 #16203；
  • チャット チャネル、ユーザー名の検証、モデル編集に不足しているフランス語翻訳を追加します。 #16217

バグ修正

  • ファイル解析:
    • 「見出し」スタイルの .docx 解析中に ValueError が発生しました。 #16284
    • .docx ファイル内のテーブルは、法律文書パーサーによってサイレントに削除されました。 #16155
    • DeepDoc 区切り文字が設定されている場合、単独の Markdown ヘッダーは後続のセクションから分離されました。 #16109
    • マークダウン テーブルはチャンク結果に 2 回表示されます。1 回目はスタンドアロン チャンクとして、もう 1 回は通常のテキスト チャンク内に表示されます。 #16143
  • MCP
    • MCP サーバーは、空のドキュメント ページに遭遇すると無期限にハングしました。ページネーションに欠陥があるため、文書の最後のページが突然削除されました。 #16285
    • サーバーのハードコードされたフェッチ制限が導入された page_size 制限を超えたため、MCP 接続とデータセット検出プロセスが失敗しました。 #16148
  • データフロー
    • データフロー再実行エンドポイントを復元し、取り込み応答に DSL ペイロードが含まれていることを確認し、タイムラインとパーサー ビューを確実にレンダリングします。 #16292
    • データフロー パーサーのデフォルトを復元し、実際の SSE ペイロードを返し、パイプラインが正しく実行され、メッセージ ID とログの更新が表示されるようにします。 #16290
  • LLM: eu または us リージョン エンドポイントを使用して、Google Cloud (Vertex AI) プロバイダー経由で新しい gemini-3.5-flash モデルを使用できませんでした。この問題は、合成された <region>-aiplatform.googleapis.com ホストではなく、必要な aiplatform.<region>.rep.googleapis.com ドメインへのマルチリージョン ルーティング要求を明示的に行うことで解決されます。 #15990
  • UI/UX: メタデータ追加モーダルは空の値をバックエンドに送信しました。 #15229
