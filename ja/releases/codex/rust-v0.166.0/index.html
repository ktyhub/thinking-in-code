codex rust-v0.166.0

リリース 公開日2026年10月29日 出典openai/codex 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

コーデックス rust-v0.166.0

新機能

  • 単語、行、ページの動きによるキーボード駆動のトランスクリプト選択、統合された検索、設定可能なショートカットが追加されました。 (#57221、#57222、#57223、#57224)
  • 非同期の質問、選択肢、回答、トランスクリプトの返信でマークダウンを一貫してレンダリングしました。 (#57259、#57292)
  • GPT-6.1 Terra をバンドル、Vertex AI、Amazon Bedrock モデル カタログに追加しました。 (#57293)
  • メッセージをキューに入れた後にアンロードされたスレッドを再開するための codex queue --resume を追加しました。 (#57232)
  • TUI に、より明確な安全ブロックの説明と、選択可能なより安全なフォローアップ プロンプトを追加しました。 (#57363、#57365)
  • 集中的な構成、接続、WebSocket 診断のために codex doctor --network-only を追加しました。 (#57606)

バグ修正

  • スレッドを再開またはフォークするときに、確認済みの承認と権限の設定が保持されます。 (#57227)
  • 削除された作曲家テキストを復元する際に、ローカル画像添付ファイルが保持されるようになりました。 (#57502)
  • インストールが使用中またはパスに非 ASCII 文字が含まれている場合の、macOS でのスタンドアロン リリースのクリーンアップを修正しました。 (#57503)
  • 親を解凍するときに、生成された子孫スレッドが復元されました。 (#57635)
  • アプリサーバースレッドの起動とシャットダウンの競合を修正し、完了したランタイムを速やかにリリースしました。 (#57787、#57788)
  • オフライン /quit および /exit の処理を含む、TUI 再接続回復の改善。 (#57820)
  • 早期の圧縮を避けるために、履歴書とフォーク全体で推論トークン アカウンティングを保持します。 (#57839)

雑用

  • Bazel を、ターゲットに一致する Rust バインディングとネイティブ Windows MSVC アーカイブ サポートを備えたソースビルド V8 に切り替えました。 (#57164、#57269、#57644、#57832)
  • スタンドアロン エグゼキューターは正規の CLI およびアプリサーバー リリース パッケージで出荷されました。 (#57837)
  • 標準化された開発とリリースは、Node.js 24.22.1 および Rust 1.95.0 に基づいて構築されています。 (#57168、#57373)
