codex rust-v0.169.0

リリース 公開日2026年11月13日 出典openai/codex 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

コーデックス rust-v0.169.0

新機能

  • オプトイン ターミナル ワークスペースは、複数のサイドチャット タブをサポートします。キーボードまたはマウスを使用してチャットを切り替え、Codex を再起動した後に保存したローカル サイド チャットを再度開きます。 (#59784、#60152、#60181)
  • エージェント コマンド センターから、名前、プロンプト プレビュー、または作業ディレクトリで古いタスクを検索します。 (#60286)
  • 全画面トランスクリプトで [ターンの詳細を折りたたむ] をオンにすると、回答が表示され、ツールの出力が検索可能になったまま、完了したアクティビティが各プロンプトの下に折りたたまれます。 (#60554、#60555、#60556、#60557)
  • ターミナルからカスタム モデル プロバイダーを追加または編集します。カスタム ゲートウェイ オンボーディングを有効にすると、サインイン中にプロバイダーを作成し、SSH 経由またはローカル ブラウザーを使用せずに、サポートされているゲートウェイのデバイス コードを使用できます。 (#59779、#60009、#60186、#60486、#60662)
  • ターミナル レポート エディターで Ctrl+S を押すと、アップロードが無効になっている場合でも、診断 ZIP をローカルに保存できます。 (#60542)
  • macOS および Linux 上のオプトイン クラウド接続を使用すると、画像を送信し、モデルと推論作業を選択し、ターミナルからクラウド会話をアーカイブまたは復元します。 (#59828、#60061、#60635、#60651)

バグ修正

  • codex exec は、--sandbox workspace-write であっても、untrusted ディレクトリでプロジェクト構成と MCP サーバーを無効のままにします。プロジェクト trust を明示的に保存するには、--trust を codex exec または codex review とともに使用します。 (#60041)
  • はい、コンテキストをクリアして実装します。現在は、完全に承認された計画を新しいセッションに渡し、引き継ぎが失敗した場合は現在のセッションを開いたままにします。 (#60763)
  • 引用符で囲まれた cmd.exe パスと、作業ディレクトリに読み取り不能な親がある PowerShell セッションに対する Windows サンドボックスの処理を修正しました。 (#60624、#60647)
  • macOS に貼り付けられた画像は意図した方向を保持し、ネイティブの PNG または JPEG clipboard データが利用可能な場合には使用されます。 (#60455)
  • 端末は、共有アプリサーバーが報告しなかった MCP サーバーを待機してビジー状態になることがなくなりました。 (#60280、#60622)
  • 中断されたターンはきれいに終了し、遅延中止やファイル承認のキャンセルによって後のターンが中断されることはなくなりました。 (#59910、#60700)

ドキュメント

  • openai-docs スキルを更新して、Codex および ChatGPT Work の質問と初回の API セットアップに焦点を当て、チーム全体で Codex を構成するための専用のガイダンスを提供しました。 (#59944、#59949)
  • アプリサーバー clients が、デフォルトのプロバイダーを変更せずに、モデルをリストしたり、設定されたプロバイダーのゲートウェイを承認したりする方法を文書化しました。 (#59776、#59819)

雑用

  • バンドルされている SQLite を 3.54 に更新して、先行書き込みログの修正を取得しました。 (#60432)
  • プラグイン マーケットプレイスのアップグレードでは、ディスク上に既に存在する Git オブジェクトを再利用できるため、繰り返しのダウンロードが削減されます。 (#60528)
