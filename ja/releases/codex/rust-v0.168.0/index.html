codex rust-v0.168.0

リリース 公開日2026年11月13日 出典openai/codex 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

コーデックス rust-v0.168.0

新機能

  • [セッション] → [モデル プロバイダー] でモデル プロバイダーを参照し、新しいチャットのデフォルトを選択します。 (#59541、#59722)
  • features.tui_workspace を有効にして、メイン チャットの横にサイド会話を表示します。仕切りをドラッグしてペインのサイズを変更するか、leader z を押してフォーカスされたペインをズームします。 (#58992、#59527、#59595)
  • オーディオ対応モデルを使用する場合は、録音を添付します。 Codex は、後のターンで確認済みの拒否された録音をスキップし、clip の継続時間を使用して、より短い録音をコンテキスト内に保持します。 (#59234、#59268)
  • features.image_generation_animation を有効にして、オプションのフレーム数とタイミング制御を使用してアニメーション GIF を生成または編集します。 (#59073)
  • フルスクリーン Codex は、allow-passthrough all を使用する Ghostty と Kitty の tmux で画像プレビューとペットを表示します。 (#59579、#59580) ・端末通知にtui.notification_method = "osc777"を設定します。承認通知には長いコマンド プレビューが表示され、端末入力とネットワーク アクセス要求が区別されます。 (#59256)

バグ修正

  • ローカル TUI 履歴と再開ピッカーは、サインインした ChatGPT アカウントによって新しく作成されたスレッドをフィルターします。 (#58918)
  • 新しいチャットのデフォルトを変更した後、開いているチャットと再開したチャットでは、保存されたモデル プロバイダーが使用されます。 (#59503)
  • TUI は、ツール呼び出しによって中断された応答を単一の Markdown メッセージとしてレンダリングし、会話を再生するときに推論の要約を復元します。 (#59698、#59700)
  • ステアリング メッセージは、最終トランスクリプトの保存中、または長時間実行されるチャットに切り替えた後に送信されると、実行ターンに達します。 (#58877、#58998)
  • ファジー ファイル検索では、ファイル名の一致がより重要視されるため、一致する親ディレクトリによって除外される可能性が低くなります。 (#59709)
  • Windows 上のアイドル状態のローカル MCP サーバーは、残りの Codex がファイル システム I/O を利用できる状態にします。 (#59726)

ドキュメント

  • アプリサーバーのリファレンスでは、モデルプロバイダーのリスト、カスタムゲートウェイの作成、ゲートウェイ、Bedrock、GCP 設定の更新について説明します。 (#58845、#58876)

雑用

  • features.multi_agent が明示的に構成され、サブエージェント ツールを無効にするために agents.enabled を指す場合、Codex は警告を出します。 (#59479)
  • 寄稿者は、BuildBuddy 資格情報なしで Bazel CI ジョブをローカルで実行できます。 (#59055)
