codex rust-v0.162.0

リリース 公開日2026年10月8日 出典openai/codex 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

コーデックス rust-v0.162.0

新機能

  • ワークツリー機能が有効な場合に、trusted ローカル プロジェクトから管理対象 Git ワークツリーを作成およびリストするためのツールを追加します。 (#50148)
  • p を使用してエージェント コマンド センターにタスクを固定し、サーバーでサポートされている場合は共有の固定グループにタスクを保持します。 (#51500)
  • /copy を使用してトランスクリプト ブロックを移動およびコピーし、Ctrl+Insert を使用して選択範囲をコピーし、tui.mouse_scroll_speed を使用してマウス ホイール スクロールを調整します。 (#50434、#50215、#50209)
  • 承認ヘッダー、質問、MCP プロンプト、警告、バナー、確認プロンプトで URL clickable を作成します (リンクが複数行にまたがる場合を含む)。 (#51439、#51449、#51450、#51451、#51452、#51458)
  • カスタム Responses 互換モデル プロバイダーのライブ Web アクセスとリモート圧縮機能を構成します。 (#50459)
  • 安定したプロミス結果をストリーミングするための JavaScript ヘルパーを追加し、コード モードでランク付けされたツール検索をオプトインします。 (#51126、#51209)

バグ修正

  • 明示的な起動オーバーライドを保持しながら、新しい TUI スレッドのサーバー モデルと推論概要のデフォルトを尊重します。 (#50013、#50811、#50913)
  • オプトインを必要とせずに、apply_patch 更新で既存の CRLF 行末を保持します。 (#51203)
  • 複数の拒否されたファイルによる Linux サンドボックスの起動を修正し、書き込み可能なサンドボックス構築実行可能ファイルを拒否し、ripgrep 設定が拒否グロブ マスクを弱めないようにします。 (#50059、#51211、#51407、#51527)
  • Windows 10 で通常のドライブ文字ファイル アクセスを復元し、Windows サンドボックスの一時アクセス許可を子プロセス環境に一致させます。 (#51511、#51512)
  • 再試行可能な応答と WebSocket の失敗に関するサーバー Retry-After のアドバイスを尊重します。 (#50418、#51440)
  • PowerShell 7 モジュール パスが存在する Windows PowerShell を介してインストールする場合のアーカイブ チェックサム検証を修正しました。 (#51257)

雑用

  • Windows リリースで署名付き PowerShell インストーラーを公開します。 (#51158)
  • 古い安定版リリースとプレリリースが、新しい安定版ダウンロード ターゲットやインストーラー エイリアスに置き換わらないようにします。 (#51186、#51425)
