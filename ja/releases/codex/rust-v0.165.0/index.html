codex rust-v0.165.0

リリース 公開日2026年10月27日 出典openai/codex 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

コーデックス rust-v0.165.0

新機能

  • model_provider = "gcp" で構成された組み込みの Google Cloud Vertex AI プロバイダーを追加しました。 (#56265)
  • GPT-6.1 Terra をモデルカタログに追加しました。 (#57337)
  • セッション ピッカーにリポジトリ フィルターが追加され、エージェント コマンド センターにディレクトリ グループが追加され、リンクされたワークツリー間でセッションを簡単に移動できるようになりました。 (#56308)
  • 実験用の添付スレッド フォークをアプリサーバー API に追加しました。 (#56351)
  • サポートされているモデルでは、デフォルトで会話中の推論努力の変更が有効になりました。 (#56163)
  • 新しいプロファイルに対してメモリ v2 をデフォルトで有効にし、外部エージェント メモリをインポートするためのサポートを追加しました。 (#56211、#56414)

バグ修正

  • 明示的なオーバーライドが提供されていない場合にサーバーのデフォルトの承認レビュー担当者を尊重するように、新しい TUI セッションを修正しました。 (#56090)
  • TUI 設定を編集可能にし、実行設定が無効な場合でもすぐに適用できるようにしました。 (#56091)
  • ローカル応答先物がドロップされた場合、リモート MCP ツール要求がキャンセルされました。 (#56132)
  • 割り込みまたは計画モードへの切り替え後に、キューに入れられたエージェント メッセージが作業を再開できないようにしました。 (#56330)
  • プロバイダーがモデルが見つからなかったと報告した場合、エラー メッセージを保持したまま再試行を停止しました。 (#56445)
  • 許可されたパターンに対してチェックされたホストとは異なるホストに Git が接続できる可能性がある、マーケットプレイス URL 検証のギャップを解消しました。 (#56263)
