codex rust-v0.164.0

リリース 公開日2026年10月23日 出典openai/codex 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

コーデックス rust-v0.164.0

新機能

  • 再利用可能なプロンプトとスラッシュ コマンドを 10 個の番号付き /presets スロットに保存し、キーボード メニューですばやくアクセスできます。 (#54380、#54381)
  • インライン /model および /permissions 引数を使用して、モデル、推論労力、速度、権限プロファイルを直接設定します。 (#54378、#54383)
  • Kitty または Sixel グラフィックスをサポートする端末上で、表示および生成された画像を全画面トランスクリプトでプレビューします。 (#54216)
  • シークレットを必要とする OAuth client を含む、適格な Codex アカウント付与または専用サインインを使用してエンタープライズ MCP 接続を認証します。 (#55334、#55859、#56001)
  • サポートされているリモート Bash コマンドおよび Zsh スナップショット セッション中に、カスタム プロバイダーからの資格情報を含む資格情報をマスクします。 (#54309、#54432、#56049)
  • Amazon Bedrock セットアップ ウィザードがデフォルトで有効になり、認証情報が検出されたときに API キーエントリが他の AWS サインイン方法と並んでグループ化されます。 (#56033、#56023)

バグ修正

  • 圧縮に失敗しても会話履歴に部分的な概要が残されることはなくなり、バックグラウンドで圧縮が失敗してもパニックに陥ることなくフォールバックします。 (#53932、#55581)
  • セッションを再開すると、圧縮された履歴が検索され、保存されたスレッド設定がグローバルなデフォルトに置き換えられるのではなく復元されるようになりました。 (#54008、#55923)
  • Windows HTTPS および WebSocket 接続は、サインインしているユーザーの Negotiate または NTLM 資格情報を使用してプロキシ認証チャレンジを処理するようになりました。 (#55994、#56000)
  • -c または --config が複数のサブコマンド レベルで出現する場合、CLI 構成のオーバーライドは保持されます。 (#56022)
  • キューに入れられたプロンプトは、保留中の権限の選択が解決されるまで待機してから続行するようになりました。 (#55682)
  • 強化されたサンドボックス チェックにより、macOS 上で大文字と小文字が異なるメタデータ パスと、実行可能ファイルの検索に使用される置換可能なシンボリック リンクがチェックされます。 (#54273、#55384)

雑用

  • 未使用のインストールを削除し、放棄されたマーケットプレイス チェックアウトをクリーンアップし、デーモン ログを制限することにより、ディスク使用量を削減しました。 (#53827、#55149、#55689、#55690、#55856)
  • 最適化された Array.sort 操作のための安全性チェックを備えた組み込み JavaScript ランタイムを更新しました。 (#54519)
