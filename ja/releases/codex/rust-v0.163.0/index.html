codex rust-v0.163.0

リリース 公開日2026年10月15日 出典openai/codex 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

コーデックス rust-v0.163.0

新機能

  • /config を開いてカテゴリ全体の環境設定を検索し、サポートされている設定をすぐに変更し、再起動が必要な変更を確認します。 (#52990、#53429)
  • Codex が直ちに対応するよう応答している間にフォローアップを送信します。ターンを中断すると、アクティブなコード モード セルとそのネストされたツール呼び出しも停止します。 (#51812、#51835)
  • リーダーキーを/keymapに設定します。デフォルトは Ctrl+X で、ショートカットのヒントは選択またはキャンセルするまで開いたままになり、音声ミュートは F9 に移行します。 (#52273)
  • /daemon から管理対象バックグラウンド サーバーを再起動します。 Codex は、再起動によって中断される可能性のある作業について警告し、自動的に再接続します。 (#53173)
  • Codex は、スキル、メモリ、会話履歴の検索などの独立した読み取り専用ツールを並行して実行できます。 (#52245)
  • Daybreak は対象となるアカウントに対してデフォルトで有効になっています。 codex exec は、サーバーがアクセスを提供するときに OpenAI API キーを使用して選択することもできます。 (#53701、#53717)

バグ修正

  • 保存されたスレッドを再開すると、明示的なオーバーライドと現在の管理ポリシーが尊重されながら、その権限とネットワーク承認が復元されます。 (#53150、#53419、#53424)
  • ネットワーク プロキシは、DNS ルックアップの前に権限をチェックし、重複する Host ヘッダーを拒否し、資格情報のエイリアスが検査フックをバイパスするのを防ぎます。 (#51650、#52661、#53506)
  • スレッドを切り替えた後、/side との既存のサイドカンバセーションに戻ります。保留中のプロンプトに対する回答も、質問したスレッドに戻ります。 (#52184、#53436)
  • Windows では、Ctrl+V および Shift+Insert は画像だけでなくテキストも貼り付けます。 WSL では、貼り付けを繰り返すと clipboard リーダーが再利用され、コピー試行がハングせずにタイムアウトになります。 (#53224、#52967、#53453)
  • 子が出力パイプを開いたままにすると、ローカル コマンドは即座に終了します。リモート コマンドは、遅れて到着した出力を保存するため、最終ポーリングでも引き続き出力を収集できます。 (#52652、#53331、#53622)
  • codex exec は、無関係なコマンドの後に同じファイル diff を再度出力しなくなりました。 (#53444)

ドキュメント

  • モデル固有の推論、ツールの使用、データ常駐に関する考慮事項を含む、GPT-6 ファミリへの移行に関するバンドルされている OpenAI Docs ガイダンスを更新しました。 (#51768)
  • Linux サンドボックスがファイルシステムの分離に bubblewrap を使用し、syscall フィルタリングに seccomp を使用する方法を明確にしました。 (#52610)

雑用

  • Codex は標準のシェル エグゼキュータを使用するようになり、パッチを適用した zsh をバンドルしなくなりました。廃止されたシェル フラグを使用する構成は、移行通知を受け取ります。 (#52160、#52213)
  • 元のビルド出力にシンボルを保持しながら、パッケージ化されたバイナリからシンボルを削除することで、Linux および macOS リリースのパッケージ サイズを削減しました。 (#52178)
