codex rust-v0.167.0

リリース 公開日2026年11月6日 出典openai/codex 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

コーデックス rust-v0.167.0

新機能

  • codex agents --no-daemon を使用してエージェント コマンド センターを開きます。コマンド センターとセッション ピッカーは、未読の結果にマークを付けるようになりました (#58238、#58239、#58263、#58264)。
  • ターミナル セッション ピッカーから接続されたバックエンドを切り替え、切り替え時にドラフトを保持します (#58280、#58457)。
  • サポートされている端末で作成中にローカル画像の添付ファイルをプレビューし、clickable トランスクリプト パスから表示されたローカル画像を開きます (#58261、#58446)。
  • 「別の方法で署名する」で API キーとクラウド プロバイダーのオプションを見つけます。 gcp_setup_wizard を有効にして、アプリケーションのデフォルト認証情報または認証情報ファイル (#57857、#58427) を使用して Google Cloud Vertex AI をセットアップします。
  • /experimental (#58157) から macOS または Windows システムのプロキシ設定をオプトインします。
  • 承認プロンプトが開いているときにトランスクリプト内でパッチの詳細を直接展開します (#58281)。

バグ修正

  • 保存したチャットは、モデルプロバイダーを切り替えた後も表示されたままになります。チャットを再開できない場合は、そのトランスクリプトを読み、新しいチャットを続行するための編集可能なプロンプトを準備できます (#58202)。
  • Ctrl+L は、Ctrl+T を通じて利用可能な以前のメッセージを保持しながら、端末の表示をクリアします (#58266)。
  • 先頭の ! を公開するテキストを削除すると、チャット モードで通常の下書きが保持されます (#58412)。
  • ネットワーク承認プロンプトは、要求が終了すると閉じます。同じエンドポイントへの同時リクエストは、一度に 1 つずつプロンプトを表示します (#58350、#58351)。
  • 長時間のリアルタイム V3 会話では、トランスクリプトが大きくなるにつれて、完了した音声をチャット履歴に保存します (#58221)。
  • 自動コンテキスト圧縮は、失敗した応答およびトークン使用データが欠落している応答からの保持された出力を考慮するようになりました (#58404)。

ドキュメント

  • アプリサーバーの README では、新たな人間の承認を必要とする [permissions.network] および prompt-user コマンド ルールに基づく管理されたネットワークの制約について説明しています (#58045、#58182)。
  • openai-docs スキルは、非推奨モデル (#58134) から移行するときに文書化された置き換えを推奨します。

雑用

  • DotSlash マニフェストは、リリースに同梱された Cargo パッケージを参照するようになりました (#58717、#58757)。
  • Linux musl ビルドは、会話のアンロード後のアイドル メモリを削減するために、より少ないアロケーター アリーナを使用します (#58399)。
