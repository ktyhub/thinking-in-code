TradingAgents v0.2.5

トレーディングエージェント v0.2.5

概要

TradingAgents v0.2.5 には、グラウンディングされたセンチメント アナリスト、Qwen/GLM/MiniMax デュアル リージョン サポート、API キー自動検出を備えた `TRADINGAGENTS_*` 環境変数構成機能、リモート Ollama サポート、米国以外のティッカー用の構成可能なアルファ ベンチマーク、およびティッカー パス トラバーサル修正が含まれています。

センチメントアナリスト

名前が変更されたセンチメント アナリストは、レポートを生成する前に実際の Yahoo ニュース、StockTwits、Reddit データを読み取るようになり、急速な圧力を受けてソーシャル投稿を捏造する可能性があった以前のフローを置き換えます。新しい名前は、CLI ドロップダウン、ステータス パネル、および最終レポートに表示されます。 `AnalystType.SOCIAL = "social"` は、保存された構成の逆互換のために保持されます。

プロバイダーの範囲

  • MiniMax には完全な M2.x カタログ (204K コンテキスト) に加え、グローバル (`MINIMAX_API_KEY`) と中国 (`MINIMAX_CN_API_KEY`) のデュアルリージョンが含まれます。
  • デュアル リージョン Qwen および GLM。リージョンごとに個別のキー (`DASHSCOPE_`、`ZHIPU_`) を持ち、セカンダリ リージョン プロンプト経由で選択されるため、メイン プロバイダーのドロップダウンはクリーンなままになります。
  • すべてのプロバイダーで カタログを更新: GPT-5.5 Frontier、Claude Opus 4.7、Gemini 3.1 Flash-Lite GA、Grok 4.20、Qwen 3.6 ライン。バージョン管理された ID のみ。自動シフト エイリアスは「カスタム モデル ID」オプションに移動されました。
  • 構造化出力が DeepSeek V4/reasoner および MiniMax M2.x で動作するようになりました - これらのプロバイダーは `tool_choice` を拒否します。バインディング フローはそれを自動的にスキップするようになりました。

環境による設定

`TRADINGAGENTS_*` 環境変数は、型認識型強制 (string / int / bool) で `DEFAULT_CONFIG` キーをオーバーライドします — `llm_provider`、ディープ/クイック モデル ID、`backend_url`、`output_language`、ディベート ラウンド カウント、チェックポイント フラグ、およびベンチマーク ティッカー。選択したプロバイダーの API キーが見つからない場合、CLI はそのキーを要求し、その値を `.env` に保持するため、再起動せずに実行が続行されます。

オラマ

`OLLAMA_BASE_URL` は、CLI ユーザーとプログラム ユーザーの両方にとってリモート `ollama-serve` をファーストクラスにします。 CLI は、Ollama を選択した後に解決されたエンドポイントを出力し、一般的な不正な入力について警告します。新しい「カスタム モデル ID」オプションを使用すると、ユーザーは `ollama pull` 経由で取得した任意のモデルを選択できます。

反省

アルファは現在、米国以外のティッカーの地域ベンチマーク — `.NS` (^NSEI)、`.T` (^N225)、`.HK` (^HSI)、`.L` (^FTSE)、`.TO` (^GSPTSE)、`.AX` (^AXJO)、`.BO` (^BSESN)、米国上場の SPY に対して計算されます。非米ドル上場のアルファ数値を支配する為替ドリフトを排除します。 `benchmark_ticker` は、明示的に設定するとサフィックス マップをオーバーライドします。

ニュース取得パラメーター (ティッカー記事ごとの制限、マクロ ヘッドライン制限、ルックバック ウィンドウ、マクロ検索クエリ) が、戦略固有の調整のために `DEFAULT_CONFIG` 経由で公開されるようになりました。

多言語

`output_language` は、ユーザーと接するすべてのエージェント (研究者、リスク討論者、リサーチ マネージャー、トレーダー) に伝播するようになり、アナリストとポートフォリオ マネージャーのみが設定を尊重していた以前の部分ローカリゼーション レポートは終了します。

修正

  • セキュリティ: すべてのファイル システム パス サイトでのティッカー パス トラバーサル検証。
  • `pip install .` インストールでは、CLI をコンソール スクリプトとして実行するときに、プロジェクト `.env` が選択されるようになりました。
  • レポートはエンドツーエンドで保存されます - ストリーミングされたチャンクは以前は `complete_report.md` からドロップされていました。
  • ティッカー プロンプトは交換サフィックスを保持します (`.SH`、`.SZ`、`.SS`、`.HK`、`.T` など)。
  • Docker 権限エラーにより、`~/.tradingagents/` への初回実行書き込みがブロックされなくなりました。
  • サブ辞書が変更された場合でも、実行間で構成状態がリークしなくなりました。
  • `max_recur_limit` 設定は実際にプロパゲータに適用されます。
  • Missing-API-key error は、設定する正確な環境変数を指定します。
  • より静かな起動 — ノイズの多いアップストリームの langgraph-checkpoint 非推奨警告を抑制しました。

PR / 問題の参照を含む項目ごとの完全なリストについては、CHANGELOG.md を参照してください。
