TradingAgents v0.5.2

パッチ 公開日2026年9月29日 出典TauricResearch/TradingAgents 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

トレーディングエージェント v0.5.2

並行アナリスト、無人 CLI 実行、それらを生成したものを記録するレポート、 過去の実行では、その日付で判明している内容のみが提供されました。

追加されました

  • 並列アナリスト 選択したアナリストは同時に実行されるため、アナリストのフェーズには最も遅いアナリストのフェーズとほぼ同じ時間がかかります。 CLI には各アナリストの進行状況と終了時間が表示され、すべてのレポートが揃った時点で議論が始まります。 (#1255、#433)
  • 無人 CLI が実行されます。 実行ごとの質問にはフラグが回答し、残りの質問には TRADINGAGENTS_* 変数が使用されるため、スケジュールされたジョブまたはスクリプトでは何も質問されません (tradingagents --ticker NVDA --date 2026-09-26 --analysts market,news --save --no-show)。ターミナルを使用しないと、応答が見つからない場合、実行が開始される前に停止され、設定する内容に名前が付けられます。 (#1127、#1133)
  • レポートは、そのレポートを作成した内容を記録します。 各レポートは、分析日付、バージョン、プロバイダー、モデル、アナリスト、ラウンド、およびデータ ベンダーで開きます。状態ログには run_settings として保存されます。 (#752、#1197)
  • Docker データ フォルダー。 TRADINGAGENTS_DATA_DIR は、結果、レポート、およびメモリ ログをホスト フォルダーに保存します。 (#865)
  • アナリストのツール呼び出しの上限。 max_tool_rounds のラウンド (デフォルトは 20、TRADINGAGENTS_MAX_TOOL_ROUNDS) の後、アナリストは手持ちの情報に基づいてレポートを作成します。 (#1420)
  • tradingagents backtest は開始時の各セルを示し、--run-id は継続することを示します。 --analysts は sentiment を受け入れます。
  • 台湾、韓国、シンガポール、およびヨーロッパの主要取引所のベンチマーク。 (#1392)
  • Python 3.14 のサポート; Docker イメージは Python 3.13 を実行します。

モデル

  • deepseek-flash は思考モデルとして扱われるため、構造化された出力が機能します。 (#1388)

0.5.1 からのアップグレード

  • Python 3.11 以降が必要です。パンダ3がインストールされています。
  • 最小バージョン: yfinance 1.7.0、langchain-core 1.6.5、langchain-openai 1.6.6、langchain-anthropic 1.7.4、langchain-google-genai 4.4.0、langgraph 1.2.12、langgraph-checkpoint-sqlite 3.1.1、langchain-aws 1.7.9 (bedrock)追加）。
  • ステートメントのデフォルトは SEC EDGAR、次に Yahoo (fundamental_data = "sec_edgar,yfinance") です。
  • 過去日付の実行には、Yahoo や Alpha Vantage の声明やインサイダー取引は掲載されず、出願日は記載されず、そのようにマークされた現在の会社名のみが記載されます。
  • メモリ ログは tradingagents.memory パッケージです (以前は tradingagents.decision_log)。決済と反映は tradingagents.graph からそこに移動し、Reflector は tradingagents.graph からエクスポートされなくなりました。
  • process_signal は削除されました。定格は propagate() の 2 番目の値、つまり final_state["final_rating"] です。
  • 評価は Rating: ラベルからのみ読み取られます。これを省略した自由記述の決定は REVIEW です。
  • データ層関数は as_of_date= を使用します (以前は curr_date=)。 build_instrument_context と resolve_instrument_context は trade_date= を使用します。
  • VendorRateLimitErrorはVendorUnavailableErrorです。
  • データツールは実行状態から機器を取得します。ツール呼び出しでは symbol または ticker が使用されなくなりました。
  • 状態ログ: trader_investment_plan (以前は trader_investment_decision)、judge_decision が削除され、final_rating と run_settings が追加されました。
  • 0.5.1 からのチェックポイント、または別の設定で保存されたチェックポイントは再開されません。

修正済み

  • データ ツールは、モデルが別のシンボルを渡す場合でも、実行の手段として機能します。
  • 失敗したベンダー要求は、欠落またはリストから除外されたシンボルとしてではなく、利用不可として報告されます。あるベンダーの「データがない」ということは、もはや別のベンダーが失敗したチェーンを代弁するものではありません。 (#1386)
  • 格付けはポートフォリオ マネージャー独自のものであり、その論文の引用ではありません (#1383)。その行は他の出力言語でも英語のラベルを保持します (#1435)。
  • 2 回与えられたバックテスト セルは 1 回実行され (#1415)、決済は同じ日付で決定をベンチマークと比較します。
  • 価格のないシンボルのスナップショットでは実行が終了しなくなりました。
  • 同時実行によりメモリ ログ エントリが削除されなくなりました。
  • 年初から現在までにのみ提出された SEC EDGAR の四半期数値が、そのスパンでラベル付けされて提供されます。
  • Yahoo の配当利回りと負債対株式比率がパーセンテージで表示されます。 (#1414)
  • FRED の変更行には、その範囲にまたがる日付の名前が付けられています。 (#1397)
  • stream_run は、グラフ独自の構成をそのツールに提供します。
  • テスト スイートはネットワークやユーザーのファイルから離れた状態にあり、任意の順序でテストされます。統合テストは -m integration で実行されます。 (#1395)
