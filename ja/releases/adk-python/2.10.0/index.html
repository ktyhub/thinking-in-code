#adk-python v2.10.0

2.10.0 (2026-09-24)

ハイライト

このリリースでは、高度なスキル ライフサイクル管理が導入され、データベースとモデルの統合サポートが拡張され、エージェント評価により豊富な効率指標が導入されています。

  • スキル: 新しい一時的なライフサイクルとアクティブなスキル制限を使用して、リソースの使用量とツールの永続性を動的に制御します (実験的。ADK_ENABLE_SKILL_LIFECYCLE=1 で有効になります)。 (43b73e4)
  • データベース統合: 新しい MongoDB ツールセットを使用して、エージェント フロー内で高性能のベクトル検索とハイブリッド検索をシームレスに実行します。 (0961ced)
  • 評価: 期間、トークン消費量、モデル呼び出し数を追跡するための新しい評価指標を使用して、エージェントの実行コストと待機時間を最適化します。 (2d428ea)
  • モデル サポート: 自動化されたリクエスト パラメーターの適応と正確な推論トークン レポートにより、OpenAI 推論モデルをより効果的に統合します。 (52a2f0f)

行動の変化

  • BigQuery 保護書き込みモード では、ドライ ランによってセッションの匿名データセットに非 SELECT ステートメントが配置された場合にのみ非 SELECT ステートメントが実行されるようになりました。そのため、ドライ ランで宛先が指定されなかった複数ステートメント スクリプト、CALL、EXPORT DATA、およびその他のステートメントは拒否されます。 (8b883d0)
  • BigQuery 保護モード では、BigQuery セッションがセッション状態ではなくプロセス メモリに保持されるため、一時テーブルは再起動後に存続したり、別のレプリカに引き継がれたりすることはありません。 (094012b)
  • OpenAIResponsesLlm は、警告を表示して thinking_config (thinking_level / thinking_budget) を無視します。代わりに OpenAIGenerateContentConfig.effort を使用してください。 (b3d1392)
  • AgentEvaluator.evaluate および evaluate_eval_set は、評価ケースが評価されない場合、合格ではなく ValueError を発生させます。 (9dbc2ae)
  • 命令テンプレートでは、${var} とバックスラッシュでエスケープされた \{var} は、状態から埋められるのではなく、書かれたままになります。 (0caecd2)
  • **google.adk.flows.llm_flows (audio_cache_manager、audio_transcriber、transcription_manager) の下の レガシー ライブ オーディオ モジュールは、インポート時に DeprecationWarning を発します。 google.adk.liveに移動します。 -W error で実行されるテスト スイートは、これらのインポートでは失敗します。 (bf2bc56)
