#adk-python v2.7.0

2.7.0 (2026-08-13)

ハイライト

正確性のリリース: 作業のほとんどは、ツール、セッション、評価、CLI にわたる修正のロングテールと並行して、エージェントがモデルに送信する内容とモデルが返す内容に費やされました。

  • モデルは独自の機能を宣言します: ADK がモデル ID からサポートを推測するのではなく、モデルが実際にサポートしている場合、エージェントは出力スキーマとツールを組み合わせます。 (2aff82c、dc5dbfa)
  • ツールはメディアを返すことができます: ツールの関数応答は、Gemini 上でも、Anthropic、LiteLLM、Apigee および OCI 上でも同様に、画像やその他のメディアをモデルに直接送り返します。 (df9d6de、703cf43)
  • 会話履歴には、Gemini に必要なものが保存されます: 思考の署名、サーバー側のツール呼び出し部分、および並列関数呼び出しのすべての結果がラウンドトリップ後に残ります。 (d4ed347、e908137、93dff41)
  • Jinja2 命令テンプレート: use_jinja2=True を inject_session_state に渡すと、命令は条件文を使用し、{{ artifact("name") }} ヘルパーを介してロードされたアーティファクトを使用してセッション状態をループできます。 Jinja2 はオプションの依存関係のままで、正規表現エンジンはデフォルトのままです。 (4a00a34)
  • 高速な起動とホット パス: import google.adk は作業量を減らし、リクエスト パスにより、Pydantic ラウンドトリップと LiteLLM アダプターでの 2 次ストリーミングの蓄積が回避されます。 (8806dc2、9e1adde、36fd2c8)

重大な変更

  • pyarrow は gcp エクストラを残しました: これは新しい bigquery-analytics エクストラ内に存在し、pip install google-adk[gcp] から約 50 MB を奪います。 BigQueryAgentAnalyticsPlugin を使用する場合は、google-adk[bigquery-analytics] をインストールします。 (ac71709)
