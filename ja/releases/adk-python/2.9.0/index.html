#adk-python v2.9.0

2.9.0 (2026-09-10)

ハイライト

このリリースでは、自動モデル フェイルオーバー、LiveKit によるネイティブ音声サポート、MCP SDK 2.x との互換性の導入により、エージェントの回復力とエコシステムの統合に焦点を当てています。

  • モデル: プライマリ モデルでエラーが発生した場合に、バックアップ モデルに自動的にフェイルオーバーすることで、エージェントの稼働時間を保護します。 (c300b8d)
  • 統合: 新しく追加された LiveKit ランナーを使用して、リッチな音声およびテレフォニー エージェントを構築します。 (f277d91)
  • ワークフロー: 宣言型 YAML 構成から直接 ADK 2.0 グラフを作成およびロードすることで、グラフ ワークフロー管理を簡素化します。 (2a9461b)
  • MCP: 1.x サーバーとの完全な下位互換性を維持しながら、MCP SDK 2.x 機能にシームレスにアップグレードします。 (856acf2)

行動の変化

  • ワークフロー ノードの再開: ワークフローが再開されると、失敗したノードが再び実行されるようになりました。以前は、完了したかのように再生されました。ノード本体を冪等にする: 外部副作用を実行して失敗したノードは、再開するたびにその副作用を再度実行します。 (91573eb)
  • GCS ツールのローカル パス: GCS ツールは、local_file_root で指定されたディレクトリ内でのみローカル ファイルの読み取りと書き込みを行うようになり、その設定が存在しない場合はローカル ファイル アクセスを完全に拒否します。パスは絶対パスまたは相対パスであり、パスが解決される場所によって判断されます。 (c569796)
  • インメモリ セッションのみ: InMemorySessionService は、保持していないセッションにイベントが追加されたときに、イベントを受け入れて破棄するのではなく、SessionNotFoundError を発生させるようになりました。データベースを利用したサービスはすでにこのように動作しているため、これはメモリ内のセッションにのみ影響します。 (15b1392)
