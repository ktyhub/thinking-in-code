#adk-python v2.12.0

2.12.0 (2026-10-13)

ハイライト

このリリースでは、ツールの実行、ワークフローの承認、展開のセキュリティに対するより詳細な制御を導入しながら、長時間のセッションでの実行パフォーマンスが強化されています。

  • パフォーマンス: 長いセッションにおいて、最初のモデルリクエストまでの時間を 40% 短縮します。 (1754b3e)
  • ツール: after_tool_callback を使用してモデルに返す前に、ツールの出力をインターセプトおよびフィルターします。 (fdda17c)
  • ワークフロー: require_confirmation 経由でワークフロー ノードを実行する前に人間による確認が必要です。 (988fd1a)
  • 展開: 専用のカスタム サービス アカウントを使用して、エージェントをエージェント エンジンに展開します。 (629e119)
  • Python 3.15: Python 3.15 に ADK をインストールして実行します。 (75aef1e)
