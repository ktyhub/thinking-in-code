adk-python v2.11.0

#adk-python v2.11.0

2.11.0 (2026-10-01)

ハイライト

このリリースでは、ワークフローに適切なキャンセルとツールの確認、タスク中に別のモデルを参照するためのツール、および組み込みの SQLite メモリ サービスが追加されています。

  • 実行のキャンセル: 実行を正常に停止するには、abort_signal を Runner、Workflow、およびノー​​ドに渡します。 client が切断されると、/run_sse は実行をキャンセルするようになりました。詳細は「ユニットガイド」(https://github.com/google/adk-python/blob/main/docs/guides/runners/runner/abort.md)をご覧ください。 (ef5bbcf、3d73603)
  • ワークフローでのツール確認: ツール ノードは、ダウンストリームにエラーを渡す代わりに、LlmAgent と同じ方法で、RequestInput 経由でユーザーの承認のために一時停止するようになりました。 (ce132b9)
  • ModelConsultTool: エージェントがタスク中に別のモデルを参照できるようにします。このモデルは、ターンごとおよびセッションごとの予算によって制限されます。詳細は「ユニットガイド」(https://github.com/google/adk-python/blob/main/docs/guides/tools/model_consult/model_consult_tool/index.md)をご覧ください。 (84cc99a)
  • SQLite メモリ サービス: sqlite:// メモリ サービス URI で選択されたローカル SQLite データベースにエージェント メモリを保持します。 (9625b06)
  • MCP SDK 2.x: 新しいオプトイン パスを介して最新のプロトコルで MCP サーバーに接続します。 (e738c26)

機能

  • メモリ プロファイルをプリロードするサンプルを命令に追加します (fdf1b7f)

  • sqlite メモリ サービスを追加 (9625b06)
  • モデルコンサルトセッションコンテキストハンドオーバーレイヤーを追加 (b2da4c6)
  • cli: client 切断時に abort_signal を /run_sse に配線します (3d73603)
  • GCP メタデータからのデフォルトの Vertex プロジェクト (8d8bbd2)
  • イベント: ADK イベントの内部メタデータを追加します (8e29f16)
  • ライブ モード以外の同期ツールでは、tool_thread_pool_config を優先します (c50ade3)

  • 構成ベースの ADK 作成の init.py をスキップ (d594b69)、閉じます #6753
  • 中止イベントとキャンセル時の関数応答を合成します (da65851)
  • テレメトリ: スキル テレメトリ スパン属性を試験運用から移動 (e0f4c97)
  • ツール: ターンとセッションの予算を含む ModelConsultTool を追加 (84cc99a)
  • ツール: model_consult のツールを使用せずにアドバイザ モデルを呼び出します (28c47b5)
  • ワークフロー: RequestInput によるツール確認のためにツール ノードを一時停止します (ce132b9)
  • ワークフロー: Skip_summarization をノード ツールからツールの応答に伝播する (5a0421c)
  • ワークフロー: ToolNode 呼び出しの周りでプラグイン ツール コールバックを実行します (cfeece9)
