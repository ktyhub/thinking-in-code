#adk-python v2.13.0

2.13.0 (2026-10-22)

ハイライト

このリリースでは、TypeSafe ワークフロー分類、ライブ オーディオ インタラクション、MongoDB 統合、および実行パフォーマンスの向上を導入しながら、コア機能が安定化されています。

  • 安定性: 12 の成熟した実験的機能にアクセスできるようになり、安定したステータスに昇格しました。詳細は「ユニットガイド」(https://github.com/google/adk-python/blob/main/docs/guides/features/feature_registry/index.md)をご覧ください。 (ea298d4)
  • 分類子: 新しい TypesafeClassifier および ClassifierNode を介して、TypeSafe の Jev モデルでワークフローをルーティングします。 Jev は、LLM よりもはるかに高速に、単一のフォワード パスで調整された確率を返します。詳細は「ユニットガイド」(https://github.com/google/adk-python/blob/main/docs/guides/labs/classifiers/classifier_node/index.md)をご覧ください。 (ddf8c55、e8c4bac)
  • ライブ オーディオ: Gemini の音声テキスト変換およびテキスト音声変換の統合に加えて、バージイン サポートにより、自然なリアルタイム音声対話が可能になります。詳細は「ユニットガイド」(https://github.com/google/adk-python/blob/main/docs/guides/live/cascade_live/index.md)をご覧ください。 (2e7ef92)
  • MongoDB セッションとメモリ: MongoDB にセッションを保持し、新しい MongoDbSessionService を使用してランナー レプリカ間でセッションを共有します。 MongoDbMemoryService を使用して、埋め込みモデルを使用せずに長期メモリを追加します。MongoDbMemoryService は、ベクター インデックスを必要とせず、MongoDB デプロイメント上のキーワード一致によって過去のターンを呼び出します。どちらも実験的なものです。詳細については、セッション サービス および メモリ サービス のガイドを参照してください。 (0df43f5、e40e349)
  • MongoDB: 接続文字列をパッケージ化せずに MongoDbToolset をエージェント エンジンにデプロイすると、Atlas Automated Embedding によってサーバー側に検索クエリが埋め込まれます。Google の埋め込み呼び出しや認証情報は必要ありません。詳細は「ユニットガイド」(https://github.com/google/adk-python/blob/main/docs/guides/integrations/mongodb/mongodb_toolset/index.md)をご覧ください。 (bc3773f、2f6c666、8bbfc33)
  • パフォーマンス: 文字列モデル エージェントの実行ターンが最大 8 倍高速になり、イベント読み込みのオーバーヘッドが軽減されます。 (772f139)

重大な変更

  • テレメトリ: デフォルトは OpenTelemetry GenAI v2 (otel_semconv_1_44、call_llm を削除)。 ADK_TELEMETRY_SCHEMA_VERSION_OPT_IN=otel_semconv_1_36 を設定してレガシー v1 スキーマを保持します。詳細は「ユニットガイド」(https://github.com/google/adk-python/blob/main/docs/guides/telemetry/telemetry_config/index.md)をご覧ください。 (7838488)
