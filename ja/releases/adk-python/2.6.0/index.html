#adk-python v2.6.0

2.6.0 (2026-07-29)

機能

  • a2a: エージェント カードを取得するときに呼び出しごとの認証ヘッダーをサポート (3dd1156)
  • --extra_packages オプションを adk deploy agent_engine (93db97d) に追加し、#3936 を閉じます
  • ADK 評価サンプルを追加: 共有ホーム オートメーション エージェント (6ba41ef)
  • エージェント ID 認証マネージャーを追加し、認証マネージャーを使用した 3 Legged OAuth フローのエンドポイントを終了します (8d2ded3)
  • Basic_criteria ADK 評価サンプルを追加 (fdebd9d)
  • ADK BigQuery ツールに bigquery-graph スキルを追加 (f1a0a14)
  • CLI で実行されるコマンドをログに記録する機能を追加 (a58220c) *custom_metric ADK 評価サンプルを追加 (f71d9df)
  • llm_judge_match ADK 評価サンプルを追加 (0f0fa6b)
  • A2A コンバーターにメタデータ抽出の対称性を追加 (3127f36)
  • オプトインの Final_response_tool_names を BigQueryAgentAnalyticsPlugin に追加 (07455ee)
  • 自己修復モデル エラー用の ReflectAndRetryModelPlugin を追加 (322f455) *rubric_criteria ADK 評価サンプルを追加 (852a66a)
  • ライブ モードの LiveRequest に state_delta サポートを追加 (8219774)、クローズ #4220
  • テレメトリ同意チェック、ステータス コマンド、割り込み安全性を CLI (6bab08f) に追加
  • テレメトリ同意構成エンドポイントとローカル書き込みユーティリティを追加 (26f3d45)
  • ADK CLI 実行用のテレメトリ メトリック コレクションを追加 (2280f1c)
  • test_file_vs_evalset ADK 評価サンプルを追加 (57a34ba)
  • user_simulation ADK 評価サンプルを追加 (481fe21)
  • エージェント: 管理対象エージェントに指示フィールドを追加 (720af3d)
  • エージェント: 管理対象エージェント命令を system_instruction (49fdc26) として転送します
  • eval: パブリック エントリポイント (5091f0a) 経由でライブ評価とオーディオ評価に到達できるようにします。
  • eventarc: ADK 用 Eventarc Advanced ツールセットを追加 (217a90a)
  • eventarc: ADK 用 Eventarc Advanced ツールセットを追加 (d4f157d)
  • OAuth2 nonce を認可リクエスト (79cc1f2) に転送し、クローズ #2067
  • 統合: OCI Generative AI プロバイダー (625ef1a) を追加し、#5069 を閉じます
  • エージェントの評価を事前にロードされたアーティファクトと互換性を持たせる (02e32a4)、クローズ #2075
  • EventsCompactionConfig のスライディング ウィンドウ フィールドをオプションにする (ec42cfa)、閉じる #6398
  • 推移的な依存関係保護のためのコンパニオン制約 - 3.11.txt および制約 - 3.12.txt ファイルを公開 (サプライ チェーン攻撃から保護するための 4 日間のバッファー) (75c773e)
  • OpenAPI 資格情報交換器で期限切れの OAuth2 トークンを更新 (b3c9783)
  • サンプル: 管理対象エージェントを追加し、カスタム エージェントを作成して使用するサンプル (d86ae20)
  • オーディオ生成ユーザー シミュレーター (327afeb) をサポート
  • パス プレフィックス (1ae292f) での to_a2a エージェントのサービスのサポート、クローズ #4448
  • RunConfig でのユーザー ラベルのサポート (13bef9c)
  • テレメトリ: エージェント エンジンのリクエスト駆動型メトリック エクスポートを追加 (8930d9b)
  • テレメトリ: プロバイダーのステータス コード (b956d15) から gen_ai error.type を導出します。
  • mTLS エンドポイントを内部で処理するために、agent_registry を更新 (66cf08d)

バグ修正

  • a2a: NotImplementedError を発生させる代わりにタスクのキャンセルを受け入れます (fb55d4a)
  • エージェント: 3.11 より前の ParallelAgent マージでキャンセルされたタスクを待機 (bc55099)、クローズ #5297
  • エージェント: タスクモード LlmAgent での中間会話テキストの Output_key 処理をスキップします (54344ed) *generate_content_config で http_options.extra_body を許可します (4c6f22e)
  • 呼び出しレベルのルーブリックを許可 (67ab27f)
  • アーティファクト: アプリ別の名前空間ファイル アーティファクト (f72f0db)
  • 現在のターンのみを組み立てます (c328cec)
  • バインドされた統合 HTTP 待機 (bf4143a)
  • 反重力統合における Protobuf ジェンコード/ランタイム バージョン チェックをバイパスする (91038f2)
  • キャッシュ: 動的ツール (509be09) を使用するときにプロンプト キャッシュが無効になるのを防ぎ、#3227 を閉じます。
  • client_cert_available 引数を指定して mtls.Should_use_mtls_endpoint を呼び出します (b315b00)
  • 安定したハッシュのためにコンテキスト キャッシュ フィンガープリントを正規化 (425dda1)
  • ci: すでに閉じられている場合でも、インポートされた PR をマージ済みとしてマークします (2eca8b1)
  • cli: ADK Web でサブフォルダーを持つエージェント フォルダーを単一のエージェントとして扱う (40cf97b)
  • 呼び出し元が消費を停止したときに A2A 応答ストリームを閉じる (31392ba)
  • DaytonaEnvironment.close (ecf6d13) の AsyncDaytona client を閉じる
  • ネイティブ ツールがドロップされないようにすべてのツールを収集 (c429d75)、クローズ #6091
  • SDK に準拠した反重力会話 ID (64b758a) を取得します。
  • クラスタ認証情報を GKE コード サンドボックスにマウントしないでください (8207880)
  • ストリーミング アーティファクト更新で新しいアーティファクト パーツのみを発行 (088be86)、クローズ #6343
  • ワークフロー グラフ ノードから再開可能チェックポイントを発行します (cecc1f9)
  • eval: adk eval で get_agent_async をサポート (ebaef9f)
  • 評価: ROUGE-1 マッチングで英語以外の応答をサポート (8200fae)
  • マルチモーダル ツールの結果プラグインを空のコンテンツから保護します (5a248de)
  • adk eval (6f6106f) で Windows パスを処理し、#6415 を閉じます
  • A2A メタデータのシリアル化とパーサー タイプの検証を強化 (eee700a)
  • 資格情報の失敗の詳細が含まれます (13c7272)
  • 委任されたタスクのブランチを分離 (95feafa)、クローズ #6457
  • httpx にマルチパート境界 Content-Type (3367b5b) を設定させます
  • Web UI が eval ケース (b549ab4) を保存できるように、InvocationEvent.content をオプションにして、クローズ #6336
  • ParallelWorker の同時障害例外を確定的にする (d31b5e7)
  • 言い換えられたルーブリックがドロップされないように、エコーされた ID によってルーブリックの判定を照合します (0b7355b)、クローズ #6171
  • メモリ: Vertex RAG top-k 構成を優先 (d4d2f6e)
  • メモリ: Vertex RAG アップロードを非同期安全にします (80a05b7)
  • v0 イベントのタイムスタンプを UTC ではなく現地時間として移行します (6f1efe7)
  • モデル: ストリーミング中に人間的思考ブロックの署名をキャプチャします (bb56aa5)
  • モデル: 欠落フィールド AttributeError (df02689) から Gemini.client_kwargs を保護します
  • モデル: AnthropicLlm 応答にfinish_reason を設定します (716be89)
  • エージェント ID 認証情報プロバイダー (0598c9b) を除き、狭い、広い
  • コンテキスト ID フィールドをパーセントエンコードして、ID に区切り文字を往復させる (fab5347)
  • SHAS をコミットするサードパーティの github アクションを固定します (4e16855)
  • プラグイン: BigQuery Agent Analytics のプライバシーとシャットダウンの強化を完了する (9adf011)
  • プラグイン: ReflectAndRetryModelPlugin の正しい遅延インポート パス (c59fd0e)
  • プラグイン: フェールオープン プライバシー、GCS 同時実行性、起動損失ギャップに対して BigQuery エージェント分析を強化します (2919bf5)
  • プラグイン: 再試行ツール プラグインで失敗カウンターのプロパティを復元 (66a7233)
  • Anthropic LLM 応答にfinish_reason を設定します (802a079)
  • FunctionResponse 部分に関数名を入力します (540cfdf)
  • client 証明書を提示し、API ハブ呼び出しに mTLS エンドポイントを使用します (2cf5433)
  • Windows での ADK 動作の保持 (6e9895c)
  • 明示的な false とゼロの OpenAPI クエリ パラメーター (b3abcb2) を保持し、#6287 を閉じます
  • A2A アーティファクト更新でメタデータを保持 (2316b83)
  • adk deploy が .adk/session.db ファイル (dab351b) をアップロードできないようにします
  • ツール確認における継続偽造を防止 (4b002c4)
  • 再開可能な呼び出しリプレイでの transfer_to_agent ループを防止 (19df9b9)
  • カスタム メタデータを RunConfig から InvocationContext に伝播する (79ba5af)
  • 見つからないセッションに追加するときに SessionNotFoundError が発生します (0a70337)
  • LocalEvalSampler の eval 設定からカスタム メトリクスを登録 (79a879f)、閉じます #6177 *generate_content_config でのbase_url と extra_body を拒否 (472e463)
  • 不完全な評価入力を拒否します (8ca9128)
  • パッチ適用された非同期 LangGraph ランタイムが必要 (551372b)
  • 本番環境でのツール確認再開の失敗を解決 (c427020)
  • 受信イベント変換で A2A Message.role を尊重 (968845f)、クローズ #5186
  • プロパティがない場合は _get_required_fields から空のリストを返します (1890557)、閉じます #5920
  • 現在の呼び出しまでのスコープ再生シーケンス (455853b)、クローズ #6497
  • ツール スレッド プールのスコープをそのイベント ループに設定します (a1792a7)
  • AgentTool からベアの input_schema ペイロードを再度送信します (ba17367)
  • 評価基準を具体的なサブクラスとしてシリアル化します (623da49)
  • A2A コンバーターで生のバイトを Base64 としてシリアル化します (e6604e1)
  • セッション: VertexAiSessionService で after_timestamp と num_recent_events を一緒に適用します (021f6f6)
  • ストリーミング応答の部分チャンク全体で 1 つのイベント ID を共有 (8f98bcd)、クローズ #1006
  • シングルフライト Discovery Engine モード検出 (3a9a88c)、クローズ #6101
  • Vertex AI 戻り値の型 (268815d) で失敗する自動関数呼び出しを停止し、#3543 を閉じます
  • config.http_options (761f1ac) 経由で渡された認証情報のトレースを停止します
  • Output_schema JSON (28c649a) を検証する前にマークダウン コード フェンスを削除します
  • dot_adk_folder 解決でネストされたエージェント パスをサポート (d33ca5f)
  • AgentTool からのサブエージェント RPC エラーを表示 (e737f22)
  • スパンプロセッサの不正な形式のトレースペアレントヘッダーを許容します (de2e66e)
  • ツール: ToolConnectionAnalyzer.analyze の JSONDecodeError をバインドします (a60d5b9)
  • adk_team サンプル エージェントでは GitHub コンテンツを untrusted として扱います (f4979b5)
  • 実行中の BigQuery 書き込みを待機します (6e43800)
  • ワークフロー: ネストされたワークフローでのタスク エージェントの再開を修正 (fd006db)
  • ReAct プロンプトで input_schema ペイロードをラップし、tool_choice を LiteLLM に伝播します (550189c)
