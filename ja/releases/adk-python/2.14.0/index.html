#adk-python v2.14.0

2.14.0 (2026-11-04)

ハイライト

このリリースでは、実行環境、A2A、評価、およびコア ランタイム モジュールが実験的モジュールから卒業し、複数実行の評価とセマンティック ツールの引数マッチングが追加され、Microsoft Teams と OpenAI Decisions の統合が追加され、長い複数ターンのワークフローが高速化されます。

  • 実行環境とサンドボックス:
    • BaseEnvironment、LocalEnvironment、EnvironmentToolset、DaytonaEnvironment、E2BEnvironment が安定しました。 (c54b253、799fc94)
    • BaseEnvironment.read_file_stream はファイルを LocalEnvironment、E2BEnvironment、DaytonaEnvironment にまたがるチャンクにストリーミングするため、ReadFileTool はファイル全体をメモリにロードせずに行範囲を読み取ります。詳細はユニットガイドをご覧ください。 (fd8d8c1)
    • AgentEngineEnvironment は、大きなファイルをチャンクで読み書きし、570 秒以上かかるコマンドをサービス期限前にタイムアウトしたとして報告します。詳細は【本体ガイド】(https://github.com/google/adk-python/blob/main/docs/guides/integrations/vmaas/agent_engine_environment/index.md)、【サンプル】(https://github.com/google/adk-python/tree/main/contributing/samples/environment_and_skills/agent_engine_environment)をご覧ください。 (4c88040、5843c58、b13fa19、d3a199d)
    • ContainerCodeExecutor は入力ファイルと出力ファイルをサポートし、RunSkillScriptTool はシェル コマンド文字列の代わりに検証されたパスと引数からスキル スクリプトを実行します。 (effd641、ff61524)
  • 評価:
    • MultiRunConfig (adk eval --num_runs) および --parallelism は、各評価ケースを同時に複数回実行し、実行間のスコアまたは合格率を結合します。詳細については、eval config および agent evaluator ガイドを参照してください。 (7f3517e、e9e8f61)
    • AgentEvaluator は実行時にビルドされた BaseNode または App を受け入れ、--eval_storage_uri は読み取り専用 agents_dir の外側に eval ファイルを保存します。 (ce92e92、ff66b1f)
    • ToolArgsMatcher は、正確、大文字と小文字を区別しない、数値許容、または LLM に基づくセマンティック チェックを使用して、評価におけるツール呼び出し引数と EnvironmentSimulation を比較します。詳細は「ユニットガイド」(https://github.com/google/adk-python/blob/main/docs/guides/tools/tool_args_matcher/tool_args_matcher/index.md)をご覧ください。 (ed76f94、08c289b)
  • A2A: A2A 統合は安定しており、adk generate_agent_card は CLI から A2A エージェント カードを構築します。詳細は「ユニットガイド」(https://github.com/google/adk-python/blob/main/docs/guides/a2a/utils/agent_to_a2a/index.md)をご覧ください。 (95d4a56、875e2ae)
  • 統合:
    • TeamsRunner は、ADK エージェントを Microsoft Teams のチャットおよびチャネルに接続します。詳細は「ユニットガイド」(https://github.com/google/adk-python/blob/main/docs/guides/integrations/teams/teams_runner/index.md)をご覧ください。 (c4376a6)
    • OpenAIDecisionsClassifier は、OpenAI Decisions API を使用してワークフローとツールゲーティングの質問を分類します。詳細は「ユニットガイド」(https://github.com/google/adk-python/blob/main/docs/guides/integrations/openai/openai_decisions_classifier/index.md)をご覧ください。 (aa98d18)
    • MongoDbMemoryService は、ベクトル検索の取得 (retrieval_mode="vector" または "auto") と TTL 有効期限 (memory_ttl_days) を追加します。詳細は「ユニットガイド」(https://github.com/google/adk-python/blob/main/docs/guides/integrations/mongodb/memory_service/index.md)をご覧ください。 (1c84bb9)
  • 安定した API: 26 個の認証、環境、アプリ、CLI およびキャッシュ モジュール、16 個のツールセットと統合機能、および成熟した評価クラスとユーザー シミュレーション クラスは実験版を卒業したため、実験的な警告なしで構築できます。 (c54b253、799fc94、1112606)
  • ワークフローのパフォーマンス: 長い複数ターンのワークフローはより高速に実行され、メモリの使用量が少なくなります。 30 ノードのワークフローの 200 ターンの実行は 23% 高速になり、ピーク メモリは 9% 削減されます。 (532580c、1f21370)

重大な変更

  • 列挙ツールの引数はメンバーとして受信されます: Enum、Optional[Enum]、または list[Enum] の注釈が付けられた FunctionTool パラメーターは、(FUNCTION_TOOL_ARG_VALIDATION がすでに行っていたように) モデルが送信した生の文字列の代わりに列挙メンバーを受信するようになりました。プレーンな Enum、arg == "value"、文字列キーの辞書検索、文字列の match、json.dumps、および文字列メソッドは機能しなくなります。呼び出し可能な require_confirmation は、引き続き生の値を受け取ります (FUNCTION_TOOL_ARG_VALIDATION がオンでない場合)。 (str, Enum)、str()、および Python 3.11+ の場合、f 文字列は Cls.MEMBER をレンダリングするようになりました。メンバーと比較するか、.value を使用するか、StrEnum に切り替えます。ツールが結果として返す列挙型メンバーは、引き続きその値としてモデルに送信されます。 (82fe029、58332a2)
  • VertexAiSessionService.create_session はセッション構成オプションのみを受け入れます: 追加のキーワード引数は、display_name、ttl、expire_time、および labels (およびキャメルケース エイリアス) に制限されます。他のセッション API 構成キー (http_options、session_state、sessionId、wait_for_completion など) は、ValueError (セッション options から adk api_server として送信される場合は HTTP 400) を生成するようになりました。状態と ID には state= と session_id= を使用します。 (968cd86)
  • RunSkillScriptTool は環境モードで command を受け付けなくなりました: SkillToolset 環境では、モデルは自由形式シェル command の代わりに args、short_options、および positional_args を渡すようになり、スクリプトは環境の作業ディレクトリではなくスキル ディレクトリから実行され、.py、.sh、および .bash スクリプトのみがサポートされます (その他のスクリプトは返されます) UNSUPPORTED_SCRIPT_TYPE）。 command を渡す呼び出し、評価セット、またはプロンプトは、INVALID_ARGUMENTS を返すようになりました。これにより、プロンプト挿入モデルで任意のシェル コマンドを実行できる穴が塞がれます。 (ff61524)

行動の変化

  • /run_live はソケットをハングしたままにするのではなく、不正なフレームではコード 1007 で、実行終了時にコード 1000 で閉じるようになりました。アイドル状態のソケットを再利用するのではなく、新しいライブ実行ごとに再接続します。 (3b227d6)
  • OpenAPI ツールのクエリ パラメーターは、宣言された style および explode に従うようになりました。 (1d81896)
  • DatabaseSessionService は、新しい PostgreSQL JSON 列を jsonb ではなく json として作成します。既存の jsonb テーブルは移行されず、引き続き動作します (PostgreSQL サンプル README にテーブルの変換方法が示されています)。 jsonb のみの演算子または GIN インデックスに依存する ADK 外部のクエリは、新しいテーブルでは機能しません。 (d487c53)
  • gen_ai.invoke_workflow.duration、gen_ai.client.operation.duration、および gen_ai.client.token.usage ヒストグラムは semconv バケット境界を使用するようになりました。 (ba45671)
  • output_schema を備え、独自のツールがなく、転送ターゲットを持つエージェントは、応答スキーマと関数呼び出しを組み合わせることができないモデルで JSON モードの代わりに set_model_response ツールを取得するようになり、応答ごとに 2 つのイベントが追加されます。 (73b6790)
  • トークンしきい値圧縮は、最後のモデル呼び出し以降のツール出力をカウントするため、変更されていない token_threshold に対してはより早く実行されます。 (a72a8ed)
  • 端末 wait_for_output ノードが新しい待機実行に再トリガーされるネストされたワークフローでは、そのノードの以前の出力が表示されなくなりました。 (cddc57f)
  • 新しい teams および fsspec エクストラ、および e2b フロアは 2.29.5 に引き上げられます。 (c4376a6、6bf806a、75fb788)
  • FirestoreSessionService はイベント ペイロードを JSON 文字列として保存し、アプリとユーザーの状態でネストされたリストをラップします。既存のセッションはロードを続け、新しいイベントを受け入れますが、このバージョンが書き込むセッションは、ロールバック後に 2.13.0 以前では読み取ることができません。 (0894c03)
  • 安定版に昇格した 16 のツールセットおよび統合機能 (Bigtable、コンピューター使用、Daytona および E2B 環境、環境シミュレーション、GCS、MCP エージェント サーバー、Pub/Sub、Spanner など) は常に利用可能です。ADK_DISABLE_<FEATURE>、override_feature_enabled(<FEATURE>, False)、および --disable_features は、エラーや警告なしにそれらをブロックしなくなりました。 (799fc94)
