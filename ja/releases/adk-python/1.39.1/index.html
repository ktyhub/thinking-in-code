#adk-python v1.39.1

1.39.1 (2026-08-27)

バグ修正

  • a2a: イベント アクション ホワイトリスト、エージェント カード記述ソースをポートし、v1 へのフラット化を再開します (#6801) (1f898a6)
  • アーティファクト: アプリ スコープのファイル アーティファクト ストレージとレイアウト由来のペイロード パスを v1 (#6795) (0ae2bff) に移植します。
  • アーティファクト: v1 へのポート アーティファクト参照スコープとパス セグメント検証 (#6794) (efc5bb8)
  • cli: すべてのローカル API サーバー要求の Host ヘッダーを確認します (v1) (#6789) (15bf230)
  • cli: 無視ファイル処理を v1 にポート デプロイ (#6793) (8467bf0)
  • v1 バックポート レビューからの残りのギャップを埋める (#6890) (218061e)
  • 統合: api レジストリ資格情報を Google api エンドポイント (v1) (#6889) (1e9e117) にのみ送信します
  • mcp: ポート構成 stdio オプトインと予約済みツール名チェックが v1 (#6796) (28b32b4) にチェックされます。
  • モデル: ポート Gemini コンテキスト キャッシュ フィンガープリントのスコープが v1 (#6804) (f2f8456)
  • プラグイン: BigQuery 分析行をサニタイズし、呼び出しごとに GCS パスを構築します (v1) (#6808) (80e56de)
  • ポート A2A エージェント カード RPC ターゲット起点の v1 への検証 (#6800) (ccb4812)
  • ポート エージェント ローダーとファイル パス解決を v1 に修正 (#6788) (8bc927f)
  • エージェント設定コード参照と config_path 検証を v1 にポート (#6790) (15ae713)
  • ポート ブランチ スコープの認証応答と v1 への OAuth2 nonce 転送 (#6803) (5817d30)
  • ポート コード エグゼキューター コンテナーとポッド分離のデフォルトは v1 (#6807) (1b4da44)
  • ログ、repr、および v1 へのポート資格情報とインライン データ フィールドの除外 (#6797) (7c2075c)
  • ポート評価識別子の検証と v1 へのペルソナ テンプレートのレンダリング (#6806) (0a4a5c6)
  • ポート移行のアンピックル許可リストとデータベース URL の v1 への編集 (#6791) (6deda28)
  • ポート セッション ID 検証、スレッド ID スコープ、および Vertex RAG クリーンアップを v1 に修正 (#6809) (3fec8c5)
  • ポートスキルのリソースパスとスキル名の検証を v1 に修正 (#6805) (1353e8d)
  • ポート URL 検証、client タイムアウト、資格情報スコープを v1 に修正 (#6802) (7b6547f)
  • run_async (v1) を介してスレッド プールとライブ モード ツールのディスパッチをルーティングします (#6799) (48c56c3)
  • レジストリごとにカスタム評価メトリックのスコープを設定し、評価構成 (v1) (#6792) (9886410) からの関数パスを解決します。
  • セッション: v1 で完全なセッション リソース名を再度受け入れます (#6888) (ef4f1e0)
  • ユーザーメッセージ部分とエージェント転送ターゲットの検証 (v1) (#6798) (d830355)
