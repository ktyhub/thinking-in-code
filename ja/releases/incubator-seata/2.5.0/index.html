インキュベーターシート v2.5.0

Apache Seata(インキュベート中) 2.5.0 がリリースされました。

Apache Seata(インキュベート) は、使いやすく、高性能な、オープンソースの分散トランザクション ソリューションです。

バージョンは以下のように更新されます。

機能:

  • [#7261] アカウントの初期化を強制し、デフォルトの認証情報を無効にします
  • [#7451]seata-serverはHTTP/2プロトコルをサポートします
  • [#7496] オーシャンベースオラクルのサポートを追加

バグ修正:

  • [#7349] EtcdRegistryServiceImplMockTest の NullPointerException を解決する
  • [#7354] libs フォルダー内のドライバーをロードできない問題を修正
  • [#7356] codecov のバグを修正
  • [#7370] ISSUE_TEMPLATEが機能しない問題を修正
  • [#7397] NullPointer およびポート バインディング エラーを解決します
  • [#7502] 余分なドットを削除し、他のテーブルとの命名スタイルの一貫性を保ちます。
  • [#7498] Fury 逆シリアル化におけるクラス名のホワイトリスト チェックの問題を修正
  • [#7504] ヒカリのロードドライバークラスを修正
  • [#7529] ネーミングサーバーが他のレジストリで使用されている場合にサーバーがハートビートを送信しない問題を修正しました。
  • [#7546] clientスプリングバージョン互換修正

最適化:

  • [#7270] CI 構成を強化します
  • [#7282] FileRegistryServiceImpl クラスの検索メソッドでの予期しない NullPointerException を最適化します。
  • [#7310] ネーミングサーバーの軽微な問題を最適化します。
  • [#7329] Tomcat を 9.0.100 にアップグレードします
  • [#7346] サーバー上の Tomcat を netty-http に置き換えます
  • [#7344] raftモードはトランザクションサイズチェックを事前に実行します
  • [#7343] Tomcat を 9.0.104 にアップグレードします
  • [#7337] メモリリークを防ぐために ChannelEventListener サポートを追加しました
  • [#7344] raftモードはトランザクションサイズチェックを事前に実行します
  • [#7345] 空のチェックと重複した型のチェックを RegistryFactory に追加します
  • [#7350] codecov.yml を最適化します。
  • [#7360] チャネル切断のためのリソースクリーンアップロジックを更新
  • [#7363] npmjs の依存関係をアップグレードする
  • [#7372] ライセンス無視の最適化
  • [#7375] ディスカバリーモジュールの close() ロジックを最適化します。
  • [#7388] バイナリパッケージのディレクトリ構造を最適化します。
  • [#7412] 新しいバージョンのシータに適応したヘルムテンプレート
  • [#7414] 未使用のdefaultEventExecutorGroupをNettyClientBootstrapから削除します。

  • [#7418] ジャクソン通知を追加
  • [#7419] ソース コードのパッケージ化をサポートするための Maven プロファイルを追加
  • [#7428] pmd-check ログが ERROR レベルである

  • [#7445] ライセンスをサーバーおよびネーミングサーバーから分離します
  • [#7426] ライセンスヘッダーを追加
  • [#7450] コードベース全体に Spotless を適用する
  • [#7456] Druid SQL パーサーがサポートされていない REPLACE ステートメントに対して ParserException をスローする
  • [#7466] 発行テンプレートに貢献意向チェックボックスを追加
  • [#7478] メトリクスに再試行ステータスが追加されました
  • [#7483] retryDeadThreshold の値を 70 秒に変更します

  • [#7518] ChannelEventHandlerIntegrationTest で不安定な API の使用を避ける
