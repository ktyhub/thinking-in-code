インキュベーターシート v2.0.0

シータ2.0.0発売

Seata は、使いやすく、高性能の、オープンソースの分散トランザクション ソリューションです。

バージョンは以下のように更新されます。

特徴：

  • [#5165] TCC 構造を最適化し、API アクセスをサポートします。トランザクション プロセス定義とプロキシ拡張のための統合層モジュール (seata-integration-tx-api) を追加します。
  • [#5352] TCC ビジネス アクション コンテキストに jackson json パーサーと gson json パーサーを追加
  • [#5377] AbstractHttpExecutor.class が http put をサポートするようにします
  • [#5396] TC ログ アペンダー メトリック
  • [#5118] は 2 段階の同時通知実行をサポートします
  • [#5529] docker イメージは JVM パラメーター インジェクションをサポートします
  • [#3887] AT モードでの SQL Server データベースのサポートを追加
  • [#4033] サーバー DB ストレージ モードの SQLServer サポートを追加
  • [#5600] 機能: XID に応じたトランザクション リンクのトレースのサポート
  • [#5357] 機能: コンソール統合 saga-statemachine-designer
  • [#5717] バージョン 1.4.2 以下の file.conf および registry.conf 構成と互換性があります
  • [#5842] docker 画像にメタ情報を追加します
  • [#5902] IPv6をサポート
  • [#5907] AT モードでの Polardb-x 2.0 のサポート
  • [#5932] Dameng データベースをサポート
  • [#5946] コンソール ページング インターフェイスに sqlserver の適応を追加します。
  • [#5226] ラフトクラスターとストアモードをサポート

バグ修正：
