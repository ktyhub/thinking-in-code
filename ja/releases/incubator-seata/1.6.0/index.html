インキュベーターシート v1.6.0

シータ1.6.0発売。

Seata は、使いやすく、高性能の、オープンソースの分散トランザクション ソリューションです。

バージョンは以下のように更新されます。

特徴：

  • [#4863] Oracle および postgresql マルチ主キーをサポート
  • [#4649] Seata-server は複数のレジストリをサポートします
  • [#4779] Apache Dubbo3をサポート
  • [#4479] TCC モードは、インターフェイスと実装クラスの両方でマークされた tcc アノテーションをサポートします
  • [#4877] シータ client support jdk17
  • [#4914] mysql 更新結合 SQL をサポート
  • [#4542] Oracle タイムスタンプ タイプをサポート
  • [#5111] Nacos contextPath をサポート [#4802] dockerファイルサポートアーム64

バグ修正：

  • [#4780] タイムアウト ロールバックが成功した後に TimeoutRollbacked イベントをポストできない問題を修正しました
  • [#4954] 出力式が誤って npe をスローする問題を修正しました
  • [#4817] 標準ではない高バージョンの Springboot プロパティを修正しました
  • [#4838] Statement.executeBatch() を使用すると元に戻すログを生成できない場合を修正しました
  • [#4533] ロールバックイベントが繰り返され、一部のイベントステータスが正しくない問題を修正しました。
  • [#4912] mysql InsertOnDuplicateUpdate 列の大文字と小文字が異なるため、一致できない問題を修正しました
  • [#4543] Oracle nclob タイプのサポートを修正しました
  • [#4915] サーバー回復プロパティの取得に失敗した問題を修正しました
  • [#4919] coordinator.init の前の XID ポートとアドレス null:0 を修正
  • [#4928] rpcContext.getClientRMHolderMap NPE を修正しました
  • [#4953] InsertOnDuplicateUpdate バイパス修正PKを修正
  • [#4978] kryo サポートの循環参照を修正
  • [#4874] OpenJDK 11を使用して起動エラーを修正しました
  • [#5018] 起動スクリプトのローダー パスを修正
  • [#5004] 更新結合の重複画像行を修正
  • [#5032] プレースホルダー インデックス計算エラーが原因で発生する mysql InsertOnDuplicateUpdate SQL クエリ エラーを修正しました
  • [#5033] 重複した場合の挿入で SQL 列が空の場合の null 例外を修正しました
  • [#5038] @EnableConfigurationProperties({SagaAsyncThreadPoolProperties.class}) を削除します
  • [#5050] グローバルセッションがsagaモードでコミット済みに変更されない問題を修正しました
  • [#5052] 更新結合条件プレースホルダー パラメーター エラーを修正
  • [#5031] mysql InsertOnDuplicateUpdate は画像の SQL クエリ条件として null インデックス値を使用すべきではない問題を修正しました
  • [#5075] InsertOnDuplicateUpdateExecutor が主キーと一意のキーを持たない SQL をインターセプトできなかった問題を修正しました
  • [#5093] Seata サーバーの再起動後のアクセス キーの損失を修正
  • [#5092] Seata と jpa を一緒に使用すると、AutoConfiguration の順序が正しくなくなる問題を修正しました。
  • [#5109] RM側に@GlobalTransactionalアノテーションがない場合に発生するNPEを修正
  • [#5098] Druid が Oracle の暗黙的キャッシュを無効にする
  • [#4860] Seataサーバー側のメトリクスタグのカバレッジを修正
  • [#5028] 重複 SQL での挿入で文字列として解析される挿入値 null を修正しました
  • [#5078] 主キーと一意のキーがない SQL をインターセプトできなかった問題を修正しました
  • [#5097] サーバー再起動後のアクセスキー損失を修正
  • [#5131] ロールバック XA 接続のアクティブ状態を修正しました
  • [#5134] 光データソースの自動プロキシの失敗を修正
  • [#5163] 不正なサービス構成ファイルとコンパイルの失敗を修正

最適化：

  • [#4774] Seataio/seata-server イメージの mysql8 依存関係を最適化します。
  • [#4790] SeataをOSSRHに公開するgithubアクションを追加
  • [#4765] mysql 8.0.29 は接続のために保留すべきではありません
  • [#4750] unBranchLock romove xidを最適化します
  • [#4797] githubのアクションを最適化します
  • [#4800] Apache ライセンス V2 として通知を追加
  • [#4681] グローバルトランザクション中のチェックロックを最適化します。
  • [#4761] フィールドが 1 つしかないため、hmget を置き換える hget を使用します
  • [#4414] log4j 依存関係を除外します
  • [#4836] BaseTransactionalExecutor#buildLockKey(TableRecords rowsincludePK) メソッドをより読みやすく最適化します。
  • [#4865] GGEditor のいくつかのセキュリティ脆弱性を修正
  • [#4590] 自動デグレード有効化による動的構成
  • [#4490] インデックスによる tccfence ログ テーブルの削除
  • [#4911] ライセンス チェッカー ワークフローを追加
  • [#4917] アップグレード package-lock.json の脆弱性を修正
  • [#4924] pom 依存関係を最適化します
  • [#4932] 一部のプロパティのデフォルト値を抽出します
  • [#4925] Java ドキュメントの警告を最適化します
  • [#4921] コンソールのいくつかの脆弱性を修正し、skywalking-eyes をアップグレードします
  • [#4936] ストレージ構成の読み取りを最適化します
  • [#4946] ロックを取得するときに SQLException を client に渡します
  • [#4962] ビルドを最適化し、基本イメージを修正します
  • [#4974] 最適化して、Redis モードでの globalStatus クエリ数の制限をキャンセルします
  • [#4981] 最適化 TCC フェンス レコードが存在しません errMessage
  • [#4985] undo_log ID の繰り返しを修正
  • [#4995] イメージ クエリ SQL 後の mysql InsertOnDuplicateUpdate 重複 pk 条件を修正しました
  • [#5047] 無駄なコードを削除
  • [#5051] アンドゥ ログ ダーティ スロー BranchRollbackFailed_Unretriable
  • [#5075] 主キーと一意のインデックス値を持たない InsertOnDuplicateUpdate ステートメントをインターセプトします
  • [#5104] ConnectionProxy の druid 依存関係を削除します
  • [#5124] tccfence ログの削除で Oracle をサポート
  • [#4468] kryo 5.3.0 をサポート
  • [#4807] docker 画像を最適化し、公開を強化しました
  • [#4445] トランザクションタイムアウト判定の最適化
  • [#4958] タイムアウトの場合はtriggerAfterCommit()を実行しません
  • [#4582] redis モードのサポート タイムアウトによるソート セット
  • [#4963] ARM64 CI ワークフローを追加
  • [#4434] Seata-server の CMS パラメータを削除します

コードをコミットしてくれたこれらの貢献者に感謝します。意図しない省略があった場合はご報告ください。
