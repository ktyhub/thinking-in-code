インキュベーターシート v2.6.0

Apache Seata(インキュベート中) 2.6.0 がリリースされました。

Apache Seata(インキュベート) は、使いやすく、高性能な、オープンソースの分散トランザクション ソリューションです。

バージョンは以下のように更新されます。

機能:

  • [#7485] Seata-server の http リクエスト フィルターを追加
  • [#7509] 接続を再利用してブランチ トランザクションをマージします
  • [#7492] 共通モジュールの HTTP client をアップグレードして HTTP/2 をサポートします
  • [#7503] シリアライザーとアンドゥログパーサーをサポート
  • [#7551] XAUtils が DM データベースのサポートを追加
  • [#7559] TableMetaRefreshHolder インスタンスのクリーンアップ API の導入
  • [#7669] PostgreSQL 配列型の Jackson シリアル化と逆シリアル化のサポートを追加
  • [#7664] shentongdatabase XAモードをサポート
  • [#7675] Oracle Batch Insert をサポート
  • [#7663] CI 構成ファイルに Java 25 サポートを追加
  • [#7851] トランザクション グループ管理のサポートを追加
  • [#7857] コンソールでのクラスター情報の表示をサポート
  • [#7826] サーバー Raft モードでの Watch API の HTTP/2 応答処理をサポートします。
  • [#7863] JDK バージョン 25 未満のビルド ワークフローからネーミングサーバーとコンソール モジュールのビルドを除外します

  • [#7872] JVMパラメータの値を自動計算します
  • [#7876] 機能: MCP カスタム構成と認証コードを追加
  • [#7878] コンソールは、Raft クラスターのトランザクション グループの作成と変更をサポートします
  • [#7893] グローバルおよびブランチ セッションおよびロック管理 MCP ツールを追加
