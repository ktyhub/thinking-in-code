インキュベーターシート v1.4.2

シータ1.4.2発売。

Seata は、使いやすく、高性能の、オープンソースの分散トランザクション ソリューションです。

バージョンは以下のように更新されます。

特徴：

  • [#2933] mysql sqlparser の antlr を追加
  • [#3228] カスタムシリアル化プラグインをサポート
  • [#3172] AT で undo_log 圧縮モードをサポート
  • [#3372] Saga サポートは、最終リトライ ログを更新するかどうかをカスタマイズします
  • [#3411] は、seata-server スレッド プール パラメータ設定をサポートします
  • [#3348] TC で redis センチネル ストレージ モードをサポート
  • [#2667] db および redis ストレージ モード使用時のパスワード復号化をサポート
  • [#3427] 分散ロックインターフェースを追加
  • [#3443] seata-server ログの logstash または kafka への送信をサポート
  • [#3486] メトリックのトランザクション サービス グループを追加します
  • [#3317] zookeeper を構成センターとして使用する場合、単一ノードを介して複数の構成を取得するためのサポート
  • [#3516] consul が使用されるレジストリおよび構成センターでの ACL トークンのサポート
  • [#3116] apollo configService とクラスターの構成をサポート
  • [#3468] saga サポート ステートでのループ実行
  • [#3447] ロギングフレームワークでトランザクションコンテキストの印刷をサポート

バグ修正：

  • [#3258] AsyncWorker の潜在的な OOM 問題を修正

  • [#3293] 構成キャッシュ取得値の型の不一致例外を修正しました

  • [#3241] マルチ SQL での使用順序または制限が禁止されています

  • [#3406] config.txt に特殊な文字セットがある場合、値を nacos にプッシュできない問題を修正しました。

  • [#3418] getGeneratedKeys が履歴 pk を取得する可能性がある問題を修正

  • [#3408] 別のパッケージに 3 番目の依存関係がある場合の JAR 実行モードの NPE 問題を修正

  • [#3431] 設定の読み取り時にプロパティ Bean が初期化されない可能性がある問題を修正しました

  • [#3413] セーブポイントへのロールバックとセーブポイントへのリリースのロジックを修正しました。

  • [#3367] xa ブランチがロールバックされると、アイドル状態のため実行できません

  • [#3448] 不必要な競合を減らし、不足しているロックを削除します

  • [#3451] ローカルトランザクションが使用されていない場合に自動コミットを true に設定する問題を修正しました。ロックの競合に失敗すると、グローバル トランザクションが終了し、グローバル行ロックとデータのダーティ ライトが無効になります。

  • [#3481] consul client が例外をスローするため、seata ノードのリフレッシュに失敗する問題を修正しました。

  • [#3491] README.md のタイプミスを修正

  • [#3531] ブランチ トランザクションを取得する際の RedisTransactionStoreManager の NPE を修正しました

  • [#3500] Oracle と postgreSQL が列情報をクエリできない問題を修正しました

  • [#3560] コミット状態のトランザクションの非同期タスクに時間しきい値がなく、トランザクションを回復できない問題を修正

  • [#3555] jdbc 例外を無効にするために setBlob を呼び出さないでください

  • [#3540] サーバー配布の欠落ファイルを修正

  • [#3597] 発生する可能性のある NPE を修正

  • [#3568] ConcurrentHashMap.computeIfAbsent デッドロック問題によって引き起こされる自動データソース エージェントを修正

  • [#3402] 更新されたSQLのフィールド名にデータベース名が含まれるため、更新された列が解決できない問題を修正

  • [#3464] テストケース NPE と StackTraceLogger のログを修正しました。

    • [#3522] AT ブランチが競合ロックを必要としない場合のレジスタ ブランチとストア アンドゥログを修正しました。
    • [#3635] zookeeper で設定が変更されたときにプッシュ通知が失敗する問題を修正しました
    • [#3133] グローバルロックの取得を再試行できない問題を修正
    • [#3156] SpringProxyUtils.findTargetClass のロジックを最適化します。

    最適化：

    • [#3341] 指定された構成ファイルへのパスの形式を最適化します。
    • [#3385] github アクションを最適化し、単体テストの失敗を修正
    • [#3175] スノーフレーク アルゴリズムの「履歴時間」バージョンを使用して UUIDGenerator を改善しました
    • [#3291] mysql jdbc 接続パラメータ
    • [#3336] System.getProperty を使用した netty 構成プロパティの取得をサポート
    • [#3369] dockerHub の github アクション シークレット環境を追加
    • [#3343] CI プロバイダーを Travis CI から Github に移行する アクション
    • [#3397] 変更記録フォルダーを追加します
    • [#3303] は、単一の Nacos dataId からのすべての構成の読み取りをサポートします
    • [#3380] globalTransactionScanner リスナーの最適化
    • [#3123] Seata-server のパッキング戦略を最適化します。
    • [#3415] Maven Clean プラグインを最適化して配布ディレクトリをクリアします
    • [#3316] 設定値の読み取り中にプロパティ Bean が初期化されない可能性がある最適化
    • [#3420] 列挙型クラスを最適化し、単体テストを追加します
    • [#3533] 現在のトランザクション ロールを取得するためのインターフェイスを追加しました
    • [#3436] SQLType クラスのタイプミスを最適化します
    • [#3439] XML Bean よりも前に呼び出せるように springApplicationContextProvider の順序を調整します。
    • [#3248] client ノードに属するようにロードバランス移行の構成を最適化します。
    • [#3441] スターターの自動設定処理を最適化します。
    • [#3466] 文字列比較はequalsIgnoreCase()を使用します
    • [#3476] サポート 渡されたサーバーパラメータがホスト名である場合、自動的に IP に変換されます
    • [#3236] ロック解除の実行条件を最適化します
    • [#3485] ConfigurationFactory の無駄なコードを最適化します。
    • [#3505] GlobalTransactionScannerクラスの無駄なif判定を最適化します。
    • [#3544] 自動生成されたキーが false の場合に、自動による取得 pk を最適化します。
    • [#3549] DBストレージモード使用時の異なるテーブルのxidの長さを統一しました。
    • [#3551] RETRY_DEAD_THRESHOLD を大きくして構成可能にします
    • [#3589] JUnit APIの使用法による例外チェックを変更
    • [#3601] LoadBalanceProperties を spring-boot:2.x 以降と互換性を持たせる
    • [#3513] Saga SpringBeanService 呼び出しサポート スイッチ json パーサー
    • [#3318] CLIENT_TABLE_META_CHECKER_INTERVAL を構成可能にします
    • [#3371] メトリックの applicationId を追加します
    • [#3459] 重複した validAddress コードを削除します
    • [#3215] ファイルモードでの起動時のリロードを選択します
    • [#3631] nacos-config.py パラメータを最適化します
    • [#3638] SQL で結合を使用して更新または削除を使用するときのエラーを最適化します。
    • [#3523] Oracle 使用時のリリース セーブポイントを最適化します。

  • [#3458] 削除されたMDを元に戻します

    • [#3574] EventBus.java ファイルのコメントのスペル エラーを修復します
    • [#3573] README.md のデザイナー ディレクトリ パスを修正
    • [#3662] GPG キーを更新します
    • [#3664] 一部の Javadoc を最適化します。
    • [#3637] 参加企業とプルリクエスト情報を登録します

    テスト

    • [#3381] tmClient のテスト ケース
    • [#3607] EventBus 単体テストのバグを修正しました
    • [#3579] StringFormatUtils のテスト ケースを追加
    • [#3365] ParameterParserTest テスト ケースの最適化が失敗しました
