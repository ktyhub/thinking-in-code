incubator-seata v1.7.0

マイナー 公開日2023年7月11日 出典apache/seata 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

インキュベーターシート v1.7.0

シータ1.7.0発売。

Seata は、使いやすく、高性能の、オープンソースの分散トランザクション ソリューションです。

バージョンは以下のように更新されます。

機能:

  • [#5476] seata-client の最初のサポート native-image
  • [#5495] コンソール統合 saga-statemachine-designer
  • [#5668] バージョン 1.4.2 以下の file.conf および registry.conf 構成と互換性があります

バグ修正:

  • [#5682] サーガモードのリプレイコンテキストが失われた startParams を修正
  • [#5671] サガモードのserviceTask inputParams json autoType変換例外を修正
  • [#5194] テーブル作成時の oracle の間違ったキーワード順序を修正しました
  • [#5021] JDK17 で失敗した Spring オリジン プロキシの JDK Reflection を修正しました
  • [#5023] seata-dubbo での seata-core 依存関係の推移的な競合を修正しました。
  • [#5224] Oracle初期化スクリプトindex_nameが重複している問題を修正
  • [#5233] LoadBalance に関連する一貫性のない構成項目名を修正しました。
  • [#5266] サーバーコンソールが解放されたロックをクエリした問題を修正しました
  • [#5245] 配布モジュールの不完全な依存関係を修正
  • [#5239] JDK プロキシを使用するときに getConfig が ClassCastException をスローする問題を修正しました。
  • [#5281] 並列リクエスト ハンドルが IndexOutOfBoundsException をスローする
  • [#5288] AT モードの Oracle での pk 列の自動インクリメントを修正しました
  • [#5287] AT モードの PostgreSQL での pk 列の自動インクリメントを修正しました
  • [#5299] ロールバック再試行またはコミットタイムアウト再試行時の GlobalSession 削除を修正しました
  • [#5307] キーワードにエスケープ文字が追加されない問題を修正
  • [#5311] ファイルストレージ内のリカバリ中に RollbackRetryTimeout セッションを削除します
  • [#4734] AT モードでテーブル メタ キャッシュを更新する必要があるかどうかを確認します
  • [#5316] jdk8 の G1 jvm パラメータを修正
  • [#5321] TC 側のロールバック ロジックが RollbackFailed を返した場合、カスタム FailureHandler が実行されない問題を修正しました。
  • [#5332] 単体テストで見つかったバグを修正
  • [#5145] グローバルセッションが常にsagaモードで開始される問題を修正
  • [#5413] 不正なサービス構成ファイルとコンパイルの失敗を修正
  • [#5415] client 側でフックと FailureHandler が実行されないトランザクション タイムアウトを修正しました。
  • [#5447] 同じデータベースでは oracle xa モードを使用できない問題を修正しました
  • [#5472] RM で @GlobalTransactional を使用すると ShouldNeverHappenException がスローされる問題を修正しました
  • [#5535] ログ ファイルのパスが正しくロードされていなかった問題を修正しました
  • [#5538] 完了したトランザクションがコミット時に例外を飲み込む問題を修正しました。
  • [#5539] Oracle 10g の「setDate」条件によるテーブル全体のスキャンの問題を修正しました。
  • [#5540] DB ストレージ モードで GlobalStatus=9 をクリアできない問題を修正しました
  • [#5552] mariadb のロールバックが失敗する問題を修正しました
  • [#5583] grpc インターセプターの XID バインド解除の問題を修正
  • [#5602] 参加者トランザクション ロールのログインを修正しました
  • [#5645] Oracle 挿入取り消しログの失敗を修正
  • [#5659] キーワードにエスケープ文字を追加した後にデータベースで大文字と小文字が区別される問題を修正しました
  • [#5663] connectionProxyXA 接続が再利用されるときにタイムアウトが null になる問題を修正しました
  • [#5675] xxx.grouplist と grouplist.xxx 構成項目間の互換性を修正しました
  • [#5690] コンソールの印刷 unauthorized error を修正
  • [#5711] 取得構成項目に下線付きのエラーが含まれている問題を修正しました

最適化:

  • [#5208] スロー可能な getCause を再度最適化します
  • [#5212] ログメッセージレベルを最適化します
  • [#5237] 例外ログメッセージの印刷を最適化します(EnhancedServiceLoader.loadFile#cahtch)
  • [#5089] TCCフェンスログクリーンタスクの遅延値のチェックを最適化します。
  • [#5243] kryo 5.4.0 を最適化し、jdk17 との互換性を最適化します。
  • [#5153] ATモードのみ他のアプリでチャンネルを取得しようとします
  • [#5177] server.session.enable-branch-async-remove が true の場合、ブランチを非同期的に削除し、同期的にロックを解除します。
  • [#5273] protobuf-maven-plugin プラグインのコンパイル構成を最適化し、上位バージョンで長すぎるコマンド ラインの問題を解決します。
  • [#5303] -Xmn 構成の起動スクリプトを削除します
  • [#5325] ストア モード、構成タイプ、レジストリ タイプのログ情報を追加
  • [#5315] SPIのログを最適化します
  • [#5323] グローバル トランザクション タイムアウト ログの時間情報を追加
  • [#5414] トランザクション失敗ハンドラーを最適化します
  • [#5537] client側のトランザクションログを最適化します
  • [#5541] サーバーログ出力を最適化します
  • [#5548] 有効期限切れの GPG キーを更新し、ワークフローを公開します
  • [#5638] 最適化: サーバーのトランザクション レベルを READ_COMMITTED に設定します
  • [#5646] ColumnUtils と EscapeHandler をリファクタリングします
  • [#5648] サーバーログの印刷を最適化します
  • [#5647] テーブルと列のメタデータの大文字と小文字を区別する属性をサポートします
  • [#5678] 列名の場合のエスケープ文字を最適化します。
  • [#5684] CodeQL、スカイウォーキングアイ、チェックアウトの github アクションを最適化します。
  • [#5700] 分散ロックログを最適化します

セキュリティ:

  • [#5172] いくつかのセキュリティ脆弱性を修正
  • [#5683] ヘシアン シリアライザー WhiteDenyList を追加
  • [#5696] いくつかの node.js セキュリティ脆弱性を修正

テスト:

  • [#5380] UpdateExecutorTest の失敗を修正しました
  • [#5382] マルチスプリングバージョンのテストが失敗した問題を修正

コードをコミットしてくれたこれらの貢献者に感謝します。意図しない省略があった場合はご報告ください。
