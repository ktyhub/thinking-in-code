インキュベーターシート v1.4.0

シータ1.4.0発売。

Seata は、使いやすく、高性能の、オープンソースの分散トランザクション ソリューションです。

バージョンは以下のように更新されます。

特徴：

  • [#2380] yml 設定をサポート
  • [#3191] jdbc タイプ nclob をサポート
  • [#2676] 最小アクティブ負荷分散をサポート
  • [#3198] spring boot のカスタム構成とレジストリ タイプのサポート
  • [#2806] デフォルトのグローバル トランザクション タイムアウトミリスの構成をサポート
  • [#2941] apollo 秘密鍵構成を追加
  • [#2080] ConsistentHashLoadBalance をサポート
  • [#2950] redisモジュールのリエントラントロックをサポート
  • [#2913] データ ソース プロキシ モードは AT または XA として選択できます
  • [#2856] Fst シリアル化を使用した undoLog のサポート
  • [#3076] @GlobalLock を使用するときに TC でロックをチェックします
  • [#2825] 認証メッセージの送信をサポート
  • [#2962] @GlobalTransactional と @GlobalLock はロック再試行構成のカスタマイズをサポートできます

バグ修正：

  • [#3214] 場合によっては「RootContext.DEFAULT_BRANCH_TYPE」が間違っている問題を修正

  • [#3129] pk値を更新するSQLの実行を禁止します

  • [#3205] 設定でブール値を取得できない問題を修正しました

  • [#3170] ディスポーザブル ツリー セットは、同じ優先度を持つ別のディスポーザブルを受け入れません

  • [#3180] シリアライザー fst パッケージ名エラー

  • [#3178] 次の行をスペースに削除します

  • [#2929] アプリケーションが起動時に機能を低下させるように構成されており、アップグレードされたものに動的に切り替えることができない問題を修正しました。

  • [#3050] ステートメントの削除および更新時の画像の前のフェッチを修正しました

  • [#2935] ノード切り替え時にプロパティボックスが切り替わらないというサガデザイナーのバグを修正

  • [#3140] Propagation.REQUIRES_NEW を修正し、いくつかのコメントを追加

  • [#3130] 自動データ ソース プロキシのいくつかの問題を修正しました

  • [#3148] redis ロック キーとセッション キーが競合しています

  • [#3136] redis パイプラインを修正

  • [#2551] dataSourceがATのdataSourceProxyの場合、Sagaは使用できません

  • [#3073] xid なしで接続をプロキシしません

  • [#3074] XA スキーマが XID を見つけられない場合、再試行する必要はありません

  • [#3097] Springboot 環境で HttpAutoConfiguration が常にインスタンス化される問題を修正しました

  • [#3071] 接続の一部がアンパックされていません

  • [#3056] ブランチ削除後もブランチロックが残っているバグを修正

  • [#3025] 間違ったパッケージ パスを修正

  • [#3031] redis ロッカー削除ロックが不完全

  • [#2973] フィールドサイズが1000を超えるOracleデータベースを修正しました

  • [#2986] checkstyle プラグインが単一のファイルを除外できない問題を修正

  • [#2910] エラー レジストリ タイプ コメントを修正

  • [#2914] コンシューマが TCC モードの場合に BranchType がクリーンアップされない問題を修正しました

  • [#2926] fastjson パーサーではなく元に戻すログの書き込み

  • [#2897] ジェディスのロック解除失敗を修正

  • [#2918] AT モードでのロールバック時の分離の問題を修正

  • [#2972] UUIDGenerator が重複した ID を生成する

  • [#2932] nacos-config.py スクリプトは名前空間で実行できませんでした

  • [#2900] ColumnUtils でスキームを使用したエスケープを追加

  • [#2904] getConfig キャッシュ値が「null」である問題を修正しました

    • [#2890] statelang の例のスペルミスを修正
    • [#3040] 自動コミットが false の場合に繰り返されるコミットを修正しました
    • [#3230] @EnableAutoDataSourceProxy の起動に失敗した問題を修正しました。
    • Sharingjdbc と統合された結果セットの [#2979] 列は小文字である必要があります
    • [#3233] コレクション NPE を修正
    • [#3242] バッチ SQL getTableMeta エラーを修正
    • [#3246] 制限条件に VariantRefExpr が含まれる場合の例外を修正しました

    最適化：

    • [#3062] redis セッション ストアをリファクタリングします
    • [#3201] 間違ったスタックが完全に表示されない最適化
    • [#3117] ログをより明確にし、無駄なコードを削除します
    • [#3134] マップとリストに関連するコードを最適化します
    • [#3195] XID関連コードを最適化します
    • [#3200] メッセージが部分文字列だった場合の RPC メッセージを最適化します
    • [#3186] 文字列 utils 内の重複を削除します
    • [#3162] 繰り返しの条件テストを削除します
    • [#2969] ドルイド 1.1.23 にアップグレード
    • [#3141] nacos と FastJSON の依存関係をアップグレードします
    • [#3118]Additional-spring-configuration-metadata.json に構成ヒントを追加します。
    • [#2597] 処理の繰り返しを避けるために xid ステータスを判断する
    • [#3102] ContextCore を最適化し、「Object」値を設定できるようになりました
    • [#3016] redis ロック文字列をハッシュにリファクタリングします
    • [#3046] シリアライザー ファクトリで未使用のコードを削除します
    • [#3053] jedis プールに maxtotal 構成が追加されました
    • [#3012] 設定ポートを繰り返し削除します
    • [#2978] AT と TCC の混合使用のために globalCommit を最適化します。
    • [#2967] ラムダに置き換えます
    • [#2968] RM client の初期化後に登録メッセージが送信されるようにします
    • [#2945] 非同期コミットを最適化し、更新を 1 つ削減します
    • [#2952] 追加スプリング構成メタデータを最適化します。json
    • [#2920] いくつかの文法エラーを最適化
    • [#2906] 公式ドキュメントとの一貫性を保つためにいくつかの設定項目を追加しました
    • [#3222] fileListener を最適化して CPU 時間の使用量を削減します
    • [#2843] redis/db SessionManager からリロード可能を削除しました
    • [#3209] 会社ロゴを使用して追加
