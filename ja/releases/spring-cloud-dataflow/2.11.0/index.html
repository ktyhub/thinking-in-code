spring-cloud-dataflow v2.11.0

spring-cloud-dataflow v2.11.0

注目すべき

Spring Boot 3 つのアプリケーション

  • Spring Boot 3.x ベースのストリーム アプリケーションのサポートを追加します。
  • Spring Cloud Task 3.x ベースのタスク アプリケーションのサポートを追加します。
  • Spring Batch 5.x ベースのバッチ アプリケーションのサポートを追加します。

詳細については、Boot 3 付録 を参照してください。

ライブラリの更新

  • Spring Boot 2.7.15
  • スプリングクラウド 2021.0.8

Kubernetes アップデート

  • 待望の Kubernetes cron ジョブのバッチ/v1beta -> バッチ/v1 の更新により、ユーザーは Kubernetes >= 1.25.0 を実行できるようになります。
