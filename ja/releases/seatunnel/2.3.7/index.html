seatunnel 2.3.7

パッチ 公開日2024年8月19日 出典apache/seatunnel 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

シートトンネル 2.3.7

バグ修正

コネクタ V2

  • [Hotfix][MySQL-CDC] mysql バイナリ読み取り時の ArrayIndexOutOfBoundsException を修正 (#7381)
  • [修正][ドリス] ドリスの主キーの順序とフィールドの順序が矛盾している問題を修正 (#7377)
  • [バグ修正][Doris] Json シリアル化、null 値によりデータ エラーが発生する問題を修正 (#7379)
  • [ホットフィックス][Jdbc] jdbcコンパイルエラーを修正 (#7359)
  • [修正][OceanBase] mysql ドライバーに対する OceanBase カタログの依存関係を削除 (#7311)
  • [修正][Tdengine] taos に接続してデータを読み取るときの SQL 例外と concurrentmodifyException を修正 (#6088)
  • [Hotfix][Kafka] Kafka コンシューマ ログの次回起動オフセットを修正 (#7312)
  • [修正][Doris] CDCシナリオにおけるデータ削除の異常を修正。 (#7315)
  • [ホットフィックス][Hbase] hbase ソースの問題を修正および最適化します (#7148)
  • [修正][Iceberg] 識別子「Iceberg」のソースを作成できません。 #7182 (#7279)

ゼータ(STエンジン)

  • [Fix][Zeta] ロックメトリクスの失敗によりタスクを終了できない問題を修正 (#7357)
  • [Hotfix][Zeta] システムがビジー状態のときにタスクを停止できない問題を修正 (#7292)
  • [Hotfix][Zeta] システムがビジー状態のときにタスクを停止できない問題を修正 (#7280)

E2E

  • [修正][HTTP] http e2e ケースを修正 (#7356)

改善する

コア

  • [改善][Flink]メソッド名を最適化 (#7372)
  • [改善][API] ダウンストリームに送信する前にカタログ テーブルのフィールド名が正当であることを確認する (#7358)
  • [改善][Flink] flink プロキシ ソース/シンクをリファクタリング (#7355)
  • [改善][API] TablePath のテーブル名が null でないことを確認します (#7252)
  • [改善][コア] ルックアップ戦略のプラグイン名に基づいて改善 (#7278)

コネクタ V2

  • [改善][マルチテーブル] マルチテーブルシンクオプションチェックを追加 (#7360)
  • [改善][コンソール] ConsoleSinkFactory.java を更新 (#7350)
  • [改善][Jdbc] テーブルの自動作成時にすべてのインデックスをスキップして、書き込みのパフォーマンスを向上させます (#7288)
  • [改善][ドリス] ドリスのエラーメッセージを改善 (#7343)
  • [改善][Jdbc] JdbcDialect の MysqlType 参照を削除 (#7333)
  • [改善][Jdbc] テーブル作成時にユーザー設定の主キーをマージする (#7313)
  • [改善][Jdbc] データベースとテーブルの存在チェック方法を最適化します (#7261)

変換 V2

  • [改善][DynamicCompile] DynamicCompile変換を改善(#7319)
  • [改善][SQL] 出力フィールドからエスケープ識別子を削除 (#7297)
  • [改善][DynamicCompile] DynamicCompile変換を改善(#7264)

E2E

  • [改善][改善]spark/flinkのfakesource e2eを有効にする (#7325)
  • [改善][改善] JdbcPostgresIdentifierIT を有効にする (#7326)
  • [改善][改善]パイモンのe2eのサポートウィンドウ (#7329)

機能

コネクタ V2

  • [機能][Aliyun SLS] Aliyun SLS コネクタ #3733 (#7348) を追加
  • [機能][Activemq] activemq シンクを追加しました (#7251)

変換 V2

  • [機能] 変換を分割し、jar をコネクター ディレクトリに移動 (#7218)
  • [機能][LLM] LLM変換を追加 (#7303)
  • [機能][SQL] SQLのバイトへのキャスト機能をサポート (#7284)

ドキュメント

  • [ドキュメント] setup.md の非推奨のコネクタ名を変更する (#7366)
  • [ドキュメント] sftp シンクドキュメントのユーザー名パラメータエラーを修正 (#7334)
  • [Docs] oss がチェックポイント ベースとして選択されている場合にドキュメント構成が修正されるように修正 (#7332)
  • [ドキュメント] サイドバーのsink-options-placeholders.mdのミスを修正 (#7310)
  • [ドキュメント] Oracle-CDC.md を更新する (#7285)
  • [ドキュメント] ハイブリッド クラスター展開ドキュメントの表示エラーを修正 (#7306)
  • [ドキュメント] イベントリスナードキュメントを中国語に翻訳 (#7274)

その他

  • org.apache.activemq:activemq-client をバンプする (#7323)
  • [改善] 未使用のコードを削除 (#7324)
  • [改善] スナップショットのバージョンを 2.3.7 に更新 (#7305)
