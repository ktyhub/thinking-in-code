#シートトンネル3.1.0

3.1.0 Release Note

これは、バージョン 3.0.0 に続く、Apache SeaTunnel のもう 1 つの重要なリリースです。

バージョン 3.1.0 には、Zeta エンジンの安定性と Connector-V2 データの正確性に重点を置いた、395 個の PR と 11 個の新しいコネクタが含まれています。また、導入、運用、データ変換も改善され、実稼働データ統合ジョブの信頼性が高まります。

このアップデートに尽力してくれたすべての寄稿者に感謝します。バージョン 3.1.0 は、より安定した信頼性の高いデータ統合エクスペリエンスをコミュニティに提供すると信じています。

ハイライト

  • ネイティブ Kubernetes アプリケーション モード: ジョブごとに専用のマスターと固定数のワーカーをデプロイし、ジョブ終了時の自動リソース クリーンアップにより、1 回限りのデータ処理ジョブや大規模なバッチ ワークロードを実行するチームにリソースの分離とオンデマンドのリソース解放を提供します。
  • Java の最小バージョンは 11 に引き上げられ、Java 17 までサポートされます。
