#シートトンネルv3.0.0

3.0.0 Release Note

これは、Apache SeaTunnel プロジェクトにとって素晴らしいマイルストーンです。
バージョン 3.0.0 のリリースは、927 個の PR、30 個の新しいコネクタ、および Zeta エンジン、Connector-V2、および CLI にわたる大幅な改善を含むメジャー アップデートであり、ユーザーのデータ統合ワークフローの効率が大幅に向上します。

私たちは、このアップデートに貢献した方々の献身と努力に本当に感銘を受けており、この新しいバージョンがコミュニティに広く歓迎されるものと確信しています。
