2.3.5 Release Note

バグ修正

コア

  • [修正][Kafka-Sink] Kafka シンクのファクトリー オプション ルールを修正 (#6657)

  • [修正][ドキュメント] FTP シンク設定キー username を user に修正 (#6627)
  • [E2E] AmazondynamodbIT の不安定性を修正 (#6640)
  • [修正][Connector-V2] パーティションが既に存在する場合のハイブ パーティションの追加エラーを修正 (#6577)
  • [修正][Connector-V2] doris/starrocks 作成テーブル SQL 解析エラーを修正 (#6580)
  • [修正][Connector-V2] ストリームロードでデータが読み込まれない場合に doris シンクを閉じることができない問題を修正 (#6570)
  • [修正][Connector-V2] コネクタのサポート SPI を修正しましたが、引数コンストラクターがありませんでした (#6551)
  • [修正][Connector-V2] doris ソース選択フィールドの主キー情報の損失を修正 (#6339)

  • [修正][Connector-V2] mongodb cdc 起動モードのオプション値が正しくない問題を修正 (#6338)
  • [BugFix][Connector-file-sftp] SFTPInputStream.close がファイル ストリームのクローズを正しくトリガーしない問題を修正 (#6323) (#6329)
  • [修正] doris ストリームのロード失敗が報告されないエラーを修正 (#6315)
  • [修正][connector-rocketmq]checkpoint.interval の設定が小さすぎる場合の NPE の問題を修正(#6624)
  • [バグ修正][TDengine] サブミットジョブ REST API への複数の呼び出しによりドライバーが失われる問題を修正 #6581 (#6596)
  • [修正][StarRocks] 上流のカタログ可能テーブルのパスにテーブル名部分しかない場合の NPE を修正 (#6540)

フォーマット

  • [バグ] [フォーマット] コンテンツにファイル区切り文字が含まれている場合に行の解析に失敗する問題を修正 (#6589)

  • [ホットフィックス] http ソースが yyyy-MM-dd HH:mm:ss 形式を読み取れないバグを修正し、DateTime ユーティリティを改善しました (#6601)
