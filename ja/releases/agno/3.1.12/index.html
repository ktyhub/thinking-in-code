#アグノv3.1.12

#Changelog

新機能:

  • ハーネス エージェントのネイティブ承認: クロードとコーデックス自身の権限リクエストが AgentOS 承認 UI に到達するようになりました。エージェントにデータベース (AgentOS が提供するデータベースを含む) がある場合、ネイティブ リクエストは、既存のチャット ビューと承認ビューに表示される一時停止中の実行を永続化し、解決と実行の続行により、プロンプトを再実行せずに同じネイティブ実行に決定を返します。ハーネス独自のポリシーがいつ要求するかを決定します。Claude は permission_mode と明示的な許可コールバックを維持し、Codex は既存の SDK auto_review および deny_all モードとともに approval_policy="on-request" | "untrusted" | "never" をサポートします。そのため、個別の Agno 設定をオンにする必要はありません。決定は、同期および非同期の継続、キャンセル、有効期限およびストレージ障害の処理によって、要求された正確なアクションに対して検証され、サンドボックス エージェントはこれを Docker と AgentCore 間で維持します。機能ネゴシエーション、決定 RPC、フェンスされた永続性、API ワーカー喪失後の再接続、個別の承認待機予算と実行予算、およびプロセス喪失後の再実行なし。承認設定のない CodexAgent はネイティブ on-request ポリシーの下で実行されるようになったので、以前はどこにも行かなかったリクエストは代わりに実行を一時停止することに注意してください。 hitl_timeout (デフォルトは 900 秒) は、待機時間を制限します。 cookbook/frameworks/human_in_the_loop/を参照してください。
  • 初期的に無効になっている会社のルーチン: Routine(enabled=False) を使用すると、テンプレートは非アクティブなルーチンを出荷でき、後でユーザーが UI から有効にすることができます。True は引き続きデフォルトです。無効化されたルーチンはアトミックに作成され、製品へのリンクを維持してリストに表示され、スケジューラによってスキップされ、再起動後もユーザーが保存した選択が保持されます。このフラグは、Python および YAML ブートストラップ、API のセットアップと作成、同期および非同期の Company Manager、および Company ツールで尊重されます。重複した作成リクエストは依然として 409 を返し、既存のルーチンを有効にすることができません。また、既存の一時停止/再開エンドポイントは再作成しなくても有効にします。 cookbook/05_agent_os/30_company/11_disabled_routine.pyを参照してください。
  • チャートの見出し番号: ChartTools.create_chart() は、オプションのフォーマット済み value ("$22.3K" や "94%" などの合計値または最新値) を受け取り、チャート ブロック内で "value" として出力され、チャート タイトルの横に Agno OS によってレンダリングされます。 docstring は、チャートを要約する単一の数値がない場合はそれを省略するようにモデルに指示するため、平均と率は合計されません。

改善点:

  • 会社ルーチンの並べ替え: GET /company/routines は next_run_at、schedule_type、enabled によっても並べ替えられるようになり、Agno OS はルーチン テーブルを次回の実行時間、スケジュール、およびアクティブによって並べ替えることができます。一時停止されたルーチンとオンデマンドのルーチンには今後の実行がないため、どちらの方向でも最後になり、同じ値を持つルーチンは作成順序を維持します。
  • クックブック: ツール フックでアクターのアイテム数を制限し、各データセット アイテムをタイトル、会社、場所、投稿日、リンクにトリミングする ApifyTools 求人検索の例を追加しました。これにより、広範な検索がコンテキスト内で小規模に留まります。ローカルの sentence-transformers 埋め込みと Ollama を使用して、langchain-pixeltable を通じてチャンクを書き込み、LangChainVectorDb でそれらを検索する、完全にローカルな Pixeltable RAG サンプルを追加しました。埋め込み API キーや個別のベクトル データベース サーバーはありません。

バグ修正:

  • FastAPI ネイティブ トレース: FastAPI 0.142.0 は、グローバル トレーサ プロバイダーが存在するとすぐに独自の OpenTelemetry トレースを有効にし、AgentOS(tracing=True) がインストールするため、FastAPI のリクエスト スパンは Agno のリクエスト スパンと一緒に保存されました。すべての実行はリクエスト スパンの子となり、トレースは空の run_id、session_id、agent_id を含む fastapi.dependencies として記録され、[実行] ビューが壊れる一方、各 UI リクエストは独自のトレースを保存しました。 AgentOS は、FastAPI のトレースから構築するアプリを選択し、setup_tracing() が外部スパンをフィルター処理して、保存されたトレースが Agno 実行にルートされるようになりました。 tracing=True のないアプリは FastAPI のデフォルトを保持し、ツール内で作成されたユーザー独自のスパンも引き続き保持されます。
  • 会社ルーチンのキャンセル: POST /company/routines/{id}/cancel は、実行者が要求を受け入れるとすぐに実行を cancelled として記録しましたが、エージェントは次のチェックポイントでのみ停止します。そのウィンドウでは、エージェントがまだ動作しており、実行中にアーカイブ、削除、実行者の変更が行われている間に、API が cancelled を報告しました。ルートは永続的な証拠からのみステータスを記録するようになりました。ライブ実行は ScheduleExecutor が解決するまで放置され、終了した実行はスケジューラ独自のマッピングを通じて書き込まれ、欠落した実行は cancelled に記録され、タイムアウトを過ぎてクラッシュした実行はアーカイブ、削除、実行者の変更をブロックしなくなりました。
  • AccuracyEval Judge: model と evaluator_agent のない AccuracyEval は、OpenAI が 2026 年 10 月 23 日にシャットダウンした OpenAIChat(id="o4-mini") を使用してジャッジを構築していました。そのため、すべてのジャッジ呼び出しで 404 model_not_found が返され、反復スコアは付けられず、評価では背後のプロバイダー エラーではなく空の実行が報告されました。デフォルトは gpt-5.6-terra になり、これは o4-mini の代替 OpenAI リストです。廃止されたモデルを固定した例も移行され、OpenAIChat がこれらのモデルの関数ツールを拒否するため、精度の例が OpenAIResponses に切り替わります。
  • アップロードごとのナレッジ チャンキング: POST /knowledge/content はアップロードごとの chunker、chunk_size、chunk_overlap を受け入れ、process_content() はそれらを content.reader (ナレッジ ベース上の共有カスタム リーダーまたは既に解決されたリーダー) に直接適用しました。その後、そのリーダーを使用してアップロードするたびに、プロセスが再開されるまで、前のアップロードのチャンカーが保持されます。アップロードでは、チャンク戦略が適用される前に、リーダーの独自の浅いコピーが取得されるため、ナレッジ ベースは独自の構成を保持します。

何が変わったのか

  • 修正: アップロードごとのチャンカー オプションをナレッジ ベース リーダーから除外する (https://github.com/agno-agi/agno/pull/11327 の @sunhouy による)
  • 修正: https://github.com/agno-agi/agno/pull/11347 の @kausmeows により、AccuracyEval ジャッジとサンプルを廃止された OpenAI モデルから移動しました。
  • [クックブック] @pierrebrunelle によるローカル Pixeltable RAG サンプルを https://github.com/agno-agi/agno/pull/11314 に追加
  • [クックブック] https://github.com/agno-agi/agno/pull/11305 の @johnisanerd による、制限された実行とトリミングされた結果を含む ApifyTools ジョブ検索
  • 功績: ChartTools チャートにヘッドライン番号を表示 (https://github.com/agno-agi/agno/pull/11110 の @anuragts により)
  • 修正: https://github.com/agno-agi/agno/pull/11346 の @kausmeows による Agno トレースから FastAPI ネイティブ スパンを除外
  • 修正: 実行が停止した場合にのみルーチン キャンセルを記録する [SDK-643] @harshsinha03 (https://github.com/agno-agi/agno/pull/11352)
  • 雑用: @ashpreetbedi による README (https://github.com/agno-agi/agno/pull/11380)
  • 功績: https://github.com/agno-agi/agno/pull/11372 の @ashpreetbedi により、当初無効になっていた会社ルーチンをサポート
  • 偉業: https://github.com/agno-agi/agno/pull/11374 の @ashpreetbedi により、AgentOS を介してネイティブのクロードとコーデックスの承認をルーティングします。
  • 機能: ルーチンを次回の実行、スケジュール タイプで並べ替え、https://github.com/agno-agi/agno/pull/11382 の @Ayush0054 によって有効化
  • 雑務: https://github.com/agno-agi/agno/pull/11383 の @kausmeows によるコア リリース v3.1.12
