agno v3.0.6

#アグノv3.0.6

Changelog

新機能

  • ステートレス MCP サービス。 MCPConfig(stateless=True) はセッション追跡なしで /mcp をサービスするため、どのレプリカもあらゆるリクエストに応答でき、マルチインスタンスの展開にはセッション アフィニティが必要ありません。サーバーから開始される通知と SSE の再開にはコストがかかるため、デフォルトではオフのままです。 クックブックを参照してください。
  • MCPTools(protocol_mode=...) は、どの MCP プロトコル時代をネゴシエートするかを選択します。デフォルトは "legacy" で、今日のセッションベースの動作が維持されます。 "auto" は、最新時代の両側サポートをネゴシエートします (2026-07-28 からセッションレス)。既存のサーバーは影響を受けません。最新のサーバーは従来のハンドシェイクを引き続き受け入れます。内部的には、MCP client は fastmcp.Client 上に構築されるようになりました。 クックブックを参照してください。
  • AgentOS MCP サーバー カード (GET /mcp/server-card)。提供されるツールのリストと、構成可能な名前、バージョン、手順が記載されています。
  • AgentOS での .zip および .eml ファイルのアップロード。 クックブックを参照してください。
  • AuthorizationConfig.excluded_route_paths は、認証をグローバルに無効にすることなく、カスタム ルートをパブリックとしてマークします。
  • Bedrock: 独自の非同期 client をモデルまたはエンベッダーに渡します。

バグ修正

  • 人間的: リプレイ アシスタントが逐語的に変換するため、思考ブロックが拒否されなくなります。
  • Gemini: image/jpeg をハードコーディングする代わりに、画像の MIME タイプを解決します。
  • RecursiveChunking: 重複した後続チャンクの出力を停止します。
  • AG-UI: RunContext の代わりにワイヤー フィールドをリモート エンティティに送信します。
  • AG-UI: ストリーミング実行エラーを公開します。
  • tree-sitter-language-pack<1.16 をピン留めして、chonkie コード チャンカーのブロックを解除します。

何が変わったのか

  • [修正] https://github.com/agno-agi/agno/pull/9887 の @BlueX888 によるハードコーディング画像/jpeg の代わりに Gemini 画像の MIME タイプを解決する
  • 修正: https://github.com/agno-agi/agno/pull/9901 の @Himanshu040604 による Chonkie コード チャンカーのブロックを解除するために Tree-sitter-Language-pack<1.16 を固定
  • 偉業: MCP client および AgentOS サーバーを mcp 2.x に移行 (https://github.com/agno-agi/agno/pull/9269 の @ProgrammerPlus1998 により)
  • [修正] https://github.com/agno-agi/agno/pull/9487 の @uuzzrm によるストリーミング AG-UI 実行エラーを公開
  • 特技: https://github.com/agno-agi/agno/pull/9531 の @ddellspe-vl によって提供された bedrock async client のサポート
  • 修正: https://github.com/agno-agi/agno/pull/9909 の @Himanshu040604 により、RunContext の代わりにワイヤー フィールドを AG-UI 経由でリモート エンティティに送信
  • クックブック: @kausmeows による gemini-3.8-flash の例を https://github.com/agno-agi/agno/pull/9916 に追加
  • 修正: https://github.com/agno-agi/agno/pull/9919 の @devYRPauli により、RecursiveChunking が重複した末尾チャンクを出力しないようにしました。
  • 特技: AgentOS MCP サーバーの名前、バージョン、および手順 (https://github.com/agno-agi/agno/pull/9930 の @ashpreetbedi による)
  • 修正: リプレイ Anthropic アシスタントが逐語的に変わるため、https://github.com/agno-agi/agno/pull/9924 で @ysolanky によって思考ブロックが拒否されなくなります。
  • 功績: MCP サーバー カード (/mcp/server-card、https://github.com/agno-agi/agno/pull/9932 の @ashpreetbedi 著)
  • 功績: https://github.com/agno-agi/agno/pull/9949 の @sannya-singal により、MCP サーバー カード上で提供されるツールをリストします。
  • 功績: https://github.com/agno-agi/agno/pull/9295 の @kinKingen によるカスタム パブリック ルートの AuthorizationConfig.excluded_route_paths を追加
  • 特技: AgentOS での .zip および .eml ファイルのアップロードのサポート (https://github.com/agno-agi/agno/pull/9193 の @luisnmartins による)
  • 雑用: https://github.com/agno-agi/agno/pull/9813 の @ysolanky によって AGENTS.md を CLAUDE.md へのシンボリックリンクにします
  • 偉業: ステートレス MCP トランスポートを追加し、https://github.com/agno-agi/agno/pull/9927 の @sannya-singal により fastmcp.Client に MCP clients を構築
  • 雑用: @sannya-singal による v3.0.6 を https://github.com/agno-agi/agno/pull/9907 でリリース
