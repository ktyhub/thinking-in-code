#アグノv3.0.7 #Changelog

新機能

  • agno.knowledge.page のページ ストレージ。 ナレッジは、カタログ メタデータ、ファイル システム テキストおよびベクターをアトミックに公開し、更新が失敗した場合に以前のリビジョンを保存し、境界付き同期および非同期セットアップ、ソース同期、検索、読み取り、リスト、および grep API を公開します。新しいagno[pages]エクストラを介してインストールされます。 (#9963)
    • Knowledge(page_search=PageSearchConfig(...)) は、型付きのトランザクション ローカル プランナー コントロールを提供します。未設定のスキャン設定、コスト、ワーカー数、およびしきい値は、PostgreSQL 設定を継承します。
  • PublicSurface パブリック サービング用: 共有クォータ、リクエストと出力の境界、CORS、および内部サービス認証を使用して、選択されたエージェント、ネイティブ ステートレス MCP、認証された永続同期ワークフローを提供します。 (#9963)
    • 明示的に選択された チーム も REST および gzip サポートにより提供できるようになりました。これらはエージェントの許可、実行、および出力の制限を共有します。名簿は削減され、メンバーのルートは個別に選択されない限り非公開のままになります。 (#9996)
  • PageFileSystem(knowledge=...): files.tools() を通じて明示的に公開される、同期および非同期実行を備えた制限付き読み取り専用ページ ファイルシステム ツールキット。コマンドは、固定されたリビジョンに対して遅延的にページを読み取り、スコープ指定されたメタデータをリストし、制限されたリテラル grep を実行します。シェルを実行したり、ファイルを書き込んだりすることはできません。 (#9997)
  • エージェント依存関係呼び出し可能関数は、既存の agent および run_context に加えて、run_input および session を受け取ることができます。解決はプリフックの前に実行され、モデルの再試行時に成功した値が再利用されます。 add_dependencies_to_context のデフォルトは引き続き False です。 (#9963)
  • AIMLAPI: リクエストには固定の分析専用アトリビューション ヘッダー セットが含まれており、agno.models.aimlapi.AIMLAPI_HEADERS として検査可能で、default_headers 経由でモデルごとにオーバーライド可能で、呼び出し元が指定したキーが優先されます。ヘッダーにはユーザー データは含まれず、ルーティング、モデルの選択、請求には影響しません。デフォルトのモデルも、廃止された gpt-4o-mini から gpt-5.6-terra に移行します。 (#9898)

改善点

  • ワークフローは、発生した実行プログラムの失敗と明示的に失敗した出力の両方について、失敗したステップを StepError として報告し、現在のステップの ID を伝えます。機能レポートは引き続き StepOutput として保持され、エージェント、チーム、およびネストされたワークフロー コンテンツは既存の実行ストリームを保持します。どちらのコンソール ストリーミング プリンタも StepError を明示的にレンダリングし、元の失敗を表示し、古い進行状況出力を消去します。 (#10001)

バグ修正

  • 失敗したワークフローの実行は、ターミナル ストリーミング イベントの前に終了します。 バックグラウンド ストリーム中に一時停止したワークフローは、非ストリーミングの継続中に失敗し、ERROR をデータベースに保存し、追跡されたストリームが PAUSED でスタックしたままになる可能性があります。新しいストリーミングの失敗では、失敗した実行が保存される前に WorkflowError が生成されたため、そのイベントで終了したコンシューマは実行を完全に失う可能性がありました。 (#10001)
    • ネストされたワークフローのガードレールの拒否は、以前は以前の子の副作用を再試行しなくなりました。明示的な skip_on_failure は既存の最終試行ポリシーによって尊重され、通常のエグゼキュータの再試行は保持されます。
  • Meta Llama と AIMLAPI: すべての実行がクラッシュしました。 両方のプロバイダーの _format_message オーバーライドが、位置的に compress_tool_results を渡す OpenAIChat からずれていたため、各呼び出しで TypeError: _format_message() takes 2 positional arguments but 3 were given が発生しました。 (#10031、#9898、#9034 を修正)
  • 人為的: 空のツール引数は保持されます。 引数ゼロの Claude ツール呼び出しは空の入力オブジェクトであり、アダプターはこれを false として扱い、function.arguments を省略しました。ストリーミング解析と非ストリーミング解析ではすべてのツール入力がシリアル化されるため、空の入力は "{}" になります。 (#8970、#8971 を修正)
  • キャッシュされたツール ラッパーは、呼び出し元のフレームを固定しなくなりました。 validate_call は、構築したラッパーに呼び出し元の f_locals を保存し、Function はプロセスが存続する間これらのラッパーをキャッシュします。そのため、Python 3.13 では、キャッシュされたすべてのツールが、スタック上のエージェント、セッション、および実行状態とともにラッピング フレームを生きたままにしていました。名前空間リゾルバーは、バリデーターが構築されるとクリアされます。 (#9941、#9940 を修正)
  • 匿名ネイティブ エージェント JSON は診断をリークしなくなりました: 失敗した実行ではステータス ERROR とネストされたモデル診断を含む HTTP 200 が返されましたが、現在は安全な 503 run_failed であり、ストリーミング エラー保護に一致しています。認証されたオペレーターの診断は影響を受けません。 (#9963)
  • **ソースの再試行、正規リンクの重複排除、公開時のソース バインディング、制限されたページのチェックアウト、およびエージェント継続の依存関係の順序付けにわたる ページ サービングの修正。 (#9996)

重大な変更

  • Knowledge コンストラクター引数はキーワードのみです。 Knowledge("docs") などの位置呼び出しは Knowledge(name="docs") になる必要があります。現在では、content_db が推奨されるスペルです。 contents_db は、同じデータクラス フィールドを共有するサポートされる読み取り/書き込みエイリアスのままであるため、シリアル化、コピー、および dataclasses.replace(..., contents_db=...) は変更されません。両方のキーワードを渡すには、同じオブジェクトが必要です。 (#9963)
  • ページ検索では、暗黙的に 200 を強制するのではなく、構成された PgVector HNSW ef_search が尊重されるため、暗黙的な 200 に依存する展開では、明示的に設定する必要があります。暫定的なメイン ビルドから構築されたページ インデックスには暗黙的な ef_construction=64 が含まれる可能性があり、オペレーター管理の再構築が必要です。セットアップは、自動的に再構築するのではなく、対処可能なエラーを報告します。 (#9963)

何が変わったのか

  • 功績: https://github.com/agno-agi/agno/pull/9963 で @ashpreetbedi が提供するコーディネートされたページとパブリック ドキュメントを追加
  • 修正: ページ配信を修正し、https://github.com/agno-agi/agno/pull/9996 の @ashpreetbedi によって選択された公開チームを追加しました
  • 偉業: https://github.com/agno-agi/agno/pull/9997 の @ashpreetbedi による境界付き読み取り専用ページ ファイルシステムの抽出
  • [修正] agno 3.x: 呼び出し元フレームの名前空間を削除 pydantic は https://github.com/agno-agi/agno/pull/9941 の @basnijholt によってキャッシュされたツール ラッパーを保持します
  • [修正] https://github.com/agno-agi/agno/pull/8970 で @basnijholt による空の Anthropic ツール引数を保持する
  • [修正] AIMLAPI: 壊れた統合を修復し、https://github.com/agno-agi/agno/pull/9898 の @hugoaimlapi による収益帰属ヘッダーを追加
  • 修正: https://github.com/agno-agi/agno/pull/10031 の @kausmeows による LlamaOpenAI._format_message の compress_tool_results を転送
  • 修正: https://github.com/agno-agi/agno/pull/10001 の @ashpreetbedi によるストリーミング エラーの前に、失敗したワークフローの実行を終了する
  • 雑用: @ysolanky による 3.0.7 を https://github.com/agno-agi/agno/pull/10055 でリリース
