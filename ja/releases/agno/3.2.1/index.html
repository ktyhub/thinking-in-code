agno v3.2.1

#アグノv3.2.1 #Changelog

新機能:

  • セッションの圧縮: GET /sessions/{session_id}/compactions は、SqliteDb および PostgresDb に関するセッションの圧縮を最新のものから順にリストし、それぞれ置換されたメッセージの数と前後のトークン数を示します。
  • 会社ファイル: タスクのファイルと共有メモを、GET /company/tasks/{task_id}/files および GET /company/notes を使用して API 経由で読み取ることができるようになりました。それぞれに 1 つのファイルを読み取るための /{path} ルートが付いています。 クックブックを参照してください。

改善点:

  • LinearTools、DiscordTools、および ModelsLabTools: すべてのリクエストに適用される timeout (デフォルトは 30 秒、ModelsLab の場合は 120 秒) を取得します。
  • ExaTools: include_text、exclude_text、user_location、moderation、highlights、subpages を使用できるようになりました。
  • MCPTools: connect() は、接続されている場合は True を返し、接続されていない場合は False を返すようになりました。
  • Qdrant: async_insert は、insert と同様に、batch_size を使用するようになりました。
  • WebSearchTools および DuckDuckGoTools: 検索エラーが JSON の結果として返されるようになりました。
  • スキル: 中国語およびその他の非 ASCII 言語でのスキルの指示、リファレンス、およびスクリプト出力が、読み取り可能な文字としてモデルに送信されるようになりました。
  • AntigravityTools および AntigravityAgent: デフォルトが antigravity-preview-09-2026 になりました。
  • Slack: default_role は、users= に含まれていない Slack メンバーに管理対象ロールの権限を与えます。各メンバーは引き続き本人として記録されます。

バグ修正:

  • SQLTools: 接続フィールドも指定されている場合でも、渡した db_engine が常に使用されるようになり、結果行の読み取りが失敗した場合に run_sql_query がデータベース エラーを返すようになりました。
  • OpenRouter、Perplexity、および Requesty: max_tokens が設定されていない場合、応答ではモデル独自の出力制限が使用されるようになったため、長い応答が完全に返されます。
  • OpenRouterResponses: 実行メトリックとメッセージ メトリックに、OpenRouter がリクエストごとにレポートする cost が含まれるようになりました。
  • トレース: GET /traces は他のトレース ルートと同様に 1 からページをカウントするようになり、page が指定されていない場合、JsonDb および GcsJsonDb は limit を適用します。
  • WebSearchTools および DuckDuckGoTools: max_results=0 は結果を返さないようになり、search_news は modifier を適用します。
  • ExaTools: livecrawl が Exa に提供されるようになり、Exa の概要とハイライトがモデルに提供されるようになりました。
  • PostgresDb: PostgresDb または AsyncPostgresDb でテーブルの作成に失敗した場合、原因が修正されると、次の呼び出しで同じ DB インスタンスがテーブルを作成するようになりました。
  • MCPTools: 失敗またはキャンセルされた connect() は、接続とそれが開始したすべての stdio サーバーを閉じるようになりました。
  • Qdrant: insert(batch_size=...) は、そのサイズのバッチでドキュメントを送信するようになりました。
  • CodexAgent: ネイティブの権限リクエストと質問が openai-codex 0.163.0 以降で機能するようになりました。
  • DaytonaTools: agno[daytona] は、DaytonaTools がサポートする Daytona SDK (daytona<1) をインストールするようになり、インポート エラーでそのバージョンの名前が表示されます。
  • Mistral: agno[mistral] は httpx2 2.16.1 をスキップするようになりました。そのため、MistralChat と MistralEmbedder はきれいにインポートされます。
  • ファイルツールとワークスペース: read_file は、正確に max_file_lines 行を含むファイル全体を返すようになりました。
  • PageMarkdownChunking: C# など、リテラルの # で終わる見出しは、チャンク ブレッドクラムとページ コンテキスト行に保持されるようになりました。
  • DocxReader および PPTXReader: FastAPI の UploadFile.file などの一時ストリームから読み取られた Word および PowerPoint ファイルは、そのコンテンツを返すようになりました。
  • ModelsLabTools: 生成されたメディアの待機が max_wait_time で停止するようになりました。
  • Sambanova: デフォルトは Meta-Llama-3.3-70B-Instruct になるため、id を設定しなくても動作します。
  • Slack: スーパー エージェントは、users= なしで AgentOS(authorization=...) で開始されるようになりました。 users= にいないメンバーはチャットでき、許可が必要なアクションは default_role が許可しない限り拒否されます。

  • 偉業: https://github.com/agno-agi/agno/pull/11612 の @ashpreetbedi による会社 API を通じて会社ファイル ツリーを読み取る

  • 修正: https://github.com/agno-agi/agno/pull/11540 の @xingjy10 によるスキル ツール出力で非 ASCII 文字を保持する
  • 修正: https://github.com/agno-agi/agno/pull/11722 で @HhH666-ux によってドキュメントを挿入するときに qdrant はバッチサイズを優先します
  • 修正: https://github.com/agno-agi/agno/pull/11680 の @adityav1709 による [] を返す代わりに SQLTools フェッチ エラーを表面化
  • 修正: MCPTools.connect() の結果をレポートし、https://github.com/agno-agi/agno/pull/11135 の @surlymochan による CancelledError をクリーンアップ
