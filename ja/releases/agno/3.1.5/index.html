#アグノv3.1.5

#Changelog

新機能:

  • サンドボックス エージェントのリポジトリ: サンドボックス ClaudeAgent または CodexAgent は repository=Repository(url, branch="main") を受け取り、そのリポジトリ内のすべてのセッションを /workspace/repository で開始します。最初のターンでは正確なコミットが固定され、後のターンではウォーム再利用とチェックポイント復元の間、ピンとエンジニアの編集が保持され、プライベート リポジトリはサンドボックス環境から GITHUB_READ_TOKEN で認証されます。 クックブックを参照してください。 (#11121)
  • S3 チェックポイント ストア: S3CheckpointStore(bucket, prefix=..., endpoint_url=...) は、サンドボックス チェックポイントを S3 互換バケットに保持するため、サンドボックス エージェントは共有ファイル システムなしで複数のレプリカ上で実行されます。オブジェクトはコンテンツでアドレス指定され、アップロードは put が返される前に検証され、認証情報は AWS 環境から取得されます。 クックブックを参照してください。 (#11133)
  • 実行のサンドボックス チェックポイントを開く: サンドボックス エージェント上の open_run_checkpoint(run_id) / aopen_run_checkpoint は、コミットされた完了した実行の検証済みアーカイブを生成するため、ホスト プロセスはコンテナーがなくなった後に残されたターンを読み取ることができます。 checkpoint_store は、エージェントが書き込み先となるストアを公開します。 クックブックを参照してください。 (#11131)
  • オンデマンド スケジュール: 空の、または省略された cron_expr を含むスケジュールは、それ自身を準備することはなく、そのトリガー ルート、HTTP および ScheduleManager を通じてのみ実行されます。 ScheduleResponse.cron_expr はオプションになり、null として報告されます。 (#11118)
  • KeenableTools: Keenable Web 検索およびページ抽出用の新しいツールキット (web_search、fetch_url_content、非同期バリアント付き)。 API キーや新しい依存関係がなくても動作し、プライベート アドレスやループバック アドレスに解決されるフェッチを拒否します。 クックブックを参照してください。 (#9558)

改善点:

  • レジストリ内の外部エージェント: Registry(agents=[...]) は ClaudeAgent および CodexAgent を受け入れ、AgentOS エージェント、チーム、およびワークフローの応答には sandboxed フラグが付けられます。 (#11127)
  • スケジュール エンドポイントの編集: スケジュールの endpoint を PATCH /schedules/{schedule_id} または ScheduleManager 経由で変更すると、ターゲット列が古いままになるのではなく、更新されるようになりました。 (#11118)

バグ修正:

  • FastAPI 0.147 の AgentOS フォームのデフォルト: FastAPI 0.147.0 は、省略された bool フォーム フィールドを False として読み取るため、実行および続行すると、stream が省略された場合に SSE の代わりに JSON が返され、regenerate=true が 400 で失敗することなく続行されます。ルートは、stream の宣言されたデフォルトを復元するようになりました。 monitorとreplace_original。 (#11160)
  • サンドボックスは Redis なしで実行されます: サンドボックス エージェントは POST /agents/{agent_id}/runs 上で実行され、Redis なしの Postgres 耐久キューで 400 に応答しなくなりました。クロスレプリカのストリーミングとキャンセルには引き続き Redis が必要です。 (#11161)
  • ワークフロー ファイル: Parallel、Steps、Loop、Condition、Router ステップ内で生成された File 出力は、次のステップおよび workflow_run_response.files に到達するようになりました。 (#10950)
  • YouTubeTools: 動画 ID はショート、ライブ、モバイル、音楽、プライバシー強化 URL から読み取られ、空の ID はリクエストの前に No video ID found を返します。 (#10707)
  • PerplexitySearch および PubmedTools: 明示的な max_results=0 は、デフォルトで置き換えられるのではなく受け入れられます。 (#10595)
  • InMemoryDb: upsert_user_memory はコピーを保存するため、更新/挿入後に UserMemory を変更しても、保存されているメモリは変更されなくなります。 (#11016)

何が変わったのか

  • 功績: @ashpreetbedi による会社のハートビート ルーチンとソースを https://github.com/agno-agi/agno/pull/11102 に追加
  • 偉業: 準備完了タスクと制限付きルーチンの受け入れを自動化 (https://github.com/agno-agi/agno/pull/11104 の @ashpreetbedi による)
  • 功績: https://github.com/agno-agi/agno/pull/11121 の @ashpreetbedi によるサンドボックス ハーネス エージェントのリポジトリの構成
  • 修正: https://github.com/agno-agi/agno/pull/11118 の @ashpreetbedi による会社の自動化と構成のフォローアップを完了
  • 修正: https://github.com/agno-agi/agno/pull/11126 の @ashpreetbedi による会社タスクのセッションの所有権と回復を安定化させました。
  • 功績: サンドボックス化されたハーネス エージェントを使用して会社のタスクを実行 (https://github.com/agno-agi/agno/pull/11127 の @ashpreetbedi 著)
  • [修正] ワークフロー コンテナー ステップを通じてファイルを伝播する (https://github.com/agno-agi/agno/pull/10950 の @Timotty による)
  • [feat] キーレス Web 検索とページ抽出用の KeenableTools を追加 (https://github.com/agno-agi/agno/pull/9558 の @ilya-bogin-keenable により)

  • [修正] https://github.com/agno-agi/agno/pull/10595 の @ryanakml による PerplexitySearch および PubmedTools での明示的な max_results=0 を尊重する

  • 偉業: 実行のコミットされたサンドボックス チェックポイントをエージェント経由で開く by @ysolanky (https://github.com/agno-agi/agno/pull/11131)
  • 功績: https://github.com/agno-agi/agno/pull/11133 の @kausmeows により、オブジェクト ストレージ内のサンドボックス チェックポイントに S3CheckpointStore を追加
  • 修正: https://github.com/agno-agi/agno/pull/11161 の @ashpreetbedi により、サンドボックス API が Redis なしで永続キューで実行できるようにしました
  • 修正: https://github.com/agno-agi/agno/pull/11160 の @harshsinha03 により、FastAPI 0.147 で AgentOS のブール形式のデフォルトを復元
  • 偉業: https://github.com/agno-agi/agno/pull/11159 の @ashpreetbedi による OS Manager チャットから会社の製品とルーチンを作成
