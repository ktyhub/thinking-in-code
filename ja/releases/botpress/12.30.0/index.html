#ボットプレスv12.30.0

12.30.0 (2022-08-29)

⚠ 重要な変更のお知らせ

このリリースには、Docker イメージのセキュリティの改善が含まれていることに注意してください。デフォルトでは、root ユーザーとしての実行から、非 root botpress ユーザーとして実行するようになりました。 Dockerfile USER 命令の詳細については、次のドキュメントを参照してください: https://docs.docker.com/develop/develop-images/dockerfile_best-practices/#user. これらの変更は既存のユーザーに影響を与えることはほとんどありませんが、新しいイメージを使用できるようになる前に手動で変更を実行する必要がある場合があります。 /data フォルダーに対して ローカル バインド マウント を使用するか、使用することを期待しているユーザーのみが、次の手順に従う必要があります。

  1. ホスト マシン上で、UID=999 および GID=999 を持つ botpress ユーザーを作成します。
    • 例: ubuntu では、コマンドは次のようになります: groupadd -g 999 botpress && useradd -m -r -u 999 -g botpress botpress
  2. ローカル /data フォルダーの所有権を、新しく作成したユーザーに変更します。
    • 例: chown -R botpress:botpress <path to /data>
  3. これで、botpress アカウントを使用して docker イメージを開始し、セキュリティがすべて強化されたホスト マウントを使用できるようになります。 または、botpress/server イメージを拡張したもの:
FROM botpress/server:v12_30_0
# Changes the user to root so you can run privileged commands.
+USER root
# Code that requires superuser privilege
# ...
# Switch back to the botpress user to keep the security improvement.
+USER botpress
