openai-agents-python v0.24.0-alpha.6

openai-agents-python v0.24.0-alpha.6

プレビューをインストールする

仮想環境では標準の CPython 3.10 ～ 3.14 を使用します。これらのホイールにはネイティブ ランタイムが含まれています。 Rust ツールチェーンやソース ビルドは必要ありません。このプレビューは、PyPI ではなく、GitHub リリースを通じて配布されます。

プラットフォームに応じてコマンドを実行します。

Linux x86_64 (glibc 2.39 以降)

python -m pip install "https://github.com/openai/openai-agents-python/releases/download/v0.24.0-alpha.6/openai_agents-0.24.0a6-cp310-abi3-manylinux_2_39_x86_64.whl"

Apple Silicon 上の macOS 11 以降

python -m pip install "https://github.com/openai/openai-agents-python/releases/download/v0.24.0-alpha.6/openai_agents-0.24.0a6-cp310-abi3-macosx_11_0_arm64.whl"

Windows x64

python -m pip install "https://github.com/openai/openai-agents-python/releases/download/v0.24.0-alpha.6/openai_agents-0.24.0a6-cp310-abi3-win_amd64.whl"

ホイールは、Intel Mac、ARM Linux、ARM Windows、Alpine/musl、PyPy、またはフリースレッド Python には提供されません。 cp310-abi3 ファイル名は、標準の CPython 3.11 ～ 3.14 もサポートします。

インストールされているバージョンとネイティブ モジュールを確認します。

python -c "from importlib.metadata import version; import agents._native; print(version('openai-agents'))"

0.24.0-alpha.6 または同等の Python パッケージ スペル 0.24.0a6 を期待してください。 SHA256SUMS には、3 つのホイールすべてのチェックサムが含まれています。

#Release notes

0.24.0-alpha.5からの変更点。このプレビューでは、会話制御、状態回復、およびツール ポリシーが拡張され、パブリック API の変更が含まれています。

追加

  • get_result()、パッシブ events()、手動リクエスト処理、ステアリング、およびキャンセルを使用して、キャプチャされた Turn を通じて送信された作業を制御します。 Session.submit(..., if_busy="queue") でプロンプトをキューに入れるか、if_busy="steer" でアクティブなターンを操作します。
  • LocalStorage を追加してローカル プロファイルから会話を再開し、ポータブル SessionState のキャプチャとリカバリを拡張します。アイドル状態のフォーク、呼び出し元が提供する圧縮サマリーを追加し、機能サポートとチェックポイントの準備状況をチェックします。 LocalStorage プロファイルはポータブル チェックポイントをエクスポートできません。
  • ネイティブ厳密出力用に NativeOutput を追加し、Python で検証された JSON 用に PromptedOutput を追加します。オプションの max_retries は、ツールを使用したりタスクを再実行したりせずに、限定された修正を実行します。 LocalStorage には max_retries=0 が必要です。
  • ライブ手動ツール リクエストを処理し、サポートされている保留中のリクエストをチェックポイントから再開します。 agents.experimental.deferred とオプションの MCP タスク アダプターを介して実験的な外部ジョブ リカバリを追加します。
  • セッションの開始権限内で、各提出またはモデル ステップのツールを選択します。ネイティブ Web 検索、ネイティブ子チェックリスト、ローカル ストレージ セッションのネイティブ目標を追加します。
  • Python ツールが返す注釈を検証し、引数と結果を検査するためのツール ポリシーを追加します。引数の置換、結果の変換、サポートされている HTTP、stdio、およびモデル WebSocket パスを介したアプリケーション管理のフォームと URL の対話により、ネイティブ MCP サポートを拡張します。
  • 各プラットフォームのネットワークと Unix ソケットの制限に従って、サポートされている Linux および macOS エグゼキューター上のネイティブ コマンド用に NetworkPolicy を追加します。セッションを開いたりエージェントを実行したりするときに提供される Environment を通じて、リモート エグゼキュータのライフタイムを管理します。
  • NativeAgents(interactions=True) を使用して、ネイティブの子の承認とフォーム要求を有効にします。子は引き続きセッションのツールとアプリケーション コンテキストを共有します。
  • ネイティブ OpenTelemetry エクスポートを構成し、型指定された観察を検査します。 NativeError は、利用可能なプロバイダーのステータス コード、エラー コード、リクエスト ID、および障害カテゴリを公開するようになりました。
  • ライブ モデルや API キーを使用せずに、agents.testing.ScriptedResponses を使用してローカルのスクリプト応答に対して実際の SDK セッションと Python ツールをテストします。

API の変更点

  • ワンショット コールには Agent.run() または Agent.run_sync() を使用します。冗長な Runner エイリアスは削除されました。
  • 占領したターンの Turn.wait() と Session.wait() を Turn.get_result() に置き換えます。
  • 1 つのルート ターンの場合は Session.interrupt() を Turn.cancel() に、セッション全体の場合は Session.cancel_all() に置き換えます。
  • Subagent.submit() の名前を Subagent.start() に変更します。 Python コールバックと手動ツールを FunctionTool に統合します。個別の ManualTool 宣言を削除します。
  • エージェント宣言は不変です。新しいエージェントを作成してデフォルトを変更するか、出力タイプのバリアントとして with_output_type() を使用するか、オープンな会話に対してサポートされているアイドル セッションの更新を使用します。
  • ツールの選択とセッションの更新では、セッションを開いたときに取得された権限を拡張できません。復元されたセッションでは、現在のアプリケーション ツール、資格情報、およびポリシーが使用されます。

修正済み

  • 受け入れられたステアリング、ネイティブ継続、およびその後の送信全体にわたって、キャプチャされた各ターンの結果を安定させます。サポートされている保存と復元の境界を越えて、ワンショットの手動チェックポイント、一致するインタラクション応答、および出力修復状態を保持します。
  • ネイティブの子のキャンセルとセッションのクリーンアップを改善しました。結果ポリシーの有効期限が切れるとネイティブの作業を停止し、ルートと子の結果を報告するときにポリシーの失敗理由を保持します。
  • 不正な形式の Python ツール結果エンベロープを拒否し、MCP 結果変換を通じてサーバー エラーを保持します。ネストされた OpenAI 拡張フォームと client 証明書を使用した HTTP テレメトリ エクスポートをサポートします。

ドキュメントと例

  • プレビュー ソースをパブリック リポジトリに移動します。ビルド済みホイールのインストール ガイダンスに焦点を当て、SDK ビルド手順を CONTRIBUTING.md に移動します。
  • ブラウザ アプリケーション、AG-UI ストリーミング、遅延ジョブ、評価、可観測性、一般的なアプリケーション タスクの例を追加します。プレビュー ドキュメントから移行ガイドを削除します。
