openai-agents-python v0.20.0

主要な変更点

バージョン 0.20.0 は、暗黙的なデフォルト モデルを変更し、カスタマイズされたローカル HTTP トランスポートを使用するアプリケーションに対する潜在的に破壊的な MCP 依存関係の移行が含まれているため、マイナー リリースです。 MCP v1 は引き続きサポートされ、影響を受けるアプリケーションは httpx2 またはピン mcp<2 に移行できます。

ハイライト:

  • デフォルトのモデルは gpt-5.6-luna になりました。明示的なモデル、実行レベルのオーバーライド、および OPENAI_DEFAULT_MODEL は引き続き優先されます。
  • ローカル MCP 接続は、stdio、SSE、およびストリーミング可能な HTTP トランスポート全体で MCP Python SDK v1 および v2 をサポートします。
  • カスタム MCP HTTP 認証または client ファクトリを使用するアプリケーションは、インストールされている MCP メジャー バージョン、またはピン mcp<2 が所有する HTTP タイプを使用する必要があります。
  • RunState.add_input() は、ガードレール、永続性、およびシリアル化のサポートを使用して、モデル呼び出しを再開する前に永続的なユーザー入力をステージングできます。
  • サンドボックス マウント検証により、明示的な資格情報公開確認が追加され、資格情報権限をシリアル化することなく編集されたエラー コントラクトが保存されます。
  • リアルタイム入力トランスクリプションは、gpt-live-transcribe、gpt-transcribe、および gpt-realtime-whisper の GA トランスクリプション設定をサポートします。
