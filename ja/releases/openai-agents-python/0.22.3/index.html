openai-agents-python v0.22.3

パッチ 公開日2026年9月17日 出典openai/openai-agents-python 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

openai-agents-python v0.22.3

何が変わったのか

  • 修正 (コア): https://github.com/openai/openai-agents-python/pull/5066 の @seratch によって条件付き承認を検証されたツール引数と調整する
  • 修正（コア）: https://github.com/openai/openai-agents-python/pull/4947 の @hyeonsang010716 によるサーバー管理の履歴書でツールが見つからない出力を配信する
  • 修正 (サンドボックス): Windows ホスト上でコマンド パス POSIX を維持 (https://github.com/openai/openai-agents-python/pull/4958 の @hyeonsang010716 により)
  • 修正(セッション): https://github.com/openai/openai-agents-python/pull/4987 の @00200200 による非同期 SQLite の同時起動を処理する
  • 修正（セッション）: https://github.com/openai/openai-agents-python/pull/4961 の @tiagovilasboas によるセッション制限を会話ページ サイズとして転送しないようにしました
  • 修正(トレース): https://github.com/openai/openai-agents-python/pull/5017 の @hyeonsang010716 による欠落している OPENAI_API_KEY をキャッシュしないようにしました。
  • 修正（拡張機能）: AdvancedSQLiteSession のツール使用法にシェルと apply_patch の呼び出しを含める (https://github.com/openai/openai-agents-python/pull/4982 の @rioyu123 による)
  • 修正 (拡張機能): https://github.com/openai/openai-agents-python/pull/4804 の @Hughhahacoder によって近い初期ストリームでサブプロセスを取得します
  • 修正 (拡張機能): https://github.com/openai/openai-agents-python/pull/4980 の @JiangLLM により、AdvancedSQLiteSession.delete_branch に正確な ID が保存されるようになりました。

ドキュメントとその他の変更点

  • ドキュメント: リポジトリのセキュリティと共同作成者のガイダンスを調整する (https://github.com/openai/openai-agents-python/pull/4962 の @jbeckwith-oai による)
  • ドキュメント: https://github.com/openai/openai-agents-python/pull/5064 の @seratch による Unix ローカル実行境界を明確にする
  • ドキュメント: https://github.com/openai/openai-agents-python/pull/5065 の @seratch によって翻訳されたページを更新
  • docs(examples): https://github.com/openai/openai-agents-python/pull/5079 の @simpleqt によって、Temporal トレース名の重複した単語を削除します。
  • 雑用: https://github.com/openai/openai-agents-python/pull/4964 の @jbeckwith-oai によるリリース年齢クールダウンで Python の dependabot カバレッジを有効にする
  • 雑用: https://github.com/openai/openai-agents-python/pull/4965 で @jbeckwith-oai によるコードの所有権と必要なリリース レビュー ガイダンスを追加
  • fix(deps): https://github.com/openai/openai-agents-python/pull/4963 の @jbeckwith-oai による SDK APIs を変更せずに脆弱な依存関係を更新
  • chore(deps): https://github.com/openai/openai-agents-python/pull/4966 の @dependabot[bot] により、/examples/realtime/twilio_sip で fastapi 要件を >=0.120.0 から >=0.141.1 に更新します
  • chore(deps): https://github.com/openai/openai-agents-python/pull/4968 の @dependabot[bot] により /examples/realtime/twilio_sip で uvicorn 要件を >=0.38.0 から >=0.52.4 に更新します
  • chore(deps): https://github.com/openai/openai-agents-python/pull/4969 の @dependabot[bot] により /examples/realtime/twilio_sip の openai 要件を <4,>=3.0.0 から >=3.8.0,<4 に更新します
  • chore(deps): https://github.com/openai/openai-agents-python/pull/4970 の @dependabot[bot] による 4.14.1 から 4.16.0 へのタイピング拡張機能のバンプ
  • chore(deps-dev): https://github.com/openai/openai-agents-python/pull/4971 の @dependabot[bot] により、grpcio を 1.76.0 から 1.83.1 にバンプします
  • chore(deps): https://github.com/openai/openai-agents-python/pull/4973 の @dependabot[bot] による sqlalchemy を 2.0.43 から 2.0.52 に変更
  • chore(deps-dev): https://github.com/openai/openai-agents-python/pull/4975 の @dependabot[bot] による 45.0.7 から 50.0.0 への暗号化のバンプ
  • ci: https://github.com/openai/openai-agents-python/pull/4974 に @jbeckwith-oai による Python と Actions CodeQL セキュリティ スキャンを追加
  • fix(ci): https://github.com/openai/openai-agents-python/pull/4976 の @dependabot[bot] による依存関係とワークフローの更新後にドキュメントをデプロイします
  • 修正 (deps): https://github.com/openai/openai-agents-python/pull/5030 の @dependabot[bot] により、/examples/realtime/twilio の python-multipart 要件を >=0.0.31 から >=0.0.32 に更新
  • 修正 (deps): https://github.com/openai/openai-agents-python/pull/5031 の @dependabot[bot] により、/examples/realtime/twilio の python-dotenv 要件を >=1.2.2 から >=1.2.3 に更新
  • 修正 (deps): https://github.com/openai/openai-agents-python/pull/5033 の @dependabot[bot] により、/examples/realtime/twilio_sip のスターレット要件を >=1.3.1 から >=1.6.0 に更新
  • 修正 (deps): https://github.com/openai/openai-agents-python/pull/5034 の @dependabot[bot] により、/examples/realtime/twilio_sip の python-dotenv 要件を >=1.2.2 から >=1.2.3 に更新
  • 修正(deps-dev): https://github.com/openai/openai-agents-python/pull/5036 の @dependabot[bot] により、pymdown 拡張機能を 11.0.1 から 11.0.2 にバンプします
  • 修正 (deps): https://github.com/openai/openai-agents-python/pull/5037 の @dependabot[bot] によるランループのバンプ api-client を 1.16.0 から 1.31.0 に
  • 修正(deps): https://github.com/openai/openai-agents-python/pull/5038 の @dependabot[bot] によりスターレットを 1.3.1 から 1.6.0 に変更
  • 修正 (deps): https://github.com/openai/openai-agents-python/pull/5032 の @dependabot[bot] により、/examples/realtime/twilio のスターレット要件を >=1.3.1 から >=1.6.0 に更新
  • https://github.com/openai/openai-agents-python/pull/5058 の @jbeckwith-oai により、SDKs チームをリポジトリ コード所有者として追加
