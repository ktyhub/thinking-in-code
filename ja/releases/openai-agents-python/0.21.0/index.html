openai-agents-python v0.21.0

主要な変更点

このマイナー リリースでは、既知の重大な SDK 動作変更は導入されていません。マイナー バージョンのバンプは、新しいプロバイダー中立のテスト API と OpenAI Python v3 互換性アップデート用です。

ハイライト:

  • プロバイダー要求なしで確定的なエージェント、サンドボックス、リアルタイム、および音声のワークフロー テストを行うための agents.testing、agents.realtime.testing、および agents.voice.testing ユーティリティを追加しました。
  • HTTPX2 対応のリクエスト、レスポンス、トランスポート、例外処理を含む、OpenAI プロバイダーの互換性を openai>=3.0.0,<4 に更新しました。
  • 強化された RunState 中断スナップショット、再帰的なエージェント ツール承認、最大ターン終了処理、ストリーミング クリーンアップ、および機密エラーの編集。
  • MCP ライフサイクル スナップショット分離が改善され、構成可能な再試行バックオフ上限が追加されました。
  • Sandbox Runloop の既存のシークレットのサポートを追加し、ビューイメージのパス許可を強化しました。
  • 無効なチャネル、フレーム レート、不完全なマルチチャネル フレーム、および非有限オーディオ レートに対する、より厳格な音声検証を追加しました。

何が変わったのか

  • 特技: https://github.com/openai/openai-agents-python/pull/4380 の @seratch による OpenAI Python 3 および HTTPX2 のサポート
  • 功績: https://github.com/openai/openai-agents-python/pull/4362 の @seratch によるスクリプト化されたモデル テスト ユーティリティを追加
    • 修正: https://github.com/openai/openai-agents-python/pull/4386 の @seratch によるパブリック テスト モジュール コントラクトを凍結する
    • 修正: https://github.com/openai/openai-agents-python/pull/4404 の @seratch による API 状態コントラクトの公開テストを凍結
    • 修正 (コア): https://github.com/openai/openai-agents-python/pull/4422 の @apcha-oai による Python SDK リリース全体でスクリプト化された注釈ストリーミングを保持する
  • fix(core): https://github.com/openai/openai-agents-python/pull/4384 の @hsusul による割り込み結果を分離
  • 修正（コア）: https://github.com/openai/openai-agents-python/pull/4366 の @Lucccvb により、ストリームされたターンが端末障害で終了した場合にモデル ストリームを閉じる
