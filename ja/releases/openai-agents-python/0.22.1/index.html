  • 修正（コア）: https://github.com/openai/openai-agents-python/pull/4692 の @XuQuanxin04 による完了イベントでコンシューマーが停止すると、ストリーミング応答スパンが応答/入力を失う問題を修正
  • 修正（コア）: https://github.com/openai/openai-agents-python/pull/4714 の @abhay-codes07 により、**kwargs 値アノテーションを各キーワード値に適用します
  • 修正（コア）: https://github.com/openai/openai-agents-python/pull/4674 の @rajarshidattapy による名前付きツール パラメーターと衝突する **kwargs キーを拒否します
  • fix(core): https://github.com/openai/openai-agents-python/pull/4735 の @subashpolisetti による可変引数ツール引数の固定長タプル アノテーションを拒否する
  • 修正（コア）: https://github.com/openai/openai-agents-python/pull/4739 の @rioyu123 による可変個引数ツール パラメーターのフィールド制約を保持
  • 修正 (コア): https://github.com/openai/openai-agents-python/pull/4785 の @Excelius-Wang によって Runner によって作成されたモデル プロバイダーを閉じる
  • 修正 (コア/音声): https://github.com/openai/openai-agents-python/pull/4530 の @green3sf によるデフォルトの clients よりも OpenAI プロバイダー オプションを優先します
  • fix(chat-completions): https://github.com/openai/openai-agents-python/pull/4728 の @mmjerge により、ストリームされたターンのメッセージを保留中のツール呼び出しメッセージにマージします
  • 修正（チャット補完）: https://github.com/openai/openai-agents-python/pull/4513 の @weike-zhang による切り捨てられた空の補完で ModelBehaviorError が発生する
  • fix(chat-completions) は、https://github.com/openai/openai-agents-python/pull/4699 の @apcha-oai によるチャット補完でペアになっていない関数の出力を拒否します
  • 修正（拡張機能）: ブランチに順番がない場合、AdvancedSQLiteSession 使用ストアをスキップ (https://github.com/openai/openai-agents-python/pull/4822 の @rioyu123 による)
