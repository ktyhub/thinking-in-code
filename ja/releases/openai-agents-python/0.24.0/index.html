主な変更点の草案

主要な変更点

0.24.0 は、実行全体の関数エラーの書式設定と MCP 検出の注釈を追加し、リカバリ、サンドボックスの安全性、およびトレースを改善します。このマイナー リリースには、カスタム エラー コールバックと一部の保存されたエージェント グラフの互換性の変更が含まれています。アップグレードする前に、最初の 2 つのハイライトを確認してください。

ハイライト:

  • カスタム エラー フォーマッタを更新します。 RunConfig.tool_error_formatter は、kind="tool_exception" およびオプションの error を受信できます。新しい種類を処理するか、None を返してデフォルトのメッセージを保持します。明示的なツールごとのハンドラーが優先されます。未構成のデフォルトは変更されません。
  • 保存された実行に基づいてアップグレードを計画します。 新しい RunState スナップショットはスキーマ 1.21 を使用します。影響を受ける古い同名のエージェント グラフを元の SDK で終了します。エージェント コードと元のフックの順序は変更しないでください。新しい永続的な実行には一意のエージェント名を使用します。保存されたグラフの名前変更は移行ではありません。
  • 完了した作業をより確実に回復します。 延期された承認履歴、完了したツール出力、エイリアス、および圧縮状態は、サポートされている回復パスに残ります。自動圧縮は承認を待ちます。 Redis は、サポートされているスタンドアロン client で履歴をアトミックに置き換えます。会話の追加では、20 項目のリクエスト制限が尊重されます。再試行する前に、部分的な書き込みを調整してください。
  • ローカルでの実行と表示を強化します。 macOS サンドボックス コマンドは Launch Services リクエストを拒否します。サンドボックス ツールは、無効なモデル引数から回復します。保護されたマウント エラーは、捕捉されたトレースバックを切り離す間、呼び出し元の例外データを保持します。リアルタイム デモでは、ツールのコンテンツがテキストとして表示されます。
  • 再開とクリーンアップを通じてトレースの選択を尊重します。 実行ごとのトレースのオプトアウトは呼び出し側トレース内に適用され、承認された再開ツールは再開されたエージェント スパンに接続されます。
  • より豊富な統合例とメタデータを使用します。 MCP ツールは、オプションの mcp_annotations を検出ヒントとして公開します。新しい Decisions レシピでは、OpenAI >=3.26.0,<4 を使用した分類、ルーティング、ツール レビューを示します。これらは、エージェント モデル アダプターではなく、別の client を使用します。
  • オプションの依存関係ロックを更新します。 Temporal エクストラは temporalio==1.34.0 を使用します。 Vercel エクストラは vercel-sandbox>=0.7.0,<0.9 をサポートします。コア Python および OpenAI SDK の最小値は変更されません。
