openai-agents-python v0.21.1

何が変わったのか

  • feat(core): https://github.com/openai/openai-agents-python/pull/4428 の @seratch によるモデル呼び出しタイムアウトを追加
  • 特技(サンドボックス): https://github.com/openai/openai-agents-python/pull/4427 の @seratch により、実行スコープのサンドボックス作業ディレクトリを追加します。
  • 特技(サンドボックス): https://github.com/openai/openai-agents-python/pull/4452 の @koadegno により、Docker サンドボックスでネットワークを無効にすることを許可します。
  • 特技(サンドボックス): https://github.com/openai/openai-agents-python/pull/4455 の @Filimoa によるモーダル サンドボックス リソース オプションを追加
  • 修正(コア): https://github.com/openai/openai-agents-python/pull/4447 の @seratch による正確な通話承認決定を尊重します。
  • fix(core): https://github.com/openai/openai-agents-python/pull/4453 の @seratch による使用なしの応答リクエストの数をカウントします。
  • 修正（コア）: https://github.com/openai/openai-agents-python/pull/4438 の @fszcd による失敗後にすべてのマルチプロバイダーの子を閉じる
  • 修正（コア）: https://github.com/openai/openai-agents-python/pull/4431 の @Coiggahou2002 による、部分的に一致するスタックされたアンカーを拒否する
  • fix(chat-completions): https://github.com/openai/openai-agents-python/pull/4432 の @seratch によるチャット完了推論リプレイ
  • 修正（リアルタイム）: https://github.com/openai/openai-agents-python/pull/4457 の @Chirag6722 による経過時間ゼロでオーディオを切り捨てる
  • 修正（リアルタイム）: https://github.com/openai/openai-agents-python/pull/4461 の @seratch によってクリーンなサーバーが閉じられた後に反復を終了
  • 修正(セッション): https://github.com/openai/openai-agents-python/pull/4454 の @seratch による高度な SQLite 構造テーブルの競合を防止
  • 修正（セッション）: https://github.com/openai/openai-agents-python/pull/4446 の @seratch による実行合計に圧縮の使用量を含める
  • 修正 (サンドボックス): https://github.com/openai/openai-agents-python/pull/4462 の @seratch による view_image ラスター コンテンツの検証
  • 修正 (サンドボックス): https://github.com/openai/openai-agents-python/pull/4416 で @sylvesterkaczmarek によって POSIX 正規化されたモデル パスを維持します
  • 修正（サンドボックス）: https://github.com/openai/openai-agents-python/pull/4437 の @sylvesterkaczmarek により apply_patch パスを POSIX として正規化

ドキュメントとその他の変更点

  • ドキュメント: https://github.com/openai/openai-agents-python/pull/4381 の @seratch による v0.21.0 リリースの更新
  • ドキュメント: https://github.com/openai/openai-agents-python/pull/4440 の @cerebrixos による統合をトレースするチューニング エンジンのリスト
  • 修正: https://github.com/openai/openai-agents-python/pull/4448 の @seratch による Python 3.14 の cffi ロックの更新
  • リリース: 0.21.1 by @seratch (https://github.com/openai/openai-agents-python/pull/4467)
