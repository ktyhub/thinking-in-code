LightRAG v1.4.0

マイナー 公開日2025年7月15日 出典HKUDS/LightRAG 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#ライトラグv1.4.0

重要な注意事項

  • アップグレード後、ドキュメント削除機能が正しく機能するために、ドキュメントとキャッシュをクリアしてからドキュメントのインデックスを再作成してください。ドキュメントをクリアするときは、必ず「キャッシュを同時にクリア」オプションを選択してください。ドキュメント削除機能がすぐに必要でない場合は、ドキュメントのインデックスを再作成する必要はありません。
  • このアップグレードには、QueryParam パラメータへの変更が含まれています。以前に QueryParam を使用して LightRAG を統合していた場合は、最新の API に従ってパラメータ受け渡しを更新してください。 Web UI の API ページの /query エンドポイント パラメーターを参照してください。
  • このバージョンの Reranker の統合により、混合クエリのパフォーマンスが大幅に向上しました。 Reranker が有効な場合は、混合クエリ モードをデフォルトとして使用することをお勧めします。

追加されました

  • クエリのパフォーマンスを向上させるためにチャンクの再ランキングのサポートを追加 (https://github.com/HKUDS/LightRAG/pull/1753 https://github.com/HKUDS/LightRAG/pull/1782 の @LarFii による)
  • WebUI にドキュメント削除機能を実装 by @danielaskdd (https://github.com/HKUDS/LightRAG/pull/1698 https://github.com/HKUDS/LightRAG/pull/1697 https://github.com/HKUDS/LightRAG/pull/1732)
  • WORKSPACE 環境変数を介してすべてのストレージ タイプのデータ分離を実装 (https://github.com/HKUDS/LightRAG/pull/1743 の @danielaskdd による)
  • 文書処理のマージ段階で並列処理を有効にして、LLM 同時機能を活用します by @maharjun (https://github.com/HKUDS/LightRAG/pull/1549 https://github.com/HKUDS/LightRAG/pull/1772 https://github.com/HKUDS/LightRAG/pull/1771 https://github.com/HKUDS/LightRAG/pull/1770)
  • https://github.com/HKUDS/LightRAG/pull/1724 の @SLKun による ollam 互換の api を更新
  • https://github.com/HKUDS/LightRAG/pull/1729 の @danielaskdd によるリコール効率向上のための LLM キャッシュ構造の平坦化
  • Webui は、https://github.com/HKUDS/LightRAG/pull/1747 の @danielaskdd によるバックエンドからの MAX_GRAPH_NODES 設定を同期します
  • https://github.com/HKUDS/LightRAG/pull/1750 の @danielaskdd により、デフォルトの埋め込みバッチ サイズが 32 から 10 に削減されました。
  • https://github.com/HKUDS/LightRAG/pull/1752 の @SLKun によるエンティティおよびキーワード抽出の <think> タグを削除することで、COT/推論モデルをサポートします。
  • https://github.com/HKUDS/LightRAG/pull/1783 の @danielaskdd による LLM 出力の切り捨てを防ぐために、非推奨の MAX_TOKEN_SUMMARY パラメーターを削除しました。
  • 概要ロジックを改良し、https://github.com/HKUDS/LightRAG/pull/1778 の @danielaskdd による専用の Ollama num_ctx 構成を追加
  • https://github.com/HKUDS/LightRAG/pull/1703 https://github.com/HKUDS/LightRAG/pull/1766 の @DavIvek によりサポートされるグラフ データベース バックエンドとして Memgraph を追加
