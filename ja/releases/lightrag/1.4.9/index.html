LightRAG v1.4.9

#ライトラグv1.4.9

重要な注意事項

v1.4.9 では、参照出力形式を改良し、構造化参照をクエリ結果に組み込むことに重点を置いた主要な機能強化が導入されています。すべてのクエリ API エンドポイントに references フィールドが含まれるようになり、フロントエンド アプリケーションが、LightRAG クエリ結果に関連付けられた引用文書とそれに対応する識別子を取得できるようになりました。 LLM に送信されるコンテキスト形式が更新されました。 LLM からのストリーミング応答に references フィールドが含まれるようになりました (デフォルトではフロントエンドによって無視されます)。 アプリケーションが LightRAG クエリ API によって返されるコンテキスト データに依存している場合は、それに応じてコードを更新する必要がある場合があります。 user_prompt パラメータを利用することで、ユーザーは脚注注釈を含む応答を生成するように LLM に指示できます。 LLM 出力の脚注番号は、references フィールドで返される文書 ID にシームレスにマッピングできます。この統合により、LightRAG とビジネス システム間の連携が強化され、ユーザーはオリジナルのソース素材に直接アクセスできるようになります。 user_prompt は、LLM の追加出力命令として機能します。ここでは 2 つの例を示します。

  1. gpt-4.1-mini または Qwen3 の場合は user_prompt
For inline citations, employ the footnote reference format `[^1]`, where the `^` following the opening square bracket denotes a superscript link. When multiple citations are required at a single location, enclose each reference ID within separate footnote markers (e.g., `[^1][^2][^3]`).

2.ディープシーク用のuser_prompt:

内嵌引文标注使用Markdown脚注格式`[^1]`, 当某处有多个引文标注时,应将每个引用ID分别置于独立的中括号内（例如：`[^1][^2][^3]`）。仅需对回答的关键事实和依据信息给出标注。出现在引文标中的引文ID都应该列在最后生成的参考文献中段落中。不要在参考文献段落之后生成脚注段落。

このスクリーンショットは、WebUI の user_prompt パラメーターの機能を示しています。 <img width="1104" height="571" alt="image" src="https://github.com/user-attachments/assets/7428b1b2-1b0e-4d06-961c-1f547f062020" />

新機能

  • リファクタリング: LLM に引用コンテキストを提供し、参照セクションの生成品質を向上 by @danielaskdd (https://github.com/HKUDS/LightRAG/pull/2140)
  • 機能: すべてのクエリ エンドポイントに対する参照リストのサポートを追加 (https://github.com/HKUDS/LightRAG/pull/2147 の @danielaskdd による)
  • リファクタリング(WebUI): https://github.com/HKUDS/LightRAG/pull/2124 の @danielaskdd によるサーバー駆動のエンティティ名検索による Client 側の検索ロジックの変更
  • 機能 (webui): https://github.com/HKUDS/LightRAG/pull/2132 の @danielaskdd によるバイパス モードでの履歴メッセージの強制送信
  • 機能 (WebUI): チャット メッセージのマークダウン レンダリングに脚注サポートを追加 (https://github.com/HKUDS/LightRAG/pull/2145 の @danielaskdd により)
  • 機能 (webui): https://github.com/HKUDS/LightRAG/pull/2146 の @danielaskdd によるクエリ設定にユーザー プロンプト履歴ドロップダウンを追加

修正された内容

  • WebUI を修正: https://github.com/HKUDS/LightRAG/pull/2114 の @danielaskdd によるエラー メッセージのツールヒント テキストの折り返しを修正し、ツールヒントの読みやすさを向上
  • 取得ページのパラメーター オプションを修正: 「コンテキストのみが必要」と「プロンプトのみが必要」の間の相互排他性を強制 (https://github.com/HKUDS/LightRAG/pull/2118 の @Saravanakumar26 により)
  • リファクタリング: クエリ プロンプトとユーザー プロンプト処理の最適化 (https://github.com/HKUDS/LightRAG/pull/2127 の @danielaskdd による)
  • WebUI のバグ修正と改善 (https://github.com/HKUDS/LightRAG/pull/2129 の @danielaskdd による)
  • 修正: https://github.com/HKUDS/LightRAG/pull/2131 の @danielaskdd によるメッセージ入力ボックスのブラウザーのオートコンプリート機能を復元
  • 功績: 包括的な文書重複防止システムの実装 (@danielaskdd 著、https://github.com/HKUDS/LightRAG/pull/2135)
  • https://github.com/HKUDS/LightRAG/pull/2137 の @danielaskdd によるノード タイプの凡例とカラー マッピングのリファクタリング
  • タイプミスを修正: "Oputput" -> https://github.com/HKUDS/LightRAG/pull/2139 の @SeungAhSon による出力
  • 機能: @danielaskdd による WebUI の拡張マークダウン サポートを https://github.com/HKUDS/LightRAG/pull/2143 に追加

  • https://github.com/HKUDS/LightRAG/pull/2152 の @danielaskdd による一貫した応答処理のための aquery_llm 関数を追加して二重クエリの問題を修正
  • Web UI - 読み込みアイコンを中央に配置し、https://github.com/HKUDS/LightRAG/pull/2150 の @zl7261 によって GraphSeach 幅を調整します
