LightRAG v1.5.7rc2

パッチ 公開日2026年8月19日 出典HKUDS/LightRAG 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#ライトラグv1.5.7rc2

新機能

  • https://github.com/HKUDS/LightRAG/pull/3620 の @ysys143 により、Apache AGE から PostgreSQL テーブルにグラフを移行するオフライン ツールを追加
  • 機能: https://github.com/HKUDS/LightRAG/pull/3473 の @letsgetai による遅延ベクトル インデックスによるグラフファースト インジェストのサポート
  • 功績: @er-s-an による明示的なカスタム チャンキング セレクターを https://github.com/HKUDS/LightRAG/pull/3665 に追加
  • feat(api): https://github.com/HKUDS/LightRAG/pull/3672 の @danielaskdd による API ドキュメント公開用の ENABLE_API_DOCS スイッチを追加

何が変わったのか

  • fix(kg): https://github.com/HKUDS/LightRAG/pull/3588 の @santhreal によって NetworkXStorage get_node および get_edge からコピーを返す
  • fix(operate): 最も一般的なエンティティ タイプを計算し、https://github.com/HKUDS/LightRAG/pull/3589 の @santhreal による再構築時にキーワードを正規化します。
  • fix(kg): https://github.com/HKUDS/LightRAG/pull/3590 の @santhreal による get_all_update_flags_status からのブール値を返す
  • 修正 (utils): https://github.com/HKUDS/LightRAG/pull/3592 の @santhreal によって merge_source_ids の GRAPH_FIELD_SEP を分割
  • fix(utils): docstring の例を修正し、https://github.com/HKUDS/LightRAG/pull/3591 の @santhreal によって compute_incremental_chunk_ids を強化しました
  • 修正 (パーサー): ドキュメントごとにバインドされたネイティブ マークダウン イメージのダウンロード (GHSA-25c3-j78v-83qx) (https://github.com/HKUDS/LightRAG/pull/3605 の @danielaskdd による)
  • fix(kg): 共有行ヘルパーを介してトラックドキュメントをハイドレートし、https://github.com/HKUDS/LightRAG/pull/3595 の @santhreal による TypeError をキャッチします
  • fix(kg): https://github.com/HKUDS/LightRAG/pull/3593 の @santhreal により、グラフ バックエンド全体で get_knowledge_graph の切り捨てが決定的になります
  • 修正 (セキュリティ): https://github.com/HKUDS/LightRAG/pull/3614 の @danielaskdd によるバインドされた DOCX 解凍とサイドカー イメージ パスを含む
  • 修正(rebuild_vdb): https://github.com/HKUDS/LightRAG/pull/3587 の @ysys143 による引用を含むentity_idを破損する非可逆agtype引用ストリップを削除
  • 修正（抽出）：トークン制限の切り捨てを表面化し、https://github.com/HKUDS/LightRAG/pull/3607 の @pengpengyi92 による空の切り捨てられた応答で失敗する
  • build(deps): https://github.com/HKUDS/LightRAG/pull/3616 の @dependabot[bot] による 2 つの更新で github-actions グループをバンプします
  • 修正 (パーサー): OOXML メンバーと DOCX イメージのバジェットを適用 (https://github.com/HKUDS/LightRAG/pull/3619 の @danielaskdd による)
  • fix(graph): https://github.com/HKUDS/LightRAG/pull/3623 の @danielaskdd による手動エンティティ/リレーション API (GHSA-c922-pw4m-4wcv) の属性を検証します
  • fix(kg): https://github.com/HKUDS/LightRAG/pull/3624 の @danielaskdd により、グラフ属性コントラクトを必要とするバックエンドでグラフ属性コントラクトを強制します
  • 修正(api): https://github.com/HKUDS/LightRAG/pull/3626 の @danielaskdd によるドキュメント ソース内の保存できない文字を拒否
  • 修正(グラフ): https://github.com/HKUDS/LightRAG/pull/3622 の @pengpengyi92 によるエンティティの名前変更時に自己ループを保持
  • 修正(グラフ): https://github.com/HKUDS/LightRAG/pull/3625 の @danielaskdd による手動書き込みパスでの自己ループ関係を拒否
  • perf(kg): https://github.com/HKUDS/LightRAG/pull/3618 の @ysys143 による PGTable トラバーサルからのシード次数ラウンド トリップを削除します
  • fix(milvus): gRPC 応答上限 #3584 (https://github.com/HKUDS/LightRAG/pull/3629 の @El-Tatane による) を尊重するためのページ ベクター/ID ルックアップ
  • 修正: https://github.com/HKUDS/LightRAG/pull/3604 の @Vishwamitra による Ollama の埋め込み API に embedding_dim を転送
  • 修正: https://github.com/HKUDS/LightRAG/pull/3599 の @Vishwamitra によってデフォルトで Ollama 抽出/キーワード ロールの思考を無効にする
  • fix(base): https://github.com/HKUDS/LightRAG/pull/3633 の @qianheng-aws による DocProcessingStatus のリハイドレート時に宣言されていないフィールドを許容する
  • 修正 (llm): GeneratorExit が https://github.com/HKUDS/LightRAG/pull/3635 の @AmirF194 による COT 途中のクローズを中断したときに OpenAI ストリーム/client を閉じる
  • 修正(api): https://github.com/HKUDS/LightRAG/pull/3636 の @pengpengyi92 によるカスタム Ollama 埋め込みディメンションのフェイルファスト
  • build(deps-dev): https://github.com/HKUDS/LightRAG/pull/3641 の @dependabot[bot] による 5 つの更新で /lightrag_webui の build-tools グループをバンプします
  • build(deps): https://github.com/HKUDS/LightRAG/pull/3639 の @dependabot[bot] による 3 つの更新で 1 つのディレクトリに反応グループをバンプします
  • build(deps): https://github.com/HKUDS/LightRAG/pull/3640 の @dependabot[bot] により、ui-components グループの /lightrag_webui で 1.26.0 から 1.29.0 に lucide-react をバンプします。
  • build(deps): https://github.com/HKUDS/LightRAG/pull/3642 の @dependabot[bot] による 2 つの更新を使用して、1 つのディレクトリにコンテンツ レンダリング グループをバンプします。
  • build(deps): https://github.com/HKUDS/LightRAG/pull/3643 の @dependabot[bot] による 4 つの更新を使用して、1 つのディレクトリにまたがるfrontend-minor-patch グループをバンプします。
  • fix(kg): Apache AGE >= 1.8.0 で PGGraphStorage を拒否すると、https://github.com/HKUDS/LightRAG/pull/3621 の @ysys143 によってバックエンドがクラッシュします
  • リファクタリング/パーサーキャンセル例外の名前変更 (https://github.com/HKUDS/LightRAG/pull/3637 の @MasaSN による)
  • リファクタリング(neo4j): https://github.com/HKUDS/LightRAG/pull/3648 の @danielaskdd によるバッチ エッジ読み取りコントラクトを明確化
  • 修正(api): https://github.com/HKUDS/LightRAG/pull/3632 で @pengpengyi92 によって重複したマーカーを削除するときにソース ファイルを保持する
  • ドキュメント: https://github.com/HKUDS/LightRAG/pull/3649 の @Shizoqua によるプログラミング ガイド内の壊れたサンプル リンクを修正
  • ドキュメント: https://github.com/HKUDS/LightRAG/pull/3653 の @Shizoqua による古いデフォルトと環境変数名を修正
  • 修正 (パーサー): https://github.com/HKUDS/LightRAG/pull/3638 の @Shizoqua による MinerU および Docling のバインドされた外部結果ダウンロード
  • 修正 (webui): https://github.com/HKUDS/LightRAG/pull/3655 の @danielaskdd により予約されたプロパティ名に対してグラフ タイプの色の解像度を強化
  • docs(env.example): 不足している EXTRACT ロール変数を @torvalstrom によって https://github.com/HKUDS/LightRAG/pull/3651 に追加
  • 修正(lmdeploy): https://github.com/HKUDS/LightRAG/pull/3654 の @Shizoqua による do_sample 設定を保存
  • 修正 (パーサー): https://github.com/HKUDS/LightRAG/pull/3656 で @danielaskdd による二次マークダウン画像解析を防止
  • 修正(api): https://github.com/HKUDS/LightRAG/pull/3646 の @ClaireXi99 により、EMBEDDING_DIM スタートアップ ガードをすべての埋め込みバインディングに一般化
  • ドキュメント: https://github.com/HKUDS/LightRAG/pull/3650 の @Marc-oss-hub による OpenAI 互換 LLM バインディングとして OrcaRouter を文書化
  • 修正: https://github.com/HKUDS/LightRAG/pull/3662 で @er-s-an によってセレクターがカスタム チャンクをバイパスすると警告する
  • 修正（チャンカー）: https://github.com/HKUDS/LightRAG/pull/3663 の @Shizoqua による負のトークンの重複を拒否
  • 修正(再ランク): https://github.com/HKUDS/LightRAG/pull/3667 の @Shizoqua による負のチャンクの重複を拒否
  • 修正(lollms): https://github.com/HKUDS/LightRAG/pull/3668 で @Shizoqua によって設定されたバインディング ホストを尊重します
  • build(deps): https://github.com/HKUDS/LightRAG/pull/3670 の @dependabot[bot] により、openai 要件を <3.0.0,>=2.0.0 から >=2.0.0,<4.0.0 に更新します
