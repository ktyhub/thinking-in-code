LightRAG v1.4.7

パッチ 公開日2025年8月29日 出典HKUDS/LightRAG 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#ライトラグv1.4.7

重要な注意事項

  • Doc-id ベースのチャンク フィルタリング機能は PostgreSQL ベクトル ストレージから削除されました。
  • プロンプト テンプレートが更新され、すべての LLM キャッシュが無効になりました
  • FORCE_LLM_SUMMARY_ON_MERGE 環境変数のデフォルト値が 4 から 8 に変更されました。この調整により、ドキュメントのインデックス作成フェーズ中の LLM 呼び出しの数が大幅に減少し、ドキュメント全体の処理時間が短縮されます。
  • 複数の再ランク プロバイダー (Cohere AI、Jina AI、Aliyun Dashscope) のサポートを追加しました。再ランク付けが以前に有効になっており、再ランク付けを再度有効にするには新しい環境変数を設定する必要がある場合:
RERANK_BINDING=cohere
  • 特に大規模言語モデル (LLM) のタイムアウトを制御するために、新しい環境変数 LLM_TIMEOUT が導入されました。既存の TIMEOUT 変数は、Gunicorn ワーカーのタイムアウトを排他的に管理するようになりました。デフォルトの LLM タイムアウトは 180 秒に設定されています。以前に LLM タイムアウト構成に TIMEOUT 変数を使用していた場合は、代わりに LLM_TIMEOUT を使用するように設定を更新してください。
LLM_TIMEOUT=180
  • OpenAI および Ollama 大規模言語モデル (LLM) バインディング用の包括的な環境変数設定を追加します。 LLM 温度制御用の汎用 TEMPERATURE 環境変数は非推奨になりました。代わりに、LLM 温度はバインディング固有の環境変数を使用して設定されるようになりました。
# Temperature setting for OpenAI binding
OPENAI_LLM_TEMPERATURE=0.8

# Temperature setting for Ollama binding
OLLAMA_LLM_TEMPERATURE=1.0

無限の出力ループを軽減し、Qwen3 の貪欲なデコードを防ぐには、温度パラメーターを 0.8 と 1.0 の間の値に設定します。 モデルの「思考」モードを無効にするには、次の構成を参照してください。

### Qwen3 Specific Parameters depoly by vLLM
# OPENAI_LLM_EXTRA_BODY='{"chat_template_kwargs": {"enable_thinking": false}}'

### OpenRouter Specific Parameters
# OPENAI_LLM_EXTRA_BODY='{"reasoning": {"enabled": false}}'

サポート オプションの完全なリストを表示するには、次のコマンドを使用します。

lightrag-server --llm-binding openai --help
lightrag-server --llm-binding ollama --help
lightrag-server --embedding-binding ollama --help
  • 追加された新しい環境変数または新しいデフォルト値の完全なリスト:
# Timeout for LLM requests (seconds)
LLM_TIMEOUT=180

# Timeout for embedding requests (seconds)
EMBEDDING_TIMEOUT=30

### Number of summary segments or tokens to trigger LLM summary on entity/relation merge (at least 3 is recommended)
FORCE_LLM_SUMMARY_ON_MERGE=8

### Max description token size to trigger LLM summary
SUMMARY_MAX_TOKENS = 1200

### Recommended LLM summary output length in tokens
SUMMARY_LENGTH_RECOMMENDED=600

### Maximum context size sent to LLM for description summary
SUMMARY_CONTEXT_SIZE=12000

### RERANK_BINDING type:  null, cohere, jina, aliyun
RERANK_BINDING=null

### Enable rerank by default in query params when RERANK_BINDING is not null
# RERANK_BY_DEFAULT=True

### chunk selection strategies
###     VECTOR: Pick KG chunks by vector similarity, delivered chunks to the LLM aligning more closely with naive retrieval
###     WEIGHT: Pick KG chunks by entity and chunk weight, delivered more solely KG related chunks to the LLM
###     If reranking is enabled, the impact of chunk selection strategies will be diminished.
KG_CHUNK_PICK_METHOD=VECTOR

### Entity types that the LLM will attempt to recognize
ENTITY_TYPES=["person", "organization", "location", "event", "concept"]
