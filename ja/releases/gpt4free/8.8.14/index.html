gpt4free v8.8.14

#gpt4free v8.8.14

フル Changelog: https://github.com/xtekky/gpt4free/compare/v8.8.13...v8.8.14

ダウンロード オプション

Python パッケージ:

  • PyPI: pip install g4f==v8.8.14

実行可能ファイル (g4f-go、組み込み Python を備えた自己完結型):

  • Windows amd64: g4f-go-v8.8.14-windows-amd64.zip
  • Linux x64: g4f-go-v8.8.14-linux-amd64.zip
  • Linux ARM64: g4f-go-v8.8.14-linux-arm64.zip
  • macOS x64: g4f-go-v8.8.14-darwin-amd64.zip
  • macOS ARM64: g4f-go-v8.8.14-darwin-arm64.zip
  • FreeBSD amd64: g4f-go-v8.8.14-freebsd-amd64.zip

スタンドアロン サンドボックス ランチャー (Docker/Podman、イメージはオンデマンドで取得):

  • Windows amd64/arm64: g4f-sandbox-v8.8.14-windows-<arch>.zip
  • Linux amd64/arm64: g4f-sandbox-v8.8.14-linux-<arch>.zip
  • macOS amd64/arm64: g4f-sandbox-v8.8.14-darwin-<arch>.zip
  • Termux/Android arm64: g4f-sandbox-v8.8.14-android-arm64.zip (ネイティブ Python API、Docker なし)
  • デフォルトは小さい API 専用イメージ (latest-slim) です。 --desktop は、必要な場合にのみ完全なデスクトップ イメージを取得します。

Android アプリ:

  • Android APK: g4f-v8.8.14.apk

ブラウザ拡張機能 (Chrome/Edge):

  • g4f-browser-extension-v8.8.14.zip (解凍して、解凍されたものを chrome://extensions 経由でロード)

システム パッケージ:

  • WinGet: winget install gpt4free

Docker:

  • docker pull hlohaus789/g4f:v8.8.14
  • docker pull hlohaus789/g4f:v8.8.14-slim
  • docker pull hlohaus789/g4f:v8.8.14-sandbox-desktop

Docker サンドボックス AI ツール セット (1 つの click インストール、100 以上の異なる AI ツール):

  • docker pull hlohaus789/g4f:v8.8.14-sandbox-desktop — g4f API を備えた完全な Xfce デスクトップ (TigerVNC + noVNC) と 100 以上の異なる AI ツール用の 1 つの click の「インストール & 開く」メニュー: コーディング エージェント (OpenCode、Copilot CLI、Hermes、Aider など)、チャット UI、画像/オーディオ/ビデオ ツール、ゲートウェイ。
  • デスクトップ + API: http://localhost:8080/desktop/ — API: http://localhost:8080
  • 独自のアプリを /app/gpt4free にマウントし、エージェント設定を永続化します。 
    docker run -d --name g4f-sandbox-desktop \  -p 8080:8080 -p 5900:5900 --shm-size="2gb" \  -v ${PWD}:/app/gpt4free \  -v ${PWD}/sandbox-home/.config:/home/pn/.config \  -v ${PWD}/sandbox-home/.local:/home/pn/.local \  hlohaus789/g4f:v8.8.14-sandbox-desktop
  • ドキュメント: docker/sandbox-menu/README.md
