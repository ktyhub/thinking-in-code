Agent-Reach v1.4.0

マイナー 公開日2026年3月31日 出典Panniantong/Agent-Reach 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#エージェントリーチ v1.4.0

コアの変更: 6 つの主要なアップストリーム移行

このバージョンには、複数のチャネルからの上流ツールの大規模な移行が含まれており、非推奨のツール、不安定なソリューション、および高い導入しきい値の問題を解決します。

上流への移行

|チャンネル |古い計画 |新しいプラン |効果 | |------|--------|----------|------| | ツイッター/X |鳥 CLI (レポ 404) | twitter-cli (2,137 ⭐) |完全に使用できないチャンネルを修正する | | レディット | Exa クロール (頻繁にタイムアウト) | rdt-cli (304 ⭐) |検索 + 全文 + コメントへのフルアクセス、ログイン不要 | | 小紅書 | Docker MCP (導入しきい値が高い) | xhs-cli (1,477 ⭐) | pipx install は 1 行で実行でき、階層 2→1 | | WeChat パブリック アカウント | miku_ai (20ヶ月休止中) |エクサ検索＋閲覧 |ゼロ構成、階層 2→0 | | スノーボールクッキー | browser_cookie3 (15 か月間サービス停止中) |ルーキーピー (Rust カーネル) |より安定し、フォールバックを保持 | | ビリビリ |純粋な yt-dlp | yt-dlp + bili-cli (590 ⭐) |人気/ランキング/検索を追加 |

チャンネル調整

  • ➕ サイト B が bili-cli 拡張バックエンドを追加
  • ➖ Discord を削除します (メタデータのみ、実用的ではありません)
  • ➖ 見出しを削除します (HTML 解析は脆弱です)

コミュニティ PR マージ

  • #225 修正 (youtube): クロスプラットフォーム yt-dlp 構成パス (@biyusku)
  • #200 ドキュメント: 日本語 README (@eltociear)
  • #211 ドキュメント: Douyin/Xiaohongshu オプションの MCP ドキュメント (@JNHFlow21)

エンドツーエンドの検証

16 チャンネルすべてが実際のネットワークでテストされています。

  • ✅ Reddit: rdt search 実際の投稿とすべてのコメントに戻る
  • ✅ Twitter: twitter search は実際のツイート + インタラクション データを返します
  • ✅ ステーション B: bili hot が人気の動画と再生回数に戻ります
  • ✅ WeChat: Exa 検索で公式アカウントの記事と全文の読み取りが返されます
  • ✅ 小紅書: xhs CLI は正常にインストールされ、ログイン後に使用可能になります。
  • ✅ 77 のテストに合格

アップグレード方法

pip install --upgrade agent-reach
agent-reach doctor

注意: Twitter ユーザーはツールを再インストールする必要があります。

pipx install twitter-cli
# bird CLI 已弃用，可卸载：npm uninstall -g @steipete/bird
