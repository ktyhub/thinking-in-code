#ファイアクロールv2.6.0

#v2.6.0

ハイライト

  • 統合請求モデル - クレジットとトークンが単一のシステムに統合されました。 Extract はクレジット (15 トークン = 1 クレジット) を使用するようになり、既存のトークンはどこでも機能します。
  • ブランディング形式の完全リリース - Playground、MCP、JS、および Python SDK を完全にサポートします。
  • 変更追跡 - Web ページのコンテンツ更新をより迅速かつ確実に検出します。
  • 信頼性と速度の向上 - 信頼性が向上し、すべてのエンドポイントが大幅に高速化しました。
  • インスタント クレジット購入 - 自動リチャージを待たずに、ダッシュボードから直接クレジット パックを購入できます。
  • マークダウン解析の改善 - マークダウン変換とメインコンテンツ抽出の精度が強化されました。
  • 主要な安定性の修正 - 変更追跡の問題、PDF タイムアウトを修正し、エラー処理を改善しました。

何が変わったのか

  • fix(mu): https://github.com/firecrawl/firecrawl/pull/2345 の @tomkosm による v2 exp のバグ修正
  • https://github.com/firecrawl/firecrawl/pull/2346 の @amplitudesxd による waitFor (ENG-3481) でのインデックスの使用を許可
  • autoCharge リターンを修正し、https://github.com/firecrawl/firecrawl/pull/2341 の @abimaelmartell によるトップレベルのガードを追加
  • 修正: https://github.com/firecrawl/firecrawl/pull/2333 の @prashu0705 による 1000 URL の上限を解決するために、types.ts から MAX_MAP_LIMIT をインポート
  • 雑務: https://github.com/firecrawl/firecrawl/pull/2348 の @amplitudesxd による llm 抽出ログの改善
  • 修正: https://github.com/firecrawl/firecrawl/pull/2349 での @amplitudesxd によるエラー切り捨て
  • feat(go-html-to-md): 堅牢な PRE と… by @rafaelsideguide in https://github.com/firecrawl/firecrawl/pull/2321 でマークダウン変換を強化
  • feat(課金): https://github.com/firecrawl/firecrawl/pull/2352 の @mogery によるクレジットとトークンをマージします。
  • 雑務: https://github.com/firecrawl/firecrawl/pull/2354 の @amplitudesxd による geoip データベースの更新
  • @abimaelmartell によるブランディング フォーマットを https://github.com/firecrawl/firecrawl/pull/2326 に実装
  • https://github.com/firecrawl/firecrawl/pull/2357 の @devin-ai-integration[bot] による別のエラー メッセージで非 HTTP(S) プロトコルをフィルタリングします
  • https://github.com/firecrawl/firecrawl/pull/2360 の @devin-ai-integration[bot] により、JS および Python SDK にブランド形式のサポートを追加
  • 修正: https://github.com/firecrawl/firecrawl/pull/2361 の @abimaelmartell によるメタデータ抽出で無効なファビコン URL を適切に処理する
  • 特技: https://github.com/firecrawl/firecrawl/pull/2367 で @amplitudesxd による Webhook 配信の無効化を許可
  • 功績: https://github.com/firecrawl/firecrawl/pull/2371 の @devin-ai-integration[bot] によるドメイン パターンによるエンジン強制の追加
  • https://github.com/firecrawl/firecrawl/pull/2376 の @amplitudesxd による nuq コミットを元に戻す
  • CI: https://github.com/firecrawl/firecrawl/pull/2385 の @abimaelmartell によるサーバー テストから npm 監査を削除
  • ci: https://github.com/firecrawl/firecrawl/pull/2386 の @abimaelmartell による依存関係の監査を修正
  • (修正/ctracking) https://github.com/firecrawl/firecrawl/pull/2391 の @nickscamara による変更追跡の問題を修正
  • 更新: https://github.com/firecrawl/firecrawl/pull/2266 の @Chadha93 によるモデル選択による python-sdk の再帰的スキーマのサポートを追加
  • 修正: https://github.com/firecrawl/firecrawl/pull/2244 の @naaa760 による Python SDK の画像検索フィールド マッピング
  • 修正(api/スクレイプ): https://github.com/firecrawl/firecrawl/pull/2396 の @delong3 によるドキュメント + PDF スクレイピング ループ
