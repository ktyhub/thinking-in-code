firecrawl v2.2.0

#ファイアクロールv2.2.0

v2.2.0

機能

  • MCP バージョン 3 が公開されました。 HTTP トランスポートおよび SSE モードを使用したクラウド mcp の安定したサポート。 v2 および v1 と互換性があります。
  • Webhook: 署名 + 抽出サポート + イベント失敗をサポートするようになりました。
  • 地図が 15 倍高速になり、より多くの URL をサポート
  • 検索の信頼性の向上
  • 使用状況は API キーによって追跡されるようになりました
  • 追加の場所のサポート (CA、CZ、IL、IN、IT、PL、PT)
  • キューステータスエンドポイント
  • PDF 解析用に maxPages パラメーターを v2 スクレイピング API に追加しました

改善点

  • API:
    • 新しい /team/queue-status エンドポイント。
    • nuq 機能を追加しました。
    • VIASOCKET 統合を追加しました。
    • 拡張データを含む履歴のクレジット/トークン使用状況エンドポイント。
  • 学生プログラム: 学生プログラムを通じて、より多くの大学と学生が無料単位を取得できるようサポートします。
  • マップ: 15 倍高速になり、制限が 100k に増加しました
  • API のスクレイピング: PDF パーサーに maxPages パラメーターを追加しました。
  • Python SDK:
    • get_queue_status を aio + 検索結果のドキュメントの正規化に追加しました。
    • SDKs: 次のカーソルのページネーションと統合パラメータのサポートを追加しました。
  • インフラストラクチャ: 静的 IP プロキシ プール + プロキシ ロケーションのサポートを追加しました。
  • Webhook: 署名を実装し、送信をリファクタリングし、スクレイピング エラー イベントを追加しました。
  • パフォーマンス: マップが最適化され、Rust ネイティブが単一の NAPI ライブラリに変換されました。
  • CI/CD: CI が刷新され、プリコミット フック、クロスプラットフォーム ハーネスが追加されました。

🐛 修正

  • 同時実行制限のスケーリングを修正しました。
  • 検索結果のリンク/説明と空の結果の再試行メカニズムを修正しました。
  • 期限切れのスクリーンショット URL に再署名しました。
  • PDF タイトルから null 文字をトリミング + エンコードを修正。
  • サイトマップの解析を修正し、.gz サイトマップのサポートを追加しました。
  • js-sdk zod-to-json-schema インポートを修正しました。
  • Webhook データ形式の回帰を修正しました。
  • アカウントオブジェクトでのクレジット処理が改善されました。

🛠️ 家事とその他

  • 未使用の依存関係を削除し、CONTRIBUTING.md を更新しました。
  • デバッグ ログを追加し、CI ビルド中にスクリプトを無視しました。
  • さまざまな依存関係の改善とビルドの改善。
