#ファイアクロールv2.0.0

v2.0.0 のご紹介

主な改善点

  • デフォルトで高速: リクエストは maxAge のデフォルトで 2 日間キャッシュされ、blockAds、skipTlsVerification、removeBase64Images などの適切なデフォルトが有効になります。

  • 新しい概要形式: ページ コンテンツの簡潔な概要を直接受信する形式として "summary" を指定できるようになりました。

  • JSON 抽出の更新: JSON 抽出と変更追跡では、オブジェクト形式 { type: "json", prompt, schema } が使用されるようになりました。古い "extract" 形式は "json" に名前が変更されました。

  • 強化されたスクリーンショット オプション: オブジェクト フォーム: { type: "screenshot", fullPage, quality, viewport } を使用します。

  • 新しい検索ソース: sources パラメーターを設定すると、Web 結果に加えて "news" および "images" も検索できます。

  • プロンプト付きのスマート クロール: クロールする自然言語 prompt を渡すと、システムがパス/制限を自動的に導出します。新しいcrawl-params-previewエンドポイントを使用して、ジョブを開始する前に派生オプションを検査します。

クイック移行チェックリスト

  • v1 client の使用法を v2 clients に置き換えます。
    • JS: const firecrawl = new Firecrawl({ apiKey: 'fc-YOUR-API-KEY' }) ※Python：firecrawl = Firecrawl(api_key='fc-YOUR-API-KEY')
    • API: 新しい https://api.firecrawl.dev/v2/ エンドポイントを使用します。
  • アップデート形式:
    • 必要に応じて "summary" を使用してください
    • JSON モード: JSON の抽出には { type: "json", prompt, schema } を使用します
    • スクリーンショットとスクリーンショット@fullPage: オプションを指定するときにスクリーンショット オブジェクト形式を使用します
  • SDK で標準化された非同期フローを採用:
    • クロール: startCrawl + getCrawlStatus (または crawl ウェイター)
    • バッチ: startBatchScrape + getBatchScrapeStatus (または batchScrape ウェイター)
    • 抜粋: startExtract + getExtractStatus (または extract ウェイター)
  • クロール オプションのマッピング (下記を参照)
  • クロール prompt を crawl-params-preview で確認してください

フォーマットとスクレイピングのオプション

  • 基本には文字列形式を使用します: "markdown"、"html"、"rawHtml"、"links"、"summary"。 ※parsePDFの代わりにparsers: [ { "type": "pdf" } | "pdf" ]を使用してください。
  • JSON、変更追跡、およびスクリーンショットのオブジェクト形式を使用します。

JSON形式

 curl -X POST https://api.firecrawl.dev/v2/scrape \
     -H 'Content-Type: application/json' \
     -H 'Authorization: Bearer YOUR_API_KEY' \
     -d '{
       "url": "https://docs.firecrawl.dev/",
       "formats": [{
         "type": "json",
         "prompt": "Extract the company mission from the page."
       }]
     }'

スクリーンショットの形式

  curl -X POST https://api.firecrawl.dev/v2/scrape \
      -H 'Content-Type: application/json' \
      -H 'Authorization: Bearer YOUR_API_KEY' \
      -d '{
        "url": "https://docs.firecrawl.dev/",
        "formats": [{
          "type": "screenshot",
          "fullPage": true,
          "quality": 80,
          "viewport": { "width": 1280, "height": 800 }
        }]
      }'
