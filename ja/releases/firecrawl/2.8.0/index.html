#v2.8.0

ファイヤークロール v2.8.0 登場!

Firecrawl v2.8.0 は、新しいスキルを含む、エージェント ワークフロー、開発者ツール、API と SDK 全体のセルフホスト型展開に大幅な改善をもたらします。

  • 新しい Spark 1 Fast モデルを利用して、数千の /agent クエリを同時に実行するための並列エージェント。
  • スクレイピング、検索、クロール、マップ コマンドを完全にサポートする Firecrawl CLI。
  • AI エージェント (Claude Code、Codex、OpenCode) が Firecrawl を自律的に使用できるようにする Firecrawl スキル。
  • /agent を強化する 3 つの新しいモデル: 即時検索用の Spark 1 Fast (現在 Playground でのみ利用可能)、複雑な調査クエリ用の Spark 1 Mini、および高度な抽出タスク用の Spark 1 Pro。
  • Webhook、モデル選択、新しい MCP サーバー ツールなどのエージェントの機能強化。
  • 検索実行の高速化や Redis 呼び出しの最適化など、プラットフォーム全体のパフォーマンスが向上しました。
  • Zod v4 との互換性を含む SDK の改善。

他にもたくさんありますので、以下をチェックしてください。

新機能

  • 並行エージェント
    自動障害処理とインテリジェントなウォーターフォール実行により、数千の /agent クエリを並行して実行します。 Spark 1-Fast を搭載して即時検索を実現し、完全な調査が必要な複雑なクエリのために Spark 1 Mini に自動的にアップグレードします。

  • ファイアクロール CLI
    スクレイピング、検索、クロール、マップ コマンドを完全にサポートする Firecrawl の新しいコマンド ライン インターフェイス。 npm install -g firecrawl-cliと一緒に取り付けます。

  • ファイアクロールスキル
    Claude Cursor、Codex、OpenCode などのエージェントが Web scraping およびデータ抽出に Firecrawl を使用できるようにします (npx skills add firecrawl/cli. 経由でインストール可能)

  • Spark モデル ファミリー
    /agent を強化する 3 つの新しいモデル: 即時検索用の Spark 1 Fast (現在 Playground で利用可能)、60% 低コストで日常の抽出タスク用の Spark 1 Mini (デフォルト)、最大の精度を必要とする複雑なマルチドメイン研究用の Spark 1 Pro。 Spark 1 Pro は最大 50% の再現率を達成し、Mini は最大 40% の再現率を達成します。どちらも、タスクごとに 4 ～ 7 倍のコストがかかるツールを大幅に上回っています。

  • Firecrawl MCP サーバー エージェント ツール
    MCP 対応エージェントを介した自律的な Web データ収集のための新しい firecrawl_agent および firecrawl_agent_status ツール。

  • エージェント Webhook
    エージェント エンドポイントは、ジョブの完了と進行状況に関するリアルタイム通知のための Webhook をサポートするようになりました。

  • エージェント モデルの選択
    エージェント エンドポイントは model パラメーターを受け入れ、ステータス応答にモデル情報を含めるようになりました。

  • マルチアーチ Docker イメージ
    セルフホスト型展開では、amd64 に加えて linux/arm64 アーキテクチャもサポートされるようになりました。

  • サイトマップのみのクロール モード
    リンクをたどらずにサイトマップ URL を排他的に使用する新しいクロール オプション。

  • ignoreCache マップ パラメータ
    URL をマッピングするときにキャッシュされた結果をバイパスする新しいオプション。

  • /map のカスタム ヘッダー
    マップ エンドポイントがカスタム リクエスト ヘッダーをサポートするようになりました。

  • 背景画像の抽出
    Scraper は CSS スタイルから背景画像を抽出するようになりました。

  • エラー メッセージの改善
    ユーザーに表示されるすべてのエラー メッセージには、問題の診断に役立つ詳細な説明が含まれるようになりました。

API の改善点

  • 同時実行制限なしの検索 - 検索のスクレイピングがキューのオーバーヘッドなしで直接実行されるようになりました。
  • 要求されたアクションが利用可能なエンジンでサポートされていない場合、サポートされていないアクションに対して明確なエラーが発生し、400 を返します。
  • 追跡しやすくするために、ジョブ ID が検索メタデータに含まれるようになりました。
  • メタデータ応答に検出されたタイムゾーンが含まれるようになりました。
  • メタデータ タイトルが欠落している場合は、og:title または twitter:title から埋め戻します。
  • Google スプレッドシートの URL を書き換えるときは、gid パラメータを保持します。
  • バッチ スクレイピング ステータス ページネーションの v2 パスを修正しました。
  • 既存のクロールに追加するときにチームの所有権を検証します。
  • カスタム ビューポートまたは品質設定を使用したスクリーンショットはキャッシュをバイパスするようになりました。
  • エンドポイント間での Redis 呼び出しが最適化されました。
  • 過剰な robots.txt のフェッチと解析を削減しました。
  • 最小リクエスト タイムアウト パラメータが設定可能になりました。

SDK の改善

JavaScript SDK

  • Zod v4 の互換性 — エラー検出が改善され、スキーマ変換が Zod v4 で機能するようになりました。
  • Watcher のエクスポート - Watcher および WatcherOptions が SDK エントリポイントからエクスポートされるようになりました。
  • エージェント Webhook サポート — エージェント呼び出し用の新しい Webhook オプション。
  • ポーリングのエラー再試行 — SDK は、一時的なエラーの後にポーリングを再試行します。
  • 例外のジョブ ID - エラー例外にはデバッグ用の jobId が含まれるようになりました。

Python SDK

  • 結果を反復処理するための手動ページネーション ヘルパー。
  • エージェント Webhook サポートがエージェント client に追加されました。
  • エージェント エンドポイントはモデル選択パラメーターを受け入れるようになりました。
  • メタデータに同時実行制限情報が含まれるようになりました。
  • クロール リクエストにおける max_pages の処理を​​修正しました。

ダッシュボードの改善

※ダークモードに対応しました。

  • 使用量ページで、クレジットの使用量を日別に表示できるようになりました。
  • アクティビティ ログ ページで、使用された API キーでフィルターできるようになりました。
  • Playground で「画像」出力形式がサポートされるようになりました。
  • すべての管理者がチームのサブスクリプションを管理できるようになりました。

品質とパフォーマンス

  • 大きな HTML ドキュメントのマークダウン変換チェックをスキップします。
  • パフォーマンスを向上させるために、Google ドキュメントを PDF ではなく HTML としてエクスポートします。
  • PDF およびドキュメントのロゴ検出とエラー メッセージが改善され、ブランド形式が改善されました。
  • lopdf メタデータの読み込みパフォーマンスが向上しました。
  • html-to-markdown モジュールを更新し、複数のバグを修正しました。
  • マークダウン サービス本文の制限が増加し、リクエスト ID のログが追加されました。
  • キャンセルされたジョブやエンジン エラーに対する Sentry フィルタリングが改善されました。
  • 抽出の競合状態と RabbitMQ ポイズン ピルの処理を修正しました。
  • コードベース全体で Firecrawl 設定を一元化。
  • CVE-2025-59466 や lodash プロトタイプ汚染など、複数のセキュリティ脆弱性が修正されました。

自己ホスト型の改善

  • ローカル インスタンスの firecrawl --api-url http://localhost:3002 を介した CLI カスタム API URL のサポート。
  • Apple Silicon および ARM サーバーのマルチ アーキテクチャ イメージを介した ARM64 Docker のサポート。
  • すぐに使用できる docker-compose データベース資格情報を修正しました。
  • Chromium パスの問題によって引き起こされる Playwright サービスの起動を修正しました。
  • Node.js を固定マイナーではなくメジャー バージョン 22 に更新しました。
  • RabbitMQ ヘルスチェックエンドポイントを追加しました。
  • docker-compose での PostgreSQL ポートの露出を修正しました。
