firecrawl v2.4.0

#ファイアクロールv2.4.0

v2.4.0

新機能

  • 新しい PDF 検索カテゴリ - .pdf カテゴリを指定することで、v2/検索エンドポイント経由で PDF のみを検索できるようになりました。
  • Gemini 2.5 Flash CLI 画像エディタ — Firecrawl + Gemini 2.5 Flash 統合を使用して、CLI で直接画像を作成および編集します (#2172)
  • x402 検索エンドポイント (/v2/x402) — 精度と速度が向上した次世代検索 API を追加しました (#2218)
  • RabbitMQ イベント システム — Firecrawl ジョブは、イベントベースの通信と Postgres からのプリフェッチをサポートするようになりました (#2230、#2233)
  • 改善されたクロール ステータス API — 新しい crawl_status_2 RPC を使用した、より正確でリアルタイムのクロール ステータス レポート (#2239)
  • 低結果と Robots.txt の警告 — クロールが robots.txt によって制限されている場合、または結果がほとんどない場合に、ユーザーは明確なフィードバックを受け取るようになりました (#2248)
  • 拡張トレース (OpenTelemetry) — サービス全体の可観測性を向上させるために大幅に改善された分散トレース (#2219)
  • メトリクスと分析 — スクレイプ エンドポイントと検索エンドポイントの両方にリクエスト レベルのメトリクスを追加しました (#2216)
  • セルフホスト Webhook のサポート — Webhook をセルフホスト環境のプライベート IP アドレスに配信できるようになりました (#2232)

改善点

  • Docker イメージ サイズの削減 — Chromium をインストールするだけで、Playwright サービスのイメージ サイズが 1 GB 削減されました (#2210)
  • Python SDK の機能強化 — "cancelled" ジョブ ステータスの処理とポーリング間隔の修正を追加しました (#2240、#2265)
  • ノード SDK タイムアウトの高速化 — Axios タイムアウトが正しく伝達されるようになり、高負荷時の信頼性が向上しました (#2235)
  • クロール パラメーター プレビューの改善 — クロール パラメーター プレビューのプロンプトと検証の強化 (#2220)
  • Zod スキーマ検証 — 余分なフィールドを拒否する、より厳密な API パラメータ検証 (#2058)
  • Redis ジョブ処理の改善 — Redis の取得をより安定させるために、getDoneJobsOrderedUntil のエッジ ケースを修正しました (#2258)
  • マークダウンと YouTube の修正 — YouTube キャッシュと空のマークダウン概要のバグを修正しました (#2226、#2261)
  • ドキュメントとメタデータの更新 - README の更新と新しいメタデータ フィールドが JS SDK (#2250、#2254) に追加されました
  • API ポート構成の改善 — API は、環境定義のポート (#2209) を考慮するようになりました。

修正

  • 再帰的 $ref スキーマ検証のエッジケースを修正 (#2238)
  • 列挙型配列がオブジェクトに誤って変換される問題を修正しました (#2224)
  • ハーネスのタイムアウトとセルフホスト型 docker-compose.yaml の問題を修正 (#2242、#2252)
