firecrawl v2.1.0

#ファイアクロールv2.1.0

ファイアクロール v2.1.0 登場！

✨ 新機能

  • 検索カテゴリ: categories パラメータを使用して、特定のカテゴリで検索結果をフィルタリングします。
    • github: GitHub リポジトリ、コード、問題、ドキュメント内を検索します。
    • research: 学術および研究の Web サイト (arXiv、Nature、IEEE、PubMed など) を検索します。
    • さらに近日公開予定
  • 画像抽出: v2 スクレイピング エンドポイントに画像抽出サポートを追加しました。
  • データ属性 Scraping: data-* 属性の抽出をサポートするようになりました。
  • ハッシュベースのルーティング: クロール エンドポイントがハッシュベースのルートを処理できるようになりました。
  • Google ドライブ Scraping の改善: Google ドライブから TXT、PDF、スプレッドシートをスクレイピングする機能を追加しました。
  • PDF の機能強化: PDF タイトルを抽出し、メタデータに表示します。
  • API の機能強化:
    • マップ エンドポイントは最大 100,000 件の結果をサポートします。
  • Helm チャート: Firecrawl デプロイメント用に追加された初期 Helm チャート。
  • セキュリティ: XFF スプーフィングに対する保護が強化されました。

🛠 修正

  • Google 検索スクレイパーの UTF-8 エンコーディングを修正しました。
  • プレビュー モードでのクロール ステータスを復元しました。
  • Python SDK で欠落していたメソッドを修正しました。
  • scrapeOptions.formats を使用した v2 検索の JSON 応答処理を修正しました。
  • v0 スクレイピングの credits_billed のフィールド人口を修正しました。
  • v2 検索のドキュメント フィールド オーバーレイが改善されました。

👥 新しい貢献者

  • @kelter-antunes
  • @vishkrish200
  • @ieedan

🔗 フル Changelog

何が変わったのか

  • 修正: https://github.com/firecrawl/firecrawl/pull/1924 の @kelter-antunes による Google 検索スクレイパーで UTF-8 エンコーディングを適切に処理する
  • 偉業(api): https://github.com/firecrawl/firecrawl/pull/2008 の @vishkrish200 による v2 スクレイピング エンドポイントに画像抽出サポートを追加
  • 特技(api): https://github.com/firecrawl/firecrawl/pull/2006 の @vishkrish200 によるスクレイピング エンドポイントでの data-* 属性の抽出のサポート
  • 功績: @JakobStadlhuber による Firecrawl デプロイメントの初期 Helm チャートを https://github.com/firecrawl/firecrawl/pull/1262 に追加
  • 特技(api/クロール): https://github.com/firecrawl/firecrawl/pull/2031 で @mogery によるハッシュベースのルーティングをサポート
  • 修正(python-sdk): https://github.com/firecrawl/firecrawl/pull/2050 の @rafaelsideguide による client のメソッドが欠落していました
  • feat(countryCheck): https://github.com/firecrawl/firecrawl/pull/2051 の @mogery による XFF スプーフィングに対する保護の向上
  • 修正: https://github.com/firecrawl/firecrawl/pull/2052 で @ieedan によるscrapeOptions.formats を使用する場合、v2 /search 応答に json を含める
  • 偉業(scrapeURL/rewrite): Google ドライブの TXT/PDF ファイルとシートをスクレイピング (https://github.com/firecrawl/firecrawl/pull/2053 の @mogery による)
  • https://github.com/firecrawl/firecrawl/pull/2060 の @nickscamara による README.md を更新
  • (修正/クロール) https://github.com/firecrawl/firecrawl/pull/2061 の @nickscamara によりプレビュー モードでクロール ステータスを再度有効にします
  • feat(pdf-parser): PDF タイトルを取得し、https://github.com/firecrawl/firecrawl/pull/2062 の @mogery によってメタデータに表示されます。
  • 修正(v2/検索): https://github.com/firecrawl/firecrawl/pull/2054 の @mogery によるスプレッド演算子を介してドキュメント フィールドをオーバーレイ
  • feat(api): https://github.com/firecrawl/firecrawl/pull/2049 の @mogery による課金関数に向けて api_key_id を伝播します。
  • feat(api/map): 新しい RPC を使用 + 制限の最大値を 100k に設定 (https://github.com/firecrawl/firecrawl/pull/2065 の @mogery により)
  • 修正(api/v0/scrape): https://github.com/firecrawl/firecrawl/pull/2066 の @mogery によって Credits_billed フィールドにデータを入力
