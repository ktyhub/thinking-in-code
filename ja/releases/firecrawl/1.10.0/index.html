firecrawl v1.10.0

マイナー 公開日2025年6月3日 出典firecrawl/firecrawl 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#ファイアクロールv1.10.0

Web 検索と Firecrawl の強力な scraping 機能を組み合わせた、新しい検索 API エンドポイントのリリースを発表できることを嬉しく思います。

検索機能:

  • 1 回の API 呼び出しで Web を検索し、結果から完全なコンテンツを取得します
  • 特定の出力形式を選択します (マークダウン、HTML、リンク、スクリーンショット)
  • 検索パラメーター (言語、国、時間範囲、結果の数) をカスタマイズします。
  • Python および Node.js の SDK の完全サポート

その他の機能

  • scraping (scrapeURL、js-sdk) #1551、#1602 の自動モード プロキシ
  • scrapeURL/pdf #1570、#1604、#1592 のタイムアウト処理とコンテンツ タイプの改善
  • Redis の改善: 個別の非エビクション Redis サポート #1600
  • 検索の改善: ignoreBlockedURLs、同時実行制限を無視 #1580、#1617
  • 同時実行ログ用の新しい /cclog エンドポイント #1589
  • メタデータ抽出に itemprop 属性が含まれるようになりました #1624
  • 自己ホスト型: デプロイ可能な Playwright イメージ #1625

修正と改善

  • LLMs.txt + バイパス オプションのサブドメイン処理の改善 #1557
  • URL 検証と特殊文字処理の改善 #1547
  • ゾンビ ワーカーのクリーンアップ + 抽出ステータスの TTL 処理 #1575、#1599
  • 同時実行キューのロジックとレート リミッターのオーバーライドを修正 #1595、#1593
  • 検索ページネーションと堅牢なフェッチのためのロギングの向上 #1572、#1588
  • 軽微な修正: og:locale:alternate、広告ブロックの切り替え、Playwright 専用ロジック、不正なメタデータ配列 #1597、#1616、#1574

テストとドキュメント

  • MAX_RAM および MAX_CPU 環境変数ドキュメントを追加 #1581
  • テストインフラストラクチャの改善 #1623

何が変わったのか

  • サブドメインに関する LLMs.txt キャッシュのバグを修正し、https://github.com/mendableai/firecrawl/pull/1557 の @devin-ai-integration によるバイパス オプションを追加
  • FIR-1951: https://github.com/mendableai/firecrawl/pull/1547 の @devin-ai-integration によるクエリ パラメーター内の特殊文字の URL 検証を修正
  • feat(scrapeURL): プロキシ自動モード (FIR-1853) by @mogery (https://github.com/mendableai/firecrawl/pull/1551)
  • feat(scrapeURL/pdf/mu): https://github.com/mendableai/firecrawl/pull/1570 の @mogery によるタイムアウトと created_at (FIR-2008) を追加
  • fix(auto_charge): https://github.com/mendableai/firecrawl/pull/1571 の @mogery による ACUC クリア (FIR-1805) を修正
  • 修正 (api/search): ページ オプションを正しくログに記録 (FIR-2015) (https://github.com/mendableai/firecrawl/pull/1572 の @mogery による)
  • https://github.com/mendableai/firecrawl/pull/1566 内の @emircanerkul による docker-compose.yaml コメントを更新
  • ホットフィックス: ゾンビ ワーカーを強制終了し、タイムアウトをより適切に尊重する (FIR-2034) by @mogery (https://github.com/mendableai/firecrawl/pull/1575)
  • 修正: https://github.com/mendableai/firecrawl/pull/1574 の @devin-ai-integration による例外を含むメタデータ配列を文字列に連結する
  • https://github.com/mendableai/firecrawl/pull/1578 の @rafaelsideguide による sdk/未定義応答ハンドル エラーを修正
  • 偉業(python-sdk/CrawlWatcher): https://github.com/mendableai/firecrawl/pull/1577 の @mogery により WebSocket (FIR-2038) から最大ペイロード サイズを削除
  • FIR-2006: https://github.com/mendableai/firecrawl/pull/1569 の @devin-ai-integration による Deep Research API の maxUrls と timeLimit パラメータを修正
  • ドキュメント: https://github.com/mendableai/firecrawl/pull/1581 の @devin-ai-integration による MAX_RAM および MAX_CPU 環境変数のドキュメントを追加
  • 偉業(検索):ignoreBlockedURLs (FIR-1954) by @mogery (https://github.com/mendableai/firecrawl/pull/1580)
  • fix(queue-worker): https://github.com/mendableai/firecrawl/pull/1582 の @mogery によってすべての追加可能な URL が既にロックされている場合 (FIR-1936)、クロールを終了します。
  • feat(api/extract): https://github.com/mendableai/firecrawl/pull/1584 の @mogery によるスクレープ (FIR-2061) に由来するスクレープの元として抽出物を表示します。
  • feat(api/v1/extract):ignoreInvalidURLs (FIR-1948) by @mogery (https://github.com/mendableai/firecrawl/pull/1585)
  • 修正(robustFetch): https://github.com/mendableai/firecrawl/pull/1588 の @mogery による選択的ロギング (FIR-2072)
  • feat(scrapeURL, logJob): pdf ページ数を db に記録 (FIR-2068) by @mogery (https://github.com/mendableai/firecrawl/pull/1587)
  • feat(concurrency-log): https://github.com/mendableai/firecrawl/pull/1589 の @mogery による cclog エンドポイント (FIR-2067) を追加
  • 特技: FC 側で PDF を解析し、タイムアウトが長すぎる場合は拒否 (FIR-2083) by @mogery (https://github.com/mendableai/firecrawl/pull/1592)
  • feat(queue-worker/afterJobDone): https://github.com/mendableai/firecrawl/pull/1595 の @mogery による ccq 挿入ロジック (FIR-2082) の改善
  • 修正(v1): https://github.com/mendableai/firecrawl/pull/1593 の @mogery による FIRE-1 レート リミッター (FIR-2090) による rateLimiterMode の上書きを回避
  • fix(html-transformer): og:locale:alternate の outName が正しくありません (FIR-2101) by @mogery (https://github.com/mendableai/firecrawl/pull/1597)
  • fix(extract-status): https://github.com/mendableai/firecrawl/pull/1599 の @mogery により TTL が経過した後でも抽出ステータスを取得できるようにしました
  • feat(scrapeURL): https://github.com/mendableai/firecrawl/pull/1601 の @mogery による DX (FIR-2137) に一致する URL の unnormalizedSourceURL を追加
  • feat(apps/api): https://github.com/mendableai/firecrawl/pull/1600 の @mogery による個別の非エビクション Redis のサポートを追加

  • feat(scrapeURL/pdf): ページごとに n クレジットを請求 (FIR-1934) by @mogery (https://github.com/mendableai/firecrawl/pull/1553)
