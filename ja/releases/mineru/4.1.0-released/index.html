MinerU 4.1.0-released

#MinerU マイネル-4.1.0-released

中国語

  • メインストリーム プラットフォームと GPU 自動アクセラレーション: デフォルトのインストールでは、Windows、Linux、macOS で実行される CPU に加え、Intel、AMD、NVIDIA、Apple Silicon と互換性のある独立または統合グラフィックス推論アクセラレーションがサポートされます。適切な GPU または CPU を自動的に選択します。代表的なコア推論シナリオは、CPU よりも約 2 ～ 3 倍高速です。
  • 統合タスクの非同期インターフェイス: 古い /v1/uploads および /v1/parse/jobs ワークフローを /v1/tasks に置き換えます。/v1/tasks は、ファイル リスト、URL 入力、キャッシュなしの送信、ファイルごとの実行と結果のダウンロード、および統合されたステータス クエリとキャンセル操作をサポートします。詳細については、「タスク インターフェイスの説明」(https://github.com/opendatalab/MinerU/blob/mineru-4.1.0-released/docs/zh/usage/tasks.md) を参照してください。
  • 復元可能な同期解析サービス: スタンドアロン file-parse-server は、単一ファイルのアップロードと添付ファイルの返却、待機タイムアウト後のクエリ、リクエスト ID による既知のタスクの回復をサポートする /v1/file_parse を提供します。詳細については、ファイル解析インターフェースの説明 を参照してください。
  • ハードウェア診断とギアの推奨事項: 適切なサービス ギアの選択、機器、動作環境、および校正情報の表示に役立つ mineru-kit hardware detect および hardware info を追加しました。

アップグレードのヒント: Python のサポート範囲は 3.11 ～ 3.14 に調整されています。今回は、HTTP インターフェースの破壊的な変更が含まれています。サーバー、ルーター、SDK、クライアントのアップグレードを調整してください。詳細については、「4.1 移行手順」(https://github.com/opendatalab/MinerU/blob/mineru-4.1.0-released/docs/zh/reference/migration_4_1.md) を参照してください。

英語

  • 主要なプラットフォームと GPU にわたる自動アクセラレーション: デフォルトのインストールでは、Windows、Linux、macOS での CPU 推論に加え、統合グラフィックスを含む互換性のある Intel、AMD、NVIDIA、Apple Silicon GPU でのアクセラレーション推論がサポートされています。 MinerU は、適切な GPU または CPU の実行を自動的に選択します。代表的なコア推論ワークロードは、約 2 ～ 3 倍の CPU 速度で実行されます。
  • 統合された非同期タスク API: /v1/tasks は、以前の /v1/uploads および /v1/parse/jobs ワークフローを置き換え、ファイル マニフェスト、URL 入力、キャッシュされたアップロードの再利用、ファイルごとの実行とダウンロード、ステータス クエリ、およびキャンセルをサポートします。 タスク API リファレンス を参照してください。
  • 回復可能な同期ファイル解析: スタンドアロン file-parse-server は、単一ファイルのアップロードと添付ファイル応答用の /v1/file_parse を提供し、待機タイムアウト後のクエリと既知のタスクを回復するための要求 ID を提供します。 ファイル解析 API リファレンス を参照してください。
  • ハードウェア診断と層の推奨事項: 新しい mineru-kit hardware detect および hardware info コマンドは、適切なサービス層を選択し、デバイス、ランタイム バージョン、および調整情報を検査するのに役立ちます。

アップグレードに関する注意: サポートされている Python バージョンは現在 3.11 ～ 3.14 です。このリリースには、HTTP API の破壊的な変更が含まれています。サーバー、ルーター、SDK、client をまとめてアップグレードします。 4.1 移行ガイド を参照してください。
