#MinerU マイネル-4.0.12-released

何が変わったのか / 何が変わったのか

新機能/機能

  • V1 API: 自己展開 API およびルーターには、ファイルの送信、ステータスのクエリ、および JSON/ZIP 結果の一度の取得をサポートする /v1/tasks 非同期便利なインターフェイスと /v1/file_parse 同期パッケージが追加されます。タスク ID を /v1/parse/jobs / V1 API と共有: 非同期 /v1/tasks および同期 /v1/file_parse コンビニエンス エンドポイントを自己ホスト型 API サーバーおよびルーターに追加し、1 回のリクエストでファイル送信、ステータス クエリ、既存の解析ジョブ ID を共有する JSON/ZIP 結果を実行します。
  • アップロードの再利用: SHA-256 プリフライトと既存の file_id 参照をサポートします。 raw バイトのエンドポイントは、scripts/http_task_example.sh の client の例を使用して、キャッシュ ヒット時に本文を読み取る前に応答できます。

改善/改善

  • ルーター: ワーカーの状態、解析機能、未完了のジョブ負荷に基づいてスケジュールを設定し、同じ負荷のワーカー間でローテーションし、ワーカー間の入力コピー、予約、負荷解放を改善します。
  • リソースの保持: API サーバーとルーターは、デフォルトで 24 時間後に期限切れのリソースを収集します。 --retention-seconds または MINERU_API_RETENTION_SECONDS を構成し、0 を使用して自動リサイクル自動収集を無効にします。
  • モデルのライフサイクル: 致命的なエンジン エラーを検出して 503 engine_dead を返し、バックオフで管理対象ワーカーの世代を回復し、古い応答を拒否します。
  • トーチ CPU: 明示的な設定、有効な CPU クォータ、および既存の下限を使用してオペレータ スレッドを制限し、選択した制限を後続のワーカー スレッドに適用します。
  • API ドキュメント: オフライン アクセス、ベアラー認証、およびリバース プロキシ パス プレフィックスを使用して Swagger/ReDoc アセットをローカルで提供する / API ドキュメント: オフライン アクセス、ベアラー承認およびリバース プロキシ パス プレフィックスを使用して Swagger/ReDoc アセットをローカルで提供する

修正

  • ルーター: ワーカー間の入力クリーンアップ後にジョブの保持を開始し、収集とワーカーの削除を通じて所有者ごとの生涯使用量を保持し、ワーカーの選択前に無効な出力形式を拒否します。
  • PDF: スキャンされた PDF ルーティングとネイティブ テーブル モデル フォールバックの回帰カバレッジを使用して、Python/Rust パス全体にわたる CJK 境界句読点と生成されたスペースの処理を修復します。
  • レイアウト分析: PP-DocLayoutV2 モデル クラスのしきい値を復元し、Torch/ONNX 出力フィルタリングを読み取り順序候補の有効性と調整します / レイアウト: PP-DocLayoutV2 モデル クラスのしきい値を復元し、Torch/ONNX 出力フィルタリングを読み取り順序候補の有効性と調整します
  • Office: パブリック DocVortex 解析インターフェイスを介して DOCX/PPTX テーブルにリッチ テキスト ハイパーリンクを保存します。

依存関係/依存関係

  • docvortex の最小バージョンは 0.5.16 (>=0.5.16,<1) にアップグレードされます/docvortex>=0.5.16,<1 が必要です
  • fastapi-オフライン (>=1.7.7,<2) を追加/fastapi-オフライン>=1.7.7,<2 を追加

アップグレードに関する注意事項

  • コンビニエンス エンドポイントは V1 名前空間を使用します。同期待機タイムアウトは、タスクの続行中にタスク参照を含む 202 を返すため、clients は結果のポーリングを続けることができます。
  • 製品を長期保存する場合は、長期保存の保存期間内に出力をダウンロードするか、展開に合わせて保存期間を調整してください。
