nacos 3.1.1

パッチ 公開日2025年11月26日 出典alibaba/nacos 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#ナコス3.1.1 このリリースは、Nacos の MCP および A2A (エージェント間) 機能の強化、システムの安定性の向上、セキュリティと構成管理の改良に重点を置いています。主な追加機能には、エージェント エンドポイントのバッチ登録のサポート、MCP サーバーのインポート中のバージョンのマージ、overrideExisting オプションを使用した MCP サーバーの更新の柔軟性の強化などが含まれます。このリリースでは、インバウンド通信とアウトバウンド通信の両方に対するデフォルトのセキュリティ構成サポートも導入され、安全な AI エージェント対話の基盤が築かれます。 このバージョンでの詳細な変更点は次のとおりです。

機能

[#13867] MCPサーバーの更新時の既存の設定の上書きをサポートします。 [#13922] コアスレッドのタイムアウトを許可するスレッドプール設定を追加しました。 [#13946] AgentEndpoint モデルをリファクタリングし、高度なプロトコルとクエリをサポートする新しいフィールドを追加しました。 [#13953] インバウンドおよびアウトバウンドのセキュリティスキームの選択と設定を含む、デフォルトのセキュリティ構成のサポートを追加しました。 [#13957] エージェントエンドポイントのバッチ登録をサポートします。 [#13951] コンソールモジュールに構成可能な CORS フィルターを追加しました。

拡張/リファクタリング

[#13822] スレッドプールの枯渇を防ぐために、client エグゼキュータとログインスケジュールされたエグゼキュータの間で責任を分けます。 [#13863] shutdown.sh スクリプトを最適化して、複数の PID を 1 行に結合し、よりクリーンなプロセス終了を実現します。 [#13911] ストリーミング可能なプロトコルサーバーをサポートするために importToolsFromMcp API を強化しました。 [#13914] コードのリンティングと保守性を向上させるために、checkStyle プラグインのバージョンをアップグレードします。 [#13945] MCPサーバー仕様をインポートする際のバージョンのマージをサポートします。 [#13963] configTags と desc の戻りをサポートするために、構成 api のリストをリファクタリングしました。

バグ修正

[#13140] client ネームスペースが空の場合の ConfigChangeNotifyRequest の一貫したネームスペース処理を修正しました。 [#13860] ConfigMigrateService における潜在的な null ポインター例外のリスクを修正しました。 [#13866] インポートされたMCPサーバーをコンソールで編集できない問題を修正しました。 [#13869] 依存関係の注入が欠落しているため、Bean 'consoleHealthController' を作成する際のエラーを修正しました。 [#13877] 不正なコンテキスト伝播を引き起こすMcpRemoteHandlerのnamespaceIdの問題を修正しました。 [#13882] 同期ロックを修正し、スレッドの安全性を確保するために TpsControlManager に volatile キーワードを追加しました。 [#13884] インポート中のMCPサーバー検証APIでのJSON解析エラーを修正しました。 [#13902] ロガー初期化ロジックを更新することで、非推奨の Log4j2 パッケージのスキャン警告を修正しました。 [#13948] コンソールインターフェースを介してエージェントカードを更新するときの失敗を修正しました。 [#13959] 独立したコンソール/サーバーで展開するとパスワードの更新が失敗する問題を修正しました。 [#13964] nacos.extension.ai.enabled が false の場合、nacos の起動に失敗する問題を修正しました。

依存関係

[#13879] AI関連コンポーネントの単体テストを追加しました。 [#13881] 開発およびテスト目的でユーティリティ API を追加しました。

導入が必要です

|モジュール | Java が必要 | | ------- | -------------- | | Nacos サーバー/Nacos コンソール| Java 17 | | Nacos-Client | Java 8 | | Nacos-Maintainer-Client | Java 8 |
