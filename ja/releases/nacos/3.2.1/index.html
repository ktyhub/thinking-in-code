nacos 3.2.1

パッチ 公開日2026年4月23日 出典alibaba/nacos 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#ナコス3.2.1 Nacos 3.2.1 は、3.2.0 で発見された問題に対する重要なバグ修正と機能拡張に焦点を当てたパッチ リリースです。このリリースでは、AI レジストリの機能、データベースの互換性、セキュリティ、コンソールのユーザー エクスペリエンスが大幅に改善されました。 主なハイライトは次のとおりです。

  • AI レジストリの成熟度: UI、A2A AgentCard v1 プロトコルのサポート、スキル bizTag フィルタリング、MCP サーバーのリソース仕様ストレージによる完全なプロンプト ライフサイクル管理
  • セキュリティの強化: LDAP 認証バイパスの脆弱性を修正し、両方のコンソールに OIDC/OAuth2 SSO ログイン サポートを追加しました。
  • データベース互換性: 確定的なページネーションとスキーマのタイムスタンプの問題を含む、PostgreSQL、Oracle、MySQL、Derby の包括的な修正
  • 依存関係のアップグレード: Spring Boot 3.5.13、MCP SDK 0.17.0、および log4j-core 2.25.4
  • 同時実行性と信頼性: AI パブリッシュ パイプライン、ネーミング モジュール、client フェイルオーバー、および構成エクスポート操作における競合状態が排除されました。
  • コンソール UX: 従来のコンソールと次のコンソールの両方で設定編集エラー、名前空間 ID 検証、バッチ インポート、トークンの有効期限処理、UI のバグを修正しました。

⚠️ 重大な変更と移行に関する注意事項

データベース スキーマの更新 (重要)

必要なアクション: このリリースには、PostgreSQL、Oracle、MySQL、および Derby スキーマ、特にデフォルトのタイムスタンプ値と確定的なページネーションのための ORDER BY 句に関する重要な修正が含まれています。 アップグレード前:

  1. 既存のデータベースをバックアップします
  2. 更新されたスキーマ スクリプトを適用します: conf/schema.sql (データベース タイプの場合)
  3. スキーマ移行後に Nacos サーバーを再起動 影響を受けるデータベース:
  • PostgreSQL: デフォルトのタイムスタンプの修正、AI リソースの永続性の互換性
  • Oracle: デフォルトのタイムスタンプの修正
  • MySQL: ページネーション クエリの精度の向上
  • Derby: ORDER BY 句の追加、JDBC リソース リークの修正 スキーマ変更の適用に失敗すると、次のような結果が生じる可能性があります
  • データベース起動の失敗 (PostgreSQL)
  • 一貫性のないページネーションの結果
  • JDBC リソースのリーク
  • AIリソースバージョンの汚染

OIDC/OAuth2 SSO 構成

このリリースでは、従来のコンソールと次のコンソールの両方に OIDC/OAuth2 SSO ログイン サポートが追加されています。有効にするには:

# OIDC Configuration
nacos.auth.oidc.enabled=true
nacos.auth.oidc.issuer-uri=<your-oidc-issuer-uri>
nacos.auth.oidc.client-id=<your-client-id>
nacos.auth.oidc.client-secret=<your-client-secret>
nacos.auth.oidc.redirect-uri=${domain}/v3/console/login

📚 AI レジストリの新機能

A2A レジストリ 1.0

  • AgentCard v1 プロトコル: 拡張機能を備えた A2A AgentCard v1 プロトコルの完全サポート
  • 統合インターフェイス: エージェント カード処理でサポートされるインターフェイスが正規化および検証されています
  • バージョン メタ API: 完全なコンテンツをロードせずにエージェント仕様メタデータをクエリするための新しい API
