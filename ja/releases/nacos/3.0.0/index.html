nacos 3.0.0

メジャー 公開日2025年4月27日 出典alibaba/nacos 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#ナコス3.0.0 3.0.0 (2025 年 4 月 25 日) このバージョンは 3.0.0 の GA バージョンです。このバージョンでは、Nacos 3.0.0-BETA に基づいて MCP (Model Content Protocol) 管理をサポートします。 この 3.0.0 GA バージョンでは、Nacos は次の重要な機能と変更を行います。

  1. API はさまざまなタイプに分類されており、API のタイプが異なれば、異なるデフォルトの認証戦略が採用されます。
  2. nacos コンソール認証を有効にし、初回展開時に追加の構成設定が必要です。
  3. Nacos コンソール UI は、古い v1 API を置き換える新しい v3 コンソール API を使用し、使用される古い v1 API 古いコンソール UI をデフォルトで無効にします。
  4. デフォルトの名前空間 public の ID を ``(empty string) to public から変更します。
  5. xDS プロトコルを直接サポートします。現在、EDS、LDS、RDS、CDS をサポートしています。
  6. spring boot を 3.4.1 にアップグレードし、jdk バージョンを 17 にアップグレードします。
  7. Nacos 3.0 の ADMIN API のシリアルを追加して、メンテナーとカスタム コンソールが Nacos のデータを保守および取得できるようにします。
  8. Nacos コンソールの独立した展開をサポートします。nacos サーバーと nacos コンソールの構成の一部が変更されました。アップグレードを行う前に applciation.properties を確認してください。
  9. MCP (モデル コンテンツ プロトコル) 管理をサポートします。
  10. 実験的機能の分散ロックをサポートします。
  11. 実験的機能のファジー リッスン サービスと構成をサポートします。 3.0.0 での詳細な変更点は次を参照してください。
