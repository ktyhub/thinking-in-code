nacos 3.2.0

マイナー 公開日2026年3月27日 出典alibaba/nacos 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#ナコス3.2.0 Nacos 3.2.0 は、プラグイン アーキテクチャの強化、AI レジストリの拡張、API の最新化、およびコード品質の向上に重点を置いたメジャー リリースです。主なハイライトは次のとおりです。

  • AI レジストリが「AI トライアド」を完成: スキル レジストリとプロンプト レジストリが既存の MCP/エージェント レジストリに加わり、AI 支援管理のための Nacos Copilot 統合
  • プラグイン アーキテクチャの最新化: コンソール UI、クラスタ全体の同期、PostgreSQL の機能強化を備えた包括的な SPI ベースのプラグイン管理
  • API クリーンアップ: 従来の UDP PUSH サポートが削除され、/v1 および /v2 HTTP API は将来の削除に備えてサブモジュールに抽出されました。
  • セキュリティとコード品質: OIDC/OAuth2 認証プラグイン、複数の FindBugs 修正、デッド コードの削除、JDK 17+ の互換性強化
  • コンソールの最新化: ユーザー エクスペリエンスが向上した、新しい/従来のコンソール切り替えのためのデュアル UI サポート

⚠️ 重大な変更と移行に関する注意事項

データベース スキーマの変更 (重要)

必要なアクション: このリリースでは、プラグイン管理、AI レジストリ (スキル/プロンプト)、強化された監査機能用に複数の新しいテーブルが追加され、データベース スキーマに大幅な変更が加えられています。 アップグレードする前に、新しいスキーマを適用する必要があります:

  1. 既存のデータベースをバックアップします。
  2. スキーマ アップグレード スクリプトを適用します: conf/schema.sql (MySQL の場合)、またはデータベース タイプに対応するスクリプト
  3. スキーマ移行後に Nacos サーバーを再起動します。 スキーマの変更を適用しないと、プラグイン管理、AI レジストリ、その他の新機能が正しく機能しなくなる可能性があります。

API レガシー アダプター プラグイン

api-legacy-adapter プラグインと従来の /v1 および /v2 HTTP API は、フットプリントを削減するためにこのリリースから削除されました。 デプロイメントが依然として従来の /v1 または /v2 API に依存している場合は、以下から互換性プラグインを手動で導入できます。 https://github.com/nacos-group/nacos-api-legacy-adapter 従来の API の互換性を復元するには、プラグインをダウンロードして plugins ディレクトリに配置してください。

命名モジュール: UDP PUSH サポートの削除

命名モジュールは従来の UDP PUSH サポートを削除し、よりクリーンな HTTP API アーキテクチャに移行しました。 UDP ベースのサービス ディスカバリ更新に依存する Client は、HTTP ベースのメカニズムに移行する必要があります。

📚 AI レジストリの新機能

スキルレジストリ

  • 一元管理: UI または API と changelog を介してスキルを作成、更新、バージョン管理します。
  • スキル構成: 複数の MCP ツールをビジネスに意味のある機能にチェーンします (例: "user_onboarding" = verify_email + create_profile + send_welcome_email)
  • MCP 統合: スキルは、整合性検証を使用して、登録された MCP ツールへの依存関係を明示的に宣言します。
  • フォルダーベースの構成: スキルを複数レベルのフォルダー構造で表示し、より適切に構成します。
  • エージェントフレンドリーな API: スキルを検出してサブスクライブするためのエージェント フレームワーク (LangChain、CrewAI など) 用の REST/gRPC API
  • アップロード サポート: 認証付きでスキル パッケージ (zip 形式、最大 10MB) をアップロードします。
  • セキュリティ スキャン: AI スキルのセキュリティ検証のための統合スキル スキャナー
  • データ レベル アクセス: きめ細かい可視性とアクセス制御 (フェーズ 2 および 3)

プロンプトレジストリ

  • ファーストクラス構成: メタデータ (agentId、modelId、バージョン、タグ) を含むプロンプトをバージョン化された構成アーティファクトとして保存します
  • マルチバージョン管理: テンプレートとコミットメッセージ追跡による並列マルチバージョン管理をサポートします。
  • タグベースのサブスクリプション: 動的更新のためにタグによってプロンプトをサブスクライブします。
  • 対話型デバッグ: コンソールで直接、バージョン間のプロンプト出力をテストおよび比較します。
  • AI Client プロキシ: プロンプト操作のための統合 HTTP/gRPC client インターフェイス

ナコス副操縦士

  • AI 搭載アシスタント: プロンプトとスキルの最適化と作成を支援する統合 AI アシスタント
  • インテリジェントな検出: レジストリから関連する既存のスキルを自動的に検索します。
  • コンソール統合: Nacos コンソールから直接アクセスできるため、シームレスなワークフローが実現します。
