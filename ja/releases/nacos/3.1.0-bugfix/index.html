nacos 3.1.0-bugfix

マイナー 公開日2025年9月22日 出典alibaba/nacos 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#ナコス3.1.0-bugfix

Nacos 3.1.0 のリリース中に、MCP 公式チームはレジストリ プロトコルの新しいバージョン (2025-09-16) を公開しました。 Nacos 3.1.0 は、このプロトコルへの適応を迅速に完了しました。この機能を利用するには、最新の Nacos 3.1.0 リリース パッケージと Docker イメージをダウンロードしてください。 このバージョンは新しい石臼バージョンであり、3.1.0-BETA のいくつかのバグが修正されています。 3.1.0 では、Nacos は新しい MCP 公式レジストリ プロトコルに従います。すべてのユーザーは、Nacos を MCP 公式レジストリのプライベート展開として使用して、MCP サーバー用の独自のプライベート マーケットまたはレジストリを構築できます。 Nacos は、MCP サーバー仕様 json による MCP サーバーのインポートと、mcp URL による自動取得ツールのサポートもサポートしています。これら 2 つの新機能により、ユーザーが Nacos に MCP サーバーを作成する際の使用法が向上します。 また、このバージョンでは、コンソールでユーザーが有効/無効にした MCP サーバーをサポートし、構成暗号化プラグインを使用したスト​​レージの暗号化 mcp ツール スキームをサポートします。 さらに、このバージョンでは、Nacos は A2A レジストリをサポートしており、ユーザーまたは Spring AI Alibaba などのエージェント フレームワークが AgentCard とエージェント エンドポイントを公開および検出できるようになります。現在、エージェントの名前による検出のみがサポートされています。 Nacos は将来、スキル、タグ、または説明による発見をサポートする予定です。 その他の変更点は、バージョン以前に見つかった多くのバグを修正し、いくつかの依存関係をアップグレードすることです。 3.1.0-BETAからブロックが1つ変更されています。 3.1.0-BETA からバージョンアップする場合は、アップグレード前に AgentCard をすべて削除するか、アップグレード後に agent と agent-version を含む構成グループをすべて削除してください。そして、AgentCard 用に再公開してください。他のバージョンからアップグレードする場合は無視できます。 3.1.0 での詳細な変更点は次を参照してください。

機能

[#12191] ネームスペースの存在チェックを追加しました。 [#13322] A2Aレジストリをサポートしました。 [#13423] コンソールで有効または無効の MCP サーバーをサポートします。 [#13543] レジストリサポートによるMCPサーバーインポート機能を追加しました。 [#13783] 構成メタデータ更新管理者 api を追加しました。 [#13808] 公式 mcp レジストリ プロトコルのサポートを追加しました。 [#13814] mcp ツールのプロンプト暗号化をサポートします。

拡張/リファクタリング

[#13777] コード品質を向上させるために、名前空間の存在チェックロジックを強化しました。 [#13829] エージェントの重複した名前を公開するときのヒントを強化しました。

バグ修正

[#13744] 構成データソースプラグインの省略されたCONFIG_INFO_GRAY_WRAPPER_ROW_MAPPERを修正しました。 [#13752] NPEを修正し、InterruptedExceptionスタックログを無視します。 [#13761] ROLE_ADMINを誤って削除するなどの問題を防ぐために、ロールを削除する際の追加検証を修正しました。 [#13767] K8S getSpec() 時のサービス NullPointerException を修正しました。 [#13773] MCP OpenAPI 派生 URL を構築する際にプロトコルのスラッシュを保持する問題を修正しました。 [#13779] Mcp ツールの説明編集の制限を修正しました。 [#13787] Nacos Mcp コンソールが OpenApi ファイルを正しく解析できないバグを修正しました。 [#13801] MCPコンソールでOpenAPIファイルURLを解析する際に文字化けが発生することがあるバグを修正しました。 [#13810] 設定を公開するときに、Derby データベースと MySQL データベースの間でパフォーマンスの不一致を引き起こすバグを修正しました。 [#13824][#13826] nacos-clientのAI gRPCリソースパーサーとMCP/A2Aリクエストの認証ログインのリークを修正しました。 [#13830] AgentCardのサブスクライブ判定の問題を修正しました。 [#13832] ぼかし検索に予期しない結果が含まれる可能性がある問題を修正しました。

依存関係

[#13385] os-maven-plugin バージョンを 1.7.1 にアップグレードします。 [#13711] spring boot バージョンを 3.4.9 にアップグレードします。 [#13753] grpc バージョンを 1.75.0 にアップグレードします。 [#13825] JRAFTのバージョンを1.3.15.bugfixにアップグレードします。
