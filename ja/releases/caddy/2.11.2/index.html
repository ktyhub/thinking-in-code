#キャディv2.11.2

Caddy 2.11.2 には、多数のバグ修正と機能強化が含まれています。大雑把な要約であることは承知していますが、本当にあちこちにあります。

ハイライト

  • リバース プロキシは、PROXY プロトコル、ヘルス チェック ポート、および再試行時の本体の終了に関連する特定のエッジ ケースで多くの人気を得ました。動的アップストリームが追跡されるようになり、パッシブなヘルスチェックが可能になります。
  • メトリクスのパフォーマンスの向上。
  • ACME DNS チャレンジの使用時にすべてのサイトの DNS リゾルバーを制御するための新しい tls_resolvers グローバル オプション。
  • ログ ローリングで zstd 圧縮がサポートされるようになりました。 roll_gzip は非推奨であり、将来削除される予定です。代わりに roll_compression を使用してください。
  • ログといくつかのエラー メッセージが改良されました。
  • URI パスがターゲット パスのエスケープ形式である場合、一部の URI が書き換えられない可能性がある書き換えハンドラーのバグを修正しました。レポートを提供してくれた @MaherAzzouzi に感謝します。

セキュリティ修正

このリリースでは 2 つの CVE が修正されています。

  • @NucleiAv は、ID インジェクションと潜在的な権限昇格を許可する可能性がある forward_auth ディレクティブのバグを報告しました。
  • @sammiee5311 は、vars_regexp がプレースホルダーを二重に展開し、一部の異常な設定で秘密が明らかになる可能性があると報告しました。

さらに:

  • いくつかの CVE にパッチを適用する Go 1.26.1 (こちらも本日リリース) 上に構築されています。
  • ドキュメントが更新され、ファイル システムの大文字と小文字の区別が file_server ハンドラーの hide オプションの動作に影響を与える可能性があることが記載されました。

ご協力いただいた皆様、そしてこの開発を可能にする継続的なスポンサーシップに感謝いたします。
