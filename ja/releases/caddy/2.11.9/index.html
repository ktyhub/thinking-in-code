caddy v2.11.9

パッチ 公開日2026年11月5日 出典caddyserver/caddy 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#キャディv2.11.9

これは、2.11.8 の簡単なフォローアップであり、2.11.8 によって発生した回帰と、主に FastCGI で発生したいくつかのセキュリティ問題を修正しています。これには、マスターからバックポートされた修正と、いくつかの小さな追加のみが含まれています。 2.11.8 を使用していて PHP を提供している場合は、アップグレードすることをお勧めします。

リソースを活用してプロジェクトを存続させてくれたスポンサーと、この絶え間ない AI の新時代で精力的にトリアージと支援を行ってくれたメンテナーに多大な感謝を申し上げます。

ハイライト

  • 修正: PHP ディレクトリ インデックス (2.11.8 のリグレッション)。 /wp-admin/ のような末尾にスラッシュがあるディレクトリに対するリクエストは、index.php ではなくディレクトリ自体と一致したため、PHP に到達することはなく、通常は 404 を受け取りました。これにより、WordPress 管理ページや、末尾のスラッシュ URL を通じてインデックスを提供する他のアプリが機能しなくなってしまいました。 try_files パターンは、/ で終わるディレクトリのみと一致するようになりました。ありがとう@dunglas! (#8352)
  • プレースホルダーを使用したパス マッチャーが期待どおりに動作するようになりました。{env.FOO} のようなプレースホルダーは、検索前に {env.foo} に小文字に変換されなくなり、その値は静的パターンのように、大文字と小文字を区別せずにリクエスト パスと比較されます。ありがとう@BenMacha! (#8343)
  • file_server browse の新しい plain_time_format オプション: プレーンテキストのディレクトリ リスト (Accept: text/plain) の時間レイアウトを設定します。ありがとう@steffenbusch! (#8084)
  • パスのクリーニング、ヘッダーの書き換え、weighted_round_robin の選択における 割り当ての減少。ありがとう@jvoisin! (#7842)
  • プラグイン作成者向け: 新しい httpcaddyfile.Helper.IsNamedRoute() は、名前付きルート 内で解析されているかどうかをディレクティブに伝えます。 (#8354)

:警告: 重大な変更

  • 競合する client_auth は Caddyfile エラーになりました。 2 つのサイト ブロックが同じホスト名の TLS 接続ポリシーを共有しているが、異なる client_auth を設定している場合、アダプターは最初のブロックを保持し、もう 1 つをサイレントに削除していました。これにより、より厳格な mTLS 要件がサイレントに削除される可能性がありました。 (#8306)
  • どのスクリプトを実行するかが曖昧な FastCGI リクエストは 400 を取得します:
    • エスケープされたパス (% を含むパス マッチャーが参照する) とデコードされたパスが異なるスクリプトを選択する場合。 /public/tool.php%2f..%2f..%2fadmin%2ftool.php (#8357)
    • Windows では、8.3 短縮名コンポーネント (ADMINI~1 など) または : (NTFS 代替データ ストリーム) を含むスクリプト パス (#8356)
  • FastCGI env 値がリクエスト ヘッダーよりも優先されるようになりました。そのため、client は、env で設定した HTTP_* 変数をオーバーライドできなくなりました (以下を参照)。 (#8358)

セキュリティ修正

責任を持って報告し、パッチに協力してくれた皆さんに感謝します。

  • fastcgi: client は、一致する要求ヘッダーを送信することによって (たとえば、アプリケーションが HTTP_X_AUTH_USER で認識するユーザーを選択するなど)、FastCGI トランスポート (または php_fastcgi) の env サブディレクティブで設定された HTTP_* 変数をオーバーライドできます。設定された値が優先されるようになりました。 @JebeenLee と @Camel4 によって報告され、@dunglas によって修正されました。 (GHSA-q34h-28rj-5hjm、#8358)
  • fastcgi: Windows では、NTFS 8.3 短縮名と代替データ ストリームが、パス ルールで拒否されるはずのスクリプトを実行する可能性があり、2.11.8 からの FastCGI 修正が完了しました。ありがとう@dunglas。 (GHSA-9cr8-wmhh-39pm、#8356)
  • fastcgi: エンコードされたスラッシュとドット セグメントにより、% を含むパス マッチャーが 1 つのスクリプトを実行中に別のスクリプトを承認する可能性があります。ありがとう@dunglas。 (#8357)
  • fastcgi: HTTP/2 経由で、:authority の次に送信される host フィールドにより、アプリケーションは Caddy がリクエストをルーティングしたホストとは異なるホスト (HTTP_HOST) を参照する可能性がありました。ありがとう@dunglas。 (#8355)
  • httpcaddyfile: TLS 接続ポリシーをマージするときに、より厳密な client_auth がサイレントに削除される可能性があります (上記を参照)。ありがとう@sam-kota。 (#8306)
  • GHSA-mgcc-cww5-fp2q の go-jose を v4.1.6 に更新しました。 (#8299)

:警告: アプリケーションがバグのある動作に依存している場合、これらのセキュリティ パッチは壊れる可能性があります。

:rotating_light: Caddy プラグインの管理者への注意: dependabot はおそらく Caddy のセキュリティ修正について警告し、go.mod ファイルでそれをアップグレードするよう促します。プラグインが使用するエクスポートされた API に変更がある場合にのみ、Caddy 依存関係をアップグレードしてください。

何が変わったのか

  • caddyhttp: https://github.com/caddyserver/caddy/pull/8343 の @BenMacha によるリクエスト時のプレースホルダーを含む小文字のパス パターン
  • httpcaddyfile: https://github.com/caddyserver/caddy/pull/8306 の @sam-kota による TLS ポリシーをマージするときに競合する client_auth を拒否する
  • build(deps): https://github.com/caddyserver/caddy/pull/8340 の @dependabot[bot] による 10 件の更新で、actions-deps グループを 1 つのディレクトリにバンプします。
  • build(deps): https://github.com/caddyserver/caddy/pull/8299 の @dependabot[bot] により、github.com/go-jose/go-jose/v4 を 4.1.5 から 4.1.6 にバンプします
  • ファイルサーバー: https://github.com/caddyserver/caddy/pull/8084 の @steffenbusch によってプレーンテキストのブラウズ時間形式を構成可能にします
  • ファイルサーバー: パターンが https://github.com/caddyserver/caddy/pull/8352 の @dunglas で終わる場合にのみディレクトリと一致します
  • httpcaddyfile: @dunglas による Helper.IsNamedRoute を https://github.com/caddyserver/caddy/pull/8354 に追加
  • fastcgi: https://github.com/caddyserver/caddy/pull/8355 の @dunglas によってのみルーティングされたホストから HTTP_HOST を取得します
  • fastcgi: https://github.com/caddyserver/caddy/pull/8356 の @dunglas による Win 8.3 エイリアスと代替データ ストリーム パスを拒否します
  • caddyhttp: https://github.com/caddyserver/caddy/pull/7842 の @jvoisin による割り当てを減らすために、ホット パス内のバッファーのサイズを事前に設定します。
  • fastcgi: https://github.com/caddyserver/caddy/pull/8358 の @dunglas によるリクエスト ヘッダーを設定された環境変数でオーバーライドします
  • fastcgi: エスケープ形式が https://github.com/caddyserver/caddy/pull/8357 の @dunglas による別のスクリプトを選択するパスを拒否します
