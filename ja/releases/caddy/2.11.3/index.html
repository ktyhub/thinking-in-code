#キャディv2.11.3

このリリースでは、マイナーな機能、バグ修正、セキュリティ パッチにより、Caddy のいくつかの側面が改善されています。このリリースをこれまでで最高のものにするために貢献してくれた皆さんとそのボットに感謝します。

セキュリティ パッチ:

  • fastcgi: 非 PHP ファイルの実行を可能にするバグに対する FrankenPHP からのパッチを引き継ぎます。 @dunglas、@KC1zs4、@chenjj による共同制作。
  • vars: @everping と @vnxme が協力した https://github.com/advisories/GHSA-m2w3-8f23-hxxf, のより徹底的な修正。
  • admin: @Amemoyoi とボットによるリモート管理ソケット認証バイパスを防ぐための配列インデックスの正規化。
  • 管理者: @Amemoyoi とボットによるリモート管理ソケットの認証バイパスを防ぐための、より厳密なパス プレフィックス マッチング。

また、quic-go や CertMagic などの他のプロジェクトのアップストリームのセキュリティ バグを修正するいくつかの PR をマージしました。 quic-go を熱心にメンテナンスしてくれた @marten-seemann に感謝します。

何が変わったのか

  • caddyhttp: https://github.com/caddyserver/caddy/pull/7573 の @vnxme による vars および vars_regexp のプレースホルダー拡張の同期
  • caddytls: https://github.com/caddyserver/caddy/pull/7577 の @steadytao による暗黙的な Tailscale *.ts.net ポリシーの ACME フォールバックを回避する
  • 雑用: https://github.com/caddyserver/caddy/pull/7593 の @mholt による最近の CI エラーを解決する
  • caddytls: https://github.com/caddyserver/caddy/pull/7567 の @mholt により空の AP をよりスマートに統合
  • 書き換え: https://github.com/caddyserver/caddy/pull/7599 の @steadytao により、ソースキーが存在しない場合にクエリの名前変更をスキップします
  • root: https://github.com/caddyserver/caddy/pull/7594 の @henderkes によって使用される他のディレクティブ/プラグイン用にダウンプロパゲーティング Helper.BlockState を導入します。
  • http: https://github.com/caddyserver/caddy/pull/7586 の @ottenhoff によって zstd チェックサムを構成可能にします
  • 通知: https://github.com/caddyserver/caddy/pull/7597 で @francislavoie によるエラーが発生した後でも、常に "READY=1" を送信します
  • reverseproxy: https://github.com/caddyserver/caddy/pull/7564 の @yubiuser による header_up Host {upstream_hostport} 冗長性チェックを修正
  • caddytls: https://github.com/caddyserver/caddy/pull/7609 の @pberkel による dns_challenge override_domain tls パラメーターのプレースホルダーを展開します
  • tls: https://github.com/caddyserver/caddy/pull/7406 の @HarshPatel5940 によるシステムおよび結合 CA プール モジュールの追加
  • vars: https://github.com/caddyserver/caddy/pull/7629 の @vnxme による値のプレースホルダーを展開しないでください。
  • build(deps): https://github.com/caddyserver/caddy/pull/7637 の @dependabot[bot] により go.opentelemetry.io/otel/exporters/otlp/otlpmetric/otlpmetrichttp を 1.42.0 から 1.43.0 にバンプします
  • build(deps): https://github.com/caddyserver/caddy/pull/7641 の @dependabot[bot] による 11 個の更新を含むすべての更新グループを 1 つのディレクトリにバンプします
  • リバースプロキシ: https://github.com/caddyserver/caddy/pull/7627 の @steadytao によってストリーム コピー バッファ サイズを設定可能にします
  • vars: @steadytao によるマッチャー プレースホルダー処理テストを https://github.com/caddyserver/caddy/pull/7640 に追加
  • build(deps): https://github.com/caddyserver/caddy/pull/7621 の @dependabot[bot] により、github.com/go-jose/go-jose/v4 を 4.1.3 から 4.1.4 にバンプします
  • ロギング: @steadytao による Journald エンコーダ ラッパーを https://github.com/caddyserver/caddy/pull/7623 に追加
  • caddyfile: https://github.com/caddyserver/caddy/pull/7642 の @steadytao によるグローバル オプションの前のインポートのインポート/グローバル オプション UX を改善
  • 雑務: https://github.com/caddyserver/caddy/pull/7571 の @tsinglua による最新化のために interface{} を any に置き換えます
  • 雑用: https://github.com/caddyserver/caddy/pull/7618 の @DeRuina により木こりを v1.4.1 にぶつける
  • ロギング: https://github.com/caddyserver/caddy/pull/7644 の @steadytao による、journald でラップされた JSON ログの ts を保存します。
  • ファイルサーバー: シンボリックリンクターゲットを逐語的に表示 (#7476) by @maxtruxa (https://github.com/caddyserver/caddy/pull/7579)
  • 修正（キャディファイル）：https://github.com/caddyserver/caddy/pull/7558 の @prettysunflower によるスニペットの {block}
  • caddyhttp: https://github.com/caddyserver/caddy/pull/7659 の @steffenbusch によるエスケープ URI とプレフィックス付きクエリのプレースホルダーが不足しているドキュメント
  • 雑用: @mohammed90 による AGENTS.md を https://github.com/caddyserver/caddy/pull/7652 に追加
  • build(deps): https://github.com/caddyserver/caddy/pull/7655 の @dependabot[bot] により、github.com/jackc/pgx/v5 を 5.8.0 から 5.9.0 にバンプします
  • 管理者: https://github.com/caddyserver/caddy/pull/7578 の @steadytao による API ログの機密リクエスト ヘッダーを編集します
  • リバースプロキシ: https://github.com/caddyserver/caddy/pull/7569 の @seroperson による応答ステータスに lb_retry_match 条件を追加
  • caddyhttp: 自動 HTTPS ではポート 443 を優先し、https://github.com/caddyserver/caddy/pull/7666 に @mholt によるテストを追加します
  • 修正: https://github.com/caddyserver/caddy/pull/7670 の @steadytao によって ECH キーを QUIC リスナーに伝播する
  • 雑用: 必要に応じてアトミックを使用 (https://github.com/caddyserver/caddy/pull/7648 の @francislavoie による)
  • メトリクス: https://github.com/caddyserver/caddy/pull/7664 の @dunglas による OLTP 経由のプッシュの実装
  • ロギング: https://github.com/caddyserver/caddy/pull/7620 の @steadytao による回転ファイル モードの回帰カバレッジを追加
  • httpcaddyfile: https://github.com/caddyserver/caddy/pull/7617 の @steadytao による TLS ショートカットのグローバル ACME 発行者設定を継承
  • build(deps): https://github.com/caddyserver/caddy/pull/7668 の @dependabot[bot] により、github.com/jackc/pgx/v5 を 5.9.0 から 5.9.2 にバンプします
  • 管理者: https://github.com/caddyserver/caddy/pull/7673 の @Amemoyoi によるリモート アクセス制御でパス セグメント境界が必要です
  • リバースプロキシ: https://github.com/caddyserver/caddy/pull/7662 の @mholt による再試行中に動的アップストリーム キャッシュをクリアする機能を追加
  • リスナー: Windows 上の古い Unix ソケット ファイルをクリーンアップ (https://github.com/caddyserver/caddy/pull/7676 の @mfrischknecht)

  • caddytls: https://github.com/caddyserver/caddy/pull/7554 の @tribut による ACME 資格情報の展開

  • caddyauth: https://github.com/caddyserver/caddy/pull/7688 の @steadytao による認証拒否時のユーザー プレースホルダーを元に戻す
  • 雑用: @steadytao による golangci-lint 2.12.1 の発見を https://github.com/caddyserver/caddy/pull/7690 で修正
  • httpcaddyfile: https://github.com/caddyserver/caddy/pull/7694 の @tomholford によるログ サンプリング間隔の期間文字列を受け入れます
  • tls: https://github.com/caddyserver/caddy/pull/7653 の @steadytao によって管理対象 HTTPS レコードに alpn を追加
  • caddytls: https://github.com/caddyserver/caddy/pull/7697 の @Rijul-A によるワイルドカードでカバーされたホストの重複自動化を回避します。
