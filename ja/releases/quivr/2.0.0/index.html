quivr v2.0.0

#quivr v2.0.0

クイヴル 2.0.0

Quivr は、続々と配信されるコンテンツ用のオープンソース エンジンです。アプリケーション、または Quivr のソース (RSS、Microsoft 365 メールボックス、X リスト) は、ドキュメントを送信します。 Quivr は各ドキュメントのすべてのバージョンを保存し、キーワード、意味、またはその両方で数秒以内に検索できるようにします。また、すべての新しいドキュメントを保存されたアラートと照合してチェックします。 Quivr にはユーザー インターフェイスがありません。アプリケーションは HTTP API 経由で Quivr と通信し、AI エージェントは quivr mcp 経由で Quivr を使用します。

2.0.0 は、書き直された Quivr の最初の安定版リリースです。アルファは評価用です。このリリース以降、Quivr は構築できることを約束します。

2.0 が約束するもの

  • 安定した API。 HTTP API は、2.x リリースごとに /v0 パスを保持します。 2.x リリースでは、新しいエンドポイント、オプションのフィールド、応答フィールド、および列挙値が追加されるだけです。動作中の client を破壊する可能性のある変更は、次のメジャー リリースを待っています。
  • データを保持したアップグレード。 ある 2.x リリースから別の 2.x リリースへのアップグレードでは、quivr migrate が実行され、データが配置された状態でワーカーと API がロールされます。
  • 互換性をチェックするプラグイン。 プラグインはサポートするプラグイン API バージョンを宣言し、Quivr は実行できないバージョンのアクティブ化を拒否します。
  • 各機能のステータスを明確にします。 ドキュメント内のすべては、実験的な機能の短いリストを除き、2.x 内で安定しています。各機能はそのページにマークされています。検索測定ツール、Jev 再ランキングおよび Jev 判定アラート、専用ベクトル ホスト、quivr-autoscaler バイナリです。

【バージョンと互換性】(https://docs.quivr.thevibecompany.co/reference/compatibility)の詳細が記載されています。 既知の制限 は、2.0 がまだ実行していないことを示しています。テキストのみを検索し、OCR を持たず、ユーザー アカウントを持たず、ドキュメントごとおよび検索ごとにサイズ制限があります。

始めましょう

  • ローカルで試してください: リポジトリのクローンを作成し、make dev を実行して、クイックスタート に従います (約 15 分)。
  • 署名済みリリース イメージ (linux/amd64) からサーバーにインストールします: 1 台のマシンで Quivr を実行する、または鉄道および Kubernetes については Quivr を展開して構成する を参照してください。
  • 最初に理解してください: コアコンセプト および Quivr の仕組み。

2.0.0 アルファからの提供

アルファ版インストールのアップグレードはサポートされていません。新しく 2.0.0 インストールを開始するか、アルファ版からドキュメントをエクスポートして新しいものに送信します。

2.0.0-alpha.7以降

  • セキュリティ:
    • Quivr とそのイメージは、CVE-2026-111943 に対応する Go 1.27.3 で構築されています。
    • golang.org/x/net、certifi、pillow、および SeaweedFS イメージの curl および brotli にはパッチが適用されます。
  • 検索は、データベースの再起動後にバッファが復元され、ハイドレーション作業が制限された状態で回復します。
  • 輸入:
    • 継続的なインポート中もキュー数は利用可能です。
    • オートスケーラーは、コネクタのインポート用のバルク ワーカーを追加します。
  • ドキュメント:
    • 新しいページを追加して初心者向けに書き直されました: Quivr の仕組み、用語集、バージョンと互換性、既知の制限。
    • 「評価段階」の警告が表示されなくなりました。

最初のアルファ版以降の変更点の完全なリストは CHANGELOG.md にあります。

2.0.0-alpha.7 (生成) 以降の変更点

特長

  • docs-site: PostHog 分析をドキュメント サイトに追加します (#3954) (1f72133)

バグ修正

  • 自動スケーリング: コネクタ プリフェッチ バウンドでバルク ワーカーをスケーリング (#3952) (8a58f13)
  • キュー: 継続インポート中に制限されたスナップショットを保持します (#3951) (90e7c63)
  • リリース: パブリッシュで署名付き画像をダウンロードする前にチェックアウトしてください (#3971) (313f51e)
  • 検索: 再起動後にバッファーと結合水和を復元 (#3953) (ec80407)
  • セキュリティ: Go 1.27.3 でビルドし、脆弱な依存関係にパッチを適用します (#3967) (426bc62)

雑務

  • リリース: Quivr 2.0.0 (#3968) (5bb5690) を準備します。
