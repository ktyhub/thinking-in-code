quivr v2.0.3

#quivr v2.0.3

クイヴル 2.0.3

2.0.3 は、セキュリティおよび修正リリースです。 API、構成、保存されたデータは変更されません。 2.0.x インストールをそれにアップグレードします。

セキュリティ修正

  • Go 1.27.4 は、すべての Quivr バイナリとイメージ (net/http の GO-2026-6859) をビルドします。
  • PostgreSQL 17.12 は、データベース イメージ内の 17.11 を置き換えます。 zlib 1.4 (CVE-2026-4738) が同梱されます。これは PostgreSQL のマイナー リリースです。ディスク上のデータはそのまま残ります。
  • オリジナル ファイルを保存する SeaweedFS は、zlib 1.4 (CVE-2026-4738) および brotli v1.2.7 (GO-2026-6888) を取得します。

修正済み

  • デモのフォームはプレーンな HTTP 経由で動作します。
    • 以前: HTTPS または localhost 以外のアドレスで、ソースの追加、テキストの追加、アラートの作成、コネクタの編集が「crypto.randomUUID は機能ではありません」というエラーで失敗しました。ブラウザは、安全なページでのみその機能を提供します。
    • 現在: ブラウザにキーがない場合、デモは別の方法でキーを作成します。
  • デモのアラートは、Quivr が提供するアラート プラグイン バージョンを使用します。 以前は、設定のない展開では古いバージョンが要求され、エンジンはすべてのアラートを「インストールされていない」として拒否していました。

2.0.x からのアップグレード

2.0.3 イメージ、またはこのリリースに添付されている 2.0.3 構成バンドルを単一のマシンに展開します。 PostgreSQL 17.12 でデータベース コンテナーを再起動する場合、ダンプや移行は必要ありません。検索データベースと Quivr のデータはそのまま残ります。

Quivr リリースのセキュリティ で説明されているように、リリース イメージには署名があり、SBOM が含まれています。

2.0.3 (2026-11-16)

バグ修正

  • デモ: プレーン HTTP 経由で crypto.randomUUID を使用せずにべき等鍵を作成します (#3991) (890b968)
  • デモ: コアが提供するプラグインのバージョンに対するアラートをピンで通知します (#3980) (25e4edf)
  • イメージ: Go 1.27.4 でビルドし、Postgres と SeaweedFS で zlib と brotli にパッチを適用します (#3992) (b29e919)
