  • [fastproxy] NTLM を分離し、FastProxy でバックエンド接続をネゴシエートします (#13914 @kevinpollet)
  • [k8s/gatewayapi] ゲートウェイの構成を許可します (#13819 @kevinpollet)

  • [k8s/ingress-nginx] ingress-nginx プロバイダーでリソース名を正規化しないでください (#13922 @kevinpollet)
  • [k8s/ingress-nginx] ルーティングとプロバイダーのドキュメント間の ingress-nginx クロスリンクを修正 (#13925 @simpleqt)
  • [k8s/ingress-nginx] ImplementationSpecific パスで末尾のキャプチャ グループをオプションにします (#13455 @mmatur)
  • [k8s/ingress-nginx] 基本認証およびダイジェスト認証の Authorization ヘッダーを削除 (#13631 @josmo)
  • [k8s/ingress-nginx] Ingress-NGINX HTTP ルーターに Ssl-Client-* リクエスト ヘッダーを設定します (#13912 @rtribotte)
  • [k8s/ingress-nginx] ingress-nginx プロバイダーの cors-allow-origin でワイルドカード オリジンをサポート (#13726 @kimsehyoung)
  • [ログ、ミドルウェア、k8s/crd] IngressRoute メタデータをアクセス ログに公開します (#12985 @mmatur)
  • [ミドルウェア] レート リミッター Lua スクリプトで非推奨の table.maxn を回避する (#13825 @lazerg)
  • [otel] go.opentelemetry.io/otel/exporters/otlp/otlpmetric を v1.46.0 (#13933 @kevinpollet) にバンプします
  • [otel] go.opentelemetry.io/otel/exporters/otlp/otlptrace を v1.46.0 (#13932 @kevinpollet) にバンプします
  • [otel] otlploggrpc と otlploghttp を v0.22.0 にバンプします (#13931 @kevinpollet)
  • [ルール] ルール ドメインを解析するときに否定されたマッチャーを無視します (#13863 @rtribotte)
  • [サーバー] golang.org/x/crypto を v0.57.0 (#13930 @kevinpollet) にバンプします
  • [サーバー] 一部の文字が許可されていない場合、エンコードされた文字の警告を表示しなくなりました (#13470 @Adel-Ayoub)
  • [サービス] ServersTransport ごとにスティッキー トランスポートを専用にします (#13838 @sdelicata)
  • [サービス] P2C ロード バランサーの 2 番目のサーバー選択バイアスを修正 (#13644 @lazerg)
  • [サービス] 事前認証された NTLM および Kerberos バックエンド接続を分離します (#13902 @kevinpollet)
  • [udp] キューに入れる前に UDP データグラムを適切なサイズのバッファにコピーします (#13941 @rtribotte)
  • [webui] 反応ルーターを v7 にバンプし、vite を v8 にバンプします (#13794 @gndz07)
  • GOPROXY=direct でのビルドを修正 (#12724 @mehrdadbn9) ドキュメント:
  • [accesslogs] アクセス ログのバッファリング動作を明確にする (#13510 @amazon7737)
  • [accesslogs] USR1 のみがアクセス ログ ファイルを再度開くことを明確にします (#13955 @rtribotte)
  • [k8s] Kubernetes リファレンス ドキュメントでネイティブ LB ロード バランシングの動作を明確にしました (#13358 @zarko-a)
  • [セキュリティ] セキュリティ レポートに対する協調的な開示禁止措置を文書化します (#13982 @emilevauge)
  • [サーバー] ヘッダー戦略ハンドラー内の誤解を招くトレーラー コメントを修正 (#13938 @AleksaMCode)
  • [tcp] TCP ServersTransport の「構成を許可する」文法を修正 (#13894 @fng713)
  • TCP HostSNI ルールの「一致を許可」文法を修正 (#13895 @fng713)
  • 大文字と小文字を区別するオプションアンカーを修正 (#13924 @simpleqt)
  • 単一テストの例のエンドアンカーを修正 (#13898 @amazon7737)
