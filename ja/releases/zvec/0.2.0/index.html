#ズベックv0.2.0

🚀 ズベック v0.2.0 Release Notes

メジャー アップデートでは、最適化、プラットフォームの拡張、開発者エクスペリエンスの改善に焦点を当てました。

📦 主要な機能と改善点

  • オンデバイス埋め込みワークフロー用の AI 拡張フレームワークをサポート (#88)
  • MMap ストレージ ファイル内の自動スケーラブルなセグメント メタデータ (#67)
  • コア内の統合検索呼び出しインターフェイス (#15)
  • Linux ARM64 ビルドのサポート (#71)
  • 初期化試行を繰り返した場合のサイレント障害 (#79)

🐞 バグ修正

  • インデックスの代わりにキーを使用する delete_by_filter ロジックを修正しました (#84、#87)
  • 量子化 int 単体テストを修正 (#47)
  • AddColumn API (#59) から不要な column_name パラメータを削除しました。
  • HNSW インデックス実装のタイプミスを修正 (#50)
  • テストで予想される冗長なエラーを削除しました (#82)
  • 未使用の ailego モジュール (#85) をクリーンアップしました

🔧 開発者エクスペリエンス

  • typing_extensions を標準 typing (Python ≥3.10) (#99) に置き換えました。
  • cerr ではなく LOG_ERROR による C++ エラー ログの改善 (#80)
  • Python バインディングの docstring と .pyi スタブを更新 (#41)
  • 廃止された IndexMeta::MetricType 定義 (#53) を削除しました。
  • C++ の例を macOS/Linux CI マトリックスに追加しました (#86)

🤖 CI/CD とツール

  • フォークされた PR の CI 実行をサポート (#52)
  • マークダウンのみの変更で CI をスキップ (#55)
  • コミュニティサポートを向上させるために問題テンプレートを追加しました (#46)
  • CMake の最小バージョン要件を更新 (#44、#57)
  • ベンチツールのドキュメントの更新 (#77)

📚 ドキュメント

  • README バッジと参加セクションを更新 (#45、#54)

👋 新しい寄稿者

  • @SYaoJun — 最初の投稿 (#50)

フル Changelog: https://github.com/alibaba/zvec/compare/v0.1.1...v0.2.0
