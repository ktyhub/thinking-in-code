zvec v0.5.0

#ズベックv0.5.0

🚀 ズベック v0.5.0 Release Notes

📦 新機能

  • 全文検索 (FTS): Zvec は、全文検索をネイティブにサポートするようになりました。Collection::CreateIndex / DropIndex によるインデックス管理により、任意の文字列フィールドに FTS インデックスを添付し、自然言語または構造化式でクエリを実行します。 (#408、#445)
  • ハイブリッド取得: スカラー フィルタリングと再ランキングを使用して、フルテキスト、密ベクトル、およびスパース ベクトルの取得を 1 回のクエリ呼び出しで組み合わせます。ネイティブのマルチクエリの実行と再ランキングは、Python、Go、Rust、および C++ 全体で一貫して動作するようになりました。 (#459、#405)
  • DiskANN インデックス: インデックスの大部分を RAM ではなくディスク上に保持する新しい DiskANN インデックスを追加しました。これにより、10 億規模のデータセットのメモリ使用量が大幅に削減され、メモリに制約のあるマシンでも大規模な ANN 検索が可能になります。 (#369)
  • 出力フィールドの選択: fetch() は、返されるフィールドを制御する output_fields パラメーターを受け入れるようになりました。 (#358)

🌐 エコシステム

コア エンジンを超えて、Zvec エコシステムは新しい公式言語 SDK とビジュアル管理ツールによって拡張されます。

  • 公式 Go SDK (zvec-go): libzvec_c_api をラップする cgo バインディング。Linux (x64/ARM64)、macOS (ARM64)、および Windows (x64) 用の事前構築ライブラリが含まれます。
  • 公式 Rust SDK (zvec-rust): RAII リソース管理、ビルダー API、および Result<T> エラー処理を備えた安全で慣用的な Rust バインディング。 macOS (x86_64/ARM64)、Linux (x86_64/ARM64)、Windows (x86_64/MSVC) をサポートします。
  • Zvec Studio (zvec-studio): Zvec 組み込みベクトル データベース用のビジュアル管理ツール — コードを記述せずにデータを参照し、クエリをテストし、スキーマを管理します。 pip install zvec-studio 経由でインストールするか、macOS / Linux / Windows 用のデスクトップ アプリをダウンロードします。

🚀 パフォーマンスの向上

  • 高速な最適化: 最適化中に最初のベクター インデックス ファイルをマージ ベースとして再利用します。 (#440)
  • バインディング内の GIL リリース: Python の同時実行性を向上させるために、コレクション バインディング内の GIL をリリースします。 (#363)

🐞 バグ修正

  • データの正確性: マルチセグメント コレクションでの NULL 許容列 SIGABRT、NULL 許容スカラー フィルターによる NULL 漏洩、DDL 後のクエリア スキーマ同期、およびセグメントごとの QueryInfo による SQL オプティマイザーの相互汚染を修正しました。 (#415、#416、#410、#429、#449)
  • インデックスの安定性: 強化された DiskANN (medoid エントリ、同時ビルド クラッシュ、プルーン品質)、RaBitQ (最適化中の生ベクトルのマージ、コンバータ パス、ex_bits 検証)、IVF 結果の順序付け、およびベクトル インデックスの命名。 (#433、#456、#425、#436、#422、#421)
  • その他の修正: Windows マクロの競合、uint64_t 形式指定子、HNSW コンテキスト フェッチ、および Python 単体テスト。 (#435、#374、#386、#401)

🔧 リファクタリングとクリーンアップ

  • 統合クエリ API: VectorQuery を削除し、単一ターゲット クエリを SearchQuery に統合し、リランクをベクトルベースのインターフェイスに切り替えました。 (#428、#431、#458、#267)
  • コードベースのクリーンアップ: modernize-use-override を適用し、セグメントローカル行 ID を明確にし、DiskANN ビルドを調整し、明示的な x86 CPU ホワイトリストに切り替え、ハミング メトリックとバッファ マネージャーを削除し、エラー メッセージを修正しました。 (#442、#419、#432、#475、#258、#365、#437、#400)

🤖 CI とビルドの改善

  • ビルド強化: すべての CI プラットフォームで -Werror を有効にし、SIMDe 経由で RISC-V FastPFOR を修正し、サードパーティ インクルードを SYSTEM としてマークし、DiskANN CMake パスを修正しました。 (#460、#470、#413、#464)
  • 高速な CI: ccache/sccache (Windows を含む) の追加、テストの並列化、clang-tidy の高速化、メイン ワークフローの範囲指定、および CRoaring の統合 (~292M → ~1MB)。 (#360、#439、#454、#384、#412、#417、#418、#438、 #396、#448、#381)
  • 依存関係のバンプ: actions/cache 4→5 および codecov/codecov-action 6→7。 (#466、#467)
