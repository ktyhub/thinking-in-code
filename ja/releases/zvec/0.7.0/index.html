zvec v0.7.0

#ズベックv0.7.0

🚀 ズベック v0.7.0 Release Notes

⚠️重大な変更

  • C++ パブリック API は、snake_case に切り替えられました: すべてのパブリック C++ SDK インターフェイス (Index、Collection など) は、PascalCase からsnake_case に移動されました。たとえば、Open() → open()、Search() → search()、Query() → query()、Insert() → insert() のようになります。 C++ SDK ユーザーは、アップグレード時にコール サイトを更新する必要があります。 C の API および Python API の名前は変更されません。 (#683)

📦 新機能

  • IVF RaBitQ インデックス: IVF インデックスに RaBitQ 量子化サポートを追加し、RaBitQ をより高密度のベクトル取得シナリオに拡張しました。 C および Python バインディングとテスト カバレッジが含まれています。 (#540)
  • ターボ プリプロセッサ フレームワーク: ターボ量子化モジュールにオプションのプリプロセッサ コンポーネントが導入されました。高速アダマール変換 (FHT) 回転が現在実装されており、将来のリリースでは OPQ 回転と次元削減が予定されています。 (#548)
  • Turbo PQ-INT8 量子化器: Turbo フレームワークに PQ ベースの INT8 量子化器を追加し、より高い圧縮を必要とするユーザーのために L2、コサイン、および内積距離メトリクスをカバーします。 (#554)
  • ターボ レコード量子化器: INT8/INT4 レコード量子化と FP16 量子化器をターボ フレームワークに移行し、非 SIMD ターゲット用の移植可能なスカラー距離カーネルを追加し、カーネル ディスパッチ レジストリを再加工して、すべての量子化タイプが 1 つの明示的なバックエンド パスにマップされるようにしました。 (#624)
  • Uniform uint7/uint8 量子化: Uniform uint7 を公開し、Uniform uint8 量子化オプションを追加しました。これにより、圧縮とリコールをトレードする際の柔軟性が高まります。 (#608)
  • RaBitQ ランタイム AVX2/AVX512 ディスパッチ: HNSW-RaBitQ は、ホスト CPU に基づいて実行時に AVX2 または AVX512 実装を選択するようになり、ビルド時に命令セットをハードコーディングする必要がなくなりました。 (#632)
  • DiskANN クロスプラットフォーム サポート: DiskANN は、Linux x86_64 から Linux ARM64 および macOS ARM64 (Apple Silicon) に拡張されました。利用可能な最適な I/O バックエンド (io_uring、libaio、または pread) が選択され、安全にフォールバックされるようになりました。 macOS は F_NOCACHE を使用し、DiskANN ファイルの先読みを無効にします。 (#557、#599)
  • Vamana 2 パス グラフ ビルド: Vamana にオプションの 2 パス グラフ ビルド パスを追加し、一部のデータセットのグラフ品質を向上させました。 (#634)
  • 元のベクトルからの HNSW グラフ構築: HNSW は、インデックスに格納されたベクトルに対して検索を実行しながら、プロバイダーから提供された生の元のベクトルからグラフを構築できるようになり、格納されたベクトルが非可逆である場合のグラフの品質が向上します。 (#657)
  • FTS ngram トークナイザー: 全文検索用の ngram トークナイザーを追加しました。これは、短いテキスト、コード、ピンインなどの文字レベルのマッチングに役立ちます。 (#593)
  • フル コレクション トラバーサル用の DocIterator: C++、C、および Python にわたるフル コレクション トラバーサルをストリーミングするための DocIterator を追加しました。イテレータはスナップショットを取得するため、その後の書き込みと削除は表示されなくなり、Python API は with collection.iter_docs() をサポートします。 (#597)
  • musllinux ホイール: musl libc 環境用の x86_64 および arm64 Python ホイール ビルドを追加し、さらに musl スレッド スタック、ロガー シングルトンの有効期間、および DiskANN ヒープ オーバーリードの互換性修正を追加しました。 (#649)
  • 事前構築された SDK リリース パイプライン: PR #628 は、Linux (glibc と musl、x86_64 と arm64)、macOS ARM64、Windows x86_64、Android arm64、および iOS XCFrameworks 用の事前構築済み C/C++ SDK パッケージをビルドして公開する GitHub リリース パイプラインを提案しています。 v*タグがプッシュされます。

🚀 パフォーマンスの向上

  • DiskANN 非同期 I/O オーバーラップと動的ビーム: CPU 作業とディスク I/O をオーバーラップするように DiskANN ビーム検索を再加工し、動的ビーム幅を導入して、ディスク バインドされたワークロードでのクエリ レイテンシーを削減しました。 (#617)
  • 動的ライブラリの縮小: シンボルの可視性を制御し、デッドコードの削除を有効にし、protobuf/protoc ビルドの依存関係を削除することにより、事前に構築された動的ライブラリのサイズを削減しました。 macOS ARM64 では、libzvec_c_api.dylib は 37.21 MB から 22.06 MB (-40.7%) に低下し、libzvec.dylib は 36.96 MB から 23.37 MB (-36.8%) に低下しました。コア検索コードは -O3 でコンパイルされたままであるため、クエリのパフォーマンスは影響を受けません。 (#627)

🐞 バグ修正

  • インデックスとストレージの安定性: フォワード ストア ライターを開くことができなかった場合のクラッシュを修正しました。 WAL を開かずにクラッシュ回復後の最適化を有効にしました。永続化された削除専用の書き込みセグメント レコード。 mmap ストア内の大きな最終 IPC チャンクを処理しました。クラッシュ回復後に孤立したセグメント ディレクトリをクリーンアップしました。 Windows 上で最適化した後、廃止されたセグメント ディレクトリをクリーンアップしました。 (#579、#600、#618、#645、#674、#676)
  • DiskANN: DiskANN を zvec コア ライブラリに正しく接続しました。 Linux AIO フォールバックを部分的な操作に対して安全にしました。 add_vector のヒープ オーバーリードと convert_pivot_data のオフバイ 1 を修正しました。 (#602、#615)
  • Vamana / HNSW: Vamana は非対称クエリ メトリクスを受け入れるようになりました。 HnswExternalStreamerEntity に関する問題を修正。 ARM NEON の pq_int8 バグを修正しました。球面 K 平均重心正規化と K-MC2 サンプリング重みを修正しました。 (#635、#607、#682、#654、#655)
  • 検索とフィルタリング: フィルターの検証と古いフィルター状態のリセットを修正しました。 SQL エンジン内の AND をまたがる分離された等価またはリライト。ヒープの不変条件がバイパスされるのを防ぎました。また、visit_filter off-by-one を含む ASan の問題を修正しました。 (#663、#679、#633、#650)
  • Python バインディング: クエリ topk とフィールド名を検証し、空の FTS クエリを拒否し、コレクションに close() メソッドを追加し、doc numpy ベクトルを正規化して、ユーザーがサイレントな不正行為ではなく明確なエラーを取得できるようにします。 (#616、#612、#640、#567、#653)
  • コレクション メンテナンスの同時実行性: 最適化の実行中に読み取りと書き込みを続行できるようになりました。不一致のスカラー バッチ境界も修正されました。 (#614、#639)
  • ビルドとバージョン管理: C API は、git タグが欠落している場合に偽の 0.2.1 バージョンを報告しなくなりました。 UTF-8 パスは Windows 上で正しく処理されます。オールインワン DLL のエクスポートは制限されています。 ANTLR4 MSVC D9025 警告と ThreadQueue ラムダ キャプチャ エラーが修正されました。古いサブモジュールのパッチ マーカーと汚れた protobuf ワークツリーがクリーンアップされます。 (#629、#666、#611、#693、#688、#675、#671)

🔧 リファクタリングとクリーンアップ

  • スレッド プールの CPU アフィニティがオプトインになりました: スレッド プールは、デフォルトでスレッドを CPU コアに固定しなくなり、コンテナーやその他のスケジュールに依存する環境での予期せぬ事態を回避します。アフィニティは引き続き明示的に有効にすることができます。 (#623)
  • 冗長なコンポーネントを削除しました: メンテナンスの手間を減らすために、冗長な IndexLogger キーワードと不要な virtual キーワードを削除しました。 (#652、#631)
  • テストの安定化: DiskANN および IVF サーチャー テストを安定化し、ThreadQueue 待機を確定的にし、新しい API のコレクション回復テストを更新しました。 (#637、#680、#686)

🤖 CI とビルドの改善

  • Windows / MSVC ビルド: MSVC との互換性のために Snowball codegen ビルドを CMake にリファクタリングし、nmake サポートを追加し、MSVC ラムダ キャプチャと ANTLR4 警告の問題を修正して、Windows 開発をよりスムーズにしました。 (#668、#661、#688、#693)
  • 依存関係とアクションのバンプ: actions/setup-python (6→7)、actions/setup-java (5→5.6.0→5.7.0)、および mozilla-actions/sccache-action (0.0.10→0.0.11) を更新しました。 (#620、#641、#667、#642)
  • CI の動作: ドラフト PR の準備ができたときにチェックが実行されるようになりました。 pyproject.toml は、cibuildwheel の python_version マーカーを追加し、[dev] に欠落している pytest-xdist を組み込みます。 (#670、#560)

📝 ドキュメント

  • README を v0.6.0 に更新し、WeChat QR コードのリンクを修正しました。 (#606、#610、#651)
