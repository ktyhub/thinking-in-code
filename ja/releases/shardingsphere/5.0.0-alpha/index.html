shardingsphere 5.0.0-alpha

プレリリース 公開日2020年11月10日 出典apache/shardingsphere 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#シャーディングスフィア5.0.0-alpha

5.0.0-alpha

新機能

  1. プラグイン可能なアーキテクチャが利用可能であり、SPI を介した機能拡張をサポートします。
  2. 独立した SQL 解析エンジンを使用して、さまざまなデータベース言語の SQL 解析済み AST を取得できます。
  3. ShardingSphere プロキシの新しい RDL 機能は、シャーディング ルールとシャーディング テーブルの作成をサポートします。
  4. ShardingSphere-Scaling は、ブレークポイントからのデータ移行の再開をサポートします。
  5. ShardingSphere-Scaling は、ShardingSphere JDBC を使用した新しいクラスターへのデータの移行をサポートします。
  6. ShardingSphere シャドウ データベースが利用可能です。

API の変更点

  1. 新しいシャーディング/暗号化/シャドウ/クエリレプリカ API。
  2. 新しいシャーディング アルゴリズムと戦略 API。
  3. タスクを作成するための ShardingSphere Scaling 用の新しい API。
  4. DefaultDataSourceNameの設定項目を削除します。
  5. パラメータ設定項目の区切り文字をドット「.」からマイナス記号「-」に変更します。
  6. パラメータallow.range.query.with.inline.shardingをグローバルパラメータからシャーディングアルゴリズムパラメータに変更します。

リファクタリング

  1. データベース言語に基づいて SQL 解析モジュールのアーキテクチャをリファクタリングします。
  2. SPI メカニズムを使用して、オンラインのメタデータ変更処理を再構築します。
  3. オーケストレーション モジュールの名前をガバナンス モジュールに変更します。
  4. MasterSlave モジュールの名前を QueryReplica モジュールに変更します。
  5. ガバナンス登録センターのメタデータ構造をリファクタリングします。
  6. GovernmentShardingSphereDataSource をリファクタリングします。
  7. ShardingSphere UI は、構成センターと登録センターの表示レイアウトを統合します。

機能強化

  1. サポートされている最小バージョンの JDK を Java8 にアップグレードします。
  2. Zookeeper curator をバージョン 5.1.0 に更新します。
  3. Google Guava をバージョン 29.0-jre に更新します。
  4. MySQL SQL 構文定義および解析プロセスの機能強化。
  5. PostgreSQL 構文定義と解析プロセスの機能強化。
  6. さまざまなデータベース言語でのサブクエリの機能強化。
  7. 非シャーディングテーブルに対する MySQL ビュー操作のサポート
  8. 非シャーディング テーブルに対する MySQL ストアド ファンクションおよびプロシージャ操作をサポートします。
  9. SQLServer Top 構文をサポートします。
  10. メタデータの読み込みを最適化して起動速度を向上させます。
  11. バッチ挿入のパフォーマンスを最適化します。
  12. Oracle RAC JDBC URL の使用をサポートします。
  13. XA トランザクション マネージャーは、Oracle データベースのサポートを追加します。
  14. ShardingSphere プロキシは、p6sy ドライバーの使用をサポートします。
  15. ShardingSphere Proxy 起動スクリプトにヘルプ情報を追加します。

バグ修正

  1. OrderBy条件処理時のエイリアス書き換えエラーを修正。
  2. MYSQL Insert ステートメントに式が含まれている場合の SQL 書き換えエラーを修正しました。
  3. 重複したSQLでの更新時のパラメータ計算エラーを修正しました。
  4. バッチ挿入時に generatedKeys が間違っている問題を修正しました。
  5. DML ステートメント更新操作における複数テーブル検証の異常問題を修正します。
  6. テーブルが存在しないときに SQL を実行することによって発生する NPE 問題を修正します。
  7. 未構成のテーブルに対して Show table コマンドを使用する場合の例外を修正します。
  8. Oracle データベースに複数の資格のあるユーザーがいる場合のメタデータのロード エラーを修正しました。
  9. レプリカノードをオンラインで有効にできない問題を修正します。
  10. ShardingSphere-JDBC が PostgreSQL 配列型をサポートしていない問題を修正します。
  11. 長い BLOB データをクエリするときに ShardingSphere-Proxy が応答しない問題を修正します。
