shardingsphere 5.1.0

マイナー 公開日2022年2月16日 出典apache/shardingsphere 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#シャーディングスフィア5.1.0

新機能

  1. SQLヒントのサポート
  2. 新しい DistSQL 構文: SHOW AUTHORITY RULE
  3. 新しい DistSQL 構文: SHOW TRANSACTION RULE
  4. 新しい DistSQL 構文: ALTER TRANSACTION RULE
  5. 新しい DistSQL 構文: SHOW SQL_PARSER RULE
  6. 新しい DistSQL 構文: ALTER SQL_PARSER RULE
  7. 新しい DistSQL 構文: ALTER DEFAULT SARDING STRATEGY
  8. 新しい DistSQL 構文: DROP DEFAULT SARDING STRATEGY
  9. 新しい DistSQL 構文: CREATE DEFAULT SINGLE TABLE RULE
  10. 新しい DistSQL 構文: SHOW SINGLE TABLES
  11. 新しい DistSQL 構文: SHOW SINGLE TABLE RULES
  12. 新しい DistSQL 構文: SHOW SARDING TABLE NODES
  13. 新しい DistSQL 構文: CREATE/ALTER/DROP SARDING KEY GENERATOR
  14. 新しい DistSQL 構文: SHOW SARDING KEY GENERATORS
  15. 新しい DistSQL 構文: REFRESH TABLE METADATA
  16. 新しい DistSQL 構文: PARSE SQL、SQL を解析して得られた抽象構文ツリーを出力
  17. 新しい DistSQL 構文: 未使用のシャーディング アルゴリズムを表示
  18. 新しい DistSQL 構文: 未使用のシャーディング キー ジェネレーターを表示
  19. 新しい DistSQL 構文: CREATE/DROP SARDING SCALING RULE
  20. 新しい DistSQL 構文: シャーディング スケーリング ルールの有効化/無効化
  21. 新しい DistSQL 構文: SHARDING SCALING RULES
  22. 新しい DistSQL 構文: SHOW INSTANCE MODE
  23. 新しい DistSQL 構文: COUNT SCHEMA RULES
  24. スケーリング: rateLimiter 構成と QPS TPS 実装を追加します。
  25. スケーリング: DATA_MATCH データ整合性チェックを追加
  26. スケーリング: OOME の可能性を回避するために batchSize 構成を追加します。
  27. スケーリング: streamChannel 構成と MEMORY 実装を追加します。
  28. スケーリング: MySQL BINARY データ型をサポート
  29. スケーリング: MySQL YEAR データ型をサポート
  30. スケーリング: PostgreSQL BIT データ型をサポート
  31. スケーリング: PostgreSQL MONEY データ型をサポート
  32. データベース検出により、JDBC Spring Boot のサポートが追加されました
  33. データベース検出により、JDBC Spring 名前空間のサポートが追加されました
  34. データベース検出により、openGauss のサポートが追加されました
  35. Shadow DB は論理データ ソース転送のサポートを追加します
  36. 列マッチングシャドウアルゴリズム用のデータ型バリデータを追加
  37. データ ソースが 1 つだけの暗号化ケースでの XA の開始/終了/準備/コミット/回復のサポートを追加します。

API 変更

  1. データベース検出関連の DistSQL 構文を再設計する
  2. DistSQL では、キーワード GENERATED_KEY が KEY_GENERATE_STRATEGY に調整されます。
  3. ネイティブ機関プロバイダーは非推奨としてマークされており、将来のバージョンでは削除される予定です
  4. スケーリング: スケーリング構成をserver.yaml から config-sharding.yaml に移動します。
  5. スケーリング:clusterAutoSwitchAlgorithm SPI の名前を completedDetector に変更し、メソッド パラメーターをリファクタリングします。
  6. スケーリング: データ整合性チェック API メソッドの名前変更と戻り値の型の変更
  7. データベース検出モジュール API リファクタリング
  8. 読み取り/書き込み分割は静的構成と動的構成をサポートします
  9. Shadow DB の有効化設定を削除します。
  10. シャドウアルゴリズムタイプの変更

機能強化

1.複数の単一テーブルのロードのパフォーマンスを向上させる

  1. 自動的に追加された主キー句による順序を削除する
  2. 結合条件で列をシャーディングせずにバインディング テーブルのルート ロジックを最適化します。
  3. シャーディングルーティング結果が同じ場合のシャーディングキーの更新をサポート
  4. 書き換えエンジンのパフォーマンスを最適化する
  5. フェデレーション エンジンによる select Union/Union all ... ステートメントのサポート 1.ルートコンテキストが同じままの場合、重複キー更新シャーディング列での挿入をサポートします
  6. Union All を使用して SQL ルートユニットをマージし、単純な選択を行うことでパフォーマンスを向上させます。
  7. ShardingSphere-Proxy での自動コミットのサポート
  8. ShardingSphere openGauss Proxy は sha256 認証方式をサポートします
  9. プロキシ起動スクリプトからプロパティ java.net.preferIPv4Stack=true を削除します。
  10. JDBC の null ルールの検証を削除する
  11. openGauss バッチ バインド実行のパフォーマンスを最適化します。
  12. Netty リソース リーク ディテクタをデフォルトで無効にする
  13. PostgreSQL / openGauss Proxy でプリペアドステートメントの記述をサポート
  14. PostgreSQL バッチ挿入実行のパフォーマンスを最適化する
  15. SHOW INSTANCE LISTの結果にinstance_idを追加します。
  16. プロキシ インスタンスを有効/無効にするときに、instance_id を使用して操作を実行するためのサポート
  17. CREATE SHARDING TABLE RULE時の自動クリエイティブアルゴリズムをサポートし、ルール作成の手順を削減します
  18. CREATE SHARDING TABLE RULE 時の既存の KeyGenerator の指定をサポート
  19. DROP DATABASE は IF EXISTS オプションをサポートします
  20. SHARDING TABLE RULE の DATANODES は列挙型インライン式をサポートします
  21. CREATE/ALTER SARDING TABLE RULE は複雑なシャーディング アルゴリズムをサポートします
  22. SHOW SARDING TABLE NODES は、非インライン シナリオ (範囲、時間など) をサポートします。
  23. 読み取り/書き込み分割ルールに読み取りデータ ソースが 1 つしかない場合、それを無効にすることはできません。
  24. スケーリング: チャンク化されたストリーミング データの整合性チェックの基本サポートを追加します。
  25. シャドウアルゴリズムの決定ロジックの最適化によるパフォーマンスの向上

リファクタリング

  1. フェデレーション エンジンのスキャン テーブル ロジックをリファクタリングします。
  2. プロキシで準備されたステートメントを実行するときに、重複した TCL SQL 解析を回避します。
  3. スケーリング: パイプライン モジュールを追加してスケーリングを再設計する
  4. スケーリング: 複数のジョブ構成構造をリファクタリングする
  5. スケーリング: タスク分割を事前計算し、ジョブ構成に保持します。
  6. スケーリング: 暗号化ジョブのパイプラインコアコード再利用の基本サポートを追加します。
  7. スケーリング: スケーリング ジョブと暗号化ジョブを組み合わせた実行の基本サポートを追加します。
  8. スケーリング: workerThread および rateLimiter を含む、input および output 構成を追加します。
  9. スケーリング: blockQueueSize を streamChannel に移動します。
  10. スケーリング: jobId タイプを整数からテキストに変更します。
  11. 指定されたスキーマのみをロードするように JDBC を最適化します。
  12. レジストリセンターのメタデータ構造を最適化する
  13. Note シャドウ アルゴリズムの名前を HINT シャドウ アルゴリズムに変更します

バグ修正

  1. 解析機能をサポート
  2. テーブルドロップの変更制約を修正 1.テーブルルートの最適化を修正
  3. サポートルートリソースグループ
  4. バイナリログの解析をサポート
  5. postgreSql/openGauss '&' および '|' をサポートオペレーター
  6. 重複キーでの openGauss 挿入の解析をサポート
  7. postgreSql/openGauss Union の解析をサポート
  8. キーワードを含む列を持つテーブルのクエリをサポートします
  9. 関数内の欠落しているパラメータを修正
  10. エイリアスのないサブクエリテーブルを修正 1.utcタイムスタンプ機能を修正
  11. 暗号化列の変更を修正
  12. 位置暗号化列を使用した列の変更をサポート
  13. postgresql のスキーマを使用した削除を修正
  14. Oracle パーサーのあいまいさによって引き起こされる間違ったルート結果を修正 1.シャーディングと暗号化を使用する場合の投影カウントエラーを修正
  15. シャドウと readwrite_splitting を使用するときの NPE を修正 1.実際のテーブルが大文字と小文字を区別しない場合の間違ったメタデータを修正
  16. 複数のテーブル結合クエリを実行するときの暗号化リライト例外を修正
  17. テーブルレベルの queryWithCipherColumn による暗号化リライトの誤った結果を修正 1.中国語の解析を修正
  18. 暗号化が存在するサブクエリを修正
  19. シャーディング条件の MySQL BINARY キーワードによって引き起こされるフル ルートを修正します。
  20. JDBCMemoryQueryResult 処理ステートメントを使用する場合の getResultSet メソッドの空の結果例外を修正しました。 1.ストア関数/プロシージャを作成する際の間違ったシャードテーブル検証ロジックを修正
  21. プロキシを一部の PostgreSQL client に接続すると発生する null 文字セット例外を修正 1.プリペアドステートメントでコミットを実行すると、MySQLプロキシでトランザクションステータスが正しくなくなる問題を修正しました。
  22. 英語以外のロケールの PostgreSQL でエラーが発生した場合、プロキシに接続されている client がスタックすることがある問題を修正 1.設定のパスに空白文字が含まれている場合にファイルが見つからない問題を修正
  23. 早期フラッシュによりトランザクションステータスが正しくなくなる可能性がある問題を修正
  24. PrepareStatement を使用してクエリを実行するときの符号なしデータ型の問題を修正
  25. MySQL プロキシの準備されたステートメントの実装におけるプロトコル違反を修正
  26. openGauss バッチ バインドでのキャッシュが多すぎる接続を修正
  27. db-discovery と readwrite-splitting を一緒に使用すると、SHOW READWRITE_SPLITTING RULES でデータが欠落する問題を修正しました。
  28. db-discovery と readwrite-splitting を一緒に使用すると、SHOW READWRITE_SPLITTING READ RESOURCES でデータが欠落する問題を修正しました。
  29. CREATE SHARDING TABLE RULE ステートメントでサブデータベースおよびサブテーブル戦略が指定されていない場合の NPE を修正します。
  30. schema.tableによるSQLのPREVIEW時のNPEを修正
  31. 場合によっては、DISABLE ステートメントにより読み取り書き込み分割書き込みデータ ソースが無効になる可能性がある問題を修正しました。
  32. 場合によっては DIABLE INSTANCE が現在のインスタンスを無効にする可能性がある問題を修正
  33. プロバイダーが SCHEMA_PRIVILEGES_PERMITTED の場合、ユーザーが未承認のロジック スキーマをクエリする可能性がある問題を修正します。
  34. 認証プロバイダーが構成されていない場合の NPE を修正する
  35. スケーリング: データ整合性チェックによって引き起こされる XA 初期化時の DB 接続リークを修正しました。
  36. スケーリング: 複数のデータ ソースでの PostgreSQL レプリケーション ストリーム例外を修正
  37. スケーリング: PostgreSQL 増分フェーズでの更新されたレコードの移行例外を修正しました。
  38. スケーリング: MySQL 5.5 チェック BINLOG_ROW_IMAGE オプションの失敗を修正
  39. スケーリング: PostgreSQL XML データ型の一貫性チェックを修正しました。
  40. データベース検出で cron 設定を変更できない問題を修正
  41. 単一読み取りデータソース使用時の重みロードバランスアルゴリズムエラーを修正
  42. メモリモードなしで冗長データソースを作成する問題を修正
  43. シャドウアルゴリズムのデータ型変換例外に一致する列値を修正
