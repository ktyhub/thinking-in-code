shardingsphere 5.2.1

パッチ 公開日2022年10月18日 出典apache/shardingsphere 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#シャーディングスフィア5.2.1

新機能

  1. ShardingSphere のデフォルト システム データベースを追加して、グローバル メタデータ管理をサポートします。
  2. 非同期データの整合性チェックをサポート
  3. Consul ガバナンス センターのサポートを追加しました
  4. Nacos ガバナンス センターのサポートを追加しました
  5. ガバナンスセンターのビュー機能のサポートを追加

機能強化

  1. SQL FederationエンジンはADVANCEDエグゼキューターを追加し、openGaussデータベースに適応します
  2. 読み取り/書き込み分割読み取りデータベースが無効になった後の ShardingSphere プロキシの起動をサポートします。
  3. SQL HINT は強制シャーディング ルートをサポートします
  4. Show processlist はプロキシ接続 (スリープ、アクティブ) の表示をサポートします。
  5. 最適化された ShardingSphere-JDBC データ ソース構成エラー メッセージ
  6. ShardingSphere-JDBC は SpringBoot 3.x バージョンをサポートします
  7. MySQL、PostgreSQL、openGauss、SQLServer ビューのメタデータのロードをサポート
  8. Snakeyaml を 1.33 に更新し、YAML の 3MB 制限を開放します
  9. ユニキャストシャーディング時にキャッシュされた接続を可能な限り再利用する
  10. Oracle での ALTER ROLE の解析のサポート
  11. Oracle の ALTER RESOURCE COST のサポートを追加
  12. Oracle でのドロップ マテリアライズド ビューの解析のサポート
  13. Oracle での DROP LIBRARY の解析をサポート
  14. Oracle での DROP JAVA の解析のサポート
  15. Oracle での DROP PLUGGABLE DATABASE の解析のサポート
  16. Oracle での DROP INDEX TYPE の解析をサポート
  17. openGauss での ALTER PACKAGE の解析をサポート
  18. openGauss の選択オフセット、カウント ステートメントの解析をサポートし、PostgreSQL 文法の不要な構文を削除します。
  19. openGauss 構文に max_size を追加します。
  20. ビュー変更/ドロップビュー解析ロジックを最適化し、ビュー変更リフレッシュのバグを修正しました。
  21. SQL パーサー エラーの詳細を Parse cancelException に追加します。
  22. postgres の OptOnConflict 解析のサポートを追加
  23. PostgreSQL での ALTER TABLE および ALTER VIEW のサポートを強化
  24. PostgreSQL Declare ステートメントに欠落しているキーワードを追加します。
  25. json 関数のサポートを mysql パーサーに追加します。
  26. ShardingSphere-Proxy は、Docker 環境の cgroup メモリ制限に自動的に適応します
  27. 移行ステータスを表示する DistSQL は、新しく追加された error_message 列に応答します 1.移行ステータスを表示し、新しく追加されたprocessed_records_count列に応答します
  28. インクリメンタルダンプでの MySQL 8 caching_sha2_password 認証のサポート
  29. ドロップ パイプライン プロセスの構成を改善する 1.一意のキーテーブルの移行をサポート
  30. テーブルを新しい名前テーブルに移行するサポート
  31. パイプラインタスクとランナーでのスレッドプールの使用率を改善します。
  32. キャンセル可能なデータ整合性チェックをサポート
  33. DistSQL: 読み取り書き込み分割ルールを作成または変更するときは、書き込みリソースまたは読み取りリソースの重複を確認します。
  34. DistSQL: ALTER SHARDING BINDING TABLE RULES の有効性チェックを追加
  35. スタンドアロン モード H2 サポート永続メタデータ
  36. xa トランザクションでの openGauss カーソルの実行を修正
  37. トランザクション関連の例外を追加

バグ修正

  1. 書き換え時に PostgreSQL の適切なプレースホルダーを生成する
  2. opengauss 更新セット解析例外を修正
  3. 負の値を指定して挿入ステートメントを実行した場合の解析例外を修正
  4. OracleDataSourceMetaData の間違った connectDescriptorUrlPattern を修正する
  5. 特別なルールでシャーディングを書き換えた後の挿入 SQL の文字化けを修正
  6. select * from information_schema.tables 実行時の例外を修正
  7. alter view rename実行時の例外を修正
  8. rolsuper 使用時の PostgreSQL チェック データ ソース権限を修正しました。
  9. DistSQL: リソースがない場合の REFRESH TABLE METADATA の NPE を修正
  10. ルールを変更するときに未変更のテーブルのメタデータを修正する 1.データベース検出を修正する
  11. MySQL.NORMAL_REPLICATION アルゴリズムでプライマリ ノードが見つかりません」
  12. etcd を使用してクラスターイベントを認識しない問題を修正しました。 1.トランザクション管理が作成されていない場合に発生するNPEを修正
  13. InlineShardingAlgorithm アルゴリズムのシャーディング値が Integer を超えたときに発生するルーティング例外を修正しました

API の変更点

  1. SQL HINT 構文形式を SQL 形式に調整
  2. DistSQL: 構文 COUNT DATABASE RULES を削除
  3. ShardingSphere モードで上書き構成を削除する
  4. エージェント: エージェントの構成を最適化します。yaml
