#シャーディングスフィア5.5.2

5.5.2 をリリース

API の変更点

新機能

  1. カーネル: Firebird SQL パーサー モジュールとデータベース タイプを追加 #33773

機能強化

  1. カーネル: RouteUnit 作成時に引数の非 null チェックを追加 - #33382
  2. カーネル: IndexColumnTokenGenerator の空でないインデックス列の判定を追加 - #33384
  3. カーネル: 所有者テーブルにバインディングを追加 - #33533
  4. カーネル: 所有者テーブルにバインディングを追加 - #33533
  5. カーネル: WithAvailable インターフェイスを追加し、選択サポート チェッカーで暗号化、結合、挿入 - #34175
  6. メタデータ: ロードテーブルメタデータバッチサイズプロパティを同時ロードテーブルメタデータに追加 - #34009
  7. DistSQL: インライン シャーディング アルゴリズムを使用してシャーディング テーブル ルールを作成するときにインライン式をチェックする - #33735
  8. SQL パーサー: Doris BITXOR の解析をサポート - #33258
  9. SQL パーサー: Doris INSTR の解析をサポート - #33289
  10. SQL パーサー: Doris STRRIGHT の解析をサポート - #33393
  11. SQL パーサー: MySQL 8.4 ドキュメント - #33846 に従って、BaseRule.g4 ファイルに予約されていないキーワードを追加することで、MySQL の解析をサポートします。
  12. SQL パーサー: Doris EXTRACT_URL_PARAMETER の解析をサポート - #33571
  13. SQL パーサー: ビューの作成、ビューの変更、ビューのドロップ SQL パーサーを強化 - #34283
  14. SQL バインダー: テーブル作成ステートメントの SQL バインド ロジックを追加 - #34074
  15. SQL バインダー: インデックス ステートメントの SQL バインドの作成をサポート - #34112
  16. SQL パーサー: ステートメント解析による MySQL 更新のサポート - #34126
  17. SQL バインダー: TablesContext#findTableNames メソッドを削除し、バインド ロジックによる選択順序、グループ化を実装します - #34123
  18. SQL バインダー: ステートメント SQL バインドによる選択とバインド テスト ケースの追加をサポート - #34141
  19. SQL バインダー: 現在の選択プロジェクション参照による選択の SQL バインドをサポート - #34151
  20. SQL バインダー: テーブルの変更、テーブル SQL バインドの削除、およびテスト ケースの追加をサポート - #34154
  21. SQL バインダー: ddl および dml パッケージへの名前変更テーブル ステートメント SQL バインドおよび分割セグメント バインドをサポート - #34158
  22. SQL バインダー: コピー ステートメント SQL バインドとバインド テスト ケースの追加をサポート - #34159
  23. SQL バインダー: テーブル SQL バインドの切り捨てとテスト ケースの追加をサポート - #34162
  24. SQL バインダー: ビューの作成、ビューの変更、ビューの削除 SQL バインド ロジックをサポート - #34167
  25. SQL バインダー: データのロードと XML SQL バインドのロードとテスト ケースの追加をサポート - #34177
  26. SQL バインダー: テーブル SQL バインドの最適化とテスト ケースの追加をサポート - #34242
  27. SQL バインダー: show create table、show columns、show Index Statement binding のサポート - #34271
  28. SQL バインダー: ユーザー SQL バインドの拒否とテスト ケースの追加をサポート - #34279
  29. SQL バインダー: UniqueCommonTableExpressionException によるセグメント バインド チェックのサポート - #34163
  30. ストレージ: HiveServer2 への接続時に jdbcURL の hive_conf_list、hive_var_list、sess_var_list の設定をサポート - #33749
  31. ストレージ:HikariCP 以外のデータベース接続プールを介した HiveServer2 への接続のサポート - #33762
  32. ストレージ: 組み込み ClickHouse chDB - #33786 への接続を部分的にサポート
  33. トランザクション: jdbc アダプターでセーブポイント/リリース セーブポイント TCL ステートメントをサポート -#34173
  34. トランザクション: Seata AT 統合用の最小 Seata Client バージョンを 2.2.0 にバンプします - #33872
  35. SQL フェデレーション: 方解石バージョンを 1.38.0 にアップグレードし、LICENSE ファイル内のすべてのライセンス情報を更新します - #33279
  36. JDBC: SHOW COMPUTE NODES の実行時に JDBC の表示データベース名を追加 - #33437
  37. JDBC: ResultSet で ZonedDateTime をサポート - #33660
  38. プロキシ: クエリ パラメーターを追加し、MySQL kill processId を確認します - #33274
  39. プロキシ: PostgreSQL プロキシのサポート テーブルが存在しない例外 - #33885
  40. プロキシ ネイティブ: ShardingSphere プロキシ ネイティブのベース Docker イメージを変更する - #33263
  41. プロキシ ネイティブ: GraalVM ネイティブ イメージで有効になっている ZooKeeper サービス ディスカバリーによる HiveServer2 への接続のサポート - #33768
  42. プロキシ ネイティブ: GraalVM ネイティブ イメージでの ClickHouse のローカル トランザクションをサポート - #33801
  43. プロキシ ネイティブ: GraalVM ネイティブ イメージのプロキシ ネイティブで Seata AT 統合をサポート - #33889
  44. シャーディング: MySQL、OpenGauss、Doris で複数のシャードを集約するための GroupConcat 関数をサポート - #33808
  45. エージェント: エージェントの Docker イメージの使用を簡素化 - #33356
  46. モード: スタンドアロン モードでの小道具を介した Hikari-CP 構成の変更をサポート #34185
  47. 暗号化: 引用符を使用した挿入ステートメントの書き換えをサポート #34259
  48. インフラ: fdb への絶対パスを含む jdbcUrl を介した Firebird への接続をサポート - #34335

バグ修正

  1. SQL パーサー: SQL パーサーの LiteralExpressionSegment キャスト例外を修正 - #33332
  2. SQL パーサー: PostgreSQL および openGauss 時間抽出関数の週および四半期の解析エラーを修正 - #33564
  3. SQL パーサー: MySQL 解析ゾーンの予約されていないキーワード エラーを修正 - #33720
  4. SQL パーサー: テーブル所有者を使用する場合の MySQL 範囲解析エラーを修正 - #33874
  5. SQL バインダー: HintManager#setDatabaseName を透過的に使用すると、テーブルが存在しないという例外が修正されました - #33370
  6. SQL バインダー: 同じテーブル エイリアスによる MySQL 複数テーブル結合をサポートするために、Multimap と CaseInsensitiveString を使用して CaseInsensitiveMap を置き換えます - #33303
  7. SQL バインダー: バインド時に結合ステートメントが外部テーブルを見つけられない問題を修正 - #33357
  8. SQL バインダー: サブクエリのフェッチの繰り返しによって引き起こされる SQL パフォーマンスの問題を修正 - #33361
  9. SQL バインダー: バインド時に式セグメントが外部テーブルを見つけられない問題を修正 - #34015
  10. ストレージ: リモート Hive Metastore Server を使用して HiveServer2 に接続できない問題を修正 - #33837
  11. プロキシ: プロキシ アダプターで INSERT INTO ON DUPLICATE KEY UPDATE を実行するときの BatchUpdateException を修正 - #33796
  12. プロキシ: MySQL の SELECT 権限検証中に「ALL PRIVILEGES ON DB.*」が認識されない問題を修正 - #34037
  13. プロキシ: プロキシ プロトコルによって返される MySQL longblob の間違った列タイプを修正 - #34121
  14. プロキシ: 挿入 SQL に値の挿入構文にないパラメーターがさらに含まれている場合のプロキシ エラー MySQL を修正 - #34287
  15. シャーディング: 実際の異なるテーブル名構成をサポートするために、ShardingRouteAlgorithmException チェック ロジックを一時的に削除 - #33367
  16. シャーディング: 不正な行が返されるのを防ぐために、GROUP BY を使用した SQL COUNT を修正 - #33380
  17. シャーディング: クエリ結果が返されない場合に avg、sum、min、max 関数が空のデータを返す問題を修正 - #33449
  18. 暗号化: データベースの暗号化ルールがない場合のマージ例外を修正 - #33708
  19. 暗号化: EncryptInsertPredicateColumnTokenGenerator で SQL バインド情報を使用して、間違った列テーブルのマッピングを回避します - #34110
  20. モード: メモリモードでの H2 データベースの JDBCRepository の不適切な処理を修正 - #33281
  21. モード: DDL でインデックスが変更されたときに追加される重複した列名を修正 - #33982
