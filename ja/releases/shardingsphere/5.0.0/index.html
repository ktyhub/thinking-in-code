shardingsphere 5.0.0

メジャー 公開日2021年11月10日 出典apache/shardingsphere 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#シャーディングスフィア5.0.0

新機能

  1. SQLコメントの解析をサポート
  2. 新しい DistSQL 構文: シャドウ ルール管理
  3. 新しい DistSQL 構文: ジョブ管理のスケーリング
  4. 新しい DistSQL 構文: プロキシ インスタンスを無効にする
  5. 新しい DistSQL 構文: 読み取り書き込み分割読み取りデータ ソースを無効にする
  6. 新しい DistSQL 構文: DROP SHARDING ALGORITHM
  7. 新しい DistSQL 構文: ALTER RESOURCE
  8. 新しい DistSQL 構文: CREATE SHARDING ALGORITHM
  9. 新しい DistSQL 構文: CREATE DEFAULT SHARDING [TABLE | DATABASE] STRATEGY
  10. 新しい DistSQL 構文: SHOW ALL VARIABLE
  11. 新しい DistSQL 構文：SHOW VARIABLE variableName;
  12. メモリ、スタンドアロン、クラスター モードを含む 3 モードをサポート
  13. openGauss のプロキシ サポート
  14. スケーリング: openGauss の基本サポートを追加します。
  15. スケーリング: インクリメンタルタスク完了検出アルゴリズム SPI インターフェイスを追加
  16. スケーリング: データ整合性チェック アルゴリズム SPI インターフェイスを追加
  17. スケーリング: MySQL および openGauss のターゲット上にテーブルを自動的に作成する基本サポート
  18. スケーリング: ジョブ終了時のクラスター構成の自動切り替えをサポートします。
  19. スケーリング: データ整合性チェックなどの DistSQL サポートを追加します。

API 変更

  1. ShardingSphere-JDBC のスキーマ名設定を追加します
  2. デフォルトのシャーディング列設定を追加します
  3. デフォルトの認証プロバイダーを NATIVE から ALL_PRIVILEGES_PERMITTED に変更します。
  4. SCTL 構文の調整、DistSQL RAL 構文との統合
  5. SHOW RESOURCES DistSQL は SHOW SCHEMA RESOURCES に調整されます
  6. shadow 論理フィールドを削除し、シャドウ アルゴリズムをサポートします。

機能強化

  1. MySQL Union/Union all ステートメントの解析をサポート
  2. PostgreSQL ABORT ステートメントのサポート
  3. メタデータ読み込みプロセスをリファクタリングおよび改善する
  4. インデックスが指定されていない場合にインデックスを自動的に生成するための PostgreSQL CREATE INDEX ステートメントをサポートします。
  5. 論理スキーマによる SQL ステートメントの実行をサポート
  6. 異なるシャーディング列を使用したバインディングテーブル構成のサポート
  7. カーネルのパフォーマンスを最適化する
  8. プロキシは、client 接続エクスペリエンスを最適化するために、information_schema テーブルの一部に対するクエリをサポートします。
  9. DistSQL は、パラメータ名としてキーワードを使用するための引用符の使用をサポートしています
  10. ADD RESOURCE ステートメントのパスワードは特殊文字をサポートしています
  11. ADD RESOURCE はカスタム JDBC パラメーターと接続プール プロパティをサポートします
  12. DROP RESOURCE は、単一テーブル ルールの制限を無視するために使用されるオプションのパラメーター ignore single tables をサポートします。
  13. 読み取り/書き込み分割ルールに基づいてシャーディング テーブル ルールを作成するための DistSQL の使用をサポートします。
  14. SHOW DATABASES ステートメントは同様の構文をサポートします
  15. CREATE SHARDING TABLE RULE は、リソースを指定するためのインライン式の使用をサポートします。
  16. CREATE SHARDING TABLE RULE は、dataNodes を使用した構成をサポートします
  17. CREATE SHARDING TABLE RULE は既存のアルゴリズムの再利用をサポートします
  18. SET VARIABLE、プロキシ構成の変更のサポート
  19. PostgreSQLのプロトコル強化（ポータル、不特定タイプのサポートなど）
  20. Netty エグゼキューターを使用して、指定されたシナリオでプロキシのパフォーマンスを最適化する
  21. プロキシでメモリのフェッチ サイズを厳密に設定できるようにする
  22. スケーリング: PostgreSQL のサポートを改善
  23. スケーリング: ソース側とターゲット側の同時データ整合性チェックをサポート

リファクタリング

  1. SingleTable 機能をリファクタリングして、複数のデータ ソースの暗号化をサポートする
  2. レジストリ センターの状態ノードの永続データ構造を調整する
  3. シャドウ用の DML の SQL リライトを削除する
  4. ShadowのDDLのSQLルーティングをサポート
  5. スケーリング: 増分タスク完了検出アルゴリズムのデフォルト実装をリファクタリングします。
  6. スケーリング: データ整合性チェック アルゴリズムのデフォルト実装をリファクタリングします。
  7. スケーリング: HTTP API とバイナリ配布を削除

バグ修正

1.シャーディング間隔アルゴリズムを修正

  1. SHOW INDEX FROM TABLE FROM TABLE ステートメント書き換え例外を修正 1.暗号化マルチテーブル結合クエリ書き換え例外を修正
  2. サブクエリインデックスの範囲外例外を修正
  3. Oracle ページング クエリの間違った結果を修正
  4. KeyGenerateStrategy がシャーディング機能で構成されていない場合の書き換え例外を修正
  5. Oracle の方言のケースによって引き起こされるフェデレーション エグゼキュータ エンジンの例外を修正 1.シャーディングと暗号化統合の使用法書き換え例外を修正
  6. Oracle メタデータ読み込み例外を修正
  7. SHOW RESOURCES ステートメントでカスタム属性を表示できない問題を修正
  8. SQL実行例外がスローされない問題を修正
  9. Etcd がノード追加イベントを送信できない問題を修正
  10. PostgreSQL 行に null 値が含まれる場合、クエリ結果に欠落する可能性がある問題を修正
  11. PostgreSQL メタデータ列の順序が乱れている問題を修正
  12. プロキシでの client 文字セットが正しくない可能性がある問題を修正
