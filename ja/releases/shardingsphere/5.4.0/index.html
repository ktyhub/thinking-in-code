shardingsphere 5.4.0

マイナー 公開日2023年7月8日 出典apache/shardingsphere 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#シャーディングスフィア5.4.0

API の変更点

  1. メタデータ: シャーディング ブロードキャスト テーブルをグローバル ブロードキャスト テーブルに変更します。
  2. JDBC: グローバル ルールの感嘆符 (!) を削除します。
  3. DistSQL: 暗号化 DistSQL のキーワード ASSISTED_QUERY、LIKE_QUERY を簡素化します。
  4. DistSQL: SQL_PARSER ルール構文の最適化
  5. 暗号化: 暗号化、いいね、支援クエリ構成を区別するために暗号化 yaml API を調整します。
  6. 暗号化: 暗号化機能のプレーン列と queryWithCipherColumn 構成を削除します。
  7. 読み取り/書き込み分割: 読み取り/書き込み分割のリファクタリング api
  8. プロキシ: プロパティ proxy-instance-type 構成を削除します。
  9. プロキシ: proxy-backend-executor-suitable プロパティを削除します。
  10. プロキシ: プロパティ proxy-mysql-default-version を削除します。
  11. スケーリング: コミット ロールバック ストリーミングをリファクタリングしてストリーミングをドロップする
  12. シャーディング: ShardingCacheRule を ShardingRule にマージします (実験的)

新機能

  1. DistSQL: SQL_FEDERATION ルールを管理するための新しい構文
  2. プロキシ: Unix ドメインソケットをサポート

機能強化

  1. スケーリング: CDC は純粋なインクリメンタル モードをサポートします
  2. スケーリング: CDC はトランザクションによるデータのエクスポートをサポートします
  3. スケーリング: CDC は MySQL および PostgreSQL をサポートします
  4. スケーリング: CDC は単一テーブルをサポートします
  5. スケーリング: CDC はすべての openGauss データ型をサポートします
  6. スケーリング: CDC はレプリケーションの再接続をサポートします
  7. スケーリング: DataConsistencyCalculateAlgorithmChooser を削除します
  8. スケーリング: 整数の一意のキー テーブル インベントリ データ分割のパフォーマンスを向上させます。
  9. スケーリング: プロセス構成のデフォルト値を調整してリソース消費を削減します。
  10. スケーリング: 移行のためのテーブルメタデータの自動更新
  11. スケーリング: データベースが存在しない場合の openGauss の既存のレプリケーション スロットの再利用と互換性があります。
  12. スケーリング: データ整合性チェック ステータスの表示が完了していない場合、結果は空になります。
  13. スケーリング: ソースとターゲットでの同時 CRC32 照合を有効にする
  14. スケーリング: シャーディング ルールの監査戦略と互換性のあるパイプライン ジョブ
  15. メタデータ: メタデータの永続構造をリファクタリングする
  16. メタデータ: 単一テーブルのメタデータをロードするプロセスを最適化します。
  17. メタデータ: MySQL/PostgreSQL/openGauss システム テーブルの空のクエリをサポート
  18. DistSQL: 読み取り/書き込み分割ルールのtransactionalReadQueryStrategyのサポートを追加
  19. DistSQL: アルゴリズム プロパティ チェックの強化
  20. トランザクション: 権限チェックを追加
  21. トランザクション: TransactionTypeHolder を削除し、現在のトランザクション マネージャーのみを作成します。
  22. パーサー: 単一テーブルまたはブロードキャスト テーブルでの MySQL LOAD DATA および LOAD XML ステートメントをサポート
  23. パーサー: MySQL テスト プログラムのテスト結果における優先度の高い SQL ステートメントの解析サポートを改善します。
  24. パーサー: Oracle 方言パーサーが中国語のカンマをサポートするようになりました。
  25. 暗号化: 暗号化機能を使用する場合、プロジェクション サブクエリで暗号化列のクエリをサポートします。
  26. カーネル: INSERT、DELETE、UPDATE、および SELECT ステートメントのテーブル存在メタデータ チェックを追加
  27. JDBC: ShardingSphereStatement のバッチ実行を実装する
  28. プロキシ: フロントエンドは SSL/TLS をサポートします
  29. プロキシ: PostgreSQL/openGauss プロキシのフラッシュ メッセージをサポート
  30. プロキシ: サポート データ タイプ ビット、PostgreSQL プロキシのブール値

バグ修正

  1. スケーリング: パイプライン ジョブの失敗ステータスの永続性と使用法を修正
  2. スケーリング: CDC DELETE イベント Record.beforeList が null である問題を修正
  3. スケーリング: openGauss mppdb デコード プラグインの一重引用符の問題を修正
  4. スケーリング: ジョブの停止後に実行エンジンが閉じられない問題を修正しました。
  5. スケーリング: タスク開始前にジョブが停止する問題を修正
  6. メタデータ: H2 データベースでスキーマ メタデータをロードする際の大文字と小文字が区別される問題を修正
  7. メタデータ: PostgreSQL/openGauss スキーマ名をデータベース名として構成する場合の「オブジェクトが見つかりません」例外を修正
  8. DistSQL: SHOW DIST VARIABLE 実行時の check_table_metadata_enabled の誤った結果を修正
  9. 暗号化: PostgreSQL/openGauss 暗号化のような機能を使用する場合の SQL 書き換え例外を修正
  10. シャーディング: ユーザーが null 値のルートを制御できるように、シャーディング アルゴリズムに渡す null シャーディング条件をサポートします。
  11. パーサー: MySQL プロジェクションでの BETWEEN AND 式解析をサポート
  12. マスク: KEEP_FROM_X_TO_Y で from-x と to-y の同じ値を設定した場合の間違ったマスク結果を修正
  13. インフラ: pgjdbc が見つからない場合に ClassNotFoundException が発生する可能性がある問題を修正
  14. プロキシ: client がパイプライン要求を送信するときに MySQL パケットの順序が狂う問題を修正しました。
