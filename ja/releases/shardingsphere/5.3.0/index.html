shardingsphere 5.3.0

マイナー 公開日2023年1月8日 出典apache/shardingsphere 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#シャーディングスフィア5.3.0

API の変更点

  1. DistSQL: リファクタリング構文 API、ユーザー マニュアルを参照してください。
  2. プロキシ: グローバル ルールの構成スタイルを変更し、感嘆符を削除します。
  3. プロキシ: ゼロ構成の起動を許可し、権限構成がない場合はデフォルトのアカウント root/root を有効にします。
  4. プロキシ: デフォルトの logback.xml を削除し、API 初期化を使用します。
  5. JDBC: Spring 構成を削除し、代わりに Driver + YAML 構成を使用します。

機能強化

  1. DistSQL: 新しい構文 REFRESH DATABASE METADATA、ロジック データベース メタデータのリフレッシュ
  2. カーネル: DistSQL REFRESH DATABASE METADATA をサポートし、ガバナンス センターから構成をロードし、MetaDataContext を再構築します。
  3. postgresql/openGauss 設定トランザクション分離レベルをサポート
  4. スケーリング: インベントリ タスクの進捗状況の更新頻度を増やす
  5. スケーリング: DATA_MATCH 整合性チェックのサポート ブレークポイント再開
  6. スケーリング: DistSQL を介したドロップ一貫性チェック ジョブのサポート
  7. スケーリング: ジョブ リスト DistSQL 応答の列名を sharding_total_count から job_item_count に変更します。
  8. スケーリング: ブロードキャスト ルーティングを回避するために、インクリメンタル タスク SQL にシャーディング列を追加します。
  9. スケーリング: SQL の生成時にシャーディング列が更新される可能性がありました。
  10. スケーリング: DATA_MATCH 整合性チェックのための列値リーダーを改善します。
  11. DistSQL: DistSQL 構文の暗号化最適化、クエリ アルゴリズムなどのサポート
  12. DistSQL: REGISTER STORAGE UNIT 時のプロパティ値チェックを追加
  13. DistSQL: DROP RULEと同時に無駄なアルゴリズムを削除
  14. DistSQL: EXPORT DATABASE CONFIGURATION はブロードキャスト テーブルをサポートします
  15. DistSQL: REGISTER STORAGE UNIT は異種データ ソースをサポートします
  16. 暗号化: 暗号化 LIKE 機能をサポート
  17. 複数のシャードにわたって DML ステートメントを実行するときに、分散トランザクションを自動的に開始します。
  18. カーネル: PostgreSQL および openGauss の client \d をサポート
  19. カーネル: 列に null 値が含まれる場合、select group by、order by ステートメントをサポートします。
  20. カーネル: PostgreSQL/openGauss Insert の解析 RETURNING 句をサポート
  21. カーネル: SQL HINT パフォーマンスの向上
  22. カーネル: ステートメント解析時に mysql ケースをサポート
  23. カーネル: データソースレベルの異種データベースゲートウェイのサポート
  24. (実験的) シャーディング: シャーディング キャッシュ プラグインを追加します。
  25. プロキシ: より多くの PostgreSQL 日時形式をサポートします。 1.プロキシ: MySQL COM_RESET_CONNECTION をサポート
  26. スケーリング: 未知のイベント タイプをサポートするために MySQLBinlogEventType.valueOf を改善しました。
  27. カーネル: フェデレーションの場合のサポート ケース

バグ修正

  1. スケーリング: ジョブ削除時に作成されるバリアノードを修正
  2. スケーリング: DATA_MATCH 整合性チェックで列値の一部が無視される可能性がある問題を修正
  3. スケーリング: 整合性チェックで jdbc URL パラメーターが更新されない問題を修正しました。
  4. スケーリング: テーブル シャーディング アルゴリズム タイプ INLINE で大文字と小文字が区別される問題を修正しました。
  5. スケーリング: MySQL の増分タスクを修正するには、mysql システム データベース権限が必要です
  6. プロキシ: ストレージ ノードなしで選択 SQL を実行するときの NPE を修正
  7. プロキシ: ユニキャスト シナリオでの DATABASE_PERMITTED 権限の検証をサポートします。
  8. カーネル: show compute names の worker-id の間違った値を修正
  9. カーネル: 読み取り可能なデータ ソースの数と重みアルゴリズムの重み設定が等しくない場合のルート エラーを修正しました。
  10. カーネル: 複数の読み取り書き込み分割グループが同じロード バランサー名を参照し、ロード バランサーが失敗する問題を修正しました。
  11. カーネル: 計算ノードを無効化および有効化できない問題を修正
  12. JDBC: ShardingSphereDriver クラスター モードで起動時の問題が発生したときにデータ ソースが閉じられる問題を修正しました。
  13. カーネル: バインディングテーブルの論理テーブル名の一部が実際のテーブル名と一致し、一部が一致しない場合の誤った書き換え結果を修正
  14. カーネル: ルールを設定せずに SpringBoot を使用する場合の起動例外を修正
  15. Encrypt: Encrypt 値が null の場合の null ポインタ例外を修正
  16. カーネル: oracle 解析が varchar2 で指定された型をサポートしない問題を修正しました。
  17. カーネル: トランザクション内のシリアルフラグ判定エラーを修正
  18. カーネル: wasNull の変更によって引き起こされるカーソルフェッチエラーを修正
  19. カーネル: メタデータを更新する際のトランザクション ルール変更エラーを修正
  20. 暗号化: 暗号化シナリオでプロシージャ呼び出しステートメントが実行されるときに発生する EncryptRule の TransparentRule 例外へのキャストを修正しました。
  21. 暗号化: 短縮投影における ExpressionProjection によって引き起こされる例外を修正
  22. プロキシ: PostgreSQL プロキシの int2 負の値のデコードが正しくない問題を修正しました。
  23. プロキシ: PostgreSQL/openGauss サポートの記述挿入戻り句
  24. プロキシ: プロキシの接続時に gsql 3.0 がスタックする場合がある問題を修正
  25. プロキシ: プロキシ バックエンドで SQL をチェックするときにパラメータが欠落する問題を修正しました。
  26. プロキシ: MySQL プロキシを有効にして大きなパケットをエンコードします
  27. カーネル: 空白エラーのない Oracle 解析コメントを修正
  28. DistSQL: 暗号化テーブルの show create table を修正

リファクタリング

  1. スケーリング: SQL キーワードの場合、SQL 生成時にテーブル名と列名を逆にする
  2. スケーリング: 増分タスクの失敗処理を改善します。
  3. カーネル: ガバナンス センター ノードの調整、ハンプをアンダースコアに統合
