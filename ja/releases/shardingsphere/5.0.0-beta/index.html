shardingsphere 5.0.0-beta

プレリリース 公開日2021年6月19日 出典apache/shardingsphere 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#シャーディングスフィア5.0.0-beta

新機能

  1. すべての ShardingSphere 構成ルールをロードして表示する新しい DistSQL
  2. 異なるデータベースインスタンスからの SQL 結合をサポート
  3. データベース ゲートウェイの新機能のために複数のバックエンド データベース タイプをサポート
  4. オンラインでの認証の作成と更新をサポート
  5. 新しい自動エージェント モジュールを追加する

API 変更

  1. QueryReplica 構成項目は read-write-splitting に置き換えられます。
  2. ShardingProxy の Authentication 構成項目は AUTHORITY に置き換えられます。
  3. dataSourceClassName を使用して ShardingJDBC の dataSource 構成を最適化する
  4. 標準および自動シャーディング テーブルを提供する自動シャーディング テーブル構成用の新しい API
  5. ShardingProxy から構成アイテム acceptor-size を削除します
  6. ユーザーが 4.x のようにクラス名を直接設定できるようにする組み込みシャーディング アルゴリズム SPI を作成します。

機能強化

  1. メタデータの読み込みプロセスを明確に改善する
  2. Oracle、SQLServer、PostgreSQL の SQL 解析を大幅に強化
  3. MySQL/PostgreSQL/SQLServer/Oracle からのロード権限のサポート
  4. 暗号化機能の DDL ステートメントをサポート
  5. シャーディングと暗号化を一緒に使用する場合、プロジェクションの所有者テーブル名の書き換えをサポート
  6. 暗号化された SQL から SELECT * を使用する場合は、キーワードとの競合を避けるために、書き換えられる列に引用符文字を追加します。
  7. PostgreSQL JSON/JSONB/パターンマッチング演算子の解析をサポート
  8. MySQL/PostgreSQL CREATE/ALTER/DROP TABLESPACE ステートメントをサポート
  9. PostgreSQL PREPARE, EXECUTE, DEALLOCATE ステートメントのサポート
  10. PostgreSQL EXPLAIN ステートメントのサポート
  11. PostgreSQL START/END TRANSACTION ステートメントのサポート
  12. PostgreSQL ALTER/DROP INDEX ステートメントのサポート
  13. PostgreSQL の CREATE TABLESPACE をサポート
  14. MySQL CREATE LOADABLE FUNCTION ステートメントのサポート
  15. MySQL/PostgreSQL ALTER TABLE RENAME ステートメントをサポート
  16. PostgreSQL クローズコマンドをサポート

リファクタリング

  1. レジストリ センターの新しいスキーマ構造
  2. Nacos および Apollo 構成センターのサポートを削除
  3. ShardingScaling はジョブ分散として elasticJob を活用します
  4. メタデータのコンテンツとその更新プロセスをリファクタリングする

バグ修正

  1. 読み取り/書き込み分割のみの場合に SELECT * wildcard を使用できないバグ修正
  2. カスタム シャーディング アルゴリズムが構成タイプと一致しない場合のインスタンス エラーを修正します。
  3. テーブル削除ステートメント実行時の NoSuchTableException を修正
  4. UPDATE ... SET ... ステートメントの誤ったテーブルの書き換えを修正します。
  5. CREATE/ALTER TABLE ステートメントの外部キー参照テーブルの誤ったテーブル書き換えを修正
  6. 既存のサブクエリ一時テーブルの場合のプロジェクション所有者チェック例外を修正
  7. Oracle/SQL92 SELECT ... WHERE ... LIKE ステートメント クラス キャスト例外を修正
  8. MySQL SELECT EXISTS ... FROM ... ステートメント解析エラーを修正
  9. SHOW INDEX ステートメントの間違った結果を修正します。
  10. SELECT ... GROUP BY ... ステートメントの書き換えとマージ結果のエラーを修正
  11. 暗号化時の CREATE TABLE ステートメントの書き換えエラーを修正 1.テキスト形式のパラメータ値を読み取るときにPostgreSQLプロキシで例外が発生する問題を修正
  12. PostgreSQL プロキシの配列オブジェクトのサポートを強化
  13. ShardingProxy のデータ型キャストのバグを修正
  14. PostgreSQL プロキシは数値型の使用をサポートします
  15. PostgreSQL プロキシ トランザクション コマンド完了パケットのタグが正しくない問題を修正
  16. PostgreSQL プロキシが client が予期しないパケットを返す場合がある問題を修正
