#シャーディングスフィア5.5.3

リリース 5.5.3

CVE

  1. CVE-2025-55163、CVE-2025-58056、CVE-2025-58057 #36758 を修正します。
  2. CVE-2025-48924 #36085 を修正
  3. CVE-2024-7254 #36153 を修正
  4. CVE-2015-5237、CVE-2024-7254、CVE-2022-3171、CVE-2021-22569、CVE-2021-22570を修正#37888
  5. CVE-2024-12798、CVE-2024-12801、CVE-2025-11226 #37936 を修正します。
  6. CVE-2023-39017 #38039 を修正
  7. CVE-2024-22399、CVE-2021-32824、CVE-2025-5222、CVE-2016-1000027 #38040 を修正します。
  8. CVE-2023-2976、CVE-2024-29131、CVE-2025-27821 #38042 を修正します。

メタデータ ストレージの変更

  1. シャーディング ルール メタデータの永続化で default_strategies プレフィックスを削除 - #34664

API の変更点

  1. SQL フォーマット機能を削除 - #35390
  2. ログ ルール機能の削除 - #35458
  3. 構成プロパティ キー system-log-level - #35493 を削除します。
  4. ShardingSphere SQL ログ トピックを ShardingSphere-SQL から org.apache.shardingsphere.sql に変更します - #37022
  5. 一時構成キー instance-connection-enabled - #37694 を追加します。
  6. プロパティ構成キー proxy-frontend-connection-idle-timeout - #38045 を追加します。

新機能

  1. ShardingSphere BOM を追加 - #36866
  2. 機能モジュールをプラグ可能として切り離す - #36086
  3. データベース タイプをプラガブルとして分離 - #35346
  4. レジストリ センター タイプをプラグ可能として切り離す - #36087
  5. プロキシ: Firebird プロキシをサポート - #35937
  6. JDBC: ZooKeeper および ETCD URL 形式をサポート - #37037
  7. プロキシ: プロキシのアイドル状態のフロントエンド接続を自動的に閉じる - #38045
