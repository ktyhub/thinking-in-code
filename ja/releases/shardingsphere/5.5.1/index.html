shardingsphere 5.5.1

パッチ 公開日2024年10月22日 出典apache/shardingsphere 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#シャーディングスフィア5.5.1

API の変更点

  1. 権限: 権限プロバイダー ALL_PERMITTED を非推奨としてマークし、将来削除される予定です
  2. DistSQL: ストレージ ユニットの表示からオプションのパラメータ useCount を削除します。
  3. 読み取り書き込み分割: YAML の dataSources を dataSourceGroups に変更します。

新機能

  1. カーネル: 新しい doris、hive、presto SQL パーサー モジュールとデータベース タイプを追加

機能強化

  1. DistSQL: ストレージユニットの登録または変更時の権限の確認
  2. DistSQL: シャーディング テーブル ルールの作成または変更時に重複する実際のデータ ノードをチェックする
  3. DistSQL: ストレージ ユニットの表示に対する同様のサポートを追加
  4. DistSQL: インポートデータベース構成が失敗した場合のロールバック
  5. DistSQL: 論理テーブルの表示の結果セットにテーブル タイプを追加します。
  6. SQL パーサー: サーバー ID を使用しない MySQL 変更レプリケーションをサポート
  7. SQL パーサー: ON DUPLICATE KEY UPDATE による MySQL 行および列のエイリアスをサポート
  8. SQL パーサー: mysql 接頭辞を持つ MySQL CALL SQL をサポート
  9. SQL パーサー: MySQL をサポートし、ローダブル関数を作成して int/dec を返します。
  10. SQL パーサー: Mysql-8 での MySQL CREATE TABLESPACE/TABLE の解析をサポート
  11. SQL パーサー: ENGINE_ATTRIBUTE を使用した MySQL CREATE INDEX の解析をサポート
  12. SQL パーサー: @ 変数を使用した MySQL LOAD DATA の解析をサポート
  13. SQL パーサー: MySQL START REPLICA ステートメントの解析をサポート
  14. SQL パーサー: MySQL json テーブル関数の解析をサポート
  15. SQL パーサー: null ではない MySQL 列を追加 SQL 解析
  16. SQL パーサー: MySQL 文字セット SQL 解析を追加
  17. SQL パーサー: mysql json 関数の Visit ステートメントの結果の強化
  18. SQL パーサー: PostgreSQL COLLATION および CONSTRAINT キーワードをサポート
  19. SQL パーサー: PostgreSQL、openGauss 関数テーブルをサポートし、解析から更新
  20. SQL パーサー: PostgreSQL および openGauss による CTE のサポート
  21. SQL パーサー: PostgreSQLDateValueParser のタイムゾーン サポートを最適化します。
  22. SQL パーサー: PostgreSQL 制限と null としてのオフセットをサポート
  23. SQL パーサー: Oracle の更新ステートメントをエイリアス解析として拡張し、テスト ケースを追加
  24. SQL パーサー: Oracle 列長単位型 SQL 解析をサポート
  25. メタデータ: PostgreSQL のテーブル タイプを収集します。
  26. カーネル: SQL に dbeaver ヒント コメントが含まれる場合の SQL ヒント抽出をサポート
  27. カーネル: extractFromSelectStatementWithoutProjection メソッドに抽出結合左選択を追加
  28. カーネル: データベースを作成および削除するための支援ノードを追加します。
  29. トランザクション: JDBC アダプター内の 1 つのトランザクションで同じトランザクション タイプを使用する
  30. トランザクション: トランザクションタイプの切り替えのサポート
  31. SQL フェデレーション: mysql の SQL フェデレーション bit_count 関数をサポート
  32. SQL フェデレーション: mysql の atan および anan2 SQL 関数を改善
  33. SQL フェデレーション: フェデレーテッド クエリ mysql bin 関数をサポート
  34. SQL フェデレーション: フェデレーテッド クエリ NOT 演算子のサポート
  35. プロキシ: ショーテーブルの結果を順番に作成します。
  36. プロキシ: データベースとテーブルの作成および削除時にメタデータ収集をトリガーします。
  37. プロキシ: ドライバーと使用する場合に、複数のデータ ソースからのメトリクス データの収集をサポートするようにエージェントを最適化します。
  38. プロキシ ネイティブ: カフェイン キャッシュの graalvm 到達可能性メタデータを追加します。
  39. シャーディング: シャーディング テーブルのすべてのローカル インデックスを改訂し、インデックス トークン ジェネレーターを制御するためにオブジェクトの一意性レベル spi を追加します。
  40. シャーディング: シャーディング機能で NULL 注文を処理するために NullsOrderType.LOW および NullsOrderType.HIGH を追加します。 1.シャーディング: 実際のデータノードと一致するインラインシャーディングアルゴリズムを追加チェック
  41. 暗号化: 暗号化列を含む結合ステートメントのサポートされていないチェックを追加します。
  42. 暗号化: select unique(column) encrypt のリライトと SubstitutableColumnNameToken ビルド ロジックのリファクタリングをサポートします。
  43. 暗号化: 暗号化機能を使用した concat ネストされた concat ステートメントの書き換えなどのサポート
  44. パイプライン: CPU コア要件を改善するために JobExecutorServiceHandler の SHARDING_TOTAL_COUNT インプルを追加
  45. パイプライン: インベントリ ダンパーおよびデータ整合性ストリーミング クエリのサポート ページ クエリ
  46. パイプライン: 大文字と小文字を区別しない識別子を使用してテーブル メタデータ ローダーを強化します
  47. パイプライン: 標準パイプライン テーブル メタデータ ローダーの主キー列の順序付けをサポートします。

バグ修正

  1. DistSQL: 論理データ ソース作成後の単一テーブルのロード エラーを修正
  2. DistSQL: デフォルトの単一テーブル ストレージ ユニットをランダムに設定する問題を修正しました。
  3. DistSQL: デフォルトの単一テーブル ストレージ ユニットを論理データ ソースに設定する問題を修正しました。
  4. DistSQL: メタデータをインポートする際の NPE を修正
  5. SQL パーサー: PostgreSQL 何も競合しないアクションをサポート
  6. SQL パーサー: oracle nvl 関数と間隔時間解析エラーを修正
  7. メタデータ: ストレージ ユニットの登録を解除するときに、使用中のストレージ ノードを保持します。
  8. メタデータ: ストレージユニットの登録時にストレージユニットが見つからない問題を修正しました
  9. カーネル: クロススレッドの使用をサポートするために、HintManager で ThreadLocal を TransmittableThreadLocal に置き換えます。
  10. カーネル: ConnectionPropertiesParser spi を使用して jdbcUrl を解析し、Oracle URL 解析エラーを解決します。
  11. カーネル: postgresql システム テーブル ジャッジによって引き起こされる列カウント アサート例外を修正
  12. SQL バインダー: CloseStatementContext、MoveStatementContext、FetchStatementContext の TableAvailable インターフェイスを追加し、SQL リライト テスト ケースを修正しました。
  13. トランザクション: setSavepoint メソッドの呼び出しがクリーンアップされない問題を修正
  14. トランザクション: 分散トランザクションでクリーンアップされないセーブポイント マネージャーを修正
  15. トランザクション: xa トランザクションがコミットされたときにトランザクション コンテキストがクリーンアップされない問題を修正しました。 1.トランザクション：カーソルが書き換えられない問題を修正
  16. SQL フェデレーション: フェデレーション クエリの LocalDateTime 変換を修正しました。
  17. SQL フェデレーション: SQL フェデレーションで SQL に中国語が含まれている場合のプッシュダウン SQL 実行エラーを修正
  18. SQL フェデレーション: フェデレーション クエリのバイナリ タイプのデータ クエリを修正
  19. SQL フェデレーション: 単一の射影列に対するフェデレーテッド クエリの null 結果を修正
  20. SQL フェデレーション: bigint での calcite の間違った結果の型によって引き起こされる SQL フェデレーションの不明な型例外を修正しました。
  21. プロキシ: PostgreSQL でバイナリ型 bool 値をサポート
  22. プロキシ: PostgreSQL で配列タイプの準備されたパラメータをサポート
  23. プロキシ: PostgreSQL のテキスト配列のバイナリ プロトコル値をサポート
  24. プロキシ: information_schema.SCHEMATA をクエリするときの重複した結果を修正しました。
  25. プロキシ: information_schema.SCHEMATA のクエリに対する誤った結果を修正しました。
  26. プロキシ: show table status 実行時の NPE を修正
  27. プロキシ: データベースからテーブルを表示するときにデータベースが選択されていないという例外が発生する問題を修正しました。
  28. プロキシ: プロキシの起動に失敗した後にプロセスが終了しないエラーを修正
  29. プロキシ: PostgreSQL シナリオでデータベースが削除された後、永続化されたシステム メタデータがクリアされなかったというエラーを修正しました。
  30. プロキシ: クエリ SQL のデータベース選択なし例外を修正
  31. JDBC: SpringBoot 2.3 より前のバージョンで「zip ファイルが閉じられる」問題を解決しました。
  32. JDBC: ドライバーに指定されたロジック データベースが含まれていない場合の NPE を修正しました。
  33. シャーディング: エイリアスを介して追跡されないシャーディング列を修正
  34. シャーディング: シャーディング ルールとバインディング テーブル ルールを構成する際のビュー変更例外を修正しました。
  35. シャーディング: 蓄積ロジックが必要な問題を修正しました。
  36. シャーディング: 生成されたキー列名の大文字と小文字を区別しないエラーを修正
  37. 暗号化: データ型に float が含まれる場合の暗号化による show create table の誤った結果を修正しました。
  38. 暗号化: 暗号化されていないテーブルを更新したり、暗号化されたテーブルでサブクエリを使用したりする問題を修正します。 1.暗号化: 暗号化用の挿入選択リライトを追加
  39. パイプライン: BigInteger 主キーと互換性のある InventoryTaskSplitter
  40. パイプライン: 移行ジョブの作成時に失われたデフォルトのデータ ソースを修正
