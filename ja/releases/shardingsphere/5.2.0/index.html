shardingsphere 5.2.0

マイナー 公開日2022年9月8日 出典apache/shardingsphere 英語原文

#シャーディングスフィア5.2.0

新機能

  1. シャーディング機能の SQL 監査をサポート
  2. MySQL show processlist および kill プロセス リスト ID 機能をサポートします。
  3. スケーリング: データ移行用に専用の DistSQL を追加する
  4. スケーリング: 異種データベースへのデータ移行の基本サポート
  5. DistSQL: 新しい構文 CREATE MIGRATION PROCESS CONFIGURATION
  6. DistSQL: 新しい構文 ALTER MIGRATION PROCESS CONFIGURATION
  7. DistSQL: 新しい構文 SHOW MIGRATION PROCESS CONFIGURATION
  8. DistSQL: 新しい構文 ADD MIGRATION SOURCE RESOURCE
  9. DistSQL: 新しい構文 SHOW SQL_TRANSLATOR RULE
  10. DistSQL: 新しい構文 CREATE SHARDING AUDITOR
  11. DistSQL: 新しい構文 ALTER SHARDING AUDITOR
  12. DistSQL: 新しい構文 SHOW SHARDING AUDIT ALGORITHMS

バグ修正

  1. DataSourceContainedRule のフィルタリングによって発生する単一テーブルのメタデータ更新エラーを修正
  2. MySQL BLOB タイプの NULL 値によって引き起こされる解析例外を修正
  3. PostgreSQL/openGauss リセット ステートメント解析エラーを修正
  4. シャーディングと暗号化を使用する際の誤ったパラメータの書き換えを修正
  5. IntervalShardingAlgorithm での Month 関連クラスの変換に失敗する問題を修正
  6. select Union ステートメントにサブクエリが含まれている場合に発生する NullPointerException を修正 1.メタデータの順序が間違っていることによる間違った暗号化書き換え結果を修正
  7. MySQL トリム関数の解析エラーを修正
  8. MySQL 挿入値の _binary 解析エラーを修正
  9. MySQL 構文エラーを client にスローできない問題を修正
  10. JDBC リソースのクローズによる EventLoop のブロックを回避する
  11. MySQL プロキシによって返される正しいサーバー ステータス フラグ
  12. プロキシ client がトランザクション中に切断された場合に発生する可能性のある接続リークの問題を修正
  13. プロキシ client が切断されているときに実行されるステートメントで発生する可能性のある一貫性の問題を修正しました。
  14. SET ステートメントの実行によるプールされた接続の汚染を回避する
  15. SHOW TABLES FROM を ShardingSphere-Proxy で機能させる
  16. PostgreSQL DDL が拡張クエリで実行できなかった問題を修正 1.リソースなしのPostgreSQLプロキシでSHOW VARIABLESを実行できなかった問題を修正
  17. SpringBoot fatjar で ShardingSphere ドライバーを使用する場合の FileNotFoundException を修正
  18. スケーリング: インベントリ移行時にテーブルに主キーと一意のインデックスの両方が含まれる問題を修正
  19. スケーリング: 増分移行を改善し、バッチ挿入イベントの途中で最新の位置をサポートします。
  20. スケーリング: openGauss 増分移行の null フィールド値によって引き起こされるエラーを修正
  21. DistSQL: SHOW SHARDING TABLE RULES の結果の誤った戦略名を修正
  22. DistSQL: ALTER SHARDING TABLE RULE 時に現在のルール設定が事前に変更されるのを修正
  23. DistSQL: ALTER RESOURCE 時の接続リークを修正
  24. DistSQL: ロード バランス アルゴリズムが null の場合に失敗する CREATE TRAFFIC RULE を修正
  25. データベースが検出され、論理ライブラリが削除されたときに、監視ハートビート タスクが停止されなかった問題を修正しました。
  26. クラスター モードの ShardingSphere-JDBC がすべてのロジック データベースをロードする問題を修正しました。 1.クラスターモードでSnowflakeKeyGenerateAlgorithmによって生成されたworker-idが最大値を超える場合がある問題を修正
  27. シャドウ データ ソースなしでシャドウ アルゴリズム例外を追加する DistSQL を修正しました。
  28. 複数の論理データベースで同じデータ ソース名が原因で発生するデータベース間のデータ ソースの混乱を修正 1.トランザクションでのRUL DistSQL実行エラーを修正
  29. PostgreSQL と openGauss の修正開始
  30. エージェント: メトリクス データを収集する際の contextManager の null 値のエラーを修正しました。

API の変更点

  1. データソースへの SQL パススルー機能を削除する
  2. 新しいAssistedQueryEncryptorNameを追加し、QueryAssistedEncryptAlgorithmインターフェイスを削除します。
  3. ユーザー エクスペリエンスを向上させるために、読み取り書き込み分割 api をリファクタリングします。
  4. 重複テーブルのチェックが有効な設定を削除します
  5. 不要な設定項目 show-process-list-enabled 設定を削除します
  6. スケーリング: データ移行 DistSQL の一部のキーワードを変更
  7. スケーリング: データ移行 DistSQL の一部を再設計する
  8. DistSQL: パラメータの型指定を統一する
  9. DistSQL: SHOW INSTANCE MODE を SHOW MODE INFO と SHOW INSTANCE INFO に分割
  10. DistSQL: DROP SCALING jobId を CLEAN MIGRATION jobId に変更します。
  11. DistSQL: COUNT INSTANCE RULES を削除します。
  12. 高可用性がすべてのスレーブ ライブラリのオフライン化をサポートし、メイン ライブラリが読み取りトラフィック構成を引き受けることが判明したデータベースを追加します。
  13. SnowflakeKeyGenerateAlgorithm は、スタンドアロン モードでの worker-id の構成をサポートします
  14. シャドウ API 構成で sourceDataSourceName を productionDataSourceName に置き換えます。
  15. 権限: 非推奨のネイティブ権限プロバイダーを削除します。

リファクタリング

  1. 実際のメタデータと論理メタデータを分割するための ShardingSphere メタデータ リファクタリング
  2. ConnectionContext、QueryContext を使用して、FetchOrderByValueQueuesHolder、TrafficContextHolder、SQLStatementDatabaseHolder、および TransactionHolder の ThreadLocal を削除します。
  3. Helm チャートの ShardingSphere-Proxy バージョンのデフォルト値を変更します
  4. ShardingSphere-Proxy の起動に失敗した場合、Docker コンテナは終了します
  5. ShardingSphere リポジトリの Helm チャートがサブプロジェクト shardingsphere-on-cloud に転送されます
  6. スケーリング: コードの再利用を改善するための豊富なリファクタリング
  7. DistSQL: RUL という名前の新しいカテゴリを追加します。
  8. スケジュール モジュールをリファクタリングし、クラスタ スケジュールとスタンドアロン スケジュールに分割します。
  9. メモリ モードを削除し、スタンドアロン モードとクラスタ モードを維持します。
  10. メタデータ テーブルのロード ロジックと永続化ロジックのリファクタリング
  11. 分散ロックをリファクタリングして、最も簡潔なインターフェイス設計を維持する
  12. リファクタリング : IT におけるプロキシ コンテナの作成を ENV モジュールから統合する 1.リファクタリング：testcontainerで作成したコンテナの構成を統一する
