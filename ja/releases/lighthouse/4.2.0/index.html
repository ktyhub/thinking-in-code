lighthouse v4.2.0

マイナー 公開日2019年3月14日 出典GoogleChrome/lighthouse 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#灯台v4.2.0 #4.2.0 (2019-03-06) フルChangelog このリリースは Chrome 74 の DevTools に同梱される予定です。

新しい貢献者です!

@pra85、@tgfjt、@gidztech、@jburger424。ありがとう！

新しい監査

  • タップターゲット: タップターゲットが適切なサイズで明確であることを確認します (#5846)

レポート

  • a11y 監査グループを再編成します (#7129)
  • clip ヘッダー内の非常に長い URL (#6858)
  • 詳細レンダラ: 新しい監査詳細タイプを使用します (#7192)

コア

  • fid: 最大潜在 FID を JSON に追加 (#5842)
  • アーティファクト: AnchorElement を単一のギャザラーに統合 (#7101)
  • アーティファクト: スクリプト アーティファクトにインライン スクリプトを含めます (#7065)
  • アーティファクト: ViewportMeta 計算アーティファクトを作成 (#7264)
  • アーティファクト: TestedAsMobileDevice ベース アーティファクト (#7280) を追加
  • 起動時: より良いアトリビューション (#7059)
  • バイト効率: より楽観的な GZIP 比率を使用します (#7210)
  • キャッシュヘッダー: 必須再検証のタイプミスを修正 (#7189)
  • 詳細レンダラー: スニペット詳細レンダラーを追加 (#6999)
  • 診断: 診断監査を追加 (#7052)
  • ドライバー: waitForFCP タイムアウトを追加 (#7356)
  • ドライバー: アウトプロセス iframe からネットワーク リクエストを収集します (#6922)
  • ドライバー: ユーザーエージェントに「Chrome-Lighthouse」を追加 (#7297)
  • エミュレーション: Chrome ユーザーエージェントを m74 にバンプ (#7211)
  • fcp-3g: LR 互換性のために未使用の i18n を削除 (#7103)
  • font-display: CSS 仕様 (#7191) に従います。
  • image-elements: ナチュラルサイズの取得時間のキャップ (#7274)
  • ランタン: 事前計算されたネットワーク分析の構成を追加 (#7239)
  • lhr: ネットワーク要求監査に resourceSize を含める (#7056)
  • マニフェスト: 新しい WebAppManifest (#7078) を優先してマニフェスト アーティファクトを削除します。
  • メトリクス: TTI が失敗しても失敗しない (#7132)
  • ネットワーク分析: 追加の RTT を NaN ではなく 0 に設定 (#7156)
  • ネットワークレコーダー: スクリプトによって開始されたリダイレクトはイニシエーターとして設定されます (#7352)
  • プラグイン: グループのサポートを追加 (#7304)
  • seo: 手動のモバイル フレンドリー監査を削除 (#7223)
  • seo: ドメイン ルートを監査するための rel=canonical テストを追加 (#7228)
  • タップターゲット: フォント サイズを無効にし、デスクトップでのタップ ターゲットの監査 (#7393)
  • タップターゲット: タップターゲットの失敗をより見やすくする (#7373)
  • tsc: 監査詳細タイプ階層を修正 (#7177)、#7154、#7285)
  • 未使用-CSS: タイトル変更 延期 -> 削除 (#7235)
  • ノード 11 で壊れたテストの詳細に対してソート フォールバックを提供する (#7216)
  • LR のアプリ マニフェストのバグに対するプロトコル タイムアウトを抑制 (#7184)
  • タップターゲット監査の最適化 (#7130)
  • エラーがない場合は NO_ERROR runtimeError を削除 (#7358)

CLI

  • Chrome を終了する前に runLighthouse でレポートを作成する (#7339)

デプス

  • snyk: snyk スナップショットを更新します (#7277、(#7233、#7167)、#7116)
  • 推移的な脆弱性を取り除くためのアップデート (#7319)
  • より多くの名前付き色、CSS4 色を解析するために cssstyle を更新 (#7283)

ドキュメント

*貢献.md: タイプミスを修正 (#7170)

  • スロットル レートのコメントを修正し、コムキャスト帯域幅を調整 (#7374)
  • 設定ファイルの拡張と使用に関する説明を改善 (#7354)
  • 調整ドキュメントを公開バージョンに更新 (#7332)
  • readme: 灯台管理者を統合に追加 (#7399)
  • ドキュメント (関連プロジェクト) は、react-lighthouse-viewer を追加します (#7262)
  • readme: Fluxguard を統合のリストに追加 (#7249)
  • 変動性: 専用の変動性ドキュメントを追加 (#7175)

I18n

  • 潜在的な最大 FID の説明を修正 (#7353)
  • ICU 構文修正 (#7320)
  • i18n 用に準備された seo 文字列 (#6860)
  • タップターゲット監査の文字列を翻訳します (#7111)
  • a11y カテゴリのタイトルと説明 (#7113)
  • 翻訳されたアクセシビリティおよび lh エラー メッセージをインポート (#7008)

テスト

  • ドライバーのリファクタリング、追加の gotoURL テスト (#7270、#7242、#7212)
  • CI でノード 11 を実行 (#7230)
  • 不揮発性スナップショットをインライン リテラルに置き換えます (#7217)
  • スモークハウス: Smokerider を有効にするためのリファクタリング (#7284)
  • スモークハウス: +/- 演算子 (#7343)
  • スモークハウス: 転送サイズとリソース サイズをアサートするための gzip テスト (#7286)
  • スモークハウス: FinalUrl/errorCode の不一致で失敗する (#7227)

その他

  • タップターゲット: 末尾に空白がある行を削除 (#7105)
  • travis がキャッシュを構築する前に、node_modules/.cache をクリーンアップします (#7388)
  • インテリセンスを向上させるために Flags コメントを jsdoc に変換 (#7359)
  • Emulation.js から UA 文字列をエクスポート (#7318)
  • コメントのタイプミスを修正 (#7296)
