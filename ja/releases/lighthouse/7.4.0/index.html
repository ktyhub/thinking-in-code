lighthouse v7.4.0

マイナー 公開日2021年4月27日 出典GoogleChrome/lighthouse 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#灯台v7.4.0 フルChangelog このリリースは 2 週間以内に Chrome 92 の DevTools および PageSpeed Insights にリリースされる予定です。

新しい貢献者

新しい寄稿者 👽🐷🐰🐯🐻 に感謝します!

  • カスペラ @kasperadk
  • ミルティン・クリストフィック @milutin
  • 黒澤武 @takenspc

注目すべき変更点

  • PSI に要素のスクリーンショットを追加 (#12288)

コア

  • csp-xss: 非表示の重大度 (#12240)
  • 非推奨: ::-webkit-details-marker の警告を無視します (#12341)
  • ドライバー: EvaluateOnNewDocument をexecutionContext に移動 (#12381)
  • フェッチャー: プロトコルを介したフェッチ (#12199)
  • フェッチャー: 挿入された iframe の自動アタッチを無効にする (#12347)
  • hreflang: Audit.makeNodeItem (#12273) を使用します
  • メタ要素: NodeDetails (#12274) を追加します
  • サイズのない画像: 明示的なアスペクト比を指定して渡します (#12377)

フラグルロック

ユーザー フローの監査のサポート (#11313)

  • ストレージおよびサービスワーカードライバーメソッドの抽出 (#12400)
  • 共有用のエミュレーション ユーティリティを準備する (#12375)
  • 手動専用カテゴリ (#12367) を除外します
  • 待機ロジックを使用して PerformanceObserver インストールを同じ場所に配置します (#12365)

CLI

  • アセットセーバー: 1 行に 1 つの devtoolsLog イベントを出力します (#12348)

レポート

  • 概要マーカーのスタイルを調整 (#12267)
  • 診断後に予算を移動 (#12334)

デプス

  • 詳細要素ポリフィルとリムラフを削除 (#12369)
  • snyk: snyk スナップショットを更新します (#12385、#12361、#12336、#12315、#12289)
  • jsonld を最新 (#12338) に更新します
  • 問い合わせ者を問い合わせ者に置き換えます (#12317)
  • eslint を最新のものに更新 (#12333)

I18n

  • 新しい文字列をインポートします (#12411)

ドキュメント

  • アーキテクチャ: 収集とアーティファクトの説明を強化 (#12368)
  • Readme: 統合のリストに Alertdesk を追加 (#12356)

テスト

  • スモークリクエスト数アサーション (#12325)
  • ユニット cli から不安定な Chrome 起動を削除 (#12359)
  • 失敗した場合はいくつかの冗談テストを再試行します (#12298)
  • 関連するクロムの変更をチェックする cron (#11763)
  • devtools: Web テストの同期 (#12310)
  • スモーク: dbw_tester から HTML インポートを削除 (#12354)
  • スモーク: CLS-AF の期待値を更新 (#12353)
  • ジョブ間でのスモーク テストの分割を修正 (#12323)
  • 煙: オフライン警告チェックを一時的に無効にする (#12312)
  • スモーク: ランタン スクリプトの帰属の最大クロムを削除 (#12270)

その他

  • ci: 糸ネットワークのタイムアウトを増やす (#12376)
  • ツリーマップ: ルート ノード セレクター (#12360)
  • 未使用の監査文字列を調整 (削除 -> 削減) (#12281)
  • devtools からページをテストするための puppeteer スクリプト (#12145)
  • ツリーマップ: ロゴの間隔とテキストの色のスタイルを調整 (#12342)
  • roll-devtools スクリプトのパス チェックを修正 (#12358)
  • パトリックフルスを課題の課題に追加し直す (#12357)
  • open-devtools スクリプトを修正 (#12313)
  • 型指定された querySelector にデフォルトで SVG 要素を含めます (#12307)
  • スタックを含むように PhaseArtifact タイプを修正 (#12280)
  • セントリー: タグプロトコルメソッド (#12268)
