lighthouse v8.6.0

マイナー 公開日2021年10月13日 出典GoogleChrome/lighthouse 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#灯台v8.6.0 フルChangelog このリリースは 2 週間以内に Chrome 97 の DevTools および PageSpeed Insights にリリースされる予定です。

新しい貢献者

新しい寄稿者 👽🐷🐰🐯🐻 に感謝します!

  • ミーホーク @meehawk
  • エドウィン・グスタフソン @edwingustafson
  • ヨーキー・リュー @yorkie

コア

  • クロール可能アンカー: イベント リスナーを無視し、URL を検証します (#13105)
  • フルページのスクリーンショット: エミュレーションのリセットを修正 (#13175)
  • 応答圧縮: x-content-encoding-over-network を追加 (#13176)
  • コアとレポートの間でローカリゼーションを共有 (#13146)
  • cdt SourceMap を最新の devtools フロントエンドに更新 (#13095)
  • スタックパック: i18n ファイル名の検索を簡素化 (#13133)

⛏️👷 フラグルロック

ユーザー フローの監査のサポート (#11313)

  • UserFlow の使いやすさの改善を追加 (#13139)
  • カテゴリに supportedModes フィルターを追加 (#13161)
  • キャッシュされたタイムスパン レコードを処理します (#13181)
  • パリティログを追加 (#13114)
  • アニメーションのタイムスパンのサムネイル (#13178)
  • スナップショットとタイムスパンのパフォーマンスを調整 (#13184)
  • トップバーの保存ボタン (#13109)
  • ステップ名を省略します (#13171)
  • ローカライズされたサンプル (#13143)
  • タイムラインヘッダー (#13128)
  • フローを説明するヘルプ ダイアログを追加 (#13159)
  • i18n 文字列を収集 (#13152)

CLI

  • リストロケールフラグを追加 (#12983)
  • 常に正しいバージョンを返します (#13130)

レポート

  • ロガースタイルを js に移動 (#13204)
  • カテゴリスコアゲージから href を削除 (#13180)
  • reports/assets/styles.css をコンポーネント.js 経由で挿入 (#13057)
  • スムーズ スクロール CSS を削除 (#13102)
  • 残りの表示クラスに lh- プレフィックスを追加 (#13203)
  • スクリプト内のゲージ フラグメント リンクの処理 (#13186)

Clients

  • psi: 従来の psi レンダリングにグローバル レポート スタイルを含めます (#13151)
  • ビューア: ロケールの交換 (#10148、#13192)
  • ビューア: devtools の免責事項を削除 (#13145)
  • ビューア: ボディ スタイルを追加 (#13144)
  • ビューア: firebase 9 にアップグレード (#13115)
  • ビューア: Firebase 認証に関係なくアクセス トークンを使用する (#13116)
  • ビューア: 新しい Firebase 認証情報を使用します (#13110)

I18n

  • インポート (#13206)

ドキュメント

  • Node.js バージョン ベースを修正 (#13099)
  • ユーザー フロー ドキュメントを追加 (#13134)

テスト

  • スモーク: 非推奨について具体的な主張を行う (#13191)
  • M96 の非推奨スモークを更新 (#13179)
  • ヤーンユニットに利用可能なすべてのユニットテストを実行させる (#13148)
  • ドキュメント テストの実行を一元化する (#13150)
  • 分割斧テスト (#13142)

その他

  • ライトハウスコア/スクリプトを ES モジュールに変換 (#13121)
  • 問題の割り当て者からパトリックを削除 (#13194)
  • サンプル json タイミング エントリの予測可能な順序を設定 (#13162)
  • スクリプト: run-devtools スニッフィングを修正し、エラー チェックを追加 (#13163)
  • psi.espanol サンプルレポート es en espanol (#13160) を確認してください
  • 問題テンプレートにソフトウェア バージョンに関するメモを追加 (#13089)
  • ビルド: スモークハウス バンドルを修正 (#13135)
  • ビルド: より厳密な engines 文法を採用することで vercel のデプロイメントを修正 (#13183)
  • ビルド: rollup-plugins.js ヘルパー モジュールを作成 (#13122)
  • ビルド: --standalone のみが要求された場合はフローをビルドしません (#13124)
