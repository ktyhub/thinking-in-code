lighthouse v8.4.0

マイナー 公開日2021年9月8日 出典GoogleChrome/lighthouse 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#灯台v8.4.0 フルChangelog このリリースは 2 週間以内に Chrome 95 の DevTools および PageSpeed Insights にリリースされる予定です。

新しい貢献者

新しい寄稿者 👽🐷🐰🐯🐻 に感謝します! エマヌイル・ゾンポラキス @emzoumpo ミルティン・クリストフィック @milutin ビョルン・エリック・ペダーセン @bep ジェローム・キュキエ @jckr サウラフ・クマール @svkrclg

新しい監査

  • LCP 要素が遅延ロードされるときを検出します。遅延して読み込まれるスクロールせずに見える画像は、ページのライフサイクルの後半でレンダリングされるため、最大のコンテンツを含むペイントが遅れる可能性があります。 詳細 (#12838)

コア

  • network-request: ファイルシステム リソースを非ネットワークとして識別します (#12970)
  • ビューポート: ビューポート監査をパフォーマンス診断として追加 (#12972)
  • csp-evaluator: パッケージのバージョンをバンプ (#12990)
  • 設定: SkipAudits の場合にフルページのスクリーンショットを保持する (#12645)
  • 大きい-javascript-ライブラリ: 削除 (#12941)

⛏️👷 フラグルロック

ユーザー フローの監査のサポート (#11313)

  • pageLoadError で devtoolsLog を収集 (#12980)
  • 構成検証を追加 (#12945)
  • ナビゲーション失敗時の動作を調整 (#12862)
  • セッションにプロトコル タイムアウトを追加 (#12913)
  • スタックと FullPageSnapshot ギャザラーのパリティ (#12907)
  • http-status-code: ナビゲーションのみ (#13005)
  • --debugNavigation 設定を追加 (#12902)
  • フロー: サイドバー モック (#13002)
  • フロー: 埋め込み灯台レポート (#12989) ※フロー：概要ページ（#12973）
  • フロー: ナビゲーション サイドバー (#12929)
  • フロー: Preact を使用したスタンドアロン シェル レポート (#12850)

レポート

  • アクセス可能な該当なしアイコン (#12984)
  • 分割トップバー機能 (#12926)
  • すべてのクラス名の先頭に lh- (#12985) を付けます
  • 分離型チェック (#12953、#12952、#12951)
  • postMessage を使用して devtools の外でビューアを開く (#12927)
  • 警告の重複排除の改善 (#12355)

デプス

  • snyk: snyk スナップショットを更新 (#13001、#12982)
  • typescript 4.4.2 (#12909、#12999) に更新します

Clients

  • lightrider: iframe フェッチャーを使用します (#13006)
  • ツリーマップ: ES モジュールに変換 (#12892)
  • ビューア: ディレクトリ全体がモジュールを使用するようにします (#12975)

ドキュメント

  • 認証: README に不足しているビルド ステップを追加 (#12911)
  • changelog: changelog.md のタイプミスを修正 (#12997)
  • ハッキング: buildtracker/pr-tracking へのリンクを追加 (#12922)

テスト

  • ノード 16.9.0 (#13012) を回避します
  • ci: ToT Chromium ダウンロードを復元 (#12943、#12950)
  • dom: ノード 16 createObjectURL のバグを修正 (#12935)
  • eslint: インポート/順序ルールを追加 (#12998)
  • fr: スクリーンショットの期待値を変換 (#12912)
  • 煙: 通過ロボットのチェック-txt (#13007)
  • スモーク: dbw コンソールのエラー予期を修正 (#13011)
  • スモーク: 失敗を再実行するコマンドを出力します (#12924)
  • 開発ツール: 同期 (#12899)
  • devtools: tsc タイプ オーバーライドのバグ回避策 (#12933)
  • 偽の psi レポートを作成 (#12815)

その他

  • 素晴らしいサンプルのリベースライン (#12932)
  • プロジェクト参照を使用するようにタイプを再構築します (#12914、#12946、#12940)
  • ビルド: サンプル フロー レポート (#12930)
  • ビルド: devtools バンドルにロケールを含めない (#12921)
  • ビルド: devtools レポート リソースから template.html を削除 (#12891)
  • ビルド: UMD バンドル ビルドを作成 (#12898)
  • ビルド: サンプル レポートのビルド名の正規化 (#12901)
  • ビルド: gh-pages-app を使用するときにパスを優先する (#12905)
  • ビルド: devtools バンドルの調整をリファクタリング (#12974)
  • vercel のデプロイメントに使用される調整フォルダー (#12879)
  • cli: --output 引数に無効な値が渡された場合のエラーを改善 (#12836)
  • 失敗した場合はエラー コードを表示して収集文字列スクリプトを終了します (#12971)
