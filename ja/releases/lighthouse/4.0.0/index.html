lighthouse v4.0.0

メジャー 公開日2019年1月16日 出典GoogleChrome/lighthouse 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#灯台v4.0.0

新しい貢献者です!

@mattzeunert、@dima74、@jeffbcross、@knoxmic、@shogunsea。ありがとう！

大きな変更点

  • 一連のバグ修正とパフォーマンスの向上。 ※満点を獲得すると特別な報酬が得られます。
  • スピード、インストール性、洗練さを重視した、PWA カテゴリの新しいレイアウト。 <a href="https://user-images.githubusercontent.com/316891/51218948-6e60ef00-18e3-11e9-8a48-535b59a41301.png"><img height="300" alt="ライトハウス 4.0 PWA カテゴリ" src="https://user-images.githubusercontent.com/316891/51218948-6e60ef00-18e3-11e9-8a48-535b59a41301.png"></a>

重大な変更

  • 新しい PWA カテゴリ、組織、スコアリング (#6395)
    • レポートの PWA セクションには、数値スコア ゲージの代わりに一連のバッジが表示されます (#6526、#6670)
    • webapp-install-banner 監査は installable-manifest (#6630) になりました。
    • 以前 webapp-install-banner にあったオフライン チェックは、新しい監査 offline-start-url (#6397) です。
  • 監査の scoreDisplayMode 'not-applicable' は 'notApplicable' (#6783) になりました
  • no-websql 監査はパフォーマンスコストのため削除されました (#6293)
  • speed-index スコアリングはスロットリングに基づいてスケールされるようになりました (#7007)
  • 空の子配列が critical-request-chain 監査結果から削除されるようになりました (#6211)
  • Nexus 5X の正しい画面高さ 732 ではなく 660 が使用されるようになりました (#6932)
  • mobile3G のスロットリング定数は、値を変更せずに、より正確な mobileSlow4G に名前変更されました (#6163)
  • typescript 定義ファイルは types/ (#6617) の下に配置されました。
  • 計算されたアーティファクト ファイルは lighthouse-core/computed/ (#6618) の下に配置されるようになりました。 <時間> 完全な Changelog (4.0.0-beta、4.0.0-alpha.1、および 4.0.0-alpha.0 の変更に加えて)

コア

  • 設定: 新しいスコア ゲージの順序に一致するようにカテゴリを並べ替えます (#6848)
  • ドライバー: Driver.gotoURL 内でナビゲーション拒否を処理 (#6739)
  • ドライバー: 安全でない証明書を含むページをテストする場合は早期に終了します (#6608)
  • ドライバー: トレース時 waitForFCP (#6944)
  • 無効なネットワーク タイミング データを処理する (#6780)
  • ImageElement の usesObjectFit プロパティを修正 (#6761)
  • フォント: スタイルシート (#6782) に関連して URL を解決します。
  • ランタン: 不要なソート呼び出しを削除 (#6900)
  • ランタン: エラー メッセージからノード ID を削除 (#6774)
  • 縮小化: 正規表現文字クラスを適切に処理する (#6745)
  • 事前接続: 事前接続リンクが使用されていない場合の警告を追加 (#6694)
  • プリロード: 重複したリクエストが発行された場合に警告する (#6849)
  • scoreDisplayMode: 'not-applicable' を 'notApplicable' に変更 (#6783)
  • サービスワーカー: start_url が SW のスコープ内にあることを確認します (#6678)
  • Speedindex: スロットルに基づくスケール スコアリング係数 (#7007)
  • タップターゲット: ClientRects (#6703) を操作するためのヘルパー関数
  • URL: NON_NETWORK_PROTOCOLS にインテント プロトコルを追加 (#6711)
  • user-timings: 計算されたアーティファクトに移動 (#6719)
  • displayValue を文字列のみに変更 (#6767)
  • pwmetrics-events に型チェックを追加 (#6980)
  • より厳格な LR デスクトップ メトリック スコアリング (#6969)
  • ページ内関数のリファクタリング (#6702)

デプス

  • 軸コアを最新のものに更新 (#7020)
  • 詳細要素ポリフィルを 2.2.0 (#6928) に更新します
  • tsc を 3.2.2 (#6684) に更新します
  • snyk: snyk スナップショットを更新 (#6888、#6842)

ドキュメント

  • Readme: 統合リストに SpeedRank を追加 (#6987)
  • readme: インストール オプションに関する簡単なガイダンスを追加 (#6810) *configuration.md: pwmetrics へのリンクを更新 (#6816)
  • スコアリング: TTI 参照を更新 (#6865)
  • --help: bit.ly/chrome-flags への HTTPS リンクを使用します (#6692)
  • まずアップストリームで a11y の問題をテストするよう人々に依頼します (#6764)

拡張子

  • runLighthouseInExtension() から runnerResult を返します (#6839)

I18n

  • LighthouseError メッセージのローカライズ (#6457、#6812)

レポート

  • pwa: バッジ ゲージにツールチップを追加 (#6689)
  • 警告があった合格した監査の最上位セクションを追加 (#6989)
  • すべての 100 を祝います (#5455)
  • デフォルトでは「合格した監査」内のグループを展開します (#6930)
  • スコアゲージラッパーのマージンを修正 (#6948、#6972)
  • 狭い画面をサポート (#6857)
  • 監査グループの概要のマージンを大きくしました (#6688)
  • より多くの塊/グループ/拡張可能な塊をクリーンアップ (#6982)

テスト

  • スモークハウス: 期待値で errorCode をアサート (#6851)
  • スモークハウス: ノードのネイティブ URLSearchParams (#6929) を使用します
  • cli/tests/ に型チェックを追加 (#6874)
  • レポート: 失敗した古いグループ化テストを無効にして復元 (#7006)

その他

  • 説明: より正確なメトリックの説明 (#6508)
  • エミュレーション: 正しい Nexus 5X 画面サイズを使用します (#6932)
  • snyk: 検出可能なライブラリの脆弱性データのみを保持します (#6919)
  • Config 内のローカル名をクリーンアップ (#6950)
