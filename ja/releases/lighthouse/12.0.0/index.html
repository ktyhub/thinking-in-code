lighthouse v12.0.0

メジャー 公開日2024年4月22日 出典GoogleChrome/lighthouse 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#灯台v12.0.0 フルChangelog このリリースは、2 週間以内に Chrome 126 の DevTools および PageSpeed Insights にリリースされる予定です。

新しい貢献者

新しい寄稿者 👽🐷🐰🐯🐻 に感謝します!

  • アシュリー・リッチ @A5hleyRich
  • ミスターアディブ @JohnAdib

注目すべき変更点

PWA カテゴリの削除

Chrome の更新されたインストール可能性基準 に従って、Lighthouse は PWA カテゴリを削除しました。今後の PWA テストでは、ユーザーは 更新された PWA ドキュメント を使用するように指示されます。

SEOカテゴリーの再編

SEO カテゴリは、2024 年の Google 検索の優先順位を反映するように更新されました。そのため、いくつかの監査が削除されるか、他のカテゴリに移動されました。

  • is-crawlable 監査は、単独で SEO カテゴリに合格しないほど十分に重み付けされています。 (#15933)
  • viewport および font-size 監査は SEO の優先事項ではなくなりましたが、UX 全般にとって依然として重要であるため、ベスト プラクティスのカテゴリに移動されました。 (#15930)
  • plugins 監査は SEO の優先事項ではなくなったため、削除されました。 (#15928)
  • tap-targets 監査は SEO の優先事項ではなくなり、アクセシビリティの target-size 監査に置き換えられました。 (#15906)

全体的な貯蓄の減価償却

パフォーマンス診断監査の overallSavingsMs 値は非推奨になりました (#15902)。パフォーマンス診断によるメトリックの推定節約量を把握するには、metricSavings.LCP または metricSavings.FCP を使用することをお勧めします。

🆕 新しい監査

  • aria-conditional-attr、aria-deprecated-role、aria-prohibited-attr の斧チェックが灯台のアクセシビリティ カテゴリに追加されました。 (#15963)
  • redirects-http 監査は戻されましたが、指定された URL が http 上にある場合にのみ http -> https リダイレクトを受動的にチェックします (#13548)

その他の監査の変更

  • layout-shifts-elements 監査は削除されました。改善されたレイアウト シフト情報は、layout-shifts 監査で確認できます。 (#15931)
  • no-unload-listeners 監査は削除されました。アンロード リスナーは非推奨ですが、deprecations および bf-cache 監査でフラグが付けられています。 (#15874)
  • duplicate-id-active 監査は、対応する Ax チェックが非推奨になったため削除されました。 (#15900)
  • uses-rel-preload および preload-fonts 監査は実験用構成に移動されました。プリロード アドバイスはまだ保留中であり、これらの監査はすでに無効な状態になっています。 (#15876)

💥重大な変更

  • CSSUsage アーティファクトを分割 (#15952)
  • 予算を削除 (#15950)
  • 関連する監査リストを構成から削除します (#15878)
  • ScriptElements アーティファクト (#15879) を削除
  • 設定: 明示的な診断グループを使用する (#15901)
  • サービスワーカー: service-worker ギャザラー (#15942) を削除します

コア

  • a11y: ターゲット サイズの非表示監査を再度有効にする (#15888)
  • ドライバー: sendCommandAndIgnore を追加 (#15913)

  • ランタン: LR 統計を削除 (#15946)
  • ランタン: インライン rtt 定数 (#15944)
  • ランタン: LanternError とアダプターを LH エラーに追加 (#15937)
  • ランタン: CPU ノードで重複するタスクを修正 (#15938)
  • ランタン: lib/lantern 内の isNonNetworkProtocol が重複しています (#15936)
  • ランタン: LH.Artifacts.ProcessedTrace の使用を置き換えます (#15905)
  • ランタン: ランタンのメトリクスを lib/lantern に移動 (#15875)
  • メトリック: GatherContext モード チェックを削除 (#15899)
  • レンダーブロッキング: 信頼できる情報源としてトレース エンジンを使用する (#15839)
  • ランナー: 読みやすくするために早期リターンを使用します (#15914)
  • seo: リンクテキスト監査でペルシア語をサポート (#15949)
  • target-size: バイナリ表示モードを使用します (#15910)
