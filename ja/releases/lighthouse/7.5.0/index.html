lighthouse v7.5.0

#灯台v7.5.0 フルChangelog このリリースは 2 週間以内に Chrome 92 の DevTools および PageSpeed Insights にリリースされる予定です。

  • ヨハネス・ウェーバー @johannes-weber

注目すべき変更点

灯台ツリーマップをリリースします！ webtreemap (私たちが使用しています!) または source-map-explorer のおかげで、ツリーマップについてはすでによく知っているかもしれません。 Lighthouse ツリーマップを使用すると、ページ上の JavaScript の量を減らすのに役立ついくつかの洞察に加えて、Lighthouse レポートからページ上のすべての JavaScript バンドルを簡単に表示できるようになります。唯一の要件は、ソース マップに (パブリックに、または Lighthouse 監査を実行している同じコンピューターから安全に) アクセスできることです。 Chrome からコード カバレッジ データも収集し、バンドル内の個々のモジュールのカバレッジを推定します。 注: これはコールドロードのみを考慮しています。ユーザー操作後にのみ使用されるコードは未使用としてマークされます。今後のリリースにご期待ください。これにより、ユーザー フローを構成し、さらに正確なパフォーマンスの洞察を取得できるようになります。 複数のバンドルに含まれる大きなモジュールが検出された場合は、それについても警告します。 レポートから Lighthouse ツリーマップにアクセスできます。 現在、Lighthouse ノード CLI で生成されたレポートのみが Lighthouse Treemap アプリに接続されます。私たちは、DevTools および PageSpeed Insights の Lighthouse にこの機能を追加することに取り組んでいます。 デモ
