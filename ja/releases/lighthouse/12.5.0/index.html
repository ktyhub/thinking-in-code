lighthouse v12.5.0

マイナー 公開日2025年3月25日 出典GoogleChrome/lighthouse 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#灯台v12.5.0 フルChangelog このリリースは 2 週間以内に Chrome 136 の DevTools および PageSpeed Insights にリリースされる予定です。

注目すべき変更点

  • legacy-javascript は、どのコードが「レガシー」とみなされるかを決定するために、esmodule ではなく Baseline をターゲットにするように更新されました (#16366)。

コア

  • 拡張トレースを有効にし、ソース マップをトレース エンジンに渡します (#16396)
  • ランタン設定をトレース エンジンに渡し、ログを追加します (#16377)
  • トレース エンジン i18n 機能を LH i18n モデルに適応 (#16365)
  • 計算されたアーティファクト: 未定義のプロパティを禁止します (#16397)
  • 重複-javascript: しきい値を 1 KiB から 10 KiB に増加 (#16368)
  • image-delivery-insight: 保存せずに文字列を使用する (#16364)
  • 洞察: use-cache-insight を実装 (#16401)
  • 洞察: アップグレードと強制リフローの実装 (#16395)
  • インサイト: デフォルトで非表示グループに移動 (#16391)
  • インサイト: フォント表示インサイトを実装 (#16369)
  • レガシー-javascript: 一部の非縮小バンドル検出を再加工/元に戻す (#16394)
  • レガシー-javascript: ロールアップ バンドルをサポート (#16389)
  • レガシー-javascript: esbuild バンドルをサポート (#16385)
  • レガシー-javascript: 非縮小コードをサポート (#16384)
  • レガシー-javascript: 変換検出を改善 (#16381)
  • script-treemap-data: ノードを折りたたむときに重複した情報を保持する (#16379)

デプス

  • アップグレード配備 (#16408)
  • トレースエンジンを 0.0.47 にアップグレード (#16376)
  • トレースエンジンをアップグレードし、cdt bf-cache/非推奨文字列を再利用 (#16362)

I18n

  • インポート (#16409)

テスト

  • isUnderTest が適切に設定されていないローカルの mocha テストを修正 (#16399)
  • ノード 20.19 の i18n フォーマットを修正 (#16398)
  • トレースエンジン: 期待値を修正 (#16380)

その他

  • サポート ファイルを core/lib/legacy-javascript に移動 (#16393)
  • 従来の javascript 検出をコア/ライブラリに抽出 (#16392)
  • ビルド: バンドル ライセンス著作権ヘッダーに現在の年を使用 (#16375)
  • ツリーマップ: 新しいデザインに合わせてヘッダーを再構築 (#16402)
