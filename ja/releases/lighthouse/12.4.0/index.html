lighthouse v12.4.0

マイナー 公開日2025年2月26日 出典GoogleChrome/lighthouse 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#灯台v12.4.0 フルChangelog このリリースは 2 週間以内に Chrome 135 の DevTools および PageSpeed Insights にリリースされる予定です。

新しい貢献者

新しい寄稿者 👽🐷🐰🐯🐻 に感謝します!

  • ダニール・ヴァンゴネン @dvangonen
  • レネ・シュヴィーツケ @rschwietzke
  • アンティ @hilja
  • ヨハネス・ホーミエ @homj

注目すべき変更点

  • 一部のパフォーマンス監査は、合格した監査セクションに隠されるのではなく、合格した条件下で情報としてマークされます。このリリースでは、この動作が発生する監査の数が減少しました。 (#16315)

新しい監査

  • XFO または CSP (#16290) を通じて cliCKjacking を確実に軽減します。

コア

  • より多くの洞察監査を実装し、ローカリゼーションを処理します (#16326)
  • インサイト カテゴリに基づいて関連する指標を設定します (#16325)
  • 各インサイトに非表示の監査を追加 (#16312)
  • cls-culprits-insight: 実装 (#16357)
  • インスペクターの問題: SRI メッセージ署名の問題をサポート (#16345)
  • インスペクターの問題: 選択要素 a11y 問題をタイプに追加 (#16298)
  • レガシー-javascript: Babel と core-js をアップグレードします (#16331)
  • 根本原因: プロトコルを使用するのではなく、トレースの洞察から取得する (#16352)
  • トレースエンジン: 無効化ハンドラーを再度有効にする (#16293)

レポート

  • DevTools でのレスポンシブ デザインにコンテナー クエリを使用する (#16342)
  • インサイトとともに LH のみの診断をレンダリングします (#16332)
  • 実験的洞察を切り替えるボタンを追加 (#16329)
  • チェックリストの詳細タイプを追加 (#16324)

デプス

  • 重要な依存関係をアップグレードします (#16358)
  • csp_evaluator を 1.1.5 (#16347) にアップグレードします
  • 最新の chrome-devtools-frontend に更新します (#16333)
  • 人形遣いを 24.2.1 (#16341) にアップグレードします
  • サードパーティ Web を 0.26.5 (#16340) にアップグレードします
  • 人形遣いを 24.1.1 (#16302) にアップグレードします
  • trace_engine を 0.0.40 (#16311) にアップグレードします

I18n

  • インポート (#16360)

ドキュメント

  • readme: Web Perf サービスのリストに Sonā を追加 (#16282)

テスト

  • アドレスアップストリーム変更 (#16335)
  • サンプル アーティファクトを更新 (#16322)
  • dbw: アンロード ハンドラーの期待値を元に戻す (#16353)
  • devtools: DT スロットルによるスモーク テストのエラーを修正 (#16301)

その他

  • 問題の割り当て者を削除 (#16317)
  • ci: クロムに関する新しい ubuntu 23 セキュリティ問題の回避策 (#16296)
  • readme: ネオジムへのリンクを追加 (#16349)
  • リリース: 重要な依存関係を更新するためのスクリプトを追加 (#16359)
  • タイプ: NodeValue の説明のために不足しているタイプを追加 (#16314)
