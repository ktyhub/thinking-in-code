lighthouse v7.0.0

メジャー 公開日2020年12月18日 出典GoogleChrome/lighthouse 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#灯台v7.0.0 #7.0.0 (2020-12-17) フルChangelog Lighthouse 7.0 には、アクセシビリティ および PWA カテゴリのプログラムによる重大な変更と新しい監査が多数含まれています。指標計算の精度はいくらか向上しましたが、ほぼすべてのサイトで パフォーマンス スコアが大幅に変化することは予想されません。新しい監査により、アクセシビリティ および PWA のスコアに大きな変化が生じる可能性があります。 このリリースは、Chrome 89 の DevTools に同梱される予定です。 2021 年 2 月 19 日に PageSpeed Insights で公開されました。

注目すべき変更点

  • 全ページのスクリーンショットが撮影され、DOM 要素の詳細を表示するエクスペリエンスを向上させるために使用されます。サムネイルが表示され、clicking を実行すると、ページ内の DOM ノードが存在する場所を示すライトボックスが表示されます。このスクリーンショットでは、Lighthouse JSON のサイズが最大 33% 増加しています。 (#11769、#11768、#11829、#11846、#11852)
  • PWA カテゴリはかなり大幅に変更されました。
    • Installable グループは、Chrome のインストール可能基準を有効にする機能チェックによって完全に強化されています。これらは、Chrome DevTools の Manifest ペインに表示されるシグナルと同じです。そのため、「Service Worker の登録…」監査は PWA Optimized グループに移動し、「HTTPS の使用」監査は主要な「インストール要件」監査の一部として含まれるようになりました。
    • 「速くて信頼できる」グループは消滅してしまいました。 🌬 改良された「インストール可能性要件」監査にオフライン機能チェックが含まれるようになったため、オフライン時に現在のページと start_url が 200 で応答するかどうかをチェックする専用の監査を削除しました。これとは別に、「モバイル ネットワーク上でページの読み込みが十分に速い」監査は削除されました。この監査は PWA セクションの一部ではなくなりましたが、PWA を構築している人は、Web アプリが高速で快適であることを確認するためにパフォーマンス カテゴリを参照することをお勧めします。
  • 夜間の Lighthouse ビルド は、npm で lighthouse@next として利用可能になりました。自動テストは公開前に合格しますが、このバージョンは通常のリリース (#11792、#11805、#11810) よりも不安定になることが予想されることに注意してください。
  • アクセシビリティ テスト ライブラリ axe-core は、最新の 4.1.1 リリースに更新されました。アクセシビリティ監査はより高速かつ堅牢になり、複数の新しいチェックが含まれています (#11661)
  • Lighthouse は起動時に小規模なベンチマークを実行し、テスト マシンのパワーが不足しているようです 場合に警告が含まれるようになり、Lighthouse メトリクスの精度に影響を与える可能性があります (#11350)
  • Joomla と October CMS 検出が追加されたため、これらのプラットフォーム上のページは、一部の Lighthouse 監査に関するカスタマイズされたアドバイスを取得できるようになります (#11788)

新しい貢献者

最初の寄稿をしていただいた Kohta Ito (@koh110) と Sam Stoelinga (@samos123) に感謝します。

🆕 新しい監査

  • 前述の新しい installable-manifest PWA 監査は Chrome 独自のインストール可能性基準を使用するため、インストール可能性の要件と常に同期されます (#11745)
  • third-party-facades は、静的な「ファサード」で遅延ロードできるテスト ページ内のサードパーティの埋め込みを探します。ユーザーによる即時操作に埋め込みが必要ない場合は、ファサードの 1 つを使用してページの読み込みを高速化することを検討してください (#11290)
  • axe バージョンのアップグレードに伴い、アクセス可能な名前付けを保証する新しい監査が追加されました: aria-treeitem-name、aria-command-name、aria-tooltip-name、aria-meter-name、および aria-progressbar-name (#11661)

♻️ 監査を削除しました

  • 最新の axe-core への更新により、あまりチェックされていなかった 2 つの監査も削除されます: layout-table および video-description (#11661)
  • works-offline および offline-start-url 監査は、それらのチェックが新しい installable-manifest 実装 (#11806) でカバーされるようになったため、削除されました。
  • Lighthouse の既存のパフォーマンス指標がニーズを十分にカバーしているため、load-fast-enough-for-pwa 監査も削除されました (#11764)
  • without-javascript は削除されました (#11711)

💥 重大な変更

  • デバイス エミュレーション構成設定と CLI フラグが、より明確になり、重複が少なくなるように変更されました。 --emulated-form-factor またはその他のエミュレーション関連の構成を使用している場合は、変更を加える必要があります。新しい設定は、実際のデバイス、Puppeteer、またはシステムレベルのスロットリングを使用するカスタム Lighthouse ランナーで使用するのがかなり簡単になります。移行ガイダンスについては、エミュレーション ドキュメント を参照してください。 (#11779)
  • ページが完全にロードされるのを待機するときに、アクティブな優先度の高いネットワーク要求がある場合、Lighthouse は待機するようになりました。まれに、アプリの初期化が単一の応答の遅い XHR に依存している場合など、一部のパフォーマンス指標が悪化することがあります。ただし、新しい測定値は正確になりました。 (#11738、#11851)
  • Node 10 のサポートは終了しました。必要なノードの最小バージョンは 12 になりました (#11656)

🤖💥 プログラマティック ユーザー向けの重大な変更

これらの変更がエンド ユーザーに影響を与える可能性はほとんどありませんが、カスタム構成、プラグインを作成する場合、または Lighthouse JSON 出力を処理する場合には重要になる可能性があります。

  • ConsoleMessages は、古い ConsoleMessages アーティファクトと RuntimeExceptions アーティファクトを組み合わせた 新しいアーティファクト であり、コンソールに記録される項目に関する拡張データがいくつか含まれています。 RuntimeExceptions は削除されました (#11663)
  • 以前は既存のアーティファクト全体に分散していた DOM の「ノードの詳細」データが、各要素 (#11474、#11695、#11752) の NodeDetails プロパティに収集されるようになりました。
  • ImageElements アーティファクト は、収集されたデータとその使用方法をより適切に表現するために 合理化 されました (#11703、#11707、#11733)
  • 以前は、デフォルトの Lighthouse 設定ファイルから 設定を拡張するための extends: 'lighthouse:default' のエイリアスとして extends: true が許可されていました。有効な構成ファイルから拡張する方法を準備するために、ブール値オプションが削除されました (#11835)
  • 構成からギャザラーにオプションを渡すために使用されなかった機能は、将来の変更との互換性を保つために削除されました (#11743)

🧱 コア

改善、バグ修正、説明

  • ランタン: 非 XHR が CPU ノードに依存できるようにする (#11767)
  • ランタン: HTTP/2 でスループットを最大化します (#11666)
  • Unicode サロゲート ペアに基づいてレポート内のノード ラベルを適切に分割しました (#11698)
  • service-worker 監査を pwa 最適化グループに移動します。 JSON 内のパスとスコープ URL のメタデータは変更されません (#11798)
  • グローバルにインストールされた Lighthouse からのローカル プラグインをサポート (#11696)

内部リファクタリングと改善

  • ドライバー: 関数コードから型付き Runtime.evaluate を作成 (#10816)
  • ギャザーランナー: InstallabilityErrors の <M82 compat を削除 (#11782)
  • シミュレーター: より明確な中間タイミング タイプ (#11744)
  • タイプ: 不要なキャストを削除 (#11753)
  • lightrider: uses-http2 監査をスキップ (再度) (#11777)
  • script-treemap-data: SourceRoot と欠落カバレッジのバグを修正 (#11825)
  • fraggle-rock: ベース スナップショット ランナーを追加 (#11748)
  • fraggle-rock: ドライバーを追加 (#11742)

テスト

  • github アクションで変更関連のテストを再度有効にします (#11801)
  • 煙: テストで非合成アニメーションのフォント サイズを使用します (#11808、#11836)
  • スモーク: テスト中のハンドル warn-not-offline-capable (#11799)
  • スモーク: 失敗理由マスクフレークを修正 (#11791)
  • スモーク: 不安定な third-party-facades テストを更新 (#11786)
  • devtools の Web テストを安定して信頼できるものにする (#11717、#11731、#11751、#11789、#11790、#11804、 #11809、6ad47fa)

その他

  • uses-http2: ドキュメント内の h2 プッシュに関する記述を削除 (#11834)
  • readme: 統合を追加 (#11775)
  • GCP 実行結果にログ ファイルを追加 (#11833)
  • 一時的に redirectPass の CSS が crbug を回避できるようにしました (#11813)
  • *.d.ts ファイル (#11793) を無視します
  • buildtracker: トークンがない場合は git --deepen をスキップ (#11785)
  • ビルド: npm pack コマンドを停止します (#11783)
  • ビルド: Lightrider の lighthouse-plugin-publisher-ads のバンドルを修正 (#11648)
  • リリース: print-contributors.js スクリプトを追加 (#11736)

デプス

  • yargs を最新のものに更新 (#11794)
  • 古い推移的な deps を更新 (#11811)
