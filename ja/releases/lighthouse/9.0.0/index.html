#灯台v9.0.0 フルChangelog このリリースは Chrome 98 の DevTools に同梱される予定です。これは、新しい PageSpeed Insights ですでに公開されています。 Lighthouse 9.0 のブログ投稿の新機能 を参照してください。 changelog に続きます。
