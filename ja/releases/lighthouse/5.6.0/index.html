lighthouse v5.6.0

マイナー 公開日2019年10月17日 出典GoogleChrome/lighthouse 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#灯台v5.6.0 フルChangelog このリリースは Chrome 79 の DevTools に同梱される予定です。

新しい貢献者です!

最初の貢献をしてくれた @dpacassi、@lirantal、@yeonjuan に感謝します。

注目すべき

  • 収集: 新しい MainDocumentContent パブリック アーティファクトを追加 (#9781)
  • スタックパック: angular、react、amp、magento パックを追加 (#9797)

コア

  • トレースハウス: 子が親より 1ms 未満で開始できるようにする (#9786)
  • ドライバー: Runtime.evaluate のエラー処理を修正 (#9831)
  • コンソールのエラー:ignoredPatterns オプションを追加 (#9480、#9829)
  • 画像要素: NaturalSize 結果をキャッシュ (#9818)
  • リンク要素: 非 HTMLLinkElements を無視します (#9765)
  • 最適化された画像: ログエラー (#9782)
  • seo: リンクテキスト監査で韓国語をサポート (#9804)
  • トレースハウス: 終わりのないネストされたトレース イベントを許可します (#9785)
  • 要素の名前を LHElement (#9832) に変更します

デプス

  • サードパーティ Web を 0.11.0 (#9849) に更新します
  • snyk: snyk スナップショットを更新 (#9793)

レポート

  • サードパーティおよび crc 用にタイトルを言い換え (#9419)
  • dom サイズの記述を書き換え (#9821)
  • トップバーのロゴを更新 (#9728)
  • いくつかのデッドコードを削除 (#9800)

Clients

  • lr: バンドルに HTML レポート アセットを含めない (#9828)
  • ビューア: インライン レポート ジェネレーター バンドルを縮小 (#9596)

I18n

  • インポート: web.dev リンクと小さな修正 (#9846)
  • インポート翻訳 (#9802)

ドキュメント

  • 関連プロジェクト: 灯台チェックを追加 (#9753)
  • 関連プロジェクト: is-website-vulnerable CLI ツールを追加 (#9810)
  • 関連プロジェクト: Gradle Lighthouse プラグインを追加 (#9789)
  • i18n Readme のドキュメントの「意味」フィールド (#9787)
  • 監査への古い参照を更新 (#9760)

テスト

  • バンドルをテストするには消防署煙テスト ランナーを使用します (#9791)
  • CI でバンドル テストを 3 回試行します (#9830)
  • スモークハウス: tmp ディレクトリの作成を修正 (#9855)
  • スモークハウス: テスト定義に静的要件を使用する (#9501)

その他

  • ビルド: Lightrider レポート ジェネレーター用のレポート javascript を縮小 (#9823)
  • さらなるリリース調整 (#9772)
  • タイミング比較スクリプトを追加 (#9723、#9776)
