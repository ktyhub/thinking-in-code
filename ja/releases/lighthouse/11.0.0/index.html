lighthouse v11.0.0

メジャー 公開日2023年8月3日 出典GoogleChrome/lighthouse 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#灯台v11.0.0 フルChangelog このリリースは、2 週間以内に Chrome 118 の DevTools および PageSpeed Insights にリリースされる予定です。

新しい貢献者

新しい寄稿者 👽🐷🐰🐯🐻 に感謝します!

  • 中村彩人 @penicillin0
  • パトリック・ケトナー @patrickkettner
  • ラッセシュウ @lasesschou
  • @ZzZzzxc

注目すべき変更点

従来のナビゲーション ランナーを削除しました

CLI の --legacy-navigation フラグ、ノード API の legacyNavigation() 関数、および DevTools パネルの [レガシー ナビゲーション] チェックボックスはすべて削除されました。

新しい DevtoolsLog および Trace アーティファクト

カスタム監査の場合、devtoolsLogs['defaultPass'] および traces['defaultPass'] アーティファクトは非推奨になり、DevtoolsLog および Trace が優先されます。使用例については、プラグイン ドキュメント を参照してください。 devtoolsLogs と traces は互換性のためにまだ存在していますが、将来の最新リリースでは削除される予定です。

🆕 新しい監査

  • マイナー軸監査を追加し、既存のものを再重み付けします (#15298)

💥 重大な変更

  • その他: ノード 16 のサポートを削除 (#15290)
  • コア: resource-summary 監査を削除 (#15299)
  • コア: DevtoolsLogError および TraceError アーティファクトを追加 (#15311)
  • コア: INP を非実験的にする (#15285)
  • コア: service-worker 監査を削除 (#15257)
  • コア: レガシー ランナーを削除 (#15253)
  • コア: first-contentful-paint-3g 監査を削除 (#15252)

コア

  • 再重み付けのベスト プラクティス (#15321)
  • 単一のネットワーク モニターをドライバー上に維持 (#15055)
  • レコードが正常でない場合に NOT_HTML エラーを発行しません (#15271)
  • 収集時にアーティファクト エラーを報告、err.extra (#15258) を追加
  • タイプから「FR」プレフィックスを削除します (#15274)
  • 従来のアーティファクト タイプを削除 (#15273)
  • 重複-javascript: 有効な粒度を使用します (#15275)
  • lcp 要素: フェーズ テーブルのエラーを適切に処理する (#15329)
  • ネットワーク アナライザー: オリジンごとの粗い rtt 推定 (#15103)
  • ネットワーク要求: ライトライダー タイミング チェックサムを緩める (#15330)
  • render-blocking-resources: FCP と LCP の節約を追加 (#15238)
  • 応答圧縮: 予期しないエラーが発生した場合にスロー (#15259)
  • ソースマップ: Scripts を依存関係として使用します (#15293)
  • スタックパック: NitroPack 検出を追加 (#15314)
  • uses-http2: LCP と FCP の節約を追加 (#15320)
  • uses-rel-preconnect: FCP と LCP の節約を追加 (#15281)

CLI

  • セントリー: プロンプトで --enable-error-reporting フラグに言及 (#15174)

レポート

  • 手動監査を再順序付けし、監査に合格したら拡張します (#15310)
  • 「オリジナル トレースの表示」をトップバーのドロップダウンに移動 (#15315)

デプス

  • 人形遣いを 21.0.1 (#15331) にアップグレードします
  • lighthouse-logger を 2.0.1 (#15282) にアップグレードします
  • chrome-launcher を 1.0.0 (#15287) にアップグレードします
  • 重複排除のyarn.lock (#15269)
  • ロボットパーサーを 3.0.1 (#15268) にアップグレードします

Clients

  • 拡張機能: マニフェスト v3 に更新 (#15219)

I18n

  • インポート (#15334)

ドキュメント

  • 従来のナビゲーション (#15340) を削除します
  • devtoolsLogs および traces (#15318) への参照を削除
  • プラグイン: 構文のタイプミスを修正 (#15264)
  • readme: PageVitals を統合のリストに追加 (#15288)

テスト

  • ページ関数バンドルテストを追加 (#15280)
  • 再帰フラグを使用してスモークハウス出力ディレクトリを作成 (#15261)
  • スモークハウスの出力を .tmp/smokehouse-output に保存 (#15251)
  • バンドルされたワーカーからのエラーに対して toString を呼び出します (#15245)
  • devtools: 未使用のテスト オプションを削除 (#15260)
  • 開発ツール: 同期 e2e (#15250)
  • スモーク: a11y タップターゲットで小数を許可 (#15327)
  • スモーク: 従来のサポートを削除 (#15249)

その他

  • レガシーへの残留参照を削除 (#15292)
  • タイプミスを修正 (#15120)
  • fraggle-rock フィクスチャ ディレクトリの名前を user-flows (#15291) に変更します
  • ロガーへのメインパスを追加 (#15284)
  • ビルド: terser の代わりに esbuild minification をバンドルします (#15283)
  • ビルド: ロールアップを esbuild に置き換えます (#15239)
  • ci: 非推奨のノード 12 を使用した更新アクション (#15304)
  • ロガー: タイプを追加し、cjs を削除 (#15279)
