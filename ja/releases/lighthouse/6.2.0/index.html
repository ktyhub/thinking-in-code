lighthouse v6.2.0

マイナー 公開日2020年8月6日 出典GoogleChrome/lighthouse 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#灯台v6.2.0 #6.2.0 (2020-08-06) フルChangelog このリリースは、Chrome 86 の DevTools および PageSpeed に同梱される予定です。 2 週間以内に分析情報が得られます。

新しい監査

  • 重複した javascript 監査と従来の javascript 監査をデフォルト設定に移動 (#10881、#11103)
  • レポート アニメーションはコンポジターでは実行されません (#11138、#11168、#11105)
  • サイズ変更されていない画像の監査を追加 (#11188、#11115、#11217)
  • アンロードリスナーなしの監査を追加 (#11085)

コア

  • uses-http2: 機会に変換 (#10626)
  • ランタン: ウェイト 0 の SI 状況での FCP へのフォールバック (#11174)
  • スタック: タイムアウトスタック検出 (#11172)
  • FormElements ギャザラーを追加 (#11062)
  • cls: 早期シフト イベントが無視された場合に追加し直す (#11079) *critical-request-chains: イニシエーターなしでリクエストをプルーニングします (#11151)
  • Chrome バージョンが lcp メトリクスをサポートしていない場合のエラー (#11016)
  • font-display: フォントの起源による重複排除警告 (#11068)
  • 収集ランナー: 非 HTML でのエラー (#11042)
  • hreflang: href が完全修飾であることをアサートします (#11022)
  • 画像要素: srcset の正しい自然なサイズを収集 (#11101)
  • is-on-https: 混合コンテンツの解決策を追加 (#10975)
  • ランタン: 循環イニシエーターを無視する (#11148)
  • リンク要素: devtoolsNodePath を追加 (#11061)
  • リンクテキスト: ブロックリストから inicio を削除すると #11026 (#11073) が解決されます
  • ページ関数: シミュレートされたスロットル requestIdleCallback シムを公開 (#11032)
  • リダイレクト: サーフェス client 側リダイレクト (#11027)
  • トレースハウス: NavigationStart を timeOrigin としてのみ公開 (#11034)
  • シミュレートされたスロットルのためのアンプ スタイルシート リンクにキャップを追加 (#11069)
  • 非推奨のextendedInfoフィールドの使用を削除 (#10779)
  • 設定: a11y テーブル リスト グループのタイプミスを削除 (#11099)

CLI

  • 高速終了のための clearTimeout (#11170)
  • Chrome が終了せずに自動的に終了した場合に警告する (#11139)

レポート

  • 予算表に CLS を正しく表示 (#11209)
  • フルページのスクリーンショットを実験的な構成に追加 (#10716)
  • 縦中央のサムネイル (#11220)
  • HTML スニペット内の長い属性値を切り詰めます (#10984)
  • 未使用-javascript: 「詳細」リンクを更新 (#10985)

デプス

  • snyk: スクリプトを更新して <0.0.0 をプルーニングし、スナップショットを更新します (#11223)
  • snyk: snyk スナップショットを更新 (#11046)
  • dot-prop の二次依存関係を更新 (#11198)
  • jpeg-js を 0.4.x (#11167) に更新します
  • サードパーティ Web を更新 (#11137)

I18n

  • インポート文字列 (#11082、#11225)
  • 複雑な ICU 引数以外の無効なテキストを禁止します (#11135)
  • AMP オプティマイザー URL を更新 (#11088)
  • 翻訳されたメッセージの割合をログに記録します (#11149)

ドキュメント

  • 構成: 更新と調整 (#11141)
  • アーキテクチャ.md を更新 (#11040、#11089)
  • readme: Screpy を統合のリストに追加 (#11126)
  • readme: プログラムによる使用コード例でのログ記録を修正 (#11116)
  • devtools のスクリーンショットを更新 (#11092)
  • URL から json をロードするためのビューアの Readme のタイプミスを修正 (#11080)
  • Readme: Foo 統合の更新 (#11050)

テスト

  • イスタンブールはページ内機能を無視 (#11229)
  • chromestatus の期待値を更新 (#11221)
  • minification-est: 事前に縮小されたバンドルを含むテストケースを追加します (#11191)
  • typescript 3.9.7 (#11158) に更新
  • スモーク: _chromeMajorVersion で期待値をスキップ (#10976)
  • スモーク: ポリマーショップの代わりに caltrainschedule を使用します (#11052)
  • requestIdleCallback のスモーク期待値を緩和 (#11041)
  • すべてのテストを並列化します (#11009)
  • codecov を 3.7.0 (#11039) にアップグレードします
  • Angular Fixture Redux のマイナー バージョンを更新 (#11192)
  • マスターと PR で GitHub アクションを実行 (#11035)
  • github アクションでテストビューアーを実行 (#11195)
  • GitHub アクション CI にウィンドウを追加 (#11087)
  • appveyor の最新の Windows イメージを使用します (#11083)
  • appveyer を削除 (#11171)

その他

  • LH.Audit.Product の最後のextendedInfoを削除 (#11067)
  • GCP 収集スクリプトを追加 (#11189)
  • RecursivePartial 型を締める (#11175)
  • リリース: 調整 (#11021)
  • 比較実行: lh-flags 引数が渡されなかった場合のエラーを修正 (#11015)
  • バージョン固有のロジックに COMPAT コメントで注釈を付ける (#11019)
  • 問題の応答時間を追跡するツールを追加 (#11020)
  • 要素スクリーンショット レンダラーでの名前付けの調整 (#11152)
  • ページ関数のカバレッジを無視します (#11136)
