lighthouse v10.3.0

マイナー 公開日2023年6月14日 出典GoogleChrome/lighthouse 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#灯台v10.3.0 フルChangelog このリリースは 2 週間以内に Chrome 116 の DevTools および PageSpeed Insights にリリースされる予定です。

新しい貢献者

新しい寄稿者 👽🐷🐰🐯🐻 に感謝します!

  • デレク・パーキンス @derekperkins
  • ロブ・マクガイア @robatron
  • Aditya Dharmawan Saputra @adityadees

新しい監査

  • table-fake-caption、html-xml-lang-mismatch、input-button-name (#15098)
  • td-has-header (#15051)

コア

  • エラーが発生した監査でエラー スタックを公開 (#14491)
  • メトリックの節約を監査製品に移動 (#15074)
  • 監査結果にメトリックの節約を追加 (#14997)
  • バイト効率: 対数正規分布スコアリングを使用します (#14977)
  • クロール可能アンカー: アンカーとして機能する要素を許可します (#15079)
  • 累積レイアウトシフト: totalCumulativeLayoutShift (#15122) を削除します
  • エンティティ分類: クロム拡張機能を個別のエンティティに分類します (#15017)
  • global-listeners: すべての実行コンテキストを反復します (#15054)
  • 検査官の問題: federatedAuthUserInfoRequestIssue (#15149) を追加します
  • 検査官の問題: stylesheetLoadingIssue (#15144) を追加します
  • biggest-contentful-paint-element: LCP 値を表示 (#15061)
  • レイアウトシフト要素: CLS 節約を追加 (#15070)
  • ネットワーク アナライザー: lrStatistics からの推定値 (#15158)
  • ネットワーク アナライザー: rtt 推定値に 0 開始時間を含めます (#15100)
  • ネットワーク アナライザー: h3 推定のラウンドトリップ数を修正 (#15102)
  • ネットワーク アナライザー: 中央値に算術平均を使用します (#15096)
  • ネットワーク アナライザー: h3 の単一の rtt 推定値を推測します (#15095)
  • network-request: recomputeTimesWithResourceTiming を簡略化します (#15107)
  • network-requests: エンティティ分類を追加 (#15105)
  • サーバー応答時間: ライトライダーの修正 (#15156)
  • サーバー応答時間: end の代わりに acceptHeadersStart を使用します (#15155)
  • 最初のバイトまでの時間: acceptHeadersStart (#15126) を使用します
  • トレース要素: CLS メトリック イベント フィルタリングを使用する (#15067)
  • uses-rel-preconnect: 0 の接続開始タイミングを処理する (#15157)

レポート

  • utm クエリ パラメータをスタック パック リンクに追加します (#15094)
  • エラーアイコンを更新 (#15092)
  • 紙吹雪アニメーションのキーフレームを更新 (#15059)

デプス

  • サードパーティ Web を 0.23.0 (#15166) にアップグレードします
  • 人形遣いを 20.7.1 (#15164) にアップグレードします
  • 軸コアを 4.7.2 (#15165) にアップグレード
  • 最新の chrome-devtools-frontend に更新します (#15137)
  • puppeteer および puppeteer-core をアップグレード (#15143)
  • サードパーティ Web を 0.22.0 (#15097) にアップグレードします
  • 軸コアを 4.7.1 (#15078) にアップグレード
  • lighthouse-logger を 1.4.1 (#15082) にアップグレードします
  • es-main: 1.2.0 (#15121) に更新

I18n

  • インポート (#15168)

ドキュメント

  • Readme: 単体テストのヒントを追加 (#15108)
  • Readme: laravel-lighthouse をプロジェクト リストに追加 (#15011)

テスト

  • afterPass のほとんどの使用を削除 (#15057)
  • リベースラインインスペクターの問題の詳細タイプ (#15050)
  • ci: Windows 遅延障害を修正するためのノードのバンプ (#15162)
  • スモーク: network-rtt、network-server-latency の期待値を追加 (#15113)
  • スモーク: dbw から外部リソースを削除 (#15111)
  • スモーク: lcp 要素の期待値を追加 (#15112)

その他

  • lighthouse-logger でノード 10 をサポート (#15089)
  • ロガーの cjs パスを追加 (#15084)
  • lighthouse-logger を v1.4.0 にバンプ (#15081)
  • 比較実行: ライトハウスへの複数の引数を許可します (#15066)
  • ランタンコレクト: ドロップサンプリング (#15072)
  • ランタン収集: ゴールデン ジップに中央値 lhr を追加 (#15077)
  • ランタン収集: 新しい ttfb メトリクスを含めるためにベースラインを変更 (#15069)
  • proto: パッケージ名を追加 (#15116)
