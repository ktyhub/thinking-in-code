#13.6.0 (2026-10-27) フルChangelog

注目すべき変更点

  • CLI 一括 URL 監査: CLI は、複数の URL 引数を渡すか、--url-file (最初の失敗時に中止する --fail-fast を使用) を介して、単一のコマンドで複数の URL を順次監査することをサポートするようになりました (#17404)。同じホスト上のページ間の衝突を避けるために、デフォルトのレポート ファイル名に URL パス名 (<hostname>-<pathname>_<date>) が含まれるようになりました (#17405、#17423)。
  • ランタン シミュレーションの改善: trace_engine (0.0.66 および 0.0.67) がアップグレードされ、シミュレーションの精度を向上させるためにリクエスト/グラフ モデリングが更新されました (#17307、#17379):
    • ネットワークとプロトコル モデリング: HTTP/3 接続を多重化として扱い、シミュレーション ステップ全体で消費された H2 オーバーフロー バイトをクレジットし、アクティブな接続数からコネクションレス リクエストを除外し、オリジン RTT/スループットの推定とリダイレクト処理を改善しました (#17415)。
    • 依存関係グラフとメトリクス: v8.compileModule および v8.evaluateModule トレース イベント属性を追加し、レンダリング ブロッキング優先度にプロトコル renderBlocking ステータスを使用 (#16869)、テキスト LCP が FCP と同じフレームで発生する場合に FCP グラフを使用し、シミュレートされた LCP ブレークダウン計算 (#17269) とトレースモード ナビゲーション/URL 処理を修正しました。 (#17431、#17433)。
  • エージェント リソース ディスカバリ (ARD) v0.91: ard-schema 監査およびギャザラーを ARD v0.91 仕様 (ai-catalog.json の代わりに ard.json) に更新し、Link HTTP ヘッダー、<link rel="ard">、および /.well-known/ard.json による検出をサポートし、レガシー ai-catalog の場所に関する警告を表示し、レポート フッターに ARD 仕様のバージョンを表示します。 (#17258、#17259、#17260、#17448、#17452)。
  • パフォーマンス インサイト numericValue: パフォーマンス インサイト監査では、推定時間またはバイト節約 (#17346) から numericValue および numericUnit が設定され、トレースに複数のナビゲーションが含まれている場合に正しいナビゲーション (#17174) が選択されるようになりました。
  • メモリと収集の最適化: トレースのストリーミング (ReturnAsStream)、トレース イベントからのスクリプト ソースの再利用、speedline のデコードされたフレーム バッファの削除、中間ギャザラーとトレース エンジンの状態の解放 (#17286、#17289、#17290、 #17407)。
