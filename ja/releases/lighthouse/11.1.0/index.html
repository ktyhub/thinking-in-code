lighthouse v11.1.0

マイナー 公開日2023年9月7日 出典GoogleChrome/lighthouse 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#灯台v11.1.0 フルChangelog このリリースは、2 週間以内に Chrome 119 の DevTools および PageSpeed Insights にリリースされる予定です。

新しい貢献者

新しい寄稿者 👽🐷🐰🐯🐻 に感謝します!

  • トルティータス @TortitasT
  • イアン・キルパトリック @bfgeek
  • GLI @tobyglei

コア

  • TBT 節約を bootup-time に追加 (#15431)
  • パフォーマンス監査にガイダンス レベルを追加 (#15025)
  • サードパーティ監査に TBT の影響を追加 (#15385)
  • index.cjs タイプを修正 (#15387)
  • アセットセーバー: 新しい DevtoolsLog および Trace アーティファクトを使用します (#15345)
  • クロール可能なアンカー: 空の rawHref がクロール可能であるとみなします (#15406)
  • dom-size: TBT 節約を追加 (#15307)
  • image-aspect-ratio: アスペクト比のしきい値を緩める (#15328)
  • installable-manifest: 利用可能な更新のインストール可能性エラー (#15388)
  • biggest-contentful-paint-element: LCP の節約を追加 (#15178)
  • lcp-lazy-loaded: LCP 節約の見積もりを追加 (#15064)
  • main-resource: ページのリロード時のプロトコル エラーを修正 (#14520)
  • リダイレクト: 無駄なミリ秒のみのスコア (#15401)
  • timespan-runner: ナビゲーションが検出された場合に警告する (#15407)
  • viewport-meta: 初期スケール値の条件を含めます (#15394)

レポート

  • DevTools のカテゴリのハイライトを修正 (#15413)

デプス

  • third-party-web を 0.24.0 (#15354) にアップグレードします
  • axe-core を 4.8.0 (#15430) にアップグレードします
  • 人形遣いを 21.1.1 (#15403) にアップグレードします
  • 人形遣いを 20.0.3 (#15375) にアップグレード

Clients

  • 拡張機能: マニフェスト v3 の一部のプロパティを更新 (#15347)

I18n

  • インポート (#15443)

ドキュメント

  • devtools ビルドの説明を更新 (#15414)
  • Lighthouse を大規模に実行するためのガイドを追加 (#10511)
  • Readme: Chrome ランチャーのインポート例を修正 (#15428)
  • Readme: Lighthouse Metrics China をサービス リストに追加 (#15256)
  • リリース: 更新ケイデンス セクション (#15392)
  • リリース: 自動テストの対象となる命令を削除 (#15353)

テスト

  • テストモジュールのロードに失敗したときのエラー処理の改善 (#15421)
  • モック dt ログでハッシュを許可しない (#15363)
  • dbw: LCP ロードの開始/終了の上限を削除 (#15432)
  • dbw: LCP ロード開始/終了のしきい値を増加 (#15393)
  • 開発ツール: 同期 e2e (#15389)
  • スモーク: ToT のインストール可能性アイコンの更新エラー (#15422)
  • ユニット: 再試行失敗とアップロード失敗アーティファクト (#15378)

その他

  • root.js をshared/に移動 (#15439)
  • ツリーマップ、ビューアでの gtm のハングを避けるために URL ハッシュを削除 (#15425)
  • esm-utils.js をshared/に移動 (#15418)
  • dependabot.yml を正しいフォルダーに移動 (#15417)
  • dependabot.yml を追加 (#15341)
  • ビルド: ブラウザ拡張機能を縮小しません (#15381)
  • build: バンドルビルド時の出力ソースマップ (#15348)
  • readme: ノード バージョンのコールアウトに関するメモを使用します (#15410)
  • ツリーマップ: バイト値の粒度を下げる (#15415)
