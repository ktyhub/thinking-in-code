lighthouse v5.0.0

メジャー 公開日2019年5月8日 出典GoogleChrome/lighthouse 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#灯台v5.0.0 #5.0.0 (2019-05-07) フルChangelog

主な新機能

  • スタック パック は、Lighthouse レポート内でスタック固有のアドバイスを表示する新しい方法です。この初期バージョンでは、サイトが WordPress で実行されているかどうかを検出し、WordPress プラグインと設定を利用してパフォーマンスを向上させる方法に関する追加情報をレポートに追加します (#7243、#8169、#8633、#8536、#8778)。
  • パフォーマンス バジェット は、時間の経過とともにサイトのパフォーマンスが低下するのを防ぐ Lighthouse の新機能です。ページがロードするリソースの予算を設定し、予算が満たされていない場合に Lighthouse アラートを発行します (#8539、#8522、#8727、#8709、#8427、#8708)。
  • Lighthouse プラグイン は、Lighthouse の実行にカスタム チェックを追加する新しい方法です。これらは、標準の結果と一緒に (またはその代わりに) Lighthouse レポートに表示され、Lighthouse 内のツールと結果を活用して仕事を完了できます。例についてはドキュメントを参照してください (#8728)。
  • すべてのスクリーンショットを見て気づいていない場合は、HTML レポートが 再設計されました!

新しい監査

  • apple-touch-icon PWA 監査 (#8857)
  • performance-budget (#8539)
  • resource-summary (#8522)
  • max-potential-fid (以前は JSON 出力にあり、HTML レポートに新規) (#8729、#8817)

<a name="breaking-changes-5.0">重大な変更</a>

  • ノード 10 (LTS) 以降が必要になりました (#8117) ※rawValueは監査結果から削除されました。監査で意味のある数値結果 (メトリックなど) があった場合、この結果は numericValue (#8343、#8385、#8421) に表示されます。
  • アクセシビリティ カテゴリのスコアは、重大度に基づいて再重み付けされました (#8823)
  • FCP の精度が向上し (「シミュレーション」スロットリングで)、スコアに顕著な影響を与える可能性があります (#7513)
  • 非推奨の --disable-device-emulation フラグは削除されました。 --emulated-form-factor (#8289、#8334) を使用します。
  • dom-size は <head> の要素を無視し、スコアリングを本体内の DOM ノードのみに制限するようになりました (#7241)
  • diagnostics 監査の詳細の type 値は debugdata (#8298) に変更されました。 ※screenshot-thumbnailsのスクリーンショットの形式が変更になりました。完全な画像データ URL (#8299) になりました。

新しい貢献者です!

最初の貢献をしてくれた @arnabsen、@housseindjirdeh、@MarkelFe、@muuvmuuv、および @Meggin に感謝します。
