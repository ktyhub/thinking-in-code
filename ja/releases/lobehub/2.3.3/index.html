#ローブハブv2.3.3

v2.3.3 をリリース

PR #22891 より: https://github.com/lobehub/lobehub/pull/22891

🚀 LobeHub リリース (20261112)

発売日: 2026 年 11 月 12 日
v2.3.2 以降: 253 のマージされた PR · 252 のコミット · 12 人の貢献者

チャットを実際のワークスペースに変えるのに 1 週間かかりました。独自の返信ルール、すべてのエージェントの受信トレイ ID、およびリポジトリから直接作成できるプロジェクトを備えたダイレクト チャネル。

✨ ハイライト

  • ダイレクト チャネル — すべてのエージェントとグループに IM スタイルの会話画面が用意されています。スタックされたヘッダー アバター、ヘッダーへの入力、+ メニューを備えたカード コンポーザー、日の区切り、リスト行での返信アクティビティなどです。 (#22559、#22583、#22556、#22440)
  • エージェントごとの応答戦略 - 各エージェントがいつウェイクアップするかを決定します。最初に独自のルールを作成し、フォローアップはサイレントのままにし、宛先のないメッセージには 1 人のプライマリ レスポンダを取得し、ランタイムはウェイクが発生した理由を記録します。 (#22551、#22454、#22847)
  • エージェント ID とメール - エージェントは、ID グループの下にアドレス、受信トレイ、プロファイル ページを取得します。 mail-waken 実行は、結論を所有者のチャネルに投稿し、自分のメールボックスのみを参照します。 (#22009、#22010、#22578、#22686)
  • GitHub のプロジェクト - リポジトリからプロジェクトを作成し、その作業場所を選択し、作業ディレクトリを編集または削除し、ピッカー、バッジ、およびグループ化を使用してタスクをプロジェクトにリンクします。 (#21552、#22612、#22725、#22383)
  • ナレッジ ベースの順序付け — 自然なプレフィックスの並べ替え、並べ替え制御、ドラッグ アンド ドロップによる並べ替えに加え、呼び出し元を対象としたビジネス ナレッジ アクセス シーム。 (#22866、#22863)
  • デスクトップがリモート端末を提供 — デスクトップ アプリは、リモート デバイスのローカル ファイル プレビューと並行して、Web およびモバイル clients にリモート端末を提供できるようになりました。 (#22852、#22647)
  • フラグの背後にある新しい表面 — ローブ ベンチ ワークスペース ページ (ベンチマーク、データセット、実験)、TRPC API を使用した会議データ モデル、およびバージョン管理されたスキル アーカイブ。 (#22483、#21259、#22590)

🏗️ チャンネルと会話

  • サイドバー チャネルは未読および @mention ハイライトで並べ替えられ、プロジェクトの一般チャネルが常に開きます。 (#22859、#22870)
  • スレッドはサイド パネルではなくページとして開きます。エンティティ リンクはフィードの横に表示され、承認レポートが開きます。 (#22850、#22584)
  • Composer はタグではなくテキストとしてハイライトをメンションし、フィードがフェードインする間、Composer の返信バーが柔らかくなります。 (#22846、#22839)
  • エージェント プロフィール カードは、メッセージ アバターにカーソルを合わせると表示され、イベント ラインに参加します。 (#22515、#22836)

🤖 エージェントのランタイムと ID

  • リレイヤード モデル ランタイム: ルーターは 1 つのライフサイクルを通じて実行を試行し、キャンセル時に停止します。並列ツール呼び出しの引数は独自の呼び出しに留まり、ストリーム中のソケット ドロップは ProviderStreamInterrupted として分類されます。 (#22819、#22718、#22827)
  • Anthropic コード、OpenAI および OpenAI 互換コードはプロトコルごとに編成され、共有ルーター ヘルパーが抽出されます。 (#22785、#22731、#22818)
  • ゲートウェイ ステップはサーバー時間順に並べられ、ロックが失われた後はステップ コミットが拒否され、バックグラウンド サブエージェントの結果が再度配信されます。 (#22842、#22524、#22530)
  • 禁止されたユーザーのメモリ作業は停止し、失敗した抽出はその本当の原因を記録し、長い統合マージは小さなバッチで実行されます。 (#22691、#22797、#22596)
  • クロード コード セッションはキューに入れられたフォローアップで操作でき、OpenCode 2.x がサポートされ、Copilot / Cursor ACP はデフォルトでフル アクセスで実行されます。 (#22575、#22740、#22574)

📱 プロジェクト、タスク、目標

  • 新しいプロジェクトはデフォルトで専用のメイン エージェントに設定され、サイドバーではプロジェクトがお気に入りと並べ替えを使用して 1 つのリンクに折りたたまれ、GitHub から作成することでそのエージェントを作成することもできます。 (#22401、#22320、#22696)
  • コード プロジェクトは、プロジェクト独自のリポジトリ内のサンドボックスで実行されます。 (#22761)
  • スケジュールされたタスクは正確な分を受け入れます。ワークスペース間のタスク リンクがサイド パネルで開きます。再配信された完了により、実行が一度解決されます。 (#22406、#22473、#22637)
  • 全体の目標修正: ゲート保持ラウンドはリリース待ちとして読み取られ、計画ターンのストールは終了し、ユーザーが送信したランには goal:manage が付与されます。 (#22750、#22760、#22726)

🖥️ デスクトップ & Clients

  • AppImage コア OTA は分離されたスポーンを通じて再起動され、タイトルバーはタブ ストリップ上でドラッグ可能な状態を維持し、開発インスタンスは分離されてラベルが付けられます。 (#22793、#22462、#22823)
  • タスク トピック ドロワー ヘッダーはドラッグ領域から離れ、サイドバー エージェント ヘッダーはホームの後にタブのエージェントに従います。 (#22831、#22825)
  • lh は、エージェント作成時に --visibility / --json、mcp エイリアス、コマンドを満たす、および目標の CLI 要件編集を取得します。 (#22801、#22626、#22593、#20568)

🔒 セキュリティと信頼性

  • セキュリティ: ワークフロー コールバックは、認証されていない場合にフェール クローズされるようになりました。メールが起動された実行は、その独自のメールボックスにスコープされます。 SWR キー レジストリが凍結されるため、新しいサーバー データはローカル レプリカにルーティングされます。 (#22864、#22686、#22727)
  • 信頼性: ページのコラボレーションにより、耐久性のあるルームを使用してページごとに 1 つの Yjs ツリーが維持されます。コンテキスト エンジンのスナップショットはプールされるため、長期実行トレースが二次関数的に増大することはなくなります。ファイル解析によってイベント ループがブロックされなくなりました。 (#22695、#22522、#22796)

🔧 ツーリングとメンテナンス

  • StyleX の移行は、移行された子孫ルールがどこに移動したかを示すスタイル等価性検証機能を使用して続行されます。 (#22041、#22658)
  • モジュール間のテスト統合、データベース カバレッジを 100% に戻し、デッド v8 フォールバックを削除しました。 (#22337、#22719、#21893)
  • new_tier_plans フラグ、未使用のエージェント ストリーム エンドポイント、および毎日の無料ビデオ クォータ ヒントを廃止しました。 (#22611、#22601、#22811)
