v2.3.4 をリリース

PR #23286 より: https://github.com/lobehub/lobehub/pull/23286

🚀 LobeHub リリース (20261118)

リリース日: 2026 年 11 月 18 日
v2.3.3 以降: 291 コミット · 291 マージ PR · 13 貢献者

この毎週のリリースは、チャネルをユーザーとエージェントが並行して作業する場所に変え、MCP コネクタを自分のデバイスで実行できるようにし、実行中のコーディング セッションの操作を容易にします。

✨ ハイライト

  • チャネル内のエージェント — エージェントは、お互いにメッセージを送信したり、リクエスタの担当者にメッセージを送信したり、その場またはスレッドで応答したり、@メンションされるまでミュートしたり、応答に失敗する代わりにオフライン デバイスを待機したりできます。 @メンションされたエージェントが 1 つのスレッドに集まり、作業を分担するようになりました。 (#23139、#23244、#22911、#23164、#23060、#23103、#23222)
  • デバイス上の MCP コネクタ - lh connect デバイス上で stdio およびローカル MCP コネクタを実行し、デバイス経由で HTTP MCP サーバーをルーティングし、Webhook イベントをサブスクライブし、OAuth コネクタごとに複数のアカウントを接続します。 (#23047、#23056、#23067、#22991、#22988)
  • Webhook と自動化 - CLI およびエージェント ツールから Webhook と自動化を管理し、それらのイベントをチャネルに配信します。 (#23266)
  • より良いコーディング エクスペリエンス ラボ - エージェントの実行中にフォローアップをキューまたは操作し、新しいトピックのブランチを選択し、送信時にワークツリーを切り替えまたはフォークし、複数のプル リクエストを 1 つのトピックに、それぞれがリンクされた理由とともにリンクします。アプリが作成したワークツリーは、トピックがアーカイブまたはゴミ箱に入れられるとクリーンアップされます。 (#23171、#23186、#23175、#23173、#23185、#23248、#23241)
  • 永続サンドボックス — 実行環境から永続サンドボックスを選択します。新しい会話では、各クラウド サンドボックスの最後のフォルダーとリポジトリが保持されます。 (#23126、#23122、#23212)
  • DingTalk および WeCom ボット - DingTalk を IM ボット チャネルとして接続し、ガイド付きセットアップを使用して長時間の接続で WeCom AI ボットを実行します。 (#22336、#22326、#23089)
  • 音声と音楽の生成 - イレブンラボ、Fish Audio、Doubao Speech、Gemini テキスト読み上げ機能に加え、プロバイダーに依存しない音楽生成とオーディオ ファイル プレビューを追加しました。 (#22168、#22951、#22977、#23000、#22918)
  • よりシンプルなコンポーザー — 送信/停止ボタンが 1 つ固定され、送信キーの選択が設定に移動されました。ファイルのアップロード中に送信すると、メッセージがキューに入れられます。貼り付けてアップロードした画像はアニメーション カードとして表示され、重複した貼り付けはスキップされ、引用された選択内容がメッセージ内に保持されます。 (#23261、#23095、#23098、#23080、#23096、#23111)

🏗️ コアエージェントとアーキテクチャ

エージェントのランタイム

  • エージェントは、長時間実行されるシェル コマンドをポーリングするのではなく保留し、未知のツール名が繰り返された後は正常に停止するようになりました。 (#22979、#23024)
  • 実行中のサブエージェントは、フォローアップで操作したり、キャンセルしたりできます。 (#22377、#22496)
  • エージェントは汎用 Webhook から起動できます。 (#23128)
  • ランタイム ステータスの読み取りでは完全な状態 BLOB が読み込まれなくなり、ツール セットのコピーはステップごとの状態から外れ、インライン ステップはトピックを 1 回読み取ります。 (#23210、#23170、#23144)
  • 手動圧縮ではトピック固定モデルが使用され、古いツール結果のトリムがウォーム ターン全体にわたって残ります。 (#22697、#22981)
  • 削除されたエージェントドキュメントはトピック履歴から送信されなくなりました。 (#23235)
  • 「停止」を押しても、中断したステップのメッセージが失われることがなくなりました。 (#23269)

目標とタスク

  • 目標は、実行間のマークと評価者が採点した目標をサポートし、完了した目標のレポートを共有できます。 (#23108、#22752)
  • [目標] ページを検索し、コマンド メニューから目標を見つけます。 (#23206)
  • Mod+F を使用して、[タスク] ページでビュー内を検索します。ファイルされていないタスク ツリーをプロジェクトに移動すると、そのサブタスクも移動します。 (#22960、#23214)

記憶と知識

  • メモリ抽出は、一時的なモデルの停止を再試行し、コンテキスト ウィンドウ内に留まり、廃止されたモデルからフォールバックします。 (#22894、#23088)
  • ナレッジアイテムは、コンテンツの読み取り時に強制されるアイテムごとのアクセス リストをサポートします。 (#22905)
  • アップロードされたファイルの解析とチャンク化は、メイン サーバーから分離して実行されるようになりました。 (#23117、#23260)

📱 チャネルと統合

  • 管理者は、ワークスペースが参加できるグループ チャネルを公開できます。プロジェクト チャネルは、最初にプロジェクト エージェントとともにプロジェクトに対して開かれます。 (#23110、#23107)
  • 会話を固定したり、自分のメッセージを編集したり、長い直接返信をスレッドに移動したりできます。グループでは、エージェントはリクエストの下で長い返信のスレッドを開き、その中で確認応答します。 (#23161、#23155、#23074、#23268)
  • スレッドのプレビューは、ルート メッセージの下とチャネル リストに表示されます。 (#22914、#23204)
  • 送信したメッセージは未読としてカウントされなくなります。 (#23263)
  • QQ グループの @メンションが LobeHub に到達し、ウィンドウで返信が得られるようになりました。 (#22921)
  • 遅延ボット メッセージはループ内で再生されなくなり、WeCom はゲートウェイの再起動中に到着した応答を保持します。 (#23147、#23092)

🖥️ デスクトップとユーザー エクスペリエンス

  • デスクトップ: 診断バンドルをエクスポートし、クエリ CLI を使用して構造化ログを書き込み、マシンをプライベート ワークスペース デバイスとして登録します。 (#22966、#22873、#22826)
  • デスクトップ: Cmd/Ctrl+Shift+T で閉じたタブを再度開き、Cmd+1 ～ 9 でタブを切り替えます。最近のページには、各ページのタイトルが表示されます。 (#23224、#23223)
  • デスクトップ: 段階的なコア OTA アップデートが、「最新」をレポートする代わりに表示されるようになりました。 (#23018)
  • サイドバー: ドラッグすると、チームと個人のピンを並べ替えたり、エージェント グループを非表示にしたり、コンパクトなお気に入り行でタスクのステータスを確認したりできます。 Cli されたトピックのタイトルはホバー時にスクロールし、トピックをダブル cli クリックしても新しいタブは開かなくなりました。 (#23048、#23072、#23203、#23062、#23076)
  • 作業サイドバー: 概要には、Claude Code のバックグラウンド タスクが表示されます。 (#23198)
  • プロジェクト: フォルダー カード ビュー、[設定] → [環境] による統合プロジェクト環境、および各新しいプロジェクト専用のメイン エージェント。 (#22860、#23150、#23129)
  • スキル: ライブラリ スキルはエージェントごとにオプトインされており、コネクタとスキル カタログには新しいレイアウトがあります。 (#23188、#23187)
  • エージェント プロファイル: ナビゲーションと指示の編集が簡単になりました。 (#23275)
  • エージェント共有: 訪問者は共有エージェントの実行環境を使用できます。 (#23240)
  • サブスクリプション: 使用量と残高が 1 つの設定ページに統合され、ベーシック プランが利用可能です。個人設定には、サブスクリプション アカウントがワークスペース タブとプライベート タブに分かれてリストされるようになりました。 (#22985、#23090、#23270、#23250、#23242、#23245)
  • 設定: データのエクスポートはバックグラウンドで実行され、ファイルの準備ができたら通知されます。 (#23125)
  • メンバーとエージェントのホバー カードがアプリ全体に表示されるようになりました。 (#22970、#23054)
  • 長時間のワークフローを開いたときやストリーミング中にも応答性が維持されます。 (#23176)
  • 回答された質問カードは正しくクリアされ、アバターは非正方形の画像を引き伸ばすのではなく切り抜きます。 (#23063、#23064)

🔧 ツーリング & CLI

  • lh agent list --tag、lh agent create --tag、エージェント転送およびグループ移動コマンド。 (#23016、#23012、#22923)
  • lh acceptance delete は受け入れシェルを削除します。 (#23081)
  • CLI からのライブラリのアップロードは、同じアカウントの資格情報を使用して回復されます。 (#23259)
  • Antigravity はローカル エージェントとしてサポートされており、DeepSeek ハーネス モデルは ACP 経由で検出されます。 (#22008、#22542)
  • フォローアップでは、接続されたデバイス上でネイティブ Codex が実行されるようになり、Codex の警告はツール呼び出しとして保存されなくなりました。モデルの週次クォータは、そのモデルが選択されている場合にのみ表示されます。 (#23264、#23252、#23071)
  • 固定プライベート ワークスペース エージェントの所有者は、それを自分のプライベート デバイスに切り替えることができます。 (#23230)
  • GPT-6.1 Terra モデル カードと Gemini 4 Hydrogen の xhigh 思考を追加しました。 (#22805、#22933)

🔒 セキュリティと信頼性

  • セキュリティ: サーバー側の HTTP MCP リクエストは、SSRF 安全なフェッチを通過します。 (#23050)
  • セキュリティ: アップロードには予約によるアップロード セッションが必要になりました。 (#20524)
  • セキュリティ: GitHub 資格情報は、異種エージェントのデバイスに送信されなくなりました。 (#23225)
  • 信頼性: 予期されるエラー条件は、500 として表示されるのではなく、4xx またはフォールバックを返します。 (#23058)
  • 信頼性: 拒否された非同期タスクは、JWT の有効期限とイメージ タイプのガードにより正常に失敗します。 (#23135)

⚙️ アップグレードに関する注意事項

  • このリリースには、連絡先、受信 Webhook、コネクタの可視性、チャネル スレッド ロック、受け入れレビュー ラウンド、アートボード テーブルのデータベース移行が含まれています。 (#23045、#22990、#22996、#23143、#22833、#22772) セルフホスト展開では起動時にそれらが適用されます。アップグレードする前にデータベースをバックアップしてください。
  • im_layout レール レイアウトとレガシー プラグイン CLI の作成/インストール サブコマンドは削除されました。 (#23084、#22372)
