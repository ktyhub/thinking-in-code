opentelemetry-java v1.67.0

マイナー 公開日2026年10月9日 出典open-telemetry/opentelemetry-java 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

opentelemetry-java v1.67.0

API

  • TextMapGetter.keys() を非推奨にし、TextMapGetter を機能インターフェイスにします (#8531)
  • トレース、バゲッジ、属性、ロギング、およびメトリクス用の null ガードと API 使用状況ロギングを追加 (#8803、#8863、#8864)
  • W3C tracestate (#8817、#8914) を解析する際の割り当ての制限と正規表現のバックトラックの回避

孵化中

  • 型イントロスペクション メソッドを DeclarativeConfigProperties に追加 (#8883)

拡張機能

  • トレース プロパゲータ: イェーガー バゲージおよび B3 シングルヘッダー伝播を解析するときのバインドされた割り当て (#8817)

SDK

  • デッドロックを回避するために、内部ロックの外側で CompletableResultCode 完了アクションを実行します (#8773)
  • 属性の上書きを削除された属性としてカウントしません (#8833)
  • グロブ マッチングでの正規表現のバックトラッキングを回避します (#8909)
  • 実験的なリソース エンティティのサポート、OTLP エクスポート、otel.entities および宣言型リソース ディテクタによる構成を追加 (#8464)

トレース

  • スパンプロセッサが設定されていない場合に noop トレーサを返す (#8815)
  • SimpleSpanProcessor および MultiSpanExporter で Throwable をキャッチ (#8848)
  • スパンプロセッサーの自己観測性メトリックには {span} ユニットを使用します (#8873)

メトリクス

  • PeriodicMetricReaderBuilder.setMaxExportBatchSize(int) (#8829) を安定化させます
  • 試験的なメトリック属性/バゲッジ処理を削除 (#8818)
  • 修正: リザーバー セルがスパンの外側で上書きされた場合、模範スパン コンテキストをリセット (#8871)

ログ

  • ログ レコード プロセッサが構成されていない場合、SdkLoggerProvider.get() から noop ロガーを返します (#8838)
  • SimpleLogRecordProcessor および MultiLogRecordExporter で Throwable をキャッチ (#8848)

プロフィール

  • パブリック KeyValueAndUnitData インターフェイスを返すように KeyValueAndUnitData.create() を修正 (#8875)

輸出業者

  • OTLP: 欠落しているリクエスト サイズ制限を修正し、デフォルトは 64 MiB で、setMaxRequestBodySize(long) および setMaxRequestMessageSize(long)、および宣言的構成 OtlpGrpcExporter、OtlpHttpExporter を通じて構成可能 (完全なスキーマ ドキュメントは こちら を参照) (#8446)
  • OTLP: シャットダウン後の障害ログを FINE に削減 (#8819)
  • OTLP: トレーラー ヘッダーの応答ステータス コードに基づいて gRPC を再試行します (#8854)
  • Prometheus: ユニットの注釈を削除するときに正規表現のバックトラックを回避します (#8910)

拡張機能

  • 自動構成: ServiceInstanceIdResourceProvider を安定させ、デフォルトで service.instance.id を生成します (#8770)
  • 自動構成: リソース属性をデコードするときに、エンコードされていない非 ASCII 文字を保持します (#8893)
  • 自動構成: experimental-otlp/stdout スパンおよびメトリック エクスポーターに不足していたアーティファクト ヒントを追加 (#8897)
  • 宣言型構成: スキーマ v1.2.0 に更新し、always_record サンプラー (#8801) をサポートします。
  • 宣言型構成: null 値を持つリソース属性を無視します (#8889)
  • 宣言型構成: rule_based サンプラーで配列属性を要素ごとに一致させる (#8895)
  • Yetager リモート サンプラー: シャットダウン後の障害ログを FINE に削減 (#8819)
  • Jaeger リモート サンプラー: レート制限がゼロの場合、オペレーションごとのサンプリング戦略を保持します (#8888)
  • インキュベーター: OnEndSpanProcessor.create() を公開 (#8892)
  • Incubator: ComposableProbabilitySampler の説明内のクラス名を修正 (#8891)

テスト

  • 間違った値またはタイプを報告するアサーション失敗メッセージを修正 (#8872)

シム

  • OpenCensus: スパンの変換時に W3C マルチテナント tracestate キーをスキップする (#8810)
  • OpenTracing: SpanBuilderShim の親コンテキストにバゲッジを伝播する (#8812)

プロジェクトのツール

  • Kotlin 拡張機能: Kotlin の最小バージョンを 2.2 に引き上げます (#8804)
