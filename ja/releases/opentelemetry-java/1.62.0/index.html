opentelemetry-java v1.62.0

opentelemetry-java v1.62.0

API

コンテキスト

  • GHSA-rcgg-9c38-7xpx を修正: W3CBaggagePropagator、OtTracePropagator、JaegerPropagator の手荷物エントリーに制限を適用 (#8378)

SDK

トレース

  • 一般的なケースでは、スパン開始時の parentContext 割り当てを回避します (#8332)

メトリクス

  • setMaxExportBatchSize を PeriodicMetricReaderBuilder に追加 (#8296)
  • 最後のフラッシュをドロップする可能性がある PeriodicMetricReader シャットダウン レースを修正 (#8299)

輸出業者

  • 重大 Prometheus: デフォルトのサーバー ホストを 0.0.0.0 から localhost に変更します (#8298)
  • 速報 Prometheus: ユニット "1" から "ratio" への変換を停止します (#8252)
  • OTLP: StringEncoder での null 入力処理を修正 (#8312)
  • OTLP: マーシャラーでプロト フィールド タイプとワイヤー タグ名を調整 (#8293)
  • OTLP: MarshalerUtil sizeRepeatedString の計算を修正 (#8284)
  • OTLP: 無制限のスレッド作成を防ぐための、JdkHttpSender スレッド プール サイズの制限 (#8276)
  • OTLP プロファイル: プロファイル データ モデルを個別の sdk-profiles および JFR シム モジュールに分割します (#8207)
  • OTLP プロファイル: opentelemetry-sdk-profiles および opentelemetry-exporter-otlp-profiles のアルファ リリースを公開 (#8351)

拡張機能

  • 速報 宣言型構成: 新しいパッケージ io.opentelemetry.sdk.autoconfigure.declarativeconfig (#8265) を使用して新しい opentelemetry-sdk-extension-declarative-config アーティファクトに抽出します
  • 自動構成: int への安全でないキャストを回避するために、OtlpConfigUtil にファイル サイズ検証を追加 (#8287)
  • 宣言型構成: コレクション フィールドがデフォルトで空に初期化されないように修正 (#8356)
  • インキュベーター: ログベースのイベントを複数のイベントにブリッジするために EventToSpanEventBridge を追加 (#8372)

テスト

  • OpenTelemetryAssertions の equalTo 値引数に @Nullable を追加 (#8301)
  • あいまい値一致のために hasValueSatisfying を LongPointAssert および DoublePointAssert に追加 (#8328)
  • 合計、ゲージ、ヒストグラム、指数ヒストグラム、および要約データに対する「指定された各アサーションは少なくとも 1 つのポイントによって満たされる必要があり、追加は許可される」チェックのためのメトリック データ アサートに containsPointsSatisfying を追加 (#8329)

プロジェクトのツール

  • 初期 OSGi サポートを追加 (#7964)
  • ApiUsageLogger を opentelemetry-common パブリック API (#8318) に昇格
  • 例外ログのガイドラインを確立し、エクスポーターと SDK (#8231) 全体で一貫性のないパターンを修正しました。
  • japicmp との互換性を持つ内部コードに *.impl.* パッケージ命名規則を追加 (#8325)
  • ビルドに Sonatype 依存関係監査を追加 (#8365)
