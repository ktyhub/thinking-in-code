opentelemetry-java v1.63.0

マイナー 公開日2026年6月5日 出典open-telemetry/opentelemetry-java 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

opentelemetry-java v1.63.0

API

  • 欠落していた setAttribute ショートカットを Span および LogRecordBuilder に追加 (#8255)
  • InstrumentationUtil を io.opentelemetry.api.impl パッケージのパブリック クラスに昇格 (#8413)
  • StrictContextStorage の範囲外のインデックスを修正 (#8294)

孵化中

  • 速報 非推奨の ExtendedAttributes および関連コード (#8395) を削除します。

SDK

メトリクス

  • エグザンプラ フィルタが always_on (#8363) の場合に非同期エグザンプラを収集します
  • デルタレコード/収集コーディネーションを機器からシリーズレベルに移動 (#8313)

輸出業者

  • noop() ファクトリ メソッドを SpanExporter および LogRecordExporter に追加 (#8435)
  • 速報 OTLP: 非推奨の GrpcSenderProvider および HttpSenderProvider SPI プロパティ名のサポートを削除 (代わりに io.opentelemetry.sdk.common.export.GrpcSenderProvider / io.opentelemetry.sdk.common.export.HttpSenderProvider を使用) (#8392)
  • OTLP: バインドされた OkHttp 送信側ディスパッチャと表面拒否 (#8422)
  • Prometheus: Prometheus の制限に準拠するようにサンプル ラベル文字を制限します (#8362)
  • ロギング: フラッシュの失敗を保存するために LoggingSpanExporter.flush() を修正 (#8361)
  • Zipkin: 共有の内部コードの依存関係を削除してエクスポーターを自己完結型にします (#8413)

拡張機能

  • 速報 自動構成: 非推奨の otel.experimental.config.file プロパティを削除 (#8393)
  • 速報 インキュベーター: 非推奨の ViewConfig/ViewConfigCustomizer ビュー ファイル構成メカニズムを削除 (#8394)
  • 宣言型構成: モデル パッケージを修正 (#8403)
  • 宣言型構成: Java モジュール名を io.opentelemetry.sdk.autoconfigure.declarativeconfig (#8452) に修正

シム

  • OpenTracing シムのパブリック API (#8373) を廃止

プロジェクトのツール

  • すべてのモジュールにわたる OSGi サポートの追加を完了 (#8401、#8417)
  • 問題のある gson バージョンを回避するために io.zipkin.zipkin2:zipkin:3.6.1 を強制します (#8430)
