opentelemetry-java v1.64.0

マイナー 公開日2026年7月10日 出典open-telemetry/opentelemetry-java 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

opentelemetry-java v1.64.0

API

  • W3C 仕様に従って空の手荷物値を許可するように W3CBaggagePropagator を修正 (#8468)
  • 無効なパーセントでエンコードされたメンバーのバゲッジ解析を修正 (#8480)

孵化中

  • 速報 非推奨の InstrumentationConfigUtil.peerServiceMapping (#8542) を削除します
  • キャリアエントリを列挙または正規化しないように EnvironmentGetter/EnvironmentSetter を修正し、空の名前を一貫して正規化します (#8474、#8481)

SDK

トレース

  • SimpleSpanProcessor.create(SpanExporter) をミラーリングするために BatchSpanProcessor.create(SpanExporter) コンビニエンス ファクトリを追加 (#8564)
  • BatchSpanProcessor ベンチマーク補助カウンター (exportedSpans/droppedSpans) が常にゼロを報告する問題を修正 (#8539)

メトリクス

  • forEach 中にエントリが削除されたときにライブ エントリを削除する PooledHashMap を修正 (#8499)
  • FixedSizeExemplarReservoir の模範リザーバー ストレージを安全に初期化 (#8524)
  • エクスポーターがビジー状態の場合は、PeriodicMetricReader で failExceptionally を使用します (#8525)
  • false の場合のみ AggregatorHandle に valuesRecorded を設定します (#8559)
  • Double/LongLastValueAggregator のアトミックの代わりに volatile を使用します (#8560)
  • 同時実行ホットスポットを回避するために、メトリック ベンチマークでスレッドごとの記録順序をランダム化します (#8550)

ログ

  • ランタイム以外の例外によって強制終了される BatchLogRecordProcessor ワーカー スレッドを修正 (#8529)

輸出業者

  • 速報 Prometheus: 非推奨の PrometheusMetricReader コンストラクターを削除 (#8541)
  • OTLP: EndpointUtil.validateEndpoint でホストレス エンドポイントを拒否 (#8489)
  • OTLP: Jackson OTLP JSON シリアル化を手動実装に置き換えます (#8545)
  • OTLP プロファイル: OtlpGrpcProfileExporter toString クラス名を修正 (#8492)
  • Prometheus: 変換戦略のサポートを追加 (#8346)
  • Prometheus: 配列値スコープとリソース属性の JSON 文字列へのシリアル化を修正 (#8497)

拡張機能

  • 速報 宣言型構成: 実験的なタイプを内部パッケージに移動 (#8530)
  • 宣言型構成: 生成されたスキーマ POJO を git にコミット (#8408)
  • 宣言型構成: opentelemetry-configuration v1.1.0 (#8451) に更新
  • 宣言型構成: AutoValue セマンティクスに一致するように POJO toString/hashCode/equals を調整します (#8526)
  • 宣言型構成: 生成されたモデル クラスに参照記述を追加 (#8540)
  • 宣言型構成: 生成されたモデルで一貫した @JsonProperty アノテーションを出力 (#8563)
  • 宣言型構成: DeclarativeConfigPropertyUtil の重複したリゾルバーを削除 (#8579)

プロジェクトのツール

  • 構成ポリシーのガイダンスを追加 (#8429)
  • 特定の GitHub アクションをフォークでの実行から除外 (#8466)
  • パラメーター化されたテストを優先するためのガイダンスを追加 (#8469)
  • ベンチマーク パスを構成可能にする (#8557)
