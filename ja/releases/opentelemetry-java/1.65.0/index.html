opentelemetry-java v1.65.0

マイナー 公開日2026年8月7日 出典open-telemetry/opentelemetry-java 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

opentelemetry-java v1.65.0

注: opentelemetry-exporter-zipkin アーティファクトは公開を停止しました。以前のリリースでは非推奨になりました。ユーザーは OTLP に移行するか、Zipkin 互換のコレクター エクスポーターを使用する必要があります。

API

  • ImmutableBaggage.put の空の荷物キーを無視する (#8658)
  • 手荷物デコーダーで NumberFormatException を使用します (#8593)
  • 同じキーが 2 回削除されるとビルダーが破損する TraceStateBuilder.remove を修正 (#8613)

孵化中

  • バインドされたインストゥルメント API (BoundLongCounter、BoundDoubleCounter、BoundLongHistogram、BoundDoubleHistogram、BoundLongUpDownCounter、BoundDoubleUpDownCounter、BoundLongGauge、BoundDoubleGauge) をインキュベーター メトリクス API (#8527) に追加します。

拡張機能

  • トレース プロパゲータ: JaegerPropagator バゲージ ヘッダーのキーケースの感度を修正 (#8496)
  • トレース プロパゲーター: JaegerPropagator (#8632) 内の空のバゲージで既存のバゲッジを上書きしないでください。
  • トレース プロパゲータ: OtTracePropagator 抽出で空のバゲージ キーをスキップ (#8631)
  • トレース プロパゲーター: 不正な形式のトークンを含む 64 個のトークンの後で jaeger-baggage ヘッダーの解析を停止します (#8702)

SDK

  • SDK 属性の実装 (AttributesMap) を更新し、AttributeKey.getKey() の文字列値に基づいて最後の値優先セマンティクスを適用します (#8548)

トレース

  • Sampler シャットダウン ライフサイクルの追加: Sampler は Closeable を拡張し、SdkTracerProvider のシャットダウン時に呼び出されるデフォルトの shutdown() を公開します。 JaegerRemoteSampler は、ポーリング エグゼキューターを停止するためにこれを実装します (#8574)

メトリクス

  • 内部テレメトリ バージョンによるゲート PeriodicMetricReader 自己観測性メトリクス (#8597)
  • 失敗したコレクションの error.type を PeriodicMetricReader に記録します (#8650)
  • テスト: 属性の正確な一致を強制するように LongExemplarAssert.hasFilteredAttributesSatisfyingExactly を修正 (#8518)

ログ

  • レコードのタイムスタンプを返す ReadWriteLogRecord のデフォルト getObservedTimestampEpochNanos を修正 (#8504)

プロフィール

  • プロファイル データ モデル属性カウント パラメーター名とタイムスタンプ ドキュメント ユニットを修正 (#8514)

輸出業者

  • 警告 Zipkin: opentelemetry-exporter-zipkin を削除します。アーティファクトは公開されなくなりました (#8677)
  • OTLP: HttpExporter 警告ログで HTTP エラー応答本文を使用する (#8428)
  • OTLP: プラットフォームのデフォルトの trust ストアを使用する場合の OkHttpHttpSender mTLS を修正 (#8565)
  • OTLP: 低割り当てログ マーシャラーの LogRecord フラグの符号拡張を修正 (#8493)
  • OTLP: エグゼキューター/チャネルの終了を待機するための OkHttpHttpSender、JdkHttpSender、および UpstreamGrpcSender のシャットダウンを標準化 (#8495、#8627、#8624)
  • OTLP: gRPC 応答フレームが無効な場合に、基礎となる例外/イオンをログに記録します (#8626)
  • OTLP: Android で安全でない文字列エンコーダーを回避する (#8637)
  • Prometheus: 衝突する Prometheus ラベル値をマージ (#8364)
  • Prometheus: 設定済みのデフォルト ハンドラーを削除する PrometheusHttpServer.toBuilder() を修正 (#8619)
  • ロギング: SystemOutLogRecordExporter にイベント名を出力 (#8609)
  • ロギング: LoggingMetricExporter toString に集約の一時性を含めます (#8623)

拡張機能

  • 自動構成: エラー メッセージで構成値を公開しないようにします (#8669)
  • 宣言型構成: Jaeger サンプラーのポーリング間隔構成を修正 (#8668)
  • 宣言型構成: DeclarativeConfigPropertyUtil 内の重複した getStringList リゾルバーを削除 (#8572)
  • 宣言型構成: jsonschema2pojo を手動の POJO ジェネレーター (#8600) に置き換えます。
  • インキュベーター: コンポジット サンプラー コードと仕様間の準拠を復元 (#8450)

シム

  • 非推奨 OpenCensus シムのパブリック API (#8674) を非推奨にします
  • OpenCensus: OpenTelemetry に変換するときに OpenCensus ステータスの説明を保持 (#8511)
  • OpenCensus: 警告を記録して削除する代わりに、OpenTelemetry スパンへのリンクを追加します (#8635)
  • OpenTracing: キャリアにスパン コンテキストがない場合、TracerShim 抽出から null を返します (#8505)
  • OpenTracing: 抽出された SpanContext がサンプリングされたが無効な場合は、抽出された SpanContext を返します (#8634)

プロジェクトのツール

  • version.gradle.kts の japicmp ベースラインを固定 (#8591)
  • フィードバックに応じて貢献ガイドを更新 (#8655)
