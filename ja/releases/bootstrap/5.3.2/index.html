bootstrap v5.3.2

パッチ 公開日2023年9月14日 出典twbs/bootstrap 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

ブートストラップ v5.3.2

ハイライト

  • Dart Sass v1.65.0 以降、パーセント単位をグローバル abs() に渡すことは非推奨になりました。その結果、Dart Sass で Bootstrap をコンパイルするときに非推奨の警告が表示されました。この問題は、divide() 関数に渡される値を変更することで内部的に修正されました。 divide() 関数自体は修正されていないため、ノード間の相互互換性のサポートを継続できます。 v6 では、node-sass のサポートを終了する予定であるため、これは問題になりません。
  • 折りたたみターゲットで複数の id を使用すると機能しなくなり、修正されました。

カラーモード

  • ライトモードとダークモードでのフォーム範囲トラックの背景の色のコントラストが増加しました。
  • カラー コントラストを高めるために、ダーク モードのストライプ テーブルに重点を置いたカラー モードのテーブル状態のレンダリングを修正しました。
  • カラー モードの <mark> カラー カスタマイズを許可します。

ドキュメント

  • [はじめに -> ダウンロード] (https://getbootstrap.com/docs/5.3/getting-started/download/#alternative-cdns) に代替 CDN セクションを追加しました。
  • README と はじめに -> はじめに に Discord と Bootstrap のサブレディット リンクを追加しました。
    • Discord コミュニティによって管理されています
