  • 🔓 デフォルトではサブエージェント制限はありません。 管理者設定および「SUBAGENTS_MAX_CONCURRENT」、「SUBAGENTS_MAX_ASYNC」、「SUBAGENTS_MAX_ITERATIONS」および「SUBAGENTS_MAX_OUTPUT」によるサブエージェント制限はデフォルトで制限なしになり、1 つを空のままにすると制限なしを意味します。デフォルトでは一度に 20、バックグラウンドで 20、それぞれ 30 のツール ループと 30000 文字の出力。 コミット
  • 🧠 コンテキストの圧縮とプロンプトのキャッシュ 同じモデルが会話とその圧縮の概要を処理する場合、対象となるリクエストは会話のプロンプト構造を再利用するようになり、プロバイダーがそのプロンプト キャッシュを使用できるようになります。これにより、長い会話やエージェントのワークフローを要約するコストを削減できます。他のリクエストは別の要約パスを保持します。 コミット
  • 💻 デスクトップ 0.1.x アップグレードの変更点。 Open WebUI デスクトップでは、リモート サーバー間の切り替え、Open Terminal のバンドル、古い Spotlight およびグローバル音声オーバーレイの提供がなくなりました。既存のリモート接続ユーザーは、Open WebUI Tether を確認してください。上で説明した Open Terminal の [デスクトップ] タブと [ブラウザ] タブは、個別に構成された Open Terminal 接続を使用します。 デスクトップ 0.1.0 release notes
  • 📭 ファイル処理アラートが削除されました。 [設定] > [通知] の個人通知に「コンテンツの取得プロセスが失敗しました」が表示されなくなり、ファイルの処理が失敗したときに通知 Webhook がアラートを受信しなくなります。 コミット
