open-webui v0.10.2

パッチ 公開日2026年7月1日 出典open-webui/open-webui 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

オープンウェブイ v0.10.2

追加

  • 💭 ストリームされた推論表示。 思考や推論を出力するモデルは、そのコンテンツをストリーミングとして表示し、チャットの概要やエクスポートされた会話で正しくレンダリングされます。 コミット、コミット、コミット、コミット
  • 🗂️ ナレッジ ベースへのフォルダーのアップロード。 フォルダーをナレッジ ベースにドラッグするかフォルダーを同期すると、すべてを個別のファイルにフラット化するのではなく、サブフォルダー構造が再作成されるようになりました。 #26130、コミット
  • 🧠 メモリ システム コンテキストの切り替え 管理者は、管理設定の新しい「メモリ システム コンテキスト」切り替えを使用して、保存されたメモリをシステム コンテキストに追加しないことを選択しながら、メモリ ツールを利用可能な状態にしておくことができるようになりました。 コミット
  • 🧹 整理された自動記憶。 自動的に保存される記憶は、好みや目標などの永続的な詳細に焦点を当て、覚えておきたいと頼まない限り、食事、日常的な出来事、一時的な気分などの 1 回限りのことはスキップします。 コミット
  • 🎙️ Speech-to-Text リクエスト形式 OpenAI 互換の Speech-to-Text は、管理音声設定で選択可能なマルチパート アップロードまたは Base64 JSON として音声を送信できるようになりました。 コミット
  • 🧰 環境経由の API 構成。 管理者は、「OLLAMA_API_CONFIGS」および「OPENAI_API_CONFIGS」環境変数を使用して、接続ごとの Ollama および OpenAI API 構成を設定できるようになりました。 コミット
  • 📡 プロバイダー障害イベント。 失敗した Ollama および OpenAI 互換プロバイダー リクエストは、エラー タイプ、プロバイダー、ステータスを説明する構造化イベントを発行するようになり、管理者は上流の障害をより明確に把握できるようになります。 コミット
  • 🏟️ 環境を介したアリーナ モデル 管理者は、「EVALUATION_ARENA_MODELS」環境変数を介して評価アリーナ モデルを定義できるようになりました。 #26174
  • ♿ ハイ コントラストのサイドバーの選択がより明確になりました。 ハイ コントラスト モードを有効にすると、サイドバーで現在選択されているチャットがより強い色で目立ち、どのチャットがアクティブであるかを簡単に区別できるようになります。 #26469、コミット
  • 🔄 全般的な改善。 パフォーマンス、安定性、セキュリティを強化するために、アプリケーション全体にさまざまな改善が実装されました。
  • 🌐 翻訳の更新。 タイ語、ポルトガル語 (ブラジル)、カタロニア語、スペイン語の翻訳が強化および拡張されました。

修正済み

  • 🛡️ セキュリティ勧告: このリリースには、セキュリティとアクセス制御の修正が含まれています。実稼働環境をできるだけ早く更新することをお勧めします。このバージョンのすべてのセキュリティ修正が修正セクションに列挙されているわけではありません。管理者にアップグレードする時間を与えるために、一部は短期間保留される場合があります。 アドバイザリー
  • 🔐 予期しないログアウトが減少しました。 アプリがログインにリダイレクトする前にセッション ステータスを確認するようになったため、セッションがまだ有効である間、承認エラーを返す 1 つのリクエストでサインアウトすることがなくなりました。 コミット
  • 🔒 Web 検索ドメイン フィルタリング。 Web 検索結果のドメイン許可ルールとブロック ルールがホストと照合されるようになり、一部の URL がフィルタをすり抜ける可能性があるギャップがなくなりました。 コミット
  • 🕵️ 画像プロンプト ログのプライバシー 画像生成ワークフローはデフォルトのログ レベルでサーバー ログに書き込まれなくなり、ユーザーが作成したプロンプト コンテンツがオペレーターに表示されるログから除外されます。 #26400、コミット
  • 🗄️ より安全なデータベース アップグレード。 既存の SQLite データベースをアップグレードしても、ユーザー テーブルの移行中にクラッシュしたり、保存されたユーザー設定が破損したりすることがなくなり、アップグレード後に起動をブロックしたりログインを中断したりする可能性のある障害が解決されました。 #26403、コミット
  • ⚙️ 非管理者として設定を保存 管理者以外のユーザーは、インターフェイスが誤って成功を報告した際にサーバー エラーで失敗したデフォルトのモデルやテーマなどのインターフェイス設定を再度保存できます。 #26627、コミット
  • 🕒 サイドバー チャットのタイムスタンプ。 サイドバーのチャットには、作成日ではなく最後にアクティブだった時間が表示されるようになりました。そのため、タイム ラベルはリスト内のチャットの位置と一致し、新しいメッセージが表示されるたびに更新されます。 #26454、#26451
  • 🎯 更新後のデフォルト モデル。 モデルの選択はモデル リストの読み込みが完了するまで待機するようになったため、ページを再読み込みしても選択したモデルはクリアされなくなりました。 コミット
  • ⏳ ツール ダイアログがハングしなくなりました。 cli を外に出してツールまたは関数の入力ダイアログを閉じると、チャットが無期限に回転したままになるのではなく、保留中のリクエストがキャンセルされるようになりました。 #26417、コミット
  • 🐍 信頼性の高いコード実行の読み込み。 チャットで Python コードを実行すると、ランタイムが確実に読み込まれるようになり、最近のリリースでコードの実行と Pyodide ファイル ビューアを中断するサンドボックスの起動エラーが修正されました。 #26625、#26390
  • 🤖 null 機能を持つモデル。 メモリ機能または自動化が関係している場合、機能が設定されていないモデルとのチャットがエラーで失敗しなくなりました。 #26412、コミット、コミット
  • 🔎 検索可能な応答。 チャット検索により、以前はスキップされていたテキストが構造化出力として保存されているアシスタント メッセージが再び検索されます。 #26405
  • 🔔 チャット通知プレビュー バックグラウンド チャット完了通知とトーストでは、構造化出力として保存されたメッセージが空白で表示されるのではなく、クリーンな応答プレビューが表示されるようになりました。 コミット
  • 💾 バナーと構成の起動。 管理構成値がデータ型に関係なく正しく保存されるようになったため、「WEBUI_BANNERS」などの構成を設定しても起動エラーが発生しなくなりました。 #26431、コミット
  • 📑 RAG テンプレートの表示。 RAG テンプレート エディターは、埋め込みと取得のバイパスが有効になっている場合でも、管理ドキュメント設定に表示されたままになります。これは、そのモードでもテンプレートがドキュメント コンテンツに適用されるためです。 #26126、コミット
  • 🧬 派生モデルの編集 ワークスペース モデルを編集しても、そのベースがプリセットまたはモデル自体である場合を含め、そのベース モデルはクリアされなくなりました。 コミット、コミット
