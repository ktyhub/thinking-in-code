open-webui v0.12.2

パッチ 公開日2026年10月14日 出典open-webui/open-webui 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

オープンウェブイ v0.12.2

追加

  • 📑 MinerU 4.x サーバー MinerU ドキュメント エンジンは、セルフホスト型 MinerU 4.x サーバーで動作するようになりました。4.x では古い解析インターフェイスが削除されたため、すべてのドキュメントが 404 で失敗しました。 3.x サーバーは以前と同様に動作しますが、4.x サーバーは階層 (フラッシュ、ベーシック、スタンダード、またはアドバンスト) を取得し、MinerU パラメーターの enable_ocr を使用しますが、言語とモデルバージョンは 3.x のみとなり、ドキュメント テキスト内で 4.x が返す画像はインデックス付きコンテンツから除外されます。 #32422、コミット、#31516
  • 🤝 比較するときに両方の変更を保持します。 リビジョン比較ビューには、選択した変更の元のテキストと提案されたテキストを提案されたリビジョンに (オリジナルを最初に) 配置する両方を保持するボタンが追加されました。そのため、どちらかの側を選択する必要がなくなりました。 コミット
  • 📚 添付されたナレッジをプレビューから開きます。 Cli添付されたナレッジ コレクションのプレビューで名前を選択すると、ワークスペースでそのコレクションが開き、ファイル名とリンク名は新しいタブで開く実際のリンクになります。 コミット
  • 🏷️ カスタム ヘッダーのモデル ID。 接続およびツール サーバーのカスタム ヘッダーで、チャット リクエストを処理するモデルの ID、ワークスペース モデルのワークスペース モデル独自の ID、およびマルチモデル チャット内の各モデル独自の ID を保持する {{MODEL_ID}} を使用できるようになりました。そのため、ダウンストリーム サービスはモデルごとに使用状況をルーティングまたはログ記録できます。 #32426、コミット、#30006
  • 🧾 監査ログ内のリクエストされたモデル。 OpenAI、Ollama、Anthropic 互換エンドポイントを含む、チャットおよび完了リクエストの監査ログ エントリには、client が AUDIT_LOG_LEVEL ごとに要求したモデルを含む model_id フィールドが含まれるようになりました。モデルはリクエスト本文にのみ表示され、MAX_BODY_LOG_SIZE が長いプロンプトをカットしたときに失われます。他のリクエストでは null としてログに記録されます。 #32429、コミット、#30097
  • 🔐 Milvus 用のカスタム TLS 証明書。 Open WebUI は、通常モードおよびマルチテナント モードで、証明書ファイルに新しい「MILVUS_SERVER_PEM_PATH」環境変数を指定することで、自己署名または会社発行の TLS 証明書を使用して Milvus サーバーに接続できるようになりました。 #32427、コミット、#31632
  • 🧭 ツール検索用の call_tool。 ツール検索がオンになっていると、モデルは新しい call_tool ツールを取得し、厳密なプロバイダーが拒否した、リクエストのツール リストにない名前で遅延ツールを直接呼び出すのではなく、search_tools で見つけたツールをそのツールを通じて実行し、ツールの名前とその引数を渡します。承認やその他のツールの動作は変わりません。 コミット、#32243
  • 🔄 全般的な改善。 パフォーマンス、安定性、セキュリティを強化するために、アプリケーション全体にさまざまな改善が実装されました。

修正済み

  • 🔏 チャネル メッセージのメタデータはサーバー側に保持されました。 API を通じて投稿または編集されたチャネル メッセージはリクエストからメタデータを取得しなくなりました。そのため、ユーザーはメッセージがチャネル Webhook またはモデルから送信されたように見せることができなくなりました。 #32421、コミット
  • 👮 SCIM は管理者を削除できません。 ID プロバイダーは、SCIM 削除リクエストを通じて最初の管理者を含む管理者アカウントを削除できなくなりました。SCIM 削除リクエストは 403 で応答し、アカウントをそのまま残すようになりました。そのため、割り当てられていないユーザーを削除する同期は、管理者なしでインスタンスを離れることができなくなりました。管理者は管理パネルで削除されます。 #32415、コミット、#27662
  • 🗝️ コレクション名が保存済みとしてチェックされるようになりました。 取得アクセス チェックでは、ベクター ストアが解決する方法でコレクション名を比較するようになり、大文字と小文字は無視され、ハイフンとアンダースコアも同様に扱われるため、別の方法で書かれた名前は、その後読み取られるコレクション以外のものとしてチェックを通過できなくなります。 #32435、コミット
  • 📱 Android Chrome での音声。 Android Chrome での音声通話とディクテーションは、約 10 回使用してもページがリロードされるまで音声が聞こえなくなったり、ハングアップしたりすることがなくなりました。これは、マイク レベルの表示がターンごとに音声出力を解放するようになったためです。 #32417、コミット、#29969
  • 🖥️ チャット ターミナル ファイルごとのアクション。 オープン ターミナル チャット コンテキストをチャットごとに設定すると、HTML ファイルを開く、ノートブックを実行する、編集したファイルを保存する、新しいファイルを作成する、選択した複数のファイルを削除する、フォルダーまたは選択内容を zip としてダウンロードするときに、チャット独自のワークスペースが使用されるようになりました。このワークスペースでは、HTML ファイルには「ファイルが見つかりません」と表示され、保存されたファイルはチャットに表示されませんでした。 #32418、コミット、#29965
  • 🧮 メモリ再インデックスのレート制限。 管理者の [ナレッジとメモリ ベクトルの再インデックス] ボタンからのメモリの再インデックスは、ユーザーがメモリ ベクトルをリセットするか、埋め込みモデルの変更後に自動再インデックスを設定することで、埋め込み同時リクエストの制限とバッチ サイズに従います。これにより、メモリごとに 1 つのリクエストが一度に送信され、レート制限されたプロバイダはそのほとんどが 429 エラーで失敗しました。 #32420、コミット、#32212
  • ⏰ オートメーションの実行結果。 オートメーションの実行は、返信が完了した後でのみ成功として記録されるようになり、失敗またはキャンセルされた返信はチャットにリンクするエラーとして記録され、返信が開始されるとすぐに実行が成功としてカウントされます。 コミット
  • 📜 ロング ポーリングは監査ログから除外されます。 WebSocket サポートがオフになっていると、すべての Socket.io ロング ポーリング リクエストが独自のエントリとして監査ログに書き込まれなくなります。監査ログが溢れ、AUDIT_EXCLUDED_PATHS でフィルタリングできなかったため、監査ログはどちらのトランスポートでも同じように見えます。 #32425、コミット、#31871
  • 📎 承認されたツールのソース ツール承認を質問に設定すると、ユーザーが承認したナレッジ ツールまたはファイル ツールが保存され、承認後に失われたソースが返信の下に表示されるようになりました。 #32439、コミット、#32436
  • 🗂️ サイドバーのホバー プレビュー あるサイドバー フォルダーから次のサイドバー フォルダーにポインターを移動しても、最初のフォルダーのプレビューが開いたままになったり、次のフォルダーが開かなくなったりすることがなくなり、ポインターが名前の周囲のパディング上にあるときにもフォルダーとチャットのプレビューが開くようになりました。 #32438、コミット、#32437

変更されました

  • 🔖 Open WebUI としてタグ付けされた Valkey 接続。 Open WebUI の Valkey ベクター ストア接続は、ライブラリ名を GlidePySync(open-webui) として報告するようになりました。そのため、共有 Valkey または ElastiCache のオペレーターは、そのトラフィックを区別できます。これには valkey-glide-sync 2.5.2 以降が必要なので、手動でインストールされた古いバージョンで VECTOR_DB=valkey を使用するインストールではアップグレードする必要があり、そうしないと起動に失敗します。 #32428、コミット、#31654
