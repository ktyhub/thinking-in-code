open-webui v0.12.3

オープンウェブイ v0.12.3

追加

  • 🔐 エンドツーエンドの暗号化チャット。 ダイレクト メッセージとプライベート グループ チャネルは、一時的なエンドツーエンドの暗号化チャットを保持できるようになりました。メンバーはチャンネル メニューで暗号化チャットを選択し、他のメンバーには参加リンクのある「暗号化チャットが進行中」が表示されます。最大 16 KiB のメッセージはブラウザーで MLS で暗号化され、保存されずにサーバーのみを通過します。参加者はコードを比較することで相互に確認し、他のユーザーが入力しているタイミングを確認できます。チャットは、退席またはリロードするとクリアされ、チャンネル メンバーシップまたはアクセスが変更されると終了します。管理者は、[管理設定] > [一般] > [暗号化チャネル] でこの機能をオンにするか、「ENABLE_ENCRYPTED_CHANNELS」を使用してこの機能をオンにし、新しい暗号化チャネル権限を付与します。デフォルトでオフにするか、「USER_PERMISSIONS_FEATURES_ENCRYPTED_CHANNELS」で設定します。また、WebSocket サーバーがログオフし、運用環境で HTTPS を使用した WebSocket 接続が必要です。 コミット、コミット、コミット、コミット
  • 📡 Redis によるはるかに軽量なストリーミング。 Redis では、更新のたびに応答全体を共有ハッシュに書き換えるのではなく、ストリーミング応答が独自のキーの下に保存され、新しいテキストが追加されます。また、古いインスタンスで開始された応答はアップグレード中にも読み取られます。ルーム チャネルがオンになっていると、各インスタンスは接続しているユーザーのルームのみをサブスクライブするようになり、Redis はサービスを提供しないチャットのライブ更新を送信しなくなります。 コミット コミット #32478
  • 🔍 ビュー オプションの比較と元に戻す リビジョン比較ビューには、空白を無視したり、強調マーカーを無視したり、未変更の行を折り畳んで変更のみを表示したりするための比較オプション メニュー、両方のペインでの編集内容を順番に戻す [元に戻す] ボタン、一致するテキストで整列された変更された行があります。 コミット、コミット、コミット、コミット
  • 📝 より豊富な Markdown ファイル プレビュー。 ターミナル ファイル ブラウザで開かれた Markdown ファイルは、チャット返信と同じレンダラーでレンダリングされるようになりました。これには、数式、脚注、強調表示されたコード ブロック、アラート、マーメイド ダイアグラム、Markdown と混合された HTML ブロックが含まれ、コンパクトなドキュメントとしてレイアウトされ、編集可能なファイル内のタスク リストのチェックボックスをオンにして、変更をファイルに保存できます。 コミット コミット コミット #32514
  • 👀 共有チャットのライブコラボレーター チャットの上部バーには、その時点で同じチャットを開いている他のユーザーの写真が最大 3 人まで表示され、残りはカウントされ、プロフィール カードを開くコラボレーター リストが表示されます。 コミット、コミット、コミット
  • ✏️ 返信を含む共有チャットでの編集と再生成。 返信を許可する共有フォルダーからのチャットでは、メッセージを編集できるユーザーがプロンプトを編集して新しいブランチを開始し、自分のメッセージに返信するだけでなく、任意の返信を再生成できるようになり、チャットを閲覧している他の人は選択したブランチに留まります。 コミット、コミット
  • 🗄️ フォルダー エディターでのフォルダー アクセス。 フォルダーの共有は、フォルダー メニューの [共有] 項目ではなく、[フォルダーの編集] ダイアログの [アクセス] ボタンを通じて行われるようになりました。共有モードは、誰かを追加する前に設定できます。また、サブフォルダーは、親フォルダーに付与されたアクセスが自分にも適用されることに注意します。 コミット、コミット
  • 🔎 ワークスペース検索 検索ウィンドウでは、チャット、あなたと共有されているフォルダー内のチャット、あなたと共有されているチャット、チャンネルとダイレクト メッセージ、メモが 1 か所で検索され、コンテンツ タイプ、フォルダーまたはチャンネル、何かがあなたによって作成されたかあなたと共有されたかどうかのフィルター、強調表示された一致、Ctrl/Cmd + Enter による各結果のプレビュー、リンクのコピー、一致するメッセージまでスクロールされたスレッドを開くチャンネル結果が検索されます。 コミット、コミット、コミット
  • 💭 ドキュメント プレビューのコメント ターミナルのファイル ブラウザーで開かれた Word、Excel、PowerPoint、および PDF ファイルにはコメントと返信が表示され、ドキュメント内の該当する場所にマークが付けられ、マーカーをホバーまたはタップして開くことができます。また、古い .xls スプレッドシートもプレビューできるようになりました。 コミット
  • 🧹 入力選択をクリアするショートカット。 チャット入力からのモデル オーバーライド、選択したツールとフィルター、Web 検索、画像生成、コード インタープリターの切り替えをクリアするショートカットは、[設定] > [ショートカット] で変更できるようになりましたが、デフォルトではエスケープのままです。 コミット
  • 🙋 ファイル ブラウザからファイルについて質問します。 ターミナルのファイル ブラウザで開いているファイル内のテキストを選択すると、「質問または編集…」ボックスが表示され、ファイルが添付され、選択内容が引用された状態でモデルにリクエストが送信されるため、モデルは同じターミナルでそのファイルに応答したり編集したりできます。未保存の編集は送信前に保存でき、応答の実行中に送信されたリクエストはキューで待機します。 コミット
  • ☁️ Google ドライブへのアクセスは、選択したファイルに限定されます。 Google ドライブ ピッカーは、ドライブ全体への読み取りアクセスではなく、ユーザーが選択したファイルへのアクセスのみを要求するようになりました。そのため、自己ホスト型インストールでは Google の制限された範囲の検証が必要なくなり、ユーザーには「Google はこのアプリを検証していません」という警告が表示されなくなりました。 #32531 コミット #29537
  • 📜 長いステータス行の全文。 関数によって送信されたトークン使用量の概要など、応答の上のステータス行を click して全文を表示できるようになり、複数のステータス行を含む履歴にすべてのエントリが完全に表示されます。 #32532 コミット #30056
  • 📏 スキルの読み取り制限。 管理者は、管理者設定 > 一般で、「スキルの読み取り制限」と「スキルのプレビューの長さ」、または「SKILL_CONTENT_MAX_CHARS」と「SKILL_PREVIEW_MAX_CHARS」環境変数 (デフォルトは 20000 と 5000) を使用して、モデルが一度に読み取るスキルの文字数と長い命令のプレビューの長さを設定できます。 コミット
  • 🔄 全般的な改善。 パフォーマンス、安定性、セキュリティを強化するために、アプリケーション全体にさまざまな改善が実装されました。
  • 🌐 翻訳の更新。 ポルトガル語 (ブラジル)、中国語 (繁体字)、アラビア語、ベンガル語、ヘブライ語、グルジア語、パンジャブ語、スロバキア語、セルビア語、ウルドゥー語、ウズベク語、ベトナム語の翻訳が強化および拡張されました。 #32440、#32482、#32501

修正済み

  • 🧾 監査ログ内の API キー ヘッダー リクエスト。 Anthropic SDK が送信する x-api-key ヘッダー内の API キーで認証されたリクエスト、または「CUSTOM_API_KEY_HEADER」が設定されたヘッダー内の API キーで認証されたリクエストは、キーの所有者の下で監査ログに表示されるようになり、間違ったキーによる失敗した試行はログに記録されません。これらのリクエストが監査ログから欠落している場合。 #32443、コミット
  • 📚 ナレッジ共有は名前変更後も維持されました。 共有ナレッジ ベースの名前または説明を編集する書き込みアクセス権を持つ共同作業者が、自分で設定できなかった共有 (パブリックなど) をオフにしなくなりました。 #32450、コミット、#32449
  • 🤝 プロンプトとツールの共有は保存されたままになります。 書き込みアクセス権を持つ共同作業者が共有プロンプトまたはツールを保存しても、それが全員に非公開になることはなくなりました。自分で設定できなかった共有は保持されるようになりました。 #32493、コミット、#32492
  • 📄 長いメモやチャットの PDF エクスポート。 長いメモやチャットは PDF としてダウンロードされるようになりました。Firefox では「キャンバスが最大サイズを超えています」というエラーが発生し、Chrome では黒い PDF が保存されました。 #32459、コミット、#18334、#26373、#19583
  • ⏩ 複数のモデルで応答を続行します。 応答を続行すると、click された応答が続行され、複数のモデルとのチャットで別のモデルの応答を拡張できます。 #32456、コミット、#32455
  • 🏷️ インポートされたチャットのタグ インポートされたチャットにはタグが表示され、そのタグがタグ候補に表示されます。アカウントに欠落しているタグはインポート時に作成されませんでした。 #32454、コミット、#32453
  • 🔖 アーカイブされたチャットのタグ。 チャットがすべてアーカイブされているタグをサイドバーで検索しても、タグは削除されなくなりました。チャットがアーカイブ解除されたときに元の名前は失われます。 #32452、コミット、#32451
  • ⌨️ チャンネルの入力メソッド 日本語、中国語、韓国語などの入力メソッドで入力中に Enter キーを押して単語を確定しても、単語が入力される前にチャンネル メッセージが送信およびクリアされなくなりました。 コミット
  • 🖱️ チャット退出後のスクロール エラー Notes を開く直前にチャットをスクロールしても、ブラウザ コンソールに TypeError が記録されなくなりました。 #32458、コミット、#32457
  • 📐 新しいチャットでの最初のターンの安定性 新しいチャットの最新のメッセージと返信は、チャットが保存されてメッセージ リストがリロードされたときに実際の高さを維持するようになり、最初のターンでビューがジャンプすることはなくなりました。 コミット
  • 💬 チャンネルでの送信 独自のチャンネル メッセージは、サーバーが確認したときに再描画されるのではなくその場に留まり、送信するとチャンネルが新しいメッセージまでスクロールします。ジャンプしたり、古いスクロール位置を保持したりすることができます。 コミット
  • 📂 新しいチャットのターミナル フォルダー。 新しいチャットでは、添付したファイルはターミナルのファイル ブラウザーで開いているフォルダーにアップロードされ、チャットが作成されるとファイル ブラウザーはそのフォルダーに残ります。アップロードはデフォルトのフォルダーに移動し、ブラウザーはそのフォルダーに戻ることができます。 コミット
  • 📁 共有フォルダーの設定とアクセス。 共有フォルダーのモデル、システム プロンプト、またはファイルを編集しても、その共有モードはリセットされなくなり、書き込みアクセスで共有されたフォルダー内のサブフォルダーは、読み取りアクセスで直接共有されている場合でも書き込み可能のままになります。 コミット、コミット
  • 🔑 client_secret_basic による OAuth トークンの更新。 「OAUTH_TOKEN_ENDPOINT_AUTH_METHOD」が client_secret_basic の場合、トークンの更新ではサインインと同様に Basic ヘッダーで client 資格情報が送信されるようになりました。Basic のみを受け入れるプロバイダーは更新を拒否し、Open WebUI がユーザーの資格情報を削除しました。 OAuth トークン。次回のサインインまでモデル接続とそれを使用するツール サーバーを切断します。 #32507、コミット、#32506
  • 🛠️ サインイン後の OAuth ツール モデルにデフォルトのツールがあり、?tools= でリンクするとリストされたツールがオンになる場合、OAuth MCP ツールはサインイン リダイレクト後にオンのままになるようになりました。 #32488、コミット、#32476
  • 🔤 管理者のデフォルト フォントは保持されます。 [設定の保存] > [インターフェイス] では、管理者のデフォルトのフォントと画像圧縮サイズが独自の設定として保存されなくなりました。そのため、後からこれらのデフォルトに変更を加えても、引き続き反映されます。 #32497、コミット、#32496
  • 🔊 ゆっくりとした音声で読み上げます。 音声エンジンが次の文を生成するのに現在の文の再生にかかる時間よりも時間がかかる場合でも、最初の文の後に読み上げが停止することがなくなりました。 #32484、コミット、#32446
  • 🖼️ チャット端末ごとのインライン HTML プレビュー オープン ターミナルのチャット コンテキストがチャットごとであり、「ファイルが見つかりません」と表示されている場合、返信のインライン HTML プレビューでチャット独自のターミナル ワークスペースでファイルが検索されるようになりました。 #32485、コミット、#32477
  • 🧵 チャネル スレッドでの返信。 あるチャネル スレッドで開始された返信は、開いた次のスレッドに引き継がれなくなり、メッセージが他のスレッドからのメッセージを引用する可能性があります。 #32490、コミット、#32489
  • 📑 スキャンされた PDF のプレビュー ナレッジ ベース ビューアーでテキスト レイヤーなしでスキャンされた PDF をプレビューしても、ページが上にスクロールしたり、ヘッダーやツールバーが届かなくなったりすることがなくなりました。 #32487、コミット、#32481
  • ↩️ 右から左へのリスト マークダウン リストの箇条書き、数字、タスクのチェックボックスが、返信やファイル プレビューの右から左へのテキストに対して正しい側に配置されるようになりました。 コミット、#32444
  • 🔁 複製された共有チャットでの再生成。 他の人の共有から複製またはフォークしたチャットで再生成が機能するようになりました。以前は「自分のメッセージのみを再生成できます」というエラーで失敗していました。 #32508、コミット、#32505
  • 🗑️ 共有チャットの返信者には削除が非表示になりました。 共有チャットで返信する人には、サーバーが拒否した「削除」ボタンが表示されなくなりました。これにより、削除された返信がリロード時に戻ってきます。 「ENABLE_ADMIN_CHAT_ACCESS」がオンの場合、削除するとチャットの所有者と管理者に表示されます。 #32480、コミット、#32479
  • 🎛️ モデルのデフォルト機能をオフにできます。 モデルは、管理者がモデルのデフォルトでオンにしたコード インタープリターなどのデフォルト機能をオフにできるようになりました。再度開いたときや新しいチャットでオンに戻りました。 #32500、コミット、#32498
  • 🧰 オンに戻った内蔵ツールはオンのままです。 モデルのデフォルトでオフになっているメモリなどの内蔵ツールは、モデルがオンに戻って保存された後もオンのままになります。 #32504、コミット、#32503
  • 🏠 ランディング ページ モードをチャットに設定して更新します。 ランディング ページ モードがチャットのときに新しいチャットを更新しても、メッセージ フィールドが非表示にならず、左上隅にモデル メニューが開きます。 #32510、コミット、#32509
  • 🗜️ ツール実行中の圧縮により、ソースが排除されます。 一連の長いツール呼び出し中のコンテキスト圧縮により、知識やファイルのコンテンツが追加されずに独自のメッセージが要約され、そのコンテンツは後でモデルに返されます。 コミット、#32491
  • 🧩 カスタム ツール パラメーターを備えた組み込みツール。 プロバイダーのネイティブ Web 検索を有効にするモデルなど、tools という名前のカスタム パラメーターを持つモデルは、組み込みツール、添付ツール、およびファイル コンテキストを保持し、カスタム ツールがそれらと一緒に送信されるようになりました。 #32530 コミット #32528
  • 🔌 ツール サーバーが停止後に戻ってきました。 Redis では、OpenAPI ツール サーバーからのツールは、サーバーに再びアクセスできるようになると戻ってくるようになりました。この場合、すべてのサーバーがダウンしている間に空のリストがキャッシュされたため、再起動するかツール サーバー設定に保存するまでツール サーバーが見つからなくなりました。 #32533 コミット #29573
  • 📥 PDF リンクはドキュメントとして読み取られます。 未知の clients をブロックするサイト (Wikimedia など) や arxiv.org/pdf/1706.03762 などの arXiv リンクからの PDF はドキュメント抽出に移行し、モデルは生の PDF バイトを取得します。 #32523 コミット #32524 コミット

変更されました

  • 🎯 モデル スキルが完全な命令をロードするようになりました。 スキル組み込みツールがオンになっていると、モデル エディターでモデルにアタッチされたスキル (新しいチャットごとに事前選択)、およびチャット入力メニューから選択されたスキルが各メッセージとともに完全な命令を送信するようになりました。ここでは、view_skill でロードするモデルの名前と説明のみがリストされていました。スキルを使用可能にするためだけにモデルにスキルをアタッチしたデプロイメントでは、ユーザーが読み取ることができるすべてのスキルがモデルにリストされるため、余分なプロンプトの長さを避けるためにモデルからスキルを削除する必要があります。 コミット
  • 📮 ルーム チャネルの Redis 権限。 「WEBSOCKET_REDIS_ROOM_CHANNELS」をオンにすると、Redis ユーザーには PUBLISH、SUBSCRIBE、UNSUBSCRIBE、PING 権限と、「&socketio」および「&socketio#*」チャネルへのアクセスが必要になりますが、PSUBSCRIBE は使用されなくなりました。不足している権限は、その修正方法とともにログに記録されます。 コミット
