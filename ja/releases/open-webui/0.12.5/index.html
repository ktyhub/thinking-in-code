オープンウェブイ v0.12.5

追加

  • 🧭 Analytics セッション エクスプローラー。 管理者は、「ENABLE_ADMIN_CHAT_ACCESS」がオンである限り、Admin Analytics で各チャットとそのトークン、応答、エラー、期間をリストし、検索、モデル、トークン範囲またはサブエージェントでフィルタリングし、チャットの保存された応答とツール呼び出しをそのタイミングと結果とともに表示する Admin Analytics の [セッション] タブを開くことができるようになりました。 コミット
  • 📑 ノートのページ ノートには複数のページとサブページを保持できるようになり、追加、名前変更、並べ替え、別のページの下への移動、ダウンロード、ページ タブからのリンク、削除が可能になり、検索結果とモデルがページごとにノートを操作できるようになりました。 コミット
  • 👀 メモ内のライブ プレゼンス。 メモには他に誰が開いているかが表示され、その人を cli クリックすると、その人が作業しているページとスポットにジャンプします。 コミット
  • ✏️ チャット メニューから名前を変更。 オープン チャットのタイトルの横のメニューに [名前変更] が追加されました。これにより、ページ上部のタイトルがテキスト ボックスに変わり、最初にサイドバーで名前を見つけなくてもチャットの名前を変更できます。 #33177、#33176、#33246、#33339、#33338、コミット、コミット
  • 🖼️ 端末で生成された画像。 チャットで端末が選択されると、生成および編集された画像もその作業フォルダーに保存されるようになりました。そのため、モデルは端末のツールを使用して画像の作業を続けることができます。 コミット
  • 🗃️ モデルはチャット ファイルを表示します。 モデルは、組み込みの display_file ツールを使用して、チャットに添付されたファイル、または添付されたナレッジ ベースに保存されているファイルを返信内で表示できるようになりました。これまではターミナル ファイルに対してのみ機能していました。 #32471、コミット、コミット
  • 💾 チャット モデルの選択が保存されました。 チャットでのモデルの変更はチャットとともにすぐに保存されるようになりました。そのため、変更後にメッセージが送信されなかった場合でも、チャットはそのモデルで再度開かれます。 コミット
  • ⌨️ 単一のショートカットの割り当てを解除します。 [設定] > [キーボード] では、割り当てられたすべてのショートカットの横に、そのショートカットのみの割り当てを解除する小さな x が表示されるようになりました。そのため、Ctrl+R または Cmd+R での応答の再生成などのショートカットをオフにして、他のすべてのショートカットが機能し続けるようにすることができます。 #33185、#31463、コミット
  • 🎚️ 数値バルブのスライダー プラグインの作成者は、数値バルブまたはユーザーバルブを、その横に数値ボックスが付いたスライダーとして表示できるようになりました。その端はフィールドの最小値と最大値から来ているため、ユーザーは値を選択するときに許容範囲を確認できます。 #33179、#32045、コミット
  • 📇 モデルのプロバイダーの詳細 モデルを編集する管理者には、入力と出力のタイプ、コンテキスト ウィンドウ、最大出力、およびプロバイダーがレポートするサポートされているパラメーターを含むプロバイダーの詳細セクションが表示されるようになりました。 コミット
  • 🧲 設定でのプレフィックスの埋め込み。 管理者は、一部の埋め込みモデルに必要なクエリおよびコンテンツ プレフィックスを、[管理設定] > [ドキュメント] で設定できるようになりました。これらのプレフィックスは、「RAG_EMBEDDING_QUERY_PREFIX」および「RAG_EMBEDDING_CONTENT_PREFIX」環境変数でのみ設定できました。 コミット
  • ⏱️ ターミナルの起動タイムアウト。 Open WebUI は、ターミナルにスキル、AGENTS.md ファイル、またはアップロードを要求するときに、デフォルトで最大 60 秒待機するようになりました。そのため、まだ起動中のターミナルは、制限を変更するための「AIOHTTP_CLIENT_TIMEOUT_TERMINAL」と、まだタイムアウトしている場合にターミナルを指定するメッセージで応答できます。 コミット
  • 🚨 オートメーションの失敗通知。 オートメーションの実行失敗は、ユーザーが [設定] > [通知] で通知ターゲットとして選択できるようになりました。これにより、所有者は失敗したすべての実行についてオートメーションの名前とエラーとともに通知されます。 #33331、#33228、コミット
  • ⚡ ナレッジ ベース コマンドの高速化。 ls、cat、grep などのナレッジ ベース コマンドとナレッジ ベースの同期チェックでは、すべてのファイルの全文をロードせずにファイルが一覧表示されるため、大規模なナレッジ ベースでは各呼び出しが最大 10 倍高速になり、使用するメモリが大幅に少なくなります。 #33332、#33322、コミット
  • 🔭 チャット検索の高速化 [参照チャット] メニューやモデルのチャット検索ツールを含むチャットの検索では、一致するすべてのチャットが完全に読み込まれることがなくなり、大規模なチャット履歴で結果がより速く返され、[参照チャット] メニューにカーソルを置くと結果のメッセージ プレビューが読み込まれるようになりました。 コミット
  • 📦 ドキュメントのバッチ埋め込み。 大きなドキュメントは、デフォルトで「RAG_EMBEDDING_BUFFER_SIZE」で設定された 1000 チャンクのバッチで埋め込まれ、保存されるようになりました。そのため、非常に大きなファイルを一度に処理する際に保持されるメモリの量ははるかに少なくなります。 コミット
  • 🧾 Mistral OCR モデルの選択。 管理者は、Mistral OCR モデルを選択し、[管理設定] > [ドキュメント] の [パラメーター] フィールドまたは「MISTRAL_OCR_PARAMS」を通じて追加の要求オプションを送信できるようになりました。たとえば、古い OCR モデルを使用し続けるか、Azure AI Foundry エンドポイントが期待するものと一致するようにすることができます。 #33333、#19707、コミット
  • 📉 負の関連性のしきい値。 [管理設定] > [ドキュメント] の関連性のしきい値は、ゼロ未満の未加工スコアを返すリランカーに対して負の値を取るようになりました。フィールドでは拒否され、負の "RAG_RELEVANCE_THRESHOLD" により、ハイブリッド検索がオンになっている間はページが保存されませんでした。 #33330、#29888、コミット
  • 🎞️ アニメーション化された ComfyUI 画像。 ComfyUI の [アニメーション化された WEBP を保存] および [アニメーション化された PNG を保存] ノードからの画像が、画像生成と画像編集の両方でアニメーション ファイルとしてチャットに表示されるようになりました。 #33325、#33013、コミット
  • 📡 メトリクスはヘルス チェックをスキップします。 OpenTelemetry メトリクスでは、URL が「OTEL_PYTHON_FASTAPI_EXCLUDED_URLS」または「OTEL_PYTHON_EXCLUDED_URLS」に一致するリクエストを除外するようになりました。そのため、ヘルス チェックとプローブは、トレースがすでにスキップしているのと同じように、リクエスト メトリクスを埋めることはなくなりました。 #33329、#31609、コミット
  • 🗝️ 管理者はユーザーの API キーを管理します。 管理者は、[ユーザーの編集] ダイアログでユーザーの API キーをローテーションまたは削除できるようになりました。ローテーションされたキーは 1 回表示されるため、コピーできます。 #32774、コミット、コミット
  • 👓 非表示可能なチャット コントロールが増えました。 管理者は、[管理者設定] > [インターフェイス] または [UI_VISIBILITY] の [表示] コントロールを使用して、チャット入力に表示される選択したツール、スキル、フィルター、Web 検索、画像生成、およびコード インタープリターを非表示にすることもできるようになりました。 #32408、コミット
  • ♿ UI アクセシビリティの向上 スクリーン リーダーとキーボードのユーザーは、各メッセージの名前を見出しとしてメッセージごとにチャット メッセージ内を移動し、矢印キー、ホームとエンドを使用してメニューとサブメニュー間を移動し、メモの [タイトルの生成] ボタンとマウスで開いたフィルター リストのオプションに到達し、Escape と Tab を使用してリビジョン エディターの比較を終了し、カレンダー イベント ウィンドウの各フィールド、ユーザーとフィードバックのテーブルの最後の列、および毎日の名前を聞くことができるようになりました。 [設定] > [使用状況] ヒートマップでは、モデル ピッカーのアウトラインは 1 行のみですが、ウィンドウ内で開いたときにキーボード フォーカスが取得され、ウィンドウを閉じるときにフォーカスがそのウィンドウ内に残ります。また、タブ行のフォーカス アウトラインが切り取られなくなりました。
  • 🔄 全般的な改善。 パフォーマンス、安定性、セキュリティを強化するために、アプリケーション全体にさまざまな改善が実装されました。
  • 🌐 翻訳の更新。 ポルトガル語 (ブラジル)、カタロニア語、イタリア語、アゼルバイジャン語、バスク語、ベンガル語、ボスニア語、ブルガリア語、セブアノ語、クロアチア語、チェコ語、デンマーク語、オランダ語、エストニア語、フェロー語、フィリピン語、ガリシア語、グルジア語、ドイツ語、ギリシャ語、ヘブライ語、ヒンディー語、ハンガリー語、インドネシア語、アイルランド語、日本語、カビル語、韓国語、ラトビア語、リトアニア語、マレー語、ノルウェー語ブークモール語、ペルシア語、ポーランド語、パンジャブ語、ルーマニア語、ロシア語、セルビア語、スロバキア語、スロベニア語、スペイン語（スペイン）、スウェーデン語、タミル語、タイ語、チベット語、トルコ語、トルクメン語、ウクライナ語、ウルドゥー語、ウイグル語、ベトナム語が強化および拡張されました。

  • 🛡️ セキュリティ勧告: このリリースには セキュリティ修正が含まれています。最新のセキュリティ修正を適用するには、できるだけ早くすべての展開を更新することを強くお勧めします。これらの修正は この changelog には記載されていません。 CVE の割り当て後すぐに、セキュリティ アドバイザリを公開します。 アドバイザリー

  • 📍 タイプ別に場所を検索します。 検索ウィンドウの場所フィルターには、チャットのフォルダーのみ、メッセージのチャネルのみがリストされるようになり、コンテンツ タイプを切り替えると、そのような選択で空のリストが返された適合しなくなった場所がクリアされます。 #33183、#33182、コミット
  • 🧮 ストリーミング トークン数のインフレ。 プロバイダーがすべてのストリーミング チャンクで使用量を再度報告するときに、応答のトークン数がインフレしなくなり、すべてのレポートが合計されるため、応答および管理分析に表示される使用量がプロバイダーの最終的なカウントと一致するようになりました。 #32052、#29064、#28528、コミット
  • 📝 書式設定後のメモの入力 メモのメニューで書式設定をオンまたはオフに切り替えた直後にメモの入力が機能するようになりました。ページがリロードされるまでエディターは入力の取得と保存を停止しました。 #33222、コミット
  • 🎙️ ノートの記録は保持されます。 ラップトップがスリープ状態になった場合など、文字起こし中に接続が切断された場合でも、ノートの記録はノートに残るようになりました。 #33240、コミット
  • 🀄 IME での Backspace 入力。 チャット入力で日本語またはその他の入力方法でテキストを作成中に Backspace キーを押しても、0.12.4 で始まったように、作成が終了したり、テキストが 2 回表示されたりすることがなくなりました。 #33245、#33223、コミット

  • 🔃 切断された返信は終了したままになります。 サーバーの再起動によって切断された返信は、後で接続が戻ったときに読み込みドットに戻らなくなりました。 #33277、コミット

  • 👁️ ビジョンがオフのツール画像。 ビジョンがオフのモデルでは、ツールが返す各画像の代わりに短い「[画像]」メモが表示されるようになりました。返信はエラーで失敗し、チャット内のその後のメッセージもすべて同じように失敗しました。 #33345、#32720、コミット

  • 📌 共有フォルダーにピンが保持される 共有フォルダーの所有者がチャットをそのフォルダー内の別のフォルダーに移動し、メンバーのピン留めリストから削除された場合でも、メンバーのチャットはそのピンを保持するようになりました。 #33342、#33341、コミット
  • 🌙 夜間のカレンダー イベント。 午後 8 時から午前 1 時など、真夜中を過ぎて終了するカレンダー イベントは、保存時にイベントが削除され、開始時刻に終了するように保存されていた終了時刻が翌日に保持されるようになりました。 #33290、#33289、コミット
  • 🗓️ 深夜のカレンダー イベント。 深夜に終了するカレンダー イベントは、月表示ではその日のみ表示されますが、翌日も表示されます。 #33292、#33291、コミット
  • 🪝 古い Webhook が削除可能。 v0.11 より前から引き継がれた通知 Webhook は、[設定] > [通知] から削除されたままになり、削除するとすぐに戻ってきました。 #33295、#33294、コミット
  • 🔔 新しいデフォルトの通知ターゲット。 最後の通知ターゲットを削除した後に追加された通知ターゲットが、デフォルトになりませんでした。 #33284、#33283、コミット
  • 🗣️ 翻訳された検索とスキル ラベル ワークスペース検索、スキル リスト、スキル エディター、ターミナル ファイル ブラウザーのラベルは、インターフェイス言語に従います。以前は、いくつかのラベルは常に英語で表示されていました。 #33308、#33304、#33305、コミット
  • 📜 キーボード タブのスクロール [設定] > [キーボード] タブをスクロールしても、[設定] ウィンドウ全体が移動しなくなりました。 #33187、#33186、コミット

変更されました

  • 🔀 モデルの切り替えにより選択内容が保持されます。 チャットでモデルを切り替えると、新しいモデルのデフォルトのツール、スキル、フィルター、機能が適用されるようになり、自分でオンまたはオフにしたものは維持されます。すべてのスイッチで選択がクリアされ、複数のモデルとのチャットでは、選択したすべてのモデルのデフォルトのツールとスキルが取得されるようになりました。 コミット、コミット
  • 📣 モデルのメンションによるチャットの切り替え @ で選択したモデルにメッセージを送信すると、チャットがそのモデルに切り替わります。メンションは入力の上に留まり、チャットは独自のモデルを保持します。 コミット
  • 🔁 再生成では現在のモデルが使用されます。 複数のモデルを使用したチャットでの応答の再生成では、その列で現在選択されているモデルが使用され、最初に応答を書き込んだモデルが再利用されます。 コミット
  • 📎 ページ内のノートの添付ファイル。 ノートに添付されたファイルは追加されたページ内に配置され、既存のノートの添付ファイルはノートの最初のページの末尾に移動します。 コミット
  • 📂 フォルダーを移動してもチャットの日付は維持されます。 チャットをフォルダーに移動したり、フォルダーから移動したりしても、最後のアクティビティの日付が保持されるようになりました。そのため、実際に最後にアクティブだった日、つまり「今日」の下のサイドバーの上部にジャンプした日によって並べ替えられたままになります。 #33327、#30362、コミット
  • 📮 オートメーション失敗 Webhook。 システム イベントのみに設定された管理イベント Webhook はオートメーション実行失敗を受信しなくなり、オートメーションの所有者を含む特定のユーザーまたはグループに設定された Webhook に送信されるようになりました。 #33331、コミット
  • 📃 ナレッジ ベース API の応答がトリミングされました。 ナレッジ ベース ファイルの追加、更新、または削除、および API を介したナレッジ ベースの名前変更または共有では、影響を受けるファイルまたは空のリストのみが返されるようになりました。そのため、ナレッジ ベースが大きくなってもこれらの呼び出しが遅くなることはなくなり、ページ分割されたファイル エンドポイントから完全なリストを利用できるようになります。 #33335、#31397、コミット
