cherry-studio v1.7.15

#チェリースタジオv1.7.15

何が変わったのか

  • ci(workflows): https://github.com/CherryHQ/cherry-studio/pull/12375 の @EurFelux によるワークフローの失敗に対する Feishu 通知を追加
  • fix(aiCore): https://github.com/CherryHQ/cherry-studio/pull/12387 の @DeJeune による openai 互換の SDK プロバイダーにのみ sendReasoning を適用します
  • 修正: https://github.com/CherryHQ/cherry-studio/pull/12391 の @defi-failure による claude-agent-sdk のパッチを復元
  • 修正: https://github.com/CherryHQ/cherry-studio/pull/12319 の @DeJeune によるエラーを防ぐために useAssistant とアシスタント スライスのトピックを正規化
  • fix(mcp): MCP 設定タイムアウト フィールドが https://github.com/CherryHQ/cherry-studio/pull/12384 の @Xtaiyang による文字列タイプをサポートしていない問題を修正
  • 修正(セキュリティ): DXT プラグイン システムのパス トラバーサルの脆弱性を防ぐ (https://github.com/CherryHQ/cherry-studio/pull/12377 の @kangfenmao による)
  • ci(ワークフロー): pnpm インストールを修正し、https://github.com/CherryHQ/cherry-studio/pull/12388 の @EurFelux による問題トラッカーを改善
  • feat/add-qwen-text-embeddings by @GeorgeDong32 (https://github.com/CherryHQ/cherry-studio/pull/12410)
  • 修正 (ロガー): https://github.com/CherryHQ/cherry-studio/pull/12406 の @0xfullex による不明なウィンドウ ソースでのロギングを許可
  • 功績: https://github.com/CherryHQ/cherry-studio/pull/12408 の @Copilot によるトピックのタイムスタンプに年を追加し、固定解除の UX を改善しました。
  • 修正: https://github.com/CherryHQ/cherry-studio/pull/12415 の @DeJeune による MCP ツールをサポートするために OpenRouter の厳密な JSON スキーマを無効にします
  • i18n: https://github.com/CherryHQ/cherry-studio/pull/12428 の @NicolaeFericitu によるルーマニア語 (ro-RO) ローカリゼーションの大幅な改善
  • fix(qwen-code): OpenAI 互換ツール用に BaseUrl を /v1 でフォーマット (https://github.com/CherryHQ/cherry-studio/pull/12418 の @GeorgeDong32 による)
  • https://github.com/CherryHQ/cherry-studio/pull/12419 の @flt6 による人為的キャッシュで Cumsum を使用する
  • 修正: https://github.com/CherryHQ/cherry-studio/pull/12430 の @DeJeune によるリクエスト本文フィールド名を変更
  • 修正 (aiCore): https://github.com/CherryHQ/cherry-studio/pull/12239 の @DeJeune による画像強化モデルの会話履歴を保存
  • 修正: https://github.com/CherryHQ/cherry-studio/pull/12455 内の @eeee0717 により小さい組み込み api キーを削除
  • 修正: Qwen ミニアプリで新しい URL に切り替える (https://github.com/CherryHQ/cherry-studio/pull/12460 の @Astricaelus による)
  • feat(i18n): https://github.com/CherryHQ/cherry-studio/pull/12438 の @NicolaeFericitu によるルーマニア語ローカリゼーション (ro-RO) の更新
  • フィート(Baichuan): @Pippobj による Baichuan-M3 モデルを https://github.com/CherryHQ/cherry-studio/pull/12478 に追加
  • 修正: https://github.com/CherryHQ/cherry-studio/pull/12492 での @DeJeune による画像生成のために、API URL の末尾のスラッシュを処理する
  • 特集: Git フック用の Husky から Prek への移行 (@DeJeune 著、https://github.com/CherryHQ/cherry-studio/pull/12491)
  • https://github.com/CherryHQ/cherry-studio/pull/12500 の @AdySnowflake による Azure OpenAI 完了モードの API プレビュー リンクを修正
  • 修正: https://github.com/CherryHQ/cherry-studio/pull/12513 の @Pleasurecruise による CLI ツール更新のバージョン チェック ロジック
  • 機能: Kimi CLI をコード ツールに統合 (https://github.com/CherryHQ/cherry-studio/pull/12511 の @xiaoju111a により)
  • リファクタリング: https://github.com/CherryHQ/cherry-studio/pull/12508 の @SherlockShemol により、ネストされたコンポーネントを設定ポップアップのレンダリング関数に変換します。
  • feat(i18n): https://github.com/CherryHQ/cherry-studio/pull/12471 の @NicolaeFericitu によるルーマニア語ローカリゼーション (ro-RO) の更新
  • 修正(ビルド): https://github.com/CherryHQ/cherry-studio/pull/12412 の @kangfenmao による Alpine サポートのための Linux musl ネイティブ依存関係を追加
  • リファクタリング ( ThinkingEffect ): https://github.com/CherryHQ/cherry-studio/pull/12536 の @SherlockShemol により useState + useEffect を useMemo に置き換えます
  • 修正 (コード ツール): カスタム プロバイダーをサポートし、https://github.com/CherryHQ/cherry-studio/pull/12504 の @GeorgeDong32 による Windows ターミナルの問題を修正
  • 機能 (メモ): Word へのエクスポート機能を追加 (https://github.com/CherryHQ/cherry-studio/pull/12393 の @DeJeune により)
  • 修正: https://github.com/CherryHQ/cherry-studio/pull/12550 の @DeJeune による無限の再レンダリングを防ぐためにプロバイダー セレクターをメモ化
  • 修正(Linux): https://github.com/CherryHQ/cherry-studio/pull/12503 の @beyondkmp による試行から clicked したときにメイン ウィンドウが前面に表示されない問題を修正
  • 機能: Linux システム タイトル バー設定オプションを追加 (@beyondkmp による https://github.com/CherryHQ/cherry-studio/pull/12040)
  • fix(header): https://github.com/CherryHQ/cherry-studio/pull/12549 の @DeJeune によるレンダラ プロセスの User-Agent 禁止ヘッダーを解決します
  • fix(linux): https://github.com/CherryHQ/cherry-studio/pull/12561 の @DeJeune によるアイコン表示と deb インストールの問題を修正
  • 機能: @pippobj による Baichuan-M3-Plus モデルを https://github.com/CherryHQ/cherry-studio/pull/12567 に追加
  • 機能 (プロバイダー設定): https://github.com/CherryHQ/cherry-studio/pull/12423 で @GeorgeDong32 による詳細なエラー メッセージの表示をサポート
  • 修正 (埋め込み): https://github.com/CherryHQ/cherry-studio/pull/12573 の @DeJeune による一時ドキュメント クエリのクエリ コンテンツを切り詰める
  • 機能 (i18n): https://github.com/CherryHQ/cherry-studio/pull/12547 に @DeJeune によるハードコードされた文字列検出スクリプトと CI チェックを追加
  • 機能 (minapps): https://github.com/CherryHQ/cherry-studio/pull/12572 の @DeJeune によるロケールベースのフィルタリングと i18n サポートを追加
  • リファクタリング: https://github.com/CherryHQ/cherry-studio/pull/12343 の @kangfenmao による二重言語セレクターを削除して翻訳アクションを簡素化
