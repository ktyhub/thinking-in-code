#チェリースタジオv1.7.18

何が変わったのか

  • ci: https://github.com/CherryHQ/cherry-studio/pull/12738 の @EurFelux によるメイン ブランチ プッシュで CI を実行します。
  • feat(code-tools): https://github.com/CherryHQ/cherry-studio/pull/12576 の @GeorgeDong32 による OpenCode CLI ツールのサポートを追加
  • 修正: https://github.com/CherryHQ/cherry-studio/pull/12744 の @kangfenmao による tsgo の BlobPart との Uint8Array 型の非互換性を解決
  • 修正: https://github.com/CherryHQ/cherry-studio/pull/12730 の @DeJeune によってアプリが Dock/Finder から起動されたときの npm 検出の問題を解決
  • 修正: Together と DashScope の推論コントロールを https://github.com/CherryHQ/cherry-studio/pull/12737 の @EurFelux によって改良しました
  • 修正: https://github.com/CherryHQ/cherry-studio/pull/12752 の @kangfenmao による UpdateAppButton の表示位置を調整
  • 修正: https://github.com/CherryHQ/cherry-studio/pull/12731 の @DeJeune による kimi-k2.5 モデルの温度と top_p を無効にしました
  • 機能: https://github.com/CherryHQ/cherry-studio/pull/12725 の @EurFelux により、エージェント ワークスペースに外部エディターで開くサポートを追加
  • 修正: WriteTool ストリーミングと React キーの重複 (https://github.com/CherryHQ/cherry-studio/pull/12750 の @DeJeune による)
  • 雑用: @kangfenmao による v1.7.17 を https://github.com/CherryHQ/cherry-studio/pull/12753 でリリース
  • 修正: https://github.com/CherryHQ/cherry-studio/pull/12762 の @eeee0717 による正しい openai 互換の strictJsonSchema パッチ
  • 修正: MCP ツールで二重引用符をエスケープし、https://github.com/CherryHQ/cherry-studio/pull/12773 で @EurFelux によるプロンプトの例を使用する
  • 功績: https://github.com/CherryHQ/cherry-studio/pull/12757 の @EurFelux による lint フィードバックを含む JSON カスタム パラメーターに CodeEditor を使用する
  • 修正: https://github.com/CherryHQ/cherry-studio/pull/12778 の @EurFelux によるストア サブスクリプションにウィンドウの存在チェックを追加
  • スタイル: https://github.com/CherryHQ/cherry-studio/pull/12759 の @EurFelux によるチャット コンポーネント レイアウト アニメーションを最適化します。
  • 功績: https://github.com/CherryHQ/cherry-studio/pull/12755 の @EurFelux によるコピー ボタンとホバー修正による OpenClaw インストール パス表示の改善
  • 修正: Gemini OpenAI 互換の思考シグネチャの処理と、https://github.com/CherryHQ/cherry-studio/pull/12769 の @EurFelux によるツールコール インデックスの欠落
  • 修正: https://github.com/CherryHQ/cherry-studio/pull/12787 の @EurFelux による CLAUDE.local.md をロードするために、settingSources に「local」を追加
  • 功績: @EurFelux による Claude Opus 4.6 モデルのサポートを https://github.com/CherryHQ/cherry-studio/pull/12777 に追加
  • 功績: https://github.com/CherryHQ/cherry-studio/pull/12656 の @felix-windsor によるマークダウン テーブルの Excel へのエクスポート ボタンを追加
  • 修正(エージェント): https://github.com/CherryHQ/cherry-studio/pull/12803 の @EurFelux によるクロード コード エージェントの言語命令を改善
  • 雑用: https://github.com/CherryHQ/cherry-studio/pull/12800 の @EurFelux によるビルドの問題を修正するために、tsdown を ^0.20.3 にアップグレードする
  • 修正: https://github.com/CherryHQ/cherry-studio/pull/12782 の @ChenYangBin666 により、AgentSessionInputbar モデルに不足していた機能フィールドを追加
  • perf: メインプロセスで未使用の Redux 状態キャッシュを削除 (https://github.com/CherryHQ/cherry-studio/pull/12790 の @kangfenmao により)
  • 修正(推論): https://github.com/CherryHQ/cherry-studio/pull/12823 の @GeorgeDong32 により、サポートされている推論モデルに qwen3-max を追加
  • リファクタリング: https://github.com/CherryHQ/cherry-studio/pull/12824 の @EurFelux による思考制御のための DeepSeek v3.1+ プロバイダーのホワイトリストを削除
  • リファクタリング: https://github.com/CherryHQ/cherry-studio/pull/12826 の @EurFelux による、InputbarCore での手動 Enter キーの改行挿入を削除
  • 修正: @uiw/codemirror-extensions-langs を 4.25.1 に固定して、https://github.com/CherryHQ/cherry-studio/pull/12829 の @EurFelux による運用ビルドを修正
  • 修正(エージェント): https://github.com/CherryHQ/cherry-studio/pull/12830 の @EurFelux によりバックアップの一貫性を保つために、agents.db を Data/ ディレクトリに移動
  • 修正: https://github.com/CherryHQ/cherry-studio/pull/12794 で @DeJeune によるエージェント メッセージを送信するときに一番下までスクロールする
  • https://github.com/CherryHQ/cherry-studio/pull/12797 に @DeJeune による OpenClaw インストール用の Git 可用性チェックを追加
  • 修正: https://github.com/CherryHQ/cherry-studio/pull/12793 の @DeJeune による Windows MAX_PATH エラーを防止
  • 功績: https://github.com/CherryHQ/cherry-studio/pull/12809 の @kangfenmao によるトークン使用状況追跡のための Analytics-client の統合
  • 功績: @cnJasonZ による PPIO ペイント モデルを https://github.com/CherryHQ/cherry-studio/pull/12520 に追加
  • リファクタリング: https://github.com/CherryHQ/cherry-studio/pull/12815 の @EurFelux によりファイル タイプの命名を改善し、明確さと一貫性を実現
  • fix(ci): https://github.com/CherryHQ/cherry-studio/pull/12847 の @EurFelux によって PR ベース ブランチが変更されたときに CI をトリガーする
  • 修正: Windows での実行可能ファイルの検出に更新されたシェル環境を使用 (https://github.com/CherryHQ/cherry-studio/pull/12853 の @DeJeune により)
  • 修正: https://github.com/CherryHQ/cherry-studio/pull/12844 の @EurFelux によるダーティ データ クラッシュを防ぐために、ブロック レベルの ErrorBoundary と防御セレクター チェックを追加しました。
  • 修正: https://github.com/CherryHQ/cherry-studio/pull/12849 の @DeJeune によるトピックの名前付けが失敗した場合、最初のメッセージ テキストにフォールバックする
  • 修正: PP-OCRv5 応答をサポートし、https://github.com/CherryHQ/cherry-studio/pull/12852 の @DeJeune による PaddleOCR プリプロセスで破損した PDF を処理する
  • 功績: Cherry Studio OpenClaw 設定を別のファイルに分離 (https://github.com/CherryHQ/cherry-studio/pull/12798 の @DeJeune 氏)
  • fix(codeblock): https://github.com/CherryHQ/cherry-studio/pull/12813 の @GeorgeDong32 による編集後に変更されたコンテンツをコピー
  • 修正(推論): https://github.com/CherryHQ/cherry-studio/pull/12833 の @DeJeune による推論検出のために Fireworks モデル ID を正規化
  • 修正: https://github.com/CherryHQ/cherry-studio/pull/12810 の @DeJeune により、PluginInstaller の .tmp+rename を削除することで Windows 上で EPERM を回避
  • 功績: @DeJeune によるエージェント ツール用の AskUserQuestion ツール レンダラーを https://github.com/CherryHQ/cherry-studio/pull/12467 に追加
  • 雑務: https://github.com/CherryHQ/cherry-studio/pull/12869 の @crazyrabbit0 によりノード v22 の .nvmrc と .node-version を追加
  • ci: https://github.com/CherryHQ/cherry-studio/pull/12876 の @kangfenmao によるリリース ブランチからの PR に基づいてリリース ビルドをトリガーします
  • ci: CI をマトリックスに分割し、https://github.com/CherryHQ/cherry-studio/pull/12864 の @GeorgeDong32 によって通知ジョブを追加します
  • リファクタリング: https://github.com/CherryHQ/cherry-studio/pull/12857 の @DeJeune によるプロセス生成用の統合シェル環境ユーティリティを抽出
  • 修正: チャット レイアウトのオーバーフローを修正し、https://github.com/CherryHQ/cherry-studio/pull/12879 の @EurFelux によるパネル アニメーションを簡素化しました。
  • feat(analytics): https://github.com/CherryHQ/cherry-studio/pull/12875 の @kangfenmao による非ストリーミング コンプリーションのトークン使用状況を追跡します。
