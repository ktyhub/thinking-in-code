<summary>Release Note</summary> Cherry Studio 2.1.3 - 新しい機能、パフォーマンス、信頼性 ✨ 新機能 - [リモート] デバイス接続: 互換性のあるモバイル client をペアリングしてプロバイダーをインポートし、暗号化された LAN 接続経由でデスクトップ エージェントを使用し、再接続の回復、実行の失敗、承認、および質問を行います。必要なアクション: 従来のデバイスは、新しい ID ベースのプロトコル用に再度ペアリングする必要があります。 - [ドキュメント] 従来の Open MinerU サーバーとの互換性を維持しながら、セルフホスト型 MinerU 4 ドキュメント解析をサポートします。 - [スクリーンショット] macOS および Windows でシステム OCR を使用して、ローカル モデルをダウンロードせずにスクリーンショット テキストを選択してコピーします。 - [モデル] Claude Opus 5.5 を API チャットに追加し、モデル制限、価格設定、推論制御、Web ツールの適格性を更新しました。 - [モデル] GPT-6 Sol および Luna カタログ メタデータ、OpenAI Web 検索資格、および OpenAI Codex モデル エントリを追加します。 - [モデル] xhigh 推論の取り組みにより、Grok 4.7 をモデル カタログ (xAI、OpenRouter、Vercel AI Gateway、OpenCode、Copilot) に追加します。 Grok CLI には、Grok 4.6、Grok 4.7、および Grok 4.7 Fast がリストされるようになりました。 Grok 4.6 は xhigh 推論努力を獲得します。 - [モデル] Xiaomi MiMo V2.6 Flash、Pro、Pro-UltraSpeed を MiMo、OpenRouter、Vercel AI Gateway、OpenCode プロバイダーのモデル カタログに追加し、思考のオン/オフ スイッチを追加します。 - [スキル] サポートされている正確なパスからインストールされたスキルに対して、保護された自動ファイル保存と手動リモート更新を追加します。 - [スキル] 専用のスキル詳細ページ、ソース ラベル、より安全な削除、およびエージェント セッションへの 1 つの click 起動を追加します。 - [設定] プリセット値とカスタム値を使用して「エージェントの返信言語」設定 (デフォルト: 会話言語に従う) を追加し、さらに有効な言語プレビューによるエージェントごとのオーバーライドを追加して、ユーザーがエージェントが返信する言語を固定できるようにします。 - [ショートカット] macOS では、Command+W でウィンドウの代わりにアクティブなタブを閉じるようになりました。ウィンドウを閉じる操作は Command+Shift+W に移動しました。 🐛 バグ修正 - [設定] リスト外からのプロバイダー モデル リストのスクロールを復元し、グループ見出しがページと一緒にスクロールできるようにします。 - [設定] 英語の検索語で V2 の会話スタイル設定が検索されるようになりました。 - [設定] モデルの追加後にプロバイダーを自動的に検証して有効にし、大きなリストの読み込み時にモデル選択ダイアログがジャンプするのを防ぎます。 - [プロキシ] IPv4 または IPv6 ループバック リクエストがプロキシ経由でルーティングされると、DeepSeek Harness などのローカル サービスが接続に失敗する問題を修正しました。 - [プロキシ] 企業プロキシの背後で失敗する、またはインターセプトされた TLS 証明書を使用してモデル リストの同期が失敗する問題を修正しました。以前は、プロバイダー自体がチャットで機能していても失敗していました。 - [プロキシ] ベア IPv6 リテラル (`::1`、`fe80::1`、`2001:db8::1`) として記述されたプロキシ バイパス ルールが一致しない問題を修正し、IPv6 アドレスを値で一致させるため、同等の表記が認識されます。 - [エージェント] セッション再利用制御とより明確な名前競合ガイダンスを使用して、スケジュールされたタスクを cron ツールを通じてその場で編集できるようになりました。 - [エージェント] バンドルされている Cherry ツール ガイドに、通知ツールがいつ利用可能になるか、およびスケジュールされたタスクが通知受信者を取得する方法が説明されるようになりました。 - [エージェント] 設定されたプロキシをエージェントのランタイム プロセスに継承することにより、プロキシ専用ネットワークで失敗する dsh タイプのエージェント セッションを修正しました。 - [エージェント] コンパクトなサブタスク リストと信頼性の高いネストされたタスク ナビゲーションにより、すべての作業が完了するまで複数のエージェントのリクエストを 1 つの応答にまとめます。 - [エージェント] 送信メッセージのリンク チップと Web サイトのホバー プレビューが、エージェントの会話のブラウザ ペインを使用する代わりに別のタブを開く問題を修正しました。 - [チャット] 長い推理コンテンツの思考パネルの高さ、スクロール、テキストの読みやすさを改善します。 - [チャット] 会話を切り替えるときに未送信の AskUserQuestion の回答を保持するため、保留中の質問に戻ると、ユーザーが中断したところから再開されます。 - [チャット] メッセージ更新後に一部のモデルでトークンの使用量が計算されない、または表示されない問題を修正しました。 - [チャット] マウスホイールで下にスクロールしたり、スクロールバーをドラッグした後、チャットメッセージが下部に留まらない問題を修正しました。 - [チャット] 入力項目 ID として UUID を送信し、ID が rs または msg で始まる必要があるために拒否される応答の継続を修正しました。 - [チャット] 移行されたマネージド イメージが依然として古いデータ ディレクトリを指している問題を修正しました。 - [スキル] 周囲のリポジトリアーカイブが古い共有上限を超えていたため、スキルの ZIP インポートが制限内のスキルを拒否する問題を修正しました。スキル パックには最大 20,000 個のファイルを保持できるようになりました。 - [スキル] ダウンロードサイズの制限が定義されていないため、ClawHub スキルのインストールが失敗する問題を修正しました。 - [スキル] Claude Plugins と skill.sh からのスキルのインストールでは、リポジトリ全体ではなくスキルのディレクトリのみがダウンロードされるようになり、GitHub リンクからのより大きなスキルのインストールがタイムアウトしなくなりました。 - [スキル] カードのサイズを維持しながら 2 列の設定レイアウトで名前の読みやすさを向上させ、ツールチップにフルネームと説明を表示します。 - [スキル] メッセージ編集中および編集キャンセル後のスラッシュコマンドとスキルメニューを修正しました。 - [スキル] 実際にインストールが実行されていないときに、CLI カードが「インストール中…」でスタックする問題を修正しました。ステータスは、残りのマーカーを trust するのではなく、ライブ操作と照合するようになりました。 - [スクリーンショット] 選択範囲がディスプレイの左端付近にある場合、スクリーンショット ツールバーの一部が画面からはみ出す問題を修正しました。 - [ファイル] 一時的な Windows ファイル ロック ウォッチャー エラーの後に停止するワークスペース ファイル ツリーを修正しました。 - [ファイル] ページをアクティブにしたままにせず、短いページ切り替えの間でもディレクトリの状態を保持します。 - [AI] ツール スキーマに propertyNames またはAdditionalProperties キーワードが含まれている場合、Gemini リクエストが不明フィールド 400 エラーで失敗する問題を修正しました。 - [AI] HTTP 400 リクエスト失敗メッセージを明確に表示し、正確なエラー分類のためにクロード エージェント SDK HTTP ステータス コードを保持します。 - [AI] HTTP 413 エージェントのリクエストの失敗について説明し、再試行する前にペイロード サイズを減らすことを提案します。 - [Windows] アプリケーション制御がネイティブ シャットダウン ハンドラーをブロックする場合に Windows 起動時にクラッシュする問題を修正しました。 - [Linux] Linux AppImages はシステム libfuse2 ライブラリを必要としなくなりました。 - [ミニアプリ] インストールコンテンツがダイアログ内に残るように、ミニアプリの追加ダイアログの幅を修正しました。 - [履歴] チャットとエージェントの履歴では、回復可能なアーカイブ アクションを正確に説明するアーカイブ アイコンとラベルが使用されるようになりました。 - [UI] エージェント セッションで cli がファイル パスをロックした後、ツールチップ コンテンツが左上隅に固定されて残ることがある問題を修正しました。 - [UI] 右ペインのパネルを切り替えた後、ウィンドウの左上隅に残るツールチップを修正しました。 - [UI] キーボードが取り外された Windows タブレットなど、ホバー サポートのないデバイスでもメッセージ、会話、およびクリア アクションにアクセスできるようにします。 - [エラー] レンダリングエラーは、安全な表示のために HTML ではなくテキストとして発生します。 - [引用]
