<summary>Release Note</summary>

Cherry Studio 2.1.8 - 編集、音声、統合のアップデート

✨ 新機能

  • [ファイル編集] メモ、スキル、アーティファクト全体で下書きを分離し、失敗した編集を再試行のために保持し、最大 8 MiB のテキスト編集とプレビューをサポートします。
  • [言語] 完全な翻訳と絵文字ピッカーを備えたイタリア語 (IT-IT) UI サポートを追加します。
  • [音声] テキスト入力中にマウス ボタンを押し続けるとディクテーションが開始され、離すと書き写されます。
  • [音声] リアルタイムオーディオ再生によるストリーミング音声合成。
  • [Web 検索] Tencent Yuanbao Search を組み込みプロバイダーとして追加します。
  • [スケジュールされたタスク] インタラクティブなタスク カードを使用したエージェント チャットを通じて、スケジュールされたタスクを作成および管理します。
  • [スクリーンショット] オーバーレイを開いたまま、キャプチャを clipboard にコピーします。
  • [選択] テキストを任意の場所で選択すると、自動的にコピーされ、クイッククォート ツールバーが表示されます。
  • [Composer] ファイルとリンクのトークンがテキスト行に整列し、タイプごとのファイル アイコンが表示され、編集中にファビコンが読み込まれます。
  • [RTF] リッチ テキスト形式のファイルを書式設定されたドキュメントとしてプレビューします。
  • [フェイシュウ] グループチャットの@メンションのみにボットが返信するかどうかを設定します。
  • [リモートアクセス] ペアリング招待用のカスタムホスト名、IP、またはポートを設定します。
  • [アシスタント] 今後アーカイブする場合は、「関連トピックもアーカイブする」の選択を覚えておいてください。

🐛 バグ修正

  • [メモ] キャッシュされたメモを切り替えるときにメモの内容が上書きされる問題を修正しました。
  • [スキル] ZIP またはフォルダーに SKILL.md がない場合、一時パスを漏らすことなく、ローカライズされたエラー メッセージを表示します。
  • [チャット] デフォルトで長いユーザーメッセージを展開します。フォローアップキューを開封確認から独立させます。
  • [プロキシ] Windows 上の 192.168.* のような短いワイルドカード IP バイパス ルールに一致します。
  • [クロード コード] 内部ゲートウェイ経由でルーティングする場合は、1M コンテキスト バジェットを維持します。
  • [タブ バー] 最後のタブを閉じると、アプリを終了する代わりにランチパッドが開きます。
  • [ファイルプレビュー] ファイルを更新するときに読み取り状態を保存します。 Word文書の行間を修正します。
  • [サイドバー] 選択したエントリでは、明るいテーマと暗いテーマの両方でニュートラルな塗りつぶされたアイコンが使用されます。
  • [チャット レイアウト] リスト グループの展開状態をウィンドウごとに分離します。
  • [ペイント] パフォーマンスの問題を防ぐために、読み込みグリッド密度を制限します。
  • [MCP] 保存されたヘッダーと環境値にリテラル # 文字を保持します。
  • [ナレッジ] Linux x64 用のベースライン sqlite-vec ビルドを出荷します。
  • [音声] 操作の失敗とストリームのタイムアウトの診断を追加します。
  • [エージェントセッション] エージェント間で作成する場合、ターゲットワークスペースを継続します。表面圧縮の失敗。
  • [メッセージ] 互換性のないリプレイ入力を持つ履歴ツール パーツを削除します。
  • [仮想リスト] 固定されたスタックの一番下にスティッキー ヘッダーを渡します。
  • [メモ] 「ディスク上で変更されたメモ」競合ダイアログを閉じるとエディターセッションがスタックしたままになり、以降のメモの名前変更、削除、移動がすべて失敗し、誤解を招くエラーが発生する問題を修正しました。

🔒 セキュリティ

  • [Electron] 証明書のセキュリティを修正するには、44.9.3 にアップグレードします。

</詳細>
