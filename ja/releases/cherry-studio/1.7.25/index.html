  • 修正: https://github.com/CherryHQ/cherry-studio/pull/13356 の @SiinXu による sudo OpenClaw インストール/アンインストールの PATH にノード ディレクトリを追加
  • 修正: https://github.com/CherryHQ/cherry-studio/pull/13392 の @kangfenmao により、dev 環境と prod 環境の間で Agents.db パスを統一しました。
