<詳細> <概要>英語</概要> Cherry Studio 2.1.0 - システムドクター、ブラウザコントロール、オフィストランスフォーム ✨ 新機能

  • [ドクター] AI診断、システムチェック、ガイド付き修正、診断エクスポート、フィードバックを備えたシステムドクターを追加します。チェックでは、インストール、権限、ストレージ、プロバイダー、MCP、管理ツール、最近のエラーが対象になります。完全なシステム レポートとは別に、個々のチャットまたはエージェント セッションを診断します。フィードバックまたはエクスポートを開いても、ヘルスチェックは開始されません。
  • [ブラウザ] エージェントとチャット アシスタントは、エージェントのアクションを示すアニメーション ポインタを備えた組み込みブラウザを使用できます。エージェントは、ページ要素を検索し、ページ更新後にそれらを復元し、コンソールとネットワークのアクティビティを検査し、Web サイトの WebMCP ツールを使用できます。閲覧履歴の検索、ブラウザデータのインポート、履歴やキャッシュの個別クリアもサポートしています。
  • [Office] オフィス変換スキルを追加します。エージェントは、ワークシート範囲、文書段落、PDF ページ、およびスライド図形を新しいファイルに抽出できます。
  • [選択] 「領域の選択」をオンにすると、ワークシート範囲、Word 段落、PDF ページ、またはスライドを選択し、正確な構造参照として引用します。
  • [Web 検索] Web 検索プロバイダーとして Serply を追加します。
  • [モデル] 推論労力制御と Web 検索サポートを備えた DeepSeek V4.1 Flash モデルを追加します。
  • [エージェント] エージェントは、[設定] → [一般] でクロード コードのコミット帰属をオプトアウトできます。
  • [サイドバー] アプリ、ミニアプリ、エージェント、アシスタント、ナレッジベース、トピック、エージェント セッション、ファイル、コード CLI ツールをショートカットとして固定します。
  • [チャット] 内蔵または外部ブラウザで開くための会話リンク コンテキスト メニューを追加します。
  • [履歴] Ctrl+A/Cmd+A 全選択、Shift-click 範囲選択、部分選択インジケーターを追加。
  • [モバイル] ローカライズされたモバイル アプリ ダウンロード カードを使用して、デバイス接続がすべてのユーザーに表示されるようになりました。
  • [ゴミ箱] トピック、エージェント、アシスタント、またはファイルを削除すると、それらは設定 → データ → ごみ箱に移動され、復元または完全に削除されるようになりました。
  • [Markdown] LaTeX コード ブロックにデフォルトで数式プレビューが表示されるようになりました。
  • [Markdown] アシスタント応答内のベア ローカル ファイルおよびフォルダー パスが clickable になりました。
  • [ログ] 自動クリーンアップによるログ保持設定 (7/14/30/90 日) を追加します。 🐛 バグ修正
  • [コードブロック] 編集内容が間違ったコードブロックに保存されたり失われたりする問題を修正しました。ツールバーはスクロールしても表示されたままになります。
  • [Composer] ファイルを読み取れない場合に何もせずにペーストする問題を修正しました。
  • [Composer] メッセージ送信時に入力フォーカスを保持します。
  • [会話リスト] さらに表示すると、残りのすべての会話が展開されます。
  • [履歴] 会話を削除した後も履歴を開いたままにします。
  • [Markdown] 遅延読み込み中に生のメッセージがフラッシュされるのを防ぎます。
  • [Markdown] 空白行にわたる表示数学レンダリングを修正しました。
  • [Windows] ログに「fsync(dir) failed」という警告が繰り返し表示される問題を修正しました。
  • [モデル] ツール対応の LMStudio/Ollama モデルの Web 検索を有効にします。
  • [モデル] /api/v0/models から LM Studio モデルをリストします。
  • [プロバイダー] DeepSeek V4 の出力を 384000 トークンに制限します。 GLM-5.3 および MiMo V2.5 の制限を修正します。
  • [DSH] バンドルされた Bun で DSH を起動します。 OpenCode セッション ヘッダーを保持します。
  • [DSH] 互換性のないアップグレードされた DSH ホームでフェイルファストが発生します。
  • [エラー] Chromium net::ERR_* トランスポートの失敗を分類します。構造化されたプロバイダー障害メッセージを保持します。
  • [画像] HDR 参照画像の互換性を復元します。画像の回転反転を修正しました。
  • [移行] 不正な MCP サーバー レコードが v2 移行を中止しないようにします。
  • [ショートカット] ショートカットがメインプロセスのショートカットと衝突した場合に警告します。
  • [チャット]送信後にボトムフォローを元に戻します。タブを切り替えるときにサイドバーの状態を保持します。
  • [チャット] ホバー時にマルチモデルのスクロールバーを表示します。スクロールのリバウンドを防ぎます。
  • [知識] ファイル リーダーのスクロールバーを表示します。
  • [スムーズ ストリーム] 完了時にバッファリングされたテキストをフラッシュします。
  • [Claude Code] ぶら下がっているシンボリックリンクをワークスペースエスケープとして扱います。 Linux デスクトップ セッション バスを保持します。
  • [副操縦士] 応答 API を通じて GPT-6 アストラをルーティングします。 </詳細> <詳細>
