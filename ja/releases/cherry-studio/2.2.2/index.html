Cherry Studio 2.2.2 - エージェントの承認、プロバイダーの修正、およびポーランド語

✨ 新機能

  • [コンピューターの使用] コンピューターの使用がデフォルトでオンになり、各アプリにアクセスする前に質問が表示されます。 [常に]、[セッションに対して承認]、または [拒否] を選択し、保存された承認を [設定] で管理します。バイパス モードでは、アクセス許可を保存せずにこれらのプロンプトをスキップします。 (要対応: 不要な場合は設定でオフにしてください。)
  • [スキル] 設定→スキルに「スキルを外部エージェントにエクスポート」スイッチを追加しました。新規インストールではデフォルトでオフになっているため、共有スキル ディレクトリは明示的なオプトインなしでは作成されなくなりました。すでにエクスポートされているインストールではオンのままであり、オフにすると、Cherry Studio が作成したリンクのみが削除されます。
  • [エージェント] DeepSeek モデルのエージェントは、各ツール呼び出しの上に短い意図行を表示するようになりました。エージェント セッションでは、デフォルトでツール ステップが展開された状態が維持され、同じ種類の繰り返し呼び出しが折りたたまれます。
  • [アプリ] ポーランド語のサポートを追加しました。

💄 改善点

  • [MCP] QVeris は、オプションのフォールバックとして QVERIS_API_KEY を使用してプライマリ資格情報として OAuth ブラウザ サインインをサポートするようになりました。そのため、API キーなしで有効にできます。
  • [ファイル] ファイル サイズは、アプリ全体で 1 つの一貫した形式を使用します。
  • [エージェント] セッションの詳細のタイポグラフィ、アイコンの配置、間隔、およびワークスペースのないプレースホルダーが洗練されました。

🐛 バグ修正

  • [モデル] CherryIN Claude Sonnet 4.5 ツール リクエストが Bedrock パラメータ検証エラーで失敗しなくなりました。
  • [モデル] AWS Bedrock の Claude Opus 5.5 リクエストは適応推論を使用するようになりました。
  • [モデル] SiliconFlow は手動の API キー入力を使用します。廃止された OAuth ログインは削除されました (OAuth でサインインした場合はアクションが必要です)。
  • [チャット] 「入力がコンテキスト制限を超えています」エラーはコンテキスト長の拒否として認識されるようになったため、既存の回復ガイダンスが表示されます。
  • [チャット] アーティファクト プレビューを提供しないチャット サーフェスからローカル マークダウン ファイル リンクが開かれるようになりました。
  • [チャット] ロード中に最初のコンポーザーツールバーのアクティブ化が失われる問題を修正し、内部タブのナビゲーションが対話をブロックしなくなりました。
  • [エージェント] ストリーミングされた承認リクエストがツール ソースより前に到着した場合に、AskUserQuestion カードが欠落する問題を修正しました。
  • [エージェント] すべての質問がスキップされたときに、最後の AskUserQuestion で [スキップ] ボタンが動かなくなる問題を修正しました。
  • [エージェント] Pi Durable 読み取りツール呼び出しを展開しても、空のファイルの詳細が表示されなくなりました。
  • [エージェント] Pi Durable エージェントは、AGENTS.md などのワークスペース指示ファイルを自動的にロードするようになりました。
  • [エージェント] 通常の MCP ツールは、「一致するツールが見つかりません」を返す代わりに、Pi Durable ランタイムのツール検索を通じて検出できます。
  • [エージェント] エージェント ツール ガイダンスは、遅延ツールを検出を通じて使用できるものとして扱い、セッションからの正確なツール名を使用するようになりました。そのため、エージェントは、使用可能なツールが不足していると報告しなくなります。
  • [エージェント] 推論により応答バジェットが使い果たされた場合、出力トークン制限の正確なガイダンスが得られるようになり、DeepSeek V4.1 フラッシュ容量はバージョン管理されたモデル ID に対して正しく解決されます。
  • [API ゲートウェイ] Claude Code MCP ToolSearch の結果がサードパーティ モデルでドロップされなくなりました。
  • [コード] Code Mate の Unified Gateway モデル ピッカーに、エージェントのみが利用できる Cherry Cloud モデルがリストされるようになりました。
  • [Doctor] Doctor は、欠落している API キーや、CherryAI および Cherry Cloud の利用できないモデル リストを報告しなくなりました。 Cherry Cloud では、サインインが必要なときに通知されるようになりました。
  • [UI] ウェブサイトのファビコンは、元の色を維持しながら、柔らかいライトグレーのバックプレートでダーク モードでも表示され続けます。
  • [アップデーター] 更新ダイアログの Release note は、アプリがシステム言語に従う場合を含め、アプリの解決された言語に従うようになりました。

</詳細>
