何が変わったのか

  • 修正 (トピック名): https://github.com/CherryHQ/cherry-studio/pull/18320 の @tommyzhang100504 によるアシスタント ツール設定から自動名前変更リクエストを解放したままにする
  • 修正（ミニアプリ）: https://github.com/CherryHQ/cherry-studio/pull/18233 の @kennyzheng-builds による既存のサイドバー タブを再利用

  • 修正（コンポーザー）: https://github.com/CherryHQ/cherry-studio/pull/18301 の @Pleasurecruise による長いテキストの貼り付けにアクティブなエディターを使用する
