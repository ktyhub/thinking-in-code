<summary>Release Note</summary> Cherry Studio 2.1.7 - 音声、クラウド、モデルのアップデート ✨ 新機能 - [音声] Windows x64、Linux、macOS 用の 103 音声を備えた Kokoro 中国語-英語 TTS、および Apple Silicon 用の Qwen3-TTS を追加します。初めて使用する前に、[設定] > [ローカル モデル] からモデルをダウンロードします。 - [音声] 音声再生およびディクテーション コントロールでライブ オーディオ スペクトルを表示します。空のディクテーションの後、マイクを元に戻します。 - [音声] Windows、Linux、macOS にローカル FunASR 音声文字起こしを追加します。 - [Cherry Cloud] サブスクリプション プランとクォータ使用量の可視性をグローバル エディションに追加し、管理対象モデルの期間限定無料クォータと使い果たされたクォータの説明を追加します。 - [Cherry Cloud] コンパクトなアンカー付きサイドバーアカウントメニューを追加します。アバターとニックネームは個人情報設定を開きます。 「外観」と「ログイン」はメニューに残ります。 - [Cherry Cloud] 一時的な接続または更新の失敗時にログインを保持します。 - [自動化] より明確な実行フィードバックを備えた永続的な JavaScript を通じて、ブラウザーとコンピューターの使用を調整します。 - [ナレッジベース] グループ間でナレッジベースをドラッグし、グループを並べ替えます。項目列を昇順、降順、およびデフォルトの順序で循環させます。 - [画像] 16:9、9:16、16:10、および 4K 出力用の GPT-Image-2 アスペクト比プリセットを追加します。 - [モデル] 思考レベルと自動長時間出力継続による Gemini 4 Argon サポートを追加します。 - [モデル] マルチモーダル機能と推論制御を備えた Muse Spark オープン モデル認識を追加します。 - [検索] DuckDuckGo をフリーキーワード Web 検索プロバイダーとして追加します。 API キーは必要ありません。 - [ツール] ツールの結果で画像リンクがプレビューされ、clickable Web リンクが表示されるようになりました。 - [エラー] 読み取り可能な診断、展開可能な詳細、会話、プロバイダー チェック、MCP エラーの回復アクションを含む実用的なエラー通知を表示します。 - [チャット] キューに登録されたフォローアップ メッセージが折りたたまれて開始されます。 Cliヘッダーを確認して展開または折りたたむことができます。 - [チャット] 会話の上にマウスを置くと、フルネーム、アクティビティ時間、ワークスペースの詳細が表示されます。 - [注意事項] コードブロック言語を名前で検索します。 🐛 バグ修正 - [添付ファイル] 認識できない拡張子のテキスト ファイル (例: .lrmx) がテキストとして読み込まれない問題を修正しました。 - [OCR] 非ビジョン モデルに画像を送信するときにどの OCR パスが失敗したかを、失敗タイプごとのガイダンスとともに特定します。 - [ウィンドウ] Windows/Linux でトレイ アイコンが使用できない場合にメイン ウィンドウが閉じてウィンドウが非表示になり、復元または終了できない問題を修正しました。 - [メッセージ] 開示状態を保持し、メッセージ表示でストリーム推論に従います。 - [Composer] プロンプトテキストの指示に自動的に従います。ファイル名の先頭にドットを付けます。エージェント表面上のあらゆる種類のファイルを受け入れます。 - [ファイル] ファイルのコンテキスト メニュー アクションを追加します。ファイルのリンクとアイコンをインライン テキストに合わせて配置します。 - [MCP] 5xx エラーでバージョン プローブを拒否するリモート MCP サーバーに接続します。再接続する前に健全性を確認してください。 - [モデル] Null Gemini モデル リストのページネーション トークンを受け入れます。 Gemini モデルの検出とメタデータの更新を改善します。 - [トレイ] ポータブル インストールには安定した Windows トレイ GUID を使用します。 - [音声] コードブロックおよびインラインコード内のテキストをスキップする読み上げを修正しました。 - [エージェント] ユーザーが declining セットアップによってオンボーディングをオフにできるようにします。 - [翻訳] 余分なツールバー行を追加せずに、入力テキストの横にアイドル状態のディクテーションとコピー ボタンを保持します。 - [コンピュータの使用] クロード エージェントの自動化ツール出力の欠落を修正し、大規模な観察が省略されるのを防ぐために構造化されたアクセシビリティ ツリーのページネーションを追加しました。 - [設定] 設定スクロールバーと一貫したレイアウトを復元し、コンピューターの使用許可アクションを明確にし、clipped コンテンツ、MCP タブ オーダー、および不要な使用状況ヒートマップ オーバーフローを修正します。 </詳細> ##
