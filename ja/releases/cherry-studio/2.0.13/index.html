<詳細> <概要>英語</概要> Cherry Studio 2.0.13 - 新機能、修正、改善 ✨ 新機能

  • [モデル] コンテキスト制限、推論制御、高速モード、ネイティブ Web 検索、階層型価格設定、および公式モデル アイコンを備えた GPT-6 Astra サポートを追加します。
  • [モデル] ブラウザベースの API キー認証を備えた組み込みモデル プロバイダーとして TokenDance を追加します。
  • [スケジュールされたタスク] 毎日、平日、および毎週のプリセットが、1 日に複数回 (例: 09:00 と 18:00) をサポートするようになりました。
  • [チャット] トピックとセッションのタイトルを表示し、ヘッダーからブランチを切り替え、個々のブランチを Markdown としてエクスポートします。
  • [スキル] スキル設定にインストール済みスキルのソースフィルターと 1 列/2 列レイアウトの切り替えを追加します。
  • [クイックパネル] 管理アクションは、プロンプト、スキル、MCP、メモ、ナレッジベース、ツールバーのカスタマイズ全体にわたってアクセス可能なフッターに留まるようになりました。
  • [コンポーザー] 入力にフォーカスするための構成可能な Ctrl+I / Cmd+I ショートカットを追加します。
  • [画像のエクスポート] メッセージ画像のエクスポートでは、画面に表示されているものと一致するピクセル完璧な出力のために Chromium のコンポジターが使用されるようになりました。
  • [翻訳] リッチな Markdown 形式でストリーミング出力をレンダリングします。 🐛 バグ修正
  • [モデル] Cherry Studio の自動アトリビューション ヘッダーを拒否するカスタム モデル プロバイダーを修正しました。
  • [モデル] カスタム サンプリング設定が有効になっている場合に失敗する Moonshot Kim K2.5+ リクエストを修正しました。
  • [モデル] サポートされていない推論努力が選択された場合に失敗する Kim K3 リクエストを修正しました。
  • [モデル] サービス終了に伴い、Yi (01.AI) プロバイダーを廃止しました。
  • [モデル] v1 から移行されたプロファイルは、インストールされているエディションに関係なく、すべてのプロバイダーとモデルへのアクセスを保持するようになりました。
  • [チャット] プロバイダーが非標準のアイテム ID を返した場合、ツール呼び出し後に 400 エラーが発生して永続的に失敗するトピックを修正しました。
  • [チャット] 応答のストリーミング中のマルチモデルの応答間の切り替えを修正しました。
  • [チャット] 自動再試行後にプロバイダー設定にリンクできない通常のチャット認証エラーを修正しました。
  • [チャット] プロバイダーから返されたネイティブ Web 検索の引用がチャット応答に表示されるようになりました。
  • [チャット] 完了したエージェント セッションには、誤解を招くゼロではなく、使用できないトークンの使用量が表示されるようになりました。
  • [チャット] エージェント client 証明書の認証失敗時に、プロキシと SSL の回復ガイダンスが表示されるようになりました。
  • [チャット] Claude Code Agent のサインイン失敗は、回復に必要なプロバイダー設定にリンクされるようになりました。
  • [チャット] 一般的な HTTP 400 エラーにプロバイダー設定の回復アクションを追加します。
  • [チャット] メッセージの引用符が間違ったウィンドウにルーティングされる問題を修正しました。
  • [スケジュールされたタスク] スケジュールされたエージェントの実行が失敗、タイムアウト、またはキャンセルされたときに、タスク実行ログの「セッションの表示」リンクが失われる問題を修正しました。
  • [エージェント] セッションが右側に表示されている場合、タスクレスエージェントがエージェントリストから消えてしまう問題を修正しました。
  • [エージェント] コマンド出力ではなくエラーとしてラベル付けされる Bash ツールの失敗を修正しました。
  • [エージェント] ツール呼び出しを修正して、修復および再生された引数が予想される JSON の形状を維持できるようにしました。
  • [エージェント] RTK が Bash コマンドを書き換えるときに、クロード コードの繰り返しコマンドのループ ガードを復元します。
  • [エージェント] エージェントがネイティブ ツールを通じて Cherry Studio のユーザー データ SQLite ファイルを変更できないようにします。
  • [エージェント] クロード コード プロセスの失敗に、対処可能な原因と診断参照が表示されるようになりました。
  • [エージェント] コンテキスト使用状況インジケーターは、完了時のみではなく、タスク中にライブで進行するようになりました。
  • [DeepSeek] ランタイムがトークン認証された URL を必要とする場合、DeepSeek Harness Web セッションが正しく開始されるようになりました。
  • [Pi] コンテキストクランプされた長さの応答後、制限付きのコンパクトアンドリトライ試行で Pi タスクを再開します。
  • [OpenCode] OpenCode Go の自動会話タイトルでは、セッション ID が保持されるようになりました。
  • [コンテキスト] コンテキスト圧縮モデルセレクターを修正し、ユーザーが「現在のモデルに従う」に戻せるようにしました。
  • [設定] プロバイダーのモデルが多数ある場合に、プロバイダー モデルのリストでアプリがフリーズする問題を修正しました。
  • [設定] 安全でない最大トークン値による自動保存を妨げるアシスタント設定を修正しました。
  • [設定] 中国版のオンボーディングでは、デフォルトで再び CherryIN ログインが使用されるようになりました。
  • [設定] AMD GPU クラウドでは、プロモーションの「無料」または毎日のクレジット メッセージが表示されなくなりました。
  • [クイックアシスタント] MCP を備えたクイックアシスタントが設定されている場合に、MCP ツールを呼び出すための組み込みの選択クイック アクションを修正しました。
  • [翻訳] 間違ったペインにフィードバックが表示されるコピー ボタンを修正しました。
  • [翻訳] Enter または Space でアクティブ化したときに、翻訳履歴のスターが切り替わらず、詳細を開く問題を修正しました。
  • [Web 検索] 個々のアイテムがオプションのメタデータを省略しても、有効なクエリ結果を保持します。
  • [Word エクスポート] Word エクスポートでは、4 つのスペースでインデントされたコード ブロック、番号付きリスト、画像代替テキスト、取り消し線がレンダリングされ、空のブロック引用エラーが修正されました。
  • [Markdown] マークダウン内のオーバーフローしたコンテンツに水平スクロールバーが表示されるようになりました。
  • [ブラウザ MCP] 非表示または非アクティブな組み込みブラウザ ページが可聴メディアを再生できないようにします。
  • [バックアップ] 新しいバージョンで作成されたバックアップを復元する際の誤解を招く「バックアップ ファイル形式エラー」を修正しました。
  • [バックアップ] リージョン エンドポイントを使用する場合の Qiniu Cloud S3 のバックアップ、復元、管理、および保持のクリーンアップを修正しました。
  • [地域] IP 地域の検出が失敗した場合、地域依存のルーティングは、中国本土として処理するのではなく、グローバル エンドポイントにフォールバックするようになりました。
  • [リージョン] 別のプロキシからの実行中のリクエストを再利用するリージョン検出を修正しました。
  • [ミニアプリ] ミニアプリ検索で翻訳された表示名でアプリが見つからない問題を修正しました。
  • [ミニアプリ] 未翻訳の文字列を表示した生の権限キーのツールチップを削除します。
  • [メモ] ユーザーが新しい名前を入力する前にメモとフォルダーの名前変更フィールドが閉じる問題を修正しました。
  • [PDF プレビュー] 送信時に範囲外の数値が保持される PDF ページ入力を修正しました。
  • [Cherry Cloud] サインイン完了後、Cherry Studio をフォアグラウンドに表示します。
  • [ポータブル] パッケージ化されたリソースを失う可能性がある 2 番目のアプリ インスタンスを開いている Windows ポータブル ディープ リンクを修正しました。
  • [Windows] [プログラムから開く] メニューでローカライズされたデフォルトのアプリケーション名が文字化けする問題を修正しました。
  • [macOS] macOS キーチェーンの署名を修復します。 💄 改善点
  • [イメージ生成] 自動再試行を無効にして、重複した請求可能なリクエストを回避します。
  • [画像生成] 編集モード経由で編集専用の画像モデルを調査します。
  • [エージェント チャネル] 1 秒のバッチ遅延の後に受信メッセージの処理を開始します。 ⚡ パフォーマンス
  • [コード エディター] CodeMirror テーマ カタログは、コード エディターを開いたときにのみ読み込まれるようになりました。
  • [HTML アーティファクト] HTML アーティファクトのプレビューは、スクロール可能なコンテンツの要素全体のレイアウト スイープをスキップします。 </詳細> <詳細>
