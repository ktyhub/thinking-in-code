#チェリースタジオv2.0.2

何が変わったのか

  • feat(chat-branch): https://github.com/CherryHQ/cherry-studio/pull/17667 の @zhangjiadi225 による空のブランチ ノードを永続化
  • perf(chat-tabs): https://github.com/CherryHQ/cherry-studio/pull/18038 の @zhangjiadi225 によるメッセージ ツール、アーティファクト ペイン、およびトレース ページでの冗長な再表示作業をスキップします。
  • 修正 (claude-code): https://github.com/CherryHQ/cherry-studio/pull/17969 の @kovsu によるシャットダウン時に sdk cli サブプロセスを取得
  • fix(tool-loop): https://github.com/CherryHQ/cherry-studio/pull/18072 の @DeJeune によりデフォルトのツール呼び出しラウンドキャップを引き上げます
  • fix(directory-tree): https://github.com/CherryHQ/cherry-studio/pull/18009 の @DeJeune によるスナップショットからストリームへの配信ギャップを埋める
  • 機能 (プロバイダー): DeepSeek/OpenRouter/Dashscope の組み込み Web 検索 + https://github.com/CherryHQ/cherry-studio/pull/17983 の @DeJeune による識別可能な解決済みモデル名
  • 修正(v2-migration): https://github.com/CherryHQ/cherry-studio/pull/18093 の @kangfenmao による v2.0.x への直接アップグレードを許可
  • feat(cache-cleanup): https://github.com/CherryHQ/cherry-studio/pull/17377 の @kangfenmao による選択的キャッシュとレガシー データ クリーンアップを追加
  • 修正 (コンポーザー): https://github.com/CherryHQ/cherry-studio/pull/18082 の @zhangjiadi225 による共有プレビューで画像トークンを開く
  • 修正 (エージェント チャネル): https://github.com/CherryHQ/cherry-studio/pull/18071 で @Pleasurecruise による WeChat QR ログインを開始
  • リファクタリング(プロキシ): https://github.com/CherryHQ/cherry-studio/pull/18095 の @eeee0717 によって ProxyService 独自のワーカー ルーティング ポリシーを作成します
  • 機能: https://github.com/CherryHQ/cherry-studio/pull/16164 で @Pleasurecruise による Claude (Anthropic) 会話インポート サポートを追加
  • feat(cli-config): https://github.com/CherryHQ/cherry-studio/pull/18014 の @eeee0717 による統合ゲートウェイを介した詳細モデルのサポート
  • feat(data-migration): https://github.com/CherryHQ/cherry-studio/pull/18002 の @kangfenmao による v1 移行の再実行を許可します。
  • 修正(mcp-settings): https://github.com/CherryHQ/cherry-studio/pull/17647 の @Pleasurecruise により、フォームの編集を保持し、ツールの詳細を改善しました。
  • 修正(new-api): https://github.com/CherryHQ/cherry-studio/pull/18033 の @DeJeune によるルートごとのバージョンで 1 つのホストからすべてのエンドポイントを提供します
  • 修正（エージェント移行）: https://github.com/CherryHQ/cherry-studio/pull/18101 の @kangfenmao による移行中にシンボリックリンクをスキップ
  • 修正 (ローカル モデル): ミラー障害を乗り越え、オフラインでの推論の埋め込みを継続 (https://github.com/CherryHQ/cherry-studio/pull/18016 の @eeee0717 により)
  • 雑用: @kangfenmao による v2.0.2 を https://github.com/CherryHQ/cherry-studio/pull/18107 でリリース
  • 修正 (選択アシスタント): https://github.com/CherryHQ/cherry-studio/pull/18098 の @AtomsH4 による繁体字中国語ロケールを尊重 フル Changelog: https://github.com/CherryHQ/cherry-studio/compare/v2.0.1...v2.0.2
