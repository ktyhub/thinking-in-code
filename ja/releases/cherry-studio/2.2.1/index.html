<summary>Release Note</summary>

Cherry Studio 2.2.1 - リモート タスク、検索プロバイダー、およびエージェントの修正

✨ 新機能

  • [タスク] リモート client は、スケジュールされたタスクの結果の会話を検出し、タスクのスケジュール、実行履歴、および限定された概要をクエリできます。実行レコードがクリーンアップされた後も、タスクの会話は引き続き検出可能です。
  • [モデル] Rapid-MLX は、内蔵のキーレス ローカル プロバイダーとして利用できます。
  • [Web 検索] SerpKite および StepFun キーワード検索プロバイダーが追加され、Exa はコンテンツ API を通じて URL のコンテンツをフェッチできるようになりました。
  • [ファイル] Markdown ファイル (.md、.markdown、.mdx) をアプリ ウィンドウにドロップすると、読み取り専用プレビューで開きます。
  • [エージェント] システムおよびグローバル パッケージのインストールは、すべてのモードでブロックされるのではなく、通常モードで承認を求め、フル アクセスで実行されるようになりました。
  • [エージェント] エージェントとアシスタントは、カタログ、セレクター、会話、メッセージ ヘッダー、および [作業] タブのアイコンに表示されるアップロードされた画像をアバターとして使用できます。既存の絵文字アバターは変更されません。
  • [エージェント] ワークスペースおよびエージェント グループは、タスクを展開可能な状態のまま、上部の固定セクションに固定できます。
  • [エージェント] コンピューター使用の通話には操作したアプリケーションが表示され、セッションの詳細には同じアプリのアイコンが表示されます。
  • [エージェント] サブエージェント呼び出しではプロバイダーとモデルの両方を指定でき、サブタスク行には要求されたモデルが表示されます。
  • [Composer] Markdown 入力レンダリングを有効にすると、チャット、エージェント、および選択作成バーでの入力中に Markdown がライブでプレビューされます。マーカーは、キャレットが到達すると表示され、送信されたテキストは変更されません。
  • [Composer] Markdown プレビューで、Cmd/Ctrl+B、Cmd/Ctrl+I、およびバッククォートを使用して、選択したテキストを太字、斜体、またはインライン コードにすることができます。
  • [Composer] Markdown プレビューでは、フェンスで囲まれたコード ブロックが強調表示されたコード領域としてレンダリングされ、Enter キーによる改行の挿入、タブ インデント、括弧の自動ペアリング、および変数またはショートカットがフェンス内にリテラルのまま残ります。
  • [ブラウザ] 内蔵ブラウザの新しいタブは、空白のページ、最後に開いたページ、またはカスタム URL から開始できます。
  • [ナレッジ] OpenDocument (.odt、.odp、.ods) および RTF (.rtf) ファイルをナレッジ ソースとして追加できます。
  • [API ゲートウェイ] CherryAI サブスクリプション モデルは、サインインしたアカウントのクォータを使用して、ゲートウェイ経由で外部の client および Code Mate に利用可能です。

💄 改善点

  • [エージェント] Pi および Pi Durable は、ランタイムのネイティブ圧縮を使用し、プロバイダー エラーの詳細を保持します。
  • [エージェント] セッションの詳細には、エージェントが制御しているアプリケーションとそのステータスおよび停止アクションがリストされます。
  • [チャット] ブランチ マップはアクティブなブランチ ノードを特定し、スクロール時にパンできます。
  • [モデル] 推論-努力スライダーはドラッグにスムーズに追従し、努力レベルに落ち着き、モーションの削減設定を尊重します。
  • [モデル] モデル セレクターでモデル名が切り詰められているが、ホバーすると完全な名前が表示され、モデルの詳細カードでは clips が表示されなくなりました。
  • [スケジュールされたタスク] 履歴の読み込み中、アンカー ナビゲーションが整列したままになり、失敗した実行の概要がツールチップにエラーの詳細を表示します。
  • [ファイル] ファイル リストとグリッドには、名前ツールチップに各ファイルのソース パスが表示されるため、同じ名前のファイルを区別できます。
  • [Prompt Polish] デフォルトのモデルとその設定へのリンクを表示し、タイムアウト、モデルの欠落、空の応答、プロバイダーの障害を区別します。
  • [フィードバック] 問題レポートへの診断の添付はオプションになりました。
  • [macOS] DMG インストーラーには、新しい背景と、中央に配置されたより大きなドラッグからアプリケーションへのレイアウトが追加されました。
  • [アシスタント] 英語のデフォルトアシスタントの名前が「Cherie」になりました。
  • [UI] 拡張された通知スタックはシャドウを clip しなくなりました。

🐛 バグ修正

  • [エージェント] Pi および Pi デュラブル コードモードでのネストされたシェル、ファイル、アーティファクト ツールの結果が、会話を再開した後も含めて再度表示されます。
  • [エージェント] 明示的なタイムアウトのない Pi シェル コマンドは、無期限に待機しなくなりました。
  • [エージェント] セッションを閉じると、最初にクロードの作業が中断され、中断されたクロード コード ターンに「応答要求なし」が表示されなくなりました。プレースホルダー。
  • [エージェント] フォークと編集と再送信は /compact 境界の後で機能し、フォークは空白のフレーム行を持つ正常なクロード セッションを拒否しなくなりました。
  • [エージェント] ステップ パネルに終了したターンが実行中として表示されなくなり、エージェントによって削除されたタスクがリストから残ります。
  • [エージェント] エージェントのトップバーには、最初のメッセージの後にワークスペース名とディレクトリを開くアクションが表示されます。
  • [エージェント] サブエージェントの出力とメイン エージェントの継続が、開いている会話に正しい順序で表示されます。
  • [エージェント] 検証モデルがその判定をコード ブロックまたは追加のテキストでラップすると、目標は完了します。
  • [エージェント] エージェント メッセージの編集に失敗すると、コピー可能な診断を含む完全な永続的な説明が表示されます。
  • [エージェント] コンテキスト使用パネルには、ID の代わりに設定された MCP サーバー名が表示されます。
  • [エージェント] クロスエージェント セッション カードは、ターゲット エージェントに名前を付けます。
  • [エージェント] アシスタントの仕事会話での返信では、削除が提供されなくなりました。これは、返信を削除しても実行時トランスクリプトを削除できないためです。
  • [エージェント] メッセージを編集すると、後の会話履歴を置き換える前に確認が求められます。
  • [エージェント] ワークスペースが空の場合でも、エージェントの会話からマークダウン アーティファクトをプレビューできます。
  • [エージェント]タブが非表示のときにエージェントのアバターが変更されると、[作業]タブのアイコンが更新されます。
  • [チャット] 送信メッセージ内のリンクを誤って移動することなくスムーズに選択できます。
  • [チャット] メッセージを編集しても、cli編集を実行した直後に入力した文字が削除されなくなりました。
  • [チャット] 古いメッセージで 2 回保存されたエラーには、1 つのエラー カードが表示されるようになりました。
  • [チャット] 空または不正な API 応答は、不明なエラーではなく、再試行ガイダンスによる明確な診断を示します。
  • [チャット] 「メッセージはまだ同期中です」ブランチスイッチ警告がローカライズされています。
  • [メモ] エディターでコード構文の強調表示が消えなくなりました。
  • [ショートカット] 会話番号のショートカットは、最初の切り替え後もウィンドウのフォーカスを再設定せずに機能し続けます。
  • [ブラウザ] ページ読み込みエラーでは、ローカル サーバーが停止したことを示唆するのではなく、一般的なメッセージが使用されます。
  • [ミニアプリ] Web サイトの MiniApp サインイン ポップアップは永続セッションに残ります。
  • [ナレッジ] 失敗したナレッジ項目には失敗の理由が表示され、空の抽出メッセージはローカライズされます。
  • [スケジュールされたタスク] Cron タイムアウトは Gemini 互換ランタイムで動作し、約 32,000 セッションを超えるタスクの削除は失敗しなくなりました。
  • [プロバイダー] client ツールの名前が空白の場合でもリクエストは失敗しなくなりました。
  • [Claude] Claude Code は、ダウンロードをステージングする前にランタイム フォルダーを作成するため、フォルダーが見つからない場合でもインストールが失敗することがなくなりました。
  • [ペイント] 画像サイズが選択されていない場合でも、SiliconFlow MOSS 画像リクエストが失敗しなくなりました。
  • [コード] Codex CLI は、構成を再構築するときに、選択したモデルのコンテキスト ウィンドウと圧縮制限を保持します。
  • [UI] エージェント セッションの詳細がコンテンツを混雑させたり、ファイル プレビューに重なったりすることがなくなりました。

⚡ パフォーマンス

  • [エージェント] 長いセッションでのブランチ切り替えとメッセージ編集が高速になります。
