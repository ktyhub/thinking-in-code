<summary>Release Note</summary>

Cherry Studio 2.1.10 - コメントのファイル、並べ替えのタッチ、タイムラインの更新

✨ 新機能

  • [エージェント ファイル] エージェントのファイルにコメントします。テキスト ファイルで、行にカーソルを合わせて click '+' (または複数行にわたってドラッグ) して、コメントを書き込みます。 Word、Excel、PDF、PowerPoint ファイルで、部分を選択し、click コメントします。各コメントは、その位置を含むチップとしてメッセージに追加されます。
  • [更新] スキップされた安定版 release note を折りたたみ可能なタイムラインで表示します。単一バージョンの更新では、メモが直接表示されます。 Markdown の脚注ナビゲーションがバックリンクで正しく動作するようになりました。
  • [プロキシ] 保存する前に、一般設定でプロキシ接続をテストします。PAC プロキシ/ダイレクト フォールバック レポートがサポートされています。
  • [タッチ] 行を長押ししてリストの順序を変更します。行内のボタンでドラッグが開始されなくなりました。選択アシスタントの設定では、有効なアクションと無効なアクションが区切り線で区切られた 1 つのリストに表示されるようになりました。

🐛 バグ修正

  • [チャット] コードブロックを含む会話をスクロールしているときに、メッセージリストが最初のメッセージに戻らなくなりました。
  • [エージェント] データ ディレクトリの移動後、既存の会話が正しく再開され、履歴が保存されます。
  • [ローカルディクテーション] ローカル音声認識で長い発話の後半が自動的に失われる問題を修正しました。
  • [ストリーミング] ストリーム再生が受信出力と重なる場合の応答テキストの欠落または重複を修正しました。
  • [Composer] 質問パネルのオプションの説明が切り詰められなくなりました。
  • [右パネル] エージェント タスクの作成または切り替え時にブラウザのサイドバーが予期せず開かなくなりました。
  • [コード ブロック] ダイアグラム プレビュー ツールバーは、clipped ではなくなりました。 Mermaid、Graphviz、SVG、LaTeX、および ECharts のプレビューがメッセージの背景に溶け込みます。
  • [知識] ファイル変換の進行状況は 0% から開始され、5 秒ごとではなく即時に更新されます。
  • [会話リスト] 最近の会話が午前0時を過ぎても下にソートされなくなりました。
  • [MiMo] 「サポートされていないモデル」エラーを返す MiMo モデルを修正しました。

⚡ パフォーマンス

  • [コード ブロック] コード ブロックを使用して会話をスクロールする際の不要なレンダリング作業を削減します。

</詳細>
