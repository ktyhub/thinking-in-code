<summary>Release Note</summary>

Cherry Studio 2.1.9 - ダイアグラム、ファイル ペイン、およびプロバイダーの更新

✨ 新機能

  • [図] 人魚図は、バックグラウンドでより高速なエンジンでレンダリングされ、アプリのライト/ダーク テーマに一致し、.mmd/.mermaid ファイルからプレビューとして開くようになりました。
  • [エージェント ファイル] ブレッドクラム付きのタブでファイルを開き、ツリーのサイズを変更し、ペイン設定で自動保存、インデント、ワードラップを構成します。右クリックして click を押してファイルまたはフォルダーをコンテキストとして添付します。
  • [エージェント] エージェントのすべての会話を 1 つのアクションでアーカイブし、カウントを示す確認メッセージを表示します。 [ブランチ管理] パネルから会話ブランチを削除します。
  • [Web 検索] Desearch と SearchApi を Web 検索プロバイダーとして追加します。
  • [プロバイダー] チャット、画像、推論コントロール、ネイティブ Web 検索を備えた QwenCloud を追加します。 DashScope を Qwen AI Platform にリブランドし、エンドポイントとアイコンを更新しました。 Vercel AI Gateway に Anthropic プロンプト キャッシュのサポートを追加します。
  • [コードテーマ] 新しいデフォルトの「チェリー」コードテーマは、ライトモードとダークモードでアプリの背景に溶け込みます。
  • [思考] メッセージの推論内容をアシスタント メッセージ エディターで直接編集します。
  • [権限] フルアクセスを有効にすると、有効になる前にスコープの確認が表示されるようになりました。
  • [タブ] アクティブな会話タブでは、選択されたアウトラインがより明確になり、タイトルが少し太くなります。
  • [メモ] エクスポート成功トーストから直接、新しく保存したメモを開きます。

🐛 バグ修正

  • [ツールチップ] 選択アシスタントのカスタム アクション ダイアログのヘルプ ツールチップなど、ダイアログの端で切り取られるツールチップを修正しました。
  • [チャット] 長い沈黙の推論フェーズが 30 分後に中止されなくなりました。アイドル限界は 120 分になりました。アップデート後にアシスタントのモデルが存在しなくなった場合の誤解を招くエラーを修正しました。
  • [タブ] タブに会話名とアシスタントアイコンを再度表示します。アクティブなタブの隣に新しいタブが開きます。プラスボタンは最後に追加されます。
  • [ナビゲーション] サイドバーとタブの選択スタイルを統一し、明るいテーマと暗いテーマのコントラストを明確にしました。
  • [メモ] 図のコードブロックを入力するときにフリーズする問題を修正しました。新しい図ブロックが編集モードで開きます。
  • [ナレッジ] チャンキング ルールをリセットする再構築、待機中のインポートのタイムアウト、再起動後に再開される中断された変換、および「準備中」状態のスタックを修正しました。
  • [ブラウザ] ローカル HTML ファイルのフラグメント リンクをたどるときに、保存されていない入力とページの状態を保持します。
  • [ファイル リンク] チャット ファイル リンクからホバー表示アイコンを削除しました。コンテキスト メニューを使用してファイルを表示します。
  • [Web Search] 「このモデルはenable_searchをサポートしていません」というエラーで失敗するDashScopeモデルを修正しました。ブラックリスト ルールにより、Bocha と Querit のドメインが除外されるようになりました。
  • [TTS] Kokoro 中国語のテキスト読み上げは、必要な北京語の eSpeak データを使用して Windows 上で正しく初期化されるようになりました。
  • [MCP] 削除されたページを開いてしまう組み込み MCP サーバーのドキュメント リンクを修正しました。
  • [AiHubMix] 組み込みツールに入力例が含まれている場合に HTTP 400 で失敗するクロード チャットを修正しました。

⚡ パフォーマンス

  • [ナレッジ] 大規模なナレッジ ベース内のアイテムの削除またはインデックスの再作成が大幅に高速化されました。
  • [会話] 非常に長い会話における分岐の切り替えとメッセージの削除が遅い問題を修正しました。以前のメッセージの読み込みは高速になります。

</詳細>
