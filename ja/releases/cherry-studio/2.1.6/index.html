<summary>Release Note</summary> Cherry Studio 2.1.6 - バグ修正とプロバイダーのアップデート 🐛 バグ修正 - [検索] メッセージと一致しないハッシュ記号を含むプログラミング言語 (C#、F# など) の検索を修正しました。 - [バックアップ] ブラウザのストレージが現在のセッションによってロックされている場合、Windows で復元が失敗する問題を修正しました。復元の進行状況は単調なままとなり、失敗した試行は再試行ガイダンスとともに報告され、孤立した復元ファイルはクリーンアップされます。 - [エラー] client 拒否エラーを「無効な API キー」として誤って報告するのを停止 — 有効なキーを再生成するようにユーザーに送信する代わりに、正しい権限ガイダンスを表示するようになりました。 - [チャット] コンテキスト使用トークンのカウントは、選択したインターフェイス言語に従い、変更されると更新されるようになりました。 </詳細> ## 何が変わったのか * 修正 (スケジュールされたタスク): 実行ログの日付検索を、https://github.com/CherryHQ/cherry-studio/pull/21442 の @xiajiahang によって表示されたタイムスタンプと一致させる * ホットフィックス(リリース): https://github.com/CherryHQ/cherry-studio/pull/21459 の @kangfenmao によるドラフト検証資格情報を修正 * 修正(選択アシスタント): https://github.com/CherryHQ/cherry-studio/pull/21467 の @WhiteZeek によるスクロール後のウィンドウのドラッグを保持する * chore(release): https://github.com/CherryHQ/cherry-studio/pull/21471 の @kangfenmao による v2.1.5 メタデータを同期します * 修正 (プロバイダー): レガシー Tencent TI および Hunyuan プロバイダーを廃止 (https://github.com/CherryHQ/cherry-studio/pull/21474 の @ousugo により) * fix(context-usage): https://github.com/CherryHQ/cherry-studio/pull/21480 の @kangfenmao によるインターフェース言語でトークン数をフォーマットします * 修正 (共有): https://github.com/CherryHQ/cherry-studio/pull/21486 の @ggbdpq による client 拒否を無効な API キーとして報告するのを停止 * fix(message-parent): https://github.com/CherryHQ/cherry-studio/pull/21466 の @focus-zyw により自分自身とクロストピックの親を拒否します * 修正(バックアップ-復元): セッションを分離し、https://github.com/CherryHQ/cherry-studio/pull/21385 の @kangfenmao により失敗した復元をクリーンアップ * 修正(検索): https://github.com/CherryHQ/cherry-studio/pull/21472 の @HHHSL で始まる行までのアンカー見出しストリップ正規表現 ## 新しい貢献者 * @xiajiahang が https://github.com/CherryHQ/cherry-studio/pull/21442 に初めて投稿しました * @HHHSL が https://github.com/CherryHQ/cherry-studio/pull/21472 に初めて投稿しました **フル Changelog**: https://github.com/CherryHQ/cherry-studio/compare/v2.1.5...v2.1.6 --- > **ソース** [CherryHQ/cherry-studio](https://github.com/CherryHQ/cherry-studio) · `v2.1.6` · 2026-10-11 · [アップストリーム リリース](https://github.com/CherryHQ/cherry-studio/releases/tag/v2.1.6) *インデックス作成のためにそのままミラーリングされます。すべての権利は上流プロジェクトに帰属します。*
