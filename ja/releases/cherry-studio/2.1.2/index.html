Release Notes / リリースノート

<詳細> <概要>英語</概要> Cherry Studio 2.1.2 - 安定性とユーザー エクスペリエンスの向上 ✨ 新機能

  • [モデル] oMLX を組み込みローカル プロバイダーとして追加します。ベース URL はプリセットされており、API キーは必要ありません。
  • [モデル] 国際 Moonshot コンソールのユーザー向けに Moonshot AI グローバル エンドポイントを追加します。
  • [設定] ごみ箱の名前を「アーカイブ」に変更し、レイアウトとナビゲーションが改善されたスタンドアロン設定ページに昇格しました。
  • [MCP] 組み込みの mcp-auto-install サーバーは、レジストリ キャッシュと設定の書き込みを Cherry の config ディレクトリ内に保持するようになりました。
  • [サインイン] CherryIN サインインは、システム カスタム プロトコル ハンドラーの代わりにローカル HTTP コールバックを使用するようになりました。
  • [エージェント] 分岐境界のリンクから元のチャットに戻ります。
  • [WebView] ブラウザ ペインの「ページに注釈を付ける」ピッカーは、一貫したアイコンを使用し、原色に従います。
  • [ペイント] モデルで宣言された maxInputImages をgenerate_image参照に使用します。 🐛 バグ修正
  • [サイドバー] Cliサイドバーでアプリのアイコンをクリックすると、別のタブにジャンプするのではなく、アクティブなタブが再び置き換えられます。
  • [サイドバー] すべてのリソースのショートカットをコンテキスト メニューから削除できるようになりました。
  • [設定] システムブラウザではなく内部ブラウ​​ザで開かれる設定、承認、請求、およびフィードバックのリンクを修正しました。
  • [設定] 英語の検索語で V2 セリフフォント設定が検索されるようになりました。
  • [エージェント] 長い DSH 会話をフォークする際のタイムアウトを修正しました。
  • [モデル] 古い D​​eepSeek モデルのリストを修正し、バンドルされたカタログと価格を更新します。
  • [モデル] 1 つのカタログ エントリの形式が不正な場合でも、有効な LM Studio モデルを保持します。
  • [ツール] コマンドルックアップがタイムアウトまたはエラーになった場合に失敗するスキルのインストール、スキルツールの依存関係チェック、および Windows バイナリ管理を修正しました。
  • [入力] AskUserQuestion の回答はラップして拡大し、カスタム メモが入力されたときに選択されたオプションを保持するようになりました。
  • [AI] ツールのパラメーターが数値またはブール列挙値を宣言すると、Gemini リクエストが HTTP 400 で失敗する問題を修正しました。
  • [AI] 組み込みブラウザ ツールが有効になっている場合に HTTP 400 で失敗する Gemini リクエストを修正しました。
  • [Markdown] レンダリングされた数式から KaTeX で引き伸ばされた記号 (平方根など) が消える問題を修正しました。
  • [マークダウン] 各ティックでの完全なマークダウンの再解析を回避することで、長いエージェント ストリーム中に UI の応答性を維持します。
  • [Markdown] 隣接する句読点を含むメモを保存した後に強調フォーマットが失われる問題を修正しました。
  • [Windows] エージェントセッションのトレース履歴が保存されない問題を修正しました。
  • [チャット] 編集オプションのないツールまたは MCP 呼び出しに関連する AI 応答を修正しました。テキストは編集可能になりました。
  • [プライバシー] データ収集を無効にした後も分析イベントが送信される問題を修正しました。
  • [macOS] Intel ビルドを実行している Apple Silicon ユーザーに、正しいエディションのダウンロード ページへのリンクを警告します。 </詳細> <詳細>
