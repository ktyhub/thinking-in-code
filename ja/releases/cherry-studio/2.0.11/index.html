Release Notes / リリースノート

<詳細> <概要>英語</概要> Cherry Studio 2.0.11 - 機能、修正、改善 ✨ 新機能

  • [Cherry Cloud] 資格を認識するエージェント モデル、ローカル ゲートウェイの自動起動、クォータを認識するモデルの選択、永続的な製品セッション処理を行うには、Cherry Cloud にサインインします。
  • [コンテキスト管理] 圧縮トリガーのしきい値をアシスタントごとに、または設定でグローバルに設定します。
  • [ミニアプリ] ドラッグ アンド ドロップ パッケージ、安定したタブとアイコン、透明な翻訳ビューとペイント ビューによるインストールとナビゲーションが改善されました。
  • [翻訳] 一方向のテキスト翻訳にはターゲット言語のみが必要になり、ソース言語の検出なしで開始されます。
  • [ファイル] ファイルリストで Ctrl+A (macOS では Cmd+A) を押して、現在のビュー内のすべてのファイルを選択します。
  • [翻訳] 1 つの click でメッセージの翻訳を削除するためのインライン削除ボタンを追加しました。
  • [サイドバー] 外観設定を使用してサイドバーからチャット アシスタントを非表示にし、最初に表示されるサイドバー アプリを直接起動します。
  • [エージェント] エージェント会話ツールバーにグローバル検索アクションを追加しました。
  • [モデル] Hy4 プレビュー、Ling 3.0 フラッシュ、および Qwen3.8 フラッシュのサポートを追加します。
  • [Anthropic キャッシュ] Anthropic 互換プロバイダーは、API 設定からプロンプト キャッシュを 1 時間保持できるようになりました。
  • [i18n] Cherry Studio 全体に初期のトルコ語ローカリゼーション サポートを追加しました。
  • [スクリーンショット] 選択四角形内のダブル click でキャプチャを確認します。 🐛 バグ修正
  • [エージェント セッション] 固定されたエージェント セッションはエージェント グループに残り、固定されていないセッションの前に表示されるようになりました。
  • [引用] 後のターンで再度参照されるナレッジ ベースと Web 検索の引用が、番号付き引用としてレンダリングされ、正しくエクスポートされるようになりました。
  • [WebDAV] WebDAV バックアップでは、デフォルトでサーバーの TLS 証明書が検証されるようになりました。サーバーが自己署名証明書を使用している場合は、「自己署名証明書を許可する」を有効にします。
  • [Web 検索] Web 検索はデフォルトでモデルネイティブ検索を優先し、設定されたサービスへの自動フォールバックが行われるようになりました。
  • [エクスポート] 画像を含むマークダウン エクスポートを修正しました。サイズの大きい埋め込みはスキップされ、フォルダー モードの画像は直接コピーされ、壊れたリンクは削除されます。
  • [バックアップ] ディスクがいっぱいでバックアップまたはリストアが失敗した場合に、使用可能なディスク容量が表示されます。
  • [チャット] 大きなチャット履歴でプロバイダーのすべてのモデルを削除すると、アプリが数秒間フリーズする問題を修正しました。
  • [PDF] 選択可能なテキスト、直接ページ ジャンプ、ドキュメント アウトラインを備えた PDF プレビューが改善されました。
  • [思考] ストリーミング中にタブを切り替えると思考時間が0から再スタートする問題を修正しました。
  • [移行] v1 から v2 への移行を修正し、マルチモデルの会話でコンテキストとして選択された応答が保持されるようにしました。
  • [トピック] アクティブな会話を削除すると、UI が削除された会話でスタックしたままになる可能性があるレースを修正しました。
  • [トピック] 会話がアシスタントごとにグループ化されている場合、固定された会話をアシスタント グループ内に保持します。
  • [Composer] セッションを切り替えた後、エージェントの入力ボックスに生のナレッジベースのプロンプト文が表示されることがある問題を修正しました。
  • [Composer] 長くペーストされたテキストは、デフォルトで再びプレーンテキストとしてペーストされます。 「長いテキストをファイルとして貼り付け」トグルが入力設定に戻りました。
  • [プロバイダー] プロバイダーのリクエスト構成ドロワーでカスタム リクエスト ヘッダーが削除できない問題を修正しました。
  • [プロバイダー] バージョン管理された GPT イメージ ID を持つ OpenRouter モデルでイメージ生成アイコンが表示されない問題を修正しました。
  • [プロバイダー] オプションの OpenRouter 推論モデルのオフ推論オプションを復元しました。
  • [プロバイダー] DashScope Responses エンドポイントの Qwen3.8 Flash および Max の推論労力オプションを修正しました。
  • [プロバイダー] TokenHub の「Get API key」リンクを API キー管理ページにポイントします。
  • [モデル] プリザーブ花火君 Fast と Turbo のバリエーション。
  • [モデル] アシスタントのサンプリング設定が有効になっている場合に、Kimi K2.5 以降のリクエストが失敗する問題を修正しました。
  • [チャット] アシスタントのメッセージに対する一貫性のない編集アクションが修正され、テキスト付きのすべてのアシスタントの返信が均一に編集可能になりました。
  • [チャット] 会話ヘッダーからモデルを切り替えると、次のメッセージが以前に選択したモデルにルーティングされたままになる可能性がある競合を修正しました。
  • [チャット] 明示的な言語名を使用して選択した言語で会話タイトルを要求することにより、自動会話タイトルが改善されました。
  • [チャット] 出典と一致しない引用マーカーは、回答内に生の [cite:...] テキストとして表示されなくなりました。
  • [チャット] アプリが終了する前にキャンセルされた実行について、スケジュールされたタスク カードが永久に「実行中」と表示される問題を修正しました。
  • [チャット] v1 から移行されたエージェントでエージェントのハートビートの切り替えが無視される問題を修正しました。
  • [チャット] 右側のリストが左側のリストと同じ幅で開き、独自の幅を記憶していた問題を修正しました。
  • [チャット] 大きなアシスタントとエージェントのリソース セレクターでのフォーカスの応答性が向上しました。
  • [チャット] タブを切り替えても安定して思考が経過します。
  • [Markdown] equation や aligned などのスタンドアロン LaTeX 環境のレンダリングを修正しました。
  • [Markdown] ノートエディターで列を挿入またはサイズ変更した後、テーブル列が古い固定幅を維持する問題を修正しました。
  • [ミニアプリ] チャットまたはファイルのエクスポートに null オプションを渡しても、予期しないエラーで拒否されなくなりました。
  • [ミニアプリ] ミニアプリのタブアイコンには固定の25ピクセルサイズを使用します。
  • [ミニアプリ] マネージド DeepSeek Harness セッションは、開始時または再起動時にシステム ブラウザーを開かなくなりました。
  • [ミニアプリ] 不正な HTML アーティファクト プレビュー内のリンクは、プレビュー フレーム内を移動できなくなりました。
  • [MCP ブラウザ] Windows 上の MCP ブラウザ ウィンドウ コントロールとタブ バー アクションを復元しました。
  • [ナレッジ] Reindex は実際のソースからファイルを再取得するようになりました。
  • [ファイル] 複数のファイルをコンポーザーに貼り付けても、1 つのファイルの読み取りに失敗したときに残りのファイルがドロップされることがなくなりました。
  • [ペイント] 送信ボタンを無効にする未解決のモデル参照を残すペイント マイグレーターを修正しました。
  • [サイドバー] 新規インストールではエージェントが最初に開き、チャットの前に配置されるようになりました。既存のユーザーは保存された順序を保持します。 ⚡ パフォーマンス
  • [エクスポート] 多くの Web/ナレッジ検索を伴う長いトピックのエクスポートまたは分析の速度が二次関数的に低下することがなくなりました。
  • [ファイルプレビュー] ファイルのメタデータをチェックしながら、サポートされているプレビューモジュールをロードすることで、ファイルプレビューの起動時間を改善しました。 </詳細> <詳細>
