#チェリースタジオv1.5.10

何が変わったのか

  • https://github.com/CherryHQ/cherry-studio/pull/9772 の @MengXiangxi によって不足している引用符を追加
  • 功績: @rien7 によるサイドバーのアニメーションを https://github.com/CherryHQ/cherry-studio/pull/9768 に追加
  • 読み込み状態ブロックの入力を削除し、https://github.com/CherryHQ/cherry-studio/pull/9513 に @oyasumiaiko による「失敗したメッセージを再試行」ボタンを追加
  • https://github.com/CherryHQ/cherry-studio/pull/9777 の @co63oc によるタイプミスのグラップギャップを修正
  • リファクタリング: https://github.com/CherryHQ/cherry-studio/pull/9775 の @beyondkmp による system-ocr の Linux ビルドを改善
  • 偉業: https://github.com/CherryHQ/cherry-studio/pull/9752 の @kovsu により、リンクされたOG データを解析し、プレビュー コンテンツに追加します。
  • 雑務: https://github.com/CherryHQ/cherry-studio/pull/9794 の @beyondkmp による vite を 7.1.5 まで更新
  • 雑用: https://github.com/CherryHQ/cherry-studio/pull/9792 の @beyondkmp による TypeScript 構成とスクリプトの更新
  • 修正: Gemini 2.5 フラッシュ イメージ モデルのイメージ生成ボタンの自動有効化 (https://github.com/CherryHQ/cherry-studio/pull/9787 の @yyhhyyyyyy による)
  • 修正: https://github.com/CherryHQ/cherry-studio/pull/9780 の @kovsu によるタブの高さが不十分なため、境界線スタイルが親要素を占有しない問題が発生しました。
  • chore(移行): バージョン 145 の移行ロジックを更新し、https://github.com/CherryHQ/cherry-studio/pull/9805 の @teojs による showMessageOutline のデフォルトを強制します
  • 雑務: https://github.com/CherryHQ/cherry-studio/pull/9808 の @EurFelux による Yarn.lock の更新
  • refactor(CodeViewer): https://github.com/CherryHQ/cherry-studio/pull/9786 の @alephpiece によって CodeEditor に合わせてプロパティを改善します。
  • 修正: https://github.com/CherryHQ/cherry-studio/pull/9809 の @alephpiece によるドラッグ可能なリスト ID タイプ
  • 功績: https://github.com/CherryHQ/cherry-studio/pull/9815 の @beyondkmp による KnowledgeFiles コンポーネントにファイル選択とアップロード機能を統合
  • refactor(electron.vite.config.ts): 外部依存関係を合理化し、https://github.com/CherryHQ/cherry-studio/pull/9835 の @beyondkmp によるビルド構成を改善
  • https://github.com/CherryHQ/cherry-studio/pull/9831 の @co63oc によるタイプミスを修正
  • fix(Markdown): https://github.com/CherryHQ/cherry-studio/pull/9839 の @alephpiece によるスタイルの正規表現
  • 修正: https://github.com/CherryHQ/cherry-studio/pull/9821 の @thericardoli による複数のインストール方法に対する Obsidian Vault の検出を強化
  • 修正: https://github.com/CherryHQ/cherry-studio/pull/9800 の @alephpiece による iframe 内のアニメーションとフォントのキャプチャ
  • リファクタリング: https://github.com/CherryHQ/cherry-studio/pull/9814 の @Pleasurecruise により showWorkspace 設定をグローバル設定からメモ モジュールに移行
  • リファクタリング: https://github.com/CherryHQ/cherry-studio/pull/9841 の @alephpiece によるツールチップ アイコン
  • 修正: https://github.com/CherryHQ/cherry-studio/pull/9852 の @vaayne による syncModelScopeServers 関数の正しいプロバイダー URL フォーマット
  • 功績: https://github.com/CherryHQ/cherry-studio/pull/9817 の @DeJeune により、ログ機能を備えた RichEditor を強化し、NotesPage エディターの同期を改善しました。
  • 修正: https://github.com/CherryHQ/cherry-studio/pull/9850 の @EurFelux による json による mcp 追加時の変換パラメーター
  • 修正: NavigationService の初期化タイミングの問題と、https://github.com/CherryHQ/cherry-studio/pull/9700 の @Pleasurecruise によるタブ ドラッグの並べ替えを追加
  • リファクタリング(mcp): https://github.com/CherryHQ/cherry-studio/pull/9865 の @EurFelux によるストリーミング可能な http タイプの mcp サーバーを検出するには、includes http を使用します。
  • 修正(翻訳): https://github.com/CherryHQ/cherry-studio/pull/9867 の @EurFelux による間違ったコピー ボタンの状態
  • 修正: https://github.com/CherryHQ/cherry-studio/pull/9871 で @kovsu によって手動ブラックリストを更新するときの正規表現パターン エラー
