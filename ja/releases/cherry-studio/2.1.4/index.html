<summary>Release Note</summary> Cherry Studio 2.1.4 - 新しいモデル、デバイス接続、およびバグ修正 ✨ 新機能 - [デバイス接続] IPv4/IPv6 サポート、自動アドレス優先順位付け、ネットワーク インターフェイスによる手動選択を備えた、到達可能な LAN または外部設定された VPN ネットワーク経由で接続します。必要なアクション: 互換性のあるモバイル アプリに更新して、追加のアドレスを保存して確認し、16 個を超えるアドレスを含むペアリング コードをスキャンします。 - [メッセージ] 複数選択アクション バーにエクスポートを追加: 選択したメッセージを Markdown、Word、または Notion/Yuque/Obsidian/Joplin/Siyuan としてエクスポートします。 - [モデル] 価格設定と推論設定を含む、OpenAI および OpenAI Codex の GPT-6.1 Sol サポートを追加します。 - [モデル] 思考制御とネイティブ Web ツールの資格を備えた Claude Sonnet 5.5 および Opus 5.5 を追加します。 - [モデル] Claude Code プロバイダーは、Claude Opus 5.5 (高速モード付き) と Claude Fable 5.1 を提供するようになりました。 - [モデル] 5 つの推論努力レベルを備えた MiniMax M3.1 フラッシュ プレビューを追加します。 - [ComfyUI] ローカル ComfyUI イメージ プロバイダーを追加します。保存されたワークフローをモデルとして選択し、ペイント ページから生成します。 - [Launchpad] 組み込みアプリのタイルでテーマに対応したカード表面が使用されるようになりました。 🐛 バグ修正 - [エージェント] 以前のクロード コード プロセスの終了が遅い場合にエージェント セッションが使用できなくなる問題を修正しました。 - [エージェント] 新しく作成されたリモート エージェント セッションで繰り返されるメッセージの競合と古いタイトルを修正しました。 - [エージェント] 編集と再送信時のチェックポイント エラー メッセージを修正 - 問題を明確に説明するようになりました。 - [エージェント] 削除に成功した後にリストに残るエージェント セッション メッセージを修正しました。 - [エージェント タスク] 孤立したスケジュールとともに未使用のハートビート ワークスペースを再利用します。 - [チャット] 間違ったプロバイダーを使用して再生成する問題を修正 - コンポーザーの選択を使用するようになりました。 - [チャット] 返信自身のモデルではなくアシスタントのデフォルト モデルを使用したマルチモデル グループの再試行を修正しました。 - [チャット] 開いたときにアーカイブの取り消しを介して復元された会話が飛び出す問題を修正しました。 - [チャット] ツール呼び出しパネルが思考パネルと同じビューポート対応の高さを使用していない問題を修正しました。
