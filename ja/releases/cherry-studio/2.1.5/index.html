<summary>Release Note</summary> Cherry Studio 2.1.5 - リモートアタッチメント、チャンネル、および主要な改良点 ✨ 新機能 - [リモート アクセス] ペアリングされたモバイル デバイスからリモート エージェント セッションに画像とファイルをアップロードします。転送はファイルごとに最大 1 GiB まで再開できます。 - [チャネル] QR セットアップ、エージェントの会話、ストリーミング応答、通知、添付ファイルを備えた WeCom および DingTalk チャネルを追加します。 - [MCP] チャットとエージェントのランタイム全体で対話型リクエスト、検証済みフォーム、キャンセル、構造化された結果を備えた MCP SDK v2 をサポートします。 - [エージェント] ネイティブのサンドボックス コード モードと MCP サポートを備えた Pi ランタイムを 1.0 にアップグレードします。必要なアクション: カスタム Pi スクリプトをネイティブ コードモード API に更新します。 - [Doctor] System Doctor は、診断レポートを読み取り、適用および元に戻すことができる制限付きの修正を提案する AI 分析セクションを獲得します。 - [デバイス接続] プラットフォーム固有のダウンロード、進行状況の記憶、自動モバイル プレビューにより、モバイル オンボーディングが向上します。 - [ペイント] 生成後のプロンプトドックを最小化し、生成された画像をマウスホイールでズームし、click で共有画像ビューアを開きます。 - [モデル] 推論制御、更新されたトークン制限、価格、およびクロード コードの可用性を備えた Claude Haiku 5.5 サポートを追加します。 - [コンポーザー] 現在のチャットまたはエージェント セッションで MCP ツールが有効になっている場合、MCP ツールバーのショートカットを強調表示します。 - [Web 検索] 構成可能な API ホストとオプションのベアラー トークンを使用して、セルフホスト型 Crawl4AI を URL フェッチ プロバイダーとして追加します。 - [Windows] カスタム タイトル バーとテーマの適応を維持しながら、メイン ウィンドウと分離ウィンドウでネイティブ キャプション ボタンを使用します。 - [更新] 互換性のあるキャッシュされたインストーラーが利用可能な場合、ネイティブの差分ダウンロードを有効にして更新サイズを削減します。 - [ファイル プレビュー] タッチ ズーム、弾力性のある PowerPoint スライド、およびより明確なサイズ制限フォールバックにより、ドキュメント プレビューが改善されました。モバイル統合のための WebView 互換性を追加します。 - [アーカイブ] エージェントを復元すると、そのセッションも復元され、アーカイブされたタスク/トピック行には、その所有エージェントまたはアシスタントが表示されます。 🐛 バグ修正 - [エージェント] アクティブなタスク中にセッションを切り替えたりタブを閉じたりするときのブラウザツールのタイムアウトを修正しました。 - [エージェント] ツールの出力と間違われるツール拒否の理由を修正 - ユーザーの言葉として明示的に表示されるようになりました。 - [チャット] すでにストリーミングされたコンテンツを破棄する応答途中のエラーを修正 - エラーと一緒に保存されるようになりました。 - [チャット] アシスタントメッセージ内にコンテキスト圧縮の進行状況が表示されない問題を修正。 - [チャット] 以前のチャット履歴への上向きスクロールをブロックする水平マルチモデル回答を修正しました。 - [ComfyUI] 実行ごとに同じ画像をレンダリングするランダム化シードを使用したワークフローを修正しました。 - [ComfyUI] プロバイダーの API キーがないと失敗するパートナー (API) ノードを修正し、正しく送信されるようになりました。 - [ComfyUI] ワークフローが間違った値で変換されたり、no_prompt_node で失敗したりする問題を修正しました。 - [通知] トピックまたはセッション名と最後の文を表示する完了通知を修正しました。 - [通知] すべての通知設定がオフになっている場合、macOS Dock バッジを消去します。 - [Markdown] 単一セグメントのスラッシュラン (`/jX_s` など) をファイル パスとしてリンクするのを停止します。 - [WebView] ネイティブ ユーザー エージェントを Google サインインに制限し、AI Studio やその他のリクエスト用にクリーンな UA を保持します。 - [Open Responses] 互換性のあるゲートウェイがマークされた SSE キープアライブ デルタを発行するときに失敗する会話を修正しました。 - [バックアップ] 宛先が Windows ドライブのルートである場合に失敗するローカル バックアップを修正しました。 - [チャンネル] 保存された WeChat 認証情報の不正な形式のユーザー ID によって引き起こされるチャンネル設定のレンダリング エラーを修正しました。 - [ツール] 組み込みコード CLI
