<summary>Release Note</summary> Cherry Studio 2.2.3 - 会話の並べ替え、新しいモデル、エージェントの信頼性 ✨ 新機能 - [会話] グループ化と並べ替えが独立しました。最終更新日、作成日、名前 (自然数順)、または手動順序で並べ替えると、既存のカスタム順序が保持されます。 - [エージェント] インポート DeepSeek v3 エクスポートは、自動的に作成された DeepSeek エージェントにエクスポートされ、履歴、分岐、推論、検索レコード、および利用可能な添付ファイルが保持されます。 - [エージェント] 返信後に短い次のプロンプトが表示されます。Tab キーを押して送信せずに受け入れるか、Esc キーを押して無視します。入力設定で提案をオフにすることができます。 - [エージェント] エージェント作成時に画像アバターをアップロードできます。 - [エージェント] 自動コマンド承認は、共有リスク ルールを使用して Bash と PowerShell を解析し、危険なコマンドの前に質問するようになりました。承認カードには、要求元のタスク、作業ディレクトリ、および理由が表示されます。 (アクションが必要です: 既存のプロンプトに依存している場合は、アクセス許可モードを確認してください。フル アクセスでは必須の拒否が引き続き適用されますが、一致しないコマンドは自動的に実行されます。) - [ブラウザ] 会話サイドバーは、統一されたスタイルとコンテキスト メニューを備えた複数の保持されたタブをサポートし、設定されたホームページを使用し、最後のページで閉じます。 - [ファイル プレビュー] PPTD スライド デッキは、ページ ナビゲーション、ズーム、サムネイル、更新、ソース ビューを使用してアプリでプレビューできるようになりました。 - [ファイル] 行番号付きのファイル パスとマークダウン リンクは、プレビュー内の参照行にジャンプし、強調表示されます。 - [ファイル] ファイル選択ダイアログは、現在のセッション中に選択した最後のファイルのフォルダーで開きます。 - [チャット] 外観 → メッセージ設定「送信時に最新のメッセージまでスクロールする」(デフォルトでオン) を追加しました。 - [チャット] 長い成果物ファイル リストには最初の 3 つのファイルが表示され、残りのファイルを展開または折りたたむことができます。 - [チャット] Ctrl + マウス ホイールでインターフェースをズームし、スクロール中にズーム レベルを表示し、Ctrl + 0 でリセットします。 - [知識] URL ソースは、一度に複数のリンク (改行、カンマ、またはスペースで区切られる) を受け入れ、有効な URL を個別に追加し、無効なエントリを個別に報告します。 - [絵画] 生成された画像にはモデルと返されたサイズが表示され、常に PNG に変換されるのではなく、元の形式で保存されます。 - [コンピュータの使用] Linux 専用の新しい「グローバル入力」スイッチ (デフォルトではオフ) により、エージェントは共有マウス ポインタとシステム キーボードを制御できます。 - [モデル] GPT-6.2 Astra および Sol、Gemini 4 Carbon および Hydrogen (推論コントロール付き)、Tencent Hunyuan 4 Flash、および Mistral Large 4 推論コントロールを追加しました。 - [モデル] DeepSeek のファーストパーティのコスト見積もりでは、カスタム価格を維持しながら、平日のピーク料金とオフピーク料金を使用するようになりました。 (要対応: ピークのみの見積もりに依存している場合は、ローカルのコスト見積もりを確認してください。) - [モデル] 有効なプロバイダーがモデル サービス リストの最初に表示されるようになり、プライマリ モデル ピッカーは記憶されたダイアログ モードで開くことができます。 - [マーケットプレイス] 検索と水平カテゴリ ナビゲーションを使用して、厳選されたスキルをカテゴリ別にフィルタリングできます。 - [Composer] コピーしたフォルダーをエージェントの会話に貼り付けると、ファイルの添付が失敗する代わりにフォルダー参照が追加されます。 - [エクスポート] Obsidian エクスポートでは、各アシスタント メッセージに、それを生成したモデルのラベルが付けられます。 - [ショートカット] 番号のショートカット (1 ～ 9) には、[設定] → [ショートカット] で明示的にオフのプリセットがあります。 - [音声] 認識モデルに、保存された言語やホットキーを削除せずにローカルのディクテーションを無効にするオフ オプションが追加されました。 - [コード CLI] Qwen コード 1.0 は、GitHub リリースからインストール可能です。 - [アプリ] チェコ語 (cs-CZ) 言語のサポートを追加しました。 🐛 バグ修正 - [チャット] コード プレビュー、エディター、埋め込みアーティファクトなどのネストされたスクロール可能なコンテンツは、メッセージ リストのスクロール中に独立してスクロールします。 - [チャット] 設定 → アーカイブから復元された会話は、空の会話ではなくメッセージとともに開きます。 - [チャット] 中断されたストリーミング応答は、無効な AI 応答ではなく、部分的な出力が再試行のために保持される接続エラーとして報告されます。 - [チャット] マルチモデルの折りたたみタブにすべてのモデル名が再び表示され、コンパクトなタブに戻ります。 - [チャット] モデル コンテキスト ウィンドウを超えるチャット リクエストがより確実に回復されます。 - [Notes] \[ … \] と \( … \) で書かれた LaTeX は、Notes エディターで再度レンダリングされます。 - [チャット] ブラウザのサイドパネルのサイズ変更バーは、高さ全体に沿ってドラッグできます。 - [エージェント] ツールの呼び出し前または呼び出しの間に発行されたアシスタントのテキストが、エージェント セッションで再び表示されます。 - [エージェント] Pi Durable: Stop はセッションを開いたままにし、応答を一時停止します。終了後に再度開くと、中断された応答が継続されるか、実際の結果が表示されます。エージェントの作業中に送信されたメッセージは保存され、順番に応答されます。取り消されたメッセージには、再送信と編集で「送信前に停止」のマークが付けられます。 - [エージェント] ターンの実行中に送信されたメッセージは、黙って無視されるのではなく、確認されて処理されます。 がコンテキストを保持できる場合、ツールの再試行または圧縮後にフォークまたは編集できます。 - [エージェント] 編集受け入れモードでは、クロード コードは、エスカレーションされた Bash コマンドを最初の単語で自動実行するのではなく、実行する前に質問します。 - [エージェント] エージェントのセッション履歴により、アップグレード中にメッセージ ツリーが修復され、実行中の配信の編集が防止されます。 - [エージェント] ディレクトリが永続ストア名を占有すると、ネットワーク エラーで失敗するのではなく、エージェント ターンが回復します。 - [エージェント] 履歴メッセージの編集および再送信時に、推論作業、サービス層、および高速コントロールは引き続き利用可能です。 - [エージェント]
