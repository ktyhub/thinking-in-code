LlamaFactory v0.8.0

マイナー 公開日2024年6月7日 出典hiyouga/LlamaFactory 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#ラマファクトリーv0.8.0

より強力な ラマボード 💪😀

  • Web UI での単一ノード分散トレーニングのサポート
  • チェックポイントから簡単に再開し、#4053 の @hiyouga と @hzhaoy によって保存された構成を選択するためのドロップダウン メニューを追加しました。
  • フル/フリーズチューニングのチェックポイント選択をサポート
  • #4066 の @injet-zhou によりスループット メトリクスを LlamaBoard に追加
  • UIの読み込みが高速化

新機能

  • @enji-zhou による KTO アルゴリズムを #3785 に追加
  • @hiyouga による SimPO アルゴリズムを追加
  • #3794 の @jue-jue-zi による vLLM バックエンドへの max_lora_rank の受け渡しをサポート
  • sharegpt 形式の設定データセットをサポートし、#3799 の @hiyouga により git リポジトリから大きなファイルを削除します
  • #3812 の @ycjcl868 による CLI 推論でのシステム メッセージの設定をサポート
  • @seanzhang-zhichen による #3829 で dataset_info.json に num_samples オプションを追加
  • @dongdongqiang2018 による NPU docker 画像を #3876 に追加
  • #3930 の @MengqingCao による NPU ドキュメントの改善
  • #4009 の @AlongWY による貪欲なナップザック アルゴリズムによる SFT パッキングをサポート
  • バグレポート用にllamafactory-cli envを追加
  • APIモードでの画像入力をサポート
  • train_from_scratch 引数によるランダム初期化のサポート
  • CIの初期化

新モデル

  • ベースモデル
    • Qwen2 (0.5B/1.5B/7B/72B/MoE) 📄
    • PaliGemma-3B (ポイント/ミックス) 📄🖼️
    • GLM-4-9B 📄
    • ファルコン-11B 📄
    • DeepSeek-V2-Lite (16B) 📄
  • モデルの指導/チャット
    • Qwen2-命令 (0.5B/1.5B/7B/72B/MoE) 📄🤖
    • ミストラル-7B-指示-v0.3 📄🤖
    • Phi-3-small-8k-instruct (7B) 📄🤖
    • アヤ-23 (8B/35B) 📄🤖
    • オープンチャット-3.6-8B 📄🤖
    • GLM-4-9B-チャット 📄🤖
    • #3958 の @hzhaoy による TeleChat-12B-Chat 📄🤖
    • Phi-3-medium-8k-instruct (14B) 📄🤖
    • DeepSeek-V2-Lite-チャット (16B) 📄🤖
    • コードストラル-22B-v0.1 📄🤖

新しいデータセット

  • 事前トレーニングデータセット
    • FineWeb (英語)
    • FineWeb-Edu (英語)
  • 教師付き微調整データセット
    • Ruozhiba-GPT4 (zh)
    • STEM 命令 (zh)
  • 好みのデータセット
    • Argilla-KTO-mix-15K (en)
    • ウルトラフィードバック (英語)

バグ修正

  • マルチモーダル微調整のための RLHF を修正
  • #3835 の @BUAADreamer によるマルチモーダル微調整での LoRA ターゲットを修正
  • #3925 の @Yimi81 による yi テンプレートを修正
  • #3987 の @injet-zhou による LlamaBoard の中止問題を修正
  • #4006 で @Uminosachi により scheduler_specific_kwargs を get_scheduler に渡します
  • #4007 の @xu-song によるハイパーパラメータの修正ヘルプ
  • #4011 の @statelesshz による問題テンプレートの更新
  • vllm dtype パラメータを修正
  • #4080 の @MengqingCao によるハイパーパラメータのエクスポートを修正
  • PPO トレーナーの DeepSpeed ZeRO3 を修正
