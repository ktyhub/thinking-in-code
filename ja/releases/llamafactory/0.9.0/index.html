#ラマファクトリーv0.9.0

スター 30,000 個おめでとうございます 🎉 X (twitter) でフォローしてください

新機能

  • 🔥 #5290 の @simonJJJ によるマルチ画像データセットの Qwen2-VL モデルの微調整をサポートします
  • 🔥@hiyouga による enable_liger_kernel 引数を介して、時間とメモリ効率の高い Liger-Kernel をサポートします
  • 🔥 #5095 の @relic-yuexi による use_adam_mini 引数を介して、メモリ効率の高い Adam-mini オプティマイザーをサポートします
  • @hiyouga (#5365) および @BUAADreamer (#4136) によるビデオ データセットの Qwen2-VL モデルの微調整をサポート (パッチ https://github.com/huggingface/transformers/pull/33307 が必要)
  • @hiyouga による RLHF/DPO/ORPO/SimPO アプローチを使用したビジョン言語モデル (VLM) の微調整のサポート
  • use_unsloth_gc 引数を介した Unsloth の非同期アクティベーション オフロード メソッドをサポート
  • vLLM 0.6.0 バージョンをサポート
  • #5388 の @yzoaim による MFU 計算をサポート

変更点

  • 互換性を考慮して、ビジョン言語モデル (VLM) の微調整には transformers>=4.35.0.dev0 が必要です。pip install git+https://github.com/huggingface/transformers.git をインストールしてみてください。
  • visual_inputs は非推奨になったため、この引数を指定する必要はなくなりました。
  • LlamaFactory はマルチモーダル入力の遅延読み込みを採用するようになりました。詳細については #5346 を参照してください。データセットの前処理でバッチ サイズを制限するには、preprocessing_batch_size を使用してください ( #5323 の @naem1023 によってサポートされています)。
  • LlamaFactory は、ショートカット コマンドとして lmf (llamafactory-cli と同等) をサポートするようになりました。
