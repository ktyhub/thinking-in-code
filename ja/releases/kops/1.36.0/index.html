kops v1.36.0

#コップv1.36.0

重大な変更や非推奨を含む詳細については、完全な kOps 1.36 release notes を参照してください。

ハイライト

  • Kubernetes 1.36 のサポート およびツリー内クラウド プロバイダーからの移行の完了
  • アドオン管理の見直し: kops-channels はコントロール プレーン ノード上で静的ポッドとして実行されるようになりました。スタンドアロンの channels バイナリは配布されなくなりました
  • ゴシップ クラスター用のハイブリッド ブートストラップ: ワーカーは API ロード バランサーに対して直接ブートストラップし、非推奨となったゴシップ DNS からの移行を容易にします。
  • Karpenter の更新: インスタンス グループごとの kOps 管理の EC2NodeClass および NodePool オブジェクトを含む Karpenter v1.13.0
  • etcd-manager の改善: データ ディスクを交換したメンバーのリカバリ、到達不能なメンバーに対する回復力のあるメンバーシップの変更、ディストロレス イメージ、および単一メンバー クラスターの起動の高速化
  • 拡張された Azure サポート: クラウド コントローラー マネージャー、Azure ディスク CSI ドライバー、および実験的な Terraform ターゲット
  • Hetzner Cluster Autoscaler サポート および新しいクラウド プロバイダーとしての Linode (Akamai) の基礎
  • コンポーネントの更新: コンテナー v2.2.4、etcd マネージャー v3.0.20260707 (etcd 付き) 3.5.31/3.6.12、AWS ロード バランサー コントローラー v3.3.0、Cilium チューナブル、CoreDNS v1.14.2、クラスター オートスケーラー v1.36.0
  • 削除: Kubernetes 1.30、etcd 3.4、Amazon Linux 2、Ubuntu 20.04、および Debian 10 のサポート

何が変わったのか

  • #18484 の自動チェリーピック: gce: https://github.com/kubernetes/kops/pull/18488 の @rifelpet による kops.k8s.io/instancegroup ノード ラベルの発行
  • #18478 の自動チェリーピック: nodeup: ip_set モジュールをロードし、https://github.com/kubernetes/kops/pull/18492 の @rifelpet により RHEL10 で firewalld を無効にします
  • #18498 の自動チェリーピック: https://github.com/kubernetes/kops/pull/18499 の @rifelpet による DO ClusterRole からの名前空間の削除
  • #18511 の自動チェリーピック: https://github.com/kubernetes/kops/pull/18512 の @hakman によるコマンドラインから欠落しているスライス要素を設定できるようにする
  • ##18479 の自動チェリーピック: Karpenter を v1.13.0 にアップグレード ##18486: Karpenter.sh/unregistered taint を使用して Karpenter ノードを登録する ##18487: 不足している EC2 読み取り権限を Karpenter IAM ポリシーに追加します ##18497: マネージド Karpenter EC2NodeClass と NodePool を @hakman により https://github.com/kubernetes/kops/pull/18513 に追加
