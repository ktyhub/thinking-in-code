#コップv1.36.2

何が変わったのか

  • #18636 の自動チェリーピック: azure: https://github.com/kubernetes/kops/pull/18637 の @hakman による Terraform プロバイダー azurerm v5 のサポート
  • #18638 の自動チェリーピック: hcloud-go/v2 を最新バージョン (v2.47.0) に更新 (https://github.com/kubernetes/kops/pull/18639 の @hakman により)
  • #18641 の自動チェリーピック: ローリング更新: https://github.com/kubernetes/kops/pull/18643 の @hakman によるポッドエビクションの再試行間の遅延を 5 秒に戻す
  • #18642 の自動チェリーピック: aws: https://github.com/kubernetes/kops/pull/18644 の @hakman によってプライマリ ネットワーク インターフェイスを「Unmanaged=yes」に設定しないでください
  • #18645 の自動チェリーピック: etcd-manager: https://github.com/kubernetes/kops/pull/18646 の @hakman による使用時に kops-utils-cp イメージを計算
  • #18649 の自動チェリーピック: aws: https://github.com/kubernetes/kops/pull/18652 の @rifelpet によるすべての k8s バージョンのデフォルトは AWS CCM v1.36.1
  • #18657 の自動チェリーピック: fix(channels): https://github.com/kubernetes/kops/pull/18659 の @hakman による既知の準備完了状態のみを健康シグナルとして扱う
  • #18655 の自動チェリーピック: https://github.com/kubernetes/kops/pull/18673 の @hakman によるルート ボリュームの EC2NodeClass ブロック デバイス マッピングの生成
  • @hakman による 1.36.2 を https://github.com/kubernetes/kops/pull/18674 でリリース
