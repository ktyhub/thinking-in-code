kops v1.37.0-beta.1

#コップv1.37.0-beta.1

重大な変更や非推奨を含む詳細については、完全な kOps 1.37 release notes を参照してください。

何が変わったのか

  • ドキュメント: https://github.com/kubernetes/kops/pull/18592 の @hakman による 1.36 release notes の更新
  • 修正: https://github.com/kubernetes/kops/pull/18595 の @hakman による kops delete cluster のクラウド リソースのリストを再試行します
  • ハック: GitHub リリース プロモーションを並列化し、https://github.com/kubernetes/kops/pull/18594 に @hakman によるチェックサム検証を追加
  • feat(linode): VPC モデルをより広範なネットワーク モデルにリファクタリングし、https://github.com/kubernetes/kops/pull/18590 の @moshevayner によるサブネット タスクを追加します。
  • 雑用: https://github.com/kubernetes/kops/pull/18598 の @hakman による Kubernetes 1.31 のサポートを削除
  • ドキュメント: @hakman による https://github.com/kubernetes/kops/pull/18599 のリリース後に 1.36 release note を更新
  • ノードアップ: https://github.com/kubernetes/kops/pull/18600 で @hakman によってオーセンティケーター構成をクリアするときにクラスター仕様を変更しないでください。
  • Azure: https://github.com/kubernetes/kops/pull/18604 の @hakman により、kindnet ポッド CIDR が kube-apiserver に到達することを許可します。
  • https://github.com/kubernetes/kops/pull/18609 の @hakman による gsutil を gcloud storage に置き換えます
  • build(deps): https://github.com/kubernetes/kops/pull/18611 の @dependabot[bot] によるアクション/セットアップを 6.5.0 から 7.0.0 にバンプします。
  • https://github.com/kubernetes/kops/pull/18612 の @YahiaBadr による gce に適切なコントロール プレーン マシンを追加
  • https://github.com/kubernetes/kops/pull/18614 の @Jefftree による検証中に準備ができていないノードの数を指定できるようにする
  • 雑務(ネットワーキング): https://github.com/kubernetes/kops/pull/18615 の @moshevayner により aws-cni を v1.22.3 にバンプします
  • https://github.com/kubernetes/kops/pull/18616 の @Jefftree によるスケーラビリティ テスト検証中に準備ができていないノードを許容する
  • aws: https://github.com/kubernetes/kops/pull/18617 の @hakman による API のクラシック ロード バランサーのサポートを削除
  • 雑務(チャネル): https://github.com/kubernetes/kops/pull/18621 の @moshevayner によるアルファチャネルでの k8s と Ubuntu AMI のバージョンのバンプ
  • build(deps): https://github.com/kubernetes/kops/pull/18626 の @dependabot[bot] による 7.0.0 から 7.0.1 へのアクション/チェックアウトのバンプ
  • gce: コントロール プレーン ノード エクスポーター ポート (tcp/9100) を開く (https://github.com/kubernetes/kops/pull/18620 の @Jefftree による)
  • aws: https://github.com/kubernetes/kops/pull/18632 の @hakman による IP ベースのノード名のオプションを追加
  • aws: https://github.com/kubernetes/kops/pull/18630 の @hakman により、共有サブネットがゾーンを省略できるようにします
  • hetzner: https://github.com/kubernetes/kops/pull/18631 の @krillerdk によるロード バランサーを比較するときに WellKnownServices を無視する
  • https://github.com/kubernetes/kops/pull/18635 の @michaelasp により、kops の kindnet での nri マウントを有効にします
  • azure: Terraform プロバイダー azurerm v5 をサポート (https://github.com/kubernetes/kops/pull/18636 の @hakman 氏)
  • hcloud-go/v2 を最新バージョン (v2.47.0) に更新 (https://github.com/kubernetes/kops/pull/18638 の @krillerdk)
  • gce: https://github.com/kubernetes/kops/pull/18623 の @hakman によるカールを使用してプライベート GCS バケットからノードアップをダウンロードします
  • aws: https://github.com/kubernetes/kops/pull/18642 の @hakman によってプライマリ ネットワーク インターフェイスを「Unmanaged=yes」に設定しないでください
  • ローリング更新: https://github.com/kubernetes/kops/pull/18641 の @hakman によるポッドエビクションの再試行間の遅延を 5 秒に戻す
  • https://github.com/kubernetes/kops/pull/18601 の @hakman によるゴシップ DNS のサポートを削除
  • etcd-manager: https://github.com/kubernetes/kops/pull/18645 の @hakman による使用時に kops-utils-cp イメージを計算します
  • chore(channels): https://github.com/kubernetes/kops/pull/18647 の @moshevayner によるアルファを安定したチャンネルにプロモートします
  • aws: すべての k8s バージョンのデフォルトは AWS CCM v1.36.1 (https://github.com/kubernetes/kops/pull/18649 の @rifelpet による)
  • 雑務(ネットワーキング): https://github.com/kubernetes/kops/pull/18648 の @moshevayner によって aws-cni をバージョン 1.22.4 にバンプします
  • https://github.com/kubernetes/kops/pull/18650 の @hakman によるゴシップの残り物を削除
  • https://github.com/kubernetes/kops/pull/18653 の @hakman による prookube バイナリを削除
  • ドキュメント: kOps 1.37 でのゴシップの削除と、https://github.com/kubernetes/kops/pull/18651 での @hakman による移行ガイド
  • https://github.com/kubernetes/kops/pull/18654 の @hakman による実際のコンシューマーに対するインスタンスのクラウド権限の制限
  • https://github.com/kubernetes/kops/pull/18656 の @hakman による狭いインスタンスの説明権限
  • https://github.com/kubernetes/kops/pull/18658 の @hakman によるゴシップ削除の残り物をクリーンアップ
  • https://github.com/kubernetes/kops/pull/18640 の @cheftako による動的チャネル ラベルの追加
  • fix(channels): https://github.com/kubernetes/kops/pull/18657 の @argoyle による既知の準備完了状態のみを健全性シグナルとして扱う
  • aws: https://github.com/kubernetes/kops/pull/18661 の @hakman によるカールを使用してプライベート S3 バケットからノードアップをダウンロード
  • スケールテスト: スケジューラー QPS/BURST の kops スケーラビリティ構成を kube-up と調整します (https://github.com/kubernetes/kops/pull/18080 の @ronaldngounou による)
  • Azure: https://github.com/kubernetes/kops/pull/18666 の @hakman によるカールを使用して Blob Storage からノードアップをダウンロードします ※古い画像はアップロードしないでください。 @cheftako 著、https://github.com/kubernetes/kops/pull/18665
  • スケールテスト: CCM concurrentNodeSyncs の kops スケーラビリティ構成を kube-up と調整します (https://github.com/kubernetes/kops/pull/18082 の @ronaldngounou による)
  • ドキュメント: https://github.com/kubernetes/kops/pull/17954 の @eshaanm25 による seccomp 機能ゲートを削除

  • iam: https://github.com/kubernetes/kops/pull/18672 の @hakman による AsJSON() の Policy.Statement を変更しないでください
  • testing/e2e: gs:// ベース URL は、https://github.com/kubernetes/kops/pull/18670 の @hakman によってサポートされている kops バージョンにのみ使用します。
  • aws: KMS アクセス許可を https://github.com/kubernetes/kops/pull/18671 の @hakman によるサービス仲介呼び出しに制限する
  • kops コントローラーのブートストラップ再試行バックオフを制限し、https://github.com/kubernetes/kops/pull/18675 の @rifelpet によって e2e アップグレードが実際にロールされることを確認します

  • gce: https://github.com/kubernetes/kops/pull/18685 の @Jefftree によってノードからマスターへのファイアウォールで etcd イベント メトリクス ポートを開きます。

  • feat(akamai): ボリューム タスクを追加し、クラウド インターフェイスを拡張し、https://github.com/kubernetes/kops/pull/18700 の @moshevayner によるボリューム管理のモックを作成しました。
