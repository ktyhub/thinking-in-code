claude-mem v15.12.0

マイナー 公開日2026年11月7日 出典thedotmack/claude-mem 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

クロード・メム v15.12.0

画像はデフォルトで保持され、「マイワーク」に表示されます

  • デフォルトで保持: エージェントが読み取ったり作成したスクリーンショットと画像は、AI モデルに送信せずに保持され、そのターンの観察にリンクされるようになりました。画像推論はオフのままです (#5426)。
  • 「画像を保持」スイッチ: メモリ ビューアの設定に新しい 画像 セクションが追加されました。 画像の保持 をオフにすると、新しい画像の保持が停止されます。すでに保存されている画像はそのまま残ります。自分で保存した "false" は尊重されます (#5426)。
  • 私の作品のギャラリー: リクエスト カードには画像数と最初の 4 つのサムネイルが表示されます。リクエストドロワーには、リンクされたすべての画像が表示されます。どのサムネイルでも、キーボード ナビゲーションを備えたフルサイズのギャラリーが開きます (#5427)。
  • 新しいデータベース: My Work は、新しく作成されたデータベース (#5427) 上で観察アクティビティを再度リストします。
  • 信頼できるローカル変換: キャプチャされたスクリーンショットは、ビジーまたはタイムアウトとして失敗するのではなく、自分のコンピューターで変換されるようになりました。変換は順番を待ってそれぞれ 20 秒かかります。保存されたコピーはすべて非可逆 WebP であるため、サイズは小さいままです (#5431)。
  • クラウド クォータ: 各所有者は cmem.ai に最大 25 GiB のイメージを保存できます。これは Pro が適用する制限と同じです (#5467)。

修正

  • セッション: ビューアでセッションを削除すると、同じ再開された会話内の新しい作業が再びキャプチャされます (#5463)。
  • セッション: コミットされたトランスクリプト エントリは、ワーカーの再起動後に再生されなくなりました (#5321、ありがとう @lamimiahmed45-droid)。
  • フック: Grok Build のキャメルケース フック ペイロードが受け入れられます (#4282、ありがとう @nathan-v)。
  • フック: PreToolUse のメモリ ルックアップは現在のプラットフォームに限定されているため、あるハーネスが別のハーネスの観察を取得できなくなりました (#5008、ありがとう @SuperMarioYL)。
  • 私の作業: スケジュールされた更新は、別のエージェントにフォールバックするのではなく、構成されたエージェントに残ります (#5245、ありがとう @Dev-0710)。
  • クロード CLI: CLAUDE_CODE_PATH が変更されると、クロード CLI が再び見つかります (#5460、ありがとう @WhitePepperLambSoup)。
  • セキュリティ: CLAUDE_MEM_DATA_DIR および CLAUDE_MEM_WORKER_HOST は POST /api/settings を通じて変更できなくなり、OpenClaw を再インストールすると既存の設定がすべて保持されます (#5147、ありがとう @Wenjix)。
  • 設定: Grok Bot 認識パイロット エージェント ID はデフォルトでは出荷されなくなりました (#4970、ありがとう @zichen0116)。
  • 同期: バックログされた同期は停止する代わりに消耗し、projection_busy 応答には Retry-After が送信されます (#3488)。
  • 同期ハブ: リクエストごとの Durable Object 行の書き込みが少なくなり (#4424、@necatisozer に感謝)、バイト数をカウントするときに操作ごとにページの再シリアル化がなくなりました (#4937、@devkancheti4-design に感謝)。

このリリースにも含まれています

  • My Work: は、何が動いているかを示し、状態ごとにカードをグループ化し、ライブ変化をアニメーション化します (#5365)。
  • 私の作品: テキストは、オプトイン言語設定 (#5156、ありがとう @mehmetcelik7) を使用して、所有者の言語で書かれています。
  • インターフェイス: ワーカー インターフェイスの簡体字中国語をオプトインします (#5325、ありがとう @h6rime)。
  • オブザーバーの状態: SessionStart クォータ通知が明確になりました (#5134)。
  • インストーラー: オプションの電子メールと「どのようにお手伝いできますか?」という質問が戻ってきました。対話型ターミナルで 1 回のみ尋ねられます。サインインは CMEM Pro (#5218) のみです。
  • Claude アプリ プラグイン: は cmem-pro に名前変更され、cmem.ai コネクタを搭載し、メモリ ルックアップをメモリにキャプチャしなくなりました (#4570)。
  • プロバイダー: OpenAI 互換プロバイダー用の、cheapaimodel (#5158、感謝 @nicho810) および Obscurify.ai (#5165、感謝 @tonydavis629) プリセット。
  • 賢明な読み方: Delphi/Pascal のサポート (#4953、@nm3xyz に感謝)。
  • スキル: 新しいコミュニティ一掃スキル (#4374); oh-my-issues はクラスター パスをブラインドで開始し、オープン PR パス (#3617) を追加します。 version-bump スキルは、dotmack/claude-mem の外部での実行を拒否します (#4575、ありがとう @somil14)。
  • ドキュメント: README には、オブザーバートライアルでは支払い方法のチェックアウトが行われると記載されています (#5087、感謝 @Iyanuoluwa007)。

完全な changelog: https://github.com/thedotmack/claude-mem/compare/v15.11.1...v15.12.0
