claude-mem v15.14.0

マイナー 公開日2026年11月9日 出典thedotmack/claude-mem 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

クロード・メム v15.14.0

新しい

  • 私の仕事の重点分野: 私の仕事が開き、重点分野の概要が表示されます。各エリアには、バンドルされたコンセプト アートワーク、その目標、ライブ リクエスト数が記載されたカードが提供されます。そのうちの 1 つを開いてリクエストを確認します。セットアップ公開画面でも同じビューが使用されます。アートワークはフル、コンパクト、またはオフに設定でき、画像はプラグインに同梱されているため、実行時に何も生成または取得されません (#5652)。
  • claude-mem は自身を更新できます: ワーカーは releases/promoted-release.json でプロモートされたリリースを 1 日 1 回チェックし、npm が来歴付きのリリース ワークフローによって公開されたと示す新しいバージョンのみをインストールします。これは、ユーザーがしばらく離れている間のみです。更新に失敗すると、前のバージョンに戻ります。 npx claude-mem doctor は自動更新行を示します。 CLAUDE_MEM_AUTO_UPDATE=false でオフにします。 Claude Code 自身の更新スイッチ (DISABLE_AUTOUPDATER とその仲間) もこれをオフにします。新規インストールでは、Claude Code のバックグラウンド更新をオフにしてマーケットプレイスを登録するため、1 つのアップデーターのみが実行されます。新しい自動更新ドキュメント ページ (#5500) を参照してください。
  • 起動コンテキストはタイムラインのみです。 SessionStart メッセージはヘッダー行となり、その後にタイムラインが続き、最新のエントリで終わります。より長い作業状態とメモリ使用命令は、claude-mem MCP サーバーの命令に移動されました。ターミナルバナーも同じ形状です(#5487)。
  • より高速なフック: フックは、完全なワーカー バンドルではなく、小さなフックのみのバンドルから実行されます。 1 つのフックに必要な時間とメモリは約半分です。 12 個の並列フックは CPU の約 4 分の 1 を使用します (#5541、ありがとう @bulanovk)。
  • 生のツール証拠検索 (オプトイン、ローカル): CLAUDE_MEM_TOOL_USES_SEARCH_ENABLED=true では、ローカル search と deep: true は、観察検索で何も見つからなかった場合に保存されたツールの入力と出力を調べ、get_tool_uses の #T ID を返します (#5167、ありがとう @ShitK)。
  • 韓国語 UI: ビューア、マイワーク、セットアップ、および観察 TV を韓国語で表示できます (#5522、感謝 @BaeJinSeop)。

プライバシーとセキュリティ

  • コンテキスト: プライバシー フィルターは、起動時に表示される前のセッションの応答にも適用されるようになりました (#5626)。
  • バックアップ: SQLite スナップショットは、ユーザーのみが読み取り可能に作成されます (#5642)。
  • メディア: オプトアウトするとクラウド アップロードが開始されなくなります (#5622)。
  • 編集: Cookie ヘッダー値が編集され、Cowork shim (#5591、感謝 @DeryFerd) と一致し、Cowork shim は依然として送信されたキーシェイプをそのまま編集するようになりました (#5543、感謝 @DeryFerd)。
  • ワーカー: cwd からのプロジェクトを解決する読み取りルートは保護されています (#5590、ありがとう @DeryFerd)。
  • Auth: 文字列ではない保存されたアクセス トークンは拒否されます (#5506、ありがとう @Kirat0201)。
  • ランチャー: macOS の署名は、ランチャーが配置される前に検証されます (#5503、ありがとう @Kirat0201)。
  • テレメトリ: 保存された同意の選択は、識別子の作成時に保持されます (#5629)。

インストーラーと統合

  • アトミックな設定書き込み: Codex、OpenCode、OpenClaw、Kimi、Antigravity、Hermes、Grok Bot、OMP 設定ファイルとフック ファイルはアトミックに書き込まれるため、インストールを中断しても壊れたファイルが残ることはありません (#5592、#5593、#5594、#5595、#5596、#5597、#5598、#5599、ありがとう) @DeryFerd)。
  • カーソル: uninstall は、install --ide cursor が追加したフックと MCP サーバーを削除します (#5584、ありがとう @tanisqbaweja)。
  • インストーラー: ツール バージョン プローブ、ブラウザー セットアップ ワーカー リクエスト、および npm 子プロセスは制限されており、npm 子孫はタイムアウトで終了します (#5634、#5638、#5644)。
  • インストーラー: 既存のホスト インストールは構成されたフォルダー内で検出され、実行不可能なパスはランタイム検出中にスキップされ、Roo コードはマーケットプレイス ID によって検出され、修復中に PATH 上の互換性のあるツリー シッターが使用されます (#5552、#5556、#5560、#5576、ありがとう @Kirat0201)。
  • フック: フックは、インストールされているプラ​​グイン リゾルバーを通じてディスパッチされます (#5504、ありがとう @Kirat0201)。
  • OpenCode: 1 つの制限付きライブ オブザーバー ハンドオフ (#5621)。 Pi: ツールの結果は証拠のために正規化されています (#5605)。 Goose: 実行可能パスは YAML 設定 (#5606) で引用されています。 Devin: 独自のツールマップ エントリのみが翻訳されます (#5512、ありがとう @Kirat0201)。 テレグラム: 送信は制限されています (#5636)。
  • アダプター: 明示的なツールの失敗は証拠として保存されます (#5620)。
  • DSH: ワーカー MCP エラー結果はパススルーされ、応答本文読み取り中のエラーは正しく分類されます (#5604、#5619)。

私の仕事

  • リストは元のアクティビティ時間順に並べられ、オーナーの目標はイベント順に再生され、会話タイトルはプラットフォームに限定されます (#5580、#5589、#5561)。
  • 会話が移動すると古いグループの証拠が削除され、無効な監視ファイルのエントリがスキップされ、Git ブランチ製品が確認されたリモート更新に起因し、削除された Windows 一時フォルダーが認識されます (#5587、#5585、#5533、#5554)。
  • 大規模な履歴とカタログは SQLite の制限内に留まり、深くネストされた公開結果が処理され、台帳スナップショットは分離されたアトミック書き込みを使用し、短いハッシュを共有する成果物のリビジョンが保持されます (#5588、#5549、#5579、#5582、#5536)。
  • 空のルール ページでは、エージェントを待機していることが説明され、空のリストの後に最初のライブ リクエストがアナウンスされ、セットアップ メモリ検索カードに記録されたエージェントが表示されます (#5575、ありがとう @Kirat0201; #5564、#5574)。

検索、コンテキスト、記憶

  • スマート検索はソース メモリを制限し、移植可能なパス フィルタを受け入れます。ファイル履歴のランキングとインデックス ページが高速になりました (#5534、#5586、#5602)。
  • 検索では、複数行のタイトルが 1 つのテーブル行に保持され、ゼロ値の日付境界が保持され、コーパスを置き換える前に SQLite エラーが伝播され、個別の DSH 結果が保持されます (#5583、#5520、ありがとう @Kirat0201; #5610、#5548)。
  • コンテキストは一貫して等しい時間の行を選択し、サーバーでモード フィルターを適用し、シェル読み取りでリテラルの ~ および + という接頭辞が付いたファイル名を尊重します (#5608、#5623、#5633、#5510、ありがとう @Kirat0201)。
  • ナレッジ コーパスはソースの証拠とアイデンティティを保持し、重複する操作は保存された状態を上書きできず、キャンセルされたクエリは保存されません (#5528、#5612、#5648)。
  • スマート ナビゲーションには、Rust の特性、実装、データ定義が表示されます (#5531)。
  • 重複排除読み取りは制限されており、IDF モデルはロックされたスナップショットから再構築されます (#5632、#5613)。
  • CLAUDE.md は観察数ゼロを尊重し、claude-md clean は作成されたインデントを維持します (#5508、ありがとう @Kirat0201; #5566)。

バックアップ、復元、インポート、同期

  • リストアは、ライブ データに触れる前に新しいスキーマのスナップショットとリモート ワーカーのリストアを拒否し、クリーンアップ エラーにもかかわらずコミットされたスワップを報告し、破損したリカバリ ペアを保持し、選択したリストア ポイントを保持から保護します (#5649、#5562、#5624、#5630、#5532)。
  • スナップショット ボリューム上の WAL ページのバックアップ アカウント (#5627)。
  • インポートは観察の来歴と補強履歴を保持し、UTF-8 BOM を受け入れ、従来のリストに一貫してインデックスを付け、行が拒否された場合はゼロ以外で終了します (#5609、#5518、#5514、#5516、ありがとう @Kirat0201)。
  • 同期は、リモートの廃棄後にレプリカ ベクターを削除し、プロジェクトの再マップ後にベクター メタデータを更新し、範囲外の番号を隔離し、不正なポートを拒否し、古いマーケットプレイス ディレクトリ内の除外フォルダーを保護します (#5647、#5645、#5611、#5573、#5525)。
  • Chroma は、プロトタイプ名付きプロジェクトのチェックポイントを永続化します (#5607)。 Notion のエクスポートは UTF-8 リクエスト制限内に収まります (#5529)。メモリ エクスポートは、応答本文 (#5547) を通じて期限を守ります。

サーバーと CLI

  • サーバー: 生成完了は 1 回計測され、推論修正はジョブの有料送信上限内に留まり、オペレーター生成状態の変更はロックされ、従来の取り込みルートは使用状況保護を取得し、切断時にイベント ポーリングが停止し、エラー後にシャットダウン クリーンアップが終了し、Redis 停止中はキューの健全性読み取りが制限されます (#5640、#5615、#5650、#5641、#5651、#5628、 #5617)。
  • PostgreSQL: 明示的な TLS ポリシーが維持され、失敗したプール接続が回復し、べき等書き込みは推論をスキップし、再配信されたイベントがリンクされ、スコープ指定されたジョブ数はグローバル合計と比較されません (#5637、#5537、#5538、#5546、#5559)。
  • CLI: 完了した生成ジョブは再試行されず、前のキー検索が失敗するとキーのローテーションが停止し、コマンド所有のジョブ プールが閉じられ、シグナルで終了した子が失敗を報告し、検索ではローカル プラグインなしでワーカーにクエリを実行できます (#5603、#5618、#5639、#5569、#5568)。
  • MCP: npm MCP サーバーはチェックアウトの呼び出しで起動し、空の明示的なポートは拒否され、サーバー MCP clients には利用できないローカル操作が表示されず、セットアップはサーバー MCP エンドポイント (#5553、#5571、#5551、#5563) を出力します。
  • 初期化が失敗すると SQLite ハンドルが閉じられます。拒否されたワーカーの実行約束は監視されます。一時的なメディア クラウドの読み取りは再試行可能のままです (#5635、#5616、#5614)。
  • 小規模な修正: 従来の SQLite タイムスタンプは正しい年を表示し、Unicode はプロンプト履歴の短縮を存続し、一重引用符で囲まれたスキップ理由が受け入れられ、すでに試用版または Pro になっているアカウントでは Pro 試用版の提案がスキップされ、末尾のストリームが正しく記録され、フォルダー コンテキストの生成は不完全な作業を報告します (#5557、#5550、#5558、#5545、#5526、#5565、#5572)。

ドキュメント

  • 翻訳された README にはリンクと見出しが修正され (#5527、感謝 @vietmy1711)、2 つの古い release note でクラウド同期とテレメトリが正しく説明されるようになりました (#5577、感謝 @Kirat0201)。
