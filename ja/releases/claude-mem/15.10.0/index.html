claude-mem v15.10.0

マイナー 公開日2026年11月5日 出典thedotmack/claude-mem 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

クロード・メム v15.10.0

新機能

オンボーディングにより、既存の作業が検索されます。 セットアップでは、トランスクリプトから既存の作業、ルール、焦点を検出します。メインボタンは「Discover My Work, Rules & Focus」で、「Skip this step」はその下の小さなアクションです。 「Claude-mem エクスペリエンスを向上させるために、匿名の使用状況統計を共有する」ボックスがチェックされます。チェックを外すと保持され、Discover を押すまで何も送信されません。ホストされたセットアップがビジーな場合、claude-mem はアップロード前に容量をチェックし、再起動後のクールダウンを記憶して、セットアップを完了できるようにします。 (#5270、#5308、#5384 by @thedotmack)

メモリ キャプチャをオフにします。 新しい CLAUDE_MEM_OBSERVER_ENABLED 設定とメモリ キャプチャの切り替え。 "false" に設定すると、既存のメモリ、検索、およびセッション開始コンテキストを保持しながら、新しい観察および要約モデルの呼び出しが停止されます。 (#5353 by @tarunbad)

ツールごとにオブザーバーを選択します。 新しい CLAUDE_MEM_PROVIDER_BY_SOURCE 設定では、セッション ソースごとにオブザーバー プロバイダーを選択します。たとえば、Codex 上の Codex セッションや Claude 上の Claude コード セッションなどです。 (#5333 by @ankit4479)

長寿命のクロード ログイン。 ~/.claude-mem/.env が CLAUDE_CODE_OAUTH_TOKEN を提供できるようになったため、保存されたクロード コード ログインの有効期限が切れてもキャプチャは停止しません。認証のために一時停止されたセッションは、資格情報が機能することが示されると再開されます。 (#5372 by @MeggDistribution、#5383 by @xunguangzlj-cloud)

モードを結合します。 モード オーバーライドがチェーンされるようになったので、code--chill--ko のように言語モードを Chill と組み合わせることができます。 (#5349 by @BaeJinSeop)

医師がオブザーバーの欠落について説明します。 npx claude-mem doctor は、すべてが順調であると言う代わりに、オブザーバーのプロバイダーが利用できないこととワーカーの依存関係を報告するようになりました。 (#5366 by @parveen0029)

ビューアの同期とマイ ワーク。 ビューアの同期リカバリがメインになりました。高速な制限付きビュー、正確な同期ステータス、デバイス間での共有マイ ワーク状態、およびリモート変更のリカバリです。クラウド ビューアでは、[マイ ワーク] が [アカウントと請求] にリンクされます。 (#5410、#5416 by @thedotmack)

信頼性

  • ワーカーは、10 個のプールがいっぱいの場合は失敗せずに空きスロットを待ち、他のセッションが待機している場合はアイドル スロットを解放します。 (#5386 by @balabommablock-cpu、#5388 by @0xABCD01)
  • ハングしたコンテキスト リーダー リクエストがタイムアウトするようになったため、読み取りがスタックしても観察が停止することがなくなりました。 (#5387 by @markjoin123)
  • 障害の種類が変わると障害追跡が再開されます。 (#5380 by @xunguangzlj-cloud)
  • コーデックス出口は、最新の標準エラー出力からのみ分類されます。 (#5310 by @2023Anita)
  • オブザーバーは親ゲートウェイのモデル名を継承しなくなり、Claude ベータ版をオプトアウトしたままになります。モデルの拒否は、モデルの停止として報告されます。 (#5316 by @sayedrisat、#5317 by @parveen0029、#5348 by @tarunbad)
  • SSE ストリームはチャンク境界を越えてフレームを維持し、ビューアは解析できないフレームを無視します。 (#5367 by @Afloat16、#5364 by @DeryFerd)
  • キャップ付きエラー本体リーダーはロックを解放します。 (#5340 by @Afloat16)
  • SDK がレポートを完了しない場合、バグ レポートはテンプレートに戻ります。 (#5302 by @liuyinchu)

インストールとプラットフォーム

  • Windows: ワーカー デーモンは PowerShell なしで起動します。 (#5351 by @REI-330)
  • Copilot CLI: MCP サーバーは ~/.copilot/mcp-config.json に登録されており、Copilot CLI がそれを読み取ります。 (#5305 by @tanishqbaweja)
  • Windows 上の Goose: claude-mem は %APPDATA%\Block\goose\config に登録されます。 (#5323 by @tanishqbaweja)
  • Devin: Devin がセッションを圧縮した後、コンテキストが再度挿入されます。 (#5314 by @patricballard)
  • キミ: パスに引用符が含まれている場合でも、フック コマンドは有効な TOML のままです。 (#5363 by @DeryFerd)
  • Docker: サーバーとワーカーは同じ BullMQ キュー プレフィックスを共有しており、ドキュメントにはテスト済みの Redis 互換サーバーがリストされています。 sync-api コンテナーは、非 root ユーザーとして実行されます。 (#5389、#5390 by @murtazayusuf、#5331 by @DeryFerd)
  • プロセス ID プローブは UTC に固定されます。 (#5312 by @LuckVd)

インポートと検索

  • プロンプト インポートは、CODEX_HOME および XDG_DATA_HOME によって設定された Codex および OpenCode プロファイルを読み取り、コミットされた OpenCode WAL 更新を含み、OpenCode ツール入力をエージェント作成として認識し、コピーされた Codex フォーク プロンプトを除外し、JSON ツール文字列をデコードし、セッション読み取りが不完全な場合にフック プロンプトを保持します。 (#5303、#5297、#5304、#5300、#5369、#5301 by @rudycelekli)
  • 採用により、メモリを再マップする前に実際のチェックアウト パスが保持され、チェックアウト ID は空白を保持します。 (#5296 by @rudycelekli、#5368 by @liuyinchu)
  • フォルダー検索は、相対バックスラッシュ パスと Makefile のような拡張子のないファイルに一致します。 (#5309 by @rudycelekli、#5343 by @liuyinchu)
  • Chroma のセマンティック フォールバック クエリには doc_type が含まれなくなりました。 (#5355 by @0xABCD01)
  • コンパクトタイムは午前/午後の前に U+202F セパレータを処理します。 (#5356 by @kevin9327)

プライバシーとセキュリティ

  • より多くのシークレットが保存前に編集されます: Groq、xAI、NVIDIA NIM、Runcrate、Google OAuth (ya29.)、Linear、Notion、Supabase、Sentry、Databricks、および HashiCorp Vault トークン。 (#5298、#5342、#5345、#5352、#5373 by @kevin9327; #5327 by @DeryFerd)
  • 改行を含むログ値はエスケープされ、ログ レコードが偽造されなくなります。 (#5328 by @DeryFerd)
  • 同期: 402 検証応答はキャッシュされた判定を削除し、分離ごとの認証メモは制限され、認証判定が失効すると勧告ソケットが閉じます。 (#5329、#5332 by @DeryFerd、#5358 by @REI-330)
  • バッチ ID 配列、タイムラインの深さ、求人リストのオフセット、および空の URL 修飾子の入力境界。 /api/observations/batch では数値文字列 ID が受け入れられます。 (#5360、#5362、#5361、#5330 by @DeryFerd; #5341 by @Afloat16; #5336 by @ryrenz)
  • Hermes はリニアスキャンでメモリタグを除去します。 (#5320 by @REI-330)

ドキュメント

  • 開発の前提条件とテスト手順が現在のツールと一致している。 README にはすべての組み込み言語モードがリストされています。簡体字中国語とベトナム語の README が同期されます。 (#5324 by @POWDER-RANGER、#5334 by @BaeJinSeop、#5322 by @h6rime、#5391 by @vietmy1711)
  • macOS SQLite のテスト修正。 (#5313 by @patrickballard)
