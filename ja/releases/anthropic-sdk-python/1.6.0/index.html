anthropic-sdk-python v1.6.0

1.6.0 (2026-09-15)

フル Changelog: v1.5.0...v1.6.0

機能

  • api: 管理対象エージェントの自動モード ツール権限を追加 (909d92f)
  • api: 圧縮パラメーターと署名付き圧縮ブロック (ベータ) を追加 (8689179)
  • api: ワークスペースのデータ常駐地域フィールドの列挙型を追加します (3dc6dbf)
  • api: Thinking_mismatch_allowed エントリを input_transformations に追加 (ベータ) (14d1792)
  • api: url_sources を Web フェッチ ツールに追加します (4ba7115)
  • api: ユーザー プロファイル メソッドに workspace_id パラメータを追加 (1c359b2)
  • client: 非同期資格情報トークン プロバイダーをサポート (95e93f7)

バグ修正

  • api: 使用反復モデルを NULL 可能としてマークします (520d000)
  • api: メッセージとデルタ イベントに 1 つの入力変換タイプを使用します (ae86d7d)
  • client: 60 秒を超える再試行後の値を尊重する (2d03ba2)
  • client: 無効な Retry-After 値を無視し、maxRetries を検証します (909d92f)
  • client: 非同期 client で接続エラーを再試行し、コルーチン再試行ループでブロックを停止します (909d92f)
  • client: Retry-After が範囲外の場合はデフォルトのバックオフを使用します (3d15f04)

雑用

  • deps: 開発ロックファイルで aiohttp、pygments、pytest をバンプします (005ad11)
  • deps: anyio 4.1 以降が必要 (79b4175)
  • ドキュメント: ツール使用イベントの session_thread_id が情報であることを明確にします (2ac7b60)
  • ドキュメント: 圧縮ベータ版のパラメーターの説明を修正 (5048c9a)
  • 内部: beta_message.py 内のインポートを並べ替えます (0a92f91)
  • テスト: モジュール レベルでモデル テストの型エイリアスを定義します (98c3a7a)
  • テスト: 合格したテストの実行に失敗することなくモック サーバーを停止します (d28aea7)

ドキュメント

  • api: サーバー側フォールバックでの use.iterations エントリの入力を明確にする (bb06629)
  • 最初のバリアントの説明を使用して共用体を文書化するのをやめます (7a94250)
  • ほとんどのドキュメント文字列でマークダウン形式を使用します (25f344f)
