anthropic-sdk-python v1.9.0

1.9.0 (2026-09-28)

フル Changelog: v1.8.0...v1.9.0

機能

  • api: between_tools 思考タイプを追加 (a9a577d)
  • api: クロード-ソネット-5-5 (a5a25e9) を追加します
  • api: include_inherited とソースをワークスペースのレート制限に追加します (0bf4af8)
  • api: 入力されたイベント タイプの値を管理対象エージェントのイベント リスト フィルターに追加します (1b82cd9)
  • api: キャッシュ診断 GA — Message / MessageCreateParams の診断 (22062b8)
  • tools: オプションで、応答ストリーム中にツール呼び出しを実行します (26d0812)

バグ修正

  • client: 名前のないファイルのアップロードに対してプレースホルダー ファイル名を送信しません (9e9709d)
  • ヘルパー: フォールバック ホップで無効になると考えられる between_tools を劣化させます (#952) (a3834d4)
  • メッセージ: stream() および parse() で診断を受け入れます (#929) (fad840c)

雑用

  • api: 既知のモデル ID をモデル タイプの最初にリストします (e5a082a)
  • ci: リポジトリによって CI ランナーを選択します (39ccf62)
  • client: 解析およびツール ランナーからのベータ ヘッダーの送信を停止 (#907) (1428100)
  • ドキュメント: stream: true が生のイベント ストリームを返すことを明確にします (82918fa)
  • ドキュメント: 管理対象エージェントのアクター説明をリソース中立にする (34ef524)
  • ドキュメント: Dream タイプに関する研究プレビュー通知を復元します (f03e32e)

ドキュメント

  • フィールド docstring の間隔ルールを CLAUDE.md に追加 (e5c35f4)
  • api: 共有型 (d79a2e7) よりも各フィールド独自の説明を優先します。
  • claude.md: 関数本体の間隔ルールを追加 (3174f8f)
  • api.md 内のインポート可能な型名をリストします (56a42ab)
