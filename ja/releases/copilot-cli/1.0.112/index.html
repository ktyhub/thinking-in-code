copilot-cli v1.0.112

パッチ 公開日2026年11月13日 出典github/copilot-cli 英語原文

副操縦士-cli v1.0.112

2026-11-13

  • 失敗した /compact では、内部ホスト再スロー プレフィックスなしでモデル プロバイダーのエラー メッセージが表示されるようになりました。
  • 管理対象アカウント ポリシーの読み込み中に入力されたプロンプトなど、CLI がまだ送信していないプロンプトは、貼り付けられたテキストを保持するため、もう一度 Enter キーを押すと、リテラルの [#N - M 行を貼り付け] プレースホルダーの代わりに貼り付けが送信されます。
  • /plugin マネージャーは、有効としてロードされなかったリポジトリ プラグインを表示しなくなり、ソースがマーケットプレイスの外部を指しているときにプラグイン リストにそのディレクトリが見つからなかったと表示されなくなりました。
  • copilot help sandbox は、macOS では、サンドボックス ホスト ルールが、デーモンに到達するビルド client などのローカル ポートへの直接 TCP 接続をブロックすると述べています。 localhost は、HTTP またはプロキシ対応 client からの CONNECT トンネルとして、ローカル プロキシ経由でのみ到達可能です。
  • copilot workflow run --help では、ワークフローを実行できるサインインの中に Microsoft 365 アカウントがリストされるようになり、GitHub からサインアウトしているときに使用量ベースの請求とカスタム モデル プロバイダー (BYOK) も実行できるようになりました。
  • /subagents モデル ピッカーは、同じエージェントに対して再度開き、セッションから切り替えて戻った後に入力を受け入れます。
  • 狭いターミナルの /subagents 設定でオン/オフ状態とモデル ピッカーの矢印を表示したままにする
  • サブエージェントのビューを開いたときに、エスケープ シーケンスや制御文字がタスク プロンプトから端末に書き込まれなくなりました。
  • /copy は、Word、Outlook、または Teams に貼り付けるときに書式を維持し、複数メッセージ応答の各メッセージを独自の段落、表、リスト、または引用として保持します。
  • モデル切り替えプロンプトは、それを発生させたセッションに残り、そのセッションに戻ると再び表示されます。
  • /settings リスト項目は、幅 20 列以下の端末で保存された値を入力または表示するときにすべての文字を表示します
  • 端末が短くなり、再び高くなっても、画面下部の権限プロンプトやその他のダイアログが下にスクロールし続けなくなるため、拡張機能の環境変数プロンプトには、リストされている変数名が表示されます。
  • /フィードバックは、追加のログ パスがフィードバック バンドルにファイルを提供しない場合に警告します。
  • 絵文字やその他の Unicode 文字は、[問題] タブと [プル リクエスト] タブの検索カーソルの下に正しく表示されます。
  • 絵文字または CJK 文字を含むパスと変数名が正しく切り詰められ、/sandbox 内で整列されるようにします。
  • メッセージ、シェル コマンド、およびシェル出力で cli がチェックされた場合、バランスの取れた括弧が付いたリンクで完全な URL が開かれるようになりました。
  • セッション制限ダイアログはそのセッションに残り、切り替え時に他のセッションを自由に入力できるようになります。
  • copilot mcp get は、テキストおよび JSON 出力で見つからない toString などの未構成のサーバー名を正しく報告します。
  • セッション サイドバー アクションは、CLI の終了中にセッションの作成や切り替えを行わなくなり、終了サマリーの再開コマンドは有効なままになります。
  • /settings のテキストおよび数値エディターでは、入力された値が幅の狭い端末のダイアログ内に表示されたままになります。
  • ツールのプレビューは絵文字をそのまま保持し、SQL およびエージェントのメッセージをプレーン テキストとして表示し、メモリ投票のプレビューを 1 行に保持します。
  • @ ファイル ピッカーは、絵文字とアクセント付き文字をそのまま維持し、狭い端末でパスを短縮するときに @ プレフィックスを保持します。
  • /lsp ログのエラー概要は絵文字を分割せずに利用可能な幅に収まり、サーバー メッセージはプレーン テキストとして表示されます。
  • /environments 接続追加ダイアログで j/k または Ctrl+N/Ctrl+P を使用した後、矢印キーと Tab を使用して強調表示されたアクションに従います。
  • Vim モードで貼り付けた直後に Esc または Ctrl+C を押すと、貼り付けたテキストが正しい位置に留まります
  • キューに入れられたコマンドが /login などのダイアログを開くときに、[セッション] タブの応答性を維持します。
  • Ctrl+C は、新しくキューに入れられたプロンプトを実行したり、送信の失敗を表示したりすることなく、確実にキャンセルします。
  • 起動時にセッション ピッカーをキャンセルするときに、ようこそヘッダーと [はじめに] ボックスを表示します。
  • 組織に必要なプラグインを起動時に一度準備し、重複インストールや繰り返しの成功または失敗の通知を回避します。
  • ツールの許可プロンプトは、タイトルと選択した回答をショートターミナルに表示したままにし、PgUp/PgDn でコマンドまたはファイルの詳細をスクロールします
  • MCP システムのプロンプト レビューでは、ターミナル コントロールによるコンテンツのスタイル変更、リンク、非表示を許可せずにプレーン テキストが表示されます。
  • /plugin は、再チェックで利用可能なアップデートがないことが確認されたときに、マーケットプレイスのアップデート バッジとカウントをクリアします。
  • プロンプト モードでの Untrusted フォルダー警告により、親ディレクトリ内のスキップされたワークスペース MCP 構成が識別され、フォルダーが trust にロードされるようになりました。
  • copilot help environment は、すべてのサーバーの MCP ツール スナップショット キャッシュをオフにする変数 COPILOT_MCP_TOOL_CACHE を再度文書化します。
  • タイムラインのエージェント、コード検索、および IDE ツールの行には、エスケープ シーケンスや制御文字を端末に渡すのではなく、モデルおよび IDE で記述されたテキストがプレーン テキストとして表示されます。
  • /model plan は、追加の引数なしでプラン モデルを保存またはクリアする代わりに、追加の引数を拒否し、PLAN および --plan plan をプラン キーワードとして読み取ります。
  • タイムラインの質問行には、回答を待っている間、cline を実行した後、およびオートパイロットが回答したときの質問テキストが表示されます。
  • セッションを再開するときに、以前に使用した AI クレジットをセッション制限にカウントします
  • /diff 内の追跡されていないファイルの .gitattributes バイナリ設定を尊重し、その内容を追加行数から除外します。
  • すべての CLI オプションをリストするのではなく、引数エラーの使用行に関連するオプションのみを表示します。
  • @ または # メンションに貼り付けてすぐに Enter、Tab、または Ctrl+Y を押しても、以前の結果からファイルまたは課題が選択されなくなりました
  • リストがターミナルよりも高い場合、強調表示されたエージェントを /agent に表示したままにします
  • /env 内のマークダウン文字を含む URL のような名前をバックスラッシュなしで表示します
  • /pr fix 競合または /pr fix all でマージ戦略ピッカーを開いたときに、チャットとセッションの履歴に指示が表示されるようにします。
  • MCP 検査コマンドは、フォルダーが trust されていないためにワークスペース MCP 構成がスキップされると警告し、それを trust する方法を説明します
  • デバイス ポリシーで --yolo または --allow-all フラグが無効になっている場合、プロンプト モードの警告で組織のサポート リンクを表示します。
  • セッション ピッカーは、--connect がリモート セッションまたはタスクを見つけられない場合、または検索が失敗した場合に説明します。
  • @ を含むリポジトリ パス (スコープ指定されたパッケージ ディレクトリを含む) からプラグインをインストールします。
  • 幅の狭い端末でも /diff 検索カーソルを表示したままにして、スペースが許せば一致数を表示します
  • Copilot の質問や MCP フォームで長いリストをナビゲートするときに、強調表示された選択肢を表示したままにします。
  • CLI の終了中にセッション タブまたはサイドバーを開くと、画面がブランクにならずに表示されたままになります。
  • 狭い端末でも、「セッション」タブの切り詰められたセッション名に省略記号を表示したままにします。
  • フォルダー名またはブランチ名に中国語、日本語、韓国語などのワイド文字が含まれている場合は、フッター パス、ブランチ名、ステータス テキストを適切に適合させます。
  • /tasks には、セッション再開後のサブエージェントのフォローアップ実行時間が含まれます
  • セッション サイドバーを開いた状態で /exit または /quit をすばやく 2 回実行すると、空白の応答しない端末が残されるのではなく、CLI が終了します。
  • /help や /environments などの全画面ビューから戻ったときに、目標パネルの ToDo カウントを正確に保つ
  • 幅の狭い端末では、/settings レコード エディターと入力されたキーをダイアログ内に保持します。
  • フォルダーが見つからない無効なローカル マーケットプレイス プラグインの /plugin で使用できない更新アクションを非表示にします
  • アクティブなターン中にキューに入れられた MCP サーバーのセーブをエラーではなくステータス メッセージとして表示します
  • 色が選択範囲、検索一致、またはホバーされた行の背景と一致する場合、強調表示された会話テキストを読みやすい状態に保ちます
  • 絵文字を含む長いプラグイン フォルダー パスは、有効化および無効化ダイアログで短縮された場合に正しく表示されます。
  • 返信内のマークダウン テーブルは、境界線や行を複数の行に分割することなく、狭い端末に適合します
  • /env は、/instructions で無効になっている命令ファイルをロード済みとしてリストしなくなりました
  • テキストに終端エスケープ シーケンスが含まれている場合でも、オートパイロットの目標とサブエージェントの説明を読み取れるようにする
  • /settings を使用して editorMode を変更すると、/vim を切り替えた直後に有効になります。
  • 狭い端子で折り返される場合、折りたたまれた読み取り、作成、および編集行に完全なファイル名を表示します
  • 長いクエリの横や狭い端末でも /search の一致カウントを読み取れるようにします
  • セッション サイドバーを開いた状態でターミナルのサイズを変更しても、/help テーブルは正しく配置されたままになります。
  • 強調表示された許可プロンプトの回答と入力された返信を幅の狭い端末でも読みやすい状態に保ちます
  • 検索に一致しないプロバイダーを再スキャンした後でも、/model ピッカーの詳細とキーボード ヒントが正しく表示された状態を維持します。
  • バックグラウンドで再試行されたセッションに切り替えるときに、応答または最終エラーの上に再試行通知を表示します。

  • で選択された問題とプル リクエストには、エージェントの動作中にプロンプトを送信またはキューに追加するときにその詳細が含まれます

  • INSERT モードからプロンプトを送信またはキューに追加した後、Vim の元に戻すコマンドを保持し、現在のドラフトに範囲を限定してコマンドを繰り返す
  • 左キーを 2 回押してセッション サイドバーを開いたときに、狭いターミナルを広げた後もプロンプトの応答性を維持する
  • ロード後に /mcp auth に完全なサーバー リストとキーボード ヒントを表示します
  • 長い単一行出力で、折りたたまれた失敗したシェル行にコマンドの説明と終了ステータスが表示されるようにします。
  • 組織のポリシーで MCP サーバーが無効になっている場合、組み込みの GitHub MCP サーバーは使用できなくなります
  • サブエージェントは、--max-ai-credits で設定されたセッション全体の AI クレジット制限を尊重するようになりました。
  • /env は、構成された名前を Markdown ブロックまたは絵文字ショートコードとして解釈するのではなく、文字通り表示します。
  • copilot mcp remove および /mcp delete は、--additional-mcp-config で渡されたサーバーは、見つからない、または組み込みサーバーと呼ぶのではなく、そのオプションから来ており、削除できないことを示すようになりました。
  • /subagents は、設定メニューで Esc キーを押した後、設定したばかりのサブエージェント上にカーソルを保持するため、スペースによって別のサブエージェントがオフにならなくなります。
  • スクリーン リーダー モードでは、ナロー ターミナル上で現在の /config セクションに正しく名前が付けられます。
  • /plugin、/skills、および /mcp search に貼り付けると、貼り付けが不完全なエスケープ シーケンスで終了した場合でも、カーソル以降のテキストが保持されます。
  • プロンプト テキストは完全に表示され、スラッシュ コマンドの後に貼り付けたり、入力したり、Ctrl+G で編集したり、履歴から呼び出したりしたときに、改行が正しく処理されます。
  • モデルピッカーは、キーヒントが狭い端末上でドッキングされたセッションサイドバーの横でより多くの行に折り返されるときに、画面の上部または下部を越えて実行されなくなりました。
  • 応答が中断された後も、各再試行の推論を独自の応答で保持します。
  • 最終モデル呼び出しの前に表示されるセッション制限プロンプトは、使用済み AI クレジットを制限値まで切り上げることがなくなり、「300 個の AI クレジットのうち 300 個を使用しました」の横に「セッション制限にほぼ達しました」と表示されなくなりました。タイムラインのセッション制限ラインと同じ数値 (299.6 の 300 など) が表示されます。
  • プロンプト内のキーボード ナビゲーションと単語の削除により、添付画像と貼り付けられたテキスト ラベルはそのまま維持されます
  • エージェントの動作中に送信されたメッセージを巻き戻すと、それに応答してエージェントが変更したファイルが復元されるようになりました。
  • 圧縮の実行中に /compact を再度入力しても、実行中の圧縮のインジケーターが非表示にならなくなり、Ctrl+C および Esc Esc を押しても停止します。
  • ローカル ディレクトリ マーケットプレイスのプラグインのカタログ パスがフォルダーではなくファイルを指している場合でも、すべての MCP サーバーの起動が停止されなくなりました。そのプラグインはスキップされ、そのプラグインとパスの名前を示す警告が表示されます
  • チーム プラグインは、マーケットプレイスから特定のブランチまたはタグ、またはリポジトリのサブフォルダーにインストールされます。
  • 公式 OS サポートを拡張せずに、macOS Ventura 13.5 以降でのベストエフォート起動を改善しました
  • 明示的なコンテキストの選択を維持しながら、各モデルの推奨コンテキスト ウィンドウをデフォルトで使用します。
  • /chronicle コスト ヒントに Copilot アプリ セッションが含まれるようになり、使用状況に基づいて安価なモデルと推論設定を推奨し、ローカル使用が利用可能になった場合はより早くレポートします。
