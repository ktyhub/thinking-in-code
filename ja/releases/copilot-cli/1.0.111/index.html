副操縦士-cli v1.0.111

2026-11-13

  • エンタープライズ管理の Shell、Bash、および PowerShell 権限ルールに正規表現サポートを追加します。
  • --host-allow-session-creation を追加して、保存された設定を変更せずにリモート clients が 1 回の起動で CLI ホスト上にセッションを作成できるようにします。
  • パーセントが最新の状態に保たれるように、プレミアム リクエストの使用状況を更新します。
  • 重複した MCP OAuth 再接続を防止し、承認をキャンセルした後もサーバーをニーズ認証状態に保ちます
  • ⌛︎ などのテキスト バリエーション セレクターが後に続くワイド シンボルを含むマークダウン テーブルは、正しく配置された行でレンダリングされます。
  • footer.showCodeChanges 設定の説明には、保留中の変更ではなく、このセッションでの Copilot のファイル編集によって追加および削除された行が表示されると記載されるようになりました。
  • /usage アクティビティ グラフは、毎日の行を 2 つにまとめるのではなく、表示する週の数を減らして狭い端末に適合するようになりました。
  • ターミナル コントロール シーケンスが表示されるときに、意図しないテキスト スタイルを適用することなく、シェル出力とカスタム ステータス ラインが正しく表示されます。
  • 会話 + ファイルを使用した /rewind は、後ですでに元に戻されているか再度削除されているファイルを復元したとしてカウント、リスト、またはレポートしなくなりました
  • インタラクティブな /plugin マーケットプレイス コマンドは、CLI がサブディレクトリで開始されるときにリポジトリ ローカル マーケットプレイスを検索します
  • --screen-reader を使用する場合、選択ラベルを読み取り可能にし、/environments 内で行を整列させます。
  • /skills はスキル名と /mcp 使用テキスト名なしで取得され、廃止された情報と削除の代わりに動詞の取得と削除が行われます。
  • /diff は、文字化けしたテキストや空のペインの代わりに、バイナリ ファイルに関する明確な通知を表示します。
  • /usage アクティビティ グラフは、余分な行に折り返されないように、狭いペインで凡例を非表示にします。
  • $ シェル ショートカットは、Ctrl+G で同時にエディタを開いた場合など、明確な理由で起動の失敗を 1 回報告します。
  • /mcp search は、入力した値を使用して URL 変数を含むレジストリ サーバーをインストールします。
  • カスタム ステータス ラインは、色のリセット後に文字が消えることなく、端末の色と書式を正しくレンダリングします。
  • フック承認ダイアログでは、ツール名と引数の制御文字を非表示にしたりスタイルを変更したりするのではなく、表示テキストとして表示します。
  • /session delete-all、/session prune、および /session delete は、同じウィンドウ内のバックグラウンドで実行されているセッションを保持します。
  • 1 行に収まるテキストは、端末のサイズを変更した後も 1 行に留まります
  • /workflows では、実行のエージェント リストが短いターミナルの下部に表示されなくなりました。選択したエージェントは画面上に残り、長いフェーズのタイトルは 1 行に残ります。
  • コパイロット プラグインの有効化、無効化、更新、アンインストールが失敗し、解析できない場合、変更なしで成功したこと、またはプラグインがインストールされていないことを報告するのではなく、config.json という名前が付けられるようになりました。
  • --no-color は、FORCE_COLOR が設定されている場合でも、色を無効にしながらテキストのスタイルを保持します。
  • 貼り付けられた入力をマークする端末に貼り付けた直後に Enter キーを押すと、貼り付けられた画像パスが正しく添付されます。
  • 短い端末でナビゲーション キーで選択を移動できない場合でも、選択された/共有アクションを表示したままにします
  • MCP フォームでは、Ctrl+G を使用して外部エディターで編集された回答に対して検証エラーがすぐに表示されます。
  • 以前のセッションなしで copilot --continue を実行すると、ようこそヘッダーと [はじめに] ボックスが表示されます。
  • ナビゲーション中にダイアログが開いたときに「セッション」タブの応答性を維持し、応答できる保留中のダイアログを表示します
  • 強調表示された確認オプションが [セッション] タブと短い端末の /environments に表示されたままになります。
  • 幅の狭い端末では、/テーマ ピッカーのタイトルと枠線を画面上でドッキングされたセッション サイドバーの横に維持し、代わりにプレビューをドロップします。
  • /share 画面では、選択したアクションが狭い端末でも表示されます。
  • /ask および /btw は、狭いターミナルのセッション サイドバーの横に回答を正しく表示します
  • タスクリストが端末に表示できるよりも長い場合、/tasks のタイトルと境界線を表示したままにします
  • copilot -p "/compact" --silent は圧縮結果行を標準出力に出力しなくなり、--silent の出力はエージェントの応答に限定されます。
  • 短い端末で起動アニメーション中に複数行の下書きを入力するときに、プロンプト、タブ バー、ステータス ラインを表示したままにする
  • /diff は、名前変更中に行われた編集を含む、段階的な名前変更を新しい名前で表示します。
  • 実験的な動的ワークフローでは、ワークフロー自体のエージェントはワークフローの実行を開始または再開できなくなりました。そのため、すべてのツールが許可されている場合、ワークフローはそれ自体のコピーを無制限に開始できなくなりました。
  • 16 色または 256 色の端末でハイ コントラスト テーマを使用すると、[セッション] タブには選択した行のステータス アイコンが青地に青で描画されるのではなく表示されます。
  • エージェントの作業中に入力されたフォローアップは、入力された順序で実行されるようになりました。 2 つのターンの間にセッションに到達したものは、その後に入力されたフォローアップによって追い越されることはなくなりました。
  • /usage アクティビティ グラフでは、サブエージェントまたは自動操縦のプロンプトではなく、入力したプロンプトのみがカウントされ、そのメッセージの合計はグラフが描画される日数と一致します。
  • 貼り付けたエスケープ シーケンスによってテキストの色が変更されたり、検索フィールドのテキストが非表示になったりしなくなりました
  • --trust-folder を指定した copilot -p は、リポジトリのサブディレクトリから実行され、リポジトリ ルートのフックがロードされていないことを警告し、フックをロードする方法を指示します。
  • カスタム ステータス行は、コマンドが非 ASCII 文字を分割して書き込む場合でも、非 ASCII 文字を正しく表示します。
  • 端末のサイズを変更した後にラップされた行からインライン コードをコピーすると、余分な非改行スペースが含まれなくなりました。
  • キューに入れられたスラッシュ コマンドは、失敗したときに何も表示されずに消えるのではなく、エラーが表示されるようになりました。
  • ターン終了時に送信されるプロンプトは、バックグラウンド エージェントの完了を待たずに実行されるようになりました。
  • マウスの左ボタンを押したままにしないと、セッション分割線またはスクロールバーのドラッグが正常に終了するようになりました。
  • --disallow-temp-dir が設定されていない限り、macOS の /tmp にある独自のスクラッチ ファイルをパス許可プロンプトなしで許可します
  • モデルの切り替えまたはセッションの圧縮後に画像またはドキュメントを再添付すると、そのコンテンツがモデルに送信されます
  • /update がリリースをダウンロードできない場合、ダウンロードの進行状況メッセージを無期限に残す代わりにエラーを表示します
  • /new または [セッション] タブで開始されたセッションは、リモート セッションが有効な場合、GitHub から制御できます。
  • プラグイン フックの作業ディレクトリと環境値の ${COPILOT_PLUGIN_ROOT} を展開します。
  • プッシュ トゥ トークは、押したままにすると口述テキストを保持します。スペース キーは一時停止と再開を繰り返します。
  • リモート MCP サーバーの OAuth サインインは、Kerberos (ネゴシエート) 認証を必要とするプロキシを通じて機能します。
  • 許可のプロンプト、質問、確認をサブエージェント ビューに直接表示するため、画面を離れることなく応答できます。
  • ターミナル制御シーケンスの後のテキストをラベルと出力に表示したままにし、埋め込み画像データを非表示にします。
  • /skills、/mcp、および /plugin での検索は、ターミナルのエスケープ シーケンス内に隠された単語ではなく、表示されているテキストと一致します。
  • Copilot Fusion プロファイルを切り替えるときに、フッターとカスタム ステータス行から以前のプロファイルのルーティングされたモデルをクリアします。
  • 素早く入力するときに、@ ファイルのメンションと /sandbox のパス補完で古い候補が選択されないようにする
  • /sandbox Credentials タブは、マスクされていない提案とは別に、マスクされた環境変数をカウントします。
  • /resume はセッションの行を整列させ、--screen-reader で列を表示し続け、未読ステータスを一度通知します
  • 最後の行を cli 削除したり余分な空白行を残さずに、折り返された日本語、中国語、韓国語のテキストのすべての行を表示します。
  • テキスト選択のドラッグ中にターミナルのサイズを変更すると、空の行やハイライトされていないテキストをコピーする代わりに、clipboard が保持されます。
  • 作業ディレクトリより上でファイルの変更が無視される場合でも、@ ファイル ピッカーを最新の状態に保ちます
  • 自動操縦の確認では、管理者ポリシーによって無効になっている場合に補助アクセス許可が非表示になり、それらが使用できない理由が説明されます。
  • /config ビュー タブと選択したビューを幅の狭い端末のスクリーン リーダー モードで読める状態に保ちます。
  • macOS および Linux で CLI を終了すると、終了信号を無視する場合でも、接続されているバックグラウンド シェルが停止するようになりました。
  • サンドボックス化された MCP 起動エラーは、サーバーがスタック トレースを出力する場合でも、拒否されたファイル システム操作を識別します
  • /mcp トークン数には、client 側ツール検索によって延期されたツールは含まれません。
  • 外部エディタを隠したり開いたりするときに、新しく貼り付けたテキストを保持し、貼り付けの保留中に Ctrl+D キーが終了しないようにします。

  • 素早く入力したときに問題とプル リクエスト ピッカーが古い結果を選択しないようにします

  • /plugin 詳細には、ユーザー スコープ ラベルのないリポジトリ ローカル プラグインが表示され、説明とは別にバージョンが保持されます。
  • ワークスペース MCP サーバーは、/cd の後やサブディレクトリから起動する場合など、構成のディレクトリ レベルから相対的な作業ディレクトリを解決します。
  • /mcp delete は、接続されている他の MCP サーバーを再起動せずにサーバーを削除します
  • セッションのサイドバーとシェルのショートカットのヒントが狭い端末でも読みやすいように、適合しないヒントを非表示にします。
  • キューに入れられた Copilot Fusion のルーティング プロファイルの変更では、現在のターンが終了すると、次のプロンプトの前に確認応答が表示されます。
  • 大きな追跡されていないファイルに対する /diff の応答性を維持し、内容ではなくターゲット パスによって追跡されていないシンボリック リンクを表示します
  • HTML エクスポートとリッチ テキスト コピーでは、Vec<String> や <file> などの山括弧で記述されたジェネリック型とプレースホルダーが保持されます。
  • settings.json が空であるか、空白のみが含まれている場合に画像生成を許可します
  • エリア リストにフォーカスがある間、現在の場所を強調表示したままにして、狭い /config ビューでスクリーン リーダーに通知します。
  • オプションのフィールドを空白のままにしてレジストリから MCP サーバーをインストールすると、プレースホルダー テキストを保存するのではなく、サーバーのデフォルトが保持されるようになりました。
  • カスタム エージェントが名前を共有する場合に /subagents にエージェント ID を表示するので、どのエージェントを構成しているかがわかります
  • 色付きの端末出力または制御文字を貼り付けるときに、/ask および /btw の質問ヘッダーをプレーン テキストのままにします。
  • CLI のテーマが変更されたときに、Ctrl+G で開いたエディターと $ で開いたシェルで端末独自の色を維持します。
  • サーバーにインストール確認フラグがすでに含まれている場合、MCP レジストリのインストールでは npm 起動引数が保持されます。
  • 貼り付け直後に入力したテキストを分離しておき、貼り付けた画像パスが正しく添付され、長時間貼り付けた後のテキストも編集可能なままになります。
  • /config ビュー タブをそのまま維持し、選択した領域を狭い端末でも表示できるようにする
  • CLI が終了する間、エディターのショートカットは非アクティブなままとなり、ターミナルをシェルの準備ができた状態に保ちます。
  • /mcp 認証ピッカーで空の認証チャレンジを返す MCP サーバーを表示します。
  • Ctrl+R 履歴検索にテキストを貼り付けるとエスケープ シーケンスが無視されるため、一致、色、カーソルの位置は正しいままになります。
  • 色付きのテキストを /plugin、/skills、および /mcp 検索に貼り付けると、表示されているテキストと一致し、ダッシュボードの色が保持されます。
  • 絵文字は /model 検索でカーソルの下に表示されたままになり、長い /diff 検索クエリは 1 行でスクロールします
  • [セッション] タブと /resume での長い検索クエリは正しく折り返され、カーソルが入力されたテキストに合わせて配置されます。
  • /diff は、Git コピー検出が有効な場合にコピーされたファイルを正しくリストし、名前がスペースで終わるファイルを保持します。
  • アカウント検索がレート制限されている場合でも、Copilot モデルへのアクセスを維持します
  • 折りたたまれた失敗したシェル行全体の終了ステータスを狭いターミナル内に保持し、その横に収まる限りのコマンドの説明を表示します
  • client ツールの 1 つが実行中に SDK を介してセッションを削除すると、セッションが終了した後にツールのハンドラーを実行したままにするのではなく、そのツールのハンドラーがキャンセルされるようになりました。
  • GITHUB_ASKPASS ヘルパーが応答しなくても、起動が 5 分以上停止することがなくなりました。 1 回のヘルパー タイムアウト後にサインインが失敗するようになりました
  • /code がセッションを VS Code に引き渡した後、同じウィンドウでそのセッションを再開して切り替えても、VS Code チャットでセッションが開いているという通知が表示されなくなりました。
  • 承認ダイアログでコマンドのプレビューをラップするときに、Windows ドライブ文字とそのパスを保持します。
  • 余分な閉じ中括弧があるものや、書き込みの中断により短縮されたものなど、読み取ることができない config.json は、起動時に firstLaunchAt のみを保持するファイルに置き換えられなくなりました。 trusted フォルダー、プラグイン、マーケットプレイス、その他の保存された状態はファイルに残ります。
  • MCP の有効化/無効化とプラグイン コマンドは settings.json が空の場合に機能します
  • セッション開始時に最初の接続を拒否または閉じるリモート MCP サーバーは、セッションの残りの部分で失敗したままになるのではなく、計画どおりに再試行されます。
  • Sidebar.hoverFocus がオフで、sidebar.showCloseButton がオンの場合、マウスをセッション サイドバー カード上に移動しても、選択内容がそのカード上に移動しなくなります。
  • マウスで回答をコピーすると、ブロック引用符内の空白行が保持されます。
  • 「会話履歴の圧縮」カウンタは、0 から再開するのではなく、キュー マネージャを開いて閉じた後に圧縮が開始されたときからカウントし続けます。
  • plugin.json の場所に名前付きパイプまたは /dev/zero などのデバイスへのリンクが保持されているプラグインは、スキル、プロンプト、またはプラグイン リストのロード時にハングしたりメモリを使い果たしたりすることがなくなりました。ファイルは読み取れないマニフェストのようにスキップされます
  • シーケンスがコマンド出力の 2 つの読み取りに分割されている場合、シェル ツールの結果はターミナル エスケープ シーケンスまたはハイパーリンク ターゲットを保持しなくなりました。これは、1 つの読み取りより大きい色付き出力で発生します。
  • /compact の後、ランタイムは次のイベントまで CPU コアをビジーにしなくなり、セッションのライブ イベント ストリームは、圧縮によって以前のイベントが削除された後に到着するイベントをスキップしなくなりました。
  • Assisted Permissions が問い合わせなしに承認したリクエストに対して、permission_prompt 通知フックが実行されなくなりました。
  • CLI の実行中にリポジトリの GitHub リモートを追加または変更すると、すぐに認識されるようになりました。そのため、CLI が再起動するまで、/pr はリポジトリが GitHub に接続されていないことを言い続けることがなくなりました。
  • 拡張機能のロードに失敗した場合、そのログには、単一行ではなく、構文エラーのファイルと行、スタック トレース、およびあらゆる原因を含む完全なエラー レポートが表示されるようになりました。
  • 現在参加しているセッションのセッション サイドバーの行には、実行中のターン全体で動作していることが示され、スクリーン リーダーには「ステータス完了」ではなく「ステータス動作中」と読み上げられます。
  • 自動が選択されている場合、フッターのコンテキストのパーセンテージとステータス ラインのdisplayed_context_limitは、固定の200,000トークンの代わりに、/contextに一致する自動ルーティング先のモデルのウィンドウを使用するようになりました。
  • スタンドアロン CLI は、cli-native.node がなくなった場合に、ネイティブ アドオン "cli-native" が見つからずに毎回起動に失敗するのではなく、キャッシュされたパッケージを再抽出するようになりました。
  • セッション ファイルシステム SQLite プロバイダーがコミットしたが、postCommitAmbiguous として報告されたワークフロー実行が、失敗してキャンセルまたは再開できない保留中の実行を残すのではなく、開始されるようになりました。
  • 短い端末上で多くの機密環境変数を要求する拡張プロンプトは、すべての名前をスクロールして表示から外すのではなく、最初にリストされた名前と残りの数を画面上に保持するようになりました。
  • CLI の選択では、背景色が表示されている場合、装飾的なパディングなしでインライン コードと色見本がコピーされます。
  • 複数の userPromptSubmitted フックからのコンテキストが、最後のフックのコンテキストだけではなくモデルに到達するようになりました。
  • ポリシー ガイダンスおよび管理設定通知に組織サポート リンクを表示します。
