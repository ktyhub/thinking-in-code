副操縦士-cli v1.0.110

2026-11-12

  • 実験的: マスクされたダイアログでエージェント コマンドからの git、ssh、および sudo のパスワード プロンプトに応答します (/experimental をオンにすると有効になります)
  • 組織アカウントが使用可能な場合、Microsoft Entra サインイン中の不要なエラー ポップアップを回避します
  • スクリーン リーダーは現在のセッションを識別し、セッションが注意を必要とするとき、またはセッション リストでアイドル状態になったときに通知します。
  • /usage モデルの行は 100 列で分割されるのではなく、端末の幅で折り返されます。
  • / コマンド ピッカーは、スキルの説明がターミナル エスケープ シーケンス内に隠されている単語のスキルをリスト、事前選択、または実行しなくなりました。説明に示されている単語のみが一致します
  • Ctrl+X ショートカット ウィンドウを閉じるときに入力したキーを保持します
  • 幅の狭いターミナルまたは短いターミナルでは、セッション行と選択カーソルが「セッション」タブに表示されたままになります。
  • /mcp add または /mcp edit で無効な構成ファイルが検出された場合、既存の MCP 構成を保持し、保存エラーを表示します
  • 推論に目に見えない文字のみが含まれている場合、空の思考行を非表示にします
  • テキストを保持しながら、部分的な応答と、中断または失敗した試行からの推論を不完全としてラベル付けします
  • 削除されたディレクトリから copilot を起動すると、ノード スタック トレースでクラッシュするのではなく、ディレクトリがもう存在しないことと回復方法が表示され、そこから -C <directory> が動作するようになりました。
  • ワークフロー実行ツールは、すべてのツール権限が事前承認されている場合に、ユーザーがすべての実行の制限を確認することをモデルに指示しなくなりました。
  • /compact はセッション AI クレジット制限を尊重し、制限に達した場合の追加料金を防ぎます
  • Vim の通常モードでは、$ または End の後の行末に j/k が保持され、短い行にわたって Up/Down を使用するときにカーソル列が保持されます。
  • プラグインのリストには、ディレクトリが欠落している有効なローカル マーケットプレイス プラグインが、有効ではあるがロードされていないものとして説明付きで表示されます。
  • /init stop は、「はじめに」の /init ヒントをすぐに非表示にし、フォルダーに戻ったときにも非表示のままにします。
  • 折り返したプロンプト テキストをコピーすると、視覚的な折り返し時に改行を追加せずに、入力された改行が保持されます。
  • /worktree HEAD および /move HEAD は、失敗する代わりに、正規化されたブランチ名「head」を使用してワークツリーを作成します。
  • /session プルーンとその予行演習は、他のプロセスで開いているセッションをスキップし、スキップされたセッションの数を報告します
  • /statusline プレビューにより、幅の狭い端末でもフッター セグメントが読みやすくなります
  • /mcp の追加および編集フォームで Ctrl+S を押すと、一度保存され、成功メッセージが 1 つ表示され、サーバーがリロードされます。
  • Ctrl+Y および /share リサーチでは、リサーチ フォルダーを読み取れない場合、生のファイル システム エラーではなく、通常のレポートなしメッセージが表示されます。
  • /lsp list および /lsp reload は、誤解を招くキー欠落エラーの代わりに、LSP 構成内の構文エラーを報告します。
  • 名前のないセッションでは、[セッション] タブと /resume リストに短い ID が表示され、再開後も同じラベルが維持されます。
  • アシスタントの応答は、右端で正確に終わるインライン コード スパンの後の行をインデントしたり折り返したりしなくなりました。
  • セッション サイドバーがドッキングされている場合、/lsp logs、/every スケジュール マネージャー、/workflows、および /mcp add フォームは、端で切り取られるのではなく、ペインの横に収まります。
  • スクロールアップされた会話でマウスを選択すると、プロンプトまたはステータス ライン上で放したときに強調表示されたテキストのみがコピーされます
  • /agent および [セッション] タブ内の検索は、非表示のエスケープ シーケンスではなく、表示されているテキストと一致します。
  • Ctrl+R 履歴検索は、分解されたアクセントを持つ一致を強調表示し、スクロールし、カーソルを置きます。
  • settings.json に無効な値がある場合、プラグインのインストール、アンインストール、有効化または無効化、またはマーケットプレイスの追加または削除を行っても、他のプラグインやマーケットプレイスの設定が消去されなくなりました。コマンドはエラーを報告し、ファイルは変更されないままになります。
  • アイドルプロンプトで失敗したスラッシュコマンドは、コマンド名と理由を含むエラーを表示するようになりました。
  • スラッシュ コマンド ピッカーは、capital 点線 I を含む説明内で一致する文字に正しく下線を引きます。
  • /cwd、/cd、および /add-dir は、ディレクトリの候補が更新される前に Enter キーを押したときに入力したパスを使用します。
  • 許可プロンプトで Enter を 2 回押すと、誤った再試行警告が表示されずにリクエストが承認されます。
  • 行内に収まる単語を分割したり、途中で折り返したり、先頭のスペースや空白行を追加したりせずに、プロンプト テキストを折り返します。
  • キーボード ショートカットの後に入力したり、遅い端末接続で貼り付けたりするときに、アクセント付き文字と CJK 文字をそのまま維持します。
  • copilot config <key> および /settings show <key> を使用して、フック定義などの JSON 値の設定を読み取ります。
  • Ctrl+C で ! を停止します。シェルコマンドを送信した直後に押した場合でも
  • /settings のメモリ変更は、CLI を再起動しなくても有効になります。
  • JSON ツールの結果をプレビューや展開ビューで表示するときに、正確な番号、重複キー、およびキーの順序を保持します。
  • /model --global または /model --repo でデフォルトを保存した後、リポジトリ設定が新しいセッションの推論作業をオーバーライドするときに警告する
  • /context は、ロードされたカスタム命令をシステム プロンプトに含めるのではなく、別のトークン数として表示します。
  • CLI が -Csub または -C=sub などのディレクトリ引数を付けて起動されたときに /restart が機能するようにします。
  • /compact がキャンセルされた場合、または圧縮するものが何もない場合に、圧縮するものが何もないことをエラーとして処理せずに、単一のステータス エントリを表示します。
  • 使用可能なペインの幅にレイアウトを合わせることで、ドッキングされたセッション サイドバーの横で /config と /settings を読み取れるようにします。
  • 非対話型実行を含め、バイパス許可モードが無効になっているために --yolo または --allow-all フラグが無視された場合に警告を表示します
  • シェル補完は、--effort、--no-remote-export、および裸の --sync-session フラグの後に機能します。完了スクリプトを再生成して適用します
  • 見つからない MCP サーバーを無効にするコマンドを提案するのではなく、欠落している MCP サーバーを copilot mcp remove および /mcp delete で見つからないものとして報告します。
  • /new worktree、/fork worktree、または /resume が別のディレクトリでセッションを開くときに、MCP リロード通知を 1 回だけ表示します
  • capital ドット付き I を含む名前のディレクトリおよびエージェント ピッカーでの強調表示と絵文字表示を修正しました。
  • /skills reload は、/skills list と同じスキル数を報告します。
  • mcp-config.json が無効な場合でも、ほとんどのサーバーで copilot mcp enable を許可します
  • ダイアログとテーブルは、clipped テキストや列なしでセッション サイドバーの横に収まり、/sandbox は幅の狭い端末にフィットします。
  • /subagents で user-invocable: false とマークされたカスタム エージェントを表示し、モデルを構成してオンまたはオフにできるようにします
  • copilot instruction list でデフォルトでオフになっているプラグイン ルールを表示します
  • /env で設定されているとおりにマークダウン文字を含む名前とファイル パスを表示します。
  • NO_COLOR が設定されている場合、色を追加せずにテキストの選択範囲を表示したままにします。
  • cli がプロンプトのラベル内に移動して入力するときに、添付ファイルと貼り付けたテキストをそのまま維持します
  • シェル コマンドの出力を書き換える postToolUse フック (たとえば、シークレットを編集する) は、モデルが受け取る内容だけでなく、シェルの行と copilot -p が出力する内容を再度変更します。
  • /settings に保存されている URL ルールを再起動せずにアクティブなセッションに適用します
  • セッション サイドバーがドッキングされているときに /model の詳細を表示したままにする
  • /diff 内の非 UTF-8 ファイル名を持つ変更されたファイルをパッチも含めて表示します
  • マウスを使用してプロンプトからテキストをコピーするときに空白行を保持します。
  • /settings および /config のマウス スクロールと clicks は、セッション サイドバーがドッキングされた状態で正しく動作します。
  • 制御文字を含むフォルダー名またはエージェント名を入力した後、入力したテキストが表示されたままになり、カーソルが位置合わせされます。
  • /model スイッチがキューに入れられているときに Esc Esc でターンを中断したときにキャンセルを 1 回だけ表示します
  • /settings の問題を削除すると、無関係な行にジャンプするのではなく、最初に残った行の選択が保持されます。
  • ツールの結果とアシスタントの応答に Unicode の行区切り文字や段落区切り文字が含まれている場合、それらを読みやすく整列させます。
  • 短い /search クエリを編集した直後に Enter、Up、Down キーが応答し、最後に一致した部分から新しいクエリを開始するようにします。
  • リモート MCP ツールは、サーバーの応答に切り詰められた絵文字が含まれている場合でも、タイムアウトすることなくロードして応答します。
  • /settings リストの最初の項目にスクロールして戻るときにグループの見出しを表示したままにする
  • /ask と /btw は起動時にサインインが完了するのを待ち、サインアウトしたユーザーに /login を実行するよう促します
  • [セッション] サイドバーをスクロールまたは cli クリックしても、構成の検索結果は変更されません。
  • settings.json が代替キーのスペルを使用し、無効な値が含まれている場合、起動時にプラグインの有効化設定を保持します。
  • セッション所有のインデックス付き検索サーバーを停止するときに、/exit および /cd での 5 秒の遅延を回避します。
  • ファイルタイプのバッジの NO_COLOR を尊重し、NO_COLOR または TERM=dumb でスクロールバーのサムカラーを無効にします
  • コマンドが Unicode の行区切り文字または段落区切り文字を印刷するときに、シェル出力の位置を揃えて表示アーティファクトを発生させないようにします。
  • mcp-config.json がまだ存在しないファイルへのシンボリックリンクである場合、copilot mcp の追加と削除を許可します
  • アシスタントが目に見えないコンテンツを返信しても、会話内に空の箇条書きが表示されなくなりました。
  • リポジトリが同じ名前のローカル マーケットプレイスを定義している場合、リモート マーケットプレイスからプラグインをインストールしたままにする
  • /ahp sessions の絵文字をそのままにし、幅の広いセッション タイトルを列制限内に保ちます
  • ツール検索が有効になっているサーバーを無効にした後、/mcp で残りの MCP サーバーのツール トークン カウントを正確に保ちます。
  • 画面上に更新ステータスを残すのではなく、/mcp、/skills、および /plugin のインストール済みビューに更新の完了を表示します。
  • 「セッション制限に達しました」をキャンセルすると、待機中のメッセージが送信されずにクリアされ、メッセージごとにダイアログが再度開かれます。
  • /mcp は、カスタム エージェントによって提供されるサーバーの正しいリポジトリまたはプラグインのオリジンを示します
  • Ctrl+C でシェル モードを終了すると、終了ヒントがクリアされるため、次に押すと終了する前に警告が表示されます。
  • 端末のサイズが変更されたときに、フォーカスされたフィールドとそのオプションを MCP 設定フォームに表示したままにします
  • セッション サイドバー ヘルプのステータス凡例を狭いペインで完全に表示できるようにする
  • ユーザー検索の期限が切れた後に一度に開始された複数の CLI は、ユーザーを 2 回検索し、開始する前に 2 回目の検索を待機することがなくなりました。
  • セッション制限によりプロンプトがブロックされると、それ以降ブロックされるプロンプトも応答なしで終了するのではなく、制限を報告します。非対話型セッションでは、ブロックされた各プロンプトがセッション制限エラーで失敗します。
  • 名前が既に使用されている場合に、/mcp add および /mcp edit が既存の MCP サーバーを上書きしないようにします
  • copilot -p は、ユーザーの mcp-config.json を解析できないなどの理由で MCP サーバーを起動できない場合、警告なしで続行するのではなく、標準エラー出力と JSON 出力で警告するようになりました。
  • セッション中に /model から追加および選択されたローカル モデルでは、フッター、/usage、または終了概要に Copilot プラン クォータと AI クレジットが表示されなくなりました
  • コパイロット プラグイン マーケットプレイス リスト、参照および更新はリポジトリのサブディレクトリから実行され、現在のディレクトリではなくリポジトリ ルートでリポジトリの相対ディレクトリ マーケットプレイスを検索します。
  • 同じ名前のサーバーをインストールするときに、既存の無効な MCP サーバー構成を保持します。
  • macOS 13 以前では、CLI はネイティブ アドオン読み込みエラーで終了するのではなく、macOS 14 以降が必要であると表示するようになりました。
  • /remote on と /remote share は、受信接続を有効にするために /environments にユーザーを送信するのではなく、組織がリモート制御を無効にしていることを通知するようになりました。これもポリシーによってブロックされます。
  • Providers.json が構成されているが、GitHub でホストされるモデルが選択されており、/usage とフッターが一致している場合、終了サマリーに AI クレジットが再度表示されます。
  • ユーザー設定に適用されない管理者のみの制限が含まれている場合は、アシストされたアクセス許可の起動デフォルトを尊重します。
  • ブラウザーで待機している MCP サインインは、アカウントのサードパーティ MCP ポリシーによってサーバーがブロックされると、サインインを終了して使用できなくなったサーバーのトークンを保存するのではなく、停止するようになりました。
  • grep および glob の検索行では、postToolUse フックの追加Context が結果としてカウントされなくなりました。そのため、何も一致しなかった検索では、見つかった 4 つのファイルが読み込まれなくなりました。
  • /settings ダイアログと /config では、/streamer-mode を使用できないアカウントに streamerMode が表示されなくなりました。設定がすでにオンになっているアカウントには引き続きその行が表示されるため、オフにすることができます
  • インデックス付き検索は、長いセッションで時折接続が失われても、残りのセッションでは ripgrep に切り替えるのではなく、再接続を続けます。
  • IDE diff の受け入れまたは拒否は、別の MCP サーバーのステータスが変更された場合でも機能します。
  • copilot --resume で再度開かれたセッションは、開くとすぐに使用中としてマークされるため、アイドル状態の間に copilot -p --resume と 2 番目のウィンドウが書き込みを行うことはなくなりました。
  • カスタム ステータス行は最初の行のインデントを保持するため、すべての行が一貫して整列します。
  • 端末のスタイルやハイパーリンクを適用する代わりに、/settings リスト項目に制御文字を表示します。
  • 波線ダッシュや同様の幅の広いシンボルを含むマークダウン テーブルは、正しく配置された行でレンダリングされます。
  • /logout が無効な認証情報を持つ最後に保存されたアカウントを削除した後、再起動を必要とせずにサインイン プロンプトを表示します
  • 折り返されたテキストは、段落内に余分な空白行を挿入せずに、各行の全幅を使用します。
  • copilot mcp add は既存の無効なサーバー エントリを保存し、名前を再利用する前に削除するように求めます。
  • settings.json に無効な値が含まれているか解析できない場合、起動時にプラグインの基本設定と設定ファイルを保持します。
  • シェルと検索の結果には正確な行数とファイル数が表示され、AI クレジット制限が設定されている場合はモデルのみのコスト ガイダンスが省略されます。
  • Vim モードの j/k モーションは、gg、ge、operator、または redo の後に現在のカーソル列を使用します。
  • カスタム エージェント名とモデルを /subagents にプレーン テキストとして表示し、テーブルの列を整列させてターミナルの書式設定やリンクが埋め込まれないようにします。
  • 返信に唯一の UTF-16 サロゲート エスケープ (絵文字内のツール説明など) が含まれるローカル MCP サーバーが 60 秒後に失敗したり、ツール呼び出しが 3 分間ハングしたりすることがなくなりました。返信は置換文字で読み取られます
  • プラグインの切り替えは、リポジトリで制御されるライブ プラグイン設定を尊重し、リストとアクティベーションの間で一貫して同じマーケットプレイス ソースを使用するようになりました。
  • 失敗した圧縮結果とキャンセルされた圧縮結果をタイムラインに表示し、再起動と再開のガイダンスでメモリプレッシャー圧縮について説明します。
  • 機能ブランチの /diff は、ファイル リストから除外するのではなく、名前にアクセント付き文字や他の非 ASCII 文字、二重引用符、バックスラッシュ、またはタブが含まれるコミットされたファイルをリストするようになりました。
  • コパイロット ヘルプ ネットワークは、Linux 上の untrusted プロキシ CA についてコパイロットが報告する証明書エラー (「証明書の検証に失敗しました」、「ローカル発行者の証明書を取得できません」) を引用するようになりました。メッセージは生成されなくなりました。
  • copilot help permissions では、決して一致しないルールの例として shell(gh pr create) が示されなくなりました。現在は shell(gh pr) を使用し、最初のサブコマンドのみがコマンド名の一部であると説明しています。
  • /mcp reload は、MCP 構成をロードできなかったときにサーバーが再起動されたことを示さなくなりました
  • skills、skill、tools、messages などのトップレベル キーも持つ MCP ツールの結果が、ツール呼び出しに失敗するのではなく、モデルに到達するようになりました。
  • /every と /after は、自然言語時刻が解析されるときに複数行のプロンプトの改行とインデントを保持します。行を結合したり、繰り返されたスペースを折りたたんだりするのではありません。
  • 「考えられた」期間は、各推論パートが終了すると更新され、回答のストリーミングに費やされた時間は含まれなくなります
  • 分岐したセッションを終了サマリーに名前で表示し、再開コマンドを識別しやすくします。
  • /share file および /share html は、非表示または誤って配置されたエクスポート ファイルを作成する代わりに、ディレクトリ パスを拒否します。
  • コパイロット構成がコメントのみを含む設定.json ファイルを読み取って更新できるようにします。
  • Linux および macOS では、短縮されたパスによりバックスラッシュを含むフォルダー名が保持されます。
  • copilot -p は、trusted リポジトリのコミット トレーラーの includeCoAuthoredBy 設定を尊重します。
  • スタートアップの自動インストールは、不足しているプラグイン マーケットプレイスを報告する前に管理設定を待機するようになりました。
  • 拡張機能がセッションを自動操縦から切り替えた後、対話型プロンプトが正しく表示されます。
  • /move は、assume-unchanged とマークされたファイルへの編集を保存し、元の作業ツリーに残っているサブモジュールの変更を報告します。
  • /statusline の設定を変更すると、ピッカーが開いている間に別のセッションによって更新された他のフッター設定が保持されます。
  • ディレクトリを変更するシェルコマンドの後に、リポジトリ内読み取りのための不要なパスアクセスプロンプトを回避します。
  • /new または /clear の後でも、CLI を再起動せずに、永続的に承認された URL を承認されたままにします。
  • JSON プロンプト モードは、認証が失敗した場合、またはプロンプトが空白の場合に最終結果レコードを出力します。
  • プロンプトを黙ってドロップしてサブコマンドを実行するのではなく、サブコマンドと組み合わせたプロンプト オプションを拒否します。
  • 空のディレクトリ パスを入力した後に Enter キーを押すと、Windows 上で /add-dir または /cd が確実に実行されます。
  • 同様の名前の兄弟ディレクトリではなく、/cd、/cwd、および /add-dir に入力された正確なディレクトリ名を使用します。
  • フォルダー trust ダイアログに制御文字を表示し、フォルダー名が非表示の書式設定や余分な行なしで表示されるようにします。
  • ファイルまたはディレクトリが大きすぎて読み取りまたは一覧表示できない場合、折りたたまれたツールの結果で誤解を招くカウントを報告するのではなく、表示します。
  • リポジトリ設定が新しいセッション用に保存されたデフォルト モデルをオーバーライドするときに警告し、引き続き適用されるモデルと設定ファイルに名前を付けます
  • 空の、または完全にコメントされたリポジトリ設定ファイルを、起動警告や解析エラーなしで空の設定として扱います。
  • 複数行の出力を含む折りたたまれた失敗したシェル行にコマンドの説明と終了ステータスが表示されるようにします。
  • Ctrl+R 検索とセッション確認で貼り付けたターミナル テキストを単純に表示するため、エスケープ シーケンスでテキストの色を変更したり非表示にしたりできません
  • サンドボックス設定には有効なデフォルトが表示され、最初に押すとデフォルトでオンになっているオプションがオフに切り替わります。
  • settings.json が無効な場合に、重複した誤解を招くポリシー更新警告を表示せずに設定ファイル エラーを表示します。
  • /settings から保存されたフックの変更は、CLI を再起動せずに次のプロンプトに適用されます。
  • IDE 自動接続は、/cd の後の現在のフォルダーに従い、エディターの選択内容と差分を正しい IDE に保持します。
  • 拡張されたシェル出力では、差分前後のテキストが保持され、差分のみの出力のファイル名が表示されます。
  • プラグイン言語サーバーが正常にロードされたときに、copilot lsp list 出力に警告が表示されないようにする
  • アクティブな音声モデルを削除すると、音声モードがオフになっていることと、別のモデルを選択する方法が表示されるようになりました。
  • 検索結果が大きすぎてリストできない場合、間違った一致数の代わりに出力サイズを表示します。
  • MCP サーバーおよびスキルの有効化/無効化コマンドは、--Additional-mcp-config または --plugin-dir を通じて指定された名前の成功を正しく報告します。
  • 行が非表示の幅ゼロ文字で終わる場合、ダイアログの境界線とパディングを揃える
  • 計画およびタスクの概要のリスト項目は、リテラルのアスタリスクまたは数字で終わる文が含まれる場合、1 行に留まります。
  • copilot plugin list および --json 出力の組み込みプラグインに対する組織の管理設定によって強制された有効な状態を表示します。
  • CLI を再起動せずに、/settings のバイパス許可モードを無効にする変更を直ちに適用します。
  • /cd、/cwd、および /add-dir は、兄弟が大文字と小文字またはアクセントだけが異なる場合に、入力した正確なディレクトリ名を選択します。
  • 組み込み名を持つカスタム エージェントを /subagents から非表示にし、コントロールが組み込みエージェント設定を変更できないようにします
  • 展開されたシェル行で git status --short などのスペースに依存する結果が正しく表示されるように、シェル コマンド出力の最初の行のインデントを保持します。
  • シグナルによって終了されたシェル コマンドは、SIGKILL の場合は 137、セグメンテーション フォールトの場合は 139 など、正しい終了ステータスを報告します。
  • エージェントの動作中にキューに入れられたモデルの切り替えが有効になったときに確認を表示します
  • コマンド出力が大きすぎて表示できない場合、シェルの概要の誤った行数の代わりに出力サイズを表示します。
  • フッター コンテキストの使用率は、/context と同じ事前リクエストの割合を示します。
  • GitHub ホスト モデルが選択されている間は、providers.json がカスタム プロバイダーを構成している場合でも、プラン クォータとコパイロットの使用量はステータス ライン、/usage、および終了概要に表示されたままになります。これらは、そのプロバイダーのモデルが選択されている間のみ非表示になります。
  • 過去のプロンプトのセッションメンションを保存するファイルが破損しているか、新しいバージョンで書き込まれた場合、プロンプト履歴が非表示にならなくなり、次のプロンプトによって消去されるようになりました。
  • Ctrl+Y フッター ヒントは、セッション開始直後に書き込まれた計画を見逃すことがなくなり、計画ファイルが監視できない場合でも更新を続けます
  • フック イベントおよびその他の JSON 設定は、エディターから /settings に保存できます。 unset フック イベントが空のリストとして開くようになりました
  • --resume を使用して名前でセッションを再開しても、テレメトリでセッション名が送信されなくなりました。セッションIDのみが報告される
  • 終了時に、すでにシャットダウンしたセッションのクリーンアップに関する数十のエラーがプロセス ログに書き込まれなくなりました。
  • settings.json に無効な値がある場合、/sandbox は保存されたサンドボックス設定をデフォルトに置き換えなくなりました。代わりに読み込みエラーが表示され、許可プロンプトから保存されたサンドボックス パスはサンドボックス ブロックを上書きせずに拒否されます。
  • コンパクトおよびスイッチの圧縮中に送信されたプロンプトは、圧縮が完了するまで消えるのではなく、再びキューに入れられたものとして表示されます。
  • MCP サーバーを無効にすると、別のモデルの応答を待たずに /mcp 内のトークン数が更新されます。
  • Linux では、ファイルを監視する言語サーバーは、2 つのファイルまたはディレクトリが一時名を介して交換された後、ディスク上に残っているファイルが削除されたことを通知されなくなりました。
  • trusted フォルダー内の copilot -p は、プラグインのロードが同時に終了したときにリポジトリのフックなしで実行されることはなくなりました
  • copilot mcp remove および /mcp remove は、サーバーが見つからなかったことを報告する代わりに、無効としてスキップされた mcp-config.json エントリを削除するようになりました。
  • /resume を使用して ID または名前でセッションを再開すると、開いたままにしたセッションがバックグラウンドで維持されるため、引き続き sessionEnd フックが実行され、シャットダウンが記録され、終了時にリストに表示されます。
  • 1 分以内に終了する copilot -p およびその他の CLI の実行には、プロセス ログの保持が適用されるようになりました。そのため、古いログは実行ごとに 1 つずつ蓄積されるのではなく、7 日後に削除され、最新の 50 を超えて削除されます。
  • copilot plugin marketplace add ./name、../name、~/name は、GitHub リポジトリのクローンを作成する代わりに、ローカル マーケットプレイス ディレクトリを追加するようになりました。
  • 実行中にサンドボックス設定が変更されたために強制終了されたシェル コマンドは、出力なしで成功したコマンドとして報告されるのではなく、失敗として報告されるようになりました。
  • CLI の起動中にセッションのモデルが変更された場合でも、サポートされていない --reasoning-effort 値の警告が失われなくなりました。
  • copilot help '' は、copilot help と同様に、一般的なヘルプを出力し、正常に終了します。
  • 圧縮するものが何もない /compact では、タイムラインに古い「会話履歴を圧縮しています...」行が残されなくなりました。
  • 読み取れない、または JSON オブジェクトではない mcp-config.json は、ファイル名と実際の問題を示すエラーで失敗するようになりました。また、コメントや末尾のカンマのあるファイル内の構文エラーは、最初のコメントやカンマではなく実際の間違いを示します。
  • /user スイッチで使用できないアカウントを選択すると、回復ガイダンスと再試行アクションが表示されます
  • 拡張推論の任意の場所で Click を実行すると、ヘッダーにスクロールせずに折りたたむことができます。
  • エージェントがツールにアクセスできなくなる前に、使用率 90% でセッション AI クレジット制限の補充を提供します
  • 従来のリモートステアリングを削除します。クラウド セッションとリモート接続には AHP 環境が必要になりました
