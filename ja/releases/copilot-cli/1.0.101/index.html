copilot-cli v1.0.101

副操縦士-cli v1.0.101

2026-10-20

  • サポートされているモデルで動的ワークフロー サブエージェントのネイティブ構造化出力を追加
  • AssistedPermissions の確認決定をガイドするための、assistedApprovalInstructions 設定を追加します。
  • ディレクトリを作成してディレクトリに入るシェル コマンドは、早期に拒否されるのではなく、パスの承認を要求するようになりました。
  • 保存されたトークンにサインインが必要な場合、OAuth ハンドラーを使用しないヘッドレス セッションと SDK セッションは MCP 接続をスキップしますが、更新可能な許可は引き続き接続します。
  • macOS サンドボックス コマンドは、ローカル アクセスが有効でホスト フィルターが適用されない場合、localhost TCP サービスに直接接続できます。
  • Providers.json のローカル モデルとループバック プロバイダーは、Copilot へのサインイン時に Auto、保存されたモデル、またはデフォルト モデルをブロックしなくなりました
  • 明示的な Entra MCP サインインは、対話型サインインを続行することで、拒否されたキャッシュされたトークンから回復するようになりました。
  • 推論作業のみを切り替えると、予算を超えるセッションで圧縮が強制されなくなりました。
  • コピー キーは、ドラッグした直後に押した場合でも、マウスの選択内容を確実にコピーするようになりました。
  • 放棄された Microsoft サインイン フローをキャンセルして、再試行を正常に開始できるようにします
  • 起動状態が変更されていない場合でも、設定された MCP インベントリの読み取りが失敗しなくなりました
  • Google モデルは、スクリーンショットを大量に使用するセッションが画像制限を超えた場合にリクエストの繰り返しの書き換えを回避し、余分なトークンの使用を削減します。
  • チーム定義の GitHub マーケットプレイスからチームが割り当てたプラグインをインストールします
  • 拡張機能リクエストでは、判事補の代わりに明示的な承認を使用します。
  • 共有 MCP 認証エラーは、client のサインイン設定を示しています。 CLI 認証警告には引き続き /mcp auth が表示されます。
  • GPT モデルから Gemini への切り替えは、初期のターンにカスタム ツール呼び出しが含まれている場合でも失敗しなくなりました。
  • Google モデル リクエストは、イメージ数リクエストの失敗を回避するために、レジストリ イメージの制限を考慮するようになりました。
  • 起動時にモデルが選択されていない場合に、最初のプロンプトが何も表示されずにハングすることがなくなりました。 CLI では、/model を使用して選択するよう求められ、プロンプトが維持されます。
  • /usage には、「不明なプロバイダー」ではなく、プロバイダー ラベルなしで BYOK のモデル名だけが表示されるようになりました。
  • 入場制限プロンプトをキャンセルすると、バックグラウンド作業が継続している間、追加の入力を必要とせずに Enter キーが再び有効になるようになりました。
  • モデル ピッカーは、管理者が管理するモデルが使用可能な場合、デフォルトとしてマークします。
  • ICC カラー プロファイルを含む MCP PNG 画像を省略せずに保存します
  • Windows シェル コマンドは復元されたセッションで確実に開始され、孤立した子プロセスをクリーンアップします。
  • HydraFusion への切り替えは、ルーティングされたモデルが実際に必要な場合にのみ圧縮します
  • CLI モデルのリストは、エンドポイントの更新後に古いまたは空のままではなく更新されます。
  • Windows タスクバー アイコンのステージングにより、一時ファイルの同時衝突が回避されるため、起動後もアイコンの存在が安定します。
  • セッションを再開すると、プレースホルダー環境のセットアップを待たずに会話がすぐに表示されます
  • サンドボックス化された MCP サーバーとのセッションを開始すると、不必要な再起動が回避され、応答が速くなります。
  • /config および /settings で showReasoning を設定および設定解除できるようにする
  • 権限承認プロンプトでエスカレーションの原因を説明し、リクエスト固有の診断コマンドを表示します
