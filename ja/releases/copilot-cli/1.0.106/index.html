副操縦士-cli v1.0.106

2026-11-05

  • Rex 端末は、Kitty の直接配置を使用してインライン画像をレンダリングします。
  • /code コマンドを追加して、VS Code で現在のセッションを開きます
  • Fusion 層設定を copilot config に追加します。
  • /settings を使用してすべてのユーザーに対して統合ダッシュボードを開き、設定とローカル リソースにわたるグローバル検索を追加します。
  • インタラクティブな CLI は、注意が必要な場合を含め、プログラムのステータスをサポート端末に報告します。
  • オプトイン セッション管理ツールとオプトイン ローカル セッション用の @メンションを追加します
  • LSP およびローカル MCP サーバー構成を起動および拡張するための COPILOT_SESSION_CWD を追加します。
  • アカウントで利用可能な場合、GPT-6.1 Terra を新しいモデルの下に選択可能なモデルとして追加します
  • サンドボックス内で拡張機能プロセスを実行するためのサンドボックス拡張機能設定を追加します。
  • client テレメトリ オプトアウトを考慮して、OneAuth を介した Entra 認証用の MATS テレメトリを追加します。
  • Ctrl+U、Ctrl+K、または Ctrl+W でプロンプトから削除された画像、または呼び出された履歴エントリに置き換えられた画像は、メッセージと一緒に送信されなくなり、後で Ctrl+S でプロンプトを隠しておくことができます。
  • NEL、Unicode 行区切り文字、または段落区切り文字を含むテキストを貼り付けた場合、別のプロンプト行が埋められるようになり、貼り付けられた DEL および C1 制御文字は、プロンプト内に保持されて行の末尾から文字が切り取られるのではなく、削除されます。
  • copilot -p --plan では、エージェントは、プラン モードを終了するために Shift+Tab を提案するように指示されなくなりました。これは対話型インターフェイスでのみ機能し、代わりに、応答にプランのキー ポイントを含めるように求められます。
  • Copilot タスク サービスが応答しない場合に、copilot --resume <id> が出力も終了もせずに待機することがなくなりました。タスクの検索は 10 秒後に中止され、解決が続行されます。
  • サンドボックス化された grep、rg、および glob は、サイレント不一致結果ではなく Windows 起動失敗を報告するようになりました。
  • モデル ピッカーは、フラット、価格設定されていない、単層モデルのコンテキスト ウィンドウ サイズを表示します。
  • サンドボックス化されたローカル MCP サーバーは、別の作業ディレクトリで構成されている場合でも、セッション ディレクトリからの相対的なファイル システム アクセス許可を尊重します。
  • CLI が長いディレクトリ パスにインストールされている場合、PowerShell コマンドが Windows 上で動作します。
  • 他のセッションがビジー状態のときにセッションを切り替えても、CLI がクラッシュし、端末が空白のままになることはなくなりました。
  • 破損した画像を含むプロンプトを再試行するときに、読み取り可能な画像添付ファイルを保持します。
  • Copilot CLI 事前認証が利用できない場合、MCP Entra 認証は VS Code 登録にフォールバックするようになりました。
  • サンドボックス化されたローカル MCP サーバーは、相対 cwd で構成された場合に正しく起動するようになりました。
  • Windows では、ネストされた Git ディレクトリ内のサンドボックス セッションは、リポジトリ ルートに変更して書き込むことができます。
  • オートパイロットは、レビューまたは分析のみを要求したリクエストの後に独自の推奨事項の実装を開始しなくなりました
  • プラグインサーバーが変更されていない場合、不要な MCP リロードサマリーを抑制します
  • 負荷がかかっているときに Copilot のサービスが空の 404 で応答するモデル リクエストは、「実行に失敗しました: 404」でターンを終了するのではなく、再試行されるようになりました。
  • copilot help config には、askUser、effortLevel、planModel、toolSearch、worktreeBaseRef など、手書きのテキストから欠落していた設定も含め、設定カタログが提供するすべての設定がリストされるようになりました。
  • ACP clients は、 --yolo で開始されたセッションを自動操縦から切り替えることができ、ポリシーによってブロックされてスイッチが失敗し、2 回目の試行ですべて許可をオフにする代わりに、すべて許可をオンのままにすることができます。
  • @ ファイル ピッカーは、クエリがドットなしで入力された場合に、İstanbul.txt などの capital ドット付き I の名前に下線を引き、その行の一致したフォルダーを短縮しなくなりました。
  • @ ファイル ピッカーは、分解されたアクセントで保存された名前、またはアクセントなしで入力されたクエリで見つかった名前の一致に下線を引き、そのような行の一致したフォルダーを短縮しなくなりました。
  • 複数行のプロンプトで Up および Down を実行すると、キャレットを行の先頭近くに残すのではなく、より短い行を通過するときに開始した列が保持されます。
  • Ctrl+Y および /share Research は、リンク切れやレポートのような名前のフォルダーなど、読み取り不可能なファイルであるリサーチ フォルダー エントリを、失敗したり提供されたりせずにスキップします。
  • 複数のエージェントが表示名を共有する場合、/agent に各エージェントの選択 ID を表示します。
  • 編集ツールは、ターンを停止させる FIFO のもう一方の端を永遠に待つのではなく、名前付きパイプ、ソケット、またはデバイスですぐに失敗するようになりました。
  • 空の plan.md では、ctrl+y の計画ヒントまたは /session の Plan: yes が表示されなくなり、代わりに ctrl+y を押すと、/session plan と一致するリサーチ レポートが開きます。
  • フッターは、行の終わりから項目を切り取るのではなく、ディレクトリとブランチを最初に短縮することにより、狭い端末上で「N スケジュール済み」、サンドボックス、YOLO、および CI ステータス項目全体を保持します。
  • プル リクエスト、発行、要旨の詳細、およびそれらのロード エラーで、タイトル、名前、ブランチ、要旨ファイル、またはサーバー メッセージのエスケープ シーケンスによってターミナルのスタイルが変更されなくなりました。
  • 自動操縦セッションを再開するときに、保存された一時停止された目標と継続ガイダンスを表示します。

  • copilot help limits は、実際の最小 AI クレジット限度額でのステータスの例を示し、限度額の 10% 以下が残っている場合に最終コール警告が表示されると述べています。

  • /user スイッチ、環境および /mcp 認証ピッカー、Run on: ステータス、発信接続リストでは、名前、パス、または URL のエスケープ シーケンスによってターミナルのスタイルが変更されなくなりました。

  • /pr は、クローズまたはマージされたドラフトをクローズまたはマージとして表示し、 | を含むブランチ名とラベルを保持します。チェック実行はそのままであり、開始に失敗したチェック実行、またはアクションを待機しているチェック実行は、保留中ではなく失敗としてカウントされます。
  • .github/hooks の下にある読み取りできないリポジトリ フック ファイル、またはその中の無効なフック エントリは、起動時およびリポジトリへの /cd 後に、サイレントにスキップされるのではなく、ファイルとその理由とともに報告されるようになりました。
  • /session delete --yes=false および --yes=<value> の入力ミスによって現在のセッションが削除されなくなり、/session delete --local-only <id> がそのセッションをプレビューするようになりました。

  • 副操縦士スキルの削除と /skills 削除は、削除されたスキルの無効状態を忘れるようになり、同じ名前で後で追加されたスキルは無効状態から開始されなくなりました。

  • ターミナル セットアップは、検出したすべての Windows ターミナル設定ファイルを構成し、既存の Shift+Enter バインディングを正しく検出します。

  • 絵文字や補助記号などの Unicode 文字の /diff 出力をそのまま維持します。
  • モデルが回答テキストを返さない場合、クイック質問は明示的なエラーを報告するようになりました。

  • モデルピッカーは、各モデルの詳細を個別に予算化することで、より多くの選択の余地を残します
  • copyOnSelect が無効な場合にのみフッターのコピー ショートカット ヒントを表示します
  • プラグインの更新が同時に発生した場合でも、/cd の後に MCP のリロード確認を表示します。
  • サーバーが変更されていない場合、起動中に誤った「MCP サーバーがリロードされました」通知を回避する
  • 端末のサイズを変更した後、古いピッカー テキストを残さずにモデル ピッカーをきれいに閉じます。

  • ACP /session のクリーンアップ、プルーン、および削除が、対象となる保存済みセッションに対して機能するようになりました。

  • ヘッドレス プロンプト モードでの MCP サンプリング リクエストは、ホストが応答できない場合にすぐにキャンセルされるようになりました。
  • ローカル/コンパクト中に送信されたプロンプトはキューに残り、圧縮が完了するかキャンセルされた後に送信されます。
  • ACP セッションが永続化され、Copilot ホームから MCP OAuth 許可が更新されるようになり、ブラウザーの再認証が繰り返されることを回避できます。
  • 作業ディレクトリが削除された後に /restart を実行すると、明確なエラーが表示され、CLI が実行されたままになります。
  • macOS コンソール ホストでは、OneAuth サインイン ダイアログがフォアグラウンドで開きます。
  • サンドボックス オンボーディングは、アクセスが許可されていると主張するのではなく、送信ネットワーク ステータスの /sandbox ポリシーを指すようになりました。
  • Trusted 非リポジトリ フォルダーは、プロンプトとプラグインのリロード フローで EnabledPlugins を適用します。
  • CLI は、プロセスのティアダウンが停止した場合でも、終了後に無期限に実行し続けることがなくなりました。
  • 重複するカスタム エージェントのリロード中に断続的に発生する Custom agent not found エラーを修正
  • フッターがビジー状態のときに、武装した Ctrl+X リーダーのヒントを表示します
  • 変更されていない制限ポリシーの更新に対して、管理ポリシーのバイパス権限取り消し警告を 1 回だけ表示します
  • 組み込みのブラウザ フックは、調整後のアクティベーション設定を尊重します。
  • フォークされたセッションでは、再開後もファイルの巻き戻しが可能であり、フォーク後のファイル編集のみが復元されます。
  • マネージド プラグインは、リロード中にポリシーが変更された後、既存のセッションでアクティベーションを復元します。
  • MCP ツールは、出力にわかりやすいサーバー ラベルを保持しますが、ID に依存する動作では設定されたサーバー キーが使用されます。

  • 中断されたプロンプト モードの実行では、プロセスと JSON 出力の両方でゼロ以外の終了ステータスが返されるようになりました。
  • レンダリングされたリンクが正しいローカル ファイル パスを維持できるように、Markdown リンク ターゲットで Windows パス区切り文字を保持します。
  • 従来のフォールバックまでの待機時間を長くすることで、MCP HTTP 検出の信頼性を向上させます。
  • 回答された ask_user の質問には、要約メッセージに選択されたオプションのラベルが表示されます
  • 再開ピッカーで、保存された会話の上に一時的な起動セッションが表示されなくなりました
  • Windows および macOS で OneAuth をデフォルトの Microsoft Entra サインイン パスとして使用する
  • 起動時と再開時にエージェントの選択を維持し、選択したエージェントがフッターに表示されたままになります。
  • Windows ローカル モデルをダウンロードすると、llama.cpp が自動的にインストールされ、エンジンのインストールの進行状況が表示されます。
  • /memory show は、リポジトリ メモリ スコープが利用できないことを示します
  • 組み込みのブラウザ使用プラグインを 0.1.0 に更新し、セットアップとブラウザ統合の動作を改善しました
  • クロード トークンの推定を改善し、コンテキストの予算設定とトリミングの決定がより正確になるようにしました。

  • リモート セッションにより、リモート ワークスペースとこのマシンの間で @ ピックを切り替えることができ、貼り付けた画像が正しくアップロードされます。

  • クラウドの起動では、最初のワークスペース コンテキストの永続化が完了する前に、リポジトリのクローン作成の進行状況が表示されるようになりました。
