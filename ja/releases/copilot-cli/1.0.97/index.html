副操縦士-cli v1.0.97

2026-10-13

  • カスタム エージェント用のエージェント スコープの宣言フックを追加します。
  • リモート プラグイン マーケットプレイスとプラグインの取得は、HTTPS 認証が失敗した後、サインインした GitHub トークンを使用して 1 回再試行します。
  • close_notify が省略された場合、TLS インターセプト プロキシの背後でストリーミングされた応答が完了する
  • 絶対パスを使用した GitHub SCP リモートの解析を修正し、リポジトリの所有者と名前が正しく解決されるようにしました。
  • リポジトリで 100 を超えるエージェント ファイルが定義されている場合や、エージェント ファイルが深くネストされている場合でも、すべてのカスタム エージェントを検出します。
  • オートパイロットは、誰も見ていない許可ダイアログで停止するのではなく、preToolUse フックの「ask」決定を拒否します。
  • 安定したアイコン パスを使用して、CLI アップデート全体で Windows タスクバー エージェント アイコンをグループ化したままにします。
  • config.json 内の 1 つのエントリが無効な場合、起動するたびにリセットするのではなく、無視されたプロンプト、trust フォルダー、サインインなどの保存された設定を保持します。
  • /config では、管理されたアクセス許可ルールは読み取り専用であり、組織によって設定されない限り非表示になります。
  • トークン請求セッションの /usage に請求された AI クレジットを表示します (再開後も含む)
  • 単独の開始行など、正確に 2 つの要素ではない view_range を使用してファイルを読み込むと、タイムラインにその行範囲と行数が表示されるようになり、セッションのエクスポートにはリテラル テキストが含まれなくなりました。
  • トランスクリプト内のテキストをドラッグして選択すると、ポインタの下の行が強調表示されてコピーされることがなくなりました。
  • Power BI および Bluebird MCP サーバーは、サインイン中に公開されたリソース スコープを受け入れます。
  • 有効な変数参照を保持しながら、 --output-format json 出力でシークレットを安全に編集します
  • 一時停止されたセッションを再開すると、中断されたツール呼び出しが報告され、キャンセルされた書き込みの再実行が回避されるようになりました。
  • 同期 /task JSON 出力には、完了前の失敗した子エラーとライフサイクル イベントが含まれるようになりました。
  • 明示的な GitHub MCP ツールおよびツールセットの選択では正しいエンドポイントが使用されるため、要求された書き込みツールは引き続き使用可能です。
  • キャッシュされた MCP ツール呼び出しは、ツール リストの同時更新によってカタログが変更されると、その定義を再チェックします。
  • --plugin-dir プラグインのスキルとカスタム エージェントが、失われるのではなくオートコンプリートと呼び出しに到達するようになりました。
  • 再開されたセッションが間違ったプラグイン リストからプラグイン フックを再構築する問題を修正しました。そのため、リポジトリ ローカル マーケットプレイス プラグインからのフックは --resume 以降も実行され続けるようになり、設定が無効になったプラグインからのフックは戻らなくなりました。
  • ショートターミナルでのアカウントチェック後に /user switch の新しいセッションの選択肢が表示されるようにする
  • 利用できない権限の回復試行がリクエストごとに追跡されるようになったため、無関係な呼び出しが互いの再試行バジェットを消費することがなくなりました。
  • フォアグラウンド作業が実行されていない場合、バックグラウンドシェルの待機ステータスがアニメーション化されなくなりました
  • 長いセッションにおける緊急メモリ救済は、V8 が中止される前のクールダウンをバイパスできるようになりました。そのため、JavaScript ヒープ アウト オブ メモリ クラッシュによって強制終了されたはずのセッションが、代わりに圧縮された履歴で存続する可能性があります。
  • インライン画像は、実験モードを有効にしなくても、サポートされている端末でデフォルトでレンダリングされます。 /settings inlineImages false を使用してオフにします
