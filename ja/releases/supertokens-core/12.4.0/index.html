supertokens-core v12.4.0

スーパートークンコア v12.4.0

何が変わったのか

  • 修正: https://github.com/supertokens/supertokens-core/pull/1431 の @supertokens-agent-runner[bot] により、EE ライセンス同期を FeatureFlag コンストラクターからジッターのある cron に移動しました。
  • 功績: https://github.com/supertokens/supertokens-core/pull/1433 の @supertokens-agent-runner[bot] によるポート スコープのルート分類を備えたオプトイン管理コネクタを追加
  • 功績: https://github.com/supertokens/supertokens-core/pull/1435 の @supertokens-agent-runner[bot] による管理者専用のグローバル ステータスクラスごとのリクエスト統計エンドポイントを追加
  • 修正: https://github.com/supertokens/supertokens-core/pull/1432 で @supertokens-agent-runner[bot] によって CUD をフィルタリングする前に supertokens_saas_load_only_cud を正規化
  • 修正: 読み込み失敗時に以前の FeatureFlag リソースを保持し、https://github.com/supertokens/supertokens-core/pull/1430 の @supertokens-agent-runner[bot] によるエラー ログを復元する
  • 功績: DB-free /livez liveness エンドポイント (ADMIN_ONLY) を @supertokens-agent-runner[bot] により https://github.com/supertokens/supertokens-core/pull/1434 に追加
  • 偉業: https://github.com/supertokens/supertokens-core/pull/1455 の @supertokens-agent-runner[bot] によるデバッグ ログ OAuth 非回転リフレッシュ アトミック ギャップとコミット エラー
  • テスト: https://github.com/supertokens/supertokens-core/pull/1454 の @supertokens-agent-runner[bot] による非回転 OAuth リフレッシュに対する決定的な単一接続所有権回帰
  • 偉業: https://github.com/supertokens/supertokens-core/pull/1442 の @supertokens-agent-runner[bot] による RequestStats で同時実行上限の拒否とインフライト数を公開
  • 修正: https://github.com/supertokens/supertokens-core/pull/1422 の @tamassoltesz による、FeatureFlag リソースの回復力とノンブロッキング ライセンス同期 (PLAN-013)
  • 機能: 分離された管理コネクタ + DB フリー /livez liveness (PLAN-014) by @tamassoltesz (https://github.com/supertokens/supertokens-core/pull/1426)
  • 修正: https://github.com/supertokens/supertokens-core/pull/1437 の @tamassoltesz による、制限されたプラットフォーム スレッド プール + 並列ストレージ初期化 (12.3.1) のタイムアウト
  • 修正: 強化: レガシー SAML ユーザー情報トークン解析 + Tomcat エラー応答 (12.3.1) (https://github.com/supertokens/supertokens-core/pull/1438 の @tamassoltesz による)
  • 功績: https://github.com/supertokens/supertokens-core/pull/1441 の @supertokens-agent-runner[bot] によってプール飽和状態で強制される CUD ごとのインフライト リクエスト同時実行数の上限
  • 修正: 非ローテーション OAuth リフレッシュは、https://github.com/supertokens/supertokens-core/pull/1453 の @supertokens-agent-runner[bot] によるネストされた DB 接続を借用しなくなりました
  • 修正: https://github.com/supertokens/supertokens-core/pull/1457 の @breken-ai によるBulk_migration_sleep_between_rounds_in_batch_ms などのボックス化された設定フィールドに環境変数を適用
  • 修正: コンテナー セキュリティ スキャン — 1.85 (CVE-2026-8763) に bccrov-jdk18 をピン留め + https://github.com/supertokens/supertokens-core/pull/1456 の @tamassoltesz によるイメージ ビルドに基づくプル
  • 修正: https://github.com/supertokens/supertokens-core/pull/1458 の @breken-ai によるオブジェクトまたはアレイのコア構成値に対して 500 ではなく無効な構成を返す
  • 修正: https://github.com/supertokens/supertokens-core/pull/1459 の @amirsalarsafaei による証明書利用者 ID によって WebAuthn サインイン資格情報を検索する
  • 修正: https://github.com/supertokens/supertokens-core/pull/1460 の @tamassoltesz によるトランザクション内で WebAuthN.updateUserEmail のユーザー ID 検索を保持する
  • 修正: https://github.com/supertokens/supertokens-core/pull/1467 の @supertokens-agent-runner[bot] によるトランザクション接続上の WebAuthn サインインの外部ユーザー ID を解決します。
  • 修正: https://github.com/supertokens/supertokens-core/pull/1466 の @supertokens-agent-runner[bot] によるトランザクション接続上のメモリ内 FK 競合を分類
  • 修正: https://github.com/supertokens/supertokens-core/pull/1488 で @tamassoltesz によって作成されたセッションごとに 1 つのアクティビティ ログ イベントを書き込む
  • 特技: ネストされた同一プール接続の取得に対するテストのみのガード (メモリ内 + 回帰テスト) (@tamassoltesz による https://github.com/supertokens/supertokens-core/pull/1461)
  • 修正: https://github.com/supertokens/supertokens-core/pull/1487 の @supertokens-agent-runner[bot] によって残りの REPEATABLE READ トランザクションをデフォルト レベルで実行する
  • 修正: https://github.com/supertokens/supertokens-core/pull/1468 の @supertokens-agent-runner[bot] によるレシピ フロー内のトランザクション接続で AuthRecipe ユーザー ルックアップを実行
  • 修正: https://github.com/supertokens/supertokens-core/pull/1491 の @supertokens-agent-runner[bot] によってデフォルトでメモリ内のネストされた同一プール接続ガードを装備する
  • 修正: https://github.com/supertokens/supertokens-core/pull/1490 の @choksi2212 によるアプリのパブリック テナント ストレージに対するロールの取り消しを解決します。
  • テスト: https://github.com/supertokens/supertokens-core/pull/1492 の @supertokens-agent-runner[bot] によるベースライン テストによる、メモリ内ストレージのリクエストごとのトランザクションおよびコミット カウンター
  • 修正: https://github.com/supertokens/supertokens-core/pull/1493 の @supertokens-agent-runner[bot] によるトランザクションなしでユーザー ID マッピングを読み取る
  • 修正: 非ローテーション OAuth リフレッシュは、https://github.com/supertokens/supertokens-core/pull/1496 の @tamassoltesz による単一の DB 接続 (PLAN-017) を保持します。
  • 雑務: https://github.com/supertokens/supertokens-core/pull/1498 の @tamassoltesz による 12.4.0 リリースの統合/12.3-next を 12.4 にマージする
