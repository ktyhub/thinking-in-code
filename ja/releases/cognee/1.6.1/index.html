コグニー v1.6.1

v1.6.1 — Google 同期と視覚化

発売日: 2026-09-24 変更点: v1.6.0 → v1.6.1

プル リクエスト: #5141、#5158、#5166、#5180

概要

このリリースでは、Google 統合 (ドライブと Gmail) が強化され、大規模なサブグラフの視覚化ストリーミングが改善され、GLiNER のインストールとテレメトリがスムーズになります。また、より優れた来歴スコーピングを追加し、外部メタデータを文書チャンクにスタンプして、取得によりより豊富な結果が返されるようにし、さまざまな同期、取り込み、UI の問題を修正します。

ハイライト

  • 新しい Google ドライブ OAuth コネクタに加え、Gmail と共有ドライブの同期 - Google ワークスペースからのインポートがより簡単かつ安全になりました。
  • /visualize/json 応答をチャンク単位でストリーミングするため、メモリを使い果たさずに大きなグラフ ビューを読み込むことができます。
  • GLiNER インストーラーのオーバーホール: イベント ループからインストールし、最初の使用時に CPU トーチを自動インストールし、インストール テレメトリとエラーをレポートします。
  • チャンクはドキュメントの外部メタデータを保持するようになり、そのメタデータはハイブリッド検索 (意味検索と語彙検索の組み合わせ) で表示されます。

重大な変更

  • dlt はコア依存関係になりました。CSV ローダーは dlt でインポートをゲートしなくなりました。 dlt はコア依存関係に昇格されました。 Cognee をソースからインストールする場合、または依存関係を手動で管理する場合は、dlt が環境で利用できるか、パッケージ マネージャーによってインストールされることを確認してください。

新機能

  • Google ドライブ OAuth コネクタ: Google ドライブ用の完全な OAuth ベースのコネクタを追加し、Google アカウントまたは共有ドライブからファイルを認証および同期できるようにします。重要な理由: ドライブのコンテンツを Cognee に安全に取り込むことが簡単になり、共有ドライブのワークフローがサポートされます。
  • Gmail と共有 Google 同期: Gmail の取り込みと共有ドライブ同期のサポートに加え、Google 同期操作の UI と進行状況インジケーターを追加します。機能: Gmail に接続し、UI で同期の進行状況を監視できます。それが重要な理由: Gmail からのよりシームレスな取り込みとより明確な同期ステータス。
  • SDK にバンドルされた Google コネクタ: Google 関連のコネクタが SDK ディストリビューションに含まれるようになりました。機能: 余分なインストール手順とバージョンの不一致を削減します。それが重要な理由: セットアップが速くなり、統合エラーが少なくなります。
  • /visualize/json をチャンクでストリーミング: 大規模な視覚化応答 (グラフ/サブグラフ JSON) が、1 つの大きなペイロードではなくチャンク化された部分でストリーミングされるようになりました。機能: メモリの大量使用を回避し、大きなグラフの表示を可能にします。それが重要な理由: 大きなメモリ グラフの視覚化は、より信頼性と応答性が高くなります。
  • GLiNER インストーラーの改善: GLiNER 名前付きエンティティ モデル インストーラーは、サーバー イベント ループから実行され、インストールとエラーのテレメトリを記録し、インストールが失敗した場合に必要な追加機能を推奨するようになりました。重要な理由: サーバーのブロックを回避し、より明確なエラー メッセージを表示し、初回セットアップを改善します。
  • GLiNER の初回使用時の CPU トーチ: GLiNER がトーチ (PyTorch) を必要とする場合、CPU ビルドはパッケージのインストール時に強制されるのではなく、初回使用時にインストールされます。機能: 必要になるまで大量のインストールを延期します。それが重要な理由: GLiNER をすぐに必要としないユーザーの初期インストールの手間を軽減します。
  • ドキュメントの external_metadata がチャンクにスタンプされ、ハイブリッド検索で表示される: ドキュメントがチャンクに分割されると、提供した外部メタデータ (元のファイル パスやソース ID など) が各チャンクに保存され、ハイブリッド検索結果 (ハイブリッド = セマンティック + キーワード検索) に含まれるようになりました。重要な理由: 検索結果にはより豊富なコンテキストが含まれ、結果を元のドキュメントにリンクしやすくなります。

改善点

  • 強化された Google ドライブの同期と OAuth バインディング: いくつかの修正により、ドライブの同期プロセスがより堅牢になり、競合状態が軽減され、再接続後も認証情報のメタデータが保持されます。重要な理由: 同期がより安全で信頼性が高く、資格情報の紛失が少なくなります。
  • 取り込みの成功が確認されるまで孤立したクリーンアップを延期する: 取り込み中に発生する可能性のある一時レコードまたは孤立したレコードのクリーンアップは、取り込みが成功したことが確認されるまで延期されるようになりました。重要な理由: 取り込みプロセスが失敗したり再試行されたりしたときに、アイテムが誤って削除されるのを防ぎます。
  • ソースチェックヒットのランク付けとコンテキストの表示: ドキュメントをスキャンして問題を検出すると、結果がランク付けされ、周囲のコンテキストが含まれるようになりました。重要な理由: トリアージと診断をより迅速かつ実行可能にします。
  • 来歴のスコープの洗練: 来歴 (データの一部を作成した人物/内容) のスコープが呼び出し元の読み取り可能なデータセットに正しくスコープされるようになり、データセット レベルの方向データの漏洩が防止されます。重要な理由: より強力なデータ分離とより明確な来歴出力。
  • デコード不可能なファイルに対する HTTP エラーの改善: CSV ローダーは、デコード不可能なファイルに対して 500 サーバー エラーではなく HTTP 415 (サポートされていないメディア タイプ) を返すようになりました。重要な理由: ユーザーと発信者にとってエラー セマンティクスが明確になります。
  • 可観測性: GenAI 埋め込みスパンには標準属性が含まれるようになったため、トレースおよび可観測性ツールは埋め込み操作用の一貫したデータを取得できます。

パフォーマンス

  • 視覚化ストリーミング: チャンク化された /visualize/json により、ピーク メモリ使用量が削減され、サーバー メモリを使い果たすことなく、より大きなグラフ スナップショットをレンダリングできるようになります。
  • GLiNER インストールがイベント ループから移動: GLiNER コンポーネントをインストールしてもメイン イベント ループがブロックされなくなり、初回セットアップ時の応答性が向上しました。
  • Google コネクタを SDK にバンドルすると、client 側のインストールの手間が軽減され、統合の実行が高速化されます。

セキュリティ

  • Google ドライブの同期と OAuth バインディングを強化して競合状態を軽減し、再接続時に認証情報のメタデータを保持することで、同期の失敗や認証情報の損失の可能性を減らします。
  • CodeQL Cookie 構築の潜在的な発見に対処 (ユーザー指定の入力を使用した構築) — 静的分析によってフラグが付けられたリスクを軽減します。
  • アクセスと来歴のスコープが強化され、呼び出し元は読み取り可能なデータセットの出典のみが表示されるようになりました。これにより、偶発的なデータ漏洩が軽減されます。

バグ修正

  • 実行時エラーを引き起こすシャドウイングされたインポートを避けるために、GLiNER Python インポートの正しいディストリビューションを固定します。
  • GLiNER のインストール テレメトリを注文し、エラーを登録して、診断で障害が表示されるようにします。
  • GLiNER 関連のインストールで明確な修正ガイダンスが提供されない場合は、追加のグライナーを推奨します。
  • 境界付きグラフ読み取りでエンティティ タイプの解決を解決するため、視覚化とグラフ クエリは正しいエンティティ ラベルを返します。
  • clients と CI 全体でのデータセットのページネーション、順序付け、重複排除の問題を修正し、データセットのリストとページが一貫して動作するようにします。
  • PR テキストを docs-sync シェル ステップから除外し、チェックされたページからドキュメント パスを正しく計算して、doc-sync の回帰を回避します。
  • Google 同期および統合 CI のさまざまな回帰を修正し、Google 同期のクリーンアップを安全にします。
  • 自己改善モジュールの重複した書き換えを削除し、自己改善を記憶するためのコントロールを公開します。

技術的な変更

  • ストリーミング JSON と境界付き近傍読み取りをサポートするための、新規/書き換えられた視覚化モジュールとグラフ ストリームの実装。
  • サブグラフのサイズを制限し、重いクエリを回避するために、グラフ データベースの SQL に境界付き近傍読み取りが実装されました。
  • 多数の新しいテストと CI ワークフローが追加されました (視覚化、Google 統合、グラフ/近隣コントラクト ヘルパー、ドキュメント トリアージ自動化)。
  • Google Drive および Gmail コネクタ用の新しいタスクの実装とドキュメント、さらにサンプル ガイドと一時的なハイブリッド Cognify デモ。
