コグニー v1.6.2

v1.6.2 — 埋め込みの信頼性と Slack の履歴

発売日: 2026-09-29 変更点: v1.6.1 → v1.6.2

プル リクエスト: #4932、#4951、#5146、#5196、#5231、#5235、#5236、#5240、#5241、#5242、#5247、#5250、#5251、#5274

概要

このリリースでは、埋め込みの信頼性と透明性を高めることに焦点を当てており (サイレント切り詰めがなくなりました)、Slack 会話のインポートと同期が追加され、クロスプラットフォーム ツールを改善するために「スキル」の保存方法が再編成されました。埋め込みが失敗した場合のエラーがより明確になり、モデル トークンの制限に基づいたより安全なチャンク サイズ設定が表示され、これらの動作に合わせて CLI/docs が更新されます。

ハイライト

  • 埋め込み修正により、サイレント切り捨てが防止され、各モデルのトークン制限に従ってチャンクのサイズが変更されるため、コンテンツはそのままの状態で一貫して埋め込まれます。
  • Slack の統合: 会話履歴を Slack から Cognee にインポートし、継続的に同期します。
  • スキルは、Windows リンクのサポートとリンク失敗時の回復を備えた新しい .agents/skills の場所に移動されました。
  • エラーが改善され、回復不能な埋め込みエラーでの失敗が速くなります。不透明なメッセージではなく、本当の原因が表示されます。
  • CLI とドキュメントが更新されました (データベースの移行/コマンドと Docker クイックスタート認証の修正を含む)。

重大な変更

  • スキル パスの変更: 組み込みおよびパッケージ化されたスキルは、.agents/skills の下に配置されました (以前の場所から移動)。古いパスを参照するカスタム スクリプト、自動化、ビルド フック、または CI を維持している場合は、それらを .agents/skills に更新します。リンクを支援するために、小さなヘルパー スクリプト (link-skills.sh) と Windows フックが追加されました。
  • env_file が設定から削除されました: env_file を自動的にロードするランタイム設定が削除されました。設定ファイル経由で環境変数をロードするためにその動作に依存していた場合は、起動スクリプトで明示的な env ローダーに切り替えるか、新しく追加されたshared/env_file ヘルパーを使用してください (例については docs/tests を参照)。

新機能

  • Slack 会話のインポートと同期 — Slack 会話履歴をインポートして Cognee と同期させるための新しい統合。これにより、チャネルとスレッドのメッセージがデータセットに取り込まれ、検索機能とメモリ機能で Slack コンテンツを使用できるようになります。重要な理由: 手動でエクスポートしなくても、過去の Slack データから記憶、検索、概要を構築できます。
  • モデルの入力制限に応じたチャンク サイズ — システムは各埋め込みモデルの入力制限 (モデルが受け入れるトークンの最大数) を測定し、テキストをその制限に合わせたサイズのチャンクに分割します。内容: チャンク化は固定ヒューリスティックに依存しなくなりました。予期しない切り捨てを避けるために、実際のモデル/トークナイザーの制限が尊重されます。重要な理由: 文書が埋め込みモデルに送信されるときに暗黙的に短縮されないため、検索と記憶がより完全で一貫性のあるものになります。
  • スキル ディレクトリの再編成 (.agents) と Windows リンク フック - スキル (自動化されたエージェント スクリプトとサンプル) が古い場所から新しい .agents/skills ディレクトリに移動され、リンク用の Windows フレンドリーなフックが追加されました。機能: 組み込みスキルが存在する場所を標準化し、リンク プロセスが Windows 上で機能するようにします。重要な理由: プラットフォーム間でスキルをインストール、リンク、実行するための、より簡単で一貫性のあるワークフロー。

改善点

  • 堅牢な埋め込み入力制限解決 — SDK は、オプションのトークナイザー ライブラリ (トランスフォーマーなど) がインストールされていない場合でもモデルの入力制限を解決し、必要に応じて非同期的に解決します。これにより、起動時の驚きが減り、軽量インストールの動作が改善されます。
  • トークナイザー間での正確なトークン カウント — トークン カウントには各プロバイダーのトークナイザー (利用可能な場合は HuggingFace トークナイザーを含む) が使用されるようになり、モデル独自の特別なトークンがカウントに含まれます。機能: チャンクのサイズ設定を改善し、少数のトークンによる切り捨てを防ぎます。
  • Fastembed バッチ パディング — 高速埋め込みバックエンドに送信されるバッチは、バッチ レベルでの一貫性のない切り捨てを避けるために、バッチ内の最も長いテキストにパディングされるようになりました。結果: 混合長の入力を送信する際のサイレントトランケーションが減少し、より予測可能な埋め込みが行われます。
  • より明確な埋め込みエラーとフェイルファスト動作 — 埋め込みエラーでは根本的な原因 (単なる一般的なメッセージではなく) が表示されるようになり、ターミナル エラーでは再試行がすぐに停止されます。重要な理由: 外部プロバイダーまたは構成が間違っている場合に、デバッグと回復をより速く行うことができます。
  • 失敗時のスキル リンクの回復とキーなしのリンクの検証 — スキルのリンク プロセスはより堅牢です。部分的な失敗ではリンクの回復が試行され、リンク チェック ワークフローは秘密キーなしで実行できます。これにより、脆弱な操作が軽減され、CI チェックが簡素化されます。
  • CLI のドキュメントと動作の更新 - CLI のドキュメントが拡張され、明確になりました (データベース移行コマンド、新しい例、メモリ コマンドのメモ)。 Docker クイックスタート 401 トラップが改善され、認証がない場合でもクイックスタートが正しく動作するようになりました。

パフォーマンス

  • より信頼性の高い埋め込みスループット — fastembed バッチをパディングし、チャンクのサイズをモデル入力制限に合わせることで、埋め込みは、効果的なスループット/品質を低下させるサイレント トランケーションを回避します。これにより、混合長入力の使用可能な埋め込みの実際のスループットが向上します。
  • 軽量セットアップでの埋め込み制限の迅速な検出 — 入力制限の解決は、重いトークナイザーの依存関係なしで機能し、非同期的に解決されるため、埋め込みの初期化中の遅延が減少します。

セキュリティ

  • Docker クイックスタート 401 の処理 - Docker クイックスタートと関連ドキュメントが修正され、紛らわしい 401 トラップを回避し、より明確な認証ガイダンスが生成されるようになりました。

バグ修正

  • マークされたオプションのトランスフォーマーは、型チェックのために正しくインポートされるため、インストール中にオプションの依存関係が正常に動作します。
  • トークナイザーを使用して HuggingFace トークンを正しくカウントしました (異なるトークナイザー コード パスが使用される場合の誤カウントを回避します)。
  • トランスがインストールされていない場合でもモデルの入力制限を読み取り、間違ったチャンク サイズを引き起こすサイレント フォールバックを防ぎます。
  • 将来のチャンク サイズ決定を損なう可能性がある、以前に保存された切り捨て/パディング メタデータを無視しました。
  • クリア失敗時のスキルリンクの回復（スキルインストールの破損を避けるためのリンク回復）。
  • 予期しない動作を避けるために、実行時設定から env_file 設定を削除しました (重大な変更を参照)。
  • 委任された CLI コマンドの失敗に関する完全なトレースバックがログに記録されるため、エラーの診断が容易になります。
  • エッジケースの削除順序のバグを修正するために、データベースがプルーニングされる順序を変更しました。

技術的な変更

  • エンジン インターフェイスへの input_limit() の埋め込みをリファクタリングし、プロバイダーによる各制限ルックアップを維持して、制限解決をプラガブルにしました。
  • fastembed での no-op re-raise を削除し、欠落している埋め込み SDK をきれいに処理するために再試行述語分類を簡素化しました。
  • トークナイザーの順序付けガードをリファクタリングし (transformers-before-torch ガードを削除)、インポート順序とパディング動作の回帰を防ぐためにガードされたテストを追加しました。
  • 大規模なテストとサンプルの追加: 多くのエンドツーエンド、単体、およびジャーニー テストが追加または拡張されました (埋め込み制限、スラック履歴、チャンキング、ジャーニー) に加えて、新しい company_brain マルチソース デモと拡張された CI ワークフローが追加されました。
  • ドキュメントとスキル: 多数のドキュメントの更新 (AGENTS.md、スキル ドキュメント、移行ガイダンス、README の調整) と Python スキルの例の書式修正。
