コグニー v1.5.2

v1.5.2 — 安定性と検索の改善

発売日: 2026-08-22 変更点: v1.5.2 → メイン

概要

このパッチ リリースは、Cognee の信頼性を高め、日常的なクエリに対する検索の関連性を向上させることに重点を置いています。これには、対象を絞ったバグ修正、明確なエラー メッセージ、取り込みと検索のパフォーマンスの向上、API の動作をより安全にするための内部強化が含まれています。

ハイライト

  • 短くあいまいなクエリに対する検索の関連性が向上し、回答がより便利になりました。
  • 大規模なアップロードと一括インポートのための、より高速で信頼性の高いデータの取り込み。
  • エラー メッセージとログが明確になり、デバッグと統合が容易になります。
  • 複数のバグ修正と内部強化により、同期の失敗とクラッシュが減少しました。

重大な変更

  • v1.5.2 には重大な変更はありません。アップグレードはすべてのユーザーにとって安全である必要がありますが、運用環境にデプロイする前に、ステージングで取り込みと検索のワークフローをテストすることをお勧めします。

新機能

  • v1.5.2 には、主要な新機能モジュールは追加されませんでした。このリリースでは、ユーザー向けの改良に焦点を当てています。検索では短いクエリがより適切に解釈されるようになり (そのため、短いフレーズで検索すると、より関連性の高い結果が得られます)、大規模なインポートをより確実に完了するために取り込みパスが強化されました。

改善点

  • 検索の関連性: 検索ランキング ロジックのチューニングにより、短いクエリまたは曖昧なクエリの結果が改善されます。つまり、より直接的に関連するドキュメントが表示され、ノイズの多い一致が減少します。
  • 取り込みの信頼性: アップロードおよび一括インポートのプロセスは、中断や一時的なエラーに対してより堅牢になり、データセットのインポートが部分的または失敗する可能性が減少します。
  • 開発者エクスペリエンス: API および SDK によって返されるエラー メッセージが明確になり、実用的なヒント (問題の内容と一般的な次の手順) が含まれるようになり、統合の問題をより迅速に診断できるようになりました。
  • ログと可観測性: 内部ログにより、データセットの同期とクエリのライフサイクル イベントに対する明確なマーカーが提供されるため、サポートとデバッグが容易になります。

パフォーマンス

  • 一般的なシナリオにおける検索クエリの待ち時間が短縮され (短い/フレーズ クエリが大幅に改善されました)、インタラクティブな検索でより速く回答が返されます。
  • 以前はタイムアウトや再試行を引き起こす可能性があったスパイクを回避するために、大きなファイルの取り込み中のメモリ処理が改善されました。

セキュリティ

  • 不正なリクエストが矛盾した状態を引き起こす可能性を減らすために、パブリック API エンドポイント周辺の入力検証とエラー処理が強化されました。これにより、サードパーティのデータ ソースを統合する際の全体的な堅牢性が向上します。

バグ修正

  • ネットワークが断続的に中断された後にデータセットの同期が停止する可能性がある状態を修正しました。
  • 同時実行性の高い取り込みジョブ中に発生するまれなクラッシュを解決しました。
  • 一部の一時的なエラーが永続的であるかのように見える、誤解を招く API エラー メッセージを修正しました。
  • 小規模/短いクエリが関連性の低い結果を返す場合がある問題を修正しました。

技術的な変更

  • データセットの同期と取り込みコードの内部リファクタリングにより、再試行動作が簡素化され、保守性が向上します。
  • 依存関係の更新とマイナーな SDK の修正により、ネットワーク障害時の client の動作がより堅牢になります。
  • 検索ランキングとデータセットの同期に関する単体テストと統合テストが改善されました。
