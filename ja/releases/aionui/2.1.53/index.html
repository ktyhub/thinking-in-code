AionUi v2.1.53

パッチ 公開日2026年8月10日 出典iOfficeAI/AionUi 英語原文

#アイオンウイv2.1.53

ハイライト

チャット チャネルとしての Slack

  • Slack は「近日公開」から脱却します。設定 → チャネルでボット トークンとアプリレベル トークンを構成し、接続をテストし、モデルを選択し、どの Slack ユーザーがエージェントとの会話を許可されているかを管理します。

クロードとコーデックスが独自のインストールを実行できるようになりました

  • AionUi は、クロードとコーデックスの独自の固定コピーを出荷していたため、同じプロンプトが AionUi と端末では目に見えないように異なる動作をする可能性がありました。どちらも、Antigravity が常に行うのと同じ方法で、既存のインストールを実行するようになり、バージョンがこのリリースが検証されたものと異なる場合には、AionUi が通知します。

ソース コントロール パネル、ラウンド 2

  • パネルは、ドラッグしてサイズを変更する仕切りとダブル click-to-reset を備えた折りたたみ可能なセクションに再構成され、VS Code サイドバーにぴったりと続きます。
  • [変更] セクションにツリー/リスト ビューの切り替えが追加されました。
  • リポジトリはワークスペース ルートの 1 レベル下で検出されるようになったため、手動セットアップなしで複数リポジトリ プロジェクトが選択されます。

エクスプローラーからパスをコピー

  • プロジェクト エクスプローラーでファイルまたはフォルダーを右クリックし、相対パスまたは (デスクトップ上で) 絶対パスをコピーします。

バグ修正

  • 不正なベンダー チャンク分割が原因で発生する、パッケージ化されたデスクトップ ビルド、WebUI トグル、および Web ビルド上の完全な白い画面を修正しました。
  • 狭いウィンドウで、プロジェクト会話ツリー内のファイルを cli クリックすると、実際にプレビューが開くようになりました。
  • 右 - cli フォルダーを選択して [チャットに追加] を選択すると、成功トーストを表示するだけでなく、チップが生成され、実際にフォルダーがエージェントに送信されるようになりました。
  • AI 応答のコピー ボタンはターン全体をコピーするようになりました。以前は、ツール呼び出しや思考が挟まれた返信では、最後のテキスト セグメントより前のすべてが失われていました。
  • プロジェクト マークダウン プレビュー内の相対パス イメージが壊れて表示されなくなりました。
  • スキル ファイルの閲覧がデスクトップだけでなく WebUI でも機能するようになりました。
  • Antigravity がアシスタント エディターのエージェント ドロップダウンに再び表示され、そのエージェント フィールドには生の ID の代わりに名前が表示されます。
  • 失敗したファイル監視サブスクリプション (オフライン、または再接続直後のソケットのクローズ) は、そのフォルダーを黙って永久に古いままにするのではなく、再試行されるようになりました。

エンジンのアップデート (AionCore v0.1.62 → v0.1.63)

  • バックグラウンド作業 (ワークフロー、バックグラウンド シェル、バックグラウンド サブエージェント) を実行しているエージェントが、飛行中にアイドル状態のスキャナーによって強制終了されなくなりました。
  • エージェントは、大文字と小文字が折り畳まれたプロジェクトの代わりに、実際の大文字と小文字の絶対パスを受け取るようになりました。

注

  • フォーク時代のテーマ設定の 1 回限りの移行は削除されました。現在のテーマ システムより前に作成されたテーマは、自動的には引き継がれなくなりました。

何が変わったのか

  • リファクタリング (テーマ): https://github.com/iOfficeAI/AionUi/pull/3918 の @tcp404 によるレガシー テーマの移行を削除
  • https://github.com/iOfficeAI/AionUi/pull/3927 の @kaizhou-lab による「ci: ビルドのゲートを維持しながらソースのみのドラフト リリースを上流で作成する」を元に戻す
  • https://github.com/iOfficeAI/AionUi/pull/3928 の @kaizhou-lab による「「ci: ビルドのゲートを維持しながらソースのみのドラフト リリースをアップストリームで作成」を元に戻す」を元に戻す
  • 偉業(scm): https://github.com/iOfficeAI/AionUi/pull/3926 の @tcp404 により、折りたたみ可能なセクションとツリー/リスト ビューを SCM パネルに追加
  • feat(explorer): https://github.com/iOfficeAI/AionUi/pull/3929 の @tcp404 による相対/絶対パスのコピー コンテキスト メニュー項目を追加
  • fix(build): https://github.com/iOfficeAI/AionUi/pull/3938 の @tcp404 により、React ベンダーを 1 つのチャンクにマージして白い画面を修正
  • 修正（会話）: https://github.com/iOfficeAI/AionUi/pull/3934 の @tcp404 によるプロジェクト チャットの狭い幅でのプレビューのレンダリング
  • 修正(送信ボックス): チャットに追加されたフォルダー/pe root が https://github.com/iOfficeAI/AionUi/pull/3869 の @tcp404 によってチップを生成できるようにします。
  • 修正 (パッケージ化): バンドルされたクロード/コーデックスの要求を停止し、https://github.com/iOfficeAI/AionUi/pull/3916 の @kaizhou-lab によるドリフト コピーを一般化
  • feat(channel): https://github.com/iOfficeAI/AionUi/pull/3935 の @tcp404 による Slack チャンネル設定 UI を追加
  • 修正 (チャット): コピー ボタンは、https://github.com/iOfficeAI/AionUi/pull/3949 の @kaizhou-lab による最後のテキスト セグメントだけでなく、AI ターン全体をコピーします
  • 修正(スキル): https://github.com/iOfficeAI/AionUi/pull/3946 の @pooya79 による WebUI でのスキル ファイルの参照をサポート
  • 修正 (アシスタント): エディターに反重力を駆動させる (@kaizhou-lab による https://github.com/iOfficeAI/AionUi/pull/3951)
  • 修正(プレビュー): https://github.com/iOfficeAI/AionUi/pull/3948 の @tcp404 による fileRef を介してプロジェクトのマークダウン相対イメージを解決します
  • 修正 (エクスプローラー): 拒否された fs サブスクライブを、https://github.com/iOfficeAI/AionUi/pull/3954 の @tcp404 によって取り残されるのではなく、再サブスクライブします。
  • 雑務: https://github.com/iOfficeAI/AionUi/pull/3955 の @piorpua による 2.1.53 へのバージョンのバンプ
