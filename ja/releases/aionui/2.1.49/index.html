#アイオンウイv2.1.49

ハイライト

話したり聞いたり: オーディオ添付ファイルと音声入力

  • 音声ファイル (mp3、wav、m4a、ogg、flac) をアップロードまたは貼り付けによって添付できるようになり、画像と音声がファイル パスではなくネイティブ コンテンツとして有能なエージェントに届くようになりました。エージェントが添付ファイルをネイティブにサポートしていない場合、チップはそのことを事前に通知します。ファイルはパスとしてそのまま通過します。
  • 会話の実行中も音声入力が利用可能で、コンパクトなモバイル レイアウトで動作し、Cmd/Ctrl+M ショートカットを選択して、アクティブなコンポーザー (チーム列を含む) で録音を開始および停止できます。

エージェントは実際の質問をすることができます

  • エージェントが構造化された質問をすると、単一選択、複数選択、入力可能な「その他」行など、適切なカードとして表示されるようになりました。 1 回の送信で、カード内のすべての質問に一度に回答します。これは、クロードが部分的な返信で未回答の質問を黙って削除するためです。そのため、すべての質問に回答するまでカードは送信を拒否し、カードを却下すると、空の承認ではなく明示的な decline が送信されます。
  • 回答のない質問がある状態で会話を再開すると、単なる許可プロンプトの代わりに同じカードが再構築されます。
  • 許可チャネルを通じて質問をルーティングするエージェントも読み取り可能になりました。リクエストの詳細は、ツール名のみが含まれるカードではなく、フォーマットされた JSON としてレンダリングされます。

コマンドの実行を監視する

  • ACP エージェントが実行するコマンドを AionUi に渡すと、コマンド、そのストリーミング出力、そのステータス、および残りのターンには触れずにその特定のコマンドを強制終了する停止ボタンなど、コマンドがライブで表示されます。

チームモード: メッセージとタスクのアクティビティ

  • リーダーを含むすべてのチーム メンバーは常にメールボックスとタスク ボードを持っていました。どちらもどこにも見えませんでした。両方を表示する読み取り専用のボード ビューがあり、リアルタイムで更新され、ジャンプできる依存関係ラベルが付いています。リーダーはメールボックスを介して直接仕事を割り当てることが多いため、タスクの横にメッセージが表示されます。
  • エージェント アバターの選択と列の入力のフォーカスは同じ動作になりました。以前は、すべての列がマウントにフォーカスを取得するために競い合っていました。そのため、フォーカスされた入力は事実上ランダムであり、強調表示したエージェントが表示されることはほとんどありませんでした。
  • このビューは、複数のメンバーがいるチームに表示されます。

プロジェクトごとのプレビュー パネル

  • プレビュー パネルのスコープが各プロジェクトに設定され、開いているタブが記憶されるため、切り替えたり戻したりすると、開いていたタブが復元されます。保存されていないテキスト編集は残ります。画像、PDF、Office ファイルは保存されるのではなく再取得されるため、大きな画像によってローカル状態が肥大化することはありません。
  • 仕事を失ういくつかの方法が閉鎖されています。サイズを超えるファイルは、黙って切り詰められるのではなく、エディターから除外され、保存にはファイルの変更時間が記録されます。何かが背後でファイルを変更した場合、上書きする代わりに通知されます。
  • ディスク上で変更されたファイルは、そのタブに再ロードのフラグを立て、保存されていない編集内容を再ロードする際に最初に質問します。

他の場所

  • 単一ファイルのファイル変更カードは、ファイル名、+/- カウント、およびプレビュー リンクという 1 つのコンパクトな行に折りたたまれます。
  • スケジュールされたタスクがカード グリッドからコンパクトな行リストに移動され、アシスタントのアバター、スケジュール、次回の実行時間、ステータス、および有効化スイッチが行ごとに表示されます。各行がすでに詳細ページを開いているため、オーバーフロー メニューはなくなりました。
  • モバイル WebUI ファイル処理: ファイルとフォルダーのピッカーは狭い画面に適応し、プロジェクト エクスプローラーの項目は表示されるアクション メニューを取得し (デスクトップは右側を維持します - click)、ホーム コンポーザーはホスト ファイルと、持っているデバイスからのアップロードの両方を提供します。

バグ修正

  • 長時間実行されるコマンドによって会話ビューが破損しなくなりました。 Codex はコマンドの実行中にターンを終了することができ、その後コマンドが出力するものはすべて数分後に新しいターン ID で到着します。 2 つのパスは、その遅い完了を現在のターンに適用するため、完了したターンのエンディングが開始したばかりのターンに着地する可能性がありました。そして、サイドバーは後続のターンごとに「生成中」と表示されなくなりました。あるユーザーのログには、1 日に 4 つの会話にわたって 1,580 のドロップ フレームが記録されていました。
  • エージェント プロセス レジストリが破損してもシャットダウンが中止されなくなりました。ファイルはバックエンドと共有されているため、同時書き込みにより破損する可能性があります。その後、解析の失敗によりクリーンアップが中断され、孤立したエージェント プロセスがリークされ、運用環境ではメッセージ送信が中断されました。読み取りはスローではなく劣化し、書き込みはアトミックになり、同時に登録されたエントリはクリーンアップ パス後も存続します。
  • 起動に時間がかかるバックエンドは、壊れたインストールとして報告されなくなりました。 「再インストール / ウイルス対策チェック」ダイアログは、バックエンドが 30 秒間静かなままになるたびに起動します。これには、完全に無傷のインストールの場合も含まれます。あるユーザーのバックエンドは 47 秒で報告され、その後は正常に実行されました。この場合、正直なところ「起動がタイムアウトしました」というメッセージが表示され、ウィンドウは 60 秒になります。
  • Y2K Ledger スキンでは、Windows ファイル パスにバックスラッシュが再び表示されます。テーマでは最初に日本語フォントがリストされ、メイリオと游ゴシックは従来の JIS 規約に従って U+005C を円記号として描画しました。テキストは決して変更されず、間違って描画されただけです。
  • Thinking ヘッダーと View Steps ヘッダーのスピナーは、その隣のテキストの 3.5 ピクセル下に位置し、静的なアイコンに切り替わるとジャンプしました。ピクセル位置が調整され、コンポーネントごとではなく両方のアイコン システムで中央に固定されるようになりました。

エンジンのアップデート (AionCore v0.1.58 → v0.1.59、Aion CLI ランタイム v0.2.8 → v0.2.9)

  • ネイティブの画像および音声コンテンツ ブロック。各エージェントが受け入れることができると宣言したものによってゲートされます。上記の添付ファイルのバックエンド半分が機能します。
  • チーム アクティビティ ビューの背後にある、読み取り専用のメールボックスとタスク API およびそれらのリアルタイム イベント。
  • Aion CLI: 推論のみを生成したターン、またはストリームに埋め込みエラーが含まれていたターンが空に戻らなくなりました。ストリーム エラーとターミネータの欠落は、サイレントにパスするのではなくターンに失敗するようになり、最初の空の応答の再試行ではツールが引き続き利用可能になり、公式の OpenAI エンドポイントはデフォルトで max_completion_tokens になります。
