AionUi v2.1.61

#アイオンウイv2.1.61

ハイライト

外観: 独自のフォント ファミリとウェイトを選択します

  • [設定] → [外観] で、マシンにインストールされているフォントの検索可能なリストから、アプリ、チャット、マークダウン、コードの 4 つの領域で書体を選択できるようになりました。さらに、各領域に対応するフォントの太さのコントロール (ライト/レギュラー/ミディアム/セミボールド/ボールド、またはシステムのデフォルト) も選択できます。

アーカイブされた会話、完全にアクセス可能

  • アーカイブされた会話リストは、サイレントに切り捨てられるのではなく、各グループの残りのページに表示されるようになりました。「さらに読み込む」ボタンを押すと、古いアーカイブされたチャットが一度に 1 ページずつ表示されます。

送信ボックスの上に固定されたプラン バー

  • エージェントの計画/ToDo スナップショットがメッセージ ストリームから送信ボックスの上に固定された折りたたみ可能なバーに移動し、隣接するメッセージを破棄する際に計画カードが複製される可能性があるバグが修正されました。

プレビューパネル: 最大化切り替えとタブメニューの改善

  • プレビュー パネルには、チャット領域を非表示にし、プレビューを全幅に表示する最大化/復元トグルが追加されました。復元は瞬時に行われます。
  • プレビュー タブを右に cli クリックしても、非表示のオフスクリーン メニューが開かなくなり、メニューには「閉じる」および「未変更を閉じる」アクションが含まれるようになりました (Cmd/Ctrl+W のサポート範囲はパネルに限定されています)。

スラッシュコマンドと図

  • チャット送信ボックスのスラッシュ コマンド メニューは、Tab/Shift+Tab で強調表示されたコマンドを受け入れるようになり、高速入力で選択する代わりに生の /command テキストを送信できる競合が修正されました。
  • Markdown は、WaveDrom/WaveJSON タイミング ダイアグラムをインラインでレンダリングするようになりました。マーメイド ダイアグラムですでに利用可能な同じパン、ズーム、および click からズームへのインタラクションを使用します。

エンジンのアップデート (AionCore v0.1.71 → v0.1.72)

  • クロード セッションのモデル選択は、クロード CLI が適用するのと同じ方法で適用されるようになり、アプリと CLI はどのモデルが実際に実行されているかについて一致します。
  • セッション JWT は Cookie の有効期間と一致するように 30 日間持続するようになり、予期しない再認証が回避されます。
  • プランのスナップショットは会話とともに保持されるようになり、後で復元できるようになり、会話を適切にアーカイブするとエージェント プロセスが破壊されます。
  • エージェント コンテキストに挿入されたスキルの説明は、挿入予算に合わせてトリミングされ、起動時のオーバーヘッドが削減されます。

バグ修正

  • 空白の clickable タイトルを表示する空のメッセージから会話が開始される問題を修正しました。タイトル領域は、空の場合でも常に clickable の名前を変更できるようになりました。
  • 明示的な位置合わせマーカーのないマークダウン テーブルが、左揃えの本文行の上に中央のヘッダーを表示してレンダリングされる問題を修正しました。ヘッダーはテーブルの残りの部分と同様に左揃えになりました。
  • 選択されていないモデルが、エージェントを独自のデフォルトで起動させるのではなく、前のセッションから古い選択を暗黙的に継承するケースを修正しました。

何が変わったのか

  • 特技(設定): https://github.com/iOfficeAI/AionUi/pull/4137 の @tcp404 によるロードモアを使用してアーカイブされたグループをページ化
  • 特技(設定): https://github.com/iOfficeAI/AionUi/pull/4138 に @tcp404 によるフォント ファミリの選択を追加
  • feat(plan): 送信ボックスの上にプランを固定し、https://github.com/iOfficeAI/AionUi/pull/4133 の @kaizhou-lab による重複カードのマージを修正
  • 特技(設定): https://github.com/iOfficeAI/AionUi/pull/4152 に @tcp404 によるフォントの太さの選択を追加
  • feat(プレビュー): https://github.com/iOfficeAI/AionUi/pull/4153 の @tcp404 によるプレビュー パネルの最大化トグルを追加
  • 特技（チャット）：Tab でスラッシュコマンドを受け入れ、https://github.com/iOfficeAI/AionUi/pull/4154 の @tcp404 による Enter 送信レースを修正
  • feat(renderer): https://github.com/iOfficeAI/AionUi/pull/4135 の @heartacker によるマークダウンでの WaveDrom タイミング図のレンダリング
  • 修正(guid): https://github.com/iOfficeAI/AionUi/pull/4162 の @piorpua による「選択されたモデルがありません」をサイレント選択に変えるのをやめる
  • 機能 (プレビュー): オフスクリーン タブのコンテキスト メニューを修正し、https://github.com/iOfficeAI/AionUi/pull/4164 の @kaizhou-lab によるタブ アクションを追加しました。
  • 修正 (会話): 空の会話タイトル click を、https://github.com/iOfficeAI/AionUi/pull/4169 で @piorpua によって名前変更できるようにしました。
  • 修正(マークダウン): https://github.com/iOfficeAI/AionUi/pull/4167 の @kaizhou-lab によりテーブルのヘッダーと本文の行を揃える
  • 雑用: https://github.com/iOfficeAI/AionUi/pull/4173 の @piorpua による 2.1.61 へのバージョンのバンプ
