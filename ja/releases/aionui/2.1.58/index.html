AionUi v2.1.58

#アイオンウイv2.1.58

ハイライト

国際化と右から左へ (RTL) のサポート

  • ペルシア語 (fa-IR) は、完全な右から左のレイアウト (アプリ全体でミラー化されたアイコン、パネル、読み取り方向) でレンダリングされるようになりました。
  • 数値、日付、時刻は、OS ロケールではなく、AionUi 内で選択した言語に従ってフォーマットされるようになりました。通貨記号の不一致や予期しない日付の順序はもう発生しません。
  • フランス語、ドイツ語、スペイン語、ポルトガル語など、数十の不足している翻訳を埋めました。ドロップダウンとダイアログのコンポーネント文字列が、サポートされている 13 言語のうち 5 言語ではなく 11 言語で正しくレンダリングされるようになりました。
  • カウントされるテキスト (例: 「1 ファイルが変更されました」) は、ロシア語とウクライナ語の 3 方向複数規則を含む、各言語の正しい複数形を使用するようになりました。
  • スケジュールされたタスクのタイトルとファイル サイズでは、ハードコードされた形式ではなく、ロケールを認識した日付と数値の形式が使用されるようになりました。

カスタムテーマ

  • テーマでは、ライト モードとダーク モードの検証済みのカラー トークンのセットを定義できるようになり、新しいカスタム テーマ ガイドで独自のテーマを作成する手順が説明されています。 「設定」→「外観」でバンドルされている Neo-Brutalism のサンプルを試してください。

マークダウン プレビュー: 数式

  • ファイル プレビュー ビューアの複数行の LaTeX/KaTeX 数学ブロックが数式の途中で分割されなくなりました。数学は 1 つの部分としてきれいにレンダリングされるようになりました。

チームモードの改善

  • モデルピッカーの隣にモデル更新ボタンを追加したため、他の場所で行われたモデルの切り替えはセッションに即座に反映されます。
  • チャット履歴を保持しながら構成変更を取得するためにエージェントのプロセスを再構築するランタイム再起動コントロールを追加しました。
  • チーム リーダーは、/clear を使用してメンバーのコンテキストをクリアし、一度に 1 メッセージずつ中断されるのではなく、キューに入れられたメンバーのメッセージをすべて一緒に読み取ることができるようになりました。
  • チームメンバーは、通常のセッションと一致する独自のバインドされた MCP ツールを取得できるようになりました。
  • メンバーが選択したモデルが保持されるようになり、リードはメンバーの現在のターンに割り込んで、すぐに新しい指示を送信できるようになりました。
  • チームメンバーが時々「処理中」状態でスタックする問題を修正しました。

エンジンのアップデート (AionCore v0.1.69)

  • クロードのツール呼び出しステップには、実際に行う内容ごとにラベルが付けられるようになり、ツールの実行中の会話を簡単に理解できるようになりました。

バグ修正

  • AionUi の内部 PREBUILDS_ONLY 設定がエージェントのサブプロセスに漏洩し、起動時に「ネイティブ ビルドが見つかりませんでした」エラーでサードパーティの CLI (カーソル エージェントなど) をクラッシュさせる可能性がある問題を修正しました。
  • ダーク モードでの一貫性のない送信/ドラフト アクション ボタンの色を修正し、送信ボタンの周囲にある背景のアーティファクトを削除しました。
  • 以前の RTL 修正後に左から右へ記述する言語でシステム設定のディレクトリ パスがずれていた問題を修正しました。

何が変わったのか

  • fix(i18n): https://github.com/iOfficeAI/AionUi/pull/4068 の @kaizhou-lab により、ホスト ロケールではなく、アプリの言語に基づいて数値と日付をフォーマットします
  • 修正 (i18n): 欠落している Arco ロケール、トレイフランス語、古いタイトル、ハードコードされた句読点と単位を @kaizhou-lab により https://github.com/iOfficeAI/AionUi/pull/4071 で登録
  • feat(i18n): ペルシア語 (fa-IR) の右から左へのレイアウト (@kaizhou-lab による https://github.com/iOfficeAI/AionUi/pull/4069)
  • 修正 (i18n): 欠落している翻訳をすべて埋め戻し、https://github.com/iOfficeAI/AionUi/pull/4072 の @kaizhou-lab によって webFsPicker キーを接続します
  • fix(i18n): https://github.com/iOfficeAI/AionUi/pull/4074 の @kaizhou-lab によるカウントを含む文字列に i18next 複数形を採用
  • fix(i18n): ロケールを意識した cron タイトルとバイト サイズ、https://github.com/iOfficeAI/AionUi/pull/4075 の @kaizhou-lab による繁体字中国語マッピング
  • fix(i18n): RTL ポリッシュ パス — LTR パスとファイル名、短縮パディング、ミラーリングされたシェブロン by @kaizhou-lab (https://github.com/iOfficeAI/AionUi/pull/4077)
  • 偉業(チーム): ランタイム再起動コントロール、モデル更新ボタン、チーム UX 修正 (https://github.com/iOfficeAI/AionUi/pull/3893 の @baibai-git による)
  • 修正 (web-host): https://github.com/iOfficeAI/AionUi/pull/4078 の @kaizhou-lab による aioncore エージェントのサブプロセスへの PREBUILDS_ONLY のリークを停止
  • 雑務(ドキュメント): WeChat グループの QR コードを wx-21 に更新 (https://github.com/iOfficeAI/AionUi/pull/4080 の @IceyLiu)
  • 特技(テーマ): 構造化トークン チャネルをアクティブ化し、https://github.com/iOfficeAI/AionUi/pull/4081 の @tcp404 によるカスタム テーマ ガイドを追加します。
  • fix(i18n): https://github.com/iOfficeAI/AionUi/pull/4086 の @kaizhou-lab によってハードコードされた末尾ではなく、ディレクトリ パスをページ方向に揃えます。
  • feat(renderer): https://github.com/iOfficeAI/AionUi/pull/4079 の @heartacker によるマークダウン ビューアの数式レンダリング サポートを追加
  • 修正 (チャット): https://github.com/iOfficeAI/AionUi/pull/4082 の @IceyLiu による作成アクションとドラフト キューの排出を調整しました。
  • 雑務: https://github.com/iOfficeAI/AionUi/pull/4089 の @piorpua によるバージョンを 2.1.58 にバンプします
