AionUi v2.1.55

#アイオンウイv2.1.55

ハイライト

Aion CLI の会話をフォークする

  • フォーク (以前のメッセージから会話を分岐させ、両方の系統を維持する) が、クロードとコーデックスだけでなく、Aion CLI の会話でも機能するようになりました。フォーク ボタンはメッセージに表示され、結果の会話には系統バッジが表示されます。チームの会話は分岐不可能なままです。

バグ修正

  • 「アップデートの確認」は、リリース チャネルがロールバックされたときに、あたかもアップデートであるかのように古いバージョンを提供する可能性があります (例: 2.1.54 → 2.1.53)。現在は、厳密に新しいバージョンのみを提供しています。

エンジンのアップデート (AionCore v0.1.65 → v0.1.66、Aion CLI ランタイム v0.2.10 → v0.2.11)

  • Aion CLI は、ターン アンカー境界によるセッション フォークを獲得します。これは、上記の機能のバックエンドの半分です。
  • クロードの会話のタイトルは、生成が停止すると再試行されるため、無題のまま残る会話が少なくなります。

何が変わったのか

  • 修正(更新): https://github.com/iOfficeAI/AionUi/pull/4010 の @tcp404 による更新チェックでダウングレード オファーを拒否する
  • feat(会話): https://github.com/iOfficeAI/AionUi/pull/4022 の @jiahe0510 による aionrs チャットのサーフェス フォーク エントリ ポイント
  • 雑務: https://github.com/iOfficeAI/AionUi/pull/4034 の @kaizhou-lab による 2.1.55 へのバージョンのバンプ

フル Changelog: https://github.com/iOfficeAI/AionUi/compare/v2.1.54...v2.1.55
