canal 1.1.6

パッチ 公開日2022年5月24日 出典alibaba/canal 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#運河運河-1.1.6

新しい機能

  1. PolarDB-X 2.0 binlog のサブスクリプションと使用をサポートします。 ※PolarDB-Xは、アリババが独自に開発したクラウドネイティブな分散データベースです。最近リリースされたグローバル Binlog は、mysql binlog プロトコル [参考資料] (https://help.aliyun.com/document_detail/207719.html) と完全な互換性があります。
    • canal は、PolarDB-X binlog ドッキングをネイティブにサポートでき、tcp/MQ/adapter #3494 などの複数のモードを完全にサポートします。
  2. Puslar MQ サポートを追加 #3791 #4060
  3. TableStore #3754 をサポートするアダプターを追加
  4. 隠し列、型タイプなど、新しいバージョンの MySQL8.0 (8.0.29) と互換性があります。 #3976

重要な最適化

  1. fastjson をバージョン 2.0.2 に切り替え、druid をバージョン 1.2.10 にアップグレードします。
  2. テーブルメタ内の関連する DDL ステートメント解析の問題を修正 #3839 #3840 #3954 #3900
  3. 履歴バージョンを保存するときにテーブルメタがフィルター条件に正しく一致しない問題を修正しました #3693
  4. Kafka コネクタの環境変数読み取りを修正 #3829
  5. 一部のシナリオで ES アダプターの起動に失敗する問題を修正 #3466 #3144 #3684
  6. jvm gc を G1 アルゴリズム #4014 にアップグレードします。
  7. RDB同期時のキーワードによる同期エラーを修正 #2783 #3984
  8. アダプタ #3923 の単一マシンおよび複数のインスタンスでの同時スレッドの問題を修正します。

小さな要件とバグ修正

  1. CanalServer.get() #4027 の null ポインターの問題を修正します。
  2. 管理モードでのインスタンス起動の同時実行の問題を修正 #4018
  3. 管理者モードでの 6 桁の強力なパスワード検証を修正 #3877
  4. mysql 8.0 でテーブル メタを取得する際の null ポインター例外を修正 #3538
  5. mysql 時間タイプ #4178 の負の時間問題を修正
  6. canal-server の docker 画像エクスポーター監視設定 #3576 を修正
  7. Windows 上の canal-server と互換性のあるローカル モードの起動を修正 #3484
  8. アダプター モード #3880 と互換性を持たせるために、guava バージョン 18.0 をロールバックします。
  9. es 同期でのインデックス名の取得の例外を修正 #4122
  10. ES 同期における 2 つの結合テーブルの問題を修正 #4161
  11. rocketmq のログ印刷設定を最適化する #3329
