logging-log4j2 3.0.0-beta3

メジャー 公開日2024年11月12日 出典apache/logging-log4j2 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#logging-log4j2 rel/3.0.0-beta3

このリリースでは、オプションの log4j-core 依存関係を使用するすべてのコードを新しいモジュールに移動することにより、Log4j コアのモジュール化プロセスを終了します。

  • 最近の Windows OS は ANSI エスケープ シーケンスをサポートしているため、JAnsi ライブラリのサポートは削除されました。 詳細については、「Windows での ANSI スタイル設定」(https://logging.apache.org/log4j/3.x/manual/pattern-layout.html#ansi-windows) を参照してください。
  • DisruptorBlockinQueue キュー ファクトリ は、新しい log4j-conversant アーティファクト に移動されました。
  • 高度な圧縮アルゴリズム のサポートは、新しい log4j-compress アーティファクト に移動されました。 Gzip および Zip 形式は、そのままの状態で引き続きサポートされます。

個別のライフサイクル

  • Flume Appender リリースは独自のライフサイクルに従います。
  • Log4j API との間のすべての ロギング ブリッジ は、Log4j Core 3.x リリースから削除されました。 互換性のあるバージョンのロギング ブリッジを常に使用するには、log4j-bom で依存関係を管理してください。

追加

  • RFC5424 レイアウトに useFqdn 構成属性を追加します。 (#1740)
  • log4j-jdbc の JNDI サポートを新しい log4j-jdbc-jndi モジュールに分割 (#1914)
  • Web サイトに 「プラグイン リファレンス」 を追加します。これは、Log4j プラグインに焦点を当てた Javadoc-on-steroids です。 (#1954)
  • 拡張圧縮アルゴリズムのサポートを新しい log4j-compress モジュールに分割しました。 (#2921)

変更されました

  • Windows コンソールが ANSI エスケープをサポートするようになったので、JAnsi ライブラリのサポートを削除します。 (#1736)
  • DisruptorBlockingQueue プラグインを新しい log4j-conversant モジュールに移動します。 (#2914)
  • JAnsi ライブラリなしで動作するように JAnsiTextRenderer を書き換えます。 (#2916)

修正済み

  • MongoDB テストを Docker を使用するように切り替えます。 (#2229)
  • ルックアップとフィルターでのカスタム スレッド コンテキスト データ プロバイダーの処理を修正しました。 (#2331)
  • HTTP(S) ソースからの設定のリロードを修正 (#2937)
  • Log4j Core の Android 関連の問題を修正。 (#3056)
  • ウェブサイトは Antora に移行され、いくつかのフォーマットとリンクが修正されました (#2443)

削除されました

  • UNIX と UNIX_MILLIS を除く、パターン レイアウトの named 日付と時刻の書式設定パターンを削除します (#3150)
  • Flume Appender を独自のリリース ライフサイクルに移動します。 (#2902)
  • ThrowableProxy とその使用法を削除 (#3047)
  • ロギング ブリッジをディストリビューションから削除し、log4j-bom で 2.x の同等のものを参照します。
  • ロガー ラッパーを生成し、構成ファイルを変換するための CLI ツールを削除します。 これらのツールは、Log4j Transform の次のリリースで利用可能になります。
  • 非推奨の org.apache.logging.log4j.core.appender.rolling.action.Duration クラスを削除します。
  • log4j-1.2-api モジュール (#2621) を削除します。
  • log4j-iostreams モジュール (#2630) を取り外します。

更新されました

  • apache/logging-parent をバージョン「 (#2598)」に更新します。
  • com.fasterxml.jackson:jackson-bom をバージョン 2.18.1 (#3136) に更新します。
  • io.fabric8:docker-maven-plugin をバージョン 0.45.1 (#3036) に更新します。
  • org.apache.commons:commons-compress をバージョン 1.27.1 (#2870) に更新します。
  • org.apache.commons:commons-csv をバージョン 1.12.0 (#3020) に更新します
  • org.apache.commons:commons-dbcp2 をバージョン 2.12.0 (#2342) に更新します
  • org.apache.logging.log4j:log4j-api をバージョン 2.24.1 (#3035) に更新します。
  • org.jctools:jctools-core をバージョン 4.0.5 (#2638) に更新します
  • org.jspecify:jspecify をバージョン 1.0.0 (#2750) に更新します。
  • org.mongodb:bson をバージョン 5.2.1 (#3179) に更新します。
  • org.springframework.boot:spring-boot-autoconfigure をバージョン 3.3.5 (#3120) に更新します。
  • org.springframework.cloud:spring-cloud-context をバージョン 4.1.4 (#2733) に更新します。
  • org.springframework:spring-framework-bom をバージョン 6.1.14 (#3102) に更新します。
