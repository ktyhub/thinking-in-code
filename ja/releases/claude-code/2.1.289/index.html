claude-code v2.1.289

パッチ 公開日2026年10月3日 出典anthropics/claude-code 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

クロードコード v2.1.289

何が変わったのか

  • 複合シェルコマンドのネストされた部分の拒否または確認ルールが、管理対象マシン上でユーザーがインストールした MOD の承認を保持しない問題を修正しました。
  • 多くの閉じられていない <script> タグまたは深くネストされた ${ 置換を含むショート コード ブロックで端末がフリーズする問題を修正しました。
  • シンボリックリンクを介してIDEで@言及、変更、または選択されたファイルにRead拒否ルールが適用されない問題を修正
  • [VSCode] サインアウトの頻度を高めた可能性がある 2.1.288 の変更を claude auth status に戻しました。
  • ハイライトされたビューを最終的な幅で 1 回レイアウトすることで、プラグイン コード ペインで大きなファイルを開く速度が向上しました。
  • ローカル フォルダー マーケットプレイスからインストールされたプラグインの古いコピーを表示する plugin list、plugin eval、plugin update と、シンボリックリンクされた --plugin-dir のホット リロードを修正しました。
  • アップグレード後の最初のセッションでインストール済みの MOD が読み込まれない問題を修正
  • バックグラウンド タスク ダイアログが全画面で開いているときに、プロンプトの上にあるプラグインの行に古い行が表示される問題を修正しました。
  • リンクでローカルホスト アドレス、パス内の @、大文字のホスト、または file: パスが使用されている場合、プラグイン ペインに何も描画されない問題を修正しました。
  • ユーザーがインストールしたプラグインが、組織が管理する MCP サーバーのサインイン ツールの記述を書き換えることができる問題を修正しました。
  • プラグインが端末が認識しない境界線スタイルでボックスを描画したときの起動時のフリーズまたは強制終了を修正しました
  • プラグインの画面上のハンドラーが非同期にスローしたときに終了する監視対象セッションとバックグラウンド セッションを修正しました
  • 高さのないプラグイン領域が成長し続けると、インターフェイス エラーで終了するセッションを修正しました
  • サンドボックスがコマンドを自動許可する場合、Bash の拒否および確認ルールで、拡張された値 (例: TZ="$HOME" rm -rf build) を持つ環境変数プレフィックスの背後にあるコマンドが欠落する問題を修正しました。
  • コマンドの前に裸の変数の割り当てが行われた場合、サンドボックスの自動許可の下でスキップされる Bash の拒否または確認ルールを修正しました
  • フォルダーにマーケットプレイスのマニフェストも保持されている場合にプラグインをスキップする claude plugin validate を修正しました
  • チームメイト用の agent.spawn、プラグイン フック イベント全体の 1 つのエージェント ID、および $.agent.list() のアイドル状態と待機状態を追加しました。
  • Mod の ui.render フックが書き込んだ値が描画中に行をスローした場合に「回復不能なインターフェイス エラー」で終了するセッションを修正しました。エンジンは代わりに独自の行を描画するようになりました
  • タブ、迷走エスケープ、C1 コントロールを含むテキスト、またはタブと CRLF 行末を含む短いテキストで、その下の行を上書きする問題を修正しました。
  • MOD のペインまたは終了マークまたは [-] の下のバンド描画内の右揃えのコンテンツを修正しました。これにより、端末の端から 1 列が内側に保持されるようになりました。
  • MOD の Client が、MOD が周囲に描画したすべてのものを削除する描画中に失敗する問題を修正しました。現在は単独で失敗し、ui.fault が発生します。
  • claude plugin validate が Anthropic マーケットプレイス独自のプラグインに失敗し、クリーンな plugin.json が --json にリストされる問題を修正
  • MOD のバンドが一時的に描画に失敗し、その下のカードに脇に置くように指示する問題を修正しました
  • エラーによってメッセージが伝えられなかった場合に、エラーの原因として Error または何も表示されないプラグイン コンポーネントを修正しました
  • バンドまたはペインの描画に失敗したときに MOD の作成者に表示される行を改善しました。MOD に名前を付け、何も描画されていないことが表示されます。
  • 多くの閉じられていない <script> タグを含む短いコード ブロックで、公開されたアーティファクト ページがリーダーのブラウザ タブをフリーズまたはクラッシュさせる問題を修正しました。
  • MOD の Client 領域が、描画中に端末がスローされた後、セッション全体にわたって失敗したままになる問題を修正しました
