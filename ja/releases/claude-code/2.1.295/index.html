claude-code v2.1.295

パッチ 公開日2026年10月8日 出典anthropics/claude-code 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

クロードコード v2.1.295

何が変わったのか

  • コマンドおよび HTTP フック用に onFailure: "block" を追加しました。フックが開始できない、タイムアウトする、または予期しないコードで終了する場合、アクションを通過させるのではなくブロックします。
  • プログラム ステータス プロトコル (OSC 7501) のサポートを追加: これを実装した端末は、クロード コードが動作しているか、待機しているか、完了したかを表示できます。
  • /copy ピッカーに引用テキストを追加したため、下書きメッセージは > マーカーなしでコピーされます。
  • claude plugin install、enable、disable、marketplace add に書き込む設定ファイルが読み込まれない場合の警告を追加しました。
  • 端末の場合、claude -p 実行が最後のターン後に開いたままになっているときに何を待っているかを示す行を標準エラー出力に追加しました。
  • クロード アプリ ゲートウェイの Bedrock、Vertex、Foundry、およびその他のクラウド アップストリームでの timeouts.upstream_ttfb_ms のサポートを追加しました。設定した値により、そこでストリームが開始されるまでの時間が制限され、その後フェールオーバーするか 502 が取得されます。
  • ← が現在のツールの終了を待っている間にターンを停止すると、「バックグラウンドがキャンセルされました」というメッセージが追加されました。
  • オプションの models リストをすべてのクロード アプリ ゲートウェイ アップストリームに追加しました。リストされたモデルのみがフェールオーバー時にもそこに送信され、エントリ内の 1 つの * はワイルドカードです。
  • 管理対象設定のないマシン上の独自のユーザー設定に forceLoginMethod: "gateway" および forceLoginGatewayUrl のサポートが追加されたため、/login はクロード アプリ ゲートウェイで開きます
  • プラグインの README にインストール行がない場合の claude plugin validate へのアドバイスを追加しました。--strict であっても、貼り付ける行が出力され、終了コードは変更されません。
  • クロード アプリ ゲートウェイの inference 監査イベントに upstream_request_id を追加しました: サポート ケース用の Amazon Bedrock、Anthropic API、または別のアップストリームからのリクエスト ID
  • MOD 用に $.ui.notify を追加: 独自の通知設定を通じてネイティブ通知を生成し、どのチャンネルがそれを送信したかを示します
  • MOD の Button に子を追加しました: 文字列と Text なので、リストの行は内部のチップまたは薄暗いディテールで押せるようになります
  • 無人再試行モード (CLAUDE_CODE_RETRY_WATCHDOG) が 429 および 529 エラーを待機する時間を制限するための CLAUDE_CODE_RETRY_WATCHDOG_MAX_WAIT_MS を追加しました。
  • クロード アプリ ゲートウェイの成功した推論応答に request-id ヘッダーを追加したため、クロード コード テレメトリの request_id はゲートウェイの監査ログと一致します。
  • ゲートウェイ、Bedrock、Vertex、または Foundry が context-1m ベータを拒否した場合に、[1m] モデルですべてのリクエストが失敗する問題を修正しました。クロードコードはそれなしで再送信されるようになりました
  • バックグラウンド作業が別のターンを開始したときに、claude -p テキスト出力が以前の応答をドロップする問題を修正しました。各ターンの応答がターン終了時に印刷されるようになりました
  • ヘッドレス セッションおよび SDK セッションのリモート MCP サーバーが、15 秒を超える停止後に切断されたままになるか、接続直後に各接続が切断されるサーバーへのタイト ループで再接続する問題を修正しました。繰り返しのドロップが最大 30 秒で元に戻るようになりました
  • サーバーのエラー応答にネットワーク エラー名が含まれていた場合にリモート MCP 接続がドロップされる問題を修正しました。
  • 接続するたびに同じページを要求されるページネーション カーソルを最大 20 回繰り返す MCP サーバーを修正しました
  • MCP ツールによって返される CSS、JavaScript、および XML ファイルが .bin として保存され、読み取りツールが拒否する問題を修正しました。フォントとアイコンのファイルにも独自の拡張子が付けられるようになりました
  • モデルが description ではなく command_description を渡すと失敗する Bash ツール呼び出しを修正しました
  • Chrome のクロードが、ポート 80 (host:80) で記述されたサイト拒否ルールをそのホスト上のプレーン http:// ページに適用しない問題を修正しました。
  • /plugin の [エラー] タブで、最初に確認せずに Enter キーを押すと、ロードに失敗したマーケットプレイスが削除され、そのプラグインがアンインストールされる問題を修正しました。
  • プラグインをインストールできない名前のマーケットプレイスで成功を報告する claude plugin marketplace add を修正しました。そのような追加は現在拒否されています
  • 編集またはシェルコマンドがサブエージェントの背後で待機している間にサブエージェントをバックグラウンドに移動し、サブエージェントが終了する前にその呼び出しを開始する CLAUDE_AUTO_BACKGROUND_TASKS を修正しました。
  • 電話メッセージの直後、/config トグルなし、またはクロード コード内から開始された場合に、claude remote-control セッションでプッシュが送信されなかったという PushNotification を修正しました。
  • リモート セッションから送信されたファイルが一度に 256 個を超えると「保証できない」として拒否される問題を修正
  • ログイン更新直後の起動時に管理対象設定を読み込むことができないまれな失敗を修正しました
  • クロードコードを再度開始できなかった場合に、メッセージを表示せずに終了するか、生のシステムエラーで終了する /tui を修正しました
  • テーブルまたは質問プレビューで折り返される場所を含め、返信が残された色または非表示スタイルによって隠されているテキストとして表示されるリンク アドレスを修正しました
  • availableModels にリストされている Fable モデルが、Claude アプリ ゲートウェイにサインインしたセッションの /model ピッカーに表示されない問題を修正しました。このようなモデルでは、同じモデルに追加された modelPicker 行の代わりに、その組み込み行が表示されるようになりました。
  • セッションがグループの保持を停止した後、開発者の古いグループとグループの上限が表示されるクロード アプリ ゲートウェイの管理支出ビューを修正しました
  • /usage とステータス行でクロード アプリ ゲートウェイの使用制限を隠す CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC を修正しました。使用制限リクエストは、セッションがサインインしているゲートウェイに送信されます。
  • リンクされた独自のワークツリー内のサブエージェントに親セッションの git ブランチ、ステータス、最近のコミットが表示される問題を修正
  • プロンプトに入力したテキストが ← でバックグラウンドをキャンセルすると、クロードが現在のツールの最後で停止する問題を修正しました。クロードは今もフォアグラウンドで働き続けています
  • --tools および --restricted が起動後に登録される組み込みツールに適用されず、非推奨のツール名が呼び出し元のツール セット外のツールに及ぶ問題を修正しました。
  • クロードがMCPサーバーのリソースリストを待っている間、タイムアウトになるまでターンを終了しない割り込みを修正しました
  • MOD のフックに深くネストされたツール入力が渡され、エラーなしで短縮される問題を修正しました。そのため、ガードは見たことのないコンテンツを渡すことができます。
  • ← でバックグラウンドに移動されたマイペース /loop が Esc で停止しない問題を修正しました。保留中のウェイクアップをキャンセルすると通知が表示されるようになりました
  • クロードが読み取る出力にカラー エスケープ コードを挿入する、FORCE_COLOR=3 を継承するバックグラウンド セッションのコマンドとフックを修正しました。
  • claude agents が、セッションを開いたまま (再起動時など) 両方が停止したときに終了すると、新しいバックグラウンド サービスを開始する問題を修正しました。これにより、シャットダウンが遅れ、中断されたセッションが再開される可能性がありました。
  • 自動モード拒否通知およびタスク詳細ビューのアクティビティ リストに「エージェント」として表示される worker という名前のカスタム エージェントを修正しました
  • glob パターンに対する for ループの Bash 権限チェックを修正し、権限チェックの精度を向上させました。
  • ワークフロー サブエージェントから呼び出されたフォークされたスキルが、呼び出し元のエージェントではなくメインの会話に結果を提供する問題を修正しました。
  • ツール検索を通じてツールをロードするまで、インプロセス エージェントのチームメイトが最初の SendMessage 呼び出しに失敗する問題を修正しました
  • 再開時にクロードに、未完了のバックグラウンド ワークフローが TaskStop によって停止された可能性があると言われる問題を修正しましたが、それが原因であることはあり得ません
  • タスクパネルまたは接続されているclientから長時間実行されているMCPツール呼び出しを停止するときにクロードに通知されない問題を修正
  • セッションのプロセスがダウンしているときに次のウェイクアップが期限になったときに、バックグラウンド セッションの /loop が予告なく停止する問題を修正しました。セッションは今そう言い、クロードはそう言います
  • 返信またはチームメイトのメッセージ内の生のターミナル ハイパーリンク バイトが、隠しアドレスを持つ clickable リンクとして描画される問題を修正しました。
  • リポジトリに大きな git サブモジュールがあるプラグイン マーケットプレイスの追加または更新に失敗する問題を修正しました。プラグイン ファイルを保持するサブモジュールのみがフェッチされるようになりました。
  • 利用できなくなった保存済みアドバイザ モデルにチェックマークが表示される /advisor ダイアログを修正しました。 「アドバイザーなし」で開くようになりました
  • バックグラウンドに移動して短縮されたタスク ID が表示される MCP ツール呼び出しの通知を修正しました
  • vim モードの ~ がカーソルを行の最後の文字を超えて移動するため、x が何も行われず、3~ が次の行に続く問題を修正しました。
  • macOS からコピーしたアクセント付きテキスト (ファイル名など) をプロンプトの中央に貼り付けた後、カーソルが 1 文字離れすぎてしまう問題を修正しました。
  • 応答が数万行に及ぶ場合、ctrl+c が無視されて端末がフリーズする問題を修正しました。
  • .catch を持つ別の MOD のガード フックを通過するプラグイン フック ワーカーの再起動中に、MOD がリロード中に行う呼び出しを修正しました。そのような電話は現在拒否されています
  • フックモジュールが数千レベルの深さでコードをネストしているプラグインが、ベアスタックオーバーフローメッセージでロードまたは検証に失敗する問題を修正しました
  • 実際のセッションが保持するツール呼び出し、ツール結果、または思考ブロックを削除する session.append フックを渡す claude plugin test を修正しました。
  • セッションが強制終了され、2 回目に再開された後、SendMessage でバックグラウンド サブエージェントを再開できることがクロードに通知されない問題を修正
  • cat などの Bash コマンドが印刷されずに実行された後、ファイルが既読として扱われる問題を修正しました
  • constructor または prototype という名前のプラグイン オプションが常にデフォルトとして読み取られ、編集時にプラグインがリロードされない問題を修正しました。
  • /reload-plugins またはセッション開始が MOD のファイルを読み取っている間に作成された保存が欠落する MOD のホット リロードを修正しました
  • 回答を選択せずに承認された場合、セッション全体にわたって毎ターン再質問されるMODのホットリロードの質問を修正しました
  • プラグインの config.set フックを要求せずに設定を保存する /model、/fast、/output-style を修正しました
  • 太字テキストが薄暗いテキストの直後にある場合、パイプ出力で薄く描画される問題を修正しました
  • 引用符が数行ごとに深くネストされ、端末が数秒間フリーズし、ギガバイトのメモリを使用する返信を修正しました
  • MOD のホットリロードで最後のリロードから数ミリ秒以内に行われた保存が欠落し、次の保存まで MOD が古いバージョンのままになる問題を修正しました。

  • 再開するたびに、非同期 SessionStart フックの変更されていないコンテキストが再び会話に追加される問題を修正しました
  • SessionStart フックが CLAUDE_ENV_FILE に書き込む変数が、アプリ内 /resume または /branch の後に Bash ツールに到達しない問題を修正しました。
  • 応答ストリームが終了する前にスキルツールが終了すると、スキルの allowed-tools および effort がドロップされ、-p の実行でスキルの Bash コマンドが拒否される問題を修正しました。
  • サーバー管理設定の改ざんされたキャッシュにより、管理設定がプラグインをリストまたは有効にするマシン上で個人のプラグインが組織管理としてカウントされる問題を修正しました
  • Claude 3 Opus および Claude 3.x Sonnet セッションでツール検索が提供されるが、これらのモデルでは機能フラグが利用できないため拒否される問題を修正

  • タブまたは双方向制御文字を含むテキストが画面の端で終端を失ったり、近くの行に重なって表示されたりする問題を修正しました。

  • Mod の prompt.submit フックがプロンプト履歴とトランスクリプトのキューに入れられたプロンプト レコードに入力されたまま保存されているまま書き換えまたはドロップされたプロンプトを修正しました

  • mcp__server__tool 識別子の代わりにサーバーと読み取り可能な名前で MCP ツールに名前を付ける許可プロンプトを待機しているセッションのリモート コントロール、claude.ai、およびデスクトップ アプリに表示されるステータスを改善しました。
  • クロード アプリ ゲートウェイの背後でバックグラウンド リクエストを改善し、セッション モデルの代わりに Haiku 4.5 を使用し、ゲートウェイが Haiku 4.5 を提供しないセッション モデルにフォールバックします。
  • クロード アプリ ゲートウェイが、AWS の米国地域外の Amazon Bedrock リージョンで models: にリストされていないモデルを処理する方法を改善しました。 AWS は常にこれらのリクエストを拒否しました。ゲートウェイは独自のリージョンでモデルを試行し、拒否された場合は追加するモデルに名前を付けます。
  • ヘッドレス rate_limit_event の使用制限警告を改善し、アカウントで追加使用量が有効になっているかどうかを通知するようにしました。
  • 組み込みの plugin-authoring スキルを改善しました。ターミナルのないセッションにターミナル コマンドを実行するように指示しなくなり、要求された場合にのみ MOD を共有することを説明します。
  • Grep 入力処理の改善: grep の -l、-c、または -r フラグを使用して送信された検索が、呼び出しに失敗する代わりに実行されるようになりました。
  • claude plugin validate とプラグインの読み込みの改善: フック モジュールがリバウンドのトップレベル var で拒否された場合、エラーにはそれを再バインドする行、原因、および修正が示されるようになりました。
  • ワークフロー ツールの scriptPath 拒否を改善しました。読み取りツールなしのセッションで機能するルートである script 経由でスクリプトをインラインで渡すよう指示されるようになりました。
  • 送信された大きなファイルが理由も示されずにアップロードに失敗したときにクロードに通知される内容を改善しました。そのため、ファイルを縮小する代わりに失敗を報告します。
  • ツール検索を通じてモデルがロードする MCP ツールの説明が 2,048 文字ではなく 16,384 文字で切り取られるように変更されました。
  • skills フィールドから最大 32 のスキルをそれぞれ 1 回ずつプリロードするようにサブエージェントを変更しました。 Skill ツールを備えたサブエージェントは残りの部分を呼び出すことができます
  • 接続されたバックグラウンド セッションのアイドル プロンプトで Ctrl+C を変更し、保留中の /loop ウェイクアップをそのままにしておくようにしました。そのため、2 回押すと接続が解除され、ループが実行され続けます。 Escを押して停止します
  • バックグラウンド サービス (macOS、またはサービスがインストールされていない Linux) で停止する claude agents を変更しました。実行中のセッションは、再実行しない限り約 1 分で停止するようになり、その旨の通知が表示されます。
  • フラグを取得しないインストールでデフォルトで MCP プロトコル バージョン 2026-07-28 をネゴシエートするように claude.ai コネクタを変更しました。 MCP_PROTOCOL_NEGOTIATION=legacy はオプトアウトします
  • 独自の背景のないアーティファクトページをオフホワイトではなく白で表示するように変更しました
  • ツールの実行後に MOD がツール呼び出しを拒否したときにクロードとあなたが読む内容を変更しました。ツールが実行され、プラグインがその結果を保留したと表示されるようになりました。
  • 画面の左端からではなく、テキストの開始位置からカウントするようにタブストップを変更しました。2 でインデントされた回答は、最初のストップが 8 セルにあります (6 セルでした)。
  • テレメトリが無効になっているアーティファクト ツールの権限プロンプトを、他の人のアーティファクトを読み取ったりデータを編集したりする前に尋ねるのではなく、他のインストールと同じ 5 つの質問に変更しました。
  • 変更されたスケジュール設定と今すぐ実行ルーチンは、他のインストールと同様に、新しいプライベート アーティファクトを公開し、質問することなく独自のアーティファクトを更新するためにテレメトリが無効になっているインストールで実行されます。
  • 組織の MOD からのトーストが、他の MOD のトーストの後ろで待つのではなく、先に表示されるように変更されました。
  • 警告から開始し、バンドルされている Claude デスクトップ スキーマが認識しない desktop ポリシー キーを提供するように Claude アプリ ゲートウェイを変更しました。そのため、新しいデスクトップ設定ではゲートウェイをアップグレードする必要はありません
  • 変更された WebSocket (ws) MCP サーバー: 16 MiB を超えるメッセージは解析されなくなり、他のトランスポートがすでに持っている制限である接続が閉じられます。
  • [VSCode] クロードが送信するファイルのチャット行を追加しました: cliファイル名を確認してエディタで開きます。クロードのキャプションが下に表示され、その行はフォーカス ビューで表示されたままになります。
  • [VSCode] バックグラウンド エージェントのアクティビティまたはパネル独自のステータス行の 1 つ後に、「ここから会話をフォーク」および「セッション内にメッセージが見つかりません」というメッセージが表示されて巻き戻しの会話の復元が失敗する問題を修正しました。
  • [VSCode] チャット入力で Ctrl+Shift+Tab、Cmd+Shift+Tab、Alt+Shift+Tab を使用すると許可モードが切り替わり、Ctrl+Tab が提案されたプロンプトを受け入れる問題を修正しました。
  • [VSCode] 同時に表示される 2 つのクロード ビュー間でキーボード フォーカスがバウンスする問題を修正しました。これにより、入力されたテキストが間違った会話に送信される可能性がありました。
  • 自己ホスト型ランナー: CCR_AUTO_MODE_ALLOW、CCR_AUTO_MODE_ENVIRONMENT、CCR_AUTO_MODE_SOFT_DENY をセッションの環境に渡すのを停止するようにランナーを変更しました。
  • 自己ホスト型ランナー: git サーバーが大規模なリポジトリの進行状況を報告している間に、git のフェッチが中断される問題を修正しました。 CLAUDE_RUNNER_FETCH_SERVER_PROGRESS_CAP_MS はチューニングまたは待機をオフにします
  • [クラウド セッション] クラウド セッションのアーカイブを解除した直後に送信されたメッセージが、コンテナーを開始できないために応答が得られない場合がある問題を修正しました。
  • [クラウドセッション] 保存されたプロンプトをクロードに与えずに実行を開始するいくつかの古いルーチンを修正しました。これらのルーチンはプロンプトを再度実行するようになりました
  • [クラウド セッション] 接続が切断された後、クラウド セッションに追いつくまでの速度が向上しました。見逃したアクティビティが行ごとではなく一度に表示されるようになりました。
  • [クラウド セッション] クラウド環境フォームのセットアップ スクリプト ボックスを改善しました。高さから開始し、スクリプトに合わせて成長し、ドラッグしてサイズを変更できます。
  • [Claude Tag] クロードが Slack チャンネルに投稿する設定確認カードが、10 分間ではなく 30 分間開かれるように変更されました。
  • [Claude Tag] Enterprise Grid ワークスペース間で共有されているチャネルでは、誰かがクロードに言及した場合にのみ投稿するように組織のデフォルトを使用し、最大月に 1 回投稿するというクロードの通知を変更しました。
  • [Claude Tag] 生の Slack コードとして表示される、フォークされたスレッドの「続きから」カード内のチャンネル リンクと @ メンションを修正しました
  • [Claude Tag] @Claude !restart が再起動を確認した後、スレッドの下で Slack の作業ステータスが回転する問題を修正
  • [Claude Tag] クロードがタグなしメッセージの読み取りを停止していた混雑したチャネルで、別のアプリまたはボットの @Claude が無応答になる問題を修正しました。
  • [クロード タグ] チャネル マネージャーを追加する前に、そのメンバーをカスタム ロールに移動する前に、クロード タグの管理設定に確認を追加しました。これにより、他のアクセス権が削除される可能性があります。

  • [コード レビュー] プル リクエストでファイルを編集するときに、コード レビューで大きな CLAUDE.md のルールが依然としてスキップされる問題を修正しました。
