claude-code v2.1.293

パッチ 公開日2026年10月7日 出典anthropics/claude-code 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

クロードコード v2.1.293

何が変わったのか

  • クロード俳句 5.5 (claude-haiku-5-5) を追加しました。現在、Anthropic API のデフォルトの Haiku モデルです — 1M コンテキスト、Mtok あたり $0.10/$0.50 (100K を超えるプロンプトの場合は $0.50/$2.50)
  • agentType を subagentStatusLine ペイロードに追加したため、スクリプトでカスタム サブエージェント タイプを区別できるようになりました
  • MOD 用に isDeferred を $.tool.register に追加しました: false は、ツール検索の後ろではなく、最初からプロンプトにツールのスキーマをリストします。
  • クロードがコンテキスト圧縮前の自身の最後のアクションをコンテキスト圧縮後に行われたものとして扱い、完了した作業を撤回またはやり直すことがある問題を修正しました。
  • HTTP MCP 接続が閉じるまで送信したすべてのリクエストを保持するメモリ リークを修正しました
  • クロードの作業中に送信されたメッセージが、← がセッションをバックグラウンドに移動したときに失われる問題を修正しました。キューに入れられたメッセージが移動できない場合、← はそのまま留まり、その旨を通知するようになりました。
  • 最高レベルまたは最低レベルを超えてラップする /model 努力値 ←/→ を修正しました。これにより、モデルのデフォルトの努力値として誤って Low が保存される可能性がありました。
  • --chrome で開始されたセッションで、/tui が Chrome でクロードを切断し、--no-chrome を無視する問題を修正しました。
  • ホスト、権限ルール、または --tools リストによってそのツールが削除されたセッション (再開されたセッションを含む) で、クロードが続行するか、SendMessage を使用してサブエージェントにメッセージを送信するように指示される問題を修正
  • サブエージェントと --agent セッションで、独自のツール リストのみが組み込みツールを除外した場合、セッション全体で組み込みツールが無効になったと通知される問題を修正しました。
  • claude.ai 同期スキルの編集された説明が、新しい会話または /clear までモデルに到達しないことがある問題を修正しました
  • claude logs、stop、kill、rm、claude daemon status、stop、uninstall が、ログインの有効期限が切れたか、ログイン期限が切れようとしていたときにサインアウトすることがある問題を修正しました。
  • セッションフォルダーの読み取りに一時的に失敗した後（開いているファイルが多すぎるなど）、フッターのエージェント数が消える問題を修正しました。
  • worker という名前のカスタム エージェントが開始時に「エージェント」として表示され、エージェントが終了するとエージェントの詳細ダイアログのタイトルでエージェント タイプが失われる問題を修正しました。
  • パブリッシュ呼び出しがストリーミング中に、アーティファクト ツールのトランスクリプト行が短時間 Artifact("(unprintable path)") と読み取られる問題を修正しました。
  • Linux 上の /ultrareview アップロードが、サンドボックス コマンドの実行中に「解析できなかった」設定ファイルを理由に、別のチェックアウト内のリポジトリなどの一部のリポジトリを誤って拒否する問題を修正しました。
  • git がインデックスを読み取れなくなる可能性がある git コマンドを通知する、分割インデックス ファイルに対する /ultrareview アップロードの拒否を修正しました。
  • 非常に長いリモート コントロールおよびクラウド セッションで、ストリーミングではなく一度にブロックが表示される可能性がある返信を修正しました。
  • 資格情報を回復するたびにリモート コントロールがセッションの開始履歴を再度アップロードする問題を修正
  • claude remote-control で開始されたセッションで「リモート コントロールが無効です」と報告される PushNotification を修正しました
  • プラグイン フック ワーカーの再起動中に classic.* イベントに対する MOD のフックがスキップされ、設定フックがフックなしで応答するままになっていた問題を修正しました。
  • $.session.append を呼び出す MOD で claude plugin test が失敗する問題を修正しました。テストは新しい mock.session を使用して追加された行を読み取ることができます
  • Docker デスクトップを搭載した Mac 上ですべての Bash 付与の実行を拒否する claude plugin eval を修正しました (~/.docker/bin の下のリンク)。拒否により、資格情報ストアのどの部分がリンクを保持したかが示されるようになりました。
  • desktop ポリシーが Claude Desktop の組み込みブラウザ キー (builtinBrowserEnabled など) を設定している場合に、Claude アプリ ゲートウェイの起動が拒否される問題を修正しました。
  • 同意が .claude/settings.local.json または --settings ファイルにのみ保存されている場合に、バックグラウンド セッションが無視するバイパス権限を提供する claude agents を修正しました。最初に同意を求めるようになり、バイパスを無視するセッションでは、そのままの短い通知が表示されます。
  • プロンプトに未送信のテキストが表示されている間 (移動がキャンセルされるようになりました)、または質問が回答を待っている間に 10 秒後にセッションがバックグラウンドになる ← を修正しました
  • セッションをバックグラウンドに移動するために ← を押したばかりのときに、許可プロンプトで Esc またはフィードバックなしの No を押してもターンが停止しない問題を修正しました。
  • セッションフォルダーを読み取れなかった場合（たとえば、開いているファイルが多すぎる場合）、セッションリストをプレースホルダー行に一時的に置き換えるエージェントビューを修正しました。
  • クロードが読み取りツールではなく Bash ツールで単一ファイルの cat、head、tail、sed -n または grep コマンドを使用してファイルを表示すると、パス スコープのルールとネストされた CLAUDE.md ファイルが読み込まれない問題を修正しました。
  • 同じ単語で始まり同じ単語で終わる貼り付けられたテキストが、入力されたかのようにクロードに送信されることがある問題を修正しました
  • ペーストが最後の文字にマージされた直後にアクセントが入力または貼り付けられた場合、ペーストされたテキスト内のスキル名が入力されたものとして扱われる問題を修正しました
  • レポートの送信中に Ctrl+O または Ctrl+Z を押すと /feedback が下書きリストに戻り、送信をキャンセルできなくなる問題を修正しました。
  • ファイルまたはフォルダーを削除できない場合に、claude purge がサイレントに停止する (0 で終了する、またはターミナルでハングする) 問題を修正しました。残りを削除し、削除できなかったものをリストして、1 を終了します。
  • キーバインドを修正しました。json チェック: 単独の " " (スペース キー) はエラーとして報告されなくなり、「ctrl+ k」のようなキーは警告を受けるようになりました。
  • スペースのみの行でカーソルが行末を超えて残る vim モードの >> と << を修正しました。後続の x は何も削除しませんでした。
  • vim モードの修正: ビジュアル モードで行全体を削除した後 (V、続いて d)、カーソルは最初の非空白に位置し、カーソルの行に作用した後は . になります。
  • Windows: ステータス ライン、フック、またはシェル コマンドを停止すると、同じプロセス ID が与えられた無関係なプロセスが終了することがある問題を修正しました。
  • 拒否は正確なコマンドだけでなく結果もカバーすることをクロードに伝えた 2.1.281 からの自動モード拒否メッセージの変更を元に戻しました
  • コンテナーの再起動により保留中の /loop ウェイクアップまたはスケジュールされたタスクが失われた後、クラウド セッションがスリープ状態のままになる 2.1.290 の修正を元に戻しました。クロードについては何も言われず、セッションはスリープ状態のままになります。
  • チーム組織およびエンタープライズ組織向けの起動の改善: ポリシーと管理設定がより早くフェッチされ、停止したリクエストは 3 秒後に再試行されます。
  • Chrome のクロードの改善: ブラウザーのタブのレポートが遅い場合に拒否されるページ アクションが減少しました。
  • ブラウザーにアクセスできない場合のクラウド セッションでの Chrome のクロード メッセージを改善しました。複数の組織に属している場合、拡張機能は同じ組織にサインインする必要があることと、その変更方法が表示されるようになりました。
  • コマンドの実行中にリストされたファイルが変更されたことを示す Bash 編集の差分ノートを改善しました。これには、他のプロセスによる書き込みが含まれる可能性があります。
  • アーティファクトの改善: クロードはライブラリを 2 週間以上前の正確なバージョンに固定します
  • セッションが使用されていない間、10 分ごとではなく約 40 分ごとに変更をチェックするように claude.ai スキルの同期を変更しました。
  • モデルに通知されたエージェント リストと MCP サーバーの順序を変更しました。非 ASCII 文字を含む名前は、ASCII 名の後にソートされるようになりました。
  • プロンプトが読み取られるたびに最大 100 個のエージェント イベントと 100 個の MCP リソース イベントを発行するように OpenTelemetry claude_code.at_mention ログを変更しました。
  • 自己ホスト型ランナー: ポーリング間のポーリング間隔が定数 5 秒ではなく 4 ～ 6 秒スリープするようにオーケストレーターを変更したため、1 つの環境の複数のレプリカが同時にポーリングを停止します。
  • [Claude Tag] Slack がメッセージに接続されていないワークスペースのラベルを付けると、Slack のクロードがワークスペース間で共有される Enterprise Grid チャネルにワークスペースが設定されていないと表示する問題を修正しました。
  • [Claude Tag] 管理者がチャンネルのコネクタ、プラグイン、スキル、またはルールを変更したときに、Slack のクロードがチャンネルのタスクの途中で停止する問題を修正しました。クロードが終了すると変更が適用されるようになりました
  • [Claude Tag] Slack の Claude に、ポストバックできない別の実行を開始する追加のメモを付けてスレッドのルーチンを実行するよう求める問題を修正しました。実行はそのスレッドで継続されます
  • [Claude Tag] Claude Tag 管理設定のアクセス バンドルの [コネクタの追加] ダイアログで、1 回の Google サインイン後にすべての Google コネクタが接続済みとして表示される問題を修正しました。
  • [Claude Tag] まだ接続されていない Enterprise Grid を [接続] ボタンで一覧表示するように、Claude Tag の管理設定を改善しました。
  • [Claude Tag] SlackのClaudeがイントロを投稿せずに、管理者のみが投稿できるアナウンスチャンネルに参加するように変更しました。
  • [Claude Tag] Claude Tagの管理設定におけるチャネルルールの制限を、各ワークスペースおよび組織全体のSlackページで20から50に変更しました。
  • [コード レビュー] コード レビューの [リポジトリの追加] ダイアログを改善し、追加できなかった各リポジトリとその理由 (GitHub 書き込みアクセスの欠落など) をリストするようにしました。
