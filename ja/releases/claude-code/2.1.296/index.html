claude-code v2.1.296

パッチ 公開日2026年10月9日 出典anthropics/claude-code 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

クロードコード v2.1.296

何が変わったのか

  • クロード アプリ ゲートウェイの managed.policies[] に code キーを追加しました。cli と同じ設定で、クロード デスクトップの [コード] タブにも適用されます。 desktop の横にあると、Claude Desktop のゲートウェイ モードがオンになります
  • autoCompactWindow をサブエージェントのフロントマター定義と --agents 定義に追加したため、サブエージェントはメインの会話ウィンドウよりも早く自動圧縮できるようになりました。
  • 他のサブエージェントがそのモデルを維持しながら、1 つのモデル上ですべてのワークフロー エージェントを実行するための CLAUDE_CODE_WORKFLOW_SUBAGENT_MODEL を追加しました。
  • オーバーロードされた (529) リクエストを再試行する際のバックオフの最大遅延をより長く設定するための CLAUDE_CODE_OVERLOADED_RETRY_MAX_DELAY_MS 環境変数を追加しました。
  • 別の有効なプラグインが同じ名前を持っているため、フックが省略されているプラグインに関するメモを /plugin に追加しました。
  • 読み取りツールに allow_large オプションを追加しました。これにより、ファイル全体が必要でコンテキストに余裕がある場合に、クロードが 1 回の呼び出しで通常のサイズ制限を超えたテキスト ファイルを読み取ることができます。
  • "continue": false によるツール呼び出しを拒否するマネージド設定の PreToolUse フックと、ツール呼び出しをブロックして呼び出しを拒否するがターンを終了しないマネージド prompt フックを修正しました
  • 一部のセッションで updatedMCPToolOutput が適用されない管理設定の PostToolUse フックを修正しました
  • ディレクトリを変更したりプラグインをリロードした後、そのフォルダーに対してオフになっていたフォルダーの .mcp.json またはプラグイン MCP サーバーが開始されるヘッドレス セッションを修正しました。
  • allowedProviders と "gateway" を提供するクロード アプリ ゲートウェイがユーザー設定でそのゲートウェイを指定するラップトップをロックアウトする問題を修正しました
  • 管理設定が forceLoginGatewayUrl なしで forceLoginMethod から gateway に設定されているマシンで、保存されたクロード アプリ ゲートウェイのサインインが無視される問題を修正しました (2.1.295 の回帰)
  • セッション履歴を読み取れない場合に空の会話を開く --teleport を修正しました
  • Haiku 5.5 および適応的思考のみを採用するその他のモデルのトークン数を修正しました。一部のゲートウェイの背後で失敗し、他の場所では予算思考でカウントされていました。
  • セッションのシャットダウンにより中断されたツール呼び出しをユーザーが拒否したと、再開されたサブエージェントに通知される問題を修正
  • プラグインのヒントタグに似たテキストが含まれている場合に変更されるフック出力を修正しました
  • シェル文字列内に記述された JSON など、値のないキーに続く一部の値が欠落している共有トランスクリプトとデバッグ ログのシークレット編集を修正しました。
  • MATE ターミナルなどの古い VTE ベースのターミナルでコピーした後に画面に印刷される迷走 52;c;… エスケープ シーケンスを修正しました
  • /diff パネルまたはダイアログが開いている間、トーストと通知が表示されずに待機する問題を修正しました
  • UserPromptSubmit フックまたは MOD の prompt.submit フック中に Esc または割り込みが発生すると、ヘッドレス セッションが終了したり、入力されたプロンプトがクリアされたり、チェックされていないプロンプトが通過したりする問題を修正しました。
  • 同じ名前または別のスペルを持つ別のプラグインがすでに実行されている場合、ヘッドレス セッションの開始後にロードされたプラグインの SessionStart フックがスキップされる問題を修正しました。
  • 登録が拒否されたときに誤解を招くエラーを出力する claude self-hosted-runner を修正しました。組織の管理者設定に名前を付けるか、再起動されたオンデマンド ランナーには新しい作業指示が必要であると表示されるようになりました。
  • --capacity が 1 を超えるランナーで同じリポジトリの別のセッションが開始されているときに、自己ホスト型ランナー セッションの git フェッチ、プル、プッシュが失敗する問題を修正しました。
  • 約 20,000 レベルより深くネストされた結果、エージェント オプション、その他の値をサイレントに切り捨てるワークフロー スクリプトと、巨大なタスク出力ファイルを書き込む深くネストされた結果を修正しました。
  • プラグインが提供する $ メソッドが、呼び出しエージェントの代わりにメイン セッションの作業ディレクトリで実行され、呼び出しフックが保持する順番を無視する問題を修正しました。
  • MOD がリロードまたは削除された後も実行されていた MOD のフックから継承される $.agent.register を修正しました。現在通話は拒否されています
  • 応答で 4 MiB の本文制限を超える Content-Length が宣言されている場合、MOD 内の $.http.fetch が HEAD リクエストを拒否する問題を修正しました。
  • constructor のような名前のマーケットプレイスで、claude plugin marketplace add、marketplace update、plugin install が内部エラーで失敗する問題を修正しました。 add はそのような名前を明確に拒否するようになりました。
  • constructor または prototype という名前のプラグイン シークレットが、プラグインのオプションの次回の保存によって削除される問題を修正しました。
  • 機能フラグが読み込まれていないときに、保存された権限で許可されている Chrome アクションのクロードに対する自動モードのチェックをスキップするクラウド セッションを修正しました
  • MCP ツールの結果がそのターンを終了した場合に、再起動後に終了したターンを再実行する CLAUDE_CODE_RESUME_INTERRUPTED_TURN を修正しました
  • BASH_ARGV0 シェル変数を割り当てて使用する一部のコマンドを自動承認する Bash 権限チェックを修正しました。これらは承認を求めるようになりました
  • 有効な UTF-8 (Windows-1252、Shift-JIS、GBK) ではないファイル内のすべての非 ASCII 文字を置き換える Edit および NotebookEdit を修正しました。そのような編集は現在拒否されています
  • ← が 2 回実行された直後、バックグラウンド サービスの応答が遅いときに、1 回目はフォアグラウンドで表示されずに送信されるプロンプトを修正しました。
  • SessionStart フックの実行中に送信されたプロンプトが、← がセッションをバックグラウンドに移動すると消える問題を修正しました。まだ送信されていませんが、↑ が送信を戻します
  • 遅延読み込みプラグインの SessionStart フック出力が、ヘッドレス セッションで /clear の後に新しい会話に到達する問題を修正しました。
  • フックが CLAUDE_ENV_FILE に書き込む変数が PowerShell コマンドで認識されない問題を修正しました (ファイルが単純な割り当てのみを保持している場合)
  • クロードがクラウド セッションを非対話型と呼び、MCP サーバーが認証を必要とする場合に /mcp または claude mcp を提案する問題を修正しました。
  • クラウド セッション、エージェント SDK、および IDE 統合で生の JSON 配列で終わる /code-review を修正しました。結果が番号付きリストとして印刷されるようになりました
  • 自動モードが時折、自分のアーティファクトへの 1 つの更新を拒否し、共有が変更されていないのに変更されたと主張する問題を修正しました。
  • 複数のセッションが構成ディレクトリを共有している場合、claude.ai から同期されたスキルがインストールを完了せず、同期のたびに再度ダウンロードされる問題を修正しました
  • claude.ai から同期されたプラグインが宣言するマーケットプレイスの依存関係も claude.ai から同期された場合に無効になる問題を修正しました
  • Linux マシンからコピーされたプラグイン パスが /home の下を指している場合に、macOS で起動がハングする問題を修正しました。
  • Windows でチェックアウトされたファイルなど、CRLF 行末を持つスクリプト ファイルをワークフロー ツールが拒否する問題を修正しました。
  • git commit -q または git -C <dir> commit の後に git_commit_id が欠落している OpenTelemetry tool_result イベントを修正しました
  • テキストに Unicode 行または段落区切り文字 (U+2028、U+2029) が含まれている場合に、保存されたトランスクリプトからメッセージを削除する CLAUDE_CODE_TRANSCRIPT_LOCAL_GC を修正しました。
  • claude purge のテキストに Unicode 行または段落区切り文字 (U+2028、U+2029) が含まれている場合に、履歴ファイルにプロンプトが残る問題を修正しました。
  • Windows: 約 1 KB を超える PowerShell コマンドが常に許可を要求する問題を修正したため、許可ルールと読み取り専用検出が最大 32 KB まで適用されるようになりました。
  • Windows: シャットダウン時に標準出力 MCP サーバーが強制終了される問題を修正しました。サーバーが 300 ミリ秒後にまだ実行されている場合にのみ、stdin が最初に閉じられ、プロセス ツリーが強制終了されるようになりました。
  • Windows: GitHub SSH キーのないマシンで GitHub owner/repo プラグイン ソースに対して失敗する claude plugin install を修正しました。クローンは HTTPS 経由で再試行されるようになりました
  • Windows: Git Bash の rm -rf /c/Users/<name> がバイパス権限モードで要求しない問題を修正しました。
  • フルスクリーン モードの改善: マウス ポインタの下のリンクに下線が付けられ、開くことができることが示されます。
  • 構文が強調表示されたコード ブロックをキャッシュすることで、コードの多い会話におけるトランスクリプトの切り替え (ctrl+o) の応答性が向上しました。
  • Claude アプリ ゲートウェイの背後にある Claude デスクトップの [コード] タブの改善: ゲートウェイの code 設定がセットアップされていないマシンなどでセッションを開始できない場合、その理由が応答として表示されます。
  • 拒否されたクラウド セッションのエラーを改善しました。組織のポリシーを読み込めなかった理由が表示され、claude.ai ログインをオーバーライドする API キーまたは認証トークンに名前が付けられるようになりました。
  • カスタム エージェント ファイル内の認識されないフロントマター フィールドに名前を付けるための --debug 出力が改善され、タイプミスの可能性がある場合のヒントが示されました。
  • 自動モードの改善: 自動モードのチェックで使用可能な回答がなかったために実行されなかったツール呼び出しは、赤色のエラーではなく薄暗い「実行されていません」行として表示されるようになりました。
  • フックの --debug 出力の改善: ツール呼び出し、プロンプト、SessionStart および Stop のコマンド フックは、コマンド、プラグイン、結果、終了時の継続時間をログに記録するようになり、遅いフックを識別できるようになりました。
  • CLAUDE_CODE_TRANSCRIPT_LOCAL_GC の改善: 空き容量が 10% 未満の大きなトランスクリプト ファイルが書き換えられなくなりました。
  • /cost、ステータス ライン、--max-budget-usd、および SDK のコスト数値を更新し、Sonnet 5.5 キャッシュ読み取りの価格を 100 万トークンあたり $0.10 (以前は $0.20) に設定しました。
  • バンドルされた dataviz スキルを更新しました: ライト モードの 7 番目のシリーズの明るい紫色、ダーク モードのより柔らかいプライマリ テキスト、および 1K のようなコンパクトな y 軸ラベル
  • 事前に送信される MCP ツールの説明および MCP サーバー命令のデフォルト制限を 2,048 文字から 4,096 文字に変更しました。
  • ← の変更: セッションがバックグラウンドに移動している間に開始されたターンまたは ! コマンドは、見えないところで終了するのではなく停止されるようになりました。
  • [VSCode] 拡張機能の設定に欠落している claudeCode.spinnerVerbs を修正したため、settings.json が完了して検証されるようになりました。不正な値によってチャット パネルが表示されなくなりました
  • [VSCode] 端末と同様に、@browser に接続されたセッションを含むすべてのセッションでブラウザーのアクションの前に質問するように Chrome のクロードを変更しました。サイトにセッションを許可すると、繰り返しの質問が停止します
  • [VSCode] C:\repo\file.ts や file:///C:/repo/file.ts などの完全な Windows パスとして記述されたチャット リンクが Windows 上で開かない問題を修正しました。
  • [VSCode] OS、VS Code、または prefersReducedMotion 設定でモーション軽減がオンになっている場合でも、動作中のインジケーターがアニメーションする問題を修正しました。
  • [VSCode] ディスプレイがオフになった後やリモート ウィンドウが再接続された後など、パネルがメッセージに遅れて追いついた後、プロンプト キャッシュ クロックの読み取りがウォームになる問題を修正しました。
  • [クラウド セッション] 管理者設定のセルフホスト環境の [アクティビティ] タブにあるセッションとランナーのリストにステータス フィルターを追加しました。一度に複数のステータスを選択できます
  • [クラウドセッション] 同じキュー位置を示すセルフホストランナーを待機しているすべてのクラウドセッションを修正しました。それぞれが自分より先に進んでいるセッションの数を表示するようになりました
  • [クラウドセッション] クラウドセッションでクロードがまだ返信している間に送信したメッセージが、終了時にその返信の上にジャンプする問題を修正しました。リロード後も含めて、それより下に留まるようになりました
  • [Claude Tag] Slack の Claude を変更し、スレッド内の最新の返信にのみセッション リンク、モデル、コストを含むフッターを表示するようにしました。フッターが削除される前の返信
  • [Claude Tag] クロードの Slack 返信とタスク チェックリストの一部に括弧が含まれている URL へのリンクを修正しました。これにより、括弧テキストが表示され、間違ったページが開かれてしまいました。
  • [Claude Tag] Claude の Slack 返信で、6 桁のプル リクエスト番号など、16 進数の色にしか見えないコードの横に色見本が描画される問題を修正しました。
  • [Claude Tag] Claude Tag 管理者権限を持つメンバー向けに、アクティビティ ページの [メモリ] タブにワークスペースおよびチャネル メモリ ファイルの作成、編集、削除を追加しました。
  • [Claude Tag] クロードが Slack チャンネルに投稿するプラグイン確認カードに、名前の代わりにプラグインの ID が表示される問題を修正しました。
  • [Claude Tag] Slack でクロードがチャンネル独自の設定に含まれていないプラグインを削除するカードを投稿する問題を修正しました。代わりにプラグインの出所を説明するようになりました
  • [Claude Tag] セルフホスト環境のセッションがタスクの途中で新しいランナーに移動したときに、Slack の Claude が応答を失うことがある問題を修正しました。
  • [コードレビュー] レビュー終了後、プルリクエストでコードレビューチェックが「進行中」のままになることがある問題を修正しました。レビューの結果が表示されるようになりました
  • [コード レビュー] コード レビューの管理設定が改善され、一般的なエラー メッセージではなく、ポリシー制限などの設定を保存できなかった理由が表示されるようになりました。
