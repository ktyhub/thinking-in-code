claude-code v2.1.290

パッチ 公開日2026年10月5日 出典anthropics/claude-code 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

クロードコード v2.1.290

何が変わったのか

  • MOD の turn.step フックの結果に serverToolUses を追加しました。ツールは API 実行自体 (アドバイザー) を呼び出し、それぞれに ID、名前、入力、開始、終了を指定します。
  • プラグイン フックの tool.check イベントに agentId を追加しました。これにより、フックはメイン セッションの権限チェックからサブエージェントの権限チェックを指示できるようになります。
  • MOD の tool.check フックが読み取る質問と評決に ceiling を追加し、組織がツールに必要とする承認の名前を示しました
  • ThemeKey および Color タイプをプラグイン フックのタイピングに追加したため、MOD の描画に名前を付けることができるテーマ カラーがエディタにリストされるようになりました。
  • claude plugin validate に追加: MOD がゲーティング サイトに登録する各フックは、.catch (--json の下の gatingHooks) を持つかどうかとともにリストされます。
  • クロード アプリ ゲートウェイのサインイン承認ページに [拒否] ボタンを追加しました。保留中のサインインが終了するため、待機中の端末は数秒以内に停止します。
  • claude attach <name> および claude logs <name> を追加: セッション名の一部が ID の代わりに機能します。
  • ページで ant apply ファイルとして説明されている管理対象エージェント パターンを設定するための /claude-api managed-agents-onboard <url> を追加しました
  • ant CLI を使用して、deep-researcher などのコンソール クイックスタート テンプレートを構築するための /claude-api managed-agents-onboard <quickstart-name> を追加しました。
  • 管理設定ファイルが管理設定フォルダー外のファイルへのリンクである場合の警告を追加しました
  • 管理設定がユーザー構成のサンドボックスのallowReadパスまたは許可されたドメインを無視する場合の/statusとドクター警告を追加しました
  • ステータスが 400 以外のクロード コードのベータ ヘッダーの 1 つ、または 2 番目のベータと一緒に拒否するプロキシやゲートウェイの背後でリクエストが失敗する問題を修正しました。
  • 数百枚の画像を含む長いセッションが「リクエストはモデルによって処理不可能として拒否されました」エラーでスタックする問題を修正
  • クロードがまだ考えている間にAPIの出力コンテンツフィルターが応答を停止すると、ターンがすぐに終了する問題を修正しました。エラーが表示される前にリクエストが 1 回再試行されるようになりました
  • 再開されたサブエージェントとチームメイトが、実行中にメッセージを受信した後に以前の思考とプロンプトのキャッシュを失う問題を修正
  • WebFetch が 100,000 文字を超えるページ テキストをサイレントに削除する問題を修正しました。未読の量が表示され、読み続けるには offset 時間がかかります
  • 応答が数千レベルの深さでネストされたリストまたは引用符を含む場合のクラッシュ (「最大コール スタック サイズを超えました」) を修正しました
  • クロードがまだ作業している間に送信されたプロンプトが /rewind に表示されない問題を修正
  • 会話がコンパクトになると、スケジュールされたタスク (間隔のある /loop、リマインダー) が再開時に静かに戻らない問題を修正しました。このバージョン以降に作成された圧縮をカバーします
  • フォアグラウンドに設定されたスケジュールされたタスクが ← または /background ハンドオフ後に起動されず、定期的なタスクが再開、リスポーン、またはフォークのたびに追加の実行を起動する問題を修正しました
  • 構造化された出力がすでに配信された後に接続が切断された場合、ヘッドレス --json-schema が success 結果で is_error: true でゼロ以外で終了する問題を修正しました。
  • 自動モード分類子がサーバープッシュ型の ask ポリシーを実行する非読み取り専用コネクタ ツールを承認できるようにするプラン モードを修正しました。
  • permissions.blockReadsOutsideWorkingDirectories または Read 拒否ルールの下でロードされる作業ディレクトリの外でシンボリックリンクされたプロジェクト CLAUDE.md、ルール、または AGENTS.md を修正しました。
  • xn-- ホスト ラベル内のワイルドカードを使用した URL の許可パターンと拒否パターンがプロセスごとに異なるように一致する問題を修正しました。
  • サインインまたは再接続後に、組織によって提供された MCP サーバーが自分のものとして再リストされる問題を修正しました (ヘッドレス セッションや SDK セッションでの遅い結果などによるもの)
  • git stash create が失敗した場合、Windows 上でコミットされていない変更を警告なしで削除し、git add -N ファイルが削除または移動された後に /ultrareview が拒否する問題を修正しました。
  • macOS および Linux でのバックスラッシュを含むパスに対する plansDirectory 設定のプロジェクト ルート チェックを修正しました。
  • 非常に長いリモート コントロールおよびクラウド セッションで、ストリーミングではなく一度にブロックが表示される可能性がある返信を修正しました。
  • claude daemon run および claude daemon logs で端末制御文字を画面に渡すバックグラウンド デーモンのログを修正しました。 \uXXXX が逃げるように表示されるようになりました
  • 自己ホスト型ランナー: ランナーを数秒間フリーズさせる、セッションのエラー出力の細工された非常に長い行を修正しました。
  • フックがプロンプトまたはツールの呼び出しでフック ワーカーをビジー状態に保つと、アンロードされる .catch を含むプラグイン フックとその .catch がスキップされる問題を修正しました。
  • 応答中のモデルのフォールバックが破棄したツール呼び出しをリストする MOD の turn.step 結果を修正しました
  • クロードがメッセージまたはファイルを送信した直後にコンテナが再起動されると、Cowork クラウド セッションの応答が完了しないことがある問題を修正しました
  • 最上位関数の 1 つに似た名前のオプションを構造化するフック モジュールを拒否する claude plugin validate とプラグインの読み込みを修正しました
  • git の設定で core.safecrlf=true が設定されている場合、/ultrareview がコミットされていない変更をアップロードできない問題を修正しました
  • 設定に異なるレベルが保存されているフォールバック モデルでフラグ付きメッセージが再試行されるときに変更されるエフォート レベルを修正しました
  • Windows: ファイルが CRLF 行末で保存されると失敗するスキルとコマンドの複数行の ! シェル ブロックを修正しました。
  • 全画面モードで検索中に /permissions タブが click された場合、強制終了されるまでクロード コードがハングする問題を修正
  • 「null はオブジェクトではありません」エラーで会話の圧縮が失敗することがある問題を修正
  • 自動モードでレポートを返すサブエージェントの turn.complete で空の answer を読み取るプラグイン フックを修正しました
  • 失敗したリロードの後に更新を行うと、メッセージなしで MOD がアンロードされる問題を修正しました。その失敗行は、以前にロードされたバージョンがアンロードされたことを示すようになりました。
  • next(e) を呼び出した後にプロンプトが表示される MOD の prompt.submit フックがサイレントに無視されるのを修正しました。フックは名前で失敗として報告されるようになりました。
  • 描画するたびに高さが変わる木の上でモジュールのペインまたはバンドが終わりなく再描画される問題を修正
  • macOS および Windows で読み取られた画像が、読み取り中に交換されたリンクを通じて、承認された内容以外のファイルを返すことができる問題を修正しました。
  • ユーザーがインストールした MOD が組織のプラグインをアンロードしてしまう可能性がある問題を修正しました。 MODはアンロードされたものになります
  • disableClaudeAiConnectors および allowedMcpServers の URL ルールが、.mcp.json で宣言された一部の MCP エントリ、プラグイン、またはエージェントに適用されない問題を修正しました。
  • 描画するたびにツリーの高さが変更されると、MOD のインライン ペインが際限なく再描画される問題を修正
  • 読み取りブロックの下の @ メンションまたは --restricted が、読み取り中に変更されたリンクを通じて作業ディレクトリ外のファイルを読み取ることができる問題を修正しました。
  • エージェント ビューで Esc キーを押すと、「もう一度 Enter キーを押してこのセッションを再開します - 応答していません」と確認される問題を修正しました。 Esc はセッションを再度開くだけになりました
  • セッションが作成したワークツリーに入った後、エージェント ビューがバックグラウンド セッションの /loop 実行カウント、カウントダウン、およびライブ ステータス ラインを失う問題を修正しました。
  • 返信または新しいエージェントのプロンプトに貼り付けられた画像を読み取るための承認を求める手動許可モードの claude agents セッションを修正しました
  • declare、typeset、export、または readonly のプレフィックスとして設定された変数に由来する名前を持つコマンドまたはパスが欠落している拒否または確認ルールを修正しました
  • プロンプトに貼り付けまたはドラッグされた画像パス、または @ で言及されたフォルダーにリストされているファイル名に読み取り拒否ルールが適用されない問題を修正しました。
  • ユーザーがインストールした MOD により、組織の警備員がチェックをスキップする可能性がある問題を修正しました。そのようなMODは現在アンロードされています
  • MOD が非ラテン文字を含む長い複数行のテキストを描画するときに各再描画を停止させるプラグイン フックを修正しました
  • セクションの一番下のセッションが削除された後、エージェント ビューで Ctrl+X を繰り返すと次のセクション全体が削除される問題を修正しました
  • languageの設定に関係なく、メモを英語で書くことを知っておくべきを修正しました
  • 非常に長いメッセージを送信した後のフリーズを修正しました
  • トランスクリプトを拡大したり (ctrl+o)、または矢印、ダッシュ、ボックス描画などの非 ASCII 文字を含む大きなツール出力のサイズを変更したときの速度低下を修正しました。
  • claude respawn が、空の会話から開始するのではなく、トランスクリプトが保存されていないバックグラウンド セッションに以前のメッセージを再送信する問題を修正しました。
  • エージェント ビューで n: または Ctrl+F 検索後の Esc キーでフォーカスがセクション ヘッダーに移動する問題を修正しました。Ctrl+X を 2 回押すと、セクション内のすべてのセッションが削除されます。
  • claude agents が停止したセッションに配信できなかったスラッシュ コマンドを保存し、次回そのセッションが再開されたときに単独で実行する問題を修正しました。
  • unset または unspecified という名前の git フィルター ドライバーの下で、ファイルに対してフィルターされていないコミットされていない変更をアップロードする /ultrareview を修正しました。アップロードが停止し、ドライバーの名前を変更するように求められます。
  • ツール全体の分類子をスキップする許可ルール、またはクロード コードが無視する許可ルールを示唆する自動モード拒否を修正しました。
  • スタッシュを選択したときに、同じ名前の追跡されたファイルを置き換えたフォルダー内のファイルを削除する claude --teleport および /teleport を修正しました。スタッシュは拒否され、その理由が表示されます。
  • Esc キーでエージェント ビューの「このセッションを新たに再起動するには、もう一度 Enter キーを押してください」というプロンプトを確認する問題を修正しました
  • エージェント ビューの /loop 実行カウントがフリーズし、/clear 後にカウントダウンが消える問題を修正しました。新しい会話からカウントが再開されるようになりました
  • --channels 権限リレーを修正: セッション内で繰り返される応答 ID は、別のプロンプトを承認する代わりに無視されるようになりました。
  • Chrome 接続に失敗した後に /chrome「再接続拡張機能」がブラウザ ツールを復元しない問題を修正し、復元できない場合の説明を追加しました (anthropics/claude-code#98135)
  • ゲートウェイ (ANTHROPIC_BASE_URL と ANTHROPIC_AUTH_TOKEN) を介してクロードに到達し、Anthropic アカウントを持たない人々に対して MOD がオフのままになる問題を修正
  • バックグラウンド セッションがクラッシュした直後に claude agents から送信された応答が 2 秒後に拒否される問題を修正しました。セッションの再開中に最大 12 秒間再試行されるようになりました。
  • claude agents が保存され、次回再起動されたときに自動的に送信される実行中のセッションに配信できなかったスラッシュ コマンドと多肢選択の質問に対する回答を修正しました。
  • ヒアドキュメントを別のコマンドにパイプして実行するたびに承認を求めるサンドボックス コマンド (cat <<EOF | python3) を修正しました
  • 「バックグラウンド サービスを再起動できませんでした」というエラーで claude agents が失敗し、Homebrew アップグレード後にバックグラウンド セッションが停止する問題を修正しました (この後のアップグレードから有効になります)
  • エージェント ビューの「このセッションを新たに再起動」すると、空の会話から開始するのではなく、セッションから以前のメッセージが再送信される問題を修正しました。
  • シェルが引数をワイルドカードとして展開する一部の読み取り専用コマンド (rg や git grep など) を自動承認する Bash 権限チェックを修正しました。これらは承認を求めるようになりました
  • 保存された設定が古いためにアップグレード後に実行を拒否する claude plugin test を修正
  • zsh が bash とは異なる変数名を読み取る特定のコマンドを自動承認する Bash 権限チェックを修正しました。これらは承認を求めるようになりました
  • sandbox.excludedCommands の git * などの git パターンからのサンドボックス除外を維持する git clone オプションの短い形式を修正しました。現在は長い形式のように扱われます
  • プロジェクトの設定で設定されたプロキシまたは API エンドポイントを無視するセッションの最初の機能フラグ リクエストを修正しました
  • ローカル ブランチの /ultrareview が、そのブランチを .git の外に保持するリポジトリ内のアップロードからコミットされていない作業をサイレントに残す問題を修正しました (git 2.54+)。今では説明付きで拒否される
  • コンテナの再起動により保留中の /loop ウェイクアップまたはスケジュールされたタスクが失われた後、クラウド セッションがスリープ状態のままになる問題を修正しました。クロードはその旨を伝えられ、再度スケジュールを設定できるようになりました
  • 2025 年 11 月の修正が適用されていない PostgreSQL バージョンで、クロード アプリ ゲートウェイの保持スイープが同時に更新された復帰開発者の ID 行を削除する問題を修正しました。
  • サンドボックス自動許可の下で、サンドボックス監視ツールのコマンドが許可プロンプトをスキップする問題を修正しました。彼らはあなたの許可ルールに従います
  • ID プロバイダーに提示する証明書の件名が空の場合にクロード アプリ ゲートウェイが起動できない問題を修正しました
  • store.postgres_url を解析できない場合に、「無効な URL」を表示して終了するクロード アプリ ゲートウェイを修正しました。エラーは設定に名前を付け、URL が何を保持しているかを示すようになりました。
  • バックグラウンド エージェントが「エージェントが停止しました」で失敗し、Mac がスリープから復帰したときにワークフロー ツールのサブエージェントがプロンプトから再起動する問題を修正しました。
  • 管理設定が遅いファイル システム (特に WSL 下の Windows ドライブ) 上の多くのパスの読み取りを拒否する場合、VS Code 拡張機能などの SDK ホストでの 2.1.285 以降の起動の遅さや失敗を修正しました。
  • Bedrock、Vertex、Foundry、およびカスタム ゲートウェイで停止したストリームとして扱われるコンピューターのスリープによって応答が中断される問題を修正しました。
  • ~/**/.env などのサンドボックス読み取りルールが大きなフォルダーをカバーしている場合、最初のリクエストの前、および Linux および WSL の /sandbox Config タブでフリーズする問題を修正しました。
  • フォルダーの名前が異なる場合（英語以外の名前など）、SKILL.md で名前を要求してもスキルが見つからない問題を修正しました。スキルのリストには両方の名前が表示されるようになりました。
  • プランが表示される前にクラウドセッションのコンテナが再起動されると、プランモードで書かれたプランが失われる問題を修正しました
  • Bash ツールが、新しい設定ディレクトリで起動してから数秒後に最初のコマンドを実行したときに、セッション全体のシェル エイリアス、関数、プラグインの PATH エントリが時々失われる問題を修正しました。
  • HTTP MCP サーバーが非常に大きな応答を送信する場合の無制限のメモリ使用を修正しました
  • クラウド セッション内から開始されたクロード コードの実行で失敗するアーティファクト操作を修正しました (たとえば、Bash ツールから実行された claude -p)
  • リモート セッションから送信されたファイルが 4 つ以上同時に送信された場合、「承認されたファイルではない」として拒否されることがある問題を修正
  • 端末で--continueまたは--resume <session-id>とのセッションを再開するときにプランモードが復元されない問題を修正
  • 別の GitHub マーケットプレイスのダウンロード フォルダーにちなんで名付けられたマーケットプレイスが、そのマーケットプレイスのダウンロードを停止する問題を修正しました
  • Mac が実行中にスリープ状態になったときに「プロンプトが長すぎます」というメッセージが表示されて自動圧縮が中断される問題を修正しました。
  • 会話に貼り付けられた非常に大きなスタック トレースまたはソース ファイルが含まれている場合、キーを押すたびに数百ミリ秒間フリーズする巻き戻しメニュー (Esc Esc / /rewind) を修正しました。
  • サブディレクトリの下のファイルが @ メンションされている場合、そのサブディレクトリの AGENTS.md が添付されない問題を修正しました。
  • セッションフォルダーが相対シンボリックリンクである場合、停止したランナーが「欠落しているがすでに登録されているワークツリー」で失敗した後に再開されるセルフホストランナーセッションを修正しました。
  • シークレットスキャンまたは許可プロンプトが長いトークンのようなテキストに遭遇したときのフリーズを修正しました
  • Bash 権限チェックで、読み取り専用コマンドの一部のオプション値のワイルドカードに読み取り拒否ルールまたはディレクトリ外読み取りブロックが適用されない問題を修正しました。
  • CLAUDE_CODE_USER_DIALOG_TIMEOUT_MS=5m が 5 ミリ秒として読み取られ、リモート ダイアログが一度にキャンセルされる問題を修正しました。単位接尾辞が付いた値は dialogExpiry に戻るようになりました。
  • MCP サーバーのツール リストに結合文字の非常に長い実行が含まれている場合のストールを修正しました。
