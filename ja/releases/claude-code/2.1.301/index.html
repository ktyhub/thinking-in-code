claude-code v2.1.301

パッチ 公開日2026年10月15日 出典anthropics/claude-code 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

クロードコード v2.1.301

何が変わったのか

  • CLAUDE_CODE_RETRY_WATCHDOG_MAX_USAGE_LIMIT_WAIT_MS を追加しました。無人再試行モード (CLAUDE_CODE_RETRY_WATCHDOG) は、待機するのではなく、リセットが遠すぎる使用制限でリクエストを終了します。
  • ant CLI によるトレース宛先の設定を含む、OpenTelemetry トレース ガイダンスを claude-api スキルに追加しました。
  • % モーションを vim モードに追加しました。単独または d/c/y を使用して、対応するブラケットにジャンプします。
  • rows を MOD の Input に追加しました: ターミナル内の数行のテキスト フィールド。 Enter キーで送信され、Shift+Enter または Enter キーで新しい行を開始する前にバックスラッシュが入力されます。
  • classifier_verdict および permission_mode を OpenTelemetry tool_decision イベントに追加したため、自動モード分類子の決定をパーミッション ルールとは別に伝えることができます。
  • classifier_category を OpenTelemetry tool_decision イベントに追加し、OTEL_LOG_TOOL_DETAILS=1 の場合に分類子ブロックが一致した組み込みルールに名前を付けました。
  • プッシュされていないコミットがいつ保持されるかを確認せずに、WorktreeCreate フックによって作成されたワークツリーの削除を終了する問題を修正しました。
  • 最新の Fable モデルが組織で利用できない場合に Anthropic API で発生する fable (および best) モデルのエイリアス エラーを修正しました。Claude Code は以前の Fable モデルで 1 回再試行するようになりました。
  • ディスクがいっぱいでログインが更新されない場合の、誤解を招く「/login を実行してください」エラーを修正しました。エラーはディスクに名前を付け、ファイルを削除するように指示します。
  • 検索プログラムが結果を返す前に予期せず失敗した場合に、一致しないと報告する Grep と Glob を修正しました。検索が失敗したことを示すエラーが返されるようになりました
  • ワークフロー エージェントがタスク テキストにユーザー権限を持たないというハーネスのメモを読んだ後でも、ステップをスキップし、実行が引き続き成功を報告することがある問題を修正しました。
  • PreToolUse フックが編集または書き込みをカバーする場合にアーティファクトの更新が拒否される問題を修正しました。クロードは、パブリッシュ呼び出しでファイルを変更するのではなく、ファイルを編集してから再パブリッシュするようになりました。
  • 非常に多くの引数名または非常に長い引数名を持つスキルとコマンドが呼び出されると数秒間停止する問題を修正しました。最初の 64 個の名前のみ (それぞれ最大 64 文字) が入力されるようになりました。
  • 引数が多くのプレースホルダーを満たすときに非常に大量のメモリを使用するスキル、コマンド、フックを修正しました
  • RHEL 8 の MATE ターミナルなど、0.53 よりも古い VTE 上に構築されたターミナルで、フォルダ trust プロンプトを覆う >0q や、終了時のシェル プロンプトの前の >4m などの浮遊文字を修正しました。
  • iTerm2 の一部のバージョンで起動時のプロンプトに表示される迷走 GOK テキストを修正しました
  • プロバイダーが Bedrock ではない場合、awsAuthRefresh コマンドを実行すると名前に application-inference-profile が含まれるモデルに切り替わり、モデル切り替えフックが遅延する問題を修正しました。
  • トークン更新の途中で claude auth status や claude plugin list などの短いコマンドが終了した後のサインイン更新タイムアウトと予期しないサインアウトを修正しました
  • 許可チェック中にターン途中に送信されたメッセージによってツール呼び出しが中断され、ユーザーによって拒否されたとしてモデルに報告される問題を修正しました
  • コンテキスト ウィンドウが小さいモデルに切り替えると、最初に確認せずに前のモデルによる概要に使用クレジットが費やされる可能性がある問題を修正しました
  • LLM ゲートウェイの背後で、選択しなかったモデル上で会話が何度も圧縮され、その応答で要求されたモデルとは異なるモデル名が返される問題を修正しました。
  • 低速またはビジーなマシン上で Escape 後に vim モードが INSERT のままになることがある問題を修正
  • vim モードで入力された AskUserQuestion の回答を破棄する Esc を修正しました。フリーテキスト フィールドは vim NORMAL モードをサポートし、Esc は NORMAL からのみキャンセルします。
  • .xlsm、.parquet、.epub、.heic などのバイナリ ファイルをテキストとして読み取る読み取りツールを修正しました
  • 計画承認カードの計画を含め、端末に対して幅が広すぎる場合に、ヘッダー行のみが何も描画されないマークダウン テーブルを修正しました
  • AWS の Claude Platform では CMEK 外部キー エンドポイントが利用できないという /claude-api スキルを修正しました
  • /rewindを使用した後、スキルがモデルにリストされなくなる問題を修正
  • ロードされていない履歴に対して ctrl+o を提供する再開セッションの圧縮行を修正しました。以前のメッセージが保存されている場所が表示され、全画面表示にも表示されるようになりました。
  • 応答を中断した直後に「新しいタスク?/トークンの保存をクリア」というヒントが表示される問題を修正しました
  • プラグインまたはスキルフックの ask 決定に対する許可プロンプトで、フックがどのプラグインまたはスキルからのものかを表示しない問題を修正しました。
  • /diff が、git チェックの 1 つがタイムアウトまたは失敗した場合に、reftable リポジトリで競合するチェリーピックまたはリバートに気付かない問題を修正しました。
  • 同じセッション内で Bash cd の後に読み取り、編集、または再実行すると、許可を求めるか拒否されるワークフロー スクリプトを修正しました
  • ダーク ANSI テーマと 16 色端末での薄暗いテキストを修正しました。塗りつぶされたボックス内では薄暗くなりますが、選択と検索のハイライトの下では薄暗くならず、リストの説明は他の二次テキストと同様に薄暗くなります。
  • claude -p の実行やクラウド セッションのように、新しいクロード コード プロセスの最初の応答が完了する前に呼び出された場合に nothing-to-fork を返す MOD の $.model.fork を修正しました。
  • フルスクリーン モード: 表示されるトランスクリプトが再構築されている間、/compact と自動コンパクトで UI が一時的にフリーズする問題を修正しました。
  • 自己ホスト型ランナー: 管理設定が MCP サーバーを制限している場合、Slack から開始されたセッションがリポジトリを見つけたり接続したりできない問題を修正しました。 deniedMcpServers を使用してこれらのツールをオフにしてください
  • セルフホストランナー: 無関係なセットアップまたはセッションエラーが git の missing-ref 文言を引用した場合、ソース ブランチが削除され、再試行されないと報告されるセッションを修正しました。
  • 自己ホスト型ランナー: 終了しようとしているセッションに対して、失敗または declined セッションの解放の再試行を約束するログを修正しました。繰り返される失敗のカウントが表示されるようになりました
  • Windows: 停止したバックグラウンド PowerShell コマンドで出力ファイルの終了 [killed] 行が欠落している問題を修正しました。
  • コンテキスト ウィンドウが小さいモデルへの切り替えが改善されました。新しいモデルには長すぎる会話が、最初に前のモデルによって要約されるようになりました。
  • 長時間実行されるサブエージェントが動作する際のレンダリング パフォーマンスの向上: 進行状況の追跡は、レンダリングごとに完全に再処理されるのではなく、段階的に更新されるようになりました。
  • アーティファクトの改善: クロードが作成したページがスティッキー ヘッダーの上のバンドをペイントするようになり、スクロールされたテキストがモバイル アプリで表示されなくなりました。
  • 改善された MOD: VS Code、デスクトップおよびモバイル アプリでは、質問ダイアログの上に描画されるツリーに Markdown と最大 48 行を保持できるようになりました。ターミナルは 12 個のプレーン行を保持します
  • フックがスローまたはタイムアウトした場合にのみ実行されるように、MOD フックの .catch ハンドラーを変更しました。フック自身の呼び出しの下で発生したイベントは、.catch を尋ねることなくそのフックをスキップするようになりました。
  • 変数が設定または設定解除されると {} で解決するか、書き込みが行われない場合にその理由を示す { deny } で解決するように MOD の $.env.set を変更しました。
  • [VSCode] クロードの応答に LaTeX 数学レンダリングを追加しました ($$ および複数行 \[ … \] ブロック、インライン $…$ および \(…\) 数学を含む)
  • [VSCode] VS Code および JetBrains パネルの Pro および Max プランの使用量制限バナーに「さらに使用量を取得」リンクを追加しました
  • [VSCode] リロードするたびにパネルが再度開かれるとクラッシュまたはフリーズする会話を修正しました
  • [VSCode] 長い思考中にチャット パネルの速度が低下する問題を修正しました。アップデートのたびに思考テキスト全体を再解析しなくなりました。
  • [VSCode] 一部の言語サーバーのルール コード (MD013 など) の代わりに「[object Object]」と表示される診断を修正しました。
  • [VSCode] ディクテーションが提供されない場合 (claude.ai 以外のサインイン、リモート Windows) で、マイクの許可を確認するためにロードされているネイティブ ディクテーション オーディオ モジュールを修正しました。
