claude-code v2.1.284

パッチ 公開日2026年9月28日 出典anthropics/claude-code 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

クロードコード v2.1.284

何が変わったのか

  • Claude Sonnet 5.5 (claude-sonnet-5-5) を追加しました。Anthropic API のデフォルトの Sonnet モデルになりました - 1M コンテキスト、Mtok あたり $2/$10、$0.20/Mtok キャッシュ読み取り
  • 作業ディレクトリ外の読み取りの前に、自動モードのプロンプトに「はい、ただし次回も尋ねます」という回答を追加したため、その読み取りを許可しても、その後の読み取りについては尋ねられるようにすることができます
  • ゲートウェイがこのバージョン以降を実行している場合、/usage およびステータス行 (「$271.40 / $500.00 今月の支出額」など) のクロード アプリ ゲートウェイの支出制限に金額が追加されました。ステータス行の rate_limits.spend_limit も used_usd、limit_usd、period になります。
  • effortSlider:decreaseEffort、increaseEffort、toggleUltracode のキーバインド アクションを追加したため、/effort スライダーの矢印キーと Tab キーを keybindings.json でリバウンドできるようになりました。
  • /rate-limit-options を /help に追加し、claude.ai サブスクライバー用のコマンド メニューを追加しました。これにより、使用制限の通知に、見つけられるコマンドが示されるようになりました。
  • 接続に失敗した、または認証が必要なすべての MCP サーバーを一度に再試行するために、対話型ターミナルに /mcp reconnect all を追加しました。
  • 管理ポリシーの availableModels が空の場合、または model または enforceAvailableModels を設定せずにクロード コードが開始されるモデルを省略した場合の、クロード アプリ ゲートウェイの起動警告を追加しました。
  • クロード アプリ ゲートウェイの telemetry.forward_to 宛先に auth: { google: {} } を追加したため、ゲートウェイの Google Cloud 認証情報を使用してテレメトリを Google Cloud の OTLP エンドポイントに直接エクスポートできるようになりました
  • client シークレットの代わりに証明書資格情報を発行する ID プロバイダー向けに、Claude アプリ ゲートウェイとその ID プロバイダーの間に証明書 client 認証 (private_key_jwt) を追加しました。
  • 中断された応答として再試行または報告されるのではなく、「JSON 解析エラー」や「未定義はオブジェクトではありません」などの生のエラーを表示したり、応答に「未定義」という単語が書き込まれたりする破損した応答ストリームを修正しました。
  • 思考ブロックが再試行されずにエラーでターンを終了した直後に発生する過負荷またはサーバーエラーを修正しました
  • 圧縮後に持続する「プロンプトが長すぎます」エラーを修正しました。圧縮されたリクエストがまだ長すぎる場合、クロード コードはもう一度圧縮され、最近の会話の内容が少なくなります。
  • モデルが利用できず、フォールバック モデルが残っていないセッションで、モデルが利用できない通知とその詳細リンクの代わりに、裸の「現在利用できません」メッセージ (クラウド セッションでは「問題が発生しました」) が表示される問題を修正しました。
  • ユーザー メッセージに不正な形式の source を含む画像が含まれている場合にエージェント SDK セッションがクラッシュし、不正な形式のドキュメント ブロックの後に毎ターン失敗する問題を修正しました。不正な画像が説明文に置き換えられるようになりました
  • サーバーがまだ接続しているときに、再開されたセッションでの MCP ツール呼び出しが「利用可能なツールはありません」というメッセージで失敗する問題を修正しました。通話はサーバーを待つまで最大 10 秒かかります
  • プラン使用量エンドポイントがレート制限またはログインを拒否した後に繰り返し呼び出される問題を修正しました。/usage、/extra-usage、および IDE 使用量ビューは、再質問する代わりにバックオフされるようになりました。
  • 管理設定が MCP サーバーをプラグインに制限している場合に成功を報告する claude mcp add を修正しました。ロードしないサーバーを保存する代わりに、拒否して何をすべきかを指示するようになりました。
  • /plugin 設定画面を修正しました。ブール値オプションはフリー テキストではなく true/false の選択肢になり、数値オプションは無効な入力を拒否し、タブを切り替える代わりに ←/→ オプション フィールドを変更します。
  • ANTHROPIC_FOUNDRY_RESOURCE が未検証の Foundry エンドポイント ホストに挿入される問題を修正。プレーンなリソース名ではない値は拒否されるようになりました
  • Claude アプリ ゲートウェイの背後にある Claude デスクトップが 1M コンテキスト オプションを提供しない問題を修正しました。ゲートウェイは、各 1M 対応モデルをデスクトップ用に自動的にマークするようになりました。
  • シェル モードで非表示のバックグラウンド タスク ピルを選択する ↓ を修正しました。これにより、Backspace キーと Ctrl+U キーによるプロンプトの編集が停止されました。
  • 多くのプラグインが有効になっている Windows で Bash ツールが失敗する問題を修正しました。存在しないプラグイン bin/ ディレクトリは PATH に追加されなくなり、継承されたエントリは 2 回追加されなくなりました。
  • sparsePaths プラグイン マーケットプレイスが空のクローンを作成し、古い git (2.39 より前) で動作するローカル コピーを置き換える問題を修正しました。これは、更新のたびに「marketplace.json ファイルが存在しません」というメッセージが表示されて失敗していました。
  • トランスクリプト モードの [ が会話をスクロールバックに書き込むときに、セッションの上のターミナル出力が消去されるフルスクリーン レンダリングを修正しました (macOS および Linux)
  • 上にスクロールしているときに返信のストリーミングが終了すると、前のメッセージまたは一番下にジャンプする全画面のスクロール位置を修正しました
  • /config や /plugin などのダイアログのタブ バーで、幅の狭いターミナルの単語の途中でタイトルとタブ ラベルが壊れる問題を修正しました。収まらないタブは次の行全体に移動します
  • 最後のモデルまでスクロールした後、リストの下に「+1 モデル」と表示される /model ピッカーを修正しました。カウントは、表示されている行の下にあるモデルのみをカバーするようになりました。
  • 生成された keybindings.json に何も行わないフッター アクションのバックスペースと削除バインディングを書き込む /keybindings を修正しました。
  • 表示しているエージェントの行で、リバウンド エージェント パネル閉じるキー (footer:close) 自体の代わりに「x」を入力する問題を修正しました。
  • vim モードの . が、非常に高速に入力されたテキスト (たとえば、ssh 経由または tmux で) または括弧で囲まれて貼り付けずに貼り付けられたテキストを繰り返さず、何も入力せずに変更を繰り返した後 (cw から Esc など)、プロンプトが INSERT モードのままになる問題を修正しました。
  • 最後の行の dd またはプロンプトの終わりの yy の後、画像プレースホルダーの左括弧上にカーソルが残る vim モードを修正しました。この場合、r または x は画像を分割または削除します。
  • 短い安全遅延が再起動する前に、リモートコントロール有効化プロンプトに応答して端末がフォーカスを取り戻した瞬間にキーが押される問題を修正しました。
  • クロード コードがホーム ディレクトリで開始されたときに、レンダラーを切り替えたり更新したりした後、ワークスペース trust ダイアログが 2 回目に表示される問題を修正しました。
  • プロジェクト外部から .claude/rules にシンボリックリンクされたルールが、外部インポートの承認プロンプトを表示せずにスキップされる問題を修正しました。プロジェクトの外部からシンボリックリンクされた .claude ディレクトリが同じ承認を要求するようになりました。
  • マネージド allowManagedPermissionRulesOnly の下で allowed-tools 経由で独自のツールを事前承認するマーケットプレイス、claude.ai および npm のプラグインを修正しました。公式の Anthropic ソースまたは設定を管理しているソースからのプラグインのみが事前承認の維持を保証します
  • 依存関係のバージョン範囲が満たされない場合に、プラグインが有効になり記録されたままになる最初の claude plugin install の失敗を修正しました。
  • フックが stdout にも書き込んだときに失敗したフックの stderr が削除され、失敗したフックに対して出力が何も記録されないデバッグ ログを修正しました。失敗したフックもステータスコードを記録するようになりました
  • Elitation フックと ElitationResult フックによって返される {"decision":"block"} が無視される問題を修正しました。終了コード 2 と同様に、MCP 誘発を declines するようになりました。
  • SendMessage ツール (Claude Desktop など) を使用せずに起動されたセッションでも、それを使用して他のセッションにメッセージを送信するように指示される問題を修正しました。
  • クロード アプリからリモート コントロール経由で送信された写真が、キューに入れられたメッセージが編集するためにターミナル プロンプトに引き戻されたときに失われ、キャプションのない写真のカーソルが 1 文字移動する問題を修正しました。
  • 自動使用制限の待機中にメッセージを入力すると、そのターンが再び制限に達したときに、「使用制限で自動的に続行」設定の制御から待機が外れる問題を修正しました。
  • すでに最高の Max プランを利用しているユーザーに /upgrade を示唆する使用制限の警告を修正しました。警告と /upgrade 自体は、利用可能な場合は /usage-credits を指すようになりました。
  • プロキシの背後にあるカスタム モデルなど、Claude Code が認識しないモデル ID をセッションで実行すると、Explore サブエージェントが Claude API の Opus に切り替わる問題を修正しました。 Explore はそのモデルを継承するようになりました
  • クロードが推論のみで更新したため、セルフペースモードでの /loop ステータス更新が表示されないことが多い問題を修正しました。クロードは各更新とループ停止時の結果を表示テキストとして書き込むようになりました。
  • Claude デスクトップ アプリが macOS または Linux 上で作成した git ワークツリーから起動すると、/ultrareview が作業ツリーのアップロードに失敗する問題を修正しました
  • 作業ディレクトリが書き込みが拒否され、読み取りが拒否されたディレクトリが含まれている場合、Linux 上でサンドボックス化された Bash コマンドが起動できない問題を修正しました。
  • すべてのビューアがビューアのプライベート data/users/ サブツリーへの書き込みを見ることをクロードに伝えるアーティファクト データベースの書き込み結果を修正し、as_level に「ビュー」レベルを追加しました
  • クロード アプリ ゲートウェイが、ID プロバイダーに多くのグループがリストされているサインインからのすべての要求に対して 431 Request Header Fields Too Large に応答する問題を修正しました。最大 256 KiB のリクエスト ヘッダーを受け入れるようになりました
  • 使用量制限の待機を改善しました。制限の状態と、使用量クレジット オプションを使用したカウントダウンがプロンプトの下に 1 つのブロックとして表示され、制限メッセージでカウントダウンが繰り返されなくなりました。
  • プレフィックスなしで呼び出される Chrome ツールのクロードの「そのようなツールは利用できません」エラーを改善しました。呼び出すツールに名前を付けるようになりました。
  • 説明を繰り返すのではなく、各イベントが出力した内容を表示するようにモニター イベント行を改善し、イベントごとに未変更の「N … が終了するのを待っています」行を繰り返すのを停止しました。
  • 非同期スクリプト フックによってスローされるエラーに対するワークフロー ツールのサンドボックス強化の強化
  • 設定ファイルが実際に使用する設定スキーマの部分のみを構築することで、起動時間とメモリ使用量が改善されました。
  • /claude-api の改善: hillclimb は、eval で測定するには小さすぎるプロンプトの言い換えにラウンドを費やすことがなくなり、report.html の横に要求された追加のページは、ネットワークから何もロードしない 1 つのローカル ファイルとして構築されます。
  • /tasks、/copy、/hooks などのリストの改善: 各名前の後の詳細が、収まる場合は 1 列に整列し、収まらない場合は右端に配置されるようになりました。
  • 別のソースから同じ名前で既に追加されたマーケットプレイスを置き換える場合と、それを元に戻す方法を示す claude plugin marketplace add を改善しました。
  • 管理設定でサインイン (forceLoginMethod または forceLoginOrgUUID) が必要で、API キー、トークン、または apiKeyHelper が構成されている場合の起動の拒否を改善しました。使用中の資格情報、その資格情報が設定されている場所、およびその削除方法を指定するようになりました。
  • 自動メモリ読み込みの改善: クロード コード自身のマークアップを模倣する非表示の文字とタグは、MEMORY.md で無効化され、クロードに到達する前にメモリ ノートが呼び出されます。
  • claude remote-control の改善: まだ trust していないフォルダーでは、終了する代わりに端末上でワークスペース trust を要求するようになりました。
  • アーティファクト ページの改善: クロードは、返信の代わりにページにデザイン プランを書き込み、既に付けた名前をページ タイトルとして使用します。
  • アーティファクト ツールを改善し、クロードに claude.ai チャットまたはプロジェクト リンク、チャットからのアーティファクト、または独自のアーティファクト ID が与えられたときに、停止するのではなく正しいリンクまたはコンテンツを要求するようにしました。
  • すべてのプランとプロバイダーで、許可モードが設定されていない場合に、対話型ターミナルと VS Code セッションが自動モードで開始されるように変更されました。 permissions.defaultMode は依然としてそれをオーバーライドします
  • /effort (タブ、または /effort ultracode [on|off]) で Ultracode を独自のトグルに変更しました。xhigh の努力を強制することはなくなり、どの努力レベルでもオンのままになります。
  • 応答中に接続が切断された後の再試行を変更して、1 つの予算をリクエストの残りの再試行と共有するようにしました。これにより、失敗したリクエストがより早く諦めるようになります。
  • Sonnet モデルのセーフガードがメッセージにフラグを立てたときに表示される通知を変更し、それが発生した理由を説明し、編集と再試行を提供するようにしました。
  • Opus モデルを ANTHROPIC_DEFAULT_OPUS_MODEL または modelOverrides で固定するセッションでの安全関連のモデル スイッチを変更しました。Anthropic API では、API は、固定されたモデルではなく、フラグの種類ごとに切り替えるモデルを選択するようになりました。
  • CLAUDE_CODE_MCP_STARTUP_WAIT_MS が 0 の場合でも、--allowedTools または mcp_tool フックで指定された MCP サーバーの接続に最大 2 秒待機するように、非対話型の最初のターンを変更しました。
  • /recap を decline に変更し、チャット スレッド (独自のものを含む) またはルーチンまたは Webhook から中継されて到着したときに、短い通知を出しました。ターミナル、Claude アプリ、リモート コントロール、-p または SDK ホストに入力すると、以前と同様に実行されます。
  • /artifacts を変更して、/config および /plugin と同じタブ バーを使用して、タイトルの横に 1 単語のラベル (すべて、私の、共有) が付いたフィルター タブを表示します。
  • --add-dir で追加されたマップされたネットワーク ドライブ上にない限り、ネットワーク共有 (\\host\share パスまたは /net 自動マウント) 上のファイルを拒否するようにアーティファクトの公開を変更しました。
  • [VSCode] 各プロンプトと応答の上にオプションの時刻を追加し、日付が変わる日付行を追加しました (クロード コード: [メッセージ タイムスタンプを表示] 設定、デフォルトではオフ)
  • [VSCode] プラグインの読み込みエラーとメモを「プラグインの管理」行に追加し、エラーを無効化、アンインストール、またはコピーするためのポップアップを追加しました。

  • [VSCode] 編集したファイルが保存される前に [メモリからクロードを再ロード] ダイアログが再起動する問題を修正しました。

  • [VSCode] サブエージェントが動作しているとき、またはセクションの最初のステップがビューからトリミングされているときに、展開したフォーカス ビュー セクションが自動的に閉じる問題を修正しました。

  • [Claude Tag] クロードアカウントに接続していない人からの@メンションごとに、最初のサインイン後に沈黙するのではなく、プライベートサインイン通知を投稿するようにクロードを変更しました。
