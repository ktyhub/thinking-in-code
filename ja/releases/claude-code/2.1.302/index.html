claude-code v2.1.302

パッチ 公開日2026年10月16日 出典anthropics/claude-code 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

クロードコード v2.1.302

何が変わったのか

  • client 側の自動モード分類器が使用するモデルを選択するための CLAUDE_CODE_AUTO_MODE_MODEL を追加しました。サーバー側の自動モードのモデルは変更されません。
  • アイドル圧縮をオフまたはオンに戻すための Idle compaction 行を /config に追加しました。アイドル状態の圧縮後に表示される通知に、それをオフにする方法が表示されるようになりました。
  • スタンドアロンの Claude Design (claude.ai/design) が 2026 年 12 月 14 日までに閉鎖されるという通知を /design-sync および /design-login に追加しました。
  • 会話が圧縮されている間にターンを停止するときの「プロンプトが長すぎます」エラーを修正しました
  • セッション中に Vertex または Bedrock に切り替えた後、「診断: 追加の入力は許可されていません」というメッセージが表示されて失敗するリクエストを修正しました
  • 読み取りツールが、任意のサイズの画像ファイル、または画像のような名前のパイプやデバイスを完全にメモリにロードする問題を修正しました。 128 MB を超える画像ソースは拒否されるようになりました
  • ゲートウェイが anthropic/claude-opus-4-1 などの接頭辞を付けて Opus 4 または 4.1 に名前を付けると、/autocompact および /effort が間違ったモデルに保存される問題を修正しました。
  • セッション中に追加されたツールが ToolSearch を通じて、または圧縮後に再度ロードされたときのプロンプト キャッシュ ミスを修正しました
  • claude plugin およびその他のサブコマンドが、キューに入れられた設定または構成の書き込みが完了する前に終了することがあり、変更が失われたり、.tmp ファイルが残される可能性がある問題を修正しました。
  • git がデフォルトで reftable ref 形式になっている場合、更新ごとにプラグイン マーケットプレイスの再クローンが作成され、新しくインストールされた git プラグインがバージョン「不明」と表示される問題を修正しました。
  • PowerShell ツールがプラグインの bin/ フォルダーでコマンドを見つけられず、何も見つからない検索 (rg、grep、findstr、git grep) が Select-Object または別のフォーマット コマンドレットにパイプされたときにエラーを報告する問題を修正しました。
  • デスクトップ アプリのクロードが、オプションが利用できない場合に MCP サーバーを承認または再接続するために claude.ai 設定または /mcp を指示する問題を修正しました
  • クロードが空の編集リストを送信したときにアーティファクトの公開が失敗することがある問題を修正し、アーティファクトの新しいバージョンによって無効になった後、クロードが間違った方法でアーティファクトの更新を再試行しました。
  • ほとんどの自動モード分類子ブロックの OpenTelemetry tool_decision イベントから classifier_category が欠落していた問題と、OTEL_LOGRECORD_ATTRIBUTE_COUNT_LIMIT が低いときに tool_use_id、tool_source、tool_parameters を押し出す新しい tool_decision 属性を修正しました
  • 長いリストを下に移動するか、セクションを折りたたんだ後、エージェント ビューの行が空白のままになる問題を修正しました。
  • claude remote-control --help がその使用法を出力せず、サインインしていないときに終了してしまう問題を修正
  • /design consent と /design revoke が利用できないクラウド セッションで失敗した場合に /design-login を示唆する問題を修正しました。メッセージは claude.ai/design/settings を指すようになりました。
  • サーバーがプロトコル バージョン 2026-07-28 をネゴシエートし、resultType、ttlMs、または cacheScope を省略した場合、MCP サーバーがツールを表示しないか、すべてのツール呼び出しが失敗する問題を修正しました。
  • プランのクレジットのみで支払われるモデルで使用量クレジットを消費するプロンプト提案を修正しました。クレジットへの請求が返信された後はスキップされるようになりました。
  • バッククォートで書かれた URL が折り返されたときに最初の行でのみ clickable になる問題を修正しました。ハイパーリンクをサポートする端末では、URL 全体が 1 つのリンクになりました。
  • プラグインが見つからない場合、組み込みプラグインが表示されない claude plugin details <name>@builtin が claude plugin list を示唆する問題を修正しました。 /plugin を指すようになりました。
  • リンクが 1 列の幅で折り返されて内側から始まる絵文字を修正しました。問題のプレビューで非表示になり、表がリストになってしまいました。
  • 存在しない .git ファイルが存在しないディレクトリを指している場合、git 2.56 以降でワークツリーの作成または再開を拒否するワークツリー分離を修正しました。
  • 新しいプロセスでセッションが再開された後、クラウド セッションのコストと使用量がゼロから再開される問題を修正しました
  • 自己ホスト型ランナー: git の reftable 形式で保存されたチェックアウトを再利用するセッションで、「不正なオブジェクト参照/ヘッド」により失敗する git フェッチを修正しました。
  • Windows: --plugin-dir で開始されたセッションを含む、exFAT または FAT32 ドライブ上のプロジェクトに対して、すべてのファイルの書き込みが拒否されたり、質問されたりする問題を修正しました。
  • 多くのプラグインを有効にして起動時間の改善: プラグイン コマンドとエージェント ファイルの読み込みにかかるファイル システム呼び出しが大幅に減りました (特に Windows 上で)
  • サーバー側分類子による自動モードの改善: 安全性チェックには長すぎる会話が、チェックされたすべてのツール呼び出しが拒否されるのではなく、圧縮されるようになりました。
  • 別のフォルダーからバックグラウンド セッションを再度開いたときに LLM ゲートウェイがない場合のメッセージを改善しました。「ログインしていません」の代わりに理由が表示されるようになりました。
  • 許可なしモードの claude -p およびエージェント SDK セッションが、テレメトリがオフまたは新規インストールされたサードパーティ プロバイダーで default モードで開始されるように変更されました。 --permission-mode auto は自動を維持します
  • フォーク サブエージェント (subagent_type: "fork") は、すでにターミナルにあるため、claude -p、エージェント SDK、デスクトップ アプリ、VS Code でデフォルトでオンになるように変更されました。 CLAUDE_CODE_FORK_SUBAGENT=0 はそれらをオフにし、claude mcp serve はそれらを提供しません
  • クロードに選択させるのではなく、ターミナルと同様にメインの会話のサブエージェントを常にバックグラウンドで実行するようにデスクトップ アプリと VS Code を変更しました。サブエージェント自身のエージェントが claude -p で呼び出し、エージェント SDK、デスクトップ アプリおよび VS Code がデフォルトでフォアグラウンドで実行されるようになりました。
  • ← for agents フッター ヒントが、セッションが開いてから 10 秒後に非表示になるように変更されました。あなたを待っているエージェントの数がまだ表示されています
  • Chrome のクロードの命令がシステム プロンプト内に配置される場所を変更し、新しい会話で共有プロンプト キャッシュから命令を読み取れるようにしました。
  • プロンプトとエージェントのフックを変更し、1 つのイベントを一度に最大 12 個実行できるようにしました。残りは順番を待ちます
  • 組織のポリシーで /feedback がオフになったときに表示されるメッセージを変更しました。組織管理者ではなく GitHub の問題を指すようになりました。
  • [VSCode] 返信ストリーム中にプレーン テキストとして表示され、その後コードに変換される、リスト内の閉じられていないコード ブロックの後のテキストを修正しました。
  • [VSCode] サーバー URL にクエリ文字列が含まれている場合に、パネルから MCP サーバーにサインインすると壊れた認証ページが開く問題を修正しました。
  • [VSCode] Claude 拡張機能を持つブラウザにアクセスできない場合に「ブラウザが接続されました」と表示される @browser バナーを修正しました
  • [クラウドセッション] 組織が同時クラウドセッションの制限に達しているなど、最後の実行が開始されなかった理由を示すバナーをルーチンのページに追加しました。
  • [クラウド セッション] クラウド セッションの最新メッセージを除くすべてのメッセージで「ここまで巻き戻す」が失敗する問題を修正しました。自己ホスト型ランナーにはクロード コード v2.1.246 以降が必要です
  • [クラウド セッション] GitHub が再チェックしている間に、マージ コンフリクトのあるプル リクエストが準備完了状態に戻るクラウド セッションのプル リクエスト ステータス バーを修正しました。
  • [クラウド セッション] クラウド セッションが予期せず停止した後、ルーチンの実行が完了として表示され、開始前にアーカイブされると失敗ではなくキャンセルとして表示される問題を修正しました。
  • [クラウド セッション] セッションの GitHub リポジトリの名前が変更または移動された後、クラウド セッションの差分ビューで変更が欠落しているか、ロードに失敗する問題を修正しました。
  • [クラウドセッション] スケジュールされたルーチンの実行が途中で失敗し、1時間以上後に最初から再度実行すると、同じレポートを2回投稿するなどの作業が繰り返される可能性がある問題を修正しました。
  • [クラウド セッション] ページをリロードするか、cli が移動して元に戻るまで、開いているクラウド セッションで別のデバイスから送信されたメッセージが表示されないことがある問題を修正しました。
  • [クラウド セッション] クラウド セッションの開始に失敗したときに表示されるエラーを改善しました。「問題が発生しました」ではなく「接続が失われました」または「サーバー エラー」と表示されるようになりました。
  • [リモート コントロール] コンピュータがオフラインになった後、リモート コントロール セッションでサブエージェントのペインが永久に回転する問題を修正しました。リモコンが接続されていないと表示されるようになりました
  • [Claude Tag] クロードが以前のメッセージの 1 つを編集して応答した後、Slack チャンネルまたは DM のメンションの下で「考え中…」が表示されたままになる問題を修正
  • [Claude Tag] クロードの Slack 返信の番号付きまたは箇条書きのステップの下のコード ブロック内の URL が山括弧で囲まれており、コピーされたコマンドが壊れていた問題を修正しました。
  • [Claude Tag] Slack に添付された HEIC、SVG、TIFF、BMP 画像がクロードに届かない問題を修正。他のファイルタイプと同様に、作業ファイル内のファイルとして到着するようになりました。
  • [Claude Tag] ロールごとに Claude Tag を制限している組織で、新しいチャネル マネージャーが Slack で Claude にアクセスできなくなる問題を修正しました。マネージャーの役割により、Slack の Claude Tag も付与されるようになりました
  • [Claude Tag] MCP サーバーが 1 つのホストを共有するカスタム コネクタが、Claude Tag 管理設定で単一のコネクタとして表示される問題を修正しました。各サーバーは独自のコネクタになりました
  • [Claude Tag] Slack のクロードがダイレクト メッセージに「DM は一時的に利用できません」と応答し、単一の Slack ルックアップが停止したときにメッセージがドロップされることがある問題を修正しました。最初に再試行されるようになりました
  • [Claude Tag] Slack のワークスペース ドロップダウンを無視する Slack Enterprise Grid 上の Claude とのダイレクト メッセージを修正しました。クロードを最後に開いた接続されたワークスペースで実行されるようになりました。
  • [Claude Tag] チャンネルの月間支出制限に関する Slack の通知で、チャンネルマネージャーが上限を引き上げることができるとクロードが述べていた問題を修正。組織の所有者を指定し、使用状況ページにリンクするようになりました。
  • [Claude Tag] Claude の Slack 返信内のリンクが、その直後の太字または斜体の終了マーク、または全角の句読点を吸収し、リンクと書式が壊れていた問題を修正しました。
  • [Claude Tag] Claude Tag 管理設定のリポジトリ検索が改善され、接続されている GitHub アカウントを最大 100 個カバーし、GitHub アプリ インストールの最初の 5,000 を超えるプライベート リポジトリを検索できるようになりました。
  • [Claude Tag] 組織の完全なチャンネル リストが読み込まれた後ではなく、すぐに入力または貼り付けたチャンネルをリストできるように、Claude Tag 管理設定の追加場所を改善しました。
  • [Claude Tag] Claude Tag 管理設定のワークスペースまたはチャネルのページの [追加] > [ドメイン] を改善し、すべてのチャネルが読み込まれた後だけでなく、ページが読み込まれた後にも利用できるようにしました。
  • [クロード タグ] クロード タグの管理設定を変更し、クロードのアクセスを 4 つのタブ (バンドル、コネクタ、スキルとプラグイン、チャネル) に整理しました。
  • [Claude Tag] 組織設定の [ロール] ページを変更して、Claude Tag チャネル マネージャー用に作成されたロールを、組織独自のロールの下にある折りたたまれたセクションにグループ化するようにしました。
  • [コード レビュー] GitHub への接続を終了した後、コード レビューのセットアップが再開されない問題を修正しました。管理設定に戻ると、リポジトリ ピッカーで再度開きます
