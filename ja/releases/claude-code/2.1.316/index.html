claude-code v2.1.316

パッチ 公開日2026年10月31日 出典anthropics/claude-code 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

クロードコード v2.1.316

何が変わったのか

  • ultrathink キーワードをオフにする CLAUDE_CODE_DISABLE_ULTRATHINK を追加しました
  • プールされたグループ予算をクロード アプリ ゲートウェイに追加しました。グループのメンバーが共有する 1 か月の予算。各メンバー独自の制限に加えて、支出制限管理者 API の pooled_budget で設定されます。
  • プライベート CA が必要とするサーバー向けに、ループ内で相互に認証するシステム相互証明書を保持するための CLAUDE_CODE_DISABLE_LOOPED_CROSS_CERT_DROP を追加しました。
  • セッションの継承ではなく、他に名前がない場合にサブエージェントが実行されるエフォート レベルを設定する CLAUDE_CODE_SUBAGENT_EFFORT を追加しました。
  • クロード アプリ ゲートウェイに managed.policy_mode: layered を追加しました。開発者に一致するすべてのポリシーが適用され、最初のポリシーだけでなく、その下にリストされているポリシーとマージされます。
  • クロード アプリ ゲートウェイ Bedrock アップストリームに guardrail.input_tagging を追加しました。これは、Amazon Bedrock ガードレールのプロンプト攻撃フィルターに必要な入力タグでプロンプトをラップします。 all_messages_and_system はシステム プロンプトにもタグを付けます
  • 2026 年 10 月 30 日以降、Opus 4.8 の高速モードは非推奨になりました。 2026 年 11 月 30 日に削除されます。削除後、Opus 4.8 の高速モード リクエストはエラーを返し、標準の Opus 4.8 にフォールバックしません。高速化を維持するには、Opus 5.5 に移行してください
  • クロード コードが単独で終了する場合、たとえば認証情報が拒否された場合やクラウド セッションがアーカイブされた場合など、macOS および Linux 上でシェル コマンドが実行されたままになる問題を修正しました。
  • 値に改行が含まれる bash エイリアス (Git Bash を除く)、および名前がダッシュで始まる関数が Bash ツールのシェルで文字化けまたは失われる問題を修正しました。
  • SHELLOPTS がエクスポートされると、Bash ツールから開始された bash スクリプトが最初のコマンドの後に停止する問題を修正しました。
  • コマンドが型キャスト、param、using、または属性で始まる場合、終了コード 2 で PowerShell フックがブロックされない問題を修正しました。
  • 圧縮された応答が切断されたり破損したりしたときにハングする一部のネットワーク リクエストを修正しました
  • Vertex AI および Amazon Bedrock の sonnet、opus、haiku で、アカウントまたはリージョンで最新モデルがまだ利用できない場合に古いモデルに切り替えるのではなく、セッション中にエラーが表示される問題を修正しました。
  • クロード アプリ ゲートウェイがすべてのモデルのリクエスト名を availableModels、deniedModels、models に対してチェックしない問題を修正しました。ブロックされたモデルに名前を付けるリクエストは、フィールドに名前を付ける 400 を取得するようになりました。
  • 管理対象設定にクロード アプリ ゲートウェイが必要な場合に実行を拒否する claude auth login を修正しました。ターミナルにゲートウェイのサインインが表示されるようになりました
  • 読み取り許可ルールが対象となっている場合に、作業ディレクトリの外部からファイルをアップロードする --restricted セッションを修正しました。
  • 送信するには 2 回目の Enter キーが必要な、非表示の文字を含むプロンプトを修正しました。単純なプロンプトは最初の Enter でクリーンアップされた状態で送信されるようになり、コマンドは引き続きレビューを待ちます
  • バックグラウンド ジョブまたはメッセージによって起動されたときに、親サブエージェントのモデルを継承したサブエージェントがメイン モデルに移動する問題を修正しました。
  • "$defaults" がホスト アプリの --settings、/permissions で追加された最初のルール、または /auto-mode-setup から組み込み例外を取得しないマネージド autoMode.allow リストを修正しました。
  • サーバーが安全性の判定を返さなかったため、自動モードでターンを停止したときに、クラウド セッションとクラウド スケジュールされたタスクが失敗としてマークされない問題を修正しました
  • バックグラウンド エージェントがまだ実行されているときに自動モードがターンを停止した理由が時々表示されない claude -p テキスト出力を修正しました
  • 実験的ベータがオフになっているプロキシまたは LLM ゲートウェイの背後にあるホスト アプリケーション (Claude Desktop など) によって開始されたセッションで CLAUDE_CODE_AUTO_MODE_SERVER=1 が無視される問題を修正
  • 認証情報名付き環境変数が 1 などのスイッチ値に設定されている場合に、プラグイン MCP headersHelper スクリプトが破損した CLAUDE_PLUGIN_ROOT とサーバー URL を受け取る問題を修正しました。
  • SDK register_repo_root コントロール リクエストが作業ディレクトリ外のディレクトリの CLAUDE.md をロードしない問題を修正しました (CLAUDE_CODE_ADDITIONAL_DIRECTORIES_CLAUDE_MD=1 の場合)
  • アーティファクト ツールが、self レベルでアーティファクト データベース アクセス ルールに対して ? を表示し、それらのルールを削除する再公開を拒否する場合にそれらのルールを引用しない問題を修正しました。
  • モデルがこのバージョンで認識されず、自動圧縮が 200K コンテキスト ウィンドウを想定する場合に警告が表示されない /model <id> を修正しました
  • 「スペースを押して話す」ヒントが 1 つのセッションで 3 つの表示を使い果たし、プッシュ トゥ トークがバインドされていないときに空のキーが表示される問題を修正しました。
  • Windows で発生する、検索プロセスがタイムアウトで強制終了されても終了しない場合、Grep と Glob が戻らない問題を修正しました。
  • 会話の一部がまだ保存されている間に /clear または /resume が実行された場合、会話を再開しても計画が復元されないまれなケースを修正しました
  • 狭い端末でのセキュリティノートと端末セットアップの説明から単語が削除される初回実行セットアップを修正しました
  • エンタープライズ調査カードが短い一時停止の後に入力された 1 または 0 を取得する問題を修正しました。入力した回答には Enter が必要になります
  • 自己ホスト型ランナー: クロードの作業中に送信されたメッセージが、セッションのプロセスが置き換えられると、停止後に応答される問題を修正しました。
  • セルフホスト ランナー: セッションが新しいマシンに移動すると、MCP サーバーのオン/オフ スイッチが失われることがある問題を修正しました。
  • Windows: rc ファイルで errexit と Pipefail が設定され、winpty エイリアスのみが定義されているか、何も定義されていない場合に、Git Bash でエイリアスと関数が失われる Bash ツールを修正しました。
  • Claude Desktop または Web の [コード] タブから開始される /code-review の改善: クラウドおよび claude remote-control セッションでは、プレーンテキストのリストではなく、結果カードが表示されるようになりました。
  • 大規模なリポジトリでの /diff の改善: 通常、各更新で実行されるフルリポジトリの git コマンドは 1 つ減り、git が遅い場合には更新の間隔があけられます。
  • /ultrareview、クラウド セッション、またはクラウド エージェントが GitHub リモートを見つけなかったときに表示されるメッセージを改善しました。https://github.com/new, でリポジトリを作成するように指示され、/ultrareview は gh が拒否する gh コマンドを提案しなくなりました。
  • SSL 証明書エラーを改善し、中間証明書を省略したサーバーなど考えられる原因を列挙し、それぞれの修正を加えました。
  • 自動モードを変更し、"$defaults" のない autoMode.allow リストによってスケジュールされたタスク プロンプトの組み込みルールが削除されないようになりました。
  • チームおよびエンタープライズ ログインのサーバー管理設定が変更されました。Anthropic の API から取得した設定は、承認プロンプトなしで適用されるようになり、検証されない保存されたコピーは拒否されます。
  • [VSCode] チャット パネルからクロード アプリ ゲートウェイへのサインインを追加しました。ターミナルは必要ありません。
  • [VSCode] ultrathink が xhigh の努力でターンを実行し、ターミナルと同様にチャット ボックスに虹で表示されるように変更しました。
  • [VSCode] モデル設定に opus[1m] などの [1m] タグがある場合に欠落していたエフォート スライダー、Ultracode スイッチ、モデル名を修正しました。
  • [VSCode] 設定ファイルにエラーがあるときに保存された /btw サイド質問履歴が早期に削除される問題を修正しました
  • [VSCode] 計画が「はい、編集を手動で承認する」で承認された場合、リロードまたは再起動後に会話が自動モードに戻る問題を修正しました。
  • [クラウド セッション] クラウド セッションにフォーム カードを追加したため、MCP サーバーが要求するフォームが表示されずにキャンセルされる代わりに、フォームに記入したり、フォームを削除したりできるようになりました。
  • [クラウド セッション] 切り替え後のクラウドまたはリモート コントロール セッションがメッセージを最新の状態にしている間に表示される「追いついています…」行を追加しました。
  • [クラウド セッション] ネットワーク シークレットを変更し、Enterprise メンバーがネットワーク シークレットを表示するだけでなく、自分のクラウド環境で追加および削除できるようにしました。
  • [クラウド セッション] クラウド セッションの [変更] ペインを改善しました。リストで省略されたものに関するメモは、差分の上の行ではなく、ブランチ名の横にバッジで表示されるようになりました。
  • [クラウド セッション] クロードがディレクトリを変更した後、クラウド セッションの [ファイル] ペインでフォルダーが ../.. パスとして表示されるファイル検索を修正しました。結果にはプロジェクトのルートからのパスが表示されるようになりました
  • [Claude Tag] キャンバスが別のチャンネルまたは DM にも共有されると、Slack チャンネルで作成したキャンバスをそのチャンネルから編集したり追加したりすることをクロードが拒否する問題を修正しました。
  • [Claude Tag] 両方の組織が Claude をインストールし、Slack が他の組織のアプリに返信を配信した場合、Slack Connect スレッドでタグなしの返信が未回答になる問題を修正しました。
  • [Claude Tag] Slack のクラウドスケジュールタスクのライブステータスチェックリストが中途半端なままになる問題を修正。実行中に投稿されたトップレベルのメッセージを編集できるようになりました
  • [Claude Tag] Slack チャンネルの応答が、チャンネルの設定ページおよびクロード タグの管理設定で「クロードの参加方法」の選択肢に自動的に切り替わるように変更されました。
  • [コード レビュー] コード レビュー分析ページに重大度別の検出結果カードを追加しました。これには、期間の合計検出結果、重大度ごとに積み上げられた日次グラフ、および各重大度の数が表示されます。
