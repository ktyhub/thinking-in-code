claude-code v2.1.314

パッチ 公開日2026年10月30日 出典anthropics/claude-code 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

クロードコード v2.1.314

何が変わったのか

  • permissions.blockWritesOutsideWorkingDirectories を追加: すべてのアクセス許可モードで、書き込み、編集、および NotebookEdit が作業ディレクトリ外のパスを拒否する
  • オプションの groups リストをクロード アプリ ゲートウェイのアップストリームに追加しました。リストされた IdP グループの開発者のみが、フェールオーバー時にもそのアップストリームに送信されます。
  • guardrail_trace をクロード アプリ ゲートウェイ Bedrock アップストリームに追加し、リクエストでどの Amazon Bedrock ガードレール フィルターが起動されたかを、一致するテキストなしでログに記録します。
  • VS Code と Claude Desktop の [コード] タブにアイドル圧縮を追加しました。アイドル状態のままの 200,000 以上のトークンの会話が要約され、プロンプト キャッシュの有効期限が切れた場合、その要約が次のメッセージで使用されます。
  • 組織の管理者がモデルの工数に上限を設定すると、「無効な工数レベル」でセッションがターンごとに失敗する問題を修正しました。Claude Code は工数を下げて再試行し、使用するレベルを通知するようになりました。
  • 起動に失敗したときにコード 0 で終了し、何も出力されない claude -p を修正しました。エラーを出力して終了します 1
  • 多くの画像が毎ターン失敗する Bedrock セッションと、「400 入力が長すぎます」という /compact を修正しました。古いイメージを削除して圧縮する代わりに
  • リソースにデフォルトの Sonnet、Opus、または Haiku モデルのデプロイメントがない場合に失敗する Microsoft Foundry セッションを修正しました。Claude Code は、そのファミリーの古いモデルにフォールバックするようになりました。
  • ツール検索の tool_reference ブロックを受け入れないゲートウェイの背後で繰り返し拒否されたリクエストを修正しました。リクエストはツール検索なしで 1 回再送信され、セッションが記憶します。
  • システム証明書ストアが、以前の証明書と相互署名された更新されたルート証明書を保持している場合に、TLS 接続が UNABLE_TO_GET_ISSUER_CERT で失敗する問題を修正しました。
  • 保存されたサインインが機能しなくなった後、サインインなしでも動作する MCP サーバーに「認証が必要」と表示される問題を修正しました。現在はサインアウトして使用されています
  • MCP サインインが削除されなかった場合 (たとえば、macOS キーチェーンが SSH 経由でロックされている場合) に成功を報告する claude mcp logout を修正しました。
  • 複数のセッションが Anthropic プロファイル ログインを共有し、資格情報ロックがビジー状態である場合の追加のサインイン更新を修正しました
  • ターミナルのある CI ジョブでワークスペース trust の質問をする claude ultrareview および claude remote-control を修正しました。 CI を設定すると、untrust フォルダーを一度に拒否するようになりました。
  • 管理対象設定における管理者の TLS trust 設定がクロード デスクトップ セッションに適用されない問題を修正しました。
  • 独自の --plugin-dir または --plugin-url プラグインのいずれかにマニフェストが壊れているか、ダウンロードに失敗した場合に、管理されたプラグイン設定を持つマシンでモデルの切り替えが拒否される問題を修正しました。
  • 管理設定がモデルを固定している場合、Bedrock および Vertex モデルのアップグレードオファーが開始するたびに戻ってくる問題を修正しました
  • 保存されたコピーの有効期限が切れると、リモート管理設定のみで設定された forceRemoteSettingsRefresh が適用されなくなる問題を修正しました。これにより、サーバーに接続できないときにポリシーなしでセッションが開始できるようになります。
  • タスクが待機 (/goal チェックイン、バックグラウンドまたはスケジュールされたタスク) の間に自動的に再起動されたときに、プロンプトが表示されずに「使用制限で自動的に続行」が 3 回以上継続する問題を修正しました。
  • Ultracode によって開始されたバックグラウンドおよびクラウド セッションがオフになった後、次回の開始時に再びオンになる問題を修正しました
  • クロードが解析できなかったツール呼び出しを諦めた後、最後の壊れた返信とその再試行プロンプトが会話に残る問題を修正しました。
  • 非常に大きな出力を伴う PreCompact フックが圧縮を失敗または繰り返してしまう問題を修正しました。各フックの出力は 10,000 文字でカットされるようになりました。
  • リポジトリのインデックス ロックを短時間取得するバックグラウンドの差分更新を修正しました。これにより、同時に実行された git コマンドが「'.git/index.lock' を作成できません: ファイルが存在します」というエラーで失敗する可能性がありました。
  • ストリーミング中にマークダウン テーブルが半分型付けされた行のグリッド レイアウトとスタック レイアウトの間でジャンプし、長いテーブルが生のパイプにフォールバックする問題を修正しました。
  • セッションでスラッシュ コマンドのみが実行された場合に、セッションのタイトルとして CLAUDE.md または CLAUDE.local.md のテキストを表示する /resume ピッカーを修正しました。
  • サブエージェントの公開トランスクリプトから質問されたとき、メインの会話から応答する /btw を修正しました
  • SSH を介して Linux マシンにイメージを貼り付けると、サイレントに何も実行されない問題を修正しました。ファイルをコピーしてそのパスを貼り付けるようにプロンプトが表示されます
  • セッション サービスが一時的に遅い場合に開始に失敗する claude remote-control セッションを修正しました。ワーカーの登録は待機が増加して再試行されるようになりました。
  • リモート コントロールを切り替えるモデルが 8 秒以上かかり、最終結果ではなく「まだ保留中」エラーが発生する問題を修正
  • リストされたコマンドは常にサンドボックスの外で実行されるという sandbox.excludedCommands 設定の説明を修正しました。呼び出し内のすべてのコマンドはエントリと一致する必要があると表示されるようになりました
  • 自動モード、拒否ルール、PreToolUse フックがブロックされた、またはその他の方法で実行されなかったシェルおよび MCP 呼び出しが、折りたたまれたツール グループで実行されたかのように読み取られる問題を修正しました。
  • claude -p --resume または --continue によって入力されたワークツリーにサンドボックス保護が適用されない問題を修正
  • 監視ツールによって開始されたシェル コマンドで実行されない Bash に一致するフックを修正しました。このようなフックはブロックしたり質問したりすることはできますが、それらのコマンドを承認したり書き換えたりすることはできません
  • --setting-sources で除外された設定ファイルを修正しましたが、自動モード ルールや保存されたアクセス許可などの一部の設定が提供されていました。
  • 安全性チェックで判定が得られなかった場合に、自動モードで通話がブロックされていると報告され、/permissions にリストされる問題を修正しました。
  • Google トークン エンドポイントが接続を受け入れても応答しない場合に、Claude アプリ ゲートウェイ Vertex アップストリームが数分間ハングする問題を修正しました。
  • 非推奨の Claude Desktop キーに対する Claude アプリ ゲートウェイの起動警告が修正され、キーの終了日以降も「受け入れを停止する」と書かれたままの状態で機能します。
  • /upgrade がブラウザを開いて App Store または Google Play 経由で請求されたプランの新しいログインを開始する問題を修正しました。計画を変更する場所が表示されるようになりました
  • --resume を修正し、拒否後に別のモデルへの切り替えを過ぎて巻き戻し、クロード コードが認識しないモデル名のセッションを別のモデルに移動する
  • ゲートウェイまたはクラウド プロバイダーがクロード コードのベータ ヘッダーの 1 つを名前で拒否した場合に失敗するリクエストを修正しました。リクエストはヘッダーなしで再送信されます。
  • claude-opus-4.8 など、LLM ゲートウェイの後ろにドットで綴られたモデル ID が、間違ったコンテキスト ウィンドウ、出力制限、労力、思考モード、コストを持つ古いモデルとして扱われる問題を修正しました。
  • リモート コントロール clients で、/compact の後に「圧縮済み (完全な概要を表示するには ctrl+o)」行が表示される問題を修正しました。
  • 組織のポリシーによってこれらの機能がオフになったときに表示されるクラウド セッションのヒントとリモート コントロールのアイドル通知を修正しました
  • 新しいチャットのファイルを受信した直後に前のワーカーが停止したときに、再開された claude.ai クラウド セッションで誰も要求されていないモデル呼び出しが行われる問題を修正しました
  • Cowork クラウド セッションの WebFetch が、PDF のテキストが 100,000 文字を超えるとサイレントに削除される問題を修正しました。未読の量とどこから読むかが表示されるようになりました
  • クラウド セッションまたは IDE で Esc または Stop を使用してコマンドを停止した後、コマンドが declined されたことだけがクロードに通知される問題を修正しました。コマンドが実行された可能性があることも認識されるようになりました
  • コード ブロックが引用を開いたときにコード ブロックの先頭にある空白行が消える問題を修正しました。

  • 別のエージェントが開始または終了したときに、エージェント パネルの x と Enter が間違ったエージェントで動作することがある問題を修正しました。
  • 「その他」行にフォーカスがない限り、クロードの質問ダイアログで貼り付けたテキストとドラッグインしたファイルが失われる問題を修正
  • プロンプトフッターの行が選択されたときに貼り付けられたテキストが失われる問題を修正
  • ヤンクされたテキストが行全体であるかどうかを無視する、文字選択に対する vim モード p を修正しました。
  • Vim モード aw および iw が行末で改行を行う問題を修正しました
  • ? で隠れているフッター項目を選択する ↓ を修正しました。ヘルプ メニュー、コマンド リスト、または貼り付けヒント
  • /btw などのコマンドのパネルで Esc を押すと、トランスクリプトが開いているサブエージェントも中断される問題を修正しました。

  • 上にスクロールしたときに巻き戻しメニューの「会話を復元」した後、会話の途中で全画面のトランスクリプトが残される問題を修正
  • 削除されたセッションがほぼ空のエントリとして再開リストに再表示されるまれなケースを修正しました

  • 最初のプロンプトが失敗し（使用量制限などで）、その後会話が継続した場合にセッションが無題のままになる問題を修正
  • ~/.claude/skills/.trash に保持されているすべての削除されたスキルをチェックするスキル ファイル ウォッチャーを修正しました。これにより、削除するたびに増大するファイル システムの負荷が増加しました。
