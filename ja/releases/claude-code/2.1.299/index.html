claude-code v2.1.299

パッチ 公開日2026年10月14日 出典anthropics/claude-code 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

クロードコード v2.1.299

何が変わったのか

  • CLAUDE_CODE_DISABLE_FILE_MENTIONS 環境変数の追加: クロードは、ファイルの内容ではなく、ファイル ツールで読み取る @ ファイルの言及のパスを取得します。
  • ターミナルにアイドル圧縮を追加しました。約 54 分間アイドル状態のまま放置された 200,000 以上のトークンの会話は、1 時間のプロンプト キャッシュが期限切れになる前に圧縮されるため、次のメッセージはすべてを再処理しません。
  • アイドル圧縮の最小 200K トークンを変更するために CLAUDE_CODE_IDLE_COMPACT_MIN_TOKENS を追加しました。設定の"idleCompaction": false。jsonでオフになります。どちらも v2.1.290 以降が必要です
  • $.prompt.media を追加しました。これにより、管理設定によってインストールされた MOD の prompt.submit フックが、プロンプトに添付された画像またはドキュメントのバイトを読み取ることができます。
  • 管理対象設定によってインストールされた MOD 用に $.session.identity() を追加しました: セッションのサインイン方法、および管理対象 forceLoginOrgUUID がその組織をリストする場合のその組織と電子メール
  • size、weight、mono、tabular を MOD の Text に追加し、名前付き間隔ステップ (xs から xl) を Box に追加しました。 bold は非推奨になり、weight が優先されます
  • --shutdown-drain-sec を claude self-hosted-runner orchestrator に追加: SIGTERM ではポーリングを停止し、ポーリングを実行中に実行し、終了するまでの秒数までスポーン フックを実行します。
  • MODのskill.promptフックが受け取るものに、スキルのフロントマター、ソース、プラグイン名、ファイルパスを追加しました。
  • 新しいセッションを開始する内容を設定するために、エージェント ビューに /effort および /fast を追加しました。ベア /model、/effort、または /fast ではピッカーが開きます
  • --safe-mode で開始されたバックグラウンド セッションのエージェント ビュー ピーク パネルに「セーフ モード」行を追加しました
  • バイパス権限が利用可能なため、プラン モードでほとんどの編集またはコマンドの前に質問されない場合の 1 回限りのメモを追加しました
  • エージェントなどの特定の組み込みツールを評価実行から除外するために、--disallow-tools および disallowed_tools ケース フィールドを claude plugin eval に追加しました。
  • Claude デスクトップの [コード] タブでアトリビューション ブロックをオフにするためのサポートを追加しました。Claude アプリ ゲートウェイの code ポリシーの env に CLAUDE_CODE_ATTRIBUTION_HEADER=0 を設定します。
  • クロード アプリ ゲートウェイの背後にあるクロード コード セッションのアトリビューション ブロックにフィールドを追加しました。 CLAUDE_CODE_ATTRIBUTION_HEADER=0でブロックを取り除く
  • session.append MOD フックに queue ドアを追加しました。これにより、MOD はトランスクリプトのキュー レコードを、送信されたプロンプトと異なるものにすることができます
  • 組織がクロード コードを管理する場合にスキップされる MOD のフックの名前を /plugin および claude plugin validate に追加しました。
  • 最大の労力、ワークフロー、常時オンのコンテキスト、および大規模なツールの結果に対する /usage 警告を追加しました
  • apiKeyHelper のキーが使用されているときに間違った組織を指す可能性がある、拒否されたクラウド セッションのエラーを修正しました
  • カスタム ANTHROPIC_BASE_URL の背後にあるゲートウェイ固有のモデル名のセッションが、リクエストを送信する代わりに 200K トークン近くで「プロンプトが長すぎます。自動圧縮に失敗しました」で終わる問題を修正しました。
  • --max-turns、--max-budget-usd、割り込み、またはホストの会話の終了を通過するヘッドレス実行を維持する毎ターンの終わりにプロンプトを送信する MOD を修正しました
  • クラウド セッションで、ツール グループの 1 行ラベルの後にモデルのフォローアップ テキストが表示されることがある問題を修正しました。
  • 設定ディレクトリのパスに .claude が含まれていない場合、編集受け入れモードで質問せずにセッションの mods フォルダーに mod を作成する書き込みツールと編集ツールを修正しました。
  • インストールされた MOD がリモートでオフになった後も開いたセッションで実行され続ける問題を修正しました。彼らはターンの間にアンロードするようになりました
  • UserPromptSubmit または mod prompt.submit フックがまだ実行中に停止したメッセージで失敗する Cowork および claude.ai クラウド セッションの編集と再試行を修正しました (2.1.296 のリグレッション)
  • エージェントのチームメイトが説明なしで開始すると、プロンプトに表示されるタスクの説明に資格情報の一部が残る問題を修正しました
  • 遅い接続で大量のイベントのアップロードを完了できなかった場合にリモート コントロールまたはクラウド セッションがフリーズする claude.ai ビューを修正しました
  • サンドボックス化されたシェル コマンドが --plugin-dir フォルダーに書き込むことができ、そのコード Claude Code がサンドボックスの外でリロードされて実行される問題を修正しました。

  • フルスクリーンで上にスクロールしているときに質問された場合、/btw がトランスクリプトを一番下にジャンプする問題を修正しました
  • サンドボックスが Windows ドライブに書き込むことができる場合、bwrap: Can't mkdir /mnt/c/Program Files/ClaudeCode を使用する WSL2 でサンドボックス コマンドが失敗する問題を修正しました。
  • エージェント SDK、IDE、および claude remote-control セッションでバックグラウンド タスクが実行されている間、スケジュールされたウェイクアップ (ScheduleWakeup) が起動しない問題を修正しました。
  • 貼り付けられた画像または読み取れない画像を含む一部のプロンプトに対して、MOD の prompt.submit 書き換えがサイレントに削除され、入力されたとおりにプロンプトが送信される問題を修正しました。
  • 同じバッチ内のキューに入れられた別のプロンプトが配信に失敗したときにリモート コントロール プロンプトが失われる問題を修正しました

  • サンドボックス コマンドによって config ディレクトリに空の .config.json が残った後、Linux 上でサインイン、MCP サーバー、プロジェクト trust が失われたように見える問題を修正
  • プロジェクト フォルダーが書き込み可能でないために設定を保存できなかった場合に、/sandbox が成功を報告する問題を修正しました。今は何も変わっていないと言われます、そしてその理由は
  • ホストが自動モードをサポートしないモデルに切り替えた後、SDK およびヘッドレス セッションが自動モードのままになる問題を修正
