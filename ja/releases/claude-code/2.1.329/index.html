クロードコード v2.1.329

何が変わったのか

  • フォルダーのフックが宣言されている場所を示す trust ダイアログ警告を追加しました
  • クロード デスクトップおよびその他の非対話型ホストで、管理設定のフックの読み込みに失敗した場合の会話に警告を追加しました。
  • このセッションのスケジュールされたタスク、/loop ウェイクアップ、目標、およびこの会話のフォークを /tasks に追加しました。 xは尋ねた後に1つ停止します
  • 接続を拒否したリモート HTTP MCP サーバーの JSON-RPC エラー メッセージを示す「サーバー メッセージ」行を /mcp のサーバー ページに追加しました。
  • 自動更新を取得しないマネージド マーケットプレイスの名前とその理由を示す「マーケットプレイスの自動更新」行を /status に追加しました。
  • OpenTelemetry イベントとメトリクスが有効なときにコード モードをオンにするためのサポートが追加されました。コードが行う各ツール呼び出しは、そのイベントを送信します。トレースしてもまだオフのままです
  • ネットワーク停止またはファイルロックにより読み取り不能になり、保存中にクリアされると、~/.claude.json がデフォルトにリセットされることがある問題を修正しました
  • クロード コードがキーチェーンを読み取ることはできても、キーチェーンに保存できない場合に、macOS でサインアウトが繰り返される問題を修正しました。そのセッションは期限切れで停止し、その理由が表示され、他のセッションはサインインしたままになります。
  • /terminal-setup が VS Code 設定またはブロック コメントの周りのキーバインド ファイルを破損し、keybindings.json に閉じられていない文字列がある場合に Shift+Enter バインディングが失われながら成功を報告する問題を修正しました。
  • IDE の差分を介して受け入れられたファイルが最後の改行なしで保存され、VS Code で差分を保存することによって編集が受け入れられたときにバイト オーダー マーク (BOM) が失われる問題を修正しました。
  • 開いている会話を置き換える /teleport でクラウド セッションを選択する問題を修正しました。/clear と同様に、選択すると新しいセッションが開始され、/resume は古いセッションを戻します。
  • ブラウザを開いた後に Pro および Max ユーザーに再度ログインを求める /usage-credits を修正し、ブラウザが開かず使用量クレジットのためにタスクが停止すると 8 秒後にリンクが消える
  • /usage が、使用量クレジットがなくなったとき、または月間制限に達したときに使用量クレジットがオフであると表示し、/model がその制限によって使用量クレジットで実行されるモデルがブロックされているときに Pro および Max ユーザーに通知しない問題を修正しました。
  • 支出を月間制限として表示し、狭いウィンドウでその行をポインターの下で折り返す支出制限メニューを修正しました
  • プロンプトをフリーズさせずに印刷し、ギガバイトのメモリを使用するステータス ライン スクリプトを修正しました。
  • --resume ピッカー、trust ダイアログ、または別のセットアップ画面が待機している間に管理設定を承認した後、空のフリーズした画面を修正しました
  • /model でデフォルトを選択すると、デフォルト行に保存済みモデルがすでに表示されている場合に、保存済みモデルを組織のデフォルトに置き換える問題を修正しました。
  • トークン更新の実行中に認証をクリアした後、MCP サーバーが再度サインインする問題を修正しました
  • 遅い再接続後に停止するバックグラウンド MCP タスクを修正しました。古いプロトコル バージョンのままになっている場合、クロード コードはほとんどの HTTP MCP サーバーを自動的に再接続するようになりました。
  • MCP サーバーまたは Web サイトが application/octet-stream として送信する PDF、画像、および .docx、.xlsx、または .pptx ファイルが .bin として保存される問題を修正しました。これにより、Claude が PDF と画像を読み取れなくなりました。
  • /code-review <pr number> が、何も言わずにプル リクエストの代わりにチェックアウトされたブランチをレビューすることがある問題を修正しました。今では、gh pr diff でプル リクエストを読み取るか、それができない場合に通知するようになりました。
  • ほとんどのモデルで、存在しない ~/.claude/CLAUDE.md を探すために /code-review が許可プロンプトで停止する問題を修正しました
  • セルフホストランナー: --push-outcome-on-release が git ホスト上のセッションのブランチを削除することがある問題を修正しました。
  • コードモードでスクリプトの完了した編集と Esc 後に停止したコマンドが非表示になり、終了時にそれらが失われる問題を修正しました。
  • コードモードでマシンのメモリを埋める暴走ループを修正しました。今は限界で止まっています
  • 再開中に停止した場合にバックグラウンド エージェントが実行されていた問題を修正しました
  • 終了するまで以前の会話にメモリを使用するバックグラウンド シェル コマンドを修正しました
  • クロード デスクトップ、IDE、または SDK によって実行されるセッションで、圧縮または /clear 後の以前の会話にメモリを使用するリモート コントロールを修正しました。
  • ハングした AWS credential_process またはサインイン呼び出しを待機している間、Bedrock 上のクロード デスクトップ セッションでリクエストが終了しない問題を修正しました

  • コード モードを変更し、コード モード外のようにエラーを発生させる PreToolUse フックがスクリプトのツール呼び出しを拒否しないようになりました。拒否する必要があるコマンド、HTTP、または MCP ツール フックに "onFailure": "block" を設定します。
  • ギガバイトのメモリを使用する可能性がある 256 MiB を超える行範囲のスクリプトの読み取りを拒否するようにコード モードを変更し、非常に長い行の読み取りのタイムアウトを修正しました
  • テレメトリ、不要なトラフィック、または機能フラグがオフになっている場合にもコード モードが開始されるように変更しました。管理者は管理設定でこれをオフにしておくことができます
  • コード モードを変更して、以前は拒否していた独自の log、preview、または sleep を宣言するスクリプトを実行するようにしました。
  • Claude Code-write-check アイテムでキーチェーンをテストするように macOS ログインの更新を変更しました
  • /tasks ヘッダーとフッターのバックグラウンド カウントを、シェル、モニター、MCP コール、エージェント、ワークフロー、スケジュールされたタスクをカバーする 1 つの数値に変更しました。
  • background_tasks でモニターのスクリプトを shell ではなく monitor としてリストするように Stop フックと SubagentStop フックを変更しました。
  • max_tokens エラーで指定された制限での 2.1.326 の自動再試行を削除しました。出力トークンの使用量が少ないモデルのゲートウェイの背後では、CLAUDE_CODE_MAX_OUTPUT_TOKENS をその制限に設定します
  • [VSCode] trust プロンプトを cline した後にメッセージ ボックスの上に行を追加し、ウィンドウを再ロードせずにプロンプトを戻すために trust を確認する
  • [VSCode] サインイン サーバーが拡張機能のトークン更新に応答するまでに 10 ～ 30 秒かかった場合、すべてのウィンドウとターミナルで Claude Code からサインアウトされる問題を修正しました。
  • [VSCode] 入力メソッド (IME) がアクセス許可プロンプトへのフォーカスの移動または decli を作成し、メニュー行を実行し、ダイアログを閉じるときに押されるキーを修正しました (anthropics/claude-code#106358)
  • [VSCode] Bash、Edit、Write、およびその他の組み込みツールの権限プロンプトで、安全性チェックで尋ねる理由が表示されない問題を修正しました。
  • [VSCode] 書きかけの計画コメントが失われたり別のパッセージに移動されたり、入力メソッドの Enter でコメントを送信したり、セッション名の変更を終了したり、@ で言及されたファイルを選択したりする問題を修正しました。
  • [VSCode] 使用クレジットが使用中であることを示さない制限バナーと、そのバナーと使用クレジット カードをカバーするセッション アンケートを修正しました。
  • [VSCode] [アカウントと使用状況] ダイアログが開いている間に届いたアクセス許可リクエストを、ダイアログが閉じるまでスクリーン リーダーがアナウンスしない問題を修正しました。
  • [VSCode] ターミナルのクロード コード セッションが切断された後、提案された編集の差分タブが開いたままになり、承認ボタンが何も行われない問題を修正しました。
  • [VSCode] 短いツールの入力と出力がパネルの端で切り取られ、残りを読む方法がなく (エディター タブで開くようになりました)、ドラッグしてテキストを選択すると 1 つも開く問題を修正しました。
  • [VSCode] 入力メソッド (IME) がメッセージ ボックスで作成しているテキストの上に以前のメッセージを配置する Up キーを修正しました (anthropics/claude-code#101294)
  • [VSCode] エクスプローラー フォルダーをチャットにドロップすると、VS Code 1.103 ～ 1.139 またはフローティング チャット ウィンドウに何も挿入されず、ドロップ ハイライトが誤った「Shift キーを押したまま」のヒントとともに消える問題を修正しました。
  • [VSCode] ボタンがオンになったときに、スクロールしている詳細からキーボードのフォーカスが移動する許可プロンプトを修正しました
  • [VSCode] claudeCode.lockEditorGroups がオフのときに別のエディター グループで開くクロード タブのファイル リンクを修正しました (anthropics/claude-code#108884)
  • [VSCode] 単一のチルダ (3~5 … 7~10) で書かれた範囲でチルダが失われ、それらの間に取り消し線のテキストが表示される問題を修正しました。現在は ~~text~~ のみ取り消し線が引かれています
  • [VSCode] 狭い列に折り返されるディクテーション エラー、質問カードの待機中にスピナーが回転する問題、および失敗した UTF-16 コマンドの出力の各文字の後に NUL 記号が表示される問題を修正しました。
  • [VSCode] 許可プロンプトの最後の項目で停止するように Down を Yes にラップするのではなく変更しました。
  • [VSCode] 隠し文字と無地以外の制御シーケンスを記号として表示するようにコマンド出力を変更したため、ペルシア語、クメール語、ラオス語、シンハラ語、マラヤーラム語のテキストが壊れたり、順序が狂って見える可能性があります。
