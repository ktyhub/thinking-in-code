claude-code v2.1.321

パッチ 公開日2026年11月9日 出典anthropics/claude-code 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

クロードコード v2.1.321

何が変わったのか

  • Claude Fable 5.2 (claude-fable-5-2) を追加しました。デフォルトの Fable モデルになりました - 1M コンテキスト、$0.20/Mtok キャッシュ読み取りで Mtok あたり $8/$40
  • --settings <file> を claude remote-control に追加しました。これにより、開始されるすべてのセッションに設定ファイルが適用されます。ファイルが変更された場合、claude remote-control を再起動するまで新しいセッションは開始されません
  • サーバーがリダイレクトしたときに、リフレッシュ トークンなどのシークレットを別のホストに送信する MCP OAuth リクエストを修正しました
  • 読み取り専用の Bash コマンドが許可プロンプトなしでサンドボックスの外で実行されるケースを修正しました
  • Bash 権限チェックで間違ったフォルダーからのファイル書き込みと判断され、プロンプトが表示されないケースを修正しました。
  • cp または mv がディレクトリに書き込むファイルに拒否ルールと保護ファイル プロンプトが適用されない問題を修正
  • プランに Fable が含まれている Enterprise シートで Fable に切り替えた後に表示される「使用量クレジットからの引き出し」という注記を修正しました
  • 応答する前に最初のモデルがブロックされたときに、フォールバック モデルが時々リクエストを decli したり、応答の停止に言及したりする問題を修正しました
  • クロード コードが登録されているサーバーに再度サインインするたびに、claude mcp login が SEP-2352 発行者警告を出力する問題を修正しました。
  • ネットワーク パス (UNC 共有、WSL フォルダー、/net マウント) 上で呼び出しがセル名を指定しない場合に、ノートブックの最初のセルを削除または上書きする NotebookEdit を修正しました。
  • ネットワーク パス (UNC 共有、WSL フォルダー、/net マウント) 上で、いくつかの一致の最初の変更、空の old_string 上のファイル全体の置換、またはノートブックをテキストとして編集する編集を修正しました。
  • 新しいセッションが自動モードで開始されると、デフォルトの許可モードとして手動が表示される /config を修正しました。 「自動 (デフォルト)」でスペースを押すと、計画ではなく質問しないで保存されるようになりました
  • Windows: セッションの作業ディレクトリに小文字のドライブ文字が含まれている場合、最初のシェル コマンドの後に watchPaths を介して設定されたパスに対して FileChanged フックが停止する問題を修正しました。
  • クロード コードの組み込みプラグイン用に生成されたタイプ ファイルを builtin フォルダーに書き込む --plugin-dir . および --plugin-dir ./builtin を修正しました。
  • 正確なトークン数が利用できない場合に、コンテキスト使用量の推定値がツール定義を過大にカウントする問題を修正しました。
  • Web およびモバイルのリモコンで /compact が 2 回表示される問題を修正
  • リポジトリのワークツリーまたはフォルダーごとにプラグインを再度ダウンロードするプラグインの自動更新と /plugin マーケットプレイスの更新を修正しました
  • クロードが応答する前に会話が圧縮されたときに、ターンを開始していたバックグラウンド サブエージェントのレポートが失われる自動モードを修正しました
  • プロジェクトのスキル、コマンド、エージェントが、ワークツリーに入った後など、git stash などのフォルダーが削除され、セッション中に戻った後も消失したままになる問題を修正しました。
  • claude -p がバックグラウンド コマンドが 10 分後に停止されると 30 分かかるとクロードに伝えることがある問題を修正しました。
  • セッション自体の親プロセスと一致するクラウド セッションの pkill、pgrep、pidwait を修正しました
  • Chrome のクロードとコンピュータが接続を停止させるプロキシの背後で親が終了した後もサーバー プロセスが生き続ける問題を修正しました
  • 同じツール呼び出しからの別のフックの出力を保持するファイルをクロードに指す大きなフック出力を修正しました
  • クロード コードを埋め込むアプリが、両方のフックを要求されたときに、別のフックではなく独自の PreToolUse フックの ask 理由を取得する問題を修正しました。
  • 別のフックの defer が最初に終了し、尊重されなかったときに PreToolUse フックの ask が失われる問題を修正しました
  • 許可プロンプトとバックグラウンド タスクでまれに発生するクラッシュを修正しました
  • クロードがワークツリーに入った後、SDK およびデスクトップ セッションのメニューからプロジェクト スキル、コマンド、エージェントが消える問題を修正
  • macOS 上の /desktop が ~/Applications の場合、Claude Desktop がインストールされていないと表示される問題を修正
  • 事前に開始されたプロセスで開始されるクロード デスクトップ セッションから欠落している OpenTelemetry リポジトリ属性 (vcs.*) を修正しました
  • ページを読み取っているモデルがテキストを返さなかった場合に、WebFetch が「モデルからの応答なし」をページ コンテンツとしてクロードに渡す問題を修正しました。通話は明らかなエラーで失敗するようになりました
  • クロード コードの起動中にシステム クロックが戻ったときに、起動時のプロンプトが遅れるスクリーン リーダー モードを修正しました。
  • ダイアログを閉じた後にコマンドのパネルが戻らないことがあり、次の再描画まで画面にパネルやプロンプトが残らない問題を修正しました。
  • デスクトップ アプリに同じ名前の MCP サーバーまたは拡張機能がある場合、クロード デスクトップ コード タブ セッションの最初のメッセージの後にプロジェクトの MCP サーバーが切断される問題を修正しました。
  • 応答の途中で接続が切断されたときに「API エラー: EPROTO: TLS ハンドシェイクが失敗しました」でターンが終了する問題を修正しました。 2.1.302 のように、部分的な応答が保持されるか、要求が再試行されます。
  • 大きなファイルから単一行を繰り返し読み取る長時間セッションでの高いメモリ使用量を修正しました
  • 高速サービスがレート制限されている場合、過負荷になっている場合、または失敗している場合に、高速モードで応答が失われたり、モデルを切り替えたり、数分間再試行したりする問題を修正しました。最初に同じモデルで標準速度を試行するようになりました
  • いくつかの待機中にクロードが停止された後、意図したよりもはるかに多くのバックグラウンド エージェント レポートを送信する 1 つのリクエストを修正しました
  • クロードの作業中に入力した後、クロード デスクトップ コード タブ セッションから他のセッションへのメッセージが一時停止したままになる問題を修正
  • --verbose などのフラグも行にあるときに、agents より前に入力された --permission-mode、--dangerously-skip-permissions、--model、--effort、または --agent を無視する claude agents を修正しました。
  • アプリが一時的にサインイン トークンを引き渡すことができなかったため、デスクトップ アプリの接続がまだ確立されているにもかかわらず、リモート コントロールが「ログイン期限切れ」でオフとして表示されるケースを修正しました
  • 実行ターンの途中でクロードに届く「後でキュー」で送信されたリモート コントロール メッセージを修正しました
  • git status が失敗したときに、セッション開始時に Claude に与えられる git status が clean として読み取られる問題を修正しました。現在は利用不可と表示されています
  • 変更がステージングされていないときに最初にリストされたファイルがステージング済みとして表示されるセッション開始時にクロードに与えられる git ステータスを修正しました
  • クラウド セッションのコネクタが非常に長い名前のリソースをリストした場合のハングまたはメモリ不足のクラッシュを修正しました
  • セッション履歴のアップロード中に接続が完全に閉じられた後、リモート コントロールが接続済みとして表示される問題を修正
  • エージェント ビューから会話に戻るとスクリーン リーダー モードがオフになる問題を修正
  • スクリーン リーダー モードの y/n の質問で、質問を開いたときに入力されたテキストの末尾にある「y」が「y」とみなされる問題を修正しました。
  • ホストが許可されていて、ネットワーク プロキシが接続できない場合にホストがおそらく許可されていないことをクロードに伝えるクラウド セッションを修正しました。
  • MCP サーバーが再接続された後、またはツールの読み込み中にセッションのディレクトリが変更された後、ツールなしで接続されていると表示されることがある MCP サーバーを修正しました
  • クロードが一度に複数を送信し、以前のコマンドがフォルダーを変更した場合に、Bash コマンドが間違ったフォルダーで実行されることがある問題を修正しました。
  • アップロードがプロキシから HTTP 507 を取得すると、クロードがクラウドから送信するファイルとリモート コントロール セッションが同時に失敗する問題を修正しました。アップロードが 2 回試行されるようになりました
  • トランスクリプトの読み取り中にメモリが不足すると、新しいメッセージが保存されず、claude -p、SDK、VS Code セッションがハングする問題を修正
  • ネットワーク上の何かが接続を受け入れても TLS ハンドシェイクに応答しない場合に、サインイン、トークンの更新、ログアウトが無期限に待機する問題を修正しました。
  • 送信されたファイルの名前にテキスト方向または制御文字が隠れている場合に、クロード アプリで別の名前で表示される送信ファイルを修正しました。クロードは現在、そのようなファイルの送信を拒否しています
  • モデルがツール呼び出しで応答した後、リクエストを最後まで実行するサブエージェントの進行状況の概要を修正しました
  • パスが入力された同じコマンドが許可を求めずに実行されると、grep -r foo "$PWD/src" などの Bash 読み取りが許可を求める問題を修正しました。
  • マネージド MCP サーバーの oauth.omitResource など、desktop 設定にゲートウェイより新しいフィールドが保持されている場合にクロード アプリ ゲートウェイの起動が拒否される問題を修正しました。今では警告を発して提供するようになりました
  • .zshrc が KSH_OPTION_PRINT を設定している zsh ユーザーに対して Bash コマンドが空で返される問題を修正
  • macOS: 有効な MDM プロファイルの読み取りが遅い場合の起動時の「管理ポリシー設定を読み取ることができません」を修正しました。読み取りは 1 回再試行され、タイムアウトがタイムアウトとして報告されるようになりました。
  • 何も入力せずに更新のために再起動すると、エージェント ビューが別のエージェント ビューの保存された入力テキストを消去する問題を修正しました
  • UserPromptSubmit フックが再生された許可の応答をブロックした場合、再起動後に応答が返されないリモート セッションを修正しました。これらのフックはリプレイでは実行されなくなりました
  • 端末の入力が終了したとき、最初に実行される質問で Enter キーなしで入力された y を受け入れる claude remote-control を修正しました。
  • ポリシーに code: ルールがないクロード アプリ ゲートウェイの背後でクロード デスクトップに支出制限の警告が表示されない問題を修正
  • 短くなったツールの結果が画面の上部からスクロールされると、一部のプラグインを使用した全画面セッションがエラーで終了する問題を修正しました
  • モデルがツール呼び出しで応答したときに追加の API リクエストを行うプロンプト提案を修正しました
  • 応答が 16 MiB を超えた場合に、stdio および HTTP MCP サーバー上の PreToolUse mcp_tool フックがスキップされる問題を修正しました。ツールの呼び出しは拒否されました
  • 一部のフォントで空白として描画されるバムム文字を含むスキル名とコマンド名を修正しました。現在は拒否されています
  • 完全な NFS エクスポートまたは使い果たした NFS クォータでトランスクリプト行が失われたときに、Linux 上で claude -p がサイレントで 0 を終了する問題を修正しました。エラーが表示され、テキストおよび json 出力で 1 が終了するようになりました。
  • サービスがクラウド セッションを中断し、誰も停止を押さなかった場合に、バックグラウンド エージェントがユーザーによって停止されたと報告され、再開が拒否される問題を修正しました。
  • 許可プロンプトが開いている間にノートブックが変更された場合など、編集が失敗した場合にフックとテレメトリに成功を報告する NotebookEdit を修正しました
  • 保存された MCP サインイン レコードが null の場合、起動時に空白の画面または応答がなく、空の claude mcp list 出力が修正されました。
  • アーティファクトのデータベース コレクションが大きすぎて並べ替えられない場合に、クロードにフィルターを追加するように指示するアーティファクト ツールを修正しました。コレクションをページごとに読み取り、結果を並べ替えるようになりました
  • クロードが最初に返信する前に再起動したときに、再起動されたクラウド セッションで大きな画像を含むメッセージがドロップされる問題を修正しました
  • 再開されたクラウド セッションでメインの会話に対するサブエージェントのメッセージが未応答のままになる問題を修正しました
  • 実行中のワークフローを停止または一時停止するときにクロードに通知されない問題を修正したため、ワークフローがまだ実行中であると表示されなくなりました
  • /model ピッカーを改善しました。「その他のモデル」が他の行の下に番号のない行になり、古いモデルは残りの番号を付け直さずにその下に開きます。
  • ゲートウェイ: ビジーなレプリカの使用制限が改善され、スキップされるチェックが減り、レコードの使用が早くなりました。
  • Claude Code および /device ページの Claude アプリ ゲートウェイのサインイン制限メッセージを改善しました。ゲートウェイ設定に名前を付けなくなりましたが、ゲートウェイ自体のログには依然として名前が付けられています。
  • claude install とインストール スクリプトの改善: 終了が 2 ～ 4 秒早くなりました
  • プロセスがクラッシュしたリモート コントロール セッションが新しいメッセージを受信できるまでの時間を改善しました
  • Windows: ヘルパー プロセスを開始せずに PATH 上のプログラムを検索することで、起動時間と最初のコマンドの時間を短縮しました。
  • ヘッドレス セッション、デスクトップ アプリ、VS Code の自動モードの改善: 一緒に待機しているバックグラウンド サブエージェントからのレポートは、ターミナルと同様に 1 つのモデル呼び出しで応答されます。
  • ワークツリーを設定できなかった claude --bg --worktree セッションのエージェント ビューの行を改善しました。内部タグや最後の 200 文字ではなく、最初からエラーが表示されるようになりました。

  • 管理対象 extraKnownMarketplaces の変更: 宣言された名前は別のソースから追加できず、他の場所からのエントリは非表示になり、宣言されたマーケットプレイス リストのプラグインはそこから再インストールされます。
  • 組織の Claude in Chrome ポリシーに従うように、Claude Code を実行するアプリが提供する Claude in Chrome ツール (Claude デスクトップ アプリの [コード] タブなど) を変更しました。
  • クロード アプリ ゲートウェイの policy_mode: layered を変更しました。マネージド MCP サーバーは、match: {} を含むすべての一致するポリシーを合計するようになりました。そのため、すでに存在するゲートウェイは、アップグレード後により多くのサービスを提供できるようになります。
  • ゲートウェイ: ゲートウェイ環境の ANTHROPIC_*_BASE_URL 変数を無視するように、Bedrock、Vertex、および Foundry アップストリームを変更しました。別のエンドポイントを使用するようにアップストリームで base_url を設定します。
  • ファイルが変更されたときに .claude/skills で MOD をリロードするようにヘッドレス セッションを変更しました。 CLAUDE_CODE_PLUGIN_DIR_WATCH=0 を設定してこれをオフにします
  • サイバー セーフガード ブロックに関するサイバー検証プログラムの文を変更し、claude.ai と同じ単語を使用するようにしました。
  • Cowork クラウド セッションの変更: PostToolUse フックは、AskUserQuestion への回答や ExitPlanMode の結果の計画を置き換えることができなくなりました。クロードは原作を読んでいます
  • cp および mv を /bin/cp などのパスで綴り、cp および mv と同じパス チェックを行うように変更しました。
  • バックグラウンド コマンドの通知と TaskStop の結果を変更し、1,000 文字を超えるコマンドの開始と終了のみをクロードに表示するようにしました。これにより、コンテキストが節約されます。
  • Inter および Space Grotesk を適切なデフォルト書体として扱うようにアーティファクトのデザイン ガイダンスを変更しました。
  • アカウントの電子メールチェックを変更して、電子メールを保持し、ユーザーエージェントに名前を付けるシェルコマンドのみを尋ねることなく拒否するようにしました。そのため、他のコマンドやスケジュールされた実行はプロンプトで停止しなくなりました。
  • リモート コントロール セッションが開始されたフォルダーを保持するように変更されました。接続された client はセッションを別のフォルダーに移動できなくなりました。
  • 宣言されていないソースからの管理対象 extraKnownMarketplaces の引き継ぎを変更しました。保存されたデータは cleanupPeriodDays 用に確保され、オプションとシークレットは claude plugin restore-set-aside まで保存されます。
  • [VSCode] 認証トークンと API キーの両方が設定されている場合、端末の起動警告と一致する警告をプロンプト ボックスの上に追加しました
  • [VSCode] 隠し文字を含む名前が表示されるプラグインの許可リクエストを修正しました。「プラグイン」と表示されるようになりました。
