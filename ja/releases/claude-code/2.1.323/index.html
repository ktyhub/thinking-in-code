クロードコード v2.1.323

何が変わったのか

  • クロードがツールを呼び出すために JavaScript を書き込む実験的なオプトインであるコード モードを追加しました。組織に対して有効にするか無効にする場合は、https://code.claude.com/docs/en/code-mode を参照してください。
  • engines["claude-code"] を plugin.json に追加: 指定されたクロード コードのバージョン範囲外のプラグインはインストール、更新、またはロードされず、インストールおよび更新では適合する最新バージョンを選択してください。
  • プラグインの TypeScript フック モジュールの型チェックを claude plugin validate に追加しました。それぞれの結果は警告であり、--strict は失敗します。
  • claude plugin validate に $ 名詞が追加され、MOD の engine.create フックが追加、保留、または置換します。
  • サードパーティプロバイダーの Claude Desktop セッションの管理設定で CLAUDE_CODE_AUTO_MODE_MODEL のサポートを追加しました (Claude Desktop にこのバージョンが含まれると有効になります)
  • モデルがオフになっている、または使い果たされている使用クレジットが必要な場合のオプション メニュー (停止、使用クレジットへの切り替え、アップグレード) を追加しました。
  • claude -p および SDK セッションでフックが長時間実行されている間、30 秒ごとに進行状況ハートビートを追加しました。そのため、Claude Desktop などのホストはハングとしてターンを終了しません (このバージョンが含まれると)。
  • Artifact ツール アセットのアップロードに .docx サポートを追加しました
  • 差分パネルに /diff to close ヒントを追加し、パネルをフォーカスして閉じるキーを ? ショートカット ガイドに追加しました。
  • 変数の値に * (Bash(PORT=* npm run dev) など) を含む Bash 許可ルールの起動警告を追加しました
  • プラグインの言語サーバーを起動できない場合の警告、サーバーの名前と確認内容を追加しました
  • Perforce 設定が見つかり、モードがオフの場合に、CLAUDE_CODE_PERFORCE_MODE という名前の 1 回限りの起動通知を追加しました
  • CLAUDE_CODE_DISABLE_AGENT_PROGRESS_SUMMARIES を追加 (2.1.318 以降利用可能): 1 に設定すると、サブエージェントの進捗状況の概要とそれを書き込むリクエストがオフになります (anthropics/claude-code#86879)
  • CLAUDE_CODE_RESUME_HINT_COMMAND を追加しました。クロード コードを開始するプログラムは、終了ヒント名に独自の再開コマンドを付けるように設定できます。
  • claude plugin install --json 結果に unsetOptionCount を追加: まだ設定されていない userConfig オプションの数
  • MOD のペインが描画される小道具に isPromptCovered を追加し、ダイアログまたはプロンプトの上のフィールドがプロンプトをカバーするときを通知します。
  • /compact を再度実行するか、/context などのコマンドを実行した後、クロードがまだ応答していないメッセージを要約する問題を修正しました。
  • 再開されたセッションが、再開されなかった古い中断されたメッセージに次のメッセージを結合する問題を修正しました
  • クロードが非常に大きなファイルを変更した後の次のプロンプトでのメモリのスパイクを修正しました
  • 実行中のセッションに保存された設定が、直前に settings.json に加えられた手動編集を元に戻す問題を修正しました。セッション中に削除した設定ファイルは削除されたままになります
  • トークンの更新中に終了すると、claude plugin コマンドと claude mcp list がコンソール プロファイルからサインアウトする問題を修正しました
  • 特定の /proc ファイルでの Edit と Bash のメモリ不足、およびデバイスと名前付きパイプでの Edit のハングまたはメモリ不足を修正しました
  • 構成ファイルの保存が「メモリ不足」で失敗した場合、クロード コードが起動できない、またはサインアウト時に保存されている資格情報がクリアされない問題を修正しました。
  • 拒否されたイメージ、思考ブロック、ベータ ヘッダーなど、ストリーミング リクエストが回復するエラーでストリーミングが失敗せずに送信されたリクエストを修正しました
  • ワークツリーに入る前にシェルが存在していたフォルダーが削除されている場合に、ワークツリー終了ダイアログと /resume が間違ったフォルダーにセッションを残す ExitWorktree を修正しました。
  • アクセントやその他の結合マークがテキストの左側に表示されることがあり、画面上に古いコピーが残ったり、テキストが折り返されるときに静かに消えたりする問題を修正しました。
  • コード自体のアクションがダイアログのテキスト フィールドで利用できない場合に、ctrl+x Enter の Enter などのキー コードの最後のキーがダイアログのテキスト フィールドに作用する問題を修正しました。
  • コマンドを停止する前にクロード コードをリストするプロセスの実行に時間がかかりすぎると、ps プロセスが山積みになる問題を修正
  • WorktreeCreate フックによって作成されたワークツリーに入った後、またはネストされたリポジトリに属した後、サブエージェントのトランスクリプトと大きなツールの結果がセッションのトランスクリプトとは別に保存される問題を修正しました。
  • /fork、左矢印、または --bg がバックグラウンドでセッションを継続すると、名前付き Anthropic プロファイルのセッションが別のサインインに移動する問題を修正しました。更新中に開いていたセッションを再度開きます
  • 名前付きの Anthropic プロファイルが見つからない、変更されている、または上書きされている場合に、別のサインインで会話を送信するバックグラウンド セッションを修正しました。それは今立ち止まってそう言います
  • API キー、認証トークン、またはワークロード ID のセッションがそのシェル (セットアップ トークンではない) からバックグラウンドで別のサインインに移動する問題を修正しました。それは今立ち止まってそう言います
  • 再度サインインを求める代わりに、サインイン サーバーのエラー (TOKEN_EXPIRED など) で終了する MCP ツール呼び出しを修正しました。
  • 保存されたコンソール キーまたはクレジットなしの ant auth login プロファイルが代わりに使用された場合に、期限切れの claude.ai ログインで「クレジット残高が低すぎます」と表示される問題を修正しました。
  • サインインを維持できない古いバックグラウンド サービスに渡される、名前付き Anthropic プロファイルのセッションを修正しました。サービスを再起動するように表示されます
  • バックグラウンド セッションのサインインで、以前のアカウントのログイン情報またはその他の資格情報がそのまま残る問題を修正しました。コンピューター上のセッションごとにそれらがクリアされるようになり、サインインが拒否されるとログインできなくなる可能性があります。

  • PreToolUse フックが "allow" を返した後、ツールの権限チェックがエラーで失敗した場合の動作を変更しました。クロード コードは、フックが応答しなかったかのように呼び出しを判断するようになりました。
  • PermissionRequest フックが書き換えた入力でツールの権限チェックが失敗した場合の動作を変更しました。クロード コードは再度尋ねるか、誰も応答できない通話を拒否するようになりました。
  • GitLab マージ リクエスト バッジが、サンドボックス セッションが開かれたリポジトリに対してのみ表示されるように変更されました。
  • claude mcp add --help の例をローカル コマンドに変更しました
  • 変更された MOD: *、名前空間、または engine.create の否定されたフックは監視のみになりました。 $ 名詞を追加または保留するには、engine.create を名前でフックします
  • engine.create フックが受け入れられた形式で書かれていない MOD は失敗するように claude plugin validate を変更しました。インストールされたMODはロードされ続けます
  • Git サブモジュールがリポジトリ レコードのコミットにない場合、マーケットプレイスとプラグインのインストールが失敗するように変更されました。
  • プロジェクト (.mcp.json) MCP サーバーの承認をサーバーの正確な名前と一致するように変更しました。別のスペルで書かれた承認エントリが再度質問されるようになりました
  • untrusted フォルダー内の --trust-workspace false および VS Code セッションでセルフホスト ランナーを変更しました。リポジトリの設定ではフックを無効にしたり、プラグインをオンまたはオフにしたりできなくなりました。
  • tool.list プラグイン フックを変更し、追加または削除するツールがモデルとすべてのエージェントに適用されるようにしました。
  • プラグインのインストール コマンドが stderr に書き込むときに、成功ではなく警告を表示するように claude plugin install および /plugin を変更しました。
  • claude.ai チャットと Cowork タスクを変更し、プラグイン ファイルを送信する前に秘密キーをチェックし、秘密キーが保持されているかどうかを最初に尋ねるようにしました。
  • claude rm とエージェントのビューを変更し、セッションが削除ではなくリストから削除されたことを示すようになりました。 claude rm ヘルプには会話が維持されていると表示され、claude --resume には会話がリストされています
  • /stickers を変更して、ブラウザでページを開くのではなく、ステッカー パックが今のところすべて要求されていると表示するようにしました。
  • ユーザーまたは --settings ファイルから環境変数を取得しないように管理設定 policyHelper を変更しました。マネージド env または起動シェルで必要なものを設定します
  • claude.ai またはデスクトップ アプリで選択された 2 つのファイルの間、または選択されたファイルとリンクの後に入力された /skill または @file が有効にならないように変更しました。
  • リクエストがチーム リーダーからのものであることを確認するように分割ペイン エージェントのチームメイトを変更しました。リードを超えたチームのリクエストは拒否され、計画の承認は /clear または /resume の後に再送信する必要があります。
  • .git フォルダーがリンクであるか、git-new-workdir レイアウトや cp -al コピーなどのハード リンクを保持しているチェックアウトを拒否するようにワークツリーの作成を変更しました。プレーンクローンを使用する
  • セーフガードによってフォークされたスキルまたはワークフロー エージェントが停止された後にクロードに通知される内容を変更しました。作業自体を実行する代わりに、より狭いプロンプトで再試行するか、通知します。
  • ブラウザ ツール呼び出し (Chrome のクロード、デスクトップ ブラウザ ペイン) を変更して、一部のエスケープまたは JSON テキスト入力を拒否し、クロードにそれらのスペルを変更する方法を指示しました。
  • アプリが未入力としてマークしたプロンプトがリクエストとしてエージェントに届かないようにワークフローを変更しました。
  • macOS でのコンピューターの使用を変更し、Control または Option を押しながらスペースを押すキー コードや、許可が必要なその他のシステム ショートカットを拒否するようにしました。
  • Terminal.app の初回実行セットアップを変更して、「オプションをメタ キーとして使用する」設定、どのオプションが入力を停止するか、および同意する前にそれを元に戻す方法に名前を付けました。
  • CLAUDE_CODE_OVERLOADED_RETRY_MAX_DELAY_MSの最大値を64000から300000に変更しました
  • デスクトップ アプリの [コード] タブのワークフローを変更し、使用制限に達すると一時停止し、リセット後に続行するようにしました。
  • クラウド セッションおよびリモート コントロールでの使用制限と 1M コンテキスト エラー、および /usage-credits を変更しました。Web アドレスは提供されなくなりました。
  • 現在のコネクタ ディレクトリに従うように、OpenTelemetry エクスポートで名前で報告される MCP サーバーを変更しました。
  • バックグラウンド セッションで /logout を変更しましたが、効果はありませんでした。ターミナルの場合と同様に、コンピュータ上のすべてのセッションからサインアウトし、保存されている MCP ログインとプラグイン シークレットを削除し、セッションを終了します。
  • macOS: Bash サンドボックスを変更したため、lsof および同様のツールでは、コマンドが開始しなかったプロセスについての表示が少なくなることがあります。
  • 変更されたクラウドスケジュールタスク: 独自の設定からの PostToolUse フックは、ExitPlanMode の結果の計画を置き換えることができなくなりました
  • Anthropic がホストするクラウド セッションの CLAUDE_AUTOCOMPACT_PCT_OVERRIDE を変更して、自動メモリ抽出への適用を停止し、一部のセッションでは /btw に適用しました。メインの会話がまだ続きます
  • subagentStatusLine 設定を削除しました。サブエージェント行は常にデフォルトの外観を使用し、キーを保持する設定ファイルは以前と同様にロードされます。
  • プラグインの agent 設定が非推奨になりました。この設定は引き続き適用され、起動時、claude plugin list および claude plugin validate で警告されるようになりました。
  • [VSCode] trust していないフォルダー内の最初のセッションの前に、Claude Code trust プロンプトを追加しました。 declining では、フォルダーの設定と MCP サーバーが未使用のままになります。

  • [VSCode] クロードが再試行した後もツール呼び出しが解析できずに表示されたため破棄された応答を修正しました
  • [VSCode] キューに入れられたメッセージが圧縮概要の直後にある場合に、会話またはフォークから欠落する問題を修正しました。
  • [VSCode] 使用クレジットがオフのときに Fable の支払いに同意したものとしてカウントされる「claude.ai で使用クレジットを購入」ボタンを修正しました
  • [VSCode] ウィンドウがリロードまたは再起動されるたびに、開いているターミナルで「拡張機能がターミナルの再起動を求めています」という警告が表示される問題を修正しました。
  • [VSCode] 最初のプロンプトの前にクロード プロセスが再起動された新しいチャットに表示される「この会話の保存された履歴を読み込めませんでした」を修正しました
  • [VSCode] コードを貼り付けた後にログインの選択肢が再度表示されるサインイン画面を修正しました。サインインが完了するまで「サインイン中…」と表示されるようになりました。
  • [VSCode] 別のモデルを選択した後、VS Code および JetBrains パネルに残る「Fable の制限に達しました」という行が修正されました。
  • [VSCode] VS Code および JetBrains パネルで、オフまたは使い果たした場合の使用クレジットに名前を付ける Fable の使用警告を修正しました。

  • [VSCode] TLS 検査プロキシの背後でのサインイン エラーの改善: 証明書の失敗により、端末と同様に何をすべきかが示されるようになりました。

  • [Claude Code on the web] 一部のネットワーク シークレットを新しいクラウド環境に追加できない場合のメッセージを改善しました。各ホストを一覧表示し、追加できる場合はその理由を示し、削除するまでそのまま表示されます。

  • [Claude Code on the web] 数分間接続に失敗した後、開いているクラウドまたはリモート コントロール セッションのページが「切断」のままになる問題を修正しました。自動的に再接続を試みるようになりました
  • [Web 上の Claude Code] オープン クラウドまたはリモート コントロール セッションでの「再試行」カードがメッセージとして「再試行」を送信する問題を修正しました。代わりに再接続を試みます
  • [Claude Code on the web] クロードがまだ作業している間、返信から 5 分後に何も表示されなかったクラウド セッションから [停止] ボタンが消える問題を修正しました。

  • [Claude Code on the web] クラウド セッションで 10 分以上かかる git クローンとフェッチが最後に切断されることがある問題を修正しました。

  • [Claude Code on the web] クラウド セッションを削除すると、そのセッションで実行されるスケジュールされたタスクが一時停止される場合の警告をクラウド セッションの削除ダイアログに追加しました。

  • [リモートコントロール] クロードが開始される前にコンピューターが切断された後も、セッションリストに実行中として表示される一部のセッションを修正しました。エラーマークが表示されるか、アイドル状態として表示されるようになりました
  • [リモートコントロール] セッションを実行しているコンピュータがクロードコードからサインアウトしたときに表示されるエラーに「再試行」ボタンを追加しました

  • [Claude Tag] 管理者が組織の Claude Tag をオフにするときに、何が停止するかを示すダイアログを表示する確認ステップを追加しました。
