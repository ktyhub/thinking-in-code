sim v0.9.55

パッチ 公開日2026年11月13日 出典simstudioai/sim 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#シムv0.9.55

特徴

  • feat(credentials): キーレス AWS、Databricks、Snowflake、Microsoft、および Google 認証情報の構成可能な対象者 (#9962)
  • 特技(gitlab): 権限CSVエクスポーターを追加 (#9955)
  • feat(computer-use): デフォルトでコンピュータの使用を有効にし、権限グループの制限によって管理されます (#9944)
  • 特技(ライブラリ): 注文と在庫のための Shopify AI エージェントを構築する方法 (#9940)
  • feat(ライブラリ): AI エージェント プラットフォーム ベンダーの存続可能性: 資金調達、導入、維持力の比較 (#9941)
  • feat(aws-marketplace): 期間ごとの計測集計を通じて、リスティングの LLM 使用量を AWS に請求します (#9921)
  • feat(資格情報): 保存された PostgreSQL、MySQL、および SQL Server 接続 (#9929)
  • feat(credentials): ServiceNow、Snowflake、Infisical、Google Ads の 2 番目の認証モード (#9928)
  • 特技(知識): S3 コネクタを保存された AWS 認証情報と同期させます (#9934)
  • feat(資格情報): Amplitude、Kalshi、Splunk、CB Insights、Railway、および Qdrant の保存された資格情報。 Kalshi Ed25519 の署名を修正 (#9927)
  • feat(資格情報): 国内クラウドを使用した Power BI および Azure Data Explorer 用の Microsoft アプリ資格情報 (#9931)
  • 特技(認証情報): IAM SignJwt を介したキーレスの Google Workspace ドメイン全体の委任 (#9933)
  • feat(credentials): 保存されたトークンの有効期限を記録、表示、説明します (#9930)
  • feat(bedrock): 保存された AWS 認証情報を使用して Bedrock モデルを実行します (#9932)
  • feat(認証情報): 保存された LaunchDarkly、LangSmith、New Relic、Square、SendGrid、Hex、および Sentry 認証情報のリージョン ホストとインスタンス ホスト (#9926)
  • feat(apollo): オプションの OAuth 接続を追加 (#9922)
  • feat(aws-marketplace): 製品カタログを通じて 1 つの統合から複数のリストを販売する (#9920)

改善点

  • 改善(デスクトップブラウザ): ターゲット全体を満たすネストされたコントロールによる click (#9956)
  • 改善(デスクトップブラウザ): 安定した要素参照、待機監視、および誤った拒否の減少 (#9953)
  • 改善(aws-marketplace): 請求ギャップを解消し、ライセンス書き込みパスを簡素化しました (#9946)
  • 改善(資格情報): 更新停止を通じて有効な client 資格情報トークンを維持し、障害の種類ごとにトークンの再試行のペースを調整します (#9925)
  • 改善(changelog): v0.9.54 を通じて意味のある製品アップデートをカバー (#9809)

バグ修正

  • fix(credentials): AWS キーレス ヒントをポリシー対象者に向け、ドキュメント client ID を引用し、古いコメントを修正します (#9970)
  • 修正(aws): ラウンドトリップ型の DynamoDB カーソルとパーセンタイルのみの CloudWatch 統計を許可します (#9967)
  • 修正(デスクトップブラウザ): 待機終了スナップショットにフルバジェットを与え、ref の再利用が同じ要素名であることを確認します (#9966)
  • fix(executor): Router と Evaluator での各フォールバック試行内で保存されたモデル認証情報を解決します (#9968)
  • 修正(統合): データバースのページ サイズを返し、連絡先検索の出力を修正しました (#9965)
  • 修正(テスト): CI を剥奪した 3 つの統合テスト レースを終了 (#9964)
  • 修正(統合): Atlassian および AWS スイープの最終レビュー パス (#9961)
  • 修正(統合): Google と Microsoft のスイープからの古い値と空の値のリークを解決 (#9960)
  • 修正(デスクトップブラウザ): 以前に再発行された参照を拒否し、コミットされていない参照の再利用から回復します (#9959)
  • 修正(gitlab): 権限エクスポートで確認済み電子メールを要求する (#9958)
  • 修正(aws): SDK および API ドキュメントに対して AWS 統合を検証する (#9952)
  • 修正 (アトラシアン): Jira、Confluence、JSM、Bitbucket、Trello をベンダーのドキュメントに対して検証します (#9950)
  • 修正(Microsoft): Microsoft 統合を検証し、ドロップされたフィールドを返し、不足しているパラメータを公開します (#9949)
  • 修正(google): ワークスペース スイープからのマージ後の検証ギャップを埋める (#9954)
  • 修正(google): ワークスペースの統合を検証し、ドロップされたフィールドを返し、不足しているパラメータを公開します (#9947)
  • 修正(母艦): 毎秒再試行するのではなく、トランスポートポーリングを中止する (#9945)
  • 修正 (資格情報): Splunk パスワード サインイン、CLI の Snowflake キー ペア、Apollo OAuth ユーザー検索、および 1 回の短い SailPoint スロットル待機 (#9943)
  • 修正(api): 一時停止が完了したら、終了した実行の実際のステータスを報告します。 CLI でリクエスト ID を表示します (#9924)

その他の変更点

  • 雑務(統合): Google/Microsoft のスイープによって残された 2 つのコメントを整理する (#9969)
  • chore(api): 実行ステータス オーバーレイ TSDoc に解決済み一時停止ルールを記述します (#9957)
  • revert(library): オーケストレーションとガバナンスのポストを #9938 および #9939 (#9951) より前に復元します。
  • docs(library): オーケストレーションおよびガバナンスの投稿で重複する質問を削除 (#9948)
  • ドキュメント (ライブラリ): ガバナンス-ai-agents-multiple-teams-enterprise-workspace を更新 (#9939)
  • ドキュメント(ライブラリ): ai-agent-orchestration-frameworks-explained を更新 (#9938)
  • ドキュメント(ライブラリ): enterprise-ai-agent-compliance-deployment-guide を更新 (#9937)
