#カウエージェント2.1.7

🌐 英語 | 中文

🗂 複数のワークスペース

エージェントは単一のディレクトリに関連付けられなくなりました。複数のプロジェクト ワークスペースをセットアップして、各セッションに独自のセッションを与えることができます。 Web コンソールとデスクトップ client の両方で使用できます。

  • 複数のワークスペース: 任意のディレクトリをプロジェクト ワークスペースとして作成または開きます。エージェントが生成するドキュメント、Web ページ、コードはそこで作成および管理されます。
  • セッションごとのワークスペース: 各セッションは独自のプロジェクト ワークスペースにバインドされているため、並行して実行されているタスクは互いに邪魔になりません。
  • セッションごとのモデル: 単一セッションのモデルを切り替えます。新しいセッションはグローバルデフォルトから開始されます。
  • グループ化されたセッション: セッション リストはワークスペースごとにグループ化され、固定、並べ替え、名前変更、削除が可能です。
  • 共有システム リソース: メモリ、スキル、ナレッジ ベースは引き続きシステム ワークスペース (デフォルトでは ~/cow) に存在します。

ドキュメント: ワークスペース

🔐 許可モード

セッションは独自の権限モードを持ち、ワークスペースと連携してエージェントがどこまで到達できるかを制御するようになりました。

  • 3 つのレベル: 読み取り専用、ワークスペース書き込み、およびフルアクセス。セッションごとに個別に設定されます。
  • デフォルト モード: デフォルトの権限モードを選択すると、新しいセッションがそのモードで開始されます。
  • 実用的な拒否: ツール呼び出しがブロックされると、ヒントが clickable になるため、その場で権限を調整できます。
<img src="https://cdn.jsdelivr.net/gh/zhayujie/cowagent-assets@main/screenshots/en/web-console-access-mode.png" width="600" />

🖥 デスクトップ Client

  • 音声入力: チャット入力の音声ボタンは、あなたの発言をボックスに直接文字に起こします。音声認識と音声合成は、カスタム プロバイダーやモデルでも機能します。ありがとう@chimyves (#3052、#3050)
  • 下書きの保持: チャット ページから離れて戻ってきたときに、未送信のテキストや添付ファイルが失われることがなくなりました。ありがとう@chimyves (#3040)
  • ログイン時に起動: システム設定の新しいトグルで、デフォルトではオフになっています。
  • 起動診断: バックエンドが起動に失敗すると、client は一般的なエラーではなく、実際に問題が発生したことを報告します。
  • ログのダウンロード: 実行ログ ページではログ ファイルをダウンロードでき、ローカル アップロードでは再試行が行われ、エラーが明確になりました。

ダウンロード: CowAgent デスクトップ

ドキュメント: デスクトップ Client

🔔 タスク通知

Web コンソールとデスクトップ client はどちらも、エージェントの実行が終了または失敗すると通知 (音付き) を発するため、長いタスクから離れることができます。

  • clients の両方: デスクトップ上の OS 通知、Web 上のブラウザ通知 — ウィンドウがフォーカスされていない間のみ。 Cli1 つをクリックすると、セッションに戻ります。
  • 未読バッジ: Web タブが非表示になっている間は未読数が表示され、元に戻すとクリアされます。
  • 個別の切り替え: 通知とサウンドは 2 つの独立したスイッチであり、両方ともデフォルトでオンになっています。自分でタスクをキャンセルしても、失敗通知はトリガーされなくなりました。

ありがとう @chimyves (#3056、#3055)

🤖 モデルの更新

  • 新しいモデル: glm-5.3、qwen3.8-max、gemini-3.7-flash、および gemini-3.6-flash。それぞれプロバイダーのデフォルトとして設定されます。
  • 統合された構成ページ: Web コンソールは、[モデル] ページを [構成] に折りたたんで、[基本] タブと [モデル] タブに分割するため、あちこち移動することが少なくなります。
  • 通話の修正: GLM-5.3 の強制思考を修正し、一部の DashScope モデルのルーティングとベース URL の処理を​​修正しました。カスタム モデルがセッション モデル ピッカーに表示されるようになりました。

🛠 改善と修正

  • 画像表示: ナレッジ ドキュメント内のローカル パス画像と相対パス画像がレンダリングされない問題を修正しました。デスクトップでは、チャットまたはドキュメント内の画像を cli クリックすると、その場でズームされます。ありがとう@chimyves (#3046)
  • Windows ドライブ: Windows 上のドライブがリストされないフォルダー ピッカーを修正しました。ありがとう @CNXudiandian (#3048)
  • Windows シェル ガイダンス: Windows でシェル コマンドが失敗した場合の回復ガイダンスが改善されました。ありがとう@dajiaohuang (#3065)
  • よりクリーンな IM 返信: IM チャネルでのエージェントの返信には、思考コンテンツが含まれなくなりました。ありがとう@LHMQ878 (#3044)
  • スケジュールされたタスク: 深夜を超えて失敗し、スケジュールどおりに戻らないタスク (@chimyves #3054 に感謝) と、スケジュールされたタスクが実行されずに承認される問題を修正しました。
  • 最初のメッセージの高速化: メモリ システムの初期化が効率化され、セッションの最初のメッセージがブロックされなくなり、最初の応答までの待ち時間が大幅に短縮されました。
  • コンテキストのトリミング: コンテキストがトリミングされたときに AI 応答が保存されない問題を修正しました。
  • Feishu チャンネル: ストリーミング カードはターンをまたいでテキストを蓄積するようになりました。
  • Docker: config.json は、COW_DATA_DIR マウントを通じてコン​​テナーをアップグレードしても存続します。

📦 アップグレード方法

  • ソースの展開: cow update を実行して 1-click アップグレードするか、最新のコードをプルして再起動します。 アップグレードガイドを参照してください。
  • デスクトップ client: 更新を確認し、client 内の 1 つの click で更新するか、ダウンロード ページ から最新バージョンを入手します。
