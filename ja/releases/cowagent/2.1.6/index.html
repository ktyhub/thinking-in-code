#カウエージェント2.1.6

🌐 英語 | 中文

🤝 サブエージェント

メイン エージェントは、独立したタスクをサブ エージェントに引き渡し、それらを並行して実行できます。これにより、結果が向上し、コンテキスト コストが削減され、同時に発生する可能性のある作業が高速化されます。

  • 分離されたコンテキスト: 中間作業は主要な会話から外れ、トークンが節約され、モデルの集中力が維持されます。
  • 並列実行: 複数のサブ エージェントを同時に実行でき、メイン エージェントは終了時に結果を収集します。 Web コンソールとデスクトップ client の両方で、完全な実行が表示されます。
  • カスタマイズ可能: 2 つの組み込みタイプ (general-purpose と explore) に加えて独自のタイプ - ワークスペース subagents/ ディレクトリの下に .md ファイルをドロップして、独自のシステム プロンプトとツール セットを備えたタイプを定義します。
  • デフォルトでオン: セットアップは必要ありません。メインエージェントがいつ委任するかを決定します。 [Config] → [Agent] で切り替えて、config.json でネストの深さ、同時実行性、およびタイムアウトを調整します。

ありがとう @AaronZ345 (#2976)

ドキュメント: サブエージェント

🖥 デスクトップ Client

  • スケジュールされたタスク通知: client は、スケジュールされたメッセージとプッシュされたメッセージを受信し、OS 通知を生成します。
  • 更新パネル: 更新ダイアログが release note にリンクされるようになり、何が変更されたかを確認できます。
  • カスタム プロバイダー モデル: カスタム プロバイダーは自由形式のモデル入力を取得します。
  • スタートアップの修正: バックエンドのスタートアップのハングを修正し、自動ポート再試行を追加し、失敗時の実際のエラーを表示しました。

ダウンロード: CowAgent デスクトップ

ドキュメント: デスクトップ Client

🧠 推論の努力と思考

  • 推論努力設定: クロード、クウェン、キミなどのネイティブ reasoning_effort 構成がモデルごとに記憶されます。ありがとう @tshicheng (#3007、#3009)
  • クロードの思考: クロードの思考プロセスが Web コンソールとデスクトップ client に表示されるようになり、その推論が理解しやすくなりました。

🔒 セキュリティ強化

  • 保護された自己進化書き込み: 無人書き込みで検証とロールバックが行われるようになり、書き込みはワークスペースごとにシリアル化され、保護された書き込みパスが狭められたため、ワークスペース内のタスク ファイルが誤って操作されることがなくなりました。ありがとう @lisheng-SenLee (#3011、#3016)
  • スキル パスの検証: スキルのインストールでは、各ファイル パスをより徹底的に検証します。ありがとう@LHMQ878 (#3006)
  • 依存関係のアップグレード: デスクトップ client は js-yaml と linkify-it を強化し、悪用可能な 2 つのサービス拒否の問題を修正します。ありがとう@anupamme

💾 記憶と検索

  • プラグイン可能なベクトル バックエンド: メモリのベクトル ストレージと取得は、デフォルトとして SQLite を使用する単一のインターフェイスの背後に位置するため、後で外部ベクトル ストアを簡単にプラグインできます。ありがとう @AaronZ345 (#3021)
  • インデックス修復: チャンク更新時のトライグラム FTS5 インデックスの破損を修正しました。破損した共有データベースが自己修復されるようになりました。

ドキュメント: メモリ

🛠 改善と修正

  • カスタム イメージ プロバイダー: イメージ生成ではカスタム プロバイダーがサポートされており、ライブ資格情報の更新と削除時のクリーンアップが行われます。ありがとう@AaronZ345 (#3022)
  • 信頼性の高い SSE 再接続: Web SSE ライフサイクルが完了し、ネットワーク切断後のイベント再生で再接続し、長時間のタスクでのメッセージ損失をカットします。ありがとう@lisheng-SenLee (#3014)
  • 推論表示: 推論モードでのツール カード、ファイル リンク、および画像表示に関するいくつかの問題を修正しました。
  • レート制限バックオフ: LLM がレート制限されている場合にバックオフに上限を設け、長時間の待機を回避します。ありがとう@tim-korso (#3018)
  • 静かなスケジュールされたタスク: レポートするものが何もないスケジュールされたタスクは空のメッセージを送信しなくなりました。ありがとう @kowkowhuang (#3001)
  • サービス停止時間: サービス停止時間として拒否される一日の終わりの時間 (23:59 など) を修正しました。ありがとう@Iams4akura (#3020)
  • ドメイン スキーム: WEBSITES_DOMAIN の明示的な http/https スキームが尊重されない問題を修正しました。ありがとう@6vision (#3015)
  • WeChat メディア: 個人の WeChat が信頼性の低いネットワーク上で画像、ファイル、その他のメディアの送受信に失敗する問題を修正し、画像認識を改良しました。
  • Feishu チャンネル: 配信が遅れたときに新しいメッセージがドロップされる問題を修正しました。
  • Telegram: Markdown レンダリングと添付ファイルを削除する長い概要を修正しました。
  • ファイル応答: 付随するテキストやその他の添付ファイルを削除するファイル応答と、client のツール カードを取り残しているツールのファイル リンクを修正しました。
  • Docker: tzdata をインストールして、TZ 環境変数が有効になるようにします。

📦 アップグレード方法

  • ソースの展開: cow update を実行して 1-click アップグレードするか、最新のコードをプルして再起動します。 アップグレードガイドを参照してください。
  • デスクトップ client: 更新を確認し、client 内の 1 つの click で更新するか、ダウンロード ページ から最新バージョンを入手します。
