#カウエージェント2.1.5

🌐 英語 | 中文

🗂 ワークスペースとファイルのプレビュー

チャット ページには、ワークスペースの視覚的なビューが表示されます。エージェントが作成したドキュメント、Web ページ、および画像をその場でプレビューできます。 Web コンソールとデスクトップ client の両方がサポートしています。

  • ワークスペースの参照: パネルからワークスペース ディレクトリ内のファイルを参照し、検索してローカルにダウンロードします。
  • ファイル プレビュー: HTML ページ、ドキュメント、画像はサイド パネルで直接開き、返信内のファイル パスは clickable カードとして表示されます。
  • ファイル参照: ワークスペース ファイルを会話にドラッグするか、入力ボックスで @ を使用してファイルとディレクトリを参照し、コンテキストに取り込みます。
<img src="https://cdn.jsdelivr.net/gh/zhayujie/cowagent-assets@main/screenshots/en/workspace-file-preview-demo-en.png" width="800" />

🔧 コアツールの改善

ファイル検索、読み取り、書き込み、編集、およびシェル ツールを体系的にパスオーバーし、エージェントのファイル処理およびコーディング能力を強化します。

  • 新しいファイル検索ツール: search_files は、デフォルトで ripgrep を利用して、内容またはファイル名によってワークスペースを検索します。これにより、大きなディレクトリでは著しく高速になります。ありがとう@Maaayhan (#2982)
  • 行番号付き読み取り出力: read 出力には常に行番号が付けられるようになり、特定の行を見つけて引用することが容易になりました。
  • より正確な編集: edit はあいまい一致で周囲のインデントを書き換えなくなり、テキストが繰り返されるときに間違った箇所に到達することもなくなりました。 replace-all が追加されました。エージェントの外部で変更されたファイルにはフラグが付けられるようになりました。
  • 書き込み時の構文チェック: write / edit は、書き込み前に構造化ファイルの形式を検証し、ソース ファイルを解析して構文エラーをエージェントに報告します。
  • バックグラウンド コマンド: bash は、サービスの開始やログの追跡などの長時間実行される作業のために、コマンドをバックグラウンドで実行できます。フォアグラウンド コマンドのデフォルトのタイムアウトが発生しました。
  • キャンセルはすぐに有効になります: cli停止または実行中 /cancel は、現在実行中のコマンドを終了します。

ドキュメント: ファイル検索

🧠 コンテキスト管理

  • コンテキストの圧縮: 新しい /compact コマンドは、オンデマンドで会話コンテキストを要約して圧縮し、トークンの使用量を効果的に削減します。
  • 統合されたコマンド: /clear は、/context clear をエイリアスとして保持したまま、現在のセッションのコンテキストを一律にクリアするようになりました。
  • デフォルト ウィンドウの拡大: デフォルトのコンテキスト制限が引き上げられたため、長い会話は後でトリミングされ始めます。

ドキュメント: コンテキスト管理

🖥 デスクトップ Client

  • Mac 上でネイティブ: x64 バックエンドを搭載する macOS arm64 インストーラーを修正し、Apple Silicon マシン上のメイン プロセスとブラウザ ツールを大幅に高速化しました。
  • Feishu チャンネルを追加: client に欠落していた Feishu チャンネルを修正しました。 Feishu SDK は、初めてチャネルが有効になったときにオンデマンドでダウンロードされるトリミングされた依存関係 (約 1 MB) になりました。ありがとう @EvanProgramming (#2988)
  • 更新プロンプト: 特定のバージョンの更新ダイアログは、自動的に 1 回だけ開きます。
  • バンドルされた検索バックエンド: Windows client には ripgrep が同梱されているため、ファイル検索はすぐに機能します。

ダウンロード: CowAgent デスクトップ

ドキュメント: デスクトップ Client

✨ One-Click の即時最適化

Web 入力ボックスは、入力した内容をより完全で明示的な指示に展開できるようになり、最適化ルールはカスタム テンプレートをサポートします。ありがとう @sufan721 (#2989)

🔒 セキュリティ強化

  • MCP とファイル書き込みの強化: プロンプト インジェクションを通じて悪用可能な攻撃チェーンを修正しました。悪意のあるコンテンツによりエージェントが MCP 設定を書き換え、そこから任意のコマンドを実行してキーを盗む可能性があります。ありがとう@Correctover (#2968)
  • 資格情報ファイル保護: ~/.cow/.env の読み取りおよび書き込みのために資格情報保護をバイパスする edit ツールを修正しました。

🛠 改善と修正

  • bash 設定を尊重: config.json の tools.bash.timeout および tools.bash.safety_mode が無視される問題を修正しました。ありがとう @EvanProgramming (#2986)
  • メモリ ワークスペース パス: グローバル メモリ構成で誤って解決されるワークスペース パスを修正しました。ありがとう@Maaayhan (#2992)
  • 会話履歴の保護: 会話履歴も一緒に消去される可能性があるメモリ インデックスの自己修復を修正しました。
  • セッションの削除: 削除されたセッションをリストに書き戻すまだ送信中の応答を修正しました。
  • ブラウザの起動: ブラウザがすでに実行されている場合に重複したインスタンスが起動する問題を修正しました。
  • 正確なツールの結果: いくつかのツールで発生した誤解を招く障害が修正されました。grep / find の終了コードが間違っていると判断され、ブラウザ スクリプトが構文エラーとして誤って報告され、相対画像パスが解決されませんでした。無駄な再試行が減少しました。

📦 アップグレード方法

  • ソースの展開: cow update を実行して 1-click アップグレードするか、最新のコードをプルして再起動します。 アップグレードガイドを参照してください。
  • デスクトップ client: 更新を確認し、client 内の 1 つの click で更新するか、ダウンロード ページ から最新バージョンを入手します。
