gradle v9.8.0

マイナー 公開日2026年9月24日 出典gradle/gradle 英語原文

#グラドルv9.8.0

Gradle チームは、Gradle 9.8.0 を発表できることを嬉しく思っています。

このリリースのハイライトは次のとおりです。

  • Java 27のサポート
  • Maven ミラー設定の再利用
  • ビルド出力内のリンクされた問題の場所

Release Note を読む

Gradle のこのリリースに貢献してくれた次のコミュニティ メンバーに感謝します。 アマン・ゴータム、 ビョルン・カウトラー、 Eng Zer Jun、 ハシム カーン、 ジュリアン・クラニッチ、 KBS、 ラブ R ジェテ、 マーク・ドジソン、 マキシム、 モンキー、 ナタフォン-ktsystems、 ポール・キング、 秋天、 rg_sandesh、 ロベルト・ペレス・アルコレア、 ショーン、 【ゾングルワン】(https://github.com/Goooler)。

アップグレード手順

ラッパーを更新して、Gradle 9.8.0 を使用するようにビルドを切り替えます。

./gradlew :wrapper --gradle-version=9.8.0 && ./gradlew :wrapper

非推奨、重大な変更、およびアップグレード時のその他の考慮事項については、Gradle 9.x アップグレード ガイド を参照してください。

Java、Groovy、Kotlin、Android の互換性については、完全な互換性ノート を参照してください。

問題の報告

このリリースで問題を見つけた場合は、問題ガイドラインに従って GitHub 問題 にバグを報告してください。 バグに遭遇しているかどうかわからない場合は、フォーラム をご利用ください。

Gradle と一緒に幸せを築いていただければ幸いです。Twitter または GitHub を通じてフィードバックをお待ちしています。
