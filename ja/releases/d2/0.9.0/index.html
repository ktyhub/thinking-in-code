d2 v0.9.0

機能 🚀

  • TALA は現在オープンソースであり、JavaScript/WASM パッケージを含む D2 にバンドルされています。 d2 --layout=tala、D2_LAYOUT=tala、または vars.d2-config.layout-engine: tala で選択します。個別のプラグインのインストールやライセンス キーは必要ありません。
  • tala: --tala-seeds、D2_TALA_SEEDS、または vars.d2-config.data.tala-seeds を使用してレイアウトの試行を構成します。
  • エクスポート: 内蔵レンダラーを使用して PNG、GIF、PDF、PPTX をレンダリングします。

改善点 🧹

  • パフォーマンス: Dagre ランキング、テキスト測定、SVG 準備、および PNG エンコードにおける繰り返し作業を削減します。
  • パフォーマンス: 選択的インポート、動的グリッド レイアウト、および PNG 接続レンダリングでの繰り返し作業を削減します。
  • エクスポート: PNG メモリ使用量を削減し、以前の 67-megapixel 制限を超える画像をサポートします。
  • パフォーマンス: SVG レンダリングは、E2E コーパス全体で約 10 倍高速です。実際の図では、中央値で約 3 倍の速度でコンパイル、レイアウト、レンダリングが行われます。
  • レンダリング: SVG エクスポートは、外観は変わりませんが、E2E コーパス全体で約 24% 小さく、現実世界の器具全体で 18% 小さくなります。
  • レンダリング: Markdown ラベルを HTML foreignObject コンテンツではなくネイティブ SVG としてレンダリングします。

バグ修正 ⛑️

  • インストール: 古い D2 リリースには TALA がバンドルされていると誤って主張するのではなく、インストール前に移行ガイダンスとともに廃止された --tala インストーラー フラグを拒否します。
  • シーケンス図: 合成ライフライン エンドポイント ID をアーキテクチャ間で安定した状態に保つ
  • エクスポート: PNG および GIF レンダリング中に D2_TIMEOUT を優先します
  • コンパイラ: 再帰的グロブをクラスおよび変数定義から遠ざけ、スタックをオーバーフローさせる代わりにクラス参照サイクルを報告します。
  • レンダリング: gzip、Brotli をデコードし、リモート画像を埋め込む前に圧縮します。

最新の d2.js の変更については、別の changelog を参照してください。
