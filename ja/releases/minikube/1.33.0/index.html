#ミニクベv1.33.0

📣😀 簡単な 5 つの質問からなるアンケート にご記入ください。これにより、minikube を使用する方法と理由、そしてどのような改善が必要かを知ることができます。ありがとう！ 💃🎉

Release Notes

バージョン 1.33.0 - 2024-04-19

特徴:

  • マルチ コントロール プレーンのサポート - HA クラスター --ha #17909 チュートリアル
  • Kubernetes v1.30 #18669 のサポートを追加
  • minikube service #17877 を介したクラスター IP サービスの公開をサポート
  • アドオン gvisor: arm64 サポートを追加 #18063 #18453
  • 新しいアドオン: YAKD - Kubernetes ダッシュボード アドオン #17775

マイナーな改善:

  • アクティブな kubecontext を minikube profile list 出力に追加 #17735
  • CNI calico: kubeadm.pod-network-cidr #18233 をサポートします。
  • CNI ブリッジ: ポッド通信が許可されていることを確認してください #16143
  • アドオンの自動一時停止: メモリ リークを削除し、設定可能な間隔を追加 #17936
  • イメージ ビルド: イメージの短縮名に docker.io/library を追加 #16214
  • cp: ディレクトリが存在しない場合は作成します #17715
  • ログ取得エラーをログ出力自体に移動 #18007
  • デフォルトの sysctl を追加して、機能のない特権ポートを許可します #18421
  • プリロード tarball に拡張属性を含める #17829
  • kubeadm.applyNodeLabels ラベルをすべてのノードに適用 #16416
  • ドライバーのステータスチェックを 20 秒に制限 #17553
  • systemd サービスの開始に失敗した場合は、journalctl ログを含めます #17659
  • 「コンテナー ランタイムを有効にできませんでした: sudo systemctl restart cri-docker」を修正 #17907
  • 起動時に既存のイメージを再ダウンロードするcontainerdを修正#17671
  • kvm2 がcontainerdのプリロードを検出しない問題を修正 #17658
  • Docker binfmt 設定の変更を修正 #17830
  • 自動一時停止アドオンを修正 #17866
  • overlayfs ストレージ ドライバーでプリロードを使用しない問題を修正 #18333
  • 番号付きのサブドメインを許可しないイメージ リポジトリを修正 #17496
  • containerd で kvm2 を使用する場合のクラスターの停止を修正 #17967
  • kvm2 arm64 での複数のクラスターの起動を修正 #18241
  • arm64 Mac 上で Linux を使用した kvm2 クラスターの起動を修正 #18239
  • 存在しないクラスターを削除する際のエラー表示を修正 #17713
  • 再起動時に制限なしが尊重されない問題を修正 #17598
  • 初回起動後に追加されたノードに kubeadm.applyNodeLabels ラベルが適用されない問題を修正 #16416
  • ログの区切り文字出力を修正 #17734

バグ:

  • エスケープされていないローカル ホストの正規表現を修正 #18617
  • 特殊文字をサポートするために validateNetwork の正規表現を修正しました #18158

バージョンのアップグレード:

  • バンプ Kubernetes バージョンのデフォルト: v1.30.0 および最新: v1.30.0 #18669
  • アドオン ヘッドランプ: ヘッドランプ k8s/ヘッドランプ イメージを v0.23.0 から 0.23.1 に更新 #18517
  • アドオン inspector-gadget: inspector-gadget イメージを v0.26.0 から v0.27.0 に更新 #18588
  • アドオン istio-provisioner: istio/オペレーター イメージを 1.21.0 から 1.21.1 に更新 #18644
  • アドオン metrics-server: metrics-server/metrics-server イメージを v0.7.0 から v0.7.1 に更新 #18551
  • CNI: キャラコを v3.27.0 から v3.27.3 に更新 #18206
  • CNI: フランネルを v0.24.4 から v0.25.1 に更新 #18641
  • Kicbase/ISO: ビルドキットを v0.13.0 から v0.13.1 に更新 #18566
  • Kicbase/ISO:containerd を v1.7.14 から v1.7.15 に更新 #18621
  • Kicbase/ISO: cri-dockerd を v0.3.3 から v0.3.12 に更新 #18585
  • Kicbase/ISO: crun を 1.14 から 1.14.4 に更新 #18610
  • Kicbase/ISO: docker を 25.0.4 から 26.0.1 に更新 #18485 #18649
  • Kicbase/ISO: nerdctl を 1.7.4 から 1.7.5 に更新 #18634
  • Kicbase: nerdctld を 0.5.1 から 0.6.0 に更新 #18647

プレリリース バージョンで発生した変更を含む、changelog の詳細については、CHANGELOG.md を参照してください。
