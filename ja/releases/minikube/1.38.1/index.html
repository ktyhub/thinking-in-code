Release Notes

バージョン 1.38.1 - 2026-02-19

機能

  • Kubernetes バージョン v1.35.1 (#22665) のサポートを追加

バグ修正

  • ロック ディレクトリに UID を追加することで、ロック ファイルのリグレッションを修正 (#22623)
  • systemd-binfmt をマスクすることで回帰クロスアーチ実行を修正 (#22621)
  • 修正: Windows 上の PowerShell カール エイリアスで resgistry.k8s.io 接続を確認する (#22659)

アドオン

  • アドオン クラウド スパナー: クラウド スパナー エミュレーター/エミュレーター イメージを 1.5.47 から 1.5.49 に更新 (#22637)
  • アドオン ヘッドランプ: ヘッドランプ イメージを v0.39.0 から v0.40.0 に更新 (#22640)
  • アドオン ingress: ingress-nginx/コントローラー イメージを v1.14.1 から v1.14.2 に更新 (#22595)
  • アドオン ingress: ingress-nginx/コントローラー イメージを v1.14.2 から v1.14.3 に更新 (#22638)
  • アドオン inspector-gadget: inspector-gadget イメージを v0.48.0 から v0.48.1 に更新 (#22592)
  • アドオン inspector-gadget: inspector-gadget イメージを v0.48.1 から v0.49.1 に更新 (#22634)
  • アドオン metrics-server: metrics-server/metrics-server イメージを v0.8.0 から v0.8.1 に更新 (#22596)
  • アドオン nvidia-device-plugin: nvidia/k8s-device-plugin イメージを v0.18.1 から v0.18.2 に更新 (#22531)
  • アドオン レジストリ: レジストリ イメージを 3.0.0 から 3.0.0 に更新 (#22593)
  • アドオン火山: 火山画像を v1.13.1 から v1.14.0 に更新 (#22597)
  • アドオン火山: 火山画像を v1.14.0 から v1.14.1 に更新 (#22663)
  • アドオン yakd: manusa/yakd イメージを 0.0.7 から 0.0.8 に更新 (#22639)
  • HA (マルチ コントロール プレーン): kube-vip を v1.0.3 から v1.0.4 に更新 (#22598)

CNI

  • CNI: 繊毛を v1.18.6 から v1.19.0 に更新 (#22636)
  • CNI: フランネルを v0.27.4 から v0.28.1 に更新 (#22635)
  • CNI: kindnetd を v20251212-v0.29.0-alpha-105-g20ccfc88 から v20260131-0806d083 に更新します (#22594)
  • CNI: kindnetd を v20260131-0806d083 から v20260213-ea8e5717 に更新します (#22661) プレリリース バージョンで発生した変更を含む、changelog の詳細については、CHANGELOG.md を参照してください。
