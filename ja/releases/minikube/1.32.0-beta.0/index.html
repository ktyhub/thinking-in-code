Release Notes

バージョン 1.32.0-beta.0 - 2023-10-27

特徴:

  • docker ドライバー用の新しい --gpus=nvidia フラグによる NVIDIA GPU サポート #15927 #17314 #17488
  • 新しい kubeflow アドオン #17114
  • 新しい local-path-provisioner アドオン #15062
  • Kicbase: --cpus および --memory フラグに no-limit オプションを追加 #17491

マイナーな改善:

  • Hyper-V: 奇数のメモリ検証を追加 #17325
  • QEMU: CPU タイプと IP 検出を改善 #17217
  • 起動出力から http(s)_proxy パスワードをマスクします #17116
  • --delete-on-faliure は、kubeadm の失敗に備えてクラスターも再作成します #16890
  • アドオンの自動一時停止: --auto-pause-interval #17070 を使用して間隔を設定します。
  • --kubernetes-version は、バージョン検証のために GitHub をチェックし、無効なバージョンのエラー出力を改善しました #16865

バグ:

  • QEMU: 有効にできないアドオンを修正 #17402
  • minikube リリース後の k8s バージョン用の間違った kubeadm イメージのダウンロードを修正 #17373
  • 存在しないクラスターでのアドオンの有効化と無効化を修正 #17324
  • コンテナーランタイムが存在しない場合の削除を修正 #17347
  • 新しい Docker バージョンで検出されないネットワークが見つからない問題を修正 #17323
  • アドオン レジストリが Minikube DNS ドメイン名設定に従っていないのを修正 (--dns-domain) #15585

バージョンのアップグレード:

  • バンプ Kubernetes バージョンのデフォルト: v1.28.3 および最新: v1.28.3 #17463
  • アドオン クラウド スパナ: クラウド スパナ エミュレータ/エミュレータ イメージを 1.5.9 から 1.5.11 に更新 #17225 #17259
  • アドオン ヘッドランプ: ヘッドランプ k8s/ヘッドランプ イメージを v0.19.0 から v0.20.1 に更新 #17135 #17365
  • アドオン ingress: ingress-nginx/コントローラー イメージを v1.8.1 から v1.9.3 に更新 #17223 #17297 #17348 #17421
  • アドオン inspector-gadget: inspector-gadget イメージを v0.19.0 から v0.21.0 に更新 #17176 #17340
  • アドオン istio-provisioner: istio/オペレーター イメージを 1.12.2 から 1.19.3 に更新 #17383 #17436
  • アドオン kong: kong イメージを 3.2 から 3.4.2 に更新 #17485
  • アドオン レジストリ: レジストリ イメージを 2.8.1 から 2.8.3 に更新 #17382 #17467
  • CNI: キャラコを v3.26.1 から v3.26.3 に更新 #17363 #17375
  • CNI: フランネルを v0.22.1 から v0.22.3 に更新 #17102 #17263
  • CNI: kindnetd を v20230511-dc714da8 から v20230809-80a64d96 に更新 #17233
  • Kicbase/ISO: ビルドキットを v0.11.6 から v0.12.2 に更新 #17194
  • Kicbase/ISO:containerd を v1.7.3 から v1.7.7 に更新 #17243 #17466
  • Kicbase/ISO: crictl を v1.21.0 から v1.28.0 に更新 #17240
  • Kicbase/ISO: docker を 24.0.4 から 24.0.6 #17120 #17207 に更新します。
  • Kicbase/ISO: nerdctl を 1.0.0 から 1.6.2 に更新 #17145 #17339 #17434
  • Kicbase/ISO: runc を v1.1.7 から v1.1.9 に更新 #17250
  • Kicbase: ubuntu:jammy を 20230624 から 20231004 にバンプ #17086 #17174 #17345 #17423 changelog の詳細については、CHANGELOG.md を参照してください。
