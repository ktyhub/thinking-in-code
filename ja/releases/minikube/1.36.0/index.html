Release Notes

バージョン 1.36.0 - 2025-05-22

特長

  • Kubernetes バージョン v1.33.1 #20784 をサポート
  • 新しいフラグ「-f」により、アドオンのconfigureコマンドに設定ファイルを渡すことができます。 #20255
  • vfkit: macOS 上の優先ドライバーにバンプ #20808
  • vfkit: vfkit ドライバー用の新しいネットワーク オプション「--network vment-shared」#20501

バグ修正:

  • macOS >= 15 #20400 での bootpd チェックを修正
  • ダッシュを含むプロキシ解析のバグを修正 #20648
  • 指定されたラベルを持つすべてのポッドが準備完了になるまで待機する問題を修正しました #20315
  • 修正: KIC フォーム github アセットのダウンロードに影響を与える不正な FinalImg #20316
  • 修正: スキーマ内の欠落ファイルの参照 (クローズ #20752) #20761 改善点:
  • 9p サポートの追加チェック #20288
  • vfkit: 停止時の正常なシャットダウン #20504
  • vfkit: より堅牢な状態管理 #20506
  • vfkit vmnet: sudoers 構成なしでの実行をサポート #20719
  • 「coredns ポッドで --wait が機能しない問題を修正」を元に戻す #20313
