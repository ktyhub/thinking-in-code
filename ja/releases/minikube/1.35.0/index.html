#ミニクベv1.35.0

📣😀 簡単な 5 つの質問からなるアンケート にご記入ください。これにより、minikube を使用する方法と理由、そしてどのような改善が必要かを知ることができます。ありがとう！ 💃🎉

#Release Notes

バージョン 1.35.0 - 2025-01-15

特徴:

  • --gpus=amd #19749 経由で AMD GPU のサポートを追加
  • KIC ベース イメージ #19464 の新しいフェイルオーバーとして Github アセットを使用します
  • 最新の Kubernetes v1.32.0 #20091 をサポート
  • kubeadm.k8s.io/v1beta4 のサポートを追加 (k8s v1.31 以降で利用可能) #19790

改善点:

  • nvidia-gpu-device-plugin と nvidia-device-plugin をマージします。 #19545
  • kicbase: nvidia パッケージを更新 #19738
  • cilium: k8s<v1.30.0 #19888 の appArmorProfile を削除
  • 自動一時停止: 設定後にサービスを再起動 #19900
  • 「MINIKUBE_HOME ロジックの変更」を元に戻す #20045
  • exitcode が存在しない場合、minikube プロファイル リストをエラーで汚染しないようにします #19728
  • 統合された minikube クラスター ステータス クエリ #18998
  • Vfkit ドライバー: macOS で失敗する TestMachineType を修正 #19726
  • nerdctld #19730 のアーチ制限がなくなりました
  • より堅牢な MAC アドレス マッチング #19750
  • docker コンテキスト エラー #19197 を解決する手順を追加

バグ修正:

  • coredns ポッドで --wait が機能しない問題を修正 #19748
  • --all を指定した名前空間にサービスがない場合のパニックを修正 #19957
  • CRI-O コンテナー ランタイムで KVM マシンを停止するときのタイムアウトを修正 #19758
  • lastStart.txt の長い行がログ出力に出力されない問題を修正 #19740
  • kicbase Arch を誤って検出する問題を修正 #19664

重大な変更:

  • arm64 kvm #19985 #20062 を削除します
  • Helm-Tiller アドオンを削除 #19636

言語:

  • 中国語の翻訳をさらに追加 #19490 #19508 #19718 #19962 #19772
  • フランス語の翻訳を改善 #19654 #19978
