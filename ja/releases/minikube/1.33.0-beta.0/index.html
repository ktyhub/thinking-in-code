#ミニキューブv1.33.0-beta.0

📣😀 minikube を使用する方法と理由、そしてどのような改善が必要かを知るために、簡単な 5 つの質問からなるアンケート にご記入ください。ありがとう！ 💃🎉

Release Notes

バージョン 1.33.0-beta.0 - 2024-03-26

特徴:

  • マルチ コントロール プレーンをサポート - HA クラスター --ha #17909
  • アドオン gvisor: arm64 サポートを追加 #18063 #18453
  • 新しいアドオン: YAKD - Kubernetes ダッシュボード アドオン #17775

マイナーな改善:

  • アドオンの自動一時停止: メモリ リークを削除し、設定可能な間隔を追加 #17936
  • イメージ ビルド: イメージの短縮名に docker.io/library を追加 #16214
  • cp: ディレクトリが存在しない場合は作成します #17715
  • ログ取得時のエラーをログ出力自体に移動 #18007
  • デフォルトの sysctls を追加して、機能のない特権ポートを許可します #18421
  • プリロード tarball に拡張属性を含める #17829
  • kubeadm.applyNodeLabels ラベルをすべてのノードに適用 #16416
  • ドライバーのステータスチェックを 20 秒に制限 #17553
  • systemd サービスの開始に失敗した場合は、journalctl ログを含めます #17659
  • ISO: CONFIG_DM_MULTIPATH #18277 を追加
  • ISO: arm64 に CONFIG_QFMT_V2 を追加 #17991
  • ISO: arm64 の CONFIG_CEPH_FS を追加 #18213
  • ISO: arm64 用の CONFIG_BPF を追加 #17206

バグ:

  • 「コンテナー ランタイムを有効にできませんでした: sudo systemctl restart cri-docker」を修正 #17907
  • 起動時に既存のイメージを再ダウンロードするcontainerdを修正 #17671
  • kvm2 がcontainerd プリロードを検出しない問題を修正 #17658
  • Docker binfmt 設定の変更を修正 #17830
  • 自動一時停止アドオンを修正 #17866
  • overlayfs ストレージ ドライバーでプリロードを使用しない問題を修正 #18333
  • 番号付きのサブドメインを許可しないイメージ リポジトリを修正 #17496
  • kvm2 を containerd で使用するときにクラスターが停止する問題を修正 #17967
  • kvm2 arm64 での複数のクラスターの起動を修正 #18241
  • arm64 Mac 上で Linux を使用した kvm2 クラスターの起動を修正 #18239
  • 存在しないクラスターを削除する際のエラー表示を修正 #17713
  • 再起動時に制限なしが尊重されない問題を修正 #17598
  • 初回起動後に追加されたノードに kubeadm.applyNodeLabels ラベルが適用されない問題を修正 #16416
  • ログの区切り文字出力を修正 #17734

バージョンのアップグレード:

  • バンプ Kubernetes バージョンのデフォルト: v1.29.3 および最新: v1.30.0-beta.0 #17786
