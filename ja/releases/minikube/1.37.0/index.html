Release Notes

バージョン 1.37.0 - 2025-09-09

ハイライト

新しい krunkit driver を使用して、Kubernetes の Macbook の GPU で AI ワークロードを実行します。 AI プレイグラウンド チュートリアル を始めましょう

特徴

  • Kubernetes v1.34.0 のサポートを追加 (#21439)
  • macOS で GPU アクセラレーションをサポートする krunkit ドライバーを追加 (#20826) チュートリアル
  • --memory の短縮形 -m を追加 (#20854)
  • NVIDIA GPU への OCI アクセスのサポートを docker ランタイムに追加 (#20959)
  • coredns ログを抑制するための --disable-coredns-log フラグを追加 (#20992)
  • 新しいアドオン: kubetail (#20345)
  • ドライバー: vfkit および krunkit の Virtiofs マウントのサポートを追加 (#21149)

改善点

  • ipv4 および Windows v0.0.4 用の ingress-dns アドオンを改善 (#21449)
  • iso: grub タイムアウトを無効にして VM の起動を 5 秒高速化します (#20895)
  • docker サービスの信頼性を向上させ、docker systemd ファイルを更新 (#21174)
  • --mount-string の使用に --mount の両方を必要とせず、デフォルトの mount-string を削除する (#21250)
  • サポートされている最も古い Kubernetes バージョンを更新 (#21490)
  • ライセンス cmd: 出力ディレクトリが存在しない場合でも失敗せず、最初に github アセットからダウンロードします (#21206)
  • 非推奨の proxy-refresh-interval v2 etcd フラグを削除 (#21278)
  • vmnet: krunkit のオフロードをサポート (#20831)
  • 非 KIC ドライバーに対して startKicServiceTunnel を呼び出さないでください (#20863)
  • krunkit: ネットワークを高速化するためにオフロードを無効にする (#21341)
  • HA (マルチ コントロール プレーン): kube-vip を v0.9.1 から v1.0.0 に更新 (#20999)(#21228)

減価償却費

  • 警告付きで HyperKit ドライバーを非推奨にする (#21024)

バグ修正

  • ダーティコミットバージョンを修正 (#21062)
  • Windows での minikube イメージのロードを修正 (#20529) (#20921)
  • 同じフォルダーにマウントすると入出力エラーが発生する問題を修正 (#21077)
  • 修正: アドオンに影響する YAML ファイル エスケープ エラーの問題 (#20904)
  • iso: vfkit および krunkit ドライバーで minikube stop を修正 (#21089)
  • iso: vfkit/krunkit のコンソールを修正 (#20832)

アドオン

  • アドオン nvidia-device-plugin: nvidia/k8s-device-plugin イメージを v0.17.2 から v0.17.3 に更新 (#21225)
  • アドオン クラウド スパナー: クラウド スパナー エミュレーター/エミュレーター イメージを 1.5.34 から 1.5.41 に更新 (#20976)(#21040)(#21243)(#21287)(#21359)(#21512)
  • アドオン ヘッドランプ: ヘッドランプ イメージを v0.28.0 から v0.34.0 に更新 (#21238)(#21508)
  • アドオン ingress: ingress-nginx/コントローラー イメージを v1.12.2 から v1.13.2 に更新 (#20909)(#21232)(#21353)(#21458)
  • アドオン inspector-gadget: inspector-gadget イメージを v0.40.0 から v0.44.1 に更新 (#20873)(#21038)(#21240)(#21462)(#21510)(#21358)
  • アドオン kong: kong イメージを 3.9.0 から 3.9.1 に更新 (#20966)(#21503)
  • アドオン kong: kong/kubernetes-ingress-controller イメージを 3.4.5 から 3.5.1 に更新 (#20908)(#20969)(#21034)(#21282)
  • アドオン kubevirt: bitnami/kubectl イメージを 1.33.1 から 1.33.4 に更新 (#20911)(#20939)(#21235)(#21283)(#21414)
  • アドオン metrics-server: metrics-server/metrics-server イメージを v0.7.2 から v0.8.0 に更新 (#21033)
  • アドオン レジストリ: レジストリ イメージを 3.0.0 から 3.0.0 に更新 (#21242)
  • アドオン火山: 火山画像を v1.11.2 から v1.12.2 に更新 (#20868)(#21351)
  • アドオン kubetail: アップデート バージョン 0.13.3 (#21244)

CNI バージョン

  • CNI: キャリコを v3.30.0 から v3.30.3 に更新 (#20871)(#20971)(#21416)
  • CNI: 繊毛を v1.17.4 から v1.18.1 に更新 (#20968)(#21226)(#21349)
  • CNI: フランネルを v0.26.7 から v0.27.0 に更新 (#20907)(#21230)(#21504)

基本イメージのバージョン

  • iso: 長期カーネルを 6.6.95 に更新 (#20995)
  • iso: x86_64 および aarch64 に対して VirtioFS を有効にする (#21147)
  • iso: ビルドとクリーンアップ構成を改善 (#20991)
  • Kicbase/ISO: cni-plugins を v1.7.1 から v1.8.0 に更新 (#21517)
  • Kicbase/ISO: crun を 1.19 から 1.23.1 に更新 (#21198)(#21330)
  • Kicbase/ISO: docker を 28.0.4 から 28.4.0 に更新 (#21053)(#21248)(#21488)
  • Kicbase: ubuntu:jammy を 20250415.1 から 20250819 にバンプ (#21233)(#21413)(#21505)

UI

  • 「minikube プロファイル リスト」をやり直して、詳細な詳細を --det に移動します… (#20544)
  • 設定フラグの長い説明を改善 (#21515)
  • スピナー ライブラリをリファクタリングし、スピン後にサブステップを非表示にする (#21215)
  • kubeadm init が失敗した場合に「create github issue」を 2 回表示しない (#21263)
  • テーブルのレンダリングをリファクタリング (#20893)

UI/翻訳

  • ギリシャ語翻訳を追加
  • 韓国語の翻訳をさらに追加 (#21467)(#21465)
  • フランス語の翻訳を追加 (#21050)(#20862)(#20945)(#20964)(#21156)(#21372)(#21514)
