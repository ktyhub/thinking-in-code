minikube v1.39.0

マイナー 公開日2026年9月2日 出典kubernetes/minikube 英語原文

#ミニクベv1.39.0

📣😀 簡単な 5 つの質問からなるアンケート にご記入ください。これにより、minikube を使用する方法と理由、そしてどのような改善を行う必要があるかを知ることができます。ありがとう！ 💃🎉

Release Notes

バージョン 1.39.0 - 2026-09-01

ハイライト

  • Kubernetes v1.36 および v1.37 のサポートを追加 (デフォルト: v1.37.0)
  • デフォルトのコンテナー ランタイムはcontainerdになりました
  • Traefik Helm ベースの Ingress アドオンを追加
  • VirtualBox ドライバーが Apple Silicon をサポートするようになりました (VirtualBox 7.1+)

機能

  • Kubernetes v1.36 および v1.37 (デフォルト: v1.37.0) のサポートを追加 (#23567、#23596)
  • Traefik Helm ベースのアドオンを追加 (#23225)
  • minikube ISO に Helm を追加 (#23420)
  • デフォルトのゲスト Helm client を Helm 4 (#23383) にアップグレードします。
  • VM ドライバー用の構成可能な DNS サーバーを追加 (#23069)
  • VM の起動ごとに mDNS を有効にする --mdns フラグを追加 (#22964、#23208)
  • ドライバー: 決定的な MAC アドレスを使用する (#23172)
  • vfkit: 利用可能な場合は vmnet 共有ネットワークを自動選択 (#23040)
  • virtualbox: VirtualBox 7.1+ で darwin/arm64 をサポート (#22861)
  • ISO: クラッシュ スタック トレース用に systemd-coredump を追加 (#23064)
  • ISO: knftables コンシューマーに対してカーネル nftables (CONFIG_NF_TABLES) を有効にする (#23518)
  • ISO: Calico 3.32.2 のセキュリティを有効にする (#23592)
  • ISO: aarch64 用の openvswitch カーネル モジュールをインクルード (#23151)
  • ISO: CONFIG_TASK_IO_ACCOUNTING および関連するカーネル オプションを有効にする (#23271)
  • インフラ: デフォルトとして GitHub から、フェイルオーバーとして GCS からプリロードをダウンロード (#23087)

パフォーマンス

  • ドライバー: VM ドライバーを並行して開始 (#23112)
  • krunkit ドライバーの --vmnet-offloading 開始フラグを追加 (#22962)
  • ssh: 外部 SSH には AES-GCM 暗号を優先します client (#23125)
  • ssh: SSH サーバーを待機するときに不必要なスリープを回避します (#23001)

バグ修正

  • アドオン: ゲスト VM 内の Helm 検証エラーを修正 (#23253、#23329)
  • ExtendWebSocketsToKubelet を無効にすることで、Kubernetes v1.36+ での cri-dockerd による kubectl exec を修正しました (#22921)
  • 無効な kubeadm 構成を生成する --extra-config=etcd.* を修正 (#23051)
  • マルチノード CNI 警告のロジックを修正。 (#22779)
  • SSH コマンドに対して SSHRunner ExitCode が常に 0 を返す問題を修正 (#23364)
  • minikube ノード コマンドの使用文字列を修正。 (#22775)
  • kvm: virsh を実行する前に libvirt グループのメンバーシップを確認する (#23369)
  • ポートを使用したレジストリ参照の保持タグを修正 (#23228)
  • ステータスタイムアウト時のゴルーチンリークを防ぐためにバッファリングされたチャネルを使用します (#23215)
  • フラグが明示的である場合にのみ virtualbox に対する警告を修正 (#22960)
  • イメージのロード: コンテナーで使用されるイメージをロードする際のサイレント エラーを修正 (#23034)
  • ノードの追加: ハードコードされた 2200MB (#23305) の代わりに、suggestMemoryAllocation を使用します。
  • プロキシ: RoundTripper ラッパーを歩いて内部のプロキシを削除します *http.Transport (#22910)
  • vmnet: Intel Mac 上の brew インストール パスを修正し、brew bin パスをサポート (#23039)
  • マウント: 双方向ファイアウォール ルールの必要性を明確にする (#20442)
  • ドライバー: macOS での DHCP リース処理の重複排除 (#23084)
  • ハック/アップデート: メジャー タグのトラック レジストリ アドオン (#23586)
  • ハック/アップデート: kong イメージ タグを 3 (#23585) にアップデート
  • ISO: nerdctl-bin Buildroot パッケージ ファイルのスペースをタブに置き換えます (#23438)
  • ISO: ISO ビルドの失敗を修正しようとしました (#22879)
  • ISO: ISO ビルド スクリプトの信頼性とエラー処理を修正 (#23218)
  • ISO: arm64 ホスト上での arm64 ISO のビルドのサポート (#22862)
  • ISO: ソースからビルドするのではなく、docker buildx にバイナリを使用します (#22942)

重大な変更

  • デフォルトのコンテナランタイムをcontainerdに変更 (#23562)
  • ISO/KIC: cri-dockerd のサポートを x86 および arm64 に制限し、cri-dockerd をコンパイル済みの GitHub バイナリに移行します (#22922)

アドオン

  • アドオンヘッドランプ: v0.40.0 から v0.45.0 にアップデート
  • アドオン火山: v1.14.1 から v1.15.1 へのアップデート
  • アドオン クラウドスパナ: 1.5.49 から 1.5.56 にアップデート
  • アドオンイングレス: v1.14.3 から v1.15.1 へのアップデート
  • アドオンイングレス: kube-webhook-certgen イメージを v1.6.7 から v1.6.9 に更新
  • アドオン インスペクター ガジェット: v0.49.1 から v0.55.1 にアップデート
  • アドオン kong: kong イメージを 3.9.1 から 3.9.3 に更新
  • アドオン kong: kong/kubernetes-ingress-controller イメージを 3.5.3 から 3.5.13 に更新
  • アドオン kubevirt: v1.7.0 から v1.9.0 にアップデート
  • アドオン メトリクス サーバー: v0.8.1 から v0.9.0 に更新
  • アドオン nvidia-device-plugin: v0.18.2 から v0.20.0 にアップデート
  • アドオン レジストリ: 3.0.0 から 3.1.1 に更新
  • アドオン yakd: 0.0.8 から 0.0.9 にアップデート
  • HA (マルチ コントロール プレーン): kube-vip を v1.0.4 から v1.2.3 に更新します。

基本イメージ

  • ISO: Buildroot を 2025.02.16 に更新します。
  • ISO: docker-buildx を v0.33.0 から v0.36.1 に更新します。
  • ISO: カーネルを 6.6.95 から 6.6.152 に更新します
  • Kicbase/ISO: ビルドキットを v0.26.3 から v0.32.2 に更新
  • Kicbase/ISO: cni-plugins を v1.9.0 から v1.9.1 に更新
  • Kicbase/ISO:containerd を 2.2.1 から 2.3.4 に更新します。
  • Kicbase/ISO: cri-dockerd を v0.4.1 から v0.4.3 に更新します。
  • Kicbase/ISO: crun を 1.26 から 1.29.1 に更新
  • Kicbase/ISO: 1.26.2 から 1.26.4 へのアップデート
  • Kicbase/ISO: nerdctl を 2.2.1 から 2.3.5 に更新
  • Kicbase/ISO: runc を v1.4.0 から v1.5.1 に更新します。
  • Kicbase: debian:bookworm を 20260202 から 20260713 にバンプします。

CNI

  • CNI: キャリコを v3.31.3 から v3.32.2 に更新
  • CNI: 繊毛を v1.19.0 から v1.20.1 に更新
  • CNI: フランネルを v0.28.1 から v0.28.9 に更新
  • CNI: kindnetd を v20260213-ea8e5717 から v20260820-69b56db7 に更新します。

ローカリゼーション

  • LANGUAGE=pt-BR (#23062、#23580) を通じてブラジル系ポルトガル語を追加します。

サイト

  • ドキュメント: AWS EC2 で minikube を実行するためのチュートリアルを追加 (#23017)
  • ドキュメント: トンネル記述リンクを修正 (#22389)
  • devic.es/dri を使用するように ai-playground.md リクエスト制限を修正 (#23152)
  • vmnet-helper ドキュメントのタイプミスを修正 (#22655) ※dashboard.md内の不要なカンマを削除(#23101)
  • コピーボタンとコードブロックの重複を修正 (#23443)
  • デプロイメント イメージ タグを v10 から v11 に更新 (#23060)
  • ハイパーキットを更新して非推奨に注意し、Apple Silicon ハイパーバイザーの代替品に注意してください (#23027)
  • minikube-machine を削除してロードマップを更新 (#22763)

所有者

  • nirs を minikube 承認者に追加 (#22936)
  • spowelljr を emeritus_approvers から reviewers に移動 (#23555)

テスト

  • テンプレート生成に etcd-extra-args.yaml を追加 (#23556) *containerd: TestPreload ユーザーイメージのチェックをスキップ (#23036)
  • 不安定な TestHelmInstall を修正: 最小バージョンの下限を使用 (#23326)
  • helm: エラー処理、型の安全性、テストの明確さを改善 (#23348)
  • golangci-lint v2.12.2 アップデートを修正し、正確なチェックサムを検証 (#23009)
  • golangci-lint: 最新バージョンですべての lint エラーを修正 (#23058)
  • ハック/プラウ: ドライバーを使用しない統合スクリプト (#22992) 用に、cri-dockerd を v0.4.3 に更新します。
  • lint: lint レベルを最小からデフォルトに変更 (#23011)
  • lint: golangci-lint ルールを強化し、Go の同時実行性、ソート、エラー処理を最新化します (#23015)
  • 不安定な統合テストをスキップして CI のブロックを解除 (#23137)
  • 開発のブロックを解除するには、TestAddons/Parallel/Registry をスキップします (#23049)
  • サイトのみの変更については無関係なワークフローをスキップ (#23133)
  • テスト: TestISOImage メモリと HelmVersion パスを修正 (#23527)
  • virtiofs: darwin 上でのみパッケージをビルドしてテストします (#23504)

ビルド

  • インフラ: 自動一時停止フック イメージ ビルドを追加し、船首に registry.k8s.io のターゲットをプッシュ (#23021)
  • インフラ: ステージング registry.k8s.io にビルドするためのストレージ プロビジョナー イメージ ターゲットを追加 (#22970)
  • インフラ: 再開可能なアップロードの競合を防ぐために、gsutil 状態ディレクトリを分離します (#23020)
  • インフラ: 船首画像ターゲットを独自のメイクファイルにモジュール化 (#23019)
  • インフラ: 船首イメージ内の gh cli のインストールを修正 (#22978)
  • インフラ: staging registry.k8s.io の KIC イメージ ビルドを修正 (#22973)
  • ハック/リリースノート: changelog.go の GITHUB_TOKEN をエクスポート (#23602)

リファクタリング

  • リファクタリング: linuxNodeProvisioner を使用した NodeProvisioner インターフェイスの追加 (#23319)
  • リファクタリング: ループ内の分割をより効率的な SplitSeq に置き換えます (#23033)
  • リファクタリング: スライス.Contains を使用してコードを簡素化します (#23221)
  • リファクタリング: 組み込みの最大値/最小値を使用してコードを簡素化します (#23384)
  • for ループ内の冗長な変数宣言を削除 (#23113)
