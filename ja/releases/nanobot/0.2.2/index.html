#ナノボットv0.2.2

🐈 nanobot v0.2.2 が登場 — 140 人の PR が統合され、21 人の新しい貢献者が加わりました。エージェントがさらに強くなった！

見出しは耐久性です。 WebUI の会話は、現実の生活の中でより多く存続するようになりました。トランスクリプトは 1 つの壊れやすいファイルに保存されるのではなくセグメント化され、分岐されたチャットは返信をより確実に保存し、アクティブなターンはより予測可能にスクロールして再生し、起動パスのブロックが少なくなり、ゲートウェイのシャットダウンがより穏やかになります。長時間のセッション、古いプロバイダー、遅いルート、壊れた設定ファイル、不正な形式の履歴、ストリームの停止、空のプロバイダーの応答などすべてが作業を妨げる可能性が低くなりました。

2 番目のストーリーは、ナノボットが本物の Python ランタイムになるです。 SDK は、もはやエージェント ループの周りの単なる薄い便利な層ではありません。同時 run() 呼び出しは分離され、フックはよりクリーンになり、MCP ライフサイクル処理はより安全になり、ランタイム制御はより広範になり、ドキュメントでは SDK を第一原理から説明するようになりました。独自のアプリケーション内に nanobot を埋め込みたい場合、v0.2.2 は、そのパスが意図的であると感じられる最初のリリースです。

3つ目のストーリーは、作業台が広くなり、暮らしやすくなるです。 WebUI は、自動化管理、プロンプト ナビゲーション、トークン使用状況の可視化、モバイル機能の強化、更新チェックの改善、アクティビティ タイミングの強化、および設定画面の高速化を実現しました。エコシステムは、キーレス Web データ アプリとしての Firecrawl、Exa / Bocha / Keenable / Volcengine 検索、より多くの文字起こしプロバイダー、カスタム画像生成、Mistral と Kim の処理の改善、および Telegram、Feishu、WhatsApp、Slack、Email、QQ、DingTalk などにわたる多くのチャネル修正によって拡張されました。

ハイライト

  • より耐久性の高い WebUI セッション — セグメント化されたトランスクリプト ストレージにより、古いターンを破棄することなく大規模な会話を読みやすく保ち、フォーク/リプレイ パスによりアシスタントの応答をより確実に保持し、セッションの削除によりレガシー ファイルがクリーンアップされ、更新によって古いコンテンツが復活しなくなり、モデルが動作している間アクティブなターンは固定されたままになります。 WebUI には、プロンプト ナビゲーション、改善されたモバイル レイアウト、より明確なアクティビティ期間、トークン使用量のレンダリング、より安全な起動フェッチ、およびオンデマンドのバージョン チェックも追加されました。

  • **ファーストクラスのランタイムとしての Python SDK - SDK には、より安全な同時 run() 動作、明示的なランタイム制御、よりクリーンな実行ごとのフック処理、より優れた MCP クリーンアップ、改善されたファサード ライフサイクル動作、およびより初心者向けのドキュメントが追加されました。これにより、ナノボットをスクリプト、サービス、評価、カスタム エージェント製品に簡単に組み込むことができます。

  • ゲートウェイとオンボーディングの洗練 - ゲートウェイは、バックグラウンド/サービス制御、よりクリーンなフォアグラウンド シャットダウン、より安全な Ctrl+C 動作、より優れた MCP stdio クリーンアップを獲得しました。オンボーディング フローは、プロバイダー優先のクイック スタート、より中立的なプロバイダーの選択、より安全な WebUI セットアップ、WebSocket 障害時のロールバック、およびキーボード ナビゲーションの改善を中心に簡素化されました。

  • 検索、音声、プロバイダーの対象範囲 — Web 検索は、Firecrawl、Exa、Bocha、Keenable、および Volcengine のパスを対象とするようになりました。共有音声入力に加え、OpenRouter、StepFun、SiliconFlow、Xiaomi MiMo、AssemblyAI のサポートにより文字起こしが拡張されました。プロバイダーは、より優れた Mistral 推論処理、Kimi K2.7 思考、OpenAI 互換のクエリ/ボディ コントロール、カスタム イメージ生成、OpenAI イメージ編集、より安全な Anthropic ツール ID、より強力な再試行/フォールバック動作を実現しました。

  • エージェント コア全体の信頼性の強化 — 最近の履歴コンテキストはトークンキャップされており、アイドルの自動圧縮はデフォルトでオンになっており、Dream は空の実行を説明し、不正な履歴はスキップされ、履歴カーソルは単調なままで、ツール スキーマの推定値はキャッシュされ、未知の組み込みツール パラメーターは拒否され、プロバイダーのフォールバックは主要なエラーをログに記録し、ストリームの停止は切り捨てられた応答を返さずに再試行またはフォールバックできます。

  • 実際のアプリのように動作するチャネル — Telegram は、より安全なフォールバック検出により、より豊富なメッセージ サポートを獲得しました。 Feishu は、ストリーミング回復、WebSocket カード読み取り、テーブル抽出、SDK の遅延ロード、および QR ログインを実現しました。 WhatsApp は開封確認、転送メッセージの処理、LID マッピングを取得しました。 Slack の許可リストに登録されているチャネルにはメンションが必要な場合があります。電子メールは添付ファイルと IMAP ポストアクションを取得します。 QQ / Napcat、DingTalk、Weixin、Matrix などは対象を絞った修正を受け取りました。

  • セキュリティとワークスペースの境界 — 安全でない MCP HTTP URL はプローブする前に拒否され、ローカル プロバイダー エンドポイントは env プロキシをバイパスしますが、クラウド エンドポイントは依然としてそれらを尊重し、ワークスペースの書き込みポリシーがより明確になり、git コマンドはパス ガードを緩めることなくワークスペースのサブディレクトリから動作し、bwrap は正常な HOME を取得し、ストリップされたイメージ入力が誤解を招くローカル パスを漏らすことはなくなりました。

コミュニティ

v0.2.2 を出荷してくださった皆様、140 名の PR、21 名の初めての寄稿者、そして多くの慎重なレビュー作業に多大な感謝を申し上げます。このリリースは、1 つの大きなスイッチというよりも、安定したセッション、よりクリーンな拡張ポイント、より幅広いプロバイダー、そして実際の作業が長くなった場合の鋭いエッジの減少など、nanobot を毎日オープンし続けるのに十分な信頼性を実現することに重点を置いています。
