nanobot v0.1.4.post4

パッチ 公開日2026年3月8日 出典HKUDS/nanobot 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#ナノボットv0.1.4.post4 🐈 nanobot v0.1.4.post4 が登場 — 58 人の PR が統合され、29 人の新しい寄稿者、そしてコミュニティからの「たくさん」の現実世界の洗練が加わりました。 このリリースは大きなものです。デフォルトの安全性の向上、マルチインスタンスのサポートの向上、MCP/ツールの信頼性の強化、および Telegram、Feishu、QQ、DingTalk、Discord、WhatsApp、Matrix などにわたる大幅な改善が行われています。このサイクルでは、大量の鋭利なケースがクリーンアップされました。このような修正により、nanobot は日々より安定したものになっていると感じられます。

ハイライト

  • デフォルトでより安全 — アクセス制御がより厳格になりました。このリリースには、実際の認証バイパスの修正と、allowFrom に関するデフォルトの処理の強化が含まれており、すぐに使用できるデプロイメントがより安全になります。 (#1403、#1677)
  • マルチインスタンス サポートがついに実現 — --config サポートが導入され、ランタイム パス処理がクリーンアップされ、CLI エージェントは --workspace / --config もサポートするようになりました。個別のボット、テナント、または環境を実行することがはるかに簡単になりました。 (#1581、#1635)
  • MCP がさらに厳しくなりました — SSE トランスポートのサポートが導入され、自動検出がよりスマートになり、キャンセルや奇妙なエラーが発生したときに MCP ツール呼び出しによってプロセスがダウンする可能性が大幅に低くなります。 (#1488、#1728)
  • ツールがさらに寛容になりました — ツール パラメータの自動キャスト、より安全な検証、適切な日時処理、read_file サイズ制限はすべて、ツールや入力がおかしくなった場合でも nanobot が失敗することを軽減するのに役立ちます。 (#1610、#1507、#1508、#1511)
  • プロバイダー サポートは拡大し続けています — Azure OpenAI サポートが開始され、Alibaba Cloudcoding Plan API サポートが導入され、プロンプト キャッシュ アフィニティ ヘッダーが追加され、GitHub Copilot / Codex の互換性が向上し続けています。 (#1618、#1563、#1428、#1555、#1637、#1525)
  • Cron がより堅牢になりました — 外部 jobs.json の変更が尊重され、ジョブ コンテキストの処理が改善され、cron ジョブは再帰的により多くの cron ジョブを永久にスケジュールすることができなくなりました。 (#1371、#1375、#1399、#1458)
  • コンテキストがよりクリーンになりました — 連続するユーザー メッセージはプロバイダー側のエラーを回避するためにマージされ、内部推論はユーザー向けの進行状況の更新から隠蔽され、画像の MIME 検出の信頼性が向上し、プロンプト/プラットフォームのガイダンスがより洗練されました。 (#1456、#1655、#1573、#1579)
  • Telegram は多くの支持を得ています — プロキシ処理が修正され、グループ トピックがサポートされ、/stop の動作が向上し、ストリーミング メッセージが配信され、汎用ドキュメントが適切なファイル拡張子を保持するようになりました。 (#1535、#1476、#1482、#1660、#1522、#436)
  • Feishu は改良を続けています — リッチ テキストの解析、テーブル/カードの分割、よりスマートな形式の選択、Groq Whisper の文字起こし、オーディオ/ビデオの互換性修正、よりクリーンなイベント処理がすべてこのリリースに組み込まれています。 (#1361、#1384、#1648、#1605、#1531、#1594、#332、#1568)
  • チャネルの増加、洗練の強化 — DingTalk グループ チャット サポート、QQ グループの処理とマークダウン送信、Discord グループ ポリシー + 添付ファイル、WhatsApp メディア サポート、Slack フォールバック修正、および Matrix メディア正規化はすべて採用されました。 (#1467、#532、#1727、#553、#1613、#1638、#673、#1406)
  • クロスプラットフォームの安定性の向上 - Windows の信号処理が改善され、インポート/依存関係の欠落が減り、テストがよりクリーンになり、nanobot がさまざまな環境で適切に動作するという全体的な信頼性が向上しました。 (#1598、#1485、#1533、#1546、#1339、#1521)

コミュニティ

このリリースの 29 人の新しい貢献者を大歓迎します。チャネル、プロバイダー、ツール、ドキュメント、インフラストラクチャ全体でナノボットに参加して改善していただいた皆様に感謝します。このような貢献のおかげで、このプロジェクトはさらに良くなり続けています。
