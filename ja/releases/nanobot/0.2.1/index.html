#ナノボットv0.2.1

🐈 nanobot v0.2.1 が登場 — 84 人の PR が統合され、17 人の新しい貢献者が加わりました。エージェントは本物の作業台を手に入れました。

見出しは WebUI が実際に仕事が行われる場所になるです。チャット サーフェスはよりスムーズで、高速で、trust が簡単になりました。ライブ ファイル編集がアクティビティとして表示され、ツール トレースがよりきれいにレンダリングされ、ソース リンクが読みやすいファビコンを取得し、マークダウンとコード ブロックの動作が向上し、新しいチャットが更新され、思考/応答の順序がモデルの実際のターン構造と一致するようになりました。設定、サイドバー コントロール、モデル切り替え、コンテキスト ウィンドウ コントロール、スラッシュ コマンド、プロジェクト ワークスペース、およびアクセス モードはすべて、単一の一貫したコントロール サーフェスに近づきました。

2 番目のストーリーは、長期にわたる作業の耐久性が向上しているです。継続的な目標によってランナーがつまずくことはなくなり、目標のイテレーション バジェットが増加し、セッション ロックにより重複するターンが互いに踏み外されるのが防止され、AutoCompact と統合のレースが修正され、ハートビートが cron に移動され、セッション アーカイブの保持でいくつかのデータ損失が修正されました。実際には、これは、不可解な中断が減り、アーカイブの重複が減り、長いエージェント ワークフローが意図した流れを維持できる可能性が大幅に高まることを意味します。

3 番目のストーリーは、ナノボットを実際のスタックに簡単に接続できるようになるです。 CLI アプリと MCP は、より統合された拡張パスを共有するようになりました。プリセットのセットアップと機能に関する言及により、ツールを見つけやすくなります。拡張レジストリは統合に第一級のホームを与えます。プロバイダーの対象範囲は、Ant Ling、Skywork、Novita、Step Plan、StepFun、Zhipu イメージ生成、OpenAI/Codex イメージ生成、Ollama イメージ生成、およびより豊富な OpenAI 互換構成にわたって拡大されました。 Signal、Telegram Webhook モード、Discord モデルのスラッシュ コマンド、Matrix 検証の修正、より安全な Weixin / Teams / Matrix の動作により、チャネルも成長しました。

ハイライト

  • 日常のワークベンチとしての WebUI — WebUI はもはや単なるパッケージ化されたチャット サーフェスではありません。アクティビティのレンダリングが向上し、ライブ ファイル編集の可視性が向上し、ソース リンクがよりクリーンになり、マークダウン/コード レンダリングが強化され、サイドバーのパフォーマンスが向上し、プロジェクト ワークスペース、アクセス コントロール、コンテキスト ウィンドウの設定、モデル コントロール、スラッシュ コマンド アクション、およびより洗練されたネイティブ ホストの操作感が実現しました。最後の思考/応答順序修正により、ストリーミングされたエージェントの作業が実際に発生した順序で読み取られるようになります。 (#3877、#3899、#3906、#3951、#3953、#3987、#4007、#4045、#4108、#4121、#4137)

  • 長期実行エージェントの安定性 — ゴール モードとマルチターン作業がより堅牢になりました。持続的なゴールによりランナーは生存し続け、ゴールのイテレーション バジェットが拡張され、process_direct にはセッションごとのロックが追加され、ストリーミング/セッションの同時実行バグが強化され、AutoCompact とコンソリデーターのレースが修正され、アーカイブの保持によってアーカイブの重複とメッセージの損失が回避されるようになりました。 (#3881、#3999、#4041、#4104、#4127、#4129)

  • CLI アプリ、MCP、および拡張機能のワークフロー - CLI アプリは、CLI ネイティブ ツールを接続する方法として導入され、プリセット セットアップ、機能の言及、古いインストールの回復、レジストリ ロゴ、および拡張レジストリ ソースを通じて MCP の概念と統合されました。その結果、「便利なローカル ツールがある」から「nanobot がワークフローでそれを呼び出せる」までの道筋がより明確になります。 (#3963、#3979、#3991、#4046)

  • より多くのプロバイダー、より豊富なモデル ルーティング — Ant Ling、Skywork、Novita、Step Plan、OpenAI API タイプ選択、extraBody、および StepFun、OpenAI/Codex、Ollama、Zhipu を含む複数の画像生成プロバイダーにより、プロバイダーの対象範囲が拡大しました。いくつかのフォローアップ修正により、ツール呼び出し ID が保存され、クォータ/請求エラーが改善され、プロバイダーのトランスポート エッジ ケースが処理され、OpenAI 互換ルート全体で思考/推論制御が正直に保たれます。 (#3900、#3910、#3916、#3927、#3946、#3954、#3971、#3974、#3984、#3988、#4048)

  • チャネルと展開の洗練 — シグナルのサポート、Telegram Webhook モード、Discord モデルのスラッシュ コマンド、Docker/WebUI 展開の修正、およびより明確な秘密/展開ドキュメントにより、ローカル ターミナルの外で nanobot を実行しやすくなります。ゲートウェイのコールド スタートも、数秒から 1 秒未満の領域まで劇的に低下しました。 (#3872、#3918、#3935、#3996、#4031)

  • セキュリティと信頼性の強化 — WebSocket トークンの発行には認証が必要になり、Web フェッチの前にリダイレクト ターゲットが検証され、IPv6 マップされた IPv4 アドレスが SSRF チェックで正規化され、Teams が trust サービス URL に応答し、Matrix インバウンド メディア ダウンロードが制限され、Windows および URL を多用するコマンドでのシェル/実行動作が強化されました。 (#3928、#3933、#4051、#4086、#4103、#4106、#4047)

  • 国際化とドキュメント - WebUI ロケール セットは zh-TW、ja、および残りのキーに渡って入力され、README の位置とニュース セクションが更新され、多言語のドキュメント リンクが表示され、ローカル プロバイダーのセットアップが見つけやすくなり、AGENTS.md によりコーディング エージェントがリポジトリへの明確な方法を提供します。 (#3930、#3962、#3964、#4131)

コミュニティ

v0.2.1 を発送してくださった皆様、84 人の PR、29 人の寄稿者、そして 17 人の初めての寄稿者を温かく歓迎します。このリリースは、大きな機能が 1 つ追加されたというよりは、nanobot が 1 日中オープンしておくことができる、より安定して、より明確で、拡張がより簡単になったものになっているように感じられます。
