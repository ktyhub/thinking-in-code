nanobot v0.1.4

パッチ 公開日2026年2月18日 出典HKUDS/nanobot 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#ナノボットv0.1.4 🎉 🐈 nanobot コミュニティからのもう 1 つの大きなリリース — すべての貢献者、特に 18 人の新しい貢献者に感謝します。 このリリースでは、MCP ツール サーバーのサポート、ユーザーがエージェントの動作を実際に確認できるリアルタイムの進行状況ストリーミング、および一連の新しいプロバイダー (カスタム OpenAI 互換、GitHub Copilot、OpenAI Codex、SiliconFlow) が追加されています。チャンネルも多くの愛を受けています。Telegram はメディアのアップロードと長いメッセージを処理できるようになり、Slack は適切な mrkdwn とスレッド返信を備え、Feishu はリッチ テキストをサポートします。また、1 コマンドでデプロイできるように Docker Compose を追加し、セッションの範囲をワークスペースに限定し、完全な LLM 応答解析のために json_repair に切り替えました。沈黙を減らし、プロバイダーを増やし、チャネルを改善する — それがナノボットのやり方です。

ハイライト

  • MCP サポート — モデル コンテキスト プロトコル (#554) 経由で外部ツール サーバーに接続
  • 進行状況のストリーミング — エージェントはマルチステップ ツールの実行中に何を行っているかを表示します (#802)
  • 新しいプロバイダー - カスタム OpenAI 互換エンドポイント、GitHub Copilot、OpenAI Codex、SiliconFlow (#786、#720、#312、#151、#630)
  • チャネルの改善 — Telegram メディアのアップロードとメッセージ分割、Slack スレッドの返信と mrkdwn、Feishu リッチ テキスト (#747、#694、#717、#784、#629、#593)
  • Docker Compose — 1 つのコマンドによる展開 (#765)
  • ワークスペース スコープのセッション — 従来の移行によりセッションがワークスペース内に存在するようになりました (#713)
  • 堅牢な JSON 解析 — 不正な形式の LLM 応答を処理するための json_repair (#664)

何が変わったのか

  • https://github.com/HKUDS/nanobot/pull/593の@C-Liによるフェイシュカード情報のマークダウンタイトル表示の最適化
  • 功績: https://github.com/HKUDS/nanobot/pull/604 の @Re-bin によるカスタム プロバイダーと非破壊オンボードの追加
  • https://github.com/HKUDS/nanobot/pull/583 の @lukemilby によるオンボーディング機能のアップグレード
  • 修正: バグ #370、https://github.com/HKUDS/nanobot/pull/560 の @wymcmh による温度設定をサポート
  • 修正: https://github.com/HKUDS/nanobot/pull/590 の @chengyongru によるキャッシュ有効期限の問題関連の修正
  • フェイシュのリッチ テキスト コンテンツ受信のサポートを追加します。 @C-Li 著、https://github.com/HKUDS/nanobot/pull/629
  • 修正(プロバイダー): https://github.com/HKUDS/nanobot/pull/617 の @themavik によって LiteLLM を呼び出す前に max_tokens を >= 1 にクランプします
  • https://github.com/HKUDS/nanobot/pull/625 の @C-Li により、corn がタイムゾーン設定を無視してデフォルトでローカルタイムゾーンを自動的に使用する問題を修正
  • 特技(ツール): https://github.com/HKUDS/nanobot/pull/554 の @SergioSV96 による mcp サポートを追加
  • 修正: https://github.com/HKUDS/nanobot/pull/664 の @Re-bin による堅牢な LLM 応答解析に json_repair を使用する
  • https://github.com/HKUDS/nanobot/pull/151 に @pinhua33 による OpenAI Codex OAuth ログインとプロバイダーのサポートを追加
  • https://github.com/HKUDS/nanobot/pull/704 の @alekwo による Markdown を Slack の mrkdwn フォーマットに修正/変換
  • 修正(テレグラム): https://github.com/HKUDS/nanobot/pull/701 の @TomLisankie による sender_id にユーザー名が欠落しているため、スラッシュ コマンドがアクセス チェックに失敗する
  • 修正 (電報): https://github.com/HKUDS/nanobot/pull/694 の @zhouzhuojie による「メッセージが長すぎます」エラーを回避するために長いメッセージを分割しました。
  • スラック: https://github.com/HKUDS/nanobot/pull/717 の @xek による mrkdwn フォーマットを適切に行うために、slackify-markdown を使用します。
  • 功績: https://github.com/HKUDS/nanobot/pull/758 の @Re-bin による ClawHub スキルを追加
  • 修正(cron): https://github.com/HKUDS/nanobot/pull/744 の @jcpoyser による cron スケジュールのタイムゾーンを保持
  • 功績: https://github.com/HKUDS/nanobot/pull/720 の @DaryeDev により、プロバイダーとして GitHub Copilot を追加
  • 修正: https://github.com/HKUDS/nanobot/pull/748 の @zhuhui-in によるアシスタント メッセージで空のコンテンツ エントリを送信しないようにする
  • 特技: https://github.com/HKUDS/nanobot/pull/747 の @DaryeDev により、エージェントがメディア ファイル (音声、写真、ドキュメント) をテレグラム チャネルにアップロードできるようにします
  • 修正(config): mcpServers 環境変数は、https://github.com/HKUDS/nanobot/pull/766 の @fyhertz によってスネークケースに変換されるべきではありません
  • CLI エージェントで Cron ツールを有効にします。 @DaryeDev 著、https://github.com/HKUDS/nanobot/pull/746
  • 功績: https://github.com/HKUDS/nanobot/pull/765 の @srajasimman による簡単なデプロイメントのための Docker Compose サポートの追加
  • 功績: https://github.com/HKUDS/nanobot/pull/786 の @Re-bin による openai 互換の直接サポートを備えたカスタム プロバイダーを追加
  • スラック: https://github.com/HKUDS/nanobot/pull/784 の @hyud Ryu による設定に ReplyInThread ロジックとカスタム反応絵文字を追加しました
  • [追加] https://github.com/HKUDS/nanobot/pull/312 における @jeroenev による GitHub 副操縦士のサポート
  • 機能: https://github.com/HKUDS/nanobot/pull/630 に @mtics による SiliconFlow プロバイダーのサポートを追加
  • セッション ストレージのスコープをワークスペースに設定 (レガシー フォールバックを使用) by @kiplangatkorir (https://github.com/HKUDS/nanobot/pull/713)
  • 機能: https://github.com/HKUDS/nanobot/pull/802 の @Re-bin によるツール実行中に中間の進行状況をユーザーにストリームする
