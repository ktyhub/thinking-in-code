nanobot v0.1.5

パッチ 公開日2026年4月6日 出典HKUDS/nanobot 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#ナノボットv0.1.5 🐈 nanobot v0.1.5 が登場 🎉 — 66 人の PR が統合され、27 人の新しい貢献者が加わり、独自のホームを備えた最初のリリースがリリースされました。 nanobot の公式 Web サイト nanobot.wiki が開設され、英語、中国語、日本語、韓国語、スペイン語、フランス語の多言語ドキュメントが用意されたことを発表できることを嬉しく思います。これを構築することで、私たちがこれを行う理由を思い出しました。nanobot は常にオープンソース コミュニティに属しており、自分の言語を話す適切なホームが時代遅れに感じられました。 すべてのドキュメント ページ、すべての翻訳、すべての例はオープンであり、すぐに投稿できます。それは変わりません。 さて、リリース自体について。 v0.1.4.post6 が基礎を解体することであるとすれば、v0.1.5 は建物を住みやすいものにすることです。エージェントは、正気を失うことなく何時間も実行できるようになりました。メモリは適切なアーキテクチャを採用しました。そして実稼働環境でのナノボットの実行は「可能」から「快適」になりました。これは、nanobot がプロトタイプであることをやめ、インフラストラクチャになり始めるリリースです。

ハイライト

  • 長時間実行されるタスクの信頼性が向上 — 長時間実行されるタスクは、徹底的な信頼性パスを受け取りました。ランタイムは孤立したサブプロセスなしで CancelledError を処理するようになり、再試行分類では regex-on-error-text の代わりに構造化エラー メタデータが使用されます (そのため、レート制限による待機と再試行中に 429 クォータの枯渇は直ちに停止します)。要求の増幅を防ぐために SDK レベルの自動再試行が無効になり、Azure の再試行は二重底にならなくなりました。エージェントが cron ジョブを実行したり、ツールを夜間に調整したり、バースト的なトラフィックを処理したりする場合、これはそれらのセッションを継続させるリリースです。 (#2733、#2762、#2759、#2761、#2765)
  • 記憶はアーキテクチャを取得 — 夢との出会い — 新しい 2 段階記憶システムは、ライブの会話履歴を統合された長期知識から分離します。 Dream はバックグラウンド統合パスとして実行されます (エージェントが学習した内容を基にスリープしていると考えてください)。Git バージョン管理されたストレージによってバックアップされているため、すべてのメモリ状態が回復可能です。レガシー HISTORY.md ファイルは自動的に移行されます。 Jinja2 テンプレートは Dream とともに導入され、エージェントが応答とメモリの要約をどのように形成するかを制御できるようになりました。これは追加された機能ではなく、ナノボットが最初から備えているはずだったメモリ システムです。 (#2717、#2779、および 10 個以上のフォローアップ強化コミット)
  • 運用環境でのナノボットの実行が現実になりました — exec 呼び出しは bwrap 経由でサンドボックス化され、コンテナーはデフォルトで非 root として実行されます。実行ツールはホスト環境変数を LLM に漏らさなくなりました。 API ポートはデフォルトでローカルホストにバインドされます。構成シークレットは ${VAR} 補間をサポートしているため、キーを再度ハードコーディングする必要はありません。新しい nanobot-api Docker サービスは、すぐに使える独立した OpenAI 互換エンドポイントを提供します。 WhatsApp ブリッジは自動ローカル認証を取得しました。これらは魅力的な変更ではありません。導入後に一晩中眠れるようになるのはこのためです。 (#1940、#2831、#2830、#2841、#2715)
  • 3 つの新しいプロバイダーと GPT-5 が準備完了 — GPT-5 モデル ファミリのサポートは、適切な温度処理とともに実現しました。 Xiaomi MiMo は、オンデバイス推論ファンのために加わりました。 Baidu Qianfan が中国のエコシステムに登場しました。 Dashscope と ModelArk は適切な思考パラメータ制御を取得しました。また、reasoning_content (DeepSeek-R1、Kimi、MiMo からの思考連鎖) は、完全なメッセージ パイプラインを通じて表示され、保存されるようになりました。 nanobot はモデルがどこにいてもユーザーと出会い続けます。 (#2788、#2495、#2811、#2840、#2770)
  • チャネルは改善され続けています — 電子メールは、MIME フィルタリングとファイル名のサニタイズを使用して添付ファイルを抽出するようになりました。 WhatsApp は Groq/OpenAI Whisper 経由で音声転写を取得しました。 Feishu は処理後に反応を自動的に削除し、ビデオのダウンロードをサポートします。 Telegram はツール ヒントを折りたたみ可能なブロック引用符としてレンダリングし、DM スレッドをサポートし、特大のストリーミング返信を分割します。 WeChat のマルチモーダル連携は継続されました。 Langfuse の統合により、運用環境の可観測性が実現されました。また、/status では、Web 検索プロバイダーの使用状況とキャッシュ ヒット率が表示されるようになりました。 (#2815、#2530、#2812、#2810、#2793、#2520、#2659、#2832、#2703)
  • 開発者エクスペリエンスを静かに - 組み込みの grep および glob ツールにより、エージェントはネイティブ コードを検索できます。 Tool クラスは、パラメーターに適切な JSON スキーマを使用してリファクタリングされました。 Python SDK ファサードにより、プログラムによるセッションごとの分離が可能になります。 CLI は、マルチインスタンスセットアップ用に --config を追加しました。 Web 検索は、トグル コントロールを備えた WebToolsConfig に統合されました。そして、テスト スイートは 1,142 のテストに増加し、すべて緑色でした。 (#2754、#2780、#2653、#2740、#2643)

コミュニティ

このリリースで初めて貢献した 27 人の新しい貢献者 へようこそ。 v0.1.5 は、単純な信念によって形作られています。AI エージェント フレームワークは、機能を追加することでではなく、金曜日の夜に無人で実行するようなソフトウェアであることで trust を稼ぎます。忘れられない記憶。再試行しても増幅されません。漏れないサンドボックス。境界を強化したり、競合状態を発見したり、テストを追加したすべての貢献者は、昨日よりも今日のナノボットをさらに trust に値するものにしました。それが重要な唯一の指標です。 フル Changelog: https://github.com/HKUDS/nanobot/compare/v0.1.4.post6...v0.1.5
