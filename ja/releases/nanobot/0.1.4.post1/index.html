nanobot v0.1.4.post1

パッチ 公開日2026年2月21日 出典HKUDS/nanobot 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#ナノボットv0.1.4.post1 🎉 🐈 nanobot コミュニティからのもう 1 つの大きなリリース — すべての貢献者、特に 19 人の新しい貢献者に感謝します。 このリリースでは、Feishu、Slack、Discord にわたるチャネルの大幅な改善、新しいプロバイダー、プロンプト キャッシュ、および重要なエージェント ループのリファクタリングが行われています。より信頼性が高く、より機能的で、よりスリムなコード 😄。

ハイライト

  • Feishu Media — ボットが画像、音声、ファイルを送受信できるようになりました (#844、#922)
  • Slack メディア アップロード — エージェントからファイルを直接送信します (#904)
  • Discord の長いメッセージ — 2000 文字を超えるメッセージを自動的に分割します (#900)
  • VolcEngine プロバイダ — 新しい LLM プロバイダのサポート (#812)
  • プロンプト キャッシング — コスト削減のための Anthropic および OpenRouter のキャッシュ コントロールのサポート (#854、#905)
  • MCP 認証ヘッダー — 認証された MCP サーバーのカスタム HTTP ヘッダー (#807)
  • テレグラムの改善 — 構成可能な返信動作、/help は ACL をバイパスします (#879、#824)
  • CLI サブエージェント サポート — CLI はメッセージ バスを介してルーティングされるようになり、完全なサブエージェント サポートが有効になります (#908)
  • 信頼性の高いメモリ — メモリ統合では、脆弱な JSON 解析の代わりに構造化されたツール呼び出しを使用します (#866)
  • 無駄のないエージェント ループ — メモリ ロジックの抽出、冗長メソッドのマージ、行数の 31% 削減 (#930)
  • よりスマートなファイル編集 — old_text が一致しない場合に edit_file で差分が表示されるようになりました (#921)
  • バグ修正 — MCP 再接続、セッション キーの永続化、重複応答、cron 実行など (#892、#902、#832、#821、#823 など)

何が変わったのか

  • feat(feishu): https://github.com/HKUDS/nanobot/pull/844 の @KinglittleQ による画像、音声、ファイルの送信をサポート
  • 修正: https://github.com/HKUDS/nanobot/pull/836 の @Molunerfinn による GitHub Copilot モデルのコーデックス プロバイダー ルーティング
  • 修正: https://github.com/HKUDS/nanobot/pull/851 の @nikolasdehor による fd リークを防ぐために、シェル タイムアウト後にプロセスが強制終了されるまで待機する
  • https://github.com/HKUDS/nanobot/pull/820 の @rubychilds による URL の「format」に関するセーフティ ガード誤検知を修正
  • 修正: https://github.com/HKUDS/nanobot/pull/870 の @AlexanderMerkel により、MessageBus からデッド パブリッシュ/サブスクライブ コードを削除
  • 修正: https://github.com/HKUDS/nanobot/pull/864 の @nikolasdehor による中括弧での KeyError を防ぐために loguru ネイティブ書式設定を使用する
  • 修正: https://github.com/HKUDS/nanobot/pull/455 の @chtangwin による JSON 出力に UTF-8 エンコードと Unicode サポートを追加
  • 修正(ツール): https://github.com/HKUDS/nanobot/pull/653 の @omdv によってワークスペースに対する相対ファイル パスを解決します。
  • fix(cron): https://github.com/HKUDS/nanobot/pull/763 で @Athemis によってジョブを追加するときにタイムゾーン入力を検証する
  • fix(agent): https://github.com/HKUDS/nanobot/pull/644 の @jswxharry によるメモリ統合での非文字列値の処理
  • 功績: https://github.com/HKUDS/nanobot/pull/854 の @tercerapersona による、cache_control 経由で Anthropic プロンプト キャッシングを追加
  • 修正: https://github.com/HKUDS/nanobot/pull/825 の @nikolasdehor によるツール呼び出し前に暫定テキストを送信するモデルの再試行を許可
  • 修正: https://github.com/HKUDS/nanobot/pull/823 の @nikolasdehor によるセッションごとの重複したメモリ統合タスクを防止
  • 修正: /help コマンドは、https://github.com/HKUDS/nanobot/pull/824 の @nikolasdehor による Telegram の ACL をバイパスします
  • 功績: https://github.com/HKUDS/nanobot/pull/812 に @init-new-world による VolcEngine LLM プロバイダーのサポートを追加
  • 機能: MCP 認証用のカスタム ヘッダーを追加しました。 @dxtime 著、https://github.com/HKUDS/nanobot/pull/807
  • 特技: エージェントは、https://github.com/HKUDS/nanobot/pull/815 の @DaryeDev による元のメッセージ (テレグラム チャネル) に返信できます。
  • 修正: https://github.com/HKUDS/nanobot/pull/821 の @ClaytonWWilson により cron run コマンドが実際にエージェントを実行するようにしました。
  • 功績: Telegram のメッセージ返信動作を構成可能にし、https://github.com/HKUDS/nanobot/pull/879 の @Re-bin によりデフォルトを false にします
  • 修正: 思考フラグメントにツールがアタッチされている場合にツールのログが記録されない問題を修正しました。 @DaryeDev 著、https://github.com/HKUDS/nanobot/pull/833
  • 修正: https://github.com/HKUDS/nanobot/pull/795 の @Tevkanbot による StepFun および厳密なプロバイダーの「認識されないチャット メッセージ」エラーを解決
  • 功績: https://github.com/HKUDS/nanobot/pull/905 の @tercerapersona による、cache_control を介した OpenRouter プロンプト キャッシュの追加
  • feat(slack): https://github.com/HKUDS/nanobot/pull/904 で @pjbakker によるメディア ファイルのアップロード サポートを追加
  • 修正: https://github.com/HKUDS/nanobot/pull/903 の @nikolasdehor により、残りの f-string ロガー呼び出しを loguru ネイティブ形式に変換
  • 修正: https://github.com/HKUDS/nanobot/pull/900 の @nikolasdehor による 2000 文字制限を超えた Discord メッセージの分割
  • 修正: https://github.com/HKUDS/nanobot/pull/902 で @nikolasdehor による損失の多いファイル名の再構築を回避するために、セッション キーをメタデータに保存
  • 修正 (エージェント): メッセージ ツールが https://github.com/HKUDS/nanobot/pull/832 で @KimGLee によって既に送信されている場合の重複した電子メール返信を回避
  • 修正: https://github.com/HKUDS/nanobot/pull/892 の @nikolasdehor による一時的な障害の後に MCP の再接続を許可する
  • リファクタリング: https://github.com/HKUDS/nanobot/pull/908 の @Re-bin により、メッセージ バスを介して CLI インタラクティブ モードをルーティングします。
  • feat(feishu): https://github.com/HKUDS/nanobot/pull/922 の @coldxiangyu163 による画像、音声、ファイルのマルチメディア ダウンロード サポートを追加
  • fix(tools): https://github.com/HKUDS/nanobot/pull/921 で @themavik によって old_text が見つからない場合に edit_file に詳細なエラー メッセージを提供
  • 修正: https://github.com/HKUDS/nanobot/pull/887 で @nikolasdehor による再試行で空の応答が生成された場合、中間コンテンツをフォールバックとして保存する
  • リファクタリング (ループ): 暫定的なテキストの再試行を削除し、代わりに https://github.com/HKUDS/nanobot/pull/928 の @Re-bin によるシステム プロンプト制約を使用します。
  • fix(memory): https://github.com/HKUDS/nanobot/pull/866 の @rudy-of-the-corner によるツール呼び出しを使用してメモリ統合スキーマを強制します
  • リファクタリング: メモリ統合を MemoryStore に抽出し、https://github.com/HKUDS/nanobot/pull/930 の @Re-bin によってエージェント ループをスリム化
  • 修正（エージェント）: https://github.com/HKUDS/nanobot/pull/926 の @Athemis による空のフォールバック センチネル CLI のみを維持します
