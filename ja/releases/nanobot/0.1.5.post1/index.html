nanobot v0.1.5.post1

パッチ 公開日2026年4月14日 出典HKUDS/nanobot 英語原文

#ナノボットv0.1.5.post1 🐈 nanobot v0.1.5.post1 が登場 🎉 — 80 人の PR が統合され、25 人の新しい貢献者が加わりました。エージェントは自分自身を管理することを学びました。 v0.1.5 が建物を住みやすくすることであるとすれば、v0.1.5.post1 は建物が自分自身の世話をすることを学ぶことです。エージェントは、長すぎる前に独自のコンテキストを圧縮し、ユーザーを待たせる代わりにターンの途中でフォローアップ メッセージを挿入し、独自のワークフローから再利用可能なスキルを発見し、WebSocket を開いて何でも通信できるようにします。一方、cron、メモリ、再試行、チャネルにわたる 40 以上のバグ修正により、「ほとんどの場合動作する」が「動作する」に変わりました。

ハイライト

  • ミッドターンインジェクション - フォローアップは列に並んで待機しません - エージェントがまだ動作している間に別のメッセージを送信した場合、エージェントはロックの背後でキューに入れられなくなります。フォローアップはアクティブなターンに挿入され、ストリーミング チャネルでは同じライブ応答で応答が継続されます。これにより、長いツール呼び出しチェーンが一方向ではなく対話的に感じられるようになります。エラー パスでのエッジケース ドレインは、フォローアップ パスで強化されました。 (#3042、#3110)
  • Dream は事実だけでなくスキルを学習します — Dream の統合フローは、繰り返されるワークフローを認識し、skills/ の下でそれらをスタンドアロン ワークスペース スキルに昇格できるようになりました。不要なスキルを除外するための disabledSkills 構成と組み合わせることで、エージェントのスキル サーフェスは有機的に成長し、管理しやすいものになりました。 (#3048、#2959)
  • 自動コンパクト — エージェントが独自のコンテキストを管理します — セッションは壁にぶつかるまで成長しなくなりました。自動コンパクトはアイドル期間を監視し、最近のライブ メッセージを保存しながら古いコンテキストを積極的に要約します。そのため、エージェントは戻ってきたときに、重要でないものをすべて引きずることなく、重要なものを思い出します。これは、古い「セッションを無効にする」アプローチではありません。会話を継続的に感じさせるのは外科的圧迫です。設定で idleCompactAfterMinutes と組み合わせて、きめ細かい制御を実現します。 (#3007、#3081、#3093)
  • WebSocket チャネル — 何でも接続 — 新しい websocket チャネルは、ストリーミング (delta + stream_end イベント)、トークンベースの認証 (静的または発行)、接続ごとのセッション、および TLS サポートを備えた WebSocket サーバーを実行します。 Web アプリ、CLI、Chrome 拡張機能、スクリプトなど、ソケットを開くことができるものはすべて、リアルタイムでエージェントと通信できるようになります。 (#2964)
  • チャネルがさらに深くなりました — Telegram は位置情報の共有を実現しました。 Discord にはストリーミング応答とプロキシのサポートが追加されました。 Feishu は、完了絵文字ライフサイクル、インライン ツール ヒント、Lark グローバル ドメイン設定を追加しました。 QQ と WeCom はメディアから全面的なサポートを受けました。 Slack の message ツールは、#channel_name と @user を実際の ID に解決するようになりました。 API エンドポイントは、JSON Base64 およびマルチパートを介したファイルのアップロードを受け入れ、すべてのチャネルにわたる自動ドキュメント抽出 (PDF、DOCX、XLSX、PPTX) を行います。また、送信に失敗するとカスケード再試行がトリガーされる再試行増幅がすべてのチャネルで修正されました。 (#2910、#2939、#2960、#2993、#3046、#3044、#3138、#2938、#3053)
  • プロバイダー — 適応的思考とキミ — Anthropic の adaptive 推論モードが登場し、クロードにいつ、どれだけ考えるかを決定させました。キミ思考対応モデル (kimi-k2.5、k2.6-code-preview) は、reasoningEffort 経由で自動 extra_body.thinking インジェクションを取得できるようになりました。 StepFun Plan API 推論フィールドは正しくフォールバックします。クロード以外のプロバイダーには、適切なロール代替が適用されます。また、ツール呼び出しの引数は、不正な形式の JSON を拒否する厳密なプロバイダー用に正規化されます。 (#2882、#3124、#2903、#2637、#3154)
  • MCP、ツール、検索 — MCP リソースとプロンプトは読み取り専用ツールとして公開されるようになり、エージェントはそれらを直接クエリできるようになります。複数の MCP サーバーは、互いに競合するのではなく、分離されたタスクで接続します。ノート編集ツールが到着しました。 Kagi が Web 検索プロバイダーのラインナップに加わりました。そして、実行ツールもより厳密になりました。Windows サポートが追加され、allowed_env_keys で環境変数を選択的に転送できるようになり、内部状態ファイルは書き込み保護され、ワー​​クスペース外の working_dir は拒否されます。 (#2907、#3019、#3017、#2945、#2893、#2962、#3061)
  • Cron はジョブのドロップを停止しました - 4 つの cron 修正は、ジョブ実行中の再入可能ストアのリロード、同時ストア置換による固定間隔タスクの重複、ジョブ設定がリロードされない、および手動実行状態が保存されない問題に対処しました。スケジュールされたタスクに依存している場合、このリリースはそれが退屈になるものです。 (#3038、#3034、#2895、#2930)

コミュニティ

このリリースで初めて貢献した 25 人の新しい寄稿者へようこそ: @Bahtya、@LeoFYH、@xwind、@Xerxes-cn、@BalorLC3、@invictus-z、@zijiefang、@kronk307、@stutiredboy、@SHLE1、@RohitDayanand、@justforyoudear、@XJPeng12、@linziyanleo、 @chenyahui、@JonasGao、@weitongtong、@danielphang、@mterhar、@ramonpaolo、@nikube、@yeyitech、@ravs-cyberrock、@samyzhh、@razzh7。 v0.1.5.post1 は、私たちがコミット ログで確認し続けていることを反映しています。つまり、最高の貢献が常に最も派手なものであるとは限りません。 @weitongtong によって検出された cron 競合状態。 @Bahtya によって発見された再試行増幅ループ。 @yanghan-cyber によって修正された、メッセージを黙って飲み込むチャネル エラー パス。これらの変更は、エージェントを trust 価値のあるものにする変更です。エージェントがより多くのことを実行できるからではなく、間違ったことを行わなくなるからです。 80 回の PR を経て、nanobot はより静かで、より安定し、少し大人っぽくなりました。それは祝う価値があるよ。 フル Changelog: https://github.com/HKUDS/nanobot/compare/v0.1.5...v0.1.5.post1
