nanobot v0.1.4.post3

パッチ 公開日2026年2月28日 出典HKUDS/nanobot 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#ナノボットv0.1.4.post3 🐈 nanobot v0.1.4.post3 が削除されました — 33 人の PR が統合され、16 人の新しい貢献者が追加されました!君たちは止められない🔥 このリリースは、コンテキストをよりクリーンにし、セッション履歴を強化し、ゴースト メッセージを減らすなど、エージェントをジャンクの表示を減らしてより賢くすることを目的としています。入ってくる騒音が減り、出てくる幻覚も減ります。さらに、ピカピカの新しいマトリックス チャンネルと実験的思考モードも追加されました。

ハイライト

  • エージェント ループの強化 — 空のアシスタント メッセージ (コンテンツなし、ツール呼び出しなし) は、コンテキストを汚染する代わりにフィルタリングされるようになりました。 LLM エラー応答は履歴に保存されなくなり、永続的な 400 エラー ループが防止されます。メッセージ ツールの抑制は同一チャネルのみに限定されます (#1314、#1198、#1206)
  • コンテキスト ノイズ削減 — ランタイム メタデータ (時間、チャネル、チャット ID) が untrusted レイヤーに分離され、セッション履歴から除外されるため、エージェントは重要なものだけを確認できます。つまり、トークンが減り、混乱が減り、幻覚が減ります (#1126、#1222)
  • セッションの安全性 — コンテキストのオーバーフローを防ぐために、Base64 イメージが履歴から削除されます。 null 応答が将来のターンを破損しなくなりました (#1191、#1314)
  • マトリックス チャネル — E2EE、メディア アップロード、タイピング インジケーターによる完全なマトリックス (要素) チャット チャネル サポート (#420、#1239)
  • プロバイダーの互換性 — ミストラルの場合は短い英数字 tool_call_id。リストタイプのツール引数は適切に処理されます。構成での明示的なプロバイダーの選択 (#1293、#1294、#1214、#1316)
  • 思考モード (実験的) — 新しい reasoning_effort 構成により、サポートされているモデルの LLM 推論が有効になります。セッション履歴はターンを超えて reasoning_content と thinking_blocks を保持します (#1351、#1330、#1074)
  • サブエージェントの改善 — /stop は生成されたサブエージェントをキャンセルします。合理化されたプロンプトによりデッドコードが排除され、ContextBuilder が再利用されます (#1180、#1347)
  • Feishu — インタラクティブなカードテキスト抽出の修正、設定可能なリアクション絵文字、修正されたボット権限 (#1323、#1257、#1317、#1348)
  • DingTalk — プレーンテキスト リンクではなく、適切なメッセージ タイプとして送信される画像とメディア (#1337)
  • Telegram — 単一の受信メッセージに集約されたメディア グループ (#1258)
  • QQ — C2C 応答権限を修正し、読み取り専用ファイル システムでのファイル ログを無効にしました (#1307、#1346)
  • WhatsApp — メッセージの重複排除により、冗長なエージェント処理が防止されます (#1325)
  • シェルとセキュリティ - ワークスペース ガードでの完全な Windows パス解析。サブプロセス PATH の構成可能な path_append (#1286、#1083)
  • メモリと同時実行 — 統合ロック用の WeakValueDictionary により、競合状態と手動クリーンアップが排除されます (#1326)
  • ワークスペース — 自動テンプレート同期により、起動時に重要なファイルが復元されます (#1253)

何が変わったのか

  • feat/fix(exec): https://github.com/HKUDS/nanobot/pull/1083 の @aiguozhi123456 によるサブプロセスの PATH を拡張するために path_append 設定を追加
  • 功績: https://github.com/HKUDS/nanobot/pull/1126 の @pikaxinge による安定したシステム レイヤー + untrusted ランタイム コンテキスト レイヤーを追加
  • 機能: /stop は、https://github.com/HKUDS/nanobot/pull/1180 の @coldxiangyu163 によるセッション追跡を介して生成されたサブエージェントをキャンセルします

  • 修正: Base64 イメージがセッション履歴に保存され、コンテキスト オーバーフローが発生します。 @dxtime 著、https://github.com/HKUDS/nanobot/pull/1191
