注目すべき変更点

その他のライブラリ

  • automl: java-automl ライブラリを削除 (#14540) (6f13a1d)

  • bigquery-jdbc: PreparedStatement の宣言されていないフィールドを推測します (#14400) (e989a72)

  • gax,gapic-generator-java: アップロード呼び出しの開始を再試行し、ResumableUploadCallSettings の名前を ResumableUploadOptions (#14511) (98c2073) に変更します。

  • gax: 再開可能なアップロード用のチャンク アップロード回復ループを追加 (#14424) (8ecd1e5)

  • gax: ResumableUploadProgressListener と関連インフラストラクチャを追加 (#14426) (c7f10d8)

  • gax: チャンク アップロードのリカバリの準備に RewindableStreamBuffer を追加 (#14423) (349c315)

  • gax: 再開可能なアップロードにグローバル タイムアウトを強制します (#14425) (3cb9805)

  • gax: 再開可能なアップロード コマンド応答オブジェクトにアップロード ステータス ヘッダーを含めます (#14420) (23e49c1)

  • gax: 再開可能なアップロード公開サーフェスで、InputStream を InputStreamSupplier に置き換えます (#14521) (3c79730)

  • gax: 一時的なエラーでチャンクのアップロードを再試行します (#14422) (e72365e)

  • gax: 再開可能なアップロード サーバーの拒否を端末として扱います (#14516) (b288788)

  • gax: ResumableUploadProgressTracker (#14427) (e7ba3e8) を接続します

  • grpc-gcp: 共有フォールバック状態とプローブ回復オプションを GcpFallbackChannel に追加 (#14013) (675f639)

  • pubsub: パブリッシュ開始時刻を client テレメトリ ヘッダーに追加 (#14496) (4b6a671)

  • 認証: api の共通依存関係 (#14538) (668fd18)、参照 #12363 から javax.annotation-api を除外します。

  • bigquery-jdbc: 接続が閉じられたときにセッションを中止します (#14273) (5bd4520)、参照 #13922

  • storage: App Hub storage.googleapis.com プレフィックスを destination.id に追加します (#14527) (0f6f9b5)
