グーグルクラウドJava v1.94.0

1.94.0 (2026-10-22)

機能

  • auth: (01eaba1) によってエージェント ID の証明書にバインドされたトークンを要求します
  • bigquery-jdbc: クリアカット テレメトリ client (#14607) (c702438) を追加します
  • bigquery-jdbc: ジョブレス クエリの QueryStatistics を公開 (#14596) (15f472c)
  • bigquery: TableResult から QueryStatistics を公開 (#14588) (40b2b1a)
  • bigtable: メソッドごとのセッション迂回構成を追加 (#14681) (042dd3e)
  • bigtable: セッション client (#14565) (86de9c1) で SessionCheckAndMutateRow をサポートします
  • bigtable: セッション client (#14585) (8e653b2) で SessionReadModifyWriteRow をサポートします
  • firestore: DML (#14703) (11bc071)
  • gax: 操作レベルの client 要求スパン (T3) (#14549) (275063b) を実装します
  • gax: リンク試行が親コンテキストに広がり、操作完了時にクリーンアップされます (#14459) (0c481bd)
  • gax: 端末再開可能アップロード例外の ApiException (#14624) (d4961f0) へのマッピングを標準化します。
  • google/devicesandservices/health/v4beta: health v4beta を追加 (#14600) (95f863c)
  • google/shopping/merchant/reviews/v1: shopping-merchant-reviews を追加 (#14724) (13310c7)
  • トレース ID の一部として WriterId を含めます (#13488) (ffa8063)
  • LoggingTracer の操作失敗時の対処可能なエラーをログに記録します (#14460) (27559f4)
  • AppendRowsRequest に client_stats を設定します (#14614) (a7a0098)
  • spanner: プールごとではなくチャネルごとに GcpFallbackChannel を作成するオプションを追加 (#14501) (74f7591)

バグ修正

  • api-common: ドット セグメント (#14641) (4ad59e2) に対してパス テンプレート変数を検証します
  • auth: DownscopedCredentials と UrlIdentityPoolSubjectTokenSupplier のシリアル化ギャップを修正 (#14341) (a3e3324)
  • bigquery-jdbc: JDBC がデフォルトで PQC 準拠のアルゴリズムを使用するようにします (#14560) (b0ffe3d)
  • bigquery-jdbc: 例外処理を修正 (#14566) (3e7a206)
  • bigquery-jdbc: 欠落しているロガー インスタンスを修正 (#14733) (0e822dc)
  • bigquery-jdbc: プロキシ環境で動作する PQC を修正 (#14599) (ceb45b4)
  • bigquery-jdbc: Struct.toString() でネストされた ARRAY フィールドを有効な JSON としてフォーマットします (#14720) (bc0126a)
  • bigquery-jdbc: getString で TIMESTAMP を UTC としてフォーマットし、マルチゾーン TIMESTAMP(12) テストを追加します (#14666) (e666612)
  • bigquery-jdbc: Calendar タイムゾーンを尊重し、ResultSet 一時ゲッターで ClassCastException を防止します (#14657) (7dd2b37)
  • bigquery-jdbc: ストレージ読み取り API Arrow バッチ キューを 32 バッチに制限します (#14709) (d339c41)
  • bigquery-jdbc: setTime をカレンダー ゾーンから JVM ゾーンに正規化します (#14660) (54d2bc6)
  • bigquery-jdbc: JSON 参照キューをポーリングし、処理されたファイナライザーを解放します (#14719) (1b7d00d)
  • bigquery-jdbc: PreparedStatement および CallableStatement カレンダー オーバーロードで Timestamp インスタントを保持 (#14640) (3b02a44)
  • bigquery-jdbc: TIMESTAMP 書き込みパス上のインスタントを保存し、LocalDateTime を STRING としてバインドします (#14647) (2106e26)
  • bigquery-jdbc: ResultSet ごとのロガー登録リークを停止 (#14718) (e83c768)
  • bigquery-jdbc: プロデューサーを停止し、ResultSet.close でリソースを解放します (#14712) (6b99452)
  • bigquery: ドメイン モデルの無効なマッピングを修正 (#14646) (17048ed)
  • bigquery: 重複した google-cloud-storage 依存関係を削除します (#14586) (ab6173e)
  • データストア: DatastoreOptions で任意の gRPC TransportChannelProvider を許可します (#14478) (d9a8db5)
  • データストア: 2.3.1 のエミュレーター zip チェックサムを更新 (#14592) (fb73ed5)
  • deps: 依存関係 com.google.api-client:google-api-client-bom を v2.9.2 (#14725) (1ffa467) に更新します
  • gax-httpjson: 認識できないタイプのエラー詳細を適切に処理します (#14612) (7295640)
  • ヘルスメトリクス inflightBytes を inflightBytesMax (#14613) (44a12ef) になるように修正します。
  • ショーケース: ITOtelTracing の操作スパンの親コンテキスト再試行テストを更新 (#14673) (312b5ea)
  • スパナ: 受信メッセージの最大サイズを 256MB から 300MB に増加 (#14551) (70c7439)
  • スパナ: 最大受信メッセージ サイズを (70c7439) として 256MB から 300MB に増加します。
  • スパナ: 結果セットを閉じる際のストリーム リークと競合状態を防止します (#14665) (013b49b)
  • スパナ: クラウド インスタンス アクションで自動スケーリング構成、エディション、ポジティブ キャパシティをサポート (#14574) (004f0fd)

パフォーマンスの向上

  • bigquery: getNextPage() (#14650) (6183b63) まで、QueryPageFetcher でブロッキング jobs.get RPC を延期します。

依存関係

  • jackson-bom を v2.22.4 (#14701) (09ce4c5) にアップグレードします。

ドキュメント

  • 認証: ImpersonatedCredentials でのクォータ プロジェクトの動作を明確にする (#14597) (4e5a0d0)
  • pubsub: ヘッジを使用して公開するための Cloud Pub/Sub サンプルを作成します (#14623) (9de611f)
  • pubsub: README.md サンプル テーブル (#14643) (5394618)、参照 #14543 を再生成します
