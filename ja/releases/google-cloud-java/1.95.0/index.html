グーグルクラウドJava v1.95.0

1.95.0 (2026-11-02)

機能

  • bigquery-jdbc: BigQueryResultSetMetadata と getField(int) (#14761) (f01245a) を公開します
  • gax: 再開可能なアップロード チャンク サイズをサーバーの粒度とサーフェスの有効チャンク サイズに合わせます (#14670) (6cbb096)
  • google/cloud/designcenter/v1: designcenter (#14823) (01d27dc) を追加します
  • google/cloud/observability/v1: 可観測性を追加 (#14722) (624f28e)
  • oauth2: Workload Identity Federation の証明書バインド OAuth2 トークンと mTLS ローテーションをサポート (#14781) (dcb29b0)
  • ストレージ: バケット IP フィルタリングのサンプルとテストを追加します (#14328) (cb2b726)
  • ストレージ: インターコネクト経由の DirectPath のサポートを追加 (#14006) (ad0eb94)
  • ストレージ: OpenTelemetry client メトリクスの構成とオプション (#14484) (7c29e48)
  • ストレージ: OpenTelemetry client メトリクス計測器のレジストリとビュー (#14398) (60233b7)

バグ修正

  • ユーザーエージェントをセッションパスに追加します (#14835) (a653638)
  • auth: mTLS トランスポートとバインドされたトークン証明書の起動ポーリングと既知の検出を調整します (#14748) (0bae268)
  • bigquery-jdbc: OOM エラーへの処理を拡張 (#14759) (7d4b921)
  • bigquery-jdbc: パラメータ数の単純なフォールバックを修正 (#14779) (c3e4a5b)
  • bigquery-jdbc: REST と Arrow 全体で一貫して RANGE 境界をフォーマットします (#14807) (2108b8e)
  • bigquery-jdbc: 科学表記法のエポック TIMESTAMP を解析します (#14777) (71a31b1)
  • bigquery-jdbc: 1582 年以前および標準時以前の DATE/DATETIME 桁を保持 (#14787) (3dc394f)
  • bigtable: createPointReadCallable でのクエリのインプレース変更を回避します (#14797) (1b1c6a7)
  • bigtable: RetryingVRpc. shouldRetry (#14795) (d821bd3) で最初に isOk と getRejected を確認してください
  • bigtable: RetryingVRpc で client によって開始された再試行の残りの期限を確認します (#14796) (a04e24c)
  • bigtable: TestProxy の空の RowResult セマンティクスを修正しました。 (#14810) (1d2fb9a)
  • bigtable: クエリの等しい値、ハッシュコード、および toString に反転が含まれます (#14799) (fe9232b)
  • bigtable: RowBuilderShim の RowBuilder.startCell にセル値のサイズを渡します (#14800) (cfa7949)
  • bigtable: RowSetUtil の空の分割ポイントを拒否し、QueryPaginator Javadoc (#14811) (1bc507f) を明確にします
  • bigtable: ClientConfigurationManager で従来の PollingConfiguration 移行を削除 (#14822) (95ead45)
  • bigtable: 単一の共有ルール (#14738) (00f7bea) を通じてセッションの迂回を解決します
  • bigtable: pageSize より小さいクエリ制限を尊重し、QueryPaginator でのクエリの変更を回避します (#14821) (cecd09e)
  • firestore: プレビューから GA までの卒業パイプライン検索 (#14741) (a993026)
  • gax: SocketTimeoutException をスレッド割り込みとして処理しません (#14778) (7b91805)
  • jdbc: 空の DatabaseMetaData 結果セットに ResultSetMetaData を設定します (#14809) (4c6a7e3)
  • pubsub: パブリッシュ ヘッジをクロック ジャンプ、キュー エラー、シャットダウンに対して堅牢にします (#14860) (9b9e2a5)
  • スパナ: 読み取り/書き込みトランザクション要求にルーティング ヒントを添付します (#14786) (54e0585)
  • スパナ: クローズ時にクエリを即座にキャンセルし、エラー処理を同期します (#14887) (323a8f7)
  • spanner: AbstractLazyInitializer で再試行可能なエラーをキャッシュしません (#14752) (6a9ac76)
  • spanner: ストリーム テストの互換性のために setCall オーバーロードを復元 (#14885) (cfe728e)
  • spanner: ストリームのライフサイクルを同期し、ResumableStreamIterator でバッファリングを再試行します (#14770) (4edefc5)
  • spanner: 不定のコミット失敗時にベストエフォート型ロールバックをトリガーする (#14831) (b9d1b95)
  • ストレージ: XML マルチパート アップロード エラーの HTTP ステータスを保持するため、再試行が機能します (#14804) (3c03034)
  • ストレージ: ターゲット BlobInfo が提供されている場合、gRPC コピーの宛先を送信します (#14784) (43a67a0)
  • ストレージ: 解凍されていない HTTP ダウンロードで CRC32C を検証します (#14805) (61aa22f)

ドキュメント

  • bigtable: 行制限にカウントされる大きな行をスキップしたドキュメント (#14801) (91d60e0)
