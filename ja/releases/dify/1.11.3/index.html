#ディファイ1.11.3

🚀 v1.11.3 の新機能は何ですか?

当社の最新リリース v1.11.3 では、パフォーマンス、機能性、ユーザー エクスペリエンスに重点を置いた多数のバグ修正と機能が提供されます。変更点は次のとおりです。

🎬 新機能

  • MCP ツールの機能強化: embeddedResource のサポートを追加し、#30261 と #30019 の @IthacaDream と @faterei による素早いアクセスのために MCP ツールが直接表示されるようにしました。
  • バッチ操作: #30275 で @faterei によってドキュメントのバッチ操作に再インデックス操作が導入されました。
  • エージェントとワークフローの更新: @faterei による新しい AgentMaxIterationError とアプリ モード チェックの機能強化により、ワークフローとエージェントがより堅牢になりました。
  • OAuth 統合: フロントエンド ログインは、#30370 の @zyssyz123 による oauth_new_user フラグをサポートするようになりました。
  • PDF 抽出: #30399 の @yangzq50 による PDF からの画像抽出をサポートするために RAG エクストラクターが改良されました。
  • ストレージとアーカイブ: #30422 の @hjlarry によるアーカイブ ストレージ client と構成設定を追加しました。
  • 翻訳と国際化: #30596 の @hyoban により、世界中の読者向けの翻訳のための初期 RSC サポートが追加されました。

🛠️ バグ修正

  • Redis とキャッシュ: パイプラインを使用して Redis キャッシュの削除を最適化し、#30159 の @fatelei によって速度と信頼性が向上しました。
  • UI/UX の修正: 権限エラーによるページのクラッシュの防止から、フリック ボタン サイズの修正まで、複数の UI 関連の問題がさまざまな貢献者によって解決されています。
  • データ操作: @zhaobingshuang らによるデータセット アクセス エラーを修正し、バッチ操作でのエラー処理を改善しました。
  • パフォーマンス: #30236 の @SherlockShemol による潜在的なメモリ リークを防ぐために、高負荷時のランタイム状態参照をリリースしました。
  • セキュリティ: ボットの統合と Celery の操作に影響を与える可能性がある CORS および SSL の問題を修正しました。
  • 国際化: 韓国語の翻訳とコンテンツは、#30347 の @sangyun-han によって正確さを期して更新されました。

🔧 ボンネットの下

  • CI/CD とビルドの機能強化: @bowenliang123 と @hyoban により、GitHub のアクションとビルド プロセスが強化され、信頼性が向上し、ダウンタイムが減少しました。
  • コードとクエリの最適化: ワークフローおよび API での SQL クエリとデータ処理の非効率性に対処し、全体的な安定性を向上させました。

このリリースでは、バックエンド操作の合理化、セキュリティの強化、よりスムーズで生産性の高いエクスペリエンスを実現するためのユーザー インターフェイスの強化に重点が置かれています。 Dify を改良し、プラットフォームを前進させてくれたすべての貢献者に感謝します。 🛠️💡

アップグレード ガイド

Docker デプロイメントの構成

  1. カスタマイズした docker-compose YAML ファイルをバックアップします (オプション)

    cd docker
cp docker-compose.yaml docker-compose.yaml.$(date +%s).bak

  2. メインブランチから最新のコードを取得します。

    git checkout main
git pull origin main

  3. サービスを停止します。 dockerディレクトリで実行してください。

    docker compose down

  4. データのバックアップ

    tar -cvf volumes-$(date +%s).tgz volumes

  5. アップグレードサービス

    docker compose up -d

ソースコードのデプロイメント

  1. API サーバー、ワーカー、および Web フロントエンド サーバーを停止します。

  2. リリース ブランチから最新のコードを取得します。

    git checkout 1.11.3

  3. Python の依存関係を更新します。

    cd api
uv sync

  4. 次に、移行スクリプトを実行しましょう。

    uv run flask db upgrade

  5. 最後に、API サーバー、ワーカー、および Web フロントエンド サーバーを再度実行します。
