#ディファイ1.12.0

🚀 新機能: 概要インデックス

概要インデックスを導入します。これはナレッジ ベース検索システムの強力な機能強化であり、AI を活用してドキュメント チャンクの概要を生成することで検索精度を大幅に向上させます。

背景

従来のベクトル検索は生のチャンクの埋め込みに依存しているため、ユーザーのクエリを照合するときに意味のニュアンスやコンテキストが見逃される可能性があります。これは、重要な情報が複数のチャンクに分散している可能性がある長い文書や複雑なコンテンツの場合に特に困難です。 Summary Index は、ドキュメント チャンクごとに簡潔で意味論的に豊富な要約を作成することでこの問題に対処し、それをベクトル化して追加の検索レイヤーとして使用します。

主な機能

  • AI を活用した要約: 構成可能な LLM モデルを使用して、ドキュメント チャンクの簡潔な要約を自動的に生成し、重要な意味情報をコンパクトな形式でキャプチャします。
  • マルチモーダル サポート: ビジョン対応 LLM (GPT-4V、Claude-3 など) を使用すると、システムはドキュメント チャンクからテキストと画像の両方を組み込んだ概要を生成し、より豊かなコンテキストの理解を提供できます。
  • 検索精度の向上: 要約ベクトルは追加の検索レイヤーとして機能し、元のコンテンツと AI が生成した要約の両方に対してクエリを照合することで、ナレッジ ベース検索の精度を向上させます。
  • 柔軟な構成: デフォルトの概要プロンプトをサポートしているため、ドメイン固有の要件に合わせて要約スタイルを調整できます。
  • 非同期処理: 概要の生成は非同期で実行され、ドキュメントのインデックス作成が高速かつノンブロッキングのままであることが保証されます。
  • 手動要約編集: AI によって生成された要約を手動で編集および調整して、元のチャンク コンテンツとよりよく一致させることができ、要約がドメイン固有の用語とコンテキストを正確に反映するようにします。
  • インデックス構造の互換性: 一般的なチャンク モードと親子チャンク モードの両方で動作し、階層的なドキュメント関係をインテリジェントに処理します。
  • 高品質インデックス統合: 「high_quality」インデックス作成技術を使用するデータセットにのみ利用可能で、本番ナレッジ ベースの最適なパフォーマンスを保証します。

その他の改善点

  • エージェント アプリのマルチモーダル サポート: エージェント アプリは、マルチモーダル入力 (画像/ファイル) をネイティブにサポートするようになりました。
  • Qdrant 全文検索: Qdrant ベクトル データベースの複数キーワードをサポートする全文検索を実装しました。
  • ワークフローの強化:
    • ワークフローでのコンテキストの登録と読み取りのサポートが追加されました。
    • 単一実行に対する OpenTelemetry のサポートを追加しました。
  • プラグイン システム: プラグインをアンインストールするときに API キーを削除または保持するオプションを追加しました。
  • 作成前のテンプレート プレビュー: アプリ タイプ別のワークフロー グラフまたはアプリ構成を含む詳細なアプリ テンプレート プレビューを追加しました。

⚙️ 構成の変更

  • SANDBOX_EXPIRED_RECORDS_CLEAN_TASK_LOCK_TTL: サンドボックスの期限切れレコードのクリーンアップ タスクのロック TTL を設定します (デフォルト: 90000)。
  • SMTP_LOCAL_HOSTNAME: SMTP HELO/EHLO 中に使用されるローカル ホスト名のオプションのオーバーライド。
  • PLUGIN_MODEL_SCHEMA_CACHE_TTL: プラグイン モデル スキーマのキャッシュ TTL を設定します (デフォルト: 3600)。
  • ENABLE_TRIAL_APP: 試用版アプリを有効にします (デフォルト: false)。
  • ENABLE_EXPLORE_BANNER: 探索バナーを有効にします (デフォルト: false)。

アップグレード ガイド

Docker デプロイメントの構成

  1. カスタマイズした docker-compose YAML ファイルをバックアップします (オプション)

    cd docker
cp docker-compose.yaml docker-compose.yaml.$(date +%s).bak

  2. メインブランチから最新のコードを取得します。

    git checkout main
git pull origin main

  3. サービスを停止します。 dockerディレクトリ内で実行してください。

    docker compose down

  4. データのバックアップ

    tar -cvf volumes-$(date +%s).tgz volumes

  5. アップグレードサービス

    docker compose up -d
