chatgpt-on-wechat 2.1.4

#chatgpt-on-wechat 2.1.4

🌐 英語 | 中文

🖥 デスクトップ Client

以前のリリースでリリースされたデスクトップ client に続き、このバージョンではブラウザーの機能、システム互換性、および全体的なエクスペリエンスがさらに向上しています。

  • ブラウザ ツールのサポート: client はブラウザ機能をバンドルしており、システムにインストールされている Chrome / Edge の再利用を優先し、ブラウザの起動とアクセスのパフォーマンスを最適化します。
  • UI の洗練: チャット ビュー、メッセージ バブル、ツール呼び出しステップ、チャネル ページのビジュアルとインタラクションが洗練されました。
  • Windows コード署名: Windows インストーラーがコード署名されるようになり、インストール中のセキュリティ警告が軽減されます。
  • Windows 7/8 サポート: Windows 7/8 などのレガシー システムに対する client サポートを追加し、より多くの環境をカバーします。
  • ナレッジ ベース リンクの修正: ナビゲートできなかったデスクトップ ナレッジ ベースのドキュメント内リンクを修正しました。
  • パスワード ログイン: デスクトップ client はログイン パスワードの設定をサポートし、パスワードの設定後にウィンドウの読み込みに失敗する問題を修正します。

ダウンロード: CowAgent デスクトップ

ドキュメント: デスクトップ Client

🔌 MCP OAuth 認証

リモート MCP サーバーは OAuth 認証をサポートするようになりました。ログインが必要なサードパーティの MCP サーバーに接続する場合、標準の OAuth フローを介して認証を完了できます。トークンを手動で構成および維持する必要はありません。

ドキュメント: MCP ツール

⏰ スケジュールされたタスク

  • サイレント モード: メッセージをプッシュせずにバックグラウンドで実行するサイレント実行のスケジュールされたタスクを作成します。データの整理や定期的なアーカイブなど、邪魔されないシナリオに最適です。 (#2954)
  • 手動実行: 次のスケジュールを待たずに、既存のタスクを手動でトリガーして、コンソールからすぐに実行します。 (#2958)
  • 編集時に設定を保存: Web コンソールでタスクを編集すると、モード タイプなどの非表示フィールドが削除される可能性がある問題が修正されました。 (#2959)
  • クロスチャネルタスクコマンド: チャネル間で互換性のある /tasks 管理コマンドを追加しました。 (#2965)

ありがとう @AaronZ345

ドキュメント: スケジュールされたタスク

💬 フェイシュチャンネルの改善

Feishu チャネルは、より良いエクスペリエンスを実現するために、一連のメッセージ表示とインタラクションが強化されました。

  • ストリーミング カードの洗練: ストリーミング カードには、思考プロセス、ツール呼び出し、実行時間を表示する折りたたみ可能なパネルが追加されています。 (#2963)
  • マークダウン形式: 非ストリーミング応答およびスケジュールされたプッシュの場合、マークダウンを含むメッセージは、より明確に表示するためにカードとしてレンダリングされます。 (#2962)
  • スケジューラ カード: /tasks コマンドはカードとして表示され、カードから直接タスクを有効または無効にすることができます。 (#2961)
  • 引用されたメッセージ コンテキスト: ユーザーがメッセージを引用すると、引用された内容がエージェントに送信されるコンテキストに自動的に追加されます。 (#2966)
  • リモート画像レンダリング: リモート画像リンクを Feishu カード内でレンダリングできるようになりました。 (#2967)
  • メッセージ呼び出し時のキャンセル: Feishu メッセージを呼び出すと、対応する実行中またはキューに入れられたタスクが自動的にキャンセルされます。 (#2978)

ありがとう @AaronZ345

ドキュメント: フェイシュ

💾 データのバックアップと復元

cow backup および cow restore コマンドが追加され、ローカル データ (構成、ナレッジ ベース、メモリなど) を 1 つのコマンドでエクスポートおよび復元できるため、移行とバックアップが簡単になります。ありがとう @AaronZ345 (#2957)

ドキュメント: データバックアップ

🤖 新しいモデル

  • kimi-k3 のサポートを追加しました
  • gpt-5.6-luna、gpt-5.6-terra、gpt-5.6-sol のサポートを追加しました

ドキュメント: モデル

🛠 改善と修正

  • アクティブ タスク ステアリング: タスクの実行中に新しい命令を挿入し、実行中のタスクをその場でガイドまたはリダイレクトする /steer コマンドを追加しました。ありがとう @AaronZ345 (#2977)
  • ファイル編集: ファイル編集時にあいまい一致により間違った位置が特定される可能性がある問題を修正しました。ありがとう@weijun-xia (#2945)

📦 アップグレード方法

  • ソースの展開: cow update を実行して 1-click アップグレードするか、最新のコードをプルして再起動します。 アップグレードガイドを参照してください。
  • デスクトップ client: 更新を確認し、client 内の 1 つの click で更新するか、ダウンロード ページ から最新バージョンを入手します。
