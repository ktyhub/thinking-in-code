chatgpt-on-wechat 2.1.2

パッチ 公開日2026年6月18日 出典zhayujie/chatgpt-on-wechat 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#chatgpt-on-wechat 2.1.2

🌐 英語 | 中文

💬 Web コンソールの改善

このリリースでは、Web コンソールにいくつかの視覚的な管理機能が追加されているため、ファイルを編集せずに UI でさらに多くの設定を行うことができます。

  • スケジュールされたタスクの管理: スケジュールされたタスクをコンソールで直接表示、編集、有効化/無効化、および削除します。タスク リストは、最初に有効なステータスによって並べ替えられ、次に次回の実行時間によって並べ替えられます。ありがとう@HnBigVolibear (#2892)
  • ナレッジ ベースのカテゴリとドキュメント管理: ナレッジ ベースをカテゴリ別に整理し、各カテゴリのドキュメントを UI で管理できるようになりました。ありがとう @yangziyu-haha (#2893)
  • 複数のカスタム モデル プロバイダー: 複数の OpenAI 互換プロバイダーを構成し、単一の click でアクティブなプロバイダーを切り替え、既存の構成と完全に互換性があります。ありがとう @kirs-hi (#2877)
  • セッション名の変更: 並列タスクを区別するためにセッションの名前を手動で変更します (#2897)
  • Bash ストリーミング出力: 長時間実行される Bash コマンドは、進行状況をリアルタイムでストリーミングするようになりました。ありがとう @yangziyu-haha (#2879)

🧬 自己進化の改善

以前のリリースで導入された自己進化を基にして、このバージョンではさらに改良されています。

  • トリガーしきい値の引き下げ: デフォルトのレビューしきい値が引き下げられるため、日常のコラボレーションがより早く改善につながります。
  • 同時レビューなし: 1 つのターンが長くかかる場合、アイドル レビューが誤って起動されなくなり、アクティブな会話への干渉が回避されます。
  • レビューの要約の改善: 要約を簡潔に保ち、情報密度を高め、会話言語で出力するように要約プロンプトを改良しました。

ドキュメント: 自己進化

🤖 新しいモデル

  • kimi-k2.7-code: 追加され、デフォルトの Kim モデルとして設定されます。kimi-k2.7-code-highspeed も使用可能です
  • glm-5.2: 追加され、デフォルトの GLM モデルとして設定されます

ドキュメント: モデルの概要

🏢 WeCom スマートボット コールバック モード

WeCom スマートボット チャネルは、既存の長時間接続に加えて HTTP コールバック モードを追加するため、長時間接続を開いたままにできない展開でも確実に接続できます。

  • モード切り替え: wecom_bot_mode 経由で websocket (長時間接続) と webhook (コールバック) を切り替えます。
  • 暗号化されたトランスポート: コールバック モードは、URL 検証、メッセージ復号化、およびパッシブ応答暗号化を完全にサポートします。
  • 安定性の修正: 返信の中断、ストリームの途中終了、一時的な画像ファイルのリークを修正しました。

ありがとう@6vision (#2896 #2869)

ドキュメント: WeCom スマート ボット

🔒 セキュリティ強化

  • ビジョン ツール SSRF 保護: 画像 URL を解決する前にターゲット アドレスを検証し、内部、ループバック、およびクラウド サーバーのメタデータ エンドポイントへのリクエストをブロックします。ありがとう @kirs-hi (#2886)
  • Web フェッチ SSRF 保護: web_fetch は、フェッチする前にターゲット アドレスを検証し、すべてのリダイレクト ホップを再検証して、リダイレクトが内部アドレスに到達するためのチェックをバイパスするのを防ぎます。ありがとう@christop (#2900)
  • スキルのインストール パス トラバーサル保護: スキルのインストール時にパスを検証し、悪意のあるスキル名がパス トラバーサルを通じて skills/ ディレクトリに escaping を実行したり、不正な場所に書き込んだりすることを防ぎます。ありがとう @kirs-hi (#2886)

🛠 改善と修正

  • CLI 自己再起動: エージェントが独自のプロセスを再起動できるように、cow self-restart コマンドを追加しました。
  • Windows 互換性: 牛 CLI ディレクトリをユーザー PATH に保存します。 cmd.exe の長さ制限を超える python -c の長いコマンドを修正しました。インストール中にソースからグリーンレットを構築しないようにする
  • カスタム ロール: ロール プラグインは、roles/*.json でのスタンドアロン プロンプト ファイルによるカスタマイズをサポートします。ありがとう @sufan721 (#2891)
  • 安定性の修正: /cancel の KeyError と画像圧縮の無限ループを修正しました (@kirs-hi #2888 に感謝)
  • インストールの改善: 起動スクリプトとデフォルト設定を更新しました。 ASR/TTS のデフォルト、自己進化フラグ、インストールのハングを修正
  • ビジョン ツールの安定性: ビジョン ツールのタイムアウトと max_tokens を増加しました。
  • メモリ蒸留: 大きな MEMORY.md が切り捨てられるのを避けるために、ディープ ドリーム蒸留の出力長キャップを削除しました。

📦 アップグレード

ソース コードのデプロイメントでは、cow update を実行して 1-click アップグレードすることも、最新のコードをプルして手動で再起動することもできます。詳細については、「アップグレードガイド」(https://docs.cowagent.ai/guide/upgrade)を参照してください。
