2.1.8 パッチ MT

CowAgent はマルチエージェント フレームワークになりました。それぞれに独自の役割を持つ複数のエージェントを作成してチームを形成し、単一セッション内で複雑なタスクに共同で取り組むことができます。 Web コンソール、デスクトップ client、および…でサポートされています。

 08/21
2.1.7 パッチ MT

エージェントは単一のディレクトリに関連付けられなくなりました。複数のプロジェクト ワークスペースをセットアップして、各セッションに独自のセッションを与えることができます。 Web コンソールとデスクトップ client の両方で使用できます。

 08/12
2.1.6 パッチ MT

メイン エージェントは、独立したタスクをサブ エージェントに引き渡し、それらを並行して実行できます。これにより、結果が向上し、コンテキスト コストが削減され、同時に発生する可能性のある作業が高速化されます。

 07/29
2.1.5 パッチ MT

チャット ページには、ワークスペースの視覚的なビューが表示されます。エージェントが作成したドキュメント、Web ページ、および画像をその場でプレビューできます。 Web コンソールとデスクトップ client の両方がこれをサポートしています。
