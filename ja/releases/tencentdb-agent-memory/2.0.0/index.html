TencentDB-エージェント-メモリ v2.0.0

[2.0.0] - 2026-08-03

v2.0.0の正式版をリリースしました。 beta.1と比較して、新しいスキルの強制アーカイブ、CodeGraphのスケジュールされた同期、 このパネルには中国語と英語の切り替え/管理者資産管理などの機能があり、展開プロセスとドキュメントへのアクセスが改善されました。

製品のポジショニング: エージェントのエクスペリエンス、ドキュメント、コードを次のエージェントにとって再利用可能な資産にします ファイルを直接読み取ります。詳細については、README_CN.md を参照してください。

🧠 4 つのメモリ資産 · 初めて完全にオープンソース化

「会話・作業軌跡」からは以下の4種類のアセットが自動で預けられます。

  • チャット メモリ — 会話から L0 元のレコード → L1 ファクト → L2 シーン → L3 をレイヤーごとに抽出します 長期的な認知。セッション間での設定、決定、対話履歴の保持。
  • スキル — バージョン/リソース ファイル/トリガー境界/を使用して、完了したタスクから再利用可能な SOP を抽出します。 実行ステップ/検証ルール。 新機能 重要なスキルを逃さないようにするための強制アーカイブ機能が追加されました。
  • Wiki — ドキュメントを構造化ページ + リンク グラフに変換します (Karpathy の LLM ナレッジ ベースからインスピレーションを受けています) 練習してください）。
  • CodeGraph — ウェアハウス シンボル/ファイル/呼び出し関係/影響パスのインデックスを作成し、エージェントがコードを変更します まず影響分析を行います。 新機能 コードベース関数を定期的に自動的に同期します。ウェアハウスの変更後に手動で行う必要はありません。 トリガー。

🎛️ メモリハブ · チーム指向のコンソール

管理パネル (agentmemory/memory-hub イメージ、パネル + ナレッジ サービスを含む):

  • チーム/エージェントを作成し、所有者/バージョン/ステータス/可視性ごとにアセットを均一に管理します
  • レベル 3 可視性: private/team/restricted (ユーザー/ロール/エージェント ACL)、 Plus agent 方向性アセンブリ
  • エージェントロードアウト: 異なるアセットを異なるエージェントにバインドし、優先順位と使用方法を調整します。
  • Wiki + CodeGraph ワークショップがハブに組み込まれており、コード ライブラリ/ドキュメントをインポートすることで自動的に構築できます
  • 新規 管理者(システム管理者)も資産管理機能を利用可能
  • 新しいパネルは中国語と英語の切り替えを完全にサポートします。統一されたページ デザイン スタイル、最適化されたリスト インタラクションとページング エクスペリエンス

🔀 メモリ プロキシ · エージェントがメモリ チャネルを切断する

agentmemory/memory-proxy を使用すると、Claude Code などのコーディング エージェントがチーム メモリを直接使用できるようになります。

  • Anthropic / OpenAI デュアル プロトコル: /claude-code/<spaceId>/v1/messages および /v1/chat/completions すべて受け入れられます
  • 最初のラウンドブート: sessionInit により、ユーザーは AskUserQuestion を通じてチーム / エージェント / を選択できます。 タスク、プロキシはバインディングを記憶する
  • 各ラウンドでの注入: エージェントの L2/L3 メモリ、一致するスキル、Wiki/コードグラフを注入します。 システムプロンプトを入力し、上流の LLM を転送します。
  • 認証: x-tdai-user-key → カーネル /v3/meta/auth/verify が user_id に置き換えられます。 ユーザーディメンションによってアセットの可視性を制御

🚀 導入方法

|方法 |説明 | |------|------| | Docker 3点セット | agentmemory/memory-core / agentmemory/memory-hub / agentmemory/memory-proxy、マルチフレーム (linux/amd64 + linux/arm64)、ワンクリック start-all.sh プルアップ。自動 init-admin を初めて開始し、.admin-key を生成します。 start-all.sh がセルフテストに合格すると、コピー可能な claude 起動コマンドが出力されます。 |ソースコードの実行 |参照 INSTALL_CN.md / INSTALL.md |

stop-all.sh --purge はボリュームと管理キーを完全にクリーンアップして、環境のリセットを容易にします。
