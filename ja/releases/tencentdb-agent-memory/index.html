11/19
v2.0.4 パッチ MT

v2.0.4がリリースされました。 v2.0.3 と比較すると、スキル圧縮パッケージのバッチ インポートとカスタム メモリ プロンプト ワード置換モードが追加され、メモリ構成、長時間のアップストリーム リクエスト、オンライン セッション レコードとトラブルシューティング ログが強化され、安定性と権限に関する多くの問題が修正されています。

 10/26
v2.0.3 パッチ MT

v2.0.3 が発行され、v2.0.3-beta.1 に比べて Wiki 富文に新しく追加され、個別に構成されていないアップストリーム等の待ち時間が 10 分から 1 時間に変更されます。ヘルプ インターフェイス、履歴表示時間形式、インストール スクリプト、パネル インタラクション、ナレッジ アクティベーション、および Redis 中断後にプロキシを自動更新できない問題があります。

 10/13
v2.0.3-beta.1 プレリリース MT

v2.0.3-beta.1 が発行され、v2.0.2 と比較して、新たに実行可能な政策サービス、スキル要件の選択と会議轨迹记录機能、および齐代コード知识库の SSH が追加されました上記の新しい機能はすべて停止されており、古い構成は変更する必要がなく、以前と一致したまま動作します。

v2.0.2 パッチ MT

团队记忆不再定一データ底座，MongoDB 後端能力进一步全

v2.0.1 パッチ MT

现在無论你用哪款コーディング代理人，都能直接上团队记忆

 08/03
v2.0.0 メジャー MT

v2.0.0 正式版公開、相対 beta.1 はスキル強化機能、CodeGraph 定時同期、パネル中英文切替え / 管理機能など​​の機能を強化し、フローと入力テキストの配置を完全に完了しました。

 07/14
v1.0.1 パッチ MT

ゲートウェイ ローカル L2 タイマーがシーン抽出を実行していない (#227): ローカル タイマーは、L2 スケジュールを非シーン抽出タスク タイプにルーティングし、タイマー メンバーの前に正のマッピング オフロードを引き起こす timer-routing.ts を抽出します。 offload-l15 / offload-l2 は L1 / L2 / L3 と連動します。

 06/11
v1.0.0 メジャー MT

クライアント/サービス エンド アーキテクチャの構成: OpenClaw プラグインからの承認は独立したゲートウェイ サービスとして割り当てられ、配置方式と接続方式に変更が発生します。フィールドがサーバーに移行されました。; アプリケーション エントリ モードの変更: ローカル (プロセス内で直接実行、承認) と client (外部メモリ ゲートウェイに接続) の 2 つの入力モードをサポートします。

 05/28
v0.3.6 パッチ MT

リコール コンテキスト コンピューティング制御 (#71 / #70): 新しくrecall.maxCharsPerMemoryとrecall.maxTotalRecallCharsを配置し、超長条項を分数順に裁断し、オーバーフロー部分を回避し、コンテキストの拡大を防ぎます。

 05/20
v0.3.5 パッチ MT

互換 OpenClaw v2026.5.7 zod v4 子路径：显式指示 zod@^4.4.3 依赖，解决 @ai-sdk/provider-utils@4.x 必要 zod/v4 子路径导出但宿主環境可能 hoist zod@3.x 開始 モジュール zod/v4 が見つかりませんの実行時間。

 05/13
v0.3.4 パッチ MT

オフロード ローカル モード：本地モード実行オフロード、不依存赖远端後端；Docker 統合镜像（Dockerfile.hermes）：单容器捆绑Hermes Agent +memory_tencentdb 插件 + TDAI Memory Gateway、统一モデル環境变量驱动

 05/12
v0.3.3 パッチ MT

短期记忆压缩（コンテキスト オフロード）：新しいオフロード モジュール、サポート长对话场景下の上下文压缩と记忆卸売; 架台重构：コア + 多框架配： TdaiCore 宿主無关核心層 + に重構成アダプタ モード、解読 OpenClaw フレーム依存；新しい HostAdapter / LLMRunner 抽象インターフェイス

 05/12
v0.2.2 パッチ MT

Tencent Cloud Vector Database (TCVDB) ストレージ バックエンドを追加し、ベクター + BM25 混合リコールをサポートします。 SQLite ↔ TCVDB インデックス同期、L2 シーン/L3 ポートレート ローカル キャッシュ、ベクトル データベースとの双方向同期をサポートします。ローカル BM25 キーワード検索を追加し、外部 HTTP サイドカーを置き換え、外部依存関係を排除しました。 TCVDB に HTTPS 接続サポートが追加され、caPemPath を通じてカスタム CA 証明書を構成できるようになりました
