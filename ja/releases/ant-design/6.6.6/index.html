ant-design 6.6.6

パッチ 公開日2026年10月12日 出典ant-design/ant-design 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#アリデザイン 6.6.6

  • テーブル
    • 🐞 テーブル選択メニューの「すべてのデータを選択」オプションでツリー データの子孫行が欠落している問題を修正しました。 #59342 @QDyanbing
    • 🐞 preserveSelectedRowKeys が有効な場合に、保存されたキーに対して undefined を返すテーブル rowSelection onSelect を修正しました。 #59449 @Chaoqi31
    • 🐞 テーブル column.filterDropdownProps.popupRender が機能しない問題を修正。 #59393 @ramen2020
    • 🐞 scroll が ConfigProvider でのみ設定されている場合、テーブルが最初の行にスクロールしない問題を修正しました。 #59394 @ramen2020
    • 🐞 v6 論理プロパティの移行後、テーブル選択列 z-index が固定列に適用されない問題を修正しました。 #58609 @leshalv
  • 転送
    • 🐞 数値 0 に設定すると、転送 selectAllLabels がデフォルトのカウントに戻る問題を修正しました。 #59487 @QDyanbing
    • 🐞 一方向の削除後に制御された転送選択がチェックされたままになる問題を修正しました。 #59428 @yunfeizhu
    • 🐞 フィルターで除外された項目に影響を与える転送シフトの選択と、検索結果が変更された後の誤った範囲の選択を修正しました。 #59348 @QDyanbing
  • 木
    • 🐞 Tree.DirectoryTree の数字キーと defaultExpandAll によるシフト範囲選択を修正しました。 #59375 @QDyanbing
    • 🐞 シフト範囲選択中に、Tree.DirectoryTree が selectable: false または disabled: true を含むノードを誤って選択する問題を修正しました。 #59341 @QDyanbing
  • カルーセル
    • 🐞 dotPlacement がカルーセルを垂直にすると、RTL でカルーセルの垂直スライド順序が逆転する問題を修正しました。 #59436 @Chaoqi31
    • 🤖 無視された verticalSwiping プロパティを公開するカルーセル タイプを修正しました。 #59366 @QDyanbing
  • 🐞 リスト、ディバイダー、ドロワー全体での数値 0 コンテンツのレンダリングを修正しました。 #59118 #59517 #59437 @nrps9909 @Ye-YiChen @Chaoqi31
  • 🐞 ホバーされた通知を閉じた後に通知タイマーが再開しない問題を修正しました。 #59435 @zombieJ
  • 🐞 DatePicker と TimePicker RangePicker が ConfigProvider locale.DatePicker を適用しない問題を修正しました。 #59356 @QDyanbing
  • 🐞 コンポーネント名の代わりに Select を使用して renderEmpty を呼び出す TreeSelect と Mention を修正しました。 #59364 @QDyanbing
  • 🐞 ConfigProvider select から allowClear を誤って継承する AutoComplete を修正しました。 #59358 @QDyanbing
  • 🐞 cli がファイル名リンクをリンクするときに linkProps.onClick を無視してアップロードする問題を修正しました。 #59324 @QDyanbing
  • 🐞 貼り付け後に間違ったセルに着地するInput.OTPフォーカスを修正しました。 #59479 @dogledogle
  • 🐞 onClick が提供されている場合にタイポグラフィーのテキスト編集が機能しない問題を修正しました。 #59325 @QDyanbing
  • 🐞 closable.disabled が true の場合、アラートを閉じるボタンが clickable のままになる問題を修正。 #59432 @QDyanbing
  • 🐞 最初のタブを選択するときにカードがtabProps.defaultActiveKeyを無視する問題を修正しました。 #59414 @QDyanbing
  • 🐞 親項目に href または path がない場合、undefined で始まるパンくずリストのドロップダウン メニュー リンクを修正しました。 #59423 @QDyanbing
  • 🐞 設定されたサイズなしでより大きなブレークポイントが一致した場合に、アバターがデフォルトのサイズに戻る問題を修正しました。 #59446 @QDyanbing
  • 🐞 水平方向の小数点以下の offset 値が切り捨てられるバッジを修正しました。 #59314 @QDyanbing
  • 🐞 読み込み遅延が終了する前に表示されるボタンのカスタム読み込みアイコンを修正しました。 #59353 @QDyanbing
  • 🐞 ツアー nextButtonProps.onClick と prevButtonProps.onClick がマウス イベントを受信しない問題を修正しました。 #59332 @QDyanbing
  • 🤖 Form.Item、Rate、および QRCode TypeScript 定義を修正して、サポートされていないプロパティを除外します。 #59373 #59379 #59408 @QDyanbing
  • 🤖 abort ハンドルを公開するようにアップロード カスタム リクエスト タイプを修正しました。 #59382 @QDyanbing
  • 🌐 残りのロケールに欠落している DatePicker プレースホルダーとカルーセル矢印ラベルを追加します。 #59351 @shoutoutuoadi325
  • 🌐 ルーマニア語 (ro_RO) ロケール翻訳を改善します。 #59528 @vicuts

-テーブル

  • 🐞 テーブルツリーデータの「すべて選択」を使用すると子孫行が欠落する問題を修正しました。 #59342 @QDyanbing
  • 🐞 テーブルでpreserveSelectedRowKeysがオンになっている場合、rowSelectionのonSelectが予約キーのundefinedを返す問題を修正しました。 #59449 @Chaoqi31
  • 🐞 テーブルcolumn.filterDropdownProps.popupRenderが有効にならない問題を修正。 #59393 @ramen2020
  • 🐞 scroll が ConfigProvider のみで設定されている場合、ページめくりまたはフィルタリング後にテーブルが最初の行にスクロールしない問題を修正しました。 #59394 @ramen2020
  • 🐞 テーブル v6 論理方向属性移行後、固定列シナリオで列 z-index を選択しても有効にならない問題を修正しました。 #58609 @leshalv
  • 転送
    • 🐞 TransferのselectAllLabelsを値0に設定すると、デフォルトのコピー数に戻ってしまう問題を修正しました。 #59487 @QDyanbing
    • 🐞 一方向転送でエントリが削除された後、制御された選択状態がチェックされたままになる問題を修正しました。 #59428 @yunfeizhu
    • 🐞転送でShiftキーを押しながら連続選択すると検索非表示項目が選択されてしまう問題と、検索結果変更後の選択範囲が正しくなくなる問題を修正しました。 #59348 @QDyanbing
  • 木
    • 🐞 Tree.DirectoryTreeで数字キーとdefaultExpandAllを使用した場合にShift範囲選択に失敗する問題を修正しました。 #59375 @QDyanbing
    • 🐞 Tree.DirectoryTreeでShiftキーを押しながら連続選択するとselectable: falseまたはdisabled: trueノードが選択されてしまう問題を修正。 #59341 @QDyanbing -カルーセル
    • 🐞 dotPlacement が原因で、RTL でポートレート モードに変更すると、カルーセルが依然としてスライド順序をミラーリングして逆にする問題を修正しました。 #59436 @Chaoqi31
    • 🤖 無効な verticalSwiping 属性を公開するカルーセル タイプを修正しました。 #59366 @QDyanbing
  • 🐞 List、Divider、Drawer が値 0 コンテンツを正しくレンダリングできない問題を修正しました。 #59118 #59517 #59437 @nrps9909 @Ye-YiChen @Chaoqi31
  • 🐞通知でホバー通知を閉じた後、他の通知のタイミングが復元できない問題を修正しました。 #59435 @zombieJ
  • 🐞 DatePicker、TimePickerのRangePickerにConfigProvider locale.DatePickerが適用されない問題を修正。 #59356 @QDyanbing
  • 🐞 TreeSelect および Mentions で renderEmpty を呼び出すときに、それぞれのコンポーネント名の代わりに Select が渡される問題を修正しました。 #59364 @QDyanbing
  • 🐞 AutoComplete が ConfigProvider select.allowClear を誤って継承する問題を修正しました。 #59358 @QDyanbing
  • 🐞 アップロードでファイル名のリンクをクリックしたときに linkProps.onClick がトリガーされない問題を修正しました。 #59324 @QDyanbing
  • 🐞Input.OTPを貼り付けた後、間違ったグリッドにフォーカスが当たる問題を修正しました。 #59479 @dogledogle
  • 🐞 onClick提供時、Typographyがテキスト編集状態にならない問題を修正。 #59325 @QDyanbing
  • 🐞 closable.disabled が true の場合でも [アラートを閉じる] ボタンをクリックできる問題を修正しました。 #59432 @QDyanbing
  • 🐞カードtabProps.defaultActiveKeyで初期選択タブが設定できない問題を修正しました。 #59414 @QDyanbing
  • 🐞 ブレッドクラムの親が href と path を設定していない場合、ドロップダウン メニューのリンクが undefined で始まる問題を修正しました。 #59423 @QDyanbing
  • 🐞 より大きなブレークポイントに一致し、対応するサイズが設定されていない場合に、アバターが誤ってデフォルトのサイズを復元してしまう問題を修正します。 #59446 @QDyanbing
  • 🐞 バッジでレベル offset の小数値が切り捨てられる問題を修正しました。 #59314 @QDyanbing
  • 🐞 遅延が終了する前にボタンのカスタム読み込みアイコンが事前に表示される問題を修正します。 #59353 @QDyanbing
  • 🐞 TourのnextButtonProps.onClick、prevButtonProps.onClickでマウスイベントが取得できない問題を修正しました。 #59332 @QDyanbing
  • 🤖 Form.Item、Rate、QRCode の TypeScript 型定義を修正して、無効な属性を除外します。 #59373 #59379 #59408 @QDyanbing
  • 🤖 abort キャンセル ハンドルの取得をサポートするために、アップロード カスタム アップロード リクエストの型宣言を修正しました。 #59382 @QDyanbing
  • 🌐 残りの言語パックで欠落している DatePicker プレースホルダー コピーとカルーセル矢印ラベルを補足します。 #59351 @shoutoutuoadi325
  • 🌐 ルーマニア語 (ro_RO) 言語パックの翻訳を改善しました。 #59528 @vicuts
