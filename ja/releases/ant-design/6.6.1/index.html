ant-design 6.6.1

パッチ 公開日2026年8月17日 出典ant-design/ant-design 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#アリデザイン6.6.1

  • ♿ アップロード アクション、モーダルおよび通知を閉じるボタンのローカライズされたアクセス可能な名前を改善しました。 #58953 #58957 @nrps9909
  • 🌐 ローカライズされたコンポーネント全体で繁体字中国語の用語を改善し、DatePicker で台湾で推奨される週の表現を使用します。 #58947 #58951 @nrps9909
  • 🐞 非同期 onRemove が解決されると、新しく追加されたファイルが削除されるアップロードを修正しました。 #58814 @afc163
  • 🐞 getCurrentAnchor を使用するときにアンカーがスクロール時に重複した onChange コールバックをトリガーする問題を修正しました。 #58834 @nikzanda
  • フォーム
    • 🐞 rapid 検証状態の変更中のフォームの高さの変動を修正しました。 #59008 @waterWang
    • 🐞 フォームの垂直レイアウト labelCol.offset がラベルの余白によって上書きされる問題を修正しました。 #58981 @nikzanda
    • ♿ ラベルをネストされたコントロールに明示的に関連付けられるように、フォームの複合コントロールのガイダンスを改善しました。 #59001 @nrps9909
    • 📝 Form.Item required のドキュメントを修正して、検証ルールが設定されていないときに必要な状態を推測することを明確にしました。 #58989 @QDyanbing
  • リスティ
    • 💄 Listy 仮想スクロールバー トラックのホバー フィードバックを改善します。 #58964 @QDyanbing
    • 📝 アイテムのレンダリング、仮想スクロール、一般的な置換パターンをカバーする、非推奨の List に対する List から Listy への移行ガイダンスを追加します。 #58985 @aojunhao123
    • 📝 Listy のドラッグ並べ替えデモを追加します。 #58962 @li-jia-nan
  • メニュー
    • 🐞 インライン メニューを展開または折りたたむときにメニュー アイコンが揺れる問題を修正しました。 #59018 @afc163
    • 🐞 項目をホバーしているときにインライン メニューが折りたたまれたときにメニュー ツールチップが点滅する問題を修正しました。 #58865 @QdabuliuQ
  • テーブル
    • 🐞 bordered が有効で、showHeader が false の場合のテーブルの最初の行のコーナーを修正しました。 #57035 @Largopie
    • 🐞 展開された行が rowSpan 範囲をオフセットしている場合に、表の行にカーソルを合わせると間違ったセルが強調表示される問題を修正しました。 #58935 反応コンポーネント/テーブル#1488 @jiangrong-devops
  • 転送
    • 🐞 検索入力をクリアするときに onSearch を 2 回トリガーする転送を修正しました。 #59016 @QDyanbing
    • 🐞 locale.remove を考慮しない一方向アイテムの転送アクションを修正しました。 #58955 @nrps9909
  • 🇮🇸🇲🇳 アイスランド語とモンゴル語のロケールのフォーム最小値検証メッセージの無効なプレースホルダーを修正しました。 #58965 @nrps9909
  • 🆕 ConfigProvider locale を介して、デフォルトの前と次の矢印にカルーセルのローカライズされたアクセス可能な名前を追加します。 #59014 @waterWang
  • ♿ カスタム セパレータのアクセシビリティを維持しながら、装飾的なデフォルトのセパレータを非表示にすることで、DatePicker.RangePicker スクリーン リーダーのエクスペリエンスを向上させました。 #58999 @nrps9909
  • ♿ インタラクティブなアイコン トリガーのアクセス可能な名前を維持しながら、装飾的なデフォルトの展開アイコンから冗長なラベルを非表示にすることで、折りたたみスクリーン リーダーのエクスペリエンスを改善しました。 #59000 @nrps9909
  • 🐞 TreeSelect SHOW_PARENT が制御モードで選択された無効な子ノードを失う問題を修正しました。 #58935 反応コンポーネント/ツリー選択#681 @zombieJ
  • ⌨️ Enter または Space でアクティブ化したときに選択クリア ボタンの値がクリアされない問題を修正しました。 #58958 反応コンポーネント/select#1247 @Pareder
  • 🐞 カスタム入力とホバー時にコンテンツを移動する allowClear によるオートコンプリートを修正しました。 #58932 @lazerg
  • 🐞 一部のページで、FloatButton.BackTop の進行状況リングの境界線が最初に表示される前にオーバーライドされる問題を修正しました。 #58982 @ZQDesigned
  • 🐞 クリアボタンを二度cliクリックした後にColorPickerがドラッグできなくなる問題を修正。 #58995 @dogledogle
  • 🐞 Radio.Group オプションが選択されたときにオプションの onChange コールバックを呼び出さない問題を修正しました。 #59010 @moon6967
  • 💄 動的コンテナ border-radius の変更との BorderBeam ビーム半径の同期を改善します。 #58923 @li-jia-nan
  • 📝 タイポグラフィ編集可能な onChange ドキュメントを修正し、編集完了時に起動することを明確にしました。 #59021 @EmilyyyLiu
  • ♿ アップロード アクション ボタン、モーダルおよび通知を閉じるボタンのローカライズされたアクセシビリティ名を最適化します。 #58953 #58957 @nrps9909
  • 🌐 複数のコンポーネントの繁体字中国語の用語を最適化し、DatePicker の週の選択プロンプトを台湾の慣用句に合わせて調整します。 #58947 #58951 @nrps9909
  • 🐞非同期onRemoveのアップロード完了時に新しく追加したファイルを誤って削除してしまう問題を修正しました。 #58814 @afc163
  • 🐞 アンカーが getCurrentAnchor を使用しているときにスクロールすると、繰り返し onChange がトリガーされる問題を修正しました。 #58834 @nikzanda
  • フォーム
    • 🐞 ステータスの変更を素早く確認するときにフォームが非常に不安定になる問題を修正しました。 #59008 @waterWang
    • 🐞 フォームの縦レイアウトでラベルの余白がlabelCol.offsetを覆ってしまう問題を修正しました。 #58981 @nikzanda
    • ♿ ラベルを内部コントロールに明示的にリンクすることをサポートするために、フォームの複雑なコントロールのガイダンスを改善しました。 #59001 @nrps9909
    • 📝 Form.Item required ドキュメントを修正して、設定されていない場合、必要なステータスが検証ルールに基づいて推測されることを明確にします。 #58989 @QDyanbing -リスティ
    • 💄 Listy 仮想スクロール バー トラックのホバー フィードバックを最適化します。 #58964 @QDyanbing
    • 📝 アイテムのレンダリング、仮想スクロール、および一般的な代替手段をカバーする、非推奨のリストの Listy への移行に関するガイダンスを追加しました。 #58985 @aojunhao123
    • 📝 Listy ドラッグソートの例を追加しました。 #58962 @li-jia-nan -メニュー
    • 🐞 メニューインラインメニューを展開または折りたたんだときにアイコンが揺れる問題を修正しました。 #59018 @afc163
    • 🐞 メニューのインライン メニューで、メニュー項目をホバーしたときにツールヒントがちらつく問題を修正しました。 #58865 @QdabuliuQ -テーブル
    • 🐞 borderedがオンでshowHeaderがfalseの場合、テーブルの1行目の角が異常に丸くなる問題を修正しました。 #57035 @Largopie
    • 🐞 テーブルが行を展開するときに rowSpan 範囲がオフセットされると、行ホバーで強調表示されたセルが正しくなくなる問題を修正しました。 #58935 反応コンポーネント/テーブル#1488 @jiangrong-devops
  • 転送
    • 🐞 転送で検索入力ボックスをクリアすると、onSearch が繰り返しトリガーされる問題を修正しました。 #59016 @QDyanbing
    • 🐞一方通行モードのアイテム削除ボタンがlocale.removeを正しく使用しない問題を修正しました。 #58955 @nrps9909
  • 🇮🇸🇲🇳 アイスランド語とモンゴル語のフォームの最小値チェック メッセージの無効なプレースホルダーを修正しました。 #58965 @nrps9909
  • 🆕 カルーセルのデフォルトのフロントページとバックページの矢印のローカライズされたアクセシビリティ名を追加しました。これは、ConfigProvider locale を通じて設定できます。 #59014 @waterWang
  • ♿ DatePicker.RangePicker の画面読み取りエクスペリエンスを最適化し、カスタム セパレーターのアクセシビリティを維持しながら、非セマンティックなデフォルトのセパレーターを非表示にします。 #58999 @nrps9909
  • ♿ Collapse の画面読み取りエクスペリエンスを最適化し、インタラクティブなアイコン トリガーのアクセス可能な名前を維持しながら、装飾的なデフォルトの拡張アイコンの冗長なラベルを非表示にします。 #59000 @nrps9909

  • 🐞 AutoComplete カスタム入力コンポーネントを allowClear で使用するときに、ホバーによりコンテンツが移動する問題を修正しました。 #58932 @lazerg
  • 🐞 一部のページが初めて表示される前に、FloatButton.BackTop の進行状況リングの境界線が隠れてしまう問題を修正しました。 #58982 @ZQDesigned
