ant-design 6.5.3

パッチ 公開日2026年7月31日 出典ant-design/ant-design 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#アリデザイン6.5.3

  • 入力
    • 🐞 明示的な type 値を保持しながら、mask が文字列の場合に type="text" を使用する Input.OTP を修正しました。 #58835 @QDyanbing
    • 🐞 mask が true の場合に、Input.OTP が元の値を表示する問題を修正しました。 #58805 @cyphercodes
    • 💄 タッチデバイス上でドットとしてレンダリングされるInput.TextAreaのサイズ変更ハンドルを修正しました。 #58812 @pupuking723
  • タイポグラフィー
    • ⚡️ 大きなリストでのタイポグラフィの省略記号ツールチップのパフォーマンスを向上させます。 #58806 @lkxdsb
    • 🐞 タイポグラフィの編集可能なテキストエリアのフォントサイズが編集内容と一致しない問題を修正。 #58551 @gaurav0107
  • 🐞 showTime および allowEmpty を使用する場合、ブラーで未確認の部分値を送信する DatePicker.RangePicker を修正しました。 #58803 @zombieJ
  • 🐞 検証ステータスが変更されていない場合に古いエラーと警告を返す Form.Item useStatus を修正しました。 #58815 @afc163
  • 🐞 onFocus および onBlur コールバックを複数回トリガーするスライダーを修正しました。 #58711 @QDyanbing
  • 🐞 別の Spin にネストされている場合に、Spin スタンドアロン インジケーターが誤って配置される問題を修正しました。 #58801 @QDyanbing
  • 🐞 開いているときにテーブルで制御されたフィルターのドロップダウン選択が更新されない問題を修正しました。 #58816 @afc163
  • 🐞 新しく開いたタブがオープナー ページにアクセスできるように、デフォルトのダウンロード リンクをアップロードする問題を修正しました。 #58817 @afc163
  • 💄 theme.zeroRuntime または CSS レイヤーが有効な場合の不完全なアイコン ベース スタイルを修正します。 #58763 @QDyanbing
  • 💄 カスタムテーマカラーを使用したクリアアイコンと重なる選択サフィックスアイコンと選択したコンテンツを修正します。 #58581 @QDyanbing
  • 💄 タブのサードパーティ製 <svg> アイコンがラベルと垂直方向に揃っていない問題を修正しました。 #58847 @mohamedkhaled4053
  • 入力
    • 🐞 Input.OTP を修正するには、文字列 mask を使用しますが、 type="text" の問題を採用し、形式 type の構成を維持します。 #58835 @QDyanbing
    • 🐞 Input.OTP の mask を true に修正すると、元の値の問題が表示されます。 #58805 @cyphercodes
    • 💄 Input.TextArea を修正して、ハンドルのサイズを調整すると、タッチ デバイス上で小さな点の問題が表示されます。#58812 @pupuking723
  • タイポグラフィー
    • ⚡️ タイポグラフィーを促進し、大列表内の染込みパフォーマンスの提案を省略しています。
    • 🐞 タイポグラフィーを修正すると、本文の文字番号が、解釈される内容と一致しない問題が発生します。
  • 🐞 DatePicker.RangePicker を修正して showTime および allowEmpty を使用すると、時間遅れにより未確認の部分値の問題が発生する可能性があります。#58803 @zombieJ
  • 🐞 Form.Item useStatus を修正すると、チェック状態が変化しないときに古い警告と警告内容の問題が返されます。#58815 @afc163
  • 🐞 Slider の onFocus と onBlur が繰り返し起動される問題を修正しました。
  • 🐞 スピン独立追加インジケーターの互換性を使用する時間指定乱数の問題を修正しました。 #58801 @QDyanbing
  • 🐞 テーブルの制御下でパネルが開いたままになる問題は、同時に更新されません。#58816 @afc163
  • 🐞 アップロードを修正すると、ダウンロードが開始された新しい面がソース面の問題を引き起こす可能性があります。
  • 💄 theme.zeroRuntime または CSS レイヤーを使用して修正する場合、アイコンの基本形式が不完全になる問題があります。#58763 @QDyanbing
  • 💄 修正 メインの色の下にある画像マークを選択するか、削除画像マークに追加されるコンテンツを選択します。 #58581 @QDyanbing
  • 💄修正タブ中三方 <svg> 図マークとマーク文字が垂直方向に表示されない問題。#58847 @mohamedkhaled4053
