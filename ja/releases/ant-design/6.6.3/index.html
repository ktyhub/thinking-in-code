ant-design 6.6.3

パッチ 公開日2026年9月7日 出典ant-design/ant-design 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#アリデザイン 6.6.3

  • 🐞 prefix、suffixIcon、allowClear.clearIcon、または renderExtraFooter によって返される値が 0 の場合の DatePicker および TimePicker レンダリングの問題を修正します。 #59212 反応コンポーネント/ピッカー#1009 @github-actions @QDyanbing
  • 🐞 mask 構成オブジェクトを再利用する場合のモーダル マスクとドロワー マスク click の終了動作を修正しました。 #59233 @giaBaoJS
  • 🤖 Select、AutoComplete、Cascader、および TreeSelect popupRender タイプを修正して、ReactElement を受け入れ、ReactNode を返すようにしました。 #59207 @QDyanbing
  • 日付ピッカー
    • 🇩🇪 ドイツ語ロケールで誤ったデフォルトの日付と日時の形式を使用する DatePicker を修正し、それぞれ DD.MM.YYYY と DD.MM.YYYY HH:mm:ss を使用します。 #59151 @nrps9909
    • 🐞 minDate または maxDate で設定された月の境界に移動すると、DatePicker ポップアップが予期せず閉じる問題を修正しました。 #59212 反応コンポーネント/ピッカー#1012 @github-actions @zombieJ
    • 🐞 showTime が有効な状態で別の日付の上にマウスを移動すると、DatePicker.RangePicker が保留中の日付選択のハイライトを失う問題を修正しました。 #59212 反応コンポーネント/ピッカー#1010 @github-actions @zombieJ
    • 🌐 32 のロケールで、欠落している DatePicker の年、四半期、月、週、および範囲のプレースホルダーを追加します。 #59219 @stop1love1
    • 🌐 DatePicker 確認ボタンと ColorPicker のグラデーション カラーの繁体字中国語 (台湾) テキストを修正しました。 #59129 @nrps9909
  • アイコン
    • 🆕 MetaFilled と NetflixFilled のブランドアイコンをアイコンに追加します。 #59178 ant-design-icons#755 @github-actions @mohamedkhaled4053
    • 🐞 アイコン XFilled が実線の正方形としてレンダリングされる問題を修正しました。 #59178 ant-design-icons#758 @github-actions @QDyanbing
    • 🐞 Bun にバンドルされている場合にアイコンのレンダリングに失敗する問題を修正しました。 #59178 ant-design-icons#768 @github-actions @zombieJ
    • 🐞 アイコン定義が無効な場合にアイコンがページをクラッシュさせる問題を修正しました。 #59178 ant-design-icons#762 @github-actions @nrps9909
  • 入力
    • 🐞 可視性の切り替えをアクティブにするときに制御された可視性を無視する Input.Password を修正しました。 #59168 @QDyanbing
    • ⌨️ Enter または Space を押したときに、Input.Password でパスワードの表示が繰り返し切り替わる問題を修正しました。 #59135 @nrps9909
    • 🐞 Input.Search がカスタム enterButton onMouseDown ハンドラーを呼び出さない問題を修正しました。 #59180 @QDyanbing
  • 🐞 popupRender が null、配列、または数値を返すときのドロップダウンのスロー エラーを修正します。 #59207 @QDyanbing
  • 🐞 value が undefined の場合、Checkbox.Group でデフォルトの選択が失われ、選択の更新に失敗する問題を修正しました。 #59217 @dogledogle
  • 🐞 value が undefined の場合、Radio.Group の選択が更新されない問題を修正しました。 #59162 @dogledogle
  • 🐞 collapsed を undefined に設定して cli がトリガーを引いたときに、Layout.Sider が折りたたまれない問題を修正しました。 #59175 @dogledogle
  • 🐞 テーブルの単一選択ツリー フィルターで空の文字列値が選択されない問題を修正しました。 #59141 @QDyanbing
  • 🐞 RTL モードで Image.PreviewGroup のナビゲーション矢印が間違った方向を指している問題を修正しました。 #59145 @dogledogle
  • ⌨️ Enter キーまたは Space キーを押したときにタグの閉じるボタンと Tag.CheckableTag が繰り返しアクティブになる問題を修正しました。 #59134 @nrps9909
  • ♿ ステップ進行状況アイコンのアクセシビリティセマンティクスを改善し、ハードコードされた英語名を削除します。 #59073 @giaBaoJS
  • 🌐 45 のロケールでカルーセル ナビゲーション矢印のローカライズされたアクセシビリティ対応の名前を追加します。 #59218 @stop1love1
  • 🐞 DatePicker、TimePickerのprefix、suffixIcon、allowClear.clearIcon、renderExtraFooterの戻り値が0の場合に描画が異常になる問題を修正しました。 #59212 反応コンポーネント/ピッカー#1009 @github-actions @QDyanbing
  • 🐞モーダルとドロワーがmask設定オブジェクトを再利用する場合、マスクをクリックして閉じるときの異常な動作の問題を修正しました。 #59233 @giaBaoJS
  • 🤖 ReactElement の受信と ReactNode の返しをサポートするために、Select、AutoComplete、Cascader、および TreeSelect の popupRender タイプを修正しました。 #59207 @QDyanbing -DatePicker
    • 🇩🇪 ドイツ語のロケール設定で、それぞれ DD.MM.YYYY と DD.MM.YYYY HH:mm:ss を使用する DatePicker のデフォルトの日付と日時の形式が正しくない問題を修正しました。 #59151 @nrps9909
    • 🐞 DatePicker を minDate または maxDate に設定した後に境界月に切り替えると、パネルが予期せず閉じてしまう問題を修正しました。 #59212 反応コンポーネント/ピッカー#1012 @github-actions @zombieJ
    • 🐞 DatePicker.RangePicker が showTime オンのときに、他の日付をマウスオーバーすると、確定する日付の選択スタイルが失われる問題を修正しました。 #59212 反応コンポーネント/ピッカー#1010 @github-actions @zombieJ
    • 🌐 DatePicker に欠落していた年、四半期、月、週、および 32 の言語パックに対応する範囲選択のプレースホルダー コピーを追加しました。 #59219 @stop1love1
    • 🌐 DatePicker 確認ボタンと ColorPicker のグラデーション カラーの繁体字中国語 (台湾) のコピーライティングを修正しました。 #59129 @nrps9909 -アイコン
    • 🆕 新しいアイコンブランドアイコン MetaFilled と NetflixFilled を追加しました。 #59178 ant-design-icons#755 @github-actions @mohamedkhaled4053
    • 🐞アイコンのXFilledアイコンが塗りつぶされた四角で表示される問題を修正しました。 #59178 ant-design-icons#758 @github-actions @QDyanbing
    • 🐞 Bunパッケージ化後にアイコンが表示されなくなる問題を修正しました。 #59178 ant-design-icons#768 @github-actions @zombieJ
    • 🐞 アイコンが無効なアイコン定義に遭遇したときにページがクラッシュする問題を修正しました。 #59178 ant-design-icons#762 @github-actions @nrps9909 -入力
    • 🐞 可視性を切り替えるときに、Input.Password が制御された可視性状態に従わない問題を修正しました。 #59168 @QDyanbing
    • ⌨️ Enter キーまたはスペースバーを長押しすると、Input.Password がパスワードの表示状態を繰り返し切り替える問題を修正しました。 #59135 @nrps9909
    • 🐞Input.Search がカスタム enterButton の onMouseDown コールバックをトリガーしない問題を修正しました。 #59180 @QDyanbing
  • 🐞 ドロップダウンの popupRender が null、配列、数値などのコンテンツを返すときにエラーをスローする問題を修正しました。 #59207 @QDyanbing
  • 🐞 Checkbox.Groupのvalueがundefinedの場合、デフォルトの選択項目が無効となり、選択状態が更新できない問題を修正しました。 #59217 @dogledogle
  • 🐞 valueがundefinedの場合、Radio.Groupが選択項目を更新できない問題を修正しました。 #59162 @dogledogle
  • 🐞 collapsedがundefinedの場合、Layout.Siderをクリックして折りたたむことができない問題を修正しました。 #59175 @dogledogle
  • 🐞 テーブルツリーラジオ選択フィルターで空の文字列値が選択できない問題を修正しました。 #59141 @QDyanbing
  • 🐞 RTLモードでImage.PreviewGroup切り替えボタンの矢印の方向が間違っている問題を修正しました。 #59145 @dogledogle
  • ⌨️ Enter キーまたはスペースバーを長押しすると、タグの閉じるボタンと Tag.CheckableTag が繰り返し操作をトリガーする問題を修正しました。 #59134 @nrps9909
  • ♿ ステップ進行状況アイコンのアクセシビリティ セマンティクスを最適化し、ハードコーディングされた英語名を削除します。 #59073 @giaBaoJS
  • 🌐 45 の言語パックにカルーセルのフロントページとバックページの矢印のアクセシビリティ名を追加しました。 #59218 @stop1love1
