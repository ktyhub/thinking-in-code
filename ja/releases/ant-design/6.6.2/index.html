ant-design 6.6.2

パッチ 公開日2026年8月28日 出典ant-design/ant-design 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#アリデザイン6.6.2

  • ♿ 冗長な SVG アナウンスを回避し、キーボードのアクティブ化でステップ項目 onClick をトリガーし、既存のツールチップ aria-describedby 関係を維持することにより、進行状況、ステップ、およびツールチップのアクセシビリティを向上させます。 #59139 @github-アクション
  • 🐞 Alert、Empty、Card、Tag、Breadcrumb、Segmented、FloatButton、Form.Item、Statistic にわたる数値 0 コンテンツのレンダリングを修正します。 #59117 #59094 #59079 #59101 @bhumin18 @QDyanbing @dogledogle
  • 🤖 サポートされていないコールバックまたはプロパティを誤って公開するアラート グローバル closable および選択およびオートコンプリート onPopupVisibleChange タイプ定義を修正しました。 #59100 #59142 @QDyanbing
  • メニュー
    • ⌨️ 複数のインスタンス間で重複するメニュー ポップアップ ID を修正します。 #59048 @zombieJ
    • 🐞 ポインタが項目からそのポップアップに移動すると、メニューの水平サブメニューが予期せず閉じる問題を修正しました。 #59088 @EmilyyyLiu
    • 🐞 インライン メニューの折りたたみが終了した後もメニュー アイコンが動き続ける問題を修正しました。 #59085 @QDyanbing
  • 転送
    • 🐞 すべての検索結果が無効になっている場合でも、「全選択を転送」チェックボックスが有効のままになる問題を修正しました。 #59121 @QDyanbing
    • 🐞 フィルタリングされたデータが空の結果から復元された後、アイテムがレンダリングされない転送を修正しました。 #59074 @biubiukam
  • テーブル
    • 🐞 Enter 以外のキーに対してカスタム onKeyDown ハンドラーを呼び出さないテーブルの並べ替え可能な列を修正します。 #59078 @QDyanbing
    • 🐞 組み込みフィルター ドロップダウンを閉じるときに filterDropdownProps.onOpenChange(false) を 2 回トリガーするテーブルを修正しました。 #59023 @thlovey
  • 木
    • 🐞 expandedKeys または selectedKeys が明示的に undefined である場合、Tree.DirectoryTree がノードの展開または選択に失敗する問題を修正しました。 #59076 @giaBaoJS
    • 🐞 key が数値 0 であるノードから開始するときの Tree.DirectoryTree のシフト範囲選択を修正します。 #59029 @QDyanbing
  • リスト
    • 🐞 rowKey が数値 0 を返す場合のリストの再マウント項目を修正しました。 #59113 @nrps9909
    • 🛎 Listy への移行を推奨するために List の非推奨に関する警告を更新します。 #59060 @QDyanbing
  • 🐞 Checkbox.Group disabled={false} が JSX の子のグローバル無効状態をオーバーライドできない問題を修正しました。 #59109 @QDyanbing
  • 🐞 GIF プレビューを生成した後、DOM に非表示のキャンバス要素が残るアップロードを修正しました。 #59137 @dogledogle
  • 🐞 通知を閉じるボタンが意図せず同封フォームを送信する問題を修正しました。 #59126 @nrps9909
  • 🐞 extra プロップのみが提供されている場合に、ドロワーヘッダーのアクション領域がレンダリングされない問題を修正しました。 #59089 @dogledogle
  • 🐞 小道具が削除された後、またはレスポンシブ ブレークポイントの一致が停止した後、古い align および justify クラスが保持されるグリッド行を修正しました。 #59066 @QDyanbing
  • 🐞 ConfigProvider tag.style によって上書きされる Tag.CheckableTag ローカル style を修正します。 #59087 @QDyanbing
  • ♿ 装飾パネルの矢印を支援技術から非表示にすることで、階段へのアクセシビリティを向上させます。 #59105 @nrps9909
  • ♿ 装飾的なプレースホルダー グラフィックを支援技術から非表示にすることで、Skeleton.Image のアクセシビリティを向上させます。 #59107 @nrps9909
  • 🐞 key: 0 でアイテムを再注文した後にアイテムの状態がリセットされる説明を修正しました。 #59064 @QDyanbing
  • 🐞 notFoundContent が null の場合にデフォルトの空の状態を表示する Cascader と Cascader.Panel を修正しました。 #59028 @QDyanbing
  • 🐞 content が undefined の場合にエラーをスローするウォーターマークを修正しました。 #59077 @VamoBao
  • 📖 Web サイトのミラーおよびローカル展開上のコンポーネント LLM リンクを修正します。 #59062 @QDyanbing
  • ♿ 進行状況、ステップ、ツールチップのアクセシビリティ エクスペリエンスを最適化し、進行状況バーの SVG が繰り返し読み取られるのを回避し、ステップ項目がキーボードでアクティブ化されたときに onClick がトリガーされるようにし、ツールチップの既存の aria-describedby 関連付けを保持します。 #59139 @github-actions
  • 🐞 Alert、Empty、Card、Tag、Breadcrumb、Segmented、FloatButton、Form.Item、Statistic が値 0 コンテンツを正しくレンダリングできない問題を修正しました。 #59117 #59094 #59079 #59101 @bhumin18 @QDyanbing @dogledogle
  • 🤖 アラート グローバル closable、Select、および AutoComplete の onPopupVisibleChange タイプ定義エラーにより、コールバックまたはプロパティがサポートされていないことが明らかになった問題を修正しました。 #59100 #59142 @QDyanbing -メニュー
    • ⌨️複数のメニュー インスタンス間でポップアップ ID が重複する問題を修正しました。 #59048 @zombieJ
    • 🐞 メニューランドスケープモードでマウスをメニュー項目からサブメニューポップアップレイヤーに移動すると、サブメニューが予期せず閉じてしまう問題を修正しました。 #59088 @EmilyyyLiu
    • 🐞 インラインメニューが縮小した後、メニューアイコンが移動し続ける問題を修正しました。 #59085 @QDyanbing
  • 転送
    • 🐞 すべての転送検索結果が無効なアイテムである場合に、「すべて選択」チェックボックスが引き続き使用できる問題を修正しました。 #59121 @QDyanbing
    • 🐞 Transfer が空のフィルター結果からデータを回復した後にリスト項目が表示されない問題を修正します。 #59074 @biubiukam -テーブル
    • 🐞 テーブルの並べ替え可能な列が Enter キー以外のカスタム onKeyDown コールバックをトリガーしない問題を修正しました。 #59078 @QDyanbing
    • 🐞 テーブルが内蔵フィルターパネルを閉じたときにfilterDropdownProps.onOpenChange(false)が繰り返しトリガーされる問題を修正します。 #59023 @thlovey
  • 木
    • 🐞 undefinedに明示的にexpandedKeysまたはselectedKeysを渡すとTree.DirectoryTreeの展開や選択ができない問題を修正しました。 #59076 @giaBaoJS
    • 🐞 Tree.DirectoryTree が key から 0 の値を持つノードから開始される場合、シフト範囲の選択に失敗する問題を修正しました。 #59029 @QDyanbing
  • リスト
    • 🐞 rowKey が値 0 を返した場合に List がリスト項目を再マウントする問題を修正しました。 #59113 @nrps9909
    • 🛎 Update List の非推奨に関する警告。Listy への移行を推奨します。 #59060 @QDyanbing
  • 🐞 JSX 子ノードのシナリオで Checkbox.Group disabled={false} がグローバルの無効状態をオーバーライドできない問題を修正しました。 #59109 @QDyanbing
  • 🐞 アップロードによって GIF プレビューが生成された後、DOM に非表示のキャンバス要素が残る問題を修正しました。 #59137 @dogledogle
  • 🐞 通知を閉じるボタンが予期せず外側のフォームを送信する問題を修正しました。 #59126 @nrps9909
  • 🐞 Drawerでextra属性のみを設定した場合、ヘッド操作領域が描画されない問題を修正。 #59089 @dogledogle
  • 🐞 align、justify 属性またはレスポンシブ ブレークポイントを削除した後、古い配置クラス名が保持されるグリッド行が一致しなくなる問題を修正しました。 #59066 @QDyanbing
  • 🐞 Tag.CheckableTag のローカル style が ConfigProvider tag.style によって上書きされる問題を修正しました。 #59087 @QDyanbing
  • ♿ Steps のアクセシビリティ エクスペリエンスを最適化し、支援技術のパネル内の装飾的な矢印を非表示にします。 #59105 @nrps9909
  • ♿ Skeleton.Image のアクセシビリティ エクスペリエンスを最適化し、支援技術の装飾的なプレースホルダー グラフィックを非表示にします。 #59107 @nrps9909
  • 🐞説明文のkey: 0のエントリを並べ替えるとコンテンツのステータスがリセットされる問題を修正しました。 #59064 @QDyanbing
  • 🐞 CascaderおよびCascader.PanelのnotFoundContentがnullの場合、デフォルトの空の状態が表示されたままになる問題を修正しました。 #59028 @QDyanbing
  • 🐞 content が undefined の場合にウォーターマークがエラーをスローする問題を修正しました。 #59077 @VamoBao
  • 📖 Web サイトのミラーリングおよびローカル展開でコンポーネント LLM リンクが正しく読み込めない問題を修正しました。 #59062 @QDyanbing
