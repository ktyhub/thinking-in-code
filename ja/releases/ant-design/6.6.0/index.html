ant-design 6.6.0

マイナー 公開日2026年8月10日 出典ant-design/ant-design 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#アリデザイン6.6.0

  • 🔥 グループ化、スティッキーヘッダー、強制スクロールを備えた高性能仮想化リスト用の Listy コンポーネントを追加します。 #58724 @aojunhao123
  • 構成プロバイダー
    • 🆕 ConfigProvider focusOutline テーマ トークンを追加して、入力、選択、レート、ステップ、スプリッター、その他のコンポーネントにわたる共有フォーカス アウトラインを制御します。 #58647 #58708 @QDyanbing
    • 🆕 Input.Search、Input.Password、Input.OTP 用の ConfigProvider グローバル variant 構成を追加します。 #58784 @QDyanbing
    • 🆕 Tooltip、Popover、および Popconfirm 用の ConfigProvider グローバル mouseEnterDelay および mouseLeaveDelay 構成を追加します。 #58892 @EmilyyyLiu
  • 🌐 ローカリゼーション
    • 🇦🇱 アルバニア語 sq_AL ロケールのサポートを追加します。 #58618 @li-jia-nan
  • 🆕 ノード パスを取得するためのツリー useTree を追加し、スクロールする前にターゲット ノードを展開するための scrollTo({ autoExpand: true }) をサポートします。 #58841 @zombieJ
  • 🆕 FloatButton.BackTop showProgress を追加して、ボタンの周囲の現在のスクロールの進行状況を表示します。 #58894 @ZQDesigned
  • 🆕 テーブル expandable.forceRender を追加して、最初の展開の前に展開された行コンテンツをレンダリングします。 #58860 @nikzanda
  • 🆕 ページネーション components.sizeChanger を追加して、テーブルのページネーションなどのページ サイズ チェンジャーをカスタマイズします。 #58831 @QDyanbing
  • 🆕 メンション popupRender を追加して、提案ドロップダウンのレンダリングをカスタマイズします。 #58582 @EmilyyyLiu
  • 🆕 タブ more.popupRender を追加して、オーバーフロー ドロップダウン コンテンツをカスタマイズします。 #58651 @EmilyyyLiu
  • 🆕 BorderBeam count を追加して、コンテナの境界線の周囲に複数の均等に分散されたビームを表示します。 #58691 @meet-student
  • 🆕 画像 preview.wheel を追加して、プレビューのマウス ホイール ズームを制御します。 #58728 @EmilyyyLiu
  • 🆕 アラート borderRadius コンポーネント トークンを追加して、角の半径をカスタマイズします。 #57765 @guoyunhe
  • 🆕 Avatar.Group、Badge.Ribbon、Breadcrumb、Calendar、Card.Grid、Carousel、Carousel、Descriptions、Divider、Empty、FloatButton.Group、List.Item.Meta、QRCode、Result、Skeleton、Space.Compact、Spin、Splitter、Transfer、Watermark に nativeElement ref サポートを追加します。 #58627 #58628 #58629 #58630 #58631 #58632 #58633 #58634 #58635 #58636 #58637 #58638 #58639 #58640 #58641 #58642 #58643 #58644 #58645 #58667 @li-jia-nan
  • 🤖 Alert、Carousel、Cascader、Masonry、Mentions、Radio、Slider、Statistic、Table、Tabs、Tooltip、Upload の欠落しているパブリック Props と Ref タイプをエクスポートします。 #58700 #58798 @li-jia-nan
  • 🐞 ConfigProvider とコンポーネントレベルを組み合わせる場合の Calendar、ColorPicker、DatePicker、Divider、Dropdown、Input、Masonry、Popover、Popconfirm、QRCode、Space、Spin、Tag、TimePicker、Tooltip、Typography、Badge、Drawer、FloatButton、Image、Message、Modal、Notification、Steps、Timeline、Tour、Upload のセマンティック スタイルの優先順位を修正style および styles の設定。 #58550 #58564 @QDyanbing
  • 選択
    • 🐞 祖先が非表示になっているときに選択プレースホルダーが表示されたままになる問題を修正しました。 #58572 @QDyanbing
  • 🐞 ダークモードでネイティブボタンの背景を表示する選択クリアアイコンを修正しました。 #58928 @zombieJ
  • 🐞 closable.disabled が有効になっているときに引き出しを閉じるボタンがインタラクティブのままになる問題を修正しました。 #58853 @QDyanbing
  • 🐞 子供が動的に追加されたときに最初のスライドにジャンプするカルーセルを修正しました。 #58845 @EmilyyyLiu
  • 🐞 loadingアニメーション開始時のボタンレイアウトのずれを修正。 #58690 #58712 @zombieJ
  • 🐞 ユーザーがポップアップを操作できる前にタイポグラフィの省略記号ツールチップが閉じる問題を修正し、アクション ボタンの周囲でのホバー動作を改善しました。 #58661 #58722 @zombieJ
  • 💄 選択、ツリー、テーブルの仮想スクロールバー トラックのフィードバックを改善し、テーブル スクロールバー トラックの cli ロックによるジャンプをサポートします。 #58625 #58658 @QDyanbing
  • 🔥 新しい Listy 高性能仮想リスト構成要素、コンポーネント、吸収マーク、およびコマンド形式の動作をサポートします。#58724 @aojunhao123
  • 構成プロバイダー
    • 🆕 新しい ConfigProvider メイン トークン focusOutline は、入力、選択、レート、ステップ、スプリッターなどのコンポーネントの制御に使用されます。#58647 #58708 @QDyanbing
    • 🆕 ConfigProvider の完全な局所構成 Input.Search、Input.Password、Input.OTP variant の機能が新しく追加されました。#58784 @QDyanbing
    • 🆕 ツールチップ、ポップオーバー、ポップコンファームの ConfigProvider が新しくなり、mouseEnterDelay と mouseLeaveDelay の完全なローカル構成がサポートされました。#58892 @EmilyyyLiu
  • 🌐 国际化
    • 🇦🇱新増阿尔巴尼亚语 sq_AL ロケール本地化サポート。#58618 @li-jia-nan
  • 🆕 ツリー useTree を追加して、アクセス ポイントの経路を取得し、動作前の自動展のターゲット ポイント scrollTo({ autoExpand: true }) をサポートします。
  • 🆕 FloatButton.BackTop showProgress が新しく追加され、現在の動作レベルを表示するために使用されます。#58894 @ZQDesigned
  • 🆕 新しいテーブル expandable.forceRender は、初回展の前に展実行コンテンツをサポートします。#58860 @nikzanda
  • 🆕 新しいページネーション components.sizeChanger は、各条数スイッチをサポートしており、テーブル分割に使用できます。
  • 🆕 popupRender プロパティについて新たに言及し、自己定義のダウンロード野菜単位の感染をサポートします。#58582 @EmilyyyLiu
  • 🆕 新しいタブ more.popupRender、自動的に折り畳まれたメニューのコンテンツをサポートします。#58651 @EmilyyyLiu
  • 🆕 新しい BorderBeam count プロパティ、コンテナ内で複数の均一分布を表示するストリームライトをサポートします。#58691 @meet-student
  • 🆕新しい画像 preview.wheel プロパティ、マウスを使用して解放されるかどうかを制御するために使用されます。#58728 @EmilyyyLiu
  • 🆕 新しいアラート borderRadius コンポーネント トークン、独自の円角設定に使用されます。#57765 @guoyunhe
  • 🆕 新增 Avatar.Group、Badge.Ribbon、Breadcrumb、Calendar、Card.Grid、Card.Meta、Carousel、Descriptions、Divider、Empty、FloatButton.Group、List.Item.Meta、QRCode、Result、Skeleton、Space.Compact、Spin、Splitter、Transfer、Watermark の nativeElement #58627 #58628 #58629 #58630 #58631 #58632 #58633 #58634 #58635 #58636 #58637 #58638 #58639 #58640 #58641 #58642 #58643 #58644 #58645 #58667 @li-jia-nan
  • 🤖 アラート、カルーセル、カスケード、メーソンリー、メンション、ラジオ、スライダー、統計、テーブル、タブ、ツールチップ、およびアップロードに失敗した公開プロパティと参照タイプを追加します。#58700 #58798 @li-jia-nan
  • 🐞 カレンダー、カラーピッカー、日付ピッカー、ディバイダー、ドロップダウン、入力、メーソンリー、ポップオーバー、ポップコンファーム、QRコード、スペース、スピン、タグ、タイムピッカー、ツールヒント、タイポグラフィ、バッジ、ドロワー、フロートボタン、画像、メッセージ、モーダル、通知、ステップ、タイムライン、ツアー、ConfigProviderを使用したアップロードを同時に修正コンポーネントレベルと比較した場合のセマンティックスタイルの優先順位style、styles。 #58550 #58564 @QDyanbing -選択
    • 🐞 祖先要素が非表示になっている場合でも、選択プレースホルダー テキストが表示されたままになる問題を修正します。 #58572 @QDyanbing
    • 🐞 ダークモードでクリアアイコンを選択するとネイティブボタンの背景が表示される問題を修正しました。 #58928 @zombieJ
  • 🐞 ドロワーでclosable.disabledが有効になった後も閉じるボタンが操作できる問題を修正。 #58853 @QDyanbing
  • 🐞 サブアイテムを動的に追加すると、カルーセルが自動的に最初の画像に戻る問題を修正します。 #58845 @EmilyyyLiu
  • 🐞 ボタンがloadingアニメーションを開始するときのレイアウトジャンプの問題を修正します。 #58690 #58712 @zombieJ
  • 🐞 タイポグラフィーがプロンプトを省略して早期に閉じてしまうため、弾性レイヤーとインタラクションできなくなる問題を修正し、操作ボタン付近のフローティングインタラクションを最適化しました。 #58661 #58722 @zombieJ
  • 💄 選択、ツリー、テーブルの仮想スクロール バー トラックのインタラクティブなフィードバックを最適化し、テーブル スクロール バー トラックをクリックして素早くジャンプすることをサポートします。 #58625 #58658 @QDyanbing
