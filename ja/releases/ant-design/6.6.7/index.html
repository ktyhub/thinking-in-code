ant-design 6.6.7

パッチ 公開日2026年10月20日 出典ant-design/ant-design 英語原文

#アリデザイン 6.6.7

  • 🐞 React バージョンのエクスポートが利用できない場合に、一部の実稼働ビルドで antd のロードに失敗する問題を修正しました。 #59560 react-component/util#810 @github-actions @nrps9909
  • 🐞 アンマウント後の状態更新の遅延を引き起こすボタン、フォーム、スライダー、タイポグラフィ、アップロードを修正しました。 #59560 react-component/util#806 @github-actions @nrps9909
  • 🐞 Form.Item 検証ステータスとフィードバック アイコンを継承する Select、TreeSelect、Cascader、Mentions popupRender コンテンツを修正しました。 #59463 @huytdps13400
  • 🐞 Popover と Popconfirm プリセット color がパネルの背景に適用されない問題を修正しました。 #59549 @dogledogle
  • フォーム
    • 🐞 preserve={false} を含むネストされたフィールドがアンマウントされている場合、フォームのカスタム shouldUpdate 比較で更新が欠落する問題を修正しました。 #59560 react-component/util#807 @github-actions @nrps9909
    • 🐞 コロンを表示するときに Form.Item が文字列 label から末尾の | を誤って削除する問題を修正しました。 #59599 @wfatih
    • ⌨️ aria-describedby を通じて警告のみのメッセージをコントロールに関連付けない Form.Item を修正します。 #59443 @Chaoqi31
  • 入力
    • 🐞 フィルタリング formatter を使用してテキストを貼り付けると、Input.OTP が有効な文字を失う問題を修正しました。 #59580 @yunfeizhu
    • 🐞 ルート要素の rootClassName を無視する Input.OTP を修正しました。 #59439 @Chaoqi31
    • 🐞 Input.OTP が数値 0 を separator としてレンダリングしない問題を修正しました。 #59518 @Ye-YiChen
  • テーブル
    • 🐞 選択を反転するときに現在のページのツリーの子孫をスキップし、選択をクリアするときに他のページの無効な行の選択を解除するテーブル選択メニューを修正しました。 #59570 @yunfeizhu
    • 🐞 テーブルのソートされた固定ヘッダーのホバー背景と fixedHeaderSortActiveBg トークンが有効にならない問題を修正しました。 #59554 @dogledogle
  • カラーピッカー
    • 🐞 ConfigProvider direction が ltr の場合に RTL スタイルを適用する ColorPicker を修正しました。 #59441 @Chaoqi31
    • 🐞 ColorPicker の数値入力コントロール ボタンの幅を修正しました。 #59538 @QDyanbing
  • 🐞 外側コンポーネントの境界線、間隔、セル レイアウトの影響を受けるネストされた説明を修正します。 #59547 @xushanpei
  • 🐞 ['50%', 20] などの size の文字列幅を無視し、常にコンテナを埋めるプログレス ラインを修正しました。 #59597 @wfatih
  • 🐞 borderRadius トークンが 8 を超えると、パネルの角の半径を左右の配置で 8 ピクセルに制限できないツールチップを修正しました。 #59568 @dogledogle
  • 🐞 ポップアップ コンテンツ内で 1 つの click に対して Popconfirm onPopupClick が 2 回起動する問題を修正しました。 #59440 @Chaoqi31
  • 🐞 showUploadList.extra が 0 であるか、0 を返す場合に追加のコンテンツ スタイルをアップロードする問題を修正しました。 #59438 @Chaoqi31
  • ♿ デフォルトの編集アイコンのタイポグラフィの重複ボタンのセマンティクスを修正しました。 #59112 @nrps9909
  • ⚡️ 転送元リストのレンダリングパフォーマンスを向上させます。 #59524 @QDyanbing
  • 🐞 修正および一部の構築中に React バージョン情報が失われ、ロードされた問題が追加されました。 @nrps9909
  • 🐞 アンインストール後も、ボタン、フォーム、スライダー、タイポグラフィー、およびアップロードでステータス更新の遅延が発生する問題を修正しました。 #59560 react-component/util#806 @github-actions @nrps9909
  • 🐞 Select、TreeSelect、Cascader、Mentions の popupRender コンテンツが Form.Item 検証ステータスとフィードバック アイコンを継承する問題を修正しました。 #59463 @huytdps13400
  • 🐞 PopoverとPopconfirmでプリセットcolorを設定してもパネルの背景色が反映されない問題を修正しました。 #59549 @dogledogle
  • フォーム
    • 🐞 フォームのネストフィールドを preserve={false} に設定してアンインストールした場合、カスタム shouldUpdate 判定で関連コンテンツが更新されない場合がある問題を修正しました。 #59560 react-component/util#807 @github-actions @nrps9909
    • 🐞 Form.Itemにコロンが表示されている場合、文字列labelの末尾の|を誤って削除してしまう問題を修正しました。 #59599 @wfatih
    • ⌨️ 警告情報のみがある場合に、Form.Item が aria-describedby を通じてコントロールに関連付けられない問題を修正しました。 #59443 @Chaoqi31 -入力
    • 🐞Input.OTPでフィルタータイプformatterを使用した場合、テキストを貼り付けるときに有効な文字が失われる問題を修正しました。 #59580 @yunfeizhu
    • 🐞Input.OTPルートノードにrootClassNameが適用されない問題を修正。 #59439 @Chaoqi31
    • 🐞Input.OTP が値 0 を separator としてレンダリングできない問題を修正しました。 #59518 @Ye-YiChen -テーブル
    • 🐞 テーブル選択メニューの選択を解除すると現在のページのツリー状の子ノードが省略され、選択を解除すると他のページで無効になっている行の選択状態が解除される問題を修正しました。 #59570 @yunfeizhu
    • 🐞 テーブル固定ソートヘッダーの異常なホバリング背景と fixedHeaderSortActiveBg トークンが有効にならない問題を修正しました。 #59554 @dogledogle -カラーピッカー
    • 🐞 ConfigProvider の direction が ltr の場合でも ColorPicker が RTL スタイルを適用する問題を修正しました。 #59441 @Chaoqi31
    • 🐞 ColorPicker数値入力ボックス操作ボタンの幅が異常になる問題を修正しました。 #59538 @QDyanbing
  • 🐞 ネストされた説明が外側のコンポーネントの境界線、間隔、セルのレイアウトの影響を受ける問題を修正しました。 #59547 @xushanpei
  • 🐞 文字列幅 (['50%', 20] など) が渡され、常にコンテナーを満たす場合、プログレス リニア プログレス バー size が有効にならない問題を修正しました。 #59597 @wfatih
  • 🐞 ツールチップのborderRadiusトークンが8より大きい場合、左右の伸縮レイヤーの角丸が8pxに制限されない問題を修正しました。 #59568 @dogledogle
  • 🐞 Popconfirm ポップアップ コンテンツをクリックすると onPopupClick が 2 回トリガーされる問題を修正しました。 #59440 @Chaoqi31
  • 🐞 アップロードのshowUploadList.extraが0、または0を返す場合、エクストラコンテンツスタイルが有効にならない問題を修正。 #59438 @Chaoqi31
  • ♿ タイポグラフィーのデフォルトの編集アイコンが重複したボタンのセマンティクスを公開する問題を修正しました。 #59112 @nrps9909
  • ⚡️ Transferの左側のリストのレンダリングパフォーマンスを最適化します。 #59524 @QDyanbing
