#思源v3.8.11

アップグレードのお知らせ

データベース形式

  • 主キー リッチ テキスト (形式 15 および 16)。 以前のプレビュー ビルドによって形式 15 で保存されたインライン リッチ テキストは、引き続き読み取り可能です。画像付きテキストを含む新しいブロック リッチ テキストを主キーに保存すると、データベースが少なくとも形式 16 にアップグレードされます。 主キーの互換性
  • 通常のテキスト フィールドのインライン画像 (形式 17)。 通常のテキスト フィールドに最初のインライン画像を保存すると、データベースが形式 17 にアップグレードされます。 テキスト フィールドの互換性 データベースを開くだけでは、これらのアップグレードはトリガーされません。バージョン 3.8.10 は、最大 14 のデータベース形式をサポートします。client は、サポートする形式でのみデータベースを開くことができます。新しい形式を使用する前に、同じデータを同期またはアクセスするすべてのデバイスを更新してください。事前にワークスペースをバックアップしてください。ロールバックするには、アップグレード前の完全なスナップショットを復元します。

その他の互換性の変更

  • AI 長期メモリ。 ワークスペースのスナップショットを復元すると、メモリ レコードとその失効状態の両方がロールバックされるようになりました。メモリが忘れられる前からスナップショットを復元すると、通常の有効性チェックに合格した場合、再び利用できるようになります。 長期記憶
  • カーネル API. API コントラクトによって処理される JSON リクエストには、本文の制限が 32 MiB あり、loginAuth の制限は 64 KiB です。これらの制限を超えるリクエストはコード -1 を返します。 API 契約

概要

このリリースでは、データベースの主キーのリッチ テキストとブロック編集、組み込みの日付ピッカー、統一されたカラー編集、プラグイン スナップショットの参照と復元が追加されています。 マインド マップは、カスタム ノードとコネクタ スタイル、およびノー​​ド間のフリーフォーム接続をサポートします。スタンドアロンの Markdown エディターには検索と置換が追加され、macOS にはオフラインの Markdown Quick Look プレビューが追加されます。 リリースの概要をご覧ください: YouTube

Changelogs

このバージョンでの詳細な変更点は以下のとおりです。

機能強化

  • 組み込みの日付ピッカーをサポートし、日付と時刻の編集を改善
  • HEX、RGB、およびネイティブ ピッカーによる統合カラー編集をサポート
  • データベースの主キーでリッチ テキストとブロック編集をサポート
  • macOS でのオフライン Markdown Quick Look プレビューのサポート
  • 原稿読み取り位置を復元するかどうかの選択をサポート
  • プラグインスナップショットの参照と復元をサポート
  • Linux でのカーネル プロセス アイコンの表示を改善
  • データベースの主キーとリレーション/ロールアップ フィールドの個別のエントリ アイコン コントロールをサポート
  • Linux での KDE システム プロキシ検出のサポート
  • マインド マップでノードごとのコネクタ スタイルと形状をサポート
  • 読みやすさを向上させるためにドキュメント ツリーのインデントを減らす
  • 構成可能なパスと線のパターンによる自由形式のマインド マップの関係をサポート
  • 未使用アセットのクリーンアップの無視ルールをサポート
  • 表示されているブロックへの参照をたどるときにドキュメントのコンテキストを保持する
  • モバイルボトムシートのドラッグを改善
  • スタンドアロンの Markdown エディターでの検索と置換のサポート
  • デフォルトでグループ化された検索結果の展開または折りたたみをサポート

バグ修正

  • データベース ブロックの削除後も自動ブロック収集は継続されます
  • 埋め込まれたローカル HTML 添付ファイルは iOS の外部ブラウザで開きます
