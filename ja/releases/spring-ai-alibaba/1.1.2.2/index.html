spring-ai-alibaba v1.1.2.2

#春愛アリババv1.1.2.2

AgentScope の統合

AgentScope Java は、LLM を利用したアプリケーションを構築するためのエージェント指向のプログラミング フレームワークです。

  • AgentScope – AgentScopeAgent は、AgentScope ReActAgent をグラフ ワークフローで使用する BaseAgent としてラップします。
# Add the following dependency to ochestrate AgentScope using SAA Graph
<dependency>
  <groupId>com.alibaba.cloud.ai</groupId>
  <artifactId>spring-ai-alibaba-starter-agentscope</artifactId>
  <version>1.1.2.2</version>
</dependency>

マルチエージェント パターン

  • サブエージェント – メイン オーケストレーターは、タスク/タスク出力ツールを介して特殊なサブエージェント (コードベース エクスプローラー、Web 研究者など) にタスクを委任します。 Markdown と API で定義されたサブエージェントの両方をサポートします。
  • スーパーバイザー – 中央スーパーバイザー エージェントは、カレンダー エージェントと電子メール エージェントをツール (AgentTool) としてラップし、オンデマンドで呼び出し、結果を合成します。
  • スキル – 単一エージェントは read_skill を使用してスキル コンテンツをオンデマンドでロードします。システムプロンプトには、段階的な開示とより小さなコンテキストのためにスキルの説明のみが表示されます。
  • ルーティング
    • ルーティング (シンプル) – LlmRoutingAgent はユーザーのクエリを分類し、専門のエージェント (GitHub、Notion、Slack) を並行して呼び出し、単一の回答を合成します。
    • ルーティング (グラフ) – 前処理/後処理を備えた StateGraph ノードとしての LlmRoutingAgent、およびルーティングと結果合成のための内部マージ ノード。
  • ハンドオフ
    • ハンドオフ (シングルエージェント) – 1 つの ReactAgent が状態を介してステップを進めます (例: current_step)。 ModelInterceptor は、ターンごとにステップ固有のシステム プロンプトとツールを挿入します。
    • ハンドオフ (マルチエージェント) – グラフ ノードとしての販売およびサポート エージェント。ハンドオフ ツールは、エージェント間の active_agent と条件付きエッジ ルートを更新します。
  • ワークフロー – カスタム ワークフローの例: グラフベースのフローとしての RAG (書き換え → 取得 → 準備 → エージェント) および SQL エージェント (list_tables → get_schema → run_query)。

マルチモーダルおよび音声エージェント

  • 音声エージェント – サンドイッチ アーキテクチャ (STT → ReactAgent → TTS): DashScope ASR および CosyVoice TTS を使用した WebSocket ベースのリアルタイム音声、およびテキスト入力。エージェントはサンドイッチ順序ツールを使用し、イベント (stt_chunk、agent_chunk、tts_chunk) をストリーミングします。
  • マルチモーダル – ビジョン (画像入出力) および TTS: 画像理解のための DashScope ビジョン モデルとメディア入力を備えた ReactAgent。ツール (Wanx) による画像生成、DashScopeAudioSpeechModel による TTS。構造化ツール応答の ToolMultimodalResult (url/base64)。
