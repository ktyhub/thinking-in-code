spring-ai-alibaba v1.0.0.2

#春愛アリババv1.0.0.2

最初の GA バージョンである Spring AI Alibaba 1.0.0.2 のリリースを発表できることを嬉しく思います。 Spring AI 上に構築され、Bailian と緊密に統合された Spring AI Alibaba は、チャットボット、ワークフロー、およびマルチエージェント アプリケーションの開発をサポートします。

主な機能

1. 包括的なフレームワークの統合

  • Alibaba Cloud との統合: Bailian の Dashscope を含む Alibaba サービスにシームレスに接続し、Qwen や Deepseek などのさまざまな主流 AI モデルをサポートします。

2. マルチエージェントフレームワーク

  • グラフベースのマルチエージェント フレームワーク: Langgraph からインスピレーションを得た Spring AI Alibaba Graph により、ワークフローとマルチエージェント アプリケーションを簡単に構築できます。

3. エンタープライズ対応の AI エージェント ソリューション

  • ナコス MCP レジストリ
    • 分散型 MCP 検出と負荷分散
    • MCP プロキシへの動的 API
  • 自然言語クエリを SQL ステートメントに変換するための NL2SQL。
  • 可観測性

開発者のエクスペリエンス

クイックスタートガイド

次の依存関係を Spring Boot プロジェクトに追加して、Spring AI Alibaba を使用して最初の AI アプリケーションをキックスタートします。

<dependencyManagement>
    <dependencies>
        <dependency>
            <groupId>com.alibaba.cloud.ai</groupId>
            <artifactId>spring-ai-alibaba-bom</artifactId>
            <version>1.0.0.2</version>
            <type>pom</type>
            <scope>import</scope>
        </dependency>
    </dependencies>
</dependencyManagement>

<dependencies>
    <dependency>
        <groupId>com.alibaba.cloud.ai</groupId>
        <artifactId>spring-ai-alibaba-starter-dashscope</artifactId>
    </dependency>
</dependencies>

Spring Boot スターター

  • spring-ai-alibaba-starter-dashscope - 統合モデル サービスの適応
  • spring-ai-alibaba-graph-core - AI Graph フレームワークのコア コンポーネント
  • spring-ai-alibaba-starter-nl2sql - 自然言語から SQL への変換コンポーネント
  • spring-ai-alibaba-starter-memory - セッションメモリコンポーネント
  • spring-ai-alibaba-starter-nacos-mcp-client - Nacos MCP client;推奨バージョン: Nacos 3.0.1。 Nacos 2 Server ユーザーの場合は、古いバージョン (spring-ai-alibaba-starter-nacos2-mcp-client) を使用してください。
  • spring-ai-alibaba-starter-nacos-mcp-server - Nacos MCP サーバー。推奨バージョン: Nacos ZZPH100​​ZZ。 Nacos 2 Server をご利用の場合は、旧バージョン (spring-ai-alibaba-starter-nacos2-mcp-server) をご利用ください。
  • spring-ai-alibaba-starter-nacos-prompt - Nacos プロンプト管理
  • spring-ai-alibaba-starter-arms-observation - ARMS の可観測性
  • コミュニティ コンポーネント
    • spring-ai-alibaba-starter-tool-calling-* - ツール呼び出しコンポーネント
    • spring-ai-alibaba-starter-document-reader-* - 文書読み取りコンポーネント
    • spring-ai-alibaba-starter-vector-store-* - Vector Store コンポーネント

サンプルプロジェクト

公式コミュニティは、Spring AI Alibaba に基づいた完全なフロントエンド UI とバックエンドを含む プレイグラウンド サンプル を開発しました。 Playground を使用すると、ユーザーはチャット、オブザーバビリティ、マルチラウンド会話、画像生成、マルチモダリティ、ツール呼び出し、MCP、RAG などのすべてのコア フレームワーク機能を体験できます。

その他の使用例については、Spring AI Alibaba Examples Repository を参照してください。
