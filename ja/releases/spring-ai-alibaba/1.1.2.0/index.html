spring-ai-alibaba v1.1.2.0

パッチ 公開日2026年2月2日 出典alibaba/spring-ai-alibaba 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#春愛アリババv1.1.2.0

まとめ

このリリースでは、Spring AI を 1.1.2 にアップグレードし、エージェント フレームワークのエージェント スキル サポートを追加し、ワークフロー エージェント (LlmRouting、スーパーバイザー) の並列サブエージェント実行を追加し、並列条件付きエッジ、並列集約戦略 (allOf および anyOf)、非同期ツール実行、およびツール returnDirect を使用してグラフを拡張します。また、シリアル化と MergeStrategy の修正、管理/UI の修正、ドキュメントの更新も含まれています。

詳細については、<a href="https://java2ai.com/docs/versions/" target="_blank">ドキュメント</a>をご覧ください。

特徴

エージェント

  • <a href="https://java2ai.com/docs/frameworks/agent-framework/tutorials/skills" target="_blank">ReactAgent のエージェント スキル</a> (#3975) — ReactAgent に統合されたスキル機能により、スキルと高度な開示がサポートされます。
  • 組み込みのマルチエージェント パターン サポート — ルーティング、スーパーバイザー、スーパーバイザー（ツールとしてのエージェント）、ハンドオフ、スキルなど、マルチエージェント パターンをサポートします。ルーティングおよびスーパーバイザ パターンの並列実行サポートが追加されました。
  • フロー エージェント フックのサポート (#3983) — すべてのフロー エージェント (ルーティング、スーパーバイザー、ループ、シーケンシャルなど) は、カスタマイズされたフックをサポートします。
  • 新しいエージェント API (#4031) — 簡素化されたメッセージ ストリーミング用の新しい streamMessages API。追加入力用の新しいオーバーロード invoke および call メソッド。
  • 非同期および並列ツール実行 (#4037) — 並列化および非同期ツール実行でのツール実行をサポートします。
  • ツール returnDirect (#4139) — ツール returnDirect の動作のサポート。
  • ToolContextHelper (#4163) — ツール コンテキストでのメタデータ アクセス用のヘルパー クラス (修正 #3110)。

グラフ

  • 並列条件付きエッジ (#4027) — 条件付きエッジは並列実行をサポートします (修正 #3917)。
  • 並列ブランチの集約戦略 (#4028) — 並列ブランチの新しい集約戦略 (AllOf および AnyOf)。
  • 並列分岐用のバッチ addEdge (#3938) — StateGraph での並列分岐定義のための便利なバッチ addEdge メソッド。
  • interruptAfter フック (#3864) — InterruptableAction は interruptAfter フックをサポートします (#3447、#3904 を修正)。
  • AgentToolNode の非同期ツール実行 (#4037 / #3988) — AgentToolNode の非同期ツール実行のサポート。
  • ストリーミング ノードの完全な出力 (#3941) — ストリーミング ノードは、_FINISHED OutputType を含む完全な出力を出力するようになりました。

サンドボックスとスタジオ

  • SAA サンドボックス (#4069) — 安全かつ分離されたツールの実行を提供する新しい SAA サンドボックス モジュール。
  • 組み込みの RenderTemplate (#3935) — 組み込みのカスタマイズされた RenderTemplate 実装。
  • Studio CORS オプション (#4154) — Studio では CORS 構成がオプションになりました。

修正

DashScopeChatModel

  • ** #3942 (spring-ai-alibaba/spring-ai-extensions#140) で報告された接続リセット** — 接続をより適切に管理するために、DashScopeApi にデフォルトの HTTP client を設定し、モデル サーバーによって接続が閉じられたときの接続リセットの問題を回避します。

グラフ

  • シリアル化 (#3969) — シリアル化における class のバグを修正しました (修正 #3895、#3931)。
  • MergeStrategy (#4129) — Optional の処理を修正し、MergeStrategy での厳密な型チェックを強制しました (修正 #3909)。

エージェント

  • 命令 (#3974) — 命令処理を追加しました。 CI とテストを修正しました。
  • AgentLlmNode モデル オプション (#3986) — AgentLlmNode がデフォルトのモデル オプションをオーバーライドしないようにします。 ChatOptions に internalToolExecution(false) が設定されていることを確認します (修正 #3903)。
  • selectorModel (#4045) — selectorModel のサポートを追加しました (修正 #4026)。
  • systemPrompt (#4067) — システム プロンプトの処理を修正しました。
  • ParallelAgent maxConcurrency (#4053) — ParallelAgent の maxConcurrency 関数が実装されていることを確認しました。
  • jumpTo (#4081) — jumpTo が正しく動作することを確認しました。
  • ModelRequest ビルダー systemMessage (#4138) — ModelRequest ビルダーは systemMessage を失わなくなりました。
  • NacosReactAgentBuilder (#4093) — ローカル ツールを適切にマージするように NacosReactAgentBuilder を修正しました。
  • AgentLlmNode ツールのコールバック (#4112) — AgentLlmNode のツール コールバックのフィルタリング ロジックを修正しました。

管理者と UI

  • 管理パッケージの名前変更 (#3977) — @agentscope-ai/flow の名前を @spark-ai/flow に変更しました (#3949 を修正)。
  • 管理者の起動/コンパイル (#4123) — spring-ai-alibaba-admin の起動およびコンパイルの問題を修正しました。
  • CustomInputsControl (#4106) — CustomInputsControl に variableList プロップを追加しました。

依存関係

  • Spring AI バージョン — Spring Ai から 1.1.2 にアップグレード
  • Spring AI Alibaba Extensions バージョン — Spring Ai Alibaba Extensions が 1.1.2.1 にアップグレードされました

アップグレードに関する注意事項

  • Spring AI: このリリースでは Spring AI 1.1.2 を使用します。それに応じてプロジェクトの Spring AI バージョンを調整します。
  • 管理: 管理フロー UI を使用する場合は、依存関係を @agentscope-ai/flow から @spark-ai/flow に更新します。
