spring-ai-alibaba v1.0.0-M3.3

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#春愛アリババv1.0.0-M3.3

何が変わったのか

  • 機能/autoconfig 2024 (https://github.com/alibaba/spring-ai-alibaba/pull/110 の @disaster1-tesk による)
  • 機能/時間プラグイン 20241119 by @ppbcn (https://github.com/alibaba/spring-ai-alibaba/pull/113)
  • Baidu 検索プラグイン (https://github.com/alibaba/spring-ai-alibaba/pull/112 の @CZJCC による)
  • https://github.com/alibaba/spring-ai-alibaba/pull/118 の @CZJCC による bing プラグイン
  • プラグインの仕様に合わせて bing 検索プラグインを変更します。 @CZJCC 著、https://github.com/alibaba/spring-ai-alibaba/pull/132
  • ding talk プラグインを追加 - カスタム ロボットが https://github.com/alibaba/spring-ai-alibaba/pull/115 の @673575554 によるグループ メッセージを送信
  • https://github.com/alibaba/spring-ai-alibaba/pull/133 の @673575554 による機能/gaodemap
  • 機能: https://github.com/alibaba/spring-ai-alibaba/pull/122 の @PolarishT による統合 LarkSuite PluginTool
  • 機能: https://github.com/alibaba/spring-ai-alibaba/pull/135 の @Yeaury による統合天気 PluginTool
  • https://github.com/alibaba/spring-ai-alibaba/pull/127 の @sincerity-being によるポイ github リーダーの更新
  • 追加: TencentCos リーダー、https://github.com/alibaba/spring-ai-alibaba/pull/140 の @sincerity-being
  • 修正: DashScopeAiUsage#getTotalTokens() が https://github.com/alibaba/spring-ai-alibaba/pull/147 の @ZeroVd によって NPE をスローされていたバグを修正 *修正: https://github.com/alibaba/spring-ai-alibaba/pull/146で@yuluo-yxによってyamlに設定された場合に画像モデルパラメータが空になるバグを修正
  • DashScope ChatModel の監視レジストリを自動構成し、可観測性の例でトレース ID にアクセスできるようにします。 @Cirilla-zmh 著、https://github.com/alibaba/spring-ai-alibaba/pull/155
  • https://github.com/alibaba/spring-ai-alibaba/pull/176 の @wstever によってコード形式と SpringAI バージョンを更新します
  • 功績: @robinyeeh による文分割ツールを https://github.com/alibaba/spring-ai-alibaba/pull/169 に追加
  • https://github.com/alibaba/spring-ai-alibaba/pull/174 の @sincerity-being によるドキュメント リーダー パーサーの更新
  • https://github.com/alibaba/spring-ai-alibaba/pull/149 の @wblu214 によりフェイシュプラグインを SAA に追加
  • 功績: @yuluo-yx による response_format パラメータを https://github.com/alibaba/spring-ai-alibaba/pull/171 に追加
  • 機能: https://github.com/alibaba/spring-ai-alibaba/pull/150 の @673575554 による yuque リーダーの追加
  • @superhandsomeg による SerpApi 検索プラグインを https://github.com/alibaba/spring-ai-alibaba/pull/178 に追加
  • 機能: @Yeaury による翻訳プラグインを https://github.com/alibaba/spring-ai-alibaba/pull/144 に追加
  • 功績: @yuluo-yx による LLM クローラー プラグインを https://github.com/alibaba/spring-ai-alibaba/pull/145 に追加
  • 功績: Regex FC 、JsonProcessor FC と @PolarishT によるコード形式を https://github.com/alibaba/spring-ai-alibaba/pull/187 に追加
  • [reactor]: https://github.com/alibaba/spring-ai-alibaba/pull/212 の @PolarishT によってカタログの名前が変更されました
  • [ホットフィックス]: https://github.com/alibaba/spring-ai-alibaba/pull/217 の @PolarishT によるストリーム関数呼び出し例外を修正
  • https://github.com/alibaba/spring-ai-alibaba/pull/220 の @Cirilla-zmh による関数呼び出しの ID と名前を解析できないことによって引き起こされる IllegalStateException を修正
  • 功績: @Cirilla-zmh による DashScopeEmbeddingModel 可観測性を https://github.com/alibaba/spring-ai-alibaba/pull/222 に追加
  • [機能]: spring ai alibaba yuque impl & リアクター コード & ライセンス ヘッダーの更新 (https://github.com/alibaba/spring-ai-alibaba/pull/294 の @PolarishT による)
  • https://github.com/alibaba/spring-ai-alibaba/pull/307に@xiaohai-78によるニュース機能呼び出しを追加
  • 功績: @Yeaury による github ツールキット プラグインを https://github.com/alibaba/spring-ai-alibaba/pull/308 に追加
  • 功績: https://github.com/alibaba/spring-ai-alibaba/pull/298 の @SCMRCORE による Baidu 翻訳の実装を追加
  • 功績: @CoderSerio による Baidu マップ プラグインを https://github.com/alibaba/spring-ai-alibaba/pull/219 に追加
  • 功績: @fuyou-lxm による OpenSearch ベクトル ストレージの実装クラスと構成クラスを https://github.com/alibaba/spring-ai-alibaba/pull/240 に追加
