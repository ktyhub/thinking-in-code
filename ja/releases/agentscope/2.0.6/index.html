agentscope v2.0.6

パッチ 公開日2026年8月7日 出典agentscope-ai/agentscope 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

エージェントスコープ v2.0.6

ハイライト

  • AgentScope で チャネル (Feishu と Discord) をサポート (#1997)
  • Apple Container をワークスペース バックエンドとしてサポート (#2068)
  • エージェント サービスで MCP およびスキル ハブ/マーケットをサポート (#2197)
  • on_check_permission ミドルウェア フックを追加 (#2001)
  • Web UI チャット ページを shadcn でリファクタリング (#2171)

何が変わったのか

  • 偉業(webui): shadcn を使用してチャット ページをリファクタリングし、https://github.com/agentscope-ai/agentscope/pull/2171 の @DavdGao による npm リリースの準備をします
  • feat(workspace): https://github.com/agentscope-ai/agentscope/pull/2068 の @iluv7 によるワークスペース バックエンドとして Apple コンテナをサポート
  • 修正(モデル): https://github.com/agentscope-ai/agentscope/pull/2063 の @dongfeng3692 による呼び出しごとの新規作成ではなく、呼び出し全体で openai.AsyncClient を再利用
  • 特技(ミドルウェア): @Miracle778 による on_check_permission フックを https://github.com/agentscope-ai/agentscope/pull/2001 に追加
  • perf(model): https://github.com/agentscope-ai/agentscope/pull/2158 の @qbc2016 によるストリーム蓄積内の O(n²) 文字列連結を O(n) フラグメント結合に置き換えます
  • docs(readme): https://github.com/agentscope-ai/agentscope/pull/2182 の @xu20160924 による README_zh.md の更新
  • 修正(エージェント): https://github.com/agentscope-ai/agentscope/pull/2167 の @March-77 による外部ツール開始イベントの重複を回避
  • feat(ハブ): https://github.com/agentscope-ai/agentscope/pull/2197 の @DavdGao による MCP/スキル ハブからの MCP とスキルのインストールのサポート
  • 修正 (ハブ): ClawHub カード ID を所有者ごとにスコープする (https://github.com/agentscope-ai/agentscope/pull/2214 の @DavdGao による)
  • 修正(モデル): https://github.com/agentscope-ai/agentscope/pull/2209 の @logicwu0 による応答中断の理由を保存
  • feat(web_ui): https://github.com/agentscope-ai/agentscope/pull/2234 の @DavdGao によるサイドバー、パネル、フォーム コントロールのスタイルを統合しました。
  • fix(tool): https://github.com/agentscope-ai/agentscope/pull/2178 の @KXHXK によるツール応答でエラー状態を保存
  • 偉業(アプリ): 健全性エンドポイントを追加し、Web UI に入る前にチェックします (https://github.com/agentscope-ai/agentscope/pull/2237 の @DavdGao)
  • feat(サービス): ワークスペース アーティファクト list_dir および read_file エンドポイント (#2039) を追加 (#2039) by @RerankerGuo (https://github.com/agentscope-ai/agentscope/pull/2187)
  • ci(hitl): https://github.com/agentscope-ai/agentscope/pull/2203 の @csurong による混合中断カバレッジを復元します。
  • ci: https://github.com/agentscope-ai/agentscope/pull/2233 の @RerankerGuo によるコミット前の失敗の伝播
  • 偉業(モデル): https://github.com/agentscope-ai/agentscope/pull/2240 の @DavdGao によるすべてのプロバイダーのモデル カードを更新します。
  • feat(channel): https://github.com/agentscope-ai/agentscope/pull/1997 の @qbc2016 によるチャンネルを実装
  • 修正 (エージェント): https://github.com/agentscope-ai/agentscope/pull/2217 の @RICARDO51167 による推論動作ラウンドを 1 回カウントする
  • fix(channel): https://github.com/agentscope-ai/agentscope/pull/2261 の @qbc2016 によるチャネル フォーム フィールドのローカリゼーションを修正
  • feat(web-ui): https://github.com/agentscope-ai/agentscope/pull/2257 の @DavdGao による git ステータスを含むセッション作業ディレクトリ
  • 修正(トレース): https://github.com/agentscope-ai/agentscope/pull/2077 の @alex-mm によるクロスタスク ストリームでの otel コンテキスト デタッチ エラーを回避
  • docs(readme): SDK/サービス機能テーブルを含む README を改訂。 https://github.com/agentscope-ai/agentscope/pull/2262 の @DavdGao により 2.0.6 にバンプします
  • 修正 (webui): https://github.com/agentscope-ai/agentscope/pull/2243 の @qbc2016 による保留中のツール呼び出し間の確認状態のリセット
  • feat(app): https://github.com/agentscope-ai/agentscope/pull/2263 の @DavdGao により、解決されたワークスペースを extra_agent_middlewares に渡します
