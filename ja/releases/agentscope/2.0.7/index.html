agentscope v2.0.7

エージェントスコープ v2.0.7

何が変わったのか

  • 修正(gemini): https://github.com/agentscope-ai/agentscope/pull/2277 の @qbc2016 により、サポートされていない $schema をツール パラメーターから削除しました
  • feat(ワークスペース): https://github.com/agentscope-ai/agentscope/pull/1951 の @iluv7 により、異なるエージェント間でワークスペースを共有します
  • feat(ワークスペース): エージェントごとにスキルを分離し、セッションごとに選択します (https://github.com/agentscope-ai/agentscope/pull/2283 の @DavdGao による)
  • 修正(ハブ): https://github.com/agentscope-ai/agentscope/pull/2230 の @RerankerGuo による GitHub MCP 環境入力を保持
  • 修正 (アプリ): 次のユーザーが https://github.com/agentscope-ai/agentscope/pull/2295 の @DavdGao によってターンするまで、セッションの受信トレイ ペイロードの滞留を停止します。
  • 機能 (コンソール): https://github.com/agentscope-ai/agentscope/pull/2297 の @DavdGao によるエージェントの試行とデバッグ用のターミナル コンソールを追加
  • fix(tool): https://github.com/agentscope-ai/agentscope/pull/2302 の @DavdGao によるメタ ツールを修正
  • 修正(モデル): https://github.com/agentscope-ai/agentscope/pull/2314 の @silicon14 による MoonshotChatModel ストリーミングの使用を修正
  • 修正 (mcp): https://github.com/agentscope-ai/agentscope/pull/2308 の @Solaris-star によるステートフル clients の再接続を許可
  • feat(エージェント): on_reply ミドルウェアが ReplyEndEvent を飲み込んで、https://github.com/agentscope-ai/agentscope/pull/2322 の @DavdGao による応答ループを継続させます。
  • 修正 (フォーマッタ): https://github.com/agentscope-ai/agentscope/pull/2315 の @qbc2016 による DashScope Base64 オーディオのデータ URL を使用
  • 修正(モデル): https://github.com/agentscope-ai/agentscope/pull/2349 の @BlessedWithLuck1105 によって OpenAI 応答ストリームを決定的に閉じる
  • 修正(モデル): https://github.com/agentscope-ai/agentscope/pull/2350 の @BlessedWithLuck1105 によって Anthropic ストリームを決定的に閉じる
  • 修正(フォーマッタ): https://github.com/agentscope-ai/agentscope/pull/2351 の @BlessedWithLuck1105 によるツール呼び出し前に画像を蓄積しておく
  • 修正 (ハブ): https://github.com/agentscope-ai/agentscope/pull/2291 の @csurong による所有者スコープのスキル カード ID を受け入れる
  • feat(rag): https://github.com/agentscope-ai/agentscope/pull/2083 の @qbc2016 によってチャンカー構成を明示的かつスキーマ駆動にする
  • fix(ui): TTS では名前で認証情報を区別し、https://github.com/agentscope-ai/agentscope/pull/2169 では @qbc2016 でフォールバック モデル セレクターを区別します。
  • 修正: 構造化出力呼び出しの思考を無効にし、https://github.com/agentscope-ai/agentscope/pull/2140 の @qbc2016 による圧縮フォールバックを追加
  • 修正(アプリ): https://github.com/agentscope-ai/agentscope/pull/2232 の @qbc2016 によるセッション ロックの下で可変セッション状態をロードする
  • feat(エージェント): https://github.com/agentscope-ai/agentscope/pull/2362 の @DavdGao により、コンテキスト内の画像を制限するために max_image_num を ContextConfig に追加しました
  • 修正(ツール): Bash のホスト OS ではなくバックエンド OS によってシェルを選択 (https://github.com/agentscope-ai/agentscope/pull/2366 の @DavdGao により)
  • docs(tool): https://github.com/agentscope-ai/agentscope/pull/2355 の @hata333 によるツールキット グループ検証コメントのタイプミスを修正
  • feat(ツール): https://github.com/agentscope-ai/agentscope/pull/2114 の @qbc2016 によるバイナリおよび構造化ファイルの読み取りツールでの DataBlock リターンのサポート
  • fix(tool): https://github.com/agentscope-ai/agentscope/pull/2371 の @DavdGao によってツール スキーマを抽出する際の PEP 563 遅延アノテーションを解決
  • 修正(イベント): https://github.com/agentscope-ai/agentscope/pull/2370 の @fancyboi999 によるツール結果データ ソースの検証
  • 修正(mcp): URL パスによって SSE トランスポートを検出し、クエリ文字列が https://github.com/agentscope-ai/agentscope/pull/2311 の @1753936488 によって機能するようにしました。
  • fix(tool): https://github.com/agentscope-ai/agentscope/pull/2316 の @wizardeur による check_tool_available で、非アクティブなツール グループと不足しているツールを区別します。
  • 修正(アプリ): https://github.com/agentscope-ai/agentscope/pull/2220 の @helloJamest によるキャンセル時にインデックス ワーカー タスクをクリーンアップ
  • 修正(utils): https://github.com/agentscope-ai/agentscope/pull/2241 の @jesseedcp による欠落属性セマンティクスを DictMixin が考慮するようにしました。
  • 修正(状態): https://github.com/agentscope-ai/agentscope/pull/1811 の @faisalishfaq2005 によるアクセス時の読み取りファイル キャッシュの最新性を更新
  • fix(memory): https://github.com/agentscope-ai/agentscope/pull/2374 の @ployts による独自の最小限の ReMe 構成
  • feat(tool): FunctionTool でカスタム input_schema をサポート (https://github.com/agentscope-ai/agentscope/pull/2378 の @DavdGao による)
  • feat(ui): https://github.com/agentscope-ai/agentscope/pull/2381 の @DavdGao によるチャット ページに最大反復回数を超えたアラートを表示
  • 機能 (ラグ): チャンクの参照、生のドキュメントのプレビュー、https://github.com/agentscope-ai/agentscope/pull/2372 の @DavdGao による充実したナレッジ ベースのリストを追加
  • feat(agent-team): https://github.com/agentscope-ai/agentscope/pull/2379 の @DavdGao によるチーム内のサブエージェント用のループ ミドルウェアを追加
  • feat(エージェントチーム): メンバーのターンが失敗したときにリーダーに通知 by @DavdGao in https://github.com/agentscope-ai/agentscope/pull/2386
  • 修正(web_ui): ワーカーが https://github.com/agentscope-ai/agentscope/pull/2387 の @DavdGao によってインデックスを作成している間、アップロードされたファイルを表示したままにします
  • fix(rag): Word および PPT Markdown テーブルのセルをエスケープする (https://github.com/agentscope-ai/agentscope/pull/2377 の @kaiwangleo による)
  • 修正 (エージェント): https://github.com/agentscope-ai/agentscope/pull/2318 の @yingz23 によるプロンプト キャッシュ トークンの使用を維持する
  • feat(チャンネル): https://github.com/agentscope-ai/agentscope/pull/2390 の @DavdGao による専用ワーカーで長い接続を保持します
  • 修正(コンテキスト): https://github.com/agentscope-ai/agentscope/pull/2396 で @qbc2016 による 0.9 のトリガー率を許可
  • リファクタリング(チャネル): https://github.com/agentscope-ai/agentscope/pull/2395 の @DavdGao によって生成されたノードからの応答を配信します。
  • feat(チャンネル): @iluv7 による DingTalk チャンネルを https://github.com/agentscope-ai/agentscope/pull/2285 に追加
  • chore(version): https://github.com/agentscope-ai/agentscope/pull/2407 の @DavdGao によるリリース用にバージョンを 2.0.7 にバンプします
  • feat(workspace): https://github.com/agentscope-ai/agentscope/pull/1755 の @cuiyuebing によるプーリング用のワークスペース プールを追加
  • 修正(トレース): https://github.com/agentscope-ai/agentscope/pull/2391 の @qbc2016 によるチャット スパンに入力メッセージを含める
  • 修正(スケジューラー): https://github.com/agentscope-ai/agentscope/pull/2410 の @DavdGao により、実際のワークスペースをスケジュールされたセッションにバインドします
  • 修正(チャネル): https://github.com/agentscope-ai/agentscope/pull/2409 の @DavdGao により、DingTalk が受信接続なしで送信できるようにします
  • 機能 (ストレージ): SQL ストレージ上のチャネル レコードをサポート (https://github.com/agentscope-ai/agentscope/pull/2388 の @DavdGao による)
