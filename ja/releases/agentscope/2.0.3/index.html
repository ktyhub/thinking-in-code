agentscope v2.0.3

パッチ 公開日2026年6月29日 出典agentscope-ai/agentscope 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

エージェントスコープ v2.0.3

主な新機能

RAG モジュール

  • 分散型、マルチテナント、およびマルチセッションの RAG サービスを完全にサポートするネイティブ RAG (Retrieval-Augmented Generation) モジュールを導入し、ナレッジ検索機能を大幅に強化しました。 長期記憶ミドルウェア
  • mem0 を利用した長期記憶ミドルウェアを追加し、エージェントがセッション間で永続メモリを保持できるようにしました。 予算管理ミドルウェア
  • トークンの予算制限を強制するための BudgetControlMiddleware を導入し、チームが API コストを効果的に管理および制御できるようにしました。 ツールレベルの Onion ミドルウェア
  • ToolBase は、ツール レベルでオニオン スタイルのミドルウェアをサポートするようになり、ツールの実行に柔軟な前処理/後処理ロジックを挿入できるようになりました。

何が変わったのか

  • 修正 (ダッシュスコープ): https://github.com/agentscope-ai/agentscope/pull/1876 の @Rise1024 による qwen max 3.7 モデル ID を修正
  • feat(ミドルウェア): https://github.com/agentscope-ai/agentscope/pull/1775 の @Osier-Yi による mem0 支援の長期記憶ミドルウェアを追加
  • 修正(モデル): ID なしで Gemini 関数呼び出しを処理 (https://github.com/agentscope-ai/agentscope/pull/1883 の @he-yufeng による)
  • 特技(ミドルウェア): https://github.com/agentscope-ai/agentscope/pull/1738 の @MannXo によるトークン予算執行のための BudgetControlMiddleware を追加
  • feat(tts): @qbc2016 による cosyvoice リアルタイム tts モデルを https://github.com/agentscope-ai/agentscope/pull/1855 に追加
  • feat(モデル): https://github.com/agentscope-ai/agentscope/pull/1750 の @nuthalapativarun による openai-response 用に gpt-4o、gpt-4o-mini、および gpt-4.1-nano カードを追加
  • fix(schema): SummarySchema フィールドから max_length 制約を削除し、https://github.com/agentscope-ai/agentscope/pull/1891 の @qbc2016 によってツール結果の制限を増加
  • fix(gemini): _sanitize_schema_for_gemini を追加して、https://github.com/agentscope-ai/agentscope/pull/1886 の @qbc2016 によって Gemini と互換性のない JSON スキーマ構造を削除します
  • feat(tool): https://github.com/agentscope-ai/agentscope/pull/1754 の @nuthalapativarun による ToolBase でのツールレベルのオニオン ミドルウェアのサポート
  • 偉業(utils): https://github.com/agentscope-ai/agentscope/pull/1839 の @lajxw による set_id_factory() 経由で構成可能な ID ファクトリを追加
  • feat(embedding): https://github.com/agentscope-ai/agentscope/pull/1897 の @jinliyl による OpenAI 埋め込みモデルの pass_dimensions オプションを追加
  • chore(version): https://github.com/agentscope-ai/agentscope/pull/1898 の @Copilot を使用した @DavdGao による 2.0.2 から 2.0.3 へのバージョンのバンプ
  • chore(ワークフロー): https://github.com/agentscope-ai/agentscope/pull/1912 の @DavdGao による監視用に github ワークフローを追加
  • 修正 (フォーマッタ): https://github.com/agentscope-ai/agentscope/pull/1894 の @qbc2016 により、AnthropicChatFormatter の並列ツール結果を 1 つのユーザー メッセージにマージします
  • feat(workspace): https://github.com/agentscope-ai/agentscope/pull/1903 の @DavdGao による e2b および docker ワークスペースの組み込みツールをサポート
  • fix(tool): https://github.com/agentscope-ai/agentscope/pull/1901 の @wang-zhengxin により、base64 ツール応答チャンクをバイト単位でマージします
  • 修正 (エージェント): https://github.com/agentscope-ai/agentscope/pull/1906 で @Premsenareddy による共有デフォルト設定を回避
  • feat(agent-team): https://github.com/agentscope-ai/agentscope/pull/1918 の @DavdGao によるチーム リーダーのセッションでの hitl イベントの公開のサポート
  • 修正(アプリ): https://github.com/agentscope-ai/agentscope/pull/1917 の @YingchaoX による AG-UI SSE ストリーム イベントを変換する
  • refactor(message_bus): https://github.com/agentscope-ai/agentscope/pull/1923 の @DavdGao によるメッセージ バスのリファクタリングとサービス ロジックからの切り離し
  • feat(message_bus): https://github.com/agentscope-ai/agentscope/pull/1925 の @DavdGao による単一ノード デプロイメント用のインメモリ メッセージ バスを追加
  • feat(webui): https://github.com/agentscope-ai/agentscope/pull/1856 で @Premsenareddy による書き込みおよび編集ツールの差分をレンダリングします。
  • リファクタリング(webui): 冗長なタスクと権限コンテキスト、装備された MCP とスキル (https://github.com/agentscope-ai/agentscope/pull/1945 の @DavdGao による) をサポートするために WebUI に右側のパネルを追加します。
  • ドキュメント: https://github.com/agentscope-ai/agentscope/pull/1946 の @qbc2016 によるドキュメント内のハイパーリンクを修正
  • 修正（ミドルウェア）: https://github.com/agentscope-ai/agentscope/pull/1930 の @YingchaoX によって TTS オーディオ ブロックに設定された ID ファクトリを使用する
  • feat(rag): Agentscope に RAG モジュールを追加し、https://github.com/agentscope-ai/agentscope/pull/1926 の @DavdGao による分散&マルチテナント&マルチセッション RAG サービスをサポート
  • feat(agent): https://github.com/agentscope-ai/agentscope/pull/1942 の @h2h2h によるメモリ圧縮時のユーザー定義のヒント/命令をサポート
  • リファクタリング: _ flatten_json_schema を共有ユーティリティにリフトし、https://github.com/agentscope-ai/agentscope/pull/1940 の @qbc2016 によって OpenAI チャット モデルに適用
