agentscope v2.0.8

パッチ 公開日2026年9月8日 出典agentscope-ai/agentscope 英語原文

エージェントスコープ v2.0.8

ハイライト

  • リアルタイム音声エージェント: DashScope バックエンドとローカル トランスポート サポートを備えたリアルタイム音声エージェントが導入されました。
  • A2A プロトコルのサポート: エージェント モジュールに A2AAgent クラスが追加され、エージェント間の通信が可能になりました。
  • 新しいパイプライン モジュール: 目標主導型エージェント ワークフロー用の GoalPipeline クラスを含む新しいパイプライン モジュールを追加しました。
  • エージェント主導のコンテキスト圧縮: エージェントが独自のコンテキスト ウィンドウを管理できるようにするコンテキスト圧縮ツールが導入されました。
  • RAG の LLM 再ランク: RAG の取得品質を向上させるために、LLM ベースの再ランク付けサポートを追加しました。
  • Volcengine Ark モデル: Volcengine Ark チャット モデルのサポートを追加しました。
  • MCP の機能強化: Docker ワークスペースでのランタイム MCP ヘッダーのサポートと、MCP 接続のクリーンアップの改善。
  • Web UI の改良: セッションの自動命名、クエリ キャッシュ、ダーク モードのサポートの改善など、チャット エクスペリエンスが向上しました。
