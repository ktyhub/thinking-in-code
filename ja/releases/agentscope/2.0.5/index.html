agentscope v2.0.5

パッチ 公開日2026年7月23日 出典agentscope-ai/agentscope 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

エージェントスコープ v2.0.5

ハイライト

エージェント

  • 構造化出力のサポート (#2150)
  • 環境情報の挿入をサポート (#2134)

ワークスペース

  • OpenSandbox (#1953)、Daytona (#1943)、K8s (#1933)、Bubblewrap (#2051) をサポート

ツール

  • Windows 向け PowerShell のサポート (#2132)

ラグ

  • MongoDB (#2008)、Elasticsearch (#2129) をサポート
  • Excel (#2026) および Word (#2025) パーサーをサポート

サービスとしてのエージェント

  • SQLAlchemy ベースのストレージをサポート (#2029)

  • グループまたは組織としてユーザー間のリソース共有をサポート (#1998)

モデル

  • 新しいダッシュスコープ モデル (#2073)、キミ K3 (#2141) を追加
  • Gemini TTS API の実装 (#1879)

何が変わったのか

  • fix(gemini): https://github.com/agentscope-ai/agentscope/pull/2020 の @qbc2016 によって null を含む gemini スキーマを修正
  • feat(workspace): https://github.com/agentscope-ai/agentscope/pull/1933 の @XiuShenAl による Pod/PVC ライフサイクル、tar ストリーム バックエンド、MCP ゲートウェイのサポートを備えた K8sWorkspace を追加
  • feat(rag): MongoDB ベクター ストア バックエンドを追加 https://github.com/agentscope-ai/agentscope/pull/2008 の @xu-suping によって閉じられます
  • 修正 (フォーマッタ): https://github.com/agentscope-ai/agentscope/pull/2006 の @nolanchic による ollam ツールの結果メッセージに tool_name を含めます
  • 偉業(ワークスペース): @lumman0 による OpenSandbox バックエンドを https://github.com/agentscope-ai/agentscope/pull/1953 に追加
  • 修正 (フォーマッタ): https://github.com/agentscope-ai/agentscope/pull/2007 の @nolanchic による人文学の空のテキスト ブロックをドロップ
  • feat(rag): @qbc2016 による Excel パーサーを https://github.com/agentscope-ai/agentscope/pull/2026 に追加
  • feat(rag): @qbc2016 による単語パーサーを https://github.com/agentscope-ai/agentscope/pull/2025 に追加
  • 機能 (サービス): https://github.com/agentscope-ai/agentscope/pull/1998 の @DavdGao により、グループまたは組織としてさまざまなユーザー間でリソース (資格情報、エージェント、知識ベース) を共有するためのサポート
  • feat(workspace): https://github.com/agentscope-ai/agentscope/pull/1943 の @BreezyB1n による daytona ワークスペース バックエンドを追加
  • 修正(ワークスペース): https://github.com/agentscope-ai/agentscope/pull/2056 の @dailingtao によるデフォルトの glob ヘルパー パスを復元
  • 修正: https://github.com/agentscope-ai/agentscope/pull/2065 の @qbc2016 による openai チャット モデルの max_tokens を max_completion_tokens に変更
  • fix(workspace): https://github.com/agentscope-ai/agentscope/pull/2046 の @jwx0925 による OpenSandbox ブートストラップと状態フィルタリングを修正
  • リファクタリング (webui): Web UI でレンダリングするツールを更新 (https://github.com/agentscope-ai/agentscope/pull/2072 の @DavdGao による)
  • feat(dashscope): https://github.com/agentscope-ai/agentscope/pull/2073 の @qbc2016 によるダッシュスコープの新しいモデルを追加
  • 修正 (webui): ツール呼び出しストリーミング中の不完全な JSON または https://github.com/agentscope-ai/agentscope/pull/2075 での @DavdGao による中断によって引き起こされる読み取り/書き込み/編集ツールのレンダリング エラーを修正
  • 修正(ラグ): https://github.com/agentscope-ai/agentscope/pull/2089 の @qbc2016 による MilvusLiteStore を milvus-lite 3.1.0 COSINE 距離セマンティクスに適応させます
  • chore(deps): https://github.com/agentscope-ai/agentscope/pull/2091 の @qbc2016 により、MCP 依存関係のバージョンを 2.0.0 未満に制限
  • 修正(モデル): https://github.com/agentscope-ai/agentscope/pull/2071 で @qbc2016 による OpenAI 応答推論履歴の再生を保存
  • 修正(アプリ): https://github.com/agentscope-ai/agentscope/pull/2081 の @DavdGao による list_messages にカーソルベースのページネーションを使用する
  • 修正 (webui): https://github.com/agentscope-ai/agentscope/pull/2100 の @JanCong により、新しくロードされたセッションを一番下までスクロールします
  • fix(mem0): OSS で個別の LLM インスタンスを使用する例 (https://github.com/agentscope-ai/agentscope/pull/2078 の @Osier-Yi による)

  • 修正(エージェント): https://github.com/agentscope-ai/agentscope/pull/2093 の @qiuC123 によるコンテキスト圧縮中にマルチツールのペアを保持
  • 修正(ツール): https://github.com/agentscope-ai/agentscope/pull/2004 の @VectorPeak により、変更する検索コマンドを読み取り専用として拒否する
  • perf(prompt): ワークスペース、コンテキスト圧縮、CreateTask ツールの命令を https://github.com/agentscope-ai/agentscope/pull/2111 の @DavdGao により改善
