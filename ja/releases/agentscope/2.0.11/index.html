  • 偉業(asr): https://github.com/agentscope-ai/agentscope/pull/2667 の @wangtaotaotao95 によるバッチ転写抽象化と OpenAI モデルを追加

  • 修正 (フォーマッタ): https://github.com/agentscope-ai/agentscope/pull/3250 の @kabishou11 によって開く前に、パーセントでエンコードされたローカル ファイル URL をデコードします
  • 修正(フォーマッタ): https://github.com/agentscope-ai/agentscope/pull/3141 の @qingshungLI によって ollam ファイル URL をデコードする
  • 修正 (コンソール): https://github.com/agentscope-ai/agentscope/pull/3317 の @FengZhiheng666 によるエージェントの切り替え間で保留中の応答を保持する

  • 修正(asr): https://github.com/agentscope-ai/agentscope/pull/3333 の @lihongyuan99 による文字起こしのデフォルトを呼び出しごとのオプションでオーバーライドできるようにする
  • fix(rag): https://github.com/agentscope-ai/agentscope/pull/3363 の @kaijin-code によってストリームが閉じるときに静的ヒントをクリーンアップ

  • 修正（埋め込み）: https://github.com/agentscope-ai/agentscope/pull/3350 の @HootRock によって設定されたダッシュスコープのマルチモーダル ディメンションを保持する
  • fix(workspace): https://github.com/agentscope-ai/agentscope/pull/3338 の @Tong-bit-art により、永続化された .mcp ファイルを utf-8-sig として読み取ります
  • 修正 (埋め込み): https://github.com/agentscope-ai/agentscope/pull/2690 の @ZxlDragonDoctor による完全にキャッシュされたマルチバッチ マージのレポート キャッシュ ソース
  • 修正(埋め込み): https://github.com/agentscope-ai/agentscope/pull/2967 の @aniruddhaadak80 による合計ではなく最大バッチ時間を報告します
  • 修正 (メッセージ バス): https://github.com/agentscope-ai/agentscope/pull/3376 の @wuwenbo0626 によるメモリ内のゼロ キュー TTL を優先します
  • 修正(ツール): https://github.com/agentscope-ai/agentscope/pull/3378 の @lihongyuan99 による書き込み/編集権限の提案でグロブ メタキャラクターをエスケープする
  • テスト (フォーマッタ): https://github.com/agentscope-ai/agentscope/pull/3107 の @GoldArowana による Ollama ファイル URI デコードのエッジ ケースをカバーします
