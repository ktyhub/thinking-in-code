skywalking v10.2.0

マイナー 公開日2025年3月24日 出典apache/skywalking 英語原文

#スカイウォーキングv10.2.0

ダウンロード

https://skywalking.apache.org/downloads/

お知らせ

このページからソース コードをダウンロードしないでください。 自分でソース コードをビルドしたい場合は、ビルド ドキュメント に従ってください。

H2 なし、BanyanDB を追加

  • BanyanDB 0.8.0 サポートを追加します。
  • H2 ストレージ オプションは完全に削除されました。

プロジェクト

  • Elasticsearch で並べ替えまたは集計する必要があるフィールドには doc_values を追加し、その他はすべて無効にします。
    • この変更は、正式リリース ユーザーの既存の展開とその機能には影響しません。
    • 警告 Elasticsearch インデックスにカスタム クエリ プラグインがある場合、予期しないフィールドを使用した並べ替えクエリや集計クエリがブロックされるため、この変更によりプラグインが壊れる可能性があります。
  • [重大な変更] debugging-query モジュールの名前を status-query モジュールに変更します。相対的に露出された API は 未変更です。
  • [重大な変更] skywalking-oap-server のすべての jar は、Maven Central を通じて公開されなくなりました。ソース tar とバイナリ tar は Web サイトのダウンロード ページに、docker イメージは docker ハブにのみ公開されます。
    • 警告 プロジェクトで skywalking-oap-server を依存関係として使用している場合は、Web サイトからソース tar をダウンロードし、プライベート Maven リポジトリに公開する必要があります。
  • [重大な変更] H2 をストレージ オプションとして永久に削除します。 BanyanDB 0.8 (OAP 10.2 が必要) は簡単で安定しており、すぐに実稼働可能です。デフォルトのストレージとして H2 を使用する必要はなくなりました。
  • [重大な変更] BanyanDB サーバーのバージョンを 0.8.0 に上げます。このバージョンは以前のバージョンと互換性がありません。 OAP を 10.2.0 にアップグレードする前に、BanyanDB サーバーを 0.8.0 にアップグレードしてください。
  • 最新の UI(booster-ui) コンパイルのために、nodejs を v22.14.0 にバンプアップします。
  • tj-actions/changed-files を Dorny/paths-filter に移行します。

OAP サーバー

  • フラグ FLAG_NO_RECORDED_VALUE を持つ OTLP メトリクス データ ポイントの処理をスキップすると、例外的な結果が発生します。
  • GraphQL クエリ graphql_query_latency の自己可観測性メトリクスを追加します。
  • プロセスインデックスの数を減らし、プロセスインデックスをクエリする際の時間範囲を追加します。
  • Apache commons-io を 2.17.0 に強化します。
  • eBPF so11y メトリクスを磨き、クエリ メトリクスのエラー数を追加します。
  • 期間パラメーター (オプション) を使用したクエリ エンドポイント リストをサポートします。
  • 追加の列 last_ping の endpoint_traffic を更新可能に変更します。
  • GoZero フレームワークのコンポーネント ID(5023) を追加します。
  • Kong モニタリングをサポートします。
  • サービス/エンドポイント レベルのメトリックに対する追加の attr[0-5] の追加をサポートします。
  • パフォーマンス分析のための非同期プロファイラー機能をサポートします。
  • メトリクス topN クエリ結果のメトリクス値の所有者を追加します。
  • EndpointDependencyBuilder の命名制御を追加します。 ※インデックスタイプBanyanDB.IndexRule.IndexType#TREEは削除されます。現在、すべてのインデックスで IndexType#INVERTED が使用されています。
  • BanyanDB に最大クエリ サイズ設定を追加します。
  • 「BanyanDBTraceQueryDAO.queryBasicTraces」が「trace_id」によるクエリをサポートしていない問題を修正しました。
  • ポリッシュ メッシュ データ ディスパッチャ: 空の場合、インスタンス/エンドポイント メトリクスを生成しません。
  • Istio 1.24 で新しいメタデータ標準化を適応させます。
  • netty を 4.1.115 に、grpc を 1.68.1 に、ボーリングSSLを 2.0.69 にバンプアップします。
  • BanyanDB: OAP 起動時のグループ設定の更新をサポートします。
  • BanyanDB: インデックス モードを導入し、banyandb グループ設定をリファクタリングします。
  • BanyanDB: 新しいプログレッシブ TTL 機能を導入します。
  • BanyanDB: OAP 起動時のスキーマの更新をサポート。
  • BanyanDB: BanyanDB の初期化中の OAP 起動を高速化します。
  • BanyanDB: 列で @EnableSort をサポートし、IndexRule の並べ替えを有効にし、デフォルトを false に設定します。
  • Get Effective TTL Configurations API をサポートします。
  • ServerStatusService.statusWatchersの同時修正を修正。
  • 動的な構成変更の伝播チェーンに対する保護を追加します。
  • Ruby コンポーネント ID (HttpClient=2、Redis=7、Memcached=20、Elasticsearch=47、Ruby=12000、Sinatra=12001) を追加します。
  • カフェインのコンポーネント ID(160) を追加します。
  • アラーム: アラームがトリガーされたときのメトリクス スナップショットの保存とクエリをサポートします。
  • 警告: 未使用の Alarm Trend クエリを削除します。
  • zipkin クエリ モジュールのスパン クエリで欠落しているリモート エンドポイント IP アドレスを修正。
  • start.jar に誤ってパッケージ化されていた hierarchy-definition.yml 設定ファイルを修正。
  • bydb.dependencies.properties 構成ファイルを追加して、サーバーの依存関係のバージョンを定義します。
  • AvgHistogramPercentileFunction に ranks の適切なフィールド定義がない問題を修正。
  • BanyanDB: 新しいプロパティ データ モジュールをサポートします。
  • MQE: 複数のメトリックのトップクエリをマージするための top_n_of 関数をサポートします。
  • OAL エンジンで labelAvg 機能をサポートします。
  • カウントできるラベルの数を制限するために、OAL の labelCount 関数に maxLabelCount パラメーターを追加しました。
  • 新しいブラウザ API(/browser/perfData/webVitals、/browser/perfData/webInteractions、/browser/perfData/resources) プロトコルを適応させます。
  • サーキットブレーカー機構を追加します。
  • BanyanDB: BanyanDB サーバーの API バージョンに基づく互換性チェックのサポートを追加します。
  • MQE: &&(and)、||(or) ブール演算子をサポートします。
  • OAP の自己観測性: JVM ヒープとダイレクト メモリの使用メトリクスを追加します。
  • OAP 自己観測性: ウォーターマーク サーキット ブレーク/リカバリ メトリックを追加します。
  • AI パイプライン: ベースライン メトリクス名のクエリとメトリクス値の予測をサポートします。 ※Get Node List in the Cluster APIを追加します。
  • Envoy ログを永続化のために JSON に変換するときに、変換エラーを避けるためにタイプ記述子を追加します。
  • Bseline: MQE によるクエリ ベースラインをサポートし、アラーム ルールで使用します。
  • CVE-2025-24970 を修正するには、netty を 4.11.118 に引き上げます。 ※Get Alarm Runtime Status APIを追加します。
  • アラーム メトリック ウィンドウの値をクエリする場合は、lock を追加します。
  • メモリ内とデータベース サーバー間でトラフィック メトリクスの不一致を防ぐためのフェールセーフ メカニズムを追加します。
  • oap-cluster-internal データ (メトリクス/トラフィック) 形式が一貫していない場合は、クリア ログを追加します。
  • トレース遅延がキャッシュ タイムアウトを超える場合、メトリクス キャッシュの読み込みを最適化します。
  • DSL での lang.groovy.GString の呼び出しを許可します。
  • BanyanDB: ソートなしのアラーム クエリ結果を修正。
  • 仮想スレッドエグゼキュータのコンポーネント ID を追加します。
  • OAP ストレージ初期化のためのモデル インストール ログ情報を追加します。
  • BanyanDB: ストレージ構成を独立したファイル bydb.yaml に分離します。
  • Armeria を 1.32.0 といくつかの推移的な依存関係にバンプします。
  • 有効期限が切れた永続的なメトリクス/レコード データをスキップします。
  • Last Ping データが欠落している問題を修正しました。
  • アラーム Webhook の HTTP ヘッダー設定を追加します。
  • BanyanDB java client を 0.8.0 に強化します。

UI

  • ダッシュボード リストで大文字と小文字を区別しない検索のサポートを追加します。
  • テーブルとカードのウィジェットにコンテンツの装飾を追加します。
  • 期間パラメータを使用したエンドポイント リスト ウィジェット クエリをサポートします。
  • 値マッピングのサポート範囲。
  • General-Root、Mesh-Root、K8S-Root ダッシュボードにサービス グローバル TopN ウィジェットを追加します。
  • 初期化ダッシュボードを修正しました。
  • MQE で計算される複数のメトリックを減らすために、Kubernetes メトリックを更新します。
  • TopList ウィジェットでのデータ値関連のダッシュボードの表示をサポートします。
  • General-Root、Mesh-Root にエンドポイント グローバル TopN ウィジェットを追加します。
  • 関連するトレース オプションで TopList ウィジェットの所有者オプションを実装します。
  • topn リスト内の無関係なダッシュボードへの入り口を非表示にします。
  • 最大クエリの複雑さを超えないように、トポロジ メトリック クエリを分割します。
  • ビュー メトリック関連のトレースとメトリック クエリを修正しました。
  • サポート崩壊スパンを追加します。
  • Web ZZPH100​​ZZ を使用したコピー ユーティリティをリファクタリングします。
  • 既存のオブジェクト URL を解放します。
  • トレースプロファイリングウィジェットを最適化します。
  • 非同期プロファイリング ウィジェットを実装します。
  • エンドポイント トポロジ ページの不正確なデータ クエリの問題を修正。
  • 新しい指標に合わせてブラウザーのダッシュボードを更新します。
  • Alerting ページの Snapshot を視覚化します。
  • OAP 自己観測性ダッシュボード: JVM ヒープとダイレクト メモリの使用メトリクスを追加。
  • OAP 自己観測性ダッシュボード: ウォーターマーク サーキット ブレーク/リカバリ メトリックを追加します。
  • メトリクス チャートに凡例セレクターを実装します。 *ルーターで重複する名前を修正しました。
  • 依存関係を強化します。
  • ツールチップにメトリクス情報が完全に表示されない問題を修正しました。
  • リンク生成時の時間範囲を修正しました。
  • Sk​​ywalking Go Agent の自己観測性メニューを追加。
  • エンドポイントリストのtopNセレクターを追加します。

ドキュメント

  • 新しく追加されたリビジョンベースのプロセスを採用するためにリリース ドキュメントを更新します。
  • BanyanDB ドキュメントを改善しました。
  • コンポーネント ライブラリのドキュメントを改善します。
  • 設定に関する語彙のドキュメントを改善します。
  • Get Effective TTL Configurations API のドキュメントを追加。
  • ステータス API のドキュメントを追加。
  • Maven 中央のパブリッシュ関連プロセスを削除して、リリース プロセスを簡素化しました。
  • サーキットブレーカーメカニズムのドキュメントを追加。
  • Get Node List in the Cluster API ドキュメントを追加。
  • mal.md がすべての内容をカバーしているため、meter.md ドキュメントを削除します。
  • browser-http-api-protocol.md ドキュメントを browser-protocol.md にマージします。
