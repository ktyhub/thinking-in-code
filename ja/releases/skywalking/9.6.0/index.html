skywalking v9.6.0

マイナー 公開日2023年9月3日 出典apache/skywalking 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#スカイウォーキングv9.6.0

ダウンロード

https://skywalking.apache.org/downloads/

お知らせ

このページからソース コードをダウンロードしないでください。 自分でソース コードをビルドしたい場合は、ビルド ドキュメント に従ってください。

新しいアラート カーネル

  • MQE (Metrics Query Expression) と新しい通知メカニズムがサポートされています。

Loki LogQL をサポート

  • SkyWalking で収集されたログ用の Loki LogQL および Grafana Loki ダッシュボードのサポートが新たに追加されました

警告

  • ElasticSearch 6 ストレージ関連テストは削除されました。それは機能しましたが、正式にサポートが終了したため保証されていません。

プロジェクト

  • CVE-2020-8908 により脆弱としてリストされたライブラリを回避するために、Guava を 32.0.1 にバンプアップします。このAPIは未使用です。
  • Maven アーティファクト skywalking-log-recevier-plugin は skywalking-log-receiver-plugin に名前変更されました。
  • cli バージョン 0.11 を 0.12 に強化します。
  • ASF 親 pom のバージョンを v30 に上げます。
  • 自動リリース CI でビルドを再現可能にします。

OAP サーバー

  • Neo4j コンポーネント ID(112) 言語: Python を追加します。
  • ALS で不明な IP を解決するために Istio ServiceEntry レジストリを追加します。
  • deleteProperty API を BanyanDBStorageClient にラップします。
  • [重大な変更] matchedCounter を HttpUriRecognitionService#feedRawData から削除します。
  • HttpUriRecognitionService#feedRawData からパターンを削除し、パターンごとに生の URI の候補を最大 10 個追加します。
  • WebSphere のコンポーネント ID を追加します。
  • AI パイプライン URI キャッシュの NullPointer および IllegalArgument 例外を修正しました。
  • メトリクスが存在しない場合のメトリクス クエリの NPE を修正しました。
  • Istio < 1.15、ElasticSearch < 7.16.3 の E2E テストを削除します。これらは引き続き機能する可能性がありますが、計画どおりにはサポートされません。
  • ElasticSearch ストレージ内のすべての結果をスクロールし、サービス、インスタンス、エンドポイント、 プロセスなど
  • クラスター内の Terminating OAP ポッドを削除するように Kubernetes コーディネーターを改善しました。
  • SW_CORE_SYNC_PERIOD_HTTP_URI_RECOGNITION_PATTERN および SW_CORE_TRAINING_PERIOD_HTTP_URI_RECOGNITION_PATTERN をサポート トレーニングの期間を制御し、HTTP URI 認識パターンを同期します。デフォルトの期間を 10 秒に短縮します。 トレーニング用の同期と60秒。
  • ElasticSearch スクローラーのバグを修正。 ※Aerospike(ID=149)のコンポーネントIDを追加します。
  • recevier という名前のパッケージは、receiver に名前が変更されます。 ※BanyanDBModelExtensionはmultiGet、BanyanDBMetricsDAOはstoreIDTagを扱います。
  • エンドポイントのグループ化関連のロジックを修正し、PatternTree 取得のパフォーマンスを向上させます。
  • mysql-connector-java 使用時のバッチ挿入後のメトリック セッション キャッシュ保存を修正。
  • 動的 UI メニュー クエリをサポートします。
  • docker/.env の使用方法を説明するコメントを追加しました。
  • 間違った環境変数名 SW_OTEL_RECEIVER_ENABLED_OTEL_RULES を正しい SW_OTEL_RECEIVER_ENABLED_OTEL_METRICS_RULES に修正します。
  • JDBC実装におけるインスタンスクエリを修正。
  • SW_QUERY_MAX_QUERY_COMPLEXITY のデフォルト値を 3000 (以前は 1000) に設定します。
  • イベントの length=4000 パラメータ値を受け入れます。 2000年のことでした。
  • 不正な JSON 形式のパラメータ値を許容します。
  • BanyanDB Java Client を 0.4.0 に更新
  • MQE での集約 Labeled Value Metrics をサポートします。
  • [重大な変更] MQE のデフォルトのラベル名を label から _ に変更します。
  • grpc バージョンを 1.53.0 に強化します。
  • [重大な変更] OAP サーバー プロセスがバックグラウンド プロセスとして実行されるのを避けるために、シェル スクリプトから「&」記号を削除しました。
  • 予期せぬ変更を修正するために #10616 の一部を元に戻します。データがない場合は、0 を含む配列を返す必要があります。 しかし、#10616 では空の配列が返されます。
  • クエリのためにすべてのサービス エンティティをメモリにキャッシュします。
  • ジャクソンバージョンを2.15.2にバンプアップ。
  • OOM を回避するには、デフォルトのメモリ サイズを増やします。 *graphql-java を 21.0 に強化します。
  • Echo コンポーネント ID(5015) 言語: Golang を追加。
  • aggregate_labels MQE 関数の index out of bounds exception を修正しました。
  • OTEL による MongoDB サーバー/クラスター監視をサポートします。
  • 機密情報の漏洩を避けるために、ログに構成値を出力しないでください。
  • Move は、404 例外を回避するために、エイリアスによるインデックスの取得前に最新のインデックスを作成します。これは、手動操作による干渉を防ぐだけです。
  • 0.2 リリース以降に提供される新しい Skywalking-go エージェントとして、Go VM メトリクスをさらに追加します。
  • ロック用のコンポーネント ID (ID=5016) を追加します。 ※【ブレーキ変更】alarm-settings.ymlのフック構造を調整。フック タイプごとに複数の設定をサポートし、アラーム ルールでフックを指定します。
  • Armeria を 1.24.3 にバンプアップします。
  • ブール比較を行う BooleanMatch と BooleanNotEqualMatch を修正しました。
  • LogQL HTTP クエリ API をサポートします。
  • Mux Server コンポーネント ID(5017) 言語: Golang を追加します。
  • client lib テストから ElasticSearch 6.3.2 を削除します。
  • 最新の e2e テスト用に、ElasticSearch サーバー 8.8.1 を 8.9.0 に強化します。 8.1.0、7.16.3、7.17.10 はまだテストされています。
  • OpenSearch 2.8.0 を client ライブラリ テストに追加します。
  • 動的構成の apollo 実装にはリスニング モードを使用します。
  • 指定された優先順位の順序でメトリクスをリストするための view_as_seq 関数を MQE に追加。
  • 明示的に設定されていない場合、k8sServiceNameRule の誤ったデフォルト値を修正します。
  • PromQL を改善して、単一のクエリ内で複数のメトリック操作を可能にします。
  • ラベル付きメトリックと他のタイプの値結果の間の MQE バイナリ演算を修正しました。
  • Nacos のコンポーネント ID (ID=150) を追加します。
  • MQE で Compare Operation をサポートします。
  • Kubernetes リソース キャッシュが更新されない問題を修正しました。
  • 起動時に OOM を引き起こす可能性がある間違ったクラスパスを修正。
  • delimiter および component フィールドの設定を追加して、MAL の serviceRelation を拡張します。
  • [重大な変更] アラートで MQE をサポートします。アラーム ルール設定 (alarm-settings.yml)、 expression フィールドを追加し、metrics-name/count/threshold/op/only-as-condition フィールドを削除し、composite-rules 構成を削除します。
  • ログごとではなく、ダウンストリーム/アップストリームごとに ALS で結果を確認します。
  • endTime クエリを使用しない GraphQL クエリ listInstances を修正
  • サーバーと Kafka コンシューマーを init モードで起動しないでください。 ※IrisコンポーネントID(5018)を追加します。
  • OTLP トレースのサポートを Zipkin トレース入力として追加します。

UI

  • Browser-Root ダッシュボードのメトリクス名 browser_app_error_rate を修正。
  • General-Service ダッシュボードのエンドポイント リストの endpoint_cpm の表示名を修正しました。
  • カスタマイズメニューとマーケットプレイスページを実装します。
  • minTraceDuration および maxTraceDuration タイプを修正しました。
  • init minTime を無限大に修正します。
  • 依存関係をバンプして脆弱性を修正します。
  • scss変数を追加します。
  • インスタンス リストのタイトルとプロファイリングを継続する際の注意事項を修正しました。
  • 式メトリックを説明するリンクを追加し、プロファイリングを継続するウィジェットに単位を追加します。
  • 文字列の幅を計算してタブ名の幅を設定します。
  • [重大な変更] Web アプリケーション サーバー プロセスがバックグラウンド プロセスとして実行されるのを避けるために、シェル スクリプトから「&」記号を削除しました。
  • チャートのラベルをリセットします。
  • サービス アソシエイト インスタンスを修正します。
  • ノードサスを削除します。
  • Windows でのコミット エラーを修正しました。
  • MYSQL、POSTGRESQL、REDIS、ELASTICSEARCH、DYNAMODB レイヤー UI テンプレートに MQE を適用します。
  • 仮想キャッシュ層の UI テンプレートに MQE を適用する
  • APISIX、AWS_EKS、AWS_GATEWAY、AWS_S3 レイヤー UI テンプレートに MQE を適用します。
  • RabbitMQ ダッシュボードに MQE を適用します。
  • Virtual-MQ レイヤーの UI テンプレートに MQE を適用する
  • インフラ Linux レイヤーの UI テンプレートに MQE を適用する
  • インフラ Windows レイヤーの UI テンプレートに MQE を適用する
  • ブラウザー層の UI テンプレートに MQE を適用します。
  • トポロジ ウィジェットに MQE を実装します。
  • getEndpoints キーワードの空白を修正。
  • ナビゲーションとしてブレッドクラムコンポーネントを実装します。

ドキュメント

  • Go エージェントをサーバー エージェントのドキュメントに追加します。
  • 継続的プロファイリング ポリシーの設定にデータ ユニットの説明を追加します。
  • storage extension ドキュメントは有効期限が切れているため削除します。
  • Sk​​yWalking はマーケットプレイスと新しいバックエンドベースのセットアップをサポートするため、how to add menu ドキュメントを削除します。
  • 貢献ドキュメントを新しいメニュー構造に分離します。
  • i18n の管理方法を説明するドキュメントを追加します。
  • OTLP トレースのサポートを説明するドキュメントを追加します。
  • dynamic-config-configmap.md のタイプミスを修正。
  • Kafka fetcher に関する古いドキュメントを修正。
  • 3 番目の部分フェッチャーはメンテナンスされなくなったため、ドキュメントから削除します。

すべての問題とプルリクエストはここです。
