skywalking v9.7.0

マイナー 公開日2023年12月1日 出典apache/skywalking 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#スカイウォーキングv9.7.0

ダウンロード

https://skywalking.apache.org/downloads/

お知らせ

このページからソース コードをダウンロードしないでください。 自分でソース コードをビルドしたい場合は、ビルド ドキュメント に従ってください。

ダークモード

dafultスタイルモードはダークモードに変更されますが、ライトモードは引き続きご利用いただけます。

新しい設計ログ ビュー

ログ ビューの新しいデザインが現在利用可能です。ログの検索が容易になり、生のテキストのためのスペースが増えます。

プロジェクト

  • e2e テストで Java エージェントを 9.1-dev にバンプします。
  • netty を 4.1.100 にバンプアップします。
  • Groovy 3 を 4.0.15 にアップデートします。
  • JDK21 でのプロジェクトのパッケージ化をサポートします。コンパイラーのソースとターゲットは JDK11 に残ります。

OAP サーバー

  • ElasticSearchClient: deleteById API を追加します。
  • カスタム アラーム ルールが「resource/alarm-settings.yml」によって上書きされる問題を修正
  • Kafka モニタリングをサポートします。
  • Pulsar サーバーと BookKeeper サーバーの監視をサポートします。
  • [重大な変更] Elasticsearch ストレージは、すべての管理データ インデックスを 1 つのインデックス management にマージします。 ui_template，ui_menu，continuous_profiling_policyを含む。
  • OOM の場合にアラーム ウィンドウが期限切れになった場合のリリース メカニズムを追加します。
  • Zipkin トレース レシーバーの応答を修正: HTTP ステータス コードを 200 から 202 にします。
  • BanyanDB Java Client を 0.5.0 に更新します。
  • BanyanDB メタデータ DAO の getInstances クエリを修正。
  • BanyanDBStorageClient: keepAliveProperty API を追加します。
  • JDBC ストレージ プラグインのテーブル存在チェックを修正しました。
  • HTTP Server ライブラリの拡張性を強化しました。
  • AlarmRecord AlarmMessage 列の長さを 512 に調整します。
  • EventHookCallback ビルド イベントを修正: Service's Layer からレイヤーをビルドします。
  • AlarmCore doAlarm: 中断を避けるために各コールバックの例外をキャッチする問題を修正しました。
  • TraceQueryEsDAO の queryBasicTraces を最適化します。
  • WebhookCallback が誤ったメッセージを送信する問題を修正し、各コールバック HTTP ポストのキャッチ例外を追加しました。
  • AlarmRule 式の検証を修正: チェック用にラベル付きメトリクスのモック データを追加。
  • ZGC メモリ プール メトリクスの収集をサポートします。
  • Netty-http (ID=151) のコンポーネント ID を追加します。 ※FibreのコンポーネントID(ID=5021)を追加します。
  • BanyanDBStorageClient: define(Property property, PropertyStore.Strategy strategy) API を追加します。
  • Kafka の e2e テストを監視するためにファイル形式を修正し、ファイル名のタイプミスを修正しました。
  • LAL のパターン化された日時文字列からのタイムスタンプの抽出をサポートします。
  • 起動ログの出力キーパラメータをサポートします。
  • JDBC 関連ストレージ内の annotationQuery パラメーターを使用して zipkin トレースをクエリできない問題を修正しました。
  • limit が ES ストレージ内の findEndpoint API に対して機能しない問題を修正。
  • MAL CounterWindow キャッシュをメトリック名で分離します。
  • JDBC ログのクエリ順序を修正しました。
  • ArrayBlockingQueue 実装を使用するように DataCarrier IF_POSSIBLE 戦略を変更します。
  • L1メトリクス集計ワーカーのキュー(DataCarrier)のポリシーをIF_POSSIBLEモードに変更します。
  • 放棄メトリクスの数をカウントするために、自己観測性メトリクス metrics_aggregator_abandon を追加します。
  • Nginx監視をサポートします。
  • BanyanDB Metadata Query を修正: NPE を回避するために、クエリが単一のインスタンス/プロセスで完全なタグを返すようにします。
  • go2sky E2E を GO エージェントに置き換えます。
  • UI テンプレートおよび E2E テストで、Metrics v2 プロトコルを MQE に置き換えます。
  • 誤った apisix メトリクスのホテル ルールを修正。 ※Scratch The OAP Config Dumpをサポートします。
  • MQE クエリ言語で increase/rate 関数をサポートします。
  • エンドポイントの負荷が高い場合、サービス エンドポイントを _abandoned にグループ化します。 カーディナリティ。

UI

  • Kafka監視のための新しいメニューを追加します。
  • 独立したウィジェットの継続時間を修正しました。 ※リンクツリー構造の表示高さを修正しました。
  • サービスウィジェット上の名前を shortName に置き換えます。
  • リファクタリング: ページネーションのスタイルを更新します。視覚化スタイルの変更はありません。
  • K8s レイヤー UI テンプレートに MQE を適用します。
  • トレースツリー図のアイコン表示を修正。
  • 修正: メトリクス グラフで複数のメトリクスのスクロール ビューをサポートするようにツールチップ スタイルを更新しました。
  • jvm メモリ プールの詳細を表示する新しいウィジェットを追加します。
  • 修正: 空のパラメーターを使用してデータをクエリすることは避けてください。
  • トレースセグメントのタイトルと説明を追加します。
  • Netty HTTP プラグインの Netty アイコンを追加します。
  • Pulsar メニューの i18n ファイルを追加します。
  • ログビューのリファクタリング。
  • ダークテーマを実装します。
  • テキストウィジェットの UI テンプレートを変更します。
  • Nginx メニュー i18n を追加しました。
  • トレースウィジェットの高さを修正しました。
  • ポーランド語のリスト形式。
  • ログとトレースの関連付けを修正。
  • 壊れたトポロジ ウィジェットのレイアウトを強化します。
  • トポロジ ウィジェットのコール タイプのコール メトリックを修正。
  • トポロジ ウィジェットのメトリクス設定の変更を修正しました。
  • タブウィジェットのルートを修正。
  • OpenFunction(FAAS レイヤー) の関連 UI テンプレートとメニュー項目を削除します。
  • 修正: ネットワーク プロファイリングのダーク テーマに合わせて色を変更します。
  • UI i18n の OpenFunction の記述を削除。
  • コンポーネントのチャンクを減らして、ページの読み込みリソース時間を短縮します。

ドキュメント

  • ストレージ ドキュメントを別のファイルに分割し、BanyanDB の推定タイムライン (2023 年末) を追加します。
  • UI-Grafana ドキュメントにトポロジ構成を追加。
  • 不足しているメトリクスを OpenTelemetry Metrics ドキュメントに追加します。
  • Concepts and Designs のポーランド語ドキュメント。 *slowCacheReadThresholdの誤ったメモを修正。
  • OAP セットアップとクラスター コーディネーターのドキュメントを更新して、ログ内の新しい起動パラメーター テーブルとセットアップ方法を説明します。 クラスターモード。

すべての問題とプルリクエストはここです。
