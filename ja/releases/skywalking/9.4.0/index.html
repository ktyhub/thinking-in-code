PromQL および Grafana のサポート

Zipkin レンズ UI がバンドルされています

AWS S3 と DynamoDB のモニタリング

プロジェクト

  • Zipkin と Zipkin レンズ UI の依存関係を 2.24.0 に引き上げます。
  • Apache の親 pom バージョンを 29 に上げます。
  • Armeria バージョンを 1.21.0 に強化します。
  • Maven pom.xml をクリーンアップします。
  • Java バージョンを 11 に上げます。
  • スネークyaml を 2.0 にバンプアップします。

OAP サーバー

  • コア モジュールに ServerStatusService を追加して、起動ステータスを他のモジュールに公開する新しい方法を提供します。
  • 新しいコンポーネントとしてマイクロメーターを追加します。(ID=141)
  • MetricsPersistentWorker のセッション キャッシュをリファクタリングします。
  • キャッシュの強化 - データベースから新しいメトリクスを微細な次元で読み取らないようにしました。
    // When
    // (1) the time bucket of the server's latest stability status is provided
    //     1.1 the OAP has booted successfully
    //     1.2 the current dimensionality is in minute.
    //     1.3 the OAP cluster is rebalanced due to scaling
    // (2) the metrics are from the time after the timeOfLatestStabilitySts
    // (3) the metrics don't exist in the cache
    // the kernel should NOT try to load it from the database.
    //
    // Notice, about condition (2),
    // for the specific minute of booted successfully, the metrics are expected to load from database when
    // it doesn't exist in the cache.
  • ワーカーの作成シーケンスに従って、メトリック セッション タイムアウトのオフセットを削除します。
  • 手動エンティティ内の MetricsExtension 注釈宣言を修正。
  • プロセス関係メトリックにおけるコンポーネント ID の優先順位をサポートします。
  • 予期しない更新不能を引き起こす MergableBufferedData の放棄ロジックを削除しました。
  • メトリクス セッションの期限切れを引き起こすミス セット LastUpdateTimestamp を修正。
  • MAL ルールの名前を spring-sleuth.yaml から spring-micrometer.yaml に変更します。
  • Zipkin API のメモリ リークを修正。
  • elasticsearch/flushInterval 構成から ElasticSearch インデックスの refresh_interval の依存関係を削除します。さて、 代わりに、すべてのインデックスに対して core/persistentPeriod + 5 を refresh_interval として使用します。
  • elasticsearch/flushInterval を 5 秒に変更します (以前は 15 秒でした)。
  • ElasticSearch BulkProcessor の flushInterval を最適化し、連続バルク ストリームでの余分な定期的なフラッシュを回避します。
  • exp が純粋なメトリック名であり、expPrefix != null の場合、予期しないドットが追加されます。
  • MariaDB の監視をサポートします。
  • BanyanDB のメジャー/ストリーム固有の間隔設定を削除します。
  • BanyanDB のグローバル構成 (segmentIntervalDays、blockIntervalHours など) をオーバーライドするために使用されるグローバル固有の設定を追加します。
  • BanyanDB の measure-default グループには TTL 駆動の間隔設定を使用します。
  • BanyanDB の非時間相対メタデータの間違ったグループを修正。
  • StorageData#id を String 型から新しい StorageID オブジェクトにリファクタリングします。
  • サービス トポロジ レベルで複数のコンポーネント ID をサポートします。
  • ElasticSearch.Keyword アノテーションを追加して、ターゲット フィールドの型を keyword として宣言します。
  • [重大な変更] service_relation_client_side および service_relation_server_side の列 component_id が component_ids に置き換えられました。
  • component-libraries.yml での priority 定義をサポートします。
  • サービス トポロジ クエリを強化します。サーバー側から複数のコンポーネントが検出された場合、 ノードのコンポーネント タイプは優先度によって決定されますが、以前のリリースでは優先度はランダムでした。 ※ service_instance_relation_client_side、service_instance_relation_server_side から component_id を削除します。
  • 衛星 E2E テストをより安定させます。
  • Istio 1.16 をテスト マトリックスに追加します。
  • BanyanDBストレージプラグインにレコードのタグとしてValueColumnを登録します。
  • Netty を 4.1.86 にバンプアップします。
  • ストレージが論理シャーディング モードの場合は、不要な追加の列を削除します。
  • クラスター コーディネーターは、RemoteClientManager および ServerStatusService を通知するための監視メカニズムをサポートします。
  • SW_OAL_ENGINE_DEBUG を開いたときに ServiceMeshServiceDispatcher が ServiceDispatcher デバッグ ファイルを上書きする問題を修正しました。
  • groupBy および in 演算子を使用して、BanyanDB ストレージ プラグインのトポロジ クエリを最適化します。
  • MetricsPersistentWorker のサーバー ステータス ウォッチャーをサポートし、初期化が必要かどうかメトリクスをチェックします。
  • sumPerMinLabeldまたはsumHistogramPercentile MAL機能使用時にメーター値が正しくない問題を修正。
  • Zipkin Lens UI クエリ トレースを使用するときに、添付されたイベントを表示できない問題を修正しました。
  • BanyanDB プラグインのストリームとメジャーの両方の種類の time_bucket を削除します。
  • Metrics と Record の TIME_BUCKET を StorageData にマージします。
  • listServices クエリでは layer はサポートされません。
  • MALのslowSqlでServiceTrafficのtime_bucketが正しく設定されていなかったのを修正。
  • BanyanDBのTopNレコードクエリDAOを修正。
  • BanyanDB の間隔設定を調整します。
  • AWS Cloud EKS のモニタリングをサポートします。
  • BanyanDB Java client を 0.3.0-rc1 にバンプします。 ※対策からidタグを削除します。
  • Banyandb.MeasureField を追加して、列を BanyanDB メジャー フィールドとしてマークします。
  • BanyanDB.StoreIDTag を追加して、検索用のプロセス ID を保存します。
  • [重大な変更] ShardingSphere-Proxy のサポートされているバージョンが 5.1.2 から 5.3.1 にアップグレードされました。 ShardingSphere の API の変更により、5.3.1 より前のバージョンには互換性がありません。
  • eBPF ネットワーク プロファイリング E2E テストをストレージごとに追加します。
  • TCP サービス インスタンスに pod や namespace などのインスタンス プロパティがないため、Pod ログが TCP ワークロードで機能しない問題を修正しました。
  • Python HBase happybase モジュール コンポーネント ID(94) を追加します。
  • gRPC アラームが動的構成ソースから設定を更新できない問題を修正しました。
  • batchOfBytes 構成を追加して、バルク フラッシュのサイズを制限します。
  • Python Websocket モジュール コンポーネント ID(7018) を追加します。
  • (オプション) ElasticSearch でルーティングをカスタマイズすることで、単一トレース クエリのパフォーマンスを最適化します。 SkyWalking トレース セグメントと Zipkin スパンは、ルーティングにトレース ID を使用します。これはデフォルトではオフであり、storage/elasticsearch/enableCustomRouting によって制御されます。
  • OAP HTTP サーバーを強化して HTTPS をサポートします
  • オテル受信機のハンドラー スキャンを削除し、代わりに手動で初期化します
  • AWS CloudWatch メトリクス (OpenTelemetry 形式) の収集をサポートするために aws-firehose-receiver を追加します。 HTTPS/TLS が設定されていないことに注意してください サポートします。 AWS Firehoseリクエストに従い、プロキシリクエストを利用します (/aws/firehose/metrics ではなく https://...)、プロキシ (Nginx、Envoy など) が必要です。
  • Antlr 依存関係のバージョンはコンパイル時と実行時で異なる可能性があるので避けてください。
  • PrometheusMetricConverter#escapedName は、/ から _ への変換もサポートするようになりました。
  • 欠落している TCP スループット メトリックを追加します。
  • @Column アノテーションをリファクタリングし、Column#name と ElasticSearch.Column#columnAlias を交換し、ElasticSearch.Column#columnAlias の名前を ElasticSearch.Column#legacyName に変更します。
  • Python HTTPX モジュール コンポーネント ID(7019) を追加します。
  • テストを junit 4 から junit 5 に移行します。
  • http ベースのアラーム プラグインをリファクタリングし、共通ロジックを HttpAlarmCallback に抽出します。
  • Amazon Simple Storage Service (Amazon S3) メトリクス監視をサポート
  • AGGREGATION_TEMPORALITY_DELTA ケースでの合計メトリックのサポート プロセス
  • Amazon DynamoDB モニタリングをサポートします。
  • prometheus HTTP API および promQL をサポートします。
  • メトリクス クエリ v1 プロトコルのエンティティの Scope は必須ではなく、自動修正されます。スコープはメトリック自体に基づいて決定されます。
  • IllegalArgumentException: Cache watchInterval=10sec >= networkClientReadTimeout=10000ms を回避するために、ConsulConfigurationWatcher に明示的な ReadTimeout を追加します。
  • startTimeBucket が endTimeBucket と等しい場合に、DurationUtils.getDurationPoints が超過する問題を修正しました。
  • プロセス OpenTelemetry ExponentialHistogram メトリクスをサポート
  • FreeRedis コンポーネント ID(3018) を追加します。

UI

  • Zipkin Lens UI を Web アプリに追加し、コンテキスト パス /zipkin にプロキシします。
  • ビルド ツールを vue cli から Vite4 に移行します。
  • インスタンス関係の修正およびエンドポイント関係のダッシュボードが表示されます。
  • マイクロメーターのアイコンを追加します。
  • MariaDB をサポートするために MySQL UI を更新します。 ※AWS監視をサポートするためのAWSメニューを追加しました。
  • 欠落していた FastAPI ロゴを追加します。
  • JSON コンテンツのフォーマットされた表示をサポートするために、ログの詳細ページを更新します。
  • ビルド構成を修正。
  • 初めてプロセス ノードをドラッグできないことを回避します。
  • ノードフォルダーを無視リストに追加します。
  • コンポーネントタイプに ElPopconfirm を追加します。
  • zipkin UI 用の iframe ウィジェットを追加します。
  • グラフのツールチップを最適化して、より使いやすくします。
  • json5 を 1.0.1 から 1.0.2 にバンプします。
  • WebSocket アイコンを追加します。
  • ウィジェットの独立モードを実装します。
  • http-cache-semantics を 4.1.0 から 4.1.1 に変更します。
  • OpenFunction のメニューを更新。
  • ウィジェット独立モードに自動更新を追加します。
  • 修正: 関連付けを使用した後、ログ ウィジェットとトレース ウィジェットのトレース ID をクリアします。
  • 修正: 時間範囲の変更後にクエリ条件の期間をリセットします。 ※AWS S3メニューを追加しました。
  • リファクタリング: サイドバーコンポーネントを最適化して、より使いやすくします。
  • 修正: クエリ結果の重複したポップアップ メッセージを削除しました。
  • HTTPX のロゴを追加します。
  • リファクタリング: トレース ウィジェット内のアタッチされたイベントの視覚化を最適化します。
  • BanyanDB client を 0.3.1 に更新します。 ※AWS DynamoDBメニューを追加しました。
  • 修正: ウィジェットの独立モードに自動ピリオドを追加しました。
  • メニューを最適化し、Windows 監視メニューを追加します。
  • cpm5dAvg の計算を追加します。
  • cpm5d 計算を追加します。
  • eBPF プロファイリング ウィジェットのデータ処理エラーを修正。
  • SlowSQL ステートメントでの二重引用符のサポート。
  • 修正: cli がトポロジ ノードをロックするときのメニューの間違った位置。

ドキュメント

  • Spring Sleuth ドキュメントを削除し、最新の Java エージェント側を備えた Spring MicroMeter Observations Analysis を追加 強化。
  • monitoring MySQL document を更新して、MariaDB パーツを追加します。
  • プロトコルのドキュメントをより明確な API ドキュメントに再編成します。
  • Zipkin サーバーを SkyWalking OAP に置き換えることに関するドキュメントを追加。
  • Zipkin トレース セクションに Lens UI の関連ドキュメントを追加。
  • API のプロファイリングを追加。
  • OAP Prometheus フェッチャーが 9.3.0 以降削除されたため、バックエンド テレメトリ ドキュメントと so11y ダッシュボード ドキュメントを修正

すべての問題とプル リクエストは [こちら] (https://github.com/apache/skywalking/milestone/160?closed=1)
