プロジェクト

  • delombok の目標により Duplicate class found を修正。

OAP サーバー

  • DynamoDB モニタリングのメトリクス user error の間違ったレイヤーを修正しました。
  • OAP が no-init モードで実行されている場合、ElasticSearch ストレージはフィールド タイプをチェックしません。
  • サービス トポロジのコンポーネントの一部として TLS ステータスのバインドをサポート。
  • コンポーネントIDの優先順位のバグを修正。
  • ストレージ層のバグによるトポロジーのコンポーネント ID の重複を修正。
  • [重大な変更] テーブルの結合と日ベースのテーブル ローリングの管理により、JDBC ストレージを強化します。
  • [重大な変更] デフォルトで日ベースのローリング メカニズムがあるため、Sharding-MySQL の実装とテストが削除される
  • otel k8s-cluster ルールを修正して、MAL 集計計算用の名前空間ディメンションを追加 (展開ステータス、展開スペック レプリカ)
  • 継続的なプロファイリング機能をサポートします。
  • プロセス レベル関連のメトリクスの収集をサポートします。
  • 名前空間の不一致の可能性により、K8sRetag が間違った k8s サービスをキャッシュから読み取る問題を修正しました。
  • [重大な変更] クロススレッド トレース プロファイリングをサポートします。データ構造とクエリ API が変更されます。
  • PromQL HTTP API /api/v1/labels 応答に service ラベルがない問題を修正。
  • IntList の初期化時に発生する可能性のある NPE を修正。
  • サポート解析 PromQL 式では、メタデータ クエリの中括弧内に空のラベルが含まれています。
  • アラームメトリック OP != をサポートします。
  • サポート メトリック クエリは、値 == 0 が実際にゼロを表すか、データがないかを示します。
  • ElasticSearch ストレージ内に存在しないシリーズ インデックスをクエリする場合の NPE を修正しました。
  • VM 監視におけるメモリ バフ/キャッシュ メトリクスの収集をサポートします。
  • PromQL: クエリ結果から空の値を削除し、範囲外を引き起こす可能性がある /api/v1/metadata パラメーター limit を修正しました。
  • k8s StatefulSet と DaemonSet の合計数メトリクスの監視をサポートします。
  • Amazon API ゲートウェイ監視をサポートします。
  • cveを修正するためにgraphql-javaを強化します。
  • Kubernetes Java client をバンプアップします。
  • Redisモニタリングをサポートします。
  • amqp、amqp-Producer、および amqp-consumer のコンポーネント ID を追加します。
  • aws-firehose レシーバーのプロキシなしモードをサポート
  • アルメリアを1.23.1にバンプアップ
  • Elasticsearchモニタリングをサポートします。
  • メトリックと一致するときに、PromQL HTTP API /api/v1/series 応答で service ラベルが欠落していた問題を修正しました。
  • BanyanDB の ServerSide TopN をサポートします。
  • Jersey のコンポーネント ID を追加します。
  • OpenCensus サポート、関連コード、ドキュメントを 廃止予定 として削除します。
  • searchableTracesTags の動的構成をサポート
  • Kafka チャネルを介してエラー ステータス トレース セグメントをエクスポートするための exportErrorStatusTraceOnly をサポート
  • Grizzly のコンポーネント ID を追加します。
  • Span にいくつかのフィールドが欠落している場合に、Zipkin レシーバーで発生する可能性のある NPE を修正。
  • フィルタリングして、unknown_cluster メトリクス データを除外します。
  • RabbitMQ モニタリングをサポートします。
  • Redis の遅いログ収集をサポートします。
  • 継続的プロファイリング タスク レコードをクエリするときのデータ損失を修正しました。
  • 継続的プロファイリング タスク クエリ GraphQL を適応させます。
  • メトリック クエリ式 (MQE) をサポートし、ユーザーが式を通じて簡単なクエリ段階の計算を実行できるようにします。
  • 非推奨のメトリクス クエリ v2 プロトコル。
  • 非推奨のレコード クエリ プロトコル。
  • go-redis のコンポーネント ID を追加します。
  • OpenSearch 2.8.0 をテスト ケースに追加します。
  • ai-pipelineモジュールを追加します。
  • パターン認識を行うために、ai-pipeline による HTTP URI 形式をサポートします。
  • ベンチマークを備えた新しい HTTP URI グループ化エンジンを追加します。
  • [重大な変更] 新しい HTTP URI グループ化エンジンを使用して、古い正規表現ベースのメカニズムを置き換えます。 ※MALでsumLabeledに対応しました。
  • kubernetes-client/java から Fabric8 client に移行します。
  • Envoy ALS で生成された関係メトリックは、http ステータス コード >= 400 に client 側でエラーがあるとみなします。
  • 継続プロファイリング タスクをクエリするときに原因メッセージ フィールドを追加します。

UI

  • 元に戻す: cpm5d 関数。この機能はバックエンドからキャンセルされます。
  • 修正: トポロジ上のリンク切断の警告。
  • トポロジ ウィジェットをリファクタリングして、より階層的にします。
    1. 最初のノードとして User を選択します。
    2. User ノードが存在しない場合は、最もビジーなノード (すべての中で最もコールが多いノード) を選択します。
    3. 左から右へのフロー処理を実行します。
    4. 同じレベルで、ノードをアルファベット順に上から下にリストします。
  • ReadRecords メトリックがトレースに関連付けられる場合のフィルター ID を修正しました。 ※AWS APIゲートウェイメニューを追加しました。
  • トレースプロファイリングプロトコルを変更します。 ※Redisメニューを追加しました。
  • データ型を最適化します。
  • メトリクス クエリの isEmptyValue フラグをサポートします。 ※elasticsearchメニューを追加しました。
  • [アップグレード前のクリーンな UI テンプレート] showSymbol: true を設定し、データ ポイントを折れ線グラフに表示します。 elasticsearch ストレージ内の ui_template インデックスまたは JDBC ストレージ内のテーブルをクリーンアップしてください。
  • [アップグレード前のクリーンな UI テンプレート] UI テンプレート: メトリック名をラベルで簡略化します。 ※MQメニューを追加しました。
  • Jeyseyアイコンを追加します。
  • 修正: URL パラメーターを使用してエンドポイントとインスタンスのセレクターを正しく設定しました。
  • 依存関係のバージョンを強化する icons-vue 1.1.4、element-plus 2.1.0、nanoid 3.3.6、postcss 8.4.23
  • OpenTelemetry ログ プロトコルのサポートを追加。
  • [重大な変更] 構成キー enabledOtelRules の名前が enabledOtelMetricsRules に変更され、 対応する環境変数の名前は SW_OTEL_RECEIVER_ENABLED_OTEL_METRICS_RULES に変更されます。
  • ハイイログマのアイコンを追加します。
  • インスタンスリストデータの表示エラーを修正。
  • 修正: topN タイプを Number に設定します。
  • メトリック クエリ式 (MQE) をサポートし、ユーザーが式を通じて簡単なクエリ段階の計算を実行できるようにします。
  • zipkin ui の依存関係を 2.24.1 に引き上げます。 ※バイトを4.0.5にバンプアップします。
  • General および Virtual-Database レイヤーの UI テンプレートに MQE を適用します。

ドキュメント

  • プロファイリング関連のドキュメントを追加します。
  • MAL ドキュメントに SUM_PER_MIN を追加。
  • ログ関連ドキュメントをより明確にし、さらに多くの形式のサポートを容易にします。
  • クラスター管理および高度な展開に関するドキュメントを更新します。

すべての問題とプルリクエストはここです。
