BanyanDB 0.6 をクラスター モードで実行する

プロジェクト

  • Java 21 ランタイムをサポートします。
  • Java 21 ランタイムの oap-java21 イメージをサポートします。
  • すべての e2e テストで、OTEL collector バージョンを 0.92.0 にアップグレードします。
  • CI macOS ランナーを m1 に切り替えます。
  • CVE-2024-1597 を修正するには、PostgreSQL ドライバーを 42.4.4 にアップグレードします。 ※画像からCLI(swctl)を削除してください。
  • Makefile ビルドから CLI_VERSION 変数を削除します。
  • BanyanDB を docker-compose クイックスタートに追加します。
  • CVE を修正するために Armeria、jackson、netty、jetcd、grpc を強化します。
  • BanyanDB Java Client を 0.6.0 に強化します。

OAP サーバー

  • グローバル トポロジgraphQLクエリにlayerパラメータを追加します。
  • リストメトリクスに値があるかどうかをチェックするための is_present 関数を MQE に追加しました。
  • gRPC スレッド エグゼキュータの不合理なデフォルト設定を削除します。
  • gRPCThreadPoolQueueSize (SW_RECEIVER_GRPC_POOL_QUEUE_SIZE) 構成を削除します。
  • 最終的な解決方法として ServiceEntries を検索するときに、一部の名前空間で ServiceEntries を除外できるようにします。 サービスメタデータ。
  • サービス、インスタンス、エンドポイント、プロセスの関連エンティティのソース ID と宛先 ID の長さを 250 に設定します(以前は 200）。
  • サービス/インスタンス階層の構築とクエリをサポートします。
  • 32766 を超える長さが設定されている場合は、Elasticsearch ストレージの文字列フィールドを キーワード タイプから テキスト タイプに変更します。
  • [重大な変更] Elasticsearch ストレージ内の ui_template および ui_menu の構成フィールドを キーワード タイプから テキスト に変更します。
  • サービス階層の自動マッチングをサポートし、次のように自動マッチング レイヤー関係 (上位 -> 下位) を追加します。
    • メッシュ -> MESH_DP
    • メッシュ -> K8S_SERVICE
    • MESH_DP -> K8S_SERVICE
    • 一般 -> K8S_SERVICE
  • デフォルトとして、K8S_SERVICE_NAME_RULE/ISTIO_SERVICE_NAME_RULE および metadata-service-mapping.yaml に namespace サフィックスを追加します。
  • ALS 受信機の専用ポートの使用を許可します。
  • JDBCLogQueryDAOのtraceIdによるログクエリを修正。
  • ハンドラー eBPF アクセス ログ プロトコルをサポートします。
  • SumPerMinFunctionTest エラー関数を修正。
  • メーター機能から不要な注釈と機能を削除します。
  • MAL ダウンサンプリング用の max および min 関数を追加します。
  • TopN 統計の制御されていないメモリ コストの重大なバグを修正。 topN グループ キーを StorageId から entityId + timeBucket に変更します。
  • 次のようにサービス階層の自動一致レイヤー関係 (上位 -> 下位) を追加します。
    • MYSQL -> K8S_SERVICE
    • POSTGRESQL -> K8S_SERVICE
    • SO11Y_OAP -> K8S_SERVICE
    • 仮想データベース -> MYSQL
    • 仮想データベース -> POSTGRESQL
  • AMQP のサポート対象言語として Golang を追加します。
  • トポロジ内で利用可能なサービス層をサポートします。
  • MAL 用の count 集計関数を追加
  • 次のようにサービス階層の自動一致レイヤー関係 (上位 -> 下位) を追加します。
    • NGINX -> K8S_SERVICE
    • APISIX -> K8S_SERVICE
    • 一般 -> APISIX
  • RocketMQ のサポート対象言語として Golang を追加します。
  • Apache RocketMQ サーバー監視をサポートします。
  • 次のようにサービス階層の自動一致レイヤー関係 (上位 -> 下位) を追加します。
    • ROCKETMQ -> K8S_SERVICE
    • VIRTUAL_MQ -> ROCKETMQ
  • ServiceInstance in クエリを修正。
  • PromQL API のモック /api/v1/status/buildinfo。
  • JDBC ストレージ プラグインのテーブル存在チェックを修正しました。
  • JDBC ストレージにおける日ベースのテーブルローリング時間範囲戦略を修正。
  • DCS の最大受信メッセージ サイズを変更するには、maxInboundMessageSize (SW_DCS_MAX_INBOUND_MESSAGE_SIZE) 構成を追加します。
  • EventHookCallback でイベントを構築する際のサービス レイヤーを修正しました。
  • Pulsar のサポート対象言語として Golang を追加します。
  • 次のようにサービス階層の自動一致レイヤー関係 (上位 -> 下位) を追加します。
    • RABBITMQ -> K8S_SERVICE
    • VIRTUAL_MQ -> RABBITMQ
  • カーネル内の Column#function メカニズムを削除します。
  • クエリ readMetricValue が常に継続時間の平均値を返すようにします。
  • 次のようにサービス階層の自動一致レイヤー関係 (上位 -> 下位) を追加します。
    • カフカ -> K8S_SERVICE
    • VIRTUAL_MQ -> カフカ
  • ClickHouse サーバー監視をサポートします。
  • 次のようにサービス階層の自動一致レイヤー関係 (上位 -> 下位) を追加します。
    • CLICKHOUSE -> K8S_SERVICE
    • 仮想データベース -> CLICKHOUSE
  • 次のようにサービス階層の自動一致レイヤー関係 (上位 -> 下位) を追加します。
    • パルサー -> K8S_SERVICE
    • VIRTUAL_MQ -> パルサー
  • Golang を Kafka のサポート対象言語として追加します。
  • サーバーの起動時に OAP および UI からサービスがリッスンするポートの表示をサポートします。
  • メトリクスの生成をサポートするためにデータ ジェネレーターをリファクタリングします。
  • AvgHistogramPercentileFunction のレガシー名を修正。
  • [重大な変更] ラベル付きメトリックは複数のラベルをサポートします。
    • ストレージ: 値だけではなく、すべてのラベル名と値を保存します。
    • MQE:
      • 匿名ラベル名として _ を使用する代わりに、複数のラベル (名前と値) によるクエリをサポートします。
      • aggregate_labels 関数は、特定のラベルによる集計をサポートします。
      • relabels 関数にはターゲット ラベルが必要であり、ラベル名と値の名前を変更します。
    • PromQL:
      • 匿名ラベル名として lables を使用する代わりに、複数のラベル (名前と値) によるクエリをサポートします。
      • 一般的なラベル labels/relabels/label 機能を削除します。
      • API /api/v1/labels および /api/v1/label/<label_name>/values は、一致したメトリック ラベルを返すことをサポートしています。
    • OAL:
      • percentile 関数を廃止し、代わりに percentile2 関数を導入します。
  • Kafka を強化して CVE を修正します。
  • Istio ServiceEntry レジストリの NullPointerException を修正。
  • ServiceRelationClientSideMetrics および ServiceRelationServerSideMetrics エンティティ内のシリーズ ID として不要な componentIds を削除します。
  • 式の一部が MQE および PromQL のどの式ノードにも一致しない場合にエラーがスローされない問題を修正しました。 ※[#7326](https://github.com/apache/skywalking/issues/7326)(v8.7.0)以降は自動的に作成されるため、kafka-fetcher/default/createTopicIfNotExist`を削除します。
  • 不正確な nginx サービス メトリクスを修正。
  • Windows メトリクス名の修正/変更 (スワップ -> 仮想メモリ)
    • memory_swap_free -> memory_virtual_memory_free
    • memory_swap_total -> memory_virtual_memory_total
    • memory_swap_percentage -> memory_virtual_memory_percentage
  • Windows Swap -> 仮想メモリの UI 初期設定を修正/変更
  • UI初期化によるMemory Swap Usage/Virtual Memory Usageの表示を修正(Linux/Windows)
  • 不正確な APISIX メトリクスを修正。
  • 不正確な MongoDB メトリクスを修正。
  • Apache ActiveMQ サーバー監視をサポートします。
  • 次のようにサービス階層の自動一致レイヤー関係 (上位 -> 下位) を追加します。
    • アクティブMQ -> K8S_SERVICE
  • MQE による Nginx サービスの HTTP レイテンシーを計算します。
  • MQE クエリ: メタデータが null を返さないようにします。
  • MQE ラベル付きメトリックのバイナリ操作: ラベルが一致しない場合は、エラーを報告するのではなく、空の値を返します。
  • RabbitMQ サーバー監視メトリクスの不正確な階層を修正。
  • 不正確な MySQL/MariaDB、Redis、PostgreSQL メトリクスを修正。
  • OTEL メトリック属性で DoubleValue、IntValue、BoolValue をサポートします。
  • [重大な変更] gGRPC メトリクス エクスポーターはメトリクス値のタイプを統合し、ラベル付きメトリクスをサポートしました。
  • c3p0(JDBC3 Connection and Statement Pooling)のコンポーネント定義(ID=152)を追加。
  • MQE top_n グローバル クエリを修正。
  • 不正確な Pulsar および Bookkeeper メトリクスを修正。
  • MQE は sort_values および sort_label_values 機能をサポートします。

UI

  • Linux-Service Dashboard の「ネットワーク帯域幅使用量」ウィジェットの単位と計算の不一致を修正しました。
  • テーマ変更アニメーションを追加します。
  • サービスとインスタンスの階層トポロジを実装します。
  • MQE 式のときに表示されるウィジェット内のタブをサポートします。
  • マーケットプレイスでの検索をサポートします。
  • デフォルトルートを修正。
  • ログウィジェットのレイアウトを修正しました。
  • トレースとログ ウィジェットの関連付けを修正。
  • isDefault をダッシュ​​ボード設定に追加します。
  • ダッシュボード リスト ページのダッシュボード構成に式を追加します。
  • eBPF アクセス ログからのデータを適応するために、Kubernetes 関連の UI テンプレートを更新します。
  • ダッシュボードの K8S-Service-Root メトリクス表現を修正しました。
  • サービス/インスタンス階層のダッシュボードを追加します。
  • Card widget 使用時のダッシュボードの MQE を修正。
  • ツールチップのスタイルを最適化します。
  • ウィンドウのサイズ変更によりトレース グラフが正しく表示されない問題を修正しました。 ※見つからないページ(404)を追加しました。
  • VNode ロジックを強化し、スパンの参照で複数のトレース ID をサポートします。
  • レイヤー フィールドを追加し、サービス トポロジ ノードのレイヤー ダッシュボードを関連付けます。
  • Nginx-Instance メトリクスをインスタンス レベルに修正しました。
  • Kubernetesサービスページのタブを更新。
  • Airflowメニューi18nを追加。
  • トレースパネルでのドラッグのサポートを追加しました。
  • ワークフローアイコンを追加します。
  • メトリクスは複数のラベルをサポートします。
  • テーブルウィジェットの SINGLE_VALUE をサポートします。
  • 一般メトリック モードと関連する論理コードを削除します。
  • トポロジー内の非現実ノードのメトリックを削除します。
  • バッチ消費スパンのトレース ウィジェットを強化します。
  • UI テンプレート内の未使用の要素を削除します。

ドキュメント

  • テストは手動ではなく e2e を通じて行われるため、リリース ドキュメントを更新してアナウンスを削除します。 ※リリース通知メールを少し更新しました。
  • ポーランド語のドキュメント構造。カスタマイズ ドキュメントを導入ドキュメントとは別に移動します。
  • backend-alarm.md の Webhook/gRPC フック設定例を追加しました。 ※SWIP - SkyWalking Improvement Proposalの処理を開始します。 ※SWIP-1 Create and detect Service Hierarchy Relationshipを追加します。 ※SWIP-2 Collecting and Gathering Kubernetes Monitoring Dataを追加します。
  • Overview ドキュメントを更新して、Service Hierarchy Relationship セクションを追加します。
  • backend-bookkeeper-monitoring.md と backend-pulsar-monitoring.md の誤った単語を修正
  • OAP の負荷分散を行う新しい方法を文書化します。 ※SWIP-3 Support RocketMQ monitoringを追加します。
  • OpenTelemetry SkyWalking Exporter の非推奨の警告ドキュメントを追加。
  • rocketmq 監視用に i18n を更新します。
  • 修正: アンマウント後に click イベントを削除。
  • 修正: クエリ結果なしでロードを終了します。
  • nanoid のバージョンを 3.3.7 に更新します。
  • postcss のバージョンを 8.4.33 に更新します。
  • エクスポータドキュメントのkafkaトピック名を修正。
  • query-protocol.md を修正し、GraphQL クエリ プロトコルとの一貫性を持たせます。 ※SWIP-5 Support ClickHouse Monitoringを追加します。
  • OTEL アップストリームでメンテナンスされていないというフラグが立てられているため、メーター ドキュメントから OpenTelemetry Exporter サポートを削除します。
  • さまざまなストレージ タイプ用の 1 行のクイック スタート スクリプトのドキュメントを追加しました。 ※Why is Clickhouse or Loki or xxx not supported as a storage option?のFAQを追加しました。 ※SWIP-8 Support ActiveMQ Monitoringを追加します。
  • BanyanDB ストレージを推奨ストレージに移動します。

すべての問題とプルリクエストはここです。
