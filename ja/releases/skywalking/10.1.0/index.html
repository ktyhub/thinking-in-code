skywalking v10.1.0

マイナー 公開日2024年9月29日 出典apache/skywalking 英語原文

#スカイウォーキングv10.1.0

ダウンロード

https://skywalking.apache.org/downloads/

お知らせ

このページからソース コードをダウンロードしないでください。 自分でソースコードをビルドしたい場合は、ビルドドキュメントに従ってください。

パフォーマンスのバージョン

  • UI パフォーマンスの大幅な向上。メトリクス ウィジェット クエリは、GraphQL 機能を活用してバンドルされています。
  • GraphQL エンジンでの並列クエリのサポート。クエリのパフォーマンスを向上させます。
  • OTEL メトリクス ハンドラーのパフォーマンスが大幅に向上しました。 OTEL メトリクス プロセスにおける CPU コストと GC コストを削減します。
  • BanyanDB 0.7 の採用により、ネイティブ データベースのパフォーマンスと安定性が向上しました。

プロジェクト

  • E2E: opentelemetry コレクターのバージョンを 0.102.1 に上げます。
  • スナップショット データ ジェネレーター docker イメージを ghcr.io にプッシュします。
  • GHA による docker-compose v1 の削除を回避するには、skywalking-infra-e2e を強化します。
  • CodeQL GitHub アクションを強化します。
  • ビルド警告を減らすために delombok プラグインの間違ったフェーズを修正しました。
  • プロジェクトのバージョンを設定するには、ci フレンドリーなリビジョンを使用します。

OAP サーバー

  • eBPF プロファイリング関連モデルの間違ったインデックスを修正。
  • サポートは、eBPF アクセス ログ レシーバー内の特定の名前空間トラフィックを除外します。
  • Elasticsearch のサポートされる言語として Golang を追加します。 ※不要なBanyanDBフラッシュログ(情報)を削除します。
  • SW_CORE_GRPC_MAX_MESSAGE_SIZE を 50MB に増やします。
  • PromQL を介した関係メトリクスのクエリのサポート。
  • デバッグ用のトレース MQE クエリをサポートします。
  • Solon フレームワークのコンポーネント ID(158) を追加します。
  • ブラウザ受信プラグインの HTTP ハンドラーのメトリクス タグを修正しました。
  • alarm_record#message 列の長さを 200 から 2000 に増やします。
  • alarm_record#message 列のインデックスを削除します。
  • Pulsar のサポート対象言語として Python を追加します。
  • persistence_timer_bulk_prepare_latency 用に、より適切なヒストグラム バケットを作成します。 PersistenceTimer の persistence_timer_bulk_execute_latency および persistence_timer_bulk_all_latency メトリクス。
  • [重大な変更] Nacos バージョンを 2.3.2 に更新します。 Nacos 1.x サーバーは、クラスター コーディネーターおよび構成サーバーとして機能できません。
  • デバッグ用のトレース トレース クエリ (SkyWalking および Zipkin) をサポートします。
  • BanyanDB メトリクス クエリを修正: スキーマの検索に間違った Downsampling タイプを使用しました。
  • cilium サービス間のネットワーク トラフィックを監視するための cilium フローのフェッチをサポートします。
  • OAL エンジンで labelCount 機能をサポートします。
  • BanyanDB の内部測定クエリ実行トレースをサポートします。
  • BanyanDB client config: デフォルトの maxBulkSize を 10000 に上げ、flushTimeout を追加して、デフォルトを 10 秒に設定します。
  • BanyanDB グループとスキーマ作成ロジックをポーランド語に修正し、分散競合状態でのスキーマ作成失敗の問題を修正しました。
  • デバッグ用のトポロジ クエリのトレースをサポートします。
  • MySQLダッシュボードのグラフCurrent QPSの表現を修正。
  • デバッグ用のトレース ログ クエリをサポートします。
  • BanyanDB: タグのオートコンプリート データ ストレージとクエリを修正。
  • PromQL クエリで集計演算子をサポートします。
  • kubernetes HTTP 遅延関連メトリクス ソース ユニットを ns から ms に更新します。
  • BanyanDB 内部ストリーム クエリ実行トレースをサポートします。
  • Elasticsearch、MySQL、RabbitMQ ダッシュボードのタイプミスと欠落している表現を修正。
  • BanyanDB: Zipkin モジュールは、クエリのパフォーマンスを向上させるためにサービスをエンティティとして設定します。
  • MQE: 堅牢性を向上させるために、バイナリ演算を実行する前にメトリクス値をチェックします。
  • 回避策を Armeria ネイティブでサポートされているコンテキスト パスに置き換えます。
  • ヘルスチェック用の http エンドポイント ラッパーを追加します。
  • Armeria と推移的な依存関係を強化します。
  • BanyanDB: モデル列がすでに @BanyanDB.TimestampColumn である場合は、インデックスを減らすためにそれに @BanyanDB.NoIndexing を設定します。
  • BanyanDB: time クエリによるストリーム並べ替え。クエリのパフォーマンスを向上させるために、index ではなく内部時系列を使用します。 *graphql-java を 21.5 に強化します。
  • 受信 Kubernetes ピア アドレスが現在のクラスターで認識されない場合は、不明なノードを追加します。
  • CounterWindow の同時増加により、PriorityQueue による NPE が発生する問題を修正
  • 空の文字列を含むエンドポイント名の形式を修正しました。
  • 複合GraphQLクエリの非同期クエリをサポートします。
  • タイムスタンプの説明によってエンドポイント リストの順序を取得します。
  • eBPF レシーバーによって生成されたメトリクスのソート クエリをサポートします。
  • label_values クエリ変数を使用する場合の Grafana 11 との互換性を修正しました。
  • 構成サーバーおよびクラスター コーディネーターとしての Nacos は、構成 contextPath をサポートします。
  • eBPF アクセス ログ レシーバーのエンドポイント名の形式を <Method>:<Path> に更新します。
  • OpenTelemetry受信機の自己観測性メトリクスを追加。
  • eBPF アクセス ログ レシーバーでポッド コンテキストが欠落している場合のサービス レベル メトリックの集約をサポートします。
  • 指定されたレイヤーでサービスが見つからなかった場合に例外をスローするクエリ getGlobalTopology を修正しました。
  • ALS k8s-mesh アナライザーで以前の分析結果が欠落していた問題を修正しました。
  • BanyanDB を使用する場合、findEndpoint クエリに keyword が必要になる問題を修正しました。
  • eBPF アクセス ログ レシーバーでの ztunnel マップされた IP アドレスと mTLS モードの分析のサポート。
  • BanyanDB Java Client 0.7.0 を適応させます。
  • Sk​​yWalking Java Agent 自己観測性ダッシュボードを追加します。
  • GoFrame フレームワークのコンポーネント ID(5022) を追加します。
  • protobuf Java 依存関係を 3.25.5 に追加します。
  • BanyanDB: クエリ findEndpoint および getAlarm での keyword のネイティブ用語検索の使用をサポートします。
  • BanyanDB: TLS 接続と構成をサポートします。
  • PromQL サービス: クエリ API は RFC3399 時間形式をサポートします。
  • OTEL メトリクス ハンドラーのパフォーマンスを向上させます。
  • PromQL サービス: rangeExpression フラグが欠落していた演算子の結果を修正。
  • BanyanDB: TimestampRange を使用して、BanyanDB の「イベント」クエリを改善します。
  • network_address_alias テーブルを最適化してインデックスの数を減らします。
  • PromQL サービス: 丸括弧演算子をサポートします。
  • オートコンプリート用のクエリ アラーム メッセージ タグをサポートします。

UI

  • 検索ログのキーワードを強調表示します。
  • ブラウザログにエラー URL を追加します。
  • SolonMVC アイコンを追加します。 *メニューに繊毛アイコンとi18nを追加しました。
  • Windows サービス ダッシュボードの「ネットワーク帯域幅使用量」ウィジェットの単位と計算の不一致を修正しました。
  • サービス/インスタンス/エンドポイント リスト ウィジェットでは、クエリごとに最大 20 個のエンティティを作成します。
  • トレースウィジェットのエラーノードを修正。
  • トレースプロファイリングにフレームグラフを導入します。
  • ページ番号を変更するときにサービスとインスタンスを修正しました。
  • メトリクスクエリを改善して、ページを開く速度を速くしました。
  • 依存関係を強化して CVE を修正します。
  • 初期化ページのローディングビューを追加します。
  • cliが更新アイコンをクリックしたときのセレクターのバグを修正。
  • OAP バックエンドのヘルスチェックを修正しました。
  • Service、ServiceInstance、Endpoint ダッシュボード フォワーダーを Kubernetes トポロジに追加します。
  • サービス/インスタンス リスト ウィジェットのページネーションを修正しました。
  • アラームタグのクエリを追加します。
  • スカイウォーキング Java エージェントの自己観測メニューを追加。

ドキュメント

  • zabbix レシーバーがサポートするバージョンの説明を更新します。
  • 公式ダッシュボードのドキュメントをマーケットプレイスのドキュメントに移動します。
  • 機能ドキュメントを見つける際の混乱を軽減するために、quick start メニューの下にマーケットプレイスの紹介ドキュメントを追加しました。
  • Windows メトリクスの更新 (スワップ -> 仮想メモリ)
