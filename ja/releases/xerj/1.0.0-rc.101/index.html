資産と来歴

8 つのターゲットと XERJ Query-1 モデル バンドルのバイナリ:

  • xerj-1.0.0-rc.101-<target>.tar.gz / .zip (+ .sha256)、.deb (2 つの linux-gnu ターゲット用)。
  • xerj-model-bundle-v1-v1.0.0-rc.101.tar.gz (+ .sha256): XERJ Query-1 バンドル (candidate_a_s47、FP16、CPU 上で int8 として機能)。 xerj --facts-model-dir <DIR> で有効にします。フラグがない場合、ノードは rc.100 です。両方を 1 つのステップでインストールします: curl -fsSL https://xerj.org/get | sh -s -- --with-model。

来歴: このリリースのバイナリは、プライベート ツリー (3f6aefa8 のパブリック main + XERJ-R ストレージ/インジェスト/ファクト レーン + 独自のモデル クレート xerj-infer/xerj-serve/xerj-exec、バイナリ + バンドルのみとして出荷され、このリポジトリには存在しません) から構築されました。 6 つの x86_64/macOS/Windows アセットは、リリース ワークフローによってクロスビルドされました。 2 つの aarch64 Linux アセットは、GitHub の ARM クロスビルド ランナーがジョブの途中で 2 回シャットダウンされた後、同じタグから aarch64 ホスト上でネイティブにビルドされました。すべての資産には SHA-256 が適用されます。 既知の制限 (測定済み): カウントは subject_id を含むファクトのみに適用され、合計ではなくセット カウントをカバーします。カウントは、一致したセットを集計し、質問の名詞をチェックしません (ストアに欠けている関係に関する数量の質問は、メンバーのカウントとして提供できます)。モデルは、declines (1,600 個の標準評価項目のうち 383 個) を上回っています。詳細：docs/FACTS_API.md、docs/XERJ_QUERY_1.md。

既知の問題 (オプトイン ストレージ オプション): source_ref を有効にすると、編集によってファイル サイズが同じに保たれる場合 (断続的、3 回のうち 2 回の分離実行)、編集されたソース ファイルからテキストを読み取る検索で、「ファイルが変更されました」エラーの代わりに古いテキストが返されることがあります。デフォルトのレイアウトはテキストをインデックスに保存しますが、影響を受けません。 rc.102を追跡しました。
