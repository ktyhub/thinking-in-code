lowcode-engine v1.1.7

ローコードエンジン v1.1.7

何が変わったのか

  • https://github.com/alibaba/lowcode-engine/pull/1856 の @lijicheng123 による setters.md の更新
  • リファクタリング: https://github.com/alibaba/lowcode-engine/pull/1864 の @duoduoObama によって let を const に変更
  • 功績: @eternalsky によるComponentRenderer lifeCycles ログを https://github.com/alibaba/lowcode-engine/pull/1865 に追加
  • 功績: https://github.com/alibaba/lowcode-engine/pull/1870 の @liujuping によるワークスペース モードの機能の追加
  • 修正: https://github.com/alibaba/lowcode-engine/pull/1871 の @liujuping によるモーダル追加/削除関連の操作にアウトライン ツリーが応答しない問題を修正
  • 修正(utils): isReactComponentにreact.memoが含まれていない (https://github.com/alibaba/lowcode-engine/pull/1885の@liujupingによる)
  • 特技(共通): https://github.com/alibaba/lowcode-engine/pull/1889 の @liujuping により、古いプラットフォームと互換性を持たせるために api を追加
  • feat(renderer-core): https://github.com/alibaba/lowcode-engine/pull/1892 の @liujuping による setState 実行時のログを追加
  • 功績: https://github.com/alibaba/lowcode-engine/pull/1893 の @liujuping による編集者 api の削除
  • feat(material): マテリアル apis は、https://github.com/alibaba/lowcode-engine/pull/1900 の @liujuping により、refreshComponentMetasMap 関数を追加しました
  • docs(config): https://github.com/alibaba/lowcode-engine/pull/1908 の @liujuping による config.getPreference api のデモを追加
  • fix(prop): https://github.com/alibaba/lowcode-engine/pull/1912 の @liujuping による prop.export が unknown[] を正しくエクスポートできない問題を修正
  • feat(workspace): https://github.com/alibaba/lowcode-engine/pull/1910 の @liujuping により、enableAutoOpenFirstWindow 設定と onWindowRendererReady 関数を追加
  • ドキュメント: https://github.com/alibaba/lowcode-engine/pull/1914 の @LeoYuan による素晴らしいバッジを README に追加
  • ドキュメント: 修复表格排版错误 by @StringKe in https://github.com/alibaba/lowcode-engine/pull/1923
  • 機能: https://github.com/alibaba/lowcode-engine/pull/1919 の @LeoYuan によるベース ブランチをチェックするためのワークフローを追加
  • 功績: https://github.com/alibaba/lowcode-engine/pull/1934 の @liujuping によるセッター型の更新
  • feat(utils): カーソル不使用less by @StringKe in https://github.com/alibaba/lowcode-engine/pull/1937
  • feat(シェル): https://github.com/alibaba/lowcode-engine/pull/1941 の @liujuping によるエディター ビュー モデルを追加
  • ドキュメント: https://github.com/alibaba/lowcode-engine/pull/1943 の @liujuping による common.md の更新
  • feat(outline-pane): https://github.com/alibaba/lowcode-engine/pull/1953 の @liujuping により、OutlinePaneContext をエクスポートし、setPluginContext に null オプションと HideFilter オプションを Pane に追加しました。
  • feat(workspace): https://github.com/alibaba/lowcode-engine/pull/1954 の @liujuping によりリソース シェル モデルに config 属性を追加
  • 修正: https://github.com/alibaba/lowcode-engine/pull/1955 で、removeEditorWindow が @liujuping によるタイトルを比較しない
  • 特技: これからエディターを取得するか、https://github.com/alibaba/lowcode-engine/pull/1957 の @liujuping によるパラメータを取得します。
  • 功績: 外部パラメータを受信できるポップアップ by @wendell0316 (https://github.com/alibaba/lowcode-engine/pull/1947)
  • 修正: https://github.com/alibaba/lowcode-engine/pull/1962 の @BARMPlus によってプロキシ plugins.delete が非同期で追加されない問題を修正しました。
  • 雑務: https://github.com/alibaba/lowcode-engine/pull/1976 の @BARMPlus によるより安全な plugins.delete
  • 修正: 編集ページドキュメントでのドラッグ方法に関連する 4 番目の見出し名を修正します。 @milocooper 著、https://github.com/alibaba/lowcode-engine/pull/1974
  • リファクタリング: コンポーネントの moduleName は、https://github.com/alibaba/lowcode-engine/pull/1991 の @LeoYuan によって変換されるべきではありません
  • 功績: @liujuping によるスケルトン アイテム モデルを https://github.com/alibaba/lowcode-engine/pull/2020 に追加
  • 特技: https://github.com/alibaba/lowcode-engine/pull/2021 で @liujuping によるロケール設定のリセットをサポート
  • 功績: ワークスペース追加 onChangeActiveWindow イベント api by @liujuping (https://github.com/alibaba/lowcode-engine/pull/2022)
  • 修正: https://github.com/alibaba/lowcode-engine/pull/2025 の @liujuping によって plugin-outline-pane 条件タグが更新されない問題を修正
  • 雑用: @alilc/build-plugin-lce を使用して、https://github.com/alibaba/lowcode-engine/pull/2014 の build-plugin-component を @JackLian に置き換えます。
  • 修正: 入力スキーマが https://github.com/alibaba/lowcode-engine/pull/2032 の @proclml による反応 dom の場合に最初に返す
  • 功績: ワークスペースにいくつかの機能を追加 (https://github.com/alibaba/lowcode-engine/pull/2038 の @liujuping による)
  • 功績: Canvas.activeTracker でターゲット プロップを追加 (https://github.com/alibaba/lowcode-engine/pull/2044 の @liujuping による)
  • 功績: https://github.com/alibaba/lowcode-engine/pull/2043 の @liujuping によるワークスペースの睡眠シーンの改善
  • 修正: https://github.com/alibaba/lowcode-engine/pull/1994 の @BARMPlus によって、outlinePane TreeView が 1 回だけレンダリングされる問題を修正しました。
  • 修正: タイプがページの場合に内部 dep をスキップし、https://github.com/alibaba/lowcode-engine/pull/2050 の @LeoYuan による #2049 を閉じます
  • 修正: https://github.com/alibaba/lowcode-engine/pull/2053 で @LeoYuan によるコード生成のための Fusion-UI スタイルを追加
  • https://github.com/alibaba/lowcode-engine/pull/2054 の @LgnMs により、node-children.md を更新します
  • 偉業: Canvas.activeTracker.target は、https://github.com/alibaba/lowcode-engine/pull/2046 の @liujuping によって追加 null を返します
  • 功績: ワークスペース ウィンドウのアドオンSave api by @liujuping in https://github.com/alibaba/lowcode-engine/pull/2055
  • fix(setters): getSettersMap 関数のこのバインド エラー (https://github.com/alibaba/lowcode-engine/pull/2060 の @Justin-lu による)
  • 功績: https://github.com/alibaba/lowcode-engine/pull/2064 の @liujuping により、アウトライン ペインでモーダルの表示状態を更新
  • ドキュメント: 追加图编排扩展使用说明 by @lukeup (https://github.com/alibaba/lowcode-engine/pull/2082)
  • 修正: npm 情報のない comp は、https://github.com/alibaba/lowcode-engine/pull/2087 の @LeoYuan により lowCode comp と見なされるべきです
  • 修正: supportVariable は supportVariableGlobally よりも優先されるべきです (https://github.com/alibaba/lowcode-engine/pull/1997 の @LeoYuan による)
  • feat(ts ファイル形式): 出力生成的 *.ts 和 *.tsx 文件使用 babel 格式化 by @ChiZng in https://github.com/alibaba/lowcode-engine/pull/2088
