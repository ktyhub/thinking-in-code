dubbo-go v3.3.1

パッチ 公開日2025年12月27日 出典apache/dubbo-go 英語原文

#ダボ号v3.3.1

3.3.1

概要

このリリースでは、Triple プロトコルの大幅な機能強化、構成およびレジストリ センター (Nacos、Apollo、Zookeeper) の改善、および安定性とパフォーマンスを向上させるためのコア モジュールの広範なリファクタリングが導入されています。このバージョンでは、Go 1.24 への互換性も更新されます。

新機能

  • サポート グループとバージョンのワイルドカードを使用して、インターフェイスを正確に一致させます。 #3080
  • サポート サービス メタデータへの dubbo.tag の挿入。 #3069
  • 公開 ルーター関連の API。 #3066
  • 更新 Go バージョンのサポートを Go 1.24 に変更し、非推奨の rand.seed の使用を削除します。 #3046
  • インポート フォーマッタ ツールを導入し、CI チェックに統合します。 #3019
  • 構成のホットリロード機能を追加します。 #2992
  • サポート HTTP/2 サーバーと HTTP/3 サーバーの同時実行。 #2972
  • 追加 client 初期化用の WithInterface オプション。 #2946
  • **トリプル サービスの OpenAPI ドキュメントを生成するためのツール サポートを追加します。 #2951
  • **実験的な HTTP/3 サポートをトリプル プロトコルに追加します。 #2916
  • TLS API を再設計し、トリプル プロトコル用の新しい TLS 構成を追加します。 #2852 #2891
  • サポート 新しいトリプル実装での非 IDL モード。 #2858
  • 構成センターとしての Apollo のサポートを追加。 #2857
  • サポート ストリームからのヘシアンのデコードにより、大規模なパケット送信のパフォーマンスが向上します。 #2841
  • 新しいトリプル プロトコルの汎用呼び出しサポートを追加します。 #2818

バグ修正

  • 修正 シャットダウン中の Nacos 登録解除エラー。 #3108
  • Java プロバイダーからメタデータを取得する際のパニックを防止します。 #3092
  • タグルーターでアプリケーションパラメータが空の場合、ログレベルをエラーから警告に調整します。 #3035
  • 修正 複数のモジュールでの nil ポインター逆参照。 #3071
  • 解決 SetParams メソッドでの URL パラメーターの損失。 #3022
  • クラスター拡張機能の作成失敗をパニックに陥らずに処理**します。 #3021 #3064
  • ファイルの損失を防ぐために、間違ったログ ローテーション パスを 修正 します。 #3014
  • エラー時のカウンター減分ロジックを修正。 #3013
  • 修正 meta-v エラーと空のリモート ストレージ パラメータによって引き起こされるメタデータ取得エラー。 #2952 #2953
  • 修正 dubbo.Load() でのプロバイダー設定の読み込み。 #2941
  • 修正 トリプル プロトコルでサーバーから client に添付ファイルを渡す問題。 #2928 #2854
  • 修正 Nacos ウェイト設定が有効にならない。 #2937
  • Zookeeper client ノードの認識における遅延を削減します。 #2930
  • 修正 通信層の読み取りプレフィックス EOF エラー。 #2912
  • 修正 Nacos インスタンスの上書き問題。 #2882
  • 論理無限ループの問題を解決します。 #2879
  • 修正 新しく登録されたサービスが検出されない Nacos サブスクリプションの問題。 #2859
  • 修正 Nacos ウェイト オプション設定ロジック。 #2843
  • marshalRequest でのエラー伝播を修正。 #2817
  • 修正 トリプル ストリーミング コールでのコンテキスト アタッチメント エラー処理。 #2810

コードの機能強化

  • リファクタリング: 構成の分離。 レジストリ、フィルター、および TLS モジュールにわたる循環依存関係を解決するために、config パッケージから依存関係を分離しました。
  • 正規表現パターンをプリコンパイルすることでパフォーマンスを最適化します。 #3067
  • 改善 lastUpdate フィールドを状態ストレージに追加することにより、加重ラウンドロビンを改善します。 #3053
  • 修正 トリプル コード生成における複数のパッケージのインポート。 #3052
  • ゴルーチン管理、ファイル ハンドル、拡張機能キャッシュに関連するメモリ リークに対処します。 #3023
  • ロガー モジュールをリファクタリングし、包括的な単体テストを追加します。 #2838 #2993
  • Makefile を書き換えて、ビルドの一貫性と開発者のエクスペリエンスを向上させます。 #2975
  • errgroup を使用して、正常なシャットダウン中のエラー処理を改善します。 #2973
  • 廃止された CAS 操作を CompareAndSwap に置き換えます。 #2962
  • **構成エラーに対するトリプル openServer エラー処理を強化します。 #2945
  • **トリプル プロトコルでの正常なシャットダウンのためのタイムアウト制御を追加します。 #2943
  • Go 1.18+ との互換性を確保するために、コードベース全体で interface{} を any に**移行します。 #2848

可観測性

  • サービス登録ライフサイクルのログを追加**します。 #3043
  • トレース スコープ名を OpenTelemetry 仕様に合わせます。 #3041
  • **Insecure オプションをトレース構成に追加します。 #3028
  • アップグレード OpenTelemetry の依存関係を v1.21.0 にします。 #2971

ドキュメントと CI

  • **make check-fmt コマンドを CI パイプラインに追加します。 #3055
  • README の連絡先情報を更新し、README_CN の無効なリンクを修正します。 #3020
  • 統合 は、フォーマッタとライセンス ヘッダー チェックを CI にインポートします。 #2961 #2957
  • 解決 さまざまな SonarQube/SonarCloud の誤検知と AI ボットの警告。 #2902
