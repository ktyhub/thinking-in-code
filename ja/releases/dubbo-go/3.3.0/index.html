dubbo-go v3.3.0

マイナー 公開日2025年3月22日 出典apache/dubbo-go 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#ダボ号v3.3.0

概要

このリリースでは、Apache Dubbo-Go の安定性と機能性を向上させるために、複数のバグ修正、新機能、コード拡張が導入されています。主な改善点には、サービス検出やレジストリ関連のさまざまな問題の解決、メモリ リークへの対処、基盤となる通信ライブラリのエラー処理と安定性の強化などが含まれます。さらに、スクリプトベースのルーティング、Java 互換性の向上、トリプル プロトコル キープアライブ、Protobuf ベースの MetadataService のサポートなどの新機能が実装されました。

バグ修正

  • 正しい OTEL-GRPC エクスポーターの初期化が解決されました。 #2666 #2679
  • テスト ケースの不一致を解決しました。 #2660
  • makezero のバグを解決しました。 #2682
  • nacos サービス検出の問題を解決しました。 #2691 #2694
  • protoc-gen-go-triple パスを修正しました。 #2690
  • nil BackupCodec によるセグメンテーション違反を解決しました。 #2698
  • zookeeper マッピング キーの問題を解決しました。 #2711
  • nacos レジストリ '*' サブスクリプションに関する問題を解決しました。 #2713
  • nacos サービス検出ですべてのサービス名が取得されない問題を解決しました。 #2715
  • 潜在的なデッドロックのシナリオを解決しました。 #2716
  • サービスの切断と構成の無効化の問題が解決されました。 #2717
  • codeUnimplemented を使用してトリプル ハンドラーのエラー処理を実装しました。 #2719
  • ルーター ルールの解析ログ エラーが解決されました。 #2720
  • Baseinvoker の URL を nil に設定することでメモリ リークの問題を解決しました。 #2726
  • 不正な CallClientStream 結果処理を解決しました。 #2732
  • スライスの初期化の長さの問題を解決しました。 #2734
  • ファイル名、関数名、行番号のログ記録が改善されました。 #2744
  • HTTP プロキシリクエストにおける自動キャメルケース変換を解決しました。 #2746
  • golangci-lint によって報告された問題を解決しました。 #2754
  • dubbo_registry_directory の誤ったメトリック タイプを解決しました。 #2766
  • findMappedServices のパニックを解決しました。 #2768
  • CacheListener でのスレッドセーフな ListenerSet の使用を保証しました。 #2769
  • 登録の完了またはタイムアウトを待機するサブスクリプションの動作が改善されました。 #2775
  • rc.id が常に nil になる問題を解決しました。 #2778
  • 同じ住所が異なるレジストリ センターを区別できない問題が解決されました。 #2784
  • 不要な setdeadline の使用を削除しました。 #2785
  • さまざまな問題のあるエラーリターンを解決しました。 #2791
  • 追加のメモリ リークの問題を解決しました。 #2792
  • いくつかの不正確なコメントを解決しました。 #2793
  • ReadMessage() でのデータ競合を修正しました。 getty#123
  • スライスのインターセプトによって引き起こされるメモリ リークの問題を修正しました。 #hessian2/374
  • URL 解析パニックを解決し、ZooKeeper の dubbogo-cli でのエラー処理を改善しました。 2795

新機能

  • スクリプトベースのルーティング機能を追加しました。 #2669
  • 複数の宛先を持つ条件付きルーティングのサポートが導入されました。 #2685
  • 新しい条件付きルールを実装しました。 #2686
  • Java の相互運用性が強化されました。 #2687
  • Protobuf ベースの MetadataService サポートを追加しました。 #2723
  • トリプルプロトコルのキープアライブ設定を導入しました。 #2757
  • マルチカテゴリのサブスクリプションのサポートにより nacos レジストリが強化されました。 #2783
  • トリプルプロトコルキープアライブ設定を追加しました。 #トリプル87
  • トリプルプロトコル接続プールを追加しました。 #トリプル91

コードの機能強化

  • メタデータの単体テストを追加しました。 #2665
  • コードのコメントを改善しました。 #2668
  • メソッドの名前が WithClientCheck から WithClientNoCheck に変更されました。 #2680
  • Nacos エンドポイント処理の最適化。 #2692
  • 上書きを防ぐために文字列値を使用するように UseAsMetaReport および UseAsConfigCenter を更新しました。 #2693
  • 条件ルールの並べ替えロジックを更新しました。 #2688
  • ビジネス エラーと RPC ワイヤ エラーを区別します。 #2712
  • Dubbo プロトコルのタイムアウト単位をミリ秒に標準化しました。 #2737
  • 内部を dubbo-go-sample リポジトリに移動します。 2794
  • 再接続の試行と期間が制限されています。 getty#117
