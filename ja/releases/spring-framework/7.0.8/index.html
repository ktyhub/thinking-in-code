spring-framework v7.0.8

パッチ 公開日2026年6月8日 出典spring-projects/spring-framework 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

スプリングフレームワーク v7.0.8

:警告: セキュリティ修正

このメンテナンス リリースでは、多数の CVE が修正されています。これについて詳しくは、「AI 時代の Spring とセキュリティ」 ブログ投稿をご覧ください。 16 個の CVE の完全なリストは次のとおりです。

  • CVE-2026-41838 「Spring Framework WebSocket モジュールの予測可能なセッション ID」
  • CVE-2026-41839 「WebFlux でのセッション固定による Spring Framework エスカレーション」
  • CVE-2026-41840 「Spring Framework WebFlux でのマルチパート リクエストによるサービス拒否」
  • CVE-2026-41841 「Spring MVC および WebFlux における静的リソース キャッシュを介した Spring Framework 情報開示」
  • CVE-2026-41842 「Spring Framework Spring MVC および WebFlux のバージョン管理されたリソースを介したサービス拒否」
  • CVE-2026-41843 「Spring MVC および WebFlux のバージョン管理された静的リソースを介した Spring Framework パス トラバーサル」
  • CVE-2026-41844 「Spring MVC および WebFlux での Spring Framework オープン リダイレクト」
  • CVE-2026-41845 「JavaScriptUtils を介した Spring Framework クロスサイト スクリプティング」
  • CVE-2026-41846 「Spring Framework JSP フォーム タグによるクロスサイト スクリプティング」
  • CVE-2026-41848 「Spring Framework AntPathMatcher によるサービス拒否」
  • CVE-2026-41850 「Spring Framework SpEL 式によるアルゴリズムによるサービス拒否」
  • CVE-2026-41851 「Spring Framework SpEL の無制限キャッシュによるサービス拒否」
  • CVE-2026-41852 「Spring Framework SpEL 式での任意のメソッド呼び出し」
  • CVE-2026-41853 「Spring MVC および WebFlux での Spring Framework マルチパート リクエストの密輸」
  • CVE-2026-41854 「Spring Framework UriComponentsBuilder を介したサーバー側のリクエスト フォージェリ」
  • CVE-2026-41855 「Spring Framework Jackson JMS コンバーターによる安全でない逆シリアル化」

:star: 新機能

  • CronTrigger の equals/hashCode 実装にゾーン ID を含める #36871
  • DefaultDeserializer #36833 から ClassLoader を公開します
  • DefaultPathContainer の SEPARATORS 静的フィールドに不変マップを使用する #36821
  • SpEL 式の評価中の操作の追跡 #36801
  • SpEL #36800 でゲッターの戻り値の型が void でないことを確認します。
  • AntPathMatcher #36799 での文字アクセス試行が多すぎることを避ける
  • デフォルトのビュー名解決を調整 #36793
  • リファインジャクソン JMS コンバータ #36791
  • RfcUriParser の ABNF ルール チェックを改善 #36787
  • SpringVersion.getVersion() を「major.minor.patch」形式に制限する #36785
  • JPA 4.0 M4 および対応する Hibernate 8.0 スナップショットとのランタイム互換性 #36784
  • ExchangeFilterFunctions#basicAuthentication で使用する文字セットを指定できるようにしました #36777
  • CollectionUtils を使用して DefaultUriBuilderFactory で HashMap を初期化する #36763
  • SpEL のエラー メッセージを改善 #36756
  • SpEL のパターン キャッシュを改善 #36755
  • 暗黙的なキャッシュクリーンアップのための ResolvableType#forType 競合を回避する #36745
  • WebSocket セッションの JdkIdGenerator への切り替え #36740
  • AbstractValueAdaptingCache #36727 でカスタム逆シリアル化された NullValue インスタンスを検出します。
  • LiteWebJarsResourceResolver がディレクトリを解決しない #36726
  • MVC および WebFlux における安全でない静的リソースの場所に対する警告 #36692
  • Xerces #36682 の代替として Woodstox との一貫した互換性
  • SockJS セッションのプリンシパル チェックを改善 #36681
  • STOMP リレー CONNECT フレームにホスト ヘッダーを一貫して設定する #36673
  • Kotlin Flow でマイクロメーター コンテキストの伝播をサポート #36667
  • UserDestinationMessageHandler でのブロードキャスト メッセージの信頼性の高い検出 #36662

:lady_beetle: バグ修正

  • CookieLocaleResolver#setLocaleContext の共有 Cookie フィールドに対する同時実行の問題 #36869
  • サーバー送信イベントは複数行のコメントをサポートしていません #36866
  • CronExpression は真夜中の DST ギャップの日をスキップします #36865
  • 6.2.0+ のリグレッション: 同じクラスが XML 経由で別の名前でも登録されている場合、ConfigurationClassParser はコンポーネントでスキャンされた Bean を誤って削除します #36835
  • awaitEntity() でジェネリック型情報を保持する #36834
  • Bean バックグラウンド ブートストラップと遅延初期化 #36844
  • OracleAQ での DefaultMessageListenerContainer のバックオフが変更され、SpringBoot 4 では非常に短くなりました #36809
  • Content Disposition で許可された範囲外の文字 #36805
  • JSPタグ処理を修正 #36797
  • スクリプト処理機能を修正 #36795
  • Jaxb2XmlEncoder の排他性により、JacksonXmlEncoder の使用が妨げられ、POJO シリアル化が妨げられます #36776
  • JacksonXmlEncoder.canEncode が application/xml の文字列本体に対して誤って true を返す #36775
  • PropertyAccessorUtils #36765 でマップ キーの引用符を一貫して公開します
  • RFC URI パーサーにおける相対 URI のフラグメント解析を修正 #36762
  • InMemoryWebSessionStore の競合状態を修正 #36742
  • 引用符で囲まれたパラメーター値を含む MIME タイプの解析エラー #36730
  • サプライヤーが作成した Bean 間の循環依存関係は起動時に暗黙的に無視されます #36725
  • DataBufferUtils で結合された DataBuffer のデータが失われる #36714
  • CachingResourceResolver でのキャッシュ衝突 #36713
  • バージョン管理されたリソースを解決するときに予期しないパス要素が削除される #36698
  • org.springframework.http.codec.multipart.PartGenerator での非決定的な「ボディ トークンが予期されません」#36694
  • 値クラスのパラメータ処理に関する回帰 #36665
  • バイナリ メッセージ送信時の JettyWebSocketSession のブール型最後のフラグの反転ロジックを修正 #36650
  • WebClient.awaitExchange 関数を呼び出すときに親の TraceId が再利用されない #36182

:notebook_with_decorative_cover: ドキュメント

  • Selenium ドキュメントへの壊れたリンクを修正 #36875
  • setAutoGrowCollectionLimit の適用に関する注意事項を修正 #36863
  • ネストされた @Configuration クラスの @Conditional ゲートに関するドキュメント #36831
  • MethodParameter コンストラクターのnestingLevel パラメーターの Javadoc が実際の実装と矛盾しています #36826
  • ドキュメントの Web セクションにおけるデータ バインディング コンテンツの再構成 #36803
  • validateExistingTransaction #36767 のタイプミスを修正

:hammer: 依存関係のアップグレード

  • マイクロメーター 1.16.6 #36883 へのアップグレード
  • リアクター 2025.0.6 #36884 へのアップグレード
