スプリングフレームワーク v7.0.9

:警告: 注意が必要です

  • Spring Framework、7.0.9、ForwardedHeaderFilter (Spring MVC)、および ForwardedHeaderTransformer (WebFlux) では、それぞれ、標準の "Forwarded" ヘッダーを使用するか、または "X-Forwarded" 代替ヘッダーを使用するかどうかのブール型コンストラクター引数を提供します。別のプロパティで「X-Forwarded-Prefix」の使用をオンまたはオフにします。デフォルトのコンストラクターは既存の動作を保持しますが、処理をより確定的にし、プロキシから期待される内容と一致させるために、新しいコンストラクターを使用して、使用する転送ヘッダーを明示的に指定することをお勧めします。詳細については、更新された セキュリティに関する考慮事項 セクションを参照してください。 #37072 の 7.1 では、デフォルトのコンストラクターが非推奨となり、削除対象としてマークされています。 #37090
  • Spring Framework 7.0.9 では、SpelParserConfiguration、spring.expression.compiler.mode システム プロパティ、Spring プロパティで設定されたコンパイラ モードに関係なく、SimpleEvaluationContext はデフォルトで式のコンパイルをサポートしなくなりました。 trusted 式で SimpleEvaluationContext を意図的に使用し、パフォーマンス上の理由からコンパイルが必要なアプリケーションは、SimpleEvaluationContext ビルダーで withCompilationSupported() を呼び出すことでオプトインできます。コンパイルをオプトインする場合は、解釈された評価中に適用された安全保護が解除されるため、注意が必要です。 #37035

  • AbstractNestablePropertyAccessor での自動拡張後のリスト インデックスのチェック #37036
  • SimpleEvaluationContext で SpEL 式のコンパイルをデフォルトで無効にする #37035
  • SpEL での BigDecimal/BigInteger 電源操作の結果サイズの制限 #37034
  • UrlHandlerFilter のリダイレクト処理をリファクタリング #37030
  • XsltView でのスタイルシートのソース処理を修正 #37029
  • UrlFilenameViewController でのビュー名の処理を修正 #37027
  • DispatcherHandler を使用せずに機能エンドポイント セットアップでプリフライト リクエストを処理する #37024
  • WebSocket ハンドシェイク エラーのログを改善 #37023
  • JdbcTemplate.batchUpdate で欠落している null 許容値を修正 #37012
  • RetryPolicy の Timeout プロパティにはデフォルトの定数がありません #36983

  • DefaultServerRequest.ServletParametersMap.entrySet() は HttpServletRequest.getParameterMap() の順序を保持しません #36966
  • SQLite の同期内でも nextKey を実行します #36959
  • DefaultDeserializer にカスタム ObjectInputFilter のサポートを追加 #36958
  • 共通ロケールのリソース バンドル キャッシュを修正 #36957
  • MockHttpServletRequest の getSession(*) の null 可能性を改善 #36926

  • プリフライトリクエストにおけるあいまいな一致チェックを改善 #36903
  • Groovy マークアップ テンプレートの読み込みを改善 #36902
  • Reactor Netty サーバーでのリクエスト パスの処理を改善 #36893
  • JettyWebSocketSession エラー処理を改善 #36891

  • MetadataReader が注釈 #37083 から byte[] 配列を読み取ることができません
  • ContentDisposition で解析/文字列の対称性を確保 #37064
  • Content Disposition で許可された範囲外の文字 #37062
  • Jackson BufferRecycler をエンコーダーのプールにリリース #37059
  • 一貫したエラー escaping #37055 を確認
  • テンプレート名の処理を改善 #37054
  • 不一致バイトの TwoByteMatcher 部分一致をリセット #37053
  • 非同期 XML 解析制限チェックをリファクタリング #37031
  • PartEventHttpMessageReader のパート制約チェックを修正 #37028
  • RSocket SETUP フレーム処理におけるバッファ リークを修正 #37026
  • Jetty コアの応答 Cookie が正しく処理されるようにする #37025
  • domainToAscii を現在の WhatWG 仕様 #37018 に合わせる
  • ButtonTag 値の属性処理の一貫性を確保 #37017
  • SpEL の InlineList はコンパイル モードで可変リストとしてキャッシュされます #37001
  • ラムダヒントのみが存在する場合にネイティブ構成ファイルを書き込む #36989
  • SpEL Indexer は無効なキャッシュされた PropertyAccessor #36986 を再利用します
  • SpEL は無効なキャッシュされた ConstructorExecutor #36985 を再利用します
  • MimeTypeUtils は、一部の無効な MIME タイプに対して StringIndexOutOfBoundsException を発生させます #36971
  • 複数行のコメント本文内の DOCTYPE を無視する #36948
  • ExponentialBackOff ジッターでのゼロ除算を回避する #36932
  • ConcurrentWebSocketSessionDecorator でのロックの使用またはクローズをリファクタリング #36909
  • StompRelayMessageBrokerHandler のホスト ヘッダーの初期化に重大な変更 #36907
  • SockJS セッション #36681 のリモート アドレス チェックにより、xhr ポーリングが中断される #36904
  • LifeCyclePrintWriter が正しく委任されない #36885
  • Hibernate 8.0.0-SNAPSHOT / JPA 4.0.0-M4 を使用して共有 EntityManager 経由で名前付きネイティブ クエリを作成すると IllegalArgumentException が発生する #36878
