spring-framework v7.0.10

パッチ 公開日2026年10月22日 出典spring-projects/spring-framework 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

スプリングフレームワーク v7.0.10

:star: 新機能

  • DelegatingMessageSource フォールバック実装を AbstractMessageSource #37383 と調整します。
  • HttpEntity(T, MultiValueMap) は HttpHeaders をチェックなしで保存するため、RestTemplate 内に IncompatibleClassChangeError が発生します #37358
  • ProxyProcessorSupport で再配置された Mockito MockAccess インターフェースを認識 #37342
  • JPA 4.0 M7 および対応する Hibernate 8.0 スナップショットとのランタイム互換性 #37315
  • 一時停止していない関数の MethodParameter での Kotlin リフレクションを回避する #37300
  • SimplePropertyRowMapper のアンダースコア命名フォールバックを修正 #37297
  • ConcurrentLruCache.clear() #37292 での無駄なキュー操作を回避します。
  • PathMatchingResourcePatternResolver は、パスに % #37280 が含まれる java.class.path 上の jar を見逃します。
  • 例外メッセージ内の冗長な空白を削除 #37277
  • OpenInView は HibernateTransactionManager では動作しなくなりました #37273
  • LazyConnectionDataSourceProxy で setClientInfo/setNetworkTimeout を遅延処理する #37261
  • FilteredMap.size() での冗長なフィルタリングを回避する #37256
  • toString() で合成されたアノテーションの NaN および無限浮動小数点値をサポート #37244
  • CompositeRetryListener では LinkedList の代わりに ArrayList を使用します #37231
  • MockMvcResultMatchers の redirectedUrl() 引数は @Nullable #37230 である必要があります
  • 公開された Gradle モジュール ファイルに javadocElements と sourcesElements がありません #37209
  • SpelParserConfiguration #37187 のビルダー紹介
  • Protobuf サポート クラスはすべて getMessageBuilder() を実装します #37147
  • ServerHttpRequest.Builder で null の contextPath を許可する #37099
  • ブローカーの可用性イベントを文字列メッセージとしてログに記録します #36856

:lady_beetle: バグ修正

  • タイプ別オートワイヤーのための不必要な依存 Bean 登録を回避する #37424
  • JdkClientHttpConnector のゼロ readTimeout を処理する #37412
  • PartGenerator.CreateFileState の競合状態により、完了シグナルが失われる可能性があります #37409
  • 遅いシャットダウンで一時停止されたエグゼキュータは、閉じた後にそのワーカー スレッド (および閉じられたコンテキスト) をリークします #37406
  • キャッシュを使用した Flux を返すメソッドのハング再試行を修正 #37403
  • AbstractIdentityColumnMaxValueIncrementer #37402 でリフィルが失敗した後に古い値を提供しないようにする
  • RenderingResponse.from() #37378 の Cookie をコピーします。
  • LinkedCaseInsensitiveMap.computeIfAbsent #37351 でのファントム キーの回避
  • TypeMappedAnnotation のプリミティブ配列型の単一値適応を修正 #37349
  • CssLinkResourceTransformer が無効な CSS リンクに対して失敗する #37336
  • MySQLMaxValueIncrementer でのコミット失敗後のキャッシュされた ID の再利用を修正 #37322
  • MySQLMaxValueIncrementer の接続リークを修正 #37321
  • @CacheEvict は、Flux の結果を最初の要素に切り詰めます #37309
  • ConcurrentLruCache.clear() は実行中に追加されたエントリを見逃す可能性があります #37287
  • パーツをディスクにスピルするときにディスク使用制限を強制する #37285
  • ConcurrentLruCache #37268 での 2 倍のサイズ減少を防止
  • Spring-core 7 が spring-jcl から commons-logging に切り替わって以来、LogAccessor.debug(CharSequence) は LogMessage を積極的にレンダリングします #37266
  • ファイル部分が最後でない場合、WebFlux は空のマルチパート ファイルを失います。 #37264
  • Mutiny リアクティブ アダプター #37259 からの完全な空の Uni インスタンス
  • DefaultAsyncServerResponse.writeAsync() は、以前に設定された AsyncWebRequest タイムアウトを破棄します #37257
  • プロキシされた Hibernate 8 クエリ タイプに欠落しているネイティブ イメージ ヒントを提供する #37251
  • SharedEntityManagerCreator によって作成された StatelessSession プロキシに欠落しているネイティブ イメージのヒントを提供します。 #37249
  • 休止状態の PersistenceUnitInfoDescriptor に欠落しているネイティブ イメージの反映ヒントを提供します。 #37247
  • SQLErrorCodes #37235 で重複するキーコードをソート
  • JdkClientHttpRequestFactory でゼロ readTimeout を処理する #37234
  • ReactorNettyTcpClient #37223 での再接続試行回数が間違っています
  • ストアド プロシージャの OUT パラメータ値は、7.0.9 #37221 以降、トランザクションの外で失われます。
  • MockMvc および FlashMap での有効期限計算における int オーバーフローを回避する #37208
  • ScheduledAnnotationBeanPostProcessor は Bean の破棄を正しくサポートしていません #37207
  • CallMetaDataContext #37206 での関数戻りパラメーター検索の正規化
  • 不透明なホストでの切り捨てられたパーセントエスケープの範囲外読み取りを修正 #37203
  • ロード時のウィービングで 2 つの永続ユニット間で ClassFileTransformerAdapter デッドロックが発生する #37199
  • AOP メソッドを一時停止するための Kotlin 値クラスの処理を修正しました #37191
  • NullAway 0.14.0 にアップデートし、新しい警告を修正 #37188
  • メディア タイプが ndjson #37158 の場合、ProtobufJsonEncoder は JSON 配列を出力します
  • ProtobufJsonEncoder のstreamingMediaTypes は encodableMimeTypes のサブセットではありません #37154
  • DataBufferUtils$WriteCompletionHandler 例外処理を read() 側と調整 #37145
  • JDK 25 で NettyDataBuffer を使用した DataBufferUtils.read() が無期限にハングする #37143
  • マルチパートキャンセル時にキューに入れられたボディトークンバッファを解放 #37115
  • 非同期 API バージョン リゾルバー順序を保持 #37096
  • ClientResponse.mutate() ビルダーは、originalResponse ヘッダーを変更できます。 #37086
  • カスタム理由が ResponseStatusException.updateAndGetBody() の i18n メッセージによって上書きされる #36984
  • 非有限浮動小数点値のコンパイル可能なコードを生成 #36965
  • ClassFileMethodMetadata のパラメーター タイプ名をレンダリングする #36919
  • AbstractXMLStreamReader#getTextCharacters #36914 の sourceStart オフセットを尊重します
  • 指定された各名前を予約するようにreserveMethodNamesを修正しました #36912
  • AbstractMockHttpServletRequestBuilder のスレッド安全でない SimpleDateFormat を DateTimeFormatter に置き換えます #36772
  • MockHttpServletRequest.isRequestedSessionIdValid() はサーブレット 6.1 Javadoc #36631 に従いません。
  • @HttpExchange から RequestMappingInfo へのマップ バージョン #36602
  • ConversionService.canConvert(Enum) が例外をスローしないようにしました #34532

:notebook_with_decorative_cover: ドキュメント

  • WebFlux および MVC ドキュメントの誤ったクラス名を修正 #37467
  • SourceHttpMessageConverter の XXE 脅威モデルを文書化 #37407
  • Eclipse IDE にプロジェクトをインポートするための手順を更新 #37397
  • リファレンスマニュアルの構文エラーを修正 #37392
  • Spring MVC テスト ドキュメントの Kotlin サンプルを修正 #37388
  • JSP <form:input> タグ内の type 属性の使用法を文書化 #37376
  • CONTRIBUTING.md を自己完結型にし、AGENTS.md #37372 を追加します
  • ConcurrentReferenceHashMap の参照セマンティクスを明確にする #37357
  • Javadoc に欠落している囲み一重引用符を追加 #37338
  • ドキュメントの MockMvc 非同期リクエストの例を修正 #37318
  • 例に閉じ中括弧を追加 #37305
  • Javadoc のタイプミスを修正 #37229
  • ドキュメントの Web セクションのデータ バインディング コンテンツのさらなる更新 #37228
  • WebFlux 構成リファレンス例に欠落していた閉じ括弧を追加 #37163
  • リファレンス ドキュメントのローカル リンクには xref: の代わりに <<id,text>> を使用します #37161
  • リファレンス ドキュメント内の壊れた内部外部参照リンクを修正 #37152
  • リファレンス マニュアルの Kotlin サンプルを修正 #37101
  • @Retryable とプロキシベースの機能を組み合わせたドキュメント #37005
  • Web データ バインディングの推奨事項を更新 #36789
