spring-framework v7.0.4

パッチ 公開日2026年2月12日 出典spring-projects/spring-framework 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

スプリングフレームワーク v7.0.4

:star: 新機能

  • MethodParameter および AnnotatedMethod のメソッド アノテーションをキャッシュする #36307
  • 任意の深さでメタアノテーションとして @Lazy を一貫してサポート #36306
  • 任意の深さでメタアノテーションとして @Validated を一貫してサポート #36305
  • 開発者が HttpMessageConverters でのデフォルトの登録を無効にできるようにします #36303
  • HandlerInterceptor が例外をスローしたログ #36281
  • リクエストマッピングのハッシュコード計算のパフォーマンスを改善 #36279
  • HandlerMethod Bean ルックアップのパフォーマンスを改善 #36278
  • バージョンマッピングのパフォーマンスを改善 #36276
  • 単一パターンのリクエストマッピングのパフォーマンスを改善 #36275
  • 検証グループ決定のパフォーマンスを改善 #36274
  • LocalEntityManagerFactoryBeanにsetPackagesToScanの設定方法を追加 #36270
  • 古い GraalVM 置換 #36257 を削除
  • RetryState 引数を使用した beforeRetry コールバックを導入 #36245
  • SqlParameter を遅延フェッチして NamedParameterUtils#buildValueArray を最適化 #36230
  • HTTP サービス プロキシの作成に使用される HttpServiceProxyFactory の ProxyFactory のカスタマイズを許可 #36225
  • FileCopyUtils の try-with-resources を通じて一貫してストリームを閉じる #36223
  • FileCopyUtils で Java ファイル ユーティリティを使用する #36221
  • SqlBinaryValue と SqlCharacterValue は、長さが不定の InputStream コンテンツをサポートする必要があります #36219
  • HibernateJpaVendorAdapter での JtaTransactionManager および SpringBeanContainer 構成のサポート #36216
  • 再試行可能なタスク用の TaskCallback/Callable/Runnable ラッパーを追加 #36208
  • YamlProcessor を改良して、さまざまな空の値を許可する #36207
  • Kotlin 2.3 コンパイル警告の修正を予定 #36203
  • YAML プロセッサーがヌルを含むフラット化されたマップを作成できるようにします #36197
  • FileCopyUtils で Reader.transferTo を使用する #36196
  • JDK 25 で NettyDataBuffer を備えた DataBufferUtils.write() が無期限にハングする #36184
  • SendToMethodReturnValueHandler と SubscriptionMethodReturnValueHandler をカスタマイズ可能にし、メッセージ ヘッダーのパススルーを許可します #36179
  • RestClient.ResponseSpec#requiredBody #36173のご紹介
  • BeanRegistry/BeanRegistrar でスコープを完全に構成可能にする #36171
  • ConcurrencyThrottleSupport とスレッド中断 #36167
  • 明示的な応答キューを使用するために、オーバーロードされた sendAndReceive メソッドを JmsTemplate に追加します #36162
  • Netty チャネルの WebClient (Reactor) 属性が接続解放後にクリアされない #36158
  • ContentRequestMatchers.multipartData で HttpEntity をサポート #36154
  • Spring Framework 6.2.x #36151 で WebLogicJtaTransactionManager を再導入
  • リスナーのセットアップが失敗した場合、DefaultMessageListenerContainer のバックオフが一貫して適用されません #36143
  • JPA 4.0 EntityAgent の早期サポート (共有プロキシの自動配線) #36025
  • JPA 4.0 および Hibernate ORM 8.0 #35705 との初期互換性

:lady_beetle: バグ修正

  • 解決された HttpEntity コントローラーの引数は、変更された HTTP ヘッダーを反映しません #36298
  • ConcurrentReferenceHashMap でのロックの輻輳を回避する #36293
  • AbstractMessageConverter は、サポートされている MIME タイプのワイルドカードをサポートしていません #36285
  • LocalEntityManagerFactoryBean#setDataSource を EclipseLink と同様に Hibernate で動作させる #36271
  • テストコンテキストの一時停止により、StompBrokerRelayMessageHandler が再起動に失敗する #36266
  • 起動時に System.exit を呼び出すとデッドロックが発生することがある (複数のシャットダウン フックに対して) #36260
  • ImportAware を実装する BeanRegistrar のリソース ヒントがありません #36242
  • アノテーション付きインターフェースでの @Retryable との一貫性のない動作 #36233
  • Netty4HeadersAdapter.remove は、存在しないキーに対して null ではなく空のリストを返します #36226
  • AsyncTaskExecutor.submit(Callable<T>) のジェネリック型は @Nullable #36191 である必要があります
  • EclipseLinkConnectionHandle はトランザクション分離競合状態で失敗する可能性があります #36165

:notebook_with_decorative_cover: ドキュメント

  • Redirecting to a resource セクションの古いコードを削除 #36284
  • Web MVC HTTP Message Conversion ドキュメントのフォーマットを修正 #36250
  • spring.context.annotated-bean-reader.create の廃止されたドキュメントを削除 #36241
  • リファレンス マニュアル #36240 の @SpringExtensionConfig について説明します。
  • STOMP 概要ドキュメントの JSON 構文を修正 #36229
  • リファレンス マニュアル #36222 の JSR-330 サポートに関するドキュメントを改訂
  • JUnit ユーザー ガイドへのリンクを修正 #36217
  • コルーチンの定義を修正 #36209
  • LocalContainerEntityManagerFactoryBean#setPersistenceUnitName javadoc #36205 を修正しました。
  • 型レベルの @GetMapping("/base") がメソッド レベルの @GetMapping("/") と組み合わされる末尾のスラッシュ処理に関するドキュメントを更新 #36198
  • 問題の詳細に使用される MediaType に関するドキュメントを更新 #36192
  • DispatcherServlet スニペットを抽出 #36175
  • 例の getErrors() を getBindingResult() に置き換えます #36170
  • 最新の変更に合わせて CORS ドキュメントを改良 #36156

:hammer: 依存関係のアップグレード

  • Apache POI 5.5 #36174 へのアップグレード
  • ASM 9.9.1 および Objenesis 3.5 #36243 へのアップグレード
  • マイクロメーター 1.6.3 #36287 へのアップグレード
  • リアクター 2025.0.3 #36288 へのアップグレード
