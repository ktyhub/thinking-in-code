spring-framework v7.1.0-M2

プレリリース 公開日2026年9月24日 出典spring-projects/spring-framework 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

スプリングフレームワーク v7.1.0-M2

:star: 新機能

  • DispatcherServlet Bean 検出ログの調整 #37296
  • Bean プロパティ パスのサポートを PropertyPath に抽出 #37275
  • 一致した PathPattern を MVC リクエスト属性として公開する #37272
  • プロパティ パスの最大ネスト深さの構成可能な制限を追加 #37252
  • 送信 SSE データ ペイロードに "data: " (スペースを含む) プレフィックスを強制する #37242
  • RFC 9651 のような日付ヘッダーを解析 #37224
  • ScheduledAnnotationBeanPostProcessor を改良して null 安全性を改良 #37219
  • JdbcClient にバッチ更新サポートを追加 #37216
  • PartGenerator で空のボディを持つマルチパート パーツを生成 #37202
  • HtmlUnit 5 #37194 へのアップグレード
  • 無効な SSE 再試行フィールドを無視する #37193
  • MIME タイプのパラメータ名を大文字と小文字を区別せずに処理する #37192
  • SpelParserConfiguration コンストラクターを非推奨にし、ビルダー API #37190 を優先します。
  • JSON の書き込み中に client への接続が失われた場合、警告として記録されないようにします #37151
  • JMS SimpleMessageConverter.fromMessage() は、@NullMarked パッケージ #37148 にもかかわらず、null を返すことができます
  • キャッシュされたアノテーション マッピングに対する不必要な割り当てを回避する #37141
  • MockCookie#parse(String) 検証を更新 #37136
  • WebFlux OpenTelemetry 観察規約を追加 #37131
  • PropertyEditorRegistrySupport の addStrippedPropertyPaths() #37020 でブラケットの深さを制限します
  • DataBinder #37019 におけるマップ作成の効率化
  • SimpleJdbcInsert で宣言および生成されたキー列の重複を拒否 #37014
  • 大文字と小文字が異なる場合のみ MIME タイプ パラメータを拒否する #37008
  • PropertyAccessorUtils #36999 で深さを考慮したブラケット解析を使用する
  • SpEL で配列サイズをチェックするときにすべての配列オブジェクトを考慮する #36998
  • SpEL のデフォルトの自動拡張サイズを Spring データ バインディングに合わせます #36995
  • DefaultFormattingConversionService での Date/Calendar/Long コンバーターの重複登録を避ける #36951
  • ライフサイクル コールバックの CGLIB 検証警告を抑制 #36935
  • Cache-Control を理解する必要があるディレクティブを追加 #36918
  • ResponseCookie の Samesite 属性を検証します #36905
  • テストコンテキストキャッシュをクリアするときにコンテキストを閉じる #36825
  • TypeDescriptor の静的キャッシュに不変マップを使用する #36813
  • SpEL 式に構造的なネストの深さの構成可能な制限を追加 #36723
  • タイムゾーンを使用した cron タスクのプログラムによるスケジューリングを簡素化 #36556
  • Derby サポートの廃止 #36045
  • 機能にリンクされたリソース生成のサポートを追加 #35862
  • RFC 10008 (QUERY HTTP メソッド) サポートを追加 #34993

:lady_beetle: バグ修正

  • PartGenerator.switchToFile() は maxDiskUsagePerPart に向けてバッファリングされたバイトをカウントしません #37238
  • Property で「set」で始まらない書き込みメソッドを拒否する #37139
  • MergedAnnotations では、属性を含むメタアノテーションが依然として不必要に合成されます #37135
  • SpEL の ReflectivePropertyAccessor #37123 で 4 引数の Property コンストラクターを使用します。
  • AOP プロキシを尊重するように BeanFactory.getBean(String, ParameterizedTypeReference) を修正 #37047
  • OptionalToObjectConverter 適用性チェックを修正 #36913
  • レコード スタイル アクセサーの Property 名前解決を修正 #36911

:notebook_with_decorative_cover: ドキュメント

  • ドキュメント内の RestClient API の使用法を修正 #37137
  • 検証セクションの例を追加 #36190

:hammer: 依存関係のアップグレード

  • Kotlin 2.4.20 #37271 へのアップグレード
  • マイクロメーター 1.18.0-M2 およびトレース 1.8.0-M2 #37288 へのアップグレード
  • リアクター 2026.0.0-M2 #37263 へのアップグレード
