spring-framework v7.1.0-RC1

マイナー 公開日2026年10月22日 出典spring-projects/spring-framework 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

スプリングフレームワーク v7.1.0-RC1

:警告: 注意が必要です

  • 7.1 #37455 で削除対象として非推奨としてマークされた API を削除します
  • WebTestClient で一貫して 0 をタイムアウトなしとして扱う #37454
  • MockMvc で 0 を一貫してタイムアウトなしとして扱う #37453
  • RSocketServiceProxyFactory で一貫して 0 をタイムアウトなしとして扱う #37451
  • HTTP client サポートで 0 を一貫してタイムアウトなしとして扱う #37425
  • Spring Boot および Tomcat に合わせて WebFlux マルチパート処理のデフォルト設定を更新 #36928
  • ReactorClientHttpConnector のデフォルト client にシステム プロパティを持つプロキシを適用 #36654
  • 現在の URL パスから設定された ProblemDetail インスタンス フィールドは、RFC #35969 を尊重しません。

:star: 新機能

  • テスト API での JSON 比較のための JSONassert の代替として JsonUnit をサポート #37490
  • onRetrySuccess および onRetryFailure に RetryState 対応オーバーロードを追加 #37465
  • AsyncServerResponse #37452 では、一貫して 0 をタイムアウトなしとして扱います。
  • 障害があっても CompositeFilter のすべてのフィルターを破壊します #37445
  • DataAccessUtils を改良して null 安全性を向上させました #37438
  • DefaultRetryPolicy.toString() #37437 内のゼロ timeout を省略します。
  • StringUtils.truncate() #37435 でのサロゲート ペアの分割を避ける
  • NumberUtils #37434 で正の 16 進数値をサポート
  • SpEL での非 String オペランドとの String 連結のコンパイルのサポート #37433
  • LinkedCaseInsensitiveMap の NULL 可能性を修正 #37432
  • JdkClientHttpRequest 内の jdk.httpclient.allowRestrictedHeaders の解析を JDK #37422 と調整します。
  • リアクティブ JdkClientHttpRequest の制限されたヘッダー処理を非リアクティブ JdkClientHttpRequest と調整します #37417
  • WebMvcConfigurer #37416 を介して問題の詳細レンダリングを構成します。
  • MergedAnnotationCollectors #37415 で欠落していた IDENTITY_FINISH 特性を修正
  • @AliasFor value および attribute が両方とも長さ #37413 の場合は拒否します。
  • 現在のリクエストへの ErrorResponse.Interceptor アクセス権を付与 #37410
  • CompositeMap #37401 の Map.equals() および Map.hashCode() 契約を尊重します
  • @ExceptionHandler メソッドでビューとして問題の詳細のレンダリングをサポート #37400
  • ExceptionHandler メソッドで処理されない例外を問題の詳細として表示する #37398
  • AnnotationAttributes.toString()#37396をさらに改良
  • AnnotationAttributes.toString() でのプリミティブ配列の処理を改善 #37395
  • AnnotatedMethod のオーバーライド チェックから静的メソッドを除外 #37390
  • MySQLMaxValueIncrementer がコミットに失敗した場合の根本原因を含める #37389
  • HTTP 5xx につながる MVC 例外を観測スタックのエラーとして記録する #37384
  • getBeanNamesForType キャッシュを改訂して、ResolvableType ベースのルックアップもカバーするようにしました #37382
  • Hibernate 8.0 の BeanContainer SPI リビジョン #37381 のサポート
  • 事前バインドされた JDBC 接続例外メッセージを改善 #37356
  • 拡張された @Configuration クラスで Kotlin コンストラクターのデフォルト値を拒否する #37350
  • シングルパスメモリ効率の高い解析のために CssLinkResourceTransformer を書き直す #37348
  • JdbcTemplate #37345 のマルチバッチ batchUpdate バリアントを廃止
  • JdbcClient バッチ更新用のエントリベースの DSL を導入 #37341
  • CompositeCollection #37332 での Collection.remove() 契約を尊重します
  • AnnotationsScanner のオーバーライド チェックから静的メソッドを除外 #37319
  • JPA 4.0 パッケージおよびモジュール記述子の検出のサポート #37316
  • 生成されたキーを使用してバッチを実行するときに、最初のバッチ引数を 1 回設定します #37308
  • BatchSpec を StatementSpec と一致させるように JdbcClient を改善 #37307
  • TypeNotPresentException プローブに enum 配列属性を含める #37153
  • 「Forwarded for」および「Forwarded by」ヘッダー情報を解析するときに、誤解を招くポート番号のデフォルトが表示される #37114
  • MatchableHandlerMapping を削除 #37093
  • ServletRequestHeadersAdapter および ServletResponseHeadersAdapter のすべての値の取得を最適化 #37080
  • RestClient.Builder.configureMessageConverters は、デフォルトのコンバーターの暗黙的な登録を無効にします。 #36747
  • ServletServerHttpRequest のcharacterEncoding に「Content-Type」をリクエストする更新を回避 #36426
  • 「Content-Type」ヘッダーから ServletResponse contentType プロパティとcharacterEncoding プロパティを設定するコードを削除 #36352

:lady_beetle: バグ修正

  • ClientHttpRequestFactory 実装での大きな Duration タイムアウトによる int オーバーフローを回避 #37427
  • アノテーションは、別のパッケージのスーパークラスの package-private メソッドから継承されます #37408
  • MVC MultipartParser にはクラスパス上に Publisher が必要です #37353
  • RepeatableContainers.standardRepeatables() のコンテナ検出を修正 #37326

:hammer: 依存関係のアップグレード

  • マイクロメーター 1.18.0-RC1 #37439 へのアップグレード
  • リアクター 2026.0.0-RC1 #37375 へのアップグレード
