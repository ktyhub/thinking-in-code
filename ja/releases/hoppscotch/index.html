hoppscotch

16 バージョンのインデックス付け · 2026年11月5日 上の最新の 2026.10.1

hoppscotch/hoppscotch ↗

202616

11/05
2026.10.1 パッチ MT

このリリースでは、デスクトップ エクスペリエンスとチャット ナビゲーションの改善に焦点を当てています。 Windows ユーザーのバンドル起点権限が改善され、チャット返信リンクがブラウザーで直接開くようになりました。

 10/30
2026.10.0 マイナー MT

このリリースは、安定性、セキュリティ、デスクトップ エクスペリエンスに重点を置いています。デスクトップ アプリはシステム trust ストアをサポートするようになり、オペレーティング システム (企業およびカスタム CA を含む) によって trusted された証明書が機能します。

 09/30
2026.9.0 マイナー MT

このリリースでは、ID およびアクセス管理、シングル サインオン、監査ログ、専用サポートを備えた新しい層である Enterprise Cloud と、編集および実行できるエンタープライズ セルフホスト用の AI アシスタントが導入されています。

 09/23
2026.8.2 パッチ MT

このパッチ リリースでは、バージョンが Hoppscotch Enterprise Edition と同期されます。これには、ユーザー グループ コンポーネントのページネーションと検索の修正が含まれています。 Community Edition では機能的な変更はありません。

 09/14
2026.8.1 パッチ MT

このパッチ リリースはエンタープライズ オファリングに限定されています

 08/28
2026.8.0 マイナー MT

このリリースでは、REST リクエストと GraphQL リクエストが 1 つのワークスペースにまとめられ、CSV または JSON データ ファイルを使用したデータ駆動型コレクションの実行が追加され、保存時のリクエスト ドキュメントの損失が修正され、セキュリティ パッチなども追加されています。

 07/30
2026.7.0 マイナー MT

このリリースでは、個人ワークスペースでのコレクション データの損失と、インポートされた大規模なチーム コレクションでのリクエストの損失に対処し、空の環境変数と構成可能な接続の初期値へのフォールバックを追加します。

 07/15
2026.6.1 パッチ MT

このパッチ リリースでは、セルフホスト型インスタンスにサインインするときのデスクトップ アプリのログイン ループを解決し、任意の非 root ユーザー ID でのコンテナ実行のサポートを追加し、エージェント ルーティングの応答 Cookie キャプチャを有効にします。

 06/30
2026.6.0 マイナー MT

クラウド製品には、個人用ワークスペースのコレクションが見つからないかアクセスできなくなるという既知の問題があり、クラウド Web 展開はロールバックされました。セルフホスト型の展開は影響を受けません。

 05/28
2026.5.0 マイナー MT

このリリースでは、セキュリティに加えて、OpenAPI 3.1 コレクションのエクスポート、デスクトップ アプリのズーム レベル コントロール、環境変数と管理ダッシュボードからの構成可能なプロキシ URL、モンゴル語の​​サポートが追加されています。

 05/14

 04/30
2026.4.0 マイナー MT

このリリースでは、コレクション レベルの事前リクエストおよびテスト スクリプト、手動更新制御を備えたデスクトップ設定、API ドキュメント エクスペリエンスの改良、SMTP OAuth2 などのセルフホスト型の改善が導入されています。

 04/10
2026.3.1 パッチ MT

This patch release, exclusive to the Enterprise offering, resolves an issue that prevented changes to settings from being saved in the admin dashboard.

 03/31
2026.3.0 マイナー MT

このリリースでは、Cloud for Organizations がデスクトップ アプリに導入され、管理ワークスペースの表示機能、英語以外のレイアウトのキーボード ショートカット サポート、およびオプションの SMTP 認証が追加され、セキュリティ パッチやバグも追加されています。

 03/05

 02/26
2026.2.0 マイナー MT

このリリースでは、API ドキュメントのバージョン管理、クラウド組織層向けの統合されたドロップダウン ベースのスイッチャー、およびスクリプト サンドボックスの信頼性の向上に加え、セキュリティ パッチ、バグ修正、機能強化が導入されています。
