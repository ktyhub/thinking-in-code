dubbo 3.3.4

パッチ 公開日2025年3月5日 出典apache/dubbo 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#ダボダボ-3.3.4

何が変わったのか

機能

  • Client は、https://github.com/apache/dubbo/pull/15029 の @funky-eyes によるパラメーターなしのサーバー ストリーミング エンドポイントへのリクエストをサポートします
  • https://github.com/apache/dubbo/pull/15032 の @finefuture によってポイントツーポイント ネットワーク インターフェイスを有効にするかどうかを決定する構成を追加します
  • https://github.com/apache/dubbo/pull/15049 の @AlbumenJ による権限を確認するための呼び出しでの SSLSession のパスをサポート
  • https://github.com/apache/dubbo/pull/15139 の @eye-gu によるネイティブ イメージ サポート汎用サービス

バグ修正

  • https://github.com/apache/dubbo/pull/14798 の @AlbumenJ による起動失敗の原因となる fastjson2 初期化エラーを修正
  • https://github.com/apache/dubbo/pull/14892 の @AlbumenJ による AbstractPortUnificationServer の初期化順序を修正
  • https://github.com/apache/dubbo/pull/15086 で @funky-eyes によって期限切れのメタデータ情報をクリーンアップするときに発生する可能性のある無限ループを修正
  • https://github.com/apache/dubbo/pull/15109 の @CrazyHZM による zookeeper リフレクション タイプ記述子のレジストラ パスを修正
  • https://github.com/apache/dubbo/pull/14986 の @songxiaosheng によるトレースで強力な深度マイクロメーターを削除
  • https://github.com/apache/dubbo/pull/15113 の @AlbumenJ でエクスポート後にサービス インスタンスを登録してみてください
  • https://github.com/apache/dubbo/pull/15126 の @zrlw によりサブスクリプションなしですべての nacos インスタンスを取得します
  • トリプル プロトコルの echoService 呼び出しを修正。 @wuwen5 著、https://github.com/apache/dubbo/pull/15127
  • https://github.com/apache/dubbo/pull/15141 の @zrlw で HttpServletRequest#getServerName を呼び出して権限を取得します
  • https://github.com/apache/dubbo/pull/15157 で @Stellar1999 によって NullPointerException が発生する gRPC 関連の URL オブジェクトを修正 ※https://github.com/apache/dubbo/pull/15006の@finefutureでメタデータキャッシュファイルのmd5を確認
  • Content-Type の文字セットが https://github.com/apache/dubbo/pull/15188 の @Stellar1999 によって正しく解析されない問題を修正

コードの拡張

関連する PR: #14800、#15058、#15064、#15017、#15065、#15082、#15122、#15125、#15135、#15163、#15164
