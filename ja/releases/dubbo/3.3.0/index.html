dubbo 3.3.0

マイナー 公開日2024年9月7日 出典apache/dubbo 英語原文

#ダボダボ-3.3.0

Apache Dubbo チームは、Dubbo 3.3 のリリースを発表できることを嬉しく思っています。 Dubbo は、主要なオープンソース マイクロサービス フレームワークとして、開発者に高性能、スケーラブル、柔軟な分散サービス ソリューションを提供し続けています。このリリースでは、強力な Triple X プロトコル、Native Image AOT のサポート、Project Loom との統合が導入され、クラウドネイティブ機能と高パフォーマンス シナリオがさらに最適化されます。

主な機能

1. トリプル X プロトコル

  • 包括的なトラフィック サポート: トリプル X は、南北 (client-server) と 東西 (サービス-サービス) の両方のトラフィックをシームレスに処理し、分散システム間の通信効率を向上させます。

  • gRPC 互換性: トリプル X は gRPC プロトコル標準に準拠し、通信に Protobuf を使用し、gRPC サービスとのスムーズな対話を可能にします。

  • HTTP 上に構築: トリプル X は HTTP/1、HTTP/2、HTTP/3 と連携して、最新の クラウドネイティブ インフラストラクチャのネットワーク通信を最適化し、ゲートウェイとサービス メッシュを強力にサポートします。

2. ネイティブ イメージ AOT サポート

  • 高速な起動と低いメモリ使用量: Dubbo 3.3 は ネイティブ イメージ AOT (Ahead-of-Time Compilation) サポートを導入し、開発者が Dubbo アプリケーションをネイティブ バイナリ ファイルにコンパイルできるようにします。これにより、起動時間とメモリ消費量が大幅に削減され、サーバーレス (AWS Lambda など) シナリオに最適です。

3. Project Loom の統合

  • 最適化された同時実行性: Dubbo 3.3 は Project Loom をサポートし、仮想スレッド を通じて同時実行性の高いシナリオでのスレッド管理を強化します。これにより、非同期プログラミング モデルが簡素化され、同時処理機能が強化され、同時実行性の高いマイクロサービスのパフォーマンスが向上します。

4. パフォーマンスの強化

  • 高同時実行性の最適化: トリプル X は、同時性が高く脆弱なネットワーク環境で顕著なパフォーマンスの向上を実現し、スループットと応答時間を向上させます。

  • ゼロ コピー テクノロジー: ゼロ コピーによりメモリと CPU の消費が削減され、高負荷環境での効率が向上します。

5. クラウドネイティブで使いやすい

  • HTTP/3 とクラウドの統合: トリプル X は、特にネットワークが弱い状況での通信を強化するために HTTP/3 をサポートし、クラウドネイティブのサービス検出およびルーティング インフラストラクチャとシームレスに統合します。

6. Spring Web からのスムーズな移行

  • 最小限のコード変更: 開発者は最小限のコード変更で既存の Spring Web プロジェクトからトリプル X に移行でき、Spring MVC との互換性を維持しながらパフォーマンスを向上させることができます。

アップグレード ガイド

Triple X、Native Image AOT、Project Loom などの Dubbo 3.3 の新機能を最大限に活用するには、Dubbo アプリケーションをアップグレードすることをお勧めします。

Dubbo 3.3 を使用して、新機能を探索し、起動速度、メモリ効率、同時実行パフォーマンスの向上を体験してください。
