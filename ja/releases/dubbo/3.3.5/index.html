dubbo 3.3.5

パッチ 公開日2025年5月29日 出典apache/dubbo 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#ダボダボ-3.3.5

何が変わったのか

機能

  • https://github.com/apache/dubbo/pull/15220 の @heliang666s による自動構成仮想スレッド プール
  • [3.3] https://github.com/apache/dubbo/pull/15239 の @zrlw によってバインドする前にサーバー ソケットの再利用アドレス オプションを有効にする
  • https://github.com/apache/dubbo/pull/15387 の @oxsean によるサーバー送信イベントのサポートを強化

バグ修正

  • [3.3] https://github.com/apache/dubbo/pull/15202 の @zrlw によって NamedThreadFactory から mGroup が削除されました
  • https://github.com/apache/dubbo/pull/15210 の @finefuture による ThreadlessExecutor の同時実行の問題を修正
  • https://github.com/apache/dubbo/pull/15221 で @Stellar1999 による registryFactory の繰り返しロードを修正
  • [3.3] https://github.com/apache/dubbo/pull/15209 の @zrlw による ClosedChannelException をキャッチしてプロバイダー サーバーへの接続を再試行します
  • https://github.com/apache/dubbo/pull/15257 の @songxiaosheng によるプロバイダーの荷物取得エラーを修正
  • [3.3] https://github.com/apache/dubbo/pull/15261 の @zrlw による ClassGeneratorTest の同時発生の問題を修正
  • https://github.com/apache/dubbo/pull/15115 の @CrazyHZM によるネイティブ イメージのトリプル プロトコルを修正
  • https://github.com/apache/dubbo/pull/15288 の @itait によるラッパー オブジェクト生成時の初期化問題 (#15276) を修正
  • 修正(MetricsEventBus): https://github.com/apache/dubbo/pull/15296 の @PengJingzhao によるいくつかのバグを修正
  • https://github.com/apache/dubbo/pull/15353 の @AlbumenJ によるデフォルトでのシリアル化トライ例外のサポート
  • https://github.com/apache/dubbo/pull/15060 の @AlbumenJ によるレジストリ通知で重複した呼び出し元を削除
  • https://github.com/apache/dubbo/pull/15262 の @songxiaosheng によるバイト エンコーダー キャスト例外を修正
  • Spring WebFlux との Dubbo トレース統合における広範すぎる型チェックによって引き起こされる ClassCastException を修正。 @heliang666s 著、https://github.com/apache/dubbo/pull/15371

コードの拡張

関連する PR: #15136、#15203、#15208、#15205、#15222、#15231、#15241、#15272、#15236、#15327、#15264、#15325、#15307、#15324、#15289、 #15258、#15338、#15378、#15379、#15384、#15394
