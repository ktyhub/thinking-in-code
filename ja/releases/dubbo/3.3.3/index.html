dubbo 3.3.3

パッチ 公開日2025年1月5日 出典apache/dubbo 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#ダボダボ-3.3.3

何が変わったのか

注目すべき

  • Dubbo は dubbo-dependency-zookeeper-curator5 と dubbo-zookeeper-spring-boot-starter の依存関係を削除しました。zk の依存関係は dubpo-zookeeper-curator5-spring-boot-starter でのみ提供されます。したがって、dubpo-zookeeper-curator5-spring-boot-starter を使用して、前の 2 つの依存関係を置き換えることができます。

機能

  • https://github.com/apache/dubbo/pull/14843 の @oxsean によるローカル変数テーブルからのパラメータ名の読み取りをサポート
  • proto ファイルからのカスタム REST パスの解析と @Ma… の生成をサポート (https://github.com/apache/dubbo/pull/14796 の @heliang666s による)
  • https://github.com/apache/dubbo/pull/14390 の @finefuture によるトリプルの WebSocket
  • https://github.com/apache/dubbo/pull/14903 の @aofall によるキュレーター セッション タイムアウトの設定をサポート
  • Triple Rest Openapi https://github.com/apache/dubbo/pull/14924 の @oxsean によるサポート

バグ修正

  • https://github.com/apache/dubbo/pull/14849 の @chickenlj によるアプリケーション サービス検出の優先プロトコル サポートを修正
  • https://github.com/apache/dubbo/pull/14851 の @chickenlj によるサービス検出 MappingListener の初期マッピング アプリを更新
  • https://github.com/apache/dubbo/pull/14873 の @oxsean によって欠落していたアノテーション構成プロセッサーの依存関係を修正
  • https://github.com/apache/dubbo/pull/14917 の @oxsean による onNext のデッド ループを修正
  • https://github.com/apache/dubbo/pull/14901 で @oxsean によって失敗した http3 ネゴシエーションを修正
  • https://github.com/apache/dubbo/pull/14905 の @aruato によりサービス名マッピング パラメータを正しく検証します
  • https://github.com/apache/dubbo/pull/14936 で @oxsean によって初期化されていない場合の DefaultRequestMappingRegistry.exists NPE を修正
  • https://github.com/apache/dubbo/pull/14955 の @oxsean による HTTP3 バグ修正
  • 最適化: https://github.com/apache/dubbo/pull/15019 の @funky-eyes による http1 自動キープアライブ設定をサポート
  • 特技: サーバー ストリームは、https://github.com/apache/dubbo/pull/15026 の @funky-eyes によるパラメーターなしのリクエストをサポートします
