#シェンユウv2.6.0

2.6.0

新機能

  1. shenyu-admin による prometheus メトリクスの公開をサポート
  2. shenyu レベル 1 キャッシュとレベル 2 キャッシュを追加
  3. 拡張プラグイン jar を Shenyu 管理者に保存します
  4. ゲートウェイで shenyu アップロード プラグインのホット ロードをサポート
  5. apollo同期データとレジスタデータをサポート
  6. client情報収集の初期化
  7. Shenyu client で spring-boot-client 自動設定をサポート
  8. TCPプラグインを追加する
  9. スーパー管理者がパスワード変更を強制する
  10. Spring-mvc(boot) client サポート収集 api-meta
  11. zookeeper 検出同期を追加する
  12. Shenyu イングレス コントローラーを初期化します。
  13. ディスカバリーアップストリームとプロキシセレクタープロキシを追加します。
  14. Shenyu アクチュエーター エンドポイントを公開する
  15. naocs 検出同期を追加する
  16. apollo Discovery 同期の追加
  17. HttpLongPolling 検出同期を追加する
  18. 領事発見同期を追加
  19. huawei Cloud lts ログプラグインを追加します
  20. shenyu管理者向けのopenGaussデータベースのサポート
  21. Polaris config sync と register center をサポート

  17. shenyu-admin サービスのテスト ケースを追加
  18. ドキュメント json データを api ドキュメントに追加します

  32. zookeeper client を更新し、アクティブなオフラインのリポジトリを登録します
  33. apollo client 登録リポジトリをオフラインで更新します
  34. Swagger タイプ API ドキュメントのストレージ調整、ローカル キャッシュからデータベースへの変更
  35. nacos client オフラインをサポート
