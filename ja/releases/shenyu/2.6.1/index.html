shenyu v2.6.1

パッチ 公開日2024年1月17日 出典apache/shenyu 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#シェンユウv2.6.1

2.6.1

新機能

  1. Shenyu Ingress コントローラーの dubbo アノテーション分析を追加
  2. プラグインのライフサイクルのサポート
  3. openFeign による shenyu-sdk-client をサポート
  4. Motan プラグインと Spring Cloud を shenyu ingress-controller に追加する
  5. サポートアラート通知
  6. Shenyu client 検出登録センターを追加
  7. Shenyu コンテキストパス プラグイン Ingress コントローラーを追加します
  8. Shenyu grpc プラグインイングレスコントローラーを追加
  9. Shenyuソファイングレスコントローラーを追加
  10. nacos、etcd、eureka を検出サービスとして追加します
  11. 新しいプラグインを追加します:basic-auth
  12. shenyulogging-rabbitmqプラグインを追加
  13. shenyu-discovery によるバインディングセレクター

API の変更点

  1. shenyu同期データのデータ構造をリファクタリングする

    plugin.list ["plugin.sign", "plugin.dubbo", "plugin.pluginName"]
-> plugin.sign
-> plugin.dubbo
-> plugin.pluginName

examples data:
selector.key1.list ["selector.key1.value1", "selector.key1.value2", "selector.key1.value3"]
-> selector.key1.value1
-> selector.key1.value2
-> selector.key1.value3

selector.key2.list ["selector.key2.value1", "selector.key2.value2", "selector.key2.value3"]
-> selector.key2.value4
-> selector.key2.value5
-> selector.key2.value6

  2. NettyClient をデフォルトとしてサポート httpclient

  3. 管理データ同期をサポートするために管理リスナーをリファクタリングする

  4. brpc プラグイン、brpc サンプル、brpc 統合テストを含む brpc サポートを削除します。

  5. Java 17をサポートするためにApolloの依存関係を削除します(jarを自分で追加します)

  6. shenyuミドルウェアレジスタclientを削除します

機能強化

  1. shenyuモデルイベントのテストケースを追加
  2. セレクター イベント テスト ケースを追加する
  3. motan e2e テスト ケースを追加する 4.motanプロトコルをサポート
  4. Grpc e2e テスト ケースを追加する
  5. apache-rat-plugin を 0.15 にバンプします
  6. 一致条件で文字列 isBlank をサポート
  7. Clickhouse サポート ttl フィールド
  8. HttpUtils ログレベルのサポート
  9. Ingress Reconciler の単体テストを追加する
  10. パッキング配布時のチェックサムをサポート
  11. TCP プラグインにゼロコピーを実装する
  12. shenyu-client-springmvc はデフォルトの appName と contextPath をサポートします
  13. sdk-feign の例と統合テスト ケースを追加
  14. ElasticSearch カスタム インデックスのロギング サポート
  15. Shenyu ロードバランサーをサポートするために grpc プラグインを強化します
  16. http2 アップストリーム サーバーをサポート
  17. Dubbo プラグインのサポート Shenyu ロードバランサーを強化
  18. イングレスコントローラー統合 springCloud テストケースを追加
  19. WebSocket プラグインのプロキシ ping 構成を追加する
  20. Ingress-Controller統合WebSocketテストを追加
  21. RewritePlugin のサポート割合
  22. 管理者は、discovery config init Discovery-service を使用します。
  23. 分割プラグイン適応神宇発見
  24. アラート レポートのサポート設定管理クラスタ マルチ サーバー
  25. WebSocket プラグインは Shenyu Discovery を適応させます
  26. サービスインスタンスをディスカバリーに登録する
  27. 管理アダプター検出ローカルモード
  28. ShenYu sdk コアのテスト ケースを追加
  29. shenyu-discovery の単体テストを追加
  30. opengauss e2e テスト ケースを追加
  31. アップロードプラグインのjarサイズ制限を追加
  32. shenyu-client-spring-websocket の単体テストを追加 34.Shiro バージョンを安全なバージョン (1.18.0) にアップグレードします。
  33. ライセンスの更新と springboot (2.7.17) のアップグレード
  34. ゲートウェイのグローバルエラーが発生したときにアラームメッセージを送信する
  35. EurekaDiscoveryService単体テストの追加

リファクタリング

  1. 2.6.1バージョン(pom.xml)のリファクタリング
  2. computeIfAbsent による Map 操作の簡素化
  3. Polaris テストケースをリファクタリングする
  4. Maven Wrapper を io.takari から正式リリースに移行する
  5. WebClientMessageWriter でコンパイルされたパターンを使用する
  6. HttpUtils リクエスト メソッドのリファクタリング
  7. github アクションのバージョンを更新します。
  8. リファクタリング同期データセンターの抽象テンプレート メソッド
  9. MenuProject、MenuModule、MenuDocItemをVOに更新します
  10. 統一ダボバージョン
  11. Httpclient のパッケージをリファクタリングする
  12. github ci アクション キャッシュのリファクタリング
  13. motan pojo を rpc メソッドのパラメータとしてリファクタリングする
  14. Kafka client バージョンを 3.4.0 にアップグレードする
  15. Admin Swagger を springfox から springdoc に移行する
  16. Dubbo バージョンを 3.2.5 にアップグレードし、いくつかのメソッドをリファクタリングする
  17. AbstractShenyuSdkClient getOrDefault メソッドをリファクタリングする
  18. http client プロパティをリファクタリングする
  19. webcliet プラグイン実装のリファクタリング
  20. com.google.guava:guava を 32.0.0-jre にアップグレードします
  21. e2e テストケース環境として k8s をサポート
  22. Restapi を REST api リクエスト マッピングとしてリファクタリングする
  23. StringBuilder を使用した文字列連結を推奨
  24. netty アロケーターを非プールに設定します
  25. スタートアップ バナーのリファクタリング
  26. 重複コードの削除と共通コードの抽出
  27. 標準化されたヌル検出コーディング
  28. ログプラグインセレクターハンドラーのリファクタリング
  29. プラグイン クラスローダーのリファクタリング
  30. プラグインレベルでsampleRateをサポートするためにログプラグインをリファクタリングする
  31. コンテキスト パスの繰り返しを避けるためにコンテキスト パス レジスタをリファクタリングします (更新には選択を使用します)。

バグ修正

  1. TimeoutException の作成による永続的なオーバーヘッドを回避する
  2. サンプルモジュールのメインクラスパスを修正
  3. プラグインのページソートバグを修正
  4. Makefile SNAPSHOT バージョンを更新する
  5. RELEASE-NOTES.md のタイプミスを修正
  6. shenyu-example のエラーパッケージ名を修正
  7. パスワードルールを修正し、特殊文字「#」と「.」を追加します。
  8. e2e での zookeeper:3.8.0 のヘルスチェックを修正 9.不安定なCIチェックを修正
  9. e2e WaitForHelper 例外ログを追加
  10. springcloud プラグインがスキームを取得できない問題を修正
  11. Javadoc ビルド エラーを修正する
  12. HttpUtils の間違ったリクエスト タイプを修正する
  13. 認証を更新すると userId が正常に更新できない問題を修正
  14. TCPプラグインのスレッドリークを修正
  15. shenyu-integrated-test/README の「クイック スタート」部分をフォーマットする
  16. SQLスクリプトエラーを修正
  17. Uri プラグインのパス エラーを修正し、パスを rawpath に変更します。
  18. WebSocket プラグインを修正してプラグインの書き換えをサポートする
  19. es-logging でインデックス名が機能しない問題を修正
  20. context-pathプラグインのエラーを修正
  21. shenyu-admin CPU サージを修正
  22. アラートの localDateTime 形式の問題を修正
  23. shenyu-client 永続 ApiDoc エラーの再試行
  24. applicationContextAware の初期化が遅すぎる問題を修正
  25. 重複した応答ヘッダーを修正
  26. k8s クラスターが起動するまでの最大待機時間を設定します。
  27. clickhouse ログ プラグインのステータス フィールドのタイプを修正
  28. 応答プラグインのメモリリークを修正
  29. dataType のコントラストエラーを修正
  30. httpデータ同期エラーを修正
  31. スペルミスを修正
  32. shenyu-dubbo レジスタのステータスを修正
  33. 複数の / を引き起こす buildDiscoveryUpstreamPath を修正
  34. EurekaInstanceRegisterRepository#persistInstance を通じて Eureka に登録するときのバグを修正
  35. AbstractLogPluginDataHandler ハッシュコード エラーを修正
  36. redis クラスター モードでの Ratelimit プラグイン キー エラーを修正
  37. マルチ Shenyu client レジスタのリピート コンテキスト パスを修正
  38. プラグインを閉じた後に shenyu が ext プラグインをロードできない問題を修正
  39. Shenyu管理者のプラグインjarアップロードのバグを修正
  40. プラグインがリソースパスファイルをロードできない問題を修正
  41. 辞書コードを表示するように管理スクリプトを修正
  42. サインプラグインの認可競合を修正
  43. 署名プラグインのコンテキストパス一致エラーを修正
