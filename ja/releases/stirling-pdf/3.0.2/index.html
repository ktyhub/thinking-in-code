Stirling-PDF v3.0.2

パッチ 公開日2026年10月1日 出典Stirling-Tools/Stirling-PDF 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

Stirling-PDF_0.33.1 Docker ハブを starlingtools v3.0.2 に移動

このリリースにはバグ修正とその他のさまざまな改善が含まれています 機能強化:

  • 選択的なページトリミングのサポートを追加
  • ユーザーの使用状況に基づいた、より適切なツールの推奨事項
  • ページの並べ替え中に視覚的なフィードバックを追加します

修正されたバグ:

  • 翻訳がありません
  • 特定の言語が正しく読み込まれない
  • アプリの特定のバージョンでプロセッサが正しくロードされない
  • 最新のファットにはファイルのアップロードの問題があります
  • ビューア/リーダーとしてのデフォルト モードが正しく動作しない

何が変わったのか

バグ修正

  • 修正: https://github.com/Stirling-Tools/Stirling-PDF/pull/6814 の @mvanhorn による設定検索結果の i18n テンプレート プレースホルダーを解決

機能強化

  • 型付きリンティングを再度有効にし、https://github.com/Stirling-Tools/Stirling-PDF/pull/8178 の @jbrunton96 による不要な型アサーションを禁止します
  • https://github.com/Stirling-Tools/Stirling-PDF/pull/8207 の @Frooodle によるローカル ツールの使用状況追跡を有効にする
  • https://github.com/Stirling-Tools/Stirling-PDF/pull/8180 の @jbrunton96 により JSX の最大深度に制限を追加
  • feat(crop): https://github.com/Stirling-Tools/Stirling-PDF/pull/7753 の @balazs-szucs による選択的なページのトリミングのサポートを追加
  • https://github.com/Stirling-Tools/Stirling-PDF/pull/6763 の @PeterDaveHello による zh-TW 繁体字中国語ロケールの更新
  • build(deps-dev): https://github.com/Stirling-Tools/Stirling-PDF/pull/7804 の @dependabot[bot] により /frontend で postcss-selector-parser を 7.1.4 から 7.1.6 にバンプします

  • デフォルトでサーバー ビルドにプロセッサを同梱し、https://github.com/Stirling-Tools/Stirling-PDF/pull/8280 の @Frooodle によって存在しない場合はそのリンクを非表示にします
  • https://github.com/Stirling-Tools/Stirling-PDF/pull/8127 の @Hariomlokhande-coder により、parsePageList で不正なページ トークンを一貫してスキップします
  • https://github.com/Stirling-Tools/Stirling-PDF/pull/8001 の @ConnorYoh によるクラウドとセルフホストの所有権の引き継ぎを調整します
  • https://github.com/Stirling-Tools/Stirling-PDF/pull/8276 の @Frooodle により、デフォルトで AI エンジンを有効にするファットイメージを停止
  • https://github.com/Stirling-Tools/Stirling-PDF/pull/8273 の @EthanHealy01 によって設定されたレガシー アイコンを削除します
  • https://github.com/Stirling-Tools/Stirling-PDF/pull/8293 の @Frooodle によって正規の sr-Latn-RS タグの下にセルビア語翻訳をロードします
  • https://github.com/Stirling-Tools/Stirling-PDF/pull/8288 の @Frooodle によるコンポーネント内のハードコードされた UI テキストの翻訳

  • ハードコードされたサービスとエラー メッセージを https://github.com/Stirling-Tools/Stirling-PDF/pull/8284 の @Frooodle によって翻訳
  • https://github.com/Stirling-Tools/Stirling-PDF/pull/8289 の @Frooodle による不安定な PDF エディター、ビューアー、設定の e2e テストを修正
  • https://github.com/Stirling-Tools/Stirling-PDF/pull/8309 の @reecebrowne によるスタートアップ ビューとデスクトップ セッションの復元を修正
