Stirling-PDF v3.3.0

マイナー 公開日2026年11月5日 出典Stirling-Tools/Stirling-PDF 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

Stirling-PDF_0.33.1 Docker ハブを starlingtools v3.3.0 に移動

Stirling Office Convert (まだベータ版) がアップグレードされました。また、電子メール、HTML、Markdown、電子書籍から PDF、PDF から HTML/Markdown/XML/EPUB/AZW3、PDF/A など、他の多くのツールのコンバーターとしても選択できるようになりました。既存のコンバータと比較してお知らせください。

私たちのロードマップは、来週 Office Convert をデフォルトでオンにし、変更が必要ない場合は翌週に LibreOffice とその他の依存関係を完全に削除することです。したがって、今がそれを試して、正しくないと思われる変換を報告 (そしてサンプル ファイルを送信) するのに最適な時期です。

その他の変更点は次のとおりです。

  • ユーザー名/パスワードによるログインが有効になっている場合でも、SSO 自動ログインが機能するようになりました (管理者は引き続き /login?all 経由でパスワード フォームにアクセスできます)
  • JPDFium のアップグレードとサポート、および Windows ARM64 のサポート。このアップデートでは、編集の改善、マージ/分割の改善、大きなファイルのメモリの削減も行われます。
  • 9MB の OpenCV バンドルが不要になり、より高速かつ正確なモバイル スキャンが可能になりました。
  • はるかに少ないデータベース読み取りと新しいエンティティのキャッシュによるリクエストの高速化
  • より静かな起動および実行時のログ
  • Spring Boot、Docker の基本イメージおよびその他の多くの依存関係の更新
  • すべての言語の翻訳を更新しました

また、以下を含むいくつかのバグも修正しました。

  • 複数または混合ファイルのアップロード送信を誤った変換に変換する
  • 電子ブックの設定により、選択した出力形式がリセットされます
  • PDF への電子メールで「すべての受信者を含める」で CC/BCC が制御されない
  • PDF/UA フォントの埋め込みによりフォームフィールドに入力できなくなる
  • 暗号化されていない PKCS#8 PEM キーを拒否する証明書署名
  • ブックマークを追加した後、閲覧者がページから飛び去ってしまう
  • 非 zip ファイルに対してアーカイブ抽出が提供されています

このリリースにはセキュリティと安定性に関するいくつかの改善も含まれているため、可能な場合は更新することをお勧めします。 注: 古い非推奨のバックエンド PDF テキスト編集 API は、新しいテキスト エディターに代わって削除されました。新しいテキスト エディター API を近々追加する予定です。
