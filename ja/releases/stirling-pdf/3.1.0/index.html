Stirling-PDF v3.1.0

マイナー 公開日2026年10月5日 出典Stirling-Tools/Stirling-PDF 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

Stirling-PDF_0.33.1 Docker ハブを starlingtools v3.1.0 に移動

このリリースでも大きな変更がいくつかあります。 グループ署名 (Stirling Sign と呼ばれる) はアルファ版から移行しており、新規ユーザーに対してデフォルトで有効になり、組織全体で PDF を共有、追跡、署名できるようになります。また、まったく新しい署名 UI も搭載されており、署名のユーザー エクスペリエンスが大幅に向上しています。何か問題がございましたらお知らせください。

また、「Stirling Office Convert」と呼ばれる新しい組み込み変換ツールも出荷しており、現在試行中です。これは、より少ないメモリでより良い変換結果をより速く提供することを目的としています。これはベータ版ですので、比較してお知らせください。 ([詳細設定] > [機能フラグ] でデフォルトで有効になります)

このリリースには他にもたくさんの機能があります。

  • テキスト エディタは、ファイル内でのテーブルの直接編集をサポートしています。
  • テキストエディタはOCRed画像PDFの編集をサポートしています。
  • テキストエディタのUIとUXの改善
  • 添付ファイルのサポートの改善 (追加、名前変更、抽出、削除など)
  • いくつかの依存関係の更新

そしてもう一度言います：

  • 新しいグループ署名 UI
  • 新しい PDF 変換ツール。将来的には古いツールに置き換わることを期待しています (ネイティブ デスクトップにも間もなく登場します!)
  • 署名ツールの改善

また、以下を含むいくつかのバグも修正しました。

  • 一部の翻訳が欠落しています
  • 特定のバージョンではアカウントのリンクが機能しない
  • デスクトップでは自動回転が機能しない
  • セルフホスト ユーザーに無効なチーム メニューが表示される
  • デスクトップが時々正しく更新されない

何が変わったのか

バグ修正

  • 修正（ビューア）: https://github.com/Stirling-Tools/Stirling-PDF/pull/8285 の @ConnorYoh によるタイマーではなく、プラグイン イベントのリロード全体でビュー ステートを引き継ぐ
  • 修正（テキストエディター）: https://github.com/Stirling-Tools/Stirling-PDF/pull/8311 の @ConnorYoh により、ワークベンチ ファイルを 150% ではなく、ビューアーのズームで開きます
  • 修正 (i18n): 欠落していたスーパー検索設定キーを https://github.com/Stirling-Tools/Stirling-PDF/pull/8339 の @reecebrowne によって en-US に追加
  • 修正 (セキュリティ): https://github.com/Stirling-Tools/Stirling-PDF/pull/7306 の @Ludy87 により、機密性の高いエンドポイントを認証された人間のユーザーに制限します

機能強化

  • deps(フロントエンド): Atlaskit プラグマティック ドラッグ アンド ドロップを 2.0.2 にアップグレード (https://github.com/Stirling-Tools/Stirling-PDF/pull/7484 の @Ludy87 により)
  • build(deps): https://github.com/Stirling-Tools/Stirling-PDF/pull/8272 の @dependabot[bot] による /frontend のバンプ ブレース展開
  • https://github.com/Stirling-Tools/Stirling-PDF/pull/6599 の @mvanhorn によりビューアの Toggle Bookmarks コントロールの名前を目次に変更
  • https://github.com/Stirling-Tools/Stirling-PDF/pull/8165 の @reecebrowne による 7 日間の孤立クリーンアップにより、オリジナルの処理を .stirling に保存します。
  • https://github.com/Stirling-Tools/Stirling-PDF/pull/8327 の @Frooodle によるローカル OCR が見つからない場合の自動回転クラウド フォールバックを修正
  • perf: https://github.com/Stirling-Tools/Stirling-PDF/pull/7939 の @balazs-szucs による冗長なリロードを回避するために、翻訳ファイルをプリロードし、言語切り替えを最適化します。
  • perf(files): https://github.com/Stirling-Tools/Stirling-PDF/pull/8037 の @balazs-szucs によって書き込まれたすべてのファイルでライブラリの再スキャンとサムネイルの書き換えを停止します
  • feat(テキストエディタ): Acrobat スタイルのオブジェクト編集 (Backspace 削除、ドラッグ選択、テキスト ボックスのサイズ変更、図形、Shift キーを押しながらサイズ変更) by @kmlakts (https://github.com/Stirling-Tools/Stirling-PDF/pull/8325)
  • 機能 (添付ファイル): https://github.com/Stirling-Tools/Stirling-PDF/pull/7333 の @balazs-szucs による完全な CRUD 操作用の UI を追加
  • build(deps): https://github.com/Stirling-Tools/Stirling-PDF/pull/8296 の @dependabot[bot] により、/frontend で axios を 1.18.1 から 1.20.0 にバンプします
  • https://github.com/Stirling-Tools/Stirling-PDF/pull/8319 の @dependabot[bot] による /frontend の 3.4.13 から 3.4.16 へのバンプ dompurify
  • https://github.com/Stirling-Tools/Stirling-PDF/pull/7758 の @stirlingbot[bot] によるフロントエンド サードパーティ ライセンスの更新
  • https://github.com/Stirling-Tools/Stirling-PDF/pull/8315 の @Frooodle によるデスクトップのアップデートと接続モード間のバージョン表示を修正
  • https://github.com/Stirling-Tools/Stirling-PDF/pull/8227 の @Frooodle による署名セッションを取得する前に、サインインしているユーザーを待ちます
  • https://github.com/Stirling-Tools/Stirling-PDF/pull/8229 の @Frooodle によるゲスト アカウントのサーバー ファイル リストをスキップ
  • https://github.com/Stirling-Tools/Stirling-PDF/pull/8274 の @EthanHealy01 によってすべてのアイコン ルールをオンに切り替えます
  • https://github.com/Stirling-Tools/Stirling-PDF/pull/8314 の @Frooodle により、OCR でスキャンされた PDF のテキストをテキスト エディターで編集します
  • https://github.com/Stirling-Tools/Stirling-PDF/pull/8338 の @ConnorYoh による追加の構成なしで、自己ホストされたストック画像を Stirling にリンクできるようにします
  • https://github.com/Stirling-Tools/Stirling-PDF/pull/8316 の @Frooodle によるセルフホスト型のユーザー メニューの表示と整理された設定を修正
  • perf(thumbnails): https://github.com/Stirling-Tools/Stirling-PDF/pull/8134 の @balazs-szucs による連続した wasm ビットマップ行のゼロコピー ビュー
  • perf(viewer): https://github.com/Stirling-Tools/Stirling-PDF/pull/8149 の @balazs-szucs によるアクション バンドルとコンテキスト値を安定化します。
  • https://github.com/Stirling-Tools/Stirling-PDF/pull/8208 の @Frooodle によって保存された署名を中心に署名ツールを再設計します。
  • https://github.com/Stirling-Tools/Stirling-PDF/pull/8335 の @Frooodle により v2 PDF テキスト エディターにテーブルの検出と編集を追加
  • スターリング サイン V1 (@ConnorYoh 著、https://github.com/Stirling-Tools/Stirling-PDF/pull/8189)
  • perf(tools): ツール ピッカー カテゴリをビューポートの近くにマウントします (https://github.com/Stirling-Tools/Stirling-PDF/pull/8234 の @balazs-szucs による)
  • perf(viewer): https://github.com/Stirling-Tools/Stirling-PDF/pull/8233 の @balazs-szucs によるリンクごとのヒット ボックスをレンダリングするアノテーション レイヤーを停止します。
  • https://github.com/Stirling-Tools/Stirling-PDF/pull/8219 の @Frooodle により Stirling Office Convert をオプトイン Office コンバーターとして追加
  • 変更された文字列を再翻訳し、ロケールを同期し、https://github.com/Stirling-Tools/Stirling-PDF/pull/8358 の @Frooodle によって 3.1.0 にバンプします
