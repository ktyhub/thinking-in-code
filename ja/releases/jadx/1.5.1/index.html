#ジャデックスv1.5.1

主な特長

コア:

  • スイッチオーバー文字列の復元をサポート
  • 半破損した APK に対する自動パッチ適用を追加 (PR #2298)
  • リソースデコードの新しいフィールドのサポート

GUI:

  • ピンタブ (PR #2230)
  • クイックタブ (PR #2241)
  • 検索をパッケージに限定する (PR #2284)
  • アプリケーション クラスに移動するボタンを追加 (#2208)(PR #2213)
  • リソース/クラス/パッケージのエクスポート (PR #2228)
  • Smali コード折りたたみ (PR #2233)

機能

  • AAB サポートを別のプラグインに移動 (PR #2165)

  • 環境変数を使用して構成ディレクトリとキャッシュディレクトリを変更できるようにしました (#2159)

  • 外部インスタンスによる内部クラスの構築をサポート (#2253)

  • 常にソースファイル名をクラス名のエイリアスとして使用するオプションを追加 (PR #2287)

  • スイッチオーバー文字列のリストアをサポート(基本的なケース)(#2288)

  • 半破損した APK に対する自動パッチ適用を追加 (PR #2298)

  • better name アルゴリズムの改善 (PR #2299)

  • インストールされているプラグインを無効にできるようにします (#2277)

  • プラグインがロックする前にブロックを編集できるようにする (PR #2336)

  • メソッドにすべてのブロック関連情報を更新するメソッドを追加 (#2335)

  • [api] XML セキュリティ チェックを調整するための JadxArgs プロパティを追加 (#2291)

  • [api] メソッドコードの取得を許可 (#2305)

  • [cli] プラグインを無効にするオプションを追加 (#2277)

  • [gui] 不安定なリリースをチェックできるようにする (PR #2200)

  • [gui] アプリケーション クラスに移動するボタンを追加 (#2208)(PR #2213)

  • [gui] リソース/クラス/パッケージのエクスポート (PR #2228)

  • [gui] タブをピン留めする (PR #2230)

  • [gui] Smali コードの折りたたみ (PR #2233)

  • [gui] クイックタブのオーバーホール (PR #2241)

  • [gui] 検索をパッケージに限定する (PR #2284)

  • [gui] Android マニフェストに移動するボタンを追加 (PR #2296)

  • [gui] クラス内のすべてのメソッドに対して Frida フック スニペットを作成する (PR #2328)

  • [java-input] 未訪問のジャンプのスタック情報を取得するための StackMapTable をサポート (#2271)

  • [プラグイン] メインウィンドウの参照をJFrameとして取得します

  • [プラグイン] プラグインの設定ディレクトリとキャッシュディレクトリを取得します

  • [プラグイン] プラグイン情報に最低限必要な jadx バージョンを設定できるようにしました (#2314)

  • [res] サポートされていない ResTable フラグのエラー メッセージを改善 (PR #2266)

  • [res] 16 ビット エントリ オフセットをサポート (PR #2269)

  • [res] コンパクトなリソースエントリをサポート (#2268)

  • [res] res config で文法語形変化フラグをサポート (#2270)

  • [レス] リソース名の改善 (PR #2316)

バグ修正

  • キャッシュ ディレクトリの代わりに設定ディレクトリが使用されました

  • 例外ハンドラーのチェックを改善 (#2086)

  • 詳細な var 情報を確定的にする (PR #2231)

  • FixAccessModifier のメソッドがインラインであるかどうかのチェックを改善しました (PR #2235)

  • ConstructorVisitor で SSA 変換を再実行しない (#2236)

  • メソッドをインライン決定的にするための回避策 (#1089)

  • インライン合成アクセサーの改善 (PR #2243)

  • 正しいアプローチを使用してパス上の prev ブロックを取得します (#2239)

  • 分岐コンストラクターでのクイックリターンの処理 (#2240)

  • ループ内のスイッチ out 検索を改善 (#2246)

  • クラスのアクセス修飾子のチェックを改善しました (PR #2251)

  • メソッドのアクセス修飾子のチェックを改善しました (PR #2252)

  • Try/Catch 温度エッジ注入を改善 (#2247)

  • アクセス修飾子のチェックを改善しました (PR #2255)

  • ループ内のスイッチの「Continue」挿入を改善 (#2249)

  • デバッグ情報オフセットが無効かどうかを確認する (#1653)

  • クラス署名の追加チェック (#2272)

  • フォールバック モードとシンプル モードにカスタム パスを追加しないでください (#2276)

  • クラス deps が異なる逆コンパイル モードでロードされないように保護します

  • ループ内の条件分岐チェックを改善 (#2274)

  • コンストラクター呼び出しと異なる場合は、new-instance の型を使用する (#2285)

  • メソッドの数値が調整されている場合、デバッグ行のヒントを無視します

  • 内部クラスに同じ「loaded from:」コメントを追加しないでください。

  • すべてのメソッド出口が内部にある場合のスイッチアウトブロック検索を改善しました (#2264)

  • 新しい充填された配列を復元するためのチェックを改善 (#2289)

  • アプリケーション内でのみ temp dir 環境変数を使用します

  • 予約キーワードの更新 (PR #2301)

  • 入力ファイルの早い段階でパッチ適用された zip を置き換えます (#2302)

  • jadx によって生成されたクラスの codegen に欠落している null チェックを追加

  • 一時ルート ディレクトリを削除する代わりにクリアします (#2312)

  • switch-over-string のデフォルトの分岐位置を修正 (PR #2331)

  • ヘッダー挿入前モジュールの無限ループを防止 (#2300)

  • スイッチオーバー文字列内の定数のラップを解除する (PR #2332)

  • スイッチオーバー文字列の否定条件チェックを改善 (#2333)

  • スイッチオーバーストリングでの「デフォルトへのフォールスルー」ケースをサポート (PR #2338)

  • 最初に使用する前に、新しい塗りつぶされた配列 insn を挿入します (#2340)

  • プリミティブからプリミティブへの変換を修正 (PR #2326)

  • [deobf] TLD の更新 (PR#2320)

  • [gui] 16 進ビューでバイナリ リソースの正しいコンテンツを表示する (#2160) (PR #2166)

  • [gui] ファイル ダイアログで複数の拡張子を持つファイルのフィルタリングをサポート (PR #2185)

  • [gui] Messages_zh_CN.properties を更新 (PR #2203、PR #2319)

  • [gui] ロシア語翻訳を更新 (PR #2209)

  • [gui] Xsolved args コード生成を修正 (PR #2212)

  • [gui] Linux での水平スクロール (PR #2229)

  • [gui] コードポップアップメニューに折りたたみアクションを表示 (#2234)

  • [gui] UI ゴーストを修正するために VM フラグを追加 (#2225)

  • [gui] 入力ファイルの末尾のスペースを削除する (#2244)

  • [gui] ファイルダイアログからパス内の先頭のスペースもトリム (#2244)

  • [gui] 名前変更ダイアログで正しい翻訳を使用する (#2254)

  • [gui] クイック タブの最適化 (PR #2242)

  • [gui] コンストラクターの完全なクラス名トークンをマージする (#2261)

  • [gui] クラスロード時に UI がスタックするのを防ぐ (#2259)

  • [gui] コードジャンプのマイナー修正

  • [gui] TabsController での古いオブジェクト参照リークを解決する

  • [gui] ショートカット コントローラーでの古い refs リークを防ぐ

  • [gui] コードジャンプの前に選択タブイベントを送信 (#2292)

  • [gui] 現在のアーティファクトの名前と一致するように更新チェックを修正しました

  • [gui] プラグイン設定グループを改善

  • [gui] 設定行で説明と値の間のスペースを減らします

  • [gui] フォントダイアログに別の実装を使用する (#2310)

  • [gui] UI を使用せずに一時コンテキストでプラグイン設定をロードする (#2206)

  • [gui] プラグインリストで正しいセクションフィルターを使用する

  • [gui] 「その他を閉じる」タブアクションのタブフィルターを修正 (#2330)

  • [launch4j] applicationDefaultJvmArgs から Java ヒープ構成を上書きしない (PR #2218)

  • [マッピング] エクスポート例外でマッピング ファイルがリセットされないようにし、リファクタリングしてコードを修正して NPE を回避します (#2220)(#2226)

  • [quark] 自動インストールを修正し、実行された外部コマンドの終了コードをチェックする (#2119)(PR #2216)

  • [res] ARSC エントリの重複を防止 (#2263)

  • [res] useRawResName = true の場合、リソース エントリの名前を変更しない (PR #2306)

  • [レス] Android 属性を API 35 に更新 (PR #2318)

  • [smali-input] 64k 制限を回避するために、一度に 1 つの smali ファイルをコンパイルします (#2158)

  • [xml] 非標準の属性サイズを許可し、一部の文字列をデコードする際のインデックス例外を回避します (PR #2210)

  • [xml] AXML/マニフェスト解析の改善 (PR #2211) </詳細>
