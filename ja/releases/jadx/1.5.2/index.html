jadx v1.5.2

パッチ 公開日2025年6月2日 出典skylot/jadx 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#ジャデックスv1.5.2

主な特長

コア:

  • 改ざんと戦うためのカスタム zip リーダーの実装
  • Gradle エクスポート テンプレートを追加し、Android アプリ/ライブラリと単純な Java をサポートします
  • DEX v41 の初期サポート (#2128)

GUI:

  • オプション付きのエクスポート ダイアログを追加 (PR #2378)
  • ツリー構造の使用状況の検索 (PR #2498)
  • UI テーマから動的コード エディター テーマを追加 (PR #2471)
  • プレビュー タブ機能を追加 (PR #2474)
  • 新しい HexViewer (PR #2469)

プラグイン:

  • APKM サポートを追加 (PR #2379)
  • クラスとパッケージの名前を変更するために SMAP で Kotlin SourceDebugExtension を解析して使用する (PR #2389)

API:

  • JadxPlugin に「unload」メソッドを追加 (#2463)
  • ツリーノードのポップアップメニューエントリを追加する方法 (#2412)
  • jadx-gui アイコンを名前で取得するメソッドを追加
  • 使用状況ダイアログを開くメソッドを追加

  • GSON での JDK Unsafe クラスの使用を無効にする (#2341)
