compose v5.2.0

マイナー 公開日2026年6月23日 出典docker/compose 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

v5.2.0 を作成する

何が変わったのか

ℹ️ このバージョンでは、観察された状態と期待される状態の間の新しい調整アルゴリズムが導入されています。

以前は動作していた Compose ワークロードで問題が発生した場合は、問題を報告してください。

✨ 改善点

  • https://github.com/docker/compose/pull/13830 の @ndeloof と @glours による和解計画
  • https://github.com/docker/compose/pull/13742 の @rajyan によりプロバイダー プラグインの rawsetenv メッセージ タイプを追加

🐛 修正

  • 修正 (ビルド): https://github.com/docker/compose/pull/13816 の @ndeloof による、bake fs.read ホワイトリストからリモート URL コンテキストをスキップ
  • https://github.com/docker/compose/pull/13831 で @scarab-systems によって構成変数を抽出するときに検証をスキップします
  • 修正 (進捗): https://github.com/docker/compose/pull/13837 の @glours による TTY 自動検出用の stderr (stdout ではない) をプローブします。
  • 修正 (公開): env_file 必須: https://github.com/docker/compose/pull/13848 の @Ijtihed による欠落ファイルの場合は false

🔧 内部

  • ドキュメント: ログの作成: https://github.com/docker/compose/pull/13806 の @thaJeztah による、since/until フラグの説明へのリンクを追加
  • Ci: https://github.com/docker/compose/pull/13820 の @securityeng-bot[bot] により、Dependabot のクールダウン (20260603-170456) を追加します。
  • ドキュメント(CLAUDE.md): https://github.com/docker/compose/pull/13817 の @ndeloof によってコミットがサインオフ (DCO) される必要があることに注意してください。
  • リファクタリング: https://github.com/docker/compose/pull/13810 の @caltechustc により、ループ内の Split をより効率的な SplitSeq に置き換え、HasPrefix+TrimPrefix を CutPrefix に置き換えます。
  • 雑用: https://github.com/docker/compose/pull/13823 の @solunolab による読みやすさを向上させるためにいくつかのコメントを修正
  • GHA: https://github.com/docker/compose/pull/13834 の @thaJeztah による sha によるワークフローを固定するために docs-upstream を更新
  • ドキュメント: ログの作成: @thaJeztah によるフラグの説明へのリンクを https://github.com/docker/compose/pull/13833 に追加
  • https://github.com/docker/compose/pull/13840 の @glours による tty ライン オーバーフロー 13595 を修正/進行
  • 修正 (公開): https://github.com/docker/compose/pull/13825 の @ptrdom によるループバック レジストリの Docker デスクトップ プロキシをバイパスします。
  • 注意: https://github.com/docker/compose/pull/13856 の @ndeloof によるファイル変更時に depend_on サービスを再構築しないでください
  • pkg/e2e: https://github.com/docker/compose/pull/13857 の @thaJeztah によるフィクスチャ内の不正な JWT を修正
  • pkg/e2e: https://github.com/docker/compose/pull/13867 の @glours により、未使用の実行パラメータを getEnv から削除します
  • ドキュメント: https://github.com/docker/compose/pull/13868 の @glours により、ps --format json は JSON 配列ではなく、JSON 行を出力します。

⚙️ 依存関係

  • ビルド (deps): https://github.com/docker/compose/pull/13802 の @dependabot[bot] により、github.com/docker/cli を 29.5.1+incompatible から 29.5.2+incompatible にバンプします
  • https://github.com/docker/compose/pull/13828 の @thaJeztah による 1.26.4 への更新
  • 雑用 (deps): github.com/containerd/typeurl/v2 v2.3.0 by @thaJeztah (https://github.com/docker/compose/pull/13829)
  • ビルド (deps): https://github.com/docker/compose/pull/13838 の @dependabot[bot] により golang.org/x/sync を 0.20.0 から 0.21.0 にバンプします
  • 雑用 (deps): github.com/docker/cli v29.5.3、github.com/docker/buildx v0.34.1、ビルドキット v0.30.0 by @thaJeztah (https://github.com/docker/compose/pull/13841)
  • ビルド (deps): https://github.com/docker/compose/pull/13832 の @dependabot[bot] により golang.org/x/sys を 0.45.0 から 0.46.0 にバンプします
  • 雑用 (deps): golang.org/x/crypto v0.53.0 by @thaJeztah in https://github.com/docker/compose/pull/13844
  • ビルド (deps): https://github.com/docker/compose/pull/13804 の @dependabot[bot] によって、go_modules グループ内の github.com/containerd/containerd/v2 を 1 つのディレクトリにある 2.2.3 から 2.2.4 にバンプします。
  • 作業 (deps): https://github.com/docker/compose/pull/13855 の @thaJeztah により、github.com/containerd/containerd/v2 を v2.2.5 にバンプします
  • 雑用 (deps): https://github.com/docker/compose/pull/13847 の @thaJeztah により github.com/golang-jwt/jwt/v5 を v5.3.1 にバンプします
  • 雑用 (deps): github.com/docker/cli v29.6.0、github.com/docker/buildx v0.35.0、ビルドキット v0.31.0 by @thaJeztah in https://github.com/docker/compose/pull/13842
  • コンポーズをバンプします - https://github.com/docker/compose/pull/13865 の @glours によるバージョン v2.12.1 に移動します
