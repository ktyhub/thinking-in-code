v5.7.0 を作成する

何が変わったのか

ℹ️ Compose をライブラリとして使用するユーザーへの注意: Up は、up -d (#14290) およびインタラクティブ up (#14305) については、単一デーモン スナップショット上の単一プランとして、作成フェーズと開始フェーズを scale として実行し、リビルドと start をすでに監視しています。 (#14291、#14296) を実行します。 CLI は以前と同様に動作します。独自のプログラムから api.Compose.Up を呼び出す場合:

  • Up は、CLI フラグと同じルールで最初にオプションを検証するようになりました。UpOptions.Validate() は、Start.Wait と Start.Attach の組み合わせ、および切り離された Up (Start.Attach なし) と OnExit、ExitCodeFrom、または Watch の組み合わせについては *api.IncompatibleOptionsError (errors.Is(err, api.ErrIncompatibleOptions)) を返します。これらの組み合わせは以前は黙って無視されていました (#14306)。
  • Up は指定されたプロジェクトで動作し、StartOptions.Project を無視します。
  • デーモンは 2 つのフェーズ間では再度観察されません。プランの構築後に終了したコンテナは再起動されず、途中で削除されたコンテナはスキップされずに起動に失敗します。開始フェーズの計画エラーは、コンテナーが作成される前に失敗するようになりました。
  • フォアグラウンドの Up は、up -d と同様に、use_api_socket サービスに /run/secrets/docker/config.json を与え、pre_start フックの出力を表示します。
  • インタラクティブな up のキーボード メニューはライブラリによって構築されなくなりました。NavigationMenu: true を設定し、そして compose.WithNavigationMenu(...) で実装を渡します。そうでない場合、メニューは表示されず、警告が表示されます (#14324)。

このリリースでのライブラリ表面へのその他の変更: DownOptions.Images は api.ImagePruneMode になり (型なし定数は引き続きコンパイルされ、string 変数は変換が必要です)、無効な値は Down が何かを削除する前に拒否されます (#14149)。 compose.ServiceHash、compose.NetworkHash、compose.VolumeHash はエクスポートされなくなり、ヘルパーは内部パッケージ (#14405) に移動されました。 api.Compose は、同じメソッドセット (#14322) を使用して 6 つの小さなインターフェイスから組み立てられるようになりました。 PushOptions.IgnoreMissingを追加しました。

✨ 改善点

実行計画

  • 機能: https://github.com/docker/compose/pull/14290 の @ndeloof による単一の計画で分離されたアップが実行されます。
  • Feat(up): https://github.com/docker/compose/pull/14305 の @ndeloof による単一プランでインタラクティブなアップが実行されます。
  • 機能: スケールとウォッチの再構築は、https://github.com/docker/compose/pull/14291 の @ndeloof による統一プランを使用します。
  • 機能: compose start は、https://github.com/docker/compose/pull/14296 の @ndeloof による開始のみのプランを構築します

コマンド

  • Feat(run): --no-recreate は、https://github.com/docker/compose/pull/14144 の @ndeloof により既存の依存関係をそのまま再利用します。
  • 機能 (プッシュ): --ignore-missing を追加して、https://github.com/docker/compose/pull/14341 の @glours によってローカルで利用できない画像をスキップします
  • 機能 (push): https://github.com/docker/compose/pull/14354 の @glours による --ignore-missing を優先して --ignore-push-failures を非推奨にします
  • 機能 (統計): https://github.com/docker/compose/pull/14337 の @glours によって --all-projects および --aggregate フラグを追加
  • 機能 (ネットワーク): https://github.com/docker/compose/pull/14342 の @glours により、サービスがネットワーク エイリアスとしてその名前をオプトアウトできるようにします。
  • https://github.com/docker/compose/pull/14352 の @maxproske により、--Parallel 制限を渡して --jobs としてベイクします

その他

  • 機能: https://github.com/docker/compose/pull/14367 の @ndeloof による umask サービス属性をサポート
  • https://github.com/docker/compose/pull/14295 の @Benehiko による Docker ハブ レジストリ資格情報には、Docker デスクトップ ハブ セッションを使用します。
