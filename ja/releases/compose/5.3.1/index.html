v5.3.1 を作成する

何が変わったのか

🔧 内部

  • Ci: https://github.com/docker/compose/pull/13890 で @derekmisler による重複レビューを防ぐために、同時実行グループを pr-review-trigger に追加します。
  • https://github.com/docker/compose/pull/13891 の @blackflytech による Attestations フィールドのコメントの文法を修正
  • Ci: https://github.com/docker/compose/pull/13897 の @thaJeztah により未使用のデスクトップ エッジ テスト ワークフローを削除
  • Ci: zizmor ワークフロー (@crazy-max 著、https://github.com/docker/compose/pull/13901)
  • Ci: https://github.com/docker/compose/pull/13912 の @crazy-max によるドキュメントアップストリーム ワークフローを修正
  • コード所有者: @thaJeztah による作成レビュー担当者を https://github.com/docker/compose/pull/13913 に追加
  • Ci: https://github.com/docker/compose/pull/13896 の @glours による GitHub アクション ワークフローを強化します。
  • GHA: dependabot: グループ docker/* https://github.com/docker/compose/pull/13914 の @thaJeztah によるアクション更新

⚙️ 依存関係

  • ビルド (deps): https://github.com/docker/compose/pull/13892 の @dependabot[bot] により、github.com/moby/buildkit を 0.31.0 から 0.31.1 に変更します。
  • ビルド (deps): https://github.com/docker/compose/pull/13893 の @thaJeztah によって github.com/moby/sys/user を v0.4.1 にバンプします
  • ビルド (deps): https://github.com/docker/compose/pull/13876 の @dependabot[bot] により go.yaml.in/yaml/v4 を 4.0.0-rc.4 から 4.0.0-rc.6 にバンプします
  • ビルド (deps): https://github.com/docker/compose/pull/13895 の @dependabot[bot] により、github.com/docker/cli を 29.6.0+incompatible から 29.6.1+incompatible にバンプします
  • ビルド (deps): https://github.com/docker/compose/pull/13902 の @dependabot[bot] により、アクション/古くなったものを 10.2.0 から 10.3.0 に変更
  • Build(deps): https://github.com/docker/compose/pull/13916 の @dependabot[bot] による 3 つの更新で docker-actions グループをバンプします。
  • Build(deps): https://github.com/docker/compose/pull/13908 の @dependabot[bot] による 7.0.0 から 7.0.1 へのアクション/アップロード アーティファクトのバンプ
  • ビルド (deps): アクション/セットアップをバンプする - https://github.com/docker/compose/pull/13907 の @dependabot[bot] による 6.3.0 から 6.5.0 へ
  • ビルド (deps): https://github.com/docker/compose/pull/13903 の @dependabot[bot] による、2.4 から 2.6 へのバンプ テストの概要/アクション
  • Build(deps): https://github.com/docker/compose/pull/13910 の @dependabot[bot] により、mxschmitt/action-tmate を 3.23 から 3.24 に変更します。
  • Build(deps): https://github.com/docker/compose/pull/13904 の @dependabot[bot] により codecov/codecov-action を 5.5.3 から 7.0.0 にバンプします
  • ビルド (deps): https://github.com/docker/compose/pull/13917 の @dependabot[bot] により、github/codeql-action/upload-sarif を 3.36.3 から 4.36.2 にバンプします
  • ビルド (deps): https://github.com/docker/compose/pull/13911 の @dependabot[bot] による 6.0.2 から 7.0.0 へのアクション/チェックアウトのバンプ
