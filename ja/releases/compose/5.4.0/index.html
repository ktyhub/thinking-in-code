compose v5.4.0

マイナー 公開日2026年8月3日 出典docker/compose 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

v5.4.0 を作成する

何が変わったのか

ℹ️ このリリースでは、ボリュームやネットワークなどのリソースを調整する新しい方法が導入されています

✨ 改善点

  • 機能(調整): https://github.com/docker/compose/pull/13962 の @ndeloof による計画でのモデル ボリュームの再作成
  • 機能 (調整): https://github.com/docker/compose/pull/13966 の @ndeloof による計画におけるネットワーク ライフサイクルのモデル化

🐛 修正

  • 修正 (調整): https://github.com/docker/compose/pull/13931 の @junhaoliao によるハッシュ中にゼロ レプリカ サービスを保持する
  • 修正(構成): https://github.com/docker/compose/pull/13950 の @glours によってサービス選択が黙って無視されると警告する
  • 修正 (ビルド): https://github.com/docker/compose/pull/13949 の @glours によって証明されたインデックスではなく、プラットフォーム イメージ マニフェスト ダイジェストを使用する
  • 修正 (oci): up が https://github.com/docker/compose/pull/13894 の @ptrdom によってモデルを再ロードするときの Honor --insecure-registry
  • 修正(構成): https://github.com/docker/compose/pull/13956 の @glours によるピン タイプ:イメージ ボリューム ソースと pre_start フック イメージ
  • https://github.com/docker/compose/pull/13603 の @maxproske により、より多くのランタイム コマンドで環境ファイルの欠落を許容
  • https://github.com/docker/compose/pull/13937 の @ndeloof によるサービス イメージと一緒に pre_start フック イメージを解決します
  • 修正 (cp): https://github.com/docker/compose/pull/13982 の @glours によるドライラン CopyFromContainer から非 nil コンテンツを返す
  • 修正(構成): https://github.com/docker/compose/pull/13979 の @glours により、構成フラグを --services/--volumes/--networks/--models/--hash に適用
  • 修正: https://github.com/docker/compose/pull/13973 での @glours によるスケール、監視およびシェル完了での環境ファイルの欠落を許容します

🔧 内部

  • README: Go レポート カード バッジを削除 (https://github.com/docker/compose/pull/13926 の @thaJeztah 著)
  • ドキュメント: AGENTS.md 標準を採用し、https://github.com/docker/compose/pull/13871 の @glours によって CLAUDE.md をそれにシンボリックリンクします。
  • Dockerfile: https://github.com/docker/compose/pull/13921 の @thaJeztah により golang イメージを alpine 3.23 に更新
  • ドキュメント: 日付付きの AI_AGENT_DISCLOSURE.md が必要、https://github.com/docker/compose/pull/13976 の @glours によってコミットされたコピーを削除
  • CI: https://github.com/docker/compose/pull/13994 の @glours による OIDC を使用して Docker ハブに画像を公開します
