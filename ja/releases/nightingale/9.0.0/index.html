nightingale v9.0.0

メジャー 公開日2026年7月25日 出典ccfos/nightingale 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#ナイチンゲールv9.0.0

何が変わったのか

  • 特技: アラート ルールは テスト ファイア をサポート — 実際にクエリされたシリーズに対してオンデマンドでルールをトリガーし、段階ごとのレポートを取得します (クエリ チェック → しきい値 → イベント → 通知パイプライン → 通知)、条件が発生する前にアラート チェーン全体を検証します。 会った (#3274)
  • 特技: ログ クエリが VictoriaLogs をサポート (#3239)
  • 特技: アラート ミュート ルールは 通知のみのミュート をサポートします — イベントは引き続き生成および記録されます (イベント内でミュートとしてタグ付けされます) リストと詳細)、通知が抑制されている間 (#3250)
  • 特技: ホスト ページは 1 つの click Categraf インストールをサポートしています — コレクター パッケージはサーバーに同梱されており、すぐに実行できるインストールが可能です スクリプトはプラットフォームごとに生成される (#3272)
  • 特技: 組み込みの /mcp エンドポイントが、きめ細かいツールセット (アラート、ターゲット、データソース、ミュート、通知ルール、アラート) を提供するようになりました。 サブスクライブ、イベント パイプライン、ユーザー、メトリクス、ログ、ダッシュボード、ロール) — デフォルトでは読み取り専用で、書き込みツールとツールセットを使用します。 どちらも明示的なオプトインを必要とするホワイトリスト (#3245)
  • 特技: AI スキルのサポート承認範囲 — パブリックまたはチームプライベート、編集は承認されたチームに制限される (#3247、#3268)
  • 特技: アラート ルール/ミュート/サブスクリプション/通知ルール フォームの再設計 — セクション カード、ライブ表示付きの右側のナビゲーション 条件の概要、自動命名、クイック持続時間のプリセット、シナリオベースの空の状態
  • 特技: メッセージ テンプレートとテンプレート センターは i18n をサポートしているため、単一のテンプレートが受信者の言語でレンダリングされます (#3235、 #3238、#3261)
  • 機能: アラート履歴イベントは、設定可能な日数の間保持できます (CleanAlertHisEventDay、夜間バッチでクリーンアップ)。 新しい複合インデックスとカーソルのページネーション (#3264)
  • 特技: イベント パイプラインの AI サマリー ノードは、独自の LLM 構成を保持する代わりに、一元化された LLM 構成を再利用できます (#3242)
  • 特技: コンソールで i18n を完全にカバー
  • 特技: リスト テーブルは、インライン行アクション、ソート可能な作成者と時刻の列、およびページネーションのクイック ジャンパーをサポートしています。
  • 修正: 集約アラート イベント操作が HTTP 414 で失敗しなくなりました。イベント ID は POST 本文で JSON 配列として送信されるようになりました。
  • 修正: 履歴イベントを一括削除しても、アクティブなアラートがまだあるイベントは削除されなくなりました (#3263)
  • 修正: DDL が MySQL 9.7 で動作するように外部設定列を引用符で囲みます (#3276)
  • 修正: HTML レンダリングの前にユーザー入力と詳細 URL をサニタイズ (XSS 強化)

新しい貢献者

  • 偉業: Nightingale AI の導入 — 組み込みの AI アシスタント、スキル マーケットプレイス、LLM 構成管理、ページ固有のプロンプト推奨事項を備えた
  • 特技: ナビゲーション メニュー、グローバル レイアウト、テーブル UI の再設計
  • 特技: 通知チャネル管理のリファクタリング
  • 特技: 詳細な実行ビューを備えた新しいイベント パイプライン実行追跡ページ

アップグレードに関するメモ ⚠️

新しい AI アシスタントは Redis ストリームに依存するため、Redis 5.0 以降が必要です (シャード Pub/Sub を有効にするクラスター ユーザーには Redis 7.0+ が推奨されます)。
