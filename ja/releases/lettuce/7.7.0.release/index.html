#レタス7.7.0.RELEASE

Lettuce チームは、Lettuce 7.7.0 のマイナー リリースを発表できることを嬉しく思います。

✨ハイライト

Lettuce 7.7.0 では、Redis OSS 8.10 リリース からの次のような新機能のサポートが導入されています。

  • 新しいコマンド: HIMPORT - 高スループットのコンパクト ハッシュの一括挿入 - ユーザー ガイド
  • 新しいコマンド: LMOVEM、BLMOVEM - リスト間で複数の要素を移動します
  • 新しいコマンド: SUNIONCARD - 複数のセットの和集合のカーディナリティを取得します。
  • 新しいコマンド: SDIFFCARD - セット間の差異の基数を取得します。
  • XREAD、XREADGROUP - 累積応答エントリとサイズを制限するための新しい MAXCOUNT および MAXSIZE 引数
  • 新しいコマンド: FT.ALIASLIST - インデックスのすべてのエイリアスを取得します
  • マレー語とタガログ語のステマーのサポート

Redis での確率的データ構造の機能サポート:

  • ブルームフィルター
  • カウントミニスケッチ
  • カッコーフィルター
  • t-ダイジェスト
  • トップK

レタス 7.7.0 は、Redis 2.6+ から Redis 8.x までをサポートします。 Java ランタイムに関して言えば、Lettuce には少なくとも Java 8 と ドライバーは、Redis 8.10、Redis 8.8、Redis 8.6、Redis 8.4、Redis 8.2、Redis 8.0、Redis 7.4、Redis に対してテストされています。 7.2。

Lettuce 7.7.0.RELEASE を可能にしてくれたすべての貢献者に感謝します。

📗 リンク 参考資料: https://lettuce.io/core/7.7.0.RELEASE
