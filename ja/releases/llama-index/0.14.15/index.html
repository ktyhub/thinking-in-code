ラマ_インデックス v0.14.15

#Release Notes

[2026-02-18]

ラマインデックスエージェントエージェントメッシュ [0.1.0]

  • [統合] AgentMesh: LlamaIndex エージェントの Trust レイヤー (#20644)

ラマインデックスコア [0.14.15]

  • マルチモーダル型の基本操作をサポート (#20640)
  • 再帰的 llm 型のサポート (#20642)
  • 修正: TextNode から冗長な metadata_seperator フィールドを削除 (#20649)
  • 修正（テスト）：mock_prompts.pyのモックプロンプトタイプを更新（[#20661]（https://github.com/run-llama/llama_index/pull/20661））
  • マルチモーダル テンプレートの var フォーマット機能 (#20682)
  • 機能マルチモーダル プロンプト テンプレート (#20683)
  • マルチモーダル チャット プロンプト ヘルパー機能 (#20684)
  • BaseExtractor に再試行とエラー処理を追加 (#20693)
  • 少なくとも 1 つのメッセージ/コンテンツ ブロックが古いメモリから返されることを確認します (#20729)

ラマインデックス埋め込みibm [0.6.0.post1]

  • 雑用:persistent_connection パラメータのサポートを削除、更新 (#20714)
  • ドキュメント: IBM ドキュメントを更新 (#20718)

ラマインデックス-llms-anthropic [0.10.9]

  • ソネット 4-6 追加 (#20723)

ラマインデックス-llms-bedrock-converse [0.12.10]

  • 修正(bedrock-converse): Thinking_delta がすべてのチャット モードに入力されるようにします (#20664)
  • feat(bedrock-converse): クロード・ソネット 4.6 のサポートを追加 (#20726)

ラマインデックス-llms-ibm [0.7.0.post1]

  • 雑用:persistent_connection パラメータのサポートを削除、更新 (#20714)
  • ドキュメント: IBM ドキュメントを更新 (#20718)

ラマインデックス-llms-ミストラライ [0.10.0]

●ルビニ/ミストラルアズール sdk (#20668)

ラマインデックス-llms-oci-データ-サイエンス [1.0.0]

  • ストリーミング ユースケース用の新しい OCI DataScience エンドポイント /predictWithStream のサポートを追加 (#20545)

ラマインデックス可観測性オテル [0.3.0]

  • 辞書を平坦化することでホテルのデータのシリアル化を改善しました (#20719)
  • 特技: カスタム スパン プロセッサをサポートします。リファクタリング: llama-index-core の代わりに llama-index-instrumentation を使用する (#20732)

ラマインデックスプログラム蒸発 [0.5.2]

  • EvaporateExtractor でのサンドボックス LLM 生成コードの実行 (#20676)

ラマインデックスリーダービットバケット [0.4.2]

  • 修正:load_all_file_paths の変更可能なデフォルト引数を置き換えます (#20698)

ラマインデックスリーダー-github [0.10.0]

  • 特技: 選択的ファイルのフェッチと重複排除による GitHubRepoReader の強化 (問題 #20471) (#20550)

ラマインデックスリーダーレイアウト [0.1.1]

  • 特技: LayoutIR リーダー統合の追加 (#20708)
  • fix(layoutir):output_dir のクラッシュとブロック抽出のホットフィックス (#20708 フォローアップ) (#20715)
  • 修正(layoutir):layoutirの依存関係に一致させるためにrequires-pythonを>=3.12に制限(#20733)

llama-index-readers-microsoft-sharepoint [0.8.0]

  • SharePoint リーダーでの Microsoft Graph API 呼び出しのページネーション サポートを追加 (#20704)

ラマ-インデックス-リーダー-whatsapp [0.4.2]

  • 修正: WhatsAppChatLoader を更新して、パンダ形式で DataFrame を取得するようにしました (#20722)

ラマインデックスツール mcp [0.4.7]

  • 特技：partial_params を get_tools_from_mcp utils に伝播する (#20669)

ラマインデックスベクターストアファイス [0.5.3]

  • FaissMapVectorStore 永続化の eval() を json.loads に置き換えます (#20675)

ラマインデックスベクターストアミルバス [1.0.0]

  • 修正: Milvus ベクター ストアの MilvusClient との ORM Collection 混合使用を削除 (#20687)
