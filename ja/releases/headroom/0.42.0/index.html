#ヘッドルームv0.42.0

0.42.0 (2026-10-26)

機能

  • パイプライン: リクエストごとに保存されたトークンを OutcomeSnapshot に配置します (#4231) (8cedf7b)
  • プロキシ: ターンフックで HTTP および WebSocket 上の OpenAI Response リクエストを書き換えます (#4232) (fbf7bc3)
  • プロキシ: ゲートウェイ /v1/compress での同じツールの節約をプロキシ パスと報告します (#4467) (a904210)
  • 節約: リクエストごとに反事実的な節約レコードを追加します (#4236) (2912b7b)

バグ修正

  • バッチ: 容量のクリーンアップ中にライブ コンテキストを保持します (#4210) (2cbdd22)
  • バッチ: ネイティブ Gemini 継続ツールを保持 (#4211) (8757458)
  • キャッシュ: ルーターの圧縮キャッシュをバインドし、残りを SQLite に保持します (#4357) (b196424)
  • キャッシュ: OpenAI ホワイトスペース正規化でインデントされた行をそのまま保持します (#4343) (2480100)
  • キャッシュ: プロキシの正常な再起動後もプレフィックス トラッカーの状態を維持します (#4299) (62b3bed)
  • ccr: client が所有する MCP 検索エイリアスを認識します (#4165) (89545fb)
  • ccr: バッファリングされた CCR アップストリーム要求をストリーミングするため、アイドル状態を強制終了するネットワークはそれをカットできません (#4206) (ca6ba34)
  • ci: リリース通知スモーク ワークフローでのピン チェックアウト (#4399) (70273db)
  • copilot: Copilot CLI >= 1.0.93 (#4450) (043fe09) の cli-main.js で COPILOT_API_URL を検出します
  • copilot: ネイティブ インライン OAuth ID を保持します (#4144) (ad62166)
  • deps: RUSTSEC-2026-0346..0349 (#4222) (132dbc7) の rustls を 0.23.46 にバンプします。
  • deps: OpenClaw Undici および狭い E2E 監査例外にパッチを適用 (#4453) (1be699f)
  • deps: には hf-xet>=1.6.0 が必要なので、ハブのダウンロードが終了時に Python をクラッシュさせることはありません (#4192) (9e5dac7)
  • deps: CVE-2026-59951 (#4239) (2f7a83a) には mcp>=1.30.0 が必要です
  • ゲートウェイ: 再ドライブの使用がマージされるときに input_includes_cache を保持する (#4423) (3f94144)
  • gemini: 圧縮時にsnake_caseのinline_dataと関数部分を保持します (#4290) (4bf1bf5)
  • image: 各 compress() 呼び出しの前に last_result をクリアします (#4341) (19c91a8)
  • 画像: JPEG として再エンコードする前に、透明な画像を白に平坦化します (#4296) (9f5cfcf)
  • インストール: Docker プリセットの書き込み可能なマウントに HuggingFace キャッシュを保持します (#4207) (#4209) (7b6cb77)
  • kompress: リモート エンドポイントが設定されている場合、ローカル モデルのダウンロードをスキップします (#4234) (ff36931)
  • kompress: 各モデルのロード ステージの時間を計り、ウォームアップ中の誤った準備完了警告を停止します (#4195) (89b229c)
  • 学習: マネージド ブロックを最後の開始マーカーに固定し、終了マーカーがない場合は追加します (#4342) (45dacc1)
  • 学習: ダイジェストのループ セクションをバジェット内に維持します (#4269) (506ba16)
  • ログ: 削除された行から省略されたレベルをカウントします (#4141) (023dd1b)
  • mcp: ラップしてインストールする JSONC オープンコード構成を受け入れ、既に受け入れています (#4297) (9202948)
  • メモリ: 埋め込み前のバインドされた取得クエリ (#4244) (8c07cf4)
  • メモリ: 付随的な CWD 散文を無視します (#4166) (3765439)
  • メモリ: ログ ストレージと SQLite の障害により、現在はサイレントに取得が失敗します (#4111) (4e6e955)
  • メモリ: 最初の 1000 レコードを超える部分 ID を解決します (#4389) (c4ea31b)
  • memory: UTF-8 形式のない cwd を (#4167) (760c05e) を発生させる代わりに未解決として扱います
  • openai: 書き込みを推論する代わりに、応答のキャッシュ_書き込み_トークンを読み取ります (#4237) (4630602)
  • openai: CCR エントリの有効期限が切れた、キャッシュされた応答ユニットを再圧縮します (#4146) (8f7b419)
  • opencode: 解析に失敗した OpenCode 構成を書き換えないでください (#4424) (0fe0a59)
  • opencode: トランスポート破棄時の環境キーの復元 (#4430) (d17bac8)
  • 価格設定: パフォーマンスを損なう litellm のプロバイダー リスト バナーを抑制します JSON (#4197) (e01ad35)
  • プロキシ: accept HEADROOM_MEMORY_INJECTION_MODE=tool (#4395) (f89c928)
  • プロキシ: client モデル文字列 (#4407) (33e5f67) をキーとするモデルごとのバインドされた状態
  • プロキシ: キャッシュされたツール圧縮結果のコピー (強化) (#4410) (a256231)
  • プロキシ: CRLF フレームの SSE ストリームからの出力トークンもカウントします (#4298) (755293d)
  • プロキシ: 失敗したターンフック再ドライブを HTTP 200 として再構築しません (#4398) (f59c8ff)
  • プロキシ: web_search ツールを使用しない応答リクエストから web_search_call 履歴を削除します (#4202) (2a70d12)
  • プロキシ: Anthropic バッチ作成でバイパス ヘッダーとライセンス ゲートを優先します (#4411) (4fd9cdd)
  • プロキシ: Bedrock ハンドラーでの実行時のインポート (#4397) (51e4ae3)
  • プロキシ: NAT64 アップストリーム アドレスを、埋め込まれた IPv4 によって判断します (#4179) (486afaa)
  • プロキシ: 入力上限に達した場合に、期間中のコストを予算台帳に保存します (#4448) (41c15b3)
  • プロキシ: 再起動後も負の圧縮節約を維持 (#4406) (bebe24c)
  • プロキシ: GitHub Copilot アップストリームのツールの延期を維持します (#4356) (217b658)
  • プロキシ: HEADROOM_LOG_LEVEL=debug で Headroom 独自のデバッグ ログを有効にします (#4137) (00093ce)
  • プロキシ: ハンドラーの失敗をログからデバッグできるようにします (#4127) (7dc20b6)
  • プロキシ: ネット ツールは、予約の保存に対してターン フックを追加します (#4057) (85520c2)
  • プロキシ: 終了イベントが完了した後に client が閉じるストリームを記録します (#4286) (762a337)
  • プロキシ: パススルー ストリームが文字の途中で終了した場合の結果を記録します (#4429) (75cfbba)
  • プロキシ: レポートは起動時に Kompress を無効にしました (#4217) (430ea4f)
  • プロキシ: キャッシュ モードで不活性として読み取り成熟度をレポート (#4198) (ba82453)
  • プロキシ: ターンフックの節約を /stats extension_ Savings に表示します。コーデックス WS (#4233) (1d112cd)
  • プロキシ: ターンフックで編集できる場合に元のメッセージのスナップショットを作成します (#4241) (df11f27)
  • 関連性: 1 つの固定スナップショットからデフォルトのエンベッダーをロードします (#4152) (f380692)
  • 節約: 共有セッションではなく、スレッド上の応答会話をキーにします (#4440) (11f743d)
  • sdk: 圧縮により Vercel AI SDK ファイルと画像部分を保存します (#4048) (1668a6c)
  • セキュリティ: 警告するだけでなく、NTFS ACL 経由で Windows ランタイム ログを制限します (#4135) (125a703)
  • smart-crusher: 監査安全な protected_patterns をエスケープされていないテキストと照合します (#4294) (e11afdb)
  • ストレージ: タイムゾーン対応の JSONL 時間フィルターを正規化します (#4063) (bf34ccf)
  • 表形式: ヘッダー名が繰り返されるテーブルを逐語的に渡します (#4278) (ed3195b)
  • テレメトリ: 空のアイテムの圧縮に安定したツール シグネチャを与える (#4396) (a79def4)
  • テレメトリ: HEADROOM_TELEMETRY=off で匿名ビーコンを停止させます (#4235) (1a40b3c)
  • 変換: 保護されたタグに対して渡されたコード ブロックのフェンスを維持します (#4292) (02958c6)
  • 変換: サイレントに「保存なし」になる圧縮エラーをログに記録します (#4092) (580cc83)
  • zcode: ヘッドルーム プロキシ自体を指すプロバイダーをスキップします (#4413) (9ac1b52)

依存関係

  • Base64 を 0.22.1 から 0.23.1 にバンプ (#4029) (8d468d4)
  • 1 つのディレクトリにわたる pip-minor-patch グループ内の 0.16.8 から 0.17.0 へのバンラフ (#4026) (de3f639)
  • 12 個の更新を含む 1 つのディレクトリにカーゴマイナーパッチグループをバンプします (#4186) (683c9a6)
  • 16 個の更新を含む npm-minor-patch グループを 2 つのディレクトリにバンプします (#4218) (07c8bbf)
  • 12 の更新を含む 3 つのディレクトリに npm-minor-patch グループをバンプします (#4219) (1f71cb3)
  • ハグフェイスハブ要件を <2.0,>=1.5.0 から >=1.5.0,<3.0 (#4027) (fcf3db8) に更新します。

コードのリファクタリング

  • 統合: asgi および litellm_callback のローカル/クラウド圧縮バックエンドを共有します (#4124) (58caafb)
  • 変換: Rust をサポートするコンプレッサー用の 1 つの CCR 永続ヘルパーを共有します (#4094) (ea947ca)
