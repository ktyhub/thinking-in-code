#ヘッドルームv0.41.0

0.41.0 (2026-10-13)

機能

  • antigravity: ネイティブ Google Antigravity IDE 統合を追加 (#3817) (cd4367b)
  • opencode: OpenCode 2.x プラグイン API (#3999) (1d4b357) をサポートします
  • プラグイン: 圧縮をアニメーション化するヘッドルーム スニップ クロード コード MOD を追加 (#3980) (17abee2)
  • プロキシ: ネイティブ支出/節約統計 + Rust プロキシ (#2321) (70b21c1) のダッシュボード
  • ルーター: max_output_tokens 条件を ModelRoute に追加します (#3898) (01185e3)
  • 節約: 履歴チェックポイントとロールアップにおけるエージェントごとの属性 (#2627) (489de46)
  • ダッシュボード、ドキュメント、llms.txt、および release note で Teams のヘッドルーム オファーを表示します (#3991) (1ad92f0)

バグ修正

  • anthropic: /api/hello 接続プローブを Anthropic (#3336) (#4059) (931e5b9) にルートします。
  • ビーコン: Cloudflare の送信者の IP アドレスのログ記録を停止します (#4018) (db983ba)

  • cli: 構成された SSL コンテキストを stdlib urlopen 呼び出しに渡します (#4011) (22d0905)

  • 副操縦士: デフォルトで GitHub のアドバタイズされた Business/Enterprise ホストを尊重します (#4155) (1dc7a18)
  • copilot: VS Code の次の編集リクエストを完了ホストに送信します (#4188) (22a1296)

  • deps: セキュリティ ワークフローに失敗した 2 つの高 npm アドバイザリ (#4004) (5a516b5) をクリアします

  • install/windows: 常時オン タスクを使用して永続サービスに戻る (#1866) (#2460) (5682883)
