#ヘッドルームv0.44.0

0.44.0 (2026-11-09)

⚠ 重大な変更

  • パッケージ化: PyTorch の追加要素をすべて含まないようにします (#4067)

機能

  • パイプライン: OutcomeSnapshot が誰のリクエストであるかを言う (#4698) (a2bcbd1)
  • プロバイダー: Herme エージェント ラップ サポートを追加 (#934) (7877241)
  • プロキシ/モデルルーター: シャドウ モードを追加 (HEADROOM_MODEL_ROUTER_LOG_ONLY) (#2395) (861ef95)
  • プロキシ: ロスレス /v1/圧縮モードを追加し、ワイヤー形状によってプロバイダーを検出します (#4617) (33f067a)
  • プロキシ: /stats Recent_requests でリクエストごとのコスト_usd を公開 (#1079) (#1565) (84cedbf)
  • プロキシ: /health および /metrics で共有 Redis ストアの可用性を公開します (#4578) (602ca65)
  • プロキシ: client 会話ごとに 1 つの会話 ID をターンフックに与えます (#4496) (94a99ed)
  • プロキシ: ダッシュボードで DeepSeek を独自のプロバイダーとしてレポートします (#2565) (9ad16a7)
  • プロキシ: トークン認証された呼び出し元にリクエストごとの /stats メタデータを表示します (#4168) (9b2dec5)
  • プロキシ: Anthropic Cloud およびローカル oMLX 用の統合マルチアップストリーム ルーティング (#4597) (f896161)
  • 節約: 履歴チェックポイントで累積的な実際の出力トークンを保持します (#2921) (8388ff5)
  • ラップ: Factory Droid の headroom wrap droid を追加 (#4143) (bb8d18a)
  • wrap: Serena コードメモリ MCP をオプトインにする (#4509) (2649835)

バグ修正

  • asgi: client が切断されるとバッファリングを停止します (GHSA-mc2f-vg4v-2fh4) (#4701) (c6d7081)
  • ビーコン: 最上位キー (#4691) (456288d) の下に許可リストを適用します
  • バイナリ: HEADROOM_BINARIES_ALLOW_UNVERIFIED=0/false でフェールクローズされました (#3218) (da6d973)
  • キャッシュ: 相対ファイル名で TTL 観測を記録します (#4711) (51d9dc5)
  • キャッシュ: 学習した TTL 上限を整数秒まで丸めます (#4710) (13347e3)
  • キャッシュ: 終了信号が到着したときにプレフィックス トラッカーの状態を保存します (#4715) (3ba4223)
  • ccr: ストリーミング フィードバック レコーダーのハッシュを小文字にします (#2313) (3912c04)
  • ci: npm パブリッシュ トークンをインストールおよびビルド ステップから除外します (#4690) (8f6366c)
  • cli: 読み取りコマンド用のアクティブなプロキシ ポートを解決します (#3522) (02c4e92)
  • content-router: trust 混合コンテンツ ヒューリスティックによる確実な HTML 検出 (#3627) (f50db67)
  • ダッシュボード: ライフタイムメトリクスと更新 (#2374) (eb9932a)
  • doctor: IPv6 ループバックおよび大文字と小文字を区別しないプロキシ ルーティング URL を認識します (#3255) (2b0315b)
  • インストール: 解析する前に Windows タスク スケジューラの XML 出力をデコードします (#3969) (#4064) (b78e07d)
  • インストール: プロキシが到達可能な場合、インストール ステータスを医師と一致させます (#3072) (#3141) (05431b2)
  • langchain: オプションの統合の可用性を確認します (#4042) (cde584d)
  • 学習: 不正な LLM 出力に対するアナライザー JSON の解析を強化します (#2471) (12864fc)
  • 学習: 学習スキャナーでオープンコード v2 セッション スキーマをサポート (#4199) (c05466a)
  • ロスレス: 純粋なパス リストのみをフォールドし、マークアップは行いません (#4716) (0ccd559)
  • メモリ: コンテキスト検索および初期化エラー時に正常に機能低下します (#3251) (#4049) (00d4f44)
  • メトリクス: Savings_by_source 行に上限を設け、残りを他の行に分割します (#4257) (2038fb2)
  • パッケージ化: PyTorch のエクストラをすべて (#4067) (a890521) から除外します。
  • プロキシ: 応答バッファリングをバイパスする --no-ccr-response-handling フラグを追加します (#3082) (#3100) (ce14271)
  • プロキシ: Bedrock Prometheus モデル ラベル (#4694) (d70a8b7) をバインドしました
  • プロキシ: 応答を転送するときに Connection によって指定されたヘッダーをドロップします (#4674) (3871b36)
  • プロキシ: コールド ターンの推論がスティッキーになるため、次のウォーム ターンではキャッシュされたプレフィックス (#4592) (3544cf5) が再利用されます。
  • プロキシ: 起動時の解決が失敗した場合に Bedrock 資格情報プロバイダーを保持します (#4705) (5438f00)
  • プロキシ: 有効期限が切れる前に Bedrock AWS 認証情報を更新します (#4696) (adc6724)
  • プロキシ: Leaked_threads メトリクスの名前を timed_out_workers_total に変更します (#3908) (bd164a2)
  • プロキシ: Response.-prefixed item および Responses SSE 状態の content-part イベントを追跡します (#4695) (8f4122f)
  • ルーター: 後続メッセージを含む可変ウィンドウ内のtool_resultブロックを圧縮します (#4717) (0511bcd)
  • ルーター: 読み取り検出で引用符で囲まれた引数内のシェル演算子を無視します (#4646) (8cdce17)
  • スクリプト: プッシュで参照のみが削除される場合、プリプッシュ フックで ci-precheck をスキップします (#4702) (cbcf8d8)
  • sdk: 圧縮を通じて Vercel AI SDK ツール結果の出力種類を保持 (#4670) (ce42754)
  • search_compressor: 行をバイト単位で入力順に保持します (#3982) (a538740)
  • スマートクラッシャー: 混合配列の辞書行と、factor_out_constants を使用した正確なドロップ数を保持します (#4692) (ced2685)
  • smart-crusher: 質問名の行を保持します (#4713) (e6e2ebb)
  • storage: JSONLStorage.get (#4675) (b25c45b) から最新のスナップショットを返します
  • 表形式: 固定幅行を二重スペースではなく列境界で分割します (#4541) (b80245e)
  • tag-protector: 引用符で囲まれていない属性内のスラッシュを自己終了として扱いません (#4681) (d5644cb)
  • タグプロテクター: マーカー モードでネストされた閉じた後も、囲んでいるタグを開いたままにします (#4682) (385d487)
  • テレメトリ: インストール ID をステートレスに保つ (#3542) (27bba79)
  • トークナイザー: chatgpt-4o-* エイリアスを o200k_base (#4672) (9648d2d) に解決します。
  • トークナイザー: HuggingFaceTokenizer.count_messages で BatchEncoding をアンラップ (#2447) (9eed58f)
  • vertex: 帯域内での Vertex エラーを説明し、モデル/領域行列を修正します (#2640) (0ddaa56)
  • wrap: クロード コードの Bedrock モードをヘッドルーム経由でルーティングします (#4316) (aa2093b)

依存関係

  • rusqlite を 0.40.2 から 0.41.1 に変更 (#4658) (74b7ac2)
  • 3 つのアップデートでカーゴマイナーパッチグループをバンプします (#4657) (c01cf07)
  • 2 つの更新を含む 1 つのディレクトリに npm-minor-patch グループをバンプします (#4650) (def4ef1)
  • click 要件を >=8.3.3 から >=8.5.0 に更新 (#4655) (ea59ac3)
  • sqlite-vec 要件を >=0.1.6 から >=0.1.9 に更新 (#4654) (de1a1e0)
  • ツリーシッター要件を <0.27,>=0.25.2 から >=0.26.0,<0.27 に更新 (#4656) (910588e)
