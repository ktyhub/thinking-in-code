MaxKB v1.8.0

マイナー 公開日2024年12月5日 出典1Panel-dev/MaxKB 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#MaxKB v1.8.0

新機能

  • アプリケーション: ユーザーが質問する際の文書や写真のアップロードをサポートします。 @liuruibin、@wangdan-fit2cloud 著、https://github.com/1Panel-dev/MaxKB/pull/1602
  • アプリケーション: ドキュメント コンテンツ抽出ノードをワークフローに追加します。 @liuruibin、@wangdan-fit2cloud 著、https://github.com/1Panel-dev/MaxKB/pull/1602
  • アプリケーション: 画像理解ノードをワークフローに追加します。 @liuruibin、@wangdan-fit2cloud 著、https://github.com/1Panel-dev/MaxKB/pull/1602
  • アプリケーション: 新しいフォーム コレクション ノードをワークフローに追加します。 @shaohuzhang1、@wangdan-fit2cloud 著、https://github.com/1Panel-dev/MaxKB/pull/1608
  • アプリケーション: ワークフローはアプリケーション ノードの埋め込みをサポートします。 @wxg0103、@wangdan-fit2cloud 著、https://github.com/1Panel-dev/MaxKB/pull/1598
  • アプリケーション: ワークフロー キャンバスは、すべてのノードの折りたたみまたは展開と、ワンクリックでのレイアウトの美化をサポートします。 @shaohuzhang1 著、https://github.com/1Panel-dev/MaxKB/pull/1644
  • アプリケーション: 基本ノードのユーザー入力パラメータでは、複数選択ボックスおよびタブ コンポーネントがサポートされています。 @shaohuzhang1 著、https://github.com/1Panel-dev/MaxKB/pull/1651
  • アプリケーション: 冒頭の発言は HTML レンダリングをサポートします。 @shaohuzhang1 著、https://github.com/1Panel-dev/MaxKB/pull/1608
  • アプリケーション: バッチでのナレッジ ベースへの会話ログの追加をサポートします。 @wxg0103 著、https://github.com/1Panel-dev/MaxKB/pull/1606
  • アプリケーション: 作成者ごとのアプリケーションの表示をサポートします。 @wxg0103 著、https://github.com/1Panel-dev/MaxKB/pull/1546
  • ナレッジ ベース: 作成者によるナレッジ ベースの表示をサポートします。 @wxg0103 著、https://github.com/1Panel-dev/MaxKB/pull/1546
  • 関数ライブラリ: 作成者別の関数の表示をサポートします。 @wxg0103 著、https://github.com/1Panel-dev/MaxKB/pull/1546
  • モデル設定: Tongyi Qianwen サプライヤーの画像理解モデルをサポートします。 @liuruibin、@wangdan-fit2cloud 著、https://github.com/1Panel-dev/MaxKB/pull/1602
  • モデル設定: OpenAI ベンダーの画像理解モデルをサポートします。 @liuruibin 著、https://github.com/1Panel-dev/MaxKB/pull/1545
  • モデル設定: Tencent Hunyuan サプライヤーの画像理解モデルをサポートします。 @liuruibin、@wangdan-fit2cloud 著、https://github.com/1Panel-dev/MaxKB/pull/1602
  • モデル設定: Alibaba Cloud Bailian サプライヤーの大規模言語モデルをサポートします。 @wxg0103 著、https://github.com/1Panel-dev/MaxKB/pull/1642
  • システム管理 (X-Pack): OAuth2 シングル サインオン方式をサポートします。 @wxg0103 より

関数の最適化

  • ナレッジベース: ドキュメントのステータスを最適化し、ベクトル化と生成の問題の進行状況の詳細を表示します。 @shaohuzhang1 著、https://github.com/1Panel-dev/MaxKB/pull/1674
  • アプリケーション: 基本ノードのユーザー入力パラメーターで、ラジオ ボタン コンポーネントはラベルとオプション値の設定方法をサポートします。 @shaohuzhang1 著、https://github.com/1Panel-dev/MaxKB/pull/1719
  • アプリケーション: 会話の詳細ページで AI 返信コンテンツに注釈を付ける場合、最後に選択したナレッジ ベース ドキュメントを保持します。 @wxg0103 著、https://github.com/1Panel-dev/MaxKB/pull/1606
  • アプリケーション: 会話ログリストの表示順序を最適化し、最新の会話時刻で降順に並べ替えます。 @wxg0103 著、https://github.com/1Panel-dev/MaxKB/pull/1645
  • アプリケーション: 会話の詳細を開いたときに、最新の会話記録がデフォルトで表示されるように最適化します。 @wxg0103 著、https://github.com/1Panel-dev/MaxKB/pull/1645

バグ修正

  • ナレッジベース: PDF ドキュメントに認識できない特殊文字が含まれている場合、ドキュメントをアップロードするときにエラーが報告される問題を修正しました。 @liuruibin 著、https://github.com/1Panel-dev/MaxKB/pull/1640
  • Knowledge Base: ステータスが「成功」のドキュメントが生成された場合、タスクが発行できない場合がある問題を修正しました。 @shaohuzhang1 著、https://github.com/1Panel-dev/MaxKB/pull/1727
  • ナレッジベース: Web サイトのエンコーディングの問題により、Web サイトのナレッジベースがテキストコンテンツを取得できない問題を修正しました。 @liuruibin 著、https://github.com/1Panel-dev/MaxKB/pull/1743
  • システム管理: ナレッジベース管理権限を持つメンバーがナレッジベースを閲覧できない問題を修正しました。 @wangdan-fit2cloud 著、https://github.com/1Panel-dev/MaxKB/pull/1740
  • システム管理 (X-Pack): アプリケーションの閲覧権限を持つメンバーがアプリケーションのアクセス構成を変更できる問題を修正しました。 @wxg0103 より
