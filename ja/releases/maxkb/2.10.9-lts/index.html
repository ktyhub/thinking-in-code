MaxKB v2.10.9-lts

バグ修正

■ ナレッジベース: 段落管理で展開した後、「位置の移動」サブメニューにマウスを移動すると、親メニューが消える問題を修正しました。 ■ ナレッジベース: PDF ファイルを含む ZIP アーカイブをアップロードした後にセグメンテーション プレビューが空になる問題を修正しました (#7436)。 ■ ナレッジ ベース: Web サイトのドキュメントをワークフロー ナレッジ ベースにインポートすると、タイトルに「/」が含まれている場合にドキュメントのタイトルが切り捨てられる問題が修正されました。 ■ エージェント: API パラメータ機能に新しいパラメータを追加すると、場合によっては履歴パラメータが上書きされる可能性がある問題を修正しました (#7638)。 ■ ワークフロー: ワークフロー エージェント、ナレッジ ベース、またはツールをインポートするときに、ワークフローとともに作成されたツールに誤った権限が与えられる問題を修正しました。 ■ ログイン認証 (X-Pack): CAS および OIDC ユーザーがログアウト後に強制的に手動ログイン ページに移動する問題を修正しました。 ■ システム: PostgreSQL をバージョンアップしました。

セキュリティ修正

■ セキュリティ: ナレッジ ワークフロー データ ソースとインポート/エクスポート機能におけるセキュリティの脆弱性が修正され、不正なツールの実行とクロスワークスペース ファイルの読み取りが可能になりました (GHSA-5545-9jgw-jg2g)。 ■ セキュリティ: oss/file の広範すぎる未認証許可リストにより、未認証ユーザーが共有 SKILL ツール (GHSA-mgph-cpg8-q442) のソース コードをダウンロードできるというセキュリティ脆弱性を修正しました。 ■ セキュリティ: ファイル削除 API の認証エラーにより、一般ユーザーがワークスペース間で SKILL パッケージを削除したり、許可なくナレッジ ベースのドキュメントを削除したりできるというセキュリティの脆弱性を修正しました (GHSA-99pv-fgf7-cjcf)。 ■ セキュリティ: シリアライザーがファイルの所有権を検証しないため、ユーザーがワークスペース間でファイル属性を改ざんしたり、プライベート ファイルをコピーしたりできるというセキュリティの脆弱性が修正されました (GHSA-v4wr-86mr-6c9x)。 ■ セキュリティ: 「改善された回答」API が会話の所有権を検証しないというセキュリティの脆弱性が修正され、他のユーザーの会話コンテンツへのクロスアプリケーション アクセスが可能になりました (GHSA-mfq-j2m8-252j)。 ■ セキュリティ: 共有チャットのファイル アクセス許可を取り消すことができず、共有リンクが削除された後もファイルが匿名でダウンロード可能なままになるセキュリティ脆弱性を修正しました (GHSA-7ghm-84fr-gw57)。 ■ セキュリティ: ログインしているユーザーが他のユーザーのデバッグ会話にメッセージを送信し、その回答を受信できるというセキュリティの脆弱性を修正しました (GHSA-39qj-6jrm-7mh8)。 ■ セキュリティ: アプリケーション ワークフローのユーザー入力フィールド設定を介したスクリプト インジェクションを許可し、アカウント乗っ取りにつながる可能性がある保存済み XSS セキュリティの脆弱性を修正しました (GHSA-jx58-5g66-wmp9)。 ■ セキュリティ: カスタム ツール「Init Param」シークレットがモデルに表示されるツール スキーマ (GHSA-52xf-4m64-j6f9) で公開されるセキュリティ脆弱性を修正しました。 ■ セキュリティ: イメージ生成ノードがプロバイダーのイメージ URL サーバー側を要求し、SSRF やクラウド認証情報の盗難の可能性を引き起こすセキュリティ脆弱性を修正しました (GHSA-8jvr-m365-hfm8)。 ■ セキュリティ: html_render の window.jump が URL をフィルタリングせず、オープン リダイレクトと XSS (GHSA-7q5v-5c8i-25wh) を引き起こすセキュリティ脆弱性を修正しました。 ■ セキュリティ: form_rander の動的フォーム テーブル項目で eval() を使用すると、メインオリジン XSS (GHSA-f78q-8qg9-2mr4) が発生するセキュリティ脆弱性が修正されました。 ■ セキュリティ: 画像からビデオへのワークフロー (GHSA-636h-95x9-7j9f) で、パブリック チャット画像 URL がサーバー側リクエスト (SSRF) をトリガーするセキュリティ脆弱性を修正しました。 ■ セキュリティ: ワークフロー フォーム ノードでエスケープされていない form_data が XSS (GHSA-jmm8-mpw4-xp9r) の保存につながるセキュリティ脆弱性を修正しました。 ■ セキュリティ: 匿名チャット ユーザーがモデル プロバイダー API キーを読み取ることができるセキュリティ脆弱性 (GHSA-467c-v7p7-c2j7) を修正しました。 ■ セキュリティ: 「関連質問のバッチ生成」API がナレッジ ベースの編集権限を検証せず、読み取り専用ユーザーが無許可の操作を実行できるというセキュリティの脆弱性を修正しました (GHSA-9278-wqwm-vfcg)。
