MaxKB v2.4.0

マイナー 公開日2025年12月11日 出典1Panel-dev/MaxKB 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

MaxKB v2.4.0

セキュリティ脆弱性の修正

  • システム ファイルの上書きによって引き起こされる権限バイパスの問題を修正しました (CVE-2025-66446)。
  • 特定の同時条件下で発生する権限バイパスの問題を修正しました (CVE-2025-66419)。 上記の脆弱性を発見し、すぐに MaxKB オープンソース コミュニティに報告してくれた GitHub ユーザー @yck99、@NikoCat233、および @Threonine に感謝します。

新機能

  • ナレッジベース: ワークフローナレッジベースを追加しました。
  • ツール: データ ソース ツールを追加しました。
  • ツール: ツール ストアのツールは、「ツール」と「データ ソース」の 2 つのタイプをサポートしています。
  • モデル: AWS プロバイダーは、ビジョン モデルと再ランキング モデルのサポートを追加しました。
  • モデル: OpenAI、Ollama、vLLM、Xinference、および Zhipu AI プロバイダーのビジョン モデルは、ビデオ理解機能をサポートします。
  • モデル: Docker AI プロバイダーからの大規模言語モデル、ベクトル モデル、再ランキング モデルのサポートが追加されました。
  • アプリケーション: ファイルアップロード設定にアップロード方法として「URL アドレス」を追加しました。
  • アプリケーション: 概要ページの監視統計に「ユーザー消費トークン」と「ユーザーの質問数」のランキング統計を追加しました。
  • リソース認可: アプリケーション、ナレッジベース、ツール、モデルをリソースごとにユーザーに認可する際に、ロールによるユーザーのフィルタリングをサポートしました。
  • ログイン認証 (X-Pack): SAML2 ログイン認証方法を追加しました。

機能の最適化

  • アプリケーション: 高度なアプリケーションの AI 会話ノードの生成されたプロンプトには、アプリケーション名と説明情報が含まれなくなりました。
  • アプリケーション: AI モデルが MCP ツールを呼び出すときのリクエスト パラメーターの出力をサポートしました。
  • アプリケーション: 高度なオーケストレーションでノードをループ本体にコピーするためのショートカット キーの使用がサポートされています。
  • ツール: ツール、MCP、データ ソースの 3 種類のリソースのインポートをサポートしました。
  • ツール: ツール ストアのエントリをツール リストに調整しました。
  • ツール: システム組み込みツールを削除し、ツール ストアに移動しました。

バグ修正

  • Q&Aページ: ループ本体内のナレッジベース検索ノードの検索結果がナレッジソースに表示されない問題を修正しました。
  • アプリケーション: 実行の詳細におけるループ ノードの実行時間の誤った表示を修正しました。
  • アプリケーション: 文書タグ取得ノードで変数値が空の場合の不正な取得結果を修正しました。
  • ナレッジベース: 置き換え後に元のドキュメントをダウンロードした後に開けなくなる問題を修正しました (#4397)。
  • モデル: Alibaba Cloud BaiLian プロバイダーからの qwen-image モデルの生成エラー (#4376) を修正しました。
  • モデル: Azure OpenAI プロバイダーから gpt-5-codex モデルを追加するときのエラーを修正しました。
  • モデル: vLLM モデルの一部のパラメーターの誤った設定を修正しました (#4403)。
  • 役割: ワークスペース管理者と一般ユーザーに許可された「バージョン情報」権限が有効にならない問題を修正しました。
  • 会話ユーザー (X-Pack): 会話ユーザー クエリ インターフェイスに重要でない情報が表示される問題を修正しました。
  • API ドキュメント (X-Pack): API ドキュメント内のいくつかの不正確な説明を改訂しました。
