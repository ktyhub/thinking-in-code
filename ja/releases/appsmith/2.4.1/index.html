appsmith v2.4.1

パッチ 公開日2026年9月17日 出典appsmithorg/appsmith 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#アプリスミスv2.4.1

🔐 セキュリティ

  • Databricks JDBC 接続 - Databricks データソース URL が検証され、Databricks ドライバーを介して直接接続されるため、Databricks 以外の JDBC URL は拒否されます。 (#42244)
  • CVE-2026-75595 に対処するために、netty-handler を 4.1.136 から 4.1.137 に更新しました。 (#42217)
  • UQI フィルタリングで WHERE 句の列名が検証されたため、untrusted 識別子は SQL 列名として使用できなくなりました。 (#42224)
  • AI および Google Sheets プラグインで強化された WebClient ビルダーを使用しました。 (#42177)
  • 報告された脆弱性に対処するために、client とサーバーの依存関係を更新しました。 (#42214、#42173、#42218)

🛠️ 信頼性

  • OpenAI、Anthropic、Google AI プラグインが競合する spring-webflux コピーをロードできないようにしました。この障害により AI クエリがダウンし、共有 Redis 接続が破損する可能性があります。 (#42240)
  • 冗長なセグメント API 呼び出しを削減しました。 (#42216)

✨ 新機能と機能強化

  • 自動化のための非対話型 appsmithctl restore を追加しました。 (#42147)

🎨 UI とウィジェットの改善

  • Anvil アプリケーションを「AI エージェント」として提出するのをやめ、名前を「レスポンシブ」に変更しました。 (#42219)

🔧 Git、デプロイメント、構成

  • MCP サーバーは、両方が設定されている場合、APPSMITH_MONGODB_URI よりも APPSMITH_DB_URL を優先するようになりました。 (#42239)
  • 基本イメージ apt インストールは、一時的なミラー障害に対する回復力を備えています。 (#42221)
