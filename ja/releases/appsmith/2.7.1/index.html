appsmith v2.7.1

#アプリスミスv2.7.1

⚠️ アップグレードに関する重要な注意事項

  • 埋め込み許可リスト: APPSMITH_ALLOWED_FRAME_ANCESTORS は、CSP frame-ancestors ソース式のリストである必要があります。その形式ではない保存された値は、次回の再起動後に 'self' として提供されます。設定を保存すると、無効な値は拒否されます。 (#42622)
  • Git ページ名: ページ名が単一のパス セグメントではない場合、Git はアプリをコミットしません。まずそのページの名前を変更します。ページを作成したり、そのような名前にページ名を変更したりすることは拒否されます。 (#42633) v2.7.0 より前のバージョンからアップグレードする場合
  • Helm チャート: いくつかの probes キーを設定すると、設定しなかったキーには新しいデフォルト (10 秒の期間、5 秒のタイムアウト) が適用されます。 failureThreshold を古い 60 年代にチューニングした場合は、periodSeconds: 60 も設定します。正の整数ではないプローブ値は、helm install および helm upgrade で失敗するようになりました。 "5" などの引用符で囲まれた番号は引き続き機能します。 (#42571)
  • パラメータ値にドットが含まれている場合でも、存在しないページ名への navigateTo は「有効な URL またはページ名を入力してください」で失敗するようになりました。以前は、名前を https://OldPage?file=report.pdf などの Web アドレスとして公開していました。ドット付きパラメータを持つ intranet などの 1 単語のホストも失敗するようになりました。代わりに完全な URL を使用してください。 (#42513)

🔐 セキュリティ

  • テーブル CSV のダウンロードでは、セルをスプレッドシートの数式として実行できなくなりました。セルはテキストとして保存されます。 Excel のダウンロードに変更はありません。 (#42569)
  • アクションの検証中にデータソースを使用できるユーザーを変更するには、そのデータソース上でアクションを作成する権限が必要になりました。単一のアクションを作成または更新するには、これがすでに必要でした。 (#42601)
  • フレーム祖先設定は、CSP ソース式のみを受け入れます。無効な保存値は 'self' として提供されます。 (#42622)
  • Git の書き込みと削除は、そのアプリのリポジトリ内に残ります。ページ名は単一のパス セグメントである必要があります。 (#42633)
  • ページの依存関係マップを更新するには、そのページを編集する権限が必要になりました。 (#42642)

🛠️ 信頼性

  • OAuth2 認証コード ログインでは、トークン交換にデータソースの自己署名証明書が使用されるようになりました。以前は、このステップでは設定が無視され、トークン URL でプライベート証明書が使用されているとログインに失敗していました。 (#42605)
  • 複数のデータソースまたは JS ライブラリが同時に作成された場合、アプリをインポートしても新しいデータソースまたは JS ライブラリはドロップされなくなりました。 (#42612)
  • MCP は、独自の統合で更新されたクエリを保持します。クエリを別のタイプのデータソースに移動しなくなりました。 (#42620)
  • これらのデータソースはパラメーターをバインドしないため、MCP は Redshift または Snowflake 上のクエリに値を追加しません。 (#42617)

✨ 新機能と機能強化

  • ファイルピッカーのアップロード ダイアログは、アプリの HTML 言語に従います。サポートされていない言語または空の言語は英語のままです。 (#42572)
  • MCP 構造化 SQL は、PostgreSQL および Redshift で日付、週、月、四半期、または年ごとに日付をバケット化し、最大 6 つの集計を返し、個別の行を選択できます。 (#42608)
  • MCP 構造化 SQL はテーブルを結合し、CASE と WITH を使用できます。 (#42619)
  • MCP は、保存された SQL または REST クエリを別のページまたは別のアプリにコピーできます。クエリ テキストはサーバー上に残ります。 (#42624)
  • MCP は、既存の SMTP データソースに電子メール クエリを作成できます。 MCP で構築された JavaScript は、日付をフォーマットしてログ エントリを書き込むことができます。 (#42638)

🎨 UI とウィジェットの改善

  • 通貨入力には、ベラルーシ ルーブル (BYN)、ベネズエラ ボリバル (VES)、ザンビア クワチャ (ZMW) が追加されます。古いコード BYR、VEF、および ZMK はリストに残ります。 (#42445)
  • 1 つのボタンを含むボタン グループは、すべての角で角の半径を維持します。 (#42250)
  • テーブル セルのアイコン ボタンとビデオ コントロールの高さは再び 30 ピクセルになり、余分な垂直パディングがないため、選択した行数がそのまま収まります。 (#42615)
  • テキスト フィールドが 1 つあり、送信ボタンがない JSON フォームで Enter キーを押しても、ページがリロードされなくなりました。 [送信] ボタンは以前と同様に機能します。 (#42607)
  • JSON フォームでは、[境界線の半径] ボタンと [ボックスの影] コントロールにより、保存されたオプションが強調表示されます。 (#42292)
  • [管理者設定] → [ブランディング] では、インスタンス ロゴの SVG が提供されなくなりました。 PNG と JPG はサーバーで許可されているため、受け入れられます。 (#42637)
