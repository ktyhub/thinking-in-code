#アプリスミスv2.4

🗑️ 機能削除のリマインダー - 2026 年 9 月 30 日 - EOL

Appsmith AI は、このリリースから 3 週間後の 2026 年 9 月 30 日にサポートが終了します。

v2.3 で発表されたように、新しい Appsmith AI データ ソース接続やクエリを追加することはできなくなりました。現在お持ちのものは、2026 年 9 月 30 日まで引き続き機能します。その日以降は、アップグレードしたかどうかに関係なく、すべての Appsmith AI データソースは機能しなくなります。

その日より前に、残りの Appsmith AI クエリを直接プロバイダー データソース (OpenAI、Anthropic、または Google AI) に移行します。このリリースでは、3 つのプロバイダーすべてで利用可能なモデルのリストが更新されるため、現在のモデルに移行できるようになります。 (#42114)

⚠️ アップグレードに関する重要な注意事項

  • 管理設定シークレット - GET /api/v1/admin/env によって返される機密値はマスクされ、編集可能な MongoDB および Redis URL フィールドは読み取り専用の接続ステータスに置き換えられます。管理者 API からこれらの値を読み取るスクリプトまたはオートメーションを更新します。マスクされた値を送信すると「変更されていない」ものとして扱われるため、既存の構成が保持されます。 (#42169)
  • AI データソースの応答 — OpenAI、Anthropic、Google AI データソースに現在のモデルがリストされるようになりました。手動で入力した最新のモデル ID を使用して保存された Anthropic クエリが completion を読み取る場合、バインディングの更新が必要になる場合があります。 (#42114)

✨ 新機能と機能強化

  • Appsmith MCP サーバー (ベータ) — 互換性のある AI client が構造化ツール API を通じて Appsmith アプリケーションを構築および編集できるようにする、オプトインの組み込み モデル コンテキスト プロトコル サーバー。エージェントは、生のウィジェット DSL、SQL、JS、または {{ }} バインディングを作成することはありません。エージェントは、サーバーが呼び出し元自身の権限に基づいてコンパイルするツールを呼び出します。 MCP サーバーのセットアップ → (#42185、#42187、#42190、#42193、#42208、#42210、 #42212)
    • デフォルトではオフ、新規インストールでもアップグレードでも同様です。v2.4 にアップグレードしても、エージェント エンドポイントは公開されません。セルフホスト: 管理者設定 → インスタンス → MCP サーバー (ベータ版) → 有効化 → 保存して再起動。カスタム組織名を持つ Appsmith Cloud アカウントでは、代わりに 組織 でそれが有効になります。
    • **管理者設定 → プロファイル → MCP キー の ユーザーごとのキー。キーは client を そのユーザー として認証し、追加のアクセス許可を付与しません。キーの有効期限は 30/60/90/180/365 日 (デフォルトは 30) で、ユーザーごとに取り消されていないキーの数は 10 に制限されます。シークレットは、作成時またはローテーション時に 1 回だけ表示されます。サーバーを無効にすると、既存のキーは拒否されますが、取り消されません。
    • 破壊的な操作には人間の承認が必要です。ターゲットとその現在のコンテンツ リビジョンに関連付けられた 1 回限りの確認による prepare_* → confirm_* ハンドシェイクを通じて行われます。
    • Git に接続されたアプリはゲートされます。 ミューテーションでは、アプリの現在のブランチに名前を付ける必要があり、git の状態を読み取れない場合はフェールクローズする必要があります。エージェントは予約された mcp/ ブランチ名前空間内でのみコミットし、すべてのエージェントのコミットには除去不可能な [mcp] プレフィックスが付けられます。
    • オペレーターメモ: mcp/ ブランチの作成またはコミットの確認は、インスタンス デプロイ キーを使用して git リモートにプッシュします。そのため、ブランチのプッシュを監視しているリモート CI および Webhook は mcp/* 参照で起動されます。
  • MSSQL 読み取り専用接続 - SQL Server Always On 展開の読み取り可能なセカンダリ ルーティングを含む、ApplicationIntent=ReadOnly による読み取り専用モードが追加されました。 (#41668)
  • 評価値ヘルパー — ポップアップの配置が改善され、永続的なコンパクトな折りたたみビューが追加されました。 (#42128)

🤖 AI の改善

  • 現在の GPT、Claude、Gemini モデルの OpenAI、Anthropic、Google AI データソース モデル検出を更新しました。 (#42114)

🎨 UI とウィジェットの改善

  • ウィジェット イベントをクリアした後の古い JavaScript lint エラーを削除しました。 (#42130)
  • カスタム ECharts 構成の null 値によってページ評価が中断されるのを防止しました。 (#42145)
  • 大きなカスタム ウィジェット JavaScript 構文エラーによるビルダーのクラッシュを防止しました。 (#42198)
  • 従来の選択、複数選択、およびツリー選択ウィジェットの必須フィールド マーカーを復元しました。 (#41927)
  • 「すべてのユーザーにサインアップを許可する」フォーム ログイン ラベルを切り替えたときに一貫性を保ちました。 (#42167)

🛠️ 信頼性

  • ブロッキング データソース操作を共有サーバー スレッドから移動し、制限された SMTP および SSH タイムアウトを追加しました。 (#42159)
  • アクション検証中の重複したデータソース ルックアップとポリシー更新を削除しました。 (#42138)

🔐 セキュリティ

  • サーバー側で共有カスタム JavaScript ライブラリ識別子を派生し、ライブラリ マニフェストを返す前にアプリケーションの読み取り権限を強制しました。 (#42108、#42131)
  • アプリケーションの更新リクエストにより、資格情報を含むエクスポートまたはフォーク動作が有効になるのを防ぎました。 (#42113)
  • Git ルートがアプリケーションを解決する前、または保存された Git 認証情報を使用する前に、アプリケーションの読み取り権限を強制します。 (#42121)
  • OAuth データソース フローがリクエスト ホストと一致しないオリジンにリダイレクトされるのを防止しました。 (#42146)
  • 代替 IPv4、IPv6、および IPv4-in-IPv6 表現の制限付きホスト チェックを強化しました。 (#42132)
  • 報告された脆弱性に対処するために、client、サーバー、可観測性、バンドルされたツール、およびベースイメージの依存関係を更新しました。 (#42103、#42110、#42075、#42154、#42183、#42200)

🔧 Git、デプロイメント、構成

  • ローカル ブランチのないリポジトリに対する Redis ベースの Git ブランチ同期が改善されました。 (#42176)
  • レプリカ セットの起動チェックで、serverMonitoringMode=poll などの新しい MongoDB URI オプションを受け入れることができるようになりました。 (#42188)
