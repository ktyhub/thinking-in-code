appsmith v2.7.0

マイナー 公開日2026年11月12日 出典appsmithorg/appsmith 英語原文

#アプリスミスv2.7.0

⚠️ アップグレードに関する重要な注意事項

  • Helm チャート: いくつかの probes キーを設定すると、設定しなかったキーには新しいデフォルト (10 秒の期間、5 秒のタイムアウト) が適用されます。 failureThreshold を古い 60 年代にチューニングした場合は、periodSeconds: 60 も設定します。正の整数ではないプローブ値は、helm install および helm upgrade で失敗するようになりました。 "5" などの引用符で囲まれた番号は引き続き機能します。 (#42571)
  • パラメータ値にドットが含まれている場合でも、存在しないページ名への navigateTo は「有効な URL またはページ名を入力してください」と失敗するようになりました。以前は、名前が https://OldPage?file=report.pdf などの Web アドレスとして開かれていました。ドット付きパラメータを持つ intranet などの 1 単語のホストも失敗するようになりました。代わりに完全な URL を使用してください。 (#42513)

🔐 セキュリティ

  • 報告された脆弱性に対処するためにバンドルされた依存関係を更新しました。 (#42502)
  • アプリのカスタム JS ライブラリを読み取るには、そのアプリへの読み取りアクセスが必要になりました。 (#42431)
  • アプリケーションをフォーク可能にする をオンにするには、アプリのエクスポート権限が必要になりました。編集アクセス権を持つユーザーは、これをオフにして他の変更を加えることができます。 (#42411)
  • S3 互換データソースと DynamoDB データソースは、REST、GraphQL、Elasticsearch、Redis、SMTP をすでにカバーしている制限付きホスト ポリシーに従うようになりました。エンドポイントホストがブロックされているデータソースは、Host not allowed. (#42527) で保存、テスト、または実行に失敗します。

🛠️ 信頼性

  • Git に接続されたアプリを削除すると、アプリが削除されるとすぐに元に戻ります。その後、ローカル リポジトリのクリーンアップが実行されるため、ディスクが遅いために削除がタイムアウトになり、アプリ カードが所定の位置に残されることがなくなりました。 (#42519)
  • MCP read_pages は、すべてのページに対して layoutId を返します。並列ページ読み取りはトークン チェックによって拒否されなくなり、失敗した読み取りは 1 回再試行され、それでも失敗するページはその理由を報告します。 (#42360、#42529)
  • MCP は、壊れた、または間違った結果をもたらす入力を拒否します。例: wire_event 呼び出し引数の不均衡な中括弧、レイアウト ツールの別のアプリのページ、SQL キーワードのような名前の列の構造化 SQL フィルター。 (#42536、#42537)
  • エージェントがページを読み取った後にページが変更された場合、MCP レイアウトの更新は拒否されます。 (#42538)

✨ 新機能と機能強化

  • 表の自動高さ: 表の 高さ を 自動高さ (または 制限付き自動高さ) に設定し、ページごとの行数を選択します。表はそれらの行に合わせて拡大され、表の代わりにページがスクロールします。既存のテーブルは 固定のままです。 (#42489、#42585)
  • [アプリ設定] → [ナビゲーション] には、共有を表示 と すべてのアプリを表示 の切り替えがあり、公開されたアプリでこれらのボタンを非表示にします。どちらもデフォルトでオンになっています。共有権限は変更されません。 (#42487)
  • ページのエクスポート (ページ メニュー → エクスポート) には、JS オブジェクト、データベース、クエリ、カスタム ライブラリのすべてのセクションで すべて選択 があります。 (#42453)
  • ボタン グループのボタンには、ボタン ウィジェットと同様にツールチップを表示できます。 (#42583)
  • JSON フォームには、[スタイル] → [色] で タイトルのフォントの色 設定があります。 (#42565)
  • MCP 構造化 SQL は、coalesce を使用して NULL 列のフォールバック値を表示できます。 (#42497)
  • MCP 構造化 SQL は、having を使用して集約グループをフィルタリングできます。 (#42503)
  • MCP 構造化 SQL は、PostgreSQL で区切り文字で区切られた列を分割し、各項目をカウントできます。 (#42504)
  • MCP get_action は、エディターで変更した人がいない限り、MCP が作成したクエリの SQL を返します。 (#42505)
  • 新しい MCP ツール set_page_visibility は、ページを非表示または表示します。ホームページを非表示にすることはできません。 (#42506)
  • MCP ナビゲート イベントは、選択された行の ID などの URL パラメータを渡すことができます。 (#42507)
  • ページまたはクエリの削除と同様に、MCP を介してウィジェットを削除するにはユーザーの承認 (prepare_remove_widgets、confirm_remove_widgets) が必要になりました。 (#42509)
  • MCP JS オブジェクトは、行を並べ替え、切り取り、合計、平均、グループ化し、日付を日、週、月ごとにバケット化できます。 (#42511)
  • MCP は、条件付きフォームを構築できます。これは、選択、日付の計算、あるケースでは表示または必須のフィールド、フォームが有効になるまで無効になる送信ボタン、およびサインインしているユーザーの名前または電子メールに依存するデフォルトと制限です。 (#42540)
  • MCPはエディタで書かれたJSオブジェクトを読み込むことができます。承認が設定されている場合は、ユーザーの承認後に承認を置き換えることができます。 (#42538)
  • MCP は、JS オブジェクトを読み取り可能なフォーマットされたコードとして書き込みます。 (#42549)
  • MCP 構造化クエリは、Oracle 上で実行可能な本体を生成し、MongoDB クエリで厳密な値を使用します。 (#42538)

🎨 UI とウィジェットの改善

  • テーブル CSV および Excel のダウンロードでは、生の HTML ではなく、HTML 列のプレーン テキストが書き込まれます。 (#42557)
  • 表セルのアイコン ボタン、メニュー ボタン、およびビデオ コントロールが行の高さに適合するため、ページ分割された表で最後の行に到達するためにスクロールバーが必要なくなりました。 (#42570)
  • テーブルの無限スクロールをオフにしても、行の追加を許可、検索、フィルター、並べ替えはオンになりません。オンにするまでオフのままです。 (#42573)
  • テーブルの [保存/破棄] 列の [無効] フィールドに、完全なバインドが再び表示されます。編集しても、すべての行で保存/破棄が有効になりません。 (#42589)
  • JSON フォームをリセットすると、空の配列フィールドは空のままになるため、フォームは有効なままになります。 (#42226)
  • JSON フォームの必須日付フィールドは、他のフィールドと同様に、ユーザーがタッチした後にのみエラーが表示されます。 (#42514)
  • ワークスペース ロゴ ピッカーは、サーバーが常に拒否した SVG を提供しなくなりました。 JPG ファイルを選択できるようになりました。 (#42594)
  • エディターは、廃止された Appsmith AI データソースとそのクエリを非表示にします。サービスは 2026 年 9 月 30 日に停止されました。Ask AI には影響はありません。 (#42559)

🔧 Git、デプロイメント、構成

  • Helm チャートのヘルス プローブは、5 秒のタイムアウトで 10 秒ごとに実行されるようになりました。 Startup では 600 秒間起動でき、liveness では 180 秒の障害後にコンテナーが再起動され、readiness では 30 秒後にポッドが準備完了としてマークされます。管理設定を保存してサーバーを再起動しても、コンテナーが強制終了されなくなりました。 (#42571)
  • バックアップでは、APPSMITH_BACKUP_EXCLUDE_COLLECTIONS (カンマ区切り) にリストされている MongoDB コレクションをスキップできます。 (#42581)
  • サーバーは、期限切れまたは取り消されたキーなど、MCP トークンを拒否した理由をログに記録します。秘密をログに記録することはありません。 (#42593)
