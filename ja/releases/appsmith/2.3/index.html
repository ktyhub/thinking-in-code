#アプリスミスv2.3

🗑️ 機能の削除 - 2026 年 9 月 30 日 - EOL

<img width="1213" height="306" alt="画像(2)" src="https://github.com/user-attachments/assets/5630ce25-4c46-48b8-8fe1-cd8c315d7d77" />

バージョン 2.3 にアップグレードすると、新しい Appsmith AI データ ソース接続やクエリを追加できなくなります。現在お持ちのものは、2026 年 9 月 30 日まで引き続き動作します。それ以降は、アップグレードしたかどうかに関係なく、Appsmith AI データソースは動作しなくなります。

✨ 新機能と機能強化

  • カスタム ウィジェット用のネイティブ AI コパイロット — カスタム ウィジェットにネイティブ AI コパイロット機能を追加しました。 (#42063)
  • Ask AI for Community Edition — Ask AI アシスタントを Community Edition に導入しました。 (#42065)。 https://docs.appsmith.com/build-apps/how-to-guides/use-ask-ai
  • カード ウィジェット — コンポーザブル ボディ キャンバスでエンティティを表示するための新しいカード ウィジェットを追加しました。 (#42026)。詳細については、https://docs.appsmith.com/reference/widgets/card をご覧ください。
  • ボタン ウィジェットのラベル スタイル - ボタン ウィジェットにラベル スタイル オプションを追加しました。 (#41998)
  • キーボード ナビゲーション - キーボード タブ ナビゲーションを改善するために、標準ウィジェット全体に共有 tabOrder プロパティを追加しました。 (#41895)
  • HTML 言語属性 - HTML lang 属性のカスタマイズのサポートが追加されました。 (#41593)
  • Git リポジトリ チェック — Redis に保存されている Git リポジトリの健全性チェックを追加しました。 (#41970)

🤖 AI とアシスタントの改善

  • AI アシスタントのタイムアウト — 信頼性を向上させるために、AI アシスタント プロバイダーのタイムアウトを増加しました。 (#42096)
  • カスタム ウィジェット AI フィードバック — カスタム ウィジェット AI アシスタントのフィードバックとエラー処理が改善されました。 (#42095)
  • Ask AI CE の強化 — CodeRabbit のレビューを受けて、Ask AI Community Edition の実装を強化しました。 (#42092)
  • Appsmith AI の非推奨 — 新しい Appsmith AI データソースの作成をブロックし、非推奨のバナーを追加しました。 (#42015)

🔐 セキュリティ

  • データソース認証バイパス - アプリケーションのインポートおよびフォーク操作中に非表示のデータソースが再利用される可能性がある脆弱性を修正しました。 (#42066)
  • Git インポート パス トラバーサル — 任意のファイルの読み取り/書き込みにつながる可能性がある、Git インポート中のシンボリック リンク ベースのパス トラバーサルを防止しました。 (#41993)
  • 権限グループのセキュリティ — 権限グループを割り当てるときにワークスペースの境界を強制します。 (#42023)
  • データソース承認 — ユーザーが認証されていない実行のために別のワークスペースのプライベート データソースを公開することを防ぐためのアクションの作成/更新承認を修正しました。 (#42018)
  • データソース ネットワーク アクセス — データソース アクセスをインスタンス自身のネットワーク アドレスに制限します。 (#41985)
  • Frame Ancestors Security - 過度に寛容な埋め込みポリシーを防ぐために、デフォルトのワイルドカード frame-ancestors を削除しました。 (#42012)
  • 事前認証電子メール セキュリティ — 事前認証電子メール エンドポイントからの応答を標準化し、未使用のルートを削除しました。 (#41996)
  • テナント エンドポイント セキュリティ — 匿名ユーザーのテナント応答から内部構成の詳細を削除しました。 (#42001)
  • ログイン オープン リダイレクト — ログイン中の偽造 Origin ヘッダーによって引き起こされるオープン リダイレクトを防止しました。 (#41995)
  • アクチュエータのセキュリティ — 内部パスワードが設定されていない場合、アクチュエータの基本認証を防止しました。 (#41964)
  • SMTP TLS 検証 — SSRF で検証されたアドレスへの接続を維持しながらホスト名を検証することにより、SMTP TLS 検証が改善されました。 (#42060)
  • Caddy レート制限 - trusted client IP を使用し、trusted プロキシを制限することにより、レート制限が改善されました。 (#42071)
  • サーバーとプラグインの CVE - Docker Scout スキャンによって特定されたサーバーとプラグインの JAR 脆弱性を修正しました。 (#42074)
  • npm セキュリティ アップデート — 重大な node-tar DoS 脆弱性 (CVE-2026-59873) に対処するために、npm を 11.18.0 にアップグレードしました。 (#42064)
  • tar セキュリティ更新 — CVE-2026-59873 に対処するために、tar 解決策を ^7.5.19 に更新しました。 (#42034)
  • 依存関係のセキュリティ更新 — 報告された複数の脆弱性に対処する適用された依存関係の更新。 (#42091、#42051、#42049、#41969、#41965)

🔧 Git とバージョン管理

  • Git エラー メッセージの改善 — 一般的なメッセージを表示するのではなく、失敗の実際の原因を明らかにするために、Git エラー処理を更新しました。 (#42053)
  • Git インポートの最適化 — 兄弟ブランチ エンティティのインポートを、インポート中に必要なフィールドのみに制限します。 (#41972)
  • Git リリースの安定性 — リリースの問題を引き起こしていた孤立したレガシー Git コントローラーを削除しました。 (#41974)

🎨 UI とウィジェットの改善

  • アプリケーション テーマの権限 — 編集モードでアプリケーション テーマを読み取るときに必要な編集権限。 (#42090)
  • バナーの位置 - バナーのオフセットを修正しました。 (#42073)
  • アプリケーションにコピー — ドロップダウンのスクロールを修正し、コピー モーダルでのデータソース ノートの表示を改善しました。 (#42007)
  • テーブル ウィジェット — メニュー ボタンの列幅を修正しました。 (#41948)
  • テキスト ウィジェット リンク - mailto:、tel:、および ftp: リンクが誤って変更される問題を修正しました。 (#41997)

🛠️ 信頼性、テスト、開発者の経験

  • Cypress API インターセプト — cy.log が原因で失敗する統合 API インターセプト フックを修正しました。 (#42069)
  • ファイルピッカーの評価 — ファイルピッカーのバイナリ データがアクションの実行に渡されるときに保存される兄弟パラメータ。 (#42021)
  • MSSQL 検証 — 接続文字列区切り文字を含む MSSQL データベース名を拒否しました。 (#42077)
  • Intl Linting — 誤った Intl is not defined lint エラーを修正しました。 (#42080)
  • JDBC の信頼性 - JDBC 接続に Hikari キープアライブと制限付きソケット タイムアウトを追加しました。 (#41851)
  • 電子メール設定テスト — 電子メールの HTML 本文を待ってから続行することで、テストの信頼性が向上しました。 (#41893)
  • Client Build CI — 変更されたファイルを判断する際の「引数リストが長すぎます」エラーを防止しました。 (#42050)
  • MongoDB エラー処理 - 既存のトーストがクリアされるのを待ってから再度チェックすることで、繰り返される MongoDB レプリカ セット エラーの処理が改善されました。 (#41963)

🏢 権限と設定

  • 自動コミット承認 - ターゲット アーティファクトの Auto Commit Pro 設定を読み取る前に承認チェックを追加しました。 (#42083)
  • 匿名追跡 - block-anonymous-tracking フラグが client とサーバーの両方で一貫して尊重されるようにしました。 (#41973)
  • 使用状況追跡 — セグメントが匿名ユーザーに対してブロックされている場合、使用状況追跡用に匿名ユーザー ID が保存されます。 (PR番号は記載されていません)
