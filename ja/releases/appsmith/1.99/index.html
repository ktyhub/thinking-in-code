appsmith v1.99

マイナー 公開日2026年4月16日 出典appsmithorg/appsmith 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#アプリスミスv1.99

修正

  • インポートによって公開された layoutOnLoadActions が破損するのを防止しました。 (#41737)
  • wrapCode の 自動セミコロン挿入 (ASI) がリファクタリングの失敗を引き起こすのを防止しました。 (#41727)
  • persistentVolume オブジェクトから余分な nfs フィールドを削除しました。 (#41724)
  • 新しいパッケージ URL を使用するように BetterBugs 録画リンクを更新しました。 (#41667)
  • cleanup-dp ワークフローの PAT を GITHUB_TOKEN に置き換えました。 (#41699)
  • スクロールバー選択ウィジェットに関するスタイルの問題を修正しました。 (#41656)
  • スーパー ユーザー作成の競合状態を防止しました。 (GHSA-9wcp-79g5-5c3c) (#41681)
  • send-test-email SMTP ホスト検証によって SSRF がブロックされました。 (GHSA-vvxf-f8q9-86gh) (#41666)
  • 重大な CVE-2025-70952 を修正しました。 (#41673)
  • CVE-2026-33937 を解決するために、handlebars を 4.7.9 にアップグレードしました。 (#41672)
  • Spring Security HTTP ヘッダーが書き込まれなかった CVE-2026-22732 を軽減しました。 (#41669)
  • createdAt フィールドが欠落している場合でもデータソース クエリが失敗しない問題を修正しました。 (#41665)
  • 目に見えない Unicode 文字を削除するために、保存時にユーザーの電子メールを正規化しました。 (#41664)
  • OAuth2 コールバック データソース ルックアップで ACL 権限チェックを強制しました。 (GHSA-rg2x-4v4h-g78w) (#41640)
  • DROP TABLE より前の フィルター一時テーブル名 を検証しました。 (#41642)
  • 安全でない文字列連結によって引き起こされる、ArangoDB プラグインでの AQL インジェクション を防止しました。 (#41641)
  • SSRF 保護を強化するために メタデータ拒否リスト を拡張しました。 (GHSA-9m89-5jw7-q5cr) (#41643)
  • 強化された 管理環境値 escaping。 (#41637)
  • ManualUpgrades の URL をサニタイズして、XSS の反映を防ぎます。 (#41636)
  • アプリケーション スナップショットの削除に 編集権限 を適用しました。 (GHSA-g2hc-wmw2-32jr) (#41624)
