QwenPaw v2.0.1

パッチ 公開日2026年7月24日 出典agentscope-ai/QwenPaw 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#クウェンパウv2.0.1

何が変わったのか

✨ 追加しました

PawApp プラットフォーム

  • PawApp SDK & Kanban App: プラグインで QwenPaw 上にリッチなインタラクティブ UI を構築できる新しいミニアプリ プラットフォーム。プロジェクト管理用の組み込みかんばんタスク ボード アプリが付属 (#6150) カスタム エージェント モード
  • ユーザー編集可能なエージェント モード: カスタム エージェント ループ モードをコンソールから直接作成および編集します。コードに触れることなく、反復制限、停止条件、および承認ゲートを定義します (#6270)
  • Oh-My-Paw プラグイン: マルチエージェントのコラボレーションと長時間実行タスク用の 5 つのすぐに使用できるエージェント ループ (UltraQA、Ralph、Ultrawork、Autopilot、Team) (#5882) メモリと可観測性
  • ReMe Light インデックスのメンテナンス: コンソール ボタンまたは API による明示的なインデックスの再構築、起動時の自己修復の改善、大きなドキュメント向けの Markdown チャンクの最適化 (#6235)
  • ReMe の信頼性の向上: ランタイム メモリ統計検査、CJK 埋め込みの安全性、およびバックグラウンド サマライザの正常なシャットダウン (#6098)
  • ReMe インデックス作成保護機能: 強化された構成検証とインデックス作成の安定性 (#6153)
  • Langfuse トレースの強化: フィルタリングと分析を改善するために、トレースにユーザー ID、セッション ID、パッケージ バージョンが含まれるようになりました (#5922)
  • 履歴保持設定: スクロール コンテキストの保持日数をコンソールから設定できるようになりました (#6214) コンソールとデスクトップ
  • チャットのアーカイブ: セッション リストをクリーンな状態に保つために古い会話をアーカイブします (#6078)
  • ドラッグ アンド ドロップ ファイル アップロード: デスクトップ アプリのチャット入力領域にファイルを直接ドロップします (#6327)
  • プラグイン マーケットの並べ替え: ダウンロード、更新時間、またはお気に入りによってプラグインを並べ替えます (#6349)
  • One-click エージェント構成コピー: 単一の click を使用してエージェント構成を複製します (#6262)
  • 構成可能なログ ローテーション: 構成からログ ファイルのローテーション制限を設定します (#6183) セキュリティとガバナンス
  • Windows 制限付きトークン サンドボックス: 追加のサンドボックス オプションの Windows 制限付きトークンを介してコード実行が分離される (#5931)
  • ガバナンス ルール: より詳細なアクセス制御のための新しいガバナンス ルール定義 (#6215)
  • 機密ファイルの検出: より多くのファイル タイプが機密ファイルとして検出されます。非機密パスに対してグローバル ファイルの読み取りがデフォルトで許可されるようになりました (#6067) ランタイムとマルチエージェント
  • マルチエージェント起動制御: コンソールの部分準備インジケーターによる制限付き起動同時実行 (#6198)
  • サイレント cron 配信: スケジュールされたタスクは、通知なしでサイレントに結果を配信できます (#6080)
  • イベント メタデータの保存: プラグインと拡張機能のメタデータは、リアルタイム出力エンベロープを通じて伝送されるようになりました (#6224)
  • Readiness Probe: ヘルスチェックおよびコンテナオーケストレーション用の新しい /api/healthz エンドポイント (#6028)
  • Trusted プロキシ認証: trusted プロキシを検証し、ロード バランサーの背後にあるデプロイメントの実際の client IP を解決します (#6030) CLI
  • gh CLI がガバナンスで許可されました: GitHub CLI コマンドがガバナンス ポリシーによって許可されるようになりました (#6031)

🔄 変更されました

  • デフォルトの ReAct ループはファーストクラス DefaultMode としてモデル化され、各モードにライフサイクルとゲートの明示的な所有権が与えられます (#6210)
  • コアから分離された ACP スラッシュ コマンド、スタンドアロン モジュールに抽出された安全性チェック、および統合されたブートストラップ フロー (#5796)
  • チャネルのツール呼び出しとツール結果の表示に個別の切り替えコントロールが追加されました (#6233)
  • ToolGuard 検出ルールは、統合評価のためにガバナンス ポリシー エンジンにブリッジされるようになりました (#6390)
  • DEFAULT_USER_RULES 自動同期では手動のホワイトリストが必要なくなりました (#6025)
  • ツール承認ボタンは、「常に許可」コントロールに executionLevel の代わりに toolSource を使用するようになりました (#6095)
  • 冗長な思考ループと重複したツールの呼び出しを削減するために最適化されたエージェント推論 (v2.0.0.post4)

🐛 修正済み

デスクトップ

  • デスクトップ アプリが終了前にバックエンドを正常にシャットダウンするようになり、メモリの損失や不完全なクリーンアップが防止されます (#6225)
  • デスクトップのマークダウン リンクは、アプリ ウィンドウをナビゲートするのではなく、システム ブラウザーで開くようになりました (#6300)
  • Monaco エディターは、オフライン コーディング プレビュー用にローカル バンドルからロードされます (#6291)
  • WKWebView は古いコンソール フロントエンド バージョンを固定しなくなりました (#6107)
  • Tauri のアップデートは OSS ビルドのみに制限されています (#6071) ランタイムとエージェント
  • ストリーミング中に推論コンテンツが新しい推論ブロックで正しく回転するようになりました (#6310)
  • ツール呼び出しの引数は、完全な応答をバッファリングするのではなく、段階的にストリーミングされます (#6343)
  • サブエージェントの承認がルート セッションから正しくルーティングおよび解決されるようになりました (#6295)
  • Oh-My-Paw 並列ワークフローをブロックする入力検証エラーを修正しました (#6395)
  • 停止したタスクは、完了を通知する前に適切なクリーンアップを待機するようになりました (#6347)
  • バックグラウンド チャットが適切に登録されています。レガシー ランナーが削除されました (#6272)
  • 推論出力とツールセグメントが正しく配置されるようになりました (#6280)
  • リクエストごとのモデルのオーバーライドが適切に受け入れられるようになりました (#5731)
  • 不正なツール呼び出し入力が自己修正のためにモデルに表示されます (#5761)
  • 誤検知を減らすために Doom ループのしきい値を微調整しました (#6184)
  • 推論モデルには max_completion_tokens を使用します (#6015)
  • ストリーミング思考/テキストデルタの空白が正しく保存される (#6166)
  • モデル情報の検索が失敗したときに、マルチモーダル モデルの画像が削除されなくなりました (#6154、#6217) コンソールと UI
  • ツールの出力コピーは、非 HTTPS (#6275) を含むすべてのブラウザー コンテキストで機能します。
  • マーケットからインストールした後、スキルリストが自動的に更新されます (#6296)
  • ワンタイムツールの承認がセッションレベルの設定より優先されるようになりました (#6357)
  • 受信トレイのバッジには、高/重大なものだけでなく、すべての保留中の承認の数が表示されます (#6391)
  • 古いメディア プレビュー エラーが解消されます。相対パス画像が正しく処理されました (#6385)
  • ループ テンプレートとチャット履歴のダーク モード テキストのコントラストが改善されました (#5975)
  • プロバイダー検索入力時にブラウザーの自動入力がトリガーされなくなりました (#6011)
  • セッションが削除されたときにチャット メッセージ キューが正しくクリアされるようになりました (#6045)
  • スキルページのスクロール読み込みが最初のバッチ後に停止しなくなりました (#5968) ガバナンスとセキュリティ
  • 無効化された監査ログが適切に受け入れられるようになりました (#6369)
  • プラグイン ツールはアンロード時に登録解除されます。 ToolGuard の安全性チェックがコンテキスト間で正しく共有されるようになりました (#6311)
  • Oh-My-Paw ワークフロー モードの分離は、ワークスペースごとのインスタンスとフォーク/全拒否ゲートの修正により強化されました (#6317)
  • プラグイン ツールは登録時にデフォルトで更新されます。ツールタイプの検証が追加されました (#6313)
  • @tool_descriptor および PluginApi 経由でツール自動登録 (#6190)

  • フロントエンド ツール ガード ルールがポリシーのディープ スキャンにブリッジされるようになりました (#6063)
  • サンドボックスはシェル実行時に venv PATH を保持します (#6081)
  • sandbox_enabled スイッチがオフモードのサンドボックス パスで尊重される (#6109)
  • Sudo コマンドがユーザーに適切に許可を求めるようになりました (#6079) メモリ
  • 外部ユーザーのクエリのみに制限された自動メモリ (#6120)
  • auto_memory_interval を 0 に設定すると、自動メモリを無効にすることができます (#6135)
  • 夢スケジュール切り替え追加(#6171)

  • ドライバーの移行中に ${VAR} ヘッダーが env 資格情報参照に移行されました (#6091)
  • レガシー MCP 移行はスキーマ ウォーターマークを介してワンショットで行われました (#6133)
  • MCP アクセス ポリシーの更新はすぐに適用されます (#5949)
  • ワークスペースの起動が MCP 接続タイムアウトによってブロックされなくなりました (#6174)
  • OpenAI 準拠のためにサニタイズされた MCP ツール名のフォールバック名前空間 (#6209) CLI とチャンネル
  • cron update は、変更されていないランタイムおよびリクエスト フィールドを保持するようになりました (#6236)

  • cliストリーミング出力を接続するときのTUIクラッシュを修正 (#6069) 可観測性
