QwenPaw v2.2.2

パッチ 公開日2026年10月15日 出典agentscope-ai/QwenPaw 英語原文

#クウェンパウv2.2.2

何が変わったのか

✨ 追加しました

コンソールとワークスペース

  • ライブ プレビューと保存された設定を使用して、6 つのテーマ パレットとカスタム カラーと角の半径を追加します (#7741)
  • 各会話の作業ディレクトリを備えた認証済みのマルチタブ端末をチャット内に追加します (#7861)
  • コンソールのフォント サイズをチャットと設定全体で 12 から 20 ピクセルに調整できるようにします (#8005)
  • マルチフォルダー ワークスペースを今後のタスク用にエージェントのデフォルトとして保存 (#7789)
  • プレビューとダウンロードを容易にするために、エージェントによって配信されたファイルをその応答のすぐ下に表示します (#7750)

QwenPaw-フラッシュ

  • QwenPaw-Flash 9B、27B、および 35B-A3B をローカルで推奨: 9B 推奨を更新し、27B および 35B-A3B オプションを追加 (#8155)

パウポート

  • PawPort を追加して、互換性チェックと選択的再試行を使用して、サポートされている会話、メモリ、スキル、プラグイン、MCP 設定、プロジェクト、スケジュールされたタスクを Codex および Qoder からインポートします (#6960)

QwenPaw 作成者とデータ

  • Creator を 2.0.1 にアップグレード: メディア制作前にスクリプトを確認し、手動再生成によって有料のダウンストリーム ステップがトリガーされないようにして、停止したプロジェクトを回復します (#8121)
  • 統合された分析ワークスペース、インタラクティブな説明、インライン HTML レポート、チャット チャネルの /data および /datasource コマンドを備えた QwenPaw データを 0.3.0 にアップグレードします (#7637)

モデルとメモリ

  • 候補モデル プール、会話ごとのモデル、思考コントロールを使用して、モデルの検出、価格設定、選択を統合します (#7899)
  • カスタム プロバイダーの名前、エンドポイント、プロトコル、および API キーを 1 つのダイアログで構成します (#7826)
  • コンソールで ReMe 検索の再ランキングを構成します (モデル、エンドポイント、候補乗数、タイムアウトなど) (#6399)

ハブ

  • 一元管理された組織モデル、メンバー トークンの予算、使用状況ダッシュボード、招待ベースの登録を備えたハブ モデル ゲートウェイを追加します (#7779)
  • Docker SDK (#7696) を使用しないローカルのみの展開を含む、コマンド ラインからの最初のハブ管理者の初期化のサポート

スキル、ツール、自動化、チャネル

  • view_audio ツールを追加して、エージェントが既存の文字起こしパイプラインを通じて音声ファイルを理解できるようにします (#8083)
  • プレーンテキストの命令と選択したモデルを使用してスケジュールされたタスクを構成し、中断後に履歴を保存し、受信トレイからタイムアウト結果とセッションを検査します (#7776)
  • スキルプールから選択したスキルをバッチでワークスペースに配布します (#7852)
  • 組み込みチャンネルだけでなくカスタムチャンネルにもスキルを割り当てることができるようになりました (#7782)
  • QwenPaw、ClawHub、ModelScope、Aliyun (#8128) などのスキル マーケット ソースをプラグインとしてインストールまたは削除します
  • フェイシュウに折りたたみ可能な思考パネルを追加し、オプションで生成後の自動折りたたみ機能を追加 (#7685)
  • サポートされていない場合はフォールバックを使用して、マークダウン テーブルを返信および完了したストリーム内のネイティブ Telegram リッチ メッセージとしてレンダリングします (#7713)

🔄 変更されました

  • コンソールでのモデル設定と選択のインタラクションを改善しました (#8017)
  • 設定のナビゲーションと検索を改善し、より明確なランタイム構成タブを追加し、会話をスムーズに切り替えます (#7956)
  • メモリ コマンドを /reme <action> key=value に統合し、/dream、/memorize、/reme_status を置き換えます (#7444)
  • ビジュアル圧縮を古い会話履歴に制限し、最新の 2 つのユーザー ターンを保存し、recall_context (#7703) で元のパッセージを取得します
  • リクエストごとに完全な履歴データベースのチェックを繰り返すことを避けることで、長い会話の遅延を軽減します (#7639)
  • 時間、ソース、またはグループ化されていないビューを使用して会話履歴を再設計し、小さな画面でより多くのスペースを確保し、より豊富なセッション詳細を表示し、会話 ID をコピーします (#7665、#7688、#7788、#7846)
  • デフォルトで会話リストにソース グループ化を使用します (#7972)
  • チャットファイルドロワーを右側に移動(#7704)
  • チャットの依存関係と言語リソースをオンデマンドでロードすることで、最初のコンソールのダウンロードを削減します (#7829)
  • タスク パネルが展開されている間のみバックグラウンド ツールの出力をストリーミングし、アイドル状態の接続を削減します (#7831)
  • Make Skill を、より信頼性の高い計画、引数の検証、評価ガイダンスを備えた 2.1 にアップグレード (#7753)
  • 既存のテレメトリ同意およびオプトアウト設定を尊重しながら、エージェントが実行するときにスケジュールされたタスクを含む実行時アクティビティを毎日レポートします (#7802)

🐛 修正済み

パウポート

  • PawPort インポートが失敗したときに正確なアセットと原因を表示し、失敗したアイテムを再試行できるようにします (#7953)

コンソール、チャット、ファイル

  • UUID セッション ID (#8144、#8146) を割り当てる HTTP デプロイメントでチャット ターミナル タブを動作させ続ける
  • ウィンドウが狭い場合でもチャット入力コントロールを使用できるようにします (#8145)
  • 会話が履歴から復元された後も、エージェントによって送信されたファイルが表示されたままになります (#7949)
  • メッセージの読み込み中にユーザーが会話間のナビゲーションを中断できるようにします (#8214)
  • メッセージの重複処理を防ぐために、リプレイされた QQ ゲートウェイ イベントを無視します (#8006)
  • キューに入れられたメッセージを元のエージェントと会話にバインドしたままにし、チャットの作成や履歴の読み込みが遅れてナビゲーションやキャンセルが中断されるのを防ぎます (#7382)
  • 長いテキストをチャットに貼り付けるときに未送信の下書きを保存する (#8119)
  • 応答を停止した後、中断されたツール呼び出しを実行状態のままにするのではなく、正しくマークするようにしました (#7345)
  • アシスタントの応答タイムスタンプと応答アクションの正しい可視性を復元 (#7851)
  • 新しいセッションを開く代わりに、現在の会話で /compact を実行します (#7834)
  • 未保存の編集を保持しながら、再度開くかアクティブ化すると、キャッシュされたテキストと CSV タブを更新します (#7902)
  • スキル プールのダウンロードをリクエスト パスから移動し、未完了の一時ファイルをクリアします (#8055)
  • 現在のページネーション状態を失わずに、展開されたファイル ディレクトリを更新します (#8149)
  • コンソール release note およびマークダウン ファイル プレビューで LaTeX 数式をレンダリング (#7909)
  • ローカル サービスが再び利用可能になった後、リロード試行を早期に使い切ることなく、失敗したコンソール コードのダウンロードから回復します (#8154、#8219)
  • プロジェクト ディレクトリの選択をより明確にし、ブラウザから直接ディレクトリを適用できるようにしました (#7897)
  • API 応答が小さくなり、スキル リスト要求の回復力が向上することで、低速ネットワークでの負荷が改善されました (#7917)
  • バックグラウンドのポーリングを制限し、リクエストが遅い場合でもモデル ピッカーの応答性を維持します (#8221)
  • モデルルーティングの変更を他のエージェント設定と一緒に保存 (#7747)
  • 継承された思考設定を正しく表示し、空のモデル プールから直接モデルを選択できるようにし、新規インストールに Kilo フリー モデルのデフォルトを提供します (#7920)
  • ベトナム語とブラジル系ポルトガル語の言語選択を復元 (#7752)
  • リロード後もサイドバーの折りたたまれた状態を保持する (#7681)
  • 設定の色とメニューのタイポグラフィをコンソールの残りの部分と一致させます (#7682、#7805)
  • リンク上に表示されるキーボード フォーカス インジケーターを復元 (#7759)
  • エージェント設定の PawPort エントリを復元する (#7770)

モデル、ランタイム、セキュリティ

  • EXIF 回転データを含む画像のサイズを変更するときに写真の向きを維持する (#8136)
  • モデルの解決されたコンテキスト制限に対してハブ モデル設定を検証します (#8168)
  • キャンセル理由を表示したままにし、ツールが停止したときにエージェント ループを継続します (#8183)
  • プロバイダーが解決したコンテキスト ウィンドウを尊重して、早期の会話圧縮を回避します (#7652)
  • 会話トランスクリプトのタイムスタンプを表示するときに夏時間対応のタイムゾーンを使用する (#8050)
  • ツールによって返された PDF が、マルチモーダル モデルを含むチャット完了モデルへの後続のリクエストを中断しないようにします (#7636)
  • プロバイダーが会話履歴でサポートされていない input_audio コンテンツを拒否した場合に回復します (#7886)
  • モデルが画像またはその他のメディア ペイロードを拒否した後、拒否されたブロックを毎ターン再生するのではなく、会話を回復します (#8010)
  • テキストのみのモデル (#8190) を含む、選択したモデルの解決された機能に従って履歴画像をフィルター処理します。
  • 厳密な検証が明示的に有効になっていない限り、Responses API モデルのオプションのツール パラメーターはオプションのままにしておきます (#7915)
  • モデルプロバイダーによって使用される新しい GPT トークン制限パラメーターを受け入れます (#8090)
  • エージェントのトークンバジェットアカウンティングとループ警告を修正し、ストリーミング応答の開始時のコンテキストオーバーフローから回復します (#7748)
  • 古いメディアとツールの結果を早期に再利用して、長時間の会話がモデル コンテキスト ウィンドウ内に留まるようにします (#7965、#8193)
  • ループ保護により、新たなツール呼び出しが繰り返されずにタスクが終了することを防止します (#7919)
  • 重複または断片化された ACP 応答を防止し、異なるツール引数形式を持つ外部ランナーに対してワークスペース保護を適用します (#7783)
  • trusted セッションでの不必要なプロンプトを回避するために、プロトコルで定義された種類によって ACP 権限の選択を認識します (#7732)
  • サービスとして実行するとき、またはコンテナ内で実行するときにユーザーがインストールしたコマンドライン ツールを検索する (#7057)
  • ストリームを閉じるときにプロバイダーが停止した後にモデル応答を回復する (#7960)
  • Windows シェル コマンドが QwenPaw サーバーを終了するコンソール制御イベントを伝播するのを防ぎます (#7910)
  • 必要な場合にのみ初期化コードをロードすることで、コマンドラインの起動時間を短縮します (#8004)
  • 接続ネゴシエーションを中断せずに圧縮された MCP エラー応答を処理する (#7787)
  • Unix システムで既存のキーを読み取るときに、過度に広範なマスター キー ファイルのアクセス許可を制限する (#7699)
  • スキル名をインストール パスとして使用する前に検証します (#8065)
  • NaN および無限の数値入力に対してサーバー エラーの代わりに検証エラーを返す (#7677)

メモリ、ハブ、展開

  • ハブ招待の引き換えが失敗した場合の具体的な理由を表示する (#7952)
  • 接続の枯渇を避けるために、トランザクション後にハブ データベース接続を閉じます (#8038)
  • Windows デスクトップのシャットダウンを含む正常なシャットダウン中に保留中のメモリ ジョブを終了できるようにします (#7760)
  • 破損した履歴検索インデックスを修復し、会話履歴を破棄せずに保持クリーンアップを回復します (#7655)
  • 履歴データベースの書き込み、バックアップ、復元を強化し、中断または失敗した操作後のデータ損失を軽減します (#6459)
  • 受信トレイ通知で、空のエラー詳細を持つ失敗したメモリ ジョブと成功した空の結果を区別する (#7756)
  • 失敗したバックエンドの変更をロールバックした後にメモリ ランタイムを復元する (#7893)
  • 設定を保存するとき、または接続をテストするときに、埋め込みサービスのタイムアウトを一貫して検証します (#7758)
  • 50 件を超える保留中の電子メールを処理する前に確認を要求し、3 回連続で失敗した場合は一時停止し、受信トレイの再開コントロールを使用します (#7690)
  • タイムアウト レースを通じて承認の決定を維持するため、保留中のツール リクエストが一貫して解決されます (#8188)
  • ハブ ローカル ランタイムの初期化、CLI アクセス、永続ワークスペースを修正し、正しいモデル制限で認証された PawApp アクセスを復元します (#7833)
  • ハブでメンバー トークンの権限を確認するときに管理者がオーバーライドすることを優先する (#8169)
  • Hub パーソナル ランタイム プロキシを介してファイル プレビューを復元する (#7766)
  • ログイン試行と拒否されたランタイム作成を Hub 監査ログに記録します (#7683)
  • 内部サーバーエラーを返さずに、中断されたプラグインカタログのダウンロードを処理します (#7763)
  • バンドルされた omp-roles スキルがインストールされているように見えても使用できない場合に、そのスキルのロードを復元します (#7922)
  • PawApp ストリーミング リソースを確実に解放し、キャンセルによってタスクが無期限に待機状態になるのを防ぎます (#7488)
  • アプリケーションが正しく起動できるように、デスクトップ パッケージにコンソール チャネルを含めます (#7816)
  • デスクトップ ペットが有効な場合にツール リクエストの承認と拒否を復元します (#7933)
  • Docker とデスクトップ ビルドで同じ固定アプリケーション Python ランタイムを使用する (#7751)
  • QwenPawを起動した端末が閉じた後に繰り返される出力エラーを停止 (#6569)
