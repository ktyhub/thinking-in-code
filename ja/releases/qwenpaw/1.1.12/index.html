QwenPaw v1.1.12

#クウェンパウv1.1.12

何が変わったのか

✨追加しました

コンソール

  • モデル ページのオーバーホール: プロバイダーの集約、統合カード UI、レイアウトの再設計 (#5203)
  • シンプル モード: フラット ナビゲーションと更新時間ごとにソートされたセッション リストを備えたシンプル モードを追加 (#5222)
  • ワイド モード切り替え: 拡張チャット レイアウト用のワイド モード切り替えを追加 (#5212)
  • ターンごとのトークンの使用法: ターンごとのトークンとコンテキストの使用法ポップオーバーを追加 (#5130)
  • ユーザー入力キュー: ユーザー入力キューを追加します (#5158)
  • タイトルによるセッション フィルター: タイトルによるセッション フィルターを追加します (#5178)
  • 構文の強調表示: すべてのビューにわたるコード ブロックの構文の強調表示を追加します (#5219)
  • ベトナム語: 完全なベトナム語 (vi) インターフェース言語サポートを追加 (#5186)
  • フォールバック メッセージ: 応答出力が空の場合にフォールバック メッセージを表示します (#5232) スキル
  • スキル マーケットの更新: スキル マーケットを更新し、QwenPaw プラットフォームを含め、UI を改善します (#5123)
  • スキルスラッシュインジェクト: スキルスラッシュインジェクトと表示を改善 (#5146) チャンネル
  • 元宝の引用メッセージ: 引用メッセージをサポートし、メディア ダウンロード パイプラインを統合します (#5160)
  • Yuanbao ボット フィルタリング: ボット メッセージ フィルタリングと環境変数のサポートを追加 (#5150)
  • ノンブロッキング フラッシュ: すべてのチャネルの適応スロットルを備えたノンブロッキング フラッシュ (#5215)
  • DingTalk Liveness Watchdog: システムのスリープ後にストリームを回復するための liveness watchdog を追加 (#5224) デスクトップ
  • ポートの永続性: localStorage を保持するために、再起動後もバックエンド ポートを永続化します (#5051)
  • ポート設定: デスクトップ ポート設定のサポート (#5272) ファイル
  • ファイル プレビュー: ファイル プレビューのエラー処理を改善し、FileResponse (#5115) を使用します。 CI
  • リリース検証ゲート: ビルドと公開の間にリリース検証ゲートを追加します (#5121) 可観測性
  • Langfuse エージェント ループ: エージェント ループごとに langfuse 観察をグループ化します (#5128)

🔄変更されました

  • リクエスト ペイロード変換: リクエスト ペイロード変換 (#5188)
  • メモリ検索スタイル: メモリ検索ツールの結果スタイルをリファクタリングします (#5154)
  • Xiaoyi デュアル WebSocket: デュアル WebSocket への接続をリファクタリングし、使用できないチャネルを修正します (#5274)
  • カレンダー日付のグループ化: セッション リストの日付グループ化にカレンダー日付を使用します (#5257)

🐛修正済み

セキュリティ

  • キーチェーン マスター キー: インストールごとにキーチェーン マスター キーを分離 (#5028) デスクトップ
  • Windows コンソール クラッシュ: Windows コンソール クラッシュおよび自己終了コマンドから保護します (#5192)
  • Tauri Windows CI: crates.io フェッチの失敗に対する Tauri Windows CI の強化 (#5125)
  • プラグインの依存関係: Tauri サイドカーにインストールされているプラグインの依存関係を修復します (#5260)
  • セッション ファイル名: セッション ファイル名の重複とデスクトップのエージェント間通話の失敗を解決します (#5036) コンソール
  • セッション リダイレクト: コード モードを切り替えるときのセッション リダイレクトを修正しました (#5147)
  • パネル レンダリングの折りたたみ: メモリ構成の損失を防ぐためにパネルの折りたたみを強制的にレンダリングします (#5144)
  • 承認コマンドのオーバーフロー: 水平方向のオーバーフローを防ぐために、承認コマンドのテキストを単語区切りで囲みます (#5176)
  • ツール カードのロード: シェル コマンドおよび未登録ツール用のツール カード ロード スピナー (#5141)
  • ブラウザ オートコンプリート: プロバイダー検索入力時のブラウザ オートコンプリートを無効にする (#5112)
  • Dream Cron: ドリーム ジョブを無効にするには、dream_cron を空のままにしておきます (#5256) プロバイダーと構成
  • PRO タブのローカル プロバイダー: ModelSelector の PRO タブにローカル プロバイダー (ollama/lmstudio) を表示します (#5113)
  • ディープ コピー キャッシュ: キャッシュされたエージェント構成のディープ コピーを確保します (#5229) コンテキストとエージェント
  • 空のメッセージ ガード: LightContextManager.pre_reply の空のメッセージ リストをガードします (#5038)
  • ミッション クラッシュ: 破損したloop_config.json / prd.json (#5000) でのエージェントのクラッシュを防止します。 ローカルモデル
  • Llama.cpp バージョン: 固定幅スライスを使用しない llama.cpp サーバー バージョンを解析します (#5035) MCP
  • OAuth IndexError: OAuth 検出における空の authorization_servers での IndexError を回避します (#5194) メモリ
  • Chromadb 非同期プローブ: chromadb Rust バインディング用の非同期ランタイム プローブを追加 (#5271) 双子座
  • ツール スキーマのサニタイズ: 関数呼び出し時の 400 INVALID_ARGUMENT を防ぐためにツール スキーマをサニタイズします (#5226) ツール
  • Raw Decode: raw_decode を使用して、パラメータなしのツール呼び出しでの偽の「余分なデータ」警告を沈黙させます (#5220)
  • タイトル生成: すべてのモデル プロバイダーをサポートするために、タイトル生成とスキルの最適化にフォーマッタを使用します (#5228) インストール
  • 安定版 PyPI デフォルト: デフォルトは安定版 PyPI リリースのみ (#5269) パック
  • OpenSSL ピン: デスクトップ起動の失敗を修正するために openssl<3.5.7 をピン留めします (#5100)

⚡ パフォーマンス

  • 不要なコピーの削除: エージェント構成内の不要なディープ コピー操作を削除します (#5240)

🏗️ インフラストラクチャ

  • リリース義務チェックリスト: 雑務リリース義務チェックリスト (#5105)
  • ツール カード タイトルの切り詰め: ツール カード タイトルを省略記号付きの 1 行に切り詰めます (#5119)
  • Datapaw エージェント メニュー: エージェント スイッチの Datapaw エージェント メニューを更新します (#5114)

🧪 テスト

  • Sprint 2.4 テスト: Sprint 2.4 cron 実行およびツール API テストを追加 (#5201)

📖 ドキュメント

  • ベトナム語 README: ベトナム語 README (README_vi.md) (#5245) を追加
  • ロードマップの更新: ロードマップの更新 (#5277)
