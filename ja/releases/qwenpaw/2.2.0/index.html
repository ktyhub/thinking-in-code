QwenPaw v2.2.0

マイナー 公開日2026年9月3日 出典agentscope-ai/QwenPaw 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#クウェンパウv2.2.0

何が変わったのか

✨ 追加しました

QwenPaw ハブ

  • ローカルプロセスまたはDockerランタイム、ワークスペースレベルのアクセス制御、資格情報管理、およびリバースプロキシサポートを備えたマルチユーザーQwenPawハブを自己ホストします(#7112)

QwenPaw データ

  • 耐久性のある分析ワークスペース、パッケージ化されたランタイム、および 1 つのコマンドを備えた QwenPaw データをネイティブ PawApp として展開します。Docker Compose の例 (#6940、#7190)

QwenPaw メール

  • リアルタイム監視、検索、スレッド対応アクション、送信者の許可/拒否ルール、不明な受信者に対する人間による承認を備えたインテリジェントなメール アシスタントを追加します (#6800)
  • Mail MCP をデスクトップ アプリにバンドルして起動する (#7170)
  • メール ツールの応答を中国語の会話で読み取れるようにする (#7303)

モデルとプロバイダー

  • 統合プロバイダー検出、機能を認識したルーティング、フォールバック ポリシー、思考制御との一貫性を高めたモデルのセットアップと選択を行う (#6302)
  • Volcengine エージェント プランと MiMo V2.5 プロバイダーを追加し、更新された Volcengine カタログ (#6515)
  • プロンプトキャッシュヒットと書き込みオブザーバビリティをトークン使用法に追加 (#7342)

QwenPaw クリエイター

  • クリエイター 1.1.0 は、主流プロバイダー全体で画像とビデオの生成を拡張し、計画されたダイアログを生成プロンプトに組み込むことでナラティブ ビデオを改善します (#7167)
  • クリエーター 1.1.1 は、記録された Web サイトとデスクトップ操作、Bailian Wan3 ビデオ生成、および構成可能な自動ビデオ品質チェックを追加します (#7274)

コンソールとワークスペース

  • サブエージェントの会話をグループに整理し、完了および未読ステータスを表示します (#7035、#7275)
  • コンパクトなタスク リストと一貫した実行追跡により、バックグラウンド作業を追跡しやすくします (#7083、#7319)
  • 応答アーティファクトを表示し、生成されたメディアを直接ダウンロード可能にします (#7161、#7036)
  • ワークスペース UI からシステム プロンプト ファイルを選択 (#7078)
  • ワークスペース UI からフォルダーを作成し、ファイルをコピーします (#7151、#7314)
  • プロジェクト ディレクトリのスコープを各セッションに設定し、同時作業で異なるルートを安全に使用できるようにします (#6976)
  • モデルとツール呼び出しの傾向、エージェントごとの内訳、および全エージェント ビュー (#7207、#7219) を使用してトークンの使用状況を拡張します。
  • 最大化されたウィンドウの QwenPaw OS ドックを自動的に非表示にする (#7233)
  • エディターのタブがオーバーフローした場合のナビゲーションを改善しました (#6983)
  • 非表示の推論テキストを含めずにアシスタントの応答をコピーします (#7448)

スキル、チャネル、メディア

  • AnySearch を Web SearchProvider および MCP サービスとして統合 (#7081)
  • スキルを検索して一括で有効または無効にします (#7140、#6990)
  • より高速なファイル読み込み、よりクリーンなバインディング、組み込みの自動更新 (#7097、#7232) により、スキルを最新の状態に保ちます。
  • アプリ、プラグイン、スキルを 1 つのマーケットプレイスで管理 (#6880、#7017、#7235)
  • コンソールをリロードせずに新しくインストールした PawApps を開く (#7238)
  • CLI (#6943) から対話的にプラグイン チャンネルを設定します
  • エージェント MCP アクセス ルールにカスタム チャネルを含める (#7225)
  • Matrix グループのセッションとメモリを送信者ごとに分離し、一時的なログイン失敗の場合は再試行します (#7001、#7109)
  • 設定時に DingTalk グループが会話コンテキストを共有できるようにします (#7208)
  • DingTalk ワイドスクリーン カードの自動レイアウトを構成する (#7416)
  • エージェントの処理前に OneBot メディアをローカルにダウンロードする (#6715)
  • コンピュータに関連ウィンドウを監視させます (#7037)
  • 必要に応じて、モデルに送信する前に特大画像のサイズを変更します (#7294)
  • コンソール停止リクエストをアクティブなエージェントツールに伝播します (#7349)
  • 完了したアシスタントプロセスメッセージを自動的に折りたたむ (#7374)

🔄 変更されました

  • ワークスペースの起動を高速化するために、永続的なドライバーを同時に開始します (#7174)
  • 長い応答時のストリーミング オーバーヘッドを削減します (#7244、#7239)
  • リクエスト間で再利用可能なプロンプト キャッシュ プレフィックスを安定化しました (#7346)
  • マークダウンを多用した長時間のチャットの応答性を維持する (#7176)
  • マークダウン リストに、より狭くて一貫した間隔を使用します (#7317)
  • ReMe ランタイム ダッシュボードと長期記憶ガイダンスを改善しました (#6984、#6997)
  • スケジュールされたジョブが変更されていない場合の通知の送信を停止する (#7115)
  • 廃止されたデスクトップ モードのリマインダーと古い承認ヒントを削除します (#7245、#6981)
  • 2.0.7.post1 を通じて AgentScope を更新します (#7276、#7373)
  • このリリースで使用されるコンソール チャット パッケージを更新します (#7257、#7289)
  • 各承認モードの動作を明確化 (#7368)
  • 埋め込みモデルの変更を明示的かつ元に戻せるようにし、スコープ指定された再インデックスが成功するまで BM25 にフォールバックします (#7133)
  • Marketplace の名前を Extensions に変更し、コンソール全体でダークモードのスタイルを復元します (#7454)

🐛 修正済み

モデル、ランタイム、メモリ

  • 完全なフリーモデルリストとレガシーモデル名を復元 (#7175)
  • アリユンとキミのモデルカタログを更新 (#7271、#7277)
  • モデル出力機能をリクエスト制限から分離し、ルーティングと検証で正しいメタデータを使用するようにします (#7337)
  • 厳密な DashScope ツール スキーマおよび音声メッセージ (#7284、#7024) との互換性を向上しました。
  • ストリーミング中にサーバーが提供する再試行制限を尊重します (#6617)
  • 停止したモデル ストリームから回復する (#7150)
  • モデルのタイムアウトを正確に伝播およびレポートします (#7268、#7308)
  • AgentScope 2.0.6 (#6908) とエージェントの動作の互換性を保つ
  • Ollama 埋め込みバックエンドを有効にする (#7131)
  • ナビゲーション中に埋め込み検証を保持する (#7227)
  • 生成されたチャット タイトルから推論テキストを除外する (#7187)
  • 明示的な値をオーバーライドせずに、バックグラウンド タスクに信頼できるデフォルトのタイムアウトを与える (#6869)
  • モデルを構成する前に ReMe メモリ サービスを開始し、モデルを構成しなくてもローカル メモリ機能を引き続き利用できるようにします (#7468)
  • ~ ベースのエージェント ワークスペース パスをモデルとツールの使用傾向に含めます (#7432)

コンソール、ファイル、メディア

  • 新しいチャットから直接唯一の履歴セッションを再開します (#7104)
  • アシスタントの応答の実際の完了時間を表示します (#6938)
  • リロード後に履歴データの URL 画像をレンダリング (#7069)
  • モデルセレクターのスタイルとダークモードセッショングループを改善しました (#7137、#7111)
  • 空の grep バッジと使用できない承認コントロールを非表示にする (#7165)
  • モバイルコンポーザーコントロールの改善 (#7334)
  • cron カレンダーの日付を日曜日が最初のヘッダーに揃えます (#7352)
  • エージェントを切り替えるときに埋め込み検証を継続する (#7353)
  • アップロードされたファイル名と非 ASCII ファイル名を保持します (#6492、#7192)
  • Windows CRLF 行末を保持し、変更後にファイル プレビューを更新 (#7091、#7094)
  • ダウンローダーのタイムアウト後にリモート ファイルのダウンロード フォールバックを続行する (#6371)
  • ツールの結果を保存する前にリモート イメージを保持する (#7146)
  • OpenAI Responses API (#7061) を通じてツール結果ビデオを配信します
  • インラインビデオ制限を構成可能にする (#7071)
  • メディア メッセージの正規化中にローカル ファイルの URL を保持する (#7343)
  • スクリーンショットをアクティブなプロジェクト ディレクトリに保存 (#7439)
  • Daily Paper を正しい QwenPaw ドキュメントにリンク (#7466)

チャンネル

  • protobuf 6 以降で Yuanbao メッセージのデコードを復元 (#7421)

プラグイン、デスクトップ、操作

  • リロード前にプラグイン ワークスペースの状態を復元し、プラグイン ネームスペース間の絶対インポートを分離します (#6996、#6688)
  • ブラウザーのクラッシュ後に Windows WebView2 を回復する (#7128)
  • NSIS 呼び出し元自体 (#7281、#7323) を含め、Windows インストーラーでの誤ったプロセスの一致を回避します。
  • NSIS アンインストール ブロッカーを処理し、アプリケーション データのクリーンアップの選択を明示的にします (#7336、#7354)
  • ワークスペースの起動がキャンセルされたときに安全にクリーンアップする (#7194)
  • 環境設定を部分的または破損した書き込みから保護します (#7135)
  • SSE 接続が閉じた後もバックアップ ジョブを実行し続ける (#7283)
  • 共有ファイルシステムおよび同時書き込み全体でエージェント設定の永続性の一貫性を維持します (#6767)
  • アクティブなポリシー評価中に File Guard パスを強制する (#7375)
  • サンドボックスのマウント パスを正しく展開します (#7116)
  • サンドボックスのセットアップ中のウイルス対策の干渉を回避する (#6986)
  • QQ 会話を分離し、その返信ルートを保存します (#7169)
  • Xiaoyi プロアクティブ送信失敗を確実に報告し、セッション ID を保存します (#7147)
  • セキュリティに敏感な Web サイトと Creator の依存関係にパッチを適用します (#7172)
  • プラグインごとにモジュール全体のスキャンを回避することで、プラグインのロードを高速化します (#7383)
  • パッケージ化されたデスクトップ ビルドで ReMe とその Auto Fin および Daily Paper プラグインを復元 (#7458)
  • デスクトップ パッケージが異なる Python ランタイム ソースを混合しないようにします (#7372)
  • シェルの行継続バリアントが機密パス保護をバイパスするのをブロック (#7472)
