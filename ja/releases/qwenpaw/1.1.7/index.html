QwenPaw v1.1.7

パッチ 公開日2026年5月14日 出典agentscope-ai/QwenPaw 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#クウェンパウv1.1.7

✨ 追加しました

ツールと MCP

  • ブラウザの使用 - バッチ アクション: 単一のツール呼び出しで複数のブラウザ ステップ (ナビゲート、click、入力、スクリーンショットなど) を実行します (#4139)
  • ブラウザの使用 - ファイルのダウンロード: cliページ要素をチェックするか、URLを直接取得してファイルをダウンロードします (#4261)
  • GPT イメージ 2 参照イメージ: GPT イメージ 2 プラグインの URL またはローカル パス経由で 1 ～ 16 の参照イメージのアップロードをサポート (#4194)
  • 外部エージェントの非同期実行: delegate_external_agent は、タスク リスト、ステータス クエリ、および構成可能なタイムアウトを使用した非同期ストリーミングをサポートします (#4197)
  • シェル実行可能構成: 構成オプションを介してコマンドを実行するシェルを選択します (#4215)
  • リモート MCP サーバー用の OAuth 2.1: PKCE を使用した OAuth 2.1 経由でリモート MCP サーバーを認証します (#4256) プラグイン
  • コンソール プラグイン管理: ローカル パス、ZIP アップロード、または URL (#4214、#4266) を介して、設定 UI からプラグインをインストールおよびアンインストールします。
  • Qwen-Image & Wan 2.7 プラグイン: 画像生成/編集およびビデオ生成用の新しいプラグイン (#4248)
  • プラグイン HTTP API ルーター: プラグインはカスタム HTTP API エンドポイントを登録できます (#4255) チャットとコンソール
  • 複数のファイル添付: チャット入力では、単一メッセージ内の複数のファイルの選択がサポートされるようになりました (#4206)
  • インドネシア語: コンソール UI とバックエンドに対する完全なインドネシア語ロケールのサポート (#4219)
  • 受信箱: ツールガードの承認を管理し、トレース付きの cron 実行結果を表示するための、[承認] タブと [プッシュ メッセージ] タブを備えた新しい一元的な受信箱 (#4210、#4305)
  • Cron ジョブの機能強化: Cron ジョブは、1 回限りのスケジュールされた実行、今後の実行を視覚化するためのカレンダー ビュー、迅速な作成のための組み込みテンプレート、詳細な実行トレースを含むジョブごとの実行履歴、および受信箱への保存配信をサポートするようになりました (#4210) チャンネル
  • Feishu 音声バブル: Feishu 経由で送信されたオーディオ ファイルがネイティブ音声バブルとしてレンダリングされるようになりました (#4202)
  • DingTalk の引用メッセージ: DingTalk の引用メッセージを含む返信には、エージェント コンテキストに引用テキストとメディアが含まれるようになりました (#4209)
  • Feishu QR コード ボットの作成: チャンネル設定 UI で QR コードをスキャンして、Feishu/Lark ボットを作成します (#4236)
  • WeCom ストリーミング出力: リアルタイム メッセージ配信および推論インジケーターのサポートを備えた WeCom チャネルのオプションのストリーミング応答 (#4271)

🔄 変更されました

  • モデル セレクターの再設計: ホバー ドロップダウンをプロバイダーごとにグループ化された検索可能なフラット リストに置き換えました (#3876)
  • フローティング チャット ボタン: チャット ナビゲーションがサイドバー メニューからエージェント セレクターの横にあるスティッキー ボタンに移動されました (#4240、#4273)
  • エージェント統計セッション ディスカバリ: チャネル サブディレクトリを直接ウォーキングすることにより、セッション ファイル ルックアップを簡素化しました (#4250)

⚡ パフォーマンス

  • 非同期 FastAPI 依存関係: モデルとプロバイダー マネージャーの依存関係が非同期に変換され、不要なスレッド プールのディスパッチが排除されます (#4229)
  • ファイル読み取りサイズ制限: 実際のファイル サイズに基づいた事前割り当てにより、最大ファイル読み取りサイズが 1 GB から 200 MB に減少しました (#4272、#4276)
  • キーリング タイムアウト: 資格情報マネージャーのハングによる起動のブロックを防ぐために、キーリング操作に 10 秒のタイムアウトが設定されるようになりました (#4263)

🐛 修正済み

プロバイダーとモデル

  • Volcengine モデル ID: 実際の API エンドポイントと一致するようにモデル ID を修正し、機能フラグを更新しました (#4169)
  • プロバイダー メタの保持: プロバイダー情報を取得するときにプロバイダーのメタデータが削除されなくなりました (#4200)
  • 不正な形式のツール使用フィルタリング: ストリーミング パーサーは、null ID または空の名前を持つツール使用ブロックをフィルタリングするようになりました (#4234) チャンネル
  • WeCom 承認カード オペレーター: 解決された承認カードにオペレーター名が表示されるようになりました (#4233)
  • Feishu WebSocket Keepalive: サイレント WebSocket 接続損失を検出して回復します (#4241) コンソールと UI
  • セッション履歴ルーティング: セッション履歴が消え、メッセージが間違ったセッションにルーティングされる問題を修正しました (#4203)
  • プラン パネル ダーク モード: プラン パネル ダーク モードでのテキストのコントラストが向上しました (#4190)
  • モバイル サイドバー: 狭い画面ではサイドバーが自動的に折りたたまれます (#4225)
  • ユーザー メッセージの改行: ユーザー メッセージで改行が保持されるようになりました (#4231)
  • トークン使用量の日付ラベル: 日付範囲が年の境界を越える場合、グラフのラベルに年の接頭辞が表示されるようになりました (#4268)
  • デスクトップ外部リンク: デスクトップ ビルドでリンクが正しく開くようになりました (#4270)
