QwenPaw v2.1.0

#クウェンパウv2.1.0

何が変わったのか

✨ 追加しました

QwenPaw OS シェル

  • ランチャー、タスクバー、通知、保存されたレイアウトを備えた、移動可能でサイズ変更可能なウィンドウでアプリを開きます (#6645)
  • インストールされたアプリとマーケットプレイス アプリは、App Center と QwenPaw OS シェル全体で 1 つのカタログを共有するようになりました (#6718) 統合ファイル ワークスペース
  • チャットを終了せずに、ワークスペース ファイルを参照、プレビュー、編集、比較、アップロード、ダウンロードできます (#6504)
  • QwenPaw OS シェルから直接ファイル ワークスペースを開きます (#6758)
  • 構文強調表示を使用してロボット フレームワーク ファイルを編集 (#6519) QwenPaw クリエイター
  • 専門エージェントのチームと一緒に、アイデアや既存の映像を完成したビデオに変換します (#6284)
  • clips、字幕、エフェクト、アセット、またはテキストを選択して、直接制御を維持しながらエージェントを集中編集します (#6740)
  • 画像、ビデオ、音声、字幕、モーション、オーバーレイ、並行制作ステップを使用して作成 (#6740)
  • メディア タスクのリカバリ、レンダリングの修正、構造化ログ、レビュー フィードバックを追加 (#6556、#6641)
  • 設定センター、外部スキル、非同期メディア生成、より多くのレンダリング形式を追加し、Windows と狭い画面のサポートを改善 (#6870) クロスハーネスの統合
  • セッションごとのモデル、権限、スキル、MCP サービスを使用して、Codex または Qoder を利用したエージェントを作成します (#6397)
  • ACP clients は、ランタイム資格情報を保存せずに、一時モデル、プロジェクト フォルダー、および MCP サービスを渡すことができます (#6754)
  • ACP セッションは、利用可能なモデルと現在のモデルを互換性のある clients に報告するようになりました (#6531) ブラウザでの使用
  • ブラウザでの使用はベータ版のままです。別のブラウザ セッションを使用したり、ユーザーのサインインしている Chrome から選択したタブに接続したりできます。ブラウザ側のコード実行はホストレベルのサンドボックスによって保護されておらず、アクション ポリシーはまだ適用されていません (#6276、#6157) コンピュータ使用
  • Windows デスクトップ アプリの自動化を追加します。 macOS のパッケージ化と署名は完了しましたが、デバイス レベルのエンドツーエンド検証はまだ進行中です。操作にはアプリごとの承認が必要で、ユーザーが入力を引き継ぐと停止します (#6424)
  • ネイティブ コンピューター使用により、キーボード シーケンスが追加され、Windows のモーダル ターゲティングとテキスト編集が改善され、macOS メニュー、ドラッグ、キャプチャ、フォーカスの信頼性が向上しました (#6891、#6913、#6977) コンテキスト、リカバリ、長期にわたる作業
  • プロジェクトの Git 履歴を変更せずに、会話、メモリ、および選択したワークスペース ファイルのスナップショットと復元 (#6269)
  • 長い会話はアクティブなタスクを保持し、古い正確な履歴は検索可能なインデックスに移動します (#6323)
  • 履歴検索は、ペアのリクエストとレスポンスを返し、日付ベースのクエリを理解します (#6237)
  • Visual Compact は、ソースの回復を維持しながら、サポートされているマルチモーダル モデルの長いコンテキスト入力を削減します (#6456)
  • 長時間実行されるツールは、進行状況、延長、キャンセルの制御を使用してバックグラウンドで継続できます (#6151)
  • ツールのワークフローは、結果を再利用し、分岐、ループし、独立したステップを並行して実行できます (#5698)
  • ReMe Light メモリ検索では、オプションで OpenAI 互換エンドポイントを通じて候補を再ランク付けでき、再ランク付けが利用できない場合は正常にフォールバックできます (#6398)
  • ReMe Light は、検証済みのホットアップデート可能な埋め込み設定、デイリー ペーパーとサービス レベルのスケジュール、エージェントごとのランタイム ステータス、手動再インデックス制御、および独立した検索および通知オプションを追加します (#6772) コンソールとモデル
  • エージェント統計にトークンの使用状況が表示され、結果が現在のエージェント (#6503、#6402、#6862) に絞り込まれるようになりました。
  • プロジェクト ディレクトリの選択には、要求に応じて隠しフォルダーを含めることができます (#6878)
  • コード ブロックは、構文の強調表示、コピー、ダウンロードのアクションを備えた、レスポンシブでテーマを意識したデザインを共有するようになりました。 LaTeX ブロックと Mermaid ブロックに、ローカライズされた [プレビュー] タブと [ソース] タブが追加されました (#6911)
  • フォーカス、フィルタリング、およびモーション削減のサポートを備えたインタラクティブな 3D グラフでメモリ関係を調査します (#6922) チャンネル
  • Feishu、QQ、WeCom、Xiaoyi、および Yuanbao は、デフォルトを変更せずに、プライベート展開およびローカル統合テストにオプトイン カスタム ゲートウェイ エンドポイントを使用できます (#6907)
  • 有効な組み込みチャネルを保存すると、同じボット ID が別の実行中のエージェントによってすでに使用されている場合に警告が表示されますが、明示的なオーバーライドは引き続き許可されます (#6909)

🔄 変更されました

  • App Center は、インストールされているアプリと利用可能なアプリを分離し、アプリの詳細を拡張し、シンプル モード エントリを追加します (#6553、#6638)
  • チャットはループ モードをアクティブなエージェントに合わせて維持し、ローカライズされた Oh-My-Paw モード (#6711、#6521) をリストします。
  • スラッシュ コマンド スキルは挿入されたコンテンツを表示し、重複したコピーはスキップされ、QwenPaw スキル リンクは直接インポートできます (#6345、#6650、#6517)
  • Windows は現在の権限に基づいてサンドボックスを選択します。サポートされていない制限はすべてのプラットフォームで報告されます (#6383、#6657)
  • OneBot/QQ はテキストとメディアの順序を保持し、引用または転送されたメッセージを展開します (#6543、#6769)
  • QwenPaw OS シェルは、シンプル/デスクトップ モード スイッチを並べて配置し、デスクトップ モード ラベルを短縮します (#6763)
  • QwenPaw OS シェルは 1 つのブラウザー エントリを使用し、デスクトップ内からアプリを起動し、廃止されたコーディング起動パスを削除するようになりました (#6868)
  • プロアクティブ モードは、アクティブなワークスペースを再利用し、無効になったときにそのリソースを解放し、研究に軽量の Web ツールを使用します (#6712)
  • MiniMax モデルとコンテキスト制限が M3 および M2.7 世代用に更新されました (#6479、#6554)
  • プラグインのインストールは、新しい互換性上限を宣言するパッケージ (#6532) をより許容します。

🐛 修正済み

QwenPaw クリエイター

  • 入力が変更されると失敗した作業が再開され、ビデオの重複レンダリングが回避され、最終的な構成の前に古いシーンがレビューされます (#6937) デスクトップ
  • コンピューターでの使用では、署名された macOS アプリ ID が再利用されるため、起動後も権限が維持されます (#6590)
  • デスクトップ起動ではポートエラーが処理されます。 Windows シャットダウン チェックは制限されており、非表示のままになります (#6705、#6203)
  • Chrome は中断後に再接続し、パッケージ化されたブラウザはデスクトップ上で検出され、Windows の復元ロックにより同時回復が妨げられます (#6669)
  • QwenPaw OS シェル ウィンドウはメニュー バーを表示したままにし、ビューポート内に留まり、テキストの選択とコピーを許可します (#6801、#6861) ランタイムとエージェント
  • プロバイダー固有のツール呼び出しフィールドが、ストリーミング、履歴保存、圧縮、または再生中に失われることがなくなりました (#6759)
  • モデルがコンテキスト制限エラーを報告すると、Scroll はコンテキストを圧縮して 1 回再試行します。履歴の移行ではセッション ID も保持されます (#6267、#6068)
  • Codex ランタイムが利用できない場合でも、Codex-backed Agent は引き続き管理可能 (#6664)
  • サブエージェントは現在のセッションの承認レベルを継承します。空のバッチ フィールドによって単一タスクがバッチ リクエストに変換されなくなりました (#6508、#6595)
  • ループ制限は古い構成に対して書き戻され、名前変更されたツールごとのエントリは保持されます (#6530、#6682)
  • シェルの実行は複数行のコマンドを保持し、継承されたバックグラウンド パイプでハングしなくなりました (#6412、#6748)
  • ヘッドレス タスクは効果的なユーザー メッセージを構築し、何も構成されていない場合、ワークスペースのコミットはローカルのデフォルト Git ID を使用します (#6616、#6350)
  • エージェントをコピーしても、空のスキルやスケジュールされたタスクのスキャフォールディングは作成されなくなりました (#6493)
  • バックグラウンドのサブエージェントタスクは、権限のあるフォークの終了を待機し、ワークツリーの変更を破棄せずに失敗を報告します (#6725)
  • 破損したエージェント構成と無効な JSON により、構成のロードが中断されるのではなく、回復可能な構成エラーが生成されます (#6615)
  • スクロールリコールは、部分文字列および複数用語検索で完全な CJK ターンを検出し、逆の拡張範囲を拒否します (#6824)
  • レガシー セッションは、Windows UNC パスやパーセント エンコードされた非 ASCII パスを含むローカル パス メディアを再度ロードします (#6873)
  • 記憶のヒントによって会話が中断されることはなくなり、通常の非ストリーミング応答でチャット タイトルが生成されるようになりました (#6360、#6816)
  • 継続サマリーは障害のある思考を尊重し、中断またはタイムアウトの動作を保持します (#6818)
  • ヘッドレス ACP セッションは、一時的なモデル コンテキストと出力制限を保存せずに尊重します (#6933) コンソールと UI
  • 再接続とエージェントの切り替えによって、間違ったチャット、古いチャネル、または重複した保留中のメッセージが復元されなくなりました (#6602、#6546、#6382)
  • リッチ メッセージが送信キューに入り、複数ファイルのプレビューがコンポーザー内でラップされます (#6798、#6662)
  • 大きなツールの出力では制限されたプレビューが使用され、長いコマンドはカード内でラップされます (#6637、#6677)
  • ストリーミングが終了するまでツール コントロールは非表示のままになります (#6749)
  • サイドバーが折りたたまれているときに設定が表示されたままになる (#6488)
  • Production Console ビルドで依存関係 CSS が省略されなくなりました (#6639)
  • チャット ホイールのスクロールが安定し、画面外でもロードモア スピナーが実行されなくなりました (#6904、#6896)
  • ヘッダー リソース メニューに重複した GitHub リンクが表示されなくなりました (#6903)
  • ワークスペースのプレビューは、Unicode PDF ファイル名と SVG メディア タイプをサポートし、プレビューおよび編集サーフェスのダークモード スタイルが修正されました (#6915)
  • 長い複数行のアシスタントとツールの出力では改行が保持されますが、幅の広いコード ブロックとテーブルはコンテナ内でスクロールします (#6890)
  • チャットは標準のテキストエリア入力にフォールバックし、デスクトップとエンドツーエンドの検証はテキストエリアとコンテンツ編集可能な入力の両方をサポートします (#6934)
  • 画像のアップロードで、Base64 データをテキストとしてカウントすることによってコンテキスト使用リングが膨らまなくなりました (#6968)
  • 大きなスクリーンショットをプレビューできるようになり、完成したツールに回転ステータス アイコンが表示されなくなりました (#6965、#6967)
  • 毎日の思い出メモがグループ化され、パスの日付ごとに並べ替えられます (#6941) ガバナンスとセキュリティ
  • ユーザーが明示的にオプトアウトしない限り、ブラウザのデバッグには認証が必要です (#6500)
  • プロジェクトのインポートは承認されたパスのみを読み取り、スキップされた機密フォルダーをレポートします (#6487、#6713)
  • サンドボックスのクリーンアップは中断されたセッションを処理します。無効な設定はクラッシュせずにフォールバックし、警告を表示します (#6600、#6582、#6747、#6857)
  • サンドボックス化された子プロセスは PYTHONHOME を継承しなくなり、間違った Python ランタイムを解決できなくなります (#6902)
  • 会話コマンドの引数がログに書き込まれなくなりました (#6692) メモリ
  • コンテキストの移行および Web ワークスペースのリカバリ中のメモリとチェックポイントの保存を修正しました (#6592、#6597)
  • 自動メモリの進行状況は、コンテキスト圧縮とセッション回復後も存続します。失敗した送信は、チャット履歴を汚すことなく再試行できます (#6830) MCP
  • 終了した MCP セッションは、アクティブなエージェントからすべてのツールをドロップせずに回復します (#6894) CLI とチャンネル
  • サービスがアイドル状態のときにスケジュールされたタスクが起動される (#6481)
  • スケジュールされたタスクを一時停止および再開すると、有効な状態が保持されます (#6691)
  • スケジュールされたタスクの結果は、移行されたタスク (#6182、#6511) を含む、構成された配信動作に従います。
  • 欠落しているスケジュールされたタスクを一時停止または再開すると、見つからない応答が返されます (#6858)
  • task コマンドは、トレースバックを出力せずに、欠落しているエージェント構成を報告します (#6865)
  • CLI プロジェクト パスはグローバル オプションの後に受け入れられます (#6892)
  • qwenpaw update --prerelease は PyPI からの新しいプレリリースを検出するようになりました (#6939)
  • OneBot はデフォルトでローカルでリッスンし、ネットワークに公開する場合はトークンを必要とします (#6676)
  • OneBot 構成宣言は、構成 API (#6864) と一致したままになります。
  • チャネルの承認はドライバー ゲートを介してルーティング フィールドを保持し、Xiaoyi メッセージは内部スクロール ヘッドラインを非表示にします (#6833、#6888)
  • DingTalk 組織の承認により、返された資格情報がチャネル設定に入力されるようになりました (#6709)
  • マトリックスは、Python 3.12 (#6486) でメッセージを接続して復号化できます。
  • タイムゾーンのないタイムスタンプは一貫してローカルプロセス時間として解釈されます (#6685、#6855) その他
  • バックアップ復元はバックグラウンド操作が完了するのを待ち、ゼロバイトのロック ファイル (#6735、#6703) を受け入れます。
  • OpenRouter は既知のマルチモーダル サポートを保持し、回復可能なストリームまたは推論エラー (#6733、#6714、#6721) を再試行します。
  • ビデオ入力はビデオ サポートを宣言したモデルに転送され、チャネル音声が再度転写されます (#6495、#6573)
  • ローカル イメージはファイル変更後も元のコンテンツを保持し、一時的なメディア エラーによってマルチモーダル サポートが無効にならなくなりました (#6930)
