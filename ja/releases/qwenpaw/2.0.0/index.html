#クウェンパウv2.0.0

何が変わったのか

✨ 追加しました

コアアーキテクチャ

  • ランタイム 2.0: AgentScope 2.0 (#5078、#4846、#5018、#5552) に基づいてカーネルをリファクタリングします。
  • エージェント OS ドライバー: MCP/A2A/ACP 接続、暗号化された資格情報ストレージ、および通話ごとの承認ポリシーの統合管理 (#5067)
  • ループ エンジニアリング: 3 つのループ テンプレートを備えた新しいループ ゲート設計: ノーマル モード / ミッション モード / ゴール モード (#5665、#5727)
  • ガバナンスとサンドボックス: 許可/拒否/要求ルールを備えたポリシー エンジン、単一のポリシー評価パスに統合された ToolGuard 検出器、およびプラグインの一般化されたガバナンス パターン (#5088、#5546、#5301) コンテキスト管理
  • スクロール コンテキスト: SQLite ベースの作業履歴 (history.db)。FTS5 全文検索、エビクション インデックス、ターン レベルの永続性、および古いターンをオンデマンドで呼び出すためのサンドボックス recall_history_python REPL を備えています。 30 日間のデフォルト保持、起動時に既存のセッションを自動インポート (#5321)
  • ネイティブ圧縮: AgentScope 2.0 の組み込みコンテキスト圧縮戦略 (#5309) を使用したリファクタリング 長期記憶
  • ReMe v0.4.0 バックエンド: 社内メモリ ランタイムを ReMe v0.4.0 に置き換えます — ベクター ストア、自動追跡、および取得は ReMe v0.4.0 ライブラリによって処理されるようになりました (#5349)
  • ターンベースのトラッキング: メモリの書き込みはミドルウェア経由でターンごとに行われるようになり、セッション終了に関連付けられなくなりました (#5540)
  • 使用状況を考慮した検索: メモリ検索では、最新性と頻度が考慮されるようになりました。バックエンド固有の埋め込みモデルの選択が構成 UI に追加されました (#5820)
  • ADBPG REST モード: ADBPG メモリ バックエンドが自動検索付きの REST 専用に切り替えられました (#5296)
  • 検索 UI の簡素化: メモリ検索表示がよりクリーンになり、メタデータ フィールドが必須項目に削減されました (#5482)
  • 'none' バックエンド: 軽量展開のメモリ システムを完全に無効にする構成オプション (#5732) ターミナル UI (TUI)
  • フルスクリーン TUI: テキストベースのターミナル チャット アプリ (qwenpaw tui) — ストリーミング出力、ツール呼び出しレンダリング、ステータス バー、セッション管理がすべてターミナル内で行われます (#5032)
  • プロジェクト スコープのセッション: TUI は、特定のプロジェクト ディレクトリをスコープとするコーディング モード セッションを起動できます (#5448)
  • コンテキスト使用状況バー: TUI ステータス バーのライブ トークン/コンテキスト使用状況インジケーター (#5673)
  • TUI の ACP コマンド: /approve、/deny インライン承認コマンド + トランスクリプト パネルの改善 (#5443、#5714) コンソールと UI
  • 承認カード: 大きなアクション ボタン、より鮮明な差分プレビュー、1 つの click 承認/拒否 (#5855)
  • 長いテキストのアップロード: 大きなテキスト ブロックをチャット入力に直接貼り付けるかアップロードします (#5854)
  • セッションレベルのツール承認: セッションごとにグローバル ツール ポリシーを上書きします (#5685、#5832)
  • 非所有者バナー: 他の人のセッション タブを表示するときに「表示専用」バナーを表示します (#5664)
  • モバイル レイアウト: すべてのコンソール ページのレスポンシブ CSS + ドロワーベースのナビゲーション (#5444 ～ #5470)
  • ツール ページの分割ビュー: 有効なツールと利用可能なツールが別の列に表示されます。ツールごとの構成認識切り替え (#5509、#5604)
  • スキル マーケットの改善: スター/ダウンロード数、分割の有効/無効、CDN からの自動同期 (#5521、#5706、#5639)
  • チャンネル ページのデュアル レイアウト: 有効なチャンネルが上部、利用可能なチャンネルが下にあります (#5504)
  • コーディング モード 50/50 分割: チャット パネルはビューポートの半分を占めます (#5473)
  • プロジェクト ブラウザの隠しフォルダー: . という接頭辞が付いたディレクトリが選択可能になりました (#5828)
  • セッション ドロワー: インライン検索を使用した日付グループ化されたセッション (#5728)
  • トークン使用量のポップオーバー: ターンごとのトークン/コンテキストの使用量を示すリング チャート。ランタイム 2.0 (#5493、#5544) 用に復元されました。
  • 受信トレイ フィルター: ソース タイプごとにプッシュ通知をフィルターします (#5522)
  • メッセージ アンカー: ユーザー ターンのためのメッセージへのジャンプ ナビゲーター (#5515)
  • リクエスト タイムアウト: 構成可能な HTTP タイムアウト + バックエンド呼び出しの AbortSignal 伝播 (#5764) モデルプロバイダー
  • OpenAI Response API: OpenAI Response API 形式の新しいプロバイダー (#5519)
  • DashScope の更新: Qwen3.7 + DeepSeek V4 が組み込みモデル リストに追加されました。 generate_kwargs の extra_body パススルー。モデルごとの思考リレー切り替え (#5646、#5491、#5687、#5730)
  • GitHub モデル: 新しい API エンドポイントに移行します。きめ細かい PAT をサポート (#5735)
  • テレグラム カスタム ベース URL: セルフホスト型テレグラム ボット API サーバーの api_base_url 構成 (#5651) チャンネル
  • マトリックス ストリーミング: 編集インプレース ストリーミング。チャンクごとに新しいメッセージを送信しなくなりました (#5585)
  • プラグイン登録チャンネル: プラグインは、設定 UI を自動生成する JSON スキーマを使用してカスタム チャンネル タイプを登録できます (#4693)
  • チャネルごとのデバウンス切り替え: 高速チャネルでメッセージがバッチ処理されないように no_text_debounce フラグを設定します (#5617)
  • Slack: マルチモーダル添付ファイル、スレッド返信、ストリーミングを備えた完全なチャネル実装 (#5193)
  • DingTalk プライベート デプロイ: オンプレミス DingTalk インスタンスの api_endpoint 構成 (#5111)
  • Azure Bot チャネル: Azure Bot チャネルがプラグインとして追加され、プラグイン チャネルの i18n/custom-icon/doc_url サポートが追加されました (#5849)
  • Discord の添付ファイル: ローカル media_dir にダウンロードし、静的ファイル ルート経由で提供します (#5468) デスクトップ
  • Tauri の移行: デスクトップ ビルドが Electron から Tauri に移行されました - より小さいバイナリ、ネイティブ Web ビュー、Windows 上の NSIS インストーラー (#5734、#4669、#4041)
  • バンドルされた ACP ランタイム: Node.js ランタイム + ACP モジュールは、すぐに使用できるエージェント通信用のデスクトップ パッケージ内に同梱されています (#5814、#5794)
  • DevTools ジェスチャ: 8x ロゴ click は、デバッグのために Chromium DevTools を開きます (#5805) セキュリティとサンドボックス
  • Windows AppContainer サンドボックス: Windows ネイティブ AppContainer API (#5525) 経由で分離されたコード実行
  • Linux bubblewrap サンドボックス: Linux コード実行用に bwrap 経由で名前空間分離をマウント (#5310)
  • Cron ツールの安全性切り替え: スケジュールされたタスクに対してツールの承認を要求/スキップするジョブごとのフラグ (#5847)
  • 危険なコマンドの検出: ToolGuard は、find -delete および類似の破壊的なシェル パターン (#5843) を検出します。
  • アクセス ポリシー: 機能呼び出しごとに評価される宣言的な許可/拒否/要求ルール プラグイン
  • AgentScope ミドルウェア フック: プラグインは、Semver バージョン管理を使用して AgentScope 互換ミドルウェアを登録できます (#5221)
  • バージョン管理されたカタログ: プラグイン マーケットと CDN には、実行中の QwenPaw バージョン (#5661) と互換性のあるプラグインのみが表示されます。
  • ライフサイクル フック: on_uninstall フック、バリデータ修正、プラグイン作成者向けのパブリック スキル プロバイダー API (#5008) ツール
  • web_search および web_fetch: 製品 ID を備えた組み込み Web 検索およびフェッチ ツール (#5890)
  • grep_search show_file オプション: 一致したファイルの内容を表示するための show_file フラグを追加 (#5840)
  • ツール エラー パススルー: UX を向上させるために、ツール結果のエラー状態がフロントエンドに転送されました (#5912) CLI
  • cron update: 削除+再作成を行わずに既存の cron ジョブのスケジュール/プロンプト/構成を編集 (#5210) 可観測性
  • Langfuse 2.0: フック統合によりトレース グループ化が復元されました。各エージェント ループは Langfuse 生成スパン (#5511)

🔄 変更されました

  • relay_reasoning: preserve_thinking の名前が relay_reasoning に変更されました。出力での重複した推論を避けるために、DashScope のデフォルトはオフです (#5876)
  • レート制限: 構成可能なウィンドウによる多次元 (IP + ユーザー + エンドポイント) レート制限 (#5738)
  • メモリのライフサイクル: /compact コマンドが再加工されました。新しい /system_prompt コマンド。古い埋め込みを避けるために簡略化された検索状態 (#5450、#5815)
  • SessionItem コンポーネント: すべてのセッション レンダラーが 1 つの SessionItem コンポーネントに統合されました (#5754)
  • スキル UI: SkillPool/SkillMarket コンポーネントがリファクタリングされました。無効な CSS を削除しました (#5753、#5532)
