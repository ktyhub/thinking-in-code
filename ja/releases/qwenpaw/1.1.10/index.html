QwenPaw v1.1.10

パッチ 公開日2026年6月1日 出典agentscope-ai/QwenPaw 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#クウェンパウv1.1.10

何が変わったのか

✨ 追加しました

エージェントシステム

  • Spawn Subagent: 一時的なワークスペース内サブエージェント実行用の新しい spawn_subagent ツール (#4806) コーディングモード
  • オープン ディレクトリ: ファイルをワークスペースにコピーせずにローカル プロジェクトを参照するための新しい [オープン ディレクトリ] タブ (#4762) チャンネル
  • Tencent Yuanbao チャネル: Tencent Yuanbao ボットの新しいチャネル統合 (#4856)
  • フェイシュ スレッド返信: エージェントはフェイシュ メッセージ スレッド内で返信できるようになりました (#4708) プロバイダー
  • OpenRouter アトリビューション: OpenRouter ランキングの可視性のためのアプリ アトリビューション ヘッダーを追加しました (#4809) コンソールとアップロード
  • 動的アップロード制限: アップロード サイズ制限がコンソールとチャネル全体で設定できるようになりました (#4734) テスト中
  • E2E テスト移行: モック インフラストラクチャを使用して python_e2e を CoPaw に移行しました (#4464)
  • 統合テストの拡張: シードされたデータのシナリオによる適用範囲の拡大 (#4745)

🔄 変更されました

  • Feishu カード システム: wecom/qq パターンに一致するようにカード システムを再構築し、ストリーミング モードで解決されたカードを修正しました (#4742)

🐛 修正済み

デスクトップおよびCLI

  • バンドルされたデスクトップ CLI: Tauri デスクトップ アプリ用にバンドルされた qwenpaw CLI を追加しました (#4779)
  • Windows Git コンソール: コーディング モードで Windows Git コンソール ウィンドウを非表示にする (#4696) コンソール
  • モバイル チャット入力: モバイル上のセーフ エリアと仮想キーボードに適応したチャット入力 (#4751)
  • チャット入力の下書き: メッセージの送信後にチャット入力の下書きをクリアします (#4755)
  • チャット入力: 追加のチャット入力の問題を修正しました (#4862)
  • チャット コード: チャット コードの表示の問題を修正しました (#4805)
  • Antd の非推奨: antd 5.29 の非推奨の警告をクリーンアップし、AllowNoAuthHosts アイコンを修正しました (#4790) チャンネル
  • OneBot WebSocket: TCP ヘルス プローブ経由で接続が失われたときに WebSocket サーバーを自動再起動します (#4793) エージェント
  • 推論内容: アシスタント メッセージ内のファイル ブロック全体で reasoning_content を保持する (#4728)
  • メッセージ タイムスタンプ: ユーザー タイムゾーンのサポートによるタイムスタンプ処理の強化 (#4763) スキル
  • スキル更新の安定性: スキル更新中にタグ、有効化/無効化、およびチャネル設定を保持します (#4847)
  • 古いスキルの処理: pip 操作中に ~ というプレフィックスが付いた古いスキルを無視します (#4851) ペット
  • 依存関係の自動インストール: v1.1.9 での起動エラーを解決するために不足している依存関係を自動インストールします (#4801) ウェブサイト
  • ヘッダー スタイル: ヘッダー スタイルを修正し、自動継続ビデオを追加しました (#4812)

🏗️ インフラストラクチャ

  • CI クリーンアップ: 冗長な unit-tests.yml ワークフローを削除 (#4748)
  • 寄稿者データ: PR マージ時の GitHub アクションによる contributors_data.json の自動維持 (#4692)
