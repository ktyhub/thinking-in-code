QwenPaw v1.1.11

#クウェンパウv1.1.11

何が変わったのか

✨ 追加しました

プロバイダー

  • 無料モデル OAuth: 1-click OAuth 認証を備えたゼロ構成の無料モデル (#5049)
  • Xiaomi MiMo プロバイダー: Xiaomi MiMo トークン プランを組み込みプロバイダーとして追加します (#4722)
  • 追加ボディ ルーティング: 非標準のgenerate_kwargsをextra_bodyにルーティングします (#4689) コンソール
  • プラグイン マーケット: AgentScope プラットフォーム統合によるプラグイン マーケット タブの追加 (#5023)
  • プラグイン拡張インフラストラクチャ: コンソール用プラグイン拡張インフラストラクチャ (#4997)
  • ツール カード プラグイン システム: ツール カード プラグイン システム (#5046)
  • スラッシュ コマンドの提案: UI の最適化により、現在のエージェント スキルを追加してコマンドの提案をスラッシュします (#4810)
  • 外部 URL ナビゲーション: 外部 URL ナビゲーション用に MenuItem の href フィールドをサポート (#5071) MCP
  • ツールのホワイトリスト: フロントエンド切り替え UI を使用してサーバーごとの MCP ツールのホワイトリストを追加 (#5002) プラグイン
  • プロンプト セクション レジストリ: プラグインが定義されたアンカー ポイントにシステム プロンプト ブロックを挿入できるようにします (#4804)
  • アンインストール フック: アンインストール フックを追加し、バリデーターのインポートを修正し、スキル プロバイダー API (#4794) を公開します
  • CloudPaw エージェント インポート: AgentHub からのエージェントのインポートをサポートし、A2A 機能を強化します (#5033) スキル
  • 自己進化スキル作成: 自己進化スキル作成をサポートするためにスキル作成フローを強化 (#4857)
  • スキルタグ一括ダウンロード: スキルタグ一括ダウンロードを追加(#4969)
  • マルチパス スキル プール: スキル プールにマルチパス サポートを追加 (#4891) チャンネル
  • テレグラム ツール ガード: インライン キーボードによる対話型ツール承認 (#4737)
  • フェイシュグループ共有: グループセッション共有モードを追加 (#4821)
  • Feishu インタラクティブ カード: インタラクティブ カード コンテンツの抽出とメッセージ解析のリファクタリングをサポート (#4879)
  • QQ QR コード認証: QQ チャネル (#4848) に QR コード認証を追加します
  • DingTalk インライン メディア: Webhook 経由でインライン画像プレビューとビデオ再生カードを有効にする (#5073)
  • Yuanbao タイピング インジケーター: ハートビート経由でタイピング インジケーターを追加 API (#5020)
  • アクセス制御ユーザー名: 統合されたユーザー情報構造を使用して、送信者のユーザー名をアクセス制御に追加します (#4897) ブラウザ
  • ページ座標 Click: ページ座標 click のサポートをブラウザー コントロールに追加します (#4905) ACP
  • ACP の機能拡張: コマンド、サーフェス エラー、ツール パラメーター、エージェント/モデル メタ、ファイル リンクをアドバタイズします (#4949) ランナー
  • ストリーム クエリ タイムスタンプ: stream_query をオーバーライドして、応答に現在のタイムスタンプを設定します (#4892)

🔄 変更されました

  • Cron プッシュ バブル: タイプ「エージェント」の cron ジョブのプッシュ バブルを無効にする (#4803)
  • コンソール メディア処理: コンソール チャネルでのメディア メッセージ処理を簡素化します (#5077)
  • セッション パネルを元に戻す: 「履歴セッション リストを右側のパネルとして埋め込む」を元に戻します (#5076)

🐛 修正済み

プロバイダーと構成

  • ProviderManager フォールバック: ProviderManager フォールバックを get_model_max_input_length に追加 (#4827)
  • 圧縮の修正: active_model が設定されていない場合、モデルの max_input_length を無視する /compact を解決します (#5021) コーディングモード
  • Windows ドライブの参照: Windows 上のすべてのドライブの参照をサポート (#4906)
  • セッションスイッチとヘッダー: コーディングモードセッションスイッチの失敗とヘッダーオーバーフローを修正 (#5011) コンソール
  • セッション リスト スピナー: セッション リストが回転し続ける問題を修正 (#4929)
  • スクロールバーのちらつき: スクロールバーのちらつきを防ぐためにホバー変換を削除します (#4766)
  • シールド アイコンとテーブル: シールド アイコンを中央に配置し、ルール テーブルの列幅を調整します (#4765)
  • テーマ切り替えアイコン: システム テーマ切り替えアイコンをコンピューターから太陽に変更します (#5050) デスクトップ
  • Tauri 外部リンク: Tauri デスクトップの外部リンクを修正 (#4683) エージェントとメモリ
  • ブロードキャスト コルーチン: _broadcast_to_subscribers で待機していないコルーチンを待機します (#5048)
  • 自動メモリをスキップ: オートメーション自動メモリをスキップ (#4348)
  • Dream ワークスペース: Dream は、古いインスタンス ディレクトリ (#4936) ではなく、cron ランナーのワークスペースを使用する必要があります。
  • メディア ブロック処理: メディア ブロック処理で非辞書ソース オブジェクトを処理する (#4933) MCP
  • ツール名の正規表現: OpenAI スタイルの正規表現によって拒否されたエイリアス書き換えツール名 (#4958)
  • サブプロセスの蓄積: 再起動後のサブプロセスの蓄積を防止します (#5014) チャンネル
  • DingTalk メッセージの結合:conversation_id サフィックスが衝突する場合のクロスユーザー メッセージの結合を防止します (#4932)
  • OneBot ポートの競合: リロード中のポート競合の正常な機能低下 (#5010)
  • ACL 送信者 ID: すべてのチャネルにわたるネイティブ ペイロードのマージ中に acl_sender_id を保持します (#4925) ブラウザ
  • CDP タイムアウトとプロファイル: クロスブラウザー切り替えのための CDP タイムアウト パラメーターとブラウザー プロファイル分離を追加 (#4944) ファイルとセッション
  • 非同期ファイル書き込み: ノンブロッキング ファイル書き込みには aiofile を使用します (#4954)
  • アトミック状態書き込み: セッション状態をアトミックに書き込みます (#4706)
  • アップロード サイズとタイムアウト: アップロード サイズ制限 + プラグイン ローダー タイムアウト回復力 (#4940)
  • zip ダウンロード サイズ: zip ダウンロード ファイル サイズを増やします (#4941) セキュリティ
  • ファイル プレビューの制限: ファイルのプレビューを WORKING_DIR に制限し、機密ファイルをブロックします (#4981) パッケージ
  • 元宝プロト JSON: 元宝プロト JSON ファイルをパッケージ データに含めます (#4899)

⚡ パフォーマンス

  • バックエンド起動: イベント ループのブロックを解除し、起動を並列化します (#5074)
  • CI カバレッジ: カバレッジ コレクションを py3.10 から py3.13 に切り替えます (#4952)

🏗️ インフラストラクチャ

  • E2E CI パイプライン: 完全な E2E 統合 CI パイプライン — バックエンドの起動、カバレッジ、テスト修正 (#5054)
  • CI クリーンアップ: 冗長なチャネル テスト ワークフローを削除 (#5056)
  • 依存関係: reme-ai の依存関係をバージョン 0.3.1.10 (#4935) に更新します
  • チャット コンポーネント: @agentscope-ai/chat を 1.1.68 (#5072) に更新します

🧪 テスト

  • フロントエンド単体テスト: 完全なフロントエンド単体テストのマイルストーン — 定数、コンテキスト、レイアウト、api タイプ、コンポーネント (#4332)
  • ランナーとルーターのテスト: ランナーとルーターの単体テストとコントラクト テストを追加 (#4852)
  • エージェント対象の P0 テスト: エージェント対象の P0 契約の適用範囲 (+55 件) (#4945)
  • エージェント ページ テスト: エージェント ページ + API モジュール単体テスト + カバレッジ ラチェット (#5012)
  • プロバイダーとユーティリティのテスト: local_models、プロバイダー、トンネル、ユーティリティの単体テストを追加 (#4973)
  • チャネル層テスト: チャネル層 + マルチエージェント管理統合テスト (#5058)
  • E2E トークン使用量: クリーン環境でのトークン使用量テストの空状態検出を修正 (#5068)

📖 ドキュメント

  • ロードマップの更新: ロードマップを更新します (#4942)
  • フロントエンド プラグイン ドキュメント: フロントエンド プラグイン ドキュメントを Web サイト ページに統合します (#5066)
