QwenPaw v2.3.0

#クウェンパウv2.3.0

何が変わったのか

✨ 追加しました

ピッコロ局所決定モデル

  • BF16 および Q8_0 の推奨事項、ランタイムのインストールと更新、および Hugging Face または ModelScope のダウンロードを含む、ツール レビューおよびコンテキスト圧縮のためのローカル デシジョン モデルとして Piccolo 4B、9B、および 27B を追加します。レビューと圧縮はオプトインのままです。ローカル ランタイムは一度に 1 つのモデルを提供します (#8463、#8573)

QwenPaw コミュニティ

  • コンソールから QwenPaw コミュニティの投稿を参照、並べ替え、コメントし、モデル支援を使用してリソースにリンクされた問題レポートを草案し、コミュニティ エディタを開きます。アカウントを接続して、選択したメッセージ カテゴリを受信トレイとデスクトップ通知に同期します (#7903)

コンソールとデスクトップ

  • オプションの OpenUI プラグインを追加して、返信内のインタラクティブなフォームとコンポーネントを表示し、ストリーミング中にそれらの状態を保持し、元の会話にアクションを送信します (#8239、#8248)
  • 古い未読メッセージを見つけやすくするために、受信トレイのプッシュ メッセージに未読専用フィルターを追加しました (#8484)
  • デスクトップ ウィンドウで 1 つのバックグラウンド サービスを共有し、最後のウィンドウを閉じた後もタスクを実行し続け、ウィンドウ間で更新を調整します。サービスの再接続時に未送信の下書きを保存する (#8373)
  • デスクトップがトレイに最小化されたときを含む、承認、完了した返信、およびバックグラウンド タスクに関するブラウザーとデスクトップの通知を受信します。 cli通知を確認して、関連する会話または承認に戻る (#8504)

エージェントモード

  • アドバイザ モードの追加: アドバイザ モデルとワーカー モデルをペアにし、開始計画を準備し、必要に応じてアドバイザに相談し、ツールの失敗が繰り返された後に計画を調整します (#7569)
  • 実験的な Python コード モードを追加して、同時呼び出しや順序付けされたテキストおよびメディア出力など、有効なツールを 1 つのスクリプトに結合します。ネイティブ ツールの権限は引き続き適用されます。コード モードではサンドボックスが有効になりません。デフォルトではオフになっています (#8224)
  • qwenpaw acp --agent-mode (#8352) による新しい ACP セッションの初期エージェント モードを選択します
  • 必要に応じて、意思決定モデルを使用して、完了セルフチェック中に未完了の作業の会話とツールの証拠をチェックします。モデルが利用できないか不確実な場合は、元のセルフチェックを保持します。このオプションはデフォルトではオフになっています (#8544)

メモリ

  • 画像メモリ、自動タグ、タグ フィルター検索、および元のツール出力への参照を保持する意思決定モデル コンテキスト圧縮を備えた ReMe を 0.4.2.0 にアップグレードします。画像メモリ、自動タグ付け、デシジョン圧縮はデフォルトではオフになっています。 Auto-Dream はメモリの統合に重点を置いています (#8347)
  • clickable タグと [タグ] タブを使用して ReMe Light メモリ ファイルを参照し、ファイル数、ページネーション、異なるビューから同じファイルを開いたときに保存された未保存の編集内容を表示します (#8470)
  • 構成済みの OpenViking サービスを介した、自動リコール、完了ターンの永続性、および明示的なメモリ検索を備えた OpenViking メモリ プラグインを追加します (#7613)

モデルと承認

  • ローカル インストールで ChatGPT サブスクリプションを使用してサインインし、プラットフォーム API キーなしでアカウントで利用可能なモデルを選択します。アカウントの切り替えとサインアウトをサポートします。リモートおよびハブのサインインはサポートされていません (#8437)
  • TypeSafe/JEV 意思決定モデルをチャット モデルとは別に設定し、ツールの承認に使用します。明示的な拒否は引き続き適用されます。不確実な評価またはサービスの失敗には手動の承認が必要です (#8205、#8283、#8360)

QwenPaw 作成者とデータ

  • カスタム スキル管理、スクリプトの直接インポート、ナレーションの重複防止、一時ファイルのクリーンアップを備えた Creator を 2.0.4 にアップグレードします。プロバイダー全体でのローカル メディアの処理を改善し、ASR 接続テストをより正確に検証し、設定されたテスト宛先に保存された資格情報を保持します (#8357、#8529)
  • データ アプリをランタイム 0.3.3 を使用して 1.0.3 に更新します。ワークスペース モデルを継承し、チャットごとのデータセット選択を保持し、完了するまで分析ストリームを開いたままにします。公開されたアプリのマニフェストは依然として QwenPaw 2.2.2 をターゲットにしており、2.3.0 の互換性を宣言していません。スコープ外の古いセッションはディスク上に残りますが、新しいリストには自動的に表示されません (9af3b184、#8346)

スキル、プラグイン、チャンネル、ツール

  • スキルプールのダウンロードをコンソールからキャンセルできるようにします。キャンセルの進行状況が表示され、以前にインストールされたスキルを保持するクリーンアップが表示されます (#8285)
  • オプションの API キー (#8200) を使用して、Web 検索プロバイダーとして Firecrawl を追加します。
  • コンソールでオプションの Tavily API キーを構成し、拒否されたキーまたはクォータおよびレート制限に対するキーレス フォールバックを使用します (#8204)
  • ライブ環境設定から構成可能なオプションのシェル メモリ保護を追加して、コマンド プロセスを監視し、キャプチャされた出力を制限します。デフォルトでは無効になっており、ベストエフォート型のリソース保護を提供します (#8574)
  • プラグインが明るいテーマと暗いテーマの両方で共有の背景、表面、境界線、およびテキストの色をオーバーライドできるようにし、プラグインがアンロードされるときにユーザーのプリセットを復元します (#8422)
  • Matrix のエンドツーエンド暗号化の依存関係をチャネルとともにインストールするため、個別の依存関係のインストールは必要ありません。暗号化はデフォルトでオフのままです (#8559)

評価

  • ベンチマーク スコア、コストと実行時間の比較、調整可能なベンチマークの重み、バージョン履歴、ダウンロード可能な結果レコードを含むバイリンガルの評価ページを追加します (#8253)

🔄 変更されました

  • 明示的なプロバイダーの選択を保持しながら、プロバイダーが保存されていない場合は、AnySearch をデフォルトの Web 検索プロバイダーとして使用します (#8536)
  • 承認メニューから直接意思決定モデルツールのレビューを有効にし、余分な会話スイッチを削除します。選択した意思決定モデルが利用できない場合は手動承認を使用します (#8556)
  • プラグインの依存関係チェックと共有アップグレードを調整して、影響を受けるランタイム、オプションの依存関係追加、アップグレード失敗時のロールバックを考慮します (#8598)
  • コンソールのレイアウト、タッチターゲット、キーボードナビゲーション、ロードと再試行状態、およびデスクトップとモバイル全体でのドラフト処理を改善します。繰り返されるポーリングと不要なバックグラウンド作業を削減します (#8332)
  • グローバル モデル管理をエージェントのランタイム設定から分離し、プロバイダー カードの API キーの編集をサポートし、宣言されたモデル機能と一貫性のある設定を維持します (#8240)
  • 数値コントロールを統合し、実行モード設定とサイドバーのスタイルを簡素化 (#8432)
  • エージェント作成時に最初のスキル選択を維持します。 「スキル」ページから既存のエージェントのスキルを管理します (#8448)
  • 既存の選択とユーザーが追加したモデルを保持しながら、モデルの推奨事項、機能メタデータ、プロバイダーのプリセットを更新します (#8447)
  • コンソール以外の公式チャネルをプラグインとして管理し、有効な場合にのみ別のプロセスで開始し、既存のチャネル構成を保持します (#8187)
  • すべてのアクティブなワークスペースを再構築せずにプラグインをインストール、更新、削除し、更新が失敗した場合はリソースをクリーンにシャットダウンしてロールバックします (#7565)
  • 各ワークスペース内で履歴データベース接続を再利用して、リクエストごとにセットアップとチェックを繰り返すことを減らします (#8482)
  • バンドルされたランタイムとインストールの依存関係を更新します。対応するアップデートおよびプラグインのインストール パスには pip 26.2.2 または uv 0.13.4 以降が必要です (#8391)
  • アクティブな履歴データベースを上書きする可能性がある従来のワークスペース ZIP アップロードおよびダウンロード API を削除します。ワークスペースのバックアップにはバックアップと復元を使用します。通常のファイル転送とプロジェクト ZIP インポートは引き続き利用可能です (#8508)

🐛 修正済み

コンソール、チャット、ファイル

  • 未送信の下書きを会話ごとに分けて保存し、送信されたコンテンツをすぐに消去し、応答が遅れて新しく入力したテキストが消去されるのを防ぎます (#8362、#8272)
  • アーカイブされた会話を含む、正しいエージェントの下で直接会話リンクを開き、無効または曖昧なリンクに対する再試行可能なエラーを表示します (#8209)
  • 会話の削除後に古いリクエストを停止し、モデル変更イベントのスコープを独自の会話に限定します (#8375)
  • 会話が切り替わっている間、インライン プラグインの送信を正しいセッションにバインドしたままにします (#8330)
  • 長い会話でのメッセージ ナビゲーションを修正し、セッションの切り替え中にサイドバーのポーリングを一時停止します (#8273、#8493)
  • スケジュールされたタスクおよびサブエージェント グループの最初の会話がグループ見出しと重複しないようにします (#8334)
  • 保存が完了する前に会話を切り替えるときに、思考スライダーの値を正確に表示し、送信された設定を保存します (#8287)
  • 検証または保存が失敗した場合でも構成エディタを開いたままにし、編集を続行するか変更を破棄するかの明確な選択肢を提供します (#8263)
  • 繰り返し保護のしきい値を表示および編集可能にします (#8282)
  • clipped モバイル モデル コントロールとバックグラウンド ツール ポリシー エントリを復元し、ポップアップ フォーカスとエスケープ処理を改善し、非表示タブでの通知ポーリングを一時停止します (#8452)
  • HTML プレビューが JavaScript に依存する場合を説明し、空のプレビューのままにする代わりにブラウザーで開くアクションを提供します (#8245)
  • 失敗したメディアのプレビューをコンパクトに保ち、展開時に完全なファイル名とエラーの詳細を利用できるようにします (#8451)
  • 完了したステップ カードにツール アイコンが cli で追加されないようにする (#8503)
  • 保存された履歴を保持しながら、低速接続での読み込みを改善するために、チャット履歴応答内のサイズの大きいツール出力を制限します (#8229)
  • キャッシュされた /clear または /new コマンドを復元するのではなく、再度開くか更新した後、クリアされた会話を空のままにします (#8600)
  • 最初のメッセージを通じて新しいタスクの選択されたプロジェクト ディレクトリを保持し、ディレクトリが保存されるときにファイル タブを開いたままにします (#8582)
  • 中国語の文字、スペース、Windows 区切り文字を含むパスを含む、ドキュメントのディレクトリに相対する Markdown プレビュー リンクと画像を解決します (#8551)
  • 設定検索とフィールド ナビゲーションを改善し、プラグイン ページでの設定ナビゲーションを保持し、現在のエージェント ランタイム (#8545、#8593、#8572) でサポートされている設定のみを表示します。
  • オーディオ表示ツールの翻訳された名前と説明を表示し、メディア ツールとグループ化します (#8597)
  • エージェントがファイルを編集するときに CRLF と混合行末を保持し、無関係なファイル全体の変更を回避します (#8235)

モデル、ランタイム、承認

  • 内部制御フラグをプロバイダーに漏らすことなく、各モデルの宣言されたリクエスト パラメーター (思考オフ設定を含む) を使用して、モデルのデフォルトと会話の思考設定を尊重します (#8358、#8436)
  • 圧縮、コンテキスト制限、タイトル、メディア チェック、および継承されたサブエージェント設定に対して、会話で選択されたモデルと思考設定を一貫して使用します (#8465)
  • モデルストリームの開始を待機している間にタイムアウトを適用し、静かにハングしているように見えるのではなく、長時間のレート制限待機を報告します (#8468)
  • 元のアセットと現在のターンのメディアを保持しながら、モデル入力から古いメディアを省略することで、リクエスト サイズ エラーから回復します (#8395)
  • ラマサーバー音声エラーや DashScope 音声 URL エラー (#8299、#7654) など、会話履歴でプロバイダーがビデオまたは音声を拒否した場合に回復します。
  • 会話を再度開いた後にコード モードのメディア プレビューを復元し、コード モード内で CloudPaw ツールを利用できるようにします (#8461)
  • コード モード計算に対する不必要な JEV 承認プロンプトを削減し、承認メッセージ内のローカル プリフライト チェック、利用できないサービス、およびモデル リスク評価を区別します (#8492)
  • 長いツール呼び出し中に ACP セッションを維持し、ターン終了前に最終応答を排出するため、完了したタスクの結果が失われないようにします (#8327)
  • 新しい検出プロトコルがプローブされると HTTP 422 を返す古い MCP サーバーに接続します (#8051)
  • 保存する前に無効な思考バジェットとコンテキスト制限を拒否することで、不正な値によって再起動後にプロバイダーが消えることがなくなります (#8550)
  • CLI セットアップ中にインストールされている Ollama モデルを検出し、検出が利用できない場合は構成されたモデルの選択を保持します (#8309)
  • 構成可能な 300 秒のデフォルト タイムアウトで遅い要約モデルをサポートし、単一の出力トークン制限を送信し、スクロールがコンテキストの使用量を過小評価した場合の回復を改善します (#8496、#8571)
  • 各モデル リクエストのインライン メディアの合計サイズを制限し、予算を超えた場合は新しいメディアを保持し、送信前に空のメディア ブロックを削除します (#8034、#8066)
  • コード モード ツールが describe_tool(name=...) (#8583) を含む内部ルーティングと衝突することなく name 引数を受信できるようにします。
  • サンドボックス分離なしでコマンドを実行するときに Windows cmd.exe 引用符を保持する (#8602)

記憶と歴史

  • 自動メモリーリコールコンテンツを目に見えるトランスクリプトやチャンネルメッセージから除外します (#7835)
  • API キーが空の場合は ReMe の再ランキングをスキップし、欠落している構成を明確に報告します (#8291)
  • 起動時に完了した履歴の移行をスキップし、バックアップ用にアクティブな SQLite データベースのスナップショットを安全に作成し、オプションの検索インデックス修復を備えた履歴チェック コマンドを追加します (#8541)
  • 予約された URL 文字を含む Windows の長いパス、ネットワーク パス、およびファイル名で履歴を正しく開き、呼び出し、バックアップできるようになりました (#8587)

スキルとプラグイン

  • GitHub (#8198) からスキルをインポートするときにバイナリ アセットを保持します
  • Make Skill の検証とインストールにネイティブ スキル CLI を使用することで、デスクトップ パッケージが内部 Python モジュールのインポートに依存しなくなります (#8344)
  • 失敗したプラグインを表示および削除可能な状態に保ち、スキル ハブのインストール状態を更新し、ローカル再インストールにバンドルされたソースを使用します (#8261)
  • 接続失敗、タイムアウト、TLS 問題、不完全な応答について明確なプラグイン ダウンロード エラーを表示 (#8397)
  • 通常の依存関係保護を維持しながら、冗長な依存関係チェックによって SDK プラグインのインストールが拒否されることを回避します (#8462)
  • インポートキャッシュの更新が失敗した場合でもプラグインのロードを継続する (#8497)
  • Windows パス比較や読み取り専用ソース ファイル バックアップの失敗を含む、デスクトップ チャネル プラグインのインストールと依存関係のアップグレードを修復します (#8509、#8633)
  • インストール ソース (#8231) を保持することで、サードパーティのマーケットプレイス プラグインをすべて更新に含めます。
  • プラグインの依存関係状態ディレクトリが使用できない場合と、書き込み可能な場所を設定する方法について説明します (#8527)
  • 組み込みの Make Skill バリデーターがスキル セキュリティ スキャナーによって誤ってブロックされるのを防ぎます (#8400)

クリエイター、メール、スケジュールされたタスク

  • 古い Windows プロセス チェック後の Creator の起動、ログが開いている間のプロジェクトの削除、および長い Windows パスの下で再試行できない決定のレビューを修正しました (#8196、#8210、#8167)
  • ドメインを再度追加せずに、完全な電子メール アドレスをメール アカウント名として受け入れます (#8438)
  • エージェントのリロード時に、実行中のスケジュールされたタスク、実行履歴、および同時実行制限を保持します (#8353)
  • スケジュールされたタスクの時間ピッカーの同期を維持し、保存に失敗した後に下書きを保存し、明示的な保存およびキャンセルのアクションを復元します (#8349)
  • 有効な命令を誤って空として拒否することなく、スケジュールされた Codex および Qoder タスクを実行します (#8535)

チャンネル

  • Matrix セッションと欠落しているデバイス キーを復元し、ID によって暗号ストアを分離し、Windows データを失ったり無関係なアカウントをブロックしたりすることなく、一致するレガシー状態を移行します (#8558、#8584、#8599、#8411)
  • 長い DingTalk 応答をマークダウン メッセージに分割して、テーブルと書式設定が保持されるようにします (#8341)
  • サポートされているチャネル メッセージおよび最終的な TUI 応答で、中国語、日本語、および韓国語の句読点の周囲の強調を正しくレンダリングします (#8067)
  • キャッシュされた値が元のタイプを失った場合に応答をドロップするのではなく、シリアル化されたチャネル応答設定を再構築します (#8564)

  • ハブ モデル ゲートウェイのタイムアウトを 600 秒のデフォルトで構成可能にし、更新中に保存されていないポリシー編集を保持し、機密情報が削除されたアップストリーム エラーを表示します (#8387、#8399)
  • デスクトップのアップグレード後に古い共有バックエンドを置き換え、実行中のバックエンドに新しいデスクトップが必要な場合に明確なメッセージを表示します (#8430)
  • PowerShell が PATH にない場合に Windows インストーラーの準備を回復し、空のランチャー ファイルを処理し、実際の準備の失敗を表示します (#8455)
  • Windows 上でデスクトップ ログを確実にローテーションし、macOS および Linux 上でローテーション後にリダイレクトされた出力を保持します (#8390)
