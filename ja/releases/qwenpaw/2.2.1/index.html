QwenPaw v2.2.1

パッチ 公開日2026年9月11日 出典agentscope-ai/QwenPaw 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#クウェンパウv2.2.1

何が変わったのか

✨ 追加しました

モデル、エージェント、メモリ

  • プロバイダー設定やフォールバック動作など、エージェントごとにモデル ルーティングを個別に構成します (#7501)
  • Auto Fin プロアクティブ メモリ レビューを追加し、より信頼性の高い長期メモリ処理のために ReMe をアップグレードします (#7441)
  • コンソールでの構成を使用して、オプションの長期メモリ バックエンドとして PowerContext を追加します (#7080)
  • リクエストのスコープ、untrusted コンテンツ、確認、ツールの使用、完了に関する組み込みエージェントの動作を強化 (#7526)

QwenPaw クリエイター

  • ブループリント ワークベンチ、マルチタイムライン比較、再利用可能なビデオ テンプレート、MiniMax H3 サポート、プロジェクト スナップショット ロールバック、より明確なエージェントの進行状況、および Creator 1.2.0 への Docker デプロイメントを追加 (#7486)

コンソールとワークスペース

  • エージェント、MCP サービス、ツール、ローカル モデルで共有される統合設定ページで環境変数を管理 (#7538)
  • 利用可能なプラグインと PawApp アップデートを検出し、1 つの click (#7605) でインストールします。
  • カスタマイズ可能なナビゲーションと改善されたセッション ブラウジングにより、サイドバーと設定エクスペリエンスを再設計しました (#7502)
  • セッションプロジェクトディレクトリ選択時にダイレクトパスエントリを復元 (#7593)
  • エージェント カンバンに中国語と英語のローカライズを追加 (#7482)

スキルと MCP

  • 選択したスキルの完全な命令をプリロードすることで、追加のアクティブ化手順なしで準備が整います (#7183)
  • ガイド付き製図、検証、動作テスト、公開ツールを使用して Make Skill をアップグレード (#7509)
  • スキルのバージョンを表示し、使用前に宣言された依存関係を検証します (#7609)
  • HTTP および SSE MCP clients の接続タイムアウトを構成する (#7649)

🔄 変更されました

  • 自動メモリ バックエンドに一貫したライフサイクルとアクション インターフェイスを提供し、ADBPG と PowerContext をプラグインとして提供します (#7561、#7616)
  • 明るいテーマと暗いテーマにわたってコンソールの色とコンポーネントの状態を標準化します (#7487)
  • 小さい画面でのエージェント セレクターを改善 (#7623)

🐛 修正済み

コンソール、チャット、ファイル

  • ストリーミング、会話の切り替え、メッセージの迅速な送信時の古いセッション状態とキュー送信競合を防止します (#7523、#7610、#7237)
  • 無料モデルを Pro モデル タブとは別にしておきます (#7524)
  • リンクからチャットを開くときに選択したループ モードを保持する (#7560)
  • コンソール全体で同じ言語オプションを使用する (#7595)
  • Chrome 拡張機能タブを正しい QwenPaw セッションとグループ化したままにします (#7457)
  • ナビゲーションとテーマ切り替えアイコンの視覚的な一貫性を持たせる (#7499)
  • インストールされているバージョンと利用可能なバージョンが異なる場合は常に PawApp の更新を表示 (#7651)
  • ワークスペース内でのみファイル アップロード コントロールを表示する (#7667)
  • フォームと Git パネルの一貫した QwenPaw スタイルを復元 (#7646)

ランタイム、セキュリティ、互換性

  • ポリシーがアクションを明示的に拒否しない限り、重要なセキュリティの検出結果には承認が必要です (#7525)
  • 各 MCP サーバーのツール許可リストをエージェント ランタイム パスに適用します (#7504)
  • 管理対象の Chromium インストールを起動パスから移動し、ブラウザーのセットアップで QwenPaw の起動をブロックできないようにします (#7539)
  • Windows 上でワークスペースの起動中に ACP エージェントが停止するのを防止 (#7401)
  • 一部のモデルで JSON 数値として出力される数値のように見えるツール引数を受け入れます (#6936)
  • 選択したモデルがテキストを受け入れてもドキュメント ブロックを受け入れない場合に PDF コンテンツを安全に変換する (#7621)
  • すでに消費されている思考コンテンツを折りたたむことで、コンテキストの制限内で長い会話を維持します (#7521)
  • 従来の認証フローが HTTP 401 による検出に応答する MCP サーバーとの互換性を復元 (#7627)
  • シェルの子プロセスが対話型入力に関して QwenPaw と競合するのを防ぎます (#7598)
  • 不明なツールの設定が要求された場合に、正しい not-found 応答を返すようにしました (#7498)
  • ダウンストリームのツール呼び出しハンドラーが失敗した場合に、完全な例外の詳細をログに保存し、安全なエラーをモデルに返します (#7578)

メモリ、ハブ、オペレーション

  • 設定されたバックエンドが利用できない場合に実用的なメモリのステータスを返し、プラグインをロードできない場合は安全にフォールバックします (#7544、#7663)
  • ライフサイクル操作をブロックせずにハブ ランタイムを開始し、アクティブなローカル ランタイムへの CLI リクエストを認証します (#7566、#7631)
  • 現在の ClawHub エンドポイントを通じてスキル検出を復元します (#7640)
  • 復元されたシークレットとマスター キーの Unix 許可ビットを保持 (#7658)
  • Base64 でエンコードされた画像やその他のメディアを、サポートされているチャット チャネル間で正しく配信します (#7647)
