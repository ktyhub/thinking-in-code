#プロンプトフ 0.124.1

0.124.1 (2026-10-08)

機能

  • アサーション: しきい値なしでコストを記録します (#11451) (037f1f6)
  • プロバイダー: OpenAI Decisions サポートを追加 (#11454) (2dbf3ec)
  • プロバイダー: カタログ テキスト トークンの価格設定 (#11452) (3ecce2e) を公開します

バグ修正

  • アサーション: 非同期式のグレーディングを保持します (#11453) (1df3eb8)
  • アサーション: キーワード プロパティのグレーディングを保持します (#11450) (a2da804)
  • アサーション: 生成後に正規表現オペランドを保持します (#11463) (4b4151a)
  • コード スキャン: CLI インストール後のミント OIDC (#11467) (9a404c8)
  • deps: 3 つの更新で 1 つのディレクトリにまたがる npm_and_yarn グループをバンプします (#11441) (84f7aaa)
  • deps: Sharp および Codex SDK のセキュリティ脆弱性 (#11456) (0c78299) にパッチを適用します。
  • eval: Google スプレッドシート URL の #gid を尊重します (#11460) (8950bce)
  • アサーション コメントとデータセット制限を処理します (#11435) (a65fe81)
  • クラウドエラーを保存し、npm エイリアスをチェックします (#11447) (8321730)
  • プロバイダー: 不完全な応答ステータスを公開します (#11465) (49ba1ce)
  • プロバイダー: 準備されたカスタム環境 (#11442) (4415bcb) を保持します
  • redteam: ターゲット出力の欠落をエラーとして報告 (#11445) (a2e6681)
  • redteam: データセット プラグイン行を均一にサンプルします (#11461) (e9ba85c)
  • redteam: 無効な JSON リクエストでメタを停止 (#11466) (d56d58c)
  • redteam: Codex パスと client クリーンアップを同期します (#11462) (99b2b09)
  • util: 完全な JSON オブジェクトを保存します (#11468) (bde0dbe)

パフォーマンスの向上

  • eval: 結果のフィルタリング時に抽出されたテストのインデックス (#11464) (ee1e987)
