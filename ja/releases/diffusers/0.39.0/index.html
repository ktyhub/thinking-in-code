新しいパイプライン

コスモス 3

Cosmos 3 は、物理 AI 用の NVIDIA の統一ワールド基盤モデル (WFM) です。これは、ワールド生成、物理推論、およびアクション生成を組み合わせた Mixture-of-Transformers (MoT) アーキテクチャ上に構築された単一のオムニ モデルであり、以前の Cosmos リリースの個別の Predict、Reason、および Transfer モデルを置き換えます。単一の Cosmos3OmniTransformer は、3D マルチモーダル RoPE と結合された拡散生成経路と並行して Qwen スタイルの言語モデルを実行します。このリリースでは、ビデオ間生成、アクション条件付き生成、およびサウンド エンコーダーも導入されています。

  • PR: https://github.com/huggingface/diffusers/pull/13818
  • ドキュメント: https://huggingface.co/docs/diffusers/main/api/pipelines/cosmos3

@atharvajoshi10、@yzhautouskay、@MaciejBalaNV の貢献に感謝します。

表意文字 4

Ideogram 4 は、マルチモーダル テキスト エンコーダーと非対称分類子を使用しないガイダンス スキームを使用する、テキストから画像へのフロー マッチング モデルです。専用の unconditional_transformer はゼロ化されたテキスト特徴を持つ否定分岐を生成し、メインの transformer は完全なパックされたテキスト + 画像シーケンスを消費します。パイプラインには、構造化されたプロンプト アップサンプリングと LoRA 読み込みサポートが付属しています。

  • PR: https://github.com/huggingface/diffusers/pull/13859
  • ドキュメント: https://huggingface.co/docs/diffusers/main/api/pipelines/ideogram4

@JinLiIdeogram の貢献に感謝します。

クレア2

Krea 2 (K2) は、グループ化されたクエリ アテンションを備えた単一ストリーム MMDiT を中心に構築された、テキストから画像へのフロー マッチング モデルです。 Qwen3-VL テキスト エンコーダーは、条件付けを提供します。12 のデコーダー層からの隠れた状態がトークンごとにタップされ、小さなテキスト融合ステージによってトランスフォーマー内で融合されます。画像は Qwen-Image VAE でデコードされます。 LoRA DreamBooth トレーナーとともに、ベース (ミッドトレイン) チェックポイントと TDM (蒸留、数ステップ) チェックポイントの両方がサポートされています。

  • PR: https://github.com/huggingface/diffusers/pull/14045
  • ドキュメント: https://huggingface.co/docs/diffusers/main/api/pipelines/krea2

@EleaZhong と @Abhinay1997 の貢献に感謝します。

ドリームライト

DreamLite は、ByteDance のテキストから画像への変換および画像編集モデルです。カスタム 2D U-Net (DreamLiteUNetModel) と Qwen3-VL マルチモーダル エンコーダーをプロンプト/画像命令エンコーダーとして組み合わせ、高速潜在エンコード/デコードに AutoencoderTiny (TAESD スタイル) VAE を使用します。抽出された DreamLiteMobilePipeline は、デバイス上の低遅延生成をターゲットとしています。

  • PR: https://github.com/huggingface/diffusers/pull/13815
  • ドキュメント: https://huggingface.co/docs/diffusers/main/api/pipelines/dreamlite

@Carlofkl の貢献に感謝します。

PRX ピクセル

PRXPixel は、Photoroom によるピクセル空間のテキストから画像への生成モデルです。 ~7B PRXTransformer2DModel は生の RGB 画像を直接ノイズ除去します。VAE は必要ありません。モデルは Qwen3-VL テキスト エンコーダーで条件付けされており、トランスフォーマーが各ステップ (x 予測) でクリーンなイメージを予測するフロー マッチングを使用します。

  • PR: https://github.com/huggingface/diffusers/pull/13928
  • ドキュメント: https://huggingface.co/docs/diffusers/main/api/pipelines/prx_pixel

@DavidBert の貢献に感謝します。

モチーフビデオ

Motif-Video は、テキストからビデオへの生成および画像からビデオへの生成のための 2B パラメーター拡散トランスフォーマーです。 3 ステージ アーキテクチャ (12 デュアル ストリーム + 16 シングル ストリーム + 8 DDT デコーダ レイヤー)、長いシーケンスにわたって安定したテキストとビデオの位置合わせを実現する共有クロスアテンション、T5Gemma2 テキスト エンコーダー、および速度予測のための整流フロー マッチングを備えています。

  • PR: https://github.com/huggingface/diffusers/pull/13551
  • ドキュメント: https://huggingface.co/docs/diffusers/main/api/pipelines/motif_video

@waitingcheung の貢献に感謝します。

エニーフロー

NVIDIA、NUS、MIT の AnyFlow は、フロー マップに基づいて構築された初のエニーステップ ビデオ拡散フレームワークであり、単一モデル (双方向または因果関係) が任意の推論バジェットに適応できるようにします。 Wan2.1 バックボーン上に構築された双方向パイプラインと FAR 因果パイプラインの両方を提供し、テキストからビデオ、画像からビデオ、ビデオからビデオをカバーします。

  • PR: https://github.com/huggingface/diffusers/pull/13745
  • ドキュメント: https://huggingface.co/docs/diffusers/main/api/pipelines/anyflow

@Enderfga の貢献に感謝します。

JoyAI-画像-編集

JoyAI-Image は、画像の理解、テキストから画像への生成、および命令ガイド付きの画像編集のための統合されたマルチモーダル基盤モデルです。 8B マルチモーダル LLM と 16B マルチモーダル拡散トランス (MMDiT) を組み合わせています。 JoyImageEditPipeline は、一般的な画像編集だけでなく、オブジェクトの移動、オブジェクトの回転、カメラ制御などの空間編集機能もサポートしています。

  • PR: https://github.com/huggingface/diffusers/pull/13444
  • ドキュメント: https://huggingface.co/docs/diffusers/main/api/pipelines/joyimage_edit

@Moran232 の貢献に感謝します。

拡散ジェマ

DiffusionGemma は、ブロック拡散エンコーダー/デコーダー言語モデルです。コーザル エンコーダーはクリーン プロンプト (および以前に生成されたブロック) を KV キャッシュに読み取り、双方向デコーダーはそのキャッシュにクロスアテンドすることで固定サイズのトークンの「キャンバス」のノイズを除去し、新しい BlockRefinementScheduler 経由で最も信頼性の高いトークンをコミットします。解放されたチェックポイントは google/diffusiongemma-26B-A4B-it です。

  • PR: https://github.com/huggingface/diffusers/pull/13986
  • ドキュメント: https://huggingface.co/docs/diffusers/main/api/pipelines/diffusion_gemma

アニマ

Anima は、CircleStone Labs と Comfy Org のコラボレーションによって作成された 20 億パラメータのテキストから画像へのモデルです。主にアニメのコンセプト、キャラクター、スタイルに焦点を当てていますが、他のさまざまな非フォトリアリスティックなコンテンツも生成できます。

CosmosTransformer3DModel を Qwen3 テキスト エンコーダー、T5 トークン テキスト コンディショナー、および AutoencoderKLQwenImage VAE とともに再利用します。

  • PR: https://github.com/huggingface/diffusers/pull/13732
  • ドキュメント: https://huggingface.co/docs/diffusers/main/api/pipelines/anima

@rmatif の貢献に感謝します。

LTX-2.X IC LoRA および HDR パイプライン

新しい LTX2InContextPipeline (インコンテキスト LoRA) および LTX2HDRPipeline は、インコンテキスト コンディショニングと HDR ビデオ生成により LTX-2 ファミリを拡張します。

  • PR: https://github.com/huggingface/diffusers/pull/13572
  • ドキュメント: https://huggingface.co/docs/diffusers/main/api/pipelines/ltx2
