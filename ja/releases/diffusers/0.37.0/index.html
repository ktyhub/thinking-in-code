ディフューザー v0.37.0

モジュラーディフューザー

Modular Diffusers は、再利用可能なブロックを構成することで拡散パイプラインを構築する新しい方法を導入します。パイプライン全体を最初から作成する代わりに、構成要素を組み合わせて特定のニーズに合わせたカスタム ワークフローを作成できるようになりました。これは既存の DiffusionPipeline クラスを補完し、カスタム拡散パイプラインを作成するためのより柔軟な方法を提供します。 モジュラー ディフューザーの使用を開始する方法の詳細については、こちら をご覧ください。また、発表投稿 もご覧ください。

新しいパイプラインとモデル

画像 🌆

  • Z Image Omni Base: Z-Image は、Z-Image ファミリの基礎モデルであり、高品質、堅牢な生成多様性、幅広いスタイルの適用範囲、および正確な即時遵守を実現するように設計されています。 Z-Image-Turbo は速度を重視して構築されていますが、Z-Image は最高レベルの創造的自由を必要とするクリエイター、研究者、開発者のバックボーンとなるように設計されたフル容量の未蒸留トランスです。 #12857 でこれを貢献してくれた @RuoyiDufor に感謝します。
  • Flux2 Klein:FLUX.2 [Klein] は、単一のコンパクトなアーキテクチャで生成と編集を統合し、わずか 1 秒未満でエンドツーエンドの推論による最先端の品質を実現します。品質を犠牲にすることなくリアルタイムの画像生成を必要とするアプリケーション向けに構築されており、わずか 13 GB の VRAM を備えた民生用ハードウェアで実行されます。
  • Qwen Image Layered: Qwen-Image-Layered は、画像を複数の RGBA レイヤーに分解できるモデルです。このレイヤー化された表現により、固有の編集可能性が解放され、各レイヤーは他のコンテンツに影響を与えることなく独立して操作できます。 #12853 でこれを提供してくれた @naykun に感謝します。
  • FIBO Edit: Fibo Edit は、構造化制御の新しいパラダイムを導入する 8B パラメーターのイメージ間モデルで、ソース イメージとペアになった JSON 入力で動作し、確定的で反復可能な編集ワークフローを可能にします。細かい精度を実現するネイティブ マスキングを特徴としており、単純なプロンプトベースの拡散を超えて、運用環境に最適化された明示的で解釈可能な制御を提供します。その軽量アーキテクチャは、深いカスタマイズ向けに設計されており、研究者が最高レベルの美的品質を提供しながら、ドメイン固有のタスクに特化した「編集」モデルを構築できるようにします。 galbria さん、https://github.com/huggingface/diffusers/pull/12930 に投稿していただきありがとうございます。
  • Cosmos Predict2.5: Cosmos-Predict2.5、Cosmos World Foundation Models (WFM) ファミリの最新バージョンで、世界の将来の状態のシミュレーションと予測に特化しています。 #12852 に貢献してくれた @miguelmartin75 に感謝します。
  • Cosmos Transfer2.5: Cosmos-Transfer2.5 は、適応マルチモーダル制御を備えた条件付きワールド生成モデルであり、複数の制御入力を条件とした高品質のワールド シミュレーションを生成します。これらの入力は、エッジ、ぼやけたビデオ、セグメンテーション マップ、深度マップなどのさまざまなモダリティを取ることができます。 #13066 に貢献してくれた @miguelmartin75 に感謝します。
  • GLM-Image: GLM-Image は、ハイブリッド自己回帰 + 拡散デコーダ アーキテクチャを採用した画像生成モデルで、視覚的な忠実性ときめ細かい詳細の上限を効果的に押し上げます。一般的な画像生成の品質は、業界標準の LDM ベースのアプローチと一致しており、知識集約型の画像生成シナリオにおいて大きな利点を示しています。 https://github.com/huggingface/diffusers/pull/12973 に貢献してくれた @zRzRzRzRzRzRzR に感謝します。
  • RAE: Representation Autoencoders (別名 RAE) は、画像生成の潜在空間拡散モデルの分野で通常使用される、従来の VAE に代わる魅力的な代替手段です。 RAE は、事前にトレーニングされたビジョン エンコーダーを活用し、再構成タスクのために軽量デコーダーをトレーニングします。

ビデオ + オーディオ 🎥 🎼

  • LTX-2: LTX-2 は、同期されたオーディオを含むビデオを生成できる、オーディオ調整されたテキストからビデオへの生成モデルです。完全なモデル推論と抽出されたモデル推論、および空間サンプリングを使用した 2 段階推論がサポートされています。また、さまざまな条件 (画像、一連の画像など) を渡すことができる調整パイプラインもサポートしています。詳細については、ドキュメントをご覧ください。
  • Helios: Helios は、単一の NVIDIA H100 GPU 上で 17 FPS で実行される 14B ビデオ生成モデルであり、品質の強力なベースラインと一致しながら分単位の生成をサポートします。 https://github.com/huggingface/diffusers/pull/13208 でこれを提供してくれた @SHYuanBest に感謝します。
