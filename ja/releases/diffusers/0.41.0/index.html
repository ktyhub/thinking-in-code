ディフューザー v0.41.0

[!ヒント] このリリースでは、テキストから画像への生成、画像編集、ネイティブ透明度、および LoRA トレーニングを備えた Qwen-Image 2.1 がディフューザーに提供されます。

このリリースから、私たちはトランスフォーマーのリリース哲学を採用しています。つまり、以前のリリース以降にマージされた他の変更を含めながら、新しいモデルの統合を中心にマイナー リリースを調整します。パッチリリースは引き続き修正に重点を置いています。 リリース ポリシー を参照してください。

Qwen イメージ 2.1

Qwen-Image 2.1 は、画像の生成と編集を 1 つのモデルで統合します。ビジュアル生成コンポーネントには 7B のパラメーターがあり、複数の参照イメージと透明イメージのネイティブ RGBA 出力をサポートしています。詳細については、ドキュメント を参照してください。

モデルの統合 (#14804) については @naykun に感謝します。

その他のハイライト

  • Tensor 並列チェックポイントのロード: 各ランクは、シャードされた重みの独自のスライスを直接読み取り、ロード中に必要なメモリを削減します。 (#14544)
  • LTX-2.5 DFR: 新しいパイプラインは、キーフレーム スロットを使用した生成と、コンポーザブルな空間的および時間的洗練をサポートします。 (#14567)
  • Cosmos 3: SeaCache サポートおよび ModelOpt FP8 チェックポイントの混合 W8A8/W8A16 ノイズ除去。 (#14663、#14664)
  • モジュラーディフューザー: Wan 2.2 VACE はモジュラーブロックを獲得し、既存のローカルパスからロードすることで不必要な重量ダウンロードを回避します。 (#14432、#14797)
  • 単一ファイル ローダーの追加: Krea 2 および MiniMax-H3 のサポート。 (#14914、#14839)
  • テスト: よりモジュール性と透過的なテスト実装を確立するために、モノリシック test_pipelines_common.py テスト スイートを削除しました。詳細については、https://github.com/huggingface/diffusers/pull/14669/を参照してください。

非推奨と互換性

🚨 ONNX サポートは廃止されました。 Optimum for ONNX ランタイム ワークフローを使用します。 (#14658)

以前に非推奨となった API は、LuminaText2ImgPipeline および Lumina2Text2ImgPipeline エイリアスを含めて削除されました。代わりに LuminaPipeline および Lumina2Pipeline を使用してください。古い統合では、アップグレードする前に 削除されたコード パス を確認する必要があります。

このリリースに貢献してくれた皆さんに感謝します!
