ディフューザー v0.43.0

[!ヒント] このリリースでは、画像生成、編集、オーディオ付きビデオ、音声駆動アニメーション、ワールド シミュレーションのための 5 つのモジュラー モデル統合が追加されています。また、アテンション バックエンド、テンソル並列処理、LoRA 処理、チェックポイント保存も改善されます。

MiniMax-H3-画像

MiniMax-H3-Image は、テキストから画像への生成と、1 つ以上の参照画像を使用した編集をサポートします。この統合には、固定の 6 ステップのサンプリング スケジュールと抽出されたガイダンスを備えた専用の画像トランスフォーマーとオートエンコーダーが含まれています。別のプロンプト強化ワークフローは短いリクエストを拡張し、アスペクト比を提案します。

ModularPipeline.from_pretrained(...) を通じてロードしてから、load_components(...) を呼び出します。 MiniMax-H3-Image ドキュメント では、参照イメージのプロンプト、出力サイズ、プロンプトの拡張、コンポーネントのオフロードについて説明しています。

ピカ H3 フレックス

Pika H3 Flex は MiniMax-H3 をベースとして構築されており、6 つのステップでビデオと同期ステレオ オーディオを生成します。テキスト プロンプト、最初および/または最後のフレーム、および個別のモジュール式ワークフローによるマルチモーダル参照をサポートします。統合には、LoRA アダプターのロードと、ロード済みの MiniMax-H3 コンポーネントを 2 つのパイプライン間で共有するためのガイドが含まれます。

ワークフローの選択、アダプターのロード、コンポーネントの再利用については、Pika H3 Flex ドキュメント を参照してください。

P-H3-画像

Pruna AI の P-H3-Image は、最大 8 つの入力画像を使用したテキストから画像への生成と命令ベースの編集を実現します。そのモジュラー パイプラインには、リクエストを詳細な生成または編集プロンプトに変換するプロンプト アップサンプラー、画像オートエンコーダー、およびテキスト コネクタが含まれています。チェックポイントでは、抽出されたガイダンスとともに 8 つのサンプリング ステップが使用されます。

画像のサイズ変更、参照画像の編集、プロンプト アップサンプリング、およびオフロードについては、P-H3-Image ドキュメント を参照してください。 #15171 への統合については @nifleisch に感謝します。

カンディンスキー S2V 1.0

Kandinsky S2V 1.0 は、参照画像と音声録音に基づいて人物をアニメーション化し、音声に合わせた全身の動きを含めます。ビデオを 5 秒のチャンクで生成し、チャンク間に FramePack メモリを運びます。提供された音声はサウンドトラックとなります。モデルがビデオを生成します。

モジュラー統合は、デフォルトの 16 ステップで PiflowScheduler を使用する蒸留バリアントを含む、Lite チェックポイントと Pro チェックポイントをサポートします。オーディオの準備、チェックポイント設定、メモリ要件については、Kandinsky S2V ドキュメント を参照してください。 #15164 での統合については @nvsm に感謝します。

パン 2

PAN 2 は、時間の経過に伴うアクションとカメラの動きを説明するプロンプトのシーンをシミュレートします。このリリースでは、テキストからビデオへのモジュラー ワークフローおよび画像からビデオへのモジュラー ワークフローを通じて、29B 生成シミュレーターが統合されています。コンテキスト並列処理と FirstBlockCache、MagCache、TaylorSeer キャッシュがサポートされています。プロンプトおよびビデオの安全性チェックはデフォルトで有効になっており、別個の pan2-guardrail パッケージが必要です。

読み込み、ガードレール、分散推論については、PAN 2 ドキュメント を参照してください。統合にはシミュレータも含まれます。プロンプトを記述する別の推論モデルは、モデルのドキュメントからリンクされています。 #15202 への統合については @wu-qing-157 に感謝します。

その他のハイライト

  • MiniMax-H3 テンソル並列処理: 大きな変調投影を含め、デバイス間でトランスフォーマーをシャーディングします。レプリケートされたパラメーターも、テンソル並列読み込み中に意図した dtype を保持します。参照: #14609、#15147。
  • AMD tention サポート: 新しい aiter_sage_hub バックエンドは、サポートされていない入力形状に対するネイティブ SDPA フォールバックを備えた、ハブでホストされる SageAttend カーネルを RDNA4 gfx1201 GPU にもたらします。 #15060を参照してください。
  • バックエンドの修正に注意: 1 つのモデルでバックエンドを選択しても、無関係なモデルのバックエンドは変更されなくなりました。個々のアテンション モジュールは、バックエンドの選択時に要件を確認して Hub カーネルをダウンロードするようになり、FlashAttendant-2 統合は新しいバージョンの Hub カーネルで動作します。 #14335、#15000を参照してください。
  • LoRA の修正: コンポーネントの重み付け辞書が複数のアダプター間で正しくブロードキャストされるようになり、Kohya テキスト エンコーダーの LoRA はモジュールごとのアルファ値を保持します。アダプターの重みに関するドキュメントと型ヒントでも、サポートされる形式が明確になっています。参照: #15128、#15157。
  • チェックポイントの保存: save_pretrained() は、シャード チェックポイントを単一ファイル チェックポイントに置き換えるときに、他のバリアントのシャードを保存し、古いインデックスを削除します。 #14844 を参照してください。
  • モジュラー キャッシュ: ステートフル キャッシュ フックは、例外を発生させる呼び出しを含む各パイプライン呼び出し後にリセットされるため、後続の世代は新しいキャッシュ状態から始まります。 #15212 を参照してください。
  • トレーニング例: テキストから画像への LoRA および SDXL LCM LoRA スクリプトの勾配 clipping を修正し、現在の Transformer の FLUX 量子化埋め込み準備を更新し、--revision によるトレーニングをクラッシュさせた期限切れの非推奨ブロックを削除します。参照: #15184、#15144、#15118。
  • ドキュメント: 分散推論ガイドを再構成し、ネイティブ TorchNeuron 用の AWS Trainium サンプルを更新し、Cosmos3 FP8 チェックポイントの場所を修正しました。参照: #15172、#15138、#15236。

非推奨と互換性

  • 依存関係チェック: 可用性チェックでは、サポートされている依存関係バージョンが強制されるようになりました。サポートされている最小値を下回るインストール済みパッケージは利用できないものとして扱われ、アップグレード メッセージが表示されます。たとえば、既存の最小値 torch>=2.6 および transformers>=4.41.2 がこれらのチェックによって適用されるようになりました。 (#15148)
  • 再配置されたモデル コンポーネント: 潜在アップスケーラーと条件エンベッダーは diffusers.models の下に移動します。既存のチェックポイントは引き続きロード可能ですが、古いパイプライン モジュールのインポートは 1.0.0 で削除される予定です。 from diffusers import LTX2TextConnectors などのパブリック インポートを使用します。参照: #15111。
  • モジュラー入力のデフォルト: 明示的に None を渡すと、その値が保持されます。省略された入力は、それを読み取る最初のブロックのデフォルトを受け取ります。必須と宣言された InputParam と非 None デフォルトの両方が宣言された InputParam はオプションとして扱われ、警告が生成されます。参照: #15135、#14521。
  • トレーニング動作: 影響を受ける LoRA サンプルで --max_grad_norm が有効になるようになりました。したがって、clipping しきい値を超える勾配での実行は、以前のバージョンとは異なる動作をする可能性があります。参照: #15184。
  • コンポーネントの読み込み: リポジトリ設定により、任意のコンポーネント ライブラリのインポートが発生しなくなります。サポートされているライブラリ セット外のカスタム コンポーネント モジュールは、呼び出し元によってすでにインポートされている必要があり、モジュラー カスタム ブロックの読み込みでは、要件を処理する前にリモート コード trust がチェックされます。参照: 3076605。 コード、ドキュメント、レビュー、問題レポートに貢献してくれた皆さんに感謝します。
