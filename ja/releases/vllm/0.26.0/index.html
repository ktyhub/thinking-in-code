vllm v0.26.0

vLLM v0.26.0 Release Notes

ハイライト

このリリースには、212 人の寄稿者 (61 人が新規) からの 411 件のコミットが含まれています。

  • 新しい Inkling モデル ファミリー は完全なサポート スタックを備えています: ベース モデリング (#48799)、区分的 CUDA グラフ サポート (#48822)、Hopper FA4 相対アテンション (#48858)、MTP=1 投機的デコード (#48869)、LoRA (#48884)、および標準 ModelOpt NVFP4 量子化 (#48990)。
  • DeepSeek-V4 のパフォーマンスをベンダー全体で推進: 特殊なルーティング カーネル (2.94% E2E TPOT、#48660)、fused_topk_bias (1.5–2x カーネル、#47463)、冗長リピート/コピーの削除 (1.8% E2E TPOT、#48137)、および HCA 用の ROCm 2 段階コンプレッサープレフィル (#47718)、スパース デコード/プレフィル最適化 (#48519、#48788、#46275)、AMD (#47419) および XPU (#47677) での DSpark 投機的デコード。
  • head_dtype (#48390) を介した生成モデル用の fp32 lm_head。LoRA パス (#48525) に拡張され、ROCm torch.mm 高速パス (#48688) が与えられ、生成ヘッドの精度が向上しました。
  • 柔軟なアテンション バックエンド: アテンション バックエンドは KV キャッシュ グループごとに選択できるようになり (#48012)、スライディング ウィンドウのサポートは明示的なバックエンド機能 (#48011) になり、ハイブリッド モデルのサポートが向上します。
  • KV オフロードと階層型セカンダリ ストレージは大幅に成熟しました: オフロード メトリクス (#45958、#47666、#47679)、階層所有イベント処理 (#46544、#47923)、ワークロード ID を備えたオブジェクト ストア セカンダリ階層 (#47063、#47274、#48150)、DP レプリカ対応階層化(#47987)、および CPU オフロードを含むエンコーダー キャッシュ (EC) コネクタ (#42433、#47423)。
  • Rust フロントエンド には、マルチモーダル ビデオ (#47959) とオーディオ (#48554)、Seed-OSS ツール パーサー (#47741)、およびネイティブ vllm-bench ポート (#48107) が追加されました。
  • トランスフォーマー 5.13.0 (#47867) と、より多くのモデルがトランスフォーマー モデリング バックエンドに移行されました: Olmo/Olmo2 (#48100)、MistralLarge3 (#48153)、および HunyuanVL (#47872)。

モデルのサポート

  • 新しいモデル: Inkling ファミリ (#48799、#48822、#48858、#48869、#48884、#48990)、BertForMaskedLM (#48463)、RobertaForTokenClassification / XLMRobertaForTokenClassification (#47991)、LongCat-Flash-Lite n-gram 埋め込み(#47857)、Cosmos3 Edge Reasoner (#48291) および Cosmos3-Super 登録 (#48211)、TranslateGemma-12b-it (#41599)。
  • Transformers バックエンドの移行: Olmo/Olmo2 (#48100)、MistralLarge3 から AutoWeightsLoader (#48153)、Transformers 5.13 用の HunyuanVL ネイティブ トランスフォーマー プロセッサ (#47872)。
  • GLM5.2: MoE シーケンス並列サポートを非トーチ コンパイル パスに移行します (#47881)。
  • LoRA: BF16 モデル用 FlashInfer MoE LoRA (#48632)、LlavaNextVideo のタワー/コネクタ用 LoRA (#48594)、LoRA パス上の fp32 lm_head (#48525)、最適化された TrtLlmLoRAExperts (#48759)。
  • マルチモーダル: TP が利用できない場合、ViT データ並列処理への自動フォールバック (#49046)。
  • 修正: torch.compile でのチャンク プレフィルのプーリング スコアが修正されました (#48901)。

エンジンコア

  • head_dtype (#48390) を介した世代モデルの場合は fp32 lm_head。大きな CUDA グラフ サイズをキャプチャするためのメモリの削減 (#48483);オプトインの永続性と、ブート後のメモリ プロファイリング結果の再利用 (#47388)。 InstantTensor の読み込みを改善しました (#46868)。
  • アテンション: KV キャッシュ グループごとに異なるアテンション バックエンドを選択します (#48012)。明示的なバックエンド機能としてのスライディング ウィンドウ (#48011); KV キャッシュ レイアウトは、バックエンド全体で K/V をコンテンツ dim にパッキングするリファクタリングを行いました (#44455)。 MLA 用の MRV2 仮想バッチ PCP (#46570)。
  • 投機的デコード: ランタイム ドラフト ウェイト アップデート (#46725)、ハイブリッド (SWA + フル アテンション) DFlash ドラフター (#47914)、qwen-eagle3 の SWA サポート (#47568)、Gemma4-12B DSpark ドラフト モデル (#47216)、AMD 上の DSv4 DSpark (#47419)、speculative_config 用の個別の kv_cache_dtype (#48787)。
  • KV オフロード: 基本的なオフロード メトリクス (#45958)、CPU キャッシュ使用量を読み取り/書き込みゲージに分割 (#47666)、階層化ルックアップ遅延を同期/非同期ヒストグラムに分割 (#47679)、階層所有のイベント処理と BlockStored イベント (#46544、#47923)、ワークロード ID を備えたオブジェクト ストア セカンダリ階層 (#47063、 #47274、#48150)、DP レプリカ対応階層化 (#47987)、異種 KV グループの blocks_per_chunk 構成 (#48878)、P2P デフォルトのホスト/ポート環境変数 (#47636)。
  • キャッシュ: ハイブリッド モデルの部分的なプレフィックス キャッシュ ヒット (#46384)、選択的なハイブリッド キャッシュ保持 (#47782)、フル レポート モードでのプレフィックス キャッシュ再利用ブロックのレポート (#45261)。
  • 推論: 投機的デコードで使用する場合、思考バジェットの TPOT を最適化します (#46662)。
  • RLHF: ステートフル トレーナー送信抽象化 (#48042)。
  • 修正: 非排出 new_block_ids によるホスト メモリ リーク (#44490)、DSv3.2 + MTP + シーケンス並列精度 (#48036)。

ハードウェアとパフォーマンス

  • DeepSeek-V4: 特殊なルーティング カーネル (2.94% E2E TPOT、#48660)、fused_topk_bias 1.5–2x (#47463)、冗長リピート/コピーの削除 (1.8% TPOT、#48137)。
  • MoE ルーター GEMM: BF16x3 ルーター GEMM (#47973)、FP32 ルーター GEMV (#48335)、汎用 CuteDSL LL BF16 ルーター GEMM (#42562); TRTLLM BF16 MoE モジュラー カーネル (#45182); FlashInfer を最終出力に結合して書き込みます (#47156)。
  • Qwen: Qwen3.5 で RMSNorm + all-reduce をさらに融合 (#46998)、MoE all-reduce を Reduce-scatter に置き換え (#47006)、Qwen3.5 H20 最適化 (#48350)、Triton ウォームアップ範囲を拡張 (#47546)。
  • MLA: 短いスパース MLA シーケンス用の高密度 MHA パス (#47327)。 sm100 上の MiniMax-M3 ロングコンテキスト デコード インデクサー (#48582)。
  • カーネル: ReLUSquaredActivation / relu^2 用の CUDA カーネル (#39058)、Helion カーネルの遅延登録 (#48264)、_copy_mamba_state_block を uint64 にベクトル化 (#48110)、サンプラーでの fp32 へのログのアップキャストの停止 (#48641)。
  • ROCm: fp32 head_dtype torch.mm 高速パス (#48688)、DSv4 2 段階圧縮カーネル (#47718)、スパース デコード/プリフィル最適化 (#48519、#48788、#46275)、DSv3.2 スパース MLA KV 分割ヒューリスティック (#46832) MTP CUDA グラフ モード (#45149)、MiniMax-M3 用 MXFP8 GEMM (#46117)、MiniMax-M3 用 AITER スパース ページ アテンション + 仕様デコード (#47287、#47984)、MiniMax-M2 融合 QK ノルム + AITER 経由の all-reduce (#44849)、HybridW4A16 リニア カーネル(#40977)、Qwen3-30B-A3B QK-Norm+RoPE+KV ランタイム フュージョン (#42749)。
  • XPU: バッチ不変カーネル (#41934)、HND KV レイアウト サポート (#47975)、DSv4 の DSpark 仕様デコード (#47677)、夜間/リリース イメージ公開 (#47880、#48126)。
  • CPU: CPU 上の GDN モデルの DFlash 投機的デコード (#46090)、s390x NUMA トポロジ (#40714)、ネイティブ macOS arm64 CPU ホイール ビルド (#48289)。 POWER VSX 数学関数の最適化 (#47321) と、事前構築されたホイールを使用した IBM Power docker ビルド (#46017)。
  • 分散フュージョン: FlashInfer MNNVL オールリデュース RMS クオンツ フュージョン (#48064)。
  • ビルド/自動調整: arm64 Blackwell SM10x/SM110 イメージ ビルド (#48041);デフォルトで CuTeDSL fp4_gemm 自動チューニングをスキップします (#48268)。

大規模なサービス提供と分散

  • デコード コンテキスト パラレル (DCP): ハイブリッド アテンション サポート (#40996)、Tokenspeed MLA バックエンド用の DCP + Eagle (#48180)。
  • PD 分解: プッシュ モードでの NIXL パイプライン並列プレフィル (#45880)。
  • エンコーダー キャッシュ コネクタ: EC 転送パラメータ (#42433) および CPU オフロード EC コネクタ (#47423)。

量子化

  • 圧縮テンソルを使用した重みのみの推論でのハミング w[2-7]a[4,8] (#46390);エミュレーション MoE バックエンドの int4 量子化 (#48451); INT2 XPU 重みのみの量子線形 (#47521)。
  • NVFP4/MXFP4: nvfp4_per_token オンライン MoE 量子化 (#48538)、CuTe-DSL FlashInfer MXFP4 量子化 (#48417)。 Marlin (#47851) および NVFP4 MoE ウェイト ロード (#46276) の FP4 MoE ウェイトを再パックするときの制限されたピーク メモリ。
  • MLA: kv_cache_dtype_skip_layers のサポート (#47309)。
  • ROCm: HybridW4A16 リニア カーネル (#40977)。

API とフロントエンド

  • Rust フロントエンド: マルチモーダル ビデオ (#47959) およびオーディオ (#48554)、Seed-OSS ツール パーサー (#47741)、ネイティブ vllm-bench ポート (#48107)、レンダラー センチネルによる continue_final_message 処理 (#47844)。
  • OpenAI 互換性: /v1/completions の bad_words (#46793)、Python OpenAI エンドポイントで logprob_token_ids を公開 (#43463)、非 Harmony モデルの include_reasoning パラメーター (#44301)、メッセージ応答で num_cache_creation_tokens を設定 (#48535)。
  • エンドポイント プラグイン フレームワーク (#47454); RLHF dev API ルーター上の /abort_requests (#47173)。ディープストリーム ビデオ デコード バックエンド (#42424);オフライン推論でのプーリングモデルの前処理と計算を重複させます (#47699)。
  • UX: より多くの CLI 引数のための人が判読できる整数 (#47608)、CuTeDSL コンパイル進行状況バー (#48881)、拡張された GPU プロファイラー設定スコープ/注釈 (#37524)、プロセスが予期せず終了したときのワーカー終了コードのログ (#38641)。
  • 安定性/正確性: エンジンをクラッシュさせることなく文法コンパイルの失敗を処理し (#47312)、SentencePiece スペースからの logprobs トークン文字列の衝突を修正しました (#48674)。

セキュリティ

  • ディスクキャッシュを置き換えて、pickle 逆シリアル化を排除します (#44549)。
  • CVE 修復をバイパスする同時スパースインバリアント競合を修正しました (#48583)。
  • レンダリングエンドポイントにリソース境界検証を追加 (#47260);検証エラー応答からサーバー ファイル パスをサニタイズします (#46415)。無制限のエンジンファンアウトを防ぐために、完了プロンプトリストを制限しました (#47845)。 lm-format-enforcer 正規表現コンパイルをタイムアウトでガードします (#47595)。

依存関係

  • トランスフォーマー 5.13.0 (#47867)、FlashInfer 0.6.14 (#47669)、NIXL 1.3.1 (#47559)、tpu 推論 v0.24.0 (#47835)、nvidia-cutlass-dsl 4.6.0 (#47442)、vllm_xpu_kernels v0.1.11.1 (#48942)。
  • FlashAttendant 3 はトーチ安定版 ABI コミットに固定されています (#47995)。 ABI 安定の FlashMLA ビルド (#48174)。

非推奨と削除

  • 削除されたモデル: TeleChat (#47989)、Persimmon および Fuyu (#48096)。
