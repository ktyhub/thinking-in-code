vllm v0.33.0rc3

#v0.33.0

ハイライト

このリリースには、389 人の寄稿者 (122 人が新規) からの 927 件のコミットが含まれています。

  • 新モデル: DFlash2 ドラフターを備えた Reflection Beam-1.0 (501B MoE、23B アクティブ) (#62074)、Yandex AliceAI-Foundation-80B-A3B (#57963)、Recursive Flint (40B MoE、2.5B アクティブ) (#62938)、Muse Spark Open (#61879)、ステップ 5 プレビュー (#61727、#63147)、NVIDIA Alpamayo 2 Super (#62957)、Nemotron-Labs Dory1.0-4B (#60149)、Nemotron Parse 3.5 (#61651)、MiniCPM-OCR 1.0 (#63095)、Domyn Edge (#62544) と ColUltraVBERT ビジュアル ドキュメント レトリーバー (#62237)。
  • PyTorch 2.14: vLLM は、torchvision 0.29.0 および Triton 3.8.0 (#52183) を備えた PyTorch 2.14.0 にアップグレードされます。
  • CUDA 12.9 は削除されました: リリース ホイールと画像は CUDA 13.0 のみです。 CUDA 12.9 ホイールと -cu129 / -cu129-ubuntu2404 画像は公開されなくなりました (#62575)。代わりに、デフォルトの CUDA 13.0 アーティファクトを使用してください。
  • libtorch ABI の安定した CUDA ホイール: CUDA ホイールは、libtorch で ABI 安定になりました。
  • AWS EFA イメージ: 新しい vllm/vllm-openai:v0.33.0-efa イメージ (x86_64 および aarch64) には、AWS EFA ライブラリと Mooncake 転送エンジンの EFA ビルドがバンドルされており、EFA が有効な EC2 インスタンス (#58768) で KV 転送とマルチノードを提供します。
  • vllm/vllm イメージ エイリアス: すべてのリリース イメージは、短い vllm/vllm 名でも公開されるようになりました。 vllm/vllm:v0.33.0、vllm/vllm:v0.33.0-efa、vllm/vllm:v0.33.0-rocm。
  • 投機的デコード: DFlash や DSpark などのブロック拡散ドラフター用の新しい XPress リファイナー (#54448)。 FLy、MI355X および B300 で 1.04-1.31x デコード スループットを備えたオプトイン非可逆検証ポリシー (#53987)。 DFlash/DSpark はトークン バジェットでドラフト スロットを予約しなくなり、PR のベンチマーク (#59468) で GB300 上の DeepSeek-V4.1-Flash + DSpark の出力トークンが 1373 から 3390 に増加しました。量子化されたドラフト lm_head (draft_lm_head_quantization、同時実行時 18% デコード) (#59973);先読みブロック ハッシュにより、EAGLE/MTP プレフィックス キャッシュ ヒットが最後のブロックを保持します (デフォルトでオン)。トランスフォーマー モデリング バックエンドの MTP ドラフト (#61270)。
  • NVIDIA でのより高速なデコード: Kim-K3 (TP8/TP16 での 1.5-2x、#61867) および DeepSeek-V4.1-Flash (バッチ 1 での 18.3% 高速なデコード ステップ、#61868) の GB300 でのオプトイン レイテンシーに特化したデコード。 DeepSeek-V4/V4.1 MXFP4 エキスパートは、Humming on Hopper を通じてブロック FP8 として実行されます (4x H200、#61875 で +9 ～ 21% のデコード)。 Blackwell での FA4 スパース MLA デコード (#55866)。 trtllm-gen での FlashInfer DCP プレフィルは、8xB200 の 100k 入力で平均 TTFT が 39 ～ 48% 低下しました (#62029)。 MRV2 プレフィル コンテキスト並列処理でのデコード専用の完全な CUDA グラフ (2.6 倍、eager、#62377)。
  • AMD ROCm: デフォルトの ROCm イメージとホイールは ROCm 10.0 に移動し、ROCm 7.2 は引き続き -rocm72 (#58761) として公開されます。 MI300X/MI325X 上の DeepSeek-V4.1-Flash (同時実行 1 での 2.32x P50 インタラクティブ性、#60731) およびすべての MI355X レイヤー (#61082)、および MI355X 上の MiniMax-M3-MXFP4 (16.6% 低い TPOT、 #62712、#62994); ROCM_OCTAVE 3 ～ 4 ビット KV キャッシュ (RX 7900 XTX 上の fp16 の KV トークンの 4.6 倍、#59774)。 gpt-oss-120b、DeepSeek-R1、DeepSeek-V4-Flash、および MiniMax-M3 (#58800) の gfx1250 の有効化。
  • API およびサービング: OpenAI 互換の /v1/decisions エンドポイント。サポートされる世代モデル (#60465、#61550) ではデフォルトでオンになります。 /v1/embeddings でオプションの後期チャンクを使用したトークン埋め込み (#61772、#63051、#60164)。 /inference/v1/generate 上の output_mode="derender" (#60082);長い会話での HTTP 500 の廃止 (#62374) や起動時に失敗するサポートされていないフラグ (#62431) を含む、大規模な Rust フロントエンド パリティ プッシュ。 TP > 1 でのワーカーの同時起動 (#60028);そして、スタックしたエンジンとワーカープロセスからスタックトレースをダンプするウォッチドッグ (#55700)。
  • 重大な変更: Medusa と MLP スペキュレーターが削除されました (#61701)。従来の Ray コンパイル済みグラフ エグゼキュータが削除されました (#61712、#62228)。 --mamba-cache-mode は非推奨になりました (#60043)。生成の一時停止中に送信されたリクエストは HTTP 503 を取得するようになりました (#51488)。 NIXL コネクタには NIXL 1.5 以降 (#61032) が必要です。 LM フォーマット エンフォーサと --ir-op-priority は非推奨になりました (#63423、#63371)。

モデルのサポート

  • 新モデル: Reflection Beam-1.0 (BeamForCausalLM) は、DFlash2 ドラフターと融合 Blackwell カーネル (#62074、#62042)、さらに beam 推論およびツール パーサー (#62052) を使用して初日からサポートされます。 Yandex AliceAI-Foundation-80B-A3B (キミ デルタ アテンション ハイブリッド、512 人の専門家 MoE、262K コンテキスト) (#57963);小規模バッチ Blackwell デコード カーネルを使用した再帰的 Flint BF16 および NVFP4 GGUF チェックポイント (#62938)。 Muse Spark Open (#61879) と推論およびツールパーサー (#62207)。ステップ 5 プレビュー (#61727、#62126、#62132)、SM100 (#63147) と LoRA (#62498) で実行。 NVIDIA Alpamayo 2 スーパー (#62957); Nemotron-Labs Dory1.0-4B (#60149); Nemotron は MRV2 上の MTP プロポーザーを使用して 3.5 を解析します (#61651)。 MiniCPM-OCR 1.0 (#63095);ドミン・エッジ (#62544); ColUltraVBERT (#62237); LFM2.5-Embedding-350M (Lfm2BidirectionalModel、#62201);トランスフォーマー バックエンドを介した Kolibri 1 (#60827); /v1/systemone の Decision 3.0 モデル (#61565、#61778) と Cloudflare Clef-Flash (#61308)。
  • DeepSeek-V4 および V4.1: 長さを認識したデコード インデクサー ブロックの選択 (1M コンテキストでステップごとに約 850 us を節約、#61039); MegaMoE の専門家は、reload_weights が動作するように DeepGEMM レイアウトに直接ロードしました (#60096)。 fused_wqa_wkv は SM90 の TP 全体でトークンによって分割されました (#58872)。 MegaAttn wo_a は wo_b の MXFP8 入力を書き込みます (#60118)。 SM90 上のネイティブ スモールヘッド FlashMLA スパース プレフィル (#61615)。 FlashMLA インターリーブ KV レイアウト (#61371);冗長 EPLB エキスパート スロットがロードされました (#59611)。 GPU Engram テーブルがピア HBM から読み取られ、GB200 での DEP デコードのハングが修正されました (#62091)。 PP での Engram (#62208)、Engram all-to-all ハング (#62269)、プリフィル インデックス ワークスペース NaN (#60613)、PIECEWISE グラフでの C128 圧縮 KV 書き込み (#59709)、リプレイでのルーティングされたエキスパート行 (#61643、#62652)、および更新された 1017 参照エンコーディングの修正(#62199、#62200)。
  • GLM: GLM-5.3-Flash はデフォルトで FP8 KV キャッシュ (PR のベンチマークで 9.8% 高いエンドツーエンド スループット、#61228) を使用し、Blackwell で mHC TileLang デコード カーネルを取得します (#62745)。 GLM-5.3 トークン グループごとのクオント (2.8% ITL、#60927)、インプレース ドラフト デコード メタデータ (#61873)、およびスキップされた concat_and_cache_mla スケール (B300 の 1.2-3.0% TPOT、#62102)。 FP8 インデクサー WK ペアは load_weights 呼び出し全体で保持され、runai_streamer による思考ループを修正しました (#59223)。
  • Kimi-K3: KDA RecoverSSM CuTe DSL は SM10x でカーネルを検証/コミットします。検証レコードは KV キャッシュから移動され、KV コネクタが機能します (#63045)。 NVIDIA プロジェクションのオンライン量子化 (#62980)。
  • Qwen: Ampere 上の Qwen3.8-Flash-Next FP8 QSA KV キャッシュ (#60602、#60992)、1 つの DGX Spark (#56273) および PLE short-conv プリフィル チェックポイント (#61601) 上の Qwen3.8-Flash-Next-NVFP4 に適合するパックされた NVFP4 PLE エンベディング。 Qwen3-Next / Qwen3.5 の FlashInfer GDN 事前入力チェックポイント (#60050)。
  • その他のモデル: Cohere2MoE アテンション/MoE デュアル ストリーム、シングル TP オールリダクションおよび融合加算 + RMSNorm (1.14-1.36x TPOT、デフォルトでオン、#62101);ビーム TP オールリダクションがノルムと MoE ファイナライズと融合されました (#62366)。 MiniMax-M3 CUTLASS MSA デコード クロスオーバー (#55838); EAGLE3/DFlash/DSpark ターゲットとしての Granite MoE (#61110); NemotronHMTP 共有ターゲット埋め込み (#62194); BERT クロスエンコーダーおよびトークン分類用の LoRA (#61279、#61391)。
  • マルチモーダル: PaddleOCR-VL バッチ ビジョン エンコーダー (スループットが 34 ～ 85% 向上、#61458) および compile_mm_encoder (#61838)。 DeepSeek-VL2 ViT フル CUDA グラフ (#46005); Gemma4Unified バッチ埋め込み (#60643);コンパイル中の Pixtral 実数値 RoPE (#63145); EXAONE-4.5 イメージ (v0.29.0 以降壊れている、#61104)、Gemma 4 エンコーダー グラフ (#61365、#60687、#63538)、DeepSeek-VL2 エンコーダー キャッシュと PP (#63120、#63192)、および Gemma 4 プレースホルダー (#61196) の修正。
  • トランスフォーマー モデリング バックエンド: MTP 投機的ドラフト (#61270)、融合ポストトップ k MoE ルーター (#57410)、AOT キャッシュの代わりにグラフ キャッシュ (#58918)、および動的 RoPE CUDA グラフ (#58064)。

エンジンコア

  • 投機的デコード: XPress (#54448)、FLy (#53987)、DFlash/DSpark のドラフト スロット バジェット予約なし (#59468)、量子化ドラフト lm_head (#59973)、先読みブロック ハッシュ (#61589)、リクエストで使用できない MRV2 スキップ ドラフト (最大 7.3% プレフィル) DFlash によるスループット、#62784)、Triton Split-K 検証 (#56148)、適応検証のための varlen Mamba2 デコード (#53036)、ストップトリムされたトークン数の修正 (#58668)、ブロック検証のランダム性 (#61161)、MTP ブロック テーブル (#61174)、文法マスク (#52477)、EAGLE SWA プレフィックス ヒット(#62206)、DFlash/DSpark Mamba チェックポイントの再利用 (#54163)、および PP ウォームアップ (#62129)。
  • Model Runner V2: 適応検証 (#58466) を備えた GPT-OSS のバッチ シャーディング サンプリング (#61257)、GB200 での 31 ～ 120 倍高速なロングプロンプト ステージ書き込み (#62698)、後の PP ステージでエンコーダー タワーをスキップ (ステージあたり 0.58-1.27 GiB、#60238)、ngram 用に保持される非同期スケジューリング(#62521)、後期の PP ステージでの input_ids (#61016)、およびメモリ プロファイリングの修正 (#57926、#58243、#61509、#63431)。
  • サンプリング: Triton top-k/top-p は、マスクされたロジットのカットオフ検索をスキップします (最大約 8 倍、#61213)。スモールバッチ スプリット トップ P (B300 の 1.22-2.70x、#61996)。巨大なロジットと境界関係の修正 (#58231、#62046)。
  • 起動と信頼性: TP > 1 でのローカル ワーカーの同時起動 (TP8、#60028 で約 50 秒を節約)。共有 Triton JIT コンパイル プール (コールド ウォームアップが 9 ～ 28% 高速化、#61422)。エンジンとワーカーのウォッチドッグ (#55700); libgomp フォークのデッドロックが修正されました (#62884)。エキスパート並列処理 (#55490) とデーモン修正 (#62583、#63451、#63088、#62734、#63506) によるファスト スタート。 SHM ブロードキャスト リーダーのメモリ増加が修正されました (#63165)。
  • メモリとパフォーマンス: ソートされた融合 MoE パス上の UVA オフロード MoE 専門家 (+7-19%、#62054);同種プーリングのための DispatchPooler バイパス (最大 10.3%、#62940)。リニアタイムエンコーダキャッシュフリー (#62850);スライディング ウィンドウ ブロック テーブルの null 解放エントリ (#60767)。
  • LoRA: flashinfer_trtllm の MXFP4 MoE のエキスパート LoRA (#61979)、マルチモーダル ラッパーのテキストのみの LoRA (#62224)、検証時に拒否されたサポートされていないモデル (#61884)、および load_inplace リロード (#41482)、max_loras アカウンティング (#60306)、SM90 の修正lora_expand NaN (#61906) およびレベル 2 スリープからのウェイクアップ (#62358)。
  • RL: 選択ごとの return_weight_versions (#61347)、パラメータごとのメッシュを使用した NCCL M2N 転送 (#60934)、一度送信されるパラメータ メタデータ (#35911)、ParamMeta / iter_full() / iter_local() ウェイト転送 API (#63256)、およびパックされた NCCL 転送によるサイレント MoE ウェイト破損修正さらにレイヤーごとのリロード (#62555)。
  • バッチ不変: 圧縮テンソル W4A16/W8A16 (#60524)、GateLinear ルーター (#59985)、オンライン FP8 MoE (#57092)、および VLLM_BATCH_INVARIANT (#61118) でのインダクター バッチ不変モード。

大規模なサービス提供

  • コンテキスト並列処理: MRV2 PCP デコード完全な CUDA グラフ (#62377);プレフィックス キャッシュと SWA 制限付きリプレイを備えた DeepSeek-V4.1-Flash 用の PCP (#59857、#62183、#62384)。 trtllm-gen 上の FlashInfer DCP プレフィル (#62029);ストライド LSE を使用したダイレクト DCP オールツーオール (#60373)。 a2a DCP バックエンド上の FlashMLA スパース (#61285)。
  • HiSparse: GPU 常駐 KV の直接読み取り、長いプロンプトと 1M トークンのプレフィルでの 3.3 倍の速度低下による OOM を修正 (#60417)。より高速なホストプールのデフォルト (#60869); P/D の正確性の修正 (#61659、#62739、#63827)。
  • KV コネクタ: NIXL 1.5 ストライド記述子 (#61032)、プル コネクタによるスリープ モード (#59635)、混合ハイブリッド MLA ブロック サイズ (#61002)、および GQA ドラフト ヘッド シャーディング (#58471)。 RDMA 経由の Mooncake スリープ モード (#59625) および Prometheus メトリクス (#56939)。 MoRIIO ハイブリッドおよび異種 TP WRITE 転送 (#60544、#61726);ストリーミング応答には kv_transfer_params (#40186) が含まれます。フォールト トレランスが P/D に拡張され、KV ブロック リークが修正されました (#56430)。
  • KV オフロード: 最大 32 の shm ファイルにわたる CPU オフロード (GLM-5.3 オフロード起動 63.6 から 38.3 s、#59546)、オプトイン同一ステップの小規模ロード (#61961)、整列モードでの EAGLE/MTP 部分テール (#61019)、ロック/ロック解除およびオフスレッド階層化(#58168)、および多くの正確性の修正 (#63266、#60810、#63652、#62929、#63010、#60574、#63655)。
  • MoE および DP: DeepEP-v2 融合デコード globalize+align (H200 EP32 で最大 2.01x、#53911)。外部ロード バランサーを備えた Elastic EP (#43202)。 DP 同期の低レイテンシ CPU all-reduce (#61767) および DP wave ハング修正 (#59559)。 MXFP4/MXFP8 スケール (#61786) および NIXL 読み取り (#62081) の EPLB が修正されました。

重大な変更と非推奨

※CUDA 12.9のホイールと画像は公開されなくなりました(#62575)。

  • Medusa と MLP 投機家が削除されました (#61701)。従来の Ray コンパイル済みグラフ エグゼキュータは削除され、VLLM_USE_RAY_V2_EXECUTOR_BACKEND はなくなりました。 RayExecutorV2 は唯一の Ray 実行者 (#61712、#62228) です。
  • 非推奨: --mamba-cache-mode (影響なし、#60043)、--ir-op-priority (v0.34.0 で削除、#63371)、および LM Format Enforcer 構造化出力バックエンド (v0.34.0 でのオプトイン、v0.35.0 での削除、#63423)。
  • API の変更: 生成の一時停止中に送信されたリクエストは HTTP 503 (#51488) を返します。 kv_transfer_params / ec_transfer_params はレンダリング出力の最上位に移動しました (#61241)。 LoRA サポートのないモデル上の LoRA は検証で失敗します (#61884)。 RL ウェイトトランスファー API は、ParamMeta、iter_full()、iter_local() (#63256) を使用するようになりました。ビーム検索スコアは生成された長さによって正規化されます (#62928)。
  • Rust フロントエンド: サポートされていない vllm serve フラグとリクエスト フィールドは無視されずに失敗します (#62431、#62434)。リクエストによって提供されるチャット テンプレートには --trust-request-chat-template (#62673) が必要です。空の tools 配列は 400 を返します (#63060)。
  • NIXL コネクタには、NIXL 1.5 以降 (#61032) が必要です。
  • 削除された環境変数: VLLM_ROCM_AITER_MLA_DCP_VERIFY (#61628)、VLLM_ROCM_USE_AITER_FP4_ASM_GEMM (#61278)、および VLLM_ROCM_AITER_MEGA_MOE_FUSE_SHARED_EXPERTS (#61345)。 ZZPH100​​ZZ は --monokernel (#61082) に置き換えられます。
  • 新しいデフォルト: GLM-5.3-Flash FP8 KV キャッシュ (#61228); EAGLE/MTP プレフィックス キャッシュの先読みブロック ハッシュ (#61589); Cohere2MoE デュアル ストリーム (#62101); Blackwell のランクあたり 16 以下のクエリ ヘッドでの FA4 スパース MLA デコード (#55866)。 ROCm: MLA オフの AITER FP8/FP4 BMM (#53123)、FlyDSL GDN プレフィル (#60645)、AITER topk_gating (#56226)、rms_norm_gated (#60250)、および DeepSeek-V4 の CDNA4 上の MXFP4 インデクサー K キャッシュ (#63669)。
