vllm v0.31.0

#v0.31.0

ハイライト

このリリースには、307 人の寄稿者 (96 人が新規) からの 717 件のコミットが含まれています。

  • DeepSeek-V4.1-Flash パフォーマンス: V4.1 NVFP4 圧縮 KV キャッシュで大きな注目を集めた FlashMLA が SM100 のデフォルト (#56935) になりました。インデクサー用の DeepGEMM スパース MQA ログ (#56254) およびゲート GEMM とエキスパートの選択を融合する Mega-Gate (#56266)。デコーダ境界は、TP all-reduce、mHC 入力準備 (#57643)、および MoE ファイナライズ (#58586) を融合します。 SM100/SM103 上の逆 RoPE および MXFP8 Quant を備えた融合スモールバッチ WO-A (#58634)。 MXFP8 wo_b GEMM とシーケンス並列リデュース散乱 (#57428) が融合されました。 Engram wkv は TP ランク間でシャーディングされ (#58678)、Engram ホスト テーブルはデフォルトで同じ場所にある DP レプリカ間で共有されます (#57651)。ビジョンタワー用のエンコーダー CUDA グラフ (#56625);そして、スライディング ウィンドウ KV をプレフィックス キャッシュから除外する SWA 制限付きリプレイ (#56227)。
  • 高速再起動: 新しい vllm preload CLI は、エンジンの再起動後も量子化後の重みを GPU メモリに常駐させ続ける重みキャッシュ デーモン (#56680) を起動し、データ並列処理 (#57386)、MTP ドラフト モデル (#57312)、/health エンドポイント (#58552)、および準備完了待機 (#58370) を備えています。実験的な初期化されたエンジンのスナップショット (vllm snapshot create/restore) は、CRIU を使用して完全に初期化された TP1 エンジン (#51360) を復元します。
  • Model Runner V2 と推測的デコード: Model Runner V2 上のドラフトモデルの推測的デコード (#43091) とカスタム ロジット プロセッサ (#56497)。新しい LiLiCorr 製図者 (#57934);ドラフト CUDA グラフ (#57632) でキャプチャされたコンテキスト K/V 事前計算を使用した DFlash (#58065) の非同期スケジューリング。 Gemma4 の DSpark 適応検証 (#57263) および Kimi-K3 の可変長デコード (#52988)。非 DCP DSpark ドラフトを持つ DCP ターゲット (#56723)。また、MoE メモリは MRV2 プロファイリング中にカウントされるようになり、 WideEP 展開での OOM が回避されます (#57270、#58411)。
  • 大規模サービス: --all2all-backend moonep 経由の MoonEP バランス型 EP all2all バックエンド (#52101)、データ並列処理を伴うプリフィル コンテキスト並列処理 (#57075)、SM100/SM103 の低 SM マルチメモリ リデュース スキャッター (#55072)、シーケンス並列処理を備えた DeepEPv2 (#57210)、および共有エキスパート オーバーラップを備えた EPLB (#57236)、 RL 用のシャーディング対応 NCCL M2N ウェイト転送バックエンド (#51520)、および KV オフロード バック プレッシャー検出 (#50045)。
  • スケジューリング制御: --max-num-active-seqs は max_num_seqs とは独立して RUNNING アドミッションを制限します (#56758)、--long-prefill-token-threshold は単独のリクエストをチャンクするのではなく待機中のプレフィルの数に適応するようになりました (#57951、#58459)、待機キューが作り直され、すでに KV ブロックを保持しているリクエストが最初にスケジュールされるようになりました (#58947)、KV コネクタ + MTP デッドロックが発生しました。 KV 圧力が修正されました (#57104)。
  • HiSparse の強化: MTP 検証行はユニオン常駐カーネルで解決 (#59235)、FULL グラフでの MTP 受け入れ崩壊の修正 (#59309)、ホスト バッキングのない GPU ページなし (#59036)、チャンク プリフィル プリエンプション ライブロックの修正 (#59494)、HiSparse が割り当てるグループからの KV キャッシュ サイズ(#59450)、ホスト プレフィックスの公開と GPU プレフィックス採用の修正 (#59007、#59282)。
  • セキュリティ: --trust-request-mm-kwargs が設定されていない限り、リクエストごとの mm_processor_kwargs および media_io_kwargs は拒否されます (#58830)。プレフィックスキャッシュの追加キーはソースによってタグ付けされるため、LoRA 名と cache_salt は衝突できなくなり (#51899)、LoRA パスはブロック ハッシュの一部になります (#59335)。古いマルチモーダル受信機キャッシュ エントリは、新しいペイロードを置き換えることができなくなりました (#57833)。
  • 重大な変更: リクエストごとのマルチモーダル kwargs ゲート (#58830); tokenizer_mode="slow" が削除されました (#58545)。 --enable-mamba-fine-grained-prefix-cache は --enable-mamba-shared-prefix-checkpoint (#57382) に名前変更されました。 quantization="fp8" によるオンライン量子化が fp8_per_tensor 短縮表現 (#53585) に置き換えられ、Quark サイレント オンライン量子化が削除されました (#51800)。 AllSpark INT8 W8A16 バックエンドが削除されました (#58001)。 --enforce-eager は JIT カーネル ウォームアップも無効にするようになりました (#58197)。 XPU グラフはデフォルトで有効になり、VLLM_XPU_ENABLE_XPU_GRAPH は削除されました (#51600)。

  • デフォルトの max_tokens を超える min_tokens は、エンジンを固定する代わりに拒否されます (#57731)。メッセージのサニタイズにより、大文字のメモリ アドレスがフィルタリングされます (#58832)。提供されているモデルにちなんで名付けられた LoRA アダプターは拒否されます (#59286)。

重大な変更と非推奨

  • サーバーが --trust-request-mm-kwargs で起動されていない限り、リクエストごとの mm_processor_kwargs および media_io_kwargs はエラーを返すようになりました。サーバーレベルの --mm-processor-kwargs / --media-io-kwargs およびオフライン LLM は変更されません (#58830)。
  • tokenizer_mode="slow" は削除されました。すでに Transformers v5 では "hf" のように動作していました (#58545)。
  • --enable-mamba-fine-grained-prefix-cache は --enable-mamba-shared-prefix-checkpoint (#57382) に名前変更されました。
  • quantization="fp8" によるオンライン量子化は、fp8_per_tensor オンライン短縮表現 (#53585) にリダイレクトされるようになりました。 Quark 固有のサイレント オンライン MXFP4 量子化は、オンライン量子化 API (#51800) を優先して削除されました。
  • AllSpark INT8 W8A16 GEMM バックエンドは削除されました (#58001)。 /render の return_assistant_tokens_mask オプションと assistant_tokens_mask 応答フィールドが削除されました (#57520)。
  • VLLM_PLE_CPU_OFFLOAD は削除されました。 --engram-config (#57937) を使用してください。 VLLM_XPU_ENABLE_XPU_GRAPH は削除され、XPU グラフはデフォルトでオンになっています (#51600)。
  • --collect-detailed-traces のカンマ区切り形式は削除されました。リスト構文 (#55702) を使用してください。
  • 新しいデフォルト: --enforce-eager は、フォールト トレランスが有効でない限り、JIT カーネル ウォームアップも無効にします (#58197、#58593)。 VLLM_BATCH_INVARIANT=1 は、torch.compile を使用せずに壊れやすい CUDA グラフを使用し (#57586)、シーケンス並列処理と非同期 TP を無効にします (#56377)。 DeepSeek-V4.1 SWA 限定リプレイは ROCm (#57906) を除きオン (#56227) です。 Engram ホスト テーブルは、可能な場合、同じ場所にある DP レプリカ間で共有されます (#57651)。 FlashMLA の大きな注目は、SM100 の DeepSeek-V4.1 デフォルト (#56935) です。 AITER w4a4 ASM GEMM は ROCm ではデフォルトでオフになっています (#57055)。
  • Model Runner V1 + PP > 1 + 非同期スケジュール + 構造化出力は起動時に拒否されるようになりました (#56250)。 json_object は、アウトライン バックエンドでの検証時に拒否されます (#57743)。
  • transformers には要件に上限が設けられました (#59614)。
