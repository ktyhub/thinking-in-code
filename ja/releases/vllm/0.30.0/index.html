vllm v0.30.0

#v0.30.0

ハイライト

このリリースには、315 人の寄稿者 (104 人が新規) による 762 件のコミットが含まれています。

  • 新しいモデル: DeepSeek-V4.1-Flash (#56214、#56228、#56208)、SM100 上の FlashMLA V4.1 レコードを介して MXFP8 に保存された KV 全体 (#56893)、DeepGEMM Mega-mHC (#56962)、および Engram DP シャーディングによる非同期 Engram プリフェッチ (#56512)。 DeepSeek-V4-Flash-Vision-Exp (#54566)、ROCm (#55107) および LoRA (#55897) でも使用可能。 GLM-5.3-Flash (#53906) EPLB (#55119) 付き。 K2-ホライゾン (#55063);コヒアコンパス (#54774); V3 VL をベイリング (#55921); Nanbeige4.2 (トランスフォーマー バックエンド経由) (#56071); AVX512/AMX スパース MLA、インデクサー、mHC、およびコンプレッサー カーネルを備えた DeepSeek-V4 CPU バックエンド (#55355)。
  • ファスト スタート: 永続的な GPU ごとのウェイト キャッシュ デーモンは、量子化後の TP シャード化されたウェイトを GPU メモリに保持するため、エンジンを再起動すると、ディスクからリロードする代わりに、--load-format ipc_cache を使用して CUDA IPC 上にウェイトをマップし (#54921)、FP4 チェックポイント (#55465) とマルチノード TP (#55468) をカバーするようになりました。
  • **ウォーターマーク*​​: キー付き PRF、リクエストごとのオプトアウト、サンプル検出エンドポイントによる Gumbel-max ウォーターマークの生成と検出 (#54053)。デュアルキー Gumbel-max により、投機的デコードとの互換性が得られます (#56122)。 Rust フロントエンドはリクエストごとのコントロールを転送します (#56338)。
  • HiSparse: GPU プレッシャー下で KV ページをピン留めされたホスト メモリにスピルし、リクエストごとの GPU ホット バッファから上位 k のミスを処理するスパース MLA デコード用のホスト常駐層。HiSparseConnector (#53781)、Prometheus カウンター (#56061)、TP ランク間で共有されるホスト キャッシュ (#56629)、および推論されたアテンション設定によって有効になります。コネクタ (#57041) から接続します。
  • Model Runner V2: イーガー モード (#50945) およびマイクロバッチ ステップのフル CUDA グラフ (#51700) でのデュアル バッチ オーバーラップ。 MTP (#46994) および EAGLE3/DFlash/DSpark (#50514) パイプライン並列処理下での投機的デコード。オンライン受け入れ推定ツールによるすべてのドラフトモデル投機者の適応検証 (#52228);グラフのキャプチャ中に gc がフリーズし、H200 ではキャプチャが 12 秒から 2 秒に、エンジンの初期化が 28.9 秒から 8.2 秒に短縮されました (#54646)。 --return-sampling-mask は GPU 上で圧縮され、約 2 倍の RL ステップ時間回帰を修正しました (#54901)。
  • Qwen3.8-Flash-Next パフォーマンス: 個別のプリフィルとデコード QSA インデクサー カーネル (#54513)、融合 PLE カーネル (#54517)、FP8 インデクサー キャッシュ (#54890)、スパース GQA でのパディング インデックス スキップ (#54873)、融合 PLE 残差および QSA 出力ゲート (#55309)、UVA PLE --engram-config によるオフロードとエングラム テンソル並列処理 (#54371)、および FP8 が単一の GB300 に適合するように torch.compile が NVIDIA 実装から削除されました (#55272)。
  • Kimi K3 パフォーマンス: SM100 でのネイティブ CUDA AttnRes のデフォルト (#54261)、KDA 混合バッチの収集/散乱の削除 (5.2-7.7% E2E スループット、#56159)、グループ化された FP8 MLA キャッシュの挿入 (小規模バッチでのカーネルの 4 ～ 6 倍の高速化、#55356)、ストライド テンソル上の DSV3 低レイテンシ GEMM (12-81% のカーネル速度向上、#54565)、オーバーラップした TP8 KDA プロジェクション (#54697)、FlashInfer KDA カーネル (#55364)、部分的なプレフィックス キャッシュと投機的デコードを備えた内部プレフィックス チェックポイント (#53614)、およびハイブリッド Mamba モデルの対称 DCP 分解 (#55531)。
  • 大規模サービス: スパース MLA モデル上の PCP+DCP (#56157)、単一モジュール MTP と複製された DSpark を備えた PCP (#56107)、およびデコード専用の FULL CUDA グラフ (#53867)、再構成全体で CUDA グラフを再利用する Elastic EP (#54985)、オプトイン FlashInfer PCIe IPC all-reduce NVLink レス ボックス (#53576)、DeepEP v2 非同期は結合による重複する共有エキスパートのファイナライズ (#52781)、Mooncake Store の異種 TP 共有 (#53129)、KVCR セカンダリ層アダプター (#53624)、NIXL (#47941) および Mooncake (#41567) を介したエンコーダー キャッシュ共有。
  • 量子化: quantization_config.targets (#51285) および任意の量子メソッドからの部分的に事前量子化されたチェックポイントを使用したターゲット オンライン量子化 (#51392)、nvfp4_fp8_ds_mla KV キャッシュを使用した W4A16 DSA (#51724)、SM100/103 の Marlin に対する FlashInfer CuTeDSL NVFP4 W4A16 デフォルト (#53014)、トーチ線形バックエンドの NVFP4 (#53319)、量子化ごとの線形バックエンド オーバーライド (#51204)、CUDA 上の AutoRound 2/3/5/6/7 ビット (#52890)、DSA スパース インデクサーの DeepSelect top-k (#56464)。
  • 重大な変更: スケールアウト エンドポイントは、VLLM_ENABLE_SCALE_OUT_ENDPOINTS (#54579、#55176) を置き換えて、--enable-scale-out 経由でプレーン vllm serve にオプトインされます。 GPTQ アクティベーション順序 (g_idx) が削除されました (#54809)。 VLLM_PREFIX_CACHE_RETENTION_INTERVAL および VLLM_MM_HASHER_ALGORITHM 環境変数を含む、0.29 で非推奨の項目が削除されました (#55353)。 all Mamba キャッシュ モードは非推奨になりました (#55041)。 python -m vllm.entrypoints.grpc_server は非推奨となり、vllm serve --grpc (#56746) が採用されました。 YaRN が Transformers と連携したため、ベンダー YaRN エイリアスは max_model_len (#56446) を再スケーリングしなくなりました。

重大な変更と非推奨

  • スケールアウト エンドポイント (/render、/derender、/inference/v1/generate) は、--enable-scale-out が渡されない限り、プレーン vllm serve に登録されなくなりました。 VLLM_ENABLE_SCALE_OUT_ENDPOINTSを取り外しました。 vllm launch render と vllm serve --tokens-only は常に登録します (#54579、#55176)。

  • 0.29 で非推奨となった項目が削除されました: VLLM_PREFIX_CACHE_RETENTION_INTERVAL および VLLM_MM_HASHER_ALGORITHM 環境変数 (構成フィールドを使用)、use_fp4_indexer_cache エイリアス (indexer_kv_dtype を使用)、ROCm の CUDA_VISIBLE_DEVICES フォールバック (HIP_VISIBLE_DEVICES を使用)、および seq_lens_cpu / num_computed_tokens_cpu アテンション メタデータ プロパティ(#55353)。
