vllm v0.25.0

#vLLM v0.25.0 Release Notes

ハイライト

このリリースには、232 人の寄稿者 (64 人が新規) による 558 件のコミットが含まれています。

  • Model Runner V2 がすべての高密度モデルのデフォルトになりました (#44443)。以前のリリースの量子化モデルのサポートに基づいて構築された MRv2 は、EVS (#46535)、リアルタイム埋め込み (#46762)、Mamba ハイブリッド モデルのプレフィックス キャッシング (#42406)、マルチモーダル プレフィックス双方向アテンション (#46942)、および完全な CUDA グラフと互換性のある動的投機的デコーディング (#45953) の新しいサポートを備えた標準実行パスになりました。
  • PagingAttendant は削除されました (#47361)。 V1/MRv2 バックエンドが標準パスになったため、従来のアテンション実装は削除されました。
  • Transformers モデリング バックエンドは、ネイティブ vLLM (#47187) と同じくらい高速になり、FP8 MoE サポート (#46820)、CUDA グラフ + 埋め込みスケーリング修正 (#48010)、GPTBigCode/Starcoder2 (#30966) および RoBERTa (#47452) の移行を獲得しました。
  • 新しいモデル: LLaVA-OneVision-2 (#44785)、Unlimited OCR (#46564、#47102)、MOSS-Transcribe-Diarize (#47729)、openai/privacy-filter (#41026)、および Hy3 (#47192)。 GLM-5 / DeepSeek-V3.2 は、GLM-5.2 チューニングによりモデル動物園 (#46808) に登場し、MiniMax-M3 はパイプライン並列処理 (#45810) と NVFP4 サポート (#46756) を獲得しました。
  • 新しいストリーミング パーサー エンジン (#46610) - 新しい Kim k2.5/k2.6/k2.7 パーサーと、seed_oss (#46314) および DeepSeek V4 (#45877) のポートを備えた、統合されたツール呼び出し/推論解析フレームワーク。 Rust フロントエンドは、HTTPS/mTLS (#45890)、DP スーパーバイザー (#47076)、およびプロファイラー制御ルート (#46306) で成熟し続けています。
  • 異種語彙のユニバーサル投機的デコード (TLI) (#38174)、および新しい DSpark (#46995) および DFlash (#46770、#46853) ドラフター。

モデルのサポート

  • 新しいモデル: LLaVA-OneVision-2 (#44785)、Triton R-SWA バックエンドを備えた Unlimited OCR (#46564) (#47102)、MOSS-Transcribe-Diarize (#47729)、openai/privacy-filter (#41026)、トークンサフィックスと JSON スキーマ配列サポートを備えた Hy3 (#47192)。
  • GLM-5 ファミリ: GLM-5 / DeepSeek-V3.2 がモデル ズー (#46808)、GLM-5.2 FP32 ゲート (#47410)、GLM MTP ポストファイナルノルム修正 (#47448)、GLM4V スタートアップ修正 (#47155) に追加されました。
  • MiniMax-M3: パイプライン並列処理 (#45810)、ストリーミング推論解析 (#45718)、および Triton カーネルを置き換える MSA の tok_sparse_select (#47502)。
  • Transformers バックエンド: ネイティブ vLLM (#47187)、FP8 MoE 修正 (#46820)、埋め込みスケーリング + CUDA グラフ修正 (#48010)、GPTBigCode/Starcoder2 (#30966) および RoBERTa (#47452) 移行、M-RoPE mm_token_type_ids 修正 (#46552)、タイエンベディングと同等の速度になりました。 lm_head.bias 修正 (#46835)。
  • Voxtral: ミストラル共通 1.11.5 オーディオ API (#46705) およびリアルタイム トークン フィードバックのハング修正 (#44461) に移行されました。
  • Gemma ファミリ: Gemma4 スライディング ウィンドウ/FA4 アテンション修正 (#47217、#47332)、Gemma4 MTP quant_config 修正 (#47091)。 DiffusionGemma テンソル並列処理 (#45719) および HF 安定性ウィンドウ セマンティクス (#45965)。
  • その他の修正: MiniCPM-V 4.6 言語バックボーン LoRA (#46740) およびプレースホルダー グリッド修正 (#45918)、プールされた Whisper スライディング ウィンドウ サイズ変更 (#47071、#47437)、architectures なしの Mamba/Mamba2 チェックポイント クラッシュ修正 (#46037)、DeepSeek-V2 の隠しサイズと補助隠し状態修正 (#46986、#46973)。

エンジンコア

  • Model Runner V2: すべての高密度モデルのデフォルト (#44443)。 EVS (#46535)、リアルタイム埋め込み (#46762)、Mamba ハイブリッド プレフィックス キャッシング (#42406)、マルチモーダル プレフィックス双方向アテンション (#46942)、クロス アテンション ウォームアップ/ブロック テーブル修正 (#46753、#47308)、Mamba2 クラッシュ修正 (#47428)、スロット アカウンティングのスケジューリング(#46974)、シャットダウン時のモデル参照クリーンアップ (#47483)、大規模な logprobs リクエスト用の制限付きメモリ (#46746)。
  • 投機的デコード: 異種語彙のユニバーサル仕様デコード (TLI) (#38174); DSpark ドラフター + スペキュレーター チェックポイントのサポート (#46995、#47093); DFlash バックエンド選択 (#46770)、レイヤーごとの RMSNorm フュージョン (#46761)、CPU サポート (#44029)、MiMo 用 SWA+DFlash (#46104)、Laguna XS.2.1 ドラフター (#46853)。 Bailing ハイブリッド モデル用の MTP (#44880);拒否サンプリングのブロック検証 (#46781);ドラフトトークンの TP 通信を削減しました (#46448)。
  • スリープ モード: コミュニケータに依存しない機能フラグ (#47243) を備えた、プラグ可能なスリープ モード バックエンド抽象化 (RFC #34303、#44074)。
  • 注意: ハイブリッド モデル (#36701)、FLASH_ATTN_MLA_SPARSE Hopper sparse-MLA バックエンド (#46189)、MLA デコードの DCP + FP8 KV キャッシュ (#44044)、XQA デコード カーネル (#43232) の FlashAttend ブロック サイズ制限が削除されました。
  • KV オフロード: 階層化メトリック プラミング (#45959)、リクエスト ライフサイクル修正 (#46284)、C でのバッチ ルックアップ (#46713)、LookupResult 列挙型 (#46363)。
  • その他: VLLM_GPU_SYNC_CHECK 環境変数 (#44800)、VRAM セマフォ インフラストラクチャ (#44465)、オンライン ビーム検索でのトークン化解除のスキップ (#46422)、サンプラー/アテンション カーネルでのいくつかの int32 オーバーフローの修正 (#46560、#47383、#47671)。

ハードウェアとパフォーマンス

  • GLM-5.2 / DeepSeek: fused_indexer_q_rope_quant Triton カーネル (1.9–3.3% E2E スループット) (#46862)、リデュース散乱 MoE オールリデュース (3.1–3.2% E2E) (#46635)、GLM5/DSV3.2 のオプフュージョン (#46876)、 DSv4 の token_to_req_indices キャッシュ (5 ～ 6 倍のカーネル速度向上) (#47474)、より優れた DSv4 MXFP8 カーネル (#47229)、冗長演算の削除 (#47198、#46651)。
  • NVIDIA/Blackwell: GB300 で world_size=16 用に調整された FlashInfer 融合オールリデュース (#46392)、Blackwell デコード スループットを回復するための NVFP4 スウィズルスケール ゼロ初期化の復元 (#45739)、CuTeDSL/FA4-MLA ウォームアップ インフラストラクチャ (#46182)、SM120 での協調的なトップ K のスキップ (#47164)、非ゲート MoE 用の B12x バックエンド (#43328)。
  • カーネル: Helion fused_qk_norm_rope (#44010) および silu_and_mul_per_block_quant (#43994)、Triton MLA ロジット ワークスペース (#46819)、融合 MoE のスワップ AB 最適化 (#36559)、任意の Top-k をサポートするベクトル化 fp32 moe_sum (#46643)、ドライバー ロックのビジー ポーリングを回避するための CUDA イベントのブロック(#47081)。
  • AMD/ROCm: トーチ 2.11 安定版 ABI (#47128) に移動しました。 AITER FlashAttendant MLA プレフィル バックエンド ROCM_AITER_FA (#45033); GLM-4.5/6/7 (#44313) および MiniMax-M3 (#46474、#46545) の共有エキスパートを融合。 DeepSeek-V4 向け AITER MoE 最適化 (#46122); CudaCommunicator の AITER カスタム all-reduce (#46065); QuickReduce の INT3 量子化 (#45666)。
  • Intel XPU: マルチ粒度クオントを備えた W8A8 FP8 リニア カーネル (#43645)、パイプライン並列精度修正 (#47253)、FA2 用の均一バッチ CUDA グラフ (#46555)、Triton アテンションへの mm_prefix モデルのルート (#47688)、C++ get_memory_info (#47134)。
  • CPU: AArch64 の非量子化 MoE の高速化 (#46353)、OpenMP による macOS/Apple Silicon ハング修正 (#46769) および壊れたインストールの修正 (#47457)、圧縮テンソル w8a8 int8 MoE (#42920)、Mamba ShortConv (#35059)、Qwen3.5 のチャンク プリフィル + プレフィックス キャッシュ(#46202)、tanh AOR 経由でのゲルの高速化 (#44639)。
  • RISC-V: W4A8 INT4 GEMM の RVV パス (#45269)、VLEN=256 ハードウェア上の BF16 (#45243)、INT4 LUT デカントの LMUL 圧力の低減 (#47538)。 POWER: PowerPC での fp16 のサポート (#46135)。
  • プラットフォーム: アクセラレータに依存しない get_memory_info (#44825)。

大規模なサービス提供と分散

  • DP を必要としないシーケンス並列処理、1.9 ～ 5.0% E2E スループット向上 (#47070)。
  • 分散: NCCL 対称メモリが AllGather および ReduceScatter に拡張 (#46703)、FlashInfer all-reduce のデフォルトが単一ノード上の MNNVL (#47219、#47589)、フォールト トレランス バックエンドで all2all ピアの障害を検出し、出力の破損を防止 (#43637)。
  • データ パラレル: ローカル プレフィル作業に基づくスロットル プレフィル (#46532)、エンジン バイアスを回避するためのロード バランサー タイブレークの回転 (#47420)、Rust フロントエンド経由の DP スーパーバイザ (#47076)、DP MTP ハング修正 (#40589)。
  • PD 分割: セカンダリ層実装 (#42285)、Mooncake コネクタ GDN (Qwen3.5) + MLA (DeepSeek-V4-Flash) サポート (#46807)、NIXL Mamba1 サポート (#45019)、MultiConnector kv_transfer_params マージ (#46777)、分割サービス用に公開された使用状況フィールド (#42748)。
  • DCP: FlashInfer MLA サポート (#43729)、FLASHINFER_MLA_SPARSE サポート (#46076)、LSE ログベースの修正 (#47079)。 Mooncake の並列化された KV ロード (#45971) と DCP>1 ルックアップの修正 (#46855)。
  • ROCm: DP+EP 用の安定化された高スループット DBO (#46990)、Quark OCP MXFP4 MoE 用の EPLB (#47220)。

量子化

  • 2/3/5/6/7 ビットのパック量子化された重みのみの推論 (ハミング) (#46389)、Triton INT4 トークンヘッドごとの KV キャッシュ量子化 (#40835)。
  • NVFP4: MoE MLP Triton カーネルの計算と重み逆量子化の融合 (#44667)、スキップレイヤー スライディング ウィンドウを備えた NVFP4 KV キャッシュ (#42890)、MiniMax-M3 ModelOpt NVFP4 サポート (#46756)。
  • FP8: ブロックごとのオンライン量子化のための重みパディング (#44763);古い FP8 オンライン MoE 量子化クラス (#44514) が非推奨になりました。
  • Marlin: スレッド タイル パディングを MoE (WNA16 + FP8/MXFP8) に拡張 (#45703)、int8 グループ化 WNA16 MoE (#47154)。ゲート SiLU 用の FlashInfer MXINT4 MoE (#46518)。
  • 修正: W8A8 int-quant スキーム選択回帰 (#46860)、ModelOpt Gemma4 の結合量子化埋め込み (#45544)、Qwen3Next での NVFP4+MTP クラッシュ (#46316)、スパース構成の ModelOpt 混合精度 (#47318)、CPU w4a8_int8 MoE パス(#46739)、グループサイズ/TP の不一致に関する対処可能なエラー (#46230)。

API とフロントエンド

  • ストリーミング パーサー エンジン (#46610): 新しい Kim k2.5/k2.6/k2.7 パーサーによる統合ツール呼び出し/推論解析。 seed_oss (#46314) と DeepSeek V4 (#45877) を移植しました。
  • OpenAI 互換性: レスポンス API 名前空間ツール (#47024)、チャット/完了レスポンスのリクエストごとのタイミング metrics フィールド (#46768)、レンダー エンドポイントのトークン オフセット (#44226)、トレーニング データ生成用の return_loss_mask (#46846)、処理できない画像 URL 用の HTTP 422 (#47165)。
  • gpt-oss / Harmony: 専用 Harmony レンダラ (#46800)、process_eos() フラッシュ (#46437)、非端末解析での raw 出力リカバリ (#47062、#47379)。
  • Rust フロントエンド: HTTP および gRPC 用の静的 HTTPS および mTLS (#45890)、DP スーパーバイザー (#47076)、プロファイラー制御ルート (#46306)、repetition_detection サンプリング パラメーター (#46684)、統合/結合パーサー インターフェイス (#46583)、削減されたマルチモーダル テンソル コピー (#47581)、さらに、多くのパーサーと検証が修正されました。
  • ビデオ: TorchCodec がビデオ デコード バックエンドとして追加されました (#46609)。
  • CLI/UX: 開発/デバッグ用の vllm chat (#46775)、model_class_overrides (#47148) での TTFT および TPS 印刷。
  • ツール/検証: 多くのツール パーサーの修正 (Kimi K2 ID #46344、PoolsideV1 #46486/#47311、非 ASCII 引数 #46308、thinking_token_budget 再エントリ #43757)。無効な設定値の拒否 (#44070、#44002、#46612) と、EngineCore をクラッシュさせる structured_outputs の縮退 (#45346)。

セキュリティ

  • 画像解凍爆弾による OOM サービス拒否 (#47010) を防止します。
  • NaN オーディオ サンプルを使用した split_audio での無限ループを防止します (#46463)。
  • 明示的な truncation_side が設定されている場合、バインドされたトークナイザーが機能します (#47007)。
  • ブロックリクエストレベルの GPU ビデオバックエンド選択 (#47259)。
  • gRPC インターフェイスは個人使用のみを目的として安全ではないものとして文書化します (#45903)。

依存関係

  • FlashInfer 0.6.13 (#46683)、tpu 推論 v0.23.0 (#46568)、aiter 0.1.16.post2 (#46692)、vllm_xpu_kernels v0.1.10.1 (#46607)、huggingface-hub v1.22.0 (#47551)。
  • SM120 サポート (#47304) を有効にするために DeepGEMM が更新され、トーチ安定版 API (#46644) に対して構築された FlashAttendant 3、Rust フロントエンド TLS が rustls からネイティブ tls/OpenSSL (#46696) に切り替えられました。

非推奨と削除

  • PagesAttention が削除されました (#47361)。
  • 削除されたモデル: Baichuan (#46362)、Aquila (#46605)、Grok (#46706)、Tarsier / Tarsier2 (#47143)、AyaVision / MusicFlamingo (#47263)、Mantis (#46806)。
  • 古い FP8 オンライン MoE 量子化クラス (#44514) は非推奨になりました。従来の api_server.py はサンプル ディレクトリ (#46783) に移動されました。 gptq_marlin は、サポートされている ROCm 量子スキームから削除されました (#46655)。
