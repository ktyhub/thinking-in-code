vllm v0.21.0

ハイライト

このリリースには、202 人の寄稿者 (49 人が新規) による 367 件のコミットが含まれています。

  • Transformers v4 は非推奨になりました: このリリースでは、transformers v4 のサポートが正式に非推奨になりました (#40389)。ユーザーは transformers v5 に移行する必要があります。
  • C++20 ビルド要件: vLLM では、PyTorch (#40380) との互換性のために C++20 互換コンパイラーが必要になりました。これは 重大なビルド変更 です。
  • KV オフロード + ハイブリッド メモリ アロケータ (HMA): KV オフロード サブシステムは、スケジューラ側のスライディング ウィンドウ グループのサポートと完全な HMA 有効化を含む、ハイブリッド メモリ アロケータと統合されました (#41228、#41445、#39571)。
  • 思考バジェットを使用した推測デコード: 推測デコードは推論/思考バジェットを尊重するようになり、推論モデルの正しい仕様デコードが可能になりました (#34668)。
  • Blackwell 上の TOKENSPEED_MLA バックエンド: 新しい TOKENSPEED_MLA アテンション バックエンドが、Blackwell GPU 上の DeepSeek-R1/Kimi-K25 プリフィル + デコードに利用可能です (#41778)。

モデルのサポート

  • 新しいアーキテクチャ: MiMo-V2.5 (#40967)、Laguna XS.2 (#41129、#41880)、Moondream3 (#32325)、Qianfan-OCR (#40136)、Cohere MoE (#40817)、Cohere Eagle (#42078)。
  • 投機的デコード: Mistral 用 EAGLE (#41024)、Gemma4 MTP (#41745)、MiMo-V2.5 用 MTP (#41905)、Cohere Eagle (#42078)。
  • DeepSeek V4: AMD/ROCm サポート (#40871)、パイプライン並列処理 (#41694)、max 推論作業 (#40982)、細分化されたサービング修正 (#41957)。
  • ツール呼び出し: Cohere 推論およびツール パーサー (#40422)、LFM2/2.5 ツール パーサー (#39243)。
  • Gemma3/Gemma4: hidden_act バリアントのサポート (#40588)、パイプライン並列処理の修正 (#40786)、MoE の修正 (#41206、#41574、#41401)、ツール パーサーのクラッシュの修正 (#41991、#42188)。
  • Model Runner V2: Qwen3.5/Mamba ハイブリッド モデル サポート (#35520)、logprob_token_ids サポート (#40559)。
  • CUDA グラフ: Qwen2.5-VL の ViT CUDA グラフ サポート (#40830)。
  • 互換性: Transformers v5 用ベンダー HCXVisionConfig (#38447)、レガシー rope_type チェックポイント サポート (#41734)。

エンジンコア

  • KV オフロード + HMA: スケジューラー側のスライディング ウィンドウ グループ (#41228)、完全な HMA 有効化 (#41445)、マルチコネクタ HMA (#39571)、ジョブごとのストア完了 (#39186)、OffloadingConnector での DCP/PCP サポート (#41549)、分散 KV オフロード用の MooncakeStoreConnector (#40900)。
  • 投機的デコード: 思考予算サポート (#34668)、独立した製図者の注意バックエンド選択 (#39930)、警告付きマルチモーダル モデル サポート (#41752)、ステップごとの割り当ての削除 (#41043)。
  • Model Runner V2: リジェクト サンプリング受け入れ率の修正 (#40651)、ドラフト プレフィル前のメタデータ再構築のスキップ (#40410)、ドラフト デコード ステップ間のメタデータ再構築 (#41162)、Qwen3.5/Mamba ハイブリッド サポート (#35520)。
  • ルーティング: ルーティングのリプレイをデバイス キャッシュと非同期 D2H パイプラインに置き換えます (#39917)。
  • Ray: RayExecutorV2 がデフォルトで有効になり (#41421)、DP > 1 のアクター名の衝突が修正されました (#40398)。
  • 安定性: スケジューラのデッドロックを防ぐための 2 フェーズ一時停止 (#39366)、スレッドセーフな HF トークナイザー ラッパー (#41181)、モデル読み込み中の max_split_size_mb による OOM 防止 (#41268)。
  • DSA モデルの IndexCache サポート (#37735)。

ハードウェアとパフォーマンス

  • NVIDIA Blackwell: DSR1/Kimi-K25 用 TOKENSPEED_MLA バックエンド (#41778)、より高速なトークンごとの FP8 グループ クォント パック カーネル (#41326)、NVIDIA Thor/SM110 上の FP8 (#39712)、非互換サイズ用の CUTLASS スケール mm (#41868)。
  • パフォーマンス: デフォルトで有効になっている FlashInfer top-k/top-p サンプラー (#40376)、ViT に対する FP8 FlashInfer アテンション (#38065)、TurboQuant 共有デカント バッファー (#40941)、AllPool.forward 51% 高速化 (#41163)、プーリングにおける GPU<->CPU 同期の削除 (#41433) およびアテンション(#41434)、numpy ゼロコピー埋め込みシリアル化 (#41681)、テキスト専用のマルチモーダル プロセッサ スキップ (#41246)、FlashInfer FP8 非同期 TP フュージョン (#39505)、AsyncTP 用の NVFP4 オールギャザー GEMM フュージョン (#41882)、DP/PP の allreduce+RMS フュージョンを再有効化(#41458)、torch.mm 経由の DeepSeek bf16→fp32 (#41300)、スパース バックエンド用の永続的 MLA (#41990)、構成可能なセーフテンソル チェックポイント プリフェッチ (#41499)、融合された mhc_post_pre カーネル (#41536)、2D グリッド W8W8 グループ クォント カーネル(#42153)、KV キャッシュ スワップのメモリ順序を緩和しました (#39306)。
  • AMD ROCm: ROCm 7.2.2 (#41386)、DBO (動的バッチ最適化) (#34726)、AITER Fused Allreduce+RMSNorm (#37646)、Fused Shared Expert (FSE) for Qwen3-Next (#39280)、DeepSeek V3.2 TP4 AITER MLA (#41835)、GDN リニア アテンション フュージョン (#40711)、AITER での冗長な MoE バッファ コピーの排除 (#41713)、CPU オフロード サポート (#40549)、DeepEP API アップデート (#39721)、共有メモリ OOM を修正するための Triton ページ アテンション ブロック サイズの制限 (#38502)。
  • CPU: AMX/AVX-512 の FP8 アテンション (#39445)、FP8 W8A16 リニア (#41186)、FP8 W8A16 MoE (#41314)、DNNL AVX2 W8A8 Int8 (#41318)、Qwen 3.5/3.6 のゲート デルタネット アテンション(#41025)、RISC-V OMP スレッドの自動バインディング (#40569)。
  • インテル XPU: Top-k/top-p サンプル カーネル (#39285)、out-of-place all-reduce (#41808)、LoRA サポート (#38206)。
  • IBM Power: VSX アテンション バックエンド (#40451)。
  • FlexAttend: バッチ不変モードが再度有効になりました (#40842)。
  • MLA: MLA プレフィル バックエンドを抽象化し、cuDNN 依存関係を排除しました (#32623)。

大規模なサービス提供

  • 分散サービング: P と D の間の双方向 KV キャッシュ転送 (#32553)、NIXL 転送の再設計 (#40731)、EPLB メモリ オーバーヘッドの最適化 (#40013)、NIXL コネクタを 1.x に引き上げ (#42364)、転送可観測性のための Mooncake KVConnectorStats (#40414)、NIXL P ノードの事前承認拒否通知(#41269)、スキップされた P ランクの KV ブロックの解放 (#40449)。
  • DCP: DCP A2A (#41160) の出力と LSE をパックします。
  • MoE: ツリー外 MoE ランナー用の PluggableLayer インターフェイス (#35178)。
  • LoRA: 初期エキスパート パラレル (EP) サポート (#40867)、Qwen3.5 LoRA fusion 修正 (#37912)。

量子化

  • NVFP4: KV キャッシュ サポート (#40177)、Hopper および AMD 用の Triton dequant/QDQ エミュレーション カーネル (#40033)、Gemma4 用 TRT-LLM NvFP4 融合 MoE 上の GELU (#41050)、ModelOpt NVFP4 W4A16 (#41769)、NVFP4 オールギャザー GEMM 融合AsyncTP (#41882)、GLM4-MoE NVFP4 読み込み修正 (#41755)。
  • MXFP4: ハミング MXFP4 MoE バックエンド (#41083)、FlashInfer CUTLASS MXFP4-MXFP8 MoE 修正 (#42089)。
  • TurboQuant: ハイブリッド モデルと均一量子化のサポート (#39931)。
  • 圧縮テンソル: 明示的でない無視を含む構成を許可します (#41965)。
  • FP8: バイアス ローディングの修正 (#41424)、正確性を保つために FlashInfer の自動調整が一時的に無効になりました (#41524)。
  • DSV4: 改良された融合インデクサー Q クォント カーネル (#41428)。

API とフロントエンド

  • レスポンス API: required (#40700) および名前付きツール/関数の選択 (#41110) を使用したストリーミング ツール/関数呼び出し。フィールドが欠落している出力項目を再送信します (#41355)。
  • OpenAI 互換性: 応答の system_fingerprint フィールド (#40537)、prompt_embeds コンテンツ部分のサポート (#40720)、defer_loading および tool_reference のサポート (#40190)、チャット完了応答のレンダリングされたプロンプト テキスト (#42052)、強制ツール選択での空のコンテンツの許容 (#40148)。
  • ツール呼び出し: 厳密なツール呼び出し + 推論用の構造タグを備えた XGrammar 0.2.0 (#40894)、Cohere 推論/ツール パーサー (#40422)、LFM2/2.5 ツール パーサー (#39243)。
  • トークナイザー: Fastokens のサポート (#41741)。
  • RLHF: 明示的な /start_weight_update および /finish_weight_update API (#39212)。
  • ASR: キャンセル時にエンジン リクエストが中止される (#41266)。
  • 構成: VLLM_SKIP_MODEL_NAME_VALIDATION 環境変数 (#34676)、構成可能なモデル重み読み込み追跡 (#41086)、Triton JIT コンパイル モニター (#40137)。

ビルドと依存関係

  • 重要: PyTorch との互換性には C++20 が必要です (#40380)。
  • 速報: トランスフォーマー v4 は非推奨になりました (#40389)。
  • Docker 画像サイズは、FlashInfer cubin ダウンロードの遅延により ~2.5 GB 削減されました (#41134)。
  • CUDA 13.0 ホイールは PyTorch manylinux_2_28 ベース (#41416) に切り替えられました。
  • CPython 互換性のために Python ごとに構築された DeepGEMM バンドル ホイール (#41516)。
  • コンテナーイメージの来歴メタデータが埋め込まれました (#40653)。
  • tpu 推論が v0.19.0 (#41844) にアップグレードされました。
  • NIXL コネクタは 1.x (#42364) にバンプされました。
  • ROCm 7.2.2 (#41386)。
