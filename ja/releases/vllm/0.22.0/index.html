vllm v0.22.0

ハイライト

このリリースには、230 人の寄稿者 (63 人が新規) からの 459 件のコミットが含まれています。

  • DeepSeek V4 の成熟度: DeepSeek V4 は、このサイクルで主要な強化パスを取得しました。モデルは専用の vllm/models/deepseek_v4/ パッケージ (#43004、#43039、#43073、#43077、#43149) に再編成され、NVFP4 融合 MoE サポート (#42209)、完全 + 区分的 CUDA グラフ (#42604) を獲得しました。 MTP の投機的デコード (#43385)。融合されたカーネル (MegaMoE、mhc、Q-norm、インデクサー、スパース MLA) と ROCm パリティ修正の大規模なセットが、精度修正 (#42810、#43710) とともに追加されました。
  • Model Runner V2 はデフォルトに向けて前進: MRv2 は Qwen3 高密度モデルのデフォルトになりました。 vLLM は、MRv2 でまだサポートされていない機能については MRv1 にフォールバックします (#39337)。スリープ モード ウェイト リロード (#42673)、update_config (#42783)、共有 KV キャッシュ レイヤー (#35045) に加えて、多くの正確性の修正が行われました。
  • 実験的な Rust フロントエンド: 新しい Rust フロントエンド統合がリリースされ (#40848)、その実装はツリーに移動され (#43283)、データ並列処理用の DP スーパーバイザーが追加されました (#40841)。
  • バッチ不変性、高速化: バッチ不変推論は、28.9% エンドツーエンドのレイテンシ改善 (#40408)、SM80 でのコンパイルモードのサポート (#42456)、および NVFP4 Cutlass 線形パス (#39912) のための Cutlass FP8 サポートを獲得しました。
  • 多層 KV キャッシュ オフロード: Python ファイルシステムのセカンダリ層 (#41735)、DSv4 サポート (#43142)、および Mooncake ディスク オフロード (#42689) を備えた新しい多層 KV キャッシュ オフロード フレームワーク (#40020) は、オフロードを CPU メモリを超えて拡張します。

モデルのサポート

  • 新しいアーキテクチャ: MiniCPM-V 4.6 (#41254)、InternS2 プレビュー (#42705)、OpenVLA (#42654)、MolmoWeb hf_overrides ドキュメント (#42163)。 EXAONE-4.5 はトランスフォーマーのアップデート (#42246) に合わせました。
  • 投機的デコード: カスタム呼び出し可能プロポーザー バックエンド (#39487)、ポストノルム EAGLE-3 スペキュレーター (#42764)、peagle スペキュレーター (#41826)、extract_hidden_states のハイブリッド アテンション モデル (#39949)、NemotronH の非 MTP 投機 (#43130)、MRv2 の共有 MTP 重み (#42538)。
  • DeepSeek V4: NVFP4 MoE (#42209)、CUDA グラフ フル/ピース単位 (#42604)、MTP (#43385)、モデル パッケージ リファクタリング (#43004、#43039、#43073、#43077)、スパース MLA + コンプレッサー リファクタリング (#43149、#43710)、MegaMoE input-prep カーネルの移動 (#43632)。
  • Qwen3.5/3.6: GDN 出力投影フラット化 (#42311)、GatedDeltaNet Marlin TP≥2 修正 (#36329)、ViT フル CUDA グラフ (#42151)、Qwen3.5/MTP/Qwen3-VL の runai-streamer ウェイト ロード (#42521、#42716)、KDA チャンク プレフィルexp2 セマンティクス (#43195)。
  • Gemma3/Gemma4: 混合解像度の画像の同時バッチ処理のクラッシュ修正 (#42217)、MoE ルーティング クロージャの修正 (#42250)、ツール パーサーのフロート破損修正 (#42128)、画像/ビデオのバッチ ビジョン エンコーダ (#43169)、マルチ GPU の修正 (#42630)。
  • Kim-K2.5: 量子化時のビジョンタワー dtype 変換をスキップ (#42869)、mm_projector dtype 修正 (#42081)。
  • Cohere: Cohere MoE (#43143)、Cohere ビジョンのパイプライン並列処理 (#42819) を有効にします。
  • ツール呼び出し: Apertus ツール パーサー (#41154)、Qwen3Coder anyOf/oneOf/$ref 解決再ランディング (#37831)、MiniMax-M2 / DeepSeek-V3.2 / Seed-OSS パーサー間で共有される coerce_to_schema_type (#43006、#43019、#43140)。
  • ViT CUDA グラフ: Qwen2-VL (#41736)、Step3-VL エンコーダー (#42224)、Qwen3.5 (#42151)、Qwen2.5-VL ビジョン アテンション用の FlashInfer メタデータ (#42787)。

エンジンコア

  • Model Runner V2: Qwen3-dense-by-default oracle (#39337)、スリープモード リロード ウェイト (#42673)、update_config (#42783)、共有 KV キャッシュ レイヤー (#35045)、FP32 ガンベル サンプリング (#41775)、コネクタを使用した MRv1 への自動フォールバック (#42955)、 logprob_token_ids の正確さ (#43125、#41761)、prompt-logprobs のサイズ修正 (#42778)。
  • KV オフロード: 多層フレームワーク (#40020)、Python ファイルシステム セカンダリ層 (#41735)、DSv4 サポート (#43142)、層オフロード フォローアップ (#42529)、HND レイアウト優先 (#41928)、reset_cache() (#41956)、リクエストごとの追跡 (#42507)、ストア遅延修正 (#41945)。
  • MoE リファクタリング: ExpertMapManager (#41046)、専門家は experts/ (#42334)、FusedMoE の RoutedExperts エイリアス (#40735)、FusedMoE の EPLB リファクタリング (#41055) に移動しました。
  • Mamba: アテンション モジュール リファクタリング (#41126)、Mamba2 SSD カーネル ウォームアップ (#39822)、bf16 SSM キャッシュ (#41680)、GPU 側状態後処理融合カーネル (#40172)、単一トークン拡張をデコードとして実行 (#42430)。
  • KV イベント: KV キャッシュ メタデータを出力します (#40984)。
  • アロケーター: 手動のcumem アロケーター有効化 (#33648)、ストリーム対応の無料コールバック (#43020)。
  • elastic-EP: 再構成時の MoE quant メソッドのステージ/コミット (#40881)。

ハードウェアとパフォーマンス

  • NVIDIA Blackwell / SM12x: SM120/121 用 FlashInfer b12x MoE + FP4 GEMM (#40082)、SM12.1 上のテンソルごとの FP8 CUTLASS (#41215)、FlashInfer TRTLLM アテンション用 head_dim=512 (#38822)、FlashInfer Blackwell GDN プレフィル (#40717)、 SM100 用の GDN プレフィル カーネル (#43273)。
  • パフォーマンス: バッチ不変 Cutlass FP8 (+28.9% E2E) (#40408)、CutlassFP8 パディング前処理 (+13.5% TTFT) (#42651)、パディングされた NVFP4 Quant カーネル (+2.4–5.7% E2E) (#42774)、 GPU<->CPU 同期除去 1/n (#41429) および 4/n (#42347)、MLA 用の RoPE+KVCache+q_concat の融合 (#40392)、MLA compute_prefill_context / _v_up_proj 最適化 (#42460、#42561)、ペナルティ Triton カーネル (#40657)、do_not_specialize融合型 FP8 RoPE (#42849)、TRITON_MLA デコード用の FULL CUDA グラフ キャプチャ (#42885)。
  • AMD ROCm: DSV4 機能 + 精度修正 (#42810、#43679 Tilelang MHC)、フラッシュ スパース MLA Triton カーネル (#41812)、gfx950/MI355X 上の gluon ページング MQA ロジット (#42062)、gfx950 用 RMSNorm+Quant fusion (#41825)、 AITER FA バックエンド クリーンアップ (#41942)、MoRI コネクタ用 XGMI バックエンド (#41753)、QuickReduce 最小サイズ オーバーライド (#41675)、DSV4 MTP (#43385)。
  • CPU / RISC-V: VLEN=256 の RISC-V Vector Extension (#40119) (#42943) 用の RVV に最適化されたアテンション カーネル、AMX CPU 用の融合 GDN (#42707)、MXFP4 W4A16 MoE (#41922)、CPU 上の実験的 Triton + MRv2 (#43225)、改善された CPU スレッド使用率 (#42666)、--cpu-distributed-timeout-seconds (#42968)。
  • インテル XPU: GPTQ int4 サポート (#37844)、mxfp8 MoE (#41918)、FP8 ブロックスケール量子化 (#42952)、カスタム操作集合動作 (#41354)、複数のスパース アテンション カーネル (#37888)、MoE topk ルーティング + MXFP4 フォールバック (#42951)、 CT W4A4 MXFP4 パス (#38896)、XPU MoE ホスト オーバーヘッドの削減 (#42915)。
  • カーネル ABI: libtorch 安定版 ABI への継続的な移行 — 5/n (#42339)、6/n (#42663)、7/n (#43209)。
  • 実験的: 壊れやすい CUDA グラフ (#42304)。

大規模なサービス提供

  • 分散サービング (NIXL): P 上の KV ブロックのリース更新 TTL (#41383)、ハンドシェイク失敗ポリシー遵守 (#40364)、NIXL による PD の GDN サポート (#41869)、マルチノード TP>8 修正 (#39907)、サイドチャネル ホスト選択修正 (#41806)。
  • Mooncake: MooncakeStoreConnector でのディスク オフロード (#42689)、DSV4 の HMA サポート (#42828)、操作メトリクス (#43392)、ロード障害の伝播 (#42788)、ブロック整列されたフル ヒット (#43494)、プリエンプション後の終了処理 (#43281)。
  • データ パラレル: DP スーパーバイザー (#40841)、エンジン ステップ開始時のパブリッシュ リクエスト数 (#41626)、X-data-parallel-rank ヘッダーの転送 (#42330)。
  • EPLB: デフォルトの EPLB コミュニケーターを変更 (#43110)、VLM ラッパー初期化を修正 (#39805)、無効な torch.accelerator.synchronize() (#40733) を削除。
  • LoRA: MoE LoRA 用のワンショット Triton カーネル (#42290)、同時 2D および 3D MoE LoRA アダプター (#42242)、EP での 2D 重みメモリの削減 (#42737)、MoE LoRA align-kernel グリッド修正 (#40131)。

量子化

  • MXFP4: 線形レイヤー + 圧縮テンソルの統合 (#41664)、CPU W4A16 MoE (#41922)、XPU mxfp8 MoE (#41918)。
  • NVFP4: DeepSeek V4 融合 MoE (#42209)、ModelOpt W4A16 NVFP4 融合 MoE + 混合精度ディスパッチ (#42566)、バッチ不変 NVFP4 Cutlass リニア (#39912)、FlashInfer TRTLLM NvFP4 モノリシック MoE ルーティング修正 (#43223)、TRTLLM NVFP4 MoE チャンク修正 (#43599)。
  • Quark: Quark NVFP4 チェックポイント (#35859)、Step-3.5-Flash の W8A8 INT8 ガベージ出力修正 (#41892)、W4A4 oracle リファクタリング (#41436) をロードします。
  • AutoRound: W4A16 のサポート (#39778)。
  • ModelOpt: Qwen3.5/3.6 VLM 量子化プレフィックス マッピング (#42546)。
  • フレームワーク: アクティベーションオーバーライドで QuantKey を使用するように quantization_config を再加工 (#41566)、MoE W4A8 CT を Oracle に移行 (#42680)、AWQ Marlin MoE をモジュラー WNA16 oracle に (#42483)、GPTQ 統合 (gptq_marlin → auto_gptq) (#38288)。

API とフロントエンド

  • Rust フロントエンド: 統合 (#40848)、ツリー内コード移動 (#43283)、ユーティリティ コール ID の新しいタイプ (#43405)、簡素化された AuthenticationMiddleware パス抽出 (#43426)。
  • レスポンス API: chat_template_kwargs のサポート (#42272)、メッセージ結合の修正 (#42189)、空のチャネル/受信者のハーモニーの修正 (#35540)。
  • 完成: thinking_token_budget サポート (#42116) と反転条件修正 (#41674)。 reasoning_effort を enable_thinking にマップします (#43401)。
  • フロントエンド: OpenAI エンドポイントの切り捨て側 (#43260)、reasoning_content → reasoning の正規化 (#42664)、再加工された fastoken 統合 (#43168)、統合された Speech-to-Text エントリポイント (#42370、#42274)、BeamSearchMixin によるビーム検索統合(#42946)、チャット テンプレートのスコア/再ランク付け手順 (#42412)。
  • 認証: /v2 エンドポイントの API キー認証 (#42594)。
  • オフライン API: オフライン API のプールを PoolingOfflineMixin (#42267) に分割し、オフライン推論 APIs/utils (#43553) を分割しました。

ビルドと依存関係

  • CUDA 12.9 ホイール ビルドは PyTorch manylinux_2_28 ベース (#41668) に切り替えられました。
  • FlashInfer は v0.6.11.post2 (#41711) に変更されました。 nvidia-cutlass-dsl ～ 4.5.2 (#42991、#43230、#43745); 1.7 (#42150) へのご案内。 gpt-oss 用に triton_kernels が v3.5.1 にダウングレードされました (#43135)。
  • Rust フロントエンド ビルド: setuptools-rust 依存関係 (#43287、#43377)、rust ビルド ステージで固定された protoc (#43292)。
  • Docker: 非ルート vllm-openai ターゲット (#40275)、ソースからの mooncake-transfer-engine のビルド (#42114)、AINIC および Thor NIC サポート (#40453)。 Python のみのインストールがオプションになりました (#42293)。
  • vllm-tpu: CUDA deps のビルド分離を無効にする (#43038)、tpu-inference docker ビルド修正 (#43360)。
  • humming MoE バックエンド依存関係が追加され、元に戻され、CuPy ランタイム修正 (#42540、#43492、#43530) で復元されました。

非推奨と削除

  • get_tokenizer および resolve_hf_chat_template の古い場所を削除しました (#35024)。
  • マークされた環境変数は --moe-backend / --linear-backend (#43148) でカバーされるようになりました。
  • 非推奨の MLA 事前入力引数 (#42555) を削除しました。
  • デッド CUDA カーネルとデッド コード (#42767、#42889、#43144) を削除しました。
