vllm v0.24.0

vLLM v0.24.0 Release Notes

ハイライト

このリリースには、256 人の寄稿者 (77 人が新規) による 571 件のコミットが含まれています。

  • MiniMax-M3: 新しい MiniMax-M3 モデル (#45381) のサポートが追加され、MSA 経由の BF16/FP8 インデクサー (#45892)、MXFP4 サポート (#45896)、FP8 スパース GQA (#45744)、および広範な AMD/ROCm チューニング - mxfp8 MoE/リニア オンが追加されました。 gfx950 (#45725)、MI300X の bf16 重み用 fp8_per_channel (#45854)、FP8 KV キャッシュ修正 (#45720)、およびパックモジュール マッピング (#45794)。 MiniMax-M2 のパフォーマンス回帰も修正されました (#45935)。
  • DeepSeek-V4 は成熟し続けています: デビュー後、DeepSeek-V4 は別の大規模な最適化パスを受け取りました。これには、FlashInfer スパース インデックス キャッシュ (2 ～ 4% TTFT) (#45863)、プリフィル チャンク プランニングの最適化 (4% E2E スループット) (#45061)、低レイテンシーのためのクラスター連携の topK カーネル (#43008)、連続ブロックごとの KV 割り当て (#44577)、ブロック FP8 共有エキスパートの TEP=16 (#46001)、SM100 上の next_n > 2 のネイティブ DSA インデクサー デコード (#45322)。これは、GLM-5.1 (#43477) と並んで SM120 で有効になり、XPU (#44144、#44517、#45240) および ROCm (#44899、#45103、#45681) のアテンション/MoE パスが追加されました。
  • Model Runner V2 (MRv2) は拡張を続けています: MRv2 は デフォルトで量子化モデルをサポート (#44446)、デフォルトで GraniteMoE を有効にします (#45461)、Qwen + DeepSeek-V2 MoE モデル (#42667)、DFlash 投機的デコード (#44586)、およびより正確な FP32 Gumbel サンプリングの移行が可能になりました。 (#45996)。
  • ストリーミング パーサー エンジン: 新しいストリーミング パーサー エンジンは、Qwen3 (#45413)、MiniMax-M2 (#45701)、GLM-4.7/5.1/5.2 (#45915)、および Nemotron V3 (#45755) のパーサーを使用して、モデル間のツール呼び出し/推論解析を統合します。
  • Diffusion LLM: CPU パス (#45690) と拡散デコーダ用の構造化出力ガードレール (#45468) を含む DiffusionGemma (#45163) を追加しました。
  • ** WideEP / DeepEP v2**: エキスパート並列処理 (#41183) のために DeepEP v2 が統合され、後続の堅牢性修正 (#46404、#46432) が行われました。
  • Rust フロントエンドがさらに成熟: API キー認証 (#44321)、CORS (#45753)、/tokenize + /detokenize (#44222)、/pause /resume /is_paused (#44499)、/abort_requests (#44382)、/get_world_size を追加しました。 (#44801)、thinking_token_budget (#46137)、Rust ツール パーサー用の Python ブリッジ (#44624)、および多くの新しいパーサーと検証パス。
  • デバイス選択の変更: vLLM は内部で CUDA_VISIBLE_DEVICES を設定しなくなりました。代わりに、新しい device_ids 引数が提供されます (#45026)。 ROCm では、CUDA_VISIBLE_DEVICES の非推奨期間が始まりました (#46636)。

モデルのサポート

  • 新しいモデル: MiniMax-M3 (#45381)、DiffusionGemma (#45163) + CPU 上の Gemma 拡散 (#45690)、階層推論モデル — テキスト / HrmTextForCausalLM (#43098)、OpenMOSS (#44124)。
  • Gemma 4: すべてのレイヤーにわたる Unified FlashAttendant (FA4) + mm_prefix サポート (#42175);多くのパーサー/サービングの修正 - 必須/名前付きツール選択の強制 JSON スキップ (#45795)、思考を無効にした解析 (#45832)、ストリーミング推論状態の初期化 (#45852)、アシスタント ターン時の推論レンダリング (#45867)、オフライン パーサーの切り捨て/トークン リークの修正 (#45553)。従来の Gemma4 パーサーはエンジンベースの実装に置き換えられました (#45588)。
  • DeepSeek-V4: OOM 修正 (#44914)、MTP プロジェクション プレフィックス (#44821)、サポートされる KV キャッシュ dtype (#44892)。
  • Qwen / マルチモーダル: Qwen3-VL ビデオ ローダー (#44412)、Qwen2-VL/Qwen2.5-VL プロセッサー マップド ビデオ ローダー (#45555)、Qwen3-VL マルチビデオ処理最適化 (#46026) およびマルチビデオ クラッシュ修正 (#46305)、Qwen3-Omni VIT cu_seqlens デバイス修正(#44264)、Qwen3.5 用の qk-rmsnorm-rope-gate の融合 (#44176)、Qwen3.5 EP の重量読み込み修正 (#45002)。
  • ViT フル CUDA グラフ: GLM-4.1V (#40576)、DeepSeek-OCR デュアルパス (#43586)、Kimi-VL (#41992)、mllama4 (#40660)、Lfm2VL エンコーダー (#44930)。
  • その他のモデルの修正: Llama4 ウェイト ロード (#45047) およびホスト OOM を回避するためのストリーミング ロード (#44645)、MiMo v2.x QKV TP シャーディング + FP4 (#45200)、ColQwen3.5 取得の正確性 (#46108)、EXAONE-4.5 ビジョン エンコーダ (#45073)、 MiDashengLM TP>1 オーディオ エンコーダのクラッシュ (#44408)、MiniCPM-o/V デバイスの配置と画像サイズの修正 (#43844、#42332、#44980、#45244)、Cohere2 MoE 重み読み込み + パーサー (#44747、#44907)、Nemotron V3 コンテンツとしての推論 (#39091)、 ColBERT AutoWeightsLoader + クエリ/ドキュメント埋め込み IO プロセッサ (#44999、#45210)。
  • カーネル: GLM-5 TRT-LLM 不規則な MLA プレフィル寸法 (#43525)、GLM-5 ルーター GEMM (#46385)。

エンジンコア

  • Model Runner V2: デフォルトの量子化モデル (#44446)、GraniteMoE デフォルト (#45461)、Qwen/DSv2 MoE 移行 (#42667)、DFlash (#44586)、簡素化された非同期出力処理 (#45442)、num_heads_q でのアテンション グループ分割 (#45564)、LoRA ウォームアップ修正(#35536)、より正確な FP32 Gumbel サンプリング (#45996)、V2 GPU サンプラーの min_tokens オフバイワン修正 (#46243)、さらにさまざまなモデル/構成互換性修正 (#45868)。
  • 投機的デコード: ダイナミック SD (#32374); FlashInfer を使用した DFlash (#43081)、混合 KV ページ サイズ (#45181)、および Qwen3Next ターゲット (#45319)。 EAGLE3 による Qwen3 のサポート (#43132);語彙の多いドラフトの TP コミュニケーションを削減 (#39419)。非同期受け入れカウントの競合修正 (#45100); EAGLE マルチモーダル エンコーダ キャッシュの修正 (#46315)。
  • KV キャッシュとスケジューラ: プリエンプションを削減する KV キャッシュ ウォーターマーク (#44594)、クロスグループ プレフィックス キャッシュ ヒットに対する 2 フェーズ割り当て (#44409)、ハイブリッド キャッシュ用のマルコーニ スタイル アドミッション ポリシー (#37898)、Mamba/リニア アテンション用のプレフィックス キャッシュ保持 (#45845)、MTP アライン モード用の DS Mamba テール コピー(#45473)、スケジューラーのコピーのオーバーヘッドが削減されました (#45840)。
  • 注意: ストライド認識カーネルによる MLA のクロスレイヤー KV キャッシュ レイアウトの再有効化 (#45111)、MLA プレフィル FA4 fp8 出力 (#43050)、完全に cudagraphable となった FlexAttend カスタム マスク MOD (#45232)、MiMo 用の triton diff-kv バックエンド (#41797)、FlashMLA スパース精度の修正(#36616)。
  • ウェイト ロードとコア: ウェイト ロード用の fastsafetensors ParallelLoader (#40183)、UMA GPU の圧力下でキャッシュされたデバイス メモリの解放 (#45179)、ビーム サーチ用の構造化出力 (#35022)、device_ids 引数 / 内部 CUDA_VISIBLE_DEVICES なし (#45026)、numactl --membind がブロックされた場合のグレースフル フォールバック(#45438)、トークナイザー初期化前の構成クラスの登録 (#40299)、マルチモーダル モデルのプロンプト埋め込みによる非同期スケジューリング (#45673)。

大規模なサービス提供と分散

  • エキスパート並列: DeepEP v2 統合 (#41183) とトークン バインドおよび topk インデックスの修正 (#46404、#46432); NIXL EP — NIXL EP による DBO (#45275)、top-k インデックス dtype クエリ (#45298)、NVFP4 受信後量子化スキップ (#45606)、elastic-EP コミュニケーター (#45013)。非同期 EPLB を使用した NCCL ベースの EPLB を拒否します (#44978)。
  • KV コネクタ / 分散サービング: プリフィルから NIXL 経由でデコードするための KV プッシュ (#35264)。 full-attn + MLA 混合グループの領域ごとの KV 転送分類 (#44583); Mooncake パイプライン並列 PD サポート (#44528)、非同期ルックアップ (#45659)、コンパクト チャンク ハッシュ ゼロコピー ルックアップ (#45969)、SWA ブロック スキップ (#45444)。 DP スーパーバイザー (#46628) および DSV4 分解 (#45831) による P/D の修正。 P2pNcclConnector (#44854) を削除しました。
  • KV オフロード: 多層非同期バッチ ルックアップ (#44193)、パックされた HMA KV キャッシュ レイアウト (#46205、ゲート付き #46252)、並列に依存しない fs 層キャッシュ (#44733)、オフロード マネージャー統計 (#35669)、およびラベル付き/CPU 使用率メトリクス (#45957、 #45737)、自己記述型 KV イベント (#43468)、非ブロッキング アイドル フラッシュ (#45595)、および多数の正確性/競合修正 (#44784、#45823、#46231、#46278)。
  • 分散コア: 非 PD DP バランスを改善するためのプレフィル ステップ ケイデンス (#44558)、KV イベント マップ エンコーディング (#42892)、ワンショット フューズド all-reduce PDL NaN 修正 (#45448)。

ハードウェアとパフォーマンス

  • NVIDIA / カーネル: swap_ab による SM90 CUTLASS FP8 mm 奇数 M サポート (180 ～ 290% のカーネル速度向上) (#44572)、H100 上の Qwen3-Next-80B 用に fused_moe FP8 を調整 (+25%) (#44830)、SM100 上のネイティブ DSA インデクサー デコード(#45322)、DeepSeek 低レイテンシー用のクラスター連携 topK (#43008)、DeepGEMM の PDL サポート (#46006)、FlashInfer のcutedsl NVFP4 GEMM (#42235) およびcute-dsl MXFP8 リニア カーネル (#46393)、FP8/RMSNorm quant 用の新しい Helion カーネル (#36902、 #33790、#36895、#34432)。
  • torch 安定版 ABI: libtorch 安定版 ABI へのカーネルの移行が継続 (および完了) — MoE [10c/n] (#44565)、Marlin [11a/n] (#45176)、Machete [11b/n] (#45304)、最終的な _C ライブラリ移行 [12/n] (#45415)。
  • AMD ROCm: トーチ 2.11 (#45362);融合 AR + RMSNorm + グループごとの FP8 quant (#42864)、AITER の下で融合 Softplus-sqrt-topk MoE ルーター (#44945)、DSv4 フラッシュ デコード スプリット K カーネル (#44899) およびインバース RoPE 融合 (#45103)、W4A16 FlyDSL MoE (#44400)、A8W4 MoE gpt-oss の CDNA4 スウィズル ゲート (#44804); ROCm の CUDA_VISIBLE_DEVICES に対して非推奨期間が開始されました (#46636)。
  • インテル XPU: シーケンス並列サポート (#38608)、torch-xpu 2.12 (#42262)、vllm-xpu-kernels v0.1.10 (#40367)、W4A16 int4 group_size=32 MoE (#45136)、DeepSeek-V4 attention/MoE パス (#44144、 #44517、#45240)、top-p サンプリングの正確性の修正 (#44470)。
  • CPU およびその他のアーキテクチャ: マルチスレッドによる 2.5 倍の高速 ASR CPU 前処理 (#44612)、CPU W4A16 INT4 MoE (#43409)、cgroup メモリ制限を意識した KV キャッシュ サイズ設定 (#45086)、RISC-V oneDNN W8A8 INT8 (#44478)、および RVV micro-GEMM WNA16 (#44324)、WSL2 用の固定メモリ (#41496)、ZenCPU ランタイム ログ (#42726)。
  • TPU: tpu 推論が v0.22.1 (#45793) にアップグレードされました。
  • その他のパフォーマンス: VLLM_TRITON_FORCE_FIRST_CONFIG は、Triton 自動チューニング (#42425)、Triton 再コンパイル検出 (#45631)、融合型マルチグループ ブロックテーブルの段階的書き込み (#44944) をスキップします。

量子化

  • オンラインおよび混合精度: オンライン FP8 チャネルごとのトークンごと (PTPC) 量子化 (#44132)。 modelopt_mixed のサポートが Ampere/SM80-86 (#45306) および Turing/SM75 (#45375) に拡張されました。
  • FP4 / MXFP: FlashInfer Cutedsl NVFP4 GEMM バックエンド (#42235) および Cute-dsl MXFP8 リニア カーネル (#46393)、MXFP4 W4A4 MoE CUTLASS E8M0 スケール修正 (#43557)、非 Blackwell 上の NVFP4 MoE 用に配線された SwiGLU クランプ (#45836)、 flashinfer_cutlass は、クランプされた NVFP4 MoE バックエンド (#46492)、NVFP4/OCP MX MoE エミュレーション修正 (#46254)、NVIDIA Thor で再有効化された FP8 MoE (#46339) として許可されました。
  • GGUF / 圧縮テンソル / AWQ: GGUF 量子化はプラグインに移行されました (#39612)、圧縮テンソル WNA16 MoE アクトオーダー修正 (#41161) および KV キャッシュ スキーム拒否 (#45312)、XPU 上の AWQ 形式 (#43404) および Intel XPU 上の AWQ 逆量子化修正 (#42727)。
  • カーネルと正確性: QuantizedActivation リニアカーネル コントラクト (#44260)、統合された Marlin スレッド タイル パディング (#45295)、(K, N) に正規化された FP8 重みレイアウト (#44735)、LoRA がロードされた MoE FP8 の出力破損の修正 (#42120)、GPTQ/CT MoE の対称クオンツ回帰修正(#45656)、fp8_e5m2 KV キャッシュは非 fp8 チェックポイントに許可されました (#45040)。

API とフロントエンド

  • ツール呼び出しと解析: チャット完了 (#45003) および応答 API (#45396) でのツール呼び出しの厳密モード。 Qwen3、MiniMax-M2 (#45701)、GLM-4.7/5.1/5.2 (#45915)、Nemotron V3 (#45755) パーサーを備えた新しいストリーミング パーサー エンジン (#45413)。チャットサービスにおける統合パーサーの統合 (#45548);多数のパーサーの正確性の修正 (#46047、#46091、#46159、#45763、#46351、#43984)。
  • OpenAI / 応答: メッセージ + chat_template_kwargs の実際の /v1/embeddings サポート (#45173)、usage.prompt_tokens_details のマルチモーダル トークン カウント (#45458)、チャット応答から空の tool_calls を省略 (#44105)、応答 API ストリーミング function_call ID 修正 (#44608)、ハーモニー リファクタリングストリーミング/非ストリーミング パス (#45171、#45104)。
  • Anthropic Messages API: /v1/messages でのキャッシュ使用量レポート (#40912)、会話中のシステム メッセージ処理 (#46025)、プレフィックス キャッシュ用に保存されるインライン システム メッセージ位置 (#44602)、tool_use 引数ドロップの修正 (#45287)。
  • Rust フロントエンド: API キー認証 (#44321)、CORS (#45753)、/tokenize + /detokenize (#44222)、/pause /resume /is_paused (#44499)、/abort_requests (#44382)、/get_world_size (#44801)、thinking_token_budget (#46137)、parallel_tool_calls=false (#44760)、継続使用統計 (#43965)、/v1/models のモデル メタデータ (#45950)、Rust ツール パーサー用の Python ブリッジ (#44624)、HTTP/ZMQ 専用ランタイム(#46051)、および多くの検証/正確性の修正。
  • メトリクス: vllm:tool_call_parser_invocations_total (#44448)、vllm:cache_config_info のグループ対応 KV キャッシュ容量 (#42206)、DeepSeek MFU 推定の MLA アテンション メトリクス (#39457)。
  • プーリング/埋め込み: Cohere /v2/embed 入力排他性 (#45640)、非負再ランク top_n (#46119)、マトリョーシカ埋め込み次元境界 (#46313) の検証。
  • ベンチマーク: vllm bench serve 用の BFCL ツール呼び出しデータセット (#42457)、マルチターン ベンチマーク api_key/カスタム ヘッダー (#44516)、トークナイザーの不一致自動修正 (#44708)。

セキュリティ

このリリースには、別の調整されたセキュリティ強化バッチが同梱されています (その多くはセキュリティ研究者 @jperezdealgaba によるものです)。

  • サービス拒否: speech-to-text エンドポイントでのオーディオ解凍爆弾 (#44970)、投機的デコードでの無効な回復トークン再注入によるリモート DoS (#44744)、M-RoPE モデルでの prompt_embeds による DoS (#45252)、構造化出力での正規表現コンパイルのタイムアウト ガード (#45118)、完全な実体化前のオーディオ アップロード サイズ制限(#45510)、チャット完了パスのオーディオ デコード期間制限 (#45908)。
  • 情報開示: GGUF 逆量子化カーネルにおける int32 の切り捨て (#44971)。
  • 入力検証と強化: 画像の EXIF 方向と tRNS 透明度の処理 (#44974)、非有限 temperature/repetition_penalty の拒否 (#45116)、Anthropic および STT エラー パスに適用される sanitize_message (#45119)。
  • 依存関係: CVE-2026-48710 (#45675) を修正するには、Starlette を 1.0.1 以上にアップグレードします。

依存関係

  • ROCm のトーチ 2.11 (#45362)、トーチ xpu 2.12 (#42262)、tpu 推論 v0.22.1 (#45793)、XPU の NIXL v0.10.1 (#40287)、Starlette ≥ 1.0.1 (#45675)。
  • mistral_common は遅延インポート (#45305) によりオプションになりました。 C++20 の CUDA Docker ファイルが GCC 10 から GCC 12 にアップグレードされました (#44923)。 Python < 3.11 でスピンループ拡張がスキップされました (#44783)。

非推奨と削除

  • 削除されたモデル: ERNIE (廃止) (#45127)、Xverse (#45638)、Dots1 (#45637)、Bamba (#45990)、Mono-InternVL (#45129)、InternLM レジストリ エイリアス (#45128)。
  • 非推奨: 第一世代の Qwen および QwenVL モデル (#45131)、Transformers v4 サポート (#45161)、ROCm 上の CUDA_VISIBLE_DEVICES (#46636)。 v0.23/v0.24 の一般的な非推奨 (#44992)。
