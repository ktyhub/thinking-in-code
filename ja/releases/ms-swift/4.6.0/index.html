ms-swift v4.6.0

ms-swift v4.6.0

#v4.6.0

JEV サポート (型付き決定 / System-1)

  • JEV スタイルの意思決定モデルに decision タスク タイプを追加しました。テキストを生成する代わりに、モデルは単一の前方パスで各質問の固定オプション セット (choice / score / noul) に対する調整された確率を返します。 (#10306)
  • リリースされた 3 つの意思決定モデル JEV-27B-VL、Clef、および OmniJev のすぐに使えるレシピ。トレーニング、推論、LoRA マージ/エクスポートをカバーします。 CausalLM は swift sft --task_type decision で変換することもできます。
  • 詳細: 決定事項 (ベスト プラクティス) · 例

新しいモデル

  • MiniCPM5 (1B / 2B) — ベースおよび SFT バリアントを備えた LLM シリーズ、vLLM 推論がサポートされています。
  • MiniCPM-V-4.7 (1B / 35B-A3B) — 画像およびビデオをサポートするビジョン言語モデル。
  • GLM-5.3-Flash — ビジョンとビデオをサポートする ZhipuAI GLM-5.3-Flash。
  • DeepSeek-V4.1-Flash — Megatron-SWIFT のフルパラメータ SFT および GRPO と vLLM 推論。
  • Xing4.0-29B-A4B — MLA + MoE + mHC; LoRA およびフルパラメータ SFT (DDP / DeepSpeed ZeRO-3)、grouped_mm エキスパート アクセラレーション (~3.7x)。
  • MonkeyOCRv2 (S / B) — OCR およびドキュメント理解モデル。

新機能と互換性

  • torchada 経由で Moore Threads (MUSA) バックエンドを追加しました。 (#10224)
  • 互換性: Transformers ≥ 5.17 カーネル プロキシ、vLLM 0.28+ コロケート ウェイト同期 / ウェイクアップ API、および Transformers 5 での TRL オプションの依存関係チェック (#9770、#10311、#10315)
  • GLM-5.3 をサポートする qwen4_exp / glm5_next MTP サンプルを更新しました。 (#10219)

セキュリティ

  • WebUI とロールアウトの強化: 認証されていない RCE と任意のファイル読み取り、ロールアウト側の脆弱性、および GitHub アクション ワークフロー インジェクションを修正しました。 (#10209、#10218、#10226、#10227)
  • リクエストボディの逆シリアル化の前に認証します。メガトロンチェックポイントロード用のweights_only=True。セキュリティ修正プログラムをダウンロードします。 (#10062、#10066、#10234、#10235)

トレーニングと研修

  • SP、DPO、DAPO/CISPO/FIPO、および GKD/GRPO にわたる損失と勾配の調整 (ライガーおよびオフポリシーのパスを含む)。 listwise reranker と部分的な勾配累積の修正。 (#9977、#10100、#10104、#10116、#10130、#10144、#10185、#10244、#10285)
  • Megatron と並列処理: 連続した CP トークンの順序、出力アンパック/パックされた seq_acc / MoE aux loss、mcore チェックポイント メタデータでのリング パディング処理。 (#10071、#10113、#10181、#10182、#10184、#10242)
  • トレーニングの安定性: 生成エラー後の ZeRO-3 フック、GaLore チェックポイント、LISA 初期化とレイヤー選択、SP サンプラー オプション、CPU オフロード アクティベーション ビュー。 (#10132、#10140、#10157、#10161、#10173、#10260)
  • RLHF とロールアウト: オフロード/vLLM ウェイクアップ順序の併置、非同期ロールアウト障害の伝播、IPC バケット確認、vLLM LoRA メタデータ、およびローカル教師アダプター。 (#10092、#10107、#10109、#10207、#10231、#10232)
  • 埋め込みとリランカー: DDP / Megatron DP での InfoNCE ネガティブ サンプリングと勾配補正、DP メトリック収集、WeMM 重複転送。 (#10059、#10068、#10069、#10081、#10088、#10091、#10150)

推論と展開

  • qwen-omni vLLM 推論、フレーム サンプリング後のビデオ メタデータ処理、および video_second_per_grid テンソル処理を修正しました。 (#10168、#10274、#10330)
  • infer: アダプター キャッシュと非同期リクエストの分離、独立したイベント ループ スレッド、ストリーミングされたリクエストの完了、ワーカー エラーの伝播、SSE ハートビート。 (#10080、#10086、#10093、#10094、#10134、#10135、#10177)
  • MP+DDP のデバイスマップ メモリ解像度。 CLI リスト値のシリアル化。空白の LOG_LEVEL / LOCAL_RANK の取り扱い。 WebUIのデフォルトポート。 (#10210、#10217、#10245、#10246、#10248、#10292)

テンプレート、エージェント、ツール呼び出し

  • GLM / glm4_5 / Qwen3-Coder / kimi_k25 / ReAct / Seed-OSS、OpenAI および Anthropic ツール結果の調整、および JSON-Schema の型結合解析にわたるツール呼び出しの正確性。 (#10169、#10174、#10270、#10271、#10284、#10293、#10294、#10299、#10300、#10304)
  • gemma4、marco_o1、Qwen3-VL ビデオ、Janus、拒否された応答の配置およびツール応答名のテンプレートを修正しました。 (#10120、#10127、#10171、#10190、#10199、#10203、#10230、#10238)

データと WebUI

  • データセット パイプライン: クロスランク キャッシュ レース、Arrow ツールのスキーマ忠実度、ストリーミング パッキング ワーカー検出、バージョン管理されたマップ キャッシュ、メタデータ キャッシュの無効化、メディア シャーディング。 (#10083、#10121、#10125、#10159、#10160、#10162、#10297、#10298、#10301)
  • WebUI: 名前付きデータセットにハブ ID がリストされるようになりました。 (#10119)
  • モデルの読み込み: Idefics3 AutoModelForImageTextToText、DDP での MiniCPM 位置キャッシュ、MiniCPM-o パディング オフセット、seq-cls メタデータ ラウンドトリップ。 (#10187、#10202、#10228、#10253)

パフォーマンス

  • ベクトル化されたリングアテンション LSE 抽出とパックされたジグザグ CP 再構成。シングルランクグループのより高速なデータローダー。バッチロールアウト / 教師-API メトリック収集。 (#10064、#10082、#10239、#10240、#10241)

ドキュメント

  • AGENTS.md および貢献ガイドライン (人間が提出した PR、初めての貢献者および AI 支援による貢献者) を追加しました。 (#10339、#10347)
  • ハードウェアと docker イメージのドキュメントを更新しました。報酬の例、部分損失重量ドキュメント、ページ内アンカーを修正しました。 (#10067、#10118、#10170、#10172、#10188、#10233)
