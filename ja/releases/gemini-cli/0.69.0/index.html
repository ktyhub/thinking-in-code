gemini-cli v0.69.0

#ジェミニ-cli v0.69.0

何が変わったのか

  • fix(core,cli): https://github.com/google-gemini/gemini-cli/pull/30136 内の @jesussamuel-byte によるテンプレート プレースホルダー置換中にリテラル $ 文字を保持する
  • feat(cli): https://github.com/google-gemini/gemini-cli/pull/30135 の @jvargassanchez-dot による毎日のトークン使用量の /stats ヒートマップ サブコマンドを追加
  • 修正（コア）: https://github.com/google-gemini/gemini-cli/pull/30138 の @villahernandez-coder による ExpandEnvVars での GCLI_EXPAND_TARGET 環境衝突を防止
  • 雑務(リリース): https://github.com/google-gemini/gemini-cli/pull/30140 の @gemini-cli-robot による 0.69.0-nightly.20261104.g89e9d25d6 へのバージョンのバンプ
  • 修正(cli): https://github.com/google-gemini/gemini-cli/pull/30141 の @diegogodinezr による ACP ツール呼び出し更新で AnsiOutput をテキスト コンテンツにシリアル化します。
  • v0.67.0 の Changelog (https://github.com/google-gemini/gemini-cli/pull/30145 の @gemini-cli-robot による)
  • https://github.com/google-gemini/gemini-cli/pull/30146 の @gemini-cli-robot による v0.68.0-preview.0 の Changelog
  • 修正 (コア): https://github.com/google-gemini/gemini-cli/pull/30110 の @duvanka-prasad による Windows PowerShell 置換の誤検知とポリシー処理を修正
  • 修正(cli): https://github.com/google-gemini/gemini-cli/pull/30150 の @duvanka-prasad による @file 参照の先頭と末尾の空白を保持する
  • 修正（コア）: https://github.com/google-gemini/gemini-cli/pull/30153 の @tadipavan による thoughtSignature のみのターンを防止し、マルチモーダル ツールの応答を保持します。
  • 修正(cli): パイプされた標準入力 EOF を待ち、https://github.com/google-gemini/gemini-cli/pull/30163 の @villahernandez-coder による process.stdin の破壊を回避します。
  • 修正(cli): https://github.com/google-gemini/gemini-cli/pull/30147 で @jvargassanchez-dot による escaping エディター選択時に保留中のツール確認を保持する
  • 特技(cli): スタンドアロン テーマのサポート。https://github.com/google-gemini/gemini-cli/pull/30119 の @jesussamuel-byte によるカスタム テーマの json 構成
  • 修正(cli): https://github.com/google-gemini/gemini-cli/pull/30117 の @jvargassanchez-dot によるヘッドレス CLI フォーマットのエラー ペイロードを正規化
  • 修正（コア）：https://github.com/google-gemini/gemini-cli/pull/30124 の @villahernandez-coder による tildeifyPath にパス区切り文字の境界が必要
  • 修正(cli): モデル名を検証し、https://github.com/google-gemini/gemini-cli/pull/30137 の @jesussamuel-byte による /model コマンドの直接引数をサポート
  • 修正(cli): ファイル ウォッチャー エラーを処理し、macOS の許容サンドボックスで FSEvent を許可 (https://github.com/google-gemini/gemini-cli/pull/30143 の @diegogodinezr による)
  • 修正（コア）: マルチパート ツールの出力をバインドし、https://github.com/google-gemini/gemini-cli/pull/30180 の @tadipavan により古いマルチモーダル inlineData を削除しました
  • 修正 (vscode): https://github.com/google-gemini/gemini-cli/pull/30181 の @ugorla-dev によるバレル インポート バンドルの肥大化と冗長な setContext 呼び出しを排除
  • fix(acp): https://github.com/google-gemini/gemini-cli/pull/30165 での @urielefrenvirtusa によるテキストの連結を防ぐために、ストリーム中の再試行を処理します。
  • fix(core,cli): https://github.com/google-gemini/gemini-cli/pull/30182 の @villahernandez-coder によるネットワーク障害時のサイレントな数分間の読み込みハングを防止
  • fix(core,cli): https://github.com/google-gemini/gemini-cli/pull/30186 の @villahernandez-coder による再開時の端末モデル ターン 400 秒とメインスレッド JSONL のフリーズを防止
  • 修正 (コア): 複数時間にわたるクォータの再試行を防止し、https://github.com/google-gemini/gemini-cli/pull/30187 の @urielefrenvirtusa による再試行時に ACP client に通知します
  • 修正（コア）: https://github.com/google-gemini/gemini-cli/pull/30184 の @ugorla-dev による macOS PTY スポーンで孤立した /dev/ptmx マスター FD を閉じる
  • fix(core,cli): https://github.com/google-gemini/gemini-cli/pull/30183 の @jesussamuel-byte により、すべての認証モード (model.requestTimeoutMs / GEMINI_API_HEADERS_TIMEOUT_MS) で 60 秒の API ヘッダー タイムアウトのオーバーライドを許可します
  • 修正(cli): https://github.com/google-gemini/gemini-cli/pull/30160 の @duvanka-prasad によるテーマ ファイルのホーム ディレクトリ チェックに isSubpath を使用
  • 修正(cli): https://github.com/google-gemini/gemini-cli/pull/30164 の @diegogodinezr により、macOS シートベルト サンドボックスに入る前にフォルダー trust を解決します。
  • 修正(cli,core): 子プロセスを強制終了し、キャンセルされたツールを記録し、https://github.com/google-gemini/gemini-cli/pull/30204 の @duvanka-prasad によるヘッドレス アボート時にシグナル終了コードを保存します。
  • 修正(cli): https://github.com/google-gemini/gemini-cli/pull/30185 の @jvargassanchez-dot によるシェル モードでの再帰的対話型 Gemini セッションを防止
  • 修正（コア）: https://github.com/google-gemini/gemini-cli/pull/30189 の @luisfelipe-alt によるパブリッシュが失敗した場合、すぐに MessageBus.request() を拒否する
  • 修正 (コア): https://github.com/google-gemini/gemini-cli/pull/30211 の @urielefrenvirtusa によって明示的に要求されたバイナリ アセット (#29045) のみを read-many-files でインライン化するようにしました。
  • 修正(コア): TortoiseGitPlink を PuTTY ファミリ SSH client (#29917) として認識 (#29917) by @urielefrenvirtusa (https://github.com/google-gemini/gemini-cli/pull/30214)
  • 修正（コア）: https://github.com/google-gemini/gemini-cli/pull/30217 の @tadipavan による PDF inlineData とテレメトリ バッファー メモリの保持を防止 フル Changelog: https://github.com/google-gemini/gemini-cli/compare/v0.68.0...v0.69.0
