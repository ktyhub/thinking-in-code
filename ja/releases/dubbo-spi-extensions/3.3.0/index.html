何が変わったのか

参照

・Apache Dubbo3.3.xに対応

機能強化

  • [dubbo-wasm-rpc-api ] dubbo-wasm-rpc-api モジュールの初期化 (279 の @loongs-zhang による)
  • [dubbo-wasm-cluster-api ] dubbo-wasm-cluster-api モジュールを初期化 (283 の @loongs-zhang による)
  • [dubbo-wasm] プロトコル/エクスポーター/インボーカー SPI をサポート (284 の @loongs-zhang による)
  • [dubbo-wasm-registry-api] init dubbo-wasm-registry-api モジュール by @loongs-zhang (285)
  • [dubbo-wasm-common-api ] パート 5 init dubbo-wasm-common-api モジュール by @loongs-zhang (286)
  • [dubbo-proxy-bytebuddy] 294 の @finefuture による Dubbo 3.2 から bytebuddy 実装をインポートします。
  • [dubbo-wasm-remoting-api] init dubbo-wasm-remoting-api モジュール (295 の @loongs-zhang による)
  • [dubbo-cluster-router-mesh] 307 の @heliang666s による SPI 拡張機能 #13957 へのメッシュ ルール ルーターの移動
  • [dubbo-cluster-router-mesh] 306 の @wcy666103 により REST プロトコルを SPI 拡張機能 #13958 に移動
  • [dubbo-serialization-native-hessian] 377 の @wcy666103 により hession の名前を hessian に変更します
  • [dubbo-serialization-fury] 395 の @wcy666103 による不要な maven.compiler 17 を削除します。
  • [[dubbo-serialization-jdk] jdk-serialize を移動し、417 の @wcy666103 によるテスト ケースを追加します。

バグ修正

  • 修正: 308 の @aofall による dubbo-registry-dns リソース リーク
  • 310 の @wcy666103 によるテスト ライブラリを修正
  • 修正: redis 接続が閉じず、[311] (https://github.com/apache/dubbo-spi-extensions/pull/311) の @aofall によって接続プールに戻されませんでした。
  • 修正: 312 の @aofall によって時々失敗する etcd 単体テストを修正しようとしました
  • 342 の @wcy666103 によるモジュール依存関係エラーを修正

ドキュメント/CI

  • @wcy666103 による auddo-wasm/README_zh.md を 298 に追加

  • ビルド: 300 の @aofall による GitHub アクション ワークフローを追加

  • @wcy666103 による configcenter README を 299 に追加

  • :memo: 304 @songxiaosheng による Readme アップデート

  • ビルド: Windows プラットフォームでの CI サポート単体テスト && 309 の @aofall による依存ボット構成を追加

依存関係のアップグレード

  • #252 の @aofall による avro バージョン 1.8.2 -> 1.11.3 を更新します。
  • 330 の @dependabot による commons-lang3 3.8.1 -> 3.14.0 の更新
  • 337 の @dependabot によるテストコンテナ 1.15.2 -> 1.19.8 の更新
  • Spring-cloud-dependency Hoxton.SR8 -> Hoxton.SR10 を 335 の @dependabot によって更新します。
  • 332 の @dependabot による protostuff_version 1.5.9 -> 1.8.0 の更新
  • 331 の @dependabot による org.apache.maven.plugins:maven-assembly-plugin 3.1.0 -> 3.7.1 の更新
  • 329 の @dependabot による protobuf-java_version 3.16.3 -> 3.25.3 の更新
  • 328 の @dependabot により、sofa_registry_version 5.2.0 -> 5.4.3 を更新します。
  • 326 の @dependabot による rocketmq.version 4.9.2 -> 4.9.8 の更新
  • 327 の @dependabot による spring-boot.version 2.4.1 -> 2.7.18 の更新
  • 324 の @dependabot により com.google.code.gson:gson 2.8.9 -> 2.10.1 を更新します
  • 321 の @dependabot により、fabric8_kubernetes_version 6.9.2 -> 6.12.0 を更新します。
  • 320 の @dependabot による org.apache.httpcomponents:fluent-hc 4.5.5 -> 4.5.14 の更新
  • 319 の @dependabot による io.netty.incubator:netty-incubator-codec-quic 0.0.14.Final -> 0.0.20.Final の更新
  • 323 の @dependabot による org.apache.maven.plugins:maven-clean-plugin 3.1.0 -> 3.3.2 の更新
  • 317 の @dependabot による org.codehaus.mojo:license-maven-plugin 2.0.0 -> 2.4.0 の更新

  • 316 の @dependabot による grpc.version 1.53.0 -> 1.63.0 の更新
  • 345 の @wcy666103 によるダボ 3.3 をアップグレードします。
