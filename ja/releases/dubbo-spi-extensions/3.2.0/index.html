dubbo-spi-extensions v3.2.0

dubbo-spi-extensions v3.2.0

何が変わったのか

参照

※Apache Dubbo3.2.xに適合します。

機能強化

  • [dubbo-cluster-specify-address-dubbo2] https://github.com/apache/dubbo-spi-extensions/pull/179 の @wxbty による dubbo-cluster-specify-address-dubbo2 の非ローカル クラスターの動的 IP アクセスをサポートします。
  • [polaris 拡張機能] https://github.com/apache/dubbo-spi-extensions/pull/184 の @andrewshan により、dubbo2.7.x が Polaris にアクセスできるように、polaris 拡張機能を追加します。
  • [dubbo-filter-polaris-dubbo2] 回路ブレーカーとレートリミット フィルターを分離し、開発者にとってよりわかりやすく分解できるようにします (https://github.com/apache/dubbo-spi-extensions/pull/187 の @andrewshan による)
  • [dubbo-gateway-extensions] https://github.com/apache/dubbo-spi-extensions/pull/205 の @wxbty によるゲートウェイ モード拡張機能を追加
  • [polaris] https://github.com/apache/dubbo-spi-extensions/pull/212 の @chuntaojun による Polaris サーキットブレーカー機能をサポートします
  • [クロススレッド] https://github.com/apache/dubbo-spi-extensions/pull/215 の @carlvine500 による dubbo-cross-thread-extensions のアノテーションによるタグ corss thread
  • [タグサブネット] https://github.com/apache/dubbo-spi-extensions/pull/216 の @carlvine500 により、near-rpc のサブネットごとにタグを追加します
  • [連載] https://github.com/apache/dubbo-spi-extensions/pull/226の@chaokunyangによるダボに怒りの連載フレームワークを追加
  • [dubbo-serialization-jackson] @aofall によるジャクソンシリアル化拡張機能を https://github.com/apache/dubbo-spi-extensions/pull/231 に追加
  • [dubbo-xds] https://github.com/apache/dubbo-spi-extensions/pull/251 の @AlbumenJ による Dubbo 3.2 から Kubernetes と xDS 実装をインポート

バグ修正

  • https://github.com/apache/dubbo-spi-extensions/pull/209 の @wxbty による元に戻すエラーの説明を修正
  • https://github.com/apache/dubbo-spi-extensions/pull/233 の @aofall によりリソース ファイルを dubbo-serialization-jackson の正しいパスに移動する問題を修正
  • ダボ 3.0 の ServiceConfigURL シリアル化問題を修正: アプリケーション、バージョンなどのパブリック パラメーターが転送されない、https://github.com/apache/dubbo-spi-extensions/pull/67 の @zrlw による protostuff の追加と ServiceConfigURLDelegate
  • 修正(#207): Dubbo Redis レジスタは、https://github.com/apache/dubbo-spi-extensions/pull/247 の @aofall による選択データベースをサポートします。
  • 修正[#267] JvmInvoker で deepCopy するときに protobuf タイプがフィールドを失う問題を修正… by @vio-lin in https://github.com/apache/dubbo-spi-extensions/pull/268

ドクター

  • https://github.com/apache/dubbo-spi-extensions/pull/196 の @raboof によって hessian-rpc がデフォルトで unstafe であることを明示的に呼び出します
  • 自動生成コード ツリー ドキュメント (https://github.com/apache/dubbo-spi-extensions/pull/224 の @songxiaosheng による)
  • :memo: https://github.com/apache/dubbo-spi-extensions/pull/235 の @songxiaosheng によるアップグレード Readme
