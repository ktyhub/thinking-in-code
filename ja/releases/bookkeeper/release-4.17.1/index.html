#簿記リリース-4.17.1

リリース 4.17.1 には、複数のバグ修正といくつかの依存関係の更新が含まれています。

Apache BookKeeper ユーザーは、4.17.x を使用している場合は、4.17.1 にアップグレードすることをお勧めします。 このリリースの技術的な詳細は以下にまとめられています。

ハイライト

バグ

  • TimedRunnable ログ NPE を修正 PR #4425
  • Auditor が Auditor の開始前にブックのシャットダウンを無視する問題を修正 PR #4419
  • OrderedExecutor で失われた prometheus メトリクスを修正 PR #4374
  • 修正: JournalChannel が完全に初期化されていない場合のリソース リーク PR #4340
  • 修正: bookie http エンドポイント情報は常に 0.0.0.0 PR #4325 を返します
  • ディスク ウェイト アンサンブルの無限ループのバグを修正 PR #4324
  • 分散ログのグアバ シェード エラーを修正 PR #4319
  • 正しい Prom メトリクスを確保するために ThreadRegistry#register の動作を修正 PR #4300
  • 修正: PerChannelBookieClient での参照カウント (保持/解放) PR #4293
  • PerChannelBookClient の ByteBuf リリース/保持を修正 PR #4289
  • テスト: prometheus-metrics-provider モジュールのテスト ログのミス PR #4279
  • NativeUtils での一時ディレクトリの作成を修正 PR #4262
  • オプティミスティック ロックによって引き起こされる ArrayIndexOutOfBoundsException を修正 PR #4066
  • ブックキーが readOnlyMode を禁止している場合、休息によるブックキーのシャットダウンを防止 api PR #3972
  • bookkeeper-benchmark のパーセンタイルの誤った実装を修正 PR #3864

改善点

  • WriteEntryProcessor の LedgerFencedException のログ レベルを調整 PR #4327
  • 改善: GarbageCollectorThread のスケジュール AtFixedRate をScheduleWithFixedDelay に変更 PR #4296
  • ByteBufVisitor から未使用のコードを削除 PR #4383
  • vertx BlockingHandlers を使用して、ブロックしている可能性のある Bookkeeper http ハンドラーを実行します PR #4266

依存関係の更新

  • 0.5.0 から 0.7.7 へのバンプ Jetcd PR #3849
  • CVE リストをアドレス指定するために、netty を 4.1.107.Final から 4.1.108.Final にバンプします PR #4426
  • CVE リストにアドレス指定するためにジャクソンを 2.13.4.20221013 から 2.17.1 にバンプ PR #4345
  • CVE-2024-1300 PR #4265 に対処するために、vertx-core を 4.5.7 にアップグレードします。
