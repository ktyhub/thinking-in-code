#iotdbv1.3.2

機能と改善点

  • ストレージ モジュール: 書き込み時の insertRecords インターフェイスのパフォーマンスの向上
  • クエリ モジュール: 新しい Explain Analyze ステートメントが追加されました (単一 SQL 実行の各ステージに費やされた時間を監視)
  • クエリモジュール: 新しい UDAF (ユーザー定義集計関数) フレームワークが追加されました
  • クエリ モジュール: 新しい MaxBy/MinBy 関数が追加され、対応するタイムスタンプとともに最大/最小値の取得をサポートします。
  • クエリ モジュール: 値フィルタリング クエリのパフォーマンスの向上
  • データ同期: パスマッチングはパスパターンをサポートします
  • データ同期: メタデータ同期をサポートします (時系列および関連する属性、権限などを含む)
  • ストリーム処理: Alter Pipe ステートメントを追加し、Pipe タスクのプラグインのホット アップデートをサポートしました。
  • システム モジュール: システム データ ポイント数統計に、TsFile のロードによってインポートされたデータの統計が含まれるようになりました。
  • スクリプトとツール: 新しいローカル アップグレード バックアップ ツールが追加されました (ハード リンクを介して元のデータをバックアップします)。
  • スクリプトとツール: 新しいデータ エクスポート/データ インポート スクリプトが追加され、CSV、TsFile 形式、または SQL ステートメントでのデータ エクスポートをサポートします。
  • スクリプトとツール: Windows 環境では、ConfigNode、DataNode、Cli をウィンドウ名で区別できるようになりました。 ...

バグ

  • データベース削除時のタイムアウトにより NullPointerException (NPE) が発生した場合のエラー メッセージを最適化します。 -notifyLeaderReady、notifyLeaderChanged、およびプロシージャ ワーカーのログを追加します。
  • ファイルのマージ中に既存の誤ったデータに対する互換性処理を追加します。
  • クエリ中に空のファイルをフラッシュすることによって引き起こされるデッドロックの問題を修正します。
  • 読み取り、書き込み、削除の操作中に Ratis が応答しなくなる問題を修正します。
  • ロードおよびマージ操作の同時実行のバグを修正しました。
  • 特定のシナリオでシステムの圧縮率がファイルに負の数値として記録される問題を修正します。
  • マージ タスクのメモリ推定中の ConcurrentModificationException 問題を修正します。
  • データベースの書き込み、自動作成、削除を同時に行うときに発生する可能性がある潜在的なデッドロックを修正します。 ...
