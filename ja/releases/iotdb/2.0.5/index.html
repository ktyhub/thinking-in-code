iotdb v2.0.5

パッチ 公開日2025年8月21日 出典apache/iotdb 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#iotdbv2.0.5

機能と改善点

  • データ クエリ: ツリーからテーブルへのビューの手動作成をサポート
  • データクエリ: テーブルモデルにウィンドウ関数を追加
  • データ クエリ: テーブル モデルに集計関数近似_most_frequent が追加されます。
  • データクエリ: テーブルモデルの JOIN 関数拡張、LEFT & RIGHT JOIN、ASOF LEFT JOIN をサポート
  • データ クエリ: テーブル モデルは行パターン認識をサポートし、分析と計算のための連続データのキャプチャを可能にします。
  • ストレージ管理: テーブル モデルは、VIEWS (テーブル ビュー情報)、MODELS (モデル情報) などの複数のシステム テーブルを追加します。
  • AI 管理: AINode に 2 つの組み込みモデルが追加されました: Timer-XL と Timer-Sundial
  • AI 管理: AINode はツリー モデルとテーブル モデルの推論機能をサポートします
  • ...

バグ

  • 最後のクエリの where time > X および time < X がパーティション テーブルのフェッチに適用されず、PartitionCache にヒットしない問題を修正しました。
  • リージョン全体の単一デバイスに対する時間による順序 + デバイスによる位置合わせによる集計クエリのエラーを修正しました
  • リージョン全体の複数のデバイスに対する時間順 + デバイスごとの整列による集計クエリのエラーを修正しました
  • データ同期バッチ処理は、sink.batch.max-delay-ms をサポートし、よりきめ細かいキャッシュ時間制御を提供します。
  • シンク format=tsfile でのデータ同期中にタブレットに null 値が含まれている場合の潜在的な NPE 問題を修正しました。
  • タイムスタンプが重複したnull値のタブレットを書き込む際のパイププロセッサの処理結果が正しくない問題を修正しました。
  • テーブルモデルのスキーマキャッシュを更新するツリーモデルのロードの問題を修正しました
  • ディスラプターキューのクローズを完了できず、DN 停止スクリプトがスタックする可能性がある問題を修正しました。
  • 通常シナリオ、再起動シナリオ、削除シナリオにおけるデータ同期に関する複数の問題を修正しました
  • テーブルモデルを CSV にエクスポートする際の時刻の書式設定の問題を修正しました
  • ...

新しい貢献者

  • @jtmer が https://github.com/apache/iotdb/pull/15468 に初めて投稿しました
  • @Young-Leo が https://github.com/apache/iotdb/pull/14423 に初めて投稿しました
