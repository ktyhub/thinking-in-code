Vane v1.12.0

マイナー 公開日2025年12月27日 出典ItzCrazyKns/Vane 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

ベーン v1.12.0

何が変わったのか

これは、アーキテクチャの完全な見直しを特徴とするメジャー リリースです。ストリーミング、生成、プロバイダー固有の機能を低レベルで制御するためのカスタム実装を優先して、Langchain を削除しました。このリファクタリングは、今後のリリースの新機能の基礎を築きます。

一般的なアップデート

  • UX を向上させるために、プロバイダーの名前を接続に変更しました。スイッチ設定フィールドを追加し、パーソナライゼーションと設定を分離しました。
  • SearxNG のビルドおよび起動エラーを修正しました。
  • 新しいエージェント DIR、移行された提案、ビデオおよびオーディオ エージェントを追加しました。
  • タイプの安全性を高めるためにメッセージとチャンクのタイプを追加しました。
  • 構文強調表示によるコード ブロック レンダリングを追加しました。
  • 設定にバージョン番号と GitHub リンクを追加しました。
  • Framer Motion によるアニメーションによるさまざまな UI の改善、テーマの不一致の修正、多数の小さいながらも注目に値する詳細の更新。全体的に UI がより反応しやすくなりました。

ラングチェーンの削除とカスタム プロバイダー システム

Langchain を削除し、streamText、streamObject、generateText、generateObject メソッドを使用してカスタムのベース クラスとプロバイダー クラスを実装しました。また、部分ストリーミングを使用した関数呼び出しも実装したため、アプリは XML 解析 (混沌としたものでした) の代わりにそれを使用するようになりました。

Langchain は、ストリーミング方法や生成方法などを低レベルで制御するために削除されました。これにより、構造化された出力などのプロバイダー固有の機能を追加し、生成プロセスを微調整できるようになります。

新しいセッションマネージャー

各セッションに ID があり、30 分間記録される新しいセッション マネージャーが追加されました。ページが更新されたり、ストリームが切断された場合、ID を介してセッションを復元できます。マネージャーには、ストリーミング、再生、複数のリスナーなどをブロックするためのメソッドが含まれています。

ストリームの自動再接続: ページが更新されたり、ストリームが切断された場合に、ストリームに自動的に再接続できるようになりました。アプリは LLM が中断したところから再開し、以前に生成された応答全体をストリームバックするため、完了を待たずにメッセージを続行できるようになります。

ウィジェット

研究と並行して抽出および実行されるウィジェットを追加しました。これらは、天気、株価情報、計算結果などの特定の種類のデータを取得します (さらに多くのウィジェットが近日公開されます)。各ウィジェットは、UX を向上させる特定の UI カードで表されます。

現在利用可能なウィジェット:

  • 気象情報
  • 株式市場データ
  • 数学的計算

アクションを含むクエリ分類と研究者

クエリ分類: 各クエリは調査開始前に分類されるようになり、適切なソースとウィジェット情報の抽出が保証されます。

アクションを含む研究者クラス: 研究者は、推論のための特定のアクションとともに、アクション (ツール呼び出しを使用) を使用します。これにより、研究者はウェブ検索、scraping、特定のウェブサイト検索、ディスカッション検索、ファイルアップロード検索などの多くのアクションを実行できるようになります。これにより、将来のリリースでさらに多くのアクションや Google Workspace (カレンダー、Gmail など) のような統合を追加できる可能性があります。

ディープリサーチモード (ベータ版)

LLM が収集されたデータを繰り返し推論して次のアクションを予測する、品質検索モード (詳細な調査) が追加されました。回答するのに十分な情報があると確信できるまで適切なアクションを実行し、長くて包括的なレポートを作成します。これにより、トピックをより深く調査し、詳細なレポートを作成することができます。

注: 詳細な研究は現在ベータ版です。この機能には、適切なレポートを準備するためのドキュメント、画像、ファイル、グラフなどの作成など、さらに多くの機能が追加されます。

研究モードを更新しました

バランス モード: LLM に推論を強制するようになりました (ただし、制御されたトークンの使用に対するアクションの最大数は制限されています)。

スピード モード: 高速応答のため、理由なく実行されます。

ブロックおよび JSON パッチベースのストリーミング

LLM の各ステップがストリーミングされるため、LLM が何を行っているかを確認できるため、行き詰まりを感じなくなります。これにより、研究プロセスをリアルタイムで可視化できます。

新しいアップロード マネージャーと強化されたファイル検索

ファイルのアップロードと検索を処理するための新しいアップロード マネージャーとアップロード ストアが追加されました。 PDF、DOCX、およびテキスト ファイルをサポートしており、ファイル サイズや数に厳しい制限はありません (合理的な制限内で)。

マネージャーを使用すると、クエリを使用して複数のファイルを検索し、RRF (相互ランク フュージョン) によって再ランク付けおよび選択できるため、検索の品質が大幅に向上します。

再設計されたソース システム

フォーカス モードは削除され、ウェブ、学術、ディスカッションの 3 つのソースに置き換えられます。これらは、発言内容の検索を可能にし、個別に切り替えることができ、3 つすべてを一度に使用したり、外部データ ソースを完全に無効にしてアップロードされたファイルのみを操作したりすることもできます。
