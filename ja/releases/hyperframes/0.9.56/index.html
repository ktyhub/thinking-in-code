ハイパーフレーム v0.9.56

ハイパーフレーム v0.9.56

2026 年 11 月 16 日にリリースされました。

Studio のプレビューとローカル サーバーは、独自のページに対してのみ機能するようになりました。 CLI は、キャッシュ、履歴、復元をプロジェクト内に保持します。 arm64 Lambda イメージにはレビュー済みの ffmpeg ビルドのみが同梱されており、大きなプレビューのビルドはより高速になります。

修正

  • スタジオ サーバー: 構成ファイル サーバーは、認証情報ファイルまたはツール状態ファイル (014326b40、#7889) を提供しなくなりました。
  • Studio サーバー: lint とプローブは、Studio 自身のページ (bbac8900e、#7894) からのリクエストに対してのみ実行されます。
  • スタジオ サーバー: 履歴の復元はプロジェクト内に留まり、無傷のコピー (478313ba0、#7902) のみを使用します。
  • スタジオ: テイク再生は、サーバーが不透明にしたプレビューに対して機能します (1e542956d、#7815)。
  • スタジオ: プレビュー フレームは、サンドボックスの原点をそのホスト セット (b650d0d19、#7886) に保持します。
  • スタジオ: 現在のデッキは独自のサイトでのみ開き、プレビューは独自のフレームのメッセージ (4067efc45、#7877) のみを読み取ります。
  • コア: ランタイム ブリッジは、各制御メッセージを処理する前にチェックします (97d8f26e7、#7892)。
  • CLI: render --docker は、コンテナー内でホストのページ ネットワーク制限を維持します (5d8605eb8、#7890)。
  • CLI: preview --stop は、ポート (ace8a78dc、#7882) を保持しているとシステムが報告するプロセスのみを停止します。
  • CLI: チェック キャッシュはプロジェクト レコードとしてのみ保存され、リンク ファイル (7801e3ff3、#7884) を通じて保存されることはありません。
  • CLI: プロジェクト フォルダーから読み取られた履歴ターン ID がチェックされ、エンコードされて送信されます (6efa6b635、#7883)。
  • CLI: キャッチアップには、ハンドオフ後にアプリが追加されたターンのみがリストされます (0f23f40f8、#7874)。
  • CLI: プロジェクトの下のフォルダーにある受信ファイル レコードは、レンダリングの対象となります (1c159c550、#7900)。
  • CLI: メディア使用は、バンドルされたインデックス名 (ed93a1312、#7895) の効果音のみをコピーします。
  • メディアの使用: ローカル モデルは、プロジェクトの外部のフォルダー (756c2c6c1、#7888) から開始されます。
  • エンジン: キャッシュされたブラウザーは、そのファイルが固定されたビルド (56a2d0c53、#7865) と一致する場合にのみ使用されます。
  • エンジン: タイムライン フレーム予測はレンダリングのフレーム内に留まります (f5a74a567、#7885)。
  • エンジン: 各スーパーセット抽出は、独自のフォルダー (a4139e9ea、#7901) で機能します。
  • パーサー: キャンバス スキャフォールドの幅と高さの読み取りには、どの入力でも同様に短時間かかります (b856a1d63、#7873)。
  • リント: エージェントが作成したシーンとサウンドエフェクトは 1 つのタイムライン レーンに残ります (98208241e、#7775)。
  • スキル: スタンドアロン インストールでは、ランチャーを通じて CLI も実行します (3fc3050bc、#7879)。
  • AWS Lambda: リリースでは、ビルドの横にコミットされたダイジェストと一致する場合にのみ arm64 ffmpeg が出荷されます (d9488119b、#7872)。

パフォーマンス

  • コア: プレビュー ビルドは、パスごとにコピーせずに大きなページを読み取ります (082d63683、#7878)。
  • プロデューサー: コンパイルとレンダリング テレメトリ タグのスキャンには、ページのサイズに応じて時間がかかります (82fdf406c、#7896)。

内部

  • パブリッシュ: すべての npm パブリッシュは、npm-publish の承認 (a54de748e、#7870) を待ちます。
  • 公開: 事前構築された tarball は、リリース コミット (af0560c85、#7869) のコードを実行しないジョブから公開されます。
  • CI: パブリッシュ ワークフローはメイン (7bd6b9daf、#7875) に対してのみ実行されます。
  • CI: テスト フィクスチャは本物の HeyGen キーのようには見えなくなり、CI は本物の HeyGen キーのように見えるもの (5dc3b336a、#7876) を拒否します。
