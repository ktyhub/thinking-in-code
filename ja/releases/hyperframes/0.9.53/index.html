ハイパーフレーム v0.9.53

ハイパーフレーム v0.9.53

2026 年 11 月 15 日にリリースされました。

中国語、日本語、韓国語の文字が多く含まれるページは、いくつかの小さなリクエストでフォントを読み込むようになり、タイムアウトすることなくレンダリングされるようになりました。クラウド レンダーは、未使用のページ名のみを持つファイルを拒否しなくなり、アップロードでは、プロジェクトの外部から運ばれるすべてのファイルがリストされるようになりました。

特徴

  • CLI: アップロードでは、プロジェクトの外部から運ぶすべてのファイルがリストされます (e426ce4eb、#7831)。

修正

  • プロデューサー: ページでシェーダー トランジションを合成できない場合、シェーダー トランジションはノードにブレンドされます (fb1a383bd、#7840)。
  • CLI: アップロード カット テストは、ビジー状態の Windows ランナー (2ea78c0ab、#7843) で失敗しなくなりました。
  • エンジン: 制限されたダウンロードには、キャプチャ プロキシのアドレス ルール (125a9446b、#7839) が適用されます。
  • LAN ホストのプレビューと再生ページは、メタデータを取得せずに他のサイトを拒否します (2ceb682f9、#7836)。
  • CLI: ベンチマークは受信したファイルのルールを維持します。受信した .env キーがログイン (a7266e4c8、#7837) を置き換えることはありません。
  • CLI: クラウド レンダーは、未使用のページ名 (45cc331e5、#7812) のみのファイルを拒否しなくなりました。
  • コア: 多くの CJK 文字を含むページは、複数のリクエストでフォントを取得します (6a8f4b5b4、#7823)。
  • CLI: ハイパーフレーム オーディオは、別のコンピューターの共有 (eaf33bc65、#7826) 上のメディアを検索しません。
  • CLI: アップロードでは外部スクリプトが除外されます。 .ts は 1 つの場合のみビデオとしてカウントされます (04202e8a4、#7818)。
  • CLI: プレビューのようにホストを再生および表示チェックします。ローカル レンダーでは、受信したコンポジションの外部ファイルが除外されます (ac0247410、#7792)。
  • スタジオ メディア ルートはクロスサイト読み込みを拒否し、CLI は端末テキストをエスケープし、バッチ出力はフォルダーに残ります (c4d60c347、#7779)。
  • CLI: テンプレート内でマウントされたシーンを検出します (a75e61f31、#7822)。
  • Studio サーバー: 履歴ロック レコードは置き換えられ、リンク (0248ea033、#7821) を通じて書き込まれることはありません。
  • プロデューサー: トークンで保護されない限り、レンダー サーバーをローカルに保ちます (f667111d1、#7814)。
  • Engine,cli: プレイリスト フォルダー チェックは、ffmpeg と同様に HLS を読み取ります。スナップショットでも実行されます (797a622be、#7810)。
  • エンジン、プロデューサー: レンダーネットワーク設定はスイッチのようになります。 render-service プローブは、チェックされた入力 (be740d021、#7807) に留まります。
  • CLI: 印刷された Windows コマンドは、すべてのシェル (a07d4cf73、#7769) で文字通りフォルダー名を読み取ります。
  • CLI: ネストされた受信レコードは追加のみです。受信した .env がアカウントを選択することはありません。フォント名はエージェント ファイル (80b09cc94、#7808) には含まれません。
  • Cloud Run レンダリングはパブリック アドレスのみに到達します。フレーム キャッシュ フォルダーはユーザーにプライベートです (55b514709、#7777)。
  • Deps: bun.lock の zod、smol-toml、aws-cdk-lib、および関連する解決策を更新します (28d4ba50f、#7741)。
  • Deps: @mcp-b/global を 6.1.0 にバンプして、@modelcontextprotocol/server アドバイザリ (beeb17e85、#7742) をクリアします。
  • エンジン: 失敗した並列キャプチャでは、停止したピアではなく、失敗したワーカーに名前が付けられます (db6b7478a、#7803)。
  • エンジン: レンダリング拒否には、IPv6 マップまたは NAT64 ホストが持つアドレス (04ee926d9、#7802) が指定されます。
  • プロデューサー: ループバック、IP、またはリストされたホスト名 (03e6a1a18、#7798) の下でのみブラウザー要求を受け入れます。
  • パーサー: 別のコンピューターの共有 (2de5c027f、#7797) 上のメディアを検索しないでください。
  • CLI: アーカイブをアップロードすると、常に env ファイルとプライベート レコード (477a3aea1、#7796) が除外されます。
  • エンジン: サイズ、エンコード、およびスループットによるバインドされたリモート メディアのダウンロード (5111cf384、#7786)。
  • CLI: すべてのプラットフォームの trusted PATH フォルダーからのみヘルパー プログラムを起動します (83eae240f、#7787)。

パフォーマンス

  • Lint: リニアタイムで CSS URL 参照をスキャンします (bcf3d177d、#7829)。
  • CSS URL、@import、@font-face、スタイル、コメントのスキャンは線形時間で実行されます (ded5e3eec、#7809)。

カタログ

  • CLI: 受信した設定のレジストリからリスト ファイルを追加します (6a7b4df7c、#7820)。
  • カタログ: ペイロード チェックは、オプションの caption-overrides.json が存在せず、失敗していないと扱います (b7c26ff84、#7813)。
  • レジストリ: キャプション キーワード、絵文字、および余震は、a ～ z (8dbbc1d37、#7804) 以外の単語に対して機能します。
  • ドキュメント: カタログ リンクの値を確認し、コピーされたコマンド (7c7ff6d89、#7783) にそれらの値が含まれないようにします。
