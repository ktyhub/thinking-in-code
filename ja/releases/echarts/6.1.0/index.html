echarts 6.1.0

マイナー 公開日2026年5月19日 出典apache/echarts 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

echarts 6.1.0

  • [機能] [軸] 適切な軸範囲を計算するための dataMin および dataMax オプションをサポートします。 #20838 (ジャスティン-ZS、オヴィリア)
  • [機能] [軸] すべてのタイプの軸 (つまり、"value"/"time"/"category"/"log") を包括的に有効にして、シリーズ (通常は "bar"/"pictorialBar"/"candlestick"/"boxplot") をオーバーフローなしでレンダリングします ("category" 軸と boundaryGap: false の場合を含む)。 containShape オプションを提供します。対応する clip オプションをいくつか提供します。 dbfaf6a73 fe932a2aa 3973b21ee (100pah) #21511 (アカシュ ソヌネ)
  • [機能] [軸] "log" 軸上の非正の系列データ値を自動的に除外します。 dedc5dc18 (100pah)
  • [機能] [軸] axisLabel.formatter が customValues と連携するためのインデックスを受信できるようにします。 #21220 #21432 (シモン・パチュキ、オヴィリア、プレーンハート)
  • [機能] [行] マウスイベントをより詳細に制御するための triggerEvent オプションを追加しました。 #21001 (スティーブン・コブ、プレーンハート)
  • [機能] [パイ] ラベルを反転せずに接線状態に保つための tangential-noflip 回転モードを追加しました。 #21258 (春秋半夏, オヴィリア)
  • [特徴] [ゲージ] progress.colorは'auto'に対応します。 #21224 (シュトニマーライン、オヴィリア)
  • [機能] [レーダー] clockwise オプションを追加します。 #21143 (大雪州、オヴィリア)
  • [機能] [ローソク足] [データズーム] candlestick シリーズに cursor オプションを追加し、'inside' データズームに cursorGrab オプションと cursorGrabbing を追加します。 #21558 (ズミング、オヴィリア、100pah)
  • [Feature] [scatter] [effectScatter] [geo] geo の "scatter"/"effectScatter" で clip オプションを有効にします。 417592289 (100pah)
  • [機能] [visualMap] 複数の系列次元マッピングのための seriesTargets オプションを追加します。 #20703 (ジャスティン-ZS、プレーンハート)
  • [機能] [行列] 配列を構成せずにヘッドレス行列を簡単に作成できる matrix.x/y.length をサポートしました。 #21191 (100pah、プレーンハート)
  • [機能] [行列] 行列セルでのイベントのトリガーをサポートする triggerEvent オプションを追加します。 #21390 (河合奈津夫, 100pah)
  • [機能] [i18n] ラトビア語(LV)翻訳を追加しました。 #21546 (EPoikans)
  • [修正] [軸] 丸め誤差と自動精度ユーティリティとソリューションを変更して明確にします。 479dcd454 (100pah)
  • [固定] [軸] 時間軸 (axis.type: 'time') ラベルに formatter を含む customValues を使用すると、固定チャートが機能しません。 #21352 (スラジャン・サンジェイ・サクセナ、プレーンハート)
  • [修正] [軸] alignTick 戦略を修正して明確にし、LogScale 精度を修正します。 a6ab2458f ffcc636fb (100pah)
  • [修正] [軸] 時間軸 (axis.type: 'time') または customValues を使用すると、splitArea のジッターが発生する重複したティックを修正します。カテゴリ軸の showMin/MaxLabel 処理を修正しました (axis.type: 'category')。数値軸 (axis.type: 'value' | 'time' | 'log') での均一な bandWidth 計算を有効にします。 8de2b64fa 15af0db02 8ddaa5c69 (100pah)
  • [修正] [軸] 値のスケールがミリ秒の場合の時間軸 (axis.type: 'time') のバグを修正しました。 40b77b464 (100pah)
  • [修正] [バー] バーシリーズの幅/高さが 0 の場合に間違ったラベルの位置を修正します。 #21218 (ジャスティン-ZS、オヴィリア)
  • [修正] [散乱] ジッター レイアウトの修正はプログレッシブ レンダリングをサポートしていないため、チャートがフリーズし、NPE が発生する可能性があります。 #21436 (プレーンハート)
  • [Fix] [lines] roundTrip が有効になっていない場合の一方向ループエンドでのエフェクト シンボルの反転を修正しました。 #21320 (マヤンク・メータ、プレーンハート)
  • [修正] [ローソク足] 水平レイアウトでの series.encode によるローソク足のレンダリング エラーを修正しました。 #21325 (プルバヤン・プラマニク, 100pah)
  • [修正] [並列] 後続のシリーズの値が最初のシリーズよりも大きい場合に、間違った軸範囲を修正します。 #21387 (ジャヒクソン, 100pah)
  • [固定] [パイ] パイが直交座標 (grid コンポーネント) にレイアウトされるときに、軸範囲ユニオンのパイの中心が自動的にサポートされます。 18a23a875 (100pah)
  • [修正] [ツリーマップ] scaleLimit が指定されている場合、ツリーマップをズームインした後にズームアウトできない問題を修正 #21427 (TateLiu, 100pah)
  • [修正] [ライン] ラインシリーズ (series.type: 'lines') の潜在的な tooltip XSS 脆弱性を修正します。 #21608 (プレーンハート)
  • [修正] [マップ] [地理] 失敗した同期と地理ローミングとアニメーションの視覚的なアーティファクトを修正します。 417592289 (100pah)
  • [修正] [ツールチップ] ツールチップ トリガーを 'axis' から 'item' に変更すると、tooltip のコンテンツが更新されない問題を修正しました。 #20710 (ジャスティン-ZS、プレーンハート)
  • [修正] [ツールチップ] valueFormatter コールバック パラメーター dataIndex は、フィルターされた dataZoom ではなく rawDataIndex である必要があります。 #21479 (100pah、プレーンハート)
  • [修正] [axisPointer] axisPointer シャドウを修正し、clipping を有効にします。以前は "category" 軸にのみ適用されていましたが、"bar" シリーズの数値軸ではバグがありました。 8de2b64fa (100pah)
  • [修正] [axisPointer] axisPointer 復元の失敗によって引き起こされる視覚的なアーティファクトを修正します。 56a32c0bb (100pah)
  • [Fix] [hoverLayer] ホバーレイヤー上で発生する視覚的なアーティファクトを修正します。 zrender#1151 933585126 (100pah)
  • [修正] [マーカー] marker が dataset および encode でレンダリングできない問題を修正しました。 #21439 (プレーンハート、100pah)。
  • [修正] [データズーム] series にデータ ポイントが 1 つしかない場合、dataZoom の間違った位置を修正します。 #21196 (アレミット、オヴィリア)
  • [修正] [dataZoom] ドラッグを解除するとデータ情報が消えるdataZoomのバグを修正; dataZoom のドラッグ カーソル スタイルを修正しました。 64305a4b8 (100pah)
  • [修正] [データズーム] より優れた自動精度メソッドを適用します。 dataZoom が alignTicks: true で軸を制御するときの予期しない動作を修正しました。 d168bf237 (100pah)
  • [修正] [dataZoom] dataZoom オプションが変更されたときに AxisProxy をクリアできない問題を修正しました。関連する onZero の動作を修正しました。 52ceb924a 2e82d33c3 (100pah)
  • [修正] [エリアスタイル] ディメンション名が空の文字列の場合の areaStyle レンダリング エラーを修正しました。 #21219 (ジャスティン-ZS、オヴィリア)
  • [修正] [サンバースト] ルートノードのラベルが中央に配置されない場合があるのを修正しました。 #21306 (アカシュ・ソヌネ、オヴィリア)
  • [修正] [行列] 行列ラベル フォーマッタが機能しない問題を修正しました。 #21410 (ジャスティン-ZS、オヴィリア)
  • [修正] [ツールボックス] emphasisの色がデフォルトの色と同じになるのを修正します。 #21384 (オヴィリア) b094f987d (100pah)
  • [修正] [ツールボックス] dataViewコンポーネントがダークモードに適合しない問題を修正。 #21176 (この列車ではありません、オヴィリア)
  • [修正] [プログレッシブ] プログレッシブ レンダリングの問題を修正します。 91a60fc76 (100pah)
  • [修正] [labelLine] labelLine.smoothがリセットできない問題を修正。 #21425 (ファンwww、プレーンハート)
  • [修正] [グラフィック] roundRect ヘルパーでパスを閉じないことによるストローク コーナー ギャップを修正しました。 zrender#1155 (プレーンハート)
  • [修正] [svg] SVG encodeBase64 の互換性を強化し、Web Worker/NodeJS/Bun などのより多くの環境で利用できるようにします。 zrender#1145 (プレーンハート)
  • [修正] [コア] echarts インスタンス オブジェクトを Vue 内の raw としてマークします。 #21293 (プレーンハート)
  • [修正] [コード] 不足しているコードチャートのエクスポートエントリを追加します。 #21197 (プレーンハート、オヴィリア)
  • [修正] [i18n] langDE のカスタム シリーズ名の誤った翻訳を修正しました。 #21571 (A-戦利品、プレーンハート)
  • [修正] [typescript]
    • TS、ESM、CJS の互換性を修正および強化しました。 #21411 (アカシュ ソヌネ、100pah)
    • 欠落または不一致の TS エクスポート タイプを修正しました。 #21147 (100pah、オヴィリア)
    • graphシリーズのnodeScaleRatioオプションタイプを修正しました。 #21229 (オクショーン、プレーンハート) ・slider、dataZoomのemphasis.handleLabelはオプションタイプとなります。 #21175 (オヴィリア、プレーンハート)
    • タイプミス Continous → Continuous を修正し、タイプミスのあるタイプを非推奨にします。 #21528 (ホーマ・ウォン、プレーンハート)
  • [雑用] [リファクタリング]
    • 軸スケールの実装をリファクタリングします。 fe932a2aa 18a23a875 (100pah)
    • シリーズデータユニオンの実装を統一します。 fe932a2aa 0f4561dbe (100pah)
    • ローミング実装を統合します。 417592289 (100pah)
  • [Chore] [security] PR テンプレートにセキュリティチェックのヒントを追加します。 #21327 (100pah、プレーンハート)
  • [雑務] unpkg エントリを package.json に追加します。 #21177 (ユエ ジン、プレーンハート)
  • [Chore] SeriesDataのeachメソッドの記述例を修正。 #21294 (ゆるん、プレーンハート)
  • [雑用] test/webkit-dep.htm テスト ケースを修正します。 #21508 (ズミング、オヴィリア)
  • [Break] v6.0.0 に対する重大な変更:
    • tooltip.valueFormatter: tooltip.valueFormatter コールバックの 2 番目のパラメーターは、dataIndex (つまり、series データを dataZoom でフィルターした後のインデックス) から rawDataIndex (つまり、元の入力 series データのインデックス) に変更されます。
    • axis.startValue: axis.min が指定されていない場合、以前は startValue が axis.min としても使用されていました。新しいバージョンではそれらが切り離されており、両方を明示的に設定する (例: startValue: 111, min: 111) ことは、以前の動作と同等です (startValue: 111 と min は指定されていません)。
  • 以前は、"bar"/"pictorialBar"/"candlestick"/"boxplot" シリーズは、エッジ形状でデカルト長方形 (グリッド) をオーバーフローする可能性がありました。新しいバージョンでは、このオーバーフローが解消されました。以前の動作は、axis.containShape: false によって復元できます。
