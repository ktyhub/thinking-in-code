echarts 5.5.0

マイナー 公開日2024年2月18日 出典apache/echarts 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

echarts 5.5.0

  • [Break Change] [Feature] [core] をデフォルトの ESM パッケージに変更します。 #19513 (100pah)
  • [機能] [ssr] サーバーサイド レンダリングと client ハイドレーション。 #18381 (オヴィリア)
  • [機能] [アニメーション] は、普遍的な遷移のためのマルチレベルのドリルダウンをサポートします。 #17611 (tyn1998)
  • [機能] [パイ] padAngle オプションを追加します。 #19076 (リンハオス)
  • [機能] [パイ] 制御パイ範囲に endAngle を追加します。 #18820 (リンハオス)
  • [機能] [極性] で angleAxis.endAngle を設定できます。 #19099 (ヤシラ)
  • [機能] [サンプラー] 最小-最大サンプラー機能を追加します。 #19279 (スヌクーロフ)
  • [機能] [i18n] アラビア語(AR)翻訳を追加します。 #19214 (オスマンアリモード)
  • [機能] [i18n] オランダ語(NL)翻訳を追加します。 #19252 (ティジメナムシング)
  • [機能] [ツールチップ] ツールチップコンテナをカスタマイズできるように appendTo オプションを追加しました。 #18436 (バイキング7982)
  • [機能] [ラベル] は最小/最大ラベルの位置合わせをサポートします。 #19228 (オヴィリア)
  • [機能] [pictorialBar] pictorialBarシリーズのclipに対応しました。 #19197 (オヴィリア)
  • [機能] [ツールチップ] dataIndex から valueFormatter コールバックを追加します。 #19123 (チェプテア・カタリン)
  • [修正] [ツールボックス] ツールボックスのテキストに指定されたフォント スタイルまたはグローバル フォント スタイルを適用できない問題を修正します。 #19170 (プレーンハート)
  • [修正] [ラベル] 通常の状態では表示されないが、他の状態では表示される場合の labelLine のデフォルトのスタイルを修正しました。 #18800 (リンハオス)
  • [修正] [labelLine] emphasis.labelLine が円グラフで動作しない問題を修正しました。 #19180 (シエルサンシ)
  • [固定] [マーカー] 軸がalignWithLabelの場合のmarkAreaの位置を修正します。 #19516 (オヴィリア)
  • [固定] [線] アニメーションが有効な場合、固定線が時間軸を横切る場合があります。 #18960 (プレーンハート)
  • [Fix] [scatter] 修正エッジ散乱は、微小なオフセットにより予期せず clipped になる場合があります。 #18867 (プレーンハート)
  • [修正] [サンバースト] ラベルの回転反転。 #19176 (オヴィリア)
  • [修正] [aria] ハードコードされたシリーズの型名の変換を修正しました。 #19239 (オヴィリア)
  • [フィーチャー] [マトリックス] を使用すると、原点とは異なる点を基準にして回転できます。 #1034 (チェプテア・カタリン)
  • [修正] [グラフ] チャートを破棄した後に強制レイアウト反復タイマーが停止しない問題を修正しました。 #19514 (プレーンハート)
  • [修正] [ツールチップ] ツールチップ要素の親ノードが存在しない場合の潜在的な NPE を修正します。 #19265 (プレーンハート)
  • [Fix] [visualMap] 最初の連続visualMap以外で連続visualMapのマウスオーバーイベントが登録されない問題を修正しました。 #19097 (リンハオス)
  • [修正] [clip] 予期しない clip を防ぐために、clip パス幅に余分なスペースを追加します。 #19056 (RexSkz)
  • [修正] [データセット] 複数型の配列検出の欠陥を修正します。 #19035 (リンハオス)
  • [修正] [コア] 開発環境でグローバル オブジェクトからデフォルトの初期化オプションを読み取るときに潜在的な NPE を修正しました。 #19217 (サン午後)
  • [修正] [i18n] デフォルト言語のフォールバックを強化します。 #19107 (ウルトラバイア)
  • [修正] [svg] CSP が適用されている場合、スタイル属性の割り当てが機能しない問題を修正しました。 ecomfe/zrender#1030 (alxnddr)
  • [修正] [svg] 複数のチャートを持つ背景四角形の重複した ID。 ecomfe/zrender#1002 (オヴィリア)
  • [修正] [ノード] で、nodejs 検出の回復力を高めます。 ecomfe/zrender#1036 (ウズロパック)
  • [修正] [タイプ] 関数 truncateText の ellipsis および options をオプションにします。 ecomfe/zrender#1047 (プレーンハート)
  • [修正] [タイプ] バー シリーズの barMinWidth と barMaxWidth に欠損値タイプ string を追加します。 #19424 (zhaxnb)
  • [機能] [タイプ] EChartsInitOpts および一部の Payload タイプを echarts/core にエクスポートします。 #19103 (ダレングエン)
  • [修正] [タイプ] OptionDataValue に null 許容値を許可します。 #19111 (アビン・カビッシュ)
  • [修正] [型] graphic.clipRectByRect 関数の戻り値の型に undefined を追加します。 #18950 (ベンロンゴ)
  • [修正] [タイプ] GraphNodeItemOption で重複する拡張を削除します。 #18901 (ねのなにぬ)
  • [リファクタリング] [util] zrender から liftColor 関数をインポートします。 #19526 (プレーンハート)
