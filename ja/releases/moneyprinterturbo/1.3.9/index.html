MoneyPrinterTurbo v1.3.9

パッチ 公開日2026年10月21日 出典harry0703/MoneyPrinterTurbo 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#マネープリンターターボ v1.3.9

英語 | 中文

<h2 id="en-v1.3.9">ハイライト</h2>
  • 公式 mpt pip パッケージを追加しました。 mpt webui で WebUI を開始するか、mpt cli でビデオを生成します。
  • ローカル画像と AI 生成画像に 静的および低速ズーム画像効果 を追加しました。遅いズームはデフォルトのままです。
  • サインイン ダイアログ、ステータス更新、およびキャンセルの改善に加えて、ブラウザー認証を使用した Kimi Code サブスクリプション アクセスが追加されました。
  • アイドル状態の GPU オフロードを備えた、OpenAI 互換の画像マテリアル ワークフロー用のオプションの ローカル SDXL 画像サーバー を追加しました。
  • Opper、onomeo、Muse Spark、EmpirioLabs AI LLM プロバイダーを追加し、ブラジル ポルトガル語 WebUI の翻訳を完了しました。
  • WebUI に 診断ログ コントロール を追加しました。これには、ランタイム ログ レベルの変更や、秘匿化とサイズ制限を伴うオプトイン API リクエスト トレースが含まれます。

修正と改善

  • グレースケール画像の明るさ、透明画像の背景、ズームマスクの配置、字幕の背景色を修正しました。短い clips でのトランジション、BGM のフェードアウト、連結パスでの特殊文字の処理が改善されました。
  • 同時実行ジョブ間で中間イメージ ファイルを分離し、イメージ キャッシュ ID を改善し、キャッシュされたダウンロードを検証しました。同じバッチ内の別のビデオが失敗しても、完了したビデオは保持されます。
  • 複数のプロバイダーにわたる音声の速度、音量、およびオーディオ コンテナの処理を修正しました。リモートオーディオ検証が改善され、置換出力の準備ができるまで既存のオーディオが保存されます。
  • 字幕のタイムスタンプの丸め、長い単語の折り返し、Unicode の処理、一時停止タグの認識が改善されました。シンボルのみの行と区切り文字によって、推定される字幕の配置が歪むことがなくなりました。
  • スクリプト全体を使用する中国語と日本語のフォールバック ソーシャル タイトルを修正しました。 JSON の抽出、推論の削除、マークダウンのクリーンアップ、および生成された検索用語の検証が改善されました。
  • マルチピクチャ カメラ JPEG など、サポートされるローカル アップロード形式を拡張しました。 WebUI でのタスク履歴チェック、削除状態、字幕プレビュー、モデル接続エラー メッセージが改善されました。
  • 生成されたアーティファクトに対する HEAD サポートが追加され、バイト範囲のダウンロード、検証エラー、Redis タスクの更新と削除の安全対策が改善されました。
  • 応答喪失またはリダイレクト後の安全でない音声の再送信を削減し、アップロードポスト追跡ハンドルを保持し、WaveSpeed 送信エラー検出を改善しました。
  • 403 エラーに対処するために Edge TTS を更新し、Whisper との互換性のために PyAV を制限し、ロケール ファイルでの Windows キャッシュ クリーンアップと UTF-8 BOM 処理を修正しました。
  • LLM を必要としない、準備されたナレーションとビジュアルを含むワークフローを含む、エージェント ヘルパーの設定処理とプリフライト チェックが改善されました。

完全な Changelog: v1.3.8...v1.3.9

<h2 id="cn-v1.3.9">注目更新</h2>
  • pip インストール担当者 **mpt パケット **、mpt webui インターフェイスの使用、または mpt cli によるビデオの生成をサポートします。
  • 新しい写真の動きの効果を選択 **、独自の写真と AI 生成の写真はどちらも「静止」または「ゆっくり拡大」を選択でき、ゆっくり拡大を維持します。
  • 新しい Kim Code ログインのサポート、視聴者による登録の許可、および登録口の配置、状態の更新、および取消操作が強化されました。
  • 新しいオプション独自のSDXL生成サービス、OpenAI互換インターフェースを介して画像素材を生成し、リアルタイムのGPUストレージをサポートします。
  • Opper、onomeo、Muse Spark、および EmpirioLabs AI 大モデル サービス、完善巴西葡萄牙会話インターフェイスの翻訳が追加されました。
  • 新しい日志設定が追加され、WebUI中の即日志等のレベルがサポートされ、非感度および長さの制限を超えるAPIリクエストパラメータが必要です。

修正与変更

  • 灰色の写真の明るさ、透明な写真の背景、アニメーションと字幕の背景の色の問題を修正し、短い部分の遷移、背景音、および接続経路内の特殊な文字処理を改善しました。
  • 予約された写真の中間ファイルを分離して送信し、写真の保存を改善し、ダウンロード保存をチェックします。大量生成の部分が失われた場合、完了したビデオを保持します。
  • 一部の音声サービスの通話速度、音量、および音声形式の処理を修正し、完全な音声品質チェックを行います。代替音声標準は、既存のファイルを保存する前に完了します。
  • 字幕時間の入力、長時間変換行、Unicode 文字、および停止マークの認識を改善し、厳密なシンボルラインと分割線の字幕時間の計算を回避します。
  • 中国語、日文の社交用の修正は、全体の脚本を使用する際の問題を修正します。JSON の抽出、予備コンテンツの移動、Markdown 文パターンの清算、および素材検索の検証を改善します。
  • サポートされている地上転送形式には、複数の画像のコンピューター JPEG が含まれています。WebUI の履歴ビデオ監視、予約解除ステータス、キャプション ビュー、およびモデル接続のメッセージが改善されています。
  • 生成されたファイルの HEAD リクエスト、完全なダウンロード、パラメータの提示、および Redis の状態更新と削除保護をサポートします。
  • 音声リクエストが失われたり、逆方向になったりした後に繰り返し転送される問題を軽減し、アップロードポストリクエストの追跡情報を保持し、WaveSpeed の転送ロスの認識を改善します。
  • Edge TTS を更新し、関連 403 の問題を修正し、Whisper と互換性を持たせるために PyAV バージョンを制限し、Windows の保存クリーンアップとバンドル UTF-8 BOM の翻訳ファイルの取得を修正しました。
  • エージェント補助の配置処理と起動検査が改善され、画面に音声を配置するタスクが再度大きなモデル サービスを必要としないようになりました。
