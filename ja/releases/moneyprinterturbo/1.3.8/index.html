#マネープリンターターボ v1.3.8

英語 | 中文

<h2 id="en-v1.3.8">ハイライト</h2>
  • ストック フッテージのダウンロード、clip 処理、および最終レンダリング中の継続的な進行状況レポートが追加され、バックグラウンド ヘルパー スレッドからのタスク ログが WebUI に表示されます。
  • 構成可能なストック マテリアルと clip レンダリングの同時実行性が追加されました。ストック素材の同時実行性は Pexels、Pixabay、Coverr に適用されます。どちらの設定もデフォルトは 1 (シリアル処理) です。
  • VoxCPM リファレンス オーディオの音声クローン作成と、編集可能なリファレンス トランスクリプトのローカル ウィスパー トランスクリプションを使用して、ペーシングと感情を引き継ぐためのオプションの配信コンディショニングを追加しました。
  • Fluxion AI、Cheer Inference、Requesty、FutureInfra、Y-API、および iFlytek Spark (Astron MaaS) LLM プロバイダーを追加しました。
  • モデル エンドポイント構成と非同期生成を備えたビデオ素材ソースとして MuAPI を追加しました。
  • カタロニア語 WebUI ローカリゼーションを追加しました。
  • メイン レンダリング パイプラインで BT.709 変換マトリックスとカラー メタデータを使用することにより、ビデオの色の一貫性が向上しました。
  • オプトイン ローカル ビデオ プロジェクト CLI を追加しました。リビジョン追跡、変更比較、およびシーン、ナレーション、または BGM を置き換える際の未変更のレンダリング アーティファクトの再利用が可能です。

修正と改善

  • Redis タスクの更新、キュー アドミッション、および起動時の回復が改善され、フィールドの損失、スケジュールの競合、およびキューの停止が削減されました。キューに入れられた無効なリクエストによって、後で使用可能なタスクがディスパッチされることが妨げられなくなりました。
  • FFmpeg 操作の停止に対する期限を追加し、一時ファイルのクリーンアップを改善しました。エンコードが失敗しても、成功したビデオ出力が不完全なファイルに置き換えられることはなくなりました。
  • ジョブとビデオの組み合わせ全体で連結マニフェストと中間 clips を分離することにより、同時レンダリングが改善されました。
  • キャッシュへのストリーミング リモート ビデオ ダウンロード、ダウンロード制限と検証の追加、キャッシュ ID とクリーンアップの改善により、間違ったアセットの再利用や新しいダウンロードの削除を回避します。
  • サポートされているアップロード形式、画像デコード、カメラの向き、CMYK カラー、ビデオ映像として誤って識別されたアルバム アートワークの拒否など、ローカル マテリアルの処理が改善されました。
  • 字幕テキストに表示されるタイムスタンプ、ウィスパーワード結果の句読点、手動改行が保持されます。無効化された字幕では、古いキャプション ファイルが検出されなくなりました。
  • 字幕タイミングのフォールバックと同時の Whisper 初期化が改善されました。空の字幕結果は、キューなしでキャプション ファイルを公開するのではなく、明示的に失敗するようになりました。
  • 複数のプロバイダーにわたる強化されたナレーション生成: 既存のファイルを置き換える前にオーディオを検証し、エクスポートが失敗した場合でも正常なナレーションを保持し、合成がすでに受け入れられた後に安全でない再試行を停止します。
  • 一時停止セグメントのアセンブリと Azure タイミング変換が改善され、設定された音量を無視するナレーションのみのエクスポートが修正されました。
  • スクリプトとキーワード生成の検証が改善され、プロバイダーのエラー メッセージが生成されたコンテンツとして受け入れられなくなりました。 Groq の廃止されたデフォルト モデルを更新し、標準入力を介してクロード コード プロンプトを渡しました。
  • ローカル マテリアルとカスタム ナレーションの WebUI プリフライト検証を追加しました。設定キャッシュのシリアル化、アクティブなタスクの更新、履歴データの処理、バージョン チェック、失敗したオーディオ アップロードのクリーンアップが改善されました。
  • アップロードされたファイル名、字幕フォント パス、メディア サイズ制限、レンダリング パラメーターが強化されました。 Windows スモーク カバレッジを拡張し、UTF-8 を使用するようにサブプロセス出力のデコードを修正しました。
  • いくつかの認証済みリクエストまたは支払いの可能性があるリクエストのリダイレクトを拒否し、認証情報の公開と偶発的な繰り返し送信を削減しました。
  • アップロード - ポスト結果の検証と回復追跡が改善されました。キューに入れられた公開では選択したアカウントが保持され、メタデータが生成されない場合でも YouTube のプライバシー設定は保持されます。
  • API ダウンロード URL、特殊文字 escaping、メディア タイプ、範囲処理、ブール解析、CORS 原点正規化、および検証エラー応答が改善されました。
  • サポートされている CLI 機能およびマテリアル ソースとよりよく一致するように、プロバイダーのドキュメント、設定例、およびエージェント ヘルパーを更新しました。

使用法とアップグレードに関する注意事項

  • 両方の同時実行設定のデフォルトは 1 です。 ストックマテリアルの同時実行数が高くなると、プロバイダーのレート制限がトリガーされる可能性があります。 clip レンダリングの同時実行性が高くなると、より多くの CPU とメモリが使用されます。環境に応じて増やしてください。
  • VoxCPM リファレンス オーディオと配信トランスクリプトは、合成が要求されると ModelBest に送信されます。使用を許可されている自分の音声または録音のみを使用してください。オプションのローカル Whisper トランスクリプションでは、最初の使用時に構成されたモデルをダウンロードできます。
  • ローカル ビデオ プロジェクトのワークフローは CLI のみで、最初は準備されたローカル映像とナレーションに限定されます。 WebUI ビデオ エディターを追加したり、スクリプト、音声、字幕、トランジションを自動的に生成したりすることはありません。保持されるソースのスナップショットとリビジョンには追加のディスク容量が必要です。
  • カスタム字幕フォントは、プロジェクトの resource/fonts ディレクトリ内で解決される必要があります。そのディレクトリの外側を指す外部パスとシンボリックリンクは拒否されます。
  • 生成リクエストをリダイレクトするプロバイダーまたはゲートウェイでは、最終的な API エンドポイントを直接構成する必要があります。未確認の有料リクエストは自動的に再送信されず、ローカル処理を停止します。これは、最初のリクエストが課金されなかったことを意味するものではありません。
  • 新しいプロバイダーの統合には、対応する API 資格情報とサービス構成が必要です。 iFlytek Spark の従量課金制エンドポイントとトークン プラン エンドポイントは異なる認証情報を使用します。アカウントに一致するエンドポイントを選択します。
  • 既存の WebUI 生成エントリ ポイントは変更されません。新しい同時実行オプション、リファレンス オーディオ コントロール、およびローカル プロジェクト CLI を必要に応じて使用できます。

修正与変更

  • Redis のタスク状態の更新、配列の入力、および起動の変更を変更し、フィールドの損失、調整の競合、および排気の停止を減少させます。実行されなかった排気要求は再び妨害されず、引き続き使用できるようになります。
  • 長時間停止するため、FFmpeg オペレーションの時間が長くなり、ファイルが完全に消去されます。コード化が失われると、正常に生成されたビデオが不完全なファイルで覆われることはありません。
  • コンテンツとさまざまなビデオの組み合わせの中間セグメントを分離して送信し、圧縮中のファイルのクラッシュを軽減します。
  • 素材のダウンロードは、ストリーム形式の書き込み保存に変更され、サイズ制限と効率性の検証が追加され、ファイルの使用と更新の保存が回避されるように、ファイルの消去が行われます。
  • アップトランスポート形式、写真の方向、CMYK カラーを含む完全なローカル素材処理。オーディオ ファイルの表紙の写真はビデオ素材として識別されません。
  • 修正された字幕の正文、ささやきの結果のポイント、および手動の切り替えは、ブロックされた処理の対象になります。
  • キャプションの時間軸を変更して、Whisper の初期化を開始します。空キャプの結果は重大な問題を引き起こす可能性があり、キャプション内容のないファイルの生成を回避します。
  • 完全な複数の音声サービスの音声チェックとファイルの置換: 失われると、すでにある音声が保持され、合成要求が処理された後、安全でない再試行が停止されます。
  • 分割音声の完全性検査と Azure 時間の切り替えを変更し、音声の出力時に発生する問題を修正します。
  • 完全な文言とセキュリティチェック。サービスのセキュリティメッセージが生成コンテンツとして使用されることを回避します。Groq が使用していたセキュリティモデルを更新し、stdin 経由で転送されるようにクロードコードを提案します。
  • WebUI は、タスクを引き継ぐ前に、本素材と独自のサウンドをチェックし、設定の順序付け、実行中のタスクの刷新、履歴データの処理、バージョンの検出、およびオーディオ上での転送のクリアを改善します。
  • 上流ファイル名、字幕文字路、メディアサイズ、および圧縮パラメータのチェックを強化し、Windows の検査を拡張し、UTF-8 を使用して子プロセス出力を解読します。
  • 複数の伝送データまたは必要に応じて要求される自動送信を禁止し、データの漏洩と重複伝送を低減します。
  • アップロード後の公開結果の判断とリクエストの追跡を改善します。選択したアカウントはキューに入れられたタスクに対して保持され、生成されたメタデータが欠落している場合でも YouTube のプライバシー設定は保持されます。
  • API ダウンロード リンク、特殊文字エンコーディング、メディア タイプ、範囲リクエスト、ブール解析、CORS 原点正規化、パラメーター エラー応答を改善しました。
  • サポートされている CLI 機能およびソース資料と一致するように、プロバイダーのドキュメント、サンプル構成、およびエージェント補助スクリプトを更新しました。

使用法とアップグレードの手順

  • **両方の同時実行数のデフォルトは 1 です。 ** インベントリ マテリアルの同時実行数を増やすと、プラットフォームの電流制限がトリガーされる可能性があり、フラグメント レンダリングの同時実行数を増やすと、より多くの CPU とメモリを占有します。実際の環境に合わせて調整してください。
  • VoxCPM を使用して合成する場合、リファレンス オーディオとレンディションがそのまま ModelBest に送信されます。自分の声または許可された録音のみを使用してください。初めてローカルのウィスパー認識を使用するときに、構成済みのモデルをダウンロードする必要がある場合があります。
  • ローカル ビデオ プロジェクトは現在 CLI 機能であり、最初は準備されたローカル素材とダビングをサポートします。これは WebUI ビデオ エディターではなく、コピーライティング、吹き替え、字幕、トランジションを自動的に生成しません。フッテージのスナップショットと履歴リビジョンを保存すると、追加のディスク容量が必要になります。
  • カスタム字幕フォントは、プロジェクト resource/fonts ディレクトリ内に配置する必要があります。ディレクトリの外のパスとディレクトリの外を指すシンボリック リンクは拒否されます。
  • サービス プロバイダーまたはゲートウェイが生成されたリクエストをリダイレクトする場合は、最終的な ZZPH100​​ZZ アドレスを直接構成する必要があります。支払いリクエストの結果が不明瞭な場合、プログラムはローカル処理を停止し、自動的に再送信しません。これは、最初のリクエストに料金がかからないという意味ではありません。
  • 新しいサービスでは、対応する API 資格情報を構成する必要があります。 iFlytek MaaS の従量課金制とトークン プランでは異なるアドレスとキーが使用されるため、アカウントの種類に応じて設定してください。
  • 既存の WebUI ビデオ生成の入口は変更されません。新しい同時実行機能、リファレンス オーディオ機能、およびローカル プロジェクト機能をオンデマンドで使用できます。
