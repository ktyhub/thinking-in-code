MoneyPrinterTurbo v1.3.6

パッチ 公開日2026年9月2日 出典harry0703/MoneyPrinterTurbo 英語原文

#マネープリンターターボ v1.3.6

英語 | 中文

<h2 id="en-v1.3.6">ハイライト</h2>
  • スクリプト セグメントから直接ソース clips を生成するネイティブ Volcano Engine Ark Seedance ビデオ生成を追加しました。
  • OFox マルチモデルのテキストからビデオへのサポートが追加され、Seedance、Wan、およびその他のモデルが 1 つの API キーを共有できるようになりました。
  • 768P/2K 出力、4 ～ 15 秒の clips、および 9:16、16:9、および 1:1 のアスペクト比を備えた Metaso MiniMax H3 テキストからビデオへのサポートを追加しました。
  • クラウドリレーおよびローカルゲートウェイ用の OpenAI 互換のテキストから画像への素材ソースを追加しました。
  • OpenAI互換LLMプロバイダとしてOpenRouterとAPIMartを追加しました。
  • より明確な API キーとアカウント設定ガイダンスを備えた、アップロード - 投稿用の WebUI 自動公開設定タブを追加しました。
  • CLI バッチ マニフェスト モードを追加し、コマンド ライン値が省略された場合に保存された WebUI 設定を CLI のデフォルトとして適用しました。
  • 構成可能なソース clip フィット モードを追加: cover は余分なエッジをトリミングしてフレームを埋めますが、contain はレターボックスで完全なソースを保持します。
  • フランス語と韓国語の WebUI の完全な翻訳を追加しました。
  • 素材ソース設定を再編成し、ビデオ ソースを機能ごとにグループ化し、WebUI 設定で AI ビデオ プロバイダーの資格情報を一元化しました。

セキュリティ

  • デフォルトで、ブラウザーのクロスオリジン API による同一オリジンリクエストへのアクセスが制限されました。 Trust のスタンドアロン ブラウザ フロントエンドは、CORS_ALLOWED_ORIGINS を使用して明示的に有効にすることができます。
  • 公開されたコンテナー イメージに来歴と SBOM 証明書を追加しました。

修正と改善

  • 字幕キューのみに依存するのではなく、生成された音声ファイルからナレーション時間を測定しました。
  • SiliconFlow 字幕タイムラインを完全な音声継続時間に固定しました。
  • AudioFileClip リソースが Celebrities、Chatterbox、Fish Audio パスで閉じられていることを確認しました。
  • スクリプトのクリーンアップで、関係のない角かっこで囲まれたテキストが貪欲に削除されるのを防ぎました。
  • 最後の LLM 試行後の誤解を招く再試行警告を削除しました。
  • パスワードが設定されていない場合の Redis URL を修正しました。
  • プロジェクトのルートとログの宛先が異なるマウント上にある場合でも、ログ レコードが保存されます。
  • Windows 上で CLI 生成が成功した後の Unicode コンソール出力を修正しました。
  • RFC 互換の引用符や Windows 予約名からの保護を含む、安全でポータブルなダウンロード ファイル名を追加しました。
  • ブラウザーの再生とダウンロードにフォールバックすることで、ヘッドレス サーバーでの WebUI プレビュー動作が改善されました。
  • アップロードと投稿の構成を自動公開から切り離したため、アップロードを有効にしなくても設定を保存できます。
  • 強化された OpenAI 互換の画像処理: 不正な 200 応答は、影響を受けるキーワードのみをスキップするようになりましたが、ローカル ストレージの障害により、それ以降の有料リクエストは停止されます。

アップグレードに関する注意事項

  • ブラウザ API アクセスは、デフォルトで同一生成元のリクエストになるようになりました。スタンドアロン Web フロントエンドは、CORS_ALLOWED_ORIGINS を通じて trusted のオリジンを宣言する必要があります。 curl、Postman、n8n などのサーバー側の client は影響を受けません。
  • CLI コマンドは、省略されたオプションについて保存された WebUI 設定を継承するようになりました。明示的な CLI 引数とバッチ マニフェスト値は引き続き優先されます。

<h2 id="cn-v1.3.6">注目更新</h2>
  • 新しい火山誘導方舟 Seedance 生動画生成サービスは、脚本のセグメントに基づいて直接動画素材を生成できます。
  • 新しい OFox 多モデル文生成ビデオ サービス、API キー、つまり Seedance、Wan などのモデルを使用できます。
  • 新しい秘塔 MiniMax H3 文生ビデオ サービスは、768P/2K、4 ～ 15 秒のセグメント、および 9:16、16:9、1:1 の 3 つの画幅をサポートします。
  • クラウド ターミナルおよびローカル ネットワークでの OpenAI 互換の画像素材ソースが新たに追加されました。
  • 新しい OpenRouter と APIMart OpenAI 互換大言説モデル サービス。
  • WebUI は、アップロード - ポスト自動配信設定を新たに強化し、API キーと名前の申請、設定ガイドを完了しました。
  • CLI 新しい大量クリア モード。コマンド行パラメータが渡されていない場合、WebUI が保持している設定を継承できます。
  • 新素材画面調整モード：cover カット剪定により素材を詰め込み、contain は完全な素材を保持し、比率を変えて追加します。
  • 新しい完全な法文およびWebUIの翻訳。
  • 素材ソース設定を再整理し、ビデオ ソース コンポーネントを管理し、AI ビデオ サービス データベースを WebUI 設定に集中管理します。

安全性

  • コンバーターのフィールド API は、承認時にソース ポリシーに従っています。独立したネットワーク フロントエンドを使用する必要がある場合は、CORS_ALLOWED_ORIGINS 経由で構成可能な情報源を使用できます。
  • 公開されたコンテナイメージは、ソースの説明と SBOM の材料の洗浄の説明を新しく構成しました。

修正与変更

  • キャプション時間軸のみに依存せず、実際に生成された音声ファイルからの録音時間を測定するように変更されました。
  • SiliconFlow のキャプション時間軸の末尾を完全な音声時間と比較します。
  • イレブンラボ、チャターボックス、フィッシュオーディオの回線開始停止 AudioFileClip ソースを保護します。
  • 脚本のテキストを修正すると、多くのブロック番号の内容が削除される可能性があります。
  • 最後の再試行が終了した後、大言説モデルの「再試行中」の日印を削除します。
  • Redis が未構成の場合に暗号化セグメントが生成される問題を修正しました。
  • 修正されたリストのリストと日のリストが異なるダウンロード ポイントに配置されている場合、リストのリストが失われるという問題があります。
  • Windows 端末を修正すると Unicode が暗号化されないため、CLI がビデオの生成に成功した後に頻繁に終了する問題が発生します。
  • 標準参照コードと Windows の保存名保護を含む、ダウンロード ファイル名の安全性とプラットフォーム全体の互換性が変更されました。
  • 画面のないサーバー環境では、WebUI はプレーヤーのブロードキャストやビデオのダウンロードに戻ります。
  • Upload-Post 構成は自動配信と関連付けられており、ユーザーは構成を保存できますが、即時に転送されることはありません。
  • OpenAI 対応文生図常処理の追加: HTTP 200 が図片を返すときのみ、現在のアクセス許可をスキップし、失われているときは停止後の継続的な支払い要求を保存します。

升级说明

独立したネットワーク フロント エンドは、CORS_ALLOWED_ORIGINS を介して通信可能なソースを構成する必要があります。curl、Postman、n8n などのサービス エンド エンドは影響を受けません。

  • CLI がパラメーターを明示的に渡さない場合、WebUI によって保存された設定が継承されます。 CLI パラメータおよびバッチ リスト フィールドで明示的に渡されたものの優先順位は依然として高くなります。
