MoneyPrinterTurbo v1.3.1

パッチ 公開日2026年7月6日 出典harry0703/MoneyPrinterTurbo 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#マネープリンターターボ v1.3.1

ハイライト

  • AIML API、EvoLink、VolcEngine Ark などの新しい LLM プロバイダーと統合を追加しました。
  • イレブンラボやセルフホスト型の OpenAI 互換 Chatterbox TTS など、新しい TTS オプションを追加しました。
  • よりスマートなマテリアルの理解と再ランキングのために、オプションの TwelveLabs ビデオ AI 統合を追加しました。
  • アップロード投稿による YouTube ショート公開サポートを追加しました。
  • 純粋な CLI ワークフローを追加し、より多くの WebUI ベースのビデオ パラメーターをコマンド ライン生成に公開しました。
  • コンテナーのデプロイメントを容易にするために、GHCR Docker イメージの公開を追加しました。
  • インドネシア語とスペイン語の更新を含む多言語 WebUI サポートの改善と、明示的な es-ES スクリプト生成のサポート。

修正と改善

  • 字幕の背景 clipping を修正し、字幕レンダリングの信頼性を向上しました。
  • Whisper使用時のカスタムオーディオ字幕生成を修正しました。
  • Windows Defenderの干渉を避けるために、Windows MoviePyの一時オーディオ処理を修正しました。
  • WebUI の起動をブロックする Streamlit の初回実行プロンプトを修正しました。
  • LLM プロバイダー選択ボックスの切り替えを 2 回選択する必要がある問題を修正しました。
  • ビデオ持続時間の安全マージンの処理を修正しました。
  • video_concat_mode を正しく使用することで、video_contact_mode のタイプミスの互換性を修正しました。
  • Pollinations のデフォルト API エンドポイントを修正しました。
  • フェンスで囲まれたまたは複数行の LLM 応答に対する堅牢な JSON 解析が改善されました。
  • API という用語で match_materials_to_script を公開しました。
  • マテリアルのマッチングが改善され、スクリプトの順序によりよく従うようになりました。
  • ローカル ビデオ素材ワークフローの CLI 引数検証を強化しました。
  • 機密情報の漏洩を避けるために、LLM エラー出力を編集しました。
  • スポンサーの謝辞とプロバイダーのコピーを更新しました。

何が変わったのか

  • https://github.com/harry0703/MoneyPrinterTurbo/pull/1005 の @copilot-swe-agent によるヘッドレス ビデオ生成のための純粋な CLI ワークフローを追加
  • video_contact_mode のタイプミスを修正し、https://github.com/harry0703/MoneyPrinterTurbo/pull/1021 で @reyys による video_concat_mode を使用
  • https://github.com/harry0703/MoneyPrinterTurbo/pull/1022 に @D1m7asis による AIML API プロバイダーを追加
  • https://github.com/harry0703/MoneyPrinterTurbo/pull/1025 の @muhamadmaliqia による Pollinations のデフォルト エンドポイントを修正
  • https://github.com/harry0703/MoneyPrinterTurbo/pull/1026 の @xlab-nyc によるフェンスで囲まれた/複数行の LLM 応答からの堅牢な JSON 解析を修正しました。
  • Windows での MoviePy 一時オーディオ処理を修正 (https://github.com/harry0703/MoneyPrinterTurbo/pull/1029 の @mertfurkandgn により)
  • https://github.com/harry0703/MoneyPrinterTurbo/pull/1030 の @BinaryOutlook による Streamlit の初回実行プロンプトが WebUI の起動をブロックしないようにしました
  • https://github.com/harry0703/MoneyPrinterTurbo/pull/1031 の @BinaryOutlook による CI と対象を絞った品質修正を追加
  • https://github.com/harry0703/MoneyPrinterTurbo/pull/1033 の @kapil971390 により、CLI の --video-source local 制約を検証します
  • https://github.com/harry0703/MoneyPrinterTurbo/pull/1035 の @BinaryOutlook による GUI ベースのカスタマイズ オプションを CLI に移植
  • @lsopenad によるスペイン語 (スペイン) WebUI 翻訳を https://github.com/harry0703/MoneyPrinterTurbo/pull/1037 に追加
  • https://github.com/harry0703/MoneyPrinterTurbo/pull/1046 の @lsopenad によるアップロード投稿 API を通じて YouTube ショートのサポートを追加します
  • https://github.com/harry0703/MoneyPrinterTurbo/pull/1065 の @kapil971390 により、/terms エンドポイントで match_materials_to_script を公開します
  • @mteguhfh によるインドネシア語 WebUI 翻訳を https://github.com/harry0703/MoneyPrinterTurbo/pull/1066 に追加
  • @nhatanh2996 による Celebrities TTS サポートを https://github.com/harry0703/MoneyPrinterTurbo/pull/1071 に追加
  • @pcbntt による Chatterbox TTS プロバイダーを https://github.com/harry0703/MoneyPrinterTurbo/pull/1077 に追加
  • @kapil971390 による https://github.com/harry0703/MoneyPrinterTurbo/pull/1078 の YouTube ショート メタデータのアップロードを修正
  • https://github.com/harry0703/MoneyPrinterTurbo/pull/1084 の @mohit-twelvelabs によるオプションの TwelveLabs ビデオ AI 統合を追加
