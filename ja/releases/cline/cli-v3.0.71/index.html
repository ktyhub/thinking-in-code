cline cli-v3.0.71

#cline cli-v3.0.71

  • プラグインは別個のノードやバン プロセスではなくハブ内にロードされるようになったため、CLI はプラグインを実行するために PATH 上に JavaScript ランタイムを必要としなくなりました。ロードに失敗したプラグインが自動的にツールを失うことはなくなりました。Cline はプラグインとエラーの名前を示す警告を出力し、cline config tools --json はプラグインを plugin_failure エントリとしてリストし、新しい cline hub plugins は各プラグインのステータスと最後のエラーを表示します (--reload <plugin> はハブを再起動せずにプラグインを再インポートします)。古いサブプロセスの動作を維持するには、CLINE_PLUGIN_MODE=sandbox を設定します。
  • --thinking が ACP モード (--acp) に適用されるようになりました。以前は、ACP セッションは常に推論をオフにして実行されていました
  • cline hook は agent_error イベントを受け入れます。以前は、エラーと応答なしで終了しました
  • 環境内に設定されたプロバイダー API キー (OPENROUTER_API_KEY など) は、単一の環境変数を読み取るプロバイダーの場合、起動時に構成されたものとしてカウントされるようになりました。以前は、TUI はとにかくプロバイダーをセットアップするように求めていました
  • モデルが選択されていないため、Cline プロバイダーは Cline の推奨リストの最初のモデル (Claude Sonnet 5.5) を使用するようになりました。
  • 推論をオフにすると、すべてのプロバイダーで機能するようになりました。オフにできないモデルはデフォルトを維持し、レベルのみの Gemini モデルは思考バジェット エラーでリクエストを拒否しなくなりました。
  • スクリーンショットやその他の画像によってトークンの見積もりが膨らまなくなり、会話が限界に近づくずっと前に自動圧縮が実行されるようになりました。
  • 自動圧縮では、カタログ エントリに何もない場合、選択したモデルのコンテキスト ウィンドウが使用されます。
  • スケジュールされた実行: キューに入れられた実行が永久に保留されるのではなく開始されるようになりました。モデル呼び出しが失敗した実行 (廃止されたモデルなど) はエラーで失敗としてマークされ、ダウンタイム後にはスケジュールが連続して実行されるのではなく、最後に失敗したスケジュールのみが実行されます。
  • シンボリックリンクであるルール ファイルが読み込まれるようになりました
  • .claude/skillsのスキルが発見されました
  • エディター ツールは、一部のモデルから置換するテキストの代わりに null を受け取らなくなりました。
  • モデルカタログを更新しました。 AI/ML API、LowRouter、および Prime Inference プロバイダーを追加します。 v0 プロバイダーは現在、デフォルト モデル v0-1.5-md のみを提供しており、OpenCode Go は新しい https://opencode.ai/inference/go/v1 エンドポイントを使用します。 Cline の空きリストには、ステップ 5 のプレビューが追加されます。 302.AI、CrossModel、Cortecs、DigitalOcean、NEAR AI Cloud、Ofox (Claude Haiku 5.5)、DevPass (LLM Gateway)、LLM Gateway、Meta (Muse Wonder 1.0)、Aixy (GPT-6.1 Sol)、CloudFerro Sherlock および Moark (GLM 5.3) のデフォルト モデルが変更されます。アンビエント、NanoGPT、Neuralwatt、Novita AI フル Changelog: https://github.com/cline/cline/compare/cli-v3.0.70...cli-v3.0.71
