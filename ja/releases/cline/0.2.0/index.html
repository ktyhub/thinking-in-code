cline v0.2.0

マイナー 公開日2026年10月26日 出典cline/cline 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#cline sdk/sdk/v0.2.0

  • すでに実行中の実行があるセッションを開始すると、ランタイムを置き換えるのではなく、ライブ セッションに再接続されるようになりました。以前は、元の実行は継続していましたが、到達できず、そのトランスクリプトの書き込みは古いスナップショットに到達していました。実行の進行中にプロンプトを含む開始は拒否される
  • ハブは、すでに実行中のタスクに参加する client を含む、セッションの機能を登録したすべての client を記録し、まだ接続されている最初のタスクに各要求を送信します。何も残っていない場合、リクエストはすぐに失敗し、永久に待つのではなく、ユーザーがアクションを実行できるメッセージが表示されます。
  • モデルが推論のみをストリーミングした後に接続が切断されたターンは再試行されるようになり、部分的な推論は破棄されます。テキスト、メディア、ツール呼び出しによるターンはまだ再試行されません
  • モデルは、最初の試行後の再試行を最大 3 回要求します (5 回から減少)。失敗した試行は Langfuse トレースに記録され、キャンセルされたリクエストは Langfuse エラーとして報告されなくなりました。
  • AI SDK が ai 7.0.136 / @ai-sdk/provider-utils 5.0.58 に更新されました。 max 推論がプロバイダーに到達するようになりました。ゲートウェイはそれを xhigh に変換しなくなり、Kimi K3 は Extra High および Max の max を取得します。新しい anthropic.* カスタム ストリーム パーツにもかかわらず、空の Anthropic ターンがまだ再試行されます。
  • gemini プロバイダーはネイティブ Google 検索を送信しなくなりました。 Gemini 3+ では、フリー層キーが毎ターン 429 クォータ エラーで失敗し、Gemini 2.x ではすべての Cline ツールがドロップされました。 Vertex はネイティブ検索を維持します
  • モデルの入力制限が不明な場合、自動圧縮は実行されなくなりました。手動圧縮とオーバーフロー回復圧縮は引き続き機能します
  • 最初の圧縮後、サイズ推定では実際に送信されたメッセージが使用され、ツールの結果は切り捨てられます。以前は約 7 倍過大評価されており、数回のツール呼び出しごとに圧縮が再度実行されていました。
  • チェックポイントの差分は、ファイルごとに最大 2 つの git show プロセスではなく、単一の git cat-file --batch プロセスでファイルの内容を読み取ります。多数の追跡されていないファイルを含むワークスペースが数千の git プロセスの生成に使用されていた
  • SSH リモートは ProxyJump エイリアスの背後で動作します。接続バジェットは 10 秒から 30 秒に、コマンドごとの制限は 60 秒に、トンネルの準備完了は 40 秒に増加します。 SSH がアップロード中に終了すると、EPIPE ではなく実際のエラーが報告され、エイリアスの LocalForward がトンネルと衝突しなくなります。
  • ask_question の回答はフレーム化されているため、モデルは必要最小限の選択の後も続行されます。空の回答は拒否され、添付ファイルのみの回答は回答済みとしてカウントされます。
  • run_commands はツール エラーで空の commands リストを拒否し、そのスキーマは minItems: 1 をアドバタイズするようになりました。
  • PowerShell では、run_commands の説明でバッククォート escaping、一重引用符で囲むリテラル パス、cmd /c よりもコマンドレットを優先すること、最初に再帰的削除を確認することが説明されています。
  • プラグイン コマンドは、アクティブなセッション ランタイムとハブで実行されます。検出ディレクトリが表示されると、プラグイン監視が再び動作を開始します
  • コンパイルされたバイナリは、埋め込みプラグインとダッシュボード リソースをバイナリから直接読み込み、宣言されたすべての SDK ランタイム エクスポートがパッケージ化されます。
  • 構成された CLINE_PLUGIN_RUNTIME_DIR は絶対パスに解決されます
  • OpenRouter に Cline 推奨モデルと一致しない場合、その機能は Vercel カタログから入力されます。
  • デスクトップ クラウド セッション オーケストレーションがハブに移動されました。 session.list は activeCloudCommands を報告し、クラウド コマンドがまだ実行されている間はハブは交換されません
  • コアは会話の要約とクラウド継続サポートを追加します
  • ストールテレメトリの実行: agent.run-finished および agent.run-failed は、新しい RunHealthObserver からのストール信号を伝送します。
  • @cline/ui は、共有バージョンの SDK パッケージとともに出荷されるようになりました。 Kbd コンポーネントと、AgentComposer でのスラッシュ コマンドとファイルの言及用のトークン チップを追加します。 ・モデルカタログを更新（7,041→6,457モデル）。 Liquid Inference、Munito AI、Munito AI (EU) プロバイダーを追加し、CrofAI、iFlow、Llama を削除します。 Cline のフリーリストには、Reflection Beam、Nemotron 3.5 Lightning、Laguna S 2.1 が追加され、Mimo V2.6 Flash と Muse Spark 1.3 Contributor が削除されます。 ClinePass は、Kimi K3.1 Pro (現在はデフォルト)、MiniMax M3.1 Flash、DeepSeek V4.1 Flash 1017 を追加し、Mimo V2.5 と V2.5 Pro を削除します。他の 56 のプロバイダーのデフォルト モデルが変更され、主に Kim K3.1 Pro、MiniMax M3.1 Flash、または DeepSeek V4.1 Flash 1017 に変更されます。 フル Changelog: https://github.com/cline/cline/compare/sdk/sdk/v0.0.95...sdk/sdk/v0.2.0
