cline v0.0.91

パッチ 公開日2026年10月7日 出典cline/cline 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#cline sdk/sdk/v0.0.91

  • 終了理由が見つからない、または認識されないまま終了した応答は、正常に完了したものとして扱われなくなりました。 AgentModelFinishReason は unknown を取得します (AI SDK アダプターは、統合された other と欠落している理由を stop の代わりにマップします)。ツールのアクティビティがなければ、エージェントは部分的な応答を保持し、非表示のユーザー メッセージを 1 回続けます。 2 番目の未知のフィニッシュはランに失敗します。キューに入れられたユーザー メッセージは、最初の反復を含むすべてのリクエスト境界で消費されるようになりました。
  • Stdio MCP サーバーは、デフォルトで 10 秒の初期化バジェットを取得します (以前は 3 秒でした)。 Windows 上の cmd.exe を介した npx/uvx ランチャーは、通常 3 ～ 6 秒かかり、警告なしにセッションから削除されました。明示的な timeout は依然としてこれをオーバーライドします。
  • Anthropic プロバイダーは、サーバー側の拒否 fallbacks オプションを api.anthropic.com にのみ送信します。 Azure AI Foundry などのカスタム エンドポイントは 400 で拒否しました。新しい isOfficialAnthropicEndpoint ヘルパー
  • cline および openai-compatible アダプターのポータブル推論レベルは、モデルで宣伝されている努力レベルにスナップします。 Kimi K3 (低/高/最大) medium および minimal が送信されましたが、拒否されました
  • OpenAI 互換プロバイダー (汎用、vercel-ai-gateway、ユーザー定義 ID) は、キャメルケース エイリアスの下でのみ providerOptions を書き込みます。これにより、@ai-sdk/openai-compatible からのチャンクごとの providerOptions key 'openai-compatible' 非推奨警告が停止されます。
  • 新しい apiKeyOptional プロバイダー ファクト (GatewayProviderMetadata.apiKeyOptional、resolveProviderApiKeyOptional、ProviderListItem.auth.apiKeyOptional)。openai 互換、ollama、lmstudio、litellm、vertex、bedrock、および providers.json/models.json のユーザー追加エンドポイントで宣言されました。
  • ルール: 新しい listEnabledRulesFromRecords / loadRulesForSystemPromptFromRecords エクスポート。結合されたユーザー指示サービスは、単一ワークスペースのパスに一致する名前でルールを順序付けするようになりました。
  • BYOK プロバイダー (CLINE_LANGFUSE_ALL_PROVIDERS) のオプトイン Langfuse トレース、および CLINE_LANGFUSE_TAGS、CLINE_LANGFUSE_METADATA、LANGFUSE_TRACING_ENVIRONMENT を介したオペレーター タグ、メタデータ、環境
  • フック検出テレメトリは Windows パス区切り文字を処理します
  • モデルカタログを更新しました。 Cline の無料リストに Solar Mini 4 が追加され、DeepSeek V4.1 Flash と space-bunny-alpha が削除されました。 Engy プロバイダーを追加します。 AKI.IO、Blue Claw、CoralBricks、CrossModel (GPT-6.1 Sol)、DevPass、LLM Gateway、Mistral、NanoGPT、Requesty (Mistral Large 4)、Neon (Claude Opus 5.5)、Subcious、および The Grid AI のデフォルト モデルが変更されました。 フル Changelog: https://github.com/cline/cline/compare/sdk/sdk/v0.0.90...sdk/sdk/v0.0.91
