desktop-v0.0.49 リリース MT

cli-v3.0.74 リリース MT

Opening a task that's already running in another Cline app now attaches to that run instead of starting a second one that couldn't be stopped.

クラウド タスク: [設定] > [API 構成] にローカル |クラウドセッションがオンのときにクラウドを切り替えます。クラウドは、新しいクラウド タスクが実行される Cline モデルを選択し、ローカル モデルとは別に保存されます。

desktop-v0.0.48 リリース MT

GPT-6 モデル (gpt-6-sol や gpt-6.1-sol など) は、OpenAI および Azure OpenAI 互換エンドポイントで動作します。以前は、Cline が max_completion_tokens ではなく max_tokens を送信したため、すべてのリクエストが拒否されました。

cli-v3.0.73 リリース MT

GPT-6 モデル (gpt-6-sol や gpt-6.1-sol など) は、OpenAI および Azure OpenAI 互換エンドポイントで動作します。以前は、Cline が max_completion_tokens ではなく max_tokens を送信したため、すべてのリクエストが拒否されました。

 10/17
v0.0.95 パッチ MT

OpenAI-compatible requests for GPT-6 models (gpt-6-sol, gpt-6.1-sol, gpt-6-1-sol, and later gpt-5 through gpt-9 ids) send max_completion_tokens instead of max_tokens, so OpenAI and Azure no longer reject them.

 10/16
desktop-v0.0.47 リリース MT

ゴールなどのマーケットプレイスプラグインが再度ロードされます。 0.0.46 では、パッケージ化されたアプリに SDK パッケージ プラグインのインポートが含まれていなかったため、モジュール '@cline/sdk' が見つかりませんで失敗しました。

 10/16
cli-v3.0.72 リリース MT

Plugins now run in a worker instead of directly inside the hub. If this build can't run plugins, Cline says so in cline config tools, cline hub plugins, and the session-start warnings instead of quietly running them…

 10/16
v4.1.25 パッチ MT

Cline クラウド セッション、段階的にロールアウト: GitHub リポジトリと選択したブランチ上のホストされたサンドボックスでタスクを実行します。設定でオンにします。

 10/16
v0.0.94 パッチ MT

プラグインは、ワーカー スレッド (デフォルト、CLINE_PLUGIN_MODE=worker) またはサブプロセス サンドボックス (サンドボックス) でのみ実行されるようになりました。 in_process モードはサイレント フォールバックとともに削除されます。

desktop-v0.0.46 リリース MT

A new outline along the left edge of the conversation lists each prompt you sent. Hover a mark to preview the prompt, and click it to jump there

 10/13
cli-v3.0.71 リリース MT

Plugins now load inside the hub instead of a separate node or bun process, so the CLI no longer needs a JavaScript runtime on your PATH to run plugins.

v4.1.24 パッチ MT

モデルが選択されていないため、Cline プロバイダーと OpenRouter プロバイダーは Claude Sonnet 5.5 を使用するようになりました。 Clineについては、Clineの推奨リストの最初のモデルです。

v0.0.93 パッチ MT

プラグインは、ノード/bun サブプロセスではなくプロセスごとに 1 つのレジストリを介してインプロセスでロードされるため、コンパイルされた CLI とそのハブは PATH 上のランタイムを必要とせず、プラグインは Bun で構築されたハブの下で Bun グローバルを使用できます。
