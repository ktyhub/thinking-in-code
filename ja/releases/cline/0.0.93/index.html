cline v0.0.93

パッチ 公開日2026年10月13日 出典cline/cline 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#cline sdk/sdk/v0.0.93

  • プラグインは、ノード/bun サブプロセスではなくプロセスごとに 1 つのレジストリを介してインプロセスでロードされるため、コンパイルされた CLI とそのハブは PATH 上のランタイムを必要とせず、プラグインは Bun で構築されたハブの下で Bun グローバルを使用できます。 CLINE_PLUGIN_MODE=sandbox はサブプロセスのサンドボックスを保持します。レジストリはインポート、セットアップ、フック、ツール、コマンドをタイムアウトとエラー キャプチャでラップし、各プラグインの状態 (読み込み中/準備完了/劣化/失敗/無効) を最後のエラーとともに追跡します。障害が発生したプラグインがそのツールをサイレントにドロップすることはなくなりました。session.create は plugins ポリシーを受け入れて pluginIssues を返し、その後の障害はステータス通知として影響を受けるセッションに届き、ハブは plugins.list/plugins.status/plugins.reload に応答して plugin.status_changed をブロードキャストし、デーモンはプラグインからの捕捉されなかったエラーが発生したときにシャットダウンするのではなく、プラグインに失敗のマークを付けます。各セッションはすべてのプラグイン モジュールの独自のコピーを取得するため、モジュール レベルでセッションごとの状態を維持するプラグインは動作し続けます。
  • 推論をオフにすると、固定リストだけでなく、すべてのプロバイダーで機能するようになりました。カタログ エントリにオフ オプションがないモデルには何も送信されず、デフォルトが維持され、reasoning 機能のないモデルはスキップされます。 Gemini と Vertex は、予算をアドバタイズするモデルにのみ正確な thinkingBudget 値を送信します。レベルのみの Gemini モデルは、代わりに思考レベルを取得します (thinkingBudget は拒否されました)。リクエストに移植可能な推論オプションとネイティブ プロバイダー コントロール (effort、thinking、thinkingConfig など) の両方が含まれることはありません。ネイティブの方が勝ちます
  • cline プロバイダーのデフォルト モデルは、Cline 推奨モデル リストの最初のエントリであり、anthropic/claude-sonnet-5.5 に戻ります。 CLINE_DEFAULT_MODEL_ID は Claude Sonnet 5 から Claude Sonnet 5.5 に移行し、openrouter プロバイダーのデフォルトも anthropic/claude-sonnet-5.5 になりました。
  • estimateRequestInputTokens および createTokenEstimator は、base64 画像ペイロードをテキスト レートで請求しなくなりました。約 90 KB のスクリーンショットは約 30,000 トークンとしてカウントされるため、トランスクリプトが予算に近づくずっと前に、いくつかの画像で自動圧縮がトリガーされました。各イメージにフラット ESTIMATED_TOKENS_PER_IMAGE (1600) が追加されます。 @cline/shared の新しい createImageAwareReplacer エクスポート
  • 自動圧縮では、解決されたモデルのコンテキスト ウィンドウが使用されます。検出されたカタログ エントリには制限がなく、選択されたモデルのオーバーライドには制限があった場合、圧縮にはベア カタログ エントリが渡され、間違ったバジェットに対して実行されました。
  • スケジュールされた実行: キューに入れられた実行は、ストアの名前付きパラメーターを NULL としてバインドする bun:sqlite の下で正しく要求されるため、デスクトップ ハブはキューに入れられた実行を要求せず、エラーなしで保留状態のままになります。エージェントのターンがプロバイダー エラー (廃止されたモデル ID など) で終了した実行は、サイレントに成功するのではなく、エラー メッセージとともに失敗として記録されるようになり、実行レポートには使用状況とツール呼び出しが記録されます。同じスケジュールの新しい発生によって置き換えられたキューに入れられた cron 発生はキャンセルされるため、バックログは失われたすべてのスロットを連続して再生しなくなりました。
  • シンボリックリンクであるルール ファイルは、スキップされるのではなく、config ディレクトリからロードされるようになりました。リンクのターゲットに対する編集は、次回の更新または新しいセッションで反映されます。
  • resolveSkillsConfigSearchPaths は .claude/skills をスキャンするため、クロード コード用に作成されたスキルが Cline に表示されます。
  • エディタ ツールは、old_text をプレーン文字列としてアドバタイズします。スキーマで null が許可されている場合、一部のモデルでは置換テキストの代わりに null が送信されました。 Null は実行時に引き続き受け入れられ、省略されたものとして扱われます。
  • Composio コネクタ: サインインしたセッションは Composio のメタ ツール (検索、接続の管理、接続の待機、複数実行) を登録するため、エージェントはツールキット全体でコネクタ ツールを見つけ、まだ接続されていないアプリの接続リンクをユーザーに渡し、見つかったものを実行できます。コネクタ ツールはメタ検索を通じて検出されます。保存されたデスクトップ接続状態では、モデル ツールが提供されなくなりました。ホストは、新しい connectorsRequest オプション (@cline/core からエクスポートされた ConnectorsRequest) を通じて独自の認証を提供でき、これはスケジュールされたセッションにも転送されます。 resolveComposioToolsStatePath は resolveComposioConnectionStatePath に名前変更されました
  • @cline/core の Cline クラウド サインイン ヘルパーは AbortSignal を受け入れるため、ホストはポーリング中に保留中のサインインをキャンセルできます。
  • クラウド セッションの更新により、Web 上で名前が変更されたタイトルで開いているセッションが更新され、更新の進行中はローカルで行われた名前の変更が維持されます ・モデルカタログを更新（6,572→6,862モデル）。 AI/ML API、LowRouter、および Prime Inference プロバイダーを追加します。 models.dev には v0 がリストされなくなったため、v0 プロバイダーにはデフォルトのモデル v0-1.5-md のみが付属します。 OpenCode Go のベース URL は https://opencode.ai/zen/go/v1 から https://opencode.ai/inference/go/v1 に移動します。 Cline の空きリストには、ステップ 5 のプレビューが追加されます。 302.AI、CrossModel、Cortecs、DigitalOcean、NEAR AI Cloud、Ofox (Claude Haiku 5.5)、DevPass (LLM Gateway)、LLM Gateway、Meta (Muse Wonder 1.0)、Aixy (GPT-6.1 Sol)、CloudFerro Sherlock および Moark (GLM 5.3) のデフォルト モデルが変更されます。アンビエント、NanoGPT、Neuralwatt、Novita AI フル Changelog: https://github.com/cline/cline/compare/sdk/sdk/v0.0.92...sdk/sdk/v0.0.93
