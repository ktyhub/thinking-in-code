PX4-Autopilot v1.17.0

マイナー 公開日2026年5月13日 出典PX4/PX4-Autopilot 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

PX4-オートパイロット v1.17.0

何が変わったのか

PX4 v1.17 は PX4 v1.16 をベースに構築されており、v1.16.2 以降に以下の変更が加えられています。このリリースでは、高度巡航 モードが追加され、ナビゲーション喪失時の固定翼離陸動作が改善され、ROS 2 ワークフロー用のよりクリーンな高レベルの固定翼および探査車制御インターフェイスが公開されています。ツリー内 Zenoh ミドルウェアは rmw_zenoh 互換性まで成熟し、シミュレーションは Gazebo Jetty サポートと Ackermann SIH を獲得し、3 つの新しい INS ドライバー (MicroStrain、sbgECom、EULER-NAV) が Septentrio GNSS レジリエンス レポートと GNSS 高さに対する気圧計の自動校正とともにエコシステムに加わりました。 PX4 v1.17 には、ユーザーに表示される MAVLink、RC、ロギング、フェールセーフ、およびスタック全体にわたる探査機の改良も含まれています。

大きな変更点

  • 新しいマルチコプター飛行モード: 高度巡航。スティックを放しても傾斜と進行方向を保持するため、車両は高度モードのように停止するのではなく、一定の速度で巡航し続けます。
  • 固定翼離陸モード は、ナビゲーション損失時に水平翼で climbing を維持し、離陸ウェイポイントの緯度と経度を使用して徘徊者の位置を定義できるようになりました。 (PX4-オートパイロット#25226)
  • 固定翼機 (および固定翼モードの VTOL) は、PX4 ROS 2 制御インターフェイスの新しい FwLateralLongitudinalSetpointType を介して ROS 2 から制御できるようになり、横方向および縦方向の設定値を直接公開できます。
  • ローバーは、PX4 ROS 2 制御インターフェイスの新しい RoverSetpointTypes を介して ROS 2 から制御できるようになり、位置、速度、スロットル、姿勢、レート、ステアリング セットポイントの有効な組み合わせが有効な保証されたセットポイント タイプとして公開されます。 ローバー アプリと API を参照してください。
  • ツリー内 Zenoh ミドルウェア は、rmw_zenoh 互換性 (CDRv1 シリアル化、ROS 2 グラフの活性化、dds_topics.yaml から自動生成された構成、ドメイン ID パラメーター、Zenoh CLI) まで成熟しました。 Zenoh は FMU-v6xRT のデフォルトのファームウェアに組み込まれています (px4_fmu-v6xrt_default を作成します)。 FMU-v6x および SITL では、zenoh ビルド バリアントとして出荷されます (make px4_fmu-v6x_zenoh、make px4_sitl_zenoh)。
  • 初期の MC ニューラル ネットワーク コントロール テスト パス: PX4 v1.17 は、デバイス上に TensorFlow Lite Micro を統合しているため、外部でトレーニングされたネットワーク (たとえば、空中ジム で強化学習でトレーニングされた) を tflite モデルとしてロードし、研究やベンチ テスト用のマルチコプター コントローラーの代わりに使用できます。これは、実稼働コントローラー スタックの代替品ではありません。(PX4-Autopilot#24366)
