sofa-boot v4.3.0

マイナー 公開日2024年6月6日 出典sofastack/sofa-boot 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

ソファブーツ v4.3.0

⭐️新機能

  • https://github.com/sofastack/sofa-boot/pull/1291 の @wangchengming666 による PolarisRegistryConfiguration をサポート
  • https://github.com/sofastack/sofa-boot/pull/1293の@EvenLjjによる監視開始時にqueueRemainingSizeログを追加
  • https://github.com/sofastack/sofa-boot/pull/1294 の @HzjNeverStop により、sofa-boot-actuator-autoconigure モデルに spring-boot-configuration-processor を追加
  • https://github.com/sofastack/sofa-boot/pull/1301 の @HzjNeverStop によるソファ スレッド プール アクチュエータをサポート
  • https://github.com/sofastack/sofa-boot/pull/1288 の @wangchengming666 による kubernetes レジストリ構成をサポート
  • https://github.com/sofastack/sofa-boot/pull/1305 の @CrazyHZM による Mac M1(osx-aarch_64) のコンパイルとテストをサポート
  • https://github.com/sofastack/sofa-boot/pull/1326 の @HzjNeverStop による Spring Boot 3.2.6 の更新

🔨 最適化

  • https://github.com/sofastack/sofa-boot/pull/1287 の @NTP1996 による Map.toArray() (#1286) の呼び出しを減らすことで getBiz メソッドを最適化します。
  • https://github.com/sofastack/sofa-boot/pull/1297 の @HzjNeverStop により DynamicJvmServiceInvoker の ThreadLocal を削除
  • テスト: 新しいテスト ケースを追加します。 @JAYDIPSINH27 著、https://github.com/sofastack/sofa-boot/pull/1299
  • https://github.com/sofastack/sofa-boot/pull/1274 に @Duan-0916 によるコード スキャン アクションを追加
  • https://github.com/sofastack/sofa-boot/pull/1308 の @CrazyHZM により、github アクション バージョンを v4 にアップグレード
  • https://github.com/sofastack/sofa-boot/pull/1313 の @CrazyHZM によるコミュニティ連絡方法を更新
  • https://github.com/sofastack/sofa-boot/pull/1325 の @HzjNeverStop によるアプリケーション起動更新レジスタ順序
  • https://github.com/sofastack/sofa-boot/pull/1327 の @HzjNeverStop による非同期呼び出しメソッドに実行可能/呼び出し可能クラスを追加

🐞 バグ修正

  • ヘルスチェックのダブルチェックが成功した後の #1276 を修正し、https://github.com/sofastack/sofa-boot/pull/1290 の @wangchengming666 によって非同期を登録します
  • https://github.com/sofastack/sofa-boot/pull/1295 の @HzjNeverStop による jvmfilterholder の同時発生の問題を修正
  • https://github.com/sofastack/sofa-boot/pull/1310 の @CrazyHZM による並行チェック シナリオにおける準備状況チェック リストの間違いを修正
  • https://github.com/sofastack/sofa-boot/pull/1315 の @CrazyHZM によるビルド ステータスの Readme を修正
  • https://github.com/sofastack/sofa-boot/pull/1314 の @CrazyHZM によるタイプミスを修正
  • https://github.com/sofastack/sofa-boot/pull/1318 の @CrazyHZM によるビルド ステータスを修正
  • https://github.com/sofastack/sofa-boot/pull/1316 の @CrazyHZM による Lazyinit 値転送の問題を修正
  • https://github.com/sofastack/sofa-boot/pull/1319 の @CrazyHZM によって失われたparentId Bean 情報を修正
  • https://github.com/sofastack/sofa-boot/pull/1324 で @CrazyHZM によってシャットダウンせずにソファランタイム マネージャーが破壊される問題を修正

新しい貢献者

  • @NTP1996 が https://github.com/sofastack/sofa-boot/pull/1287 に初めて貢献しました
  • @wangchengming666 が https://github.com/sofastack/sofa-boot/pull/1290 に初めて投稿しました
  • @JAYDIPSINH27 が https://github.com/sofastack/sofa-boot/pull/1299 に初めて投稿しました
  • @Duan-0916 が https://github.com/sofastack/sofa-boot/pull/1274 に初めて投稿しました
