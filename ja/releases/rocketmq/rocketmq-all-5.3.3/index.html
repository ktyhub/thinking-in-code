rocketmq rocketmq-all-5.3.3

何が変わったのか

このバージョンでは「ACL 1.0」関連の機能はサポートされなくなりました。「ACL 2.0」を使用してください。 さらに、このマイナー バージョンには、いくつかの一般的なバグ修正が含まれています。

  • [問題 #8997] ブローカーが https://github.com/apache/rocketmq/pull/9137 の @gaoyf から応答がない場合に、再試行メッセージを送信する機会があることを確認します。
  • [問題 #9233] https://github.com/apache/rocketmq/pull/9234 の @bxfjb によって最初の正しいインデックス ファイルが選択されていないため、階層ストレージ内のクエリ メッセージが失敗する場合がある
  • [問題 #9246] https://github.com/apache/rocketmq/pull/9247 の @lizhimins による PopConsumerService での init オフセット モードのサポート
  • 不安定なテストを修正: BrokerOuterAPITest.test_needRegister_timeout by @DivyanshIITB (https://github.com/apache/rocketmq/pull/9250)
  • [問題 #9249] 配信が失敗すると、https://github.com/apache/rocketmq/pull/9252 の @coolmoon101 による配信設定の開始オフセットが正しくありません
  • [問題 #9241] RocksDBConsumeQueueStore は、https://github.com/apache/rocketmq/pull/9242 の @qianye1001 によって StoreCheckpoint を更新する必要はありません
  • [問題 #9244] https://github.com/apache/rocketmq/pull/9245 の @3424672656 による消費モードでのダーティ データの書き込みを回避する
  • [問題 #8701] https://github.com/apache/rocketmq/pull/9263 の @DivyanshIITB による MQClientInstance.java の BrokerAddrTable プロパティのドキュメントを修正
  • [問題 #8243] RocketMQ 5.x の互換性に関する構成ドキュメントの更新 (https://github.com/apache/rocketmq/pull/9258 の @DivyanshIITB による)
  • [問題 #9259] https://github.com/apache/rocketmq/pull/9260 の @mxsm による StoreCheckpoint の重複したフラッシュ操作を削除
  • [問題 #9266] README のクイック スタート バージョンを、https://github.com/apache/rocketmq/pull/9267 の @yx9o による最新バージョンに更新します
  • [問題 #7948] https://github.com/apache/rocketmq/pull/9265 で @yangxiaohui-coll による OOM につながる queryMessage メソッドの呼び出しを防止する
  • [問題 #9271] https://github.com/apache/rocketmq/pull/9272 の @bxfjb による階層型ストレージの getQueueOffsetByTimeAsync の強化
  • [問題 #9282] BrokerController#printWaterMark の最適化 (https://github.com/apache/rocketmq/pull/9283 の @yx9o による)
  • [問題 #9304] https://github.com/apache/rocketmq/pull/9305 の @ymwneu による DefaultMessageStore のコールド データ読み取り制御の問題を解決する
  • [問題 #9300] https://github.com/apache/rocketmq/pull/9301 の @ymwneu による StatsItemSet 内の非アクティブな項目の定期的なクリーンアップ
  • [問題 #9286] https://github.com/apache/rocketmq/pull/9287 の @ymwneu による SQL92 によるフィルター時のフィルターされたメッセージのカウント
  • [問題 #9284] pullMessage が 1 をオーバーフローした場合、https://github.com/apache/rocketmq/pull/9285 の @ymwneu によって RecordDiskFallBehind データを更新する必要があります
  • [問題 #9279] システム サブスクリプション グループの作成を制限し、https://github.com/apache/rocketmq/pull/9280 の @ymwneu によるプル リクエスト拒否ポリシーを追加します
  • client 設定を処理するための NPE を回避するnotifyClientTermination で https://github.com/apache/rocketmq/pull/9308 の @lollipopjin によって null
  • [問題 #9297] https://github.com/apache/rocketmq/pull/9298 の @ymwneu による TopicStatusSubCommand に TPS を設定したトピックの出力をサポートします
  • [問題 #1918] https://github.com/apache/rocketmq/pull/9278 の @fuyou001 による PullMessageService スレッド実行メソッドでスロー可能オブジェクトをキャッチします
  • [問題 #9302] SendMessageContext は、https://github.com/apache/rocketmq/pull/9303 の @ymwneu によってメッセージ タイプを追加します
  • https://github.com/apache/rocketmq/pull/9324 の @RongtongJin による tlsHelper のログ出力を最適化
  • https://github.com/apache/rocketmq/pull/9295 の @gaoyf による Prxoy リモート互換バッチ メッセージ
  • [問題 #9115] https://github.com/apache/rocketmq/pull/9116 の @yx9o による ConsumerId 変更に対するブローカーの逆通知を最適化します。
  • [問題 #9288] https://github.com/apache/rocketmq/pull/9293 で @ymwneu によるプロデューサー登録の無効化と高速チャネル シャットダウンをサポート
  • [問題 #9331] https://github.com/apache/rocketmq/pull/9332 の @WJ66880 により、プロキシの起動中にパラメータが失われる情報ログが 1 つ見つかりました
  • https://github.com/apache/rocketmq/pull/9327 の @lollipopjin によって、'systemTopicClusterName' クラスター内のすべてのブローカーにシステム トピックが作成されていることを確認してください。
  • [問題 #9339] https://github.com/apache/rocketmq/pull/9340 で @lizhimins によってメッセージがフィルターされる場合のポップ更新消費オフセットを修正
  • [問題 #9358] https://github.com/apache/rocketmq/pull/9359 の @bxfjb によって階層型ストレージからメッセージをクエリする場合、Timediff は 1000 を乗算する必要があります
  • [問題 #9360] ブローカーがオフラインになったときに一部のサービスがシャットダウンされない問題を修正 (https://github.com/apache/rocketmq/pull/9361 の @lizhimins により)
  • [問題 #9351] https://github.com/apache/rocketmq/pull/9352 の @golden-yang による queryTopicConsumeByWho コマンドにトピック グループ マッピングを追加
  • [問題 #9313] スケジュールされたクリーン タスクを追加します。 @GenerousMan 著、https://github.com/apache/rocketmq/pull/9314
  • [問題 #9369] https://github.com/apache/rocketmq/pull/9370 で @lizhimins によるポップ コンシューマー サービスを使用する場合のリセット オフセット コミット プル オフセットを修正しました。
  • [問題 #9371] https://github.com/apache/rocketmq/pull/9372 の @lizhimins による階層型ストレージの CommitLog の前に ConsumeQueue インデックスを削除する
  • [問題 #9233] https://github.com/apache/rocketmq/pull/9374 の @dingshuangxi888 による階層型ストレージでのクエリ時間境界計算を修正
  • [問題 #9375] client トレース スレッドを https://github.com/apache/rocketmq/pull/9376 の @qianye1001 によって正しく閉じることができるようにする
  • [問題 #9362] [RIP-77] @dingshuangxi888 による https://github.com/apache/rocketmq/pull/9363 の ACL 1.0 を非推奨にして削除
  • [問題 #9377] https://github.com/apache/rocketmq/pull/9378 の @kingkh1995 による「プロデューサーをすぐにシャットダウンするとトレース データの送信が失敗する可能性がある」を修正
  • [問題 #9379] https://github.com/apache/rocketmq/pull/9384 の @lizhimins による IndexService の timeStoreTable 削除ロジックを修正しました
