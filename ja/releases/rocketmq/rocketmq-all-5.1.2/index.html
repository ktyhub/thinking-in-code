rocketmq rocketmq-all-5.1.2

リリース 公開日2023年6月12日 出典apache/rocketmq 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

rocketmq rocketmq-all-5.1.2

何が変わったのか

  • [問題 #6747] INNER_MULTI_DISPATCH チェックを追加し、https://github.com/apache/rocketmq/pull/6746 に @humkum によるパス区切り文字を含めることはできません
  • [問題 #6761] https://github.com/apache/rocketmq/pull/6762 の @xdkxlk によるブローカーの再入可能通知の順序付けのサポート
  • [問題 #6765] org.apache.rocketmq.util.cache は、https://github.com/apache/rocketmq/pull/6766 の @socutes によって使用されているように見えません
  • [問題 #6745] https://github.com/apache/rocketmq/pull/6740 の @haiyanghan による冗長変数の削除
  • [問題 #6771] https://github.com/apache/rocketmq/pull/6772 の @mxsm による PullMessageProcessor#composeResponseHeader メソッドのいくつかのケースをマージする
  • [問題 #6774] https://github.com/apache/rocketmq/pull/6775 の @mxsm により README.md rocketmq バージョンを 5.1.1 に更新
  • [問題 #6789] https://github.com/apache/rocketmq/pull/6790 の @DL1231 によって DefaultMQProducerImpl のプレースホルダーを変更する
  • [問題 #6792] https://github.com/apache/rocketmq/pull/6793 の @DL1231 により、log.warn で送信メソッドが長時間ブロックされていたバグを修正
  • [問題 #6785] https://github.com/apache/rocketmq/pull/6786 の @xdkxlk により、remoteChannel をグループごとに分離する
  • [問題 #6797] https://github.com/apache/rocketmq/pull/6798 の @DongyuanPan による PopBufferMergeService に保存するバッファ ak を返信するときのバッチ ack をサポートします
  • https://github.com/apache/rocketmq/pull/6799 の @maclong1989 によるoperation.md のタイプミスを修正
  • [問題#6595] NPE を修正し、https://github.com/apache/rocketmq/pull/6596 の @miles-ton によるアクセス キー ログを繰り返す
  • [問題 #6816] https://github.com/apache/rocketmq/pull/6817 の @RongtongJin によるpersistent_unique_broker_id ドキュメントを修正する
  • [問題 #6803] https://github.com/apache/rocketmq/pull/6804 の @DL1231 によるベンチマーク サポート reportInterval オプション
  • [問題 #6819] https://github.com/apache/rocketmq/pull/6820 の @xiaochanbai により、brokerHeartbeatExecutorService executorService 名を変更します。
  • [問題 #6828] https://github.com/apache/rocketmq/pull/6829 の @xdkxlk により、注文コンシューマーの messageQueue の数に等しい割り当ての数を返します。
  • [問題 #6777] https://github.com/apache/rocketmq/pull/6778 の @TheR1sing3un によるコントローラーでのサポート メトリック
  • [問題 #6624] https://github.com/apache/rocketmq/pull/6625 の @TheR1sing3un による TieredFileSegmentInputStream の mark() と replace() をサポート
  • [問題 #6845] https://github.com/apache/rocketmq/pull/6846 の @TheR1sing3un によるバゼル付きコントローラーの構築
  • https://github.com/apache/rocketmq/pull/6843 で @RongtongJin による誤った命名を修正
  • [問題 #6849] https://github.com/apache/rocketmq/pull/6850 の @GenerousMan による 3 つのレプリケーターで RT が増加する問題を修正
  • [問題 #6779] https://github.com/apache/rocketmq/pull/6780 で @HScarb による LMQ のスケジュールされたメッセージをサポート
  • [問題 #6336] [RIP-62] https://github.com/apache/rocketmq/pull/6507 の @zk-drizzle によるコールド読み取り制御
  • [問題 #6858] https://github.com/apache/rocketmq/pull/6859 の @xdkxlk による将来の拡張のための ProxyContext のパススルー
  • [問題 #6154] TieredStorage で Amazon S3 バックエンドをサポート (https://github.com/apache/rocketmq/pull/6495 の @TheR1sing3un により)
  • [問題 #6861] https://github.com/apache/rocketmq/pull/6862 の @RongtongJin により、CURRENT_VERSION を 5.1.2 に変更します
  • [問題 #6866] https://github.com/apache/rocketmq/pull/6867 の @dingshuangxi888 により、grpc TLS モードの判断ロジックを移動して ProtocolNegotiator のスケーラビリティを向上
  • [問題 #6824] @deepsola による golang e2e テストを https://github.com/apache/rocketmq/pull/6825 に追加
  • [問題 #6633] [RIP-65] 階層型ストレージ実装の改善 (https://github.com/apache/rocketmq/pull/6781 の @lizhimins 氏)
  • [問題 #6881] https://github.com/apache/rocketmq/pull/6882 で @gaoyf によってスケジュールされたメッセージが再生されるバグを修正
  • [問題 #6800] https://github.com/apache/rocketmq/pull/6801 の @absolute8511 により、構成変数 isEnableBatchPush を EnableBatchPush に変更します。
