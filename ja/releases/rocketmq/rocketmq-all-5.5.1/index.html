rocketmq rocketmq-all-5.5.1

このメンテナンス リリースでは、fastjson 1.x がディストリビューションから削除され (fastjson2 は 2.0.63 にアップグレードされ、DLedger は 0.3.3.4 にアップグレードされました)、クロスプラットフォーム JNI シムを備えたネイティブ RocksDB CqCompactionFilter が導入され、従来の Broker DLedger モードが廃止され、階層型ストレージ、ライト モード、プロキシ、およびストア全体にわたる広範な安定性とパフォーマンスの修正が提供されます。層。

セキュリティと依存関係

  • [問題 #7703] https://github.com/apache/rocketmq/pull/10715 の @lizhimins によるセキュリティ修正のために、fastjson2 を 2.0.63 にアップグレードします。
  • [問題 #10651] DLedger を 0.3.3.4 (メンテナンス ライン) にバンプ (https://github.com/apache/rocketmq/pull/10958 の @RongtongJin により)
  • [問題 #10641] https://github.com/apache/rocketmq/pull/10642 の @RongtongJin による従来の Broker DLedger モードを非推奨にする

新機能 (Native RocksDB 圧縮フィルター)

クロスプラットフォーム JNI シムをサポートするネイティブ ConsumeQueue 圧縮フィルターを導入し、以前の Pure-Java フィルターとシェーディングされた rocketmq-rocksdb 依存関係を公式の Rocksdbjni アーティファクトに置き換えました。

  • [問題 #10334] https://github.com/apache/rocketmq/pull/10335 の @lizhimins によるクロスプラットフォーム JNI シムを使用したネイティブ CqCompactionFilter のサポート
  • [問題 #10334] https://github.com/apache/rocketmq/pull/10371 の @lizhimins により、rocksdbjni 依存関係なしでネイティブ CqCompactionFilter シムを自己完結型にする
