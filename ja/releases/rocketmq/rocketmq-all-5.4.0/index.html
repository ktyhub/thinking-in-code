rocketmq rocketmq-all-5.4.0

リリース 公開日2025年12月24日 出典apache/rocketmq 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

rocketmq rocketmq-all-5.4.0

このバージョンでは、2 つの新機能といくつかのマイナーな修正が導入されています。

  • [RIP-80] https://github.com/apache/rocketmq/pull/9929に@imzsによる優先メッセージを実装
  • [RIP-82] https://github.com/apache/rocketmq/pull/9787 の @zk-drizzle による RocksDB に基づくタイマー メッセージ、トランザクション メッセージ、インデックスの実装

何が変わったのか

  • [問題 #9891] https://github.com/apache/rocketmq/pull/9892 の @qianye1001 による拡張を容易にするためにポップの秩序ある実装を最適化します。
  • [問題 #9883] https://github.com/apache/rocketmq/pull/9884 の @yx9o による不要な MessageFormat.format を削除する
  • [問題 #9888] https://github.com/apache/rocketmq/pull/9889 の @RongtongJin による JVM クラッシュを防ぐために、popConsumerService のシャットダウン動作を延期する
  • [問題 #9894] RocketMQ 5.3.4 の README を更新し、https://github.com/apache/rocketmq/pull/9895 の @majialoong によるマイナー修正を追加
  • [問題 #9396] すべてのモジュールで fastjson2 を使用 (https://github.com/apache/rocketmq/pull/9397 の @yx9o により)
  • https://github.com/apache/rocketmq/pull/9896 の @qianye1001 による gRPC ルートのログを追加
  • https://github.com/apache/rocketmq/pull/9897 の @LittleBoy18 によるコントローラー モードの HAService RemoveConnection を修正
  • [問題 #9898] AbstractBrokerRunnable を削除し、https://github.com/apache/rocketmq/pull/9893 の @RongtongJin による Runnable に置き換えます。
  • [問題 #9910] [ACL 2.0] https://github.com/apache/rocketmq/pull/9911 の @dingshuangxi888 による SEND_MESSAGE_V2/SEND_BATCH_MESSAGE の再試行トピックからのコンシューマー グループの抽出が正しくありません
  • [問題 #9885] https://github.com/apache/rocketmq/pull/9886 の @majialoong による階層型ストアのキャッシュ数とバイトのメトリクスを修正
  • [問題 #9918] gRPC プッシュ コンシューマーが https://github.com/apache/rocketmq/pull/9919 の @qianye1001 によって予期せず切断された場合、メッセージが再度更新される可能性がある問題を修正しました。
  • [問題 #9912] https://github.com/apache/rocketmq/pull/9913 の @woaishixiaoxiao により、階層型ストアでコンシューマー オフセット タイムスタンプが正しく表示されない
  • [問題 #9868] https://github.com/apache/rocketmq/pull/9869 の @yx9o による空のパラメーターに対する getBrokerEpoch の応答がない問題を修正
  • https://github.com/apache/rocketmq/pull/9851 の @LittleBoy18 により、jdk9+ で dledger モードの期限切れメッセージを削除できない問題を修正
  • [問題 #9396] https://github.com/apache/rocketmq/pull/9927 の @yuz10 による fastjson を fastjson2 に置き換えます
  • [問題 #9902] https://github.com/apache/rocketmq/pull/9903 の @yx9o による不要な String.format を削除する
  • [問題 #9921] Pop revive の同時実行を制限する (@lizhimins による https://github.com/apache/rocketmq/pull/9922)
  • [問題 #9914] https://github.com/apache/rocketmq/pull/9915 の @yx9o による sendKernelImpl の障害項目を更新する際の分離ロジックを簡素化
  • [問題 #9928] GRPC プロトコルの優先 IT を追加します。 @imzs 著、https://github.com/apache/rocketmq/pull/9932
  • [問題 #9933] RocksDBConfigToJsonCommand が https://github.com/apache/rocketmq/pull/9934 の @RongtongJin によってローカルにエクスポートされるときの失敗を修正
  • https://github.com/apache/rocketmq/pull/9935 の @zk-drizzle による関数命名を最適化しました。
  • [問題 #9938] https://github.com/apache/rocketmq/pull/9939 の @yx9o により、誤った名前の Messing クラスの名前を Messaging に変更します
  • [問題 #9943] https://github.com/apache/rocketmq/pull/9944 の @yx9o による checkBrokerConfig の冗長な containsKey チェックを削除
  • https://github.com/apache/rocketmq/pull/9942 で @LittleBoy18 によるエポックの切り捨てを修正
  • [問題 #9945] デフォルトで UniqueKey を TimerDelKey として使用します。 @imzs 著、https://github.com/apache/rocketmq/pull/9946
  • [問題 #9947] https://github.com/apache/rocketmq/pull/9948 の @gaoyf により TimerMessageStore.checkAndReviseMetrics が BufferUnderflowException をスローする問題を修正
  • [問題 #9945] https://github.com/apache/rocketmq/pull/9951 で @imzs によって名前空間が追加されない場合、TimerDelKey 値として UniqueKey を使用する
