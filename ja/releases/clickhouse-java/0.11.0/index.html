重大な変更

  • [client-v2、jdbc-v2] ソケット バッファ オプション socket_rcvbuf および socket_sndbuf にはデフォルト値がなくなりました。アプリケーションがオプションを設定した場合にのみオプションが適用されるようになりました。 (Client.Builder#setSocketRcvbuf、 Client.Builder#setSocketSndbuf、または同じ名前のプロパティ)。これは、OS の TCP スタックを自動調整するために行われます。 価値観。どうしても必要になるまでは設定しないでください。 (https://github.com/ClickHouse/clickhouse-java/issues/3121)

  • [client-v2、jdbc-v2] サーバー エラー 159 (TIMEOUT_EXCEEDED) は、デフォルトでは再試行されなくなりました。それは独自のものを持っています 再試行原因 ClientFaultCause.ServerTimeoutExceeded、ServerRetryable には含まれず、 デフォルトの client_retry_on_failures リスト。このエラーを再試行するには、リストに ServerTimeoutExceeded を追加します。 (https://github.com/ClickHouse/clickhouse-java/issues/3072)

  • [r2dbc] R2DBC API が安定した 1.0.0 バージョンに達したため、1.0.0 より前のアーティファクトはサポートされなくなりました。

  • [jdbc-v2] DatabaseMetaData#getTables は、REMARKS (テーブル コメント) で null を返し、次のように TYPE_SCHEM を返します。 メタデータは SHOW ステートメントで読み取られるため、デフォルトです (「新規」の jdbc_metadata_use_show_statements エントリを参照) 特徴）。テーブルのコメントを取得するには、jdbc_metadata_use_show_statements=false を設定します。 (https://github.com/ClickHouse/clickhouse-java/issues/2907)

  • [client-v2,jdbc-v2] ブロック圧縮ストリームの ZSTD 圧縮サポートを追加し、デフォルトでは使用されません client リクエストを圧縮します。以前は、この場合は LZ4 のみがサポートされていました。注: ZSTD ライブラリとネイティブを追加しました サーバーと連携する必要があるため、ライブラリを -all JDBC パッケージに追加します。 (https://github.com/ClickHouse/clickhouse-java/issues/3105)。

  • [client-v2、jdbc-v2] User-Agent ヘッダーでは、標準の ClickHouse client 形式が使用されるようになりました。 <client name> clickhouse-java-v2/<version> (lv:java/<java.version>; os:<os.name>; hc:ahc_<version>): jvm:<version> は lv:java/<version> になり、OS は os: エントリになり、末尾の Apache-HttpClient/<version> は、hc:ahc_<version> エントリ (Apache HttpClient バージョン) に置き換えられます。 client は組み込まれています)。追加する Client.Builder#setClientName(String, Map) (プロパティ client_id_metadata) を追加しました キーと値のペアをコメント グループに追加します。このペアでは、lv、os、および hc を設定して、client の値を置き換えることができます。 先頭と末尾の空白は、client 名とカスタム User-Agent 値から削除されます。空白の値 1 回の操作で設定された場合は、未設定としてカウントされます。 client は、client の User-Agent 値が次の場合に警告をログに記録します。 設定が 200 文字を超えています。 system.query_log で http_user_agent を解析するクエリでは、新しい形式を使用する必要があります。 (https://github.com/ClickHouse/clickhouse-java/issues/3202)
