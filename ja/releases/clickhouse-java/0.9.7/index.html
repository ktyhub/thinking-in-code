clickhouse-java v0.9.7

パッチ 公開日2026年3月3日 出典ClickHouse/clickhouse-java 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#clickhouse-java v0.9.7

重要な注意事項

  • Client.Builder.addEndpoint(String) の動作が変更されました。URL ベース パスが保存されるようになりました (詳細は https://github.com/ClickHouse/clickhouse-java/issues/2344 にあります)。以前は、このメソッドはベース パスを無視していました。このメソッドでもクエリ パラメーターが無視されることに注意してください。エンドポイントは JDBC URL とは異なります。 Client には、構成を設定するための指定されたビルダー メソッドがあります。

重大な変更

  • [client-v2] 不明な構成プロパティが渡された場合、Client.Builder#build() は ClientMisconfigurationException をスローするようになりました。以前は、予期しない動作や問題の原因となる未知のプロパティは無視されていました。以前の動作を復元するには、ignore_unknown_config_key=true を client プロパティに追加します。 JDBC ドライバー専用プロパティ (ssl など) は、基礎となる client に転送されなくなりました。 (https://github.com/ClickHouse/clickhouse-java/issues/2658)

  • [client-v2] Date/Date32 列は、タイムゾーン調整なしで LocalDate としてデコードされるようになりました。以前は、Date 値が ZonedDateTime として返される可能性がありました。 ZonedDateTime を必要とするアプリケーションは、独自のタイムゾーン コンテキストを使用して、返された LocalDate からそれを構築する必要があります。詳細については、こちらをご覧ください - https://clickhouse.com/docs/integrations/language-clients/java/jdbc_date_time_guide (https://github.com/ClickHouse/clickhouse-java/pull/2727)

改善点

  • [client-v2] マルチパート フォーム エンコーディングを使用して HTTP リクエスト本文でクエリ パラメーターを送信するオプションを追加しました。新しい client.http.use_form_request_for_query 構成プロパティ (または Client.Builder#useHttpFormDataForQuery()) によって有効になります。クエリパラメータが URL の長さ制限を超える場合に便利です。 (https://github.com/ClickHouse/clickhouse-java/issues/2324)

  • [client-v2] QueryResponse、InsertResponse、および CommandResponse は、X-ClickHouse-Server-Display-Name HTTP 応答ヘッダーの値を取得するために getServerDisplayName() を公開するようになりました。ホワイトリストに登録された応答ヘッダーの完全なマップには、getResponseHeaders() 経由でアクセスできます。 (https://github.com/ClickHouse/clickhouse-java/issues/2347)

  • [client-v2] ネストされた配列の再帰サポートを含め、Array(...) 列を Object[] として読み取るための getObjectArray() を ClickHouseBinaryFormatReader および GenericRecord に追加しました。 getStringArray() は、列挙名を返すことで Array(Enum*) も処理するようになりました。 (https://github.com/ClickHouse/clickhouse-java/issues/2738)

  • [jdbc-v2] String/FixedString 列に対する byte[] の読み取りおよび書き込みのサポートが追加されました。 PreparedStatement#setBytes() は、値を ClickHouse unhex() 式としてエンコードして、生のバイトを保持します。 ResultSet#getBytes() は、文字列値の UTF-8 バイトを返します。 (https://github.com/ClickHouse/clickhouse-java/pull/2734)

  • [client-v2] ビルダー メソッド `addEndpoint() に渡された URL のパス部分を保持します (https://github.com/ClickHouse/clickhouse-java/pull/2691)

日付と時刻の処理

  • [ドキュメント] ドライバーがさまざまな日付/時刻値を処理する方法を説明する ドキュメント を追加しました。

  • [client-v2、jdbc-v2] タイムゾーン変換が明示的に実行されるように、Date/Time/Timestamp 値の書き込みを修正しました。以前は、特に Calendar またはデフォルト以外の JVM タイムゾーンが使用されている場合、タイムゾーン ナイーブ エンコーディングによって日シフトと精度のバグが発生していました。 (https://github.com/ClickHouse/clickhouse-java/issues/2701, https://github.com/ClickHouse/clickhouse-java/issues/2065, https://github.com/ClickHouse/clickhouse-java/issues/2496, https://github.com/ClickHouse/clickhouse-java/issues/1220, https://github.com/ClickHouse/clickhouse-java/issues/1117, https://github.com/ClickHouse/clickhouse-java/issues/1048, https://github.com/ClickHouse/clickhouse-java/issues/2381, https://github.com/ClickHouse/clickhouse-java/issues/1735, https://github.com/ClickHouse/clickhouse-java/issues/2542, https://github.com/ClickHouse/clickhouse-java/issues/2557)

  • [client-v2、jdbc-v2] Date/Time/DateTime 値の読み取りが一貫性があり正確になるように修正されました。 Date/Date32 は LocalDate (タイムゾーンなし) としてデコードされるようになり、Time/Time64 は UTC ベースの LocalDateTime としてデコードされます。 LocalTime アクセス用のリーダーに新しい getLocalTime() API が追加されました。 Dynamic 列と Variant 列からの日付/時刻の読み取りも修正されました。 (https://github.com/ClickHouse/clickhouse-java/pull/2727)

  • [jdbc-v2] DatabaseMetaDataImpl#getTypeInfo() は、v1 ドライバーの動作に一致する、確定的なアルファベット順で型情報を返すようになりました。 (https://github.com/ClickHouse/clickhouse-java/pull/2733)

SQL パーサー (jdbc-v2)

  • [jdbc-v2] SQL パーサーがテーブル名または列の別名として使用される ClickHouse キーワード (例: AS value、FROM date) を処理できない問題を修正しました。 ANTLR4 パーサーと JavaCC パーサーはどちらも、識別子の位置で許可される非予約キーワードのリストを維持するようになりました。また、DESCRIBE (SELECT ...)、SELECT の IN 演算子の解析、式内の括弧で囲まれた配列アクセスも修正されました。 (https://github.com/ClickHouse/clickhouse-java/issues/2718)

  • [jdbc-v2] 最近の ClickHouse HEAD ビルドで導入された新しい ClickHouse キーワード (ABI、ARGUMENTS、DRY、LANGUAGE、RETURNS、RUN) を認識するように SQL パーサーを更新しました。以前は、これらのキーワードを識別子として使用するクエリは解析に失敗していました。 (https://github.com/ClickHouse/clickhouse-java/pull/2761)

  • [jdbc-v2] toJSONString(data.^header_index) など、^ (キャレット) 演算子を含むステートメントで SQL パーサーが失敗する問題を修正しました。新しい CARET トークンが認識され、ドット付き識別子チェーンで許可されるようになりました。 (https://github.com/ClickHouse/clickhouse-java/issues/2768)

配列とコレクションの処理

  • [jdbc-v2] ネストされた配列を文字列に変換するときに NPE を引き起こす DataTypeConverter を修正しました (例: Array(Array(...)) 列の ResultSet#getString())。コンバータは再入可能になりました。以前はNullPointerExceptionを投げていました。 (https://github.com/ClickHouse/clickhouse-java/issues/2723)

  • [client-v2、jdbc-v2] 多次元 List/配列値の Java 配列への変換を修正しました。子配列の次元が親の深さレベルから正しく計算されるようになりました。以前は、List<List<T>> または同様の構造を変換すると、誤った結果が生成されました。 (https://github.com/ClickHouse/clickhouse-java/issues/2741)

  • [client-v2] 配列の最初の要素が空の Map または List である場合のバイナリ配列のデコードを修正しました。以前は、これにより配列作成中に型不一致エラーが発生していました。 (https://github.com/ClickHouse/clickhouse-java/issues/2499, https://github.com/ClickHouse/clickhouse-java/issues/2657, https://github.com/ClickHouse/clickhouse-java/issues/2703)

バグ修正

  • [jdbc-v2] サポートされている JDBC 仕様のバージョンではなく、ClickHouse ドライバーのバージョンを返す DatabaseMetaDataImpl#getJDBCMajorVersion() および getJDBCMinorVersion() を修正しました。 4 および 2 (JDBC 4.2) を正しく返すようになりました。 (https://github.com/ClickHouse/clickhouse-java/pull/2736)

  • [jdbc-v2] すべての既知の ClickHouse テーブル エンジンの JDBC テーブル タイプへのマッピングを追加しました。新しいテーブルタイプとしてMATERIALIZED VIEWを追加しました。 getTables() は、以前は表示されなかったリモート/外部エンジン テーブルを正しく報告するようになりました。 (https://github.com/ClickHouse/clickhouse-java/issues/2664)

  • [jdbc-v2] 型 Map、IPv4、IPv6、UUID、BFloat16、Decimal256、Geometry、すべての Interval* 型、JSON、LowCardinality、Nullable、Variant の列に対する JDBC 型メタデータの NullPointerException を修正しました。 Dynamicなど。以前は、これらの型には Java クラス マッピングがありませんでした。 (https://github.com/ClickHouse/clickhouse-java/issues/2711)

  • [jdbc-v2] ClickHouse サーバー エラー コードが SQLException#getErrorCode() に伝播されるようになりました。以前は、SQLException はベンダー エラー コードなしで作成されていたため、プログラムでエラー タイプを区別することができませんでした。 (https://github.com/ClickHouse/clickhouse-java/issues/2717)

  • [client-v2] max_execution_time がサーバーに正しく送信されない問題を修正しました。以前は、これは client オプションとして扱われ、ClickHouse によって無視されました。サーバー設定として送信されるようになりました。 (https://github.com/ClickHouse/clickhouse-java/issues/2750)

  • [client-v2] 列名が存在しない場合に例外をスローする hasValue(columnName) を修正しました。以前は、hasValue() 経由で不明な列または範囲外のインデックスを参照すると、エラーが発生していました。 false を返すようになりました。 (https://github.com/ClickHouse/clickhouse-java/issues/2755)

  • [jdbc-v2] エラー メッセージで 0 から始まるインデックスを使用して不足しているパラメータを報告する PreparedStatement を修正しました。 JDBC パラメータの位置は 1 から始まります。エラー メッセージにこれが正しく反映されるようになりました。 (https://github.com/ClickHouse/clickhouse-java/pull/2749)

  • [jdbc-v2] 従来の JDBC v1 接続プロパティ (ZZPH100​​ZZ、CUSTOM_SETTINGS、HTTP_CONNECTION_PROVIDER、REMEMBER_LAST_SET_ROLES、USE_SERVER_TIME_ZONE_FOR_DATES) を JDBC v2 に移植しました。 JDBC v1/v2 構成コードを共有する統合に必要です。 custom_http_params および custom_settings の値はサーバー設定に自動的に変換されます。 (https://github.com/ClickHouse/clickhouse-java/pull/2757)

  • [client-v2、jdbc-v2] custom_ プレフィックスを使用する場合、custom_ プレフィックスが付いた構成プロパティがカスタム設定としてサーバーに転送されない問題を修正しました。また、HTTP client に誤って転送されるドライバー専用プロパティ (ssl など) も修正されました。 (https://github.com/ClickHouse/clickhouse-java/issues/2658)
