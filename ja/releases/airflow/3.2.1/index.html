airflow 3.2.1

パッチ 公開日2026年4月22日 出典apache/airflow 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

エアフロー 3.2.1

📦 PyPI: https://pypi.org/project/apache-airflow/3.2.1/ 📚 ドキュメント: https://airflow.apache.org/docs/apache-airflow/3.2.1/ 🛠 Release Note: https://airflow.apache.org/docs/apache-airflow/3.2.1/release_notes.html 🐳 Docker 画像: 「docker プル アパッチ/エアフロー:3.2.1」 🚏 制約: https://github.com/apache/airflow/tree/constraints-3.2.1

重大な変更

  • DAG への読み取りアクセスのみを持つユーザーは、/dags endpoint, as it now requires additional permissions (DagAccessEntity.RUN, DagAccessEntity.HITL_DETAIL, and DagAccessEntity.TASK_INSTANCE). This change was made because the endpoint returns aggregated data from these multiple entities. Please update your custom user roles to include read access for DAG Runs, Task Instances, and HITL Details if those users should still have access to the /dags エンドポイントからデータをフェッチできなくなります。 (#64822)

改善点

  • CSS オーバーライドのみ、アイコンのみ、または空の {} to restore OSS defaults. The tokens フィールドを使用した UI テーマ設定を許可することが、テーマ設定のオプションになりました。 (#64552)

  • DEFAULT_LOGGING_CONFIG to use right kwargs (#65412) (#65424) を修正
  • バンドルの更新中にクリアされる zip DAG インポート エラーを修正 (#63617) (#65296)
  • シャットダウン時に非同期エンジンを破棄しない dispose_orm() を修正 (#65274) (#65284)
  • get_team_name_dep creating wasted async sessions when multi_team=False (#65275) (#65282) を修正
  • ユーザーの権限外で DAG が漏洩するアセット グラフ ビューを修正 (#65273) (#65280)
  • 移行を修正: 欠落していた disable_sqlite_fkeys を移行 0108 に追加 (#65288) (#65290)

  • UI: 古い DAG で非アクティブ化状態が表示されない問題を修正 (#65214) (#65218)
  • 一括プリフェッチによる DAG シリアル化中の N+1 クエリを修正 (#64929) (#65208)
  • 接続中の余分な空の文字列のシリアライザーを修正 (#65014) (#65215)

  • UI: SearchBar value not syncing with defaultValue の変更を修正 (#65054) (#65140)

  • is_alive default to None in jobs list CLI (#65065) (#65091) を修正
  • 欠落していた dag_id in get_task_instance (#64957) (#64968) (#65067) を修正
  • UI: 古い検索値を防ぐために、クリア時に「debounce」をキャンセルする問題を修正しました (#64893) (#64907)
  • CommsDecoder の送信メソッドでの読み取り順序が狂う問題を修正 (#64894) (#64946)

  • TypeError in GET /dags/{dag_id}/tasks when order_by field has None 値を修正 (#64384) (#64587)
  • UI: iframe が認証ページから移動するときに重複するナビゲーション サイドバーを修正 (#63873) (#64854)
  • UI: DagRun 実行時のガント ビューの「無効な日付エラー」を修正 (#64752) (#64853)
  • 失敗時にゼロ以外の終了コードを返す connections import を修正 (#64416) (#64449)
  • 単一 dict 引数の structlog の位置書式設定を修正 (#62849) (#64773)

  • UI: DagVersionSelect options not filtered by selected DagRun を修正 (#64736) (#64771)
  • フィルタリングされたタスクログのダウンロードにおける偽の空白行を修正 (#64235) (#64640)
  • フォークされたタスクプロセスで失われた OTel メトリクスを修正 (#64703) (#64720)
  • タイムゾーン変換のオーバーフローを回避するためにサンプル DAG の start_date を修正 (#63882) (#64758)
  • AirflowPlugin が再エクスポートされず、プラグインで mypy エラーが発生する問題を修正 (#65132) (#65163)
  • Python 3.13 での apache-airflow-providers-fab minimum version to prevent connexion インポート エラーを修正 (#65523) (#65524)
