アクティブな実行をドレインすることで Dags を正常に一時停止します (#72407、#73225、#73055、#73763)

Airflow は、Dags の「draining」スケジューリング状態をサポートするようになりました。ドレインするとスケジューラが停止します すでにキューに入っている Dag と実行中の Dag を許可しながら、新しいスケジュール済みまたはアセットトリガーの Dag 実行を作成します。 続行するには実行します。明示的にトリガーされた実行は引き続き許可されます。

未処理の Dag 実行が終了すると、Dag は自動的に「paused」に移行します。ユーザーは次のことができます ドレインをキャンセルして Dag を active に戻します。

一時停止した Dag での手動実行、バックフィル、アセットの具体化により、Dag が空になる可能性があります。 一時停止を解除するには、UI で Drain を選択するか、REST API リクエストで drain_dag を設定します。水抜き Dag の未完了の実行を開始または再開できるようにします。ただし、一時停止されたバックフィルによって保持されているものを除き、何も作成されません。 スケジュールされた実行を実行し、未完了の実行がすべて終了すると、Dag を再び一時停止します。一時停止されたバックフィルが残る 一時停止しており、実行を終了して排水を完了するには再開する必要があります。

UI、REST API、および airflowctl expose the active, draining, and paused のスケジューリング Dag リストでは、選択した複数の Dag を一度に一時停止、ドレイン、または一時停止解除できます。既存の is_paused API usage remains supported; use scheduling_state 排水状態でなければならない場合 明示的に選択または報告されます。
