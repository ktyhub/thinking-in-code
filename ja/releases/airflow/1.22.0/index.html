airflow 1.22.0

マイナー 公開日2026年6月13日 出典apache/airflow 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

エアフロー ヘルムチャート/1.22.0

重大な変更

Helm の最小バージョンが 3.19.0 に更新されました (#66970)

デフォルトのエアフロー イメージが 3.2.2 に更新されました (#67681)

チャートで使用されるデフォルトのエアフロー イメージは、以前は 3.2.1 でしたが、現在は 3.2.2 です。

enableServiceLinks の構成のサポートを追加しました (#67447)

チャート 2.0 では、デフォルトは false になります。これらの環境変数に依存する場合、 明示的に enableServiceLinks: true を設定するか、DNS ベースのサービス ルックアップを使用するようにコードを移行します。

新機能

  • オプションの OTel サービスをエアフロー ヘルム チャートに追加 (#64902)
  • クリーンアップ cron に serviceAccountTokenVolume を追加 (#67446)
  • ワーカー logGroomerSidecar に requirePersistence オプションを追加 (#65884)

改善点

  • API サーバー展開における api サーバー構成のチェックサムを追加 (#66468)

バグ修正

  • エグゼキューターのエイリアスをサポートするように Helm チャートのエグゼキューター ラベルを修正しました (#67762)
  • トリガー KEDA データベース接続レンダリングを修正 (#67538)
  • Celery ワーカー活性プローブのホスト名検索を修正 (#67471)
  • eq を使用してスライスを nil と比較する Go テンプレートのエラーを修正 (#64032)
  • Kubernetes ワーカー サービス アカウント値を修正 (#66598)
  • workers.kubernetes および条件ワーカー ServiceAccount のバインディングを追加 (#66730)
  • エグゼキュータークラスパスのランチャー RBAC を修正 (#66208)
  • Airflow 2 および 3 の NetworkPolicies によるタスク ログ アクセスを修正 (#65754)
  • ServiceAccount アノテーションに欠落していた tpl レンダリングを追加 (#66095)
  • ログ グルーマー保持値の go-template if ステートメントを修正 (#66012)
  • データベースクリーンアップのライフサイクルフックを修正 (#65881)
  • クリーンアップ ポッドのライフサイクル フックが適用されない問題を修正 (#65764)
  • 非推奨の警告を修正 (#66238)

ドキュメントのみが変更されます

  • Airflow 3 移行ガイドの Helm Chart アップグレード タスクを展開する (#66118)

その他

  • ジョブ/ポッドロールバインディングのレンダリングとリファクタリング関連のテストを変更 (#66626)
  • チャートの文言における Dag capitalization の標準化 (#66114)
