orca v1.4.250

#シャチv1.4.250

今日は2本リリースしました！ v1.4.249 release notes を必ずチェックしてください。これには、チャットまたはターミナルのセットアップが簡単になり、会話の制御が強化され、再設計された Phone Home が含まれます。

端末のメモリ使用量の削減、チャットの変更の明確化、Chrome 互換のパスワード マネージャー ✨

  • ⚡ ターミナルのメモリ使用量の削減: ターミナルの合字用のフォント ファイルの繰り返しの読み取りと解析を停止し、メモリ使用量の増加の原因を修正し、多くのターミナルとのセッションでクラッシュが発生するようにします。
  • ⚡ ワークツリーの切り替えの高速化: パフォーマンスの向上により、ワークツリー間の切り替えが高速化されました。
  • 📝 エージェントの変更内容を確認: チャット ターンには、変更されたファイルと行数が表示され、デスクトップと電話でインラインで利用できるパッチが表示されます。
  • 🔐 Chrome 互換パスワード マネージャー: [設定] → [ブラウザ]** で有効にし、OS の安全なストレージでローカルに暗号化された Chrome パスワードを保存、入力、インポートし、ログインを管理します。
  • 💬 チャット UI はエージェントに常に対応します: ツールを多用する長時間のターンはチャット UI で接続されたままになり、モデルを選択しない限り、新しいチャットはエージェント独自のモデル構成に従います。
  • 🖥️ より信頼性の高い端末とホスト: 端末出力ギャップ後の迷走エスケープ シーケンス テキストを防止し、ペアリングされたサーバー ワーカーと使用状況ポーリングをヘッドレス ホストで利用できるようにします。
  • 📱 電話の継続性の向上: Cmd/Ctrl+Enter でチャットを送信し、ペアリングされたデバイスが開いているタブを追跡し続けます。

ハイライト

  • パフォーマンス: ワークツリーの切り替えが高速化されました。端末の合字は、端末ごとにフォント全体を解析しなくなりました。 Commit Mono を使用した PR の Windows テストでは、前回のメモリ不足によるクラッシュは発生せずに 32 台の端末が再起動されました。結果はフォントとワークロードによって異なります。長いエージェント ターンでツールを閉じると、他のすべてのライブ ツールをスキャンすることも避けられます。
  • チャット: クロードとコーデックスの編集が成功すると、会話内で変更されたファイルの概要が表示され、選択したパッチの詳細が読み込まれます。チャット UI は、ライブ テキストまたはツールのエントリが 128 を超えた場合でも、正常なエージェントのターンを中断しなくなりました。コーデックス チャットは、要求された待機時間を表示し、目標の一時停止、再開、クリアをサポートします。
  • ブラウザ: Orca のブラウザでログイン情報を保存して入力し、ブラウザ設定で管理します。パスワードには OS による暗号化が使用されます。安全なストレージが利用できない場合、ボールトは利用できません。
  • ターミナルとリモート ホスト: ターミナル ストリームの回復により、出力ギャップ後の部分的なエスケープ シーケンスの出力が回避されます。ヘッドレス ホストは、ペアになったサーバー ワーカーと使用状況のポーリングに必要なサービスを開始します。
  • ワークスペースとオンボーディング: オンボーディング中にチャット UI を選択し、オンボーディング チェックリストを非表示にし、プロジェクト グループ外で非表示に検出されたワークツリーを検索し、改善された非アクティブなワークスペース クリーンアップ インターフェイスを使用します。

互換性とアップグレードに関する注意事項

  • 末端合字: 一般的な合字は引き続き使用できます。組み込みリスト外のフォント固有の合字は、GPU レンダラと結合できなくなる可能性があります。
  • ブラウザのパスワード: ボールトは、ローカルおよび SSH ワークスペース ページを含むデスクトップ ブラウザで利用できます。ストリーミングされたペアサーバーページと Web client にはボールトがありません。安全な OS 暗号化が必要です。
  • チャット モデルのデフォルト: 明示的にモデルを選択しない新しいチャットでは、エージェントの設定が使用されます。表示されるデフォルトは、エージェントが起動してそのモデルを報告するまでは古いままである可​​能性があります。
  • 端末回復: リモート ランタイム ストリームは、既存の回復動作を保持します。

製品体験

ネイティブチャットとエージェント

変更されたファイルをコンテキスト内で確認し、エージェントのターンを長く続けます。

  • 修正 (チャット): 保留中のワークスペース コンポーザーを準備しておく (https://github.com/stablyai/orca/pull/37954 の @AmoabaKelvin による)
  • https://github.com/stablyai/orca/pull/37951 の @brennanb2025 による Codex チャットで要求された待機時間を表示します
  • 修正(チャット): https://github.com/stablyai/orca/pull/38269 で @AmoabaKelvin によって実行されている間、コーデックス イメージの生成を生成中として表示する
  • https://github.com/stablyai/orca/pull/38257 の @brennanb2025 による 128 タイムライン エントリを超えてエージェントのターンを長く維持します
  • チャット ターンで変更されたファイルを直接表示 (https://github.com/stablyai/orca/pull/38256 の @brennanb2025 による)
  • https://github.com/stablyai/orca/pull/38252 の @brennanb2025 によってモデルが選択されていない場合、新しいチャットではエージェントの構成モデルが実行されます。
  • 修正 (ネイティブチャット): https://github.com/stablyai/orca/pull/38285 の @big-sheq により、矢印キーが質問カードの回答フィールドに到達できるようにしました
  • 修正 (ネイティブ チャット): https://github.com/stablyai/orca/pull/38250 の @brennanb2025 による Codex チャットでの /goal の一時停止、再開、クリアを実行
  • 修正 (ネイティブ チャット): https://github.com/stablyai/orca/pull/38319 の @AmoabaKelvin による折りたたまれたチャット メッセージ内のリスト番号を表示
  • 修正 (ネイティブ チャット): https://github.com/stablyai/orca/pull/38325 の @AmoabaKelvin による質問カードの回答フィールドで長い回答を折り返す
  • 修正（ディクテーション）: 作曲家の停止ボタンで停止したときにトランスクリプトを保持する by @AmoabaKelvin (https://github.com/stablyai/orca/pull/38327)
  • 修正（ネイティブチャット）: https://github.com/stablyai/orca/pull/38322 の @AmoabaKelvin により、フローティング パネルが移動するときにチャットの提案をコンポーザーの上に維持します
  • 修正（ネイティブチャット）: https://github.com/stablyai/orca/pull/38328 の @AmoabaKelvin によるエージェント設定サブメニューの上に @ と / の提案を表示
  • https://github.com/stablyai/orca/pull/38207 の @brennanb2025 によってバックグラウンド サブエージェントが実行されている間、Pi チャットを起動したままにします

端末、パフォーマンス、ホスト

端末のメモリ使用量を削減し、ストリームとヘッドレス ホストの信頼性を向上させます。

  • 修正（ターミナル）: https://github.com/stablyai/orca/pull/38240 の @OrcaWin によって合字アドオンがフォント ファイルを読み込まないようにする
  • fix(terminal): xterm があるターミナルストリームのみを再開するため、https://github.com/stablyai/orca/pull/38049 の @nwparker によってエスケープテールが出力されることはありません
  • 修正 (orcad): https://github.com/stablyai/orca/pull/38263 の @nwparker による ulimit -v アドレス空間制限の下での管理対象サーバーのクラッシュ ループを停止します。
  • fix(agent-state-rules): 404 を https://github.com/stablyai/orca/pull/38278 の @nwparker による警告ではなく、何も公開されていないものとして扱います
  • fix(serve): ヘッドレス ホストに、https://github.com/stablyai/orca/pull/37633 の @nwparker によって開始されたデスクトップ ウィンドウ パスをサービスに提供します。
  • fix(terminal): ターミナルのタブを閉じるたびに、誰が質問したかを宣言します。 https://github.com/stablyai/orca/pull/38284 の @nwparker の近くに暗黙のユーザーがいません
  • https://github.com/stablyai/orca/pull/38213 の @brennanb2025 による端末クイック コマンドに共有エージェント ピッカーを使用する

ブラウザ

ログインを保存し、リモート ワークスペース ブラウザの動作を改善します。

  • 修正 (ブラウザ): https://github.com/stablyai/orca/pull/38262 の @AmoabaKelvin によるエージェントのグローを表示するリモート ワークスペースのターミナル リンクを停止します。
  • 偉業(ブラウザ): Orca のブラウザにパスワードを保存して入力する by @AmoabaKelvin (https://github.com/stablyai/orca/pull/33994)

電話とペアリングされたデバイス

チャット入力とタブ ナビゲーションの一貫性をデバイス間で保ちます。

  • 修正（モバイル）: https://github.com/stablyai/orca/pull/38267 の @brennanb2025 による Cmd/Ctrl+Enter でチャットを送信
  • エージェントが作業している間、電話のチャットの [送信] ボタンをデスクトップと同じに保ちます (https://github.com/stablyai/orca/pull/38317 の @brennanb2025)
  • fix(session-tabs): ペアリングされたデバイスは、https://github.com/stablyai/orca/pull/38336 の @AmoabaKelvin による最初のタブだけでなく、開いているすべてのタブをたどります

セットアップ、ワークスペースのナビゲーション、自動化の実行が簡単になります。

  • https://github.com/stablyai/orca/pull/36204 の @AmethystLiang によるオンボーディングにチャット UI の選択肢を追加
  • https://github.com/stablyai/orca/pull/38241 の @AmethystLiang によりオンボーディング チェックリストに非表示ボタンを追加
  • 修正 (右側のサイドバー): https://github.com/stablyai/orca/pull/38261 で @AmoabaKelvin によってワークスペースが作成されている間、前のワークツリーのパネルを非表示にしました。
  • 修正（自動化）: https://github.com/stablyai/orca/pull/38029 の @Jinwoo-H による GitHub ソース ツールをチェックせずに「Run Now」を開始できるようにしました。
  • Orca がチャット UI をオンにするとどこでチャット UI に切り替えるかを指示します (https://github.com/stablyai/orca/pull/38243 の @brennanb2025)
  • 修正 (サイドバー): https://github.com/stablyai/orca/pull/38231 の @brennanb2025 によるプロジェクト グループ外で検出された非表示のワークツリーを表示する
  • 修正(サイドバー): https://github.com/stablyai/orca/pull/38288 の @OrcaWin により、ワークスペース リストのスクロールバーのヒット領域を継ぎ目を越えて拡張しました。
  • グループ化されたワークスペース カードをサイドバー ヘッダーと揃える (https://github.com/stablyai/orca/pull/38245 の @AmethystLiang による)
  • 非アクティブなワークスペースのクリーンアップ インターフェイスを改善し、https://github.com/stablyai/orca/pull/38281 の @Jingyue-Wu によるリポジトリ インジケーターを追加しました
