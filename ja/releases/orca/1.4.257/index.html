#シャチv1.4.257

以前のリリース: 1.4.256 — デバイス上のディクテーションのセットアップが簡単になり、以前のロング チャットのパフォーマンスが向上しました。

長いチャットがよりスムーズになり、フィードバックが保存され、ディクテーションが改善されました ✨

Orca 1.4.257 は、複数の長いチャット UI 会話が一度にストリーミングされるときのフリーズを軽減します。複数のエージェントが大量の履歴を持つ会話で作業を続ける場合、このアップデートにより、返信が到着するときに Orca が行う作業が削減されます。

  • 🌐 再起動してもブラウザのフィードバックを保持: Orca のブラウザのページ上の未送信のテキスト メモが、リロードまたは再起動後に返されるようになりました。未送信のメモがあるタブを閉じると、メモを破棄する前に尋ねられるため、フィードバックを残して後で戻ってくることができます。デスクトップ上で実行されているエージェントは、送信を押す前に orca tab annotations を使用してこれらのメモを読むことができます。
  • 🎙️ ディクテーション中に考える時間を与えてください: 設定 → 音声 → 入力 → 無音の後に停止 で、30 秒、1 分、2 分、またはオフを選択します。ディクテーションは、メッセージまたは端末コマンドを作成している間、長い一時停止の間待機することができます。同じ設定ページには、マイクの録音と再生を行うための テスト ボタンが追加されており、音声モデルの準備ができたらトランスクリプトが表示されます。
  • ⌨️ ターミナルの接続中に貼り付ける: 開始中または再接続中のターミナルに貼り付けられたコマンドは、ドロップされるのではなくシェルを待機するようになりました。これは、最大 64 KB のペーストのローカル、SSH、およびリモート端末をカバーします。より大きなペーストでも接続された端子が必要です。
  • 🗂️ フォルダー ワークスペース ルーチンの自動化: CLI を介した場合を含め、フォルダー ワークスペースを作成するときに、構成されたセットアップ スクリプトが実行されるようになりました。削除前に実行されるアーカイブ スクリプト。これらを使用してプロジェクトを準備し、クリーンアップ ルーチンを実行します。これらのスクリプトは共有プロジェクト フォルダーで動作します。

ハイライト

  • 分割ペインに属するものを検索する: 空の分割ペインで / を押して、エージェントまたはファイルを検索します。キーボードから離れることなく、矢印キーと Enter を使用して選択内容を開きます。
  • 選択したクロード モデルを保持する: チャット UI ピッカーは、以前のターンからの応答が到着したときに、モデルにスナップバックするのではなく、最新の選択を保持します。
  • Codex に作成を依頼した画像をご覧ください: 生成された画像は、ターン終了後もツールの詳細を展開せずに表示されたままになります。リモート チャットの場合、この動作を実現するには、ホストと client の両方を更新します。
