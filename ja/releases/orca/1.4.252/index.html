#シャチv1.4.252

あらゆる返信からチャットを分岐、プラン モード、高速電話 ✨

  • 📱 携帯電話でのよりスムーズなエクスペリエンス: 携帯電話の起動と再接続がより早くなり、チャットのスクロールとストリーミングがよりスムーズになり、Markdown と数学の読み取りが向上し、再接続後も未送信のチャット、レビュー、タスク テキストが保持されます。
  • 🗂️ マシン間でワークスペースを整理する: 他のマシン上のワークスペースを含め、フォルダー ワークスペースの下にワークスペースをネストします。
  • 🌿 チャット UI でさらに多くのことを行う: 元のチャットはそのままにして、終了した応答をフォークして別の方向を試みます。クロード チャットまたはコーデックス チャットで、/plan と入力してプラン モードに切り替えます。プラン モードは、チャットを再度開いても維持されます。
  • 🖥️ より信頼性の高いターミナル: ターミナル ペインはズームを維持し、スクロールバックを復元し、コピーしたファイルをフル パスとして貼り付け、ビジーなターミナル出力のレンダリングにかかる​​作業が軽減されます。
  • 🤖 より優れたエージェント サポート: 実行中のサブエージェントをチャットから開き、提案されたファイルと Codex 承認の差分を確認し、OpenCode の選択に関する質問に答え、Gemini Enterprise で Antigravity Chat にサインインします。
  • 🎙️ より良いディクテーション: ディクテーション言語を選択し、最初と最後の単語を保持し、モデルの読み込み中にリスニングを参照し、デバイス上のテキストを約 3 分の 1 早く取得します。
  • 🧭 チャットが実行される場所を知る: チャット コンポーザーにはマシン、ワークスペース、ブランチが表示され、チャットにはエージェントが開く各プル リクエストのカードが表示されます。
  • ⚡ より快適なデスクトップ チャット: 1 つのチャットのステータス変更によってすべてのチャットが起動されることはなくなり、すべてのワークツリーを移動することなくモデル ピッカーが開き、長い応答は再レンダリングせずにストリーミングされます。

ハイライト

  • チャット: 終了した応答からフォークし、クロード チャットとコーデックス チャットでプラン モードを使用し、エージェント ストリップから実行中のサブエージェントを開きます。 Codex の承認では提案されたファイルと差分が表示され、OpenCode では選択の質問をすることができ、Claude の組み込みサーバー ツールは通常のツール カードとして表示されます。忙しいチャットで Cmd/Ctrl を押し続けると、Cmd/Ctrl+Enter の動作が表示され、アプリのショートカットがチャット エディターから機能し、貼り付けられた特大の画像が失敗するのではなく、ぴったり収まるように縮小されます。サインアウトした OpenCode、Pi、OMP チャットには [サインイン] ボタンが表示されます。
  • 電話: マークダウンは読みやすく、数式、GitHub アラート、タスク ボックス、画像をレンダリングします。メニューからワークスペースの名前を変更し、使用制限通知で自動続行とアカウントの切り替えを確認し、接続が切断された場合でもチャット送信、PR テキスト、レビューメモ、タスクの下書きを保持します。前回正常に動作したときは、電話機はすぐにリレーにダイヤルし、ネットワーク スイッチを介して端末の出力を維持し、ビジー状態の端末を遅れずにストリーミングします。
  • エージェントとアカウント: Antigravity Chat は Gemini Enterprise でサインインし、保存されているすべてのアカウントのクォータをレポートし、WSL 内でアカウントを管理できます。 orca account は、保存されているアカウントを選択して削除できます。 Antigravity IDE が Open In プリセットに加わりました。
  • リモート ホスト: ホストが別の Orca サーバーにサービスを提供し、サーバーを停止したホストを切断し、手動ホストで IdentitiesOnly を尊重する場合、SSH は明確に通知します。スリープ状態のレシピ VM は、client が開くと起動し、orca serve は 1 つのアドレスにバインドでき、高遅延リンクではペアになったサーバーを介した参照が高速になります。ブラウザ タブには、SSH ホストがブラウザ タブを制御しているときと、それを停止する方法が表示されます。
  • ソース管理とタスク: 電話ブランチの切り替えは、コミットされていない作業を移動したり、リベース中に着陸したりする場合、明確な理由で拒否されます。チェックには、いつ実行されたか、どのくらい時間がかかったのかが表示されます。タスクでは、GitHub PR と GitLab MR を州別、作成者またはレビュー者別にフィルタリングでき、GitHub ドラフトが公開される前にアップロードされた貼り付け画像を作成できます。
  • ワークスペースとプラグイン: マルチリポジトリ フォルダー ワークスペースはワークスペースの親になることができ、ワークスペースは他のマシン上の親の下にネストできます。 orca plugin はプラグインのインストール、更新、削除、カタログの管理を行います。プラグイン ページには発行者に関する詳細が表示され、類似したプラグイン名には発行者が表示されます。

互換性とアップグレードに関する注意事項

  • macOS 13.4 の最小要件: Orca には macOS 13.4 以降 (以前は macOS 12) が必要になりました。古いバージョンの Mac は、アプリ内アップデーターを通じて最新の互換性のあるビルドに残り、通知が表示されます。macOS 13.0 ～ 13.3 では、Homebrew がアップグレードを拒否します。 macOS 13 上のすべての Mac を macOS 13.7 にアップデートして、Orca アップデートを取得し続けることができます。
  • ディクテーション モデル: Zipformer EN ディクテーション モデルは提供されなくなりました。これを選択した場合、Orca は Parakeet v2 に移動します。ディクテーションが機能する前に、[設定] › [音声] でダウンロードする必要がある場合があります。
  • 新しいプロファイル: 新しいデスクトップ プロファイルは、ホーム フォルダーの ~ という名前のフォルダー ワークスペースで開きます。既存のプロファイルは変更されません。オンボーディングの「後でセットアップ」により、デフォルトのエージェントが開くようになりました。
  • ペアリング コードの有効期限が切れます: 未使用のデスクトップ ペアリング コードの有効期限が切れます。電話機の QR コードは 10 分後に、別のコンピュータとのペアリング リンクは 60 分後に期限切れになります。すでにペアリングされているデバイスは影響を受けません。
  • チャット UI 設定: 変更されたファイル カードと開いたプル リクエスト カードは、設定 › チャット UI › ターン アクティビティから、ターンの差分および開いたプル リクエストとして制御されるようになりました。
  • ローカル ブラウザ プロキシ: ローカル ブラウザ コントロール プロキシには、Orca 独自のエージェント ブラウザ起動のみが受け取るセッションごとのトークンが必要となるため、マシン上の他のプログラムはそれを使用できなくなります。
  • ダウングレード: ダウングレードすると、プラン モードを使用したチャットを v1.4.251 で開くことができなくなります。アップグレードして戻すと、再び開きます。
