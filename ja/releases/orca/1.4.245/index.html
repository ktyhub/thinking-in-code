#シャチv1.4.245

より高速な Orca、プラグイン、バックグラウンド コンピューターの使用 ⚡

  • ⚡ より高速な Orca: 入力やタブの切り替え時の遅延が少なく、何百ものチャットをスムーズに起動できます。
  • 🧩 Orca をカスタマイズ アイコン テーマ、構文の強調表示、カスタム エディターを使用します。
  • 🖱️ **エージェントがバックグラウンドで Chrome、Blender、その他の Mac アプリを使用している間も、作業を続けてください。
  • 🎙️ 携帯電話でディクテーションすると、話しながら自分の言葉を確認できます。
  • 💬 新しいチャット UI をお試しください: 設定で「チャット UI」を検索してオンにし、タブを右クリックして cli クリックしてチャット UI と TUI をライブで切り替えます。

ハイライト

  • より高速な Orca: 数百のチャットを備えた高速アプリ。入力の応答性が向上し、他のタブを使用しているときの非表示チャットの動作が軽減されます。
  • プラグイン: [設定] → [プラグイン] から、アイコン テーマ、構文の強調表示、カスタム エディターを追加します。コミュニティ公開が近々開始される予定なので、独自のプラグインを共有できるようになります。
  • Mac でのバックグラウンド コンピュータの使用: マウスとキーボードを使用し続けながら、エージェントが Chrome、Blender、その他のアプリで作業できるようにします。 Orca のアプリ内ブラウザはすでにバックグラウンドで動作しています。今ではコンピューターも使用されています。一部のアクションでは、依然としてアプリを前方に移動する必要があります。
  • チャット: 非常に洗練されたチャット UI、停止後の再送信、チャット内のリンクのプレビューをお楽しみください。設定で「チャット UI」を検索してオンにし、タブを右クリックして cli クリックしてチャット UI と TUI をライブで切り替えます。
  • ターミナル: [設定] → [ターミナル] → [詳細設定] で、コンピュータごとに実行中のターミナルの制限を設定します。
  • WSL: 停止したディストリビューションは、[開始] を選択するまで停止したままになります。端末はそのフォルダーを記憶します。
  • ブラウザ: ブラウザを分割するには、Mac で Cmd+Opt+B を押します。短い注釈フィードバックを、貼り付けた画像とともに送信できるようになりました。
  • ワークスペース: ワークスペース名が再びブランチ名になります。ソース管理アクションはモデルと工数のコントロールを取得します。
  • 電話: 話しながらディクテーションを確認し、より明確なコード、表、図を読みます。

互換性とアップグレードに関する注意事項

  • 新しい端末ホスト: このリリースでは、新しい端末に対して新しい端末ホストが開始されます。更新前にすでに開いていたターミナルは、以前のホスト上で実行され続け、接続されたままになります。新しい実行端末制限設定には新しいホストが必要であり、ble.sh スタートアップ修正や macOS での軽量プロセス チェックなどの修正も必要です。これらは、更新後に開いた端末に適用されます。
  • プラグインはデフォルトでオンになっています: orca://plugins リンクからなど、プラグインをインストールすると、最初に確認画面のみが開きます。コードを実行するプラグインは、インストールする前に同意を求め、承認されると、コンピューターへの完全なアクセス権を持って実行されます。
  • 実行中の端末制限: デフォルトは各コンピュータに従います。システムの端末制限の半分、最大 4096、または Orca がその制限を読み取れない場合は以前のように 256 になります。 [設定] または環境変数で設定した値が優先されます。上げたり下げたりしても、実行中の端末が閉じることはありません。古い Orca を実行しているリモート サーバーは引き続き動作しますが、更新されるまで制限を変更することはできません。
  • チャットの名前付け: チャットには、デフォルトで独自のエージェントとアカウントによって名前が付けられるようになりました。以前に保存したネーミング エージェント、カスタム コマンド、または引数は引き続き機能し、ネーミング エージェントの選択は、[設定] → [チャット] → [チャットのネーミング] の [詳細設定] に移動しました。
  • アカウント間での Codex 履歴: 新しいスイッチ、[設定] → [エージェント] → [アカウント間で Codex 履歴を共有] はデフォルトでオンになっており、現在の動作が維持されます。これをオンにすると、システムのデフォルトに戻ったときに、Orca の管理対象アカウントの履歴が自分の ~/.codex にも表示されるようになります。これをオフにすると、新しい共有が停止され、何も削除されません。古い Orca を実行している SSH または WSL ホストでは、ホストが更新されるまでスイッチは無効のままです。
  • macOS および Linux 上の Codex: Orca は、貼り付け推測をオフにして Codex を開始するため、電話または別の client から入力されたプロンプトは、コンポーザーに留まるのではなく送信されます。本物のペーストはまだペーストのままで届きます。
  • Mac でのコンピュータの使用: エージェントはデフォルトでバックグラウンドで動作するようになりました。エージェントは引き続き --restore-window を使用して古いフォアグラウンド モードを要求できます。これは、Chromium アプリと Electron アプリに引き続き必要です。
  • ブラウザ注釈: 送信とコピーにより、メモごとにエージェントに短い概要が表示されるようになりました。古い完全な出力を取得するには、[送信] メニューの [ページの詳細を含める] をオンにします。選択はそのブラウザ ペインに対して継続されます。
  • ワークスペース ブランチ名: 新しいワークスペースに入力した名前は、作業からのブランチの自動名前変更がオンになっている場合でも、そのブランチとして再度使用されます。自動名前変更では、Orca が作成した名前のみが置き換えられます。
  • 自動化: 自動化によって開始されたエージェントは、CLI の起動更新プロンプトをスキップするため、プロンプトがタスクを飲み込むことができません。自分で立ち上げたエージェントは変わりません。
  • ソース コントロール アクション: アクションの引数に保存されたモデル フラグとエフォート フラグは、Orca のロード時に新しいモデル コントロールとエフォート コントロールに移動します。他の引数はそのままです。古い Orca 上の電話またはリモート サーバーは、更新されるまで、別のモデルまたは作業でこれらのアクションを起動する可能性があります。
  • 新しいショートカット: Cmd/Ctrl+Shift+X を押すとプラグイン (テキスト フィールドの外側) が開き、macOS 上で Cmd+Opt+B を押すと右側に分割されたブラウザ タブが開きます。 Cmd+Opt+Bは「設定」→「キーボード」で変更できます。
  • 既知の制限、ダウングレード: v1.4.244 に戻すと、ソース管理 AI アクションのカスタム モデルとエフォートの選択がエージェントのデフォルトにリセットされ、再度更新してもそれらは元に戻りません。
