#シャチv1.4.255

セッション検索の高速化、電話上のエージェント、スムーズなチャット切り替え ✨

昨日は 1.4.254 、今日は 1.4.255 という 2 つのリリースを立て続けに出荷しました。 Git Graph、チャット フォーク、デバイス上の電話ディクテ​​ーション、より復元性の高いモバイル作業、ペアリングと trust の改善については、1.4.254 release notes を参照してください。

待ち時間が少し減り、流れが少し良くなります。このアップデートにより、大規模なセッション履歴が検索しやすくなり、エージェントが携帯電話に集まるようになり、アカウント、モデル、ワークスペースを切り替える日常の作業がスムーズになります。

  • ⚡ 速度を落とさずに過去の作業を検索: セッション履歴の検索はアプリのメイン スレッドから実行され、入力中に結果が表示されたままになり、再起動直後に更新中に最後のリストが表示されます。検索は SSH およびリモート サーバー ホストでも機能します。
  • 📱 エージェントが携帯電話で一緒に: 新しい [エージェント] タブには、接続されているデスクトップ全体のエージェントがリストされます。デスクトップから提供されるアクティビティ ステータスを使用して、それらを既読としてマークするか、リストからクリアします。保存されたタスク リストとホスト ラベルは、アプリを再度開くとすぐに表示されます。
  • 💬 チャットを移動し続ける: Codex アカウントを切り替えると、開いている Codex チャットが選択したアカウントに移動します。フォークするとチャットの履歴が保存され、貼り付けられたリッチ テキストはそのリンクを保持し、キューに入れられたメッセージは再起動後に再開されます。
  • 🎛️ セットアップを選択するためのより明確な方法: エージェントの速度は 1 つのボタンになり、現在の選択が強調表示された状態でモデル セットアップが開き、「codex」を検索すると、Enter キーを押したときも含めて、Codex エージェントが他のエージェントの Codex 名付きモデルよりも先に表示されます。
  • 🌳 今いる場所からさらに多くのことを実行: Git Graph からコミットをチェックアウト、チェリーピック、または元に戻します。チャット コンポーザーの下のブランチ名から直接ブランチ ピッカーを開き、より単純な空の分割ペインから次のアクションを選択します。

ハイライト

  • セッション履歴とパフォーマンス: ワーカーで検索が実行されている間、大規模な履歴の応答性が維持されます。ワークスペース フィルターとプロジェクト フィルターは独自のセッションをクエリし、変更されていない履歴行により余分なレンダリングを回避し、検索インデックス作成とプロファイルの保存によるディスク作業が軽減されます。
  • チャットとエージェント: アカウントの切り替え後に Codex チャットを開くと、最初のメッセージの前に新しくインストールされたスキルが Codex の $ メニューに表示され、Antigravity チャットにはインストールされているスキルが表示されます。 OpenCode 2 は、選択したモデルから始まります。チャットをクリアすると古いトランスクリプトはすぐに非表示になり、失敗したモデルや作業の変更はチャット全体ではなくメッセージに影響します。
  • 電話とリモート ホスト: [エージェント] タブでは、デスクトップ全体のアクティビティが 1 か所にまとめられます。プレウォーミングによりページが早く開き、Git が変更されると Review がブランチ比較を更新し、ファイル プレビューの復元バーがキーボードの上に留まります。停止した LAN の再接続はリレーにフォールバックでき、ホスト キーが変更されていない場合、再開された VM はデバイスのペアリングを維持します。
  • ワークスペースとソース管理: Git Graph にチェックアウト、チェリーピック、および元に戻すアクションが追加されました。親を削除するときに対象となる子ワークスペースを保持したり、空のフォルダー ワークスペースから各リポジトリのワークツリーを作成したり、リポジトリ名がすでに使用されている場合に別のフォルダーにクローンを作成したりできます。サイドバーの分割線により、サイドバーのサイズが確実に変更されます。
  • ブラウザ、エディタ、ターミナル: リモート ブラウザ タブにはサイトのファビコンが表示され、Web サイトのリンクは新しいタブで開きます。CLI は、インストールされているブラウザ拡張機能をリストしてリロードできます。 PDF はプレビュー ペインの幅に収まります。ターミナル ペインは、別のウィンドウがそのサイズを保持していることを説明し、それを元に戻す方法を提供します。
  • 毎日の洗練: 長い設定リストでは検索可能なピッカーが使用され、古いチャット メッセージには日付が表示され、ライブ エージェントは未読フィルターに表示されたままになります。このリリースでは、古いブラウザー、リニア ツールバー、使用法ツールチップの表示、さらに日本語 IME をオフにした後の最初の Enter キーの押下も修正されています。
