#シャチv1.4.248

より信頼性の高い端末、信頼性の高いチャット、そしてより簡単な AI の選択 ✨

  • 🖥️ 信頼性の高い端末: アクティブなリモート ストリームの接続を維持し、デーモンの再起動後もエージェント ID を保持し、順序付けされたモバイル入力と Windows Codex への長いメッセージを改善し、フォントの読み込み後に Nerd Font シンボルを正しくレンダリングします。
  • 💬 より信頼性の高い会話: プロンプトの後に返信をストリーミングし続け、ターンが失敗した場合はキューに入れられたフォローアップを保持し、貼り付けられたテキストと端末の下書きをチャット送信とは別に保持します。
  • 🎛️ AI による書き込み方法を選択します: ソース管理設定から、コミット メッセージ、プル リクエストの説明、ブランチ名、チャット名のモデルと作業量を選択します。
  • ⚡ 不必要なチャット作業の削減: プレビュー更新により、読み込まれた完全な会話のコピーが回避され、このリリースでは、大規模なチャットを停止させる可能性があるライブ履歴のクリーンアップが削除されます。
  • 📱 電話の継続性の向上: キャッシュされたメッセージからチャットを再開し、オプションを最新の状態に保ち、Windows Codex に長いメッセージをより確実に送信します。
  • ⏳ アップデートがいつ到着するかを選択します: 待機をスキップする 1 回限りのオプションを使用して、設定にオプションのアップデート遅延を追加します。
  • 📝 エディターとワークスペースの改善: 保存時にフォーマットを選択し、テーマ ピッカーを検索し、チャット タブで使い慣れた右 click アクションを使用します。

ハイライト

  • ターミナル: 出力が流れている間、リモート ストリームは接続を維持し、エージェント ID はデーモンの再起動後も存続し、モバイル入力は順番にパイプライン化され、長電話メッセージは Windows Codex に到達します。フォントが読み込まれると Nerd Font シンボルが再描画され、閉じられたターミナル ワーカーはオーケストレーション カードから再度開くことができます。
  • チャットの継続性: ストリーミング応答は、プロンプトに応答した後も残ります。ターンが失敗した後もフォローアップはキューに残り、送信が拒否された場合は期限切れの添付ファイルが識別され、貼り付けられたテキストは構造化チャットから開くことができます。
  • エージェントの起動と選択肢: 最初の試行後に、再試行を繰り返す代わりに、最終的な起動の拒否が表示されます。一時的な障害はまだ回復します。オーバーライドを選択していない場合、チャットでは構成された作業量が保持され、ソース管理テキスト アクションではモデル メニューと作業量メニューが使用されます。
  • 電話: キャッシュされたチャットは、変更を取得する前に再度開きます。チャット オプション、ターミナル設定、ブランチとプルリクエストの詳細がより確実に更新されます。電話の長メッセージは Windows Codex に到達し、デスクトップ サーバーによってホストされているブラウザ タブを電話にストリーミングできます。
  • 更新と Windows: 更新の遅延を選択し、更新中に移動された Windows インストールの場所を保持し、インストールが不完全な場合には明確な説明を取得します。
  • エディターとナビゲーション: 保存時の形式を有効にし、テーマの選択肢を検索し、選択した Markdown テーブルのセルを強調表示し、エディター タブの外で画像ズーム ショートカットを使用します。
  • オーケストレーションとプラグイン: オーケストレーション パネルが実験的なオプトインとして再び利用可能になりました。閉じられたターミナル ワーカーはカードから再度開くことができ、ネイティブ チャットは完全なオーケストレーション メッセージを受信し、有効なステータス バー プラグインによりワーカーの実行が継続されます。
  • パフォーマンスと信頼性: チャット プレビューの更新により、冗長な全履歴コピーが回避され、キャッシュされたテキスト スクロールによりファイル全体のレイアウトの更新が回避され、診断ログの使用量が減少します。プレビューの変更により、不必要な作業が削除されます。アプリ全体のレイテンシの改善は主張されていません。

互換性とアップグレードに関する注意事項

  • 更新の遅延はオプションです: [設定] → [一般] → [更新] では、なし、1、3、7、14、または 30 日が提供されます。 [なし] がデフォルトのままで、遅延を 1 回スキップ すると、保留された更新がバイパスされます。
  • 保存時の形式はオプションです: 既存の編集動作は、有効にするまで同じままです。
  • オーケストレーション パネル: このリリースでは、以前のパネルの無効化の後、試験的なオプトインが復元されます。
  • 電話の変更: 電話アプリの変更には、更新された Orca モバイル アプリと互換性のあるデスクトップまたはサーバーが必要です。
  • 保存されたチャット履歴: 以前に追加されたライブ履歴のクリーンアップはロールバックされました。すでに圧縮された履歴を含め、既存の保存された会話は引き続き読み取り可能です。

既知の問題

保存されたチャット ストレージ: ライブ履歴の圧縮は一時停止されるため、会話が続くとチャット ストレージが増加する可能性があります。このリリースでは、チャット停止の原因をすべて取り除くとは主張していません。

アップデートの長い遅延: 14 日または 30 日の遅延があると、リリースが対象となる前にアップデート フィードから削除される可能性があります。 [なし] と [遅延を 1 回スキップ] は引き続き使用できます。

古いペアリングされたサーバーでの GitHub の問題: リポジトリまたは URL を通じて課題を開くと、タイトル、ラベル、担当者の編集が利用できなくなる可能性があります。ローカルおよびプロジェクト元のルートは影響を受けません。 GitHub でオープン は引き続き利用可能です。

プラグイン コマンドの置換: 組み込みコマンドを置換するプラグインは、Orca が代わりに通常のコマンドを使用した後でも終了する可能性があり、アクションが 2 回発生します。
