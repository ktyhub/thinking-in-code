#シャチv1.4.246

Orchestrator V3、改善されたターミナル、実験版のチャット UI、および更新された電話アプリ ✨

  • 🤝 Orchestrator V3: トークンの効率と信頼性が大幅に向上しました。 CLI エージェントとチャット UI の両方で動作し、チャット UI には視覚的なワーカー インジケーターが表示され、進行状況の追跡に役立ちます。
  • 🔕 静かな通知: Orca は、オーケストレーション中にワーカー エージェントの通知をフィルターで除外するようになりました。
  • 📱 更新された Orca モバイル: ライト、ダーク、またはシステムを選択し、設定で表示言語を選択します。よりクリーンな画面、よりスムーズなシート、より高速なワークスペース リストをお楽しみください。
  • 💬 チャット UI は実験段階ではありません: エージェントごとにチャットまたは CLI を選択し、機能している間はフォローアップをキューに入れ、使用制限に達した場合は別のアカウントまたはエージェント ハーネスを続行します。
  • ⌨️ ターミナルの改善: ターミナル エージェントの入力の高速化、セッションの復元の信頼性の向上、テキスト レンダリング、リンク、パディングの修正。
  • 🎨 Orca を自分のものにしましょう: アプリとは別にエディターのテーマを選択したり、背景画像を追加したり、ウィンドウ全体を端末のテーマに合わせたりできます。
  • 🧩 コミュニティ プラグインを探索する: コミュニティ カタログを参照し、構文テーマを試し、TypeScript と TSX を使用して独自のパネルを構築します。
  • 🖱️ コンピュータの使用とブラウザの使用の改善: バックグラウンド ブラウジング、サインイン ポップアップ、アップロードとダウンロードの信頼性が向上し、さらに Windows および Linux でのコンピュータの使用に関する修正が行われました。

ハイライト

  • モバイルのテーマと言語の選択: 電話アプリの ライト、ダーク、またはシステムを選択し、[設定] → [外観と言語] で 表示言語を選択します。
  • 更新された電話アプリ: 必要なものに焦点を当てたホーム画面、コンパクトな上部バー、下部検索、フィルター チップ、より明確なリスト、よりスムーズなシート。ワークスペース リストはより少ないデータで読み込まれ、画像と人魚図はピンチズームをサポートし、iOS はインライン HTML カードとプレビューを表示できます。携帯電話からも自動化を実行できます。
  • プラグイン: コミュニティ カタログはデフォルトで表示され、パブリック インストール数とより明確な発行者情報が表示されます。プラグイン作成者は、個別のビルド ステップ、コンポーネント ベースのパネル、ワーカー コミュニケーション、ホット リロード、およびテストとスクリーンショット用の CLI ツールを必要とせずに、TypeScript と TSX を入手できます。
  • チャット UI: チャットは実験版のままです。各エージェントの [設定] 行で [チャット] または [CLI] を選択し、デフォルトのモデルと作業量を選択します。デフォルトでは、エージェントが動作している間、フォローアップ メッセージがキューに入れられます。 Cmd/Ctrl+Enter は 1 つをそのまま実行ターンに送ります。アカウントを切り替えてオープン チャットを行ったり、別のアカウントまたはエージェント ハーネスで使用量が制限された会話を継続したりできます。
  • テーマとエディタ: 個別のコード エディタのテーマを設定し、エディタのタイポグラフィを調整し、背景画像を使用し、ウィンドウ全体に Match Terminal を適用します。画像の横に SVG ソースをプレビューし、click で画像をズームし、Alt キーを押しながらドラッグしてパンします。
  • ソース管理: デスクトップまたは電話上で競合を解決し、マージを完了します。モバイルの差分画面から変更されたすべてのファイルを開き、ペアリングされた携帯電話からドラフトにプル リクエストを返し、現在のプロバイダー データでチェックとレビューを更新します。
  • ブラウザとコンピュータの使用: エージェントは、サインインおよび支払いポップアップを操作し、ネストされたフレーム内のファイル ピッカー ボタンを介してアップロードし、ページ ダイアログに応答し、要求されたパスにダウンロードを保存できます。バックグラウンド ブラウザ ページは、エージェントが使用している間もアクティブなままです。
  • Orchestrator V3: トークンの効率と信頼性が大幅に向上しました。コーディネーターはターンを終了し、ワーカーが報告すると起動し、CLI ステータスと受信箱出力が短くなります。これはチャット UI でうまく機能し、視覚的な従業員カードとアクティビティ インジケーターが進捗状況の追跡に役立ちます。終了したワーカーにフォローアップ タスクを与え、閉じたワーカーを再開します。
  • 日々のスピードと洗練度: 多くのチャットによるアプリ全体の遅延が減り、シェルの送信が速くなり、ワークツリーのチェックアウトが速くなり、チャットや差分での再描画が少なくなります。子エージェントは折りたたまれて開始され、アイドル状態のエージェントがデスクトップと電話上でグループ化されます。

互換性とアップグレードに関する注意事項

  • エージェントごとのチャットまたは CLI: チャット UI には実験用スイッチが必要なくなりました。既存のユーザーは起動設定を維持し、既存の会話は表面を維持します。新しいインストールはターミナルで開始されます。 [設定] → [エージェント] で [チャット] または [CLI] を選択し、デフォルトのモデルと作業量を選択します。
  • デフォルトでフォローアップ キュー: エージェントの作業中に、Enter キーを押すと次のメッセージがキューに追加されます。 Cmd/Ctrl+Enter を押すと、代わりにそれを実行中のターンに送ります。デフォルトを変更するには、[設定] → [チャット] → [動作] で フォローアップのキュー をオフにします。電話機では、[送信] を押したままにして、[キュー] または [ステアリング] を選択します。電話はホストの設定に従います。キューをサポートしていない古い client またはホストは、すぐに送信を続けます。
  • モバイル アプリの更新: テーマや言語ピッカーを含むネイティブ設定の変更には、更新されたモバイル アプリが必要です。完全なエクスペリエンスを得るには、デスクトップまたはサーバーだけでなく Orca Mobile も更新してください。
  • プラグイン trust とアップデート: Orca は非公式プラグインを trust する前に警告します。より多くのアクセスを要求する更新は個別のレビューを待ち、インストールされたプラグインのコンテンツはロード時に再度検証されます。
  • 分離されたデスクトップ プラグイン ビュー: プラグイン パネルとカスタム エディターは、直接ネットワーク アクセスがブロックされた個別のプロセスとストレージを使用するようになりました。ブラウザーとサービスの client は、既存の iframe の動作を保持します。
  • WSL ホスト: 停止したディストリビューションは、ワークスペースの復元または切り替え時に停止したままになり、ブロックされたペインで [開始] が提供されます。 WSL ホストの設定をオフにすると、新しいホストが停止し、保存されたホストがサービスを提供し続けながら移動します。アイドル状態の WSL サーバーは、独自のシェルにアイドル タイムアウトを設定しなくても、5 分後に終了できます。
  • Orca スキル: 未編集のバンドル スキルは自動的に更新されます。変更したスキルは引き続き確認を求められます。
