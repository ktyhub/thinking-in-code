コンサルタント-changelog-1.22.0

1.22.0+ent (2025 年 10 月 24 日)

このリリースは、Consul Enterprise changelog を共有し、利用可能であることを消費者に通知するために作成されました。添付のソースとアセットには Consul Enterprise コードは含まれていないため、公式 Docker イメージやバイナリの代わりに使用しないでください。

セキュリティ:

  • 接続: Consul にバンドルされている Envoy バージョンを 1.35.3 にアップグレードし、1.31.10 のサポートを削除します。この更新には、CA バンドルが存在する場合にのみ TLS トランスポート ソケットを構成することで、Envoy (v1.35+) の起動エラーを防ぐ修正も含まれています。 [GH-22824]
  • セキュリティ: ACL を有効にせずにリモート/ローカル スクリプト チェックが有効になっている場合の警告を追加 [GH-22877]
  • セキュリティ: 潜在的なサービス拒否攻撃を防止するために、Consul KV エンドポイントの Content-Length ヘッダーの検証が改善されましたCVE-2025-11374 [GH-22916]
  • セキュリティ: サービス拒否 (DoS) 攻撃を修正するために、イベント エンドポイントに最大 Content-Length を追加します。これにより CVE-2025-11375 が解決されます。 [GH-22836]
  • セキュリティ: 重大な変更 - DisableKVKeyValidation 構成とともにキー/値エンドポイントにキー名検証を追加して、構成ミスまたは欠落している ACL ポリシーに対するパス トラバーサル攻撃を修正するために無効化/有効化します。 [GH-22850]

特徴:

  • 複数のポートを使用して consul にサービスを登録するためのサポートを追加 [GH-22769]
  • エージェント: 「エージェント/セルフ」API から取得したバインド アドレスに基づいて、エージェントが IPv4 と IPv6 (デュアル スタック モード) の両方に設定されているかどうかを検出する IsDualStack ユーティリティ関数を追加しました。 [GH-22741]
  • インストール: インストール後に表示される更新されたライセンス情報
  • ipv6: ipv6 およびデュアル スタック サポートのための ip6tables の変更の追加 [GH-22787]
  • oidc: JWT アサーションと PKCE を使用した client 認証を追加します。デフォルトの PKCE は有効になっています。 [GH-22732]

改善点:

  • セキュリティ: golang を 1.25.3 にアップグレードします。 [GH-22926]
  • ui: 現在発生している計算プロパティ オーバーライドの問題を修正し、場合によっては ember v4 で非推奨になったため、事前に修正します [GH-22947]
  • ui: https://deprecations.emberjs.com/id/ember-component-send-action/ [GH-22938] の一部として送信アクション インスタンスを削除します。
  • ui: Ember v4 にアップグレードするための増分ステップとして、Ember パーシャルをコンポーネントに置き換えました [GH-22888]
  • api: 手動スナップショット レポート用のエンタープライズ API をサポートするための新しい API (/v1/operator/utilization) を追加しました [GH-22837]
  • cmd: 国勢調査の使用率スナップショットを含むバンドルを生成するための新しいサブコマンド consul operator utilization [-today-only] [-message] [-y] を追加しました。主なフローは consul-enterprise で実装されます http: /v1/operator/utilization 用の新しい API ハンドラーを追加しました。 consul-enterprise に実装されるコア機能 エージェント: Hashicorp Reporting にエクスポートするための構成可能なオプションを使用して、国勢調査指標の収集を常に有効にしました [GH-22843]
  • cli: snapshot agent は、Azure Managed Service Identities (MSI) を使用した Azure Blob Storage への認証をサポートするようになりました。 [GH-11171]
  • コマンド: connect envoy ブートストラップのデフォルトは、IPv4 のみの環境では 127.0.0.1 に、IPv6/DualStack 環境では ::1 に設定されます。 [GH-22763]
  • 接続: IPv6 エージェント バインド アドレスのデフォルトのupstream.local_bind_address ::1 [GH-22773]
  • プロキシ: IPv6 エージェント バインド アドレスのデフォルトの proxy.local_service_address ::1 [GH-22772]
  • ui: Consul UI のアクセシビリティ機能が改善され、障害のあるユーザーの使いやすさが向上しました [GH-22770]
  • ui: パッケージ管理のために糸を pnpm に置き換える [GH-22790]
  • ui: 認証方式の設定値がオーバーフローしていました。この PR では問題が修正され、大きなコンテンツを含むテーブル要素にワード ブレークが追加されます。 [GH-22813]

バグ修正:

  • ui: Consul Web インターフェイスに FQDN を表示できるようにします。 [GH-22779]
  • ui: 名前空間が消え、タブを切り替えた後に [名前空間へようこそ] 画面が表示される問題を修正 [GH-22789]
  • ui: 複数のトークンまたはポリシーを削除するときに、最初の削除後に右側の 3 つのドットが応答しなくなる問題を修正します。 [GH-22752]
  • cmd: 余分なパラメータを含まずに利用可能なオプションのみを表示するように consul operator utilization --help を修正しました。 [GH-22912]
