consul v2.0.0

メジャー 公開日2026年5月24日 出典hashicorp/consul 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#領事v2.0.0

2.0.0 (2026 年 5 月 22 日)

セキュリティ:

  • 接続: envoy バージョンを 1.37.2 以降のバージョンにアップグレード [GH-23469]
  • go: go バージョンを 1.26 [GH-23493] にアップグレードします
  • エージェント: 長いポーリングのブロッキング クエリの中断を防ぐために、デフォルトの HTTP サーバーのタイムアウトが増加しました。 read_timeout と write_timeout は 15 分 (30 秒から増加) に設定されていますが、read_header_timeout (10 秒) と idle_timeout (120 秒) は引き続き Slowloris 攻撃に対する保護を提供します。すべてのタイムアウトは、http_config ブロックを介して引き続き構成可能です。 [GH-23267]
  • api-gateway、terminated-gateway: api-gateway および terminated-gateway HTTP リスナーに HTTP 要求パス正規化を適用して、正規化されていないパスを介した L7 インテンション RBAC バイパスを防止します (CVE-2024-10005)。 [GH-23534]
  • docker: ubi ベース イメージを ubi9-minimal:9.7 に更新します。 [GH-23553]
  • docker: コンテナー イメージの Alpine Edge から curl を >= 8.20.0 にアップグレードして、アドレスを指定します。 CVE-2026-6429、 CVE-2026-4873、 CVE-2026-5773、 CVE-2026-6253、 CVE-2026-6276、 CVE-2026-7168、 CVE-2026-5545。 Alpine 3.23 安定版にはパッチ適用バージョンがまだ提供されていません。 [GH-23750]
  • docker: [CVE_2026-2100] [GH-23588] を修正するために、UBI ベース イメージを 9.8 に更新します。

特徴:

  • (エンタープライズのみ) PAO の新しいライセンスに適応するために go-licensing/v4 および go-census/v3 に更新します。
  • グローバル レート リミッター: (エンタープライズのみ) 新しい「レート制限」設定エントリの種類で、Raft に保存され、すべてのサーバーに自動的にレプリケートされる動的でクラスター全体の RPC レート制限を有効にします。これにより、オペレーターは Consul サーバーを再起動することなく、実行時にグローバル レート制限を適用または調整できます。これは、クラスターに過剰な負荷がかかる緊急事態のシナリオでは重要な機能です。
  • api-gateway: リスナー レベルのデフォルト TLS 証明書と HTTP/TCP ルート サービス TLS SDS オーバーライドを含む、API ゲートウェイ リスナーの SDS 証明書サポートを追加しました。サービス オーバーライドは、省略された場合にリスナー SDS クラスターを継承し、ゲートウェイ検証/xDS 生成では、証明書の選択を確定的に保つために競合するオーバーライド マッピングを拒否するようになりました。 [GH-23354]
  • api-gateway: ゲートウェイ レベルのデフォルトのアップストリーム制限のサポートと、MaxConnections、MaxPendingRequests、および MaxConcurrentRequests のルート サービス レベル制限のオーバーライドのサポートを追加します。 [GH-23396]
  • api: すべての RPC メソッド名をリストする新しい API "/v1/internal/rpc/methods" を追加しました。 Operator:read ACL トークンが必要です。これは、ユーザーが特定の RPC エンドポイントを除外するレート制限を構成する場合に便利です。 [GH-23329]
  • ca: (エンタープライズのみ) Cyberark WIM 用の新しい Connect CA プロバイダー (connect.ca_provider = "pan-distributed-issuer") が追加され、Consul が Cyberark WIM を通じて証明書を発行できるようになりました。
  • サーバー: (エンタープライズのみ) 安定したクラスター ID と、サービス概要公開用のリーダーゲート型グローバル レジストリ同期を追加します。
  • テレメトリ: (エンタープライズのみ) 匿名のオプトイン使用状況レポートを備えた自己管理型 Consul 用の製品テレメトリ。
  • メッシュ: (エンタープライズのみ) Consul でマルチポート (名前付きポート) サービスのサポートを導入します。これには、ポート名を使用してトラフィックを指定およびルーティングする機能や、特定のサービス ポートの仮想 IP を取得する機能が含まれます。また、特定の高度なマルチポート機能が Consul Enterprise でのみ利用可能であることが強制され、クラスターの命名と ALPN プロトコル生成のための新しいユーティリティ関数が含まれます。

改善点:

  • エージェント: (エンタープライズのみ) エンタープライズ使用状況メトリクスに結果整合性のあるバックグラウンド キャッシュを追加し、GET /v1/operator/usage レイテンシーを O(PNK) から O(1) に削減し、監視駆動のメンテナ ゴルーチンを介して高頻度の scraping 中の CPU/メモリの負荷を下げます。
  • メッシュ: (エンタープライズのみ) Consul でマルチポート (名前付きポート) サービスのサポートを導入します。これには、ポート名を使用してトラフィックを指定およびルーティングする機能や、特定のサービス ポートの仮想 IP を取得する機能が含まれます。また、特定の高度なマルチポート機能が Consul Enterprise でのみ利用可能であることが強制され、クラスターの命名と ALPN プロトコル生成のための新しいユーティリティ関数が含まれます。
  • terminated-gateway: 静的証明書の代わりに sds を使用するようにクラスターのアップストリーム TLS を更新しました。これにより、終端ゲートウェイを再起動する必要なく動的証明書を更新できるようになります。 [GH-23288]
  • テレメトリ: Prometheus メトリクス (データセンター/パーティション/名前空間のラベル付き) による証明書の有効期限監視、構成可能な重大度しきい値による構造化ログ、およびルート証明書と中間証明書の NotAfter フィールドを含めるための Connect CA API の強化を追加します。 [GH-23147]
  • deps: github.com/hashicorp/vault/sdk を v0.7.0 から v0.25.1 に、github.com/hashicorp/vault/api を v1.12.2 から v1.16.0 にアップグレードします。 [GH-23574]
  • test-integ: 統合テスト モジュールの testcontainers-go (v0.22.0->v0.40.0) および docker/docker (v24.0.5->v28.5.1) をアップグレードします。これにより、テスト フレームワークの Go 依存関係として opencontainers/runc が削除されます。これらはテスト インフラストラクチャの依存関係のみであり、Consul バイナリや Consul のデプロイメントには影響しません。 [GH-23573]
  • xds: Consecutive5xx、ConsecutiveGatewayFailure、および EnforcingConsecutiveGatewayFailure フィールドを PassiveHealthCheck に追加し、オペレーターがアップストリームのデフォルトで 5xx 応答およびゲートウェイ障害 (502/503/504) に対する Envoy 外れ値検出しきい値を設定できるようにします。

バグ修正:

  • 監査ログ: (エンタープライズのみ) obj の配列が AuditReq 本文に渡されるときの JSON アンマーシャル エラーを修正しました。
  • cli: consul config write コマンドのエラー メッセージが強化され、ゲートウェイまたはルーターによる参照が原因で構成エントリを変更できない場合に実用的なガイダンスが提供されます。 [GH-22921]
  • xds: ピア接続時に API ゲートウェイの正しいエンドポイントとクラスター構成を生成するように XDS パッケージを修正し、メッシュ ゲートウェイ構成をアップストリームに伝達するように API ゲートウェイ更新ハンドラーを更新しました。 [GH-23454]
  • XDS: DNS ホスト名が IP ではなく AWS NLB に割り当てられ、envoy の EDS エンドポイント検証ではアドレスが IP であることが想定されるため、AWS EKS のリモート モードでのメッシュ ゲートウェイの問題を修正しました。ホスト名ベースのゲートウェイにより CDS/EDS の同期が維持されるため、非ピア リモート メッシュ ゲートウェイ ターゲットに対して EDS 負荷割り当てがスキップされるようになりました。 [GH-23543]
  • api-gateway: API ゲートウェイ検出チェーン合成中にルートのサービス サブセットを解決します。 [GH-23294]
  • ui: 壊れたドキュメントのリンクを修正 [GH-23578]
