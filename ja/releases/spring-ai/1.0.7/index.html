#春愛v1.0.7

Spring AI 1.0.7 Release Notes

🎯 ハイライト

このリリースには 5 つのバグ修正と 6 つのその他の改善が含まれています。

⏪ 重大な変更

  • チャット メモリ アドバイザでは、明示的な会話 ID の指定が必要になりました。以前は、デフォルトまたは暗黙的な ID が使用されていた可能性があり、会話全体でメモリのスコープが正しく設定されない可能性がありました。発信者は会話 ID を明示的に提供する必要があります。 be48f06

⚠️ アップグレードに関するメモ

  • PromptChatMemoryAdvisor を使用している場合は、代替 Advisor に移行します。すべてのチャット メモリ アドバイザーでは、明示的な conversationId を指定する必要があります。チャット メモリ アドバイザーを作成または呼び出すときに、会話 ID を渡すようにコードを更新します。 be48f06

🪲 バグ修正

  • ID リストを処理する際の Milvus ベクター ストアの doDelete メソッドの文字列 escaping を修正し、削除操作中の潜在的なクエリ エラーを防止しました。 864ef81
  • MCP サーバーの ObjectMapper の構成ミスを解決し、適切な JSON シリアル化および逆シリアル化動作を保証します。 436c765
  • MCP サーバーと Spring WebMvc サーバーのセットアップに影響する自動構成の問題を修正しました。以前の誤った修正は元に戻され、適切な解像度に置き換えられました。 4b21612
  • チャット メモリ アドバイザの明示的な ID に対する新しい要件に合わせて、明示的な会話 ID を提供するために ChatClientAdvisor の統合テストを更新しました。 a5fb397
  • メソッド呼び出し関数コールバックの Anthropic チャット client 統合テストでのテストの失敗を解決しました。 daa1b68

🔨 依存関係のアップグレード

  • モデル コンテキスト プロトコル (MCP) SDK を大幅なバージョン ジャンプ (0.10.0 → 0.18.2) によって更新し、多くのアップストリームの改善、新機能、および互換性の更新を組み込みました。 #5958

🔩 ビルドのアップデート

  • プロジェクトのビルドでは JDK 17.0.19 が使用されるようになり、最新の LTS パッチ リリースとの整合性が確保され、ビルド環境のセキュリティと安定性が向上しました。 1badb6f
  • Spring AI スターター モジュールは専用の starters/ ディレクトリに再配置され、プロジェクトのディレクトリ構造と構成が改善されました。 36df6b9
  • プロジェクト バージョンは 1.0.7-SNAPSHOT に進み、1.0.6 リリースに続く次の開発サイクルを開始しました。 82848f2
