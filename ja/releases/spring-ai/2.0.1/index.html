spring-ai v2.0.1

パッチ 公開日2026年8月21日 出典spring-projects/spring-ai 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#春愛v2.0.1

2.0.0 から 2.0.1 へのアップグレードについては、こちら のアップグレード ノートを参照してください。

2.0.1 の詳細なリファレンス ドキュメントについては、こちら を参照してください。

:star: 新機能

  • 脆弱性に対する Ollama 統合テストの強化 #6776
  • 非推奨の Mistral AI チャット モデルを廃止 #6772
  • 追加の 2.0.1 の重大な変更を文書化 #6771
  • OpenAiAudioSpeechModel #6733 でのオーディオ ストリーミングのサポート
  • 構成可能なツール呼び出し制限を追加 #6726
  • OpenAI 転写オプションと応答を強化 #6697
  • Spring Boot が管理する client #6583 を使用するように Couchbase ベクター ストアを更新します
  • 明示的な protobuf-java バージョン プロパティを削除 #6552
  • Google GenAI チャット モデルの ToolChoice サポートを追加 #6531
  • spring-ai-azure-store から fastjson2 依存関係を削除 #6508
  • 型付き data オーバーロードを使用するように Media ビルダーをリファクタリング #6481
  • TokenTextSplitter ビルダー引数を検証する #6452
  • PagePdfDocumentReader #6445 のページ範囲をサポート
  • DeepSeekApi #6428 を修正
  • mcp アノテーションの GraalVM は、Spring AI 2.0.0 #6427 では機能しません。
  • spring-ai-autoconfigure-model-chat-memory-redis #6416 の名前を変更します。
  • OpenAiChatModel #6410 で PDF メディア マッピングを復元
  • Google 画像生成サポート #6408
  • 未使用フィールドを削除 maxResults #6344
  • AWS リージョン解決中の WARN ログが混乱する #5108
  • SpringAI は、AWS SDK のデフォルトのリージョン解決ルール #823 に従っていません。

:lady_beetle: バグ修正

  • Redis チャット メモリ タイムスタンプをアトミックに予約 #6784
  • RedisChatMemoryRepository clear() #6783 を修正しました。
  • Redis チャット メモリ クエリのメタデータ値をエスケープする #6765
  • 解決されたリソース パスを検証します #6764
  • maxSessions と sessionIdleTimeout を導入 #6760
  • キャンセル時にストリームがリークする OpenAiAudioTranscriptionModel を修正 #6759
  • #6756 をオーバーライドする代わりに、java-compile のコンパイラArgs をマージします。
  • デフォルトの OpenAI ツール呼び出し厳密モードを false #6755
  • キャッシュに一時ディレクトリを使用する #6754
  • PdfDocumentReader での不正な PDF の処理 #6753
  • ツール解像度フォールバックを構成可能にする #6751
  • 完全長ハッシュ #6746 を使用します
  • ToolContext パラメータ検出を修正 #6744
  • ToolCallLimitExceededException で単一の世代を返す #6742
  • DoBeforeStream ミューテーションをドロップする ToolCallingAdvisor ストリーミング ループを修正 #6737
  • OpenAiAudioSpeechModel に指示オプションを追加 #6731
  • MCP HTTP client リクエスト カスタマイザー Bean を適用 #6716
  • キャンセル時に OpenAI ストリーム応答を閉じる #6656
  • MarkdownCodeBlockCleaner の StringIndexOutOfBoundsException を防ぐためにテキストの長さを検証する #6645
  • モデル構築外で無視される AnthropicChatOptions.timeout(Duration) を修正 #6605
  • TransformersEmbeddingModel #6572 でネイティブ リソースを閉じる
  • 設定されたモデルを継承しない OllamaChatModel プロンプト オプションを修正 #6567
  • ワイヤ/プロトコル値に対する文字列の大文字/小文字操作には Locale.ROOT を使用します #6566
  • Mistral AI モデレーション Categories および CategoryScores での null フィールドの処理 #6565
  • TLS 検査プロキシの背後での Azure OpenAI 認証エラーを修正 #6553
  • OpenSearchVectorStore ドキュメントの逆シリアル化を修正 #6550
  • MilvusFilterExpressionConverter #6543 のグループ優先順位を修正
  • OpenAiChatModel #6540 の厳密モードのペイロード配置を修正
  • @McpTool 例外処理を @Tool コントラクトに合わせます #6534
  • 引数なしの MCP stdio 接続を修正 #6533
  • Milvus メタデータの整数値が Double ではなく Long として逆シリアル化される問題を修正 #6517
  • 空のツール_コールの OpenAI ストリーム処理を修正 #6504
  • チャット オプション ビルダー clone() の共有可変状態を修正 #6498
  • 並列呼び出しのツール検索参照抽出を修正 #6497
  • CouchbaseSearchVectorStore.Builder #6490 の誤ったアサーションを修正
  • AnthropicChatOptions.Builder.clone() の共有可変状態を修正 #6487
  • ブロッキング モードでのツール呼び出し監視の null 親を修正しました #6475
  • カスタム メタデータ フィールドを使用した Milvus フィルターを修正 #6470
  • BOM にツール検索アドバイザ モジュールを追加 #6464
  • ツール呼び出しトークンの使用にモデルに依存しないアサーションを使用する #6461
  • ツール検索アドバイザの自動構成の順序を修正 #6458
  • openai ストリーミング モードにバグがあります #6441
  • 初期化後に PgVectorStore テーブルのスキーマを検証する #6438
  • ツール呼び出しアドバイザの使用量を蓄積する #6424
  • 単一行のフェンスで囲まれたコード ブロックのコンテンツを破棄する MarkdownCodeBlockCleaner を修正しました #6423
  • OpenAiChatModel #6381 のインデックスによるストリーミング ツール呼び出しデルタのマージ
  • OpenAI API #6375 経由で DeepSeek モデルを呼び出す場合、メタデータの reasoningContent は常に null になります
  • Genai 思考レベルの検証を修正 #6339
  • プロキシ ホストの Microsoft Foundry URL パス モードを修正 #6180
  • OpenAiChatModel#buildGeneration #6009 で Optional アンラップを実行します。
  • event フィールドのない SSE フレームを受け入れるようにストリーミング可能な HTTP WebClient トランスポートを修正 #5783

:notebook_with_decorative_cover: ドキュメント

  • 不正確なコンテンツ インターフェイス Javadoc を修正 #6704
  • チャット メモリの会話 ID スコープを文書化 #6651
  • OpenAI オーディオ ドキュメントのタイトルとリンク切れを修正 #6606
  • 構造化出力ドキュメントの再構築 #6495
  • CosmosDBChatMemoryRepository セクションを復元 #6491
  • McpTool JavaDoc コメントのタイプミスを修正 #6449
  • 再構築ツール呼び出しのリファレンス ドキュメント #6432
  • アップグレード ノートの ToolSearchToolCallingAdvisor を削除 #6421
  • アップグレード ノートの無効な JavaDoc リンクを修正 #6419
  • 古い Pinecone 無料層名前空間ノートを更新 #6383
  • openai-chat.adoc #6037 の重複した「is is」タイプミスを修正
  • ビルダー パターン #5999 を使用するように Ollama OpenAI API 互換性サンプルを更新します。

:hammer: 依存関係のアップグレード

  • Maven プラグインのバージョンを Spring Boot BOM #6586 に委任します
  • gRPC のバージョン管理を Spring Boot #6585 と合わせました。
  • Milvus java client を 2.6.21 #6503 にアップグレードします。
  • 松ぼっくり client を 6.2.0 #6496 にアップグレードします
  • qdrant client を 1.18.0 #6494 にアップグレードします。
