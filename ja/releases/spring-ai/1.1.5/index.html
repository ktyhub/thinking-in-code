#春愛v1.1.5

Spring AI 1.1.5 Release Notes

🎯 ハイライト

このリリースには、9 件のバグ修正、3 件のドキュメントの改善、11 件のその他の改善が含まれています。

⚠️ アップグレードに関するメモ

  • Pixtral 12B モデルは削除され、Pixtral Large は非推奨になりました。将来のリリースでの問題を回避するには、現在推奨されている Pixtral モデルを使用するようにモデル構成を更新してください。 447d2a4

📢 注目すべき

  • Pixtral 12B モデルは削除され、Pixtral Large モデルは非推奨になりました。推奨される代替モデルを使用するように統合テストが更新されました。これらのモデルに依存しているユーザーは、推奨される代替モデルに移行する必要があります。 447d2a4

🪲 バグ修正

  • クエリを適切にパラメーター化するように CosmosDB ベクター ストアの doDelete メソッドを修正し、潜在的な SQL インジェクションの脆弱性を防止し、正確性を向上させました。 6039e57
  • VectorStoreChatMemoryAdvisor フィルターでconversationIdが正しく適用されず、会話全体で不正なメモリ取得が発生する可能性がある問題を修正しました。 3cccfdf
  • フィルター式が適切に評価されるように、ベクター ストア フィルター式コンバーターのキー処理を修正しました。 01386e2
  • BedrockConverse ストリーミング トークン使用テストにおけるテストの非決定性が解決され、テストの信頼性が向上しました。 4747a3c
  • 統合テストのサフィックスを適切に適用するようにテスト クラスの名前を修正し、適切なテストの分類と実行を確保しました。 #5853
  • OpenAiSdkChatModel のtoolChoice フィールドの文字列解析ロジックを修正し、ツール選択構成を適切に処理できるようにしました。 aeb33b0 #5735経由
  • 発信 OpenAI API リクエストに extra_body パラメーターが誤って含まれており、予期しない動作を引き起こす可能性がある問題を修正しました。 4c0120c
  • Javadoc の生成と構成に関する問題を解決し、API ドキュメントが正しく生成されるようにしました。 0a71804
  • 必要な API キーが環境内に構成されていない場合に統合テストが適切にスキップされるように、テスト バイパス条件を修正しました。 bc26dc1

📓 ドキュメント

  • README を更新して、CPU アーキテクチャ要件または互換性情報に関するメモを追加しました。 a21e988
  • MCP サーバーが MCP clients からツールを再公開する方法を説明するドキュメントを追加し、マルチサーバー設定でのツール伝播モデルを明確にしました。 #5778
  • OpenAI API リクエストにおける extra_body パラメーターの意図された使用法と動作を明確にするためにドキュメントを改善しました。 3d4d75b

🔨 依存関係のアップグレード

  • Spring Boot の依存関係をバージョン 3.5.14 に更新し、Spring Boot チームからの最新のバグ修正と改善を組み込みました。 eb4c9a5
  • 中間アップグレードとして、Spring Boot の依存関係をバージョン 3.5.13 に更新しました。 9b902f8
  • ドキュメント解析の依存関係の更新: ドキュメント処理機能の向上とバグ修正のため、Apache Tika は 3.3.0 に、jsoup は 1.22.1 に、Apache PDFBox は 3.0.7 にアップグレードされました。 f25fc52

🔩 ビルドのアップデート

  • CI/CD の信頼性とセキュリティを向上させるために、GitHub アクション ワークフローの依存関係を最新バージョンに更新しました。 9b70b38
  • プル リクエストの検証をより効率的に行うために、mvn test ではなく mvn package を使用するように PR チェック ワークフローを変更しました。 7d2e455
  • ビルドのパフォーマンスを向上させるために、CI パイプラインで統合テストがスキップされるようになり、release notes 生成ワークフローが削除されました。 #5688
  • プロジェクトは、リリース後、次の開発バージョン 1.1.5-SNAPSHOT に移行されました。 400dc42

🔐 セキュリティ

  • 変圧器モデルに使用されるデフォルトのキャッシュ ディレクトリを強化し、キャッシュされたモデル ファイルへの不正アクセスや改ざんを防ぎます。 aac6b80
  • 不正な形式の PDF によってドキュメントの解析中に過剰なメモリ割り当てが発生する可能性があるサービス拒否の潜在的な脆弱性を修正しました。 b61ac6a
