#しろしろ-ルート-2.0.3

バグ修正

  • バグ修正 (テスト): https://github.com/apache/shiro/pull/1890 で @lprimak による Guice テストの不安定なロックが失敗する
  • [DOC] - https://github.com/apache/shiro/pull/1986 の @arthenice による無効な Javadoc 構文と壊れた参照をクリーンアップします。
  • [DOC] - https://github.com/apache/shiro/pull/2023 の @jkaving による AuthenticatingRealm のコメントとログ メッセージを修正
  • [#2050] バグ修正: https://github.com/apache/shiro/pull/2052 の @lprimak による validate() で IllegalStateException をキャッチ

改善点

  • 雑用: https://github.com/apache/shiro/pull/1881 の @lprimak による CI JDK 22 -> 23 の更新
  • 雑用: Maven ラッパーを追加し、3.9.9 を更新し、https://github.com/apache/shiro/pull/1935 の @lprimak によって CI スクリプトでそれを使用できるようにしました。
  • deps: dev.aspectj に切り替えます - https://github.com/apache/shiro/pull/2062 の @lprimak による新しい Maven プラグイン
