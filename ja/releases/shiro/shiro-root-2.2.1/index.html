#しろしろ-ルート-2.2.1

バグ修正

  • chore(jacoco): https://github.com/apache/shiro/pull/2769 の @lprimak による溶接 client プロキシの除外を追加

セキュリティの改善

  • [#2704] [#2710] https://github.com/apache/shiro/pull/2711 の @lprimak によるセッション固定関連のリグレッションを修正しました
  • [#2758] https://github.com/apache/shiro/pull/2770 の @lprimak によるエントロピー不足のため、RandomSessionIdGenerator を非推奨にしました
  • enh(jakarta-ee): リファラーヘッダーのホスト部分を削除
  • Rdn.escapeValues() の使用

改善点

  • https://github.com/apache/shiro/pull/2705 の @jbampton によるプリコミットを ASF 承認の prek-action に切り替える
  • https://github.com/apache/shiro/pull/2702 の @potiuk によりプロジェクトのセキュリティ モデルをリンクする AGENTS.md + SECURITY.md を追加
  • [CI] CITATION ファイルを検証するためのプリコミット フックを追加します。 @jbampton により欠落している必須フィールド message を https://github.com/apache/shiro/pull/2717 に追加
  • [CI] https://github.com/apache/shiro/pull/2716 の @jbampton による事前コミットで dependabot.yml を検証するフックを追加
  • 雑用: @lprimak によるブランチ保護ルールを https://github.com/apache/shiro/pull/2701 に追加
  • 雑務: メインからブランチ保護を削除し、追加のブランチを含めるように github ルールセットを更新
  • [CI] すべてのコミット前フックを SHA に固定し、https://github.com/apache/shiro/pull/2730 の @jbampton によってクリーンアップする
  • https://github.com/apache/shiro/pull/2747 の @jbampton により、より多くのファイル タイプ用に EditorConfig を構成します
  • https://github.com/apache/shiro/pull/2766 の @jbampton による CITATION ファイルの更新と展開
  • [#2760] 雑務: https://github.com/apache/shiro/pull/2768 の @lprimak による、より新しいバージョンとメンテナーで hiro.doap ファイルを更新します。

新しい貢献者

  • @potiuk が https://github.com/apache/shiro/pull/2702 に初めて投稿しました

依存関係の更新

  • chore(deps): https://github.com/apache/shiro/pull/2709 の @dependabot[bot] による pre-commit-hooks グループ内の https://github.com/zizmorcore/zizmor-pre-commit を v1.24.1 から 1.25.2 にバンプします
  • chore(deps): https://github.com/apache/shiro/pull/2700 の @dependabot[bot] により org.apache:apache を 37 から 38 に変更
  • chore(deps): https://github.com/apache/shiro/pull/2699 の @dependabot[bot] による com.github.siom79.japicmp:japicmp-maven-plugin を 0.25.6 から 0.25.7 にバンプします
  • chore(deps): https://github.com/apache/shiro/pull/2694 の @dependabot[bot] により slf4j.version を 2.0.17 から 2.0.18 に変更
  • chore(deps): https://github.com/apache/shiro/pull/2697 の @dependabot[bot] により log4j.version を 2.25.4 から 2.26.0 に変更
  • chore(deps): https://github.com/apache/shiro/pull/2698 の @dependabot[bot] によって org.apache.johnzon:johnzon-jsonb を 1.2.22 から 1.3.0 にバンプします
