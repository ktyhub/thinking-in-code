spring-kafka v4.2.0-M2

プレリリース 公開日2026年9月24日 出典spring-projects/spring-kafka 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

春カフカ v4.2.0-M2

:star: 新機能

  • AbstractKafkaListenerContainerFactory では、KafkaAdmin #4654 を構成できるようにする必要があります
  • Deserializer サブクラスに null 可能性を適用する #4653
  • null 可能性アノテーションを適用する #4648
  • Serializer サブクラスに null 許容性を適用する #4647
  • 非同期 @KafkaListener (CompletableFuture/Mono/suspend): 実行中の作業がコンテナの停止を超えて存続し、ダウンストリーム リソースのシャットダウンと競合する #4519
  • ShareKafkaListenerContainerFactory のメッセージ コンバーターのサポートを追加 #4394
  • KIP-714 テレメトリ用の ShareConsumer.clientInstanceId(Duration) を公開 #4325
  • コンテナの開始、停止カウントのメトリクスを追加 #4277
  • ConsumerRecordRecoverer の障害により無限の再処理が発生する #4272

:lady_beetle: バグ修正

  • DefaultShareConsumerFactory #4698 でブートストラップ サーバー サプライヤーを適用します。
  • @KafkaListener の一時停止: コンシューマーはリバランス中に保持するパーティションのフェッチを永久に停止します #4687
  • キューに入れられた共有確認応答を停止時に排出する #4679
  • 非同期リスナー応答成功パスは受信者に失敗を報告しません 観測 #4677
  • copyWithType #4662 で型リゾルバーをコピーします。
  • トピック パターンまたはパーティション リストから構築された場合の start() での ShareKafkaMessageListenerContainer NPE #4660
  • null 逆シリアル化値を検証しません #4651
  • DelegatingByTopicSerialization #4650 でデフォルトのデリゲートを構成します。
  • ShareConsumerAcknowledgment 状態が端末タイプから RENEW に退行する可能性がある #4634
  • DelegatingByTypeSerializer 割り当て可能モードでは、非推移的なコンパレータ #4624 により、より一般的なデリゲートを選択できます。
  • JSON タイプのヘッダーが存在する場合、複数値ヘッダー マッピングでは受信時に値が失われます #4623
  • 保留中のコンシューマウェイクアップにより次のオフセットコミットが中止され、スキップされます #4622
  • ReplyingKafkaOperations sendAndReceive オーバーロードにより、replyTimeout および returnType の不正な null 可能性が公開される #4620
  • setTopicPartitions および setDefaultReplyTimeout の Assert メッセージが間違ったプロパティ名を指定する #4605
  • ソース レコードがない場合にスローされるストリーム例外ハンドラーのリカバリ #4603
  • 共有コンテナは ContainerProperties.clientId #4601 を無視します
  • ShareKafkaListenerContainerFactory.createContainer(String...) は工場出荷時設定を適用しません #4593
  • DelegatingByTopicSerialization #4588 でデフォルトのデリゲートを閉じる
  • DelegatingByTypeSerializer がデリゲートを閉じない #4569
  • autoStartup=false の Kafka リスナーは ApplicationContext.restart() で無条件に開始されます (alwaysStartAfterRefresh=true は最初の更新後の autoStartup を無視します) #4567

:notebook_with_decorative_cover: ドキュメント

  • trusted-packages エラー メッセージ ガイダンスを改善 #4629
  • エラー処理ドキュメントの DeadLetterPublishingRecoverer API 名を修正 #4599
  • テストにおける @RetryableTopic の誤解を招く autoStartDltHandler プロパティ/ドキュメント #4388

:hammer: 依存関係のアップグレード

  • マイクロメーター トレースを 1.8.0-M2 #4715 にアップグレード
  • マイクロメーターを1.18.0-M2 #4714にアップグレード
  • リアクターを2026.0.0-M2 #4713にアップグレード
  • spring-data-bom を 2026.1.0-M2 #4712 にアップグレードします
  • スプリングフレームワークを7.1.0-M2 #4711にアップグレード
  • com.fasterxml.jackson:jackson-bom を 2.21.6 から 2.22.2 にバンプ #4695
  • org.apache.logging.log4j:log4j-bom を 2.25.5 から 2.26.1 にバンプ #4694
  • org.jetbrains.kotlinx:kotlinx-coroutines-reactor を 1.10.2 から 1.11.0 にバンプ #4693
  • 9.4.1 から 9.7.1 への Gradle ラッパーのバンプ #4692
  • com.github.spotbugs:spotbugs-annotations を 4.9.8 から 4.10.4 にバンプ #4691
  • kotlin バージョンを 2.3.21 から 2.4.20 にバンプ #4690
  • org.slf4j:slf4j-api を 2.0.18 から 2.0.19 にバンプ #4671
  • com.fasterxml.jackson:jackson-bom を 2.21.5 から 2.21.6 にバンプ #4586
  • バンプ tools.jackson:jackson-bom を 3.2.1 から 3.2.2 に #4585
