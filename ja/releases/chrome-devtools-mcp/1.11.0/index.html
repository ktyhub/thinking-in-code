クロム-devtools-mcp クロム-devtools-mcp-v1.11.0

1.11.0 (2026-10-15)

🎉 機能

  • ファイルを拒否する --file-navigations フラグを追加: URL ナビゲーション (#2853) (54cae57) *analyze_heapsnapshot_contexts MCP ツールを追加 (#2791) (190aeee) *ignoreCache オプションを Performance_start_trace に追加 (#2931) (3467d40)
  • maxNameLength 切り捨てオプションを Compare_heapsnapshots に追加 (#3098) (1e1c53e)
  • Compare_heapsnapshots にページネーションを追加 (#3140) (daebfd1)
  • config: 構成ファイルの変更を監視するために ConfigWatcher を追加します (#3139) (9171f77)
  • 事前定義された場所で構成ファイルを検出します (#2876) (02c0112)
  • デフォルトで有効になっている ffmpeg フリーのスクリーンキャスト ツールを実装 (#3123) (8953ea5)
  • テキスト スナップショットの StaticText ノイズを軽減 (#2895) (4441325)
  • 入力アクションによって開かれたレポート ページ (#2679) (28fb230)
  • CLI と設定ファイル (#2849) (bdeb70d) をマージした後に設定のデフォルトを解決します
  • 失敗した監査と DOM ノードを lighthouse_audit からインラインで返します (#2930) (241fba5)
  • テキスト スナップショット内の冗長データをさらにスキップ (#2896) (b2f522c)
  • サードパーティ開発者ツールで WebMCP ツールのデバッグをサポート (#2900) (0db519f)
  • 追加の CSS メディア機能のエミュレーションをサポート (#2929) (69524f0)
  • ローカル ファイルからのスクリプトの評価をサポート (#2606) (9cf47a4)
  • get_heapsnapshot_details で切り捨てをサポート (#3137) (f827e06)
  • 長い名前はデフォルトで 100 文字に切り詰められます (#2893) (5ddb0a3)

🛠️ 修正

  • ダウンスケールされたスクリーンショットのスクロール オフセットを考慮します (#2685) (830c693)
  • 既存のブラウザに接続するときに --categoryExtensions を許可します (#3041) (d250bc5)
  • コマンドが失敗した場合に CLI を停止できるようにする (#3088) (77e238e)、終了する #2982
  • 実行時のタイトルのフェッチを回避します (#2883) (04195d1)
  • chrome-devtools CLI (#2819) (9624e64) の設定サポートの改善
  • クランプ非同期スタック トレース セパレータ繰り返しカウント (#3035) (93e06ab)、クローズ #3031
  • cli: - で始まる位置の値をツール (#3084) (9de05ae) に渡し、#2984 を閉じます
  • コレクター: Service Worker をサブスクライブするときに一時的なターゲット エラーを無視します (#2888) (551dd6c)
  • デーモン: ブラウザーのシャットダウンをバインドし、停止時の watchFile タイムアウトを回避します (#2887) (f3db5e7)
  • デーモン: フォールバック ソケットをプライベート ランタイム ディレクトリに保持します (#2766) (871a37e)
  • デーモン: PID ファイルをアクティブとして扱う前にプロセス ID を検証する (#3109) (b608bed)
  • ツール呼び出しが 60 秒を超える場合は、正常なブラウザを閉じないでください (#3149) (39c7db1)
  • ヒープ スナップショット内の集計 ID が決定的であることを確認します (#2923) (e918c47)
  • McpContext ログおよびエラー内の client が提供する値をエスケープ (#2832) (efb0d02)、クローズ #2831
  • ブラウザー接続が切断された後にスタックするツール呼び出しでフェイルファスト (#2699) (2a7ef50)
  • サードパーティツールの結果シリアル化を強化 (#2892) (4418a7b)
  • CLI モードでは明示的な --allowUnrestrictedPaths=false を尊重します (#3040) (61fc362)
  • スリム応答にエラーが含まれます (#3085) (ee38097)
  • 入力: Upload_file の単一ファイル入力で複数のファイル パスを拒否します (#2995) (#3135) (e650843)
  • 新しいページのタイトルをリストします (#3103) (e717082)
  • メモリ: take_heapsnapshot の矛盾するページネーション オプションを拒否します (#3002) (#3131) (508126c)
  • ネットワーク: リダイレクト全体で URL ポリシーを適用する (#2767) (274cd4c)
  • 接続時に categoryExtensions をターゲット フィルターに渡します (#3047) (4e90238)
  • パフォーマンス: アクティブなトレースがない状態で Performance_stop_trace が呼び出された場合にエラーを報告します (#3001) (#3126) (e170384)
  • ブラウザーの再接続時に HeapSnapshotManager を保持します (#3025) (64388c6)
  • 本文が利用できないことを報告する代わりに、失敗したresponseFilePath書き込みエラーを伝播します (#2957) (#3119) (3cee3bd)
  • pwa: 起動時に最初のナビゲーションを待機し、一時的なインストール エラーを再試行します (#2889) (63010cb)
  • ページのデバイス ピクセル サイズでスクリーンキャストを記録します (#3155) (62e2aa4)
  • --blockedUrlPattern/--allowedUrlPattern ホスト名正規表現グループを拒否 (#2796) (ae0aaef)
  • JSON 配列を 3p および WebMCP ツール パラメーターとして拒否 (#2785) (c14e616)
  • URL パターン内の名前付きグループを拒否 (#2857) (5b2c6f9)
  • 非正の --viewport ディメンションを拒否 (#2781) (0ef528a)
  • 非正のサイズページのサイズを拒否 (#2784) (6ab6d35)
  • 明示的なワークスペースを持つ無制限のパスを拒否します (#2858) (45c1c6c)
  • close_page の最後のページ ガードの前に不明なページ ID をレポート (#3042) (bdc7e24)
  • ライトハウス カテゴリのスコアを丸め、スコアのないカテゴリを n/a として表示 (#2924) (7007680)、クローズ #2915 #2916
  • 空の filePath を空の文字列 (#2836) (adfc1ff) ではなく未定義に設定し、#2825 を閉じます *execute_webmcp_tool で WebMCP ツールの例外を表示 (#3107) (d80d22e)、クローズ #2975
  • URL パターンの一部 ipv4 (#2859) (c87d190)

📄 ドキュメント

  • VS コード拡張の反重力 MCP セットアップを明確にする (#2855) (12e13ca)
  • --no-javascript-評価の範囲を明確にする (#3100) (0c67cd5)

  • SECURITY.md 内の trusted ホスト環境の文書 (#3125) (1352207)

  • 報告されたいくつかの問題を修正 (#3099) (d5d2f08)
  • 評価スクリプトの serviceWorkerId パラメータを含めます (#3015) (#3129) (0623434)
  • 実行間でキャッシュされるヒープスナップショットについて言及 (#3045) (f08dbe1)、クローズ #2976
  • スキル: lighthouse_audit 呼び出しから無効な OutputDir フラグを削除します (#3013) (#3130) (7754226)
  • get_css_styles ツールのドキュメントと SKILL を更新 (#2824) (3c12a91)
