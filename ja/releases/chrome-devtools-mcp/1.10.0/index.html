chrome-devtools-mcp v1.10.0

マイナー 公開日2026年9月23日 出典ChromeDevTools/chrome-devtools-mcp 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

クロム-devtools-mcp クロム-devtools-mcp-v1.10.0

1.10.0 (2026-09-23)

🎉 機能

  • CSS フォーマッタ クラスを追加 (#2707) (f0b5fa4)
  • get_css_style ツールを追加 (#2612) (4454ae0)
  • パフォーマンス: 大規模な記録用のチャンク トレース バッファー パーサー (#2721) (23b9a48)
  • get_css_styles ツールのデフォルトの pageSize と pageIdx を設定 (#2799) (dc9d14d)
  • サポート設定ファイル (#2661) (314a5fa)
  • telemetry: 最後のツール呼び出しの日付を保持します。 (#2705) (c54a493)
  • テレメトリ: client 名のサニタイズされたバージョンを記録しています (#2757) (55fbc57)
  • テレメトリ: hermes client の使用状況を報告します。 (#2703) (fb47e6c)
  • CSS フォーマッタ クラスを更新して AtRule、PositionTryRule、PropertyRule、FunctionRule (#2717) (d4a0620) を追加します
  • CSS フォーマッタ クラスを更新して、継承されたルールを追加します (#2715) (3d7e7bb)
  • CSS フォーマッタ クラスを更新して、一致したルールを追加します (#2713) (8c8616f)
  • CSS フォーマッタ クラスを更新して疑似要素 (#2716) (df1469a) を追加します
  • CSS フォーマッタを更新してキーフレーム ルールを追加 (#2718) (cdc365c)

🛠️ 修正

  • ナビゲーションごとのバインドされた ConsoleCollector 保持 (#2773) (e98a3ca)
  • cli: 開始時に明示的な false オプションを転送 (#2702) (d9a8cb6)
  • config: 構成強制のため生の値を保存します (#2747) (906c83b)
  • 要求されない限り、Puppeteer ログをファイルに記録しません (#2743) (4fbfbc4)
  • root として実行することによって引き起こされる起動エラーについて説明します (#2634) (9d29223)
  • 入力ツールのアクション中に開かれた JavaScript ダイアログを処理します (#2794) (266112b)
  • パフォーマンス: 解析ごとにトレース エンジン モデルをスコープすることでメモリ リークを防止します (#2720) (d05cbc0)
  • 同じドキュメントのナビゲーション間でコンソール履歴を保存 (#2676) (aa25562)
  • 入力ツールのアクションで基礎となるエラー メッセージを保持 (#2792) (6e47dbb)
  • エミュレートされたUserAgentを設定し、lighthouse_auditでfinalDisplayedUrlを使用します (#2795) (941f82a)
  • WaitForHelper.ts のタイムアウト (#2772) (dc1d055)

📄 ドキュメント

  • FLUJO client 構成を追加 (#2690) (65a679e)
  • カテゴリが正しく設定されていない問題を修正 (#2807) (2250cdc)
  • 非ブール値のデフォルトを修正 (#2744) (342d243)
  • ページ ルーティング オプション名を更新します (#2748) (8939965)
  • get_css_styles ツールを使用するように chrome-devtools の SKILL を更新 (#2760) (421011e)

🏗️ リファクタリング

  • ツールを登録しない代わりに無効にする (#2636) (b455469)
  • BrowserManager クラスでブラウザを抽出 (#2787) (3228f44)
  • MCP SDK を v2 に移行 (#2408) (da3c406)
  • コメントの書式設定を CommentFormatter クラスに移動 (#2719) (e3cded0)
  • SDK v2 (#2771) (61780c7) を準備します
  • gen スクリプトを簡略化します (#2793) (5068584)
  • 呼び出しタイプを統一し、タイプセーフティを確保する (#2659) (882f93e)
