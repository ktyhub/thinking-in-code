chrome-devtools-mcp v1.7.0

マイナー 公開日2026年8月10日 出典ChromeDevTools/chrome-devtools-mcp 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

クロム-devtools-mcp クロム-devtools-mcp-v1.7.0

1.7.0 (2026-08-10)

🎉 機能

  • localhostをチェックするユーティリティ関数を追加します。 (#2454) (c5ebf9e)
  • get_heapsnapshot_object_details MCP ツールを追加 (#2374) (8432cb9)
  • スナップショット概要でネイティブ コンテキストを出力 (#2375) (f78a911)
  • ネイティブ コンテキストによるヒープ スナップショット オブジェクトのフィルター (#2377) (76fd242)
  • テレメトリ: devtools データをログに記録します。 (#2460) (df2c753)
  • テレメトリ: ツール呼び出しごとに is_devtools_open をログに記録します。 (#2445) (6f60eab)
  • telemetry: ツール呼び出しがローカルホスト上で行われたかどうかを報告します。 (#2455) (6398b7e)
  • 灯台を 13.4.1 (#2398) (745ffe7) に更新します

🛠️ 修正

  • バインドされたナビゲーションごとのネットワーク リクエスト保持 (#2435) (b08c73c)
  • cli: セッション ID を検証します (#2475) (5ca9121)
  • cli: cli とデーモンの間のバージョンの不一致について警告します (#2461) (3afc44d)
  • daemon: 引数のシリアル化と遅延デーモンの起動でハイフンでつながれたブラウザ フラグを保持します (#2405) (d79f3ba)
  • コンテキストのティアダウンでヒープ スナップショット ワーカーを破棄 (#2428) (f245c76)
  • CDP セッションがなくなったときに同期的にスローしない (#2466) (ba4fe3e)
  • ダイアログが処理された場合はスローしない (#2437) (574c320)
  • ビューポートがエミュレートされていない場合のビューポートのスクリーンショットを縮小する (#2380) (39c4140)
  • デーモンのライフサイクルを改善 (#2360) (3ee6a27)
  • ファイル書き込みを改善 (#2447) (1da4bb0)
  • get_tab_id のテキスト応答にタブ ID を含めます (#2381) (dcbaf49)
  • メモリ: ロードが失敗したときにヒープ スナップショット ワーカーを破棄します (#2449) (744738d)
  • パフォーマンス: start_trace セットアップが失敗したときにトレース実行フラグをリセット (#2420) (40240c0)
  • #2443 (#2462) (4c80ce4) の後の回帰
  • maxRetainedSize 列の名前を変更 (#2402) (75c7048)
  • スクリーンショット: take_screenshot の後に要素ハンドルを破棄 (#2422) (fffb40e)
  • ソースマップの遅延読み込みを切り替えます。 (#2486) (8028bfe)
  • 待機: アクション中にダイアログが開いたときの 180 秒のミューテックス ストールを回避します (#2427) (b4e8f74)

📄 ドキュメント

  • devin cli のインストール手順を README に追加 (#2361) (45262c0)
  • ユーザー データ ディレクトリのドキュメントを修正 (#2473) (5ddbffd)
  • スキル: ネイティブ MCP ツールを使用するようにメモリ リーク デバッグ スキルを更新します (#2436) (99bd90a)
  • カテゴリExperimentalWebmcp の Chrome 要件を更新 (#2163) (354458e)
  • security.md を更新 (#2362) (5012b07)

🏗️ リファクタリング

  • McpResponse.handle (#2392) (348975d) をクリーンアップします
  • Explicit リソース管理の導入 (使用) (#2443) (5b25370)
  • ツールグループを移動 (#2365) (2d944f9)
  • Puppteer Mutex (#2444) (775ea2d) を再利用します
  • わかりやすくするためにメソッドの名前を変更 (#2442) (dc23bcd)
  • デストラクターを使用して呼び出しを短縮します (#2376) (77e1d3f)
