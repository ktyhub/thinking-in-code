chrome-devtools-mcp v1.8.0

マイナー 公開日2026年8月25日 出典ChromeDevTools/chrome-devtools-mcp 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

クロム-devtools-mcp クロム-devtools-mcp-v1.8.0

1.8.0 (2026-08-25)

🎉 機能

  • get_heapsnapshot_edges にパラメータを追加 (#2561) (b58c613)
  • オプションのスタック トレースを list_console_messages に追加 (#2505) (85c73a0)
  • PWA 自動化ツールを追加 (#2430) (0ea5c8d)、閉じます #2270
  • query_heapsnapshot MCP ツールを追加 (#2553) (fadbf41)
  • Evaluate_script が安定した DOM 待機をスキップできるようにします (#2346) (781e2fb)
  • デフォルトでページスコープのツールに pageId が必要になるようにします (#1777) (50a16fa)
  • get_heapsnapshot_summary のコンテキストによって維持されるレポート メモリ (#2570) (4103808)
  • エッジの自己サイズと保持サイズを表示 (#2529) (2a7eb76)
  • Upload_file による複数のファイルのアップロードをサポート (#2257) (c8a2393)
  • 人間が判読できるサイズの範囲を使用します (#2589) (61e312f)

🛠️ 修正

  • cli: chrome-devtools の起動デフォルトを調整 (#2597) (c6cff23)
  • cli: CLI で --memoryDebugging を必要とするツールを有効にします (#2585) (1c92ba0)
  • clI: CLI 内の JSON の代わりにエラー メッセージのみを出力します (#2580) (fce756a)
  • cli: CLI スキルを更新します (#2569) (0e108ea)
  • 以前に選択したページがなくなった場合は、ページ URL を追加しないでください。 (#2588) (6506425)
  • ルート/リストでのツール呼び出しをブロックしないでください。client の応答が遅い (#2477) (d93e667)、クローズ #2476
  • パフォーマンス トレースで無効化追跡を有効にしない (#2500) (f00778d)、クローズ #2499
  • リモート ブラウザーのローカル ファイルを検証しません (#2573) (c0a7417)
  • デバッガ ステートメントが devtools によって確実にスキップされるようにします (#2555) (f8572f0)
  • フォーマッタのバグを修正 (#2552) (b247315)
  • ヘルパー待ちの不安定さ (#2541) (12f989a)
  • 入力: 空の値のオプションをテキストで選択 (#2501) (b969c45)
  • ページ ID ルーティングの新しいフラグがメトリクス json (#2613) (6dba5c7) の最後に移動されました
  • 人形遣いのアクションはシンボリックリンクをたどらなくなります (#2592) (1bac85c)
  • ファイル拡張子として .heapsnapshot (または .heaptimeline) が必要です (#2579) (b750168)
  • HiDPI ディスプレイのスクリーンショット境界を尊重する (#2536) (ebf58f2)
  • 不明な CLI 引数を警告します (#2577) (e450369)

📄 ドキュメント

  • Bob MCP client 構成を追加 (#2364) (5c16940)
  • 修正コマンド (#2546) (9331b63)

🏗️ リファクタリング

  • validatePath が解決された URL を返すようにします (#2572) (57adfa9)
  • 設定ファイルをビンから移動 (#2578) (5d02839)
  • ファイルをその用途をより適切に表すフォルダーに移動します (#2564) (06b7a5c)
  • パフォーマンス: DevTools のデフォルトのトレース カテゴリを使用します (#2571) (cb89762)
  • デバッグを NodeJS ネイティブに置き換えます (#2562) (f44f3c6)
