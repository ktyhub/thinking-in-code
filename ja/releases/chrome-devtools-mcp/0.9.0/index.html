chrome-devtools-mcp v0.9.0

マイナー 公開日2025年10月22日 出典ChromeDevTools/chrome-devtools-mcp 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

クロム-devtools-mcp クロム-devtools-mcp-v0.9.0

0.9.0 (2025-10-22)

🎉 機能

  • クロード マーケットプレイスとプラグイン json (#396) (0498611) を追加します
  • コンソール メッセージ ツールにフィルターとページネーションを追加 (#387) (15d942c)
  • WebSocket エンドポイントとカスタム ヘッダーのサポートを追加 (#404) (41d6a10)
  • ツール カテゴリの構成を許可します (#454) (0fe2b8a)
  • 以前のナビゲーションを MCP に公開します (#419) (165cf9c)
  • コンソール メッセージの以前のナビゲーションをサポート (#452) (6f24362)
  • ネットワークリクエストの安定した ID をサポート (#375) (f4d7b49)
  • 冗長スナップショットをサポート (#388) (d47aaa9)
  • 詳細な単一のコンソール メッセージを取得するツール (#435) (9205593)
  • ネットワーク リクエストのクエリには安定した ID を使用します (#382) (579819b)

🛠️修正

  • フレームでの評価を許可 (#443) (053f1f8)
  • 評価スクリプトのより適切な表現 (#392) (2313fda)
  • リクエストおよびレスポンスボディが利用できない場合を示します (#446) (7d47d6b)
  • 非エラータイプのページエラー (#442) (b6b42ec)
  • 3 つ未満のナビゲーションでデータを正しく取得します (#451) (4c65f59)

📄 ドキュメント

  • Qoder の命令を追加 (#386) (d8df784)
  • VM からホストへのリモート デバッグ回避策を追加 (#399) (9f9dab0)
  • Copilot CLI 命令を更新 (#423) (c7733a8)

♻️ 雑用

  • すべての依存関係をまとめてバンドルします (#450) (914b980)
  • バンドル モデルコンテキストプロトコル-sdk (#409) (6c8432b)
  • バンドル puppeteer-core (#417) (b443033)
  • zod を modelcontextprotocol/sdk (#414) (800e7e8) とバンドルします
  • クリーンアップデータの取得 (#441) (5c871c3)
  • 破棄されたページのリスナーを破棄します (#318) (76d5e94)
  • 共通ページネーション タイプを抽出 (#415) (29fd602)
  • 最後の 3 つのナビゲーションを PageCollector に保存します (#411) (b873822)
  • 要求 ID には別の形式を使用します (#380) (78bf66a)
