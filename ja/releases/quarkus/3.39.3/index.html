  • #56301 - aesh を 3.17.5 にアップグレードし、AeshLauncher テスト フレームワークを改善します

  • #56357 - [3.39] ドキュメント改善のバックポート

  • #56391 - ドキュメントの例の番号付き吹き出しリストを修正

  • #56395 - PeriodicMetricReader エクスポーターの警告を抑制します

  • #56408 - サポートされている API のロギング ガイドを更新します

    • #56424 - Quarkus REST: パスを持つ抽象リソースがパスのないサブクラスによって拡張される場合のネイティブ モードを修正しました

    • #56429 - Websockets-next ガイドのタイプミスを修正

    • #56449 - ドキュメント内の残りのコールアウト リストの配置の問題を修正
    • #56470 - [3.39] デカップリング タイプの検出と反射のない Jackson シリアライザーの生成
    • #56480 - 修正: docs-preview.sh のデフォルト ポートを 8042 に揃えます

    • #56489 - SBOM コンポーネントと製品の帰属
    • #56493 - 証明書のリロードでは、起動スナップショットと比較することにより、復元された証明書がスキップされます
    • #56497 - [3.39] SBOM CPE 帰属
