#FastGPT v4.17.1

📦 アップグレード ガイド

ミラーアップデート

  • fastgpt-app (FastGPT メイン サービス) イメージ タグを更新します: v4.17.1
  • fastgpt-pro (FastGPT 商用版) イメージ タグを更新します: v4.17.1
  • fastgpt-plugin イメージ タグを更新: v1.1.4
  • AI プロキシ イメージ タグを更新: v0.7.3

アップグレードスクリプト

このアップグレードには次の自動スクリプトが含まれています

  1. アプリケーションのリソース権限スナップショットをバックフィルし、レガシー V1 アプリケーションとバージョン データをクリーンアップして、アプリケーションの正式バージョンを確認します。移行タスクはサービスの起動をブロックせず、進行状況と失敗の記録はシステム アップグレード タスクで表示できます。
  2. 互換性のあるチャネルの推論マッピングを有効にする: 既存の AIProxy OpenAI プロトコル チャネルの map_reasoning_to_reasoning_content: true 応答フィールド変換を有効にして、深層思考モデル (DeepSeek-R1 など) の思考コンテンツ フィールドの互換性問題を解決し、チャネルの元の構成を保持します。この項目で構成されたチャネルは繰り返し更新されず、移行タスクによってサービスの起動がブロックされることはありません。
  3. ナレッジ ベースのタグ データをアップグレードします。既存のコレクション タグを型付きタグに移行し、重複したタグ定義をクリーンアップします。移行タスクはサービスの起動をブロックしません。
  4. チーム メンバー名設定マークのバックフィル: 歴史的なチーム メンバーの isSetMemberName マークをバックフィルします。所有者は常に設定済みとしてマークされ、ログイン ユーザー名と同じ非所有者メンバー名は補足が必要としてマークされます。移行タスクはサービスの起動をブロックしません。

管理者入口調整

商用バージョンの管理インターフェイスは、FastGPT メイン アプリケーションに統合されています。 rootユーザーはログイン後、「管理者」ポータルからシステム構成、運用管理、ライセンス認証・更新ページにアクセスできるようになります。システム構成は /admin/settings/* にあり、システム ツールとシステム モデルはそれぞれ /admin/resources/tool と /admin/resources/model にあります。旧道はもう整備されていません。

FastGPT Pro サービスは引き続き保持する必要があります。カスタム ヘルス チェックが Pro 用に構成されている場合は、検出パスを /api/health に調整してください。

🚀 新しいコンテンツ

  1. アプリケーションのリリース バージョンでは、新しいリソース許可スナップショットと実行時認証が追加されます。静的リソースはリリース時のスナップショットに基づいて検証され、動的リソースは実際に実行されているユーザーに基づいて検証されます。共同開発したアプリケーションで実行時の権限が分散されているために正しく計算されない問題を解決します。
  2. ナレッジ ベースのタグ管理とフィルタリングを追加し、型指定されたタグ値のサポート、コレクション タグのメンテナンス、およびワークフローとエージェント V2 ナレッジ ベースの検索でのタグ条件の使用をサポートしました。
  3. パスワード変更はサードパーティ認証をサポートしており、パスワード変更の承認、検証、およびパスワード更新プロセスが統合されています。
  4. Agent V2 のナレッジ ベース検索はナレッジ ベースの引用をサポートしており、この検索によって返された実際の参照コンテンツをチャットに表示できます。
  5. アプリケーションはトークン統計ボードを追加し、使用記録にはトークンの消費量も同時に表示されます。
  6. アプリ、エージェント、スキル、ツール、およびデータセットのリストは、バッチ選択、移動、削除をサポートし、管理権限に基づいて操作可能なリソースを制限します。
  7. 管理者機能は本体アプリケーションに統合されており、ライセンス認証に応じて管理メニューや機能状態が表示されます。
  8. ファイル読み取りノードのデバッグは、ファイルのローカル アップロードとファイル リンクの追加をサポートし、アップロードが不完全な場合やファイルが異常な場合の操作を防ぎます。
  9. 新しいナレッジ ベースのファイル レベルのアクセス許可 (コレクション レベルのアクセス許可): コラボレーターはファイル/フォルダーごとに個別に構成でき、継承と独立状態、回復の継承、所有権の譲渡がサポートされています。スイッチはデフォルトでオフになっており、既存のナレッジ ベースの動作は変更されません。オンにすると、リスト、詳細、および検索のリコールがファイルのアクセス許可に従って 1 つずつ認証され、オフにすると、すべてのファイルのアクセス許可設定がクリアされます。詳細については、ナレッジ ベース ファイル レベルのアクセス許可 を参照してください。
  10. システム モデルの健全性ステータスの検出と監視: 管理者は、システム モデルの健全性ステータスのスケジュールされた検出を有効にし、48 時間のステータス チャートによる視覚的な監視を提供し、モデル ステータスが変化したときに Webhook 通知をトリガーするためのアラーム Webhook とトークンの構成をサポートできます。詳細については、「システム モデルの構成と監視」(../../config/model/intro) を参照してください。
  11. 初回ログインの To-Do およびガイダンス プロセス: 初回ログインでは、チーム メンバーの表示名を入力する必須要件がサポートされ、保留中のチームへの招待を自動的にプロンプ​​トおよび処理し、システムのアナウンスやエンタープライズ認定プロンプトなどのフォローアップ ポップアップを均一に配置します。
  12. システム モデル識別子の変更: 管理者は、安定版 modelId を通じてシステム モデルのモデル識別子 (model) を直接変更することをサポートし、モデル マッピングと関連チャネルのリストを同時に自動的に更新します。
  13. OFD ファイル解析をサポートします。
  14. TokenDance 統合 AI API ゲートウェイ アクセスのドキュメントと例を追加しました。
  15. SSO パスワード ポリシーの追加: 管理者は、SSO 名前空間アカウントがプラットフォーム パスワードを使用してログインおよびパスワードを変更することを禁止できます。ログイン ページには、利用可能な認証方法に応じた入り口が表示されます。
  16. パーソナル ワークフロー ツールの構成は最新のリリース バージョンをサポートしており、アップデートの適用後にツールのバージョンを手動で調整する必要はありません。
  17. 新しい off ノード入力タイプがワークフローに追加されました。これは、パラメーターをサードパーティ インターフェイスに渡すように特別に設計されています。インターフェイスはこの入力をレンダリングしませんが、パラメータ定義、デフォルト値、検証を完全に保持し、エージェントとしてパラメータを自動生成することは禁止されています。
  18. ワークフロー ナレッジ ベース検索は、文字列 (string) タイプのラベル フィルタリングをサポートします。構造化テキストと参照変数のフィルタリングをサポートし、検索レイヤーで対応する一致ロジックを実行します。
  19. OpenAPI オープン ドキュメントは、「基本機能 - モデル管理」カテゴリとインターフェイスを追加し、パブリック モデル リスト、メンバーが利用可能なモデル リスト、およびバッチ モデル詳細インターフェイスを開き、API キーを介した現在利用可能なモデルのクエリをサポートします。
  20. 新しい環境変数 DISABLE_MARKETPLACE を追加しました (デフォルトは false): システム ツールでのプラグイン マーケットのインストール入り口の非表示をサポートし、ローカル ファイルのインポートのみを保持します。
  21. 管理者によって作成されたユーザー インターフェイスは、メンバー表示名 (memberName) の明示的な渡しと保存をサポートしています。
  22. ナレッジ ベース、スキル、アプリケーションに使用方法の参照が追加され、リソースがどのアプリケーションで参照されているかを簡単に確認できるようになりました。

⚙️ 最適化

  1. ナレッジベースコレクションのバッチ操作バー、ラベル間隔、ラベル管理の空ステータスを調整します。
  2. アプリ ログのユーザー フィルタリングが、ロード前にフィルター ボックスを開くように変更され、サーバー側の検索とページングをサポートし、固定の 100 ユーザー制限が削除されました。
  3. 知識ベース検索ノードは、レコード再配置前の想起候補セットをサポートしており、検索結果と再配置結果の比較が容易になります。 RETRIEVAL_RESULTS_LIMIT を通じて記録の上限を設定します。デフォルトでは記録しません。
  4. モデル セレクターは、ベータ モデルをリストの最後に配置します。
  5. ナレッジベース内のデフォルトのイメージモデルがクリアされた後に自動的に埋め戻される問題は、イメージモデルを構成しなくても許可されます。
  6. 管理者のシステム設定フォームの対話とレイアウト設計を再構築して、より明確な分類ナビゲーションと設定保存エクスペリエンスを提供します。
  7. 製品版ライセンスのアクティベーションは、永久/無制限の有効期限をサポートし、有効期限のないライセンスの表示と検証を改善します。
  8. 中国語環境での大きな数値の書式設定を最適化し、数万や十億などのローカライズされた単位を正しく表示します。
  9. テーブルはデフォルトで水平スクロールを有効にし、左右の余分なパディングを削除します。長いテーブルは狭い画面でも閲覧しやすくなります。
  10. ワークフロー配列型変数が単一オブジェクトの JSON 文字列を受け取ると、それは通常のオブジェクトとして解析され、ループ ノードと並列ノードが「配列ではありません」というエラーを報告し、自動的に単一要素の配列にラップします。
  11. テンプレートから追加されたモデル リストは、モデル プロバイダー (プロバイダー) の事前設定された順序での並べ替えと戻りをサポートし、インターフェイス モデルのグループ化と表示をきちんと一貫して保ちます。
  12. セッション タイトル生成ルールを最適化します。ファイルをアップロードするときのみ、または最初のラウンドで自動実行をトリガーするときに、ローカライズされた固定タイトル (「ファイルのアップロード」/「自動実行」など) の生成をサポートします。後続のラウンドで質問テキストを入力すると、新しい質問タイトルで自動的に上書きされます。ユーザー定義のタイトル (customTitle) は最も高い優先順位を持ち、自動的には上書きされません。セッション履歴、ログ、エクスポートのタイトル表示とカバーロジックを統一し、空の値やプレースホルダーをタイトルとして保持することを禁止します。
  13. マルチモーダル メッセージのトークン推定の最適化: マルチモーダル コンテンツ (写真、オーディオ、ビデオ、ファイル) は、トークン計算ワーカーに入る前に固定プレースホルダーを使用して、base64、メディア URL、またはバイナリ データを置き換え、トークン計算のタイムアウトや推定の重大な逸脱を引き起こす長い URL や大きなバイナリ データを回避します。
  14. パスワード取得検証プロセスを最適化します。グラフィカル検証コードを開いたり、インターフェイスを要求したりするときに、不正なアカウントがパラメータ検証エラーを引き起こすのを避けるために、検証コードを送信する前に、入力されたアカウントが電子メールまたは携帯電話番号の形式と一致するかどうかを検証します。

  37. 一般的なコンカレントタスクスケジューラbatchRunのいずれかのタスクが失敗した後、他のコンカレントスロットが新しいタスクを受け取り続け、エラーが報告された後、新しいタスクの割り当てが即座に終了される問題を修正しました。
  38. CHECK_INTERNAL_IP=true イントラネット防御が有効になっている場合、チャット ログのプッシュ、DingTalk トークンの取得、サードパーティの API ナレッジ ベースの同期、カスタム PDF 解析などのシステム構成のイントラネット サービスが誤って傍受される問題を修正しました。
  39. レガシー V1 アプリケーションと、非 ObjectId およびその他の違法なリソース参照を含む不正なリソース参照により、アプリケーション リソースのバックフィル移行中にエラーが発生し、移行中にレガシー V1 アプリケーションとその関連バージョン、会話、および外部リンクのカスケード クリーンアップが発生する問題を修正しました。
  40. 検索語強調表示コンポーネント (HighlightText) が、エスケープされていない検索語を直接使用して正規表現を構築し、括弧 (、[、c++ などの特殊文字を入力するとページがクラッシュする問題を修正しました。
  41. Web リンクをナレッジ ベースにインポートするときに、相対パスを含む画像とリンク (./、../ など) が完了せず、インポート後に画像と無効なリンクが表示されなくなる問題を修正しました。
  42. OpenAI 互換インターフェイスが履歴メッセージをマージしたときに、複数のシステム メッセージの順序が逆になり、メッセージが元の相対順序でモデルに渡されるようにする問題を修正しました。
  43. Markdown リンクのセキュリティ検証中に、UTF-8 パーセント以外のエンコード (GBK エンコードのクエリ パラメータなど) を含む合法的なリンクが安全でないリンクと誤判断され、クリックできなくなり、画像が表示されなくなる問題を修正しました。
  44. ドキュメント解析（Docx、XLSX が保持する HTML テーブルなど）の埋め込み HTML <img> Base64 画像が自動的にアップロードおよび保存されず、チャンク内に巨大な Base64 文字列が残る問題を修正しました。
  45. ワークフロー条件判定器 (If/Else) が非文字列値の「開始条件」または「終了条件」を使用して trim is not a function を報告し、ノードの実行時にエラーが発生する問題を修正しました。
  46. 一部のナレッジ ベース ファイル インポート ポータルが S3 オブジェクト キーを認証されたリソースにバインドしない問題を修正しました。
  47. 外部ドキュメント解析サービスが構成され、xlsx 解析が有効になっている場合、ナレッジ ベース テンプレートとバックアップ インポートが外部解析にルーティングされ (Markdown のみが返される)、構造化ヘッダーとテーブルの検証が失敗し、「ファイル形式エラー」が報告される問題を修正しました。テンプレートとバックアップのインポートでは、システムの組み込み解析を使用することが強制されます。

🛠️ コードの最適化

  1. モデル テスト インターフェイスは、チャネルを構成せずにリクエストをサポートします。
  2. 新しいピン インターフェイスがアプリケーションとフォルダーに追加され、リスト インターフェイスにより必要に応じてピンの並べ替えが可能になります。
  3. ナレッジ ベース インターフェイスは、ヘッダー、フッター、付録、画像認識、チャート解析結果の保持を制御できる外部文書解析構成をサポートします。これは、外部解析サービスが有効になっている場合にのみ有効になります。
  4. スケジュールされたタスクと分散ロック アーキテクチャ (checkTimerLock) を再構築します。モデル ステータス検出のコア ロジックはサービス層で統合されており、複数のノードの同時検出を回避します。
  5. システムの機密データの暗号化と復号化のパフォーマンスを最適化し、scrypt 派生キーをキャッシュし、ブロックする CPU 情報クエリを削除します。メイン アプリケーションの Dockerfile ベース イメージを debian-slim に切り替えます。
  6. hono、multer、nodemailer などのコア依存関係のバージョンをアップグレードします。
