#ナマケモノv0.1.912-beta

ハロウィン👻がやってきました。 10 月まで、サイドバーの トリック オア トリート 行を開くと、11 のハロウィーン テーマ、不気味な挨拶、いくつかのクモとコウモリが表示されます。

このリリースでは、最初の起動、Linux ツールの呼び出し、モデルの読み込みも高速化され、互換性のある微調整ジョブをマルチ LoRA とともにトレーニングします。

ハイライト

  • トリック オア トリート: 🎃 新しいハロウィーン テーマ - 11 月 1 日まで
  • Unsloth の高速化: 初回起動が 2 倍高速になり、さらにツール呼び出し、モデル リスト、データセットの準備、MiniMax-H3 ロードが高速化されます。
  • マルチ LoRA バッチング: 最大 4 つの互換性のあるキューに入れられた微調整ジョブが一緒にトレーニングされます
  • SGLang 思考 + 自動圧縮: 再開と JSON 出力が vLLM と SGLang でも動作するようになりました
  • ブラウザ使用スイッチ: モデルが新しいタブ ページから内蔵ブラウザを制御できるようにします。

最適化

  • セットアップで Python ファイルがプリコンパイルされるようになったため、最初の起動が約 2 倍速くなりました。
  • Linux では、ツール呼び出しは 2 GB サーバー プロセスで 84 ～ 174 ミリ秒かかるのではなく、1 ～ 2 ミリ秒で開始されます。
  • キャッシュされたモデルが 497 個あるため、モデル リストは CPU 時間の約 3 分の 1 を使用します。
  • Gemma 3 4B 用の 1,000 行チャット データセットの準備には、テストで 6.6 ではなく 1.75 が必要でした。
  • MiniMax-H3 は、Linux A100 では 61 秒ではなく 49 秒でロードされました。

マルチ LoRA + API

複数の互換性のあるジョブが微調整キューで待機している場合、Unsloth は共有ベース モデル上の独自の LoRA アダプターを使用してそれらを一緒にトレーニングするようになりました。

  • GPU がビジーな間に送信されたジョブは順番にキューに入れられ、それぞれ単独でキャンセルできます。
  • ジョブの fine_tuned_model 名をロードして、そのトレーニング済みアダプターとチャットします。
  • clip のレンダリング中に /v1/videos リクエストがキューに入れられ、一致する /v1/images/generations リクエストがバッチ処理されるようになりました。

仕組み

  • 新しい Triton カーネルは、バッチごとに基本層を 1 回実行しますが、各アダプターは独自の損失と学習率で独自のトークンからのみ学習します。
  • 4 つのアダプターを使用すると、4096x4096 レイヤーの前方および後方パスは、一度に 1 つのアダプターよりも 1.5​​2 倍高速に実行されました (A100、bf16、ランク 16)。

チャット + ツール

  • ローカル モデルは出力制限に達するツール呼び出しをスキップするため、書きかけの cat > app.py がファイルを上書きすることはできません。
  • 以前は、カットオフ リライトにより、RTX 3090 では 175 行のテスト ファイルがわずか 6 行に縮小されました。
  • Qwen3 や DeepSeek R1 などの思考モデルは、その推論と SGLang の Think トグルを表示するようになりました。
  • 自動圧縮がオンになっていると、長い SGLang チャットは最も古いターンを削除し、応答し続けます。
  • vLLM および SGLang では、最大トークンで切断された応答を再開し、response_format を使用して JSON をリクエストできます。

ブラウザ + デスクトップ

  • ブラウザの新しいタブ ページには、モデルがブラウザを制御できるようにする ブラウザ使用 スイッチがあります。
  • デスクトップでは、一時的なチャットのために動作するブラウザ エージェントが履歴にページを追加しなくなります。
  • Safari 18.4 以前を搭載した macOS では、デスクトップ ブラウザのタブとその閉じるボタンが再び機能します。
  • ログアウト が Unsloth デスクトップのユーザー メニューに追加されました。

トリック・オア・トリート

トリック オア トリート… 行はサイドバーの その他 の上にあり、ハロウィーン メニューが開きます。

  • パンプキン、コーヴン、幽霊船など、それぞれにライト モードとダーク モードがある 11 のテーマから 1 つを選択します。
  • 不気味な挨拶をオンにすると、ハロウィーンのセリフとナマケモノで新しいチャットが開きます。
  • クモとコウモリ をオンにすると、ハロウィーンのテーマで奇妙なクモとコウモリが窓を横切ります。
  • どのテーマかわからないですか? トリック オア トリート! はランダムに 1 つ選択します。 Unsloth は 11 月 1 日の深夜、または 今すぐ削除 することですぐに通常に戻ります。

トレーニング

  • Gemma 4 E2B および E4B は、データセットの思考テキストを削除するのではなく、トレーニング中に保持するようになりました。
  • 新しいチャット トレーニング セットアップでは、モデルとデータがサポートするシーケンス パッキングと アシスタント補完が有効になります。
  • ローカルの JSON および JSONL データセットは、後の行に新しいキーが追加された場合でもロードされます。
