#ナマケモノv0.1.914-beta

Unsloth には Glass テーマと、背景、挨拶、チャットのカスタマイズ オプションが追加されました。このリリースでは、Unsloth でのより高速な生成、より多くのマルチ GPU トレーニング オプション、および CPU トレーニングも提供されます。

<img width="800" alt="ナマケモノのガラスのテーマ" src="https://github.com/user-attachments/assets/bc38677f-9e49-4b46-b0ac-f16522541a57" />

ハイライト

  • 新しい Glass テーマ (5 つのテーマ、透明性 + ネイティブ macOS ガラス)
  • カスタム挨拶、背景コントロール、コードフォントによる カスタマイズ
  • DeepSeek-V4.1 512K コンテキスト ベンチマークでは、Unsloth の GGUF が Terminal Bench、DeepSWE、AutomationBench 全体で最も強いランクにあることが示されています。 分析
  • チャット ナビゲーション でプレビュー、ブックマーク、前のターン間のジャンプが可能
  • CPU テキスト トレーニング をトレーニング ページから直接実行

自分のものにしましょう

  • 強度を調整できる 5 つのガラス スタイルと、背景画像の有無にかかわらず、オプションのガラス メニューから選択します。
  • Mac 上の Unsloth デスクトップはネイティブ ガラスをサポートしており、ウィンドウを通してデスクトップを表示できます。
  • 背景のサイズと位置を調整し、チャット全体で表示する場所を選択します。
  • テキスト、アイコン、または画像を使用して独自の挨拶を追加するか、完全に非表示にします。
  • ライブ プレビューを使用して、コード フォント、行番号、文字の折り返し、合字をカスタマイズします。
  • 季節限定の特典なしで、トリック オア トリートのテーマを一年中使用できます。

チャット

  • 新しいチャット ナビゲーターを使用して、以前のメッセージをプレビューしたり、順番をブックマークしたり、長い会話をジャンプしたりできます。
  • リンク、リスト、スプレッドシート表などの書式設定されたコンテンツをマークダウンとして貼り付けます。
  • アラビア語、ペルシア語、ヘブライ語、ウルドゥー語のメッセージは右から左に表示されますが、コードは元の方向を維持します。
  • 返信がストリーミングされたりスクロールしたりしても、長いチャットの応答性が向上します。
  • MCP 接続はサーバーの再起動後に回復します。
  • コーディング エージェントは、プロジェクトの作業フォルダー内のファイルの指示に従うことができます。

パフォーマンスとメディア

  • サポートされているシングル GPU Llama および Qwen3 モデルは、Linux または WSL を搭載した NVIDIA GPU 上の Unsloth の Transformers バックエンドでより高速に生成されます。 A100 テストでは、4 ビット Qwen3-8B は 25.7 から 99.1 トークン/秒に達し、3.9 倍の高速化が実現しました。
  • SDXL は 4 GiB VRAM バジェットでレンダリングできるようになり、T4 および L4 GPU でテストされました。
  • RAG の新しいインデックスを使用して、大規模なドキュメント コレクションをより高速に検索します。
  • 出力を変更せずに、生成された画像を PNG としてより速く保存します。
  • ビデオ モデルは、キャッシュされた INT8 重みを再利用して、繰り返し読み込みを高速化します。
  • Wan2.2 A14B は、オフロード生成用の INT8 重みを構築するときに使用するシステム メモリを削減します。
  • アダプター ファイルを再ロードせずに画像 LoRA の強度を調整します。
  • audio.cpp を使用して、アップロードとストレージの制限に従って、最長 4 時間の音声を書き起こします。

マック

  • サポートされている MLX 投機的デコード モデルを使用して生成を高速化するには、実験的な Fast Verify を試してください。返答は多少異なる場合があります。
  • MLX ストリーミングは、返信が増えるにつれてテキストの処理にかかる時間を短縮します。
  • Unsloth はデフォルトで Mac システム フォントを使用するようになりました。

トレーニング

  • GPU が使用できない場合は、[トレーニング] ページから CPU でテキスト モデルを微調整します。
  • チャットのみのインストールでは、トレーニングのインストール を通じて CPU トレーニングを追加できます。
  • 同じデータセット内のオーディオと画像を一緒に使用して、Gemma 3n や Gemma 4 などのオーディオ ビジョン モデルを微調整します。
  • 各 GPU に割り当てられたパイプライン レイヤーのみをロードすることにより、単一 GPU より大きいサポートされている非量子化モデルをロードします。
  • UNSLOTH_PARALLEL を使用して、データ、テンソル、パイプライン、およびコンテキスト並列処理のサポートされている組み合わせを構成します。
  • unsloth.tile_mlp(model) を使用したトレーニング中の MLP アクティベーション メモリを削減します。
  • CLI チャットおよび推論コマンドを通じて画像をビジョン モデルに送信します。
