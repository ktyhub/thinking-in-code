unsloth v0.1.916-beta

#ナマケモノv0.1.916-beta

このリリースでは、Unsloth 全体で大幅なパフォーマンス修正が行われ、長時間のチャットでの入力と検索の高速化、画像/ビデオの読み込みの高速化、2 GPU による画像/ビデオの生成が行われました。また、チャットごとに個別のブラウザ、フローティング ブラウザ ウィンドウが追加されます。

ハイライト

  • 大規模なパフォーマンス修正、さらに多くの Glass テーマの最適化が来週予定されています
  • ガラステーマの修正 ぼかしがなくなり、レンダリングが向上し、オプションが増えました
  • 統合メモリ オフロード が大規模モデルでも適切に機能するようになりました
  • チャットごとに個別のブラウザ - 複数のチャットで独自のブラウザを個別に実行できるようになりました
  • フローティング ブラウザ チャット上で移動やサイズ変更ができ、モデルに任せることができます
  • ダイナミック V3.1 Qwen3.8-Flash - トークンの使用量が 50% 削減され、精度が 15% 向上
  • 2 GPU の画像とビデオ 対応する NVIDIA カードで最大 2 倍高速
  • チャットの検索と削除が高速化 - チャットの検索と削除が大幅に高速化
  • 安定した拡散画像/ビデオ モデルの読み込みが最大 40% 高速化
  • LTX-2.5 ビデオ 16 ～ 24 GB GPU での新しいプロンプトの速度が大幅に向上

チャットのパフォーマンス

  • Glass テーマまたはチャットの背景がオンになっているときに、長いチャットでの入力に遅れが生じなくなりました。
  • チャット検索は、非常に長い履歴でも読み込みに失敗することなく、高速に実行されます。
  • 履歴が大きい場合、チャットのクリアと削除がはるかに高速になります。
  • 起動後の最初の音声またはオーディオ機能の使用時に、ストリーミング応答が数秒間フリーズすることがなくなりました。
  • Unsloth モデル エンジンを使用した読み上げでは、発話する前にモデル検索で数秒待つことがなくなりました。
  • 一部の Linux デスクトップのように、背景画像上のガラス テーマは GPU レンダリングなしで最大 2 倍高速に応答します。

画像とビデオ

  • 2 つの一致するアイドル状態の NVIDIA GPU を使用すると、SDXL、Qwen-Image、Wan2.2 5B などのモデルは、1 つに収まる場合、2 番目のカードで各ステップの半分を実行し、約 1.5 から 1.8 倍の速度になります。
  • 同じセットアップで、FLUX と Lumina 2 は両方のカードに均等なサイズの画像のバッチを分割します。
  • SDXL は最大 40% 高速にロードされるため、最初のイメージがより早く到着します。
  • 16 ～ 24 GB GPU では、LTX-2.5 は CPU ではなく GPU で新しいプロンプトをエンコードするため、新しいプロンプトを備えた clip のレンダリングが大幅に高速になります。
  • LTX-2.5 GGUF Q8_0 ビデオは、NVIDIA GPU 上で同一のフレームで約 10% 高速にレンダリングされます。
  • モデルが量子化、GGUF、またはオフロードされていない場合、同じ LoRA での繰り返しレンダリングが高速になります。
  • FLUX や Z-Image などの一部の画像モデルは、AMD RDNA3 および RDNA4 GPU を搭載した Linux 上でより高速にレンダリングされます。

Unsloth の新機能

  • 内蔵ブラウザをチャット上に小さなウィンドウとしてフロートさせ、移動やサイズ変更が可能です。各チャットはフローティングかどうかを記憶します。
  • Anima、Chroma、MOSS-Image、および Krea 2 イメージ モデルを、Chroma を除くすべての LoRA および LoKR ファイルを使用して単一ファイル チェックポイントからロードします。
  • ガラス テーマは背景画像をぼかすのではなく暗くし、他のページのコントロールはチャットのガラスと一致します。
  • 所有者は、チャット、ファイル、設定を失うことなく、管理対象アカウントの名前を変更できます。
  • 所有者は、[設定] > [一般] > [ダウンロード] でモデルのダウンロード速度を制限できます。
  • OpenAI 互換接続ではカスタム ヘッダーを送信できます。

修正

  • 非 GGUF モデルが既にダウンロードされているチャットのみのインストールでは、最初のチャットは失敗せずにデフォルト モデルを取得します。
  • CPU のみのマシン上の GGUF モデルは、自動コンテキストでメモリ不足にならなくなりました。
  • Windows では、HTTPS ダウンロードは一時停止または中断後に最初からやり直すのではなく再開されます。
  • Windows で Unsloth を更新しても、最後に 30 分間沈黙することがなくなりました。
  • MCP 経由で Blender を接続すると再び動作します。
  • 比較モードでは、最初のメッセージで 1 つのペインが空のままになることがなくなりました。

トレーニングとライブラリ

  • Python、Llama、Qwen2、および Qwen3 モデルの model.generate() は、Linux 上の NVIDIA GPU ではデフォルトで高速であり、小規模モデルでは最大で数倍高速です。
  • 数百のファイルに分割されたハブ データセットでのトレーニングが最大 1 分早く開始されます。
  • アシスタント補完のみを使用すると、改行で始まる回答がトレーニングから除外されなくなりました。
