spring-batch v6.0.6

パッチ 公開日2026年10月22日 出典spring-projects/spring-batch 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

スプリングバッチ v6.0.6

:ロケット: 機能強化

  • @FunctionalInterface を StepInterruptionPolicy に追加 #5402
  • SimpleJobOperator jobRegistry 状態メッセージを修正 #5369
  • JdbcJobExecutionDao#synchronizeStatus(StepExecution) #5365を改良
  • 非推奨の Jackson2JsonMessageConverter を JacksonJsonMessageConverter #5350 に置き換えます。
  • System.getProperty("line.separator") を System.lineSeparator() #5341 に置き換えます。
  • 実行時のcreateTimeに対する不要なnullチェックを削除 #5304
  • 実行中のジョブを開始しようとすると不正確な例外メッセージが表示される #5280
  • パフォーマンスと正確性を確保するために、JdbcPagingItemReader および JpaPagingItemReader の CopyOnWriteArrayList を ArrayList に置き換えます #5112
  • 現在のバージョンの不要なクエリを削除 #4797
  • ジョブを実行すると、ジョブ実行の完全な履歴が取得される #4169
  • FlowJob 内の固有でないステップ名は警告をログに記録する必要があります #3757
  • 未使用の ClassUtils インポートを JdbcPagingItemReader から削除 #5407

:lady_beetle: バグ修正

  • ChunkOrientedStep は、チャンク トランザクションがコミットされていない場合、ステップの実行を復元しません #5594
  • MongoCursorItemReader を開く前に閉じると NullPointerException をスローする #5589
  • BATCH_JOB_SEQ #5586 の名前を変更すると、MariaDB 6.0 の移行が失敗する
  • リスナー例外はスキャン モードではスキップ可能ですが、他の場所では致命的です #5585
  • AbstractPaginatedDataItemReader #5583 での欠落ページの増加を修正
  • ジョブスコープ Bean は、マルチスレッドステップおよび並列フローのワーカースレッドからは使用できません #5576
  • チャンク スキャン中の失敗後に再起動すると、ChunkOrientedStep #5558 のチャンクの残りの項目がスキップされます。
  • NullPointerException 未開封の JpaPagingItemReader #5539 を閉じるとき
  • @OnSkipInRead/@OnSkipInProcess/@OnSkipInWrite メソッドは ChunkOrientedStepBuilder#listener(Object) によって無視されます #5531
  • 再試行なしのスキャン モードでの誤解を招くログ #5527
  • FlatFileItemReaderBuilder.addComment() は comments(...) の後に UnsupportedOperationException をスローします #5520
  • フィールドが一重引用符の場合、DelimitedLineTokenizer は StringIndexOutOfBoundsException をスローします #5519
  • 厳密モードの FixedLengthTokenizer は、オープンエンド範囲が最初の範囲の最小値またはその前に始まる場合に行を拒否します #5518
  • ステップの ExitStatus に一致する遷移がない場合、JobFlowExecutor は共有スレッドでのジョブ実行全体で StepExecution をリークします #5514
  • ロールバックされたチャンクは書き込まれたものとしてカウントされ、ChunkOrientedStep でステップが完了しました (OptimisticLockException のフォールトトレラントな再試行) #5509
  • 並列ジョブ実行時の MongoSequenceIncrementer の TransientTransactionError #5507
  • JacksonExecutionContextStringSerializer の QName デシリアライゼーションを修正 #5502
  • ChunkOrientedStep スキャン モードは、処理されたチャンクを ChunkListener#beforeChunk に渡し、リスナーが #5493 をスローすると、サイレントにスキャン項目を削除します。
  • ChunkOrientedStep は、FaultTolerantChunkProcessor #5490 とは異なり、チャンク スキャン中に ItemProcessor を再呼び出ししません。
  • JpaCursorItemReader.doClose() entityManager で null チェックが欠落している #5486
  • StaxEventItemReader #5483 の encoding の誤った null 可能性コントラクトを修正
  • CRLF #5481 により、Windows で JsonFunctionalTests が失敗する
  • @OnChunkError はチャンク指向のステップでは決して呼び出されません #5468
  • アイテムハンドラーにもリスナーアノテーションがある場合、インターフェイスリスナーコールバックが 2 回呼び出されます #5466
  • spring.batch.job.launch.count がサイレントに欠落しています: JobOperator は、ほとんどの構成パスで ObservationRegistry.NOOP を保持します #5463
  • Spring Batch 6.x #5455 での格納と取得の間の JobParameter 型処理の不一致
  • @BeforeStep/@AfterStep メソッドは ChunkOrientedStepBuilder#listener(Object) によって無視されます #5451
  • Jetbrains @NotNull を jspecify @NonNull #5443 に置き換えます。
  • SimpleJobOperator.restart(JobExecution) は、誤解を招く「ジョブ実行はすでに実行中です」メッセージで実際の失敗の理由をマスクします #5439
  • MongoDB 永続モデルのクラスとリソースの GraalVM ランタイム ヒントが欠落しています #5435
  • カスタムヘッダー/フッターコールバックで追加が許可されている場合に有効な JSON を生成するように JsonFileItemWriter を修正しました #5432
  • ステップが Bean として定義されておらず、名前も割り当てられていない場合、ステップ名は null になります #5278
  • MongoCursorItemReaderBuilder とクエリを使用してビルドする場合、sorts() メソッドを介した強制ソート #4860

:notebook_with_decorative_cover: ドキュメント

  • ドキュメントの付録の JpaItemWriter の記述が間違っています #5556
  • JMS ヘッダーに関するリモート チャンキングおよびリモート パーティショニングのサンプルの不正確なドキュメント #5513
  • Javadoc コメントのタイプミスを修正 #5511
  • 再試行可能な読み取りと前方専用セマンティクスとの互換性を明確にする #5510
  • トランザクション範囲に関する SkipListener 契約書と参照ドキュメントを明確化 #5494
  • リファレンス ドキュメントのトレース例では、スパンを作成しないハンドラーが登録され、ジョブが失敗します #5475
  • JobOperator.start() #5434 の Javadoc のタイプミスを修正
  • 「ItemStream を Step に登録する」の間違った例 #5429
  • JobExecution.isStopped() の誤った Javadoc 参照を修正 #5414
  • SqlPagingQueryUtils #5403 の Javadoc を修正
  • EnableBatchProcessing Javadoc のタイプミスを修正 #5375
  • BatchStatus.isLessThanOrEqualTo の不正確な JavaDoc #5285
  • Spring Data からのスクロール API を再利用するための IteratorItemReader の活用に関するドキュメントを強化 #4484

:hammer: タスク

  • Apache Artemis groupId を org.apache.artemis にアップデート #5482
  • Groovy バージョンを 5.1.2 #5327 に更新
  • pom.xml #5506 のバージョン プロパティに .version サフィックスを一貫して使用します。
