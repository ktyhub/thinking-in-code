spring-batch v6.1.0-M2

プレリリース 公開日2026年9月24日 出典spring-projects/spring-batch 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

スプリングバッチ v6.1.0-M2

:star: 新機能

  • Mongo JobRepository を任意の PlatformTransactionManager #5508 と併用できるようにする
  • パターンによるリソースの指定をサポートする ResourcesItemReader のビルダーを追加 #5487
  • BatchConstants #5190のご紹介
  • デフォルトのリーダー/ライター名をBean名に変更 #5149
  • MultiResourceItemReaderBuilder #5056 のパターンを使用したリソースの場所の指定のサポート
  • MongoDB ジョブ リポジトリにカスタム コレクション プレフィックスのサポートを追加 #4980
  • 相互に排他的なビルダー メソッドにコンパイル時の安全性を追加 #4888
  • スキーマの場所を DatabaseType に追加して、メタデータ テーブルの文字列パスのタイプミスを防止します #4586

:lady_beetle: バグ修正

  • リポジトリ/DAO レベルのカウント方法では、ジョブ/ステップの存在を適切に検証できません #5544
  • @OnSkipInRead/@OnSkipInProcess/@OnSkipInWrite メソッドは ChunkOrientedStepBuilder#listener(Object) によって無視されます #5531
  • ロールバックされたチャンクは書き込まれたものとしてカウントされ、ChunkOrientedStep でステップが完了しました (OptimisticLockException のフォールトトレラントな再試行) #5509
  • 並列ジョブ実行中の MongoSequenceIncrementer の TransientTransactionError #5507
  • JacksonExecutionContextStringSerializer #5502 での QName の逆シリアル化を修正しました。
  • ChunkOrientedStep スキャン モードは、処理されたチャンクを ChunkListener#beforeChunk に渡し、リスナーが #5493 をスローすると、サイレントにスキャン項目を削除します。
  • ChunkOrientedStep は、FaultTolerantChunkProcessor #5490 とは異なり、チャンク スキャン中に ItemProcessor を再呼び出ししません。
  • JpaCursorItemReader.doClose() エンティティマネージャーで null チェックがありません #5486
  • StaxEventItemReader #5483 でのエンコーディングの誤った null 可能性コントラクトを修正しました。
  • CRLF #5481 が原因で Windows で JsonFunctionalTests が失敗する
  • @OnChunkError はチャンク指向のステップでは決して呼び出されません #5468
  • アイテムハンドラーにもリスナーアノテーションがある場合、インターフェイスリスナーコールバックが2回呼び出されます #5466
  • spring.batch.job.launch.count がサイレントに欠落しています: JobOperator は、ほとんどの構成パスで ObservationRegistry.NOOP を保持します #5463
  • Spring Batch 6.x での保存と取得の間の JobParameter タイプの処理に一貫性がない #5455
  • @BeforeStep/@AfterStep メソッドは ChunkOrientedStepBuilder#listener(Object) によって無視されます #5451
  • Jetbrains @NotNull を jspecify @NonNull #5443 に置き換えます。
  • SimpleJobOperator.restart(JobExecution) は、誤解を招く「ジョブ実行はすでに実行中です」メッセージで実際の失敗の理由をマスクします #5439
  • MongoDB 永続モデルのクラスとリソースの GraalVM ランタイム ヒントが欠落しています #5435
  • カスタム ヘッダー/フッター コールバックで追加が許可されている場合に有効な JSON を生成するように JsonFileItemWriter を修正しました #5432
  • ステップが Bean として定義されておらず、名前も割り当てられていない場合、ステップ名は null になります #5278
  • MongoCursorItemReaderBuilder とクエリを使用してビルドする場合、sorts() メソッドを介した強制ソート #4860
  • リモートパーティショニングにおけるジョブ実行リスナーの呼び出し順序が正しくない #4133
  • リモート チャンクの実装は、同じジョブの並列実行をサポートしません #1372

:ロケット: 機能強化

  • デフォルトのメソッドと同一の冗長メソッドを削除 #5516
  • 一貫性のないビルダー メソッド名: MultiResourceItemReaderBuilder.setStrict() #5512
  • DefaultJobParametersConverter および JsonJobParametersConverter を改善 #5457
  • 可能であれば、isAssignableFrom() を isInstance() に置き換えます #5427
  • 未使用の ClassUtils インポートを JdbcPagingItemReader から削除 #5407
  • @FunctionalInterface を StepInterruptionPolicy に追加 #5402
  • SimpleJobOperator jobRegistry 状態メッセージを修正 #5369
  • 非推奨の Jackson2JsonMessageConverter を JacksonJsonMessageConverter #5350 に置き換えます。
  • System.getProperty("line.separator") を System.lineSeparator() #5341 に置き換えます。
  • 実行の createTime に対する不要な null チェックを削除 #5304
  • 実行中のジョブを開始しようとすると不正確な例外メッセージが表示される #5280
  • JacksonExecutionContextStringSerializer #5233改良
  • カスタム コンバータを DefaultFormattingConversionService #5186 に置き換えます。
  • 非同期処理 API を spring-batch-core に移動 #5185
  • パフォーマンスと正確性を確保するために、JdbcPagingItemReader および JpaPagingItemReader の CopyOnWriteArrayList を ArrayList に置き換えます #5112
  • RepositoryItemWriter #5073 にフラッシングのサポートを追加

:notebook_with_decorative_cover: ドキュメント

  • Javadoc #5545 を修正
  • JMS ヘッダーに関するリモート チャンキングおよびリモート パーティショニングのサンプルの不正確なドキュメント #5513
  • Javadoc コメントのタイプミスを修正 #5511
  • 再試行可能な読み取りと前方専用セマンティクスとの互換性を明確にする #5510
  • トランザクション範囲に関する SkipListener 契約書と参照ドキュメントを明確化 #5494
  • リファレンス ドキュメントのトレース例では、スパンを作成しないハンドラーが登録され、ジョブが失敗します #5475
  • JobOperator.start() #5434 の Javadoc のタイプミスを修正
  • Registering ItemStream with a Step #5429 の間違った例
  • JobExecution.isStopped() の誤った Javadoc 参照を修正 #5414
  • SqlPagingQueryUtils #5403 の Javadoc を修正
  • EnableBatchProcessing Javadoc のタイプミスを修正 #5375
  • BatchStatus.isLessThanOrEqualTo #5285 の不正確な JavaDoc
  • Spring Data からのスクロール API を再利用するための IteratorItemReader の活用に関するドキュメントを強化 #4484

:hammer: タスク

  • pom.xml のバージョン プロパティに .version サフィックスを一貫して使用する #5506
  • Apache Artemis グループ ID を org.apache.artemis #5482 に更新します
  • Groovy バージョンを 5.1.2 #5327 に更新
  • JobInstance ID #5533 の JobExecution コンビニエンス ゲッターを非推奨にする
  • RepositoryItemWriter で setRepository を非推奨 #5473
  • RepositoryItemReader #5472 で setRepository と setSorts を廃止
  • Apache Derby が廃止されたため、Derby サポートを非推奨にする #5254
  • 冗長性を排除するために JobInstance::getInstanceId を非推奨として削除 #5244
  • JobExecution ID とパラメーターの StepExecution 便利なゲッターを非推奨にする #5142
  • JPA アイテムリーダー/ライターの setEntityManagerFactory を非推奨 #5101
