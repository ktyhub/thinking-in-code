#v0.92.0を潰す

コンパクト終了バナー + モード

このリリースには、いくつかの修正と UX の改善が含まれています。

コンパクトな出口バナー

ご希望に応じて、出口バナーをよりコンパクトに設定できるようになりました。 .crushrc:

option ui exit-banner compact
option ui exit-banner none
option ui exit-banner default  # default

crush.json:

{
  "options": {
    "tui": {
      "exit_banner": "compact"
    }
  }
}

エージェントによる修正

Fantasy をより安定させ、一部の推論プロバイダーに関するいくつかの問題を修正するために、かなりの数の修正を行いました。

Bash 構成の小規模な修正

@devYRPauli が Bash 構成を修正しました。モデルを追加するときに、--price-cache-create と --price-cache-hit が交換されましたが、この問題は解決されました。 チャームチーム
