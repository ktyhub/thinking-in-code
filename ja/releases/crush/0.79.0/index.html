crush v0.79.0

マイナー 公開日2026年6月19日 出典charmbracelet/crush 英語原文

#v0.79.0を潰す

Bang Mode™ のさらなる改善

今朝、新しいBang Modeをリリースしました。このリリースでは、いくつかの小さな修正と機能強化を行いました。

  • 読みやすくするためにフォントの色を微調整しました。
  • 長時間実行されるコマンドはすぐに表示され、コマンドの実行時に出力がストリーミングされるようになりました。
  • セッション名の生成は、コマンドで開始されたセッションに対して固定されています。

エージェントのバグ修正

Fantasy にいくつかのバグ修正を加え、特定のプロバイダーやモデルでの Crush の動作を改善しました。

  • tool not found エラーにより、利用可能なツールのリストが出力されるようになりました。これは、時々道に迷ったり、存在しないツールを呼び出したりする可能性がある、キミのような特定のモデルを対象としています。
  • Fireworks を介した GLM ファミリでの潜在的なツール呼び出しエラーを修正。
  • Azure 経由で一部の GPT モデルを修正 (@dustinlagoy に感謝)。
  • VertexAI 経由で Gemini を修正 (@eswar-7116 に感謝);
  • ローカル モデルでツール呼び出しが正しく動作しないことがある問題を修正しました。 素晴らしい週末を過ごして、頑張ってください! :ロケット: チャームチーム
