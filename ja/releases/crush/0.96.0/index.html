Crush にテーマが追加されました! 🎨 コマンド パレットから新しいテーマ ダイアログを開いてライブ プレビューで外観を切り替えたり、組み込みの Gruvbox Dark を試したり、TUI 内で独自のカスタム パレットを作成して編集したりできます。この機能については @meowgorithm と @gurnben に感謝します。

QoL と修正

小さな変更ですが、重要なことは変わりません。

  • ハイパークレジットがリアルタイムで表示されるようになりました。
  • @tacturnaxolotl によるチャットのエラーにスペースを追加
  • @andreynering によりデフォルトのタイムアウトが 2 分に増加されました
  • @meowgorithm によるモード中の拡張ヘルプを修正
  • プラン表示時のラッピングを修正
  • @taciturnaxolotl による長い bash 呼び出しでの構文の強調表示を修正
  • お気に入りの @tacturnaxolotl による bang モードと bash ツールのさらなる改善

詳細は以下をご覧ください。

<summary>アーティファクトの確認</summary>

まず、checksums.txt ファイル と checksums.txt.sigstore.json ファイル ファイルを、たとえば wget でダウンロードします。

wget 'https://github.com/charmbracelet/crush/releases/download/v0.96.0/checksums.txt'
wget 'https://github.com/charmbracelet/crush/releases/download/v0.96.0/checksums.txt.sigstore.json'

次に、cosign を使用して検証します。

cosign verify-blob \
  --certificate-identity 'https://github.com/charmbracelet/meta/.github/workflows/goreleaser.yml@refs/heads/main' \
  --certificate-oidc-issuer 'https://token.actions.githubusercontent.com' \
  --bundle 'checksums.txt.sigstore.json' \
  ./checksums.txt

出力が Verified OK の場合は、sha256sum を使用してリリースからダウンロードした他のアーティファクトのチェックサムを検証するために安全に使用できます。

sha256sum --ignore-missing -c checksums.txt

完了！これでアーティファクトが確認されました。
