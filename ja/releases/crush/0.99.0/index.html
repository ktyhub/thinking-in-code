crush v0.99.0

マイナー 公開日2026年10月29日 出典charmbracelet/crush 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#v0.99.0を潰す

フック、キャットウォーク v3!

大きなものです！ Crush は Catwalk v3 で実行できるようになり、フックは実行のあらゆる部分を確認できるようになり、Crush をホストする編集者はまったく新しいツール セットを手に入れて快適に使用できるようになりました。

どこにでもフック 🪝

フックはもはや単なるツールではありません。セッション、ターン、権限など、実行全体を追跡できるようになりました。

ツールの実行後にフックも介入できるようになりました。モデルがシークレットを確認する前に、出力のシークレットを編集したり、メモを追加したり、ターンを停止したりできます。ツールが、すべきではないことをすでに行っている場合、フックはモデルに「テストを実行せずにコミットした」ことを伝えることができます。

hook add TurnEnd --name "ding" --command 'afplay /System/Library/Sounds/Glass.aiff'

詳細はこちらをお読みください。

Client/サーバー モード

Crush を内部で実行するものを構築する場合は、このリリースが最適です。

  • ホスト テーマ: ホスト アプリはサーバー API 上の TUI をテーマにできるため、Crush はアプリケーションに一致します。
  • ホスト コンテキスト: ホストは、開いているファイルなど、ビュー内にあるものを Crush に伝えることができ、それらのファイルは補完に表示されます。
  • 次のプロンプトに追加: clients は、実行を開始したりチャットを混乱させたりすることなく、エージェントが次のプロンプトで読むテキストを追加できます。
  • 共有視聴: client は、他の client がどのセッションを見ているかを確認できます。
  • パイプされたアクセス許可: CRUSH_PERMISSIONS_PIPED=1 を設定すると、ホストがアクセス許可のプロンプトに応答するため、二度尋ねられることはありません。
  • http:// アドレスは、サーバーの起動時に tcp:// のエイリアスとして機能します。

安定したサーバー

  • SIGHUP はサーバーを停止する代わりに設定をリロードするようになりました。
  • ターミナルを閉じるか、サービス マネージャーを介して Crush を停止すると、正常にシャットダウンされるようになりました。そのため、進行中の作業がスタックしたままになるのではなく、保存されます。

[Catwalk v3][catwalk] の簡単な概要:

クラッシュは [Catwalk v3][catwalk] を話すようになりました。プロバイダー type では、プロバイダーが使用する API 形式について説明しますが、作成者ではありません。

  • completions: OpenAI 互換の API
  • responses: OpenAI、またはそれを介してルーティングされるもの
  • messages: Anthropic 互換の API

設定はロード時に自動的に移行されるため、openai、openai-compat、anthropic は引き続き動作します。編集は必要ありません。

provider add および model add フラグが続きます。

crush provider add deepseek \
  --type completions \
  --base-url "https://api.deepseek.com/v1" \
  --api-key "$DEEPSEEK_API_KEY"

crush model add deepseek/deepseek-chat --thinking toggleable --max-attachments 5
  • --can-reason は --thinking always|never|toggleable になりました
  • --max-attachments Nは新しいです
  • 推論レベルでは、ピッカーに「X-High」などのわかりやすい名前が表示されます。

今のところはここまでです！ チャームXX 💫

<summary>アーティファクトの確認</summary>

まず、checksums.txt ファイル および checksums.txt.sigstore.json ファイル ファイルを、たとえば wget でダウンロードします。

wget 'https://github.com/charmbracelet/crush/releases/download/v0.99.0/checksums.txt'
wget 'https://github.com/charmbracelet/crush/releases/download/v0.99.0/checksums.txt.sigstore.json'

次に、cosign を使用して検証します。

cosign verify-blob \
  --certificate-identity-regexp '^https://github.com/charmbracelet/crush/\.github/workflows/(release|nightly)\.yml@' \
  --certificate-oidc-issuer 'https://token.actions.githubusercontent.com' \
  --bundle 'checksums.txt.sigstore.json' \
  ./checksums.txt

出力が Verified OK の場合は、sha256sum を使用してリリースからダウンロードした他のアーティファクトのチェックサムを検証するために安全に使用できます。

sha256sum --ignore-missing -c checksums.txt

完了！これでアーティファクトが確認されました。

</詳細>
