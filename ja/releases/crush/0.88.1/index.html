#v0.88.1をクラッシュする

バグ修正のスローダウンの時間です

このリリースは安定性と生活の質を重視しており、MCP、サーバー client、およびその他の問題に関する修正が加えられています。中身は次のとおりです。

  • UX: コマンドに clear と入力すると、Summarize と一致します。ありがとう、@joestump!
  • LSP: @piakdev は LSP がパニックになる可能性があるケースを修正しました
  • MCP: MCP の読み込みが遅いと、メッセージの送信がブロックされる可能性があります。デフォルトのタイムアウトが減少します。
  • Server-Client: MCP OAuth は、server-client モードでは機能しませんでした。今はそうなります
  • Server-Client: 同じワークスペース内の Client は互いに殺し合う可能性があります。もうそれはありません
  • サーバー-Client: サーバーが TCP 上で実行されている場合、キーストロークがサーバーにヒットしなくなり、すべての速度が低下します。
  • ハイパー: UX を向上させるためにさまざまな小さな改善を追加しました。 クラッシュをご利用いただきありがとうございます。良い週末を！ 魅力💌
