#v0.86.0を潰す

LSP ツール、スクロール可能なサイドバー、取り外し可能な添付ファイルなど

やあ、皆さん。 LSP の商品やその他のグッズを発送して、スタイリッシュに週を始めましょう。

新しい LSP ツール

これらの新しい LSP ツールを使用すると、モデルがいくつかのリファクタリングをより正確に実行できるようになります。

  • lsp_rename - プロジェクト内のシンボルとそのすべての参照の名前を変更します。
  • lsp_replace_symbol - 関数/メソッド/クラス全体を名前で置換、前後に挿入、または削除します。 LSP が期待どおりに動作しない場合でも、心配する必要はありません。 edit ツールの使用にフォールバックできるように、モデルにエラーを報告します。

これはかなりクールです。サイドバーのスペースが不足していませんか?心配しないでください。コンテンツは今すぐスクロールできます。
