#v0.102.0をクラッシュする

チャネル、カスタム プロンプト、サーバーの強化

このリリースには素晴らしいものがたくさんあり、私たちはそのすべてを本当に誇りに思っています。続きを読んでください。

BYO プロンプト

最後に、システム プロンプトを好きなものに置き換えることができます。また、メイン エージェントだけでなく、サブエージェント、計画、圧縮、セッション タイトル、crush init のプロンプトも表示されます。

option prompt coder ~/.config/crush/prompts/coder.md.tpl
option prompt summary prompts/summary.md

グローバル設定でプロンプトを設定したり、ローカル設定でプロジェクトごとにオーバーライドしたり、--prompt name=path でプロンプトをオーバーライドしたりできます。 プロンプトの詳細については、ドキュメント を参照してください。

夜のライディング

@cdancy の厚意により、Crush にはナイト ライダーからインスピレーションを得た KITT テーマが同梱されるようになりました。ロゼパインクラシック、ムーン、ドーンも登場しました。

<p><img width="730" height="528" alt="image" src="https://github.com/user-attachments/assets/2c139b67-92a3-4600-9278-761c813699ed" /></p> ## Nerd フォントでオタクを表現する ついにオタクフォント登場！サポートは自動的に検出されるため、端末が壊れることもありません。 Crush では、アイコン、LSP ステータス、および Git が含まれるようになりました。 Crush over SSH を実行している場合は、Nerd フォント `option ui nerd-fonts true` を有効にする必要があることに注意してください。 ```bash # Hate nerd fonts? You can turn 'em off, too. option ui nerd-fonts false ``` ## チャンネル [チャンネル](https://code.claude.com/docs/en/channels-reference) は Claude による実験的な MCP 機能で、@joestump の素晴らしい取り組みのおかげで Crush で利用できるようになりました。つまり、チャネルを使用すると、MCP サーバーはイベントが発生したときにセッションにイベントをプッシュできるようになります。 ```bash crush --channels server:webhook --channels server:signal ``` または、`crushrc` で 1 つを永続的にオンにします。 ```bash # crushrc mcp add webhook \ --type http \ --url https://example.com/mcp \ --channel true ``` Crush は [Claude Channels](https://code.claude.com/docs/en/channels-reference) と同じプロトコルを使用するため、既存のチャネル サーバーはそのまま動作するはずです™。 ## サーバーの強化 Client サーバー モードは、これまでよりも堅牢になりました。より安全になり、特に Windows 上で、小さな改善、正確さの修正、その他のバグ修正が数多く行われています。 ## その他にもたくさん - システム管理モードは 1 つ前の <kbd>shift+tab</kbd> ではなくなりました。 - キューに登録されたプロンプトは、送信した瞬間にピルに表示されます。 ・`sudo`が使用可能な機種ですので、Touch IDによる承認が可能です。 - コンテンツの拒否は自動的に再試行されます。 - クロードが仕事を拒否し続けたセッション。 - ツールを呼び出すことができない Ollama モデルがモデル リストに表示されなくなりました。 - 子プロセスを残すコマンドがハングしなくなりました。 - タイマーが刻々と動き、ツールが応答するまで実行中のツール タイマーが動き続けます。 - テーマを切り替えても、会話全体が再レンダリングされなくなりました。 - セッションを削除しても、リスト内の位置は維持されます。 - 再生されたメッセージは空白を維持し、プラン カードは適切に整列します。 幸運を祈ります。 チャームXX🌤️ ## Changelog ### 新しい! * 01780cc0384227b90071a8bbf26559410b748efc:
