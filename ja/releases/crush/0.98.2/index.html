<詳細>

<summary>アーティファクトの確認</summary> まず、[`checksums.txt` ファイル](https://github.com/charmbracelet/crush/releases/download/v0.98.2/checksums.txt) と [`checksums.txt.sigstore.json` ファイル](https://github.com/charmbracelet/crush/releases/download/v0.98.2/checksums.txt.sigstore.json) ファイルを、たとえば `wget` でダウンロードします。 
wget 'https://github.com/charmbracelet/crush/releases/download/v0.98.2/checksums.txt'
wget 'https://github.com/charmbracelet/crush/releases/download/v0.98.2/checksums.txt.sigstore.json'

次に、cosign を使用して検証します。

cosign verify-blob \
  --certificate-identity-regexp '^https://github.com/charmbracelet/crush/\.github/workflows/(release|nightly)\.yml@' \
  --certificate-oidc-issuer 'https://token.actions.githubusercontent.com' \
  --bundle 'checksums.txt.sigstore.json' \
  ./checksums.txt

出力が Verified OK の場合は、sha256sum を使用してリリースからダウンロードした他のアーティファクトのチェックサムを検証するために安全に使用できます。

sha256sum --ignore-missing -c checksums.txt

完了！これでアーティファクトが確認されました。

</詳細>
