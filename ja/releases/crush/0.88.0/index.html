#v0.88.0をクラッシュする

.crushrc が登場！

おい！皆さんも素晴らしい一週間を過ごしていただければ幸いです。 Charm ではかなり生産性が高かったので、今日はいくつかの素晴らしいものをリリースします。

Bash の設定! (.crushrc)

そうだ、.crushrcが来た！既存の JSON 構成は引き続き機能しますが、より柔軟な構成への移行を開始したところです。 これが優れている理由の例: Crush 構成を dotfiles リポジトリで管理している場合でも、source を使用して .gitignore 内にある別のファイルを呼び出すことで、マシン固有のオーバーライドを行うことができます。他にもたくさんの使用例があると思います。 これに関する完全なドキュメントを読むには、このドキュメントを読む を参照してください。 切り取ったものを見て、どのように見えるかを理解してください。

# Add Ollama.
provider add ollama --type ollama --base-url "http://localhost:11434/v1"

# Register a model on Ollama.
model add ollama/llama3.3 --name "Llama 3.3" --context-window 128000

# Auto-approve some tools.
permissions allow view edit

# Add an MCP server
mcp add github \
  --type http \
  --url "https://api.githubcopilot.com/mcp/" \
  --header Authorization "Bearer $GITHUB_TOKEN"

# Load some extra config
source "$XDG_CONFIG_HOME/squid-config.sh"

# Change config based on the machine you're on.
if [[ $HOSTNAME == "babysquid" ]]; then
    option skill-path "$HOME/squid-skills"
fi

フィードバックを送りたいですか? Discord の #crush チャンネルに参加してください。

AWS Bedrock SSO サポートの向上

@jan-xyz はこれに命を吹き込む素晴らしい仕事をしてくれました! SSO 経由で AWS Bedrock を使用する場合、トークンは時間の経過とともに期限切れになるため、更新する必要があります。 Crush には認証用の適切な構成と UX が備わっており、トークンを更新する必要がある場合は常に Crush が表示されます。 詳細については、#2886 を参照してください。 <img width="572" height="231" alt="2026 年 7 月 31 日 18 04 21 のスクリーンショット" src="https://github.com/user-attachments/assets/993034d2-89d2-42f4-ba9c-30b01a1debd6" />

より信頼性の高いエージェントフェッチ

@sven2718 は、最初の試行で検索が機能しなかった場合の再試行の改善に貢献しました。特に短期間に多数の検索を実行する場合、検索の信頼性が向上しました。

Fable 5 の修正

@sven2718 も Fable 5 の修正に貢献しました。Anthropic がセキュリティ上の理由からプロンプトを拒否することを決定した場合、Crush で適切なエラー メッセージが表示されるようになりました。以前は、Crush は理由の説明をせずにただ停止していました。

Crush が IlluminOS 上でコンパイルされるようになりました

IllumiOS について聞いたことはありませんか? Charm の私たちではありませんが、@timotheosh がコードを調整して、確実にコンパイルできるようにしました。 Go は多くの環境にコンパイルされ、Crush がより多くのオペレーティング システムで動作するのを見るのはいつも楽しいことです。ところで、AndroidでもCrushが使えることをご存知ですか？ :ロボット:

強化された MCP OAuth

前回のリリースでは、MCP の OAuth 認証のサポートがリリースされました。 @BrunoKrugel は、OAuth を必要とするより多くの MCP が期待どおりに動作するようにいくつかの修正を行いました。

エージェントによる修正

エージェントとしての Crush にもかなりの修正が加えられました。これらのいくつかは Fantasy で作成され、Crush に持ち込まれました。

新しいハイパー モデル

同様に重要なことですが、私たちは Hyper にアップデートを提供し続けています。これはこれまでよりも安定しており、Minimax M3 と Qwen3.7-Flash が利用できるようになりました。

今週は色々なことがありました！楽しんで、Crushing を続けていただければ幸いです :tm:! チャーム
