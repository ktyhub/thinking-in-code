crush v0.87.0

マイナー 公開日2026年7月24日 出典charmbracelet/crush 英語原文

#v0.87.0を潰す

MCP OAuth、パフォーマンスなど

みなさん、ハッピーフライデー！ 週末のバイブコーディングを楽しんでいただけるよう、いくつかの便利な機能をリリースします。 (そうでない場合は、外にいて :sun_with_face: 、月曜日にはクラッシュに戻りましょう! :smiley:)。

MCP OAuth

それはそれです、ついにここに来ました！長い間このことを求めていた人もいます。 これは一部の MCP が動作するために必要です。設定方法を知りたいですか? README のこのセクションを参照してください。 この貢献に対して @joestump と彼のエージェント @joestump-agent に感謝します。そしてもちろん、私たちのお気に入りの @tacturnaxolotl も助けてくれました。

クロード チャネル MCP 拡張機能

@joestump (および彼のエージェント) も、Claude Channels MCP 拡張機能 をサポートするための初期実装を追加しました。これは、MCP が特定のイベントが発生したときに Crush に通知を送信できることを意味します。 ご興味がございましたら、ぜひ試してみて、どの程度効果があるかお知らせください。

MCP プロンプトが復元されました

以前のリリースでは MCP プロンプトが意図せず無効になっていましたが、現在は再び追加されています。

LSP パフォーマンスの向上

もう 1 つの素晴らしい投稿は @TheJhyeFactor によって作成されました。彼は大規模なリポジトリで LSP サーバーを処理する際の CPU とメモリの使用量を大幅に改善しました。 最適化の詳細な説明については、#3370 を参照してください。

Bang モードのパフォーマンス向上

@TheJhyeFactor また、bang モードでコマンドを実行するときの出力ストリーミングのパフォーマンスも向上しました。 #3381 をチェックしてベンチマークを確認してください。

/etc/crush/crush.json

ちゃんと読んでますね！ @Muttaqin86 のおかげで、/etc/crush/crush.json でシステム全体の Crush 構成を使用できるようになりました。 その動機は、NixOS との互換性の向上でした。

固定副操縦士 + GPT-5.6

3 つの GPT-5.6 モデル (Sol、Terra、Luna) はすべて、GitHub Copilot 経由で実行すると修正されるようになりました。 @nghiant03 に感謝します! 大変なことではありましたが、コミュニティが Crush 開発にどれだけ関わっているかは本当に興味深いです。 クラッシュし続けてください！ :tm: チャーム
