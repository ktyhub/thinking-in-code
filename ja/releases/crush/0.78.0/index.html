バングモード

「バンモードって何ですか？」あなたは尋ねます。これがセッション内で Bash コマンドを直接実行できるようにするための優れた方法である理由は単純です。 Crush を離れることなくシェルを活用するのに最適です。強打モードに入るには、「!」と入力するだけです。終了するには、Backspace キーを押します。

をご覧ください](https://github.com/charmbracelet/crush#local-models)。 (クールなのか何なのか? 誰か @tacturnaxolotl に Strix Halo をプレゼントしてください!) ## clipboard: これまでよりも clipper になりました Crush、特に X11 と Wayland での clipboard の動作方法が大幅に改善されました。`xclip` と `xsel` はもう必要ありません。 TIFF を貼り付けることもでき (WeChat ユーザーの皆さん、お喜びください!)、<kbd>super+v</kbd> (はい、<kbd>⌘+v</kbd>、macOS のユーザー) も画像を貼り付けることができます。 ## 花火 ご好評により、Crush は新しいプロバイダー [Fireworks](https://fireworks.ai/) をサポートするようになりました。 API キーを手に取り、Fireworks でモデルを選択して街へ出かけましょう。 ## ありがとう いつものように、良い雰囲気を出し続けて、それを粉砕し続けてください！ Charm™ チーム ## Changelog ### 新しい! *
