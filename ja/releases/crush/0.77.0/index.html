#v0.77.0を潰す

グローバルコンテキスト、より良いコミットメッセージ…そしてあなた

少し経ちましたね！このリリースには良いものがたくさんあるので、早速見ていきましょう。

グローバルコンテキスト

クラッシュにいつもシャーリーと呼んでもらいたいですか?それとも、デフォルトを Jujutsu に設定したいでしょうか? @Amolith のおかげで、これはユーザーレベルのコンテキスト ファイルを使用して簡単にできるようになりました。 ~/.config/AGENTS.md または ~/.config/crush/CRUSH.md を作成すると、Crush は通常のプロジェクト レベルの AGENTS.md および CRUSH.md と同様に、セッション開始時にそれを参照します。ニース！

クラッシュしますか?キーランの時計には載っていない。

@tacturnaxolotl としても知られる Kieran は速いです。本当に速いです。先日、Crush が彼のためにクラッシュしました。彼は リップグロス と グラマー の 2 つのバグに焦点を当て、私たちが「パニックにならないでください!」と言う前にパッチを適用しました。ありがとう、キーラン！

コミットメッセージと PR 説明の改善

何が私たちを狂わせるか知っていますか？ LLM がコードのあいまいな部分を参照する過度に技術的なコミット メッセージや PR 記述を作成する場合。コミット メッセージと PR は、コードベースに詳しくない読者でも理解できるものでなければなりません。 この PR によりシステム プロンプトが改善され、LLM は人間にとってより明確で理解しやすいコミット メッセージを作成できるようになります。

名前付きフック

寄稿者 @BrunoKrugel のおかげで、フックに名前を付けることができるようになり、CLI 内でフックを識別しやすくなりました。

{
  "hooks": {
    "PreToolUse": [
      {
        "name": "Mr. Hot Hook",
        "matcher": "bash",
        "command": "./hooks/my-hot-hook.sh",
      },
    ],
  },
}

詳細については、https://github.com/charmbracelet/crush/pull/2778. を参照してください。

Client-server: ソケットの修正

Client-server モードはまだゴールデンタイムに向けた準備が整っていませんが、私たちの多くはそれにもかかわらず日常的に使用しています。 client サーバー モードの最も優れた点の 1 つは、UNIX ドメイン ソケット (これは本当に素晴らしい) と Windows 上の名前付きパイプ上で実行されることです。このリリースでは、それに関する 2 つのバグが修正されています。

  • 古いソケットが起動時にクリーンアップされ、Crush が適切に実行できるようになりました
  • UNIX システムでは、ソケットは実際に属する場所 (Linux では $XDG_RUNTIME_DIR、macOS では /tmp ではなく $TMPDIR) に存在するようになりました。 CRUSH_CLIENT_SERVER=1 で client-server モードを試してください。 ##また会いましょう Crush について肯定的なフィードバックをいただきありがとうございます。私たちは❤️あなたです！ チャーム
