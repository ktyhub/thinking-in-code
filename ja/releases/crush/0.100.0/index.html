#v0.100.0を潰す

サブエージェント、システム管理者モード、および PGP/SSH プロンプト

これは大きいですね！ Crush はサブエージェントのチームを実行できるようになり、権限がより柔軟になり、Crush 内で GPG および SSH 認証を直接実行できるようになりました。続きを読んでください。

👩🏼‍🐰‍👩🏽 サブエージェント

いよいよサブエージェントです。 Crush は、バックグラウンドで友好的なサブエージェントの小さなチームを生成できるようになりました。また、それらをチェックしたり、実行中にフォローアップを送信したり、停止したり、別のモデルに移動したりすることもできます。

<p><img width="600" alt="image" src="https://github.com/user-attachments/assets/a8f4f437-dd9a-46bb-ab31-65a14b84c07a" /></p>

トランスクリプト、サイドバー、ヘッダーで機能する様子を確認できます。すべてのサブエージェントにも独自の名前が付けられるため、誰が何をしているのかを常に把握できます。そして、あなたが彼らの名前を呼ぶと、クラッシュはあなたが彼らのうちの誰について話しているのかを知るでしょう！

🚨 システム管理者モード

Crush が DROP SCHEMA public CASCADE; できたらいいのにと思ったことはありませんか?システム管理者モードを使用すると、それができるようになりました。実際、システム管理者モードでは、Crush はシステム上であらゆるコマンドを実行できます。気をつけて。

<p><img width="600" alt="image" src="https://github.com/user-attachments/assets/c8ccbd1b-aba2-48cc-bef7-b15045b41241" /><p>

コマンド パレット (<kbd>ctrl+p</kbd>) でシステム管理者モードを見つけるか、<kbd>shift+tab</kbd> ですべてのモードを切り替えます。

🙅🏻‍♀️ 安全なコマンド

もちろん、Yolo モードは依然として危険なコマンドをブロックしますが、どのコマンドが危険であるかはあなた次第です。

  • permissions safe は、yolo にとって安全なコマンドをマークします
  • permissions block はコマンドを完全にブロックします
  • permissions unblock は制限されたコマンドのブロックを解除します
# Building is fine
permissions safe "go build" "cargo check"

# Don't touch my infra please
permissions block kubectl terraform

# Curl your heart out
permissions unblock curl

🗝️ PGP と SSH

AI エージェントを使用していて、SSH パスワードを入力したり、Yubikey をアクティブ化したり、GPG パスワードを入力したりできないのはとても面倒ですよね? Crush を使えば、その煩わしさは過去のものになります。

<img width="600" alt="out" src="https://github.com/user-attachments/assets/fb19ae55-8e0e-415e-8604-07029d9c9995" />

AI を使用するときにセキュリティを危険にさらす必要はもうありません。

<summary>アーティファクトの確認</summary>

まず、checksums.txt ファイル および checksums.txt.sigstore.json ファイル ファイルを、たとえば wget でダウンロードします。

wget 'https://github.com/charmbracelet/crush/releases/download/v0.100.0/checksums.txt'
wget 'https://github.com/charmbracelet/crush/releases/download/v0.100.0/checksums.txt.sigstore.json'

次に、cosign を使用して検証します。

cosign verify-blob \
  --certificate-identity-regexp '^https://github.com/charmbracelet/crush/\.github/workflows/(release|nightly)\.yml@' \
  --certificate-oidc-issuer 'https://token.actions.githubusercontent.com' \
  --bundle 'checksums.txt.sigstore.json' \
  ./checksums.txt

出力が Verified OK の場合は、sha256sum を使用してリリースからダウンロードした他のアーティファクトのチェックサムを検証するために安全に使用できます。

sha256sum --ignore-missing -c checksums.txt

完了！これでアーティファクトが確認されました。
