AstrBot v4.26.0-beta.2

プレリリース 公開日2026年6月16日 出典AstrBotDevs/AstrBot 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#アストラボットv4.26.0-beta.2

リマインダー: WebUI の「構成 -> システム構成」は、WebUI サイドバーの下の「設定」に移動されました。

注: WebUI の「Config -> System Config」は、WebUI サイドバーの下部にある「Settings」に移動しました。

  • アップデートログ(簡体字中国語)
  • Changelog(英語) <a id="中国語"></a>

何が変わったのか

主要な更新

  • WebUI システム構成ページを再構築し、システム構成エントリをサイドバーの下の設定領域に移動し、関連する設定、自動保存、および再起動プロンプトのエクスペリエンスを最適化しました。 (#8777)
  • 新しいプラットフォーム レベルの create_event エントリを追加しました。 StarTools がイベントを作成すると、イベントは代わりにプラットフォーム アダプターに委任されます。これにより、ツール層を特定のプラットフォーム実装にバインドすることが回避され、プラットフォームごとに排他的なイベント構築ロジックが完成します。 (#8813)

修正

  • プロジェクトの更新プロセスをアトミック操作に変更し、更新の中断または再開時に不完全な状態になるリスクを軽減します。 (#8805)
  • 静的リソースが欠落している場合でも WebUI Ready バナーが表示される問題を修正しました。 (#8804)
  • アトミック書き込みを使用して構成ファイルを保存し、書き込みの中断によって引き起こされる構成の破損の可能性を減らします。 (#8793)
  • ローカル Python ツールが現在のセッション ワークスペースで実行されない問題を修正しました。 (#8792)
  • 登録プロセス中に保護されたツールが誤って失われるのを防ぐために、実行ベースのツールの保護ロジックを修正しました。 (#8790)
  • 安定したダッシュボード ルーティング関連のテスト。最新の FastAPI 動作と互換性があります。 (コミット)

最適化とエンジニアリング

  • コアモジュールの Pyright 型エラーの数を減らし、型の絞り込み、宣言、境界チェックを補足します。 (#8197)
  • Ruff 書式設定を適用します。 (コミット)
  • 昇級 GitHub アクション中の pnpm/action-setup。(#8808) <a id="english"></a>

変更点 (英語)

ハイライト

  • WebUI システム構成エクスペリエンスを再編成し、システム構成エントリーをサイドバーの下部にある設定エリアに移動し、関連する設定、自動保存、および再起動通知を改善しました。 (#8777)
  • プラットフォーム レベルの create_event フックを追加しました。これにより、StarTools は、具体的なプラットフォーム実装にバインドするのではなく、イベントの作成をプラットフォーム アダプターに委任し、アダプター全体にプラットフォーム固有のイベント構築が追加されました。 (#8813)

バグ修正

  • プロジェクトの更新フローをアトミックにし、中断または再起動中の不完全な更新状態を減らしました。 (#8805)
  • 静的アセットが欠落している場合に WebUI 対応バナーが表示されるのを回避しました。 (#8804)
  • 構成ファイルをアトミックに書き込み、書き込みの中断中に破損する可能性を減らしました。 (#8793)
  • ローカルの Python ツールが現在のセッション ワークスペース内で実行されるようにしました。 (#8792)
  • 登録中に保護された実行ベースのツールを保持します。 (#8790)
  • 最新の FastAPI 動作に対するダッシュボード ルート テストが安定しました。 (コミット)

改善とメンテナンス

  • より厳密な絞り込み、宣言、境界チェックにより、コア モジュール全体での Pyright 型エラーが減少しました。 (#8197)
  • Ruff フォーマットのクリーンアップを適用しました。 (コミット)
  • GitHub アクションの pnpm/action-setup を更新しました。 (#8808)
