AstrBot v4.29.1

#AstrBot v4.29.1

2026 年 11 月 1 日に、< Python 3.12 バージョンのサポートを終了する予定です。Python バージョンがまだ 3.10、3.11 である場合は、適時に新しい Python バージョンに置き換えてください。
3.12 より前のバージョンの Python のサポートは 11 月 1 日に終了する予定です。現在 Python、3.10、または 3.11 を使用している場合は、新しいバージョンの Python にアップグレードしてください。

[4.29.1] - 2026-10-17

新しい

  • Web 検索: 「Web 検索」機能が追加されました [SerpApi 検索サービス] (https://serpapi.com/) (Google Web 検索、画像検索、学術検索、金融検索)、[DeepSeek 検索サービス] (https://api-docs.deepseek.com/zh-cn/guides/search/) (Web 検索、Web コンテンツ抽出)。 (#10599)
  • プラグイン開発: ローカライズされた subtitles 字幕メタデータをプラグインの単一選択/複数選択構成項目 (リスト型) に追加します。

修正

  • ‼ ️ コンピューターの使用: 一部の環境 (Docker コンテナー環境など) でローカル分離が利用できない場合、ローカル権限を保存できない問題を修正しました。 (#10584)
  • PC の使用: Windows でワークスペース全体のファイルの読み取り、書き込み、編集を復元し、ネイティブ ファイル ハンドル チェックによって再解析ポイントとハード リンク エイリアスを拒否します。 (#10584)
  • コア: 「セッション分離」機能をオンにすることによって発生する可能性のあるメモリ リークを修正します。メッセージ処理パイプラインを登録する前にグループ チャット セッションの分離を完了して、実行中のタスクと停止リクエストが正しいセッションを使用していることを確認します。 (#10581)
  • Telegram: メッセージを変換するときに非表示のリンクを保持します。 (#10557)
  • Discord: すべてのメンバーのメンションを修正しました。 (#10563)
  • WebUI: モバイル端末でプラグインビュー情報をクリックした直後にフローティングレイヤーが閉じてしまう問題を修正しました。 (#10562)
  • Edge TTS: リクエストの失敗を避けるために、ネイティブ クライアントのユーザー エージェントを保持します。 (#10588)
  • スキル: 単一のディレクトリ例外によってエージェント リクエスト全体が失敗することを避けるため、読み取り不可能なローカル ディレクトリとプラグイン スキル ディレクトリをスキップします。 (#10591)

追加

  • Web 検索: SerpApi (Google 検索、Google 画像検索、Google Scholar 検索、Google Finance 検索) および DeepSeek 検索 API (Web 検索およびページ コンテンツ抽出) を追加しました。 (#10599)
  • プラグイン開発: プラグインの単一選択/複数選択構成オプション (タイプ「リスト」) にローカライズされた字幕メタデータを追加しました。

修正済み

  • ‼ ️ コンピューターの使用: Windows でのワークスペース スコープのファイルの読み取り、書き込み、編集が復元されました。ネイティブ ハンドル チェックでは、再解析ポイントとハードリンク エイリアスが拒否されます。 (#10584)
  • コンピューターの使用: 分離が利用できない場合のローカル権限の保存を修正しました。ファイル アクセスは引き続き構成可能です。利用できない分離を必要とする実行は、ツールの実行時にブロックされます。デフォルトでは、メンバーには実行なしでワークスペース ファイルへのアクセスが許可され、管理者にはネットワークを使用して環境全体の実行が許可されます。すべてのアクセスが無効になっている従来の Windows メンバー ポリシーは、元のものが保存されていないために手動で同一に無効になったポリシーを含め、ワークスペース ファイル アクセスに一度移行されます。その後の選択肢は変更されません。 (#10584)
  • コア: 「セッション分離」機能が有効になっている場合に発生する可能性のある潜在的なメモリ リークを修正しました。グループ チャット セッションの分離は、メッセージ処理パイプラインを登録する前に実行されるようになり、進行中のタスクと終了リクエストの両方で正しいセッションが使用されるようになります。 (#10581)
  • Telegram: メッセージの変換時に隠しリンクが保持されます。 (#10557)
  • Discord: 全員のメンションを修正しました。 (#10563)
  • WebUI: モバイルでタップするとプラグイン表示情報のポップオーバーが開きます。 (#10562)
  • Edge TTS: リクエストの失敗を回避するために、ネイティブ client ユーザー エージェントを保持しました。 (#10588)
  • スキル: エージェントのリクエスト全体を失敗させる代わりに、読み取り不可能なローカルおよびプラグインのスキル ディレクトリをスキップしました。 (#10591)

完全な Changelog: https://github.com/AstrBotDevs/AstrBot/compare/v4.29.0...v4.29.1

何が変わったのか

  • 修正: https://github.com/AstrBotDevs/AstrBot/pull/10557 の @wcqqq1214 による変換されたメッセージ内の Telegram の隠しリンクを保持する
  • 修正: https://github.com/AstrBotDevs/AstrBot/pull/10563 で @wcqqq1214 が全員に言及した Discord を修正
  • 修正 (ダッシュボード): https://github.com/AstrBotDevs/AstrBot/pull/10562 の @lingyun14beta により、プラグイン ビュー情報のポップオーバーがモバイル上で開いたままになります
  • 修正（コア）: https://github.com/AstrBotDevs/AstrBot/pull/10581 の @Soulter によるパイプライン登録の前にセッションを分離
  • 修正: Windows ワークスペース ファイルを復元し、https://github.com/AstrBotDevs/AstrBot/pull/10584 の @Soulter によるローカル アクセス許可を簡素化
  • feat(websearch): DeepSeek 検索とページ取得を追加 (@letr007 による https://github.com/AstrBotDevs/AstrBot/pull/10599)
  • ドキュメント: 簡体字中国語の行動規範を追加し、https://github.com/AstrBotDevs/AstrBot/pull/10580 の @XTsat によって問題テンプレートにリンクします。
  • 修正: https://github.com/AstrBotDevs/AstrBot/pull/10588 の @wcqqq1214 によるネイティブ Edge TTS ユーザー エージェントの保持
  • 修正(スキル): https://github.com/AstrBotDevs/AstrBot/pull/10591 の @he-yufeng によるリクエスト全体が失敗しないように、1 つの読み取り不可能なスキル ディレクトリを維持
  • 功績: SerpApi 検索ツールと、https://github.com/AstrBotDevs/AstrBot/pull/10601 の @Soulter によるプロバイダーの説明を追加
  • 雑用: https://github.com/AstrBotDevs/AstrBot/pull/10602 の @Soulter による 4.29.1 へのバージョンのバンプ
