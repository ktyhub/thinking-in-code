#アストラボットv4.30.0-beta.1

[4.30.0-beta.1] - 2026-11-18

**このバージョンはベータ版であり、不安定性や互換性の問題がある可能性があります。まずはテスト環境で検証することをお勧めします。この時間には、会話データベース、エージェント構成、およびセッション設定の移行が含まれます。アップグレードする前にデータと構成をバックアップしてください。古いバージョンにロールバックする場合は、同時にアップグレードする前にバックアップを復元する必要があります。 **

v4.30.0-alpha.1 以降の更新

  • ユーザーが命令 (ステアリング) を追加すると、待機中のツール呼び出しは自動的にバックグラウンド タスクに移動され、フォアグラウンドで新しい入力の処理が続行されます。 (#11142)
  • QQ公式グループチャットのストリーミング返信がマージされる問題を修正しました。 (#11229)
  • QQ 公式アダプターはプライベート チャット ユーザーの名前の取得をサポートし、グループ チャットの表示名はグループ内のユーザーのニックネームを使用することによって優先されます。 (#11184)
  • プラグイン ビュー機能のアップグレード: ChatUI には、新しいページング ワークベンチと常駐プラグイン ビューが追加され、「+」からビューを開くこと、ドラッグして幅を調整すること、全画面表示、セッションごとのタブとレイアウトの復元をサポートします。 (#11218)
  • プラグイン ビュー機能のアップグレード: プラグインは、チャット メッセージ内でインタラクティブな HTML コンポーネントを表示し、コマンド、メッセージ プロセッサ、またはモデル ツールを通じてコンポーネントを作成し、ユーザー操作を処理できます。他のプラットフォームではテキストのフォールバックが保持されます。 (#11179)
  • プラグイン ビュー機能のアップグレード: プラグイン ビューは metadata.yaml および views で統一的に宣言されます。 (#11218)
  • ChatUI は、編集可能な下書きへの音声の文字起こしをサポートします。 「会話/テキスト読み上げ/テキスト読み上げ」カテゴリ エントリが、ChatUI のモデル構成ページの上に追加されます。 (#11170)
  • チャット推論サイドバーを、メッセージ内で折りたたみ可能な実行中の詳細に変更し、考え、ツール呼び出し、および中間応答をグループで表示します。バックエンドが実行を継続している場合、更新または再接続することで進行中の会話を再開し、その後の応答を保持できます。 (#11166)
  • Gemini 4 シリーズの推論強度構成をサポートし、プレビュー モデルを改善し、パラメーターの互換性を要求します。 (#11219)
  • コンテキスト トークンの推定と切り捨ての繰り返し計算を削減し、セッション メタデータと冪等クエリをマージし、パフォーマンスを最適化します。 (#11167、#11199)
  • スケジュールされたタスクとバックグラウンド タスクが起動すると、完了概要の追加の自動送信を避けるために、通知は明示的なメッセージング ツールを通じてのみ送信されます。 (#11198)
  • OpenRouter の非ストリーミング応答で推論の詳細を保持します。 (#11168)
  • Gemini 履歴メッセージの URL オーディオ処理を修正し、SDK 3.4 の下にカスタム ユーザー エージェントを保存します。 (#11143、#11196)
  • DashScope TTS は Qwen-Audio-TTS をサポートします。 (#10495)
  • System One のブール判定は、オプションの真偽判定条件をサポートし、一部の互換性のあるエンドポイント接続テストで HTTP 400 が返される問題を修正しました。 (#11062)
  • チャット セッションを切り替えるときにウェルカム ページが点滅する問題を修正し、非推奨の VoceChat アイコンの参照を削除しました。 (#11182、#11186)
  • ローカルの AstBot データからテスト構成を分離し、Windows データベースのクリーンアップを改善し、プロジェクト配信テストでの Git 署名を明示的に無効にします。 (#11231、#11222)
  • プラグイン開発ドキュメントの QQ グループ情報を更新しました。 (#11178)

alpha.1 メジャー アップデート

  • セッション バックエンドをイベント ソーシング モードに移行して、コンテキストの繰り返し書き込みと部分的な書き込み増幅を削減し、ストレージ パフォーマンスを最適化します。メッセージとツール呼び出しを段階的に保存し、実行中断後の履歴処理を改善します。 (#10077、#11158、#11162)
  • 新しいエージェント ランタイム モデルの導入。プラグインは、ctx.agent.run_turn() 経由でエージェント ターンを呼び出すことができます。 (#10934、#10936、#11052、#11148、#11153)
  • サブエージェントを、独立したコンテキストを持つバックグラウンド タスクに再構築し、一般エージェントと特別エージェント、追加の命令、および結果の戻りをサポートします。入り口はサイドバーから **プロファイル → AI → 機能 → サブエージェント ** に移動し、プロファイルによって管理されます。 (#11053)
  • カスタム ルールとセッション管理を [構成ファイル] → [セッション構成マッピングの管理] に統合し、基本的な構成とフィールド カバレッジ、バッチ編集とリカバリの継承をサポートします。モデルの説明書とページは同じ設定を共有します。 (#11097)
  • ワークスペースの分離、コード実行、ネットワーク制御をサポートする Windows AppContainer ネイティブ サンドボックスを追加しました。 (#10466)
  • DeepSeek 音声認識および音声合成プロバイダーを追加しました。 (#11118)
  • OpenAI Decisions 判定モデルを追加し、選択、ブール判定、スコアリングをサポートしました。 (#10968)
  • ようこそページ → 概要: 毎日の使用状況、システム リソース、ロボットの異常が表示されます。 (#11100)
  • 外観設定でサイドバーにチャット入口を配置できるようにしました。 (#11090)
  • アップグレードされた Markdown レンダリング、オンデマンドでのチャットおよび構文ハイライト リソースの読み込み。 (#11138)
  • プラグイン設定は折りたたみ可能なグループをサポートし、デフォルトの折りたたみ状態を宣言できます。 (#11067)
  • プラグイン ページでは、現在のテーマの色とその変更を取得できます。 (#11046)
  • AI 開発ドキュメントを再編成し、プラグイン構成制御の例とスクリーンショットを追加しました。 (#11154)

alpha.1 最適化と修復 (そのままの状態を維持)

  • 操作中の追加入力の保存と継続を改善しました。 (#11141)
  • メインセッションのブロックを避けるために、実行時に使用できないサブエージェント構成をスキップします。 (#11128)
  • 実行時に無効になっている、欠落している、または使用できないサブエージェント構成の選択を解除できるようにします。 (#11147)
  • フル ツール スキーマ モードでのデフォルトのツール呼び出しプロンプト ワードを削除しました。 (#11152) ・最後に成功したモデルのリトライが失敗と判定されてしまう問題を修正しました。 (#10922)
  • Anthropic の非ストリーミング応答で複数のテキスト ブロックが欠落している問題を修正しました。 (#11057)
  • 検索キーの有効期限が切れたり、残高が不足したりした場合は、設定されている他のキーを試してください。 (#10877)
  • Gemini TTS のデフォルト モデルを gemini-3.8-flash-tts に更新しました。 (#10828)
  • 失われた写真、ファイル、その他のメディアに QQ ボタンが応答する問題を修正しました。 (#10903)
  • QQ イメージのアップロードが失敗した場合に完全なイメージ ロードを記録しないようにし、パネルへのログの影響を軽減します。 (#10740)
  • OneBot ストリーミング セグメンテーションを最適化して、長いテキストの繰り返しスキャンを削減します。 (#10989)
  • 送信者がユーザー名を持たない場合、Telegram は表示名を使用します。 (#10715)
  • Firefox でのチャット履歴のスクロールの問題を修正しました。 (#11036)
  • モデル構成を編集するときにプレビューと機能の識別が一致しない問題を修正しました。 (#10792)
  • WebUI メニューとポップアップ ウィンドウのスタイルを統一し、スクロール バーとクリック フィードバックを最適化します。 (#11107、#11090、#11102)
  • EPUB 解析でリンク テキストが欠落する問題を修正しました。 (#10794)
  • GIF をパズルに変換した後も説明を保持し、歴史的文脈におけるアニメーション情報が失われないようにします。 (#10837)
  • フィルタリングとトラブルシューティングを容易にするために、プラグインのロードと実行の失敗ログを対応するプラグインに関連付けます。 (#10904)
  • スタック接続状態を回避するために、SSE ストリームが閉じられたときにプラグイン ページに通知します。 (#10932)
  • コンソール ログのタイムスタンプは日付ごとに増分されます。 (#9617) これはベータ版であるため、安定性や互換性の問題が発生する可能性があります。まずテスト環境で検証してください。このリリースでは、会話ストレージ、エージェント構成、およびセッション設定が移行されます。アップグレードする前にデータと構成をバックアップしてください。ダウングレードには、アップグレード前のバックアップの復元も必要です。

v4.30.0-alpha.1 以降の変更点

  • + ランチャー、サイズ変更可能なパネル、全画面モード、タブとレイアウトのセッションごとの復元を備えた、タブ付き ChatUI ワークベンチと常駐プラグイン ビューを追加します。 (#11218)
  • プラグインでチャット メッセージ内のインタラクティブな HTML コンポーネントをレンダリングし、コマンド、メッセージ ハンドラー、またはモデル ツールを通じてコンポーネントを作成し、ユーザー アクションを処理できるようにします。他のプラットフォームでテキストのフォールバックを保持します。 (#11179)
  • views の下の metadata.yaml でプラグイン ビューを宣言します。 (#11218)
  • プラグイン ビューと ChatUI カードのドキュメントを、スタンドアロン ページ、メッセージ コンポーネント、ワークベンチを中心に編成されたプラグイン ビュー セクションに統合します。以前のリンクからのリダイレクトを使用して、バイリンガルのチュートリアル、スクリーンショット、例を追加します。 (#11179、#11218)
  • 編集可能な下書きにマイクのディクテーションを追加し、音声メッセージを直接録音して送信します。統合モデル構成セレクターを会話 / Speech to Text / Text to Speech カテゴリに置き換えます。 (#11170)
  • 推論サイドバーを、思考、ツール呼び出し、中間応答をグループ化した折りたたみ可能なインライン実行の詳細に置き換えます。更新または再接続後にアクティブな会話を再開し、バックエンドが実行されている間は後続の応答を保存します。 (#11166)
  • フォローアップ入力が到着したときに、サポートされている保留中のネイティブ ツールをバックグラウンドに移動し、フォアグラウンドで処理できるようにします。発信者の ID、権限、および完全なバックグラウンド結果を保持し、完了時に元の会話を復帰させ、セッションが停止したときに転送された作業をキャンセルします。 (#11142)
  • QQ 公式送信者プロファイル、アバター、およびオンデマンドのユーザー情報クエリをサポートし、グループの表示名としてグループのニックネームを優先します。 (#11184)
  • Gemini 4 推論エフォート構成をサポートし、プレビュー モデルとリクエスト パラメーターの互換性を向上させます。 (#11219)
  • 繰り返されるコンテキスト トークンの推定と切り捨て作業を削減し、会話メタデータと冪等性検索をマージします。 (#11167、#11199)
  • 明示的なメッセージ ツールを通じてスケジュールされた通知とバックグラウンド タスクの通知を送信し、余分な自動完了サマリーを回避します。 (#11198)
  • QQ 公式グループのストリーミング返信がマージされないようにします。 (#11229)
  • 非ストリーミング OpenRouter 応答で推論の詳細を保持します。 (#11168)
  • Gemini 履歴での URL オーディオ処理を修正し、SDK 3.4 でカスタム ユーザー エージェントを保持します。 (#11143、#11196)
  • DashScope TTS プロバイダーで Qwen-Audio-TTS をサポートします。 (#10495)
  • System One のブール決定に対するオプションの true/false 基準をサポートし、それを必要とする互換性のあるエンドポイントでの HTTP 400 接続テストの失敗を修正します。 (#11062)
  • チャット セッションを切り替えるときにようこそ画面が点滅するのを防ぎ、従来の VoceChat ロゴ参照を削除します。 (#11182、#11186)
  • ローカルの AstBot データからテスト構成を分離し、Windows データベースのクリーンアップを改善し、プロジェクト配信テストでの Git 署名を明示的に無効にします。 (#11231、#11222)
  • プラグイン開発ドキュメントの QQ グループ情報を更新します。 (#11178)
