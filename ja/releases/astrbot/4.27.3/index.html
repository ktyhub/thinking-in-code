#アストラボットv4.27.3

[4.27.3] - 2026-08-13

そしてまた星を見に出かけました。 私たちはそこから出て、再び星を見ました。

追加

  • AstBot Desktop はパスワードなしのセッションを使用し、ログインを必要とせずに WebUI を直接開きます。 (#9585)
  • 有効な AstBot 時間を設定に追加し、cron ジョブが設定されたタイムゾーンを継承するようにしました。 (#9579、#9581)
  • WebChat のドラッグ アンド ドロップによるアップロードをチャット エリア全体に拡張しました。 (#9564)
  • プラグイン設定のデフォルトを復元するための one-click オプションを追加しました。 (#9599)
  • Windows ローカル シェルに対する PowerShell 7 のサポートを追加しました。 (#9622)
  • プラグイン マーケットプレイスにダウンロード数のソートを追加しました。 (#9570)
  • 大きなファイルをより確実にサポートするために、QQ 公式にチャンク ファイルのアップロードを追加しました。 (#9646)
  • デフォルトのプラグインアイコンとしてファビコンを使用し、ダークテーマのテキストのコントラストを改善しました。 (#9547、#9643)

変更されました

  • 移行された SharedPreferences と構成設定の非ブロッキング パスへのアクセスにより、影響を受けるフローのパフォーマンスが向上し、明らかなフリーズやデッドロックのリスクが軽減されます。 (#9582、#9584、#9649)
  • ナレッジ ベースのドキュメント検索の安定化、読み込み失敗と空の結果の区別、完全な検索結果の復元、ナレッジ ベースを名前で解決する際の UUID フォールバックのサポート。 (#9577、#9578、#9618、#9636)
  • 削除後にメモリ内のプロバイダー構成が更新され、ダッシュボード全体でプラグインのスキル状態が同期されました。 (#9568、#9596)
  • 一時的なプロジェクト セッションが ChatUI に表示されるのを防ぎ、失われた WebChat セッションを復元しました。 (#9587、#9607)
  • LLM API の MCP ツール名をサニタイズし、空の構成スキーマを構成可能な項目がないものとして扱いました。 (#9534、#9619)
  • 明示的に構成された WebUI ディストリビューションが古い場合に警告されます。 (#9518)
  • 統計を公開する前にエージェントの終了時間を記録し、停止したエージェントの実行をすぐにキャンセルしました。 (#9597、#9602)
  • アニメーション化された Telegram ステッカーに静的なサムネイルを使用し、Telegram ビデオ ノートをビデオ コンポーネントに変換しました。 (#9610、#9627)
  • QQ メディアのアップロードの失敗が、サイレントに続行されるのではなく伝播されました。 (#9644)

メンテナンス

  • グループ化された GitHub アクションの依存関係を更新し、パイプライン スケジューラのタイピングを改善し、OpenAI HTTP client テストを安定化しました。 (#9620、#9621)

中国語

新しい

  • AstrBot デスクトップはログイン不要の仕組みを実装しており、ログインせずに直接 WebUI に入ることができます。 (#9585)
  • Windows ネイティブ シェルに PowerShell 7 サポートが追加されました。 (#9622)
  • QQ公式ロボットは、大きなファイルを正常に送信できない問題を修正するために、分割されたファイルアップロードを追加しました。 (#9646)
  • WebChat のドラッグ アンド ドロップ アップロード エリアをチャット エリア全体に拡張しました。 (#9564)
  • ワンクリックでプラグイン設定のデフォルト値を復元する機能を追加しました。 (#9599)
  • 設定でAstrBotの実際の有効時間を表示し、スケジュールされたタスクに設定されたタイムゾーンを継承させます。 (#9579、#9581)
  • プラグイン マーケットに新しく追加されたプラグインは、ダウンロード量によって並べ替えられます。 (#9570)
  • ファビコンをプラグインのデフォルトアイコンとして使用し、暗いテーマでのテキストのコントラストを改善します。 (#9547、#9643)

修正

  • 一部のパフォーマンスが向上し、潜在的な一時停止アニメーションやデッドロック状況が減少しました (移行された SharedPreferences と非同期のノンブロッキング パスへの構成設定アクセス)。 (#9582、#9584、#9649)
  • ナレッジ ベースのドキュメント検索を安定化し、ロードの失敗と空の結果を区別し、完全な検索結果を復元し、ナレッジ ベースを名前で検索する際の UUID フォールバックをサポートします。 (#9577、#9578、#9618、#9636)
  • プロバイダ設定を削除した後にメモリのステータスを更新し、ダッシュボードでプラグインのスキルのステータスを同期します。 (#9568、#9596)
  • 一時的なプロジェクト セッションが ChatUI セッション リストに表示されないようにし、失われた WebChat セッションを復元します。 (#9587、#9607)
  • LLM API に送信された MCP ツール名をクリーンアップし、空の構成スキーマを構成項目として正しく処理しません。 (#9534、#9619)
  • 明示的に構成された WebUI リリース ファイルが古い場合に警告します。 (#9518)
  • 統計を公開する前にエージェントの終了時刻を記録し、停止したエージェントの実行をすぐにキャンセルします。 (#9597、#9602)
  • Telegram の動的なステッカーは静的なサムネイルに置き換えられ、Telegram のビデオ メッセージはビデオ コンポーネントに変換されます。 (#9610、#9627)
  • QQ メディアのアップロードが失敗した場合、エラーは上方に正しく渡され、サイレントに続行されなくなりました。 (#9644)

メンテナンス

  • AstrBot デスクトップは、アップデート ソースとして Cloudflare R2 を使用します。
  • GitHub アクション依存関係グループを更新し、パイプライン スケジューラ タイプの注釈を改善し、OpenAI HTTP クライアント テストを安定させました。 (#9620、#9621)

  • https://github.com/AstrBotDevs/AstrBot/pull/9582 の @RC-CHN による同期共有設定のリファクタリング/削除
