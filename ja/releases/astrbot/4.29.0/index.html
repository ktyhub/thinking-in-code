#アストラボットv4.29.0

[4.29.0] - 2026-10-14

このリリースには、v4.29.0-beta.1 および v4.29.0-beta.2 からのすべての変更に加え、v4.29.0-beta.2 以降の変更が含まれています。フルリリース範囲は v4.28.0 から始まります。

主な追加点

  • コンピューターの使用: ローカル実行環境用の OS 固有のサンドボックス サポートが追加されました。シートベルトを備えた macOS とバブルラップを備えた Linux でのみ利用可能です。参照：https://docs.astrbot.app/use/astrbot-agent-sandbox.html (#9472)
  • ChatUI: チャット履歴とサイドバー セッションのページネーション、永続的な入力ドラフト、セッションごとのモデル選択、プロジェクト切り替え時の入力オートフォーカスが追加されました。 (#9667、#10279、#10247、#10301)
  • ChatUI: プロバイダー ソース フィルターとスティッキー グループをモデル選択に追加し、さらにスキル ページと MCP ページでの検索を追加しました。 (#10084、#10217)
  • テキストから画像への設定は [設定] から [構成プロファイル] → [拡張機能] に移動し、プロファイルごとに個別に構成されるようになりました。
  • 管理者とホワイトリストの設定は、構成プロファイル → プラットフォーム から 構成プロファイル → アクセス制御 に移動しました。 (#10321)
  • WebUI: ワークスペース ディレクトリ ピッカーを追加し、デスクトップ アプリでダウンロードの進行状況を更新します。 (#10222、#10227、#10050)
  • デスクトップ: WebUI のサイドバーとトップ バーに macOS の曇りガラス効果を追加しました。 (#10222、#10227、#10050)
  • コア: エージェント ステップ予算リマインダーの追加、従来の制限の移行、デフォルトのエージェント ステップ制限の増加、およびシェル セッション待機の延長。 (#10131、#10133)
  • コア: プロバイダー要求に x-astrbot-conversation-id 会話 ID ヘッダーを追加しました。 (#10218、#10237)
  • WebUI: 選択したモデルの横およびモデル/フォールバック メニューにモデル設定のショートカットを追加しました。そのモデルを使用するすべての構成プロファイルの変更はすぐに保存されます。 (#10321)
  • WebUI: コンソール ログ検索とキーワード ハイライト、スキルのソース バッジ、ChatUI でのステージングされたイメージ プレビューを追加し、最後に開いた [データとログ] タブを記憶しました。 (#10327、#10339、#10376、#10251)
  • WebUI: ボットエディターからサイドドロワーで構成プロファイル編集を追加しました。 (#10310)
  • Docker: コンテナ内のパスワードをリセットするための astrbot CLI が含まれています。 (#10442)
  • ログ: レベル、ソース、プラグイン、プラットフォーム、およびキーワードの組み合わせフィルタリング、ユーザー チャット ログを非表示にするオプション、および 8 ～ 16 ピクセル (デフォルトでは 12 ピクセル、2 ピクセル単位) のフォント サイズ制御を追加しました。プラグイン セレクターには、ID を含む表示名が字幕として表示されます。 (#10514)

主な最適化

  • WebUI: サイドバーとトップバーを改良し、より多くの情報を表示するために垂直方向のフットプリントを削減しました。 (#10222、#10227、#10050)
  • データとログ ページの会話データのプレビューが改善されました。 (#10021、#10020、#10023、#10108)
  • メモリ使用量を制限した再開可能なチャンクアップロード、ダッシュボードの静的アセットの圧縮、バンドルされたフォントと図アセットの削減を追加しました。 (#10123、#10187、#10034)
  • ストリーミング応答と推論パネルのスクロールの改善、履歴の読み込み中のスクロール位置の保持、アニメーション フレームごとの合体自動スクロール。 (#10219、#10221、#10243、#10253、#10257、#10271)
  • モデル入力画像の準備が改善され、画像ジオメトリが保存され、エンコードされた画像サイズが制限され、モデルへのアニメーションからフレームへの変換が説明されました。 (#9703、#10071、#10120、#10119)
  • コンソール ログのバッチ レンダリング、プロバイダー ダイアログとトレースの更新の最適化、不要なセッションとレート制限の作業の削除。 (#9990、#10007、#10270、#10273、#10274)
  • WebUI: VAD、Monaco、翻訳、ApexChart の遅延読み込みと gzip 応答の有効化により、初期読み込みのオーバーヘッドが大幅に削減され、読み込み速度が向上しました。 (#10413)
  • WebUI: スクロール中にコンテンツの境界線と角を固定し、デスクトップの右/下に 6 ピクセルのギャップを追加し、コンテンツ ペインのスクロール中に構成/設定ヘッダーとセクション ナビゲーションを固定しました。 (#10480)
  • コンピュータの使用: ローカル権限アクセス モードを明確にし、ローカル分離が利用できない場合でも実行とファイル アクセスの制御を表示し続け、セットアップ ガイダンスを統合されたエージェント サンドボックス ガイドにリンクしました。 (#10444、#10445、#10487)
  • ドキュメント: 最新の中国語と英語のプラグインと、現在のワークフロー、トラブルシューティング、ローカライズされたスクリーンショットを含む組み込み AI ガイド。 Slack と Lark/Feishu のセットアップ手順を更新しました。 (#10487、#10353、#10400)
  • ログ: メモリ内フィルタリング用に構造化されたソース、プラグイン、プラットフォーム、およびカテゴリのメタデータを追加しました。一番下までスクロールすると新しいログが自動的に続き、古いエントリを表示するときに読み取り位置が保持されます。 (#10514)
  • エージェント: システム プロンプトを安定させ、プロンプト キャッシュの再利用を維持するために、実行ごとにスケジュールされたタスクのコンテキストを会話履歴の後に移動しました。 (#10549)

  • 以前のコマンド動作を復元しました。/reset は現在の会話コンテキストをクリアします。 /new は新しい会話を作成し、新しい会話に切り替えます。永続的な会話の削除と履歴のタイトルを修正しました。 (#10118、#10003、#9983)
  • キューに入れられたリクエスト履歴の更新、セッション ロック前の添付ファイルの準備、LLM 処理が無効になった後もキューに入れられたリクエストが継続される問題を修正しました。 (#10238、#10209、#10234)
  • WebChat サイドスレッド モデルの選択、プロアクティブ エージェント モデル フォールバック、WebChat ウェイク プレフィックス ゲーティング、およびストリーミング フォールバック応答を修正しました。 (#10065、#10028、#10245、#10025)
  • スケジュールされたエージェントの失敗レポート、コンテキスト圧縮、プラグイン フィルターを修正しました。無効な編集後のリマインダーの保持、タスクの所有権の明確化、cron の誤起動猶予期間の 300 秒への増加。 (#9987、#9992、#10163、#10075、#10104、#10183)
  • OpenAI 互換のエンドポイント解決、スタックされた SDK 再試行、思考タグ解析、Gemini ナレーション履歴、Azure TTS client ライフタイム、Xinference リランク エラー伝播、および絵文字トークン推定を修正しました。 (#10079、#9669、#10116、#10132、#10101、#10051、#10216)
  • Lark のプライベート メッセージ配信、QQ 公式メンションと C2C ストリームの完了、OneBot ファイル解決、過剰な Telegram ポーリング ログを修正しました。 (#10018、#9705、#10069、#10098、#10046)
  • クリアされたSatoriハートビート/再接続設定とWeChat公式アカウントのタイムアウトフィールドが予期される安全策を無効にする問題を修正しました。 (#10248、#10229)
  • URL およびファイルからのプラグインの更新、Windows の長いパスのプラグインの抽出、およびデフォルトの GitHub ブランチ解決を修正しました。 (#10053、#10193、#10080)
  • Web 検索パラメーターの処理、ナレッジベースの URL レート制限、ファイル編集時のリテラル エスケープ、画像添付ファイルの有効期間とクリーンアップ、応答をドロップするセグメント応答ログの失敗を修正しました。 (#9979、#10015、#10112、#10042、#10090、#10231)
  • SQLModel のアップグレード全体での日時の永続性を修正し、プラットフォーム メッセージ履歴のカットオフを UTC で比較しました。 (#10211、#10246)
  • 古いデスクトップ WebUI アセットと提供されるバージョンの検出、モバイル ドロワーの動作、ダークモード アイコンとコンソールのコントラスト、非表示の会話、レガシー アイコン、アンマウント後の統計タイマーを修正しました。 (#9898、#10156、#10256、#10061、#10135、#10129、#10278、#10272)
  • エージェント: セッションを停止すると、バックグラウンド エージェントの作業が停止し、メイン エージェントの遅れたウェイクアップが防止されるようになりました。セッション ウェイターを 1 回だけクリーンアップし、非同期ツール ジェネレーターを同じタスク内に保持しました。 (#10323、#10347、#10474)
  • エージェント: バックグラウンド タスクの結果がユーザーに配信されず、一致するプラットフォームがない場合に cron 送信の記録を回避した場合に警告されます。 (#10398、#10468)
  • コア: コンテキスト サマリーの失敗後にすぐに戻り、コマンド グループ名を単語全体として照合し、1 つの編集可能なシステム デフォルト ペルソナを維持し、ペルソナ フォルダーを削除するときに子フォルダーを保持しました。 (#10436、#10372、#10287、#10361)
  • プロバイダー: 空のストリーム入力による Anthropic ツール呼び出しの保存、カスタム サーバー ツールと登録済みツールのマージ、廃止された Gemini 埋め込みデフォルトの gemini-embedding-001 への置き換え、Dify ストリームでの CRLF セパレーターの処理。 (#10432、#10437、#10393、#10392)
  • 画像: ローカル パスを作成する代わりに、未解決および非正規の画像参照を拒否し、オーディオ/ビデオ/ファイルの保留中のパス処理を保持し、非厳密なペイロード アセンブリ中に無効な画像をスキップしました。サイズ超過の Base64 ペイロードと長い Windows パスに対する耐性が追加されました。 (#10434)
  • オーディオ: ターンを失敗することなく解決できない音声添付ファイルを劣化させ、フォーマット プローブのブロックを回避し、リクエスト後に FishAudio TTS clients を閉じました。 (#10337、#10055、#10358)
  • プラットフォーム: Telegram での UTF-16 オフセットと大文字と小文字を区別しないボットの言及を修正し、デフォルトで Telegram トークンを空のままにしました。 Slack コードブロック、引用、リスト、リンク、メンションを保存し、アップロード前にリモート Slack ファイルを解決しました。 Discord ビデオ コンポーネントを添付ファイルとして送信し、自己返信ループを防止しました。 (#10367、#10399、#10365、#10380、#10447、#10448、#10355、#10423、#10425)
  • WebUI: チャット メッセージの送信時にセッションの所有権を強制し、添付ファイルを一意の名前で保存し、プラグインの README アンカーを復元し、ダークモードのログ検索とデフォルト プロファイルのローカリゼーションを修正しました。 (#10346、#10356、#10341、#10351、#10296)
  • WebUI: ナビゲーションとプロバイダーのアイコンを更新し、構成テスト チャット ボタンのテーマの色を修正し、プラグインの送信リンクとラベルを更新しました。ロゴ トークンを再利用し、期限切れのプラットフォーム キャッシュを更新しました。 (#10304、#10332、#10309、#10471、#10294)
  • プロバイダー: 参照と制約を含む完全な Anthropic ツール パラメーター スキーマが保存され、非オブジェクト ルート スキーマが拒否されました。 Coze チャットの失敗と不完全なストリームを報告し、Dify ワークフロー エラー、失敗した完了ステータス、成功した完了イベントなしで終了したストリームを処理しました。 (#10520、#10523、#10545)
  • プラットフォーム: テキスト フォールバック付きの Slack TTS オーディオを配信し、モデル リクエストに引用された Discord 返信テキストを含め、QQ 公式アウトバウンド返信リファレンスを入力し、引用メッセージを含む Lark/Feishu リッチ テキスト タイトルと空白を保持しました。 (#10496、#10452、#10489、#10543)
  • ChatUI: LLM リクエスト エラーをローカライズし、送信されたオーディオ、ビデオ、およびファイル メッセージの再生とダウンロードを復元しました。 (#10478、#10483)
  • WebUI: ワークスペースを離れるときに記憶された [データとログ] タブを保持し、モバイル サイドバーの下部をブラウザー コントロールから遠ざけるようにしました。 (#10498、#10512)
  • WebUI: ローカライズされたタイトルとプラグイン メタデータを備えた優れたプラグイン ビュー、プラグイン グループを一意に保ち、モバイル上のボタンからプラグイン情報にアクセスできるようにしました。 (#10502、#10519)
  • WebUI: 不足している翻訳キーを埋め、未使用のロシア語翻訳エントリを削除しました。 (#10505)

ナビゲーションと構成の変更

  • サイドバー: コア エントリはシステムの下にグループ化されています。ペルソナ、ナレッジベース、スケジュールされたタスク、サブエージェント オーケストレーション、およびプラグイン ビューが「拡張機能」の下に表示されます。バージョンはサイドバーのフッターに表示されます。 (#10304、#10307)
  • 設定: 管理者とホワイトリストの設定 → アクセス制御; プラットフォーム → プラットフォームとメッセージ。 (#10321)
  • 構成: システム設定 → テキストから画像へのレンダリング → 構成プロファイル → 拡張機能 → テキストから画像へのレンダリング。各プロファイルには独自のテキストから画像への設定が含まれるようになりました。 (#10306)
  • 外観: サイドバーのカスタマイズ機能を削除しました。 (#10480)
  • ドキュメント:「使用法」セクションのガイドを改善しました。 (#10487)
  • ログ: 一番上の行のフィルター → フィルター サイドバー。コア ソース ラベル → システム;自動スクロールスイッチ→自動下フォロー。検索、全画面表示、フォント サイズ コントロール、および Pip インストールはツールバーに残ります。 (#10514)

構築とメンテナンス

  • ダッシュボードの pnpm オーバーライドと依存関係ビルドの権限をワークスペース構成に移行し、pnpm 11 との互換性のためにドキュメント ワークスペース構成を追加しました。 (#10541)
  • CI にダッシュボード変換キー チェックを追加し、CodeQL GitHub アクションを更新しました。 (#10505、#10552)

主要新增

  • 電気の使用: 環境の新しいオペレーティング システムに適したサンドボックス セパレートを実行し、現在 macOS シートベルトと Linux バブルラップをサポートしています。 参考: https://docs.astrbot.app/use/astrbot-agent-sandbox.html (#9472)
  • ChatUI: 新しい天気履歴とサイド ミーティングの議事録、入力草の長期化、選択されたモデルのミーティングの承認、および切り替え時の自動フォーカス入力フレーム。 (#9667、#10279、#10247、 #10301)
  • ChatUI: モデル選択ツールが新しくなり、ソース選択とコンテンツが新しくなり、スキルが MCP トップから新しく検索されます。 (#10084、#10217)
  • 「文本転送図」に関連する配置**が「配置」から「配置ファイル」→「展開機能」**に移動し、配置ファイルが分離されました。
  • 「管理」、「白名」に関連する配置が「配置ファイル」 -> 「平台」から「配置ファイル」 -> 「許可制御」に移動しました。 (#10321)
  • 日志：サポート按级别、来源、插件、平台および关键词結合筛选、可隐藏用户对话日志；新增 8–16px 字号控制、默认 12px、按 2px (#10514) ファイル名が表示され、ID がサブマークとして使用されます。
  • セクション: WebUI のサイド エッジと macOS のヘアガラス効果。
  • コア: 新しいエージェントの残りの数を増やし、古いバージョンの数の制限を移し、承認数の上限を増やし、シェル会議などの待機時間を延長します。 (#10131、#10133)
  • コア: モデル プロバイダーが新しい x-astrbot-conversation-id セッション ID 要求を要求します。 (#10218、#10237)
  • WebUI: モデルに関連するモデル選択ツール、モデル メニュー内の新しい設定エントリを戻し、変更後すぐにそのモデルのすべての構成ファイルを参照します。 (#10321)
  • WebUI：新しい制御台日志検索が強化され、スキルがリソースマーク、ChatUI が画像事前送信を待機し、「データと日志」の最初に起動されたトークが認識されます。 #10251)
  • WebUI：マシンマンのサイドポンプ内のハードウェア構成ファイルをサポートします。 (#10310)
  • Docker：画像内に astrbot CLI が含まれており、コンテナ内に暗号を再配置できます。
  • WebUI: 面端の新しいオペレーション エリア リスト選択およびダウンロード速度の更新。 (#10222、#10227、#10050)

主优化

  • WebUI のサイドバーとトップバーが拡張され、情報の密度が増すために長さが短くなります。
  • 「データと日報」の対向データの拡張。 (#10021、#10020、#10023、#10108)
  • 継続的に転送可能なブロック上での転送をサポートし、内部占有を制御し、WebUI の静的ソースを圧縮し、文字と図表のソースを削減します。 (#10123、#10187、#10034)
  • ストリーム形式の反転と待機パネルの動作を促進し、ロード時に移動位置を保持し、画枠を結合して自動操作します。
  • モデルは、画像処理を入力し、画像の比率を保持し、コード化を制限し、モデルにアニメーション画像が多フレーム画像に変換されたことを示します。 (#9703、#10071、#10120、#10119)
