#アストラボットv4.28.1

4.28.1 - 2026-09-14

私たちは集団的に信じている物語の中で生きています。

私たちは共通の相信の故事の場所に住んでいます。

追加と最適化

  • ページ分割された ChatUI 履歴の読み込みを追加し、チャット設定、メッセージ コンポーザー、ストリーミング インタラクションを改善しました。推論がデフォルトで表示されるようになり、ワークスペースのコード プレビューでは Shiki の強調表示が使用されます。 (#9667、#10021、#10020、#10023)
  • モデル選択にプロバイダー ソース フィルターとスティッキー グループ ヘッダーを追加し、プロバイダー設定ダイアログを改善しました。 (#10084、#10007)
  • 組み込みエージェントに適応型入力画像処理を追加しました。必要に応じて画像のサイズ変更または変換を行い、アニメーション画像をフレーム モンタージュに変換します。 CUA サンドボックスで静的画像のサイズを保持し、画像がプロバイダーのアップロード制限を超える可能性がある場合に警告します。 (#9703、#10071)
  • コマンド管理で構成可能な権限を使用して、新しい会話を開始できるように /new と /reset を統合しました。 (#10004)
  • デスクトップ更新のダウンロード進行状況を追加し、バンドルされている WebUI フォントと図アセットを削減しました。 (#10050、#10034)
  • 設定スライダーの堅牢性が向上しました。 (#10037)
  • 標準化されたプロバイダー要求の User-Agent ヘッダーに AstrBot バージョンを含めます。 (#10082)

修正

  • ‼️ イベントのクリーンアップ後に元の画像添付ファイルのパスが保存されるため、エージェントは引き続き添付ファイルにアクセスできます。 (#10042)
  • URL とファイルのインストールによるプラグインの更新を修正しました。 (#10053)
  • WebChat サイド スレッドでのモデル選択を修正し、プロアクティブ エージェントのセッション モデル フォールバックを復元しました。 (#10065、#10028)
  • ストリーミング中のスキルのようなフォールバック応答の配信を修正しました。 (#10025)
  • スケジュールされたエージェントがセッション コンテキストの圧縮設定を尊重し、ランナーがエラー状態で終了したときに失敗を記録するようにしました。 (#9992、#9987)
  • api_base が空の場合の OpenAI エンドポイント解決を修正しました。 (#10079)
  • Web 検索ツールのフィールドの欠落、飲み込んだエラー コード、パラメーターの検証を修正しました。 (#9979)
  • ナレッジ ベース内の同時 URL クリーニング レート リミッター ウェイターの間隔をあけました。 (#10015)
  • 成功した送信を重複させることなく、拒否されたオープン ID から既知のチャット ID にフォールバックすることにより、Lark プライベート メッセージ配信が改善されました。 (#10018)
  • QQ 公式 C2C ストリーミング応答の終了フレームが欠落している問題を修正しました。 (#10069)
  • Telegram ポーリングと競合エラー ログ スパムを削減しました。 (#10027、#10046)
  • メッセージ アウトラインでのメンションオール処理を修正しました。 (#9993)
  • アクティブな会話をストレージから解決する必要がある場合の現在の会話の削除を修正し、WebChat セッション タイトルを会話履歴のフォールバックとして使用しました。 (#10003、#9983)
  • WebUI のフリーズを防ぐためのバッチ化されたコンソール ログ レンダリング。 (#9988、#9990)
  • デスクトップ管理モードで古い WebUI アセットを拒否し、PyPI ソース パッケージから一時的なダッシュボード ビルド アーティファクトを除外しました。 (#9898、#10036)

アップグレードに関する注意事項

  • /reset が /new に続くようになりました。組み込みエージェントは、古い履歴と現在のペルソナを保持しながら、新しい会話を開始します。サードパーティのエージェント バックエンドは、保存されているセッション ID をリセットし、古いレコードを保存しない場合があります。 (#10004)

中国語

新增与优化

  • ChatUI の履歴メッセージの追加、拡張された天気設定、メッセージ入力フレームとストリーム形式の対話が追加されました。
  • モデルプロバイダーの新しいプロバイダーのために、ソース選択とパケットマークを吸収し、モデルプロバイダーの構成をモデル化します。 (#10084、#10007)
  • 内部エージェントが新たに適切な入力を行うために、ピクチャの処理を行う必要があります。CUA サボックスで静的なピクチャのサイズを維持し、ピクチャがモデル プロバイダーの送信制限時間を超過する可能性があるため、警告が表示されます。 (#9703、#10071)
  • /new および /reset の新しいペアが実行され、命令管理における構成制限がサポートされます。
  • 新しいインターフェイスは、ダウンロード表示、正確な WebUI に含まれる文字および図のソースを更新します。 (#10050、#10034)
  • 配置スライダーの健壮性を変更しました。 (#10037)
  • モデルプロバイダーから要求されたユーザーエージェントを統合して、AstrBot バージョンを含めます。 (#10082)

修正

  • ‼ ️ イベントがクリーンアップされた後も、エージェントが引き続き添付ファイルにアクセスできるように、添付ファイルの元のイメージ パスを保持します。 (#10042)
  • URL またはファイルのインストールを介してプラグインを更新するときの問題を修正しました。 (#10053)
  • WebChat 側スレッドのモデル選択を修正し、セッション モデルのアクティブ エージェントのフォールバック ロジックを復元します。 (#10065、#10028)
  • スキルのようなフォールバック返信がストリーミング モードで配信されない問題を修正しました。 (#10025)
  • cron ジョブ エージェントがセッション コンテキストの圧縮設定を尊重し、エグゼキュータがエラー状態で終了したときにタスクの失敗をログに記録します。 (#9992、#9987)
  • api_base が空の場合の OpenAI インターフェイスのアドレス解決を修正しました。 (#10079)
  • Web 検索ツールにおけるフィールド損失、エラー コードの飲み込み、パラメータ検証の問題を修正しました。 (#9979)
  • ナレッジベースの URL クリーニング電流リミッターで同時待機リクエストが時間差で実行されない問題を修正しました。 (#10015)
  • Feishu プライベート チャット メッセージ配信の信頼性の向上: 成功したメッセージの繰り返し送信を避けるために、オープン ID が拒否された場合に既知のチャット ID にフォールバックします。 (#10018)
  • QQ公式ボットC2Cストリーミング返信で終了フレームが欠落する問題を修正しました。 (#10069)
  • Telegram ポーリングおよび競合エラーの重複ログを削減します。 (#10027、#10046)
  • メッセージ概要内のすべてのメンバーのメンションの処理順序を修正しました。 (#9993)
  • 現在の会話を永続ストレージから解析する必要がある場合の削除動作を修正し、WebChat セッション タイトルを会話履歴のフォールバックとして使用します。 (#10003、#9983)
  • WebUI の遅延を避けるために、コンソール ログをバッチでレンダリングします。 (#9988、#9990)
  • デスクトップ ホスティング モードで期限切れの WebUI リソースを読み込み、PyPI ソース パッケージから一時的なフロントエンド ビルド アーティファクトを除外する問題を修正しました。 (#9898、#10036)

アップグレードのヒント

  • /reset は /new と一貫して動作するようになりました。組み込みエージェントは新しい会話を作成し、古い履歴を保持し、現在の人格を継承します。サードパーティのエージェント バックエンドは保存されたセッション ID をリセットするため、古いレコードを保持する保証はありません。グループ チャットのデフォルトの権限は会話分離設定に従い、既存のコマンド権限設定は引き続き有効になります。 (#10004)
