#アストラボットv4.15.0

何が変わったのか

⚠️ v4.14.8 ユーザーへのリマインダー: v4.14.8 バージョンのバグにより、Electron AstrBot デスクトップ アプリケーションを使用していない場合、WebUI ダイアログ ボックスから誤って Github リリース ページにジャンプします。 次のようなダイアログ ボックスが表示されます。 <img width="400" height="710" alt="image" src="https://github.com/user-attachments/assets/e9a0e3e1-d41d-42c5-b36c-6b9efe298dac" /> この場合、以下のインストールパッケージをダウンロードしてインストールしないでください。アップグレードするには 2 つの方法があります。

  1. アップグレードするには、AstrBot を手動で再デプロイする必要がある場合があります。 (更新ページを開いて新しいバージョンに切り替えることができる場合は、このリマインダーは無視してかまいません)
  2. [このファイル] (https://github.com/AstrBotDevs/AstrBot/releases/download/v4.15.0/AstrBot-v4.15.0-dashboard.zip) をダウンロードして解凍し、AstrBot のデータ ディレクトリに置き、dist ディレクトリを置き換えてから WebUI インターフェイスを更新し、もう一度更新ボタンをクリックして元の更新ダイアログ ボックスを復元します。

新しい

  • エンタープライズ WeChat スマート ロボットはアクティブ メッセージ プッシュをサポートし、ビデオ、ファイル、その他のメッセージ タイプのサポートを追加します (#4999)
  • エンタープライズ WeChat アプリケーションは、アクティブ メッセージ プッシュをサポートし、エンタープライズ WeChat アプリケーション、WeChat パブリック アカウント、および WeChat カスタマー サービスの音声処理プロセスを最適化します (#4998)
  • DingTalk アダプターはアクティブ メッセージ プッシュをサポートし、画像、ビデオ、オーディオ、その他のメッセージ タイプのサポートを追加します (#4986)
  • 性格管理ポップアップウィンドウに削除ボタンを追加しました (#4978)

修正

  • SubAgents ツールの重複排除に関連する問題を修正しました (#4990)
  • WeCom AI Bot のストリーミング メッセージ処理ロジックを改善し、セグメンテーションとストリーミング応答の安定性を向上させました (#5000)
  • ソース コードおよび Electron パッケージング環境での pip インストール動作を安定させ、非 Electron シーンで WebUI 更新ボタンをクリックしたときに誤ってジャンプ ダイアログ ボックスがトリガーされる問題を修正しました (#4996)
  • デスクトップ バックエンドを構築する際の証明書データ収集の問題を修正しました (#4995)
  • フリーズしたランタイムでの pip install 実行の問題を修正 (#4985)
  • Windows ARM64 向けに vcpkg 経由で OpenSSL をプロビジョニングし、関連するビルド準備の問題を修正

最適化

  • pydantic 依存バージョンの更新 (#4980)
  • GHCR名前空間のCI構成を調整

変更点 (英語)

新機能

  • ペルソナ ツール管理の強化と、サブエージェント オーケストレーションのための UI ローカリゼーションの改善 (#4990)
  • WeCom AI Bot にプロアクティブなメッセージ プッシュを追加し、ビデオ、ファイル、その他のメッセージ タイプをサポートしました (#4999)
  • WeCom アプリにプロアクティブなメッセージ プッシュを追加し、WeCom アプリ、WeChat 公式アカウント、および WeCom カスタマー サービスの音声処理を改善しました (#4998)
  • プロアクティブなプッシュと画像、ビデオ、オーディオ メッセージ タイプのサポートを備えた強化された Dingtalk アダプター (#4986)
  • 使いやすさを向上させるために、ペルソナ管理ダイアログに削除ボタンを追加しました (#4978)

修正

  • WeCom AI Bot のストリーミング メッセージ処理が改善され、セグメント化されたストリーミング応答の安定性が向上しました (#5000)
  • ソースおよび Electron パッケージ環境での pip インストール動作を安定させ、非 Electron モードで cliWebUI 更新を実行するときの予期しないリダイレクト ダイアログを修正しました (#4996)
  • デスクトップ バックエンド ビルドでの証明書データ収集を修正しました (#4995)
  • フリーズしたランタイムでの pip install の実行を修正しました (#4985)
  • Windows ARM64 ビルド フロー用に vcpkg 経由で OpenSSL を準備

改善点

  • pydantic 依存関係のバージョンを更新 (#4980)
  • GHCR 名前空間の CI 構成を更新

詳細

  • 功績: リリース ワークフローをリファクタリングし、https://github.com/AstrBotDevs/AstrBot/pull/4969 の @Soulter による Electron アプリの特別な更新処理を追加しました
  • 雑用: https://github.com/AstrBotDevs/AstrBot/pull/4903 の @Dt8333 による ruff による自動アン修正
  • 雑務: https://github.com/AstrBotDevs/AstrBot/pull/4980 の @Soulter による pydantic 依存関係のバージョンの更新
  • 功績: https://github.com/AstrBotDevs/AstrBot/pull/4978 の @Copilot により、ペルソナ管理ダイアログに削除ボタンを追加しました。
  • 功績: https://github.com/AstrBotDevs/AstrBot/pull/4986 の @Soulter による、アクティブなプッシュ メッセージと画像、ビデオ、オーディオ メッセージ タイプを使用して Dingtalk アダプターを強化しました。
  • 修正: https://github.com/AstrBotDevs/AstrBot/pull/4985 の @zouyonghe によるフリーズされたランタイムでの pip install 実行の処理
  • https://github.com/AstrBotDevs/AstrBot/pull/4995 の @Raven95676 による電子パッケージング モードでの証明書の問題を修正
  • 功績: エンタープライズ WeChat アプリケーションはアクティブ メッセージ プッシュをサポートし、エンタープライズ WeChat アプリケーション、WeChat パブリック アカウント、および WeChat カスタマー サービス音声の処理を最適化します (https://github.com/AstrBotDevs/AstrBot/pull/4998 の @Soulter)
  • 功績: エンタープライズ WeChat インテリジェント ロボットは、アクティブ メッセージ プッシュをサポートし、https://github.com/AstrBotDevs/AstrBot/pull/4999 の @Soulter によるビデオ、ファイル、その他のメッセージ タイプの送信をサポートします。
  • 功績: WecomAIBotAdapter と WecomAIBotMessageEvent を強化し、https://github.com/AstrBotDevs/AstrBot/pull/5000 の @Soulter によるストリーミング メッセージ処理を改善しました。
  • 功績: ペルソナ ツール管理を強化し、https://github.com/AstrBotDevs/AstrBot/pull/4990 の @Soulter によるサブエージェント オーケストレーションの UI ローカリゼーションを更新
  • perf: ソースコードおよび Electron パッケージ環境での pip インストール動作を安定させ、非 Electron 環境で WebUI 更新ボタンをクリックしたときにジャンプ ダイアログ ボックスが表示される問題を修正 by @zouyonghe (https://github.com/AstrBotDevs/AstrBot/pull/4996)
  • 修正: 'HandoffTool' オブジェクトには属性 'agent' がありません (https://github.com/AstrBotDevs/AstrBot/pull/5005 の @Li-shi-ling による)
  • chore(deps): https://github.com/AstrBotDevs/AstrBot/pull/5006 の @dependabot[bot] による 2 つの更新で github-actions グループをバンプします
  • 修正: https://github.com/AstrBotDevs/AstrBot/pull/5007 の @zouyonghe によるパッケージ化されたランタイムの pip/ssl 動作と Mac フォント フォールバックを安定化
  • 修正: Windows パッケージ バージョンのバックエンドの再起動に失敗する問題を修正 (https://github.com/AstrBotDevs/AstrBot/pull/5009 の @zouyonghe 氏)
  • 修正: アプリの再起動例外を修正し、アプリで再起動をクリックしてもすぐに再起動を促すことができない問題を修正し、バックエンドの準備ができたらインターフェースを更新します (https://github.com/AstrBotDevs/AstrBot/pull/5013 の @zouyonghe 氏)
  • 雑務: https://github.com/AstrBotDevs/AstrBot/pull/5003 の @Soulter による 4.15.0 へのバージョンのバンプ フル Changelog: https://github.com/AstrBotDevs/AstrBot/compare/v4.14.7...v4.15.0
