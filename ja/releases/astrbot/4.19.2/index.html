AstrBot v4.19.2

パッチ 公開日2026年3月5日 出典AstrBotDevs/AstrBot 英語原文

#アストラボットv4.19.2

何が変わったのか

新しい

  • 統合された KOOK プラットフォーム アダプター (#5658)。
  • Discord の反応前の絵文字サポート (#5609) を追加しました。
  • sendMessageDraft ストリーミング リアルタイム出力 API (#5726) の Telegram サポートを追加しました
  • エージェントの実行中のメッセージ フォローアップ機能をサポートし、フォローアップ メッセージがリアルタイムでエージェントに挿入されます (#5484)。
  • DeerFlow Agent Runner を統合し、ストリーミングを最適化します (#5581)。
  • Windows でのツール呼び出しの成功率を向上させるためのオペレーティング システム情報を含む新しいシェル ipython ツールを追加しました (#5677)。
  • Shipyard-neo のサンドボックス サポート - スキルの自己反復のサポート (#5028)。
  • ChatUI WebSocket 送信モード選択を追加、OpenAPI Chat ZZPH100​​ZZ は WebSocket 接続をサポートしました (#5410)。
  • ペルソナのカスタム エラー応答メッセージと回避ロジック (#5547) をサポートします。
  • WebUI 静的ファイルをホイールにパッケージ化し、astrbot CLI ログを英語 (#5665) に置き換えます。
  • 強化されたチャット インターフェイスとモバイル応答エクスペリエンス (#5635)。
  • プラグイン障害処理ロジックと拡張リスト対話エクスペリエンスを最適化します (#5535)。

修正

  • MCP 初期化タイムアウト パラメータのキーワードの不一致を修正しました (#5743)。
  • 「完了を解析できません」エラーを引き起こす MCP ツールの競合状態を修正しました (#5534)。
  • LINEアダプターにおける非HTTPS URLの直接透過送信の問題を修正しました(#5697)。
  • WebUIサイドバーのカスタムステータスが不安定になる問題(#5670)を修正しました。
  • KOOKアダプターがメッセージおよびハートビート応答を受信したときに冗長なデバッグログを出力する問題を修正しました。
  • DEMO_MODE 環境変数がブール値として正しく解析されない問題を修正しました (#5676)。 ・サブエージェントがローカル画像(参照画像)のパスを正しく受信できない問題(#5579)を修正しました。
  • 別のプロバイダー モデルに切り替えるときに誤解を招く動作を引き起こす /model コマンドを修正しました (#5578)。
  • UTC タイム ゾーン オフセットが処理されず、タイムスタンプ例外が発生する会話レコードの問題を修正しました (#5580)。
  • バックアップのインポート時にプラットフォーム統計の重複により例外が発生する問題を修正しました (#5594)。
  • max_agent_step 設定が子エージェントに適用されない問題を修正しました (#5608)。
  • プラグイン リストの並べ替えと検索フィルタリング ロジックを修正しました (#5559)。 ・uv sync使用時にNode.js環境が不要になる問題を修正しました。

変更点 (英語)

新機能

  • 統合された KOOK プラットフォーム アダプター (#5658)。
  • 最適化されたストリーミング サポートを備えた統合 DeerFlow Agent Runner (#5581)。
  • feat(テレグラム): sendMessageDraft API (#5726) をサポート
  • Shipyard Neo サンドボックス (#5028) を介した完全なライフサイクル管理 (候補、リリース、削除) を備えた統合された Neo スキル自己反復機能。
  • Discord の事前確認絵文字サポートを追加しました (#5609)。
  • チャット インターフェイスに WebSocket トランスポート モードの選択を追加しました (#5410)。
  • 単体テスト カバレッジを含むツールの説明に OS 情報を追加しました (#5677)。
  • ToolLoopAgentRunner にフォローアップ メッセージの処理を追加しました (#5484)。
  • フォールバック ロジックを使用したペルソナ カスタム エラー応答メッセージのサポートを追加しました (#5547)。
  • WebUI 静的ファイルを Wheel パッケージにバンドルし、astrbot CLI ログを英語 (#5665) に置き換えました。
  • 非同期 IO パフォーマンスが最適化され、ベンチマーク カバレッジが追加されました (#5737)。
  • API キーの作成をリファクタリングし、オープン API ルートの単体テストを追加しました。
  • エージェント ランナーでの AI 実行エラーに対するエラー メッセージが改善されました。
  • チャット インターフェイスとモバイルの応答性が強化されました (#5635)。
  • プラグインの失敗処理と拡張機能リストの UX を改善しました (#5535)。

バグ修正

  • MCP 初期化タイムアウトのキーワードの不一致を修正しました (#5743)。
  • completion 无法解析 エラーを引き起こす MCP ツールの競合状態を修正しました (#5534)。
  • 非 HTTPS URL が直接通過できるようにする LINE アダプターを修正しました (#5697)。
  • WebUI の不安定なサイドバーのカスタマイズ状態を修正しました (#5670)。
  • 受信メッセージとハートビート応答に対する KOOK アダプターの過剰なデバッグ ログを修正しました。
  • DEMO_MODE 環境変数がブール値として正しく解析されない問題を修正しました (#5676)。
  • サブエージェントがローカル イメージ (参照イメージ) パスを正しく受信できない問題を修正しました (#5579)。
  • 別のプロバイダーのモデルに切り替えるときの /model コマンドの誤解を招く動作を修正しました (#5578)。
  • 会話レコード内の不正なタイムスタンプを引き起こす未処理の UTC タイムゾーン オフセットを修正しました (#5580)。
  • プラットフォーム統計エントリの重複によるバックアップ インポートの失敗を修正しました (#5594)。
  • max_agent_step 設定がサブエージェントに適用されない問題を修正しました (#5608)。
  • プラグイン リストの並べ替えと検索フィルタリング ロジックを修正しました (#5559)。
  • uv sync 中に欠落していた Node.js 環境要件を修正しました。
