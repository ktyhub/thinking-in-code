AstrBot v4.25.0

#アストラボットv4.25.0

  • アップデートログ(簡体字中国語)
  • Changelog(英語) <a id="中国語"></a>

何が変わったのか

修正

  • \x02 プレフィックスが付いた Tencent SILK オーディオが認識されず、後続の ffmpeg 変換が失敗する問題を修正しました。 (#8009)
  • 個人のWeChatメディアメッセージの送信に失敗した場合に、エラーが上向きに公開されない問題を修正しました。 (#8175)
  • None パラメータをパラメータなしのツールに返すときのクロード API のツール呼び出しの失敗を修正しました。 (#8136) ・register_platform_adapter_type、register_permission_typeが正しく**kwargsを透過送信しない問題を修正しました。 (#8141)
  • MiniMax TTS 木材重量設定が空または不正な JSON の場合に初期化クラッシュを引き起こす可能性がある問題を修正しました。

新機能

  • Ollama Embedding および NVIDIA NIM Embedding プロバイダー アダプターを追加しました。 (#8104)
  • フェイシュQRコードをスキャンしてワンクリックで作成できる機能を追加しました。 (#8191)
  • DingTalk で QR コードをスキャンしてワンクリックで作成機能を追加しました。 (#8198)
  • 個人の WeChat 作成時に新しい QR コード ログイン プロセスを追加しました。個人の WeChat を選択すると、作成ポップアップ ウィンドウに QR コードが直接表示されます。ログインに成功すると、ロボットの構成が保存されます。 (#8196)

最適化

  • 個人の WeChat ログイン ステータスの処理を最適化します。高頻度で無効なセッションが継続することを避けるために、インターフェイスがセッション タイムアウトを返したときに古いログイン ステータスを消去します。 (#8196)
  • AMR オーディオ変換品質を最適化し、一般的なオーディオ変換ロジックを再利用して、Opus 変換の実装を簡素化します。 (#8153)
  • WebUI リソース選択ロジックの最適化: data/dist のダッシュボード バージョンが現在のコア バージョンより古い場合、古いフロントエンド リソースによって引き起こされる互換性の問題を回避するために、パッケージに組み込まれているダッシュボードの使用が優先されます。 (#8172)
  • ダッシュボードに Noto Sans フォントのサポートが追加され、キリル文字などの多言語テキストの表示効果が向上します。 (#8015)
  • コンソールの自動スクロール ステータスの同期を最適化し、更新後に正しく復元してログ表示コンポーネントと同期できるようにしました。 (#8186)
  • Feishu、DingTalk、および個人 WeChat プラットフォームのドキュメントを更新し、QR コードの作成/ログイン手順を補足し、Feishu 権限アクティベーション リマインダーと個人 WeChat の新しいバージョンの作成プロセスを追加しました。
  • AI プラグイン開発ドキュメントを更新して、context.register_llm_tool() が非推奨であることを明確にし、LLM ツールの docstring パラメータ解析要件を追加しました。 (#8178) <a id="english"></a>

変更点 (英語)

新機能

  • フェイシュ/ラーク用のone-click QRセットアップを追加しました。ボットを作成するとき、ユーザーは Feishu China または Lark Global を選択し、QR コードをスキャンして、app_id、app_secret、およびドメイン設定を自動的に入力できます。 AstrBot は、生成された構成 ID 表示用のボット名も取得します。 (#8191)
  • DingTalk 用の 1 つの click QR セットアップを追加しました。ユーザーは QR コードをスキャンして、ClientID と ClientSecret を自動的に入力することで、DingTalk アプリを作成またはバインドできますが、手動セットアップは引き続き利用できます。 (#8198)
  • 個人 WeChat ボットの作成中に QR ログインを追加しました。作成ダイアログにログイン QR コードが直接表示され、ログイン成功後に保存できるようになりました。 (#8196)
  • Ollama Embedding および NVIDIA NIM Embedding プロバイダー アダプターを追加しました。 (#8104)

改善点

  • API がセッション タイムアウトを報告したときに古いログイン状態をクリアし、無効なセッションに対するリクエストの繰り返しを回避することで、個人 WeChat のログイン状態の処理を改善しました。 (#8196)
  • 共有オーディオ変換パスを再利用することで、AMR オーディオ変換品質が向上し、Opus 変換が簡素化されました。 (#8153)
  • WebUI アセット選択の改善: data/dist に現在のコア バージョンより古いダッシュボードが含まれている場合、AstrBot は古いフロントエンド互換性の問題を回避するためにバンドルされたダッシュボードを優先するようになりました。 (#8172)
  • キリル文字および多言語テキストのレンダリングを改善するために、Noto Sans サポートをダッシュボードに追加しました。 (#8015)
  • コンソールの自動スクロール状態の同期が改善され、復元された設定が更新後にログ表示コンポーネントに適用されるようになりました。 (#8186)
  • QR セットアップ/ログイン手順、Feishu 許可リマインダー、および新しい個人 WeChat 作成フローを含む、Feishu / Lark、DingTalk、および個人 WeChat プラットフォームのドキュメントを更新しました。
  • AI プラグイン開発ガイドを更新して、context.register_llm_tool() が非推奨であることを明確にし、必要な LLM ツールの docstring 引数形式を文書化しました。 (#8178)

バグ修正

  • 先頭の \x02 バイトを持つ Tencent SILK オーディオが検出されず、ffmpeg 変換エラーが発生する可能性がある問題を修正しました。 (#8009)
  • 個人 WeChat メディア送信エラーが適切に表示されない問題を修正しました。 (#8175)
  • クロード API がパラメーターのないツールに対して None 引数を返すとツール呼び出しが失敗する問題を修正しました。 (#8136)
  • register_platform_adapter_type と register_permission_type が **kwargs を正しく転送しない問題を修正しました。 (#8141)
  • 木材重量設定が空または無効な JSON の場合に MiniMax TTS 初期化がクラッシュする問題を修正しました。
