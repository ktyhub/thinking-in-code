#アストラボットv4.25.2

  • アップデートログ(簡体字中国語)
  • Changelog(英語) <a id="中国語"></a>

何が変わったのか

新規追加と最適化

  • スムーズな Markdown ストリーミング レンダリングを有効にします。 (#8371)
  • グループ チャットのコンテキスト認識のキャッシュ ヒット率を最適化します。 (#8226)
  • 構造化ドキュメントのインポート後のチャンク品質を向上させるために、Markdown 対応チャンカーをナレッジ ベースに追加します。 (#8151)
  • ChatUI にコマンド候補機能を追加し、カスタム ウェイク ワードとフローティング プロンプトをサポートしました。 (#8279、#8353)
  • 構成されたモデルに機能アイコンを追加して、モデルでサポートされている機能を簡単に識別できるようにします。 (#8405)
  • Xiaomi および Xiaomi Token Plan LLM プロバイダーを追加しました。 (#7744)
  • QQ 公式アダプターのメッセージ チェーン メディア分割および送信ロジックを最適化し、QQ Webhook 拡張フィールドを透過的に送信します。 (#8376、#6274)
  • 最初の通知に EULA プロンプトを追加しました。 (#7955)
  • WebUI プラグイン カードにより、直接アクセス ボタンが追加され、埋め込みページの高さが向上します。 (#8369)
  • ダッシュボードの開発および構築プロセスでは、MDI アイコン フォントのサブセットが自動的に生成されます。 (#8264)
  • AstBot ダッシュボードのパスワードを変更するための新しいコマンドを追加しました。 (#8272)
  • デフォルトの LLM 圧縮プロンプトワードを最適化して、コンテキストの継続をより自然にします。 (#8424)

修正

  • ChatUIの音声入力録音とアップロードに失敗する問題を修正しました。 (#8440)
  • ChatUIの思考プロセスのタイトル概要表示を修正し、右側のアイコンを縦方向の中央に配置します。
  • 特定の状況下で 1 つのプラグインの読み込み失敗が他のプラグインの再読み込みに影響する問題を修正し、失敗したプラグイン ステータスのクリーニングを強化しました。 (#8441)
  • 空の LLM 概要処理の問題を修正しました。 (#8195)
  • RST および AsciiDoc ナレッジ ベースのアップロード サポートを修正しました。 (#8255)
  • T2I Shiki 関連の問題を修正しました。 (#8013)
  • ストリーミング応答 delta=None がチャンクに分割され、SDK to_dict() エラーが発生する問題を修正しました。 (#8244)
  • skill_like ツールが再クエリされたときに、元の completion_text が保持されない問題を修正しました。 (#8240)
  • OpenAI ストリーミング応答の終了時に使用状況情報が失われる問題を修正しました。 (#8306)
  • macOS での SQLAlchemy の互換性の問題を修正しました。 (#7724)
  • WebUI モバイル プロバイダー ソースの削除機能を修正しました。 (#8321)
  • Mimo音声デザインモデルリクエストに無効な音声パラメータが含まれる問題を修正しました。 (#8326)
  • Mimo 推論コンテンツに関連する問題を修正しました。 (#8327)
  • Anthropic API tool_choice スキーマ変換の問題を修正しました。 (#8328)
  • プラグインのメタデータ リポジトリ フィールド タイプの保護を修正しました。 (#8207)
  • コア イメージ リクエストがビジュアル フォールバックにルーティングされる問題を修正しました。 (#8089)
  • ファイルコンポーネントのファイル名のサニタイズを修正しました。 (#8318) ・ダッシュボードのサブコマンド番号ラベルとプラグインが繰り返し表示される問題を修正しました。 (#8388、#8389)
  • 専用の画像記述プロバイダーがない場合に、マルチモーダル メイン プロバイダーが参照画像を繰り返し処理する問題を修正しました。 (#8401)
  • 分割された返信で余分な空白行が発生する問題を修正しました。 (#8304)
  • プラグインマーケットのプラグイン名がローカルのプラグイン名と一致しない問題を修正しました。 (#8276) ・ダッシュボードリストの設定項目にスペースが入力できない問題を修正しました。 (#8403)
  • 古いコマンドヒントに関連する問題を修正しました。 (#8245)
  • SendMessageToUserToolの説明を改善しました。 (コミット)

ドキュメントとエンジニアリング

  • リリース バージョンのリリース ノートを更新しました。 (コミット)
  • ダッシュボードのダウンロード リンク、FAQ の強制更新手順、削除数量手順を更新しました。 (#8359、#8235、コミット)
  • ドキュメント内の QQ 公式 WebSocket ロボットの中国語の説明のタイプミスを修正しました。 (#8351)
  • GitHub アクションの依存関係を更新しました。 (#8233、#8335)
  • 不要なログを削除します。 (コミット) <a id="english"></a>

変更点 (英語)

機能と改善点

  • 構造化されたドキュメントの取り込みを改善するために、Markdown 対応のナレッジ ベース チャンカーを追加しました。 (#8151)

  • Xiaomi および Xiaomi Token Plan LLM プロバイダーを追加しました。 (#7744)
  • QQ 公式メディア チェーンの分割とメッセージ送信が改善され、QQ Webhook の追加フィールドが渡されました。 (#8376、#6274)

  • WebUI プラグイン カードに直接アクセス ボタンを追加し、埋め込みページの高さを改善しました。 (#8369)

  • 空の LLM 概要を修正しました。 (#8195)

  • skill_like ツールの再クエリでオリジナルの completion_text を保持。 (#8240)
  • OpenAI ストリーミング応答に欠落していた最終使用状況メタデータを修正しました。 (#8306)
  • macOS での SQLAlchemy の互換性の問題を修正しました。 (#7724)
  • WebUI でのモバイル プロバイダー ソースの削除を復元しました。 (#8321)
  • Mimo 音声デザイン モデル リクエストの無効な音声パラメーターを修正しました。 (#8326)
  • Mimo 推論コンテンツの処理を修正しました。 (#8327)
  • Anthropic API tool_choice スキーマ変換を修正しました。 (#8328)
  • プラグインのメタデータ リポジトリ値のタイプ ガードを追加しました。 (#8207)
  • コアイメージリクエストのビジョンフォールバックへのルーティングを修正しました。 (#8089)
  • ファイルコンポーネント内のファイル名をサニタイズしました。 (#8318)
  • ダッシュボードのサブコマンド数ラベルと重複したプラグイン表示を修正しました。 (#8388、#8389)
  • 専用の画像キャプションプロバイダーが設定されていない場合、マルチモーダルメインプロバイダーによる引用画像の重複処理を防止しました。 (#8401)
  • 分割された返信内の余分な空白行を削除しました。 (#8304)
  • マーケットプレイスとローカル プラグイン間のプラグイン名の不一致を修正しました。 (#8276)
  • ダッシュボード リストの設定項目でスペースを入力できない問題を修正しました。 (#8403)
  • 古いコマンドヒントを修正しました。 (#8245)
  • SendMessageToUserToolの説明を改善しました。 (コミット)

文書化とメンテナンス
