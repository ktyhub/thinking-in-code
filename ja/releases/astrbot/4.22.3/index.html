AstrBot v4.22.3

#アストラボットv4.22.3

  • アップデートログ(簡体字中国語)
  • Changelog(英語) <a id="中国語"></a>

何が変わったのか

新しい

  • さまざまな API パスに柔軟に適応できる、構成可能な rerank_api_suffix をサポートする vllm_rerank プロバイダーを追加しました。 (#7278)
  • llama.cpp のトークン使用量抽出サポートを適応させて、トークン統計と請求分析機能を強化します。 (#7358)
  • WebUI には、CDN からのダウンロードの失敗を防ぐために Monaco Editor のワーカー ファイルがバンドルされています。 (#7249)
  • 新しいモデル/プラットフォームの概要統計パネル。 (#7152)

最適化

  • OpenAI メッセージ処理を最適化します。content リストが空の場合は、それを None に設定し、空のコンテンツでの例外率を減らします。 (#6551)
  • プロバイダーのページ レイアウトとスタイルを最適化して、全体的な設定ページ レイアウトの一貫性を向上させます。 (#7248)
  • ユーザーがログインすると、ようこそページに直接ジャンプし、再度ログイン ページに入る手順を減らします。 (コミット)

修正

  • Windows の MCP ランナーが完全なシステム環境変数を継承せず、起動例外が発生する問題を修正しました。 (#7054)
  • Gemini リフレクション スニペットがユーザーに表示されるメッセージ リンクに漏洩する問題を修正しました。 (#7196)
  • Gemini (API と互換性のある OpenAI) での function_response 形式要件によって引き起こされる 400 Invalid argument エラーを修正しました。 (#7216
  • ナレッジ ベースの初期化が失敗した場合のエラー プロンプトと回復の問題を修正しました。 (#7243)
  • 解析エラーを回避するために、Bailian Rerank の新旧の応答形式との互換性を修正しました。 (#7217)
  • Docker イメージは AMR エンコーダの依存関係を補完し、一部の導入シナリオでオーディオのトランスコーディングが欠落する問題を修正します。 (#7247)
  • pip インストールで pysocks 依存関係が欠落しているために発生する SOCKS5 プロキシが利用できない問題を修正しました。 (#7221)
  • トークン統計の混乱を避けるために、_extract_usage の cached_tokens の処理ロジックを修復します。 (#6719)
  • SSE 切断保護を強化し、圧縮伝送下でハートビートを積極的に送信し、WebChat の偶発的な切断を減らします。 (#7003)
  • 厳密な API での空のアシスタント メッセージによって引き起こされる 400 エラーを修正しました。 (#7202)
  • 欠落している QR コード機能に対する qrcode 依存関係の修復を追加し、QR コード生成機能を復元しました。 (コミット)
  • 異常な入力シナリオでの処理逸脱を回避するために、コンフィギュレーターのデジタル入力コンポーネントのインタラクティブ エクスペリエンスの問題を修正しました。 (#7153)
  • Pydantic v2 で Record.path が必須フィールドとして誤って扱われる問題を修正しました。 (#7048) <a id="english"></a>

変更点 (英語)

新機能

  • カスタム API パスをサポートするために、vllm_rerank プロバイダーに構成可能な rerank_api_suffix を追加しました。（#7278）
  • トークン アカウンティングを改善するために、llama.cpp にトークン使用量抽出サポートを追加しました。（#7358）
  • コード編集が外部 CDN ダウンロードに依存しないように、WebUI に Monaco Editor ワーカーをバンドルしました。（#7249）
  • モデルとプラットフォームの使用状況に関する新しい統計概要を追加しました。（#7152）
  • ログインしているユーザーをログイン ページではなくウェルカム ページにリダイレクトしました。（commit）

改善点

  • コンテンツ リストが空の場合にメッセージ content を None に設定することで OpenAI メッセージ処理を改善し、空のペイロードのエッジ ケースを削減しました。（#6551）
  • 設定ページの一貫性を保つためにプロバイダー ページのレイアウトとスタイルを改善しました。（#7248）
  • ユーザーがすでにログインしている場合の接続成功の処理とメッセージングを洗練しました。（commit）

バグ修正

  • Windows MCP ランナーのすべてのシステム環境変数を継承して、環境依存の起動問題を修正しました。（#7054）
  • ユーザー向けメッセージ チェーンから Gemini の思考部分をフィルタリングしました。（#7196）
  • 400 Invalid argument 応答を防ぐために Gemini function_response の互換性を修正しました。（#7216）
  • ナレッジベースの初期化エラー処理を改善しました。（#7243）
  • 古い応答形式と新しい応答形式の両方に対する Bailian のリランク解析を修正しました。（#7217）
  • 欠落しているオーディオ コーデック サポートを修正するために、Docker ビルドに AMR エンコーダー サポートを追加しました。（#7247）
  • pip インストールで SOCKS5 プロキシを正しく使用できるように、pysocks 依存関係を追加しました。（#7221）
  • _extract_usage キャッシュされたトークンの処理を修正しました。（#6719）
  • 圧縮下でのWebChat切断を防ぐためにSSEハートビートパケットを送信しました。（#7003）
  • 厳密な API での空のアシスタント メッセージによって引き起こされる 400 エラーを修正しました。（#7202）
  • QR コード生成を復元するために欠落していた qrcode 依存関係を追加しました。（commit）
  • コンフィグレンダラーの入力UXの数を修正しました。（#7153）
  • Pydantic v2 で Record.path が必須として誤って扱われる問題を修正しました。（#7048）

何が変わったのか

  • ドキュメント: https://github.com/AstrBotDevs/AstrBot/pull/7115 の @piexian によるプラグイン開発ドキュメントに select_knowledgebase の使用法を追加
  • 功績: https://github.com/AstrBotDevs/AstrBot/pull/7152 の @Soulter による強化された統計概要用の新しい StatsPage を追加
  • 修正（コア）： https://github.com/AstrBotDevs/AstrBot/pull/7048 の @No-22-Github により、Pydantic v2 で Record.path が必須として誤って処理されました
  • 修正: https://github.com/AstrBotDevs/AstrBot/pull/7153 の @Reisenbug による構成レンダラーの数値入力 UX を改善
  • 修正: https://github.com/AstrBotDevs/AstrBot/pull/7003 の @he-yufeng による圧縮中の WebChat 切断を防ぐために SSE ハートビートを送信
  • perf: https://github.com/AstrBotDevs/AstrBot/pull/7178 の @Soulter による UI の改善
  • chore(deps): https://github.com/AstrBotDevs/AstrBot/pull/7209 の @dependabot[bot] により、github-actions グループの codecov/codecov-action を 5 から 6 に変更します。
  • https://github.com/AstrBotDevs/AstrBot/pull/6719 の @LIghtJUNction による _extract_usage メソッドの cached_tokens 処理を修正
  • リファクタリング: https://github.com/AstrBotDevs/AstrBot/pull/7248 の @Soulter によるレイアウトとスタイルを改善するためにプロバイダー パネルを更新
  • 功績: https://github.com/AstrBotDevs/AstrBot/pull/7249 の @Soulter による強化されたコード編集サポートのために Monaco Editor ワーカーを統合
  • 修正: https://github.com/AstrBotDevs/AstrBot/pull/7221 の @Neko-Yukari による pip インストール用の SOCKS5 プロキシをサポートするために pysocks 依存関係を追加
  • 修正(Docker): @WenqiOfficial による AMR エンコーダを https://github.com/AstrBotDevs/AstrBot/pull/7247 に追加
  • 修正: https://github.com/AstrBotDevs/AstrBot/pull/7217 の @he-yufeng による新旧両方の Bailian Rerank API 応答形式をサポート
  • https://github.com/AstrBotDevs/AstrBot/pull/7279 の @Thelia-Lzr による QQ WebSocket 接続のドキュメント エラーを修正
  • 修正: https://github.com/AstrBotDevs/AstrBot/pull/7202 の @kaixinyujue による厳密な API での 400 エラーを防ぐために空のアシスタント メッセージをフィルタリングしました。
  • ドキュメント/更新 mimo プロバイダーの Readme (@RichardLiuda 著、https://github.com/AstrBotDevs/AstrBot/pull/7207)
  • 機能 (webui): https://github.com/AstrBotDevs/AstrBot/pull/7215 の @M1LKT によるダッシュボードとコンソールの QOL の改善
  • 修正: https://github.com/AstrBotDevs/AstrBot/pull/7243 の @piexian によるナレッジ ベースの初期化エラー処理を改善
  • ドキュメント: https://github.com/AstrBotDevs/AstrBot/pull/7298 の @piexian による uv デプロイメント ドキュメントに WebUI アップグレードをサポートしないための手順を追加
  • 修正: https://github.com/AstrBotDevs/AstrBot/pull/7331 の @Soulter による client_self_id の誤用を修正することで、Discord/Misskey ホット リロードの問題を解決します。

  • 修正: https://github.com/AstrBotDevs/AstrBot/pull/7196 の @he-yufeng による、ユーザー向けメッセージ チェーンから Gemini の思考部分をフィルターする
  • perf: OpenAI メッセージ コンテンツ リストが空の場合、https://github.com/AstrBotDevs/AstrBot/pull/6551 の @he-yufeng によって content を None に設定します。
  • 修正 (Windows): https://github.com/AstrBotDevs/AstrBot/pull/7054 の @SoloLevelingAI により、すべてのシステム環境変数を Windows 用の MCP ランナーに継承します
