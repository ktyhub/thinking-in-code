AstrBot v4.18.3

#アストラボットv4.18.3

何が変わったのか

新しい

  • クライアントでの更新プロセスへのアクセスを容易にするデスクトップ ユニバーサル アップデート ブリッジ機能を追加しました (#5424)。

修正

・新規プラットフォームダイアログに回線アダプタが表示されない問題を修正しました。

  • Telegram がビデオを送信できない問題 (#5430) を修正しました。
  • 埋め込みプロバイダーの作成時にベクトル次元が自動的に認識されない問題を修正しました (#5442)。
  • QQ 公式プラットフォームでメディア メッセージを送信するときにマークダウン フィールドがクリーンアップされない問題を修正しました (#5445)。
  • コンテキスト管理ポリシー -> コンテキストの切り捨て時にツールの呼び出し/応答のペアが失われる問題を修正しました (#5417)。
  • セッション更新中にpersona_idが上書きされる問題を修正し、ペルソナ解析ロジックを強化しました。
  • WebUIでGitHubのプロキシアドレスが異常に表示される問題を修正しました(#5438)。
  • 設定ページで新しい開発者 API キーを作成した後にコピーが失敗する問題を修正しました (#5439)。
  • OpenAI STT (OGG を使用) との Telegram 音声メッセージ形式の互換性の問題を修正しました (#5389)。

最適化

  • ナレッジ ベースの取得プロセスを最適化し、バッチ クエリ メタデータに変更し、N+1 クエリのパフォーマンスの問題 (#5463) を修正します。
  • 将来のタスク実行のために Cron のセッション分離機能を最適化し、同時実行の安定性を向上させます。
  • WebUI プラグイン ページのインタラクションを最適化します。

変更点 (英語)

新機能

  • 統合プラグイン拡張ページ状態管理用に useExtensionPage コンポーザブルを追加しました。
  • アプリ内更新ワークフローをサポートするための汎用デスクトップ アプリ アップデーター ブリッジを追加しました (#5424)。

バグ修正

  • 「プラットフォームの追加」ダイアログに回線アダプターが表示されない問題を修正しました。
  • Telegram ビデオ送信の問題を修正しました (#5430)。
  • Pyright の静的型チェック エラー (#5437) を修正しました。
  • 埋め込みプロバイダー作成時の埋め込みディメンションの自動検出を修正しました (#5442)。
  • QQ 公式プラットフォーム経由でメディア メッセージを送信するときの古いマークダウン フィールドを修正しました (#5445)。
  • コンテキスト切り捨て中のツールの呼び出し/応答ペアリングの損失を修正しました (#5417)。
  • 会話の更新中に persona_id が上書きされる問題を修正し、ペルソナ解決ロジックを改善しました。
  • WebUI での誤った GitHub プロキシ表示を修正しました (#5438)。
  • 設定で新しいキーを作成した後の API キーのコピーの失敗を修正しました (#5439)。
  • OGG (#5389) を使用して、OpenAI STT と Telegram 音声フォーマットの互換性を修正しました。

改善点

  • メタデータ クエリをバッチ処理して N+1 クエリ パターン (#5463) を排除することにより、ナレッジ ベースの検索が改善されました。
  • 将来の cron タスクのセッション分離が改善され、同時実行時の安定性が向上しました。
  • WebUI プラグイン ページのインタラクションが改善されました。

何が変わったのか

  • 修正: https://github.com/AstrBotDevs/AstrBot/pull/5389 の @realquantumcookie による OpenAI STT API の問題を引き起こすテレグラム音声メッセージ形式 (WAV ではなく OGG)
  • 機能 (ダッシュボード): @zouyonghe による汎用デスクトップ アプリ アップデータ ブリッジを https://github.com/AstrBotDevs/AstrBot/pull/5424 に追加
  • 修正(ダッシュボード): https://github.com/AstrBotDevs/AstrBot/pull/5439 の @exynos967 による設定ページで新しい API キーを作成した後にコピーが失敗する問題を修正
  • 修正: https://github.com/AstrBotDevs/AstrBot/pull/5438 の @letr007 により、GitHub プロキシが WebUI で正しく表示されない
  • 修正: https://github.com/AstrBotDevs/AstrBot/pull/5417 の @Luna-channel によるコンテキスト切り捨てでツールの呼び出し/応答のペアリングを確認
  • 修正（ペルソナ）: 会話の persona_id を保持し、https://github.com/AstrBotDevs/AstrBot/pull/5440 の @Raven95676 によるセッション/会話の解決を統合します。
  • 修正: https://github.com/AstrBotDevs/AstrBot/pull/5445 の @KBVsent による QQ 公式プラットフォーム経由でメディア メッセージを送信するときにマークダウン フィールドをクリアする
  • 修正: https://github.com/AstrBotDevs/AstrBot/pull/5442 で @exynos967 によって埋め込みプロバイダーを作成するときに、自動的に埋め込み dim を取得できない
  • 修正: https://github.com/AstrBotDevs/AstrBot/pull/5437 の @Dt8333 による著作権チェック
  • 修正(電報): https://github.com/AstrBotDevs/AstrBot/pull/5430 の @CCCCCCTV によるビデオ メッセージ (#2536) を送信できない
  • perf: https://github.com/AstrBotDevs/AstrBot/pull/5463 の @CAICAIIs による N+1 問題を修正するための KB 取得でのバッチ メタデータ クエリ
  • 修正: 残留プラグインの不完全なクリーンアップが発生する問題を修正… by @Waterwzy (https://github.com/AstrBotDevs/AstrBot/pull/5462)
  • 雑用: https://github.com/AstrBotDevs/AstrBot/pull/5474 の @Dt8333 による著作権の UnsupportedDunder レポートを修正
  • [バグ] 介入チュートリアル行を表示すると、https://github.com/AstrBotDevs/AstrBot/pull/5479 の @Sjshi763 による間違ったインターフェイスに移動します

新しい貢献者

  • @realquantumcookie が https://github.com/AstrBotDevs/AstrBot/pull/5389 で最初の投稿を行いました
  • @CCCCCCTV が https://github.com/AstrBotDevs/AstrBot/pull/5430 に初めて投稿しました フル Changelog: https://github.com/AstrBotDevs/AstrBot/compare/v4.18.2...v4.18.3
