AstrBot v4.20.0

マイナー 公開日2026年3月12日 出典AstrBotDevs/AstrBot 英語原文

#アストラボットv4.20.0

何が変わったのか

新しい

  • ロシア語の翻訳を追加しました (#6081)。
  • QQ 公式ボットは、ファイル、音声、およびビデオ メッセージ (WebSocket モードを含む) のサポートを追加しました (#6063)。

最適化

  • QQ 公式ボットのストリーミング メッセージ配信の信頼性とアクティブ メディア送信機能を最適化します (#6131)。
  • エッジ シナリオでのブート選択ロジックとメッセージ送信ツールを最適化します (#6064)。

修正

  • ダッシュボードの README ダイアログのアンカー ナビゲーションの失敗 (#6083) を修正しました。
  • 曖昧さを避けるために、曜日を指定した cron の例を優先します (#6091)。
  • インストール後のプラグインマーケットステータスの更新が間に合わない問題を修正しました (#6124)。
  • プラグインの依存関係のインストール ロジックを修正しました。不足している依存関係のみをインストールします (#6088)。
  • Telegram アダプターの非推奨の normalize_whitespace パラメーター (#6044) を削除しました。
  • Windows ローカル スキル ファイル読み取りの問題 (#6028) を修正しました。
  • Discord の事前確認絵文字設定が再起動後に保持されない問題を修正しました (#6031)。
  • WebUI の検索ボックスのクリア動作を統合しました (#6017)。
  • プラグインの依存関係の自動インストール プロセスとダッシュボードのインストール エクスペリエンスを最適化します (#5954)。

変更点 (英語)

新機能

  • ロシア語翻訳のサポートを追加しました (#6081)。
  • QQ 公式ボット (WebSocket モードを含む) にファイル、音声、およびビデオ メッセージのサポートを追加しました (#6063)。

改善点

  • QQ 公式 API (#6131) のストリーミング メッセージ配信の信頼性とプロアクティブなメディア送信が向上しました。
  • エッジケースおよびメッセージ送信ツールでのブーター選択ロジックを最適化しました (#6064)。

バグ修正

  • ダッシュボードの破損した README ダイアログのアンカー ナビゲーションを修正しました (#6083)。
  • 曖昧さを減らすために、名前付き平日 cron の例を優先しました (#6091)。
  • インストール後のプラグイン マーケットのインストール状態の更新を修正しました (#6124)。
  • 不足しているパッケージのみをインストールするようにプラグインの依存関係のインストール ロジックを修正しました (#6088)。
  • Telegram アダプターの非推奨の normalize_whitespace パラメーター (#6044) を削除しました。
  • Windows でのローカル スキル ファイルの読み取りの問題を修正しました (#6028)。
  • Discord の事前確認絵文字設定が再起動後も保持されない問題を修正しました (#6031)。
  • WebUI 検索入力のクリア動作を統合しました (#6017)。
  • プラグインの依存関係の自動インストール フローとダッシュボードのインストール エクスペリエンスが改善されました (#5954)。

何が変わったのか

  • 修正: https://github.com/AstrBotDevs/AstrBot/pull/5954 の @zouyonghe によるプラグイン依存関係の自動インストール ロジックとダッシュボードのインストール エクスペリエンスの最適化
  • 修正(webui): https://github.com/AstrBotDevs/AstrBot/pull/6017 の @Flartiny による検索入力クリア動作を統一
  • 修正: https://github.com/AstrBotDevs/AstrBot/pull/6031 の @Jzjerry によって欠落しているデフォルト キーを追加することで、再起動後も Discord の事前確認絵文字設定を維持します
  • 修正: https://github.com/AstrBotDevs/AstrBot/pull/6028 の @zouyonghe による Windows ローカル スキル ファイルの読み取りを改善しました。
  • 特技: QQ 公式ボット (WebSocket モードを含む) のファイル、音声、およびビデオ メッセージのサポートを追加しました。 @Soulter 著、https://github.com/AstrBotDevs/AstrBot/pull/6063
  • perf: https://github.com/AstrBotDevs/AstrBot/pull/6064 の @Soulter によるエッジ ケースおよびメッセージ送信ツールのブーター選択を最適化します。 *修正（ドキュメント）：https://github.com/AstrBotDevs/AstrBot/pull/6048の@shudorclによるdocker.mdとnapcat.mdのタイプミス
  • fix(telegram): https://github.com/AstrBotDevs/AstrBot/pull/6044 の @DOHEX による telegramify_markdown.markdownify 呼び出しから非推奨のnormalize_whitespace パラメータを削除
  • 修正: https://github.com/AstrBotDevs/AstrBot/pull/6088 の @zouyonghe による不足しているプラグイン依存関係のみをインストールする
  • 雑用: https://github.com/AstrBotDevs/AstrBot/pull/6119 の @zouyonghe による依存関係とワークフローのバージョンの更新
  • 修正(拡張機能): https://github.com/AstrBotDevs/AstrBot/pull/6124 の @letr007 によるインストール後にプラグイン マーケットのインストール状態を更新
  • ドキュメント: @advent259141 による Astrbook および Joupa Mew コミュニティ リンクを https://github.com/AstrBotDevs/AstrBot/pull/6135 に追加
  • [セキュリティ] 致命的な脆弱性を修正: V-004 by @orbisai0security (https://github.com/AstrBotDevs/AstrBot/pull/6093)
  • 修正: https://github.com/AstrBotDevs/AstrBot/pull/6091 の @stablegenius49 による名前付き平日 cron 例を優先します。
  • 修正 (ダッシュボード): https://github.com/AstrBotDevs/AstrBot/pull/6083 の @stablegenius49 による README ダイアログのアンカー ナビゲーションを復元
  • 功績: @seoeaa によるロシア語翻訳を https://github.com/AstrBotDevs/AstrBot/pull/6081 に追加
  • perf(QQ 公式 API): https://github.com/AstrBotDevs/AstrBot/pull/6131 の @2ndelement によるストリーミング メッセージ配信の信頼性とプロアクティブなメディア送信を向上させます。
