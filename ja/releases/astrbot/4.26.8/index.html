#AstrBot v4.26.8

[4.26.8] - 2026-07-28

私たちは庭を耕さなければなりません。 私たちは自分たちの庭を耕さなければなりません。

新しいプラグイン マーケット AstrBot Cloud を立ち上げました。プラグイン開発者とユーザーは、このプラットフォームを使用して、AstrBot プラグインをアップロード、管理、探索できます。 AstrBot WebUI からのプラグイン データはこのマーケットにリダイレクトされます。詳細については、[AstrBot Docs | AstBot Docs] を参照してください。プラグインの公開](https://docs.astrbot.app/en/dev/star/plugin-publish.html)

プラグイン開発者とユーザーがプラグインをアップロード、管理、閲覧できるプラットフォーム、新しいプラグイン マーケット システム [AstrBot Cloud] (https://cloud.astrbot.app) をリリースしました。 AstrBot WebUI 内のプラグイン マーケットのデータはプラットフォームから同期されます。詳細については、「AstrBot ドキュメント | 」を参照してください。プラグインリリース](https://docs.astrbot.app/dev/star/plugin-publish.html)。

追加

  • プラグインごとのログ レベル コントロールをダッシュボードとプラグイン API に追加しました。 (#9342)
  • FishAudio TTS プロバイダーのモデル構成サポートを追加しました。 (#9381)
  • プラットフォーム ログの分類と、ユーザー チャット エントリを非表示にするコンソールの切り替えを追加しました。 (#9165)
  • マルチモーダル モデルをサポートする DashScope 埋め込みプロバイダーを追加しました。 (#9137)
  • ChatUI にワークスペース ファイル ブラウザを追加しました (プロジェクトのみ)。 (#9432)

変更されました

  • Telegram メッセージ内の部分的な返信の引用を尊重します。 (#9236)
  • イベント ループをブロックすることなく、プロセスの CPU 使用率を報告します。 (#9367)
  • 辞書設定フィールドのデフォルト値マッピングを追加しました。 (#9414)

修正済み

  • 非 ASCII 文字を含む Windows パスでの FAISS アクセスを修正し、起動時のハングを防ぐために遅延インポートを復元し、新しいインデックスの無効なディメンションを拒否しました。 (#8323、#9350、#9385)
  • 関連するロックを保持しながらタイムスタンプを更新し、cron スケジューラの状態をデータベース同期から切り離して、永続的なジョブが常に読み込まれるようにしました。 (#9349、#9419)
  • LLM リクエストが失敗した後もチェックポイントを保持し、埋め込みバッチ結果の順序を維持し、メッセージを再生成するときに現在のプロバイダーを使用しました。 (#9358、#9359、#9241、#9402)
  • コンテンツの安全性を確保するために引用テキストをチェックし、ゼロ値の前方パーサー制限を尊重し、メッセージ アウトラインから末尾の区切り文字を削除しました。 (#9232、#9394、#9390)
  • Tavily の日付フィルターの競合、入れ子になった OpenAI 補完の選択肢、および Bailian 再ランク プロトコルの非互換性を解決しました。 (#9234、#9386、#9413)
  • DingTalk コマンドのエラーとリッチテキストのメンションを処理し、正しい WebChat イメージの MIME タイプを返し、Discord のスラッシュ コマンドの検証を修正しました。 (#9389、#9319、#9411)
  • プラグイン設定の保存の進行状況を表示し、ペルソナ ダイアログが誤って閉じることを防ぎ、重複したスクロールバーを削除し、ローカル プラグインのアップロードがハングするのを防ぎました。 (#9327、#9238、#9382、#9406)
  • 会話リストのパフォーマンスが向上し、古くなった非同期更新が防止されました。 (#9226)
  • デフォルトの MiMo TTS モデルを mimo-v2.5-tts に更新しました。 (#9428)
  • プロキシが設定されていない場合はシステム プロキシ変数が無視され、ローカル API リクエストが傍受されるのを防ぎます。 (#8897)
  • 独立した FTS5 インデックス間での順序の歪みを回避するために、ランク融合中に知識ベースごとのスパース検索ランクを保持します。 (#9426)
  • プロセスのクラッシュを防ぐために、ガードされた C 拡張機能がリロードされます。 (#9148)

ドキュメント

  • README バナーを更新し、公式 QQ ボットの統合を推奨しました。
  • Windows Docker デスクトップ導入ガイドを追加しました。 (#9339)
  • 英語と中国語のプラグイン公開ガイドを拡張しました。 (#9415)

メンテナンス

  • グループ化された GitHub アクションの依存関係と docker/login-action を更新しました。 (#9333、#9416)
  • ラフを0.15.22に固定しました。 (#9369)
  • アップデータ パス テストで迷走ディレクトリが作成されるのを防止しました。 (#9376)

中国語

新しい

  • コンソールおよびプラグイン API のプラグインごとにログ レベルを調整する機能を追加しました。 (#9342)
  • FishAudio TTS プロバイダーのモデル構成サポートを追加しました。 (#9381)
  • プラットフォーム ログ カテゴリと、コンソールでユーザー チャット レコードを非表示にするスイッチを追加しました。 (#9165)
  • マルチモーダル モデルをサポートする DashScope 埋め込みプロバイダーを追加しました。 (#9137)
  • ChatUI にワークスペース ファイル ブラウザを追加しました (プロジェクトのみ)。 (#9432)

変更

  • 電報メッセージは、部分的な応答参照の保持をサポートします。 (#9236)
  • プロセスの CPU 使用率統計がイベント ループをブロックしなくなりました。 (#9367)
  • ディクショナリ タイプ設定フィールドのデフォルト値マッピングを補足します。 (#9414)

修正

  • Windows の非 ASCII パスでの FAISS 読み取りおよび書き込みを修正し、起動時のフリーズを回避するために遅延インポートを復元し、新しいインデックスの無効なディメンションの構成を拒否します。 (#8323、#9350、#9385)
  • ロック期間中にタイムスタンプを更新し、Cron スケジューラの状態をデータベース同期状態から切り離して、永続タスクが常に読み込まれるようにします。 (#9349、#9419)
  • LLM リクエストの失敗後にチェックポイントを保持し、埋め込まれたバッチ結果の順序を維持し、メッセージを再生成するときに現在のプロバイダーを使用します。 (#9358、#9359、#9241、#9402)
  • 引用されたテキストのコンテンツ セキュリティ チェックを実行し、値 0 による前方解析制限を正しく処理し、メッセージ概要の末尾の区切り文字を削除します。 (#9232、#9394、#9390)
  • Tavily の日付フィルター パラメーターの競合、入れ子になった OpenAI 補完の選択肢、および Bailian 並べ替えプロトコルの互換性の問題を修正しました。 (#9234、#9386、#9413)
  • リッチ テキストのメンション処理、WebChat 画像の MIME タイプ、および Discord のスラッシュ コマンド名の検証に関する DingTalk コマンド エラーを修正しました。 (#9389、#9319、#9411)
  • プラグイン設定の保存の進行状況を表示して、パーソナリティ編集ポップアップ ウィンドウを誤って閉じないようにし、重複したスクロール バーを削除し、ローカル プラグインのアップロードが停止するのを防ぎます。 (#9327、#9238、#9382、#9406)
  • セッション リストのパフォーマンスを向上させ、非同期リクエストによって引き起こされる古い更新を回避します。 (#9226)
  • MiMo TTS のデフォルト モデルを mimo-v2.5-tts に更新しました。 (#9428)
  • ローカル API 要求が傍受されないようにプロキシが設定されていない場合は、システム プロキシ変数を無視します。 (#8897)
  • 独立した FTS5 インデックス間の結果の順序の歪みを避けるために、ランキングの統合中に各ナレッジ ベースのスパース検索ランキングを保持します。 (#9426)
  • プロセスのクラッシュを回避するために、C 拡張機能のオーバーロードに対する保護を追加しました。 (#9148)

ドキュメント

  • README バナーを更新し、QQ 公式ロボット アクセスの使用を推奨しました。
  • Windows Docker デスクトップ導入ガイドを追加しました。 (#9339)
  • 中国語と英語のプラグイン リリース ガイドを拡張しました。 (#9415)

メンテナンス

  • GitHub アクション依存関係グループと docker/login-action を更新しました。 (#9333、#9416)
  • ラフを0.15.22に修正しました。 (#9369)
  • 残りのディレクトリを作成するアップデータ パス テストを回避します。 (#9376) [4.26.8]: https://github.com/AstrBotDevs/AstrBot/compare/v4.26.7...v4.26.8
