#アストラボットv4.26.0

注:

  1. WebUI「Config -> System Config」は、WebUI サイドバーの下部にある「Settings」に移動しました。
  2. このバージョンに更新する前に、v4.25.6 に更新することをお勧めします。

リマインダー:

  1. WebUI の「構成 -> システム構成」は、WebUI サイドバーの「設定」に移動されました。
  2. まず v4.25.6 にアップグレードしてから、このバージョンにアップグレードすることをお勧めします。
  • アップデートログ(簡体字中国語)
  • Changelog(英語) <a id="中国語"></a>

何が変わったのか

✨ 新機能

  • バックエンド アーキテクチャが Quart から FastAPI に移行されました。複数のAstrBot OpenAPIを追加しました。 (#8688)
  • すべてのプラットフォームにわたるメッセージ メディア ファイルの処理ロジックを統一し、画像、音声、ファイル、および参照されるメッセージ メディアの解析の一貫性を向上させ、Tencent ベースの Silk 形式の音声ファイルに Pilk ライブラリを使用しなくなります。 (#8764)
  • 安定性を高めるために、モデル呼び出しエラーが発生した場合の再試行回数の構成をサポートします。
  • WebUI は、関数ツールのツールごとの権限管理を追加し、ツール パネルでのツール権限の表示と切り替えをサポートします。 (#8693)
  • WebUI には、ライト、ダーク、システムに従うという 3 つの新しいテーマ モードが追加され、システム テーマの同期を一元的に処理します。 (#8648)
  • WebUI システム構成ページを再構築し、システム構成エントリをサイドバーの下の設定領域に移動し、関連する設定、自動保存、および再起動プロンプトのエクスペリエンスを最適化しました。 (#8777)
  • QQ 公式ロボット WebSocket アダプターのスキャン コード バインディング プロセスを追加しました。これにより、WebUI を介したワンクリック スキャンを通じて AppID とシークレットを取得してバックフィルし、WebSocket テンプレートを推奨としてマークできます。 (#8821)
  • QQ 公式ロボットのグループ チャット機能を強化し、グループ メッセージ作成タイプをサポートし、キャッシュ msg_id がない場合でも Webhook アダプターがグループ メッセージをアクティブに送信できるようにします。 (#8838、#8841)
  • OpenAI、Gemini、Anthropic、その他のモデル リクエストに構成可能な再試行メカニズムを追加し、一時的なネットワーク エラーや 5xx サーバー エラーの安定性を向上させるために最大再試行回数の新しい構成を追加しました。 (#8893)
  • プロジェクトを更新するときに、AstrBot Core をダウンロードすると、ネットワークの安定性を向上させるために、AstrBot 公式ホスティング アドレスが使用されるようになりました。 (#8888)
  • リクエストでのワークスペース スキルの読み込みをサポートし、ワークスペース スキル検出プロセスを強化します。 (#8884)
  • Exa Web 検索プロバイダーを追加しました。 (#8973)
  • イレブンラボ TTS API プロバイダーを追加しました。 (コミット)
  • ログインできない場合のアクセスの復元を容易にするために、起動時に WebUI パスワードをリセットするコマンド ライン スイッチを追加しました。 (commit)
  • プレリリースバージョンの可視性スイッチを追加しました。 (コミット)
  • ログインページに公開バージョンの詳細表示を追加しました。 (#8986)
  • バックアップ機能にスキル ディレクトリが含まれるようになりました。 (#8700)

最適化

  • スケジュールされたタスクへの不正アクセスを回避するために、将来のタスク所有者の検証を強化します。 (#8881)
  • ナレッジ ベースにアップロードされたファイル名のパスが交差するリスクを最適化します。 (#8971)
  • プラグインをアップロードする際のファイル名パス トラバーサルのリスクを最適化します。 (#8968)
  • 制限されたローカル ファイル システム ツールでハードリンク ファイルを拒否し、ワークスペース ハードリンク エイリアスを介して許可されたディレクトリ外でファイルの読み書きを回避します。
  • サンドボックスファイル転送とCUAヘルスチェックプロセスを強化し、異常な環境でのファイル操作のリスクを軽減します。 (#8840)
  • メッセージ コンポーネントのログ出力では、ログ内に大きなインライン メディア コンテンツが含まれないように、長すぎる Base64 フィールドが切り捨てられるようになりました。 (#8591)
  • グループ チャット コンテキストに、引用されたメッセージの内容が表示されるようになりました。 (コミット)
  • 会話コンテキストに今週の情報を追加しました。 (#8669)
  • アトミック書き込みを使用して構成ファイルを保存し、書き込みの中断によって引き起こされる構成の破損の可能性を減らします。 (#8793)
  • GitHub エージェント gh.dpik.top を追加し、無効なエージェント gh.llkk.cc を削除しました。 (#8772、#8761)

修正

  • aiocqhttp プラットフォーム アダプターとメッセージ イベント ハンドラーで、複数の API 呼び出しで self_id ルーティング パラメーターが欠落していた問題を修正しました。 (#8779)
  • プラットフォーム ID を生成するときに空白文字が含まれる可能性がある問題を修正しました。 (#8768)
  • Gemini プロバイダー ツール定義がモデルを正しく返さず、ツール呼び出しが繰り返される問題を修正しました。 (#8833) -プロバイダソースのIDを変更した後に保存がサイレントに復元される問題を修正しました。 (#8915)
  • 他のプラグインのツール設定の誤操作を避けるために、プラグイン LLM ツール スイッチの所有権検証の問題を修正しました。 (コミット)
  • プラグインの命名モードの検証と境界シーンの処理を改善しました。 (コミット)
  • プラグインの再インストール後にウェアハウスのソースが失われる問題を修正しました。 (コミット)
  • サブディレクトリ ツールにおける handler_module_path の不一致の問題を修正しました。 (#8578)
  • 登録プロセス中に保護されたツールが誤って失われるのを防ぐために、実行ベースのツールの保護ロジックを修正しました。 (#8790)
  • ペルソナツールリストシナリオでシステムツールが削除される問題を修正しました。 (#8908)
  • 性格設定で、指定されたリストからツールとスキルを「デフォルトですべて使用」に切り替えても有効にならない問題を修正しました。 (#8835)
  • 新しいバージョンの MCP での Streamable HTTP client の名前変更によって引き起こされる互換性の問題を修正し、mcp 依存関係を 2 未満に保ちます。
  • ローカル Python ツールが現在のセッション ワークスペースで実行されない問題を修正しました。 (#8792)
  • 静的リソースが欠落している場合でも WebUI Ready バナーが表示される問題を修正しました。 (#8804)
  • ダッシュボードでフォルダーを作成するときに Enter キーを押しても送信できない問題を修正しました。 (#8597) ・チャット入力ボックスの終了位置以外で入力方法の組み合わせを入力すると文字が消える場合がある問題を修正しました。 (#8811)
  • changelog ポップアップ ウィンドウでのアンカー リンクの処理を修正しました。 (#8750)
  • オンボーディング プラットフォームの構成とバックアップのアップロードに関連する問題を修正しました。 (#8834)
  • ナレッジ ベース コンテキストを一時的なユーザー コンテンツとして挿入し、モデル リクエストにおける不正確なナレッジ ベース コンテキスト ロールの問題を修正します。 (#8904)
  • cron 週間スケジュールの正規化の問題を修正しました。 (#8984)
  • QQ公式プラットフォームでメッセージを送信するときにAtコンポーネントが失われる問題を修正しました。 (#8983)
  • 引用メッセージ内の画像キャプションが繰り返し表示される場合がある問題を修正しました。 (#8718)
  • 埋め込み API バージョンのサフィックスが誤って切り捨てられる問題を修正しました。 (#8736)
  • 一部の環境の起動時にプロセスが停止するのを避けるために、FAISS C ライブラリのインポートを遅延しました。 (#8696)
  • シャットダウン時にデータベース エンジンを積極的に解放し、セッションやテスト環境でのリソースの残留を削減します。 (#8650)
  • CLIバージョンのソースが間違っていた問題を修正しました。 (#8692) ・astrbotコマンド実行時にデータディレクトリが不要に作成される問題を修正しました。 (#8932)
  • sdist ビルド製品パスを修正して、ダッシュボード アーティファクトを確実に含めることができるようにします。 (#8933)
  • プラグイン ページのリソース トークンのフォールバックを修正しました。 (#8970)
  • max_context_length および dequeue_context_length のデフォルト値を更新しました。
  • 安定した FastAPI ダッシュボード ルーティング登録テスト。付属のルーター ノードと互換性があります。 (コミット)
  • 安定したダッシュボード ルーティング関連のテスト。最新の FastAPI 動作と互換性があります。 (コミット) <a id="english"></a>

変更点 (英語)

✨ 新機能

  • バックエンド アーキテクチャを Quart から FastAPI に移行し、複数の OpenAPI 定義を追加しました。 (#8688)
  • プラットフォーム間でメディア ファイルの処理を統合し、画像、音声、ファイル、引用メッセージ メディアの一貫性を向上させます。 Tencent Silk 音声ファイルは、pilk ライブラリを使用しなくなりました。 (#8764)
  • WebUI の関数ツールに対するツールごとの権限管理が追加され、ツール パネルからのツール権限の表示と切り替えがサポートされました。 (#8693)
  • WebUI にライト、ダーク、およびシステム テーマ モードを追加し、システム テーマを一元的に同期しました。 (#8648)
  • WebUIシステム構成ページを再編成しました。システム構成エントリがサイドバーの下部にある設定領域に移動し、設定、自動保存、再起動通知が改善されました。 (#8777)
  • QQ Official Bot WebSocket アダプターの QR バインディング フローを追加しました。 WebUI は、one-click QR セットアップを通じて AppID とシークレットを取得および自動入力できるようになり、WebSocket テンプレートは推奨としてマークされます。 (#8821)
  • グループ メッセージ作成タイプを追加し、キャッシュされた msg_id なしで Webhook アダプターがグループ メッセージをプロアクティブに送信できるようにすることで、QQ 公式ボットのグループ チャット サポートが強化されました。 (#8838、#8841)
  • OpenAI、Gemini、Anthropic、および関連モデルのリクエストに対する構成可能な再試行処理を追加しました。これには、一時的なネットワーク エラーや 5xx サーバー エラー時の安定性を高めるための最大リクエスト再試行設定が含まれます。 (#8893)
  • AstrBot コアのダウンロードでは、プロジェクトの更新中に AstrBot の公式にホストされているソースが使用されるようになり、ネットワークの安定性が向上しました。 (#8888)
  • リクエストでのワークスペース スキルのロードと強化されたワークスペース スキル検出のサポートが追加されました。 (#8884)
  • Web 検索プロバイダーとして Exa を追加しました。 (#8973)
  • イレブンラボ TTS API プロバイダーを追加しました。 (コミット)
  • WebUI パスワードをリセットするための起動フラグを追加し、ログインできない場合にアクセスを回復しやすくしました。 (コミット)
  • プレリリースの可視性切り替えを追加しました。 (コミット)
  • ログインページに公開バージョンの詳細を追加しました。 (#8986)
  • バックアップにスキル ディレクトリが含まれるようになりました。 (#8700)

改善点

  • 将来のタスク所有者のチェックを強化し、スケジュールされたタスクへの不正なアクセスを防ぎます。 (#8881)
  • パストラバーサルのリスクに対するナレッジベースのアップロードファイル名の処理を強化しました。 (#8971)
  • プラグインのアップロード ファイル名の処理をパス トラバーサルのリスクに対して強化しました。 (#8968)

  • 強化されたサンドボックス ファイル転送と CUA ヘルス チェックにより、異常な環境でのファイル操作のリスクが軽減されます。 (#8840)
  • メッセージ コンポーネント ログは、ログ内の大きなインライン メディア ペイロードを避けるために、長い Base64 フィールドを切り詰めるようになりました。 (#8591)
  • グループ チャット コンテキストには、引用されたメッセージ コンテンツが含まれるようになりました。 (コミット)
  • 会話コンテキストに現在の平日の情報を追加しました。 (#8669)
  • 設定ファイルはアトミックに保存されるようになり、書き込みの中断中に破損する可能性が減少します。 (#8793)
  • GitHub プロキシ gh.dpik.top を追加し、無効な gh.llkk.cc プロキシを削除しました。 (#8772、#8761)
