#AstrBot v4.30.0-alpha.1

[4.30.0-alpha.1] - 2026-11-15

**このバージョンはアルファテストバージョンであり、不安定性や互換性の問題がある可能性があります。まずはテスト環境で検証することをお勧めします。この時間には、会話データベース、エージェント構成、およびセッション設定の移行が含まれます。アップグレードする前に、データと構成をバックアップしてください。古いバージョンにロールバックする場合は、同時にアップグレードする前にバックアップを復元する必要があります。このバージョンを重要な運用環境では使用しないでください。 **

メジャーアップデート

  • セッション バックエンドをイベント ソーシング モードに移行して、コンテキストの繰り返し書き込みと部分的な書き込み増幅を削減し、ストレージ パフォーマンスを最適化します。メッセージとツール呼び出しを段階的に保存し、実行中断後の履歴処理を改善します。 (#10077、#11158、#11162)
  • 新しいエージェント ランタイム モデルの導入。プラグインは、ctx.agent.run_turn() を介してエージェント ターンを呼び出すことができます。詳細については、「既存セッションのエージェントの呼び出し」(https://github.com/AstrBotDevs/AstrBot/blob/739840886c5fbbd439f477ac4b6e8eb7ba3e0649/docs/zh/dev/star/guides/ai/agent.md#%E8%B0%83%E7%94%A8%E7%8E%B0%E6%9C%89%E4%BC%9A%E8%AF%9D%E7%9A%84-agent-run-session-agent) (#10934、#10936、#11052、#11148、#11153) を参照してください。
  • サブエージェントを独立したコンテキストを持つバックグラウンド タスクに再構築し、一般エージェントと特別エージェント、追加の命令、および結果の戻りをサポートします。入り口はサイドバーから **プロファイル → AI → 機能 → サブエージェント ** に移動し、プロファイルによって管理されます。 (#11053)
  • カスタム ルールとセッション管理を [構成ファイル] → [セッション構成マッピングの管理] に統合し、基本的な構成とフィールド カバレッジ、バッチ編集とリカバリの継承をサポートします。モデルの説明書とページは同じ設定を共有します。 (#11097)
  • ワークスペースの分離、コード実行、ネットワーク制御をサポートする Windows AppContainer ネイティブ サンドボックスを追加しました。 (#10466)
  • DeepSeek 音声認識および音声合成プロバイダーを追加しました。 (#11118)
  • OpenAI Decisions 判定モデルを追加し、選択、ブール判定、スコアリングをサポートしました。 (#10968)
  • ようこそページ → 概要: 毎日の使用状況、システム リソース、ロボットの例外が表示されます。 (#11100)
  • 外観設定でサイドバーにチャット入口を配置できるようにしました。 (#11090)
  • アップグレードされた Markdown レンダリング、オンデマンドでのチャットおよび構文ハイライト リソースの読み込み。 (#11138)
  • プラグイン設定は折りたたみ可能なグループをサポートし、デフォルトの折りたたみ状態を宣言できます。 (#11067)
  • プラグイン ページでは、現在のテーマの色とその変更を取得できます。 (#11046)
  • AI 開発ドキュメントを再編成し、プラグイン構成制御の例とスクリーンショットを追加しました。 (#11154)

最適化と修復

  • 操作中の追加入力の保存と継続を改善しました。 (#11141)
  • メインセッションのブロックを避けるために、実行時に使用できないサブエージェント構成をスキップします。 (#11128)
  • 実行時に無効になっている、欠落している、または使用できないサブエージェント構成の選択を解除できるようにします。 (#11147)
  • フル ツール スキーマ モードでのデフォルトのツール呼び出しプロンプト ワードを削除しました。 (#11152) ・最後に成功したモデルのリトライが失敗と判定されてしまう問題を修正しました。 (#10922)
  • Anthropic の非ストリーミング応答で複数のテキスト ブロックが欠落している問題を修正しました。 (#11057)
  • 検索キーの有効期限が切れたり、残高が不足したりした場合は、設定されている他のキーを試してください。 (#10877)
  • Gemini TTS のデフォルト モデルを gemini-3.8-flash-tts に更新しました。 (#10828)
  • 失われた写真、ファイル、その他のメディアに QQ ボタンが応答する問題を修正しました。 (#10903)
  • QQ イメージのアップロードが失敗した場合に完全なイメージ ロードを記録しないようにし、パネルへのログの影響を軽減します。 (#10740)
  • OneBot ストリーミング セグメンテーションを最適化して、長いテキストの繰り返しスキャンを削減します。 (#10989)
  • 送信者がユーザー名を持たない場合、Telegram は表示名を使用します。 (#10715)
  • Firefox でのチャット履歴のスクロールの問題を修正しました。 (#11036) -モデル構成を編集するときにプレビューと機能の識別が一致しない問題を修正しました。 (#10792)
  • WebUI メニューとポップアップ ウィンドウのスタイルを統一し、スクロール バーとクリック フィードバックを最適化します。 (#11107、#11090、#11102)
  • EPUB 解析でリンク テキストが欠落する問題を修正しました。 (#10794)
  • GIF をパズルに変換した後も説明を保持し、歴史的文脈におけるアニメーション情報が失われないようにします。 (#10837)
  • フィルタリングとトラブルシューティングを容易にするために、プラグインのロードと実行の失敗ログを対応するプラグインに関連付けます。 (#10904)
  • スタック接続状態を回避するために、SSE ストリームが閉じられたときにプラグイン ページに通知します。 (#10932)
  • コンソール ログのタイムスタンプは日付ごとに増分されます。 (#9617)

これはアルファ版リリースであり、安定性や互換性の問題が発生する可能性があります。まずテスト環境で検証してください。このリリースでは、会話ストレージ、エージェント構成、およびセッション設定が移行されます。アップグレードする前にデータと構成をバックアップしてください。ダウングレードには、アップグレード前のバックアップの復元も必要です。

ハイライト

  • 会話をイベント ソーシングに移行し、重複したコンテキスト書き込みと一部の書き込み増幅を削減します。メッセージとツール呼び出しを段階的に保持し、実行が中断された後の履歴処理を改善します。 (#10077、#11158、#11162)
  • 新しいエージェント ランタイム モデルを導入します。プラグインは、ctx.agent.run_turn() を通じてエージェント ターンを呼び出すことができます。 (#10934、#10936、#11052、#11148、#11153)
  • サブエージェントを、独立したコンテキスト、汎用または特殊な構成、フォローアップ入力、および結果配信を備えたバックグラウンド タスクとして再構築します。プロファイルごとの設定を使用して、管理をサイドバーから Config → AI → Capabilities → Subagents に移動します。 (#11053)
  • カスタム ルールとセッション管理を [構成] → [セッション マッピングの管理] にマージし、基本プロファイル、フィールド オーバーライド、バッチ編集、復元された継承をサポートします。モデル コマンドとエディターは同じ設定を共有します。 (#11097)
  • ワークスペースの分離、コード実行、ネットワーク制御を備えた Windows AppContainer サンドボックスを追加します。 (#10466)
  • DeepSeek 音声認識および合成プロバイダーを追加します。 (#11118)
  • 選択肢、ブール質問、スコア用の OpenAI Decisions モデルを追加します。 (#10968)
  • ようこそ → 概要 に、毎日の使用状況、システム リソース、ボット エラーが表示されるようになりました。 (#11100)
  • サイドバーにチャットを表示するための外観設定を追加します。 (#11090)
  • Markdown レンダリングをアップグレードし、チャットや構文強調表示のアセットをオンデマンドでロードします。 (#11138)
  • 構成可能な初期状態を持つ折りたたみ可能なプラグイン構成グループを追加します。 (#11067)
  • 現在のテーマの色とその更新をプラグイン ページに公開します。 (#11046)
  • AI 開発ガイドを再構成し、プラグイン構成制御の例とスクリーンショットを追加しました。 (#11154)

  • 成功した最終モデルの再試行が失敗として報告される問題を修正しました。 (#10922)
  • 非ストリーミング Anthropic 応答内のすべてのテキスト ブロックを保持します。 (#11057)
  • キーが無効であるか、そのクォータが使い果たされている場合は、構成されている他の検索キーを試してください。 (#10877)
  • デフォルトの Gemini TTS モデルを gemini-3.8-flash-tts に更新します。 (#10828)
  • 画像、ファイル、その他のメディアを QQ ボタンの応答に保存します。 (#10903)
  • QQ アップロード失敗時の完全な画像ペイロードのログ記録を停止し、ダッシュボードへの影響を軽減します。 (#10740)
  • 長いテキストの繰り返しスキャンを回避することで、OneBot ストリーミング セグメンテーションを改善します。 (#10989)
  • ユーザー名が存在しない場合は、Telegram の表示名を使用します。 (#10715)

  • WebUI のメニューとダイアログを統合し、スクロールバーとプレスのフィードバックを調整します。 (#11107、#11090、#11102)

  • 会話履歴に GIF モンタージュ ガイダンスを保持するため、アニメーション コンテキストが保持されます。 (#10837)
  • ログのフィルタリングを容易にするために、プラグインの読み込みエラーと実行エラーをプラグインに関連付けます。 (#10904)
  • 古い接続状態を避けるために、SSE ストリームが閉じるときにプラグイン ページに通知します。 (#10932)
  • コンソール ログのタイムスタンプに日付を含めます。 (#9617)
