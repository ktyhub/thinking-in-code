#AstrBot v4.29.3

[4.29.3] - 2026-10-24

人生はチョコレートの箱のようなものです。

新しい

  • メッセージ追跡: メッセージ追跡機能をさらに強化し、すべての受信メッセージ イベントの記録と観察、およびイベントに対応するプラグイン呼び出しとエージェント呼び出しをサポートします。 (最初に WebUI の左下の設定でオンにする必要があります) (#10614)
  • 診断エクスポート: コンソールからの感度を下げたシステム診断パッケージと、ログ、追跡、構成、プラグインのステータス、環境、その他の情報を含むシステム設定のエクスポートをサポートします。 (#10418、#10659)
  • インストール スクリプト: 多言語インストール プロセスと中国本土のイメージ サポートを追加しました。 (#10629)

修正

  • バックアップ: データ損失を避けるために、スケジュールされたタスク、永続ファイル、および関連データ ディレクトリのバックアップとリカバリを完了します。 (#10644、#10661)
  • Gemini: モデルのカスタム生成パラメーターをサポートし、明示的に設定されたゼロ値を保持します。非文字列列挙によって引き起こされるツール スキーマの非互換性の問題を修正します。 (#10719、#10635)
  • NVIDIA 再ランク: 間違ったユニバーサル アドレスの要求を避けるために、モデル固有の API エンドポイント パスを保存します。 (#10732)
  • PC の使用: Shipyard Bay の実行結果の解析と、Windows シェルのタイムアウトまたはキャンセル時の子プロセスのクリーンアップが修正されました。 (#10671、#10729)
  • WebUI: 構成の更新後のモデルのメタデータ損失、デフォルトのチャット モデルの選択、プラグイン サイドバー名のローカリゼーション、デスクトップの更新通知、および構成テンプレート フィールドのデフォルト値を修正しました。 (#10522、#10663、#10576、#10622、#10517)
  • WebUI: 設定手順と条件オプションの表示を最適化し、全画面ログの Pip インストール ポップアップ ウィンドウ、ログ ストリーム接続待機中およびページ切り替え後のログの重複を修正し、プラグインのフィルタリング範囲を明確にします。 (#10647、#10608、#10666、#10694、#10691)
  • データベース: クロスデータベース互換性のある JSON クエリ式を使用します。 (#10664)

追加

  • メッセージ トレース: すべての受信メッセージ イベントとそれに関連するプラグインおよびエージェント呼び出しを記録および検査するためのトレースが改善されました。まず、WebUI の左下隅にある [設定] でこれを有効にします。 (#10614)
  • 診断: コンソールからの編集サポートと、ログ、トレース、構成、プラグインのステータス、環境情報などのシステム設定を含むシステム診断バンドルをエクスポートします。 (#10418、#10659)
  • インストーラー: 多言語セットアップと中国本土のミラーを追加しました。 (#10629)

修正済み

  • バックアップ: スケジュールされたタスク、永続ファイル、および関連データ ディレクトリをバックアップおよび復元操作に含めます。 (#10644、#10661)
  • Gemini: モデル固有の生成パラメーターと明示的なゼロ値を尊重し、ツール スキーマで非文字列列挙型を処理します。 (#10719、#10635)
  • NVIDIA 再ランク: 汎用エンドポイントを置き換えるのではなく、モデル固有のエンドポイント パスを保持します。 (#10732)
  • コンピューターの使用: Shipyard Bay 実行エンベロープを正しく解析し、タイムアウトまたはキャンセル時に Windows シェルの子プロセスをクリーンアップします。 (#10671、#10729)
  • WebUI: 構成の更新後にフェッチされたモデルのメタデータを保持します。デフォルトのチャットモデル選択を復元します。プラグインのサイドバー名をローカライズします。デスクトップの更新通知とテンプレートフィールドのデフォルトを修正しました。 (#10522、#10663、#10576、#10622、#10517)
  • WebUI: 構成のヒントと条件設定を明確にします。 Pip ダイアログを全画面ログに表示したままにします。ログ ストリーム ヘッダーを即座にフラッシュします。ナビゲーション後のログの重複を防ぎます。プラグインのフィルター範囲を明確にします。 (#10647、#10608、#10666、#10694、#10691)
  • データベース: 移植可能な JSON クエリ式を使用します。 (#10664)

何が変わったのか

  • 功績: メッセージ トレースを改善し、制限された SQLite 履歴を追加 (https://github.com/AstrBotDevs/AstrBot/pull/10614 の @Soulter による)
  • 修正: https://github.com/AstrBotDevs/AstrBot/pull/10522 の @wcqqq1214 による構成更新後にフェッチされたモデルのメタデータを保持する
  • 修正 (ダッシュボード): https://github.com/AstrBotDevs/AstrBot/pull/10576 の @wcqqq1214 によるサイドバーのプラグイン名をローカライズ
  • 修正: https://github.com/AstrBotDevs/AstrBot/pull/10517 の @wcqqq1214 による明示的なデフォルトを使用せずにテンプレートの辞書フィールドを初期化
  • 修正: https://github.com/AstrBotDevs/AstrBot/pull/10622 の @Soulter によるヘッダーに clickable デスクトップ更新通知を表示
  • 偉業(インストール): https://github.com/AstrBotDevs/AstrBot/pull/10629 の @Soulter による多言語セットアップと中国本土のミラーを追加
  • chore(deps): https://github.com/AstrBotDevs/AstrBot/pull/10636 の @dependabot[bot] により、github-actions グループ内の github/codeql-action を 4.38.3 から 4.39.0 にバンプします
  • 修正（ダッシュボード）: https://github.com/AstrBotDevs/AstrBot/pull/10608 の @mantoujun12 により、pip インストール ダイアログをコンソールの全画面表示に保つ
  • 修正 (ダッシュボード): https://github.com/AstrBotDevs/AstrBot/pull/10647 の @Soulter による設定ヒントを明確にし、無効なオプションを非表示にしました
  • 機能 (ダッシュボード): コンソールと設定ページからログをエクスポート (https://github.com/AstrBotDevs/AstrBot/pull/10418 の @niansia による)
  • 修正 (ダッシュボード): https://github.com/AstrBotDevs/AstrBot/pull/10659 の @Soulter による診断エクスポートの完全な改善
  • 修正(テスト): https://github.com/AstrBotDevs/AstrBot/pull/10660 の @Soulter による診断エクスポート フィクスチャで一貫した改行を使用する
  • 修正: https://github.com/AstrBotDevs/AstrBot/pull/10644 の @wcqqq1214 によってスケジュールされたタスクをバックアップに含める
  • 修正: https://github.com/AstrBotDevs/AstrBot/pull/10661 の @Soulter によるバックアップ内の永続データの保存
  • perf(db): https://github.com/AstrBotDevs/AstrBot/pull/10664 の @Soulter による移植可能な JSON クエリ式を使用します。
  • 修正 (ダッシュボード): https://github.com/AstrBotDevs/AstrBot/pull/10663 の @Soulter によるデフォルトのチャット モデル選択を復元
  • 修正: https://github.com/AstrBotDevs/AstrBot/pull/10635 の @niansia による Gemini ツール スキーマの非文字列列挙を回避
  • 修正 (セキュリティ): https://github.com/AstrBotDevs/AstrBot/pull/10670 の @DOTBave による eMudhra CA 侵害のバンプ証明書とピップ フロア
  • 修正 (ダッシュボード): https://github.com/AstrBotDevs/AstrBot/pull/10666 の @Heximiao によるイベントを待機する前にログ SSE ヘッダーをフラッシュ
  • 修正 (ダッシュボード): https://github.com/AstrBotDevs/AstrBot/pull/10694 で @Soulter によるナビゲーション後のコンソール ログの重複を防止
  • 修正: https://github.com/AstrBotDevs/AstrBot/pull/10719 で @Soulter による Gemini モデル生成パラメーターをサポート
  • 修正(ダッシュボード): https://github.com/AstrBotDevs/AstrBot/pull/10691 の @mantoujun12 によるログ プラグイン フィルターのスコープを明確化
  • 修正（コンピューター）: https://github.com/AstrBotDevs/AstrBot/pull/10671 の @Dailiduzhou によるシェルとファイル ツールの Shipyard Bay 実行エンベロープのアンラップ
  • ドキュメント: @Soulter による SerpApi および DeepSeek Search API ガイドを https://github.com/AstrBotDevs/AstrBot/pull/10731 に追加
