AstrBot v4.18.1

#アストラボットv4.18.1

何が変わったのか

修正

  • 修正: プラグイン マーケットでプラグインが空白で表示されるバグを修正しました。搭載されているプラグインカードのレイアウトを修正し、サイズを統一しました(#5309)

新しい

  • サブエージェントはバックグラウンド実行モード構成をサポートします。background: true の場合、サブエージェントはバックグラウンドで実行され、サブエージェントの完了を待たずにメインの会話を続行できます。サブエージェントが完了すると、通知が届きます。長時間実行されるタスク、またはユーザーがすぐに結果を必要としない場合に適しています。 (#5081)
  • 新しいパスワード レンダリング サポートを追加するようにスキーマを構成します。string および text タイプは、password: true (または render_type: "password") を介した WebUI のパスワード入力方法に従って表示できます。

変更点 (英語)

修正

  • 修正: プラグイン マーケットプレイスでプラグインの空白のカードが表示されるバグを修正しました。一貫したサイズにするために、インストールされているプラグイン カードのレイアウトを修正しました (#5309)

新機能

  • サブエージェントのバックグラウンド実行モードのサポートを追加しました。background: true が設定されている場合、サブエージェントはバックグラウンドで実行され、サブエージェントの終了を待たずにメインの会話を続行できるようになります。サブエージェントが完了すると通知が届きます。これは、長時間実行されるタスクや、ユーザーがすぐに結果を必要としない場合に適しています。 (#5081)
  • 構成スキーマでのパスワード レンダリング サポートの追加: string および text フィールドは、password: true (または render_type: "password") を使用して WebUI のパスワード入力としてレンダリングできます。

何が変わったのか

  • 修正(SubAgentPage): 中央の導入テキストが非常に長い場合、Flex レイアウトにより右側のコントロール ボタン領域が自動的に圧迫されます (https://github.com/AstrBotDevs/AstrBot/pull/5306 の @SXP-Simon により)
  • 修正: 新バージョンのプラグイン マーケットでプラグインの表示が空白になるバグを修正。 https://github.com/AstrBotDevs/AstrBot/pull/5309の@SXP-Simonにより、搭載されているプラ​​グインカードのレイアウトを修正しサイズを統一
  • 特技: https://github.com/AstrBotDevs/AstrBot/pull/5081 の @advent259141 により、メイン エージェントのワークフローをブロックしないバックグラウンド タスクとしてサブエージェントの生成をサポートします。 フル Changelog: https://github.com/AstrBotDevs/AstrBot/compare/v4.18.0...v4.18.1
