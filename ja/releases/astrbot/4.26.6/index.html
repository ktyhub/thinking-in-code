AstrBot v4.26.6

#アストラボットv4.26.6

[4.26.6] - 2026-07-14

追加

  • WebUI にペルソナのインポートとエクスポートを追加しました。エクスポートされたペルソナでは、ツールとスキル構成が意図的に除外されます。 (#4532)

変更されました

  • Anthropic プロバイダーの一時キャッシュ制御を有効にして、キャッシュ ヒット率を向上させました。 (#9197)
  • README ドキュメントを改良し、Satori と Mattermost チュートリアルのリンクを修正しました。 (#9205)
  • グループ化された GitHub アクションの依存関係を更新しました。 (#9170)

修正済み

  • ダッシュボードアカウントのユーザー名の更新を検証しました。 (#9175)
  • サポートされていない force 引数を LINE 応答解析から削除しました。 (#9187)
  • メッセージ配信を中断することなく、無効な応答クリーンアップ正規表現を処理しました。 (#9183)
  • モバイルチャット入力のフリーズと複数行の添付ボタンの配置を修正しました。 (#9202)
  • ChatUI モデルの選択をテーマに対応させました。 (#9200)
  • i18n コールバック パスを設定全般に修正しました。 (#9201)
  • スキルのダウンロードが失敗した場合に、適切な HTTP エラーが返されました。 (#9213)
  • WebChat をフレンドウェイクプレフィックスから除外しました。 (#9215)
  • NVIDIA MiniMax M3 で max_tokens を正しく処理しました。 (#9209)
  • トークン インジケーターで現在のコンテキストの使用状況を正確に報告しました。 (#9255)
  • ページ更新後にアクティブな ChatUI ストリームを再開しました。 (#9259) [4.26.6]: https://github.com/AstrBotDevs/AstrBot/compare/v4.26.5...v4.26.6

何が変わったのか

  • 修正: https://github.com/AstrBotDevs/AstrBot/pull/9175 の @VectorPeak によるダッシュボード アカウントのユーザー名の更新を検証
  • 修正: https://github.com/AstrBotDevs/AstrBot/pull/9187 の @SpencerFang0617 による、astrbot\core\platform\sources\line\line_adapter.py の get_json から予期しない強制引数を削除
  • 修正: https://github.com/AstrBotDevs/AstrBot/pull/9183 の @CooperWang0912 によるフィルター処理に Try Except を追加
  • 修正（プラットフォーム）: https://github.com/AstrBotDevs/AstrBot/pull/9205 の @th-dd による、Satori と Mattermost の正しいチュートリアル リンク
  • 修正: https://github.com/AstrBotDevs/AstrBot/pull/9202 の @leafliber によるモバイル チャット入力のフリーズと複数行の添付ファイル ボタンの配置を解決
  • 修正: ChatUI モデル選択をテーマに対応させる (https://github.com/AstrBotDevs/AstrBot/pull/9200 の @wcqqq1214 による)
  • 修正: Anthropic プロバイダーで一時キャッシュ制御モードを使用して、https://github.com/AstrBotDevs/AstrBot/pull/9197 の @911218sky によるキャッシュ ヒット率を向上させました。
  • chore(deps): https://github.com/AstrBotDevs/AstrBot/pull/9170 の @dependabot[bot] による 4 つの更新で github-actions グループをバンプします
  • 修正(i18n): https://github.com/AstrBotDevs/AstrBot/pull/9201 の @th-dd によるプラットフォーム コールバック パス変換を更新
  • 修正: https://github.com/AstrBotDevs/AstrBot/pull/9213 で @VectorPeak によって失敗したスキルのダウンロードに対して HTTP エラーが返される
  • 修正: https://github.com/AstrBotDevs/AstrBot/pull/9215 の @wcqqq1214 によるフレンド ウェイク プレフィックスから WebChat を除外
  • 修正: https://github.com/AstrBotDevs/AstrBot/pull/9209 の @Last-emo-boy による NVIDIA MiniMax M3 の max_tokens のハンドル
  • 修正: WebChat トークン リングが https://github.com/AstrBotDevs/AstrBot/pull/9255 の @Fronut によってコンテキストの使用状況を過剰に報告しないようにしました。
  • fix(group_chat_context): https://github.com/AstrBotDevs/AstrBot/pull/9216 の @tsaitang404 による設定プロファイルに image_caption_prompt がない場合に、.get() を使用して KeyError を回避します
  • 修正: https://github.com/AstrBotDevs/AstrBot/pull/9259 で @Soulter による更新後に ChatUI ストリームを再開
  • 功績: ペルソナのインポートとエクスポート (https://github.com/AstrBotDevs/AstrBot/pull/4532 の @Sjshi763 による)
  • 雑務: https://github.com/AstrBotDevs/AstrBot/pull/9273 の @Soulter による 4.26.6 へのバージョンのバンプ
