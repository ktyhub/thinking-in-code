#アストラボットv4.27.1

[4.27.1] - 2026-08-02

ペル・アスペラ・アド・アストラ。

追加

  • -y / --yes を astrbot init に追加したため、無人展開でインストールの確認プロンプトをスキップできます。 (#9514)
  • OpenAI および DeepSeek テンプレート、推論とツール呼び出しの全履歴再生、および新しい xAI プロバイダーのデフォルトとしての応答 API を含む、OpenAI 互換エンドポイント用の独立したステートレスな応答 API プロバイダーを追加しました。 (#9515)
  • 構成可能な保持機能、正規化されたストレージ、および現在のグループからメッセージを検索および取得するための LLM ツールを備えた永続的なグループ メッセージ履歴が追加されました。 (#9465)
  • 増分出力、標準入力書き込み、中断、終了、タイムアウト、ライフサイクル クリーンアップを備えたマネージド ローカル シェル セッションを追加しました。 Windows セッションでは PowerShell が使用され、行指向プログラムは明示的な行書き込みをサポートするようになりました。 (#9470、#9471、#9501)
  • 共有機能セレクター、ルーティングされたプラグイン ワークスペース、より明確な MCP サーバー、ツール、スキルの来歴とステータスを備えた統合された拡張機能とペルソナ管理エクスペリエンスが追加されました。 (#9499)
  • 再利用可能なスキルを作成し、Office ドキュメント、PDF、スプレッドシートを操作するための組み込み skill-creator、documents、pdf、spreadsheets スキルを追加しました。
  • 汎用 HTTP(S)、SSH、および SCP スタイルの Git リポジトリでホストされるプラグインのインストールと更新を追加しました。 (#9493)
  • 変換された ChatUI は、10,000 文字を超える文字をテキスト添付ファイルに貼り付けます。 (#9496)
  • 管理者のチャット アクセスおよび管理者の構成変更のための機密性の高い API キー サブスコープを追加し、スコープからエンドポイントまでのリファレンス ドキュメントを生成しました。 (#9503)

変更されました

  • 正規化された密/疎相対スコア融合とソース文書の多様化により、ナレッジ ベースの検索品質が向上しました。 (#9455)
  • ドキュメントコンテキストと保存された見出しパスを備えたナレッジベースの埋め込みが強化されました。 (#9457)
  • パッケージとメタデータの検証を備えた、より安全なアップデータ アーキテクチャの背後で一元化されたコア、ダッシュボード、プラグインの更新フロー。 (#9493)
  • ランタイム警告を伴う既存の非推奨の API を正式化し、下位互換性のあるエイリアスを保持しながら OpenAI ツール呼び出し変換メソッド名を修正しました。 (#9468、#9469)
  • スキル カード、ペルソナ管理、拡張機能ワークスペース、プロジェクト チャット コンポーザーのレイアウトを改良しました。
  • ツール パス トークンの使用量を削減するために、コンパクトなタイムスタンプ ベースの一時ファイル名と、より明確なワークスペース相対パス ガイダンスを使用しました。 (#9505)
  • アクティブなコマンドの管理対象セッションのメタデータを保持しながら、完了したローカル シェル コマンドについては簡潔なプレーンテキストの結果が返されました。 (#9507)

修正済み

  • ソースおよび Docker ディストリビューションの v4.27.0 で発表された組み込みの skill-creator、documents、pdf、および spreadsheets スキルが、読み取り専用のプリセット検出とローカル オーバーライドのサポートとともに含まれています。 (#9517)
  • ダークモードでの機能チップの色を修正しました。
  • インストールされている NumPy ビルドと互換性のない CPU 上で AstrBot が FTS5 取得を開始して使用できるように、BM25 依存関係のインポートを延期しました。 (#9435)
  • ナレッジ ベースのランク フュージョンを決定的にし、vLLM 再ランク応答エラーを表面化しました。 (#9454)
  • ChatUI ストリーミング応答の末尾を保持し、QQ 公式ストリーミング バッファで先頭の文字が失われるのを防ぎました。 (#9439、#9444)
  • システムのタイムゾーンを使用したローカライズされた将来のタスクのタイムスタンプ。 (#9462)
  • 管理されたローカル シェル セッションを送信者ごとに分離し、会話管理者が会話内のセッションを管理できるようにします。 (#9479)
  • 管理者 ID、機密構成、およびプロジェクト ワークスペース パスの API キー認証境界を強化しました。 (#9503)
  • アシスタントの応答が生成されない場合の永続的なターミナル ツールの呼び出し、結果、および trusted トークンの使用。 (#9500)
  • 拡張された ChatUI コンポーザ、返信、添付ファイルが最新のメッセージと重複しないようにしました。 (#9496)
  • モバイル プラグイン設定ダイアログから二重スクロールバーを削除しました。 (#9491)
  • ストレージのクリーンアップ後にツール イメージ キャッシュ ディレクトリを再作成し、新しいイメージを引き続き保存できるようにしました。 (#9490)
  • 非同期ダウンロードが失敗しないように、グローバル一時ファイルのクリーンアップまでアウトバウンド TTS および QQ 公式オーディオを利用できるようにします。 (#9506)

ドキュメント

  • QQ コミュニティ グループ 15 および 16 をコミュニティ ドキュメントに追加しました。

メンテナンス

  • Kept Responses API テスト フィクスチャは、最新の OpenAI SDK トークン使用スキーマと互換性があります。
  • グローバル一時ディレクトリ クリーナーを優先して、未使用のツール イメージのクリーンアップ パスを削除しました。 (#9504)

中国語

新しい

  • astrbot init に -y / --yes オプションを追加し、インストール確認プロンプトをスキップする無人展開を容易にしました。 (#9514)
  • 新しい独立したステートレスな OpenAI 互換の Responses API プロバイダーを追加し、OpenAI および DeepSeek テンプレートを提供し、推論とツール呼び出し履歴の完全な再生をサポートし、Responses API を新しい xAI プロバイダーのデフォルト インターフェイスとして設定します。 (#9515)
  • 設定可能な予約数でグループ メッセージの履歴を保持し、標準化されたストレージをサポートし、LLM が現在のグループ履歴メッセージを検索して読み取るためのツールを提供する機能が追加されました。 (#9465)
  • 増分出力、標準入力、割り込み、終了、タイムアウト、ライフサイクル クリーンアップをサポートする、ローカルでホストされる新しいシェル セッションを追加しました。 Windows セッションでは代わりに PowerShell が使用され、明示的な行ごとの書き込みがサポートされます。 (#9470、#9471、#9501)
  • 拡張機能とパーソナリティの管理エクスペリエンスを統合し、共有アビリティ セレクター、ルーティングされたプラグイン ワークスペース、MCP サービス、ツール、スキルのソースとステータスの明確な表示を提供します。 (#9499)
  • 再利用可能なスキルの作成とオフィス文書、PDF、スプレッドシートの処理をサポートする組み込みの skill-creator、documents、pdf、spreadsheets スキルを追加しました。
  • 一般的な HTTP(S)、SSH、および SCP スタイルの Git リポジトリからのプラグインのインストールと更新をサポートします。 (#9493)
  • ChatUI は、10,000 文字を超えるテキストを貼り付けるときに自動的にテキスト添付ファイルに変換します。 (#9496)
  • 管理者チャット アクセスおよび管理者構成変更のための機密性の高い API キー サブ権限を追加し、インターフェイスへの権限からリファレンス ドキュメントを生成しました。 (#9503)

変更

  • 正規化された密/疎相対スコア融合とソースドキュメントの重複排除を通じて、ナレッジベース検索の品質を向上させます。 (#9455)
  • ドキュメントコンテキストを使用し、タイトルレベルのパスを保持することで、ナレッジベースの埋め込みを強化します。 (#9457)
  • コア、ダッシュボード、プラグインの更新プロセスをより安全な更新アーキテクチャに統合し、インストール パッケージとメタデータの検証を追加します。 (#9493)
  • 非推奨の API に対する実行時警告を追加し、下位互換性エイリアスを保持しながら、OpenAI ツール呼び出し変換メソッド名を修正しました。 (#9468、#9469)
  • スキルカード、パーソナリティ管理、拡張ワークスペース、プロジェクトチャット入力エリアのレイアウトを最適化します。
  • コンパクトなタイムスタンプの一時ファイル名を使用し、ワークスペースの相対パス ガイダンスをクリアして、ツール パスが占めるトークンの量を減らします。 (#9505)
  • 完了したローカル シェル コマンドの圧縮されたプレーン テキストの結果を返し、実行中のコマンドの管理されたセッション メタデータを引き続き保持します。 (#9507)

修正

  • v4.27.0 アナウンスの組み込み skill-creator、documents、pdf、spreadsheets スキルをソース コードと Docker ディストリビューションに追加し、読み取り専用プリセット機能として自動検出をサポートし、同じ名前のローカル スキル オーバーライドを許可します。 (#9517)
  • ダークモードでの能力ラベルの色を修正しました。
  • インストールされた NumPy が CPU と互換性がない場合でも、AstrBot が起動して FTS5 取得を使用できるように、BM25 依存関係のインポートを遅延しました。 (#9435)
  • ナレッジ ベースのランキング フュージョンの結果が安定していることを確認し、vLLM の並べ替え応答エラーを正しく明らかにするようにします。 (#9454)
  • ChatUI ストリーミング応答の最後にコンテンツを保持し、QQ 公式ロボット ストリーミング バッファで先頭の文字が失われるのを防ぎます。 (#9439、#9444)
  • 今後のタスク時間にはシステムのタイムゾーンを使用します。 (#9462)
  • ローカルでホストされているシェル セッションを送信者ごとに分離し、セッション管理者が同じセッション内のシェル セッションを管理できるようにします。 (#9479)
  • 管理者 ID、機密性の高い構成、プロジェクト ワークスペース パスに対する API キーの認証境界を強化します。 (#9503)
  • アシスタントが応答しない場合のターミナル ツールの呼び出し、結果、および信頼されたトークンの使用の永続化。 (#9500)
  • 拡張された ChatUI 入力領域、返信、添付ファイルによって最新のメッセージがブロックされるのを防ぎます。 (#9496)
  • モバイル プラグイン設定ポップアップ ウィンドウの二重スクロール バーを削除しました。 (#9491)
  • 新しいイメージを引き続き保存できるように、ストレージ クリーニング後にツール イメージ キャッシュ ディレクトリを自動的に再構築します。 (#9490)
  • 非同期ダウンロードの失敗を避けるために、TTS および QQ 公式ロボットのアウトバウンド音声をグローバル一時ファイルのクリーンアップに保存します。 (#9506)

ドキュメント

  • コミュニティ ドキュメントに QQ グループ 15 および 16 を追加しました。

メンテナンス

  • レスポンス API テスト データを、最新の OpenAI SDK のトークン使用構造と互換性のあるものにします。
  • 未使用のツール イメージの独立したクリーニング ロジックを削除し、管理のためにグローバル一時ディレクトリ クリーナーに統合しました。 (#9504) [4.27.1]: https://github.com/AstrBotDevs/AstrBot/compare/v4.26.8...v4.27.1
