AstrBot v4.24.4

#アストラボットv4.24.4

  • アップデートログ(簡体字中国語)
  • Changelog(英語) <a id="中国語"></a>

何が変わったのか

最適化

  • ダッシュボードのログインとパスワードのセキュリティを強化: 初回起動時に強力なランダムな初期パスワードを生成し、パスワード ストレージを PBKDF2 にアップグレードし、古い MD5 互換アップグレード プロセスを保持し、必要に応じてセキュリティ アップグレードを完了するようにユーザーをガイドします。 (#7338)
  • 強化されたプラグイン ページの国際化機能、プラグイン ページ、拡張ページ、および関連するダッシュボード コピーを現在の言語でより適切に表示できるようになりました。 (#7998)
  • ダッシュボードのインジケーター統計をオフにできる WebUI インジケーター スイッチ構成 disable_metrics を追加しました。 (#7946)
  • ページを更新した後もユーザーの選択を保持するために、コンソールの自動スクロール スイッチの永続性を追加しました。 (#8024)
  • メッセージの読み取りエクスペリエンスを向上させるために、思考内容と最終返信を視覚的に分離する機能を追加しました。 (#8059)
  • プラグインのインストール、バックアップとリカバリ、およびパスの競合処理を最適化し、自己修復ロジックを追加して、一時ディレクトリの残留物とエラー追跡の誤検出を削減します。 (#7737、#8148)
  • Windows Updater の zip ルート ディレクトリの正規化と Python ツールのエンコード処理を最適化し、Windows 環境の互換性を向上させます。 (#8019)
  • CUA ファイルのアップロード ロジックを最適化し、ネイティブ ファイル インターフェイスを使用してアップロードを処理します。 (#8069)
  • CUA アイドル サンドボックス セッションの有効期限機能を最適化し、ダッシュボードで CUA アイドル タイムアウト設定を公開します。 (#8074、#8075)
  • マネージド httpx client を使用するように Gemini プロバイダーを最適化します。 (#8112)
  • ダッシュボードのモバイルレイアウト、コンソールのログレベルの調整、リストアイテムの操作ボタンの表示ロジックを最適化します。 (#7988、#8081)

修正

  • ナレッジ ベースが空のプロンプトで検索をトリガーする問題を修正しました。 (#8073)
  • Discord コマンド同期がクォータに達したときにプラットフォームの起動に影響する問題を修正しました。 (#8061)
  • GitHub フォールバック ダウンロード URL のリソース ファイル名が正しくない問題を修正しました。 (#8046)
  • フォルダーの名前を変更すると親関係が失われる問題を修正しました。 (#7974)
  • 設定にwebsearch_firecrawl_keyが欠落しており、Baidu検索を閉じてもキーフィールドが表示されたままになる問題を修正しました。 (#8012、#7992)
  • 未検証の T2I テンプレート コンテンツが Jinja2 SSTI インジェクションにつながる可能性がある問題を修正しました。 (#8077)
  • 貢献者画像の最大数、API キー ドキュメントの例、プラグイン リリースの 16MB 制限の説明、README バッジ、および複数のプラグイン開発ドキュメントのエラーを修正しました。 (#8000、#7977、#8108、#8079、#7979、#8001、#8129、 #8166) <a id="english"></a>

変更点 (英語)

新機能

  • プラグイン changelog とプラグイン更新システムを追加しました。これにより、プラグイン詳細ページにバージョン更新情報が表示され、より完全なプラグイン更新フローがサポートされます。
  • プラグイン ページの国際化が強化され、プラグイン ページ、拡張機能ビュー、および関連するダッシュボード コピーが現在の言語に準拠できるようになりました。 (#7998)
  • ダッシュボードからのメトリック収集を無効にするための disable_metrics WebUI 構成オプションを追加しました。 (#7946)
  • 永続的なコンソール自動スクロール設定を追加しました。 (#8024)
  • 思考内容と最終応答の間に視覚的な区切り文字を追加しました。 (#8059)
  • CUA サンドボックス セッションのアイドル有効期限を追加し、ダッシュボードで CUA アイドル タイムアウト設定を公開しました。 (#8074、#8075)

改善点

  • 強化されたダッシュボード認証とパスワード セキュリティ: 初期パスワードはランダムに生成され、パスワード ストレージは PBKDF2 にアップグレードされ、従来の MD5 互換性はアップグレードのために保持され、必要に応じてユーザーはセキュリティ アップグレードを案内されます。 (#7338)
  • プラグインのインストール、バックアップの復元、および自己修復動作によるパス競合の処理が改善され、一時ディレクトリの残り物や誤ったエラー レポートが減少します。 (#7737、#8148)
  • Windows アップデータの zip-root 正規化と Python ツールのエンコード処理が改善され、Windows の互換性が向上しました。 (#8019)
  • ネイティブ ファイル インターフェイスを使用して CUA アップロードを改善しました。 (#8069)
  • マネージド httpx client を使用するように Gemini プロバイダーを改善しました。 (#8112)
  • ダッシュボードのモバイル レイアウト、コンソールのログレベルの調整、リスト項目のアクション ボタンの可視性が改善されました。 (#7988、#8081)

バグ修正

  • Jinja2 SSTI インジェクションを可能にする T2I テンプレート コンテンツの検証が欠落していたのを修正しました。 (#8077)
  • 空白のプロンプトに対してナレッジ ベースの取得がトリガーされる問題を修正しました。 (#8073)
  • コマンドクォータ処理によって Discord の起動が中断される問題を修正。 (#8061)
  • GitHub フォールバック ダウンロード URL の誤ったアセット ファイル名を修正しました。 (#8046)
  • 名前を変更するとフォルダーの親関係が失われる問題を修正しました。 (#7974)
  • デフォルト設定で欠落している websearch_firecrawl_key と、無効になったときに非表示になる Baidu Web 検索キーを修正しました。 (#8012、#7992)
  • 寄稿者の画像制限、API キーの例、プラグインの公開サイズ制限ドキュメント、README バッジ、および複数のプラグイン開発ガイドの問題を修正しました。 (#8000、#7977、#8108、#8079、#7979、#8001、#8129、 #8166)

何が変わったのか
