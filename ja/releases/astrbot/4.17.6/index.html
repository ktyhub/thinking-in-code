AstrBot v4.17.6

パッチ 公開日2026年2月20日 出典AstrBotDevs/AstrBot 英語原文

#アストラボットv4.17.6

何が変わったのか

新しい

  • リスクの高い操作のセキュリティを向上させるために、Python/シェル実行ツールの管理者権限の検証を追加しました (#5214)。
  • プラグイン astrbot-version とプラットフォーム バージョン要件の検証サポートを追加し、プラグイン互換性管理機能を強化しました (#5235)。
  • 誤った入力によって引き起こされる構成の問題を軽減するために、アカウントのパスワード変更プロセスに「新しいパスワードの確認」チェックを追加しました (#5247)。

修正

  • MCP ツールがメイン エージェントに完全に公開され、パーソナリティ ツールの選択を無視する問題を修正しました (#5252)。
  • WeChat パブリック アカウントのパッシブ返信処理メカニズムを改善し、バッファリングと断片化された返信を導入し、タイムアウト動作を最適化して返信の安定性を向上しました (#5224)。
  • JSON メッセージ セグメント (#5208) のみを送信すると、空のメッセージ返信エラーが発生する可能性がある問題を修正しました。
  • セッションのリセット/作成/削除時にアクティブなイベントが終了しないことによって引き起こされる古い応答の問題を修正しました (#5225)。
  • プロバイダーが dict 形式 content シナリオで JSON コンテンツを保持する可能性がある問題を修正しました (#5250)。
  • ツール スキーマ属性の additionalProperties 構成の問題を修正 (#5253)。
  • アカウント編集および検証エラー プロンプトを最適化し、ユーザー名/パスワードが空の場合に返される情報を簡素化して統一します。

最適化

  • ペルソナフォームのレイアウトとツール選択表示を最適化し、ツールの非アクティブ化ステータスのローカライズされた表示を改善しました。

その他

  • Electron Desktop パイプラインを削除し、Tauri リポジトリ (#5226) に移動しました。
  • 関連するウェアハウス リンクと機能リクエスト テンプレートのコピーを更新して、中国語と英語の表現を統一します。
  • 廃止されたドキュメント ファイル heihe.md を削除しました。

変更点 (英語)

新機能

  • 高リスク操作の安全性を向上させるために、Python/Shell 実行ツールの管理者権限チェックを追加しました (#5214)。
  • 互換性管理を改善するために、astrbot-version のサポートとプラグインのプラットフォーム要件チェックを追加しました (#5235)。
  • タイプミスによる設定ミスを減らすために、アカウントのパスワードを変更する際のパスワード確認を追加しました (#5247)。

修正

  • 安定性を向上させるためにバッファリング/チャンキングとタイムアウト動作を最適化することで、WeChat 公式アカウントのパッシブ応答処理を改善しました (#5224)。
  • JSON メッセージ セグメントのみが送信された場合の空メッセージ応答エラーを修正しました (#5208)。
  • リセット/新規/削除操作でアクティブなイベントを終了することにより、古い応答を修正しました (#5225)。
  • content が dict 形式 (#5250) の場合のプロバイダー処理における残留 JSON コンテンツの問題を修正しました。
  • メイン エージェントに対する MCP ツールの不完全な公開を修正しました (#5252)。
  • ツール スキーマ プロパティでの additionalProperties の処理を​​修正しました (#5253)。
  • 空のユーザー名/パスワードのシナリオに対するアカウント編集検証エラー応答が簡素化され統合されました。

改善点

  • ペルソナフォームのレイアウトとツール選択表示が強化され、非アクティブなツールのローカライズされたラベルが改善されました。

その他

  • Electron デスクトップ パイプラインを削除し、Tauri リポジトリ (#5226) に切り替えました。
  • 関連リポジトリ リンクを更新し、中国語と英語の両方で機能リクエスト テンプレートの文言を洗練しました。
  • 古いドキュメント ファイル heihe.md を削除しました。

何が変わったのか

  • 功績: https://github.com/AstrBotDevs/AstrBot/pull/5214 の @Soulter によるコンピューター使用機能の管理者権限チェック構成項目を追加
  • 修正: WeChat 公開アカウントの受動的な返信処理メカニズムを改善し、バッファリングと断片化された返信を導入し、https://github.com/AstrBotDevs/AstrBot/pull/5224 の @Trance-0 によるタイムアウト動作を最適化します。
  • 修正: https://github.com/AstrBotDevs/AstrBot/pull/5208 で @NanoRocky によって JSON メッセージ セグメントのみを送信するときの空のメッセージ応答エラーを修正
  • 修正（コア）: https://github.com/AstrBotDevs/AstrBot/pull/5225 の @YukiRa1n による古い応答を防ぐために、リセット/新規/削除時にアクティブなイベントを終了します。
  • 雑務: Electron デスクトップ パイプラインを削除し、https://github.com/AstrBotDevs/AstrBot/pull/5226 の @zouyonghe による tauri リポジトリに切り替える
  • フィート/構成は https://github.com/AstrBotDevs/AstrBot/pull/5249 の @SnowNightt によって確認されています
  • 機能: https://github.com/AstrBotDevs/AstrBot/pull/5235 の @Soulter によるプラグインの astrbot バージョンとプラットフォーム要件チェックのサポートを追加
  • 特技: https://github.com/AstrBotDevs/AstrBot/pull/5247 で @whatevertogo によるパスワード変更時にパスワード確認を追加
  • fix(provider): 修正 dict 格式内容 导致的 JSON 残留问题 by @NayukiChiba in https://github.com/AstrBotDevs/AstrBot/pull/5250
  • 修正: https://github.com/AstrBotDevs/AstrBot/pull/5252 の @Soulter によってメイン エージェントに公開されたすべての mcp ツール
  • 修正: https://github.com/AstrBotDevs/AstrBot/pull/5253 の @Soulter によってツール スキーマ プロパティから追加のプロパティを削除

  • @Trance-0 が https://github.com/AstrBotDevs/AstrBot/pull/5224 に初めて貢献しました
  • @whatevertogo が https://github.com/AstrBotDevs/AstrBot/pull/5247 で最初の投稿を行いました フル Changelog: https://github.com/AstrBotDevs/AstrBot/compare/v4.17.5...v4.17.6
