#AstrBot v4.29.4

[4.29.4] - 2026-10-31

新しい

  • メッセージ ボタン: 新しいクロスプラットフォーム ボタン コンポーネントが追加され、リンク、メッセージ送信、プラグイン コールバックをサポートし、インタラクション タイムアウト プロンプトを提供します。各プラットフォームでサポートされるボタンのタイプはドキュメントの対象となります。 (#9809)
  • デシジョン モデル: プラグインのチャット モデルから独立したデシジョン プロバイダーと System One アダプターを追加し、構造化された選択、ブール判定、スコアリングを呼び出すことができます。 (#10775)
  • Web 検索: SerpApi Google ニュースにアクセスし、ニュース ソース、著者、発行時刻、WebUI 引用表示をサポートします。 (#10773)
  • セッションとユーザーの選択: セッション ソース選択ポップアップ ウィンドウを統合し、ニックネーム検索、プラットフォーム識別、ページング、ID コピーをサポートします。送信者情報を記録し、Feishu と QQ の公式グループ名を完全に記録します。管理者設定の入り口が「追加 → リスト項目の編集」から「ユーザーの選択」に変更されました。元のセッションのドロップダウンボックスとリスト編集の入り口が「セッションソースの選択」に統一され、「既知のセッション」が「記録されたセッションソース」に変更されます。 (#10747)
  • ロボット管理: ロボットを削除するときに、構成、スケジュールされたタスク、会話、メッセージ記録、追跡および使用状況データをクリーンアップすることを選択できます。会話と履歴データはデフォルトで保持されます。 (#10761)
  • スケジュールされたタスク: グループ内の共有タスク リストの表示をサポートし、管理者がグループ タスクを削除できるようにします。 (#10785)
  • ネットワーク設定: PyPI ミラーセレクターと速度測定機能を追加しました。 (#10657)

最適化と修復

  • 安定性: ログ出力がブロックされているときに WebUI と WebChat が応答しなくなる可能性がある問題を修正し、診断パッケージでコンソール ログ破棄統計を提供します。 (#10902)
  • コンテキスト圧縮: 設定を簡素化し、「履歴が上限に達した場合またはコンテキスト ウィンドウが狭い場合の処理方法」を「圧縮戦略」に、「コンテキスト圧縮モデル プロバイダー ID」を「圧縮モデル」に変更します。最大ラウンド数、破棄されたラウンド数、圧縮命令、最近のコンテキスト比率、およびフォールバック ウィンドウ サイズは、既存の構成と実行動作を保持したまま「その他の設定」に移動されます。 (#10753)
  • モデル サービス: Anthropic 互換サービスに必要な API Key 要求ヘッダーを保持します。 DashScope エージェントのタイムアウト構成が有効にならない問題を修正します。 (#10787、#10868)
  • Gemini: ネイティブ パラメーター ショートカット テンプレートと正しいネイティブ ツール構成プロンプトを提供します。 (#10771、#10875)
  • プラグインとスキル: NAS およびその他の環境での一時ディレクトリと .astrbot マーク ファイルの間の競合によって引き起こされるプラグインのインストールの失敗を修正しました。プラグイン設定のリロード失敗が報告されました。スキルロード時にファイル読み込みツールの使用を優先しました。 (#10784、#10788、#10789)
  • セキュリティ: デフォルトの PyPI イメージの TLS 証明書検証を有効にします。 (#10685)
  • オーディオ: 0x03 プレフィックスを持つ Tencent SILK オーディオをサポートします。 (#10744)
  • ChatUI: ファイル パネルは現在のセッションの作業ディレクトリを使用します。 (#10883)
  • WebUI: トラッキング リストのリアルタイム更新を最適化し、設定フォーム スタイルを統一し、カスタム ルールでサポートされていない「all」オプションを削除し、ネイティブ スクロール バー スタイルが Firefox でのみ有効になるように制限します。 (#10748、#10755、#10757、#10760)

追加

  • メッセージ ボタン: リンク、メッセージ送信、プラグイン コールバック用のポータブル ボタン コンポーネントと、インタラクション タイムアウト通知を追加しました。サポートされるアクションのタイプはプラットフォームによって異なります。ドキュメントを参照してください。 (#9809)
  • 意思決定モデル: チャット モデルから独立した意思決定プロバイダーと、構造化された選択肢、ブール型の質問、プラグインのスコア用の System One アダプターを追加しました。 (#10775)
  • Web 検索: SerpApi Google ニュースと発行者、著者、発行時刻、および WebUI 引用を統合しました。 (#10773)
  • セッションとユーザーの選択: ニックネーム検索、プラットフォーム ラベル、ページネーション、ID コピーを備えた統合されたセッション ソースの選択。送信者情報を記録し、Lark と QQ の公式グループ名を強化しました。管理者設定は、「さらに追加」→「リスト項目の編集」から「ユーザーの選択」に移動します。以前のセッションのドロップダウンとリスト エディターは、セッション ソースの選択になります。既知のセッションは記録されたセッション ソースになります。 (#10747)
  • ボット管理: ボットを削除する際の構成、スケジュールされたタスク、会話、メッセージ履歴、トレース、および使用状況データの選択的なクリーンアップが追加されました。会話と履歴データはデフォルトで保持されます。 (#10761)
  • スケジュールされたタスク: グループ タスク リストを共有し、管理者がグループ タスクを削除できるようにします。 (#10785)
  • ネットワーク設定: PyPI ミラー ピッカーと速度テストを追加しました。 (#10657)

改善および修正されました

  • 安定性: コンソール出力がブロックされているときに WebUI と WebChat が応答しなくなる問題を修正し、診断エクスポートにコンソール ログ ドロップ カウンタを含めました。 (#10902)
  • コンテキスト圧縮: 履歴制限またはコンテキスト ウィンドウの圧力から圧縮戦略への処理の名前が変更され、コンテキスト圧縮のモデル プロバイダー ID が圧縮モデルへ変更されました。最大ターン、破棄されたターン、圧縮命令、最近のコンテキスト比率、およびフォールバック コンテキスト ウィンドウ サイズを詳細設定に移動し、既存の構成と実行時の動作を維持しました。 (#10753)
  • モデル プロバイダー: Anthropic 互換プロバイダーの API キー ヘッダーを保持し、構成された DashScope エージェント タイムアウトを尊重しました。 (#10787、#10868)
  • Gemini: ネイティブ パラメーターのクイック テンプレートを追加し、ネイティブ ツールの構成ヒントを修正しました。 (#10771、#10875)
  • プラグインとスキル: NAS および同様の環境で一時ディレクトリが .astrbot マーカー ファイルと競合する場合のプラグインのインストールを修正しました。プラグイン設定のリロード失敗が報告されました。スキルをロードするときに推奨されるファイル読み取りツール。 (#10784、#10788、#10789)
  • セキュリティ: デフォルトの PyPI ミラーの TLS 証明書検証を有効にしました。 (#10685)
  • オーディオ: 0x03 プレフィックスを持つ Tencent SILK オーディオをサポートしました。 (#10744)
  • ChatUI: ファイル パネルのアクティブ セッション ワークスペースを使用しました。 (#10883)
  • WebUI: ライブ トレースの更新をスムーズにし、設定フォームのスタイルを統一し、カスタム ルールからサポートされていない [すべて] オプションを削除し、ネイティブ スクロールバー スタイルのスコープを Firefox に設定しました。 (#10748、#10755、#10757、#10760)

完全な Changelog: https://github.com/AstrBotDevs/AstrBot/compare/v4.29.3...v4.29.4
