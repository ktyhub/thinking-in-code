AstrBot v4.26.0-beta.1

#アストラボットv4.26.0-beta.1

  • アップデートログ(簡体字中国語)
  • Changelog(英語) <a id="中国語"></a>

何が変わったのか

主要な更新

  • バックエンド アーキテクチャが Quart から FastAPI に移行され、AstrBot の内部インターフェイスと OpenAPI インターフェイス形式が統合され、複数の OpenAPI が追加されました。 (#8688)
  • すべてのプラットフォームにわたるメッセージ メディア ファイルの処理ロジックを統合し、画像、音声、ファイル、および参照されたメッセージ メディアの解析の一貫性を向上させ、メディア フォーマットに起因するエラーを削減します。 (#8764)
  • WebUI は、関数ツールのツールごとの権限管理を追加し、ツール パネルでのツール権限の表示と切り替えをサポートします。 (#8693)
  • WebUI はテーマ追従システムをサポートします。 (#8648)s
  • pilk ライブラリは、Tencent ベースの Silk 形式の音声ファイルには使用されなくなりました。 (#8764)
  • イレブンラボ TTS API プロバイダーを追加しました。 (コミット)
  • バックアップ機能にスキル ディレクトリが含まれるようになりました。 (#8700)

修正

  • プラットフォーム ID を生成するときに空白文字が含まれる可能性がある問題を修正しました。 (#8768)
  • 他のプラグインのツール設定の誤操作を避けるために、プラグイン LLM ツール スイッチの所有権検証の問題を修正しました。 (コミット)
  • プラグインの命名モードの検証と境界シーンの処理を改善しました。 (コミット)
  • プラグインの再インストール後にウェアハウスのソースが失われる問題を修正しました。 (コミット)
  • サブディレクトリ ツールにおける handler_module_path の不一致の問題を修正しました。 (#8578) ・参照画像の説明文が繰り返し表示される場合がある問題を修正しました。 (#8718)
  • 埋め込み API バージョンのサフィックスが誤って切り捨てられる問題を修正しました。 (#8736)
  • changelog ポップアップ ウィンドウでのアンカー リンクの処理を修正しました。 (#8750)
  • ダッシュボードでフォルダーを作成するときに Enter キーを押しても送信できない問題を修正しました。 (#8597)
  • 一部の環境の起動時にプロセスが停止するのを避けるために、FAISS C ライブラリのインポートを遅延しました。 (#8696)
  • シャットダウン時にデータベース エンジンを積極的に解放し、セッションやテスト環境でのリソースの残留を削減します。 (#8650) ・CLIのバージョンソースが間違っていた問題を修正。 (#8692)
  • 安定した FastAPI ダッシュボード ルーティング登録テスト。付属のルーター ノードと互換性があります。 (コミット)

最適化とエンジニアリング

  • メッセージ コンポーネントのログ出力では、ログ内に大きなインライン メディア コンテンツが含まれないように、長すぎる Base64 フィールドが切り捨てられるようになりました。 (#8591)
  • pilk ライブラリは、Tencent ベースの Silk 形式の音声ファイルには使用されなくなりました。 (#8764)
  • グループ チャット コンテキストに、引用されたメッセージの内容が表示されるようになりました。 (コミット)
  • 会話コンテキストに今週の情報を追加しました。 (#8669)
  • CLI プラグイン リスト構築のパフォーマンスと堅牢性を最適化し、キー マージ ロジックと境界シナリオ テストを補足します。 (#8705)
  • GitHub エージェント gh.dpik.top を追加し、無効なエージェント gh.llkk.cc を削除しました。 (#8772、#8761)
  • PR タイトル チェックにより、より従来型のコミット プレフィックスが可能になります。 (#8665)
  • pyupgrade コード最新化アップデートを適用し、Codecov GitHub アクションをアップグレードします。 (#8684、コミット)
  • ドキュメント内の LM Studio パブリック IP の説明を修正し、OpenAPI およびプラグイン ページに関連するドキュメントを更新します。 (#8707、#8688) <a id="english"></a>

変更点 (英語)

ハイライト

  • バックエンド バックボーンを Quart から FastAPI に移行し、ASGI ランタイム、ダッシュボード API ルーター/サービス、OpenAPI v1 定義、および生成されたダッシュボード API client を追加しました。 (#8688)
  • メッセージ コンポーネント、エージェント ランナー、プロバイダー、および複数のプラットフォーム アダプターにわたる統合されたメディア参照処理により、より一貫した画像、音声、ファイル、および引用メッセージのメディア解像度が実現します。 (#8764)
  • WebUI の関数ツールにツールごとの権限管理が追加され、ツール権限の表示と切り替えのコントロールが追加されました。 (#8693)
  • 一元的なシステム テーマ同期を備えた、ライト、ダーク、およびシステム設定の WebUI テーマ モードを追加しました。 (#8648)
  • イレブンラボ TTS API プロバイダーを追加しました。 (コミット)
  • スキル ディレクトリをバックアップに含めました。 (#8700)

バグ修正

  • 複数の aiocqhttp プラットフォーム アダプターおよびメッセージ イベント API 呼び出しにわたって欠落していた self_id ルーティング パラメーターを修正しました。 (#8779)
  • 空白文字を避けるために、生成されたプラットフォーム ID をサニタイズしました。 (#8768)
  • プラグイン LLM ツールを切り替えるときの所有権チェックを修正し、他のプラグインのツール設定が誤って変更されるのを防ぎます。 (コミット)
  • プラグインの命名パターンの検証とエッジケースの処理が改善されました。 (コミット)
  • プラグインの再インストール時にリポジトリのソース情報が保持されます。 (コミット)
  • サブディレクトリ内のツールの一貫性のない handler_module_path 値を修正しました。 (#8578)
  • 引用画像のキャプションの重複を回避しました。 (#8718)
  • API バージョンのサフィックスを誤って切り捨てるのではなく、埋め込みを維持しました。 (#8736)
  • ダッシュボード ダイアログでの changelog アンカー リンクの処理を修正しました。 (#8750)
  • Enter キーを押してダッシュボード フォルダーの作成を送信できるようにしました。 (#8597)
  • 一部の環境での起動のハングを回避するために、FAISS C ライブラリのインポートを延期しました。 (#8696)
  • セッションとテストでのリソースの残りを減らすために、シャットダウン時にデータベース エンジンを破棄しました。 (#8650)
  • CLI バージョンのソースを修正しました。 (#8692)
  • 付属のルーター ノードの FastAPI ダッシュボード ルート登録テストが安定しました。 (コミット)

改善とメンテナンス

  • メッセージ コンポーネントのログ出力では、ログ内の大きなインライン メディア ペイロードを避けるために、長い Base64 フィールドが切り捨てられるようになりました。 (#8591)
  • Tencent Silk 音声ファイルは、pilk ライブラリを使用しなくなりました。 (#8764)
  • グループ チャット コンテキストには、引用されたメッセージ コンテンツが含まれるようになりました。 (コミット)
  • 会話コンテキストに現在の平日の情報を追加しました。 (#8669)
  • CLI プラグイン リストの構築パフォーマンスと堅牢性が向上し、キーのマージとエッジ ケースのテストが行われました。 (#8705)
  • GitHub プロキシ gh.dpik.top を追加し、無効な gh.llkk.cc プロキシを削除しました。 (#8772、#8761)
  • PR タイトル チェックでより従来型のコミット プレフィックスを使用できるようにしました。 (#8665)
  • pyupgrade アップデートを適用し、Codecov GitHub アクションをアップグレードしました。 (#8684、コミット)
  • LM Studio のパブリック IP ドキュメントの文言を修正し、OpenAPI/プラグイン ページのドキュメントを更新しました。 (#8707、#8688)
