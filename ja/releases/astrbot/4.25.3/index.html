AstrBot v4.25.3

#アストラボットv4.25.3

  • アップデートログ(簡体字中国語)
  • Changelog(英語) <a id="中国語"></a>

何が変わったのか

主要な更新

  • DingTalk Streamタスクが異常終了すると再接続を継続できない問題を修正し、DingTalkアダプターの長時間接続の安定性を向上しました。 (#8610)
  • ダッシュボードログインには TOTP の 2 要素認証が追加されます。 (#8189)
  • 新しいプラグイン WebUI エントリがダッシュボード サイドバーに追加され、MDI アイコンをサポートします。プラグイン ページはダッシュボード テーマと同期します。 (#8569、#8390)
  • 今後のタスクUIを最適化し、「タスク作成」の製品化レベルを向上させます。 (#8559)
  • umo に名前を付けて UI に表示するための /name コマンドを追加しました。 (#8575)
  • MiniMax トークン プランは、モデル リストの動的取得をサポートし、デフォルト モデルは M3 にアップグレードされます。 (#8475、#8505)
  • コンテキスト圧縮を最適化して、圧縮品質と KV キャッシュ ヒット率を向上させます。 (#8530、#8226)

修正

  • SQLite ロックが発生したときにプロバイダ統計が再試行されない問題を修正しました。 (コミット)
  • 空のモダリティが設定された機能として扱われ、コア イメージ リクエストがビジュアル フォールバックに誤ってルーティングされる問題を修正しました。 (#8451)
  • Reply コンポーネント toDict の追加フィールドによりプライベート メッセージの送信に失敗する問題を修正しました。 (#8477)
  • Reply コンポーネントを使用してロボットを起動し、ユーザー プロンプトが空の場合の処理の問題を修正しました。 (#8461)
  • aiocqhttp アダプタが音声を解析できない問題を修正し、音声ファイルの存在チェックを追加しました。 (#8523、#8529)
  • SiliconFlow 非 Qwen 埋め込みモデルでの OpenAI 埋め込みの無効なパラメーターの問題を修正しました。 (#8508)
  • gemini-embedding-2 で Gemini Embedding バッチ テキストが折りたたまれる問題を修正しました。 (#8537)
  • WeCom AI メッセージ チェーンからプレーン テキストを抽出する際の空白処理の問題を修正しました。 (#8563)
  • ダッシュボードがランチャーで実行されているときにフレーム セキュリティ ヘッダーが厳しすぎる問題を修正しました。 (#8554)
  • コンソールの pip インストール エラー表示を修正し、代わりにトースト プロンプトを使用します。 (#8462)
  • テンプレート設定に関連する問題を最適化します。 (#8228)

最適化とエンジニアリング

  • 応答メッセージ チェーンのレコード コンポーネントの処理を強化します。 (#8527)
  • Whisper STT は、OpenAI トランスコーディング インターフェイスを呼び出した後、オーディオ ファイル ハンドルを閉じます。 (#8528)
  • wake コマンドがグループ チャット コンテキストとして記録されないようにします。 (#8536)
  • 中国語テキストのトークン用語を修正しました。 (#8465)
  • GitHub アクションを更新します。(#8533) <a id="english"></a>

変更点 (英語)

ハイライト

  • DingTalk Stream タスクの回復を修正し、予期しない SDK タスクが終了した後もアダプターが再接続し続けるようにしました。 (#8610)
  • ダッシュボードログインに TOTP 2 要素認証を追加しました。 (#8189)
  • MDI アイコンをサポートするプラグイン WebUI エントリをダッシュボード サイドバーに追加し、ダッシュボード テーマのスタイルをプラグイン ページに同期しました。 (#8569、#8390)
  • 今後のタスク UI を追加し、UI に表示される umo エントリに名前を付けるための /name を導入しました。 (#8559、#8575)
  • MiniMax トークン プランは、デフォルト モデルが M3 にアップグレードされた状態で、モデル リストを動的にフェッチできるようになりました。 (#8475、#8505)
  • KV キャッシュ ヒット率の向上など、長期メモリとコンテキスト圧縮の品質が向上しました。 (#8530、#8226)

バグ修正

  • SQLite がロックされているときにプロバイダー統計の読み取りを再試行しました。 (コミット)
  • 空のモダリティを未構成として扱うため、画像リクエストが誤ってビジョン フォールバックにルーティングされなくなります。 (#8451)
  • 返信コンポーネント toDict 出力の余分なフィールドによって引き起こされるプライベート メッセージ送信エラーを修正しました。 (#8477)
  • Reply コンポーネントと空のユーザー プロンプトでボットを起動する問題を修正しました。 (#8461)
  • aiocqhttp アダプターの音声解析を修正し、オーディオ ファイルの存在チェックを追加しました。 (#8523、#8529)
  • SiliconFlow 非 Qwen 埋め込みモデルの無効な OpenAI 埋め込みパラメータを修正しました。 (#8508)
  • gemini-embedding-2 での崩壊を避けるために、コンテンツ内のテキストを埋め込む Gemini バッチをラップしました。 (#8537)
  • WeCom AI メッセージ チェーンからプレーン テキストを抽出するときの空白の処理を修正しました。 (#8563)
  • ランチャーの下で実行する場合のダッシュボード フレームのセキュリティ ヘッダーを緩和しました。 (#8554)
  • コンソールの pip-install エラーとトースト メッセージが表示されました。 (#8462)
  • テンプレート設定の処理が最適化されました。 (#8228)

改善とメンテナンス

  • レコード コンポーネントの返信チェーン処理が強化されました。 (#8527)
  • Whisper STT での OpenAI トランスクリプション呼び出し後にオーディオ ファイル ハンドルを閉じました。 (#8528)
  • wake コマンドがグループ チャット コンテキストとして記録されないようにしました。 (#8536)
  • 中国語のトークン用語を修正しました。 (#8465)
  • GitHub アクションの依存関係を更新しました。 (#8533)

何が変わったのか

  • 修正と機能: https://github.com/AstrBotDevs/AstrBot/pull/8228 の @Railgun19457 によるテンプレート構成の最適化
  • 雑務: https://github.com/AstrBotDevs/AstrBot/pull/8465 の @Rain-0x01-39 による zh のトークン用語を修正
  • 機能: https://github.com/AstrBotDevs/AstrBot/pull/8475 の @Blueteemo による /v1/models API 経由で MiniMax トークン プランのモデル リストを動的に取得します
  • 修正: https://github.com/AstrBotDevs/AstrBot/pull/8461 の @lingyun14beta による、返信コンポーネントと空のユーザー プロンプトを備えた起動ボット
  • 功績: https://github.com/AstrBotDevs/AstrBot/pull/8189 の @Raven95676 によるダッシュボード ログインに TOTP 2 要素認証を追加
  • fix(message): ReplyコンポーネントのtoDictメソッドが冗長なフィールドを出力し、プライベートメッセージの送信に失敗する問題を修正。 @NayukiChiba 著、https://github.com/AstrBotDevs/AstrBot/pull/8477
  • fix(core): 空のリスト モダリティを未構成として扱い、https://github.com/AstrBotDevs/AstrBot/pull/8451 の @Sisyphbaous-DT-Project によって画像をモデルに渡せない問題を修正
  • 功績: https://github.com/AstrBotDevs/AstrBot/pull/8505 の @octo-patch により MiniMax トークン プランのデフォルト モデルを M3 にアップグレード
  • 修正（コンソール）: https://github.com/AstrBotDevs/AstrBot/pull/8462 の @xxynet による pip-install エラー表示にトーストを使用する
  • 修正(ltm): https://github.com/AstrBotDevs/AstrBot/pull/8536 で @RC-CHN によってウェイク コマンドがグループ チャット コンテキストとして記録されないようにする
  • 修正: https://github.com/AstrBotDevs/AstrBot/pull/8523 の @tjc6666666666666 による aiocqhttp アダプターを使用すると音声を解決できません
  • chore(deps): https://github.com/AstrBotDevs/AstrBot/pull/8533 の @dependabot[bot] により、github-actions グループ内の docker/setup-qemu-action を 4.0.0 から 4.1.0 にバンプします
  • https://github.com/AstrBotDevs/AstrBot/pull/8529 に @tjc6666666666666 による音声ファイルの存在チェックを追加
  • perf(stt-whisper): https://github.com/AstrBotDevs/AstrBot/pull/8528 の @tjc6666666666666 による OpenAI トランスクリプション API を呼び出した後、オーディオ ファイル ハンドルを閉じる
  • fix(openai-embedding): https://github.com/AstrBotDevs/AstrBot/pull/8508 の @Allenyou1126 による SiliconFlow プロバイダーの非 Qwen 埋め込みモデルの無効なパラメーターを一時的に修正
  • fix(gemini-embedding): https://github.com/AstrBotDevs/AstrBot/pull/8537 の @Rat0323 による gemini-embedding-2 での折りたたみを避けるために、コンテンツ内のバッチ埋め込みテキストをラップします。
  • fix(compress): コンテキスト圧縮を改善し、コンテキスト圧縮の kv キャッシュ レートを改善し、https://github.com/AstrBotDevs/AstrBot/pull/8530 の @Foolllll-J による圧縮モデル モダリティを処理します。
  • 修正 (ダッシュボード): https://github.com/AstrBotDevs/AstrBot/pull/8554 の @lxfight によるランチャーの下で実行する際のフレーム セキュリティ ヘッダーを緩和
  • 功績: https://github.com/AstrBotDevs/AstrBot/pull/8559 の @Soulter による将来のタスク UI
  • fix(wecomai_event): https://github.com/AstrBotDevs/AstrBot/pull/8563の@NayukiChibaによるメッセージチェーンから平文を抽出する際の空白処理を修正
  • https://github.com/AstrBotDevs/AstrBot/pull/8527 の @tjc6666666666666 によるレコード コンポーネントの返信チェーン処理を強化
  • 修正: https://github.com/AstrBotDevs/AstrBot/pull/8574 の @zouyonghe による SQLite ロックのプロバイダー統計を再試行
  • 特技: umo に名前を付けるコマンド /name を導入し、https://github.com/AstrBotDevs/AstrBot/pull/8575 の @Soulter によって ui に表示します。
  • 功績: https://github.com/AstrBotDevs/AstrBot/pull/8390 の @lxfight によるダッシュボードのテーマをプラグイン ページに同期
  • 機能 (ダッシュボード): https://github.com/AstrBotDevs/AstrBot/pull/8569 の @lxfight による MDI アイコンのサポートを使用して、プラグイン WebUI エントリをサイドバーに追加します。
  • 修正: https://github.com/AstrBotDevs/AstrBot/pull/8610 の @Soulter による DingTalk ストリームの再接続を維持する
