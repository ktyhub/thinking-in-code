openhuman v0.64.7

#オープンヒューマンv0.64.7

インテリジェンスのアップグレード 🎉

v0.64.4 から v0.64.7 では、12 のコミットで 12 の PR が提供され、メモリ、音声、エージェント、信頼性、開発者基盤全体がアップグレードされます。このリリースに貢献してくださった皆様に感謝します。 ✨

ハイライト 🚀

✅ タスク、チャット、エージェントのワークフロー

タスクボード、永続的な実行状態、より安全な委任、より明確なモデル/スレッド制御により、タスク、チャット、およびエージェントのワークフローの操作と検査が容易になります。 (#6672、#6683、#6702、#6760) — @M3gA-Mind と @senamakel に感謝します。

🧩 統合、UI、開発者の基盤

統合、UI の洗練、および開発者の基盤も前進しており、これには、より明確な接続アカウントのサーフェス、会議エージェントの配線、プレゼンテーション/アーティファクトの改善、よりクリーンなドキュメント/コードの編成などが含まれます。 (#6668、#6678、#6693、#6699、#6700、#6701、#6704、#6759) — @senamakel、@M3gA-Mind、@siddarthkay に感謝します。

貢献者のクレジット 🙌
