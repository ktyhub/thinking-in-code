openhuman v0.58.7

#オープンヒューマンv0.58.7

ミーティングとコネクションのパワーアップ

v0.58.0 ～ v0.58.7 には、より鮮明な会議エクスペリエンス、より高速で信頼性の高い接続 (スキル/MCP)、およびエージェント、メモリ、プロバイダーにわたる安定性の大きなアップグレードが詰め込まれています。 🚀

ハイライト

ミーティング、エンドツーエンドの磨きをかける 🎥

Meetings は、プラットフォーム セレクター、クリーンな履歴のマスター/詳細レイアウト、よりスマートなデフォルトを備えた完全な再設計が行われ、さらに、セッションがより「生きている」と感じられ、エラーが発生しにくくなる一連の高品質な修正が加えられました。 UI フィードバックの改善 (「退出中…」状態を含む)、会議終了時の最近の通話の自動更新、バックエンド キャパシティ メッセージングの処理の改善が見られます。 ウェイク フレーズがアクティブな会議ボットに正しく転送されるようになり、会議の表示名が接続されているアカウントから自動入力できるようになり、「質問」フローの新しい手動要約 RPC により自動要約ポリシーが適用されるようになりました。
(#4308、#4348、#4347、#4221、#4231、#4297、#4353) — @graycyrus と @YOMXXX に感謝します。

つながり: MCP と速いと感じる (そして速く続ける) スキル 🔌

MCP は大きな進歩を遂げました。MCP サーバー ページは、厳選されたカタログ、ライフサイクルの改善、E2E の範囲を備えて「完成」しました。内部では、MCP ツールの呼び出しは応答フレームが到着するとすぐに戻り (大幅な遅延が発生します)、stdio サーバーはユーザーの実際のシェル PATH (こんにちは npx/uvx) で生成され、スキーマ移行は同時実行安全になりました。 認証とインストールの UX も全体的に改善されました。MCP 401 の説明がより明確になり (メッセージングがより安全になりました)、カードの「インストール済み / インストール中」の状態が改善され、アクティベーションの永続化、レジストリのキャッシュ + ページネーション、レイテンシの計測などのスキルの改善が行われました。
(#4300、#4220、#4295、#4219、#4321、#4224、#4288、 #4120、#4182、#4188、#4238) — @YellowSnnowmann、@M3gA-Mind、@oxoxDev、@YOMXXX に感謝します。

チャット エクスペリエンス: 添付ファイル、ビジュアル、スムーズな長回し 💬

Chat には、ドラッグ アンド ドロップと貼り付けをサポートする、画像、ビデオ、ドキュメント用の最上級の添付ボタンが追加されました。コード ブロックでは、マークダウン サーフェイス全体で構文の強調表示が可能になり、コンポーザー/フッター レイアウトが動的にスペースを予約するようになったので、キューに入れられたフォローアップ (およびその他の拡張フッター コンテンツ) が会話と重なりなくなりました。 信頼性の面では、ハートビートの進行状況信号のおかげで、長い推論ターンは古い 2 分間の沈黙タイムアウトを過ぎても存続します。
(#4292、#4335、#4334、#4282) — @oxoxDev と @graycyrus ありがとう！

エージェントとツールのランタイム: ループが減り、停止が明確になります 🧠

エージェント オーケストレーションは、脱線しにくくなりました。同一のツール呼び出しループが検出されて停止され、スタックしたサブエージェントが明示的に 不完全 として返される可能性があり、セッション ツール呼び出しは永久にハングするのではなくタイムアウトを考慮するようになりました。 MCP セットアップ エージェントは、ユーザーの説明のために一時停止したときに再生成ループに閉じ込められることがなくなり、目標完了の指示が強化されて自動完了の動作が改善されました。 組み込みのリサーチャー エージェントも、境界のあるツール サーフェスと制限された回転ごとの出力によって強化されました。 (#4230、#4262、#4303、#4310、#4313、#4314) — ありがとうございます @sanil-23、@YOMXXX、@oxoxDev、 @salarkhannn、そして@senamakel!

メモリとインテリジェンス: より優れた継続性とより安全なクロスホスト動作 🗂️

メモリの耐久性が大幅にアップグレードされました。概要のみの Wiki 履歴が git 経由で追跡されるようになり、大量のヒットを複製する前にランク付けすることでスレッド間検索が高速になり、Vault ガイダンスが開いている場合でも Trees UI のフィードバックが明確になり、ツールバーのレイアウトが安定しました。 マルチデバイス設定の場合、クロスホスト ボールト パスが特定のホスト OS に属するものとして明示的に表示されるようになりました。そのため、フロントエンドは Linux 上で macOS パスを開こうとしません (またはその逆)。 Brain メモリ グラフは再ログイン後に確実にリロードされ、Intelligence ページは Brain カード内で正しくスクロールします。
(#4168、#4311、#4331、#4342、#4330、#4223、#4332) — @senamakel さん、ありがとうございます。 @mysma-9403、@graycyrus、@oxoxDev、@M3gA-Mind!

プロバイダー、推論、可観測性の強化 🧰

このリリースには、ノイズの多い「エラー」を正しく分類された予想される状態に変換し、再試行の嵐を減らし、プロバイダーとローカル環境全体での回復力を向上させる広範な修正セットが含まれています。ハイライトには、より安全なモデル カタログ解析、より優れたエンベディング検証 (自動検出されたディメンションおよび Gemini モデル ID 正規化を含む)、クォータ/制限状態の処理の改善、およびより堅牢な OpenAI 互換解析が含まれます。 バックエンド ルーティングも安全です。バックエンド API 呼び出しが誤って BYO クラウド推論ホストにルーティングされることはありません。チャネルについては、ディープリンクのラウンドトリップが失敗した場合に、OAuth の「接続中」状態が正常に回復されるようになりました。また、cron ジョブの場合、API キーが欠落していると早期に停止します (エラーがユーザーにわかりやすく表示されます)。
(#4157、#4160、#4184、#4186、#4185、#4207、#4209、 #4210、#4161、#4189、#4187、#4208、#4286、#4306、 #4166、#4169) — @oxoxDev と @M3gA-Mind に感謝します。

Tiny Place: ID + 取引の修正、よりスムーズな Linux レンダリング 🪙

Tiny Place では、正しい価格設定、ハンドル登録に対する USDC SPL ミントの承認、報奨金作成時の RPC タイムアウトの延長、アプリ内確認モーダルによる破壊的なアクションに対するより洗練された UX など、強力な修正が行われました。取引もより使いやすくなり、残高は正しい決済 RPC から読み取られ、購入試行後に Buy が適切に再度有効になり、ユーザーは複数の ID 間でプライマリ ハンドルを切り替えることができます。 Linux では、ワールド レンダラーは SwiftShader 経由で動作する WebGL コンテキストを取得できるようになりました (古い「GPU を無効にする」鈍器に戻すことなく)。
(#4215、#4211、#4212、#4214、#4218、#4217、#4216、 #4213) — @M3gA-Mind ありがとうございます!

音声、人間、デバイス、デスクトップの信頼性 🎙️

macOS 上の音声はより堅牢です。インプロセス Whisper STT は外部バイナリに依存せずに動作し、インストール/テスト UI はより予測どおりに動作します。 Human UI にも実用的な修正が加えられました。マイク デバイス セレクターが画面外に表示されるのではなく、ビューポート内に留まります。 デスクトップの信頼性の向上には、厳しい環境向けの CEF GPU 無効起動オーバーライド、.deb パッケージ (適切なランタイム deps を含む) を優先する Debian インストール、正しい Socket.IO ACK フローを使用するデバイス ペアリングが含まれます。
(#3915、#4343、#4309、#4263、#4355) — @YellowSnnowmann、@graycyrus、@Sam、@YOMXXX に感謝します。

新しいクリエイティブ ツール、マスコット、モデル ルーティング ✨

画像/ビデオ エージェントと、出力を安定したローカル パスにダウンロードする GMI メディア ツールを備えた、まったく新しいメディア生成ドメインがあります。マスコットは GitHub をサポートするマニフェストからロードできるようになり、時間の経過とともにヒューマン エクスペリエンスを拡張および進化させることが容易になります。ルーティング側では、新しい burst-v1 層が登録され、SuperContext スカウトやその他のツール駆動エージェントなど、適切なローコンテキスト ワーカーに使用されます。 また、処理されたチャネル イベントのプロバイダー/モデルのメタデータを記録することにより、チャネル応答の監査可能性も向上しました。
(#4244、#4312、#4260、#4315、#3682) — @senamakel さん、@senamakel-droid さん、@ron-liu さん、ありがとうございます。

スタック全体にわたる小規模な (しかし強力な) 修正 🛠️

一連の鋭い修正が、トークン アカウンティング、学習、セキュリティ、人材、アーティファクト、CI 人間工学にわたって適用されました。 TokenJuice は、UTF-8 文字境界パニックを回避し、圧縮の節約をターンごとのモデルに正しく帰属させます。サブエージェント トークンにより、使用量ゲージが 100% を超えなくなりました。学習の安定性は正しいファセット半減期を使用します。コールド スタート時にチャット ファイルがアーティファクト台帳からハイドレートされます。また、People ストアはコア ブートで正しくシードされます。 セキュリティ強化により、いくつかの untrusted 入力シンクも強化され、llvm-cov スタックのオーバーフローを回避するために RUST_MIN_STACK を上げることで CI カバレッジの実行が安定しました。
(#4170、#4229、#4327、#4328、#4232、#4345、#4158、 #4346) — @mysma-9403、@rainbowpuffpuff、@oxoxDev、@Sam、@obchain、@graycyrus に感謝します。

ドキュメントの更新 📚

ドキュメントは、GitBook/README の大幅な見直しと、用語、範囲、RPC 命名を厳格化するための一連の正確性のフォローアップを受けました。
(#4225、#4243) — @senamakel ありがとうございます!
