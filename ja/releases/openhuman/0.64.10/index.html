openhuman v0.64.10

#オープンヒューマンv0.64.10

スピード、構造、信頼性のアップグレード

このリリースでは、コア エクスペリエンスがエンドツーエンドで強化され、最初のターンの高速化、より明確なチャット フィードバック、より強力な統合、さらに迅速なイテレーションを可能にする大きな内部モジュール化の推進が行われています。 🎉

ハイライト

パフォーマンスと応答性 ⚡

エージェント ループは著しくスムーズになりました。最初のターン プロンプトは大幅に小さくなり、プロンプト キャッシュはウォームな状態を維持し (最初のトークンまでの時間が短縮され)、管理された推論パスにより、コールごとの不要な client セットアップが回避されます。ツール出力の圧縮もデフォルトで再び有効になり、保存された結果に対する新しい「REPL スタイル」ツールを使用して、大きなツール出力による回転の停止を防ぎます。

(#6787、#6788、#6823) — @senamakel ありがとうございます!

チャット UI と承認の洗練 💬

チャットには一連の UX の改善が加えられました。長いソース リストがきれいに折りたたまれるようになり (ファビコンが改善され)、Web 検索のレンダリングで厄介なギャップが残らなくなり、サイレンス ウォッチドッグが実行中のターンを強制終了する代わりに警告を発するようになり、コアの実際のターン状態と同期を保ちます。承認もよりスムーズになりました。回答された承認が背景のデッキに「ゴースト」されることはなく、拒否にはモデルが実際に読み取ることができる明確な拒否理由が含まれるようになりました。

(#6802、#6827、#6800、#6810) — @senamakel と @M3gA-Mind に感謝します。

記憶および知識エンジン 🧠

メモリが明示的に選択可能になりました。ローカル (TinyCortex) または TinyHumans 経由の CortexDB、およびその他のサポートされているプロバイダーを含む、アクティブなエンジンを 1 つだけ選択できます。エンジンを切り替えると、既存のメモリをコピーすることもできるため、実験や移行の負担が大幅に軽減されます。

(#6777) — @senamakel ありがとうございます!

MCP と Composio の統合 🔌

MCP ツールは、より人間工学的で堅牢になりました。サーバー ツールは、永続的なキャッシュから安定した個別にアドレス指定可能なツールとして公開され、文字列エンコードされた JSON 引数は正規化されるため、呼び出しが予期せず失敗することはありません。ツール リストからの拒否により、モデルが何が「できる」のかが通知されるようになりました (そして、RPC のみのメソッドを指すことを避けられます)。 Composio 側では、エンベッダーが各エージェントに独自の資格情報を与えることができ、バックエンドでルーティングされた Composio 呼び出しは、インプロセス client ではなく tinyconnectors モジュールを経由して流れるようになりました。

(#6767、#6769、#6818、#6689、#6796) — @senamakel さん、@M3gA-Mind さん、@oxoxDev さん、ありがとうございます。

セキュリティ、安全性、ポリシーの強化 🛡️

セキュリティ保護はより鮮明になり、ノイズが少なくなります。プロンプト インジェクション ガードはリコールされたトランスクリプトに対して誤検知を起こす可能性が低くなり、ブラウザの IP ブロックでは完全な非グローバル範囲定義が使用されるようになりました (回帰テストを使用)。 Windows 上のスケジュールされたジョブにおけるシェル実行の信頼性も向上し、一貫性を保つためにシェル スキャン ロジックがアップストリームに統合されます。

(#6776、#6709、#6764、#6790) — @senamakel、@Avi-Bendetsky、@sanil-23 に感謝します。

アーキテクチャとベンダーのモジュール化推進 🧱

このシリーズの主なテーマは、ホストに依存しないロジックを openhuman-core から抽出して適切な vendor/tiny* モジュールに組み込むことです。コアは製品ポリシー、アダプター、契約に重点を置いています。これには、RPC/サーバーの責任の分割、チャネル/スキル/web3/ファイルシステム/フック/セッション/ランタイム/ツールヘルパーの所有クレートへの移動、マージされたアップストリームメインへのベンダーピンの更新が含まれます。その過程で、古いサブシステム参照がクリーンアップされ、重複とドリフトを減らすためにツール呼び出しタイプが tinytools から直接採用されるようになりました。

(#6703、#6779、#6780、#6782、#6783、#6784、#6785、 #6786、#6789、#6791、#6793、#6794、#6795、#6797、 #6804、#6805、#6806、#6807、#6809、#6773) — @senamakel ありがとう！

信頼性、アップデート、CI/e2e の安定性 ✅

このセットは「メイン グリーンの維持」にも重点を置いています。E2E Web の実行では、ポートの衝突を回避し、取得されたポートを拒否するようになりました。コア アップデーターは、正しいバージョン管理されたアーカイブを再度解決して実際のバイナリをステージングし、管理されたバックエンドの停止により、明示的なターミナル結果を伴う制限付き指数バックオフがトリガーされるようになりました。モジュールゲート Rust テストの実行、レイアウト ゲート動作の改善、ベンダー/ロックファイル ピンの位置合わせの維持 (tinymcp および tinymemory ピンの処理を含む) など、CI カバレッジも向上します。

(#6719、#6770、#6569、#6605、#6817、#6771、#6772、 #6798) — @obchain、@lorenzozanee、@M3gA-Mind、@sanil-23、@senamakel に感謝します。

デスクトップ、音声、プラットフォームの修正 🖥️

TinyComputer は、保存されたフロー、タスク レポート、およびライブ バリ予約 E2E を利用して、現実世界のデバッグと反復をはるかに容易にします。重要なプラットフォームの修正もあります。macOS デスクトップ ビルドはアップストリーム アクセシビリティ API の変更後に復元され、ベンダー バンプには tinyagents の unsafe_code 制約に対する Windows ビルドの修正が含まれています。

(#6761、#6822、#6839) — @senamakel と @M3gA-Mind に感謝します。

Web3 および x402 の改善 💱

Web3 機能は tinywallet への移行を続けており、重要な x402、料金、プローブ、チェーン ステータスの修正を取得するための後続のピンニングに加えて、動作を正しく追跡可能に保つためのホスト側のサポートとテストが行われます。

(#6792) — @senamakel ありがとうございます!

使用状況と会計の正確さ 📊

「使用状況」ページには、実際に記録された支出が反映されるようになりました。ワークスペースの追跡は認証遷移全体で修正され、重複した記録が回避され (従来の重複は無視され)、<$0.01 やマイナスゼロのレンダリングなどの小さな UI の詳細が修正されました。 「トークンとコスト」タブの名前も、実際に表示される内容と一致するように、すべてのロケールで「トークンの節約」に変更されました。

(#6720) — @graycyrus ありがとうございます!

エンベッダーとエージェントのコントロール ノブ 🎛️

エンベッダーは、永続エージェント構成を変更する必要なく、ターンごとのツール呼び出しバジェット リミッターを使用して実行をより厳密に制御できるようになりました。インラインスキル/遅延ツールの動作後のクリーンアップもあります。痕跡スポーン引数が削除され、それに応じて e2e テストが修正されます。

(#6350、#6762) — @theamazinghenk と @senamakel に感謝します。

設定とプロバイダー カタログの変更 🔁

組み込みの安価な推論プロバイダーのエントリが追加され、その後元に戻され、設定とドキュメントが以前のルーティング動作に戻りました。

(#6620、#6778) — @aiapienthusiast と @senamakel に感謝します。

ドキュメントと開発者のワークフロー ヘルパー 🧰

内部コントリビューター ツールは、コードをベンダー サブモジュールに移行するための新しい追跡された Claude スキル ガイドによって改善され、tinyskills は非 SKILL.md Markdown BLOB のsourceUrl 解決動作を修正するために強化されています。

(#6775、#6819) — @senamakel と @M3gA-Mind に感謝します。

ハウスキーピングを解放する 🚀

この範囲には、バンドルのカットと出荷に使用されるリリース PR が含まれます。

(#6826) — @M3gA-Mind ありがとうございます!

追加のハイライト 🔗

いくつかのより焦点を絞った貢献により、注目に値する修正と改善を対象としたこのリリースが完成します。 (#6781、#6803) — @senamakel ありがとうございます!
