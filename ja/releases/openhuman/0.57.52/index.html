openhuman v0.57.52

#オープンヒューマンv0.57.52

Agent World とウォレットの安全性のアップグレード

このリリースでは、Agent World の深さが大幅に向上し、アプリ全体のナビゲーションがよりスムーズになり、ウォレットの安全性が大幅に修正され、さらに全体的に生活の質が向上しました。 🎉

ハイライト

Agent World がネイティブになります 🌍

Agent World (tiny.place) は、完全な Rust データ レイヤーおよび移植された React UI と深く統合され、フィード、メッセージ、ジョブ/報奨金、ディレクトリ/アイデンティティなどのコア サーフェス、および支出前確認による devnet 支払いフローのロックが解除されます。その基盤に加えて、Explore は実際のライブ データを取得し、ID 登録はディレクトリに正しく公開され、DM はハンドルを確実に解決し、グループ/報奨金の作成により明確な UX フィードバックが提供されるようになりました。
(#3780、#3839、#3847、#3846、#3840、#3837、#3835) — @graycyrus ありがとう！

よりスマートなエージェントのワークフローとオーケストレーション 🤖

切り離されたバックグラウンド サブエージェントは、親スレッドが閉じられたときに完全にキャンセルされるようになり、削除された会話に対する「ファイア アンド フォーゲット」の実行が防止されます。また、エージェントはターンごとのライブ クロックに基づいているため、時間関連のステートメント (「おはよう」、「今日/明日」) は長いセッションでも正確に保たれます。
(#3742、#3752) — @sanil-23 ありがとうございます!

ウォレットの安全性、可視性、trust 🔐

ウォレットの重要な修正により、ユーザーのウォレットを誤って再生成/上書きするのではなく、リカバリ フレーズ エクスペリエンスで既存のフレーズが表示されるようになりました。明示的な「強制」パスとより明確な UI ステート マシンによって保護されるようになりました。ウォレットへのアクセスも、サイドバーのエントリを目立つようにすることで見つけやすくなり、Agent World ではサイドバーのヘッダーに便利なウォレット アドレス チップが表示されるようになりました。
(#3849、#3836、#3838) — @graycyrus ありがとう！

ナビゲーションとチャットシェルの洗練 🧭

シェルは、アイコンのみのナビゲーション レールのおかげで、折りたたんだときにも使いやすくなり、ツールチップとアクティブな状態を備えた完全なナビゲーションが可能になります。サイドバーのヘッダーもよりクリーンになり (言語ピッカーは [設定] に移動)、チャット/サイドバーのエクスペリエンスは、サイドバーに流れ込むスレッド タイトルの変更やその他のチャット シェルの改良により有意義な再加工を受けています。
(#3802、#3810、#3854) — @graycyrus と @senamakel に感謝します。

報酬 + Discord リンクが実現 🎁

Discord のリンクでは実際に Rewards ページから OAuth が実行され (すぐに戻ってきます)、Rewards エクスペリエンスには切断/再リンクに加えて、実績ごとの明確なロール割り当てステータスが追加されるため、ロールの申請は透過的で実行可能です。
(#3748、#3766) — @YellowSnnowmann ありがとうございます!

ローカリゼーションと UX の正確性を修正 🌐

OpenHuman Link アカウント/通知メッセージングやモデル カウンシル ヒント ピッカー ラベルなど、より多くのユーザー向け文字列が完全にローカライズされ、英語リテラルが i18n をバイパスしていたギャップが解消されました。また、rapid clicks での重複実行を防ぐために、Conscious ループ トリガーが保護されるようになりました。
(#3702、#3704、#3708) — @obchain ありがとうございます!

埋め込み WebView プロバイダーの拡張 🧩

埋め込み Webview アカウント ピッカーは、フロントエンド、Tauri シェル、コア ログイン検出、プロバイダー レシピにわたって、より主流のプロバイダー (Gmail、Outlook、Instagram、X) をサポートするようになりました。
(#3755) — @senamakel ありがとうございます!

健康改善をテストしてリリースする 🧪

E2E カバレッジと Playwright/Vitest セットアップがチャット アズ ホーム シェルに適応され、ナビゲーションの競合が修正され、カバレッジ タイムアウトが安定しました。
(#3754) — @senamakel ありがとうございます!

Agent World UI の調整とサイドバーのクリーンアップ 🧹

Agent World は引き続き合理化されます。求人は Agent World のサイドバーから非表示になり (ディープ リンクのルートにアクセスできるまま)、求人の応募にはエージェント ツールと、より明確な「提案送信」の成功 UX が追加されます。
(#3855、#3848) — @graycyrus ありがとうございます!

Linux パッケージングの信頼性 🐧

AppImage バンドルは、新しいディストリビューション (例: glibc ≧ 2.42 を備えた Fedora) で見られる glibc 不一致クラッシュを防ぐために、CI ホスト システムからバンドルされた ld-linux を一貫して置き換えるようになりました。
(#3645) — @0xhis ありがとうございます!

新しい貢献者

  • バンドルされた ld-linux が常にホスト システムから置き換えられるようにすることで、AppImage glibc の不一致クラッシュを修正してくださった @0xhis に感謝します。 (#3645) ぜひ Discord に参加して、独占的な役割と貢献者報酬を手に入れてください!
