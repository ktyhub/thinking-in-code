openhuman v0.63.0

#オープンヒューマンv0.63.0

信頼性と制御のアップグレード

このリリースには、より堅牢なワークフロー、よりスムーズなチャットとエージェント ワールドのエクスペリエンス、そしてすべてを高速かつ信頼性を維持するための大量の内部強化が詰め込まれています。 🎉

ハイライト

できるワークフロー trust 🧩

ワークフローのコパイロットとキャンバスは大きな信頼性を獲得しました。プロポーザルは一貫してレンダリングされ (大きなグラフであっても)、すべてのコパイロットのターンは実際の最終結果で終了するようになり (サイレント トレイルオフはなくなりました)、承認は自動的に保存されるようになり、実行 UI は正確でライブ更新され続けます。安全性と正確性も、更新時のライブアーミングの修正、回路遮断の改善、承認状態の可視化、Composio ツール呼び出しの階層/承認の強化の強化によって改善されました。 (#4881、#4886、#4887、#4888、#4889、#4890、#4891、 #4893、#4904、#4911、#4932、#4933、#4941、#4942、 #4943、#4945、#4955、#4956、#4999、#5000、#5007、 #5011、#5012、#5013) — @graycyrus と @senamakel に感謝します。

よりきびきびと制御しやすくなったチャット 💬

Chat は、[停止] ボタンに加えて、中断して再編集するための ESC 機能と、新しいストリーミングやツールのタイムラインを消去する「ハイドレート」スナップショットに対する強力な保護により、UX に大きなメリットをもたらしました。オーケストレーションもより透明になりました。非同期サブエージェントの失敗と「ユーザー待ち」の結果がチャットに正しく表示されるようになり、委任はデフォルトで非同期となり、耐久性のある再開可能なセッションと永続的なワークフロー提案が提供されるようになりました。 (#4898、#4903、#4908、#5074) — @M3gA-Mind、@graycyrus、@senamakel に感謝します。

メモリとトランスクリプトのアップグレード 🧠

メモリの取り込みとリコールがより鮮明かつ安全になりました。OpenHuman は Codex と Claude のコーディング セッションを取り込むことができ、Composio Sync は秘密のようなタイトルからキーを更新/挿入しなくなり、リコールは実際の事実をかき消す同じセッションの「エコー」ドキュメントのプルを回避します。それに加えて、トランスクリプトはより堅牢になりました。コールドブート履歴書は完全に忠実なコンテキストと思考を復元し、トランスクリプト システムは、真実のソースとして生のセッション ログを使用する追加専用の派生ビューに移行しています。 (#4863、#4953、#4991、#5077、#5086) — @senamakel さん、@M3gA-Mind さん、@graycyrus さん、ありがとうございます！

エージェント ワールド (小さな場所) は生き生きとしています 🌍

Tiny Place はよりインタラクティブで完全になりました。DM とフィードはリアルタイムで更新され、台帳とフィードは最初の 50 アイテムを超えてページ分割され、ディレクトリ エントリでは最終的に豊富なプロフィール ビューが開きます。自分のプロフィール (名前/プロフィール/アバター) の編集と、任意のハンドルのパブリック ビューアー ルートによってプロフィールもレベルアップされました。 (#4951、#4952、#4988、#4989、#4990、#4994、#4996、 #4997) — @M3gA-Mind ありがとうございます!

パフォーマンス、洗練、そして「うまくいく」修正 ⚡

アクセシビリティや UI の改良から起動時や実行時のパフォーマンスに至るまで、このリリースではアプリ全体の摩擦が軽減されています。ダーク テーマのコントラストが改善され、アプリが表示されていないときにメッシュ グラデーション レンダリングが一時停止され、ブート ポーリングが統合され、より静かになりました。初回実行セットアップのオーバーレイは実際にプロビジョニングする場合にのみ表示されるようになり、チャネル設定ガイダンスがアプリ内で修正され、価格設定/チェックアウトのリダイレクトが適切に動作し、リセットされた「アプリ データのクリア」設定がサインイン ユーザーを正しくターゲットにするようになりました。 (#4897、#4902、#4905、#4910、#4939、#4954、#5035、 #5036、#5066、#5075、#5085) — @M3gA-Mind、@YellowSnnowmann、@senamakel に感謝します。

ビルドの柔軟性、CI 強化、新しい表面 🛠️

コアははるかにモジュール化されており、コンパイル時の機能ゲート (メディア、Web3、フロー、スキル、MCP、ミート) と新しい機能ゲート型ターミナル チャット UI (openhuman tui) を介してスリム ビルドでの出荷が容易になりました。デスクトップの出荷と CI もより厳密かつ安全になりました。音声とトークンジュース ツリーシッターがデスクトップ ビルドに正しく転送され、CI が機能転送ドリフトをゲートし、macOS clippy ブロッカーが解決され、「ゲートオフ」スモーク レーンが修復されてテストが実行され、学習スタートアップのサブスクライバーがチャネルから切り離され、より安定したテストでカバーされます。 Web チャット コンジットを channels/ から移動するコア リファクタリングもあります。 (#4840、#4855、#4912、#4913、#4914、#4915、#4916、 #4917、#4934、#5004、#5020、#5023、#5025、#5070、 #5082、#5084) — @oxoxDev、@CodeGhost21、@senamakel、@M3gA-Mind に感謝します。

統合、推論、ツールの改善 🔌

統合とローカル AI の信頼性が向上しました。OpenAI 互換のローカル ランタイムが /v1/models を正しくプローブするようになり、カスタム埋め込みエンドポイント検証エラーがより明確で対処可能になり、ストリーミングの再試行が Retry-After を尊重するようになりました。 Composio ツールの実行は、完全なコントラクトに基づいてゲートされたアクションごとのツール (引数の推測を減らす) により、よりスマートかつ安全になり、同期できないツールキットはメモリ ソースとして自動登録されなくなりました。本物の .docx を出力する新しい generate_document ツールに加えて、ダウンストリーム ホスティング/課金の最終ターンの使用量合計に対するパブリック アクセサーもあります。 (#4899、#4909、#4940、#4993、#4995、#5064、#5067) — ありがとうございます @M3gA-Mindそして@senamakel!

アカウント、共有、ナビゲーションの楽しみ 🔗

X と LinkedIn の「エージェントが行ったことを見てください」共有カードをワンタップで生成できるようになりました。X/Twitter の「Continue with Google」ポップアップはアプリ内に留まり、報酬はクラウドゲートのサイドバーエントリ経由で最終的に見つけられるようになり、Codex 認証ボタンが適切にローカライズされました。さらに、UI の一貫性を保つために、プロアクティブな「エージェント タスクの洞察」フィクスチャとライフサイクル リセットが強化されました。 (#4892、#4944、#4949、#4992、#5010、#5015、#5065) — ありがとうございます@YellowSnnowmann、@graycyrus、@M3gA-Mind!

安全性と迅速な規律の変更 🧯

デスクトップ オートメーションの安全制御にはチャーンが見られました。緊急停止が導入されましたが、その後、製品の方向性に基づいて完全に削除されました。一方、ローカル LLM プロバイダーのエージェントの動作は、プロバイダー対応のコンテキスト/委任ガードレール、より強力な構造化出力の強制、小規模モデル向けのより回復力の高いツール呼び出し解析によって改善され、AGENTS.md 命令がシステム プロンプトに読み込まれるようになりました。これにより、シンボリックリンク/パスのエスケープを防止し、AGENTS.md が存在する場合はデバッグ ログを編集するためのフォローアップのセキュリティ強化が行われます。 (#4600、#4900、#4935、#4938、#5073、#5087、#5096) — @CodeGhost21、ありがとうございます。 @M3gA-Mind、@sanil-23、@yh928、@senamakel!
