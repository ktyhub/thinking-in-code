openhuman v0.63.7

パッチ 公開日2026年8月7日 出典tinyhumansai/openhuman 英語原文

#オープンヒューマンv0.63.7

フロー、メモリ、音声のパワーアップ

このリリースには、ワークフロー構築の徹底的なアップグレード、よりスリムなカーネル化コア、メモリ、推論、音声にわたる大きな信頼性の向上が詰め込まれています。さらに、すべてがよりきびきびと頑丈に感じられるようにする一連の UI の洗練が含まれています。 🎉

ハイライト

フローとワークフローの副操縦士、レベルアップしました 🧩

ワークフロー オーサリングとコパイロットは、大幅な使いやすさと信頼性を実現しました。明確なステップ ラベル、「保存して有効化」パス、承認後の安全なライブ テスト実行、停止ボタン、ランレール動作の向上、コンパイル/ランタイムの正確性の向上、キャンバス全体の視覚的な更新です。また、ストアの動作 (破損した行の処理、トランザクションの更新/挿入) がより堅牢になり、ローカリゼーションの範囲が向上し、実行/承認の境界が厳格化され、ユーザーが承認したものがそのまま実行されます。

(#5088、#5089、#5090、#5097、#5099、#5111、#5112、#5114、 #5115、#5120、#5128、#5135、#5148、#5150、#5153、 #5176、#5205、#5212、#5223、#5227、#5228、#5248、 #5264、#5265、#5285、#5286、#5287、#5289、#5290、 #5292、#5293、#5294、#5296、#5297、#5302、#5303、 #5304、#5366) — @graycyrus と @senamakel に感謝します。

拡張可能なメモリとエージェントのプロファイル 🧠

メモリは大きな前進を遂げました。TinyCortex の統合とツール メモリのカットオーバーは継続し、識別子はより確実に正規化され、新しい警告は、埋め込み予算が使い果たされたときの「サイレント」メモリ停止を防ぐのに役立ちます。また、フローには、より意図的なメモリ動作 (フロー名前空間 + ダイジェスト、専用メモリ ノードのサポート、読み取り専用メモリ ヘルパー) が追加され、プロファイルには、プロファイルごとのワークスペース、メモリ、スキル、および cron 属性をきちんと整理する「hermes スタイル」ホームが追加されました。

(#5043、#5101、#5118、#5140、#5175、#5176、#5205、 #5220、#5227、#5237、#5244、#5246、#5275、#5280、 #5282、#5368、#5398、#5402、#5427) — @senamakel、@graycyrus、@YellowSnnowmann、@CodeGhost21、@mysma-9403 に感謝します。

音声、マスコット、リアルタイム体験 🎙️

音声キャプチャと TTS の信頼性が向上し (サンプル形式の処理の改善、Piper バイナリの修正、プロバイダーのクリーンな動作など)、リアルタイム音声モードがデフォルトで表示されるようになりました。また、大きな新しい統合も行われています。それは、コア RPC、リアルタイム セッション、およびローカル リレー ハンドラーを備えた Celebrities Voice Agents であり、センテンスごとのストリーミングなどの UX の改善と組み合わせて、知覚される遅延を削減します。

(#4537、#5216、#5367、#5404、#5407、#5428、#5441) — ありがとうございます@mysma-9403 と @YellowSnnowmann!

チャット、会話、日々の UI の洗練 💬

チャットと会話の UX はよりスムーズかつ堅牢になりました。長い URL が正しくラップされるようになり、レンダリング ループが修正され、テンプレートの拒否がより明確になり、スレッドのゴール フッターが予期せず自動スクロールすることがなくなりました。 「ヒューマン」エクスペリエンスも進化しています。マスコットがチャット内にライブドッキングできるようになり、アップロードされたカスタム アバターをサポートし、口パク関連の UI ロックアップが回避されます。さらに、スレッドに 3 つの単語で名前を付けることができます。

(#5030、#5210、#5274、#5309、#5369、#5412、#5419、 #5420) — @jgentes、@graycyrus、@YellowSnnowmann ありがとうございます!

推論、埋め込み、検索、コストの正確性 ⚡

推論と埋め込みの動作はより予測可能かつ安全になります。モデル ルーティングの改善 (ビジョン対応モデルを含む)、より対処可能なエラー (および編集されたシークレット)、ローカル モデルの信頼性の向上、BYOK キーとバジェットのより明確な処理が可能になります。 Exa サポート (マネージド + BYOK) によって検索が拡張され、アトリビューションが改善され、使用状況が解決されたプロバイダーに正しくリンクされるようになりました。

(#4885、#5103、#5117、#5206、#5207、#5215、#5218、 #5219、#5222、#5253、#5254、#5262、#5363、#5371) — ありがとうございます @M3gA-Mind @YellowSnnowmann、そして@samrusani!

コアカーネライゼーション、機能ゲート、パフォーマンス 🧱

コアは、大幅な依存関係のトリミング、カーネル化作業、DomainGroup の再調整、および明示的なコンパイル時機能の背後で制御されるその他の機能など、よりスリムかつモジュール化され続けています。バッチ処理、共有構成アーク、委任のチェックポイント/再開、エージェントとスキル実行全体にわたるランタイム プロセス プーリングによって、パフォーマンスとオーケストレーションも向上しました。

(#5029、#5040、#5052、#5061、#5062、#5068、#5078、 #5079、#5129、#5178、#5202、#5233、#5240、#5314、 #5328、#5332、#5364、#5365、#5396、#5405) — @senamakel さん、@YellowSnnowmann さん、ありがとうございます。 @oxoxDev、そして@mysma-9403!

エージェント、承認、オーケストレーションの安全性 🤖

エージェントと承認の鋭利なエッジが削除されました。クリーンアップ中に置換ルートが保持され、パスのスクラブがより安全になり、オプトインの「すべて自動承認」設定が利用可能になり、カスタム レジストリ エージェントが実際のツールで実行されるようになりました。オーケストレーションの信頼性は、cron の正確性、無効なホスト ステアリング ポーリングの削除、デリゲーション/エージェントの動作をサイレントに結果をドロップするのではなく大声で失敗させるなど、いくつかの場所でも向上しています。

(#4786、#4998、#5039、#5042、#5094、#5121、#5123、 #5211、#5306) — @graycyrus、@samrusani、@mysma-9403、@oxoxDev、@sanil-23、@M3gA-Mind に感謝します。

デスクトップのパッケージ化、構成/認証の回復力、ビルドの健全性 🛠️

起動フローとサインイン フローの回復力が向上しています。読み取り不能な構成は修復して説明でき、一時的なストア読み取りによってプロファイルはリセットされず、セッションの有効期限は分類可能なままです。デスクトップ パッケージ化には対象を絞った修正 (AppImage パス、ユーザー緩和、D‑Bus セッション バス) が加えられ、混合 DPI マルチモニター セットアップにおける Tauri ウィンドウの動作が改善され、CI/テスト カバレッジ/安定性が意味のあるアップグレードを受けました。

(#4716、#4772、#5081、#5083、#5171、#5181、#5189、 #5190、#5221、#5241、#5252、#5255、#5267、#5276、 #5277、#5311、#5336、#5337、#5340、#5341) — ありがとうございます @YellowSnnowmann、@senamakel、 @M3gA-Mind、@samrusani、@myi1、そして @senamakel!

メデュラ、SDK ルーティング、およびバックエンド側配管 🌐

OpenHuman は、ホストされたオーケストレーターに機能する新しいファサード/RPC サーフェスとワークフロー プレーンを備えた、Medulla コアとしての位置付けが高まっています。バックエンド client はベンダーの tinyhumans SDK 経由でルーティングされるようになり、管理されたバックエンド トラフィックはカットオーバーされ、いくつかの Medulla/MCP カタログと URL 解決の修正により、エンドツーエンドの一貫性が維持されます。

(#5105、#5229、#5232、#5233、#5234、#5238、#5245、 #5260、#5266、#5361) — @senamakel と @graycyrus ありがとう！

Tiny Place とエージェントワールドの改善 🗺️

Tiny Place とエージェント ワールドの機能は、ディレクトリ検索 + ページネーション、台帳フィルター (コピー可能な tx-id 付き)、転送配線の処理の改善、リレー シームを備えたローカル SIM としての Tiny Place World のより明確なフレーミング/ドキュメント化によって成熟し続けています。一部の ID/フィード メディアの動作は、必要に応じて明示的に Web 専用になりました。

(#4998、#5192、#5193、#5271、#5278、#5295) — @CodeGhost21 と @M3gA-Mind に感謝します。

開発ツール、ベンチ ハーネス、ドキュメント 📚

新しいベンチマークとプロファイリング環境、ログファーストのタブ付き TUI、および広範な CI 検証により、開発者のエクスペリエンスが向上しました。ドキュメントにも有意義な更新が加えられました。CITATION メタデータ、インストール修正 (macOS Homebrew Cask)、Windows デスクトップ セットアップのガイダンスの提供、Exa の検索ドキュメントの更新などです。

(#5060、#5107、#5131、#5142、#5145、#5152、#5177、 #5215) — @YellowSnnowmann、@senamakel、@mwakedenis、@NgoQuocViet2001、@M3gA-Mind に感謝します。

UI の基礎、クリーンアップ、生活の質 ✨

ここには、再利用可能な React 基盤、未使用または孤立したモジュールとファイルの削除、コアをスリム化しデスクトップ機能を適切に再配置するための複数のパスなど、多くの思慮深いクリーンアップと UI の基礎作業が行われています。また、削除可能なアプリ内 GitHub スター CTA やより安全なテーマ/グラデーションの分解動作など、小さいながらも楽しい工夫も見られます。 (#5095、#5102、#5110、#5113、#5124、#5125、#5130、 #5141、#5143、#5185、#5186、#5188、#5206、#5273、 #5279、#5310、#5343) — @graycyrus、@senamakel、@sanil-23、@M3gA-Mind、@YellowSnnowmann に感謝します。
