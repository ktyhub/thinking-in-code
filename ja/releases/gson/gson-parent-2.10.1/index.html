gson gson-parent-2.10.1

新しい JsonObject.isEmpty() メソッドという API の小さな変更が 1 つあるため、これは技術的にはパッチ リリースではなくマイナー リリースです。

変更点: ユーザーに見える変更点

  • JsonObject メソッド isEmpty() を https://github.com/google/gson/pull/2233 の @dhoard によって追加しました
  • cyclic 依存関係を持つタイプのアダプターの非スレッドセーフ作成を修正 https://github.com/google/gson/pull/1832 の @Marcono1234 による
  • JsonStreamParser.next() の EOFException 特殊ケーシングを削除 (https://github.com/google/gson/pull/2281 の @Marcono1234 により)
  • 重複するフィールド名の例外メッセージを改善 by @Marcono1234 (https://github.com/google/gson/pull/2251)
  • https://github.com/google/gson/pull/2243 の @MaicolAntali による JsonDeserializer.deserialize() の javadoc を修正
  • _https://github.com/google/gson/pull/2235 の @dependabot による 1.7.0 から 1.7.1 への os-maven-plugin のバンプ
  • 2.13.4.2 から 2.14.0 に jackson-databind をバンプ https://github.com/google/gson/pull/2234 の @dependabot により
  • Maven-release-plugin を 3.0.0-M6 から 3.0.0-M7 にバンプ (https://github.com/google/gson/pull/2232 の @dependabot による)
  • apicmp-maven-plugin を 0.16.0 から 0.17.1 にバンプ https://github.com/google/gson/pull/2238 の @dependabot により
  • 2.14.0 から 2.14.1 に jackson-databind をバンプ https://github.com/google/gson/pull/2241 の @dependabot により
  • _https://github.com/google/gson/pull/2245 の @dependabot による 6.3.1 から 6.4.0 への bnd-maven-plugin のバンプ

サイトのドキュメントとメンテナンスの変更 (これらはすでに表示されていました)

  • トラブルシューティング ガイドを追加 @Marcono1234 による https://github.com/google/gson/pull/2285
  • カスタム ユーザー ガイド ヘッダー アンカーを置換 by @Marcono1234 (https://github.com/google/gson/pull/2289)
  • ユーザー ガイドの変数名を改善 by @Marcono1234 (https://github.com/google/gson/pull/2290)
  • _2.10 を CHANGELOG に変更します。 @Marcono1234 によるマイナー リリースのフォローアップ (https://github.com/google/gson/pull/2229)
  • CHANGELOG で GitHub リリースが将来使用されることについて言及 https://github.com/google/gson/pull/2230 の @Marcono1234 による
  • GitHub ワークフローのセキュリティ強化 @sashashura 著 (https://github.com/google/gson/pull/2274)

その他の変更点

  • PerformanceTest で一貫したプレフィックスを作成 by @CirQ (https://github.com/google/gson/pull/1760)
  • バージョン番号を調整し、SemVer 仕様に準拠するテストを行います。 by @eamonnmcmanus (https://github.com/google/gson/pull/2237)
  • JsonNull.equals() でカバーされた条件を削除 https://github.com/google/gson/pull/2271 の @MaicolAntali により
  • private メソッドから final キーワードを削除 by @MaicolAntali (https://github.com/google/gson/pull/2276)
  • コードのクリーンアップ @MaicolAntali による (https://github.com/google/gson/pull/2282)
  • JsonPrimitive.getAsBoolean() での不要なアンボックス化 (https://github.com/google/gson/pull/2277 の @MaicolAntali による)
  • testParsingDatesFormattedWithSystemLocale() を書き換え、#2199 を修正 @MaicolAntali による https://github.com/google/gson/pull/2287
  • JUnit 3 から JUnit 4 へのポート テスト @MaicolAntali 著 (https://github.com/google/gson/pull/2294)

新しい貢献者 (ありがとう!)

  • @CirQ は https://github.com/google/gson/pull/1760 で最初の貢献をしました
  • @dhoard が https://github.com/google/gson/pull/2233 で最初の投稿を行いました
  • @MaicolAntali が https://github.com/google/gson/pull/2243 で最初の投稿を行いました
  • @sashashura が https://github.com/google/gson/pull/2274 に初めて投稿しました
