gson gson-parent-2.10

リリース 公開日2022年10月25日 出典google/gson 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

gson gson-parent-2.10

最も重要な変更点

  • Java 16 以上での Java レコードのシリアル化と逆シリアル化のサポート。(#2201)

  • JsonArray.asList および JsonObject.asMap ビュー メソッドを追加 (#2225)

  • TypeAdapterRuntimeTypeWrapper が反射型 TreeTypeAdapter および FutureTypeAdapter を検出しない問題を修正 (#1787)

  • JsonReader.skipValue() を改良 (#2062)

  • プリミティブ数値型アダプターの数値変換を実行する (#2158)

  • Gson.fromJson(..., TypeToken) オーバーロードを追加 (#1700)

  • 既存の Gson インスタンスに影響する GsonBuilder への変更を修正 (#1815)

  • JsonElement 変換メソッドの一貫性を高め、javadoc (#2178) を修正

  • JsonWriter.jsonValue がサポートされていない場合は UnsupportedOperationException をスローする (#1651)

  • JsonObject Entry.setValue(null) を禁止します (#2167)

  • カスタム IOException に対して AssertionError をスローする TypeAdapter.toJson を修正 (#2172)

  • JsonArray.set の場合、null を JsonNull に変換します (#2170)

  • nullSafe の使用法を修正しました。 (#1555)

  • TypeToken.getParameterized 引数を検証する (#2166)

  • 修正 #1702: Gson.toJson は toString を実装しない CharSequence を作成します (#1703)

  • 同時 Gson.getAdapter 呼び出しには既存のアダプターを優先します (#2153)

  • ArrayTypeAdapter を Object[] 用に改良 (#1716)

  • AppendableWriter のパフォーマンスを向上 (#1706)

  • https://github.com/google/gson/pull/1706 の @Marcono1234 による AppendableWriter のパフォーマンスの向上
  • https://github.com/google/gson/pull/1716 の @Marcono1234 による Object[] の ArrayTypeAdapter を改善
  • Gson.getAdapter の同時呼び出しには既存のアダプターを優先 (https://github.com/google/gson/pull/2153 の @Marcono1234 による)
  • 修正 #1702: Gson.toJson は、https://github.com/google/gson/pull/1703 の @Marcono1234 による toString を実装しない CharSequence を作成します

  • https://github.com/google/gson/pull/2166 の @Marcono1234 による TypeToken.getParameterized 引数の検証
  • nullSafe の使用法を修正しました。 @bufistov 著、https://github.com/google/gson/pull/1555
  • https://github.com/google/gson/pull/2170 の @Marcono1234 により、JsonArray.set の null を JsonNull に変換します
  • GsonBuilder.setExclusionStrategies が既存のものを置き換えるものではないことを https://github.com/google/gson/pull/2168 の @Marcono1234 によって明確にしました
  • https://github.com/google/gson/pull/1246 の @JamesZBL によるタイプミスを修正

  • https://github.com/google/gson/pull/1815 の @Marcono1234 により、既存の Gson インスタンスに影響を与えない GsonBuilder をチェックするテストを追加
  • 修正 #1697: https://github.com/google/gson/pull/1704 の @Marcono1234 により、GsonBuilder.registerTypeAdapter が (デ) シリアライザーを null セーフにすることに言及

  • JsonTreeReader と JsonTreeWriter が、https://github.com/google/gson/pull/2181 の @Marcono1234 によるすべてのメソッドをオーバーライドすることを確認します。
  • コンパイラ警告で Maven ビルドが失敗する。 https://github.com/google/gson/pull/2183 の @Marcono1234 によるいくつかの警告抑制を削除
