gson gson-parent-2.11.0

リリース 公開日2024年5月20日 出典google/gson 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

gson gson-parent-2.11.0

最も重要な変更点

  • デフォルトの ProGuard / R8 ルールを追加しました (@Marcono1234、#2397、#2420; @sgjesse、#2448; @sfreilich)
    ProGuard または R8 (Android プロジェクトなど) を使用している場合、クラスに引数なしのコンストラクターがあり、フィールドに @SerializedName を使用している場合は、特別な Gson 構成はもう必要ありません。
  • Android では、Gson には API レベル 21 以降が必要になりました
  • 新しい Strictness API (@marten-voorberg と仲間の学生、#2437)\ を追加しました Gson の API の一部は依然としてデフォルトで寛容ですが、新しく追加されたメソッド GsonBuilder#setStrictness、JsonReader#setStrictness、および JsonWriter#setStrictness を Strictness.STRICT とともに使用して、この動作をオーバーライドし、代わりに解析時に JSON 仕様に厳密に従うことができるようになりました。
  • JSON 出力で改行を構成できる新しい FormattingStyle クラス (@mihnita、#2231)
    GsonBuilder#setFormattingStyle、JsonWriter#setFormattingStyleで設定可能です。
  • TypeToken はデフォルトで型変数をキャプチャできなくなりました (@Marcono1234、#2376)
    これは以前は一般的な問題の原因でした。新しくスローされた例外は、これについてより詳細に説明し、影響を受けるコードを更新するための提案を提供する トラブルシューティング ガイドの記事 を参照しています。
  • カスタム アダプターを使用した匿名クラスとローカル クラスのシリアル化サポートを追加しました (@Marcono1234、#2498)
    これは、たとえば、匿名クラスとして実装され、以前は null としてシリアル化されていた Guava などのライブラリによって返される List 実装に影響します。カスタム アダプターのない匿名クラスとローカル クラスは、引き続き null としてシリアル化されます。
  • com.google.errorprone:error_prone_annotations\ への依存関係を追加 プロジェクトでは、Maven または Gradle の依存関係の除外を使用して、Gson から推移的な error_prone_annotations 依存関係を削除できます。または、プロジェクト内の依存関係を JAR として手動で管理している場合は、error_prone_annotations を省略できます。それでも正しく動作するはずです。
    ただし、Gson 自体はこれを必須の依存関係として宣言しており、カスタム構成を実行しない場合、Maven または Gradle はデフォルトでそれをダウンロードして使用しようとします。
  • 多くの例外メッセージが トラブルシューティング ガイド (@Marcono1234、#2357) を参照するようになりました。 トラブルシューティング ガイドに関するフィードバックをお待ちしております。
  • Java 以外の JVM 言語は完全にはサポートされていない可能性があることが公式に文書化されています。README を参照してください。
  • JsonElement#toString が JSON 出力を生成することを保証します (@Marcono1234、#2659)

その他の変更点

バグ修正

  • 大きな BigInteger 値に対する誤った JsonPrimitive#equals 結果を修正しました (@MaicolAntali、#2311)
  • 大きな BigDecimal 値に対する誤った JsonPrimitive#equals 結果を修正しました (@MaicolAntali、#2364)
  • 不正な Unicode エスケープ シーケンスに対して MalformedJsonException の代わりに NumberFormatException をスローする JsonReader を修正しました (@MaicolAntali、#2337)
  • 非ジェネリック型に対して偽の ParameterizedType を返す TypeToken#getParameterized を修正しました (@Marcono1234、#2447)
  • GraalVM ネイティブ イメージで動作しない Java レコード アダプターを修正 (@eamonnmcmanus、#2465)
  • JSON オブジェクトが現在書き込まれていないときに JsonWriter#name が例外をスローしない問題を修正 (@shivam-sehgal、#2475; @Marcono1234、#2476)
  • Gson#getDelegateAdapter が @JsonAdapter に対して正しく動作しない問題を修正 (@Marcono1234、#2435)
    null は、以前は許可されていましたが文書化されていませんでしたが、現在は skipPast 値として許可されなくなっていることに注意してください。
  • GsonBuilder が、デフォルトのアダプターをオーバーライドできない Object および JsonElement のタイプアダプターを拒否しない問題を修正 (@sachinp97; #2479)
  • BigDecimal および BigInteger を逆シリアル化するときに制限が適用されない問題を修正 (@Marcono1234、#2510)
    新しい制限により、ユーザー コードで逆シリアル化された数値が使用される場合の潜在的なパフォーマンスの問題が防止されます。 Gson 自体は、これらのパフォーマンスの問題の影響を受けており、影響を受けていません。制限は、ほとんどの使用例で問題が発生しない程度に十分に高いはずですが、フィードバックは歓迎です。
  • GsonBuilder#setDateFormat が無効な日付形式を拒否しない問題を修正 (@Carpe-Wang、#2538)
  • GsonBuilder#setDateFormat が無効な日付スタイルを拒否しない問題を修正 (@Marcono1234、#2545)
  • 部分的な DEFAULT スタイルを無視する GsonBuilder#setDateFormat を修正 (@Marcono1234、#2556)
  • 場合によっては TypeToken#isAssignableFrom が AssertionError をスローする問題を修正 (@Marcono1234、#2544)
  • 解析後にタイムゾーンを復元しない日付アダプターを修正しました (@Carpe-Wang、#2549)
  • 場合によっては、等しいジェネリック型パラメーターに対して TypeToken#equals が誤って false を返す問題を修正しました (@d-william、#2599)
  • pom.xml の誤った継承 URL を修正 (@Marcono1234、#2351)

パフォーマンスの向上

  • リフレクションベースのアダプターのメモリ使用量をわずかに削減 (@sembseth、#2325; @Marcono1234、#2440)
  • ToNumberPolicy#LONG_OR_DOUBLE の解析速度の向上 (@ctasada、#2674)

Gson メンテナンス

  • アサーションに JUnit ではなく Truth を使用するように多くの単体テストを変更しました (@MaicolAntali、#2299、#2304)
  • コンパイル時にバグを自動的にチェックするようにエラー傾向を設定しました (@MaicolAntali、#2308)
  • テストで予期される例外処理を簡素化 (@elevne、#2454)
  • GraalVM ネイティブ イメージの統合テストを追加 (@Marcono1234、#2466)
  • Google スタイル ガイドに従ってコードをフォーマットし、Spotless を設定しました (@MaicolAntali、#2531、#2537)
  • Maven ビルドを再現可能にしました (@Marcono1234、#2543)
  • コードの重複を減らすために内部 DateTypeAdapter クラスを削除しました (@Marcono1234、#2546)
  • dependabot によって更新された依存関係とプラグイン

GitHub リポジトリ

  • デフォルトのブランチの名前を master から main に変更しました
  • GitHub ディスカッション が有効になりました
    質問、アイデア、ヒントなど...
  • GitHub プル リクエスト テンプレートを追加しました (@Marcono1234、#2326)
  • Android API 互換性チェックを追加 (@Marcono1234、#2431)

その他

  • 必要に応じて @CanIgnoreReturnValue を Gson メソッドに追加しました (@eamonnmcmanus、#2369)
    これは、コンパイル時にプロジェクトで Error Prone の CheckReturnValue を有効にする場合に便利ですが、Gson 自体はデフォルトではこれを有効にしません。
  • さまざまなドキュメントとテストの改善とタイプミスの修正 (@False-Mask; @avimathur009; @elevne; @0o001; @Codegass; @33nya)

これらの release note のドラフトを作成してくれた @Marcono1234 に感謝します。
