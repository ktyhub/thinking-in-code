spring-cloud-tencent 2.1.2.0-2024.0.3

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

春-雲-テンセント 2.1.2.0-2024.0.3

依存関係のバージョン

  • 春雲テンセント: 2.1.2.0-2024.0.3
  • 春の雲: 2024.0.3
  • Spring Boot: 3.4.12
  • Spring Framework: 6.2.15

フル Changelog

https://github.com/Tencent/spring-cloud-tencent/compare/2.1.1.0-2024.0.3...2.1.2.0-2024.0.3

機能/拡張機能

  • サーキットブレーカー

    • 特技: ワイルドカード api レベルで分離された CB の使用をサポートし、CB カウンターの有効期限切れ間隔設定 #1809 を追加します。

  • 設定

    • 特技: client URL 変換をレポートするための構成アドレスを追加しました。 #1795
    • 偉業: 構成サーバー IP を 127.0.0.1 に更新し、テスト #1796 を調整します。
    • 特技: Polaris 設定環境値をサポートし、関連テストを追加 #1797

  • コンテキスト

    • リファクタリング: ApplicationContextAwareUtils の初期化を変更します。 #1798
    • 特技: 設定によるクラウド ロケーション プロバイダーの有効化/無効化をサポートします。 #1799

  • 発見

    • 偉業: Feign 熱心なロードをリファクタリングし、LoadBalancer ウォームアップを追加し、ゲートウェイの末尾のスラッシュの互換性を修正しました #1800

  • レートリミット

    • 特技: ratelimit、イベント レポーター、統計モジュールの overrideHost 構成をサポート #1804

修正

  • テスト: ConfigurationModifier の単体テストを追加し、TsfConsul レポート ロジック #1802 を修正しました。
  • 修正: コントラクト レポーター API パス #1803 の先頭にコンテキスト パスを追加
  • 修正: springdoc スキャン #1807 の分割コントラクト基本パッケージ
