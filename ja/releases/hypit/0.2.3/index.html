hypit v0.2.3

パッチ 公開日2026年9月17日 出典hypit-ai/hypit 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#ハイピットv0.2.3

ローカル実行とリクエストの正確性

  • ファイルベースの資格情報は、結果ストアのネイティブ Windows 置換実装を共有するようになりました。 CLI およびワーカー プロセスは、プロセス ローカル キューを使用せずに完全な資格情報の値を読み取り、置換できます。置換に失敗した場合は、以前の値が保持されます。サポートされていないファイルシステム操作ではエラーが報告されます。
  • Windows OS 資格情報の置換では、書き込み前に以前の値が削除されなくなりました。子プロセスのタイムアウトと出力の失敗により、ヘルパーが終了します。
  • ホスト状態ルート外の明示的なファイル/プラットフォーム認証情報ディレクトリが再び受け入れられます。プロファイルは、選択した保存場所の制御を保持します。
  • 生成マッピングは、リクエストをアップロードまたは送信する前に、送信できない明示的に指定されたメディア フィールドを拒否します。オプションのブール値は、true と false の両方を保持します。
  • メディアの準備は、実行環境で選択された FFmpeg/FFprobe 実行可能ファイルをプローブします。プローブ専用プログラムは、実行中のサービスであることを主張せずに、インストール/準備を正確に報告します。
  • ランチャーは、パッケージをロードする前に物理的な配布ディレクトリを解決します。これにより、インストールされたフォントが独自のディストリビューションの外に表示される Windows ショートパス エイリアスが誤って修正されます。
  • インストールされたパッケージ CI は、コンポーネントのビルド、フォント、明示的なブラウザーの準備、レンダリング、エクスポート、フル メディア デコードを含め、Windows と Linux の両方を検証するようになりました。
  • プロジェクト ビデオ プロバイダーの例では、例示的なアップロード トランスポートを通じて、最初/最後のフレームの人物参照分類が伝送されます。

これらの変更により、サイレント ダウンロード、再試行、フォールバック ブラウザ、ロック ファイル プロトコル、中央キュー、永続的な調整メタデータは追加されません。論理モジュールとフォーマット識別子は @1 のままです。スクリプトの構文は変更されません。

更新中

グローバル CLI インストールの場合:

npm install -g @hypit/hypit@0.2.3
hypit --version

プロジェクトローカルインストールの場合:

npm install --save-exact @hypit/hypit@0.2.3
npm exec --no -- hypit --version

インストールされた Hypit スキルは、インストールに使用されたツールを通じて個別に更新されます。このリポジトリからそのインストールを更新して、準備、プロセスの起動、資格情報の接続を分離する改訂された ランタイム プロファイル ガイダンス を受け取ります。どちらのインストールを更新しても、保存されたビデオ プロジェクトは移行または書き換えられません。

リポジトリのみの変更: オプションの AI 分析ワークフローは手動でトリガーされ、1 つの問題または PR を読み取り、アクションの概要にアドバイスを返します。これには問題/PR 書き込み権限はなく、npm CLI から独立しています。
