hypit v0.3.0

マイナー 公開日2026年10月8日 出典hypit-ai/hypit 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#ハイピットv0.3.0

ハイライト

  • Hypit にはドメイン中立言語ホストとアダプティブ ビデオ オーサリング レイヤーが追加されました。 SVML、SVS、および SVRun は引き続き作成者向けのソース ファミリですが、ビデオ セマンティクス、オーディオビジュアル トラック、コンポーネント、および実行は、コアにハードコーディングされるのではなく、コンポーザブル パッケージによって所有されます。
  • 時間は明示的で再利用可能です。 タイムラインの構築は絶対的な終了とアンカーを解決します。意味論的射影は明示的な著者関係です。コンポーネント サーフェスは、名前付き Windows とインスタントを消費します。ビジュアル、オーディオ、タイポグラフィ、およびキャプション トラックは、セマンティック時間を必須の骨格にすることなく、より明確なアイテム モデルを共有します。
  • キャプションは作成された構造を保持します。 キャプション ドキュメントは、同じモデルに基づく完全なタイミング バインディングと Studio プレゼンテーションにより、表示単語、意味単位、および作成されたキューを区別します。
  • メディア構成はより直交的です。 A ロールと B ロールは、タイミング証拠を提供した後、同じビジュアルおよびオーディオ clip モデルを使用します。再生、空間マッピング、描画順序は独立して表現され、ローカル メディア/イメージの実行には単一の所有者が存在します。
  • ローカル ツールチェーンは、2 番目のパッケージ システムなしで構成できます。 ルート CLI は、プロジェクト構成を通じてインストールされたコマンド コントリビュータを検出します。 npm パッケージとパッケージ マネージャー ロックファイルは、引き続きインストールとバージョンの権限を持ちます。
  • ディストリビューションには明示的な所有権グラフがあります。 必須の実装パッケージが埋め込まれていますが、デフォルトのモデル、プロバイダー、キットは通常のバージョン管理された依存関係です。リリース候補はそのグラフから組み立てられ、Linux および Windows 上でのコールド インストールと実際のレンダリングを通じて検証されます。

アップグレード

パッケージ マネージャーを使用して @hypit/hypit@0.3.0 をインストールし、結果として得られるロックファイルをコミットします。これはアーキテクチャ上のリリースです。削除された従来のフォームに依存するのではなく、0.2 ソース、レシピ、実行、およびプロジェクト コンポーネントを 0.3 オーサー モデルに移行します。リポジトリの例、公開ドキュメント、および Hypit Skill では、現在の構文と所有権の境界が説明されています。

Hypit Skill を個別にインストールした場合は、hypit-ai/hypit からそのインストールを更新します。 npm とスキルのインストールは個別に更新されます。

検証

公開は、型チェック、テスト、Linux および Windows 上での 1 つの不変候補のコールド インストール、コンポーネントのコンパイル、ブラウザの準備、240 フレームのレンダリング、エクスポート、およびメディアのデコードに基づいて制御されます。ディストリビューションは、すべての独立したパッケージのバージョンと候補の整合性が検証された後にのみ公開されます。
