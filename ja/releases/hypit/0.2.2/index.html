hypit v0.2.2

パッチ 公開日2026年9月17日 出典hypit-ai/hypit 英語原文

#ハイピットv0.2.2

Windows メディア環境と資格情報ストアの正確性

このリリースには、Windows 実行の修正と資格情報ディレクトリの選択の変更が含まれています。ホスト状態ルート外のファイルまたはプラットフォーム ストア パスを含む既存のプロファイルは、0.2.2 によって拒否されます。これは 0.2.1 からの動作の変更です。新しいスターター ストアの選択は、新しく初期化されたプロファイルにのみ適用されます。

Windows メディアの実行

ffmpeg および ffprobe は環境変数のホワイトリストを使用して開始されるため、ホスト環境にはメディアの子が含まれないようになります。そのホワイトリストは POSIX 用に作成されたため、Windows の子は %TEMP% も %TMP% も受け取らず、一時ファイルの作成に失敗しました。 HyperFrame のレンダリング パスと共有メディアの実行パスの両方に、POSIX リストとともに Windows リストが含まれるようになりました。ホストの秘密は依然として隠蔽されています。 (#259、#260)

認証情報のストレージ

  • runtime init は、@hypit/credential-store-platform を選択するスターター プロファイルを書き込むため、生成されるプロファイルは Linux、macOS、Windows 上で開いて書き込みます。 macOS と Windows はプラットフォーム ロッカーを同じサービスとキーに維持するため、既存の認証情報は引き続き見つかります。 os、file、env は引き続き名前で選択できます。 (#247)
  • ファイルおよびプラットフォーム ストアのプロファイルの config.path は、ホスト状態ルートに対して解決され、含まれているかどうかがチェックされます。そのルートをエスケープするパスは、ストアが開くときに拒否されます。ルート外部の絶対パスは以前は受け入れられていましたが、現在は受け入れられません。 (#265)
  • 1 つの認証情報ドキュメントの読み取りと置換は、プロセス内で順番に行われます。 resolve は、読み取り全体にわたってドキュメントを開いたままにし、put がそれを名前変更で置き換えます。Node の Windows 名前変更実装では、宛先が開いている間は置き換えを拒否できる MoveFileExW が使用されます。プロセスローカルの順序付けにより、1 つのプロセス内でのこの重複が軽減されます。個別の CLI プロセスとワーカー プロセスを調整しません。 0.2.2 にはプロセス間交換の失敗が残っています。キーは独立したままになります。 (#276)
  • Windows Credential Manager ヘルパーは、macOS security(1) 呼び出しと同じ 10 秒のタイムアウトに制限されているため、スタックしたロッカーは CLI をハングさせる代わりに失敗します。 (#261)

ランタイムと CLI

  • programs down は、有効な Hypit PID と start コマンドがないプログラムを停止するものが何もないものとして扱い、終了する代わりに No external programs to stop を報告します 1。スターター プロファイルの media.local および hyperframes.local は probe() のみを宣言するため、準備ができたプローブは、プロセスが実行中であることを意味するのではなく、ツールがインストールされていることを意味します。 Hypit PID がなくても準備ができている起動可能なプログラムは、依然として not-ours を報告します。 (#272)
  • 概要ヘルプ リスト programs prepare|up|status|down、プロファイルが選択されていない programs、および runtime は、build、pricing、auth および実行コマンドが既に使用しているものと同じリカバリ センテンスを報告します。 (#266)
  • 3 つのパッケージは、ソースがインポートするワークスペース パッケージを宣言します。 (#253)

ドキュメント

  • 英語のクイックスタートのビルド ワークフロー セクションには、依存関係の準備、.gitignore、共有アセット ライブラリ、および中国語版のアーカイブ コマンド マテリアルが含まれています。 (#275)
  • auth status の例には、必要なエンドポイント引数が含まれています。 (#254)
