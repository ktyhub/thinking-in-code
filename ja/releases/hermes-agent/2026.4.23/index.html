エルメスエージェント v2026.4.23

#エルメスエージェント v0.11.0(v2026.4.23) 発売日: 2026 年 4 月 23 日 v0.9.0 以降: コミット数 1,556 · マージされた PR 761 · 変更されたファイル 1,314 · 挿入 224,174 · コミュニティ貢献者 29 名 (共著者を含むと 290)

Interface リリース — インタラクティブな CLI の完全な React/Ink 書き直し、すべてのプロバイダーの下にあるプラグイン可能なトランスポート アーキテクチャ、ネイティブ AWS Bedrock サポート、5 つの新しい推論パス、17 番目のメッセージング プラットフォーム (QQBot)、劇的に拡張されたプラグイン サーフェス、Codex OAuth 経由の GPT-5.5。 このリリースには、v0.10.0 (Nous Tool Gateway のみを出荷) から延期されたすべてのハイライトも組み込まれているため、スタック全体で約 2 週間の作業がカバーされます。

✨ ハイライト

  • 新しいインクベースの TUI — hermes --tui は、Python JSON-RPC バックエンド (tui_gateway) を備えた、インタラクティブな CLI の完全な React/Ink 書き換えです。 Sticky Composer、OSC-52 clipboard サポートによるライブ ストリーミング、安定したピッカー キー、ターンごとのストップウォッチと git ブランチを備えたステータス バー、/clear 確認、ライトテーマ プリセット、およびサブエージェント スポーン可観測性オーバーレイ。 ui-tui/ + tui_gateway/ へのコミット数は約 310 です。 (@OutThisLife + テクニウム)
  • トランスポート ABC + ネイティブ AWS Bedrock — フォーマット変換と HTTP トランスポートが run_agent.py からプラグイン可能な agent/transports/ レイヤーに抽出されました。 AnthropicTransport、ChatCompletionsTransport、ResponsesApiTransport、および BedrockTransport は、それぞれ独自の形式変換と API 形状を持っています。 Converse API を介したネイティブ AWS Bedrock サポートは、新しい抽象化に加えて提供されます。 (#10549、#13347、#13366、#13430、#13805、#13814 — @kshitijk4poor + Teknium)
  • 5 つの新しい推論パス — ネイティブ NVIDIA NIM (#11774)、Arcee AI (#9276)、ステップ プラン (#13893)、Google Gemini CLI OAuth (#11270)、および Vercel価格設定 + 動的検出を備えた AI ゲートウェイ (#13223 — @jerilynzheng)。さらに、Gemini はネイティブ AI Studio API 経由でルーティングされ、パフォーマンスが向上しました (#12674)。
  • Codex OAuth 上の GPT-5.5 — OpenAI の新しい GPT-5.5 推論モデルは、ChatGPT Codex OAuth を通じて利用できるようになりました。モデル ピッカーに接続されたライブ モデル ディスカバリにより、新しい OpenAI リリースはカタログ更新なしで表示されます。 (#14720)
  • QQBot — 17 番目にサポートされるプラットフォーム — QQ 公式 API v2 経由のネイティブ QQBot アダプター。QR スキャンして設定するセットアップ ウィザード、ストリーミング カーソル、絵文字反応、WeCom/Weixin 同等の DM/グループ ポリシー ゲーティングを備えています。 (#9364、#11831)
  • プラグイン サーフェスの拡張 — プラグインは、スラッシュ コマンドの登録 (register_command)、ツールの直接ディスパッチ (dispatch_tool)、フックからのツール実行のブロック (pre_tool_call は拒否権あり)、ツール結果の書き換え (transform_tool_result)、ターミナル出力の変換 (transform_terminal_output)、image_gen バックエンドの配布、カスタム ダッシュボード タブの追加ができるようになりました。バンドルされているディスク クリーンアップ プラグインは、リファレンス実装としてデフォルトでオプトインされています。 (#9377、#10626、#10763、#10951、#12929、#12944、 #12972、#13799、#14175)
  • /steer — 実行中のエージェント ナッジ — /steer <prompt> は、ターンを中断したりプロンプト キャッシュを中断したりすることなく、実行中のエージェントが次のツール呼び出し後に表示するメモを挿入します。飛行中のエージェントの軌道を修正したい場合に使用します。 (#12116)
  • シェル フック - Python プラグインを作成せずに、任意のシェル スクリプトを Herme ライフサイクル フック (pre_tool_call、post_tool_call、on_session_start など) として接続します。 (#13296)
  • Webhook 直接配信モード — Webhook サブスクリプションは、エージェントを経由せずにペイロードをプラットフォーム チャットに直接転送できるようになりました。アラート、稼働時間チェック、イベント ストリームのためのゼロ LLM プッシュ通知です。 (#12473)
  • よりスマートな委任 — サブエージェントには、構成可能な max_spawn_depth (デフォルトのフラット) を使用して、独自のワーカーを生成できる明示的な orchestrator ロールが与えられるようになりました。同時兄弟のサブエージェントは、ファイル調整レイヤーを通じてファイルシステムの状態を共有するため、互いの編集内容が破壊されません。 (#13691、#13718)
  • 補助モデル — 構成可能な UI + メインモデル優先 — hermes model には、タスクごとのオーバーライド (圧縮、ビジョン、セッション検索、タイトル生成) のための専用の「補助モデルの構成」画面があります。 auto ルーティングは、すべてのユーザーのサイド タスクのデフォルトがメイン モデルになるようになりました (以前は、アグリゲーター ユーザーは、安価なプロバイダー側​​のデフォルトにサイレントにルーティングされていました)。 (#11891、#11900)
  • ダッシュボード プラグイン システム + ライブ テーマ切り替え — Web ダッシュボードが拡張可能になりました。サードパーティのプラグインは、フォークせずにカスタム タブ、ウィジェット、ビューを追加できます。ライブ切り替えテーマ システムと組み合わせると、テーマで色、フォント、レイアウト、密度を制御できるようになり、ユーザーはリロードせずにダッシュボードの外観をホットスワップできるようになります。 CLI と同じテーマの規律がウェブ上に公開されました。 (#10951、#10687、#14725)
  • ダッシュボードの洗練 — i18n (英語 + 中国語)、react-router サイドバー レイアウト、モバイル対応、Vercel 導入、実際のセッションごとの API 通話追跡、および 1 つの click 更新 + ゲートウェイ再起動ボタン。 (#9228、#9370、#9453、#10686、#13526、#14004 — @austinpickett + @DeployFaith +テクニウム)

🖥️ 新しいインクベースの TUI
