エルメスエージェント v2026.9.11

#Hermes Agent v0.21.2 (v2026.9.11) — state.db パッチ リリース

発売日: 2026 年 9 月 11 日

パッチリリース。 v0.21.0 はセッション ストアの接続処理の大規模な書き換えを同梱し、一部のインストールでは state.db を脆弱にしました。2 番目のライターがお互いのロックをキャンセルし、正常なデータベースが破損していると報告され、1 つの不良行が sessions list を破壊しました。このリリースはそのクラスを終了し、v0.21.1 以降の 4 日間に main に登録されたその他のすべてをまとめたものです。

このリリースについて

コミット 04dd80a977f40b05e5b2054111747af07a61886a で測定した場合、v0.21.1 以降のウィンドウには、1,869 の変更されたファイル (+182,504 / −15,564) と 312 のマージされた PR にわたる 947 の非マージ コミットが含まれます。 140 人の寄稿者 がコミット、共著者トレーラー、またはサルベージ クレジットに表示されます。

✨ ハイライト

state.db 信頼性キャンペーン (PR 6 件、解決済みの問題 44 件)

0.21.0 の後に state.db が壊れた場合は、これがあなたのためのリリースです。 6 つの PR は、症状ではなく根本原因を修正します。

  • 2 番目のライターは不要です。 プロファイル ゲートウェイは、ホストされたルームの状態を 5 秒ごとに ルート state.db に書き込みました。ダッシュボードは起動時に書き込み可能なハンドルを開きました。 cron のライフサイクル ガードは、ライブ データベース上で生の open() を実行しました (これにより、ゲートウェイの POSIX ロックが解除されます。古典的な「SQLite を破損する方法」のレシピです)。 doctor --fix はライブ ホルダーの下にチェックポイントを置きます。 4 つすべてが消えています。ホストされているルームは shared-state.db に存在し、ダッシュボードは最初に読み取り専用で開き、ガードは追跡された接続レジストリを調べ、doctor --fix は安全であることを証明できないチェックポイントを拒否します。 (#108076 — サルベージ #103489 @RikETS、#102682 @JoaoMarcos44、#108012 @Halldrix、#105428 @TaoMasterCoder)
  • 健全な WAL データベースはウェッジを停止します。 OpenZFS (deleted) デントリと append_message と競合する close() は両方とも、完全に良好なストアで粘着性のある DeletedWalGenerationError を生成しました。読み取りプールが未確認のジャーナル モードで配布されました。 WSL2 上の一時的な disk I/O error が最初の試行で get_session を強制終了しました。ロックがすでに解除された後、「state.db locked」バナーがブロードキャストされました。 (#108082 — サルベージ #107411 @chelsealong、#105578 @ca-shrimp、#105711 @gaoanze888、#106958 @nikkoxgonzales; 共著 @QDung210、@fangliquanflq、@Sahilvishnaliya)
  • FTS ダメージによってターンが終了することはなくなりました。 全文検索インデックスに範囲を限定したエラーは、ファイル全体の破損として分類され、会話がフェールクローズされました。現在は fts_index です。検索は低下し、インデックスは後で再構築されますが、トランスクリプト ストアは変更されません。同じ PR: 医師は「FTS 書き込み破損」ではなく構造的損傷を正直に名づけ、FTS 書き込みプローブは書き込みがすべて失敗する一方ですべてのチェックに合格した古いインデックス形状を検出し、.recover 出力が孤立した FTS5 シャドウ テーブルでの起動に失敗しなくなり、ヘッダーがゼロになったデータベースが拒否されずに回復し、ダッシュボード分析ポーラーは 1 日あたり 520,000 のトレースバックではなく 503 を返します。 (#108130 — サルベージ #97843 @SulthanZahran1 + #97841 @Finn763, #88604 #56824 #103657 @liuhao1024, #106890 @nftpoetrist, #103321 @jangomango76, #91413 @leegunwoo98, #102808 @TaoMasterCoder)
  • 1 つの破損した行によって sessions list、エクスポート、またはインサイトが強制終了されることはなくなりました。 TEXT タイムスタンプまたは 1e30 エポックは、リスト全体をクラッシュさせるために使用されました。不正な形式のマーカー JSON が json_extract をクラッシュさせました。 999 を超える ID で一括削除/削除がクラッシュしました。すべてのリーダーに 1 つの coerce_epoch() ヘルパー (不正な行では、セッションに名前を付ける警告とともに ? が表示されます)、json_valid ガード、IN リスト チャンキング、およびバッチ エクスポート ハイドレーション。 (#108086 — サルベージ #106071 @Xipong、#101726 @efe-arv、#94701 @liuhao1024、#102679 @mssteuer、#100658 @Mi55ed)
  • セッションが別のプロファイルのデータベースにバインドしたり、読み取ったりすることはありません。 デスクトップ起動バックエンドは、HERMES_HOME オーバーライド競合により、間違ったプロファイルの state.db に自身を固定する可能性があります。 session_search は裸の ID ですべてのプロフィールを黙ってスキャンし、他人の記録を返しました。リカバリ ガイダンスが間違ったファイルを指していました。プロファイルを削除すると、ハンドルが開いたままになりました (WinError 32)。 (#108074 — サルベージ #102534 @HexLab98、#106975 @Sora-bluesky)
  • 書き込みの必要がない場合に、state.db を開くときに書き込みロックがかかりなくなりました。 ビジーなゲートウェイの背後でストアを開くワンショット hermes プロセスが 4 ～ 20 秒停止し、「データベースがロックされています」というエラーで失敗しました。今は0.01です。 (#108067 — サルベージ #106751 @kshitijk4poor、#101881 @jonpol01)

同じサブシステムのウィンドウでも: 新しい state.db は再構築ロックを所有する前に FTS テーブルを公開しなくなり (#106311)、WAL 生成を失ったハンドルはシャットダウン時に古いフレームをチェックポイントしなくなり (#106315、#106840)、破壊された最初のページは破壊的に開かれるのではなく WAL で隔離され (#106587)、WAL セットアップは検証できないデータベースは変更されておらず (#106568)、隔離されたハンドルは VACUUM/FTS 最適化を拒否しています (#106343、#106349)。これらのほとんどは、@kshitijk4poor によるコミュニティ診断を回収したものです。

マルチプロファイル絶縁強化

1 つのゲートウェイ (マルチプレックス) で複数のプロファイルを実行するインストールに対する修正のクラスター: セカンダリ プロファイルのボットはデフォルト プロファイルの許可リストを継承しなくなり (#107616)、アダプターはデフォルト プロファイルのホストに認証情報を送信しなくなり (#107617)、stdio MCP サーバーはデフォルト プロファイルのボールト シークレットを受信しなくなり (#107630)、MEDIA: 配信では別のプロファイルをアタッチできなくなりました。プロファイルの .env / auth.json / state.db (#107609)、Feishu ドライブ コールバックおよび /p/<profile>/ Webhook 応答はルーティングされたプロファイル (#107620、#107626) に残り、セカンダリ プロファイルはプロセスごとのメモ (#107611) から兄弟の Nous ベアラーを取得しなくなります。

デスクトップ バックエンド スポーンの嵐は終わった

ボット モードでは、起動時および名簿ティックごとにプロファイルごとに 1 つのバックエンドを生成またはダイヤルしていましたが、ボット名簿にカーソルを置くと行ごとにバックエンドが生成され、プロファイルのスイッチによって重複したプライマリが生成される可能性がありました。 (#108069、#108107、#108118、#108134、#107969、#108112 — サルベージ #102512、#103634、#103399、#107997、その他 by @kshitijk4poor)

パスワードブラインド資格情報ボールト

エージェントは、シークレットを見ることなく、1Password、Bitwarden、またはローカルの Herme 保管庫からサインイン、支払い、アドレスの入力を行うことができます。 2 要素コードは、保存された認証キーから取得されるか、ユーザーの UI で要求されます (#106480、#107585)。プライベート git プラグインは、ユーザーの保存された認証情報を使用してインストールされます (#106981)。

プラグイン カタログと 1 つのプラグイン ページ

CLI、アドミッション CI、ドキュメント、ダッシュボードを含む厳選された SHA 固定プラグイン インデックス (#69446)。デスクトップは、エージェント + デスクトップ プラグイン、インストール、カタログ、およびコミットごとのピンニングを所有する 1 つのプラグイン ページを取得します (#107212、#107314、#107321)。ラジオはオプトイン SDK プラグイン (#107072) として出荷されます。

無料枠とガイド付きの初回起動

1 つのコマンドですぐに使える無料の推論とコネクタ (#105258、#105260)、チャットからの /login (#105261)、tool_search を通じて検索可能なコネクタ ツール (Gmail、Linear、Notion など) (#106842)、HERMES_GUEST_ONBOARDING=1 の背後でのガイド付き初回起動 (#107697、#107958、 #107985、#108211)。

🐛 注目すべきバグ修正

ゲートウェイとプラットフォーム

  • config.yaml 内の裸の display: キーは、ゲートウェイのターンごとにクラッシュしなくなりました (#106305)。プラットフォームによって拒否されたキューレーン最終は記録され、再配信されます (#106316)。 WebSocket 送信が停止しても、その後のすべてのイベントがブロックされなくなりました (#106581)。最初のターンは Python ツールチェーン プローブで待機しなくなりました (#106556)。
  • bots_require_mention がオンの場合、Telegram ボットは @メンションする必要があり、ボット間のループを解消します (#106534)。 Matrix は LaTeX をレンダリングします (#106515)。 Signal はマークダウン テーブルをレンダリングします (#106538)。 WhatsApp は 1 回限りのメッセージに返信すると引用文が保持されます (#106541)。メディアのみの返信はどこでも成功を報告します (#106557)。

プロバイダーとルーティング

  • /model および補助自動は、選択しなかったプロバイダーに請求を行うことはありません (#107366)。資格情報を持たないプロバイダーには決して自動切り替えしないでください (#107281)。 Bedrock Claude/Converse/Mantle モデルは /model で生き残り、フォールバックして復元します (#107621、#107658)。岩盤ガードレールが施行されました (#107815)。
  • コーデックス: パッチバジェット イメージ 400 が縮小して再試行される (#106525)。無資格のプライマリ + フォールバックは発振しなくなりました (#106549)。 Azure Foundry の再生推論による拒否が分類され、プルーニングされました (#106718 @erosika)。 MCP OAuth リフレッシュによってリフレッシュ トークンが消去されなくなりました (#106185)。 Anthropic clients は 1 つの資格情報 (#107978) を送信します。
  • Nous Portal および OpenRouter ピッカー上の DeepSeek V4.1 Flash (#107489); OpenAI および FAL 経由の GPT イメージ 2.5 (#105988);ネイティブ Anthropic ピッカー (#106636 @xxxigm) の Opus 5 / Fable 5.1。

エージェント ループと圧縮

  • ブロックされた 1 つの定期コールバックがリース更新を停止しなくなりました (#106308)。ターン途中の /steer は独自のユーザー行として保持されます (#106317、#106344)。ローカル推論メモリ上限の拒否は、履歴を圧縮する代わりにバックオフされます (#106307)。部分ストリーミングがターンを終了した後のコンテキスト オーバーフロー (#106567);プロンプトがウィンドウいっぱいになると長さの継続が停止します (#106571)。圧縮は補助再試行時にサイレントにタイムアウトしなくなりました (#106866)。 model_thresholds キーはプロバイダースコープにすることができます (#108061)。
  • Surface スイッチ (デスクトップ↔TUI) はシステム プロンプトを再構築せず、プロンプト キャッシュを破壊しなくなりました (#105844)。 CLI は api_content サイドカーを保持するため、初期の永続化でもキャッシュが存続します (#105842)。

CLI、TUI、デスクトップ

  • hermes -z --resume はセッションを継続します (#106313)。 Shift+文字と Cmd+Shift+Z は拡張キー端末で機能します (#90674 @francip、#105493)。 browser_exec タイムアウトによりプロセス ツリー全体が強制終了されます (#106589)。更新チェックでは、30 分ごとに git フェッチを行うのではなく、1 日に 1 回 GitHub API をポーリングします (#107648)。 hermes update は本当の原因を特定し、フェッチの停止でハングアップできません (#108053)。
  • デスクトップ: UI 言語はアップデートの再起動後も存続します (#106476)、期限切れの OAuth 許可は 1 つの click 再サインインを取得します (#106965)、HUD モードはトランスクリプトを再度表示し、常にウィンドウを戻します (#107491、#107423)、デスクトップの親が終了するとバックエンドは終了します (#107977)、Windows アップデートは誤った失敗を報告しなくなります(#106175、#107183)、Windows GPU での WSLg レンダリング (#106528)、ダッシュボードから移植された QR を使用した Telegram のクイック セットアップ (#107242)、および主に @OutThisLife と @kshitijk4poor から提供された約 60 のデスクトップ修正。

クロンとカンバン

  • 「今すぐ実行」のチェックを外しても、次にスケジュールされた実行がキャンセルされなくなりました (#106306)。手動実行を強制終了しても、次の実行が 5 分間ブロックされなくなりました (#106733)。ワンショットが繰り返し発火に変更されました (#106532)。固定されていないジョブは作成スナップショット モデルで実行されます (#106499)。 --clone-all は cron ジョブをコピーしなくなりました (#106478)。 kanban promote は元に戻した親を拒否します (#106550)。 kanban_request_review は不明なレビュー担当者プロファイルを拒否します (#106547)。

ツールとメモリ

  • 通話中に標準出力 MCP サーバーが停止しても、ツール呼び出しが再生されなくなりました (#106546)。スキルのみのバックグラウンド レビューではメモリ エントリを削除できなくなりました (#106310)。 mem0 メモリは長いターンでドロップしなくなりました (#106542)。 tool_search は、1 つの単語を共有する 5 つのツールを返すだけで何も返しません (#106676)。リモート NOPASSWD sudo はプロンプトを表示しなくなりました (#107939)。 RSS と Reddit の読み取りはデフォルトで有効になりません (#105873)。

ハウスキーピング

  • config.yaml バックアップは、1 つの境界のある backups/config/ ディレクトリ (#106388) に存在します。 hermes backup は最新の 3 つの zip (#106455) を保持します。 hermes setup --reset は実際の構成 (#106453) をバックアップします。 dpaste フォールバックでは、debug share の保持期間が 1 日に短縮されました (#106531)。
