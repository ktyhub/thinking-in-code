エルメスエージェント v2026.3.28

#エルメスエージェント v0.5.0(v2026.3.28) 発売日: 2026 年 3 月 28 日

強化リリース — Hugging Face プロバイダー、/model コマンドのオーバーホール、Telegram プライベート チャット トピック、ネイティブ モーダル SDK、プラグイン ライフサイクル フック、GPT モデルのツール使用の強制、Nix フレーク、50 以上のセキュリティと信頼性の修正、および包括的なサプライ チェーン監査。

✨ ハイライト

  • Nous Portal が 400 以上のモデルをサポートするようになりました — Nous Research 推論ポータルが劇的に拡張され、Hermes Agent ユーザーが単一のプロバイダー エンドポイントを通じて 400 以上のモデルにアクセスできるようになりました
  • ファーストクラスの推論プロバイダーとしての Face の実現 — OpenRouter 類似物にマッピングする厳選されたエージェント モデル ピッカー、ライブ /models エンドポイント プローブ、セットアップ ウィザード フロー (#3419、#3440) を含む HF Inference API との完全な統合
  • Telegram プライベート チャット トピック — トピックごとに機能的なスキル バインディングを備えたプロジェクト ベースの会話により、単一の Telegram チャット内で分離されたワークフローが可能になります (#3163)
  • ネイティブ モーダル SDK バックエンド — swe-rex の依存関係をネイティブ モーダル SDK (Sandbox.create.aio + exec.aio) に置き換え、トンネルを排除し、モーダル ターミナル バックエンドを簡素化しました (#3538)
  • プラグイン ライフサイクル フックが有効化されました - pre_llm_call、post_llm_call、on_session_start、および on_session_end フックがエージェント ループと CLI/ゲートウェイで起動され、プラグイン フック システムが完成しました (#3542)
  • OpenAI モデルの信頼性の向上 — GPT モデルがツール呼び出しを行う代わりに意図したアクションを記述することを防ぐために GPT_TOOL_USE_GUIDANCE を追加しました。さらに、モデルがターン間でツールを回避する原因となった古い予算警告を会話履歴から自動的に削除します (#3528)
  • Nix flake — 完全な uv2nix ビルド、永続コンテナ モードを備えた NixOS モジュール、Python ソースから自動生成された設定キー、およびエージェント対応のためのサフィックス PATH (#20、#3274、#3061) by @alt-glitch
  • サプライ チェーンの強化 — 侵害された litellm 依存関係を削除し、すべての依存関係のバージョン範囲を固定し、ハッシュを使用して uv.lock を再生成し、サプライ チェーン攻撃パターン用の CI ワークフロー スキャン PR を追加し、CVE を修正するために Deps を強化しました (#2796、#2810、 #2812、#2816、#3073)
  • Anthropic 出力制限の修正 — ハードコードされた 16K max_tokens をモデルごとのネイティブ出力制限 (Opus 4.6 では 128K、Sonnet 4.6 では 64K) に置き換え、直接 Anthropic API (#3426) での「応答切り捨て」と思考予算の枯渇を修正しました。 #3444)

🏗️ コアエージェントとアーキテクチャ

新しいプロバイダー: ハグフェイス

  • ファーストクラスのハグ顔推論 API と認証、セットアップ ウィザード、モデル ピッカーの統合 (#3419)
  • 厳選されたモデル リストのマッピング OpenRouter エージェントのデフォルトは HF 相当 — 8 つ以上の厳選されたモデルを持つプロバイダーは、速度のためにライブ /models プローブをスキップします (#3440)
  • Z.AI プロバイダー モデル リストに glm-5-turbo を追加 (#3095)

プロバイダーとモデルの改善

  • /model コマンドのオーバーホール - CLI およびゲートウェイ用に抽出された共有 switch_model() パイプライン、カスタム エンドポイント サポート、プロバイダー対応ルーティング (#2795、#2799)
  • hermes model サブコマンド (#3080) を優先して、CLI およびゲートウェイから /model スラッシュ コマンドを削除しました。
  • openrouter にサイレントに再マッピングするのではなく、custom プロバイダーを保持します (#2792)
  • ルートレベルの provider および base_url を config.yaml からモデル config に読み取ります (#3112)
  • Nous Portal モデルのスラッグを OpenRouter の命名に合わせます (#3253)
  • Alibaba プロバイダーのデフォルトのエンドポイントとモデルのリストを修正 (#3484)
  • MiniMax ユーザーが /v1 → /anthropic 自動修正をオーバーライドできるようにします (#3553)
  • OAuth トークンのリフレッシュをフォールバック付きで platform.claude.com に移行 (#3246)

エージェントのループと会話

  • OpenAI モデルの信頼性の向上 — GPT_TOOL_USE_GUIDANCE により、GPT モデルがツールを呼び出す代わりにアクションを記述することができなくなり、履歴から自動的に予算警告が削除されます (#3528)
  • ライフサイクル イベントの表示 - すべての再試行、フォールバック、および圧縮イベントが、フォーマットされたメッセージとしてユーザーに表示されるようになりました (#3153)
  • 人為的出力制限 — ハードコードされた 16K max_tokens (#3426) の代わりに、モデルごとのネイティブ出力制限を使用します。
  • 思考予算枯渇の検出 — モデルが推論ですべての出力トークンを使用する場合、無駄な継続再試行をスキップします (#3444)
  • サブエージェントのハングを防ぐために、API コールのストリーミングを常に優先します (#3120)
  • ストリーム障害後の安全な非ストリーミング フォールバックの復元 (#3020)
  • サブエージェントに独立した反復予算を与える (#3004)
  • サブエージェント認証用に _try_activate_fallback の api_key を更新 (#3103)
  • スレッドをクラッシュさせる代わりに最大再試行で正常に復帰 (タグなしコミット)
  • 再試行制限に向けてカウント圧縮が再開される (#3070)
  • プリフライト推定にツール トークンを含め、コンテキスト プローブの永続性を保護 (#3164)
  • フォールバックのアクティブ化後にコンテキスト コンプレッサーの制限を更新 (#3305)
  • Anthropic API 400 エラーを防ぐために空のユーザー メッセージを検証します (#3322)
  • GLM 推論のみおよび最大長の処理 (#3010)
  • 思考の遅いモデル向けに、API タイムアウトのデフォルトを 900 秒から 1800 秒に増やします (#3431)
  • Claude/OpenRouter に max_tokens を送信 + SSE 接続エラーを再試行 (#3497)
  • @ctlst によるゲートウェイ モードでの AsyncOpenAI/httpx クロスループ デッドロックの防止 (#2701)
