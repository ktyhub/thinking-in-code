エルメスエージェント v0.23.2

#エルメスエージェント v0.23.2

発売日: 2026 年 11 月 16 日

パッチリリース。このタグは、v0.23.1 以降、GitHub リリース (CLI およびインストーラー)、Microsoft Store アプリ、Docker、Hermes Cloud の安定リリースにマージされた ~1,989 の PR をロールアップします。このウィンドウ用に厳選された完全なメモが v0.24.0 に同梱されています。

<!-- エルメス_ビルド_テーブル -->

このリリースについて

コミット ae2a81ccc00 で測定したところ、v0.23.1 以降のウィンドウには、5,211 の変更されたファイル (+239,733 / −22,788) にわたる 7,918 の非マージ コミット、1,989 のマージされた PR、940 のクローズされた問題が含まれます。

また、ここでは意図的に文書化されていませんが、ウィンドウ内にあります: ゲートウェイの再起動またはクラッシュ後も存続し、独自の会話を続行できる耐久性のあるサブエージェント、セッションごとに 1 つのプロンプト キャッシュ クロック、フォールバック チェーンの準備のための hermes fallback check、ドレインではなくゲートウェイを一度に停止する hermes update --force、Telegram と Discord から入力された 1 回限りの browser_vault コード、共有 Telegram DM スレッドのオプトイン、Gemini Interactions のデフォルトの API Gemini 3 以降と Gemini 4 Carbon、Claude Mythos 5.2 の高速モード、ジョブごとの cron オプション (wrap_response、実行ごとの新しいスレッド)、新しいプラグイン API (ctx.fork_session、ctx.redact_text()、ctx.register_idle_task)、モジュールを移動しても更新が機能する互換性シム、初回使用時に Chromium をインストールするスリムな macOS バンドル、および新しいプラグイン カタログ エントリの大規模なバッチ。

このウィンドウ用に厳選された release note には v0.24.0 が同梱されており、これには v0.23.0 以降のすべて (ハイライト、特集エリア、完全な貢献者クレジット) が文書化されています。このウィンドウ内の何もスキップされません。

リリース候補で修正されました

  • ベア custom プロバイダーを使用した 8 月のビルドによって作成されたデスクトップ チャットは、更新後に再度送信できます (#156545)。
  • Todo またはメモリー呼び出しの横にストリーミングされたデスクトップまたは TUI 応答は、「停止」ボタンを押したままにするのではなく、解決されるようになりました (#156553)。
  • Telegram やその他の編集ストリーミング チャットでストリーム中にクラッシュしても、重複した「回復された返信」が表示されなくなりました。単語の途中にキー接頭辞を含む単語 (program_id) が再び定刻に表示されます (#156546)。
  • デスクトップが開始して最後のチャットを再開するときに、入力内容が失われたり混乱したりすることがなくなりました (#156615、#156642)。
  • 返信中に再接続すると、デスクトップには添付ファイルを含む返信が一度だけ表示されます (#156611)。
  • Web アプリで、このインストールが Nous Portal にサインインしていないときに Hermes Cloud エージェントを開くと、Web アプリのログインに送信されるのではなく、Nous Portal にサインインするように指示されるようになりました (#156652)。
  • GitHub での起動更新チェックの待機中に CLI を終了しても、git は実行されたままになりません (#156616)。

更新中

  • Microsoft Store アプリ: ストアを通じて更新します。
  • インストーラーからインストールされたデスクトップ アプリ (.exe / .dmg): このリリースでは変更はありません。次のバンドル リリースで更新されます。
  • CLI: hermes update、またはインストーラーのワンライナーを再実行します。
  • Docker / エルメスクラウド: nousresearch/hermes-agent:stable (または :latest)。
