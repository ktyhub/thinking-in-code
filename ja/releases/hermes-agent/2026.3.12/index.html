エルメスエージェント v2026.3.12

#エルメスエージェント v0.2.0(v2026.3.12) 発売日: 2026 年 3 月 12 日

v0.1.0 (初期の公開前の財団) 以来の最初のタグ付きリリース。コミュニティからの爆発的な貢献のおかげで、Hermes Agent はわずか 2 週間強で小さな社内プロジェクトからフル機能の AI エージェント プラットフォームに成長しました。このリリースでは、63 人の寄稿者からの 216 件のマージされたプル リクエストをカバーし、119 件の問題を解決しています。

✨ ハイライト

  • マルチプラットフォーム メッセージング ゲートウェイ — 統合されたセッション管理、メディア添付ファイル、およびプラットフォームごとのツール構成を備えた Telegram、Discord、Slack、WhatsApp、Signal、電子メール (IMAP/SMTP)、および Home Assistant プラットフォーム。
  • MCP (モデル コンテキスト プロトコル) Client — 標準入出力および HTTP トランスポート、再接続、リソース/プロンプト検出、およびサンプリング (サーバー開始の LLM リクエスト) によるネイティブ MCP サポート。 (#291 — @0xbyt4、#301、#753)
  • スキル エコシステム - コミュニティの検出、プラットフォームごとの有効化/無効化、ツールの可用性に基づく条件付きアクティベーション、および前提条件の検証のためのスキル ハブを備えた 15 以上のカテゴリにわたる 70 以上のバンドルおよびオプションのスキル。 (#743 — @teyrebaz33、#785 — @teyrebaz33)
  • 集中プロバイダー ルーター — 統合 call_llm()/async_call_llm() API は、ビジョン、要約、圧縮、および軌跡保存にわたって散在するプロバイダー ロジックを置き換えます。すべての補助コンシューマは、自動資格情報解決を使用して単一のコード パスを介してルーティングされます。 (#1003)
  • ACP サーバー — エージェント通信プロトコル標準を介した VS Code、Zed、および JetBrains エディターの統合。 (#949)
  • CLI スキン/テーマ エンジン — データ駆動型のビジュアル カスタマイズ: バナー、スピナー、色、ブランディング。 7 つの組み込みスキン + カスタム YAML スキン。
  • Git Worktree Isolation - hermes -w は、同じリポジトリ上で安全な並列作業を行うために、Git Worktree で分離されたエージェント セッションを起動します。 (#654)
  • ファイルシステムのチェックポイントとロールバック — /rollback による破壊的な操作を復元する前の自動スナップショット。 (#824)
  • 3,289 テスト — ほぼゼロのテスト カバレッジから、エージェント、ゲートウェイ、ツール、cron、CLI をカバーする包括的なテスト スイートまで。
