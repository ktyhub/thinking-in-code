エルメスエージェント v2026.4.3

#エルメスエージェント v0.7.0(v2026.4.3) 発売日: 2026 年 4 月 3 日

復元力のリリース — プラグイン可能なメモリ プロバイダー、認証情報プールのローテーション、Camofox 検出防止ブラウザ、インライン差分プレビュー、競合状態と承認ルーティング全体にわたるゲートウェイの強化、168 の PR と 46 の解決済みの問題にわたる徹底したセキュリティ修正。

✨ ハイライト

  • プラグイン可能なメモリ プロバイダー インターフェイス — メモリは拡張可能なプラグイン システムになりました。サードパーティのメモリ バックエンド (Honcho、ベクター ストア、カスタム DB) は、単純なプロバイダー ABC を実装し、プラグイン システム経由で登録します。内蔵メモリがデフォルトのプロバイダです。 Honcho 統合は、プロファイル スコープのホスト/ピア解決を備えたリファレンス プラグインと完全に同等に復元されました。 (#4623、#4616、#4355)
  • 同一プロバイダー資格情報プール — 自動ローテーションを使用して、同じプロバイダーの複数の API キーを構成します。スレッドセーフな least_used 戦略により、キー全体に負荷が分散され、401 エラーが発生すると、次の資格情報への自動ローテーションがトリガーされます。セットアップ ウィザードまたは credential_pool 構成を使用してセットアップします。 (#4188、#4300、#4361)
  • Camoufox 検出防止ブラウザ バックエンド — ステルス ブラウジングに Camoufox を使用する新しいローカル ブラウザ バックエンド。視覚的なデバッグのための VNC URL 検出による永続セッション、ローカル バックエンドの構成可能な SSRF バイパス、hermes tools による自動インストール。 (#4008、#4419、#4292)
  • インライン差分プレビュー — ファイルの書き込みおよびパッチ操作では、ツール アクティビティ フィードにインライン差分が表示されるようになり、エージェントが次に進む前に何が変更されたかを視覚的に確認できるようになりました。 (#4411、#4423)
  • API サーバー セッションの継続性とツール ストリーミング - API サーバー (Open WebUI 統合) は、ツールの進行状況イベントをリアルタイムでストリーミングし、リクエスト全体にわたる永続的なセッションの X-Hermes-Session-Id ヘッダーをサポートするようになりました。セッションは共有 SessionDB に保持されます。 (#4092、#4478、#4802)
  • ACP: Client 提供の MCP サーバー — エディター統合 (VS Code、Zed、JetBrains) で独自の MCP サーバーを登録できるようになり、Hermes は追加のエージェント ツールとして選択します。エディターの MCP エコシステムはエージェントに直接流れ込みます。 (#4705)
  • ゲートウェイの強化 — 競合状態、写真メディアの配信、フラッド コントロール、スタック セッション、承認ルーティング、および圧縮デス スパイラルにわたる主要な安定性。ゲートウェイは実稼働環境での信頼性が大幅に向上します。 (#4727、#4750、#4798、#4557)
  • セキュリティ: シークレット漏洩のブロック - ブラウザの URL と LLM 応答でシークレット パターンがスキャンされ、URL エンコード、base64、またはプロンプト インジェクションによる漏洩の試みがブロックされるようになりました。資格情報ディレクトリの保護が .docker、.azure、.config/gh に拡張されました。 Execute_code サンドボックスの出力は編集されています。 (#4483、#4360、#4305、#4327)
