エルメスエージェント v2026.4.13

#エルメスエージェント v0.9.0(v2026.4.13) 発売日: 2026 年 4 月 13 日 v0.8.0 以降: コミット数 487 · マージされた PR 269 · 解決された問題 167 · 変更されたファイル 493 · 挿入 63,281 · 貢献者 24

どこでもリリース — Hermes は Termux/Android でモバイル化し、iMessage と WeChat を追加し、OpenAI と Anthropic の高速モードを搭載し、バックグラウンド プロセス監視を導入し、エージェントを管理するためのローカル Web ダッシュボードを起動し、サポートされている 16 のプラットフォームにわたってこれまでで最も深いセキュリティ強化パスを提供します。

✨ ハイライト

  • ローカル Web ダッシュボード — Herme エージェントをローカルで管理するための新しいブラウザベースのダッシュボード。設定の構成、セッションの監視、スキルの参照、ゲートウェイの管理はすべて、構成ファイルやターミナルに触れることなく、きれいな Web インターフェイスから行うことができます。エルメスを始める最も簡単な方法。
  • 高速モード (/fast) — OpenAI および Anthropic モデルの優先処理。 /fast を切り替えて、サポートされているモデル (GPT-5.4、Codex、Claude) での待ち時間を大幅に短縮するために優先キューを介してルーティングします。すべての OpenAI Priority Processing モデルと Anthropic の高速層にわたって拡張されます。 (#6875、#6960、#7037)
  • BlueBubbles を介した iMessage — BlueBubbles を介した iMessage の完全な統合により、Hermes が Apple のメッセージング エコシステムに加わります。自動 Webhook 登録、セットアップ ウィザードの統合、およびクラッシュ耐性。 (#6437、#6460、#6494)
  • WeChat (Weixin) および WeCom コールバック モード - iLink ボット API を介したネイティブ WeChat サポートと、自社構築エンタープライズ アプリ用の新しい WeCom コールバック モード アダプター。ストリーミング カーソル、メディア アップロード、マークダウン リンク処理、およびアトミック状態の永続化。エルメスは現在、中国のメッセージング エコシステムをエンドツーエンドでカバーしています。 (#7166、#7943)
  • Termux / Android サポート — Termux を介して Android 上で Herme をネイティブに実行します。適応されたインストール パス、モバイル画面用の TUI 最適化、音声バックエンドのサポート、およびデバイス上で動作する /image コマンド。 (#6834)
  • バックグラウンド プロセスの監視 (watch_patterns) - バックグラウンド プロセスの出力で監視するパターンを設定し、一致した場合にリアルタイムで通知を受け取ります。エラーを監視したり、特定のイベントを待機したり (「ポートでの待機」)、ビルド ログを監視したりできます。これらはすべてポーリングなしで実行できます。 (#7635)
  • ネイティブ xAI および Xiaomi MiMo プロバイダー — 直接 API アクセス、モデル カタログ、セットアップ ウィザードの統合を備えた、xAI (Grok) および Xiaomi MiMo のファーストクラス プロバイダー サポート。さらに、ポータル リクエストのサポートを備えた Qwen OAuth。 (#7372、#7855)
  • プラグイン可能なコンテキスト エンジン — コンテキスト管理は、hermes plugins を介してプラグイン可能なスロットになりました。フィルタリング、要約、ドメイン固有のコンテキスト インジェクションなど、エージェントが各ターンに表示する内容を制御するカスタム コンテキスト エンジンを交換します。 (#7464)
  • 統合プロキシ サポート - すべてのゲートウェイ プラットフォームにわたる SOCKS プロキシ、DISCORD_PROXY、およびシステム プロキシの自動検出。企業ファイアウォールの背後にある Hermes は正常に機能します。 (#6814)
  • 包括的なセキュリティ強化 — チェックポイント マネージャーでのパス トラバーサル保護、サンドボックス書き込みでのシェル インジェクションの無効化、Slack イメージ アップロードでの SSRF リダイレクト ガード、Twilio Webhook 署名の検証 (SMS RCE 修正)、API サーバー認証の強制、git 引数インジェクションの防止、および承認ボタンの承認。 (#7933、#7944、#7940、#7151、#7156)
  • hermes backup および hermes import — ヘルメスの設定、セッション、スキル、メモリの完全なバックアップと復元。大きな変更を行う前に、マシン間を移行するか、スナップショットを作成します。 (#7997)
  • 16 のサポート対象プラットフォーム — Telegram、Discord、Slack、WhatsApp、Signal、Matrix、Email、SMS、DingTalk、Feishu、WeCom、Mattermost、Home Assistant、Webhooks に BlueBubbles (iMessage) と WeChat が加わり、Hermes はすぐに 16 のメッセージング プラットフォームで動作するようになりました。
  • /debug および hermes debug share — 新しいデバッグ ツールキット: 迅速な診断のためのすべてのプラットフォームにわたる /debug スラッシュ コマンドに加え、トラブルシューティング時に簡単に共有できるように完全なデバッグ レポートをペーストビンにアップロードするための hermes debug share。 (#8681)
