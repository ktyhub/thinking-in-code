エルメスエージェント v2026.3.23

#エルメスエージェント v0.4.0(v2026.3.23) 発売日: 2026 年 3 月 23 日

プラットフォーム拡張リリース — OpenAI 互換の API サーバー、6 つの新しいメッセージング アダプター、4 つの新しい推論プロバイダー、OAuth 2.1 による MCP サーバー管理、@ コンテキスト参照、ゲートウェイ プロンプト キャッシュ、デフォルトで有効になっているストリーミング、および 200 以上のバグ修正を含む包括的な信頼性パス。

✨ ハイライト

  • OpenAI 互換の API サーバー — cron ジョブ管理用の新しい /api/jobs REST API を使用して、Hermes を /v1/chat/completions エンドポイントとして公開します。入力制限、フィールド ホワイトリスト、SQLite ベースの応答永続性、CORS オリジン保護 (#1756、#2450、 #2456、#2451、#2472)
  • 6 つの新しいメッセージング プラットフォーム アダプター - Signal、DingTalk、SMS (Twilio)、Mattermost、Matrix、Webhook アダプターが Telegram、Discord、WhatsApp に加わりました。ゲートウェイは、指数バックオフを使用して障害が発生したプラットフォームを自動再接続します (#2206、#1685、#1688、#1683、#2166、#2584)
  • @ コンテキスト参照 — CLI のタブ補完によるクロード コード スタイルの @file および @url コンテキスト インジェクション (#2343、#2482)
  • 4 つの新しい推論プロバイダー — GitHub Copilot (OAuth + トークン検証)、Alibaba Cloud / DashScope、Kilo Code、OpenCode Zen/Go (#1924、#1879 by @mchzimm、#1673、 #1666、#1650)
  • MCP サーバー管理 CLI — 完全な OAuth 2.1 PKCE フローを使用して MCP サーバーをインストール、構成、認証するための hermes mcp コマンド (#2465)
  • ゲートウェイ プロンプト キャッシュ — セッションごとに AIAgent インスタンスをキャッシュし、ターン全体で Anthropic プロンプト キャッシュを保持することで、長い会話のコストを大幅に削減します (#2282、#2284、#2361)
  • コンテキスト圧縮のオーバーホール — 反復更新、トークンバジェットテール保護、構成可能なサマリーエンドポイント、およびフォールバックモデルのサポートを備えた構造化サマリー (#2323、#1727、#2224)
  • デフォルトでストリーミングが有効になっています - CLI ストリーミングはデフォルトでオンになり、ストリーミング モード中に適切なスピナー/ツールの進行状況が表示されます。さらに、広範囲にわたる改行と連結の修正 (#2340、#2161、#2258)

🖥️ CLI とユーザー エクスペリエンス

新しいコマンドとインタラクション

  • @ context completed — ファイル コンテンツまたは Web ページを会話に挿入する、タブ補完可能な @file/@url 参照 (#2482、#2343)
  • /statusbar — プロンプトにモデル + プロバイダー情報を表示する永続的な構成バーを切り替えます (#2240、#1917)
  • /queue — 現在の実行を中断せずにエージェントのプロンプトをキューに追加します (#2191、#2469)
