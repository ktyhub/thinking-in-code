エルメスエージェント v2026.4.8

#エルメスエージェント v0.8.0(v2026.4.8) 発売日: 2026 年 4 月 8 日

インテリジェンス リリース — バックグラウンド タスクの自動通知、Nous Portal 上の無料の MiMo v2 Pro、すべてのプラットフォームにわたるライブ モデルの切り替え、自己最適化 GPT/Codex ガイダンス、ネイティブ Google AI Studio、スマートな非アクティブ タイムアウト、承認ボタン、MCP OAuth 2.1、および 82 件の解決済みの問題を含む 209 のマージ PR。

✨ ハイライト

  • バックグラウンド プロセスの自動通知 (notify_on_complete) - バックグラウンド タスクが完了すると、エージェントに自動的に通知できるようになりました。長時間実行プロセス (AI モデルのトレーニング、テスト スイート、デプロイ、ビルド) を開始すると、エージェントは完了時に通知を受け取ります。ポーリングは必要ありません。エージェントは他の作業を続けて、着陸時に結果を得ることができます。 (#5779)
  • Nous Portal で Xiaomi MiMo v2 Pro を無料 — Nous Portal は、補助タスク (圧縮、ビジョン、要約) 用に無料層 Xiaomi MiMo v2 Pro モデルをサポートし、モデル選択での無料層モデルのゲートと価格表示を備えています。 (#6018、#5880)
  • ライブ モデル スイッチング (/model コマンド) — CLI、Telegram、Discord、Slack、または任意のゲートウェイ プラットフォームからセッション中にモデルとプロバイダーを切り替えます。アグリゲーター対応の解決策により、可能な場合は OpenRouter/Nous を使用し続け、必要に応じて自動的にクロスプロバイダー フォールバックが行われます。 Telegram と Discord のインライン ボタンを備えたインタラクティブなモデル ピッカー。 (#5181、#5742)
  • 自己最適化された GPT/Codex ツール使用ガイダンス - エージェントは、自動動作ベンチマークを通じて GPT および Codex ツール呼び出しの 5 つの障害モードを診断してパッチを適用し、OpenAI モデルの信頼性を劇的に向上させました。実行規律のガイダンスと、構造化された推論のための思考のみの事前入力の継続が含まれています。 (#6120、#5414、#5931)
  • Google AI Studio (Gemini) ネイティブ プロバイダー — Google の AI Studio API を介して Gemini モデルに直接アクセスします。あらゆるプロバイダーにわたるリアルタイムのコンテキスト長検出のための自動models.devレジストリ統合が含まれています。 (#5577)
  • 非アクティブ ベースのエージェント タイムアウト - ゲートウェイと cron のタイムアウトは、実時間ではなく実際のツールのアクティビティを追跡するようになりました。アクティブに動作している長時間実行タスクが強制終了されることはありません。本当にアイドル状態のエージェントのみがタイムアウトします。 (#5389、#5440)
  • Slack と Telegram の承認ボタン — /approve と入力する代わりに、ネイティブ プラットフォーム ボタンを介して危険なコマンドを承認します。 Slack ではスレッド コンテキストが保存されます。 Telegram は承認ステータスの絵文字リアクションを取得します。 (#5890、#5975)
  • MCP OAuth 2.1 PKCE + OSV マルウェア スキャン — MCP サーバー認証用の完全標準準拠の OAuth に加え、OSV 脆弱性データベースを介した MCP 拡張パッケージの自動マルウェア スキャン。 (#5420、#5305)
  • 一元的なログと構成の検証 - テーリングとフィルタリングのための hermes logs コマンドを使用した、~/.hermes/logs/ (agent.log +errors.log) への構造化ログ。構成構造の検証により、不可解なエラーが発生する前に、起動時に不正な YAML が検出されます。 (#5430、#5426)
  • プラグイン システムの拡張 — プラグインは、CLI サブコマンドを登録し、相関 ID を持つリクエスト スコープの API フックを受け取り、インストール中に必要な環境変数の入力を求め、セッション ライフサイクル イベント (ファイナライズ/リセット) にフックできるようになりました。 (#5295、#5427、#5470、#6129)
  • Matrix Tier 1 とプラットフォームの強化 — Matrix は、反応、開封確認、リッチ フォーマット、およびルーム管理を取得します。 Discord では、チャンネル コントロールと無視されるチャンネルが追加されます。 Signal は完全な MEDIA: タグ配信を取得します。 Mattermost は添付ファイルを取得します。すべてのプラットフォームにわたる包括的な信頼性の修正。 (#5275、#5975、#5602)
  • セキュリティ強化パス — 統合された SSRF 保護、タイミング攻撃の軽減、tar トラバーサル防止、資格情報漏洩ガード、cron パス トラバーサルの強化、およびクロスセッション分離。すべてのバックエンドにわたるターミナル workdir のサニタイズ。 (#5944、#5613、#5629)
