エルメスエージェント v2026.9.24

#エルメスエージェント v0.21.5(v2026.9.24)

発売日: 2026 年 9 月 24 日

パッチリリース。このタグは、v0.21.4 以降にマージされた約 460 の PR を、ダウンストリーム コンシューマー (Docker イメージ、Hermes Cloud、ホストされた展開) 向けの安定したタグ付きリリースにロールアップします。このウィンドウの完全に厳選されたメモは、v0.22.0 まで延期されます。

このリリースについて

コミット f97608f178d1ffeca59860195ab7da295f7c8e5f で測定した場合、v0.21.4 以降のウィンドウには、4,828 個の変更されたファイル (+164,132 / −149,440) にわたる 1,610 個の非マージ コミット、460 個のマージされた PR、475 個のクローズされた問題が含まれます。

またウィンドウ内にありますが、ここでは意図的に文書化されていません: デスクトップ プラグイン SDK ウェーブ (コンポーザー ドラフト API、セッション リストと行装飾スロット、サイドバー ナビゲーション プリファレンス、モデル ピル ラベル プロバイダー、型指定された設定/スキル/ツールセット/プロファイル ブリッジ、サンドボックス埋め込みプリミティブ、外観設定スロット、およびプラグイン バックエンド用のパブリック イベント ブリッジ)。デスクトップ用のシンプル/アドバンストインターフェイスモード。コネクタ ページでは MCP タブが置き換えられ、新しくインストールされたプラグインの MCP サーバーとインストールされたプラグインのツールとスキルがすべてのオープン チャットでライブになるための [今すぐ接続] が表示されます。コネクタのほかにカタログ プラグインを提供するオンボーディング。フランス語、ドイツ語、スペイン語の完全なデスクトップ カタログに加え、RTL/LTR テキスト方向設定。コンポーザーと設定ピッカーからのカスタム モデル エントリ。ファンクションキーとディクテーション音声ショートカット。ホスト マルチプレクサおよび gateway.standalone でプロファイルごとに停止/開始/再起動し、プロファイルをオプトアウトします。立っている /goal と、CLI および TUI のキューに入れられたプロンプトを示すライブ ドック。 2 列のチケットモーダルとマークダウンタスクテキストを含むカンバンデザインパス。 Webhook 配信はターゲット チャット セッションにミラーリングされます。ホストされた -desktop 画像上のボット画面。 Nous および OpenRouter カタログの GPT-6 Sol/Terra/Luna および Claude Opus 5.5。公式の Blender Lab 統合と NVIDIA アプリ/ブロードキャスト プラグイン。構成の読み込み、ツール レジストリ、ゲートウェイ メッセージ処理、モデル ピッカーにわたるホットパス パフォーマンス作業の長時間実行。カタログには多数の新しいコミュニティ プラグインが含まれています。

このウィンドウ用に厳選された release note には v0.22.0 が同梱されており、v0.21.0 以降のすべて (ハイライト、特集エリア、完全な貢献者クレジット) が文書化されます。このウィンドウ内の何もスキップされません。

更新中

  • hermes update (git installs)、またはインストーラーのワンライナーを再実行します。
  • Docker / Hermes Cloud: 画像はこのタグ (nousresearch/hermes-agent:v2026.9.24) から構築されます。
