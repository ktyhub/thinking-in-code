エルメスエージェント v2026.6.5

#エルメスエージェント v0.16.0(v2026.6.5) 発売日: 2026 年 6 月 5 日 v0.15.2 以降: コミット数 874 · マージされた PR 542 · 変更されたファイル 1,962 · 挿入 205,216 · 削除 46,217 · クローズされた問題 399 件 (P0 2 件、P1 62 件、セキュリティタグ付き 16 件) · コミュニティ貢献者 170 名 (共著者を含む)

Surface リリース。 エルメスはどこで働いていてもあなたに会えます。 1 週間で 100 の PR と 159 のコミットにわたって構築された真新しいネイティブ デスクトップ アプリは、実際の macOS/Linux/Windows アプリケーションとしての Herme を提供します。click 1 回のインストール、アプリ内自己更新、チャットへのファイルのドラッグ アンド ドロップ、ステータス バーのインライン モデル ピッカー、同時マルチプロファイル セッション、完全な簡体字中国語翻訳、および OAuth 経由でリモートの Herme ゲートウェイに接続する機能や、ユーザー名/パスワード。これに加えて、Web ダッシュボードには完全なブラウザベースの管理パネル (MCP カタログ、メッセージング チャネル、資格情報、Webhook、メモリ、プラグイン可能な OIDC / ユーザー名とパスワードのログイン) が追加され、初回セットアップには、インストールから最初のメッセージまで数秒で完了できる「Nous Portal 経由のクイック セットアップ」パスが追加されました。デフォルトのスキル セットは実際に必要なものに合わせてトリミングされ、NVIDIA/スキルが trusted スキル ハブ タップに追加され、モデル ピッカーはどこでも (デスクトップ、Web、TUI、CLI) あいまい検索可能になり、ついに /undo で最後の N ターンを取り戻すことができるようになりました。 2 つの P0 および 62 の P1 クロージャーに加えて、セキュリティ ラウンド (CVE-2026-48710 Starlette ピン、SSRF オフループ強化、サブプロセス資格情報のストリッピング) が適用されます。

✨ ハイライト

  • Hermes デスクトップ — ターミナル ラッパーではなく、本物のネイティブ アプリ — これが見出しです。 apps/desktop/ Electron アプリケーションが登場しました。これは、他のデスクトップ アプリと同じように macOS、Linux、Windows にインストールされ、アプリ内から自動的に更新され、Hermes のすべての機能に洗練された GUI を提供します。ストリーミング機能を備えた適切なチャット ウィンドウ、アーカイブと検索が可能なセッション リスト、チャット エリアのどこにでもファイルをドラッグ アンド ドロップ、clipboard 画像の貼り付け、Cmd+K コマンド パレット、ステータス バーのモデル ピッカーが表示されます。友人に「これは CLI エージェントです」と話し、彼らの目を曇らしているのを眺めていたなら、今ならインストーラーを送るだけで済みます。 1週間前にはこんなことは存在しませんでした。 (#20059、#35607、#37099、#37379、#38631 — @OutThisLife、@jquesnelle、@ethernet8023、@austinpickett、 @ベンバークレー)
  • リモートのHermesに対してデスクトップ アプリを実行します — OAuth またはユーザー名/パスワードを使用してサインインします — デスクトップ アプリはHermesをローカルで実行する必要はありません。リモートの Herme ゲートウェイ (ホームラボ、ホストされたボックス、チームメイトのサーバー) に接続すると、安全な WebSocket 経由で接続し、OAuth またはユーザー名/パスワードによるログインで認証します。--insecure フラグや手動でコピーしたセッション トークンをいじる必要はありません。各プロファイルは独自のリモート ホストをターゲットにすることができ、プロファイル間 @session リンクを使用して 1 つのウィンドウで複数のプロファイル間で同時セッションを実行できます。実用的なバージョン: ラップトップはシン GUI を実行し、重いエージェントは API キーとコンピューティングが稼働している場所であればどこでも実行します。 (#37888、#38851、#39330、#39778 — @benbarclay、@OutThisLife、@teknium1)
  • Web ダッシュボードが完全な管理パネルになりました - ブラウザからすべてを設定 - ダッシュボードは、「セッションの表示」から完全な管理画面に成長しました。ブラウザーからすべてのゲートウェイ メッセージング プラットフォーム (Telegram、Discord、Slack など) を設定するチャネル ページ、有効/無効の切り替え、資格情報の管理、Webhook とフックの作成、メモリ構成、ゲートウェイ コントロールを備えた MCP カタログの管理パネル、更新前チェックと 1 つの click デバッグ共有を備えたシステム ページがあります。新しいメッセージング チャネルまたは MCP サーバーを接続するために SSH 接続して config.yaml を編集する必要はなくなりました。すべてポイント アンド click で行うことができます。 (#36704、#36736、#37211、#38205、#38600 — @teknium1)
  • Hermes デスクトップは簡体字中国語を話します — チャット GUI では完全な简体中文 — デスクトップ アプリでは、チャット ウィンドウ自体、サイドバー、設定、コマンド センター、cron、メッセージング、プロファイル、スキル、エージェントなど、すべての UI サーフェスにわたって完全な簡体字中国語 (简体中文) 翻訳が提供されるようになりました。英語がデフォルトのままです。外観設定で言語を切り替えると、選択は設定に維持されます (display.language)。これは適切に型指定された i18n レイヤー上に構築されているため、ここからさらに言語を追加するのは簡単です。 (#38241 — @JimLiu)
  • 無駄のないデフォルトのスキルセット — Hermes は実際に必要なものだけを同梱しています — バンドルされたスキルセットは意図的にトリミングされています。冗長または廃止されたスキルはなくなりました (spotify — ネイティブ Spotify プラグインの 7 ツールに置き換えられました。linear — hermes mcp install linear に置き換えられました。kanban-codex-lane、debugging-hermes-tui-commands、古い domain 孤立、およびいくつかの空のカテゴリ マーカー)。より高度なスキルまたはニッチなスキルがバンドルからオプション (Baoyu クリエイティブ セット、dspy、subagent-driven-development、minecraft-modpack-server、pokemon-player、hermes-s6-container-supervision) に移行しました。あと 1 hermes skills install ですが、デフォルトでロードされていないだけです。また、新しい environments: 関連ゲートは、コンテキスト固有のスキル (カンバン、docker/s6) を、明示的な要求に応じてロードしながら、決して使用しないユーザーのスキル インデックスから除外します。その結果、デフォルトのスキルリストがより小さく、より明確になり、ピッカーのノイズが減り、プロンプトが軽くなります。キュレーターは、未使用の 組み込み スキル (エージェントが作成したスキルだけでなく) もプルーニングできるようになり、スキルごとに使用状況が追跡されます。 (#39028、#36701、#36228 — @teknium1)
  • NVIDIA/スキルは、組み込みの trusted スキル タップになりました - NVIDIA/skills は、スキル ハブのデフォルトの trusted タップとして OpenAI、Anthropic、および HuggingFace に加わりました - 同じパイプラインを通じて検出可能、参照可能、検索可能、自動更新可能です。 CUDA-X、AIQ、cuOpt およびその他の製品スタックに対する NVIDIA の検証済みスキルは、リポジトリの skills.sh.json サイドカーからの実際のカテゴリ ラベルを使用して 1 回のインストールで入手できます。 (#34333 — @teknium1)
  • Nous Portal によるクイック セットアップ — インストールから最初のメッセージまで数秒で完了 — 初回セットアップは、クイック セットアップ (Nous Portal でサインイン、モデル ピッカーを取得、すぐにチャットを開始) またはフル セットアップ (パワー ユーザー向けの詳細なウィザード) の 2 つの明確なパスに絞り込まれました。 hermes portal は、完全なクイック セットアップ Nous フローを実行する、人間が判読できるエイリアスになりました。初回実行メニューでは違いがインラインで説明されているため、初心者が推測することはありません。目標は、まったく新しいユーザーが最初のメッセージを送信するためにドキュメントを読む必要がないようにすることです。 (#35723、#36227、#38449、#38465 — @teknium1、@kshitijk4poor)
  • どこでもファジー モデル ピッカー - いくつかの文字を入力してモデルを検索 - モデル ピッカーは、デスクトップ アプリ、Web ダッシュボード、TUI、および CLI 全体でファジー検索を実行するようになりました。 「v4fl」および deepseek-v4-flash サーフェスを入力します。マルチエンドポイント プロバイダーは、リストが重複して乱雑になるのではなく 1 行にグループ化されており、各行には説明が含まれているため、何を選択しているかがわかります。カタログは毎日ではなく 1 時間ごとに更新されるため、新しいモデルは発売と同じ日に表示されます。新しいウィンドウ: deepseek-v4-flash、1M コンテキストの MiniMax-M3、qwen3.7-plus。 (#36928、#35227、#35756、#35659、#36214 — @kshitijk4poor、@teknium1)
  • /undo [N] — 最後の N ターンを取り戻します — 間違ったことを言いましたか、それともエージェントを悪い道に送りましたか? /undo は N 件のユーザー ターンをバックアップし、編集して再送信できるように最後のメッセージを事前入力し、その間のターンをソフト削除します。 CLI、TUI、およびメッセージング プラットフォーム (Telegram、Discord など) で完全に同等に動作します。長期にわたるリクエスト (#21910) をクローズします。 (#36229、#36699 — @teknium1)
  • デフォルト インターフェイスの選択 — cli または tui — hermes chat がデフォルトでクラシック CLI に移行するか、Ink TUI に移行するかを設定できるようになりました。--cli フラグを使用して呼び出しごとにオーバーライドします。 TUI には、単一の統合された /model コマンドと、ライブ セッション間を切り替えるためのセッション オーバーレイも追加されました。実際に気に入ったインターフェイスを使用してください。 (#37782、#37112 — @OutThisLife)

  • 代表団 max_spawn_depth のキャップを解除します (フロア 1、天井なし)。ヘルメスの自己知識のポインタをドキュメント + スキルに広げます。 hermes prompt-size 診断 (#39772、#38538、#35276 — @teknium1)
  • perf(read_file): コンパクトな行番号ガッター — 読み取りあたりのトークンが最大 14% 減少 (現在は唯一の形式) (#35368、#35532 — @teknium1)
  • 1 つのリーダーを介して TERMINAL_CWD からのエージェント cwd を解決します。プレフィルメッセージのキー処理を調整します。セッションの元の作業ディレクトリで再開を再開します (#35028 — @banditburai、#38760 — @helix4u、#38562 — @teknium1)
  • セッション ID フォークによる同時圧縮を防止します。オブザーバー テレメトリ フック + NeMo-Relay プラグイン (ゲート ツール エミット) (#34351、#38232 — @teknium1)

セッション、状態、メモリ

  • perf(state): VACUUM + hermes sessions optimize で FTS5 セグメントをマージします。親が再度開いた後も、/branch セッションを表示したままにします。欠落している FTS5 ランタイムで生き残る (#34596、#39214 — @teknium1、@kshitijk4poor、#35452 — @helix4u)
  • Honcho: スタートアップをフェールオープンにします。自己ホスト型セットアップ パスを強化します (#24847 — @stephenschoettler、#35170 — @kshitijk4poor)
  • スーパーメモリ: セッションレベルの取り込み + Kebab エイリアス (#38756 — @alt-glitch)

🖥️ CLI、TUI とセットアップ

  • 設定可能なデフォルト インターフェイス (cli 対 tui) + --cli フラグ。 TUI 単一 /model コマンド + 統合セッション オーバーレイ。委任の開始時に /agents ダッシュボードに向かってナッジします (#37782、#37112 — @OutThisLife、#34704 — @kshitijk4poor)
  • 間引きセットアップ — Nous ポータル経由のクイック セットアップ + フル セットアップのデフォルト。クイックとフルをインラインで説明します。 hermes portal 人間が読めるポータル オンボーディング エイリアス + 完全なクイック セットアップ Nous フロー (#35723、#36227、#38449、#38465 — @teknium1、@kshitijk4poor)
  • ps/top/htop でプロセス タイトルを hermes に設定します。サポートされていない pip インストールについて警告 + 古い更新チェック キャッシュを修正 (#35143、#34846 — @teknium1)
  • TUI パフォーマンス: 遅い/停止している MCP サーバーの起動がフリーズするのを防ぎます。積極的な MCP 検出がエージェント対応の起動をブロックするのを防ぎます。トレイル行での完全なツール出力の永続化を停止 (サイレント OOM) (#35273、#35397、#38224 — @teknium1)
  • TUI の修正: ゲートウェイが予期せず停止した場合のセッションの自動回復。分割された SGR マウス配列を再構築します。 PowerShell clipboard で UTF-8 を保持します。終了時に端子入力モードをリセットします。エルメスの家の下の /save スナップショット (#35893、#38564 — @OutThisLife、#35222 — @teknium1、#36864 — @maxmilian、#38251 — @オースティンピケット)
  • セットアップ モデル/プロバイダー ピッカーは simple_term_menu から Curses に移行されました (ESC + ゴースト行の修正)。デフォルトのブラウザ/TTS ピッカーは、Nous の支払いではなく、ローカル バックエンドを解放します (#35806、#37800 — @teknium1)

🔧 ツール システムとインストーラー

  • single managed-uv path、fts5 インストーラー エスカレーションを削除。インストーラーコミットピンニングオプトイン (デフォルトのブランチフォロー);浅いクローン (#37660 — @ethernet8023、#37123 — @jquesnelle、#39423 — @ethernet8023)
  • ensure_uv() は更新境界を越えて存続します (初回実行時のクラッシュはありません)。 venv の再構築を強化し、インストール後にコア deps を確認します。破壊的クリーンの前にマネージド マーカーが必要。非対話型更新の場合はデフォルトでスタッシュ/復元 (#39780 — @OutThisLife、#38887、#39568、#39645 — @teknium1、@helix4u)
  • MCP: トークンが取得されなかった場合に、誤った OAuth 成功の報告を停止します。ビジョンは vision_analyze + browser_vision で model.supports_vision を尊重します。 MiniMax t2a_v2 TTS raise_for_status (#34807、#34562、#39057 — @teknium1)
  • 元宝: resourceId ごとに解決されたメディア リソースをキャッシュ (#34474 — @teknium1)

🐳 Docker と展開

  • コンテナの再利用 + 境界同期クリーンアップ + 孤立したリーパー。 docker-in-docker バックエンドの Docker ソケット グループに自動参加します。非ルートコンテナを起動します (すでに特権が付与されていない場合は s6-setuidgid ドロップをスキップします) (#33645、#34407 — @benbarclay、#34837 — @IAvecilla)
  • ボリュームの所有権が再マッピングされた UID と一致する場合、不要なブート chown をスキップします。最初の起動時に HERMES_GATEWAY_BOOTSTRAP_STATE から gateway_state.json をシードします。コンテナに識別用の hermes-agent ラベルを付けます (#35027 — @Foldblade、#37896 — @benbarclay)
  • HERMES_TUI_DIR 経由で TUI ランチャーを事前構築済みバンドルにポイントします。ノード/nix ワークスペースのロックファイルを統合 + すべてのコンシューマーを更新 (#37923、#36171 — @benbarclay、@ethernet8023)

🔒 セキュリティと信頼性

  • CVE-2026-48710 (Starlette BadHost) — ピンパッチされた Starlette ≥1.0.1 (#35118 — @teknium1)
  • URL SSRF を実行すると、非同期パスのイベント ループがチェックオフされます。 Bedrock 推論ベアラー トークンをサブプロセス環境から削除します。ファイル安全読み取りガードに bws_cache.json を追加します。 Mutation-verifier フッターのファイル パスを無効化します (#39046、#34498、#34421、#35684 — @teknium1)
  • execute_code + ガード エントリ ポイントの承認/sudo コンテキストを復元します。 docker の再起動/停止/強制終了を DANGEROUS_PATTERNS に追加します。精査されたスキルコンテンツ内の目に見えない Unicode をサニタイズします。インプレース xAI 突然変異前のディープコピー ツール (#34497、#33438 — @teknium1、@Sarbai、#37245、#34416)
  • タスクごとの .hermes ミラーへの書き込みに対するサンドボックス ミラー ソフト ガード。起動時の honcho フェールオープン (#32213 — @briandevans、#24847 — @stephenschoettler)

🐛 注目すべきバグ修正

  • このウィンドウでは 399 件の問題がクローズされました (P0 2 件、P1 62 件、セキュリティタグ付き 16 件、バグラベル付き 262 件)。
  • デスクトップ: 更新時に進行中の新しいチャットが消えないようにします。停止ボタンは、ターンがキューに入れられているときに実際に中断します。バックグラウンド セッション メッセージがアクティブなトランスクリプトに流れ込むのを防ぎます。スラッシュ/@ 補完メニューに移動可能、Esc キーを押しながら閉じることが可能。 IME Enter でメッセージが分割されなくなりました (#37908 — @OutThisLife、#37948、#37975、#37937 — @kshitijk4poor、#38333 — @stremtec)
  • 更新: 管理対象クローン上のデスクトップ ソースを破壊することによるスタッシュ/復元を停止します。再構築中の venv でデスクトップの再構築/スキルの同期に失敗しないようにします。ランチャー virtualenv を UV にエクスポート (#38542、#38885、#35224 — @teknium1)
  • 音声: PortAudio フォールバックで PIPEWIRE_REMOTE を尊重します。サウンド サーバーに到達可能な場合は、SSH 経由で /voice を許可します。ミストラライの復元 (2.4.8 クリーン、禁止解除) (#33473 — @Dusk1e、#35719、#34841 — @teknium1)
