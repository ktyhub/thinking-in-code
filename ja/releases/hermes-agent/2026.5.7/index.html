エルメスエージェント v2026.5.7

#エルメスエージェント v0.13.0(v2026.5.7) 発売日: 2026 年 5 月 7 日 v0.12.0 以降: コミット数 864 · マージされた PR 588 · 変更されたファイル 829 · 挿入 128,366 · クローズされた問題 282 件 (P0 13、P1 36) · コミュニティ貢献者 295 名 (共著者を含む)

執念の解放 — ヘルメスエージェントは今、始めたことを終わらせます。 Kanban は、耐久性のあるマルチエージェント ボード (ハートビート、回収、ゾンビ検出、不完全な終了時の自動ブロック、タスクごとの再試行、幻覚回復) として出荷されます。 /goal は、ターンをまたいでエージェントをターゲットにロックし続けます (ラルフ ループ)。 Checkpoints v2 は、実際のプルーニングを使用して状態の永続性を書き換えます。ゲートウェイは再起動後に中断されたセッションを自動的に再開します。 Cron は no_agent ウォッチドッグ モードを成長させます。セキュリティ ウェーブにより 8 つの P0 が閉じられます。編集はデフォルトでオンになり、Discord のロール許可リストはギルド スコープになり、WhatsApp はデフォルトで見知らぬ人を拒否し、auth.json と MCP OAuth で TOCTOU ウィンドウが閉じます。 Google Chat は 20 番目のプラットフォームになります。プロバイダーはプラグイン可能なサーフェスになります。 7 つの i18n ロケールが出荷されます。

✨ ハイライト

  • マルチエージェント カンバン — 実際に終了する AI チームに委任 — 耐久性のあるボードを回転させ、その上にタスクをドロップし、複数の Herme ワーカーにタスクを拾い上げ、引き継ぎ、完了させます。ハートビート、回収、ゾンビ検出、再試行バジェット、幻覚ゲートにより、チームは誠実に保たれます。 1 回のインストールで、多数のカンバンをインストールできます。 (#17805、#19653、#20232、#20332、#21330、#21183、 #21214)
  • /goal — エージェントは、あなたが要求したことを忘れません — エージェントをターゲットにロックすると、エージェントはターンを超えてタスクを実行し続けます。ファーストクラスのプリミティブとしての Ralph ループ。 (#18262、#18275、#21287)
  • ビデオを表示 — Gemini および互換性のあるマルチモーダル モデルでネイティブ ビデオを理解するための新しい video_analyze ツール。 (@alt-グリッチ) (#19301)
  • 音声のクローン作成 — xAI Custom Voices は、音声クローン作成サポートを備えた TTS プロバイダーとして提供されます。 (@alt-グリッチ) (#18776)
  • Hermes はあなたの言語を話します — 静的ゲートウェイ + CLI メッセージは、中国語、日本語、ドイツ語、スペイン語、フランス語、ウクライナ語、トルコ語の 7 つのロケールに翻訳されます。ドキュメント サイトに中国語 (zh-Hans) ロケールが追加されました。 (#20231、#20329、#20467、#20474、#20430、#20431)
  • Google Chat — 20 番目のメッセージング プラットフォーム — に加えて、汎用のプラットフォーム プラグイン フックが表面化するため、サードパーティのアダプターがコアに触れることなくドロップインされます (IRC と Teams は移行されました)。 (#21306、#21331)
  • 再起動後もセッションは存続します — ゲートウェイがエージェント中にバウンスし、/update が再起動し、ソース ファイルがリロードされます — ゲートウェイが復帰すると会話が自動的に再開されます。 (#21192)
  • セキュリティ ウェーブ — 8 つの P0 閉鎖 — デフォルトで編集オン、Discord のロール許可リストはギルド限定 (CVSS 8.1 ギルド間 DM バイパスは閉鎖)、WhatsApp はデフォルトで見知らぬ人を拒否、TOCTOU ウィンドウは auth.json と MCP OAuth 全体で閉じられ、ブラウザーはクラウド メタデータ SSRF フロアを強制し、cron プロンプト インジェクション スキャンで組み立てられたスキル コンテンツ、hermes debug shareアップロード時に編集します。 (#21193、#21241、#21291、#21176、#21194、#21228、 #21350、#19318)
  • Checkpoints v2 — 状態の永続性が書き換えられました。実際のプルーニング、ディスク ガードレール、孤立したシャドウ リポジトリはもう必要ありません。 (#20709)
  • エージェントは独自の書き込みをリントします — write_file + patch での書き込み後のデルタ リント。 Python、JSON、YAML、TOML。構文エラーは、下流に出荷されるのではなく、すぐに表面化します。 (#20191)
  • no_agent cron モード - スクリプト専用ウォッチドッグ - cron ジョブはエージェントを完全にスキップし、スクリプトのみを実行できるようになりました。空の標準出力はサイレントであり、空でない場合はそのまま配信されます。 (#19709)
  • あらゆる場所のプラットフォーム許可リスト — Slack、Telegram、Mattermost、Matrix、DingTalk にわたる allowed_channels / allowed_chats / allowed_rooms 構成。 (#21251)
