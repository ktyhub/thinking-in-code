エルメスエージェント v2026.8.31

#エルメスエージェント v0.21.0(v2026.8.31) 発売日: 2026 年 8 月 31 日 v0.20.0 以降: ~5,800 コミット · ~2,475 マージ PR · ~5,680 ファイル変更 · ~869,000 挿入 · ~135,000 削除 · ~2,100 件クローズ · 760 人以上の寄稿者

パンテオンの解放。 v0.20.0 はヘルメスを伝令者にしました - 彼は話し、他のエージェントに知らせを伝えました。 v0.21.0では神々が集結する。ボット モードはデスクトップ アプリに組み込まれています。これは、独自の顔を持つ名前付きエージェントの社会であり、グループ チャットで、ボットがツールボックスではなくチームのように互いに、そしてあなたと会話します。その背骨の周りでは、cron ジョブがメモリと継続性を獲得したため、スケジュールされたエージェントが実行の間に実際に学習し、サブエージェントを飛行中にライブで操作できるようになり、MCP サーフェスが実際のコマンド センターになり、エージェントがデスクトップ独自のブラウザを駆動できるようになりました。このリリースでは、v0.20.1 ～ v0.20.6 インフラストラクチャ パッチ タグのすべてがロールアップされています。これらのウィンドウについては、ここで完全に文書化されています。

✨ ハイライト

  • ボット モード — エージェントが組み込まれた社会になります — ボット モードは、デスクトップ アプリにバンドルされ、デフォルトでオンになっている部分になりました。すべてのエージェント プロファイルには、名前、決定的なアバターの顔 (ランダム化/ロック コントロール付き)、および共有名簿内の場所が与えられます。複数のボットとあなたが 1 つの部屋で会話する Discord スタイルのグループ チャットを作成し、作成者からボットを @ メンションし、部屋の名前と写真を付けます。以前は、「マルチエージェント」とは配管工事を意味していました。今では同僚だらけのチャットアプリのように見えます。 (#87886、#88243、#89386、#96726 — @teknium1、@OutThisLife、@dokterdok)
  • hermes peer — エージェント間のボットツーボット DM — すべての Herme エージェントは、ハンドルによって、プロファイルやゲートウェイを越えて、CLI から、または会話内から他のエージェントにメッセージを送信できるようになりました。リサーチ ボットに、調査結果をコーディング ボットに渡し、返信が返されて読めるように依頼します。返信は各エージェントの正規のボット チャットに送信されるため、エージェント間の会話は耐久性があり、検査可能であり、一度忘れてしまうことはありません。 (#88725、#88178、#91487 — @teknium1)
  • 記憶する Cron ジョブ — スケジュールされたジョブは金魚ではなくなりました。 Cron エージェントは、他のすべてのエージェントと同様に永続メモリの読み込みと更新を行うようになり、continuity=true は各実行の出力を次の実行に引き継ぎます (そのため、モニターは既に報告したものと重複を排除できます)。すべてのジョブには耐久性のあるメモ帳スクラッチパッドが与えられ、モニター モードのジョブは何も変更されていない場合に LLM を完全にスキップし、cron 出力はボットの正規のボット チャット (ボットが実際に応答する場所) に到達できます。午前 9 時のブリーフィングの仕事は、昨日何を伝えたかを知ることができます。 (#91447、#80774、#81139、#81138、#91487 — @teknium1、@smwbev)
  • サブエージェントの実行中に操縦 — delegate_task はライブ オーケストレーションを獲得しました。実行中の子リストをリストしたり、軌道修正して飛行中の 1 つを操縦したり、早期に停止して部分的な結果を保持したりできます。子出力にオプションの JSON スキーマ検証を追加し、結果でデリゲーションごとのコストが明らかになり、デフォルト値が引き上げられました (反復数 250、同時子数 10)。デリゲーションは、ファイアアンドプレイから実際に管理された並列作業に移行しました。 (#85232、#81144、#81142、#86506、#86745 — @teknium1)
  • MCP コマンド センター - MCP サーバーとカタログは、ドラッグインによる「何でも貼り付け」インポート、ツール呼び出しが失敗する前に再認証を促すバックグラウンド ヘルス チェック、スキーマ トークンの見積もりとサーバーごとの 30 日間の使用量を示すフリート コスト/使用量オーバーレイ、および明示的な確認付きで MCP サーバーをインストールする hermes:// ディープ リンクを備えた 1 つの一貫したデスクトップ ページに統合されています。 20 台の MCP サーバーの管理は、かつては構成ファイルの考古学的作業でした。今はダッシュボードです。 (#87525、#87572、#87576、#87579、#87581 — @teknium1)
  • A CLI パワー ウェーブ - Ctrl+P を押すとあいまいなコマンド パレットが開き、入力時に /model ピッカーがフィルタリングします。/status は推論モード、保留中の承認、およびコンテキストの使用状況を表示します。また、ステータス バーにはライブ キャッシュ ヒット %、レイテンシー、およびトークン/秒をフィールドごとに切り替えて表示できます。さらに: グローバル緊急停止、セッションの固定/固定解除、タスク指向のコンポーザー プレースホルダーの回転、および Ghostty レベルの ターミナル ペット (コンパニオンにはコンパニオンが必要であるため)。 (#90730、#90717、#90745、#98250、#98282、#97666 — @teknium1、および回収されたコミュニティ作品)
  • エージェントがデスクトップのブラウザを駆動 — アプリ内ブラウザは、エージェントが見ることしかできないウィンドウではなくなりました。Hermes がナビゲートし、clicks して直接読み取り、完全なリンク コンテキスト メニューを使用してページをシステム ブラウザにポップアップ表示できるようになりました。ドキュメント サイトを探索したり、Web アプリをデバッグしたりして、それが自分のアプリ内で発生するのを監視するように依頼します。 (#90197、#89366 — @OutThisLife、@ethernet8023)
  • 6 つの新しいプロバイダーとモデル カタログ ウェーブ — メタ モデル API (Muse Spark) が、CommandCode、Tencent TokenPlan、Nebius Token Factory、Ramp Router、Actual Computer と並んで組み込みプロバイダーとして登場します。カタログには、GLM-5.3-Flash、qwen3.8-max/flash、Gemini 3.7 Flash、MiniMax M3 free、Nemotron 3.5 Lightning が取り上げられています。また、model_overrides を使用すると、リリースを待たずに、任意のモデルのコンテキスト ウィンドウにパッチを適用したり、自分で価格を設定したりできます。 (#88565、#88308、#97917、#97916、#97915、#85560 — @teknium1 とコミュニティ)
  • 全面的なセキュリティ強化 — 保護されたエージェント指示ファイル (AGENTS.md、スキル、メモリ ストア) には常に書き込み承認が必要となるため、プロンプト挿入されたエージェントが自身の常駐命令を静かに書き換えることはできません。徹底的な編集スイープにより、端末エラー、.env ファイル読み取り、チェックポイント、ACP ログにわたる秘密漏洩のギャップが解消されました。承認システムは Windows の破壊的なコマンドを学習しました。そして、macOS の権限付与は、安定した TCC 署名 ID を介して最終的に更新を存続します。 (#81152、#80965、#84428、#95091 — @teknium1 およびコミュニティ)

🏗️ コアエージェントとアーキテクチャ

プロバイダーとモデル

  • 新しいプロバイダー: 実際のコンピューター推論 (#79644、#26491 のサルベージ)、GOAT/Pro/Max プランを含む CommandCode (#88308、#32909 のサルベージ)、組み込みプロバイダー プラグインとしてのメタ モデル API (Muse Spark) (#88565)、Tencent TokenPlan (#97917)、Nebius Token Factory (#97916)、および Ramp Router (#97915)。

  • データ トレーニング層の警告 — 統合された選択ガード レジストリは、モデルがデータでトレーニングするときにすべてのピッカー サーフェスにわたって警告を出します (#85917)。

  • OpenAI ワイヤー (#87517 — @kshitijk4poor) で LiteLLM Claude に対してプロンプト キャッシュが実行され、api.meta.ai はキャッシュ用の応答 API 経由でルーティングされました (#88601)。
  • Codex GPT コンテキストのデフォルトは検証済みの 272K に戻り、大きなウィンドウ用の明示的な -900K ピッカー バリアント (#92797) が使用されます。

エージェント ループと信頼性

  • 停止したプロバイダーの回復 — 停止したストリームによってデスクトップが沈黙したり、再試行バジェットが消費されたりすることがなくなりました (#87236 — @fangliquanflq)。
  • MoA 強化クラスター - エージェントの混合ファサードは、準備されたリクエストをネイティブ client (#90212 および兄弟) に漏らすことなく、client の再構築、ストリームの再試行、プロバイダーのローテーション、およびフォールバック/復元に耐えられるようになりました。
  • 構造化出力の復元力 — 補助呼び出しは、Anthropic ワイヤの response_format を変換し、プロバイダーが構造化出力を拒否した場合に再試行します (#89589 — @ethernet8023)。
  • 圧縮: リーン テール モード + 実際にどのような圧縮が維持されるかを測定するための圧縮リコール評価ハーネス (#87326)。
  • サイズが大きすぎるツールの結果は、サンドボックスのないセッションでは切り捨てられるのではなく、キャッシュに溢れます (#89028)。
  • clarify は 1 回の通話で複数の独立した質問をします — 一連の往復ではなく 1 つの形式 (#89467 — @ethernet8023)。
  • サブシステムの検証 (superagent-ai/grok-cli からの移植): 実行レシピ検出 + 環境マニフェストにより、「動作する」という主張が検出されたビルド/テスト コマンドによって裏付けられます (#80686)。
