エルメスエージェント v2026.3.17

#エルメスエージェント v0.3.0(v2026.3.17) 発売日: 2026 年 3 月 17 日

ストリーミング、プラグイン、プロバイダーのリリース - 統合されたリアルタイム トークン配信、ファーストクラスのプラグイン アーキテクチャ、Vercel AI Gateway を使用して再構築されたプロバイダー システム、ネイティブ Anthropic プロバイダー、スマート承認、ライブ Chrome CDP ブラウザ接続、ACP IDE 統合、Honcho メモリ、音声モード、永続シェル、およびすべてのプラットフォームにわたる 50 以上のバグ修正。

✨ ハイライト

  • 統合ストリーミング インフラストラクチャ — CLI およびすべてのゲートウェイ プラットフォームでのリアルタイムのトークンごとの配信。応答はブロックとして到着するのではなく、生成されたときにストリーミングされます。 (#1538)
  • ファーストクラスのプラグイン アーキテクチャ — Python ファイルを ~/.hermes/plugins/ にドロップして、カスタム ツール、コマンド、フックを使用して Herme を拡張します。フォークは必要ありません。 (#1544、#1555)
  • ネイティブ Anthropic プロバイダー — クロード コード資格情報の自動検出、OAuth PKCE フロー、およびネイティブ プロンプト キャッシュを使用した直接 Anthropic API 呼び出し。 OpenRouter の仲介者は必要ありません。 (#1097)
  • スマート承認 + /stop コマンド — どのコマンドが安全であるかを学習し、ユーザーの設定を記憶する Codex からインスピレーションを得た承認システム。 /stop は、現在のエージェント実行を即時に強制終了します。 (#1543)
  • Honcho メモリの統合 — 非同期メモリ書き込み、構成可能なリコール モード、セッション タイトルの統合、およびゲートウェイ モードでのマルチユーザー分離。 @erosika より。 (#736)
  • 音声モード — CLI のプッシュツートーク、Telegram/Discord の音声メモ、Discord 音声チャネルのサポート、および高速ウィスパーによるローカル ウィスパー文字起こし。 (#1299、#1185、#1429)
  • 同時ツール実行 - 複数の独立したツール呼び出しが ThreadPoolExecutor 経由で並行して実行されるようになり、マルチツール回転の待ち時間が大幅に短縮されます。 (#1152)
  • PII 秘匿化 - privacy.redact_pii が有効な場合、LLM プロバイダーにコンテキストを送信する前に、個人を特定できる情報が自動的にスクラブされます。 (#1542)
  • CDP 経由の /browser connect - Chrome DevTools プロトコルを介してブラウザ ツールをライブ Chrome インスタンスに接続します。すでに開いているページをデバッグ、検査し、操作します。 (#1549)
  • Vercel AI ゲートウェイ プロバイダー — モデル カタログとインフラストラクチャにアクセスするために、Vercel の AI ゲートウェイを介して Herme をルーティングします。 (#1628)
  • 集中プロバイダー ルーター - call_llm API、統合された /model コマンド、モデル スイッチ上のプロバイダーの自動検出、および補助/委任 client の直接エンドポイント オーバーライドを備えた再構築されたプロバイダー システム。 (#1003、#1506、#1375)
  • ACP サーバー (IDE 統合) — VS Code、Zed、および JetBrains は、完全なスラッシュ コマンド サポートにより、エージェント バックエンドとして Hermes に接続できるようになりました。 (#1254、#1532)
  • 永続シェル モード — ローカルおよび SSH ターミナル バックエンドは、ツール呼び出し全体でシェル状態を維持できます。cd、env vars、およびエイリアスは永続的です。 @alt-glitch による。 (#1067、#1483)
  • エージェント オンポリシー蒸留 (OPD) — エージェント ポリシーを蒸留するための新しい RL トレーニング環境で、Atropos トレーニング エコシステムを拡張します。 (#1149)
