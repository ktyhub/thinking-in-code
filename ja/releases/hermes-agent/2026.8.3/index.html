エルメスエージェント v2026.8.3

#エルメスエージェント v0.20.0(v2026.8.3) 発売日: 2026 年 8 月 3 日 v0.19.0 以降: ~3,650 コミット · ~1,400 マージ PR · ~5,200 ファイル変更 · ~559,000 挿入 · ~405,000 削除 · ~1,200 件クローズ · 650 人以上の寄稿者

ヘラルド リリース。 ヘルメスは神の伝令であり、このリリースにより彼は本格的にヘラルドになります。彼は話し (ストリーミング TTS、バージイン、オンデバイス ウェイク ワード、および CLI、デスクトップ、およびすべてのオーディオ対応ゲートウェイ プラットフォームにわたるハンズフリー制御によるリアルタイムの会話音声)、他のエージェントに言葉を伝える (A2A v1.0)、イベントを発表します。あなたのシステム (署名された送信 Webhook) に送信し、情報源を引用しています (検証可能な引用と事実確認を伴う根拠のある研究)。その背骨の周りでは、デスクトップ アプリがプラットフォームになり (ライブ プレビューを備えたアーティファクト、プラグイン SDK、どこからでもクイック エントリ、複数のウィンドウ)、CLI には一連のパワー コマンド (! シェル モード、/init、/diff、/context、/focus) が追加され、圧縮はよりスマートかつ穏やかになり、ツール自体がモデルに推測させるのではなく、自身の障害から回復するようになりました。このリリースでは、v0.19.1 インフラストラクチャ パッチ タグのすべてがロールアップされます。そのウィンドウについては、ここで完全に文書化されています。

✨ ハイライト

  • ヘルメスと会話 — ストリーミング、バージイン付きの会話音声 — 音声モードは、以前は次のことを意味していました。話し、応答全体が生成されるのを待ってから、1 つの長い音声ファイルを聞きます。今では、Hermes は応答が流れてくると節ごとに話します。話すだけで文の途中で中断することもできます (立ち止まって聞き、モデルに割り込みが伝えられます)。また、話中を認識した沈黙検出により、ユーザーに話しかけることはありません。これは、CLI 音声モード、デスクトップ上、およびゲートウェイ アダプター経由で機能します。エルメスとの会話は、ついにボイスメールの交換ではなく、会話のように感じられます。 (#69511、#73862、#74223、#74000、#69602 — @teknium1、@OutThisLife)
  • ウェイク ワードとハンズフリー コントロール — 独自のオープンボキャブラリー ウェイク フレーズ (「ねえ、エルメス」または任意の言葉) を言うと、Hermes が聞き始めます。検出はデバイス上で実行されるため、待機中にマシンから音声が漏れることはありません。マルチプロファイル音声ルーティングにより、異なるウェイク ワードが異なるプロファイルに到達でき、「停止」と言うと、キーボードに触れずにすべての表面でボイス チャットが終了します。これで、端末が部屋の向こう側から会話できるようになりました。 (#70509、#73106、#73933 — @teknium1)
  • すべてのプラットフォームで音声 — WhatsApp、Feishu、DingTalk、LINE、QQ、Photon、または Weixin で Herme に音声メモを送信すると、文字に起こされて応答されます。自動 TTS 応答はプラットフォームに応じて配信されます (プラットフォームが必要とする作品、キャプションが正しく添付される)。 STT は完全に構成可能になりました。独自の hermes tools カテゴリ、GUI 切り替え、ダッシュボード ドロップダウン、トランスクリプトが間違った言語で返されないように統一された言語解決、OpenAI の gpt-transcribe サポートなどです。 1 つの統合された音声テキスト プリプロセッサが、すべての TTS プロバイダーにわたって音声からマークダウン、コード、および URL を除去します。 (#73515、#73508、#73910、#73513、#73067 — @teknium1)
  • 研究が可能です trust — ファクトチェックによる根拠のある引用 — 新しい grounded-citations スキルにより、Hermes はすべての主張が検証可能な出典によって裏付けられる研究を作成できます。引用は実際のページのテキスト (幻覚ではない) と照合され、引用は正確な証拠にリンクされ、ファクトチェック モードは、あらゆる文書または手渡しの主張に対して同じ機械を作動させます。何がチェックアウトされ、何がチェックされず、何がチェックされないのかがわかります。確認できませんでした。研究にHermesを使用する場合、これが「正しいと思われる」ことと「出典が証明されている」ことの違いになります。 (#71698、#77104 — @teknium1)
  • アウトバウンド Webhook — Herme はイベントをシステムにプッシュします — これまで、Hermes との統合は、プラットフォーム上でポーリングまたはリッスンすることを意味していました。現在、Hermes は、署名付きライフサイクル イベント (セッション アクティビティ、ターン完了、ツール イベント) を、登録されている任意の HTTP エンドポイントに HMAC 署名を使用してプッシュするため、受信者は信頼性を検証できます。ポーリング ループを使用せずに、Hermes を CI、ホーム オートメーション、ダッシュボード、または HTTP を通信するサービスに接続します。 (#69406 — @teknium1)
  • デスクトップ アプリがプラットフォームになる - アーティファクト、プラグイン SDK、クイック エントリ - Herme デスクトップは、アーティファクトをレンダリングするようになりました。右側のレール ビューアにサンドボックス化されたライブ プレビューを備えたバージョン管理されたカードが表示されるため、生成された HTML/アプリはチャットの隣で安全に実行されます。本物の プラグイン SDK は、Kanban を基礎プラグインとして、ユーザー ファイルの受け渡し、フローティング ペインの配置、および複数の GUI ウィンドウ用の ctx.download とともに登場しました。グローバル ホットキー クイック エントリ ウィンドウ により、OS のどこからでもセッションへの考えを取り込むことができます。デスクトップはチャット client であることをやめ、ワークベンチになり始めました。 (#72345、#61173、#74413、#72315、#68259、#73143 — @OutThisLife、@teknium1)
  • Hermes がエージェント間で会話 — A2A v1.0 — 新しいバンドル プラグインはエージェント間プロトコルを実装しているため、Hermes は他の A2A 互換エージェントを検出し、会話し、操作することができます。これで問題 #514 は終了します。これは、リポジトリ内で最も古い未解決の機能リクエストの 1 つです。異種スタックを使用してマルチエージェント システムを構築している場合、Hermes にはそれらを結合するための標準ワイヤ プロトコルが用意されています。 (#77109 — @teknium1)
  • CLI パワーユーザー ウェーブ — !command は、モデル ターンを費やすことなくシェル コマンドを即座に実行します。 /init はプロジェクトをスキャンし、AGENTS.md を生成 (または更新) します。 /diff は、あらゆるサーフェスからの段階的/すべて/セッションの変更を表示し、/context はコンテキスト ウィンドウに表示されている内容を正確に分析し、/focus は隠線回復機能を備えた出力を削減したビューを提供し、Ctrl+S は書きかけのプロンプトを閲覧可能なパネルに隠します。さらに、hermes import-agent は、Claude Code または Codex CLI セットアップを 1 つのコマンドで Hermes に移行します。 (#72257、#72178、#72240、#72242、#72302、#72262、#72190 — @teknium1、長年のコミュニティ PR を救出する数人）
  • ターンの途中でエージェントを修正します — リダイレクト — エルメスが間違った方向に進んでいる場合、/stop して再度説明する必要はもうありません。修正が機能している間に修正を入力すると、アクティブなターンがリダイレクトされます。進行中の作業は保存され、元のプロンプトが保持され、エージェントは新しいガイダンスに従って軌道を修正します。ダブル ESC のドラフト破棄とコンポーザーの取り消しスタックと組み合わせると、ステアリングは再起動ではなく編集のように感じられます。 (#63104、#72339、#74736 — @OutThisLife)
  • 自己修復ツール — 一連の自己回復アップグレードにより、エージェントがツールの摩擦で無駄にするターンが大幅に減ります。切り詰められたターミナル出力はエージェントが読み取れるファイルに流出し、patch はすでに適用された編集を検出して空白の不一致を診断し、write_file はディスク上の内容を検証し、何も一致しない検索でニアミスを調査して回復し、一般的な障害クラスが実用的なヒントとともに返されます。デフォルトのツール呼び出しの反復制限も 90 → 500 に跳ね上がり、長時間の自律実行が人工の壁にぶつかることはなくなりました。 (#77041、#76998、#77024、#77055、#77011、#76992、#72176 — @teknium1)
  • 会話を尊重する圧縮 — コンテキスト圧縮は大幅に見直しられました。大規模ウィンドウ モデル向けのプロアクティブなツール結果のプルーニング、1 回の巨大な一時停止の代わりにコストを償却するターンごとのマイクロ コンパクション、最新の会話が常に存続するように保証された N ユーザー メッセージ テール、遅いサマリー モデルへの罰を停止する進行状況認識タイムアウト、プルーニングされたスキルがサイレントにセッションに残らないようにするゴースト スキル防御です。しきい値はモデルごとに絶対トークンで構成できるようになりました。長時間のセッションでも一貫性が保たれ、停止がなくなりました。 (#70254、#75345、#70250、#71508、#70275 — @teknium1、@kshitijk4poor、複数のコミュニティ PR を回収)
  • スマートな承認が成長する — hermes approvals suggest は承認履歴をマイニングして許可リストの提案を作成し、オペレーターはスマート承認ポリシーをカスタマイズでき、連続拒否サーキット ブレーカーは不正な動作をするループ コールドを停止し、デスクトップ ペアリングの承認はプロファイルが修正され、応答するための適切なサーフェスが提供されます。さらに、docker/podman daemon-redirect コマンド用の新しい承認ゲートも追加されました。 cliは「承認」することを減らし、一切のコントロールを与えません。 (#72259、#72186、#72203、#74446、#71092 — @teknium1、@OutThisLife)
  • どこでも再び高速化 — プロンプト キャッシュは、履歴を失うことなくネイティブ Anthropic 上のツール スキーマをカバーするようになりました。 hermes -w のコールド スタートは約 14 秒から約 1.8 秒に低下し、hermes update の no-op は 2 ～ 6 秒速くなり、重い SDK の遅延ロードがインポート パスから外れ、構成読み取りのディープ コピーが停止し (テレメトリ ゲートで 54 倍高速)、デスクトップは 2 番目の 60 fps ウェーブを出荷しました。ストリーミング コストはトランスクリプトの長さに依存せず、5 つのストリーミング タブで 60 fps でドラッグし、バックグラウンドでアイドル状態の CPU がほぼゼロになりました。 (#76032、#71637、#74218、#74204、#71835、#72346、 #75218 — @kshitijk4poor、@teknium1、@OutThisLife)
  • 実行して到達できる新しい場所 — Buzz はバンドルされたゲートウェイ プラットフォーム (ネイティブ WebSocket トランスポートと NIP-42 認証を備えた Block の Nostr ベースのメッセンジャー) として登場し、Vercel AI Gateway プロバイダーと Vercel Sandbox ターミナル バックエンドは最新化され、デスクトップは SSH リモート バックエンド接続モードを獲得し、Relay は 4 段階のパリティ (メディア、インタラクティブ プロンプト、スレッド ライフサイクル、タイピング インジケーター) に加えて HSP 個人 +組織のスキル同期。 (#73610、#73761、#74518、#68130、#71300–#71624、 #66730 — @teknium1、@yoniebans、@benbarclay)
