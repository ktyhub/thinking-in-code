エルメスエージェント v0.21.6

エルメスエージェント v0.21.6

発売日: 2026 年 10 月 8 日

パッチリリース。このタグは、v0.21.5 以降にマージされた約 2,100 の PR を、Docker および Hermise Cloud の安定したタグ付きリリースにロールアップします。このウィンドウ用に厳選された完全なメモが v0.22.0 に同梱されています。

このリリースについて

これは、新しい安定版リリース パイプラインによってカットされた最初のリリースです。1 つの試行参照、テスト済みの Docker イメージ、および公開時の受信タグです。この GitHub リリースと Docker 画像のタグが同梱されています。デスクトップ アプリ、Termux パッケージ、および Microsoft Store は今のところ現在のビルドに残り、次のバンドル リリースに移行します。

コミット 818c13be1dc4fd28987e1e881a9408224afd4535 で測定したところ、v0.21.5 以降のウィンドウには、8,342 の変更されたファイル (+772,490 / −225,600) にわたる 8,867 の非マージ コミット、2,106 のマージされた PR、および 3,027 のクローズされた問題が含まれています。

また、ウィンドウ内では、ここでは意図的に文書化されていませんが、CLI、TUI、およびデスクトップ (stt.streaming) で話している間のライブ文字起こしが行われます。話し声は、デフォルトで推論がオフになり、独自のモデル (auxiliary.voice_chat) にルーティングされます。プロファイルごとのプラグイン ホスト (plugins.isolation: host) で実行されるサードパーティのプラグインと、その設定ページの 1 つの [設定] ▸ [プラグイン] ホーム。デスクトップピッカーの上部にあるお気に入りのピン留めされたモデル、サブスクリプションが限界に達する前の使用状況チップ、およびその理由といつまでを示す料金制限プロバイダー。 Linux x64 および arm64 上の hermes model および llama.cpp CUDA のローカル モデル。コア、デスクトップ、TUI にわたるプラグイン可能な階層型言語パック。概要が最初の hermes status (--short、--full)。レビューペインの差分スコープセレクター (未コミット/分岐/最後のターン) とターンに続くキープアウェイク。 cron ストアが書き込み不能になった場合の cron、doctor、およびホームチャネルの警告。資格情報アップロードの承認フラグとターミナル コマンドの非表示 Unicode。ボット トークンをチェックし、招待リンクを出力する Discord セットアップ。統合されたカンバン ワークフロー定義。 activate.fish;カタログ内の GPT-6.1 ソルとクロード ソネット 5.5 / Haiku 5.5。そして数十の新しいコミュニティプラグイン。

このウィンドウ用に厳選された release note には v0.22.0 が同梱されており、v0.21.0 以降のすべて (ハイライト、特集エリア、完全な貢献者クレジット) が文書化されます。このウィンドウ内の何もスキップされません。

更新中

  • Docker / エルメス クラウド: nousresearch/hermes-agent:stable (または :latest)。
  • CLI (git installs): hermes update、またはインストーラーのワンライナーを再実行します。
  • デスクトップ アプリと Termux: このリリースでは変更はありません。次のバンドル リリースで更新されます。

セキュリティ修正

ダッシュボード認証の強化

  • スプーフィングされた X-Forwarded-For ヘッダーにより、パスワード ログイン レート制限がリセットされ、ネイティブ サインインの IP ごとの上限を回避できる可能性があります (#133367)
  • 認証されていないログイン要求により、認証監査ログに無制限の値が書き込まれる可能性がありました (#133369)
  • パブリック /auth/ ルートにはリクエスト本文のサイズ制限がありませんでした (#133370)
  • ネイティブ サインインはログイン コードを非ループバック リダイレクトに送信し、セッションの引き継ぎを許可する可能性がありました (#130685)

4 つすべての問題 (TRA-725、TRA-726、TRA-727、TRA-728) を報告してくださった Tenable Research に感謝します。ネイティブ サインイン リダイレクトの問題も独立して報告され、@Froraut によって修正されました。 X-Forwarded-For 修正は、@hinotoi-agent と @BearHuddleston によるコミュニティ作業 (#40285) に基づいて構築されています。

リポジトリ git フィルターの強化

  • 自動 git 呼び出し (セッション ワークスペース スナップショット、サブエージェント ワークツリー、カンバン、ワークツリー クリーンアップ、hermes -w) は、最初のプロンプトの前に、untrusted リポジトリ独自の設定によって定義された clean/smudge/process フィルター プログラムを実行する可能性がありました (#130661)

これを非公開で報告してくれた燕涛に感謝します。 @jonpol01 (#126017、#126019) および @JoaoMarcos44 (#126075) によっても報告され、修正されました。

電子メールゲートウェイ送信者の強化

  • From ヘッダー内の引用符で囲まれた表示名 (例: "Victim <victim@example.com>" <attacker@evil.test>) により、攻撃者のメッセージが許可された送信者として電子メール ホワイトリストを通過する可能性があります (#125212)

これを報告し、修正 (#124322) を書いてくれた Daniel Steele (@keeltrace) に感謝します。
