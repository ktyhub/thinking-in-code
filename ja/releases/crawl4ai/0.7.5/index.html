#クロール4ai v0.7.5

🚀 Crawl4AI v0.7.5: Docker フックとセキュリティ アップデート

🎯 新機能

🔧 Docker フックシステム

認証、パフォーマンスの最適化、コンテンツ処理のための 8 つの主要なパイプライン ポイントにカスタム Python 関数を挿入します。

関数ベースの API (IDE サポート付き):

from crawl4ai import hooks_to_string

async def on_page_context_created(page, context, **kwargs):
    """Block images to speed up crawling"""
    await context.route("**/*.{png,jpg,jpeg,gif,webp}", lambda route: route.abort())
    return page

hooks_code = hooks_to_string({"on_page_context_created": on_page_context_created})

8 つの利用可能なフックポイント: on_browser_created、on_page_context_created、before_goto、after_goto、on_user_agent_updated、on_execution_started、before_retrieve_html、before_return_html

🤖 強化された LLM 統合

  • 創造性を制御するためのカスタム温度パラメータ
  • マルチプロバイダーのサポート (OpenAI、Gemini、カスタム エンドポイント)
  • セルフホストモデルのbase_url設定
  • Docker API の統合の改善

🔒 HTTPS の保存

新しい preserve_https_for_internal_links オプションは、クロール中に安全なプロトコルを維持します。これは、認証されたセッションやセキュリティを重視したアプリケーションにとって重要です。

🛠️ 主要なバグ修正

  • URL 処理: クエリ パラメーターでの「+」記号の保持を修正しました (#1332)
  • JWT 認証: Docker JWT 検証の問題を解決しました (#1442)
  • Playwright Stealth: ステルス機能の統合を修正 (#1481)
  • プロキシ構成: 新しい proxy_config 構造による強化された解析
  • メモリ管理: 長時間実行セッションにおけるリークを修正
  • Docker シリアル化: JSON エンコード エラー (#1419) を解決しました。
  • LLM プロバイダー: アダプティブ クローラーのカスタム プロバイダー統合を修正 (#1291)
  • パフォーマンス: バックオフ戦略の失敗を解決しました (#989)

📦 インストール

ピピ: pip インストール クロール4ai==0.7.5

Docker: docker プルアンクルコード/crawl4ai:0.7.5 docker プル アンクルコード/crawl4ai:最新

サポートされているプラットフォーム: Linux/AMD64、Linux/ARM64 (Apple Silicon、AWS Graviton)

⚠️重大な変更

  1. Python 3.10+ 必須 (3.9 からアップグレード)
  2. プロキシ パラメータの非推奨 - 新しい proxy_config 構造を使用する
  3. 新しい依存関係 - CSS 処理を改善するために cssselect が追加されました
