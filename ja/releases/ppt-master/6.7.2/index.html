#pptマスターv6.7.2

パッチリリース: 問題履歴の監査からの修正。それらのほとんどは、ツールが成功を報告する間に、ツールがコンテンツを失ったり、上書きしたり、書き換えたりするのを防ぎます。

インストールと起動

  • スキルのみのインストールでは、作業フォルダーにプロジェクトが再度作成されます (703aa72f、#144)。 v6.3.0 以降、project_manager.py init はインストールされたスキルに相対してプロジェクトを配置しました。 npx skills またはプラグインのインストールの場合、これは .agents/projects/ またはプラグイン キャッシュを意味し、更新によりそれらを置き換えることができます。リポジトリのチェックアウト内では何も変わりません。
  • Windows では、起動しない python3 (WindowsApps スタブが出力なしで 9009 を終了) は、整合性ガードの失敗として扱われなくなりました。エージェントは最初に python を使用して再試行します (e1b58732、#142 のフォローアップ)。

ソースの変換とインポート

  • PDF: 1 つのサンプル用紙に対して書かれた 4 つのテーブルの書き換えを削除しました。彼らは、ハードコーディングされたシンボルから変数カテゴリを再導出し、ヘッダーを置き換え、行を削除し、相関列を発明しました。抽出されたセルは抽出された状態で保持されるようになりました (3aa2ec62)。
  • HTML: ページは強制 UTF-8 ではなく BOM とその文字セット宣言によってデコードされるため、<meta charset="gbk"> ページは置換文字として表示されなくなりました。推測されたエンコーディングが報告されます (34d88c1a)。
  • Web: 1 つのバッチ内の同じタイトルを持つページは、相互に上書きされるのではなく、Report.md、Report_2.md を取得します (e847939c)。コード フェンスに <body> が示されている生の .md URL は、例 (6a92c1fd) に縮小されるのではなく、Markdown のままになります。
  • import-sources: GB18030 またはその他の非 UTF-8 エンコーディングの .txt ソースは、置換されずにデコードされます (39b470fe)。同じテキストで異なるコンパニオン画像 (<stem>_files/) を含むマークダウンは重複として扱われなくなり、削除されます (104bc3c9)。
  • PPTX インポート: b="true" / i="true" は、"1" が既に行っていたように、太字および斜体でインポートされるようになりました (8bdf440c)。ページタイプ分類は単語全体と一致するため、「Qatar」または「Department」は Q&A または章ページとして読み取られなくなりました (c0ce2420)。

ライブ プレビュー エディター

  • [すべて保存] は、ステージング後に変更された SVG 上でステージングされた編集を再実行することを拒否し、エラーを伴ってステージングされたままになります。以前は、現在その位置 (05e627cb) にある要素に着陸していました。
  • _edit_ で始まるユーザー ID は保持され、行が移動されたときに dy=".5" スタイルの番号が正しく解析されます (264bd669)。

エクスポート、ファイナライズ、チェッカー

  • Arial Unicode MS や Monotype Corsiva などのプロポーショナル フォントは等幅サイズではなくなりました (c2668566)。
  • 一重引用符 preserve-color または stroke='currentColor' でマークされたアイコンとイラストは、その色とスタイルを維持します (05cf79cd、0cdf8765)。
  • チェッカーは、表示テキストが class=…、onload=…、または @import … であるスライド、または data-class 属性を持つスライドを不合格にしなくなりました。実際の class、イベントおよび CSS インポートの使用は依然として失敗します (8f00128e、923a5360)。

画像、ナレーション、ビデオ

  • hero.v2.png のような名前のマニフェスト イメージが hero.png を上書きしなくなりました (e9676c5a)。
  • 画像検索は単語全体でランク付けされます: 必須 「イラン」は「ティラナ」を受け入れなくなり、交通ペナルティは「ビジネス」または「トレイル」にヒットしなくなります (d4ac79df、b827c5ce)。
  • ページのサブタイトルとメモは、スライド 9 とスライド 99 以降の数値スライド順序に従います (1036fd53)。ナレーションは #1 revenue grew などの行を保持し、実際の Markdown 見出し (06008e8e) のみをスキップします。

ドキュメント

  • FAQ は、Keynote、LibreOffice、WPS でピクセルが同一のグラフを約束するものではなくなりました。 Microsoft PowerPoint が検証対象です (ac16c041)。
