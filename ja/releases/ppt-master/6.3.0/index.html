ppt-master v6.3.0

#pptマスターv6.3.0

[!重要] このリリースは忠実性と証拠を重視しています。 ネイティブ チャートとテーブルは、描画された SVG 項目ごとに従うようになり、ラテン語テキストはクラス平均ではなく実際のグリフの進歩から測定され、テンプレートは 1 つのコマンドでインストールされ、サンプル ライブラリは、すべてのビジュアル スタイル、モード、キャンバスに加えて、最初のスプレッドシート、PDF、およびスタイル テンプレート駆動のデッキをカバーする 33 デッキまで増加しました。 [テンプレートの作成] と [ネイティブ PPTX の編集] は一時停止されたままになります (バグ修正のみ)。

コンバーター

  • ネイティブ チャートはフォールバック描画を反映します。 バーの順序、ポイント マーカーとポイントごとの色、ストロークのない領域の塗りつぶし、クラスター化されたギャップとオーバーラップ、プロット内の線の開始位置はすべて、作成された SVG から読み込まれます。スパースセルキャッシュはギャップとしてインポートされます。コンパニオン テキストはチャートとともにグループ化されているため、1 つのアニメーションでユニット全体が移動し、フォールバック ベースラインに配置されます。グラフの枠がプロットを超えて拡大するため、PowerPoint では手動の垂直レイアウトが折りたたまれずに維持されます。
  • ネイティブ テーブル は、未入力のセルを noFill としてエクスポートし、defaults.run カラーをプレーンテキスト セルに伝え、paragraphs セルに実行デフォルトを継承させ、パディング上に作成された行の高さを尊重します。
  • 実際のグリフからのテキスト幅。 Arial、Times New Roman、Georgia、Verdana、および Calibri (標準、太字、斜体、太字斜体) は、バンドルされているグリフごとのアドバンス テーブル (font_advances.json) から測定されます。等幅面は文字×固定アドバンスとして測定されます。ワイドフェイス (Arial Black) はその要素を維持します。大文字と小文字が混在する Arial 行は、折り返しヘッドルームが適用される前にテキスト フレームの約 94% を埋めることができるようになり、85% から増加し、チェッカーとエクスポーターはすべてのマシンで同じ数値に同意します。
  • エクスポートの正確性の修正: 非表示の SVG 要素と非表示の clip シェイプは非表示のまま、非表示のグループはアニメーション ターゲットを保持、単一子グループの回転は保持、インライン tspan dx は実行され、ルートとネイティブ グラデーションの不透明度が適用され、範囲外のシェイプ フレームと不完全なパターンの塗りつぶしはファイルを作成する代わりに拒否されます PowerPoint 修復、幅ゼロのストロークは線なしとしてエクスポート、カメラ MPO JPEG はプライマリ フレームを保持し、画像ツールは EXIF の方向を尊重します。

ソース変換

  • Excel の値は完全な精度を維持し、ソース エンコーディングは検出され、インライン スペースと絶対リンクは Web ページで存続し、HTML コメントは削除され、生の Markdown とプレーン テキストの URL はそのまま保存され、pdf_to_md は行頭の小数点を保持し、--no-images は Web ページで機能し、拡張子なしの -o は <name>.md になり、バッチ変換は入力を上書きせず、import-sources は別のプロジェクトのファイルを移動する代わりにコピーします。
  • ソースコンバーターの --help は、オプションの依存関係をインストールする必要がなくなりました (#282)。

テンプレート

  • apply_template.py は、apply-template-workspace Runbook に従って、選択したブランド / スタイル / レイアウト / デッキ ワークスペースをプロジェクトにインストールします: 検証、ライブラリ/明示的な出所、デッキ上のレイアウト、ロスターとアセットのコピー、冪等な再実行、および §5.3 レシート。
  • mbb-consulting、文書密度での戦略文書の新しいスタイル - ユニット行を含む番号付きの展示、含意パネルで閉じるキーメッセージ列、ページごとに 5 ～ 7 つのモジュール、固定ページのクロム、サイズ アンカー、フォールバック カラー、タイポグラフィ - EV 市場優先の例から抽出されたもの。 consulting-decision は、抑制されたメソッドファーストのデフォルトを維持します。

チェッカーとオーサリング ツール

  • --native-charts-and-tables を壊す可能性のあるチャート/テーブルのパリティ結果は、エクスポート ブロックとしてタグ付けされます。パリティは、number_format、正確なティック、最初の列の style.body_text、中央ヘッダーのデフォルトを尊重し、列全体の塗りつぶしの背後にある複数列の四角形に名前を付けます。
  • text_measure.py calibrate は、大文字と数字のレート、アウトライン列を出力し、--role をマージします。幅チェックではインライン ハイパーリンクの実行が読み取られます。 validate は実際のプロジェクト ディレクトリを解決します。 init は、スキルからプロジェクトのルートを解決し、ページ数を名簿と照合してチェックします。
  • アニメーションの順序: リストにないグループは、SVG インデックスではなく、最も近いリストの順序に従います。 static-role chrome は、サイドカーが名前を付けるとアニメーション化され、構造レイヤーとスライドの背景のみが固定されます。 list-groups はクロム ID に名前を付けます。
  • スライス診断により、オーバーフローによるドリフトを判断し、純粋なキーを保持し、バッキング パネルにフラグを立てます。保存された候補プールによる画像検索ページ。 rotate_images は障害を報告します。
  • Tencent Cloud TokenHub イメージ バックエンド (tencent、エイリアス tokenhub / hunyuan) がイメージ ジェネレーター (#279) に加わりました。

プロンプトとルール

  • アニメーション ガイダンス: クロムはデフォルトでは静的で、名前を付けるとページごとにアニメーションします。モーフ エンドポイントは最初の描画時に固定されたグループであり、連続性キャリアがデフォルトのモーフです。入場順序は読書パスに従います。イラストの役割によって何が動くかが決まります。
  • テキストとレイアウトのガイダンス: 境界の上端と下端はスペルアウトされ、役割グループは引き続き境界を宣言し、すべての tspan の最初の行はインライン強調を保持し、数字は DIGITS レートを使用し、キャリブレーション レートは 5% マージンのあるサンプル平均であり、繰り返しの書き込みフォームは初期ゲートでメソッド レベルとして扱われます。
  • ネイティブ データ: data_labels タイプのサポート、ネイティブ オブジェクトはモーフ ペアにならず、row_heights にはヘッダー行が含まれ、borders.style フォーム、defaults.cell、および完全な Chrome トークン リストがエクスポーターが読み取る場所に文書化されます。
  • docs/rules/code-style.md §11 では、指定された条件 (stdlib 単体テスト、スクリプトのみ、テスト内フィクスチャ、CI なし) での skills/ppt-master/scripts/tests/ に基づく単体テストが許可されるようになりました。このスイートには 212 のテストがあります。

例

現在、サンプルサイト には 33 デッキ (471 ページ) が含まれており、最初のデッキはスプレッドシート ソース (XLSX + CSV からの Apple 2025 年度運用レビュー)、PDF ソース (ResearchStudio-Reel の論文読み上げ、英語、学術研究スタイル)、およびバンドルされたスタイル テンプレート (Cloudflare の停止事後分析、UV 製品の発売、MBB コンサルティングでの EV 市場の優先順位) によって駆動されています。新しい写真、データ、イラスト主導の資料 (アポロの写真エッセイ、中国 2025 年経済説明会、ピクセルアートの朝食アトラス、二十四節気の長編とストーリー、お茶の A4 配布資料、遺産品の瞬間グリッド、ブルータリスト フィールド ガイド、WebGPU クイック、バナーおよびヘッダー セット) と並んで。 5 月時代の 6 つのサンプルは、再生成せずに現在のチェッカーに移行されました。

  • #282 (@QiuLsG): ソース コンバーターのヘルプは依存関係がありません。
  • #279: Tencent Cloud TokenHub バックエンド。 アセット: ppt-master-skill-v6.3.0.zip は、skills/ppt-master/ をエージェント ツールにロードするためのスキルのみのツリーです。ソース アーカイブには完全なリポジトリが含まれます。
