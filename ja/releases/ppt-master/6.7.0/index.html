ppt-master v6.7.0

マイナー 公開日2026年10月8日 出典hugohe3/ppt-master 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#pptマスターv6.7.0 マイナー リリース: 設計仕様のブラウザー レビュー ページ、デフォルトの Google 画像モデルとしての Google の新しい Nano Banana 2.1、およびソース変換と PPTX/SVG テキストのラウンドトリップで警告なしに失われていたコンテンツの修正。

画像の生成

  • Google 画像生成は、Gemini、OpenRouter (google/gemini-nano-banana-2.1)、および fal (google/nano-banana-2.1) バックエンドで、デフォルトで Nano Banana 2.1 (gemini-nano-banana-2.1、2026 年 10 月 6 日に GA) に設定されるようになりました。 Google は gemini-3.1-flash-image を非推奨としましたが、閉鎖日は発表していません。 Nano Banana 2.1 は 512px を提供していないため、3 つのバックエンドすべてがリクエストを送信する前に 512px を拒否するようになりました。ワイドレシオ 1:4 4:1 1:8 8:1 は引き続き機能します (35508e34)。
    • .env が GEMINI_MODEL=gemini-3.1-flash-image (または OpenRouter/fal と同等のもの) をピン留めしている場合でも、その設定は新しいデフォルトよりも優先されます。切り替える行を更新または削除します。
    • ID gemini-3.1-flash-image-preview および gemini-2.5-flash-image-preview を削除しました。 Googleは両モデルを閉鎖した。
  • OpenAI: OPENAI_BACKGROUND=transparent は、gpt-image-2 (OpenAI でプレビュー中) を含む GPT 画像モデルで受け入れられるようになり、JPEG 出力と一緒にのみ拒否されます。 gpt-image-2.5-sunburst / gpt-image-2.5-flare とそのスナップショットは OPENAI_QUALITY=xhigh|max を受け入れます。 gpt-image-1-mini は入力忠実度 low のみを受け入れます。デフォルトは gpt-image-2 (3f98568c) のままです。
  • バックエンドの修正:
    • Qwen 2K 2:3 / 3:2 は 3:4 / 4:3 画像の生成に使用されます。
    • /api/v3 で終わる Volcengine Ark ベース URL に /api/v1 が追加されなくなりました。
    • レプリケートは、要求を送信する前に、flux-1.1-pro が提供しない 21:9 を拒否するようになりました (06d8f0a1)。
  • image_search は、Pillow の減圧警告サイズ (481e057e) を超えるオリジナルを半分にします。 slice_images はさらに 3 つのケース (964d9209、fd20665d、adbfdf48) を処理します。
    • 凹凸はあるがキーカラーの地面。
    • キーカラーとブレンドされたエッジとシャドウ;
    • キーカラーに近い測定値の地面にスピルを除去します。

設計仕様のレビュー

  • design_spec.md の新しいブラウザ レビュー ページ: セクション、パーツ、スライドごとに 1 ページ。 1 つのブロックの Markdown を直接編集できます。編集は、ハッシュの前提条件を使用した正確なバイト範囲の置換として適用され、書き込まれる前にそのスキーマがチェックされます。ブロックごとまたはグローバル コメントを残すこともできます。コメントは別のサイドカー ファイルに記述され、仕様には決して組み込まれません。 check_spec_annotations.py は両方の種類のフィードバックをエージェント (aec32024、61ad7aec) に渡します。
  • refine_spec がオンの場合、ページ上で確認された実行により、ページ上の仕様もレビューされるようになりました。チャットで実行を確認し、チャットでレビューを続けます。承認は引き続きチャットで行われます。ロック後に仕様が変更された場合、再開は仕様の調整に戻ります (866efd84)。

ソース変換

  • DOCX、PPTX、Excel、および Web コンバータは、警告なしにコンテンツを削除しなくなりました。 影響を受けるコンテンツには、ネストされたテーブル、コンテンツ コントロール、テーブル内の文末脚注とリンク、OMML 区切り記号、PPTX フィールド テキストと番号の継続、Excel の隠しシート、結合されたセルと数値形式などが含まれます (13ac724c、2d72da61)。
  • pdf_to_md は、連続するヘッダーまたはフッターを繰り返す本文テキストを保持し、ヘッダーを共有するテーブルの間にある数値またはラベル付きの段落を保持します (51c2979a、4eb7b3d6)。 Pandoc が評価できない場合でも、Typst テキストは存続します (176235a3)。

PPTX ↔ SVG テキスト

  • テキスト ベースラインは、固定フォント サイズ推定値 (3d1b7dc6、#301) に代わって、両方向の 1 つの共有フォント メトリック モデルから取得されるようになりました。
  • フレームからはみ出すインポートされたテキストは、DrawingML のデフォルトのオーバーフローに従い、すべての行が維持され、垂直方向に固定されたままになります。明示的な clip と省略記号は引き続き受け入れられます (c9a82582、d5424756)。

UI とツール

  • 仕様のレビュー、確認、ライブ プレビュー UI:
    • すべてが同じ方法で UI 言語を検出して保存します。
    • 言語を切り替えても、入力された注釈は維持されます。
    • zh-TW は全角の区切り文字を使用します。 @kevindesuyo (#305、#306、#307) に感謝します。
  • 分離されたサーバーは、ANSI カラー コードをログに記録しません (1d76e326)。バンドルされている比較ギャラリーとロゴは小さくなっています (6a9ee2aa)。

スポンサー

  • 国内リンクの隣に国際キミ コード リンクを追加し (#296)、スポンサー期間が終了したスポンサーを削除しました (680de11f)。
