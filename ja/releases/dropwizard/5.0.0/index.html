Dropwizard 5.0.0-rc.5 以降の変更点

  • 依存関係のアップグレードおよび https://github.com/dropwizard/dropwizard/pull/10415 の @Copilot による Java 17 要件について Dropwizard 5.0.0 ドキュメントを更新
  • chore(deps): https://github.com/dropwizard/dropwizard/pull/10414 の @renovate[bot] による依存関係 sphinx-autobuild を v2025 (release/5.0.x) に更新
  • ci: https://github.com/dropwizard/dropwizard/pull/10423 の @joschi によるマストドン (foojay.social) へのリンクを更新
  • ドキュメント: https://github.com/dropwizard/dropwizard/pull/10420 の @joschi による archivedLogFilenamePattern の誤った形式文字列を修正
  • ビルド: https://github.com/dropwizard/dropwizard/pull/10429 の @joschi によって POM から空の distributionManagement を削除します
  • 修正 (deps): https://github.com/dropwizard/dropwizard/pull/10433 の @renovate[bot] による依存関係 io.dropwizard.logback:logback-throttling-appender を v1.5.2 (release/5.0.x) に更新
  • fix(deps): https://github.com/dropwizard/dropwizard/pull/10436 の @renovate[bot] により依存関係 io.dropwizard.metrics:metrics-bom を v4.2.35 (release/5.0.x) に更新
  • 修正 (deps): https://github.com/dropwizard/dropwizard/pull/10439 の @renovate[bot] による依存関係 com.fasterxml.jackson:jackson-bom を v2.20.0 (release/5.0.x) に更新
  • fix(deps): https://github.com/dropwizard/dropwizard/pull/10444 の @renovate[bot] により依存関係 org.apache.httpcomponents.core5:httpcore5 を v5.3.5 (release/5.0.x) に更新
  • chore(deps): https://github.com/dropwizard/dropwizard/pull/10445 の @renovate[bot] により、依存関係 org.sonarsource.scanner.maven:sonar-maven-plugin を v5.2.0.4988 (release/5.0.x) に更新します
  • https://github.com/dropwizard/dropwizard/pull/10447 の @joschi による非推奨のログバック PatternLayout#getDefaultConverterMap への呼び出しを置き換えます
  • fix(deps): https://github.com/dropwizard/dropwizard/pull/10451 の @renovate[bot] により依存関係 org.hibernate.orm:hibernate-core を v6.6.28.final (release/5.0.x) に更新
  • fix(deps): https://github.com/dropwizard/dropwizard/pull/10452 の @renovate[bot] により依存関係 org.checkerframework:checker-qual を v3.50.0 (release/5.0.x) に更新
  • https://github.com/dropwizard/dropwizard/pull/10455 の @joschi による client タイムアウトの管理には、非推奨ではない httpclient メソッドを使用します
  • 雑用: https://github.com/dropwizard/dropwizard/pull/10457 で @joschi によって AuthConfiguration#NT_CREDS を非推奨としてマークする
  • fix(deps): https://github.com/dropwizard/dropwizard/pull/10462 の @renovate[bot] により依存関係 io.dropwizard.metrics:metrics-bom を v4.2.36 (release/5.0.x) に更新
  • 雑務: https://github.com/dropwizard/dropwizard/pull/10463 の @joschi による Checker フレームワークの削除
  • chore(deps): https://github.com/dropwizard/dropwizard/pull/10466 の @renovate[bot] により、github/codeql-action アクションを v3.30.0 (release/5.0.x) に更新します
  • fix(deps): https://github.com/dropwizard/dropwizard/pull/10481 の @renovate[bot] により依存関係 org.apache.tomcat:tomcat-jdbc を v11.0.11 (release/5.0.x) に更新
  • chore(deps): https://github.com/dropwizard/dropwizard/pull/10480 の @renovate[bot] により、github/codeql-action アクションを v3.30.1 (release/5.0.x) に更新します
  • chore(deps): アクション/古いアクションを v10 (リリース/5.0.x) に更新 (https://github.com/dropwizard/dropwizard/pull/10482 の @renovate[bot] により)
  • 修正 (deps): https://github.com/dropwizard/dropwizard/pull/10483 の @renovate[bot] による Jetty Monorepo を v12.1.1 (リリース/5.0.x) (パッチ) に更新
  • DbMigrateCommand の非推奨の Liquibase 呼び出しを https://github.com/dropwizard/dropwizard/pull/10489 の @joschi によって置き換えます
  • https://github.com/dropwizard/dropwizard/pull/10490 で @joschi による非推奨のフリーマーカー コンストラクターを使用する
  • https://github.com/dropwizard/dropwizard/pull/10493 の @joschi によるヘルスチェックカウンターのきれいな印刷を復活させます
  • NetUtil による Linux TCP バックログ設定の解析を簡素化 (https://github.com/dropwizard/dropwizard/pull/10487 の @joschi による)
  • ドロップウィザードサーブレット ByteRange のヘッダー値の ASCII 解析を強制します… by @joschi (https://github.com/dropwizard/dropwizard/pull/10497)
  • https://github.com/dropwizard/dropwizard/pull/10495 の @joschi によるドロップウィザード構成で非推奨の LevenshteinDistance コンストラクターを回避する
  • chore(deps): https://github.com/dropwizard/dropwizard/pull/10507 の @renovate[bot] により、github/codeql-action アクションを v3.30.3 (release/5.0.x) に更新します。
  • 修正 (deps): https://github.com/dropwizard/dropwizard/pull/10508 の @renovate[bot] による依存関係 jakarta.activation:jakarta.activation-api を v2.1.4 (release/5.0.x) に更新します
  • CacheControl#toString を、https://github.com/dropwizard/dropwizard/pull/10496 の @joschi による非推奨ではない同等の文字列に置き換えます。
  • https://github.com/dropwizard/dropwizard/pull/10499 で @joschi によって getDefaultConverterMap を非推奨としてマークします
  • chore(deps): Maven プラグインを更新 (リリース/5.0.x) (パッチ) by @renovate[bot] in https://github.com/dropwizard/dropwizard/pull/10513
  • fix(deps): https://github.com/dropwizard/dropwizard/pull/10514 の @renovate[bot] により依存関係 org.hibernate.orm:hibernate-core を v6.6.29.final (release/5.0.x) に更新
  • fix(deps): https://github.com/dropwizard/dropwizard/pull/10523 の @renovate[bot] による依存関係 jakarta.xml.bind:jakarta.xml.bind-api を v4.0.4 (release/5.0.x) に更新
  • 修正 (deps): https://github.com/dropwizard/dropwizard/pull/10527 の @renovate[bot] による依存関係 io.dropwizard.logback:logback-throttling-appender を v1.5.3 (release/5.0.x) に更新
  • fix(deps): https://github.com/dropwizard/dropwizard/pull/10530 の @renovate[bot] により依存関係 io.dropwizard.metrics:metrics-bom を v4.2.37 (release/5.0.x) に更新
