#テッセラクト5.5.4

何が変わったのか

このリリースでは、17 件のセキュリティ勧告といくつかの小さな問題が修正されています。 さらに、いくつかの小規模な更新と改善が提供されます。

  • VS2022 を使用した Windows 上のトレーニング ツールのビルドを修正: by @zdenop in https://github.com/tesseract-ocr/tesseract/pull/4590
  • Arch,viewer: 欠落している <cstdlib> と <string> を @tachalorah によって https://github.com/tesseract-ocr/tesseract/pull/4592 に追加
  • https://github.com/tesseract-ocr/tesseract/pull/4598 の @Copilot を使用した @stweil による SIMDDetect::GetDetector() の再帰的静的初期化を修正
  • tesseract DLL から GetDetector() をエクスポートするため、リンカーはそれを解決できます。 @zdenop 著、https://github.com/tesseract-ocr/tesseract/pull/4602
  • https://github.com/tesseract-ocr/tesseract/pull/4594 の @darkdi による引数ではなくメンバーを参照する 2 つの \param 名を修正
  • https://github.com/tesseract-ocr/tesseract/pull/4604 の @stweil によるプル リクエストのコミットをチェックする新しい GitHub ワークフローを追加
  • トレーニング ツールを使用せずに単体テストを構築 (https://github.com/tesseract-ocr/tesseract/pull/4596 の @stweil による)
  • ドキュメント: https://github.com/tesseract-ocr/tesseract/pull/4605 の @yzxcj797 によるデッド Tesseract トレーニング ドキュメントのリンクを更新
  • https://github.com/tesseract-ocr/tesseract/pull/4597 の @stweil による Coverity Scan によって報告されたいくつかの高および中優先度の問題を修正
  • https://github.com/tesseract-ocr/tesseract/pull/4606 の @stweil による Coverity 警告を修正
  • https://github.com/tesseract-ocr/tesseract/pull/4599 で @ilkecan による二次段落リスタート スキャンを回避する
  • https://github.com/tesseract-ocr/tesseract/pull/4607 の @dependabot[bot] による 4 から 7 へのバンプ アクション/チェックアウト
  • https://github.com/tesseract-ocr/tesseract/pull/4613 の @stweil による「セキュリティと品質」からの GitHub AI の調査結果を修正
  • https://github.com/tesseract-ocr/tesseract/pull/4612 の @stweil による ScrollView メニューの非効率な空文字列テストを修正
  • https://github.com/tesseract-ocr/tesseract/pull/4611 の @stweil によって Coverity によって報告されたいくつかの問題を修正
  • 修正: https://github.com/tesseract-ocr/tesseract/pull/4609 の @SomSamantray による UNICHAR::UTF8ToUTF32 での範囲外読み取りを防止
  • 修正: https://github.com/tesseract-ocr/tesseract/pull/4617 の @stweil によって切り詰められた UTF-8 文字列と細工されたインデックス マップへの範囲外アクセスを防止
  • https://github.com/tesseract-ocr/tesseract/pull/4601 の @ilkecan による冗長な結果反復子の再起動を回避する
  • 修正: https://github.com/tesseract-ocr/tesseract/pull/4622 の @y1lan による潜在的なメモリ リーク
  • https://github.com/tesseract-ocr/tesseract/pull/4630 の @stweil による未分類単語の確実性のための float オーバーフローの回避
  • https://github.com/tesseract-ocr/tesseract/pull/4644 の @stweil によりデシリアライザーで入力がゼロの int モード重み行列を拒否
  • https://github.com/tesseract-ocr/tesseract/pull/4632 の @stweil による位置依存の段落境界ボックスを修正
  • https://github.com/tesseract-ocr/tesseract/pull/4640 の @stweil によりレガシー inttemp で負の/特大のクラス ID を拒否
  • https://github.com/tesseract-ocr/tesseract/pull/4577 の @Ramya-9353 によって execvp が失敗したときに子プロセスを終了する
  • https://github.com/tesseract-ocr/tesseract/pull/4645 の @stweil によって使用される前に、ReadAdaptedClass 内のファイルソースのポインターを無効化します。
  • https://github.com/tesseract-ocr/tesseract/pull/4654 の @SKSavale によるデーヴァナーガリー フォントのダウンロード URL を修正
  • cmake: https://github.com/tesseract-ocr/tesseract/pull/4650 の @manduinca によってインストールされた GoogleTest を単体テストで使用できるようにします
  • https://github.com/tesseract-ocr/tesseract/pull/4649 の @stweil による GENERIC_2D_ARRAY 逆シリアル化で不正なディメンションを拒否
  • ccstruct: https://github.com/tesseract-ocr/tesseract/pull/4655 の @stweil による EliminateDuplicateOutlines の孤立したアウトライン サイクルのリークを修正
  • https://github.com/tesseract-ocr/tesseract/pull/4647 の @stweil による RTL PAGE XML 出力の AppendLinePolygon の double-free/UAF を修正
  • wordrec: https://github.com/tesseract-ocr/tesseract/pull/4656 の @stweil による縮退入力でのタイムアウトを防ぐためのバインド シーム検索
  • lstm: https://github.com/tesseract-ocr/tesseract/pull/4657 の @stweil によって中止されるのではなく、古い形式の WeightMatrix を拒否します
  • wordrec: https://github.com/tesseract-ocr/tesseract/pull/4659 の @stweil により、パスごとのシーム検索バジェットを追加して、多くの単語のタイムアウトを制限します
  • https://github.com/tesseract-ocr/tesseract/pull/4642 の @stweil による LSTM モデルのロードで範囲外の null_char を拒否
  • https://github.com/tesseract-ocr/tesseract/pull/4639 の @stweil による int/adaptive 分類器でのクラス ID 処理を強化
  • https://github.com/tesseract-ocr/tesseract/pull/4641 の @stweil によるショート スケール ベクトルを持つ int モード重み行列を拒否
  • https://github.com/tesseract-ocr/tesseract/pull/4643の@stweilにより、コード範囲がネットワーク出力数を超えるリコーダを拒否します
  • https://github.com/tesseract-ocr/tesseract/pull/4646 の @stweil により、訓練されたデータ モデルが欠落している場合に単体テストをスキップします
  • nsis: https://github.com/tesseract-ocr/tesseract/pull/4661 の @stweil による固定サイズ バッファーを使用しない winpath ヘルパーの書き換え
  • https://github.com/tesseract-ocr/tesseract/pull/4665 の @stweil による constexpr FCOORD 演算子の C++17 ビルドを修正
  • https://github.com/tesseract-ocr/tesseract/pull/4667 の @mardgez により、いくつかの言語での ReplaceCurrentWord の use-after-free を修正
