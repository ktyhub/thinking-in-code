⚠️重大な変更

  • #15970 - セルフホスト型 Docker Compose はインストールごとに独自のサービス パスワードを生成し、パスワードなしでは起動しません。docker compose up の前に make init-env (またはインストーラー) を実行します。 PostgreSQL、RabbitMQ、Redis、FalkorDB、および ClamAV は 127.0.0.1 でのみリッスンするようになりました。既存のインストール: アップグレード: サービス パスワードはインストールごとに生成される (@ntindle による) を参照してください。
  • #12206 - 外部 API v1 は新しい v2 に代わって非推奨となり、2027 年 1 月 31 日まで動作し続けます (@Pwuts による)
