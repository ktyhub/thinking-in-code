  • #14990 - OAuth の開始と交換の失敗を PostHog に報告します (@kcze による)

  • #15138 - ENABLE_USER_NOTIFICATIONS スイッチにより、本番環境は認証メールのみを送信できるようになります (@Bentlybro による)

  • #15146 - 33 人目の名簿エキスパート (ホットフィックス) に Clip のアバターと名簿ピンを追加します (@ntindle による)
  • #14951 - 公式 PayPal MCP サーバーを MCP カタログに追加します (@ntindle による)
  • #15070 - GPT-6.1 Sol を LLM カタログに追加 (@ntindle による)
  • #14836 - サインアップ、オンボーディング、チェックアウト、チャーン イベントを PostHog に送信します (@kcze による)
  • #15134 - 公式 Canva MCP サーバーを MCP カタログに追加します (@ntindle による)
  • #15053 - 通常のサンドボックス作業では決して質問されません。外部コマンドとユーザーのファイルの要求されていない削除は引き続き行われます (@Pwuts による)
  • #15203 - ミストラル ラージ 4 を追加 (@ntindle による)
  • #15210 - Mistral Medium 3.5、Small 4、Ministral 3 を追加し、Medium 3.1 と Small 3.2 を廃止 (by @Pwuts)
  • #15188 - GitHub リポジトリ トラフィック ブロック (ビュー、クローン、リファラー、人気のあるコンテンツ) を追加します (@ntindle による)
  • #15191 - ハッカー ニュースの検索、ストーリー、アイテム、ユーザー ブロックを追加します (@ntindle による)
  • #15135 - 最初のセッションの前に確認済みの電子メールを要求し、サインアップ時にプラットフォーム ユーザーをプロビジョニングします (@Bentlybro による)
  • #15152 - サインアップ同意行、マーケティング オプトアウト、および MailerLite ゲート (@itsababseh による)
  • #15035 - 新しいタスクを結合し、自宅で要約します (@0ubbe による)
  • #15201 - ログアウト時のサイドバーを簡素化し、無料トライアルを促進します (@Torantulino による)
  • #15084 - すべてのストリーム エントリを ID 化し、すべての永続化チェックポイントを作成し、カーソルからターンを再開します (@Pwuts による)
  • #15088 - チャット ストリームをサーバーが保持する行に折りたたみ、どこにドリフトしたかをレポートします (@Pwuts による)
  • #14950 - Conductor 統合ブロックを追加 (@Abhi1992002 による)

機能強化

  • #14835 - 重複した PostHog イベントを削除し、基本プロパティを追加します (@kcze による)
  • #15163 - エンジニアリング ノートを公開ドキュメント フォルダーから移動します (@ntindle による)

UI/UXの改善

  • #15064 - 携帯電話でドロップダウン メニューからダイアログを開いたままにする (@Pwuts による)

  • #15102 - サイドバーから新しいエキスパート ページを開き、ホバーするとグループの山形が表示されます (@Abhi1992002 による)

  • #15155 - サインインしているユーザーとオンボーディングしているユーザーを /home に直接送信します (@Pwuts による)
  • #15082 - タッチ デバイスでは Enter キーを押して送信しないでください (@Otto-AGPT より)
  • #15160 - プロバイダーが保存された資格情報を拒否した場合に再接続を提供します (@kcze による)

  • #15045 - MailerLite がバックフィル書き込みを拒否した理由をログに記録します (@ntindle による)
  • #15021 - Cookiebot の回答 (@kcze による) まで、どこでも Google 同意モードを拒否します
  • #15039 - 承認カードには保留中の通話の引数がスーパーバイザーの 24k 上限までテキストとして表示されます (@Pwuts による)
  • #14881 - ワークスペース ファイルのダウンロードが失敗した場合、500 ではなく 404/502 を返します (@Bentlybro による)
  • #15058 - gh、Node、python を AutoPilot サンドボックス イメージに戻します (@Pwuts による)
  • #15068 - リンクされたチャット ボットから駆動される AutoPilot チャットは、チャネルが表示できない承認カードを待機しなくなりました (@Pwuts による)
  • #15042 - GPT-OSS 120B OpenRouter の表示価格ドリフトを修正 (@ntindle による)
  • #15096 - Cookiebot の回答 (ホットフィックス) (@kcze による) まで、どこでも Google 同意モードを拒否します
  • #15097 - Stripe リダイレクトの前に選択したプランを送信し、トライアル開始変換 (ホットフィックス) を追加します (@kcze による)
  • #15109 - CLI の ListAgents および SendMessage ツールを禁止します (@ntindle による)
  • #15117 - CLI の ListAgents および SendMessage ツール (開発、#15109 から) を禁止します (@Pwuts による)

  • #14890 - Next が処理した RSC フェッチ フォールバックの Sentry への報告を停止 (@Bentlybro による)
  • #15054 - リニア OAuth 更新をシリアル化します (@Bentlybro による)
  • #14895 - Sentry の LaunchDarkly 統合の初期化を停止します (@Bentlybro による)
  • #15114 - Conductor プロンプト ID を Get Session カーソルとして受け入れ、next_after を公開します (@Abhi1992002 による)
  • #15112 - 副操縦士の機能の再記述とスキルの再ロードを毎ターン停止する (@Abhi1992002 による)
  • #15111 - エキスパート find_capability が、未付与の認証情報に対して、needs_expert_grant、接続されていないことを報告します (@Abhi1992002 による)
  • #15108 - Conductor Create Workspace のベース ブランチを明示的に作成し、それを報告する (@Abhi1992002 による)
  • #15116 - 管理者権限のプランが取り消される Stripe 顧客の作成からの [設定] > [請求] を停止します (@Abhi1992002 による)
  • #15141 - チェックアウト オープナーのみが MailerLite に移動し、GTM 用にセグメント化されています (@ntindle による)
  • #15140 - チェックアウト オープナーのみが MailerLite に移動し、GTM (ホットフィックス) 用にセグメント化されています (@ntindle による)
  • #15142 - Secret_key を PostHog client に渡します (@Pwuts による)
  • #15071 - DeepSeek V4.1 Flash OpenRouter の表示価格ドリフトを修正 (@ntindle による)
  • #15139 - Kim K2.6 OpenRouter の表示価格ドリフトを修正 (@ntindle による)
  • #15095 - サインアップ ページから古いデモ リンクを削除します (@itsababseh による)
  • #15125 - スケジュールされた run_agent が DatabaseManager を通じて DB に到達し、スケジュールされたターンの失敗アラート (@Bentlybro による)
  • #15193 - パブリック メディア ストレージとプライベート メディア ストレージを分割する (@kcze による)
  • #15166 - 副操縦士のエラー再試行が新しいターンを開始するようにします (@Torantulino による)
  • #15167 - トランザクション電子メールをデザイン システムと調整する (@Torantulino による)
  • #15037 - ワークスペースへのヒアドキュメントの書き込みをシェルコマンドではなくファイル書き込みとして判断します (@Pwuts による)
  • #15181 - PostHog フラグ同期は、誰にもサービスを提供せず、リクエストが拒否された理由を示すフラグを作成できます (@Pwuts による)

  • #15131 - チャネルの承認ボタンは、Web click と同じように順番をウェイクアップするため、ゲートはユーザーのリクエストに対してそれを判断します (@Pwuts による)
  • #15197 - Redis 接続プールを使い果たす広いグラフ ファンアウトを停止します (@Bentlybro による)
  • #15186 - web_search は、引用されたすべての情報源をその番号とともに返します (@Bentlybro による)
  • #15130 - サンドボックスが実行中のコマンドをドロップしたときに bash_exec が誤ったタイムアウトを報告しなくなりました (@Bentlybro による)
  • #14882 - プロバイダーの生のクレジット不足エラーをユーザーに表示しない (@Bentlybro による)
  • #15127 - AutoPilot サブエージェントをフォアグラウンドに保ち、作業が返信に届くようにします (@Bentlybro による)
  • #15132 - スケジュールされた実行では、スケジュールの作成時に選択されたアカウントが使用され、選択者が誰も応答することはありません (@Bentlybro による)
  • #15053 - 通常のサンドボックス作業では決して質問されません。外部コマンドとユーザーのファイルの要求されていない削除は引き続き行われます (@Pwuts による)
