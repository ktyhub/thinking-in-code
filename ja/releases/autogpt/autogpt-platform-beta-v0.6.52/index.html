  • #12397 - E2B auto_resume を有効にし、セーフティネットのタイムアウトを削減します (@Otto-AGPT による)

  • #12480 - pr-address スキルの向上 — 完全なスレッド コンテキスト + PR 説明のバックティック修正 (@majdyz による)
  • #12461 - CI を待機中に新しい PR コメントをポーリングします (@majdyz による)
  • #12489 - SmartDecisionMakerBlock でのサポート応答 API (@ntindle による)

UI/UXの改善

  • #12389 - 技術ブロック用語をユーザーフレンドリーなラベルに置き換えます (@0ubbe による)

バグ修正

  • #12390 - 構造化データの自動解析と堅牢な型強制 (@majdyz による)

  • #12430 - 予想されるエラーをフィルタリングし、ログ レベルをダウングレードすることで Sentry ノイズを削減します (@majdyz による)
  • #12362 - EditAgentForm の画像削除ボタンを修正 (@Abhi1992002 による)
  • #12400 - バッチ スライスの前に CamelCase ブロック名を分割し、無効なブロックをフィルタリングしました (@majdyz による)

  • #12025 - 過度に長い「拡張子」を持つファイル名を切り詰める (@Deeven-Seru による)

  • #12413 - CoPilot SDK のプロンプトが長すぎるエラーに対する Try-compact-retry (@majdyz による)
  • #12451 - Supabase サインアップ前に招待資格を事前確認します (@Otto-AGPT による)
  • #12466 - ARM64 互換性のための Docker のアーチ条件付きクロム (@0ubbe による)

  • #12485 - 招待システムを元に戻す (@Pwuts による)
  • #12490 - 「feat(backend): OpenAI プロバイダーを応答 API に移行」を元に戻します (@ntindle による)

テスト

ドキュメント
