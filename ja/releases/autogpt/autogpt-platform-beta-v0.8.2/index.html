🔥 新機能は何ですか?

新機能

  • #14209 - AutoPilot アクション ゲート モード - Ask First、Auto、Unsupervised (by @Pwuts)
  • #14817 - AutoPilot から開始されたワークフローは、元に戻せないアクションの前に一時停止します。不可逆マーカーの名前が変更され、拡張されました (@Pwuts による)
  • #14832 - 保留中の通話がレビューを待っている間もオートパイロットは続行します: チャットごとにカードのキューがあり、承認の遅れた結果 (@Pwuts による)
  • #14837 - AutoPilot は読み取り専用でワークスペースのブロックとワークフローを何も要求せずに実行し、すべてのカードのブロックまたはワークフローに名前を付けます (@Pwuts による)
  • #14839 - AutoPilot は、各サーバーのエフェクト マップに基づいて MCP 呼び出しを決定し、他のツールの最初の使用を尋ねます (@Pwuts による)
  • #14834 - 外部読み取りは、モデルがそれらを認識する前に判断されます。命令を運ぶ読み取りがユーザーのために保持されます (@Pwuts による)
  • #14841 - チャットが支出上限を超えると、有料読み取りが要求されます (@Pwuts による)
  • #14645 - すべての E2B ボックスが出力する認証情報スワップ プロキシ (@kcze による)
  • #14792 - AnySearch 検索、並列検索、抽出ブロックを追加 (@Xxx91n による)
  • #14775 - コパイロット @ メンションでの接続された統合のサポート (@Abhi1992002 による)
  • #14695 - ブラウザ通知設定をアカウント ページに追加します (@kcze 氏)
  • #14701 - メインの AutoPilot チャットにそのコンピューターについて伝えます (@kcze による)
  • #14849 - 専門家を雇うとすぐに戻ります。スキルとワークフローはバックグラウンドでインストールされます (@Pwuts による)
  • #14853 - AutoPilot の承認リクエストは、(@Pwuts による) 作成されたグラフの実行ではなく、チャットに属します。
  • #14878 - 信用履歴とコスト ログは、でっち上げられたグラフの実行ではなく、AutoPilot チャットに名前を付けます (@Pwuts による)
  • #14931 - 承認ルールは 1 つのチャット、1 人のエキスパート、またはチーム全体に適用できます (@Pwuts による)
  • #14980 - ベアツールの承認カードには、「今後は承認」と「今後はオットーに判断させる」が提供されます (@Pwuts による)
  • #14997 - Trust はメモリ、インストールされたスキル、所有するワークスペース パスを読み取ります (@Pwuts による)
  • #14999 - 保留中の AutoPilot 呼び出しをダイアログで確認します (@Pwuts による)
  • #14858 - クレイ アバター ピッカーとライブ AI 生成を追加 (@0ubbe による)
  • #14901 - 維持されているサイトマップに公開エキスパート ページを含める (SECRT-2750) (@Abhi1992002 による)
  • #14945 - デプロイ時にスキル カタログを公開し、インストールされたコピーを所定の場所に更新します (@Torantulino による)
  • #14859 - PostHog MCP を追加し、完全な統合アイコンを追加します (@ntindle による)
  • #14971 - 自己ホスト型インスタンスを含む OpenSEO MCP を追加します (@ntindle による)
  • #14891 - 保留中の通話には、その ID が指すものの名前がリンク付きで付けられます (@Pwuts による)
  • #14494 - バックフィル スクリプト (@Pwuts による) を使用して、マーケットプレイスのリストに短い CTA スタイルのサブ見出しを必要とします。
  • #14833 - 単一の PostHog イベント リストと名前定数 (@kcze による)
  • #15040 - PostHog 担当者のサブスクリプション ステータスとライフサイクル日付を保持します (@kcze による)
  • #15026 - 既存の購読者を MailerLite にバックフィルし、トライアル グループを追加します (@Bentlybro による)
