⚠️重大な変更

  • #16459 - 支払い強制は、enable-platform-payment 機能フラグではなく、バックエンド設定 ENABLE_PLATFORM_PAYMENT (デフォルト オフ) になりました。有料のセルフホスト型インストールでは、これを設定する必要があります。 FORCE_FLAG_ENABLE_PLATFORM_PAYMENT と NEXT_PUBLIC_FORCE_FLAG_ENABLE_PLATFORM_PAYMENT は何もしなくなりました (@Pwuts より)
  • #16474 - プラットフォーム API は、アップロード ルートまたは Webhook Ingress ではないルート上の MAX_REQUEST_BODY_MB (デフォルトは 10 MiB) 上のリクエスト本文に対して 413 に応答します。より大きなファイルをインラインで渡す場合は、値を上げるか、メディア ストレージを構成します (@Pwuts による)
  • #16522 - X-Forwarded-For が複数のアドレスを持つプロキシ チェーンの背後で、新しい TRUSTED_PROXIES 設定 (IP アドレスまたは CIDR 範囲) にプロキシをリストします。設定しないままにすると、訪問者ごとの制限はヘッダーの左端のエントリの代わりに client IP を取得しません。 IP アドレスまたは CIDR 範囲ではないエントリにより、フロントエンドの起動が停止されます (@Pwuts による)
  • #15853 - LaunchDarkly のサポートが削除され、すべての機能フラグが PostHog から読み取られます。 LAUNCH_DARKLY_SDK_KEY、FEATURE_FLAG_BACKEND、NEXT_PUBLIC_LAUNCHDARKLY_ENABLED、NEXT_PUBLIC_LAUNCHDARKLY_CLIENT_ID、NEXT_PUBLIC_FEATURE_FLAG_BACKEND は無視されます。 PostHog がない場合、すべてのフラグがデフォルトになります (@kcze による)
  • #16026 - AutoPilot の会話は Langfuse まで追跡されなくなり、プロンプト管理のみに使用されるようになりました。 AutoPilot トレースは PostHog に送信されます (@kcze による)
