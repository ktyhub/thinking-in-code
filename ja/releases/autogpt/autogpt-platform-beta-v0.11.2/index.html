AutoGPT autogpt-プラットフォーム-ベータ-v0.11.2

🚀 autogpt-platform-beta-v0.11.2 をリリース

日付: 2025 年 1 月

🔥 新機能は何ですか?

新機能

  • #16308 - プランファースト トライアル: ペイウォール上のスターター タスクとエキスパート、雇用ステップが削除され、トライアル開始時にチームが雇用され、ホームはエキスパートが所有するランク付けされたタスクから開始します (@itsababseh による)
  • #16650 - Wix を MCP カタログに追加します (@ntindle による)
  • #16654 - オットーはブレイン ダンプの不十分な画面に返信します (@itsababseh による)
  • #15459 - オプションの終了質問を使用したセルフサービスのアカウント削除 (@itsababseh による)
  • #16698 - 使用制限により作業が拒否または一時停止されるたびに PostHog イベントを送信します (SECRT-3411) (by @kcze)
  • #16269 - 移行可能なオンボーディング ステップとして Microsoft 365 オファーを使用して、Microsoft を継続します (@ntindle による)
  • #16348 - アプリ内フィードバック プロンプトを追加します (@0ubbe による)
  • #16461 - デプロイメントごと、アカウントごとに一度に実行する E2B サンドボックスの数を制限します (@Pwuts による)
  • #16689 - カードとサイドバーから新しいエキスパートのチャットを開き、1 つの click を作成して開始します (@itsababseh による)
  • #16702 - PostHog 担当者にプラン層を設定します (SECRT-3411) (@kcze 氏)
  • #15454 - HubSpot ブロックが HubSpot OAuth でサインインできるようにします (@Bentlybro による)
  • #15487 - #15459 の 14 日後に閉鎖アカウントを消去し、禁止記録を残します (アカウント CLI とジョブの消去) (@kcze による)

機能強化

  • #16700 - Meta Muse Ember モデルのサポートを追加 (@ntindle による)
  • #16699 - クロード・フェイブル 5.2 サポートを追加 (@ntindle による)
  • #15761 - 副操縦士での独立したスキルの読み取りをオーバーラップします (@ntindle による)
  • #16685 - パフォーマンスを向上させるために、イベント ループから OAuth client シークレットを検証します (@ntindle による)

UI/UXの改善

  • #16697 - ライブチャットでブロックの承認カードを表示し、ホームのエキスパートに名前を付けます (@itsababseh により)

バグ修正

  • #16655 - ユーザーが名前を付けない限り、生成されたワークフローでモデルを未設定のままにしておきます (@kcze による)
  • #15081 - OAuth 更新が失敗した理由を記録し、無効なトークンの再生を停止し、欠落しているスコープに名前を付けます (@Bentlybro による)
  • #16216 - 削除が成功した後、テレグラム メッセージの削除が失敗しなくなりました (@ntindle による)
  • #16621 - チャット プラットフォーム メッセージを保存または実行する前に正規化します (@ntindle による)
  • #16667 - csv.Sniffer の代わりに解析して CSV 区切り文字を推測します (@ntindle による)
  • #16471 - crypto.randomUUID を使用せずにブレイン ダンプ ID を作成します (@posthog-eu[bot] による)
  • #16368 - ワークスペースのツール出力/パスで read_tool_result をリダイレクトします (@0ubbe による)
  • #16669 - スコープごとの cron ではなく、1 時間ごとのジョブからメモリ コミュニティを再構築します (@Pwuts による)
  • #16691 - AutoPilot ブロックの実行後にブロック メディア ファイルを削除します (@ntindle による)
  • #16690 - サブワークフローのネストをバインドし、ユーザーのワーカー共有に向けてネストされた実行をカウントします (@ntindle による)
  • #16693 - リアルタイム制限付きでエグゼキューター ループからビデオ エンコードを実行します (@ntindle による)
  • #16692 - モデレーションがタイムアウトした場合に automod_fail_open を尊重する (@ntindle による)
  • #16672 - bash_exec は、タイムアウトしたコマンドが開始したものをすべて強制終了します (@Pwuts による)
  • #16717 - v1 外部 API リクエストの認証を 1 回解決します (@Pwuts による)
  • #16670 - 電子メールの購読解除リンクをクリックすると、エラーではなく確認ページが開きます (@Pwuts による)
  • #16721 - 更新が成功したと報告された場合に Stripe の払い戻しを解決する (@Pwuts による)
  • #16671 - 有料オンボーディング チェックアウト後のホームとオンボーディングのバウンスを停止します (@Pwuts による)
  • #16682 - Discord ボットに転送された画像と返信された画像を表示させます (@Bentlybro による)
  • #16703 - LLM リクエストがプロバイダーにとって大きすぎる場合、明確なメッセージが表示されてすぐに失敗します (@Bentlybro による)
  • #16704 - オットーは、サーバーが 403 に応答したときに、サインインしている MCP アカウントが接続されていないと表示しなくなりました (@Bentlybro より)
  • #16684 - 失敗したステップでエキスパートが実行すると、失敗、完了していないと報告されました (@Bentlybro による)
  • #16707 - Mark Exa 外部アクションとしてリサーチを作成 (@0ubbe による)
  • #16713 - プラットフォームの SDK キー (Firecrawl、DataForSEO、Tavily など) をどこでもシステム資格情報として扱います (@Torantulino による)
  • #16745 - アカウントを削除すると、アカウントのチャットが削除される (SECRT-2854) (@kcze 氏)
  • #16706 - Advanced がオンの場合、実行時に入力を空白のままにします (@0ubbe による)
  • #16710 - JSON フィールドに長すぎて保持できない数値が含まれている場合に言う (@0ubbe による)

ドキュメント

  • #14339 - 承認されたレビュー結果を AGENTS.md ルールとして成文化します (@Pwuts による)
  • #12122 - デプロイメント環境変数ガイドの追加 (@Bentlybro による)
  • #15872 - すべてのレート制限と、プラットフォームが発信者の IP アドレスを見つける方法を文書化します (@Pwuts による)

依存関係とメンテナンス

  • #16609 - フロントエンドで @ai-sdk/反応を 4.0.147 から 4.0.158 にバンプします (@dependabot[bot] による)
  • #16591 - セキュリティ更新グループのフロントエンドで 7.3.1 から 7.3.7 に vite をバンプします (@dependabot[bot] による)
  • #16592 - 2 つの更新を含む 1 つのディレクトリに開発依存関係グループをバンプします (@dependabot[bot] による)
  • #16590 - security-updates グループの autogpt_libs で pyasn1 を 0.6.4 から 0.6.5 にバンプします (@dependabot[bot] による)
  • #16589 - 3 つの更新を含む 1 つのディレクトリに開発依存関係グループをバンプします (@dependabot[bot] による)
  • #16606 - フロントエンドでイベントソース パーサーを 3.0.6 から 4.1.3 にバンプします (@dependabot[bot] による)
  • #15996 - フロントエンドで 9.2.1 から 10.0.6 に同時にバンプします (@dependabot[bot] による)
  • #16610 - フロントエンドで 13.3.0 から 14.7.1 にフレーマー モーションをバンプします (@dependabot[bot] による)
  • #16653 - macos-15 で macOS インストーラー ジョブを実行します (@ntindle による)
  • #16603 - Peter-evans/create-pull-request を 6.1.0 から 8.1.1 にバンプします (@dependabot[bot] による)
  • #15225 - 最終ベイク ターゲットのみから単一コンテナーのビルド キャッシュを読み取ります (@Bentlybro による)

開発経験

  • #16712 - Max の新しい毎週のパーフェクト フィット リード ルーチンを宣言します (@Torantulino による)
  • #15477 - コア チーム エージェントの線形始業ルールを追加 (@itsababseh 著)
