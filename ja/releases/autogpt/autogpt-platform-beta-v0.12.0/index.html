AutoGPT autogpt-platform-beta-v0.12.0

プレリリース 公開日2026年11月19日 出典Significant-Gravitas/AutoGPT 英語原文

AutoGPT autogpt-プラットフォーム-ベータ-v0.12.0

⚠️重大な変更

フロントエンドは TRUST_X_FORWARDED_FOR を読み取らなくなりました (#16530、@Pwuts)。手動で設定したセルフホステッド フロントエンドは、TRUSTED_PROXIES がその前にプロキシをリストするまで、サインイン IP ログ、IP ブロック、および訪問者ごとのストア検索用に X-Forwarded-For から client IP を取得しません。単一コンテナー イメージと Vercel には何も必要ありません。 対処方法: フロントエンドで TRUST_X_FORWARDED_FOR が設定されている場合は、それを削除し、その前にあるプロキシのアドレスまたは CIDR 範囲のカンマ区切りリストを TRUSTED_PROXIES に設定します。そうするまで、フロントエンドは起動時に古い設定が無視されるという警告をログに記録します。同じ TRUSTED_PROXIES 設定により、バックエンドのプロキシと外部 API のアドレスごとの制限にも名前が付けられるようになり、動作し続けますが非推奨になった FORWARDED_ALLOW_IPS と TRUSTED_PROXY_COUNT が置き換えられます。独自のリバース プロキシの背後では、単一コンテナー イメージもそれを受け取ります。 Client IP アドレス を参照してください。

✨ ハイライト

  • AutoGPT をポケットに。 新しいネイティブ モバイル アプリを使用すると、チームが携帯電話に配置されます。サインインして、Otto や専門家とチャットし、マーケットプレイスから専門家を雇い、チャットから直接サービスに接続し、入力する代わりに生の音声ディクテーションで会話します。 (#16715、#16869、#16923、#17058)
  • より迅速に開始できます。 サインアップの手順が少なくなり (パスワードを 2 回入力する必要がなくなり)、サインアップ ページとログイン ページがすぐに表示され、セットアップが「セットアップを読み込んでいます…」でスタックすることがなくなりました。 Google にサインアップすると、同じ手順で Gmail、ドライブ、カレンダーに接続できます。 (#16829、#16831、#16968、#16845、#16877)
  • より安全なサインイン。 アカウント (Google、Microsoft、GitHub、または Discord) にサインインする新しい方法を追加すると、そのプロバイダーがメールボックス (Google 経由の Gmail、Microsoft 経由の Outlook.com) を実行している場合を除き、受信トレイから 6 桁のコードが取得されるようになりました。また、新しいサインイン方法が追加されるたびに電子メールが届きます。 (#16860)
  • メッセージを失うことはありません。 Otto がメッセージの到着を確認できない場合、送信時に 1 回の click を実行すると、ファイルも含めてメッセージが 2 回送信されることなく配信されます。そして、「考え中…」はオットーが答え始めるまで表示されるようになったので、それが機能していることが常にわかります。 (#17041、#16962、#17038)
  • 実行中の実際の位置を常に確認します。 接続が短時間切断されると、ライブラリ、実行履歴、アクティビティ、チャットが自動的に追いつくため、すでに終了した実行はまだ実行中であるようには見えなくなります。ライブ アップデートは、低速接続でも流れ続けます。 (#16898、#16915、#16932、#16903、#16865、#16960)
  • 信頼できるスケジュール 簡単なメンテナンス中、スケジュールは消えるのではなく一時的に利用不可として表示され、再起動中に予定されている実行は引き続き (正確に 1 回) 実行され、作成したばかりのスケジュールを再試行しても重複が作成されなくなります。 (#16937、#16866、#16919、#16904)
  • さらに多くのモデルから選択できます。 Gemini 4 Neon、GPT-6.2 Astra、GPT-6.2 Sol、および Qwen 4 Max がワークフローで利用できるようになり、Otto の高度な Codex 層が GPT-6.2 Astra で実行できるようになりました。 (#17023、#16870、#16899、#16836、#16852、#16902)
  • Otto 用の追加ツール。 Otto は AnySearch、Supabase、Klaviyo、AI/ML API、CompanyEnrich に接続できるようになり、Supabase からの読み取りに毎回承認が必要なくなり、Otto は接続したカスタム MCP サーバーを URL で検索できるようになりました。 (#16913、#16659、#16850、#15202、#16771、#16447、#15168)

🔒 セキュリティ

このリリースでは、非公開で報告されたいくつかのセキュリティ問題が修正されています。修正が実稼働環境に反映されたら、アドバイザリを公開します。

🧩 このリリースにも含まれています

オットーとオートパイロット

  • チャットまたは API から雇われた専門家が自己紹介します (#16687、@Bentlybro)
  • モデルアクティビティとは別に最初の応答タイミングを測定 (#15533、@ntindle)
  • チャットで送信から回答までのタイミングを測定する (#15541、@ntindle)
  • グリーティングの Sonnet 呼び出しに考えさせて、OpenRouter が拒否を停止するようにします (#16781、@Pwuts)
  • Founder プランの 3 番目のタスクの理由を言い換えます (#16851、@kcze)
  • 拒否されたツール呼び出しは発生しなかったことを Otto に伝えます (#17036、@kcze)
  • 失敗したツールのエラー テキストをその出力と同様に判断する (#16884、@ntindle)
  • bash_exec は、コマンドが自身のシェルをいつ終了したかを示します (#16347、@Pwuts)
  • ネストされたブロック出力オブジェクトを、describe_capability のフィールド名でリストします (#16679、@Bentlybro)
  • ボットの返信テキストに保存されたファイル名を保持します (#16680、@Bentlybro)
  • すでにスケジュールされている作業に対して 2 番目のスケジュールを作成しないでください (#16678、@Bentlybro)
  • 承認は最大 1 回のみ消費します (#16863、@ntindle)
  • 保存されたレビューを読み取ることができないブロック実行を払い戻します (#16895、@ntindle)
  • 古いうちはサブエージェントのキャッチアップを取りやめ、2 つのパブ/サブギャップを埋めます (#16888、@ntindle)
  • find_session と message_session のスコープを呼び出し側チャットの組織に設定します (#16966、@ntindle)
  • find_session と message_session は RPC 経由でセッションを読み取ります (#16858、@ntindle)
  • チャットのスキル インデックスを 15 分間保持し、フォローアップによる再構築を停止します (#15985、@ntindle)
  • メッセージのペイウォールを開始し、セッション チェックの横にインフライト読み取りを実行します (#15779、@ntindle)
  • ターンのチェックでオーナーのスコープの横にあるエキスパートの行を読み取ります (#15854、@ntindle)
  • セッションや次のシーケンスを再読せずにチャット メッセージを保存する (#15486、@ntindle)
  • チャット メッセージとそのセッションのフィールドを 1 つのトランザクションで保存 (#15987、@ntindle)

ビルダーとワークフロー

  • ビルダーのテキストフィールドで Ctrl/Cmd+Z を実行すると、ワークフローではなくテキストが元に戻されます (#17035、@kcze)
  • 保存後にロードされた 1 つのスナップショットからビルダー グラフを保存する (#17021、@ntindle)
  • 保存されたレビューの決定はセーフ モードよりも優先されます (#16874、@ntindle)
  • 相関クエリを使用してノードの待機中の実行を検索するため、ビジーなピン名によってタイムアウトすることはありません (#16835、@Pwuts)
  • 4 つのワークフローをスコープし、リクエストの組織へのルートを実行します (#16931、@Pwuts)
  • APS マッピングの前に、Unix cron 曜日トークンを曜日セットに拡張します (#15321、@ntindle)
  • APScheduler が受け入れるようにカスタム cron 間隔をバインドしました (#15322、@ntindle)

統合とブロック

  • ネイティブ並列プロバイダーを使用したグループ並列検索 MCP (#16572、@Iitian001)
  • テキスト情報の抽出における正規表現エラーを表面化。 Match Text Pattern で偽のデータを転送する (#15313、@ntindle)
  • スプレッドシートの読み取りは、短く、不規則で、重複ヘッダーと空白行の CSV を処理します (#15317、@ntindle)
  • ショートブロック入力エラーメッセージ (#17000、@kcze)

プラットフォームとセルフホスティング

  • スワップ プロキシ trust の背後にあるボックス、その署名 CA (#16627、@kcze)
  • アップロードを拒否する clamd は、部分的にスキャンする代わりに全体をスキャンできません。バンドルされた ClamAV の制限が 256M に上昇 (#16694、@ntindle)
  • ストレージが早期に終了したストリーミング ダウンロードを再開し、それを抑制する gzip を停止します (#16838、@Pwuts)
  • 検証ログとエラーレポートの認証情報マスキングを強化 (#16956、@ntindle)
  • リクエストの認証情報をエラー レポートやログに記録しないようにします (#16908、@ntindle)
  • 管理者がキューに入れ直してスタックした実行を公開します (#15328、@ntindle)
  • 何かがカットされた場合にのみメモリ グラフの切り捨てを報告する (#16762、@67-luck)

その他の修正

  • カードを展開した状態でサブスクリプションを読み取ることで、失敗したトライアルの [今すぐ支払う] ボタンを表示します (#16834、@Pwuts)
  • 翻訳拡張機能がホームで提案されたタスクを破壊しないようにしました (#16776、@sentry[bot])
  • e2e からのアバター イメージのハング アンド ドロップ ネットワークアイドル待機を停止します (#17013、@ntindle) 依存関係: 5 つのバンプ (#16945、#16943、#16944、#16946、#16947)。 CI、テスト、開発者ツール: 11 件の変更 (#17012、#16799、#16832、#16918、#16842、#16924、#16914、#16930、#16876、#16859、#16928)。 ドキュメント: 3 つの変更 (#17002、#16892、#16519)。
