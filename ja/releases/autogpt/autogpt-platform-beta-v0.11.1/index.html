AutoGPT autogpt-プラットフォーム-ベータ-v0.11.1

🔥 新機能は何ですか?

⚠️重大な変更

  • #16416 - セルフホスト型インストール: .env.default には Web プッシュ (VAPID) キー ペアが同梱されなくなり、バックエンドは同梱された古いペアでプッシュ通知を送信しなくなります。 make init-env を実行して、インストール用のペアを生成します。単一コンテナーのイメージは、最初の起動時に独自のイメージを生成します。ペアを置き換えると、既存のプッシュ サブスクリプションが無効になります。 NEXT_PUBLIC_VAPID_PUBLIC_KEY は空白のままにすることができ、フロントエンドはバックエンドのキーを使用します (@ntindle による)

新機能

  • #11220 - トリガー ノードと一緒に入力ノードをサポート (@Pwuts による)
  • #14991 - 副操縦士チャットで引数を指定して /commands としてスキルを実行します (@ntindle による)
  • #16582 - チャットに戻るバックグラウンド サブタスクを実際の作業にします (@ntindle による)
  • #16506 - アクセス終了の 3 日前と 1 日前にキャンセルされたトライアルに警告する (@Torantulino による)
  • #16622 - メール変更承認メールに両方のアドレスを明確にします (@Torantulino による)
  • #15488 - 実際のユーザーのワークロードを中心とした k6 負荷テストを再設計します (@ntindle による)
  • #16605 - Tencent Hy4 を LLM カタログに追加します (@ntindle による)

新しいブロック

  • #16561 - Firecrawl Alexandria データ ツール ブロックを追加 (@Torantulino による)
  • #16395 - Exa の現在の API で Exa 統合を最新の状態にします (@Torantulino による)
  • #16393 - 人、会社、Web データ用の Treg ブロックを追加 (@Torantulino による)

機能強化

  • #16446 - GitHub リポジトリの作成は、最初に自動モードで尋ねられます (@Pwuts による)
  • #14377 - 冗長なスキーマ タイトルを削除し、すべてのダイジェスト ノードをウィンドウ化します (@Pwuts による)
  • #12017 - コンテナを推測せずにアップロードされた画像タイプを修正しました (@Otto-AGPT による)

UI/UXの改善

  • #16612 - Tailwind パレットを削除します。役割は唯一の色です (SECRT-3097 C4) (@Abhi1992002 による)
  • #16620 - Meet Otto 画面 (SECRT-3380) の箇条書きを左揃えにします (@Torantulino による)
  • #16623 - 最初のオンボーディング画面 (SECRT-3382) を改善する (@Torantulino による)
  • #16584 - チャット内のアプリ リンクは、中央 click の新しいタブで開きます。外部リンクは常に最初に尋ねます (@kcze による)
  • #16617 - チャット内のラン カードはランが終了するまで続きます (@kcze による)
  • #16587 - チャット実行カードには、実行の失敗または完了が表示されます (@kcze による)
  • #16640 - サイド パネルは、Otto が上書きしたファイルに従います (@kcze による)

バグ修正

  • #16649 - トライアル中に早期に支払うとプランが付与されます (ホットフィックス、SECRT-3388) (by @kcze)
