#モビーdocker-v29.9.0

29.9.0

このリリースのプル リクエストと変更の完全なリストについては、関連する GitHub マイルストーンを参照してください。

  • docker/cli、29.9.0 マイルストーン
  • moby/moby、29.9.0マイルストーン

セキュリティ

Go ランタイム アップデートにより、Docker エンジンの次のセキュリティ脆弱性が修正されます。

  • CVE-2026-97032: HTTP/2 client は、リクエストの送信中に HPACK ヘッダー テーブルのサイズを変更することにより、デーモンをクラッシュさせる可能性がありました。 golang/go#81867
  • CVE-2026-78659: HTTP/2 client は、Trailer ヘッダーで多数のフィールドを宣言し、ヘッダー サイズ制限をバイパスすることでデーモン メモリを使い果たす可能性があります。 golang/go#81857
  • CVE-2026-78663: HTTP/2 client は、ストリームをリセットすることで接続レベルのフロー制御制限をバイパスし、デーモンに制限を超えるリクエスト データをバッファさせる可能性があります。 golang/go#81743
  • CVE-2026-78669: HTTP/2 client は、多くのストリームを開いて初期ウィンドウ サイズを繰り返し変更することにより、デーモン CPU の過度の使用を引き起こす可能性があります。 golang/go#81742
  • CVE-2026-56857: Windows では、データ ルートへの書き込みアクセス権を持つユーザーがそこにジャンクションを配置した場合、デーモンがデータ ルートの外にディレクトリを作成する可能性がありました。 golang/go#81739

golang.org/x/net から v0.60.0 への更新は、同じ HTTP/2 修正を、非推奨の /grpc エンドポイントと、# syntax= ディレクティブによって参照されるイメージなどのフロントエンド コンテナーに対して BuildKit が実行する gRPC サーバーに適用します。

バグ修正と機能強化

-containerd イメージ ストア: lazy-pull デーモン機能を追加して、スナップショッターが既に提供しているレイヤー コンテンツのダウンロードを docker pull がスキップするかどうかを制御します。遅延プルは、既知のリモート スナップショッター (nydus、overlaybd、soci、stargz) ではデフォルトで有効になっています。 白鯨/白鯨#53877 -containerd イメージ ストア: 解凍されたレイヤーが既に存在する場合に必要なレイヤー BLOB をスキップするプルを修正し、イメージは実行可能だがエクスポートまたはプッシュには不完全なままになります。 モビー/モビー#53615

  • 無効な名前の長さではなく無効な文字について言及する、誤解を招く検証エラーを報告する docker container create --name を修正しました。 白鯨/白鯨#53484
  • ルートレス モードでのすべての GET /version リクエストでの RootlessKit API ソケットへの接続リークを修正しました。 モビー/モビー#53836
  • サービス登録解除 (--unregister-service) の冪等化など、Windows サービスの登録と登録解除のクリーンアップを改善しました。 モビー/モビー#53845

パッケージの更新

  • BuildKit を v0.34.0 に更新します。 モビー/モビー#53882
  • Go ランタイムを 1.26.9 に更新します。 docker/cli#7363 -containerd (静的バイナリ) を v2.4.1 に更新します。 白鯨/白鯨#53773

ネットワーキング

  • 既存の IPv4 の動作に合わせて、コンテナ間通信が無効になっているブリッジ ネットワーク上のコンテナ間で IPv6 近隣探索を許可します。 白鯨/白鯨#53723
  • ルーテッド ゲートウェイ モードを使用するネットワークの公開ポートを省略する docker ps および GET /containers/json を修正しました。 白鯨/白鯨#53693
  • 再起動されたデーモンが、ゴシップ クラスターに再参加するまで、ピアのサービス検出およびロード バランシングから削除される可能性があるバグを修正しました。 モビー/モビー#53688
  • ルーティング メッシュを通じて公開された Swarm サービスを含む、コンテナ間通信が無効になっている場合に、同じネットワーク上の別のコンテナから公開ポートに到達できない問題を修正しました。 モビー/モビー#53723
  • オーバーレイ ネットワーク データ プレーンを暗号化するようにカーネルをプログラミングする際のエラーにより、状況によっては一部のノードへの暗号化されたオーバーレイ ネットワーク トラフィックが平文で送信される可能性がある問題を修正します。受信側ピアは暗号化されたオーバーレイ ネットワークの平文パケットをスプーフィングとしてドロップするため、機密性の損失は一方向フロー (例: UDP DNS クエリ) および決して続行されないハンドシェイク試行 (例: TCP SYN) に限定されます。 モビー/モビー#53420
  • 暗黙的な host-gateway マッピングを使用してライブ復元されたコンテナーを追加のネットワークに接続する問題を修正しました。 白鯨/白鯨#53093
  • VXLAN デバイスがすでにピアの動的 FDB エントリを学習している場合、ノードがクラスターに再参加するかサービスが再デプロイされた後、オーバーレイ ピアが到達不能になる問題を修正しました。 白鯨/白鯨#53663
  • デーモンが /var/lib/docker に書き込めない場合にオーバーレイ ネットワーク上の Swarm タスクが拒否される問題を修正。 モビー/モビー#53848
  • ユーザーランド プロキシが有効な場合、公開された Swarm サービス ポートはホストの IPv6 アドレスでアクセスできます。 v29.8.0 で導入された変更により、偶然にもこの機能が有効になりました。これは、v29.9.0 の時点でテストされサポートされている機能です。 白鯨/白鯨#53727
  • デーモンが再起動するまで漏洩するのではなく、最後のコンテナが暗号化されたオーバーレイ ネットワークから離れるときに、ノードの IPsec セキュリティ アソシエーションとポリシーを解放します。 白鯨/白鯨#53420
  • Docker エンジン 28.0.0 以前によって残された、空の DOCKER-INGRESS iptables チェーンとそれにジャンプする FORWARD ルールを削除するロジックを復元します。 白鯨/白鯨#53825

根無し草

  • RootlessKit (3.2.0) をアップデートします。 白鯨/白鯨#53607
