29.10.0

  • docker/cli、29.10.0 マイルストーン
  • 白鯨/白鯨、29.10.0 マイルストーン

⚠️ 破壊的な変更の可能性: ローカル レジストリ接続

daemon.json で insecure-registries を明示的に構成するか、--insecure-registry を使用すると、Docker エンジンはループバック アドレス (127.0.0.0/8 および ::1/128) を安全でないレジストリとして自動的に処理しなくなります。

[!警告] アップグレード後、HTTP または untrusted TLS 証明書を使用するローカル レジストリへのプルとプッシュは、それらのレジストリが安全でないレジストリ構成に明示的に含まれていない限り失敗する可能性があります。 trusted 証明書を使用して TLS を構成するか、必要なローカル レジストリ アドレス (localhost:5000 など) のみを既存の安全でないレジストリ構成に追加します。

insecure-registries が省略された場合、ループバック レジストリはデフォルトで安全でないままになります。 daemon.json で "insecure-registries": [] を設定すると、デフォルトの安全でないレジストリがすべて無効になります。 白鯨/白鯨#53868

🧻 エンジン API の仕様は OpenAPI 3.2 に移行

Engine API 仕様では、ソース形式として OpenAPI 3.2 を api/openapi.yaml で使用するようになりました。 そこから生成された Swagger 2.0 仕様は、api/swagger.yaml で既存のツール用に現在も公開されています。 移行のために、このリリースには、api/docs/v1.57-swagger.yaml の API v1.57 に固定された Swagger 2.0 コピーも含まれています。 将来の API バージョンでは、バージョンごとの Swagger 2.0 コピーが取得されないため、これらのファイルに依存するツールを更新して、OpenAPI 3.2 仕様を使用します。 モビー/モビー#53630

📦 AlmaLinux、Oracle Linux、および Rocky Linux のパッケージ

Docker エンジン パッケージは、AlmaLinux、Oracle Linux、および Rocky Linux で使用できます。 インストール手順については、AlmaLinux、Oracle Linux、および Rocky Linuxを参照してください。

新しい

  • ジョブの実験的サポートを追加します。--enable-extension org.mobyproject.jobs.v0 で有効になるオプトインの組み込み拡張機能として、デーモンによってネイティブに管理されるワンショットおよび cron スケジュールされたワークロードを実行します。 モビー/モビー#53485
  • /etc/docker/containerd.d/ の構成ファイルを使用して、Docker の組み込みコンテナーをカスタマイズするためのサポートを追加します。 白鯨/白鯨#53946
  • die イベントに restarting 属性を導入して、コンシューマにコンテナが再起動されることを知らせます。 モビー/モビー#50908

バグ修正と機能強化

  • デフォルトの AppArmor および seccomp プロファイルで古いソケット ファミリをブロックします。 モビー/モビー#54093 -containerd イメージ ストア: マルチプラットフォーム イメージのホスト プラットフォームがプルされていないが、別のプラットフォームがプルされている場合に、空のイメージを報告する docker image inspect および docker image ls を修正しました。 白鯨/白鯨#54040
  • OTLP エンドポイントが接続を拒否した場合、テレメトリ エクスポート タイムアウトを待たないでください。 docker/cli#7495
  • 「不明なコマンド」エラーの代わりに CLI バージョンを出力する docker <unknown-command> --version を修正しました。 docker/cli#7408
  • コピーが失敗した場合に「コピーに成功しました」というメッセージが出力される docker cp を修正しました。 docker/cli#7515
  • linux/loong64 など、事前定義された OS/アーキテクチャの組み合わせのリストに含まれていない有効なプラットフォームを拒否する docker manifest annotate を修正しました。 docker/cli#7448
  • クラシック Swarm API に接続されている場合など、すべてのコンテナー名にスラッシュが含まれている場合に空の NAMES 列を出力する docker ps を修正しました。 docker/cli#7481
  • ユーザー管理のブリッジとデフォルト アドレス プールが設定されている場合に、再起動時に docker0 インターフェイスを削除するデーモンを修正しました。 モビー/モビー#54157
  • NTFS スパース ファイルを含む Windows レイヤーのエクスポートを修正しました。 モビー/モビー#53745
  • 修正: clients が失敗を正しく分類できるように、JSON ストリーミング エラーに HTTP ステータス コードを含めます。 白鯨/白鯨#54133
  • ARM64 Linux ホストでのイメージ選択を改善し、ホスト CPU でサポートされている最高のイメージ バリアントを優先します。 モビー/モビー#53910
  • マニフェスト アノテーション: --os および --arch のシェル補完を追加します。 docker/cli#7449
  • 省略表現と明示的なカウント オプションが混在している場合、重複した GPU カウントを一貫して拒否します。 docker/cli#7312
  • insecure-registries が明示的に構成されている場合にループバック レジストリを安全でないものとして自動的に扱うのを停止し、daemon.json で "insecure-registries": [] を設定することでデフォルトの安全でないレジストリを無効にできるようにします。 白鯨/白鯨#53868
  • runc (静的バイナリ内) を v1.5.3 に更新します。 モビー/モビー#54183

パッケージの更新

  • BuildKit を v0.35.0 に更新します。 モビー/モビー#54180
  • Go ランタイムを 1.27.4 に更新します。 モビー/モビー#54176、docker/cli#7506

ネットワーキング

  • nftables ファイアウォール バックエンドを使用するエンジンが Swarm に参加できるようになりました。 (実験的)。 白鯨/白鯨#53125
  • ネットワークのランダムなサブセットをリストする docker network ls --filter type=builtin --filter type=custom を修正しました。 白鯨/白鯨#54127
  • nftables ファイアウォール バックエンドとユーザーランド プロキシが無効になっている状態で、同じコンテナ ポートに対して複数のホスト ポートを公開すると発生する「ルールが存在します」エラーを修正しました。 白鯨/白鯨#54031
  • 公開ポートがすでに使用されているなど、ネットワーク エラーにより以前の起動に失敗した後、ネットワークなしでコンテナが起動する問題を修正しました。 白鯨/白鯨#52480
  • ホストの /etc/resolv.conf が見つからない場合、または有効なネームサーバーが含まれていない場合の、ユーザー定義ネットワークでの DNS 解決を修正します。 モビー/モビー#54140
  • 28.0.1 よりも古いリリースが iptables で実行された後、デーモンが nftables ファイアウォール バックエンドに切り替わったときに残される iptables ルールと空の DOCKER チェーンを修正しました。 モビー/モビー#54129
  • firewalld が停止された後、またはデーモンの後に開始された後、iptables ルールが復元されない問題を修正しました。 モビー/モビー#54012
  • コンテナが別のノードで削除されたばかりのコンテナの IP アドレスを取得するときのオーバーレイ ネットワーク ドライバのエラーを修正しました。 モビー/モビー#53833
  • Swarm マネージャーが新しいアドレスに置き換えられた場合、ネットワーク分割後にオーバーレイ ネットワークが再収束できない問題を修正しました。 白鯨/白鯨#53715
  • 1 つのネットワークで割り当てが失敗するたびに、他のネットワーク上で仮想 IP アドレスを漏洩する swarm サービスを修正します。これにより、それらのネットワークのサブネットが使い果たされる可能性があります。 モビー/モビー#54148
  • ufw などのホスト ファイアウォールが一方的な受信トラフィックをドロップした場合に、Swarm タスクが自身のノードのアドレス経由でサービスの公開ポートに到達できない問題を修正しました。 白鯨/白鯨#54006
  • Swarm データ パスが IPv6 の場合、オーバーレイ ネットワーク インターフェイスの MTU が 20 バイト大きすぎる問題を修正しました。 白鯨/白鯨#54067
  • エンドポイントおよびアドレス ファミリごとにファイアウォールの更新をバッチ処理することで、nftables のポート公開のオーバーヘッドを削減します。 白鯨/白鯨#54011
  • クラスターが正常な場合、Swarm クラスター内のノードがすべてのマネージャーと完全なオーバーレイ ネットワーク状態を 1 分に 1 回交換するのを停止します。 白鯨/白鯨#53715

根無し草

  • SELinux が有効な場合、rootless モードでの overlay2 ストレージ ドライバーを許可します。 モビー/モビー#54048
  • nosuid または nodev ファイルシステムからの読み取り専用バインド マウントを持つコンテナーでルートレス モードで「remount-ro ... 操作は許可されていません」というエラーで失敗する docker cp を修正しました。 モビー/モビー#53981

API

  • API バージョンを 1.57 に更新します。 モビー/モビー#53972
