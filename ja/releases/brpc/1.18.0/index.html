#brpc1.18.0

Apache bRPC 1.18.0 は、プロトコルの適用範囲とプラットフォームのサポートを拡大し、パーサーとトランスポート内部を大幅に強化します。

特徴

  • @rajvarun77 によるクリーンルーム認証、テキスト プロトコル、トランザクション、プリペアド ステートメントを備えた MySQL client プロトコルを追加 (#3330)
  • @neilxxxxx による TLSv1.3 のサポート (#3319)
  • @wasphin による Protobuf v35 のサポート (#3429)
  • @wasphin によるフロー制御された gRPC client リクエストをサポート (#3430)
  • @wwbmmm による clients の TLS ピア名検証を追加 (#3408)
  • @yanglimingcn による本文と一緒に添付ファイルのチェックサムをサポート (#3407)
  • @chenBright による RDMA ハンドシェイク プロトコル V3 をサポート (#3350、#3326)
  • @chenBright による RDMA ハンドシェイク V3 でのエンドツーエンド ECE ネゴシエーションをサポート (#3352)
  • @zchuango による LD/ST 共有メモリ セマンティクスに基づく UBShmTransport 経由の相互接続 (#3290)
  • @rajvarun77 による Power-of-Two-Choices Peak-EWMA (p2c) ロード バランサーを追加 (#3367)
  • @rajvarun77 による制限付きロードの整合性ハッシュ (c_murmurhash_bl) ロード バランサを追加 (#3502)
  • @chenBright によるゼロコピー I/O 用の IOBuf<->std::iostream アダプターの追加 (#3341)
  • @Felix-Gong による RISC-V Zvbc ベクトル CRC32C アクセラレーションを追加 (#3332)
  • @chenBright による LeakSanitizer をサポート (#3361)
