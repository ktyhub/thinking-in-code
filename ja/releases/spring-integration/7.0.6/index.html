spring-integration v7.0.6

パッチ 公開日2026年8月20日 出典spring-projects/spring-integration 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

スプリング一体型 v7.0.6

:star: 新機能

  • デバッグログのためだけに JmsOutboundGateway.onMessageSync() 内の間違ったメッセージを変換しないでください #11212

:lady_beetle: バグ修正

  • CVE-2026-47856: JsonToObjectTransformer は、許可リストなしで json__TypeId__ メッセージ ヘッダーを任意のクラスに解決します #11337
  • CVE-2026-47859: RFC6587SyslogDeserializer (オクテットカウントフレーミング) における無制限のメモリ割り当て — リモート DoS #11335
  • CVE-2026-47862: ZipTransformer は file_name ヘッダーを使用して、サニタイズなしで workDirectory パスを構築します #11333
  • CVE-2026-47864: SerializingHttpMessageConverter での安全でない Java 逆シリアル化 — リモート コード実行 #11330
  • CVE-2026-59324: 同時実行時の fluxTransform() でのクロスメッセージ ヘッダー リークを修正 #11327
  • CVE-2026-59321: スレッドセーフではないエンジンの AbstractScriptExecutor を修正 #11325
  • CVE-2026-59322: EmbeddedHeadersJsonMessageMapper のデフォルトをヘッダーなしに変更 #11322
  • CVE-2026-59311: zip トランスフォーマーが一時ファイルをシンボリックリンクに書き込めないようにします #11319
  • CVE-2026-59292: メタデータ ストア ファイルのアクセス許可制御を追加 #11318
  • CVE-2026-59307: JdbcMessageStore: setBeanClassLoader #11315 上の新しい mapper
  • CVE-2026-59293: SMB のデフォルト バージョンを SMB202 #11312 に設定します
  • CVE-2026-59274: UnzipTransformer にサイズ制約オプションを追加 #11309
  • CVE-2026-47880: toHeaders でデフォルトでプロパティをスキップする #11306
  • CVE-2026-47861: UDP アダプターは、acknowledge=false の場合でも、パケット本体から解析された攻撃者が指定したホスト:ポートに ack を送信します #11304
  • FileWritingMessageHandler: 同じ宛先ディレクトリの同時自動作成が失敗し、「宛先ディレクトリ [...] を作成できませんでした。」 #11258
  • JdbcMetadataStore putIfAbsent が、MySQL データベースで while ループに陥る可能性があります。 #11256
  • ZookeeperLockRegistry テストの分離と割り込み処理を修正 #11246
  • 動的 IntegrationFlow 登録により、追加コンポーネントおよび内部コンポーネントの依存関係の挿入がスキップされる #11216
  • AcceptOnceFileListFilter #11195 での同時競合状態
  • バッチ モードの KafkaMessageDrivenChannelAdapter がメッセージ ID を生成しないため、スプリッターが失敗します #11186
  • Redis ロックは一意ではありません #11182
  • JdbcLockRegistry #11173 のキャッシュ容量を調整
  • JDBC ロックが一意ではありません #11171
  • lockKey および waitLockDuration の関数の戻り値の型 @Nullable をマーク #11169
  • JdbcLockRegistry および RedisLockRegistry - DefaultLockRegistry からの共有 ReentrantLock により、2 つの異なるロック キーが同じバケットにマップされている場合、ロック解除時に APP_LOCK エントリが削除されません #11155
  • AbstractWebServiceInboundGateway から client に一般エラーをスローする #11148
  • ZooKeeper レジストリ #11135 からの保持されたロックの削除を防止します。
  • BaseIntegrationFlowDefinition.REFERENCED_REPLY_PRODUCERS は同時にアクセスできます #11129
  • Java DSL でインバウンド JMS コンポーネントのチャネル名を指定すると、BeanFactory がないために起動エラーが発生する #11125
  • DatagramPacketMessageMapper #11119 のマルチバイト ACK ヘッダー オフセットを修正
  • ハッシュ コードが Integer.MIN_VALUE #11117 の場合、PartitionedDispatcher.dispatch() は IndexOutOfBoundsException で失敗します。
  • 正規ファイルを処理できるように FileReadingMessageSource を修正 #11104

:notebook_with_decorative_cover: ドキュメント

  • FileHeaders.ORIGINAL_FILE を機密メタデータとして文書化 #11218
  • storedProcedureNameExpression #11217 のセキュリティへの影響を文書化します。
  • RedisHeaders.COMMAND を機密メタデータに含める #11211
  • コントロール バス コントローラー #11208 のセキュリティ上の懸念について言及
  • FileWritingMessageHandler.trigger() Javadoc では ReDoS #11133 について言及する必要があります。
  • AI 支援用に AGENTS.md と CLAUDE.md を追加 #11102

:hammer: 依存関係のアップグレード

  • マイクロメーター トレースを 1.6.7 #11301 にアップグレード
  • マイクロメーターを1.16.7 #11298にアップグレード
  • リアクターを2025.0.7 #11296にアップグレード
  • spring-amqp を 4.0.5 #11293 にアップグレードします
  • spring-graphql を 2.0.5 #11291 にアップグレードします
  • spring-kafka を 4.0.7 #11289 にアップグレードします
  • スプリングセキュリティを 7.0.7 #11287 にアップグレード
  • スプリングフレームワークを 7.0.9 #11285 にアップグレード
  • spring-data-bom を 2025.1.7 #11283 にアップグレードします
  • org.apache.groovy:groovy-bom を 5.0.7 から 5.0.8 にバンプ #11237
  • graalvm 25.0.3 から 25.0.4 へのバージョンをバンプ #11202
  • org.apache.logging.log4j:log4j-bom を 2.25.4 から 2.25.5 にバンプ #11177
  • org.apache.groovy:groovy-bom を 5.0.6 から 5.0.7 にバンプ #11162
  • org.jruby:jruby-complete を 10.0.5.0 から 10.0.6.0 にバンプ #11110
