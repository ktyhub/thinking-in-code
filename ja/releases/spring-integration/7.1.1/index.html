spring-integration v7.1.1

パッチ 公開日2026年8月20日 出典spring-projects/spring-integration 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

スプリング一体型 v7.1.1

:star: 新機能

  • デバッグログのためだけに JmsOutboundGateway.onMessageSync() 内の間違ったメッセージを変換しないでください #11197
  • Redis 7 サーバーが DELEX #11137 をサポートしていないことを警告しない

:lady_beetle: バグ修正

  • CVE-2026-47856: JsonToObjectTransformer は、許可リストなしで json__TypeId__ メッセージ ヘッダーを任意のクラスに解決します #11340
  • CVE-2026-47859: RFC6587SyslogDeserializer (オクテットカウントフレーミング) における無制限のメモリ割り当て — リモート DoS #11338
  • CVE-2026-47862: ZipTransformer は file_name ヘッダーを使用して、サニタイズなしで workDirectory パスを構築します #11334
  • CVE-2026-47864: SerializingHttpMessageConverter での安全でない Java 逆シリアル化 — リモート コード実行 #11332
  • CVE-2026-59324: 同時実行時の fluxTransform() でのクロスメッセージ ヘッダー リークを修正 #11329
  • CVE-2026-59321: スレッドセーフではないエンジンの AbstractScriptExecutor を修正 #11326
  • CVE-2026-59322: EmbeddedHeadersJsonMessageMapper のデフォルトをヘッダーなしに変更 #11323
  • CVE-2026-59311: zip トランスフォーマーが一時ファイルをシンボリックリンクに書き込めないようにします #11320
  • CVE-2026-59292: メタデータ ストア ファイルのアクセス許可制御を追加 #11317
  • CVE-2026-59307: JdbcMessageStore: setBeanClassLoader #11313 上の新しい mapper
  • CVE-2026-59293: SMB のデフォルト バージョンを SMB202 #11310 に設定します
  • CVE-2026-59274: UnzipTransformer にサイズ制約オプションを追加 #11308
  • CVE-2026-47880: toHeaders でデフォルトでプロパティをスキップする #11305
  • CVE-2026-47861: UDP アダプターは、acknowledge=false の場合でも、攻撃者が指定したホスト:パケット本体から解析されたポートに ack を送信します #11302
  • FileWritingMessageHandler: 同じ宛先ディレクトリの同時自動作成が失敗し、「宛先ディレクトリ [...] を作成できませんでした。」 #11257
  • JdbcMetadataStore putIfAbsent が、MySQL データベースで while ループに陥る可能性があります。 #11255
  • ZookeeperLockRegistry テストの分離と割り込み処理を修正 #11245
  • 動的 IntegrationFlow 登録により、追加および内部コンポーネントの依存関係の挿入がスキップされる #11196
  • AcceptOnceFileListFilter #11185 での同時競合状態
  • バッチ モードの KafkaMessageDrivenChannelAdapter がメッセージ ID を生成しないため、スプリッターが失敗します #11183
  • Redis ロックは一意ではありません #11180
  • JdbcLockRegistry #11172 のキャッシュ容量を調整
  • lockKey および waitLockDuration の関数の戻り値の型 @Nullable をマーク #11168
  • JDBC ロックが一意ではありません #11157
  • AbstractWebServiceInboundGateway から client に一般エラーをスローする #11147
  • JdbcLockRegistry および RedisLockRegistry - DefaultLockRegistry からの共有 ReentrantLock により、2 つの異なるロック キーが同じバケットにマップされている場合、ロック解除時に APP_LOCK エントリが削除されません #11146
  • BaseIntegrationFlowDefinition.REFERENCED_REPLY_PRODUCERS は同時にアクセスできます #11127
  • DatagramPacketMessageMapper #11115 のマルチバイト ACK ヘッダー オフセットを修正しました。
  • ハッシュ コードが Integer.MIN_VALUE #11114 の場合、PartitionedDispatcher.dispatch() は IndexOutOfBoundsException で失敗します。
  • ZooKeeper レジストリ #11113 からの保持されたロックの削除を防止します。
  • Java DSL でインバウンド JMS コンポーネントのチャネル名を指定すると、BeanFactory がないために起動エラーが発生する #11107
  • 正規ファイルを処理できるように FileReadingMessageSource を修正 #11103

:notebook_with_decorative_cover: ドキュメント

  • RedisHeaders.COMMAND を機密メタデータに含める #11201
  • storedProcedureNameExpression #11200 のセキュリティへの影響を文書化します。
  • FileHeaders.ORIGINAL_FILE を機密メタデータとして文書化 #11199
  • コントロール バス コントローラー #11198 のセキュリティ上の懸念について言及
  • FileWritingMessageHandler.trigger() Javadoc では ReDoS #11132 について言及する必要があります。
