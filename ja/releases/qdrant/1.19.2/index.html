qdrant v1.19.2

変更ログ

改善点

  • https://github.com/qdrant/qdrant/pull/10682 - アップサートのたびに完全なスパース ポスティング リストを書き換えないようにし、スパース ベクターのアップサートを大幅に高速化します。
  • https://github.com/qdrant/qdrant/pull/10349, https://github.com/qdrant/qdrant/pull/10445, https://github.com/qdrant/qdrant/pull/10661, https://github.com/qdrant/qdrant/pull/10700 - プロキシ セグメントの状態を永続化し、WAL の固定と再起動時の長い回復時間を防ぎます。
  • https://github.com/qdrant/qdrant/pull/10686 - HNSW ビルドが割り当てられたすべてのスレッドを常に飽和させるわけではない問題を修正
  • https://github.com/qdrant/qdrant/pull/10624 - フィルター ID を検索リクエストごとに 1 回だけ解決し、パフォーマンスを向上させます。
  • https://github.com/qdrant/qdrant/pull/10853 - 内部 gRPC を別のネットワーク インターフェイスにバインドできるようにします
  • https://github.com/qdrant/qdrant/pull/10852 - API キーが設定されていない場合に起動警告を追加します
  • https://github.com/qdrant/qdrant/pull/10891 - Raft スナップショット中にコレクション ロックを保持しません。以前はすべてのコレクションへのアクセスがブロックされていました。
  • https://github.com/qdrant/qdrant/pull/10570 - 再選挙の時間を確保するために、コンセンサス同期の待機時間を 2 倍にします
  • https://github.com/qdrant/qdrant/pull/10617 - ブロッキング スレッドでキュー プロキシ バッチをエンコードし、Tokio ランタイムのブロックを防止します
  • https://github.com/qdrant/qdrant/pull/10480 - セグメント マニフェストの同期中に更新をブロックしないようにする
  • https://github.com/qdrant/qdrant/pull/10541 - 最適化の計画中に更新のブロックを防止します
  • https://github.com/qdrant/qdrant/pull/10610 - ランタイムのブロックを防ぐために、BM25 スパース埋め込みをブロック スレッドに移動します。
  • https://github.com/qdrant/qdrant/pull/10599 - キュー プロキシ WAL 読み取りの移動と非同期ランタイムからのバッチ構築
  • https://github.com/qdrant/qdrant/pull/10794 - ポイント数によるバインドされたカーディナリティの推定
  • https://github.com/qdrant/qdrant/pull/10618 - テレメトリでリシャーディング状態を公開する
  • https://github.com/qdrant/qdrant/pull/10458 - 並列ワーカーを使用してメモリ統計のレポートをより効率的にする
  • https://github.com/qdrant/qdrant/pull/10813 - スナップショット転送コメント内の転送バイト数とレートをレポートします。
  • https://github.com/qdrant/qdrant/pull/10781 - テレメトリでの Acorn 検索統計のレポート
  • https://github.com/qdrant/qdrant/pull/7714 - 失敗した転送の数をメトリクスに追加します (collection_shard_transfer_failed)
  • https://github.com/qdrant/qdrant/pull/10542 - 「セグメントの読み取りロックを試みています」ログ行に反復回数を追加
  • https://github.com/qdrant/qdrant/pull/10714 - コレクション スナップショット用に GCS および Azure Blob Storage をサポート
  • https://github.com/qdrant/qdrant/pull/10715 - オブジェクト ストレージ スナップショットに構成可能なプレフィックスを追加

バグ修正

  • https://github.com/qdrant/qdrant/pull/10903 - HNSW エントリ ポイントがフィルタを満たさない場合の検索結果がゼロになる問題を修正
  • https://github.com/qdrant/qdrant/pull/10870 - インデックス付きコレクションの分割検索への名前付きマルチベクトルの追加を修正
  • https://github.com/qdrant/qdrant/pull/10577 - データの不整合をフラッシュして修正するときに、未完了の操作を要求しない
  • https://github.com/qdrant/qdrant/pull/10507, https://github.com/qdrant/qdrant/pull/10531 - 一部の名前付きベクトルまたはペイロード インデックスの変更を伝播しないプロキシ セグメントを修正
  • https://github.com/qdrant/qdrant/pull/10837 - 以前はストレージを破損する可能性があったすべての Gridstore ストレージでの書き込みティアリングを防止します
  • https://github.com/qdrant/qdrant/pull/10812 - 破損した書き込み時にロードできない可変ペイロード インデックスを修正し、クラッシュ ループを引き起こす
  • https://github.com/qdrant/qdrant/pull/10643 - ピアの回復時に他のピアを破壊する古いスナップショット転送を修正
  • https://github.com/qdrant/qdrant/pull/10897 - 配列インデックスを持つパス上の group_by を修正
  • https://github.com/qdrant/qdrant/pull/10567 - オフセットによる MMR ページネーションを修正
  • https://github.com/qdrant/qdrant/pull/10878 - マージ前にベクトル距離によって順序付けされていない MMR 候補を修正し、精度を向上させます。
  • https://github.com/qdrant/qdrant/pull/10593 - インデックスのないペイロード フィールドでの TextAny の一致を修正
  • https://github.com/qdrant/qdrant/pull/10777 - 2 ホップ Acorn がキャップされていない問題を修正
  • https://github.com/qdrant/qdrant/pull/10855 - 内部 gRPC API 呼び出しで alt_api_key が使用されない問題を修正
  • https://github.com/qdrant/qdrant/pull/10862 - min_token_len > max_token_len でフルテキスト フィルターを拒否します。
  • https://github.com/qdrant/qdrant/pull/10277 - コンセンサス開始時にすでに適用されたコミットされたエントリを再適用しない

セキュリティ

  • https://github.com/qdrant/qdrant/pull/10758 - 内部 gRPC API では読み取り/書き込み API キーのみを受け入れます
  • https://github.com/qdrant/qdrant/pull/10556 - コレクション構成なしでスナップショットをアップロードするときにログ内のパスを公開しない
