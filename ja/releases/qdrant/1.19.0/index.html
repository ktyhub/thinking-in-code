qdrant v1.19.0

変更ログ

機能 :point_up:

  • https://github.com/qdrant/qdrant/milestone/50 - プライマリ ベクトル ストレージのデータ型としての TurboQuant 4 ビット。 4 ビットの量子化ベクトルと予備のディスク領域のみを元のベクトルに保存します。 [ドキュメント]
  • https://github.com/qdrant/qdrant/pull/9669, https://github.com/qdrant/qdrant/pull/9684, https://github.com/qdrant/qdrant/pull/9950 - コレクション コンポーネントのメモリ使用戦略の定義を統一します。 "memory": "cold" / "cached" / "pinned" を使用して、個々のコレクション コンポーネントのメモリ動作を定義します。メモリの使用量とパフォーマンスをよりきめ細かく制御できます。 [ドキュメント]
  • https://github.com/qdrant/qdrant/pull/9683 - filter の "match": {"prefix": "..."} がプレフィックスによるキーワードの一致を許可します。キーワード インデックスで有効にする必要があります。 [ドキュメント]
  • https://github.com/qdrant/qdrant/pull/9661 - スパース ベクトル検索用のクエリごとの IDF コーパス [docs]
  • https://github.com/qdrant/qdrant/pull/9899 - スライス フィルタリング条件: スライス スクロール / 決定論的サンプリング [docs]
  • https://github.com/qdrant/qdrant/pull/10035 - グローバル クォータ API [docs]
  • https://github.com/qdrant/qdrant/pull/9338 - 確定的な読み取りルートのルーティング トークンを追加 [docs]

  • https://github.com/qdrant/qdrant/pull/9778 - 不変インデックスの AHashSet によるサブハッシュの重複除去により、パフォーマンスが向上します
  • https://github.com/qdrant/qdrant/pull/9784 - 不変インデックスの値ごとではなく、一度削除されたポイントをマークし、パフォーマンスを向上させます。
