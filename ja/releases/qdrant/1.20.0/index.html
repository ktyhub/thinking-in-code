qdrant v1.20.0

#Changelog

特徴 🎶

  • #10750 - フルテキスト ペイロード インデックスに直接基づく BM25 スコアリング [docs]
  • マイルストーン #57 - TurboQuant: 新しい turbo8 および turbo16 ベクトル データ型 [docs]
  • #11125 - 要素ごとのペイロード インデックス: 新しい nested インデックス パラメーター、ネストされた条件フィルターの高速化。 [ドキュメント]
  • #11180、#11263 - フルテキスト インデックス用の新しい code トークナイザー [docs]
  • #10466 - 構成可能な監査ログ出力: audit.output は監査イベントを file (デフォルト)、stdout または stderr に書き込みます [docs]
  • #10992 - コレクション作成時間: created_at が記録され、コレクション情報 [docs] に返されます。
  • #10711 - 部分文字列フィルター条件: match: { substring: "..." } (フルスキャンのみ) [docs]
  • #10231、#10287、#10296 - 新しい数式クエリ式: acosh、max、min [docs] および [docs]
  • #10597、#10598 - 構成可能な ID トラッカーのメモリ配置 [docs]

改善点 🎵

  • #11009、#11020 - HNSW ペイロード リンクの構築が高速化 - ビルダーのサイズがセグメントではなくブロックに合わせて再利用される
  • #11083 - HNSW 修復の高速化 - ペイロード ブロックは古いグラフ リンクを再利用します。 m = 0 グラフも回復できる
  • #11166 - 小規模な HNSW 上位層 - レベル割り当ての floor() は HNSW の論文と一致します (m = 16 でのレベル 1 のポイントの 6.25% であり、25% ではありません)
  • #10976 - PQ トレーニングの高速化 - チャンクごとに 1 つではなく、1 つのパスで収集された K-means サンプル
  • #10975 - 高速なスカラー量子化検索 - int8 ドット積用の AVX512-VNNI および AVX-VNNI カーネル
  • #10977 - 最適化中の検索速度の低下が軽減 - 最適化ジョブ全体が低いスレッド優先度で実行されます
  • #11078、#11080 - キャンセルされる最適化が少なくなります - オプティマイザーは構成が変更された場合にのみ再作成されます
  • #11234 - ポイントの取得が高速化 - ID はセグメントごとに 1 つのバッチで解決されます
  • #11070 - スナップショットの転送とダウンロードの高速化 - 4 KiB ではなく 4 MiB のストリーム バッファー
  • #11253 - シャード転送の高速化 - transfer_raw_points および transfer_raw_payloads がデフォルトでオン
  • #11206 - より安全なスナップショット - 一意のスナップショット名、保存されたスナップショットは上書きされません
  • #11221 - スナップショットのダウンロードが停止しない - サーバーが応答しない場合の 60 秒のタイムアウト
  • #11163 - テレメトリ タイムアウト時にブロック スレッド リークがありません - タイムアウトはブロック タスク内にも適用されます
  • #11164 - tar 解凍エラーをより明確に - リリース ビルドでは、「不正な形式のアーカイブ」ではなく、エラーの種類 (例: timed out) が報告されます。
  • #11118 - タイムゾーンを考慮したログのタイムスタンプ - TZ 環境変数で設定され、デフォルトでは UTC
  • #10235 - ポイント取得のtimeoutパラメータ API
  • マイルストーン #58 - hnsw_config.inline_storage によるディスク使用量の削減 - ベクトルは HNSW グラフ ファイル内にのみ保存され、別個のベクトル ストレージ コピーは必要ありません
  • #10790 - ペイロード インデックスの enable_hnsw 変更が高速化 - インデックスを削除して再構築するのではなく、適切な場所で更新されます
  • #10906 - ディスク上のベクトルの検索が高速化 - スコアリング前にベクトルのバッチが madvise(WILLNEED) でプリフェッチされます
  • #10907 - m = 0 グラフ上の ACORN - 検索ではグラフのペイロード ブロック リンクが使用されます
  • #11255 - 小規模クラスターでのシャード分散の改善 - 自動シャード化されたコレクションは、コレクションがノードよりも少ない場合でも、3 ノード以上のクラスターではノードごとに 2 つのシャードを取得します
  • #11273 - NAT およびロード バランサーの背後で内部リクエストが停止することはありません - 内部 p2p gRPC での HTTP/2 キープアライブ
  • #11289 - 構成可能なスナップショット ストレージのタイムアウトと再試行 - S3、GCS、Azure 構成の新しい timeout_sec、connect_timeout_sec、max_retries、retry_timeout_sec

バグ修正 🎼

  • #10932、#10971 - シャード転送でシャードホルダーのロックが保持されている間にコレクション読み取りが停止する問題を修正しました。
  • #10949 - シャード転送の開始とコンセンサス操作の間のライブロックを修正しました
  • #10956 - シャードスナップショットの抽出中にブロックされるコレクションを修正しました
  • #11075 - インデックス付きのmust条件と等しい場合に無視されるmust_not条件を修正しました。
  • #11101 - ペイロードインデックスがある場合とない場合で動作が異なるマイクロ秒の日時フィルターを修正しました。
  • #10948 - 受け入れられる既存のコレクション名へのエイリアスの名前変更を修正しました。
  • #10887 - 転送中止中のレプリカ削除のクラッシュリプレイ後に転送が登録されたままになる問題を修正しました。
  • #11121 - ローカル読み取りエラーにより完了する S3 スナップショットのアップロードが切り詰められる問題を修正しました。
  • #10796 - min_token_len、max_token_len、stemmer、ascii_folding、および大文字と小文字を区別しないストップワードを無視する日本語トークナイザーを修正しました。
  • #10754 - MSVC のようなコンパイラ (clang-cl) を使用した量子化ビルドを修正しました。

セキュリティ 🔑

  • #10854 - デフォルトで内部認証が強制されます: API キーが設定されている場合、service.enforce_internal_auth はデフォルトで true に設定されるようになりました
  • #10718 - 分散モードで API キーが構成されているが、enforce_internal_auth がオフになっている場合の起動警告
  • #11275、#11290 - . や .. など、セグメント ディレクトリをエスケープするベクター名を拒否します
  • #11278 - RUSTSEC-2026-0382 および RUSTSEC-2026-0383 の rustls-webpki および webpki-root-certs を更新します。

Qdrant エッジ 📀

  • #11085 - エッジシャードのWALレスモード: EdgeConfig::wal_enabled(false)はWAL書き込みをスキップし、flush()後も更新は永続的です
  • #11084 - クラッシュ時に失われる更新を修正: エッジシャードがロードされると未確認の WAL 操作が再実行される
  • #11082 - WALで永続化されたバージョンを認識しないEdgeShard::flushを修正しました。
