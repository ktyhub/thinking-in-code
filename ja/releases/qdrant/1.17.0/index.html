Qdrant エッジ :hocho:

Qdrant Edge は Qdrant のインプロセス バージョンで、同じ内部構造、ストレージ形式、サーバー バージョンと API を共有しますが、ローカルで動作するように設計されています。 Qdrant Edge はサーバー バージョンと互換性があり、Qdrant のサーバー バージョンで作成されたシャード スナップショットを読み取ることができます。詳細なドキュメントはこちらから入手できます。

非推奨 :警告:

  • v1.17.0 以降、Qdrant は gRPC インターフェイスのベクトル フィールドの応答形式を変更します。すべての公式 Qdrant client はこの変更にすでに適用されているはずなので、必ず client ライブラリをアップグレードし、非推奨のフィールドを使用していないことを確認してください。詳細情報: https://github.com/qdrant/qdrant/pull/7183

  • 今後の非推奨:

    • Qdrant v1.18.x では、非推奨の検索メソッドはすべて完全に削除され、古い client ライブラリからも利用できなくなります。
    • Qdrant v1.17.x では、gridstore を優先して RocksDB サポートを完全に削除します。つまり、v1.15.x から v1.17.x への直接アップグレードは不可能になります。サポートされていないストレージ エラーを避けるために、アップグレード手順 に従って、一度に 1 つのマイナー バージョンをアップグレードしてください。 Qdrant Cloud インフラストラクチャは適切なアップグレード手順を自動的に生成するため、それについて心配する必要はありません。
