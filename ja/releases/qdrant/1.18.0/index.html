qdrant v1.18.0

変更ログ

特徴 🏎️

  • マイルストーン!48 - TurboQuant 量子化バリアントを追加、リコール税なしの 8 倍ベクトル圧縮
  • https://github.com/qdrant/qdrant/pull/8605 - 既存のコレクション内の名前付きベクトルを作成および削除するには、API を追加します。
  • https://github.com/qdrant/qdrant/pull/8606 - 詳細なメモリ レポート、ストレージ コンポーネントのメモリ使用量の内訳を表示
  • https://github.com/qdrant/qdrant/pull/8714 - 低メモリ モードを追加し、ディスク上のすべてを強制的に開き、起動時のメモリ不足によるクラッシュを最小限に抑えます。
  • https://github.com/qdrant/qdrant/pull/8715 - メモリ使用量が高い場合に更新を拒否する厳密モード パラメーターを追加 (max_resident_memory_percent)

改善点 📏

  • https://github.com/qdrant/qdrant/pull/8790、https://github.com/qdrant/qdrant/pull/8769 - 検索ワーカーに動的 CPU プールを使用し、IO 待機時間が長い場合の検索パフォーマンスを向上させます。
  • https://github.com/qdrant/qdrant/pull/8526、https://github.com/qdrant/qdrant/pull/8656 - シャード転送で操作サイズに基づくバッチ処理を使用して、より高いスループットを実現します
  • https://github.com/qdrant/qdrant/pull/8673 - 不変地理インデックスのメモリ使用量を 7 分の 1 に削減します。
  • https://github.com/qdrant/qdrant/pull/8529 - RocksDB サポートを完全に削除し、ストレージの処理を簡素化します
  • https://github.com/qdrant/qdrant/pull/8768 - 据え置きポイントを待機しているときに更新キューを停止させません。
  • https://github.com/qdrant/qdrant/pull/8944 - リクエストの更新にデフォルトのタイムアウト 60 秒を使用し、長時間実行される更新リクエストをクリーンアップします。
  • https://github.com/qdrant/qdrant/pull/8767 - コレクションの更新によってオプティマイザーの再作成がトリガーされると、オプティマイザーのエラーがすべてクリアされ、再起動せずに回復できるようになります。
  • https://github.com/qdrant/qdrant/pull/8784 - WAL デルタを解決できない場合は、スナップショット ベースのシャード転送を使用して、より迅速なリカバリを実現します。
  • https://github.com/qdrant/qdrant/pull/8782 - スナップショット転送時、ディスク不足クラッシュを防ぐために、まず受信側のシャード データをクリアします。
  • https://github.com/qdrant/qdrant/pull/8689 - コレクションをロードする前に一時ディレクトリをクリーンアップします。これにより、リカバリ時のディスク不足によるクラッシュを防ぐことができます。
  • https://github.com/qdrant/qdrant/pull/8830 - 他のさまざまな操作がブロックされないように、検索中にシャード ホルダー ロックを保持しないでください。
  • https://github.com/qdrant/qdrant/pull/8626、https://github.com/qdrant/qdrant/pull/8635 - 監査ログ イベントに API メソッド パスを記録します。
  • https://github.com/qdrant/qdrant/pull/8402 - 監査ログ イベントのレポート トレース ID
  • https://github.com/qdrant/qdrant/pull/8636 - テレメトリおよびメトリクスの監査ログ構成とデータ サイズをレポートします。
  • https://github.com/qdrant/qdrant/pull/8640 - ARM CPU (SIMD) でのコサイン正規化の最適化
  • https://github.com/qdrant/qdrant/pull/8571 - テレメトリ エンドポイントの監査ログをスキップします。
  • https://github.com/qdrant/qdrant/pull/8693 - HNSW サブグラフ構築を決定的にする
  • https://github.com/qdrant/qdrant/pull/8712、https://github.com/qdrant/qdrant/pull/8708、https://github.com/qdrant/qdrant/pull/8706 - さまざまな構造を決定的な順序でレポートします。
  • https://github.com/qdrant/qdrant/pull/8932 - 起動メッセージ内のエージェント スキルへのリンク

バグ修正 🪺

  • https://github.com/qdrant/qdrant/pull/8728 - gRPC が無効になっている場合でもストップ ワードが常に小文字になる問題を修正
  • https://github.com/qdrant/qdrant/pull/8719 - YYYY-MM-DDTHH:MM 形式の日時解析を修正
  • https://github.com/qdrant/qdrant/pull/8734 - 新しく再構築された null インデックスの IsEmpty 条件を修正
  • https://github.com/qdrant/qdrant/pull/8939 - フルテキスト インデックスを使用しないネストされた MatchTextAny を修正
  • https://github.com/qdrant/qdrant/pull/8646 - 地理サークル ハッシュ境界チェックを修正
  • https://github.com/qdrant/qdrant/pull/8938 - 文字列配列要素の境界を越えるフレーズ一致を修正
  • https://github.com/qdrant/qdrant/pull/8762 - 複数の検証エラーがある場合のハード パニックを修正
  • https://github.com/qdrant/qdrant/pull/8194 - 空の名前を持つスパース ベクトルを禁止します
  • https://github.com/qdrant/qdrant/pull/8832 - メイン グラフのない HNSW で GPU が使用されない問題を修正
  • https://github.com/qdrant/qdrant/pull/8691 - HNSW サブグラフ構築における無限ループを修正
  • https://github.com/qdrant/qdrant/pull/8577 - スナップショット パスに UTF-8 以外の文字が含まれている場合のパニックを修正
  • https://github.com/qdrant/qdrant/pull/8293 - 破損したコレクション エイリアス ファイルでのハード パニックを修正し、代わりにエラーを返す
  • https://github.com/qdrant/qdrant/pull/8574 - ディスク IO がマップ インデックスで常に測定されない問題を修正
  • https://github.com/qdrant/qdrant/pull/8645 - より効率的に割り当てるためにチャンク容量の予約を修正
  • https://github.com/qdrant/qdrant/pull/8651 - キャンセルをエラーとして吸収するペイロード インデックス フラッシャーを修正
  • https://github.com/qdrant/qdrant/pull/8474 - スナップショットの復元失敗時にクリーンアップされないスナップショット ファイルを修正
  • https://github.com/qdrant/qdrant/pull/8654 - ページ キャッシュのクリアが信頼できない問題を修正し、欠落している候補を追加
  • https://github.com/qdrant/qdrant/pull/8542 - 変更されたファイルを不変としてリストするマップ インデックスを修正
  • https://github.com/qdrant/qdrant/pull/8847 - ディスク ウォッチャーがウェイクアップされずタイムアウトが発生するデータ競合を修正
  • https://github.com/qdrant/qdrant/pull/8789、https://github.com/qdrant/qdrant/pull/8917 - リシャーディング操作を冪等にし、クラッシュ時のクラスター状態の破損を修正します。
  • https://github.com/qdrant/qdrant/pull/8831 - シャード レベルのエラーによる読み取り操作の遅いリクエストのログを修正
  • https://github.com/qdrant/qdrant/pull/8756 - スレッド数を減らすため、使用しない非同期検索ワーカーを割り当てないでください。
  • https://github.com/qdrant/qdrant/pull/8596 - 書き込みハッシュ コミット後のリシャーディング ダウン時に古いシャードに書き込まないようにし、欠落シャード エラーを修正
  • https://github.com/qdrant/qdrant/pull/8543 - スコア後処理でのエッジ スパース ベクトル検索パニックを修正
  • https://github.com/qdrant/qdrant/pull/8588 - 上流でのさまざまな Raft コンセンサスの正確さのバグを修正

セキュリティ 🕵️

  • https://github.com/qdrant/qdrant/pull/8676 - 内部 gRPC エンドポイントで API キー/JWT 認証を強制します
  • https://github.com/qdrant/qdrant/pull/8628 - URL からのスナップショットの復元を無効にする構成オプションを追加
  • https://github.com/qdrant/qdrant/pull/8619 - TLS 依存関係を強化してセキュリティの脆弱性を解決します

ウェブ UI 🍱

  • https://github.com/qdrant/qdrant-web-ui/pull/372 - メモリとディスク インスペクタを追加し、ストレージ コンポーネントごとの使用量の内訳を表示します
  • https://github.com/qdrant/qdrant-web-ui/pull/370 - ハイコントラストテーマを追加
  • https://github.com/qdrant/qdrant-web-ui/pull/369 - コレクション情報パネルにインライン ドキュメントを表示します
  • https://github.com/qdrant/qdrant-web-ui/pull/362 - 一部のコレクション ビューに更新ボタンを追加
  • https://github.com/qdrant/qdrant-web-ui/pull/373、https://github.com/qdrant/qdrant-web-ui/pull/377 - 検索品質の遅延測定を修正し、より適切な名前を使用します
