aider v0.85.0

マイナー 公開日2025年6月27日 出典Aider-AI/aider 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#エイダーv0.85.0

新しいモデル

  • 思考トークンのサポートを備えた gemini-2.5-pro、gemini-2.5-flash、gemini-2.5-pro-preview-06-05 などの新しい Gemini モデルのサポートを追加しました。
  • 更新されたモデル エイリアス: flash は gemini-2.5-flash を指し、gemini は gemini-2.5-pro を指すようになりました。
  • o1-pro、o3-pro などの応答 API モデルのサポート。
  • 複数のプロバイダーにわたる OpenAI o3-pro モデルのサポートを追加しました。
  • 強化された思考トークンのサポート: 0 に設定することで無効にできるようになり、例を含むヘルプ テキストが改善されました。
  • パフォーマンスを向上させるために、Deepseek モデルの最大トークンが 65536 に増加しました。
  • o3 の価格を更新しました。

新機能と機能強化

  • omarcinkonis により、.gitignore にリストされているファイルを Aider の編集スコープに追加できるようにする --add-gitignore-files フラグを追加しました。
  • 共同作成者属性がコミット メッセージに対してデフォルトで有効になるようになりました。
  • Luke Reeves により、システム プロンプト プレフィックスを使用するようにコミット メッセージ生成が強化されました。
  • 高山京介氏により、コミットメッセージの言語を指定するための --commit-language オプションを追加しました。
  • パフォーマンスを向上させるために --skip-sanity-check-repo が有効になっている場合、高価なファイル追跡操作をスキップします (Makar Ivashko 氏)。
  • jayeshthk によるチャット履歴要約パフォーマンスの最適化。
  • Vasil Markoukin による、--analytics-posthog-host および --analytics-posthog-project-api-key フラグを使用したカスタム PostHog 分析構成オプションを追加しました。

リポジトリ マップ

  • Matthew Tofano によるリポジトリ マップの MATLAB 言語サポートを追加しました。
  • Garrett Hopper によるリポジトリ マップに対する Clojure 言語サポートを追加しました。
  • コード分析を改善するために、リポジトリ マップでのケバブケース識別子の認識が改善されました。

修正と小さな改善

  • Vincent Taverna と Sebastian Estrella により、GitHub Copilot トークンの処理が改善され、検証とエラー メッセージが改善されました。
  • Vamsi Talupula により、リッチ マークダウン出力でのインライン コード レンダリングが改善されました。
  • Wietse Venema により、設定内の Vertex AI モデル名のプレフィックスを修正しました。
  • Matteo Landi により、リテラル パスを正しく解決するために /read-only コマンドが改良されました。
  • git diff 出力および LLM 履歴ログにおけるエンコードの問題を修正しました。
  • Mathis Beer により、HTML コンテンツを操作するときにオプションの終了タグを受け入れるように検索ブロック正規表現を修正しました。
  • 起動エラーを防ぐために、投稿者ごとにチャット履歴ファイルの親ディレクトリを自動作成します。
  • パッケージをインストールする前に pip が利用可能であることを確認してください。
  • Aider は、このリリースのコードの 21% を作成しました。
