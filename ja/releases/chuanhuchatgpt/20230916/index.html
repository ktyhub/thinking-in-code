ChuanhuChatGPT 20230916

#チュアンフチャットGPT 20230916 新しい Chuanhu Chat が登場しました。 <br> 新しい Chuanhu Chat のご紹介です。 Sichuan Tiger Chat の立ち上げ以来、これも大きなアップデートとなることをお知らせできることを嬉しく思います。ユーザー インターフェイスとインタラクションを完全に再設計し、これまでにない会話エクスペリエンスを提供します。しかし、心配しないでください。これは、あなたがよく知っている四川タイガー チャットです。 <br> Chuanhu Chat の開始以来、これも大ヒット アップデートであることをお知らせできることを嬉しく思います。ユーザー インターフェイスとインタラクションを完全に再設計し、これまでにない対話体験を実現しました。でも心配しないでください。これはあなたがよく知っている Chuanhu Chat です。 ＃＃ 特徴

🚀 あらゆる場所に変化をもたらすよう慎重に設計されています

  • 新しいページコンセプト、無限の可能性<br>大幅なUI UXアップデート、アダプティブヒストリーとメニューバー+チャットエリア+ツールバー。モバイル端末にも新しいスタイルが登場。
  • 完全に色に染まり、完全に機能に囲まれています<br>最新のチャット インターフェイスにはすりガラス効果が表示され、美しい入力ボックスは Gradio ほど精巧ではありません。
  • 強力な入力エリア、新次元の会話入力<br>入力エリアで直接 Web 検索、ファイルベースの質問や 1 ラウンドの会話、あらゆる種類のチャットをアクティブにして、楽しくチャットできます。
  • 新しいバブル ボタン、新しいバブルを待っています<br>より豊富な機能を備えたメッセージ バブル ボタンは、削除、生成の再試行、または最新のメッセージの「いいね」を実行できるようになりました。
  • ノッチスクリーンまたはホールパンチスクリーン、さまざまな画面に適応可能<br>ウェブページは安全なマージンを保ちながら画面いっぱいに表示されます。ツールバーと設定は引き出しスタイルでスライドさせることもできます。

🚀 新世代の対話の歴史、対話は十分に直接的です

  • 一目瞭然、徹底した管理<br>Chuanhu Chat では初めて、会話履歴の表示にリストが使用され、名前の変更や削除も可能です。リストを開いたら、好きなように開くことができます。
  • シンプルかつエレガント、会話を始めるだけ<br>質問に応じた名前付けから内容に応じた要約まで、Chuanhu Chat は会話に自動的に名前を付けることができるため、コミュニケーションに集中するだけで済みます。
  • 会話の履歴、適切な会話を見つける<br>会話履歴は名前検索をサポートし、正規表現もサポートするようになりました。
  • ワンクリックですべてのデータを取得<br>より完全でエレガントな履歴のダウンロード、エクスポート、アップロード機能が追加され、データはいつでもローカルにダウンロードできます。

🚀 PWA アプリケーションが新しい Web ページを起動します

  • いつでも使える究極のアプリケーション <br>Chuanhu Chat が PWA アプリケーションとしてインストールできるようになりました。デスクトップ ブラウザでは、インストール プロンプトが表示されます。モバイル ブラウザでは、ページをホーム画面に保存することを選択できます。
  • アイコンを変更して個性をアピール<br>アイコンは、トリミングと個別表示の要件を同時に満たせるように慎重に再設計されました。

🚀 超強力なモデルが手元にあり、あなたのスキルを試すのを待っています

  • 適切なモデルを選択し、トップまで練習しましょう <br>さまざまな大型モデルをサポートするだけでなく、Chuanhu Chat で GPT-3.5 をファインチューン (微調整) して、自分に合わせてモデルをカスタマイズすることもできます。
  • iFlytek Spark、新しいダイアログビースト<br>iFlytek Spark の大型モデルのサポートが追加されました。
  • モデルを切り替えて自分のことをよりよく理解する<br>同じ会話内で他のモデルを変更して、元のコンテキストで会話を続けることができるようになりました。

🚀 アップデートだけでなく歯磨き粉も

  • ロシア語インターフェースがサポートされるようになりました!

バグ修正

  • Azure OpenAIの問題を修正
  • ファイルの解析が失敗した場合に後続のファイルに影響を与える可能性がある問題を修正しました
  • バブルの幅がチャットボットのコンテンツを超える問題を修正しました
  • 最新バージョンにアップデートしても、ダウングレード後にアップデートを要求される問題を修正しました -Chuanhuアシスタントが検索できない問題を修正
  • Windows でのいくつかのパスの問題を解決します。

その他

  • 昇級勾配へ3.34.2
  • ログレベルを情報に設定します
  • en_US と en-US のような両方のスタイルをサポート
  • 読み取り専用履歴は、ログインしていない場合にのみ使用されるように変更され、hide_history_when_not_logged_in が設定されています
  • 翻訳を改善し、完成させます
  • 更新されたドキュメントを追加しました 完全な Changelog: https://github.com/GaiZhenbiao/ChuanhuChatGPT/compare/20230830...20230916
