ストラット STRUTS_7_3_0

何が変わったのか

  • https://github.com/apache/struts/pull/1757 の @lukaszlenart による新しい寄稿者用の CONTRIBUTING.md を追加
  • @lukaszlenart による 7.2.1-RC1 を https://github.com/apache/struts/pull/1744 でリリース
  • ドラフト セキュリティ脅威モデル (THREAT_MODEL.md) + @potiuk による発見可能性ポインタを https://github.com/apache/struts/pull/1756 に追加
  • WW-5640 https://github.com/apache/struts/pull/1765 の @lukaszlenart により Struts コアに WebJars サポートを追加
  • WW-5641 https://github.com/apache/struts/pull/1766 の @lukaszlenart による JSON プラグインの struts.json.writer / struts.json.reader オーバーライドを復元する
  • WW-4858 https://github.com/apache/struts/pull/1773 の @lukaszlenart による JSON 作成中のパラメータ フィルタリングを尊重する
  • build(deps-dev): WW-5649 https://github.com/apache/struts/pull/1760 の @dependabot[bot] により commons-logging:commons-logging を 1.3.6 から 1.4.0 にバンプします
  • WW-5643 修正 (json): https://github.com/apache/struts/pull/1775 の @g0w6y による StrutsJSONReader の解析状態を解析スレッドに制限
  • WW-5644 修正 (json): https://github.com/apache/struts/pull/1776 の @g0w6y による StrutsJSONWriter 書き込み状態を書き込みスレッドに制限
  • WW-5645 静的コンテンツ パスを正規化し、https://github.com/apache/struts/pull/1777 の @arunmanni-ai による冗長な URL デコードを削除
  • WW-4858 ネストされたリーフの受け入れ名をカバーし、https://github.com/apache/struts/pull/1783 の @lukaszlenart による JSON フィルタリングにパターンを含める
  • ドキュメント (セキュリティ): 修正または PR を開示として扱い、最初に https://github.com/apache/struts/pull/1785 の @lukaszlenart による非公開レポートを要求します
  • WW-5642 修正 (残り): https://github.com/apache/struts/pull/1774 の @g0w6y によるレコード/作成者バインドの REST 本体プロパティで @StrutsParameter を承認する
  • WW-5646 https://github.com/apache/struts/pull/1780 の @arunmanni-ai によるインクルード コンポーネントのパス正規化を最新化する
  • WW-5650 https://github.com/apache/struts/pull/1782 の @lukaszlenart による JSONInterceptor のリクエストごとに新しい JSON リーダー/ライターを取得します
  • WW-5647 https://github.com/apache/struts/pull/1781 の @arunmanni-ai による XSLT テンプレート キャッシュに ConcurrentHashMap を使用する
  • WW-5652 JSON プラグインに Java レコードとオプションのシリアル化のサポートを追加。 @srilakshmikanthanp 著、https://github.com/apache/struts/pull/1792
  • WW-5620 https://github.com/apache/struts/pull/1794 の @lukaszlenart による Log4j2 でのログ記録の標準化
  • WW-5640 https://github.com/apache/struts/pull/1795 の @lukaszlenart により、DefaultWebJarUrlProvider の名前が StrutsWebJarUrlProvider に変更されました
  • WW-5653 サンプル アプリでブートストラップを 5.3.x にアップグレード (https://github.com/apache/struts/pull/1793 の @lukaszlenart による)
  • WW-5604 https://github.com/apache/struts/pull/1796 の @lukaszlenart による SecurityMemberAccess の CDI/Weld client プロキシを認識する
  • WW-4858 https://github.com/apache/struts/pull/1784 の @lukaszlenart によってのみ、リーフ キーで JSON 名のホワイトリストを評価します
  • WW-5591 https://github.com/apache/struts/pull/1797 で @lukaszlenart によって XWorkObjectPropertyAccessor を非推奨としてマークします
  • WW-5580 https://github.com/apache/struts/pull/1798 の @lukaszlenart による FreeMarker 設定に Configuration.VERSION_2_3_34 を使用する
  • CVE のライブラリ更新、抑制クリーンアップ、および SONARCLOUD_TOKEN が見つからない場合の SonarCloud の github アクション ジョブは失敗しません (代わりに概要レポート)。 @duttonw 著、https://github.com/apache/struts/pull/1667
  • ci(owasp): ジョブのタイムアウトを制限し、チェック ステップで NVD 自動更新を無効にする (https://github.com/apache/struts/pull/1807 の @lukaszlenart による)
  • WW-5539 https://github.com/apache/struts/pull/1799 の @lukaszlenart による同時実行パフォーマンスの強化
  • WW-5413 https://github.com/apache/struts/pull/1805 の @lukaszlenart による小さなメモリ内マルチパート アップロードをディスクに書き込むのを避ける
  • WW-5474 maxFiles のみのファイルをカウントし、https://github.com/apache/struts/pull/1806 の @lukaszlenart によって maxParameterCount を追加します
  • WW-5540 https://github.com/apache/struts/pull/1808 の @lukaszlenart による AbstractLocalizedTextProvider へのキャッシュの追加
  • WW-3427 https://github.com/apache/struts/pull/1814 の @lukaszlenart によるエイリアス化されたプロパティの変換エラーの回帰テストを追加
  • WW-2934 フィールドに変換エラー (オプトイン) がある場合、フィールド バリデータをスキップ (https://github.com/apache/struts/pull/1810 の @lukaszlenart による)
  • WW-3530 https://github.com/apache/struts/pull/1811 の @lukaszlenart によるワイルドカード アクションでの訪問者と検証者のキャッシュ キーの衝突を修正
  • WW-3871 https://github.com/apache/struts/pull/1812 の @lukaszlenart による @TypeConversion キーの ConversionRule プレフィックスの導出
  • WW-3784 https://github.com/apache/struts/pull/1813 の @lukaszlenart による注釈付きワイルドカード アクションを最も特定的なものから順に並べる
  • WW-5659 https://github.com/apache/struts/pull/1816 の @lukaszlenart による呼び出しごとに遅延インターセプター パラメーターを解決する
  • ドキュメント: https://github.com/apache/struts/pull/1820 の @lukaszlenart によるセキュリティ速報スキル、速報テンプレート、トリアージ コントロール ケース ルールを追加
  • WW-5666 https://github.com/apache/struts/pull/1819 の @lukaszlenart によるリクエスト本文を読み取るときに入力長制限を一貫して適用する
  • WW-5668 ローカライズされたテキスト プロバイダー キャッシュをバインドし、https://github.com/apache/struts/pull/1821 の @lukaszlenart によってリクエスト ロケール解決を調整します
  • WW-5668 https://github.com/apache/struts/pull/1824 の @lukaszlenart によるバージョン アップグレード全体にわたって、ローカライズされたテキスト プロバイダーを逆シリアル化できるようにする
  • WW-5656 ConversionRule.COLLECTION と Collection_ プレフィックスを https://github.com/apache/struts/pull/1825 の @lukaszlenart によって @Deprecated としてマークします
  • ドキュメント: @lukaszlenart によるバージョン ノート作成スキルとページ テンプレートを https://github.com/apache/struts/pull/1826 に追加
