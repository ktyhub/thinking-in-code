struts 6_12_0

メジャー 公開日2026年9月17日 出典apache/struts 英語原文

ストラット STRUTS_6_12_0

何が変わったのか

  • Struts 6.12.0 の新しい開発サイクルの準備 (https://github.com/apache/struts/pull/1827 の @lukaszlenart による)
  • WW-5688 https://github.com/apache/struts/pull/1863 で @lukaszlenart によって宣言された場合 (6.x バックポート)、ID を持つ REST URI をルート名前空間に解決します。
  • WW-5700 マップまたはリスト要素を変換できない場合 (6.x バックポート)、https://github.com/apache/struts/pull/1878 の @lukaszlenart によりストアをスキップする
  • WW-5701 https://github.com/apache/struts/pull/1879 の @lukaszlenart による、等しい (6.x バックポート) ではなく、アイデンティティによって変換マーカーを比較します
  • WW-5706 RestfulActionMapper アクション名の処理を DefaultActionMapper (6.x) と調整する (https://github.com/apache/struts/pull/1881 の @lukaszlenart による)
  • WW-5707 コア (6.x) の従来のrestful およびrestful2 アクション マッパーを非推奨にする (https://github.com/apache/struts/pull/1883 の @lukaszlenart による)
  • WW-5711 修正 (変換): https://github.com/apache/struts/pull/1888 で @lukaszlenart によって BigDecimal をフォーマットするときに小数桁がバインドされる
  • WW-5716 https://github.com/apache/struts/pull/1903 の @lukaszlenart によりタイル プラグイン (6.x) でロケールごとの定義キャッシュがバインドされました
  • WW-5723 https://github.com/apache/struts/pull/1913 の @lukaszlenart によって REST プラグイン (6.x) で読み取られたリクエスト本文がバインドされました
  • WW-5724 https://github.com/apache/struts/pull/1915 の @lukaszlenart によってキャッシュされた MessageFormat (6.x) のクローンを配布します
  • WW-5718 修正 (rest,bean-validation): https://github.com/apache/struts/pull/1958 の @lukaszlenart により、リソース分離インターセプターをプラグインのデフォルト スタック (6.x) に追加
  • WW-5749 修正 (残り): ターゲット (6.x) がない場合、XML ハンドラーから何も書き込まない (https://github.com/apache/struts/pull/1960 の @lukaszlenart による)
