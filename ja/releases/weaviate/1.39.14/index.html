v1.39.14 を織り交ぜる

重大な変更

なし

新機能

なし

修正

  • 修正 (バックアップ): https://github.com/weaviate/weaviate/pull/13350 の @tsmith023 により、不足している基本認証を残りのハンドラーに追加します
  • 修正（テレメトリ）: タイムアウトプッシュにより、ハングしたコンシューマーが https://github.com/weaviate/weaviate/pull/13389 の @aliszka によるシャットダウンをブロックできなくなる
  • 修正（反転）: 変更されていないプロパティの長さの書き込みをスキップし、https://github.com/weaviate/weaviate/pull/13400 の @aliszka によってファイルを閉じるときにファイルを fsync します
  • fix(shutdown): https://github.com/weaviate/weaviate/pull/13412 の @aliszka により、シャードをシャットダウンする前にコレクションのサイクルを停止します。
  • test(text2vec-contextionary): https://github.com/weaviate/weaviate/pull/13531 の @antas-marcin による GraphQL 最近傍テスト ケースをスキップします
  • fix(db): バッチ削除では、https://github.com/weaviate/weaviate/pull/12889 の @abdelr によって geo インデックス キューからオブジェクトが削除されませんでした
  • https://github.com/weaviate/weaviate/pull/13508 の @dirkkul によってコンプレッサーが存在する場合、非圧縮 HNSW ベクトル キャッシュをスキップします
  • 修正 (ハイブリッド): https://github.com/weaviate/weaviate/pull/13404 の @jfrancoa による NearText サブ検索に対して再ランクを実行して 1 回生成
  • https://github.com/weaviate/weaviate/pull/13533 の @rlmanrique により、オーバーロードされた頂点から ACORN フロンティア バッファーを保護します
  • ci(gcloud): プリインストールされた gcloud を使用し、https://github.com/weaviate/weaviate/pull/13535 の @antas-marcin によるフォールバックとしてのみ最新のものをダウンロードします *修正（スキーマ）：https://github.com/weaviate/weaviate/pull/13530の@antas-marcinによる移行プロパティを持つモジュールのモジュール設定変更を拒否
  • Compactv2: https://github.com/weaviate/weaviate/pull/13545 で @asdine によって失敗するのではなく、ロード時に v1.34 以前のスナップショットを破棄します
  • fix(hybrid): https://github.com/weaviate/weaviate/pull/13405 の @jfrancoa による両方のハイブリッド レッグでページの最後までフェッチします
  • fix(google-modules): https://github.com/weaviate/weaviate/pull/13532 の @antas-marcin による Google リクエスト URL の projectId とモデルをエスケープして検証します
  • https://github.com/weaviate/weaviate/pull/13474 の @rlmanrique により、準備完了までの時間を追加し、ベクトル インデックスの復元とキャッシュのプレフィル メトリクス (最小限のセット)
  • 修正 (アグリゲーター): https://github.com/weaviate/weaviate/pull/12890 の @abdelr による再起動後にフィルターされたメタ数に削除されたオブジェクトが含まれていた
  • 自動スキーマが https://github.com/weaviate/weaviate/pull/13548 の @dirkkul によってプロパティを追加する前に、クラスのバージョンを待ちます
  • 修正 (クラスター-MT): https://github.com/weaviate/weaviate/pull/13490 の @moogacs によるシリアル RAFT 適用パスからテナントの作業を除外
  • 修正 (クラスター): https://github.com/weaviate/weaviate/pull/13491 で @moogacs によって提供できないレプリカで待機中の読み取りを停止
  • https://github.com/weaviate/weaviate/pull/13522 の @dirkkul により、memtable ツリーの再帰によるヒープ プロファイルの成長を停止
  • fix(modules): https://github.com/weaviate/weaviate/pull/13406 の @jfrancoa による他の追加プロパティの前に再ランクを実行します
  • https://github.com/weaviate/weaviate/pull/13549 の @dirkkul によって、vector_index_tombstones ゲージをトゥームストーン数と同じに保ちます
  • https://github.com/weaviate/weaviate/pull/13556 の @dirkkul によって設定された Python 名前空間のテスト セットアップの任意の 422 でユーザーの作成を再試行します
  • perf(lsmkv): ツリー レベルごとに 1 回キーを比較し、https://github.com/weaviate/weaviate/pull/13555 の @aliszka によるフラット化割り当てを削除します。
  • perf(lsmkv): https://github.com/weaviate/weaviate/pull/13552 の @aliszka によって継続時間が決して記録されないタイミング セグメント読み取りを停止します。
  • perf(lsmkv): エラーの直前に NotFound と Deleted を比較します。https://github.com/weaviate/weaviate/pull/13551 の @aliszka によるもの
  • perf(lsmkv): https://github.com/weaviate/weaviate/pull/13541 の @aliszka によるすべてのセグメントのブルーム フィルターに対して、各ローリング セット キーを 1 回ハッシュします。
  • perf(contains): https://github.com/weaviate/weaviate/pull/13540 の @aliszka によってシャードが保持していないキーに対して nil 行を返します。
  • perf(inverted): バッチ化されたビルドには、https://github.com/weaviate/weaviate/pull/13554 の @aliszka によるフィルター値ごとにキーが 1 回含まれます
  • 修正（モジュールコンポーネント）: トークナイザー語彙を埋め込み、https://github.com/weaviate/weaviate/pull/13558 の @antas-marcin による nil-トークナイザー パニックを停止します
  • perf(lsmkv): https://github.com/weaviate/weaviate/pull/13539 の @aliszka によって戦略が一致する場合に戦略チェックをインライン化します。
  • feat(text2vec-google): https://github.com/weaviate/weaviate/pull/13550 の @antas-marcin によるサービス、場所、モデルごとのリクエスト期間の記録
  • fix(slow-log): https://github.com/weaviate/weaviate/pull/13553 の @aliszka による大きな値リストを持つフィルターのスロークエリ レコードのバインド
  • fix(hfresh): 投稿マップ移行バッチを遅延的に割り当て、https://github.com/weaviate/weaviate/pull/13569 の @asdine によってバインドされました
  • v1.26.10 および 1.39 の更新は、https://github.com/weaviate/weaviate/pull/13575 の @dirkkul によって行われます。
  • eMudhra 中間証明書セキュリティ パッチ (https://github.com/weaviate/weaviate/pull/13580 の @antas-marcin による)
  • @dirkkul による v1.38.22 を https://github.com/weaviate/weaviate/pull/13577 でリリース
  • eMudhra 中間証明書セキュリティ パッチ (https://github.com/weaviate/weaviate/pull/13581 の @antas-marcin による)
  • chore(deps): Go 1.26 に切り替え、x/net、x/crypto、x/text、grpc をバンプして、https://github.com/weaviate/weaviate/pull/13587 の @antas-marcin による CVE を修正します
  • fix(add-class): https://github.com/weaviate/weaviate/pull/13590 の @tsmith023 による Raft 適用パスでコレクションの上限を強制します
  • https://github.com/weaviate/weaviate/pull/13595 の @antas-marcin により安定版/v1.36 を安定版/v1.37 にマージします
  • 雑務: https://github.com/weaviate/weaviate/pull/13599 の @asdine によるクロード コードのコミットと PR 帰属を無効にする
  • 修正: レガシー ベクターのない保存されたオブジェクトを、https://github.com/weaviate/weaviate/pull/13596 の @trengrj によって見つからないものとして扱う
  • fix(modules): https://github.com/weaviate/weaviate/pull/13407 で @jfrancoa によってプロパティが 2 つ提供される場合、すべてのリクエストで同じモジュールを選択します
  • https://github.com/weaviate/weaviate/pull/13613 の @dirkkul による名前空間受け入れテストでは、新しい DB ユーザー キーに 1 分ほどかかります
  • hnsw/compact: https://github.com/weaviate/weaviate/pull/13341 の @rlmanrique によって生のコミット ログ リーダーにガベージ ノード ID の割り当てを固定します。
  • fix(db): https://github.com/weaviate/weaviate/pull/13376 の @antas-marcin による各シャードのロード中にプロパティの長さを再計算します
  • refactor(db): ディメンション間の再インデックスとプロパティの長さの間で起動再構築ファンアウトを共有し、https://github.com/weaviate/weaviate/pull/13611 の @antas-marcin によって再カウントされます。
  • perf(db): https://github.com/weaviate/weaviate/pull/13612 の @antas-marcin によるロード前に、すべての起動リビルドに対して各シャードを開いて一度ウォークします
  • 雑務: https://github.com/weaviate/weaviate/pull/13621 の @antas-marcin による tools/gen-code-from-swagger.sh スクリプトで macOS swagger lib ダウンロードを調整します
  • 動作モードが ReadOnly の場合のホワイトリスト grpc ヘルス チェック読み取り (https://github.com/weaviate/weaviate/pull/13620 の @tsmith023 による)
