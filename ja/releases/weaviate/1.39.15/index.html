v1.39.15 を回避する

重大な変更

なし

新機能

なし

修正

  • test(authz): https://github.com/weaviate/weaviate/pull/13629 の @antas-marcin によるバッチ参照を測定する前に、保留中の認証ログを待ちます
  • セキュリティ: https://github.com/weaviate/weaviate/pull/13632 の @antas-marcin によって github.com/go-jose/go-jose/v4 を v4.1.6 にバンプします
  • このノードが https://github.com/weaviate/weaviate/pull/13557 の @dirkkul によってコレクションを作成している間、読み取りを待機させます。
  • 修正 (シャットダウン): https://github.com/weaviate/weaviate/pull/13627 の @tsmith023 によるメンバーリストの脱退前に grpc のシャットダウンを並べ替えます。
  • https://github.com/weaviate/weaviate/pull/13634 の @dirkkul による空の配列の欠落している適切な長さを修正
  • fix(add-class): https://github.com/weaviate/weaviate/pull/13592 の @tsmith023 によってローカル スキーマからコレクション キャップのフェイルファスト カウントを読み取ります
  • deps: https://github.com/weaviate/weaviate/pull/13647 の @antas-marcin により、parquet-go/parquet-go を v0.32.0 に、andybalholm/brotli を v1.2.7 にバンプします
  • deps: https://github.com/weaviate/weaviate/pull/13652 の @antas-marcin による v0.0.2 への weaviate/mockoidc のバンプ
  • オブジェクトがストア (バックポート v1.37) から欠落している場合に、ベクター検索距離を揃えるように (https://github.com/weaviate/weaviate/pull/13650 の @rlmanrique により)
  • 残りの検索: https://github.com/weaviate/weaviate/pull/13631 の @g-despot によってハイブリッド エンドポイントで呼び出し元が提供したベクトルを受け入れます。
  • オブジェクトがストア (バックポート v1.38) から欠落している場合に、ベクター検索距離を調整します (https://github.com/weaviate/weaviate/pull/13645 の @rlmanrique により)
  • 修正: https://github.com/weaviate/weaviate/pull/13649 の @trengrj による gse トークナイザー
  • https://github.com/weaviate/weaviate/pull/13049 の @etiennedi により、ランタイムの再インデックスとレプリカの移動を相互排他的にする
  • reindex: https://github.com/weaviate/weaviate/pull/13675 の @etiennedi による書き込みを分析する前に二重書き込み状態をロードします
  • lsmkv: https://github.com/weaviate/weaviate/pull/13676 の @etiennedi によってバケットを移動する前に、バケットのフラッシュされていない書き込みをフラッシュします
  • reindex: https://github.com/weaviate/weaviate/pull/13674 の @etiennedi による検索可能なインデックスが存在する場合、フィルターのみのトークン化の変更を拒否します。
  • distributiontask: ハンドは、https://github.com/weaviate/weaviate/pull/13677 の @etiennedi によって生成された失敗した ACK である FAILED ステータスをコールバックします。
  • 再インデックス: ?tenants= の凍結されたテナントを凍結として報告します。https://github.com/weaviate/weaviate/pull/13680 の @etiennedi によって欠落していません。
  • バックアップ: https://github.com/weaviate/weaviate/pull/13681 での @etiennedi による再インデックスの拒否を回避する方法をオペレーターに伝えます
  • 再インデックス: https://github.com/weaviate/weaviate/pull/13684 の @etiennedi によるすべてのユニット ID の代わりにグループのユニット数をログに記録します
  • dtm: https://github.com/weaviate/weaviate/pull/13689 の @etiennedi によって、ノードが多くの障害が発生したユニットまたはグループに対して書き込む ACK エラーを制限します
  • fix(reindex): https://github.com/weaviate/weaviate/pull/13685 の @etiennedi により、古い状態のスイープをタスクのテナントに制限します
  • https://github.com/weaviate/weaviate/pull/13683 の @etiennedi によってバックアップ再インデックス ゲートでタスク リスト呼び出しがバインドされました
  • バックアップ: https://github.com/weaviate/weaviate/pull/13678 の @etiennedi により、シャードごとに 1 つではなく、バックアップ全体で 1 つの再インデックス ゲート フェッチを共有します。
  • クラスター: https://github.com/weaviate/weaviate/pull/13699 の @etiennedi によって古いレプリカに対して構築された再インデックスの送信を拒否します
  • バックアップ: https://github.com/weaviate/weaviate/pull/13682 の @etiennedi により、シャードごとにではなく、クラスごとに再インデックスの拒否を報告します
  • インデックスの再作成: 移行ディレクトリ ハンドルをガードし、https://github.com/weaviate/weaviate/pull/13692 の @etiennedi によるより明確な保留範囲インデックス エラー
  • 再インデックス: ターゲット テナントが HOT でない間は送信を拒否 (https://github.com/weaviate/weaviate/pull/13701 の @etiennedi により)
  • インデックスの再作成: https://github.com/weaviate/weaviate/pull/13702 で @etiennedi によって新たに実行されるまで、失敗した移行のタスク レコードを保持します。
  • テスト: https://github.com/weaviate/weaviate/pull/13708 の @etiennedi による 2 つの不安定なテスト (バックアップ偽装、オーバーレイ スワップ レース チェック) を修正
  • 呼び出し元に期限がない場合に分散タスク リスト クエリをバインド (https://github.com/weaviate/weaviate/pull/13706 の @etiennedi によって)
  • 修正（レスト）: https://github.com/weaviate/weaviate/pull/13646 の @aliszka によるティアダウンの前に、グレースフル タイムアウトでもビジー状態の HTTP サーバーを閉じる
  • インデックスの再作成: エンジンをレコードに切り替え、マーカーを削除します (パート 2/2) (https://github.com/weaviate/weaviate/pull/12848 の @etiennedi による)
  • fix(queue): https://github.com/weaviate/weaviate/pull/12879 の @abdelr によって処理されたチャンクを削除する前にインデックスをフラッシュします
  • https://github.com/weaviate/weaviate/pull/13726 で @dirkkul によってバックアップ ファイルをハードリンクするときに、ディレクトリごとに MkdirAll を 1 回呼び出します
  • perf(queryadmission): https://github.com/weaviate/weaviate/pull/13617 の @aliszka によって実際にフェーズで使用される予算まで各クエリを保持します。
  • fix(router): https://github.com/weaviate/weaviate/pull/13456 の @tsmith023 によってレプリカがメンバーリストから削除された場合に整合性レベルを強制します
  • https://github.com/weaviate/weaviate/pull/13383 に @etiennedi による client 側ライセンス プロトコル パッケージ (M4) を追加
  • https://github.com/weaviate/weaviate/pull/13749 の @dirkkul により、テナントのみの許可が単独のコレクションのスキーマをリストすることを停止します。
  • X|\Q のようなロール パターンが、https://github.com/weaviate/weaviate/pull/13651 の @dirkkul によるその後の権限チェックのたびに失敗しないようにします
  • https://github.com/weaviate/weaviate/pull/13679 の @dirkkul により、バックアップ メタデータが欠落している場合にバックアップと復元のステータスを承認します。
  • 雑務(テスト): https://github.com/weaviate/weaviate/pull/13765 の @tsmith023 による TestReplicationReplicateMOVEDeletesSourceReplica の不安定性の修正を試みます
