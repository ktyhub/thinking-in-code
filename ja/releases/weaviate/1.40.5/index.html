v1.40.5 を回避する

重大な変更

なし

新機能

なし

修正

  • https://github.com/weaviate/weaviate/pull/13775 で @dirkkul によって役割を割り当てる前に、管理権限のすべての動詞が必要です
  • perf(lsmkv): https://github.com/weaviate/weaviate/pull/13658 の @aliszka によってキャッシュ ライン全体にセグメント読み取りバイト メトリックをストライプ化します。
  • test(reindex): https://github.com/weaviate/weaviate/pull/13743 の @etiennedi によってマージされたバリアの再起動テストを決定的にする
  • chore(tools): https://github.com/weaviate/weaviate/pull/13791 の @antas-marcin による gen-code-from-swagger.sh の golangci-lint バージョンを強制します
  • https://github.com/weaviate/weaviate/pull/13781 の @dirkkul による読み取り修復競合メッセージから nil エラーを削除
  • https://github.com/weaviate/weaviate/pull/13790 の @dirkkul によるロールを表示または編集するには、管理権限のすべての動詞が必要です
  • test(reindex): https://github.com/weaviate/weaviate/pull/13742 の @etiennedi によってノードごとの状態をアサートする前に、各ノードの /index を待機します。
  • perf(slow-log): 停止フィルターは、https://github.com/weaviate/weaviate/pull/13769 の @aliszka によってログに記録されないエントリに対して支払いを残します。
  • バックアップ: https://github.com/weaviate/weaviate/pull/13794 の @jeroiraz によって重複排除指定の関係をランダムに破ります
  • バックアップ: 重複排除コンバージェンスのデフォルトを 15 秒に下げ、https://github.com/weaviate/weaviate/pull/13796 の @jeroiraz によって構成可能にします
  • https://github.com/weaviate/weaviate/pull/13788 の @dirkkul によってデータ ディレクトリをエスケープするバックアップ クラスとシャード名を拒否します
  • セキュリティ (deps): https://github.com/weaviate/weaviate/pull/13806 の @antas-marcin によって golang.org/x/net を v0.62.0 にバンプします
  • インデックスの再作成: https://github.com/weaviate/weaviate/pull/13719 で @etiennedi によって間違った種族を説明した 2 つのスキーマ ガード godoc を修正
  • インデックスの再作成: https://github.com/weaviate/weaviate/pull/13720 の @etiennedi により、コードが守らない契約を述べた 2 つの godoc を修正
  • 再インデックス: シャードが https://github.com/weaviate/weaviate/pull/13718 の @etiennedi によってロードされているかどうかに関係なく、読み取り不可能なレコード セットについて合意します。
  • test(reindex): https://github.com/weaviate/weaviate/pull/13724 の @etiennedi による再インデックス完了後のバックアップ、リストア、レプリカの移動
  • https://github.com/weaviate/weaviate/pull/13709 で @etiennedi によって読み取られたコレクションとテナントによって GET /v1/tasks をフィルターします
  • 修正: https://github.com/weaviate/weaviate/pull/13822 の @trengrj による不安定なテスト削除エントリポイント
  • https://github.com/weaviate/weaviate/pull/13768 の @dirkkul による名前空間の動的ユーザー強化
  • https://github.com/weaviate/weaviate/pull/13750 の @dirkkul によりスキーマ、エイリアス、DB ユーザー リストから他の名前空間を削除
  • クラスター: https://github.com/weaviate/weaviate/pull/13819 の @etiennedi による RAFT リプレイの前にスキーマ ガードを登録します
  • https://github.com/weaviate/weaviate/pull/13823 の @dirkkul による正規表現構文を使用するロール パターンを付与するにはワイルドカードが必要です
  • 修正: https://github.com/weaviate/weaviate/pull/13795 の @augustas1 による Weaviate Embeddings モジュールのベース URL の使用を絞り込む
