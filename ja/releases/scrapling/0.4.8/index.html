Scrapling v0.4.8

パッチ 公開日2026年5月11日 出典D4Vinci/Scrapling 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

v0.4.8 をスクラップする

クロール フレームワークを次のレベルに引き上げる大きなスパイダー アップデート 🕷️

[!NOTE] 毎日のヒントやコツについては X でフォローしてください

🚀 新しいものと生活の質の変化

  • Response から URL を取得するために、scrapling.spiders.LinkExtractor に LinkExtractor プリミティブを追加しました。多くのコントロールがあります (ドキュメント を確認してください)

    from scrapling.spiders import LinkExtractor

extractor = LinkExtractor(allow=r"/posts/", deny_domains=["ads.example.com"])

  • CrawlSpider および CrawlRule の汎用スパイダー テンプレートを追加したため、同じ「このパターンに一致するリンクをたどる」定型文を手書きする必要がなくなりました。 rules() をオーバーライドして、それぞれが LinkExtractor とペアになっている CrawlRule オブジェクトのリストを返します。 (ドキュメント を確認してください)

    from scrapling.spiders import CrawlSpider, CrawlRule, LinkExtractor

class QuotesSpider(CrawlSpider):
    name = "blog"
    start_urls = ["https://quotes.toscrape.com/"]

    def rules(self):
        return [
            CrawlRule(LinkExtractor(allow=r"/author/"), callback=self.parse_author),
            CrawlRule(LinkExtractor(allow=r"/page/\d+/")),  # pagination, no callback
        ]

    async def parse_author(self, response):
        yield {
            "name": response.css(".author-title::text").get(),
            "birthday": response.css(".author-born-date::text").get(),
            "url": response.url,
        }

  • サイトマップまたは robots.txt URL から直接クロールをシードする SitemapSpider テンプレートを追加しました。 gzip 圧縮されたサイトマップ、および多くのコントロールとオプションを処理します。上記の CrawlSpider のように、URL はクロール ルールを介してディスパッチされます。 (ドキュメント を確認してください)

    from scrapling.spiders import SitemapSpider, CrawlRule, LinkExtractor

class NewsSitemap(SitemapSpider):
    name = "news"
    sitemap_urls = ["https://example.com/robots.txt"]

    def rules(self):
        return [
            CrawlRule(LinkExtractor(allow=r"/articles/"), callback=self.parse_article),
        ]

    async def parse_article(self, response):
        yield {"url": response.url, "title": response.css("h1::text").get()}

  • 適応型再配置のデフォルト値は、すべての方法で 0 ではなく 40% の類似性しきい値になりました。これにより、適応機能がより適切に機能するようになります。しきい値を超えるものがない場合、警告によって実際に確認された最高スコアが通知されるため、必要に応じて percentage を意図的に下げることができます。

  • すべてのブラウザとフィンガープリントを更新。更新後に新しい scrapling install --force を実行して、ブラウザーとフィンガープリントを更新します。

🐛 バグ修正

  • Fetcher.configure(...) がリクエストごとの呼び出しに適用されない問題を修正。同じ修正が AsyncFetcher にも適用されました。
  • #255 の @yetval による、スパイダー内で重複リクエストを引き起こす誤ったリクエスト フィンガープリンティングを修正しました。
  • 弱い一致でサイレント状態になるアダプティブ scraping エンジンを修正しました。 上記のしきい値の変更と組み合わせることで、再配置が失敗したときに誤解を招く「最良の推測」要素の代わりに警告が表示されるようになりました。

ドキュメント

  • 現在のバージョンと一致するようにドキュメント全体で古いコード例を更新しました。
  • ドキュメント サイトのコードのコピー＆ペーストのエクスペリエンスを改善し、エージェント スキルをトリミングして、呼び出しごとに使用するトークンの量を減らしました。
