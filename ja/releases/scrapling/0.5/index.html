Scrapling v0.5

マイナー 公開日2026年10月17日 出典D4Vinci/Scrapling 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

v0.5 をスクラップする

v0.5 をスクラップすると、フェッチ、解析、スパイダー、ブラウザ自動化、AI ツール、10 か国語のドキュメントなど、ほぼすべてがアップグレードされます 🚀

[!NOTE] 毎日のヒントやコツについては X でフォローしてください

[!警告] このリリースでは、ここには当てはまらない多くの重大な変更が導入されています。アップデートする前に、v0.5 への移行ガイド をご確認ください。

🚀 新しいものと生活の質の変化

  • ほぼすべての CAPTCHA を解決できる、AI エージェント用のはるかに高性能な MCP サーバー (ドキュメント を確認してください):

    • 完全なブラウザ ワークフロー: フォームへの入力、click、ホバー、スクロール、キーボードの使用、ダイアログの処理、および 1 つの順序付けされたシーケンスでの結果の待機。さまざまなフィールド タイプと低速の対話をサポートし、最初のエラーでアクションが停止します。
    • 再ロードせずに現在のページを読み取り、検索します: ページ全体または 1 つの要素から HTML、マークダウン、またはテキストを抽出します。検索可能なページのスナップショットには、要素の役割、名前、位置が表示され、周囲のコンテキストを保持するフォーカスされたビューが表示されます。
    • カスタム JavaScript を実行し、焦点を絞ったスクリーンショットを取得します: ページ独自の JavaScript にアクセスして、非同期作業を含むスクリプトを実行します。個々の要素、ビューポート、またはページ全体を PNG または JPEG としてキャプチャします。
    • ネットワーク アクティビティを検査し、ログインを再利用: 記録されたリクエストと応答を調べ、ブラウザーのログイン状態を保存および復元し、開いているまたは閉じている Shadow DOM 内の要素と対話します。セッションを閉じる前に、記録されたトラフィックを読み取ります。
    • 使用するトークンを減らし、より明確なエラーを取得: 無駄のないツールの説明と共有ガイダンスにより、テキストの繰り返しが減り、ブラウザーやリクエストの失敗に対しては役立つエラー メッセージがエージェントに届きます。

  • ページの後ろにあるリクエストをご覧ください。 record_requests=True を有効にして、ロード、アクション、タブ全体で完了したトラフィックを記録し、リクエストを再度送信せずに保存されたレスポンスを検査します。 (ドキュメント を確認してください)

    from scrapling.fetchers import StealthySession

with StealthySession(record_requests=True) as session:
    session.fetch("https://example.com", network_idle=True)
    for response in session.network.search(url_pattern=r"/api/", limit=None):
        print(response.url, response.status, response.body)
    • URL、メソッド、リソースタイプ、ステータスによるフィルタリング。 ID によって 1 つの応答を取得します。ヘッダー、送信データ、API 応答、HTTP エラー、および通常の Response API を介したリダイレクトを検査します。
    • サイズ制限付きでサポートされているテキスト本文に加えて、本文を保存できない場合のメタデータと理由も保持します。デフォルトの制限は 1,000 リクエストです。同期および非同期セッションで動作します。保存された Python 履歴は、閉じた後も読み取り可能です。

  • ログインを一度保存​​すると、複数の実行で再利用できます。 save_state(path) および load_state(path) は、Cookie、ローカル ストレージ、および IndexedDB を Playwright 互換の JSON に保存します。同期ブラウザ セッションと非同期ブラウザ セッションの両方がこれらをサポートしています。 (ドキュメント を確認してください)

    • ページをフェッチまたはリロードする前に状態をロードします。 proxy_rotator なしで開始された共有ブラウザー コンテキストが必要です。タブ、ブラウザ設定、sessionStorage は保存されません。

  • pierce_shadow=True で開いている Shadow DOM を抽出し、通常どおり CSS または XPath を使用します。ブラウザーのフェッチャー、セッション、および CLI の --pierce-shadow オプションで使用できます。ライブ ページを変更せずにスロットのコンテンツを保持します。 HTML キャプチャでは、閉じたルートと iframe ドキュメントは除外されます。 (ドキュメント を確認してください)

  • スパイダーがサイトを探索する方法を選択します。 CrawlSpider とそのサブクラス (ContentSpider を含む) は、古い順のスケジューリングの crawl_strategy="bfs" または新しい順のスケジューリングの "dfs" をサポートします。優先順位が依然として優先され、同時ページは異なる順序で終了する可能性があります。 (ドキュメント を確認してください)

🐛 バグ修正

  • **遅延ウィジェット検出、不要な待機の減少、制限されたパッシブ チャレンジと隠しフレームの再試行ループにより、Cloudflare の解決が改善されました。 #468 と #509 を修正しました。

  • 管理者特権の Windows シェルからのブラウザの起動を修正。 #463 を修正しました。

  • #430 の @alkaz-nodemaven によるカスタム ブラウザ フラグを追加するときに、組み込みのステルス フラグを維持しました。

  • ブラウザ応答の文字セット解析が改善されました。大文字と小文字、スペース、または引用符で囲まれた値が異なる宣言も含まれます。

  • 解決する必要のあるチャレンジがない場合に、Cloudflare チャレンジが存在しないことをエラーとして記録するのを停止しました。 #459 を修正しました。

  • #448 の @yetval によるクエリ パラメーターのリクエスト フィンガープリント、#480 の @ac1982 による空または偽の JSON 本体、#466 の @SarwadnyaMahajan によるヘッダー挿入順序を修正しました。

  • #462 の @yetval による、古い本文関連ヘッダーを含む、フォローされているリンクへのリクエスト データの漏洩を修正しました。

  • #446 の @Kuang-xianxin によって、ブロックされた応答が成功した開発キャッシュ エントリとして保存されるのを防ぎました。

  • クロールが例外で失敗した場合に保存されるチェックポイント ファイル、#486 の @SulimanAbdulrazzaq による。

  • #443 の @prateekraawat1 により、失敗した検索がクロールの許可としてキャッシュされないように、robots.txt の失敗処理を修正しました。

  • **#452 および #483 の @SulimanAbdulrazzaq による、空の一致やリンク要素自体をターゲットとするセレクターを含む、制限されたセレクターによるリンク抽出を修正しました。

  • #458 の @SulimanAbdulrazzaq によるサイトマップ コールバック ルーティング、および #450 の @sup3dev による コメントまたは処理命令による XML 解析を修正しました。

  • #453 の @SulimanAbdulrazzaq により、robots.txt および CSV フィード内の先頭のバイトオーダー マークを処理しました。

  • スパイダー HTTP セッションでの stealthy_headers 処理を修正、#475 の @Yigtwxx により、オプションを curl_cffi に直接ではなくセッションに渡します。

  • #485 の @SulimanAbdulrazzaq による貢献により、リクエスト本文の優先順位と既存の None 処理を維持しながら、リストおよびタプル値の辞書形式エンコードを修正しました。

  • #487 の @SulimanAbdulrazzaq によるセッションおよびリクエストごとの HTTP ヘッダーの大文字と小文字を区別しないマージを修正しました。

  • #484 の @SulimanAbdulrazzaq による、空または偽の JSON ボディをサイレントにドロップする CLI リクエストを修正しました。

  • マークダウンとテキスト ファイルのエクスポートで一貫して UTF-8 を使用するようにし、#488 の @SulimanAbdulrazzaq により、変換エラーで既存の出力ファイルが切り捨てられるのを防ぎました。

  • #490 の @SulimanAbdulrazzaq による、curl のユーザー エージェントおよびプロキシ オプションの curl2fetcher() 処理を修正しました。

  • #432 の @Yigtwxx による貢献により、選択された複数の要素が Response.markdown() または CLI 抽出を通じて変換されるときに一緒に実行される Markdown ブロックを修正しました。

  • AI 出力の非表示コンテンツのクリーニングを修正。#460 の @Yigtwxx による貢献により、opacity:0.95 などの表示コンテンツを保持し、より多くの非表示スタイルを認識し、非表示スロットを削除します。

  • **#474 の @Yigtwxx による、ネストされたタグの周囲で早期に停止するノイズタグの削除を修正しました。

  • #495 の @ yellow-dog-dog により、いくつかの同じタグの兄弟の最初のものに対して生成された CSS および XPath セレクターを修正しました。

  • #493 の @afsuyadi による lxml HTML パーサーの非推奨警告を解決しました。

ドキュメント

  • 完全な Web サイトでは現在 10 か国語をサポートしています: 英語、アラビア語、スペイン語、ブラジル系ポルトガル語、フランス語、ドイツ語、簡体字中国語、日本語、ロシア語、韓国語。ガイド、API リファレンス、チュートリアル、および changelog は、アラビア語 RTL サポートと、ページとセクションを維持する言語スイッチを使用して翻訳されます。
  • わかりやすいガイド、README の例、セットアップ手順。チェックポイント データ、ブラウザーのエンコーディング、保存された状態、ネットワーク履歴、Shadow DOM、およびクロール順序をカバーします。
  • エージェント スキル、その例、リファレンス、および現在のブラウザおよび MCP ツール用のダウンロード可能なアーカイブを更新しました。
  • changelog を Web サイトに移動し、各ページの Markdown ソースへのアクセスを追加しました。

プロジェクト

  • Scrapling のロゴ、カバー画像、Web サイトのプレゼンテーションを更新しました。
  • ブラウザーのアクション、ダイアログ、抽出、スクリーンショット、JavaScript、ネットワーク記録、状態ファイル、Shadow DOM、およびクローラーの修正のテストを拡張しました。
  • ブラウザー テスト マーカーと、個別のブラウザー、非同期、および並列テストの実行を追加しました。 #457 の @diegobravtraps-oss により、Windows チェックポイントと CSV テストの移植性が向上しました。
  • 共有多言語ドキュメントのビルド設定と貢献ガイダンスを更新しました。
