Scrapling v0.4.6

v0.4.6 をスクラップする

ブラウザのステルス性、プライバシー、開発者エクスペリエンスに重点を置いたアップデート 🔒

[!NOTE] 毎日のヒントやコツについては X でフォローしてください

🚀 新しいものと生活の質の変化

  • ブラウザフェッチャー用の組み込み広告ブロックを追加しました。 block_ads=True を渡すと、約 3,500 の既知の広告およびトラッカー ドメインへのリクエストをルート インターセプト レベルでブロックします (DNS なし、TCP なし、即時中止)。 blocked_domains と組み合わせてカスタム リストを作成できます。 MCP サーバーと CLI --ai-targeted モードでは、これが自動的に有効になり、トークンが節約され、ページの読み込みが高速化されます。 
    page = StealthyFetcher.fetch('https://example.com', block_ads=True)
  • プロキシ使用時の DNS リークを防ぐために、DNS-over-HTTPS サポートを追加しました。 dns_over_https=True を渡して、DNS クエリを Cloudflare の DoH 経由でルーティングします。これにより、HTTP トラフィックがプロキシを通過する場合でも、実際の場所が DNS 解決を通じて公開されなくなります。 
    page = StealthyFetcher.fetch('https://example.com', proxy='http://proxy:8080', dns_over_https=True)
  • ブラウザフェッチャー用の page_setup コールバックを追加しました。 page.goto() の前に実行される関数。これにより、ページが移動する前に設定する必要があるイベント リスナー、ルート、またはスクリプトを登録できます。 page_action (ナビゲーション後に実行) とペアになります。 (#237を解決します) 
    def capture_websockets(page):    page.on("websocket", lambda ws: print(f"WS: {ws.url}"))page = DynamicFetcher.fetch('https://example.com', page_setup=capture_websockets)
  • --block-ads および --dns-over-https CLI オプションを fetch と stealthy-fetch の両方のコマンドに追加しました。

🐛 バグ修正

  • 浮動小数点値を拒否する Seconds タイプ エイリアスを修正。ブラウザー フェッチャーに wait=1.5 または timeout=500.0 を渡すと、型エラーが発生して失敗します。これは、型エイリアスが float を型ではなくメタデータとして誤って処理したためです。 by @kuishou68 #240
  • フルパス セレクター生成における重複 ID セグメントを修正。 id 属性を持つ要素には、完全な CSS/XPath パスを生成するときにセレクターが 2 回追加され、body > #main > #main > #target > #target のようなセレクターが生成されました。また、*[@id='x'] の代わりにベア [@id='x'] 述語 (無効な XPath) を生成するフルパス XPath も修正されました。 @sjhddh 著 #241
  • 欠落していたシェル署名パラメータを修正。対話型シェルには、関数シグネチャから blocked_domains、block_ads、retries、retry_delay、capture_xhr、executable_path、および dns_over_https がありませんでした。
