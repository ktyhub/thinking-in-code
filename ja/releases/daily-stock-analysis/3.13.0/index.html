何が変わったのか

🤖 AI と分析

  • 功績: 米国株データ損失の修復、新しい成長ブリッジ データ ソース (https://github.com/ZhuLinsen/daily_stock_analysis/pull/981 の @BIGBbox による)
  • 功績: 既存のインターフェース契約を可能な限り破ることなく、共通の株価分析リンクが LiteLLM ストリーミング出力をサポートできるようにします... (#865) by @ZhuLinsen in https://github.com/ZhuLinsen/daily_stock_analysis/pull/924
  • https://github.com/ZhuLinsen/daily_stock_analysis/pull/982 で @xinzhifan4 による集成 Anspire 検索
  • 特技(ワークフロー): https://github.com/ZhuLinsen/daily_stock_analysis/pull/1014 の @zerubeus により、分析ジョブのタイムアウトを vars 経由で設定可能にしました
  • 修正: REPORT_LANGUAGE=en のときにディスク レビュー リンクが英語のマークダウンを出力するようにします... (#1029) by @ZhuLinsen in https://github.com/ZhuLinsen/daily_stock_analysis/pull/1030
  • 修正: REPORT_LANGUAGE をワークフローに挿入し、https://github.com/ZhuLinsen/daily_stock_analysis/pull/1028 の @ZhuLinsen により、current_price をステータス API (#1013、#983) に追加しました。
  • 修正: 版本号不对 by @ZhuLinsen (https://github.com/ZhuLinsen/daily_stock_analysis/pull/1048)
  • 修正: https://github.com/ZhuLinsen/daily_stock_analysis/pull/1051 の @ZhuLinsen による efinance インデックスのオープン列フォールバックの処理

🐛 バグ修正

  • 修正: マルチエージェント AGENT_MAX_STEPS が、https://github.com/ZhuLinsen/daily_stock_analysis/pull/1031 の @ZhuLinsen によるユーザー オーバーライドとスキル エージェントのグレースフル デグラデーションを考慮しない

📡 データソース

  • 修正: 株式名港股获取不了了 (#940) by @ZhuLinsen (https://github.com/ZhuLinsen/daily_stock_analysis/pull/964)
  • 修正: 欠損値判定ロジックは予期しない例外をサイレントに飲み込んではなりません (#996) by @ZhuLinsen in https://github.com/ZhuLinsen/daily_stock_analysis/pull/997
  • Feat/tushare は、https://github.com/ZhuLinsen/daily_stock_analysis/pull/994 の @jiangmin168168 による香港株クエリのサポートを追加しました
  • 功績: バックエンドに既存のstocks.index.jsonの再利用を優先させて株名のマッピングを解決し、欠落した場合に既存のフォールバックリンクを保持します... (#1027) by @ZhuLinsen in https://github.com/ZhuLinsen/daily_stock_analysis/pull/1033
  • 修正: チップ配布の非取引日に最新の取引日を返す…by @SophiaJiaLi in https://github.com/ZhuLinsen/daily_stock_analysis/pull/1067

🔔 通知

  • リファクタリング: Feishu を正常に構成できません (#832) by @ZhuLinsen (https://github.com/ZhuLinsen/daily_stock_analysis/pull/920)

⚙️ 構成

  • 特技: https://github.com/ZhuLinsen/daily_stock_analysis/pull/919 の @ZhuLinsen によるサポートされているすべてのモデル (#830) を取得するための /v1/models パスのサポート
  • 修正: https://github.com/ZhuLinsen/daily_stock_analysis/pull/1001 で @ZhuLinsen によってオーバーライドされるのではなく、エージェントごとの max_steps を上限として使用する
