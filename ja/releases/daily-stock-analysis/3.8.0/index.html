daily_stock_analysis v3.8.0

マイナー 公開日2026年3月17日 出典ZhuLinsen/daily_stock_analysis 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

デイリーストック分析 v3.8.0

リリースのハイライト

  • 🎨 Web インターフェイスの一連のスケルトン アップグレードが完了 — 新しい App Shell、サイド ナビゲーション、テーマ機能、ログインおよびシステム設定プロセスが統合されたエクスペリエンスに統合され、デスクトップの読み込みの背景も調整されました。
  • 📈 分析コンテキストは強化され続けています — 米国株には社会世論インテリジェンスが追加され、A 株には財務報告と配当の構造コンテキストが追加され、Tushare はチップ流通と産業セクターの騰落データに新たにアクセスしました。
  • 🔒 動作の安定性と構成の互換性の向上 — ログアウトすると古いセッションがすぐに無効になり、スケジュールされた起動は古い構成と互換性があり、MAX_WORKERS 調整の実行に関するフィードバックとニュースの適時性ウィンドウがより明確になります。
  • 💼 ポジションエラー修正リンクがより完全になりました — 売られ過ぎは事前に遮断され、誤った取引/資本フロー/企業活動を直接削除してロールバックしてダーティデータの修復を容易にすることができます。

新機能

  • 📱 米国株式の社会世論情報 — Reddit を追加 /
  • 📊 A 株の財務報告と配当構造の強化 (問題 #710) - fundamental_context.earnings.data に financial_report フィールドと dividend フィールドが追加されます。配当は「現金配当のみ、税引前基準」に基づいて一律に計算され、ttm_cash_dividend_per_share と ttm_dividend_yield_pct が加算されます。分析/履歴 API の details に financial_report、dividend_metrics のオプション フィールドが追加され、フェールオープンと下位互換性が維持されます。
  • 🔍 Tushare チップおよび業界セクター インターフェイスへのアクセス - チップの配布、業界セクターの上昇および下降データ取得機能、設定されたデータ ソースの優先順位の統合された包含が追加されました。デフォルトでは、日中/時間外取引日は上海時間に従って取得され、Tushare Flush インターフェイスの使用が優先され、必要に応じて Dongcai にダウングレードされます。
  • 🧱 Web UI の基本スケルトンのアップグレード — 共有デザイン トークンと共通コンポーネントを再構築し、App Shell、テーマ プロバイダー、サイド ナビゲーションを追加し、同時に Electron 読み込みの背景を調整して、統合された Web/デスクトップ エクスペリエンスの基礎を築きます。
  • 🔐 ログインおよびシステム設定プロセスの再構築 — ログイン、設定、および認証管理プロセスを再構築し、明示的な認証セットアップ状態処理を追加し、Web 側をランタイム認証構成 API の動作に合わせます。
  • 🧪 フロントエンド回帰とスモーク カバレッジの強化 — ログイン、ホームページ、チャット、モバイル シェル、設定ページ、バックテストの入り口などの主要なパスに対するコンポーネント テストと Playwright スモーク カバレッジを追加および拡張します。

変更

  • 🧭 新しいシェル レイアウト コントラクトへのページ アクセス — ホーム、チャット、設定、バックテストが統合され、新しいページ コンテナー、ドロワー、スクロール規則にアクセスできるようになり、UI 移行中のページ動作の不一致が軽減されました。
  • 💾 設定ページのステータスのより安定した同期 — ドラフトの保持、直接保存の同期、競合処理を最適化し、モジュールレベルの保存後のフロントエンドとバックエンドの構成ステータスの不一致の問題を軽減します。
  • 🎭 ログイン ページのビジュアル ベースラインの復帰 — ログイン ページは、新しい認証状態ロジックと統合フォーム インタラクション モデルを保持しながら、既存の 006 ブランチのビジュアル ベースラインに戻ります。
  • 🏛️ AI 共同ガバナンス資産強化 — AGENTS.md、CLAUDE.md、Copilot 命令および検証スクリプトの一貫性制約を統合および強化し、ガバナンス資産の長期ドリフトのリスクを軽減します。

修正

  • ⏰ スケジュールされた起動により、古い構成との互換性が即座に実行されます (問題 #726) - SCHEDULE_RUN_IMMEDIATELY は、設定されていない場合は RUN_IMMEDIATELY の読み取りに戻ります。アップグレード後にスケジュールされたモードでの古い .env の互換性の問題を修正します。また、.env.example / README で 2 つの構成項目の適用範囲を明確にし、Outlook / Exchange の必須 OAuth2 が現在サポートされていないことを示します。
  • 🧵 MAX_WORKERS 設定が有効になり、実行時の解釈性が向上 (#633) - 非同期解析キューが MAX_WORKERS に従って同期されない問題を修正しました。タスク キューの同時インプレース同期メカニズム (アイドル即時効果、ビジー遅延) を追加し、設定保存フィードバックと実行ログに profile/max/effective を明確に出力して、「パラメーターが有効になっていない」という誤解を減らします。
  • 🔐 ログアウトすると、既存のセッションが直ちに無効になります — POST /api/v1/auth/logout は、ログアウト後に古い Cookie が保護されたインターフェイスにアクセスし続けるのを防ぐために、セッション シークレットをローテーションします。同じブラウザ タブと同時ページは同時にログアウトされます。認証が有効になると、インターフェイスは匿名ホワイトリストに属さなくなり、非ログイン要求は 401 を返し、匿名要求によってグローバル セッションの無効化が引き起こされるのを防ぎます。
  • 🧮 Tushare セクション/チップ コール電流制限と日をまたぐキャッシュ修復 - 新しく追加された trade_cal、業界セクター ランキング、およびチップ配布リンクは統合され、_check_rate_limit() に接続されます。トランザクション カレンダー キャッシュは、サービスが複数日にまたがって実行された後、取得日を決定するために古いトランザクション日を使用し続けることを避けるために、自然日に基づいて更新されるように変更されました。
  • 💼 ポジションの売られ過ぎのインターセプトとエラー フローの回復 (#718) - POST /api/v1/portfolio/trades は書き込み前に販売可能数量を確認し、売られ過ぎの場合は 409 portfolio_oversell を返します。ポジションページには、取引/資本フロー/企業活動を削除する機能が追加されました。削除後、無効な位置キャッシュと将来のスナップショットが同期され、エラー フローからの直接回復が容易になります。
  • 📧 電子メールの中国語の送信者名のエンコード (#708) - 電子メール通知は、中国語を含む EMAIL_SENDER_NAME に対して RFC 2047 エンコードを自動的に実行し、異常なパスに SMTP 接続クリーニングを追加して、GitHub アクション / QQ SMTP での 'ascii' codec can't encode characters によって引き起こされる送信エラーを修正します。
  • 🐛 香港証券エージェントのリアルタイム市場相場の重複排除と高速ルーティング - HK01810 / 1810.HK / 01810 およびその他の香港証券コードの正規化ルールを統合します。香港株式のリアルタイム市場相場は、A 株ソースの優先順位に従って同じ障害が発生したインターフェイスを繰り返しトリガーすることを避けるために、単一の akshare_hk パスに直接従うように変更されます。エージェントの実行期間は、明示的な retriable=false に応答します。 ツールの失敗に対する短絡キャッシュを追加して、同じラウンドの分析で繰り返し失敗する呼び出しを減らします。
  • 📰 ニュース適時性ハード フィルタリングと戦略的ウィンドウ処理 (#697) - NEWS_STRATEGY_PROFILE (ultra_short/short/medium/long) を追加し、NEWS_MAX_AGE_DAYS で有効ウィンドウを均一に計算します。検索結果が返された後、リリース時間のハード フィルタリング (不明な時間の除外、スーパー ウィンドウの除外、将来 1 日のみを許容) を実行し、同じ制約を履歴フォールバック リンクに追加して、古いニュースが再び「最新ニュース/リスク アラート」に入るのを防ぎます。

ドキュメント

  • ☁️ クラウド サーバー Web インターフェイスの展開とアクセスのチュートリアルを追加 (修正 #686) - クラウド展開から外部アクセスまでの実装手順を補足し、リモート セルフホスティングのしきい値を下げます。
  • 🌍 英語のドキュメント インデックスとコラボレーション ドキュメントを完成 - 英語のドキュメント インデックス、貢献ガイド、ボット コマンド ドキュメントを追加し、中国語と英語のバイリンガルの問題/PR テンプレートを追加して、中国語と英語のコラボレーションと外部貢献者がプロジェクトの入り口を理解できるようにしました。
  • 🏷️ Trendshift バッジによって補足されたローカライズされた README — 中国語と英語の説明の間の不一致を減らすために、多言語 README に機能入口ロゴの新しいバージョンを同期的に追加します。
