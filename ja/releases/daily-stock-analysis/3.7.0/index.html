daily_stock_analysis v3.7.0

マイナー 公開日2026年3月15日 出典ZhuLinsen/daily_stock_analysis 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

デイリーストック分析 v3.7.0

新機能

  • 💼 ポジション管理 P0 はオンラインで完全に機能します (#677、問題 #627 に対応)
    • コア台帳とスナップショットのクローズド ループ: 新しいアカウント、トランザクション、キャッシュ フロー、企業行動、ポジション キャッシュ、毎日のスナップショット、その他のコア データ モデルと API エンドポイントを追加します。 FIFO / AVG デュアルコスト方式再生をサポート。同日のイベントの順序は 现金 → 企业行为 → 交易 に固定されます。位置スナップショットの書き込みではアトミック トランザクションを使用します。
    • ブローカー CSV インポート: リストのエイリアスの互換性を含む、Huatai/CITIC/China Merchants による適応の最初のバッチをサポートします。 2 段階のインターフェイス (解析プレビュー + 確認送信)。 trade_uid 優先順位、キー フィールド ハッシュの冪等重複排除。先頭のゼロの株式コードは完全に保持されます。
    • ポートフォリオ リスク レポート: 集中リスク (トップ ポジション + A 株セクターの規模)、履歴リトレースメント モニタリング (不足しているスナップショットの埋め戻しをサポート)、ストップロス アプローチの警告。複数の通貨を人民元換算に統一変換。抽出が失敗した場合は、最後に成功した為替レートにフォールバックし、古いものとしてマークされます。
    • Web ポジション ページ (/portfolio): ポートフォリオの概要、ポジションの詳細、集中円グラフ、リスクの概要、完全なポートフォリオ/単一口座の切り替え。取引/資本の流れ/企業行動の手動入力。埋め込みアカウント作成の入り口。 CSV 分析 + 送信クローズドループおよび仲介セレクター。
    • エージェント ポジション ツール: get_portfolio_snapshot データ ツール、デフォルトのコンパクト サマリー、オプションのポジション詳細およびリスク データを追加しました。
    • イベント クエリ API: 日付フィルタリングとページングをサポートする GET /portfolio/trades、GET /portfolio/cash-ledger、GET /portfolio/corporate-actions を追加しました。
    • Extensible Parser Registry: アプリケーション レベルの共有登録。新しいブローカーの実行時登録をサポートします。新しく追加された GET /portfolio/imports/csv/brokers 検出インターフェイス。
  • 🎨 フロントエンド設計システムとアトミックコンポーネントライブラリ (#662)
    • 進歩的なデュアルテーマ アーキテクチャ (HSL 変数デザイン トークン) を導入し、歴史的なレガシー CSS をクリーンアップします。ボタン / カード / バッジ / 折りたたみ可能 / 入力 / 選択などの 20 以上のコアコンポーネントをリファクタリングします。 clsx + tailwind-merge クラス名マージ ツールを追加。履歴、LLM 設定、その他のページの読みやすさが向上します。
  • ⚡ API 非同期コントラクトと起動の最適化の分析 (#656)
    • POST /api/v1/analysis/analyze 非同期リクエストのリターン コントラクトを標準化します。サービス起動補助ロジックを最適化します。フロントエンドのレポート タイプの結合定義とバックエンドの応答の間の調整の問題を修正します。

修正

  • 🔔 Discord 環境変数の下位互換性 (#659): 実行時の DISCORD_CHANNEL_ID → DISCORD_MAIN_CHANNEL_ID のフォールバック読み取りを追加しました。履歴設定ユーザーは変更せずに Discord Bot 通知を復元できます。すべての関連ドキュメントは .env.example と一致します。
  • 🔧 GitHub アクション ノード 24 のアップグレード (#665): すべての GitHub 公式アクションをノード 24 互換バージョンにアップグレードし、CI ログ内の Node.js 20 非推奨の警告を排除します (2026 年 6 月 2 日の強制アップグレード期間に影響します)。
  • 📅 ポジションページのデフォルト日付のローカライズ: 同じ日の夕方の UTC-N タイムゾーンのユーザーの日付オフセットの問題を修正するために、手動入力フォームのデフォルト日付が現地時間 (getFullYear/Month/Date) に変更されました。
  • 🔁 CSV インポート重複排除ロジックの強化: 重複排除ハッシュには、識別要素として行のシリアル番号が組み込まれており、同じフィールド内の合法的な個別のトランザクションが誤って折り畳まれないようにします。同時に、trade_uid が存在する場合、混合ソースからの繰り返し書き込みを防ぐために、ハッシュも永続化されます。

変更

  • 同じアカウント内で trade_uid が競合する場合、POST /api/v1/portfolio/trades は 409 を返します。
  • 新しい sector_concentration フィールドがポジション リスク レスポンスに追加されます (増分拡張)。元の concentration フィールドは変更されません。
  • API analyze インターフェースの非同期動作契約文書を分析します。フロントエンドレポートタイプの共同更新。

テスト

  • 新しいポジション コア サービス テストを追加しました (FIFO/AVG 部分販売、同日イベント シーケンス、trade_uid リターン 409 の繰り返し、スナップショット API コントラクト)。
  • CSV インポートの冪等性、法的分割トランザクション重複排除、重複排除境界、リスクしきい値境界、および為替レートのダウングレード動作テストを追加しました。
  • エージェント get_portfolio_snapshot ツール呼び出しテストを追加しました。
  • API 非同期コントラクト回帰テストの分析を追加しました。
