daily_stock_analysis v3.17.1

パッチ 公開日2026年5月16日 出典ZhuLinsen/daily_stock_analysis 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

デイリーストック分析 v3.17.1

リリースのハイライト

  • 特技: アラーム ルール CRUD、開始と停止、ワンタイム テスト、トリガー/通知結果クエリをサポートするアラート API MVP を追加しました。最初のバージョンは price_cross、price_change_percent、volume_spike をカバーし、従来の構成の互換性と応答の非感作を維持します。
  • 機能: 通知ゲートウェイは、ntfy および Gotify のファーストクラス チャネルを追加します。通知リンクは、Web テスト、ルーティング、アクション、診断、文書化を補完し、デフォルトではオフになっているプロセス内のノイズ低減機能を追加します。
  • 機能: Windows デスクトップ インストール バージョンでは、自動更新インストール プロセスにアクセスでき、バックグラウンド ダウンロードをサポートし、ユーザーの確認後にインストールを再開し、.env などのランタイム ファイル、データベース、ログのバックアップ/復元をサポートします。
  • 改善: 市場レビューでは、新しいコンセプトのランキング、人気銘柄、日次指値プール、その他の基礎となるデータ ソースが追加され、インデックスの上昇色と下降色のセマンティック構成がサポートされ、レビュー結果が分析履歴に書き込まれます。
  • 改善: Web システム設定ページは、.env 構成バックアップのインポート/エクスポートをサポートします。新しいローカル エラー トラップが通知テストおよびエージェント/通知設定領域に追加され、デスクトップ上の黒い画面のリスクが軽減されます。
  • 改善: レポートには、集約レポート、簡易レポート、シングルストランド レポート、およびテンプレート レポートの下部にあるランタイム モデル情報を非表示にする新しい REPORT_SHOW_LLM_MODEL スイッチがあります。
  • 改善: Docker スタートアップ ポータルは、logs が書き込み可能でない場合にマウント ディレクトリのアクセス許可を自動的に修復し、コンソール出力にダウングレードするため、通常の展開における手動修復手順が削減されます。
  • 修正: データ ソースに資格情報がない場合、または接続が失敗した場合の劣化がより緩やかになり、Longbridge/Pytdx によって冷却が追加され、資金の流れが欠落している場合に信頼性の高い購入結論が出力されるのが回避されます。
  • 修正: 分析リンクは OpenAI 互換の content_blocks 応答と互換性があり、戦略価格フィールドが正規化され、市場レビュー結果のスクロールと履歴記録の損失の問題が修正されます。
  • 修正: デスクトップ バージョンのリリース スクリプトは、electron-builder の自動リリースをオフにし、リリース ワークフローはパッケージ化完了後のタグ ビルドの失敗を回避するために製品を均一にアップロードしてリリースします。

何が変わったのか

  • #1314 の @massif-01 による、ルール CRUD、有効化/無効化コントロール、1 回限りのテスト、トリガー履歴、通知結果クエリ、および初期 price_cross、price_change_percent、volume_spike サポートを備えたアラート API MVP を追加します。
  • ファーストクラスの ntfy および Gotify チャネル、オプションのインプロセス ノイズ リダクション、集約通知障害の分離、診断、ルーティング、および #1271、#1275、#1260、#1269 の @massif-01 によるアクション環境マッピング チェックを使用して通知ゲートウェイを拡張します。と #1276
  • Windows デスクトップの自動更新インストール フローを追加し、#1256 の @ZhuLinsen によりワークフロー ビルド中に電子ビルダーの自動公開を無効にすることでリリース パッケージを修正します。
  • #1278、#1295、#1307、および #1270 の @ZhuLinsen によるセクターランキング、人気銘柄、リミットアッププールデータ、インデックスカラーセマンティクス、分析履歴の永続性、および結果パネルのスクロール修正により、市場レビューのカバレッジが向上しました。
  • Web 設定ページに .env バックアップのインポート/エクスポートを追加し、通知とエージェント設定のローカル エラー境界を追加し、#1253、#1293、および #1294 の @ZhuLinsen によるランタイム モデルのメタデータをレポートで非表示にできるようにします。
  • #1262 および #1263 で @ZhuLinsen がログ ディレクトリに書き込みできない場合に、マウントされたディレクトリのアクセス許可を修復し、コンソール ログにフォールバックすることで、Docker の起動と展開の信頼性を修正しました。
  • オプションのフェッチャー初期化スキップ、Longbridge 再接続クールダウン、Pytdx クールダウン、#1249 と #1289 の @zbl-96 と @ZhuLinsen による資金フロー データ欠落時の信頼性の低い出力など、データ プロバイダーと分析のエラーをより安全に劣化させるようにしました。
  • OpenAI 互換の content_blocks のサポート、戦略価格フィールドの正規化、#1284、#1264、および #1288 の @ZhuLinsen による基本的な集計のデフォルトのタイムアウト バジェットの増加により、レポートと LLM の互換性が向上しました。
  • #1301、#1258、#1259、および #1308 の @massif-01 および @ZhuLinsen によるアラート センター、通知チャネル、デスクトップ パッケージング、README プレゼンテーション、および PR タイトル規則に関するドキュメントを更新します。 フル Changelog: https://github.com/ZhuLinsen/daily_stock_analysis/compare/v3.16.0...v3.17.1
