daily_stock_analysis v3.31.0

#毎日の株式分析 v3.31.0

v3.31.0

リリースのハイライト

  • 機能: エージェント ツール呼び出しにより、カテゴリおよび単一ツールによって構成されたタイムアウト コントラクトが追加され、再試行防止、協調キャンセル、同時実行バジェット、スレッド セーフ、ホット リロードの一貫性が完了します。
  • 機能: 銘柄分析、StockDaily.canonical_id 二重書き込み、および A 株インデックスのマルチデータ ソース フォールバック ルーティングが連携して、銘柄のアイデンティティと市場の格下げリンクを改善します。
  • 改善: ニュース検索が空の場合、レポート内の証拠の境界を忠実に開示します。 Anspire はデフォルトでグローバル リージョンをカバーしますが、代わりにパブリック SearXNG インスタンスが明示的に有効になります。
  • 修正: サービスの再起動後のスケジュールされたタスクの回復、レポートがない場合の障害フィードバックの分析、DingTalk 通知の識別、ディスク レビュー履歴の概要と実際に生成されたバックエンド診断を修正しました。
  • セキュリティ: CVE-2026-54673 に関係する HTTP リダイレクト資格情報ヘッダー情報の漏洩のリスクを修正するために、デスクトップを builder-util-runtime から 9.7.0 にアップグレードします。
  • ドキュメント: xAI Grok の LiteLLM 構成例、Grok Bot 統合手順、再利用可能な非同期分析スキルを追加し、AIHubMix 中国本土直接接続ポータルを更新しました。

何が変わったのか

  • @lmx-2077 により、先勝解決、再試行不可能なタイムアウト結果、協調キャンセル、制限付き並列実行、キャッシュ同期、ランタイム リロード サポートを備えたカテゴリ レベルおよびツールごとのエージェント タイムアウト ポリシーが追加されました。
  • @Gach-Coder と @elvisw による、クロスマーケット名候補、決定論的な canonical_id 永続性、および登録済み A 株インデックスの専用マルチソース フォールバック ルートによる株式 ID 処理の拡張。
  • @Mach-Chan と @yddcy により、欠落しているニュース証拠をレポートとローカライズされたサーフェス全体で明示的にし、Anspire をグローバル地域検索に切り替え、信頼性の低い公開 SearXNG 検出をオプトインに変更しました。
  • @ZhuLinsen と @mameikagou により、サービスの再開後に永続的なスケジュールが復元され、レポートなし分析の失敗が明示され、DingTalk Webhook が通知チャネルとして認識され、市場レビューの概要とジェネレーターの診断が修正されました。
  • @anupamme により、CVE-2026-54673 に対処するために、デスクトップ アップデーターの依存関係パスを builder-util-runtime 9.7.0 にアップグレードしました。
  • @tseliangmin-star と @ZhuLinsen による xAI Grok LiteLLM の例、Grok Bot 統合ガイダンス、非同期安全なスキル コントラクトを追加し、中国本土接続用の AIHubMix 紹介リンクを更新しました。
  • @xxiaoxiong と @ZhuLinsen により、yfinance 配当 TTM と単一銘柄レポートのファイル名フィクスチャが安定化し、バックエンド CI が壁時計に依存しなくなります。
