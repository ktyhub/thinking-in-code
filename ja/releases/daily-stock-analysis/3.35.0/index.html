daily_stock_analysis v3.35.0

#毎日の株式分析 v3.35.0

v3.35.0

リリースのハイライト

  • 特技: 台湾株式市場のレビューと組み合わせ市場のサポート、オプションの TickPlus A 株/ETF データ ソースおよび x6.ai モデル チャネルへのアクセスを追加しました。
  • 改善: Tushare はインターフェイスごとにアクセス許可を分離できず、バックアップ ソースにフォールバックします。ファンダメンタルズは現在の市場状況を再利用し、複数のエージェントが第 1 段階で技術情報と情報情報を並行して取得します。
  • 修正: リアルタイムの市場取引日を過去の比較ベンチマークに合わせ、Yahoo の配当落ち日の価格基準、韓国の株式コード、および韓国のレポート データ ソース名を修正してフォールバックします。
  • 修正: 完全なレポート フォームは、長いテキストでの行の折り返しと広い表のスクロールをサポートし、銘柄選択ページは中国語と英語の切り替えをサポートし、金額と株式数の単位の四捨五入が修正されました。
  • 修正: Windows CLI が解析後に終了できない問題と、ARM64 Docker の OpenBLAS 不正命令クラッシュを修正しました。
  • 修正: エージェント ツール メッセージの制限されていない値が不正な JSON を生成するのを避けるために、ntfy の長いレポート、制限を超えた Bark ペイロード、およびテレグラムの電流制限の再試行を修正しました。

何が変わったのか

  • 台湾市場のレビューと複合市場の選択、オプションの TickPlus A 株/ETF プロバイダー、および x6.ai モデル チャネル プリセットを追加しました。
  • エンドポイントごとに Tushare 権限の失敗を分離し、ファンダメンタルズ分析中にリアルタイムの相場を再利用し、ランタイムコンテキストの伝播による技術/ニュースの発見を並列化します。
  • 相場取引日と過去の比較を調整し、Yahoo の未調整価格の処理を修正し、韓国語のティッカー シード、および韓国語のレポート ソース名のフォールバックを修正しました。
  • 水平スクロール、ローカライズされた株式スクリーニング制御を維持しながらマークダウン レポート テーブルの長いセルをラップし、丸みを帯びた財務単位の境界を修正しました。
  • チャンクごとの LiteLLM ログと ARM64 Docker OpenBLAS の不正な命令のクラッシュによって引き起こされる Windows CLI のシャットダウン ハングを修正しました。
  • 長い ntfy レポート、制限された Bark ペイロード、尊重される Telegram retry_after、および正規化された非有限エージェント ツール値を有効な JSON に分割します。

アップグレードに関するメモ / アップグレードに関するメモ

  • MARKET_REVIEW_REGION=both には台湾が含まれるようになりました。以前の 5 つの市場選択を保持するには、cn,hk,us,jp,kr を使用します。台湾全域とマーケット ライトは引き続き利用できません。
  • TickPlus と x6.ai はオプションです。明示的なプロバイダー/モデル設定は引き続き権限を持ちます。アップグレードする前に、構成とデータをバックアップしてください。
