daily_stock_analysis v3.22.0

マイナー 公開日2026年6月13日 出典ZhuLinsen/daily_stock_analysis 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

デイリーストック分析 v3.22.0

リリースのハイライト

  • 機能: DecisionSignal 独立ストレージと API、実行フロー スナップショット API、Web 実行フロー ビューを追加して、推奨アクションの構造化フィールドと履歴/バックテスト表示リンクを完成させました。
  • 機能: AlphaSift のホット トピック リンクは、ホット リスト、トピックの詳細、発酵ルート、コンセプト ストックの詳細、キャッシュおよび最終データ ソースをサポートする新しいバージョンの契約にアップグレードされます。
  • 特技: 個別銘柄分析では、デフォルトでその日の広範な市場環境の概要が注入され、ハイリスク/引き潮環境における積極的な購入推奨が緩和されます。
  • 修正: 株式照会履歴のコンテキスト、自ら選択した銘柄の等価コード マッチング、低品質のニュースのフィルタリング、実行中のストリームの感度の解除、AlphaSift ホットスポットの詳細の表示などの安定性の問題を修正しました。

新機能

  • 独立した DecisionSignal ストレージ、リポジトリ、サービス、および /api/v1/decision-signals API を追加し、ソース/市場/株式/アクション/期間/ステージの重複排除、クエリ、更新、ステータス更新、遅延有効期限切れ、ポジション フィルタリング、機密情報の非感作化をサポートします。
  • 分析タスクと履歴レポートの実行フロー スナップショット API を追加し、レーン、ノード、エッジ、イベント、概要などの統合コントラクトを提供し、タスク キューからの感度を下げたデータ フロー/情報フローを構築し、診断と AnalysisContextPack の概要を実行します。
  • Web 側では、アクティブなタスク、履歴レポート、ディスク レビュー レポートの実行フロー ビュー エントリを追加し、実行概要、トポロジ ノード、イベント フロー、および基本的なトラブルシューティングの詳細の表示をサポートします。
  • AlphaSift のホット トピック リンクを追加しました。バックエンドは /api/v1/alphasift/hotspots および /api/v1/alphasift/hotspots/{topic} API を提供します。 Web銘柄選択ページでは、注目のトピックエリアを追加し、発酵ルートやコンセプト銘柄の閲覧をサポート。

改善点

  • 個別銘柄分析では、日/市場ごとに再利用される市場環境の概要が追加されます。通常のパイプラインおよびエージェント分析プロンプトでは、感度の低い市場の背景を読み取ることができます。デフォルトでオンになる新しい DAILY_MARKET_CONTEXT_ENABLED 構成が追加されますが、ユーザーはこれを明示的にオフにすることができます。
  • operation_advice フリーテキストと decision_type=buy|hold|sell 統計キャリバーを保持しながら、個別銘柄分析と履歴/バックテスト表示のためのオプションの 8 状態 action / action_label 推奨アクション フィールドを追加しました。
  • Web 意思決定シグナル型の API ラッパーとコントラクト分離テストを追加しました。これは当面 UI には接続されません。
  • ランタイム ログ コンテキストを改善し、ロガー名、トリガー ソース、市場統計、およびリアルタイムの市場プリフェッチ リンク ステータスを追加して、スケジューリング、API、ボット、およびデータ ソースの劣化パスのトラブルシューティングを容易にします。
  • 新しいポジションアカウント削除エントリがポジション管理ページに追加され、既存のアカウントのソフト削除インターフェイスが再利用されます。誤って作成されたアカウントはデフォルトのリスト、スナップショット、リスク、エントリーエントリー、およびイベントリストから非表示になり、履歴記録は物理的に消去されません。
  • AlphaSift の依存関係ロックが d038c52c468543726fc1fd830b53c27d3f09d6da に更新され、DSA ランタイムと Web 適応が、最新バージョンの最新スナップショット、毎日の履歴、業界/コンセプト プロバイダー キャッシュ、ホットスポット リスト、テーマ発酵ルート、コンセプト ストック詳細、最後に成功したホットスポット キャッシュ、および分析後のメタ情報に対して完了しました。
  • デフォルトでは、AlphaSift のホット トピックの読み取りでは、最後に成功したキャッシュが優先されます。手動更新では、リアルタイムでキャッシュを取得して上書きします。リアルタイムのプルが失敗した場合は、古いキャッシュをロールバックしてみてください。
  • AlphaSift のホット トピック エリアはデフォルトの折りたたみ形式に変更され、詳細を読む前に特定のトピックを展開して選択します。発酵ルートはタイムスタンプ付きのタイムライン表示に変更され、コンセプト銘柄をクリックするとホームページにアクセスして直接分析を開始できます。
  • AlphaSift の注目のデータ リンクは、東洋フォーチュン セクターの変化の同じスナップショットを再利用し、実際の騰落、変化の数、高頻度の個別銘柄からトレンド ポイント、継続ポイント、ステージ、主要サンプルを導き出します。
  • AlphaSift のホット トピックの更新では、コントラクト レイヤーが少数の値を返すかキー フィールドが不足している場合、DSA Oriental Wealth セクター トランザクションの直接接続リストが使用され、項目が 3 未満のローカル ホットスポット キャッシュが無視され、セクターの下部フィールドが補完されます。
  • AlphaSift の注目のカードは、よりコンパクトな複数列レイアウトに変更され、コンセプト銘柄リストは個別の銘柄分析をトリガーする独立した「分析」ボタンに変更されました。オリエンタル フォーチュンの構成銘柄、フラッシュ分析、セクターの動きのリーダーを統合するために詳細が優先され、毎日タイムラインが集計および発酵されます。
  • AlphaSift のホット トピックの詳細のために、DSA 側に 30 分のディスク キャッシュを追加しました。同じトピックが繰り返しクリックされると、発酵タイムラインとコンセプト ストックの詳細が再利用されます。トピック イベントには、AlphaSift 契約タイムライン、フラッシュ サマリー、設定されたニュース検索、Dongcai セクターの変更などの実際のソースのみが表示されます。
  • AlphaSift のホット トピック メッセージ カタリシスが概要表示に変更されました。LLM を設定する場合、1 文のトピック カタリシス サマリに圧縮することが優先され、設定されていない場合や通話が失敗した場合は、ローカルの短いサマリーに戻ります。
  • AlphaSift は、オプションの include_details 詳細プリフェッチをホット トピック リストに追加します。デフォルトでは、Web はホット トピック リストとともにトップ トピックの発酵ルートとコンセプト ストックをバッチで戻し、フロントエンド メモリ キャッシュを再利用します。 LLM が利用できない場合、ニュース触媒はローカル イベントの概要に変更されます。
  • main.py --webui-only の起動動作を変更します。FastAPI リスニング ポートが占有されている場合、フェイルファストは明示的なエラーをスローして起動時に終了します。

修正

  • 履歴レポートを入力した後の調査には、現在のターゲットが引き続き適用されます。既存のセッションをスイッチバックまたはリロードする場合、基本的な現在のターゲットは履歴メッセージから復元でき、明示的な切り替えがない場合、バックエンドは誤ったストックツール呼び出し、交換フラグメント、およびインジケーター略語のミスルーティングをブロックします。
  • 独自に選択した銘柄の追加と削除は、00700、HK00700、00700.HK または aapl、AAPL が別のターゲットとして誤って判断されるのを避けるために、同等の銘柄コードに従って香港株と米国株のバリアントを照合します。
  • 推奨アクションのレガシー フォールバックを強化: 否定/回避表現、中国の金融コンテキスト、buy or sell、マルチガードのあいまいなテキスト、および英語の複合語が誤ってアクション バッジとして表示されなくなりました。構造化された action がある場合、バックテスト/履歴トレンドやその他の入り口には、インターフェイス言語に従ってアクション ラベルが表示されます。
  • 関連性ソート後の株式ニュースと多次元インテリジェンス検索にドメイン名に依存しないアクセス フィルタリングを追加し、ダウンロード/インストール パッケージ/アプリケーション評価ページとアダルト/売春サービスのジャンク ページを削除し、同じバッチ内に有効なターゲット/業界候補がある場合の score=0 背景フィラー項目を削除しました。
  • 混合タイム ゾーン イベント タイムスタンプで、ストリーム スナップショットを実行している履歴レポートが 500 を返す問題を修正しました。
  • ローカル パス、プロンプト/生の応答、プロキシ ヘッダーなどの機密の診断フィールドが再フェッチ前に一時的に公開されるのを防ぐために、スナップショット レイヤーの再帰的感度解除ルールを再利用しないストリーム ライブ SSE イベントの実行の問題を修正しました。
  • AlphaSift ホット トピックはデフォルトでロードされ、キャッシュがなく古いアダプテーション レイヤーに alphasift.hotspot モジュールがない場合は空の状態に戻ります。銘柄選択ページを開いた直後に、AlphaSift の準備ができていないことが表示されることはなくなりました。手動更新でも、依存関係を更新する必要があることが示されます。
  • THS 発酵ルートの補足リスト: stock_board_concept_summary_ths が欠落リストを返す場合、ソース濃縮のみがスキップされ、API が返す注目のトピックの詳細には影響しません。
  • デスクトップ パブリッシング パッケージでは、macOS PyInstaller が実行可能ファイルにモジュールを埋め込むときに、ファイル システム/zip スキャンによって欠落していると誤って判断されるのを避けるために、凍結された実行可能ファイルのランタイム プローブ チェック alphasift.dsa_adapter を使用します。
  • AlphaSift のホット トピックの詳細表示は、古い timeline がニュース/LLM 概要をカバーしないように、バックエンド融合 route を優先するように変更されました。ホット スポット リストを手動で更新すると、同じトピックの詳細のキャッシュが同時にバイパスされます。

ドキュメント

  • README および繁体字中国語の README クイック スタート ポータルにはビデオ チュートリアル リンクが追加されており、デスクトップ クライアント ポータルのコピーライティングはクライアント構成チュートリアルに合わせて調整されています。
  • docs/alphasift-integration.md を追加: AlphaSift ロック コミット ソース、ホットスポット コントラクト境界、LLM/LiteLLM 互換セマンティクス、シャットダウン スイッチ下のフォールバック パスを明確にしました。
  • #1381 ランタイム スコープ、互換性境界、公式セマンティック ベース、および一般的なリリース ロールバック手順を追加しました。 ＃＃＃ テスト
  • 対象となる #1381 バックエンド ランタイムと互換性チェック: tests/test_main_schedule_mode.py、tests/test_pipeline_daily_market_context.py、tests/test_daily_market_context.py、tests/test_daily_market_context_guardrail.py、tests/test_agent_executor.py、tests/test_config_env_compat.py、tests/test_config_registry.py、apps/dsa-web/tests/system_config_i18n.test.ts。
  • AlphaSift バックエンド リグレッションを追加/更新しました: python -m pytest tests/test_alphasift_api.py -q、python -m pytest tests/test_docker_entrypoint.py -q、python -m pytest tests/test_main_schedule_mode.py -q -k "start_api_server_fails_before_thread_when_port_is_busy"。
