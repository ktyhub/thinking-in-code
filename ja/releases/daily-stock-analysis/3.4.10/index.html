daily_stock_analysis v3.4.10

パッチ 公開日2026年3月7日 出典ZhuLinsen/daily_stock_analysis 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

デイリーストック分析 v3.4.10

修正済み

  • 🐛 EfinanceFetcher ETF OHLCV データ (#541、#527) — _fetch_etf_data を ef.fund.get_quote_history (NAV のみ、OHCV なし、beg/end パラメーターなし) から ef.stock.get_quote_history に切り替えます。 ETF はゼロではなく、適切な始値、高値、安値、終値、出来高、金額を返すようになりました。 _normalize_data から古い NAV 列マッピングを削除します
  • 🐛 tiktoken 0.12.0 Unknown encoding cl100k_base (#537) — 0.12.0 で導入されたプラグイン登録の回帰を回避するために、requirements.txt に tiktoken>=0.8.0,<0.12.0 を固定します
  • 🐛 Web UI API エラー分類 (#540) — フロントエンドは、すべての HTTP 400 を同じ「サーバー/ネットワーク」障害として扱わなくなりました。エージェントの無効化 / パラメータの欠落 / モデルとツールの非互換性 / アップストリーム LLM エラー / ローカル接続の失敗を区別するようになりました
  • 🐛 North Exchange コードの識別に失敗しました (#491、#533) — 8/4/92 で始まる 6 桁のコードが North Exchange として正しく識別されるようになりました。 Tushare/Akshare/Yfinance などのデータ ソースは .BJ または bj プレフィックスをサポートします。 Baostock/Pytdx は、North Exchange コードのデータ ソースを明示的に切り替えます。上海B株900xxxの誤認を避ける
  • 🐛 スナイパーポイント分析エラー (#488、#532) — 理想的な買い/セカンダリー買いおよびその他のフィールドに「元」という単語が含まれていない場合、括弧内のテクニカル指標の数値が誤って抽出されます。最初の括弧の後の内容が切り取られて抽出されるようになりました。 ＃＃＃ 追加した
  • ダッシュボード レポートの画像へのマークダウン (#455、#535) — 個別銘柄の日次サマリーは、市場のレビュー動作と一致する画像プッシュ (テレグラム、WeChat、カスタム、電子メール) へのマークダウンをサポートしています。
  • ファイルへのマークダウン エンジン (#455) - MD2IMG_ENGINE=markdown-to-file オプション、絵文字のサポートが向上、npm i -g markdown-to-file が必要
  • PREFETCH_REALTIME_QUOTES (#455) — リアルタイム相場プリフェッチを無効にし、efinance/akshare_em 市場全体のプルを回避するには、false に設定します。
  • 銘柄名のプリフェッチ (#455) — 分析前に銘柄名をプリフェッチし、レポート内の「株価 xxxxx」プレースホルダーを削減します。

変更されました

  • 強化されたマークダウンからイメージへの失敗警告 (#455) — 画像変換が失敗したときに特定の依存関係 (wkhtmltopdf または m2f) を表示する
  • WeChat 専用イメージ ルーティングの最適化 (#455) — 企業 WeChat イメージのみを構成する場合、誤解を招く障害ログを避けるために、レポート全体で冗長なイメージ転送が実行されなくなりました。
  • 株価プリフェッチ軽量モード (#455) — 追加のネットワーク オーバーヘッドを削減するために、名前プリフェッチ ステージでのリアルタイム相場クエリをスキップします。
  • 📊 分析レポート モデル マーク (#528、#534) — 分析レポート メタ、レポートの最後、およびプッシュ コンテンツに model_used (完全な LLM モデル名) を表示します。エージェントが複数のラウンドで呼び出される場合、各ラウンドで使用される実際のモデルを記録して表示します (フォールバック スイッチングをサポート)
