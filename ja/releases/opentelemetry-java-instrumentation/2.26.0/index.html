opentelemetry-java-instrumentation v2.26.0

このリリースは、OpenTelemetry SDK 1.60.1 を対象としています。

多くの成果物にはバージョン番号に -alpha というサフィックスが付いていることに注意してください。これは、成果物がまだアルファ品質であり、今後も重大な変更が加えられることを示しています。詳細については、VERSIONING.md を参照してください。

⚠️ 不安定な API に対する重大な変更

  • 非推奨の AWS Lambda v2.2 ラッパーと forceFlush(int, TimeUnit) オーバーロードを削除 (#16170)
  • 非推奨の HTTP client/server メソッドを削除 (#16167)
  • 非推奨のデータベース インストルメンテーション メソッドとクラスを削除 (#16164)
  • 非推奨のピアサービス マッピング API (#16165) を削除
  • ランタイムテレメトリの非推奨クラスを内部にしました (#16173)
  • AttributesExtractorUtil (#16152) を削除します
  • SqlClientAttributesGetter からマーカー インターフェイスを削除 (#16205)
  • ネットワーク/サーバーのゲッター メソッドを DB 属性ゲッターにマージ (#16264、#16268)
  • SQL サニタイザー クラスの名前を SQL アナライザーに変更 (#16269)
  • 新しい命名規則に従って内部共通モジュール パッケージの名前を変更します (#16284、#16308、#16327、#16341、#16373)

🚫 非推奨

  • 統合モジュールを優先して、個々のランタイム テレメトリ モジュール クラスを非推奨にしました (#16087)
  • 機密性の高いクエリ パラメータの処理を優先し、古い HTTP サーバーのクエリ パラメータ メソッドを非推奨にしました (#16097)
  • 古い RPC 属性ゲッター メソッドを非推奨にし、安定したセマンティック規則をサポートする新しいメソッドを優先しました (#16130)
  • 簡略化の一環として、古い ClickHouse インストルメンテーション メソッドを非推奨にしました (#16206)
  • 古い R2DBC メソッドを非推奨にし、db.system.name をサポートするメソッドを優先しました (#16251)
  • 古い DbClientAttributesGetter メソッドは非推奨になりました。 getErrorType() の実装を追加 (#16276)
  • 古い RPC メトリクス メソッドを非推奨にし、安定したセマンティック規約をサポートするものを優先しました (#16298)
  • 古い DbClientAttributesGetter メソッドは非推奨になりました。古い/安定した semconv 分割をより適切にサポートするために getDbName() を追加しました (#16318)

📈 機能強化

  • Spymemcached のサーバー アドレスとポート属性を追加 (#15242)
  • Kafka Connect を組み込み JMX メトリクス ターゲットとして追加 (#15561)
  • Lettuce インストルメンテーションを Instrumenter (#15838) を使用するように変換します
  • OpenSearch Java client: サニタイズされた検索クエリ本体をキャプチャします (#15634)
  • Camel JMX メトリクスに安定したセマンティック規則を適用 (#16088)
  • jvm.file_descriptor.limit メトリクスを追加 (#16174)
  • 親コンテキストを使用して gRPC client コールバックを実行します (#16175)
  • SQL の概要: EXPLAIN ステートメントを処理します (#16184)
  • InfluxDB インストルメンテーションの簡素化 (#16207)
  • db.client.operation.duration (#16222) のヒストグラム バケットを更新しました
  • SQL の概要: Oracle dblink 構文をサポート (#16230)
  • ZIO HTTP サーバー ルートのインストルメンテーションを追加 (#16232)
  • データベースの安定した semconv フラグの下のネットワーク属性を削除 (#16257)
  • Javalin 7 をサポート (#16261)
  • gRPC: 初期の安定した semconv サポート (#16304)
  • os.version リソース属性を設定します (#16311)
  • Camel: 安定した semconv では DB スパンを出力しません (#16275)
  • Dubbo: 安定した semconv サポート (#16352)
  • OpenTelemetry SDK バージョンを 1.60.0 (#16407) に更新します。
  • 新しい安定した LogRecordBuilder.setException() (#16423) を使用します
  • 宣言型構成 API を使用して semconv-stability.opt-in を構成します (#16443)
  • otel.event.name (#16220) をサポート

🛠️ バグ修正

  • SQL サニタイザーは、デフォルトで二重引用符で囲まれたフラグメントを文字列リテラルとして扱うようになりました (#15582)
  • リクエスト完了時に記録された例外をクリア (#16138)
  • スパン終了後の URL 接続状態のクリア (#16155)
  • 環境変数置換による Spring 宣言型設定を修正 (#15775)
  • Ktorサーバー送信パイプラインエラー処理を修正 (#16192)
  • ロギングアペンダ: KeyValue 属性は MDC よりも優先される必要があります (#16239)
  • リクエストごとに新しい PekkoRouteHolder を作成します (#16258)
  • Tomcat JMX: 負のスレッドおよびセッション制限を無視する (#16355)
  • HTTP client スパンでは server.port が必要です (#16388)
  • ピアアドレスを解決する Ktor サーバーのインストルメンテーションを修正 (#16392)
  • サーブレット計測におけるクラスキャスト例外を修正 (#16403)
  • Jetty HttpClient 9.4.24–9.4.43 の空の応答本文を修正 (#16406)
