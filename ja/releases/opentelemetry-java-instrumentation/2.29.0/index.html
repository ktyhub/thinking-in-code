opentelemetry-java-instrumentation v2.29.0

このリリースは、OpenTelemetry SDK 1.63.0 を対象としています。

多くのアーティファクトには、今後も重大な変更が加えられることを反映して、バージョン番号に -alpha というサフィックスが付いていることに注意してください。詳細については、VERSIONING.md を参照してください。

⚠️ 不安定な API に対する重大な変更

  • JmxTelemetry.start(...) API の戻り値の型を変更します。 (#18782)
  • 実験的なランタイム パッケージ テレメトリは、SHA1 チェックサムの代わりに package.checksum_algorithm=SHA-256 および 64 文字の package.checksum 値を出力するようになりました。 (#18846)

🚫 非推奨

  • 古いプロパティ名は非推奨のままにして、共通ログ コンテキスト キーの名前を otel.instrumentation.common.logging.trace-id-key、otel.instrumentation.common.logging.span-id-key、および otel.instrumentation.common.logging.trace-flags-key に変更します。 (#18851)
  • kafka-broker および kafka-connect JMX ターゲット システムの名前を experimental-kafka-broker および experimental-kafka-connect に変更します。古い名前は今のところまだ機能しており、警告が記録されます。 (#18971)

🌟 新しい Javaagent インストルメンテーション

  • RPC client およびサーバー スパンとメトリックを発行する SOFARPC 5.4 インストルメンテーションを追加します。 (#15589)
  • HBase client 2.0.0 から 2.5.0 用の Javaagent インストルメンテーションを追加します。 (#18253)

📈 機能強化

  • otel.semconv.exception.signal.preview=logs を使用して、HTTP リクエスト例外をログ信号として発行するためのオプトイン サポートを追加します。 (#16259)
  • OpenTelemetry、API、1.63、および opentelemetry-api-incubator 1.63 用の opentelemetry-api-1.63 Javaagent インストルメンテーションを追加します。 (#18911)
  • 宣言型 v3_preview semconv 安定性設定のフォールバックとして otel.semconv-stability.v3-preview を追加します。 (#18936)
  • スパン名や db.* 属性を含む、データベース インストルメンテーション全体にわたる実験的な安定したデータベース セマンティック規約オプトイン (otel.semconv-stability.opt-in=database) を更新します。 (#18808、#18853、#18920、#18922、#18926、#18930、#18970、 #18979、#18980、#18984、#18985、#18986、#18987、#18989、 #18990、#18992、#18993、#19004、#19005)
  • Cassandra バッチ ステートメントのクエリ テキストとパラメータ化をキャプチャします。 (#18964)
  • default-enabled=false の場合でも、otel.instrumentation.common.v3-preview の下で opentelemetry-api および opentelemetry-instrumentation-annotations を有効のままにします。 (#18792)
  • otel.instrumentation.common.v3-preview が有効な場合、影響を受ける計測器は enduser.* の代わりに user.* の ID 属性を発行します。 (#18795)
  • otel.instrumentation.common.v3-preview=true の場合、デフォルトで Kafka client メトリクスを無効にします。 (#18828)
  • JDBC 接続メタデータを解析するときに、Amazon Aurora DSQL および AWS ラッパー JDBC URL プレフィックスを認識します。 (#18831)
  • 発行されたメーター スコープに計測バージョンを設定します。 (#18866)
  • 他のアドバイスがアクティブなスパンに属性を付加できるように、他のインスツルメンテーションの後に @WithSpan インスツルメンテーションを実行します。 (#18874)
  • otel.semconv.exception.signal.preview が有効な場合、データベース client エラーを db.client.operation.exception ログとして出力します。 (#18889)
  • otel.semconv.exception.signal.preview=logs が有効な場合、RPC 例外をログ レコードとして出力します。 (#18890)
  • メッセージング例外を otel.semconv.exception.signal.preview のログ レコードとして出力します。 (#18891)
  • otel.semconv.exception.signal.preview=logs が有効な場合、FaaS 例外の faas.invocation.exception ログ レコードを出力します。 (#18892)
  • otel.semconv.exception.signal.preview=logs が有効な場合、OpenAI チャットと埋め込みエラーの gen_ai.client.operation.exception ログを出力します。 (#18893)
  • otel.semconv.exception.signal.preview=logs が有効な場合、AWS SDK リクエストの失敗を rpc.client.call.exception ログ レコードとして出力します。 (#18894)
  • 宣言型構成は、semconv.version、semconv.experimental、および semconv.dual_emit 設定を使用したドメインごとのセマンティック規約の選択をサポートするようになりました。 (#18908)
  • otel.instrumentation.common.v3-preview が有効な場合、otel.semconv-stability.opt-in の代わりに otel.semconv-stability.preview を使用して、不安定な service.peer および rpc セマンティック規則を選択します。 (#18914)
  • otel.instrumentation.common.v3-preview=true の場合、デフォルトで Kotlin コルーチン @WithSpan インストルメンテーションを無効にします。 (#18919)
  • otel.instrumentation.common.v3-preview が有効な場合は、SqlQueryAnalyzer.analyze() で要約認識パスを使用します。 (#18921)
  • otel.instrumentation.common.v3-preview が有効な場合、非推奨の JDBC/db サニタイズ構成名は無視され、db.query_sanitization.enabled が優先されます。 (#18934)
  • otel.instrumentation.common.v3-preview が有効な場合、GC 期間メトリックに jvm.gc.cause を含めます。 (#18967)
  • JDBC トランザクション操作 COMMIT および ROLLBACK の期間メトリックを出力します。 (#19003)
  • 埋め込みバージョンのプロパティを読み取る代わりに、OkHttp 3.0 で生成された InstrumentationVersion クラスを使用し、Android StrictMode のディスク読み取り違反を回避します。 (#19006)
  • distribution.spring_starter.thread_details_enabled が設定されている場合、宣言型 Spring スターター構成にスレッド詳細スパン属性を追加します。 (#19008)

🛠️ バグ修正

  • 将来の Redisson コマンド実行のために現在のコンテキストを保存し、非同期操作でアクティブなトレースを継続します。 (#18701)
  • Pulsar エージェントがマルチトピック コンシューマーに対して重複した受信スパンを作成しないようにします。 (#18771)
  • Ktor client ストリーミング リクエストのハングを修正し、スパンが Ktor 3.5.0 で即座に終了するようにします。 (#18781)
  • ツール呼び出しに空の引数がある場合の Bedrock converseStream NullPointerException を修正しました。 (#18783)
  • プロデューサー スパンが確実に記録できるように、パルサー メッセージ ID を事前に取得します。 (#18803)
  • SQLite JDBC ステートメントとプリペアド ステートメント インストルメンテーションを修正し、SQLite 接続で SQL スパンとパラメーター キャプチャが生成されるようにしました。 (#18885)
  • otel.instrumentation/development.java.* 設定が正しく適用されるように、Logback MDC 宣言型構成キーを修正しました。 (#18924)
  • create table や alter table などの大文字と小文字が混合された DDL ターゲットの SQL パスワードのサニタイズを修正しました。 (#18927)
  • 非同期 Log4j ロガーを通じて出力されたログは、スパンのみのリカバリにフォールバックするのではなく、アプリケーション スレッドの OpenTelemetry Context を保持するようになりました。 (#18937)
  • redis.clients.jedis.Jedis、BinaryJedis、UnifiedJedis をロードする際の計装エラーを回避します。 (#19000)
  • リクエストの親コンテキストを使用して OpenSearch 非同期コールバックを実行します。 (#19027)
