トゥーンフローアプリ v1.0.10

📦 ダウンロードガイド

|オペレーティング システム |建築 |ドキュメント |説明 | |----------|------|------|------| | 🪟 Windows | x64 | ToonFlow-*-win-x64-setup.exe | 推奨、ほとんどの Windows コンピュータで動作します | | 🪟 Windows | ARM64 | ToonFlow-*-win-arm64-setup.exe | ARM アーキテクチャ Windows デバイスに最適 | | 🍎 macOS |アップルシリコン | ToonFlow-*-mac-arm64.dmg | M1/M2/M3/M4 チップ用 Mac | | 🍎 macOS |インテル | ToonFlow-*-mac-x64.dmg | Intel チップを搭載した Mac | | 🐧 Linux | x64 | ToonFlow-*-linux-x64.AppImage |ほとんどの Linux ディストリビューションで動作します | | 🐧 Linux | ARM64 | ToonFlow-*-linux-arm64.AppImage | ARM アーキテクチャ Linux デバイスに最適 |

💡 **どれを選択すればよいかわかりませんか? ** Windows ユーザーは通常、x64-setup.exe を選択します。 Mac ユーザーは「この Mac について」を確認します。M シリーズ チップは arm64.dmg を選択し、Intel は x64.dmg を選択します。

🚀 インストール手順

  • Windows: .exe ファイルをダウンロードし、ダブルクリックしてインストール ウィザードを実行します。 DLL が見つからない場合、または実行時にクラッシュする場合は、まず Microsoft Visual C++ Redistributable (x64) をインストールしてください。
  • macOS: .dmg ファイルをダウンロードして開き、ToonFlow を「アプリケーション」フォルダーにドラッグします。初めて開いたときにセキュリティプロンプトが表示された場合は、「システム設定→プライバシーとセキュリティ」に移動して実行を許可してください。
  • Linux: .AppImage ファイルをダウンロードし、chmod +x ToonFlow-*.AppImage を実行し、ダブルクリックして実行します。
