FunASR 1.4.23

出典: efe5504e388613e5298e1f93d5ca9f861700b489 / タグ v1.4.23。

修正

配信 #3849: lfr_m=lfr_n=1 を使用してオンライン フロントエンドの有効フレーム カーソルを初期化し、正確な入力倍数のために冗長な空の最終オフライン VAD チャンクを回避します。配信 #3783: 提供された token_list ID は、テキスト変換の前にモデル部分にマップされます。提供された語彙を使用すると、SentencePiece ids2tokens は list[str] 部分を返します。テキストには tokens2text を使用してください。語彙が提供されない場合、従来のデコードされたテキストの動作は維持されます。

これは、事前トレーニングされた ASR の品質、Windows/NPU の受け入れ、または完全なリポジトリ スイートの結果を保証するものではありません。

個別にリリースされた funasr-onnx==0.4.9 および funasr-torch==0.1.6 には、独自のタグ、パッケージ、検証が付いています。このルート パッケージ リリースでは、それらは再公開されません。 PR #3848は含まれません。ゼロ特徴を生成する明示的なストリーミング空入力および空ではないテールは、#3849 ハードウェアの許容範囲外です。このリリースでは、すべての EOS パスが修正されているとは主張しません。

検証範囲

  • 新しい候補リリース/README チェック: 45 件、スキップ 0 件。関連ドキュメント/パッケージ/リリース チェック: 104 件、明示的に記録されたスキップ 2 件。失敗やエラーはありません。
  • 実際にインストールされた候補ホイールと最終ホイール: 61 個の CPU コントラクトがそれぞれ非 LFR 機能/チャンク処理、分析 VAD ファイナライゼーション、トークナイザー語彙セマンティクスをカバーします。ローカルの小さな SentencePiece と制御された音響設備は、事前トレーニングされた品質やハードウェア推論ではありません。 439 個のパッケージ ファイルと 13 個のエントリポイントすべてが、承認されたソースと一致します。
  • 封印された生のレシートを再ハッシュし、インストールされたホイールに正確なソースをバインドした後、#3849/#3783 からの 16 個の直接 FP32/BF16 フロントエンド ケース、12 個の FP32 VAD ケース、および 12 個の FP32/BF16 トークナイザー/デコーダー ケースを再利用しました。以前のフロントエンド実行で失敗した 6 件の VAD ケースは記録されたままです。後で修正された VAD 実行は 12 のすべてに合格しました。このリリースでは、新しい GPU 実行は実行されず、事前トレーニングされた品質についても主張されません。
  • ローカルの候補ビルドと候補/最終パッケージのチェック、テスト、およびインストールでは、プライベート HOME/キャッシュ ディレクトリと、検証済みのネットワーク到達不能プローブを備えた別個のネットワーク名前空間が使用されます。最終タグのビルドは、ローカル ネットワーク名前空間ではなく、既存のリリース ワークフローの GitHub アクションで実行されます。新しくダウンロードされた事前トレーニングされた重みは使用されません。別途報告された #3848 テストダウンロード インシデントは、このリリースの承認または検証入力ではありません。
  • 正確なリリースヘッドおよびマージされたメイン CI が実際のログから受け入れられ、アーティファクト インベントリが記録されました。最終タグのワークフローと新しくダウンロードされた Python ホイール/SDIST は、バイト/メタデータ/アーカイブ/ソース チェック、厳密な Twine、オフライン インストール、実際のインポート、および CLI チェックに合格しました。
  • 10 個の変更されていないランタイム アーカイブは、新しいアセット メタデータと既存のランタイム ソース リリースに対して新たにハッシュされた完全なキャッシュ バイトを再利用します。これらは再構築または再実行されませんでした。 SHA256SUMS は 12 個のペイロードすべてをカバーします。これはランタイム ハードウェアに関する新しい主張ではありません。
  • 完全なリポジトリ スイート、運用環境のアップグレード、Nano ベンチマーク、または導入/成長に関する主張は行われません。

何が変わったのか

  • 修正（フロントエンド）: https://github.com/modelscope/FunASR/pull/3849 の @LauraGPT によるデフォルトの非 LFR オンライン機能の処理
  • fix(onnx): https://github.com/modelscope/FunASR/pull/3846 の @BillVan1945 によるオフライン VAD で空の短い入力を処理
  • 修正(トークナイザー): https://github.com/modelscope/FunASR/pull/3783 の @carey-bk による ids2tokens のモデル語彙を尊重します
  • fix(onnx): https://github.com/modelscope/FunASR/pull/3847 の @BillVan1945 によるキャッシュを消費せずに空の句読点入力を処理する
  • 修正 (ランタイム): ONNX VAD と句読点修正を https://github.com/modelscope/FunASR/pull/3850 の @LauraGPT により 0.4.9 としてリリース
  • @LauraGPT による FunASR 1.4.23 を https://github.com/modelscope/FunASR/pull/3851 でリリース

新しい貢献者

  • @carey-bk が https://github.com/modelscope/FunASR/pull/3783 に初めて投稿しました
