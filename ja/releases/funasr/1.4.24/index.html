FunASR 1.4.24

出典: 20f26b7c4905d010768ec91206149df2a90104b6 / タグ v1.4.24。

修正

配信 #3852: 文字/音素トークナイザー スキャンを停止させる代わりに、空の非言語記号を無視します。配信 #3853: パディングされた発話の正しい分散正規化。配信 #3854: 動的 ONNX バッチを含め、バッチでゼロ発火と非ゼロ発火の発話が混在する場合に、有効な CIF 出力と勾配を保持します。

互換性: norm_means=True と norm_vars=True の両方でトレーニングされたチェックポイントでは、修正された正規化後に認識品質の再評価が必要です。 norm_vars=False はデフォルトのままです。ローカル チェックポイントの往復は、事前トレーニングされた認識品質評価ではありません。

これは、事前トレーニングされた ASR の品質、Windows/NPU の受け入れ、または完全なリポジトリ スイートの結果を保証するものではありません。

個別にリリースされた funasr-onnx==0.4.9 および funasr-torch==0.1.6 には、独自のタグ、パッケージ、検証が付いています。このルート パッケージ リリースでは、それらは再公開されません。 PR #3848は含まれません。このリリースでは、すべての EOS パスが修正されたとは主張しません。

検証範囲

  • 新しい候補リリース/README チェック: 45 件、スキップ 0 件。関連ドキュメント/パッケージ/リリース チェック: 104 件、明示的に記録されたスキップ 2 件。失敗やエラーはありません。
  • 実際にインストールされた候補ホイールと最終ホイール: トークナイザー シンボル、分散正規化、ローカル チェックポイント ラウンド トリップ、リポジトリとオーディオの推論、CIF 動的バッチをそれぞれカバーする 37 個の合格した CPU/ONNX ケース。 27 の CUDA パラメータ化はローカルで意図的にスキップされ、バインドされた以前のハードウェア証拠によって個別にカバーされます。 439 個のパッケージ ファイルと 13 個のエントリポイントすべてが、承認されたソースと一致します。
  • 33,870 個の封印された証拠ファイルと 18 個のヘルパーを再ハッシュし、インストールされたホイールに正確なソースをバインドした後、24 個のトークナイザー/CTC ケース、34 個の FP32 CIF ケース、および L20Z での 6 回の CUDA 推論呼び出しを含む 4 個のノーマライザー リポジトリ オーディオ ケースを再利用しました。 106 件のノーマライザー受け入れには、102 件の未変更のケースと 4 件の修復されたオーディオ チェックが保持されます。以前のハーネス/TF32 治具の障害はそのまま残ります。それらは黙って破棄されたり、パスとしてカウントされたりしません。このリリースでは、新しい GPU の実行は実行されず、事前トレーニングされた品質や完全なパラフォーマ エクスポートの主張も行われません。
  • ローカルの候補ビルドと候補/最終パッケージのチェック、テスト、およびインストールでは、プライベート HOME/キャッシュ ディレクトリと、検証済みのネットワーク到達不能プローブを備えた別個のネットワーク名前空間が使用されます。最終タグのビルドは、ローカル ネットワーク名前空間ではなく、既存のリリース ワークフローの GitHub アクションで実行されます。新しくダウンロードされた事前トレーニングされた重みは使用されません。別途報告された #3848 テストダウンロード インシデントは、このリリースの承認または検証入力ではありません。
  • リリースヘッド CI は実際のログと記録されたアーティファクト インベントリから受け入れられました。ロードマップ ジョブは純粋なヘッドをチェックアウトしました。他のヘッド ワークフローは、GitHub の一時的な PR マージ コミットを使用しました。両方のチェックアウト ツリーが正確な候補に対して検証されました。マージされたメイン ソース チェックアウトと最終タグ ソース チェックアウトは個別に検証されました。メインの API-doc ワークフローでは、保持されている中国語の API ページのみを gh-pages から previous-pages にチェックアウトしました。この別個のドキュメント入力は記録されており、推論ソースとしては扱われません。新しくダウンロードされた Python ホイール/SDIST は、バイト/メタデータ/アーカイブ/ソース チェック、厳密な Twine、オフライン インストール、実際のインポート、および CLI チェックに合格しました。
  • 10 個の変更されていないランタイム アーカイブは、新しいアセット メタデータと既存のランタイム ソース リリースに対して新たにハッシュされた完全なキャッシュ バイトを再利用します。これらは再構築または再実行されませんでした。 SHA256SUMS は 12 個のペイロードすべてをカバーします。これはランタイム ハードウェアに関する新しい主張ではありません。
  • 完全なリポジトリ スイート、運用環境のアップグレード、Nano ベンチマーク、または導入/成長に関する主張は行われません。
