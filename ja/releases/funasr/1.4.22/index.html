FunASR 1.4.22

出典: dedefbf643289098e5473fa0cc6ce085e2e9533e / タグ v1.4.22。

修正

Deliver #3841: generate() に渡された merge_length_s は、構築時間/デフォルトのマージ長よりも優先されます。配信 #3833: 動的沈黙スケジュールは、蓄積されたチャンク時間ではなく、現在の音声セグメントの継続時間を使用してフレームごとに評価されます。固定しきい値のオプトアウトは引き続き利用可能です。

これは、事前トレーニングされた ASR の品質、Windows/NPU の受け入れ、または完全なリポジトリ スイートの結果を保証するものではありません。

個別にリリースされた funasr-onnx==0.4.8 および funasr-torch==0.1.6 には、独自のタグ、パッケージ、検証が付いています。このルート パッケージ リリースでは、それらは再公開されません。別途再現された非 LFR フロントエンド例外は、このリリースでは修正されていません。

検証範囲

  • 新しい候補リリース/README チェック: 45 件、スキップ 0 件。関連ドキュメント/パッケージ/リリース チェック: 104 件、明示的に記録されたスキップ 2 件。失敗やエラーはありません。
  • 実際にインストールされている候補ホイール: コールごと/構築/デフォルトのマージ長と動的/固定 VAD スケジューリングをカバーする 9 CPU ユニット契約。モック化された境界はハードウェア推論ではありません。 439 個のパッケージ ファイルと 13 個のエントリポイントすべてが、承認されたソースと一致します。
  • #3841/#3833 の 32 AutoModel および 24 VAD の実際の L20Z FP32 分析統合ケースを、封印された生のレシートを再ハッシュし、正確なソースを取り付けられたホイールにバインドした後、再利用しました。以前の個別の実行では、合計 216,521 の CUDA イベントが記録されました。これは、新しい GPU の実行、BF16 の実行、または事前トレーニングされた品質の検証ではありません。
  • 正確なリリースヘッドおよびマージメイン CI が実際のログ/アーティファクトとともに受け入れられました。最終タグのワークフローと新しくダウンロードされた Python ホイール/SDIST は、バイト/メタデータ/アーカイブ/ソース チェック、厳密な Twine、オフライン インストール、実際のインポート、および CLI チェックに合格しました。
  • 10 個の変更されていないランタイム アーカイブは、新しいアセット メタデータと既存のランタイム ソース リリースに対して新たにハッシュされた完全なキャッシュ バイトを再利用します。これらは再構築または再実行されませんでした。 SHA256SUMS は 12 個のペイロードすべてをカバーします。これはランタイム ハードウェアに関する新しい主張ではありません。
  • 完全なリポジトリ スイート、運用環境のアップグレード、Nano ベンチマーク、または導入/成長に関する主張は行われません。

何が変わったのか

  • 修正(ランタイム): https://github.com/modelscope/FunASR/pull/3838 の @tanishqbaweja による ContextualParaformer および SeacoParaformer のすべてのバッチをデコードします
  • 修正(ランタイム): https://github.com/modelscope/FunASR/pull/3839 の @LauraGPT により ONNX ホットワード バッチ修正を 0.4.7 としてリリース
  • 修正(ランタイム): https://github.com/modelscope/FunASR/pull/3840 の @LauraGPT により、Torch ホットワード バッチ修正を 0.1.5 としてリリース
  • fix(auto): https://github.com/modelscope/FunASR/pull/3841 の @MohammadHijjawi97 によってgenerate()に渡されたmerge_length_sを尊重します
  • 修正(vad): https://github.com/modelscope/FunASR/pull/3833 の @lingfengyao によるフレームごとのオフライン動的沈黙スケジュールを適用します。
  • 修正(ランタイム): https://github.com/modelscope/FunASR/pull/3842 の @BillVan1945 による空白および不完全な CMVN ファイルの処理
  • 修正(ランタイム): https://github.com/modelscope/FunASR/pull/3843 の @LauraGPT により ONNX CMVN パーサー修正を 0.4.8 としてリリース
  • 修正(ランタイム): https://github.com/modelscope/FunASR/pull/3844 の @LauraGPT により、Torch CMVN パーサー修正を 0.1.6 としてリリース
  • @LauraGPT による FunASR 1.4.22 を https://github.com/modelscope/FunASR/pull/3845 でリリース
