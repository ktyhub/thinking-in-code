#何でも-llm v1.17.0

何が変わったのか

  • 修正 (コレクター): https://github.com/Mintplex-Labs/anything-llm/pull/6478 の @L4XB により、スプレッドシートの日付をシリアル番号ではなく日付として読み取る
  • 人間モデルのドロップ温度パラメータ (https://github.com/Mintplex-Labs/anything-llm/pull/6472 の @shatfield4 による)
  • https://github.com/Mintplex-Labs/anything-llm/pull/6470 の @shatfield4 によるリクエストから max_tokens を省略するために、汎用 OpenAI 最大トークン 0 を許可します
  • 修正: https://github.com/Mintplex-Labs/anything-llm/pull/6465 の @evilive3000 によるエージェントの Web ブラウジングで SearchApi エンジンをサポート
  • 修正: https://github.com/Mintplex-Labs/anything-llm/pull/6493 の @timothycarambat によりサーバーをクラッシュさせる代わりに、不正な形式のエージェント WebSocket フレームを無視するようになりました。
  • 修正 (コレクター): https://github.com/Mintplex-Labs/anything-llm/pull/6484 の @L4XB によって HTML のみの mbox メッセージをスキップするのではなく、読み込むようにしました。
  • 修正(コレクター): https://github.com/Mintplex-Labs/anything-llm/pull/6486 の @L4XB によって書き込まれたエンコーディングでテキストのアップロードを読み取ります
  • fix(weaviate, astra): https://github.com/Mintplex-Labs/anything-llm/pull/6488 の @L4XB による他のプロバイダーと同様にコサイン類似度によってチャンクをスコアリングします
  • 修正 (bedrock): AWS で OpenAI モデルをサポート by @hahahahahayesyeseys (https://github.com/Mintplex-Labs/anything-llm/pull/6473)
  • 修正: https://github.com/Mintplex-Labs/anything-llm/pull/6459 の @marmar9615-cloud がスピーチで使用するのと同じベース パスから Kokoko の声を取得する
  • feat(togetherai): https://github.com/Mintplex-Labs/anything-llm/pull/6463 で @imanecdoche による応答の切り捨てを防ぐために max_tokens を設定できるようにしました
  • 修正: https://github.com/Mintplex-Labs/anything-llm/pull/6461 の @marmar9615-cloud によって Azure 埋め込みデプロイメントが変更されるとベクターをリセットして警告する
  • 修正: 設定保存で https://github.com/Mintplex-Labs/anything-llm/pull/6457 の @marmar9615-cloud によって .env が書き換えられるときに、手動で設定された環境設定を維持する
  • 修正: https://github.com/Mintplex-Labs/anything-llm/pull/6454 の @marmar9615-cloud による埋め込みにドキュメントがない場合にワークスペース拒否テキストを使用する
  • 修正: https://github.com/Mintplex-Labs/anything-llm/pull/6452 の @marmar9615-cloud によってチャット ウィンドウに表示されるチャットのみをエクスポートする
  • 修正: @marmar9615-cloud によってアップロードされたマルチシート XLSX のすべてのシートを https://github.com/Mintplex-Labs/anything-llm/pull/6450 に保持する
  • https://github.com/Mintplex-Labs/anything-llm/pull/6482 の @shatfield4 によって生成された画像をチャット エクスポートに含めます
  • 功績: Firecrawl エージェントの Web 検索プロバイダーを追加 (https://github.com/Mintplex-Labs/anything-llm/pull/6480 の @JuampiHernandez により)
  • https://github.com/Mintplex-Labs/anything-llm/pull/6343 の @shatfield4 による編集時にワークスペース設定を自動保存
  • https://github.com/Mintplex-Labs/anything-llm/pull/6483 の @shatfield4 によりプロバイダー検索メニューにキーボード ナビゲーションとオートフォーカスを追加
  • https://github.com/Mintplex-Labs/anything-llm/pull/6496 の @timothycarambat による最初のブロックではなく、テキスト ブロックから人間的な返信を読み取ります
  • 修正: https://github.com/Mintplex-Labs/anything-llm/pull/6524 の @MohammadHijjawi97 によるマークダウン文字が含まれている場合、Telegram リンク URL をそのまま維持する
  • 功績: https://github.com/Mintplex-Labs/anything-llm/pull/6520 の @petre により、Gemini を画像生成プロバイダーとして追加
  • 修正 (ui): モバイル サイドバー ドロワーに動的ビューポートの高さを使用 (https://github.com/Mintplex-Labs/anything-llm/pull/6518 の @albiea による)
  • 修正: プロンプトまたはチャンクに「Context:」と表示される場合、圧縮された RAG コンテキストを保持する (https://github.com/Mintplex-Labs/anything-llm/pull/6503 の @breken-ai による)
  • 修正: https://github.com/Mintplex-Labs/anything-llm/pull/6500 で @SulimanAbdulrazzaq によるメッセージを読み上げるときに絵文字をスキップする
  • 修正: https://github.com/Mintplex-Labs/anything-llm/pull/6506 の @marmar9615-cloud によってシステムのデフォルトに戻すときにワークスペース ルーターをクリアする
  • 修正: https://github.com/Mintplex-Labs/anything-llm/pull/6508 で @marmar9615-cloud によって返信が空になった場合、埋め込みチャットの保存をスキップしました
  • 修正: ユーザーと管理者が https://github.com/Mintplex-Labs/anything-llm/pull/6510 の @marmar9615-cloud によってプロフィールをクリアできるようにしました
  • 修正: https://github.com/Mintplex-Labs/anything-llm/pull/6512 の @marmar9615-cloud により深くクロールするときに、表示されるページに対する相対リンクを解決します。
  • 修正: アップロード時に https://github.com/Mintplex-Labs/anything-llm/pull/6514 の @marmar9615-cloud によってタイトルが提供される場合、各 mbox メッセージの独自のタイトルを保持する
  • https://github.com/Mintplex-Labs/anything-llm/pull/6497 に @shatfield4 による lmman イメージ生成プロバイダーを追加
  • 修正: https://github.com/Mintplex-Labs/anything-llm/pull/6527 の @wenqiw777 によるスラッグが数字で始まるワークスペースに Milvus と Zilliz を埋め込むようにしました。
  • 修正: マルチユーザー モードで Google カレンダー スキルをフィルターし、無効化されたサブスキルを適用する (https://github.com/Mintplex-Labs/anything-llm/pull/6539 の @timothycarambat による)
  • 修正: https://github.com/Mintplex-Labs/anything-llm/pull/6530 の @marmar9615-cloud によって、マクロに ac:name が最初にリストされていない Confluence コード ブロックを保持します。
  • 修正: API アップロードで返されるすべてのドキュメントを https://github.com/Mintplex-Labs/anything-llm/pull/6532 の @marmar9615-cloud によって addToWorkspaces に埋め込む
  • 修正: https://github.com/Mintplex-Labs/anything-llm/pull/6534 の @marmar9615-cloud によって作成された Excel ファイル内の IP、バージョン、および小数点カンマをテキストとして保持する
  • 修正: https://github.com/Mintplex-Labs/anything-llm/pull/6536 の @marmar9615-cloud によるメッセージの先頭でのみ Telegram ボット コマンドを実行する
  • 修正: https://github.com/Mintplex-Labs/anything-llm/pull/6538 の @marmar9615-cloud によって、エージェント リクエストのキープアライブ設定を Ollama と lmmman に送信します。
  • 修正（モバイル）: https://github.com/Mintplex-Labs/anything-llm/pull/6540 の @timothycarambat によるリセット チャットおよびストリーム チャットで不明な threadSlug を拒否
  • 修正: C++、~~~、およびネストされたフェンス コードを、https://github.com/Mintplex-Labs/anything-llm/pull/6547 の @huiq777 による Telegram 返信のコードとしてレンダリングする
  • 修正: DuckDuckGo の結果リンクを一度デコードし、https://github.com/Mintplex-Labs/anything-llm/pull/6544 の @simonether によってタイトルから HTML を削除しました。
  • https://github.com/Mintplex-Labs/anything-llm/pull/6552 の @shatfield4 によるクラウド音声とテレグラム音声応答の TTS テキストをクリーンアップ
  • 修正: JSONL では各ワークスペースのプロンプトと ID を使用し、https://github.com/Mintplex-Labs/anything-llm/pull/6551 では @marmar9615-cloud による Alpaca チャット エクスポートを使用します
  • https://github.com/Mintplex-Labs/anything-llm/pull/6567 の @timothycarambat による空のチャットの挨拶を時間帯ごとにローテーションします
  • 修正: 保存された LiteLLM API キーをマスクし、@marmar9615-cloud による変更を https://github.com/Mintplex-Labs/anything-llm/pull/6556 に保存
  • 修正: https://github.com/Mintplex-Labs/anything-llm/pull/6558 の @marmar9615-cloud により、スケジュールされたジョブの曜日と日を UTC 深夜を越えてシフトします。
  • 修正: @marmar9615-cloud によって https://github.com/Mintplex-Labs/anything-llm/pull/6557 に保存された API キーを使用して Fireworks モデルと Kokoko ボイスをロードする
  • 修正: https://github.com/Mintplex-Labs/anything-llm/pull/6560 の @marmar9615-cloud によって、各新しいエージェント フロー ブロックに独自の ID を与えます
  • 修正: https://github.com/Mintplex-Labs/anything-llm/pull/6562 の @marmar9615-cloud による再起動後も存続するようにパスワード保護をオフにして保存
  • 修正: URL パスが @MohammadHijjawi97 によってパーセント デコードできないリンクを https://github.com/Mintplex-Labs/anything-llm/pull/6565 で保存する
  • 修正: https://github.com/Mintplex-Labs/anything-llm/pull/6566 の @MohammadHijjawi97 により、モデル ルーターがオンになっているときに埋め込みのメッセージ履歴制限を使用する
  • 修正: https://github.com/Mintplex-Labs/anything-llm/pull/6569 の @wenqiw777 による newText の $ パターンを展開するファイルシステム編集ファイルを停止する
  • 修正: https://github.com/Mintplex-Labs/anything-llm/pull/6573 の @timothycarambat によるエージェント チャットの開発者 API ドキュメント添付ファイルを解析する
  • 修正: https://github.com/Mintplex-Labs/anything-llm/pull/6572 の @timothycarambat によるセッション中にチャットから @agent に切り替えるときにアップロードされた画像を維持する
  • ワークスペース温度をエージェントに適用し、https://github.com/Mintplex-Labs/anything-llm/pull/6285 で @shatfield4 によって設定を解除する場合はパラメーターを省略します
  • https://github.com/Mintplex-Labs/anything-llm/pull/6269 の @shatfield4 による推論努力の制御
