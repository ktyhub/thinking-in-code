#何でも-llm v1.2.2

<p align="center"> <img alt="リリース" src="https://github.com/user-attachments/assets/4032c49f-87a1-478d-8706-2d95a4bea333"> </p> ## 🥳 大きな変化 - [**カスタム エージェント スキル:**](https://docs.anythingllm.com/agent/custom/introduction) 完全にカスタムのエージェント スキルを作成して、`@agent` 呼び出しの機能を拡張します。 NodeJS で実行できる場合は、ここで実行できます。 - [**AnythingLLM ブラウザ拡張機能:**](https://docs.anythingllm.com/browser-extension/install) Web から AnythingLLM に情報を直接送信して埋め込んだり、後で使用できるようにワークスペースに直接埋め込んだりできます。これにより、**パスワード保護、VPN 保護、またはその他の非公開 Web ページ**からデータをスクレイピングすることもできます。 - `@agent` を使用して、開発者 API 経由でスキルを実行できるようになりました。 (いいですね) ## 何が変わったのか * https://github.com/Mintplex-Labs/anything-llm/pull/2148 の @hejp001 により common.js を更新 *
