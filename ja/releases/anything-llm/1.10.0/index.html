anything-llm v1.10.0

強調表示された変更点

AnythingLLM デスクトップ アシスタントがリリースされました。

AnythingLLM Desktop は、Granola、Otter、Fireflies などの有料ツールのドロップイン代替品です。

  • デバイス上で完全に実行され、参加せずに会議を記録したり、任意のファイルを要約したりできます
  • NVIDIA Parakeet + AnythingLLM のオンデバイス オーケストレーションを利用
  • エージェント ツール、MCP、または AnythingLLM で既に使用しているその他のものを呼び出すことができます。
  • カスタムの概要テンプレート、トランスクリプトを使用したチャット、さらには話者の識別。
  • click で新しい録画を開始するための「会議に参加しました」デスクトップ通知。あらゆる会議ソフトウェア (Zoom、Slack、Discord、Teams など) の場合
  • レート制限、使用量の上限、または制限はありません https://github.com/user-attachments/assets/355ad2fc-cca1-4e9d-8f08-4a1a08dac48d

AnythingLLM モバイルは Google Play で公開されています

Android AnythingLLM モバイル アプリ は現在、Google Play で公開されています。これは、AnythingLLM のクラウド/セルフホスト バージョンとデスクトップ バージョンの両方と同期します。 https://github.com/user-attachments/assets/e4232dfa-e42e-4d15-af9e-d58f2f0245f9

その他の注目すべき変更点

  • オンボーディングの「ワークスペースの作成」ページを削除 - > ホームに直接アクセスできるようになり、ユーザーの母国語で新しいワークスペースが表示されるようになりました
  • ワークスペース ファイル ピッカーがリファクタリングされ、パフォーマンスが向上しました
  • Azure OpenAI を、完全なエージェント サポートを備えた統合 v1 api に移行しました
  • Paperless-ngx のページネーションのバグを修正
  • 文書化されていない YouTube API が変更され、YT スクレーパーが壊れる問題を修正しました
  • エージェントプロバイダーとしてCohereを実装
  • 依存関係の隆起
  • チャットにドラッグ アンド ドロップした XSLX ファイルがモデルに「表示」されないバグを修正しました
  • Windows 以外のマシン上のパスに対する MCP 修正
  • 健全なスカウトスコアを実現する Docker 画像のバンプとパッチ (B)
  • ホワイトページのクラッシュを防ぐために UI にエラー境界を追加しました
