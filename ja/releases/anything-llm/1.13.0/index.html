#何でも-llm v1.13.0

このリリースは、エージェント エクスペリエンスの改善とエージェント システムへの新機能の追加に重点を置いているほか、より受動的で個人的なハイブリッド AI エクスペリエンスに移行することに重点を置いています。

モデル ルーター: 初の消費者向けハイブリッド AI エクスペリエンス

Model Router 機能は、ローカル AI とクラウド AI を完全に制御できる単一の統合エクスペリエンスにシームレスに融合する、史上初のユーザー定義のインテリジェント ルーティング システムです。これまでは、すべてをローカルで実行するか、すべてをクラウドに送信するかを選択する必要がありました。そのトレードオフはもう終わりました。

Model Router を使用してルールを定義します。送信するすべてのメッセージは自動的に分析され、その特定のタスクに最適なモデルにルーティングされます。それは、簡単な質問のための軽量のローカル モデル、複雑な数学のための推論モデル、微妙な法的分析のための最も強力なクラウド モデルなどです。すべて同じチャットからです。ユーザーにはすべて見えません。すべてはあなたによって定義されます。

これがとてもエキサイティングな理由:

  • ハイブリッド AI。 ローカル モデル (Ollama、LM Studio など) とクラウド プロバイダー (OpenAI、Anthropic、Google) を 1 回の会話で組み合わせます。手動切り替えは不要です！
  • 完全に制御できます。 キーワード、トークン数、時刻、または画像添付ファイルを即座にトリガーする計算ルールを作成します。または、平易な英語で意図を理解する LLM 分類ルール を使用します。
  • 品質を犠牲にすることなくコストを節約します。 単純なクエリを安価なモデルまたはローカル モデルにルーティングします。実際に必要なメッセージのために、高価な API 呼び出しを予約します。
  • インテリジェント キャッシュ。 当社の高度なスティッキー ルーティング システムにより、会話スレッド中は同じモデルに留まるため、メッセージごとにモデル間を行き来することがありません。

これは、AI アシスタントの働き方における根本的な変化であると私たちは考えています。初めて、ローカル モデルのプライバシー、クラウド モデルの能力、そしてそれぞれをいつ使用するかを知るためのインテリジェンスを得ることができます。そしてそれは 100% オープンソースです。

スケジュールされたジョブ: 停止中でも動作する AI

AI アシスタントが、指を離すことなく、定義したスケジュールに従ってバックグラウンドで自動的に動作できるとしたらどうなるでしょうか?

スケジュールされたジョブ は、AnythingLLM を常時稼働の AI 労働力に変えます。朝のブリーフィング、週次レポート、データ監視、調査ダイジェストなど、自動的に実行される繰り返しタスクを作成します。通常であればエージェントに依頼するあらゆる作業が自動化され、ハンズフリーで行われます。モデルがツールで圧倒されず、結果を再現できるように設定できるジョブ固有のスキルがあります。

これによってすべてが変わる理由:

  • 設定したらあとは忘れます。 プロンプトを定義し、ツールを選択し、スケジュールを選択して、そのまま終了します。エージェントは、毎朝午前 8 時、毎週月曜日の正午、毎正時など、必要なときに正確に実行されます。
  • 技術的な知識は必要ありません。 ビジュアルな Cron Builder を使用すると、シンプルなドロップダウンでジョブをスケジュールできます。難解な cron 構文、コマンドライン、コードはありません。ポイントしてclickするだけです。
  • 完全なエージェント機能、完全に自動化。 スケジュールされたジョブは、通常のチャットと同じツール (Web 検索、ドキュメント分析、カスタム スキル、MCP 統合など) にアクセスできます。エージェントが会話内で実行できる場合は、スケジュールに基づいて実行できます。
  • 完全な実行履歴。 すべての実行は、エージェントの完全な推論、ツール呼び出し、生成されたファイル、および最終応答とともに記録されます。過去の実行をいつでも確認したり、エージェントが中断したところから新しいスレッドで続行したりできます。
  • プッシュ通知。 AnythingLLM がバックグラウンドにある場合でも、ジョブが終了した瞬間にアラートを受け取ります。 Click をクリックすると、結果に直接アクセスできます。

エンタープライズ ツールでは、この種の自動化に数千ドルの費用がかかります。クラウド専用プラットフォームでは、データをサードパーティに送信する必要があります。 AnythingLLM は、ユーザーのマシン上で、ユーザーのデータを使用して、ユーザーの制御下で完全に実行される、スケジュールされた AI エージェントを提供します。

朝起きると、夜間のメールの概要が表示されます。毎週の進捗レポートを自動的に作成します。 Web サイトの変更を監視します。可能性は無限で、重要なことに集中している間にすべてが起こります。

自動記憶とパーソナライゼーション

AnythingLLM は自動メモリ抽出とパーソナライゼーションをサポートするようになりました。これにより、AI アシスタントはユーザーが話した内容を記憶し、その知識を使用して応答をパーソナライズできるようになります。

AnythingLLM はバックグラウンド ジョブを実行して、チャットから思い出を抽出し、メモリ バンクに保存します。このメモリ バンクは、AI アシスタントの応答をパーソナライズするために使用されます。何を記憶し、どのように使用するかを完全に制御できます。 モデルにチャット履歴のレビューにサイクルを費やしたくない場合は、手動でメモリ バンクにメモリを追加することもできます。

記憶には次の 2 種類があります。

  • ワークスペースの記憶: 現在のワークスペースに固有の記憶です (作業内容、プロジェクト固有の情報など)。
  • グローバル メモリ: AnythingLLM インスタンス全体に固有のメモリです (名前、設定など)。

記憶は AI アシスタントのシステム プロンプトに挿入されるため、記憶を使用して応答をパーソナライズすることができ、AI アシスタントのナレッジ ベースへの歓迎される追加となります。

エージェントアンケート (特別なツール)

Agent Surveys は、AI アシスタントが続行する前に明確な質問をできるようにする特別なツールです。これは、複雑なタスクを処理していて、エージェントが続行するためにさらに情報を必要とする場合に便利です。

これはデフォルトではオフになっており、エージェント設定で有効にする必要があります。質問に対する回答はチャット メッセージと一緒に保存されるため、エージェントは今後のターンで回答を使用できます。
