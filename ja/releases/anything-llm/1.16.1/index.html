#何でも-llm v1.16.1

活動と思考回路の見直し

<img width="3680" height="2212" alt="image" src="https://github.com/user-attachments/assets/34e52190-51e3-40b5-baeb-d1936319cb4a" />

複数の思考とツールの呼び出しを表示する長期的なエージェント タスク向けに UI を全面的に見直し、単一のクリーンで折りたたみ可能な UI 要素にまとめられるようになりました。

これにより、モデルが生成する重要なコールスタックと思考を読みやすい形式で維持しながら、実際の応答のための画面領域がさらに広がります。

ナビゲーション警告

<img width="3680" height="2212" alt="image" src="https://github.com/user-attachments/assets/dfa98c30-4bde-4321-86cc-eb0bcd7b9873" />

最近、サポートされているすべての LLM に真の中止シグナルを追加しました。これにより、推論をキャンセルするかページを離れると、推論を停止してコンピューティング コストを節約できるようになります。

ただし、これには、チャットから離れるときに推論がキャンセルされ、バックグラウンドでの完了が妨げられるという意図しない副作用がありました。応答を中止する前に警告が表示されるようになりました。

ロードマップ項目: この動作をカスタマイズして、複数の並列推論セッションが可能な、より強力なセットアップや同時実行性の高いセットアップを使用しているユーザー向けにバックグラウンド推論を許可できるように、このユーザーを構成可能にする予定です。

Foundry ローカル組み込み (デスクトップのみ)

<img width="1280" height="720" alt="image" src="https://github.com/user-attachments/assets/d43ba423-83a8-4150-8b62-606ffb6c8882" />

FoundryLocal は、Microsoft によって構築された推論エンジンであり、Windows 11 (バージョン 24H2、ビルド 26100 以降) にプレインストールされて使用できます。

これは、WinML を使用して、あらゆる Windows ハードウェア構成にわたって CPU、GPU、または NPU のモデルを読み込みます。これは、明示的にサポートされていないハードウェア構成に最適なオプションです。 FoundryLocal はまだ展開中であるため、利用可能なモデルが制限される可能性があることに注意してください。ビジョン モデルは現在利用できません。

これに関しては Microsoft と提携しています。バグや問題がある場合は、FoundryLocal チームに転送することができます

GenieX for Snapdragon (デスクトップのみ)

<img width="1280" height="720" alt="image" src="https://github.com/user-attachments/assets/866a7cc2-e3e7-4189-af56-6a29c030aab5" />

[!NOTE] これは、以前の Snapdragon NPU エンジンを置き換えます。古いエンジンの以前のモデルは更新時に削除されるため、これらの最適化されたモデルを再ダウンロードする必要があります。 NPU モデルと通常の GGUF のパフォーマンスが大幅に向上していることがわかります。

このエンジンには GGUF モデルのみを使用することを強くお勧めします。 Qualcomm NPU のみのモデルには 4K コンテキスト ウィンドウがあり、エージェント エクスペリエンスが低下します。

GenieX は、Qualcomm (以前は NexaAI) によって構築されたオープンソース推論エンジンで、X および X2 Elite デバイスの NPU 上で GGUF および Qualcomm AI Hub モデルを効率的に実行します。

AnythingLLM は、ドロップダウンで「AnythingLLM GenieX」プロバイダーを選択することで、フルマネージドの組み込みサポートを提供します。 GGUF と NPU 専用モデルの両方で NPU を活用でき、両方の電力効率とインテリジェンスを実現します。

この点については Qualcomm と提携しています。バグや問題がある場合は、GenieX チームに転送するか、GitHub について問題を提起することができます。 @zhiyuan8、@alexchen4ai、@alanzhuly をよろしくお願いします

新機能

  • Windows (x64/ARM64) 上の [x] ネイティブ Foundry Local SDK - Foundry プロバイダーは完全に自己完結型になり、別個の Foundry Local インストールが不要になり、GPU/NPU に最適化されたモデル バリアントがカタログで公開されます。
  • [x] Windows ARM64 デバイスの GenieX ランタイム サポート
  • [x] AWS Bedrock クロスリージョン推論プロファイルのサポート - 地域プレフィックス付きのプロファイル ID (us.、eu.、global.) がモデルのドロップダウンに表示され、正しくルートされるようになりました。さらに、プリセット リスト外のリージョン (GovCloud、特殊なパーティション) の手動リージョン入力も可能になりました。
  • [x] LocalAI がイメージ生成プロバイダーとして追加され、サーバーからのイメージ対応モデルのみがリストされます。
  • [x] LocalAI コンテキスト ウィンドウの自動検出 - コンテキスト ウィンドウはサーバーの構成からモデルごとに読み取られ、手動設定はオプションでオーバーライドされるようになりました。
  • [x] Windows インストーラーのサイレント/ヘッドレス インストールおよびアンインストール フラグ - Windows インストール ドキュメント を参照してください。

改善点

  • [x] 思考の連鎖とエージェントのアクティビティは単一の折りたたみ可能なコンポーネントになりました。折りたたんだ場合は 1 行、展開した場合は接続されたレールを使用して思考ごとに 1 つのステップが表示され、ストリーミング中にライブ思考がヘッダーに表示されます。
  • [x] 新しい思考連鎖ロールアップがアシスタント パネルに反映されるようになりました。
  • [x] スレッドを離れるか推論途中で移動すると、黙って世代を強制終了するのではなく、応答が失われる前に警告が表示されるようになりました。
  • [x] Foundry Local は、組み込みランタイムの使用時にセットアップを求めるプロンプトを表示しなくなり、機能検出によってモデルを自動ロードします。
  • [x] オンボーディング ライト モード スタイルと再設計された LLM 選択 UI
  • [x] Beacon は、折りたたみ可能な思考とモデル詳細テキストのオーバーフローの修正により、ストリーミング中に思考ブロックとマークダウン形式を正しくレンダリングするようになりました。
  • [x] Windows インストーラーにサイドバー パネルのイメージが含まれるようになりました
  • [x] プロンプト入力の下書きがナビゲーション間で保持されるようになりました。

バグ修正

  • [x] 固定されていない undici バージョンでのコンテンツ ヘッダーの長さの不一致によって引き起こされる Gemini クラッシュを修正 - v6 と v7 の両方と互換性を持つようになりました
  • [x] chat モードで Anthropic (または Bedrock Anthropic) 応答を途中で中止し、フォローアップを送信するときのクラッシュを修正しました。
  • [x] チャット全体をワイプするために応答を一時停止する原因となった、リークされた中止ストリーム リスナーによるメモリ リークを修正しました。
  • [x] 新しいワークスペースを作成する際のクラッシュを修正しました
  • [x] 新しい統一モーダル コンポーネントによって導入されたモーダルで欠落していたセットアップ CTA を修正 - カテゴリ ビューとツール ビューの両方でのスケジュールされたジョブ スキルのセットアップ、コミュニティ ハブ接続キー、実験的機能の拒否ボタン
  • [x] エージェント機能の応答を待機している間に中間ローダーが高すぎる問題を修正しました。
  • [x] ワークスペース チャットの削除ボタンの周囲の境界線を修正しました
  • [x] モデルが think タグを閉じない場合に、推論が「思考」でスタックする問題を修正しました。
  • [x] 接続がまだ開いている間にエージェントの WebSocket 送信が起動される問題を修正しました
