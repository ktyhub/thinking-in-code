#何でも-llm v1.18.0

何が変わったのか

  • 修正: https://github.com/Mintplex-Labs/anything-llm/pull/6592 の @u00dxk2 によって、k8s プローブがサーバーの /api/ping を指すようにしました。
  • 修正: https://github.com/Mintplex-Labs/anything-llm/pull/6585 で @marmar9615-cloud によって画像が添付されているときに解析されたファイルを削除してもクラッシュしない
  • 修正: 添付ファイルが https://github.com/Mintplex-Labs/anything-llm/pull/6586 の @marmar9615-cloud によってファイル名を共有している場合に、clicked イメージを開く
  • 修正: https://github.com/Mintplex-Labs/anything-llm/pull/6591 の @simonether による生のチャット履歴からプロンプトを作成するプロバイダーへの履歴添付ファイルの送信を停止します。
  • 修正: https://github.com/Mintplex-Labs/anything-llm/pull/6584 の @marmar9615-cloud による埋め込み許可リストのエントリをブラウザーの起点として比較
  • https://github.com/Mintplex-Labs/anything-llm/pull/6608 で @timothycarambat による低労力研究の主張を防ぐために却下コメントを追加
  • 修正: https://github.com/Mintplex-Labs/anything-llm/pull/6595 の @wenqiw777 により、すべてのプロバイダー パスでエージェント ツールに必要なパラメーターを送信
  • 修正: ANYTHINGLLM_MAX_RETRIES が https://github.com/Mintplex-Labs/anything-llm/pull/6597 の @marmar9615-cloud によって設定されている場合、SDK の再試行回数を尊重します
  • 修正: https://github.com/Mintplex-Labs/anything-llm/pull/6599 の @marmar9615-cloud によるサインインで正しいテナントが使用されるように、Outlook アカウントの種類を保存します。
  • 修正: https://github.com/Mintplex-Labs/anything-llm/pull/6604 の @marmar9615-cloud によるシステム プロンプト変数の変更が失敗した場合にエラーを表示する
  • 修正: https://github.com/Mintplex-Labs/anything-llm/pull/6601 の @marmar9615-cloud による Telegram ツールの承認に TOOL_CALL_APPROVAL_TIMEOUT_MS を適用
  • 修正: https://github.com/Mintplex-Labs/anything-llm/pull/6605 の @marmar9615-cloud により、時間ごとのスケジュールの分を 30 分タイム ゾーンの UTC に変換します
  • 修正: https://github.com/Mintplex-Labs/anything-llm/pull/6610 でピッカーが @YokoAC によってページ分割されている場合、アップロード後にフォルダー全体を選択します
  • 修正: https://github.com/Mintplex-Labs/anything-llm/pull/6613 の @deepanshupal によって作成された Excel ファイルのテキストとして 15 桁を超える数値文字列が保持されるようになりました。
  • 修正: MCP で削除された i18n プレースホルダーと、https://github.com/Mintplex-Labs/anything-llm/pull/6614 の @theluckystrike によるプロファイル文字列を復元
  • 修正: https://github.com/Mintplex-Labs/anything-llm/pull/6619 の @MohammadHijjawi97 によるバルク リンクが #fragment だけが異なる場合に各ページを 1 回スクレイピング
  • 修正: https://github.com/Mintplex-Labs/anything-llm/pull/6623 の @marmar9615-cloud によって、要求されたファイルを Outlook の返信と返信の下書きに添付します。
  • 修正: https://github.com/Mintplex-Labs/anything-llm/pull/6625 の @marmar9615-cloud による manage-users および update-pin 上の不明なワークスペースに対して 404 を返す
  • 修正: https://github.com/Mintplex-Labs/anything-llm/pull/6628 の @marmar9615-cloud によってピッカーのサーバーのオフセットからドキュメントの次のページをロードします
  • 修正: https://github.com/Mintplex-Labs/anything-llm/pull/6629 の @marmar9615-cloud によってワークスペースへの添付ファイルの埋め込みが失敗したときにエラーを表示する
  • 修正: https://github.com/Mintplex-Labs/anything-llm/pull/6631 の @theluckystrike により、モデル ルーターとモデル ピッカー文字列でドロップされた i18n 値を復元します。
  • 修正: https://github.com/Mintplex-Labs/anything-llm/pull/6633 で @dakjdakd による孤立クリーンアップ中に参照された MBOX チャット添付ファイルを保持する
  • 修正: https://github.com/Mintplex-Labs/anything-llm/pull/6635 の @dakjdakd による会話によってチャットの添付ファイルの状態とアップロードを分離
  • 修正: https://github.com/Mintplex-Labs/anything-llm/pull/6637 の @dakjdakd により、停止されたスケジュールされたジョブの Windows 上での実行を完了します。
  • 修正: https://github.com/Mintplex-Labs/anything-llm/pull/6644 の @theluckystrike により、コレクター内で YouTube チャンネル URL をビデオ リンクとして扱わないようにしました。
  • 修正: https://github.com/Mintplex-Labs/anything-llm/pull/6648 の @marmar9615-cloud によるエージェントのラグメモリ検索にワークスペースの類似性しきい値を適用
  • 修正: https://github.com/Mintplex-Labs/anything-llm/pull/6650 の @marmar9615-cloud により、ファイル名を共有する一括スクレイピング ページを個別のファイルに書き込む
  • 修正: https://github.com/Mintplex-Labs/anything-llm/pull/6652 の @marmar9615-cloud によるページなしを報告する代わりに、Confluence の読み込みエラーを表面化
  • 修正: https://github.com/Mintplex-Labs/anything-llm/pull/6654 の @marmar9615-cloud による AstraDB のドキュメント埋め込みを復元
  • 修正: https://github.com/Mintplex-Labs/anything-llm/pull/6656 で @marmar9615-cloud によってマルチユーザー モードに切り替えた後、スケジュールされたジョブを停止する
  • 修正(サーバー): https://github.com/Mintplex-Labs/anything-llm/pull/6676 で @rome-xi によってプロンプト変数を展開するときに、$$ と $& をそのまま維持する
  • 修正(コレクター): https://github.com/Mintplex-Labs/anything-llm/pull/6670 の @moneebullah25 により、コンバーターのないバイナリ型をテキストとして扱うのをやめる
  • 修正: https://github.com/Mintplex-Labs/anything-llm/pull/6677 の @Saadanjum0 によるリポジトリ プロバイダー チェックで、response.text の代わりに response.send を使用する
  • 修正: https://github.com/Mintplex-Labs/anything-llm/pull/6672 の @moneebullah25 によるコレクター トークンの推定に現実的なフォールバック除数を使用する
  • 修正: https://github.com/Mintplex-Labs/anything-llm/pull/6671 の @moneebullah25 による、wipeCollectorStorage ガードの解決後に戻る
  • https://github.com/Mintplex-Labs/anything-llm/pull/6663 の @shatfield4 によるツール呼び出し後の、スケジュールされたジョブ応答内の生の think ブロックを修正
  • 修正: ファイルを添付するときに未送信のプロンプト テキストを保持すると、https://github.com/Mintplex-Labs/anything-llm/pull/6704 で @timothycarambat による新しいスレッドが作成されます
  • 修正: https://github.com/Mintplex-Labs/anything-llm/pull/6701 の @marmar9615-cloud による再埋め込みが失敗した場合に監視ドキュメントを再試行
  • 修正: https://github.com/Mintplex-Labs/anything-llm/pull/6699 の @marmar9615-cloud によってドキュメントが見つからなかったのではなく、失敗した最初の Paperless-ngx リクエストを報告しました
  • 修正: https://github.com/Mintplex-Labs/anything-llm/pull/6698 で @marmar9615-cloud によるページ リンクをたどるときに、設定された Paperless-ngx URL を維持する
  • 修正: https://github.com/Mintplex-Labs/anything-llm/pull/6697 の @marmar9615-cloud によってリンクされたファイルに転写と OCR 設定を渡す
  • 修正: https://github.com/Mintplex-Labs/anything-llm/pull/6693 の @marmar9615-cloud により、不明なユーザー名と間違ったパスワードに対して同じログイン エラーが発生する
  • 修正: https://github.com/Mintplex-Labs/anything-llm/pull/6688 の @wenqiw777 によって作成された Word 文書でネストされた繰り返しリストが正しく表示されるようになりました。
  • 修正: https://github.com/Mintplex-Labs/anything-llm/pull/6708 の @dakjdakd による Anthropic エージェント プロバイダー用のシリアル ツールの使用をリクエスト
  • 修正: https://github.com/Mintplex-Labs/anything-llm/pull/6706 の @dakjdakd による元のエラーを失うことなく、PGVector トランザクションの失敗を伝播します。
  • 修正: https://github.com/Mintplex-Labs/anything-llm/pull/6710 で @dakjdakd によってジョブが無効化または再同期された場合、キューに入れられたスケジュールされたジョブの実行をキャンセルする
  • https://github.com/Mintplex-Labs/anything-llm/pull/6711 内の @timothycarambat による v1.18.0 タグ
