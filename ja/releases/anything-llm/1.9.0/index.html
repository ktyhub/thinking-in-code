#何でも-llm v1.9.0

@agent オーバーホール&ストリーミング ⚡️️

<ビデオ src="https://github.com/user-attachments/assets/fbbfab37-e1b0-442b-b7d4-277aacfcf9bb"></ビデオ> anythingllm が最初にリリースされたとき、「エージェント」という言葉は LLM の世界の語彙にありませんでした。エージェントは急速に AI アプリケーションを構築するための標準になりつつあり、LLM と対話するための核となるエクスペリエンスでもあります。 あまりにも長い間、ビルディング エージェントの複雑さ、むらのあるツール呼び出しサポート、ツールを使用することさえできないモデル、その他のオタク要素のせいで、99% の時間は応答を待つローディング スピナーを眺めているだけだったので、使用するのがあまり楽しくないエクスペリエンスを解決しなければならないことがよくありました。

新しいエージェント エクスペリエンスが登場

ツールの呼び出しと応答をリアルタイムでストリーミング (すべてのプロバイダー、すべてのモデル) エージェントは、Web からファイルをリアルタイムでダウンロードして取り込むことができるようになりました (例: PDF、Excel、CSV へのリンク)。ドキュメントを使用するものはすべて、Web からエージェントによってリアルタイムで読み取ることができます。

今後の予定:

  • エージェント フローを使用しないエージェント リアルタイム API 通話
  • エージェントイメージの理解
  • エージェント システム プロンプト パススルー + ユーザー コンテキスト認識
  • リアルタイム ファイル検索クロスプラットフォームのデフォルト スキル

注目すべき改善点: 🚀

  • すべてのモデルとプロバイダーがエージェント ストリーミングをサポートするようになりました
  • Microsoft Foundryローカル統合
  • エージェントまたはアップローダー経由で Web リソースを一時的にスクレイピング/ダウンロードする
