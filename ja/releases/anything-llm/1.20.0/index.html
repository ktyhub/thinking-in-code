#何でも-llm v1.20.0

ブラウザ拡張機能を更新しました

ブラウザ拡張機能 は、ドキュメントを収集するだけの元の機能を超えて、click を右クリックして、コンテキスト (テキストと画像) を追加し、Chrome で直接チャットできる本格的な UI チャット バーに改良されました。このサイドバーには、ツールなどの従来のチャット UI とほぼ完全に同等の機能が備わっている必要があります。 下位互換性と上位互換性がありますが、サーバーと拡張機能のバージョンが 1.20.0 以降の場合は、完全な機能のみが期待されます。 Chrome ウェブストア もこのバージョンに更新されました。 https://github.com/user-attachments/assets/830069a6-34cb-4f37-80b0-6d52eb4622d0

PowerPoint ツールの全面見直し

<img width="1990" height="1099" alt="pptx 世代" src="https://github.com/user-attachments/assets/05689972-1296-4869-b208-dd9301222dd3" /> エージェントの PowerPoint ツールは、よりクリーンで見栄えの良いプレゼンテーションを作成できるよう、根本から再構築されました。 - **テーマとレイアウト:** デッキでは、新しいカラー テーマと、各スライドのコンテンツに合わせて選択された一連のレイアウトが使用されるため、同じレイアウトがスライドごとに繰り返されることはありません。 - **ライブ スライド プレビュー:** スライドが作成されるとチャットに表示されるため、デッキが完成する様子を確認できます。 Cliプレビューを確認すると、フルサイズで表示されます。 - **根拠のあるコンテンツ:** 図、グラフの値、引用は、概要、調査、または会話に含まれており、テキストが各スライドに合わせてサイズ設定されている場合にのみ保持されます。 ### Gmail および Outlook の電子メール承認カード <img width="1990" height="1099" alt="電子メール製図" src="https://github.com/user-attachments/assets/0b571869-c43b-454f-bdf1-0e2e3d4b4beb" /> エージェントが [Gmail](https://docs.anythingllm.com/agent/usage/gmail-agent) または [Outlook](https://docs.anythingllm.com/agent/usage/outlook-agent) ツールを使用して電子メールを送信または下書きする場合、承認リクエストが電子メール カードとして表示されるようになりました。承認する前に、カード内で受信者、Cc、Bcc、件名、本文を直接編集できます。編集中は承認タイマーが一時停止し、送信された電子メールを展開して、送信された内容を正確に確認できます。 ### MCP の改善 - **ID 転送:** MCP サーバーは、ワークスペースと、それを呼び出しているユーザーを受信できるようになりました。 `anythingllm.forwardIdentity` を使用してサーバーごとにオプトインします。 [MCP サーバーへの ID の転送](https://docs.anythingllm.com/mcp-compatibility/forward-identity) を参照してください。 - **サーバーごとのタイムアウト:** MCP サーバー上で `anythingllm.timeout` (秒単位) を設定して、ツール呼び出しの実行時間を制御します。デフォルトは 60 秒です。 - **開発者 API:** 新しい `/v1/mcp-servers` エンドポイントを使用すると、MCP サーバーの一覧表示、追加、更新、削除、開始、停止、リロード、および個々のツールのオン/オフを行うことができます。 - 多くのツールを備えた MCP サーバーはツールのすべてのページをロードするようになり、1 つのサーバーを起動すると新しく保存されたサーバーも選択され、切断されたサーバーは削除できます。 ---- ## 何が変わったのか * 修正: 狭い画面のスクロール コンテナーでマークダウン テーブルをラップする (#6852) by @ManojDevarajulu
