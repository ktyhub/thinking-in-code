#何でも-llm v1.15.0

AnythingLLM が OS 全体の AI エージェントになりました

AnythingLLM 1.15.0 for Desktop を使用して、私たちはエージェントをあなたのところへ連れてくることが何を意味するかについて懸命に取り組んできました。まだローカルにありますが、アプリやブラウザの壁の外にあるもの。このリリースには、この取り組みに関する最初の 3 つの機能が含まれています。楽しんでいただければ幸いです。

マジック機能の紹介

マジック機能は、AnythingLLM 内だけでなく、コンピューター全体に AI をもたらします。ディクテーション、テキスト アクション、オートコンプリートは、あらゆるアプリで完全にデバイス上で機能します。

すべての Magic 機能は無料で使用でき、サインアップは必要ありません。 Pro では 1 日あたりの制限が削除されます。

AnythingLLM プロ

AnythingLLM については何も変わりません。 Pro は純粋に追加的です。既存の機能は影響を受けず、何もロックされません。

すべての Pro 機能には常に無料の日次枠があり、サインアップは必要ありません。

AnythingLLM Pro について詳しくは、こちら をご覧ください。

マジック エコー - ドキュメント

OS 上のどこでも機能する、よりスマートな音声からテキストへのディクテーション。 SuperWhisper や WhisprFlow などのツールを完全に置き換えることができます。完全にオンデバイス。

自然に話すと、単語がカーソルのある場所に文字起こしされ、整理され、句読点が付けられて表示されます。 Echo は画面上の内容を確認して、ディクテーションをよりスマートかつ状況に応じたものにすることができます。

カスタム辞書のサポート、音声コマンドなどが含まれます。

マジック ビーコン - ドキュメント

アプリ内のテキストを強調表示し、AI で即座に操作します。

画面上のテキストを強調表示すると、要約、翻訳、書き換え、調査、カスタム アクションの実行など、即座に操作できます。 Beacon は、ウィンドウを切り替えることなく、どのアプリでも動作します。

また、エージェントのスキル、MCP、およびツールに完全にアクセスできます。AnythingLLM の全機能セットは、カーソルのある場所であればどこでも利用できます。

<ビデオ src="https://github.com/user-attachments/assets/b8131375-5530-41ae-9fc8-620944552c51"></ビデオ>

マジック タブ - ドキュメント

コンピュータ全体で文法的に - 完全にデバイス上で。

入力すると、Magic Tab が次に来る内容を提案します。どのアプリでも、作業中の内容を認識して、提案が実際に適合するようにします。テキスト フィールドに Cli と入力すると、1 文字も入力する前に何かが提案されます。

Grammarly を使用している場合、Tab はデバイス上で非公開でそれを完全に置き換えることができます。

何が変わったのか

  • https://github.com/Mintplex-Labs/anything-llm/pull/5906 の @angelplusultra によりチャット履歴の上限を解除
  • 修正: https://github.com/Mintplex-Labs/anything-llm/pull/5907 の @shatfield4 により、Windows パス上で Prisma の「ファイル名が見つかりません」で API の更新埋め込みが失敗する
  • インテリジェント ツール選択 (ToolReranker) は、https://github.com/Mintplex-Labs/anything-llm/pull/5893 の @angelplusultra によってデフォルトで有効になります
  • 功績: https://github.com/Mintplex-Labs/anything-llm/pull/5589 の @jhsmith409 により、クエリ/パッセージ プレフィックス環境変数を GenericOpenAi エンベッダーに追加
  • https://github.com/Mintplex-Labs/anything-llm/pull/5909 内の @timothycarambat による 1.15.0 タグ
