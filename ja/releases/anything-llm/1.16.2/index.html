#何でも-llm v1.16.2

新機能

  • [x] LLMman - OSS が、Docker モデル ランナーに代わるローカル LLM プロバイダーとして利用できるようになりました。
  • [x] Google Vertex AI が LLM プロバイダーとして利用できるようになりました
  • [x] チャットから画像を作成する新しい generate-image エージェント スキル
  • [x] You.com が、データ保持ゼロのより充実した Web 検索を実現するデフォルトの Web 検索プロバイダーになりました
  • [x] エージェント フロー変数がオプションの引数をサポートするようになりました
  • [x] ヒンディー語、ブルガリア語、スウェーデン語のサポートが追加されました
  • [x] ARM 上の Windows 上の GenieX は、ローカル モデル ディレクトリにあるモデルを一覧表示し、UI の Hugging Face からモデルを直接プルできるようになりました。
  • [x] Cli ウィンドウの上部にあるバージョン タグを確認して、ログとストレージ ディレクトリに簡単にジャンプします

改善点

  • [x] エージェントの Web ブラウジングがデフォルトで有効になりました
  • [x] ローカルプロバイダーがチャットでモデルの読み込みステータスを報告するようになったので、最初の応答が遅い理由がわかります
  • [x] Ollama ランタイムがバンドル モデル リストの更新により 0.33.3 に変更されました
  • [x] デスクトップ レイアウトをすっきりさせるために、メイン コンテンツ領域の周囲の境界線を削除しました。
  • [x] 「新機能」モーダル レイアウトを再設計しました
  • [x] 表内の日付が人間が判読できる形式で表示されるようになりました。
  • [x] スクレイピングされた Web ページは、テーブル、順序付きリスト、コード ブロックをフラット化するのではなく保持するようになりました。
  • [x] PDF ページが改行で結合されるようになり、単語がページ境界を越えて結合されなくなりました。
  • [x] Mistral の埋め込みがバッチ化されるようになり、大規模なドキュメントの埋め込みが大幅に高速化されました。
  • [x] ドキュメント検索は、正規表現ではなく文字通りに用語に一致するようになりました。
  • [x] 監視されているドキュメントは、同期時に古いベクトルを消去するようになりました。
  • [x] Web 検索プロバイダーとしての AnySearch
  • [x] KoboldCPP プロバイダーがオーバーホールされ、他のプロバイダーと一致するように最新化されました
  • [x] Keenable が Web 検索プロバイダーとして追加されました
  • [x] ルーティング コストと優先度を制御するための OpenRouter サービス層の選択
  • [x] 参照画像を使用した LocalAI 画像編集
