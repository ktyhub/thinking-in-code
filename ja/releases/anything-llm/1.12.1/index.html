#何でも-llm v1.12.1

注目すべき改善点

ストリームドドキュメントの埋め込み

ドキュメントをワークスペースにアップロードすると、埋め込み中にドキュメントごとのプロセスがレポートされるようになりました。これにより、パフォーマンスとユーザー エクスペリエンスが大幅に向上しました。このプロセス中に、進行状況を失うことなく、キューにドキュメントを追加したり削除したり、ページを閉じて別のページに移動したりすることもできます。

<img width="1745" height="1011" alt="キュー埋め込み" src="https://github.com/user-attachments/assets/ffbd06ad-cd2c-480a-89ba-bb7a0068abbc" />

アプリの統合

エージェント スキルに必要なセットアップが最小限またはゼロで、次のアプリの統合が組み込まれています。

  • Gmail
  • 展望
  • Google カレンダー

その他の改善点

  • [x] メイン UI の画像ライトボックス
  • [x] カスタム mdpdf フォークによる PDF 生成での韓国語、中国語、日本語の文字サポートを有効にしました。
  • [x] アプリ統合に関する引用の改善
  • [x] エージェント スキルにおける DDG のデフォルト Web 検索
  • [x] ドキュメント生成エージェントによって生成されたドキュメントをマシン上のネイティブ アプリケーションで開く
  • [x] ENV 設定によるエージェント スキルの自動承認
  • [x] Ollama が 0.20.7 に変更されました (Qwen3.5 サポート、Gemma 4 など)
  • [x] 新しいカスタマイズ > ユーザーがチャット ウィンドウを閉じたときにモデルをアンロードするための Unload model when closed のチャット設定。
  • [x] 汎用 OpenAI 機能検出/ENV 設定
  • [x] 1.10.0 の変更をサポートするために Lemonade を更新します
  • [x] カタロニア語翻訳
  • [x] API キーに名前フィールドを追加
  • [x] チャット ID がエージェント セッションで報告されるため、ページをリロードせずにチャット、TTS、その他のアクションを再生成できるようになりました。
