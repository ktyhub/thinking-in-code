pulsar v4.2.1

#パルサーv4.2.1

2026-04-27

ライブラリの更新

  • [修正][秒] BouncyCastle を 1.84 (CVE-2026-5588、CVE-2026-0636) にアップグレードします (#25569)
  • [修正][秒] CVE-2026-2332 (#25527) に対処するために Jetty をアップグレードします
  • [修正][秒] Jetty をアップグレードして CVE-2026-5795 (#25532) に対処します
  • [修正][秒] CVE-2026-40490 (#25546) に対処するために、async-http-client 2.14.5 にアップグレードします。
  • [修正][秒] CVE (#25399) に対処するために Netty 4.1.132.Final にアップグレードします
  • [修正][秒] CVE-2026-34477、CVE-2026-34478、CVE-2026-34480、CVE-2026-34481 に対処するために、log4j を 2.25.4 にアップグレードします。
  • [修正] Jetty を 12.1.6 にアップグレードして CVE-2026-1605 (#25485) を修正します

ブローカー

  • [修正][ブローカー] スキーマ非互換ログをエラーから警告レベルに変更 (#25483)
  • [修正][ブローカー] アンロードされた名前空間バンドルのバックログのクリアを修正 (#25272)
  • [修正][ブローカー] DEBUG への DrainingHashesTracker が見つからないエントリのログ レベルが低い (#25558)
  • [修正][ブローカー] タイムアウトしたプロデューサーの作成が再試行と競合するのを防ぐ (#25460)
  • [修正][ブローカー] メタデータ コマンドを使用した内部パルサー管理統計 (#25557)
  • [修正][ブローカー] 「[改善][ブローカー] ローカルホストへのフォールバックでアドバタイズされたアドレス解決を強化する (#25238)」 (#25523) を元に戻します
  • [修正][ブローカー] パブリッシュレート制限が無効になっている場合、プロデューサーのスロットルをすぐに解除します (#25502)
  • [修正][ブローカー]名前空間は空の場合もある replication_clusters ポリシーで作成できます (#25551)
  • [修正][管理者] 名前空間移行操作を残りの api で非同期にリファクタリングします (#25478)
  • [改善][ブローカー] コンシューマー書き込みのクローズに失敗した場合に接続を閉じる (#25520)
  • [改善][ブローカー] ModularLoadManagerImpl の名前空間バンドル宛先アフィニティに完全なバンドル名を使用する (#25518)

Client

  • [修正][client] スレッド セーフティを修正し、MessageCryptoBc キー管理をリファクタリングします (#25400)

パルサー IO とパルサー関数

  • [修正][io] #25198 の除外後に Kafka IO コネクタを使用して lz4 圧縮を復元する

その他

  • [改善][共通] キャッシュ検索時のロック競合を減らすために TopicName.get() を最適化します (#25367)
  • [改善][ブローカー] TopicName コンストラクターのパフォーマンスを改善 (#24463)

テストと CI

  • [修正][ci] 既存のブロックデバイスに対してのみ、discard_max_bytes が 0 に設定されていることを確認します (#25510)
  • [修正][テスト] SameAuthParamsLookupAutoClusterFailoverTest フェーズのタイムアウトを延長 (#25563)
  • [修正][テスト]不安定な BrokerRegistryIntegrationTest ポート バインディング競合を修正 (#25463)
  • [修正][テスト]不安定な ExtensibleLoadManagerImpl client 再接続テストを修正: PulsarClientException$AlreadyClosedException: Client はすでに閉じられています (#25509)
  • [修正][テスト]不安定な ExtensibleLoadManagerTest.startBroker タイムアウトを修正 (#25500)
  • [修正][テスト] 元帳ロールオーバーによる不安定な OffloadPrefixTest.testPositionOnEdgeOfLedger レースを修正 (#25561)
  • [修正][テスト] 不安定な ServerCnxTest.testCreateProducerTimeoutThenCreateSameNamedProducerShouldFail を修正 (#25497)
  • [修正][テスト] 不安定な testLoadBalancerServiceUnitTableViewSyncer を修正 (#25427)
  • [修正][テスト] Flaky SameAuthParamsLookupAutoClusterFailoverTest (#25566)
  • [修正][テスト] PublishRateLimiterTest セットアップで EventLoop を再作成する (#25560)
  • [修正][テスト] BrokerRegistryIntegrationTest ブローカー終了しきい値を緩和 (#25562)
  • [改善][ci]tune-runner-vm およびクリーンディスク アクションのクリーンアップ (#25444)
  • [クリーンアップ][ci] ドキュメント ラベル ボットを削除 (#25469)
  • [クリーンアップ][ci] すぐにテストできるラベルの適用を削除 (#25470)
  • [クリーンアップ][ビルド] バージョンを 4.2.1-SNAPSHOT に変更
  • [修正][ビルド][ブランチ-4.2] 正しい Jetty ee8 BOM 座標を使用する
  • [改善][ci] ssh アクセス アクションのバックポート修正

完全なリストについては、完全な changelog を確認してください。
