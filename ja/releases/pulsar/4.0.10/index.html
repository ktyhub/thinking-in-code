#パルサーv4.0.10

2026-04-27

アップグレードのお知らせ

このリリースでは、Jetty 9.4.x (#25534) のいくつかの高重大度 CVE に対処するために、Jetty を 9.4.x から 12.1.8 にアップグレードします。背景と議論については、開発リスト スレッド を参照してください。

このアップグレードでは、次の重大な変更が導入されます。

  1. AdditionalServlet インターフェイスの変更。 org.apache.pulsar.broker.web.plugin.servlet.AdditionalServlet インターフェイスは Jetty 9 org.eclipse.jetty.servlet.ServletHolder クラスに直接結合されました。この結合は削除されたため、このプラグイン API の外部実装を更新する必要があります。

  2. Athenz 認証には Java 17 以降が必要です。 pulsar-client-auth-athenz は Jetty に依存するようになったため、Java 17 以降が必要です。 Pulsar Client および Pulsar Admin client 自体は、Java 8+ との互換性を維持します。

  3. Prometheus メトリクス プロバイダー クラスの再配置。 BookKeeper および ZooKeeper のデフォルトの Prometheus メトリクス プロバイダー クラスは、以前のデフォルトが Jetty 9.4.x に依存していたため、置き換えられました。導入環境で以前のデフォルト構成ファイルを使用している場合は、次の設定を更新します。

    |設定ファイル |設定 |古い値 |新しい価値 | | --- | --- | --- | --- | | bookkeeper.conf | statsProviderClass | org.apache.bookkeeper.stats.prometheus.PrometheusMetricsProvider | org.apache.pulsar.metrics.prometheus.bookkeeper.PrometheusMetricsProvider | | zookeeper.conf | metricsProvider.className | org.apache.zookeeper.metrics.prometheus.PrometheusMetricsProvider | org.apache.pulsar.metrics.prometheus.zookeeper.PrometheusMetricsProvider |

バージョン 4.6.0 より前の Apache Pulsar Helm チャートのユーザーは、bookie.configData.statsProviderClass キーを org.apache.pulsar.metrics.prometheus.bookkeeper.PrometheusMetricsProvider に設定する必要があります。

bookie:
  configData:
    statsProviderClass: "org.apache.pulsar.metrics.prometheus.bookkeeper.PrometheusMetricsProvider"
