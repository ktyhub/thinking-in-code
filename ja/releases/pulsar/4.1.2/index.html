#パルサーv4.1.2

2025-11-17

ライブラリの更新

  • [修正] gRPC を 1.75.0 に更新 (#24813)
  • [改善][その他] Netty を 4.1.128.Final にアップグレード (#24911)
  • [改善] Alpine ベース イメージを 3.22 バージョン (#24840) にアップグレードします
  • [改善][ml] Oxia client を 0.7.0 (#24824) にアップグレードします
  • [修正][秒] tomcat-embed-core と derby の除外を追加し、CVE を修復するために mina-core をオーバーライドしました (#24949)
  • [修正][秒] io.vertx:vertx-web を 4.5.10 から 4.5.22 にバンプ (#24889)
  • [修正][秒] CVE を修復するために commons-beanutils と commons-configuration2 をオーバーライドします (#24936)
  • [修正][秒] kinesis-kpl-shaded で kafka-clients をオーバーライドして、CVE-2024-31141 および CVE-2025-27817 (#24935) を修正します
  • [修正][秒] nimbus-jose-jwt をオーバーライドして CVE-2023-52428 および CVE-2025-53864 (#24937) を修正します
  • [修正][秒] Hbase バージョンを 2.6.3-hadoop3 に更新し、CVE を修正するために hbase-client から Avro を除外します (#24953)
  • [修正][秒] CVE-2025-8916 (#24923) を修正するために、BouncyCastle FIPS を 2.0.10 にアップグレードします。
  • [修正][秒] hadoop3 バージョンを 3.4.0 から 3.4.1 にアップグレードします (#24950)
  • [修正][秒] CVE-2025-5115 (#24897) に対処するために Jetty を 9.4.58.v20250814 にアップグレードします
  • [修正][秒] Spring を 6.2.12 にアップグレードして CVE-2025-22233 および CVE-2025-41249 (#24903) を修正します
  • [改善][io] Debezium バージョンを 3.2.4.Final (#24896) にアップグレードします
  • [改善][ci] ubuntu-24.04 (#24841) を使用するように GitHub アクション ワークフローをアップグレードします。

ブローカー

  • [修正][ブローカー] トピックのロード時にトピック ポリシー サービスから断続的なエラーが発生することを許可します (#24829)
  • [修正][ブローカー] AvgShedder 比較エラー (#24954)
  • [修正][ブローカー] ポリシー キャッシュのクリーンアップ中の ConcurrentHashMap での再帰的な更新を回避します (#24939)
  • [修正][ブローカー] カーソル mdPosition がオープンレジャー上にある場合、BacklogMessageAge がリセットされない (#24915)
  • [修正][ブローカー] メタデータ サービスが再び利用可能になった後に LoadSheddingTask がスケジュールされていることを確認します (#24838)
  • [修正][ブローカー] ExtensibleLoadManager: ブローカーのメタデータを再登録するために SessionRepublished および Reconnected イベントを処理します (#24932)
  • [修正][ブローカー] さらなる有効期限をブロックする PersistentMessageExpiryMonitor のバグを修正 (#24941)
  • [修正][ブローカー] TransactionBufferDisable の getMaxReadPosition が最新のものを返すように修正 (#24898)
  • [修正][ブローカー] 間違ったトピック読み込み遅延メトリックとタイムアウトが尊重されない可能性がある問題を修正 (#24785)
  • [修正][ブローカー] 接続を閉じるときに競合状態によって引き起こされるスタック オーバーフローを修正しました (#24934)
  • [修正][ブローカー] 非永続ディスパッチャからコンシューマを削除するときに totalAvailablePermits が減らない問題を修正 (#24885)
  • [修正][ブローカー] 名前空間の削除や名前空間ポリシーの更新など、namespace.allowed_clusters 使用時の誤った動作を修正しました (#24860)
  • [修正][ブローカー] Flaky-test: ExtensibleLoadManagerImplTest.testDisableBroker (#24770)
  • [修正][ブローカー] Flaky-test: TopicTransactionBufferTest.testMessagePublishInOrder (#24826)
  • [修正][ブローカー] テナント/名前空間が登録されている場合にのみ ResourceGroup タスクを実行します (#24859)
  • [修正][ブローカー] レプリケーターが終了した場合にエントリの読み取りを再試行するのを停止します (#24880)
  • [修正][ブローカー] 存在しないトピックに対してトピック作成イベントを 1 回だけトリガーする (#24802)
  • [修正][ブローカー] NoSuchElementException を避けるために、remove の代わりに poll を使用します (#24933)
  • [修正][ブローカー]パーティション分割されたトピックが GC によって削除された後、孤立したスキーマとトピックレベルのポリシーが残る (#24971)
  • [修正][ブローカー]トランザクション バッファーのスナップショットを同時に取得すると、トランザクション メッセージが正常に送信されない (#24945)
  • [修正][管理者] ローカル ポリシーを設定すると、名前空間の作成時に渡された「バンドル数」が上書きされます (#24762)
  • [修正][ml] getNumberOfEntries が削除された台帳を指している可能性がある問題を修正 (#24852)
  • [修正][ml] カーソルが削除された台帳を指す原因となる台帳トリミングの競合を修正しました (#24855)
  • [修正][ml] PIP-430: MessageMetadata キャッシュの同時実行の問題を修正し、キャッシュを改善しました (#24836)
  • [修正] Oxia ベースのプロバイダーの getChildren('/') を修正しました (#24863)
  • [改善][ブローカー] 広告済みアドレスに絶対 FQDN を使用するためのテストを追加し、ブローカー ID から余分なドットを削除します (#24787)
  • [改善][ブローカー] アイドル状態のトピックの最終公開タイムスタンプをキャッシュして、ストレージの読み取りを削減します (#24825)
  • [改善][ブローカー] パーティション化されていないトピックで updatePartitionedTopic が呼び出されたときにエラーをログに記録しません (#24943)
  • [改善][ブローカー] ルックアップ結果の警告ログを最適化 (#24942)
  • [改善][ブローカー] PIP-434 パート 1: Netty チャネル設定 WRITE_BUFFER_WATER_MARK をパルサー設定に公開し、チャネルが書き込みできない場合に受信リクエストを一時停止します (#24423)
  • [改善][ブローカー] PIP-434 パート 2:channel.readable を直接変更する代わりに、ServerCnxThrottleTracker を使用します (#24799)
  • [改善][ブローカー] PIP-434: Broker.conf に設定を追加 (#24800)
  • [改善][ブローカー] イベントループシャットダウンの無駄な待機を避けるためにブローカーの終了時間を短縮します (#24895)
  • [改善][ブローカー] isServiceUnitActiveAsync を checkTopicNsOwnership に置き換えます (#24780)
  • [改善][ブローカー]スケジュールされたタスクに対して、scheduleAtFixedRate ではなく、scheduleAtFixedRateNonConcurrently を呼び出します (#24596)
  • [改善][ブローカー]クラスターの削除時に出力されるNamespaceServiceログを改善 (#24801)
  • [改善][ブローカー]期限切れのターゲット位置の場合、削除マークをスキップします… (#24881)
  • [修正][txn] TransactionBufferHandlerImpl#endTxn で txn がスタックする原因となる同時エラーを修正 (#23551)
  • [クリーンアップ][ブローカー] 未使用の構成 maxMessageSizeCheckIntervalInSeconds を削除します (#24958)
  • [feat][monitor] ML 書き込みレイテンシ ヒストグラムとエントリ サイズ ヒストグラムを OTel メトリクスとして追加 (#24815)
  • [feat][monitor] OTel メトリクスとしてパブリッシュ レイテンシー ヒストグラムを追加 (#24810)
  • [feat] PIP-442: CommandGetTopicsOfNamespace のメモリ制限を追加 (#24833)

Client

  • [修正][client] ClientBuilderに記述メソッドを追加 (#24728)
  • [修正][client] メソッド パラメータを含めるように getPartitionedTopicMetadata の重複排除を修正しました (#24965)
  • [修正][client] PartitionedTopicProducerStatsRecorderImpl の getPendingQueueSize を修正: NPE を回避し、集約を実装します (#24830)
  • [修正][client] PulsarAdmin の説明チェックを修正し、テストを追加 (#24734)
  • [修正][client] ServiceUrlProvider で使用される reloadLookUp メソッドのスレッド リークを修正 (#24794)
  • [修正][client] PIP-344 を使用しない古いブローカーでもパーティションの自動更新が機能するようにしました (#24822)
  • [改善][client] User-Agent ヘッダーへのカスタム説明の追加を許可 (#24729)
  • [改善][client] BinaryProtoLookupService の getTopicsUnderNamespace の重複排除 (#24962)
  • [改善][client] PIP-420: スキーマ ID 形式を更新します (#24798)
  • [改善][client]Pulsar client クロック設定の null チェックを追加 (#24848)
  • [feat][client] 複数の Pulsar Client インスタンス間でスレッド プールと DNS リゾルバー/キャッシュを共有するための PIP-234 の実装 (#24790)
  • [feat][client] PIP-234: スレッド使用量を削減するために PulsarAdmin の共有リソースをサポート (#24893)
  • [改善][client/broker] DnsResolverGroup を追加して、複数の PulsarClient インスタンス間で DNS キャッシュを共有します (#24784)
  • [修正] 信頼性の問題と誤った応答を引き起こす混合ルックアップ/パーティションメタデータリクエストを修正しました (#24832)

パルサー IO とパルサー関数

  • [改善][fn] ByteBufAllocator.DEFAULT の代わりに PulsarByteBufAllocator.DEFAULT を使用します (#24952)

テストと CI

  • [修正][ビルド] maven-source-plugin 3.3.1 を使用した Maven デプロイを修正 (#24811)
  • [修正][ビルド] gpg 署名の失敗の原因となった settings.xml 内の無効なプロファイルを削除します (#24812)
  • [修正][テスト] 丸めの不安定さを修正するために倍精度アサーションにデルタ許容値を追加 (#24972)
  • [修正][テスト] BacklogQuotaManagerTest.backlogsAgeMetricsNoPreciseWithoutBacklogQuota ハンドルが空の /メトリック スクレイピング (#24887)
  • [修正][テスト] 不安定な KeySharedSubscriptionBrokerCacheTest.testReplayQueueReadsGettingCached を修正 (#24955)
  • [修正][テスト] 不安定な LookupPropertiesTest.testConcurrentLookupProperties を修正 (#24854)
  • [修正][テスト] 不安定な NonPersistentTopicTest.testProducerRateLimit を修正 (#24951)
  • [修正][テスト]不安定な ReplicatorTest.testResumptionAfterBacklogRelaxed を修正 (#24904)
  • [修正][テスト] 不安定な SingleThreadNonConcurrentFixedRateSchedulerTest.testPeriodicTask cancel を修正 (#24823)
  • [修正][テスト] サブスクリプションがシーク後にのみフェンスされることをカウントすることで、不安定な SubscriptionSeekTest.testSeekWillNotEncounteredFencedError を修正しました (#24865)
  • [修正][テスト] 無効なテストを修正 NonPersistentTopicTest.testProducerRateLimit (#24957)
  • [修正][テスト] 複数のテストにおける非決定的な JSON の順序付けを修正しました (#24821)
  • [修正][テスト] SchemaInfoTest の非決定的な順序付けを修正しました (#24969)
  • [修正][テスト] テスト ヘルパーの ResponseBody チェックを修正 (#24872)
  • [修正][テスト] ProtobufNativeSchemaTest.testSchema を順序に依存しないようにしました (#24805)
  • [修正][テスト] ProtobufSchemaTest.testParsingInfoProperty を順序に依存しないようにしました (#24807)
  • [修正][テスト] 測定を調整し、隣接する 2 秒の平均を使用することで、PublishRateLimiterOver消費Test を安定させます (#24864)
  • [修正][テスト] 空の台帳の削除と送信タイムアウトを回避するために、最初の公開後にフェンシングによって SequenceIdWithErrorTest を安定させます (#24861)
  • [修正][テスト] 非永続的なパブリッシャーのドロップを確実にトリガーすることで testMsgDropStat を安定させます (#24929)
