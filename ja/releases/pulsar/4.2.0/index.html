#パルサーv4.2.0

2026-04-01

承認された PIP

  • PIP-434: Netty チャネル設定 WRITE_BUFFER_WATER_MARK をパルサー設定に公開し、チャネルが書き込みできない場合は受信リクエストを一時停止します
  • PIP-437: メッセージ配信のためのきめ細かな固定遅延ポリシー
  • PIP-439: マネージド トランザクション ラッピングによるパルサー関数へのトランザクション サポートの追加
  • PIP-442: ブローカーとプロキシの CommandGetTopicsOfNamespace および CommandWatchTopicList のメモリ制限を追加
  • PIP-443: 新しいコードでの Netty リサイクラーの使用を停止する
  • PIP-444: ZK プレッシャーを緩和するための元帳削除のレート制限。
  • PIP-446: Pulsar Java Client でのネイティブ OpenTelemetry トレースのサポート
  • PIP-447: トピック メトリック用のカスタマイズ可能な Prometheus ラベル
  • PIP-452: プロパティを含む名前空間のカスタマイズ可能なトピック リスト
  • PIP-453: メタデータ ストアのスレッド モデルの改善
  • PIP-454: メタデータ ストア移行フレームワーク
  • PIP-464: SchemaType.JSON の従来の Jackson JsonSchema 形式を非推奨にする
