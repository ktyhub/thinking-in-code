#パルサーv4.2.4

2026-08-03

ライブラリの更新

  • [修正][ci] Sandboxed-trivy-action を承認済み SHA にアップグレード (#26169)
  • [改善][メタ] Oxia client を 0.9.4 にアップグレード (#26193)
  • [改善][ビルド] docker ベース イメージ Alpine を 3.24 (#26225) にアップグレードします
  • [改善][ビルド] スログを 0.10.0 (#26226) にアップグレードします
  • [改善][その他] Jetty を 12.1.11 にアップグレード (#26233)
  • [修正][秒][ブランチ-4.2] Hadoop を 3.5.0 にアップグレード (#26194)
  • [修正][秒][ブランチ-4.2] ジャクソンのバージョンを 2.18.9 にアップグレードします (#26186)
  • [修正][秒][ブランチ-4.2] Netty を 4.1.136.Final にアップグレードします (#26168)
  • [改善][監視][ブランチ-4.2] OpenTelemetry ライブラリをアップグレードします (#26182)

ブローカー

  • [修正][ブローカー] バケット addMessage 内の containsMessage の前にdeliveryAtをチェックする (#26230)
  • [修正][ブローカー] getEstimatedSizeSinceMarkDeletePosition スロー IllegalArgumentException を修正 (#26184)
  • [修正][ブローカー] スクレイピング時にリセットされるバケットの遅延メッセージ インデックス メトリクスを修正 (#26171)
  • [修正][ブローカー] 重複するバケットのスナップショットをトリミングする際の遅延メッセージ インデックス データ損失を修正しました (#26240)
  • [修正][ブローカー] ModularLoadManager ルックアップによって返される誤ったリスナー URL を修正 (#26245)
  • [修正][ブローカー] トピックの終わりで先読みがトリガーされた場合の Key_Shared 配信の停止を修正 (#26236)
  • [修正][ブローカー] PulsarMetadataEventSynchronizer でサイレントにドロップされた確認応答エラーを修正 (#26237)
  • [修正][ブローカー] ブローカーのシャットダウンを停止させる TableViewLoadDataStoreImpl クローズのデッドロックを修正 (#26243)
  • [修正][ブローカー] マーカーの公開前にレプリケートされたスナップショットが完了しないようにする (#26119)
  • [修正][ブローカー] パーティションの拡張が遅延配信バケットの状態を継承しないようにします (#26179)
  • [修正][ブローカー] 古い読み取り完了によってフェイルオーバー サブスクリプションが孤立するのを防止 (#26174)
  • [修正][ブローカー] 古いサービスユニットのコールバックがアクティブなルックアップジョブとクリーンアップジョブを削除しないようにします (#26146)
  • [修正][ブローカー] 古いトピックのアンロード クリーンアップによってアクティブなキャッシュ エントリが削除されないようにする (#26145)
  • [修正][ブローカー] サブスクリプション プロパティをカーソルから直接読み取ります (#26159)
  • [修正][ブローカー] parseMessageMetadata がスローするときに GetLastMessageId のエントリを解放します (#26089)
  • [修正][ブローカー] トランザクション バッファーの回復中にパブリッシュされたメッセージの最大読み取り位置コールバックをトリガーする (#26234)
  • [修正][ブローカー][ブランチ-4.2] ブローカーインターセプターがロードされるときの管理 API HTTP 400 FAIL_ON_TRAILING_TOKENS を修正しました (#26223)
  • [修正][ml] 同時終了後にtransformLedgerInfoコールバックが完了するときに台帳エントリ/サイズを保持する (#26228)
  • [修正][メタ] 最初の取得が失敗した場合に例外的に将来の handleMetadataEvent を完了します (#26199)
  • [修正][メタ] MetadataEvent オプションが null の場合の shouldIgnoreEvent の NPE を修正しました (#26200)
  • [修正][メタ] 再起動後に進まない RocksdbMetadataStore インスタンス ID を修正 (#26218)
  • [修正][メタ] AbstractMetadataStore の正しい完了ブランチでレコード取得操作統計を記録する (#26201)
  • [改善][ブローカー] 非アクティブなカーソルをチェックするときにシステム カーソルをスキップします。 (#26149)
  • [改善][ブローカー] トピックのロード時にログ内の非同期タスクをトレースします (#26163)
  • [改善][オフロード] S3 および Aliyun OSS ドライバーのオフロード ポリシーからの認証情報をサポート (#26232)
  • [修正][ブローカー] LightProto 移行後の BucketDelayeddeliveryTracker の回復を修正 (#26160)
  • [修正][ブローカー] 厳密ではない遅延メッセージの早期再生を防止 (#26188)
  • [修正][ml] 元帳を閉じるときに元帳のプロパティを保持する (#26227)
  • [改善][メタ] メタデータ ストア URI を介した Oxia MetadataStoreConfig のチューニングをサポート (#26150)

Client

  • [修正][client] ClientCnx でのルックアップ許可の二重解放、待機キューの枯渇、タイムアウト応答の競合を修正 (#26143)
  • [修正][client] キャンセルされたタイムアウトをスキップするように UnAckedMessageRedeliveryTracker を修正しました (#26043)
  • [修正][client] 複数トピックのバッチ ACK での unAckedMessageTracker クリーンアップを修正 (#26001)
  • [修正][client] pulsar-admin スキーマ出力で null 値を保持する (#26196)
  • [修正][client] client の ackSet をブローカーと同期して、ACK メッセージが DLQ に到達するのを停止します (#26135)

パルサー IO とパルサー関数

  • [修正][fn] Python ランタイムの転送ソース メッセージ プロパティ (#26191)
  • [修正][fn] 関数 GET info で inputSpecs ConsumerProperties を返す (#26217)

その他

  • [修正][メタデータ] Oxia メタデータ バックエンドでクリーンアップされない孤立した UR 親ノードを修正 (#26158)
  • [改善][その他][ブランチ-4.2] スログ用の CustomLog 構成を追加
  • [修正][その他][ブランチ-4.2] log4jパターンをOxia clientアップグレードによって引き込まれたslogと互換性のあるものにします

テストと CI

  • [修正][テスト] 不安定なテスト testCompactionPriority を修正 (#26198)
  • [改善][ci] trivy-action を Sandboxed-trivy-action に置き換えます (#25480)
  • [修正][テスト][ブランチ-4.2] ManagedCursorTest コンパイルを修正 (#26221)
  • [fix][ci][branch-4.2] Etcd の testMarkReplicatedDeletesEmptyParentNodes をスキップします
  • [修正][ci][branch-4.2] Otel ライブラリのアップグレード後の OpenTelemetrySanityTest を修正

完全なリストについては、完全な changelog を確認してください。
