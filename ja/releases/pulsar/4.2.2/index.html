#パルサーv4.2.2

2026-06-08

ライブラリの更新

  • [修正][秒] org.asynchttpclient:async-http-client を 2.14.5 から 2.15.0 にバンプ (#25818)
  • [修正][秒] CVE-2026-45205 (#25844) に対処するために、commons-configuration2 を 2.15.0 にアップグレードします。
  • [修正][秒] CVE (#25670) に対処するために、Netty を 4.1.133.Final にアップグレードします。
  • [改善][その他] Netty を 4.1.134 にアップグレード (#25870)
  • [修正][秒] Netty を 4.1.135.Final にアップグレードして、いくつかの CVE (#25918) に対処します。
  • [修正][秒] CVE-2026-43869 (#25744) に対処するために、thrift を 0.23.0 にアップグレードします。
  • [修正][秒] CVE-2026-6860 (#25737) に対処するために、vert.x を 4.5.25 にアップグレードします。
  • [修正][秒] CVE-2026-6860 (#25745) に対処するために、vertx を 4.5.27 にアップグレードします。
  • [改善][その他] vert.x を 4.5.28 にアップグレード (#25924)
  • [改善][ビルド] kotlin-stdlib オーバーライドを削除します。 okhttp3 5.3.2 および okio 3.17.0 (#25855) をアップグレードします
  • [改善][ビルド] org.apache.kerby:kerb-simplekdc を 1.1.1 から 2.1.1 にアップグレードします (#25785)
  • [改善][その他] Jetty を 12.1.9 にアップグレード (#25752)
  • [改善][その他] Jetty を 12.1.10 にアップグレード (#25943)
  • [改善][その他] カフェインを 3.2.4 にアップグレード (#25663)

ブローカー

  • [修正][ブローカー] BookkeeperSchemaStorage での初期スキーマの同時作成時に孤立台帳をクリーンアップ (#25514)
  • [修正][ブローカー] BacklogQuotaManager の保留中の ACK クリーンアップ ギャップを閉じる (#25624)
  • [修正][ブローカー] ConcurrentLongHashMap が ArrayIndexOutOfBoundsException をスローする (#25644)
  • [修正][ブローカー] トラッカー コード内の 2 つの競合状態と、NoSuchElementException で失敗した InMemoryDelayeddeliveryTracker のロジック バグを修正します (#25681)
  • [修正][ブローカー] RemoveAllUpTo が保留中の ACK を削除するときに未確認のカウンターを減らす (#25581)
  • [修正][ブローカー] 圧縮カーソルのリセットによりマーク削除プロパティが失われる可能性がある問題を修正 (#25862)
  • [修正][ブローカー] ManagedLedgerImpl.advanceCursorsIfNecessary() メソッドが競合状態で非永続カーソル プロパティを失う可能性がある問題を修正 (#25796)
  • [修正][ブローカー] トピックの圧縮中に削除されない非バッチの null 値メッセージを修正しました (#25817)
  • [修正][ブローカー] PersistentMessageExpiryMonitor findEntryComplete() メソッドが競合状態でマーク削除プロパティを失う可能性がある問題を修正 (#25803)
  • [修正][ブローカー] 合計の累積のために LongAdder を DoubleAdder に置き換えることにより、DataSketchessummaryLogger の精度損失を修正しました (#25594)
  • [修正][ブローカー] ロックを保持せずにCondition.signalAllが呼び出されるPulsarService.closeAsyncを修正しました(#25777)
  • [修正][ブローカー] redeliverUnacknowledgedMessages での保留中の ACK 削除の競合を修正 (#25589)
  • [修正][ブローカー] SharedConsumerAssignor 許可追跡でスタックしたチャンクを修正 (#25620)
  • [修正][ブローカー] マージ ブローカーの余分な構成のオフロード (#25736)
  • [修正][ブローカー] 保留中の ACK クリーンアップを選択したマーク削除コールバックに移動 (#25592)
  • [修正][ブローカー] 競合状態により内部トピックで永続的なバックログが発生する (#25572)
  • [修正][ブローカー] フェンスで囲まれた/終了トピックでのバックログクォータの削除をスキップ (#25684)
  • [修正][ブローカー] 追加の構成に効果的なオフロード ポリシーを使用する (#25781)
  • [修正][ブローカー] 孤立したスキーマ台帳のクリーンアップを待ってから再試行します (#25579)
  • [fix][broker][fix][broker]クラスターが一方向レプリケーションのターゲットクラスターである場合、レプリケーション統計が空になる (#25583)
  • [修正][ブローカー]エントリの読み取りに失敗したため、レプリケーションが停止します (#25625)
  • [修正][bk] ポリシークラスが一致しない場合の IsolatedBookieEnsemblePlacementPolicy の NPE を修正しました (#25825)
  • [修正][メタ] PulsarZooKeeperClient の非同期 addWatch コールバックの再試行動作を修正 (#25913)
  • [修正][メタ] PulsarZooKeeperClient.clientCreator の ZooKeeper セッション再接続競合状態を修正 (#25910)
  • [改善][ブローカー] namespaceBundle 検証を最適化し、名前空間全体のアンロード中のシングルスレッドの 100% CPU を修正しました (#25626)
  • [改善][ブローカー] 終了後の古いレプリケーターの保留中の読み取りを防止します (#25767)
  • [改善][オフロード] 自動オフロード トリガーを結合して、再試行ループと台帳スキャンを削減します (#25793)
  • [修正][ブローカー][ブランチ-4.2] Txn 保留中確認トピックの URL エンコード サブ名 #25727 (#25728)

Client

  • [修正][client] クラスローダーなしでスキーマをデコードするときに Avro 論理型変換を適用する (#25759)
  • [修正][client] ACK タイムアウト バックオフを使用してトピックのサブスクライブを解除するときに、ACK されていないメッセージをクリーンアップする (#25916)
  • [修正][client] エラーのためコンシューマーを閉じることができなかった問題を修正しました: パラメータのメモリサイズが負の値です (#25805)
  • [修正][client] ClientBuilder をシリアル化可能にする (#25730) (#25739)
  • [修正][client] 未確認のメッセージを削除するときに論理トピックと一致する (#25921)
  • [修正][client] FieldParser マップ値の等号を保持する (#25907)
  • [修正][client] ServiceUrlProvider の重複初期化を防止 (#25899)
  • [修正][client] SameAuthParamsLookupAutoClusterFailover のリカバリ時に上位インデックスの状態をリセットする (#25826)
  • [修正][client] 同時エンキュー/テイクに対するscaleReceiverQueueHintの安定化 (#25578)
  • [修正][client]スキーマを登録している状態のプロデューサーを閉じると、ブローカー側のプロデューサー ハンドル リークが発生する (#25725)
  • [改善][client] ackReceiptEnabled=false の場合、送信失敗時の個別/バッチインデックス ACK のベストエフォート再試行 (#25525)
  • [改善][client] マルチトピックコンシューマーでトピックが削除されたときに未確認のメッセージトラッカーをクリーンアップする (#25923)
  • [改善][client] AuthenticationOAuth2 の tls_client_auth を実装 (#25538)
  • [改善][client] メッセージ損失の危険性がある場合、ログレベルをエラーに調整します (#25854)

  • [修正][fn] ユーザー例外後に続行するように Go 関数ランタイムを修正し、neg-ack テストを追加しました (#25867)
  • [修正][fn] WorkerUtils.createExclusiveProducerWithRetry の作成タイムアウト時の孤立した排他的プロデューサーを修正しました (#25942)

  • [改善][関数] Function Worker で Kubernetes サービス ドメイン サフィックスをカスタマイズできるようにします (#25872)
