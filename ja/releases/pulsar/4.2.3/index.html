#パルサーv4.2.3

2026-07-06

バックポートされた PIP

  • [feat][pip] PIP-469: レガシー対応トピック ポリシー バックエンド ルーティングおよびメタデータ ストア トピック ポリシー (#25547)

ライブラリの更新

  • [修正][秒] /pulsar-function-go で github.com/go-jose/go-jose/v4 を 4.1.3 から 4.1.4 にバンプします (#26142)
  • [修正][秒] jline を 4.2.1 に、picocli を 4.7.7 にアップグレードし、未使用の jline2 を削除します (#26068)
  • [修正][秒] pulsar-function-go で pulsar-client-go を v0.20.0 にアップグレードし、CVE にも対応します (#26140)
  • [改善][fn] pulsar-client-python を 3.12.0 にアップグレードします (#26033)
  • [改善][fn] pulsar-client-python を 3.13.0 にアップグレードします (#26139)
  • [改善][その他] Apache Commons ライブラリと Apache Http コンポーネントをアップグレードします (#25963)
  • [修正][秒][ブランチ-4.2] ジャクソンのバージョンを 2.18.8 にアップグレードします (#26099)
  • [改善][メタ] Oxia client を 0.8.0 にアップグレード (#25964)
  • [修正][ビルド][ブランチ-4.2] docker/setup-qemu-action を v4.1.0 にアップグレードします。

ブローカー

  • [修正][ブローカー] サブスクライブ時に移行された非永続トピックにコンシューマーをアタッチしないようにします (#26075)
  • [修正][ブローカー] 移行されたプロデューサー/コンシューマーをリダイレクトするときに IO スレッドで読み取られるメタデータをブロックしないようにします (#26051)
  • [修正][ブローカー] バンドルごとのメタデータ読み取りでのバンドル スループット ルックアップのブロックを回避します (#26054)
  • [修正][ブローカー] 遅延配信トラッカーのクローズ時にディスパッチャのクローズ パスをブロックしないようにします (#26053)
  • [修正][ブローカー] 閉じているトピックポリシーリーダーが同時キャッシュ初期化リロードを中止させないようにします (#26132)
  • [修正][ブローカー] スタックまたは中止されたトピック ポリシー キャッシュ初期化によって名前空間のトピックがアンロード可能にならないようにします (#26025)
  • [修正][ブローカー] ロード バランサーの構成ミスに対して、SimpleLoadManagerImpl にフォールバックするのではなくフェイルファスト (#26031)
  • [修正][ブローカー] 圧縮された読み取りが永久にスタックしたり、カーソル マークの削除によりメッセージが失われる可能性がある問題を修正しました (#25998)
  • [修正][ブローカー] 圧縮の進行中にトピック/名前空間の強制削除がハングまたは失敗する問題を修正 (#26016)
  • [修正][ブローカー] コンパクション リーダーの再接続が停止したときにトピック/名前空間の強制削除が依然としてハングする問題を修正しました (#26026)
  • [修正][ブローカー] リモート クラスターへの公開に失敗した後に地理レプリケーションがスタックする問題を修正 (#26002)
  • [修正][ブローカー] カーソルの巻き戻しが実行中の読み取りをスキップするときのレプリケーションの停止を修正しました (#26106)
  • [修正][ブローカー] レート リミッター調整でスタックするレプリケータを修正し、デフォルトの読み取りパスの readBatchSize/maxReadSizeBytes を尊重します (#26005)
  • [修正][ブローカー] 不安定なテストを引き起こす ServiceUnitStateTableViewSyncer のテーブルビューの相違を修正 (#25946)
  • [修正][ブローカー] 初期化失敗後にトピック ポリシーの更新を転送する (#26110)
  • [修正][ブローカー] 空のキューに対して BucketDelayeddeliveryTracker.nextdeliveryTime をガードする (#26080)
  • [修正][ブローカー] サブスクライブ レート制限により圧縮が停止し、強制削除がブロックされるのを防ぎます (#26015)
  • [修正][ブローカー] バッファリング リスナー ラッパーとのトピック ポリシーの初期化競合を防止します (#26044)
  • [修正][ブローカー] トピック ポリシー更新パスからメッセージの有効期限チェックを実行します (#26040)
  • [修正][ブローカー] トピック順エグゼキューターでトピック ポリシー通知を実行する (#26042)
  • [修正][ブローカー] レプリケーションがまだアクティブな場合、トピック GC をトリガーしない (#25915)
  • [修正][メタ] 選出サイクルでリーダーの値を保持し、リーダーの読み取りを権限のあるものにします (#26000)
  • [修正][メタ] メタデータ ストア リスナー スレッドから台帳不足レプリケーション通知コールバックを実行する (#26065)
  • [改善][ブローカー] ループでエントリバイトを合計することでディスパッチパフォーマンスを向上させます (#26055)
  • [改善][ブローカー] 非永続トピックのロードでトピック ポリシーをロードし、ポリシーのリプレイをゲートします (#26134)
  • [改善][ブローカー] レジャーの削除時に孤立したバケットのスナップショットをトリミング (#25984)
  • [feat][broker] トピック内部統計を介して管理対象台帳プロパティを公開 (#26079)
  • [feat][broker] PIP-469: レガシー対応トピック ポリシー バックエンド ルーティングおよびメタデータ ストア トピック ポリシー (#25707)
  • [修正][ブローカー] isDelayeddeliveryDeliverAtTimeStrict=true で停止する遅延メッセージを修正 (#26012)
  • [修正][ml] 進行中のマーカーをクリアするエビクション トリガー レースを修正 (#25988)
  • [修正][ml] recycling RangeCacheEntryWrapper のときに messageMetadataInitialized をリセット (#25987)

Client

  • [修正][client] Netty イベント ループ スレッドからフェイルオーバー正常性プローブを実行します (#26064)
  • [修正][client] DNS リゾルバーのクローズが失敗したときに、client のシャットダウンでイベント ループ スレッドがリークするのを防止します (#26045)

パルサー IO とパルサー関数

  • [修正][fn] FunctionMetaDataManager で exclusiveLeaderProducer を揮発性にする (#26046)
  • [修正][fn] ランタイムマネージャーの前にスケジューラーを停止するためのファンクションワーカーのシャットダウンを並べ替えます (#26136)

その他

  • [修正][プロキシ] コールド ブローカー キャッシュでプロキシ IO スレッドをブロックしないようにします (#26052)
  • [修正] 関数: コンシューマー イベント リスナー スレッドからワーカー リーダー選出を実行 (#26059)

テストと CI

  • [修正][テスト] 名前空間の強制削除を再試行して、TopicPoliciesTest.setupTestTopic をデフレークします (#25974)
  • [修正][テスト] 不安定な AuditorBookieTest.testBookieClusterRestart を修正 (#26122)
  • [修正][テスト] 初期化状態でチャネル トピックを再提供することで、不安定な ExtensibleLoadManagerImplTest を修正しました (#25976)
  • [修正][テスト] ウェッジされたチャネルの所有権を回復することで、不安定な ExtensibleLoadManagerImplTest.initializeState を修正しました (#25977)
  • [修正][テスト] 同時実行の Mockito スタブによって引き起こされる不安定な PersistentTopicsTest セットアップを修正 (#26083)
  • [修正][テスト] 不安定な SchemaServiceTest.testSchemaRegistryMetrics を修正 (#25645)
  • [修正][テスト] 不安定な testPrepareInitPoliciesCacheAsyncThrowExceptionAfterCreateReader を修正 (#26049)
  • [修正][テスト] SameAuthParamsLookupAutoClusterFailoverTest のタイミングの影響を軽減 (#25675)
  • [修正][テスト] 呼び出し元が提供するエグゼキューターで makeReadEntryProbFail の errorOrNot を実行する (#26123)
  • [改善][テスト]テストを追加: test/testTopicPartitionCannotBeCreatedAfterTopicDeleted (#26038)
  • [修正][テスト][ブランチ 4.2] ConfigurationDataUtilsTest を Jackson 2.18.8 InetSocketAddress 逆シリアル化に適応させる

完全なリストについては、完全な changelog を確認してください。
