#パルサーv4.1.3

2026-02-19

ライブラリの更新

  • [改善][ブローカー] ブックキーパーを 4.17.3 にアップグレード (#25166)
  • [修正][秒] /pulsar-common の .yawk.lz4:lz4-java を 1.9.0 から 1.10.1 にバンプします (#25045)
  • [修正][秒] org.apache.solr:solr-core を /pulsar-io/solr の 9.8.0 から 9.10.1 にバンプします (#25175)
  • [修正][秒] コモンズコレクションの依存関係を削除 (#25024)
  • [修正][秒] org.lz4:lz4-java を除外し、at.yawk.lz4-java で標準化して CVE-2025-12183 および CVE-2025-66566 (#25198) を修正します
  • [修正][秒] CVE-2024-29371 (#25095) に対処するために、jose4j を 0.9.6 にアップグレードします。
  • [修正][秒] CVE-2025-68161 (#25102) に対処するために、log4j を 2.25.3 にアップグレードします。
  • [修正][秒] Netty を 4.1.130.Final にアップグレード (#25078)
  • [修正][秒] CVE-2025-9624 (#25206) を修正するには、OpenSearch を 2.19.4 にアップグレードします。
  • [修正][秒] CVE-2026-1002 (#25152) に対処するために vertx をアップグレードします。
  • [修正][テスト] docker-java を 3.7.0 にアップグレードします (#25209)
  • [改善][io] Debezium バージョンを 3.2.5.Final (#25029) にアップグレードします
  • [改善][モニター] OpenTelemetry を 1.56.0 に、Otel 計装を 2.21.0 に、Otel semconv を 1.37.0 にアップグレードします (#24994)
  • [改善][その他] Snappy バージョンを 1.1.10.8 にアップグレード (#25182)
  • [feat][meta] oxia バージョンを 0.7.2 にアップグレード (#24976)
  • [修正] gson を 2.13.2 にアップグレード (#25022)
  • [改善] Apache Commons ライブラリのバージョンをアップグレード (#24983)
  • [改善] カフェインを 3.2.3 にアップグレード (#24984)
  • [改善] Log4j2 を 2.25.2 に、slf4j を 2.0.17 にアップグレード (#24985)
  • [改善] Netty を 4.1.131.Final にアップグレード (#25232)
  • [修正][秒] /pulsar-function-go で github.com/dvsekhvalnov/jose2go を 1.6.0 から 1.7.0 にバンプします (#24987)
