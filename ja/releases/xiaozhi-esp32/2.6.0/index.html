#xiaozhi-esp32 v2.6.0

何が変わったのか

  • fix(ci): https://github.com/78/xiaozhi-esp32/pull/2303 の @78 によるリリース ID によってドラフト リリースを検索し、アセットを検証します。
  • FoloToy AI Passport の複数行チャット メッセージを有効にする by @Shinku-Chen (https://github.com/78/xiaozhi-esp32/pull/2304)
  • fix(mcp): https://github.com/78/xiaozhi-esp32/pull/2305 の @Aldenshile による JSON-RPC エラー メッセージをエスケープ
  • 修正: улучbolение русского перевода (ru-RU) by @Rafza7 (https://github.com/78/xiaozhi-esp32/pull/2306)
  • 機能: https://github.com/78/xiaozhi-esp32/pull/2315 の @78 による 5 秒間のチャット ヒントでスタートアップ ウェイク ワードを表示します。
  • 修正 (オーディオ): https://github.com/78/xiaozhi-esp32/pull/2321 の @78 によるスロバキア語音声プロンプトを更新
  • 修正(アセット): スタンドアロン アセット パッカーで UTF-8 を使用 (https://github.com/78/xiaozhi-esp32/pull/2326 の @xiajiahang により)
  • feat(otto): https://github.com/78/xiaozhi-esp32/pull/2328 の @txp666 により、GIF 絵文字コンポーネントを v1.4.0 に更新
  • 偉業 (ボード): Seeed reSpeaker XVF3800 と XIAO ESP32-S3 による Flex サポートを追加 (https://github.com/78/xiaozhi-esp32/pull/2325 の @GreenShadeZhang により)
  • 修正(kconfig): https://github.com/78/xiaozhi-esp32/pull/2329 の @PG2047 による Waveshare ESP32-S3-Touch-AMOLED-2.16 で USE_DEVICE_AEC を許可
  • 修正(axp2101): https://github.com/78/xiaozhi-esp32/pull/2330 の @sylarcao-cmd によってダイ温度を 0x3C/0x3D から読み取る
  • fix(emote_display): https://github.com/78/xiaozhi-esp32/pull/2331 の @sylarcao-cmd によるすべてのパスでのフラッシュの完了を報告する
  • 修正(ボード): https://github.com/78/xiaozhi-esp32/pull/2333 の @sylarcao-cmd による CONFIG_NEWLIB_NANO_FORMAT での 64 ビット printf 変換を回避
  • feat(表示): SetEmotion は、感情が https://github.com/78/xiaozhi-esp32/pull/2332 の @sylarcao-cmd によって設定されたかどうかを報告します。
  • 修正 (emote_display): StopAnimDialog と InsertAnimDialog が https://github.com/78/xiaozhi-esp32/pull/2335 の @sylarcao-cmd によって反転ブール値を返す
  • 修正: PA_CTRL を有効にして ESP32-S3-Touch-LCD-3.5 でオーディオを復元する (https://github.com/78/xiaozhi-esp32/pull/2341 の @javen13 により)
  • 修正: https://github.com/78/xiaozhi-esp32/pull/2342 の @javen13 により ESP32-S3-Touch-LCD-3.5B で PA_CTRL を有効にしました
  • https://github.com/78/xiaozhi-esp32/pull/2343 の @Shinku-Chen によるボード所有のタイマーから AI パスポートのアイドル ステージを駆動します
  • ドキュメント: https://github.com/78/xiaozhi-esp32/pull/2347 の @78 による ESP-IDF リリース/v6.1 ブランチを推奨します
  • ドキュメント: https://github.com/78/xiaozhi-esp32/pull/2346 の @monsterlag による Windows 応答ファイル ビルドの回避策を文書化します。
  • https://github.com/78/xiaozhi-esp32/pull/2263 の @goodtft により xiaozhi をサポートするすべての Quandong ESP32-S3-dev ファミリを追加
  • fix(power_save_timer): https://github.com/78/xiaozhi-esp32/pull/2336 の @sylarcao-cmd によって、1 秒に 1 回ではなく 1 回シャットダウンを要求します
  • https://github.com/78/xiaozhi-esp32/pull/2318 に @dzmitryNz によりベラルーシ語 (be-BY) 言語を追加
  • 修正(オーディオ): PA 供給電圧を BoxAudioCodec のボード パラメーターにします (https://github.com/78/xiaozhi-esp32/pull/2359 の @Dnsayhey により)
  • feat(board): 增加 CyberAI Vocat v2.0 / v2.1 by @cyberai8 in https://github.com/78/xiaozhi-esp32/pull/2348
  • 修正 (ウェーブシェア): AMOLED 2.16 のタッチ ミラーリングとコーナー インセットを修正 (https://github.com/78/xiaozhi-esp32/pull/2327 の @Dnsayhey による)
  • feat(ボード): https://github.com/78/xiaozhi-esp32/pull/2337 の @sylarcao-cmd による StackChan (CoreS3 + Feetech SCS サーボ ネック) を追加
  • 修正(表示): https://github.com/78/xiaozhi-esp32/pull/2364 の @sylarcao-cmd による起動エモーションがパックにない場合にフォールバックする
  • feat(mcp): https://github.com/78/xiaozhi-esp32/pull/2366 の @sylarcao-cmd によって登録されたツールの数とモデルが認識できるツールの数をログに記録します。
  • 功績: @javen13 による Waveshare ESP32-C6-Touch-LCD-2.8 サポートを https://github.com/78/xiaozhi-esp32/pull/2371 に追加
  • 功績: @javen13 による Waveshare ESP32-C5-Touch-LCD-3.5 サポートを https://github.com/78/xiaozhi-esp32/pull/2350 に追加
  • 功績: @Pen9uin-g による ESP32-C6-Touch-AMOLED-1.8-v2 サポートを https://github.com/78/xiaozhi-esp32/pull/2197 に追加
  • 功績: @javen13 による Waveshare ESP32-C5-Touch-LCD-2.8 サポートを https://github.com/78/xiaozhi-esp32/pull/2349 に追加
  • feat(m5stack): @rchurro による M5Stack Cardputer ボードを https://github.com/78/xiaozhi-esp32/pull/2372 に追加
  • 修正(カメラ): https://github.com/78/xiaozhi-esp32/pull/2373 の @zzuse により JPEG プレビューを表示サイズでデコードする
  • feat(otto-robot): https://github.com/78/xiaozhi-esp32/pull/2376 に @FlashCat-Jordan による GC2145 カメラのサポートを追加
  • ドキュメント (ボード): https://github.com/78/xiaozhi-esp32/pull/2381 の @pratikgx による Electron-bot および otto-robot README の画像パスを修正
  • 修正(otto-robot): https://github.com/78/xiaozhi-esp32/pull/2384 の @FlashCat-Jordan によるサーボ制御と WebSocket リモートの安定化
  • 修正 (otto-robot): https://github.com/78/xiaozhi-esp32/pull/2385 の @FlashCat-Jordan による GC2145 プレビューの向きを修正
  • feat(bread-compact-wifi-s3cam): https://github.com/78/xiaozhi-esp32/pull/2387 の @romoss314 により USB-JTAG 用に GPIO19/20 を解放するオプションを追加
  • 修正 (カメラ): JPEG 出力バッファーの推定を修正し、固定長マルチパート アップロード (800x600 コンピューター検証) に切り替える (https://github.com/78/xiaozhi-esp32/pull/2386 の @romoss314)
  • 偉業(m5stack): @hlym123 による CoreP4X サポートを https://github.com/78/xiaozhi-esp32/pull/2403 に追加
  • 修正: OTA URL を検証し、https://github.com/78/xiaozhi-esp32/pull/2408 の @78 によるレガシー ボード ビルド コマンドを保持する
  • PowerSaveTimer: https://github.com/78/xiaozhi-esp32/pull/2375 の @Vitalymt による設定からスリープ タイマーを読み取ります
  • fix(display): prevent overlapping WeChat emotions after startup by @78 in https://github.com/78/xiaozhi-esp32/pull/2410
  • https://github.com/78/xiaozhi-esp32/pull/2367 の @sylarcao-cmd によりデバイス ステータスでリセット理由を報告します
  • feat(otto-robot): https://github.com/78/xiaozhi-esp32/pull/2377 の @FlashCat-Jordan による USB からの充電状態とバッテリー電圧をレポートします。
  • 修正(資産): https://github.com/78/xiaozhi-esp32/pull/2411 の @78 によってネットワークを開始する前にローカル リソースをロードします
  • fix(build): https://github.com/78/xiaozhi-esp32/pull/2413 の @78 による GiGi モデル ディレクトリとボードごとの画面オプションの互換性を修正
  • 修正 (カメラ): https://github.com/78/xiaozhi-esp32/pull/2416 の @78 による、サイズの大きい HTTP 書き込み結果を拒否する
  • feat(protocol): add authenticated MQTT/UDP health checks by @78 in https://github.com/78/xiaozhi-esp32/pull/2398
  • https://github.com/78/xiaozhi-esp32/pull/2415 の @78 によるレガシー デバイス ツールとともに MCP 2026-07-28 をサポート
