xiaozhi-esp32 v2.0.5

パッチ 公開日2025年11月19日 出典78/xiaozhi-esp32 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#xiaozhi-esp32 v2.0.5

何が変わったのか

  • sensecap ウォッチャーを修正: メモリ リークを修正。 jpeg メモリ 16 ビット アライメント (https://github.com/78/xiaozhi-esp32/pull/1350 の @Wvirgil123 による) *https://github.com/78/xiaozhi-esp32/pull/1359 の @txp666 による公式 GIF マネージャーを使用して V2 パーティションを更新します
  • https://github.com/78/xiaozhi-esp32/pull/1330 の @0xD34D により Xorigin AiPi Lite のサポートを追加
  • otto は、https://github.com/78/xiaozhi-esp32/pull/1365 の @txp666 による新しいアクションと AI カスタム プログラミング アクション MCP ツールを追加します
  • https://github.com/78/xiaozhi-esp32/pull/1373 の @txp666 による発振設定の Otto コントローラー パラメーターを更新
  • 機能: https://github.com/78/xiaozhi-esp32/pull/1370 の @laride によるカメラ画像の回転をサポート
  • 雑務: https://github.com/78/xiaozhi-esp32/pull/1381 の @txp666 によって、idf_component.yml の txp666/otto-emoji-gif-component バージョンを 1.0.3 に更新します
  • https://github.com/78/xiaozhi-esp32/pull/1382 の @78 によってコンポーネントのバージョンを更新します
  • https://github.com/78/xiaozhi-esp32/pull/1387 の @laoshanxi による image_player のビルド修正
  • https://github.com/78/xiaozhi-esp32/pull/1378 の @DrayxR3X による Waveshare ESP32-S3-Touch-AMOLED-1.32 ボードのサポートを追加
  • https://github.com/78/xiaozhi-esp32/pull/1388 の @txp666 による Otto コントローラーのリファクタリング
  • https://github.com/78/xiaozhi-esp32/pull/1376 の @DrayxR3X による Waveshare ESP32-C6-Touch-AMOLED-1.32 ボードのサポートを追加
  • sp-esp32-s3-1.28-box by @Spotpear (https://github.com/78/xiaozhi-esp32/pull/1397)
  • ESP-P4-Function-EV-Board に SD カード、カメラ、フォントの初期化を追加 (https://github.com/78/xiaozhi-esp32/pull/1403 の @isthaison による)
  • board/m5stack-tab5: 新しいディスプレイ st7123 サポートを追加します。 @hlym123 著、https://github.com/78/xiaozhi-esp32/pull/1409
  • 修正: https://github.com/78/xiaozhi-esp32/pull/1423 の @laride による esp_afe_sr_iface_t コンパイル エラーを修正
  • https://github.com/78/xiaozhi-esp32/pull/1430 の @Y1hsiaochunnn による MIPI_DSI_PHY_CLK_SRC_DEFAULT コンパイル エラーを修正
  • https://github.com/78/xiaozhi-esp32/pull/1375 の @DrayxR3X による Waveshare ESP32-S3-ePaper-1.54 ボードのサポートを追加
  • https://github.com/78/xiaozhi-esp32/pull/1342 の @Y1hsiaochunnn による Waveshare ESP32-C6-Touch-AMOLED-2.06 サードパーティ ボードのサポートを追加
  • 修正: https://github.com/78/xiaozhi-esp32/pull/1432 の @VanillaNahida による Xiaozhi OGG 変換スクリプトにさらに詳細な説明を追加
  • 修正: https://github.com/78/xiaozhi-esp32/pull/1441 の @laride によるソフトウェア JPEG エンコードでの SRAM オーバーフローを回避
  • 功績: https://github.com/78/xiaozhi-esp32/pull/1442 の @laride による M5Stack Tab5 のカメラ サポートを追加
  • https://github.com/78/xiaozhi-esp32/pull/1444 の @txp666 による otto-robot の wechat-mini-program サポートを追加
  • https://github.com/78/xiaozhi-esp32/pull/1438 の @78 により LCD 表示レイアウトをグリッドからレイヤーに変更
  • 特技: https://github.com/78/xiaozhi-esp32/pull/1455 で @laride による JPEG 入力をサポート

新しい貢献者

  • @0xD34D が https://github.com/78/xiaozhi-esp32/pull/1330 に初めて投稿しました
  • @laoshanxi が https://github.com/78/xiaozhi-esp32/pull/1387 に初めて投稿しました
