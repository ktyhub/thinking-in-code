xiaozhi-esp32 v2.5.0

マイナー 公開日2026年9月10日 出典78/xiaozhi-esp32 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#xiaozhi-esp32 v2.5.0

何が変わったのか

  • 功績: @Father001 による wk esp32s3 開発ボードを https://github.com/78/xiaozhi-esp32/pull/2030 に追加
  • 修正: https://github.com/78/xiaozhi-esp32/pull/2175 の @78 による WDMomo CGC LCD 選択を復元
  • 内容: @shunian11 による waveshare esp32-c6-epaper-1.54 を https://github.com/78/xiaozhi-esp32/pull/2174 に追加
  • https://github.com/78/xiaozhi-esp32/pull/2180 に @ChanchalSakardeQH によるマラーティー語 (mr-IN) インド語サポートを追加
  • feat(m5stack-stopwatch): https://github.com/78/xiaozhi-esp32/pull/2189 の @suflanker によるディスプレイの明るさ制御をサポート
  • 修正(lichuang-dev): FT5x06 タッチ コントローラーが存在しない場合でもクラッシュしないようにしました (https://github.com/78/xiaozhi-esp32/pull/2204 の @sebastjanb により)
  • https://github.com/78/xiaozhi-esp32/pull/2191 の @78 によるストリーミング通知再生を追加
  • 修正(otto): https://github.com/78/xiaozhi-esp32/pull/2219 の @txp666 による GPIO ストラップからカメラボードを検出
  • 修正(df-k10): https://github.com/78/xiaozhi-esp32/pull/2222 の @max-power により、self.led_strip.scroll の長さを実際の LED 数にクランプします。
  • https://github.com/78/xiaozhi-esp32/pull/2225 の @max-power によるビッグエンディアン RGB565 センサー (RGB565X) のカメラ フォーマット ネゴシエーションを修正
  • fix(led): https://github.com/78/xiaozhi-esp32/pull/2221 の @max-power により、CircularStrip エフェクトの状態をインスタンスにスコープします
  • 修正(表示): https://github.com/78/xiaozhi-esp32/pull/2224 の @max-power による共有タイムスタンプではなく、分が変わるとアイドル クロックを再描画します
  • 修正(ビルド): Windows 上で ESP-IDF idf.py を正しく呼び出す (https://github.com/78/xiaozhi-esp32/pull/2211 の @zfkun)
  • xpowers: https://github.com/78/xiaozhi-esp32/pull/2237 の @JackHuang021 により I2cDevice に汎用 PMU ラッパーを追加
  • feat(board): 新增 FoloToy AI Passport (ESP32-C3) 板卡サポート by @Shinku-Chen in https://github.com/78/xiaozhi-esp32/pull/2236
  • 修正 (esp-hi): 4MB アセットを調整し、https://github.com/78/xiaozhi-esp32/pull/2238 の @Copilot を使用して @78 によって ST7735 の起動を復元します。
  • https://github.com/78/xiaozhi-esp32/pull/2185 に @epaper1 による xiaozhi 用の Maza AI ボードを追加
  • https://github.com/78/xiaozhi-esp32/pull/2243 に @mederix による pt-BR (ブラジルポルトガル語) ロケールを追加
  • 修正(ビルド): https://github.com/78/xiaozhi-esp32/pull/2240 の @QiuLsG による不一致のボード構成を拒否
  • https://github.com/78/xiaozhi-esp32/pull/2227 の @78 による M5Stack Tab5 ST7121/ST7123 ディスプレイ検出を修正
  • https://github.com/78/xiaozhi-esp32/pull/2021 の @3em0 によって、Otto MCP 応答を発信元の WebSocket client にバインドします
  • 特技(ディスプレイ): https://github.com/78/xiaozhi-esp32/pull/2195の@Vitalymtによる省電力モードでOLEDパネルをオフにします
  • 特技: https://github.com/78/xiaozhi-esp32/pull/1847 の @quantumnic により、文字列 max_length 検証と JSON-RPC エラー コードを MCP サーバーに追加します。
  • C++ 例外を無効にし、https://github.com/78/xiaozhi-esp32/pull/2246 の @78 によって ESP32-S31 ファームウェアを 4MB OTA スロットに保持します。
