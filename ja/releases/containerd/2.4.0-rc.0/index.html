コンテナー v2.4.0-rc.0

Containerd の v2.4.0-rc.0 リリースへようこそ! これはcontainerdのプレリリースです

containerd 2.4 は、サポート期間が短い通常の (非 LTS) リリースです。 新機能を早く採用したいユーザーを対象としています。リリースとしては 2.3 LTS に続く、リリース サイクルの時点で、以前は 非推奨の機能は削除される可能性があるため、このリリースには破壊的な機能が含まれる可能性があります。 変化。以下の注意事項を確認し、非推奨の警告をすべてクリアしてください。 アップグレード前の現在のバージョン。

安定性とより長いサポート ライフサイクルを優先するユーザーは、そのまま使用し続ける必要があります。 2.3 LTSリリース。

ハイライト

コンテナ ランタイム インターフェイス (CRI)

  • CRI でのイメージ マウントのマウント マネージャーを有効にする (#13542)
  • CRI プラグイン情報でサンドボックス イメージと CNI ディレクトリ構成をエクスポート (#13940)
  • デフォルトの runtimeFunctions.UserNamespacesHostNetwork を true に設定します (#13162)
  • 非 runc ランタイムに対する OCI ランタイム機能のイントロスペクションをサポート (#13504)

画像配布

  • 記述子 URL を取得するときに、機密性の高い認証ヘッダーを削除するための強化を適用します (#12889)
  • レジストリからリゾルバーへの HTTP 299 警告ヘッダーの伝播をサポート (#12698)
  • gzip レイヤーの解凍には klauspost/compress を使用します (#13560)

画像ストレージ

  • スナップショットが存在する場合でも、アンパック中にすべてのレイヤー コンテンツをフェッチする client オプションを追加 (#14126)
  • コンテンツ作成イベントにメディア タイプを含めます (#13833)
  • GC コレクション コンテキストへの前方参照を追加 (#13634)

ノード リソース インターフェイス (NRI)

  • コンテナーイメージ名、ダイジェスト、構成ダイジェストを NRI プラグインに公開 (#13960)
  • 非推奨の NRI インターフェイスを使用するプラグインに対して非推奨の警告を出力する (#13916)

ランタイム

  • Linux コンテナーの /proc/interrupts および CPU サーマル スロットルの sysfs パスをデフォルトでマスクする (#14090)
  • サンドボックス コントローラーの更新をシムに伝播する UpdateSandbox RPC を追加 (#14105)
  • コンテナーが明示的に停止された後、restart=always ポリシーを使用してコンテナーをすぐに再起動しないようにします (#13993)
  • トレース コンテキストを shim から runc およびフックに渡します (#14036)
  • シンボリックリンクされた /etc/passwd または /etc/group を含むコンテナ rootfs でのユーザーおよびグループの検索エラーを修正 (#13818)
  • Windows 名前付きパイプ サーバーとログ ストリーミング サポートを pkg/shim に実装 (#13948)
  • Windows ではデフォルトでログ スクラブを有効にします (#13837)
  • runc によるチェックポイント作成時に親チェックポイント ディレクトリの指定を許可 (#13699)

スナップショットを撮る人

  • EROFS スナップショット レイヤー コンテンツ キャッシュの Prometheus メトリクスを追加 (#13941)
  • erofs スナップショッターのウォーム イメージ キャッシュをサポート (#13813)
  • スナップショットの最大サイズ ラベルを追加 (#13520)

壊れる

  • CreateContainer のリストアを削除 (#13871)

非推奨

  • MountCapabilities ブートストラップ拡張機能を優先して、containerd.io/runtime-allow-mounts シム アノテーションを非推奨にする (#14002)
  • 非推奨の shim.Command を pkg から削除 (#13991)
  • runc オプションのタスク API アドレスおよびバージョン フィールドを非推奨にし、CreateTaskRequest (#13360) に移動します。

リリースバイナリを試して、問題があれば報告してください。 https://github.com/containerd/containerd/issues.

どのファイルをダウンロードすればよいですか?

  • containerd-<VERSION>-<OS>-<ARCH>.tar.gz: ✅推奨。 glibc 2.35 (Ubuntu 22.04) と動的にリンクされます。
  • containerd-static-<VERSION>-<OS>-<ARCH>.tar.gz: 静的にリンクされます。 glibc >= 2.35 を使用しない Linux ディストリビューションでの使用が想定されています。位置に依存しません。

通常、containerd に加えて、runc をインストールする必要があります。 および CNI プラグイン も公式サイトから入手できます。

Getting Started ドキュメントも参照してください。
