コンテナー v2.3.7

Containerd の v2.3.7 リリースへようこそ!

コンテナー 2.3 の 7 番目のパッチ リリースには、さまざまな修正が含まれています セキュリティパッチを含むアップデート。

セキュリティアップデート

  • コンテナ
    • CVE-2026-95839
    • GHSA-5p7c-hggf-c748
    • GHSA-8647-2jxj-p2rc
    • GHSA-hc94-p972-ch66

ハイライト

コンテナ ランタイム インターフェイス (CRI)

  • コンテナログファイルのシンボリックリンクをたどらないように強化を適用 (#14301)

画像配布

  • 強化を適用して、「..」パスコンポーネントを含む画像参照を拒否します (#14281)

ランタイム

  • デフォルトの seccomp プロファイルのホワイトリストのソケット ドメインに強化を適用 (#14248)

スナップショットを撮る人

  • アンパック中に画像注釈から ID マッピング ラベルをフィルタリングするために強化を適用します (#14261)

リリースバイナリを試して、問題があれば報告してください。 https://github.com/containerd/containerd/issues.

どのファイルをダウンロードすればよいですか?

  • containerd-<VERSION>-<OS>-<ARCH>.tar.gz: ✅推奨。 glibc 2.35 (Ubuntu 22.04) と動的にリンクされます。
  • containerd-static-<VERSION>-<OS>-<ARCH>.tar.gz: 静的にリンクされます。 glibc >= 2.35 を使用しない Linux ディストリビューションでの使用が想定されています。位置に依存しません。

通常、containerd に加えて、runc をインストールする必要があります。 および CNI プラグイン も公式サイトから入手できます。

はじめに ドキュメントも参照してください。
