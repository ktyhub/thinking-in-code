コンテナー v2.4.1

Containerd の v2.4.1 リリースへようこそ!

コンテナー 2.4 の最初のパッチ リリースには、さまざまな修正が含まれています セキュリティパッチを含むアップデートも含まれます。

セキュリティアップデート

  • コンテナ
    • CVE-2026-53493

ハイライト

コンテナ ランタイム インターフェイス (CRI)

  • 失敗したコンテナ開始クリーンアップによりタスクがリークされ、コンテナの削除が妨げられるバグを修正 (#14223)
  • SELinux の再ラベル付けがファイル システムでサポートされていない場合にコンテナの作成が失敗するバグを修正 (#14212)

画像配布

  • EOF に達した後にコンテンツの取得を再試行するとコンテンツのアップロードが失敗する問題を修正 (#14197)

スナップショットを撮る人

  • アンパック中に画像注釈から ID マッピング ラベルをフィルタリングするために強化を適用します (#14200)

CTR開発ツール

  • 「ctr イメージのエクスポート」で「-」に続く引数が削除されるバグを修正 (#14219)
  • コンテナーコマンドの引数が「ctr run」、「ctrcontainers create」、「ctr Tasks exec」、および「containerd oci-hook」のフラグとして解析されるバグを修正 (#14215)
  • ctr サブコマンドでカンマ区切りのフラグ値が誤って分割されるバグを修正 (#14188)

リリースバイナリを試して、問題があれば報告してください。 https://github.com/containerd/containerd/issues.

どのファイルをダウンロードすればよいですか?

  • containerd-<VERSION>-<OS>-<ARCH>.tar.gz: ✅推奨。 glibc 2.35 (Ubuntu 22.04) と動的にリンクされます。
  • containerd-static-<VERSION>-<OS>-<ARCH>.tar.gz: 静的にリンクされます。 glibc >= 2.35 を使用しない Linux ディストリビューションでの使用が想定されています。位置に依存しません。

通常、containerd に加えて、runc をインストールする必要があります。 および CNI プラグイン も公式サイトから入手できます。
