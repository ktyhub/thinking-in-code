表示 →
01 集める スケジュールされたジョブは、追跡されているすべてのリポジトリについて GitHub リリース API をクエリし、別の構成がされていない限り、ドラフト、空のボディ、およびプレリリースをスキップします。
02 ノーマライズ 各リリースは、プロジェクト、セマンティック バージョン、公開日、リリース チャネル、本文から抽出された 1 行の概要などの安定したレコードにまとめられます。
03 公開 メモはマークダウンとしてリポジトリに保存され、プッシュのたびに静的ページとしてレンダリングされるため、サイトは高速に保たれ、すべてのエントリは安定した URL を持ちます。
