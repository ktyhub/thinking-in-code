cline

20-Versionen indiziert · neueste desktop-v0.0.49 auf 26. Okt. 2026

cline/cline ↗

202620

10/26
desktop-v0.0.49 Release MT

A new Changes button in the session header shows the session's line counts and opens a pane listing the files changed in the last turn or across the whole session, with a diff of each.

 10/26
cli-v3.0.74 Release MT

Opening a task that's already running in another Cline app now attaches to that run instead of starting a second one that couldn't be stopped.

 10/26
v4.1.26 Patch MT

Cloud-Aufgaben: Einstellungen > API-Konfiguration hat ein Lokal | Cloud-Umschaltung, wenn Cloud-Sitzungen aktiviert sind. Cloud wählt das Cline-Modell aus, auf dem neue Cloud-Aufgaben ausgeführt werden, und speichert es getrennt von Ihren lokalen Modellen.

 10/26
v0.2.0 Minor MT

Wenn Sie eine Sitzung starten, für die bereits eine Ausführung ausgeführt wird, wird diese nun erneut mit der Live-Sitzung verbunden, anstatt deren Laufzeit zu ersetzen. Zuvor lief der ursprüngliche Lauf weiter, konnte aber nicht erreicht werden, und seine Transkript-Schreibvorgänge landeten auf …

 10/17
desktop-v0.0.48 Release MT

GPT-6-Modelle (wie gpt-6-sol und gpt-6.1-sol) funktionieren auf OpenAI- und Azure OpenAI-kompatiblen Endpunkten. Zuvor wurde jede Anfrage abgelehnt, weil Cline max_tokens statt max_completion_tokens gesendet hat

 10/17
cli-v3.0.73 Release MT

GPT-6 models (such as gpt-6-sol and gpt-6.1-sol) work on OpenAI and Azure OpenAI-compatible endpoints. Before, every request was rejected because Cline sent max_tokens instead of max_completion_tokens

 10/17
v0.0.95 Patch MT

OpenAI-compatible requests for GPT-6 models (gpt-6-sol, gpt-6.1-sol, gpt-6-1-sol, and later gpt-5 through gpt-9 ids) send max_completion_tokens instead of max_tokens, so OpenAI and Azure no longer reject them.

 10/16
desktop-v0.0.47 Release MT

Marktplatz-Plugins wie Goal werden erneut geladen. In 0.0.46 scheiterten sie mit „Modul „@cline/sdk“ konnte nicht gefunden werden“, da die gepackte App den Import der SDK-Paket-Plugins nicht enthielt

 10/16
cli-v3.0.72 Release MT

Plugins werden jetzt in einem Worker ausgeführt, statt direkt im Hub. Wenn dieser Build keine Plugins ausführen kann, sagt Cline dies in den cline-Konfigurationstools, den cline-Hub-Plugins und den Sitzungsstartwarnungen, anstatt sie stillschweigend auszuführen …

 10/16
v4.1.25 Patch MT

Cline Cloud-Sitzungen, schrittweise Einführung: Führen Sie eine Aufgabe in einer gehosteten Sandbox auf einem von Ihnen ausgewählten GitHub-Repo und -Zweig aus. Aktivieren Sie es in den Einstellungen.

 10/16
v0.0.94 Patch MT

Plugins now run only in worker threads (the default, CLINE_PLUGIN_MODE=worker) or in the subprocess sandbox (sandbox). The in_process mode is removed, along with its silent fallback.

 10/13
desktop-v0.0.46 Release MT

Eine neue Gliederung am linken Rand der Konversation listet jede von Ihnen gesendete Eingabeaufforderung auf. Bewegen Sie den Mauszeiger über eine Markierung, um eine Vorschau der Eingabeaufforderung anzuzeigen, und klicken Sie darauf, um dorthin zu springen

 10/13
cli-v3.0.71 Release MT

Plugins werden jetzt im Hub geladen und nicht in einem separaten Knoten- oder Bun-Prozess, sodass CLI keine JavaScript-Laufzeitumgebung mehr in Ihrem PATH benötigt, um Plugins auszuführen.

 10/13
v4.1.24 Patch MT

Da kein Modell ausgewählt wurde, verwenden die Anbieter Cline und OpenRouter jetzt Claude Sonnet 5.5. Für Cline ist dies das erste Modell in der empfohlenen Liste von Cline.

 10/13
v0.0.93 Patch MT

Plugins load in-process through one registry per process instead of a node/bun subprocess, so the compiled CLI and its hub no longer need a runtime on PATH, and plugins can use the Bun global under the Bun-built hub.

 10/08
desktop-v0.0.45 Release MT

SSH remotes start again. Since 0.0.38, connecting to an SSH environment failed with SyntaxError: Invalid character

 10/08
cli-v3.0.70 Release MT

Commit message generation and tasks with reasoning off no longer fail with a 400 error on GPT-6 Astra, GPT-6.1 Sol, Claude Fable 5 or Claude Opus 5.5

 10/08
v0.0.92 Patch MT

Die AI SDK bewegt sich zusammen zu einer Release-Linie: ai 7.0.120 und jedes @ai-sdk/-Paket auf @ai-sdk/provider-utils 5.0.50 (zuvor ai 7.0.79 mit nacheinander verschobenen Paketen).

 10/07
v4.1.23 Patch MT

Wenn die Antwort eines Modells ohne erkannten Abschlussgrund endet, fordert Cline es auf, einmal fortzufahren, anstatt die Antwort als abgeschlossen zu behandeln.

 10/07
v0.0.91 Patch MT

Responses that end with a missing or unrecognized finish reason are no longer treated as successful completions. AgentModelFinishReason gains unknown (the AI SDK adapter maps unified other and missing reasons to it…
