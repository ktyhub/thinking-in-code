🚀 Was ist neu in v1.13.3?

Unsere neueste Patch-Version, v1.13.3, konzentriert sich auf Stabilität und Korrektheit bei der Workflow-Ausführung, dem Streaming und dem Wissensabruf. Hier ein kurzer Überblick über die wichtigsten Updates:

🎬 Neue Funktionen

  • Workflow-Konfiguration: Variablenreferenzunterstützung für Modellparameter in LLM-, Question Classifier- und Variable Extractor-Knoten von @scdeng in #33082 hinzugefügt.

🛠️ Fehlerbehebungen

  • Streaming-Zuverlässigkeit: StreamsBroadcastChannel-Wiedergabe- und Parallelitätsprobleme wurden behoben, um die Bereitstellung von Frontend-/Backend-Ereignissen durch @QuantumGhost in #34030 und #34061 stabil zu halten.
  • Verhalten des Workflow-Editors: Eingefügte Knoten behalten die Schleifen-/Iterationsmetadaten bei und verhindern, dass HumanInput-Knoten von @majiayu000 und @hjlarry in #29983 und #34077 in ungültige Container eingefügt werden.
  • Laufzeitausführung: Die Logik zur Umwandlung von Eingabeaufforderungsnachrichten wurde wiederhergestellt und die max_retries=0-Behandlung für die Ausführung von HTTP-Anfragen durch den Executor durch @QuantumGhost, @fatelei und @kurokobo in #33666, #33619 und #33688 korrigiert.
  • Wissensabruf: Zitiermetadaten in Webantworten wurden beibehalten, Abstürze behoben, wenn Metadaten für Datensatzsymbole fehlten, die Trefferanzahl-Abfragefilterung korrigiert und indizierte Dokumentblockvorschauen von @Theysua, @copilot-swe-agent und @fatelei in #33778, #33907, #33757 und #33942 wiederhergestellt.

🔧 Unter der Haube

  • Patch-Stabilität: Diese Version priorisiert gezielte Korrekturen für das Workflow-Laufzeitverhalten, das Echtzeit-Streaming und die Benutzerfreundlichkeit der Wissensdatenbank für Teams, die ein Upgrade von v1.13.2 durchführen.

Upgrade-Anleitung

[!IMPORTANT] Das von Dify v1.13.3 verwendete Sandbox-Image erwartet die folgenden Pfade Python und Node.js. Wenn Sie ein Upgrade von einer älteren Docker Compose-Bereitstellung durchgeführt haben und bereits über docker/volumes/sandbox/conf/config.yaml verfügen, aktualisieren Sie es auf dem Hostcomputer:

python_path: /opt/python/bin/python3
nodejs_path: /usr/local/bin/node

Bearbeiten Sie die Datei nicht im Sandbox-Container. Das Verzeichnis docker/volumes/sandbox/conf wird als /conf in den Container eingebunden, sodass Hoständerungen nach dem Neustart des Containers bestehen bleiben.

Docker Bereitstellungen erstellen

  1. Sichern Sie Ihre angepasste docker-compose YAML-Datei (optional)

    cd docker
cp docker-compose.yaml docker-compose.yaml.$(date +%s).bak

  2. Holen Sie sich den neuesten Code aus der Hauptniederlassung

    git checkout main
git pull origin main

  3. Stoppen Sie den Dienst. Bitte im Verzeichnis docker ausführen

    docker compose down

  4. Daten sichern

    tar -cvf volumes-$(date +%s).tgz volumes

  5. Upgrade-Dienste

    docker compose up -d

Quellcode-Bereitstellungen

  1. Stoppen Sie den API-Server, den Worker und den Web-Frontend-Server.

  2. Holen Sie sich den neuesten Code aus dem Release-Zweig:

    git checkout 1.13.3

  3. Aktualisieren Sie die Python-Abhängigkeiten:

    cd api
uv sync

  4. Dann führen wir das Migrationsskript aus:

    uv run flask db upgrade

  5. Führen Sie abschließend den API-Server, den Worker und den Web-Frontend-Server erneut aus.
