Diese Seite ist maschinell übersetzt. Maßgeblich ist der englische Originaltext.

Browser-Verwendung 0.13.8

Was hat sich geändert?

  • Cerebras-Modell-IDs und Standard von @ryanl-cerebras in https://github.com/browser-use/browser-use/pull/5323 aktualisieren
  • Stellen Sie die Argumente des Anthropic-Tools wieder her, wenn das Modell seinen Aufruf als Text von @ElayGelbart in https://github.com/browser-use/browser-use/pull/5330 serialisiert
  • Dokumente: Defekten Profilsynchronisierungslink durch @Hardik180704 in https://github.com/browser-use/browser-use/pull/5332 ersetzen
  • fix(agent): Schütze last_action() vor leerer Aktionsliste von @itxaiohanglover in https://github.com/browser-use/browser-use/pull/5103
  • fix(agent): _inject_budget_warning vor ZeroDivisionError von @itxaiohanglover in https://github.com/browser-use/browser-use/pull/5107 schützen
  • fix(browser): Gibt den Pfad von „validate_user_data_dir“ zurück, wenn ein temporäres Verzeichnis von @itxaiohanglover in https://github.com/browser-use/browser-use/pull/5114 erstellt wird
  • Verwenden Sie UTF-8 für Agent-Datei-Schreibvorgänge von @Ghraven in https://github.com/browser-use/browser-use/pull/5309
  • fix(dom): Klemme den letzten Block char_end an len(content) für den abschließenden Zeilenumbruch von @Diwak4r in https://github.com/browser-use/browser-use/pull/5175
  • fix(registry): Domänenbeschränkte Aktionen auf einer leeren URL von @abhay-codes07 in https://github.com/browser-use/browser-use/pull/5204 nicht verfügbar machen
  • fix(agent): Geben Sie jedem MessageManager seinen eigenen Status (veränderbares Standardargument) durch @abhay-codes07 in https://github.com/browser-use/browser-use/pull/5205
  • fix(dom): Nichtübereinstimmung des StackingContexts-Zugriffstyps durch @itxaiohanglover in https://github.com/browser-use/browser-use/pull/5104 behoben
  • Fix: Exportieren Sie dokumentierte LLM-Chat-Modelle von @Karunasagar12 in https://github.com/browser-use/browser-use/pull/5182
  • Variablenschatten in der Fehlerbehandlung von Element.click() durch @Gaurav0807 in https://github.com/browser-use/browser-use/pull/5089 behoben
  • Fix(Downloads): Komplette Rückrufe für Remote-Browser-Downloads von @sergioperezcheco in https://github.com/browser-use/browser-use/pull/5264 auslösen
  • fix(llm): Strukturierte Ausgabe von Werkzeugaufrufen für Groq-Werkzeugaufrufmodelle von @VenkateswarluNagineni in https://github.com/browser-use/browser-use/pull/5240 lesen
  • ChatAnthropicBedrock.ainvoke() IndexError für eine leere Response.content-Liste von @chuenchen309 in https://github.com/browser-use/browser-use/pull/5233 behoben
  • Fix (asynchron): Vermeiden Sie das erneute Auslösen von Task-Callback-Fehlern durch @GautamSharma99 in https://github.com/browser-use/browser-use/pull/5285
  • fix(browser): storage_state-Cookies anwenden, wenn sie von @ayaangazali in https://github.com/browser-use/browser-use/pull/5262 als In-Memory-Dict übergeben werden
  • fix(tools): SearchGoogleAction-Backcompat-Alias von @LHMQ878 in https://github.com/browser-use/browser-use/pull/5318 wiederherstellen
  • Problem behoben, bei dem Mouse.scroll() ein explizites x=0/y=0 von @chuenchen309 in https://github.com/browser-use/browser-use/pull/5231 stillschweigend in die Mitte des Ansichtsfensters umleitet
  • Behebung eines Problems, bei dem DOMTreeSerializer durch die Farbreihenfolge verdeckten Text von @chuenchen309 in https://github.com/browser-use/browser-use/pull/5225 an das LLM weitergibt
  • fix(mcp): Markieren Sie schreibgeschützte MCP-Tools mit readOnlyHint-Anmerkungen von @ayaangazali in https://github.com/browser-use/browser-use/pull/5246
  • fix(mcp): CallToolResult.isError als fehlgeschlagenes ActionResult von @chuenchen309 in https://github.com/browser-use/browser-use/pull/5235 anzeigen
  • fix(agent): PIL-Bilder nach GIF-Erstellung schließen, um Ressourcenverlust durch @itxaiohanglover in https://github.com/browser-use/browser-use/pull/5105 zu verhindern
  • Fix: Ausnahmedetails in Koordinate click einschließen und fehlende Fehlerprotokolle von @shotsan in https://github.com/browser-use/browser-use/pull/5379 hinzufügen
  • Dokumente: Aktualisieren Sie das Diagramm „Open Source vs. Cloud“ mit Cloud v4 von @Alezander9 in https://github.com/browser-use/browser-use/pull/5388
  • Dokumente: Zeigen Sie den Aufruf des gehosteten Agenten API in der README-Datei von @Alezander9 in https://github.com/browser-use/browser-use/pull/5394 an
  • fix(utils): Verhindert die Kaskadenbeschädigung von redact_sensitive_string durch @santhreal in https://github.com/browser-use/browser-use/pull/5211
  • Bump aiohttp- und pypdf-Sicherheitspins von @sauravpanda in https://github.com/browser-use/browser-use/pull/5326
  • fix(agent): Null-Schwellenwert für Nachrichtenkomprimierung von @wesleyzhangwq in https://github.com/browser-use/browser-use/pull/5401 berücksichtigen
  • fix(mcp): veraltete Bedrock Claude-Modellkennung von @scemii in https://github.com/browser-use/browser-use/pull/5448 aktualisieren
  • Dokumente: README-Demovideos von @MagMueller in https://github.com/browser-use/browser-use/pull/5463 zuschneiden
  • Dokumente: Social-Video-Vorschau von @MagMueller in https://github.com/browser-use/browser-use/pull/5464 wiederherstellen
  • feat(llm): Standard-ChatBrowserUse für bu-2-0-mini-preview von @sauravpanda in https://github.com/browser-use/browser-use/pull/5465
  • fix(deps): OpenHands mit Rich 14.3.3 von @MagMueller in https://github.com/browser-use/browser-use/pull/5477 entsperren
  • Kunststück: Erstanbieter-OpenClaw-Skill-Unterstützung von @MagMueller in https://github.com/browser-use/browser-use/pull/5476 hinzufügen
  • Veröffentlichung von 0.13.8 mit Browser Harness 0.1.9 von @gregpr07 in https://github.com/browser-use/browser-use/pull/5481
