<Details> <summary>Release Notes</summary> Cherry Studio 2.1.4 – Neue Modelle, Geräteverbindungen und Fehlerbehebungen ✨ Neue Funktionen - [Geräteverbindungen] Stellen Sie eine Verbindung über erreichbares LAN oder extern konfigurierte VPN-Netzwerke mit IPv4/IPv6-Unterstützung, automatischer Adresspriorisierung und manueller Auswahl über die Netzwerkschnittstelle her. Aktion erforderlich: Aktualisieren Sie auf eine kompatible mobile App, um zusätzliche Adressen zu speichern und zu überprüfen und Kopplungscodes mit mehr als 16 Adressen zu scannen. - [Nachrichten] Export zur Mehrfachauswahl-Aktionsleiste hinzufügen: Exportieren Sie ausgewählte Nachrichten als Markdown, Word oder nach Notion/Yuque/Obsidian/Joplin/Siyuan. - [Modelle] Fügen Sie GPT-6.1 Sol-Unterstützung für OpenAI und OpenAI Codex hinzu, einschließlich Preis- und Begründungseinstellungen. - [Modelle] Fügen Sie Claude Sonnet 5.5 und Opus 5.5 mit Denksteuerung und nativer Web-Tool-Berechtigung hinzu. - [Modelle] Der Claude Code-Anbieter bietet jetzt Claude Opus 5.5 (mit Schnellmodus) und Claude Fable 5.1 an. - [Modelle] MiniMax M3.1 Flash Preview mit fünf Argumentationsaufwandsstufen hinzufügen. - [ComfyUI] Lokalen ComfyUI-Bildanbieter hinzufügen: Gespeicherte Arbeitsabläufe als Modelle auswählen und aus der Gemäldeseite generieren. - [Launchpad] Integrierte App-Kacheln verwenden jetzt themenbezogene Kartenoberflächen. 🐛 Fehlerbehebungen – [Agent] Behebung, dass Agent-Sitzungen unbrauchbar wurden, wenn der vorherige Claude-Code-Prozess langsam beendet wurde. - [Agent] Beheben Sie wiederholte Nachrichtenkonflikte und veraltete Titel in neu erstellten Remote-Agent-Sitzungen. - [Agent] Checkpoint-Fehlermeldung beim Bearbeiten und erneuten Senden behoben – erklärt das Problem jetzt klar. - [Agent] Korrigieren Sie Agent-Sitzungsnachrichten, die nach einem erfolgreichen Löschvorgang in der Liste verbleiben. - [Agentenaufgaben] Fordern Sie ungenutzte Heartbeat-Arbeitsbereiche zusammen mit verwaisten Zeitplänen zurück. - [Chat] Fix: Neugenerierung mit dem falschen Anbieter – verwendet jetzt die Composer-Auswahl. - [Chat] Behebung eines Wiederholungsversuchs für Gruppen mit mehreren Modellen unter Verwendung des Standardmodells des Assistenten anstelle des eigenen Modells der Antwort. - [Chat] Korrigieren Sie, dass über das Archiv wiederhergestellte Konversationen beim Öffnen rückgängig gemacht werden. - [Chat] Problem behoben, bei dem Werkzeugaufruf-Panels nicht dieselbe Ansichtsfenster-abhängige Höhe wie das Thinking-Panel verwenden. - [Chat] Themen-Chats sind nicht länger in Browser-Tool-Schemata integriert, was den Overhead von mehreren tausend Token reduziert. - [Chat] Behandeln Sie den Tag-Block, der eine Antwort öffnet, nur als Inline-Begründung – wörtliche Tags in Antworten kürzen den Inhalt nicht mehr ab. - [Wissen] Korrigieren Sie die Installation des MCP-Pakets (DXT/MCPB) mit Pfaden, die sich nur in der Groß-/Kleinschreibung oder der Unicode-Form unterscheiden. - [Wissen] Korrigieren Sie erfasste URL-Snapshots, die mit Prozent-Escapezeichen benannt sind, wenn der Seitenpfad nicht ASCII ist. - [Wissen] Merken Sie sich die letzte vom Speicherdialog verwendete Wissensdatenbank. - [Skills] Behebung von skills.sh-Installationen für Repositories, in denen Skills unter .gemini/skills/, .claude/skills/ oder .agents/skills/ gespeichert sind. - [Skills] Korrigieren Sie Skill-ZIP-Importe mit Pfaden, die sich nur in der Groß-/Kleinschreibung oder der Unicode-Form unterscheiden. - [Übersetzen] Behebung, dass Meerjungfrauendiagramme während der Übersetzung nicht beibehalten und gerendert werden. - [Dateivorschau] Korrektur der Dateivorschau, in der Pfadfragmente als Sprache für Dateien in gepunkteten Verzeichnissen oder ohne Erweiterungen angezeigt werden. - [Dateivorschau] Problem behoben, bei dem die PDF-Vorschau keinen chinesischen/CJK-Text wiedergibt, der nicht eingebettete CID-Schriftarten verwendet. - [Dateisymbol] Dateisymbole für Windows-Pfade korrigiert – Artefaktkarten zeigen jetzt das richtige Symbol. - [Markdown] Problem behoben, bei dem SVGs im Chat mit Größen gerendert werden, die für zuvor gerenderte SVGs gemessen wurden. - [Modellliste] Behalten Sie die numerischen Gruppennamen in der Modellreihenfolge bei, während ein Suchfilter aktiv ist. - [Rich-Text-Editor] Über die Symbolleiste angewendete Formatierungen werden jetzt in der Notiz gespeichert. - [Browser] Stellen Sie die Größenänderung entlang der gesamten Höhe des Seitenleistentrennzeichens des Browsers wieder her. - [Chat-Layout] Verwenden Sie bei der ersten Ausführung einen schmaleren Standardwert von 280 Pixel für Datei- und Artefaktbereiche. - [Diagnose] Fehler bei der Integritätsprüfungsmeldung „Kein API-Schlüssel konfiguriert“ für Claude Code CLI-basierten Anbieter behoben. - [Diagnose] Statuslink, Verarbeitungsstatus und lokaler Verlauf für Diagnoseberichte anzeigen. - [Auswahlassistent] Korrigieren Sie, dass Ergebniscodeblöcke bei schmalen Breiten nicht umbrochen werden. - [Auswahlassistent] Behebung des schwarzen Bildschirms nach dem Schließen des Aktionsfensters im macOS-Vollbildmodus. - [Screenshot] Die Aufnahme von Windows-Screenshots auf Multi-Monitor-Layouts mit gemischten DPI wurde korrigiert. - [Websuche] Behebung, dass die Schlüsselrotation API nie andere Schlüssel erreicht, wenn ein doppelter Eintrag vorhanden ist. - [OpenClaw] Behebung des irreführenden Fehlers „binär inkompatibel“, wenn der config-schema-Probe nur langsam war. - [Copilot] Korrigieren Sie das Routing des GPT-6-Modells GitHub Copilot, indem Sie die Antworten API für die GPT-6-Familie auswählen. - [DSH] Behebung der von Windows verwalteten temporären DSH-Verzeichnisbereinigung und Aktualisierung auf 0.2.0-rc.2. - [Claude Agent] Aktualisieren Sie Claude Agent SDK auf 0.3.284 mit beibehaltenen Anweisungen im Lebenslauf. - [Agentenerstellung] DeepSeek Harness aus den Laufzeitoptionen für neue Agenten entfernen; Vorhandene Agenten werden weiterhin unterstützt. - [Dateisystem] Das `ls`-Tool hat ein Problem behoben, das ein leeres Verzeichnis anstelle einer Fehlermeldung für fehlende oder Nicht-Verzeichnispfade meldet. - [API] Behebung eines OpenAI-kompatiblen Streamings, bei dem das erforderliche `arguments`-Feld für Tools ohne Parameter weggelassen wurde. - [HTML-Vorschau] Korrigieren Sie das Springen von Text, wenn die Bildlaufleiste beim Schwellenwert für die Inhaltsgröße angezeigt/verschwindet. - [Geplante Aufgaben] Halten Sie mehrstündige Auswahlen kompakt und unterstützen Sie bearbeitbare, validierte Cron-Ausdrücke. - [Composer] Kopierte Excel-Zellen werden jetzt als Text eingefügt, wenn Rich-Text neben einem Bild steht. - [Anbietereinstellungen] Stellen Sie klar, dass Doubao-Modelle Volcengine Ark mit der unterstützten Basis-URL API verwenden. - [macOS] Problem behoben, bei dem das Hauptfenster beim ersten Dock click nach dem Schließen mit der roten Taste nicht erneut geöffnet wurde. - [Anbieter] Position der Modellanbieterliste beim Aktivieren/Deaktivieren beibehalten; neue
