openai-agents-python v0.20.0

Wichtige Änderungen

Bei der Version 0.20.0 handelt es sich um eine Nebenversion, da sie das implizite Standardmodell ändert und eine möglicherweise störende MCP-Abhängigkeitsmigration für Anwendungen mit angepassten lokalen HTTP-Transporten enthält. MCP v1 wird weiterhin unterstützt und betroffene Anwendungen können auf httpx2 oder Pin mcp<2 migriert werden.

Highlights:

  • Das Standardmodell ist jetzt gpt-5.6-luna; explizite Modelle, Runlevel-Überschreibungen und OPENAI_DEFAULT_MODEL haben weiterhin Vorrang. – Lokale MCP-Verbindungen unterstützen MCP Python SDK v1 und v2 über stdio-, SSE- und Streamable-HTTP-Transporte. – Anwendungen, die benutzerdefinierte MCP-HTTP-Authentifizierung oder client-Factorys verwenden, müssen die HTTP-Typen verwenden, die der installierten MCP-Hauptversion gehören, oder den Pin mcp<2 verwenden. – RunState.add_input() kann dauerhafte Benutzereingaben vor einem wiederaufgenommenen Modellaufruf bereitstellen, mit Leitplanken-, Persistenz- und Serialisierungsunterstützung. – Die Sandbox-Mount-Validierung fügt explizite Bestätigungen für die Offenlegung von Anmeldeinformationen hinzu und behält redigierte Fehlerverträge bei, ohne die Anmeldeinformationsautorität zu serialisieren. – Die Echtzeit-Eingabetranskription unterstützt die GA-Transkriptionseinstellungen für gpt-live-transcribe, gpt-transcribe und gpt-realtime-whisper.
