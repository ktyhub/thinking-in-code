Inkubator-Seata v2.2.0

Apache Seata (in Inkubation) 2.2.0 veröffentlicht.

Apache Seata (Incubating) ist eine benutzerfreundliche, leistungsstarke Open-Source-Lösung für verteilte Transaktionen.

Herunterladen https://seata.apache.org/download/seata-server

Die Version wird wie folgt aktualisiert:
