Inkubator-Seata v2.0.0

Seata 2.0.0 veröffentlicht

Seata ist eine benutzerfreundliche, leistungsstarke Open-Source-Lösung für verteilte Transaktionen.

Die Version wird wie folgt aktualisiert:

– [#5165] optimiert die TCC-Struktur und unterstützt den API-Zugriff.   • [#5377] sorgt dafür, dass AbstractHttpExecutor.class http put unterstützt – [#5396] TC-Log-Appender-Metrik – [#5118] unterstützt die zweistufige gleichzeitige Benachrichtigungsausführung
