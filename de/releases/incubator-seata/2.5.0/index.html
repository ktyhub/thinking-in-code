Inkubator-Seata v2.5.0

Apache Seata (in Inkubation) 2.5.0 veröffentlicht.

Apache Seata (Incubating) ist eine benutzerfreundliche, leistungsstarke Open-Source-Lösung für verteilte Transaktionen.

Die Version wird wie folgt aktualisiert:

Funktion:

– [#7261] erzwingt die Kontoinitialisierung und deaktiviert die Standardanmeldeinformationen

  • [#7451] Seata-Server unterstützt das HTTP/2-Protokoll
  • [#7496] Unterstützung für Oceanbase Oracle hinzugefügt

Bugfix:

  • [#7349] NullPointerException in EtcdRegistryServiceImplMockTest auflösen – [#7354] behebt, dass die Treiber im libs-Ordner nicht geladen werden können

  • [#7504] Ladetreiberklasse in Hikari behoben – [#7529] Behebung, dass der Server keine Heartbeats sendet, wenn der Namingserver mit anderen Registrys verwendet wird
  • [#7546] Fix client Federversion kompatibel
