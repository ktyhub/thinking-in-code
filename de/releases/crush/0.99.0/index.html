Hooks, Catwalk v3!

Ein ganz Großer! Crush läuft jetzt auf Catwalk v3, Hooks können jeden Teil eines Laufs sehen und Redakteure, die Crush hosten, erhalten eine ganze Reihe neuer Tools, mit denen sie sich wie zu Hause fühlen können.

Haken, überall 🪝

Bei Haken geht es nicht mehr nur um Werkzeuge. Sie können jetzt den gesamten Lauf verfolgen: Sitzungen, Runden, Berechtigungen und mehr!

Hooks können jetzt auch eingreifen, nachdem ein Tool ausgeführt wurde. Schwärzen Sie Geheimnisse aus der Ausgabe, bevor das Modell sie sieht, fügen Sie eine Notiz hinzu oder stoppen Sie die Runde. Wenn das Tool bereits etwas getan hat, was es nicht tun sollte, kann Ihr Hook dem Modell mitteilen, dass Sie ein Commit durchgeführt haben, ohne die Tests auszuführen.

hook add TurnEnd --name "ding" --command 'afplay /System/Library/Sounds/Glass.aiff'

Mehr können Sie [hier] lesen (https://github.com/charmbracelet/crush/tree/main/docs/hooks#readme)

Client/Server-Modus

Wenn Sie etwas erstellen, in dem Crush ausgeführt wird, ist diese Version genau das Richtige für Sie:

  • Host-Themen: Die Host-App kann die TUI über den Server API thematisieren, sodass Crush zu Ihren Anwendungen passt.
  • Host-Kontext: Der Host kann Crush mitteilen, was angezeigt wird, z. B. geöffnete Dateien, und diese Dateien werden in den Vervollständigungen angezeigt.
  • An die nächste Eingabeaufforderung anhängen: clients können Text hinzufügen, den der Agent bei der nächsten Eingabeaufforderung liest, ohne einen Lauf zu starten oder den Chat zu überladen.
  • Geteilte Anzeige: clients können sehen, welche Sitzung andere clients ansehen.
  • Weitergeleitete Berechtigungen: Legen Sie CRUSH_PERMISSIONS_PIPED=1 fest und der Host beantwortet Berechtigungsanfragen, sodass Sie nicht zweimal gefragt werden.
  • http://-Adressen fungieren beim Starten des Servers als Alias ​​für tcp://.

Stabilerer Server

  • SIGHUP lädt jetzt die Konfiguration neu, anstatt den Server zu stoppen.
  • Das Schließen des Terminals oder das Stoppen von Crush über einen Dienstmanager wird jetzt ordnungsgemäß heruntergefahren, sodass laufende Arbeiten gespeichert werden und nicht hängen bleiben.

Kleiner Überblick über [Catwalk v3][catwalk]:

Crush spricht jetzt [Catwalk v3][catwalk]. Der Anbieter type beschreibt das API-Format, das ein Anbieter verwendet, und nicht, wer es erstellt hat:

  • completions: OpenAI-kompatible APIs
  • responses: OpenAI oder alles, was darüber geleitet wird
  • messages: Anthropic-kompatible APIs

Ihre Konfiguration wird beim Laden automatisch migriert, sodass openai, openai-compat und anthropic weiterhin funktionieren. Keine Änderungen erforderlich.

Es folgen die Flags provider add und model add:

crush provider add deepseek \
  --type completions \
  --base-url "https://api.deepseek.com/v1" \
  --api-key "$DEEPSEEK_API_KEY"

crush model add deepseek/deepseek-chat --thinking toggleable --max-attachments 5
  • --can-reason ist jetzt --thinking always|never|toggleable
  • --max-attachments N ist neu
  • Argumentationsebenen zeigen in der Auswahl benutzerfreundliche Namen an, z. B. „X-High“.

Das ist alles für jetzt! Charme XX 💫
