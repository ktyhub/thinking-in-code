zerquetsche v0.81.0

Ein paar UX-Sachen für euch

Wir beginnen die Woche mit gutem Stil, indem wir einige nette Ergänzungen und Verbesserungen hinzufügen.

Chat-Bildlaufleiste

Das ist es, der Chat hat gerade eine Bildlaufleiste bekommen! Dies sollte Ihnen das Leben bei längeren Navigationssitzungen erleichtern. Sie können jetzt beim Scrollen genau sehen, wo Sie sich befinden. Es ist möglich, das Verhalten mit einer Einstellung anzupassen: options.tui.scrollbar.

  • default (versteckt sich nach 2 Sekunden)
  • always
  • never
{
  "options": {
    "tui": {
      "scrollbar": "default" // default, always, never
    }
  }
}

https://github.com/user-attachments/assets/c0c0f888-78d4-4457-ae32-eb1a2dd5f575

Herdr-Unterstützung

Wollten Sie herdr.dev schon immer für alle Ihre Agentenverwaltungsanforderungen verwenden? Nun, jetzt ist es noch besser! @taciturnaxolotl hat die Unterstützung für die Signalisierung des Agentenstatus zusammengeführt, sodass Herdr jetzt den Status eines Crushs erkennen und Ihnen Benachrichtigungen senden kann, wenn er blockiert oder beendet ist! <img width="1470" height="956" alt="image" src="https://github.com/user-attachments/assets/4ab696c7-d105-4c91-b658-8902e930dc5f" />

Geringere CPU-Auslastung

Crush könnte zu viel CPU beanspruchen, wenn es Denkspuren streamt und für Sie anzeigt. @taciturnaxolotl hat eine Optimierung durchgeführt und das ist jetzt behoben!

Möglichen Deadlock beim Start beheben

Wenn Sie in Ihrer Konfiguration eine Modell-ID haben, die nicht mehr existiert (von den Anbietern entfernt wurde), könnte Crush beim Booten blockieren und überhaupt nicht starten. Dieser Fehler wurde behoben.

Bilder und Ihre Sitzung

Dies ist eine weitere Lösung, um zu verhindern, dass Ihre Sitzung unterbrochen wird, wenn Sie zu einem Nicht-Vision-Modell wechseln, Ihre Sitzung jedoch bereits über Bilder verfügt. Wir überspringen die Bilder, damit Ihre Sitzung weiterhin funktioniert. Das ist alles! Charme
