zerquetsche v0.102.0

Kanäle, benutzerdefinierte Eingabeaufforderungen und Serverhärtung

Es gibt so viel Gutes in dieser Veröffentlichung und wir sind wirklich stolz auf alles davon. Lesen Sie weiter für mehr.

BYO-Eingabeaufforderungen

Endlich können Sie die Systemaufforderungen durch … was auch immer Sie wollen, ersetzen. Und nicht nur der Hauptagent, sondern auch Eingabeaufforderungen für Unteragenten, Planung, Komprimierung, Sitzungstitel und crush init:

option prompt coder ~/.config/crush/prompts/coder.md.tpl
option prompt summary prompts/summary.md

Sie können die Eingabeaufforderung in der globalen Konfiguration festlegen, sie pro Projekt in der lokalen Konfiguration überschreiben oder die Eingabeaufforderung mit --prompt name=path überschreiben. Weitere Informationen zu Eingabeaufforderungen finden Sie in den Dokumenten (https://github.com/charmbracelet/crush/blob/main/docs/config/README.md#option-prompt).

Reiten in der Nacht

Crush wird jetzt mit einem von Knight Rider inspirierten KITT-Design ausgeliefert, mit freundlicher Genehmigung von @cdancy. Ab sofort sind auch Rosé Pine Classic, Moon und Dawn erhältlich.

<p><img width="730" height="528" alt="image" src="https://github.com/user-attachments/assets/2c139b67-92a3-4600-9278-761c813699ed" /></p> ## Nerd raus mit Nerd Fonts Endlich Nerd-Schriftarten! Der Support wird automatisch erkannt, sodass auch Ihr Terminal nie beschädigt wird! Crush verwendet jetzt ihre Symbole, den LSP-Status und Git inklusive. Beachten Sie, dass Sie die Nerd-Schriftarten `option ui nerd-fonts true` aktivieren müssen, wenn Sie Crush über SSH ausführen. ```bash # Hate nerd fonts? You can turn 'em off, too. option ui nerd-fonts false ``` ## Kanäle [Kanäle](https://code.claude.com/docs/en/channels-reference) sind eine experimentelle MCP-Funktion von Claude, die dank der guten Arbeit von @joestump jetzt in Crush verfügbar ist. Kurz gesagt: Kanäle ermöglichen es MCP-Servern, Ereignisse in Ihre Sitzung zu übertragen, sobald sie eintreten. ```bash crush --channels server:webhook --channels server:signal ``` Oder schalten Sie einen dauerhaft in Ihrem `crushrc` ein: ```bash # crushrc mcp add webhook \ --type http \ --url https://example.com/mcp \ --channel true ``` Crush verwendet das gleiche Protokoll wie [Claude Channels](https://code.claude.com/docs/en/channels-reference), daher sollten vorhandene Channel-Server einfach funktionieren™. ## Server-Härtung Der Client-Server-Modus ist jetzt robuster als je zuvor. Es ist jetzt sicherer und enthält eine Menge kleiner Verbesserungen, Korrektheitskorrekturen und Fehlerbehebungen, insbesondere unter Windows. ## Und noch viel mehr – Der Sysadmin-Modus ist nicht länger eine <kbd>Umschalt+Tabulatortaste</kbd> hinter Yolo. - Eingabeaufforderungen in der Warteschlange werden im Tablet angezeigt, sobald Sie sie absenden. - Das Modell kann `sudo` verwenden, sodass Sie es mit Touch ID genehmigen können. - Inhaltsablehnungen werden automatisch wiederholt. - Sitzungen, die Claude immer wieder ablehnte, funktionierten wieder. - Ollama-Modelle, die keine Werkzeuge aufrufen können, werden nicht mehr in der Modellliste angezeigt. - Befehle, die untergeordnete Prozesse zurücklassen, bleiben nicht mehr hängen. - Die Timer ticken zusammen und die Timer des laufenden Werkzeugs laufen weiter, bis das Werkzeug antwortet. - Beim Wechseln des Themas wird nicht mehr die gesamte Konversation neu gerendert. - Durch das Löschen einer Sitzung behalten Sie Ihren Platz in der Liste. - Bei wiedergegebenen Nachrichten bleiben die Leerzeichen erhalten und die Plankarten werden ordnungsgemäß ausgerichtet.
