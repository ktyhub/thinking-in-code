Wenn Sie Fragen haben, haben wir Antworten

Diese Version bringt uns (endlich!) ein Fragetool sowie eine Reihe von Bugfixes und Feinheiten. Lass uns gehen!

Das Fragetool

Also! Crush wird jetzt mit einem erstklassigen Fragetool ausgeliefert, das nützlich ist, wenn LLMs Sie auf die Probe stellen möchten. Das Fragetool gibt es in vielen Formen, z. B. Einzelauswahl, Mehrfachauswahl, Freiformtext und Ja/Nein. Fragen können auch zu einem Formular zusammengefasst werden.
