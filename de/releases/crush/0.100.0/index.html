Subagenten, Sysadmin-Modus und PGP/SSH-Eingabeaufforderungen

Das ist etwas Großes! Crush kann jetzt ein Team von Subagenten leiten, Berechtigungen sind viel flexibler und Sie können jetzt GPG- und SSH-Authentifizierung direkt in Crush durchführen! Lesen Sie weiter für mehr.

👩🏼‍🐰‍👩🏽 Subagenten

Endlich, Subagenten. Crush kann jetzt im Hintergrund ein kleines Team befreundeter Unteragenten erzeugen, diese überprüfen, ihnen während des Laufs Follow-ups senden, sie stoppen oder sie zu einem anderen Modell verschieben.

<p><img width="600" alt="image" src="https://github.com/user-attachments/assets/a8f4f437-dd9a-46bb-ab31-65a14b84c07a" /></p>

Sie können direkt im Transkript, in der Seitenleiste und in der Kopfzeile zusehen, wie sie funktionieren. Jeder Subagent erhält außerdem einen eigenen Namen, sodass Sie immer wissen, wer was tut. Und wenn Sie sie beim Namen nennen, weiß Crush, von wem Sie sprechen!

🚨 Sysadmin-Modus

Haben Sie sich jemals gewünscht, dass Crush DROP SCHEMA public CASCADE; könnte? Jetzt ist es möglich, mit dem Sysadmin-Modus! Tatsächlich kann Crush im Sysadmin-Modus jeden Befehl auf Ihrem System ausführen. Seien Sie vorsichtig.

<p><img width="600" alt="image" src="https://github.com/user-attachments/assets/c8ccbd1b-aba2-48cc-bef7-b15045b41241" /><p>

Suchen Sie den Sysadmin-Modus in der Befehlspalette (<kbd>Strg+P</kbd>) oder schalten Sie mit <kbd>Umschalt+Tab</kbd> durch alle Modi.

🙅🏻‍♀️ Sichere Befehle

Natürlich blockiert der Yolo-Modus immer noch gefährliche Befehle, aber welche Befehle gefährlich sind, liegt jetzt bei Ihnen.

  • permissions safe markiert Befehle, die für Yolo sicher sind
  • permissions block blockiert Befehle vollständig
  • permissions unblock entsperrt eingeschränkte Befehle
# Building is fine
permissions safe "go build" "cargo check"

# Don't touch my infra please
permissions block kubectl terraform

# Curl your heart out
permissions unblock curl

🗝️ PGP und SSH

Es ist so nervig, wenn Sie einen KI-Agenten verwenden und kein SSH-Passwort eingeben, Ihr Yubikey aktivieren und keine GPG-Passwörter eingeben können, oder? Nun, mit Crush gehört dieser Ärger der Vergangenheit an.

<img width="600" alt="out" src="https://github.com/user-attachments/assets/fb19ae55-8e0e-415e-8604-07029d9c9995" />

Machen Sie beim Einsatz von KI keine Kompromisse mehr bei Ihrer Sicherheit!

Laden Sie zunächst die Dateien checksums.txt-Datei und checksums.txt.sigstore.json-Datei herunter, beispielsweise mit wget:

wget 'https://github.com/charmbracelet/crush/releases/download/v0.100.0/checksums.txt'
wget 'https://github.com/charmbracelet/crush/releases/download/v0.100.0/checksums.txt.sigstore.json'

Überprüfen Sie es dann mit cosign:

cosign verify-blob \
  --certificate-identity-regexp '^https://github.com/charmbracelet/crush/\.github/workflows/(release|nightly)\.yml@' \
  --certificate-oidc-issuer 'https://token.actions.githubusercontent.com' \
  --bundle 'checksums.txt.sigstore.json' \
  ./checksums.txt

Wenn die Ausgabe Verified OK ist, können Sie sie sicher verwenden, um die Prüfsummen anderer Artefakte zu überprüfen, die Sie mit sha256sum aus der Version heruntergeladen haben:

sha256sum --ignore-missing -c checksums.txt
