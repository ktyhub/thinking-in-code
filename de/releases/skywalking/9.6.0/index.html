Skywalking v9.6.0

Herunterladen

https://skywalking.apache.org/downloads/

Hinweis

Laden Sie keine Quellcodes von dieser Seite herunter. Bitte folgen Sie Build-Dokument, wenn Sie selbst Quellcodes erstellen möchten.

Neuer Alarmierungskernel

  • MQE (Metrics Query Expression) und ein neuer Benachrichtigungsmechanismus werden unterstützt.

Unterstützen Sie Loki LogQL

  • Neu hinzugefügte Unterstützung für Loki LogQL und Grafana Loki Dashboard für von SkyWalking gesammelte Protokolle

WARNUNG

  • ElasticSearch 6 Speicherrelative Tests wurden entfernt. Es hat funktioniert und wird aufgrund des offiziellen Lebensendes nicht versprochen.

Projekt

  • Erhöhen Sie Guava auf 32.0.1, um die aufgrund von CVE-2020-8908 als anfällig eingestufte Bibliothek zu vermeiden. Dieser API wird nie verwendet.
  • Das Maven-Artefakt skywalking-log-recevier-plugin wurde in skywalking-log-receiver-plugin umbenannt.
  • Erweitern Sie die cli-Version 0.11 auf 0.12.
  • Erhöhen Sie die Version des übergeordneten ASF-POM auf Version 30.
  • Machen Sie Builds für automatische CI-Releases reproduzierbar.

OAP-Server

  • Fügen Sie die Sprache der Neo4j-Komponenten-ID (112) hinzu: Python.
  • Fügen Sie die Istio ServiceEntry-Registrierung hinzu, um unbekannte IPs in ALS aufzulösen.
  • Wickeln Sie deleteProperty API in den BanyanDBStorageClient ein.
  • [Breaking Change] Entfernen Sie matchedCounter aus HttpUriRecognitionService#feedRawData.
  • Entfernen Sie Muster aus HttpUriRecognitionService#feedRawData und fügen Sie maximal 10 Kandidaten für Roh-URIs für jedes Muster hinzu.
  • Komponenten-ID für WebSphere hinzufügen.
  • Behebung von NullPointer- und IllegalArgument-Ausnahmen beim URI-Caching der AI-Pipeline.
  • Korrigieren Sie NPE in der Metrikabfrage, wenn die Metrik nicht vorhanden ist.
  • Entfernen Sie E2E-Tests für Istio < 1.15, ElasticSearch < 7.16.3. Sie funktionieren möglicherweise weiterhin, werden aber nicht wie geplant unterstützt.
  • Scrollen Sie durch alle Ergebnisse in ElasticSearch-Speicher- und Refactor-Scrolllogiken, einschließlich Service, Instanz, Endpunkt, Prozess usw.
  • Kubernetes-Koordinator verbessern, um Terminating OAP-Pods im Cluster zu entfernen.
  • Unterstützt SW_CORE_SYNC_PERIOD_HTTP_URI_RECOGNITION_PATTERN und SW_CORE_TRAINING_PERIOD_HTTP_URI_RECOGNITION_PATTERN um den Trainingszeitraum zu steuern und HTTP-URI-Erkennungsmuster zu synchronisieren. Und verkürzen Sie den Standardzeitraum auf 10 Sekunden Synchronisierung und 60s für das Training.
  • Behebung des ElasticSearch-Scroller-Fehlers.
  • Komponenten-ID für Aerospike hinzufügen (ID=149).
  • Pakete mit dem Namen recevier werden in receiver umbenannt.
  • BanyanDBMetricsDAO verarbeitet storeIDTag in multiGet für BanyanDBModelExtension.
  • Korrigieren Sie die Logik im Zusammenhang mit der Endpunktgruppierung und verbessern Sie die Leistung des PatternTree-Abrufs.
  • Das Speichern des Metrik-Sitzungscaches nach dem Batch-Einfügen bei Verwendung von mysql-connector-java wurde behoben.
  • Unterstützt dynamische UI-Menüabfragen.
  • Fügen Sie einen Kommentar für docker/.env hinzu, um die Verwendung zu erläutern.
  • Korrigieren Sie den falschen Umgebungsvariablennamen SW_OTEL_RECEIVER_ENABLED_OTEL_RULES in den richtigen SW_OTEL_RECEIVER_ENABLED_OTEL_METRICS_RULES.
  • Instanzabfrage in der JDBC-Implementierung behoben.
  • Setzen Sie den Standardwert SW_QUERY_MAX_QUERY_COMPLEXITY auf 3000 (vorher 1000).
  • Akzeptieren Sie den Parameterwert length=4000 des Ereignisses. Es war 2000.
  • Parameterwerte im unzulässigen JSON-Format werden toleriert.
  • Aktualisieren Sie BanyanDB Java Client auf 0.4.0
  • Unterstützt das Aggregat Labeled Value Metrics in MQE.
  • [Breaking Change] Ändern Sie den Standardlabelnamen in MQE von label in _.
  • Erweitern Sie die grpc-Version auf 1.53.0.
  • [Breaking Change] „&“-Symbole aus Shell-Skripten entfernt, um zu verhindern, dass der OAP-Serverprozess als Hintergrundprozess ausgeführt wird.
  • Setzen Sie einen Teil von #10616 zurück, um die unerwarteten Änderungen zu beheben: Wenn keine Daten vorhanden sind, sollten wir ein Array mit 0s zurückgeben. aber in #10616 wird ein leeres Array zurückgegeben.
  • Zwischenspeichern aller Dienstentitäten im Speicher für Abfragen.
  • Erweitern Sie die Jackson-Version auf 2.15.2.
  • Erhöhen Sie die Standardspeichergröße, um OOM zu vermeiden.
  • Erhöhen Sie graphql-java auf 21.0.
  • Echo-Komponenten-ID (5015) hinzufügen. Sprache: Golang.
  • Korrigieren Sie index out of bounds exception in der MQE-Funktion aggregate_labels.
  • Unterstützt die MongoDB-Server-/Clusterüberwachung von OTEL.
  • Drucken Sie keine Konfigurationswerte in Protokollen aus, um zu verhindern, dass vertrauliche Informationen durchsickern.
  • Move hat den neuesten Index erstellt, bevor Indizes nach Aliasen abgerufen wurden, um die 404-Ausnahme zu vermeiden. Dies verhindert lediglich einige Störungen durch manuelle Vorgänge.
  • Fügen Sie weitere Go-VM-Metriken hinzu, da der neue Skywalking-Go-Agent seit seiner Veröffentlichung 0.2 bereitgestellt wird.
  • Komponenten-ID für Sperre hinzufügen (ID=5016).
  • [Breaking Change] Passen Sie die Struktur der Hooks im alarm-settings.yml an. Unterstützt mehrere Konfigurationen für jeden Hook-Typ und die Angabe der Hooks in der Alarmregel.
  • Erhöhe Armeria auf 1.24.3.
  • Korrigieren Sie BooleanMatch und BooleanNotEqualMatch beim Boolean-Vergleich.
  • Unterstützt LogQL-HTTP-Abfrage APIs.
  • Fügen Sie die Sprache der Mux-Server-Komponenten-ID (5017) hinzu: Golang.
  • Entfernen Sie ElasticSearch 6.3.2 aus unseren client-Bibliothekstests.
  • Erhöhen Sie den ElasticSearch-Server 8.8.1 auf 8.9.0 für die neuesten E2E-Tests. 8.1.0, 7.16.3 und 7.17.10 werden noch getestet.
  • Fügen Sie OpenSearch 2.8.0 zu unseren client-Bibliothekstests hinzu.
  • Verwenden Sie den Abhörmodus für die Apollo-Implementierung der dynamischen Konfiguration.
  • Fügen Sie die Funktion view_as_seq in MQE hinzu, um Metriken in der angegebenen priorisierten Reihenfolge aufzulisten.
  • Korrigieren Sie den falschen Standardwert von k8sServiceNameRule, wenn er nicht explizit festgelegt ist.
  • Verbessern Sie PromQL, um mehrere Metrikoperationen innerhalb einer einzigen Abfrage zu ermöglichen.
  • Korrektur der MQE-Binäroperation zwischen beschrifteten Metriken und anderen Arten von Wertergebnissen.
  • Komponenten-ID für Nacos hinzufügen (ID=150).
  • Unterstützt Compare Operation in MQE.
  • Behebung des Problems, dass der Kubernetes-Ressourcencache nicht aktualisiert wurde.
  • Korrigieren Sie den falschen Klassenpfad, der beim Start zu OOM führen könnte.
  • Erweitern Sie serviceRelation in MAL durch Hinzufügen von Einstellungen für die Felder delimiter und component.
  • [Breaking Change] Unterstützung von MQE bei der Warnung. Die Konfiguration der Alarmregeln (alarm-settings.yml), Fügen Sie das Feld expression hinzu, entfernen Sie die Felder metrics-name/count/threshold/op/only-as-condition und entfernen Sie die Konfiguration composite-rules.
  • Überprüfen Sie die Ergebnisse in ALS nach Downstream/Upstream statt nach Protokoll.
  • Behebung, dass die GraphQL-Abfrage listInstances keine endTime-Abfrage verwendet
  • Starten Sie den Server und den Kafka-Consumer nicht im Init-Modus.
  • Iris-Komponenten-ID (5018) hinzufügen.
  • OTLP-Tracing-Unterstützung als Zipkin-Trace-Eingabe hinzufügen.

Benutzeroberfläche

  • Korrigieren Sie den Metriknamen browser_app_error_rate im Browser-Root-Dashboard.
  • Der Anzeigename von endpoint_cpm für die Endpunktliste im General-Service-Dashboard wurde korrigiert.
  • Implementieren Sie benutzerdefinierte Menüs und Marktplatzseiten.
  • Korrigieren Sie die Typen minTraceDuration und maxTraceDuration.
  • Init minTime auf Unendlich korrigieren.
  • Bump-Abhängigkeiten, um Schwachstellen zu beheben.
  • SCSS-Variablen hinzufügen.
  • Korrigieren Sie den Titel der Instanzliste und der Hinweise in der Profilerstellung.
  • Fügen Sie einen Link hinzu, um die Ausdrucksmetrik zu erläutern, und fügen Sie Einheiten im Widget „Profilerstellung fortsetzen“ hinzu.
  • Berechnen Sie die Zeichenfolgenbreite, um die Breite des Tabulatornamens festzulegen.
  • [Breaking Change] „&“-Symbole aus Shell-Skripten entfernt, um zu verhindern, dass der Webanwendungsserverprozess als Hintergrundprozess ausgeführt wird.
  • Diagrammbeschriftung zurücksetzen.
  • Korrigieren Sie Service-Associate-Instanzen.
  • Node-Sass entfernen.
  • Festschreibungsfehler unter Windows behoben.
  • Wenden Sie MQE auf die UI-Vorlagen der Ebenen MYSQL, POSTGRESQL, REDIS, ELASTICSEARCH und DYNAMODB an.

  • Wenden Sie MQE auf die UI-Vorlagen APISIX, AWS_EKS, AWS_GATEWAY und AWS_S3 an.
  • Wenden Sie MQE auf RabbitMQ-Dashboards an.
  • Wenden Sie MQE auf UI-Vorlagen der Virtual-MQ-Ebene an
  • Wenden Sie MQE auf UI-Vorlagen der Infra-Linux-Ebene an
  • Wenden Sie MQE auf UI-Vorlagen der Infra-Windows-Ebene an
  • Wenden Sie MQE auf UI-Vorlagen der Browserebene an.

  • Das leere Schlüsselwort „getEndpoints“ wurde behoben.
  • Implementieren Sie eine Breadcrumb-Komponente als Navigation.
