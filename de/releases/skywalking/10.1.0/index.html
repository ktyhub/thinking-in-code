Skywalking v10.1.0

Herunterladen

https://skywalking.apache.org/downloads/

Hinweis

Laden Sie keine Quellcodes von dieser Seite herunter. Bitte folgen Sie Build-Dokument, wenn Sie selbst Quellcodes erstellen möchten.

Eine Version von PERFORMANCE

  • Enorme Verbesserung der UI-Leistung. Abfragen von Metrik-Widgets werden durch Nutzung der GraphQL-Funktionen gebündelt.
  • Unterstützung paralleler Abfragen in der GraphQL-Engine. Verbessern Sie die Abfrageleistung.
  • Verbessert die Leistung des OTEL-Metrik-Handlers erheblich. Reduzieren Sie die CPU- und GC-Kosten in OTEL-Metrikprozessen.
  • Durch die Einführung von BanyanDB 0.7 werden die Leistung und Stabilität der nativen Datenbank verbessert.

Projekt

  • E2E: Erhöhen Sie die Version des opentelemetry-Kollektors auf 0.102.1.
  • Push-Bild des Snapshot-Datengenerators docker an ghcr.io.
  • Erweitern Sie skywalking-infra-e2e, um GHA zu umgehen und docker-compose v1 zu entfernen.
  • Erhöhen Sie die CodeQL GitHub-Aktionen.
  • Falsche Phase des Delombok-Plugins behoben, um Build-Warnungen zu reduzieren.
  • Verwenden Sie die ci-freundliche Revision, um die Projektversion festzulegen.

OAP-Server

  • Korrigieren Sie falsche Indizes in den eBPF-Profiling-bezogenen Modellen.
  • Unterstützung für den Ausschluss des spezifischen Namespace-Verkehrs im eBPF-Zugriffsprotokollempfänger.
  • Fügen Sie Golang als unterstützte Sprache für Elasticsearch hinzu.
  • Entfernen Sie unnötige BanyanDB-Flushing-Protokolle (Info).
  • Erhöhen Sie SW_CORE_GRPC_MAX_MESSAGE_SIZE auf 50 MB.
  • Unterstützung für die Abfrage von Beziehungsmetriken über PromQL.
  • Unterstützt Trace-MQE-Abfrage zum Debuggen.
  • Komponenten-ID (158) für das Solon-Framework hinzufügen.
  • Metrik-Tag im HTTP-Handler des Browser-Empfänger-Plugins korrigiert.
  • Erhöhen Sie die Spaltenlänge alarm_record#message von 200 auf 2000.
  • alarm_record#message-Spaltenindizierung entfernen.
  • Fügen Sie Python als unterstützte Sprache für Pulsar hinzu.
  • Erstellen Sie geeignetere Histogramm-Buckets für den persistence_timer_bulk_prepare_latency. persistence_timer_bulk_execute_latency- und persistence_timer_bulk_all_latency-Metriken in PersistenceTimer.
  • [Break Change] Nacos-Version auf 2.3.2 aktualisieren. Der Nacos 1.x-Server kann nicht als Cluster-Koordinator und Konfigurationsserver dienen.
  • Unterstützt Tracing-Trace-Abfragen (SkyWalking und Zipkin) zum Debuggen.
  • BanyanDB-Metrikabfrage behoben: Es wurde der falsche Downsampling-Typ verwendet, um das Schema zu finden.
  • Unterstützt das Abrufen des Cilium-Flusses zur Überwachung des Netzwerkverkehrs zwischen Cilium-Diensten.
  • Unterstützt die labelCount-Funktion in der OAL-Engine.
  • Unterstützt BanyanDB-internes Messabfrage-Ausführungs-Traceing.
  • BanyanDB client-Konfiguration: Erhöhen Sie den Standardwert maxBulkSize auf 10000, fügen Sie flushTimeout hinzu und setzen Sie den Standardwert auf 10s.
  • Polnische BanyanDB-Gruppen- und Schemaerstellungslogik zur Behebung des Fehlers bei der Schemaerstellung unter verteilten Rennbedingungen.
  • Unterstützt Tracing-Topologie-Abfragen zum Debuggen.
  • Ausdruck des Diagramms Current QPS im MySQL-Dashboard korrigiert.
  • Unterstützt die Abfrage von Ablaufverfolgungsprotokollen zum Debuggen.
  • BanyanDB: Automatische Vervollständigung der Tag-Datenspeicherung und -Abfrage behoben.
  • Unterstützt Aggregationsoperatoren in PromQL-Abfragen.
  • Aktualisieren Sie die Quelleinheit für HTTP-Latenzmetriken kubernetes von ns auf ms.
  • Unterstützt BanyanDB-interne Stream-Abfrageausführungsverfolgung.
  • Behebung von Tippfehlern und fehlenden Ausdrücken in den Dashboards Elasticsearch, MySQL und RabbitMQ.
  • BanyanDB: Zipkin-Modul legt den Dienst als Entität fest, um die Abfrageleistung zu verbessern.
  • MQE: Überprüfen Sie den Metrikwert, bevor Sie eine Binäroperation durchführen, um die Robustheit zu verbessern.
  • Ersetzen Sie die Problemumgehung durch einen von Armeria unterstützten Kontextpfad.
  • Fügen Sie einen HTTP-Endpunkt-Wrapper zur Gesundheitsprüfung hinzu.
  • Erweitern Sie Armeria und transitive Abhängigkeiten.
  • BanyanDB: Wenn die Modellspalte bereits eine @BanyanDB.TimestampColumn ist, legen Sie @BanyanDB.NoIndexing fest, um die Indizes zu reduzieren.
  • BanyanDB: Stream-Sortierung nach time-Abfrage, interne Zeitreihen anstelle von index verwenden, um die Abfrageleistung zu verbessern.
  • Erhöhen Sie graphql-java auf 21.5.
  • Fügen Sie einen unbekannten Knoten hinzu, wenn die empfangene Peer-Adresse Kubernetes im aktuellen Cluster nicht bekannt ist.
  • Die gleichzeitige Erhöhung von CounterWindow verursachte NPE durch PriorityQueue
  • Korrigieren Sie das Formatieren des Endpunktnamens mit einer leeren Zeichenfolge.
  • Unterstützt asynchrone Abfragen für die zusammengesetzte GraphQL-Abfrage.
  • Reihenfolge der Endpunktliste nach Zeitstempel abfragen.
  • Unterstützt Sortierabfragen zu vom eBPF-Empfänger generierten Metriken.
  • Korrigieren Sie die Kompatibilität mit Grafana 11 bei Verwendung von label_values-Abfragevariablen.
  • Nacos unterstützt als Konfigurationsserver und Clusterkoordinator den Konfigurationskontextpfad.
  • Aktualisieren Sie das Endpunktnamenformat im eBPF Access Log Receiver auf <Method>:<Path>.
  • Fügen Sie Selbstbeobachtungsmetriken für den OpenTelemetry-Empfänger hinzu.
  • Unterstützt die Aggregation von Service-Level-Metriken, wenn der Pod-Kontext im eBPF Access Log Receiver fehlt.
  • Die Abfrage getGlobalTopology löste eine Ausnahme aus, wenn auf der angegebenen Ebene keine Dienste gefunden wurden.
  • Korrigieren Sie das fehlende vorherige Analyseergebnis im ALS k8s-mesh-Analysegerät.
  • Fix findEndpoint-Abfrage erfordert keyword bei Verwendung von BanyanDB.
  • Unterstützung für die Analyse der ztunnel-zugeordneten IP-Adresse und des mTLS-Modus im eBPF Access Log Receiver.
  • BanyanDB Java Client 0.7.0 anpassen.
  • Fügen Sie das Selbstobservability-Dashboard von SkyWalking Java Agent hinzu.
  • Fügen Sie die Komponenten-ID (5022) für das GoFrame-Framework hinzu.
  • Erhöhen Sie die Protobuf-Java-Abhängigkeiten auf 3.25.5.
  • BanyanDB: Unterstützung der Verwendung nativer Begriffssuche für keyword in den Abfragen findEndpoint und getAlarm.
  • BanyanDB: unterstützt TLS-Verbindung und -Konfiguration.
  • PromQL-Dienst: Abfrage API unterstützt RFC3399-Zeitformat.
  • Verbessern Sie die Leistung des OTEL-Metrik-Handlers.
  • PromQL-Dienst: Operator-Ergebnis behoben, bei dem das rangeExpression-Flag fehlt.
  • BanyanDB: Verwenden Sie TimestampRange, um die Abfrage „Ereignisse“ für BanyanDB zu verbessern.
  • Optimieren Sie die Tabelle network_address_alias, um die Anzahl der Indizes zu reduzieren.
  • PromQL-Dienst: Unterstützung des Operators für runde Klammern.
  • Support-Abfrage-Alarmmeldungs-Tag für die automatische Vervollständigung.

Benutzeroberfläche

  • Markieren Sie Schlüsselwörter im Suchprotokoll.
  • Fehler-URL im Browserprotokoll hinzufügen.
  • Fügen Sie ein SolonMVC-Symbol hinzu.
  • Cilium-Symbol und i18n für das Menü hinzugefügt.
  • Behebung der Diskrepanz zwischen der Einheit und der Berechnung des Widgets „Netzwerkbandbreitennutzung“ im Windows-Service-Dashboard.
  • Erstellen Sie maximal 20 Entitäten pro Abfrage in Dienst-/Instanz-/Endpunktlisten-Widgets.
  • Polnische Fehlerknoten im Trace-Widget.
  • Einführung des Flammendiagramms in die Trace-Profilierung.
  • Korrigieren Sie Dienste und Instanzen beim Ändern der Seitenzahlen.
  • Verbessern Sie Metrikabfragen, um das Öffnen von Seiten schneller zu gestalten.
  • Erweitern Sie Abhängigkeiten, um CVEs zu reparieren.
  • Fügen Sie eine Ladeansicht für die Initialisierungsseite hinzu.
  • Behebung eines Fehlers für Selektoren beim Klicken auf das Aktualisierungssymbol.
  • Gesundheitsprüfung im OAP-Backend korrigiert.
  • Fügen Sie die Dashboard-Weiterleitung Service, ServiceInstance, Endpoint zu den Topologien Kubernetes hinzu.
  • Paginierung für Dienst-/Instanzlisten-Widgets korrigiert.
  • Abfragen für Alarm-Tags hinzufügen.
  • Skywalking-Java-Agent-Selbstbeobachtbarkeitsmenü hinzufügen.

Dokumentation

  • Aktualisieren Sie die vom Zabbix-Receiver unterstützte Versionsbeschreibung.
  • Verschieben Sie die offiziellen Dashboard-Dokumente in die Marktplatz-Dokumente.
  • Fügen Sie Marktplatz-Einführungsdokumente im Menü quick start hinzu, um die Verwirrung beim Auffinden von Funktionsdokumenten zu verringern.
  • Windows-Metriken aktualisieren (Swap -> Virtueller Speicher)
