Projekt

  • Duplicate class found aufgrund des delombok-Ziels behoben.

OAP-Server

  • Korrigieren Sie die falsche Ebene der Metrik user error in der DynamoDB-Überwachung.
  • Der ElasticSearch-Speicher überprüft die Feldtypen nicht, wenn OAP im no-init-Modus ausgeführt wird.
  • Unterstützung für die Bindung des TLS-Status als Teil einer Komponente für die Diensttopologie.
  • Fehler bei der Komponenten-ID-Priorität behoben.
  • Komponenten-ID der Topologieüberlappung aufgrund von Fehlern in der Speicherschicht behoben.
  • [Breaking Change] Verbessern Sie den JDBC-Speicher durch Zusammenführen von Tabellen und Verwalten des tagesbasierten Tabellenrollens.
  • [Breaking Change] Sharding-MySQL-Implementierungen und -Tests werden entfernt, da wir standardmäßig über den tagesbasierten Rollmechanismus verfügen
  • Korrigieren Sie die otel k8s-cluster-Regel und fügen Sie eine Namespace-Dimension für die MAL-Aggregationsberechnung hinzu (Bereitstellungsstatus, Replikate der Bereitstellungsspezifikation).
  • Unterstützt die kontinuierliche Profilerstellungsfunktion.
  • Unterstützung beim Sammeln prozessbezogener Metriken.
  • Behebung: K8sRetag liest aufgrund einer möglichen Nichtübereinstimmung des Namensraums den falschen k8s-Dienst aus dem Cache.
  • [Breaking Change] Unterstützt Thread-übergreifendes Trace-Profiling. Die Datenstruktur und die Abfrage-APIs werden geändert.
  • Korrigieren Sie, dass in der PromQL-HTTP-Antwort API /api/v1/labels die Bezeichnung service fehlt.
  • Mögliches NPE bei der Initialisierung von IntList behoben.
  • Der PromQL-Ausdruck unterstützt die Analyse und enthält leere Beschriftungen in den geschweiften Klammern für die Metadatenabfrage.
  • Unterstützt die Alarmmetrik OP !=.
  • Die Support-Metrik-Abfrage gibt an, ob der Wert == 0 tatsächlich null oder keine Daten darstellt.
  • Korrigieren Sie NPE, wenn die nicht vorhandenen Serienindizes im ElasticSearch-Speicher abgefragt werden.
  • Unterstützt das Sammeln von Speicher-Buff-/Cache-Metriken bei der VM-Überwachung.
  • PromQL: Entfernen Sie leere Werte aus dem Abfrageergebnis. Korrigieren Sie den /api/v1/metadata-Parameter limit, der dazu führen kann, dass der Wert außerhalb des Bereichs liegt.
  • Unterstützt die Überwachung der Gesamtzahlmetriken von k8s StatefulSet und DaemonSet.
  • Unterstützt die Amazon API Gateway-Überwachung.
  • Aktualisieren Sie graphql-java, um cve zu reparieren.
  • Erhöhen Sie Kubernetes Java client.
  • Unterstützt die Redis-Überwachung.
  • Komponenten-ID für amqp, amqp-producer und amqp-consumer hinzufügen.
  • Unterstützt den No-Proxy-Modus für den AWS-Firehose-Empfänger
  • Erhöhen Sie Armeria auf 1.23.1
  • Unterstützt die Elasticsearch-Überwachung.
  • Korrigieren Sie, dass in der PromQL-HTTP-Antwort API /api/v1/series das service-Label fehlt, wenn die Metrik abgeglichen wird.
  • Unterstützt ServerSide TopN für BanyanDB.
  • Komponenten-ID für Jersey hinzufügen.
  • Entfernen Sie die OpenCensus-Unterstützung sowie die zugehörigen Codes und Dokumente als es geht unter.
  • Unterstützt die dynamische Konfiguration von searchableTracesTags
  • Unterstützt exportErrorStatusTraceOnly für den Export der Fehlerstatus-Trace-Segmente über den Kafka-Kanal
  • Komponenten-ID für Grizzly hinzufügen.
  • Mögliches NPE im Zipkin-Empfänger behoben, wenn beim Span einige Felder fehlen.
  • Filtern Sie unbekannte_Cluster-Metrikdaten heraus.
  • Unterstützt die RabbitMQ-Überwachung.
  • Unterstützt die langsame Protokollsammlung Redis.
  • Beheben Sie den Datenverlust bei der Abfrage des kontinuierlichen Profiling-Aufgabendatensatzes.
  • Passen Sie die kontinuierliche Profiling-Aufgabenabfrage GraphQL an.
  • Unterstützt Metrics Query Expression (MQE) und ermöglicht Benutzern die Durchführung einfacher Berechnungen in der Abfragephase über den Ausdruck.
  • Veraltetes Metrikabfrage-v2-Protokoll.
  • Veraltetes Datensatzabfrageprotokoll.
  • Komponenten-ID für go-redis hinzufügen.
  • OpenSearch 2.8.0 zum Testfall hinzufügen.
  • Modul ai-pipeline hinzufügen.
  • Unterstützt die HTTP-URI-Formatierung über ai-pipeline zur Mustererkennung.
  • Neue HTTP-URI-Gruppierungs-Engine mit Benchmark hinzufügen.
  • [Breaking Change] Verwenden Sie die neue HTTP-URI-Gruppierungs-Engine, um den alten Regex-basierten Mechanismus zu ersetzen.
  • Unterstützt sumLabeled in MAL.
  • Von kubernetes-client/Java nach Fabric8 client migrieren.
  • Die von Envoy ALS generierten Beziehungsmetriken berücksichtigen HTTP-Statuscodes >= 400. Es liegt ein Fehler auf der client-Seite vor.
  • Fügen Sie ein Nachrichtenfeld für die Ursache hinzu, wenn Sie eine Aufgabe zur kontinuierlichen Profilerstellung abfragen.

Benutzeroberfläche

  • Zurücksetzen: cpm5d-Funktion. Diese Funktion wurde im Backend deaktiviert.
  • Fix: Benachrichtigung über Verbindungsunterbrechungen in der Topologie.
  • Topologie-Widget umgestalten, um es hierarchischer zu gestalten.
    1. Wählen Sie User als ersten Knoten.
    2. Wenn der Knoten User nicht vorhanden ist, wählen Sie den Knoten mit der höchsten Auslastung (der die meisten Anrufe von allen hat).
    3. Führen Sie einen Fließvorgang von links nach rechts durch.
    4. Listen Sie auf derselben Ebene die Knoten von oben nach unten in alphabetischer Reihenfolge auf.
  • Korrigieren Sie die Filter-ID, wenn die ReadRecords-Metrik mit der Ablaufverfolgung verknüpft ist.
  • AWS API Gateway-Menü hinzufügen.
  • Trace-Profiling-Protokoll ändern.
  • Redis-Menü hinzufügen.
  • Datentypen optimieren.
  • Unterstützung des isEmptyValue-Flags für Metrikabfragen.
  • elasticsearch-Menü hinzufügen.
  • [UI-Vorlagen vor dem Upgrade bereinigen] Legen Sie showSymbol: true fest und sorgen Sie dafür, dass der Datenpunkt im Liniendiagramm angezeigt wird. Bitte bereinigen Sie den Index ui_template im Speicher elasticsearch oder die Tabelle im JDBC-Speicher.
  • [UI-Vorlagen vor dem Upgrade bereinigen] UI-Vorlagen: Vereinfachen Sie den Metriknamen mit der Bezeichnung.
  • MQ-Menü hinzufügen.
  • Jeysey-Symbol hinzufügen.
  • Fix: Endpunkt- und Instanzselektoren mit URL-Parametern korrekt festlegen.
  • Erhöhen Sie die Abhängigkeiten der Versionen Icons-vue 1.1.4, Element-Plus 2.1.0, Nanoid 3.3.6, Postcss 8.4.23
  • Unterstützung für das Protokollprotokoll OpenTelemetry hinzugefügt.
  • [Breaking Change] Der Konfigurationsschlüssel enabledOtelRules wurde in enabledOtelMetricsRules umbenannt und Die entsprechende Umgebungsvariable wird in SW_OTEL_RECEIVER_ENABLED_OTEL_METRICS_RULES umbenannt.
  • Grizzly-Symbol hinzufügen.
  • Fix: Fehler bei der Anzeige der Instanzlistendaten.
  • Fix: topN-Typ auf Zahl setzen.
  • Unterstützt Metrics Query Expression (MQE) und ermöglicht Benutzern die Durchführung einfacher Berechnungen in der Abfragephase über den Ausdruck.
  • Erhöhen Sie die Zipkin-UI-Abhängigkeit auf 2.24.1.
  • Vite auf 4.0.5 erhöhen.
  • Wenden Sie MQE auf die UI-Vorlagen der Ebenen General und Virtual-Database an.

Dokumentation

  • Profiling-bezogene Dokumentationen hinzufügen.
  • SUM_PER_MIN zur MAL-Dokumentation hinzufügen.
  • Machen Sie die protokollbezogenen Dokumente klarer und einfacher, um weitere Formate zu unterstützen.
  • Aktualisieren Sie die Dokumente zur Clusterverwaltung und zur erweiterten Bereitstellung.
