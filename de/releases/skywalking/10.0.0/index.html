Mit BanyanDB 0.6 im Cluster-Modus ausführen

Projekt

  • Unterstützt Java 21-Laufzeit.
  • Unterstützt das oap-java21-Image für die Java 21-Laufzeit.
  • Aktualisieren Sie die OTEL collector-Version in allen e2e-Tests auf 0.92.0.
  • CI macOS Runner auf m1 umstellen.
  • Aktualisieren Sie den PostgreSQL-Treiber auf 42.4.4, um CVE-2024-1597 zu beheben.
  • Entfernen Sie CLI(swctl) aus dem Bild.
  • Entfernen Sie die Variable CLI_VERSION aus dem Makefile-Build.
  • Fügen Sie BanyanDB zum docker-compose-Schnellstart hinzu.
  • Steigern Sie Armeria, Jackson, netty, Jetcd und grpc, um CVEs zu reparieren.
  • Erhöhen Sie BanyanDB Java Client auf 0.6.0.

OAP-Server

  • Fügen Sie den Parameter layer zur globalen Topologie-GraphQL-Abfrage hinzu.
  • Fügen Sie die Funktion is_present in MQE hinzu, um zu überprüfen, ob die Listenmetriken einen Wert haben oder nicht.
  • Entfernen Sie unangemessene Standardkonfigurationen für den Thread-Executor gRPC.
  • Entfernen Sie die gRPCThreadPoolQueueSize (SW_RECEIVER_GRPC_POOL_QUEUE_SIZE)-Konfiguration.
  • Erlauben Sie den Ausschluss von ServiceEntries in einigen Namespaces, wenn Sie nach ServiceEntries als endgültige Auflösungsmethode suchen Dienstmetadaten.
  • Richten Sie die Länge der Quell- und Ziel-IDs in den Beziehungseinheiten Dienst, Instanz, Endpunkt und Prozess auf 250 ein 200).
  • Unterstützt die Erstellung von Dienst-/Instanzhierarchien und Abfragen.
  • Ändern Sie das Zeichenfolgenfeld im Elasticsearch-Speicher vom Typ Schlüsselwort in den Typ Text, wenn eine Länge von mehr als 32766 festgelegt ist.
  • [Break Change] Ändern Sie das Konfigurationsfeld von ui_template und ui_menu im Elasticsearch-Speicher vom Typ Schlüsselwort in Text.
  • Unterstützen Sie den automatischen Abgleich der Servicehierarchie. Fügen Sie die Ebenenbeziehungen für den automatischen Abgleich (oben -> unten) wie folgt hinzu:
    • MESH -> MESH_DP

    • MESH_DP -> K8S_SERVICE
    • ALLGEMEIN -> K8S_SERVICE
  • Fügen Sie standardmäßig das Suffix namespace für K8S_SERVICE_NAME_RULE/ISTIO_SERVICE_NAME_RULE und metadata-service-mapping.yaml hinzu.
  • Ermöglicht die Verwendung eines dedizierten Ports für den ALS-Empfänger.
  • Protokollabfrage nach TraceId in JDBCLogQueryDAO korrigiert.
  • Unterstützt das eBPF-Zugriffsprotokollprotokoll des Handlers.
  • SumPerMinFunctionTest-Fehlerfunktion behoben.
  • Entfernen Sie unnötige Anmerkungen und Funktionen aus den Messgerätfunktionen.
  • Fügen Sie die Funktionen max und min für MAL-Downsampling hinzu.
  • Beheben Sie den kritischen Fehler unkontrollierter Speicherkosten von TopN-Statistiken. Ändern Sie den TopN-Gruppenschlüssel von StorageId in entityId + timeBucket.
  • Fügen Sie die automatischen Matching-Layer-Beziehungen der Service-Hierarchie (oben -> unten) wie folgt hinzu:
    • MYSQL -> K8S_SERVICE
    • POSTGRESQL -> K8S_SERVICE
    • SO11Y_OAP -> K8S_SERVICE
    • VIRTUAL_DATABASE -> MYSQL
    • VIRTUAL_DATABASE -> POSTGRESQL
  • Golang als unterstützte Sprache für AMQP hinzufügen.

    • NGINX -> K8S_SERVICE

  • Golang als unterstützte Sprache für RocketMQ hinzufügen.

    • ROCKETMQ -> K8S_SERVICE
    • VIRTUAL_MQ -> ROCKETMQ
  • ServiceInstance in-Abfrage behoben.
  • Modell /api/v1/status/buildinfo für PromQL API.
  • Überprüfen Sie, ob die Tabelle im JDBC-Speicher-Plugin vorhanden ist.
  • Korrigieren Sie die Strategie für den tagesbasierten Tabellen-Rolling-Zeitbereich im JDBC-Speicher.
  • Fügen Sie die Konfiguration maxInboundMessageSize (SW_DCS_MAX_INBOUND_MESSAGE_SIZE) hinzu, um die maximale Größe eingehender Nachrichten von DCS zu ändern.
  • Service-Schicht beim Erstellen von Ereignissen im EventHookCallback behoben.

  • Fügen Sie die automatischen Matching-Layer-Beziehungen der Service-Hierarchie (oben -> unten) wie folgt hinzu:
    • RABBITMQ -> K8S_SERVICE
    • VIRTUAL_MQ -> RABBITMQ
  • Entfernen Sie den Column#-Funktionsmechanismus im Kernel.

    • PULSAR -> K8S_SERVICE
    • VIRTUAL_MQ -> PULSAR
  • Golang als unterstützte Sprache für Kafka hinzufügen.
  • Unterstützung für die Anzeige der von OAP und UI überwachten Portdienste während des Serverstarts.
  • Refactor-Datengenerator zur Unterstützung der Generierung von Metriken.

    • MQE: – Unterstützt die Abfrage mehrerer Labels (Name und Wert), anstatt _ als anonymen Labelnamen zu verwenden.
      • aggregate_labels-Funktionsunterstützungsaggregation nach bestimmten Labels. – Die Funktion relabels erfordert ein Ziellabel und benennt den Labelnamen und -wert um.

  • Stärken Sie Kafka, um CVE zu beheben.
  • Korrigieren Sie NullPointerException in der Istio ServiceEntry-Registrierung.
  • Entfernen Sie unnötige componentIds als Serien-ID in den Entitäten ServiceRelationClientSideMetrics und ServiceRelationServerSideMetrics.

  • Ungenauigkeiten bei den Nginx-Dienstmetriken beheben.

  • Korrigieren Sie die ungenaue Hierarchie der RabbitMQ-Server-Überwachungsmetriken.
  • Korrigieren Sie ungenaue MySQL/MariaDB-, Redis-, PostgreSQL-Metriken.
