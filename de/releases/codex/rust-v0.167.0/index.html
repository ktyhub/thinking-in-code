Codex rust-v0.167.0

Neue Funktionen

  • Öffnen Sie das Agent Command Center mit codex agents --no-daemon. Das Command Center und die Sitzungsauswahl markieren jetzt ungelesene Ergebnisse (#58238, #58239, #58263, #58264). – Wechseln Sie über die Terminal-Sitzungsauswahl zwischen verbundenen Backends und behalten Sie Ihre Entwürfe beim Wechsel (#58280, #58457). – Zeigen Sie beim Verfassen auf unterstützten Terminals eine Vorschau lokaler Bildanhänge an und öffnen Sie angezeigte lokale Bilder aus clickable-Transkriptpfaden (#58261, #58446).
  • Unter „Auf andere Weise anmelden“ finden Sie die Optionen für den API-Schlüssel und den Cloud-Anbieter. Aktivieren Sie gcp_setup_wizard, um Google Cloud Vertex AI mit Anwendungs-Standardanmeldeinformationen oder einer Anmeldeinformationsdatei einzurichten (#57857, #58427). – Aktivieren Sie die Proxy-Einstellungen des macOS- oder Windows-Systems von /experimental (#58157). – Erweitern Sie Patchdetails direkt im Transkript, während eine Genehmigungsaufforderung geöffnet ist (#58281).

Fehlerbehebungen

  • Gespeicherte Chats bleiben sichtbar, auch wenn Sie den Modellanbieter wechseln. Wenn ein Chat nicht fortgesetzt werden kann, können Sie dessen Transkript lesen und eine bearbeitbare Aufforderung vorbereiten, um in einem neuen Chat fortzufahren (#58202). – Ctrl+L löscht die Terminalanzeige, während frühere Nachrichten über Ctrl+T verfügbar bleiben (#58266). – Durch das Löschen von Text, der ein führendes ! freilegt, bleibt ein normaler Entwurf im Chat-Modus (#58412).
  • Netzwerkgenehmigungsaufforderungen werden geschlossen, wenn ihre Anforderungen enden. Gleichzeitige Anfragen an denselben Endpunkt rufen nacheinander auf (#58350, #58351). – Lange V3-Konversationen in Echtzeit speichern abgeschlossene Reden im Chat-Verlauf, wenn das Transkript wächst (#58221). – Die automatische Kontextkomprimierung berücksichtigt jetzt die beibehaltene Ausgabe von fehlgeschlagenen Antworten und Antworten mit fehlenden Token-Nutzungsdaten (#58404).

Dokumentation

– Die App-Server-README-Datei behandelt verwaltete Netzwerkeinschränkungen gemäß den Befehlsregeln [permissions.network] und prompt-user, die eine erneute menschliche Genehmigung erfordern (#58045, #58182). – Der openai-docs-Skill empfiehlt den dokumentierten Ersatz, wenn von einem veralteten Modell migriert wird (#58134).

Aufgaben

– DotSlash-Manifeste verweisen jetzt auf die mit der Version gelieferten Cargo-Pakete (#58717, #58757). – Linux-MUSL-Builds verwenden weniger Allocator-Arenen, um Leerlaufspeicher nach dem Entladen von Konversationen zu reduzieren (#58399).
