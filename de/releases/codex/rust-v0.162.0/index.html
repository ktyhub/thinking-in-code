Codex rust-v0.162.0

Neue Funktionen

– Fügen Sie Tools zum Erstellen und Auflisten verwalteter Git-Arbeitsbäume aus trusted-lokalen Projekten hinzu, wenn die Arbeitsbaumfunktion aktiviert ist. (#50148)

  • Aufgaben im Agent Command Center mit p anheften und in einer gemeinsamen angehefteten Gruppe behalten, sofern dies vom Server unterstützt wird. (#51500)
  • Navigieren und kopieren Sie Transkriptblöcke mit /copy, verwenden Sie Ctrl+Insert zum Kopieren von Auswahlen und optimieren Sie das Scrollen mit dem Mausrad mit tui.mouse_scroll_speed. (#50434, #50215, #50209)
  • Machen Sie URLs cli in Genehmigungsheadern, Fragen, MCP-Eingabeaufforderungen, Warnungen, Bannern und Verifizierungsaufforderungen aktivierbar, auch wenn Links über Zeilen hinweg umbrochen werden. (#51439, #51449, #51450, #51451, #51452, #51458)
  • Konfigurieren Sie Live-Webzugriff und Remote-Komprimierungsfunktionen für benutzerdefinierte Responses-kompatible Modellanbieter. (#50459)
  • Fügen Sie JavaScript-Helfer zum Streamen von Versprechensergebnissen hinzu, sobald diese vorliegen, sowie optionale Tool-Suche nach Rangfolge im Codemodus. (#51126, #51209)

Fehlerbehebungen

– Respektieren Sie die Standardeinstellungen für Servermodell und Begründungszusammenfassung für neue TUI-Threads und behalten Sie gleichzeitig explizite Startüberschreibungen bei. (#50013, #50811, #50913)

  • Bestehende CRLF-Zeilenenden in apply_patch-Updates beibehalten, ohne dass eine Einwilligung erforderlich ist. (#51203) – Korrigieren Sie den Linux-Sandbox-Start mit mehreren verweigerten Dateien, lehnen Sie beschreibbare ausführbare Sandbox-Konstruktionsdateien ab und verhindern Sie, dass die Ripgrep-Konfiguration Deny-Glob-Masken schwächt. (#50059, #51211, #51407, #51527) – Stellen Sie unter Windows 10 den normalen Dateizugriff über Laufwerksbuchstaben wieder her und passen Sie die temporären Berechtigungen der Windows-Sandbox an die Umgebung des untergeordneten Prozesses an. (#51511, #51512)
  • Berücksichtigen Sie den Server-Retry-After-Hinweis für wiederholbare Antworten und WebSocket-Fehler. (#50418, #51440) – Korrektur der Überprüfung der Archivprüfsumme bei der Installation über Windows PowerShell mit vorhandenen PowerShell 7-Modulpfaden. (#51257)

Aufgaben

– Veröffentlichen Sie ein signiertes PowerShell-Installationsprogramm mit Windows-Versionen. (#51158)

  • Verhindern Sie, dass ältere stabile Versionen und Vorabversionen neuere stabile Download-Ziele oder Installer-Aliase ersetzen. (#51186, #51425)
