codex rust-v0.165.0

Diese Seite ist maschinell übersetzt. Maßgeblich ist der englische Originaltext.

Codex rust-v0.165.0

Neue Funktionen

– Ein integrierter Google Cloud Vertex AI-Anbieter wurde hinzugefügt, konfiguriert mit model_provider = "gcp". (#56265)

  • GPT-6.1 Terra zu den Modellkatalogen hinzugefügt. (#57337) – Der Sitzungsauswahl und der Verzeichnisgruppierung im Agent Command Center wurde ein Repository-Filter hinzugefügt, der das Navigieren in Sitzungen über verknüpfte Arbeitsbäume hinweg erleichtert. (#56308)
  • Experimentelle angehängte Thread-Forks zum App-Server API hinzugefügt. (#56351) – Änderungen des Argumentationsaufwands während eines Gesprächs sind für unterstützte Modelle standardmäßig aktiviert. (#56163) – Speicher v2 standardmäßig für neue Profile aktiviert und Unterstützung für den Import von Speicher von externen Agenten hinzugefügt. (#56211, #56414)

Fehlerbehebungen

– Neue TUI-Sitzungen wurden korrigiert, um den standardmäßigen Genehmigungsprüfer des Servers zu berücksichtigen, wenn keine explizite Überschreibung bereitgestellt wird. (#56090)

  • Die TUI-Einstellungen blieben bearbeitbar und sofort anwendbar, wenn die Ausführungseinstellungen ungültig sind. (#56091) – Remote-MCP-Tool-Anfragen wurden abgebrochen, wenn ihre lokalen Antwort-Futures gelöscht wurden. (#56132) – Es wurde verhindert, dass in der Warteschlange befindliche Agentennachrichten nach einer Unterbrechung oder einem Wechsel in den Planmodus ihre Arbeit wieder aufnehmen. (#56330) – Wiederholungsversuche gestoppt, wenn ein Anbieter meldet, dass ein Modell nicht gefunden wurde, wobei die Fehlermeldung erhalten bleibt. (#56445) – Es wurde eine Lücke bei der Validierung der Marktplatz-URL geschlossen, die es Git ermöglichen konnte, eine Verbindung zu einem anderen Host herzustellen als dem, der anhand zulässiger Muster überprüft wurde. (#56263)
