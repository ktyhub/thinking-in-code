codex rust-v0.169.0

Release Veröffentlicht13. Nov. 2026 Quelleopenai/codex Englisches Original

Diese Seite ist maschinell übersetzt. Maßgeblich ist der englische Originaltext.

Codex rust-v0.169.0

Neue Funktionen

– Der Opt-in-Terminal-Arbeitsbereich unterstützt mehrere Side-Chat-Registerkarten. Wechseln Sie mit der Tastatur oder der Maus zwischen ihnen und öffnen Sie gespeicherte lokale Nebenchats nach dem Neustart von Codex erneut. (#59784, #60152, #60181)

  • Durchsuchen Sie ältere Aufgaben im Agent Command Center nach Name, Eingabeaufforderungsvorschau oder Arbeitsverzeichnis. (#60286)
  • Aktivieren Sie im Vollbild-Transkript die Option Details zum Zug ausblenden, um die abgeschlossene Aktivität unter jeder Eingabe einzublenden und gleichzeitig die Antworten sichtbar und die Tool-Ausgabe durchsuchbar zu halten. (#60554, #60555, #60556, #60557)
  • Fügen Sie benutzerdefinierte Modellanbieter über das Terminal hinzu oder bearbeiten Sie sie. Wenn das benutzerdefinierte Gateway-Onboarding aktiviert ist, können Sie während der Anmeldung einen Anbieter erstellen und einen Gerätecode für unterstützte Gateways über SSH oder ohne lokalen Browser verwenden. (#59779, #60009, #60186, #60486, #60662)
  • Drücken Sie Ctrl+S im Terminal-Berichtseditor, um eine Diagnose-ZIP-Datei lokal zu speichern, auch wenn Uploads deaktiviert sind. (#60542)
  • Mit der optionalen Cloud-Verbindung unter macOS und Linux können Sie Bilder senden, ein Modell und einen Argumentationsaufwand auswählen und Cloud-Konversationen vom Terminal aus archivieren oder wiederherstellen. (#59828, #60061, #60635, #60651)

Fehlerbehebungen

– codex exec hält die Projektkonfiguration und MCP-Server in untrusted-Verzeichnissen deaktiviert, auch mit --sandbox workspace-write. Verwenden Sie --trust mit codex exec oder codex review, um das Projekt trust explizit zu speichern. (#60041)

  • Ja, Kontext löschen und implementieren übergibt jetzt den vollständig genehmigten Plan an die neue Sitzung und hält die aktuelle Sitzung offen, wenn die Übergabe fehlschlägt. (#60763) – Die Windows-Sandbox-Verarbeitung für zitierte cmd.exe-Pfade und für PowerShell-Sitzungen, deren Arbeitsverzeichnis ein nicht lesbares übergeordnetes Verzeichnis hat, wurde korrigiert. (#60624, #60647)
  • Eingefügte Bilder unter macOS behalten ihre beabsichtigte Ausrichtung und verwenden native PNG- oder JPEG-clipboard-Daten, sofern verfügbar. (#60455) – Das Terminal bleibt nicht länger damit beschäftigt, auf MCP-Server zu warten, die ein gemeinsam genutzter App-Server nicht gemeldet hat. (#60280, #60622)
  • Unterbrochene Runden werden jetzt sauber geschlossen und verzögerte Abbrüche oder Dateigenehmigungsstornierungen unterbrechen eine spätere Runde nicht mehr. (#59910, #60700)

Dokumentation

– Der openai-docs-Skill wurde aktualisiert, um sich auf Codex- und ChatGPT-Arbeitsfragen und die erstmalige Einrichtung von API zu konzentrieren, mit spezieller Anleitung für die Konfiguration von Codex im gesamten Team. (#59944, #59949) – Dokumentiert, wie der App-Server clients Modelle auflisten oder ein Gateway für einen konfigurierten Anbieter autorisieren kann, ohne den Standardanbieter zu ändern. (#59776, #59819)

Aufgaben

– Das gebündelte SQLite wurde auf 3.54 aktualisiert, um Korrekturen für Write-Ahead-Protokolle zu ermöglichen. (#60432)

  • Plugin-Marktplatz-Upgrades können bereits auf der Festplatte befindliche Git-Objekte wiederverwenden, wodurch wiederholte Downloads reduziert werden. (#60528)
