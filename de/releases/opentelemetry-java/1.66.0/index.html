Diese Seite ist maschinell übersetzt. Maßgeblich ist der englische Originaltext.

opentelemetry-java v1.66.0

API

  • Korrigieren Sie Baggage.fromContext() und Baggage.fromContextOrNull(), um einen null-Kontext zu verarbeiten (#8667)
  • W3C-Gepäckmetadaten nicht prozentual kodieren (#8682)
  • Korrigieren Sie ArrayIndexOutOfBoundsException in OtelEncodingUtils für ungültige Hexadezimalzeichen (#8748)

SDK

Spuren

  • Verarbeitete Spannen aufzeichnen, bevor der Export abgeschlossen ist, und neue Spannen beim Herunterfahren in der SpanProcessor-Selbstbeobachtungsinstrumentierung ablehnen (#8735)

Metriken

  • Verbessern Sie die Leistung expliziter Bucket-Histogrammkonflikte (#8717)

Protokolle

  • Verarbeitete Protokolle aufzeichnen, bevor der Export abgeschlossen ist, und neue Protokolle beim Herunterfahren in der LogRecordProcessor-Selbstbeobachtungsinstrumentierung ablehnen (#8698)

Exporteure

  • OTLP: Retry-After in OTLP-HTTP-Absendern berücksichtigen (#8633)
  • OTLP: setEnabledProtocols-Option zu OTLP-HTTP-Exporter-Buildern hinzugefügt (#8610)
  • OTLP: Vermischung von keyManager und sslContext in TlsConfigHelper ablehnen (#8710)
  • OTLP: Fix OkHttpGrpcSender mTLS bei Verwendung des Plattform-Standardspeichers trust (#8758)
  • OTLP: Instrumentierung von Exporter-Anfragen in JdkHttpSender unterdrücken (#8757)
  • OTLP: Akzeptieren Sie RFC 1123-Hostnamen in EndpointUtil.validateEndpoint für OkHttp-Absender (#8746)
  • OTLP: Beziehen Sie die Anzahl der betroffenen Elemente in die Exporter-Fehlerprotokollierung ein (#8780)
  • OTLP: toString zu OtlpJsonLogging{Span,Metric,LogRecord}Exporter hinzufügen (#8725)
  • OTLP-Profile: JFR-Exportbeispiel verbessern und LinkData-Nullelement-Handhabung an die Spezifikation anpassen (#8349)
  • Prometheus: Standard-Hostprotokollwarnung in PrometheusHttpServerBuilder entfernen (#8679)
  • Prometheus: UCUM-Byte-Einheitenkonvertierungen an der Spezifikationstabelle ausrichten (#8752)

Erweiterungen

  • BREAKING Deklarative Konfiguration: Benennen Sie generierte Modell-POJO-Setter von with<Prop> in set<Prop> um (#8742)
  • Deklarative Konfiguration: Experimentelle Eigenschaften für stabile APIs in generierten Modell-POJOs auflösen (#8654)
  • Deklarative Konfiguration: Invertierte scope_info_enabled- und target_info_enabled-Flags im Prometheus-Komponentenanbieter behoben (#8750)
  • Deklarative Konfiguration: Unterstützung von output_stream in otlp_file/development (#8676)
  • Inkubator: toString zu ComposableAnnotatingSampler hinzufügen (#8645)

Projekttools

  • zizmor-Ergebnisse in GitHub-Aktionsworkflows beheben (#8592)
