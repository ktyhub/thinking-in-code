AionUi v2.1.46

Highlights

Antigravitationsunterstützung

– Googles Antigravity (agy CLI) ist jetzt ein vollständig unterstützter integrierter Agent. Zuvor konnte es ausgewählt werden, hat aber nichts bewirkt – es wurde keine Chat-Oberfläche angezeigt und die erste Nachricht wurde nie zugestellt. Er läuft jetzt wie jeder andere Agent über die ACP-Chatoberfläche.

Nachrichtenankerschiene

  • Lange Konversationen erhalten eine Nachrichtenankerleiste am linken Rand des Chatbereichs: ein Häkchen pro Benutzernachricht, bewegen Sie den Mauszeiger, um eine Vorschau dieser Runde anzuzeigen, click, um direkt dorthin zu springen. Eine Lupe am Kopf der Schiene bietet der Konversationssuche einen zweiten, besser sichtbaren Einstiegspunkt.

Explorer im Ordner anzeigen

  • Klicken Sie mit der rechten Maustaste auf eine beliebige Datei im Explorer, um sie in Ihrem Systemdateimanager anzuzeigen (nur Desktop).

Start- und Update-Zuverlässigkeit

– Ein langsamer Backend-Start wird nicht mehr fälschlicherweise als fehlerhafte Installation gemeldet. Zuvor konnte es bei einer Zeitüberschreitung der Integritätsprüfung dazu kommen, dass ein blockierender Dialog „Neu installieren/Antivirus überprüfen“ angezeigt wurde, obwohl das Backend aktiv war und zuhörte – irreführende Ratschläge für ein Problem konnten durch eine Neuinstallation nicht behoben werden. – Auf Systemen, auf denen das Dateiüberwachungskontingent des Betriebssystems erschöpft ist (üblich bei ARM Linux), wird das Backend jetzt ordnungsgemäß heruntergefahren, anstatt dass es nicht mehr startet, und die Benutzeroberfläche gibt nicht mehr die Schuld an einer unvollständigen Installation.

  • Installationsintegritätsfehler, die sich bereits selbst behoben haben, werden vor der Alarmierung abgeglichen, sodass Sie nicht über ein Problem gewarnt werden, das nicht mehr besteht.
  • Bei der manuellen „Nach Updates suchen“ wird das CDN-Kanalmanifest jetzt als autorisierend behandelt, sodass die Prüfung auch dann funktioniert, wenn GitHub API nicht erreichbar ist.

Korrekturen und Verbesserungen

– Durch das Öffnen von Dateien aus dem Explorer wird das Multi-Tab-Verhalten im Vorschaufenster wiederhergestellt, anstatt den aktuellen Tab zu ersetzen.

  • Beim ersten Zug eines CLI-Agenten wird nicht mehr fälschlicherweise das Aionrs-Anbietermodell verwendet.

Engine-Updates (AionCore v0.1.56 → v0.1.57)

– Antigravity (agy CLI) als direkter CLI-Agent hinzugefügt – die Backend-Hälfte der oben genannten Unterstützung.

  • Hintergrundarbeit ist jetzt sichtbar. Workflows, Hintergrund-Bash-Befehle und Hintergrund-Task-Subagenten sorgten früher dafür, dass eine Claude-Konversation völlig stumm blieb – ein 17-minütiger Workflow zeigte während seines gesamten Flugs nichts an. Sie streamen jetzt Live-Fortschrittskarten und die Ergebnisse werden außerhalb der Runde übermittelt, anstatt eine unaufgeforderte Runde auszulösen.
  • Ein Abbruch, der eintrifft, während der Agent noch an der Reihe ist, wird jetzt angewendet, anstatt verworfen zu werden. – Tool-Unterprozesse, die ihrer Prozessgruppe entkommen, werden jetzt geerntet, und vorübergehende Fehler, die die gebündelte Node-Laufzeit aktivieren, werden erneut versucht, anstatt als schwere Fehler aufzutauchen. – Windows-Pfadausgaben verlieren nicht mehr das wörtliche Präfix \\?\. – Die Vorreparatur der Datenbankmigration deckt jetzt alle Startpunkte vor 030 ab und erweitert so den Schutz vor Upgrades, die den Start blockieren.
