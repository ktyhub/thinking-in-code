5.3.0 (16.09.2019)

Voraussichtliche Veröffentlichung von DevTools in Chrome 79 (Dezember 2019)

Neue Mitwirkende!

Vielen Dank an unsere neuen Mitwirkenden @alabiaga, @olore, @letanure und @mfriesenhahn!

Kern

  • Verweisen Sie auf Prüfbeschreibungen auf neue web.dev Lighthouse-Dokumente (#9538, #9539, #9084, #9537)
  • Konstanten: Standard maxWaitForFcp auf 30s erhöhen (#9509)
  • Schriftgröße: Stildeklaration von Typattributen erfassen (#9414)
  • Gather-Runner: schlägt nur bei Interstitials fehl, die den mainRecord unterbrechen (#9576)
  • Lightwallet: Pfadeigenschaft zu budget.json hinzufügen (#9453)
  • SEO: Portugiesisch beim link-text-Audit unterstützen (#9446)
  • Start-URL: Bleiben Sie für die gesamte Dauer von offlinePass offline (#9451)
  • Third-Party-Summary: Auswirkungen auf die Blockierungszeit hinzufügen (#9486)
  • Tracehouse: Trace-Ereignisse nach Verschachtelungsreihenfolge sortieren (#9230)
  • source-maps-Sammler hinzufügen (#9101)
  • ungenutztes CSS: Erlauben Sie bis zu 10 KB ungenutztes CSS pro Datei (#9479)

CLI

  • Prüfkategorien im Hilfetext auflisten (#9399)

Clients

  • devtools: SVG mit zusammenklappbarer Breite in Flexbox behoben (#9602)
  • devtools: Testbefehl aktualisieren, um nur .js-Dateien auszuführen (#9532)
  • Proto: channel nicht aus configSettings filtern (#9554)
  • Viewer: Veraltete Polyfills entfernen (#9553)
  • Proto: Import-Hooks aktualisieren, Zeilenlänge beachten (#9595)

Abt

  • chrome-launcher: Update auf 0.11.2 (#9515)
  • details-element-polyfill: Update auf 2.4.0 (#9552)
  • jsonlint-mod: Update auf 1.7.5 (#9465)
  • Transitive Deps aktualisieren (#9670)

Dokumente

  • Defekten Plugin-Beispiellink reparieren (#9524)
  • Lightwallet: Link zum Repo budget.json hinzufügen (#9579)

I18n

  • Übersetzungen aus tc/ importieren (#9577, #9620, #9454)
  • registerLocaleData()-Methode hinzufügen (#9638)
  • aria-required-children-Titel neu schreiben (#9590)
  • pwa-page-transitions-Beschreibung umformulieren (#9615)
  • Überschüssige Platzhalter-Ersatzwerte auslösen (#9580)
  • Übersetzte Nachrichten entfernen, wenn sich ICU-Argumente ändern (#9598)
  • bessere Typen für intl-messageformat verwenden (#9570)
  • Code-Spans zur uses-rel-preconnect-Beschreibung hinzufügen (#9568)
  • Fehler in Skripten zum Importieren von Gebietsschemas beheben (#9621)
  • Benutzerdefinierte formatierte ICU innerhalb von Pluralformen korrigiert (#9460)
  • capitalize robots.txt displayValue (#9567)
  • Link zu cldr parentLocales hinzufügen (#9520)
  • PWA-Audits in das i18n-System verschieben (#9105)
  • Verwenden Sie den TypeScript-Compiler, um UIStrings zu sammeln (#9487)
  • Typnamen an Dokumenten ausrichten (#9461)
  • Platzhalterunterstützung erweitern (#9114)
  • td-headers-attr-Titel neu schreiben (#9587)
  • Intl Polyfill verbessern und in Util verwenden (#9584)

Bericht

  • Dropdown-Menü an ARIA-Aktionsmenü-Schaltflächenmuster anpassen (#9433)
  • Drop-Down-Logik in eine separate Klasse verschieben (#9564)
  • obere Leiste: Überlaufende URL beheben (#9497)
  • Viewer: Option zum Laden vom PSI API hinzugefügt (#9546)
  • Viewer: Favicon-Tippfehler behoben (#9629)
  • Verwenden Sie kein unnötiges Monospace (#9626)
  • Problemumgehung für PWA-Abzeichenflimmern für Chrome entfernen (#9636)
  • UTM-Parameter zu web.dev-Links hinzufügen (#9555)
  • Favicon auf neues Logo aktualisieren (#9591)
  • json ohne Stil rendern (anstatt zu werfen), wenn LHR einen unbekannten Detailtyp enthält (#9557)

Tests

  • Travis zu Xenial migrieren, um moderne Chrome-Unterstützung zu erhalten (#9654)
  • Fixtures: Relativen Pfad auf der statischen Server-404-Seite verwenden (d0e5c58)
  • Bericht: axe-core-Validierung der Berichtsausgabe hinzufügen (#9421)
  • Indexseite für statischen Server hinzufügen (#9541)
  • Smokehouse: Mime-Typen + richtige Kodierung für Antwortschreiben verwenden (#9542)
  • cli-Tests bis zu dreimal in Appveyor wiederholen (#9512)
  • Vereinfachen Sie die Bereitstellung von zone.js (#9672)

Sonstiges

  • Kommentar zum Unterschied zwischen document.write()-Audit und Intervention hinzufügen (#9644)
  • collect-strings umgestalten, um glob zu verwenden und unter Windows zu arbeiten (#9406)
  • Übersehene yarn.lock-Kreuzung zuschneiden und Abhängigkeiten deduplizieren (#9603, #9600)
  • veraltetes uglify-es durch terser ersetzen (#9594)
  • Markdown-Parsing in Sammelzeichenfolgen und im Bericht teilen (#9514)
  • Hinweis zu global.URL in Knoten 10 hinzufügen (#9449)
  • Build: Locale-Dateien in Devtools Roll einbinden (#9639)
