lighthouse v12.6.0

Leuchtturm v12.6.0

Vollständig Changelog

Wir gehen davon aus, dass diese Version innerhalb weniger Tage in den DevTools von [Chrome 137] (https://chromiumdash.appspot.com/schedule) und in PageSpeed Insights verfügbar sein wird.

Neue Mitwirkende

Danke an unsere neuen Mitwirkenden 👽🐷🐰🐯🐻!

Jack Franklin @jackfranklin Rob Kodey @rkodey Clément Barbaza @cba85

Bemerkenswerte Änderungen

Die Kategorie „Leistung“ im Lighthouse-Bericht verfügt jetzt über die Option „Einblicke“ umzuschalten – mehr erfahren Sie hier.

Kern

  • Deaktivieren Sie das InvalidationTracking-Trace-Ereignis, um einen Absturz zu verhindern (#16451)
  • Audits von devtoolsLogs/traces nach DevtoolsLog/Trace migrieren (#16448)
  • scoreDisplayMode für Insight-Audits so ändern, dass es mit dem Perf-Panel übereinstimmt (#16432)
  • with-Importattribute für Legacy-javascript verwenden, zum Knoten 18.20 wechseln (#16415)
  • image-size-responsive: echten mimeType verwenden, um SVG auszuschließen (#16443)
  • Insights: Slow-CSS-Selector-Insight vorerst fallen lassen (#16457)
  • Erkenntnisse: duplicated-javascript-insight implementieren (#16456)
  • Erkenntnisse: Dem Bericht ein auffälliges Umschaltbanner hinzufügen (#16461)
  • Insights: network-dependency-tree Insight implementieren (#16407)
  • optimierte Bilder: Interne Kodierungsfehler ignorieren (#16444)
  • Preload-Fonts: Stylesheets zu den erforderlichen Artefakten hinzufügen (#16421)
  • Stapel: Winkel korrekt identifizieren (#16439)
  • Cookies von Drittanbietern: Beschreibung aktualisieren (#16464)
  • Tracehouse: Übergeordnete Aufgaben beim Fummeln von endTime korrigieren (#16420)

Bericht

  • Analyse-Hook für Insights-Status hinzufügen (#16466)
  • Insights-Benachrichtigungsbanner anpassen, Zeichenfolgen lokalisieren (#16463)
  • Insights-Gruppenbeschreibung hinzufügen (#16455)
  • Insight-Audits mit Stack-Packs verknüpfen (#16440)
  • Stil der Insight-Tabellen optimieren; Systemschriftart verwenden (#16434)
  • Unterstützt Knoten innerhalb von Listendetails, Verwendung in Insight-Audits (#16433)
  • Einblicke anzeigen, wenn die Umschaltfunktion verwendet wird, auch wenn sie ausgeblendet sind (#16431)

Abt

  • Trace_engine auf 0.0.52 aktualisieren (#16465)
  • Trace_engine auf 0.0.51 aktualisieren (#16447)
  • Upgrade-Abhängigkeiten (#16438)
  • Upgrade von typescript auf 5.8.2 (#16414)

Dokumente

  • Defekter Link „standalone-template.html“ in der README-Datei des Berichts behoben (#16429)

Tests

  • oopif-scripts Smoke für Devtools Runner deaktivieren (#16446)

Sonstiges

  • Bereiten Sie core/lib/legacy-javascript für die Veröffentlichung in npm vor (#16416)
  • Baumkarte: Größen mithilfe der Übertragungsgröße darstellen (#16460)
  • Treemap: Optionen richtig aus Hash-Parametern analysieren (#16459)
  • Treemap: coerceOptions aktualisieren, um initialView zu erhalten (#16458)
  • Baumkarte: Tabelle nach rechts verschieben, Tabulator entfernen (#16428)
  • Baumkarte: Anfangsansichtsmodus über Optionen festlegen (#16427)
  • Treemap: Farben innerhalb des Bundles variieren, Schriftarten aktualisieren (#16403)
