Leuchtturm v5.0.0

5.0.0 (07.05.2019)

Vollständig Changelog

Wichtige neue Funktionen

  • Stack Packs sind eine neue Möglichkeit, Stack-spezifische Ratschläge im Lighthouse-Bericht darzustellen. Diese erste Version erkennt, ob eine Website unter WordPress ausgeführt wird, und fügt dem Bericht zusätzliche Informationen darüber hinzu, wie Sie WordPress-Plugins und -Konfiguration nutzen können, um die Leistung zu verbessern (#7243, #8169, #8633, #8536, #8778).
  • Leistungsbudgets sind eine neue Funktion von Lighthouse, die dazu beitragen soll, zu verhindern, dass die Leistung Ihrer Website im Laufe der Zeit abnimmt. Legen Sie Budgets für die Ressourcen fest, die eine Seite laden soll, und erhalten Sie eine Lighthouse-Benachrichtigung, wenn die Budgets nicht erreicht werden (#8539, #8522, #8727, #8709, #8427, #8708).
  • Lighthouse-Plugins sind eine neue Möglichkeit, benutzerdefinierte Prüfungen zu einem Lighthouse-Lauf hinzuzufügen. Sie werden im Lighthouse-Bericht neben (oder anstelle) der Standardergebnisse präsentiert und können die Tools und Ergebnisse von Lighthouse nutzen, um ihre Arbeit zu erledigen. Beispiele finden Sie in den Dokumenten (#8728).
  • Falls Sie es nach all den Screenshots noch nicht bemerkt haben: Der HTML-Bericht wurde neu gestaltet!

<a name="breaking-changes-5.0">Breaking Changes</a>

  • Knoten 10 (LTS) oder höher ist jetzt erforderlich (#8117)
  • rawValue wurde aus den Prüfergebnissen entfernt. Wenn die Prüfung ein aussagekräftiges numerisches Ergebnis (z. B. eine Metrik) ergab, wird dieses Ergebnis jetzt auf numericValue (#8343, #8385, #8421) angezeigt.
  • Die Bewertung der Barrierefreiheitskategorie wurde basierend auf dem Schweregrad neu gewichtet (#8823)
  • Die FCP-Genauigkeit hat sich verbessert (bei der „Simulations“-Drosselung) und kann sich merklich auf die Ergebnisse auswirken (#7513)
  • Das veraltete --disable-device-emulation-Flag wurde entfernt. Verwenden Sie --emulated-form-factor (#8289, #8334)
  • Der dom-size ignoriert jetzt Elemente in <head> und beschränkt die Bewertung nur auf DOM-Knoten im Körper (#7241)
  • Der type-Wert der diagnostics-Prüfungsdetails wurde in debugdata geändert (#8298)
  • Das Format der screenshot-thumbnails-Screenshots hat sich geändert. Sie sind jetzt eine vollständige Bilddaten-URL (#8299)
