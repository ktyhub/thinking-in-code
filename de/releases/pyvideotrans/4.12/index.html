#pyvideotrans v4.12

v4.12 Download der vorgefertigten Version für Win10/11

<Details> <summary>Bitte verwenden Sie die Quellcodebereitstellung für MacOS-/Linux-Systeme</summary>

  1. Abhängigkeiten installieren:

    # macOS
brew install libsndfile git

brew tap homebrew-ffmpeg/ffmpeg
 
brew install homebrew-ffmpeg/ffmpeg/ffmpeg

# Ubuntu/Debian
sudo apt-get install ffmpeg libsndfile1-dev

  2. UV installieren:

    curl -LsSf https://astral.sh/uv/install.sh | sh

  3. Klonen und starten:

    git clone https://github.com/jianchang512/pyvideotrans.git
cd pyvideotrans
uv sync
uv run sp.py
</details>

Changelog/Changelos

  • Fehler bei der Spracheinstellung von Qwen-asr (integriert) behoben
  • Spracherkennungskanal VibeVoice-ASR hinzugefügt – Der Erkennungskanal parakeet日语(内置) wird durch das Modell Nemotron-3.5-asr-0.6b(内置) ersetzt, das 40 Sprachen unterstützt, darunter Europäisch, Japanisch, Koreanisch und Vietnamesisch.
  • Huggingface_ASR(内置) fügt das Modell nvidia/parakeet-tdt-0.6b-v3 hinzu und unterstützt mehr als 10 europäische Sprachen
  • Entfernen Sie whisper预分割音频, 合并邻近短字幕
  • Optimieren Sie den VAD-Segmentierungsalgorithmus
  • Optimieren Sie Übersetzungsaufforderungswörter
  • LLM重新断句 wird auf LLM纠错 angepasst. Es korrigiert nur Tippfehler und stellt die Zeichensetzung wieder her. Sätze werden nicht neu segmentiert. Es kann in 高级选项-通用设置-LLM纠错AI渠道 eingestellt werden. Der Standardwert ist DeepSeek – 二次识别 verwendet zur Verbesserung der Sprachunterstützung und Kompatibilität standardmäßig faster-whisper und verwendet standardmäßig das Modell large-v3-turbo, das in 高级选项-语音识别参数区域-二次识别所用模型 angepasst werden kann
  • Die unabhängige Funktion 语音转录/文字合成/翻译字幕 zeigt alle verfügbaren 80 Sprachen an
  • Dropdown-Liste für die Aussprache der Videoübersetzungssprache hinzugefügt 自动检测
  • Der GeminiAI-Spracherkennungskanal verwendet fest das Modell gemini-3.5-transcribe
  • Upgrade von transformers auf 5.13.1
  • Beheben Sie andere bekannte Fehler
