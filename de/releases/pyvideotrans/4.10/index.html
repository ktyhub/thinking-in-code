#pyvideotrans v4.10

V4.10-Update-Protokoll

  • Unterstützt FireRedTTS3/Index-tts 2.5
  • Optimieren Sie die Untertitelbearbeitungsoberfläche im Einzelvideomodus
  • Einige Plattformen wie DeepL/Edge-TTS unterscheiden pt/pt-br /es/es-419-Sprachcodes
  • uz-Sprache hinzugefügt
  • Beheben Sie andere bekannte Fehler
<Details> <summary>MacOS/Linux verwenden Sie bitte die Quellcodebereitstellung</summary>

  1. Abhängigkeiten installieren:

    # macOS
brew install libsndfile git

brew tap homebrew-ffmpeg/ffmpeg
 
brew install homebrew-ffmpeg/ffmpeg/ffmpeg

# Ubuntu/Debian
sudo apt-get install ffmpeg libsndfile1-dev

  2. UV installieren:

    curl -LsSf https://astral.sh/uv/install.sh | sh

  3. Klonen und starten:

    git clone https://github.com/jianchang512/pyvideotrans.git
cd pyvideotrans
uv sync
uv run sp.py
</details>
