v4.19 Download der vorgefertigten Version für Win10/11

<Details> <summary>Bitte verwenden Sie die Quellcodebereitstellung für MacOS-/Linux-Systeme</summary>

  1. Abhängigkeiten installieren:

    # macOS
brew install libsndfile git

brew tap homebrew-ffmpeg/ffmpeg
 
brew install homebrew-ffmpeg/ffmpeg/ffmpeg

# Ubuntu/Debian
sudo apt-get install ffmpeg libsndfile1-dev

  2. UV installieren:

    curl -LsSf https://astral.sh/uv/install.sh | sh

  3. Klonen und starten:

    git clone https://github.com/jianchang512/pyvideotrans.git
cd pyvideotrans
uv sync
uv run sp.py
</details>

Hinweise zur Dekompression:

  • Entpacken Sie das komprimierte 7z-Paket. Suchen Sie nach dem Dekomprimieren die Datei sp.exe und doppelklicken Sie, um die Software zu starten. Sie können nicht doppelklicken, um es im komprimierten Paket auszuführen.
  • Extrahieren Sie die Software nicht in einen Ordner, der Administratorrechte erfordert, wie z. B. Program Files auf dem Desktop oder Laufwerk C.
  • Vermeiden Sie Pfadfehler: Fügen Sie keine chinesischen Zeichen, Leerzeichen oder Sonderzeichen in den Dekomprimierungspfad ein.
  • Wenn beim Dekomprimieren mit der 7zip-Software ein Fehler auftritt, versuchen Sie bitte, zum Dekomprimieren Bandizip oder 360-Komprimierungssoftware zu verwenden.
