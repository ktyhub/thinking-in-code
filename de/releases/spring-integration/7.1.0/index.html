spring-integration v7.1.0

Minor Veröffentlicht10. Juni 2026 Quellespring-projects/spring-integration Englisches Original

Diese Seite ist maschinell übersetzt. Maßgeblich ist der englische Originaltext.

Federintegration v7.1.0

:star: Neue Funktionen

– Nachrichtenauswahl basierend auf Header-Wert-Übereinstimmungsmustern hinzufügen #11092 – Überarbeiten Sie Tests mit IntegrationRegistrar, um Infra-Beans zu registrieren #11028 – Erlauben Sie das Überspringen der Postprozessor-Registrierung für Nachrichtenanmerkungen in reinen DSL-Szenarien #11024

  • polnische Konstrukteure in ExpressionEvaluatingMessageProcessor #11002
  • Deaktivieren Sie allowCredentials im CrossOrigin und führen Sie originPatterns ein #10988 – Message_store-Muster in IntegrationPatternType hinzufügen #10978

:lady_beetle: Fehlerbehebungen

– Verhindern Sie das Schreiben von Dateien außerhalb des Ausgabeverzeichnisses #11095 – Die RedisLockRegistry-Freischalt-Race-Bedingung im unterbrochenen Thread #11049 – Entfernen gehaltener Sperren aus der Redis-Registrierung verhindern #11044

  • Der ControlBusCommandRegistry.controlBusCommands muss ein ConcurrentHashMap sein #11042 – Entfernen gehaltener Sperren aus der JDBC-Registrierung verhindern #11041 – Serverfehler nicht vom GrpcInboundGateway an den client weiterleiten #11040 – ZookeeperMetadataStore.replace() unterbricht die CAS-Logik #11013 – Mqttv5PahoMessageHandler schlägt aufgrund falscher MessageConverter.fromMessage-Nutzung fehl #11011 – Mqttv5PahoMessageDrivenChannelAdapter ignoriert payloadType aufgrund falscher MessageConverter.toMessage-Nutzung #10990

:notebook_with_decorative_cover: Dokumentation

  • Navigationslink für Abschnitt Configuration korrigiert #11057 – Tippfehler in java-runtime-flows.adoc #11021 behoben – Irreführendes Javadoc für Messaging-Annotations-Postprozessoren behoben #11020 – Tippfehler im Abschnitt zur Nachrichten-ID-Generierung behoben #11014 – Verbesserung der Dokumentation: Beschreiben Sie Punkt-zu-Punkt im Vergleich zu zentralisiertem ESB #2886

:hammer: Abhängigkeits-Upgrades

  • Aktualisieren Sie RC und SNAPSHOT auf die Release-Versionen #11089
  • Bump io.micrometer:micrometer-tracing-bom von 1.7.0-RC1 auf 1.7.0 #11078
  • Bump io.projectreactor:reactor-bom von 2025.0.5 auf 2025.0.6 #11076 – cloudEventsVersion von 4.1.0 auf 4.1.1 erhöhen #11071
  • Projektabhängigkeitsversionen aktualisieren #11050
  • Bump com.sun.xml.bind:jaxb-impl von 4.0.8 auf 4.0.9 #11037
  • Bump com.fasterxml.jackson:jackson-bom von 2.21.3 auf 2.21.4 #11035
  • Bump tools.jackson:jackson-bom von 3.1.3 auf 3.1.4 #11034
  • Bump org.mongodb:mongodb-driver-bom von 5.7.0 auf 5.7.1 #11032
  • Bump com.google.protobuf:protobuf-bom von 4.34.1 auf 4.34.2 #11019
  • Bump debeziumVersion von 3.5.0.Final auf 3.5.1.Final #11006
  • Bump io.lettuce:lettuce-core von 7.5.1.RELEASE auf 7.5.2.RELEASE #11005
  • Bump com.sun.xml.bind:jaxb-impl von 4.0.7 auf 4.0.8 #11000
