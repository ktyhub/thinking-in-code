claude-mem v15.16.0

Neu

  • Aktualisierung „Meine Arbeit“ bei Ihrem API-Anbieter (Opt-in): Legen Sie CLAUDE_MEM_WORK_VIEW_AGENT=api fest, um die Aktualisierung „Meine Arbeit“ bei dem Anbieter auszuführen, den Sie bereits ausgewählt haben (openrouter, openai-compatible oder die alte cmem-Schreibweise). Installationen ohne angemeldeten Claude Code, Codex oder Gemini CLI (z. B. OpenCode- oder DSH-Hosts) können jetzt My Work verwenden. Wenn ein API-Anbieter ausgewählt und die Einstellung leer ist, greift die Aktualisierung nicht mehr auf einen angemeldeten Claude-Code zurück: Es wird kein Agent ausgeführt und es wird nichts ausgegeben, bis Sie einen auswählen (#5674, danke @bulanovk).
  • GitHub MCP-Pull-Anfragen in „Meine Arbeit“: Pull-Anfragen, die über das offizielle MCP create_pull_request-Tool von GitHub erstellt wurden, werden jetzt als „Meine Arbeit“-Produkte angezeigt. Es werden nur abgeschlossene Ergebnisse akzeptiert, deren URL mit dem angeforderten Repository übereinstimmt (#5809, danke @Afloat16).
  • UberLLM-Voreinstellung: uberllm ist jetzt eine Voreinstellung des openai-compatible-Anbieters (https://api.uberllm.dev/v1, Standardmodell deepseek/deepseek-v4.1-flash) (#5706, danke @PSA-Team-source).
  • Einstellbares Live-Handoff-Timeout: CLAUDE_MEM_HOOK_HANDOFF_TIMEOUT_MS (Standard 250) legt das Budget für den einzelnen Live-Handoff von einem Hook zum Worker fest, und ein verpasster Handoff wird jetzt bei WARN statt bei DEBUG protokolliert (#5831, danke @mohitdixit02).

Bemerkenswerte Korrekturen

  • Plugin-Cache-Bereinigung: Der Worker bereinigt jetzt alte Versionsordner, die durch die Marktplatz-Updates von Claude Code in ~/.claude/plugins/cache/thedotmack/claude-mem/ zurückbleiben (ein Bericht: 21 Versionen, etwa 16 GB). Es behält die laufende Kopie und die registrierte Version bei und führt einen Sweep durch, nachdem der Startvorgang abgeschlossen ist, und dann stündlich (#5685, danke @MaxWang007).
  • Windows-Antivirus-Rauschen: Installation, Update und Launcher-Neuerstellung starten keine versteckte PowerShell mehr, wenn sich der Launcher-Ordner bereits im PATH befindet, das von Kaspersky gekennzeichnete Muster (#5835, gemeldet von @Ali-Sabri-0).
  • Meine Arbeitssprache: Wenn CLAUDE_MEM_WORK_VIEW_TEXT_LANGUAGE leer ist, schreibt jeder Aktualisierungsschritt jetzt in der Sprache des Systemgebietsschemas, sodass bei einem Lauf keine Sprachen mehr gemischt werden (#5669, danke @0xABCD01).
  • Leerlaufkosten für meine Arbeit: Beim Leerlaufabruf wird nicht mehr jede synchronisierte Zeile erneut gescannt, und die Live-Übersicht, das Zusammenführen von Fokusbereichen und umfangreiche Panels verursachen weniger Arbeit pro Aktualisierung (#5834).
  • Backups: ein declined-Backup-Lauf gibt einen Fehler zurück, gespeicherte Backups werden getrennt von Aufbewahrungsfehlern gemeldet, Backup-Intervalle über das Timer-Limit hinaus werden berücksichtigt und bei der Wiederherstellung werden gestempelte Snapshots mit fehlenden Worker-Tabellen abgelehnt (#5750, #5781, #5784, #5684, danke @Kirat0201).
  • Shell-Setup: Der Launcher-PATH-Block und der Legacy-Deinstallationsalias werden atomar geschrieben, Cowork stellt gespoolte Ereignisse unter $HOME bereit, wenn der Host dies festlegt, und Hermes hält permanente HTTP-client-Fehler von seinem Leistungsschalter fern (#5680, #5679, #5677, #5678, danke @DeryFerd).
  • OpenCode: Das Bash-Tool wird als Bash gemeldet, daher gilt SKIP_BASH_PATTERNS (#5668, danke @ryrenz).
  • Synchronisierung: eine fehlgeschlagene Chroma-Bereinigung, nachdem ein Löschvorgang erneut versucht wurde (#5673, danke @Zhong-fan).
  • SessionStart: Die Schritte zum Lesen und Verfassen des Caches teilen sich ein Body-Budget, sodass ein zwischengespeicherter Body nur bereitgestellt wird, wenn er passt (#5686, danke @Varshith-Kali).

Weitere Korrekturen

Ungefähr 130 kleinere Korrekturen von @Afloat16 in den Bereichen Erfassung, Synchronisierung, Suche, Kontext, Import, Transkripte, Medien, Server und die Codex-, OpenCode-, OpenClaw-, Hermes-, Grok-, Kimi-, Gemini-, Pi-, Goose-, Notion- und Telegram-Integrationen. Höhepunkte:

  • Suche und Kontext: Literale Projektschlüssel und Dateipfade bleiben durch Rückruf, Zusammenführung und Zwischenspeicherung erhalten; Unicode und Kombinationszeichen überdauern Abfragewörter und Snippet-Beschränkungen; Der zwischengespeicherte Kontext läuft nach Wiederherstellungen und Zeilenersetzungen ab. Das größte passende Timeline-Präfix wird beibehalten.
  • Synchronisierung und Speicher: Sitzungstitel werden mit ihrer Postausgangsmutation festgeschrieben und erhalten eine Empfänger-Schwärzung; Manuelle Speicherungen und neue Eingabeaufforderungen funktionieren nach dem Löschen einer Sitzung. Anmerkungsrevisionen überdauern die Titellöschung.
  • Transkripte und Import: mehrteilige Codex-Nachrichten, gepaarte Patch-Ergebnisse und ZSTD-Frame-Seams werden korrekt gelesen; Argumentation bleibt bei endgültigen Antworten außen vor; OpenCode, Gemini und wiederhergestellte Zusammenfassungen werden ohne Duplikate oder verlorene Eingabeaufforderungen importiert.
  • Server und Anbieter: Die Schlüsselableitung API bleibt außerhalb der Anforderungsschleife; Abbrüche breiten sich durch Wiederholungsversuche und Komprimierung aus; Die Verwendung geteilter Token wird anhand kompatibler Antworten gemessen. Der Speicherinhalt wird vor der Speicherung bereinigt.
  • Medien: Bildordinalzahlen, Lesenachweise über Pfadschreibweisen hinweg und angekündigte Bilddimensionsgrenzen bleiben erhalten; Inline-Pauschale wird nur für akzeptierte Bilder berechnet.

Auch von @Kirat0201: Der Dateiverlauf folgt der Zusammenführung ganzer Projekte, die interaktive Timeline-Suche berücksichtigt Projektlisten und die einheitliche Suche behält wörtliche filePath-Werte bei (#5789, #5787, #5785).
