echarts 5.5.1

  • [Funktion] [Achse] Unterstützt benutzerdefinierte Achsenmarkierungs-/Beschriftungspositionen. #19919 (dvdkon) (Ovilia)
  • [Feature] [bar] startValue-Option hinzufügen. #17078 (jiawulin001)
  • [Feature] [sankey] itemStyle.borderRadius-Option hinzufügen. #19763 (deftliang)
  • [Feature] [Zeit] Meridianvorlage {a}/{A} hinzufügen. #19888 (maurodesouza)
  • [Feature] [geo] totalZoom-Parameter für das georoam-Ereignis hinzufügen. #19837 (zhaoxinggang)
  • [Funktion] [Baumkarte] scaleLimit-Option hinzufügen, um das Zoomen einzuschränken. #18304 (liuyizhou)
  • [Fix] [Serie] Fehler durch seriesData.getLinkedData vermeiden. #19901 (plainheart)
  • [Fix] [Marker] Fix Marker-Label-Formatierer kann keine Serieninformationen abrufen. #19898 (plainheart)
  • [Fix] [aria] Fehler im SSR-Modus vermeiden. #19892 (OverflowCat)
  • [Fix] [Daten] Fehler bei der Verwendung von BigInt-Werten vermeiden. #19847 (zettca)
  • [Fix] [pie] Fix endAngle wird nicht auf den leeren Kreis angewendet. #19642 (plainheart)
  • [Fix] [Toolbox] Nicht erfasster Referenzfehler in der Umgebung behoben, dass MouseEvent nicht existiert. #19620 (plainheart)
  • [Fix] [Tooltip] Tooltip-XSS-Problem behoben, wenn der Legendenname eine HTML-Zeichenfolge ist. #20045 (plainheart)
  • [Fix] [Typ] Behebung, dass in der .d.ts-Datei der Benutzer import('echarts/types/dist/shared') seit v5.5.0 nicht auf 'echarts/types/dist/shared.d.ts' zugreifen kann. #20030 (100pah)
