spring-ai-alibaba v1.0.0.2

Wir freuen uns, die Veröffentlichung von Spring AI Alibaba 1.0.0.2, der ersten GA-Version, bekannt zu geben! Spring AI Alibaba basiert auf Spring AI und ist tief in Bailian integriert. Es unterstützt die Entwicklung von ChatBot-, Workflow- und Multi-Agent-Anwendungen.

Hauptmerkmale

1. Umfassende Framework-Integration

  • Integration mit Alibaba Cloud: Stellen Sie eine nahtlose Verbindung zu Alibaba-Diensten her, einschließlich Bailians Dashscope, und unterstützen Sie verschiedene gängige KI-Modelle wie Qwen und Deepseek.

2. Multi-Agent-Framework

  • Graphbasiertes Multi-Agent-Framework: Spring AI Alibaba Graph wurde von Langgraph inspiriert und ermöglicht die mühelose Erstellung von Workflows und Multi-Agent-Anwendungen.

3. Unternehmenstaugliche KI-Agent-Lösungen

  • Nacos MCP-Registrierung – Verteilte MCP-Erkennung und Lastausgleich
    • Dynamischer API zum MCP-Proxy
  • NL2SQL zur Umwandlung natürlichsprachlicher Abfragen in SQL-Anweisungen.
  • Beobachtbarkeit

Entwicklererfahrung

Kurzanleitung

Starten Sie Ihre erste KI-Anwendung mit Spring AI Alibaba, indem Sie die folgende Abhängigkeit zu Ihrem Spring Boot-Projekt hinzufügen:

<dependencyManagement>
    <dependencies>
        <dependency>
            <groupId>com.alibaba.cloud.ai</groupId>
            <artifactId>spring-ai-alibaba-bom</artifactId>
            <version>1.0.0.2</version>
            <type>pom</type>
            <scope>import</scope>
        </dependency>
    </dependencies>
</dependencyManagement>

<dependencies>
    <dependency>
        <groupId>com.alibaba.cloud.ai</groupId>
        <artifactId>spring-ai-alibaba-starter-dashscope</artifactId>
    </dependency>
</dependencies>

Spring Boot Starter

  • spring-ai-alibaba-starter-dashscope – Integrierte Modelldienstanpassung
  • spring-ai-alibaba-graph-core – Kernkomponenten des AI Graph-Frameworks
  • spring-ai-alibaba-starter-nl2sql – Konvertierungskomponente von natürlicher Sprache in SQL
  • spring-ai-alibaba-starter-memory – Sitzungsspeicherkomponente
  • spring-ai-alibaba-starter-nacos-mcp-client - Nacos MCP client; empfohlene Version: Nacos 3.0.1. Für Nacos 2 Server-Benutzer verwenden Sie bitte die ältere Version (spring-ai-alibaba-starter-nacos2-mcp-client).
  • spring-ai-alibaba-starter-nacos-mcp-server - Nacos MCP-Server; empfohlene Version: Nacos 3.0.1. Für Benutzer von Nacos 2 Server verwenden Sie bitte die ältere Version (spring-ai-alibaba-starter-nacos2-mcp-server).
  • spring-ai-alibaba-starter-nacos-prompt - Nacos Prompt-Verwaltung
  • spring-ai-alibaba-starter-arms-observation - ARMS-Beobachtbarkeit
  • Community-Komponenten
    • spring-ai-alibaba-starter-tool-calling-* - Werkzeugaufrufkomponente
    • spring-ai-alibaba-starter-document-reader-* - Komponente zum Lesen von Dokumenten
    • spring-ai-alibaba-starter-vector-store-* - Vector Store-Komponente

Beispielprojekte

Die offizielle Community hat ein [Playground-Beispiel] (https://github.com/springaialibaba/spring-ai-alibaba-examples/tree/main/spring-ai-alibaba-playground) entwickelt, das eine vollständige Frontend-Benutzeroberfläche und ein Backend basierend auf Spring AI Alibaba enthält. Mit Playground können Benutzer alle Kernfunktionen des Frameworks wie Chat, Beobachtbarkeit, Mehrrundengespräche, Bildgenerierung, Multimodalität, Toolaufruf, MCP und RAG erleben.

Weitere Anwendungsfälle finden Sie unter Spring AI Alibaba Examples Repository.
