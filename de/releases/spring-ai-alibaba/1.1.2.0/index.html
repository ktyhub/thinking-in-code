spring-ai-alibaba v1.1.2.0

Patch Veröffentlicht2. Feb. 2026 Quellealibaba/spring-ai-alibaba Englisches Original

Diese Seite ist maschinell übersetzt. Maßgeblich ist der englische Originaltext.

spring-ai-alibaba v1.1.2.0

Zusammenfassung

Diese Version aktualisiert Spring AI auf 1.1.2, fügt Agent Skills-Unterstützung für Agent Framework hinzu, fügt parallele Subagent-Ausführung für Workflow-Agenten (LlmRouting, Supervisor) hinzu, erweitert das Diagramm um parallele bedingte Kanten, parallele Aggregationsstrategie (allOf und anyOf), asynchrone Tool-Ausführung und Tool returnDirect. Es umfasst außerdem Serialisierungs- und MergeStrategy-Korrekturen, Admin-/UI-Korrekturen und Dokumentationsaktualisierungen.

Weitere Informationen finden Sie in der <a href="https://java2ai.com/docs/versions/" target="_blank">Dokumentation</a>.

Funktionen

Agent

  • <a href="https://java2ai.com/docs/frameworks/agent-framework/tutorials/skills" target="_blank">Agent-Skills in ReactAgent</a> (#3975) – Integrierte Skills-Funktionen in ReactAgent, unterstützt Skills und zu progressive Offenlegung.
  • Integrierte Multi-Agent-Musterunterstützung – Unterstützt Routing, Supervisor, Supervisor (Agent als Tool), Übergaben, Fähigkeiten usw., Multi-Agent-Muster; Unterstützung für parallele Ausführung für Routing- und Supervisor-Muster hinzugefügt.
  • Unterstützung für Flow-Agent-Hooks (#3983) – Alle Flow-Agenten (Routing, Supervisor, Schleife, sequentiell usw.) unterstützen benutzerdefinierte Hooks.
  • Neuer Agent API (#4031) – Neuer streamMessages API für vereinfachtes Nachrichten-Streaming; Neue Überladungsmethoden invoke und call für zusätzliche Eingaben.
  • Asynchrone und parallele Tool-Ausführung (#4037) – Unterstützt die Tool-Ausführung bei Parallelisierung und asynchroner Tool-Ausführung.
  • Tool returnDirect (#4139) – Unterstützung für das Verhalten des Tools returnDirect.
  • ToolContextHelper (#4163) – Hilfsklasse für den Metadatenzugriff im Tool-Kontext (behebt #3110).

Diagramm

  • Parallele bedingte Kanten (#4027) – Bedingte Kanten unterstützen die parallele Ausführung (behebt #3917).
  • Aggregationsstrategie für Parallelzweige (#4028) – Neue Aggregationsstrategie (AllOf und AnyOf) für Parallelzweige.
  • Batch addEdge für parallele Zweige (#3938) – Praktische Batch-addEdge-Methoden für die Definition paralleler Zweige in StateGraph.
  • interruptAfter-Hook (#3864) – InterruptableAction unterstützt den interruptAfter-Hook (behebt #3447, #3904).
  • Asynchrone Tool-Ausführung für AgentToolNode (#4037 / #3988) – Unterstützung der asynchronen Tool-Ausführung für AgentToolNode.
  • Vollständige Ausgabe für Streaming-Knoten (#3941) – Streaming-Knoten geben jetzt die vollständige Ausgabe einschließlich _FINISHED OutputType aus.

Sandbox & Studio

  • SAA Sandbox (#4069) – Neues SAA Sandbox-Modul, das eine sichere und isolierte Tool-Ausführung ermöglicht.
  • Integriertes RenderTemplate (#3935) – Integrierte, angepasste RenderTemplate-Implementierung.
  • Studio CORS optional (#4154) – Die CORS-Konfiguration ist in Studio jetzt optional.

Korrekturen

DashScopeChatModel

  • Verbindungszurücksetzung gemeldet in #3942 (spring-ai-alibaba/spring-ai-extensions#140) – Legen Sie den Standard-HTTP client für DashScopeApi fest, um Verbindungen besser zu verwalten und Probleme beim Zurücksetzen der Verbindung zu vermeiden, wenn die Verbindung vom Modellserver geschlossen wird.

Diagramm

  • Serialisierung (#3969) – class-Fehler in der Serialisierung behoben (behebt #3895, #3931).
  • MergeStrategy (#4129) – Optional-Behandlung korrigiert und strenge Typprüfungen in MergeStrategy erzwungen (behebt #3909).

Agent

  • Anweisung (#3974) – Anweisungsverarbeitung hinzugefügt; festes CI und Tests.
  • AgentLlmNode-Modelloptionen (#3986) – Verhindern, dass AgentLlmNode Standardmodelloptionen überschreibt; Stellen Sie sicher, dass internalToolExecution(false) für ChatOptions eingestellt ist (behebt #3903).
  • selectorModel (#4045) – selectorModel-Unterstützung hinzugefügt (behebt #4026).
  • systemPrompt (#4067) – Die Behandlung von Systemeingabeaufforderungen wurde korrigiert.
  • ParallelAgent maxConcurrency (#4053) – Sichergestellt, dass die maxConcurrency-Funktion von ParallelAgent implementiert ist.
  • jumpTo (#4081) – Sichergestellt, dass jumpTo ordnungsgemäß funktioniert.
  • ModelRequest Builder SystemMessage (#4138) – ModelRequest Builder verliert systemMessage nicht mehr.
  • NacosReactAgentBuilder (#4093) – NacosReactAgentBuilder wurde korrigiert, um lokale Tools ordnungsgemäß zusammenzuführen.
  • AgentLlmNode-Tool-Rückrufe (#4112) – Filterlogik für Tool-Rückrufe in AgentLlmNode korrigiert.

Admin und Benutzeroberfläche

  • Admin-Paket umbenennen (#3977) – @agentscope-ai/flow in @spark-ai/flow umbenannt (behebt #3949).
  • Admin-Start/Kompilierung (#4123) – Start- und Kompilierungsprobleme von spring-ai-alibaba-admin behoben.
  • CustomInputsControl (#4106) – variableList-Requisite zu CustomInputsControl hinzugefügt.

Abhängigkeiten

  • Spring AI-Version – Spring Ai wurde auf 1.1.2 aktualisiert
  • Spring AI Alibaba Extensions-Version – Spring Ai Alibaba Extensions wurde auf 1.1.2.1 aktualisiert

Upgrade-Hinweise

  • Spring AI: Diese Version verwendet Spring AI 1.1.2. Richten Sie die Spring AI-Version Ihres Projekts entsprechend aus.
  • Admin: Wenn Sie die Admin-Flow-Benutzeroberfläche verwenden, aktualisieren Sie die Abhängigkeit von @agentscope-ai/flow auf @spark-ai/flow.
