mlflow v3.14.0

MLflow 3.14.0 enthält mehrere wichtige Funktionen und Verbesserungen

Wichtige neue Funktionen

  • 🚀 Ein-Befehl-Agent-Onboarding mit mlflow agent setup: Installieren Sie MLflow, richten Sie die Ablaufverfolgung ein und geben Sie Ihrem bevorzugten Codierungsagenten (Claude Code, OpenAI Codex oder OpenCode) die MLflow-Kenntnisse zur Instrumentierung Ihrer App – alles mit einem einzigen Befehl.
  • ⚡ Dauerhafte Ablaufverfolgung mit geringer Latenz für Claude Code: Führen Sie die Ablaufverfolgung von Claude Code sicher im gesamten Team ein: Ein Write-Ahead-Protokoll verhindert, dass der Agent verlangsamt, der Tracking-Server überlastet wird oder Spuren bei einem Netzwerkfehler oder -absturz verloren gehen.
  • 📝 Überprüfungswarteschlangen für Traces: Weisen Sie Traces Prüfern (oder Agenten) zu und sammeln Sie strukturiertes Feedback und fundierte Anmerkungen in der Benutzeroberfläche, die direkt in den Trace zurückgeschrieben werden, sodass sie sofort zur Auswertung verwendet werden können.
  • 🗂️ Überarbeitete Evaluierungsdatensatz-Benutzeroberfläche: Durchsuchen, prüfen, bearbeiten und massenhaft verwalten Sie Evaluierungsdatensatzdatensätze direkt in der Benutzeroberfläche, mit click-through zum Quell-Trace.
  • 🧪 Pytest-Integration für Regressionstests: Schreiben Sie GenAI-Regressionstests als einfache Pytest-Funktionen mit dem @mlflow.test-Marker, gattern Sie sie in CI und überprüfen Sie den Testverlauf und die Ergebnisse der Beurteilung pro Aussage in der Benutzeroberfläche.
  • 🎛️ LLM Playground: Iterieren Sie Eingabeaufforderungen im Browser anhand Ihrer AI Gateway-Endpunkte und Eingabeaufforderungsregistrierungsversionen mit Einstellungen, Tools, strukturierter Ausgabe und Vorlagenvariablen.
