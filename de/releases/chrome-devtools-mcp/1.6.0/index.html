chrome-devtools-mcp v1.6.0

chrome-devtools-mcp chrome-devtools-mcp-v1.6.0

1.6.0 (14.07.2026)

🎉 Funktionen

  • Flag „experimentalGcfFormat“ für GCF-codierte Tool-Antworten hinzufügen (#2235) (3d21389)
  • Objektanzahl und Gesamtgrößen in get_heapsnapshot_details drucken (#2325) (15a6b78)
  • unterstützt die Konfiguration „--allow-unrestricted-paths“ (#2296) (6e56c02)
  • Unterstützt Filter mit Heap-Snapshot-Aggregaten (#2323) (2812902)
  • Lighthouse auf 13.4.0 aktualisieren (#2317) (ffc6060)

🛠️ Korrekturen

  • .gz anstelle von json.gz in Leistungstools erzwingen (#2305) (b06e39b)
  • Behalten Sie eine noch geöffnete ausgewählte Seite bei, anstatt auf die erste Seite zurückzugreifen (#2328) (c645eee), schließt #2304
  • Seiten-IDs bei erneuten Browser-Verbindungen eindeutig halten (#2345) (3e8d922)
  • Seite 0 in list_network_requests und list_console_messages paginieren (#2359) (d0025b3)
  • Angehaltene Modifikatoren freigeben, wenn das Tastenereignis press_key fehlschlägt (#2347) (78ccb19)
  • meldet, wann die ausgewählte Seite automatisch durch den Fallback ersetzt wurde (#2308) (2c16ac3), schließt #2304
  • Seiten-IDs nur unter aufgelisteten Seiten auflösen (#2332) (eb04951), schließt #2304
  • Snapshot: Element-IDs im richtigen Snapshot auflösen (#2295) (b703f2c)
  • Telemetrie: Aufzählungswerte durch verschachtelte Schema-Wrapper auflösen (#2315) (c065fd9)
  • Warten Sie, bis der Daemon gestartet ist (#2327) (ed7e95d)

📄 Dokumentation

  • Grok Build CLI-Konfigurationsabschnitt hinzufügen (#2294) (aa4be07)
  • Fähigkeit zum Debuggen von Speicherlecks aktualisieren (#2330) (c1736a0)

⚡ Leistung

  • gleichzeitige E/A in der Root-Pfad-Auflösung (#2279) (b2c63e6)

🏗️ Refaktorieren

  • McpContext-Getter bereinigen (#2340) (5b33deb)
  • Mehr von der Kontextschnittstelle bereinigen (#2335) (9cd734b)
  • Seitenverwaltung bereinigen (#2333) (16db01f)
  • Seiten-Snapshot-Generierung bereinigen (#2348) (68cfce2)
  • Kollektoren pro Seite arbeiten lassen (#2324) (9bc61b4)
  • Dateien verschieben und umbenennen (#2355) (9c3542b)
  • DevTools-Universum nach McpPage verschieben (#2341) (c006c9b)
  • verbleibende McpContext-Getter verschieben (#2342) (58ba174)
  • Isolierten Kontext-Getter entfernen (#2336) (8a4ddb3)
  • Array statt Map für idToClassKey verwenden (#2321) (ff53b7b)
  • Hilfsprogramm für Dialoghandle verwenden (#2334) (64005f9)
  • Antwortseite in der Formatierung verwenden (#2349) (c53c1ec)
