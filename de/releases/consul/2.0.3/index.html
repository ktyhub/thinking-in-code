Konsul v2.0.3

2.0.3 (7. August 2026)

SICHERHEIT:

  • Aktualisieren Sie brace-expansion, um GHSA-rgw5-rvv9-x895 zu adressieren (DoS über unbegrenzte Zwischenarrays). [GH-23786]
  • Aktualisieren Sie fast-uri, um GHSA-7p8r-x3mc-p8w7 zu beheben (Host-Verwirrung durch Backslash-Berechtigungseinleitung). [GH-23786]
  • Aktualisieren Sie golang.org/x/text auf v0.39.0, um GO-2026-5970 zu beheben. [GH-23761]
  • Aktualisieren Sie google.golang.org/grpc auf v1.82.1, um GHSA-hrxh-6v49-42gf zu adressieren. [GH-23761]
  • Aktualisieren Sie socket.io-parser, um CVE-2026-69185 (Speichererschöpfung ohne Anhang) zu beheben. [GH-23786]
  • Upgrade zur Verwendung von Go 1.26.5. Dadurch werden Schwachstellen behoben GO-2026-4970 (os). GO-2026-5856 (crypto/tls). [GH-23761]
  • Agent: Es wurde eine Denial-of-Service-Schwachstelle behoben, bei der GET /v1/agent/connect/ca/roots und POST /v1/agent/connect/authorize nutzte den agentenseitigen Cache sogar bedingungslos als http_config { use_cache = false } vom Betreiber konfiguriert wurde. Ein Fernanrufer könnte diese Einstellung umgehen und den Agent-Cache ohne Einschränkungen vergrößern, indem die Anforderung variiert wird ACL-Token. Beide Endpunkte überspringen jetzt den Cache und geben einen direkten RPC aus, wenn use_cache vorhanden ist deaktiviert. (SECVULN-50292, SECVULN-50293) [GH-23797]
  • Agent: Eine Null-Zeiger-Dereferenzierungspanik in ShadowServiceRouterConfigEntry.CheckEnt wurde behoben wenn ein Service-Router-Konfigurationseintrag eine Route mit einem Null-Destination enthielt. Ein handgefertigtes Eine Snapshot-Wiederherstellungs- oder Replikationsnachricht mit einem solchen Eintrag könnte zum Absturz des FSM führen Dekodierungspfad. Der Nullwächter behandelt ein fehlendes Ziel jetzt als Nicht-Unternehmensdaten und setzt die Dekodierung sicher fort. (SECVULN-50291) [GH-23797]
  • Agent: Es wurde eine Sicherheitsumgehung behoben, bei der ein vom Benutzer bereitgestellter öffentlicher Listener verwendet wurde (envoy_public_listener_json) mit einem HTTP Connection Manager-Filter würde Consuls überspringen Standardeinstellungen für die Normalisierung eingehender Anfragen. Ein Angreifer könnte den nicht normalisierten Pfad ausnutzen um L7-Intention-deny-Regeln mithilfe prozentcodierter Pfadäquivalente zu umgehen. Konsul jetzt Fügt eine Pfadnormalisierung ein (standardmäßig aktiviert, es sei denn, die Mesh-Konfigurationsoption ist aktiviert). InsecureDisablePathNormalization ist festgelegt) in jeder vom Benutzer bereitgestellten HCM-Filterkette öffentliche Zuhörer, bevor die L7-Absichtsdurchsetzung angewendet wird. (SECVULN-50295) [GH-23797]
  • Agent: Eine nicht authentifizierte Denial-of-Service-Schwachstelle wurde behoben PUT /v1/agent/check/update/:id, PUT /v1/agent/check/register, PUT /v1/agent/service/register und POST /v1/agent/connect/authorize dekodierte unbegrenzte JSON-Anfragetexte, bevor die ACL des Aufrufers aufgelöst wurde Token. Ein nicht authentifizierter Anrufer könnte mehrere große JSON-Decoder behalten Puffern gleichzeitig innerhalb des Consul-Prozesses vor jeder Anfrage mit HTTP 403 abgelehnt, was zu einem vom Angreifer kontrollierten Heap-Wachstum führt. Alle vier Endpunkte begrenzen jetzt den Anforderungstext auf 512 KiB, bevor eine Dekodierung erfolgt. Rückgabe von HTTP 413 für übergroße Körper. Dieses Limit gilt für Chunked Übertragungskodierung sowie deklariertes Content-Length. (SECVULN-50418) [GH-23796]
  • Agent: Es wurde eine nicht authentifizierte Denial-of-Service-Schwachstelle behoben, bei der das externe gRPC und gRPC-TLS-Listener akzeptierten eine unbegrenzte Anzahl von TCP-Verbindungen pro Quell-IP bevor eine Anfrageverarbeitung, eine ACL-Prüfung oder eine Ratenbegrenzung erfolgen könnte. Ein entfernter Angreifer könnte die Dateideskriptoren, Goroutinen und den Speicher des Agenten erschöpfen, indem viele Verbindungen geöffnet werden und Zurückhalten des gRPC- oder TLS-Handshakes. Ein neuer pro-client-IP-Verbindungsbegrenzer ist jetzt verfügbar angewendet, bevor der gRPC-Server die Verbindung beobachtet, gesteuert durch den neuen Konfigurationsoption limits.grpc_max_conns_per_client (Standard 100). Der gRPC-Handshake Das Timeout wurde außerdem von der Bibliotheksvorgabe von 120 Sekunden auf 20 Sekunden reduziert. (SECVULN-50294) [GH-23797]

VERBESSERUNGEN:

  • ui: Yadda/Gherkin-Abnahmetests auf natives QUnit migrieren (Harness, Absichten/Erstellen, Komponenten, Einstellungen) [GH-23741]
  • xds: Fügen Sie zwei neue Opt-in-ProxyDefaults.spec.config-Schlüssel zur Steuerung des server-Antwortheaders auf API-Gateway-HTTP-Listenern hinzu: envoy_suppress_envoy_headers (entfernt den Header vollständig) und envoy_server_header_name (benennt ihn in einen benutzerdefinierten Wert um). Wenn beides gesetzt ist, hat die Unterdrückung Vorrang. [GH-13027]

FEHLERBEHEBUNGEN:

  • Agent: Stoppen Sie die Protokollierung des rohen ACL-Tokens in Inhaltstypprotokollen auf Debug-Ebene. [GH-23731]
  • api-gateway: Es wurde eine Regression behoben, die dazu führte, dass ein HTTP-API-Gateway seine Konfiguration mit einem „Inkonsistente Protokolle“-Fehler (was zu zeitweiligen 503-Fehlern führte) ablehnte, wenn der service-router eines Back-End-Dienstes während der Erkennungskettensynthese eine Route zu einem Ziel in einem anderen Dienst, Namespace oder einer anderen Partition erstellte. [GH-23793]
  • serf: WAN-Flood-Join behoben, um nicht aktive Zielmitglieder (verlassen/verlassen/fehlgeschlagen) zu ignorieren, sodass wieder beigetretene Server in der WAN-Mitgliedschaft wieder aktiv werden können. [GH-23709]
  • xds: Hinzufügung von XFCC-Headern zur GPRC-Anfrage, ähnlich der HTTP-Anfrage für den Connect-Proxy-Inbound-Listener [GH-23744]
