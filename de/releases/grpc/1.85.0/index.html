grpc v1.85.0

Dies ist die Version 1.85.0 (googol) von gRPC Core.

Die Dokumentation zu gRPC finden Sie unter grpc.io. Für frühere Versionen siehe Releases.

Diese Version enthält Verfeinerungen, Verbesserungen und Fehlerbehebungen. Die Highlights sind unten aufgeführt.

Kern

  • [Sicherheit] gRPC-Repo-Roots aktualisieren. (#43717)
  • [Experimente] Experiment „map_host_header_to_authority“ hinzufügen. (#43561)
  • [Sicherheit] Fügen Sie MLKEM1024 als Schlüsselaustauschoption hinzu. (#43514) – Entfernen Sie die OpenSSL1.0.2-Unterstützung. (#43466)
  • [Autosharding-LB][Teil-1] Implementierung von A119. (#43406)
  • [OpenSSL] Unterstützung für OpenSSL 4 hinzugefügt. (#41932)
  • [A110] Optionen für untergeordnete Kanäle hinzufügen. (#43314)

C#

  • [Build] Protobuf_version in Vorlagen eindeutig machen. (#43433)

Python

  • [Python][AIO] Datenwettlauf in PollerCompletionQueue behoben. (#43429) – [Python] Behebung eines SyncServicerContext-Abbruchs, der keine Ausnahme auslöste. (#43126)
  • [Python] Leck im Channelz-Modul behoben. (#43196)
  • [Python] CSDS-Speicherleck behoben. (#43202)
  • [Python] Cython-Abhängigkeit für Quell-Builds aufheben. (#43378)
