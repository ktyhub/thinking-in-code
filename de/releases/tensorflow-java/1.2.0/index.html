tensorflow-java v1.2.0

Änderungen

Diese Version aktualisiert die native Komponente auf TensorFlow 2.21, führt tensorflow-ndarray wieder in dieses Projekt ein und fügt kleine Korrekturen am Verlaufssystem hinzu. Aufgrund des Mangels an verfügbaren Builds vom Upstream-TensorFlow wird die Unterstützung für Windows x86 eingestellt.

Die aktualisierte TensorFlow-Java-Dokumentation ist jetzt unter tensorflow.github.io/java verfügbar und wird mit diesem Projekt gepflegt. Die alten Dokumentationsseiten unter tensorflow.org/jvm und tensorflow.org/api_docs/java/org/tensorflow/package-summary werden nicht mehr gepflegt, wir können sie jedoch derzeit nicht entfernen.
