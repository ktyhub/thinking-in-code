chatgpt-on-wechat 2.1.4

🌐 Englisch | 中文

🖥 Desktop Client

Nach dem Desktop client, der in der vorherigen Version eingeführt wurde, verbessert diese Version die Browserfunktionen, die Systemkompatibilität und das Gesamterlebnis weiter:

  • Browser-Tool-Unterstützung: Der client bündelt Browserfunktionen und bevorzugt die Wiederverwendung des im System installierten Chrome/Edge, mit optimierter Browser-Start- und Zugriffsleistung.
  • Verfeinerung der Benutzeroberfläche: verfeinerte visuelle Elemente und Interaktionen für die Chat-Ansicht, Nachrichtenblasen, Tool-Call-Schritte und Kanalseiten.
  • Windows-Codesignatur: Windows-Installationsprogramme sind jetzt codesigniert, wodurch Sicherheitswarnungen während der Installation reduziert werden.
  • Windows 7/8-Unterstützung: client-Unterstützung für ältere Systeme wie Windows 7/8 hinzugefügt, um mehr Umgebungen abzudecken.
  • Korrektur von Wissensdatenbank-Links: In-Dokument-Links in der Desktop-Wissensdatenbank wurden behoben, die nicht navigieren konnten.
  • Passwort-Anmeldung: Der Desktop client unterstützt das Festlegen eines Anmeldepassworts und behebt ein Problem, bei dem das Fenster nicht geladen werden konnte, nachdem ein Passwort festgelegt wurde.

Herunterladen: CowAgent Desktop

Dokumente: Desktop Client

🔌 MCP OAuth-Autorisierung

Remote-MCP-Server unterstützen jetzt OAuth-Autorisierung. Wenn Sie eine Verbindung zu MCP-Servern von Drittanbietern herstellen, die eine Anmeldung erfordern, kann die Authentifizierung über den Standard-OAuth-Ablauf erfolgen – keine manuelle Konfiguration und Verwaltung von Tokens mehr.

Dokumente: MCP Tools

⏰ Geplante Aufgaben

  • Silent-Modus: Erstellen Sie stillschweigend geplante Aufgaben, die im Hintergrund ausgeführt werden, ohne dass Nachrichten gesendet werden – ideal für ungestörte Szenarien wie Datenorganisation oder regelmäßige Archivierung. (#2954)
  • Manuelle Ausführung: Manuelles Auslösen einer vorhandenen Aufgabe zur sofortigen Ausführung über die Konsole, ohne auf den nächsten Zeitplan warten zu müssen. (#2958)
  • Konfiguration beim Bearbeiten beibehalten: Es wurde ein Problem behoben, bei dem beim Bearbeiten einer Aufgabe in der Webkonsole ausgeblendete Felder wie der Modustyp gelöscht werden konnten. (#2959)
  • Kanalübergreifender Aufgabenbefehl: Der Verwaltungsbefehl /tasks wurde hinzugefügt, der kanalübergreifend kompatibel ist. (#2965)

Danke @AaronZ345

Dokumente: Geplante Aufgaben

💬 Verbesserungen des Feishu-Kanals

Der Feishu-Kanal erhält eine Reihe von Verbesserungen bei der Nachrichtenanzeige und Interaktion für ein besseres Erlebnis.

  • Verfeinerung der Streaming-Karte: Streaming-Karten fügen zusammenklappbare Panels hinzu, die den Denkprozess, Toolaufrufe und die Ausführungszeit anzeigen. (#2963)
  • Markdown-Formatierung: Bei Nicht-Streaming-Antworten und geplanten Pushs werden Nachrichten, die Markdown enthalten, zur klareren Anzeige als Karten gerendert. (#2962)
  • Planerkarten: Der Befehl /tasks wird in Form von Karten dargestellt, mit der Möglichkeit, Aufgaben direkt von der Karte aus zu aktivieren oder zu deaktivieren. (#2961)
  • Zitierter Nachrichtenkontext: Wenn ein Benutzer eine Nachricht zitiert, wird der zitierte Inhalt automatisch dem an den Agenten gesendeten Kontext hinzugefügt. (#2966)
  • Remote-Bild-Rendering: Remote-Bild-Links können jetzt in Feishu-Karten gerendert werden. (#2967)
  • Abbrechen bei Nachrichtenrückruf: Beim Abrufen einer Feishu-Nachricht wird die entsprechende laufende oder in der Warteschlange befindliche Aufgabe automatisch abgebrochen. (#2978)

Danke @AaronZ345

Dokumente: Feishu

💾 Datensicherung und -wiederherstellung

Die Befehle cow backup und cow restore wurden hinzugefügt, um lokale Daten – Konfiguration, Wissensdatenbank, Speicher und mehr – mit einem Befehl zu exportieren und wiederherzustellen, was Migration und Sicherung vereinfacht. Danke @AaronZ345 (#2957)

Dokumente: Datensicherung

🤖 Neue Modelle

  • Unterstützung für kimi-k3 hinzugefügt – Unterstützung für gpt-5.6-luna, gpt-5.6-terra und gpt-5.6-sol hinzugefügt

Dokumente: Modelle

🛠 Verbesserungen und Korrekturen

  • Aktive Aufgabensteuerung: Der Befehl /steer wurde hinzugefügt, um während der Aufgabenausführung neue Anweisungen einzufügen und die laufende Aufgabe im laufenden Betrieb zu steuern oder umzuleiten. Danke @AaronZ345 (#2977)
  • Dateibearbeitung: Es wurde ein Problem behoben, bei dem der Fuzzy-Abgleich beim Bearbeiten von Dateien die falsche Position ermitteln konnte. Danke @weijun-xia (#2945)

📦 So führen Sie ein Upgrade durch

  • Quellbereitstellung: Führen Sie cow update für ein click-Upgrade aus oder rufen Sie den neuesten Code ab und starten Sie neu. Siehe die Upgrade-Anleitung.
  • Desktop client: Suchen Sie nach Updates und aktualisieren Sie mit einem click im client, ​​oder holen Sie sich die neueste Version von der Download-Seite.
