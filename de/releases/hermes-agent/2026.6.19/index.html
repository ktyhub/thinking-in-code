Hermes-Agent v0.17.0 (v2026.6.19)

Veröffentlichungsdatum: 19. Juni 2026 Seit v0.16.0: ~1.475 Commits · ~800 zusammengeführte PRs · 1.693 Dateien geändert · 235.390 Einfügungen · 50.730 Löschungen · 300+ Probleme geschlossen · 245 Community-Mitwirkende

The Reach Release. v0.16.0 bringt Hermes auf Ihren Desktop. Bei v0.17.0 geht es darum, wie weit diese Reichweite reicht – über neue Orte, an denen man mit ihr sprechen kann, tiefer in die Tools, die Sie bereits verwenden, und bis hin zu den Leuten, die Hermes für ein Team leiten. Hermes hat zwei neue Kanäle erreicht (iMessage über Photon und das Raft-Agentennetzwerk), die Desktop-App hat wesentliche neue Funktionen erhalten, Subagenten können jetzt im Hintergrund ausgeführt werden, die Bildgenerierung hat gelernt, sie zu bearbeiten, und das Composer-Modell von Cursor ist über ein xAI Grok-Abonnement erreichbar. Das Dashboard erhielt einen vollständigen Profilersteller und eine sichere Anmeldung, der Skills Hub-Browser wurde überarbeitet, das memory-Tool erhielt ein umfassendes Upgrade und der Kurator gab kein Aux-Model-Budget für jeden Routinelauf aus. Mehr als 300 geschlossene Ausgaben mit Mitfahrgelegenheit und Sicherheitsrundgang.

✨ Highlights

  • Hermes erreicht iMessage – Photon Spectrum, kein Mac-Relay erforderlich – Es gibt jetzt ein iMessage-Plattform-Plugin, das auf dem verwalteten Leitungspool von Photon basiert. Führen Sie hermes photon login aus, authentifizieren Sie sich mit einem Gerätecode, und Hermes kann iMessage senden und empfangen – kein Mac, der in einem Schrank sitzt und ein Relay betreibt, keine BlueBubbles-Bridge zum Babysitten. Es ist als Nachfolger von BlueBubbles positioniert: der Start ist kostenlos, es muss nichts selbst gehostet werden. Wenn Ihre Freunde und Familie in den blauen Blasen leben, lebt Hermes jetzt auch dort. (#32348, #42582, #44713 — @teknium1)
  • Raft – Hermes tritt dem Raft-Agentennetzwerk als Gateway-Kanal bei – Ein neuer gebündelter Raft-Plattformadapter ermöglicht Hermes die Verbindung zu Raft als externer Agent über eine Wake-Channel-Brücke. Stellen Sie RAFT_PROFILE ein, betreiben Sie die Brücke, und Raft kann Hermes für die Verarbeitung von Nachrichten aktivieren – mit einem Privacy-by-Contract-Design, bei dem Wake-Payloads nur Metadaten (Ereignis-IDs, Zeitstempel) und niemals Nachrichtentexte enthalten. Eine weitere Oberfläche, auf der Hermes auftauchen und arbeiten kann. (#48210 — @xxchan, @teknium1)
  • Eine wesentlich leistungsfähigere Desktop-App – v0.16.0 hat die Desktop-App ausgeliefert; v0.17.0 hat es in Dutzenden von PRs vertieft. Rebindbare Tastaturkürzel, native Betriebssystembenachrichtigungen mit Umschalten pro Typ, Live-Subagenten-Überwachungsfenster, die die Aktivität eines delegierten Agenten in seinen eigenen Bereich streamen, eine Composer-Modellauswahl mit Voreinstellungen pro Modell, automatische RTL-/Bidi-Textrichtung, ein in der Größe veränderbares VS-Code-Terminalfenster, pro-Thread-Composer-Entwürfe und die Möglichkeit, jedes VS Code Marketplace-Theme direkt in der App zu installieren. Der Desktop ist jetzt ein ernstzunehmender täglicher Treiber und keine Vorschau mehr. (#45866, #40660, #47060, #46959, #43292, #44596 – @OutThisLife, @teknium1)
  • Hintergrund-/asynchrone Subagenten – Arbeit delegieren und weitermachen – delegate_task(background=true) sendet jetzt einen Subagenten, der im Hintergrund läuft und sofort ein Handle zurückgibt. Sie und das Modell arbeiten weiter, während die Konversation abläuft, und das vollständige Ergebnis wird in einer neuen Runde wieder in die Konversation aufgenommen, sobald sie beendet ist. Starten Sie einen langen Forschungstauchgang oder einen mehrstufigen Aufbau und machen Sie dann mit etwas anderem weiter, anstatt blockiert und darauf zu warten. (#40946, #46968 — @teknium1)
  • Bilder bearbeiten, nicht nur generieren – Bild-zu-Bild in image_generate – image_generate kann jetzt ein Quellbild bearbeiten und umwandeln, nicht nur eines von Grund auf erstellen. Übergeben Sie ein vorhandenes Bild und eine Eingabeaufforderung und es wird über alle unterstützten Bildanbieter an den Bearbeitungsendpunkt des Backends weitergeleitet (dasselbe Tool, das gleiche Muster wie video_generate). „Machen Sie dieses Logo blau“, „entfernen Sie den Hintergrund“, „verwandeln Sie diese Skizze in ein Rendering“ – alles mit dem Tool, das Sie bereits verwenden. (#48705 — @teknium1)
  • Automatisierungs-Blueprints – Planen Sie Dinge, ohne Cron zu lernen – Wählen Sie eine Automatisierung anhand des Namens aus und Hermes fragt Sie nach dem, was sie benötigt – keine Cron-Syntax, keine slot=value-Eingabe. Eine Blueprint-Definition wird nativ auf jeder Oberfläche gerendert: ein Formular im Dashboard, ein Schrägstrichbefehl im CLI/TUI/Messenger, eine Konversation mit dem Agenten, ein Eintrag im Dokumentenkatalog. „Tägliches Nachrichtenbriefing um 8 Uhr morgens“ wird zu einer Sache, die Sie durch die Beantwortung von Fragen einrichten, nicht durch das Auswendiglernen von 0 8 * * *. (#41309 — @teknium1) – Cursors Composer-Modell über Ihr xAI Grok-Abonnement – grok-composer-2.5-fast befindet sich jetzt in der xAI OAuth-Modellauswahl, wobei sein Kontextfenster auf die vollen 200.000 abgeglichen ist. Composer ist das schnelle Codierungsmodell hinter Cursor – und wenn Sie ein xAI Grok-Abonnement haben, können Sie Hermes jetzt direkt über OAuth darauf verweisen, ohne separaten API-Schlüssel. Ihr Grok-Plan, die Agentenschleife von Hermes, die Codierungsgeschwindigkeit von Composer. (#47908, #6f89e17 — @teknium1)
  • Vollständiger Profilersteller im Dashboard – Erstellen Sie ein vollständiges Hermes-Profil über den Browser – wählen Sie sein Modell, wählen Sie seine Fähigkeiten aus, schließen Sie seine MCP-Server an – ohne manuelle Bearbeitung von config.yaml. Das Dashboard vereinheitlichte außerdem die Verwaltung mehrerer Profile in einer maschinenweiten Ansicht mit einem globalen Profilumschalter, sodass Sie jedes Profil von einem einzigen Ort aus verwalten können. (#39084, #44007 — @teknium1)
  • Überarbeitung des Skills Hub-Browsers – Der Skills Hub des Dashboards wurde grundlegend überarbeitet: verbundene Hubs, ein Abschnitt „Empfohlen“, vollständige Skill-Vorschauen vor der Installation und ein Sicherheitsscan für jeden Skill. Das Durchsuchen und Installieren von Fähigkeiten aus den trusted-Taps (OpenAI, Anthropic, HuggingFace, NVIDIA) ist jetzt ein echtes Browsing-Erlebnis und keine flache Liste. (#40384, #43398 — @teknium1)
  • Das memory-Tool hat ein großes Upgrade erhalten – atomare Batch-Operationen – Das memory-Tool hat ein operations-Array erhalten, das eine Reihe von Bearbeitungen zum Hinzufügen/Ersetzen/Entfernen atomar auf das endgültige Zeichenbudget anwendet. Das Modell kann in einem einzigen Aufruf Speicherplatz freigeben und neue Einträge hinzufügen – selbst wenn ein Hinzufügen allein das Budget sprengen würde – und bündelt so das, was früher ein fragiler Multi-Turn-Tanz war, in einen zuverlässigen Vorgang. Speicheraktualisierungen sind jetzt schneller und die Wahrscheinlichkeit, dass sie während der Bearbeitung fehlschlagen, ist weitaus geringer. (#48507 — @teknium1)
  • Sichere Dashboard-Anmeldung – Die Authentifizierung des Dashboards wurde gestärkt: Jeder Endpunkt, für den ein Token erforderlich ist, gibt jetzt korrekt 401 hinter dem OAuth-Gate zurück, die Websocket-Authentifizierung verwendet das bereitgestellte Dashboard-Token und eine Warnung wird ausgelöst, wenn eine public_url-Überschreibung stillschweigend abgelehnt wird. Standardmäßig ist es sicherer, Ihr Dashboard dem Netzwerk zugänglich zu machen. (#42578, #42578 — @benbarclay, @teknium1)
  • Offizieller WhatsApp Business Cloud API-Adapter – Neben der bestehenden Baileys-Brücke spricht Hermes jetzt die offizielle WhatsApp Business Cloud API – Metas gehosteter First-Party-Pfad ohne Bridge-Prozess. Richten Sie es auf Ihre Business-Zugangsdaten API und Hermes sendet WhatsApp über den unterstützten Kanal, ohne dass ein QR-Scanning-Bridge-Prozess aufrechterhalten werden muss. (#44331, #43921 — @jquesnelle, @teknium1)
  • Rich-Text für Telegram – Bot API 10.1 Rich-Nachrichten – Telegram-Antworten werden jetzt als richtige Rich-Nachrichten über Bot API 10.1 dargestellt: bessere Formatierung, sauberere Handhabung langer Nachrichten, natives Markup statt abgeflachtem Text. Es ist standardmäßig mit einer Opt-out-Funktion aktiviert, sodass Ihre Telegram-Konversationen auch ohne Konfiguration so aussehen, wie sie sollten. (#44829, #45584, #45953 — @teknium1)
  • Optimierung der Kuratorkosten – keine Aux-Modellausgaben für Routineläufe – Der Fertigkeitskurator bereinigt jetzt standardmäßig veraltete Fertigkeiten, führt jedoch seinen LLM-gestützten Konsolidierungsdurchlauf nicht mehr aus, es sei denn, Sie entscheiden sich dafür (curator.consolidate: true oder hermes curator run --consolidate). Der deterministische Inaktivitäts-Sweep läuft weiterhin kostenlos; Der rechthaberische, aux-model-ausgabende „Build Umbrella Skills“-Fork ist jetzt standardmäßig deaktiviert. Die routinemäßige Kuratierung im Hintergrund kostet Sie null Token. (#47840 — @teknium1)
