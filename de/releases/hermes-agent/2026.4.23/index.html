Hermes-Agent v2026.4.23

Hermes-Agent v0.11.0 (v2026.4.23)

Veröffentlichungsdatum: 23. April 2026 Seit v0.9.0: 1.556 Commits · 761 zusammengeführte PRs · 1.314 geänderte Dateien · 224.174 Einfügungen · 29 Community-Mitwirkende (290 einschließlich Co-Autoren)

Die Interface-Version – eine vollständige React/Ink-Neufassung des interaktiven CLI, eine steckbare Transportarchitektur unter jedem Anbieter, native AWS Bedrock-Unterstützung, fünf neue Inferenzpfade, eine 17. Messaging-Plattform (QQBot), eine erheblich erweiterte Plugin-Oberfläche und GPT-5.5 über Codex OAuth. Diese Version enthält außerdem alle Highlights, die von v0.10.0 (mit dem nur das Nous Tool Gateway ausgeliefert wurde) verschoben wurden – sodass etwa zwei Wochen Arbeit für den gesamten Stapel abgedeckt sind.

✨ Highlights

  • Neue Ink-basierte TUI – hermes --tui ist jetzt eine vollständige React/Ink-Neufassung des interaktiven CLI mit einem Python JSON-RPC-Backend (tui_gateway). Sticky Composer, Live-Streaming mit OSC-52 clipboard-Unterstützung, stabile Auswahltasten, Statusleiste mit Stoppuhr pro Runde und Git-Zweig, /clear-Bestätigung, Light-Theme-Voreinstellung und ein Subagent-Spawn-Beobachtbarkeits-Overlay. ~310 verpflichtet sich zu ui-tui/ + tui_gateway/. (@OutThisLife + Teknium)
  • Transport ABC + Native AWS Bedrock – Formatkonvertierung und HTTP-Transport wurden aus run_agent.py in eine steckbare agent/transports/-Schicht extrahiert. AnthropicTransport, ChatCompletionsTransport, ResponsesApiTransport und BedrockTransport besitzen jeweils ihre eigene Formatkonvertierung und API-Form. Native AWS Bedrock-Unterstützung über Converse API wird zusätzlich zur neuen Abstraktion geliefert. (#10549, #13347, #13366, #13430, #13805, #13814 — @kshitijk4poor + Teknium) – Fünf neue Inferenzpfade – Natives NVIDIA NIM (#11774), Arcee AI (#9276), Step Plan (#13893), Google Gemini CLI OAuth (#11270) und Vercel AI-Gateway mit Preisgestaltung + Dynamik Entdeckung (#13223 – @jerilynzheng). Außerdem wurde Gemini für eine bessere Leistung über das native AI Studio API weitergeleitet (#12674).
  • GPT-5.5 über Codex OAuth – Das neue GPT-5.5-Argumentationsmodell von OpenAI ist jetzt über Ihren ChatGPT Codex OAuth verfügbar, wobei die Live-Modellerkennung in die Modellauswahl integriert ist, sodass neue OpenAI-Versionen ohne Katalogaktualisierungen angezeigt werden. (#14720)
  • QQBot – 17. unterstützte Plattform – Nativer QQBot-Adapter über QQ Official API v2, mit QR-Scan-to-Configure-Setup-Assistent, Streaming-Cursor, Emoji-Reaktionen und DM/Gruppenrichtlinien-Gating, das der WeCom/Weixin-Parität entspricht. (#9364, #11831)
  • Plugin-Oberfläche erweitert – Plugins können jetzt Slash-Befehle registrieren (register_command), Tools direkt versenden (dispatch_tool), Tool-Ausführung von Hooks blockieren (pre_tool_call kann ein Veto einlegen), Tool-Ergebnisse neu schreiben (transform_tool_result), Terminalausgabe transformieren (transform_terminal_output), image_gen-Backends versenden und benutzerdefinierte Dashboard-Registerkarten hinzufügen. Das mitgelieferte Plug-in zur Datenträgerbereinigung ist standardmäßig als Referenzimplementierung aktiviert. (#9377, #10626, #10763, #10951, #12929, #12944, #12972, #13799, #14175)
  • /steer – Agenten-Anstupser während der Ausführung – /steer <prompt> fügt eine Notiz ein, die der laufende Agent nach seinem nächsten Tool-Aufruf sieht, ohne die Runde zu unterbrechen oder den Eingabeaufforderungs-Cache zu beschädigen. Für den Fall, dass Sie einen Agenten während des Flugs korrigieren möchten. (#12116)
  • Shell-Hooks – Verknüpfen Sie jedes Shell-Skript als Hermes-Lebenszyklus-Hook (pre_tool_call, post_tool_call, on_session_start usw.), ohne ein Python-Plugin zu schreiben. (#13296)
  • Webhook-Direktzustellungsmodus – Webhook-Abonnements können Nutzlasten jetzt direkt an einen Plattform-Chat weiterleiten, ohne den Agenten zu durchlaufen – Null-LLM-Push-Benachrichtigungen für Warnungen, Verfügbarkeitsprüfungen und Ereignisströme. (#12473)
  • Intelligentere Delegation – Subagenten haben jetzt eine explizite orchestrator-Rolle, die ihre eigenen Worker erzeugen kann, mit konfigurierbarem max_spawn_depth (Standardwert). Gleichzeitige Geschwister-Subagenten teilen den Dateisystemstatus über eine Dateikoordinationsschicht, sodass sie sich nicht gegenseitig bei ihren Änderungen überlasten. (#13691, #13718)
  • Hilfsmodelle – konfigurierbare Benutzeroberfläche + Hauptmodell zuerst – hermes model verfügt über einen speziellen Bildschirm „Hilfsmodelle konfigurieren“ für Überschreibungen pro Aufgabe (Komprimierung, Vision, Sitzungssuche, Titelgenerierung). Das auto-Routing verwendet jetzt standardmäßig das Hauptmodell für Nebenaufgaben für alle Benutzer (zuvor wurden Aggregatorbenutzer stillschweigend an eine kostengünstige Standardeinstellung auf der Anbieterseite weitergeleitet). (#11891, #11900)
  • Dashboard-Plugin-System + Live-Themenwechsel – Das Web-Dashboard ist jetzt erweiterbar. Plugins von Drittanbietern können ohne Forking benutzerdefinierte Registerkarten, Widgets und Ansichten hinzufügen. Gepaart mit einem Live-Switching-Themensystem – Themen steuern jetzt Farben, Schriftarten, Layout und Dichte – sodass Benutzer das Dashboard-Erscheinungsbild ohne Neuladen im laufenden Betrieb austauschen können. Die gleiche Themendisziplin wie der CLI, jetzt im Internet. (#10951, #10687, #14725)
  • Dashboard-Politur – i18n (Englisch + Chinesisch), React-Router-Sidebar-Layout, mobil-responsive, Vercel-Bereitstellung, echte sitzungsspezifische API-Anrufverfolgung und One-click-Update- und Gateway-Neustart-Schaltflächen. (#9228, #9370, #9453, #10686, #13526, #14004 – @austinpickett + @DeployFaith + Teknium)
