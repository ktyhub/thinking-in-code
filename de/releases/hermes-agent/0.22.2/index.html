Hermes-Agent v0.22.2

Veröffentlichungsdatum: 15. Oktober 2026

v0.22.1 wurde aus dem falschen Commit erstellt. Es wurden unveröffentlichte Gateway-Funktionen bereitgestellt, und die Microsoft Store-App konnte auf „Verbinden“ stehen bleiben. 0.22.2 ist die Version, für die 0.22.1 gedacht war.

Bekanntes Problem: Sitzungen, die unter dem Gateway 0.22.1 ausgeführt wurden, können in 0.22.2 nicht gelöscht werden.

<!-- HERMES_BUILDS_TABLE -->

Highlights

  • Das Gateway startet nach einem Neustart erneut. Nach einem Neustart kann Linux eine frühe PID an einen unabhängigen Prozess übergeben und das Gateway könnte sie mit einem laufenden Gateway verwechseln, sodass ein überwachtes Gateway (systemd, launchd, Docker) den Start verweigerte. Hermes zeichnet jetzt den Startvorgang auf, und wenn es nichts erkennen kann, fragt es nach der Host-Sperre, die nur ein Live-Gateway hält. (#138594, behebt #133744)
  • Lange lokale Modellrunden bleiben auf Laptops bestehen. Lokale Anfragen werden immer mit dem Lesefortschritt der Eingabeaufforderung gestreamt (in der Statuszeile angezeigt), Stopp-Timer überspringen die Zeit, in der sich die Maschine im Ruhezustand befand, ein wiederhergestellter lokaler Server erhält einen weiteren Versuch anstelle eines Unterbrechers, der bei jeder späteren Nachricht fehlschlägt, und die Komprimierung läuft nicht mehr ab, während der Server noch eine lange Konversation liest. Auf Windows-Unified-Memory-Maschinen sind der Modellstart und der Eingabeaufforderungscache so dimensioniert, dass Speicher frei wird. (#138560)

Nachfolgend finden Sie alles in der 0.22-Release-Reihe seit v0.22.0: die Fixes, die 0.22.1 liefern sollte, plus die beiden oben genannten. Arbeiten, die nur auf main möglich sind, werden mit v0.23.0 geliefert.
