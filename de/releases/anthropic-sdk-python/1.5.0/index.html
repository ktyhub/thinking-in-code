anthropisch-sdk-python v1.5.0

1.5.0 (10.09.2026)

Vollständiges Changelog: v1.4.0...v1.5.0

Funktionen

  • api: Auto-Modus-Tool-Berechtigungen für verwaltete Agenten hinzufügen (62aa21b)
  • api: content_too_large web_fetch-Tool-Fehlercode hinzufügen (4b5dec6)
  • api: Fügen Sie den Betawert „user-profiles-2026-09-04“ und „external_user_details“ zu Benutzerprofilen hinzu (5f881a5)
  • api: unterstützt das Mounten öffentlicher GitHub-Repositorys ohne Authorization_Token in Managed Agents-Sitzungen (285937c)
  • client: Message.to_param() und BetaMessage.to_param() hinzufügen (192a2b2)
  • Anmeldeinformationen: CredentialsError und IdentityTokenFileError hinzufügen (9acd79f)
  • Tools: Akzeptieren Sie Toolobjekte direkt in Nachrichten. Erstellen, Parsen, Streamen und Zählen von Tokens (ebd2fc5)

Fehlerbehebungen

  • client: extra_body zusammenführen, bevor client-Hooks ausgeführt werden (7aaf887)
  • Anmeldeinformationen: Anmeldeinformationsdateien ablehnen, auf die eine Gruppe oder andere zugreifen können (7af3e2b)
  • Streaming: Teilweise Werkzeugeingabe JSON von Inhaltsblöcken fernhalten (4605bca)
  • Typen: parsed_output aus ausgegebenen Textblöcken herauslassen (ca0706d)

Aufgaben

  • client: Bereinigen Sie die nicht verwendete Idempotenz-Anfrageoption (c97830c)
  • client: Behalten Sie die Anforderungsoption idempotency_key als veraltete No-Op bei (#621) (c2ab92e)
  • docs: Korrigieren Sie die Feldbeschreibung des Umgebungsbereichs (b903ee0)
  • intern: generierte Datei-Header-Kommentare entfernen (ae671f8)
  • intern: Paketversion wiederherstellen (f3aefc7)
  • intern: Paketversion wiederherstellen (e3c70e8)
  • intern: stoppt das Stempeln der Paketversion in generierte Dateien (e7a6a28)
  • Tests: Leere Testpaket-Markierungsdateien wiederherstellen (0803af0)
