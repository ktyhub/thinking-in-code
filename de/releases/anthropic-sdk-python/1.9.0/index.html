anthropisch-sdk-python v1.9.0

1.9.0 (28.09.2026)

Vollständiges Changelog: v1.8.0...v1.9.0

Funktionen

  • api: den Denktyp between_tools hinzufügen (a9a577d)
  • api: claude-sonnet-5-5 hinzufügen (a5a25e9)
  • api: include_inherited und Quelle zu Workspace-Ratenbegrenzungen hinzufügen (0bf4af8)
  • api: Fügen Sie typisierte Ereignistypwerte zum Ereignislistenfilter „Managed Agents“ hinzu (1b82cd9)
  • api: Cache-Diagnose GA – Diagnose für Message / MessageCreateParams (22062b8)
  • Tools: optional Toolaufrufe ausführen, während die Antwortströme (26d0812)

Fehlerbehebungen

  • client: keinen Platzhalter-Dateinamen für unbenannte Datei-Uploads senden (9e9709d)
  • Helfer: Reduzieren Sie das Between_tools-Denken auf „Deaktiviert“ bei Fallback-Hops (#952) (a3834d4)
  • Nachrichten: akzeptieren Diagnosen in stream() und parse() (#929) (fad840c)

Aufgaben

  • api: listet die bekannten Modell-IDs zuerst in den Modelltypen auf (e5a082a)
  • ci: Wählen Sie den CI-Runner nach Repository (39ccf62)
  • client: Stoppen Sie das Senden des Beta-Headers von Parse und Tool Runner (#907) (1428100)
  • docs: klarstellen, dass stream: true den rohen Ereignisstream zurückgibt (82918fa)
  • Dokumente: Akteurbeschreibungen verwalteter Agenten ressourcenneutral gestalten (34ef524)
  • docs: Wiederherstellung des Forschungsvorschau-Hinweises für den Dream-Typ (f03e32e)

Dokumentation

  • Feld-Docstring-Abstandsregel zu CLAUDE.md hinzufügen (e5c35f4)
  • api: Bevorzugen Sie die eigene Beschreibung jedes Felds gegenüber der seines gemeinsamen Typs (d79a2e7)
  • claude.md: Funktionskörperabstandsregel hinzufügen (3174f8f)
  • importierbare Typnamen in api.md auflisten (56a42ab)
