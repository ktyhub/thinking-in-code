anthropic-sdk-python v2.9.0

Diese Seite ist maschinell übersetzt. Maßgeblich ist der englische Originaltext.

anthropisch-sdk-python v2.9.0

Funktionen

  • api: Quell- und Fehlercodes zu den Leseendpunkten der RBAC-Rolle hinzufügen
  • api: Update-Bundle hinzufügen, das die Anweisungen eines Claude-Tag-Bundles festlegt und Anweisungen für das Bundle zurückgibt

Fehlerbehebungen

  • Anmeldeinformationen: Schreiben Sie die Anmeldeinformationsdatei unter Windows mit Python 3.12 und früher
  • Tools: Vergleichen Sie Verzeichnisnamen genau, wenn Sie Dateitools und Upload-Pfade unter Windows einschränken
  • Tools: Datei-Toolpfade vollständig auflösen, die über einen baumelnden Symlink verlaufen
  • Tools: Ripgrep-Konfigurationsdateien im Grep-Tool des Agent-Toolsets ignorieren
  • Tools: Behalten Sie ein vorhandenes Skill-Verzeichnis bei, wenn der Download oder die Extraktion, die es ersetzen würde, fehlschlägt
  • Tools: hält den max_idle-Countdown des Sitzungstool-Runners am Laufen, wenn ein Sitzungsthread beendet wird Wenn der Läufer den Ereignisverlauf der Sitzung nach einer erneuten Verbindung nicht lesen kann, bricht eine Beendigung, die dann im Ereignisstrom eintrifft, den Countdown immer noch ab, bis der nächste inaktive oder erfolgreiche Lesevorgang erfolgt.
  • Tools: Belassen Sie symbolische Links, die außerhalb von /memories verweisen, aus den Auflistungen
  • Tools: Suchen Sie nach Ripgrep nur in absoluten PATH-Einträgen im Grep-Tool des Agent-Toolsets Das Tool führt kein rg mehr aus einem relativen oder leeren PATH-Eintrag oder, unter Windows, aus dem aktuellen Verzeichnis aus. Unter Windows wird nach rg.exe gesucht, sodass ein rg.cmd, rg.bat oder rg.com nicht mehr verwendet wird. Bei keinem anderen rg auf PATH nutzt das Tool seine integrierte Suche.
  • tools: Übergeben Sie ein RG innerhalb der Verzeichnisse, in die die Dateitools des Agent-Toolsets schreiben können grep übergibt ein rg, das irgendwo innerhalb von workdir oder allowed_roots aufgelöst wird, unabhängig von der Groß-/Kleinschreibung der Namen. Es verwendet das nächste rg auf PATH oder die integrierte Suche, wenn es keine gibt. Bei einem workdir, der alle rg auf dem Host enthält, z. B. /, ist jede Suche eine integrierte Suche. rg erhält nicht mehr die ANTHROPIC_*-Variablen des Prozesses, wie die Shell von bash.
  • Tools: Speicherdateien nur über den validierten Pfad lesen
  • Tools: liest nur reguläre Dateien in der integrierten Suche des Grep-Tools Die integrierte Suche von grep erfolgt über einen FIFO oder ein Gerät in dem Verzeichnis, das sie durchsucht, wie dies bei Ripgrep der Fall ist. Das Lesen könnte die Suche und die damit verbundene Ereignisschleife für immer blockieren.
  • Tools: verhindert, dass EnvironmentWorker Tools für eine beendete Sitzung ausführt Bei einer beendeten Sitzung erzwingt der Worker nun das Stoppen des Arbeitselements direkt nach dem Abrufen der Sitzung, bevor er Fertigkeiten oder Speicherspeicher herunterlädt. Für eine solche Sitzung wird SessionMemoryError nicht mehr ausgelöst. Der API meldet eine archivierte Sitzung als terminated.
  • Tools: Stoppen Sie das Grep-Tool nach 30 Sekunden CPU-Zeit, wenn Ripgrep nicht installiert ist
  • Tools: Verhindern Sie, dass der Sitzungstool-Runner die Toolaufrufe eines beendeten Sitzungsthreads ausführt Der Runner gibt diese Aufrufe auch nicht mehr weiter, einschließlich eines verweigerten Aufrufs (confirmation="deny") und eines Aufrufs an ein Tool, das ihm nicht gehört. Die einzige Ausnahme ist ein Aufruf, dessen Tool bereits ausgeführt wird, wenn der Thread beendet wird: Der Läufer gibt ihn mit posted=False zurück und sendet kein Ergebnis.

Aufgaben

  • api: veraltete Beta-Header-Werte Der API akzeptiert diese Werte weiterhin, aber eine spätere Version entfernt sie aus den SDKs. Löschen Sie prompt-caching-2024-07-31, pdfs-2024-09-25, token-counting-2024-11-01, token-efficient-tools-2025-02-19, extended-cache-ttl-2025-04-11, cache-diagnosis-2026-04-07 und ce-user-management-2026-07-13 aus Ihren Anfragen. files-api-2025-04-14 und skills-2025-10-02 wählen die Beta-Antwortformen aus. Befolgen Sie daher die Migrationsleitfäden für Dateien API und Skills, bevor Sie sie löschen. In C# haben die Mitglieder der AnthropicBeta-Enumeration neue Nummern, sodass Code, der mit einer früheren SDK-Version kompiliert wurde, einen anderen Betawert ohne Fehler sendet, bis Sie ihn neu erstellen.
  • api: stoppt das Senden eines alten Beta-Headers bei Batch-Anfragen beta.messages.batches sendet nicht mehr message-batches-2024-09-24, was der API nicht benötigt. Wenn Ihr client einen Standard-anthropic-beta-Header festlegt, senden diese Anfragen ihn jetzt, während er in einigen SDKs durch den alten Wert ersetzt wurde. Der API akzeptiert weiterhin den alten Wert. Wenn Sie es selbst festlegen, löschen Sie es: Eine spätere Version entfernt es von den SDKs.
  • docs: Fügen Sie einen Beispielwert für den Arbeitsbereichsnamen hinzu
  • Dokumente: klären, wann die automatische Berechtigungsrichtlinie einen Toolaufruf verweigert
  • docs: klären, an welche Arbeitsbereiche ein externer Schlüssel angehängt werden kann
  • docs: empfehlen multiagent_20261001 anstelle des Koordinatortyps
  • docs: sagen, wann organization_id für Plugin-Lesevorgänge erforderlich ist
  • Tests: Lassen Sie ungenutzte Testmitarbeiter an in der Warteschlange stehenden Tests teilnehmen
