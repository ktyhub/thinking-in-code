Ragflow v0.26.4

Zusammenfassung

Veröffentlicht am 7. Juli 2026.

Neue Funktionen

  • NLP/Tokenisierung: Fügt einen sprachbewussten Snowball-Stemmer hinzu, der 16 Sprachen unterstützt, integriert den Datensatzparameter language in der gesamten Tokenisierungspipeline und fügt Niederländisch zum Frontend hinzu. #14140

Fehlerbehebungen

– Beim Parsen von LM-Studio-Modellnamen, die ein „@“-Symbol enthalten, stürzte das System mit einem ValueError ab. #16467 – Der MCP-Server ist abgestürzt, weil die list_chats-Funktion eine Liste vom /chats API erwartete, stattdessen aber ein paginiertes Wörterbuch erhielt. #16639 – Der Docling-Parser hat mathematische Formeln stillschweigend aus Dokumenten gelöscht, anstatt sie zu extrahieren. #16645 – Das System konnte Inline-Änderungen an Metadatenwerten nicht im Backend speichern. #16655 – Das System hat vorhandene Links entfernt, wenn Dateien in großen Mengen mit Datensätzen verknüpft wurden. #16587

  • Der Filter konnte Chinesisch nicht verwenden. #16673 – Das System konnte nicht erzwingen, dass Tag-Gewichtungen größer als Null sein müssen. #16657 – Das Layout des Dropdown-Menüs der Agentenaufforderung wurde falsch dargestellt. #16653
  • Der Laws-Chunker hat Querverweise mit gepunkteten Zahlen fälschlicherweise als Überschriften klassifiziert. #16626 – Das System konnte nicht verhindern, dass Benutzer während des Bearbeitungsvorgangs doppelte MCP-Servernamen speichern. #16588 – Das System ermöglichte es Benutzern, eine leere MCP-Serverauswahl zu exportieren. #16589
