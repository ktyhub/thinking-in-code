bookkeeper release-4.17.2

Release Veröffentlicht5. Juli 2025 Quelleapache/bookkeeper Englisches Original

Diese Seite ist maschinell übersetzt. Maßgeblich ist der englische Originaltext.

Buchhalterfreigabe-4.17.2

Die Version 4.17.2 enthält mehrere Fehlerbehebungen und wenige Abhängigkeitsaktualisierungen.

Benutzern von Apache BookKeeper wird empfohlen, ein Upgrade auf 4.17.2 durchzuführen, wenn Sie 4.17.x verwenden. Die technischen Details dieser Version sind unten zusammengefasst.

Highlights

Fehler

  • Behebung eines NPE-Fehlers nach dem Refactor-Recycler von BookieClient PR #4610
  • Speicherleck im Netty-Recycler des Buchmachers Client behoben PR #4609
  • Behebung des Datenverlustproblems, das durch den falschen Eintragsprotokoll-Header verursacht wurde PR #4607
  • Korrigieren Sie den Coredump, der auftritt, wenn KeyValueStorageRocksDB.count aufgerufen wird, nachdem rocksdb geschlossen wurde PR #4581
  • Korrigieren und verbessern Sie das Auffinden von RocksDB-Konfigurationsdateien PR #4560
  • [Fix] Der Schreibvorgang bleibt aufgrund eines ausstehenden Add-Callbacks durch mehrere Threads hängen PR #4557
  • Behebung, dass SST-Dateien im Standortordner nicht bereinigt werden PR #4555
  • Korrigieren Sie die Tune-Runner-VM-Aktion, damit sie korrekt auf dem ubuntu-24.04-Image ausgeführt wird PR #4536
  • [cli] Fix: Wiederherstellungsbefehl akzeptiert keinen Ratenbegrenzungsparameter PR #4535
  • „pendingDeletedLedgers“ beheben, Ledger-Fehler nicht entfernen PR #4525
  • Behebung eines Problems, bei dem die Festplattengewichtung der Regionsbezogenen Platzierungsrichtlinie nicht aktualisiert wird. PR #4522
  • Das Problem mit dem Speicherverlust beim Überprüfen des Lesefehlers beim Eintrag wurde behoben. PR #4513
  • [Fix] in Adresse2Region entfernen, während der Buchmacher gegangen ist, um die korrekten Rack-Informationen zu erhalten PR #4504
  • Fix: Netcat-openbsd anstelle von Netcat im Test-Image-Build installieren PR #4476
  • [fix][ci] OWASP-Abhängigkeitsprüfungs-Download mithilfe des NVD-Schlüssels API behoben PR #4473
  • Behebung des ReadOnlyLedgerHandle-Leckproblems bei checkAllLedgers. PR #4468
  • fix[rocksdb]: Fehler in der rocksdb-Standardkonfiguration für CFOptions behoben PR #4466
  • [Fix] Datenverlust behoben, der beim Schreiben des Ledgers und beim Löschen des Legders bei gleichzeitiger Ausführung auftritt PR #4462
  • [BugFix] Fix zur Verhinderung von Ressourcenlecks in 3 Klassen PR #4449
  • Korrigieren Sie RackawareEnsemblePlacementPolicyImpl defaultRack, wenn der Buchmacher nicht verfügbar ist. PR #4439
  • Behebung des CompletionObjects-Leckproblems. PR #4285
  • Problem 2161: Metriken für den Endpunkt-Inhaltstyp festlegen PR #4208

Verbesserungen

  • Passen Sie den DNS-Cache-Ablauf in Tests an, um Test-Timeout-Fehler zu reduzieren PR #4586
  • Ändern Sie das neue Ensemble-Protokoll auf die Infoebene PR #4566
  • Dokumentation zur RocksDB-Konfiguration zu bk_server.conf hinzufügen PR #4561
  • MetadataLock-Konflikt in LedgerHandle reduzieren PR #4549
  • [Verbessern] Wenn Rackaware keinen Buchmacher auswählen konnte, drucken Sie die Liste des Ensembles aus. PR #4482
  • Stellen Sie sicher, dass formatVersion für alle RocksDB-Datenbanken angegeben ist PR #4559
  • Setzen Sie die Standardformatversion für RocksDB-Datenbanken auf 5 PR #4480
  • [verbessern] ReorderReadSequence optimieren, um WriteSet zu überprüfen PR #4478
  • Anweisungen zum Update des Release-Skripts und Python-Veröffentlichungsskripts PR #4458
  • Aktivieren Sie ZooKeeper client, um eine Verbindung im schreibgeschützten Modus herzustellen PR #4244
  • Allocator unterstützt die ExitOnOutOfMemory-Konfiguration. PR #3984

Abhängigkeitsaktualisierungen

  • Aktualisieren Sie commons-beanutils auf 1.11.0, um CVE-2025-48734 PR #4608 zu beheben.
  • Veraltete Commons-Konfiguration 1.x auf Commons-Konfiguration 2.x migrieren PR #4604
  • Aktualisieren Sie Jetty auf 9.4.57.v20241219, um CVE-2024-6763 PR #4600 zu entschärfen.
  • Upgrade von Netty auf 4.1.121.Final PR #4597
  • Upgrade auf grpc 1.72.0 PR #4591
  • Aktualisieren Sie die OpenTelemetry-Version und richten Sie Versionen mithilfe von Stücklisten aus PR #4589
  • Upgrade von Netty auf 4.1.119, tcnativ auf 2.0.70 und io_uring auf 0.0.26 PR #4584
  • Aktualisieren Sie die Apache Commons-Bibliotheken auf kompatible Versionen PR #4582
  • Erhöhen Sie vertx.version von 4.5.7 auf 4.5.11, um CVE-2024-8391 PR #4545 zu beheben.
  • Upgrade auf Netty 4.1.115.Final zur Behebung von CVE-2024-47535 PR #4524
  • Aktualisieren Sie Zookeeper auf 3.9.3, um CVE-2024-51504 PR #4523 zu beheben.
  • Upgrade von gRPC auf 1.70.0 PR #4512
  • Protobuf auf 3.25.5 aktualisieren, um CVE-2024-7254 PR #4508 zu beheben
  • Upgrade auf Netty 4.1.113.Final und netty-tcnative 2.0.66.Final PR #4502
  • Erhöhen Sie grpc von 1.56.0 auf 1.64.0, um die CVE-Liste zu adressieren PR #4344
