Hyperframes v0.9.63

HyperFrames v0.9.63

Veröffentlicht am 17.11.2026.

Die versiegelte Vorschau von Studio zeigt Audiometer und Audiogruppen, eine Neuordnung der Ebenen ist ein Schritt zum Rückgängigmachen und Textfilme beginnen früher. Kein HyperFrames-Server stellt eine Projektdatei als Skript für einen Servicemitarbeiter bereit. Diese Version enthält auch alle für 0.9.62 aufgeführten Änderungen. Diese Version erreichte npm nie: Die Zusammenführungswarteschlange landete sie in einem Push mit einem anderen PR, und die Veröffentlichung las nur den letzten Commit des Pushs. Seit #8077 veröffentlicht ein Release aus seinem eigenen Commit im Push.

Funktionen

  • Kern: Die Vorschau kann die Geometrie eines Elements in jedem Frame an den Editor streamen (f9c5ed07b, #8052).

Leistung

  • Engine: Standbilder auf mehreren Seiten gleichzeitig prüfen, damit Textfilme früher beginnen (8ec97da01, #7997).
  • Produzent: Frames beginnen mit dem Zeichnen, während der Audiomix fertig ist (0be1a0719, #7985).

Korrekturen

  • CLI, Produzent, Inspektor: Render-, Capture- und Inspektorserver stellen niemals das Skript eines Servicemitarbeiters bereit (72925380c, #8073).
  • Studio: Eine Ebenen-Neuordnung ist ein erneuter Rückgängig-Schritt (df31ce2b1, #8072).
  • Studio: Audioanzeigen und Audiogruppen funktionieren in einer versiegelten Vorschau (93a4d29c0, #8011).
  • Studio: Durch das Hinzufügen eines Tracks werden nicht mehr alle clip auf der Timeline erneut bereitgestellt (b064e40e1, #8068).
  • Studio Server: Eine Projektdatei wird niemals als Skript eines Servicemitarbeiters bereitgestellt (b4acc1a1d, #8064).
  • Studio: Ein Servicemitarbeiter, der ein Projekt zurückgelassen hat, ist verschwunden, bevor ein Vorschaubild geladen wird (7a0bec682, #8067).
  • Kern: Ein gehaltenes Videobild wird durch einen VideoFrame gezeichnet, der nach dem Zeichnen geschlossen wird (43e5b7cec, #7971).
  • Produzent: Lassen Sie externe Links standardmäßig aus den Site-Auflistungen heraus und warnen Sie SDK-Anrufer (fbb483852, #8065).

Intern

  • Veröffentlichen: Eine Veröffentlichung, die in einem Push mit anderen PRs zusammengeführt wird, veröffentlicht mit ihrem eigenen Commit (9b565c8e0, #8077).
  • Veröffentlichen: Veröffentlichen Sie auf npm mit dem OIDC-Token des Jobs, nicht mit einem gespeicherten Token (c106793f7, #8070).
  • Kern: Beim Reloaded-Video-Playhead-Test wird ein kleinerer Film erstellt, sodass bei ausgelastetem CI nie eine Zeitüberschreitung auftritt (34f98e6a0, #8069).
  • Studio: Die Bearbeitungsbank liest eine versiegelte Vorschau über ihren Bearbeitungsanschluss (5f8b7a6ee, #8010).
