Hyperframes v0.9.59

HyperFrames v0.9.59

Veröffentlicht am 16.11.2026.

Der Vorschau-Player erhält eine Vollbild-Schaltfläche, und bei einem fehlgeschlagenen Rendern wird nun angezeigt, warum. Renderings, Studio und der CLI bleiben bei den projekteigenen Dateien und bei öffentlichen Medienhosts.

Funktionen

  • CLI: Diff --hide bewertet die Ebene eines Projekts anhand dessen, was es hinzufügt (e6d5c699b, #7972).
  • Player: Fügen Sie dem Vorschau-Player eine Vollbild-Schaltfläche hinzu (5be6c1580, #7726).
  • Kern: Describe-Antworten tragen die Elementbezeichnung des Pickers und Studio-Exporte stehenInHandle (51ae92510, #7936).

Korrekturen

– Versteckte Dateien und Anmeldedaten bleiben aus Studio, Verlauf und Lint fern (c68c78445, #7979).

  • Kern: Eine Seite, die für eine andere Site markiert ist, ermöglicht dieser Site nur die Wiedergabe (c4d607c7f, #7980).
  • Studio Server: Keine Schreibroute berührt Dateien, die andere Tools ausführen oder trust (2a28e4368, #7964).
  • CLI: Die Skills-Update-Prüfung liest niemals die Git-Konfiguration eines Projekts (e368db138, #7975).
  • Lint: Führen Sie Studio aus und produzieren Sie Lint vom eigenen Thread des Hosts (778a00564, #7974).
  • Produzent: Medienstandards für Unterkompositionen prüfen (95e4e7f88, #7550).
  • CLI: Validieren und Keyframes drucken Projekttext mit Steuerzeichen als sichtbare Escapezeichen (ce8d55d30, #7958).
  • Prüfen: Eine Medienquelle, die nicht geladen werden konnte, wird nicht als Zeitüberschreitung gemeldet (5e0c3db12, #7954).
  • CLI: In der Hilfe wird die Standardeinstellung jeder Option einmal angezeigt (d7f8d77fb, #7953).
  • CLI: Rendern --json gibt jedem fehlenden Werkzeug, einem gehaltenen Slot und einem alten Knoten einen eigenen Code (47d007e5b, #7842).
  • Sdk Playground: Die Vite-Konfiguration wird auf Knoten 22 vor 22.18 geladen (c7876f333, #7805).
  • Überprüfen: Markieren Sie einen Kontrastbefund nach seinem Schweregrad und zitieren Sie seinen Text (ec5a4e2a1, #7752).
  • Player: Der Fix für das Einfrieren der Vorschau, wenn viele clips eine lange Aufnahme teilen, wurde aus dieser Version entfernt, da eine App, die die Vorschau einbettete, daran gehindert wurde, eine Bearbeitung anzuzeigen (42508c1ef, #7795; zurückgesetzt durch 33e1a36a3, #7978). – Snapshot überspringt private Dateien, keine Text-Art-Demuxer, maskierter Warntext (8959deb00, #7943).
  • CLI: Capture benennt den Port seines lokalen Seitenservers im Bypass-Eintrag (a9b0371c8, #7965).
  • CLI: Ein fehlgeschlagenes Rendern gibt den Grund an, auch bei einem Absturz oder einem stillen Beenden (2623ded13, #7957).
  • Studio: Eine lange Audiodatei von außerhalb des Projekts wird niemals hinsichtlich ihrer Wellenform dekodiert (c77cd301c, #7961).
  • Veröffentlichen: Laden Sie nur das hoch, was npm als überprüft liest; Tags veröffentlichen nur Main-, Next- oder Alpha-Commits (5f4637977, #7959).
  • Engine: Medien-URL-Lesevorgänge erreichen nur öffentliche Hosts in einem eingeschränkten Seitennetzwerk (994fbbde2, #7946).
  • Cli,engine: Den direkten Host des Seitenservers an einen expliziten Port und den Studio-eigenen Ursprung anheften (dbc9c1826, #7945).
  • Produzent: Ein Renderer, der auf einen langen Audiomix wartet, gibt an, dass er Audio verarbeitet (df698a029, #7952).
  • Kern: Eine Erfassungsseite lädt ein clip ohne festgelegte Länge nur dann, wenn es fällig ist (9e5048772, #7938).
  • Studio: Die Beat-Analyse wählt niemals eine Aufnahme aus, die länger als ein Lied ist (87955b890, #7944).
  • CLI: Eigenes Render-Slot-Sperrverzeichnis; Cache-Dateien ablehnen, in die andere Konten schreiben können (071a2da0b, #7951).
  • CLI: Schreiben Sie Projektdatensätze niemals über Symlinks unter .hyperframes (061ff5bbb, #7950).

Dokumente und Beispiele

  • Changelog: Wöchentliche Zusammenfassung 2026-11-09-2026-11-16 (af873924d, #7969).
  • Veröffentlichen: Angenommen, die Veröffentlichung wartet auf keine Genehmigung und nur Administratoren pushen Vorabversions-Tags (a707e4737, #7960).

Katalog

  • CLI: Escape-Steuerzeichen in Projekt-, Seiten- und Registrierungstext (6f88be394, #7913).
  • Mcp: Führen Sie die MCP-Registrierungsveröffentlichung in der mcp-registry-Umgebung aus (45ff3526c, #7966).
  • Ci: Ein Katalogveröffentlichungslauf, den main überholt hat, endet sauber, anstatt fehlzuschlagen (77e675574, #7816).
