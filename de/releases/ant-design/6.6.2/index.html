ant-design 6.6.2

Patch Veröffentlicht28. Aug. 2026 Quelleant-design/ant-design Englisches Original

Diese Seite ist maschinell übersetzt. Maßgeblich ist der englische Originaltext.

Ameisendesign 6.6.2

  • ♿ Verbessern Sie die Zugänglichkeit von Fortschritt, Schritten und Tooltips, indem Sie redundante SVG-Ankündigungen vermeiden, das Schrittelement onClick bei Tastaturaktivierung auslösen und bestehende Tooltip-aria-describedby-Beziehungen beibehalten. #59139 @github-actions
  • 🐞 Korrektur der numerischen 0-Inhaltsdarstellung in den Bereichen Alert, Empty, Card, Tag, Breadcrumb, Segmented, FloatButton, Form.Item und Statistic. #59117 #59094 #59079 #59101 @bhumin18 @QDyanbing @doggledogle
  • 🤖 Behebung eines Problems mit den Typdefinitionen „Alert global closable“ und „Select and AutoComplete onPopupVisibleChange“, die nicht unterstützte Rückrufe oder Requisiten fälschlicherweise offenlegten. #59100 #59142 @QDyanbing
  • Menü
    • ⌨️ Korrigieren Sie doppelte Menü-Popup-IDs in mehreren Instanzen. #59048 @zombieJ
    • 🐞 Behebung eines unerwarteten Schließens horizontaler Untermenüs im Menü, wenn sich der Zeiger von einem Element zu seinem Popup bewegt. #59088 @EmilyyyLiu
    • 🐞 Problem behoben, bei dem sich Menüsymbole weiterhin bewegen, nachdem ein Inline-Menü vollständig ausgeblendet wurde. #59085 @QDyanbing
  • Übertragen
    • 🐞 Behebung des Problems, dass das Kontrollkästchen „Alle auswählen“ übertragen weiterhin aktiviert bleibt, wenn alle Suchergebnisse deaktiviert sind. #59121 @QDyanbing
    • 🐞 Fix Transfer rendert keine Elemente, nachdem gefilterte Daten aus einem leeren Ergebnis wiederhergestellt wurden. #59074 @biubiukam
  • Tisch
    • 🐞 Korrigiert, dass sortierbare Tabellenspalten keine benutzerdefinierten onKeyDown-Handler für andere Tasten als Enter aufrufen. #59078 @QDyanbing
    • 🐞 Behebung eines Problems, bei dem die Tabelle beim Schließen des integrierten Filter-Dropdowns zweimal filterDropdownProps.onOpenChange(false) auslöste. #59023 @thlovey
  • Baum
    • 🐞 Behebung, dass Tree.DirectoryTree Knoten nicht erweitern oder auswählen konnte, wenn expandedKeys oder selectedKeys explizit undefined ist. #59076 @giaBaoJS
    • 🐞 Fix Tree.DirectoryTree Shift-Bereichsauswahl beim Start von einem Knoten, dessen key numerisch 0 ist. #59029 @QDyanbing
  • Liste
    • 🐞 Korrektur der erneuten Bereitstellung von Elementen, wenn rowKey den numerischen Wert 0 zurückgibt. #59113 @nrps9909
    • 🛎 Warnung zur veralteten Liste aktualisieren, um die Migration zu Listy zu empfehlen. #59060 @QDyanbing
  • 🐞 Behebung, dass Checkbox.Group disabled={false} den globalen deaktivierten Status für JSX-Kinder nicht überschreiben konnte. #59109 @QDyanbing
  • 🐞 Problem behoben, bei dem beim Hochladen ausgeblendete Canvas-Elemente im DOM zurückblieben, nachdem GIF-Vorschauen generiert wurden. #59137 @dogledogle
  • 🐞 Behebung eines Problems mit den Schaltflächen zum Schließen von Benachrichtigungen, die dazu führten, dass beigefügte Formulare unbeabsichtigt übermittelt wurden. #59126 @nrps9909
  • 🐞 Behebung, dass der Aktionsbereich im Schubladen-Header nicht gerendert wird, wenn nur die Requisite extra bereitgestellt wird. #59089 @dogledogle
  • 🐞 Behebung eines Problems, bei dem die Grid Row veraltete Klassen align und justify beibehält, nachdem die Requisiten entfernt wurden oder responsive Haltepunkte nicht mehr übereinstimmen. #59066 @QDyanbing
  • 🐞 Behebung, dass Tag.CheckableTag local style vom ConfigProvider tag.style überschrieben wird. #59087 @QDyanbing
  • ♿ Verbessern Sie die Zugänglichkeit von Stufen, indem Sie die Pfeile der dekorativen Tafel vor unterstützender Technologie verbergen. #59105 @nrps9909
  • ♿ Verbessern Sie die Zugänglichkeit von Skeleton.Image, indem Sie die dekorative Platzhaltergrafik vor unterstützender Technologie verbergen. #59107 @nrps9909
  • 🐞 Fix Beschreibungen, die den Artikelstatus zurücksetzen, nachdem ein Artikel mit key: 0 neu bestellt wurde. #59064 @QDyanbing
  • 🐞 Korrigieren Sie, dass Cascader und Cascader.Panel den standardmäßigen leeren Zustand anzeigen, wenn notFoundContent null ist. #59028 @QDyanbing
  • 🐞 Behebung eines Fehlers beim Wasserzeichen, wenn content gleich undefined ist. #59077 @VamoBao
  • 📖 Korrigieren Sie Komponenten-LLMs-Links auf Website-Spiegeln und lokalen Bereitstellungen. #59062 @QDyanbing
  • ♿ Optimieren Sie die Barrierefreiheit von Fortschritt, Schritten und Tooltip, vermeiden Sie, dass die Fortschrittsbalken-SVG wiederholt gelesen wird, stellen Sie sicher, dass onClick ausgelöst wird, wenn das Schrittelement über die Tastatur aktiviert wird, und behalten Sie die bestehende aria-describedby-Zuordnung von Tooltip bei. #59139 @github-actions
  • 🐞 Das Problem wurde behoben, bei dem Alert, Empty, Card, Tag, Breadcrumb, Segmented, FloatButton, Form.Item und Statistic den Wert 0 Content nicht korrekt darstellen konnten. #59117 #59094 #59079 #59101 @bhumin18 @QDyanbing @doggledogle
  • 🤖 Es wurde ein Problem behoben, bei dem der onPopupVisibleChange-Typdefinitionsfehler von Alert global closable, Select und AutoComplete offenlegte, dass Rückrufe oder Eigenschaften nicht unterstützt werden. #59100 #59142 @QDyanbing -Menü
    • ⌨️Das Problem doppelter Popup-IDs zwischen mehreren Menüinstanzen wurde behoben. #59048 @zombieJ
    • 🐞 Das Problem wurde behoben, bei dem das Untermenü unerwartet geschlossen wurde, wenn die Maus im Menü-Querformat vom Menüelement zur Untermenü-Popup-Ebene bewegt wurde. #59088 @EmilyyyLiu
    • 🐞 Das Problem wurde behoben, bei dem sich das Menüsymbol weiterhin verschiebt, nachdem das Inline-Menü verkleinert wurde. #59085 @QDyanbing
  • Übertragen
    • 🐞 Das Problem wurde behoben, bei dem das Kontrollkästchen „Alle auswählen“ immer noch verfügbar ist, wenn alle Übertragungssuchergebnisse deaktivierte Elemente sind. #59121 @QDyanbing
    • 🐞 Beheben Sie das Problem, bei dem Listenelemente nicht angezeigt werden, nachdem die Übertragung Daten aus leeren Filterergebnissen wiederhergestellt hat. #59074 @biubiukam -Tisch
    • 🐞 Das Problem wurde behoben, bei dem sortierbare Tabellenspalten keine benutzerdefinierten onKeyDown-Rückrufe ohne Eingabetaste auslösten. #59078 @QDyanbing
    • 🐞 Beheben Sie das Problem, dass filterDropdownProps.onOpenChange(false) wiederholt ausgelöst wird, wenn Table das integrierte Filterfeld schließt. #59023 @thlovey -Baum
    • 🐞 Das Problem, dass Tree.DirectoryTree nicht erweitert oder ausgewählt werden kann, wenn expandedKeys oder selectedKeys explizit in undefined übergeben wird, wurde behoben. #59076 @giaBaoJS
    • 🐞 Das Problem wurde behoben, bei dem die Auswahl des Verschiebungsbereichs fehlschlug, wenn Tree.DirectoryTree von einem Knoten mit den Werten key bis 0 startet. #59029 @QDyanbing
  • Liste
    • 🐞 Das Problem der erneuten Bereitstellung von Listenelementen durch die Liste, wenn rowKey den Wert 0 zurückgibt, wurde behoben. #59113 @nrps9909
    • 🛎 Warnung vor veralteter Update-Liste. Wir empfehlen die Migration zu Listy. #59060 @QDyanbing
  • 🐞 Das Problem, dass Checkbox.Group disabled={false} den globalen deaktivierten Status im JSX-Szenario für untergeordnete Knoten nicht überschreiben kann, wurde behoben. #59109 @QDyanbing
  • 🐞 Das Problem, dass ausgeblendete Canvas-Elemente im DOM verblieben, nachdem beim Hochladen eine GIF-Vorschau generiert wurde, wurde behoben. #59137 @dogledogle
  • 🐞 Das Problem wurde behoben, bei dem die Schaltfläche zum Schließen der Benachrichtigung das äußere Formular unerwartet übermittelte. #59126 @nrps9909
  • 🐞 Beheben Sie das Problem, dass der Kopfoperationsbereich nicht gerendert wird, wenn Drawer nur das extra-Attribut festlegt. #59089 @dogledogle
  • 🐞 Behebung eines Problems, bei dem die Rasterzeile den alten Namen der Ausrichtungsklasse beibehält, nachdem die Attribute align, justify entfernt wurden oder responsive Haltepunkte nicht mehr übereinstimmen. #59066 @QDyanbing
  • 🐞 Das Problem wurde behoben, bei dem der lokale style von Tag.CheckableTag durch ConfigProvider tag.style überschrieben wurde. #59087 @QDyanbing
  • ♿ Optimieren Sie die Barrierefreiheit von Steps und blenden Sie die dekorativen Pfeile im Panel für unterstützende Technologien aus. #59105 @nrps9909
  • ♿ Optimieren Sie die Zugänglichkeit von Skeleton.Image und verbergen Sie dekorative Platzhaltergrafiken vor unterstützenden Technologien. #59107 @nrps9909
  • 🐞 Das Problem wurde behoben, bei dem der Inhaltsstatus zurückgesetzt wurde, nachdem die Einträge von key: 0 in den Beschreibungen neu angeordnet wurden. #59064 @QDyanbing
  • 🐞 Das Problem wurde behoben, bei dem der standardmäßige leere Status immer noch angezeigt wird, wenn notFoundContent von Cascader und Cascader.Panel null ist. #59028 @QDyanbing
  • 🐞 Das Problem wurde behoben, bei dem Watermark einen Fehler auslöste, wenn content undefined ist. #59077 @VamoBao
  • 📖 Es wurde ein Problem behoben, bei dem Komponenten-LLMs-Links bei der Website-Spiegelung und der lokalen Bereitstellung nicht korrekt geladen werden konnten. #59062 @QDyanbing
