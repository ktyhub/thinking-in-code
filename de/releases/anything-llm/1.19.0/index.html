Integriertes LLM für Docker

<img width="3680" height="2212" alt="AnythingLLM Docker integriertes LLM powered by Lemonade und llama.cpp" src="https://github.com/user-attachments/assets/410b5784-ca15-4027-a1c4-056d9d5c748e" />

AnythingLLM Docker verfügt jetzt sofort über ein standardmäßiges lokales LLM-Erlebnis. Die gleiche Art von integrierter Engine, die mit AnythingLLM Desktop geliefert wird, kann jetzt im Container ausgeführt werden: Lemonade, der vollständig Open-Source lokale Inferenzserver von AMD, der Ihre Modelle mit llama.cpp ausführt. Sie müssen Ollama, LM Studio oder einen anderen Inferenzserver nicht mehr neben AnythingLLM ausführen.

Übergeben Sie Ihre GPU in den Container und die Engine wird auf der von Ihnen verwendeten Hardware beschleunigt. Es wählt automatisch das schnellste Backend aus: CUDA für NVIDIA-GPUs, Vulkan für AMD- und Intel-GPUs oder die CPU. Es läuft sowohl auf amd64- als auch auf arm64-Hosts.

Wenn es aktiviert ist, wird Built-in beim Onboarding zum Standard-LLM-Anbieter, wobei drei Modelle für Ihre Hardware empfohlen werden. Sie können jedes Modell aus der Modelltabelle herunterladen oder jedes GGUF-Modell von Hugging Face abrufen. Es funktioniert überall dort, wo ein Anbieter verwendet werden kann: das System-LLM, Workspace- und Agent-LLMs, die Chat-Fenster-Modellauswahl und [Modell-Router] (https://docs.anythingllm.com/model-router/setup).

[!TIP] Das integrierte LLM ist standardmäßig deaktiviert. Aktivieren Sie es, indem Sie den Container mit -e ENABLE_BUILT_IN_LLM=true starten, und fügen Sie --gpus all hinzu (oder übergeben Sie Ihre AMD- oder Intel-GPU-Geräte), um die GPU zu beschleunigen. Die vollständige Einrichtung für jede Art von Hardware finden Sie unter Integriertes LLM für Docker.

Farbpaletten

Farbpaletten sind einfache thematische Farbtöne, die Sie auf die gesamte Benutzeroberfläche anwenden können. Wir planen, diese Funktionalität weiter zu erweitern, damit Sie die Benutzeroberfläche und sogar das Layout stärker anpassen können. Weitere Informationen
