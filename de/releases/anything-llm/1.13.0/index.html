#irgendetwas-llm v1.13.0

Der Schwerpunkt dieser Version liegt auf der Verbesserung des Agentenerlebnisses und dem Hinzufügen neuer Funktionen zum Agentensystem sowie auf dem Übergang zu einem passiveren, persönlicheren und hybrideren KI-Erlebnis.

Model Router: Das erste Hybrid-KI-Erlebnis für Verbraucher

Die Model-Router-Funktion ist das erste benutzerdefinierte intelligente Routing-System, das lokale und Cloud-KI nahtlos zu einem einzigen, einheitlichen Erlebnis verbindet, das vollständig unter Ihrer Kontrolle steht. Bisher musste man sich entscheiden: alles lokal ausführen oder alles in die Cloud schicken. Dieser Kompromiss ist vorbei.

Mit Model Router definieren Sie die Regeln. Jede von Ihnen gesendete Nachricht wird automatisch analysiert und an das perfekte Modell für die jeweilige Aufgabe weitergeleitet, sei es ein leichtes lokales Modell für schnelle Fragen, ein Argumentationsmodell für komplexe Mathematik oder Ihr leistungsstärkstes Cloud-Modell für differenzierte Rechtsanalysen. Alles aus demselben Chat. Alles unsichtbar für den Benutzer. Alles von Ihnen definiert.

Was das so spannend macht:

  • Hybride KI. Kombinieren Sie lokale Modelle (Ollama, LM Studio usw.) mit Cloud-Anbietern (OpenAI, Anthropic, Google) in einem einzigen Gespräch. Kein manuelles Umschalten!
  • Sie haben die vollständige Kontrolle. Erstellen Sie berechnete Regeln, die sofort auf Schlüsselwörter, Token-Anzahl, Tageszeit oder Bildanhänge angewendet werden. Oder verwenden Sie LLM-klassifizierte Regeln, die die Absicht im Klartext verstehen.
  • Sparen Sie Geld, ohne auf Qualität zu verzichten. Leiten Sie einfache Anfragen an günstige oder lokale Modelle weiter. Reservieren Sie teure API-Anrufe für die Nachrichten, die sie tatsächlich benötigen.
  • Intelligentes Caching. Unser fortschrittliches Sticky-Routing-System sorgt dafür, dass Sie während eines Konversationsthreads beim gleichen Modell bleiben, sodass Sie nicht bei jeder Nachricht zwischen den Modellen wechseln müssen.

Wir glauben, dass dies eine grundlegende Veränderung in der Funktionsweise von KI-Assistenten ist. Zum ersten Mal erhalten Sie die Privatsphäre lokaler Modelle, die Leistungsfähigkeit von Cloud-Modellen und die Intelligenz, um zu wissen, wann Sie jedes einzelne verwenden müssen. Und es ist 100 % Open Source.

Geplante Jobs: Ihre KI, die funktioniert, während Sie es nicht tun

Was wäre, wenn Ihr KI-Assistent im Hintergrund automatisch nach einem von Ihnen festgelegten Zeitplan für Sie arbeiten könnte, ohne dass Sie einen Finger rühren müssten?

Geplante Jobs verwandeln AnythingLLM in eine ständig verfügbare KI-Belegschaft. Erstellen Sie wiederkehrende Aufgaben, die von selbst ablaufen: morgendliche Briefings, wöchentliche Berichte, Datenüberwachung, Recherchezusammenfassungen. Alles, worum Sie normalerweise einen Agenten bitten würden, aber automatisiert und freihändig. Verfügt über berufsspezifische Fähigkeiten, die Sie festlegen können, damit das Modell nicht mit Werkzeugen überlastet wird und die Ergebnisse wiederholbar sind.

Warum sich dadurch alles ändert:

  • Stellen Sie es ein und vergessen Sie es. Definieren Sie eine Aufforderung, wählen Sie Ihre Werkzeuge aus, wählen Sie einen Zeitplan und gehen Sie weg. Ihr Agent ist genau dann im Einsatz, wenn Sie ihn brauchen: jeden Morgen um 8 Uhr, jeden Montag mittags, zu jeder vollen Stunde.
  • Keine technischen Kenntnisse erforderlich. Mit unserem visuellen Cron Builder können Sie Jobs mit einfachen Dropdowns planen. Keine kryptische Cron-Syntax, keine Befehlszeile, kein Code. Einfach zeigen und click.
  • Volle Agentenleistung, vollständig automatisiert. Geplante Jobs haben Zugriff auf dieselben Tools wie Ihre regulären Chats: Websuche, Dokumentenanalyse, benutzerdefinierte Fähigkeiten, MCP-Integrationen und mehr. Wenn ein Agent dies in einem Gespräch tun kann, kann er es nach einem Zeitplan tun.
  • Vollständiger Ausführungsverlauf. Jede Ausführung wird mit der vollständigen Begründung des Agenten, den Tool-Aufrufen, den generierten Dateien und der endgültigen Antwort protokolliert. Überprüfen Sie jederzeit frühere Ausführungen oder machen Sie in einem neuen Thread dort weiter, wo der Agent aufgehört hat.
  • Push-Benachrichtigungen. Erhalten Sie eine Benachrichtigung, sobald ein Auftrag abgeschlossen ist, auch wenn AnythingLLM im Hintergrund läuft. Click, um direkt zu den Ergebnissen zu springen.

Unternehmenstools verlangen für diese Art der Automatisierung Tausende. Bei reinen Cloud-Plattformen müssen Sie Ihre Daten an Dritte weitergeben. AnythingLLM bietet Ihnen geplante KI-Agenten, die vollständig auf Ihrem Computer ausgeführt werden und Ihre Daten unter Ihrer Kontrolle haben.

Wachen Sie mit einer Zusammenfassung der E-Mails über Nacht auf. Erhalten Sie automatisch wöchentliche Fortschrittsberichte. Überwachen Sie Websites auf Änderungen. Die Möglichkeiten sind endlos und alles geschieht, während Sie sich auf das Wesentliche konzentrieren.

Automatische Erinnerungen und Personalisierung

AnythingLLM unterstützt jetzt die automatische Speicherextraktion und -personalisierung, sodass sich Ihr KI-Assistent an das erinnern kann, worüber Sie gesprochen haben, und dieses Wissen nutzen kann, um seine Antworten zu personalisieren.

AnythingLLM führt einen Hintergrundjob aus, um Erinnerungen aus Ihren Chats zu extrahieren und sie in einer Speicherbank zu speichern. Diese Speicherbank wird dann verwendet, um die Antworten Ihres KI-Assistenten zu personalisieren – Sie haben die volle Kontrolle darüber, was gespeichert wird und wie es verwendet wird Sie können Erinnerungen sogar manuell zur Speicherbank hinzufügen, wenn Sie nicht möchten, dass das Modell Zyklen damit verbringt, den Chat-Verlauf zu überprüfen.

Es gibt zwei Arten von Erinnerungen:

  • Arbeitsbereichsspeicher: Dies sind Erinnerungen, die spezifisch für den aktuellen Arbeitsbereich sind (z. B. was Sie gerade bearbeiten, projektspezifische Informationen usw.)
  • Globale Erinnerungen: Dies sind Erinnerungen, die spezifisch für die gesamte AnythingLLM-Instanz sind (wie Ihr Name, Ihre Vorlieben usw.)

Erinnerungen werden in die Systemeingabeaufforderung Ihres KI-Assistenten eingefügt, damit dieser diese zur Personalisierung seiner Antworten nutzen kann und eine willkommene Ergänzung der Wissensdatenbank Ihres KI-Assistenten darstellt.

Agentenbefragungen (spezielles Tool)

Agent Surveys ist ein spezielles Tool, das es Ihrem KI-Assistenten ermöglicht, klärende Fragen zu stellen, bevor er fortfährt. Dies ist nützlich, wenn Sie mit einer komplexen Aufgabe arbeiten und der Agent weitere Informationen benötigt, um fortzufahren.

Dies ist standardmäßig deaktiviert und muss in den Agenteneinstellungen aktiviert werden. Antworten auf die Fragen werden zusammen mit der Chat-Nachricht gespeichert, sodass der Agent sie in zukünftigen Runden verwenden kann.
