anything-llm v1.12.1

Patch Veröffentlicht22. Apr. 2026 QuelleMintplex-Labs/anything-llm Englisches Original

Diese Seite ist maschinell übersetzt. Maßgeblich ist der englische Originaltext.

#irgendetwas-llm v1.12.1

Bemerkenswerte Verbesserungen

Einbettung gestreamter Dokumente

Wenn Sie nun ein Dokument in den Arbeitsbereich hochladen, wird der Prozess pro Dokument jetzt während der Einbettung gemeldet. Dies ist eine enorme Verbesserung der Leistung und des Benutzererlebnisses. Während dieses Vorgangs können Sie Dokumente zur Warteschlange hinzufügen und daraus entfernen sowie die Seite sogar schließen und von ihr weg navigieren, ohne Ihren Fortschritt zu verlieren.

<img width="1745" height="1011" alt="queue-embedding" src="https://github.com/user-attachments/assets/ffbd06ad-cd2c-480a-89ba-bb7a0068abbc" />

App-Integrationen

Es gibt jetzt integrierte Integrationen für die folgenden Apps, für die nur minimale bis gar keine Einrichtung für Agentenkenntnisse erforderlich ist:

  • Gmail
  • Outlook
  • Google Kalender

Weitere Verbesserungen

  • [x] Bild-Lightbox in der Hauptbenutzeroberfläche
  • [x] Unterstützung für koreanische, chinesische und japanische Zeichen für die PDF-Generierung über den benutzerdefinierten mdpdf-Fork aktiviert
  • [x] Bessere Zitate für App-Integrationen
  • [x] DDG-Standard-Websuche in Agentenfähigkeiten
  • [x] Öffnen Sie Dokumente in der nativen Anwendung auf dem Computer, wenn sie vom Document Generation Agent generiert werden
  • [x] Agent-Skill automatisch über ENV-Einstellung genehmigen
  • [x] Ollama ist auf 0.20.7 gestiegen (Qwen3.5-Unterstützung, Gemma 4 usw.)
  • [x] Neue Anpassung > Chat-Einstellung für Unload model when closed, um das Modell zu entladen, wenn der Benutzer das Chat-Fenster schließt.
  • [x] Generische OpenAI-Fähigkeitserkennung/ENV-Einstellung
  • [x] Lemonade aktualisieren, um 1.10.0-Änderungen zu unterstützen
  • [x] Katalanische Übersetzungen
  • [x] Namensfeld zu API-Schlüsseln hinzugefügt
  • [x] Chat-ID wird in Agentensitzungen gemeldet, sodass Sie jetzt Chats, TTS und weitere Aktionen ohne Neuladen der Seite neu generieren können.
