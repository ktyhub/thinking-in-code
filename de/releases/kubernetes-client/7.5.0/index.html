kubernetes-client v7.5.0

Fehler

– Fix #7160: Verwenden Sie die Dauer aus dem aktuellen Leader-Datensatz, nicht aus der Konfiguration

  • Fix #7343: Rückrufe bei der Wahl des Anführers werden nur einmal aufgerufen (statt 2) – Fix #7347: Stellen Sie sicher, dass vert.x-Websockets mehrere Frames verarbeiten – Fix #7356: Stellen Sie sicher, dass die Anforderungskonfiguration bei der Anpassung an OpenShiftClient erhalten bleibt
  • Fix #7369: Tippfehler in Warnmeldungen im Protokoll behoben – Fix #7373: (crd-generator) SchemaCustomizer mit @Repeatable-Unterstützung und besseren Ausnahmemeldungen verbessern – Fix #7380: Go openAPI-Generatorfehler treten auf, wenn eingebettete Strukturen widersprüchliche JSON-Feldnamen haben – Fix #7388: Typfilter für widersprüchliche Typen behoben – OpenAPI-Generator – Fix #7372: Die Service-Port-Weiterleitung ignoriert die Service-Port-Zuordnung

Verbesserungen

– Fix #7277: Stücklistenveröffentlichung in Maven Central behoben – Fix #7345: Veröffentlichung von Test- und Beispielmodulen in Maven Central überspringen

Abhängigkeits-Upgrade

  • Fix #7266: Jackson-Bom von 2.19.2 auf 2.20.0 verschieben, Überschreibungen korrigieren und Jackson-Anmerkungen v2.20 verarbeiten
  • Fix #7293: vertx.version von 4.5.14 auf 4.5.21 erhöhen – Fix #7358: (openapi) Gateway API von 1.2.1 auf 1.4.0 aktualisieren – Fix #7361: (openapi) Istio von 1.27 auf 1.28 aktualisieren

Neue Funktionen

– Fix #5081: Unterstützung für Streaming-Listen über die Watchable.streamingList-Methode hinzugefügt

  • Fix #7048: Unterstützung für Kubernetes v1.34 (Of Wind & Will) – Fix #7371: Fabric8 OpenShift-Modell gemäß OpenShift 4.20 aktualisieren – Fix #7355: (crd-generator) SchemaCustomizer-Annotation für erweiterte Schema-Änderung hinzufügen

Hinweis: Wichtige Änderungen

  • Fix #7048: admissionregistration.v1beta1: ValidatingAdmissionPolicy und verwandte Klassen (ValidatingAdmissionPolicyBinding, AuditAnnotation, Validation, ValidatingAdmissionPolicyBindingSpec) wurden aus v1beta1 entfernt, da sie in admissionregistration.v1 zu GA aufgestiegen sind. MutatingAdmissionPolicy wurde von v1alpha1 auf v1beta1 hochgestuft. Die V1beta1AdmissionRegistrationAPIGroupDSL und V1beta1AdmissionRegistrationAPIGroupClient wurden entsprechend aktualisiert. Benutzer sollten für GA APIs auf admissionregistration.v1.ValidatingAdmissionPolicy migrieren.
  • Fix #7266: Jackson-Bom von 2.19.2 auf 2.20.0 erhöhen, Überschreibungen korrigieren und Jackson-Anmerkungen v2.20 verarbeiten – Fix #7388: openshift-model-installer: Das Modul openshift-model-installer ist jetzt veraltet und wird in einer zukünftigen Version entfernt. Bitte verzichten Sie auf die Verwendung dieses Moduls und seiner Modelle.

  • @ash-thakur-rh hat seinen ersten Beitrag in https://github.com/fabric8io/kubernetes-client/pull/7326 geleistet
