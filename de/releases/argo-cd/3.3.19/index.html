argo-cd v3.3.19

[!IMPORTANT] HINWEIS ZUM ENDE DER LEBENSDAUER

Dies ist die letzte Veröffentlichung der v3.3-Veröffentlichungsserie. Ab dem 3. November 2026 hat diese Version das Ende ihrer Lebensdauer erreicht und erhält keine Fehlerbehebungen oder Sicherheitsupdates mehr.

Aktion erforderlich: Bitte aktualisieren Sie auf eine unterstützte Version (v3.4.13, v3.5.7 oder v3.6.0).

Schnellstart

Nicht-HA:

kubectl create namespace argocd
kubectl apply -n argocd --server-side --force-conflicts -f https://raw.githubusercontent.com/argoproj/argo-cd/v3.3.19/manifests/install.yaml

HA:

kubectl create namespace argocd
kubectl apply -n argocd --server-side --force-conflicts -f https://raw.githubusercontent.com/argoproj/argo-cd/v3.3.19/manifests/ha/install.yaml

Signaturen und Provenienz der Veröffentlichung

Alle Argo-CD-Container-Images sind von cosign signiert. Für Container-Images und CLI-Binärdateien, die den SLSA Level 3-Spezifikationen entsprechen, wird eine Provenienz generiert. Informationen zur Überprüfung finden Sie in der Dokumentation.

Release Notes Blog-Beitrag

Eine detaillierte Aufschlüsselung der wichtigsten Änderungen und Verbesserungen in dieser Version finden Sie im offiziellen Blogbeitrag.

Upgrade

Wenn Sie ein Upgrade von einer anderen Nebenversion durchführen, lesen Sie unbedingt die Dokumentation zum Upgrade.
