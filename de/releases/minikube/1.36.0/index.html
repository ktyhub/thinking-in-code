Release Notes

Version 1.36.0 – 22.05.2025

Funktionen

  • Unterstützt Kubernetes-Version v1.33.1 #20784
  • Neues Flag „-f“, um die Übergabe einer Konfigurationsdatei für den Add-on-Konfigurationsbefehl zu ermöglichen. #20255
  • vfkit: Änderung des bevorzugten Treibers auf macOS #20808
  • vfkit: neue Netzwerkoption „--network vment-shared“ für vfkit-Treiber #20501

Fehlerbehebungen:

  • Bootpd-Prüfung unter macOS >= 15 behoben #20400
  • Fehler beim Parsen von Proxys mit Bindestrichen behoben #20648
  • Behebung des Wartens darauf, dass alle Pods mit angegebenen Labels bereit sind #20315
  • Fix: Falsches finalImg wirkt sich auf das Herunterladen von KIC-Formularen aus github-Assets aus #20316
  • Fix: Verweis auf fehlende Dateien im Schema (schließt #20752) #20761 Verbesserungen:
  • Zusätzliche Prüfungen für 9p-Unterstützung #20288
  • vfkit: Ordentliches Herunterfahren bei Stopp #20504
  • vfkit: Robusteres Zustandsmanagement #20506
  • vfkit vmnet: Unterstützung für die Ausführung ohne Sudoers-Konfiguration #20719
  • „Fix --wait funktioniert nicht auf Coredns-Pods“ zurückgesetzt #20313
