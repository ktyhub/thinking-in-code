📣😀 Bitte füllen Sie unsere schnelle 5-Fragen-Umfrage aus, damit wir erfahren, wie und warum Sie Minikube verwenden und welche Verbesserungen wir vornehmen sollten. Danke schön! 💃🎉

Release Notes

Version 1.38.1 – 19.02.2026

Funktion

  • Unterstützung für Kubernetes-Version v1.35.1 hinzugefügt (#22665)

Fehlerbehebungen

  • Regression der Sperrdatei durch Anhängen der UID an das Sperrverzeichnis behoben (#22623)
  • Regressionsübergreifende Ausführung durch Maskierung von systemd-binfmt behoben (#22621)
  • Fix: PowerShell-Curl-Alias unter Windows, um die Konnektivität von resgistry.k8s.io zu überprüfen (#22659)

Add-ons

  • Add-on cloud-spanner: Cloud-spanner-emulator/emulator-image von 1.5.47 auf 1.5.49 aktualisieren (#22637)
  • Zusatzscheinwerfer: Scheinwerferbild von v0.39.0 auf v0.40.0 aktualisieren (#22640)
  • Add-on-Ingress: Ingress-Nginx/Controller-Image von v1.14.1 auf v1.14.2 aktualisieren (#22595)
  • Add-on-Ingress: Ingress-Nginx/Controller-Image von v1.14.2 auf v1.14.3 aktualisieren (#22638)
  • Addon inspektor-gadget: Inspektor-gadget-Bild von v0.48.0 auf v0.48.1 aktualisieren (#22592)
  • Addon inspektor-gadget: Inspektor-gadget-Image von v0.48.1 auf v0.49.1 aktualisieren (#22634)
  • Add-on metrics-server: Update metrics-server/metrics-server image von v0.8.0 auf v0.8.1 (#22596)
  • Addon nvidia-device-plugin: nvidia/k8s-device-plugin-Image von v0.18.1 auf v0.18.2 aktualisieren (#22531)
  • Add-on-Registrierung: Registrierungsimage von 3.0.0 auf 3.0.0 aktualisieren (#22593)
  • Addon Volcano: Vulkanbilder von v1.13.1 auf v1.14.0 aktualisieren (#22597)
  • Addon Volcano: Vulkanbilder von v1.14.0 auf v1.14.1 aktualisieren (#22663)
  • Addon yakd: Manusa/yakd-Image von 0.0.7 auf 0.0.8 aktualisieren (#22639)
  • HA (Multi-Control-Ebene): kube-vip von v1.0.3 auf v1.0.4 aktualisieren (#22598)

CNI

  • CNI: Cilium von v1.18.6 auf v1.19.0 aktualisieren (#22636)
  • CNI: Flanell von v0.27.4 auf v0.28.1 aktualisieren (#22635)
  • CNI: Kindnetd von v20251212-v0.29.0-alpha-105-g20ccfc88 auf v20260131-0806d083 aktualisieren (#22594)
  • CNI: Kindnetd von v20260131-0806d083 auf v20260213-ea8e5717 aktualisieren (#22661) Eine detailliertere changelog, einschließlich Änderungen in Vorabversionen, finden Sie unter CHANGELOG.md.
