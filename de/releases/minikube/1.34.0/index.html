📣😀 Bitte füllen Sie unsere schnelle 5-Fragen-Umfrage aus, damit wir erfahren, wie und warum Sie Minikube verwenden und welche Verbesserungen wir vornehmen sollten. Danke schön! 💃🎉

Release Notes

Version 1.34.0 – 04.09.2024

Wichtige Änderungen:

  • Erhöhen Sie die minimale Podman-Version auf 4.9.0 #19457
  • Verwendung von Docker Desktop 4.34.0 #19576 nicht zulassen

Eigenschaften:

  • Standardversion Kubernetes auf v1.31.0 erhöhen #19435
  • Neuen Treiber für macOS hinzufügen: vfkit #19423
  • Parallels-Treiberunterstützung für Darwin/Arm64 hinzugefügt #19373
  • Neues Vulkan-Addon hinzufügen #18602
  • Addons ingress-dns: Unterstützung für alle Architekturen hinzugefügt #19198
  • Unterstützt privilegierte Ports auf WSL #19370
  • VM-Treiber mit docker-Container-Laufzeit verwenden jetzt docker-buildx für die Image-Erstellung #19339
  • Unterstützt die Ausführung von x86 QEMU auf arm64 #19228
  • Option -o json für Befehl addon images hinzugefügt #19364

Verbesserungen:

  • Kurzform -d für --driver hinzufügen #19356
  • Abkürzung -c für --container-runtime hinzufügen #19217
  • kvm2: Das „Standard“-Libvirt-Netzwerk nicht löschen #18920
  • MINIKUBE_HOME-Nutzung aktualisieren #18648
  • CNI: Aktualisierte Berechtigungen zur Unterstützung von Netzwerkrichtlinien auf Kindnet #19360
  • GPU: Setzen Sie NVIDIA_DRIVER_CAPABILITIES auf all, wenn die GPU aktiviert ist #19345
  • Verbesserte Fehlermeldung beim Versuch, mount auf einem System zu verwenden, bei dem 9P fehlt #18995
  • Verbesserte Fehlermeldung beim Aktivieren von KVM-Add-ons auf Nicht-KVM-Clustern #19195
  • Warnung hinzugefügt, wenn das Bild mit dem falschen Bogen geladen wird #19229
  • profile list --output json behandelt leeren Konfigurationsordner #16900
  • Überprüfen Sie die Konnektivität außerhalb von Minikube, wenn Konnektivitätsprobleme auftreten #18859

Fehler:

  • Behebung, dass kein API-Servertunnel für QEMU mit integriertem Netzwerk erstellt wurde #19191
  • Behebung des Wartens auf Benutzereingaben beim Entsperren der Firewall, wenn --interactive=false #19531
  • Netzwerk-Wiederholungsprüfung behoben, wenn das Subnetz bereits für Podman verwendet wird #17779
  • Leerer Tarball beim Generieren der Bildspeicherung behoben #19312
  • Fehlende Berechtigung für kong-serviceaccount behoben #19002

Versions-Upgrades:

  • Add-on cloud-spanner: Cloud-spanner-emulator/emulator-image von 1.5.17 auf 1.5.23 aktualisieren #19341 #19501
  • Zusatzscheinwerfer: Scheinwerfer-k8s/Scheinwerferbild von v0.23.2 auf v0.25.0 aktualisieren #18992 #19152 #19349
  • Kong-Add-on: Kong-Image von 3.6.1 auf 3.7.1 aktualisieren #19046 #19124
  • Addon kubevirt: Bitnami/kubectl-Image von 1.30.0 auf 1.31.0 aktualisieren #18929 #19087 #19313 #19479
  • Add-on-Ingress: Ingress-Nginx/Controller-Image von v1.10.1 auf v1.11.2 aktualisieren #19302 #19461
  • Addon inspektor-gadget: Inspektor-gadget-Bild von v0.27.0 auf v0.32.0 aktualisieren #18872 #18931 #19011 #19166 #19411 #19554
  • Addon istio-provisioner: Istio/Operator-Image von 1.21.2 auf 1.23.0 aktualisieren #18932 #19052 #19167 #19283 #19450
  • Addon nvidia-device-plugin: nvidia/k8s-device-plugin-Image von v0.15.0 auf v0.16.2 aktualisieren #19162 #19266 #19336 #19409
  • Add-on metrics-server: Aktualisieren Sie das metrics-server/metrics-server-Image von v0.7.1 auf v0.7.2 #19529
  • Addon YAKD: Marcnuri/Yakd-Bild von 0.0.4 auf 0.0.5 verschieben #19145
  • CNI: Kattun von v3.27.3 auf v3.28.1 aktualisieren #18870 #19377
  • CNI: Cilium von v1.15.3 auf v1.16.1 aktualisieren #18925 #19084 #19247 #19337 #19476
  • CNI: Kindnetd von v20240202-8f1494ea auf v20240813-c6f155d6 aktualisieren #18933 #19252 #19265 #19307 #19378 #19446
  • CNI: Flanell von v0.25.1 auf v0.25.6 aktualisieren #18966 #19008 #19085 #19297 #19522
  • Kicbase: nerdctld von 0.6.0 auf 0.6.1 aktualisieren #19282
  • Kicbase: Erhöhen Sie ubuntu:jammy von 20240427 auf 20240808 #19068 #19184 #19478
  • Kicbase/ISO: Buildkit von v0.13.1 auf v0.15.2 aktualisieren #19024 #19116 #19264 #19355 #19452
  • Kicbase/ISO: CNI-Plugins von v1.4.1 auf v1.5.1 aktualisieren #19044 #19128
