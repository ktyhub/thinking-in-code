minikube v1.33.0

📣😀 Bitte füllen Sie unsere schnelle 5-Fragen-Umfrage aus, damit wir erfahren, wie und warum Sie Minikube verwenden und welche Verbesserungen wir vornehmen sollten. Danke schön! 💃🎉

Release Notes

Version 1.33.0 – 19.04.2024

Eigenschaften:

  • Unterstützung mehrerer Steuerungsebenen – HA-Cluster --ha #17909 Tutorial
  • Unterstützung für Kubernetes v1.30 #18669 hinzugefügt
  • Unterstützt die Bereitstellung von ClusterIP-Diensten über minikube service #17877
  • Add-on gvisor: arm64-Unterstützung hinzufügen #18063 #18453
  • Neues Addon: YAKD – Kubernetes Dashboard-Addon #17775

Kleinere Verbesserungen:

  • Aktiven Kubecontext zur minikube profile list-Ausgabe hinzufügen #17735
  • CNI calico: unterstützt kubeadm.pod-network-cidr #18233
  • CNI-Brücke: Stellen Sie sicher, dass Pod-Kommunikation zulässig ist #16143
  • Automatische Pause des Add-ons: Speicherverlust entfernen und konfigurierbares Intervall hinzufügen #17936
  • Bilderstellung: docker.io/library zu Bildkurznamen hinzufügen #16214
  • cp: Verzeichnis erstellen, falls nicht vorhanden #17715
  • Fehler beim Abrufen von Protokollen in die Protokollausgabe selbst verschieben #18007
  • Standard-Sysctls hinzufügen, um privilegierte Ports ohne Funktionen zuzulassen #18421
  • Erweiterte Attribute in Preload-Tarballs einbeziehen #17829
  • kubeadm.applyNodeLabels-Label auf alle Knoten anwenden #16416
  • Treiberstatusprüfung auf 20 Sekunden beschränken #17553
  • Journalctl-Protokolle einbeziehen, wenn der Systemd-Dienst nicht gestartet werden kann #17659
  • Fix „Container-Laufzeit konnte nicht aktiviert werden: sudo systemctl restart cri-docker“ #17907
  • Problem behoben, bei dem Containerd vorhandene Bilder beim Start erneut herunterlädt #17671
  • Behebung, dass kvm2 das Vorladen von Containerd nicht erkennt #17658
  • Korrektur der Änderung der binfmt-Konfiguration Docker #17830
  • Auto-Pause-Add-on behoben #17866
  • Behebung, dass Preload nicht mit dem OverlayFS-Speichertreiber verwendet wurde #18333
  • Problem behoben, bei dem Bild-Repositorys Subdomains mit Zahlen nicht zulassen #17496
  • Behebung des Clusterstopps bei Verwendung von kvm2 mit Containerd #17967
  • Behebung des Starts von mehr als einem Cluster auf kvm2 arm64 #18241
  • Problem beim Starten von kvm2-Clustern mit Linux auf arm64-Mac behoben #18239
  • Anzeigefehler beim Löschen nicht vorhandener Cluster behoben #17713
  • Behebung, dass No-Limit beim Neustart nicht berücksichtigt wurde #17598
  • Behebung, dass die Bezeichnung kubeadm.applyNodeLabels nicht auf Knoten angewendet wurde, die nach dem ersten Start hinzugefügt wurden #16416
  • Protokolltrennzeichenausgabe korrigiert #17734

Fehler:

  • Nicht maskierter lokaler Host-Regex behoben #18617
  • Regex auf „validateNetwork“ korrigiert, um Sonderzeichen zu unterstützen #18158

Versions-Upgrades:

  • Standardversion der Bump-Kubernetes-Version: v1.30.0 und neueste Version: v1.30.0 #18669
  • Zusatzscheinwerfer: Scheinwerfer-k8s/Scheinwerferbild von v0.23.0 auf 0.23.1 aktualisieren #18517
  • Addon inspektor-gadget: Inspektor-gadget-Bild von v0.26.0 auf v0.27.0 aktualisieren #18588
  • Add-on istio-provisioner: Istio/Operator-Image von 1.21.0 auf 1.21.1 aktualisieren #18644
  • Add-on metrics-server: Aktualisieren Sie das metrics-server/metrics-server-Image von v0.7.0 auf v0.7.1 #18551
  • CNI: Kattun von v3.27.0 auf v3.27.3 aktualisieren #18206
  • CNI: Flanell von v0.24.4 auf v0.25.1 aktualisieren #18641
  • Kicbase/ISO: Buildkit von v0.13.0 auf v0.13.1 aktualisieren #18566
  • Kicbase/ISO: Containerd von v1.7.14 auf v1.7.15 aktualisieren #18621
  • Kicbase/ISO: cri-dockerd von v0.3.3 auf v0.3.12 aktualisieren #18585
  • Kicbase/ISO: Crun von 1.14 auf 1.14.4 aktualisieren #18610
  • Kicbase/ISO: Update docker von 25.0.4 auf 26.0.1 #18485 #18649
  • Kicbase/ISO: Nerdctl von 1.7.4 auf 1.7.5 aktualisieren #18634
  • Kicbase: nerdctld von 0.5.1 auf 0.6.0 aktualisieren #18647

Eine detailliertere changelog, einschließlich Änderungen in Vorabversionen, finden Sie unter CHANGELOG.md.
