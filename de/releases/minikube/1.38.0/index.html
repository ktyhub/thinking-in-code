minikube v1.38.0

📣😀 Bitte füllen Sie unsere schnelle 5-Fragen-Umfrage aus, damit wir erfahren, wie und warum Sie Minikube verwenden und welche Verbesserungen wir vornehmen sollten. Danke schön! 💃🎉

Release Notes

Version 1.38.0 – 28.01.2026

Höhepunkte

  • Kein Sudo erforderlich für vfkit/krunkit unter macOS 26+ (erfordert den neuesten vmnet-helper)
  • Kein Sudo erforderlich, um [AI Playground auf MacOS-GPUs mit Minikube] auszuführen (https://minikube.sigs.k8s.io/docs/tutorials/ai-playground/)
  • vfkit: Rosetta-Unterstützung für die Bereitstellung von amd64-Images auf Apple-Chips hinzugefügt (#22140)

Funktionen

  • Unterstützung für Kubernetes v1.35.0 (#21650)(#22015)(#22119)(#22328) hinzufügen
  • VM-Treiber: Unterstützung für NVMe-oF/TCP-Blockgeräte hinzufügen (#22464)
  • VM-Treiber: BTF-Debugsymbole aktivieren, um eBPF-Tools in ISO zu unterstützen (#21800)
  • Option zum Herunterladen von Preloads von github anstelle von GCS über --preload-source hinzugefügt (#22221)
  • Vfkit/Krunkit-Treiber: Möglichkeit hinzugefügt, vmnet-helper als unprivilegierter Benutzer unter macOS 26+ auszuführen (#22501)
  • Option zum Hinzufügen von Helm-basierten Add-ons hinzugefügt (#21847)
  • Vorab laden: Download von github, wenn GCS nicht verfügbar ist (#21605)

Warnungen und Abwertungen

  • Benutzeroberfläche: Warnung beim Ändern der Standardlaufzeit in „containerd“ in der nächsten Version hinzugefügt (v1.39.0) (#22508)
  • Hyperkit: Treiber-Builds entfernen und Benutzer zum Wechseln warnen (#21946)
  • Minikube-Unterstützung für 32-Bit-Architekturen entfernen (#22401)

Verbesserungen

  • Benutzeroberfläche: bunt basierend auf dem Status (Profilliste, Add-On-Liste) (#22418)
  • Caching-Binärdateien überspringen, wenn --no-kubernetes gesetzt ist (#21139)
  • Wiederholungsprotokolle verbessern, um weniger doppelte Zeilen zu drucken (#22232)
  • SSH-Runner beim Kopieren von Zertifikatsdateien verbessern (#21923)
  • vmnet: Validierung im Nur-Download-Modus überspringen (#21635)
  • Windows-Zertifikat in kubeconfig verbessern: generierte Zertifikatspfade normalisieren, um Schrägstriche weiterzuleiten (#21845)
  • cgroup v2 Freezer-Check für API-Serverstatus hinzugefügt (#22249)
  • Legen Sie die Kubelet-Option FailCgroupV1 für Kubenetes 1.35+ fest, wenn cgroup v1 (#22319)
  • containerd: Wiederholen Sie den Versuch bei vorübergehenden EOF-Fehlern beim Laden des Bildes (#22310)
  • cri: Standard-Timeout für Crictl-Befehle auf 2 Sekunden erhöhen (#22214)
  • crio: Überprüfen Sie, ob Bilder nach „image rm“ gelöscht werden (#22243)
  • docker-Laufzeit: CRI für ListImages-Funktion verwenden (#22263)
  • Bildspeicherung: Wiederholungslogik für lokales Bild im Falle von EOF hinzugefügt (#22072)
  • HA (Multi-Control-Ebene): kube-vip von v1.0.0 auf v1.0.3 aktualisieren (#21699)(#21960)(#22258)

Treiber

  • Treiber: WaitForSSHAccess einführen und macOS-Rauchtests beheben (#22179)
  • Hyperkit-Treiber: Dateideskriptorlecks im Status behoben (#22524)
  • kvm: Minikube auf Fedora/RHEL mit SELinux reparieren (#21550)
  • kvm: Abhängigkeit von externem Treiber entfernen (#21625)
  • Markieren Sie den alten Parallels-Treiber als veraltet (#22379).
  • kein Treiber: „Stopp“ mit Containerd-Laufzeit behoben (#22275)
  • Minikube-Machine-Treiber aktualisieren (#22369)
  • Überprüfen Sie, ob die Aux-Treiber korrekt installiert sind, und beenden Sie den Vorgang, wenn nicht (#21576).
  • vfkit: Rosetta-Unterstützung für die Bereitstellung von amd64-Images auf Apple-Chips hinzugefügt (#22140)
  • VM: Aktivieren Sie cgroup v2 mithilfe von „systemd cgroup drivers“ für Kubernetes… (#22320)

Fehlerbehebungen

  • KIC-Treiber: docker-Treiber mit Crio-Laufzeit reparieren: dbus installieren (#21724)
  • Fix: Verschachtelte VMs unter macOS korrekt erkennen und Timeout-Multiplikator entfernen (#22277)
  • Fix: Timeout für Containerd-Image-Liste erhöhen (#22558)
  • Fix: Kubevirt-Add-on durch Entfernen der Curl-Abhängigkeit (#22557)
  • Fix: Rückgabe eines Exit-Codes ungleich Null, wenn der Status nicht verfügbar ist (#22494)
  • crio: Ingress durch Aktivierung von hostNetwork und ClusterFirstWithHostNet beheben (#22239)
  • crio: Behebung des Preload-Überschreibens von Benutzerbildern (#22246)
  • Podman-Mount unter macOS durch Hinzufügen von host.containers.internal-Unterstützung behoben (#22451)
  • Korrigieren Sie das Versions-Upgrade-Skript cri-dockerd (#22358).
  • Kubelet-Konfigurationsoption FailCgroupV1 auf failCgroupV1 korrigiert (#22325)
  • Addon Registry-Creds: Segfault ohne Konfigurationsdatei behoben (#21786)

Benutzeroberfläche

  • Unterstützung für kurdische Sprache durch LANGUAGE=ku hinzugefügt (#22512)

  • Unterstützung für die ukrainische Sprache über LANGUAGE=uk hinzufügen (#21624)

  • Französische Übersetzung verbessern (#21559)(#21849)(#22155)(#22386)(#22515)(#22114)

  • Chinesische Übersetzungen verbessern (#22082)

  • Benutzeroberfläche: Warnmeldung für Proxy verbessert (#21980)

  • ui: Korrekte Formatierung in der Tunneldienst-Ausgabe korrigiert (#22400)

  • Befehlsparameter für den AI-Playground-Fix ausrichten (#21583)

CNI

  • CNI: Calico von v3.30.3 auf v3.31.3 aktualisieren (#21835)(#21961)(#22259)
  • CNI: Cilium von v1.18.1 auf v1.18.6 aktualisieren (#21655)(#21794)(#21953)(#22253)(#22487)
  • CNI: Flanell von v0.27.3 auf v0.27.4 aktualisieren (#21700)
  • CNI: Kindnetd von v20250512-df8de77b auf v20251212-v0.29.0-alpha-105-g20ccfc88 aktualisieren (#22127)

  • Add-on-Ingress: Ingress-Nginx/Controller-Image von v1.13.2 auf v1.13.3 aktualisieren (#21701)(#21865)(#22049)
  • Addon inspektor-gadget: Inspektor-gadget-Bild von v0.44.1 auf v0.45.0 aktualisieren (#21708)(#22427)(#21843)(#22047)
  • Addon Kong: Kong-Image aktualisieren 3.9.1(#21698)(#21830)(#21952)(#22486)

  • Add-on-Registrierung: Registrierungs-Image von 3.0.0 aktualisieren (#21735)

  • Addon yakd: Image-Registrierung vom Docker Hub nach GHCR migrieren (#22250)
  • Addon yakd: Manusa/yakd-Image von 0.0.5 auf 0.0.7 aktualisieren (#22343)(#22128)
  • Addon: Auto-Pause-Fix github-Link (#22433)

  • Addon: Registry-Proxy Alpine-Slim korrigiert, um Wget zu verwenden (#22550)
