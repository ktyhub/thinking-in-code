📣😀 Bitte füllen Sie unsere schnelle 5-Fragen-Umfrage aus, damit wir erfahren, wie und warum Sie Minikube verwenden und welche Verbesserungen wir vornehmen sollten. Danke schön! 💃🎉

Release Notes

Version 1.39.0 – 2026-09-01

Highlights

  • Unterstützung für Kubernetes, v1.36 und v1.37 hinzufügen (Standard: v1.37.0)
  • Die Standard-Containerlaufzeit ist jetzt containerd
  • Traefik Helm-basiertes Ingress-Add-on hinzufügen
  • VirtualBox-Treiber unterstützt jetzt Apple Silicon (VirtualBox 7.1+)

Funktionen

  • Unterstützung für Kubernetes v1.36 und v1.37 hinzufügen (Standard: v1.37.0) (#23567, #23596)
  • Traefik Helm-basiertes Add-on hinzufügen (#23225)
  • Helm zur Minikube-ISO hinzufügen (#23420)
  • Aktualisieren Sie den Standard-Gasthelm client auf Helm 4 (#23383)
  • Konfigurierbare DNS-Server für VM-Treiber hinzufügen (#23069)
  • --mdns-Flag hinzufügen, um mDNS bei jedem VM-Start zu aktivieren (#22964, #23208)
  • Treiber: Deterministische MAC-Adressen verwenden (#23172)
  • vfkit: VMnet-freigegebenes Netzwerk automatisch auswählen, wenn verfügbar (#23040)
  • Virtualbox: Unterstützt Darwin/Arm64 mit VirtualBox 7.1+ (#22861)
  • ISO: systemd-coredump für Absturz-Stack-Traces hinzufügen (#23064)
  • ISO: Kernel-nftables (CONFIG_NF_TABLES) für knftables-Konsumenten aktivieren (#23518)
  • ISO: Sicherheitsfunktionen für Calico 3.32.2 aktivieren (#23592)
  • ISO: Openvswitch-Kernelmodul für aarch64 einbinden (#23151)
  • ISO: CONFIG_TASK_IO_ACCOUNTING und zugehörige Kernel-Optionen aktivieren (#23271)
  • infra: Laden Sie Preloads von GitHub als Standard und GCS als Failover herunter (#23087)

Leistung

  • Treiber: VM-Treiber parallel starten (#23112)
  • --vmnet-offloading-Startflag für Krunkit-Treiber hinzufügen (#22962)
  • ssh: AES-GCM-Verschlüsselungen für externes SSH bevorzugen client (#23125)
  • ssh: Vermeiden Sie unnötigen Ruhezustand beim Warten auf den SSH-Server (#23001)

Fehlerbehebungen

  • Add-ons: Helm-Überprüfungsfehler in Gast-VMs behoben (#23253, #23329)
  • Korrigieren Sie kubectl exec mit cri-dockerd auf Kubernetes v1.36+ durch Deaktivieren von ExtendWebSocketsToKubelet (#22921)
  • Behebung, dass --extra-config=etcd.* eine ungültige kubeadm-Konfiguration erzeugt (#23051)
  • Logik für CNI-Warnung für mehrere Knoten korrigiert. (#22779)
  • Korrigiert, dass der SSHRunner ExitCode bei SSH-Befehlen immer 0 zurückgibt (#23364)
  • Verwendungszeichenfolge für Minikube-Knotenbefehle korrigiert. (#22775)
  • kvm: Überprüfen Sie die libvirt-Gruppenmitgliedschaft, bevor Sie virsh ausführen (#23369)
  • Behebung des Erhaltungs-Tags für Registry-Refs mit einem Port (#23228)
  • Verwenden Sie gepufferte Kanäle, um Goroutine-Lecks bei Status-Timeout zu verhindern (#23215)
  • Warnung vor Virtualbox nur behoben, wenn das Flag explizit ist (#22960)
  • Bild laden: Stiller Fehler beim Laden eines von einem Container verwendeten Bildes behoben (#23034)
  • Knoten hinzufügen: VorschlagMemoryAllocation anstelle von fest codierten 2200 MB verwenden (#23305)
  • Proxy: RoundTripper-Wrapper durchlaufen, um den Proxy auf dem inneren *http.Transport zu entfernen (#22910)
  • vmnet: Brew-Installationspfad auf Intel-Macs korrigiert und Brew-Bin-Pfad unterstützt (#23039)
  • mount: Notwendigkeit bidirektionaler Firewall-Regeln klären (#20442)
  • Treiber: Deduplizierte DHCP-Lease-Verwaltung unter macOS (#23084)
  • Hack/Update: Registrierungs-Add-on auf dem Haupt-Tag verfolgen (#23586)
  • Hack/Update: Kong-Image-Tag auf 3 aktualisieren (#23585)
  • ISO: Ersetzen Sie Leerzeichen durch Tabulatoren in den Buildroot-Paketdateien von nerdctl-bin (#23438)
  • ISO: Versuch, ISO-Build-Fehler zu beheben (#22879)
  • ISO: Zuverlässigkeit und Fehlerbehandlung des ISO-Build-Skripts behoben (#23218)
  • ISO: Unterstützung beim Erstellen der arm64-ISO auf einem arm64-Host (#22862)
  • ISO: Verwenden Sie Binärdateien für docker buildx statt Build aus dem Quellcode (#22942)

Breaking Changes

  • Standard-Containerlaufzeit in „containerd“ ändern (#23562)
  • ISO/KIC: Beschränken Sie die Unterstützung für cri-dockerd auf x86 und arm64 und migrieren Sie cri-dockerd auf vorkompilierte GitHub-Binärdateien (#22922)

Add-ons

  • Zusatzscheinwerfer: Update von v0.40.0 auf v0.45.0

  • Add-on-Ingress: Update von v1.14.3 auf v1.15.1
  • Add-on-Ingress: Kube-webhook-certgen-Image von v1.6.7 auf v1.6.9 aktualisieren
  • Addon inspektor-gadget: Update von v0.49.1 auf v0.55.1
  • Kong-Add-on: Kong-Image von 3.9.1 auf 3.9.3 aktualisieren
  • Add-on kong: Kong/kubernetes-ingress-controller-Image von 3.5.3 auf 3.5.13 aktualisieren
  • Addon kubevirt: Update von v1.7.0 auf v1.9.0
  • Add-on metrics-server: Update von v0.8.1 auf v0.9.0
  • Addon nvidia-device-plugin: Update von v0.18.2 auf v0.20.0
  • Addon-Registrierung: Update von 3.0.0 auf 3.1.1
  • Addon yakd: Update von 0.0.8 auf 0.0.9
  • HA (Multi-Control-Ebene): Kube-vip von v1.0.4 auf v1.2.3 aktualisieren

Basisbilder

  • ISO: docker-buildx von v0.33.0 auf v0.36.1 aktualisieren

  • Kicbase/ISO: Buildkit von v0.26.3 auf v0.32.2 aktualisieren
  • Kicbase/ISO: CNI-Plugins von v1.9.0 auf v1.9.1 aktualisieren
  • Kicbase/ISO: Containerd von 2.2.1 auf 2.3.4 aktualisieren

  • Kicbase/ISO: Update geht von 1.26.2 auf 1.26.4

  • Kicbase: Bump debian:bookworm von 20260202 auf 20260713

  • CNI: Kattun von v3.31.3 auf v3.32.2 aktualisieren
  • CNI: Cilium von v1.19.0 auf v1.20.1 aktualisieren
  • CNI: Flanell von v0.28.1 auf v0.28.9 aktualisieren
  • CNI: Kindnetd von v20260213-ea8e5717 auf v20260820-69b56db7 aktualisieren

Lokalisierung

  • Brasilianisches Portugiesisch über LANGUAGE=pt-BR hinzufügen (#23062, #23580)

Website

  • Dokumente: Tutorial zum Ausführen von Minikube auf AWS EC2 hinzufügen (#23017)
  • Dokumente: Tunnel-Abstiegslink reparieren (#22389)
  • Behebung der Anforderungsbeschränkungen von ai-playground.md zur Verwendung von devic.es/dri (#23152)
  • Tippfehler in der vmnet-helper-Dokumentation beheben (#22655)
  • Unnötiges Komma in Dashboard.md entfernen (#23101)
  • Kopierschaltfläche und Codeblock-Überlappung behoben (#23443)
  • Bereitstellungs-Image-Tag von Version 10 auf Version 11 aktualisieren (#23060)
  • Aktualisieren Sie das Hyperkit, um die veraltete Version zu beachten. Beachten Sie die Alternativen zum Hypervisor von Apple Silicon (#23027)
  • Roadmap mit entfernter Minikube-Maschine aktualisieren (#22763)

Eigentümer

  • Spowelljr von emeritus_approvers zu Reviewers verschieben (#23555)

Testen

  • Helm: Fehlerbehandlung, Typsicherheit und Testklarheit verbessern (#23348)
