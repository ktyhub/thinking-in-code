Release Notes

Version 1.37.0 – 2025-09-09

Hervorheben

Führen Sie KI-Workloads auf der MacBook-GPU in Kubernetes mit dem neuen krunkit driver aus. Beginnen Sie mit unserem AI Playground-Tutorial

Funktionen

  • Unterstützung für Kubernetes v1.34.0 hinzufügen (#21439)
  • Fügen Sie einen Krunkit-Treiber hinzu, der die GPU-Beschleunigung unter macOS unterstützt (#20826) Tutorial
  • Kurzform -m für --memory hinzufügen (#20854)
  • Unterstützung zur docker-Laufzeit für OCI-Zugriff auf NVIDIA-GPUs hinzugefügt (#20959)
  • --disable-coredns-log-Flag hinzufügen, um CoredNS-Protokolle zu unterdrücken (#20992)
  • neues Addon: kubetail (#20345)
  • Treiber: Unterstützung für Virtiofs-Mounts für vfkit und krunkit hinzugefügt (#21149)

Verbesserungen

  • Ingress-DNS-Addon für IPv4 und Windows v0.0.4 verbessern (#21449)
  • iso: Grub-Timeout deaktivieren, um den VM-Start um 5 Sekunden zu beschleunigen (#20895)
  • docker-Dienstzuverlässigkeit verbessern, docker-Systemd-Dateien aktualisieren (#21174)
  • Für die Verwendung von --mount-string ist nicht sowohl --mount als auch das Entfernen des Standard-Mount-Strings erforderlich (#21250)
  • Älteste unterstützte Kubernetes-Versionen aktualisieren (#21490)
  • Lizenz-Befehl: Nicht fehlschlagen, wenn das Ausgabeverzeichnis nicht existiert, und zuerst von github-Assets herunterladen (#21206)
  • Veraltete Proxy-Refresh-Intervall-v2-ETCD-Flag entfernen (#21278)
  • vmnet: Unterstützung für Offloading für Krunkit (#20831)
  • Rufen Sie startKicServiceTunnel nicht für Nicht-Kic-Treiber auf (#20863)
  • krunkit: Deaktivieren Sie das Offloading für eine schnellere Netzwerkverbindung (#21341)
  • HA (Multi-Control-Ebene): kube-vip von v0.9.1 auf v1.0.0 aktualisieren (#20999)(#21228)

Abschreibung

  • HyperKit-Treiber mit Warnung veraltet (#21024)

Fehlerbehebungen

  • Dirty-Commit-Version behoben (#21062)
  • Das Laden von Minikube-Bildern unter Windows wurde behoben (#20529) (#20921)
  • Das Mounten in denselben Ordner wurde behoben, was zu einem Ein-/Ausgabefehler führte (#21077).
  • Fix: YAML-Datei-Escape-Fehlerproblem, das Add-ons betrifft (#20904)
  • iso: minikube stop mit vfkit- und krunkit-Treibern beheben (#21089)
  • iso: Konsole für vfkit/krunkit reparieren (#20832)

Add-ons

  • Add-on nvidia-device-plugin: nvidia/k8s-device-plugin-Image von v0.17.2 auf v0.17.3 aktualisieren (#21225)
  • Add-on cloud-spanner: Cloud-spanner-emulator/emulator-image von 1.5.34 auf 1.5.41 aktualisieren (#20976)(#21040)(#21243)(#21287)(#21359)(#21512)
  • Zusatzscheinwerfer: Scheinwerferbild von v0.28.0 auf v0.34.0 aktualisieren (#21238)(#21508)
  • Add-on-Ingress: Ingress-Nginx/Controller-Image von v1.12.2 auf v1.13.2 aktualisieren (#20909)(#21232)(#21353)(#21458)
  • Addon inspektor-gadget: Inspektor-gadget-Bild von v0.40.0 auf v0.44.1 aktualisieren (#20873)(#21038)(#21240)(#21462)(#21510)(#21358)
  • Kong-Add-on: Kong-Image von 3.9.0 auf 3.9.1 aktualisieren (#20966)(#21503)
  • Addon Kong: Kong/kubernetes-ingress-controller-Image von 3.4.5 auf 3.5.1 aktualisieren (#20908)(#20969)(#21034)(#21282)
  • Addon kubevirt: Bitnami/kubectl-Image von 1.33.1 auf 1.33.4 aktualisieren (#20911)(#20939)(#21235)(#21283)(#21414)
  • Add-on metrics-server: Update metrics-server/metrics-server image von v0.7.2 auf v0.8.0 (#21033)
  • Add-on-Registrierung: Registrierungs-Image von 3.0.0 auf 3.0.0 aktualisieren (#21242)
  • Addon Volcano: Vulkanbilder von v1.11.2 auf v1.12.2 aktualisieren (#20868)(#21351)
  • Addon Kubetail: Update-Version 0.13.3 (#21244)

CNI-Versionen

  • CNI: Calico von v3.30.0 auf v3.30.3 aktualisieren (#20871)(#20971)(#21416)
  • CNI: Cilium von v1.17.4 auf v1.18.1 aktualisieren (#20968)(#21226)(#21349)
  • CNI: Flanell von v0.26.7 auf v0.27.0 aktualisieren (#20907)(#21230)(#21504)

Basis-Image-Versionen

  • iso: Update auf Langzeitkernel auf 6.6.95 (#20995)
  • iso: VirtioFS für x86_64 und aarch64 aktivieren (#21147)
  • iso: Build- und Bereinigungskonfiguration verbessern (#20991)
  • Kicbase/ISO: CNI-Plugins von v1.7.1 auf v1.8.0 aktualisieren (#21517)
  • Kicbase/ISO: Crun von 1.19 auf 1.23.1 aktualisieren (#21198)(#21330)
  • Kicbase/ISO: docker von 28.0.4 auf 28.4.0 aktualisieren (#21053)(#21248)(#21488)
  • Kicbase: Bump ubuntu:jammy von 20250415.1 auf 20250819 (#21233)(#21413)(#21505)

Benutzeroberfläche

  • „Minikube-Profilliste“ wiederholen, um die ausführlichen Details in ein --det zu verschieben… (#20544)
  • Lange Beschreibung des Konfigurationsflags verbessert (#21515)
  • Spinner-Bibliothek umgestalten und Unterschritte nach dem Drehen ausblenden (#21215)
  • „github-Problem erstellen“ wird nicht zweimal angezeigt, wenn kubeadm init fehlschlägt (#21263)
  • Tabellenrendering umgestalten (#20893)

Benutzeroberfläche/Übersetzungen

  • Griechische Übersetzung hinzufügen
  • Weitere koreanische Übersetzungen hinzufügen (#21467)(#21465)
  • Weitere französische Übersetzung hinzufügen (#21050)(#20862)(#20945)(#20964)(#21156)(#21372)(#21514)
