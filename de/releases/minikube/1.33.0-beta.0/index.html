📣😀 Bitte füllen Sie unsere schnelle 5-Fragen-Umfrage aus, damit wir erfahren, wie und warum Sie Minikube verwenden und welche Verbesserungen wir vornehmen sollten. Danke schön! 💃🎉

Release Notes

Version 1.33.0-beta.0 – 26.03.2024

Eigenschaften:

  • Unterstützung mehrerer Steuerungsebenen – HA-Cluster --ha #17909
  • Add-on gvisor: arm64-Unterstützung hinzufügen #18063 #18453
  • Neues Addon: YAKD – Kubernetes Dashboard-Addon #17775

Kleinere Verbesserungen:

  • Automatische Pause des Add-ons: Speicherverlust entfernen und konfigurierbares Intervall hinzufügen #17936
  • Bilderstellung: docker.io/library zu Bildkurznamen hinzufügen #16214
  • cp: Verzeichnis erstellen, falls nicht vorhanden #17715
  • Fehler beim Abrufen von Protokollen in die Protokollausgabe selbst verschieben #18007
  • Standard-Sysctls hinzufügen, um privilegierte Ports ohne Funktionen zuzulassen #18421
  • Erweiterte Attribute in Preload-Tarballs einbeziehen #17829
  • kubeadm.applyNodeLabels-Label auf alle Knoten anwenden #16416
  • Treiberstatusprüfung auf 20 Sekunden beschränken #17553
  • Journalctl-Protokolle einbeziehen, wenn der Systemd-Dienst nicht gestartet werden kann #17659
  • ISO: CONFIG_DM_MULTIPATH #18277 hinzufügen
  • ISO: CONFIG_QFMT_V2 für arm64 hinzufügen #17991
  • ISO: CONFIG_CEPH_FS für arm64 hinzufügen #18213
  • ISO: CONFIG_BPF für arm64 hinzufügen #17206

Fehler:

  • Fix „Container-Laufzeit konnte nicht aktiviert werden: sudo systemctl restart cri-docker“ #17907
  • Behebung eines Containerd-Neuladens vorhandener Bilder beim Start #17671
  • Behebung, dass kvm2 das Vorladen von Containerd nicht erkennt #17658
  • Korrektur der Änderung der binfmt-Konfiguration Docker #17830
  • Auto-Pause-Add-on behoben #17866
  • Behebung, dass Preload nicht mit dem OverlayFS-Speichertreiber verwendet wurde #18333
  • Behebung eines Problems, bei dem Bild-Repositorys Subdomains mit Zahlen nicht zulassen #17496
  • Behebung des Clusterstopps bei Verwendung von kvm2 mit Containerd #17967
  • Behebung des Starts von mehr als einem Cluster auf kvm2 arm64 #18241
  • Fehler beim Starten von kvm2-Clustern unter Linux auf arm64-Mac behoben #18239
  • Anzeigefehler beim Löschen nicht vorhandener Cluster behoben #17713
  • Behebung, dass No-Limit beim Neustart nicht berücksichtigt wurde #17598
  • Behebung, dass die Bezeichnung kubeadm.applyNodeLabels nicht auf Knoten angewendet wurde, die nach dem ersten Start hinzugefügt wurden #16416
  • Protokolltrennzeichenausgabe behoben #17734

Versions-Upgrades:

  • Standardversion der Bump-Kubernetes-Version: v1.29.3 und neueste Version: v1.30.0-beta.0 #17786
  • Add-on cloud-spanner: Cloud-spanner-emulator/emulator-image von 1.5.11 auf 1.5.15 aktualisieren #17595 #17847 #18165 #18431
  • Add-on gcp-auth: k8s-minikube/gcp-auth-webhook-Image von v0.1.0 auf v0.1.2 aktualisieren #18222 #18384
  • Zusatzscheinwerfer: Scheinwerfer-k8s/Scheinwerferbild von v0.20.1 auf v0.23.0 aktualisieren #17586 #17846 #18320
  • Add-on-Ingress: Ingress-Nginx/Controller-Image von v1.9.4 auf v1.10.0 aktualisieren #17848 #18166 #18284
  • Addon inspektor-gadget: Inspektor-gadget/inspektor-gadget-Bild von v0.22.0 auf v0.26.0 aktualisieren #17740 #17885 #18169 #18358
  • Addon istio-provisioner: Istio/Operator-Image von 1.19.3 auf 1.21.0 aktualisieren #17651 #17777 #17957 #18168 #18429
  • Kong-Add-on: Kong-Image von 3.4.2 auf 3.6.1 aktualisieren #17605 #18200 #18350
  • Addon kubevirt: Bitnami/kubectl-Image von 1.24.7 auf 1.29.3 aktualisieren #18170 #18187 #18427
  • Add-on metrics-server: Aktualisieren Sie das metrics-server/metrics-server-Image von v0.6.4 auf v0.7.0 #18051
  • Addon nvidia-device-plugin: nvidia/k8s-device-plugin-Image von v0.14.2 auf v0.14.5 aktualisieren #17623 #18171 #18283
  • Add-on-Registrierung: k8s-minikube/kube-registry-proxy-Image von 0.0.5 auf 0.0.6 aktualisieren #18454
  • CNI: Kattun von v3.26.3 auf v3.27.0 aktualisieren #17644 #17824
  • CNI: Cilium von v1.12.3 auf v1.15.1 aktualisieren #18259
  • CNI: Flanell von v0.22.3 auf v0.24.4 aktualisieren #17837 #17975 #18014 #18500
  • CNI: Kindnetd von v20230809-80a64d96 auf v20240202-8f1494ea #18167 aktualisieren
  • Kicbase/ISO: Buildkit von v0.12.3 auf v0.13.0 aktualisieren #17738 #18375
  • Kicbase/ISO: CNI-Plugins von v1.3.0 auf v1.4.1 aktualisieren #17761 #18375
  • Kicbase/ISO: Containerd von v1.7.8 auf v1.7.14 aktualisieren #17634 #17711 #17765 #18375
  • Kicbase/ISO: docker von 24.0.7 auf 25.0.4 aktualisieren #18375
  • Kicbase/ISO: Update Go von 1.21.3 auf 1.22.1 #17619 #17760 #17953 #18197 #18375
  • Kicbase/ISO: Nerdctl von 1.6.2 auf 1.7.4 aktualisieren #17565 #17703 #17806 #18375
  • Kicbase/ISO: Runc von v1.1.9 auf v1.1.12 aktualisieren #17581 #18020 #18375
  • Kicbase: nerdctld von 0.2.0 auf 0.5.1 aktualisieren #17764 #17857
  • Kicbase: Ubuntu:jammy von 20231004 auf 20240227 aktualisieren #17719 #17822 #18244 #18375
  • ISO: cri-o von v1.24.1 auf v1.29.1 aktualisieren #18020
