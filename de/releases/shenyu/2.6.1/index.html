2.6.1

Neue Funktionen

  1. Fügen Sie die Dubbo-Annotationsanalyse für den Shenyu-Ingress-Controller hinzu
  2. Unterstützen Sie den Plugin-Lebenszyklus
  3. Unterstützen Sie shenyu-sdk-client von openFeign
  4. Hinzufügen eines Motan-Plugins und Spring Cloud zum Shenyu-Ingress-Controller
  5. Support-Benachrichtigung
  6. Shenyu client fügt Discovery Register Center hinzu
  7. Fügen Sie den Shenyu-Kontextpfad-Plugin-Ingress-Controller hinzu
  8. Fügen Sie den Shenyu grpc-Plugin-Ingress-Controller hinzu
  9. Fügen Sie den Shenyu-Sofa-Eingangsregler hinzu
  10. Fügen Sie Nacos, etcd, Eureka als Erkennungsdienst hinzu
  11. Neues Plugin hinzufügen: basic-auth
  12. Fügen Sie das Shenyu-Logging-Rabbitmq-Plugin hinzu
  13. Bindungsselektor von shenyu-discovery

API Änderungen

  1. Refaktorieren Sie die Datenstruktur der Shenyu-Synchronisierungsdaten

    plugin.list ["plugin.sign", "plugin.dubbo", "plugin.pluginName"]
-> plugin.sign
-> plugin.dubbo
-> plugin.pluginName

examples data:
selector.key1.list ["selector.key1.value1", "selector.key1.value2", "selector.key1.value3"]
-> selector.key1.value1
-> selector.key1.value2
-> selector.key1.value3

selector.key2.list ["selector.key2.value1", "selector.key2.value2", "selector.key2.value3"]
-> selector.key2.value4
-> selector.key2.value5
-> selector.key2.value6

  2. Unterstützen Sie NettyClient als Standard httpclient

  3. Refactoring des Admin-Listeners zur Unterstützung der Admin-Datensynchronisierung

  4. Entfernen Sie die brpc-Unterstützung, einschließlich des brpc-Plugins, des brpc-Beispiels und des integrierten brpc-Tests

  5. Entfernen Sie die Apollo-Abhängigkeit, um Java 17 zu unterstützen (JAR selbst hinzufügen)

  6. Entfernen Sie das Shenyu-Middleware-Register client
