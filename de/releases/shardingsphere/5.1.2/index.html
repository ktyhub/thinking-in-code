Neue Funktion

  11. Proxy: Vollständige Befehls-Tags für Schema-DDL im ShardingSphere-Proxy PostgreSQL / openGauss

  18. Skalierung: Aktualisieren Sie den lokalen Jobstatus, bevor Sie den Jobstatus im Registrierungscenter speichern. Stellen Sie sicher, dass er später nicht überschrieben wird
  19. Skalierung: Behandlung von Nullwerten im TestDecodingPlugin für PostgreSQL
  20. DistSQL: Behebung, dass die SET VARIABLE-Änderung im Standalone- und Speichermodus nicht wirksam wird
  21. DistSQL: Behebung der Inkonsistenz zwischen SHOW INSTANCE LIST-Anzeigedaten und tatsächlichen Daten
  22. DistSQL: Korrektur der capitalisierungsempfindlichkeit beim Sharding von DistSQL

  24. Verteilte Transaktion: getIndexInfo mit Katalog reparieren
