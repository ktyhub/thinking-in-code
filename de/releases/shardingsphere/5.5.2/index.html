  19. SQL Binder: Unterstützt SQL-Bindung für Select mit aktueller Select-Projektionsreferenz – #34151
  20. SQL Binder: Unterstützt das Ändern der Tabelle, das Löschen der Tabellen-SQL-Bindung und das Hinzufügen von Testfällen – #34154

  22. SQL Binder: Unterstützt das Kopieren der SQL-Bind-Anweisung und das Hinzufügen eines Bind-Testfalls – #34159

  27. SQL Binder: Unterstützt das Anzeigen der Tabellenerstellung, das Anzeigen von Spalten und das Anzeigen der Indexanweisungsbindung – #34271

  31. Speicher: Unterstützt die Verbindung zu HiveServer2 über andere Datenbankverbindungspools als HikariCP – #33762

  35. SQL Federation: Aktualisieren Sie die Calcit-Version auf 1.38.0 und aktualisieren Sie alle Lizenzinformationen in der LIZENZ-Datei – #33279
  36. JDBC: Datenbanknamen für JDBC anzeigen hinzufügen, wenn SHOW COMPUTE NODES ausgeführt wird – #33437

  41. Proxy Native: Unterstützt die Verbindung zu HiveServer2 mit aktivierter ZooKeeper Service Discovery im GraalVM Native Image – #33768

  43. Proxy Native: Unterstützt die Seata AT-Integration unter Proxy Native im GraalVM Native Image – #33889
  44. Sharding: Unterstützt die GroupConcat-Funktion zum Aggregieren mehrerer Shards in MySQL, OpenGauss, Doris – #33808
  45. Agent: Vereinfachen Sie die Verwendung des Docker-Images des Agenten – #33356
  46. Modus: Unterstützt das Ändern von Hikari-CP-Konfigurationen über Requisiten im Standalone-Modus #34185
  47. Verschlüsseln: Unterstützt das Umschreiben von Insert-Anweisungen mit Zitat #34259
  48. Infra: Unterstützt die Verbindung zu Firebird über jdbcUrl, das den absoluten Pfad zu fdb enthält – #34335

Fehlerbehebungen

  1. SQL-Parser: Behebt die LiteralExpressionSegment-Umwandlungsausnahme im SQL-Parser – #33332
  2. SQL-Parser: Behebt den Fehler „PostgreSQL“ und „openGauss Time Extract Function Parse Week and Quarter“ – #33564
  3. SQL-Parser: Behebt den Fehler „MySQL Parse Zone Unreserved Keyword“ – #33720
  4. SQL-Parser: Behebt den Bereichsanalysefehler MySQL bei Verwendung des Tabelleneigentümers – #33874
  5. SQL Binder: Behebt die Ausnahme, dass die Tabelle nicht vorhanden ist, wenn HintManager#setDatabaseName zur Transparenz verwendet wird – #33370
  6. SQL Binder: Verwenden Sie Multimap und CaseInsensitiveString, um CaseInsensitiveMap für die Unterstützung von MySQL-Mehrfachtabellenverknüpfungen mit demselben Tabellenalias zu ersetzen – #33303
  7. SQL Binder: Behebt das Problem, dass die Combine-Anweisung beim Binden die äußere Tabelle nicht finden konnte – #33357
  8. SQL Binder: Behebt SQL-Leistungsprobleme, die durch wiederholte Unterabfrageabrufe verursacht werden – #33361
  9. SQL Binder: Behebt das Problem, dass das Ausdruckssegment beim Binden die äußere Tabelle nicht finden kann – #34015
  10. Speicher: Fixes können keine Verbindung zu HiveServer2 über den Remote-Hive-Metastore-Server herstellen – #33837
  11. Proxy: Behebt die BatchUpdateException beim Ausführen von INSERT INTO ON DUPLICATE KEY UPDATE im Proxy-Adapter – #33796
  12. Proxy: Behebt, dass „ALLE PRIVILEGES AUF DB.*“ bei der SELECT-Berechtigungsüberprüfung für MySQL nicht erkannt wird – #34037
  13. Proxy: Behebt den vom Proxy-Protokoll zurückgegebenen falschen Spaltentyp MySQL Longblob – #34121
  14. Proxy: Behebt den Proxy-Fehler MySQL, wenn SQL-Einfügung mehr Parameter enthält, die nicht in der Syntax für Einfügewerte enthalten sind – #34287
  15. Sharding: Entfernen Sie die ShardingRouteAlgorithmException-Prüflogik vorübergehend, um andere tatsächliche Tabellennamenkonfigurationen zu unterstützen – #33367
  16. Sharding: Korrigiert SQL COUNT mit GROUP BY, um falsche Zeilenrückgaben zu verhindern – #33380
  17. Sharding: Behebt die Funktion „Durchschnitt“, „Summe“, „Min“, „Max“, die leere Daten zurückgibt, wenn kein Abfrageergebnis zurückgegeben wird – #33449
  18. Verschlüsseln: Behebt Zusammenführungsausnahme ohne Verschlüsselungsregel in der Datenbank – #33708
  19. Verschlüsseln: Verwenden Sie SQL-Bindungsinformationen in EncryptInsertPredicateColumnTokenGenerator, um eine falsche Spaltentabellenzuordnung zu vermeiden – #34110
  20. Modus: Behebt JDBCRepository fehlerhafte Handhabung der H2-Datenbank im Speichermodus – #33281
  21. Modus: Behebt doppelte Spaltennamen, die hinzugefügt wurden, wenn der Index in DDL geändert wurde – #33982
