Shardingsphere 5.5.1

API Änderungen

  1. Autorität: Markieren Sie den Berechtigungsanbieter ALL_PERMITTED als veraltet und wird in Zukunft entfernt
  2. DistSQL: Entfernen Sie den optionalen Parameter „usageCount“ aus den Anzeigespeichereinheiten
  3. Lese-/Schreibaufteilung: Ändern Sie dataSources in dataSourceGroups für YAML

Neue Funktionen

  1. Kernel: Neues Doris-, Hive- und Presto-SQL-Parsermodul und Datenbanktyp hinzufügen

Verbesserungen

  1. DistSQL: Überprüfen Sie die Berechtigung beim Registrieren oder Ändern der Speichereinheit
  2. DistSQL: Überprüfen Sie doppelte tatsächliche Datenknoten, wenn Sie eine Sharding-Tabellenregel erstellen oder ändern
  3. DistSQL: Ähnliche Unterstützung für Show-Storage-Units hinzufügen
  4. DistSQL: Rollback, wenn die Konfiguration der Importdatenbank fehlschlägt
  5. DistSQL: Tabellentyp zur Ergebnismenge der Anzeige logischer Tabellen hinzufügen
  6. SQL-Parser: Unterstützt die MySQL-Änderungsreplikation ohne Server-IDs
  7. SQL-Parser: Unterstützt MySQL-Zeilen- und Spaltenaliase mit ON DUPLICATE KEY UPDATE
  8. SQL-Parser: Unterstützt MySQL CALL sql mit dem Präfix mysql
  9. SQL-Parser: Unterstützt MySQL beim Erstellen einer ladbaren Funktion, die int/dec zurückgibt
  10. SQL-Parser: Unterstützt das Parsen von MySQL CREATE TABLESPACE/TABLE in Mysql-8
  11. SQL-Parser: Unterstützt das Parsen von MySQL CREATE INDEX mit ENGINE_ATTRIBUTE
  12. SQL-Parser: Unterstützt das Parsen von MySQL LOAD DATA mit @-Variablen
  13. SQL-Parser: Unterstützt das Parsen der MySQL START REPLICA-Anweisung
  14. SQL-Parser: Unterstützt das Parsen der Tabellenfunktion MySQL json
  15. SQL-Parser: MySQL-Spalte hinzufügen, keine Null-SQL-Analyse
  16. SQL-Parser: MySQL-Zeichensatz-SQL-Analyse hinzufügen
  17. SQL-Parser: Verbessern Sie das Ergebnis der Visit-Anweisung der Funktion mysql json
  18. SQL-Parser: Unterstützt die Schlüsselwörter PostgreSQL COLLATION und CONSTRAINT
  19. SQL-Parser: Unterstützt PostgreSQL, openGauss-Funktionstabelle und Aktualisierung aus der Analyse
  20. SQL-Parser: Unterstützt CTE mit PostgreSQL und openGauss
  21. SQL-Parser: Optimieren Sie die Zeitzonenunterstützung von PostgreSQLDateValueParser.
  22. SQL-Parser: Unterstützt PostgreSQL-Limit und Offset als Null
  23. SQL-Parser: Erweitern Sie die Oracle-Update-Anweisung als Alias-Parser und fügen Sie einen Testfall hinzu
  24. SQL-Parser: Unterstützt SQL-Parsing vom Typ Oracle-Spaltenlängeneinheit
  25. Metadaten: Tabellentyp für PostgreSQL sammeln
  26. Kernel: Unterstützt den SQL-Hinweisextrakt, wenn SQL einen Dbeaver-Hinweiskommentar enthält
  27. Kernel: Extrakt hinzufügen, kombinieren und links in der Methode extractFromSelectStatementWithoutProjection auswählen
  28. Kernel: Unterstützten Knoten hinzufügen, um Datenbanken zu erstellen und zu löschen
  29. Transaktion: Verwenden Sie denselben Transaktionstyp in einer Transaktion im JDBC-Adapter
  30. Transaktion: Unterstützung für den Wechsel der Transaktionstypen
  31. SQL Federation: Unterstützt die SQL Federation-Funktion bit_count für mysql
  32. SQL Federation: Verbessern Sie die SQL-Funktionen atan und anan2 für mysql
  33. SQL Federation: Unterstützt die Bin-Funktion der Verbundabfrage mysql
  34. SQL Federation: Unterstützung für den NOT-Operator für föderierte Abfragen
  35. Proxy: Bringen Sie die Ergebnisse der Showtabellen in die richtige Reihenfolge
  36. Proxy: Metadatenerfassung beim Erstellen und Löschen von Datenbanken und Tabellen auslösen
  37. Proxy: Optimieren Sie den Agent, um das Sammeln von Metrikdaten aus mehreren Datenquellen bei Verwendung mit Driver zu unterstützen
  38. Proxy Native: Fügen Sie weitere graalvm-Erreichbarkeitsmetadaten für den Koffein-Cache hinzu
  39. Sharding: Überarbeiten Sie alle lokalen Indizes für die Sharding-Tabelle und fügen Sie Objekt-Eindeutigkeitsebenen-SPI hinzu, um den Index-Token-Generator zu steuern
  40. Sharding: Fügen Sie NullsOrderType.LOW und NullsOrderType.HIGH hinzu, um die NULL-Reihenfolge in der Sharding-Funktion zu verarbeiten
  41. Sharding: Fügen Sie Inline-Sharding-Algorithmen hinzu, die mit der tatsächlichen Datenknotenprüfung übereinstimmen
  42. Verschlüsseln: Nicht unterstützte Prüfung für Combine-Anweisung mit Encrypt-Spalten hinzufügen
  43. Verschlüsseln: Unterstützt Select Unique (Spalte), Verschlüsselung, Umschreiben und Refactoring der SubstitutableColumnNameToken-Build-Logik
  44. Verschlüsseln: Unterstützt das Umschreiben verschachtelter Concat-Anweisungen wie Concat mit der Verschlüsselungsfunktion
  45. Pipeline: Fügen Sie SHARDING_TOTAL_COUNT Impl von JobExecutorServiceHandler hinzu, um die CPU-Kernanforderungen zu verbessern
  46. Pipeline: Unterstützt Seitenabfragen für Inventar-Dumper und Datenkonsistenz-Streaming-Abfragen
  47. Pipeline: Verwenden Sie Bezeichner, bei denen die Groß-/Kleinschreibung nicht beachtet wird, um den Tabellenmetadaten-Loader zu verbessern
  48. Pipeline: Unterstützt die Reihenfolge der Primärschlüsselspalten für den Standard-Metadatenlader für Pipelinetabellen

Fehlerbehebungen

  1. DistSQL: Fehler beim Laden einer einzelnen Tabelle nach dem Erstellen einer logischen Datenquelle behoben
  2. DistSQL: Fehler beim Festlegen der Standardspeichereinheit für eine einzelne Tabelle auf „Zufällig“ behoben
  3. DistSQL: Fehler beim Festlegen der standardmäßigen Einzeltabellenspeichereinheit auf logische Datenquelle behoben
  4. DistSQL: NPE beim Importieren von Metadaten beheben
  5. SQL-Parser: Unterstützt PostgreSQL, keine Konfliktaktion durchzuführen
  6. SQL-Parser: Fehler bei der Analyse der Oracle-NVL-Funktion und der Intervallstunde behoben
  7. Metadaten: Behalten Sie den verwendeten Speicherknoten bei, wenn Sie die Registrierung der Speichereinheit aufheben
  8. Metadaten: Das Problem der fehlenden Speichereinheit bei der Registrierung der Speichereinheit wurde behoben
  9. Kernel: Ersetzen Sie ThreadLocal durch TransmittableThreadLocal im HintManager, um die Thread-übergreifende Verwendung zu unterstützen
  10. Kernel: Verwenden Sie ConnectionPropertiesParser spi, um jdbcUrl zu analysieren und den Oracle-URL-Analysefehler zu beheben
  11. Kernel: Behebung der durch den Systemtabellenrichter postgresql verursachten Ausnahme bei der Spaltenanzahlzusicherung
  12. SQL Binder: TableAvailable-Schnittstelle für CloseStatementContext, MoveStatementContext, FetchStatementContext hinzufügen und den SQL-Rewrite-Testfall korrigieren
  13. Transaktion: Behebung, dass der Aufruf der setSavepoint-Methode nicht bereinigt wird
  14. Transaktion: Fix: Der Savepoint-Manager wurde in verteilten Transaktionen nicht bereinigt
  15. Transaktion: Beheben Sie, dass der Transaktionskontext nicht bereinigt wird, wenn eine xa-Transaktion festgeschrieben wird
  16. Transaktion: Beheben Sie das Problem, dass der Cursor nicht neu geschrieben wird
  17. SQL Federation: Konvertierung der föderierten Abfrage LocalDateTime korrigiert
  18. SQL-Föderation: Behebung des Push-Down-SQL-Ausführungsfehlers, wenn SQL chinesische Zeichen mit SQL-Föderation enthält
  19. SQL Federation: Korrigieren Sie die Datenabfrage des Binärtyps der Verbundabfrage
  20. SQL Federation: Null-Ergebnis in der Verbundabfrage für eine einzelne projizierte Spalte behoben
  21. SQL-Föderation: Behebung der Ausnahme eines unbekannten SQL-Föderationstyps, die durch Calcit mit falschem Ergebnistyp mit Bigint verursacht wurde
  22. Proxy: Unterstützt binäre Werte vom Typ Bool in PostgreSQL
  23. Proxy: Unterstützt den vom Array-Typ vorbereiteten Parameter in PostgreSQL
  24. Proxy: Unterstützt binäre Protokollwerte für Textarrays in PostgreSQL
  25. Proxy: Korrigieren Sie doppelte Ergebnisse beim Abfragen von information_schema.SCHEMATA
  26. Proxy: Korrigieren Sie falsche Ergebnisse bei der Abfrage von information_schema.SCHEMATA
  27. Proxy: NPE beheben, wenn der Tabellenstatus angezeigt wird
  28. Proxy: Behebung, dass keine Datenbank-Auswahl-Ausnahme auftritt, wenn Tabellen aus der Datenbank angezeigt werden
  29. Proxy: Beheben Sie den Fehler, dass der Prozess nicht beendet wird, nachdem der Proxy-Start fehlgeschlagen ist
  30. Proxy: Behebung des Fehlers, dass die persistenten Systemmetadaten nicht gelöscht wurden, nachdem die Datenbank im PostgreSQL-Szenario gelöscht wurde
  31. Proxy: Behebung der Ausnahme, dass keine Datenbank ausgewählt wurde, in der SQL-Abfrage
  32. JDBC: Beheben Sie das Problem, bei dem „Zip-Datei geschlossen“ in Versionen vor SpringBoot 2.3 war.
  33. JDBC: Beheben Sie das NPE, wenn es im Treiber keine angegebene Logikdatenbank enthält.
  34. Sharding: Behebung, dass die Sharding-Spalte nicht über Aliase verfolgt wird
  35. Sharding: Die Ausnahme beim Ändern der Ansicht beim Konfigurieren der Sharding-Regel und der Bindungstabellenregel wurde behoben
  36. Sharding: Die Lösung besteht darin, dass die Logik akkumuliert werden muss
  37. Sharding: Behebung des Fehlers bei der Groß-/Kleinschreibung bei generierten Schlüsselspaltennamen
  38. Verschlüsseln: Behebung eines Fehlers beim Erstellen einer Tabelle beim Verschlüsseln, wenn der Datentyp Float enthält
  39. Verschlüsseln: Behebung des Problems, bei dem eine nicht verschlüsselte Tabelle aktualisiert und eine Unterabfrage für eine verschlüsselte Tabelle verwendet wurde.
  40. Verschlüsseln: Fügen Sie „Einfügen“ hinzu und wählen Sie „Umschreiben“ für die Verschlüsselung aus
  41. Pipeline: InventoryTaskSplitter kompatibel mit BigInteger-Primärschlüssel
  42. Pipeline: Behebung des Verlusts der Standarddatenquelle beim Erstellen eines Migrationsjobs
