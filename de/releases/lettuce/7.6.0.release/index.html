Salat 7.6.0.RELEASE

Das Lettuce-Team freut sich, die Nebenversion von Lettuce 7.6.0 bekannt zu geben!

✨ Highlights

Lettuce 7.6.0 führt Unterstützung für die neuen Funktionen von [Redis OSS 8.8-Release] (https://github.com/redis/redis/releases/tag/8.8.0) ein, wie zum Beispiel:

  • die neue Array-Datenstruktur
  • INCREX: ein Fensterzähler-Ratenbegrenzer, der INCR, INCRBY, INCRBYFLOAT, Grenzen und Ablauf kombiniert
  • XNACK: ein neuer Streams-Befehl – ermöglicht es Verbrauchern, ausstehende Nachrichten explizit freizugeben
  • ZUNION, ZINTER, ZUNIONSTORE, ZINTERSTORE: neuer COUNT-Aggregator
  • JSON.SET: neues FPHA-Argument zur Angabe des FP-Typs für homogene FP-Arrays

Salat 7.6.0 unterstützt Redis 2.6+ bis Redis 8.x. In Bezug auf die Java-Laufzeit erfordert Lettuce mindestens Java 8 und Funktioniert mit Java 24. Der Treiber wurde gegen Redis 8.8, Redis 8.6, Redis 8.4, Redis 8.2, Redis 8.0, Redis 7.4 und Redis 7.2 getestet.

Vielen Dank an alle Mitwirkenden, die Lettuce 7.6.0.RELEASE möglich gemacht haben.

📗 Links Referenzdokumentation: https://lettuce.io/core/7.6.0.RELEASE
