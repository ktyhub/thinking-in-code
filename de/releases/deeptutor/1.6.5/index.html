DeepTutor v1.6.5

DeepTutor v1.6.5 Release Notes

Veröffentlichungsdatum: 2026.09.06 v1.6.5 gibt DeepTutor einen eigenen Ordner zum Arbeiten. Sie zeigen auf ein Verzeichnis und der Assistent kann durchsuchen, lesen und durchsuchen, was bereits vorhanden ist, während alles, was er generiert, an einem vorhersehbaren Ort landet – und alles, was diesen Ort verlässt, erfordert zuerst Ihre Zustimmung. Dabei wird die Codeausführung in einem einzigen Tool zusammengeführt, Mastery Path lernt, wann es erlaubt ist, etwas zu lehren oder neu zu entwerfen, und die Einstellungen unterscheiden schließlich zwischen „nicht konfiguriert“ und „kaputt“. Drop-in für lokale Installationen; Docker-Benutzer sollten den folgenden Hinweis zur Arbeitsbereichsbereitstellung lesen.

Was ist neu?

Ein Inhaltsarbeitsbereich, den Sie auswählen

Richten Sie DeepTutor auf einen beliebigen Ordner und dieser wird zum Arbeitsverzeichnis für die gesamte Sitzung. Der Assistent kann den Inhalt auflisten, lesen und durchsuchen, sodass Ihr eigenes Material verfügbar ist, ohne etwas hochladen zu müssen. Generierte Dateien landen in outputs/, und das Verschieben einer Datei aus outputs/ in den Rest Ihres Ordners ist ein expliziter, vom Benutzer genehmigter Schritt und nicht etwas, das stillschweigend geschieht. Verwalten Sie es über die Einstellungen oder mit deeptutor workspace show, set und reset.

Ein Tool führt Code aus

code_execution und exec waren zwei Werkzeuge mit einer Aufgabe. Sie sind jetzt ein einzelnes exec, das Python, C, C++ oder Shell akzeptiert. Jeder Aufruf in einer Runde teilt ein Arbeitsverzeichnis und eine Abhängigkeitsumgebung, sodass ein späterer Aufruf eine Datei, die ein früherer Aufruf geschrieben hat, erneut öffnen und überarbeiten kann, anstatt von vorne zu beginnen.

Mastery Path weiß, in welchem Modus es sich befindet

Ein Studienziel wechselt nun zwischen drei Modi – Entwurf entwerfen, weiterentwickeln und überprüfen – und die verfügbaren Tools folgen. Nur outline kann die Karte ändern, sodass ein Tutor Ihren Plan nicht stillschweigend mitten im Unterricht umschreiben kann; Nur study und review können Sie untersuchen, und keiner von beiden wird beginnen, bevor tatsächlich ein Entwurf vereinbart wurde. Die gestellten Fragen kommen als Karte, die den Spielzug beendet, sodass die Beantwortung eine bewusste Handlung ist.

Einstellungen unterscheiden zwischen „nicht eingerichtet“ und „kaputt“

In der Übersicht wird jede Funktion als Blocker, Warnung oder Hinweis eingestuft und in jeder Zeile wird angegeben, ob die Installation tatsächlich davon abhängt. Ein optionales Videomodell, das Sie nie konfiguriert haben, wird nicht mehr als Fehler gemeldet; ein Parser, den Sie ausgewählt haben und der nicht funktioniert. Die Matrix enthält nur Identitäten, boolesche Werte und Ursachencodes – Anbieter-URLs, Modellnamen, Anmeldeinformationen und Ausnahmetexte bleiben auf dem Server und Modellanbieter werden niemals zum Erstellen aufgerufen.

Fragen erscheinen, während sie noch geschrieben werden

Eine ask_user-Karte traf auf einmal ein, einige Sekunden nachdem sie in der Prosa vorgestellt wurde. Die Karte erscheint nun mit ihrem Intro und erweitert ihre Optionen an Ort und Stelle, während das Modell sie schreibt, sodass der Zug nicht mehr verstummt, wenn er Sie um etwas bittet.

Video-Lernen, das Sie behalten können

Verbundene Invidious-Konten erhalten ihre eigenen Adapter, Transkript-Hinweise bleiben während der Wiedergabe sichtbar und zeitgestempelte Notizen werden nach Markdown exportiert. Eine visuelle Lerntafel sammelt, was eine Sitzung hervorgebracht hat.

Wissensdatenbanken pinnen ihre Indizierungsmodelle

LightRAG-Wissensdatenbanken zeichnen auf, welche Modelle sie indiziert haben, und ermöglichen Ihnen, diese Modelle pro Datenbank anzuheften, sodass eine Neuindizierung nicht stillschweigend die Einbettung hinter einem vorhandenen Index ändert.

Subagenten über das Kabel

Ein gehärtetes Remote-Backend von Hermes verbindet die lokalen Subagenten-Kabelbäume, sodass ein konsultierter Agent an einem anderen Ort als diesem Computer ausgeführt werden kann.

Korrekturen

Chinese Markdown behält seinen Rohinhalt beim Streaming; unsichere Websuchtitel und Snippets werden gefiltert; DeepSeek Reasoning-Replay 400s aus Antwortrunden fallen zurück, anstatt in der Runde durchzufallen; Die Einstellungen scrollen in einem eigenen Bereich; alte Mastery /study-URLs leiten zu /sessions weiter; Quizkartentext dekodiert Unicode-Escapes; wiederhergestellter Lesestoff lädt langsam; und Quell-Checkouts werden beim Aktualisieren korrekt erkannt.

Upgrade-Hinweise

Führen Sie pip install -U deeptutor aus; Docker-Benutzer ziehen ghcr.io/hkuds/deeptutor:latest. Einstellungen, Bücher, Sitzungen und Lerndaten erfordern keine manuelle Migration.

  • Das code_execution-Tool ist weg – seine Arbeit wurde in exec verschoben. Benutzerdefinierte Eingabeaufforderungen, Fähigkeiten oder Plugins mit dem Namen code_execution sollten stattdessen exec mit einem language aufrufen.
  • Docker Workspace Mount. Der Container erwartet nun den Content Workspace am stabilen Pfad /workspace. Stellen Sie DEEPTUTOR_WORKSPACE_HOST=/absolute/host/folder vor python scripts/docker_compose.py up -d ein, um den Hostordner auszuwählen. wenn man es weglässt, bleibt ./data/user/workspace erhalten. Der Helfer erstellt den Ordner und seinen outputs/ für Sie, sodass der Bind-Mount nicht Root-Besitz ist.
  • Der Sandbox-Runner sieht weniger. data/users wird nicht mehr gemountet; Es empfängt /workspace schreibgeschützt und /workspace/outputs beschreibbar, begrenzt durch DEEPTUTOR_RUNNER_ALLOWED_WORKDIRS. Ausgeführter Code kann nicht mehr auf die Einstellungen, den Chatverlauf oder die Wissensdatenbanken eines anderen Kontos zugreifen.
  • Mehrbenutzerbereitstellungen teilen den gemounteten Arbeitsbereich. Wenn DEEPTUTOR_WORKSPACE_ROOT festgelegt ist (jede bereitgestellte Compose-Datei legt dies fest), ist ein Ordner der Inhaltsarbeitsbereich für jedes Konto und der Pfad wird in den Einstellungen als gesperrt angezeigt. Lassen Sie es deaktiviert, um Arbeitsbereiche pro Benutzer beizubehalten. – Erweiterungen, die deeptutor.config.schema, .defaults, .accessors oder .constants importieren, müssen in die öffentlichen Einstellungsoberflächen verschoben werden; Diese Module wurden entfernt.
  • Die englischen und chinesischen Anleitungen wurden gemeinsam unter deeptutor.info aktualisiert. Voll Changelog: https://github.com/HKUDS/DeepTutor/compare/v1.6.4...v1.6.5
