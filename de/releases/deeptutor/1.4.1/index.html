DeepTutor v1.4.1

DeepTutor v1.4.1 Release Notes

Veröffentlichungsdatum: 2026.05.27 v1.4.1 ist ein Sicherheits- und Stabilitätspatch für v1.4.0. Es verriegelt sich Die TutorBot-Tool-Sandbox isoliert Ressourcen pro Benutzer und behebt einen v1.4.0-Chat Regression, fügt ein HTTP API für die Kommunikation mit einem bestimmten TutorBot hinzu und versendet a multimodaler Bild-Fallback-Fix für Anbieter DeepTutor hat keinen Visionseintrag für.

Was ist neu?

TutorBot Tool Sandbox ist Opt-In

Das Shell-Tool exec wird nicht mehr registriert, es sei denn, ein Administrator legt dies fest allow_shell_exec, und der gesamte Dateisystem- und Shell-Zugriff ist auf den Bot beschränkt Arbeitsbereich standardmäßig. Befehlsverweigerungslisten wurden beim Befehl neu verankert Grenzen, und allow_shell_exec kann nicht über die Update-Payload aktiviert werden.

Ressourcenisolation pro Benutzer

Buchstämme, Sitzungsdatenbanken, Turn-Runtime-Speicher und TutorBot-Verzeichnisse sind pro Benutzer begrenzt, und Web/API-Konversationen werden pro Sitzung verschlüsselt – also Benutzerübergreifende Anfragen können nicht auf die Daten des jeweils anderen zugreifen.

HTTP / SSE API für einen TutorBot

Neue Endpunkte POST /{bot_id}/chat und /chat/execute-stream (SSE) mit Automatischer Start und persistenter Kontext pro Sitzung für Gespräche mit mehreren Runden mit einem bestimmten Bot von externen clients.

Multimodaler Bild-Fallback

Bilder werden optimistisch an jeden Anbieter verschickt; wenn eine Anfrage Bilder enthält fehlschlägt und das Modell nicht in der Zulassungsliste für bekannte Visionen enthalten ist, wird der Turn erneut versucht Nur Text. Behebt stillschweigend abgelegte Bilder auf Doubao / VolcEngine und anderen multimodale Modelle, denen ein Fähigkeitseintrag fehlt.

Sicherer ZIP-Upload + Netzwerkeinstellungen

.zip-Wissens-Uploads erweitern Mitglied für Mitglied durch den Dokumentenvalidator mit Größen-/Anzahl-/Komprimierungsverhältnis-Begrenzungen und Pfad-Flucht-Schutzvorrichtungen; die Das Archiv selbst wird niemals indiziert. Eine neue /settings/network-Seite zeigt Ports, öffentliche API-Basis und CORS-Ursprünge (normalisiert, um host:port und zu tolerieren). abschließende Schrägstriche) sowie eine Aktion „Modelle abrufen“, in der Modell-IDs von einem aufgelistet werden OpenAI-kompatibler Endpunkt.

Community-Korrekturen und -Änderungen

Sicherheit – TutorBot RCE über das Shell-Tool (#518) geschlossen, Pfaddurchquerung in das Dateisystem-Tool (#517), Cross-Bot-Dateiverwaltungs-Authentifizierungsumgehung (#516), Sitzungsübergreifende Turn-Regeneration-Authz-Umgehung (#515), Book-Confirmation-Authz Bypass (#514) und ExecTool führt LLM-Shell-Befehle über Chat aus (#506, erstmals gehärtet in PR #507). Fehlerbehebungen – Chat-Eingabe nach der ersten Runde deaktiviert (v1.4.0-Regression, #520), Fehler beim Einbetten der Wissensdatenbank bei langen Dokumenten (#521 / PR #509), Neue Benutzer können unter Docker (#512 / PR #513), Qwen, kein Profil erstellen Argumentationsmodelle, bei denen der native Tool-Aufruf fehlschlägt (#527 / PR #528), und das GPT-5 init-wizard-Token-Parameter (PR #508). Zusammengeführte/überarbeitete PRs – natives Tool, das Argumentationsmodelle aufruft (#528), Übergroßes Abschneiden von Sitzungsereignissen (#524), Profilschaltfläche für leeren Zustand (#513), Chunking-Pipeline-Fix (#509), GPT-5-Probe (#508), ExecTool-Härtung (#507). Beiträge Nr. 522 (Zip-Upload) und Nr. 523 (Modellabruf + Notebook-Suche) wurden lokal neu implementiert und hierher versendet. Funktionsanfrage – HTTP API für Multi-Turn-Chat mit einem bestimmten TutorBot (#511).

Upgrade-Hinweise

  • Drop-in von v1.4.0: pip install -U deeptutor; Docker-Benutzer ziehen ghcr.io/hkuds/deeptutor:latest.
  • TutorBot Shell Exec ist jetzt standardmäßig deaktiviert. Wenn Sie sich darauf verlassen haben, legen Sie fest allow_shell_exec auf dem Bot; Der Werkzeugzugriff bleibt auf den Arbeitsbereich beschränkt. – Legen Sie für die standortübergreifende HTTPS-Authentifizierung explizite CORS-Ursprünge und cookie_secure=true fest.

Was hat sich geändert?

  • Fix(Einstellungen): Profilschaltfläche hinzufügen, wenn keine Profile von @wedone in https://github.com/HKUDS/DeepTutor/pull/513 vorhanden sind
  • Korrigieren Sie den GPT-5-Token-Limit-Parameter im Init-Wizard-Probe von @lezhimiffyliu in https://github.com/HKUDS/DeepTutor/pull/508
  • Fix(Sicherheit): ExecTool-Standardeinstellungen gegen Befehlsinjektion (#506) durch @kagura-agent in https://github.com/HKUDS/DeepTutor/pull/507 härten
  • Fix: Verhindert, dass Dokumentknoten die Chunking-Pipeline von @washi4 in https://github.com/HKUDS/DeepTutor/pull/509 umgehen
  • Kunststück: Übergroße Ereignisnutzlasten in der Sitzungsantwort von @xiongjnu in https://github.com/HKUDS/DeepTutor/pull/524 abschneiden
  • fix(chat): Native Tool-Aufrufe für Argumentationsmodelle über OpenAI-kompatible Endpunkte von @wedone in https://github.com/HKUDS/DeepTutor/pull/528 aktivieren
