DeepTutor v1.7.2

DeepTutor v1.7.2 Release Notes

Veröffentlichungsdatum: 2026.11.06

Aufbauend auf v1.7.1 bietet v1.7.2 das Vorlesen ausgewählter Texte, eine einfachere Modelleinrichtung sowie zuverlässigeres geführtes Lernen, Abrufen und Aktualisierungen. Für Desktop-Versionen sind jetzt neben den beiden Windows-Downloads auch Installationsprogramme für Apple Silicon und Intel Mac erforderlich.

Was ist neu?

Vollständige Desktop-Downloads und stabilere Windows-Unterstützung

GitHub-Releases bieten Apple Silicon- und Intel-DMGs, ein Windows-Installationsprogramm und eine tragbare Windows-ZIP-Datei. Der Release-Workflow überprüft jede Plattform sowie alle versionierten Downloads und stabilen Aliase. Windows-Korrekturen umfassen Sitzungs- und Migrationssperren, Plugin-Umgebungen, die Erkennung ausführbarer Python-Dateien, Nicht-UTF-8-Ausgabe und Pfade, die Leerzeichen enthalten.

Lesen Sie nur die Passage, die Sie brauchen

Wählen Sie Text im Chat, Mastery Path oder Reading aus und wählen Sie Vorlesen, um ihn über Ihren konfigurierten Sprachanbieter anzuhören. Beim Vorlesen des Chats wird auch die Wiedergabegeschwindigkeit pro Konversation im aktuellen Browser gespeichert. Bei der Sprachwiedergabe werden maskierte Prozentzeichen und Gradnotationen natürlicher verarbeitet, und der Edge-Fallback von Video Lesson wählt eine Stimme aus, die zur Unterrichtssprache passt.

Einfachere Anbietereinrichtung und umfassendere Kompatibilität

Die Einstellungen erkennen verfügbare Modelle nach Änderungen an den Anmeldeinformationen und ermöglichen den gleichzeitigen Import mehrerer Modelle. Neue benutzerdefinierte Anbieter verwenden standardmäßig die automatische Protokollauswahl. NVIDIA NIM fügt Textabrufeinbettungen mit unterschiedlichen Abfrage- und Passagenrollen hinzu; Neuere DashScope-Bildmodelle verwenden ihr passendes Generierungsprotokoll, wobei 4K auf wan2.7-image-pro beschränkt ist. Antworten API-Toolargumente, strukturierte Ausgabe, wiedergegebener Verlauf und benutzerdefinierte Codex-Header erhalten Kompatibilitätskorrekturen.

Geführtes Lernen, das den Kontext behält

Wählen Sie ein Modell aus, bevor ein Mastery Path-Entwurf beginnt. Nachträgliche Klarstellungen und fehlende Teile werden mit der Erklärung, die sie ergänzen, bewertet, während veraltete Kartenantworten und doppelte Wiederholungsversuche sorgfältiger behandelt werden. Bei Nichtübereinstimmungen von Quelltexten wird ein begrenzter Wiederholungsversuch durchgeführt, und die Lernnavigation, das Scrollen im Forum und die Wiederherstellung des Lernspeichers sind zuverlässiger.

Zugänglichere Gespräche und Abrufmöglichkeiten

Koreanisch ist als teilweise Schnittstellenübersetzung verfügbar, mit englischem Ersatz für nicht übersetzten Text. Weitere Beschriftungen und Daten folgen der ausgewählten Oberflächensprache. Little Tutor-Threads werden in der Befehlspalette angezeigt, Dokumentleser werden bei Bedarf geladen und Socket-Fehler und -Abbrüche werden vorhersehbarer wiederhergestellt. BM25 behält gepunktete Bezeichner bei, die Dokumentenextraktion bleibt von der API-Ereignisschleife fern und Notebook- und Lieblingstools unterstützen den schreibgeschützten Datensatzabruf.

Sicherere Updates und begrenzte Argumentationswiederherstellung

Paketaktualisierungen behalten installierte Funktionsmodule auf der Zielkernversion bei und zeichnen Startfehler auf, anstatt beim Neustart hängen zu bleiben. Durch getrennte Starts werden veraltete Quellbaumimporte vermieden, und fehlgeschlagene CLI-App-Rollbacks bewahren Backups. Die Shared-Agent-Schleife kann anhalten oder einen explizit begrenzten Wiederholungsversuch mit höherem Budget durchführen, wenn die Argumentation das Ausgabebudget erschöpft, ohne dass eine sichtbare Antwort vorliegt.

Upgrade-Hinweise

  • Vollständige App: Stoppen Sie DeepTutor, sichern Sie die Laufzeit-Startseite und führen Sie dann python -m pip install --upgrade "deeptutor[full]==1.7.2" aus. Behalten Sie das gleiche DEEPTUTOR_HOME bei; Vor dem Neustart mit python -m pip check und deeptutor module list überprüfen. Alle Zusatzräder müssen ebenfalls zur Version 1.7.2 passen.
  • Legacy-Installationen: Upgrades von 1.6.15 oder früher müssen das Legacy-Paket deeptutor-cli deinstallieren, bevor die modulare Paketfamilie installiert wird. Befolgen Sie die Migrationsbefehle in v1.7.0.
  • Quelleninstallationen: Installieren Sie requirements/full.txt und dann python -m pip install -e . --no-deps. Stoppen Sie aktive Server und CLI-Turns, bevor Sie Module wechseln.
  • Docker: Ziehen Sie ghcr.io/hkuds/deeptutor:1.7.2 oder :latest und erstellen Sie den Container mit dem vorhandenen Datenvolumen neu.
  • Desktop: Verwenden Sie für diese GitHub-Version das passende Installationsprogramm oder die tragbare ZIP-Datei. Windows-Builds bleiben unsigniert. Die automatische Desktop-Update-Erkennung ist nicht verbunden. Die Shell unterstützt manuell bereitgestellte signierte Kernaktualisierungen.
  • NVIDIA NIM: Wählen Sie die Einbettungsbindung explizit aus und indizieren Sie eine vorhandene Wissensdatenbank neu, wenn Sie Einbettungsmodelle ändern. Diese Bindung unterstützt nur Text.
  • Wiederherstellung von Sprache und Argumentation: Für die Sprache ausgewählter Texte ist ein funktionierender konfigurierter TTS-Dienst erforderlich. Die Erhöhung des Wiederherstellungsausgabebudgets ist optional und kann die Latenz und Nutzung erhöhen; Das standardmäßige Wiederholungsbudget bleibt unverändert.
