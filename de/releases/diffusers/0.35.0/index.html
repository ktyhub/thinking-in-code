Diffusoren v0.35.0

Diese Version ist vollgepackt mit neuen Bildgenerierungs- und Bearbeitungspipelines, einer neuen Videopipeline, neuen Trainingsskripten, Verbesserungen der Lebensqualität und vielem mehr. Lesen Sie den Rest der release notes vollständig durch, um den Spaß nicht zu verpassen.

Neue Pipelines 🧨

Wir haben in dieser Version neue Pipelines begrüßt:

  • Wan 2.2
  • Flux-Kontext
  • Qwen-Image
  • Qwen-Bildbearbeitung

Wan 2.2 📹

Dieses Wan-Update bietet erhebliche Verbesserungen bei der Videotreue, der schnellen Adhärenz und dem Stil. Weitere Informationen finden Sie im offiziellen Dokument.

Flux-Kontext 🎇

Flux-Kontext ist ein gleichgerichteter Flusstransformator mit 12 Milliarden Parametern, der Bilder basierend auf Textanweisungen bearbeiten kann. Bitte schauen Sie sich das offizielle Dokument an, um mehr darüber zu erfahren.

Qwen-Bild 🌅

Nach einer erfolgreichen Serie der Bereitstellung von Sprachmodellen und Vision-Sprachmodellen ist das Qwen-Team mit einem Bildgenerierungsmodell zurück, das unter der Apache-2.0-Lizenz steht! Es erzielt erhebliche Fortschritte bei der Wiedergabe komplexer Texte und der präzisen Bildbearbeitung. Weitere Informationen zu diesem leistungsstarken Modell finden Sie in unseren Dokumenten. Vielen Dank an @naykun für den Beitrag von Qwen-Image und Qwen-Image-Edit über diese PR und diese PR.

Neue Trainingsskripte 🎛️

Machen Sie diese neu hinzugefügten Modelle mit unseren Trainingsskripten zu Ihren eigenen:

  • Kontexttrainer
  • Qwen-Image-Trainer

Implementierungen der Einzeldateimodellierung

Gemäß der 🤗 Transformers-Philosophie der Modellierungsimplementierungen in einer Datei haben wir mit der Implementierung von Modellierungscode in einzelnen und eigenständigen Dateien begonnen. Der Flusstransformator Code ist ein Beispiel hierfür.

Achtung Refaktor

Wir haben die Art und Weise, wie wir Aufmerksamkeit in den Modellen erzeugen, massiv überarbeitet. Dies ermöglicht uns die nahtlose Unterstützung verschiedener Aufmerksamkeits-Backends (z. B. PyTorch natives scaled_dot_product_attention, Flash Attention 3, SAGE Attention usw.) in der Bibliothek. Die auf diese Weise unterstützte Aufmerksamkeit ermöglicht es uns auch, verschiedene Parallelisierungsmechanismen zu integrieren, an denen wir aktiv arbeiten. Folgen Sie dieser PR, wenn Sie interessiert sind. Benutzer sollten von diesen Änderungen überhaupt nicht betroffen sein. Bitte öffnen Sie ein Problem, wenn Sie auf Probleme stoßen.

Regionale Zusammenstellung

Die regionale Kompilierung verkürzt die Kaltstartlatenz, indem nur die kleinen und häufig wiederholten Blöcke eines Modells kompiliert werden – typischerweise eine Transformatorschicht – und ermöglicht die Wiederverwendung kompilierter Artefakte für jedes nachfolgende Vorkommen. Bei vielen Diffusionsarchitekturen führt dies zu den gleichen Laufzeitbeschleunigungen wie die vollständige Diagrammkompilierung und reduziert die Kompilierungszeit um das 8- bis 10-fache. Weitere Informationen finden Sie in diesem Dokument. Vielen Dank an @anijain2305 für den Beitrag zu dieser Funktion in dieser PR. Wir haben auch eine Reihe von Beiträgen verfasst, die sich mit der Verwendung von torch.compile befassen. Sie können sie unter den folgenden Links nachlesen:

  • Flux schnell präsentieren: Flux auf H100 zum Erfolg bringen
  • torch.compile und Diffusoren: Ein praktischer Leitfaden für Spitzenleistungen
  • Schnelle LoRA-Inferenz für Flussmittel mit Diffusoren und PEFT

Schnelleres Laden der Pipeline ⚡️

Benutzer können Pipelines jetzt direkt auf ein Beschleunigergerät laden, was zu deutlich schnelleren Ladezeiten führt. Dies wird insbesondere beim Laden großer Pipelines wie Wan und Qwen-Image deutlich.

from diffusers import DiffusionPipeline
import torch 

ckpt_id = "Qwen/Qwen-Image"
pipe = DiffusionPipeline.from_pretrained(
-    ckpt_id, torch_dtype=torch.bfloat16
- ).to("cuda")
+    ckpt_id, torch_dtype=torch.bfloat16, device_map="cuda"
+ )

Sie können das Laden noch beschleunigen, indem Sie das parallele Laden von Status-Dikt-Shards aktivieren. Dies ist besonders hilfreich, wenn Sie mit großen Modellen wie Wan und Qwen-Image arbeiten, bei denen die Modellstatusbestimmungen normalerweise auf mehrere Dateien verteilt sind.

import os
os.environ["HF_ENABLE_PARALLEL_LOADING"] = "yes"

# rest of the loading code
....

Bessere GGUF-Integration

@Isotr0py hat in dieser PR zur Unterstützung für native GGUF-CUDA-Kernel beigetragen. Dies sollte zu einer Verbesserung der Inferenzgeschwindigkeit um etwa 10 % führen. Wir haben auch an einem Tool zur Konvertierung regulärer Kontrollpunkte in GGUF gearbeitet, damit die Community ihre GGUF-Kontrollpunkte einfach teilen kann. Erfahren Sie mehr hier. Wir unterstützen jetzt das Laden von GGUF-Prüfpunkten im Diffusor-Format. Mehr darüber erfahren Sie in unseren offiziellen GGUF-Dokumenten.

Modulare Diffusoren (experimentell)

Modular Diffusers ist ein System zum Bau von Diffusionspipelines mit einzelnen Pipelineblöcken. Es ist hochgradig anpassbar und verfügt über Blöcke, die gemischt und angepasst werden können, um sich an einen bestimmten Workflow oder mehrere Workflows anzupassen oder eine Pipeline für diesen zu erstellen.
Der API befindet sich derzeit in der aktiven Entwicklung und wird als experimentelle Funktion veröffentlicht. Erfahren Sie mehr in unseren Dokumenten.
