Meta Muse Glimmer

Muse Glimmer, das heute veröffentlicht wurde, ist Metas neues multimodales Modell, das speziell für Agenten-Anwendungsfälle entwickelt wurde. Von Muse auf 30B-Parameter destilliert und unter der Apache 2.0-Lizenz veröffentlicht, kann es in lokalen Setups für datenschutzbewusste Anwendungen wie Codierung, Dokumentenanalyse, persönliche Assistenten, Claw- oder Hermes-ähnliche Setups bereitgestellt werden.

Muse Glimmer ist ein dichtes 30B-Parametermodell, bestehend aus:

  • 2B ViT-Encoder für Vision (Perception Encoder)
  • 28B-Parameter-Textdecoder

Wir berichten darüber im folgenden Blogbeitrag: http://hf.co/blog/muse-glimmer

Breaking Changes

Für lineare Aufmerksamkeitsmodelle (Mamba, GDN, Conv-only usw.) sind Kernel jetzt optional und nicht mehr obligatorisch. Daher müssen Benutzer, die sich auf die automatische Kernelauswahl verlassen haben, Kernel explizit aktivieren, um das bisherige Verhalten beizubehalten.

  • 🚨 [Kernels] Refactoring aller linearen Attn-Modelle und nativer Kernel-Fallback (#47630) von @vasqu

Das Cache-Cropping API akzeptiert jetzt nur noch negative Werte (relative Offsets) statt absoluter Größen, daher müssen Benutzer, die Crop-Methoden direkt aufrufen, ihren Code aktualisieren, um entsprechend negative Werte zu übergeben.

  • 🚨 [cache] Zuschneiden kann nur mit negativen Werten (#47720) von @Cyrilvallez erfolgen

T5 und seine Modellfamilie (MT5, LongT5 usw.) unterstützen jetzt SDPA und andere Aufmerksamkeits-Backends über ALL_ATTENTION_FUNCTIONS, was bedeutet, dass sich die standardmäßige Aufmerksamkeitsimplementierung ändern kann und Benutzer, die auf den vorherigen Eager-Only-Pfad angewiesen sind, attn_implementation="eager" bei Bedarf explizit festlegen sollten.

  • 🚨 SDPA (und andere Aufmerksamkeits-Backends) für T5 aktivieren und an die T5-Familie weitergeben (#47014) von @jiqing-feng

Mehrere kleine private Hilfsfunktionen (z. B. _is_url, _build_image_tokens) wurden aus multimodalen Prozessordateien entfernt, daher müssen Benutzer oder Downstream-Bibliotheken, die diese privaten Funktionen direkt importiert haben, diese Verweise entfernen oder ersetzen.

  • :rotating_light: Prozessoren aktualisieren den Rest (#46556) von @zucchini-nlp

Achtung

Diese Version enthält mehrere Aufmerksamkeitskorrekturen und Verbesserungen, darunter die Korrektur der Multi-Head Latent Attention (MLA)-Cache-Komprimierung, die Optimierung der Berechnung der maximalen Sequenzlänge von Flash Attention in Vision-Modellen und die Behebung von Fehlern in CTRL Flex-Attention und SDPA Prefill mit Position Bias. Zusätzliche Änderungen überarbeiten lineare Aufmerksamkeitsmodelle für eine bessere Wartbarkeit, machen die heterogene Aufmerksamkeitskonfiguration von Gemma 4 explizit und verbessern die MPS-Unterstützung durch Metal-Flash-SDPA-Integration.
