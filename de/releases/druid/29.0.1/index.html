Druide Druide-29.0.1

Druide 29.0.1

Apache Druid 29.0.1 ist eine Patch-Version, die einige Probleme in der Druid 29.0.0-Version behebt.

Fehlerbehebungen

  • Typüberprüfung für INSERT und REPLACE hinzugefügt, um zu überprüfen, ob Strings und String-Arrays nicht gemischt sind #15920
  • Gleichzeitiges Ersetzen ermöglicht jetzt die Aktualisierung ausstehender Peon-Segmente mit dem Supervisor #15995
  • Das Attribut targetDataSource wurde geändert, um eine Zeichenfolge zurückzugeben, die den Namen der Datenquelle enthält. Dadurch wird die bahnbrechende Änderung rückgängig gemacht, die in Druid 29.0.0 für INSERT- und REPLACE-MSQ-Abfragen eingeführt wurde #16004 #16031
  • Die Größe des Verteilungsbildes Docker wurde verringert #15968
  • Es wurde ein Problem mit der SQL-basierten Erfassung behoben, bei dem Zeichenfolgeneingaben, z. B. aus CSV-, TSV- oder Zeichenfolgenwertfeldern in JSON, als Nullwerte erfasst werden, wenn sie als LONG oder BIGINT eingegeben werden #15999
  • Es wurde ein Problem behoben, bei dem eine von der Webkonsole generierte Kafka-Supervisor-Spezifikation flattenSpec an der falschen Stelle hat #15946
  • Es wurde ein Problem behoben, bei dem Filter für virtuelle Ausdrucksspaltenindizes in manchen Fällen fälschlicherweise Nullwerte für Ausdrücke berücksichtigten, die Nullwerte in Nicht-Nullwerte übersetzen #15959
  • Es wurde ein Problem behoben, bei dem der Datenlader abstürzte, wenn die eingehenden Daten nicht analysiert werden konnten #15983
  • Verbesserte Erkennung des Typs DOUBLE in der Webkonsole #15998
  • Von der Webkonsole generierte Abfragen setzen den Kontextparameter arrayIngestMode jetzt nur dann auf array, wenn Sie sich explizit für die Verwendung von Arrays entscheiden #15927
  • Die Webkonsole zeigt jetzt die Ergebnisse einer MSQ-Abfrage an, die über die Funktion EXTERN in ein externes Ziel schreibt #15969

Inkompatible Änderungen

Änderungen an targetDataSource in EXPLAIN-Abfragen

Druid 29.0.1 enthält eine bahnbrechende Änderung, die das Verhalten von targetDataSource auf seinen 28.0.0- und früheren Zustand zurücksetzt, anders als Druid 29.0.0 und nur 29.0.0. In 29.0.0 gibt targetDataSource ein JSON-Objekt zurück, das den Datenquellennamen enthält. In allen anderen Versionen gibt targetDataSource einen String zurück, der den Namen der Datenquelle enthält.

Wenn Sie ein Upgrade von einer anderen Version als 29.0.0 durchführen, ändert sich das Verhalten nicht.

Wenn Sie ein Upgrade von 29.0.0 durchführen, handelt es sich um eine inkompatible Änderung.

#16004

Abhängigkeitsaktualisierungen

  • Die JDBC-Treiberversion PostgreSQL wurde auf 42.7.2 [#15931] (https://github.com/apache/druid/pull/15931) aktualisiert.
