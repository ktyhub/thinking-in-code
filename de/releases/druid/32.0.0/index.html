Dienstgruppe als Dimension für die Metrik `coordinator.global.time` für den Statsd-Emitter hinzugefügt [#17320](https://github.com/apache/druid/pull/17320) – Die `service/heartbeat`-Metrik meldet Verwenden Sie diese Erweiterung für einfache Abfragen. Weitere Informationen finden Sie unter [gRPC-Abfrageerweiterung für Druid](https://github.com/apache/druid/tree/master/extensions-contrib/grpc-query). [#15982](https://github.com/apache/druid/pull/15982) #### <a name="32.0.0-functional-area-and-related-changes-extensions-kubernetes" href="#32.0.0-functional-area-and-related-changes-extensions-kubernetes">#</a> Kubernetes – Die Aufnahme ohne Middle Manger mit Kubernetes ist jetzt widerstandsfähiger gegenüber Overlord-Neustarts [#17446](https://github.com/apache/druid/pull/17446) – Sie können jetzt leere Arrays an Typ- und Datenquellenschlüssel in der Auswahlstrategie für selektorbasierte Pod-Vorlagen übergeben [#17400](https://github.com/apache/druid/pull/17400) – Der TaskRunner wurde verbessert, um das Feld `getMaximumCapacity` verfügbar zu machen [#17107](https://github.com/apache/druid/pull/17107) #### <a name="32.0.0-functional-area-and-related-changes-extensions-iceberg" href="#32.0.0-functional-area-and-related-changes-extensions-iceberg">#</a> Eisberg Die Iceberg-Erweiterung unterstützt jetzt den AWS Glue Iceberg-Katalog.
