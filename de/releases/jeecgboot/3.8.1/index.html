#JecgBoot v3.8.1

Upgrade-Protokoll

Einführung einer Reihe neuer Funktionen; Die Funktionen der KI-Anwendungsplattform sind stabil. unterstützt Electron-Desktopanwendungen; OpenAPI-Funktion basierend auf AK- und SK-Authentifizierung; Der Benutzerimport unterstützt den Import von Abteilungen und Rollen. Die Codegenerierung unterstützt zugehörige Datensatzsteuerelemente, JS-Erweiterungen und benutzerdefinierte Schaltflächen usw.

Neue Funktionen
  • [Großes Upgrade] Die Funktion des KI-Anwendungsmoduls wurde stabilisiert und hat Online-Standards erreicht.
  • [Neue Funktion] Unterstützt das Packen von Electron-Desktop-Anwendungen mit Vite+Vue3+Electron zum Erstellen von Client-Desktop-Anwendungen (unterstützt drei Hauptplattformen: Windows, Linux und macOS)
  • [Neue Funktion] „OpenAPI-Funktion basierend auf AK- und SK-Authentifizierung und Authentifizierung“ zur Lösung der Anforderungen externer API
  • [Neue Funktion] Der Benutzerimport unterstützt den Import von Abteilungen und Rollen
  • [Neue Funktion] Bietet eine Codegenerator-Vorlage für die neue Version von Uniapp
  • [Neue Funktionen] Die Codegenerierung unterstützt zugehörige Datensatzsteuerelemente, JS-Erweiterung und leere Methoden zur Generierung benutzerdefinierter Schaltflächen.
  • [AI] AI-Dialogfeld unterstützt mobile Endgeräte
  • [Optimierung] Unterstützt neue Version der DingTalk-Anmeldelogik
  • [Optimierung] Vereinfachte Nutzung von Multi-Tenant-Funktionen
  • [Neue Funktion] Stellen Sie AI OCR-Beispiele bereit
  • Meine Abteilungsverwaltung, die das Hinzufügen und Löschen von Unterabteilungen ermöglicht
  • Entfernen Sie den jsqlparse-Code und migrieren Sie ihn nach minidao. Das Upgrade ist nicht mehr von der jsqlparse-Kompatibilität betroffen.
  • [AI] Kompatibel mit jdk21, sodass das Programm gestartet werden kann, es wird jedoch angezeigt, dass die AI-Prozessorchestrierung nicht verwendet werden kann
  • [AI]-Prozess, die erforderlichen Felder in den Eingabeparametern werden nicht überprüft
  • [AI] Wenn der Prozess Mandantenfähigkeit ermöglicht, meldet der Schnittstellenaufruf, dass der Prozess nicht existiert.
  • [AI] Die Prozessschnittstelle, die den Prozess aufruft, wurde so geändert, dass keine Anmeldung erforderlich ist.
  • Aktualisieren Sie JVxetable auf die neue Version 4.13.31
  • Aktualisieren Sie jsqlparser auf 4.9
  • Berechtigungsanmerkungen für Funktionen im Zusammenhang mit KI-Anwendungen hinzugefügt
