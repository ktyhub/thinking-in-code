#JecgBoot v3.9.1

Veröffentlichungszeit: v3.9.1 | 28.01.2026

Upgrade-Protokoll

Dieses Upgrade erweitert die KI-Plattform umfassend, indem LangChain4j auf 1.9.1 aktualisiert wird und Inferenzmodelle, Multisitzungs- und Streaming-Anruffunktionen eingeführt werden. Das Qianwen-Modell unterstützt die Parameteranpassung und Netzwerksuche und fügt multimodale Funktionen wie KI-Malerei, vinzentinische Diagramme, grafische Diagramme und Postererstellung hinzu; KI-Anwendungen werden zu intelligenten Agenten aufgerüstet, die Speicher, Variablen, Plug-Ins, Prozesse und MCP unterstützen; Zu den Prozessfunktionen gehören neue Knoten wie Variablen, Schleifen, SQL, Timing und das Schreiben von Wissensdatenbanken. AI Chat unterstützt das Hochladen von Dateien und Chat2BI generiert Diagramme. Und brachte eine KI-Toolbox auf den Markt, die KI-Poster, KI-Lebensläufe, KI-Schreiben, KI-Zeichnungen und andere Szenarien umfasst;

AI-Plattform-Upgrade-Protokoll
Kern-Upgrade
  • LangChain4j auf 1.9.1 aktualisiert
  • MCP unterstützt die Befehlstypen http und STDIO
  • Unterstützung des Inferenzmodells, Deep Thinking ist standardmäßig nicht aktiviert -Unterstützt die Streaming-Anrufschnittstelle
  • Unterstützt den Multisitzungsmodus
  • Unterstützt das Parsen von Dateien
Große Modelle und Multimodalität
  • Das Qianwen-Modell unterstützt Parameteranpassung und Online-Suche
  • Unterstützt das AI-Bildmodell (Qianwen/OpenAPI)
  • Unterstützt Wensheng-Bilder und Tusheng-Bilder
  • Unterstützung für Claude, VL-Modell, Qianfan-Großmodell und Tongyi Qianwen hinzugefügt
KI-Anwendung
  • KI-Anwendungsportal hinzugefügt
  • Eingabeaufforderungswortverwaltung hinzugefügt
  • KI-Anwendungen werden zu intelligenten Agenten aufgewertet
  • KI-Anwendungen unterstützen Speicher, Variablen, Plug-Ins, Prozesse, MCP und Malerei
  • KI-Anwendung unterstützt Karteninhalte
KI-Prozess
  • Neue Knoten: Variablenextraktionsknoten, Variablenaggregationsknoten, N8N-Schleifenknoten, zeitgesteuerter Trigger, SQL-Knoten, Wissensdatenbank-Schreibknoten
  • Unterstützung der Prozessreplikation
  • Prozesse können direkt von Anwendungen aufgerufen werden
KI-Chat und BI
  • AI-Chat unterstützt das Hochladen von Dateien und das Parsen von Inhalten
  • Chat2BI unterstützt KI-Chat-Generierungsdiagramme -Unterstützt die Anzeige der MCP-Tool-Aufrufergebnisse
  • Unterstützen Sie eine Inhaltsantwort im Kartenstil
Chat2BI（[AI-generiertes Diagramm](https://help.jeecg.com/aigc/Chat2BI „Ai-generiertes Diagramm“))
  • Unterstützt eine Vielzahl von Diagrammtypen, darunter Balkendiagramme, Liniendiagramme, Kreisdiagramme, mehrspaltige Balkendiagramme, mehrzeilige Liniendiagramme, gefaltete Säulendiagramme, Flächendiagramme, Netzdiagramme und Dashboards.
  • Unterstützt die Abfrage mehrerer Datenquellen. Für die Diagrammabfrage können alle im System konfigurierten Datenquellen verwendet werden. Wenn keine Datenquelle angegeben ist, wird standardmäßig die Systemdatenbank verwendet.
  • Unterstützt Abfragen in natürlicher Sprache. Benutzer können Abfrageanforderungen in natürlicher Sprache eingeben und der Agent analysiert und generiert automatisch entsprechende Diagramme.
  • Unterstützt die Generierung von Diagrammen aus bekannten Daten, Benutzer können Daten direkt eingeben und der Agent generiert auf der Grundlage der Daten entsprechende Diagramme.
KI-Toolbox
  • KI-Lebenslaufgenerierung (Zeile Word)
  • AI-Produktsuchassistent
  • KI-Malerei und KI-Postergenerierung hinzugefügt
  • KI-Schreiben
  • OCR-Erkennung
Neue Anwendungsszenariofälle hinzufügen
  • Schauen Sie sich Bilder an und sprechen Sie über die Anwendung
  • Produktsuch- und Antwortanwendung
  • Hilf mir zu schreiben
  • Bilderkennung

  • Aktualisierter Bausteinbericht auf v2.3.0
