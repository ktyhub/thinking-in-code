#JecgBoot v3.7.4

Veröffentlichungszeit: v3.7.4 | 07.04.2025

Upgrade-Protokoll

Die Hintergrundarchitektur wurde einer umfassenden Aktualisierung unterzogen; das Standard-JDK wurde auf 17 geändert; Das Online-Low-Code-Modul wurde speziell aktualisiert. Knife4j hat das SpringDoc von openapi3 aktualisiert ([Upgrade ist nicht kompatibel, überprüfen Sie die Anmerkungsänderungen](https://help.jeecg.com/java/upgrade/springboot3#knife4j%E5%8D%87%E7%BA%A7%E8%AF%B4%E6%98%8E „Dieses Upgrade ist nicht kompatibel, Anmerkungsänderungsmethode“));

Inhalt aktualisieren
  • Aktualisieren Sie fastjson auf 2.0.43
  • Aktualisieren Sie JDK17 (unterstützt JDK8, JDK21)
  • Knife4j aktualisiert Springdoc von openapi3
  • Rüsten Sie Tomcat auf Sog auf
  • Aktualisieren Sie junit5
  • Aktualisieren Sie Spring-Cloud auf 2021.0.8
  • Aktualisieren Sie spring-cloud-alibaba auf 2021.0.6.2
  • Aktualisieren Sie jimureport auf die neueste Version 1.9.5
  • Aktualisieren Sie das Online-Entwicklungsmodul auf den neuesten Stand
  • Legen Sie die Standard-Cache-Gültigkeitsdauer der statischen Ressourcen Cache-Control fest
  • Aktualisieren Sie die Version jeewx-api auf weixin4j 2.0.1
  • Aktualisieren Sie Shiro auf 1.13.0 und Shiro-redis auf 3.2.3
  • Aktualisieren Sie die Druidenversion auf 1.2.24
  • Aktualisieren Sie logback.version auf 1.2.13, um die Schwachstelle zu beheben
  • Aktualisieren Sie Java-JWT auf 4.5.0
