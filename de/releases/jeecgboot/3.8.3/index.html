#JecgBoot v3.8.3

Quellcode-Download

  • Gitee-Adresse: https://gitee.com/jeecg/JeecgBoot

Upgrade-Protokoll

Diese Version wurde im Hinblick auf die Organisationsstruktur und die Jobebenen tiefgreifend umgestaltet, unterstützt Tochterstrukturen, Jobvorgesetzte und -untergebene sowie Einstellungen auf Jobebene, optimiert die Personalpflege in der Abteilung und die Haupt- und Teilzeitstellenverwaltung der Benutzer und verbessert die Flexibilität und Klarheit des Organisationsmanagements. Gleichzeitig ermöglicht die Homepage-Konfiguration eine mehrdimensionale personalisierte Anpassung, die Mieterverwaltung ist einfacher zu bedienen und das Paketkonzept ist klarer.

  • In Bezug auf die zugrunde liegende Architektur aktualisieren Sie auf Spring Boot 3.5.5, Spring Cloud 2025.0.0, Spring Cloud Alibaba 2023.0.3.3, wechseln Sie zurück zum Tomcat-Container, optimieren Sie die Startgeschwindigkeit und unterstützen Sie verzögertes Laden. Die Codegenerierung unterstützt separate Pfadkonfigurationen für das Front- und Back-End, und Menü-SQL wird automatisch mit dem Flyway-Verzeichnis synchronisiert, um die Entwicklungseffizienz zu verbessern. – Darüber hinaus behebt diese Version eine große Anzahl wichtiger Probleme in Front-End-Komponenten und Back-End-Funktionen, verbessert die Unterstützung verteilter Transaktionen, aktualisiert Datenbanktreiber und verbessert die Systemstabilität und -leistung. KI-Anwendungen und Low-Code-Plattformfunktionen wurden ebenfalls verbessert und bieten Benutzern ein reibungsloseres und intelligenteres Erlebnis.
  • Besondere Erinnerung: Der Standard-Trunk wird auf Spring Boot 3 umgestellt, wodurch das Java 21-Ökosystem vollständig berücksichtigt und die Systemleistung und -sicherheit verbessert wird. v3.8.3 wird die letzte Version von Spring Boot 2 sein. In Zukunft wird nur noch Version Spring Boot 3 veröffentlicht. Version Spring Boot 2 wird nicht mehr aktualisiert und gewartet. Benutzern wird empfohlen, sich im Voraus auf das Upgrade vorzubereiten.
Große organisatorische Veränderungen
    1. Wesentliche Umstrukturierung der Organisationsstruktur, klarere Aufteilung der unterstützenden Tochtergesellschaften, Positionen und Abteilungsfunktionen (Personalpflegefunktion auf der rechten Seite der Abteilung hinzugefügt)
    1. Positionen unterstützen die Festlegung von „Postenvorgesetzten und Untergebenen“ und die Festlegung von „Rängen“; Es wird eine neue Rangberichtsbeziehung hinzugefügt
    1. Positionsumwandlung, die ursprüngliche Personalbesetzungsfunktion „Position“ wird ungültig und in „Positionierungsebene der Abteilungsposition“ geändert.
    1. Nutzer unterstützen die Einrichtung von Hauptstellen und Teilzeitstellen
    1. Eine umfassende Überarbeitung der Homepage-Konfiguration, die die mehrdimensionale Einstellung personalisierter Homepages durch Rollen und Benutzer unterstützt.
    1. Große Renovierung für Mieter, um die Nutzung zu erleichtern (das Paketkonzept ist klarer)
    1. Erstellen Sie ein neues Paket und fügen Sie das Attribut „Benutzer automatisch zuweisen. Wenn ja, werden neue Benutzer und Anforderungsbenutzer standardmäßig mit dem Paket verknüpft.“
    1. Fügen Sie unter „Meine Mieter“ die Menüs „Mieterposition“ und „Mieterabteilung“ hinzu.
    1. Unter „Meine Mieter“ wird „Meine Mieter“ in eine Anzeigeseite geändert
Große Veränderungen

  • Optimieren Sie die Startgeschwindigkeit im Hintergrund und unterstützen Sie den verzögerten Ladestart durch verzögerte Initialisierung (lösen Sie das Problem großer Projekte und langsamen Starts).
  • Stellen Sie ein Prüfskript für die JeecgBoot-Betriebsumgebung python bereit
  • Aktualisieren Sie den Springboot3-Zweig, Spring-Boot auf 3.5.5, Spring-Cloud auf 2025.0.0, Spring-Cloud-Alibaba auf 2023.0.3.3
  • Springboot3-Version, unterstützt jdk17, jdk21, jdk24
  • Der Front-End-Code für die Codegenerierung unterstützt die direkte Generierung im Front-End-Projekt, und die Menü-SQL wird automatisch im Flyway-Verzeichnis des Startprojekts generiert. – Die Codegenerierung kann mit zwei Pfaden konfiguriert werden, die dem Front-End und dem Back-End entsprechen · Problem Nr. 7197
