AutoGPT autogpt-platform-beta-v0.7.4

🔥 Was ist neu?

Neue Funktionen

  • #14215 – Integrationen pro Expert erfassen und in der Benutzeroberfläche anzeigen (von @0ubbe)
  • #14216 – Surface-Agent-Arbeit auf der Homepage über ein Aktivitätsereignisprotokoll (von @0ubbe)
  • #14078 – Lassen Sie einen Benutzer die Verbindung auswählen, mit der jeder neue Chat beginnt (von @ntindle)
  • #14081 – Zeigt an, unter welchem ChatGPT-Konto eine Verbindung ausgeführt wird (von @ntindle)
  • #14082 – Beschreiben Sie eine KI-Verbindung auf dem Server, die sie erzwingt (von @ntindle)
  • #14086 – Zeigt die ChatGPT-Verbindung an, die ein Plan ausschließt, gesperrt (von @ntindle)
  • #14103 – Anbieterfehler auf der Engine melden, die tatsächlich ausgeführt wird (von @ntindle)
  • #14120 – Beschreiben Sie die Integrationsseite als das, was sie jetzt enthält (von @ntindle)
  • #14150 – Lassen Sie einen Chat woanders weitergehen, wenn ein Plan abläuft (von @ntindle)
  • #14024 – Erhöhen Sie das Limit der Fertigkeitsbeschreibung auf 1.024 Zeichen (von @Torantulino)
  • #14231 – Ratenbegrenzung pro Benutzer für den Abonnementstatus-Endpunkt hinzufügen (von @Bentlybro)
  • #14297 – Installieren Sie Ihre eigenen Bibliotheksagenten als Experten-Workflows (von @Pwuts)
  • #13634 – GitHub-Benachrichtigungsverwaltungsblöcke hinzufügen (von @Pwuts)

Verbesserungen

  • #14239 – Minimale Neugestaltung des Copiloten-Chats im GPT-Stil (von @0ubbe)
  • #14304 – Copilot Chrome aufräumen und aktuelle Workflow-Ausführungen in das Home-Briefing verschieben (von @0ubbe)
  • #14195 – Führen Sie Codex über HTTP aus und löschen Sie das 391 MB große Paket CLI (von @ntindle)
  • #14229 – Redundante Suchvorgänge für aktive Abonnements auf dem Abrechnungsstatus-Endpunkt zwischenspeichern (von @Bentlybro)
  • #14295 – Vollständiges PR-Objekt von GithubReadPullRequestBlock ausgeben (von @Pwuts)

UI/UX-Verbesserungen

  • #14250 – Stoppt das Flackern der Chat-Composer-Höhe und das Blinken der Platzhalter bei leerer Sitzung (von @Otto-AGPT)
  • #14270 – Stoppen Sie das Flackern des Composers zwischen seinen Zeilen- und gestapelten Layouts (von @0ubbe)

Fehlerbehebungen

  • #14163 – Claude Code-Systemaufforderung deaktivieren (von @Torantulino)
  • #14223 – Verhindern Sie nicht authentifizierte Kredit-/Abonnement-API-Aufrufe (von @ntindle)
  • #14232 – Wallet-Timer bereinigen (von @Torantulino)
  • #14259 – Asynchrone Redis clients schleifensicher machen (von @ntindle)
  • #14262 – Block-Docs-Generator stoppt das Überschreiben von Prosa bei einer Umbenennung (von @Pwuts)
  • #14267 – Pytest-Async-Loop-Bereich ausrichten (von @ntindle)
  • #14097 – Copilot-Bot-Bereitstellung und escaping-Korrekturen für alle Adapter (von @Bentlybro)
  • #14168 – Korrektur des selbstreferenzierenden Pfadfilters nach der Workflow-Umbenennung (von @DanielSwift1992)
  • #14258 – AllQuiet zu den CamelCase-Suchausnahmen hinzufügen (von @Otto-AGPT)
  • #14308 – Entfernen Sie den Morgenbesprechungs-Cron, wenn das Feature-Flag deaktiviert ist (von @Pwuts)
  • #14316 – Sorgen Sie dafür, dass das Ausfüllen einer Connect-Karte tatsächlich eine Verbindung herstellt (von @Pwuts)

Dokumentation

  • #14214 – Blockdokumente neu generieren, um Check-Docs-Sync-Drift auf dem Entwickler zu beheben (von @Pwuts)
  • #14217 – Ungültigen Git-Clone-Befehl in README beheben (von @odenta-747)
  • #14276 – PR-Test-Skill für bessere Authentifizierung, Umgebungseinrichtung und Abrechnungstest-Falle aktualisieren (von @Pwuts)

Abhängigkeiten und Wartung

  • #14225 – Master wieder mit Dev zusammenführen (von @ntindle)
  • #14245 – Aktionen/Download-Artefakt von 8.0.0 auf 8.0.1 in der Gruppe „Produktionsabhängigkeiten“ verschieben (von @dependabot[bot])
  • #14269 – Knip hinzufügen, um ungenutzte Dateien, Exporte und Abhängigkeiten zu finden (von @0ubbe)

Refactoring

  • #14083 – Entfernen Sie den Schnell-/Denkmodus, die Steuerung und die Installation (von @ntindle)
