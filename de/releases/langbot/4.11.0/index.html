#LangBot v4.11.0

LangBot ist eine Open-Source-KI-Chatbot- und Agentenplattform, die mehrere Instant-Messaging-Plattformen, große Sprachmodelle, Wissensdatenbanken und Plug-ins unterstützt, um Sie bei der Erstellung, Bereitstellung und Verwaltung von KI-Assistenten zu unterstützen. LangBot ist eine Open-Source-KI-Chatbot- und Agentenplattform, die Messaging-Plattformen, große Sprachmodelle, Wissensdatenbanken und Plugins verbindet, um Sie bei der Erstellung, Bereitstellung und Verwaltung von KI-Assistenten zu unterstützen.

🚀 Hauptfunktionen / Schlüsselaktualisierungen

LangBot 4.11 bringt ein bedeutendes Architektur-Upgrade mit sich: Der Roboter kann auf Plattformereignisse reagieren, der Agent Runner wird auf Plug-in umgestellt und die WebUI fügt einen neuen Arbeitsbereichsassistenten hinzu. LangBot 4.11 bringt ein großes Architektur-Update: Bots können auf Plattformereignisse reagieren, Agent-Runner sind jetzt Plugins und die WebUI fügt einen Workspace-Assistenten hinzu.

⚡ Event-Based Agents (EBA) – Verfasst von @RockChinQ @huanghuoguoguo @wangcham @dadachann

Neben Nachrichten können nun auch Plattformereignisse wie Gruppenbeitritt, Gruppenaustritt, Rückzug, Emoticon-Antwort, Kartenklick usw. ausgelöst und verarbeitet werden. 13 Plattformadapter wurden auf Basis der EBA-Architektur neu geschrieben und können Ereignisse im „Event Routing“ an Pipeline-, Agent- oder Plug-in-Prozessoren verteilen. Über Nachrichten hinaus können jetzt Plattformereignisse wie Beitritte, Austritte, Rückrufe, Reaktionen und Karten-clicks eine Verarbeitung auslösen. 13 Adapter wurden auf EBA neu erstellt und Event Routing leitet jedes Ereignis an eine Pipeline, einen Agenten oder einen Plugin-Prozessor weiter.

<img width="1058" height="1002" alt="Event Routing" src="https://github.com/langbot-app/LangBot/releases/download/v4.11.0/eba-event-routing.png" /> <img width="1442" height="864" alt="Ereignisprozessor erstellen" src="https://github.com/langbot-app/LangBot/releases/download/v4.11.0/eba-create-processor.png" />
  • Szenario-Routen: Erstellen Sie Routen aus gängigen Szenarien wie der Begrüßung neuer Mitglieder, der Abwicklung von Mitgliederabgängen usw. / Erstellen Sie Routen aus gängigen Szenarien wie der Begrüßung neuer Mitglieder
  • Drei Prozessortypen: Pipelines, Agenten und Plugin-Ereignisprozessoren können kombiniert werden
  • Ereignis-Debugger: Bearbeiten Sie Ereignisnutzlasten in einem Formular und überprüfen Sie Ausführungsprotokolle und Details
  • Plattform-Upgrades: Slack Socket-Modus, DingTalk-Karteninteraktionen, WeChat-Tippanzeige, OneBot WebSocket und mehr

🧩 AgentRunner Pluginized / Pluginized AgentRunner – Verfasst von @huanghuoguoguo @RockChinQ @fdc310

Integrierte Runner wie LocalAgent, Dify, Coze und n8n wurden aus dem Hauptprogramm entfernt und durch offizielle Plug-ins im Erweiterungsmarkt ersetzt, und Runner wie Codex, Claude Code und ACP wurden hinzugefügt. Der Runner kann unabhängig aktualisiert und bei Bedarf installiert werden, und Entwickler können auch ihren eigenen Runner basierend auf AgentRunner Protocol v1 schreiben. Integrierte Runner wie LocalAgent, Dify, Coze und n8n sind neben neuen Runnern wie Codex, Claude Code und ACP aus dem Kern in offizielle Marketplace-Plugins verlagert. Runner werden unabhängig aktualisiert und bei Bedarf installiert, und Entwickler können ihre eigenen auf AgentRunner Protocol v1 schreiben.

<img width="1418" height="1124" alt="AgentRunner-Plugins im Marketplace" src="https://github.com/langbot-app/LangBot/releases/download/v4.11.0/runner-plugins-marketplace.png" />
  • One-Click-Migration/One-click-Migration: Installiert die erforderlichen Plugins automatisch und sichert Ihre Konfiguration
  • Bereichsautorisierung: Läufer erreichen nur Tools und Plattform-APIs, die für den aktuellen Kontext API autorisiert sind. / Runners erreichen nur Tools und Plattform-APIs, die für den aktuellen Kontext autorisiert sind
  • Plugin-Zertifizierung: Der erweiterte Markt zeigt Zertifizierungsabzeichen an und das Hauptprogramm überprüft die Plug-in-Signatur. Zertifizierungsabzeichen im Marketplace und Signaturüberprüfung im Kern

🤖 Workspace Assistant / Workspace Assistant – Verfasst von @huanghuoguoguo @RockChinQ @dadachann

WebUI hat einen neuen Arbeitsbereichsassistenten hinzugefügt, der über Dialoge Ressourcen abfragen, Pipelines und Wissensdatenbanken erstellen und konfigurieren kann und alle Schreibvorgänge vor der Ausführung bestätigt werden müssen. Die WebUI fügt einen Workspace-Assistenten hinzu, der Ressourcen überprüft und Pipelines und Wissensdatenbanken per Chat einrichtet; Jeder Schreibvorgang wird erst nach Bestätigung ausgeführt.
