Containerd v2.0.14

Willkommen zur v2.0.14-Version von Containerd!

Die vierzehnte Patch-Version für Containerd 2.0 enthält verschiedene Korrekturen und Updates einschließlich eines Sicherheitspatches.

Sicherheitsupdates

  • Container
    • GHSA-hc94-p972-ch66

Highlights

Container Runtime Interface (CRI)

  • Härtung anwenden, um Symlinks für Container-Protokolldateien nicht zu folgen (#14299)

Laufzeit

  • Härtung auf Zulassungs-Socket-Domänen im standardmäßigen Seccomp-Profil anwenden (#14251)

Schnappschüsse

  • Härtung anwenden, um beim Entpacken ID-Mapping-Beschriftungen aus Bildanmerkungen zu filtern (#14270)

Bitte probieren Sie die Release-Binärdateien aus und melden Sie etwaige Probleme unter https://github.com/containerd/containerd/issues.

Abhängigkeitsänderungen

Diese Version weist keine Abhängigkeitsänderungen auf

Die vorherige Version finden Sie unter v2.0.13

Welche Datei soll ich herunterladen?

  • containerd-<VERSION>-<OS>-<ARCH>.tar.gz: ✅Empfohlen. Dynamisch verknüpft mit glibc 2.31 (Ubuntu 20.04).
  • containerd-static-<VERSION>-<OS>-<ARCH>.tar.gz: Statisch verknüpft. Wird voraussichtlich auf nicht-glibc-Linux-Distributionen verwendet. Nicht ortsunabhängig.

Zusätzlich zu Containerd müssen Sie normalerweise runc installieren. und CNI-Plugins auch von ihren offiziellen Websites.

Siehe auch die Dokumentation Erste Schritte.
