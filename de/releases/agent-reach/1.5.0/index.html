#Agent-Reach v1.5.0

Was ist diese Version?

Agent Reach wurde von „Tool Collection“ auf „Capability Layer“ aktualisiert: Jede Plattform = bevorzugte + alternative, geordnete Backend-Liste. Die aktuell stabilste Zugriffsmethode wird für Sie ausgewählt, installiert und durch tatsächliche Tests überprüft – Sie müssen sich keine Gedanken über den Austausch von Zugriffsmethoden machen. Alle Auswahlen in dieser Version basieren auf realen Maschinentests im Zeitraum 2026–06 (32 End-to-End-Tests).

Änderungen am Plattform-Routing

| Plattform | Die aktuelle Straße | |------|---------| | Xiaohongshu | OpenCLI (Desktop, Browser-Anmeldestatus ohne Konfiguration wiederverwenden) ▸ xiaohongshu-mcp (Server, Code scannen) ▸ xhs-cli (auf Lager verfügbar, Upstream wurde gestoppt) | | Reddit | OpenCLI ▸ rdt-cli. Ehrliches Kaliber: Reddit hat keinen Null-Konfigurationspfad (die anonyme Schnittstelle wurde vollständig blockiert und das offizielle API-Genehmigungssystem ist erforderlich), und Sie müssen sich anmelden | | Station B | bili-cli (Suchen/Beliebt/Details, keine Anmeldung erforderlich) ▸ OpenCLI (Untertitel) ▸ Suchen Sie nach API, um es herauszufinden. yt-dlp hat Site B verlassen (vollständig von der 412-Risikokontrolle abgefangen, die neueste getestete Version + Proxy + Cookie sind ungültig); yt-dlp stellt weiterhin YouTube | zur Verfügung | Twitter | twitter-cli Gatekeeper (stabil in der tatsächlichen Messung)▸ OpenCLI-Alternative, Erkennung und Wiederholung |

##Arzt ist zu einer echten körperlichen Untersuchung geworden

  • Führen Sie die Befehlserkennung tatsächlich aus, anstatt nur auf die Dateiexistenz zu achten. Sie kann „installiert, aber defekt“ identifizieren (typisch: Venv-Link ist nach System-Python-Upgrade defekt) und stellt Neuinstallationsanweisungen bereit, die direkt kopiert werden können
  • Melden Sie, welcher Pfad derzeit von jeder Multi-Backend-Plattform verwendet wird (doctor --json's active_backend)
  • Der Zusammenbruch eines Kanals führt nicht mehr zum Abbruch der gesamten körperlichen Untersuchung.

Storage OpenCLI (Desktop-Backend)

agent-reach install --channels opencli: npm wird automatisch installiert. Klicken Sie einmal auf den Chrome-Erweiterungsspeicher (Chrome-Sicherheitsmodell, kann nicht im Namen von angeklickt werden). Verwenden Sie den Anmeldestatus Ihres Browsers erneut – Sie können ihn direkt nach dem Durchsuchen von Xiaohongshu oder dem Anmelden bei Reddit verwenden. Erfordert Desktop + Chrome, Server wird automatisch übersprungen.

Installations- und Update-Erfahrung

  • Installation in einem Satz: 帮我安装 Agent Reach：https://raw.githubusercontent.com/Panniantong/agent-reach/main/docs/install.md
  • Aktualisieren Sie einen Satz: 帮我更新 Agent Reach：https://raw.githubusercontent.com/Panniantong/agent-reach/main/docs/update.md (Ontologie + Upstream-Tools + Fähigkeiten, um sofort aufzuholen)
  • Skill-Rewrite: „Netzwerkweite Recherche“ und „Hilf mir bei der Recherche“ werden zuverlässig ausgelöst; Nachdem der Agent eine große Aufgabe erledigt hat, überprüft er die Version. Wenn es eine neue Version gibt, wird er am Ende eine Erinnerung geben (keine Unterbrechung, kein wiederholtes Nörgeln)
  • check-update-Fix: Es wird nicht mehr fälschlicherweise zum „Aktualisieren“ aufgefordert, wenn die lokale Version älter als die neueste Version ist (um ein Downgrade zu vermeiden).

Qualität

  • Test 107 → 162 (Vollständige Abdeckung des Szenarios „Vertrag/gebrochener Link/Backend-Prioritätsmatrix/Versionsvergleich)“ – Nach drei Runden der kontradiktorischen Überprüfung (alle 12 Ergebnisse wurden behoben): Probleme wie die Blockierung des Twitter-Routings, Aufforderungen zum Herunterstufen von Uhren, deaktivierte Proxy-Switches usw., die den Benutzern wirklich schaden würden, wurden behoben.
  • Alle 32 End-to-End-Realmaschinentests über 13 Kanäle bestanden

Danksagungen

Neu aufgenommene Upstreams: OpenCLI(@jackwener), xiaohongshu-mcp(@xpzouying).
