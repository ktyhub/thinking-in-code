Firecrawl v2.0.0

Wir stellen vor: v2.0.0

Wichtige Verbesserungen

  • Standardmäßig schneller: Anfragen werden zwischengespeichert, wobei maxAge standardmäßig auf 2 Tage eingestellt ist und sinnvolle Standardeinstellungen wie blockAds, skipTlsVerification und removeBase64Images aktiviert sind.

  • Neues Zusammenfassungsformat: Sie können jetzt "summary" als Format angeben, um direkt eine prägnante Zusammenfassung des Seiteninhalts zu erhalten.

  • Aktualisierte JSON-Extraktion: JSON-Extraktion und Änderungsverfolgung verwenden jetzt ein Objektformat: { type: "json", prompt, schema }. Das alte "extract"-Format wurde in "json" umbenannt.

  • Erweiterte Screenshot-Optionen: Verwenden Sie die Objektform: { type: "screenshot", fullPage, quality, viewport }.

  • Neue Suchquellen: Durchsuchen Sie zusätzlich zu Webergebnissen auch "news" und "images", indem Sie den Parameter sources festlegen.

  • Intelligentes Crawlen mit Eingabeaufforderungen: Übergeben Sie ein prompt in natürlicher Sprache zum Crawlen und das System leitet Pfade/Limits automatisch ab. Verwenden Sie den neuen Endpunkt crawl-params-preview, um die abgeleiteten Optionen zu überprüfen, bevor Sie einen Job starten.

Checkliste für die schnelle Migration

  • Ersetzen Sie die Verwendung von v1 client durch v2 clients:
    • JS: const firecrawl = new Firecrawl({ apiKey: 'fc-YOUR-API-KEY' })
    • Python: firecrawl = Firecrawl(api_key='fc-YOUR-API-KEY')
    • API: Verwenden Sie die neuen https://api.firecrawl.dev/v2/-Endpunkte.
  • Update-Formate:
    • Verwenden Sie bei Bedarf "summary"
    • JSON-Modus: Verwenden Sie { type: "json", prompt, schema } für die JSON-Extraktion
    • Screenshot und Screenshot@fullPage: Verwenden Sie beim Festlegen von Optionen das Screenshot-Objektformat
  • Übernehmen Sie standardisierte asynchrone Abläufe in den SDKs:
    • Crawls: startCrawl + getCrawlStatus (oder crawl Kellner)
    • Charge: startBatchScrape + getBatchScrapeStatus (oder batchScrape Kellner)
    • Auszug: startExtract + getExtractStatus (oder extract Kellner)
  • Zuordnung der Crawl-Optionen (siehe unten)
  • Überprüfen Sie Crawl prompt mit crawl-params-preview

Formate und Scrape-Optionen

  • Verwenden Sie für die Grundlagen Zeichenfolgeformate: "markdown", "html", "rawHtml", "links", "summary".
  • Anstelle von parsePDF verwenden Sie parsers: [ { "type": "pdf" } | "pdf" ].
  • Verwenden Sie Objektformate für JSON, Änderungsverfolgung und Screenshots:

JSON-Format

 curl -X POST https://api.firecrawl.dev/v2/scrape \
     -H 'Content-Type: application/json' \
     -H 'Authorization: Bearer YOUR_API_KEY' \
     -d '{
       "url": "https://docs.firecrawl.dev/",
       "formats": [{
         "type": "json",
         "prompt": "Extract the company mission from the page."
       }]
     }'

Screenshot-Format

  curl -X POST https://api.firecrawl.dev/v2/scrape \
      -H 'Content-Type: application/json' \
      -H 'Authorization: Bearer YOUR_API_KEY' \
      -d '{
        "url": "https://docs.firecrawl.dev/",
        "formats": [{
          "type": "screenshot",
          "fullPage": true,
          "quality": 80,
          "viewport": { "width": 1280, "height": 800 }
        }]
      }'

Zuordnung der Crawl-Optionen (v1 → v2)

| v1 | v2 | | ----------------------- | ---------------------------------------------------- | | allowBackwardCrawling | (entfernt) verwenden Sie crawlEntireDomain | | maxDepth | (entfernt) verwenden Sie maxDiscoveryDepth | | ignoreSitemap (bool) | sitemap (z. B. "only", "skip" oder "include") | | (keine) | prompt |
