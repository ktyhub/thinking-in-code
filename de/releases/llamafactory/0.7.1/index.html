LlamaFactory v0.7.1

Patch Veröffentlicht15. Mai 2024 Quellehiyouga/LlamaFactory Englisches Original

Diese Seite ist maschinell übersetzt. Maßgeblich ist der englische Originaltext.

#LlamaFactory v0.7.1

🚨🚨 Kernrefaktor 🚨🚨

– CLIs-Verwendung hinzufügen. Jetzt empfehlen wir die Verwendung von llamafactory-cli zum Starten von Training und Inferenz. Der Einstiegspunkt befindet sich unter cli.py.

  • Dateien umbenennen: train_bash.py -> train.py, train_web.py -> webui.py, api_demo.py -> api.py
  • Dateien entfernen: cli_demo.py, evaluate.py, export_model.py, web_demo.py, stattdessen llamafactory-cli chat/eval/export/webchat verwenden
  • Verwenden Sie YAML-Konfigurationen in Beispielen anstelle von Shell-Skripten für eine hübsche Ansicht – Entfernen Sie die SHA1-Hash-Prüfung beim Laden von Datensätzen
  • Argumente umbenennen: num_layer_trainable -> freeze_trainable_layers, name_module_trainable -> freeze_trainable_modules

Die oben genannten Änderungen wurden von @hiyouga in #3596 vorgenommen

ERINNERUNG: Jetzt ist Installation erforderlich, um LLaMA Factory zu verwenden

Neue Funktionen

  • Support-Training und Schlussfolgerungen zu den Ascend NPU 910-Geräten von @zhou-wjjw und @statelesshz (docker-Bilder werden ebenfalls bereitgestellt) – Unterstützung des Parameters stop in der vLLM-Engine von @zhaonx in #3527 – Unterstützt die Feinabstimmung von Token-Einbettungen beim Freeze-Tuning über das freeze_extra_modules-Argument
  • Fügen Sie Llama3 Schnellstart zur Readme-Datei hinzu

Neue Modelle

  • Basismodelle
    • Yi-1.5 (6B/9B/34B) 📄
    • DeepSeek-V2 (236B) 📄
  • Modelle anweisen/chatten
    • Yi-1.5-Chat (6B/9B/34B) 📄🤖
    • Yi-VL-Chat (6B/34B) von @BUAADreamer in #3748 📄🖼️🤖
    • Llama3-Chinese-Chat (8B/70B) 📄🤖
    • DeepSeek-V2-Chat (236B) 📄🤖

Fehlerbehebung

– Badam-Argumente zu LlamaBoard von @codemayq in #3487 hinzufügen

  • OpenAI-Datenformat zur Readme-Datei von @khazic in #3490 hinzufügen
  • Langsamen Betrieb im DPO/ORPO-Trainer von @hiyouga behoben
  • Badam-Beispiele von @pha123661 in #3578 behoben
  • Download-Link des nectar_rm-Datensatzes von @ZeyuTeng96 in #3588 korrigiert
  • Projekt von @Katehuuh in #3601 hinzufügen
  • dockerfile von @gaussian8 in #3604 behoben – Korrigieren Sie die vollständige Optimierung von MLLMs durch @BUAADreamer in #3651
  • Korrektur der Gradio-Umgebungsvariablen von @cocktailpeanut in #3654
  • Tippfehler beheben und Log-in API von @Tendo33 in #3655 hinzufügen
