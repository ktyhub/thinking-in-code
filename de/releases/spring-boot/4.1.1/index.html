spring-boot v4.1.1

Patch Veröffentlicht20. Aug. 2026 Quellespring-projects/spring-boot Englisches Original

Diese Seite ist maschinell übersetzt. Maßgeblich ist der englische Originaltext.

Federstiefel v4.1.1

:warnung: Aufmerksamkeit erforderlich

– Das Gradle-Plugin von Spring Boot konfiguriert gRPC nicht mehr automatisch, wenn das Protobuf-Plugin angewendet wird. Dieses Verhalten verursachte Probleme für diejenigen, die Protobuf ohne gRPC verwendeten. Um sich für die Konfiguration von gRPC zu entscheiden, konfigurieren Sie die protobuf-Erweiterung mit dem grpc-Plugin unter Verwendung eines leeren Blocks. Das Gradle-Plugin Spring Boot konfiguriert dann automatisch die Verwendung von protoc-gen-grpc-java wie zuvor. #50822
