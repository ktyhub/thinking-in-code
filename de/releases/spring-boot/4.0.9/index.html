Federmanschette v4.0.9

:star: Neue Funktionen

– TWENTY_SEVEN zur JavaVersion-Enumeration hinzufügen #51422

:lady_beetle: Fehlerbehebungen

– JWTs werden abgelehnt, wenn issuer-uri leer und jwk-set-uri festgelegt ist #52249 – Paketmanifestattribute fehlen für verschachtelte JAR-Dateien ohne Verzeichniseinträge #52244 – OriginTrackedPropertiesLoader löscht Eigenschaften, deren Name mit # oder ! beginnt. #52207 – OriginTrackedResource implementiert Gleichheit nicht korrekt #52205 – Das ordnungsgemäße Herunterfahren von Tomcat oder Jetty ruft möglicherweise mit REQUESTS_ACTIVE zurück, wenn Stop unmittelbar nach dem ShutDownGracefully auf einem inaktiven Server aufgerufen wird #52195 – Leere Systemeigenschaft in TestPropertyValues wird gelöscht, anstatt auf ihren leeren Wert wiederhergestellt zu werden #52125 – MongoDB kann keine Verbindung herstellen, wenn Anmeldeinformationen ein Leerzeichen enthalten #52121 – NettyWebServer stop kann hängen bleiben, wenn es unmittelbar nach „shutDownGracefully“ aufgerufen wird #52119 – Die Authentifizierung schlägt fehl, wenn das in spring.elasticsearch.uris konfigurierte Passwort einen Doppelpunkt enthält #52047 – Die Protokollierung kann verloren gehen, wenn ein Kontext durch das Testkontext-Framework angehalten wird #51959 – Docker Compose-Unterstützung für MongoDB kann keine Verbindung herstellen, wenn Anmeldeinformationen ein Zeichen enthalten, das eine URL-Codierung erfordert #51939 – Jersey verwendet den Endpunkt ObjectMapper nicht, wenn Actuator auf einem separaten Port ausgeführt wird #51937 – BasicJsonParser behandelt Escape-Zeichen in verschachtelten Listen und Karten falsch #51907 – Die Konvertierung des Nullwochenwerts schlägt mit der Ausnahme „intValue kann nicht aus WEEKS extrahiert werden“ fehl #51892 – App startet nicht, wenn DevTools verwendet und JDBC oder R2DBC manuell ohne spring-boot-jdbc oder spring-boot-r2dbc konfiguriert wird #51872 – Docker Compose-Unterstützung erkennt fälschlicherweise MARIADB_ALLOW_EMPTY_PASSWORD anstelle von MARIADB_ALLOW_EMPTY_ROOT_PASSWORD #51870 – Die automatisch konfigurierte Kotlinx-Serialisierung JSON-Codec-Anpassung wird nicht angewendet #51842 – Bei Verwendung von Uber-JARs kann aufgrund einer Racebedingung in NestedJarFileResources #51744 eine NullPointerException ausgelöst werden. – DevTools erkennt keine reaktive Webumgebung #51708 – Die Verbindung schlägt fehl, wenn der Rabbitmq Docker Compose-Dienst für die Verwendung von SSL konfiguriert ist #51666 – Wenn server.reactive.session.cookie.same-site nicht festgelegt ist, haben Sitzungscookies kein SameSite-Attribut #51636 – Der OAuth2-Ressourcenserver ignoriert das Authorities-Claim-Delimiter, wenn es alleine festgelegt wird #51619 – In einer reaktiven Webanwendung gibt die Cloud Foundry-Sicherheitsintegration eine 500 statt einer 503 zurück, wenn die Cloud-Controller-URL nicht verfügbar ist #51613 – Einige Assertion-Meldungen benennen den falschen Parameter #51568 – SBOM-bezogene Manifestattribute fehlen in Maven-gepackten Kriegen #51551 – Docker Compose-Integration für RabbitMQ überspringt Anmeldeinformations-Fallbacks, wenn eine Umgebungsvariable keinen Wert hat #51546 – Jarmode-Tools-Befehle geben Stacktrace anstelle einer Fehlermeldung aus #51540 – Die temporäre Ebenendatei wird nicht gelöscht, wenn die Ebenenerstellung fehlschlägt #51519 – NestedByteChannel.read(ByteBuffer) gibt fälschlicherweise 0 zurück, wenn der Puffer nicht gefüllt werden konnte #51515 – Customizer-Nullprüfungen in HTTP client-Builder bestätigen das falsche Attribut #51509 – Die Konfigurationen „developmentOnly“ und „testAndDevelopmentOnly“ geben keine Attribute an, die potenzielle Auflösungsprobleme verursachen #51492 – Die SQL Server Docker Compose-Integration dupliziert möglicherweise den Verschlüsselungsparameter der JDBC-URL #51467 – SSL-Hostkonfigurationsanpassungen können während der Tomcat-Initialisierung verloren gehen #51466 – OAuth2ClientProperties sind nicht verfügbar, wenn eine benutzerdefinierte ClientRegistrationRepository-Bean bereitgestellt wird #51447 – Die Quelle wird nicht von allen JSON-Marshall-Testern konsistent geschlossen #51417 – JmsHealthIndicator verliert Watchdog-Threads, wenn der Start sofort fehlschlägt #51412 – Dateihandle in SpringBootJoranConfigurator sollte geschlossen werden #51398 – Die Validierung der veralteten io.buildpacks.stack.id ist zu aggressiv #51390 – Anpassungen der SSL-Hostkonfiguration gehen verloren, wenn SSL-Bundles neu geladen werden #51290 – Docker Compose ProcessRunner kann verwaiste Prozesse hängen lassen oder verlassen #50963 – Beschreibungen der Konfigurationseigenschaften können beim inkrementellen Erstellen mit Gradle verloren gehen #50489

:notebook_with_decorative_cover: Dokumentation

– Korrigieren Sie die Eigenschaftsnamen der Aktorendpunkte in Javadoc #51869 – Defekte Links von der Referenzdokumentation zum externen Javadoc beheben #51815 – Entfernen Sie den Verweis auf AppOptics im Referenzhandbuch, da es nicht mehr verfügbar ist #51807

  • Defekte Links reparieren #51791
  • Spring Framework-Referenzlinks aktualisieren #51750 – Die Maven-Plugin-Dokumentation verweist fälschlicherweise auf die Remote-Neustart-Eigenschaft #51743
  • Testcontainer-Javadoc-Links aktualisieren #51739 – Behebung der dokumentierten Standardeinstellung von spring.test.database.replace #51709
  • Jackson 3 Javadoc-Links korrigieren #51660 – Tippfehler in veralteten Pushgateway-Basis-URL-Eigenschaftsmetadaten behoben #51627 – Verweise auf Spring Data Geode entfernen #51563 – Tippfehler in Service-Containern, Javadoc und Referenzdokumentation behoben #51431 – Dokumentenunterstützung für Java 27 #51424 – SAML2-Backoff in der WebFlux-Sicherheitsdokumentation dokumentieren #51421 – Verweis auf entfernte SpringBootWebSecurityConfiguration #51411 entfernen
