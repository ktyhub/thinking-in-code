:star: Neue Funktionen

:lady_beetle: Fehlerbehebungen

– OriginTrackedResource implementiert Gleichheit nicht korrekt #52267 – OriginTrackedPropertiesLoader löscht Eigenschaften, deren Name mit # oder ! beginnt. #52265 – JWTs werden abgelehnt, wenn issuer-uri leer und jwk-set-uri festgelegt ist #52260 – Paketmanifestattribute fehlen für verschachtelte JAR-Dateien ohne Verzeichniseinträge #52258

  • Logback ColorConverter analysiert seine Optionen unnötigerweise für jedes Protokollereignis #52228 – Leere Systemeigenschaft in TestPropertyValues wird gelöscht, anstatt auf ihren leeren Wert wiederhergestellt zu werden #52208 – Das ordnungsgemäße Herunterfahren von Tomcat oder Jetty ruft möglicherweise mit REQUESTS_ACTIVE zurück, wenn Stop unmittelbar nach dem ShutDownGracefully auf einem inaktiven Server aufgerufen wird #52197 – NettyWebServer stop kann hängen bleiben, wenn es unmittelbar nach „shutDownGracefully“ aufgerufen wird #52196 – Die Lastverteilung von gRPC client „grpc“ kann nicht mit einer NullPointerException gebunden werden, wenn keine untergeordneten Richtlinien konfiguriert sind #52193 – Verhindern Sie, dass gRPC client-Eigenschaften Benutzeranpassungen überschreiben #52175 – MongoDB kann keine Verbindung herstellen, wenn Anmeldeinformationen ein Leerzeichen enthalten #52168 – Die Authentifizierung schlägt fehl, wenn das in spring.elasticsearch.uris konfigurierte Passwort einen Doppelpunkt enthält #52166 – Die Protokollierung kann verloren gehen, wenn ein Kontext durch das Testkontext-Framework angehalten wird #52088 – Docker Compose-Unterstützung für MongoDB kann keine Verbindung herstellen, wenn Anmeldeinformationen ein Zeichen enthalten, das eine URL-Codierung erfordert #52084 – Jersey verwendet den Endpunkt ObjectMapper nicht, wenn Actuator auf einem separaten Port ausgeführt wird #51982 – Bruchteile einer Sekunde werden beim Konfigurieren der Dauer der Dienstkonfiguration gRPC falsch behandelt #51957 – Beschreibungen der Konfigurationseigenschaften können beim inkrementellen Erstellen mit Gradle verloren gehen #51925 – BasicJsonParser behandelt Escape-Zeichen in verschachtelten Listen und Karten falsch #51908 – Die Konvertierung des Nullwochenwerts schlägt mit der Ausnahme „intValue kann nicht aus WEEKS extrahiert werden“ fehl #51894 – App startet nicht, wenn DevTools verwendet wird und JDBC oder R2DBC manuell ohne spring-boot-jdbc oder spring-boot-r2dbc konfiguriert wird #51890 – Docker Compose-Unterstützung erkennt fälschlicherweise MARIADB_ALLOW_EMPTY_PASSWORD anstelle von MARIADB_ALLOW_EMPTY_ROOT_PASSWORD #51888 – Die automatisch konfigurierte Kotlinx-Serialisierung JSON-Codec-Anpassung wird nicht angewendet #51877 – Bei Verwendung von Uber-JARs kann aufgrund einer Racebedingung in NestedJarFileResources #51745 eine NullPointerException ausgelöst werden. – DevTools erkennt keine reaktive Webumgebung #51730 – spring.http.clients.cookie-handling hat keine Auswirkung, wenn ein reaktiver client verwendet wird, der von einem HttpComponents-Connector unterstützt wird #51724 – Die Verbindung schlägt fehl, wenn der Rabbitmq Docker Compose-Dienst für die Verwendung von SSL konfiguriert ist #51667 – SBOM-bezogene Manifestattribute fehlen in Maven-gepackten Kriegen #51651 – Wenn server.reactive.session.cookie.same-site nicht festgelegt ist, haben Sitzungscookies kein SameSite-Attribut #51639 – Der OAuth2-Ressourcenserver ignoriert das Authorities-Claim-Delimiter, wenn es alleine festgelegt wird #51630 – Die Konfigurationen „developmentOnly“ und „testAndDevelopmentOnly“ geben keine Attribute an, die potenzielle Auflösungsprobleme verursachen #51623 – In einer reaktiven Webanwendung gibt die Cloud Foundry-Sicherheitsintegration eine 500 statt einer 503 zurück, wenn die Cloud-Controller-URL nicht verfügbar ist #51614 – Die temporäre Ebenendatei wird nicht gelöscht, wenn die Ebenenerstellung fehlschlägt #51581 – Docker Compose-Integration für RabbitMQ überspringt Anmeldeinformations-Fallbacks, wenn eine Umgebungsvariable keinen Wert hat #51578 – Einige Assertion-Meldungen benennen den falschen Parameter #51574 – OAuth2ResourceServerProperties.Jwt hat einen Setter, der nicht mit seinem Getter übereinstimmt #51562 – Jarmode-Tools-Befehle geben Stacktrace anstelle einer Fehlermeldung aus #51547 – Docker Compose ProcessRunner kann verwaiste Prozesse hängen lassen oder verlassen #51538 – NestedByteChannel.read(ByteBuffer) gibt fälschlicherweise 0 zurück, wenn der Puffer nicht gefüllt werden konnte #51520 – Customizer-Nullprüfungen in HTTP client-Builder bestätigen das falsche Attribut #51513 – Anpassungen der SSL-Hostkonfiguration gehen möglicherweise während der Tomcat-Initialisierung verloren #51511 – Die SQL Server Docker Compose-Integration dupliziert möglicherweise den Verschlüsselungsparameter der JDBC-URL #51481 – WritableJson.toByteArray() kann Zusatzzeichen beschädigen #51464 – Anpassungen der SSL-Hostkonfiguration gehen verloren, wenn SSL-Bundles neu geladen werden #51457 – OAuth2ClientProperties sind nicht verfügbar, wenn eine benutzerdefinierte ClientRegistrationRepository-Bean bereitgestellt wird #51450 – LdapHealthIndicator meldet UNBEKANNT statt UP, wenn der LDAP-Server keine Protokollversion verfügbar macht #51441 – JmsHealthIndicator verliert Watchdog-Threads, wenn der Start sofort fehlschlägt #51433 – Die Quelle wird nicht von allen JSON-Marshall-Testern konsistent geschlossen #51418 – Dateihandle in SpringBootJoranConfigurator sollte geschlossen werden #51415 – Berücksichtigen Sie das Entpacken eines Wrappers beim Auflösen der Root-DataSource #51410 – Die Validierung der veralteten io.buildpacks.stack.id ist zu aggressiv #51400 – ReactiveOAuth2ResourceServerWebSecurityAutoConfiguration mit falscher Bedingung versehen #50778
