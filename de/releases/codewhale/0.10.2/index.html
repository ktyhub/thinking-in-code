Codewal v0.10.2

Was ist in v0.10.2

Codewhale v0.10.2 fügt eine animierte Haustieransicht (/pet on) hinzu, eine Live-Terminal-Arbeit Dock, Composer-Farben pro Chat (/color) und eine einmalige Notiz auf dem ersten Starten Sie nach einem Update, das besagt, was sich geändert hat. Es schließt drei Sitzungen ab Datenverlustpfade und ein codewhale web-Sitzungsleck; fügt die Standard-Runtime hinzu Daemon-Socket-Standorte zur Sandbox-Deny-Liste; enthält einen curl oder wget, der einen hochlädt Berechtigung; lehnt Shell-Befehle ab, die unsichtbaren Unicode enthalten; hält die Die Linux-Sandbox funktioniert, wenn ein verstecktes Anmeldeinformationsverzeichnis ein Symlink ist. und Reduziert die Arbeit beim Neuzeichnen von TUI im Leerlauf. /undo nimmt ein Ganzes zurück Anfrage, einschließlich langer und mehrzeiliger Eingabeaufforderungen. exec --auto erklärt es Standardmäßiger Vollzugriff, berücksichtigt eine explizit strengere Sandbox und speichert Tool-fähige Läufe und deren Fehlerbelege. Währenddessen werden lokale Laufzeiten angezeigt Beim Onboarding funktioniert /diff außerhalb eines Git-Repositorys, der Antwortroute von DeepSeek Der wiedergegebene Tool-Verlauf wird nicht mehr abgelehnt, und Mitwirkende-Korrekturen verbessern das Token Buchhaltung, Relay-Modelllisten, lokalisierte Antworten und Windows-Launcher Anleitung. Die delegierte Arbeit wird ohne vom Modell erfundene Runden- oder Zeitbeschränkungen fortgesetzt. und unabhängige Workflow-Schritte können fortgesetzt werden, nachdem ein anderes untergeordnetes Element fehlschlägt.

Installieren

Empfohlen – offizielle GitHub-Version

Neue macOS/Linux-Installation (prüfsummende Binärdateien aus dieser Version):

curl -fsSL https://codewhale.net/install.sh | CODEWHALE_VERSION="v0.10.2" sh
"$HOME/.local/bin/codewhale" --version

Verwenden Sie für Windows das passende Installationsprogramm oder Archiv unten. Für eine bestehende Direktinstallation, codewhale update ausführen; Es gibt den ausführbaren Pfad aus und Behält neuere Builds. Wenn das Installationsverzeichnis von einem anderen Build belegt ist, Verwenden Sie die Migration in ein neues Verzeichnis in der Installationsanleitung.

Sekundärverpackung – npm und Cargo

npm install -g codewhale
# or build from source
cargo install codewhale-cli --locked

Der Wrapper lädt die übereinstimmenden Befehlsressourcen codewhale und codew herunter aus dieser Version. Beide enthalten die gleiche kompilierte Laufzeit.

Docker / GHCR

docker run --rm -it \
  -e DEEPSEEK_API_KEY="$DEEPSEEK_API_KEY" \
  -v codewhale-home:/home/codewhale/.codewhale \
  ghcr.io/codewhale-hq/codewhale:v0.10.2

Das Bild stellt die gleiche Laufzeit bereit wie codewhale und codew. Die Das latest-Tag wird bei der Veröffentlichung ebenfalls aktualisiert.

Fracht (Linux / macOS)

cargo install codewhale-cli --locked

Das Cargo-Paket installiert codewhale. Cargo kann keinen zweiten Befehl erstellen Alias von einem binären Ziel; Benutzer, die die kürzere Schreibweise wünschen, können a hinzufügen codew-Symlink zu der installierten ausführbaren Datei. Das npm, Homebrew, Archiv, Shell-Installer und Containerkanäle installieren beide Befehlsnamen direkt.

Manueller Download – Plattformarchive (empfohlen)

Jedes der folgenden Archive enthält die gleiche Laufzeit unter codewhale und codew-Befehlsnamen sowie ein Installationsskript:

| Plattform | Archiv | Skript installieren | |---|---|---| | Linux x64 | codewhale-linux-x64.tar.gz | install.sh | | Linux ARM64 | codewhale-linux-arm64.tar.gz | install.sh | | Android ARM64 (Termux) | codewhale-android-arm64.tar.gz | install.sh | | macOS x64 | codewhale-macos-x64.tar.gz | install.sh | | macOS ARM | codewhale-macos-arm64.tar.gz | install.sh | | Windows x64 (Installer) | CodeWhaleSetup.exe | NSIS-Setup | | Windows x64 | codewhale-windows-x64.zip | install.bat | | Windows x64 (tragbar) | codewhale-windows-x64-portable.zip | — | | Windows ARM64 | codewhale-windows-arm64.zip | install.bat | | Windows ARM64 (tragbar) | codewhale-windows-arm64-portable.zip | — |

Unix (Linux / macOS):

tar xzf codewhale-<platform>.tar.gz
cd codewhale-<platform>
./install.sh

Windows:

  • Für den Installationspfad führen Sie CodeWhaleSetup.exe aus; es wird installiert codewhale.exe, codew.exe und codewhale.bat unten %LOCALAPPDATA%\Programs\CodeWhale\bin, fügt dieses Verzeichnis dem hinzu PFAD des aktuellen Benutzers und erstellt eine Startmenü-Verknüpfung, die bevorzugt wird Windows Terminal (wt.exe) bei der Installation.
  • Extrahieren Sie das Archiv für Ihren Computer: codewhale-windows-x64.zip oder codewhale-windows-arm64.zip
  • Double-click codewhale.bat (nicht das rohe .exe) zum Starten
  • Führen Sie install.bat aus, um die Binärdateien und den Launcher nach %USERPROFILE%\bin zu kopieren
  • Fügen Sie %USERPROFILE%\bin zu Ihrem PATH hinzu

Das tragbare Windows-Archiv überspringt das Installationsskript – extrahieren Sie codewhale.bat und führen Sie es aus einem beliebigen Verzeichnis aus. Das NSIS-Installationsprogramm ist derzeit nicht signiert und löst möglicherweise Windows SmartScreen aus, bis ein Signaturzertifikat in die Release-Pipeline eingebunden wird.

Jede Plattform verfügt außerdem über nackte, nicht archivierte codewhale-<platform> und codew-<platform>-Vermögen. Die sieben codewhale-tui-<platform>-Dateinamen An v0.9.5 angehängt sind byteidentische Kompatibilitätskopien, die nur zum Verlassen verwendet werden Bereits installierte v0.9.4 clients entdecken und überqueren diese einzelne Binärdatei Übergang; Aktuelle Installationsprogramme stellen keine dritte Laufzeit zur Verfügung. Das alte npm Paket deepseek-tui ist veraltet und wird nicht erneut veröffentlicht. Für Migration aus v0.8.x-Legacy-Binärnamen, siehe docs/REBRAND.md.

Überprüfen (empfohlen)

Laden Sie die Prüfsummenmanifeste aus dieser Version herunter und überprüfen Sie:

# Linux — archive bundles
sha256sum -c codewhale-bundles-sha256.txt --ignore-missing

# Linux — individual binaries
sha256sum -c codewhale-artifacts-sha256.txt --ignore-missing

# macOS
shasum -a 256 -c codewhale-bundles-sha256.txt --ignore-missing
shasum -a 256 -c codewhale-artifacts-sha256.txt --ignore-missing
