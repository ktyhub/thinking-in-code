Codewal v0.9.12

Codewhale ist das öffentliche Produkt von Shannon Labs. Der codewhale Befehls-, NPM-Paket- und Release-Asset-Namen bleiben technisch in Kleinbuchstaben geschrieben Identifikatoren. Das alte NPM-Paket deepseek-tui ist veraltet und erhält keine weiteren Veröffentlichungen. Benutzer aus v0.8.x Legacy deepseek / deepseek-tui-Namen sollten mit docs/REBRAND.md migriert werden.

Installieren

Empfohlen – offizielle GitHub-Version

Neue macOS/Linux-Installation (prüfsummende Binärdateien aus dieser Version):

curl -fsSL https://codewhale.net/install.sh | CODEWHALE_VERSION="v0.9.12" sh
"$HOME/.local/bin/codewhale" --version

Verwenden Sie für Windows das passende Installationsprogramm oder Archiv unten. Für eine bestehende Direktinstallation, codewhale update ausführen; Es gibt den ausführbaren Pfad aus und Behält neuere Builds. Wenn das Installationsverzeichnis von einem anderen Build belegt ist, Verwenden Sie die Migration eines neuen Verzeichnisses in der Installationsanleitung.

Sekundärverpackung – npm und Cargo

npm install -g codewhale
# or build from source
cargo install codewhale-cli --locked

Der Wrapper lädt die übereinstimmenden Befehlsressourcen codewhale und codew herunter aus dieser Version. Beide enthalten die gleiche kompilierte Laufzeit.

Docker / GHCR

docker run --rm -it \
  -e DEEPSEEK_API_KEY="$DEEPSEEK_API_KEY" \
  -v codewhale-home:/home/codewhale/.codewhale \
  ghcr.io/hmbown/codewhale:v0.9.12

Das Bild stellt die gleiche Laufzeit bereit wie codewhale und codew. Die Das latest-Tag wird bei der Veröffentlichung ebenfalls aktualisiert.

Fracht (Linux / macOS)

cargo install codewhale-cli --locked

Das Cargo-Paket installiert codewhale. Cargo kann keinen zweiten Befehl erstellen Alias von einem binären Ziel; Benutzer, die die kürzere Schreibweise wünschen, können a hinzufügen codew-Symlink zu der installierten ausführbaren Datei. Das npm, Homebrew, Archiv, Shell-Installer und Containerkanäle installieren beide Befehlsnamen direkt.

Was ist in v0.9.12

Codewhale v0.9.12 bringt Computernutzung in die Binärdatei und eröffnet zwei neue Routen – Alibaba Model Studio über die datengesteuerte Anbietertabelle und Concentrate als Opt-in-BYOK-Response-Gateway – und fügt Cloud-Versand plus a hinzu Konfigurationsgesteuerter sitzungsspezifischer Steuerungssocket. Die Schale ist die andere Hälfte Veröffentlichung: eine neue Startkarte, die Arbeitsfläche ist unter dem Komponisten angedockt, eine Fokusbesitzer für Tab, Werkzeugzellen, die ihren eigenen Status tragen, und fleet als das öffentliche Wort für das Live-Kollektiv. Die vollständige Änderung auf Artikelebene Der Datensatz wird unterhalb der kategorisierten Release-Highlights aufbewahrt.

Hinzugefügt

  • Computernutzung wird mit der Binärdatei geliefert. Das computer-use-Plugin – 38 Tools unter macOS, Windows, Linux und HarmonyOS, barrierefreie Beobachtung mit Pixel-Fallback, Screenshots, Zoom, Bildschirmaufzeichnung und registriert Remote-Computer über SSH und HDC – ist in Codewhale eingebettet und wird beschrieben $CODEWHALE_HOME/builtin-plugins beim ersten Start, also bei jedem Installationskanal trägt es. Es wird als builtin · not-reviewed aufgeführt und bleibt deaktiviert, bis Sie überprüfen und aktivieren es: Wenn Sie es versenden, stimmen Sie dem nicht zu. Die Der Computerserver stdlib-Python, den er ersetzt, ist nicht mehr vorhanden.
  • Alibaba Model Studio tritt der datengesteuerten Anbietertabelle als bei openai-compatible-Deskriptor: Internationaler Endpunkt im kompatiblen Modus, DASHSCOPE_API_KEY-Anmeldeinformationen, Live-/v1/models-Erkennung. Qwen 3.8 Flash und Qwen 3.8 Max kommen über die Katalogautorität an – nie hartcodierte ID.
  • Konzentrat: erstklassiges Opt-in-BYOK-Response-Gateway mit Live-Modellen Erkennung und typisiertes SSE-Streaming (#5725).
  • Cloud-Versand: Der Remote-Runner verlagert die Aufgaben des Coding-Agents auf isolierte Server Cloud-Sandboxen mit maschineller Token-Authentifizierung und strukturierter Auftragsverfolgung (#5701, #5712). – Steuerungssocket pro Sitzung: config-gated [control_socket]-Tabellenbindungen <sessions-dir>/<session-id>/control.sock pro laufende Sitzung, Belichtung Nachricht, Unterbrechung, Neustart und Status JSON-RPC-Verben (#5533, #5831).
