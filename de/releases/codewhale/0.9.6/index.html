Codewal v0.9.6

Codewhale ist das öffentliche Produkt von Shannon Labs. Der codewhale Befehls-, NPM-Paket- und Release-Asset-Namen bleiben technisch in Kleinbuchstaben geschrieben Identifikatoren. Das alte NPM-Paket deepseek-tui ist veraltet und erhält keine weiteren Veröffentlichungen. Benutzer aus v0.8.x Legacy deepseek / deepseek-tui-Namen sollten mit docs/REBRAND.md migriert werden.

Installieren

Empfohlen – npm (ein Befehl, beide Einstiegspunkte)

npm install -g codewhale

Der Wrapper lädt die übereinstimmenden Befehlsressourcen codewhale und codew herunter aus dieser Version. Beide enthalten die gleiche kompilierte Laufzeit.

Docker / GHCR

docker run --rm -it \
  -e DEEPSEEK_API_KEY="$DEEPSEEK_API_KEY" \
  -v codewhale-home:/home/codewhale/.codewhale \
  ghcr.io/hmbown/codewhale:v0.9.6

Das Bild stellt die gleiche Laufzeit bereit wie codewhale und codew. Die Das latest-Tag wird bei der Veröffentlichung ebenfalls aktualisiert.

Fracht (Linux / macOS)

cargo install codewhale-cli --locked

Das Cargo-Paket installiert codewhale. Cargo kann keinen zweiten Befehl erstellen Alias von einem binären Ziel; Benutzer, die die kürzere Schreibweise wünschen, können a hinzufügen codew-Symlink zu der installierten ausführbaren Datei. Das npm, Homebrew, Archiv, Shell-Installer und Containerkanäle installieren beide Befehlsnamen direkt.

Manueller Download – Plattformarchive (empfohlen)

Jedes unten aufgeführte Archiv enthält dieselbe Laufzeit unter codewhale und codew-Befehlsnamen sowie ein Installationsskript:

| Plattform | Archiv | Skript installieren | |---|---|---| | Linux x64 | codewhale-linux-x64.tar.gz | install.sh | | Linux ARM64 | codewhale-linux-arm64.tar.gz | install.sh | | Android ARM64 (Termux) | codewhale-android-arm64.tar.gz | install.sh | | macOS x64 | codewhale-macos-x64.tar.gz | install.sh | | macOS ARM | codewhale-macos-arm64.tar.gz | install.sh | | Windows x64 (Installer) | CodeWhaleSetup.exe | NSIS-Setup | | Windows x64 | codewhale-windows-x64.zip | install.bat | | Windows x64 (tragbar) | codewhale-windows-x64-portable.zip | — | | Windows ARM64 | codewhale-windows-arm64.zip | install.bat | | Windows ARM64 (tragbar) | codewhale-windows-arm64-portable.zip | — |

Unix (Linux / macOS):

tar xzf codewhale-<platform>.tar.gz
cd codewhale-<platform>
./install.sh

Windows:

  • Führen Sie für den Installationspfad CodeWhaleSetup.exe aus. es wird installiert codewhale.exe und codew.exe unten %LOCALAPPDATA%\Programs\CodeWhale\bin und fügt dieses Verzeichnis dem hinzu PATH des aktuellen Benutzers.
  • Extrahieren Sie das Archiv für Ihre Maschine: codewhale-windows-x64.zip oder codewhale-windows-arm64.zip
  • Führen Sie install.bat aus (kopiert nach %USERPROFILE%\bin)
  • Fügen Sie %USERPROFILE%\bin zu Ihrem PATH hinzu

Das tragbare Windows-Archiv überspringt das Installationsskript – extrahieren Sie es und führen Sie es aus einem beliebigen Verzeichnis aus. Das NSIS-Installationsprogramm ist derzeit nicht signiert und löst möglicherweise Windows SmartScreen aus, bis ein Signaturzertifikat in die Release-Pipeline eingebunden wird.

Jede Plattform verfügt außerdem über nackte, nicht archivierte codewhale-<platform> und codew-<platform>-Vermögenswerte. Die sieben codewhale-tui-<platform>-Dateinamen An v0.9.5 sind byteidentische Kompatibilitätskopien angehängt, die nur zum Verlassen verwendet werden Bereits installierte v0.9.4 clients entdecken und überqueren diese einzelne Binärdatei Übergang; Aktuelle Installationsprogramme stellen keine dritte Laufzeit zur Verfügung. Das alte npm Paket deepseek-tui ist veraltet und wird nicht erneut veröffentlicht. Für Migration aus v0.8.x-Legacy-Binärnamen, siehe docs/REBRAND.md.

Überprüfen (empfohlen)

Laden Sie die Prüfsummenmanifeste aus dieser Version herunter und überprüfen Sie:

# Linux — archive bundles
sha256sum -c codewhale-bundles-sha256.txt --ignore-missing

# Linux — individual binaries
sha256sum -c codewhale-artifacts-sha256.txt --ignore-missing

# macOS
shasum -a 256 -c codewhale-bundles-sha256.txt --ignore-missing
shasum -a 256 -c codewhale-artifacts-sha256.txt --ignore-missing

Was ist in v0.9.6

Codewhale v0.9.6 ist eine subtraktive Version: weniger Laufzeitwächter, einer stabil Schnelle, zuverlässige Provider-Endungen und ein kleinerer Komprimierungspfad, der die Sicherheit gewährleistet Der Provider-Cache. Die Änderungen wurden durch die passende Terminal-Bench 2.1 geerdet läuft gegen Pi 0.8.41 und durch Dogfooding wiederholte manuelle Komprimierung.

Hinzugefügt

  • web_search ist standardmäßig Firecrawl Cloud ohne API-Schlüssel. Keyless-Anfragen sind headerlos und kontingentbegrenzt, während ein optionaler Benutzerschlüssel die Grenzen erhöht. – Grüne Web-Builds auf main geben jetzt eine umsetzbare Erinnerung an die manuelle Bereitstellung aus Site-Änderungen können nicht stillschweigend versendet werden, solange Cloudflare noch eine bereitstellt ältere Revision.
  • Mistral AI ist eine erstklassige Anbieterroute, einschließlich Codestral-Modellen, Unterstützung für First-Party-Argumentation, Authentifizierung, Auswahleinträge und Aliase.
  • Headless Bash kann explizit angeforderte persistente Unix-Dienste übertragen aus einem Exec-Lauf, mit Eigentums- und Bereinigungsbelegen.
  • /remote-env öffnet gehostete Arbeit von der aktuellen GitHub- oder CNB-Zweigstelle aus und Gibt genau an, welcher ungepushte, schmutzige, ignorierte, geheime und Sitzungsstatus erhalten bleibt lokal.
  • Linux ARM64-Release und Nightly-Assets sind statische Muss-Builds mit nativer Unterstützung Startprüfungen.
  • Betreuer können beobachtete tägliche aktive Installationen von demselben anonymen Benutzer melden. aggregierter Telemetriedatensatz; Es werden keine zusätzlichen client-Daten erfasst.
  • Von der Flotte entsandte Mitglieder unterliegen jetzt einer schreibgeschützten Beweisobergrenze (kein Netzwerk). Behalten Sie die schreibgeschützten Aktionen search und fetch des Tools Web bei – Parität mit einem gewöhnlicher Scout – während jede erreichbare Oberfläche (web.run, fetch_url, github, MCP) bleibt abgelehnt und der Sentinel-gestützte Fähigkeitsbereich bleibt erhalten bleibt die ausfallsichere Rücklaufsperre.
  • /fleet setup kann eine optionale, deterministische, nicht ratifizierte Vorbildfunktion aufweisen Hinweis, der nur aus konfigurierten fertigen Routen erstellt wird. Akzeptieren, bearbeiten und ablehnen alle bleiben innerhalb der vorhandenen, von Menschen überprüften Profilspeichergrenze; die Advisory startet niemals eine Flotte oder schreibt eine zweite Konfiguration.
  • /update sucht nach einer neueren Codewhale-Version und installiert diese von innen die TUI, während tui_help Agenten den gleichen Befehl und die gleiche Tastenzuordnung gibt, die Benutzer sehen.
  • Markdown-Dateipfade werden als OSC 8-Links gerendert, wenn das Terminal sie unterstützt. und jede Agentenzeile kann das Transkript dieses Agenten direkt öffnen.
  • ACP-Editor-Sitzungen können mehrere Datei-, Such-, Git-, Patch- und Multi-Runden-Dateien ausführen explizit aktivierte Shell-Tool-Aufrufe über die gemeinsam genutzte Runtime-Registrierung. Der Shell-Zugriff erfordert sowohl die Terminalfähigkeit des client als auch die von Codewhale Headless-Shell-Opt-in und Stornierung stoppt ein In-Flight-Tool vor dem turn kehrt zurück (#5225 von @rafaelcavalheri).
  • Der Kleinbuchstabe read gibt begrenzte typisierte PNG-, JPEG-, GIF- und WebP-Ergebnisse zurück bildfähige Chat-, Antwort-, Anthropic- und ACP-Routen. Nur-Text-Routen eine explizite Unterlassungsbestätigung erhalten; Bildbytes gehen nie ins Normale über Transkription, Export, Komprimierung oder Weiterleitung von Text.

Geändert

  • Die anonyme Nutzungszählung ist bei Neuinstallationen standardmäßig aktiviert und wird in veröffentlicht ein natives, erstmaliges Codewhale-Modal mit sofortiger Abmeldung. Vor declines bleiben ausgeschaltet. Codewhale sammelt keine Konversationen, Codes, Eingabeaufforderungen, Dateien usw. Repo- oder Branch-Namen, Anmeldeinformationen, Modellinhalt oder Aktivität pro Runde Zeitpläne.
  • Wide-Terminals verwenden eine reaktionsfähige Vollbild-Ozean-Leinwand mit bescheidenem Dachrinnen: Prosa behält ein lesbares Maß bei, während Werkzeuge, Differenziale, Arbeitsflächen, Der Composer und Status Chrome können die verfügbare Breite nutzen. Turn und Major Aktivitätsnähte atmen, ohne jeden Anruf innerhalb einer Werkzeuggruppe aufzufüllen. – Die Root-CLI-Hilfe beschreibt Produktaktionen direkt, anstatt interne Aktionen offenzulegen TUI/Laufzeitebenen.
  • Bash action="wait" blockiert jetzt standardmäßig, wenn ein Warten angefordert wird; Anrufer kann weiterhin einen nicht blockierenden Snapshot und dauerhaften Dienstbesitz anfordern bleibt explizit.
  • Bei der Komprimierung handelt es sich um eine Cache-stabile Zusammenfassungsanforderung, gefolgt von einer festgeschriebenen Ersetzungszusammenfassung und ein begrenztes Ende der letzten Nachricht. Ältere gespeicherte Sitzungen noch wiederherstellen.
  • Fragen, Arbeiten, automatische Überprüfung und Vollzugriff teilen sich eine stabile Basiseingabeaufforderung. Modi unterscheiden sich weiterhin durch Berechtigungen und den Live-Tool-Katalog; ersteres Das Act-Label lautet jetzt „Arbeiten“ im gesamten Produkt und in den Versandgebieten.
  • Vollzugriff genehmigt jetzt automatisch und konsistent nicht umgehbare Tools Die auf normalen Genehmigungskarten angezeigte Standardauswahl ist konfigurierbar.
  • Modell-, Kontextfenster-, Dispatch-Name- und Nested-Agent-Spawn-Empfangsbericht die Route und die Grenzen, die tatsächlich verwendet werden, anstatt a stillschweigend zu ersetzen vermutete Identität.
  • Child-Agent startet vor der Zulassung eine unveränderliche Routenquittung und Bewahren Sie es durch Status, Unterbrechung, Abschluss, Lebenslauf, Arbeitsdiagramm, und Hauptbuchprognosen, sodass die Anbieter-/Modellzuordnung nicht abweichen kann (#5305).
  • Zielläufe werden nicht mehr wegen interner Fortsetzung, wiederholter Lücke usw. gestoppt Wachen mit unbeantworteten Fragen. Explizite Benutzergrenzen und Endzielzustände bleiben maßgebend.
  • Die kontoeigene /rc-Fernbedienung behält jetzt das ausschließliche Eigentum und a Absturzwiederherstellbares Lieferjournal, bis der Server das Terminal bestätigt, Genehmigung, Fehler und Snapshot-Status.
  • todo_write ist eine optionale Fortschrittsoberfläche und kein erforderliches Modell Zeremonie.
  • Neue Kurven nutzen einen kleinen, stabilen Werkzeugkasten: read, write, edit, bash, agent, todo_write und tool_search. Das optionale Fortschrittstool bleibt bestehen sichtbar als vertrautes Arbeitsgedächtnis; spezialisiert nativ, Web, MCP, Plugin, Speicher-, Aufgaben- und Überprüfungstools sind richtliniengefiltert und durchsuchbar. Aktivierte Schemata bleiben in einem begrenzten Cache pro Konversation. Jeder Unteragent behält seine eigene Suche und seinen eigenen Cache bei, einschließlich der durch Richtlinien zulässigen Webrecherche Gespaltener Kontext und übergeordnete Aktivierungen bleiben Warmstarts und keine Zulassungslisten.
  • Die direkten Datei- und Shell-Schemata folgen Pis bewusst kleinem Vertrag: Begrenzte vollständige Zeilenlesevorgänge, hashfreie Schreibvorgänge, eindeutige Mehrfachbearbeitung mit BOM/CRLF-Erhaltung und konservatives Fuzzy-Matching sowie ein Vordergrund bash-Befehl mit einem begrenzten chronologischen Ausgabeende. Modi ändern sich Hinrichtungsbehörde, nicht diese primitiven Namen.
  • Codewhale gibt dem Modell nicht mehr erneut die To-Do-Liste an. Das Modell lernt Was in der Liste des Tools enthalten ist, hat seinen eigenen todo_write-Aufruf zurückgegeben. Das ist ein gewöhnlicher Gesprächsverlauf – genauso wie Pi's To-do funktioniert. Die vorübergehender <codewhale:work_state>-Block, der früher am Ende von jedem ritt Die übergeordnete Turn-Loop- und Sub-Agent-Schrittanforderung ist verschwunden, zusammen mit dem Stall Systempräfix wird durch Listenänderungen gestört. Ein Schnappschuss wird noch einmal angezeigt, wo eine Person danach gefragt hat: Der <codewhale:fork_state>-Block ist ein neu gegabelter Block Der Subagent wird übergeben, /relay-Übergabeanweisungen und die Agentenkarte. Die Die erledigte Aufgabe bleibt in der Benutzeroberfläche sichtbar. Ein Strukturtest bestätigt die Realität Ausgehende Anbieteranforderungstexte enthalten die Liste nicht.
  • Scout und Reviewer benennen die schreibgeschützten Ermittlerrollen. Beide belichten exakt ein Shell-Einstiegspunkt – kanonischer Kleinbuchstabe bash, begrenzt durch das Strikte schreibgeschützter Klassifikator – und der alte Alias Bash bleibt im Katalog verweigert und beim Versand. Zuvor ermöglichte eine Namensübereinstimmung ohne Berücksichtigung der Groß- und Kleinschreibung, dass ein Anruf buchstabiert wurde Bash wird durch diese Ausgliederung ausgeführt, wodurch die Roh-Shell wieder eine schreibgeschützte Rolle erhält.

Behoben

– Das Senden von mehr Kontext während der Ausführung eines kleingeschriebenen bash-Befehls wird jetzt verschoben den Befehl an /jobs und gibt stattdessen eine erfolgreich ausgeführte Quittung zurück fälschlicherweise Command exited with code -1 gemeldet; der Prozess läuft weiter und seine Fertigstellung erfolgt immer noch durch das normale Laufzeitereignis.

– Die erstmalige Offenlegung der Nutzung wird jetzt als natives Codewhale-Modal anstelle eines geöffnet Shell-Fragebogen vor dem Start der Anwendung. Telemetrie bleibt unbewaffnet bis die native Auswahl getroffen wird und eine speicherinterne Deaktivierungsauswahl regelt Die aktuelle Sitzung wird auch dann gespeichert, wenn die Einstellung nicht gespeichert werden kann. – /compact-Ergebnisse für Abschluss, Fehler, Warteschlange, Duplikat und Postfach dauerhafte Transkriptbelege statt kurzlebiger Trinksprüche. Ein verirrtes Terminal Das Ereignis kann nicht länger jede spätere Komprimierung als bereits ausgeführt belassen. – Die Komprimierung folgt jetzt der einfachen Transkriptform von Codex: aktueller Benutzerkontext gefolgt von einem gewöhnlichen Verlaufskontrollpunkt. Es wird niemals die Zusammenfassung angehängt, die To-Do-Liste oder der flüchtige Shell-/Worker-Status zur ständigen Systemeingabeaufforderung; Neuladungen migrieren den persistenten Träger zurück in genau ein Verlaufselement.

  • Bei der automatischen Komprimierung wird ein Prozentsatz des tatsächlichen Kontextfensters verwendet, auf den geklemmt wird die auszugebende Obergrenze der Route. Der Druck kommt von der aktuellen übergeordneten Route zeitnah, keine kumulative Abrechnung oder Nutzung des Kindermodells.
  • Verdichtung, Überprüfung, Verifizierung, Routing, Einrichtung, Flotte, MCP, RLM, Vision, Übersetzung und Subagentenaufrufe erben die normale Ausgabe der aufgelösten Route. Stichproben- und Begründungspolitik. Keine kleinen Token-Obergrenzen für interne Aufgaben mehr verkürzte Denkwege oder Sonderfälle einzelner Anbieter.
  • Unvollständige Anbieterantworten scheitern in regelmäßigen Runden und in jedem Fall wahrheitsgetreu interner Modellkonsument. Teiltext bleibt unterbrochen, ausstehende Toolaufrufe jedoch nicht ausgeführt und die abgerechnete Nutzung bleibt erhalten. – Nur für den Transport bestimmte (reasoning omitted)-Platzhalter werden nicht mehr neu eingegeben Transkripte und werden aus wiederhergestellten Sitzungen gefiltert. Argumentation erweitern/reduzieren Aktionen bleiben mit der exakt gerenderten Zelle verbunden, auch nach dem Ersetzen. Wiederherstellen, Filtern und Ändern der Größe (#5291).
  • Die Erschöpfung des Stufenbudgets ist ein typisierter Fehler und kann nicht zur Freigabe eines ausstehenden Budgets führen beständiger Dienst. Bei einer Stornierung nach der Nutzung des Terminals wird weiterhin die Gebühr berechnet. – Zurückgestellte Tools behalten jetzt ein abgeschlossenes Ergebnis bei, wenn ein Anbieter es wiederverwendet Tool-Aufruf-ID bei der Wiederholung, wodurch erfolgreiche Plugin-Aufrufe verhindert werden Eintritt in eine wiederholte Ausführungsschleife.
  • Website-Einrichtung, Anbieter, Diagnose, Flotte und Single-Runtime-Ansprüche jetzt mit dem Quellkandidaten übereinstimmen.
  • Beim Öffnen des Subagentenregisters wird die To-Do-Liste der Agenten nicht mehr ausgeblendet Im Panel werden das vollständige Register und die dauerhafte Checkliste zusammen angezeigt Der Registerkopf ist eine Zwei-Wege-Tür, die auf einem zweiten click zu Aufgaben zurückkehrt.
  • Der Detailakkord ⌥V / Alt+V öffnet die eigene Zeile der ausgewählten Arbeitsfläche Inspektor anstelle der nächstgelegenen Werkzeugzelle des Transkripts, also einer ausgewählten Die To-do-Zeile zeigt ihren eigenen Inhalt und nicht die neuesten Überlegungen. – Die erste Offenlegung der Nutzung stellt nun eine klare Frage: „Helfen Sie mit, sich zu verbessern.“ Codewal?“ – mit eindeutigem „Ja, anonyme Zählungen beibehalten“ / „Nein, ausschalten“. Tracking“-Optionen in jedem versendeten Gebietsschema und gibt die dauerhafte Abmeldung an Befehl. Die Zustimmungssemantik bleibt unverändert: Die Telemetrie bleibt unbewaffnet, bis a Die Wahl wird getroffen.
  • Screenshots von macOS-Screencaptures, auf die in einer Nachricht verwiesen wird, werden in eine kopiert Stable-Attachments-Verzeichnis in dem Moment, in dem die Nachricht empfangen wird, und die Der Verweis wird auf den stabilen Pfad umgeschrieben, sodass das Bild weiterhin vorhanden ist Der Agent liest es. Nur Dateien unter einer Bildschirmaufnahme „Temporäre Elemente“ Verzeichnis werden berührt; Kopien sind idempotent und eine fehlgeschlagene Kopie behält die Originalreferenz.
  • Das manuelle /compact während einer aktiven Runde steht jetzt auch dann in der Warteschlange, wenn der Motor ausgeschaltet ist Das begrenzte OP-Postfach ist gesättigt. Die Anfrage wird auf der client-Seite zurückgestellt und erneut versucht Postfachslots sind frei und können nach der Beruhigung nicht als bereits ausgeführt verriegelt werden.
  • Die interaktiven Auswahlpfade /load, Start --resume und /resume bleiben erhalten die beibehaltene Anbieter-, Endpunkt- und Modellidentität; Picker-Lebenslauf auch hinterlässt eine dauerhafte Abschriftsbestätigung.
  • Relative mcp_config_path-Werte hängen nicht mehr vom Startverzeichnis oder ab Laden Sie stillschweigend einen leeren Serverpool: Codewhale warnt und greift auf den zurück Benutzerglobale MCP-Konfiguration. Explizite absolute Pfade bleiben maßgebend.
  • Alibaba Model Studio qwen3.8-max und qwen3.8-max-preview werden weiterhin gestreamt ihre aktuelle Argumentation, aber historische reasoning_content nicht mehr wiedergeben dass diese Routen nicht akzeptieren. Die Wiederholung der historischen Argumentation ist jetzt eingeschränkt der genaue Anbieter/API/Modellvertrag, also unbekannte *-thinking-Doppelgänger scheitern geschlossen, während dokumentiert Qwen, Kimi, DeepSeek, Mistral, Anthropic und Die Kontinuitätsregeln für Antworten bleiben erhalten.
  • Kompatibilität Datei-/Patch-Aufrufe behalten optionale Content-Hash-Guards bei, wenn a Der Anrufer liefert sie. Die neuen direkten Schemata write und edit werden nicht verfügbar gemacht Hash- oder Vorlesezeremonie. – Shell-Vorschauen halten unvollständige UTF-8-Sequenzen zurück, anstatt sie auszugeben Ersatzzeichen und Komprimierungsbelege melden Token-Deltas.
  • Verschachtelte Agenten können ihr vererbtes Tiefenbudget einschränken, aber niemals erweitern (#5317 von @ousamabenyounes). – Die Containerveröffentlichung stellt jetzt AMD64- und ARM64-Images parallel zusammen native Läufer aus den bereits verifizierten statischen Release-Binärdateien veröffentlicht und prüft ein Multi-Architektur-Manifest. Es wird nicht mehr neu aufgebaut beide Ziele durch den einzigen langjährigen QEMU-Job, der seinen Läufer verlor.

Entfernt

  • Der No-Progress-Guard, der Repeated-Read-Guard und die Strategie für injizierte Tool-Fehler Coaching. Produktive Abfrage, wiederholte Inspektion und modelleigene Wiederherstellung werden nicht mehr durch Laufzeitheuristiken unterbrochen.
  • Niemals verkabelte Entscheidungskarte, Tastenbelegung, Hover, Shell-Ausführung, Engine-Op und Release-Skriptpfade wurden gelöscht, sodass die unterstützte Laufzeit eine Route dafür hat jedes Verhalten.
