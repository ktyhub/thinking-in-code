v0.6.0 – Semantische Suche, SIMILAR_TO-Kanten und sprachübergreifende Intelligenz

Über 85 Commits seit v0.5.7. Hauptversion mit vektorbasierter semantischer Suche, struktureller Near-Clone-Erkennung, sprachübergreifender Importauflösung und erheblichen Verbesserungen der Lebensqualität auf allen Plattformen.

Semantische Suche und Vektoreinbettungen

  • semantic_query-Tool: schlüsselwortbasierte Vektorsuche im gesamten Codebasisdiagramm über die SQL-Funktion cbm_cosine_i8
  • Nomic-Nomic-Embed-Code-Einbettungen: 40.000 vorab trainierte Token-Vektoren (768d int8), destilliert aus nomic-ai/nomic-embed-code mit simulierter Aufmerksamkeit
  • Kombinierte Bewertung mit 11 Signalen: TF-IDF, Reflektierende Zufallsindizierung, API/Type/Decorator-Signaturen, AST-Strukturprofile, ungefährer Datenfluss, Halstead-Lite-Metriken, MinHash, Modulnähe, Diagrammdiffusion
  • SEMANTICALLY_RELATED-Kanten: Funktionen mit nicht übereinstimmendem Vokabular, aber ähnlichem Zweck verbinden (Punktzahl >= 0.80, max. 10 pro Knoten, nur in derselben Sprache)
  • Die Min-Cosinus-Bewertung pro Schlüsselwort ersetzt die zusammengeführte Vektormittelung für eine bessere Präzision
  • Punktebegrenzung auf [0,1] – der Näherungsmultiplikator erhöht die Punkte nicht mehr über 1.0 – Klon-Deduplizierung: SIMILAR_TO paart mit Jaccard >= Schwellenwert überspringen SEMANTICALLY_RELATED

SIMILAR_TO Edges (Near-Clone-Erkennung)

  • MinHash-Fingerprinting: 64-Hash-Signaturen von Nur-Blatt-AST-Tokens mit struktureller Gewichtung
  • LSH-Index: bandbasiertes ortssensitives Hashing für den Abruf von O(1)-Kandidaten
  • Parallele Bewertung: Worker-Pool fragt LSH ab, bewertet Kandidaten, gibt Kanten aus
  • Einzigartiges Trigram-Gate filtert trivial kurze Funktionen
  • SIMILAR_TO-Kanten mit Jaccard-Ähnlichkeit und Same-File-Flag in den Eigenschaften

Volltextsuche

  • BM25-Volltextsuche über FTS5 mit cbm_camel_split-Tokenizer (camelCase/snake_case-fähig)
  • Inkrementeller FTS5-Neuaufbau bei Indexaktualisierungen

Neue Kantentypen und Erkennung

  • EMITS / LISTENS_ON Kanten für Socket.IO, EventEmitter und generische Kanalmuster
  • Konstante Auflösung: const EVENT = "foo"; emit(EVENT) löst Kanalnamen über dateispezifische Konstantentabellen auf
  • IMPORTS-Kanten mit relativer Pfadauflösung für JS/TS (./foo, ../bar), Python (.helpers, ..utils), Ruby
  • DATA_FLOWS Kanten mit Argument-zu-Parameter-Zuordnung + Feldzugriffsketten
  • Dienstübergreifende Kommunikationserkennung + Inkrementelle RAM-First-Indizierung
  • AST-basierte Routenregistrierung ersetzt die Prescan-Infrastruktur
  • HCL-Infrastruktur-Bindungsextraktion + Prefix-Decorator-Falsch-Positiv-Korrektur
  • Allgemeine Routenregistrierung + Infra-Bindungsbrücke

Verbesserungen bei Diagrammabfragen und Tools

  • 6 zuvor ignorierte Parameter verkabelt: min_degree, max_degree, exclude_entry_points, include_connected, aspects Filter, since für discover_changes
  • include_tests-Parameter auf trace_path – Testdateien in BFS-Ergebnissen markieren
  • risk_labels auf trace_path für sicherheitsrelevante Pfadverfolgung
  • --progress CLI-Flag für Echtzeit-Indizierungs-Feedback
  • CBM_CACHE_DIR env var für konfigurierbares Datenbankverzeichnis
  • moderate-Indexmodus zum Tool-Schema hinzugefügt (zwischen vollständig und schnell)
  • Offenlegung der Schemaeigenschaften für param_names, param_types, decorators
  • include_connected-Fix: BFS-Eingang und -Ausgang laufen getrennt (wurde falsch zusammengeführt)

Lebensqualität

  • Verschachtelte .gitignore-Unterstützung: Unterverzeichnis-Gitignores werden jetzt bei der Indizierung berücksichtigt – entscheidend für Monorepos (#178)
  • Fähigkeitskonsolidierung: 4 separate Fähigkeiten werden mit progressiver Offenlegung zu einer zusammengeführt
  • Intelligentes Update: skip update when already on latest version
  • Binärerkennung zur Laufzeit im Installationsbefehl (nicht mehr fest codiert)
  • Git-Submodul-Unterstützung im Watcher: Dirty-Status innerhalb von Submodulen erkennen
  • Schnell→Erkennung vollständiger Modusänderungen + Automatische Aktivierung der Benutzeroberfläche für UI-Varianten-Binärdateien
  • Layout-Endpunkt: O(n*e)-Kantenzuordnung durch binäre Suche ersetzt
  • Layout JSON: Behandelt ungültiges UTF-8 und NaN bei der Serialisierung

Plattformkorrekturen

  • Windows: Zed/VS Code/KiloCode-Konfigurationspfade, PATH-Trennzeichen, S_IXUSR-Prüfung, Agentenerkennung mithilfe von home_dir-relativen Pfaden, APPDATA-basierter Benutzerkonfigurationstest
  • Linux Portable: Alpine-Musl-Kompatibilität, Sicherheitsüberprüfungen zu Rauchtests hinzugefügt, XDG_CONFIG_HOME in Rauchumgebung
  • Plattformübergreifende Vektor-Blob-Assemblierung: Präprozessorbedingungen für macOS Mach-O / Linux ELF / Windows COFF – C++ SEGV-Fix: NULL-Deref im LSP-Typ-Resolver für große Header-Dateien

Codequalität und Linting

  • 337 Linter-Warnungen in 16 Dateien behoben (benannte Konstanten, Extraktion kognitiver Komplexität)
  • Schwellenwert für kognitive Komplexität auf Branchenstandard (25) eingestellt, 168 Funktionen aufgeteilt
  • cbm_write_db God-Function Split (569 → 325 Zeilen) – Alle NOLINTNEXTLINE-Unterdrückungen beseitigt, iterative AST-Walker
  • Behebung eines ASan-Lecks im semantischen Korpus token_map

CI/CD & Sicherheit

  • Entkoppeltes Sicherheitstor: security-static + CodeQL wird unabhängig ausgeführt, blockiert keine Test-/Build-/Smoke-Pipeline
  • Sicherheitsüberprüfungen für ALLE Binärvarianten (Standard + UI) – zuvor wurden UI-Binärdateien nicht geprüft
  • AV-sicheres Token-Vokabular: 11 heuristisch auslösende Wörter aus Nomic-Einbettungen entfernt
  • CI-Aufteilung in wiederverwendbare Workflow-Komponenten – Vom Anbieter bereitgestellte Abhängigkeitserweiterungen: SQLite 3.51.3, Mongoose 7.21, mimalloc 3.2.8 – Aktionen verschoben: Download-Artefakt v8.0.1, Attest-Sbom v2, Cosign v4.1.1, Msys2 v2.31.0, Checkout v6.0.2, Cache v5.0.4, Upload-Artefakt v7.0.0, Attest-Build-Provenance v4.1.0, Codeql-Aktion v4.35.1

  • @Koolerx – Korrektur der C#-Schnittstellenregistrierung, base_list-Handler, FTS5 BM25-Suche, JS/TS IMPORTS-Auflösung, Kanalschema
  • @dLo999 – CBM_CACHE_DIR konfigurierbares Datenbankverzeichnis, Skip-Update-When-Latest, verschachtelte .gitignore-Unterstützung (#178)
  • @Selene29 – Optimierung der binären Layoutsuche, Korrektur der UTF-8/NaN-Serialisierung
  • @slvnlrt – Korrektur des Windows-PATH-Trennzeichens, Erkennung des Binärpfads zur Laufzeit
  • @jimpark – Korrekturen der Windows-Konfigurationspfade für Zed und VS Code
  • @ahundt – Verknüpfen Sie stillschweigend ignorierte search_graph-Parameter
  • @maplenk – include_tests-Parameter für Trace_path, search_graph-Parameterverdrahtung
