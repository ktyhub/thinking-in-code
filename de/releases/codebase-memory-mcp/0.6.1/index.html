codebase-memory-mcp 0.6.1

📦 Archivierte Release-Seite – Binärdateien für diese Version werden nicht mehr veröffentlicht. Holen Sie sich die neueste Version.

v0.6.1 – 89 neue Sprachen, Cross-Repo-Intelligenz, vom Team gemeinsam genutztes Diagrammartefakt, npm+PyPI-Verteilung

Über 50 Commits seit v0.6.0. Fügt 89 Tree-Sitter-Grammatiken (66 → 155 Sprachen) hinzu, führt Cross-Repo-Intelligenz mit CROSS_*-Kanten ein, versendet vom Team gemeinsam genutzte Diagrammartefakte (.codebase-memory/graph.db.zst), führt vollständige Distributions-Wrapper ein (npm/PyPI/Homebrew/Scoop/Winget/Chocolatey/AUR/Go) mit npm + PyPI, die jetzt automatisch als Teil der Release-Pipeline veröffentlicht werden, und führt umfassende Installationssicherheit ein Härten.

Sprachen und Parsing – 66 → 155

  • 89 neue Tree-Sitter-Grammatiken mit bereinigtem Vokabular, Tokenisierung und Grammatiksicherheits-Audit-Skript
  • Sprachspezifikationsabdeckung für 114 Sprachen mit geeigneten Knotentypen ausgefüllt – Go (func_literal), JS (do_statement, veraltetes case_clause behoben), C#/Python-Importe, gemeinsam genutzte Arrays
  • 77 neue Erweiterungszuordnungstests für die neuen Sprachen
  • C#-, Rust- und Scala-Grammatiken auf den neuesten Upstream aktualisiert
  • lang_specs-Refaktor: designierte Initialisierer + Factory-Zeiger

Cross-Repo-Intelligence

  • CROSS_ Kantentypen* für Repository-übergreifende Abhängigkeiten und Architekturbeziehungen
  • gRPC / GraphQL / tRPC-Diensterkennung mit Protobuf-Routenextraktion
  • gRPC-Stub-Erkennung bei der Anrufauflösung + verkettete Anrufextraktion
  • Multi-Galaxy-UI-Layout + Übersichtsansicht der Cross-Repo-Architektur

Vom Team gemeinsam genutztes Diagrammartefakt

  • .codebase-memory/graph.db.zst – zstd-komprimierter Wissensgraph, der in das Repo übernommen werden kann. Teamkollegen booten vom Artefakt, anstatt eine vollständige Neuindizierung von Grund auf durchzuführen.
  • Verkaufter zstd 1.5.7 (zusammengeführt, ~52K LOC) für 8–13:1-Komprimierung
  • Zweistufiger Export: zstd -9 + Index-Stripping + VACUUM INTO für explizite Indizes (bestes Verhältnis); zstd -3 für Watcher/inkrementelle automatische Updates (geringe Latenz)
  • Importpfad: Dekomprimieren → Integritätsprüfung → Indizes automatisch neu erstellen
  • Auto-Bootstrap in index_repository: Wenn keine lokale Datenbank, aber das Artefakt vorhanden ist, importieren Sie zuerst und führen Sie dann die inkrementelle Indizierung aus – Erstellt automatisch .gitattributes mit merge=ours, um Zusammenführungskonflikte auf dem binären Artefakt zu verhindern

Importe und Kanäle

  • Generische Paket-/Modulauflösung für IMPORTS-Kanten in 10 Sprachen (löst bloße Spezifizierer wie @myorg/pkg, github.com/foo/bar, use my_crate::foo über Manifest-Scannen auf: package.json, go.mod, Cargo.toml, pyproject.toml, composer.json, pubspec.yaml, pom.xml, build.gradle, mix.exs, *.gemspec)
  • Kanalerkennung von JS/TS auf 8 Sprachen erweitert

Verteilung

Jetzt direkt aus öffentlichen Paketregistrierungen installierbar:

npm install -g codebase-memory-mcp     # npm
pip install codebase-memory-mcp         # PyPI
go install github.com/DeusData/codebase-memory-mcp/pkg/go@latest   # Go
  • npm + PyPI Auto-Publish in die Release-Pipeline integriert (publish-registries-Job nach verify, dann entwirft der atomare publish-final das GitHub-Release erst, nachdem beide Registrierungen erfolgreich waren – kein halb ausgelieferter Status) – npm-Paket verwendet --provenance (GitHub OIDC-Build-Bescheinigungen sichtbar auf npmjs.com)
  • Vollständige Vertriebsverpackungen in pkg/ für: npm, PyPI, Homebrew, Scoop, Winget, Chocolatey, AUR, Go

Sicherheitshärtung

  • PyPI-Installer: gehärtet gegen Tar-Slip- und Schema-Confusion-Angriffe (PR #248 von @dLo999, schließt #246)
  • NPM-Installationsprogramm: Prüfsummenüberprüfung, reine HTTPS-Weiterleitungen, keine Shell-Injection
  • Installationsübergreifende Härtung: Unblock-File entfernt, reine HTTPS-URL-Validierung hinzugefügt – vite auf 6.4.2 verschoben – behebt CVE GHSA-4w7w-66w2-5vf9 und GHSA-p9ff-h696-f583
  • Grammatik-Sicherheitsaudit zur Anbieter-Pipeline hinzugefügt
  • README: VirusTotal-Scan-Links (binäre Hashes), SLSA-Abzeichen, Abschnitt Sicherheit und Trust, Haftungsausschluss zur Transparenz, Einladung zur verantwortungsvollen Offenlegung
  • arXiv-Papierabzeichen + Zitat

Stabilität und Qualität

– get_graph_schema stellt jetzt Eigenschaftsdefinitionen pro Knotenbezeichnung bereit

  • sqlite_writer-Überlaufseiten – behebt SIGBUS bei großen Datensätzen (#139)
  • RSS-Rückgewinnung nach delete_project: explizites mem_collect + sofortige Bereinigung
  • MCP-Tools / CLI: verbesserte Fehlerbehandlung, Diagnose und Abbruch
  • Rosinengepflückte Extraktion und Cypher-Verbesserungen aus PR #162

Editor-/Agent-Integration

  • Kiro CLI-Unterstützung (#96)

Plattformkorrekturen

  • Windows: pass_pkgmap verwendet jetzt cbm_strndup (mingw clang fehlt POSIX strndup)
  • test_watcher: Verwendet die Umgebungsvariablen GIT_AUTHOR_*/GIT_COMMITTER_*, anstatt die globale Git-Konfiguration zu ändern

CI / Rauch

  • Analyse des Rauchtests JSON behoben – Der Standardmodus CLI entpackt den MCP-Umschlag; Smoke analysiert jetzt direkt den inneren JSON
  • Zulassungsliste für die Prüfung von Binärzeichenfolgen – Das URI-Schema telnet aus der ersten Grammatik ist als bekanntermaßen harmlose Übereinstimmung dokumentiert

Mitwirkende

Vielen Dank an alle, die zu dieser Veröffentlichung beigetragen haben:

  • @dLo999 – Härtung des PyPI-Installationsprogramms (#248)
