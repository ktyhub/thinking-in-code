Orca v1.4.255

Schnellere Sitzungssuche, Agenten auf Ihrem Telefon und reibungsloserer Chat-Wechsel ✨

Wir haben kurz hintereinander zwei Veröffentlichungen verschickt: 1.4.254 gestern und 1.4.255 heute. Siehe 1.4.254 release notes für Git Graph, Chat-Forks, Diktieren auf dem Telefon, robusteres mobiles Arbeiten sowie Kopplungs- und trust-Verbesserungen.

Etwas weniger Warten, etwas mehr Flow. Dieses Update erleichtert die Suche nach großen Sitzungsverläufen, bringt Ihre Agenten auf Ihrem Telefon zusammen und vereinfacht die alltägliche Arbeit beim Wechseln von Konten, Modellen und Arbeitsbereichen.

  • ⚡ Vergangene Arbeit finden, ohne langsamer zu werden: Suchvorgänge im Sitzungsverlauf werden im Hauptthread der App ausgeführt, die Ergebnisse bleiben während der Eingabe sichtbar und die letzte Liste wird unmittelbar nach einem Neustart angezeigt, während sie aktualisiert wird. Die Suche funktioniert auch auf SSH- und Remote-Server-Hosts.
  • 📱 Ihre Agenten zusammen auf Ihrem Telefon: Auf der neuen Registerkarte „Agenten“ werden die Agenten auf Ihren verbundenen Desktops aufgelistet. Markieren Sie sie als gelesen oder löschen Sie sie aus der Liste, wobei der Aktivitätsstatus vom Desktop bereitgestellt wird. Gespeicherte Aufgabenlisten und Hostbezeichnungen werden früher angezeigt, wenn Sie die App erneut öffnen.
  • 💬 Halten Sie Ihren Chat in Bewegung: Wenn Sie das Codex-Konto wechseln, werden Ihre offenen Codex-Chats auf das Konto Ihrer Wahl verschoben. Forks bewahren den Verlauf des Chats, eingefügter Rich Text behält seine Links und Nachrichten in der Warteschlange werden nach einem Neustart fortgesetzt.
  • 🎛️ Eine klarere Möglichkeit, Ihr Setup auszuwählen: Die Agentengeschwindigkeit beträgt jetzt eine Taste, das Modell-Setup wird mit hervorgehobener aktueller Auswahl geöffnet und die Suche nach „Codex“ bringt den Codex-Agenten vor die Codex-benannten Modelle anderer Agenten – auch wenn Sie die Eingabetaste drücken.
  • 🌳 Machen Sie mehr von Ihrem Standort aus: Schauen Sie sich Git Graph an, wählen Sie Commits aus oder setzen Sie sie zurück. Öffnen Sie die Zweigauswahl direkt über den Zweignamen unter Ihrem Chat-Composer und wählen Sie Ihre nächste Aktion aus einem einfacheren, leeren geteilten Bereich aus.

Highlights

  • Sitzungsverlauf und Leistung: Große Verläufe bleiben reaktionsfähig, während die Suche in einem Worker ausgeführt wird. Arbeitsbereichs- und Projektfilter fragen ihre eigenen Sitzungen ab, unveränderte Verlaufszeilen vermeiden zusätzliches Rendern und Suchindizierung und Profilspeicherungen verursachen weniger Festplattenarbeit.
  • Chat & Agenten: Offene Codex-Chats folgen Kontowechseln, neu installierte Fertigkeiten erscheinen im $-Menü von Codex vor Ihrer ersten Nachricht und Antigravity Chat zeigt installierte Fertigkeiten an. OpenCode 2 beginnt mit dem von Ihnen ausgewählten Modell. Durch das Löschen eines Chats wird das alte Transkript sofort ausgeblendet, und eine fehlgeschlagene Modell- oder Aufwandsänderung wirkt sich eher auf die Nachricht als auf den gesamten Chat aus.
  • Telefon und Remote-Hosts: Die Registerkarte „Agenten“ bringt Aktivitäten auf allen Desktops an einem Ort zusammen. Durch das Vorwärmen werden Seiten schneller geöffnet, Review aktualisiert Zweigvergleiche, wenn sich Git ändert, und die Dateivorschau-Wiederherstellungsleiste bleibt über der Tastatur. Eine blockierte LAN-Wiederverbindung kann auf Relay zurückgreifen und wieder aufgenommene VMs behalten ihre Gerätepaarung bei, wenn der Hostschlüssel unverändert bleibt.
  • Arbeitsbereiche und Quellcodeverwaltung: Git Graph erhält Checkout-, Cherry-Pick- und Revert-Aktionen. Sie können berechtigte untergeordnete Arbeitsbereiche beibehalten, wenn Sie einen übergeordneten Arbeitsbereich löschen, einen Arbeitsbaum für jedes Repository aus einem leeren Ordnerarbeitsbereich erstellen und in einen separaten Ordner klonen, wenn ein Repository-Name bereits vergeben ist. Der Seitenleistenteiler passt die Größe der Seitenleiste zuverlässig an.
  • Browser, Editor und Terminal: Remote-Browser-Tabs zeigen Site-Favicons an, Website-Links werden in neuen Tabs geöffnet und der CLI kann installierte Browser-Erweiterungen auflisten und neu laden. PDFs passen auf die Breite des Vorschaufensters. Terminalfenster erklären, wann ein anderes Fenster ihre Größe beibehält, und bieten eine Möglichkeit, dies rückgängig zu machen.
  • Alltäglicher Feinschliff: Lange Einstellungslisten verwenden durchsuchbare Auswahlmöglichkeiten, ältere Chatnachrichten zeigen Daten an und Live-Agenten bleiben im Ungelesen-Filter sichtbar. Diese Version behebt außerdem veraltete Browser-, lineare Symbolleisten- und Verwendungs-Tooltip-Anzeigen sowie den ersten Tastendruck der Eingabetaste nach dem Deaktivieren des japanischen IME.
