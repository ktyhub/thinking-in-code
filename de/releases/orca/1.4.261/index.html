Orca v1.4.261

Vorherige Version: 1.4.259 – Wesentliche Leistungsverbesserungen, automatische Bereinigung und fokussierte Subagentenansichten.

Wesentliche Leistungsverbesserungen, Cursor-Chat und ein anpassbares +-Menü ✨

Orca 1.4.261 macht geschäftige Chat-Workflows reaktionsschneller und gibt Speicher von Browserseiten frei, die Sie stundenlang nicht verwendet haben. Der Cursor tritt dem Chat bei und ein anpassbares +-Menü macht Ihre bevorzugten Möglichkeiten zum Öffnen von Tabs in Reichweite.

  • ⚡ Wechseln Sie zwischen geschäftigen Chats mit weniger Wartezeit: Lange Konversationen laden ihren Verlauf in Seiten und Hintergrundantworten machen in der Seitenleiste und versteckten Chats weniger Arbeit, wenn Sie zwischen Konversationen wechseln.
  • 🌐 Behalten Sie Browser-Tabs bei, ohne dass jede Seite geladen bleibt: Memory Saver gibt standardmäßig berechtigte Seiten frei, nachdem sie vier Stunden lang nicht angezeigt wurden, und lädt sie dann neu, wenn Sie zurückkehren. Websites, die Sitzungscookies verwenden, können Sie auch über Neustarts hinweg angemeldet halten.
  • 🤖 Cursor im Chat verwenden: Beginnen Sie mit der Cursor-Anmeldung auf Ihrem Computer, wählen Sie ein Modell, einen Aufwand und eine Schnelligkeit aus, genehmigen Sie Befehle und öffnen Sie die Konversation später erneut.
  • ➕ Machen Sie das +-Menü zu Ihrem eigenen: Verwenden Sie das Zahnrad neben der neuen Symbolzeile, um Aktionen neu anzuordnen, nicht verwendete Auswahlmöglichkeiten auszublenden und Verknüpfungen festzulegen. Versteckte Aktionen bleiben über die Suche und ihre Verknüpfungen verfügbar.
  • ⌨️ Terminalarbeit genau vorantreiben: Kontext kopieren, verzweigen und fortfahren, von Terminalprogrammen gezeichnete Leerzeichen beibehalten. Bearbeiten → Einfügen zielt auf den geteilten Bereich ab, der tatsächlich den Fokus hat.

Highlights

  • Mehr Platz für aktives Arbeiten: Memory Saver gilt auch für Browser-Registerkarten auf einem aktualisierten orca serve-Host. Desktop-Registerkarten behalten ihren Titel, Verlauf, Cookies und gespeicherten Site-Daten. Unter „Einstellungen“ → „Browser“ können Sie das Leerlaufintervall ändern oder den Speichersparmodus deaktivieren.
  • Mehr Agentenoptionen: Antigravity Chat funktioniert unter Windows und Pi Chat zeigt Subagenten an. Gewöhnliche Orca CLI-Befehle verhindern den Start von Electron auf unterstützten Macs; macOS 13.4 behält den vorhandenen Launcher bei.
  • Arbeitsbereiche auf einen Blick: Experimentelle Arbeitsbereichskarten zeigen Aktivitäten, ungelesene Ergebnisse, Fehler und Offline-Hosts. Wählen Sie „Klassisch“ oder „Experimentell“ aus den Arbeitsbereichsoptionen. Agenten, deren Fenster sich im Ruhezustand befinden, zeigen weiterhin „Fertig“ an.
  • Telefonnavigation: Die gekoppelte Telefonschnittstelle erhält Desktop-Projektgruppen und eine gemeinsame Browsereinstellung für Chat- und Terminal-Links, einschließlich „Jedes Mal fragen“. Übernehmen Sie auf dem Desktop alle Kontrolle über die vom Telefon gesteuerten Browser-Registerkarten.

Kompatibilitäts- und Upgrade-Hinweise

  • Chat-Verlauf: Vorhandene Chats werden im Hintergrund oder beim ersten Öffnen in den neuen Store konvertiert. Die ursprünglichen Chatdateien bleiben in dieser Version erhalten. Nach einem Downgrade und einem erneuten Upgrade werden Chats, die in der älteren Version fortgesetzt wurden, wiederhergestellt; Eine zuvor konvertierte Konversation kann neben ihrer neueren Version als zweiter Chat angezeigt werden.
  • Browser lädt neu: Freigegebene Seiten werden an Ort und Stelle neu geladen; Scrollposition und Nur-Seiten-Speicher können zurückgesetzt werden. Desktop Memory Saver lässt Seiten geladen, wenn es nicht gespeicherte Änderungen erkennt oder diese nicht sicher beurteilen kann. Die Einsparungen hängen davon ab, welche Seiten qualifiziert sind.
  • Android: Die Legacy-App weist Benutzer an, das neue dev.orca.app separat zu installieren; Es kann nicht in das neue Paket aktualisiert werden. Diese Desktop-Version installiert keine Telefon-App.
  • Fertig gestellte Agenten: Zeilen verlassen Arbeitsbereichskarten, die Agentenliste und das Dashboard, wenn der Prozess beendet wird oder sein SSH-Host die Verbindung trennt. Schlafende Fenster behalten ihren Status „Fertig“.
