Orca v1.4.263

Vorherige Version: 1.4.262 – Schnelleres Chat-Wechseln, geringere Speichernutzung und Git-Schuld.

Leichterer Chat-Start, Hermes in Chat und Browser-Erweiterungsseitenfelder ✨

Öffnen Sie Arbeitsbereiche voller Chats mit weniger Speicherverbrauch und weniger Startaufwand erneut. Die wiederhergestellten Chat-Oberflächen werden geladen, wenn sie zum ersten Mal angezeigt werden, und Orca schreibt beim Start nicht mehr jede gespeicherte Konversation neu. Geöffnete Chats behalten ihre Entwürfe und Scrollposition, wenn Sie zurückkehren.

  • 💬 Hermes-Konversationen im Chat fortsetzen: Starten Sie Hermes über das Menü „Neuer Tab“ oder wählen Sie In neuem Chat fortsetzen in einem Sitzungsverlaufseintrag, um eine Terminalkonversation in ihrem ursprünglichen Arbeitsbereich und Profil fortzusetzen.
  • 🌐 Erweiterungen neben Ihrer Seite behalten: Chrome-Erweiterungen, die Seitenbereiche verwenden, können jetzt in einem größenveränderbaren Bereich im Browser von Orca geöffnet werden. Cliklicken Sie auf die Symbolleistenschaltfläche der Erweiterung, um deren Bedienfeld beim Surfen zu verwenden. Erweiterungs-Popups akzeptieren auch Einfügen, Kopieren und Alles auswählen.
  • 🖥️ Erreichen Sie Ihre Remote-Arbeit: Verwaltete SSH-Ports verfügen jetzt über eine Schaltfläche Weiterleiten. Unter Windows können Projekte, die über einen zugeordneten WSL-Laufwerksbuchstaben geöffnet wurden, auf den WSL-Host ihrer Distribution verschoben werden.
  • ⌨️ Terminalausgabe nach einem Neustart im Blick behalten: Unter macOS und Linux kann ein Terminal, dessen Shell angehalten wurde, seine gespeicherte Ausgabe mit der neuen Eingabeaufforderung darunter wiederherstellen. Windows behält sein bestehendes Wiederherstellungsverhalten bei.

Highlights

  • Linear über die Befehlszeile verbinden: orca linear connect akzeptiert einen API-Schlüssel über stdin und verbindet den Zielhost, einschließlich eines Headless-Servers. Jeder Host behält seine eigene Verbindung. Lineare Problem- und Projektlisten geben jetzt alle Ergebnisse zurück, wenn Sie --limit weglassen.
  • Agenten unter Windows einrichten: Claude- und Codex-Chats bieten Installieren, wenn der Agent fehlt, und dann Erneut prüfen, um die Installation zu erkennen. orca agent installed listet auch aktivierte Agenten CLIs auf dem aktuellen Host für Skripts und Start-Setup auf.

Kompatibilitäts- und Upgrade-Hinweise

  • Hermes: Chat erfordert Hermes 0.23.0 oder höher auf dem Computer, auf dem der Arbeitsbereich ausgeführt wird. Bei sehr langen Importen werden aktuelle Nachrichten angezeigt, während Hermes die gesamte Konversation behält. Chat ist für SSH-Arbeitsbereiche nicht verfügbar; Ein gekoppelter Orca-Server unterstützt dies. Der erste Chat nach dem Stoppen des Hermes-Gateways kann eine Minute dauern.
  • Browseridentität: Nativ ist jetzt die Standardeinstellung und behebt die Cloudflare-Verifizierungsschleife, die bei der vorherigen Standardeinstellung aufgetreten ist. Explizite Identitätsentscheidungen bleiben erhalten; Ändern Sie Ihre Identität unter Einstellungen → Browser → Browseridentität.
  • Telefonaktualisierungen: Die unten aufgeführten Änderungen an der Benutzeroberfläche des Telefons erfordern einen entsprechenden mobilen Build. Dieses Desktop-Update aktualisiert keine Android- oder iOS-Apps.

Bekannte Probleme

  • Stattdessen Arbeitsbereich in den Ruhezustand versetzen: Die Option kann fehlschlagen, wenn auf einer anderen Registerkarte in diesem Arbeitsbereich ein Prozess ausgeführt wird.
  • orca agent installed --worktree: Die Befehlsfehler in SSH- und Paired-Server-Arbeitsbereichen.
