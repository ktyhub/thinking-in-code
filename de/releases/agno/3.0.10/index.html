agno v3.0.10

Changelog

Neue Funktionen:

– Azure OpenAI-Antworten: AzureOpenAIResponses hinzugefügt, um die Antworten API mit Azure OpenAI-Bereitstellungen zu verwenden. Siehe Kochbuch.

  • Elasticsearch: Elasticsearch-Vektordatenbank mit Vektor-, Schlüsselwort- und Hybridsuche hinzugefügt. Siehe Kochbuch.
  • DocumentationMarkdown: transform für Knowledge.sync_pages hinzugefügt, das Mintlify- und Fumadocs-Komponenten in einfachen Markdown umwandelt. Siehe Kochbuch.

Verbesserungen:

  • MCPConfig: root_host, path und path_aliases hinzugefügt, um MCP auf einem dedizierten Hostnamen oder einem benutzerdefinierten Endpunktpfad bereitzustellen.
  • MCP-Serverkarte: /mcp/server-card gibt jetzt hübsch bedruckte JSON zurück.

Fehlerbehebungen:

  • MCP-Tools: Behalten Sie AudioContent aus den MCP-Tool-Ergebnissen als Audioartefakte bei.
  • Slack: Ereigniswiederholungen durch event_id deduplizieren, anstatt sie zu verwerfen.
  • Remote-Agenten: RemoteAgent.role und RemoteTeam.role sind jetzt Eigenschaften, die die Rolle anstelle einer gebundenen Methode zurückgeben; Verwenden Sie .role, nicht .role().
  • Leser: TextReader, MarkdownReader und FieldLabeledCSVReader akzeptieren jetzt Textstreams.
  • PPTXReader: Text in gruppierten Formen lesen.
  • JSONReader: async_read() verwendet jetzt den asynchronen achunk() der Chunking-Strategie.
  • Chunking: Behalten Sie Zeilenumbrüche und Tabulatoren beim Bereinigen von Text vor dem Chunking bei.
  • CSVReader: async_read() behält jede Datenzeile seitenübergreifend mit RowChunking(skip_header=True).
  • SitemapReader: Behalten Sie Dateinamen wie myindex.html bei und setzen Sie die Suche über eine ungültige .xml.gz-Sitemap hinaus fort.
  • Tools und Workflows: Behalten Sie falsche Werte wie 0, False und [] in den Ergebnissen des Synchronisierungstools und den Workflow-Schrittausgaben Parallel bei.
  • agnoctl: agno connect liest und schreibt jetzt client-Konfigurationen als UTF-8 (agnoctl 0.2.1).
  • DynamoDB: Boolesche Werte als native BOOL-Werte serialisieren.

Breaking Changes:

  • CodingTools: run_shell ist jetzt optional (enable_run_shell=True) und im eingeschränkten Modus werden Befehle ohne Shell ausgeführt.
  • PublicSurface: Mit authorization=True und PublicSurface(mcp=True) akzeptiert MCP jetzt standardmäßig nur localhost; Fügen Sie Ihre Domain zu MCPConfig(allowed_hosts=[...]) hinzu.
