d2 v0.7.0

Funktionen 🚀

  • Symbole:
    • Verbindungen können Symbole enthalten #12
  • Syntax:
    • suspend/unsuspend zum Definieren von Modellen und deren Instanziierung #2394
  • Kugeln: – Unterstützung für das Filtern von Kanten basierend auf Eigenschaften von Endpunktknoten (z. B. &src.style.fill: blue) #2395
    • level-Filter implementiert #2473
  • Rendern:
    • Markdown, Latex und Code können als Objektbezeichnungen verwendet werden #2204
    • shape: c4-person, um die Form einer Person so darzustellen, wie es das C4-Modell vorschreibt #2397
  • Symbole:
    • Der Randradius sollte mit dem Symbol #2409 funktionieren.
  • Sonstiges:
    • Diagrammlegenden sind implementiert #2416

Verbesserungen 🧹

  • CLI:
    • Unterstützt den Befehl validate. #2415
    • Der Überwachungsmodus ignoriert Sicherungsdateien (z. B. Dateien, die von bestimmten Editoren wie Helix erstellt wurden). #2131
    • Unterstützung für die --omit-version-Flagge. #2377 – Groß-/Kleinschreibung wird bei Plugin-Namen ignoriert #2486
  • Compiler:
    • links können auf den Root-Pfad eingestellt werden, z.B. /xyz. #2357 – Versuchen Sie beim Importieren einer Datei zunächst, Ersetzungen im importierten Dateibereich aufzulösen #2482
    • Farbverlaufsstopps validieren. #2492
  • Parser:
    • Maximale Schlüssellänge festlegen. Es ist mit ziemlicher Sicherheit ein Fehler, wenn eine ID zu lang wird, z. B. fehlende Anführungszeichen #2465
  • Rendern:
    • Horizontaler Abstand für Verbindungsbeschriftungen hinzugefügt #2461

Fehlerbehebungen ⛑️

  • Compiler: – Behebt Panik, wenn der Formwert sql_shape eine gemischte Groß-/Kleinschreibung hatte #2349
    • Behebt Panik beim Importieren aus einer Datei mit Spread-Ersetzungen in vars #2427 – behebt die Unterstützung für center in d2-config #2360
    • Behebt Panik, wenn Kommentarzeilen in Arrays erscheinen #2378
    • behebt Inkonsistenzen, wenn Objekte in doppelte Anführungszeichen gesetzt wurden #2390 – Behebt, dass Globs nicht auf Spread-Ersetzungen angewendet werden #2426
    • Behebt Panik, wenn Klassen falsch mit Ebenen gemischt wurden #2448
    • Behebt Panik, wenn Verlaufsfarben im Skizzenmodus verwendet werden #2481 – Behebt Panik bei Verwendung von Glob-kaufmännischen Und-Filtern mit zusammengesetzten Werten #2489
    • Behebt den Blatt-kaufmännischen Und-Filter bei Verwendung mit Importen #2494
  • Formatierer:
    • behebt Ersetzungen in Anführungszeichen, die von Text umgeben sind #2462
  • CLI:
    • Remote-Bilder des Mimetyp-Oktett-Streams korrekt abrufen und rendern #2370
  • Zusammensetzung:
    • Spread-Importszenarien/-schritte wurden nicht korrekt geerbt #2460
    • Importierte Felder wurden nicht mit aktuellen Feldern/Kanten zusammengeführt #2464
  • Abschlag: – Behebt, dass verschachtelte Variablenersetzungen nicht funktionieren #2456

Die neuesten d2.js-Änderungen finden Sie im separaten changelog.
