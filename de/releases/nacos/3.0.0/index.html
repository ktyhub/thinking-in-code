nacos 3.0.0

3.0.0 (25. April 2025) Diese Version ist eine GA-Version von 3.0.0. In dieser Version basiert Nacos auf Nacos 3.0.0-BETA zur Unterstützung der MCP-Verwaltung (Model Content Protocol). In dieser 3.0.0 GA-Version wird Nacos diese wichtigen Funktionen und Änderungen vornehmen:

  1. APIs werden in verschiedene Typen eingeteilt, und verschiedene Arten von APIs verwenden unterschiedliche Standardauthentifizierungsstrategien.
  2. Nacos-Konsolenauthentifizierung aktiviert und bei der ersten Bereitstellung mehr Konfigurationseinstellungen erforderlich.
  3. Die Benutzeroberfläche der Nacos-Konsole verwendet die neue Version 3 der Konsole API, ersetzt die alte Version 1 API und deaktiviert standardmäßig die alte Benutzeroberfläche der alten Version 1 API.
  4. Der Standard-Namespace public ändert seine ID von „(empty string) to public“.
  5. Unterstützen Sie das xDS-Protokoll direkt. Derzeit werden EDS, LDS, RDS und CDS unterstützt.
  6. Aktualisieren Sie spring boot auf 3.4.1 und aktualisieren Sie die JDK-Version auf 17.
  7. Fügen Sie eine Seriennummer von ADMIN API für Nacos 3.0 hinzu, damit der Betreuer und die benutzerdefinierte Konsole die Daten von Nacos verwalten und abrufen können.
  8. Unterstützt die unabhängige Bereitstellung der Nacos-Konsole. Einige Konfigurationen des Nacos-Servers und der Nacos-Konsole wurden geändert. Bitte überprüfen Sie applciation.properties, bevor Sie ein Upgrade durchführen.
  9. Unterstützung der MCP-Verwaltung (Model Content Protocol).
  10. Unterstützt verteilte Sperren für experimentelle Funktionen.
  11. Unterstützt experimentelle Fuzzy-Listen-Dienste und -Konfigurationen. Detailänderungen in 3.0.0 siehe:
