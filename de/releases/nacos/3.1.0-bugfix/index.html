nacos 3.1.0-bugfix

Während der Veröffentlichung von Nacos 3.1.0 veröffentlichte das offizielle MCP-Team eine neue Version des Registrierungsprotokolls (16.09.2025). Nacos 3.1.0 hat die Anpassung an dieses Protokoll zügig abgeschlossen. Um diese Funktion nutzen zu können, laden Sie bitte das neueste Nacos 3.1.0-Release-Paket und die Docker-Bilder herunter. Diese Version ist eine neue Millstone-Version und behebt einige Fehler von 3.1.0-BETA. In 3.1.0 folgen Nacos dem neuen offiziellen MCP-Registrierungsprotokoll. Alle Benutzer können Nacos als private Bereitstellung der offiziellen MCP-Registrierung verwenden, um ihren eigenen privaten Markt oder ihre eigene Registrierung für MCP-Server aufzubauen. Nacos unterstützt auch den Import von MCP-Servern über die MCP-Serverspezifikation json und unterstützt automatische Get-Tools über die MCP-URL. Diese beiden neuen Funktionen verbessern die Benutzerfreundlichkeit beim Erstellen von MCP-Servern in Nacos. Außerdem unterstützt diese Version den vom Benutzer aktivierten/deaktivierten MCP-Server in der Konsole und unterstützt Verschlüsselungs-MCP-Tools-Schemata für die Speicherung mit dem Konfigurations-Verschlüsselungs-Plugin. Darüber hinaus unterstützt Nacos in dieser Version die A2A-Registrierung, die es Benutzern oder Agent-Frameworks wie Spring AI Alibaba ermöglicht, AgentCard und Agent-Endpunkt zu veröffentlichen und zu erkennen. Unterstützt derzeit nur die Erkennung anhand des Namens des Agenten. Nacos wird in Zukunft die Entdeckung anhand von Fähigkeiten, Tags oder Beschreibungen unterstützen. Weitere Änderungen bestehen darin, viele vor den Versionen gefundene Fehler zu beheben und einige Abhängigkeiten zu aktualisieren. Es gibt eine Blockänderung von 3.1.0-BETA. Wenn Sie die Version von 3.1.0-BETA aktualisieren, löschen Sie bitte vor dem Upgrade alle AgentCards oder löschen Sie nach dem Upgrade alle Konfigurationsgruppen mit agent und agent-version. Und veröffentlichen Sie es erneut für AgentCards. Bei einem Upgrade von anderen Versionen kann dies ignoriert werden. Detailänderungen in 3.1.0 siehe:

Funktion

[#12191] Namespace-Existenzprüfung hinzugefügt. [#13322] Unterstützt die A2A-Registrierung. [#13423] Unterstützt aktivierten oder deaktivierten MCP-Server in der Konsole. [#13543] MCP-Server-Importfunktion mit Registrierungsunterstützung hinzugefügt. [#13783] Konfigurationsmetadaten-Update-Administrator api hinzufügen. [#13808] Unterstützung des offiziellen mcp-Registrierungsprotokolls hinzugefügt. [#13814] Unterstützt die Eingabeaufforderungsverschlüsselung für MCP-Tools.

Erweiterung/Refaktor

[#13777] Verbessern Sie die Logik zur Überprüfung der Existenz von Namespaces, um die Codequalität zu verbessern. [#13829] Verbessern Sie den Hinweis, wenn der doppelte Name des Agenten veröffentlicht wird.

BugFix

[#13744] Korrektur des ausgelassenen CONFIG_INFO_GRAY_WRAPPER_ROW_MAPPER für das Konfigurationsdatenquellen-Plugin. [#13752] NPE behoben und InterruptedException-Stapelprotokoll ignoriert. [#13761] Korrektur der Validierung beim Löschen von Rollen, um Probleme wie das versehentliche Löschen von ROLE_ADMIN zu verhindern. [#13767] Dienst NullPointerException behoben, wenn K8S getSpec(). [#13773] Behebung von Protokoll-Schrägstrichen beim Erstellen von von MCP OpenAPI abgeleiteten URLs. [#13779] Behebung der Einschränkung bei der Bearbeitung der Beschreibung des Mcp-Tools. [#13787] Fehler behoben, bei dem die Nacos Mcp-Konsole OpenApi-Dateien nicht korrekt analysieren konnte. [#13801] Fehler behoben, der dazu führte, dass beim Parsen der OpenAPI-Datei-URL in der MCP-Konsole manchmal verstümmelte Zeichen angezeigt wurden. [#13810] Fehler behoben, der beim Veröffentlichen von Konfigurationen zu einer inkonsistenten Leistung zwischen Derby- und MySQL-Datenbanken führte. [#13824][#13826] AI gRPC-Ressourcenparser behoben und Authentifizierungsanmeldung für MCP/A2A-Anfrage in nacos-client verloren gegangen. [#13830] Problem mit der Beurteilung des AgentCard-Abonnements behoben. [#13832] Die Korrektur der Unschärfesuche kann zu unerwarteten Ergebnissen führen.

Abhängigkeiten

[#13385] Aktualisieren Sie die os-maven-plugin-Version auf 1.7.1. [#13711] Aktualisieren Sie die spring boot-Version auf 3.4.9. [#13753] Aktualisieren Sie die grpc-Version auf 1.75.0. [#13825] Jraft-Version auf 1.3.15.bugfix aktualisieren.
