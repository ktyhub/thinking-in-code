nacos 3.0.1

Die Release-Assets wurden auf 3.0.1.1 aktualisiert. Der Download der Assets aus dieser Version ist mit der Version 3.0.1.1 identisch. Diese Version basiert auf der 3.0.0-Version und bietet Unterstützung für die Multi-Namespace-Verwaltungsfunktionen und Multi-Versions-Verwaltungsfunktionen von MCP. Die Nacos-Community hat zum MCP Registry API-Standard beigetragen und ist die erste, die den Standard [MCP Registry API] (https://github.com/modelcontextprotocol/registry/blob/main/api/openapi.yaml) implementiert. Bei der Bereitstellung von Nacos 3.0.1 kann die Standard-MCP-Registrierung API durch Setzen des Parameters nacos.ai.mcp.registry.enabled=true aktiviert werden, und der Parameter nacos.ai.mcp.registry.port (Standard 9080) gibt den Port für die MCP-Registrierung API an. Da die MCP Registry API zusätzliche Ports und Ressourcen benötigt, bleibt sie in Standardkonfigurationen standardmäßig deaktiviert. Aufgrund von Änderungen im offiziellen MCP Registry API-Standard wurden Metadatendefinitionen für MCP Server aktualisiert, was zu potenziell inkompatiblen Datenstrukturänderungen führen kann. Ein Upgrade von der Version 3.0.0 auf 3.0.1 kann dazu führen, dass die Konsole beim Lesen von Daten von früheren MCP-Servern fehlschlägt. Die Nacos-Community hat ein Migrationstool bereitgestellt, das vorhandene MCP-Server nach der Ausführung in den Standard-Namespace public verschiebt. Detaillierte Anweisungen zur Verwendung des Migrationstools mcp-migration-tool.jar finden Sie in der Dokumentation. Da die MCP-Registrierung API nun fertiggestellt ist, hat sich die Datenstruktur von MCP Server stabilisiert und gewährleistet die Abwärtskompatibilität in zukünftigen Versionen. Neben neuen Funktionen optimiert diese Version anfängliche Passwortabfragen und Startskripte für Windows-Systeme und behebt außerdem mehrere Fehler, die in der 3.0.0-Version vorhanden waren. Detailänderungen in 3.0.1 siehe:

Feature/Refactor

[#13356] Unterstützt mehrere Namespaces für die MCP-Funktion. [#13377] Unterstützt MCP-Registrierung api im Nacos-MCP-Modul. [#13401] Versionscontroller für MCP-Server unterstützen.

Erweiterung/Refaktor

[#13335] Erweitern Sie die Datei „startup.cmd“ von Windows, um doppelte Hinweise für „secret.token.key“ zu reduzieren. [#13348] Hinweise zur Passwortinitialisierung verbessert.

BugFix

[#13249] Behebung der Inkompatibilität der Rückgabe des Konfigurationsänderungs-Plugins. [#13267] Fix kann keinen Dienst löschen, der unzulässige Zeichen enthält. [#13273] Korrigiert, dass der Cluster client nicht die nacos.remote.client.grpc-Konfiguration verwendet. [#13321] prometheus-Metriken behoben. api kann das Problem nicht akzeptieren. [#13345] Fix apiClient readTimeout muss Null sein. [#13368] Fix: Der Namespace kann in der Konsolen-Benutzeroberfläche nicht gelöscht werden. [#13405] Problem mit der Listenkonfiguration mit dem Standard-Namespace behoben. [#13413] Hinweisproblem für mcp stdio-Server behoben.
