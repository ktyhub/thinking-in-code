  • Selbstgehosteter Läufer: Es wurde ein claude geändert, bei dem ein Wrapper-Skript ausgeführt wird, bevor der eigene claude der Sitzung aktiv ist oder nachdem er beendet wurde, sodass es keinen von Anthropic verwalteten Git gibt – Selbstgehosteter Läufer: CLAUDE_RUNNER_SESSION_UUID und CLAUDE_CODE_REMOTE_SESSION_UUID wurden so geändert, dass sie beide für die Sitzung und ihre Hooks checkout, post-session und spawn-runner festgelegt werden – Selbstgehostete Läufer bei --capacity 1 wurden so geändert, dass sie eine Sitzung früher ablehnen, wenn der Pfad eines Repositorys, zu dem sie pushen, ein symbolischer Link ist – [VSCode] Es wurde eine Benachrichtigung hinzugefügt, wenn eine Nachricht aus einer anderen Sitzung gehalten wird, mit einem Link zur Einstellungsdatei, die dies zulassen kann
