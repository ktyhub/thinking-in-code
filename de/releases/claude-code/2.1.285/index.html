Claude-Code v2.1.285

Was hat sich geändert?

– Umgebungsvariable CLAUDE_CODE_DISABLE_WEB_FETCH hinzugefügt, um das WebFetch-Tool zu deaktivieren

  • claude -p mit CLAUDE_CODE_FORK_SUBAGENT=1 behoben: Der eigene Agentenaufruf eines Subagenten läuft jetzt im Vordergrund, sodass der Subagent das Ergebnis des untergeordneten Agenten erhält – Problem behoben, bei dem Plugin- und Marketplace-Installationen und -Updates über SSH das in GIT_SSH oder in core.sshCommand Ihrer Git-Konfiguration festgelegte SSH-Programm ignorierten – Problem behoben, bei dem Claude Code den Start verweigerte, wenn das Betriebssystem das Lesen der verwalteten Einstellungsdatei verweigerte; Es gibt jetzt eine Warnung aus und startet ohne die Richtlinien dieser Datei.
