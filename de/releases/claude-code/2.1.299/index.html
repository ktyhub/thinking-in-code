Claude-Code v2.1.299

Was hat sich geändert?

  • Umgebungsvariable CLAUDE_CODE_DISABLE_FILE_MENTIONS hinzugefügt: Claude ruft die Pfade der @-Dateierwähnungen ab, die mit seinen Dateitools gelesen werden sollen, nicht den Inhalt der Dateien
  • Leerlaufkomprimierung im Terminal hinzugefügt: Eine Konversation mit mehr als 200.000 Token, die etwa 54 Minuten lang inaktiv bleibt, wird komprimiert, bevor der einstündige Prompt-Cache abläuft, sodass Ihre nächste Nachricht nicht alles erneut verarbeitet – CLAUDE_CODE_IDLE_COMPACT_MIN_TOKENS hinzugefügt, um das 200-KByte-Token-Minimum der Leerlaufkomprimierung zu ändern; "idleCompaction": false in den Einstellungen.json schaltet es aus. Beide benötigen v2.1.290 oder höher – $.prompt.media hinzugefügt, damit ein prompt.submit-Hook eines durch verwaltete Einstellungen installierten Mods die Bytes eines an die Eingabeaufforderung angehängten Bilds oder Dokuments lesen kann
  • $.session.identity() für Mods hinzugefügt, die durch verwaltete Einstellungen installiert wurden: wie die Sitzung angemeldet ist und ihre Organisation und E-Mail, wenn verwaltet forceLoginOrgUUID diese Organisation auflistet
  • size, weight, mono und tabular zum Text eines Mods hinzugefügt und Abstandsschritte (xs bis xl) zu seinem Box hinzugefügt; bold ist zugunsten von weight veraltet
  • --shutdown-drain-sec zu claude self-hosted-runner orchestrator hinzugefügt: Bei SIGTERM stoppt es die Abfrage und gibt die Abfrage im Flug und beim Ausführen von Spawn-Hooks bis zu dieser Anzahl von Sekunden bis zum Abschluss

B.   • claude plugin test wurde so geändert, dass ein Aufruf der von einem Mod bereitgestellten $-Methode fehlschlägt, wenn nicht innerhalb von zehn Sekunden geantwortet wird, wie dies bei einer Sitzung der Fall ist – Geänderte MCP-Regeln, die zulassen, dass Regeln nur den von ihnen benannten Server erreichen: mcp__a lässt einen Server mit dem Namen a__b oder a_ nicht mehr zu; Schreiben Sie mcp__<server>__* mit dem gesamten normalisierten Namen des Servers – Die Listen des Agenten tools: wurden so geändert, dass nur die Tools des genannten MCP-Servers verwendet werden.
