Claude-Code v2.1.330

Was hat sich geändert?

– Anmeldung für Organisationen hinzugefügt, die in der Enterprise Admin Console von Anthropic verwaltet werden: Nach claude auth login wendet Claude Code die Einstellungen der Organisation an und verwendet deren Cloud-Anbieter oder Gateway

  • Selbstgehosteter Läufer: --start-dir / SELF_HOSTED_RUNNER_START_DIR hinzugefügt, damit Claude seine Arbeit in einem Ordner eines Repositorys startet, während Einstellungen und Hooks wie ohne geladen werden – In Cloud- und selbstgehosteten Runner-Sitzungen wurde ein Hinweis hinzugefügt, wenn ein Plugin-Marktplatz nicht abgerufen werden kann, weil sein Repository nicht zu den Sitzungen gehört
  • Selbstgehosteter Runner: Es wurde ein Hinweis hinzugefügt, wenn ein von Anthropic verwalteter Git das eigene Repository eines Plugins ablehnt, mit Angabe des Plugins und was zu tun ist – commandPrinted zu claude plugin install --json-Ergebnissen hinzugefügt, wahr, wenn der Installationsbefehl des Plugins in stderr schrieb, und commandFailed, wenn es mit einem Fehler beendet wurde, abgebrochen wurde oder eine Zeitüberschreitung auftrat – claude_code_self_hosted_runner_order_to_registered_seconds zum /metrics des selbstgehosteten Läufers hinzugefügt: Sekunden von der Arbeitsauftragserteilung bis zur akzeptierten Registrierung, bei vom Orchestrator erzeugten Läufern
