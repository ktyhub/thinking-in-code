Claude-Code v2.1.323

Was hat sich geändert?

  • Code-Modus hinzugefügt, ein experimentelles Opt-In, bei dem Claude JavaScript schreibt, um seine Tools aufzurufen; Informationen zum Aktivieren oder Deaktivieren für eine Organisation finden Sie unter https://code.claude.com/docs/en/code-mode
  • engines["claude-code"] zu plugin.json hinzugefügt: Plugins außerhalb ihres angegebenen Claude-Code-Versionsbereichs werden nicht installiert, aktualisiert oder geladen, und bei Installation und Aktualisierung wird die neueste Version ausgewählt, die passt
  • Typprüfung des TypeScript-Hooks-Moduls eines Plugins zu claude plugin validate hinzugefügt; Jeder Befund ist eine Warnung, und --strict schlägt dabei fehl
  • Zu claude plugin validate wurden die $-Substantive hinzugefügt, die der engine.create-Hook eines Mods hinzufügt, zurückhält oder ersetzt – Unterstützung für CLAUDE_CODE_AUTO_MODE_MODEL in verwalteten Einstellungen für Claude Desktop-Sitzungen bei Drittanbietern hinzugefügt (wird wirksam, sobald Claude Desktop diese Version enthält)
  • Ein Optionsmenü hinzugefügt (Stopp, Wechsel zu Nutzungsguthaben, Upgrade), wenn ein Modell Nutzungsguthaben benötigt, die deaktiviert oder aufgebraucht sind – Es wurde alle 30 Sekunden ein Fortschritts-Heartbeat hinzugefügt, während Hooks in claude -p- und SDK-Sitzungen lange laufen, sodass ein Host wie Claude Desktop die Runde nicht als hängengeblieben beendet (sobald er diese Version enthält). – .docx-Unterstützung für Asset-Uploads des Artifact-Tools hinzugefügt
