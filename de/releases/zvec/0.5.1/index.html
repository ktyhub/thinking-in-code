🚀 Zvec v0.5.1 Release Notes

📦 Neue Funktionen

  • Externe Vektorquelle: Unterstützung für die Verwendung externer Vektorquellen hinzugefügt, was flexiblere Datenerfassungs- und -abruf-Workflows ermöglicht. (#490)
  • Zero-Copy-Vektorabfragepfad: VectorViewClause hinzugefügt, um einen Zero-Copy-Abfragepfad und eine einheitliche Vektorabfragevalidierung zu unterstützen. (#478)
  • Such-Prefetch-Konfiguration: Unterstützung für die Übergabe der Prefetch-Konfiguration (PO und PL) über Suchparameter hinzugefügt. (#482)
  • Index-Dirty-Status: is_dirty über die Kernschnittstelle Index verfügbar gemacht, damit Aufrufer überprüfen können, ob für einen Index ausstehende Änderungen vorliegen. (#488)
  • Speicher-MMAP-Optionen: Offengelegte Copy-on-Write-mmap-Konfiguration und korrigierte Platzierung des MMAP_POPULATE-Flags. (#480)
  • C API FTS-Unterabfrageunterstützung: Unterstützung für die Volltextsuche für die Verwendung von Unterabfragen im C API hinzugefügt. (#520)

🐞 Fehlerbehebungen

  • Python-Bindungsstabilität: Numpy-Vektorabfragen sicher validieren, fehlende Abfrage-by-ID-Dokumente verarbeiten und fehlende FTS-Typanmerkungen zu Python-Stubs und Wrappern hinzufügen. (#502, #519, #497)
  • Python-Paketierung: Die _zvec-Erweiterung wurde im zvec-Paket installiert, C++-SDK-Header und -Bibliotheken von Wheels ausgeschlossen und das DiskANN-Plugin nur auf unterstützten Plattformen gebündelt. (#511, #509, #510)
  • Index- und Speicherkorrektheit: RocksDB-Dateien auf drop_index bereinigt, sodass create_index wiederholt werden kann, Indexparameter-Builder-Setter korrigiert und Abdeckung für Builder-Verhalten hinzugefügt. (#485, #504)
  • HNSW-Persistenz: Persistente Metadaten wurden korrekt wiederhergestellt, wenn Indizes mit dem Quantisierer UniformInt8 erneut geöffnet wurden. (#496)
  • Parkett-Puffer-Cache: Der Besitz des Parkett-Puffer-Cache wurde überarbeitet, um Probleme mit der Lebensdauer und dem Besitz zu vermeiden. (#492)
  • C API-Bereinigung: convert_c_index_params_to_cpp durch Verwendung von IndexParams::clone() vereinfacht. (#489)
  • Sonstige Korrekturen: Ein fehlendes Include in block_heap.h hinzugefügt. (#491)

🤖 CI- und Build-Verbesserungen

  • Build-Anforderungen: Die mindestens erforderliche CMake-Version wurde auf 3.26 erhöht. (#516)
  • Nächtlicher Build: aio zum nächtlichen Build hinzugefügt. (#469)
  • Abhängigkeitsprobleme: actions/checkout von 6 auf 7 aktualisiert. (#507)

👋 Neue Mitwirkende

Vielen Dank an alle Erstautoren dieser Veröffentlichung:
