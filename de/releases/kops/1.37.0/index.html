kops v1.37.0

Einzelheiten, einschließlich Breaking Changes und Deprecations, finden Sie im vollständigen kOps 1.37 release notes.

Highlights

  • Kubernetes 1.37-Unterstützung, mit etcd 3.7.3 als Standard für Kubernetes 1.37-Cluster
  • Private Asset-Repositorys im Cloud-Objektspeicher: s3://-, gs://- und azureblob://-URLs für KOPS_BASE_URL und spec.assets.fileRepository, wobei Knoten sich über ihre Instanzidentität authentifizieren
  • Kleinerer und stabilerer Knoten-Bootstrap: Der Nodeup-Download sinkt durch eine kleinere Binär- und xz-Komprimierung von etwa 120 MB auf unter 10 MB, und Bootstrap versucht fehlgeschlagene Aufgaben erneut
  • Container-Laufzeit: standardmäßig Containerd 2.3.6 und Runc 1.5.1, mit Containerd-Konfigurationsversion 4; Containerd-Versionen, die älter als 2.1.0 sind, werden nicht mehr unterstützt
  • Karpenter-Erweiterung: Karpenter v1.15.1, kOps-verwaltete Unterbrechungsbehandlung (SQS-Warteschlange und EventBridge-Regeln), Root-Volume-Einstellungen in EC2NodeClass, instanceRequirements-Unterstützung und gemischte GPU- und Nicht-GPU-Instanzgruppen
  • Engere AWS IAM-Berechtigungen für die Instanzrollen (Route 53, KMS, EC2, SQS) und keine Inline-Richtlinien für Rollen, die keine Berechtigungen benötigen
  • Änderungen am etcd-Manager: gebündelte etcd-Images, die als Image-Volumes bereitgestellt werden, und Unterstützung für benutzerdefinierte etcd-Versionen von einem vom Benutzer bereitgestellten Image auf neuen Clustern
  • Netzwerk: Calico v3.32.3 mit der Umstellung auf ClusterNetworkPolicy, Netzwerkrichtlinienunterstützung für AWS VPC CNI, Kube-Router v2.12.0 mit einem experimentellen nftables-Netzwerkrichtlinien-Backend und Kindnet v1.0.3
  • Azure: Mit signierten Instanzmetadaten authentifizierte Bootstrap-Anfragen, kops rolling-update cluster-Erkennung veralteter VMs und zwei Cloud-Controller-Manager-Replikate auf hochverfügbaren Steuerungsebenen
  • Akamai (Linode): Der experimentelle Anbieter verwaltet jetzt SSH-Schlüssel, Netzwerke, Subnetze, Instanzen und Blockspeicher-Volumes
  • Komponentenaktualisierungen: etcd-manager v3.0.20261022 mit etcd 3.5.35/3.6.16/3.7.3, Cilium v1.18.16, AWS VPC CNI v1.23.2, CoreDNS v1.15.0, AWS Load Balancer Controller v3.6.2, cert-manager v1.21.3, Cluster-Autoscaler v1.37.0
  • Entfernt: Unterstützung für Kubernetes 1.31, Gossip DNS (und protokube), AWS Classic Load Balancer für API und Kopeio-Netzwerk. Migrieren Sie vor dem Upgrade mit kOps 1.36
