supertokens-core v12.0.11

– Serialisiert die Sitzungserstellung mit der Aufhebung der Kontoverknüpfung, um ein Sitzungsrennen zu schließen (GHSA-2pc4-vw9j-454c). – Erzwingt SAML-Callback-Replay-Schutz und Anforderungsbindung (GHSA-3r7x-rhvc-fw28).

  • SAML: Ein client kann eine optionale ACS-URL-Zulassungsliste (acsURLs) enthalten. Wenn dies festgelegt ist, müssen die ACS-URL des Logins (SP-initiiert) und die Antwort Destination/SubjectConfirmationData.Recipient (IdP-initiiert) Mitglied sein. Dadurch wird die Ziel-/Empfänger-Anheftung auf den IdP-initiierten Pfad erweitert, der zuvor keinen Anker hatte. Die Liste ist erforderlich, wenn die vom IdP initiierte Anmeldung aktiviert ist: Sie wird bei jeder Erstellung/Aktualisierung von client überprüft, und vom IdP initiierte Anmeldungen für einen vorhandenen client ohne solche werden abgelehnt, bis sie festgelegt wird. (GHSA-3r7x-rhvc-fw28 Follow-up) – Bindet die SAML-Identität an eine einzelne validierte Behauptung, die ein signiertes Recipient enthalten muss, das mit der ACS-URL übereinstimmt; saml_sp_entity_id behält seinen Standardwert (GHSA-wfg2-vqfg-rqh6). – Umfasst die WebAuthn-Anmeldung beim angeforderten Mandanten (GHSA-6v34-w48w-44rc). – Verhindert, dass ein App-bezogener API-Schlüssel seine übergeordnete Verbindungs-UriDomain (GHSA-4rf2) aktualisiert. – Erzwingt den Ablauf der Dashboard-Sitzung zum Zeitpunkt der Überprüfung (GHSA-w9fp-wv6g-pqv8).

Migration

Durch die SAML-Wiedergabehärtung (angewandt durch das Supertokens-postgresql-Plugin) werden zwei Spalten zu saml_relay_state hinzugefügt: die Tabelle saml_consumed_assertions und die Spalte der Zulassungsliste saml_clients.acs_urls. Das Plugin wendet sie beim Start automatisch an (CREATE TABLE / ADD COLUMN IF NOT EXISTS); Bei großen PostgreSQL-Bereitstellungen können die folgenden Anweisungen vor dem Upgrade angewendet werden. Additiv und online-sicher.

ALTER TABLE saml_relay_state ADD COLUMN IF NOT EXISTS in_response_to VARCHAR(256);
ALTER TABLE saml_relay_state ADD COLUMN IF NOT EXISTS acs_url TEXT;

CREATE TABLE IF NOT EXISTS saml_consumed_assertions (
    app_id VARCHAR(64) NOT NULL DEFAULT 'public',
    tenant_id VARCHAR(64) NOT NULL DEFAULT 'public',
    assertion_id VARCHAR(256) NOT NULL,
    expires_at BIGINT NOT NULL,
    CONSTRAINT saml_consumed_assertions_pkey PRIMARY KEY(app_id, tenant_id, assertion_id),
    CONSTRAINT saml_consumed_assertions_app_id_fkey FOREIGN KEY(app_id) REFERENCES apps (app_id) ON DELETE CASCADE,
    CONSTRAINT saml_consumed_assertions_tenant_id_fkey FOREIGN KEY(app_id, tenant_id) REFERENCES tenants (app_id, tenant_id) ON DELETE CASCADE
);

CREATE INDEX IF NOT EXISTS saml_consumed_assertions_expires_at_index ON saml_consumed_assertions (expires_at);

ALTER TABLE saml_clients ADD COLUMN IF NOT EXISTS acs_urls TEXT;
