adk-python v2.13.0

2.13.0 (22.10.2026)

Highlights

Diese Version stabilisiert Kernfunktionen und führt gleichzeitig die TypeSafe-Workflow-Klassifizierung, Live-Audio-Interaktionen, MongoDB-Integrationen und Verbesserungen der Ausführungsleistung ein.

  • Stabilität: Zugriff auf 12 ausgereifte experimentelle Funktionen, die jetzt auf den stabilen Status hochgestuft wurden. Weitere Einzelheiten finden Sie im Gerätehandbuch. (ea298d4)
  • Klassifikatoren: Leiten Sie Workflows mit den Jev-Modellen von TypeSafe über die neuen TypesafeClassifier und ClassifierNode weiter. Jev gibt kalibrierte Wahrscheinlichkeiten in einem einzigen Vorwärtsdurchlauf zurück, viel schneller als ein LLM. Weitere Einzelheiten finden Sie im Gerätehandbuch. (ddf8c55, e8c4bac)
  • Live-Audio: Ermöglichen Sie natürliche Sprachinteraktionen in Echtzeit mit Barge-in-Unterstützung sowie Gemini-Sprache-zu-Text und Text-zu-Sprache-Integration. Weitere Einzelheiten finden Sie im Gerätehandbuch. (2e7ef92)
  • MongoDB-Sitzungen und -Speicher: Behalten Sie Sitzungen in MongoDB bei und teilen Sie sie mit dem neuen MongoDbSessionService über mehrere Runner-Replikate hinweg. Fügen Sie Langzeitspeicher ohne Einbettungsmodell hinzu, indem Sie MongoDbMemoryService verwenden, das vergangene Runden durch Schlüsselwortübereinstimmung bei jeder MongoDB-Bereitstellung abruft, ohne dass ein Vektorindex erforderlich ist. Beide sind experimentell. Weitere Einzelheiten finden Sie in den Handbüchern Sitzungsdienst und Speicherdienst. (0df43f5, e40e349)
  • MongoDB: Stellen Sie MongoDbToolset in der Agent Engine bereit, ohne Ihre Verbindungszeichenfolge zu packen, und lassen Sie Atlas Automated Embedding Suchanfragen serverseitig einbetten, ohne dass ein Google-Einbettungsaufruf oder Anmeldeinformationen erforderlich sind. Weitere Einzelheiten finden Sie im Gerätehandbuch. (bc3773f, 2f6c666, 8bbfc33)
  • Leistung: Genießen Sie bis zu 8-mal schnellere Ausführungszyklen für String-Modell-Agenten und einen geringeren Overhead beim Laden von Ereignissen. (772f139)

Breaking Changes

  • Telemetrie: Standardmäßig OpenTelemetry GenAI v2 (otel_semconv_1_44, call_llm wird entfernt); Legen Sie ADK_TELEMETRY_SCHEMA_VERSION_OPT_IN=otel_semconv_1_36 fest, um das Legacy-V1-Schema beizubehalten. Weitere Einzelheiten finden Sie im Gerätehandbuch. (7838488)
