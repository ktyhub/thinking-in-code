adk-python v2.12.0

2.12.0 (13.10.2026)

Highlights

Diese Version verbessert die Ausführungsleistung in langen Sitzungen und bietet gleichzeitig eine genauere Kontrolle über die Tool-Ausführung, Workflow-Genehmigungen und Bereitstellungssicherheit.

  • Leistung: Reduzieren Sie die Zeit bis zur ersten Modellanfrage bei langen Sitzungen um 40 %. (1754b3e)
  • Tools: Werkzeugausgaben abfangen und filtern, bevor sie mit after_tool_callback an das Modell zurückgegeben werden. (fdda17c)
  • Workflows: Erfordern eine menschliche Bestätigung, bevor Workflow-Knoten über require_confirmation ausgeführt werden. (988fd1a)
  • Bereitstellung: Stellen Sie Agenten mithilfe dedizierter benutzerdefinierter Dienstkonten in der Agent Engine bereit. (629e119)
  • Python 3.15: ADK auf Python 3.15 installieren und ausführen. (75aef1e)
