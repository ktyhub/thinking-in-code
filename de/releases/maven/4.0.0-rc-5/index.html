Notizen

Dieser neue Release Candidate von Maven 4 wird veröffentlicht, um Feedback von Benutzern einzuholen. Maven 4 weist im Vergleich zu Maven 3 einige Einschränkungen auf. Stellen Sie daher sicher, dass Sie das Tool mvnup ausführen, bevor Sie versuchen, mit Maven 4 zu projizieren.

Bean-Konfigurationsfehler

Im Bean-Konfigurationssystem wurde ein Fehler gefunden, bei dem der Feldzugänglichkeitsstatus global zwischengespeichert wird. Dies kann dazu führen, dass die Plugin-Konfigurationsinjektion fehlschlägt, wenn während eines Builds mehrmals oder in unterschiedlichen Kontexten auf dasselbe Konfigurationsfeld zugegriffen wird. Dies betrifft insbesondere die Plugin-Unit-Tests.

Dies wird in der nächsten Version durch #11433 behoben.

Parallelitätsproblem in v4 API

In Maven 4 API (immer noch im Vorschaumodus) wurde ein Parallelitätsproblem gefunden, das in der nächsten Version durch #11428 behoben wird.

Stücklistenverpackung

Ein weiterer Fehler wurde bei der Verarbeitung von Stücklistenprojekten gefunden. Wenn ein Projekt die BOM-Verpackung verwendet, wird das Consumer-POM nicht ordnungsgemäß in die Standard-POM-Verpackung konvertiert und in einigen Fällen können Abhängigkeitsversionen verloren gehen.

Dies wird in der nächsten Version durch #11427 behoben.

macOS: Die native JLine-Bibliothek wird möglicherweise bei der ersten Verwendung von Gatekeeper blockiert

Unter macOS (insbesondere Apple Silicon) schlägt der erste Aufruf von mvn möglicherweise fehl, die native JLine-Terminalbibliothek zu laden, mit einem Fehler wie dem folgenden:

java.lang.UnsatisfiedLinkError: .../libjline-native/Mac/arm64/libjlinenative.jnilib: dlopen(...): code signature ... not valid for use in process: library load disallowed by system policy

Dies geschieht, wenn die Binärverteilung über einen Webbrowser heruntergeladen wird, der das com.apple.quarantine extended-Attribut anwendet.

Workaround (einmalige Fehlerbehebung):

xattr -r -d com.apple.quarantine /path/to/apache-maven-4.0.0-rc-5/lib/jline-native

Empfohlene Download-Methode (vermeidet das Problem vollständig):

curl -L -O https://archive.apache.org/dist/maven/maven-4/4.0.0-rc-5/binaries/apache-maven-4.0.0-rc-5-bin.tar.gz
tar -xzf apache-maven-4.0.0-rc-5-bin.tar.gz

Dies ist ein bekanntes Problem Nr. 10747 und wird in einer zukünftigen Version behoben.
