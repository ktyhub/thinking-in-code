Nanobot v0.1.4

🎉 Eine weitere große Veröffentlichung aus der 🐈 Nanobot-Community – vielen Dank an alle Mitwirkenden, insbesondere an unsere 18 neuen! Diese Version bietet MCP-Tool-Server-Unterstützung, Echtzeit-Fortschritts-Streaming, sodass Benutzer tatsächlich sehen können, was der Agent tut, sowie eine Reihe neuer Anbieter (Custom OpenAI-kompatibel, GitHub Copilot, OpenAI Codex, SiliconFlow). Auch die Kanäle haben viel Zuspruch gefunden – Telegram verarbeitet jetzt Medien-Uploads und lange Nachrichten, Slack hat richtige mrkdwn- und Thread-Antworten, Feishu unterstützt Rich Text. Wir haben außerdem Docker Compose für die Bereitstellung mit einem Befehl hinzugefügt, Sitzungen auf den Arbeitsbereich beschränkt und auf json_repair für eine kugelsichere LLM-Antwortanalyse umgestellt. Weniger Stille, mehr Anbieter, bessere Kanäle – das ist der Nanobot-Weg.

Highlights

  • MCP-Unterstützung – Externe Tool-Server über Model Context Protocol verbinden (#554)
  • Fortschritts-Streaming – Agent zeigt an, was er während der mehrstufigen Tool-Ausführung tut (#802)
  • Neue Anbieter – Benutzerdefinierte OpenAI-kompatible Endpunkte, GitHub Copilot, OpenAI Codex, SiliconFlow (#786, #720, #312, #151, #630)
  • Kanalverbesserungen – Telegram-Medien-Uploads und Nachrichtenaufteilung, Slack-Thread-Antworten und mrkdwn, Feishu-Rich-Text (#747, #694, #717, #784, #629, #593)
  • Docker Compose – Bereitstellung mit einem Befehl (#765)
  • Workspace-bezogene Sitzungen – Sitzungen sind jetzt im Workspace mit Legacy-Migration verfügbar (#713) – Robustes JSON-Parsing – json_repair für die Behandlung fehlerhafter LLM-Antworten (#664)
