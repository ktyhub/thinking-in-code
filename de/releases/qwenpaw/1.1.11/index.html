QwenPaw v1.1.11

Was hat sich geändert?

✨ Hinzugefügt

Anbieter

  • Free Model OAuth: Kostenlose Modelle ohne Konfiguration mit One-click-OAuth-Authentifizierung (#5049)
  • Xiaomi MiMo-Anbieter: Xiaomi MiMo-Token-Plan als integrierten Anbieter hinzufügen (#4722)
  • Extra-Body-Routing: Leiten Sie nicht standardmäßige „generate_kwargs“ in „extra_body“ um (#4689) Konsole
  • Plugin-Markt: Registerkarte „Plugin-Markt“ mit AgentScope-Plattform-Integration hinzufügen (#5023)
  • Plugin-Erweiterungsinfrastruktur: Plugin-Erweiterungsinfrastruktur für Konsole (#4997)
  • Tool Cards Plugin System: Tool Cards Plugin-System (#5046)
  • Befehlsvorschläge kürzen: Fügen Sie Fähigkeiten des aktuellen Agenten hinzu, um Befehlsvorschläge mit UI-Optimierungen zu kürzen (#4810)
  • Externe URL-Navigation: Unterstützt das href-Feld in MenuItem für die externe URL-Navigation (#5071) MCP
  • Tool-Whitelisting: MCP-Tool-Whitelisting pro Server mit Frontend-Umschalt-Benutzeroberfläche hinzufügen (#5002) Plugins
  • Prompt Section Registry: Plugins erlauben, System-Prompt-Blöcke an definierten Ankerpunkten einzufügen (#4804)
  • Deinstallations-Hooks: Deinstallations-Hooks hinzufügen, Validator-Importe korrigieren, Skill-Anbieter API verfügbar machen (#4794)
  • CloudPaw Agent Import: Unterstützt den Import von Agents aus AgentHub und verbessert die A2A-Funktionen (#5033) Fähigkeiten
  • Selbstentwickelnde Fertigkeitserstellung: Verbesserter Fertigkeitserstellungsablauf zur Unterstützung der selbstentwickelten Fertigkeitserstellung (#4857)
  • Skill-Tag-Batch-Download: Skill-Tag-Batch-Download hinzufügen (#4969)
  • Multi-Path-Skill-Pool: Multi-Path-Unterstützung für den Skill-Pool hinzufügen (#4891) Kanäle
  • Telegram Tool Guard: Interaktive Werkzeuggenehmigung über Inline-Tastatur (#4737)
  • Feishu-Gruppenfreigabe: Modus zum Teilen von Gruppensitzungen hinzufügen (#4821)
  • Interaktive Feishu-Karten: Unterstützt die Extraktion interaktiver Karteninhalte und das Parsen von Refactor-Nachrichten (#4879)
  • QQ QR Code Auth: QR-Code-Autorisierung für QQ-Kanal hinzufügen (#4848)
  • DingTalk Inline Media: Inline-Bildvorschau und Videowiedergabekarte über Webhook aktivieren (#5073)
  • Yuanbao Typing Indicator: Tippindikator über Heartbeat API hinzufügen (#5020)
  • Zugriffskontroll-Benutzername: Absender-Benutzernamen zur Zugriffskontrolle mit einheitlicher Benutzerinformationsstruktur hinzufügen (#4897) Browser
  • Seitenkoordinate Click: Seitenkoordinaten-click-Unterstützung zu browser_control hinzufügen (#4905) AKP
  • ACP-Verbesserungen: Ankündigen von Befehlen, Oberflächenfehlern, Tool-Parametern, Agent-/Modell-Meta, Dateilinks (#4949) Läufer
  • Zeitstempel der Stream-Abfrage: Überschreiben Sie stream_query, um den aktuellen Zeitstempel für Antworten festzulegen (#4892)

🔄 Geändert

  • Cron-Push-Blasen: Push-Blasen für Cron-Jobs vom Typ „Agent“ deaktivieren (#4803)
  • Console Media Handling: Vereinfachen Sie die Handhabung von Mediennachrichten im Konsolenkanal (#5077)
  • Sitzungsbereich zurücksetzen: „Sitzungsliste des Verlaufs als rechten Bereich einbetten“ zurücksetzen (#5076)

🐛 Behoben

Anbieter & Konfiguration

  • ProviderManager-Fallback: ProviderManager-Fallback zu get_model_max_input_length hinzufügen (#4827)
  • Komprimierungskorrektur: /compact wird aufgelöst und ignoriert die max_input_length des Modells, wenn active_model nicht festgelegt ist (#5021) Codierungsmodus
  • Windows-Laufwerkssuche: Unterstützt das Durchsuchen aller Laufwerke unter Windows (#4906)
  • Sitzungswechsel und Header: Fehler beim Sitzungswechsel im Codierungsmodus und Header-Überlauf behoben (#5011) Konsole
  • Session List Spinner: Die Sitzungsliste drehte sich ständig weiter (#4929)
  • Flimmern der Bildlaufleiste: Hover-Transformation entfernen, um ein Flackern der Bildlaufleiste zu verhindern (#4766)
  • Schildsymbol und Tabelle: Schildsymbol zentrieren und Spaltenbreiten der Regeltabelle anpassen (#4765)
  • Theme-Umschaltsymbol: System-Theme-Umschaltsymbol von „Computer“ zu „Sonne“ ändern (#5050) Desktop
  • Externe Tauri-Links: Externe Links auf dem Tauri-Desktop behoben (#4683) Agent & Erinnerung
  • Broadcast Coroutine: Warten auf unerwartete Coroutine in _broadcast_to_subscribers (#5048)
  • Autom. Speicher überspringen: Automatischen Speicher für die Automatisierung überspringen (#4348) – Dream-Arbeitsbereich: Dream sollte den Arbeitsbereich des Cron-Runners verwenden, nicht das veraltete Instanzverzeichnis (#4936)
  • Medienblockverarbeitung: Behandeln Sie nicht diktierte Quellobjekte bei der Medienblockverarbeitung (#4933) MCP
  • Regex für Toolnamen: Alias-Rewrite-Toolnamen werden von Regex im OpenAI-Stil abgelehnt (#4958)
  • Ansammlung von Unterprozessen: Verhindert die Ansammlung von Unterprozessen über Neustarts hinweg (#5014) Kanäle
  • Zusammenführung von DingTalk-Nachrichten: Verhindert das Zusammenführen von benutzerübergreifenden Nachrichten, wenn das Konversations-ID-Suffix kollidiert (#4932)
  • OneBot-Portkonflikt: Ordentliche Verschlechterung bei Portkonflikt während des Neuladens (#5010)
  • ACL-Absender-ID: Behalten Sie acl_sender_id während der nativen Nutzlastzusammenführung über alle Kanäle bei (#4925) Browser
  • CDP-Timeout und Profil: CDP-Timeout-Parameter und Browser-Profil-Isolierung für browserübergreifenden Wechsel hinzufügen (#4944) Datei & Sitzung
  • Asynchrone Dateischreibvorgänge: Aiofiles für nicht blockierende Dateischreibvorgänge verwenden (#4954)
  • Atomic State Write: Sitzungsstatus atomar schreiben (#4706)
  • Upload-Größe und Timeout: Upload-Größenbeschränkung + Timeout-Resilienz des Plugin-Loaders (#4940)
  • Zip-Download-Größe: Größe der Zip-Download-Datei erhöhen (#4941) Sicherheit
  • Einschränkung der Dateivorschau: Dateivorschau auf ARBEITSVERZEICHNIS beschränken und vertrauliche Dateien blockieren (#4981) Pakete
  • Yuanbao Proto JSON: Yuanbao Proto JSON-Dateien in Paketdaten einschließen (#4899)

⚡ Leistung

  • Backend-Startup: Ereignisschleife entsperren und Startup parallelisieren (#5074)
  • CI-Abdeckung: Abdeckungserfassung von py3.10 auf py3.13 umstellen (#4952)

🏗️ Infrastruktur

  • E2E-CI-Pipeline: Komplette E2E-Integrations-CI-Pipeline – Backend-Start, Abdeckung, Testkorrekturen (#5054)
  • CI-Bereinigung: Redundanten Kanaltest-Workflow entfernen (#5056)
  • Abhängigkeiten: Reme-ai-Abhängigkeit auf Version 0.3.1.10 aktualisieren (#4935)
  • Chat-Komponente: @agentscope-ai/chat auf 1.1.68 aktualisieren (#5072)

🧪 Testen

  • Frontend-Unit-Tests: Vollständiger Frontend-Unit-Test-Meilenstein – Konstanten, Kontexte, Layouts, api-Typen, Komponenten (#4332)
  • Runner- und Router-Tests: Unit- und Vertragstests für Runner und Router hinzufügen (#4852)
  • Agentenbezogene P0-Tests: Agentenbezogene P0-Vertragsabdeckung (+55 Fälle) (#4945)
  • Agent-Seitentests: Agent-Seite + API-Modul-Komponententests + Abdeckungsratsche (#5012)
  • Anbieter- und Utils-Tests: Komponententests für lokale_Modelle, Anbieter, Tunnel und Utils hinzufügen (#4973)
  • Channel Layer Tests: Channel Layer + Multi-Agent-Management-Integrationstests (#5058)
  • E2E-Token-Nutzung: Die Erkennung des Leerzustands des Token-Nutzungstests in einer sauberen Umgebung wurde behoben (#5068)

📖 Dokumente

  • Roadmap-Update: Aktualisieren Sie die Roadmap (#4942)
  • Frontend-Plugin-Dokumente: Konsolidieren Sie Frontend-Plugin-Dokumente in Website-Seiten (#5066)
