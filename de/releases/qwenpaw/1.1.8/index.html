QwenPaw v1.1.8

✨ Hinzugefügt

Plugins und Tools

  • Offizielle Plugin-Verteilung: Durchsuchen Sie offizielle Plugins auf der Website und laden Sie sie herunter, oder installieren Sie sie mit einem click im Plugin-Manager der Konsole (#4482)
  • QwenPaw Pet: Desktop-Plugin für Haustierbegleiter mit animiertem Haustierfenster (#4418, #4516)
  • CloudPaw – Alibaba Cloud Deployment: Neues Plugin mit Multi-Agent-Orchestrierung, IaC-gesteuerter Cloud-Bereitstellung und A2A-Streaming-Integration mit Alibaba Cloud Skills Hub (#4362, #4423, #4506, #4524)
  • Robustheit des Browsers: Verbesserte Browserstabilität mit Wiederherstellung nach einem Absturz, Schutz vor Zeitüberschreitung im Leerlauf und automatischer Bereinigung beim Beenden (#4306, #4350)
  • Browser-Tab-Metadaten: Die Aktion tabs gibt jetzt die URL und den Titel jedes geöffneten Tabs zurück (#4438) Chat und Konsole
  • Batch-Vorgänge im Posteingang: Neu gestalteter Posteingang mit Batch-Auswahl und Batch-Löschen für eine effizientere Verwaltung von Nachrichten (#4358, #4493)
  • Angeheftete Chat-Verlaufsschublade: Heften Sie die Sitzungsschublade an, damit sie neben dem Chat geöffnet bleibt (#4414, #4416, #4517) Modelle & Anbieter
  • Benutzerdefinierte HTTP-Header und Authentifizierungsmodus: Benutzerdefinierter Header-Editor für alle Anbieter mit Auswahl des Authentifizierungsmodus (API-Schlüssel vs. Bearer-Token) (#4413)
  • Token-Limits pro Modell: max_tokens und max_input_length werden jetzt pro Modell in Einstellungen → Modelle konfiguriert (#4417) Agentensystem
  • /make-skill-Befehl: Ein neuer magischer Befehl, um die aktuelle Chat-Sitzung in einen wiederverwendbaren Skill umzuwandeln (#4282)
  • Indonesische Agent-Vorlagen: Agent-Persona-Markdown-Vorlagen und Asia/Jakarta-Zeitzone (#4287)
  • Cron-Job-Timeout: Konfigurierbares Timeout für Cron-Jobs (Standard 120 Sekunden) (#4425) Sicherheit
  • Skill Path Safety: Path-Traversal-Angriffe bei Skill-Verzeichnisvorgängen verhindern (#4335)
  • Backup-Trust-Kontrollen: Überprüfen Sie die Backup-Integrität beim Importieren/Wiederherstellen mit trust-Bestätigungsdialogen und stärken Sie die Fernzugriffskontrollen (#4409, #4429)
  • AgentMd Path Traversal Prevention: Verhindert Pfaddurchquerung bei Dateioperationen im Agentenspeicher (#4511)
  • Plugin API Auth: Plugin-Verwaltung APIs erfordern jetzt Authentifizierung (#4513) Kanäle
  • Matrix E2EE-Verifizierung: Passwort- und Zugriffstoken-Anmeldung mit E2EE-Umschaltung und SAS-Geräteverifizierung (#4120)
  • Telegram-Streaming-Ausgabe: Echtzeit-Streaming-Antworten mit Unterstützung für Begründungsindikatoren (#4318)
  • DingTalk Streaming Cards: Echtzeit-Streaming-Antworten über AI Card (nur Kartennachrichtenmodus) (#4420)
  • Feishu CardKit Streaming: Echtzeit-Streaming-Antworten über CardKit (#4480)

🔄 Geändert

  • Konsolen-Header-Navigation: Konsolidierte Header-Links in einem Dokumentations-Dropdown mit Tutorial-, Feature-Demos-, Changelog- und FAQ-Einträgen (#3875)
  • Feishu/Lark QR Code Domain: QR-Code API akzeptiert Abfrageparameter (#4504)
  • Timeout für Stream-Aufgaben: Für lang laufende gestreamte Agent-Aufgaben von 300 auf 1800 Sekunden erhöht (#4510)

🐛 Behoben

Kanäle

  • WeCom Duplicate Placeholder: Unterdrückung des doppelten „Thinking…“-Streams in rapid aufeinanderfolgenden Nachrichten (#4427)
  • Abschaltung der WeChat-Umfrage: Absturz beim Beenden und enge Fehlerschleifen im WeChat-Umfragethread behoben (#4490)
  • QQ-Wiederverbindungsschleife: Hochfrequenz-Wiederverbindung bei Ablehnung der IP-Whitelist verhindern (#4503) Fähigkeiten
  • Paketierung von QA-Agent-Dokumenten: Der QA-Agent funktioniert jetzt korrekt in allen Installationsmethoden (pip, Docker, Desktop) – zuvor fehlten möglicherweise einige Dokumente (#4280)
  • Skill Hub-URL-Validierung: Fehler beim Skill-Import für URLs mit dem Präfix www. behoben (#4359) Anbieter & Modelle
  • Ratenbegrenzer pro Modell: Eine Ratenbegrenzung auf einem Modell blockiert keine Anfragen an andere Modelle mehr (#4487)
  • Token-Nutzung pro Modell: Zusammenfassungen der Token-Nutzung enthalten jetzt eine Aufschlüsselung pro Modell mit der Anzahl der Eingabeaufforderungs-/Abschlusstokens (#4476) Konsole und Benutzeroberfläche
  • SSE-Verbindungsleck: Behoben, dass SSE-Verbindungen bei der Seitennavigation nicht geschlossen wurden, wodurch die Browser-Verbindungslimits ausgeschöpft werden konnten (#4488)
  • Cron-Validierungsfehler: Die Cron-Erstellung/Aktualisierung gibt lokalisierte, umsetzbare Fehlermeldungen anstelle allgemeiner Serverfehler zurück (#4495)
  • Sitzungsspeicherpersistenz: /mission- und /skill-Infoantworten werden jetzt im Sitzungsspeicher gespeichert, sodass sie das Neuladen der Seite überstehen (#4523)

📝 Dokumentation

  • Website-Feature-Demos: Docs-Demogalerie mit Walkthrough-Videos für Fertigkeiten, Arzt und Missionsmodus (#4507)
