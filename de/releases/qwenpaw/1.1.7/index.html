QwenPaw v1.1.7

QwenPaw v1.1.7

✨ Hinzugefügt

Tools und MCPs

  • Browserverwendung – Stapelaktionen: Führen Sie mehrere Browserschritte aus (Navigieren, click, Typ, Screenshot usw.) in einem einzigen Tool-Aufruf (#4139)
  • Browser-Nutzung – Datei-Download: Dateien herunterladen, indem cli Seitenelemente anklickt oder URLs direkt abruft (#4261)
  • GPT Image 2-Referenzbilder: Unterstützt das Hochladen von 1–16 Referenzbildern über URL oder lokalen Pfad im GPT Image 2-Plugin (#4194)
  • Asynchrone Ausführung externer Agenten: delegate_external_agent unterstützt asynchrones Streaming mit Aufgabenliste und Statusabfragen sowie konfigurierbarem Timeout (#4197)
  • Konfiguration der ausführbaren Shell-Datei: Wählen Sie über die Konfigurationsoption aus, welche Shell Befehle ausführt (#4215)
  • OAuth 2.1 für Remote-MCP-Server: Authentifizieren Sie Remote-MCP-Server über OAuth 2.1 mit PKCE (#4256) Plugins
  • Konsolen-Plugin-Verwaltung: Plugins über die Benutzeroberfläche „Einstellungen“ über lokalen Pfad, ZIP-Upload oder URL installieren und deinstallieren (#4214, #4266)
  • Qwen-Image & Wan 2.7 Plugins: Neue Plugins für Bildgenerierung/-bearbeitung und Videogenerierung (#4248)
  • Plugin HTTP API Router: Plugins können benutzerdefinierte HTTP API-Endpunkte registrieren (#4255) Chat und Konsole
  • Mehrere Dateianhänge: Die Chat-Eingabe unterstützt jetzt die Auswahl mehrerer Dateien in einer einzelnen Nachricht (#4206)
  • Indonesische Sprache: Vollständige Unterstützung des Bahasa Indonesia-Gebietsschemas für die Konsolen-Benutzeroberfläche und das Backend (#4219)
  • Posteingang: Neuer zentraler Posteingang mit Registerkarten „Genehmigungen“ und „Push-Nachrichten“ zum Verwalten von Tool-Guard-Genehmigungen und zum Anzeigen von Cron-Ausführungsergebnissen mit Ablaufverfolgungen (#4210, #4305)
  • Cron-Job-Verbesserung: Cron-Jobs unterstützen jetzt eine einmalige geplante Ausführung, eine Kalenderansicht zur Visualisierung anstehender Ausführungen, integrierte Vorlagen für die schnelle Erstellung, einen Ausführungsverlauf pro Job mit detaillierten Ausführungsverfolgungen und die Zustellung im Posteingang (#4210) Kanäle
  • Feishu-Sprachblasen: Über Feishu gesendete Audiodateien werden jetzt als native Sprachblasen gerendert (#4202)
  • DingTalk zitierte Nachrichten: Antworten mit zitierten Nachrichten in DingTalk enthalten jetzt zitierten Text und Medien im Agentenkontext (#4209)
  • Feishu-QR-Code-Bot-Erstellung: Erstellen Sie einen Feishu/Lark-Bot, indem Sie einen QR-Code in der Channels-Setup-Benutzeroberfläche scannen (#4236)
  • WeCom-Streaming-Ausgabe: Optionale Streaming-Antworten für den WeCom-Kanal mit Nachrichtenzustellung in Echtzeit und Unterstützung für Begründungsindikatoren (#4271)

🔄 Geändert

  • Neugestaltung der Modellauswahl: Das Hover-Dropdown wurde durch eine durchsuchbare flache Liste ersetzt, die nach Anbieter gruppiert ist (#3876)
  • Floating-Chat-Schaltfläche: Die Chat-Navigation wurde vom Seitenleistenmenü auf eine Sticky-Schaltfläche neben der Agentenauswahl verschoben (#4240, #4273)
  • Agent Stats Session Discovery: Vereinfachte Suche nach Sitzungsdateien durch direktes Durchsuchen von Kanalunterverzeichnissen (#4250)

⚡ Leistung

  • Async FastAPI-Abhängigkeiten: Modell- und Provider-Manager-Abhängigkeiten wurden in asynchron konvertiert, wodurch unnötiger Thread-Pool-Versand vermieden wurde (#4229)
  • Grenze für die Dateilesegröße: Die maximale Dateilesegröße wurde auf 200 MB (von 1 GB) reduziert, wobei die Vorabzuweisung auf der tatsächlichen Dateigröße basiert (#4272, #4276)
  • Schlüsselring-Zeitüberschreitung: Schlüsselring-Vorgänge haben jetzt eine Zeitüberschreitung von 10 Sekunden, um zu verhindern, dass Hänger des Anmeldeinformationsmanagers den Start blockieren (#4263)

🐛 Behoben

Anbieter & Modelle

  • Volcengine-Modell-IDs: Modell-IDs wurden korrigiert, damit sie mit den tatsächlichen API-Endpunkten und aktualisierten Fähigkeitsflags übereinstimmen (#4169)
  • Bewahrung von Anbietermeta: Anbietermetadaten werden beim Abrufen von Anbieterinformationen nicht mehr gelöscht (#4200)
  • Fehlerhafte Tool-Nutzungsfilterung: Der Streaming-Parser filtert jetzt Tool-Nutzungsblöcke mit Null-IDs oder leeren Namen heraus (#4234) Kanäle
  • WeCom-Genehmigungskartenbetreiber: Aufgelöste Genehmigungskarten zeigen jetzt den Betreibernamen an (#4233)
  • Feishu WebSocket Keepalive: Stillen WebSocket-Verbindungsverlust erkennen und beheben (#4241) Konsole und Benutzeroberfläche
  • Routing des Sitzungsverlaufs: Problem behoben, bei dem der Sitzungsverlauf verschwand und Nachrichten an falsche Sitzungen weitergeleitet wurden (#4203)
  • Plan Panel Dark Mode: Verbesserter Textkontrast im Plan Panel Dark Mode (#4190)
  • Mobile Sidebar: Sidebar wird auf schmalen Bildschirmen automatisch ausgeblendet (#4225)
  • Zeilenumbrüche in Benutzernachrichten: Benutzernachrichten behalten jetzt Zeilenumbrüche bei (#4231)
  • Datumsbeschriftungen für die Token-Nutzung: Diagrammbeschriftungen zeigen jetzt ein Jahrespräfix an, wenn der Datumsbereich eine Jahresgrenze überschreitet (#4268)
  • Externe Desktop-Links: Links werden in Desktop-Builds jetzt korrekt geöffnet (#4270)
