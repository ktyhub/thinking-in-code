2.3.5 Release Note

Fehlerbehebung

Kern

  • [Fix] Behebung des NPE-Problems beim Abrufen der Seatunnel-Zeilengröße (#6681)
  • [Hotfix] Problem mit der Standardtabelle behoben (#6352)
  • [Aufgabe] file-Zauberfehler beheben (#6606)
  • [BugFix][Spark-translation] Kartentyp-Umwandlungsfehler (#6552)
  • [Hotfix] Spark-Beispiel behoben (#6486)
  • [Hotfix] Kompilierungsfehler behoben (#6463)

Transformator

– [Fix][SQLTransform] behebt den Skalierungsverlust für die SQL-Transformation (#6553)

  • [Fehler] Minus-Konstantenfehler in SQLTransform behoben (#6533)

Anschlüsse

  • [Fix][Kafka-Sink] korrigiert die Kafka-Sink-Factory-Optionsregel (#6657)
  • [Hotfix] Fehler im Format „JJJJ-MM-TT HH:mm:ss“ behoben und DateTime-Dienstprogramme verbessert (#6601)
  • [Bug] Fix OrcWriteStrategy/ParquetWriteStrategy meldet sich nicht mit Kerberos an (#6472)
  • [Fix][Doc] FTP-Sink-Konfigurationsschlüssel username zu user korrigieren (#6627)
  • [E2E] AmazondynamodbIT instabil behoben (#6640)
  • [Fix][Connector-V2] Fehler beim Hinzufügen einer Hive-Partition behoben, wenn die Partition bereits vorhanden war (#6577)
  • [Fix][Connector-V2] Doris/Starrocks-Erstellungstabellen-SQL-Analysefehler behoben (#6580)
  • [Fix][Connector-V2] Fix: Doris-Senke kann nicht geschlossen werden, wenn beim Laden des Streams keine Daten gelesen werden (#6570)
  • [Fix][Connector-V2] Connector-Unterstützung SPI behoben, aber ohne Args-Konstruktor (#6551)
  • [Fix][Connector-V2] Behebung des Verlusts von Primärschlüsselinformationen in Doris-Quellenauswahlfeldern (#6339)
  • [Fix][FakeSource] behebt das Problem, dass Zufallsgeneratoren aus der Vorlage nicht den neuesten Wert enthalten (#6438)
  • [Fix][Connector-V2] Behebung, dass die Optionswerte für den Mongodb-CDC-Startmodus nicht korrekt sind (#6338)
  • [BugFix][Connector-file-sftp] Fix SFTPInputStream.close löst das Schließen des Dateistreams nicht korrekt aus (#6323) (#6329)
  • [Fix] Behebung eines Fehlers beim Laden des Doris-Streams, der nicht gemeldet wurde (#6315)
  • [fix][connector-rocketmq]Behebung eines NPE-Problems, wenn checkpoint.interval zu klein eingestellt ist (#6624)
  • [Bugfix][TDengine] Behebung des Problems, dass der Treiber aufgrund mehrerer Aufrufe des Submit-Jobs REST API #6581 verloren ging (#6596)
  • [Fix][StarRocks] NPE behoben, wenn der Pfad der Upstream-Katalogtabellentabelle nur einen Tabellennamenteil hat (#6540)

Formate

  • [Fehler] [Formate] Behebung, dass die Zeile nicht geparst werden konnte, wenn der Inhalt das Dateitrennzeichen enthielt (#6589)

Zeta (ST-Motor)

  • [Hotfix] Fehler im Format „JJJJ-MM-TT HH:mm:ss“ behoben und DateTime-Dienstprogramme verbessert (#6601)
  • [Fix][Zeta] Behebung des Thread-Stängeproblems, das durch den Sicherungspunkt-Überprüfungsmechanismus verursacht wurde (#6568)
  • [Fix][Zeta] verbessert die Hazelcast-Verbindung im lokalen Modus (#6521)
  • [Fix][Zeta] Behebung, dass der Thread-Klassenlader bei Verwendung des Cache-Modus auf Null gesetzt wird (#6509)
  • [Bug] [zeta] Nullzeiger-Ausnahme beim Senden von Jobs behoben (#6492)
  • [Bugfix] [Zeta] Behebung des Problems, dass der Klassenlader nicht freigegeben wird, wenn REST API zum Senden von Jobs verwendet wird
  • [BUG][Zeta]Jobname Anzeigefehler #6470
  • [Hotfix][Zeta] Job-Deadlock bei Schemaänderung behoben (#6389)

E2E

  • [E2E] StarRocksCDCSinkIT aktivieren (#6626)

Verbessern

  • [Doc][Verbessern] Unterstützung für Chinesisch für Seatunnel-Engine hinzufügen (#6656)

  • [Verbessern][RestAPI] gibt Informationen zum abgeschlossenen Auftrag zurück, wenn der Auftrag abgeschlossen ist (#6576)
  • [Verbessern] Verbesserung der MultiTableSinkWriter-Vorbereitungs-Commit-Leistung (#6495)

  • [Verbessern][CDC-Connector]Korrektur der CDC-Optionsregel. (#6454)
  • [Verbessern][CDC] Speicherzuteilung für Snapshot-Split-Lesen optimieren (#6281)
