Seetunnel 3.1.0

3.1.0 Release Note

Dies ist eine weitere wichtige Version für Apache SeaTunnel nach der Version 3.0.0!

Die Version 3.1.0 enthält 395 PRs und 11 neue Konnektoren, wobei der Schwerpunkt auf der Stabilität der Zeta-Engine und der Korrektheit der Connector-V2-Daten liegt. Darüber hinaus werden Bereitstellung, Betrieb und Datentransformation verbessert, um Produktionsdatenintegrationsaufgaben zuverlässiger zu machen.

Vielen Dank an alle Mitwirkenden für ihre harte Arbeit an diesem Update. Wir glauben, dass die Version 3.1.0 der Community ein stabileres und zuverlässigeres Datenintegrationserlebnis bieten wird.

Highlights

  • Nativer Kubernetes-Anwendungsmodus: Stellen Sie einen dedizierten Master und eine feste Anzahl von Workern pro Job bereit, mit automatischer Ressourcenbereinigung, wenn der Job abgeschlossen ist, und sorgen Sie so für Ressourcenisolation und Ressourcenfreigabe bei Bedarf für einmalige Datenverarbeitungsjobs und Teams, die umfangreiche Batch-Workloads ausführen.
  • Die Mindestversion von Java wurde auf 11 erhöht, mit Unterstützung bis Java 17.
