kubeflow v1.9.0

Diese Version wurde für die Kubeflow-Plattform-Version 1.9.0 erstellt.

HINWEIS: Die folgenden release notes gelten nur für die Komponenten im kubeflow/kubeflow-Repository.

Wesentliche Änderungen

Zentrales Dashboard

  • Bereinigen Sie die Homepage und gruppieren Sie die Links in der Seitenleiste von Kubeflow Pipelines: https://github.com/kubeflow/kubeflow/pull/7583
  • Mitwirkende für alle eigenen Namespaces verwalten: https://github.com/kubeflow/kubeflow/pull/7582

Kubeflow-Notizbücher

  • Standardpakete aktualisieren (Jupyter, VSCode, RStudio, PyTorch, Tensorflow, CUDA usw.): https://github.com/kubeflow/kubeflow/pull/7590 – Ermöglichen Sie die Ausführung von Notebooks mit eingeschränkten Pod-Sicherheitskontexten: https://github.com/kubeflow/kubeflow/pull/7622
