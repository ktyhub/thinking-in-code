What’s new in 1.109.0

982 PRs. 144 added, 424 fixed, 60 changed, 17 improved, 9 removed. 5 need action

Action required

  • Routing and fallbacks: Change string fallback targets to lists of model names (#48943)
  • Caching: Switch cache_params.type from disk to local or redis, since the disk cache backend (diskcache) has been removed (#48114)
  • Routing and fallbacks: Add optional_pre_call_checks: ["enforce_model_rate_limits"] to keep a hard rpm cap on deployments (#48873)
  • Vertex AI and Gemini: Set drop_params: true or stop sending temperature, top_p and top_k to Gemini 3.6 Flash, 3.5 Flash-Lite and newer (#47645)
  • Deployment: Deploy Lens from its own chart and set lens.* in your values (#49169)

Highlights

  • Admin UI: Added a Chat UI with a model hub, image generation and usage metrics (#48108)
  • Routing and fallbacks: Added mid-stream fallback continuation so a streaming chat cut off mid-answer continues on the configured fallback (#41127)
  • Deployment: Added LITELLM_OFFLINE_MODE to turn off every fetch LiteLLM makes on its own with one switch (#48096)
  • Cost tracking and pricing: Added model_info.pricing_provider to price a deployment from another provider’s catalog rates instead of $0 (#47620)
  • Vertex AI and Gemini: Added Gemini 3.1 Flash TTS support, including multi-speaker voices and mp3, opus, alaw and mulaw output (#31915)
  • SDK: Fixed tool calls on completion() and responses() failing with No module named 'mcp' on base SDK installs (#45961) Also in 1.108.4
