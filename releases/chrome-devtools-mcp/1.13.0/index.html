chrome-devtools-mcp v1.13.0

minor PublishedNov 11, 2026 SourceChromeDevTools/chrome-devtools-mcp Chinese translation

chrome-devtools-mcp chrome-devtools-mcp-v1.13.0

1.13.0 (2026-11-11)

🎉 Features

  • add logpoints built on the DevTools BreakpointManager (#3211) (0877ee0)
  • add page-scoped network mocks (#3384) (1d692d3)
  • support upstream network mock responses (#3420) (c4bf342)

🛠️ Fixes

  • config: accept config files with a UTF-8 BOM (#3365) (63170b1)
  • console: stop resolving a cyclic Error.cause chain after 10 causes (#3338) (172656a)
  • disable set_logpoints when —no-javascript-evaluation is set (#3415) (11fcc59), closes #3414
  • extensions: say list_extensions only lists unpacked extensions (#3433) (1383bb9)
  • ignore an invalid cached version in the update check (#3392) (3a9f378)
  • input: validate press_key and submitKey parameters in Zod schema (#3382) (375a269)
  • network: start an empty request list for navigations without a request (#3357) (b701776)
  • normalize non-Error values thrown by tool handlers (#3068) (535a3dc)
  • performance: error when performance_stop_trace is called on a non-recording page (#2971) (#3117) (1ab630a)
  • plugin: launch the Claude Code MCP server with npx —prefix (#3353) (a24334d)
  • preserve task serialization on request cancellation (#3079) (03fd4e8)
  • report page loads that keep the URL (#3395) (3cc38bb)
  • save binary request bodies byte for byte (#3404) (e3eb901)
  • suggest —headless when Chrome cannot find an X server (#3428) (8b0856a)
  • url: unwrap view-source: before all scheme checks in validateUrl (#3335) (7275268)
  • wait: explain whitespace-sensitive text matching (#3350) (81a0379)

📄 Documentation

  • add Pi client configuration (#3364) (bc0d93e)
  • clarify custom browser launch and connection options (#3386) (7e10c08)
  • input: note that press_key cannot drive native <select> popups on macOS (#3288) (8e79bd0)

⚡ Performance

  • memory: drop async parents of request initiators in NetworkCollector (#3345) (ca6f834), closes #3344

🏗️ Refactor

  • re-export only used Zod runtime members from third_party barrel (#3439) (6b056c8)
  • reuse Zod schemas and validate integer viewport dimensions (#3367) (3c609da)
