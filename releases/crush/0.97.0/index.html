crush v0.97.0

Crushed It!

This release introduces many new features that improve QoL by a ton! Brought to you by Charm and our favorite contributors!

Toggle MCPs

Thanks to awesome @BrunoKrugel, you can now turn off MCP servers from the UI, globally, or locally.

Git Branches

At last: @taciturnaxolotl and @Gustave-241021 have brought Git branch display to Crush, which is so useful.

More UI and QoL changes:

  • ChatGPT OAuth now refreshes with Catwalk
  • Claude Channels, part 2/3 by @joestump
  • Toggle Sidebar on and off with ctrl+b by @andreynering
  • Quit dialog improvements and mouse support by @meowgorithm

Fixed!

  • Fixed clipboard false reporting successful copies by @taciturnaxolotl
  • Count Anthropic cache-creating tokens by @yanyukang2003-ux
  • Correctly resolving the project data directory in session and stats by @devYRPauli

This release is filled with improvements! Read more below!

See you next time, Charm XX 🔆

Verifying the artifacts

First, download the checksums.txt file and the checksums.txt.sigstore.json file files, for example, with wget:

wget 'https://github.com/charmbracelet/crush/releases/download/v0.97.0/checksums.txt'
wget 'https://github.com/charmbracelet/crush/releases/download/v0.97.0/checksums.txt.sigstore.json'

Then, verify it using cosign:

cosign verify-blob \
  --certificate-identity 'https://github.com/charmbracelet/meta/.github/workflows/goreleaser.yml@refs/heads/main' \
  --certificate-oidc-issuer 'https://token.actions.githubusercontent.com' \
  --bundle 'checksums.txt.sigstore.json' \
  ./checksums.txt

If the output is Verified OK, you can safely use it to verify the checksums of other artifacts you downloaded from the release using sha256sum:

sha256sum --ignore-missing -c checksums.txt

Done! You artifacts are now verified!
