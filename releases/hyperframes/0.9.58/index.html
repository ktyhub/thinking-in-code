hyperframes v0.9.58

HyperFrames v0.9.58

Released on 2026-11-16.

Studio exports a sealed preview’s checked element reads and stand-ins, and renders, carve and the audio engine keep to the project’s own files. This release also carries everything prepared as v0.9.57, which never reached npm.

Features

  • Studio: A sealed preview frame forwards Studio’s playback keys (b741ecf13, #7844).
  • CLI: Show and open the page to manage or cancel a paid plan (b2e6076b7, #7784).
  • Studio: Export a sealed preview’s checked element reads and stand-ins (a0848ad35, #7918).

Fixes

  • CLI: Check and info never probe a composition’s remote media URLs (78648113d, #7942).
  • CLI: Open starts the desktop app in the home folder, not the folder it runs in (a2e7306b2, #7937).
  • CLI: Studio thumbnails and Ctrl-C cleanup under a restricted page network (707e20f18, #7941).
  • Studio Server: A host that built a page on the build worker can exit (e8f1fff5f, #7939).
  • CLI: Commands that open a composition honor PRODUCER_RESTRICT_PAGE_NETWORK (49e9424ba, #7935).
  • Engine,producer,cli: Media inputs refuse formats that open other files (ead110aab, #7931).
  • Engine: Check the resolved address of a restricted download under Bun too (04b690361, #7860).
  • Parsers: Bound total expansion in the GSAP timeline inliner (aed28486f, #7930).
  • Nested .hyperframes stays private, capture page server checks Host, project manifests pin no CLI (d5f0b1a5b, #7927).
  • Studio Server: Sub-composition previews build off the request thread within a deadline (d159ec51c, #7857).
  • Publish: A first release attempt no longer fails looking for an artifact a retry would reuse (9f85cf0a2, #7929).
  • Player: The Safari audio check no longer flakes on a clean ten-take play (916bcc83a, #7685).
  • Core: A color-graded video’s dissolve and wipe play in preview and export (889143eac, #7756).
  • Media Use: The carve bundle exports analyseCarveDynamics, so carve runs again (94e499d8c, #7893).
  • Parsers: Past 10,000 identical elements every id is still unique (472909914, #7919).
  • Producer: The plan copy checks every project entry, whatever its name (7aaeb9371, #7906).
  • Producer: Render compile never inlines private project files named by @font-face (209477b65, #7925).
  • Studio: The preview picture takes its box’s size in the same frame, scaled or not (1e040f6fe, #7907).
  • Engine,producer: Render media readers skip private project files and text-art input (6411df4e3, #7928).
  • Media Use: Carve runs its own copy of core’s analysis, never the project’s (25c603521, #7926).
  • Studio: A host that shows a still gets a preview reload with one page at a time (dab8dc807, #7905).
  • Warnings that name project files print control characters as visible escapes (d42bbd67f, #7863).
  • Studio: Recovery drafts are kept by each project’s own server, never the browser (2be03408d, #7904).
  • Media Use: Audio engine reads and writes only inside the project folder (c2c6d8c59, #7897).
  • CLI: Batch outputs from a template that starts with a placeholder stay in the working folder (cf44c60cd, #7868).

Docs & Examples

  • Skills: Style-sampling pulls the template every time, so a received copy is checked first (d796fd59e, #7924).

Internal

  • Skills: Read the ClawHub token from the main-only clawhub environment (5d5e2c062, #7923).
  • Studio Server: Give tests the CLI’s 20 s ceiling so a busy CI runner stops timing them out (8ec98be29, #7933).
  • Engine: Browser pool tests never start the host’s cached Chrome (cadcdb955, #7759).
  • Publish: Publish only tarballs npm reads the way the check does (dac0468f7, #7922).
  • Publish: Bind Lambda release retries to immutable run artifacts (8e8eeb205, #7920).
  • Publish: The release keeps only Lambda assets npm pins or this run built (11a7d2749, #7880).
