hyperframes v0.9.65

HyperFrames v0.9.65

Released on 2026-11-17.

Studio’s sealed preview now draws motion paths, reads keyframes and keeps a moved layer in place when you add a keyframe. Studio’s error and analytics events no longer carry your error text, file paths or selectors.

Features

  • Studio Server: Let a host count the requests the API refuses with 403 (078e54d00, #8049).

Fixes

  • Studio: Error events send a class, a shape and Studio’s own frames, not the error’s words (195aa2f0c, #8114).
  • Studio: Add keyframe on a sealed preview keeps a moved layer in place (ce3decb6b, #8117).
  • CLI: Check’s face pass reads only media the page may load (c4a4167aa, #8116).
  • Studio: A sealed preview moves and saves a layer its animation moves (7a9d78e69, #8105).
  • Studio: Analytics send path and selector facts, not the paths and selectors (d87285387, #8109).
  • Studio: The motion path draws and can be created in a sealed preview (373d987e3, #8108).
  • Skills: Select standalone CLI releases through the launcher (414adffb8, #8102).
  • Figma: Write .media and component outputs without following links (a765c9379, #8111).
  • Studio: The edit bench waits out the preview swap once a plain element gains keyframes (ba62d7748, #8113).
  • CLI: Windows Chrome cleanup and process reads no longer pass PowerShell command text (b930c4d2d, #8085).
  • Release: The no-account pusher check reads its file directly, with no pipe (740796888, #8095).
  • Producer: Bound the static media selector check by the page it walks (435dd0e68, #8091).
  • Studio: A selected element stays drawn and draggable after a sealed preview reloads (1bf629c1d, #8081).
  • Studio: A click after two quick seeks adds the keyframe in a sealed preview (93622154e, #8103).
  • Release: List the MCP server as com.heygen/hyperframes, signed by heygen.com’s key (88ba1b4d7, #8106).
  • Media Use: Audio scripts judge a received .env by the CLI’s rule (bc5259d2d, #8086).
  • Media Use: Write local generator output into private per-run folders (ac33c1f2b, #8030).
  • Studio: GSAP keyframe and value reads work in a sealed preview (133965e4f, #8003).
  • CLI: Keep files received that a host’s kept record still lists (183bf2a41, #8100).
  • CLI: Say a listed received file is gone, and drop a media file’s line on rename (4a59fef2d, #8098).

Catalog

  • Watch the MCP registry hourly for HeyGen listings server.json never held (0b0108f2f, #8107).
  • Registry: Use the installed launcher in block guides (1c99314a6, #8101).

Internal

  • Github: Secret scanning skips the generated skills manifest (06578d941, #8115).
  • Studio: The GSAP reply check shares the frame record and handle checks (53a493edc, #8104).
