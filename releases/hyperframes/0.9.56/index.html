hyperframes v0.9.56

HyperFrames v0.9.56

Released on 2026-11-16.

Studio’s preview and the local servers now act only for their own pages. The CLI keeps its cache, history and restores inside the project. The arm64 Lambda image ships only the reviewed ffmpeg build, and large previews build faster.

Fixes

  • Studio Server: The composition file servers no longer serve credential or tool-state files (014326b40, #7889).
  • Studio Server: Lint and probe run only for requests from Studio’s own pages (bbac8900e, #7894).
  • Studio Server: A history restore stays inside the project and uses only intact copies (478313ba0, #7902).
  • Studio: Take playback works for a preview its server made opaque (1e542956d, #7815).
  • Studio: The preview frame keeps the sandbox origin its host set (b650d0d19, #7886).
  • Studio: Present decks open only in their own site, and the preview reads only its own frame’s messages (4067efc45, #7877).
  • Core: The runtime bridge checks each control message before acting on it (97d8f26e7, #7892).
  • CLI: render --docker keeps the host’s page-network restriction inside the container (5d8605eb8, #7890).
  • CLI: preview --stop stops only the process the system reports holding the port (ace8a78dc, #7882).
  • CLI: The check cache is saved only as a project record, never through a linked file (7801e3ff3, #7884).
  • CLI: History turn ids read from the project folder are checked and sent encoded (6efa6b635, #7883).
  • CLI: Catch-up lists only the turns the app added after the hand-off (0f23f40f8, #7874).
  • CLI: A received-files record in a folder under the project counts for a render (1c159c550, #7900).
  • CLI: Media-use copies only the sound effects its bundled index names (ed93a1312, #7895).
  • Media Use: Local models start from a folder outside the project (756c2c6c1, #7888).
  • Engine: A cached browser is used only when its files match the pinned build (56a2d0c53, #7865).
  • Engine: Timeline frame predictions stay within the render’s frames (f5a74a567, #7885).
  • Engine: Each superset extraction works in a folder of its own (a4139e9ea, #7901).
  • Parsers: Reading a canvas scaffold’s width and height takes the same short time on any input (b856a1d63, #7873).
  • Lint: Agent-made scenes and sound effects stay on one timeline lane (98208241e, #7775).
  • Skills: Standalone installs run the CLI through its launcher too (3fc3050bc, #7879).
  • AWS Lambda: A release ships the arm64 ffmpeg only when it matches the digest committed beside its build (d9488119b, #7872).

Performance

  • Core: A preview build reads a large page without copying it on every pass (082d63683, #7878).
  • Producer: Compile and render-telemetry tag scans take time in step with the page’s size (82fdf406c, #7896).

Internal

  • Publish: Every npm publish waits on the npm-publish approval (a54de748e, #7870).
  • Publish: Prebuilt tarballs publish from a job that runs no code from the release commit (af0560c85, #7869).
  • CI: Publishing workflows run only for main (7bd6b9daf, #7875).
  • CI: Test fixtures no longer look like real HeyGen keys, and CI rejects one that does (5dc3b336a, #7876).
