hyperframes v0.9.61

HyperFrames v0.9.61

Released on 2026-11-17.

Received projects and the files they reach stay inside their own folder across render, preview and Studio, and a sealed preview reloads in place in a fraction of a second. This release also carries every change listed for 0.9.60. That version never reached npm: its publish was refused because it ran from the release PR’s merge ref, and since #8020 a stable release publishes from the push to main that merges it.

Features

  • Engine: Render telemetry says why a page cannot reuse still frames (c8df284b2, #7993).
  • Studio: An element’s source-parsed animations are part of Studio’s API (efc91fc87, #8061).
  • Producer: Enforce expected output dimensions before capture (8a13b2caf, #7871).

Fixes

  • Producer, Parsers: Render compile never looks for a scene’s assets on another computer (524ea46bf, #8063).
  • CLI: Refuse media-proxy copies another site asks for in play and the static server (f97e28905, #8058).
  • Producer: Readers re-check outside-linked compositions, and the refusal names a step every surface can take (4721739ee, #8034).
  • CLI: Leave files from outside the project out of Lambda and Cloud Run site uploads (39347da9d, #8060).
  • CLI: A host can name projects whose received files are expected or all received (5ea86450a, #8025).
  • Core: Only Studio’s own preview pages get the editing port, and undo sets only safe attributes (55291c00c, #8057).
  • Lint: Match a timed wrapper’s close tag literally (3e01f691d, #8028).
  • Studio: Each drag shows as its own undo step once its save lands (647bdd4d7, #8033).
  • CLI: A refused reverse start reports whether HeyGen sent the refusal (53080581c, #8053).
  • Producer: Cap a render’s total sub-composition expansion (b29e40d70, #8045).
  • Inspector: The inspector’s Chrome starts as root or in a container (f91bbf0da, #8050).
  • Refuse media paths that ffmpeg’s image2 demuxer would read as a pattern (fe93f9cd4, #8047).
  • CLI: A project .env provider key gives way to the person’s own credential (14c4e4c26, #8041).
  • CLI: Escape audio and media-use output, pin model files (c4439890c, #8013).
  • Producer: Keep the probe stage’s media pre-checks linear in page size (e21f56dca, #8044).
  • Studio: Colour grading works in a sealed preview (d7d416124, #7999).
  • Engine: Bound the proxied host pre-check by the download’s timeout (06b632017, #8048).
  • Engine: The GPU, host-ceiling and HDR launches keep the sandbox where the host allows it (7b27fbc84, #8038).
  • Studio Server: Cache reads never follow a link the project ships (70820b386, #8039).
  • Engine: Check proxied download hosts; keep raw GIF downloads private (5fcce21a6, #8040).
  • Skills: Locate.mjs reads the system font in place, not a shared /tmp copy (5b2990fc1, #8042).
  • Studio: Caption editing works in a sealed preview (915021265, #8002).
  • Producer: Cap the software encoder to the cores capture leaves free (f89f6d3d4, #8019).
  • Studio: A sealed preview’s reload shows in a fraction of a second, not after 8 s (9daa7e876, #8015).
  • Skills: Run bundled TTS helpers from the skill folder, not the working directory (6115945cf, #8035).
  • A received-files record follows Studio renames, moves and deletes, and a nested record can’t be moved out of reach (f5bb3e551, #7989).
  • Studio Server: A loopback page with no fetch metadata is marked unless the app framed it (b6e1e8dda, #8017).
  • Studio: The copied render command carries no composition text a shell can run (19743ea09, #8012).
  • The dev Studio’s renders follow the received-project rule, and a received project’s .env keys never replace the person’s own (8239fe470, #8004).
  • Producer: Trusted renders refuse outside-linked compositions unless —include-outside-files (00d03a412, #8024).
  • Studio Server: Audio decodes are bounded, stop when nobody waits, and their cache is capped (5f6995fe7, #7991).
  • Studio: A modal opened from a popover or menu closes first on Escape (c8235f123, #7976).
  • Engine: GPU probe, HDR capture and host-ceiling probe keep a required sandbox (fb5f9e52c, #8018).
  • CLI: Render —docker applies the received-project rule on the host (e58fb3249, #8016).
  • Studio: An undo on a sealed preview shows in place, not after a reload (fee03bfbe, #8009).
  • CLI: Files from outside the project are uploaded only once approved (22b615f1a, #7995).
  • CLI: Compare and keyframes —shot serve only the files a bare HTML file names (346579b6b, #8006).
  • Preview image prep reads no HEIC or GIF outside the project unless render would (f880693cf, #8001).
  • Engine: The playlist folder check reads colon, query and fragment names as ffmpeg resolves them (38aaad1b2, #8014).
  • Studio Server: Bound preview stills and keep proxy work to the Studio’s own pages (bffe8d598, #8007).
  • Producer: Local renders leave out scripts from outside the project unless included (581a43bb6, #7998).
  • CLI: Only the Studio’s own origin may frame the Studio page (02c1fb48e, #8000).
  • Producer: Linear probe media check, and renders refuse composition HTML over 16 MB (d53b6059b, #7992).
  • Studio Server: History writes and claims follow Studio’s write rule (32fe10a8b, #7988).
  • CLI: Error boxes and command failure lines print control characters as visible escapes (5979991d5, #7987).

Internal

  • Publish: A stable release needs a maintainer’s approval, not any account’s (4807799c4, #8062).
  • Raise the producer packed-size budget to 936,000 bytes (909a9b183, #8054).
  • Publish a stable release from the push that merges its release PR (5f6007ffc, #8020).
  • Publish: A prerelease tag publishes only to an allow-listed dist-tag (9fae4ffd8, #7963).
  • CLI: A received project’s preview still converts a photo inside it (0ad24ba83, #8021).
