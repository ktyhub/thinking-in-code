hyperframes v0.9.66

HyperFrames v0.9.66

Released on 2026-11-18.

Studio’s sealed preview now takes property edits, crops, resizes and plays slideshow scenes. A preview no longer sits in Buffering when a clip stops downloading, and the player can carry your own branding.

Features

  • Player: Add customizable branding to the preview player (a9b4745f1, #7718).

Fixes

  • AWS Lambda: Match the shell to its own pin, ship only hashed files, refuse the shell ZIP in CDK and SAM (61d65e717, #8173).
  • AWS Lambda: Pin the shell ZIP route, gate ZIP headroom, match arm64 fonts to x86 (ed3f05a05, #8170).
  • Studio: Property panel style and attribute edits show in a sealed preview (b525686e7, #8149).
  • Compiler: Rebase composition asset paths from the file read and charge what they add (bb55c1ea7, #8166).
  • CLI: Figma commands print manifest and folder text with visible escapes (420f14d15, #8126).
  • CLI: Show control characters in printed names as visible escapes (3e788fb15, #8008).
  • Skills: The launcher’s floor is 0.9.65, the oldest release Desktop ships (140b70140, #8159).
  • AWS Lambda: Chrome-headless-shell 158 in the arm64 video image, sparticuz 153 in the x86 ZIP (81d73d227, #8155).
  • Producer: Inline a local font only while the page stays within its size limit (3b79b1858, #8152).
  • Studio: A sealed preview’s element reads are bounded, and a frame with no agent answers at once (e623031f3, #8055).
  • Core: Each editing client takes its own port, so a sealed preview answers Studio again (e95cdf7d7, #8154).
  • Core: Keep SVG id renaming linear in the page size and within the render size limit (5bd3e3242, #8147).
  • Studio: Check every file a folder move or delete takes along (7ea012953, #8143).
  • Studio: A sealed preview takes its film’s size from the player (d574ded1e, #7967).
  • Core: Keep the styles of a composition whose id contains $ patterns (12a2f83c4, #8141).
  • Compiler: Bound composition variable styles and variable media sources (c6e3f30be, #8144).
  • Core: A clip that stops downloading no longer holds the preview in Buffering forever (01331014d, #8138).
  • Player: Keep the video playing when you jump to another moment (3ee095bde, #7719).
  • CLI: Run global updates from the home directory (e99cd75b4, #8131).
  • Media Use: Escape control characters in the remaining resolve and cube-validate lines (9a096d72f, #8059).
  • Media: Keep each index.md row on one line and show control characters as escapes (ebddc4248, #8127).
  • CLI: Tests read opencv.js from a CI cache, never a CDN mid-test (e6cee094b, #7968).
  • Studio: Crop and scale resize work in a sealed preview (c569417bb, #8005).
  • Core: Treat files package managers run by default as tool-trusted (5f06e1b0a, #8129).
  • Skills: The launcher never starts a CLI older than its security floor (63c8f8ef6, #8125).
  • CLI: Say when check’s face pass stopped a source at its time limit (59fbb22eb, #8122).
  • CLI: Media-use scripts read the host’s kept record copy as the CLI does (c27adb35f, #8119).
  • Studio: Slideshow scenes, block stacking, drill-down and shortcuts work in a sealed preview (80bf6a9dd, #8118).
  • CLI: A rename keeps the received-files record listing the moved file (cb2b51525, #8112).

Docs & Examples

  • Ci: Say the npm-publish environment needs a reviewer’s approval (d94aa5e30, #8123).

Internal

  • Producer: The missing-file render detail added in this cycle was taken out again before release, and returns in a later one (cfea8cfff, #7955, eb7dc14e8, #8146, 94d06663b, #8174).
  • Player: One hung Safari run no longer fails every Safari run after it (9acf26868, #8169).
  • Studio: Share one sealed preview frame that delivers messages like a browser (640cb3792, #8165).
  • Chrome: Pin chrome-headless-shell 158.0.8127.36 wherever the repo installs it (793052502, #8145).
  • Lint: Fail when a RegExp is built from text that is not escaped (dcdd34071, #8128).
