11/01
v1.6.1 patch ZH

全网搜索、Reddit、小红书、B站在 1.6.0 里会出现的几种'明明能查却报错'或'显示成功但内容是空的'，这版都修好了。；电脑上别的软件占用了浏览器端口时，可以换一个端口，不用关掉那个软件。；复制登录失败时会如实告诉你，不再假装成功。；Windows 上小红书带特殊符号的链接能正常打开了。

 10/23
v1.6.0 minor ZH

从旧版升级：把'帮我更新 Agent Reach'那句话发给你的 AI 就行。你的密钥和设置都保留，旧版程序会自动删掉。；加一个平台只要说一句，需要的软件都会自动装好，不需要管理员密码；你只需要登录或者填一个 Key。；小红书、推特这类要登录的平台，改用 Agent Reach 自己的专用浏览器，不弹窗、不占用你的浏览器；多个 AI 可以同时查。

 06/11
v1.5.0 minor ZH

Agent Reach 从「工具集合」升级为「能力层」:每个平台 = 首选 + 备选的有序后端列表,当下最稳的接入方式替你实测选好、装好、体检好——接入方式换代,你无感。本版全部选型基于 2026-06 真机实测(32 项端到端测试)。
