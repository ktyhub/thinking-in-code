TencentDB-Agent-Memory v2.0.2

patch PublishedOct 9, 2026 SourceTencentCloud/TencentDB-Agent-Memory Chinese translation

TencentDB-Agent-Memory v2.0.2

[2.0.2] - 2026-10-09

产品定位：让 Agent 的经验、文档、代码沉淀成可复用资产，让下一位 Agent 直接读档。详见 README_CN.md。

🗄️ 存储后端可扩展 · 支持 MongoDB

团队记忆不再绑定单一数据底座，MongoDB 后端能力进一步补全：

  • 新增 memory-prompt 与 generation-ref 两类存储，覆盖更多记忆数据结构
  • 一键入口 ./start-all-mongo.sh 会把 STORE_MODE 持久化写入 .env，后续启动 保持同一后端，不再每次重复配置
  • 修复索引冲突场景的自愈能力，重复的默认/抽取记录不再导致启动报错

🔀 更多客户端接入

  • OpenCode 新增官方 Memory adapter 配置包（含 opencode.json 与接入文档），按说明配置即可接入，无需编写插件代码
  • OpenCode 支持 2.0 的 v2 provider 配置结构，新版客户端可直接复用官方 opencode.v2.json
  • DeepSeek Harness 新增 dsh 桌面端适配，配置方式可参考 ./agents/dsh/README.md 中 1.6 的部分
  • 新增 Pi 客户端接入（类似 Codex 的 AI Agent 客户端，走 OpenAI Chat 协议）

🧠 外部源导入（Wiki / 代码 / 任务）

  • 新增从外部任务管理系统导入 Task 的能力，任务卡片直接展示来源、支持 ID 复制与分页
  • 新增外部代码源（私有仓）注册与凭据隔离，各团队持有独立凭据、互不可见
  • 新增 Wiki 外部来源导入，与代码源、任务源一起补齐外部资产导入链路

🧰 技能（Skill）体验优化

  • 冷启动批量技能抽取新增严格模式，抽取质量更可控
  • 技能抽取自动跟随用户语言，生成内容更贴合使用习惯
  • 技能列表支持按使用活跃度排序，高频技能更容易被找到

🎛️ Memory Hub 面板

  • 任务卡片支持来源展示、ID 复制与分页优化，批量导入交互更顺畅
  • 手动刷新时自动重置时间筛选，新产生的记忆能即时看到

🔄 会话与接入体验

  • 会话引导在更多客户端下更稳定：自动选中唯一 Agent、资产确认更精准、预设失败时 自动绕过而非卡住
  • 修复 WorkBuddy 并行子代理反复弹窗的问题，会话归一更稳健
  • 修复多种客户端下记忆命令、工具结果污染、历史消息重复等影响体验的问题

🐛 修复

  • 修复无 embedding 场景下 BM25 召回异常、L0 工具结果污染与原文展示问题
  • 修复记忆召回为空、历史消息重复、多团队切换列表截断等问题
  • 修复 Claude Code 的 AGENTS.md 指令丢失等问题
  • 修复部署脚本在部分环境下的兼容性问题
