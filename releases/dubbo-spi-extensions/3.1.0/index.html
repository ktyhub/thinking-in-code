dubbo-spi-extensions v3.1.0

What’s Changed

Reference

  • Compatible with Apache Dubbo [3.1.x](https://github.com/apache/dubbo/tree/3.1)

Enhancement

  • [dubbo-cluster-specify-address-dubbo2]support v2 ip spec by @wxbty in [#179](https://github.com/apache/dubbo-spi-extensions/pull/179)

  • [dubbo-cluster-polaris-dubbo2] Add polaris extensions support by @andrewshan in [#184](https://github.com/apache/dubbo-spi-extensions/pull/184)

  • [dubbo-filter-polaris-dubbo2] feat: separate the circuitbreaker and ratelimit filters, to make it more decompose to developers by @andrewshan in https://github.com/apache/dubbo-spi-extensions/pull/187

  • [dubbo-filter-seata] Set seata core as optional dependency by @AlbumenJ in https://github.com/apache/dubbo-spi-extensions/pull/188

  • [dubbo-gateway-extensions] add Gateway mode extension by @wxbty in [#205](https://github.com/apache/dubbo-spi-extensions/pull/205)

  • [polaris ] support polaris circuitbreaker ability by @chuntaojun in [#212](https://github.com/apache/dubbo-spi-extensions/pull/212)

  • [Cross thread] tag corss thread by annotation in dubbo-cross-thread-extensions by @carlvine500 in [#215](https://github.com/apache/dubbo-spi-extensions/pull/215)

  • [tag subnets] add tag by subnets for near-rpc by @carlvine500 in [#216](https://github.com/apache/dubbo-spi-extensions/pull/216)

  • [Serialization] add fury serialization framework to dubbo by @chaokunyang in [#226](https://github.com/apache/dubbo-spi-extensions/pull/226)

  • [dubbo-serialization-jackson] Add jackson serialization extension by @aofall in [#231](https://github.com/apache/dubbo-spi-extensions/pull/231)

  • fix test case failed by @aofall in [#303](https://github.com/apache/dubbo-spi-extensions/pull/303)

  • Compatible with Apache Dubbo 3.1.0 branch by @aofall in https://github.com/apache/dubbo-spi-extensions/pull/334

Bugfix

  • Bugfix of retries and missing field by @wxbty in [#182](https://github.com/apache/dubbo-spi-extensions/pull/182)
  • Fix revert error description by @wxbty in [#209](https://github.com/apache/dubbo-spi-extensions/pull/209)
  • Fix move the recourse file to the corrent path in dubbo-serialization-jackson by @aofall in [#233](https://github.com/apache/dubbo-spi-extensions/pull/233)

Doc

  • Explicitly call out hessian-rpc is unstafe by default by @raboof in [#196](https://github.com/apache/dubbo-spi-extensions/pull/196)
  • Auto gen code tree doc by @songxiaosheng in [#224](https://github.com/apache/dubbo-spi-extensions/pull/224)
  • :memo: visit code tree to gen doc by @songxiaosheng in [#227](https://github.com/apache/dubbo-spi-extensions/pull/227)

Dependency Upgrade

  • Update kryo 5.3.0 -> 5.4.0 by @wxbty in [#190](https://github.com/apache/dubbo-spi-extensions/pull/190)](https://github.com/apache/dubbo-spi-extensions/pull/190)
