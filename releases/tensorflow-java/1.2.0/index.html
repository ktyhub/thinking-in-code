tensorflow-java v1.2.0

Changes

This release upgrades the native component to TensorFlow 2.21, merges tensorflow-ndarray back into this project, and adds small fixes to the gradient system. Due to a lack of available builds from upstream TensorFlow it drops support for Windows x86.

Updated TensorFlow-Java documentation is now available at tensorflow.github.io/java which will be maintained with this project. The old documentation pages at tensorflow.org/jvm and tensorflow.org/api_docs/java/org/tensorflow/package-summary are no longer maintained, but we are unable to remove them at the moment.
