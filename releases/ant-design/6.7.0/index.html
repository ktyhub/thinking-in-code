ant-design 6.7.0

minor PublishedNov 4, 2026 Sourceant-design/ant-design Chinese translation

ant-design 6.7.0

  • 🆕 Add Button, Tag, Steps, Alert, and Timeline support for the global ConfigProvider variant, and component-specific divider.variant configuration for Divider line styles. #59589 #59588 #59578 #59577 #59587 #59576 @QDyanbing
  • 🆕 Add suffix to DatePicker, TimePicker, Select, AutoComplete, Cascader, and TreeSelect to customize suffix content, with state-based rendering for selection components. Deprecate suffixIcon in favor of suffix while retaining compatibility. #59240 #59185 @QDyanbing @meet-student
  • 🆕 Add allowClear.tabIndex to Input, Input.TextArea, Mentions, InputNumber, Select, AutoComplete, TreeSelect, Cascader, DatePicker, and TimePicker to control clear-button Tab order. Add allowClear.label to Input, Input.TextArea, Mentions, DatePicker, and TimePicker for accessible clear-button names, with field-level ConfigProvider inheritance. #59566 #59567 #59548 @QDyanbing
  • 🆕 Add App Fragment ref support with component={false} in React 19.3 and later. #59281 @li-jia-nan
  • 🆕 Add BorderBeam items prop to configure each beam’s color, lineWidth, outset, and size, with the array length determining the beam count. #59095 @QDyanbing
  • 🆕 Add Cascader checkStrictly to select parent and child options independently in multiple mode. #59566 @QDyanbing
  • 🆕 Add component-specific ConfigProvider allowClear settings for Cascader, TreeSelect, and AutoComplete to configure their clear buttons globally. #59593 #59592 #59591 @QDyanbing
  • 🆕 Add Checkbox.Group and Radio.Group classNames and styles to customize group containers, items, icons, and labels. #59058 #59059 @QDyanbing
  • 🆕 Add InputNumber allowClear and onClear to clear values with customizable icons, disabled state, and accessible labels. #59251 @nikzanda
  • 🆕 Add Space align="stretch" to stretch child elements along the cross axis. #59005 @dogledogle
  • 🆕 Add Typography shimmer prop for animated shimmering text, with duration configuring motion and wait times separately. #59054 @zombieJ
  • 🛠 Align Input, Input.TextArea, Mentions, InputNumber, Select, AutoComplete, TreeSelect, Cascader, DatePicker, and TimePicker allowClear.disabled behavior so true removes the clear button consistently with allowClear={false}. #59548 #59566 #59567 @QDyanbing
  • 💄 Replace Alert container radius component token borderRadius with containerBorderRadius; migrate custom container radius overrides to the new token. #59305 @MadCcc
  • DatePicker
    • 🆕 Add DatePicker and TimePicker components.nowButton and components.okButton to customize Today/Now and confirmation buttons independently. Deprecate the legacy components.button while retaining compatibility. #59778 @yoyo837
    • ⌨️ Improve DatePicker and TimePicker keyboard and screen reader support, including arrow-key navigation, Enter/Space selection, and skipping disabled time options, plus keyboard activation and native disabled states for Today/Now footer buttons. #59778 #59367 @yoyo837
    • 🐞 Fix DatePicker and TimePicker ignoring clearIcon settings when an allowClear object omits clearIcon. #59565 @QDyanbing
    • 🐞 Fix DatePicker, TimePicker, and Calendar dependency imports in native Node ESM environments. #59261 @zombieJ
    • 🐞 Fix DatePicker parsing localized date input with Day.js when the component locale differs from the global locale. #59240 @QDyanbing
    • 🌐 Correct DatePicker zh_TW week-selection terminology. #59261 @zombieJ
  • Select
    • 🆕 Add Select autoComplete and ConfigProvider select.autoComplete to configure browser autocomplete behavior for the search input. #59566 #59632 @QDyanbing
    • ⌨️ Improve screen reader support for Select, Cascader, TreeSelect, and AutoComplete by hiding default decorative arrow, search, and loading icons. #59709 @droduit
    • ⌨️ Improve Select, Cascader, and TreeSelect clear-button keyboard accessibility with focus visibility, focus outlines, and localized accessible labels. #58267 @Pareder
    • ⌨️ Fix Select and AutoComplete screen reader announcements of option positions, total counts, and groups in virtual scrolling mode. #58993 @yoyo837
  • Table
    • 🆕 Add Table expandable.showExpandAll and expandable.onExpandAll to expand or collapse all expandable rows on the current page when using expandedRowRender. #59036 @nikzanda
    • 🆕 Add Table components.ExpandIcon and an expandable.columnTitle render function to customize row and expand-all controls. Deprecate expandable.expandIcon in favor of components.ExpandIcon while retaining compatibility. #59036 @nikzanda
    • ⌨️ Improve Table row selection accessibility with localized accessible names and keyboard access to custom selection menus. #58969 @thlovey
    • ⚡️ Improve Table performance when applying multiple column filters to deeply nested data. #59719 @Aminark
  • Tree
    • 💄 Improve Tree non-checkable selectable={false} nodes with disabled text colors and cursors, without hover highlighting. #58906 @EmilyyyLiu
    • 🐞 Fix Tree ignoring defaults and preventing uncontrolled updates when expandedKeys, selectedKeys, and similar props are explicitly undefined. #59274 @aojunhao123
    • 🐞 Fix Tree unexpectedly scrolling when a focusable element inside a node title receives focus. #59274 @aojunhao123
    • 🐞 Fix Tree drop targets before nested first-child nodes, overwritten custom drag text, and delayed hover expansion after unmount. #59274 @aojunhao123
  • Listy
    • 🆕 Add Listy rowKey callback’s second argument index to generate keys from row indexes. #59347 @aojunhao123
    • 🆕 Add Listy rowHoverable prop to disable row hover highlighting. #59273 @QDyanbing
    • 🆕 Add Listy scrollWidth prop to enable horizontal scrolling for virtual lists wider than the container. #59197 @aojunhao123
  • Pagination
    • 🆕 Add an optional third info argument with info.recommendPage to Pagination onChange when page size changes to help preserve the current data position, also available through Table and List pagination.onChange. #58604 @EmilyyyLiu
    • ♿ Improve Pagination list semantics and keyboard and disabled-state accessibility for pagination controls. #58604 @EmilyyyLiu
    • 🌐 Correct Pagination and page-size text in Armenian (hy_AM), Albanian (sq_AL), Nepali (ne_NP), and Traditional Chinese (zh_TW) locales. #59500 #59499 #58604 @yoyo837 @EmilyyyLiu
  • Button
    • 🐞 Fix Button ignoring tabIndex when href is set. #59732 @nikzanda
    • 🐞 Fix Button not applying component-specific non-solid variants from ConfigProvider when color is omitted. #59589 @QDyanbing
  • ColorPicker
    • 🆕 Add ColorPicker styles.popup.container and classNames.popup.container to customize the popup content container, and deprecate styles.popupOverlayInner while preserving compatibility until v7. #59743 @QDyanbing
    • 🐞 Fix ColorPicker ignoring styles.popupOverlayInner when styles is a function or configured through ConfigProvider. #59743 @QDyanbing
  • Dropdown
    • 🆕 Add Dropdown classNames.menu and styles.menu to customize the dropdown menu root element. #58979 @QDyanbing
    • 🐞 Fix Dropdown unexpectedly scrolling when autoFocus focuses the menu. #59786 react-component/dropdown#271 @github-actions @lkxdsb
  • Form
    • 🆕 Add Form and Form.Item labelAlign values start / end for label alignment that follows text direction, while retaining and deprecating legacy left / right values. #59760 @QDyanbing
    • 🐞 Fix Form.Item noStyle fields losing the parent validateStatus after being edited. #59708 @nikzanda
  • Input
    • ⌨️ Improve Input.OTP accessibility with localized cell names through locale.Input.otpCell and aria-invalid on each input cell. #59722 @droduit
    • 🐞 Fix Input.Search applying rootClassName to the inner input instead of the root element. #59582 @Chaoqi31
  • Menu
    • 🐞 Fix Menu parent submenu selection styles not updating after items load dynamically. #59786 react-component/menu#895 @github-actions @dogledogle
    • 🐞 Fix Menu submenu Escape navigation also closing the surrounding popup. #59786 react-component/menu#899 @github-actions @nrps9909
  • Slider
    • ⌨️ Add Slider ariaDescribedByForHandle prop to associate handles with accessible descriptions. #59110 @yoyo837
    • 🐞 Fix Slider failing to finish dragging when an ancestor stops mouseup propagation and potentially throwing when its container becomes unavailable during dragging. #59786 react-component/slider#1089 react-component/slider#1087 @github-actions @nrps9909
  • Splitter
    • ⌨️ Improve Splitter collapse controls with localized accessible names and custom icon aria-label overrides. #58978 @thlovey
    • 🐞 Fix Splitter remaining in a dragging state after a touch gesture is cancelled. #59712 @Aminark
  • Tabs
    • 🆕 Add Tabs more.open and more.onOpenChange to control the overflow menu, retaining and deprecating more.visible and more.onVisibleChange. #59259 @QDyanbing
    • 🐞 Fix Tabs moreIcon being overridden by ConfigProvider tabs.more.icon and tabs.moreIcon. #59690 @nikzanda
  • Upload
    • 🐞 Fix Upload incorrectly detecting image thumbnails when URL query parameters or fragments contain slashes. #59649 @Aminark
    • 🐞 Fix Upload not triggering onFocus when focus enters select, drag, and picture-card layouts. #59002 @nrps9909
  • ⌨️ Improve Collapse accessibility with Space key activation without page scrolling and aria-controls linking expanded headers to their panels. #59771 @yoyo837
  • 🐞 Fix Card tabProps.onChange not being triggered when switching tabs. #59655 @dogledogle
  • 🐞 Fix Tooltip and Popover text shifting after the opening motion. #59729 @th74100
  • 🐞 Fix theme.getDesignToken failing to retrieve Design Token when algorithm is an empty array. #59695 @nikzanda
  • 🐞 Fix numeric 0 being ignored in Input prefixes, suffixes, and clear icons, Mentions suffixes, Cascader expand and loading icons, and Pagination custom navigation items or icons. #59548 #59566 #58604 @QDyanbing @EmilyyyLiu
  • 🐞 Fix Checkbox and Radio unexpectedly closing Tooltip when the pointer moves from the control to its text, and Radio incorrectly firing onMouseEnter and onMouseLeave. #59701 #59699 @nikzanda
  • 🐞 Fix Statistic displaying exponential notation and ignoring precision and separators for very small or very large numbers. #59693 @RaphaelFakhri
  • 🐞 Fix TreeSelect ignoring ConfigProvider className and style, and root classNames and styles incorrectly affecting the popup. #59343 @dogledogle
  • 🌐 Add German, French, and Italian translations for the clear button’s accessible name in Input, Select, and related components. #59723 @droduit
  • 🆕 新增 Button、Tag、Steps、Alert 和 Timeline 对 ConfigProvider 全局 variant 的支持，并支持通过 divider.variant 统一设置 Divider 的分割线样式。 #59589 #59588 #59578 #59577 #59587 #59576 @QDyanbing
  • 🆕 新增 DatePicker、TimePicker、Select、AutoComplete、Cascader 和 TreeSelect 的 suffix 属性，用于自定义后缀内容；选择类组件支持根据状态动态渲染。suffixIcon 保持兼容并废弃，请迁移至 suffix。 #59240 #59185 @QDyanbing @meet-student
  • 🆕 新增 Input、Input.TextArea、Mentions、InputNumber、Select、AutoComplete、TreeSelect、Cascader、DatePicker 和 TimePicker 的 allowClear.tabIndex；Input、Input.TextArea、Mentions、DatePicker 和 TimePicker 新增 allowClear.label，支持设置清除按钮的 Tab 顺序和无障碍名称，并按字段继承 ConfigProvider 配置。 #59566 #59567 #59548 @QDyanbing
  • 🆕 新增 App 在 React 19.3 及以上版本使用 component={false} 时的 Fragment ref 支持。 #59281 @li-jia-nan
  • 🆕 新增 BorderBeam items 属性，可分别设置每束光的 color、lineWidth、outset 和 size，并由数组长度决定光束数量。 #59095 @QDyanbing
  • 🆕 新增 Cascader 的 checkStrictly 属性，支持在多选模式下独立勾选父子选项。 #59566 @QDyanbing
  • 🆕 新增 Cascader、TreeSelect 和 AutoComplete 的 ConfigProvider allowClear 全局配置，可分别统一设置清除按钮。 #59593 #59592 #59591 @QDyanbing
  • 🆕 新增 Checkbox.Group 和 Radio.Group 的 classNames 和 styles，可自定义组容器、选项、图标和文本的样式。 #59058 #59059 @QDyanbing
  • 🆕 新增 InputNumber allowClear 和 onClear，可一键清空数值，并自定义清除图标、禁用状态及无障碍名称。 #59251 @nikzanda
  • 🆕 新增 Space align="stretch"，使子元素沿交叉轴拉伸对齐。 #59005 @dogledogle
  • 🆕 新增 Typography shimmer 属性，为文本显示流光效果，可通过 duration 分别设置动画和等待时长。 #59054 @zombieJ
  • 🛠 统一 Input、Input.TextArea、Mentions、InputNumber、Select、AutoComplete、TreeSelect、Cascader、DatePicker 和 TimePicker 的 allowClear.disabled 行为，设置为 true 时移除清除按钮，与 allowClear={false} 保持一致。 #59548 #59566 #59567 @QDyanbing
  • 💄 调整 Alert 容器圆角组件 Token，将 borderRadius 替换为 containerBorderRadius，自定义容器圆角时需使用新 Token。 #59305 @MadCcc
  • DatePicker
    • 🆕 新增 DatePicker 和 TimePicker components.nowButton 和 components.okButton，支持分别自定义底部的“今天／此刻”按钮和确认按钮。旧的 components.button 保持兼容并废弃。 #59778 @yoyo837
    • ⌨️ 增强 DatePicker 和 TimePicker 的键盘与读屏支持，时间面板支持方向键切换、Enter/Space 确认并跳过禁用选项，底部“今天／此刻”按钮支持键盘操作和原生禁用状态。 #59778 #59367 @yoyo837
    • 🐞 修复 DatePicker 和 TimePicker 在 allowClear 对象未指定 clearIcon 时忽略 clearIcon 配置的问题。 #59565 @QDyanbing
    • 🐞 修复 DatePicker、TimePicker 和 Calendar 在 Node 原生 ESM 环境下的依赖导入兼容性。 #59261 @zombieJ
    • 🐞 修复 DatePicker 使用 Day.js 时，组件语言与全局语言不一致导致本地化月份等日期输入无法解析的问题。 #59240 @QDyanbing
    • 🌐 修正 DatePicker zh_TW 的选周用语。 #59261 @zombieJ
  • Select
    • 🆕 新增 Select autoComplete 属性和 ConfigProvider select.autoComplete 配置，用于设置搜索输入框的浏览器自动补全行为。 #59566 #59632 @QDyanbing
    • ⌨️ 优化 Select、Cascader、TreeSelect 和 AutoComplete 的屏幕阅读器体验，隐藏默认装饰性箭头、搜索和加载图标，避免重复朗读。 #59709 @droduit
    • ⌨️ 增强 Select、Cascader 和 TreeSelect 清除按钮的键盘可访问性，聚焦时显示按钮及焦点轮廓，并使用本地化无障碍名称。 #58267 @Pareder
    • ⌨️ 修复 Select 和 AutoComplete 在虚拟滚动模式下无法正确播报选项位置、总数及分组的问题。 #58993 @yoyo837
  • Table
    • 🆕 新增 Table 的 expandable.showExpandAll 和 expandable.onExpandAll，支持使用 expandedRowRender 时一键展开或收起当前页的所有可展开行。 #59036 @nikzanda
    • 🆕 新增 Table components.ExpandIcon 和 expandable.columnTitle 渲染函数，支持自定义行展开及全部展开按钮；兼容并废弃 expandable.expandIcon，请迁移至 components.ExpandIcon。 #59036 @nikzanda
    • ⌨️ 增强 Table 行选择的可访问性，使用本地化无障碍名称，并支持通过键盘打开自定义选择菜单。 #58969 @thlovey
    • ⚡️ 优化 Table 对深层树形数据同时应用多个列筛选条件时的性能，避免重复递归筛选。 #59719 @Aminark
  • Tree
    • 💄 优化 Tree 非勾选模式下 selectable={false} 节点的样式，显示禁用文本色和光标，并取消悬停高亮。 #58906 @EmilyyyLiu
    • 🐞 修复 Tree 的 expandedKeys、selectedKeys 等显式为 undefined 时默认值及非受控交互失效的问题。 #59274 @aojunhao123
    • 🐞 修复 Tree 标题内子元素获得焦点时列表意外滚动的问题。 #59274 @aojunhao123
    • 🐞 修复 Tree 拖拽到嵌套首个子节点前方时目标错误、自定义拖拽文本被覆盖，以及卸载后仍触发悬停展开的问题。 #59274 @aojunhao123
  • Listy
    • 🆕 新增 Listy rowKey 回调的第二个参数 index，便于根据行下标生成标识。 #59347 @aojunhao123
    • 🆕 新增 Listy rowHoverable 属性，用于关闭列表行的悬停高亮。 #59273 @QDyanbing
    • 🆕 新增 Listy scrollWidth 属性，使虚拟列表内容超出容器时可横向滚动。 #59197 @aojunhao123
  • Pagination
    • 🆕 新增 Pagination onChange 可选的第三个参数 info，通过 info.recommendPage 在每页条数变化时提供推荐页码，便于保留当前数据位置；Table 和 List 的 pagination.onChange 同步支持。 #58604 @EmilyyyLiu
    • ♿ 优化 Pagination 的列表语义以及分页按钮的键盘操作和禁用状态识别。 #58604 @EmilyyyLiu
    • 🌐 修正 Pagination 亚美尼亚语（hy_AM）、阿尔巴尼亚语（sq_AL）、尼泊尔语（ne_NP）和繁体中文（zh_TW）的分页及每页条数文案。 #59500 #59499 #58604 @yoyo837 @EmilyyyLiu

  • Tabs
