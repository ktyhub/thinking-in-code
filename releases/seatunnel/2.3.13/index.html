seatunnel 2.3.13

2.3.13 Release Note

This is a great milestone for Apache SeaTunnel project! The release of version 2.3.13 with its so many new features and fixes will significantly boost the efficiency of data integration workflows for our users.

We’re really impressed by the dedication and hard work our contributors have put into this update, and we’re confident this new version will be widely welcomed by the community.
