moby docker-v29.10.0

29.10.0

For a full list of pull requests and changes in this release, refer to the relevant GitHub milestones:

  • docker/cli, 29.10.0 milestone
  • moby/moby, 29.10.0 milestone

⚠️ Potential breaking change: local registry connections

If you explicitly configure insecure-registries in daemon.json or use --insecure-registry, Docker Engine no longer automatically treats loopback addresses (127.0.0.0/8 and ::1/128) as insecure registries.

[!WARNING] After upgrading, pulls and pushes to local registries that use HTTP or untrusted TLS certificates may fail unless those registries are explicitly included in your insecure registry configuration. Configure TLS with a trusted certificate, or add only the required local registry addresses, such as localhost:5000, to your existing insecure registry configuration.

When insecure-registries is omitted, loopback registries remain insecure by default. Setting "insecure-registries": [] in daemon.json disables all default insecure registries. moby/moby#53868

🧻 Engine API specification moves to OpenAPI 3.2

The Engine API specification now uses OpenAPI 3.2 as its source format, in api/openapi.yaml. A Swagger 2.0 specification generated from it is still published for existing tooling, in api/swagger.yaml. For the transition, this release also includes a Swagger 2.0 copy pinned to API v1.57, in api/docs/v1.57-swagger.yaml. Future API versions won’t get a per-version Swagger 2.0 copy, so update tooling that depends on these files to use the OpenAPI 3.2 specifications. moby/moby#53630

📦 Packages for AlmaLinux, Oracle Linux, and Rocky Linux

Docker Engine packages are available for AlmaLinux, Oracle Linux, and Rocky Linux. For installation instructions, see AlmaLinux, Oracle Linux, and Rocky Linux.

New

  • Add experimental support for jobs: run one-shot and cron-scheduled workloads natively managed by the daemon, as an opt-in built-in extension enabled with --enable-extension org.mobyproject.jobs.v0. moby/moby#53485
  • Add support for customizing Docker’s embedded containerd using configuration files in /etc/docker/containerd.d/. moby/moby#53946
  • Introduce restarting attribute for die events to let consumer know container is going to restart. moby/moby#50908

Bug fixes and enhancements

  • Block obsolete socket families in the default AppArmor and seccomp profiles. moby/moby#54093
  • containerd image store: Fix docker image inspect and docker image ls reporting an empty image when the host platform of a multi-platform image is not pulled but another platform is. moby/moby#54040
  • Don’t wait for the telemetry export timeout when the OTLP endpoint refuses connections. docker/cli#7495
  • Fix docker <unknown-command> --version printing the CLI version instead of an “unknown command” error. docker/cli#7408
  • Fix docker cp printing a “Successfully copied” message when the copy fails. docker/cli#7515
  • Fix docker manifest annotate rejecting valid platforms not included in its predefined list of OS/architecture combinations, such as linux/loong64. docker/cli#7448
  • Fix docker ps printing an empty NAMES column when all of a container’s names contain a slash, such as when connected to a classic Swarm API. docker/cli#7481
  • Fix the daemon deleting the docker0 interface on restart when it is configured with a user-managed bridge and default-address-pools. moby/moby#54157
  • Fix Windows layer exports containing NTFS sparse files. moby/moby#53745
  • Fix: Include HTTP status codes in JSON streaming errors to allow clients to correctly classify failures. moby/moby#54133
  • Improve image selection on ARM64 Linux hosts to prefer the highest image variant supported by the host CPU. moby/moby#53910
  • manifest annotate: add shell-completion for --os and --arch. docker/cli#7449
  • Reject duplicate GPU counts consistently when shorthand and explicit count options are mixed. docker/cli#7312
  • Stop automatically treating loopback registries as insecure when insecure-registries is explicitly configured, and allow disabling the default insecure registries by setting "insecure-registries": [] in daemon.json. moby/moby#53868
  • Update runc (in static binaries) to v1.5.3. moby/moby#54183

Packaging updates

  • Update BuildKit to v0.35.0. moby/moby#54180
  • Update Go runtime to 1.27.4. moby/moby#54176, docker/cli#7506

Networking

  • Engines using the nftables firewall backend can now join a Swarm. (Experimental). moby/moby#53125
  • Fix docker network ls --filter type=builtin --filter type=custom listing a random subset of networks. moby/moby#54127
  • Fix a “rule exists” error when publishing more than one host port for the same container port with the nftables firewall backend and the userland proxy disabled. moby/moby#54031
  • Fix a container starting with no networking after an earlier start failed with a network error, such as a published port already being in use. moby/moby#52480
  • Fix DNS resolution on user-defined networks when the host’s /etc/resolv.conf is missing or contains no valid nameservers. moby/moby#54140
  • Fix iptables rules and an empty DOCKER chain left behind when the daemon switches to the nftables firewall backend after a release older than 28.0.1 ran with iptables. moby/moby#54129
  • Fix iptables rules not being restored after firewalld is stopped, or started after the daemon. moby/moby#54012
  • Fix overlay network driver errors when a container gets the IP address of a container that was just removed on another node. moby/moby#53833
  • Fix overlay networking failing to reconverge after a network partition when a Swarm manager has been replaced at a new address. moby/moby#53715
  • Fix swarm services leaking a virtual IP address on their other networks each time allocation fails on one network, which could exhaust the subnets of those networks. moby/moby#54148
  • Fix Swarm tasks failing to reach a service’s published port via their own node’s address when a host firewall, such as ufw, drops unsolicited incoming traffic. moby/moby#54006
  • Fix the MTU of overlay network interfaces being 20 bytes too large when the Swarm data path is IPv6. moby/moby#54067
  • Reduce nftables port-publishing overhead by batching firewall updates per endpoint and address family. moby/moby#54011
  • Stop nodes in a Swarm cluster from exchanging full overlay network state with every manager once a minute when the cluster is healthy. moby/moby#53715

Rootless

  • Allow the overlay2 storage driver in rootless mode when SELinux is enabled. moby/moby#54048
  • Fix docker cp failing with “remount-ro … operation not permitted” in rootless mode on containers with a read-only bind mount from a nosuid or nodev filesystem. moby/moby#53981

API

  • Update API version to 1.57. moby/moby#53972
