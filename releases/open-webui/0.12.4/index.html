open-webui v0.12.4

Added

  • 🎯 Load selected skills on demand. Administrators can turn on “Load selected skills on demand” under Admin Settings > General or set “ENABLE_SKILL_LAZY_LOADING”, so skills selected in the chat or attached to a model are only listed for the model to load when it needs them instead of sending their full instructions with every message, while skills mentioned in the message still load right away, and it is off by default and needs the built-in Skills tool. Commit
  • 📍 Compaction shown in chats. A “Context compacted” line now marks the message where older messages were summarized, opens to show the summary and also appears inside a reply when compaction ran between its tool calls, Chat Controls > Overview tags that message, and compaction progress and errors now show in the chat instead of as pop-up notices. Commit, Commit, Commit, Commit, #31324
  • 🗜️ Compaction in more chats. Context compaction now also runs in temporary chats and in short chats that are already over the threshold, such as one question with a reply full of tool output, so the follow-up and any regenerate or edit of it no longer fail with a context length error. #32794, Commit, #32781, Commit, #32600
  • 🕶️ Hide controls for users. Administrators can now hide single controls from users under Visible controls in Admin Settings > Interface or with “UI_VISIBILITY”, such as model capabilities, default features and built-in tools in the model editor, Capture, Compare text, Attach Webpage, Attach Files, Attach Notes, Attach Knowledge and Reference Chats in the + menu, the /status, /model and /settings commands, the usage info, Fork, Merge Responses, Preview, Artifacts, Archive and Tags in chats, Set as default and Keep in Sidebar for models and settings such as the Usage tab and the speech engines, while hidden controls keep their values and the features behind them stay usable, hiding Archive also hides Unarchive, and administrators still see every control. Commit, #32830
  • 🫙 Unavailable options hidden. disabled tools and functions, the Context Compaction Threshold while context compaction is off, the title, follow-up and tag generation switches in Settings > Interface while the admin has turned them   • 🔏 Access button respects sharing. The Access button and menu entry of models, prompts, tools, knowledge, skills and notes and the Access button in folder settings are now hidden from users without the matching sharing permission, who had nothing they could change in its dialog. #32979, Commit, #32830
  • 🖇️ Attach entries without uploads. When files cannot be attached, because of a missing permission or a selected model without File Upload, the greyed Attach Knowledge, Reference Chats and Attach Notes entries in the + menu no longer open and the # and @ lists leave out what cannot be attached, including pasted links for users without the web upload permission, so a picked item no longer vanishes from the input without a message. #32968, Commit, #32830
  • ⏱️ Exact last active time. Hovering the last active time in the admin user list and in a group’s member list now shows the exact date and time. Commit
  • 🗨️ New chat from folders. A folder’s menu in the sidebar now has a New Chat item that starts a chat in that folder. Commit
  • 🪪 Profile cards across the workspace. Hovering an owner’s name in the workspace lists of models, knowledge, prompts, skills and tools and in admin Functions now opens their profile card instead of an email tooltip, with their profile picture next to the name, profile pictures in access settings, version history and the Analytics user list open the card too and the Notes list shows each owner’s profile picture. Commit, Commit, Commit, Commit, Commit, Commit
  • 🔢 Turn count in chat previews. The preview shown when hovering a chat in the sidebar now shows how many user and assistant turns its current branch has. Commit
  • 🎚️ Chat Controls saved per setting. A change in a chat’s Controls, such as its system prompt or a parameter, now saves only that setting, so a copy of the chat open in another tab or on another device no longer wipes it with older settings. Commit, #32755
  • 🪃 Questions survive reconnects. When the page reloads or loses its connection while Ask User, a tool approval, an MCP server’s input request or a function’s confirmation or input dialog waits for you, the question now comes back once you reopen that chat within a minute, so the request no longer waits without an answer. Commit
  • ✍️ Note edits by text. The model can now edit a note by finding and replacing exact text instead of only by character offsets, picking one match or all of them and getting the positions and surrounding text back when a match is ambiguous. Commit, #32752
  • 🔍 Compare view stays aligned. Matching rows in the two panes of the Compare view now stay lined up and in place while scrolling, resizing or editing, and a colored bar now marks changed lines also while whitespace or emphasis markers are ignored. Commit, Commit, Commit, Commit
  • 🖱️ Clickable setting labels. Clicking the label of a setting across user and admin settings, including advanced parameters and connections, now toggles its switch, focuses its field or presses its button, and the label highlights while the row is hovered or focused, so the right control is easier to find. Commit, Commit, Commit, #32768, #32900
  • ☑️ Select several sidebar chats. Shift-clicking a chat in the sidebar starts a selection that more clicks or a shift-click range extend, and the selected chats can then be archived or, with the delete permission, deleted together, while Escape clears the selection. Commit, #32543
  • 🫲 Swipe open Chat Controls. On a phone, swiping left across a chat now pulls in the Chat Controls panel, which follows your finger like the sidebar does and closes again with a swipe to the right. Commit
  • 🗃️ Bulk file management. Manage Files in Settings > Data Controls can now download a single file and lets you select several files or all files matching a search to delete them or download them together as one zip archive, with progress and a stop button. Commit
  • 📥 Accurate upload status. A file uploaded to a knowledge base now only shows as done once it is indexed and linked to the knowledge base, so it no longer shows as done and then goes missing from the list until a reload. Commit, #32803
  • ⏳ Knowledge files show Processing. A file added to a knowledge base now switches from Uploading to Processing once it reaches the server, and the list keeps itself up to date until the file is ready, so it no longer says Uploading until you reopen the knowledge base. #32982, Commit
  • 🧮 Knowledge uploads listed at once. Files selected or dropped together into a knowledge base now all appear as Uploading right away in upload order, so each one no longer waits to appear until the file before it has finished processing. #32992, Commit
  • 📈 Analytics by tokens. The Admin Analytics dashboard now ranks models and users by tokens by default with a switch back to messages, and its usage chart adds volume and activity views, a single model view, a comparison with the previous period, a choice of time steps and Year to date and Last 12 months ranges. Commit, Commit, Commit, Commit, Commit, Commit
  • 🗂️ File browser grid view. The terminal file browser can now switch between a list and a grid view from its menu, folders show how many items they hold, and on larger screens hovering a file shows a preview, up to 1 MB for text files and 20 MB for images, audio, video and documents. Commit, Commit, Commit
  • 📁 File browser folder menu. A folder’s menu in the terminal file browser now has New File and New Folder items that create the file or folder inside that folder. Commit, Commit
  • 📬 First-message terminal uploads. With Chat Uploads set to Filesystem on a Per chat terminal, a file attached to the first message of a new chat now waits and uploads into that chat’s own terminal when the message is sent, so it no longer lands in the shared workspace. Commit, #30245
  • 🪧 Folder descriptions. Folders can now have a description in their settings, shown under the folder title on the folder’s page. Commit, Commit
  • 🚚 Organize chats in shared folders. The owner of a shared folder can now rename chats other people started in it and drag them to another folder within the same shared folder. Commit
  • 🛰️ MCP protocol 2026-07-28. MCP connections now also work with servers that speak the stateless 2026-07-28 protocol version, while older servers still connect through the earlier handshake. #33087, Commit, #29778
  • 📧 LDAP default email domain. Administrators can now set a default email domain in the LDAP settings or with “LDAP_DEFAULT_EMAIL_DOMAIN”, so LDAP users without a mail attribute sign in with their username at that domain as their email address and into any existing account with that address, which is why the domain should be one you control. Commit, #33001
  • 🔐 OAuth connections over the API. Connections set to OAuth authentication now also send the user’s OAuth token when the user calls the API with an API key or bearer token, like tool servers already did. #32826, Commit, #32820
  • 🫣 Hidden base models for groups. Administrators can now turn on the Hidden Models permission under Models Access in the user and group permissions, or set “USER_PERMISSIONS_WORKSPACE_MODELS_HIDDEN”, so those users can pick hidden models as the base model of a workspace model while the hidden models stay out of their model picker. Commit, #29806, #29639
  • 🧾 Model usage in audit logs. With audit logging on and “/chat” removed from “AUDIT_EXCLUDED_PATHS”, where it is excluded by default, each chat reply and tool call round now writes its own audit log entry with the model and the input, output and total tokens the provider reported, linked to the request that started it. Commit, #30098
  • 📨 Voice call user headers. With “ENABLE_FORWARD_USER_INFO_HEADERS” on, Realtime voice calls now also send the user info headers, or the signed user JWT when configured, to the realtime provider, like chat requests do. #32733, Commit
  • 🏎️ Faster action buttons. An action button now only saves the chat again when the action changed a message, so actions on large chats finish sooner. Commit, #32658, Commit
  • 👪 Faster group saves. Saving, deleting or changing the members or permissions of a group now finishes in well under a second with thousands of users online, where it took several seconds and reloaded the open chat of everyone online. #32883, Commit, #32882, Commit
  • 🧳 Faster folder changes. Renaming, sharing, moving or deleting a folder and deleting all chats now finish quickly with thousands of users online, where each took several seconds and reloaded the open chat of everyone online. #32888, Commit
  • 📣 Faster channel posts. Posting a message in a channel with many members online now returns in a fraction of a second, where it waited for every online member’s login to be checked again first. #32889, Commit
  • 📊 Faster analytics dashboard. The Admin Analytics dashboard now gets its totals, model and user lists and daily charts from fewer and lighter database queries, so it opens faster on instances with many messages. Commit
  • ♻️ Prompt cache survives restarts. Tools from tool servers, Open Terminal included, now reach the model in the same form after every restart, so the provider’s prompt cache keeps working and long chats are no longer processed again from scratch. #33000, Commit
  • 👁️ PDF image OCR stays light. With PDF Extract Images (OCR) on, reading text from images in PDFs now uses one processor thread per upload by default, so uploads no longer start a thread pool the size of the server’s cores that could slow the whole server down, and administrators can pass their own RapidOCR settings with “RAPIDOCR_PARAMS”. Commit, #32844

  • 🌍 Web Search settings save. Admins can now save Web Search settings such as the web loader while web search is turned off, where empty search engine fields blocked saving. #32840, Commit, #32831
  • 🖌️ Images settings save. Admins can now save Images settings while Image Generation or Image Edit is turned off, where a missing API key or URL for that feature’s engine, such as the OpenAI key on a fresh install, blocked every change on the page. #32949, Commit, #32835
  • 🌄 WebP image editing. Editing a WebP image with Image Edit now works in the Docker image, where the image reached the provider without an image type and was rejected. #32902, Commit, #32899
  • 🍴 No fork in temporary chats. The Fork chat option is now hidden in temporary chats and the /fork command answers that there is no chat to fork, where forking failed with an error. #32839, Commit, #32833
  • 🚀 First message after loading. A message sent right after the page loads is no longer wiped by the new chat setup still running, where it disappeared and its reply stayed empty until a reload. #32829, Commit, #32819
  • 📑 MinerU key in local mode. Document extraction with MinerU in local mode now sends the configured API key to MinerU 4.x servers that require one, where every document failed. #32838, Commit, #32836
  • 🚫 Model import reports taken IDs. Importing models on the Workspace Models page now stops with an error at a model whose ID belongs to another user’s model the importer cannot edit or, for non-admins, to a connection model, where that model was skipped without a message. #32866, Commit
  • 🎞️ Left-aligned PowerPoint titles. The PowerPoint preview now keeps titles and subtitles that the file aligns left on the left, where it centered them. #32876, Commit, #32873
  • 🫥 Multi-model hover previews. Sidebar hover previews of a chat with replies from several models now show one reply at full width, where every reply was squeezed into the card. Commit, #32858
  • 🐚 Launcher help in zsh. The examples in the Docker Compose launcher help now quote options with square brackets, so they also work when pasted into zsh. #32881, Commit, #32878
  • 🌡️ Context gauge uses model threshold. The context usage gauge now measures against the compaction threshold set on the model or in the default model parameters, the same one compaction uses, where it ignored a lower threshold on the model and showed a chat as far from compaction. Commit, #32821
  • 🏷️ Tooltips show text as written. Tooltips now show names, paths and descriptions that contain angle brackets as written, where they came out mangled or partly missing. #32953, Commit
  • 📇 Knowledge file text edits. The Preview of a text file in a knowledge base now shows its indexed text and refreshes after you save an edit, where it kept showing the original upload, and saving empty content is now refused. Commit
  • 📡 Websockets after Redis reconnects. With the Redis websocket manager and “retry_on_timeout” in “WEBSOCKET_REDIS_OPTIONS”, an instance now accepts new browser connections again once Redis is back after its connection dropped, where since 0.12.3 every new connection could hang until the instance was restarted. #33009, Commit, #33008
  • 🥞 One model More menu open. Clicking the More button of another model in the model picker, or clicking another model, now closes the More menu that was open, where the menus stayed open and piled up over the picker. #33020, Commit, #33019

Changed

  • 🔧 Direct Integrations off disables connections. While Direct Integrations is off, as it is by default, the tool servers and Open Terminal connections that users and admins saved in their Integrations settings are no longer used in chats, where turning it off only hid the settings tab, so instances that never turned it on lose those connections until an admin turns on Direct Integrations in Admin Settings > Connections or sets “ENABLE_DIRECT_INTEGRATIONS”. #32996, Commit
  • 🔀 Sharing changed only in Access. Saving a model, prompt, tool, skill, knowledge base, note, channel or calendar no longer changes who it is shared with, which is now changed only in the item’s Access settings, saved right away in the model editor, channel settings and external knowledge sources, or through the access endpoints that channels and calendars now also have. Commit, Commit
  • 🐳 Python 3.12 Docker image. The Docker image now runs Python 3.12 on Debian 13 instead of Python 3.11 on Debian 12, so custom functions, tools and packages installed with pip inside the container need versions that support Python 3.12. #32861, Commit
  • 🤝 Sharing permissions enforced everywhere. Sharing permissions such as Models Sharing, Knowledge Sharing and Folders Sharing now also apply to sharing through the API, and a change in an item’s Access settings that a user is not allowed to make is now refused with an error instead of being quietly left out. Commit
  • 🗄️ Manage Files shows only yours. Manage Files in Settings > Data Controls now lists only your own files, also for administrators, who saw every user’s files there while “BYPASS_ADMIN_ACCESS_CONTROL” was on, as it is by default. Commit
  • 🕹️ Model controls for all users. Anyone with access to a model can now pick its model control options, such as a Thinking level, and parameters saved to an account are no longer filtered by the Allow Chat Controls and Allow Chat Params permissions, which now only hide the Chat Controls and Advanced Parameters panels. #32860, Commit, #32626
  • 🚦 Stricter MCP timeouts and redirects. “MCP_INITIALIZE_TIMEOUT”, 10 seconds by default, now also limits listing tools and reading resources on MCP servers, so slow servers may need a higher value, and MCP connections now only follow redirects that stay on the same address. #33087, Commit
  • ⌨️ Shift quick actions removed. Holding Shift over a sidebar chat no longer shows the quick Archive and Delete buttons, since Shift-click now selects chats, which are then archived or deleted together, and deleting asks for confirmation first. Commit, #32543
  • ✉️ No emails on hover. Hovering an owner in the workspace lists and admin Functions, or a person in access settings, no longer shows their email address, since the profile card that replaces the tooltip does not include it. Commit, Commit, Commit
