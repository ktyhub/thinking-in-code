open-webui v0.12.5

patch PublishedOct 29, 2026 Sourceopen-webui/open-webui Chinese translation

open-webui v0.12.5

Added

  • 🧭 Analytics session explorer. Administrators can now open a Sessions tab in Admin Analytics that lists each chat with its tokens, responses, errors and time span, filters them by search, model, token range or sub-agents, and shows a chat’s saved replies and tool calls with their timing and outcome, as long as “ENABLE_ADMIN_CHAT_ACCESS” is on. Commit
  • 📑 Pages in notes. Notes can now hold several pages and subpages, which you can add, rename, reorder, move under another page, download, link to and delete from the page tabs, and search results and the model now work with notes page by page. Commit
  • 👀 Live presence in notes. A note now shows who else has it open, and clicking a person jumps to the page and spot they are working on. Commit
  • ✏️ Rename from chat menu. The menu next to an open chat’s title now has Rename, which turns the title at the top of the page into a text box, so a chat can be renamed without finding it in the sidebar first. #33177, #33176, #33246, #33339, #33338, Commit, Commit
  • 🖼️ Generated images in terminals. When a terminal is selected in a chat, generated and edited images are now also saved to its working folder, so the model can keep working on them with the terminal’s tools. Commit
  • 🗃️ Models show chat files. Models can now show a file attached in the chat or stored in an attached knowledge base right in the reply with the built-in display_file tool, which until now only worked for terminal files. #32471, Commit, Commit
  • 💾 Chat model choice saved. Changing the model in a chat is now saved with the chat right away, so the chat reopens with that model even when no message was sent after the change. Commit
  • ⌨️ Unassign single shortcuts. Settings > Keyboard now shows a small x beside every assigned shortcut that unassigns only that one, so a shortcut such as Regenerate Response on Ctrl+R or Cmd+R can be switched off while all others keep working. #33185, #31463, Commit
  • 🎚️ Slider for number Valves. Plugin authors can now show a number Valve or UserValve as a slider with a number box beside it, whose ends come from the field’s minimum and maximum, so users see the allowed range while picking a value. #33179, #32045, Commit
  • 📇 Provider details for models. Administrators editing a model now see a Provider details section with the input and output types, context window, maximum output and supported parameters that the provider reports for it. Commit
  • 🧲 Embedding prefixes in settings. Administrators can now set the query and content prefixes that some embedding models need under Admin Settings > Documents, where they could only be set with the “RAG_EMBEDDING_QUERY_PREFIX” and “RAG_EMBEDDING_CONTENT_PREFIX” environment variables. Commit
  • ⏱️ Terminal start timeout. Open WebUI now waits up to 60 seconds by default when it asks a terminal for its skills, AGENTS.md file or uploads, so a terminal that is still starting can answer, with “AIOHTTP_CLIENT_TIMEOUT_TERMINAL” to change the limit and a message naming the terminal when it still times out. Commit
  • 🚨 Automation failure notifications. Automation run failed is now an event users can pick for their notification targets under Settings > Notifications, so the owner hears about every failed run with the automation’s name and error. #33331, #33228, Commit
  • ⚡ Faster knowledge base commands. Knowledge base commands such as ls, cat and grep and the knowledge base sync check now list files without loading every file’s full text, so on large knowledge bases each call is up to ten times faster and uses far less memory. #33332, #33322, Commit
  • 🔭 Faster chat search. Searching your chats, including from the Reference Chats menu and the model’s chat search tool, no longer loads every matching chat in full, so results come back faster on large chat histories, and a result’s message preview in the Reference Chats menu now loads when you hover it. Commit
  • 📦 Batched document embedding. Large documents are now embedded and saved in batches of 1000 chunks by default, set with “RAG_EMBEDDING_BUFFER_SIZE”, so processing a very large file holds far less in memory at once. Commit
  • 🧾 Mistral OCR model choice. Administrators can now pick the Mistral OCR model and send extra request options through a Parameters field in Admin Settings > Documents or “MISTRAL_OCR_PARAMS”, for example to stay on an older OCR model or to match what an Azure AI Foundry endpoint expects. #33333, #19707, Commit
  • 📉 Negative relevance threshold. The Relevance Threshold in Admin Settings > Documents now takes negative values for rerankers that return raw scores below zero, where the field refused them and a negative “RAG_RELEVANCE_THRESHOLD” kept the page from saving while hybrid search was on. #33330, #29888, Commit
  • 🎞️ Animated ComfyUI images. Images from ComfyUI’s Save Animated WEBP and Save Animated PNG nodes now show up in the chat as the animated file, for both image generation and image editing. #33325, #33013, Commit
  • 📡 Metrics skip health checks. OpenTelemetry metrics now leave out requests whose URL matches “OTEL_PYTHON_FASTAPI_EXCLUDED_URLS” or “OTEL_PYTHON_EXCLUDED_URLS”, so health checks and probes no longer fill the request metrics, the same way traces already skip them. #33329, #31609, Commit
  • 🗝️ Admins manage user API keys. Administrators can now rotate or delete a user’s API key in the Edit User dialog, and a rotated key is shown once so it can be copied. #32774, Commit, Commit
  • 👓 More hideable chat controls. Administrators can now also hide the selected tools, skills, filters, web search, image generation and code interpreter shown in the chat input, through Visible controls in Admin Settings > Interface or “UI_VISIBILITY”. #32408, Commit
  • ♿ Improved UI accessibility. Screen reader and keyboard users can now move through a chat message by message with each message’s name as a heading, move through menus and submenus with the arrow keys, Home and End, reach a note’s Generate title button and the options of a filter list opened with the mouse, leave the Compare revision editors with Escape and Tab, and hear names for every field of the calendar event window, the last column of the Users and Feedback tables and each day in the Settings > Usage heatmap, while the model picker outlines only one row, takes keyboard focus when opened in a window and leaves focus in that window when it closes, and focus outlines on tab rows are no longer cut off.
  • 🔄 General improvements. Various improvements were implemented across the application to enhance performance, stability, and security.
  • 🌐 Translation updates. Translations for Portuguese (Brazil), Catalan, Italian, Azerbaijani, Basque, Bengali, Bosnian, Bulgarian, Cebuano, Croatian, Czech, Danish, Dutch, Estonian, Faroese, Filipino, Galician, Georgian, German, Greek, Hebrew, Hindi, Hungarian, Indonesian, Irish, Japanese, Kabyle, Korean, Latvian, Lithuanian, Malay, Norwegian Bokmål, Persian, Polish, Punjabi, Romanian, Russian, Serbian, Slovak, Slovenian, Spanish (Spain), Swedish, Tamil, Thai, Tibetan, Turkish, Turkmen, Ukrainian, Urdu, Uyghur and Vietnamese were enhanced and expanded.

Fixed

  • 🛡️ Security Advisory: This release contains security fixes. We strongly recommend updating all deployments as soon as possible to have the latest security fixes in place. These fixes are not listed in this changelog; we will publish the security advisories for them immediately following CVE assignment. Advisories
  • 🔎 Search dialog filters restored. The search dialog again understands and suggests the “tag:”, “folder:”, “pinned:”, “shared:” and “archived:” filters, where adding one emptied the results and archived chats could not be found at all. #33181, #32518, Commit
  • 📍 Search locations by type. The Location filter in the search window now lists only folders for Chats and only channels for Messages, and switching the content type clears a location that no longer fits, where such a pick returned an empty list. #33183, #33182, Commit
  • 🧮 Inflated streamed token counts. Token counts for a reply are no longer inflated when the provider reports its usage again on every streamed chunk, where every report was added up, so the usage shown for the reply and in Admin Analytics now matches the provider’s final count. #32052, #29064, #28528, Commit
  • 📝 Note typing after Formatting. Typing in a note now works right after switching Formatting on or off in the note’s menu, where the editor stopped taking input and saving until the page was reloaded. #33222, Commit
  • 🎙️ Note recordings kept. A recording in a note now stays in the note when the connection drops while it is being transcribed, for example when a laptop goes to sleep. #33240, Commit
  • 🀄 IME typing with Backspace. Pressing Backspace while composing text with a Japanese or other input method in the chat input no longer ends the composition or makes the text appear twice, which started in 0.12.4. #33245, #33223, Commit
  • 🤖 Photos for sub-agents. Models can now hand a photo attached in the chat to a sub-agent, where the hand-off failed with “file_ids not attached or unavailable” and no sub-agent started. #33244, #33241, Commit
  • 🪆 Sub-agent partial output kept. A foreground sub-agent that stops at the tool-call limit now hands the model its partial output along with the error, where everything it had written was lost, and the error now reads as a plain message in both foreground and background. #33269, #33267, Commit
  • 🔗 MCP failures keep the chat. A tool call to an MCP server that cannot be reached, for example after a restart or a dropped connection, now fails on its own and the reply still finishes, where the whole chat stopped as if you had pressed stop. #33272, #33268, Commit
  • 🔃 Cut-off replies stay finished. A reply cut off by a server restart no longer goes back to the loading dots when the connection comes back later. #33277, Commit
  • 🐢 Slow chat loads. Opening a chat on a slow connection or switching chats quickly now shows the chat you opened, where a slower earlier load could replace it with an old copy and the next message forked the chat. #33180, Commit
  • 👁️ Tool images with Vision off. Models with Vision turned off now get a short “[image]” note in place of each image a tool returns, where the reply failed with an error and every later message in that chat failed the same way. #33345, #32720, Commit
  • ✋ Stop button on others’ replies. In a chat shared with Allow replies, the Stop button no longer shows on someone else’s running reply, where it showed but did nothing. #33343, Commit
  • 🧷 Refused sharing changes undone. The Access dialog of a prompt, skill, tool, note or knowledge base now goes back to the saved sharing when the server refuses a change, where it kept showing the refused change as if it were saved, and the model editor now shows the server’s message for such a refusal. #33209, #33208, Commit
  • 🔌 Tool server Headers reset. Adding another connection in External Tool Servers now starts with empty Headers, where it kept the previous connection’s Headers and saved them on the new one. #33201, #33200, Commit
  • 🧰 OpenAPI tools listed. The Available Tools window in a chat now lists the tools of an OpenAPI tool server, where it said “No tools found”. #33205, #33204, Commit
  • 🎛️ Generation switches update. Saving Title, Follow-Up, Tags or Autocomplete Generation in Admin Settings > Interface now updates the matching switches in Settings > Interface and autocomplete in the chat input right away, where they kept the old setting until a reload. #33197, #33196, Commit
  • 🗂️ Local knowledge filter. Picking Local in the source filter on Workspace > Knowledge now lists knowledge bases made with Create, where it showed “No knowledge found”. #33199, #33198, Commit
  • 🪣 Large S3 Vectors deletes. Removing a file or knowledge base with more than 500 chunks from S3 Vectors now works, where the delete request went over the service’s limit of 500 keys and failed. Commit
  • 🔢 Empty embedding batch size. Clearing the Embedding Batch Size in Admin Settings > Documents now saves the default of 1, where files uploaded afterwards failed to process. #33288, #33287, Commit
  • 🔊 Read Aloud with Kokoro.js. Read Aloud now speaks with the chosen Kokoro voice when Kokoro.js (Browser) is picked in Settings > Audio, where it used the browser’s built-in voice while the server’s speech engine was Web API. #33211, #33210, Commit
  • 🔉 Kokoro.js without a GPU. Kokoro.js (Browser) now runs on the CPU in browsers that offer WebGPU but have no GPU available, where its voices never finished loading and Read Aloud kept spinning without speaking. #33233, #33232, Commit
  • 🎨 ComfyUI failures reported. A ComfyUI workflow that fails, for example when the GPU runs out of memory, now shows an error and tells the model the image could not be made, where it was reported as a successful generation with no images. #33237, #33236, Commit
  • 🖌️ Responses API images shown. Images that a model creates through the Responses API, such as Gemini image models through OpenRouter, now show in the chat, where they were saved but not displayed. #33320, Commit
  • 🛝 Playground Controls applied. Settings chosen under Controls in the Playground, such as Temperature and Seed, now reach Ollama models, where they were dropped and every run gave a different reply. #33286, #33285, Commit
  • 📋 Shift paste in channels. Holding Shift while pasting long text into a channel message or thread reply now keeps it as text when Paste Large Text as File is on, as it already did in chats. #33190, #33189, Commit
  • 🧵 Thread replies while loading. A thread reply or model answer that arrives while the thread is still loading now shows up in full, and a reply no longer shows twice. #33346, Commit, Commit
  • 👥 Analytics model chats by group. A model’s Chats tab in Admin Analytics now follows the User group filter, where it listed every user’s chats with that model. #33207, #33206, Commit
  • 🙈 Hidden files in folder counts. The item count under a folder in a chat’s terminal file browser now leaves out hidden files while Show Hidden Files is off. #33213, #33212, Commit
  • 📁 Expanded folders kept. Deleting, renaming or adding a file in a chat’s Files tab now keeps expanded folders listed, where every expanded folder came up empty. #33195, #33194, Commit
  • 📌 Pins kept in shared folders. A member’s chat now keeps its pin when the owner of a shared folder moves it to another folder inside that folder, where it dropped out of the member’s Pinned list. #33342, #33341, Commit
  • 🌙 Overnight calendar events. A calendar event that ends after midnight, such as 8:00 PM to 1:00 AM, now keeps its end time on the next day, where saving dropped it and stored the event as ending at its start time. #33290, #33289, Commit
  • 🗓️ Midnight calendar events. A calendar event that ends at midnight now shows only on its own day in Month view, where it also showed on the next day. #33292, #33291, Commit
  • 🪝 Old webhook removable. A notification webhook carried over from before v0.11 now stays removed from Settings > Notifications, where it came right back after Remove. #33295, #33294, Commit
  • 🔔 New default notification target. A notification target added after removing the last one now becomes the default, where it never did. #33284, #33283, Commit
  • 🗣️ Translated search and Skills labels. Labels in the workspace search, the Skills list, the skill editor and the terminal file browser now follow the interface language, where several always showed in English. #33308, #33304, #33305, Commit
  • 📜 Keyboard tab scrolling. Scrolling on the Settings > Keyboard tab no longer moves the whole Settings window. #33187, #33186, Commit

Changed

  • 🔀 Model switch keeps your picks. Switching models in a chat now applies the new model’s default tools, skills, filters and features while keeping the ones you turned on or off yourself, where every switch cleared your picks, and chats with several models now get the default tools and skills of every selected model. Commit, Commit
  • 📣 Model mentions switch chats. Sending a message to a model picked with @ now switches the chat to that model, where the mention stayed above the input and the chat kept its own model. Commit
  • 🔁 Regenerate uses current models. Regenerating a response in a chat with several models now uses the model currently picked for that column, where it reused the model that first wrote the response. Commit
  • 📎 Note attachments in pages. Files attached to a note now sit inside the page where they were added, and the attached files of existing notes move to the end of the note’s first page. Commit
  • 📂 Folder moves keep chat dates. Moving a chat into or out of a folder now keeps its last activity date, so it stays sorted by when it was really last active, where it jumped to the top of the sidebar under Today. #33327, #30362, Commit
  • 📮 Automation failure webhooks. Admin event webhooks set to System events only no longer receive automation run failures, which now go to webhooks set to specific users or groups that include the automation’s owner. #33331, Commit
  • 📃 Knowledge base API responses trimmed. Adding, updating or removing knowledge base files and renaming or sharing a knowledge base through the API now return only the affected files or an empty list, so these calls no longer slow down as the knowledge base grows, and the full list stays available from the paginated files endpoint. #33335, #31397, Commit
