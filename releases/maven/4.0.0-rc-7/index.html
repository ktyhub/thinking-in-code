maven maven-4.0.0-rc-7

This release candidate is expected to be the last before the Maven 4.0.0 GA release, which we aim to publish in the coming weeks, pending community feedback.

🚀 New features and improvements

  • Log API enhancements and mojo MDC (#12690) @gnodet
  • Optimize reactor sort and phase comparator performance (#12901) @gnodet
  • Add AsyncDrainWriter to eliminate PrintWriter lock contention (#12892) @gnodet
  • Add validation for Plexus-based plugin dependency injection (#12649) @slawekjaranowski
