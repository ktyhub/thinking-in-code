vllm v0.34.0

v0.34.0

1,061 commits from 412 contributors (120 new). Thank you!

TL;DR

  • 10 new models (Mistral Large 4, MiniMax-M3.1-Flash, Nemotron-3.5-Transcribe, and more!)
  • Extensible KV cache is on by default: vLLM sizes the KV cache from memory actually free after warmup, so most models get a bigger cache and more throughput.
  • Model Runner V1 is gone. Model Runner V2 is now the only GPU runner.
  • Big speedups on Blackwell and MI355X: up to 1.95× decode (Step5 on GB200), 1.6× throughput (GLM-5.3-Flash), 1.24–1.40× faster long-prompt TTFT (GLM-5.3).
  • Upgrade check: default block size is now 64, ROCm 7.2 images are gone, and huggingface_hub >= 2.0.0 is required. See Before you upgrade.

Highlights

Extensible KV cache, on by default

  • On CUDA and ROCm, the KV cache is sized from memory actually free after CUDA graph capture and warmup, not from an estimate (#56492).
  • Result: a larger cache (e.g. MiniMax-M3 on H200: 433k → 672k tokens), so throughput is higher and TTFT lower at high concurrency.
  • Trade-off: per-token decode latency can rise on some models (TPOT +6–18% on some H200 models at concurrency 128). Opt out with --gpu-memory-utilization 0.9 or --no-enable-extensible-kv-cache.
  • Hardened with fixes for allocator fragmentation, startup OOMs and KV connectors (#67296, #67485, #66731, #66523, #66197, #65137, #66605, #66674).

Model Runner V2 only

  • Model Runner V1 is removed (#63373).
  • Dual-batch overlap now runs on MRV2, including with speculative decoding and DCP (#61464).

Speculative decoding

  • Suffix decoding runs on MRV2 with a GPU speculator; Arctic Inference is no longer needed (#60339).
  • Custom speculators: declarative configs plus a register_speculative_method plugin API (#63205).
  • CUDA graphs for MRV2 draft-model speculators (#60989).
  • Adaptive verification works with XPress (#65175).
  • Draft KV cache matches the target’s dtype, so an FP8 target gets an FP8 draft cache (#65198).

AMD ROCm

  • Release images and wheels are ROCm 10.0 only (#61939).
  • MoRI EPv2 via --all2all-backend mori (#61361).
  • Kimi-K3 specialized decode on MI355X, opt-in (#61435).
  • TRITON_ATTN is the default attention backend on RDNA3 and RDNA4 (#60418).

Serving and operations

  • Checkpoint/restore (CRIU + cuda-checkpoint) through /checkpoint/prepare, /checkpoint/status and /checkpoint/restore, in both the Python and Rust frontends (#62570).
  • Fault-tolerant DP+EP scale-down: dead ranks are removed and their experts redistributed without a restart (#46370).
  • Best-effort NUMA binding on by default (#61258).
  • Opt-in cache-aware admission ordering (#54625).
  • Rust frontend: stateless Responses API (#63902) and n > 1 (#65625).

    • Responses accepts incomplete assistant/reasoning history, e.g. from Codex (#35508).
    • Multi-template processors use the default template (#63606); an empty tools array is accepted like OpenAI (#65547).
    • The first streamed usage reports cached prompt tokens (#65036); plain completion stream frames render about 9× faster (#52875).
  • Rust frontend
    • Stateless Responses API (#63902) with namespace tools (#65853); n > 1 (#65625); --skip-tokenizer-init (#64697).
    • Hybrid and external DP load balancing (#64451, #64450); native GLM-5.3 chat rendering (#62424).
    • Prompt block hashing off the engine’s GIL (#63842); --reasoning-effort-map (#62312).
    • --enable-log-outputs, --max-log-len, --root-path, --log-error-stack (#63769, #64223, #64222, #65001).
    • More request, response and metric parity with Python (#65293, #65294, #65623, #65624, #64218, #64526, #63964, #65636).
Security, dependencies and build
  • Security
    • ReDoS in the validation-error sanitizer fixed (#52120).
    • FunAudioChat audio bounded to the profiled duration (#57411).
    • /v1/systemone honors --trust-request-chat-template (#64503).
    • Raised floors for filelock, OpenTelemetry, graphql-core and others (#63574).
  • Dependencies
    • PyTorch stays at 2.14.0. FlashInfer 0.7.3 (#65930).
    • huggingface_hub >= 2.0.0, tokenizers >= 0.23.3, timm >= 1.0.30 (#64779); transformers >= 5.16.1, < 5.23.0 (#64049, #64529); mistral-common >= 1.13.0 (#64169).

  • Build
    • x86_64 CUDA wheel about 82 MB (about 25%) smaller, kernels unchanged (#65518).

All breaking changes, deprecations and new defaults
  • Model Runner V1 removed (#63373).
    • VLLM_USE_V2_MODEL_RUNNER and VllmConfig.use_v2_model_runner are gone; setting the env var to anything but 1 fails at startup.
    • Dropped with it: the V1 logits-processor API (vllm.v1.worker.gpu.sample.logits_processor is the only interface), the custom_class speculative method, use_heterogeneous_vocab, disable_padded_drafter_batch, parallel_drafting outside DFlash/DSpark, PP with external_launcher, NGramPerReqLogitsProcessor, and x86 CPUs without Triton.
    • Deprecated: parallel_drafting, capture_torch_profiler, enable_layerwise_nvtx_tracing.
  • Default --block-size is 64 instead of 16 (#63231). Backends with a preferred block size still override it (ROCm paged attention keeps 16), and an explicit --block-size still wins.
  • gpu_memory_utilization defaults to 1.0 when unset with the extensible KV cache on (#56492). An explicit value in (0.8, 1.0) that withholds 1 GiB or more logs a warning (#66704).
  • ROCm 7.2 wheels and -rocm72 images are no longer published (#61939).
  • Removed:
    • QuTLASS and the fp_quant method (#65230).
    • Marlin INT8/FP8-activation (W4A8) paths and VLLM_MARLIN_INPUT_DTYPE; use --quantization humming with VLLM_HUMMING_INPUT_QUANT_CONFIG (#65542).
    • Keye-VL and Keye-VL-1.5 (#64287); disable_mtp_completeness_check (#49459); the refresh_derived_weights hook (#65914).
  • Dependencies: huggingface_hub >= 2.0.0 (#64779); mistral-common >= 1.13.0 (#64169); XPU requires vllm_xpu_kernels 0.1.17 (#60609).
  • Model and plugin code: all process_weights_after_loading hooks share one signature and the loader runs every module’s hook (#57678); config compute_hash() replaced by compile_factors() / hash_config() (#65652).
  • API behavior:
    • llama3_json no longer streams tool arguments incrementally (#63569).
    • Canary transcription without language returns 400 (#65445).
    • An empty tools array is accepted in both frontends (#65547, #65854).
    • /v1/systemone rejects request-supplied chat templates without --trust-request-chat-template (#64503).
    • LoRA adapters on modules vLLM does not wrap are refused (#63489); misconfigured NCCL weight transfer raises (#57022).
    • vllm-rs serve no longer reads --data-parallel-rank from VLLM_DP_RANK (#65369).
    • AITER fused shared experts with MiniMax M3 and DeepSeek V4 need VLLM_ROCM_USE_AITER=1 (#61457).
  • Still deprecated: --mamba-cache-mode has no effect; its removal was postponed (#64838).
  • New defaults:
    • Extensible KV cache (#56492); block size 64 (#63231); best-effort NUMA binding (#61258).
    • Token-sharded sparse-MLA prefill at 1024 or more prefill tokens (#63956); MLA decode up-projection before the A2A merge (#64994).
    • VLLM_COMPILE_ON_ONE_RANK (#63247); minimum valid EPLB num_redundant_experts (#30614).
    • HiSparse on the extensible KV cache (#65214); encoder CUDA graphs up to encoder_cudagraph_max_token_budget=5120, eager above (#65227).
    • TRITON_ATTN on RDNA3/RDNA4 (#60418); MRV2 on non-Triton CPUs (#61995); float32 Mamba SSM cache for Nemotron Omni (#63218); Zipf routing in vllm bench forward (#64167).
