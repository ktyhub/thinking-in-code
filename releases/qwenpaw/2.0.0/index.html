QwenPaw v2.0.0

major PublishedJul 10, 2026 Sourceagentscope-ai/QwenPaw Chinese translation

QwenPaw v2.0.0

What’s Changed

✨ Added

Core Architecture

  • Runtime 2.0: Refactor the kernel based on AgentScope 2.0 (#5078, #4846, #5018, #5552)
  • Agent OS Driver: Unified management of MCP/A2A/ACP connections, encrypted credential storage, and per-call approval policy (#5067)
  • Loop Engineering: New Loop gate design with three Loop templates: Normal Mode / Mission Mode / Goal Mode (#5665, #5727)
  • Governance & Sandbox: Policy engine with allow/deny/ask rules, ToolGuard detectors merged into a single policy evaluation path, and a generalized governance pattern for plugins (#5088, #5546, #5301)

Context Management

  • Scroll Context: SQLite-backed working history (history.db) with FTS5 full-text search, eviction index, turn-level persistence, and a sandboxed recall_history_python REPL for on-demand recall of older turns. 30-day default retention, auto-imports existing sessions on startup (#5321)
  • Native Compression: Refactor using AgentScope 2.0’s built-in context compression strategy (#5309)

Long-term Memory

  • ReMe v0.4.0 backend: Replace the in-house memory runtime with ReMe v0.4.0 — vector store, auto-tracking, and retrieval are now handled by the ReMe v0.4.0 library (#5349)
  • Turn-based tracking: Memory writes now happen per-turn via middleware, no longer tied to session close (#5540)
  • Usage-aware search: Memory search now considers recency and frequency; backend-specific embedding model selection added to config UI (#5820)
  • ADBPG REST mode: ADBPG memory backend switched to REST-only, with auto search (#5296)
  • Search UI simplification: Cleaner memory search display, metadata fields reduced to essentials (#5482)
  • ‘none’ backend: Config option to fully disable the memory system for lightweight deployments (#5732)

Terminal UI (TUI)

  • Full-screen TUI: A textual-based terminal chat app (qwenpaw tui) — streaming output, tool-call rendering, status bar, and session management all in the terminal (#5032)
  • Project-scoped sessions: TUI can launch a Coding Mode session scoped to a specific project directory (#5448)
  • Context-usage bar: Live token/context usage indicator in the TUI status bar (#5673)
  • ACP commands in TUI: /approve, /deny inline approval commands + transcript panel improvements (#5443, #5714)

Console & UI

  • Approval card: Larger action buttons, clearer diff preview, one-click approve/deny (#5855)
  • Long text upload: Paste or upload large text blocks directly into the chat input (#5854)
  • Session-level tool approval: Override global tool policy per session (#5685, #5832)
  • Non-owner banner: Show “view-only” banner when viewing someone else’s session tab (#5664)
  • Mobile layouts: Responsive CSS + drawer-based navigation for all console pages (#5444–#5470)
  • Tools page split view: Enabled vs. available tools shown in separate columns; per-tool config-aware toggle (#5509, #5604)
  • Skill market improvements: Star/download counts, enabled/disabled split, auto-sync from CDN (#5521, #5706, #5639)
  • Channels page dual layout: Enabled channels on top, available below (#5504)
  • Coding Mode 50/50 split: Chat panel takes half the viewport (#5473)
  • Hidden folders in project browser: . prefixed directories now selectable (#5828)
  • Session drawer: Date-grouped sessions with inline search (#5728)
  • Token usage popover: Ring chart showing token/context usage per turn, restored for Runtime 2.0 (#5493, #5544)
  • Inbox filters: Filter push notifications by source type (#5522)
  • Message anchors: Jump-to-message navigator for user turns (#5515)
  • Request timeout: Configurable HTTP timeout + AbortSignal propagation for backend calls (#5764)

Model Providers

  • OpenAI Response API: New provider for the OpenAI Response API format (#5519)
  • DashScope updates: Qwen3.7 + DeepSeek V4 added to built-in model list; extra_body passthrough for generate_kwargs; per-model thinking relay toggle (#5646, #5491, #5687, #5730)
  • GitHub Models: Migrate to new API endpoint; support fine-grained PATs (#5735)
  • Telegram custom base URL: api_base_url config for self-hosted Telegram Bot API servers (#5651)

Channels

  • Matrix streaming: Edit-in-place streaming, no longer sends a new message per chunk (#5585)
  • Plugin-registered channels: Plugins can register custom channel types with a JSON schema that auto-generates config UI (#4693)
  • Per-channel debounce toggle: no_text_debounce flag so fast channels don’t batch messages (#5617)
  • Slack: Full channel implementation with multimodal attachments, thread replies, and streaming (#5193)
  • DingTalk private deploy: api_endpoint config for on-prem DingTalk instances (#5111)
  • Azure Bot channel: Azure Bot channel added as a plugin, with i18n/custom-icon/doc_url support for plugin channels (#5849)
  • Discord attachments: Download to local media_dir, serve via static file route (#5468)

Desktop

  • Tauri migration: Desktop build moved from Electron to Tauri — smaller binary, native webview, NSIS installer on Windows (#5734, #4669, #4041)
  • Bundled ACP runtime: Node.js runtime + ACP modules ship inside the desktop package for out-of-box agent communication (#5814, #5794)
  • DevTools gesture: 8× logo click opens Chromium DevTools for debugging (#5805)

Security & Sandbox

  • Windows AppContainer sandbox: Code execution isolated via Windows native AppContainer API (#5525)
  • Linux bubblewrap sandbox: Mount namespace isolation via bwrap for Linux code execution (#5310)
  • Cron tool-safety toggle: Per-job flag to require/skip tool approval for scheduled tasks (#5847)
  • Dangerous command detection: ToolGuard detects find -delete and similar destructive shell patterns (#5843)
  • Access policy: Declarative allow/deny/ask rules evaluated per capability call

Plugins

  • AgentScope middleware hooks: Plugins can register AgentScope-compatible middleware with semver versioning (#5221)
  • Version-gated catalog: Plugin market and CDN only show plugins compatible with the running QwenPaw version (#5661)
  • Lifecycle hooks: on_uninstall hook, validator fixes, and public skill-provider API for plugin authors (#5008)

Tools

  • web_search and web_fetch: Built-in web search and fetch tools with product identity (#5890)
  • grep_search show_file option: Add show_file flag to display matched file content (#5840)
  • Tool error passthrough: Tool result error state forwarded to frontend for better UX (#5912)

CLI

  • cron update: Edit schedule/prompt/config of existing cron jobs without delete+recreate (#5210)

Observability

  • Langfuse 2.0: Trace grouping restored via hook integration; each agent loop is a Langfuse generation span (#5511)

🔄 Changed

  • relay_reasoning: preserve_thinking renamed to relay_reasoning; defaults to off for DashScope to avoid duplicate reasoning in output (#5876)
  • Rate limiting: Multi-dimensional (IP + user + endpoint) rate limiting with configurable windows (#5738)
  • Memory lifecycle: /compact command reworked; new /system_prompt command; search state simplified to avoid stale embeddings (#5450, #5815)
  • SessionItem component: All session renderers consolidated into one SessionItem component (#5754)
  • Skill UI: SkillPool/SkillMarket components refactored; removed dead CSS (#5753, #5532)
  • Plan Mode removed: Agent config no longer includes plan_mode; UI references cleaned up (#5605, #5618)
  • Plugin version retention: Old plugin versions kept on disk after update; failed-load state cleaned up on next boot (#5695)

🐛 Fixed

Context & Memory

  • Eviction no longer removes the active turn; graduated pressure relief prevents OOM on large tool outputs (#5765)
  • Live turn anchored with a seam banner so the model knows where eviction ends (#5871)
  • Evicted spans without headlines now get auto-generated labels in the index (#5848)
  • Strip headline markers from HTTP history path (#5672)
  • Adjust system prompt wording to stop the model from writing every observation to memory (#5629)
  • Truncate oversized tool results before context insertion to prevent token overflow (#5510)

Providers & Tool Schemas

  • OpenAI Responses API formatting and reasoning_content compatibility fixed (#5920)
  • Responses API function_call names preserved correctly (#5913)
  • Fix reasoning_content alignment by improving base formatter drop prediction (#5865)
  • Fix provider-aware context threshold display (#5902)
  • Retry on OpenAI streaming errors that include a body status code (#5799)
  • Restore OpenRouter OAuth route accidentally dropped during Runtime 2.0 migration (#5806)
  • reasoning_content field errors in streaming no longer crash the response (#5582)
  • Tool schema sanitization: nullable fields, Gemini const, standalone type:null all handled (#5549, #5827, #5545)
  • Inline $ref/$defs for GLM models that don’t support JSON Schema references (#5496)
  • Normalize MCP tool names for OpenAI API compliance; gracefully decode malformed tool input JSON (#5485, #5486)
  • Empty api_domain or missing proto descriptors no longer cause hard crashes on Yuanbao (#5804)
  • Only actually configured providers count toward the “online” indicator (#5537)
  • Gemini format_tools override to match their expected schema format (#5517)

Runtime & Agents

  • Interrupted turns now persist their partial state; empty cancel messages suppressed (#5838)
  • cancel_envelope properly yielded on task cancellation (#5674)
  • Workspace prompt files (.qwenpaw.md) and skill injection restored in system prompt assembly (#5396, #5680)
  • Remove stale language arg from memory section call (#5803)
  • spawn_subagent works again under Runtime 2.0 (#5660)
  • Using project_dir without coding_mode enabled no longer silently proceeds (#5640)
  • Self-paired tool messages (call + result from same turn) no longer dropped during message sanitation (#5792)
  • SSE envelope events aligned with v1 protocol format for backward compat (#5495)
  • Windows backslash paths converted to file:// URLs; reverse parsing fixed (#5635)
  • Handle TextBlock objects in offload_tool_result (#5831)
  • Leading whitespace before JSON objects no longer breaks parsing (#5766, #5841)
  • Content-safety image rejections no longer treated as “model can’t do images” (#5533)
  • Loop gate state reset on new user turn; peer-reset on continuation (#5916)
  • Error envelope uses structured Error object for frontend SDK compatibility (#5905)
  • /stop isolated by user_id to prevent cross-user task cancellation (#5883)

Desktop

  • Plugin dep install no longer cascades into a storm of concurrent pip processes (#5570)

  • PyInstaller spec and Tauri config fixed for release packaging (#5518)
