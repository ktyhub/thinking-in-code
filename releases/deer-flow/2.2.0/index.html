deer-flow v2.2.0

DeerFlow 2.2.0

DeerFlow 2.2 turns the 2.1 super-agent harness into a deployment-grade platform with a focus on operating at scale and delegating with trust: scheduled tasks grow into goal-driven workflows with fair multi-owner execution, every subsystem from IM channels to workflows runs across multiple Gateway instances, the extension platform ships full-stack plugins, knowledge retrieval becomes provider-independent with verifiable citations, and models, memory and channels gain production-grade management — hardened by fail-closed defaults, at-rest credential encryption, and a much stricter uploads and paths layer.

This release closes the 2.2.0 milestone with 1068 merged PRs since the 2.1.0 release.

📖 Full notes: CHANGELOG.md · 中文版

⚠️ Breaking changes

  • Local dev binds loopback — make dev / make start no longer listen on all interfaces; ports 2026/8001/3000 and /setup stay off LAN/VPN. Set BIND_HOST=0.0.0.0 in .env to expose the stack, and note that values nginx would misread (0, 1.2.3, bracketed IPv6) are now rejected before any service stops. ([#6587], [#6635])
  • Stored credentials are encrypted at rest — a new env-only DEER_FLOW_CREDENTIALS_KEY (Fernet, comma-separated for rotation) protects IM channel credentials and MCP OAuth refresh tokens; multi-instance deployments with channel_connections or refresh-token OAuth refuse to start without it. IM bot credentials move from plaintext channels/runtime-config.json into the shared channel_runtime_configs table — existing bots are imported once on first start, and a downgrade must re-enter UI-configured bots. ([#6611], [#7207], [#6988])
  • The multi-process gate is stricter — GATEWAY_WORKERS > 1 (or deployment.multi_instance: true, or WEB_CONCURRENCY) now requires the Redis stream bridge; the memory bridge no longer starts multi-process. The new channels.leader_lease section must stay enabled when a non-GitHub IM channel is configured. ([#6328], [#6746], [#6252])
  • Scheduler contracts change — /api/scheduled-tasks* errors return a structured {"detail": {"code", "message", "params"}} envelope (read detail.message); a new scheduler.max_concurrent_runs_per_user (default 2) caps one owner’s concurrent scheduled runs; IM notices are honest, localized, and sent at most once per occurrence; DST-skipped once wall times are rejected with 422. ([#6378], [#6393], [#7281])
  • Thread deletion cascades — deleting a thread now also removes its runs, run events and feedback, so deleted threads can no longer be read or inherited by recreated thread ids. ([#5535])
  • Model-bound history stays append-only — superseded write_file payload elision becomes opt-in (tool_output.elide_superseded_writes, default false) because elision rewrote earlier request segments and invalidated provider prompt caches; skill allowed-tools is compatibility metadata only and no longer hides or blocks tools. ([#7319], [#7455], [#6935])
  • Tool authorization covers middleware tools — plan-mode write_todos and extension middleware tools now pass Layer-1 authorization like any other tool; deployments with an explicit tools policy that omitted them stop binding them. ([#6105])
  • Fail-closed security defaults — delegated web_fetch/web_capture backends (Browserless, Crawl4AI, Firecrawl, fastCRW) screen their base URL and refuse loopback/private defaults until confirmed; the SSRF guard refuses the CGNAT range 100.64.0.0/10 (tailnets need allow_private_addresses: true); IM allowed_users parse fail-closed on Slack, DingTalk, QQ and Telegram (an invalid list now denies everyone instead of silently allowing); external system/developer messages are rejected with 400; permission checks now cover routes that previously had authentication only, and USER.md is scoped per user. ([#6531], [#6202], [#6230], [#6742], [#6730], [#5651], [#4989])
  • Uploads and paths get strict — Windows reserved device names (including superscript COM¹–COM³ and CONIN$/CONOUT$) are rejected across uploads, sandbox writes and skill files; same-name uploads claim the next _N suffix instead of truncating; converted Markdown companions never replace an existing file; rejected attachments are recorded in skipped_files and success means at least one file stored; outline/preview records missing timestamps are rejected — re-upload to restore conversion. ([#6102], [#6148], [#6279], [#6149], [#7388], [#7054], [#7165], [#6165])
  • The composer slash menu is reduced — / now lists only the built-in /goal and /compact; select skills as inline @ references instead. ([#6154])
  • API shapes tighten — malformed run bodies return 422/400 instead of 500; wait endpoints return an SDK-compatible error envelope for completed failed runs; an explicit empty event_types filter matches nothing; keyed resume fails closed (503) for RunStores that can’t persist request identity; web-editor MCP connections become per-user; SQLite file: URIs are rejected; integer config fields reject YAML booleans; gpt-6 family models default to the Responses API; --print/--json exit 1 on LLM-error fallback. ([#7362], [#6217], [#7352], [#6571], [#6499], [#5966], [#6069], [#6017], [#6171], [#6863], [#6056])

([#6326])
  • Multi-instance readiness — IM channels run on several Gateway instances via per-provider leader leases with fencing epochs and automatic failover ([#6843], [#6746]); Helm and compose gain a multi-replica story with a shared JWT secret, surge-then-drain rollouts and PodDisruptionBudgets ([#6347]); provisioner replicas keep sandbox creation alive through restarts ([#6543]); the workflows extension coordinates across Gateways over shared Postgres with an ExecutionFence ([#7138]) and authenticated restart recovery ([#7075]); and make dev-multi boots a two-Gateway cluster locally. ([#6613])
  • The extension platform matures — full-stack plugins register browser pages, conversation actions and model tools in one namespace ([#5647]) with versioned manifests and credentialed ES-module graphs ([#5685]); plugins can contribute composer @ mention providers ([#6189]) and drive full Agent runs through the Gateway’s normal admission ([#6190]); packaged extensions can invoke host models under operator-granted limits ([#5796]); agent-teams lets Custom Agents collaborate as a team via @ mentions, with a shared activity feed and durable team state ([#6243], [#7611]); a default-disabled Script workflows extension sequences and branches Agent runs in a capability-restricted QuickJS subprocess ([#6858], [#6920]); new Jev example plugins prune stale context, classify texts and flag injected instructions ([#5731], [#5735], [#5833]); the extension API advances 0.2.2 → 0.2.7 with run-evidence readers, structured PluginToolResult artifacts and guarded skill-evolution host APIs ([#5727], [#6861], [#5645]); and the Capability Center gallery ships a bundled extension catalog. ([#6188])
  • Knowledge retrieval goes provider-independent — read-only provider catalogs are decoupled from RAGFlow through extension-API registration ([#6904]); retrieval results, capabilities and source evidence are unified across LightRAG and RAGFlow, and citations survive budgets, delegation and replay ([#6716]); RAGFlow results carry verifiable inline citations backed by bounded native excerpts ([#5551]); custom-agent chats can scope retrieval per message with fail-closed allowlists ([#5238]); and new WeKnora and knowledge-platform extensions add managed ingestion plus hierarchical logical spaces with inherited roles. ([#6950], [#7293], [#7417])
  • Models come under management — administrators manage shared models from Settings → Models with an encrypted catalog, optimistic revision checks and provider presets ([#5596], [#6757]); a declarative reasoning capability contract (thinking, dialect, effort maps) normalizes thinking policy across lead agent, subagents and helpers and drives the frontend effort menu ([#5780]); scoped model controls resolve natural-language model selection per task/turn/conversation, with up to 16 aliases per model and per-child overrides ([#7249]); and new presets and providers arrive: Kimi K3.1 ([#7566]), Opper ([#6399]), API Route ([#6579]), You.com ([#6515]), Webz News ([#5880]), Unbrowse ([#5981]), plus Exa-compatible endpoints via EXA_BASE_URL. ([#7306])
  • Channels become operations-grade — a new QQ channel runs over Tencent’s official Open Platform WebSocket with no public callback URL ([#6081]); WeChat pairs by scanning a QR code from the web UI ([#5582]); proactive notifications generalize to Feishu, QQ and WeCom with opt-in run-completion, failure and human-input notices from a durable outbox ([#6903], [#6850], [#4843]); Feishu renders clarifications as interactive button cards ([#6670]); /model switches an IM conversation’s model in place ([#6534]); /connect bindings move to a persistent dialog with copyable codes ([#7591]); and IM runs survive Gateway restarts with on_disconnect: continue and idempotent redeliveries. ([#6876], [#7104])
  • Memory sharpens — user.cognitiveStyle stores collaboration preferences separately from personal context ([#3182]); opt-in lexical relevance ranking blends IDF-weighted query coverage with confidence using a CJK bigram tokenizer ([#5251]); tolerant Markdown storage recovers corrupt or partially written files instead of crashing the agent ([#5545]); the management API and a new memory_get tool work per agent bucket ([#5565], [#6443]); opt-in TypeSafe pre-screening can skip extraction calls and classify reinforcement/correction signals ([#5906]); and extraction watermarks persist across restarts so already-extracted turns don’t re-run. ([#7205])
  • Workspace — the Capability Center unifies MCP, plugins, Lark CLI and skills into a searchable catalog with configuration forms ([#5497]); the composer gains inline @ references to skills, project documents and other conversations, up to 16 per message ([#6063]); tool-produced paths, URLs and task ids become short stable art_xxx artifact handles that survive context compaction ([#4929]); the answer toolbar shows which skills a run loaded, with inspectable snapshots ([#5758]); Custom Agents export/import as portable packages ([#6127]); and projects gain a budgeted search_project_documents tool ([#7286]) and opt-in LLM summaries on the document shelf. ([#6581])
  • Runtime & observability — an authoritative run.terminal trace event seals completed runs ([#7134]); run events carry per-LLM-call telemetry — caller category, provider, model, stop reason, token counts ([#6236]); inspect_run_status gives agents a content-free usage and context-fill snapshot ([#7297]); client context hints and the web UI locale travel into runs as sanitized request-only context ([#7051], [#7294]); and subagent batches gain browser result review with cited evidence ([#7006]), read_batch_result inspection ([#6416]), RAG evidence snapshots ([#6413]), and csv-columns/json-valid acceptance criteria. ([#6714], [#5947])
  • Persistence — a checkpoint retention service prunes trailing duration-only leaves while protecting the resume head ([#5308]); a content-addressed blob store (sha256-verified, opt-in) lets load-balanced Gateways restore externalized tool results and viewed images from shared bytes instead of hitting broken local paths. ([#5361], [#6159], [#6160])
  • Auth & guardrails — account suspension is enforced at every auth surface with a new admin Users page ([#6566], [#6641]); custom RBAC roles are assignable through the admin API ([#6382]); the skills policy governs visibility on listing surfaces without an existence oracle ([#5489]); opt-in deterministic PII redaction rewrites model-bound context with stable placeholders ([#5527]); an opt-in TypeSafe risk gate denies tool calls at a configurable threshold ([#5712]); and plugin actions and management routes are authorization-gated. ([#5842])

🚀 Performance

  • Compaction skips the summarizer LLM call when the exact rendered prompt previously produced the unchanged summary. ([#6318])
  • Opt-in sandbox prewarm overlaps authorized acquisition with the first model response for managed async runs and native subagents. ([#6998])
  • MCP tools are cached per unchanged server and only missing/changed configs are rediscovered ([#6795]); config edits retire only the affected stdio sessions via connection fingerprints. ([#6487])
  • Community tools stop blocking the event loop: You.com, GroundRoute, InfoQuest, Tavily, Firecrawl and DuckDuckGo image search become coroutines or offload to workers ([#7186], [#7183], [#5782], [#5784], [#5786], [#5788]); config reads, auth routes and route-permission resolution load in workers instead of stat+sha256 per request. ([#7580], [#7576], [#7557])
  • Channels: DingTalk AI cards use the channel’s bounded token instead of a blocking SDK call that stalled every stream ([#7597]); Feishu stores thread aliases once per reply instead of rewriting the store per chunk ([#7593]); channel stop() tears down SDK threads off the loop. ([#6134])
  • Gateway: run creation resolves the agent factory via the assembly pool so a cold import no longer stalls all requests ([#6206]); subagent batch export reads 10 rows per page and item lists return previews, cutting hundreds of MB per request ([#6706], [#6781]); skills, user-profile and thread-deletion routes offload directory scans and rmtree to workers. ([#5945], [#5935], [#6319])
  • SSE responses send Cache-Control: no-cache, no-transform so compressing proxies stop buffering run streams into bursts. ([#6393])
  • view_image re-injection caps at four images / 28 MiB per request, so re-viewing an older image no longer resends the whole image history. ([#6828], [#6829])
  • Document conversion offloads at every source size ([#6924], [#5830]); lazy shelf-document conversion writes outside the SQLite write lock. ([#6305])
  • Linear algorithms and bounded payloads: strip_think_blocks ([#5854]) and skill-review link extraction ([#5884]) lose their quadratic paths; structured tool-output previews respect excerpt budgets ([#6422]); one-shot chat models build off-loop ([#7484]); memory pre-summary saves run in a worker ([#7530]); E2B reconciliation stops connect()-probing warm pools ([#5562]); thread skill-view freshness fingerprints end a full NFS recopy per acquire. ([#7333])

🔒 Security

  • SSRF screening everywhere — every web_search provider screens result URLs through the shared public-URL policy ([#7037]); InfoQuest organic, news and image results are screened ([#7031]); image search shares one policy across DuckDuckGo, Brave and Serper with Unicode-host, NAT64 and multicast coverage ([#6740], [#6819]); the CGNAT range 100.64.0.0/10 is refused across web tools, browser and MCP ([#6202]); the agentic browser routes TCP through a per-session SOCKS5 proxy that resolves DNS under SSRF policy, defeating rebinding ([#6201]); and Unbrowse redacts authenticated finalUrls from error responses. ([#7399])
  • Authorization gaps closed — permission checks now cover routes that had authentication only, and USER.md is scoped per user ([#4989]); Live Browser WebSockets require threads:write ([#5621]); view_image requires sandbox:execute ([#5799]); the suggestions endpoint enforces model:use ([#5816]); skill activation is authorized at assembly, including via read_file of a SKILL.md ([#4541]); viewed-image blobs require owner-checked threads:read ([#7604]); and middleware-declared tools join Layer-1 tool authorization. ([#6105])
  • Server-owned state can’t be steered — restored sandbox references are scoped to the authenticated user and thread, and external input.sandbox is rejected ([#5736]); viewed-image host reads are scoped to the current thread ([#5824]); external system/developer messages are rejected before checkpoint writes ([#5651]); client uploads no longer write through symlinks and document conversion reads private descriptor-backed copies ([#5578], [#5611]); and Redis checkpoint purge escapes glob metacharacters so a custom prefix can’t delete another namespace. ([#6709])
  • Credentials & egress — modern sk- tokens, GitHub fine-grained PATs and Google API keys are detected in SkillScan and scrubbed from outgoing IM notifications ([#6394], [#6423]); MCP logs stop emitting credentials ([#6794]); 500 details no longer echo host paths for uploads, skills, custom agents and scheduled tasks ([#7217], [#7255], [#7155]); urllib3 retry/header dumps redact signed URLs ([#5745]); and IM channel credentials gain at-rest encryption keyed by DEER_FLOW_CREDENTIALS_KEY. ([#6611])
  • SkillScan matches shapes, not spellings — fork bombs are matched by structure ([#6689]); the . builtin is treated as a source execution context, including process-substitution forms ([#7247]); curl | sudo -u variants are caught ([#6372], [#6312]); binary magics are sniffed past up to 63 bytes of padding and a BOM across preflight, extraction guard, scan and nested-zip checks ([#7081]); executable-content classification uses the shared is_code_file rule ([#7088]); Windows script suffixes count everywhere ([#6321]); secret rules parse Python via AST, cutting false positives ([#5648], [#6297], [#6428], [#6247], [#6276]); a planted 300 MB file can no longer OOM the scanner ([#6359]); and tool-discovery regexes are bounded against ReDoS. ([#6676])
  • Fail-closed configuration — IM allowed_users parse strictly on Telegram, Slack, DingTalk, QQ and Buzz ([#6230], [#6742], [#6730], [#6811]); PII redaction covers the queued memory payload, invalid_tool_calls, and the /goal evaluator’s inputs ([#5577], [#6387], [#6556]); first-admin claiming is atomic under concurrency ([#5776]); image/svg is classified as active content ([#5594]); and model-written ms-msdt:-style tool-step links are gated by a scheme allowlist. ([#5526])
