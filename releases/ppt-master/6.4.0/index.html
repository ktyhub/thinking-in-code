ppt-master v6.4.0

Minor release collecting a week of fixes found by running the pipeline end to end across languages, input types, deck lengths, and a revision round on a delivered deck. Every change is backed by a reproduced defect; no route, gate, or command was added or removed.

Converter (source_to_md.py)

  • PDF tables with partial ruling keep the columns drawn outside the ruled box (059119ab); spreadsheet notes above the header become a quote instead of a phantom row; a scanned PDF and an out-of-order Arabic text layer are warned about (6c372a29, b3073f8f).
  • Web fetch keeps the declared charset under a lossy decode and warns when only a sliver of the page body was extracted (95e3c41b); web tables keep their links and land on a GFM grid (17d953ad, 0ae80b19); document URLs route to their converter and honour --no-images and meta refresh (0b593d6d, 25a9984e).
  • DOCX charts, table footnotes, and absolute chart targets survive conversion (22da436d, 4bbf7b71); PPTX read-back keeps soft line breaks (c71d9e73).
  • Safety: every redirect hop is validated before it is requested, and CGNAT and multicast targets are refused (4bbf7b71).
  • -o on a single input names the Markdown file and says so; --json keeps stdout to JSON.

Text measurement and multilingual decks

  • Width calibration runs per planned script (Thai, Devanagari, Arabic, …) and at bold weight; Indic vowel signs advance the estimator; wrapping keeps words whole in every space-delimited script and breaks Korean between words (8900e87c, e64a2b38, 88fb8221, 0ae80b19).
  • Indic, Thai, Arabic, and Japanese faces are on the PPT-safe list; Japanese decks get EA faces and kinsoku; right-to-left decks get RTL defaults; explicit BCP-47 scripts pick the theme script slot (0609875d, 5771f4f0).
  • Latin runs inside a non-Latin deck proof as English (f76d1ecb). Quick decks declare their language on the page root and the export derives theme fonts from the pages (0b06d190).

Native charts and tables

  • Table parity compares runs by effective style and lets explicit run colour and weight override the cell default (451c6814, aee33e5a); parity reads inherited text-anchor and tspan colour (5771f4f0).
  • series[].line_style is rejected with a clear error and passes only inside a combo; Cambria Math is accepted; JSON CDATA survives compaction; classic axes are refused on ChartEx charts; data-label points follow their show flags (4a7512ec, 83d8d00f, 25a9984e).
  • Fallback stamping reports a malformed page instead of skipping the valid ones; preset atoms keep their paint through style compaction (7acddfb9, 6881d370).

Export and motion

  • Morph candidates are planned and authored whether or not animation is enabled (1fb122b6); exported objects are named after their SVG id (a849c498); structured decks animate slot groups and re-skin master atoms (529403b3).
  • MiniMax word timings that share one original-text span merge into one subtitle; written-out numbers stay whole (96742ffb, 7086c45c).

Quality gate

  • The final gate compares the design_spec §IX roster with svg_output/, so a page dropped or left un-planned during a revision no longer passes silently (191f4629).
  • The carrier receipt counts pages whose §IX Relationships line names a carried relation; the unresolved-geometry warning names the tspan rule; text picture fills count as image placements (95e3c41b, ed171577).

Workflow

  • A delivered project’s revision has a named entry: routing.md sends it to a Revision Round section in generate-pptx.md (Default) or a revision note in quick-generate.md (Quick), covering which layer owns each kind of change, what a roster change renumbers, and which commands rerun (77c27457, 4d551728).
  • User-supplied images with licence terms register in image_sources.json so their credits are bound at the gate; research fetches pass --no-images (8e5e30a7).
  • update_spec.py docs state what a colour change still edits by hand and when to re-stamp fallbacks.

Preview

  • Preview URLs open in the Windows browser under WSL (#287, thanks @zhuoyi780-alt).

Install

The ppt-master-skill-v6.4.0.zip asset contains only skills/ppt-master/ for agents that load the skill directory directly.
