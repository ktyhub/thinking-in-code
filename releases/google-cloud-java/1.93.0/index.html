google-cloud-java v1.93.0

1.93.0 (2026-09-30)

⚠ BREAKING CHANGES

  • automl: remove java-automl library (#14540)

Features

  • automl: remove java-automl library (#14540) (6f13a1d)
  • bigquery-jdbc: infer undeclared fields in PreparedStatement (#14400) (e989a72)
  • gax,gapic-generator-java: retry start upload call and rename ResumableUploadCallSettings to ResumableUploadOptions (#14511) (98c2073)
  • gax: add chunk upload recovery loop for resumable uploads (#14424) (8ecd1e5)
  • gax: add ResumableUploadProgressListener and related infrastructure (#14426) (c7f10d8)
  • gax: add RewindableStreamBuffer in prep for chunk upload recovery (#14423) (349c315)
  • gax: enforce global timeout for resumable uploads (#14425) (3cb9805)
  • gax: include upload-status header in resumable upload command response objects (#14420) (23e49c1)
  • gax: replace InputStream with InputStreamSupplier in resumable upload public surfaces (#14521) (3c79730)
  • gax: retry chunk upload on transient errors (#14422) (e72365e)
  • gax: treat resumable upload server rejection as terminal (#14516) (b288788)
  • gax: wire up ResumableUploadProgressTracker (#14427) (e7ba3e8)
  • grpc-gcp: Add shared fallback state and probing recovery options to GcpFallbackChannel (#14013) (675f639)
  • pubsub: add publish start time to client telemetry header (#14496) (4b6a671)

Bug Fixes

  • auth: exclude javax.annotation-api from api-common dependency (#14538) (668fd18), refs #12363
  • bigquery-jdbc: abort session when connection is closed (#14273) (5bd4520), refs #13922
  • storage: add App Hub storage.googleapis.com prefix to destination.id (#14527) (0f6f9b5)

Documentation

  • Add gRPC Post-Quantum Cryptography Guide (#14245) (340a239)
  • samples: add zonal bucket pre-warmed writer pool sample (#14517) (32e6f87)
  • samples: pre-warm writer pool channels with flush() after open() (#14537) (df06290)
  • update PQC guide to follow standard template format (#14333) (0b969d5)
