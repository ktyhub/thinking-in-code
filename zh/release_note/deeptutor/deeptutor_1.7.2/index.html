DeepTutor v1.7.2

发布日期： 2026.11.06

v1.7.2 以 v1.7.1 为基础，添加了选定文本朗读功能、更简单的模型设置以及更可靠的引导学习、检索和更新功能。桌面版本现在需要 Apple Silicon 和 Intel Mac 安装程序以及 Windows 下载程序。

新消息

完整的桌面下载和更强大的 Windows 支持

GitHub 版本提供 Apple Silicon 和 Intel DMG、Windows 安装程序和 Windows 便携式 ZIP。发布工作流程会检查每个平台以及所有版本下载和稳定别名。 Windows 修复涵盖会话和迁移锁定、插件环境、Python 可执行文件发现、非 UTF-8 输出以及包含空格的路径。

只阅读您需要的段落

在聊天、掌握路径或阅读中选择文本，然后选择朗读以通过您配置的语音提供程序收听它。聊天朗读功能还会记住当前浏览器中每个对话的播放速度。语音渲染可以更自然地处理转义百分号和度数符号，视频课程的边缘后备选择与课程语言匹配的语音。

更简单的提供商设置和更广泛的兼容性

设置会在编辑凭证后发现可用模型，并允许您一次导入多个模型。新的自定义提供程序默认为自动协议选择。 NVIDIA NIM 添加了具有不同查询和段落角色的文本检索嵌入；较新的 DashScope 图像模型使用其匹配生成协议，4K 仅限于 wan2.7-image-pro。响应 API 工具参数、结构化输出、重播历史记录和 Codex 自定义标头接收兼容性修复。

保持情境的引导式学习

在掌握路径大纲开始之前选择一个模型。后续澄清和遗漏部分将根据其完成的解释进行评估，而过时的卡片回复和重复重试将得到更仔细的处理。源引文不匹配会受到有界重试，并且掌握导航、板滚动和辅导记忆恢复更加可靠。

更容易访问的对话和检索

韩语可作为部分界面翻译使用，未翻译的文本可以使用英语作为后备。更多标签和日期遵循所选的界面语言。 Little Tutor 线程出现在命令面板中，文档阅读器按需加载，套接字故障和取消恢复更可预测。 BM25 保留点标识符，文档提取远离 API 事件循环，笔记本和收藏夹工具支持只读记录检索。

更安全的更新和有限推理恢复

软件包更新将已安装的功能模块保留在目标核心版本上，并记录启动失败，而不是在重新启动时卡住。分离启动可避免过时的源树导入，失败的 CLI 应用程序回滚可保留备份。当推理耗尽输出预算而没有可见答案时，共享代理循环可以停止或进行一次明确限制的较高预算重试。

升级注意事项

  • 完整应用程序： 停止 DeepTutor 并备份运行时主页，然后运行 python -m pip install --upgrade "deeptutor[full]==1.7.2"。保持相同的DEEPTUTOR_HOME；重新启动之前，请与 python -m pip check 和 deeptutor module list 进行验证。任何附加功能车轮也必须与 1.7.2 版本匹配。
  • 旧版安装： 从 1.6.15 或更早版本升级必须先卸载旧版 deeptutor-cli 软件包，然后再安装模块化软件包系列。按照 v1.7.0 中的迁移命令进行操作。
  • **源安装：**安装 requirements/full.txt，然后安装 python -m pip install -e . --no-deps。在更换模块之前停止活动服务器和 CLI 转动。
  • Docker: 拉取 ghcr.io/hkuds/deeptutor:1.7.2 或 :latest 并使用现有数据卷重新创建容器。
  • **桌面：**在此 GitHub 版本上使用匹配的安装程序或便携式 ZIP。 Windows 版本保持未签名状态。自动桌面更新发现未连接； shell 支持手动提供的签名核心更新。
  • NVIDIA NIM： 显式选择其嵌入绑定，并在更改嵌入模型时重新索引现有知识库。此绑定仅支持文本。
  • 语音和推理恢复： 选定文本语音需要工作配置的 TTS 服务。增加恢复输出预算是可选的，并且可能会增加延迟和使用量；默认重试预算保持不变。
