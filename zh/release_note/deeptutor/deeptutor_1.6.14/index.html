DeepTutor v1.6.14

发布日期： 2026.10.08

v1.6.14 以 v1.6.13 为基础，带来了原始视觉实践、可恢复的知识库索引、科学研究工具和托管插件。视频学习现在生活在雷丁；重新打开时现有的观看对话会迁移。

新消息

原始图形、页面和视觉练习

询问附加知识库中的确切图形、表格或 PDF 页面。 DeepTutor 检索原始图像或渲染选定的页面或区域，保留文档标识和源链接。文件视图公开了源视觉覆盖范围，包括丢失或未经验证的提取。引导学习将这些证据用于视觉问题，并区分解释、辅助练习和独立掌握；无法获取或不确定的证据保持未评级。

可以恢复的索引

知识库详细信息显示持久的索引进度、单个源结果和恢复信息。重试重用兼容的已完成解析和经过验证的 MinerU 云切片；取消在安全边界生效。 LlamaIndex 仅在重新加载、向量验证和检索探测成功后才会发布新版本，并在重建失败时保留早期的可查询版本。检索还报告了混合向量回退和不完整的 IMA 证据。

阅读包括视频学习

YouTube 和 Bilibili 媒体共享阅读工作区，提供基于时间戳的讨论和本地播放。可以导入以前观看的对话、位置和注释，而无需修改其旧媒体或笔记本记录。阅读面板可独立调整大小，提供焦点预设，并在窄屏幕上保留可用的分页和选择控件。

研究可追踪的证据

科学请求和深度研究获得了用于阅读版本化 arXiv 论文和原始页面、根据固定的 GitHub 修订版检查论文声明以及构建文献证据矩阵的工具。 MCP 目录添加了 alphaXiv。管理员可以批准帐户拥有的研究连接的确切专用网络 MCP 源，并在工具运行时再次检查批准。

审查插件生命周期

插件CLI支持检查、安装、权限审批、启用/禁用、回滚和卸载。托管轮在单独的环境中运行，具有工件检查和可撤销的运行时门。官方目录格式支持审核包；此版本附带一个空目录，因此它不会自动安装新的第三方代码。

学习连续性和日常修复

Space 获得工作空间学习日志，显示当前任务、上次会话交接和确认的学习记录。在丢失确认后，聊天重试可重复使用原始对话，搁置的问题在重新加载后仍然存在，未发送的草稿仍然可以恢复。分支导航、内存帐户隔离、启动器恢复和错误报告得到改进； Visualize 还获得了美人鱼思维导图。

提供者和设置

GitHub Copilot 使用设备登录和每个所有者的凭据，并在设置过程中检查推理。 Opper 加入了 LLM 和嵌入提供商，Y-API 加入了 LLM 提供商。提供商设置提供更清晰的添加流程、协议感知的默认端点和提供商语音发现。本地嵌入服务可以在没有 API 密钥的情况下工作，同时嵌入并发性和 Qwen3-Instruct 思维处理得到纠正。

deeptutor.info 上的发布附带更新的英文和中文文档。

升级注意事项

运行pip install -U deeptutor； Docker用户拉动ghcr.io/hkuds/deeptutor:latest。

  • 视频学习： 使用阅读来进行新的视频课程。独立的 immersive_watching 功能和 watching / watch CLI 别名已停用。现有观看链接进入兼容性迁移；保持现有应用程序数据可用。丢失的旧视频使其对话可以像普通聊天一样进行。
  • GitHub Copilot： 如果您之前依赖外部 Copilot/nanobot 令牌文件，请再次运行 deeptutor provider login github-copilot。每个账号单独登录；副驾驶资料无法通过模型授权共享。
  • 语音： 在模型设置中明确选择语音；新的配置文件不再接收硬编码的默认语音。
  • OrcaRouter： 其内置提供商预设已删除。如果您仍使用该服务，请配置具有显式兼容端点和模型的自定义连接。
  • **知识库：**旧索引需要重新解析和重新索引才能获得新提取的图形记录。精确的PDF页面检查可以直接使用原始文档。重试仅重用有效的兼容检查点；它不会在文档中途恢复中断的本地 MinerU 推理。
  • 插件： 在批准受管软件包之前检查请求的权限。当插件生成发生更改时重新启动 DeepTutor，以便加载经过审查的代码；禁用或撤销批准会阻止后续调用。
  • systemd 安装： 停止服务，在 Python 环境中升级 DeepTutor，然后重新启动服务。
