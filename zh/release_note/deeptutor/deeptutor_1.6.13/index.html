DeepTutor v1.6.13

发布日期： 2026.10.04

v1.6.13 以 v1.6.12 为基础，扩展了阅读、听力和题库练习，改进了文档解析和语音配置，并引入了波兰语和更多模型提供程序。聊天附件现在遵循选定的工作区，并在转换过程中保留现有的上传和 URL。

新消息

阅读、聆听并重温

沉浸式阅读获得自然朗读音频和测验明星奖励。沉浸式观看会获得带时间戳的标记、注释和建议的复习点。 PDF 大小调整和 EPUB 章节导航更可靠地保留阅读位置；学习者可以在其授予的访问权限内打开明确指定的书籍和阅读材料。

从你的题库中练习

直接从题库开始练习，并选择多个已保存的问题进行聊天。引导式学习会打乱多项选择选项，并避免通过选项字母或检索提示暴露正确答案。 Co-Writer 允许您选择模型进行编辑。

更可靠的文档检索

选择独立的视觉模型进行文档图像描述；成功的描述会按工作区缓存，并具有可选的有界批处理。 MinerU 云解析对超大 PDF 进行切片并恢复已完成的部分，而本地故障则报告可操作的原因。可选的微小扫描归一化、编号练习查找和更好的图形保留可改善教科书检索。 deeptutor kb eval 根据本地评估数据集衡量检索质量。

解释失败的语音设置

语音模型具有供预览和播放使用的可配置合成超时。 DashScope Qwen-Audio 和 Qwen3 TTS 使用各自的端点、语音、格式和区域要求。预览错误区分身份验证、权限、参数、配额、网络故障和超时。回复播放可保留数学运算、取消过时的请求并防止音频重叠。

工作空间和连接

新的聊天内容上传到所选工作区的 chat/attachments 目录中，以便工作区工具可以找到它们。当使用他们的对话或迁移其数据时，早期上传的内容会移至那里；现有附件 URL 仍然可读。 SearXNG 连接测试解释了 Docker 寻址、禁用的 JSON 输出和空搜索结果。网络资源可以配对双语内容，知识库检查可以重复使用探测器，而不会阻塞 API。

合作伙伴、语言和提供商

将合作伙伴群组对话导出为 Markdown 并为每个聊天配置 Telegram 响应策略。飞书投递和Telegram代码块更可靠。波兰语加入界面语言； Requesty、API Route 和 FutureInfra 加入 LLM 提供商，提供原生 MiniMax 语音和小米 MiMo v2.5 预设语音支持。

聊天恢复和日常修复

历史记录搜索会检查完整的对话记录并排除回收的会话。长对话分支、重新连接提交、LaTeX 选择和学习者路线恢复更可靠。图像有效负载不再夸大令牌估计，GLM 推理选项与支持的设置相匹配，并且 deeptutor doctor 遵循配置的提供程序和令牌预算。

deeptutor.info 上的发布附带更新的设置和功能文档。

升级注意事项

运行pip install -U deeptutor； Docker用户拉动ghcr.io/hkuds/deeptutor:latest。

  • 附件： 无需手动移动。早期上传的内容会在需要时重新定位到选定的工作区；在升级过程中保留安装现有的应用程序数据。
  • 语音：当合成需要更多时间时，在语音模型中设置请求超时（秒）；默认值为 60 秒，支持的范围为 5-600 秒。使用预览语音来测试合成；单独获取模型列表并不能验证语音。
  • DashScope Qwen-Audio TTS： 使用北京 API 密钥和所选型号支持的语音。提供者 API 基本 URL 自动选择匹配的语音端点； Qwen3 TTS 使用自己的语音和 WAV 输出。
  • 文档图像： 如果主模型无法检查图像，请在文档解析设置中选择图像描述模型。批处理和小扫描归一化是可选的；旧的索引内容需要重新解析和重新索引以获得新生成的描述或图形记录。
  • **学习者书籍：**管理员必须授予书籍表面并明确分配书籍；学习者的访问权限仅限于这些作业。
  • systemd 安装： 停止服务，在其 Python 环境中升级 DeepTutor，然后重新启动服务。
