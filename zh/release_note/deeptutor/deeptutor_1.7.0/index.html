DeepTutor v1.7.0

发布日期： 2026.10.28

v1.7.0 建立在 v1.6.15 的基础上，带来了模块化安装、更新的学习工作区、带有 Dito 的基于块的笔记本以及旁白视频课程。完整应用程序升级现在使用 deeptutor[full]；现有的运行时数据与已安装的包保持分离。

新消息

安装您使用的部件

deeptutor现在提供核心聊天、CLI和SDK； deeptutor[full] 选择 Web 应用程序和标准功能模块。 deeptutor-cli 包成为兼容性别名。使用 deeptutor module list 检查已安装、启用和就绪状态，然后在应用程序停止时启用、禁用、安装或删除模块。依赖性检查可以保护所需的模块，而删除则可以保留用户数据。

围绕学习组织的工作空间

现代和经典布局提供不同的导航安排。主页汇集了聊天、任务板、学习笔记本和日历；学习和资源使学习活动和材料易于访问。自定义聊天模式、控件和启动提示，或选择新学习页面上显示的学习方法。对话和资源导航保留其工作区边界。

笔记本页面旁边有 Dito

学习笔记本用页面、子页面和块取代了以前的 Co-Writer 编辑器。导入 Word 文档、从收藏夹插入源记录、与 Dito 讨论段落，并在接受建议的编辑之前对其进行审查。将页面导出为 Markdown 或 Word。收藏夹保存已保存的源记录；笔记本页面包含您自己的书写和理解。

视频课程和免费朗读

选择视频课程可生成直接在浏览器中播放的课程，并带有字幕和可选的 Microsoft Edge 旁白。框架检查在有界 WebAssembly 解释器内执行生成的代码； Docker 不是必需的。 Microsoft Edge 还加入了朗读提供商，并且回复播放在 iOS 上更加可靠。

更可靠的辅导和索引

兼容中断的 LlamaIndex 重建可以恢复已完成的嵌入检查点。知识库创建会保留同名文档，并且一个失败的标题组不再中止整个摄取。聊天可以更一致地恢复工作人员故障，完整的人为思维被排除在历史重播之外，并且提示缓存使用更稳定的对话前缀。指导学习在检查引文时保留了数学意义，并将审查工作保持在其资格范围内。

英文和中文指南与此版本同步在deeptutor.info。

升级注意事项

  • 完整应用程序： 停止 DeepTutor 并备份运行时主页，然后运行 python -m pip install --upgrade "deeptutor[full]==1.7.0"。在使用相同的 DEEPTUTOR_HOME 重新启动之前运行 python -m pip check 和 deeptutor module list。裸 deeptutor 现在仅选择核心。
  • 旧版 CLI 软件包： 首先运行 python -m pip uninstall deeptutor-cli，然后安装新的核心或完整配置文件。 （可选）重新安装 deeptutor-cli==1.7.0 作为兼容性别名。旧的 CLI 拥有共享的 Python 文件，因此在同一事务中升级它可以删除新核心所需的文件。包删除使运行时主目录数据保持不变。
  • **源安装：**安装 requirements/full.txt，然后安装 python -m pip install -e . --no-deps。使用 python scripts/install_extras.py <extra> 来实现可选的源依赖项。源检查支持模块启用/禁用；软件包安装/卸载需要wheel环境。
  • Docker: 拉取 ghcr.io/hkuds/deeptutor:1.7.0 或 :latest 并使用现有数据卷重新创建容器。
  • 视频课程： 后端需要 Node.js 22+ 和 npm；首先使用下载固定渲染包。安装 edge-tts 额外的旁白。如果没有可用的旁白，课程会保留字幕并无声播放。
  • 模块版本： 核心轮和功能轮必须匹配。在更换模块之前停止活动服务器和 CLI 轮流；检查依赖项阻止程序，而不是卸载正在运行的应用程序下的包。请参阅模块安装和迁移。
