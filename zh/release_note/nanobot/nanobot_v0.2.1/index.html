nanobot v0.2.1

🐈 nanobot v0.2.1 在这里 — 合并了 84 个 PR，17 个新贡献者。代理人得到了一个真正的工作台。 标题是 WebUI 成为实际工作发生的地方。聊天界面更流畅、更快、更容易 trust：实时文件编辑显示为活动，工具轨迹呈现更清晰，源链接获得可读的图标，标记和代码块表现更好，新聊天可以在刷新中幸存，思想/响应排序现在与模型的真实回合结构相匹配。设置、侧边栏控件、模型切换、上下文窗口控制、斜线命令、项目工作区和访问模式都更加接近于单一连贯的控制界面。 第二个故事是长期运行的工作变得更加持久。持续的目标不再让跑步者绊倒，目标迭代预算更高，会话锁定可以防止重叠轮流相互影响，AutoCompact 和整合竞赛得到修复，心跳转移到 cron，会话存档保留得到了多个数据丢失修复。在实践中，这意味着更少的神秘中断、更少的重复存档，以及长代理工作流程保持其意图线程的更好机会。 第三个故事是纳米机器人变得更容易插入真实的堆栈。 CLI Apps 和 MCP 现在共享更统一的扩展路径；预设设置和功能提及使工具更容易发现；扩展注册表为集成提供了一流的家。提供商覆盖范围扩大到 Ant Ling、Skywork、Novita、Step Plan、StepFun、Zhipu 图像生成、OpenAI/Codex 图像生成、Ollama 图像生成以及更丰富的 OpenAI 兼容配置。频道也随着 Signal、Telegram webhook 模式、Discord 模型斜杠命令、Matrix 验证修复以及更安全的微信/Teams/Matrix 行为而增长。

亮点

  • WebUI 作为日常工作台 — WebUI 不再只是一个打包的聊天界面。它现在具有更好的活动渲染、实时文件编辑可见性、更清晰的源链接、更强大的降价/代码渲染、改进的侧边栏性能、项目工作区、访问控制、上下文窗口设置、模型控件、斜杠命令操作以及更精美的本机主机感觉。最终的想法/响应排序修复使流式代理工作按照实际发生的顺序读取。 （#3877、#3899、#3906、#3951、#3953、#3987、#4007、#4045、#4108、#4121、#4137）
  • 长期运行的代理稳定性 - 目标模式和多轮工作变得更加坚固：持续的目标使跑步者保持活力，目标迭代预算延长，process_direct 现在具有每会话锁定，流/会话并发错误得到加强，AutoCompact 和合并器竞争得到修复，存档保留现在可以避免重复存档和消息丢失。 （#3881、#3999、#4041、#4104、#4127、#4129）
  • CLI 应用程序、MCP 和扩展工作流程 — CLI 应用程序作为连接 CLI 原生工具的一种方式登陆，然后通过预设设置、功能提及、过时安装恢复、注册表徽标和扩展注册表源与 MCP 概念统一。结果是从“我有一个有用的本地工具”到“纳米机器人可以在工作流程中调用它”的更清晰的路径。 （＃3963，＃3979，＃3991，＃4046）
  • 更多提供商，更丰富的模型路由 - 通过 Ant Ling、Skywork、Novita、Step Plan、OpenAI API 类型选择、extraBody 以及多个图像生成提供商（包括 StepFun、OpenAI/Codex、Ollama 和 Shipu）扩大了提供商的范围。一些后续修复保留了工具调用 ID、改善配额/计费错误、处理提供商传输边缘情况，并在 OpenAI 兼容路线上保持思维/推理控制诚实。 （#3900、#3910、#3916、#3927、#3946、#3954、#3971、#3974、#3984、#3988、#4048）
  • 通道和部署完善 - 信号支持、Telegram webhook 模式、Discord 模型斜线命令、Docker/WebUI 部署修复以及更清晰的秘密/部署文档使 Nanobot 更容易在本地终端外运行。网关冷启动也大幅下降，从秒级降至亚秒级。 （#3872、#3918、#3935、#3996、#4031）
  • 安全性和可靠性强化 - WebSocket 令牌发行现在需要身份验证，在 Web 获取之前验证重定向目标，在 SSRF 检查中规范化 IPv6 映射的 IPv4 地址，Teams 回复 trust 服务 URL，Matrix 入站媒体下载受到限制，并且在 Windows 和 URL 密集型命令上加强了 shell/exec 行为。 （#3928、#3933、#4051、#4086、#4103、#4106、#4047）
  • 国际化和文档 - WebUI 语言环境集已在 zh-TW、ja 和剩余键中填写，自述文件定位和新闻部分已刷新，多语言文档链接已浮出水面，本地提供程序设置更容易找到，AGENTS.md 为编码代理提供了更清晰的方式进入存储库。 （＃3930，＃3962，＃3964，＃4131）

社区

非常感谢所有提供 v0.2.1 的人 — 84 个 PR、29 个贡献者，并热烈欢迎 17 首次贡献者。这个版本感觉不像是一个重大功能的下降，而更像是纳米机器人成为你可以整天保持开放的东西：更稳定、更清晰、更容易扩展。
