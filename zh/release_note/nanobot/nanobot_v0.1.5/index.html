nanobot v0.1.5

🐈 纳米机器人 v0.1.5 就在这里 🎉 — 合并了 66 个 PR，27 个新贡献者，以及第一个拥有自己主页的版本。 我们很高兴地宣布，nanobot 现在有一个官方网站 nanobot.wiki，提供英语、中文、日语、韩语、西班牙语和法语的多语言文档。构建它提醒了我们这样做的原因：**nanobot 一直属于开源社区，而一个合适的家——一个会说你的语言的——感觉早就该有了。**每个文档页面、每个翻译、每个示例都是开放的并且准备好贡献。这不会改变。 现在，关于发布本身。如果说《v0.1.4.post6》是为了分解地基，那么《v0.1.5》则是为了使建筑物变得宜居。该代理现在可以连续运行几个小时而不会失去理智。内存有一个合适的架构。在生产中运行纳米机器人从“可能”变成了“舒适”。在这个版本中，纳米机器人不再是原型，而是开始成为基础设施。

亮点

  • 长时间运行的任务变得更加可靠 — 长时间运行的任务获得了彻底的可靠性通过。运行时现在可以处理 CancelledError，而无需孤立子进程，重试分类使用结构化错误元数据而不是错误文本正则表达式（因此，在速率限制等待和重试时，429 配额耗尽会立即停止），禁用 SDK 级别自动重试以防止请求放大，并且 Azure 重试不再双底。如果您的代理运行 cron 作业、连夜编排工具或处理突发流量 — 这是使这些会话保持不变的版本。 （＃2733，＃2762，＃2759，＃2761，＃2765）
  • 记忆有一个架构 - 遇见梦想 - 新的两阶段记忆系统将实时对话历史与巩固的长期知识分开。 Dream 作为后台整合通道运行 - 将其视为在所学知识上睡觉的代理 - 由 git 版本化存储支持，因此每个内存状态都是可恢复的。旧版 HISTORY.md 文件会自动迁移。 Jinja2 模板与 Dream 一起出现，让您可以控制代理如何形成其响应和记忆摘要。这不是一个固定的功能——它是纳米机器人从第一天起就应该具备的存储系统。 （#2717、#2779 和 10 多个后续强化提交）
  • 在生产中运行纳米机器人变得真实 - exec 调用现在通过 bwrap 沙箱化，容器默认以非 root 身份运行。 exec 工具不再将主机环境变量泄漏给 LLM。默认情况下，API 端口绑定到本地主机。配置机密支持 ${VAR} 插值，因此您无需再次对密钥进行硬编码。新的 nanobot-api Docker 服务为您提供了一个开箱即用的隔离 OpenAI 兼容端点。 WhatsApp 桥获得自动本地身份验证。这些并不是光鲜亮丽的变化——它们是您在部署后可以安然入睡的原因。 （＃1940，＃2831，＃2830，＃2841，＃2715）
  • 三个新提供商，GPT-5 已准备就绪 — GPT-5 模型系列支持通过适当的温度处理实现。小米 MiMo 面向设备端推理爱好者加入。百度千帆登陆中国生态系统。 Dashscope和ModelArk得到了适当的思维参数控制。 reasoning_content（来自 DeepSeek-R1、Kimi、MiMo 的思想链）现在通过完整的消息管道可见并保留。无论用户的模型在哪里，纳米机器人都会不断与用户见面。 （#2788、#2495、#2811、#2840、#2770）
  • 渠道不断变得更好 — 电子邮件现在通过 MIME 过滤和文件名清理来提取附件。 WhatsApp 通过 Groq/OpenAI Whisper 获得了语音转录功能。飞书处理后自动消除反应，并支持视频下载。 Telegram 将工具提示呈现为可折叠的块引用，支持 DM 线程，并分割超大的流式回复。微信多式联运持续推进。 Langfuse集成落地生产可观测性。 /status 现在显示网络搜索提供商的使用情况以及缓存命中率。 （#2815、#2530、#2812、#2810、#2793、#2520、#2659、#2832、#2703）
  • 开发人员体验，安静 — 内置 grep 和 glob 工具为代理提供本机代码搜索。 Tool 类使用适当的 JSON 架构参数进行了重构。 Python SDK 外观可实现程序化的每会话隔离。 CLI 获得了用于多实例设置的 --config。 Web 搜索统一在 WebToolsConfig 下并带有切换控件。测试套件增长到 1,142 个测试，全部为绿色。 （＃2754，＃2780，＃2653，＃2740，＃2643）

社区

欢迎加入我们的 27 位新贡献者，他们在此版本中做出了第一个贡献。 v0.1.5 的形成源于一个简单的信念：AI 代理框架不是通过添加功能来赚取 trust，而是通过成为您在周五晚上无人值守的情况下运行的那种软件。不会忘记的记忆。重试不会放大。不泄漏的沙箱。每一位强化边界、捕捉竞争条件或添加测试的贡献者——你们让纳米机器人今天比昨天更值得 trust 。这是唯一重要的指标。 完整 Changelog：https://github.com/HKUDS/nanobot/compare/v0.1.4.post6…v0.1.5
