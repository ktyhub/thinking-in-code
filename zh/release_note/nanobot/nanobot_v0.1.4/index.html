nanobot v0.1.4

🎉 🐈 纳米机器人社区的另一个重大发布 - 感谢所有贡献者，特别是我们的 18 个新贡献者！ 此版本增加了 MCP 工具服务器支持、实时进度流，以便用户实际看到代理正在做什么，以及一波新的提供程序（兼容自定义 OpenAI、GitHub Copilot、OpenAI Codex、SiliconFlow）。频道也受到了很多人的喜爱——Telegram 现在可以处理媒体上传和长消息，Slack 拥有适当的 mrkdwn 和线程回复，飞书支持富文本。我们还添加了用于单命令部署的 Docker Compose、将会话范围限定到工作区，并切换到 json_repair 进行防弹 LLM 响应解析。更少的沉默、更多的供应商、更好的渠道——这就是纳米机器人的方式。

亮点

  • MCP 支持 — 通过模型上下文协议连接外部工具服务器 (#554)
  • 进度流 - 代理显示多步骤工具执行期间正在执行的操作 (#802)
  • 新提供商 — 自定义 OpenAI 兼容端点、GitHub Copilot、OpenAI Codex、SiliconFlow（#786、#720、#312、#151、#630）
  • 频道改进 — Telegram 媒体上传和消息分割、Slack 线程回复和 mrkdwn、飞书富文本 (#747、#694、#717、#784、#629、#593)
  • Docker Compose — 单命令部署 (#765)
  • 工作空间范围内的会话 - 会话现在位于具有旧版迁移的工作空间内 (#713)
  • 强大的 JSON 解析 — json_repair 用于处理格式错误的 LLM 响应 (#664)
