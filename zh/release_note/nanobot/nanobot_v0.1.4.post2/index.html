nanobot v0.1.4.post2

🐈 纳米机器人 v0.1.4.post2 就在这里 — 合并了 32 个 PR，14 个新贡献者！社区火了🔥 此版本的重点是可靠性：完全重新设计的心跳、提示缓存以降低 API 成本、强化的提供商兼容性以及数十个通道级修复。更少的惊喜，更多的稳定。

亮点

  • 心跳大修 - 用虚拟工具调用决策机制替换了脆弱的令牌检测；心跳现在在空闲时真正安静（#1102、#1054、#1039、#1036）
  • 提示缓存优化 - 动态上下文（时间、会话）从系统提示移动到用户消息，从而实现持久的提示缓存命中 (#1115)
  • 代理可靠性 — 行为约束、上下文中的完整工具历史记录以及可操作的错误提示 (#1046)
  • Slack — 线程隔离会话、粗体/标题工件的 mrkdwn 后处理、套接字错误处理（#1048、#1107、#957）
  • 飞书 - 帖子消息中的富文本图像提取、文件下载 API 修复（#1090、#986）
  • 电子邮件 - 即使自动回复被禁用，主动发送工作，更智能的重复数据删除（#1077，#959）
  • 提供程序修复 — DeepSeek reasoning_content 规范化、空内容块过滤、通过 @property 的 API 密钥热重载（#947、#955、#949、#1071、#1098）
  • 安全 - 使用 relative_to() 而不是 startswith() 防止路径遍历 (#956)
  • MCP — 可配置超时以防止代理挂起，删除了 HTTP 传输的冲突默认值（#950、#1062）
  • Memory — 修复了 LLM 在合并期间返回 dict 参数时出现的 TypeError (#1061)
  • Discord — 在持续 HTTP 失败时中断键入指示器循环 (#1029)
  • CLI — nanobot status 输出中添加了钉钉、QQ、电子邮件 (#982)
  • 打包 - 工作区模板移至 nanobot/templates/ 以进行正确的 pip 打包 (#1043)
  • 文档 — systemd 用户服务部署指南 (#968)
