nanobot v0.4.1

修订 发布时间2026年11月6日 来源HKUDS/nanobot 英文原文

nanobot v0.4.1

变化

  • 修复了 TLS 证书验证、沙盒 shell 执行和排队输入的工作区权限。
  • 防止闲置维护阻止活动工作或错误地拒绝更新。改进重试、重新连接和恢复行为，并通过压缩保留本机提供程序状态。
  • 添加文件上下文图，其中包含文件预览、本地 Markdown 链接和最近的上下文快照。切换主题可以使每个对话的上下文保持独立。
  • 跨代码、源预览和只读差异共享语法突出显示，并具有完整的源复制和纯文本回退。
  • 减少文件读取、会话历史记录和提供程序请求中不必要的内存副本。改进导航、上下文使用显示、历史加载和技能源识别。
  • 在整个 0.4.x 中保留旧历史记录和代理迁移，包括未迁移对话的原始工作区所有权。

升级注意事项

  • 在外部升级之前停止受影响的进程并备份配置和对话。使用原始安装程序、包管理器或容器工作流程，然后验证正在运行的版本、旧对话、新消息并再次重新启动。请参阅更新纳米机器人。
  • **0.3.5可以通过其原始安装方法直接升级到0.4.1。**无需中间安装0.4.0。旧版 JSONL 和代理进口商在整个 0.4.x 中仍然可用，并计划在 0.5.0 中删除；保留原始文件和迁移备份。
  • 0.4.1 是接受 0.4.0 中引入的临时 OpenAI apiType / api_type 转换的最终版本。 保存迁移的 api 配置并在以后升级之前替换旧的环境变量；保存配置不会重写进程环境。
  • 托管程序恢复是有条件的，不会恢复当前数据上的旧聊天。更改的数据可以防止程序安全回滚；其他安装业主保留其维修路线。
  • 此版本未启用应用程序内自动安装。 发布包不会启用发布批准证明、更改更新订阅或激活公共预览源。
  • 在速度较慢的设备上，大型或不断增长的图表以及非常大的差异仍然可能导致响应速度较低。内存变化并不是一般的延迟保证；丢失的历史图表快照不会从当前文件重建。

打包和验证

平台轮子包括内置的 WebUI 和匹配的原生 TUI。在 macOS arm64/x64、Linux arm64/x64 和 Windows x64 上通过本机安装、终端和更新/恢复检查。原始公共 0.3.5 和 0.4.0 升级路径另外在 macOS 上使用一次性数据进行了测试；这并不能保证适用于所有环境。
