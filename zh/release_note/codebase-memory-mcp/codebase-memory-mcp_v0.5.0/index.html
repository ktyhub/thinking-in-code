codebase-memory-mcp v0.5.0

完成 Go to C 重写

v0.5.0 是第一个完全由 C 构建的版本。整个代码库——管道、存储、MCP 服务器、CLI、观察器——已从 Go 重写为 C，通过 CGo 编译的树守护者语法被所有 64 种语言的供应商 C 源代码取代。

这可以实现什么

  • RAM优先管道：所有索引都在内存中运行（LZ4 HC压缩读取、内存中SQLite、最后单个转储）。批量加载和最终写入之间的磁盘 I/O 为零。
  • 融合的 Aho-Corasick 多模式匹配：调用解析使用一次 AST 传递，同时加载所有模式，取代顺序的每个函数 grep。
  • C/C++ 混合 LSP 解析器：模板替换、智能指针链、重载评分、lambda/decltype 推理、虚拟调度 - 700 多个专用测试。
  • mimalloc 全局分配器：跟踪所有分配（通过全局覆盖的 C + C++），实现每个工作线程的精确内存预算。
  • 没有 CGo 边界开销：所有树守护者解析都发生在纯 C 中——没有每个文件的 CGo 跳跃。

性能

索引 Linux 内核（28M LOC，75K 文件）：

  • 完整模式：210万个节点，5分33秒（Apple M3 Pro）
  • 快速模式：1.88M节点，1分12秒（Apple M3 Pro）

新功能：图形可视化 UI

v0.5.0 有两种型号：

  • 标准 — 仅 MCP 服务器（较小的二进制文件）
  • ui — MCP 服务器 + 嵌入式 3D 图形可视化 启用用户界面： ```bash 代码库内存-mcp —ui=true —port=9749 ``` 然后打开 http://localhost:9749 直观地探索您的知识图谱。 UI 作为本地主机上的后台线程运行，提供嵌入式前端资源并将查询代理到只读 SQLite 连接。

会话自动检测+自动索引

MCP 服务器现在会在会话启动时从工作目录中检测您的项目根目录。与配置存储结合： ```bash codebase-memory-mcp 配置设置 auto_index true ``` 启用后，新项目会在第一个 MCP 连接上自动索引，并且观察器会注册它们以进行持续的基于 git 的更改检测。无论此设置如何，先前索引的项目始终会向观察者注册。 配置 CLI 支持：`list`、`get `、`set `、`reset `。

代理行为改善

与 grep/glob/read 相比，代理现在**更喜欢 MCP 工具来进行代码发现：

  • 指令技能描述实现约 100% 自动激活（旧描述模式下约 37%）
  • PreToolUse / BeforeTool 挂钩 当代理使用内置搜索工具时打印咨询提醒
  • 关键字丰富的 MCP 工具描述 改进 Claude 的工具搜索发现
  • 说明文件，包含针对所有代理的具体示例和明确的后备指南
  • 启动更新检查 在第一次工具调用时通知是否有新版本可用 这些改进是由社区报告和贡献推动的：
