AutoMQ 1.7.3

修订 发布时间2026年8月18日 来源AutoMQ/automq 英文原文

AutoMQ 1.7.3

发生了什么变化

  • perf(zerozone)：通过@superhx在https://github.com/AutoMQ/automq/pull/3468中改进高吞吐量路由
  • perf(jvm)：通过https://github.com/AutoMQ/automq/pull/3471中的@superhx在JDK 21上启用分代ZGC
  • 修复：当https://github.com/AutoMQ/automq/pull/3474中的@superhx被重复节点屏蔽时，代理无法正常关闭 *修复（s3stream）：通过https://github.com/AutoMQ/automq/pull/3473中的@superhx改进V1流对象压缩收敛性
  • 修复（s3stream）：在https://github.com/AutoMQ/automq/pull/3481中通过@Gezi-lzq隔离快照读取选项 *修复（s3stream）：在https://github.com/AutoMQ/automq/pull/3484中延迟@Gezi-lzq的压力主要压缩
  • 壮举：@superhx 在 https://github.com/AutoMQ/automq/pull/3488 中挑选 3485 3487
  • 重构（s3stream）：删除https://github.com/AutoMQ/automq/pull/3489中@superhx的线程池状态日志记录 *修复（cli）：通过https://github.com/AutoMQ/automq/pull/3494中的@Gezi-lzq协商代理API版本以实现向后兼容性
  • 文档：由 @superhx 在 https://github.com/AutoMQ/automq/pull/3499 中定义 PR 描述约定
  • 修复(s3wal): 通过 https://github.com/AutoMQ/automq/pull/3508 中的 @Gezi-lzq 释放故障转移 WAL 资源 (#3504)
  • 修复（s3stream）：在 https://github.com/AutoMQ/automq/pull/3510 中通过 @superhx 解决小记录缓存开销
  • 修复（s3stream）：https://github.com/AutoMQ/automq/pull/3515 中 @superhx 在缓存退避时突发 WAL 上传
  • perf(s3stream): 在https://github.com/AutoMQ/automq/pull/3518中@superhx在缓存回退之前强制WAL上传
  • feat(docker)：在 https://github.com/AutoMQ/automq/pull/3521 中 @superhx 在 Bitnami 运行时映像中使用 Java 21
  • 壮举（发布）：通过 @Gezi-lzq 在 https://github.com/AutoMQ/automq/pull/3522 中发布 1.7.3

完整 Changelog：https://github.com/AutoMQ/automq/compare/1.7.2…1.7.3
