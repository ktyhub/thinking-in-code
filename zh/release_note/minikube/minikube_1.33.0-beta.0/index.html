Release Note

版本 1.33.0-beta.0 - 2024-03-26

特点：

  • 支持多控制平面 - HA 集群 --ha #17909
  • 插件gvisor: 添加arm64支持 #18063 #18453
  • 新插件：YAKD - Kubernetes 仪表板插件 #17775

小改进：

  • 插件自动暂停：消除内存泄漏并添加可配置间隔 #17936
  • 镜像构建：将 docker.io/library 添加到镜像短名称中 #16214
  • cp: 如果不存在则创建目录 #17715
  • 将获取日志的错误移至日志输出本身 #18007
  • 添加默认 sysctls 以允许没有功能的特权端口 #18421
  • 在预加载 tarball 中包含扩展属性 #17829
  • 将 kubeadm.applyNodeLabels 标签应用于所有节点 #16416
  • 将驱动程序状态检查限制为 20 秒 #17553
  • 如果 systemd 服务无法启动，则包含 journalctl 日志 #17659
  • ISO: 添加 CONFIG_DM_MULTIPATH #18277
  • ISO: 为arm64添加CONFIG_QFMT_V2 #17991
  • ISO: 为arm64添加CONFIG_CEPH_FS #18213
  • ISO: 为arm64添加CONFIG_BPF #17206

错误：

  • 修复“无法启用容器运行时：sudo systemctl restart cri-docker”#17907
  • 修复 containerd 在启动时重新下载现有镜像的问题 #17671
  • 修复 kvm2 未检测到 containerd 预加载的问题 #17658
  • 修复修改 Docker binfmt 配置 #17830
  • 修复自动暂停插件 #17866
  • 修复不使用 overlayfs 存储驱动程序预加载的问题 #18333
  • 修复图像存储库不允许带有数字的子域 #17496
  • 修复将 kvm2 与 containerd 一起使用时停止集群的问题 #17967
  • 修复在 kvm2 arm64 上启动多个集群的问题 #18241
  • 修复在arm64 Mac 上使用Linux 启动kvm2 集群的问题 #18239
  • 修复删除不存在的集群时显示错误的问题 #17713
  • 修复重启时不遵守无限制的问题 #17598
  • 修复未将 kubeadm.applyNodeLabels 标签应用于初始启动后添加的节点的问题 #16416
  • 修复日志分隔符输出 #17734

版本升级： *凹凸Kubernetes版本默认：v1.29.3和最新：v1.30.0-beta.0 #17786

  • 插件云扳手：将云扳手模拟器/模拟器映像从 1.5.11 更新为 1.5.15 #17595 #17847 #18165 #18431
  • 插件 gcp-auth：将 k8s-minikube/gcp-auth-webhook 映像从 v0.1.0 更新为 v0.1.2 #18222 #18384
  • 附加头灯：将头灯-k8s/头灯图像从 v0.20.1 更新为 v0.23.0 #17586 #17846 #18320
  • 插件入口：将入口-nginx/控制器映像从 v1.9.4 更新为 v1.10.0 #17848 #18166 #18284
  • 插件 inspektor-gadget：将 inspektor-gadget/inspektor-gadget 映像从 v0.22.0 更新为 v0.26.0 #17740 #17885 #18169 #18358
  • 插件 istio-provisioner：将 istio/operator 镜像从 1.19.3 更新为 1.21.0 #17651 #17777 #17957 #18168 #18429
  • Addon kong：将 kong 图像从 3.4.2 更新为 3.6.1 #17605 #18200 #18350
