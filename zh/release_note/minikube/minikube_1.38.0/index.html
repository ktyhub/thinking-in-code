Release Note

版本 1.38.0 - 2026-01-28

亮点

  • macOS 26+ 上的 vfkit/krunkit 不需要 Sudo（需要最新的 vmnet-helper）
  • 无需 Sudo 即可运行 使用 minikube 在 Macos GPU 上的 AI Playground
  • vfkit：添加 Rosetta 支持在 Apple 芯片上部署 amd64 映像 (#22140)

特点

  • 添加对 Kubernetes v1.35.0 的支持 (#21650)(#22015)(#22119)(#22328)
  • VM 驱动程序：添加对 NVMe-oF/TCP 块设备的支持 (#22464)
  • VM 驱动程序：启用 BTF 调试符号以支持 iso 中的 eBPF 工具 (#21800)
  • 添加选项以通过 —preload-source 从 github 而不是 GCS 下载预加载 (#22221)
  • Vfkit/Krunkit 驱动程序：添加在 macOS 26+ 上以非特权用户身份运行 vmnet-helper 的功能 (#22501)
  • 添加选项以添加基于 helm 的插件 (#21847)
  • 预加载：当 gcs 不可用时从 github 下载 (#21605)

警告和弃用

  • UI：在下一版本 (v1.39.0) 中添加有关将默认运行时更改为“containerd”的警告 (#22508)
  • hyperkit：删除驱动程序版本并警告用户切换（#21946）
  • 删除 minikube 对 32 位架构的支持 (#22401)

改进

  • UI：基于状态的彩色（配置文件列表、插件列表）（#22418）
  • 设置 —no-kubernetes 时跳过缓存二进制文件 (#21139)
  • 改进重试日志以打印更少的重复行 (#22232)
  • 改进 ssh 运行程序复制证书文件 (#21923)
  • vmnet：在仅下载模式下跳过验证 (#21635)
  • 改进 kubeconfig 中的 Windows 证书：将生成的证书路径标准化为正斜杠 (#21845)
  • 添加 cgroup v2 freeze 检查 API 服务器状态 (#22249)
  • 如果 cgroup v1，则为 kubenetes 1.35+ 设置 FailCgroupV1 kubelet 选项 (#22319)
  • containerd：重试图像加载的瞬态 EOF 错误 (#22310)
  • cri：增加 crictl 命令的默认 2 秒超时 (#22214)
  • crio：验证“image rm”后图像是否被删除（#22243）
  • docker 运行时：将 CRI 用于 ListImages 函数 (#22263)
  • 图像保存：为本地图像添加 EOF 重试逻辑 (#22072)
  • HA（多控制平面）：将 kube-vip 从 v1.0.0 更新为 v1.0.3 (#21699)(#21960)(#22258)

驱动程序

  • 驱动程序：引入 WaitForSSHAccess 并修复 macOS 冒烟测试 (#22179)
  • hyperkit 驱动程序：修复状态中的文件描述符泄漏 (#22524)
  • kvm：使用 SELinux 修复 Fedora/RHEL 上的 minikube (#21550)
  • kvm：删除对外部驱动程序的依赖（#21625）
  • 将旧版并行驱动程序标记为已弃用 (#22379)
  • 无驱动程序：修复 containerd 运行时的“停止”问题 (#22275)
  • 更新 minikube-machine 驱动程序 (#22369)
  • 验证辅助驱动程序安装是否正确，如果没有则正常退出 (#21576)
  • vfkit：添加 Rosetta 支持在 Apple 芯片上部署 amd64 映像 (#22140)
  • VM：通过使用 Kubernetes 的“systemd cgroup 驱动程序”启用 cgroup v2… (#22320)

错误修复

  • KIC 驱动程序：使用 crio 运行时修复 docker 驱动程序：安装 dbus (#21724)
  • 修复：正确检测 macOS 上的嵌套虚拟机并删除超时乘数 (#22277) *修复：增加containerd镜像列表的超时时间（#22558）
  • 修复：通过删除 curl 依赖项来修复 kubevirt 插件 (#22557)
  • 修复：状态不可用时返回非零退出代码 (#22494)
  • crio：通过启用 hostNetwork 和 ClusterFirstWithHostNet 修复入口 (#22239)
  • crio：修复预加载覆盖用户图像的问题 (#22246)
  • 通过添加 host.containers.internal 支持修复 macOS 上的 Podman 安装 (#22451)
  • 修复 cri-dockerd 版本升级脚本 (#22358)
  • 将 kubelet 配置选项 FailCgroupV1 修复为 failedCgroupV1 (#22325)
  • 插件registry-creds：修复没有配置文件的段错误(#21786)

用户界面

  • 通过 LANGUAGE=ku 添加对库尔德语的支持 (#22512)

  • 通过 LANGUAGE=uk 添加对乌克兰语的支持 (#21624)

  • 改进法语翻译 (#21559)(#21849)(#22155)(#22386)(#22515)(#22114)

  • 改进中文翻译 (#22082)

  • UI：改进代理的警告消息（#21980）

  • ui：修复隧道服务输出中的正确格式（#22400）

  • 对齐命令参数以修复 AI Playground (#21583)

CNI

  • CNI：将 calico 从 v3.30.3 更新为 v3.31.3 (#21835)(#21961)(#22259)
  • CNI：将 cilium 从 v1.18.1 更新为 v1.18.6 (#21655)(#21794)(#21953)(#22253)(#22487)
  • CNI：将法兰绒从 v0.27.3 更新为 v0.27.4 (#21700)
  • CNI：将 kindnetd 从 v20250512-df8de77b 更新到 v20251212-v0.29.0-alpha-105-g20ccfc88 (#22127)

插件

  • 插件 cloud-spanner：将 cloud-spanner-emulator/模拟器镜像从 1.5.41 更新为 1.5.47 (#21709)(#21832)(#21956)(#22255)(#22489)
  • 附加头灯：将头灯图像从 v0.35.0 更新为 v0.36.0 (#21706)(#21958)(#22256)
  • 插件入口：将入口-nginx/控制器映像从 v1.13.2 更新为 v1.13.3 (#21701)(#21865)(#22049)
  • 插件检查器小工具：将检查器小工具图像从 v0.44.1 更新为 v0.45.0 (#21708)(#22427)(#21843)(#22047)
  • Addon kong: 更新 kong 镜像 3.9.1(#21698)(#21830)(#21952)(#22486)
  • Addon kong：将 kong/kubernetes-ingress-controller 镜像从 3.5.1 更新为 3.5.3 (#21657)(#22000)
  • 插件 nvidia-device-plugin：将 nvidia/k8s-device-plugin 映像从 v0.17.3 更新为 v0.18.1 (#21652)(#21796)(#22126)
  • 附加 portainer：将 portainer 从 2.15.1 更新为 2.27.7 (#20956)
  • 插件注册表：从 3.0.0 更新注册表映像 (#21735)
  • Addon Volcano：将火山图像从 v1.12.2 更新为 v1.13.1 (#21656)(#22344)
  • 插件 yakd：将镜像注册表从 Docker Hub 迁移到 GHCR (#22250)
  • 插件 yakd：将 manusa/yakd 镜像从 0.0.5 更新为 0.0.7 (#22343)(#22128)
  • 插件：自动暂停修复 github 链接 (#22433)
  • 插件：凹凸 kube-regsitry-proxy 镜像 (#22551)
  • 插件：修复registry-proxy alpine-slim 以使用 wget (#22550)
  • inspektor-gadget 插件：删除已删除的资源 (#21855)

基础镜像版本

  • iso: 升级到containerd/nerdctl 2.x (#21409)
  • ISO：更新docker-bu
