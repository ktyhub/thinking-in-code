Release Note

版本 1.37.0 - 2025-09-09

突出显示

使用新的 krunkit driver 在 Kubernetes 中的 Macbook GPU 上运行 AI 工作负载。开始使用我们的AI Playground 教程

特点

  • 添加对 Kubernetes v1.34.0 的支持 (#21439)
  • 添加支持 macOS 上 GPU 加速的 krunkit 驱动程序 (#20826) 教程
  • 为 —memory 添加简写 -m (#20854)
  • 添加对 docker 运行时的支持，以实现对 NVIDIA GPU 的 OCI 访问 (#20959)
  • 添加 --disable-coredns-log 标志以抑制 coredns 日志 (#20992)
  • 新插件：kubetail (#20345)
  • 驱动程序：添加对 vfkit 和 krunkit 的 Virtiofs 安装的支持 (#21149)

改进

  • 改进 ipv4 和 windows v0.0.4 的 ingress-dns 插件 (#21449)
  • iso：禁用 grub 超时，将 vm 启动速度加快 5 秒 (#20895)
  • 提高 docker 服务可靠性，更新 docker systemd 文件 (#21174)
  • 不需要同时使用 —mount 来使用 —mount-string 并删除默认的安装字符串 (#21250)
  • 更新最旧支持的 Kubernetes 版本 (#21490)
  • 许可证 cmd：如果输出目录不存在，则不会失败并首先从 github 资产下载 (#21206)
  • 删除已弃用的 proxy-refresh-interval v2 etcd 标志 (#21278)
  • vmnet：支持 krunkit 卸载 (#20831)
  • 不要为非 kic 驱动程序调用 startKicServiceTunnel (#20863)
  • krunkit：禁用卸载以加快网络速度 (#21341)
  • HA（多控制平面）：将 kube-vip 从 v0.9.1 更新为 v1.0.0 (#20999)(#21228)

折旧

  • 弃用 HyperKit 驱动程序并发出警告 (#21024)

错误修复

  • 修复脏提交版本 (#21062)
  • 修复 Windows 上的 minikube 图像加载 (#20529) (#20921)
  • 修复安装到同一文件夹导致输入/输出错误的问题 (#21077)
  • 修复：影响插件的 YAML 文件转义错误问题 (#20904)
  • iso：使用 vfkit 和 krunkit 驱动程序修复 minikube stop (#21089)
  • iso：修复 vfkit/krunkit 的控制台 (#20832)

插件

  • 插件 nvidia-device-plugin：将 nvidia/k8s-device-plugin 映像从 v0.17.2 更新为 v0.17.3 (#21225)
  • 插件 cloud-spanner：将 cloud-spanner-emulator/emulator 镜像从 1.5.34 更新为 1.5.41 (#20976)(#21040)(#21243)(#21287)(#21359)(#21512)
  • 附加头灯：将头灯图像从 v0.28.0 更新为 v0.34.0 (#21238)(#21508)
  • 插件入口：将入口-nginx/控制器镜像从 v1.12.2 更新为 v1.13.2 (#20909)(#21232)(#21353)(#21458)
  • 插件检查器小工具：将检查器小工具图像从 v0.40.0 更新为 v0.44.1 (#20873)(#21038)(#21240)(#21462)(#21510)(#21358)
  • Addon kong：将 kong 镜像从 3.9.0 更新为 3.9.1 (#20966)(#21503)
  • Addon kong：将 kong/kubernetes-ingress-controller 镜像从 3.4.5 更新为 3.5.1 (#20908)(#20969)(#21034)(#21282)
  • 插件 kubevirt：将 bitnami/kubectl 镜像从 1.33.1 更新为 1.33.4 (#20911)(#20939)(#21235)(#21283)(#21414)
  • 插件指标服务器：将指标服务器/指标服务器映像从 v0.7.2 更新为 v0.8.0 (#21033)
  • 插件注册表：将注册表映像从 3.0.0 更新为 3.0.0 (#21242)
  • Addon Volcano：将火山图像从 v1.11.2 更新为 v1.12.2 (#20868)(#21351)
  • 插件 kubetail：更新版本 0.13.3 (#21244)

CNI 版本

  • CNI：将 calico 从 v3.30.0 更新为 v3.30.3 (#20871)(#20971)(#21416)
  • CNI：将 cilium 从 v1.17.4 更新为 v1.18.1 (#20968)(#21226)(#21349)
  • CNI：将法兰绒从 v0.26.7 更新为 v0.27.0 (#20907)(#21230)(#21504)

基础镜像版本

  • iso：将长期内核更新为 6.6.95 (#20995)
  • iso：为 x86_64 和 aarch64 启用 VirtioFS (#21147)
  • iso：改进构建和清理配置（#20991）
  • Kicbase/ISO：将 cni 插件从 v1.7.1 更新为 v1.8.0 (#21517)
  • Kicbase/ISO：将 crun 从 1.19 更新为 1.23.1 (#21198)(#21330)
  • Kicbase/ISO：将 docker 从 28.0.4 更新为 28.4.0 (#21053)(#21248)(#21488)
  • Kicbase：将 ubuntu:jammy 从 20250415.1 更改为 20250819 (#21233)(#21413)(#21505)

用户界面

  • 重做“minikube 配置文件列表”，将详细信息移至 —det… (#20544)
  • 改进配置标志详细描述 (#21515)
  • 重构旋转器库并隐藏旋转后的子步骤 (#21215)
  • 如果 kubeadm init 失败，则不会显示“create github issues”两次 (#21263)
  • 重构表格渲染 (#20893)

用户界面/翻译

  • 添加伟大的翻译
  • 添加更多韩语翻译 (#21467)(#21465)
  • 添加更多法语翻译 (#21050)(#20862)(#20945)(#20964)(#21156)(#21372)(#21514)
