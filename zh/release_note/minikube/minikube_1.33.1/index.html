Release Note

版本 1.33.1 - 2024-05-13

错误：

  • 修复 DNSSEC validation failed 错误 #18830
  • 修复 too many open files 错误 #18832
  • CNI cilium：修复 cilium pod 无法启动的问题 #18846
  • 插件入口：修复使用 VM 驱动程序在 arm64 机器上启用失败的问题 #18779
  • Addon kubeflow：修复一些组件缺少arm64镜像的问题 #18765

版本升级：

  • 插件 cloud-spanner：将 cloud-spanner-emulator/模拟器镜像从 1.5.15 更新为 1.5.17 #18773 #18811
  • 附加头灯：将头灯-k8s/头灯图像从 v0.23.1 更新为 v0.23.2 #18793
  • 插件入口：将入口-nginx/控制器映像从 v1.10.0 更新为 v1.10.1 #18756
  • 插件 istio-provisioner：将 istio/operator 镜像从 1.21.1 更新为 1.21.2 #18757
  • 插件 kubevirt：将 bitnami/kubectl 映像从 1.29.3 更新为 1.30.0 #18711 #18771
  • 插件 nvidia-device-plugin：将 nvidia/k8s-device-plugin 映像从 v0.14.5 更新为 v0.15.0 #18703
  • CNI cilium：从 v1.15.1 更新到 v1.15.3 #18846
  • 高可用性：将 kube-vip 从 0.7.1 更新为 v0.8.0 #18774
  • Kicbase/ISO：将 docker 从 26.0.1 更新为 26.0.2 #18706
  • Kicbase：将 ubuntu:jammy 从 20240227 更改为 20240427 #18702 #18769 #18804

更详细的changelog，请参见CHANGELOG.md。
