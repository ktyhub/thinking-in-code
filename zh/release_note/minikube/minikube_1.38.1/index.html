Release Note

版本 1.38.1 - 2026-02-19

特点

  • 添加对 Kubernetes 版本 v1.35.1 的支持 (#22665)

错误修复

  • 通过将 UID 附加到锁目录来修复锁文件回归 (#22623)
  • 通过屏蔽 systemd-binfmt 修复回归跨架构执行（#22621）
  • 修复：Windows 上的 PowerShell curl 别名用于检查 resgistry.k8s.io 连接性 (#22659)

插件

  • 插件 cloud-spanner：将 cloud-spanner-emulator/模拟器镜像从 1.5.47 更新为 1.5.49 (#22637)
  • 附加头灯：将头灯图像从 v0.39.0 更新为 v0.40.0 (#22640)
  • 插件入口：将入口-nginx/控制器映像从 v1.14.1 更新为 v1.14.2 (#22595)
  • 插件入口：将入口-nginx/控制器映像从 v1.14.2 更新为 v1.14.3 (#22638)
  • 插件检查器小工具：将检查器小工具图像从 v0.48.0 更新为 v0.48.1 (#22592)
  • 插件检查器小工具：将检查器小工具映像从 v0.48.1 更新为 v0.49.1 (#22634)
  • 插件指标服务器：将指标服务器/指标服务器映像从 v0.8.0 更新为 v0.8.1 (#22596)
  • 插件 nvidia-device-plugin：将 nvidia/k8s-device-plugin 映像从 v0.18.1 更新为 v0.18.2 (#22531)
  • 插件注册表：将注册表映像从 3.0.0 更新为 3.0.0 (#22593)
  • Addon Volcano：将火山图像从 v1.13.1 更新为 v1.14.0 (#22597)
  • Addon Volcano：将火山图像从 v1.14.0 更新为 v1.14.1 (#22663)
  • 插件 yakd：将 manusa/yakd 镜像从 0.0.7 更新为 0.0.8 (#22639)
  • HA（多控制平面）：将 kube-vip 从 v1.0.3 更新为 v1.0.4 (#22598)

CNI

  • CNI：将 cilium 从 v1.18.6 更新为 v1.19.0 (#22636)
  • CNI：将法兰绒从 v0.27.4 更新为 v0.28.1 (#22635)
  • CNI：将 kindnetd 从 v20251212-v0.29.0-alpha-105-g20ccfc88 更新到 v20260131-0806d083 (#22594)
  • CNI：将 kindnetd 从 v20260131-0806d083 更新到 v20260213-ea8e5717 (#22661) 有关更详细的 changelog，包括预发行版本中发生的更改，请参阅 CHANGELOG.md。
