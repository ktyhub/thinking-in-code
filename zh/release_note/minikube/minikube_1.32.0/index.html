Release Notes

版本 1.32.0 - 2023-11-08

特点：

  • NVIDIA GPU 支持 docker 驱动程序的新 --gpus=nvidia 标志 #15927 #17314 #17488
  • 无根：支持--container-runtime=docker #17520
  • 新的 kubeflow 插件 #17114
  • 新的 local-path-provisioner 插件 #15062
  • Kicbase：将 no-limit 选项添加到 --cpus 和 --memory 标志 #17491

小改进：

  • Hyper-V：添加奇数的内存验证 #17325
  • QEMU：改进 cpu 类型和 IP 检测 #17217
  • 从启动输出中屏蔽 http(s)_proxy 密码 #17116
  • --delete-on-faliure 还会针对 kubeadm 故障重新创建集群 #16890
  • 插件自动暂停：使用 --auto-pause-interval 配置间隔 #17070
  • --kubernetes-version 检查 GitHub 的版本验证并改进无效版本的错误输出 #16865
  • 在镜像构建过程中安装 NVIDIA 容器工具包（离线支持）#17516

错误：

  • QEMU：修复插件无法启用的问题 #17402
  • 修复 minikube 发布后为 k8s 版本下载错误的 kubeadm 镜像 #17373
  • 修复启用和禁用不存在集群的插件 #17324
  • 修复容器运行时不存在时的删除问题 #17347
  • 修复在新的 Docker 版本上未检测到网络未找到的问题 #17323
  • 修复插件注册表不遵循 Minikube DNS 域名配置 (—dns-domain) #15585
  • 修复配置验证的无限制选项 #17530
