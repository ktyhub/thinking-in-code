Release Note

版本 1.35.0 - 2025-01-15

特点：

  • 通过 —gpus=amd 添加对 AMD GPU 的支持 #19749
  • 使用 Github 资产作为 kic 基础映像的新故障转移 #19464
  • 支持最新的Kubernetes v1.32.0 #20091
  • 添加对 kubeadm.k8s.io/v1beta4 的支持（自 k8s v1.31 起可用）#19790

改进：

  • 合并 nvidia-gpu-device-plugin 和 nvidia-device-plugin。 #19545
  • kicbase：更新 nvidia 软件包 #19738
  • cilium: 删除 k8s<v1.30.0 #19888 的 appArmorProfile
  • 自动暂停：配置后重新启动服务 #19900
  • 恢复“更改 MINIKUBE_HOME 逻辑”#20045
  • 如果退出代码不存在，则不会污染 minikube 配置文件列表 #19728
  • 统一minikube集群状态查询 #18998
  • Vfkit 驱动程序：修复 TestMachineType 在 macOS 上失败的问题 #19726
  • nerdctld 不再有拱形限制 #19730
  • 更强大的 MAC 地址匹配 #19750
  • 添加解决 docker 上下文错误的说明 #19197

错误修复：

  • 修复 —wait 在 coredns pod 上无法工作的问题 #19748
  • 修复命名空间中没有使用 —all 指定的服务时出现的恐慌 #19957
  • 修复使用 CRI-O 容器运行时停止 KVM 机器时的超时问题 #19758
  • 修复了 lastStart.txt 中的长行未在日志输出中输出的问题 #19740
  • 修复错误检测 kicbase arch 的问题 #19664

重大变化：

  • 删除arm64 kvm #19985 #20062
  • 删除 helm-tiller 插件 #19636

语言：

  • 添加更多中文翻译 #19490 #19508 #19718 #19962 #19772
  • 改进法语翻译 #19654 #19978

版本更新：

  • CNI：将法兰绒从 v0.25.6 更新为 v0.26.2 #19761 #20107
  • CNI：将 cilium 从 v1.16.1 更新为 v1.16.5 #19734 #20148 #19823
  • CNI：将 calico 更新为 v3.29.1 #19884 #20052 #19667
  • CNI：将 kindnetd 更新至 v20241023-a345ebe4 #19865 #19780 #20051
  • 将 golang 更新为 1.23.3 #20065 #19868 #19756
  • 插件 istio-provisioner：将 istio/operator 镜像从 1.23.0 更新为 1.23.3 #19678 #19629 #19876
  • 插件 cloud-spanner：将 cloud-spanner-emulator/模拟器镜像从 1.5.23 更新为 1.5.24 #19679
  • 插件 gcp-auth：将 k8s-minikube/gcp-auth-webhook 映像从 v0.1.2 更新为 v0.1.3 #19787
  • 插件入口：将入口-nginx/控制器映像从 v1.11.2 更新为 v1.12.0-beta.0 #19781 #19824
  • 插件注册表：将 kube-registry-proxy 映像从 0.0.7 更新为 0.0.8 #19782
  • 插件 gvisor：将 gvisor-addon 映像从 v0.0.1 更新为 v0.0.2 #19776
  • 插件检查器小工具：将检查器小工具图像从 v0.33.0 更新为 v0.36.0 #20205 #20033
  • 插件注册表：将注册表映像从 2.8.3 更新为 2.8.3 #20035
  • 插件 kubevirt：将 bitnami/kubectl 镜像从 1.31.1 更新为 1.31.3 #19763 #20028 #20068 #19937
