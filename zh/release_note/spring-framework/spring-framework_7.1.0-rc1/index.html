小版本 发布时间2026年10月22日 来源spring-projects/spring-framework 英文原文

spring-framework v7.1.0-RC1

：警告：需要注意

  • 删除在 7.1 中标记为已弃用的 API #37455
  • 始终将 0 视为 WebTestClient 中没有超时 #37454
  • 在 MockMvc 中始终将 0 视为无超时 #37453
  • 始终将 0 视为 RSocketServiceProxyFactory 中没有超时 #37451
  • 在 HTTP client 支持中始终将 0 视为无超时 #37425
  • 更新 WebFlux 多部分处理中的默认设置以与 Spring Boot 和 Tomcat 保持一致 #36928
  • 将具有系统属性的代理应用于 ReactorClientHttpConnector 中的默认 client #36654
  • ProblemDetail 实例字段从当前 URL 路径设置，不尊重 RFC #35969

:star: 新功能

  • 支持 JsonUnit 作为 JSONassert 的替代品，用于测试 API 中的 JSON 比较 #37490
  • 为 onRetrySuccess 和 onRetryFailure 添加 RetryState 感知重载 #37465
  • 在 AsyncServerResponse 中始终将 0 视为无超时 #37452
  • 尽管失败，但销毁 CompositeFilter 中的所有过滤器 #37445
  • 优化 DataAccessUtils 以提高零安全性 #37438
  • 在 DefaultRetryPolicy.toString() 中省略零 timeout #37437
  • 避免在 StringUtils.truncate() 中分割代理对 #37435
  • 支持 NumberUtils 中的正十六进制值 #37434
  • 支持在 SpEL 中编译字符串与非字符串操作数 #37433
  • 修复 LinkedCaseInsensitiveMap 中的可为空性 #37432
  • 将 JdkClientHttpRequest 中的 jdk.httpclient.allowRestrictedHeaders 解析与 JDK 对齐 #37422
  • 将反应式 JdkClientHttpRequest 中的受限标头处理与非反应式 JdkClientHttpRequest 对齐 #37417
  • 通过 WebMvcConfigurer 配置问题详细信息渲染 #37416
  • 修复 MergedAnnotationCollectors 中缺失的 IDENTITY_FINISH 特性 #37415
  • 当 @AliasFor、value 和 attribute 都有长度时，拒绝它们 #37413
  • 授予 ErrorResponse.Interceptor 访问当前请求的权限 #37410
  • 在 CompositeMap 中履行 Map.equals() 和 Map.hashCode() 合同 #37401
  • 支持将问题详细信息渲染为 @ExceptionHandler 方法中的视图 #37400
  • 将 ExceptionHandler 方法未处理的异常渲染为问题详细信息 #37398
  • 进一步改进AnnotationAttributes.toString() #37396
  • 改进 AnnotationAttributes.toString() 中的原始数组处理 #37395
  • 从 AnnotatedMethod 中的覆盖检查中排除静态方法 #37390
  • 包括 MySQLMaxValueIncrementer 未能提交时的根本原因 #37389
  • 将导致 HTTP 5xx 的 MVC 异常记录为可观测性堆栈中的错误 #37384
  • 修改 getBeanNamesForType 缓存以覆盖基于 ResolvableType 的查找 #37382
  • 支持 Hibernate 8.0 的 BeanContainer SPI 修订版 #37381
  • 改进预绑定的 JDBC 连接异常消息 #37356
  • 拒绝增强型 @Configuration 类中的 Kotlin 构造函数默认值 #37350
  • 重写 CssLinkResourceTransformer 以实现单遍内存高效解析 #37348
  • 弃用 JdbcTemplate 中的多批次 batchUpdate 变体 #37345
  • 为 JdbcClient 批量更新引入基于入门的 DSL #37341
  • 在 CompositeCollection 中兑现 Collection.remove() 合同 #37332
  • 从 AnnotationsScanner 中的覆盖检查中排除静态方法 #37319
  • 支持
