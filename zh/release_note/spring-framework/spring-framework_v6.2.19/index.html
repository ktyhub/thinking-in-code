：警告：安全修复

此维护版本修复了大量 CVE。您可以在 “AI 时代的 Spring 和安全” 博客文章中了解更多相关信息。以下是 16 个 CVE 的完整列表：

  • CVE-2026-41838“WebSocket 模块中的 Spring Framework 可预测会话 ID”
  • CVE-2026-41839“通过 WebFlux 中的会话固定进行 Spring Framework 升级”
  • CVE-2026-41840“Spring Framework 通过 WebFlux 中的多部分请求拒绝服务”
  • CVE-2026-41841“通过 Spring MVC 和 WebFlux 中的静态资源缓存泄露 Spring Framework 信息”
  • CVE-2026-41842“Spring Framework 通过 Spring MVC 和 WebFlux 中的版本化资源拒绝服务”
  • CVE-2026-41843“通过 Spring MVC 和 WebFlux 中的版本化静态资源进行 Spring Framework 路径遍历”
  • CVE-2026-41844“Spring MVC 和 WebFlux 中的 Spring Framework 打开重定向”
  • CVE-2026-41845“通过 JavaScriptUtils 执行 Spring Framework 跨站点脚本”
  • CVE-2026-41846“通过 JSP 表单标签进行 Spring Framework 跨站点脚本”
  • CVE-2026-41848“Spring Framework 通过 AntPathMatcher 拒绝服务”
  • CVE-2026-41850“通过 SpEL 表达式的 Spring Framework 算法拒绝服务”
  • CVE-2026-41851“Spring Framework 通过 SpEL 中的无界缓存拒绝服务”
  • CVE-2026-41852“SpEL 表达式中的 Spring Framework 任意方法调用”
  • CVE-2026-41853“Spring MVC 和 WebFlux 中的 Spring Framework 多部分请求走私”
  • CVE-2026-41854“通过 UriComponentsBuilder 伪造 Spring Framework 服务器端请求”
  • CVE-2026-41855“通过 Jackson JMS 转换器进行 Spring Framework 不安全反序列化”
