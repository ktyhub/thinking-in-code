spring-framework v7.0.10

修订 发布时间2026年10月22日 来源spring-projects/spring-framework 英文原文

spring-framework v7.0.10

:star: 新功能

  • 将 DelegatingMessageSource 后备实现与 AbstractMessageSource 对齐 #37383
  • HttpEntity(T, MultiValueMap) 存储未选中的 HttpHeaders，导致 IncompatibleClassChangeError 位于 RestTemplate 内 #37358
  • 识别 ProxyProcessorSupport 中重新定位的 Mockito MockAccess 接口 #37342
  • 与 JPA 4.0 M7 和相应的 Hibernate 8.0 快照的运行时兼容性 #37315
  • 避免在 MethodParameter 中对非挂起函数进行 Kotlin 反射 #37300
  • 修改 SimplePropertyRowMapper 中的下划线命名回退 #37297
  • 避免 ConcurrentLruCache.clear() 中无用的队列操作 #37292
  • PathMatchingResourcePatternResolver 错过了 java.class.path 上路径包含 % 的 jar #37280
  • 删除异常消息中的冗余空格 #37277
  • OpenInView 不再与 HibernateTransactionManager 一起使用 #37273
  • 在 LazyConnectionDataSourceProxy 中延迟处理 setClientInfo/setNetworkTimeout #37261
  • 避免 FilteredMap.size() 中的冗余过滤 #37256
  • 支持 toString() 中的 NaN 和无限浮点值用于合成注释 #37244
  • 在 CompositeRetryListener 中使用 ArrayList 代替 LinkedList #37231
  • MockMvcResultMatchers 中的 redirectedUrl() 参数应该是 @Nullable #37230
  • 已发布的 Gradle 模块文件缺少 javadocElements 和 sourcesElements #37209
  • 引入 SpelParserConfiguration 的构建器 #37187
  • Protobuf 支持类全部实现 getMessageBuilder() #37147
  • 在 ServerHttpRequest.Builder 中允许 null contextPath #37099
  • 将代理可用性事件记录为字符串消息 #36856

:lady_beetle: 错误修复

  • 避免按类型自动装配不必要的依赖 bean 注册 #37424
  • 在 JdkClientHttpConnector 中处理零 readTimeout #37412
  • PartGenerator.CreateFileState 中的竞争条件可能会丢失完成信号 #37409
  • 延迟关闭的暂停执行器在关闭后泄漏其工作线程（和关闭的上下文）#37406
  • 修复带有缓存的 Flux 返回方法的挂起重试 #37403
  • 避免在 AbstractIdentityColumnMaxValueIncrementer 中重新填充失败后提供过时的值 #37402
  • 在 RenderingResponse.from() 中复制 cookie #37378
  • 避免 LinkedCaseInsensitiveMap.computeIfAbsent 中的幻像按键 #37351
  • 修复 TypeMappedAnnotation 中原始数组类型的单值适配 #37349
  • CssLinkResourceTransformer 因无效 CSS 链接而失败 #37336
  • 修复 MySQLMaxValueIncrementer 中提交失败后缓存的 ID 重用问题 #37322
  • 修复 MySQLMaxValueIncrementer 中的连接泄漏 #37321
  • @CacheEvict 将 Flux 结果截断为第一个元素 #37309
  • ConcurrentLruCache.clear() 可能会错过运行时添加的条目 #37287
  • 将部分溢出到磁盘时强制执行磁盘使用限制 #37285
  • 防止 ConcurrentLruCache 中的双倍尺寸递减 #37268
  • 自 spring-core 7 从 spring-jcl 切换到 commons-logging 以来，LogAccessor.debug(CharSequence) 急切地呈现 LogMessage #37266
  • 当文件部分不是最后一个时，WebFlux 会丢失空的多部分文件。 #37264
  • 从 Mutiny 反应适配器完成空 Uni 实例 #37259
  • DefaultAsyncServerResponse.writeAsync() 放弃之前配置的 AsyncWebRequest 超时 #37257
  • 为代理的 hibernate 8 查询类型提供缺少的本机图像提示
