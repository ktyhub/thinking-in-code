spring-framework v7.1.0-RC2

小版本 发布时间2026年11月5日 来源spring-projects/spring-framework 英文原文

spring-framework v7.1.0-RC2

:star: 新功能

  • 完善 PropertyPath 支持 #37642
  • 弃用 AutoPopulatingList 进行删除 #37639
  • 复制 HttpServiceProxyFactory 中的构建器列表 #37601
  • 对齐 ExceptionTypeFilter 构造函数中的泛型 #37598
  • 复制 RetryPolicy.Builder 中的包含和排除内容 #37596
  • 拒绝表达式中以空格分隔的配置文件名称 #37595
  • 拒绝缺少运算符或操作数的配置文件表达式 #37593
  • 解析别名目标时检测别名圈 #37585
  • 停止将 PropertySource.toString() 输出基于日志级别 #37540
  • 使内存中的多部分内容可重复 #37531
  • 在 SqlParameterSourceUtils.createBatch() 中按原样使用 SqlParameterSource #37524
  • 在 StatementSpec.paramSource(Object) 中使用 toSqlParameterSource #37501
  • 通过 ResultSetMetaData 而不是 findColumn 异常解决 DataClassRowMapper 列 #37329
  • 深度复制 client 构建器中的默认标头、cookie #37325
  • 尊重资源范围请求的 If-Range #37218
  • 验证 require 中的命名空间和本地名称 #36915

:lady_beetle: 错误修复

  • 尊重 ignoreUnknownFields 中 DataBinder 中的无效属性路径 #37641
  • 配置文件表达式中的双重否定解析不正确 #37594
  • 检测 NumberUtils 中浮点数的溢出 #37586
  • 将 JSON 行添加到 ProtobufJsonEncoder 媒体类型 #37559
  • MIME 类型参数前需要分号 #37545
  • 当 PartGenerator 中超出磁盘限制时，避免泄漏临时文件 #37534

:notebook_with_decorative_cover: 文档

  • 改进 FieldError 构造函数 Javadoc #37533
  • 记录 LocaleContextHolder 可继承行为 #36853

:hammer: 依赖升级

  • 升级到 AspectJ 1.9.27 以支持 Java 27 #37572
  • 升级至千分尺 1.18.0-RC2 #37633
