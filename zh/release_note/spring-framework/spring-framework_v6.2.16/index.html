spring-framework v6.2.16

:star: 新功能

  • 提高请求映射的哈希码计算性能 #36297
  • 提高 HandlerMethod bean 查找的性能 #36296
  • 提高验证组确定的性能 #36295
  • 提高单一模式请求映射的性能 #36294
  • 通过延迟获取 SqlParameter 来优化 NamedParameterUtils#buildValueArray #36232
  • 通过 FileCopyUtils 中的 try-with-resources 始终关闭流 #36224
  • SqlBinaryValue 和 SqlCharacterValue 应支持长度未定的 InputStream 内容 #36220
  • JDK 25 上的 DataBufferUtils.write() 和 NettyDataBuffer 无限期挂起 #36189
  • 连接释放后，Netty 通道上的 WebClient (Reactor) 属性不会清除 #36163
  • 在 Spring Framework 6.2.x 中重新引入 WebLogicJtaTransactionManager #36152
  • DisconnectedClientHelper 应分别检测 RestClientException 和 WebClientException 的存在 #36150
  • 将 DataAccessException 和 MessagingException 添加到 DisconnectedClientHelper 中排除的最外层异常中 #36135
  • 改进 TransportHandlingSockJsService 中的用户检查 #36129

:lady_beetle: 错误修复

  • 避免 ConcurrentReferenceHashMap 中的锁拥塞 #36308
  • 已解决的 HttpEntity Controller 参数不反映变异的 HTTP 标头 #36301
  • AbstractMessageConverter 不支持支持的 MIME 类型中的通配符 #36286
  • 使 LocalEntityManagerFactoryBean#setDataSource 在 Hibernate 以及 EclipseLink 上工作 #36272
  • 在启动时调用 System.exit 时可能会发生死锁（针对多个关闭挂钩）#36268
  • 对于不存在的键，Netty4HeadersAdapter.remove 返回空列表而不是 null #36227
  • EclipseLinkConnectionHandle 可能会因事务隔离竞争条件而失败 #36166
  • 当响应主体未消耗时，WiretapConnector 会泄漏数据缓冲区 #36051
  • 当 UriComponentsBuilder 仅包含单个字符时，它会丢失片段 #36035
  • SimpleBeanInfoFactory 无法可靠地解析具有未解析泛型的类型层次结构中的读/写方法 #36026

:notebook_with_decorative_cover: 文档

  • 修复 JUnit 用户指南的链接 #36218
  • 修复 LocalContainerEntityManagerFactoryBean#setPersistenceUnitName javadoc #36206
  • 更新有关尾部斜杠处理的文档，其中类型级别 @GetMapping(“/base”) 与方法级别 @GetMapping(”/”) 组合#36200
  • 更新用于 ProblemDetail 的 MediaType 的文档 #36193
  • 将示例中的 getErrors() 替换为 getBindingResult() #36172
  • 升级 Antora 依赖项 #36106
  • 修复拼写错误和语法 #36023

:hammer: 依赖升级

  • 将 /framework-docs 中的 fast-xml-parser 从 4.5.2 提升到 5.3.4 #36239
  • 升级到 ASM 9.9.1 和 Objenesis 3.5 #36244
  • 升级到 JUnit 5.14.2 #36148
  • 升级到千分尺1.15.9 #36290
  • 升级到反应堆 2024.0.15 #36289
