spring-framework v6.2.18

修订 发布时间2026年4月17日 来源spring-projects/spring-framework 英文原文

spring-framework v6.2.18

:star: 新功能

  • 改进 SpringValidatorAdapter 和 MethodValidationAdapter 性能 #36624
  • 添加缺失的 @Deprecated(forRemoval = true) 以在 7.0 中删除 #36591
  • 弃用 CacheAspectSupport 中的 methodIdentification() 以进行删除 #36576
  • 改进多部分编解码器中的错误处理 #36564
  • LazyConnectionDataSourceProxy 不能很好地与 Hibernate 的多租户架构策略配合使用 #36529
  • MySQL 错误 149（Galera/WSREP 冲突）未转换为 Spring JDBC/ORM 中的 ConcurrencyFailureException #36510

:lady_beetle: 错误修复

  • 在 CoroutineUtils 中正确处理 Kotlin 可为空值类参数 #36643
  • 尝试设置 id 或事件属性时，ServerSentEvent 中出现 NullPointerException #36634
  • 如果 DataSource 包裹在 TransactionAwareDataSourceProxy 中，@Sql 会失败 #36630
  • 使用“!”时，WebDataBinder 不必要地实例化集合。和“_”前缀 #36627
  • MessageSourceSupport 中高基数 FieldError 默认消息的缓存污染 #36623
  • ContentCachingRequestWrapper 不允许无限的内容缓存 #36620
  • MergedAnnotation 不使用 ClassLoader 作为方法或字段 #36614
  • 当注释引用不存在的类时，AnnotationBeanNameGenerator 失败 #36588
  • FileSystemResource 不严格遵循 Resource#isReadable() 合约 #36585
  • 查询未隐藏在 DefaultClientResponse 检查点中 #36571
  • LazyConnectionDataSourceProxy 不会将可持有性传递给目标连接 #36530
  • DefaultJmsListenerContainer 可能会在 doShutdown 中无限循环地挂起 #36511
  • 资源解析器中的编码分辨率不一致 #36508

:notebook_with_decorative_cover: 文档

  • 澄清 HttpMethod.valueOf() 的语义 #36653
  • 记录 spring.profiles.active 被 @ActiveProfiles 忽略 #36636
  • SpEL 表达式中的文档空白语义 #36629
  • MergedAnnotation.asAnnotationAttributes() Javadoc 错误地指出它创建了一个不可变的映射 #36568
  • 引入 Bean 覆盖的 Kotlin 示例（@MockitoBean 等）#36542
  • 修复 AbstractEnvironment Javadoc 中不正确的交叉引用链接 #36517

:hammer: 依赖升级

  • 升级至千分尺 1.15.11 #36661
  • 升级到反应堆 2024.0.17 #36660
