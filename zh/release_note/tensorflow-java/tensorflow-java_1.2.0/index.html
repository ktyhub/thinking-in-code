tensorflow-java v1.2.0

小版本 发布时间2026年7月24日 来源tensorflow/java 英文原文

tensorflow-java v1.2.0

变化

此版本将本机组件升级到 TensorFlow 2.21，将 tensorflow-ndarray 合并回该项目，并对梯度系统添加了一些小修复。由于缺乏上游 TensorFlow 的可用构建，它放弃了对 Windows x86 的支持。

更新后的 TensorFlow-Java 文档现已在 tensorflow.github.io/java 上提供，该文档将与该项目一起维护。 tensorflow.org/jvm 和 tensorflow.org/api_docs/java/org/tensorflow/package-summary 的旧文档页面不再维护，但我们目前无法删除它们。
