预发布 发布时间2026年9月24日 来源spring-cloud/spring-cloud-kubernetes 英文原文

spring-cloud-kubernetes v5.1.0-M1

发生了什么变化

  • 通过 https://github.com/spring-cloud/spring-cloud-kubernetes/pull/2298 中的 @spring-builds 将 Maven 包装器更新为 3.9.16
  • 继续运行所有测试作业并添加重试功能（@ryanjbaxter in https://github.com/spring-cloud/spring-cloud-kubernetes/pull/2294）
  • 通过https://github.com/spring-cloud/spring-cloud-kubernetes/pull/2300中的@wind57将配置移动到父项目
  • 通过 @wind57 在 https://github.com/spring-cloud/spring-cloud-kubernetes/pull/2301 中移动通用构建插件
  • 由 https://github.com/spring-cloud/spring-cloud-kubernetes/pull/2303 中的 @dependabot[bot] 将 /docs 中的 antora 从 3.2.0-rc.2 提升到 3.2.0-rc.3
  • 由 https://github.com/spring-cloud/spring-cloud-kubernetes/pull/2296 中的 @dependabot[bot] 将 /docs 中的 antora 从 3.2.0-rc.2 提升到 3.2.0-rc.3
  • 在https://github.com/spring-cloud/spring-cloud-kubernetes/pull/2307中通过@wind57统一事件处理程序
  • 在https://github.com/spring-cloud/spring-cloud-kubernetes/pull/2309中通过@wind57开始统一检测器
  • https://github.com/spring-cloud/spring-cloud-kubernetes/pull/2310 中@wind57 提供的更简单的处理程序
  • 由 https://github.com/spring-cloud/spring-cloud-kubernetes/pull/2313 中的 @dependabot[bot] 将 /docs 中的 antora 从 3.2.0-rc.3 提升到 3.2.0
  • @wind57 在 https://github.com/spring-cloud/spring-cloud-kubernetes/pull/2311 中的 mvn 作业超时 90 分钟
  • 由 https://github.com/spring-cloud/spring-cloud-kubernetes/pull/2314 中的 @dependabot[bot] 将 /docs 中的 antora 从 3.2.0-rc.3 提升到 3.2.0
  • 修复@wind57 在 https://github.com/spring-cloud/spring-cloud-kubernetes/pull/2317 中的测试 *统一fabric8中的处理程序client由@wind57在https://github.com/spring-cloud/spring-cloud-kubernetes/pull/2316中重新加载
  • 通过https://github.com/spring-cloud/spring-cloud-kubernetes/pull/2318中的@wind57统一fabric8中的检测器
  • 通过 @dependabot[bot] 在 https://github.com/spring-cloud/spring-cloud-kubernetes/pull/2319 中将 org.codehaus.mojo:exec-maven-plugin 从 3.6.3 提升到 3.6.4
  • 通过 @dependabot[bot] 在 https://github.com/spring-cloud/spring-cloud-kubernetes/pull/2320 中将 org.codehaus.mojo:exec-maven-plugin 从 3.6.3 提升到 3.6.4
  • 通过 @wind57 修复 https://github.com/spring-cloud/spring-cloud-kubernetes/pull/2322 中的冲突端口
  • 修复 https://github.com/spring-cloud/spring-cloud-kubernetes/pull/2321 中 @wind57 的合并问题
  • 修复了 #2323 https://github.com/spring-cloud/spring-cloud-kubernetes/pull/2324 中@paprotox 在文档中正确启用的 Secrets.enabled 默认值

新贡献者

  • @spring-builds 在 https://github.com/spring-cloud/spring-cloud-kubernetes/pull/2298 中做出了第一个贡献
  • @paprotox 在 https://github.com/spring-cloud/spring-cloud-kubernetes/pull/2324 中做出了第一个贡献
