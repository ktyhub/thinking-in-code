ppt-master v6.5.0

自 v6.4.0 以来的两轮重点发布的次要版本：创建模板/使用模板流程经过审核和重新设计，编辑本机 PPTX 路线在真实的政府和大学平台上进行了练习（多母带、源动画、本机图表、SmartArt、旁白、修订轮次）并在出现问题的地方进行了修复。每项变更都有重现的缺陷或记录的合同差距作为支持；没有添加或删除任何路线。

编辑原生PPTX（往返导入→编辑→导出）

  • 根本无法导出的套牌现在导出：没有幻灯片与折叠的 <a:ext cx="0" cy="0"/> 占位符一起使用的内置布局不再使本机结构契约失败，并且当旁白强制重建时，持有全画布图片的未触及页面不再丢失该图片到后台升级（65091298）。
  • **运动覆盖逐个字段与导入基线的差异：省略 transition 的 sidecar 行会保持源转换，即使导入器写入 defaults.transition: none 也是如此； animation.effect: none真正消除了源时序； -t 和仅效果行保留源 advClick / advTm；用户编辑的默认值是套牌范围的请求（a7cb7767）。
  • 旁白注入时序树为裸 tmRoot 的幻灯片，阻止本机保留的 click 动画，并命名输出主干、源幻灯片和形状 ID，替换其自己的早期音频而不是堆叠第二个自动播放轨道，通过清单将导入的音频与输出页面匹配，并在重新录制时重用其媒体名称（a7cb7767、b560f85b）。
  • 保真度：重建对象上的同层链接通过文本编辑、页面规划和采用来保留其源目的地；主控/布局参考拒绝编辑而不是消失，而原始内容保持渲染；祖先变换/不透明度/继承样式加入源引用差异，以便移动的包装器实际上移动；仅绘画编辑保留本机文本正文（自动编号、自动调整、字段、语言）；自定义显示选择和操作在页面计划后关闭； SmartArt、OLE 和其他不受支持的图形框架带有始终承诺的原子代理标记 (57f76234)。
  • 注释：一页的新注释不再覆盖另一页的注释部分；往返工作区按精确的词干匹配音符并打印实际计数； --no-notes 删除每个音符部分、主控、关系和覆盖；导入仅写入 notes/<stem>.md（73bc51a3、b560f85b）。
  • 包：替换的图表部分、工作簿和幻灯片关系，从未使用过的幻灯片 XML 在编辑的往返页面和每张生成的幻灯片上进行修剪（结构化导出留下在每张幻灯片上注册的升级主背景）；交付检查按内容类型对幻灯片、注释、母版和布局进行计数，将悬空的自定义显示引用报告为错误，将未引用的幻灯片关系报告为建议 (57f76234)。
  • 质量门：svg_quality_checker.py --roundtrip --json写入validation/并与导出器共享其指纹，因此往返导出可以报告quality_gate=passed；检查器逐行测量导入的 lines / paragraphs 文本，停止重新估计仅垂直移动的源文本，尽早强制导出器的单文本语义形状契约，并在编辑的页面重写导入器本身无法携带的表时发出警告（73bc51a3，65091298）。
  • 路线文档说明身份边界、导入的文本模型、跳过 --native-charts-and-tables 真正发送的内容、注释消费者合同、spid → shape-<id> 映射、页面计划下每个母版/布局的保留、--primary-language 以及修订轮段落（52a2801c、5581c851）。

创建Template和模板消费

  • 安装通过回滚和机器收据进行分阶段 (template_install.json)；确认 UI 冻结选定的根快照，接受多个显式根，按内容绑定阶段并验证安装本身 - 切换 sidecar 及其两个命令消失了（6de79399、f58f846b）。
  • A型镜像是纯粹的工具路径：零编辑导入→物化→检查器→使用实际规格骨架进行预览； B 类承诺被撤销 (f58f846b)。
  • 模板模式根据插槽边界检查运营商基线、镜像文本目标，并提供咨询 --slot-capacity-report；半透明的全画布矩形不是背景； CJK 文字字体名称从不占用拉丁语槽；布局固定的原子留下了稀疏的显示大小配额；三个捆绑套牌模板获得了更高的章节编号槽（be808929、f58f846b）。
  • 结构化导出保留自定义占位符面孔，从公共页面重新设计主背景，在预览中本地编译类型化图表/表格槽，在验证时拒绝占位符槽作为 Morph 端点，并将零填充页码编译为幻灯片编号字段（6de79399、6e3ce9c5）。
  • 提示：第一阶段保留目标，而不是抹去模板事实；创建模板获得原型评审轮；在排版锁定之前检查槽配合；快速命名类型槽导出标志； import-sources --no-image-propagation 将参考位图保留在 images/ 之外（6627d92b、f58f846b、6e3ce9c5）。

工具

  • notes_to_audio.py 接受带有空格或 = (73bc51a3) 的 --rate -5%（和 --pitch / --volume，现在传递到 Edge-tts）。
  • 测试子进程输出解码为 UTF-8，无论父区域设置如何；当读取其根语言（7879bbc8、c6ae4896）时，第一个 svg_output 页面将确定性地关闭。
  • .env.example 文档赞助商中继快捷方式 (b44cdfac)。

安装

将 skills/ppt-master/ 作为技能加载（附加的 ppt-master-skill-v6.5.0.zip 仅包含该目录）或从存储库的市场安装插件。
