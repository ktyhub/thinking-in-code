ppt-master v6.7.0

小版本：设计规范的浏览器审查页面，Google 新的 Nano Banana 2.1 作为默认的 Google 图像模型，并修复了源转换和 PPTX/SVG 文本往返过程中在没有警告的情况下丢失的内容。

图像生成

  • Google 图像生成现在在 Gemini、OpenRouter (google/gemini-nano-banana-2.1) 和 fal (google/nano-banana-2.1) 后端默认为 Nano Banana 2.1（gemini-nano-banana-2.1，2026 年 10 月 6 日正式发布）。 Google 已弃用 gemini-3.1-flash-image，但尚未宣布关闭日期。 Nano Banana 2.1 不提供 512px，因此所有三个后端现在在发送请求之前都拒绝 512px。宽比例 1:4 4:1 1:8 8:1 仍然有效 (35508e34)。
    • 如果您的 .env 引脚 GEMINI_MODEL=gemini-3.1-flash-image （或 OpenRouter/fal 等效项），该设置仍然优于新的默认值。更新或删除要切换的线路。
    • 删除了 ID gemini-3.1-flash-image-preview 和 gemini-2.5-flash-image-preview；谷歌已经关闭了这两种型号。
  • OpenAI：OPENAI_BACKGROUND=transparent 现已接受 GPT 图像模型，包括 gpt-image-2（在 OpenAI 预览中），并且仅与 JPEG 输出一起被拒绝。 gpt-image-2.5-sunburst / gpt-image-2.5-flare 及其快照接受 OPENAI_QUALITY=xhigh|max。 gpt-image-1-mini 仅接受输入保真度 low。默认值保持为 gpt-image-2 (3f98568c)。
  • 后端修复：
    • Qwen 2K 2:3 / 3:2 用于生成 3:4 / 4:3 图像。
    • 以 /api/v3 结尾的 Volcengine Ark 基本 URL 不再附加 /api/v1。
    • 在发送请求 (06d8f0a1) 之前，复制现在会拒绝 21:9，而 flux-1.1-pro 不提供该功能。
  • image_search 将高于 Pillow 减压警告尺寸 (481e057e) 的原稿减半。 slice_images 还处理另外三种情况（964d9209、fd20665d、adbfdf48）：
    • 地面不平坦但颜色为主；
    • 边缘和阴影与主色混合；
    • 在接近主色的地面上进行去溢色处理。

设计规范审查

  • design_spec.md 的新浏览器审查页面：每个部分、零件和幻灯片一页。您可以直接编辑某一块的 Markdown。该编辑将作为具有哈希前提条件的精确字节范围替换来应用，并且在写入之前会检查其架构。您还可以留下每个块或全局注释，这些注释放在单独的 sidecar 文件中，而不是放在规范中。 check_spec_annotations.py 将两种反馈传递给代理（aec32024、61ad7aec）。
  • 启用 refine_spec 后，页面上确认的运行现在也会审核页面上的规格；在聊天中确认的运行继续在聊天中查看。批准仍然在聊天中进行。如果锁定 (866efd84) 后规范发生更改，则恢复将返回到“优化规范”。

源码转换

  • DOCX、PPTX、Excel 和 Web 转换器不再在没有警告的情况下删除内容。 受影响的内容包括嵌套表格、内容控件、表格内的尾注和链接、OMML 分隔符、PPTX 字段文本和编号延续、Excel 隐藏工作表、合并单元格和数字格式等（13ac724c、2d72da61）。
  • pdf_to_md 保留重复运行页眉或页脚的正文，并保留位于共享页眉的表格之间的数字或标记段落（51c2979a、4eb7b3d6）。当 pandoc 无法评估打字文本时，它会保留下来 (176235a3)。

PPTX ↔ SVG 文本

  • 文本基线现在来自两个方向的一个共享字体度量模型，取代了固定的字体大小估计（3d1b7dc6，#301）。
  • 溢出框架的导入文本将保留每一行，遵循 DrawingML 的默认溢出，并保持垂直锚定。仍保留显式 clip 和省略号（c9a82582、d5424756）。

用户界面和工具

  • 规格审查、确认和实时预览用户界面：
    • 全部以相同的方式检测和存储 UI 语言；
    • 切换语言保留键入的注释；
    • zh-TW 使用全角分隔符。 感谢@kevindesuyo（#305、#306、#307）。
  • 独立服务器将 ANSI 颜色代码保留在其日志之外 (1d76e326)。捆绑的比较库和徽标较小（6a9ee2aa）。

赞助商

  • 在国内代码旁边添加了国际基米代码链接（#296），并删除了赞助期限结束的赞助商（680de11f）。
