AutoGPT autogpt-platform-beta-v0.12.0

预发布 发布时间2026年11月19日 来源Significant-Gravitas/AutoGPT 英文原文

AutoGPT autogpt-platform-beta-v0.12.0

⚠️ 重大改变

前端不再读取 TRUST_X_FORWARDED_FOR （#16530，@Pwuts）。手动设置的自托管前端不会从 X-Forwarded-For 获取 client IP 用于登录 IP 日志、IP 块和每个访问者商店搜索，直到 TRUSTED_PROXIES 在其前面列出代理。单容器镜像和 Vercel 不需要任何东西。 该怎么做： 如果您的前端设置了 TRUST_X_FORWARDED_FOR，请将其删除并将 TRUSTED_PROXIES 设置为其前面的代理的地址或 CIDR 范围的逗号分隔列表。在此之前，前端会在启动时记录一条警告，提示旧设置将被忽略。相同的 TRUSTED_PROXIES 设置现在还命名后端的代理和外部 API 的每个地址限制，替换 FORWARDED_ALLOW_IPS 和 TRUSTED_PROXY_COUNT，它们继续工作但已弃用；在您自己的反向代理后面，单容器映像也会使用它。请参阅 Client IP 地址。

✨ 亮点

  • AutoGPT 放在您的口袋里。 我们新的本机移动应用程序可让您的团队在手机上：登录、与 Otto 和您的专家聊天、从 Marketplace 聘请专家、直接通过聊天连接您的服务以及通过实时语音听写进行交谈，而不是打字。 （＃16715，＃16869，＃16923，＃17058）
  • 更快开始。 注册步骤更少（不再需要输入两次密码），注册和登录页面立即显示，并且设置不再卡在“正在加载您的设置…”上。注册 Google，您可以在同一步骤中连接 Gmail、云端硬盘和日历。 （#16829、#16831、#16968、#16845、#16877）
  • 更安全的登录。 添加新的帐户登录方式（Google、Microsoft、GitHub 或 Discord）现在需要从您的收件箱中获取六位数的代码，除非该提供商运行您的邮箱（Gmail 通过 Google，Outlook.com 通过 Microsoft）。每当添加新的登录方法时，您也会收到一封电子邮件。 (#16860)
  • 永远不会丢失消息。 如果 Otto 无法确认您的消息已送达，则“发送”上的 click 会再次传送该消息（包括文件），而无需发送两次。 “思考……”现在会一直持续到奥托开始回答为止，所以你总是知道它正在发挥作用。 （＃17041，＃16962，＃17038）
  • 始终查看跑步的实际位置。 在短暂的连接断开后，您的库、跑步历史记录、活动和聊天会自行赶上，因此已经完成的跑步看起来不再像是仍在进行。实时更新也可以在慢速连接上持续进行。 （#16898、#16915、#16932、#16903、#16865、#16960）
  • 您可以信赖的计划。 在短暂维护期间，您的计划显示为暂时不可用而不是消失，重新启动期间到期的运行仍然运行（仅一次），并且重试您刚刚创建的计划不再产生重复。 （#16937、#16866、#16919、#16904）
  • 更多型号可供选择。 Gemini 4 Neon、GPT-6.2 Astra、GPT-6.2 Sol 和 Qwen 4 Max 现在可在您的工作流程中使用，Otto 的高级 Codex 层现在可以在 GPT-6.2 Astra 上运行。 （#17023、#16870、#16899、#16836、#16852、#16902）
  • Otto 的更多工具。 Otto 现在可以连接到 AnySearch、Supabase、Klaviyo、AI/ML API 和 CompanyEnrich，每次从 Supabase 读取数据不再需要您的批准，并且 Otto 现在可以找到您通过 URL 连接的自定义 MCP 服务器。 （#16913、#16659、#16850、#15202、#16771、#16447、#15168）

🔒 安全

此版本修复了一些私人报告的安全问题。一旦修复程序投入生产，我们将发布建议。
