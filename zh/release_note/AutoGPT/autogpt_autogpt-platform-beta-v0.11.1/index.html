⚠️ 重大变更

  • #16416 - 自托管安装：.env.default 不再提供 Web 推送 (VAPID) 密钥对，并且后端不再使用旧提供的密钥对发送推送通知。运行 make init-env 为您的安装生成一对；单容器映像在首次启动时生成自己的映像。替换该对会使现有推送订阅失效。 NEXT_PUBLIC_VAPID_PUBLIC_KEY 可以保留空白，然后前端使用后端的密钥（by @ntindle）
