新功能

  • #11106 - 实施全面的限速 Discord 警报系统（由 @majdyz 提供）

  • #11164 - 添加专用的 Perplexity 块（由 @Torantulino 提供）
  • #11166 - 将参考输出引脚添加到事实检查器块（由@Torantulino）

  • #11179 - 添加 Claude Haiku 4.5 模型支持（由 @Bentlybro 提供）

  • #11136 - 删除代理活动标志（由@0ubbe）

  • #11159 - 修复用户注销时的发布代理行为（作者：@Abhi1992002）
  • #11160 - 修复自定义变异器中的 client 端错误处理（由 @Abhi1992002 提供）
  • #11171 - 修复新构建器中的自动选择凭证机制（作者：@Abhi1992002）

  • #11175 - 取消隐藏“添加到字典”块的 dictionary 输入（由 @Pwuts 提供）
  • #11174 - 全面的 SafeJson 清理，以防止 PostgreSQL 空字符错误（由 @majdyz 提供）
  • #11176 - 改进存储异常层次结构以获取正确的 HTTP 状态代码（由 @majdyz 提供）
