🚀 发布 autogpt-platform-beta-v0.6.36

日期： 2025 年 11 月

🔥 有什么新内容？

新功能

  • #11230 - 聊天系统后端实现（由 @Swiftyos 提供）
  • #11290 - 具有完整消息传递界面的聊天 UI 前端（由 @Swiftyos 提供）
  • #11330 - 限制经过身份验证的用户的聊天访问并限制每次聊天的代理运行（由 @Swiftyos 提供）
  • #11301 - 添加动态输入对话框以用于具有凭证支持的代理执行（由 @Abhi1992002 提供）
  • #11286 - Google Drive Picker 组件集成（由 @0ubbe 提供）
  • #11298 - 使用基于标头的身份验证实现管理员用户模拟（由 @majdyz 提供）
  • #11307 - 使用键盘快捷键向流程构建器添加撤消/重做功能（由 @Abhi1992002 提供）
  • #11312 - 将基于 cron 的调度功能添加到具有输入/凭据支持的新构建器（由 @Abhi1992002 提供）
  • #11306 - Cookie 同意横幅和设置（由 @Bentlybro）

增强功能

  • #11309 - 增加 Switch 组件的对比度以获得更好的可见性（由 @Pwuts 提供）
  • #11324 - 更改执行任务摘要的文案（作者：@majdyz）
  • #11185 - 更新 Exa 搜索块以匹配最新的 API 规范（由 @ntindle）
  • #11325 - 将正确性分数添加到执行活动生成中（由 @majdyz 提供）
  • #11320 - 将链接变体添加到按钮组件（由@0ubbe）
  • #11322 - 更新市场中的代理下载 UI（由 @Pwuts 提供）
  • #11331 - 删除已弃用的 LLM 模型并添加迁移脚本（由 @Bentlybro 提供）

错误修复

  • #11293 - 澄清 Claude 列表生成的提示要求（by @ntindle）
  • #11294 - 将 apscheduler 升级到 DST 固定版本 3.11.1 （由 @Pwuts 提供）
  • #11299 - 补丁加载流程（由@kcze）
  • #11303 - 在运行时重置珠子（由@kcze）
  • #11315 - 修复市场面包屑拼写错误（由 @0ubbe 提供）
  • #11318 - 暂时禁用图形执行的库存在检查（由@majdyz）
  • #11258 - 在新构建器的自定义节点中正确渲染所有类型的输出（由 @Abhi1992002 提供）
  • #11304 - 钱包修复（由@kcze）
  • #11326 - 通过重新发布到后台来修复速率受限的消息阻塞队列（由@majdyz）
  • #11323 - 改进图形执行权限检查（由 @Pwuts 提供）
  • #11291 - 确保当 active_version_id 存在时获取代理版本（由 @seer-by-sentry[bot]）
  • #11211 - 防止未安装的 OnboardingProvider 上的状态更新（由 @seer-by-sentry[bot] 提供）
  • #11197 - 为输入验证实现向后兼容的 Set 操作（由 @seer-by-sentry[bot] 提供）
  • #11332 - 修复聊天重复消息（由 @Swiftyos 提供）

依赖关系和维护

  • #11288 - 将开发依赖项组跨越 1 个目录，进行 13 项更新（由 @dependabot[bot] 提供）
