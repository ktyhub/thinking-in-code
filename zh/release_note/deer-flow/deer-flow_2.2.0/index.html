#鹿流v2.2.0

鹿流 2.2.0

DeerFlow 2.2 将 2.1 超级代理安全带变成部署级平台 重点是大规模运营并委托 trust：已安排 任务成长为目标驱动的工作流程，具有公平的多所有者执行，每个 从 IM 渠道到工作流程的子系统跨多个网关运行 实例，扩展平台提供全栈插件、知识 检索变得独立于提供者，具有可验证的引文和模型， 内存和通道获得生产级管理 - 通过故障关闭进行强化 默认值、静态凭证加密以及更严格的上传和路径 层。

此版本结束了 2.2.0 里程碑 自 2.1.0 发布以来，有 1068 个合并的 PR。

📖 完整笔记：CHANGELOG.md · 中文版

⚠️ 重大变更

  • 本地开发绑定环回 - make dev / make start 不再监听 所有接口；端口 2026/8001/3000 和 /setup 远离 LAN/VPN。套装 .env 中的 BIND_HOST=0.0.0.0 暴露堆栈，并注意值 nginx 会误读（0、1.2.3、括号内的 IPv6）现在被拒绝 任何服务都会停止。 （[#6587]、[#6635]）
  • 存储的凭据静态加密 - 仅限新的环境 DEER_FLOW_CREDENTIALS_KEY（Fernet，逗号分隔旋转）保护 IM 通道凭证和 MCP OAuth 刷新令牌；多实例 使用 channel_connections 或刷新令牌 OAuth 的部署拒绝 开始没有它。 IM 机器人凭证不再是明文 channels/runtime-config.json改成共享channel_runtime_configs 表 - 现有机器人在首次启动时导入一次，并且必须降级 重新输入 UI 配置的机器人。 （[#6611]、[#7207]、[#6988]）
  • 多进程门更严格 — GATEWAY_WORKERS > 1（或 deployment.multi_instance: true 或 WEB_CONCURRENCY）现在需要 Redis流桥；内存桥不再启动多进程。的 当非 GitHub IM 时，新的 channels.leader_lease 部分必须保持启用状态 通道已配置。 （[#6328]、[#6746]、[#6252]）
  • 调度程序合同更改 - /api/scheduled-tasks* 错误返回 结构化 {"detail": {"code", "message", "params"}} 信封（读 detail.message）；一个新的scheduler.max_concurrent_runs_per_user（默认 2) 限制一个所有者的并发计划运行； IM 通知是诚实的， 本地化，每次发生最多发送一次；跳过夏令时 once 墙 次被拒绝为 422。（[#6378]、[#6393]、[#7281]）
  • 线程删除级联 — 现在删除线程也会删除其运行， 运行事件和反馈，因此已删除的线程无法再被读取或 由重新创建的线程 id 继承。 （[#5535]）
  • 模型绑定历史记录保持仅追加 — 取代 write_file 有效负载 省略成为选择加入（tool_output.elide_superseded_writes，默认 false) 因为省略重写了早期的请求段并使其失效 提供者提示缓存；技能 allowed-tools 仅是兼容性元数据 并且不再隐藏或阻挡工具。 （[#7319]、[#7455]、[#6935]）
  • 工具授权涵盖中间件工具 — 计划模式 write_todos 和 扩展中间件工具现在像其他任何工具一样通过第一层授权 工具；具有省略它们的显式 tools 策略的部署将停止 束缚他们。 （[#6105]）
  • 故障关闭安全默认值 — 委托 web_fetch/web_capture 后端（无浏览器、Crawl4AI、Firecrawl、fastCRW）筛选其基本 URL 并在确认之前拒绝环回/私有默认值； SSRF警卫拒绝 CGNAT 系列 100.64.0.0/10（尾网需要 allow_private_addresses: true）； IM allowed_users 解析失败关闭 Slack、钉钉、QQ 和 Telegram（无效列表现已否定所有人） 而不是默默地允许）；外部 system/developer 消息是 被拒绝400；权限检查现在涵盖了以前的路线 仅身份验证，USER.md 的范围为每个用户。 （[#6531]、[#6202]、[#6230]、[#6742]、[#6730]、[#5651]、[#4989]）
  • 上传和路径变得严格 - Windows 保留的设备名称（包括 上标 COM¹–COM³ 和 CONIN$/CONOUT$) 被拒绝 上传、沙箱写入和技能文件；同名上传声称下一个 _N后缀代替截断；转换后的 Markdown 同伴从不 替换现有文件；被拒绝的附件记录在 skipped_files和success表示至少存储一个文件；大纲/预览 缺少时间戳的记录被拒绝 - 重新上传以恢复转换。 （[#6102]、[#6148]、[#6279]、[#6149]、[#7388]、[#7054]、[#7165]、[#6165]）
  • 作曲家斜线菜单减少 - / 现在仅列出内置 /goal 和 /compact；选择技能作为内联 @ 参考。 （[#6154]）
  • API 形状收紧 — 畸形的运行体返回 422/400 而不是 500； wait 端点返回 SDK 兼容的错误包络以完成 运行失败；显式的空 event_types 过滤器不匹配任何内容；键控的 对于无法保留请求身份的 RunStore，恢复失败关闭 (503)； 网络编辑器 MCP 连接变为每个用户； SQLite file: URI 是 被拒绝；整数配置字段拒绝 YAML 布尔值； gpt-6家族车型 默认为响应 API； --print/--json 因 LLM 错误而退出 1 后备。 （[#7362]、[#6217]、[#7352]、[#6571]、[#6499]、[#5966]、[#6069]、 [#6017]、[#6171]、[#6863]、[#6056]）

✨ 亮点
