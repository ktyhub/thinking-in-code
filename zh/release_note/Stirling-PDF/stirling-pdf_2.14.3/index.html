Stirling-PDF v2.14.3

修订 发布时间2026年8月6日 来源Stirling-Tools/Stirling-PDF 英文原文

Stirling-PDF v2.14.3

修复了许多错误的修补程序版本， （请注意，我们已经为 Mac 用户发现了一些问题，并希望在接下来的几天内再次修复） 下面列出了主要错误修复：

工具修复

  • 修复合并拆分和其他操作在 Debian 12 和 fedora 44 上不起作用的问题
  • 某些工具（例如合并）的并发使用问题
  • 修复了自动删除图像的问题
  • 大型 2GB PDF 在设定场景下不再崩溃

桌面修复

  • Windows ARM64 测试版本
  • Linux 启动修复

我们计划在 2-3 周内发布一个大型版本，其中包含一些令人兴奋的新功能，所以请继续关注！

发生了什么变化

  • 编辑：当 @jbrunton96 在 https://github.com/Stirling-Tools/Stirling-PDF/pull/6972 中没有给出文本模式（精心挑选）时，清除错误而不是 500 *修复（临时文件）：防止https://github.com/Stirling-Tools/Stirling-PDF/pull/7006中的@Ludy87清理活动注册目录
  • deps（前端）：通过https://github.com/Stirling-Tools/Stirling-PDF/pull/6989中的@Ludy87将@embedpdf包升级到v2.14.4
  • 修复（管理设置）：在 https://github.com/Stirling-Tools/Stirling-PDF/pull/6822 中 @Ludy87 输出的设置中正确屏蔽 Telegram 机器人令牌
  • 修复（管理设置）：防止 https://github.com/Stirling-Tools/Stirling-PDF/pull/6823 中 @Ludy87 的管理常规部分出现水合错误 *修复（编辑器）：在https://github.com/Stirling-Tools/Stirling-PDF/pull/6807中尊重@Ludy87在配置导航中的无登录设置可见性
  • 修复（许可证）：回退到 https://github.com/Stirling-Tools/Stirling-PDF/pull/7046 中@Ludy87 的后端依赖链接的许可证 URL *修复（签名）：在https://github.com/Stirling-Tools/Stirling-PDF/pull/7093中保留@Ludy87的PNG签名位置和页面内容
  • 修复（查看器）：https://github.com/Stirling-Tools/Stirling-PDF/pull/6607 中 @balazs-szucs 基于总页数的动态页码输入宽度
  • Google Drive 导入：脚本加载器在 https://github.com/Stirling-Tools/Stirling-PDF/pull/7075 中的 @ConnorYoh 运行脚本（精心挑选）之前不再报告准备就绪
  • 在 https://github.com/Stirling-Tools/Stirling-PDF/pull/7175 中 @Frooodle 将大型 PDF 添加到工作台时避免渲染器 OOM
  • 构建（deps）：通过 @dependabot[bot] 在 https://github.com/Stirling-Tools/Stirling-PDF/pull/7237 中将 pdfboxVersion 从 3.0.7 提升到 3.0.8
  • 从 https://github.com/Stirling-Tools/Stirling-PDF/pull/7148 中的 @Frooodle 的 GitHub Actions 工作流程中删除 depot.dev 支持
  • @Frooodle 在 https://github.com/Stirling-Tools/Stirling-PDF/pull/7174 中修复了桌面安装程序
  • 修复 @reecebrowne 在 https://github.com/Stirling-Tools/Stirling-PDF/pull/7266 中的裁剪/旋转预览
  • 修复（搜索）：修复 PDF 查看器搜索在 https://github.com/Stirling-Tools/Stirling-PDF/pull/7228 中显示 @balazs-szucs 的 0 个结果中的 0 个
  • 修复 https://github.com/Stirling-Tools/Stirling-PDF/pull/7311 中 @Frooodle 的自动化无法运行工具
