Stirling-PDF v3.0.0

Stirling PDF V3.0 上线了！ 通过此更新，我们引入了许多令人兴奋的新变化、全新的自动化系统、面向所有人的免费 OAuth SSO、全新的文本编辑器以及大量新功能、错误修复和安全修复

除了“PDF 编辑器”之外，我们还有一个新系统，称为“PDF 处理器” PDF 处理器采用您在 Stirling PDF 中已使用的工具，并允许您在具有各种来源（文件夹/FTP/S3 等）的大量文件中运行它们 这个想法是，如果您需要 OCR 10,000 个文件、压缩整个文件夹或转换整个文档库，这应该是一个可以提供帮助的工具，并允许它在未来文件到达时侦听和运行它们 这是处理器的第一个主要版本，我们将根据人们使用它的方式快速改进它。 带有示例的完整处理器指南 AI 也可作为处理器的可选部分。 您可以使用 AI 来理解文档、对其进行分类、提取信息并帮助实现自动化处理。 AI 是完全可选的（默认情况下关闭），可以使用各种模型，包括本地/自托管模型，具体取决于您的设置。 Automation 现在每月免费提供 1,000 个 PDF。 此限额适用于通过处理器、API 和 AI 功能进行的自动化处理。 将您的服务器链接到 Stirling.com，您每月可以额外获得 500 个 PDF，并可以访问我们托管的 AI（如果您不想托管自己的 AI）。 普通 PDF 编辑器的使用仍然免费且无限制。此外，我们还为所有用户免费提供 OAuth SSO。

V3.0 还包括对 PDF 编辑器方面的重大改进：

  • 已经提到的免费 OAuth SSO
  • 全新的文本编辑器，现已推出 Alpha 版本，您应该期待更好的 UI、性能和兼容性
  • 改进的表单编辑器和表单创建
  • 自动形状检测
  • 新的快速访问栏
  • 自动旋转
  • 主要修订改进
  • PDF/UA 转换（WIP）
  • PDF 包支持
  • 专用读者视图
  • 使用二维码从您的手机登录
  • RFC3161 时间戳
  • 搜索所有斯特灵 PDF
  • 移动用户界面改进
  • 改进了桌面的文件处理和文件历史记录，因此删除的文件在斯特林 UI 中删除
  • 全新的文件库
  • 新的桌面文件夹可将文件夹从磁盘安装到斯特林以运行自动化（将在未来的更新中扩展）
  • 全新的设置页面
  • 根据以前的工具使用情况提供更智能的工具建议
  • 一般用户界面改进和错误修复
  • 多个错误修复和安全改进！

请尝试 V3.0 并告诉我们您的想法。我们将在接下来的几周内发布修复、改进以及新的处理器和编辑器功能，预计将每周发布一次，并将更加关注社区 PR。
