Stirling-PDF v3.2.2

另一个小版本修复了一些错误

  • 修复了一些查看器渲染问题
  • 为查看器提供新的自动适应宽度按钮
  • 新的注释形状选项，如箭头和折线
  • QR码印章类型

发生了什么变化

错误修复

  • 修复（i18n）：在 https://github.com/Stirling-Tools/Stirling-PDF/pull/8123 中扩展@alkank 的土耳其语翻译
  • 修复（查看器）：在 https://github.com/Stirling-Tools/Stirling-PDF/pull/8629 中通过 @reecebrowne 渲染具有匹配宽度的非嵌入字体

增强功能

  • feat(viewer)：适合宽度并适合查看器中的页面按钮，作者：https://github.com/Stirling-Tools/Stirling-PDF/pull/8485 中的@EthanHealy01
  • 修复 @jbrunton96 在 https://github.com/Stirling-Tools/Stirling-PDF/pull/8619 故事书中的竞争条件 *构建（deps-dev）：通过@dependabot [bot]在https://github.com/Stirling-Tools/Stirling-PDF/pull/8580中将/frontend中的快速uri从3.1.7提升到3.1.9
  • build(deps-dev): 通过 https://github.com/Stirling-Tools/Stirling-PDF/pull/8630 中的 @dependabot[bot] 将 /frontend 中的 IP 地址从 10.7.2 提升到 10.7.4 *构建（deps）：通过https://github.com/Stirling-Tools/Stirling-PDF/pull/8631中的@dependabot[bot]将/frontend中的dompurify从3.4.16提升到3.4.17
  • 在 https://github.com/Stirling-Tools/Stirling-PDF/pull/8573 中对@jbrunton96 的 a11y nightlies 进行碎片化
  • 通过 @jbrunton96 在 https://github.com/Stirling-Tools/Stirling-PDF/pull/8585 中修复 Rust 中现有的 CI 错误
  • 壮举（注释）：在 https://github.com/Stirling-Tools/Stirling-PDF/pull/8578 中添加 @reecebrowne 的箭头和折线工具
  • feat(stamp): 在https://github.com/Stirling-Tools/Stirling-PDF/pull/8492中添加@EthanHealy01的QR码印章类型
  • 将版本升级为 3.2.2、刷新翻译以及 https://github.com/Stirling-Tools/Stirling-PDF/pull/8617 中 @jbrunton96 的后端可靠性修复

开发工具

  • 构建（deps）：通过 @dependabot[bot] 在 https://github.com/Stirling-Tools/Stirling-PDF/pull/8594 中将 astral-sh/setup-uv 从 10.2.0 提升到 10.3.0

其他变化

  • 由 @jbrunton96 在 https://github.com/Stirling-Tools/Stirling-PDF/pull/7062 中重构前端文件夹

  • 构建（deps）：https://github.com/Stirling-Tools/Stirling-PDF/pull/8373 中 @dependabot[bot] 从 6.0.2 到 7.0.1 的碰撞操作/结帐
