Stirling-PDF v3.1.0

小版本 发布时间2026年10月5日 来源Stirling-Tools/Stirling-PDF 英文原文

Stirling-PDF v3.1.0

此版本再次出现一些重大变化！ 群组签名（称为 Stirling Sign）即将退出 Alpha 版，现在默认为新用户启用，使用它，您可以在整个组织中共享、跟踪和签署 PDF。它还配备了全新的签名UI，极大地改善了用户的签名体验。如果您有任何问题，请告诉我们！

我们还推出了一款名为“Stirling Office Convert”的新嵌入式转换工具，我们正在试用该工具，它的目的是更快地提供更好的转换结果，并使用更少的内存。这是测试版，因此请进行比较并告诉我们！ （默认情况下在“高级”>“功能标志”下启用它）

此版本中还有大量其他功能：

  • 文本编辑器支持直接在文件中编辑表格！
  • 文本编辑器支持编辑OCRed图像PDF！
  • 文本编辑器 UI 和 UX 改进
  • 附件支持改进（添加、重命名、提取、删除等）
  • 几个依赖项更新

并再次提及：

  • 全新的团签UI
  • 新的 PDF 转换工具，希望将来能够取代旧工具（并且很快就会进入本机桌面！）
  • 签名工具改进

我们还修复了一些错误，包括

  • 缺少某些翻译
  • 帐户链接不适用于某些版本
  • 自动旋转在桌面上不起作用
  • Selfhost 用户显示无效的团队菜单
  • 桌面有时无法正确更新自身
