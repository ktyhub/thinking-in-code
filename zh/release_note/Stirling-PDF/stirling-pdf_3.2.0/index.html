Stirling-PDF v3.2.0

又一个好作品发布！ 旧的多功能工具已被完全重新设计的页面编辑器所取代。它现在重新支持图像、重命名文件和一系列 QOL UI 更改，使重新排列和管理文档变得更加容易。如果您有任何问题，请告诉我们您的想法！

我们处理受密码保护的 PDF 的方式发生了一些重大变化，现在可以使用常用工具打开它们进行查看和使用，而无需先删除密码，并且解锁时会保留您现有的 PDF 权限设置。

其他变化是：

  • Stirling Sign 现在随着签名请求的进展向参与者和请求者发送电子邮件
  • 将文件拖放到工作台上的任何位置，以及重新设计的添加文件按钮
  • 压缩现在会告诉您何时无法缩小文件
  • 带有指南图的整洁的小册子拼版用户界面
  • 在反向代理后面运行时，OAuth2 和 SAML 的可选 redirectBaseUrl
  • 查看器和文本编辑器的启动速度更快，内存使用量更低
  • 刷新图标和聊天 UI 改进

我们还修复了一些错误，包括

  • 在 Mac 上重新排序文件时桌面崩溃
  • 表单草稿在保存完成之前丢失
  • 调整页面大小和比例时签名丢失
  • 离开时签名工具崩溃
  • 聊天未正确更新文件版本
  • S3 上传重试失败
