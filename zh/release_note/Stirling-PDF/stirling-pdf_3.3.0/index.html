Stirling-PDF v3.3.0

Stirling Office Convert（仍为测试版）已升级。您现在还可以选择它作为许多其他工具的转换器，例如电子邮件、HTML、Markdown 和电子书到 PDF 以及 PDF 到 HTML/Markdown/XML/EPUB/AZW3 和 PDF/A。请将其与现有转换器进行比较并告知我们！

我们的路线图是下周默认打开 Office Convert，然后，如果不需要更改，则在下周完全删除 LibreOffice 和其他依赖项。因此，现在是尝试并报告（并发送示例文件）任何看起来不正确的转换的最佳时机！

其他变化是：

  • 即使启用了用户名/密码登录，SSO 自动登录现在也可以工作（管理员仍然可以通过 /login?all 访问密码表单）
  • JPDFium 升级和支持以及 Windows ARM64 支持，此更新还带来了更好的编辑、合并/拆分改进以及大文件的更低内存
  • 更快、更准确的移动扫描，不再捆绑 9MB OpenCV
  • 更快的请求，更少的数据库读取和新的实体缓存
  • 更安静的启动和运行时日志
  • Spring Boot、Docker 基础映像和许多其他依赖项更新
  • 更新了所有语言的翻译

我们还修复了一些错误，包括

  • 将发送多个或混合文件上传转换为错误的转换
  • 电子书设置重置所选的输出格式
  • “包括所有收件人”不控制电子邮件到 PDF 中的 CC/BCC
  • PDF/UA 字体嵌入使得表单字段不再可填写
  • 证书签名拒绝未加密的 PKCS#8 PEM 密钥
  • 添加书签后，查看者会跳离您的页面
  • 为非 zip 文件提供存档提取

此版本还包括多项安全性和稳定性改进，因此我们建议用户尽可能进行更新！ 注意：旧的、已弃用的后端 PDF 文本编辑 API 已被删除，取而代之的是新的文本编辑器。我们希望尽快添加新的文本编辑器 API！
