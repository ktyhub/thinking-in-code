修订 发布时间2026年10月21日 来源Stirling-Tools/Stirling-PDF 英文原文

Stirling-PDF v3.2.1

较小的版本，具有一些不错的查看器和编辑器改进以及注释和压缩的错误修复

主要特点是：

  • 对查看器的箭头键支持
  • 双页面视图支持封面
  • 现在从所选文本开始朗读
  • 您现在可以在页面编辑器中复制页面（多功能工具）
  • 内存优化
  • 标记损坏的 PDF 并提供修复
  • 将 PDF 注释导出为 CSV

错误修复

  • 修复了压缩未正确压缩的情况
  • 修复了 3.2.0 中引入的各种注释问题
  • 修复了默认工具选择器模式的问题
