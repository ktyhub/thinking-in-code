＃rocketmq-spring Rocketmq-spring-all-2.2.0

此版本的主要目标是与 RocketMQ Client 4.8.0 保持一致并支持拉动消费者模式。此外，此版本修复了一些重要的错误并进行了一些增强。

特点

  • [ISSUE #306] RocketMQ-Spring 中支持真正的 LitePullMessage。

改进

  • [ISSUE #289] 使用 acl 时使用默认实例名称。
  • [ISSUE #298] 消费失败时警告信息过多。
  • [ISSUE #308] 修复 ACLStringConsumer 类中的注释错误。
  • [ISSUE #314] 将示例项目中模块的父版本从 2.1.1-SNAPSHOT 修改为 2.1.2-SNAPSHOT。
  • [ISSUE #327] 删除 ConsumerMessage 方法中的信息日志。
  • [问题 #329] 将 RocketMQ 版本升级到 4.8.0。

错误

  • [ISSUE #268] RocketMQMessageListener nameServer 在某些场景中不起作用。
  • [ISSUE #294] RocketmqUtil 中的 GetAndWrapmessage 方法在获取密钥时缺少前缀。
  • [ISSUE #304] 修复枚举和数字之间的对应关系。
