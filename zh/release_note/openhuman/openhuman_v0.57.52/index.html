openhuman v0.57.52

openhuman v0.57.52

特工世界和钱包安全升级

此版本带来了特工世界深度的巨大飞跃、应用程序中更流畅的导航以及重大的钱包安全修复，以及整个生活质量的改进。 🎉

亮点

特工世界原生化 🌍

Agent World (tiny.place) 现已与完整的 Rust 数据层和移植的 React UI 深度集成，解锁核心界面，例如 Feed、消息、工作/赏金、目录/身份，以及通过支出前确认的 devnet 支付流程。在此基础之上，Explore 现在可以提取真实的实时数据，身份注册可以正确发布到目录，DM 可以可靠地解析处理，并且群组/创建赏金可以提供更清晰的用户体验反馈。
(#3780、#3839、#3847、#3846、#3840、#3837、#3835) — 谢谢@graycyrus！

更智能的代理工作流程和编排🤖

现在，当其父线程关闭时，分离的后台子代理会完全取消，从而防止对已删除的对话进行“即发即弃”运行。现在，代理基于实时的每轮时钟，因此时间相关的语句（“早上好”、“今天/明天”）在长时间会话中保持准确。
(#3742、#3752) — 谢谢@sanil-23！

钱包安全性、可见性和 trust 🔐

关键的钱包修复可确保恢复短语体验显示现有短语，而不是意外地重新生成/覆盖用户的钱包——现在由明确的“强制”路径和更清晰的 UI 状态机保护。通过突出的侧边栏条目，钱包访问也更容易被发现，Agent World 现在在其侧边栏标题中显示了一个方便的钱包地址芯片。
(#3849、#3836、#3838) — 谢谢@graycyrus！

导航和聊天外壳抛光 🧭

由于只有图标的导航栏可以保持完全可导航，并且具有工具提示和活动状态，因此折叠时外壳更易于使用。侧边栏标题也更干净（语言选择器移至“设置”），并且聊天/侧边栏体验得到了有意义的重新设计，线程标题重命名流入侧边栏和其他聊天 shell 改进。
(#3802、#3810、#3854) — 谢谢@graycyrus 和@senamakel！

奖励 + Discord 链接成为现实🎁

Discord 链接现在实际上从“奖励”页面运行 OAuth（并立即返回），并且“奖励”体验添加了断开/重新链接以及清晰的每个成就角色分配状态，因此声明角色是透明且可操作的。
(#3748、#3766) — 谢谢@YellowSnnowmann！

本地化和用户体验正确性修复 🌐

现在，更多面向用户的字符串已完全本地化，包括 OpenHuman Link 帐户/通知消息传递和模型委员会提示选择器标签，从而弥补了英文文字绕过 i18n 的差距。此外，Conscious 循环触发器现在受到保护，以防止在 rapid click 上重复运行。
(#3702、#3704、#3708) — 谢谢@obchain！

嵌入式 webview 提供商扩展 🧩

嵌入式 Webview 帐户选择器现在跨前端、Tauri shell、核心登录检测和提供商配方支持更多主流提供商（Gmail、Outlook、Instagram 和 X）。
(#3755) — 谢谢@senamakel！

测试并发布健康改善🧪

E2E 覆盖范围和 Playwright/Vitest 设置已适应聊天即家庭 shell，修复了导航竞争并稳定了覆盖超时。
(#3754) — 谢谢@senamakel！

Agent World UI 对齐和侧边栏清理 🧹

Agent World 继续精简：工作现在从 Agent World 侧边栏隐藏（同时保持深层链接可访问的路径），并且工作申请获得了一个代理工具以及更清晰的“提案提交”成功用户体验。
(#3855、#3848) — 谢谢@graycyrus！

Linux 打包可靠性🐧

AppImage 捆绑现在一致地替换了 CI 主机系统中捆绑的 ld-linux，以防止在较新的发行版上出现 glibc 不匹配崩溃（例如，glibc ≥ 2.42 的 Fedora）。
(#3645) — 谢谢@0xhis！
