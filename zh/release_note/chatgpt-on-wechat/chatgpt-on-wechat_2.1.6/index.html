🤝 子代理

主代理可以将独立的任务交给子代理并并行运行它们——改善结果，降低上下文成本，并加快可能同时发生的工作：

  • 隔离上下文：中间工作不参与主要对话，节省令牌并保持模型的重点。
  • 并行执行：多个子代理可以同时运行，主代理在完成时收集其结果。 Web 控制台和桌面 client 都显示完整的运行情况。
  • 可定制：两种内置类型，general-purpose 和 explore，以及您自己的 — 将 .md 文件拖放到工作区 subagents/ 目录下，以定义具有自己的系统提示符和工具集的类型。
  • 默认开启：无需设置；主代理决定何时进行委托。在 Config → Agent 下切换，并在 config.json 中调整嵌套深度、并发性和超时。

🖥 台式机 Client

  • 计划任务通知：client 接收计划和推送的消息并引发操作系统通知。
  • 更新面板：更新对话框现在链接到 release note，以便您可以看到发生了什么变化。
  • 自定义提供程序模型：自定义提供程序获得自由格式的模型输入。
  • 启动修复：修复了后端启动挂起的问题，添加了自动端口重试，并在失败时显示了真正的错误。

下载：【CowAgent桌面版】(https://cowagent.ai/download/)

文档：桌面 Client

🧠 推理努力和思考

  • 推理努力设置：Claude、Qwen、Kimi 等的本机 reasoning_effort 配置，每个模型都会记住。谢谢@tshi Cheng (#3007, #3009)
  • 克劳德思考：克劳德的思考过程现在可以显示在Web控制台和桌面client中，使其推理更容易理解。

🔒 安全强化

  • 受保护的自我进化写入：无人值守的写入现在得到验证和回滚，写入按工作区序列化，并且受保护的写入路径缩小，因此工作区中的任务文件不再被错误触及。感谢@lisheng-SenLee (#3011, #3016)
  • 技能路径验证：技能安装更彻底地验证每个文件路径。谢谢@LHMQ878 (#3006)
  • 依赖项升级：桌面 client 升级了 js-yaml 和 linkify-it，修复了两个可利用的拒绝服务问题。谢谢@anupamme

💾 记忆与检索

  • 可插拔向量后端：内存的向量存储和检索位于单个接口后面，默认使用 SQLite，以便以后轻松插入外部向量存储。谢谢@AaronZ345 (#3021)
  • 索引修复：修复了块更新时的 trigram FTS5 索引损坏；损坏的共享数据库现在可以自我修复。

文档：内存

🛠 改进和修复

  • 自定义图像提供程序：图像生成支持自定义提供程序，具有实时凭据刷新和删除清理功能。谢谢@AaronZ345 (#3022)
  • 可靠的 SSE 重新连接：Web SSE 生命周期现已完成，可在网络中断后通过事件重播重新连接，并减少长时间任务中的消息丢失。感谢@lisheng-SenLee (#3014)
  • 推理显示：修复了推理模式下工具卡、文件链接和图像显示的多个问题。
  • 速率限制退避：当 LLM 受到速率限制时，限制退避，避免长时间等待。谢谢@tim-korso (#3018)
  • 安静的计划任务：没有任何可报告的计划任务不再发送空消息。谢谢@kowkow Huang (#3001)
  • 服务停止时间：修复了被拒绝作为服务停止时间的一天结束时间（例如 23:59）。谢谢@Iams4kura (#3020)
  • 域方案：修复了 WEBSITES_DOMAIN 中未遵循的显式 http/https 方案。感谢@6vision (#3015)
  • 微信媒体：修复个人微信无法通过不可靠的网络发送或接收图像、文件和其他媒体的问题，并完善图像识别。
  • 飞书频道：修复了新消息在传送滞后时被丢弃的问题。
  • Telegram：修复了 Markdown 渲染和删除附加文件的长摘要。
  • 文件回复：修复了删除随附文本和其他附件的文件回复，以及搁浅 client 工具卡的工具文件链接。
  • Docker：安装tzdata，使TZ环境变量生效。

📦 如何升级

  • 源部署：运行 cow update 进行单 click 升级，或拉取最新代码并重新启动。参见【升级指南】(https://docs.cowagent.ai/guide/upgrade)。
  • 桌面 client：检查更新并使用 client 内的一个 click 进行更新，或从 下载页面 获取最新版本。
