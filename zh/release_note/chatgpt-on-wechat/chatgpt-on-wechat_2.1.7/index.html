chatgpt-on-wechat 2.1.7

🌐 中文 | 中文

🗂 多个工作空间

代理不再绑定到单个目录 - 您可以设置多个项目工作区并为每个会话提供自己的工作区。在 Web 控制台和桌面 client 中均可用：

  • 多个工作空间：创建或打开任何目录作为项目工作空间；代理生成的文档、网页和代码都在那里创建和管理。
  • 每会话工作区：每个会话都绑定到其自己的项目工作区，因此并行运行的任务不会相互干扰。
  • 每会话模型：切换单个会话的模型；新会话从全局默认值开始。
  • 分组会话：会话列表按工作区分组，具有固定、重新排序、重命名和删除功能。
  • 共享系统资源：内存、技能和知识库仍然存在于系统工作区中（默认为 ~/cow）。

🔐 权限模式

会话现在具有自己的权限模式，该模式与工作区一起控制代理可以到达的距离：

  • 三个级别：只读、工作区写入和完全访问权限，为每个会话独立设置。
  • 默认模式：选择默认权限模式，新会话由此开始。
  • 可操作的拒绝：当工具调用被阻止时，提示为 clickable，因此您可以当场调整权限。

<img src=“https://cdn.jsdelivr.net/gh/zhayujie/cowagent-assets@main/screenshots/en/web-console-access-mode.png” 宽度=“600” />

🖥 台式机 Client

  • 语音输入：聊天输入中的语音按钮可将您所说的内容直接转录到框中；语音识别和合成还可以与自定义提供程序和模型配合使用。谢谢@chimyves（#3052，#3050）
  • 保留草稿：离开聊天页面并返回时不再丢失未发送的文本和附件。谢谢@chimyves (#3040)
  • 登录时启动：系统设置中的新切换，默认情况下关闭。
  • 启动诊断：当后端无法启动时，client 会报告实际出现的问题，而不是一般错误。
  • 日志下载：运行日志页面可以下载日志文件，本地上传获得重试和更清晰的错误。

下载：【CowAgent桌面版】(https://cowagent.ai/download/)

文档：桌面 Client

🔔 任务通知

当代理运行完成或失败时，Web 控制台和桌面 client 都会发出通知（带有声音），因此您可以摆脱冗长的任务：

  • clients：桌面上的操作系统通知、Web 上的浏览器通知 - 仅当窗口未聚焦时。 Clicking 将带您返回到会话。
  • 未读徽章：Web 选项卡在隐藏时显示未读计数，切换回来后会清除。
  • 单独的开关：通知和声音是两个独立的开关，默认情况下均处于打开状态。自己取消任务不再触发失败通知。

谢谢@chimyves（#3056，#3055）

🤖 模型更新

  • 新型号：glm-5.3、qwen3.8-max、gemini-3.7-flash 和 gemini-3.6-flash，每个均设置为其提供商的默认值。
  • 合并的配置页面：Web 控制台将模型页面折叠到配置中，分为基本选项卡和模型选项卡，因此跳跃较少。
  • 调用修复：修复了 GLM-5.3 的强制思维，以及某些 DashScope 模型的路由和基本 URL 处理；自定义模型现在显示在会话模型选择器中。

🛠 改进和修复

  • 图像显示：修复了知识文档内的本地路径图像和相对路径图像不渲染的问题；在桌面上，clicking 聊天或文档中的图像可将其缩放到位。谢谢@chimyves (#3046)
  • Windows 驱动器：修复了文件夹选择器未列出 Windows 上的驱动器的问题。感谢@CNXudiiandian (#3048)
  • Windows shell 指导：当 shell 命令在 Windows 上失败时提供更好的恢复指导。感谢@dajiao Huang (#3065)
  • 更干净的 IM 回复：客服人员在 IM 渠道上的回复不再带有思考内容。谢谢@LHMQ878 (#3044)
  • 计划任务：修复了一个在午夜失败而永远无法按计划恢复的任务（感谢@chimyves＃3054），并且计划任务被确认而不是运行。
  • 更快的第一条消息：简化了内存系统初始化，因此它不再阻塞会话的第一条消息，显着缩短了初始回复之前的等待时间。
  • 上下文修剪：修复了修剪上下文时未保存 AI 回复的问题。
  • 飞书频道：流媒体卡现在会跨回合累积文本。
  • Docker：config.json 通过 COW_DATA_DIR 安装进行容器升级。

📦 如何升级

  • 源部署：运行 cow update 进行单 click 升级，或拉取最新代码并重新启动。参见【升级指南】(https://docs.cowagent.ai/guide/upgrade)。
  • 桌面 client：检查更新并使用 client 内的一个 click 进行更新，或从 下载页面 获取最新版本。
