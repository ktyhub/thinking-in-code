chatgpt-on-wechat 2.1.2

chatgpt-on-wechat 2.1.2

🌐 中文 | 中文

💬 Web 控制台改进

此版本向 Web 控制台添加了多项可视化管理功能，因此可以在 UI 中完成更多配置，而无需编辑文件：

  • 计划任务管理：直接在控制台中查看、编辑、启用/禁用和删除任何计划任务。任务列表首先按启用状态排序，然后按下次运行时间排序。谢谢@HnBigVolibear (#2892)
  • 知识库类别和文档管理：知识库现在可以按类别进行组织，每个类别下的文档在 UI 中进行管理。感谢@yangziyu-hhh (#2893)
  • 多个自定义模型提供程序：配置多个兼容 OpenAI 的提供程序，并使用单个 click 切换活动提供程序，与现有配置完全兼容。谢谢@kirs-hi (#2877)
  • 会话重命名：手动重命名会话以区分并行任务（#2897）
  • Bash 流输出：长时间运行的 Bash 命令现在实时流式传输其进度。谢谢@yangziyu-hhh (#2879)

🧬 自我进化改进

在上一版本中引入的自我进化的基础上，该版本进一步完善了它：

  • 降低触发阈值：默认审核阈值降低，因此日常协作更快转化为改进
  • 无并发评论：当单轮运行时间较长时，空闲评论不再错误触发，避免干扰活动对话
  • 更好的复习总结：细化了总结提示，保持总结简洁，提高信息密度，并以对话语言输出

🤖 新型号

  • kimi-k2.7-code：添加并设置为默认Kimi模型，也可以使用kimi-k2.7-code-highspeed
  • glm-5.2：添加并设置为默认 GLM 模型

文档：型号概述

🏢 WeCom 智能机器人回调模式

WeCom 智能机器人通道在现有长连接旁边添加了 HTTP 回调模式，因此无法保持长连接打开的部署仍然可以可靠地连接：

  • 模式切换：通过wecom_bot_mode在websocket（长连接）和webhook（回调）之间切换
  • 加密传输：回调模式完全支持URL验证、消息解密和被动回复加密
  • 稳定性修复：修复了回复中断、流过早终止和临时图像文件泄漏的问题

感谢@6vision (#2896 #2869)

文档：WeCom 智能机器人

🔒 安全强化

  • 视觉工具 SSRF 保护：在解析图像 URL 之前验证目标地址，阻止对内部、环回和云服务器元数据端点的请求。谢谢@kirs-hi (#2886)
  • Web 获取 SSRF 保护：web_fetch 在获取之前验证目标地址并重新验证每个重定向跃点，防止重定向绕过检查到达内部地址。谢谢@christop (#2900)
  • 技能安装路径遍历防护：安装技能时验证路径，防止恶意技能名称通过路径遍历escaping skills/目录写入未授权位置。谢谢@kirs-hi (#2886)

🛠 改进和修复

  • CLI 自重启：添加了 cow self-restart 命令，以便代理可以重新启动自己的进程
  • Windows兼容性：将牛CLI目录保留到用户PATH；修复了 python -c 长命令超出 cmd.exe 长度限制的问题；避免在安装过程中从源代码构建 greenlet
  • 自定义角色：角色插件支持通过roles/*.json下的独立提示文件进行自定义。谢谢@sufan721 (#2891)
  • 稳定性修复：修复了 /cancel 上的 KeyError 和图像压缩中的无限循环（感谢 @kirs-hi #2888）
  • 安装改进：更新了启动脚本和默认配置；修复了 ASR/TTS 默认值、自我演化标志和安装挂起
  • 视觉工具稳定性：增加了视觉工具超时和 max_tokens
  • 记忆蒸馏：删除了深梦蒸馏中的输出长度上限，以避免截断大的 MEMORY.md

📦 升级

源代码部署可以运行 cow update 进行一 click 升级，或者提取最新代码并手动重新启动。详情请参见【升级指南】(https://docs.cowagent.ai/guide/upgrade)。
