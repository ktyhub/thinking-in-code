chatgpt-on-wechat 2.2.1

🌐 中文 | 中文

📁 文物

新的 Artifacts 页面汇集了在 Web 控制台和桌面 client 中的对话中创建的文件：

  • 自动收集：您的特工创建的文档、网页、图像和视频会自动显示在所有特工的一条时间线上的工件中。
  • 预览和回溯：按类型或代理进行过滤、搜索、就地预览，然后跳回到生成文件的对话（感谢 @rudycelekli #3732）。
  • 固定和管理：固定、重命名或删除工件；对话中的文件卡可将您直接带到 Artifacts 中。 Artifacts 页面默认隐藏，可以在菜单编辑器中打开。

相关文档：Web 控制台 - 工件

🧭 自定义菜单和控制台改进

  • 自定义菜单：自定义 Web 控制台和桌面 client 中菜单项的组、顺序、名称、图标和可见性，具有一种共享配置；工件和 Web 链接可以添加为菜单条目。请参阅自定义菜单。
  • 令牌使用情况：每个回复都会显示该轮实际使用的令牌，包括缓存命中。谢谢@Harbor404 (#3440)
  • 美人鱼图：美人鱼代码块可以切换到渲染图，具有缩放和全屏功能。谢谢@akushonkamen (#3620)
  • 更快的长会话：包含许多工具调用的长会话打开速度更快。
  • 修复：新的会话标题不再丢失，默认代理上的会话操作不再失败（感谢@6vision #3625、#3617）；现在保存在一起的设置全部生效，并且工作区文件保存在它们所属的代理下（感谢@aniruddhaadak80＃3454，＃3488）。
  • 可折叠侧边栏：Web 控制台侧边栏可以折叠成图标栏。

🔌 打开代理聊天 API

现在可以通过标准聊天 API 获取代理，因此您可以连接第三方 clients 或直接从您自己的系统调用代理：

  • 开关和密钥：打开API并在Config页面上的一个click中生成API密钥；当 API 关闭时，该密钥被保留。它还可以通过配置文件或环境变量启用（感谢@AaronZ345 #3068，@Bdysj #3342）。
  • 代理商及型号选择：选择agent_id的代理商和model的型号；如果没有模型，则使用 Agent 的默认模型。
  • 多轮对话：默认情况下，呼叫者发送完整的消息历史记录；使用 conversation_id，服务器会保留历史记录，并且只需要发送最新的消息。
  • 完整输出：流式和非流式响应，包括推理、令牌使用和工具调用跟踪（感谢 @AaronZ345 #3068、@c020627 #3545、#3588）。

相关文档：聊天API

📐 提示缓存和上下文成本

  • 克劳德提示缓存：系统提示、工具定义、对话前缀都会被缓存，大大提高缓存命中率，降低令牌成本和延迟。缓存生命周期可通过 claude_cache_ttl 配置。
  • 修剪后的余量：修剪上下文现在会留下余量，因此前缀在接下来的几轮中保持不变，并且长时间会话会继续命中缓存。
  • 预算更改立即应用：对上下文预算和最大步骤的更改立即应用于正在运行的代理，而无需清除会话。
  • 压缩中保存的工具记录：压缩轮次保留其工具调用的摘要，因此模型不会弥补结果（感谢@tsumon＃3634）。
  • 修复：压缩期间到达的消息不再丢失，并且更准确地清理孤立的工具结果（感谢@c020627 #3518、@rudycelekli #3652、#3653）。

🤖 模型能力

  • Claude 扩展思考：在长时间思考期间连接保持打开状态，当输出停止时，会以较低的思考努力重试请求。
  • 自定义标头：自定义模型提供程序支持 headers，并支持 OpenCode Go。
  • 模型发现：编辑模型列表时，可以自动从提供者获取可用模型。谢谢@Harbor404 (#3441)
  • 推理内容：支持reasoning和thinking字段，并且未闭合的<think>标签不再切断回复（感谢@a1094174619＃3601，@fly0sheep-1734＃3538）。
  • 后备模型：后备模型在每回合开始时重置，而不是继续使用。
  • OpenAI：改进了对响应 API 和流响应的处理（感谢 @rudycelekli #3659、#3660、#3661、#3663、@aniruddhaadak80 #3486）。
  • 模型列表：修复了并发编辑相互覆盖、自定义主模型不生效以及功能标签匹配的问题（感谢@rudycelekli #3577、#3662、#3666、@aniruddhaadak80 #3501）。
  • 其他提供商：修复了与 MiniMax、ModelScope、百度 ERNIE 和 Azure DALL·E 的兼容性问题（感谢 @aniruddhaadak80 #3464、#3476、#3479、#3507、#3512、@rudycelekli #3678）。
  • 错误处理：不再重新发送被拒绝的请求，更准确地识别错误，并且上下文使用情况显示真实的令牌计数（感谢@c020627 #3442、#3443、#3445、@aniruddhaadak80 #3505、@6vision #3624）。
  • 图像：图像生成保持原始格式和提示，macOS 上的图像理解不再升级图像（感谢 @aniruddhaadak80 #3503、#3504、@rudycelekli #3568）。
