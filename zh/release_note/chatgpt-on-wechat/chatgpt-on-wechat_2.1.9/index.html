chatgpt-on-wechat 2.1.9

🌐 中文 | 中文

这是 2.1.8 多 Agent 版本 的改进版本，在此基础上进行了一系列跨多 Agent 协作、模型功能和渠道集成的改进和修复。

🤝 多代理体验

使用多代理团队进一步完善：

  • 多代理会话选择：会话中多代理选择器添加了一个主要代理标记，可以清楚地将主要代理与成员分开，同时简化单代理设置中的视图。
  • 协作修复：修复了在多代理组聊天中从非主导代理委派任务时出现的故障，现在可以正确识别成员代理。
  • 成员代理图像渲染：修复了非默认代理生成的图像无法在 Web 控制台和桌面 client 上渲染的问题。
  • 群聊入口：桌面团队页面添加群聊入口，因此您可以直接从代理团队启动群聊。

📡 渠道整合修复

修复了控制台通道启动/停止路径上的关键问题，以实现更稳定的通道集成：

  • 桌面频道集成修复：修复了无法在桌面 client 中启动频道的问题。
  • 通道停止修复：修复了通道停止流期间丢失的 app_module 查找，该查找导致断开连接错误（#3141 引入的回归）。
  • QQ通道重连：修复QQ通道静默WebSocket断开后不重连的问题；现在它会自动重新连接。

🤖 模型能力

  • 模型列表配置：模型提供者现在可以配置模型列表，设置模型名称、模型类型、上下文窗口、最大输出等。谢谢@alanyz106 (#3146)
  • 多个后备模型：当主模型失败时，CowAgent 现在依次尝试有序的后备链，替换之前的单一后备模型。谢谢@alanyz106 (#3125)
  • 回退凭据修复：修复了回退期间的凭据解析，现在由实际路由到的提供程序而不是全局配置来解析凭据。谢谢@alanyz106 (#3142)
  • 新图像模型：添加了 gpt-image-2.5-flare 和 gpt-image-2.5-sunburst。谢谢@cowagent (#3140)

🛠 改进和修复

  • 配置文件容忍：容忍config.json中的UTF-8 BOM，并停止登录前401轮询以避免登录前的无效请求。
  • 图像生成修复：
    • 修复了百度 Ernie IMAGE_CREATE 在不受支持时崩溃的问题，现在改为返回错误消息（感谢 @c020627 #3144）。
    • 修复了中途回复重试未正确递归到发送逻辑的问题（感谢@c020627 #3151）。
  • 语音修复：通过首先将 Silk 解码为独立的 wav，然后重新编码为 mp3，修复 Silk 语音转码，避免覆盖源文件（感谢 @c020627 #3149）。
  • 媒体 URL 分类：从解析的 URL 路径确定媒体类型，修复错误分类的媒体链接（感谢 @c020627 #3150）。
  • 百度翻译：修复了百度翻译在所有重试失败后不报告 API 错误的问题（感谢 @c020627 #3147）。
  • 后台命令检测：将 run_in_background 限制为长时间运行的进程，防止任务过早标记为完成。
  • 工具输出截断：当保留的行被部分截断时，正确报告基于字节的截断原因（感谢@c020627 #3137）。
  • 网络移动布局：改进了移动设备上的控制台布局。
  • 桌面 client：修复了多代理团队菜单不显示的问题。

📦 如何升级

  • 源部署：运行 cow update 进行单 click 升级，或拉取最新代码并重新启动。参见【升级指南】(https://docs.cowagent.ai/guide/upgrade)。
  • 桌面 client：检查更新并使用 client 内的一个 click 进行更新，或从 下载页面 获取最新版本。
