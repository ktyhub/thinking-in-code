Cherry Studio 2.2.0 - 技能市场、通知和代理运行时

✨ 新功能

  • [市场] 在一个市场中浏览技能目录、外部技能来源、代理模板和 MCP 资源，并提供指导安装和集中的 MCP 和技能管理。
  • [通知]侧边栏旁边的新通知抽屉收集任务结果和官方公告，并以您的语言显示未读指示器、回复预览和公告。
  • [计划任务] 计划任务现在有一个专用的侧边栏页面，其中包含任务对话、分页运行历史记录以及已完成或错过的任务的管理。重复的设置页面已被删除。
  • [Cherry Cloud] 订阅使用情况和每月配额显示在“设置”和帐户面板中，并带有计划徽章、订阅入口点、输入上方的配额通知以及订阅生效时的通知。
  • [选择助手]询问代理和代理绑定操作会为所选文本打开专用代理窗口。窗口可以折叠成胶囊，遵循自动关闭规则，并在主窗口中继续会话。
  • [代理] 新代理默认为 Pi Durable 运行时，它本机保留会话并独立流式传输后台子代理。会话可以在已完成的检查点分叉，同时保持独立状态。
  • [代理] 从代理配置中查看和编辑代理内存。
  • [代理] 会话详细信息在紧凑的卡片中显示分组的子代理、任务进度和上下文使用情况。
  • [代理] 现在编辑并重新发送会替换消息并删除其后的所有内容，而无需创建另一个历史版本。文件未恢复；首先分叉以保留原始对话。
  • [聊天] Click 消息上的分支计数器可在备用回复之间跳转，并在切换器中进行预览。
  • [聊天] 生成的图像可用作接受图像输入的模型的参考。
  • [绘画] GPT 图像 2.6 Flare 和 Sunburst 支持场景复杂性和动画 GIF 输出，ComfyUI 工作流程可以使用附加的输入图像。
  • [模型] 添加了带图像输入的 LongCat 2.5 和混元 4，以及 Qwen 3.8 Flash Next 的推理控制控件。
  • [文件] 将文件或文件夹本身从代理文件窗格复制到系统 clipboard。
  • [注释] 将选定的对话文本保存到注释中，并从聊天输入中用@引用注释。
  • [翻译] 将完成的翻译复制为全长 PNG 图像。
  • [导出] 将 MCP 服务器配置导出为 JSON，并将多个助手导出为一个文件。
  • [技能] 选择将哪些托管技能导出到 ~/.agents/skills 以供外部代理使用。
  • 【快捷键】数字快捷键切换对话和选项卡，新增快捷键切换助手和主题；一切都可以在“设置”中自定义。
  • [对话] 在确认命名项目后，从列表、更多和历史菜单中永久删除对话，并从列表和组菜单中删除所有者。
  • [Markdown] 响应中的裸图像 URL 现在呈现为内联图像。
  • [小应用程序]目录中有新的创意和生产力站点，更多菜单可以重新启动小应用程序。
  • [HTML 工件] 从 HTML 工件的内联源工具栏中复制其源代码。

💄 改进

  • [聊天] 重新生成可在用户消息下方使用，并使用当前选择的模型。
  • [聊天]第一回合开始出现对话锚点；单独的侧面导航工具栏已被淘汰，取而代之的是底部箭头。
  • [代理] 上下文使用情况报告运行时容量、估计类别和跨运行时一致的资源，包括子代理。
  • [代理] 任务运行时切换权限模式适用于其下一个工具调用，而不是等待下一条消息。
  • [代理] 计划和目标模式可用作明确的快速面板操作，并且禁用不支持的历史操作。
  • [UI] 上下文菜单快捷方式呈现为紧凑键帽，调整手柄大小使用中性颜色，并且 clipped 字母下降部分已修复。
  • [文件预览] Word 预览适合窗格，更多文件类型显示正确的图标和标签。
  • [型号] Qwen AI Platform 和 Qwen Cloud 品牌、链接和默认 API e
