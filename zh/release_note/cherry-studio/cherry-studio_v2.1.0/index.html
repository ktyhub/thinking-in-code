座席和聊天助理可以使用内置浏览器，并以动画指针显示座席操作。代理可以查找页面元素、在页面更新后恢复它们、检查控制台和网络活动以及使用网站 WebMCP 工具。还支持浏览历史搜索、浏览器数据导入以及单独的历史记录或缓存清除。 - [Office] 添加办公转换技能：座席可以将工作表范围、文档段落、PDF 页面和幻灯片形状提取到新文件中。 - [选择] 打开“选择区域”以选择工作表范围、Word
