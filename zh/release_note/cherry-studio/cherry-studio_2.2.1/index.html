Cherry Studio 2.2.1 - 远程任务、搜索提供程序和代理修复

✨ 新功能

  • [任务] 远程 clients 可以发现计划任务结果对话并查询任务计划、运行历史记录和有限摘要。清理运行记录后，任务对话仍然可发现。
  • [型号] Rapid-MLX 可作为内置、无钥匙本地提供商提供。
  • [Web 搜索] 添加了 SerpKite 和 StepFun 关键字搜索提供程序，Exa 现在可以通过其 Contents API 获取 URL 的内容。
  • [文件] 将 Markdown 文件（.md、.markdown、.mdx）拖放到应用程序窗口中会在只读预览中打开它。
  • [代理]系统和全局包安装现在要求在正常模式下获得批准并在完全访问下运行，而不是在每种模式下都被阻止。
  • [代理] 代理和助理可以使用上传的图像作为他们的头像，显示在目录、选择器、对话、消息标题和工作选项卡图标中。现有的表情符号头像没有变化。
  • [代理] 工作区和代理组可以固定到顶部固定部分，同时其任务保持可扩展状态。
  • [代理]计算机使用呼叫显示他们操作的应用程序，会话详细信息显示相同的应用程序图标。
  • [Agent] 子代理调用可以命名提供者和模型，子任务行显示请求的模型。
  • [作曲家] 启用 Markdown 输入渲染后，在聊天、代理和选择撰写栏中输入时可以实时预览 Markdown；当插入符号到达标记时，标记就会出现，并且发送的文本未更改。
  • [Composer] 在 Markdown 预览中，可以使用 Cmd/Ctrl+B、Cmd/Ctrl+I 和反引号将所选文本设为粗体、斜体或内联代码。
  • [Composer] 在 Markdown 预览中，围栏代码块呈现为突出显示的代码区域，使用 Enter 插入换行符、制表符缩进、自动括号配对以及变量或快捷方式保留在围栏内。
  • [浏览器] 内置浏览器中的新选项卡可以从空白页面、上次打开的页面或自定义 URL 开始。
  • [知识] OpenDocument（.odt、.odp、.ods）和RTF（.rtf）文件可以添加为知识源。
  • [API 网关] CherryAI 订阅模型可使用登录帐户的配额通过网关向外部 clients 和 Code Mate 使用。

💄 改进

  • [代理] Pi 和 Pi Durable 使用其运行时的本机压缩并保留提供程序错误详细信息。
  • [代理] 会话详细信息列出代理正在控制的应用程序及其状态和停止操作。
  • [聊天] 分支图定位活动分支节点，并且可以滚动平移。
  • [模型] 推理努力滑块跟随平滑拖动，确定努力水平，并遵循简化运动设置。
  • [模型] 模型选择器中截断的模型名称在悬停时显示全名，并且模型详细信息卡不再 clips 它们。
  • [计划任务] 加载历史记录时锚点导航保持对齐，失败的运行摘要会在工具提示中显示错误详细信息。
  • [文件] 文件列表和网格在名称工具提示中显示每个文件的源路径，以便区分同名文件。
  • [提示波兰语] 显示默认模型及其设置的链接，并区分超时、丢失模型、空响应和提供程序故障。
  • [反馈] 现在可以选择将诊断信息附加到问题报告中。
  • [macOS] DMG 安装程序具有新的背景和更大的居中拖动到应用程序布局。
  • [助手] 英文默认助手现在名为“Cherie”。
  • [UI] 扩展的通知堆栈不再是 clip 的影子。

🐛 错误修复

  • [代理] Pi 和 Pi Durable 代码模式中的嵌套 shell、文件和工件工具结果将再次显示，包括重新打开对话后。
  • [代理] 没有明确超时的 Pi shell 命令不再无限期等待。
  • [代理] 关闭会话会首先中断 Claude 的工作，并且中断的 Claude 代码不再显示“未请求响应”。占位符。
  • [代理] 在 /compact 边界后分叉并编辑和重新发送工作，并且分叉不再拒绝具有空白框架线的健康的克劳德会话。
  • [特工]步骤面板不再显示完成情况
