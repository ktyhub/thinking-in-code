Chromium 的合成器来实现与您在屏幕上看到的内容相匹配的像素完美输出。 - [翻译] 使用丰富的 Markdown 格式渲染流输出。 🐛 错误修复 - [模型] 修复拒绝 Cherry Studio 自动归因标头的自定义模型提供程序。 - [模型] 修复启用自定义采样设置时 Moonshot Kimi K2.5+ 请求失败的问题。 - [模型] 修复当选择不支持的推理工作时 Kimi K3
