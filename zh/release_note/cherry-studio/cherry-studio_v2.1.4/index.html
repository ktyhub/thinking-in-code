Cherry Studio 2.1.4 - 新型号、设备连接和错误修复
✨ 新功能
  • [设备连接] 通过可访问的 LAN 或外部配置的 VPN 网络进行连接，支持 IPv4/IPv6、自动地址优先级以及通过网络接口手动选择。需要采取的行动：更新到兼容的移动应用程序以保存和验证其他地址并扫描包含超过 16 个地址的配对代码。
  • [消息] 添加导出到多选操作栏：将选定的消息导出为 Markdown、Word 或 Notion/Yuque/Obsidian/Joplin/Siyuan。
  • [型号] 添加 GPT-6.1 Sol 对 OpenAI 和 OpenAI Codex 的支持，包括定价和推理设置。
  • [模型] 添加 Claude Sonnet 5.5 和 Opus 5.5，具有思维控制和本机网络工具资格。
  • [型号] Claude Code 提供商现在提供 Claude Opus 5.5（带快速模式）和 Claude Fable 5.1。
  • [模型] 添加 MiniMax M3.1 Flash 预览，具有五个推理能力级别。
  • [ComfyUI] 添加本地ComfyUI图像提供程序：选择保存的工作流程作为模型并从绘画页面生成。
  • [Launchpad] 内置应用程序图块现在使用主题感知卡表面。 🐛 错误修复
  • [Agent] 修复了当之前的 Claude Code 进程退出缓慢时 Agent 会话变得不可用的问题。
  • [代理] 修复新创建的远程代理会话中重复的消息冲突和过时的标题。
  • [代理] 修复编辑和重新发送时的检查点错误消息 — 现在清楚地解释了该问题。
  • [Agent] 修复成功删除后列表中残留的 Agent 会话消息。
  • [代理任务] 回收未使用的心跳工作区以及孤立的计划。
  • [聊天]修复使用错误的提供程序重新生成 - 现在使用作曲家选择。
  • [聊天]修复多模型组重试时使用助手的默认模型而不是回复自己的模型。
  • [聊天] 修复通过存档撤消恢复的对话在打开时跳转。
  • [聊天]修复工具调用面板不使用与思考面板相同的视口感知高度。
  • [聊天] 主题聊天不再内联浏览器工具模式，减少了数千个令牌的开销。
  • [聊天] 仅将打开回复的标签块视为内联推理 - 答案中的文字标签不再截断内容。
  • [知识] 修复 MCP 包 (DXT/MCPB) 安装时路径仅大小写或 Unicode 形式不同。
  • [知识] 修复当页面路径不是 ASCII 时捕获的以百分比转义命名的 URL 快照。
  • [知识] 记住保存对话框最后使用的知识库。
  • [技能]修复了 Skills.sh 安装，以便将技能存储在 .gemini/skills/、.claude/skills/ 或 .agents/skills/ 下。
  • [技能] 修复技能 ZIP 导入时路径仅大小写或 Unicode 形式不同的问题。
  • [翻译]修复美人鱼图在翻译过程中未被保留和渲染的问题。
  • [文件预览] 修复文件预览，将路径片段显示为点目录中或不带扩展名的文件的语言。
  • [文件预览] 修复 PDF 预览不渲染使用非嵌入 CID 字体的中文/CJK 文本的问题。
  • [文件图标] 修复 Windows 路径的文件图标 — 工件卡现在显示正确的图标。
  • [Markdown] 修复了聊天中的 SVG 使用之前渲染的 SVG 测量的尺寸进行渲染的问题。
  • [型号列表] 当搜索过滤器处于活动状态时，按型号顺序保留数字组名称。
  • [富文本编辑器] 从工具栏应用的格式现在保存到注释中。
  • [浏览器] 恢复沿浏览器侧边栏分隔符的整个高度调整大小。
  • [聊天布局] 首次运行时，文件和工件窗格使用较窄的 280 像素默认值。
  • [诊断] 修复基于 Claude Code CLI 的提供商的运行状况检查报告“未配置 API 密钥”。
  • [诊断] 显示诊断报告的状态链接、处理状态和本地历史记录。
  • [选择助手] 修复结果代码块未以较窄宽度换行的问题。
  • [选择助手] 修复 macOS 全屏关闭操作窗口后黑屏的问题。
  • [屏幕截图] 修复混合 DPI 多显示器布局上的 Windows 屏幕截图捕获。
  • [网页搜索] 修复当存在重复条目时 API 键轮换永远不会到达其他键的问题。
  • [OpenClaw] 修复当配置模式探测速度缓慢时误导性的“二进制不兼容”错误。
  • [Copilot] 通过选择 GPT-6 系列的响应 API 来修复 GitHub Copilot GPT-6 模型路由。
  • [DSH] 修复 Windows 管理的 DSH 临时目录清理并升级到 0.2.0-rc.2。
  • [Claude Agent] 将 Claude Agent SDK 升级到 0.3.284，并在简历中保留说明。
  • [Agent 创建] 从新代理运行时选项中删除 DeepSeek Harness；现有代理商仍受支持。
  • [文件系统] 修复 ls 工具报告空目录而不是丢失或非目录路径的错误。
  • [API] 修复了 OpenAI 兼容的流媒体，删除了无参数工具所需的 arguments 字段。
  • [HTML 预览] 修复滚动条在内容大小阈值处出现/消失时文本跳转的问题。
  • [计划任务] 保持多小时选择紧凑并支持可编辑、经过验证的 Cron 表达式。
  • [Composer] 现在，当富文本位于图像旁边时，复制的 Excel 单元格会粘贴为文本。
  • 【提供商设置】明确豆宝机型使用Volcengine Ark，并支持API基本URL。
  • [macOS] 修复了使用红色按钮关闭后主窗口无法在第一个 Dock click 上重新打开的问题。
  • [提供者] 保持模型提供者列表位置处于启用/禁用状态；在顶部显示新的提供商。 </详情>
