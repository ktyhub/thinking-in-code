<摘要>Release Notes</摘要>
Cherry Studio 2.1.10 - 文件评论、触摸重新排序和更新时间线
✨ 新功能
  • [代理文件] 对代理文件进行评论。在文本文件中，将鼠标悬停在一行和 click“+”（或跨多行拖动）以写入注释。在 Word、Excel、PDF 和 PowerPoint 文件中，选择一个部分并进行注释。每条评论都会作为带有其位置的芯片添加到消息中。
  • [更新] 在可折叠时间轴中查看跳过的稳定版本 release note；单版本更新直接显示他们的注释。 Markdown 脚注导航现在可以与反向链接一起正常工作。
  • [代理] 保存前在常规设置中测试代理连接，支持 PAC 代理/直接后备报告。
  • [触摸] 按住一行重新排序列表。行内的按钮不再开始拖动。选择助手设置现在在一个列表中显示启用和禁用的操作，并用分隔线分隔。 🐛 错误修复
  • [聊天]滚动包含代码块的对话时，消息列表不再跳回第一条消息。
  • [代理] 移动数据目录后，现有对话将正确恢复，并保留其历史记录。
  • [本地听写] 修复本地语音识别无声丢失长语音后半部分的问题。
  • [流]修复流重播与传入输出重叠时丢失或重复的响应文本。
  • [作曲家]问题面板中的选项描述不再被截断。
  • [右面板] 创建或切换代理任务时，浏览器侧边栏不再意外打开。
  • [代码块] 图表预览工具栏不再是 clipped。 Mermaid、Graphviz、SVG、LaTeX 和 ECharts 预览融入消息背景中。
  • [知识] 文件转换进度从0%开始，立即更新，而不是每5秒更新一次。
  • [对话列表] 午夜之后，最近的对话不再排序到底部。
  • [MiMo] 修复 MiMo 型号返回“不支持的型号”错误。 ⚡ 性能
  • [代码块] 使用代码块滚动对话时减少不必要的渲染工作。 </详情>
