Cherry Studio 2.2.3 - 对话排序、新模型和代理可靠性
✨ 新功能
  • [对话] 分组和排序现在是独立的。按上次更新、创建日期、名称（采用自然数顺序）或手动顺序排序，并保留现有的自定义顺序。
  • [代理] 将 DeepSeek v3 导出导入到自动创建的 DeepSeek 代理中，保留历史记录、分支、推理、搜索记录和可用附件。
  • [代理] 回复后会出现一个简短的下一个提示：按 Tab 接受而不发送，或按 Esc 忽略。可以在输入设置中关闭建议。
  • [Agent] 创建Agent时可以上传头像。
  • [代理] 自动命令批准现在使用共享风险规则解析 Bash 和 PowerShell，并在每个有风险的命令之前进行询问。批准卡显示请求的任务、工作目录和原因。 （所需操作：如果您依赖现有提示，请检查权限模式；不匹配的命令会自动运行，而强制拒绝仍然适用于完全访问。）
  • [浏览器] 对话侧边栏支持多个保留选项卡，具有统一的样式和上下文菜单，使用配置的主页，并以最后一页关闭。
  • [文件预览] PPTD 幻灯片现在可以在应用程序中预览，包括页面导航、缩放、缩略图、刷新和源视图。
  • [文件] 文件路径和带有行号的 Markdown 链接跳转到并突出显示预览中引用的行。
  • [文件] 文件选择对话框将在当前会话期间您选择的最后一个文件的文件夹中打开。
  • [聊天]添加了外观→消息首选项，“发送时滚动到最新消息”（默认打开）。
  • [聊天] 长的可交付文件列表显示前三个文件，并让您展开或折叠其余文件。
  • [聊天] Ctrl + 鼠标滚轮缩放界面，滚动时显示缩放级别，Ctrl+0 重置它。
  • [知识] URL 源同时接受多个链接（以换行符、逗号或空格分隔），单独添加每个有效 URL，并单独报告无效条目。
  • [绘画] 生成的图像显示模型和返回的尺寸，并以原始格式保存，而不是始终转换为 PNG。
  • [计算机使用] 全新的仅适用于 Linux 的“全局输入”开关（默认情况下关闭）可让代理控制共享鼠标指针和系统键盘。
  • [型号]新增GPT-6.2 Astra和Sol、Gemini 4 Carbon和Hydrogen带推理控件、腾讯混元4 Flash、Mistral Large 4推理控件。
  • [模型] DeepSeek 第一方成本估算现在使用工作日高峰和非高峰费率，同时保留自定义价格。 （需要采取的行动：如果您依赖于仅峰值估算，请检查当地成本估算。）
  • [模型] 启用的提供程序现在首先出现在模型服务列表中，并且主模型选择器可以以记住的对话框模式打开。
  • [市场] 精选技能可以按类别过滤，具有搜索和水平类别导航。
  • [Composer] 将复制的文件夹粘贴到代理对话中会添加文件夹引用，而不是失败的文件附件。
  • [导出] Obsidian 导出用生成它的模型标记每条助手消息。
  • [快捷方式] 数字快捷方式 (1–9) 在“设置”→“快捷方式”中有明确的“关闭”预设。
  • [语音] 识别模型现在有一个“关闭”选项，可以禁用本地听写，而无需删除已保存的语言或热键。
  • [代码 CLI] Qwen 代码 1.0 可以从其 GitHub 版本安装。
  • [App] 添加了捷克语 (cs-CZ) 语言支持。 🐛 错误修复
  • [聊天] 嵌套的可滚动内容（例如代码预览、编辑器和嵌入式工件）在消息列表滚动时独立滚动。
  • [聊天] 从“设置”→“存档”恢复的对话将以其消息而不是空对话打开。
  • [聊天] 中断的流式响应被报告为连接错误，并保留部分输出以供重试，而不是无效的 AI 响应。
  • [聊天] 多模型折叠选项卡再次显示每个模型名称，并可切换回紧凑选项卡。
  • [聊天] 超出模型上下文窗口的聊天请求恢复更可靠。
  • [注释] 用 [ … ] 和 ( … ) 编写的 LaTeX 在注释编辑器中再次呈现。
  • [聊天] 浏览器侧面板调整大小栏可沿其整个高度拖动。
  • [代理] 在工具调用之前或之间发出的助理文本在代理会话中再次可见。
  • [Agent] Pi Durable：停止使会话保持打开状态并暂停回复；退出后重新打开继续中断的回复或显示其真实结果；座席工作时发送的消息被保存并按顺序回复；撤回的消息被标记为“发送前已停止”，并带有“重新发送”和“编辑”。
  • [代理] 在回合运行时发送的消息会被确认并采取行动，而不是被默默地忽略。
  • [代理] 待审批的后台任务结束后将被清除，因此回复不再停留在“待处理”状态。
  • [代理] 模型选择的范围仅限于每个会话，因此更改一个会话不再更改同级会话。
  • [代理] 当 SDK 可以保留其上下文时，可以在工具重试或压缩后分叉或编辑 Claude 代码对话。
  • [Agent] 在“接受编辑”模式下，Claude Code 在运行升级的 Bash 命令之前会进行询问，而不是通过第一个单词自动运行它。
  • [代理] 代理会话历史记录在升级期间修复消息树，并防止对正在进行的交付进行编辑。
  • [代理] 当目录占用其持久存储名称时，代理将恢复，而不是因网络错误而失败。
  • [代理] 编辑和重新发送历史消息时，推理工作、服务层和快速控件保持可用。
  • [代理] 历史消息遵循代理的当前头像，并应用在创建过程中后期选择的头像。
  • [代理]选择助手：重复使用的窗口不再以完整对话尺寸打开，关闭的窗口不再留下杂散的胶囊，并且面板在活动应用程序上方打开。
  • [代理] 通过 HTTP 或进程内网关传递的代理请求保留协议元数据、Gemini 配置、生成的文件和延续状态。
  • [代理] 不可读的存储自动化工具结果将作为注释报告给模型，而不是中断对话。
  • [代理] NO_PROXY 不再包含在代理会话中破坏 Python HTTP clients 的括号内的 IPv6 或 IPv6 CIDR 条目。
  • [模型] 模型连接检查现在使用流式处理支持流式处理的模型，并检测不完整或失败的响应。
  • [模型] 不再将不支持的采样参数和处罚发送给提供商，并在请求覆盖后应用声明的采样范围。
  • [模型] 当架构包含 propertyNames 时，Gemini 工具调用不再失败。
  • [型号] 单个 Cherry Cloud 配额拒绝不再在计划配额保留的情况下锁定型号；服务器决定拒绝并显示其建议的等待。
  • [模型] CherryIN 保存的模型端点会自动从服务器刷新，同时在发现失败时保留本地值。
  • [模型] CherryAI 首先出现在付费订阅中，最后出现在没有付费订阅的情况下。
  • [模型] 没有 HTTP 状态的提供商请求拒绝将报告为请求错误而不是网络中断。
  • [模型] 使用统计数据恢复提供者缓存桶，本地计算的成本被标记为估计值。
  • [模型] OpenAI 兼容、vLLM 或 llama.cpp 模型上的代理会话报告请求超出上下文窗口的距离。
  • [模型] 中止的提供者转向现在会失败，而不是报告成功停止。
  • [文件] 文件类型图标离线渲染并在文件树、预览和附件中保持一致。
  • [文件] 文件树和预览保持最新状态，显示保存进度和失败，并支持范围刷新而不丢失本地草稿。
  • [知识] 添加 URL 对话框会立即拒绝非 http(s) 地址。
  • [知识] 自托管 MinerU 4.1 任务 API 解析受支持，而旧协议仍然有效。
  • 【反馈】问题报告再次包含最近24小时的日志、活动记录、聊天记录；各个连接开关被拆除。
  • [计划任务] 可以打开2.2.0之前记录的运行历史记录或被删除的对话并显示其存储的结果。
  • [技能] Cherry-only 内置技能不再导出到共享 ~/.agents/skills 目录。
  • [飞书]初始通道连接通过退避重试，而不是在握手失败后保持停止状态。
  • [UI] 空助手、代理和注释侧边栏说明它们是空的，而不是显示空白面板。
  • [特工]修复了后台子特工的特工会话每轮速度都会慢一些的问题。
  • [代理] 保留子代理速率限制错误详细信息，并显示 Pi 和 Pi Durable 任务的一致重试状态。
  • [代理] 减少子代理并行处理许多图像时出现的内存不足崩溃情况。
  • [Cherry AI]从服务器加载模型目录并显示登录、订阅或AMD授权要求；检测退市型号。内置 Qwen 现在需要 Cherry AI 登录（之前使用它的用户需要执行注销操作）。 💄 改进
  • [对话] 分组选项更加清晰，列表控件与对话和代理会话菜单中的历史记录和管理导航分开。
  • [代理] 服务层选择器解释了每个层的权衡，并显示保存的层何时不可用，并在可折叠的详细信息视图中提供特定于提供商的名称。
  • [代理工作区] 文件夹“打开方式”菜单现在列出了系统上注册的用于打开文件夹的每个应用程序，并带有系统图标，而不仅仅是内置编辑器和终端。
  • [UI] 品牌图标、小应用标签、设置布局、帮助、技能控制和市场视觉效果更加一致。
  • [UI]启动板和迷你应用程序图标使用一致的大小和角与刷新的暗模式图稿，文件树和列表中的嵌入滚动条与窗格边缘对齐。
  • [诊断] 当启用数据收集时，本机崩溃报告会自动上传到 Sentry。
  • 【数据升级】v1用户必须通过Cherry Studio 2.2.2迁移；符合条件的安装提供迁移版本的单 click 安装，而其他安装则保留直接平台匹配的下载。 （需要采取行动） ⚡ 性能
  • [代理] 具有许多图像或子代理的代理会话使用更少的主进程内存和 CPU；已完成的子代理被释放，并且持久历史记录被增量读取。
  • [代理] 恢复大型 Claude Code 会话并加载其历史记录使用更少的主进程内存。
  • [聊天] 流式响应和对话历史记录加载使用更少的对话快照副本。 </详情>
