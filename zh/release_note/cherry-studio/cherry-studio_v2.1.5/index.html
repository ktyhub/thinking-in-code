Cherry Studio 2.1.5 - 远程附件、通道和主要改进
✨ 新功能
  • [远程访问] 从配对的移动设备将图像和文件上传到远程代理会话，每个文件可恢复传输最多 1 GiB。
  • [频道] 添加WeCom和钉钉频道，包括二维码设置、座席对话、流式回复、通知和附件。
  • [MCP] 支持 MCP SDK v2，包括跨聊天和代理运行时的交互式请求、验证表单、取消和结构化结果。
  • [代理] 将 Pi 运行时升级到 1.0，并具有本机沙盒代码模式和 MCP 支持。所需操作：将自定义 Pi 脚本更新为本机代码模式 API。
  • [医生]系统医生获得了人工智能分析部分，可以读取诊断报告并提出可以应用和撤消的有限修复建议。
  • [设备连接] 通过特定于平台的下载、记住的进度和自动移动预览来改进移动设备入门。
  • [绘画] 最小化生成后的提示停靠，用鼠标滚轮缩放生成的图像，并在click上打开共享图像查看器。
  • [模型] 添加 Claude Haiku 5.5 支持，包括推理控制、更新的令牌限制、定价和 Claude Code 可用性。
  • [Composer] 当为当前聊天或代理会话启用 MCP 工具时，突出显示 MCP 工具栏快捷方式。
  • [Web 搜索] 添加自托管 Crawl4AI 作为 URL 获取提供程序，具有可配置的 API 主机和可选的承载令牌。
  • [Windows] 在主窗口和独立窗口中使用本机标题按钮，同时保留自定义标题栏和主题适应。
  • [更新] 当兼容的缓存安装程序可用时，启用本机差异下载以减少更新大小。
  • [文件预览] 通过触摸缩放、弹性 PowerPoint 幻灯片和更清晰的大小限制回退来改进文档预览。添加 WebView 兼容性以进行移动集成。
  • [存档] 恢复代理现在也会恢复其会话，并且存档的任务/主题行显示其所属的代理或助手。 🐛 错误修复
  • [代理] 修复在活动任务期间切换会话或关闭选项卡时浏览器工具超时的问题。
  • [代理] 修复了工具拒绝原因被误认为工具输出的问题——现在明确归因于用户的话。
  • [聊天] 修复中间响应失败，丢弃已经流式传输的内容 - 现在与错误一起保留。
  • [聊天] 修复上下文压缩进度未出现在助手消息中的问题。
  • [聊天] 修复水平多模型答案阻止向上滚动到较早聊天历史记录的问题。
  • [ComfyUI] 修复工作流程，每次运行时随机化种子渲染相同的图像。
  • [ComfyUI] 修复合作伙伴 (API) 节点在没有提供商的 API 密钥的情况下失败的问题 — 现在可以正确发送。
  • [ComfyUI] 修复了使用错误值转换的工作流程或因 no_prompt_node 而失败的问题。
  • [通知] 修复完成通知以显示主题或会话名称以及最终句子。
  • [通知] 当所有通知首选项关闭时清除 macOS Dock 徽章。
  • [Markdown] 停止将单段斜杠运行（如 /jX_s）链接为文件路径。
  • [WebView] 将本机用户代理限制为 Google 登录，为 AI Studio 和其他请求保留经过清理的 UA。
  • [开放响应] 修复当兼容网关发出标记的 SSE 保持活动增量时对话失败的问题。
  • [备份] 修复当目标是 Windows 驱动器根目录时本地备份失败的问题。
  • [频道]修复因保存的微信凭证中格式错误的用户 ID 导致的频道设置渲染错误。
  • [工具] 修复名为 constructor 或 toString 的自定义命令行工具被错误分类为内置代码 CLIs。 </详情>
