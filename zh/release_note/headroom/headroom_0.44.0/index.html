  • 代理： 在 /statscentre_requests 中公开每个请求的 cost_usd (#1079) (#1565) (84cedbf)
  • 代理： 在 /health 和 /metrics 中公开共享的 Redis 存储可用性 (#4578) (602ca65)
  • 代理： 每个 client 对话轮流挂钩一个对话 ID (#4496) (94a99ed)
  • 代理： 在仪表板中将 DeepSeek 报告为其自己的提供商 (#2565) (9ad16a7)
  • **代理：**向经过令牌验证的调用者显示每个请求/统计元数据 (#4168) (9b2dec5)
  • 代理： Anthropic Cloud 和本地 oMLX 的统一多上游路由 (#4597) (f896161)
  • ** savings:** 在历史检查点中携带累积的实际output_tokens (#2921) (8388ff5)
  • **换行：**为 Factory Droid 添加 headroom wrap droid (#4143) (bb8d18a)
  • wrap: 使 Serena 代码内存 MCP 选择加入 (#4509) (2649835)

错误修复

  • asgi: 当 client 断开连接时停止缓冲 (GHSA-mc2f-vg4v-2fh4) (#4701) (c6d7081)
  • 信标： 在顶级密钥下方强制执行白名单 (#4691) (456288d)
  • 二进制文件： 在 HEADROOM_BINARIES_ALLOW_UNVERIFIED=0/false 上关闭失败 (#3218) (da6d973)

  • 缓存： 将学习到的 TTL 上限舍入到整秒 (#4710) (13347e3)
