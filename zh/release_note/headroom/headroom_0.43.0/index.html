headroom v0.43.0

0.43.0 (2026-11-05)

⚠ 重大变更

  • mcp: 将 MCP 服务器移植到 SDK 2.x (#4603)

特点

  • ccr: 在流式聊天完成时回答 headroom_retrieve (#4631) (31dcaf4)
  • mcp: 将 MCP 服务器移植到 SDK 2.x (#4603) (ee2252a)
  • 插件： Claude Code、Codex、Copilot 和 Skills.sh 的余量技能 (#4533) (66e1467)
  • 节省： 显示代理在净空节省中的模型路由节省 (#4304) (aaab338)

错误修复

  • [BUG] 一次图像压缩调用超时会重置共享工作池并影响并发请求 (#4528) (e9bcfe7)
  • [BUG] DirectMem0Adapter.search_memories 调用删除了 mem0 搜索 API (#4518) (d9cee45)
  • [BUG] 保存的请求指标丢失其缓存优化字段 (#4584) (b4c9bdf)
  • [BUG] 易失性 SQLite 指标存储在第一次保存之前丢失其架构 (#4633) (d8ff0fe)
  • 添加有关适用于 README.md 的信息 (#1592) (4d34680)
  • backends/litellm: 在文本块上保留 cache_control 以进行基岩提示缓存 (#4565) (23a5bb1)
  • **后端：**转发标准 service_tier 参数 (litellm + anyllm) (#2468) (62cc38a)
  • **缓存：**在逐出之前构建语义条目，以便失败的嵌入保留活动条目 (#4581) (0d4c450)
  • 缓存： 将冻结前缀中没有文本的 tool_result 计为可重播 (#4523) (fba09f6)
  • **缓存：**因 SQLite 损坏而无法关闭，而不是在线删除存储 (#4361) (9801833)
  • 缓存： 替换时使配置的注册表实例无效 (#4363) (1bcdca2)
  • **缓存：**命名空间 SemanticCacheLayer 按提供程序、模型和元数据 (#4473) (99cdaaf)
  • 缓存： 在缓存重放上保留 OpenAI 工具块元数据 (#4334) (f1035ac)
  • **缓存：**范围路由器结果请求压缩策略 (#4590) (5d40fe7)
  • ccr: 仅缓冲本回合新标记的流 (#4607) (946a70c)
  • ccr: 保持主动扩展超出缓存前缀 (#4300) (b1f340e)
  • cli: 默认情况下启用代码感知压缩的文档 (#4616) (affd17c)
  • client: 当包装流关闭时关闭上游响应 (#4482) (3d8dcf4)
  • client: 遵守配置的缓存优化器启用 (#4501) (d4c0810)
  • client: 保留 Anthropic 创建流标志 (#4500) ([3910caa](https:/
