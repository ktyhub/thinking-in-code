ms-swift v4.6.0

ms-swift v4.6.0

#v4.6.0

JEV 支持（类型决策/系统 1）

  • 为 JEV 风格的决策模型添加了 decision 任务类型：该模型不是生成文本，而是在一次前向传递中返回每个问题的固定选项集 (choice / score / noul) 的校准概率。 (#10306)
  • 三个已发布决策模型的即用配方 - JEV-27B-VL、Clef 和 OmniJev - 涵盖训练、推理和 LoRA 合并/导出。任何 CausalLM 也可以使用 swift sft --task_type decision 进行转换。
  • 详细信息：决定（最佳实践） · 示例

新型号

  • MiniCPM5 (1B / 2B) — LLM 系列，具有基础和 SFT 变体，支持 vLLM 推理。
  • MiniCPM-V-4.7 (1B / 35B-A3B) — 支持图像和视频的视觉语言模型。
  • GLM-5.3-Flash — 智普AI GLM-5.3-Flash，支持视觉和视频。
  • DeepSeek-V4.1-Flash — Megatron-SWIFT 上的全参数 SFT 和 GRPO 加上 vLLM 推理。
  • Xing4.0-29B-A4B — MLA + MoE + mHC； LoRA 和全参数 SFT (DDP / DeepSpeed ZeRO-3)，具有 grouped_mm 专家加速 (~3.7x)。
  • MonkeyOCRv2 (S / B) — OCR 和文档理解模型。

新功能和兼容性

  • 通过 torchada 添加了 Moore Threads (MUSA) 后端。 (#10224)
  • 兼容性：Transformers ≥ 5.17 内核代理、vLLM 0.28+ 并置权重同步/唤醒 API 以及 Transformers 5 下的 TRL 可选依赖项检查。（#9770、#10311、#10315）
  • 更新了 qwen4_exp / glm5_next MTP 示例，支持 GLM-5.3。 (#10219)

安全

  • 强化 WebUI 和推出：修复了未经身份验证的 RCE 和任意文件读取、推出端漏洞以及 GitHub Actions 工作流程注入。 （＃10209，＃10218，＃10226，＃10227）
  • 在请求体反序列化之前进行身份验证； weights_only=True 用于威震天检查点加载；下载安全修复程序。 （#10062、#10066、#10234、#10235）

训练和强化学习

  • SP、DPO、DAPO/CISPO/FIPO 和 GKD/GRPO 之间的损失和梯度对齐（包括 Liger 和离策略路径）；列表重新排序和部分梯度累积修复。 （#9977、#10100、#10104、#10116、#10130、#10144、#10185、#10244、#10285） -威震天和并行性：连续的 CP 令牌顺序、输出解包/打包 seq_acc/MoE aux 丢失中的环填充处理、mcore 检查点元数据。 （#10071、#10113、#10181、#10182、#10184、#10242）
  • 训练稳定性：ZeRO-3 在生成错误后挂钩、GaLore 检查点、LISA 初始化和层选择、SP 采样器选项、CPU 卸载激活视图。 （#10132、#10140、#10157、#10161、#10173、#10260）
  • RLHF 和推出：并置卸载/vLLM 唤醒排序、异步推出失败传播、IPC 存储桶确认、vLLM LoRA 元数据和本地教师适配器。 （#10092、#10107、#10109、#10207、#10231、#10232）
  • 嵌入和重新排序：DDP / Megatron DP、DP 度量收集、WeMM 重复转发下的 InfoNCE 负采样和梯度补偿。 （#10059、#10068、#10069、#10081、#10088、#10091、#10150）

推理和部署

  • 修复了 qwen-omni vLLM 推理、帧采样后的视频元数据处理以及 video_second_per_grid 张量处理。 （#10168、#10274、#10330）
  • infer：适配器缓存和异步请求隔离、独立事件循环线程、流式请求完成、工作错误传播、SSE 心跳。 （#10080、#10086、#10093、#10094、#10134、#10135、#10177）
  • MP+DDP 的设备映射内存分辨率； CLI 列表值序列化；毛坯 LOG_LEVEL / LOCAL_RANK 处理； WebUI 默认端口。 （#10210、#10217、#10245、#10246、#10248、#10292）

模板、代理和工具调用

  • GLM / glm4_5 / Qwen3-Coder / kimi_k25 / ReAct / Seed-OSS、OpenAI 和 Anthropic 工具结果对齐以及 JSON-Schema 类型联合解析的工具调用正确性。 （#10169、#10174、#10270、#10271、#10284、#10293、#10294、#10299、#10300、#10304）
  • 修复了 gemma4、marco_o1、Qwen3-VL 视频、Janus、拒绝响应放置和工具响应名称的模板。 （#10120、#10127、#10171、#10190、#10199、#10203、#10230、#10238）

数据和WebUI

  • 数据集管道：跨等级缓存竞赛、Arrow 工具模式保真度、流式打包工作器检测、版本化地图缓存、元数据缓存失效、媒体分片。 （#10083、#10121、#10125、#10159、#10160、#10162、#10297、#10298、#10301）
  • WebUI：命名数据集现在列出其中心 ID。 (#10119)
  • 模型加载：Idefics3 AutoModelForImageTextToText、DDP 下的 MiniCPM 位置缓存、MiniCPM-o 填充偏移、seq-cls 元数据往返。 （#10187、#10202、#10228、#10253）

性能

  • 向量化环注意 LSE 提取和打包 zigzag CP 重建；用于单列组的更快的数据加载器；批量推出/教师-API 度量收集。 （#10064、#10082、#10239、#10240、#10241）

文档

  • 添加了 AGENTS.md 和贡献指南（人工提交的 PR；首次贡献者和人工智能辅助贡献者）。 （＃10339，＃10347）
  • 更新了硬件和 docker-image 文档；固定奖励示例、部分损失权重文档和页内锚点。 （#10067、#10118、#10170、#10172、#10188、#10233）
