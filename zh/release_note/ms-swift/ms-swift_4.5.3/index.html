ms-swift v4.5.3

修订 发布时间2026年9月8日 来源modelscope/ms-swift 英文原文

ms-swift v4.5.3

新型号

  • Qwen3.8-Flash-Next，一个多模态 MoE 模型，总参数为 125B（每个 token 激活约 6B，包括 51B N-gram 嵌入表）。它将混合 GDN + Qwen 稀疏注意力 (QSA) 主干、超连接和主机可卸载的 N-gram 表与本机 262K 上下文相结合。支持威震天训练。最佳实践：Qwen3.8-Flash-Next-Best-Practice

  • deepseek-ai/DeepSeek-V4-Pro-0813

  • inclusionAI/Ling-3.0-tiny & inclusionAI/Ling-3.0-flash

  • XHToken/Spark-X2.5

  • lmms-lab/LLaVA-OneVision-2-8B-指示

  • iic/UEmbed-2B

  • 腾讯-混元/WeMM-嵌入

新功能

  • Megatron-SWIFT Muon 优化器支持不同参数的不同学习率。
  • OPD 蒸馏 (GRPO) 现在支持教师和学生单独的视觉输入，从而实现多模式蒸馏。参考文档：https://swift.readthedocs.io/en/latest/Instruction/Distillation.html
  • 保存检查点时会保留 last-checkpoint 链接，使恢复更容易。
  • dataloader_persistent_workers 现在默认为 True，以避免每次评估时数据加载器冷启动。
  • 性能：矢量化无填充对数概率恢复和序列缩减；威震天损失全部减少，推迟到记录时间； NPU 上的向量化环注意 LSE 提取。
  • 添加了用于推出/部署的 vllm_kunlun 推理后端。
  • 删除了渐变依赖性。

错误修复

  • 训练：使用 Transformer 4.x 的 resume_from_checkpoint、DPO/IPO log-prob 归一化、与配对对齐的奖励模型边距、predict_with_generate DDP 评估、序列并行性的损失缩放、多处理中的词汇损失和外部文件、模板酸洗、py3.14 兼容性等。
  • RL：Megatron GRPO 词汇并行对数概率梯度、并置模式下的 vLLM 权重同步（LoRA IndexError、发送方设备对齐）、部署失败时的并置 vLLM 清理排序、代理多步骤部署中的令牌输入/令牌输出一致性。
  • Megatron：路由器重放 CP 分区和专家索引、MTP 共享权重转发、参考适配器加载、零多模态学习率、Megatron-FSDP DTensor 检查点保存/加载等。
  • 模型修复：Qwen3.5（线性注意 FP32 权重、多模式打包 kwargs）、Qwen-Omni 视频 fps、MiniCPM-o 4.5 视频输入、mplug_owl2_1 等。
