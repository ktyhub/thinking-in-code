ms-swift v4.5.0

新型号

Qwen3.8

Qwen3.8，迄今为止最强的开放式Qwen一代。与 Qwen3.5/3.6 相同的门控 DeltaNet 混合主干，原生视觉/视频，默认启用混合思维，加上可调节的推理工作和保留的历史思维。 (#9914)

NVIDIA Nemotron 3.5 闪电

Nemotron 3.5 Lightning 30B-A3B：混合 Mamba-2 + MoE + Attention，总共 30B / 3B 活动，1M 上下文，MTP。 (#9894)

缪斯闪烁

Muse-Glimmer-30B，Meta 的 30B 密集多模态模型，从 Muse Spark 中提取，用于本地代理。 (#9887)

其他变化

  • MiMo-V2.5 推理 (vLLM / SGLang) (#9880)
  • DeepSeek-V4-Flash-0731 适配 (#9834)
  • 思维前缀损失量表 (#9875)
  • OpenAI / Anthropic 消息处理器 (#9809)
