whisper.cpp v1.7.5

概述

这是一个相对较大的更新，包含各种构建和 CI 改进，特别是针对 iOS 和 WASM。还有一些性能提升，特别是对于 Metal 后端以及可能基于 Arm 的设备。

向 @danbev 表示大力支持并完成此版本的维护路线图！

移动示例

所有移动示例均已刷新。由于新的 XCFramework 工作流程，iOS 示例现在更容易构建。这应该会显着简化 whisper.cpp 在第 3 方 iOS 和 macOS 应用程序中的集成。 CoreML 构建和转换指令也已更新。

WASM 示例

WASM 示例现在会在每次新提交时自动更新，并托管在 Github 页面中： https://ggml.ai/whisper.cpp/

CORS 规则的问题应该得到解决。
