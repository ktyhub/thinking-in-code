anthropic-sdk-python v2.9.0

小版本 发布时间2026年11月16日 来源anthropics/anthropic-sdk-python 英文原文

anthropic-sdk-python v2.9.0

特点

  • api: 将源代码和错误代码添加到 RBAC 角色读取端点
  • api: 添加Update Bundle，设置Claude Tag Bundle的指令，并返回Bundle上的指令

错误修复

  • 凭据： 使用 Python 3.12 及更早版本在 Windows 上写入凭据文件
  • tools: 在 Windows 上限制文件工具和上传路径时精确比较目录名称
  • 工具： 完全解析通过悬空符号链接的文件工具路径
  • **工具：**忽略代理工具集的 grep 工具中的 ripgrep 配置文件
  • 工具： 当替换现有技能目录的下载或提取失败时，保留现有技能目录
  • 工具： 当会话线程终止时，保持会话工具运行程序的 max_idle 倒计时运行 如果运行程序在重新连接后无法读取会话的事件历史记录，则到达事件流的终止仍会取消倒计时，直到下一次空闲或成功读取。
  • 工具： 将指向 /memories 之外的符号链接保留在列表之外
  • 工具： 仅在代理工具集的 grep 工具中的绝对 PATH 条目中查找 ripgrep 该工具不再从相对或空的 PATH 条目运行 rg，或者在 Windows 上从当前目录运行 rg。在 Windows 上，它会查找 rg.exe，因此不再使用 rg.cmd、rg.bat 或 rg.com。由于 PATH 上没有其他 rg，该工具使用其内置搜索。
  • 工具： 传递代理工具集的文件工具可以写入的目录内的 rg grep 传递的 rg 解析为 workdir 或 allowed_roots 内部的某个位置，无论名称的字母大小写如何。它使用 PATH 上的下一个 rg，或者在没有时使用内置搜索。对于包含主机上每个 rg 的 workdir（例如 /），每个搜索都是内置搜索。 rg不再像bash的shell一样获取进程的ANTHROPIC_*变量。
  • **工具：**仅通过已验证的路径读取内存文件
  • 工具： 只读取 grep 工具内置搜索中的常规文件 grep 的内置搜索会传递 FIFO 或它所遍历目录中的设备，就像 ripgrep 所做的那样。读取一个可能会永远阻止搜索和事件循环。
  • 工具： 停止 EnvironmentWorker 为已终止的会话运行工具 对于终止的会话，工作线程现在会在检索会话后、下载技能或内存存储之前立即强制停止工作项。对于此类会话，它不再引发 SessionMemoryError。 API 将存档会话报告为 terminated。
  • **工具：**未安装 ripgrep 时，在 CPU 时间 30 秒后停止 grep 工具
  • 工具： 停止会话工具运行程序运行已终止会话线程的工具调用 运行程序也不再产生这些调用，包括拒绝调用 (confirmation="deny") 和对其不拥有的工具的调用。一个例外是当线程终止时其工具已经在运行的调用：运行程序使用 posted=False 生成它并且不发布任何结果。

家务事

  • api: 弃用旧的 Beta 标头值 API 仍然接受这些值，但后续版本将它们从 SDK 中删除。从您的请求中删除 prompt-caching-2024-07-31、pdfs-2024-09-25、token-counting-2024-11-01、token-efficient-tools-2025-02-19、extended-cache-ttl-2025-04-11、cache-diagnosis-2026-04-07 和 ce-user-management-2026-07-13。 files-api-2025-04-14 和 skills-2025-10-02 选择 beta 响应形状，因此在删除它们之前请遵循文件 API 和技能迁移指南。 在 C# 中，AnthropicBeta 枚举的成员具有新数字，因此针对早期 SDK 版本编译的代码会发送不同的 beta 值，不会出现错误，直到您重新构建它。
  • api: 停止在批量请求上发送旧的测试标头 beta.messages.batches 不再发送 message-batches-2024-09-24，而 API 不需要。如果您的 client 设置了默认的 anthropic-beta 标头，这些请求现在会发送它，而在某些 SDK 中，旧值会替换它。 API 仍然接受旧值。如果您自己设置，请将其删除：以后的版本会将其从 SDK 中删除。
  • 文档： 添加工作区名称的示例值
  • 文档： 澄清自动权限策略何时拒绝工具调用
  • 文档： 阐明外部密钥可以附加到哪些工作区
  • 文档： 推荐使用 multiagent_20261001 而不是协调器类型
  • 文档： 说明插件读取时何时需要organization_id
  • 测试： 让空闲的测试工作人员进行排队测试
