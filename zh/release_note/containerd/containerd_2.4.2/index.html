containerd v2.4.2

欢迎使用 Containerd 的 v2.4.2 版本！

containerd 2.4 的第二个补丁版本包含各种修复 以及包括安全补丁在内的更新。

安全更新

  • 容器
    • CVE-2026-95839
    • GHSA-8647-2jxj-p2rc
    • GHSA-hc94-p972-ch66

亮点

容器运行时接口 (CRI)

  • 应用强化以不遵循容器日志文件的符号链接（#14302）

图像分布

  • 修复当注册表下载超过内容写入时图像拉取过程中内存使用过多的问题 (#14342)
  • 应用强化来拒绝带有“..”路径组件的图像引用（#14282）

运行时

  • 对默认 seccomp 配置文件中的白名单套接字域应用强化 (#14247)

请尝试发布二进制文件并报告任何问题 https://github.com/containerd/containerd/issues.

依赖关系更改

此版本没有依赖项更改

以前的版本可以在 v2.4.1 找到

我应该下载哪个文件？

  • containerd-<VERSION>-<OS>-<ARCH>.tar.gz： ✅推荐。与 glibc 2.35 (Ubuntu 22.04) 动态链接。
  • containerd-static-<VERSION>-<OS>-<ARCH>.tar.gz：静态链接。预期用于不使用 glibc >= 2.35 的 Linux 发行版。不与位置无关。

除了 containerd 之外，通常您还必须安装 runc 和 CNI 插件 也来自他们的官方网站。

另请参阅入门 文档。
