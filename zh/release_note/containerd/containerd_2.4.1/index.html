containerd v2.4.1

欢迎使用 Containerd 的 v2.4.1 版本！

Containerd 2.4 的第一个补丁版本包含各种修复 以及包括安全补丁在内的更新。

安全更新

  • 容器
    • CVE-2026-53493

亮点

容器运行时接口 (CRI)

  • 修复失败的容器启动清理泄漏任务并阻止容器删除的错误 (#14223)
  • 修复当文件系统不支持 SELinux 重新标记时容器创建失败的错误 (#14212)

图像分布

  • 修复到达 EOF 后重试获取内容时内容上传失败的问题 (#14197)

快照器

  • 在解压过程中应用强化来过滤图像注释中的 ID 映射标签 (#14200)

ctr开发工具

  • 修复“ctr images export”中“-”后面的参数被删除的错误（#14219）
  • 修复容器命令参数被解析为“ctr run”、“ctrContainerscreate”、“ctrtasksexec”和“containerdoci-hook”中标志的错误（#14215）
  • 修复了 ctr 子命令中逗号分隔的标志值被错误分割的错误 (#14188)

请尝试发布二进制文件并报告任何问题 https://github.com/containerd/containerd/issues.

我应该下载哪个文件？

  • containerd-<VERSION>-<OS>-<ARCH>.tar.gz： ✅推荐。与 glibc 2.35 (Ubuntu 22.04) 动态链接。
  • containerd-static-<VERSION>-<OS>-<ARCH>.tar.gz：静态链接。预期用于不使用 glibc >= 2.35 的 Linux 发行版。不与位置无关。

除了 containerd 之外，通常您还必须安装 runc 和 CNI 插件 也来自他们的官方网站。
