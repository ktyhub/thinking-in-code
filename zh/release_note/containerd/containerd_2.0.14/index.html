containerd v2.0.14

欢迎使用 Containerd 的 v2.0.14 版本！

containerd 2.0 第十四个补丁版本包含各种修复 以及包括安全补丁在内的更新。

安全更新

  • 容器
    • GHSA-hc94-p972-ch66

亮点

容器运行时接口 (CRI)

  • 应用强化以不遵循容器日志文件的符号链接（#14299）

运行时

  • 对默认 seccomp 配置文件中的白名单套接字域应用强化 (#14251)

快照器

  • 在解压过程中应用强化来过滤图像注释中的 ID 映射标签 (#14270)

请尝试发布二进制文件并报告任何问题 https://github.com/containerd/containerd/issues.

我应该下载哪个文件？

  • containerd-<VERSION>-<OS>-<ARCH>.tar.gz： ✅推荐。与 glibc 2.31 (Ubuntu 20.04) 动态链接。
  • containerd-static-<VERSION>-<OS>-<ARCH>.tar.gz：静态链接。预计用于非 glibc Linux 发行版。不与位置无关。

除了 containerd 之外，通常您还必须安装 runc 和 CNI 插件 也来自他们的官方网站。

另请参阅入门 文档。
