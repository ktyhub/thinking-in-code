rancher v2.15.2

[!重要]

  • 如果您使用的是 Active Directory 联合服务 (AD FS)，升级到 Rancher v2.10.1 或更高版本可能会导致身份验证问题，需要手动干预。这些问题是由于 AD FS 依赖方 Trust 无法从元数据中获取签名验证证书造成的。有关更多信息，请参阅 #48655。这些问题可以通过以下两种方法之一来纠正：

  • 从联合元数据更新依赖方 Trust 信息（依赖方 Trust → 从联合元数据更新…​）。

  • 直接添加证书（依赖方 Trust → 属性 → 签名选项卡 → 添加 → 选择证书）。

Rancher v2.15.2是Rancher的最新补丁版本。这是社区版本，引入了维护更新和错误修复。

有关一般次要版本中新功能的更多信息，请参阅 v2.15.0 release notes。

漏洞的安全修复

此版本解决了以下安全问题：

牧场主

  • 修复了 Rancher 中的一个安全漏洞，其中注销会清除浏览器会话 cookie，但不会删除服务器上相应的公共 API 会话令牌。因此，先前捕获的会话令牌在其自然到期之前仍然有效，从而击败了注销作为撤销控制。仅在基于 OIDC 的身份验证中使用公共 API 会话令牌的部署才会受到影响。有关更多信息，请参阅 CVE-2026-88805。
  • 修复了 Rancher 中的一个安全漏洞，其中未经身份验证的只读 API 路由提供的一小组公共 UI 设置可能会被远程未经身份验证的用户修改。由于这些设置之一在登录页面上呈现为原始 HTML，因此攻击者控制的内容可以在访问登录页面的用户的浏览器中存储和执行，从而可能暴露本地管理员引导密码或活动管理员会话。未经身份验证的设置路由现在严格为只读。有关更多信息，请参阅 CVE-2026-88804。

舰队

  • 修复了 Fleet 中的一个安全漏洞，其中 fleet.yaml 中的 Helm valuesFiles 条目不限于捆绑包目录。能够提供 untrusted 捆绑内容的用户可能会导致 Fleet 读取存储库签出之外的文件，并通过生成的 Bundle 公开其内容，包括用户无权读取的凭证材料。 Fleet 现在拒绝脱离捆绑目录的值文件路径。有关更多信息，请参阅 CVE-2026-93537。
  • 修复了舰队代理复制 Bundle 的 downstreamResources 中列出的 Secrets 和 ConfigMap，并使用代理自己的凭据而不是固定到部署的 ServiceAccount 创建部署的目标命名空间的问题。这些写入现在由租户的下游 RBAC 控制。不固定 ServiceAccount 的部署作为代理操作不会发生变化。 Rancher v2.15.x 在默认安装中会受到影响，因为资源副本始终在其中启用。 升级后，固定 ServiceAccount 且无权创建目标命名空间或在其中写入复制的 Secrets 和 ConfigMap 的部署将不再部署。它报告“未准备好”并重试，直到获得许可。向 ServiceAccount 授予缺少的权限，或预先创建目标命名空间。有关更多信息，请参阅 CVE-2026-88808。
  • 修复了 Fleet 的 Git Webhook 接收器中的一个安全漏洞，其中当未配置 Webhook 机密时，具有 Webhook 服务网络访问权限的未经身份验证的调用者可能会更改任何命名空间中 GitRepo 资源的轮询间隔，从而延迟合法 Git 更改的推出。对于根据配置的 Webhook 密钥验证的请求，Fleet 现在仅将 Webhook 触发的更改应用于 GitRepo 规范。有关更多信息，请参阅 CVE-2026-93539。

牧场主将军

主要错误修复

  • 修复了 Kubernetes v1.36 集群的已知问题，由于备份图表问题，Rancher 备份未在 集群工具 下列出。请参阅#1055。

身份验证

主要错误修复

  • ext.Kubeconfig 存储已更新，以符合标准 Kubernetes API 资源行为。请参阅 #56341。

基于角色的访问控制 (RBAC)

主要错误修复

  • 修复了包含 inheritedFleetWorkspacePermissions 字段的全局角色的协调器循环。该修复可防止 Rancher 日志因创建/删除操作而被发送垃圾邮件。请参阅 #57050。

  • 扩展了 Rancher，以更好地保护其管理资源的限制范围和资源配额免受普通用户的干扰。

    • webhook 现在拒绝 Rancher 外部编辑这些托管资源、将非托管资源提升为托管资源或将托管资源降级为非托管的尝试，同时仍允许 Rancher 本身完全访问。请参阅 #56773。

集群配置

主要错误修复

  • 修复了 GKE 预配 UI 提供的 Kubernetes 版本不受任何 GKE 发布渠道支持的问题。 Rancher 现在仅显示基于发布通道的配置的有效 GKE 版本，这阻止了我们
