添加

  • 📑 选项卡式工作区。 聊天顶部的选项卡按钮现在可打开文件、多个终端会话、工件、预览、语音通话和评论的工作区。从 + 菜单添加选项卡，拖动以重新排序，然后创建新文件并将其直接保存到选定的终端中。在编码、分析数据或查看生成的文档时，将对话及其工作文件放在一起。 提交、提交、提交、提交
  • 🖥️ 打开终端桌面选项卡以供计算机使用。 从 + 菜单打开桌面选项卡，以查看和控制连接的开放终端提供的桌面，并提供鼠标、键盘、clipboard 和音频支持（如果有）。借助可以调用其桌面工具的模型，您可以在同一桌面中遵循计算机使用工作流程并自行介入：操作图形应用程序、检查生成的文档或处理需要手动输入的步骤。需要启用桌面支持的开放终端连接。 提交、提交、提交、提交
  • 🌐 用于浏览器使用和 Web 应用程序测试的浏览器选项卡。 在聊天旁边打开网站和本地开发服务器，带有导航控件、多个选项卡和移动视口。在兼容的开放终端连接上，Chrome 模式为您和模型提供共享浏览器会话，以实现浏览器自动化：导航站点、与表单交互以及测试模型构建的 Web 应用程序。您可以亲自观看作品并与页面互动；代理模式仍然可用于预览。需要所选终端上的浏览器支持，并且浏览器使用工具需要 Chrome 可用。 提交、提交、提交
  • ↔️ 全角选项卡。 在较大的屏幕上，展开选项卡式工作区以填充聊天区域，并将主要对话保留为其自己的选项卡。在聊天、代码、浏览器和桌面之间切换，以获得更多工作空间，或返回并排布局；您的布局选择将被记住。 提交、提交

  • 🌿 侧面板中的 Git。 当所选终端的文件夹是 Git 存储库时，选项卡式侧面板中的 Git 面板现在可让您查看差异、暂存、放弃和提交更改、管理分支和工作树、推送和拉取、浏览历史记录并使用 GitHub 拉取请求，并且打开的文件可以通过显示差异显示其更改。 提交、提交、提交、提交、提交

已修复

  • 🛡️ 安全建议：此版本包含安全修复。我们强烈建议尽快更新所有部署，以安装最新的安全修复程序。这些修复未在此 changelog 中列出；我们将在 CVE 分配后立即为他们发布安全公告。 咨询
  • 🔃 新聊天保持同步。 从主页启动的聊天在创建后会再次与服务器同步，因此从聊天控件中删除的文件在重新加载后不再返回，并且与“允许回复”共享的聊天的所有者会再次在其他人的回复中重新生成。 #33377, #33376
  • 📂 文件夹页面上的临时聊天。 使用顶部的按钮或“/temporary”在文件夹页面上打开或关闭临时聊天，现在使您保持在文件夹页面上，因此下一次聊天仍保存在文件夹中并获取其系统提示、默认模型和知识。 #33456, #33448
  • 🧵 话题回复焦点。 在频道消息上选择“在话题中回复”现在会将光标置于话题的回复框中，当话题面板已打开时也是如此。 #33467, #33466
  • 🪟 线程消息操作可见。 将鼠标悬停在频道线程中的顶部消息现在会显示其整个操作工具栏，而不是在面板边缘切断其上半部分。 提交，#33472
  • 📞 中断实时通话。 当报告的播放位置与音频不匹配时，在实时语音通话中说话时打断模型不再结束整个通话。 提交，#33550
  • 📶 重新连接后的临时聊天。 现在，在连接断开和恢复后，仍在临时聊天中写入的回复会不断到达，而无法完成的回复会显示“连接丢失。请重试”。而不是永远加载。 提交
  • 🏠 新的聊天初始化。 现在打开或重新加载主页或文件夹会选择模型并再次应用聊天 URL 参数，而不是将模型留空并忽略链接的设置。 提交
  • ✍️ 恢复聊天草稿。 保存的草稿文本现在会在新聊天编辑器安装后返回到消息输入，而不是在初始化期间消失。 提交
  • 🧩 嵌套代码预览。 预览现在可以打开列表、引号和详细信息块内的代码块，因此可以直接检查嵌入的示例和生成的工件。 提交
  • 🖼️ 从照片应用程序中删除图像。 当源省略文件类型（包括从 macOS 照片中拖动的照片）时，现在可以从其内容中识别放入聊天和频道中的图像，而不是被视为通用文件。 提交
  • 📏 实时上下文使用情况估计。 上下文指示器现在会考虑最新报告的令牌使用情况之后到达的输出，并避免在结构化输出中出现时对助理文本进行两次计数，从而更容易在长时间代理运行期间跟踪上下文窗口的使用情况。 提交
  • 🔌 支持响应的 API 流。 使用 Open WebUI 聊天完成 API 的 Client 现在即使上游模型使用响应 API 也会收到预期的流格式，包括文本、推理、工具调用、令牌使用和完成原因。 提交
  • 😀 频道反应名称。 将反应悬停在频道消息上现在会显示当这些名称可用时谁做出反应，而不是仅显示计数。 提交
  • 📊 分析活动滚动。 活动图表现在跟踪实际滚动的元素，在浏览较长的活动列表时保持其可见行同步。 提交
  • 🔑 已保存的 OAuth 提供程序设置。 OAuth 提供程序现在会在 Open WebUI 启动时加载其已保存的连接设置。管理设置还解释说，对提供商连接的更改需要重新启动每个 Open WebUI 实例。 提交

已更改

  • ⚠️ 数据库迁移：此版本包括数据库架构更改；我们强烈建议您在生产环境中升级之前备份数据库和所有关联数据。如果您正在运行多工作线程、多服务器或负载平衡部署，则所有实例必须同时更新，不支持滚动更新，并且会因架构不兼容而导致应用程序失败。

  • 🗺️ 聊天菜单中的概述。 聊天概述（所有消息及其分支的地图）现在从聊天菜单中的概述中作为全屏窗口打开，而不是作为聊天控件中的选项卡。 提交
  • 🔁 更高的工具调用限制。 使用本机函数调用的单个响应现在可以运行最多 1024 轮工具调用，然后才会因“达到工具调用限制”而停止，高于 256 轮，并且将“CHAT_RESPONSE_MAX_TOOL_CALL_ITERATIONS”设置为 256 会保留旧限制。 #33384
  • 🔓 默认无子代理限制。 管理设置中的子代理限制以及通过“SUBAGENTS_MAX_CONCURRENT”、“SUBAGENTS_MAX_ASYNC”、“SUBAGENTS_MAX_ITERATIONS”和“SUBAGENTS_MAX_OUTPUT”现在默认为无限制，留空表示无限制，默认为一次 20 个、后台 20 个、工具 30 个循环输出每个 30000 个字符。 提交
  • 🧠 上下文压缩和提示缓存。 当同一模型处理会话及其压缩摘要时，符合条件的请求现在会重用会话的提示结构，以便提供者可以使用其提示缓存。这可以降低总结长对话和座席工作流程的成本；其他请求保留单独的摘要路径。 提交
  • 💻 桌面 0.1.x 升级更改。 Open WebUI Desktop 不再在远程服务器之间切换，捆绑 Open Terminal，或提供旧的 Spotlight 和全局语音覆盖。现有远程连接用户应查看 Open WebUI Tether。上述“打开终端桌面”和“浏览器”选项卡使用单独配置的“打开终端”连接。 台式机0.1.0 release notes
  • 📭 文件处理警报已删除。 设置 > 通知中的个人通知不再提供“检索内容处理失败”，因此当文件处理失败时，通知 Webhook 不再收到警报。 提交
