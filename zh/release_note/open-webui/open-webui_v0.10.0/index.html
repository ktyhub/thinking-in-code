已修复

  • 🛡️ 安全建议：此版本包括安全和访问控制修复。我们建议您尽早更新生产部署。并非此版本中的所有安全修复程序都可以在“已修复”部分中列出 - 有些修复程序可能会暂时保留，以便管理员有时间进行升级。 咨询
  • 🔐 上传时强制执行知识库写入权限。 将上传的文件附加到知识库现在需要与 API 的其余知识相同的写入权限，因此没有写入权限的用户无法再通过引用其 ID 将文件添加到集合中。 #26001
  • 🗝️ 在所有关键端点上强制执行 API 密钥权限。 查看和删除 API 密钥现在尊重 API 密钥权限，与已应用于密钥创建的保护相匹配。 #25992
  • 🔊 在语音端点上强制执行文本转语音权限。 OpenAI 语音代理现在尊重文本转语音权限，因此不允许使用该功能的人无法再使用它。 #25993
  • 🎲 在竞技场回退时强制执行模型访问。 通过后台和任务请求上的竞技场模型间接访问模型现在会强制执行该模型的访问规则，从而关闭可能绕过它们的路径。 #26046
