open-webui v0.9.6

添加

  • 📦 官方知识库同步工具。 来自 Open WebUI 的新配套工具 oikb，使知识库与本地目录、GitHub 存储库、S3 存储桶、Confluence 空间或 40 多个其他源中的任何一个保持同步，使用此版本中添加的增量同步支持仅上传新的和更改的文件。 oikb
  • 📂 知识库的智能目录同步。 本地目录现在可以通过一个操作同步到知识库：将文件校验和与已存储的内容进行比较，仅上传添加或修改的文件，同时清理已删除的文件和孤立的子目录，自动镜像目录结构并显示每个文件的进度。 #19190、#19394、提交、提交、提交、提交、提交、提交
  • 🗂️ 知识库文件夹。 知识库内的文件现在可以组织到嵌套文件夹中，并使用面包屑导航，使管理和查找大型集合中的内容变得更加容易。 提交、提交、提交、提交、提交、提交
  • 🧰 用于知识库的文件系统工具。 通过“ENABLE_KB_EXEC”环境变量启用的新内置工具，可让 AI 模型使用熟悉的文件系统命令（例如“ls”、“cat”、“grep”、“find”、“head”、“tail”和“sed”）（包括它们之间的管道）浏览和搜索知识库内容。 提交、提交、提交、提交、提交、提交、提交、提交、 提交
  • ✏️ 知识库中的文件重命名。 现在可以直接从工作区重命名知识库内的文件，无论引用文件的位置都会反映新名称。 提交
  • 😀 消息输入中的表情符号选择器。 富文本格式工具栏中的新表情符号按钮可让您浏览表情符号并将其直接插入消息中。 #24704
  • 🪄 每聊天技能切换。 现在可以直接从聊天集成菜单打开或关闭对话的技能，与工具和功能已经工作的方式相同，而不仅仅是通过模型预设。 #25036, #25037
  • 🔎 用户和组的访问预览。 管理员现在可以准确预览给定用户或组可以访问哪些模型、知识库和工具，从而更轻松地审核和验证权限设置。 提交
  • 📄 可配置的知识库文件页面大小。 管理员现在可以在通过 API 列出知识库文件时请求更大的页面大小，从而减少检索大型集合所需的请求数量，而不是通过固定增量 30 进行分页。#25148，提交
  • 🔃 知识文件的持久处理指示器。 知识库中仍在处理的文件现在会在页面重新加载时保持显示处理指示器，因此您可以在离开和返回后知道仍在摄取哪些内容。 #25031，提交
  • 📑 MinerU 文件类型配置。 管理员现在可以通过新的“MINERU_FILE_EXTENSIONS”设置配置 MinerU 文档加载器处理哪些文件类型，将其从 PDF 扩展到 DOCX、PPTX 和 XLSX 等格式。 提交
  • 📃 旧版 Word 文档支持。 除了现代的“.docx”格式之外，较旧的“.doc”Word 文件现在还可以由默认文档提取引擎提取其文本。 提交
  • 📁 从文件夹标题创建子文件夹。 聊天文件夹现在可以直接从聊天视图中的文件夹标题创建子文件夹，而不仅仅是从侧边栏创建。 提交
  • ⚡ 更快的初始页面加载。 在每次页面访问时加载的配置端点不再运行不必要的用户计数查询，从而使数据库上的初始应用程序负载更轻，尤其是在具有许多用户的实例上。 提交
  • 🚀 更快的支持工具的聊天完成。 使用多个工具的聊天完成现在启动速度更快，因为它们引用的工具是在单个批量查询中从数据库中获取的，而不是每个工具一个查询。 #24808，提交
  • 🏎️ 负载下的网页搜索响应速度更快。 通过 SearXNG、Google PSE、Brave、Serper 和 Serpstack 进行的网页搜索现在使用非阻塞网络调用，因此服务器在搜索进行时保持对其他用户的响应，并且并发多查询搜索可以更快地完成。 提交
  • 🐎 更轻的 Ollama 后端连接。 对 Ollama 后端的请求现在重用共享连接池，而不是每次打开一个新会话，从而减少了频繁轮询 Ollama 或配置多个后端的安装的 TCP 和 TLS 握手开销。 提交
  • 💽 更少的冗余模型列表写入。 在 Redis 支持的多实例部署上，模型列表在未更改时不再重写，从而减少了冗余写入的主要来源。 #25469、#25474、提交
  • 📉 更快的 websocket 断开连接清理。 从协作会话断开连接不再触发对整个 Redis 键空间的扫描，而是使用每个会话索引，这使得大型部署中的断开连接成本较低。 #25466，提交
  • 📝 Frontmatter 自动填充工具、函数和技能。 打开工具、函数或技能编辑器现在会自动填充文件 frontmatter 中的名称、id 和描述字段，从而使您无需重新输入源中已声明的元数据。 #24649，提交
  • 🪪 自定义标头中有更多用户占位符。 用于直接连接和工具服务器的自定义标头模板现在支持“{{USER_EMAIL}}”和“{{USER_ROLE}}”以及现有的用户和会话占位符。 提交
  • ⏱️ 可配置的 MCP 连接超时。 现在可以通过新的“MCP_INITIALIZE_TIMEOUT”设置来配置与 MCP 工具服务器初始握手的超时，因此启动缓慢或暴露许多工具的服务器可以完成连接而不是超时。 #25011，提交
  • 📐 个人资料图像大小限制。 管理员现在可以通过新的“PROFILE_IMAGE_MAX_DATA_URI_SIZE”设置限制内联个人资料图像的大小，限制内联头像和模型图标可以消耗的数据库和缓存空间。 #25468, #25476
  • 🎫 通配符 OAuth 角色映射。 管理员现在可以在允许的 OAuth 角色中设置“*”，以将用户角色授予任何经过身份验证的 OAuth 用户，而不必枚举每个接受的角色。 #25062，提交
  • 📊 分页反馈历史记录。 反馈和评估历史记录列表现在已分页，使其能够响应已积累大量反馈条目的实例。 提交
  • 🔘 批量启用或禁用自动化。 现在可以从自动化页面上的操作菜单批量启用或禁用自动化，而不是单独切换每个自动化。 提交
  • ➡️ 可选自动重定向到单点登录。 管理员现在可以启用“OAUTH_AUTO_REDIRECT”，这样，在使用单点登录提供商且没有其他登录方法的部署中，用户将直接发送到提供商，而不是首先看到登录页面。 #25067，提交
  • ☁️ 带有 Entra ID 的 Azure AI Foundry v1。 Open WebUI 现在支持 Azure AI Foundry 的 OpenAI v1 端点以及 Microsoft Entra ID 身份验证，因此这些连接无需手动解决方法即可工作。 #24761、#24985、提交
  • 🌎 Linkup Web 搜索提供程序。 管理员现在可以从管理设置中选择 Linkup 作为 Web 搜索提供程序，并提供配置 API 密钥和搜索深度的选项。 #24752，提交
  • 🧊 Valkey 向量数据库支持。 Valkey 现在可以用作向量数据库后端，可通过新的“VALKEY_URL”和相关设置（包括索引类型、距离度量和 HNSW 调整）进行配置。 #24769，提交
  • 🔄 一般改进。 在整个应用程序中实施了各种改进，以增强性能、稳定性和安全性。
  • 🌐 翻译更新。 西班牙语（西班牙）、瑞典语、德语、韩语、加泰罗尼亚语、俄语、爱尔兰语、简体中文、繁体中文、芬兰语、波兰语、土耳其语和马来语的翻译得到增强和扩展。

已修复

  • 🛡️ 安全建议：此版本包括安全和访问控制修复。我们建议您尽早更新生产部署。并非此版本中的所有安全修复程序都可以在“已修复”部分中列出 - 有些修复程序可能会暂时保留，以便管理员有时间进行升级。 咨询
  • 🛡️ 工具服务器权限强制执行。 现在，内联工具服务器的每用户权限在聊天完成请求上强制执行，因此没有该权限的用户无法再通过直接在请求中提供工具服务器来绕过管理设置。 提交
  • 🔒 搜索工具中的知识库访问检查。 内置的知识搜索工具现在会在通过 ID 搜索知识库之前验证调用者是否可以访问知识库，从而防止用户读取他们未被授予访问权限的知识库内容。 #25113
  • 🗄️ 对检索集合的跨用户访问。 现在解析用于检索的文档会验证调用者对每个引用文件的访问权限，并拒绝 client 提供的集合名称，从而防止精心设计的请求将其他用户的文件或矢量集合拉入其上下文。 提交
  • 🔣 集合名称验证。 现在，矢量集合名称将被拒绝，除非它们仅包含安全字符，从而防止格式错误的名称到达矢量存储或破坏数据库查询表达式。 #24982
  • 🚫 默认情况下拒绝无范围检索集合。 现在默认情况下会拒绝非管理员对与已知文件、内存、网络搜索或知识库不对应的集合名称的检索请求，并使用新的“ENABLE_RETRIEVAL_UNSCOPED_COLLECTIONS”设置来在需要时恢复以前的行为。 提交
  • 📜 提示历史授权。 比较、删除和恢复提示版本现在可以验证历史记录条目是否属于您已授权的提示，从而防止访问或修改另一个提示的版本历史记录。 #25056
  • 🚦 遗留路径上的代码解释器权限。 遗留代码执行路径现在强制执行与当前路径相同的权限和功能检查，因此没有代码解释器权限的用户无法再通过它触发代码执行。 #24724
  • 🧱 API 密钥端点限制绕过。 限制 API 密钥可以到达的路径的端点允许列表现在直接与路由请求路径进行匹配，从而防止精心设计的请求绕过限制。 #25123
  • 🚧 通过请求参数绕过系统提示。 外部 clients 无法再通过请求参数设置跳过模型配置的系统提示的标志，因此无法从 API 绕过管理员配置的系统提示。 #25156
  • 🚪 终端代理路径遍历。 终端代理现在在验证请求路径之前对其进行完全解码，从而阻止可能逃脱预期路径的多编码有效负载。 #25157
  • 🪤 缓存文件路径遍历。 缓存文件服务器现在需要精确的目录边界匹配，从而缩小名称以缓存目录名称开头的同级目录可用于从其外部提供文件的间隙。 #25086
  • 🔀 Ollama 后端选择访问检查。 请求不能再通过索引定位任意 Ollama 后端；现在，根据实际服务于所请求模型的后端来验证调用者提供的后端选择器。 提交
  • 🔓 通过图像 URL 进行跨用户文件渗透。 当聊天消息通过“image_url”字段中的 id 引用文件时，服务器现在仅为其所有者、管理员或具有显式读取授权的用户解析该文件，从而防止其他经过身份验证的用户通过模型路由来提取文件内容。 #24625，提交
  • 📌 聊天文件附件访问检查。 将文件附加到聊天现在仅链接调用者可以读取的文件，从而防止用户将其他用户的文件与其聊天关联以访问其内容。 #25054
  • 🧾 模型知识文件所有权检查。 创建或更新模型现在会验证附加到该模型的任何知识文件是否是编辑器可以访问的文件，从而防止其他用户的文件附加到模型。 #25055，提交
  • 📅 日历事件移动授权。 更新日历事件以将其移动到不同的日历现在需要目标日历上的写入权限，从而防止用户将事件注入到他们无法写入的日历中。 #24764
  • 📣 频道聊天访问控制。 现在，在频道上下文中生成响应会验证调用者对该频道的访问权限并确定所包含消息的范围，从而防止访问不允许用户查看的频道或消息。 #24725
  • 🕸️ Web 加载器 SSRF 与 Playwright 门控。 当使用基于 Playwright 的 Web 加载器时，页面导航和重定向现在以与默认加载器相同的方式进行验证，从而消除了 Playwright 路径可能到达内部或其他被阻止 URL 的间隙。 #24756
  • 🛂 针对 URL 提取的 DNS 重新绑定保护。 为出站 URL 提取验证的 IP 地址现在与用于实际连接的 IP 地址相同，从而关闭了 DNS 重新绑定窗口，在该窗口中，攻击者控制的主机名可以在安全检查期间解析为公共 IP，然后在打开连接时解析为私有 IP。 #24759
  • 🪞 OAuth 配置文件图片重定向处理。 现在，仅当管理员明确允许时，OAuth 配置文件图片获取才会遵循重定向，从而关闭一个窗口，在该窗口中可以使用来自外部验证的 URL 的重定向来访问内部地址。 #24809
  • 🧼 模型配置文件图像脚本注入。 模型配置文件图像现在在保存时进行验证，并且仅当它们是已知安全的图像类型时才内联提供，从而防止精心制作的 SVG 配置文件图像在其他用户的浏览器中运行脚本，而验证失败的现有旧图像将被优雅地清除，而不是破坏模型列表。 #25060, #25173
  • 🧯 图表渲染脚本注入。 现在，在显示之前会对聊天中渲染的美人鱼图进行清理，以防止精心制作的图表在查看器的浏览器中运行脚本。 #25219
  • 🔐 共享聊天文件写保护。 通过共享聊天访问文件现在仅授予读取权限，因此可以读取共享聊天的用户无法再修改或删除附加到该文件的文件。 #24755
  • 🔏 跨源嵌入提示控制。 当 Open WebUI 嵌入到不同源的 iframe 中时，如果用户通过“iframe 沙箱允许同源”设置明确选择加入，嵌入页面现在只能驱动聊天输入或提交提示，从而防止 untrusted 主机页面触发确认对话框或控制聊天。 #24767，提交
  • 🗂️ 聊天文件夹所有权检查。 创建聊天或更新聊天文件夹现在会验证引用的文件夹是否属于当前用户，从而防止聊天与其他人拥有的文件夹关联。 #24588
  • 🧩 从损坏的历史记录中恢复聊天。 由于重新生成失败而使内部消息图处于格式错误状态的聊天现在可以正确打开和加载，并且会自动重建丢失的角色、父引用和当前消息指针，而不是破坏聊天。 #24424、#24157、#20474、#24799、提交
  • 📨 导入的带有文件夹的聊天显示正确。 当引用的文件夹丢失时，导入分组聊天不再使它们不可见；此类聊天现在会显示在聊天列表中，而不是默默地孤立。 #24910，提交

  • 🤝 MCP OAuth 范围发现。 MCP 工具服务器的 OAuth 流程现在读取服务器通过其受保护资源元数据通告的范围，因此可以成功连接到声明自己范围的服务器。 #24730, #24690
  • 🔍 Web 搜索可靠性。 Web 搜索再次使用默认 Web 加载器引擎可靠地获取页面内容，新的“USER_AGENT”环境变量允许管理员设置真正的浏览器用户代理，这样获取就不会被 Cloudflare、Wikipedia 和其他机器人检测系统阻止，并且在取消设置这些新环境变量时，启动脚本不再无法启动。 #24560、#24793、#24683、提交
  • 🔥 Firecrawl Web 搜索结果。 使用 Firecrawl 的 Web 搜索现在可以正确返回结果，无论 Firecrawl 版本使用哪种响应格式。 #24712
  • 🦅 Kagi 网络搜索。 在更新其 API 端点和请求方法以匹配 Kagi 当前的 API 后，使用 Kagi 的网络搜索再次工作。 #25015
  • 🔢 代码块中的括号数字。 代码块内的方括号中的数字（例如“[0]”）不再像源引用一样被删除，因此代码可以正确显示和复制。 #24948，提交
  • 🔌 API 聊天完成可靠性。 当未提供聊天会话标识符时，直接调用聊天完成 API 不再因内部错误而失败。 #24553、#25235、提交、提交
  • 🖼️ ComfyUI 图像生成和编辑。 通过 ComfyUI 后端生成和编辑图像现在可以再次使用，包括当 ComfyUI 托管在私有或内部网络上时，其中 URL 验证之前阻止了管理员配置的端点。 #24565、提交、提交
  • 🖌️ 使用非标准响应标头生成图像。 图像生成现在可与返回有效 JSON 且没有标准内容类型标头的后端配合使用，而不是拒绝响应。 #24838
  • 🐘 大型文档上的知识搜索。 在扫描具有非常大的提取文本内容的文档时，在 PostgreSQL 上搜索知识库不再失败。 #24670，提交
  • 💬 聊天标题生成。 自动生成的聊天标题现在使用当前在活动聊天的下拉列表中选择的模型，并从活动消息分支回退到模型，如果没有可用模型，则会显示清晰的消息，而不是显示无用的错误。 #24604、#24745、提交、提交
  • 🧮 消息搜索和分析一致性。 在聊天中进行的编辑、删除和分支更改现在反映在消息搜索结果和分析计数中，而不是留下过时的条目。 #25205，提交
  • 🩹 优雅地处理聊天内任务失败。 当 Web 搜索查询生成、图像提示生成或工具调用失败或引用丢失的工具时，聊天现在会回退或显示明显的错误，而不是在响应中途中断。 #25038、#25144、提交
  • 🎛️ 过滤对消息输出的更改。 在生成后修改消息的结构化输出的过滤器函数现在可以保存并显示这些更改，而不是在仅更改输出（而不是文本内容）时被丢弃。 #24884
  • ⏩ 标题和标签反映过滤后的输出。 出口过滤器现在在自动标题、标签和后续生成之前运行，因此这些过滤器基于最终过滤的消息而不是未过滤的版本。 #24717
