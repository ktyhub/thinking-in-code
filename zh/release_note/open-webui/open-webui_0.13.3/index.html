open-webui v0.13.3

修订 发布时间2026年11月8日 来源open-webui/open-webui 英文原文

open-webui v0.13.3

添加

  • 🦾 自动化中的代理。 自动化编辑器现在允许您选择终端和工作文件夹，然后选择那里可用的编码代理。计划运行使用已保存的终端和文件夹，并在开始之前检查终端和代理是否仍然可用。代理自动化将其结果发送到聊天室；普通型号仍可使用频道目的地。 提交
  • 📂 在聊天期间更改终端和文件夹。 您现在可以在发送消息后（包括在临时聊天中）选择不同的终端或工作文件夹。在生成回复时，两个控件均保持禁用状态。 提交
  • 🇧🇷 巴西葡萄牙语翻译。 添加了终端和文件夹控件、Git 操作、电子表格编辑、语音注释、选项卡快捷方式、通知声音和工具设置的缺失翻译。更新了文档检索、工具权限和语音设置的说明。 #33945

已修复

  • 📂 文件选项卡跟随终端更改。 将聊天切换到另一个终端现在会更新其打开的“文件”选项卡以显示该终端的文件，而不是在屏幕上保留先前终端的文件夹。将终端设置为“每个聊天”时，“文件”选项卡也会在第一条消息后切换到聊天自己的文件。 #33954
  • 🧭 不受支持的模型选择器中的代理。 连接终端不再将其编码代理添加到管理模型、基本模型选择器、竞技场候选项、任务模型设置、组默认值、子代理设置、通道提及或 Playground。 Notes 还停止选择终端代理来生成标题。代理无法保存或导入为自定义模型或其基本模型，并且他们的聊天菜单不再提供“编辑”。 提交、提交
  • 🔌 切换终端后的座席列表。 更改终端会立即从聊天的模型列表中删除先前终端的座席，同时加载新列表。您离开的聊天中发出的模型列表请求无法再替换当前列表。 提交
  • 📋 通过纯 HTTP 复制按钮。 在本地网络上的纯 HTTP 地址上，现在可以复制评论链接、搜索链接、共享聊天链接、Webhook URL、聊天 ID、Git 分支名称、提交哈希和电子表格单元格。复制格式化文本保留格式，复制的文本保留最后的换行符。 #33939
  • 📝 Clipboard 提示和通过普通 HTTP 的自动复制响应。 现在，即使浏览器阻止 clipboard 访问，使用 clipboard 占位符的提示也会插入到聊天和频道中，并显示一条消息解释无法读取 clipboard。自动复制响应保持关闭状态并显示许可消息，而不是默默地无法打开；将其关闭不再需要 clipboard 访问权限。 #33939
  • 🧠 具有技能、知识和记忆的 DeepSeek 思维模式。 当连接的 Provider 设置为“llama.cpp”时，这些聊天不再因缺少推理错误而失败。 DeepSeek思维模式仍然需要这样的设置；使用“默认”的连接保持不变。 #33950
  • 🏷️ 分组工具调用上的标签。 启用工具调用标签后，一组工具调用会保留存在的标签，即使一个调用没有标签也是如此。未标记的调用显示其工具名称，而不是使整个组丢失其标签。 #33932
  • 💬 稍后回复中的工具标签。 该模型现在可以在继续回复或回答另一条消息时看到为之前的工具调用编写的标签，从而消除了在对话继续时停止编写标签的原因。 #33953
  • 🔎 包含标点符号的知识搜索。 当模型将句点标记为文字标点符号时，知识文件中的搜索现在会查找诸如“Art. 40”之类的文本，而不是返回任何匹配项。 #33936
  • 🪟 禁用临时聊天的侧边聊天。 在禁用临时聊天的同时保持强制临时聊天处于打开状态，不再阻止用户发送和保存侧边聊天或将现有聊天拖到侧面板中。 #33930
  • 🏠 主文件夹选项卡标题。 连接计算机主目录中的“文件”选项卡现在显示“Home”，而不是显示目录名称，包括在重新打开已保存的选项卡时。其他文件夹保留其名称。 提交
  • 🦙 Docker 映像中缺少 Ollama。 如果未安装 Ollama，构建包含 Ollama 的映像现在会失败，而不是生成下载失败后无法启动 Ollama 的映像。 #33944
  • 📄 离开聊天后出错。 在保存选项卡布局时关闭或离开聊天不再在服务器日志中填充已断开连接的错误报告。 #33929
