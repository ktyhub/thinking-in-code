open-webui v0.12.1

添加

  • 🧱 频道中的外部应用程序。 管理员现在可以在管理设置 > 常规中打开应用程序，或使用“ENABLE_APPS”打开应用程序，并通过 HTTPS 地址在管理设置的新应用程序选项卡中连接外部应用程序，检查每个应用程序要求的权限，例如阅读其提及、阅读频道消息或发布消息，以及选择谁可以使用它；然后，频道管理员可以通过频道信息中的“添加成员”将应用程序添加到频道，该应用程序会与成员及其个人资料图片一起列出，并使用@提及它，使其在频道中回答，并提供仅向提问者显示的回复，显示带有标题、字段和缩略图的卡片，提供按钮或链接，跟进较长任务的后续消息或提供要下载的 Markdown 文件。一旦专用网络地址上的应用程序的地址列在“APP_ALLOWED_PRIVATE_ORIGINS”中，就可以通过普通 HTTP 访问该应用程序。 Open WebUI 保持与每个应用程序的实时连接，管理设置 > 应用程序会显示其是否已连接，并且连接失败会列出原因，例如 API 密钥被拒绝、公钥错误或无法访问的地址。 提交、提交、提交、提交、提交、提交、提交、提交、提交、 提交

  • 🎠 转动和缩放语音头像。 在语音通话和模型编辑器预览中，现在可以通过拖动来转动语音头像，用右键拖动、Shift 拖动或两根手指平移，用鼠标滚轮或捏合缩放，并用双 click 重置。 #32378

  • 🔆 通话期间屏幕打开。 现在，屏幕在实时语音通话和标准通话期间保持打开状态，并且可以在通话结束后再次关闭，其中实时通话会使其变暗，而标准通话在结束通话后会使其保持打开状态。 提交，#32251
  • ☁️ Azure OpenAI 实时通话。 实时语音通话现在可以使用 Azure OpenAI：在音频设置的语音通话部分，管理员选择 Azure OpenAI 作为提供程序，输入 Azure 终结点和部署名称，并使用 API 密钥或 Microsoft Entra ID 登录，更清晰的错误现在指向错误的凭据或错误的 URL 或部署，其中包含“AUDIO_REALTIME_PROVIDER”和新设置的“AUDIO_REALTIME_AUTH_TYPE”环境变量。 提交，#32343
  • 📊 分析中的输入和输出令牌。 Analytics 仪表板现在在一个带有模型和用户开关的表中显示模型使用情况和用户活动，两个列表都将输入、输出和总令牌显示为单独的列，每个列都可以排序，其中它们显示单个令牌列。 提交、提交
  • 🎚️ 实时输入参数。 管理员现在可以在音频设置的语音通话部分的输入参数下为实时语音通话的音频输入添加额外的设置，如 JSON，例如降噪，或使用“AUDIO_REALTIME_INPUT_PARAMS”环境变量。 提交
  • 🔄 一般改进。 在整个应用程序中实施了各种改进，以增强性能、稳定性和安全性。
  • 🌐 翻译更新。 葡萄牙语（巴西）、意大利语、捷克语、罗马尼亚语、荷兰语、乌克兰语、波兰语、泰语、西班牙语、马来语、波斯语、韩语、阿拉伯语、日语、印度尼西亚语、俄语、越南语、土耳其语、印地语、德语、希腊语、匈牙利语、希伯来语、保加利亚语、瑞典语、爱沙尼亚语、挪威语、立陶宛语、克罗地亚语、斯洛伐克语、波斯尼亚语、丹麦语、斯洛文尼亚语、加利西亚语、拉脱维亚语、藏语、塞尔维亚语、孟加拉语、宿务语、阿塞拜疆语、巴斯克语、爱尔兰语、格鲁吉亚语、卡比尔语、旁遮普语、法罗语、泰米尔语、维吾尔语、乌尔都语、菲律宾语和土库曼语得到增强和扩展。

  • 📑 外部知识引用的页面标题。 来自外部知识库（例如 Qdrant、Milvus 或 pgvector，其来源为网址）的引用现在会在答案下方的来源列表中显示页面标题，与文本中的编号标记相匹配，其中显示了完整的地址。 #32232, #32231
  • 🧭 Redis Sentinel 主名称带有 capital 字母。 对于 Redis Sentinel，“REDIS_URL”中带有 capital 字母的主名称，例如 myMaster，OT-Container-Kit redis-operator 的默认值，现在可以使用，它是小写的，并且每个Redis 呼叫失败，并显示“未找到主设备”。 #32234, #31918

  • 🔗 外部知识引用链接。 Cli 从外部知识库（例如 Qdrant、Milvus 或 pgvector）引用引用的标题或内容链接现在会打开引用的网页，或者当来源不是网址时将标题显示为纯文本，从而导致未找到错误。 #32233, #32231
  • 🧰 新聊天中选择的工具。 从集成菜单中选择的工具、网络搜索切换和新聊天中选择的技能现在在切换到另一个聊天并返回或重新加载后保持不变，其中聊天会回退到模型的默认工具并破坏提示缓存。 #32235, #32084
  • 📅 重复自动化运行一次。 使用“每日”、“每周”或“每月”选择器设置的自动化现在在您自己的时区中选择的确切分钟运行，其中它们可以一次运行两次，并且服务器时区后面的用户可以将其第一次运行移至第二天。 #32264, #32263
  • 📵 共享聊天中没有语音通话。 语音模式按钮不再显示在您可以回复的共享聊天中，并且当您切换到通话时，打开的通话将关闭。 提交

  • 🕶️ 临时聊天中的后续建议。 临时聊天中的后续建议现在基于刚刚编写的回复，它们是在没有回复的情况下生成的。 提交

  • 📎 笔记上传不再卡住。 在保存另一个文件或编辑时上传到笔记的文件现在已完成并在重新加载后保持附加状态，它会继续旋转并在没有文件的情况下保存。 #32328, #32327

  • 🐙 带有符号链接的 GitHub 技能导入。 现在，当存储库在技能文件夹外部具有符号链接（例如根目录中的 CLAUDE.md 链接）时，可以从 GitHub 链接导入技能，该链接会失败并显示“存档不能包含链接或特殊文件”。 #32313, #32312
