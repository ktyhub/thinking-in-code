open-webui v0.12.4

添加

  • 🎯 按需加载选定的技能。 管理员可以在“管理设置”>“常规”下打开“按需加载选定的技能”或设置“ENABLE_SKILL_LAZY_LOADING”，这样在聊天中选择的或附加到模型的技能只会列出以供模型在需要时加载，而不是在每条消息中发送完整的说明，而消息中提到的技能仍然会立即加载，并且默认情况下处于关闭状态，需要内置的技能工具。 提交
  • 📍 聊天中显示的压缩。 “上下文压缩”行现在标记了对旧消息进行汇总的消息，打开以显示摘要，并且当在其工具调用之间运行压缩时，也会出现在回复中，聊天控制 > 概述标记该消息，并且压缩进度和错误现在显示在聊天中，而不是作为弹出通知。 提交、提交、提交、提交、#31324
  • 🗜️ 更多聊天中的压缩。 上下文压缩现在也在临时聊天和已经超过阈值的短聊天中运行，例如一个带有完整工具输出回复的问题，因此后续操作以及对其的任何重新生成或编辑不再因上下文长度错误而失败。 #32794、提交、#32781、提交、#32600
  • 🕶️ 隐藏用户控件。 管理员现在可以在管理设置 > 界面中的可见控件下或使用“UI_VISIBILITY”对用户隐藏单个控件，例如模型功能、模型编辑器中的默认功能和内置工具、捕获、比较文本、附加网页、附加文件、附加注释、+ 菜单中附加知识和参考聊天、/status、/model 和 /settings 命令、使用信息、Fork、合并响应、预览、聊天中的工件、存档和标签，为模型和设置（例如“使用”选项卡和语音引擎）设置为默认值并保留在侧栏中，而隐藏控件保留其值及其背后的功能保持可用，隐藏“存档”也会隐藏“取消存档”，管理员仍然可以看到每个控件。 提交，#32830
  • 🫙 隐藏不可用的选项。 无法生效的选项现已隐藏，例如在没有视觉模型的 + 菜单中捕获、为没有 Notes 权限的用户附加注释、聊天控件中禁用工具和功能的阀门选择器、上下文压缩关闭时的上下文压缩阈值、管理员关闭时在“设置 > 界面”中切换标题、后续内容和标签生成、为无法使用频道的用户提供频道中的压缩图像、聊天设置中的 Web 搜索用户无法使用 Web 搜索、设置 > 界面的语音部分（针对无法拨打电话的用户）、管理员已关闭的功能的组和默认权限切换、模型编辑器中的终端功能和默认终端（当没有终端服务器或直接集成可用时）、新建临时聊天和删除聊天快捷方式（针对可能不使用它们的用户）、模型编辑器中的 Web 搜索、图像生成、代码解释器和内存功能以及默认功能（当该功能关闭时），模型编辑器中的内置工具模型的功能被排除或其功能已关闭、网络搜索或图像生成关闭时管理设置 > 网络搜索和管理设置 > 图像中的引擎设置、网络搜索关闭时管理设置 > 界面中的网络搜索查询生成开关、设置 > 界面中的重新生成菜单和终端设置（无法应用时）、无法创建技能的模型的“/skills:create”、语音转文本不可用时的呼叫按钮、不允许语音或呼叫的用户的音频设置选项卡、多重身份验证部分当社区共享关闭时，MFA 不适用于新聊天中的用户和 openwebui.com 作者链接，而保存的值将在再次申请时保留。 #32969、#32967、#32959、提交、提交、提交、#32962、 #32973、#32976、#32977、#32980、#32961、提交、提交、 提交、提交、提交、提交、#32972、#32975、 提交、#32983、提交、#32966、提交、#32978、提交、 #32963、提交、#32965、提交、#32984、提交、#32985、 提交、#32986、提交、#32974、提交、#32981、提交、 #32971、提交、#32970、提交、#32964、提交、#32830
  • 🔏 访问按钮尊重共享。 模型、提示、工具、知识、技能和注释的访问按钮和菜单项以及文件夹设置中的访问按钮现在对没有匹配共享权限的用户隐藏，他们无法在对话框中进行任何更改。 #32979、提交、#32830
  • 🖇️ 附加条目而不上传。 当文件无法附加时，由于缺少权限或选择的模型没有文件上传，+ 菜单中灰色的附加知识、参考聊天和附加注释条目将不再打开，# 和 @ 列表会遗漏无法附加的内容，包括没有网络上传权限的用户粘贴的链接，因此所选项目不再从输入中消失而不显示消息。 #32968、提交、#32830
  • ⏱️ 准确的上次活动时间。 将鼠标悬停在管理员用户列表和群组成员列表中的上次活动时间现在会显示准确的日期和时间。 提交
  • 🗨️ 从文件夹中进行新聊天。 侧边栏中的文件夹菜单现在有一个“新聊天”项目，可在该文件夹中启动聊天。 提交
  • 🪪 整个工作区的个人资料卡。 将所有者的姓名悬停在模型、知识、提示、技能和工具的工作区列表中以及管理功能中，现在会打开其个人资料卡而不是电子邮件工具提示，其个人资料图片位于姓名旁边，访问设置中的个人资料图片、版本历史记录和 Analytics 用户列表也会打开该卡，注释列表显示每个所有者的个人资料图片。 提交、提交、提交、提交、提交、提交

  • 🎚️ 按设置保存聊天控件。 聊天控件中的更改（例如系统提示或参数）现在仅保存该设置，因此在另一个选项卡或另一台设备上打开的聊天副本不再用旧设置擦除它。 提交，#32755
  • 🪃 问题在重新连接后仍然存在。 当询问用户、工具批准、MCP 服务器的输入请求或功能的确认或输入对话框等待您时，当页面重新加载或失去连接时，一旦您在一分钟内重新打开该聊天，问题就会回来，因此请求不再等待而没有答案。 提交
  • ✍️ 通过文本进行注释编辑。 该模型现在可以通过查找和替换确切的文本（而不是仅通过字符偏移量）来编辑注释，选择一个匹配或全部匹配，并在匹配不明确时获取位置和周围文本。 提交，#32752
  • 🔍 比较视图保持对齐。 现在，在滚动、调整大小或编辑时，比较视图的两个窗格中的匹配行保持对齐并就位，并且彩色条现在也标记更改的行，同时忽略空白或强调标记。 提交、提交、提交、提交
  • 🖱️ Clickable 设置标签。 Clicking 跨用户和管理设置的设置标签，包括高级参数和连接，现在可以切换其开关、聚焦其字段或按下其按钮，并且标签在行悬停或聚焦时突出显示，因此更容易找到正确的控件。 提交、提交、提交、#32768、#32900
  • ☑️ 选择多个侧边栏聊天。 Shift-clicking 侧边栏中的聊天会启动选择，更多 click 或 Shift-click 范围会扩展，然后可以存档所选聊天，或者在具有删除权限的情况下一起删除，而 Escape 会清除选择。 提交，#32543
  • 🫲 滑动打开聊天控件。 在手机上，向左滑动聊天现在会拉出聊天控制面板，该面板会像侧边栏一样跟随您的手指，并通过向右滑动再次关闭。 提交
  • 🗃️ 批量文件管理。 在“设置”>“数据控件”中管理文件现在可以下载单个文件，并允许您选择多个文件或与搜索匹配的所有文件以删除它们或将它们作为一个 zip 存档一起下载，并带有进度和停止按钮。 提交
  • 📥 准确的上传状态。 上传到知识库的文件现在仅在索引并链接到知识库后才显示为已完成，因此它不再显示为已完成，然后从列表中丢失，直到重新加载。 提交，#32803
  • ⏳ 知识文件显示正在处理。 添加到知识库的文件现在一旦到达服务器就会从上传切换到正在处理，并且列表会保持最新状态，直到文件准备就绪，因此在您重新打开知识库之前，它不再显示正在上传。 #32982，提交
  • 🧮 一次列出知识上传。 选择或一起放入知识库的文件现在全部按上传顺序显示为“正在上传”，因此每个文件不再等待文件处理完成之前才出现。 #32992，提交
  • 📈 按令牌进行分析。 管理分析仪表板现在默认按令牌对模型和用户进行排名，并切换回消息，其使用情况图表添加了数量和活动视图、单个模型视图、与上一时期的比较、时间步长的选择以及年初至今和过去 12 个月的范围。 提交、提交、提交、提交、提交、提交

  • 📁 文件浏览器文件夹菜单。 终端文件浏览器中的文件夹菜单现在具有“新建文件”和“新建文件夹”项目，可在该文件夹内创建文件或文件夹。 提交、提交
  • 📬 第一条消息终端上传。 在每个聊天终端上将“聊天上传”设置为“文件系统”后，附加到新聊天的第一条消息的文件现在会等待，并在发送消息时上传到该聊天自己的终端，因此它不再位于共享工作区中。 提交，#30245
  • 🪧 文件夹描述。 文件夹现在可以在其设置中包含描述，显示在文件夹页面的文件夹标题下方。 提交、提交

  • 🛰️ MCP 协议 2026-07-28。 MCP 连接现在也适用于使用无状态 2026-07-28 协议版本的服务器，而较旧的服务器仍然通过早期的握手进行连接。 #33087、提交、#29778
  • 📧 LDAP 默认电子邮件域。 管理员现在可以在 LDAP 设置中或使用“LDAP_DEFAULT_EMAIL_DOMAIN”设置默认电子邮件域，因此没有邮件属性的 LDAP 用户可以使用该域中的用户名作为电子邮件地址登录，并登录到具有该地址的任何现有帐户，这就是为什么该域应该由您控制。 提交，#33001
  • 🔐 通过 API 的 OAuth 连接。 当用户使用 API 密钥或不记名令牌调用 API 时，设置为 OAuth 身份验证的连接现在也会发送用户的 OAuth 令牌，就像工具服务器已经做的那样。 #32826、提交、#32820
  • 🫣 组的隐藏基础模型。 管理员现在可以在用户和组权限中的模型访问下打开隐藏模型权限，或设置“USER_PERMISSIONS_WORKSPACE_MODELS_HIDDEN”，以便这些用户可以选择隐藏模型作为工作区模型的基础模型，而隐藏模型则不包含在模型选择器中。 提交、#29806、#29639
  • 🧾 审计日志中的模型使用。 随着审计日志记录打开，并从“AUDIT_EXCLUDED_PATHS”（默认情况下排除它）中删除“/chat”，每个聊天回复和工具调用现在都会写入自己的审计日志条目，其中包含模型以及提供商报告的输入、输出和总令牌，链接到启动它的请求。 提交，#30098
