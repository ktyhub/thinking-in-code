open-webui v0.10.2

open-webui v0.10.2

添加

  • 💭 流式推理显示。 发出思考或推理的模型现在会在流式传输时显示该内容，并在聊天概述和导出的对话中正确呈现。 提交、提交、提交、提交
  • 🗂️ 文件夹上传到知识库。 将文件夹拖入知识库或同步文件夹，现在会重新创建其子文件夹结构，而不是将所有内容展平为松散的文件。 #26130，提交
  • 🧠 内存系统上下文切换。 管理员现在可以使用管理设置中新的“内存系统上下文”切换，保持内存工具可用，同时选择不将存储的内存添加到系统上下文。 提交
  • 🧹 更整洁的自动记忆。 自动保存的记忆现在专注于持久的细节，如偏好和目标，并跳过一次性的事情，如膳食、例行事件或情绪变化，除非您要求记住它们。 提交
  • 🎙️ 语音转文本请求格式。 兼容 OpenAI 的语音转文本现在可以以分段上传或 base64 JSON 的形式发送音频，可在管理音频设置中选择。 提交
  • 🧰 通过环境进行 API 配置。 管理员现在可以通过“OLLAMA_API_CONFIGS”和“OPENAI_API_CONFIGS”环境变量设置每个连接的 Ollama 和 OpenAI API 配置。 提交
  • 📡 提供程序故障事件。 失败的 Ollama 和 OpenAI 兼容的提供程序请求现在会发出一个结构化事件，描述错误类型、提供程序和状态，使管理员能够更清楚地了解上游故障。 提交
  • 🏟️ 通过环境的竞技场模型。 管理员现在可以通过“EVALUATION_ARENA_MODELS”环境变量定义评估竞技场模型。 #26174
  • ♿ 更清晰的高对比度侧边栏选择。 启用高对比度模式后，侧边栏中当前选择的聊天现在会以更强的颜色脱颖而出，从而更容易辨别哪个聊天处于活动状态。 #26469，提交
  • 🔄 一般改进。 在整个应用程序中实施了各种改进，以增强性能、稳定性和安全性。
  • 🌐 翻译更新。 泰语、葡萄牙语（巴西）、加泰罗尼亚语和西班牙语的翻译得到增强和扩展。

已修复

  • 🛡️ 安全建议：此版本包括安全和访问控制修复。我们建议您尽早更新生产部署。并非此版本中的所有安全修复程序都可以在“已修复”部分中列出 - 有些修复程序可能会暂时保留，以便管理员有时间进行升级。 咨询
  • 🔐 更少意外注销。 返回授权错误的单个请求不再在会话仍然有效时将您注销，因为应用程序现在会在重定向到登录之前确认会话状态。 提交
  • 🔒 Web 搜索域过滤。 Web 搜索结果的域允许和阻止规则现在与主机进行匹配，从而弥补了某些 URL 可能漏过过滤器的差距。 提交
  • 🕵️ 图像提示日志隐私。 图像生成工作流程不再以默认日志级别写入服务器日志，从而使用户创作的提示内容远离操作员可见的日志。 #26400，提交
  • 🗄️ 更安全的数据库升级。 升级现有 SQLite 数据库不再在用户表迁移期间崩溃或损坏保存的用户设置，解决了升级后可能阻止启动或中断登录的故障。 #26403，提交
  • ⚙️ 以非管理员身份保存设置。 非管理员用户可以再次保存其界面设置，例如默认模型和主题，之前由于服务器错误而失败，而界面错误地报告成功。 #26627，提交
  • 🕒 侧边栏聊天时间戳。 侧边栏中的聊天现在显示上次活动的时间，而不是创建的时间，因此时间标签与其在列表中的位置匹配，并在每条新消息后刷新。 #26454, #26451
  • 🎯 刷新后的默认模型。 重新加载页面时，您选择的模型不再被清除，因为模型选择现在等待模型列表完成加载。 提交
  • ⏳ 工具对话框不再挂起。 通过 clicking 关闭工具或功能输入对话框现在会取消挂起的请求，而不是让聊天无限期地旋转。 #26417，提交
  • 🐍 可靠的代码执行加载。 在聊天中运行 Python 代码现在可以可靠地加载其运行时，修复了最近版本中破坏代码执行和 Pyodide 文件查看器的沙箱启动故障。 #26625, #26390
  • 🤖 具有空功能的模型。 当涉及内存功能或自动化时，与未设置功能的模型聊天不再失败并出现错误。 #26412、提交、提交
  • 🔎 可搜索的响应。 聊天搜索再次查找其文本存储为结构化输出的助理消息，这些消息之前被跳过。 #26405
  • 🔔 聊天通知预览。 后台聊天完成通知和 toast 现在显示清晰的响应预览，而不是对于存储为结构化输出的消息显示为空白。 提交
  • 💾 横幅和配置启动。 设置“WEBUI_BANNERS”等配置不再导致启动失败，因为现在无论数据类型如何，管理配置值都可以正确存储。 #26431，提交
  • 📑 RAG 模板可见性。 现在，即使启用了绕过嵌入和检索，RAG 模板编辑器在管理文档设置中也保持可见，因为该模板仍然适用于该模式下的文档内容。 #26126，提交
  • 🧬 编辑派生模型。 编辑工作区模型不再清除其基础模型，包括当该基础是预设或模型本身时。 提交、提交
