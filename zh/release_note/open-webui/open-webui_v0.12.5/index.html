open-webui v0.12.5

open-webui v0.12.5

添加

  • 🧭 分析会话资源管理器。 只要启用“ENABLE_ADMIN_CHAT_ACCESS”，管理员现在可以在管理分析中打开“会话”选项卡，其中列出每个聊天及其令牌、响应、错误和时间跨度，按搜索、模型、令牌范围或子代理进行过滤，并显示聊天已保存的回复和工具调用及其时间和结果。 提交
  • 📑 笔记中的页面。 笔记现在可以容纳多个页面和子页面，您可以添加、重命名、重新排序、移动到另一个页面下、下载、链接到页面选项卡和从页面选项卡中删除，搜索结果和模型现在可以逐页处理笔记。 提交
  • 👀 笔记中的实时存在。 现在，笔记会显示还有谁打开了它，clicking 一个人会跳转到页面并发现他们正在处理的内容。 提交
  • ✏️ 从聊天菜单重命名。 打开的聊天标题旁边的菜单现在具有重命名功能，它将页面顶部的标题变成文本框，因此可以重命名聊天，而无需先在侧边栏中找到它。 #33177、#33176、#33246、#33339、#33338、提交、提交
  • 🖼️ 在终端中生成的图像。 当在聊天中选择终端时，生成和编辑的图像现在也会保存到其工作文件夹中，以便模型可以继续使用终端的工具处理它们。 提交
  • 🗃️ 模型显示聊天文件。 模型现在可以使用内置的 display_file 工具在回复中显示聊天中附加的文件或存储在附加知识库中的文件，该工具到目前为止仅适用于终端文件。 #32471、提交、提交
  • 💾 已保存聊天模型选择。 在聊天中更改模型现在会立即与聊天一起保存，因此即使更改后没有发送消息，也可以使用该模型重新打开聊天。 提交
  • ⌨️ 取消分配单个快捷方式。 设置 > 键盘现在在每个已分配的快捷方式旁边显示一个小 x，仅取消分配该快捷方式，因此可以关闭 Ctrl+R 或 Cmd+R 上的“重新生成响应”等快捷方式，而其他所有快捷方式仍继续工作。 #33185、#31463、提交
  • 🎚️ 数字 Valve 滑块。 插件作者现在可以将数字 Valve 或 UserValve 显示为滑块，旁边有一个数字框，其末端来自字段的最小值和最大值，因此用户在选择值时可以看到允许的范围。 #33179、#32045、提交
  • 📇 模型的提供程序详细信息。 编辑模型的管理员现在可以看到提供程序详细信息部分，其中包含提供程序为其报告的输入和输出类型、上下文窗口、最大输出和支持的参数。 提交
  • 🧲 在设置中嵌入前缀。 管理员现在可以在管理设置 > 文档下设置某些嵌入模型所需的查询和内容前缀，其中只能使用“RAG_EMBEDDING_QUERY_PREFIX”和“RAG_EMBEDDING_CONTENT_PREFIX”环境变量进行设置。 提交
  • ⏱️ 终端启动超时。 Open WebUI 现在在向终端询问其技能、AGENTS.md 文件或上传时默认等待最多 60 秒，因此仍在启动的终端可以应答，使用“AIOHTTP_CLIENT_TIMEOUT_TERMINAL”更改限制，并在超时时显示一条命名终端的消息。 提交
  • 🚨 自动化失败通知。 自动化运行失败现在是用户可以在“设置”>“通知”下选择其通知目标的事件，因此所有者可以听到每个失败的运行以及自动化的名称和错误。 #33331、#33228、提交
  • ⚡ 更快的知识库命令。 ls、cat 和 grep 等知识库命令以及知识库同步检查现在会列出文件，而无需加载每个文件的全文，因此在大型知识库上，每次调用的速度最高可达十倍，并且使用的内存要少得多。 #33332、#33322、提交
  • 🔭 更快的聊天搜索。 搜索聊天（包括从“参考聊天”菜单和模型的聊天搜索工具）不再完整加载每个匹配的聊天，因此在大型聊天历史记录中可以更快地返回结果，并且现在将鼠标悬停在“参考聊天”菜单中时会加载结果的消息预览。 提交
  • 📦 批量文档嵌入。 大文档现在默认以 1000 个块的批量嵌入和保存，并使用“RAG_EMBEDDING_BUFFER_SIZE”设置，因此处理非常大的文件一次在内存中占用的空间要少得多。 提交
  • 🧾 Mistral OCR 模型选择。 管理员现在可以选择 Mistral OCR 模型，并通过管理设置 > 文档或“MISTRAL_OCR_PARAMS”中的参数字段发送额外的请求选项，例如，保留较旧的 OCR 模型或匹配 Azure AI Foundry 端点的期望。 #33333、#19707、提交
  • 📉 负相关阈值。 管理设置 > 文档中的相关阈值现在对于返回低于零的原始分数的重新排序器采用负值，其中字段拒绝它们，并且负的“RAG_RELEVANCE_THRESHOLD”在混合搜索开启时使页面无法保存。 #33330、#29888、提交
  • 🎞️ ComfyUI 动画图像。 来自 ComfyUI 的“保存动画 WEBP”和“保存动画 PNG”节点的图像现在作为动画文件显示在聊天中，用于图像生成和图像编辑。 #33325、#33013、提交
  • 📡 指标跳过运行状况检查。 OpenTelemetry 指标现在会忽略 URL 与“OTEL_PYTHON_FASTAPI_EXCLUDED_URLS”或“OTEL_PYTHON_EXCLUDED_URLS”匹配的请求，因此运行状况检查和探测不再填充请求指标，就像跟踪已经跳过它们一样。 #33329、#31609、提交
  • 🗝️ 管理员管理用户 API 密钥。 管理员现在可以在“编辑用户”对话框中旋转或删除用户的 API 密钥，旋转后的密钥会显示一次，以便可以复制。 #32774、提交、提交
  • 👓 更多可隐藏的聊天控件。 管理员现在还可以通过管理设置 > 界面或“UI_VISIBILITY”中的可见控件隐藏聊天输入中显示的所选工具、技能、过滤器、网络搜索、图像生成和代码解释器。 #32408，提交
  • ♿ 改进了 UI 可访问性。 屏幕阅读器和键盘用户现在可以按消息移动聊天消息，每条消息的名称作为标题，使用箭头键、Home 和 End 在菜单和子菜单中移动，到达注释的生成标题按钮和使用鼠标打开的过滤器列表的选项，使用 Escape 和 Tab 离开比较修订编辑器，并听到日历事件窗口的每个字段、用户和反馈表的最后一列以及设置 > 使用中的每一天的名称热图虽然模型选择器仅勾勒出一行，但在窗口中打开时会获取键盘焦点，并在关闭时将焦点保留在该窗口中，并且选项卡行上的焦点轮廓不再被切断。
  • 🔄 一般改进。 在整个应用程序中实施了各种改进，以增强性能、稳定性和安全性。
  • 🌐 翻译更新。 葡萄牙语（巴西）、加泰罗尼亚语、意大利语、阿塞拜疆语、巴斯克语、孟加拉语、波斯尼亚语、保加利亚语、宿务语、克罗地亚语、捷克语、丹麦语、荷兰语、爱沙尼亚语、法罗语、菲律宾语、加利西亚语、格鲁吉亚语、德语、希腊语、希伯来语、印地语、匈牙利语、印度尼西亚语、爱尔兰语、日语、卡比尔语、韩语、拉脱维亚语、立陶宛语的翻译马来语、挪威语、博克马尔语、波斯语、波兰语、旁遮普语、罗马尼亚语、俄语、塞尔维亚语、斯洛伐克语、斯洛文尼亚语、西班牙语（西班牙）、瑞典语、泰米尔语、泰语、藏语、土耳其语、土库曼语、乌克兰语、乌尔都语、维吾尔语和越南语得到增强和扩展。

已修复

  • 🛡️ 安全建议：此版本包含安全修复。我们强烈建议尽快更新所有部署，以安装最新的安全修复程序。这些修复未在此 changelog 中列出；我们将在 CVE 分配后立即为他们发布安全公告。 咨询
  • 🔎 搜索对话框过滤器已恢复。 搜索对话框再次理解并建议使用“标签：”、“文件夹：”、“固定：”、“共享：”和“存档：”过滤器，其中添加一个会清空结果，根本找不到存档的聊天。 #33181、#32518、提交
  • 📍 按类型搜索位置。 搜索窗口中的位置过滤器现在仅列出聊天文件夹和消息频道，切换内容类型会清除不再适合的位置，这样的选择会返回空列表。 #33183、#33182、提交
  • 🧮 夸大的流式令牌计数。 当提供商在每个流式块上再次报告其使用情况（每个报告均已相加）时，回复的令牌计数不再夸大，因此回复和管理分析中显示的使用情况现在与提供商的最终计数相匹配。 #32052、#29064、#28528、提交
  • 📝 格式化后输入注释。 现在，在注释菜单中打开或关闭格式后，可以立即输入注释，编辑器将停止接受输入并保存，直到重新加载页面。 #33222，提交
  • 🎙️ 保留笔记录音。 现在，当在转录过程中连接断开时（例如，当笔记本电脑进入睡眠状态时），笔记中的录音会保留在笔记中。 #33240，提交
  • 🀄 使用退格键输入 IME。 在聊天输入中使用日语或其他输入法撰写文本时按退格键不再结束撰写或使文本出现两次，这从 0.12.4 开始。 #33245、#33223、提交
  • 🤖 子代理的照片。 模特现在可以将聊天中附加的照片交给子代理，但移交失败并显示“file_ids 未附加或不可用”并且没有启动子代理。 #33244、#33241、提交
  • 🪆 保留子代理部分输出。 在工具调用限制处停止的前台子代理现在将其部分输出与错误一起交给模型，其中它写入的所有内容都丢失了，并且错误现在在前台和后台都读取为纯消息。 #33269、#33267、提交
  • 🔗 MCP 故障保持聊天。 对无法访问的 MCP 服务器的工具调用（例如在重新启动或断开连接后）现在会自行失败，并且回复仍会完成，整个聊天会停止，就像您按下了停止键一样。 #33272、#33268、提交
  • 🔃 切断回复保持完成。 当连接稍后恢复时，因服务器重新启动而切断的回复不再返回到加载点。 #33277，提交
  • 🐢 聊天加载缓慢。 现在，在慢速连接上打开聊天或快速切换聊天会显示您打开的聊天，其中较慢的早期加载可能会用旧副本替换它，并且下一条消息会分叉聊天。 #33180，提交
  • 👁️ 关闭视觉的工具图像。 关闭视觉的模型现在会在工具返回的每个图像处显示一个简短的“[图像]”注释，其中回复因错误而失败，并且该聊天中的每条后续消息都以同样的方式失败。 #33345、#32720、提交
  • ✋ 其他人回复上的“停止”按钮。 在与“允许回复”共享的聊天中，“停止”按钮不再显示在其他人正在运行的回复上，它显示但没有执行任何操作。 #33343，提交
  • 🧷 拒绝共享更改已撤消。 当服务器拒绝更改时，提示、技能、工具、注释或知识库的访问对话框现在会返回到已保存的共享，其中会一直显示被拒绝的更改，就像已保存一样，并且模型编辑器现在会显示服务器针对此类拒绝的消息。 #33209、#33208、提交
  • 🔌 工具服务器标头重置。 在外部工具服务器中添加另一个连接现在以空标头开始，其中保留了前一个连接的标头并将其保存在新连接中。 #33201、#33200、提交
  • 🧰 列出了 OpenAPI 工具。 聊天中的可用工具窗口现在列出了 OpenAPI 工具服务器的工具，其中显示“未找到工具”。 #33205、#33204、提交
  • 🎛️ 生成开关更新。 在管理设置 > 界面中保存标题、后续、标签或自动完成生成现在会立即更新设置 > 界面中的匹配开关，并立即在聊天输入中自动完成，并保留旧设置直到重新加载。 #33197、#33196、提交
  • 🗂️ 本地知识过滤器。 在“工作区”>“知识”的源过滤器中选择“本地”现在会列出使用 Create 制作的知识库，其中显示“未找到知识”。 #33199、#33198、提交
  • 🪣 大型 S3 矢量删除。 现在可以从 S3 矢量中删除包含超过 500 个块的文件或知识库，但删除请求超出了服务的 500 个键的限制并失败。 提交
  • 🔢 清空嵌入批量大小。 在管理设置 > 文档中清除嵌入批量大小现在会保存默认值 1，之后上传的文件将无法处理。 #33288、#33287、提交
  • 🔊 使用 Kokoro.js 大声朗读。 现在，当在“设置”>“音频”中选择 Kokoro.js（浏览器）时，大声朗读会使用所选的 Kokoro 语音进行朗读，其中它使用浏览器的内置语音，而服务器的语音引擎是 Web API。 #33211、#33210、提交
  • 🔉 没有 GPU 的 Kokoro.js。 Kokoro.js（浏览器）现在在提供 WebGPU 但没有可用 GPU 的浏览器中的 CPU 上运行，其声音从未完成加载，并且 Read Aloud 一直在旋转而不说话。 #33233、#33232、提交
  • 🎨 报告 ComfyUI 失败。 ComfyUI 工作流程失败（例如，当 GPU 内存不足时），现在会显示错误并告诉模型无法制作图像，其中报告为成功生成但没有图像。 #33237、#33236、提交
  • 🖌️ 显示响应 API 图像。 模型通过响应 API 创建的图像（例如通过 OpenRouter 的 Gemini 图像模型）现在显示在聊天中，它们已保存但未显示。 #33320，提交
  • 🛝 应用了游乐场控制。 在游乐场的控制下选择的设置（例如温度和种子）现在到达 Ollama 模型，它们被丢弃，每次运行都会给出不同的回复。 #33286、#33285、提交
  • 📋 在频道中粘贴 Shift。 在将长文本粘贴到频道消息或线程回复中时按住 Shift，现在在启用“将大文本粘贴为文件”时将其保留为文本，就像在聊天中所做的那样。 #33190、#33189、提交
  • 🧵 加载时线程回复。 线程仍在加载时到达的线程回复或模型答案现在会完整显示，并且回复不再显示两次。 #33346、提交、提交
  • 👥 按组分析模型聊天。 管理分析中模型的“聊天”选项卡现在遵循用户组过滤器，其中列出了每个用户与该模型的聊天。 #33207、#33206、提交
  • 🙈 文件夹中的隐藏文件计数。 当“显示隐藏文件”关闭时，聊天终端文件浏览器中文件夹下的项目计数现在会忽略隐藏文件。 #33213、#33212、提交
  • 📁 保留展开的文件夹。 在聊天的“文件”选项卡中删除、重命名或添加文件现在会列出展开的文件夹，其中每个展开的文件夹都是空的。 #33195、#33194、提交
  • 📌 保留在共享文件夹中的图钉。 现在，当共享文件夹的所有者将其移动到该文件夹​​内的另一个文件夹（从该成员的固定列表中删除）时，成员的聊天会保留其图钉。 #33342、#33341、提交
  • 🌙 隔夜日历事件。 在午夜之后（例如晚上 8:00 到凌晨 1:00）结束的日历事件现在将其结束时间保留在第二天，保存时会将其删除并将该事件存储为在其开始时间结束。 #33290、#33289、提交
  • 🗓️ 午夜日历事件。 在午夜结束的日历事件现在仅在月视图中显示当天，并且也会在第二天显示。 #33292、#33291、提交
  • 🪝 旧的 Webhook 可移除。 v0.11 之前遗留下来的通知 Webhook 现在仍从“设置”>“通知”中删除，在“删除”后又立即返回。 #33295、#33294、提交
  • 🔔 新的默认通知目标。 删除最后一个通知目标后添加的通知目标现在成为默认目标，而以前从未这样做过。 #33284、#33283、提交
  • 🗣️ 翻译的搜索和技能标签。 工作区搜索、技能列表、技能编辑器和终端文件浏览器中的标签现在遵循界面语言，其中一些标签始终以英语显示。 #33308、#33304、#33305、提交

已更改

  • 🔀 模型切换保留您的选择。 现在，在聊天中切换模型会应用新模型的默认工具、技能、过滤器和功能，同时保留您自己打开或关闭的工具、技能、过滤器和功能，每次切换都会清除您的选择，并且与多个模型聊天现在可以获得每个选定模型的默认工具和技能。 提交、提交
  • 📣 模型提及切换聊天。 现在，向使用 @ 选择的模型发送消息会将聊天切换到该模型，其中提及保留在输入上方，并且聊天保留其自己的模型。 提交
  • 🔁 重新生成使用当前模型。 在与多个模型的聊天中重新生成响应现在使用当前为该列选择的模型，其中重用了首先写入响应的模型。 提交
  • 📎 页面中的注释附件。 附加到注释的文件现在位于添加它们的页面内，并且现有注释的附加文件移动到注释第一页的末尾。 提交
  • 📂 文件夹移动会保留聊天日期。 现在，将聊天移入或移出文件夹会保留其上次活动日期，因此它会按照上次真正活动的时间进行排序，并跳转到“今天”下方侧边栏的顶部。 #33327、#30362、提交

  • 📃 知识库 API 响应已修剪。 添加、更新或删除知识库文件以及通过 API 重命名或共享知识库现在仅返回受影响的文件或空列表，因此这些调用不再随着知识库的增长而减慢，并且可以从分页文件端点获取完整列表。 #33335、#31397、提交
