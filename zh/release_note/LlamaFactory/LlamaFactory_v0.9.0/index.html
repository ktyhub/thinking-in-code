LlamaFactory v0.9.0

恭喜您获得 30,000 颗星🎉 关注我们*X (twitter)*

新功能

  • 🔥支持在多图像数据集上微调 Qwen2-VL 模型，由 @simonJJJ 在 #5290 中提供
  • 🔥通过 @hiyouga 的 enable_liger_kernel 参数支持时间和内存效率**Liger-Kernel**
  • 🔥通过 @relic-yuexi 在 #5095 中的 use_adam_mini 参数支持内存高效 Adam-mini 优化器
  • 支持@hiyouga in #5365 和 @BUAADreamer in #4136 在视频数据集上微调 Qwen2-VL 模型（需要补丁 https://github.com/huggingface/transformers/pull/33307）
  • 使用 @hiyouga 的 RLHF/DPO/ORPO/SimPO 方法支持微调视觉语言模型 (VLM)
  • 通过 use_unsloth_gc 参数支持 Unsloth 的异步激活卸载方法
  • 支持vLLM 0.6.0版本
  • 支持#5388中@yzoaim的MFU计算

变化

  • 出于兼容性考虑，微调视觉语言模型（VLM）需要transformers>=4.35.0.dev0，请尝试安装pip install git+https://github.com/huggingface/transformers.git。
  • visual_inputs 已被弃用，现在您不需要指定此参数。
  • LlamaFactory 现在对多模式输入采用延迟加载，详细信息请参阅#5346。请使用 preprocessing_batch_size 来限制数据集预处理中的批量大小（由 #5323 中的 @naem1023 支持）。
  • LlamaFactory 现在支持 lmf（相当于 llamafactory-cli）作为快捷命令。
