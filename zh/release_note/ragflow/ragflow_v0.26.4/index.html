ragflow v0.26.4

总结

于 2026 年 7 月 7 日发布。

新功能

  • NLP/标记化：添加支持 16 种语言的语言感知 Snowball 词干分析器，在标记化管道中集成数据集 language 参数，并将荷兰语添加到前端。 #14140

错误修复

  • 解析包含“@”符号的 LM-Studio 模型名称时，系统崩溃并出现 ValueError。 #16467
  • MCP 服务器崩溃，因为 list_chats 函数需要来自 /chats API 的列表，但收到的是分页字典。 #16639
  • Docling 解析器默默地从文档中删除数学公式，而不是提取它们。 #16645
  • 系统无法将对元数据值进行的内联编辑保留到后端。 #16655
  • 将文件批量链接到数据集时，系统删除了现有链接。 #16587
  • 过滤器无法使用中文。 #16673
  • 系统未能强制标签权重必须大于零。 #16657
  • 代理提示下拉菜单的布局呈现不正确。 #16653
  • 法律词块划分器错误地将点号交叉引用分类为标题。 #16626
  • 系统无法阻止用户在编辑过程中保存重复的MCP服务器名称。 #16588
  • 系统允许用户导出空的 MCP 服务器选择。 #16589
