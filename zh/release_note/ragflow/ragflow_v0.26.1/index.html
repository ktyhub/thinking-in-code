ragflow v0.26.1

修订 发布时间2026年6月17日 来源infiniflow/ragflow 英文原文

ragflow v0.26.1

总结

新功能

  • 模型提供者：允许用户修改现有模型配置的模型类型。 #16029
  • 聊天通道：允许用户将 RAGFlow 助手部署为外部消息平台（如 Discord 和飞书）中的聊天机器人。 #15850
  • 可观察性：在 Langfuse 中按会话对多轮聊天轨迹进行分组，以方便对话调试和重播。 #15679

国际化

  • 为法语 UI 添加了约 70 个缺失的翻译键。 #15983

错误修复

  • 模型提供者：修复不准确的令牌计费，更正嵌入截断限制以防止索引失败，并重构错误处理以找出根本错误原因。 #15424
  • API：向 /chat/completions 端点添加传统模式以恢复 v0.23.0 样式的 <think> 输出以实现向后兼容性。 #16014 另请参阅与聊天助手交谈。
