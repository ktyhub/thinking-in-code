ragflow v0.25.3

修订 发布时间2026年5月13日 来源infiniflow/ragflow 英文原文

ragflow v0.25.3

总结

新功能

  • 数据源和解析：为电子表格文件解析器添加了列级语义/元数据控制；引入了 ETag 优化，用于 S3 数据源的增量同步，以避免不必要的文件传输。
  • 允许将特定角色（例如内容、元数据和主键）分配给表列。 #13710

改进

  • API 重构和安全
    • 继续将 Web API 过渡到 RESTful 约定，确保所有旧端点的向后兼容性。
    • 将 POST /api/v1/messages 中的 user_id 绑定到经过身份验证的 JWT 主体。 #14745
    • 保护沙箱执行器免受动态和间接代码执行绕过。 #14690
    • LLM请求超时控制
    • 高并发阻塞调用线程池
  • 减少摄取服务器启动时间。 #14894

错误修复

  • 多工作表 Excel 工作簿中的图像未按工作表划分范围，导致图像在不同工作表中错误归属。 #14120
  • 迭代项别名传递
  • 工具参数模板解析
  • 代码执行附件输出
  • 火山模型添加修复
