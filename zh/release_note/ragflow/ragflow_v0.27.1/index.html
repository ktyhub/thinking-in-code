ragflow v0.27.1

新功能

  • 用于数据源的新 Azure DevOps 连接器 (#18715)
  • 用于聊天和代理的新 You.com 网络搜索提供商 (#18478)
  • 用于聊天的新 Serply 网络搜索提供商 (#18475)

模型支持

  • 新的 Synthorai 模型提供程序（#18830）
  • 添加了缺少的 DeepSeek 模型 (#18678)
  • AWS Bedrock API 密钥身份验证支持（#18301）

改进

  • 检索 API 公开 rerank_candidates_count、knn top_k 和 num_candidates (#18768、#18737)
  • 元数据过滤器下推到元数据索引以加快检索速度 (#18219)
  • 聊天设置表单在保存时自动滚动到错误位置（#18811）
  • 搜索页面验证已删除的知识库（#18522）

错误修复

  • 修复了聊天中 PDF 解析失败的问题 (#18860)
  • 修复了 wiki 编译接受 LLM 错误响应的问题 (#18857)
  • 修复了 MinerU 渲染稳定性、错误可见性和代码块解析 (#18617)
  • 修复了 0 块数据集未显示的问题，防止滚动以获取更多数据集 (#18810)
  • 修复了 QA Excel 解析器删除答案为零的行 (#17902)
  • 修复了幼稚的解析器将空上传视为丢失的二进制文件的问题（#18826）
  • 修复了编码检测丢弃置信检测结果的问题 (#15793)
  • 修复了启用推理的聊天忽略对话框系统提示的问题（#18842）
  • 使用默认租户 LLM 而不是管道 LLM 修复了知识编译（#18572）
  • 修复了聊天网络搜索服务不允许为空的问题 (#18791)
  • 修复了 Firefox 聊天自动滚动未固定在底部的问题 (#18736)
  • 修复了聊天自动滚动不跟随流答案的问题 (#18570)
  • 修复了选择上传后解析进度不可见的问题 (#18741)
  • 修复了 BigQuery 连接器错误地构建 SQL 查询的问题 (#17500)
  • 修复了未传播的 WebDAV 列表错误，导致修剪数据丢失 (#18694)
  • 修复了数据源同步中的跨 KB 文档 ID 冲突 (#18244)
  • 修复了 GPUStack 模型发现和音频支持 (#18599)
  • 修正 Kimi K3 温度 (#18564)
  • 修复了未配置 image2text 模型时 OCR 文本丢失的问题 (#18012)
  • 修复了分层 Wiki 主题导航 (#18721)
