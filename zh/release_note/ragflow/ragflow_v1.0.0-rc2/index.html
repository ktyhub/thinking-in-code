ragflow v1.0.0-rc2

1.0.0-rc2 是 v1.0.0 的第二个候选版本。此版本修复了 rc1 中的几个问题并引入了新功能和扩展的支持。

亮点

1.引入代理聊天模式，取代低、中、高、超思维级别。 2. 保留与现有v1.0.0-rc1数据的兼容性，允许直接升级。 3.增加了对Team/Me共享的支持。 4. 增加了对模型提供商DemonRoute和Opper、网络搜索工具Firecrawl和Search1API以及MinerU 4模型的支持。 5. 新增捷克语、斯洛伐克语检索支持。 6. 将 12 个内置文档解析器与 Pipeline 解析器统一。 7. 添加了arm64架构的Docker镜像。
