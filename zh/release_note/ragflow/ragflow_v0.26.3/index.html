ragflow v0.26.3

总结

于 2026 年 7 月 2 日发布。

新功能

  • 数据源连接器：引入 Google BigQuery 作为数据源连接器，用于文档摄取和增量同步。 #15871
  • MCP：向 RAGFlow MCP 服务器添加两个 MCP 工具 ragflow_list_datasets 和 ragflow_list_chats。 #15384
  • 文件摄取
    • 将布局感知的 SoMark OCR 解析器集成到系统中，用于提取和索引复杂的文档元素（例如表格和图形）。 #16482
    • API：公开摄取文档端点，以使用自定义管道处理文档。 #16395

改进

  • 后端：引入批量文档上传部分成功处理，确保单个失败文件不再导致整个批次被丢弃。 #16438
  • UI/UX：重构全局标题，根据可用屏幕空间在完整的桌面导航栏和适合移动设备的侧抽屉之间动态切换，解决重叠问题并显着改善移动用户体验。 #15984

错误修复

  • 设置 Ollama 提供程序后，系统返回错误：“无法使用此 api 密钥访问模型（名称）”。 #16519
  • 由于索引未对齐，删除用户/助理聊天消息对时错误地删除了上一个对话回合的引用。 #16436
