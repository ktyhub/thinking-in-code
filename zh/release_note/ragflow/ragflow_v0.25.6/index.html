ragflow v0.25.6

总结

发布于 2026 年 5 月 26 日。

新功能

  • 代理：添加浏览器组件，使 AI 能够自主导航并与网页交互。 #14888

改进

  • RAG：RAPTOR 构建现在引入了 AHC 模式（Ψ-RAG），它将语义从文档级别扩展到数据集级别。不仅索引构建性能明显高于之前的 RAPTOR，而且在 Recall@5 和平均 F1 上也优于旧 RAPTOR。用户可以在 AHC 和 GMM 模式之间切换。此功能是在 v0.25.3 中引入的，此版本修复了多个错误。 #14674#14679
  • 代理：引入轻量级 @tool 装饰器来简化聊天模型的 Python 函数注册过程。 #15047
  • 代理：使代理消息能够显示 Base64 编码的图像。 #15212
  • 代理：将 Doc Generator 组件的文件元数据公开为离散变量。 #15080
  • 代理：允许开发人员将 chat_template_kwargs 传递给代理聊天完成端点。 #14182#14542

错误修复

  • 修复了 /chat/completions 以允许仅发送 API 有效负载中的最新消息，并删除了传输完整对话历史记录的要求。 #15197 另请参阅与聊天助手交谈。
  • 在检索阶段未应用分配给向量相似性的权重。 #15108
  • 修复了解析器配置未保存在数据集配置页面上的问题。
  • 数据源详细信息页面上的日志未完全显示。
  • 修复文档状态过滤失败的问题。
  • 修复了空 LLM 选择响应的崩溃防护。
  • RAG：使用 Infinity 文档引擎时，RAPTOR 构建过程停止。 #14998
  • 修复了 Mistral/Upstage 推理模型的流响应解析。
  • 修复了摄取管道解析器输出中的 HTML 标签。
  • 修复表解析器元数据。
  • 修复了异步事件循环嵌套和即发即忘任务问题。
  • 修复了 asyncio.Semaphore 绑定到不同事件循环的错误。
  • Agent：修复Agent组件提示变量消失和搜索向量相似度权重问题。
