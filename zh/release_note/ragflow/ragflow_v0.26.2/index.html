ragflow v0.26.2

总结

发布于 2026 年 6 月 29 日。

新功能

  • 聊天频道：
    • 通过二维码扫描集成 WhatsApp。 #16238
    • 通过机器人 API 凭证集成钉钉。 #16183
    • 通过 WebSocket 连接集成 WeCom。 #16175
  • 文件解析：为 PP-OCRv6 和类似文本识别模型添加后备逻辑，并将图像解析集成到 PaddleOCR 管道中。 #16150

改进

  • 数据集
    • 向文件摄取逻辑添加边缘情况检查，以将空文件夹安全地链接到数据集。 #16296
    • 向 get_flatted_meta_by_kbs() 方法添加分页，以防止与包含超过 10,000 个文档的数据集相关的 CRUD 失败。 #16095
  • 聊天频道：确保最终用户对话历史记录在重新启动后仍然存在，但当频道绑定到新对话框时仍然是独立的。 #16274

国际化

  • 扩大了 i18n 覆盖范围并完善了韩语 UI 的翻译。 #16203；
  • 添加了聊天频道、用户名验证和模型编辑缺失的法语翻译。 #16217

错误修复

  • 文件解析：
    • 在“标题”样式的 .docx 解析过程中引发了 ValueError。 #16284
    • .docx 文件中的表格已被法律文档解析器悄悄删除。 #16155
    • 设置 DeepDoc 分隔符时，单独的 Markdown 标头与其后续部分分开。 #16109
    • Markdown 表在块结果中出现两次，一次作为独立块，另一次在常规文本块中。 #16143
  • MCP
    • MCP服务器遇到空文档页面时无限期挂起；由于分页有缺陷，文件的最后一页被悄悄丢弃。 #16285
    • MCP 连接和数据集发现过程失败，因为服务器的硬编码提取限制超出了引入的 page_size 限制。 #16148
  • 数据流
    • 恢复数据流重新运行端点，并确保摄取响应包括 DSL 有效负载，以可靠地呈现时间线和解析器视图。 #16292
    • 恢复数据流解析器默认值并返回实际的 SSE 负载，确保管道正确运行表面消息 ID 和日志更新。 #16290
  • LLM：无法通过使用 eu 或 us 区域端点的 Google Cloud (Vertex AI) 提供商使用新的 gemini-3.5-flash 模型。这是通过将多区域路由请求明确地发送到所需的 aiplatform.<region>.rep.googleapis.com 域而不是合成的 <region>-aiplatform.googleapis.com 主机来解决的。 #15990
  • UI/UX：元数据添加模式将空值发送到后端。 #15229
