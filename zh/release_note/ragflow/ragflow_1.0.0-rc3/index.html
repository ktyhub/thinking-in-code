ragflow v1.0.0-rc3

1.0.0-rc3 是 v1.0.0 正式发布之前的第三个也是最后一个候选版本。它修复了 rc2 中发现的几个问题并引入了新功能和增强功能。

主要更新：

  1. 引入了代理工具循环内证据充分性判断的决策模型，以及代理的分类组件。 2.添加了对多个版本的摄取管道DSL的支持。
  2. 聊天历史记录现在存储并显示提示、令牌使用情况和执行时间。
  3. 兼容现有v1.0.0-rc2架构，可直接升级。
