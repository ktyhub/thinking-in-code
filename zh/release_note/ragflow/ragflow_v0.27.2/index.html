ragflow v0.27.2

新功能

  • Agentic RAG：重构了Agentic RAG检索框架，显着提高了推理速度和基准性能。 (#19046、#19112、#19172、#19209、#19424、#19459)
  • 知识编译运行时设置（#19254）
  • 对知识编译管道实施速率限制（#19156）
  • 知识图显示总节点数和当前节点数（#19142、#19095、#19114）
  • 在实体名称上按 Enter 键时，图形搜索会突出显示节点（#19320）
  • 用于基于 sitemap.xml 的 Web 摄取的新 Sitemap 数据源（#19344）
  • WebDAV 连接器支持自定义 CA 证书（#16901）
  • MonkeyOCRv2 解析支持（#18887）
  • 自托管 PaddleOCR-VL 部署支持（#19011）
  • 新的 Sofya 特工搜索工具 (#19323)
  • EPUB 文档预览 (#19242)
  • Excel 引用源位于文档预览中 (#18853)

模型支持

  • 新的 Hubris 模型提供商 (#19341)
  • 新的 llmman 模型提供程序（#19030）

改进

  • 新的 RERANK_TOKEN_LIMIT_MODE 配置（#19404）
  • 在检索测试和搜索中突出显示（#18981）
  • 相似度阈值显示为百分比（#18974）

用户界面/用户体验

  • 完成土耳其语言环境（#19009）
  • 在团队设置表中搜索突出显示的比赛 (#15985)

错误修复

  • 修复了聊天中上传的图像被视觉模型忽略的问题 (#18884)
  • 修复了 CSV/TXT 预览和文档解码中的非 UTF-8 编码（#19222、#19253）
