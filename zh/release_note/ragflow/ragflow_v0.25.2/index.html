ragflow v0.25.2

总结

改进

  • API 重构和统一：继续将 Web API 过渡到 RESTful 约定，确保所有旧端点的向后兼容性。

数据源

  • 引入轻量级快照机制，用于跨 Moodle、钉钉 AI Table、RSS 等 8 个数据源同步已删除文件，确保忠实反映所有远程数据源。 #14362#14499

错误修复

  • v0.24.0 到 v0.25.0 升级期间的元数据可见性问题。
  • 重复的聊天输出。
  • 元数据过滤在内存中处理，而不是利用 Elasticsearch，从而产生性能瓶颈。 #14576
