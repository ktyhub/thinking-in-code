:lady_beetle: 错误修复

  • 当 spring-boot-actuator-autoconfigure 存在且 spring-boot-health 不存在时，默认安全性配置错误 #50188
  • Elasticsearch Rest5Client 自动配置错误配置底层 HTTP client #50187
  • ApplicationPidFileWriter 无法正确处理符号链接 #50185
  • RandomValuePropertySource 不适合秘密 #50183
  • Cassandra 自动配置错误配置 CqlSessionBuilder #50180
  • ApplicationTemp 无法正确处理符号链接 #50178
  • Remote DevTools 执行比较不正确 #50176
  • spring.rabbitmq.ssl.verify-hostname 应用不一致 #50174
  • 配置分布汇总仪表的最小和最大期望值以及 SLO 边界时，将忽略整数值 #50077

  • 使用 @ServiceConnection 时，@Ssl 等注释不适用于 @Bean 方法 #50064

  • 当提供的模式无效时，来自 env 端点的 500 响应 #49946
  • 反应式 MongoDB 启动器对同步 MongoDB 驱动程序具有传递依赖性 #49945
  • 在 EndpointRequest 中配置排除时 HTTP 方法丢失 #49943
  • 荣誉 HttpMethod 用于反应式附加端点路径 #49880
  • Docker Compose 支持不适用于 apache/artemis 图像 #49869
  • Docker Compose 支持不适用于 apache/activemq 图像 #49866
  • 使用 WebMvcTest 和 spring-boot-security-test 时，Spring Security 的 PathPatternRequestMatcher.Builder 不会自动配置 #49854
  • API 版本控制路径策略应最后应用路径，因为它并不意味着产生 #49800
