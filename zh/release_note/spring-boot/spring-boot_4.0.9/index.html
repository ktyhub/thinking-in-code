spring-boot v4.0.9

修订 发布时间2026年10月22日 来源spring-projects/spring-boot 英文原文

spring-boot v4.0.9

:star: 新功能

  • 将 20_SEVEN 添加到 JavaVersion 枚举中 #51422

:lady_beetle: 错误修复

  • 当颁发者 uri 为空且设置了 jwk-set-uri 时，JWT 将被拒绝 #52249
  • 没有目录条目的嵌套 jar 缺少包清单属性 #52244
  • OriginTrackedPropertiesLoader 会删除名称以 # 或 ! 开头的属性#52207
  • OriginTrackedResource 未正确实现 equals #52205
  • 当在空闲服务器上 shutdownGraceously 后立即调用 stop 时，Tomcat 或 Jetty 的正常关闭可能会以 REQUESTS_ACTIVE 回调 #52195
  • TestPropertyValues 中的空系统属性被清除，而不是恢复为空值 #52125
  • 当凭证包含空格时 MongoDB 无法连接 #52121
  • 在 shutdownGraceously 之后立即调用 NettyWebServer 停止可能会挂起 #52119
  • spring.elasticsearch.uris 中配置的密码包含冒号时，身份验证失败 #52047
  • 当测试上下文框架暂停上下文时，日志记录可能会丢失 #51959
  • 当凭证包含需要 URL 编码的字符时，Docker Compose 对 MongoDB 的支持无法连接 #51939
  • 当 Actuator 在单独的端口上运行时，Jersey 不使用端点 ObjectMapper #51937
  • BasicJsonParser 错误处理嵌套列表和映射中的转义字符 #51907
  • 零周值转换失败，并出现“无法从 WEEKS 中提取 intValue”异常 #51892
  • 使用 DevTools 并在没有 spring-boot-jdbc 或 spring-boot-r2dbc 的情况下手动配置 JDBC 或 R2DBC 时，应用程序无法启动 #51872
  • Docker Compose 支持错误地识别 MARIADB_ALLOW_EMPTY_PASSWORD 而不是 MARIADB_ALLOW_EMPTY_ROOT_PASSWORD #51870
  • 不应用自动配置的 Kotlinx 序列化 JSON 编解码器自定义 #51842
  • 由于 NestedJarFileResources 中的竞争条件，使用 uber jar 时可能会引发 NullPointerException #51744
  • DevTools 未检测到反应式 Web 环境 #51708
  • 当rabbitmq Docker Compose服务配置为使用SSL时连接失败 #51666
  • 当 server.reactive.session.cookie.same-site 未设置时，会话 cookie 没有 SameSite 属性 #51636
  • OAuth2 资源服务器在单独设置时会忽略权限声明分隔符 #51619
  • 在反应式 Web 应用程序中，当云控制器 URL 不可用时，Cloud Foundry 安全集成返回 500 而不是 503 #51613
  • 一些断言消息命名了错误的参数 #51568
  • Maven 打包的战争中缺少 SBOM 相关的清单属性 #51551
  • 当环境变量没有值时，RabbitMQ 的 Docker Compose 集成会跳过凭证回退 #51546
  • jarmode 工具命令打印堆栈跟踪而不是错误消息 #51540
  • 图层创建失败时不会删除图层临时文件 #51519
  • 当缓冲区无法填充时，NestedByteChannel.read(ByteBuffer) 错误地返回 0 #51515
  • HTTP client 构建器中的定制器空检查断言错误的属性 #51509 -developmentOnly 和 testAndDevelopmentOnly 配置未指定任何导致潜在解析问题的属性 #51492
  • SQL Server Docker Compose 集成可能会重复 JDBC URL 的加密参数 #51467
  • SSL 主机配置自定义可能会在 Tomcat 初始化期间丢失 #51466
  • 当提供用户定义的 ClientRegistrationRepository bean 时，OAuth2ClientProperties 不可用 #51447
  • 所有 JSON marshal 测试人员都没有一致地关闭源 #51417
  • 如果启动立即失败，JmsHealthIndicator 会泄漏看门狗线程 #51412
  • SpringBootJoranConfigurator 中的文件句柄应该关闭 #51398
  • 部门验证
