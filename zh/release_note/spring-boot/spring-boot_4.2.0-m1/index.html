spring-boot v4.2.0-M1

预发布 发布时间2026年8月20日 来源spring-projects/spring-boot 英文原文

spring-boot v4.2.0-M1

:star: 新功能

  • 优化 Jetty 服务器的转发标头配置 #51148
  • 默认情况下在测试中禁用 Micrometer 全局注册表 #51142
  • 使用 GracefulHandler 而不是 StatisticsHandler 来协调 Jetty 的正常关闭 #51128
  • 弃用 RestTemplate 支持 #51118
  • 更新转发标头的属性以适应 Reactor Netty 更改 #51031
  • 更新转发标头的属性以适应 Spring Framework 更改 #51030
  • 删除在 4.2 中已弃用的 API #50955
  • 添加对基于图像的构建缓存的支持 #50899
  • 为 hibernate-maven-plugin 提供插件管理 #50892
  • RetryPolicySettings 中支持超时选项 #50891
  • 添加对 ApplicationContextAssertProvider 的自引用 #50500
  • 在 Kafka Streams 中添加 LeaveGroupOnClose 的配置属性 #50432
  • 在 ApplicationHome 和 ApplicationTemp 上公开 Path getters #50194
  • 引入 RabbitMQ AMQP 1.0 client 支持 #49857
  • 引入通用 AMQP 1.0 client 支持 #49678
  • 将 spring-boot-amqp 重命名为 spring-boot-rabbitmq #49677
  • 添加对 AMQP 1.0 的支持 #49619
  • 弃用 TestRestTemplate，转而使用 RestTestClient #46632
  • 当 spring-boot.run.useTestClasspath 生效时考虑目标/测试类 #36115

:lady_beetle: 错误修复

  • 结构化日志记录：失败的 JSON 编码会破坏同一线程上写入的下一个日志事件 #51371
  • 未考虑 Kafka 消费者特定的安全协议 #51370
  • 如果 gRPC 不存在，则暴露 gRPC 测试服务器端口应该退避 #51291
  • Micrometer 注册表固定应用程序上下文 #51136
  • ExportedImageTar 构建失败时不会删除临时文件 #51133
  • spring.grpc.server.health.include-overall-health 未考虑在内 #51106
  • 元数据注释处理器忽略记录的 getter 级别 @NestedConfigurationProperty #51099
  • spring-boot-h2-console 将 servlet-api 作为传递依赖项 #51096
  • PropertiesLauncher 不记录嵌套存档路径 #51090
  • 返回 Map#remove 结果的方法未使用 @Nullable 返回类型声明 #51088
  • NativeImageResourceProvider 扁平化子目录中的 Flyway 迁移路径 #50965
  • 修复了 Kotlinx Serialization CodecCustomizer 的排序 #50962
  • 从存档中查找主类时 JarFile 未关闭 #50960

:notebook_with_decorative_cover: 文档

  • spring.graphql.websocket.connection-init-timeout 的描述在参考指南中无法正确呈现 #51364
  • spring.profiles.group 应该有一个 ‘spring-profile-name’ 提示提供程序 #51285
  • 删除对已删除的 InfluxDB 自动配置的引用 #51177
  • 在 Kafka Streams 文档中使用 JacksonJsonSerde #51162
  • HttpMessageConverters 的文档替代方案 #51130
  • 修复 OTLP 日志记录传输元数据的过时类型引用 #51126
  • spring.test.mockmvc.htmlunit.url 的元数据声明了错误的类型 #51116
  • 缓存文档通过其 pre-4.0 包引用 AutoConfigureCache #51114
  • 修复元数据格式文档章节中的示例 #51103
  • 提高 AOT 缓存操作指南的可发现性 #51001

:hammer: 依赖升级

  • 升级到 ActiveMQ 6.3.1 #51334
  • 升级至[Artemis 2.55.0](https://activemq.apache.org/components/artemis/download/releas
