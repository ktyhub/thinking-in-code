spring-boot v4.2.0-RC2

:star: 新功能

  • 删除 LDAP SSL 重新加载支持 #52365
  • 使用 Reactor Netty 添加对 X-Forwarded-Prefix 的支持 #52316

:lady_beetle: 错误修复

  • 将 management.observations.conventions 设置为 open-telemetry 不会启用任何语义约定 #52619
  • 当上下文关闭时，PushGatewayTaskScheduler 无法正确关闭任务计划程序 #52591
  • ClearCachesApplicationListener 找不到继承的clearCache() 方法 #52589
  • BatchDataMongoAutoConfiguration 创建的 MongoTransactionManager 不是由 TransactionManagerCustomizers 自定义的 #52572
  • 配置处理器在完全限定时不处理已知类型 #52571
  • 报告无效的 AMQP Rabbit 主机并显示错误的值 #52568
  • 将持续时间转换为微秒时避免过早溢出 #52561
  • 从同一配置树绑定相同元素类型的集合后，从配置树绑定值失败 #52559
  • 当 usingPairs 与命名成员一起使用时，JsonWriter 写入无效的 JSON #52549
  • 当日志消息为空时，Logback GELF 结构化日志记录会写入空的短消息 #52547
  • 自动配置的 KafkaTransactionManager 不是由 TransactionManagerCustomizers 自定义的 #52542
  • Gradle 插件中的自定义层包含排除的内容而不是排除它 #52540
  • 启用 SSL 时，没有端口的 RabbitMQ 地址使用 AMQP 端口 #52538
  • BasicJsonParser 不解码 \b、\f、\n、\r、\t 和 \uXXXX 转义序列 #52534
  • 当 jar 没有注释时，NestedJarFile.getComment() 失败并出现 EOFException #52513
  • 纯文本线程转储将 Object.wait() 中的线程报告为 Java 19+ 上的停放状态 #52511
  • 同时使用 spring-boot-amqp-rabbitmq 和 spring-boot-rabbitmq 时，后者的健康信息会丢失 #52506
  • JSON 解析失败不再产生 DockerOutputParseExceptions #52500
  • ECS 结构化日志记录写入空服务和 service.node 对象 #52497
  • 如果多个端点共享相同的 ID，ConfigurationMetadataAnnotationProcessor 会生成不可重复的输出 #52494
  • Tomcat 或 Jetty 重新启动后，正常关闭不会等待活动请求 #52490
  • 配置 SSL 捆绑包时，RabbitMQ 默认使用错误的端口 #52488
  • 自动配置的 R2dbcTransactionManager 不是由 TransactionManagerCustomizers 自定义的 #52485
  • JsonWriter 将 NaN 和无限值写入无效 JSON #52483
  • ZipEndOfCentralDirectoryRecord 在 zip 注释中找到记录签名 #52481
  • 配置 LLDAP_LDAP_USER_DN 时，LLdap Docker Compose 支持无法连接 #52475
  • ZipContent.Entry hasNameStartingWith 忽略虚拟化嵌套目录名称的偏移量 #52464
  • ZipContent 无法在中央目录记录结束后打开包含数据的 zip #52461
  • 当存档具有前缀数据时，ZipContent 从错误位置读取 zip 注释 #52459
  • 无法检索根记录器配置，并且 Log4j2 没有配置级别 #52455
  • 当仅使用 HTTP 时，Docker Compose OTLP 集成需要公开 gRPC 和 HTTP 端口 #52451
  • Spring Batch JDBC 自动配置在启动时连接到数据库以检测其类型，但无法配置它 #52449
  • OnAvailableEndpointCondition 缓存通过其环境保留关闭的应用程序上下文 #52447
  • DataSourceTransactionManagerAutoConfiguration 使用旧的且不再受支持的属性来控制异常转换 #52445
  • Tomcat 的新“maxLocaleCount”属性无法轻松配置 #52443
  • DevTools 会在每次重启失败时泄漏文件观察器线程 [#52441](https://github.com/spring-projects/spri
