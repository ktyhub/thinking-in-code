spring-boot v3.2.7

修订 来源spring-projects/spring-boot

Spring-Boot v3.2.7

🐞 Bug 修复

  • 在添加 org.springframework.boot.jdbc.parameters 标签后，SQL Server JDBC URL 格式错误 #41146
  • 在升级 git-commit-id Maven 插件后，无法强制 Git 即时属性 #41109
  • MongoHealthIndicator 在严格设置下不符合 Mongo 稳定 API #41101
  • 如果未包含 java.sql 模块，DataSourceProperties 无法绑定 #41082
  • 构建镜像需要构建器指定堆栈 #41046
  • 尝试使用 Spring Boot 配置的 SSL 与 Tomcat 的 HttpNio2Protocol 时出现 IllegalArgumentException #41007
  • 当 Uber jar 包含具有 Multi-Release: true 的依赖项，并在 META-INF/versions 中有意外的文件条目时，无法启动 #41001
  • 当启用配置缓存时，Gradle 8.7 或更高版本下的 buildInfo 不起作用 #40911
  • 自动配置的 reactiveNeo4jTransactionManager 可能会因为有多个 TransactionManager beans 而导致失败 #40895
  • 当使用 GraalVM 时，Flyway 自动配置不支持 Flyway 10 #40821
  • 当配置了构建器和构建包时，构建镜像会挂起 #40697
  • 使用 ‘java -jar’ 运行时，Spring Boot 远程重启与 devtools 一起使用会导致 Tomcat 报 ‘factory already defined’ 错误 #39733
  • 当使用 Jetty 时，可能无法在可执行的 war 文件中找到 JSP 相关的资源 #39472
  • 从 DefaultErrorAttributes 中排除状态码会抛出 NPE #30011

📔 文档

  • 更精确地记录如何使用 Container 的 Docker 镜像名称来查找匹配的服务连接 #41111
  • 修复 MockServerRestClientCustomizer 和 MockServerRestTemplateCustomizer javadoc 中的拼写错误 #41052
  • 列出可观察性的三大支柱时，提高可读性 #41051
  • 修复方法名称和 javadoc 中的拼写错误 #40971
  • 在文档中警告，spring.profiles.group 只能在非特定配置文件中使用 #40918
  • 为 @Testcontainers 添加 Kotlin 示例 #40905
  • 修复文档的各种小不一致 #40900
