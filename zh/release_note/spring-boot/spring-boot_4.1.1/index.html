spring-boot v4.1.1

：警告：需要注意

  • 应用 Protobuf 插件时，Spring Boot 的 Gradle 插件不再自动配置 gRPC。对于那些在没有 gRPC 的情况下使用 Protobuf 的人来说，此行为会导致问题。要选择加入 gRPC 的配置，请使用空块通过 grpc 插件配置 protobuf 扩展。然后，Spring Boot Gradle 插件将像以前一样自动配置 protoc-gen-grpc-java 的使用。 #50822

  • 未考虑 Kafka 消费者特定的安全协议 #51369

  • 应用程序管理的 JUL 桥处理程序仅在安装后才应删除 #50950
  • CloudFoundry 反应式自动配置不应要求定义 WebClient.Builder bean #50944

  • 由于 Mongo 运行状况指示器导致连接数量较多 #50852
  • spring.security.oauth2.resourceserver.jwt Issuer-uri 和 jwk-set-uri 的空字符串值处理不一致 #50849

  • PropertiesWebClientHttpServiceGroupConfigurer 具有最高优先级，防止其他配置器在其之前排序 #50843
  • 如果 gRPC 不存在，则暴露 gRPC 测试服务器端口应该退避 #50825
