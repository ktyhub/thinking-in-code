:star: 新功能

  • 当 SSL 捆绑包被覆盖为空字符串时，不应启用 SSL #50635
  • 测试自动配置不再将 Spring Security 与 HtmlUnitDriver 集成 #50633
  • 配置属性元数据包含不正确的类引用 #50632
  • Docker Compose 支持在捕获 InterruptedException 时不会恢复线程中断标志 #50618

  • 当 SSL 捆绑包使用 client-auth 或不带服务器名称捆绑包的服务器 truststore 时，reactor-netty SniProvider 中出现 NullPointerException #50610
  • SpringJtaPlatform 自 4.1.0-M3 起就应该被弃用 #50592
  • 在根目录中使用提取层时，在“//”输出位置之外写入的层会引发异常 #50510

  • 创建的 StackTracePrinter 实例无法访问环境 #50414
  • 当父级存在时，MappingsEndpoint 将上下文自己的 ID 报告为 ParentId #50412
  • Buildpack 模块不验证 long 到 int 的转换 #50410
  • 如果使用 protobuf-java 依赖项而不是 protobuf-java-util，Gradle gRPC 支持失败 #50405
  • GraphQL WebSocket 支持不配置允许的来源 #50394
  • Spring Boot 加载器不支持 RSA 和 EC 签名 Jars #50298
  • 上下文关闭时，仪表注册表不会从全局注册表中删除 #50287
  • DataSourceBuilder 无法从惰性连接代理派生数据源 #50271
  • AbstractErrorController.getErrorAttributes 中的可为空注释与实现不一致 #50266
  • 在调用 setAllowBeanDefinitionOverriding 之前，可以使用初始化程序添加 Bean 定义 #50264
  • EndpointRequest 链接匹配器不必要地匹配除 GET 之外的 HTTP 方法 #50261
  • 如果使用名为 corsConfigurationSource 的 bean 提供限制性 CORS 配置，则执行器的“/cloudfoundryapplication”端点不起作用 #50258
  • 配置等待终止时间时，ThreadPoolTaskScheduleBuilder 不必要地丢失精度 #50234
  • NimbusJwtDecoder 静默接受 spring.security.oauth2.resourceserver.jwt.jws-algorithms 的未知值 #50228
  • spring-boot-web-server-test 缺少依赖管理 #50224
  • Spring Batch 对 MongoDB 模块的支持不包含在依赖管理中 #50223
  • 将 HTML escaping 应用于 Whitelabel 错误页面中的时间戳属性 #50216
  • GrpcServerHealthScheduler 在 servlet 环境中未启动 #50209
  • 使用 Tomcat 时设置 server.servlet.session.cookie.partitioned=true 无效 #50204
