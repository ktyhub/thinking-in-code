spring-boot v4.2.0-M2

:star: 新功能

  • 弃用 AppOptics，因为它已退休 #51810
  • 提高 jar 创建和提取期间的类路径条目查找性能 #51787
  • 添加 spring.kafka.listener.await-async-results-on-stop 属性 #51774
  • 合理化 KafkaProperties 之外的 Kafka 配置 #51769
  • 在自动配置的 DefaultMeterObservationHandler 上选择启用活动 Observation LongTaskTimer #51762
  • 在 GraphQL 传输中配置允许的 HTTP 方法 #51732
  • 允许将 Mongo JobRepository 与任何 PlatformTransactionManager 一起使用 #51725
  • 解决构造函数绑定默认值中的属性占位符 #51661
  • 为 OpenTelemetry 标签字段添加自动配置的 BaggageTaggingSpanProcessor #51656
  • 提高图层索引创建的性能 #51654
  • 提取分层 jar 时加快层查找速度 #51653
  • 将 Tomcat 的 servlet 特定属性移至 server.tomcat.servlet 下 #51603
  • 将 SPRING_APPLICATION_JSON 中的 null 和空值处理与 YAML 处理对齐 #51583
  • 删除 Janino 的依赖管理 #51567
  • 添加 jarmode 工具命令来打印/导出 SBOM #51505
  • 获取测试类上的所有 @TypeExcludeFilters 注释 #51489
  • 更轻松地将 MessageSourceProperties 映射到用户提供的 AbstractResourceBasedMessageSource #51484
  • 支持多段附加健康端点路径 #51470
  • 尊重嵌入式 LDAP 服务器中的 spring.ldap.* 属性 #51465
  • 添加配置属性，用于配置需要身份验证的嵌入式 LDAP 操作类型 #51461
  • 将 20_SEVEN 添加到 JavaVersion 枚举中 #51427
  • 自动从 Spring Boot 构建的档案中过滤其他配置元数据 #51386
  • 将 SSL 捆绑支持添加到 LDAP 自动配置 #51382
  • 将 server.tomcat.use-relative-redirects 的默认值与 Tomcat 的默认值对齐 #51173
  • 允许配置微米追踪 MDC 密钥 #50595
  • 添加端点、压缩和标头的通用 OTLP 配置 #50461
  • 在探针运行状况组上配置其他属性时保留探针默认值 #50296
  • 在 WebFlux Cloud Foundry 端点响应中包含安全错误正文 #50256
  • 提供配置属性以从 Micrometer 切换到 OpenTelemetry 语义约定 #49241
  • 支持侦听器和模板特定的 Kafka 管理属性 #38830

:lady_beetle: 错误修复

  • spring.http.clients.cookie-handling 在使用由 HttpComponents 连接器支持的反应式 client 时无效 #51767
  • 由于 NestedJarFileResources 中的竞争条件，使用 uber jar 时可能会引发 NullPointerException #51746
  • 当rabbitmq Docker Compose服务配置为使用SSL时连接失败 #51668
  • Maven 打包的战争中缺少 SBOM 相关的清单属性 #51652
  • 当 server.reactive.session.cookie.same-site 未设置时，会话 cookie 没有 SameSite 属性 #51640
  • OAuth2 资源服务器在单独设置时会忽略权限声明分隔符 #51631 -developmentOnly 和 testAndDevelopmentOnly 配置未指定任何导致潜在解析问题的属性 #51624
  • 在反应式 Web 应用程序中，当云控制器 URL 不可用时，Cloud Foundry 安全集成返回 500 而不是 503 #51615
  • ReactiveOAuth2ResourceServerWebSecurityAutoConfiguration 注释有错误条件 #51588
  • WritableJson.toByteArray() 可能会损坏增补字符 #51586
  • 图层创建失败时，图层临时文件不会被删除 [#51582](https://github
