daily_stock_analysis v3.29.0

daily_stock_analysis v3.29.0

v3.29.0

发布亮点

  • 壮举：参考AlphaSift实现的选股核心与正式策略纳入DSA，统一将选股服务与API，并新增运行历史、数据源历史和候选深度分析队列。
  • 壮举：新增1080px个股决策卡与高密市场复盘分享图，支持中英韩模板、Web原创分享、下载回退和可配置品牌元素。
  • 壮举：新增技能意见结果形成计算、表现统计及基于真实样本的有界时运行权重，让策略后验评估可追踪闭环。
  • 改进：优化选股快照复用、热点瞬时加载、多源并发、候选轮换和运行阶段展示，全局长流程等待并提升结果稳定性与多样性。
  • 修复：胶原关闭认证二次确认、短电平诊断脱敏、CI超时取证和PyInstaller/NLTK桌面启动仓库。
  • 修复：修复Longbridge量比参数、回测股票身份与日线窗口、选股后置重排，以及分享图用户激活等正确性问题。

发生了什么变化

  • 将受 AlphaSift 启发的筛选核心和策略集成到 DSA 中，具有统一的 ScreeningService、/api/v1/screening、持久运行/源历史记录、公告上下文以及候选者到深度分析的切换（作者：@ZhuLinsen）。
  • 添加了专用的 1080px 股票决策卡和密集的市场评论共享图像，具有结构化有效负载渲染、多语言模板、本机 Web 共享支持、下载回退和可配置品牌，作者：@ZhuLinsen。
  • 在独立的 30 个评估样本阈值之后添加了版本化技能意见结果评估、只读性能统计数据和有界贝叶斯运行时权重，作者：@ObVious55。
  • 强化筛选排名和分析后排序、有界近分候选轮换、快照重用、热点按需加载、多源并发、超时清理和面向用户的诊断，作者：@ZhuLinsen。
  • 禁用身份验证时需要进行当前密码验证，改进了短凭据编辑，并向发布后端门添加了超时/故障处理程序证据，作者：@xxiaoxiong。
  • 通过@xxiaoxiong、@ObVious55 和@ZhuLinsen 修正了受支持的SDK 签名中的Longbridge 容量比调用，加强了回测股票身份和每日窗口分辨率，并强化了桌面冻结包启动和共享映像回退行为。
