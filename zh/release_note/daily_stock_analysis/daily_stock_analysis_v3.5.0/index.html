daily_stock_analysis v3.5.0

小版本 发布时间2026年3月12日 来源ZhuLinsen/daily_stock_analysis 英文原文

daily_stock_analysis v3.5.0

添加

  • 📊 Web UI 完整报告抽屉（修复#214）——历史页面添加“完整报告”按钮，以在侧抽屉中显示完整的 Markdown 分析报告；新的 GET /api/v1/history/{record_id}/markdown 端点
  • 📊 LLM 成本跟踪 — 所有 LLM 通话（分析、代理、市场审查）都记录在 llm_usage 表中；新的 GET /api/v1/usage/summary?period=today|month|all 端点按调用类型和模型返回聚合令牌使用情况
  • 🔍 SearXNG 搜索提供商（修复 #550）— 无配额的自托管搜索后备；优先级：Bocha > Tavilly > Brave > SerpAPI > MiniMax > SearXNG
  • 🔍 MiniMax 网络搜索提供商 — MiniMaxSearchProvider 带断路器（3 次故障 → 300 秒冷却时间）和双时间过滤；通过 MINIMAX_API_KEYS 配置
  • 🤖 代理模型发现 API — GET /api/v1/agent/models 返回 Web UI 模型选择器的可用模型部署（主要/后备/源/api_base）
  • 🤖 代理聊天导出和发送 (#495) — 将对话导出到 .md 文件；发送到配置的通知渠道；新POST /api/v1/agent/chat/send
  • 🤖 代理后台执行 (#495) — 切换页面时分析继续；完成时发出徽章通知；在会话切换时自动取消正在进行的流
  • 📝 报告引擎 P0 — LLM JSON 的 Pydantic 模式验证； Jinja2 模板（markdown/wechat/brief）具有遗留后备功能；通过重试检查内容完整性；简短模式（REPORT_TYPE=brief）；历史信号比较
  • 📦 智能导入 — 从图像/CSV/Excel/clipboard 进行多源导入； Vision LLM提取code+name+confidence；名称→代码解析器（本地地图+拼音+AkShare）；置信度分层确认
  • ⚙️ GitHub Actions LiteLLM 配置 — 工作流程支持 LITELLM_CONFIG/LITELLM_CONFIG_YAML 以实现灵活的 AI 提供商配置
  • ⚙️ 配置引擎重构和系统 API (#602) — 统一配置注册表、验证和 API 暴露
  • 📖 LLM 配置指南 — 新的 docs/LLM_CONFIG_GUIDE.md 涵盖 3 层配置、快速启动、Vision/Agent/故障排除

已修复

  • 🐛 analyze_trend 总是报告没有历史数据 (#600) — 现在从 DB/DataFetcher 获取而不是损坏的 get_analysis_context
  • 🐛 LLM 忽略时的芯片结构回退 (#589) — 从数据源芯片数据自动填充，以实现跨模型的一致显示
  • 🐛 历史狙击点显示原始文本 (#452) — 优先考虑原始字符串而不是压缩数值
  • 🐛 GitHub 操作 ENABLE_CHIP_DISTRIBUTION 可配置 (#617) — 不再硬编码，支持 vars/secrets 覆盖
  • 🐛 .env 保存保留注释和空行 — Web 设置不再破坏 .env 格式
  • 🐛 代理模型发现修复 — 遗留模式包括 LiteLLM 原生提供商；源检测与运行时一致；后备部署不再按键扩展
  • 🐛 Stooq 美国股票前收盘价语义 — 不再误用开盘价作为前收盘价
  • 🐛 股票名称预取回归 — 在远程查询之前优先考虑本地 STOCK_NAME_MAP
  • 🐛 AkShare 涨跌停板计算 (#555) — 固定市场分析统计
  • 🐛 AkShare 腾讯源字段索引和 ETF 报价映射 (#579)
  • 🐛 Pytdx 股票名称缓存分页 (#573) — 防止缓存溢出
  • 🐛 PushPlus 超大报告分块 (#489) — 自动分段长内容
  • 🐛 代理聊天取消和切换 (#495) — 取消不再误报为失败；快速切换不再覆盖流状态
  • 🐛 /status 命令中的 MiniMax 搜索状态 (#587)
  • 🐛 config_registry 重复 BOCHA_API_KEYS — 删除了默默覆盖配置的重复字典条目

已更改

  • 🔎 Fetcher 失败可观察性 — 日志记录启动/成功/失败以及经过的时间、故障转移转换； Efinance/Akshare 包括上游端点和分类故障类别
  • ♻️ 数据源弹性和清理 (#602) — 后备链优化
  • ♻️ 图像提取 API 响应扩展 — 新的 items 字段（代码/名称/置信度）；保留 codes 以实现向后兼容
  • ♻️ 导入解析错误消息 — Excel/CSV 的具体失败原因；改进了文件类型和大小的日志记录

文档

  • 📖 LLM 配置指南为了清晰而重构 (#583)
  • 📖 image-extract-prompt.md 带有完整的提示文档
  • 📖 AkShare 后备缓存 TTL 文档
