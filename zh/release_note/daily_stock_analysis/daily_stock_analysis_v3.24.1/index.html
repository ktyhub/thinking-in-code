daily_stock_analysis v3.24.1

v3.24.1

v3.24.1 取代未成功出桌面包的 v3.24.0，作为本轮正式发布版本；包含 v3.23.0 之后的全部主要变更，以及 v3.24.1 的发布打包修复。

v3.24.1 取代了 v3.24.0，其桌面包未成功发布。这是自 v3.23.0 以来所有重大更改的有效版本，加上 v3.24.1 包装修复。

发布亮点

  • feat: 扩展台股、日股、韩股市场支持，覆盖 suffix-only 个股分析、台股三大法人资料层、JP/KR 大盘复盘和跨服务市场枚举。
  • feat: 接入 TickFlow 核心 A 股数据源，增强 A 股日 K、实时行情、股票列表/名称数据源和批量预取能力。
  • feat: 新增 GenerationBackend 抽象、codex_cli 本地 CLI backend、Hermes 本地 HTTP 渠道和 prompt cache capability registry。
  • feat: Web/API/Desktop 支持多时间定时推送与 runtime scheduler 热重建，Web 设置页补齐首次启动配置检查和定时任务面板。
  • improve: 报告与通知链路补齐信号归因、单股信号时间线、概念板块排行和关联板块展示，减少 AI 建议与报告详情之间的重复展示。
  • fix: 修复桌面/Docker 发布依赖、Windows 静态资源 MIME、回测空结果、通知 Markdown、Docker Webhook 模板占位符和 AlphaSift 数据源稳定性问题。

发生了什么变化

  • 扩大了台湾、日本和韩国市场覆盖范围，包括仅后缀分析、台湾机构流动、日本/韩国市场审查以及 @WenyuChiou 和 @ZhuLinsen 的市场枚举传播。
  • 新增 TickFlow 作为核心 A 股数据源，具有更强的报价、K 线、股票列表和 @timeance 的预取覆盖范围。
  • 添加了本地生成基础设施：GenerationBackend、codex_cli、Hermes 本地 HTTP 生成以及 @massif-01 提供的提示缓存功能控制。
  • 通过 @ZhuLinsen、@RajvardhanPatil07、@hsms4710-pixel 和 @diveintonull 改进了 Web/API/桌面调度、首次运行设置、报告信号、概念板上下文和 AI 建议工作流程。
  • 由 @ZhuLinsen 和 @LunarFeller 提供的跨桌面、Docker、静态资产、回测、通知、AlphaSift 和 Longbridge SDK 依赖项解析的强化版本打包和运行时稳定性。

贡献者

@ZhuLinsen、@WenyuChiou、@timeance、@massif-01、@hsms4710-pixel、@RajvardhanPatil07、@diveintonull、@LunarFeller
