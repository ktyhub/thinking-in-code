spring-ai-alibaba v1.1.2.0

修订 发布时间2026年2月2日 来源alibaba/spring-ai-alibaba 英文原文

spring-ai-alibaba v1.1.2.0

此版本将 Spring AI 升级到 1.1.2，添加了对 Agent Framework 的 Agent Skills 支持，添加了工作流代理（LlmRouting、Supervisor）的并行子代理执行，使用并行条件边、并行聚合策略（allOf 和 anyOf）、异步工具执行和工具 returnDirect 扩展了图。它还包括序列化和 MergeStrategy 修复、管理/UI 修复以及文档更新。

请参阅文档了解更多详细信息。

特点

代理

  • ReactAgent 中的代理技能 (#3975) — ReactAgent 中的集成技能功能，支持技能和过于渐进的披露。
  • 内置多代理模式支持 — 支持路由、主管、主管（代理作为工具）、切换、技能等，多代理模式；添加了对路由和主管模式的并行执行支持。
  • 流代理挂钩支持 (#3983) — 所有流代理（路由、管理器、循环、顺序等）都支持自定义 Hook。
  • 新代理 API (#4031) — 新 streamMessages API 用于简化消息流；用于额外输入的新过载 invoke 和 call 方法。
  • 异步和并行工具执行 (#4037) — 支持并行工具执行和异步工具执行。
  • 工具 returnDirect (#4139) — 支持工具 returnDirect 行为。
  • ToolContextHelper (#4163) — 用于工具上下文中元数据访问的帮助程序类（修复#3110）。

图

  • 并行条件边 (#4027) — 条件边支持并行执行（修复#3917）。
  • 并行分支的聚合策略 (#4028) — 并行分支的新聚合策略（AllOf 和 A​​nyOf）。
  • 并行分支的批量 addEdge (#3938) — 用于 StateGraph 中并行分支定义的便捷批量 addEdge 方法。
  • interruptAfter 钩子 (#3864) — InterruptableAction 支持 interruptAfter 钩子（修复#3447、#3904）。
  • AgentToolNode 的异步工具执行 (#4037 / #3988) — 对 AgentToolNode 的异步工具执行支持。
  • 流节点的完整输出 (#3941) — 流节点现在发出完整输出，包括 _FINISHED OutputType。

沙盒和工作室

  • SAA Sandbox (#4069) — 新的 SAA Sandbox 模块，提供安全且隔离的工具执行。
  • 内置 RenderTemplate (#3935) — 内置自定义 RenderTemplate 实现。
  • Studio CORS 可选 (#4154) — CORS 配置现在在 Studio 中是可选的。

修复

DashScopeChatModel

  • #3942 (spring-ai-alibaba/spring-ai-extensions#140) 中报告的连接重置 — 为 DashScopeApi 设置默认 HTTP client 以更好地管理连接，避免模型服务器关闭连接时出现连接重置问题。

图

  • 序列化 (#3969) - 修复了序列化中的 class 错误（修复了 #3895、#3931）。
  • MergeStrategy (#4129) — 更正了 Optional 处理并在 MergeStrategy 中强制执行严格的类型检查（修复 #3909）。

代理

  • 指令 (#3974) — 添加指令处理；修复了 CI 和测试。
  • AgentLlmNode 模型选项 (#3986) — 防止 AgentLlmNode 覆盖默认模型选项；确保为 ChatOptions 设置 internalToolExecution(false)（修复 #3903）。
  • selectorModel (#4045) — 添加了 selectorModel 支持（修复了 #4026）。
  • systemPrompt (#4067) — 修复了系统提示处理。
  • ParallelAgent maxConcurrency (#4053) — 确保实现 ParallelAgent 的 maxConcurrency 功能。
  • jumpTo (#4081) — 确保 jumpTo 正确运行。
  • ModelRequest 构建器 systemMessage (#4138) — ModelRequest 构建器不再丢失 systemMessage。
  • NacosReactAgentBuilder (#4093) — 修复了 NacosReactAgentBuilder 以正确合并本地工具。
  • AgentLlmNode 工具回调 (#4112) — 更正了 AgentLlmNode 中的工具回调过滤逻辑。

管理和用户界面

  • 管理包重命名 (#3977) — 将 @agentscope-ai/flow 重命名为 @spark-ai/flow（修复 #3949）。
  • 管理启动/编译 (#4123) — 修复了 spring-ai-alibaba-admin 启动和编译问题。
  • CustomInputsControl (#4106) — 向 CustomInputsControl 添加了 variableList 属性。

依赖关系

  • Spring AI 版本 — Spring Ai 升级为 1.1.2
  • Spring AI 阿里巴巴扩展版本 — Spring Ai 阿里巴巴扩展升级到 1.1.2.1

升级注意事项

  • Spring AI：此版本使用 Spring AI 1.1.2。相应地调整项目的 Spring AI 版本。
  • 管理员：如果您使用管理流程 UI，请将依赖项从 @agentscope-ai/flow 更新为 @spark-ai/flow。
