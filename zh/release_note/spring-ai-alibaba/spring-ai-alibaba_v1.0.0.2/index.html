spring-ai-alibaba v1.0.0.2

大版本 发布时间2025年5月29日 来源alibaba/spring-ai-alibaba 英文原文

spring-ai-alibaba v1.0.0.2

我们很高兴地宣布发布 Spring AI 阿里巴巴 1.0.0.2，第一个 GA 版本！ Spring AI阿里巴巴基于Spring AI构建并与百联深度集成，支持ChatBot、Workflow和Multi-agent应用程序的开发。

主要特点

1.全面的框架集成

  • 与阿里云集成：无缝对接阿里云服务，包括百联的Dashscope，支持Qwen、Deepseek等多种主流AI模型。

2.多代理框架

  • 基于图的多代理框架：受 Langgraph 启发，Spring AI 阿里巴巴图 可以轻松构建工作流程和多代理应用程序。

3.企业级人工智能代理解决方案

  • Nacos MCP 注册中心
    • 分布式MCP发现和负载平衡
    • 动态 API 到 MCP 代理
  • NL2SQL 用于将自然语言查询转换为 SQL 语句。
  • 可观察性

开发者经验

快速入门指南

通过将以下依赖项添加到您的 Spring Boot 项目，使用 Spring AI 阿里巴巴启动您的第一个 AI 应用程序：

<dependencyManagement>
    <dependencies>
        <dependency>
            <groupId>com.alibaba.cloud.ai</groupId>
            <artifactId>spring-ai-alibaba-bom</artifactId>
            <version>1.0.0.2</version>
            <type>pom</type>
            <scope>import</scope>
        </dependency>
    </dependencies>
</dependencyManagement>

<dependencies>
    <dependency>
        <groupId>com.alibaba.cloud.ai</groupId>
        <artifactId>spring-ai-alibaba-starter-dashscope</artifactId>
    </dependency>
</dependencies>

Spring Boot 启动器

  • spring-ai-alibaba-starter-dashscope - 集成模型服务适配
  • spring-ai-alibaba-graph-core - AI Graph框架的核心组件
  • spring-ai-alibaba-starter-nl2sql - 自然语言到 SQL 转换组件
  • spring-ai-alibaba-starter-memory - 会话内存组件
  • spring-ai-alibaba-starter-nacos-mcp-client - Nacos MCP client；推荐版本：Nacos 3.0.1。对于Nacos 2 Server用户，请使用旧版本（spring-ai-alibaba-starter-nacos2-mcp-client）。
  • spring-ai-alibaba-starter-nacos-mcp-server - Nacos MCP 服务器；推荐版本：Nacos 3.0.1。对于Nacos 2 Server用户，请使用旧版本（spring-ai-alibaba-starter-nacos2-mcp-server）。
  • spring-ai-alibaba-starter-nacos-prompt - Nacos Prompt管理
  • spring-ai-alibaba-starter-arms-observation - ARMS 可观察性
  • 社区组件
    • spring-ai-alibaba-starter-tool-calling-* - 工具调用组件
    • spring-ai-alibaba-starter-document-reader-* - 文档阅读组件
    • spring-ai-alibaba-starter-vector-store-* - 矢量商店组件

示例项目

官方社区基于Spring AI阿里巴巴开发了一个Playground示例，包含完整的前端UI和后端。 Playground允许用户体验聊天、可观察性、多轮对话、图像生成、多模态、工具调用、MCP和RAG等所有核心框架能力。 更多使用案例请参见【Spring AI阿里巴巴示例库】(https://github.com/springaialibaba/spring-ai-alibaba-examples)。
