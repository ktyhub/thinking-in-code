:lady_beetle: 错误修复

  • 当请求的偏移量丢失时，KafkaTemplate.receive() 返回不同偏移量的记录 #4830
  • GH-4823：在子容器之间保持分区暂停 #4828

  • 当默认 BackOff 没有重试时，DefaultErrorHandler 会忽略 backOffFunction #4818
  • Flaky BatchListenerConversionTests.conversionError() #4817
  • 共享容器 isInExpectedState() 忽略因错误而退出的消费者线程 #4814
  • 当发送失败时，ReplyingKafkaTemplate 回复未来超时而不是失败 #4811
  • AbstractConsumerSeekAware.onPartitionsRevoked() 删除其他消费者的回调 #4808
  • RoutingKafkaTemplate.partitionsFor() 抛出 UnsupportedOperationException #4805
  • 共享消费者确认超时警告忽略 renew() #4804
  • Lambda 或方法引用 Converter beans 破坏 @KafkaListener 启动 #4802
  • CommonMixedErrorHandler 不委托 onPartitionsAssigned()，在批量重试期间丢失记录 #4797
  • 支持 DelegatingByTopicDeserializer 中的两个参数反序列化 #4794
  • 使用 Kafka 4.4 clients 映射出站的反序列化异常标头 #4775
  • 协作重新平衡可以让消费者保留永久未使用的分区（异步侦听器）#4772
  • 当 BackOff 有其自身限制时，重试主题使用 BackOff.STOP (-1) 作为延迟 #4770
  • AbstractConsumerSeekAware 在注销后保留回调映射 #4767
  • 当seekAfterError为假时，混合和委托错误处理程序丢弃剩余的批记录#4765
  • ExponentialBackOffWithMaxRetries(0) 仍然重试一次 #4760
  • 使 ExceptionMatcher 缓存线程安全 #4757
  • 部分批次确认后的 acknowledge() 仅提交下一条记录 #4734
  • ConcurrentMessageListenerContainer 不报告来自子容器的分区暂停请求 #4730
  • 在 DefaultShareConsumerFactory 中应用引导服务器供应商 #4699
  • 暂停 @KafkaListener：消费者永久停止获取其在重新平衡过程中保留的分区 #4696
  • 异步侦听器回复成功路径永远不会向接收方观察报告失败 #4686
  • 待处理的消费者唤醒中止下一个偏移量提交，然后跳过 #4683
  • 停止时清空排队的共享确认 #4680
  • 在 copyWithType 中复制类型解析器 #4666
  • 从主题模式或分区列表构建时在 start() 处共享 KafkaMessageListenerContainer NPE #4664
  • 不验证空反序列化值 #4656
  • ShareConsumerAcknowledgment 状态可以从终端类型回归到 RENEW #4646
  • 当存在 JSON 类型标头时，多值标头映射会丢失入站值 #4644
  • ReplyingKafkaOperations sendAndReceive 重载暴露了replyTimeout 和 returnType 不正确的可空性 #4642
  • 由于非传递比较器，DelegatingByTypeSerializer 可分配模式可以选择更通用的委托 #4633
  • 共享容器忽略 ContainerProperties.clientId #4627
  • ShareKafkaListenerContainerFactory.createContainer(String…) 不应用工厂配置 #4617
  • 当没有源记录时恢复 Streams 异常处理程序抛出 #4611
  • setTopicPartitions 和 setDefaultReplyTimeout 中的断言消息命名了错误的属性 #4609
