LangBot v4.11.5

修订 发布时间2026年11月10日 来源langbot-app/LangBot 英文原文

LangBot v4.11.5

LangBot 是一个开源的 AI 聊天机器人与智能体平台，支持多种即时通讯平台、大语言模型、知识库和插件，帮助您构建、部署和管理 AI 助手。 LangBot 是一个开源 AI 聊天机器人和代理平台，它连接消息传递平台、大型语言模型、知识库和插件，帮助您构建、部署和管理 AI 助手。

LangBot v4.11.5

此补丁版本向插件和代理开放了工作区和执行 API，添加了语音模型和跨平台交互卡，重新设计了跑步者接收媒体的方式，并修复了一系列平台和运行时问题。

亮点

  • Workspace API / 工作区 API：插件与 Agent 可通过统一 API 调用工作区与执行能力，包括市场搜索与安装、读取工作区语言。插件和 Agent 可以调用 Workspace 并执行 API，包括 Marketplace 搜索/安装和 Workspace 语言。
  • 语音/语音：新增TTS与STT模型层和模拟阶段，并同步LangBot Space的TTS/ASR模型。添加TTS/STT模型和管道阶段，与Space TTS/ASR模型同步。
  • 互动卡片/交互互动：QQ、企业微信、飞书、钉钉支持跨平台互动卡片。QQ、微信、飞书、钉钉等跨平台互动卡片。
  • Runner media / Runner媒体输入：Runner输入的媒体统一为一个小区列表，附件按ref读取；官方Runner（Dify、Coze、Tbox、ACP等）已装备。Runner输入媒体是一个有序列表，附件通过ref读取；官方跑步者已更新。
  • 监控/监控：记录插件处理的消息、被同步规则刷新的阶段，以及插件在外部发起的LLM调用。监控显示插件处理的消息、丢弃消息的规则阶段以及管道外部的插件LLM调用。
  • 平台与模型/平台与模型：新增原生事件驱动的LINE适配器（旧版标记为遗留）、Slack线程、公众号自动模式主动发送、QQ官方表情解析；新增NVIDIA NIM与MiniMax发现/推理回放。原生基于事件的LINE适配器、Slack线程、公众号主动发送、QQ官方表情； NVIDIA NIM 和 MiniMax 发现/推理重播。
  • 插件/插件：支持批量升级各工作区的市场插件；新增MulticaAgent、HandoffBridge、LeadCapture官方插件。操作员扫一扫即可跨工作区升级市场插件；新的官方 MulticaAgent、HandoffBridge 和 LeadCapture 插件。
  • 修复/修复：不再路由到已删除的模拟与Agent；非流式平台逐条发送Runner消息；HTTP Bot /sync每条回复只返回一次；企业微信跳败自动重连；Box运行时属于跨重启保留；执行插件约随在途任务数伸缩；Windows上由Core启动的/Box运行时改用stdio。停止路由到已删除的Pipelines/Agents，每条消息传递非流平台、来自 HTTP Bot /sync 的单一回复、WeCom 心跳重新连接、持久 Box 运行时所有权、按比例执行租用以及 Windows 上的 stdio 运行时。
  • SDK：langbot-plugin 由 0.7.19 固定到 0.7.23。langbot-plugin 从 0.7.19 固定到 0.7.23。

发布验证

  • 单元测试（Python 3.11/3.12/3.13）、快速集成、PostgreSQL 合约、Box 集成、E2E 启动、核心烟雾、回归工具、编译的 CLI HTTP 合约、官方插件身份合约、Ruff 和前端 lint 在发布提交上传递。
  • langbot-plugin==0.7.23 在 PyPI 上发布，并从注册表固定在 pyproject.toml 和 uv.lock 中，没有 VCS 依赖性。
  • 自上次列表以来，官方插件已从以下来源重新发布到 LangBot Space：LocalAgent 0.2.9、ACPAgentRunner 0.1.21、CozeAgent 0.2.4、DeerFlowAgent 0.2.3、DifyAgent 0.2.7、N8nAgent 0.2.4 和 TboxAgent 0.2.4。
