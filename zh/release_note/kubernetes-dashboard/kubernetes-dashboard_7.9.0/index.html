kubernetes-dashboard 7.9.0

重要

此版本向仪表板 API 添加了缓存功能。一旦缓存被水化，它就会显着提高具有大量资源的集群上仪表板的响应能力和内存使用率。您可以在 设计文档 中找到更多信息，以及添加到 API 模块 中的新缓存相关参数。如果您有任何疑问，请随时通过 SIG-UI Slack 频道或 GitHub 讨论与我们联系。
