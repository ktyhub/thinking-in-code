claude-code v2.1.316

修订 发布时间2026年10月31日 来源anthropics/claude-code 英文原文

claude-code v2.1.316

发生了什么变化

  • 添加了 CLAUDE_CODE_DISABLE_ULTRATHINK，这会关闭 ultrathink 关键字
  • 向克劳德应用程序网关添加了汇总群组预算：群组成员共享的一份每月预算，除了每个成员自己的限额之外，还可以在支出限额管理员 API 上使用 pooled_budget 设置
  • 添加了 CLAUDE_CODE_DISABLE_LOOPED_CROSS_CERT_DROP 以保持系统交叉证书在循环中相互验证，适用于其私有 CA 需要一个的服务器
  • 添加了 CLAUDE_CODE_SUBAGENT_EFFORT 以设置子代理在没有其他名称时运行的工作量级别，而不是继承会话的
  • 将 managed.policy_mode: layered 添加到 Claude 应用程序网关：应用与开发人员匹配的每项策略，每一项都合并到下面列出的策略上，而不仅仅是第一个
  • 在 Claude 应用程序网关 Bedrock 上游添加了 guardrail.input_tagging，它将提示包装在 Amazon Bedrock 护栏提示攻击过滤器所需的输入标签中； all_messages_and_system还标记了系统提示符
  • 自 2026 年 10 月 30 日起，Opus 4.8 已弃用快速模式；将于 2026 年 11 月 30 日删除。删除后，Opus 4.8 上的快速模式请求会返回错误，并且不会回退到标准 Opus 4.8。迁移到 Opus 5.5 以保持加速
  • 修复了当 Claude Code 自行退出时（例如，当凭据被拒绝或云会话被存档时）在 macOS 和 Linux 上继续运行的 shell 命令
  • 修复了值中带有换行符的 bash 别名（Git Bash 中除外）以及名称以破折号开头的函数，在 Bash 工具的 shell 中出现乱码或丢失
  • 修复了导出 SHELLOPTS 时从 Bash 工具启动的 bash 脚本在第一个命令后停止的问题
  • 修复了当命令以类型转换、param、using 或属性开始时 PowerShell 挂钩不会在退出代码 2 上阻塞的问题
  • 修复了压缩响应被切断或损坏时挂起的一些网络请求
  • 修复了 Vertex AI 和 Amazon Bedrock 上的 sonnet、opus 和 haiku 在会话中显示错误的问题，而不是在帐户或区域尚不可用最新模型时切换到旧模型
  • 修复了克劳德应用程序网关不检查请求名称与 availableModels、deniedModels 和 models 的每个模型的问题；命名被阻止模型的请求现在会收到 400 命名字段
  • 修复了 claude auth login 拒绝在托管设置需要 Claude 应用程序网关的情况下运行的问题；现在在终端中显示网关登录
  • 修复了 --restricted 会话在读取允许规则覆盖时从工作目录外部上传文件的问题
  • 修复了包含不可见字符的提示，需要再次按 Enter 才能发送；简单的提示现在在第一次输入时发送清理，并且命令仍然等待审核
  • 修复了当后台作业或消息唤醒子代理时继承父子代理模型并移动到主模型的子代理
  • 修复了托管 autoMode.allow 列表，但没有 "$defaults" 从主机应用程序的 --settings 中获取内置异常，这是在 /permissions 或 /auto-mode-setup 中添加的第一条规则
  • 修复了当自动模式停止转动时云会话和云计划任务不会被标记为失败的问题，因为服务器没有返回安全判决
  • 修复了 claude -p 文本输出有时不会说明为什么自动模式在后台代理仍在运行时停止转弯的问题
  • 修复了 CLAUDE_CODE_AUTO_MODE_SERVER=1 在由代理或 LLM 网关后面的主机应用程序（例如 Claude Desktop）启动的会话中被忽略的问题，并且关闭了实验测试版
  • 修复了当以凭证命名的环境变量设置为开关值（例如 1）时，插件 MCP headersHelper 脚本接收损坏的 CLAUDE_PLUGIN_ROOT 和服务器 URL
  • 修复了 SDK register_repo_root 控制请求未加载工作目录之外目录的 CLAUDE.md（使用 CLAUDE_CODE_ADDITIONAL_DIRECTORIES_CLAUDE_MD=1）
  • 修复了工件工具在 self 级别显示工件数据库访问规则的 ?，并且在拒绝重新发布时不会引用这些规则，从而删除它们
  • 修复了当此版本无法识别模型且自动压缩将采用 200K 上下文窗口时 /model <id> 不会发出警告的问题
  • 修复了“按住空格说话”提示在一次会话中用完其三个显示，并在取消绑定一键通时显示空键的问题
  • 修复了当搜索进程在超时时终止但不退出时，Grep 和 Glob 永远不会返回，这在 Windows 上可见
  • 修复了一种罕见的情况，即当 /clear 或 /resume 已运行而部分对话仍在保存时，恢复对话未恢复其计划
  • 修复了首次运行设置从安全说明和窄终端中的终端设置说明中删除单词的问题
  • 修复了企业调查卡在短暂暂停后输入 1 或 0 的问题；输入的答案现在需要 Enter
  • 自托管运行器：修复了克劳德工作时发送的消息在会话进程被替换后在停止后得到答复的问题
  • 自托管运行器：修复了当会话移动到新计算机时 MCP 服务器的开关有时会丢失的问题
  • Windows：修复了当 rc 文件设置 errexit 和 pipelinefail 并且仅定义 winpty 别名或没有定义别名时，Bash 工具会丢失 Git Bash 中的别名和函数
  • 改进了从 Claude Desktop 或网络上的“代码”选项卡启动的 /code-review：云和 claude remote-control 会话现在显示结果卡，而不是纯文本列表
  • 改进了大型存储库上的 /diff：每次刷新通常会少运行一个完整存储库 git 命令，并且当 git 速度较慢时刷新会间隔开
  • 改进了当 /ultrareview、云会话或云代理找不到 GitHub 远程时显示的消息：他们现在说要在 https://github.com/new, 和 /ultrareview 上创建存储库，不再建议 gh 拒绝的 gh 命令
  • 改进了 SSL 证书错误以列出可能的原因，其中包括遗漏中间证书的服务器，以及每个问题的修复
  • 更改了自动模式，以便没有 "$defaults" 的 autoMode.allow 列表不再删除计划任务提示上的内置规则
  • 更改了团队和企业登录的服务器管理设置：从 Anthropic 的 API 获取的设置现在无需批准提示即可应用，并且拒绝未验证的存储副本
  • [VSCode] 添加了从聊天面板登录 Claude 应用程序网关，无需终端
  • [VSCode] 将 ultrathink 更改为以 xhigh 的速度运行，并在聊天框中显示彩虹，就像在终端中一样
  • [VSCode] 修复了当模型设置具有 [1m] 标签（例如 opus[1m]）时缺少 Effort 滑块、Ultracode 开关和模型名称的问题
  • [VSCode] 修复了在设置文件有错误时过早删除保存的 /btw 问题历史记录的问题
  • [VSCode] 修复了当计划通过“是，并手动批准编辑”获得批准时，重新加载或重新启动后对话会返回自动模式的问题
  • [云会话] 在云会话中添加了表单卡，这样您就可以填写或删除 MCP 服务器要求的表单，而不是在您看不到请求的情况下取消请求
  • [云会话]添加了一条“正在赶上…”行，显示您切换回的云或远程控制会话仍在更新其消息
  • [云会话]更改了网络机密，以便企业成员可以在自己的云环境中添加和删除它们，而不仅仅是查看它们
  • [云会话] 改进了云会话的“更改”窗格：有关列表遗漏内容的注释现在是分支名称旁边的徽章，而不是差异上方的行
  • [云会话] 修复了克劳德更改目录后云会话的“文件”窗格中的文件搜索将文件夹显示为 ../.. 路径；结果现在显示了从项目根开始的路径
  • [Claude Tag] 修复了一旦画布也共享到另一个频道或 DM 后，Claude 拒绝从该频道编辑或附加到其在 Slack 频道中制作的画布的问题
  • [Claude Tag] 修复了当两个组织都安装了 Claude 并且 Slack 将回复传递给另一个组织的应用程序时，Slack Connect 线程中未标记的回复未得到答复的问题
  • [Claude Tag] 修复了 Slack 中云计划任务的实时状态清单未完成的问题；运行现在可以编辑该运行期间发布的顶级消息
  • [Claude Tag] 更改了 Slack 频道的响应，在频道的配置页面和 Claude Tag 管理设置中自动切换为“Claude 如何参与”选项
  • [代码审查] 在代码审查分析页面中添加了按严重性划分的结果卡，显示该期间的总结果、按严重性堆叠的每日图表以及每个严重性的计数
