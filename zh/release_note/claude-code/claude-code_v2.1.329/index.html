claude-code v2.1.329

发生了什么变化

  • 添加了 trust 对话框警告，说明文件夹挂钩的声明位置
  • 当托管设置中的挂钩无法加载时，在 Claude Desktop 和其他非交互式主机的对话中添加了警告
  • 添加了本次会话的计划任务、/loop 唤醒、目标和本次对话的分叉到 /tasks； x 问完后停一
  • 在 /mcp 中的服务器页面添加了“服务器消息”行，显示拒绝连接的远程 HTTP MCP 服务器的 JSON-RPC 错误消息
  • 在 /status 中添加了“市场自动更新”行，其中列出了没有自动更新的托管市场及其原因
  • 添加了在启用 OpenTelemetry 事件和指标时打开代码模式的支持；代码进行的每个工具调用都会发送其事件；追踪仍然让它关闭
  • 修复了当网络停顿或文件锁定导致 ~/.claude.json 在保存期间无法读取和清除时，~/.claude.json 有时会重置为默认值的问题
  • 修复了当 Claude Code 可以读取钥匙串但无法保存到其中时，在 macOS 上重复注销的问题。该会话现在在到期时停止并说明原因，而其他会话保持登录状态
  • 修复了 /terminal-setup 损坏块注释周围的 VS Code 设置或键绑定文件，并在丢失 Shift+Enter 绑定（其中键绑定具有未闭合字符串）的情况下报告成功的问题。
  • 修复了通过 IDE diff 接受的文件在保存时没有最后一个换行符的情况下，以及在通过在 VS Code 中保存 diff 接受编辑时丢失其字节顺序标记 (BOM)
  • 修复了在 /teleport 中选择云会话替换您的开放对话的问题：选择现在会启动一个新会话，就像 /clear 所做的那样，而 /resume 将旧会话带回来
  • 修复了 /usage-credits 要求 Pro 和 Max 用户在打开浏览器后再次登录的问题，如果浏览器未打开且任务停止获取使用积分，则链接会在 8 秒后消失
  • 修复了 /usage 表示使用积分在用完或达到每月限制时关闭，并且 /model 不告诉 Pro 和 Max 用户该限制何时阻止使用使用积分运行的模型
  • 修复了支出限制菜单，将您的支出显示为每月限额，并将其行包裹在狭窄窗口中的指针下方
  • 修复了一个状态行脚本，该脚本会在不结束冻结提示的情况下打印并使用千兆字节的内存
  • 修复了在批准托管设置后，当 —resume 选择器、trust 对话框或其他设置屏幕正在等待时出现空的、冻结的屏幕
  • 修复了当“默认”行已显示您保存的模型时，在 /model 中选择“默认”将您保存的模型替换为组织的默认模型的问题
  • 修复了在运行令牌刷新时清除其身份验证后再次登录 MCP 服务器的问题
  • 修复了重新连接缓慢后停滞的后台 MCP 任务：当使用较旧的协议版本时，Claude Code 现在会自行重新连接大多数 HTTP MCP 服务器
  • 修复了 MCP 服务器或网站以 application/octet-stream 发送的 PDF、图像以及 .docx、.xlsx 或 .pptx 文件被另存为 .bin，这导致 Claude 无法读取 PDF 和图像
  • 修复了 /code-review <pr number> 有时会审查签出分支而不是拉取请求而无需说明的问题：它现在使用 gh pr diff 读取拉取请求，或者在无法读取时说
  • 修复了大多数型号上 /code-review 在权限提示处停止以查找不存在的 ~/.claude/CLAUDE.md
  • 自托管运行器：修复了 --push-outcome-on-release 有时会删除 git 主机上会话的分支的问题
  • 修复了代码模式隐藏脚本已完成的编辑和 Esc 后停止的命令，并在退出时丢失它们的问题
  • 修复了代码模式下的失控循环填充机器内存的问题；现在已经停在极限了
  • 修复了后台代理在恢复时停止时运行的问题
  • 修复了后台 shell 命令使用早期对话的内存，直到它们退出
  • 修复了远程控制在 Claude Desktop、IDE 或 SDK 运行的会话中压缩或 /clear 后使用内存进行早期对话的问题
  • 修复了在等待挂起的 AWS credential_process 或登录调用时停止在 Bedrock 上的 Claude Desktop 会话中未结束请求的问题
  • 修正了 Claude 有时在第一次尝试 Opus 4.8 和 Opus 5 时无法向您发送文件的问题
  • 修正了克劳德在工具搜索会话中没有被告知无法加载连接的 MCP 服务器的工具，并将其视为没有工具的服务器的问题
  • 修复了 claude mcp login 和 /mcp 表示当服务的 client 注册已停用（HTTP 410 消失）时服务不接受来自 Claude Code 的登录的问题
  • 修复了 claude.ai 同步插件挂钩在会话仍在 macOS 上运行时失败并显示“插件目录不存在”的另一种情况
