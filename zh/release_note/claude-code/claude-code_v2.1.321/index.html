修订 发布时间2026年11月9日 来源anthropics/claude-code 英文原文

claude-code v2.1.321

发生了什么变化

  • 添加了 Claude Fable 5.2 (claude-fable-5-2)，现在是默认的 Fable 模型 — 1M 上下文，每个 Mtok 8 美元/40 美元，带有 $0.20/Mtok 缓存读取
  • 将 --settings <file> 添加到 claude remote-control，它将设置文件应用于它启动的每个会话；如果文件更改，则在重新启动 claude remote-control 之前不会启动新会话
  • 修复了当服务器重定向 MCP OAuth 请求时将刷新令牌等机密发送到另一台主机的问题
  • 修复了只读 Bash 命令在沙箱外运行而没有权限提示的情况
  • 修复了 Bash 权限检查判断文件写入错误文件夹而没有提示的情况
  • 修复了拒绝规则和受保护文件提示不适用于 cp 或 mv 写入目录的文件
  • 修复了在计划包含《神鬼寓言》的企业席位上切换到《神鬼寓言》后显示的“从使用积分中提取”注释
  • 修复了后备模型有时会在第一个模型在回复之前被阻止时取消请求或提到停止响应
  • 修复了每次再次登录 Claude Code 注册的服务器时 claude mcp login 打印 SEP-2352 发行者警告的问题
  • 修复了在网络路径（UNC 共享、WSL 文件夹、/net 安装）上调用无单元时 NotebookEdit 删除或覆盖笔记本的第一个单元的问题
  • 修复了在网络路径（UNC 共享、WSL 文件夹、/net 安装）上更改多个匹配项中的第一个、替换空 old_string 上的整个文件或将笔记本编辑为文本的问题
  • 修复了当新会话以自动模式启动时，/config 显示手动作为默认权限模式的问题；在“自动（默认）”上按空格键现在可以保存“不要询问”，而不是“计划”
  • Windows：修复了当会话的工作目录具有小写驱动器号时，在第一个 shell 命令之后通过 watchPaths 设置的路径，FileChanged 挂钩会停止
  • 修复了 --plugin-dir . 和 --plugin-dir ./builtin 将 Claude Code 内置插件生成的类型文件写入 builtin 文件夹的问题
  • 修复了当确切的令牌计数不可用时上下文使用估计会过度计算工具定义的问题
  • 修复了 /compact 在网络和移动设备上的远程控制中显示两次的问题
  • 修复了插件自动更新和 /plugin 市场更新，为存储库的每个工作树或文件夹再次下载插件
  • 修正了自动模式丢失后台子代理的报告，该报告在克劳德回答之前压缩对话时已开始轮流
  • 修复了项目技能、命令和代理在文件夹被删除并在会话中返回后仍然丢失的问题，例如 git stash，包括进入工作树后
  • 修复了 claude -p 有时告诉克劳德后台命令在 10 点后停止时会持续 30 分钟的问题
  • 修复了云会话中与会话自己的父进程匹配的 pkill、pgrep 和 pidwait
  • 修复了 Chrome 中的 Claude 和计算机使用的服务器进程在其父进程退出代理后仍保持活动状态的问题，该代理会停止连接
  • 修复了一个大钩子输出，将克劳德指向一个文件，该文件保存来自同一工具调用的另一个钩子的输出

  • 修复了当另一个钩子的 defer 首先完成且无法兑现时 PreToolUse 钩子的 ask 丢失的问题
  • 修复了权限提示和后台任务中罕见的崩溃问题
