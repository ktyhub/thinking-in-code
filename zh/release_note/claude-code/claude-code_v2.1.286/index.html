claude-code v2.1.286

修订 发布时间2026年9月30日 来源anthropics/claude-code 英文原文

claude-code v2.1.286

发生了什么变化

  • 当多个权限请求叠加时，在权限提示中添加了“2 of 5”等计数
  • 在全屏模式下添加了对“N 多”行列表的鼠标支持：click 可以跳转到列表的末尾，具有悬停和按下状态
  • 修复了多个 Claude Code 进程和 IDE 扩展，当 gcpAuthRefresh 或 awsAuthRefresh 凭证过期时，每个进程和 IDE 扩展都会打开登录浏览器
  • 修复了当早期会话崩溃或被终止时，claude --resume 和 --continue 有时在一批并行工具调用后每回合都会丢失的问题
  • 修复了工具或挂钩返回对象、数字或布尔值而不是文本后的 API 400 错误，包括在恢复的会话中
  • 修复了具有非常大的历史记录的云会话永远不会唤醒的问题，因为容器在记录仍在加载时已停止
  • 修复了 Claude 应用程序网关的支出表以更便宜的 5 分钟速率定价 1 小时提示缓存写入，并仅计算运行服务器端工具（例如 Web 搜索）的流式传输上的第一个模型调用的输入令牌
  • 修复了当存在剩余的 ~/.claude/.credentials.json 时，/login 在另一个 Claude 代码窗口中成功后，macOS 会话仍显示“未登录”或“登录已过期”的问题
  • 修复了当 Anthropic API 拒绝您的默认模型或模型别名解析为的每个回合失败的问题：克劳德代码现在在同一层的先前模型上重试一次
  • 修复了在组织的策略关闭远程控制后远程控制会话（包括 claude remote-control）保持连接的问题；他们现在断开连接并发出通知
  • 修复后备模型无法快速运行时拒绝和 --fallback-model 重试失败的问题；它们现在以标准速度运行，并在交互式会话中发出一次性通知
  • 修复了启用 MCP 发现缓存后成功重新验证后无头会话重复“MCP 服务器需要验证”提醒的问题
  • 修复了 claude auth status 将控制台登录存储的 API 密钥报告为 claude.ai 的问题；它现在报告 api_key，VS Code 扩展将该会话视为 API 密钥会话
  • 修复了 /status 在 API 键旁边列出 Anthropic 配置文件，就好像两者都有效一样；该配置文件现已标记为未使用
  • 修复了当通过远程控制发送的消息所附的文件未到达时，克劳德没有被告知，并且文件有时仅在最后一次下载尝试中等待 10 秒的问题
  • 修复了克劳德·代码退出时到达的远程控制消息被标记为已发送但从未应答的问题；它现在保持排队等待会话的下一次运行
  • 修复了当“Bearer”或“Basic”出现在其密钥名称之前时显示凭证值的 MCP 错误消息
  • 修复了错误消息中仅部分掩盖百分比编码的承载令牌的问题
  • 修复了显示密钥名称内部包含不可见字符（例如零宽度空格）的秘密的编辑日志和记录
  • 修复了显示部分 URL 密码的日志和记录，其中包含标点符号，例如 )、引号、]、& 或第二个 @，或者经过 / 到括号内的主机（例如 ssh URL 中的 [::1]）
  • 修复了 /feedback 保存到磁盘的 zip 中的会话记录，其中包含秘密编辑后无效的 JSON 行
  • 修复了 MCP 连接器在服务器丢弃旧的 MCP 握手后一天内没有列出任何工具的问题
  • 修复了克劳德重复的 MCP 登录请求，替换了挂起的登录链接，这可能会阻止该链接工作
  • 修复了 /usage 不将 MCP 服务器仍在连接或刚刚连接（例如重新启动后）时进行的工具调用记入该服务器的情况
  • 修复了在短暂的服务器错误后，claude.ai 上启用的插件偶尔会从会话的 Claude Code 中丢失的问题
  • 修复了输入到正在运行的子代理中的消息在子代理读取后在其记录中显示两次的问题
  • 修复了当子代理没有注册名称时显示原始任务 ID 而不是代理名称的子代理交回消息
  • 修复了前台子代理有时会在启用任务跟踪工具（TaskCreate/Get/Update/List、TodoWrite）的会话中丢失这些工具的问题
  • 修复了工作树隔离生成的子代理加载项目 CLAUDE.md 及其在读取第一个文件时从工作树副本中第二次导入的问题
  • 修复了当连接在响应过程中停滞几分钟时工作流程工具子代理会从原始提示重新启动的问题
  • 修复了在查看后台特工或队友的笔录时键入的 /compact、/clear 和 /rewind 无声地作用于主要对话的问题：现在有一个对话框命名目标并首先询问
  • 修复了后台作业在等待您批准时显示已完成的问题
  • 修复了当模型回退仅持续一回合时在工具输出中重新发送提交归因提醒的问题
  • 修复了折叠行（例如“Thought for 4s”）单词之间空格上的 click，突出显示该行而不在全屏模式下展开它
  • 修复了没有详细信息的行，例如名称很长的操作行，将所有其他行的详细信息推到列表屏幕的右侧
  • 修复了名称很长的文件在附加到云会话时无法到达的问题
  • 修正了市场克劳德代码拒绝加载的插件错误：他们现在说为什么以及如何修复它，而不是“未找到”
  • 修复了 /plugin 的“发现”选项卡，当其行已在引号中显示该名称时，该选项卡在“检查……是否有新插件”行中显示未加引号的市场名称
  • 改进的提交指导：当您的项目或用户技能包括名为 verify 的项目或用户技能时，Claude 现在被告知在提交之前运行它，除了仅文档和仅测试提交之外
  • 改进了子代理视图中的立即发送（ctrl+enter）：它现在将子代理的运行命令移动到后台，以便立即阅读您的消息
  • 改进了后台代理对您的消息的回复，这样它们就不会再打开时单独回顾您所说的内容
  • 改进的 claude.ai 工件链接读取：WebFetch 现在询问与 Artifact 工具读取相同的问题（会话网络访问打开时没有工件提示，关闭时每个工件一个），并且自动模式“是”不再有效，只有您可以回答
  • 改进了获取、技能、文件读取、沙箱网络、Chrome 中的 Claude、工作流程脚本和笔记本编辑权限提示，以匹配文件编辑提示的外观
  • 改进了 Bash、PowerShell 和 Monitor 权限提示，以显示虚线之间的命令，匹配文件编辑提示
  • 改进了全屏模式下的列表滚动条：在大多数列表中，滚动条不再随着“N 更多”行的来来去去而移动，并且现在有 ↑/↓ 箭头，您可以 click 或按住滚动
  • 改进了外部编辑器 (Ctrl+G)：采用行号的编辑器现在在提示中光标所在的行上打开
  • 当安装了许多技能或插件命令时，改进了打字时斜杠命令建议的响应能力；命令描述现在按单词前缀匹配
  • 改进了输出样式选择器：它现在打开您当前的样式而不是默认样式，每个样式的描述位于其名称下方的行上；数字键不再选择样式
  • 改进了 /hooks：钩子详细信息屏幕的结束线现在显示“这个钩子”而不是“它”

  • 当主机为已连接的服务器重新发送 MCP 服务器启用时，改进了 SDK 和 -p 会话的响应能力
  • 改进了 Claude 应用程序网关在 /protocol 提供的协议页面：它现在表示不拒绝未知输入并与 Claude Code 今天发送的内容相匹配
  • 更改了在没有运行或排队时发送的提示，以立即以正常文本颜色而不是灰色显示
  • 更改了失败的 API 请求的重试方式：现在一个限制涵盖整个模型调用，因此使用默认重试设置，失败的调用最多发送 14 个请求
  • 将--bare更改为仅连接命令行上指定的MCP服务器，不向模型发送系统提醒，并且不启动后台任务；在 --bare 下，达到超时的 shell 命令现在会停止，而不是移动到后台
  • 更改了立即发送键（ctrl+enter）以将技能自己的 shell 命令移至后台而不是结束它
