claude-code v2.1.314

发生了什么变化

  • 添加了 permissions.blockWritesOutsideWorkingDirectories：Write、Edit 和 NotebookEdit 在每个权限模式下拒绝工作目录之外的路径
  • 向 Claude 应用程序网关上游添加了可选的 groups 列表：只有列出的 IdP 组中的开发人员才会被发送到该上游，在故障转移时也是如此
  • 将 guardrail_trace 添加到 Claude 应用程序网关 Bedrock 上游，以记录根据请求触发的 Amazon Bedrock 护栏过滤器，无需匹配的文本
  • 向 VS Code 和 Claude Desktop 的“代码”选项卡添加了空闲压缩：对闲置的 200K+ 令牌对话进行总结，如果提示缓存已过期，则该摘要将用于您的下一条消息
  • 修复了当组织的管理员限制模型的工作量时，会话会因“无效的工作量级别”而依次失败的问题：克劳德代码现在会降低工作量，重试，并说明它使用哪个级别
  • 修复了启动失败时 claude -p 以代码 0 退出且无输出的问题；现在打印错误并退出 1
  • 修复了基岩会话中许多图像每回合都会失败以及 /compact 出现“400 输入太长”的问题。而不是删除旧图像并压缩
  • 修复了当资源没有部署默认 Sonnet、Opus 或 Haiku 模型时 Microsoft Foundry 会话失败的问题：Claude Code 现在回退到该系列的旧模型
  • 修复了不接受工具搜索的 tool_reference 块的网关后面重复拒绝的请求：请求在没有工具搜索的情况下再次发送一次，并且会话会记住
  • 修复了当系统证书存储持有与其前身交叉签名的续订根证书时，TLS 连接失败并出现 UNABLE_TO_GET_ISSUER_CERT 的问题
  • 修复了无需登录即可工作的 MCP 服务器在其存储的登录停止工作后显示“需要身份验证”的问题；它们现在用于退出状态
  • 修复了未删除 MCP 登录时 claude mcp logout 报告成功的问题，例如通过 SSH 锁定 macOS 钥匙串时
  • 修复了当多个会话共享 Anthropic 配置文件登录且凭据锁繁忙时额外登录续订的问题
  • 修复了 claude ultrareview 和 claude remote-control 在具有终端的 CI 作业中询问工作区 trust 问题的问题；设置 CI 后，他们现在立即拒绝 untrusted 文件夹
  • 修复了托管设置中管理员的 TLS trust 设置未应用于 Claude Desktop 会话的问题
  • 修复了当您自己的 --plugin-dir 或 --plugin-url 插件之一的清单损坏或无法下载时，在具有托管插件设置的计算机上拒绝模型切换的问题
  • 修复了当托管设置固定模型时基岩和顶点模型升级优惠在每次启动时都会返回
  • 修复了仅在远程管理设置中设置的 forceRemoteSettingsRefresh 在存储的副本过期后不再应用，这使得会话在无法访问服务器时无需策略即可启动

  • 修复了具有非常大输出的 PreCompact 钩子，导致压缩失败或重复；每个钩子的输出现在被削减为 10,000 个字符
