claude-code v2.1.296

修订 发布时间2026年10月9日 来源anthropics/claude-code 英文原文

claude-code v2.1.296

发生了什么变化

  • 在 Claude 应用程序网关的 managed.policies[] 中添加了 code 密钥：与 cli 相同的设置，也应用于 Claude Desktop 的“代码”选项卡；除了desktop之外，它还打开Claude Desktop的网关模式
  • 将 autoCompactWindow 添加到子代理 frontmatter 和 --agents 定义中，因此子代理可以比主对话窗口更早自动压缩
  • 添加了 CLAUDE_CODE_WORKFLOW_SUBAGENT_MODEL 以在一个模型上运行每个工作流代理，而其他子代理则保留其子代理
  • 添加了 CLAUDE_CODE_OVERLOADED_RETRY_MAX_DELAY_MS 环境变量，以便在重试过载 (529) 请求时为退避设置更长的最大延迟
  • 在 /plugin 中添加了关于插件的注释，该插件的钩子由于另一个启用的插件具有相同的名称而被省略
  • 在读取工具中添加了 allow_large 选项，以便克劳德在需要整个文件并且上下文有空间时可以在一次调用中读取超过通常大小限制的文本文件
  • 修复了拒绝使用 "continue": false 进行工具调用的托管设置 PreToolUse 挂钩，以及阻止一个工具调用的托管 prompt 挂钩，拒绝调用但不结束回合
  • 修复了托管设置中的 PostToolUse 挂钩，在某些会话中不应用 updatedMCPToolOutput
  • 修复了在更改目录或重新加载插件后启动文件夹的 .mcp.json 或插件 MCP 服务器的无头会话，该服务器已为该文件夹关闭
  • 修复了为 allowedProviders 提供服务的克劳德应用程序网关，而 "gateway" 锁定了在用户设置中命名该网关的笔记本电脑
  • 修复了在托管设置将 forceLoginMethod 设置为 gateway 而没有 forceLoginGatewayUrl 的计算机上忽略已保存的克劳德应用程序网关登录的问题（2.1.295 中的回归）
  • 修复了当无法读取会话历史记录时 --teleport 打开空对话的问题
  • 修复了 Haiku 5.5 和其他仅采用自适应思维模型的代币计数，这些模型在某些网关后面失败，并在其他地方用预算思维进行计数
  • 修复了恢复的子代理被告知用户拒绝了会话关闭中断的工具调用
  • 修复了钩子输出在包含类似于插件提示标签的文本时被更改的问题
  • 修复了共享记录和调试日志中的秘密编辑丢失了一些跟随无值键的值的问题，包括在 shell 字符串内写入的 JSON 中
  • 修复了在旧版基于 VTE 的终端（例如 MATE 终端）中复制后打印在屏幕上的杂散 52;c;… 转义序列
  • 修复了只要 /diff 面板或对话框打开就等待看不见的 toast 和通知
  • 修复了 UserPromptSubmit 挂钩或 mod 的 prompt.submit 挂钩期间 Esc 或中断结束无头会话、清除键入的提示或让未选中的提示通过的问题
  • 修复了当具有相同名称或其他拼写的不同插件已经运行时，在无头会话开始后加载的插件的 SessionStart 挂钩被跳过
  • 修复了注册被拒绝时 claude self-hosted-runner 打印误导性错误：它现在命名组织管理设置，或者说重新启动的按需运行程序需要新的工作订单
  • 修复了自托管运行程序会话的 git fetch、pull 和 push 失败，而同一存储库的另一个会话在 --capacity 高于 1 的运行程序上启动
  • 修复了工作流程脚本静默截断结果、代理选项和其他嵌套深度超过约 20,000 级的值，以及深度嵌套的结果写入巨大的任务输出文件的问题
  • 修复了插件提供的 $ 方法在主会话的工作目录而不是调用代理的工作目录中运行，并忽略其调用挂钩所持有的轮次
  • 修复了 $.agent.register 从 mod 的钩子中继承的问题，该钩子在重新加载或删除 mod 后仍在运行；呼叫现已被拒绝
  • 修复了当响应声明 Content-Length 超过 4 MiB 正文限制时 mods 中的 $.http.fetch 拒绝 HEAD 请求的问题
  • 修复了 claude plugin marketplace add、marketplace update 和 plugin install 因名为 constructor 的市场出现内部错误而失败的问题； add现在明确拒绝这样的名字
  • 修复了名为 constructor 或 prototype 的插件秘密在下次保存该插件选项时被删除的问题
  • 修复了云会话在 Chrome 操作中跳过自动模式对 Claude 的检查，而保存的权限在其功能标志尚未加载时允许的操作
  • 修复了当 MCP 工具结果结束该回合时 CLAUDE_CODE_RESUME_INTERRUPTED_TURN 在重新启动后重新运行已完成的回合
  • 修复了 Bash 权限检查自动批准一些分配 BASH_ARGV0 shell 变量然后使用它的命令；这些现在提示批准
  • 修复了 Edit 和 NotebookEdit 替换非有效 UTF-8 文件中的每个非 ASCII 字符（Windows-1252、Shift-JIS、GBK）；此类编辑现在被拒绝
  • 修复了 ← 运行两次后发送的提示，一次在前台看不到，当后台服务响应缓慢时
  • 修复了当 ← 将会话移至后台时 SessionStart 挂钩仍在运行时发送的提示消失的问题；它还没有发送，但 ↑ 现在将其带回来
  • 修复了无头会话中 /clear 后延迟加载插件的 SessionStart 挂钩输出到达新对话的问题
  • 修复了 PowerShell 命令看不到挂钩写入 CLAUDE_ENV_FILE 的变量（当文件仅包含普通分配时）
  • 修复了当 MCP 服务器需要身份验证时 Claude 调用非交互式云会话并建议 /mcp 或 claude mcp
  • 修复了云会话、代理 SDK 和 IDE 集成中以原始 JSON 阵列结尾的 /code-review；现在将调查结果打印为编号列表

  • 修复了从 claude.ai 同步的技能从未完成安装，并且当多个会话共享配置目录时每次同步时都会再次下载的问题
  • 修复了当它声明的市场依赖项也从 claude.ai 同步时，从 claude.ai 同步的插件被禁用的问题
  • 修复了从指向 /home 下的 Linux 计算机复制插件路径时 macOS 上启动挂起的问题

  • 修复了当 claude purge 的文本包含 Unicode 行或段落分隔符时在历史文件中留下提示的问题（U+2028、U+2029）
