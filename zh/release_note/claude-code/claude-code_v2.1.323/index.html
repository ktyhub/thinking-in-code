claude-code v2.1.323

发生了什么变化

  • 添加了代码模式，这是一种实验性选择加入，其中克劳德编写 JavaScript 来调用其工具；请参阅 https://code.claude.com/docs/en/code-mode 打开它，或为组织关闭它
  • 添加了 engines["claude-code"] 至 plugin.json：未安装、更新或加载其规定的克劳德代码版本范围之外的插件，安装和更新时选择适合的最新版本
  • 在 claude plugin validate 中添加了插件 TypeScript 挂钩模块的类型检查；每个发现都是一个警告，--strict 失败了
  • 添加到 claude plugin validate 中的 $ 名词，mod 的 engine.create 钩子添加、保留或替换
  • 在第三方提供商的 Claude Desktop 会话的托管设置中添加了对 CLAUDE_CODE_AUTO_MODE_MODEL 的支持（Claude Desktop 包含此版本后生效）
  • 当模型需要关闭或用完的使用积分时添加了选项菜单（停止、切换到使用积分、升级）
  • 当钩子在 claude -p 和 SDK 会话中长时间运行时，每 30 秒添加一次进度心跳，因此像 Claude Desktop 这样的主机不会以挂起的方式结束回合（一旦包含此版本）
  • 添加了对 Artifact 工具资产上传的 .docx 支持
  • 在差异面板中添加了 /diff to close 提示，并将聚焦和关闭面板的按键添加到了 ? 快捷指南中
  • 添加了 Bash 允许规则在变量值中包含 * 的启动警告，例如 Bash(PORT=* npm run dev)
  • 添加了当插件的语言服务器无法启动时的警告、命名服务器以及要检查的内容
  • 添加了一个一次性启动通知，当找到 Perforce 设置且模式关闭时，命名为 CLAUDE_CODE_PERFORCE_MODE
  • 添加了 CLAUDE_CODE_DISABLE_AGENT_PROGRESS_SUMMARIES（自 2.1.318 起可用）：将其设置为 1 以关闭子代理进度摘要以及写入它们的请求 (anthropics/claude-code#86879)
  • 添加了 CLAUDE_CODE_RESUME_HINT_COMMAND，启动 Claude Code 的程序可以将其设置为具有自己的恢复命令的退出提示名称
  • 在 claude plugin install --json 结果中添加了 unsetOptionCount：尚未设置多少个 userConfig 选项
  • 将 isPromptCovered 添加到绘制 mod 窗格的道具中，当提示上方的对话框或字段覆盖提示时告诉它
  • 修复了再次运行 /compact 或在执行 /context 等命令后，总结克劳德尚未回复的消息的问题
  • 修复了已恢复的会话将您的下一条消息连接到未恢复的旧中断消息的问题
  • 修正了克劳德更改一个非常大的文件后下一个提示时的内存峰值
  • 修复了在运行会话中保存的设置，撤消之前对 settings.json 进行的手动编辑；您在会话期间删除的设置文件现在仍保持删除状态
  • 修复了 claude plugin 命令和 claude mcp list 在更新令牌时结束时将您从控制台配置文件中注销的问题

  • 修复了重音符号和其他组合标记有时会落在文本左侧，在屏幕上留下过时的副本，或者在文本换行时悄然消失的问题
