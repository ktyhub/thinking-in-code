spring-cloud-gateway v5.1.0-RC2

小版本 发布时间2026年11月5日 来源spring-cloud/spring-cloud-gateway 英文原文

spring-cloud-gateway v5.1.0-RC2

发生了什么变化

  • 通过 https://github.com/spring-cloud/spring-cloud-gateway/pull/4295 中的 @spring-builds 将 Antora UI 包更新为 v0.4.26
  • 通过 https://github.com/spring-cloud/spring-cloud-gateway/pull/4304 中的 @spring-builds 将 Maven 包装器更新为 3.10.0
  • 由 @dependabot[bot] 在 https://github.com/spring-cloud/spring-cloud-gateway/pull/4312 中将 /docs 中的 antora 从 3.2.0 提升到 3.2.1
  • 将 @antora/atlas-extension 从 1.0.0-alpha.5 中的 1.0.0-alpha.5 更改为 https://github.com/spring-cloud/spring-cloud-gateway/pull/4311 中的 @dependabot[bot] 在 /docs 中的 1.0.0-alpha.6
  • 由 @dependabot[bot] 在 https://github.com/spring-cloud/spring-cloud-gateway/pull/4334 中将 grpc.version 从 1.84.3 升级到 1.85.0
  • 由 @dependabot[bot] 在 https://github.com/spring-cloud/spring-cloud-gateway/pull/4339 中将 grpc.version 从 1.85.0 升级到 1.85.1
  • 修复：在 https://github.com/spring-cloud/spring-cloud-gateway/pull/4333 中通过 @JoeCqupt 进行过滤之前，将逗号分隔的 X-Forwarded-* 值解析为列表
  • 修复：当 @JoeCqupt 在 https://github.com/spring-cloud/spring-cloud-gateway/pull/4328 中提交响应时，跳过响应标头修改
  • 由 @dependabot[bot] 在 https://github.com/spring-cloud/spring-cloud-gateway/pull/4346 中将 blockhound.version 从 1.0.17.RELEASE 升级到 1.0.18.RELEASE
  • 通过 @nikita-kibitkin 在 https://github.com/spring-cloud/spring-cloud-gateway/pull/4249 中将 LocalResponseCache 过滤器添加到 Spring Cloud Gateway Server Web MVC

新贡献者

  • @nikita-kibitkin 在 https://github.com/spring-cloud/spring-cloud-gateway/pull/4249 中做出了第一个贡献

完整 Changelog：https://github.com/spring-cloud/spring-cloud-gateway/compare/v5.1.0-RC1…v5.1.0-RC2
