tesseract 5.5.0

小版本 发布时间2024年11月10日 来源tesseract-ocr/tesseract 英文原文

tesseract 5.5.0

发生了什么变化

  • 修复静态链接的 TARGET_PDB_FILE 错误。通过 @hglee 在 https://github.com/tesseract-ocr/tesseract/pull/4271
  • 通过 @Zopolis4 在 https://github.com/tesseract-ocr/tesseract/pull/4272 中定期使用 CMAKE_INSTALL_LIBDIR 和 GNUInstallDirs
  • 忽略https://github.com/tesseract-ocr/tesseract/pull/4278中@stweil的非法TESSDATA_PREFIX（不存在的文件系统条目，问题#4277）
  • 修复 https://github.com/tesseract-ocr/tesseract/pull/4283 中 @JKamlah 的 PAGE XML 渲染器的置信度输出
  • @stweil 在 https://github.com/tesseract-ocr/tesseract/pull/4301 中无条件设置 hOCR 功能 ocrp_dir 和 ocrp_lang
  • 通过 @heshpdx 在 https://github.com/tesseract-ocr/tesseract/pull/4303 中减少时钟系统调用
  • 根据 https://github.com/tesseract-ocr/tesseract/pull/4305 中@Balearica 的 #4304 以单字模式计算行边界框
  • 将 access/_access 替换为 https://github.com/tesseract-ocr/tesseract/pull/4307 中 @stweil 的 std::filesystem::exists
  • 通过 @stweil 在 https://github.com/tesseract-ocr/tesseract/pull/4308 中对可用模型列表进行现代化代码
  • 修复 @stweil 在 https://github.com/tesseract-ocr/tesseract/pull/4309 中由 Codacy 报告的性能和其他问题
  • 删除 https://github.com/tesseract-ocr/tesseract/pull/4313 中 @stweil 不必要的赋值和断言
  • 由 @stweil 在 https://github.com/tesseract-ocr/tesseract/pull/4306 中更新 tprintf 的代码
  • 为日志消息添加 C++ 流，并在 https://github.com/tesseract-ocr/tesseract/pull/4314 中@stweil 的两个调试消息中使用它
  • cmake：根据 @Conan-Kudo 在 https://github.com/tesseract-ocr/tesseract/pull/4319 中的 SemVer 属性正确设置版本
  • 在GitHub 中将已弃用的运行程序macos-12 替换为macos-latest 在https://github.com/tesseract-ocr/tesseract/pull/4326 中由@stweil 执行的操作
  • 现代化渲染器代码并删除 https://github.com/tesseract-ocr/tesseract/pull/4330 中 @stweil 的 Windows 文件名转换
  • 修复了 @stweil 在 https://github.com/tesseract-ocr/tesseract/pull/4337 中的一些拼写错误和语法问题
  • 在 https://github.com/tesseract-ocr/tesseract/pull/4341 中添加 @stweil 的 Windows 安装程序的 GitHub 操作和 Makefile 目标
  • 支持 @stweil 在 https://github.com/tesseract-ocr/tesseract/pull/4344 中的 —oem 和 —psm 选项的符号值
  • 在 https://github.com/tesseract-ocr/tesseract/pull/4345 中用 tesserr 流替换一些 tprintf（修复 Windows 编译器警告）
  • 添加 RISC-V V 支持#4346
  • 由 @stweil 在 https://github.com/tesseract-ocr/tesseract/pull/4348 中修复和改进 Windows 安装程序
  • 在 https://github.com/tesseract-ocr/tesseract/pull/4350 中删除 @stweil 的 Tensorflow 支持
  • 更新子模块 googletest 以通过 @stweil 在 https://github.com/tesseract-ocr/tesseract/pull/4352 中发布 v1.15.2

新贡献者

  • @hglee 在 https://github.com/tesseract-ocr/tesseract/pull/4271 中做出了第一个贡献
