11/05
2026.10.1 修订

此版本重点改进桌面体验和聊天导航。 Windows 用户现在将拥有改进的捆绑原始权限，并且聊天回复链接将直接在浏览器中打开。它还包括对 2026.10.1 的版本更新。

 10/30
2026.10.0 小版本

此版本重点关注稳定性、安全性和桌面体验。桌面应用程序现在支持系统 trust 存储，因此操作系统（包括公司和自定义 CA）颁发的证书 trust 无需额外配置即可工作。它还包括更新和登录流程的修复。自托管部署附带强化的默认机密，并且整个堆栈的依赖项已针对已知漏洞进行了修补。 Insomnia 的导​​入更具弹性，土耳其语翻译现已完成。

 09/30
2026.9.0 小版本

此版本引入了企业云，这是一个具有身份和访问管理、单点登录、审核日志和专用支持的新层，以及用于企业自托管的人工智能助手，可以编辑和运行请求、管理集合和环境、发布文档和管理模拟服务器，以及人工智能技能和可配置的提供商连接。

 09/23
2026.8.2 修订

此补丁版本与 Hoppscotch Enterprise Edition 同步，其中包括对用户组组件中的分页和搜索的修复。社区版中没有功能变化。

This patch release, exclusive to the Enterprise offering

2026.8.0 小版本

此版本将 REST 和 GraphQL 请求整合到一个工作区中，添加了使用 CSV 或 JSON 数据文件运行的数据驱动收集，并修复了保存时请求文档丢失的问题，以及安全补丁和错误修复。

 07/30
2026.7.0 小版本

此版本解决了个人工作区中的集合数据丢失和导入的大型团队集合中的请求丢失问题，添加了空环境变量初始值的回退和桌面应用程序上的可配置连接超时，以及安全补丁和错误修复。

 07/15
2026.6.1 修订

此补丁版本解决了登录自托管实例时的桌面应用程序登录循环问题，增加了对在任意非 root 用户 ID 下运行容器的支持，并启用代理路由请求的响应 cookie 捕获，以及更轻的 JSON 响应渲染器。

 06/30
2026.6.0 小版本

There's a known issue on the cloud offering where personal-workspace collections may appear missing or become inaccessible, and the cloud web deployment has been rolled back. Self-hosted deployments are not affected.
