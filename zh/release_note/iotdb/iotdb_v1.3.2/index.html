iotdb v1.3.2

功能和改进

  • 存储模块：insertRecords 写入接口的性能改进
  • 查询模块：添加了新的解释分析语句（监控单个SQL执行的每个阶段所花费的时间）
  • 查询模块：添加了新的 UDAF（用户定义聚合函数）框架
  • 查询模块：新增MaxBy/MinBy函数，支持检索最大/最小值以及相应的时间戳
  • 查询模块：值过滤查询的性能改进
  • 数据同步：路径匹配支持路径模式
  • 数据同步：支持元数据同步（包括时间序列及相关属性、权限等）
  • 流处理：新增Alter Pipe语句，支持Pipe任务插件热更新
  • 系统模块：系统数据点计数统计现在包括通过加载 TsFile 导入的数据的统计
  • 脚本和工具：新增本地升级备份工具（通过硬链接备份原始数据）
  • 脚本和工具：新增导出数据/导入数据脚本，支持CSV、TsFile格式或SQL语句的数据导出
  • 脚本和工具：Windows环境现在支持通过窗口名称区分ConfigNode、DataNode和Cli …

错误

  • 优化删除数据库超时导致出现 NullPointerException (NPE) 时的错误消息。
  • 添加notifyLeaderReady、notifyLeaderChanged 和过程worker 的日志。
  • 在文件合并过程中添加对现有错误数据的兼容性处理。
  • 修复查询时刷新空文件导致的死锁问题。
  • 修复 Ratis 在读取、写入和删除操作期间无响应的问题。
  • 修复加载和合并操作中的并发错误。
  • 修复某些场景下系统压缩率在文件中记录为负数的问题。
  • 修复合并任务内存估计期间的 ConcurrentModificationException 问题。
  • 修复并发写入、自动创建和删除数据库时可能发生的潜在死锁。 …
