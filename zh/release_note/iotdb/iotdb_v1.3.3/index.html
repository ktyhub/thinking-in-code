iotdb v1.3.3

修订 发布时间2024年11月20日 来源apache/iotdb 英文原文

iotdb v1.3.3

功能和改进

  • 存储引擎：添加了新的数据类型 String、Blob、Date 和 Timestamp。
  • 存储引擎：多级存储增加了限速机制。
  • 存储引擎：新增合并目标文件分割功能，带有额外的配置文件参数，并改进了合并模块的内存控制性能。
  • 数据查询：过滤性能优化，提升聚合查询和where条件查询的速度。
  • 数据查询：新的client查询请求负载平衡优化。
  • 数据查询：添加了新的活动元数据统计查询。
  • 数据查询：优化查询规划阶段的内存控制策略。
  • 数据同步：发送方支持将文件传输到指定目录，接收方自动加载到IoTDB中。
  • 数据同步：接收方对于数据类型请求有一个新的自动转换机制。
  • 数据同步：增强接收器端的可观测性，支持多个内部接口的操作/延迟统计，合并到单个 pipelineTransfer 显示中。
  • 数据加载：DataNode 主动监听并加载 TsFiles，并提供额外的可观察性指标。
  • 流处理模块：新增数据订阅能力，支持以数据点或tsfile文件的形式订阅数据库数据。
  • 流处理模块：Alter Pipe 支持更改源的能力。
  • 系统管理：优化配置文件，将原来的三个配置文件合二为一，降低用户运营成本。
  • 系统管理：优化重启恢复性能，减少启动时间。
  • 系统管理：内部添加设备数量、预计数据同步剩余时间、同步数据大小、同步速度等监控项。
  • 脚本和工具：对 import-tsfile 脚本进行了扩展，以支持在与 IoTDB 服务器不同的服务器上运行该脚本。
  • 脚本和工具：添加了新的元数据导入和导出脚本。
  • 脚本和工具：添加了对 Kubernetes Helm 的新支持。
  • AINode：添加AINode模块。 …

错误

  • 修复了在顺序空间中合并有修改的块和空页时出现 NullPointerException (NPE) 的问题。
  • 修复了合并过程中为跳过的文件重新分配文件位置时使用了错误的父文件，导致创建硬链接失败的问题。
  • 修复了新增四种数据类型写入空值，TsFile 对 STRING 类型处理错误，导致 BufferUnderflowException: null 的问题。
  • 修复了高可用场景下停止DataNode导致PipeException：无法启动共识管道的问题。
  • 修复了流模式下第一批写入数据点可能需要刷新才能同步的问题。
  • 修复了管道插件升级的兼容性问题。
  • 修复了最后一个查询中 ORDER BY 子句与 LIMIT 组合使用时无效的问题。 …
