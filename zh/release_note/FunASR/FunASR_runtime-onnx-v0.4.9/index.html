FunASR runtime-onnx-v0.4.9

独立式 funasr-onnx 0.4.9。这不是新的根 funasr 版本。

此版本包含已接受的脱机 VAD 修复（#3846）：空或 子帧输入为每个输入保留一个结果，而无需调用 ONNX 运行时 零帧特征。它还包括#3847：空标点符号块返回 无需标记化或推理，同时保留流缓存状态。

托管的独立包工作流程现在在 Python 上运行 #3847 回归 3.11 和 3.12。 Exact-head 和 merged-main CI 各通过了 9 个发布合约， 6个离线VAD案例，5个空标点案例，现有安装/运行时 回归、产品站点、浏览器、文档、构建、Twine 和清理 包裹检查。本地故障关闭专用网络验证也通过了 45 源/合同测试、38 个安装车轮测试和安装 sdist 来源 验证。

这些是 CPU 运行时包装修复程序。模型权重没有改变，模型没有变化 为此版本下载或加载，并且不做出 ASR 质量声明。

安装：pip install -U funasr-onnx==0.4.9。

资产：wheel、sdist 和覆盖这两个有效负载的 SHA256SUMS。 PyPI 是 最后的上传步骤，仅在下载官方字节后才被接受。
