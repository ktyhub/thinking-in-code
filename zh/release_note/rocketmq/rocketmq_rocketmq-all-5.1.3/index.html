  • [ISSUE #6929] 暂时忽略 @RongtongJin 在 https://github.com/apache/rocketmq/pull/6930 中在 Linux 平台上进行的 testQueryMessageAsync 测试
  • [问题 #6904] 修复 @yuz10 在 https://github.com/apache/rocketmq/pull/6903 中映射文件大小为 0 时启动代理失败的问题
  • [ISSUE #6926] 修复replicasManager初始化顺序错误导致控制器模式无法启动的问题。作者：https://github.com/apache/rocketmq/pull/6927 @RongtongJin
  • [ISSUE #6931] 在https://github.com/apache/rocketmq/pull/6932中通过@RongtongJin为setSubscriptionGroupTable方法设置表引用相同的对象
  • [ISSUE #6917] 修复无法通过 @yuz10 在 https://github.com/apache/rocketmq/pull/6918 中查询相同 msgId 的所有消息
  • [ISSUE #6910] 通过 @totalo 在 https://github.com/apache/rocketmq/pull/6912 中提取 fetchNameServerAddr 的间隔
  • [ISSUE #6933] 如果 https://github.com/apache/rocketmq/pull/6934 中的 @lizhimins 本地 cq 和分层存储偏移量不匹配，则支持重新创建文件
  • [问题#6916] 在 sql 过滤器中支持startsWith 和endsWith。通过 @yuz10 在 https://github.com/apache/rocketmq/pull/6915
  • [ISSUE #6935] 准备在 https://github.com/apache/rocketmq/pull/6936 中由 @RongtongJin 发布 Apache RocketMQ 5.1.3
