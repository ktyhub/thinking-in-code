rocketmq rocketmq-all-5.5.1

发布 发布时间2026年8月20日 来源apache/rocketmq 英文原文

rocketmq rocketmq-all-5.5.1

此维护版本从发行版中删除了 fastjson 1.x（fastjson2 升级到 2.0.63，DLedger 升级到 0.3.3.4），引入了带有跨平台 JNI 填充程序的本机 RocksDB CqCompactionFilter，弃用了旧版 Broker DLedger 模式，并在分层存储、Lite 模式、代理和存储层提供了广泛的稳定性和性能修复。

安全性和依赖关系

  • [问题 #7703] 将 fastjson2 升级到 2.0.63，以通过 @lizhimins 在 https://github.com/apache/rocketmq/pull/10715 中进行安全修复
  • [ISSUE #10651] 将 DLedger 升级到 0.3.3.4（维护线），作者为 https://github.com/apache/rocketmq/pull/10958 中的 @RongtongJin
  • [问题 #10641] 在 https://github.com/apache/rocketmq/pull/10642 中弃用旧版 Broker DLedger 模式 @RongtongJin

新功能（原生 RocksDB 压缩过滤器）

引入了由跨平台 JNI shim 支持的本机 ConsumeQueue 压缩过滤器，用官方的rocksdbjni 工件替换了以前的纯 Java 过滤器和着色的 Rocketmq-rocksdb 依赖项。

  • [ISSUE #10334] 支持本机 CqCompactionFilter 和 https://github.com/apache/rocketmq/pull/10335 中的 @lizhimins 的跨平台 JNI shim
  • [ISSUE #10334] 通过 @lizhimins 在 https://github.com/apache/rocketmq/pull/10371 中使本机 CqCompactionFilter shim 自包含，无需rocksdbjni 依赖
