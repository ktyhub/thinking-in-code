dubbo-go v3.3.1

修订 发布时间2025年12月27日 来源apache/dubbo-go 英文原文

dubbo-go v3.3.1

3.3.1

总结

此版本引入了 Triple 协议的重大增强、对配置和注册中心（Nacos、Apollo、Zookeeper）的改进以及对核心模块的广泛重构以提高稳定性和性能。此版本还更新了对 Go 1.24 的兼容性。

新功能

  • 支持组和版本通配符以实现精确的接口匹配。 #3080
  • 支持将 dubbo.tag 注入服务元数据。 #3069
  • 暴露与路由器相关的 API。 #3066
  • 更新 Go 版本支持 Go 1.24 并删除已弃用的 rand.seed 用法。 #3046
  • 引入导入格式化工具并将其集成到 CI 检查中。 #3019
  • 添加配置热重载功能。 #2992
  • 支持同时运行 HTTP/2 和 HTTP/3 服务器。 #2972
  • 添加 WithInterface 选项用于 client 初始化。 #2946
  • 添加工具支持来生成 Triple 服务的 OpenAPI 文档。 #2951
  • 添加对 Triple 协议的实验性 HTTP/3 支持。 #2916
  • 重新设计 TLS API 并为三重协议添加新的 TLS 配置。 #2852 #2891
  • 支持新 Triple 实现中的非 IDL 模式。 #2858
  • 添加对 Apollo 作为配置中心的支持。 #2857
  • 支持从流中解码 Hessian 以提高大数据包传输的性能。 #2841
  • 添加对新 Triple 协议的通用呼叫支持。 #2818

错误修复

  • 修复 Nacos 关机时注销失败的问题。 #3108
  • 防止从 Java 提供者检索元数据时发生恐慌。 #3092
  • 当标签路由器中的应用程序参数为空时，将日志级别从错误调整为警告。 #3035
  • 修复多个模块中的零指针取消引用。 #3071
  • 解决SetParams方法中URL参数丢失的问题。 #3022
  • 处理集群扩展创建失败而不是恐慌。 #3021 #3064
  • 修复不正确的日志循环路径以防止文件丢失。 #3014
  • 正确计数器递减逻辑出错。 #3013
  • 修复因 meta-v 错误和空远程存储参数导致的元数据检索失败。 #2952 #2953
  • 修复 dubbo.Load() 中的提供程序配置加载。 #2941
  • 修复附件在三重协议中从服务器到 client 的传递问题。 #2928 #2854
  • 修复 Nacos权重配置不生效的问题。 #2937
  • 减少 Zookeeper client 节点感知的延迟。 #2930
  • 修复通信层中读取前缀 EOF 错误。 #2912
  • 修复 Nacos 实例覆盖问题。 #2882
  • 解决逻辑无限循环问题。 #2879
  • 修复 Nacos订阅问题，未检测到新注册的服务。 #2859
  • 修复 Nacos 权重选项配置逻辑。 #2843
  • 修复 marshalRequest 中的错误传播。 #2817
  • 修复三重流调用中的上下文附件错误处理。 #2810

代码增强

  • **重构：配置解耦。**从 config 包解耦依赖关系，以解决注册表、过滤器和 TLS 模块之间的循环依赖关系。
  • 通过预编译正则表达式模式来优化性能。 #3067
  • 通过将 lastUpdate 字段添加到状态存储来改进加权循环。 #3053
  • 修复三重代码生成中的多个包导入。 #3052
  • 解决与 goroutine 管理、文件句柄和扩展缓存相关的内存泄漏。 #3023
  • 重构记录器模块并添加全面的单元测试。 #2838 #2993
  • 重写 Makefile 以提高构建一致性和开发人员体验。 #2975
  • 使用 errgroup 改进正常关闭期间的错误处理。 #2973
  • 用 CompareAndSwap 替换已弃用的 CAS 操作。 [#2962]（https://g
