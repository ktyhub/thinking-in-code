dubbo-go v3.3.2

修订 发布时间2026年8月1日 来源apache/dubbo-go 英文原文

dubbo-go v3.3.2

3.3.2

总结

Apache Dubbo-go 3.3.2 是一个生产就绪版本，专注于 API 整合、三重协议功能、应用程序级元数据、服务治理、并发安全和发布工具。它完成了旧版 config 包的删除，将项目基线移至 Go 1.25，扩展通用调用和面向 HTTP 的 Triple 功能，刷新生成的项目工作流程，并修复多个竞争、陈旧快照问题和资源泄漏。

重大变更和升级说明

  • 现在需要 Go 1.25。 模块和项目工具链已从 Go 1.24 移至 Go 1.25。 #3469
  • 旧版 dubbo.apache.org/dubbo-go/v3/config 软件包已被删除。 直接导入该软件包的应用程序必须迁移到 global 下的实例/选项 API 和配置类型。根兼容性桥也已被删除。 #3372 #3448 #3449
  • 低级别 triple_protocol.Client API 的直接用户必须显式传递 RPC 方法。 较高级别 client.Client 和生成的 client API 保持不变。 #3086
  • Hystrix 过滤器已移至 apache/dubbo-go-extensions。 现有用户应导入扩展实现并继续使用注册的过滤器名称。 #3253
  • 旧版 gRPC 和 Dubbo3 协议实现以及 IDL 模式开关现已弃用，为将来的删除做好准备。 #3469

新功能

  • 扩展泛型调用支持。 三重泛型调用现在可以在不生成存根的情况下与新的 protobuf-json 和 bean 泛化器、类型化调用、类元数据和异常类处理进行互操作。 #3154 #3170 #3171 #3174 #3175 #3183
  • 增强 HTTP 和云原生工作负载的 Triple。 此版本添加了 CORS、REST OpenAPI 支持、带探测和冷却的状态 HTTP/3 协商、在 Triple 侦听器上安装现有 HTTP 处理程序以及通过调用选项捕获一元响应标头/尾部。 #3090 #3280 #3281 #3301 #3443 #3446
  • 添加 Kubernetes 运行状况探测器。 应用程序可以公开活动性、就绪性和启动检查。 #3213
  • 返工正常关闭。 关闭生命周期现在通过统一的实现和可配置的关闭状态来协调消费者、提供者、注册表和确认。 #3235 #3293 #3386 #3388
  • 加强应用程序级元数据。 该版本完成了本地元数据生命周期，使元数据状态并发安全，澄清元数据报告选择，规范化修订，添加更新和垃圾收集，并通过报告到 RPC 回退和冲突感知服务到应用程序映射更新来强化远程加载。 #3357 #3362 #3367 #3369 #3370 #3371 #3373 #3395
  • 改进路由和治理。 现在支持静态路由器配置注入、脚本路由器注册、路由器链快照缓存和其他路由上下文。 #3215 #3224 #3252 #3305
  • 提高可观察性。 上下文感知记录器接口将跟踪字段与 Logrus 和 Zap 集成，记录器初始化现在同步公共 Dubbo-go 外观，并且三重指标区分其他 RPC 失败条件。 #3189 #3195 #3345
  • 为需要检查已解析实例配置的应用程序公开 CustomConfig 和 InstanceOptions 的快照。 #3481

错误修复和可靠性

  • 修复跨 URL 克隆、共享扩展注册表、元数据状态、协议生命周期、Nacos 和目录状态、一致哈希、循环负载平衡、粘性调用程序和服务发现侦听器的竞争。 #3160 #3264 #3265 #3269 #3270 #3271 #3307 #3317 #3367
