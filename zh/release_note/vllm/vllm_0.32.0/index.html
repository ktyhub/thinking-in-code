vllm v0.32.0

vllm v0.32.0

#v0.32.0

亮点

此版本包含来自 363 名贡献者的 814 项提交（121 名新贡献者）！

  • 结构化决策和通用解析器：新的 POST /v1/systemone 端点通过结构化状态回答 choice、noul 和 score 问题 (#59299)，默认提供服务 (#60677、#60696)，并且还可以在 Cloudflare/clef-omni (#61064)、LiquidAI/d1-3B (#60676) 和 DiffusionGemma 上运行（＃60466）。新的 hf 工具和推理解析器（--tool-call-parser hf、--reasoning-parser hf）读取检查点的 response_template，因此在 Python 和 Rust 前端（#59005）中，附带它的模型不需要特定于模型的解析器（#58604、#58602）。
  • 低精度 KV 缓存无处不在：NVFP4 KV 缓存现在运行在 SM8x 和 SM12x (#46963)、SM90 (#60620) 上，并在 SM12x 上运行 XQA 解码 (#60452)，并在 SM100 上的 MiniMax-M3 稀疏注意力上运行 (#59300)； GLM-5.x 默认在 SM100 上使用 FP8 KV 缓存，将每个等级的 KV 内存减半，吞吐量增加 2.3-5.5%，而 PR 基准测试中 TTFT 成本为 7-11%（#60140、#60281）； SM90 上的 fp8_ds_mla 使 GLM-5.3-Flash 的输出吞吐量提高了 31% (#59246)； ROCm 获得 4 位 ultraquant_4bit KV 缓存，密度约为 FP8 的 2 倍 (#57057)。
  • Model Runner V2：具有可变长度草稿的 GPU n-gram 推测器 (#40704)、Elastic EP (#53934)、MLA 模型的预填充上下文并行性的管道并行性 (#59139)、库存 torch.compile 模式 (#59079)，并且 MRV2 现在是 ROCm 上的默认模式，并删除了特定于模型的 MRV1 例外情况 (#56360)。
  • 更快的启动和服务：vllm download-kernels 安装 FlashInfer 的预编译内核 (#58765)； vllm preload --preload-autotune 在重新启动时保持 FlashInfer 自动调整表温暖 (#60085)；共享内存张量竞技场将大型多模态张量广播给具有一份副本的工作人员 (#51207)；分词器和处理器从本地快照加载（#60825）；当 --api-server-count 高于 1 时，每个连接都会转到负载最小的 API 工作线程，在 PR 基准 (#60723) 中，短请求（Qwen3-0.6B，32 个输入/1 个输出令牌）的请求/秒数增加 43-85%。
  • 模型支持：新的 EmbeddingGemma 2 全模态嵌入 (#60254)、MiniCPM-V 4.7 (#58674) 和 Nemotron 3.5 ASR (#59827)； Transformers 建模后端中的视频输入 (#57441)； GLM-5.3 稀疏 MLA 索引转换跨层重用（该内核上的 3.5-3.9x，#59464）和融合多步草案解码（并发 1 时的 13.3%，#57443）； HiSparse 按请求驻留缓存可在 B200 上的 GLM-5.3-NVFP4 上提高高达 58% 的吞吐量，并在高并发下具有长且完全驻留在 GPU 的上下文 (#60083)。
  • 安全：修复 GHSA-4hhp-h66f-j5j7（聊天模板资源耗尽，#50300）、GHSA-q97c-p368-75c4（标记器 max_token_id，#59491）和 GHSA-frvg-qw88-hww9（P2P ZMQ 套接字耗尽，#51504）； CORS 不再默认允许每个源 (#61009)； untrusted 图像仅限于光栅格式 (#60022)；共享内存多模式缓存句柄已签名 (#59357)；嵌套深度超过 64 层的 JSON 模式将被拒绝 (#60036)。
  • 重大更改：Python 3.10 已删除 (#60402)；默认 CORS 来源受到限制 (#61009)； transformers>=5.16.1,<5.20.0 和 tokenizers>=0.23.2（#57387、#59796）； torch.compile 序列并行性和 AsyncTP 通道已删除 (#60517)；级联注意力被移除（#61126）； mamba_cache_mode="all" 已删除（#58997）； max_tokens 不再从上下文窗口保留（#57035）；响应 API 推理流事件已重命名 (#59652)。

模型支持

  • 新模型：EmbeddingGemma 2 (google/embeddinggemma-2)，一种全模态文本/图像/音频/视频嵌入模型，未使用的模态编码器跳过 --limit-mm-per-prompt (#60254、#60289)； MiniCPM-V 4.7 (#58674)； Nemotron 3.5 ASR (nvidia/nemotron-3.5-asr-streaming-0.6b) 完整音频转录；尚不支持本机实时流（#59827）； /v1/systemone 上的 Cloudflare/clef-omni (#61064) 和 LiquidAI/d1-3B (#60676)； PLAMo 3 推理和工具解析器 (#56575)；和 zerrank-2 重新排序评分模板 (#60415)。
  • Transformers 建模后端：视频输入 (#57441) 和 Glm、Arcee、CWM、Mellum (#59679)、GPT-NeoX、Phi、Seed-OSS 和 Jais2 (#59701) 现在通过它提供服务。
  • 新模型功能：LoRA for BERT、RoBERTa 和 XLM-RoBERTa 嵌入模型 (#61033)； Granite 作为 EAGLE3/DFlash 目标 (#60855)； Qwen3-ASR EAGLE3 (#52824)； Sarvam MLA EAGLE3/DSpark 带 PP (#55902)； GLM-5.3-Flash 与 DFlash2 绘图仪 (#56983)；以及 MRV2 上 PP > 1 的 MiniMax-M3 EAGLE3 (#57197)，并在 PP 下共享 MTP 目标嵌入 (#58648)。
  • GLM-5.3 和 GLM-5.3-Flash：稀疏 ML
