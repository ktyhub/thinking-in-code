vllm v0.33.0rc3

vllm v0.33.0rc3

#v0.33.0

亮点

此版本包含 389 名贡献者（122 名新贡献者）的 927 次提交！

  • 新模型：Reflection Beam-1.0（501B MoE，23B 活动）及其 DFlash2 绘图器（#62074）、Yandex AliceAI-Foundation-80B-A3B（#57963）、Recursive Flint（40B MoE、2.5B 活动）（#62938）、Muse Spark Open（#61879）、 Step-5 Preview (#61727、#63147)、NVIDIA Alpamayo 2 Super (#62957)、Nemotron-Labs Dory1.0-4B (#60149)、Nemotron Parse 3.5 (#61651)、MiniCPM-OCR 1.0 (#63095)、Domyn Edge (#62544) 和ColUltraVBERT 视觉文档检索器 (#62237)。
  • PyTorch 2.14：vLLM 升级到 PyTorch 2.14.0，带有 torchvision 0.29.0 和 Triton 3.8.0 (#52183)。
  • CUDA 12.9 已删除：释放轮和图像仅限 CUDA 13.0。 CUDA 12.9 轮子和 -cu129 / -cu129-ubuntu2404 图像不再发布 (#62575)；请改用默认的 CUDA 13.0 工件。
  • libtorch ABI 稳定的 CUDA 轮：CUDA 轮现在与 libtorch 一起实现 ABI 稳定。
  • AWS EFA 映像：新的 vllm/vllm-openai:v0.33.0-efa 映像（x86_64 和 aarch64）捆绑了 AWS EFA 库和 Mooncake 传输引擎的 EFA 版本，用于在支持 EFA 的 EC2 实例上进行 KV 传输和多节点服务 (#58768)。
  • vllm/vllm 图像别名：每个发布图像现在也以较短的 vllm/vllm 名称发布，例如vllm/vllm:v0.33.0、vllm/vllm:v0.33.0-efa 和 vllm/vllm:v0.33.0-rocm。
  • 推测性解码：用于块扩散绘图器（例如 DFlash 和 DSpark）的新 XPress 精炼器（#54448）； FLy，一种在 MI355X 和 B300 上具有 1.04-1.31x 解码吞吐量的选择性有损验证策略 (#53987)； DFlash/DSpark 不再在代币预算中预留草稿位，在 PR 基准中将 GB300 上的 DeepSeek-V4.1-Flash + DSpark 从 1373 输出 tok/s 提高到 3390 tok/s（#59468）；量化草稿 lm_head（draft_lm_head_quantization，并发 1 时解码 +18%）（#59973）；前瞻块哈希，以便 EAGLE/MTP 前缀缓存命中保留其最后一个块，默认情况下处于启用状态 (#61589)；以及 Transformers 建模后端中的 MTP 草案 (#61270)。
  • 在 NVIDIA 上更快的解码：针对 Kimi-K3（TP8/TP16 上的 1.5-2x，#61867）和 DeepSeek-V4.1-Flash 选择 GB300 上的延迟专用解码（第 1 批中的 18.3% 更快的解码步骤，#61868）； DeepSeek-V4/V4.1 MXFP4 专家通过 Hopper 上的 Humming 作为 FP8 块运行（在 4x H200 上解码 +9-21%，#61875）； Blackwell 上的 FA4 稀疏 MLA 解码 (#55866)； trtllm-gen 上的 FlashInfer DCP 预填充在 8xB200 上 100k 输入时平均 TTFT 降低了 39-48% (#62029)；以及 MRV2 预填充上下文并行性下的仅解码完整 CUDA 图（2.6 倍于 eager，#62377）。
  • AMD ROCm：默认 ROCm 图像和轮子移动到 ROCm 10.0，ROCm 7.2 仍发布为 -rocm72 (#58761)； MonoKernel 通过 --monokernel 解码 MI300X/MI325X 上的 DeepSeek-V4.1-Flash（并发 1 时为 2.32x P50 交互性，#60731）和每个 MI355X 层（#61082），以及 MI355X 上的 MiniMax-M3-MXFP4（16.6% 降低 TPOT，#62712， ＃62994）； ROCM_OCTAVE 3-4 位 KV 缓存（RX 7900 XTX 上 fp16 的 KV 令牌的 4.6 倍，#59774）；以及 gfx1250 支持 gpt-oss-120b、DeepSeek-R1、DeepSeek-V4-Flash 和 MiniMax-M3 (#58800)。
  • API 和服务：兼容 OpenAI 的 /v1/decisions 端点，默认情况下针对受支持的生成模型启用（#60465、#61550）； /v1/embeddings 上具有可选后期分块的令牌嵌入（#61772、#63051、#60164）； output_mode="derender" 上的 /inference/v1/generate (#60082)；大型 Rust 前端奇偶校验推送，包括在长对话中不再出现 HTTP 500 (#62374) 以及启动时失败的不受支持的标志 (#62431)； TP > 1 时并发工作线程启动 (#60028)；以及一个从卡住的引擎和工作进程中转储堆栈跟踪的看门狗（#55700）。
  • 重大更改：删除 Medusa 和 MLP 投机者 (#61701)；删除了旧版 Ray 编译图执行器（#61712、#62228）； --mamba-cache-mode 已弃用 (#60043)；生成暂停时发送的请求现在得到 HTTP 503 (#51488)； NIXL 连接器需要 NIXL 1.5 或更新版本 (#61032)； LM Format Enforcer 和 --ir-op-priority 已弃用（#63423、#63371）。
