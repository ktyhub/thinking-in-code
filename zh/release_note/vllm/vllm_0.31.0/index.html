vllm v0.31.0

#v0.31.0

亮点

此版本包含 307 名贡献者（96 名新贡献者）的 717 次提交！

  • DeepSeek-V4.1-Flash 性能：FlashMLA 备受关注，V4.1 NVFP4 压缩 KV 缓存现在是 SM100 默认值 (#56935)；用于索引器的 DeepGEMM 稀疏 MQA logits (#56254) 和将门 GEMM 与专家选择融合的 Mega-Gate (#56266)；解码器边界融合了 TP all-reduce、mHC 输入准备 (#57643) 和 MoE Finalize (#58586)； SM100/SM103 上具有逆 RoPE 和 MXFP8 定量的融合小批量 WO-A (#58634)； MXFP8 wo_b GEMM 与序列并行减少分散融合 (#57428)； Engram wkv 在 TP 等级之间进行分片 (#58678)，默认情况下，Engram 主机表在同地 DP 副本之间共享 (#57651)；视觉塔的编码器 CUDA 图 (#56625)；和 SWA 有界重播，使滑动窗口 KV 不受前缀缓存的影响 (#56227)。
  • 快速重启：新的 vllm preload CLI 启动权重缓存守护进程，在引擎重新启动时将量化后的权重保留在 GPU 内存中 (#56680)，现在具有数据并行性 (#57386)、MTP 草稿模型 (#57312)、/health 端点 (#58552) 和就绪等待 (#58370)。实验性初始化引擎快照 (vllm snapshot create/restore) 使用 CRIU 来恢复完全初始化的 TP1 引擎 (#51360)。
  • Model Runner V2 和推测性解码：Model Runner V2 上的草稿模型推测性解码 (#43091) 和自定义 Logits 处理器 (#56497)；新的 LiLiCorr 起草者 (#57934)； DFlash 的异步调度 (#58065)，并在 CUDA 草稿图 (#57632) 中捕获上下文 K/V 预计算； Gemma4 的 DSpark 自适应验证 (#57263) 和 Kimi-K3 的可变长度解码 (#52988)；具有非 DCP DSpark 草案的 DCP 目标 (#56723)；现在，MoE 内存会在 MRV2 分析期间进行计数，从而避免 WideEP 部署上的 OOM（#57270、#58411）。
  • 大规模服务：MoonEP 通过 --all2all-backend moonep 平衡 EP all2all 后端（#52101）、具有数据并行性的预填充上下文并行性（#57075）、SM100/SM103 的低 SM 多内存缩减分散（#55072）、具有序列并行性的 DeepEPv2（#57210）和具有共享专家重叠的 EPLB (#57236)、用于 RL 的分片感知 NCCL M2N 权重转移后端 (#51520) 和 KV 卸载背压检测 (#50045)。
  • 调度控制：--max-num-active-seqs 独立于 max_num_seqs 限制 RUNNING 准入（#56758），--long-prefill-token-threshold 现在适应等待预填充的数量，而不是对单个请求进行分块（#57951，#58459），等待队列被重新设计，因此已经持有 KV 块的请求首先被调度（#58947），并且 KV 连接器 + MTP 死锁KV 压力已修复 (#57104)。
  • HiSparse 强化：使用联合驻留内核解析 MTP 验证行 (#59235)，修复了完整图下的 MTP 接受崩溃 (#59309)，没有主机支持的 GPU 页面 (#59036)，修复了分块预填充抢占活锁 (#59494)，根据 HiSparse 分配的组确定 KV 缓存大小 (#59450)，以及主机前缀发布和 GPU 前缀采用修复（#59007、#59282）。
  • 安全：每个请求 mm_processor_kwargs 和 media_io_kwargs 都会被拒绝，除非设置了 --trust-request-mm-kwargs (#58830)；前缀缓存额外的键由源标记，因此 LoRA 名称和 cache_salt 不再冲突 (#51899)，并且 LoRA 路径是块哈希的一部分 (#59335)；过时的多模式接收器缓存条目无法再替换新的有效负载（#57833）。
  • 重大更改：每个请求的多模式 kwargs 门控 (#58830)； tokenizer_mode="slow" 已删除（#58545）； --enable-mamba-fine-grained-prefix-cache 重命名为 --enable-mamba-shared-prefix-checkpoint (#57382)；通过 quantization="fp8" 进行在线量化，替换为 fp8_per_tensor 简写 (#53585)，并删除 Quark 静默在线量化 (#51800)；删除了 AllSpark INT8 W8A16 后端 (#58001)； --enforce-eager 现在还禁用 JIT 内核预热 (#58197)；默认情况下启用 XPU 图形，并删除 VLLM_XPU_ENABLE_XPU_GRAPH (#51600)。
