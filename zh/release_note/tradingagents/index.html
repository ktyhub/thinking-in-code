202615

10/27
v0.7.1 修订

决策仅在最终收盘时进行评分，并在漫长的市场假期期间结算，模型的未填充日期不再读取运行日期之后提交的文件，并修复了投资组合、价格、SEC 声明、报告、Azure 和 Claude 设置。

 10/16
v0.7.0 小版本

在您的 ChatGPT 计划上运行，回测从每次决定后的第一次关闭开始进行评分，在新版本发布时启动时进行注释，并在每个 GitHub 版本上附加一个轮子。

 10/03
v0.6.0 小版本

HTML 报告，每个模型层都有一个提供程序，在分析师工作时为每个股票做出过去的决策，在雅虎的新闻源关闭时阅读公司新闻。

 09/29
v0.5.2 修订

并行分析，无人值守的 CLI 运行，记录产生它们的报告， 过去的运行仅提供了当日已知的信息。

 09/24
v0.5.1 修订

按每个模块所容纳的内容组织的包布局，按以下方式筛选社交帖子 设置密钥时 TypeSafe 的 Jev，GPT-6 Sol 和 Luna 作为默认模型，以及 修复了运行隔离、SEC EDGAR 语句和历史运行。

 09/18
v0.5.0 小版本

每条日期路径上的时间点完整性、做出决策时记录的、对股票和日期网格的回溯测试、调用者的投资组合作为运行输入以及归档的 SEC EDGAR 基本面。

 08/31
v0.4.0 小版本

跨数据和内存层的前瞻和时间点修复、更清晰的决策信号、工作 CLI 检查点恢复以及 GPT-5.6 / GLM-5.3 模型。

 07/05
v0.3.1 修订

TradingAgents v0.3.1 是 v0.3.0 之上的正确性和稳定性补丁。

 06/22
v0.3.0 小版本

TradingAgents v0.3.0 是一个稳定性和可扩展性版本：经过验证的数据访问合约、扩展的提供商和数据供应商注册表、当前一代模型目录和 CI 门。

 05/11
v0.2.5 修订

TradingAgents v0.2.5 提供接地情绪分析、Qwen/GLM/MiniMax 双区域支持、\TRADINGAGENTS_*\ env-var 可配置性（带 API 键自动检测）、远程 Ollama 支持、非美国股票代码的可配置 alpha 基准以及股票路径遍历修复。

 04/25
v0.2.4 修订

TradingAgents v0.2.4 提供结构化输出决策代理、选择加入检查点简历、带有基于结果的反射的持久决策日志、四个新的 LLM 提供商和一个 Docker 图像。

 03/29
v0.2.3 修订

TradingAgents v0.2.3 增加了多语言输出、GPT-5.4 系列模型，并提高了回测保真度。

 03/22
v0.2.2 修订

 03/15
