29.9.1

有关此版本中拉取请求和更改的完整列表，请参阅相关的 GitHub 里程碑：

  • docker/cli、29.9.1里程碑
  • 莫比/莫比，29.9.1里程碑

安全

v2.4.2 的 containerd 更新包括对以下安全漏洞的修复：

  • CVE-2026-95839：如果子描述符包含 io.containerd.manifest.subject 注释和格式错误的摘要，则通过 Containerd 的传输服务拉取或导入映像可能会导致 Containerd 崩溃。
  • GHSA-8647-2jxj-p2rc：当使用 concurrent_layer_fetch_buffer 启用并行层提取时，返回精心设计的 Content-Length 标头的 untrusted 注册表可能会使容器崩溃。
  • GHSA-hc94-p972-ch66：提取精心制作的映像或从恶意注册表中提取可能会耗尽主机磁盘空间，因为 Containerd 在验证之前不会将传入层数据限制为声明的大小。

错误修复和增强

  • 修复了 --link-local-ip 在创建容器或将其连接到网络时接受非链接本地地址（169.254.0.0/16 或 fe80::/10），从而导致容器无法启动的问题。 莫比/莫比#53923
  • 修复了启用 userns-remap 时经典构建器中的 COPY --from 对于不属于 root 的文件失败的问题。 莫比/莫比#53859
  • 修复了当无法计算一个容器的大小时，docker ps -s 和容器列表的大小完全失败的问题。 莫比/莫比#53921
  • 修复当图像多次包含同一层（图形驱动程序图像存储）时，docker save 在删除图像后将图像层保留在磁盘上的问题。 莫比/莫比#53927
  • 修复了使用 fluentd 日志驱动程序且 TLS 地址无法连接且启用了 fluentd-async 时出现的守护程序崩溃问题。 莫比/莫比#53922
  • 修复当注册表镜像成功但后续注册表查找失败时图像摘要解析失败的问题。 莫比/莫比#53933
  • 修复获取插件失败时插件权限查找报告成功的问题。 莫比/莫比#53934

包装更新

  • 将containerd（静态二进制文件）更新为v2.4.2。 莫比/莫比#53936

网络

  • 当 iptables 和 ip6tables 都被禁用时，不要将桥接网络接口添加到防火墙的 docker 区域。 莫比/莫比#53907
  • 修复了当桥接器绑定到 docker 以外的防火墙区域时，桥接器网络在守护程序启动时无法恢复的问题。 莫比/莫比#53907

无根

  • 使用用户命名空间和无根模式修复 --domainname；这需要 OCI 运行时支持 domainname 字段（例如 runc >= v1.2.0）。 莫比/莫比#53899
  • 将 RootlessKit 更新为 v3.3.0。 莫比/莫比#53942
