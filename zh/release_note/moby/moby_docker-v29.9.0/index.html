moby docker-v29.9.0

moby docker-v29.9.0

29.9.0

有关此版本中拉取请求和更改的完整列表，请参阅相关的 GitHub 里程碑：

  • docker/cli、29.9.0里程碑
  • 莫比/莫比，29.9.0里程碑

安全

Go运行时更新修复了Docker引擎中的以下安全漏洞：

  • CVE-2026-97032：HTTP/2 client 可能会通过在发送请求时更改 HPACK 标头表大小来使守护进程崩溃。 golang/go#81867
  • CVE-2026-78659：HTTP/2 client 可能会通过在 Trailer 标头中声明大量字段来耗尽守护程序内存，从而绕过标头大小限制。 golang/go#81857
  • CVE-2026-78663：HTTP/2 client 可以通过重置流来绕过连接级流量控制限制，使守护程序缓冲的请求数据多于限制允许的数据。 golang/go#81743
  • CVE-2026-78669：HTTP/2 client 可能会通过打开许多流并重复更改初始窗口大小而导致守护进程 CPU 使用过多。 golang/go#81742
  • CVE-2026-56857：在 Windows 上，如果对数据根具有写访问权限的人已在其中放置了一个结点，则守护进程可以在其数据根之外创建一个目录。 golang/go#81739

golang.org/x/net 对 v0.60.0 的更新将相同的 HTTP/2 修复应用于已弃用的 /grpc 端点以及 BuildKit 为前端容器运行的 gRPC 服务器，例如 # syntax= 指令引用的图像。

错误修复和增强

  • 容器镜像存储：添加 lazy-pull 守护进程功能来控制 docker pull 是否跳过下载快照程序已提供的图层内容。默认情况下，已知远程快照程序（nydus、overlaybd、soci、stargz）会启用延迟拉取。 莫比/莫比#53877 -containerd 图像存储：修复了当解压的层已存在时，拉取跳过所需的层 blob，使图像可运行但导出或推送不完整。 莫比/莫比#53615
  • 修复了 docker container create --name 报告的误导性验证错误，其中提及无效字符而不是无效名称长度。 莫比/莫比#53484
  • 修复了无根模式下每个 GET /version 请求上与 RootlessKit API 套接字的连接泄漏问题。 莫比/莫比#53836
  • 改进 Windows 服务注册和取消注册清理，包括使服务取消注册 (--unregister-service) 幂等。 莫比/莫比#53845

包装更新

  • 将 BuildKit 更新为 v0.34.0。 莫比/莫比#53882
  • 将 Go 运行时更新为 1.26.9。 docker/cli#7363
  • 将containerd（静态二进制文件）更新为v2.4.1。 莫比/莫比#53773

网络

  • 允许在桥接网络上的容器之间进行 IPv6 邻居发现，并禁用容器间通信，与现有的 IPv4 行为相匹配。 莫比/莫比#53723
  • 修复了 docker ps 和 GET /containers/json 忽略使用路由网关模式的网络的已发布端口。 莫比/莫比#53693
  • 修复了一个错误，即重新启动的守护进程可能会从对等方的服务发现和负载平衡中删除，直到它重新加入八卦集群。 莫比/莫比#53688
  • 修复了当容器间通信被禁用时，同一网络上的另一个容器无法访问已发布的端口，包括通过路由网格发布的 Swarm 服务。 莫比/莫比#53723
  • 修复了以下问题：对内核进行编程以加密覆盖网络数据平面时出现的错误在某些情况下可能会导致某些节点的加密覆盖网络流量以明文形式传输。由于接收方会丢弃欺骗性的加密覆盖网络的明文数据包，因此机密性的损失仅限于单向流（例如 UDP DNS 查询）和永远不会进行的握手尝试（例如 TCP SYN）。 莫比/莫比#53420
  • 修复使用隐式 host-gateway 映射将实时恢复的容器连接到其他网络的问题。 莫比/莫比#53093
  • 修复了当 VXLAN 设备已了解对等点的动态 FDB 条目时，节点重新加入集群或重新部署服务后覆盖对等点变得无法访问的问题。 莫比/莫比#53663
  • 修复了当守护进程无法写入 /var/lib/docker 时覆盖网络上的 Swarm 任务被拒绝的问题。 莫比/莫比#53848
  • 当启用用户层代理时，可以通过主机的 IPv6 地址访问已发布的 Swarm 服务端口。 v29.8.0 中引入的更改偶然启用了此功能；自 v29.9.0 起，该功能已经过测试并受支持。 莫比/莫比#53727
  • 当最后一个容器离开加密的覆盖网络时，释放节点的 IPsec 安全关联和策略，而不是在守护程序重新启动之前泄露它们。 莫比/莫比#53420
  • 恢复逻辑以删除空的 DOCKER-INGRESS iptables 链以及跳转到它的 FORWARD 规则，这是 Docker 引擎 28.0.0 及更早版本留下的。 莫比/莫比#53825

无根

  • 更新 RootlessKit (3.2.0)。 莫比/莫比#53607
