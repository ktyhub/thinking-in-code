⚠️ 潜在的重大更改：本地注册表连接

如果您在 daemon.json 中显式配置 insecure-registries 或使用 --insecure-registry，则 Docker 引擎不再自动将环回地址（127.0.0.0/8 和 ::1/128）视为不安全注册表。

[!警告] 升级后，拉取和推送到使用 HTTP 或 untrusted TLS 证书的本地注册表可能会失败，除非这些注册表明确包含在不安全的注册表配置中。 使用 trusted 证书配置 TLS，或仅将所需的本地注册表地址（例如 localhost:5000）添加到现有的不安全注册表配置中。

当省略 insecure-registries 时，环回注册表默认情况下仍然不安全。 在 daemon.json 中设置 "insecure-registries": [] 将禁用所有默认的不安全注册表。 莫比/莫比#53868

🧻 引擎 API 规格移至 OpenAPI 3.2

Engine API 规范现在使用 OpenAPI 3.2 作为其源格式，格式为 api/openapi.yaml。 从它生成的 Swagger 2.0 规范仍然在 api/swagger.yaml 中针对现有工具发布。 对于过渡，此版本还包括固定到 api/docs/v1.57-swagger.yaml 中的 API v1.57 的 Swagger 2.0 副本。 未来的 API 版本将不会获得每个版本的 Swagger 2.0 副本，因此请更新依赖于这些文件的工具以使用 OpenAPI 3.2 规范。 莫比/莫比#53630

📦 适用于 AlmaLinux、Oracle Linux 和 Rocky Linux 的软件包

Docker 引擎包适用于 AlmaLinux、Oracle Linux 和 Rocky Linux。 有关安装说明，请参阅AlmaLinux、Oracle Linux和Rocky Linux。
