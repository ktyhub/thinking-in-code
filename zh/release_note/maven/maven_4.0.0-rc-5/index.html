maven 4.0.0-rc-5

预发布 发布时间2025年11月13日 来源apache/maven 英文原文

maven 4.0.0-rc-5

注释

Maven 4 的这个新候选版本发布是为了收集用户的反馈。 与 Maven 3 相比，Maven 4 有一些限制，因此请确保在尝试使用 Maven 4 进行项目之前运行 mvnup 工具。

Bean 配置错误

在 Bean 配置系统中发现了一个错误，其中字段可访问性状态被全局缓存。当多次访问同一配置字段或在构建期间在不同上下文中访问同一配置字段时，这可能会导致插件配置注入失败。这尤其影响插件单元测试。

该问题将在下一版本中通过 #11433 修复。

v4 API 中的并发问题

在 Maven 4 API（仍处于预览模式）中发现了并发问题，并将在下一版本中通过 #11428 修复。

BOM 包装

在 BOM 项目的处理方式中还发现了另一个错误。当项目使用 BOM 打包时，消费者 POM 未正确转换为标准 POM 打包，并且在某些情况下依赖项版本可能会丢失。

该问题将在下一版本中通过 #11427 修复。

macOS：JLine 本机库在首次使用时可能会被 Gatekeeper 阻止

在 macOS（尤其是 Apple Silicon）上，第一次调用 mvn 可能无法加载 JLine 本机终端库，并出现如下错误：

java.lang.UnsatisfiedLinkError: .../libjline-native/Mac/arm64/libjlinenative.jnilib: dlopen(...): code signature ... not valid for use in process: library load disallowed by system policy

当通过 Web 浏览器下载二进制发行版时会发生这种情况，该浏览器应用 com.apple.quarantine extended 属性。

解决方法（一次性修复）：

xattr -r -d com.apple.quarantine /path/to/apache-maven-4.0.0-rc-5/lib/jline-native

推荐的下载方法（完全避免该问题）：

curl -L -O https://archive.apache.org/dist/maven/maven-4/4.0.0-rc-5/binaries/apache-maven-4.0.0-rc-5-bin.tar.gz
tar -xzf apache-maven-4.0.0-rc-5-bin.tar.gz

这是一个已知问题 #10747，将在未来版本中解决。
