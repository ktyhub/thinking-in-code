maven 4.0.0-rc-4

Maven 4.0.0-rc-4 的目标是成为 Maven 4.0.0 GA 之前的最后一个候选版本。我们将专注于修复正式发布之前提出的关键错误。 值得一提的是新的升级工具，可用于修复 pom.xml 文件并使它们在 Maven 4 中可用。
