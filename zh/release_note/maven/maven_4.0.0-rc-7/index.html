maven 4.0.0-rc-7

预发布 发布时间2026年9月24日 来源apache/maven 英文原文

maven 4.0.0-rc-7

该候选版本预计将是 Maven 4.0.0 GA 版本之前的最后一个版本，我们的目标是在未来几周内发布该版本，等待社区反馈。

🚀 新功能和改进

  • 记录 API 增强功能和 mojo MDC (#12690) @gnodet
  • 优化反应堆排序和相位比较器性能（#12901）@gnodet
  • 添加 AsyncDrainWriter 以消除 PrintWriter 锁争用 (#12892) @gnodet
  • 添加对基于 Plexus 的插件依赖项注入的验证 (#12649) @slawekjaranowski

🔧 维护

  • 将默认生命周期插件版本外部化为 POM 属性 (#13137) @gnodet

🐛 错误修复

  • 改进独立的 ApiRunner 以正确应用设置（#13014）@gnodet

  • 从消费者 POM 中剥离可执行（）条件（[#12960]（https://github.com/apache/maven/pull/12960））@gnodet

  • 运行 JDK 时发出明确的错误，无法编译源代码级别 (#12922) @gnodet

  • 默认启用 PathConflictResolver (#12893) @gnodet

  • [mvnup] 将 maven-war-plugin 和 maven-ear-plugin 添加到插件升级列表 (#12685) @gnodet

  • 修复#13191：将 -Dmaven.maven3Personality 提示添加到错误的父相对路径的 FATAL 消息中 (#13202) @gnodet

  • 修复#13200：从 MavenProject.getArtifacts (#13203) @gnodet 发布完整的集合

  • 修复#13190：使用 BUILD_PROJECT 预构建完整反应器一次，将临时目录放入 PluginUpgradeStrategy (#13197) @gnodet

  • 修复 #13192：在 POM 中定义 CI 友好属性时，PomInlinerTransformer 失败 (#13195) @gnodet

  • 修复 #13189：mvnup 生成无效的 JDK 版本约束 ’(,-1]’ (#13199) @gnodet

  • 修复 mvnup 兼容性：jar-plugin 3.4.2、exec-plugin 子模块覆盖、工具链警告 (#13179) @gnodet

  • 修复#13135，确保反应堆摘要的完成，但特权失败是最后保持人类效率（[#13167]（https://github.com/apache/maven/pull/13167））@gnodet

  • 修复Windows上的exists()/missing()配置文件条件中的glob模式(#13163)@gnodet

  • 修复 #13084：外部模型构建的沙箱配置文件激活上下文 (#13158) @gnodet

  • 修复：通过本地存储库管理器查找实现 Node.getRepository() (#13159) @gnodet

  • 修复#13100：尊重来自合法活动的外部模型配置文件的存储库（[#13155]（https://github.com/apache/maven/pull/13155））@gnodet

  • [MNG-5146] - 修复父相对路径不匹配检查 (#13157) @gnodet

  • 在将操作系统系列与系列名称进行匹配之前将其小写 (#13154) @gnodet

  • 标准化 MavenXpp3Reader 中的惰性 StAX 解析失败 (#13149) @gnodet

  • 延迟评估配置文件激活条件 (#13144) @gnodet

  • [MNG-6979] - 从执行根初始化当前项目 (#13143) @gnodet

  • 修复列表字段中递归属性引用上的 NPE (#13145) @gnodet

  • [MNG-6568] - 修复版本限定符中的比较周期 (#13113) @gnodet

  • 保持从项目本地存储库提供的父级的 basedir 未设置 (#13212) @slachiewicz

  • 修复#13068：使 PluginDependencyResolver 方法默认 (#13069) @ascheman

  • 修复filterByScope以扩展构建排序的生命周期范围（[#13070]（https://github.com/apache/maven/pull/13070））@gnodet

  • [MNG-8174] - 当属性在插件配置中引用自身时修复 NPE (#12935) @elharo

  • 修复#12985：添加 select-jdk-toolchain 执行时升级 toolchains-plugin (#13026) @gnodet
