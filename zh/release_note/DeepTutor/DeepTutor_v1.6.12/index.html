DeepTutor v1.6.12

DeepTutor v1.6.12 Release Notes

发布日期： 2026.09.27 v1.6.12 建立在 v1.6.11 的基础上，让每个工作空间放置和移动其知识库，连接可搜索的 Kiwix 档案，并将源数据转化为有根据的答案。任务板、德语界面和恢复修复使该版本更加完善。现有数据无需迁移； systemd 现在安装在应用程序外部更新。

新消息

知识库跟随工作区

创建知识库时选择存储工作空间。在检查目标拦截器和受影响的分配后，将一个现有基地从其“设置”面板中移出； DeepTutor 在切换引用之前验证复制的数据和索引。保存的知识库 ID 和工作区分配将继续解析。处理时或当共享授权、目标冲突或不受支持的 MarginNote 数据使其不安全时，移动会被阻止。

连接 Kiwix 档案

连接 kiwix-serve 提供的一个可搜索 ZIM 存档作为知识中心或 deeptutor kb connect-kiwix 的知识库。搜索按需读取存档，无需上传副本或为其建立索引。您还可以将文章带入沉浸式阅读。删除连接不会影响存档。

接地答案中的来源数据

LlamaIndex 知识管道可以保留解析器提取的 PDF 和 EPUB 图像及其标题和源位置。当检索找到一个像素时，具有视觉能力的答案模型会看到经过验证的像素；纯文本模型接收具有明确限制的标题和上下文。沉浸式阅读可以按需检查存储的图形。这取决于发出图像并重新索引旧内容的解析器；请参阅升级说明。

任务板和学习控制

工作区本地任务板可跟踪“待办事项”、“进行中”和“已完成”卡，并附有注释、可访问的移动控件和可恢复的存档。引导式学习现在尊重明确的教学优先偏好，并给出本地化的下一步。教师和学生加入接受的非管理员角色值，而无需获得管理员权限。

语言和提供商

德语加入界面语言，马来语成为回复语言选项。 Cheaper Inference 加入 LLM 提供商行列；本地 Lemonade 嵌入无需 API 密钥即可工作。 DashScope 图像、视频和语音请求使用支持的端点、大小和模型 ID；保存的 DashScope paraformer-v2 语音配置文件会自动迁移到 paraformer-realtime-v2。

可靠性和可访问性

失败的聊天提交在重试和存储竞争中仍然可以恢复，而未答复的轮次可以从丢失的工作人员中恢复。 LightRAG 仅重用兼容的索引缓存，检索到的图形保留在有界模型上下文中，并且部分 Deep Research 和 Manim 失败会报告其原因。共享工具提示取代了学习和工作区控件中无法访问的本机标题提示，包括触摸交互。

升级注意事项

运行pip install -U deeptutor； Docker用户拉ghcr.io/hkuds/deeptutor:latest。现有数据无需手动迁移。

  • Kiwix： 运行可访问的 kiwix-serve 实例，对所选 ZIM 进行全文搜索，然后连接其服务器 URL 和存档名称。断开连接只会删除 DeepTutor 指针。
  • 较旧的知识库数字： 重新索引现有的 LlamaIndex 源文件以创建视觉记录。 MinerU 和 PyMuPDF4LLM 可以发出支持的图像；默认的纯文本解析器和当前的 Docling 适配器则不然。其他 RAG 引擎尚未对视觉记录建立索引。
  • systemd 安装： 对于正在运行的服务禁用应用内更新切换。停止该服务，在该服务的 Python 环境中升级 DeepTutor，然后使用 systemctl 重新启动它。
  • Windows 麦克风转录： 本机 DashScope 和 Volcengine 语音适配器需要服务 PATH 上的 ffmpeg 来转换浏览器 WebM/Opus 音频；安装后重新启动 DeepTutor。兼容OpenAI的STT不需要本地转换。 完整 Changelog：https://github.com/HKUDS/DeepTutor/compare/v1.6.11…v1.6.12
