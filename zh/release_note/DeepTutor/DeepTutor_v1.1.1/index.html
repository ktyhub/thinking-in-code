DeepTutor v1.1.1

DeepTutor v1.1.1 Release Notes

发布日期： 2026.04.17

亮点

通用“立即回答”逃生舱口 - 每个功能的快速路径

将“立即回答”从仅聊天功能升级为尊重每种功能输出形状的通用中断。新的共享帮助程序 deeptutor/capabilities/_answer_now.py 提供了门 (extract_answer_now_context) 和提示友好的跟踪摘要，并且每个内置功能现在在 run() 顶部拥有自己的快速路径分支：

  • chat — 从部分跟踪（现有行为）合成最终的降价答案。
  • deep_solve — 跳过计划+推理，直接跳到作家。
  • deep_question — 跳过构思/模板，在一次结构化调用中发出完整的测验 JSON（仍由 QuizViewer 呈现）。
  • deep_research — 跳过改写/分解/研究，直接根据积累的证据撰写报告。
  • math_animator — 跳过分析+设计+总结，但保留代码生成+渲染，因此用户仍然可以获得真实的动画。
  • visualize — 跳过分析 + 审查，在一次结构化调用中发出最终可渲染代码。 每个快速路径都保留与正常管道相同的结果包络（因此测验/数学动画/可视化查看器呈现不变），并在前面添加 > ⚡ Skipped X stage(s) 通知，以便用户知道这是尽力而为的提前退出。协调器不再将 answer_now 重新路由到 chat；现在，它会保留 active_capability，并且只有在最初选择的功能已从注册表中删除时才会回退到 chat。前端匹配：handleAnswerNow 不再覆盖快照的功能，单次保护的 AnswerNowRow 组件在流跟踪面板下方呈现内联操作。

共同作者 — 可调整大小的分割和线锚定滚动同步

Co-Writer 页面在编辑器和预览窗格之间采用了一个可拖动的分隔符（在 localStorage 中具有持续的比例）和真正的双向滚动同步，可以在软包装线中幸存下来。现在，每个预览块都带有一个 data-source-line 属性，该属性指向 Markdown 源中的起始行（由 remark 的 AST 位置提供）；在编辑器端，隐藏的镜像元素模仿文本区域的环绕几何形状，因此我们可以读取每个源代码行的真实像素 y。由于两侧都表示为像素坐标，同步变成任一方向上的单个分段线性插值，每个源行缓存仅在内容或换行宽度更改时才无效。

保存到笔记本 — 消息选择模式

SaveToNotebookModal 现在接受一个可选的 messages 属性，该属性将模式翻转为“选择模式”：用户准确选择要包含的用户/助理，并且发送到后端的文字记录 + userQuery 是从所选子集重建的。快速预设（“全选”、“最后一圈”、“最后 3 圈”）和跟踪第一个选定用户消息的自动生成标题可在常见情况下保持快速的流程。该模式现在还使用 Check / MessageSquare / User 图标来一目了然地区分角色，并与保存微调器分开报告笔记本列表的加载状态。

跨堆栈采用真正的笔记本系统

将所有剩余的笔记本表面从旧测验类别 API 迁移到真正的 /api/v1/notebook/* 端点。新的 web/lib/notebook-api.ts 块导出类型化的帮助程序 - listNotebooks、getNotebook、createNotebook、updateNotebook、deleteNotebook、deleteNotebookRecord - 以及保留的仅测验帮助程序。 “知识”→“笔记本”选项卡、“指南”页面的笔记本参考选择器 (useNotebookSelection) 和“保存到笔记本”模式现在都可以端到端解析 UUID，因此从共同作者、聊天或引导学习中保存的记录可以立即在任何地方作为参考被发现。

统一可折叠设置面板

将以前仅存在于 ResearchConfigPanel 中的可折叠“设置”部分提取到共享 CollapsibleConfigSection 组件中。 Quiz、Math Animator 和 Visualize 面板现在共享完全相同的 V 形 + 摘要标题，并且每个表单都附带一个 summarizeXxxConfig 帮助程序，因此折叠状态显示有意义的一行（例如 Custom · 5q · Hard · MCQ 或 Mimic · paper.pdf · max 10）。现在，无论哪个功能处于活动状态，聊天页面都会保持单个 panelCollapsed 状态，在功能切换时自动展开，并在发送消息后自动折叠，以便作曲家在对话期间保持紧凑。

流媒体停止按钮和作曲家润色

将发送按钮内的微调器替换为专用的 停止 按钮，该按钮在回合播放时代替发送按钮出现。一个微弱的环围绕边缘缓慢旋转，表示“仍在工作 - click 取消”，前面和中心有一个白色方块作为 click 目标。消息上方的标题（功能标签 + 保存/新聊天按钮）现在始终呈现，并且消息容器在顶部和底部拾取软遮罩渐变，因此流内容淡入/淡出，而不是在滚动边缘处的 clipping。在深度研究模式下，来源移至下拉列表中，其中包含活动选择的紧凑摘要行，与工具选择器使用的模式相匹配。

TutorBot 配置管理器重构

将 TutorBotManager 的配置持久性重写为小型公共 API（load_bot_config、save_bot_config、merge_bot_config），并进行了三项有意义的改进：写入现在是原子（write-temp + Path.replace），因此被杀死的进程永远不会留下半写入的 config.yaml；合并具有显式清晰的语义 - None 表示“保持原样”，空字符串或空字典是有意清除的 - 因此 clients 可以故意擦除描述或频道列表；并且 API 端点仅转发 model_dump(exclude_unset=True)，因此省略的字段会传递到磁盘上的值。新的回归测试涵盖原子写入合约、损坏的 yaml 后备以及四种合并语义情况。

Markdown 渲染器改进

MarkdownRenderer 系列获得了 trackSourceLines 属性，该属性通过每个块元素（标题、列表、段落等）传播 data-source-line 属性，并绕过换行规范化通道（processMarkdownContent、normalizeMarkdownForDisplay），因此 AST 位置对编辑器/预览同步消费者保持忠实。 RichCodeBlock 现在完全跳过 react-syntax-highlighter 对于未标记 / text / plaintext 栅栏（消除 Prism“未知语言”警告）并将它们渲染为整洁的纯等宽块。美人鱼检测还扩展到识别由预处理器重写为美人鱼的 editor.md 样式 ```flow, ```seq 和 ```sequence 栅栏。

主题和指南 UI 刷新

通过更深的前景、更温暖的边框和稍微饱和的 --primary (#B0501E) 来收紧默认的灯光和雪景主题，以便在新卡片表面上获得更好的易读性。引导学习页面 (/guide) 已从硬编码的 slate-* / indigo-* 调色板迁移到设计标记（var(--card)、var(--primary)、var(--muted-foreground) 等），因此它现在尊重主题切换器。 HistorySessionPicker 得到了相同的处理，并修复了会话时间戳，该时间戳被视为毫秒而不是秒（产生 1970 个日期）。

系统消息渲染修复

后端系统消息（例如由回合运行时编写的测验后续接地上下文）现在在 UnifiedChatContext.hydrateMessages 边界处被过滤掉，并在 ChatMessageList 中再次被防御性地过滤掉，因此它们永远不会在 UI 中以幽灵聊天气泡的形式出现，同时仍按预期流入 LLM 上下文。

错误修复

  • TutorBot 通道配置在每次服务器重新启动时都会被擦除 (#332) - create_and_start_bot 正在构建一个新的 BotConfig，每次调用时默认值都是空的，然后 _save_bot_config 会在现有的 config.yaml 上持续存在，擦除用户配置的通道（例如 Telegram）。端点现在首先加载现有配置并仅覆盖 client 提供的字段。
  • selective_access_log 中间件在每个非 200 响应上崩溃（#334 / #335） — 中间件将四个参数传递给 uvicorn 的 AccessFormatter，它期望五个（省略 http_version），在每个错误响应上引发 ValueError: not enough values to unpack。现在从 ASGI 范围读取 http_version，并使用 1.1 回退。
  • 15 个 npm 安全漏洞 (#330) — 修正了 jspdf 4.0.0 → 4.2.0（9 个 CVE，包括关键 PDF 注入）、next 16.1.1 → 16.2.3（8 个 CVE，包括 HTTP 走私、CSRF 绕过）、mermaid 11.12.2 → 11.14.0，以及配套的eslint-config-next。 npm audit fix横扫间接链条（flatted、lodash-es、minimatch、picomatch、dompurify、ajv、brace-expansion）。最终状态：0 个漏洞，无重大更改。
  • .env.example_CN — 删除了提供商列表评论中意外的 // README 后缀。

测试套件扩展

添加了一个新的 tests/services/tutorbot/test_manager_config.py 模块，涵盖加载/保存往返、损坏的 yaml 回退、原子临时文件写入、中间写入 OSError 后的故障恢复以及所有四个 merge_bot_config 语义（无现有配置、省略字段直通、None-未提供和空值显式清除）。使用显式清除测试类扩展了 tests/api/test_tutorbot_router.py。重写了 Orchestrator 立即应答路由测试以固定新合约 - 设置 answer_now_context 时会保留 ZZPH100​​ZZ，仅当原始功能丢失时，Orchestrator 才会回退到 chat，并在两者均未注册时发出明显的错误。添加了新的 tests/capabilities/test_answer_now.py 模块，其中包含 28 个案例，涵盖共享助手（extract_answer_now_context、format_trace_summary 截断/i18n、make_skip_notice、labeled_block、join_chunks）以及每个功能快速路径：chat、deep_solve、deep_question（包括unparseable-JSON 后备）、deep_research、visualize（包括代码围栏剥离和无效的 render_type 恢复）和 math_animator（验证 run_analysis/run_design/run_summary 在 run_code_generation/run_render 时不被调用是）。反向测试证实，当不存在 answer_now_context 时，功能仍然采用正常管道。
