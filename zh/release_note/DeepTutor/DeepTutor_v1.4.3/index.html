DeepTutor v1.4.3

DeepTutor v1.4.3 Release Notes

发布日期： 2026.06.12 自 v1.4.0 以来最大的版本。 TutorBot 成长为 合作伙伴，聊天折叠成单个代理循环，多用户变得真实 每用户隔离，以及 Visualize、Co-writer、文件查看器、文档 解析，CLI 全部升级。文档位于 deeptutor.info 已与 — 一起重建 每个合作伙伴渠道现在都有自己的英文和中文设置指南。

从 TutorBot 升级？ 迁移是自动且非破坏性的： 首次启动时，您的机器人将成为合作伙伴 — 通道配置（秘密 包括），模型选择，灵魂库继承，以及每个 机器人的角色变成了 SOUL.md。旧的 data/tutorbot/ 树是 保持原状，因此回滚可以保持安全。一项重大改变： HTTP API 从 /api/v1/tutorbot/... 移至 /api/v1/partners/... — 更新调用它的所有脚本。 [tutorbot] 点额外保留 作为 [partners] 的别名。

新消息

TutorBot → 合作伙伴

您的机器人现在是合作伙伴 - 相同的想法，更强的执行力：

  • 合作伙伴与产品聊天在同一代理循环上运行（单独的 纳米机器人引擎消失了），因此每次聊天改进都会影响您的 IM 机器人 自动。
  • 生产级消息管道：发送重试、重复数据删除、合并和 每个通道的传输矩阵。
  • Telegram、Discord 和 Feishu 上的 直播回复 — 答案 在生成它们时进行渲染。
  • 新的 WeCom AI Bot 频道；总共 15 个通道连接器，来自 Slack 以及钉钉、QQ 和 WhatsApp 的 Discord。
  • 网络聊天现在需要附件 - 将图像或文件直接放入 合作伙伴对话。
  • 带有应用内编辑器的重写灵魂模板库。

聊天循环

两阶段目标/响应管道已经消失。聊天现在运行单个 使用端到端调用的本机工具探索代理循环 - 减少移动 零件、更智能的工具使用、不再有错误的转弯。新的活动 header 将状态行固定在顶部并折叠思维/工具 一旦答案落地就追踪。

真正的多用户隔离

  • 每用户授权 v2：工具、MCP 服务器和执行访问受到控制 来自管理 UI 的每个用户。
  • 工作区布局移至 data/users/<uid> + data/system；现有的 部署会自动迁移。
  • exec 运行程序仅安装调用用户的工作区子树（新 Dockerfile.runner)，因此沙盒代码永远看不到其他用户的文件。

可视化、重建

内联、主题感知的 SVG 渲染；结构化提示；和一个当地人 验证 + 修复通过取代旧的全面 LLM 审查 - 更快， 更便宜，而且破损的图表也少得多。全屏现在适用于所有 视觉类型。

更锋利的日常工具

  • 共同作者通过 Mermaid 渲染流程图和序列图，以及 选择范围的问题可以从您的知识库和网络中提取。
  • 文件查看器：真正的浏览器内 docx/xlsx 预览、拖动以调整大小以及 活动面板现在与您打开的文件并存。
  • MinerU云解析作为本地后端的替代方案 (/settings/mineru)，问题提取现在捕获问题 类型、难度和答案。
  • 办公技能开箱即用 — docx/pdf/pptx/xlsx 生成号 更长的时间需要翻转沙箱开关。
  • CLI 聊天，重写：与新的循环协议一致，交互式 ask_user 在终端提示，Ctrl-C 取消，并可折叠 思维输出。

修复重要问题

Qwen 型号不再将 JSON 包装泄漏到答案中，Windows 安装 正确使用 UTF-8，Zulip 机器人可以可靠地捕获提及内容，并且 文件描述符耗尽错误和误报健康检查都消失了。

文档，已同步

deeptutor.info 在此版本中进行了重建： 每个合作伙伴渠道的专用设置指南（英语 + 中文）， 刷新了整个截图，并更新了CLI和服务器API 参考文献。

升级注意事项

  • pip install -U deeptutor — 迁移首先自动运行 开始，并且都是幂等的。
  • 旧版 multi-user/ 树木原地移至 data/users/；导师机器人 机器人成为合作伙伴（请参阅顶部的注释）。
  • 基于执行的技能现在默认允许子进程。为了恢复旧的 行为，在系统设置中将 sandbox_allow_subprocess 设置为 false。 完整 Changelog：https://github.com/HKUDS/DeepTutor/compare/v1.4.2…v1.4.3
