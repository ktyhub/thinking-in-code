DeepTutor v1.0.3

DeepTutor v1.0.3 Release Notes

发布日期： 2026.04.13

亮点

###问题笔记本——统一测验复习系统 将单一用途的“错误答案注释”替换为完整的问题笔记本，该笔记本存储每个测验问题（正确和错误）以及丰富的元数据 - 问题类型、选项、解释和难度。每个条目都支持书签和类别标记以进行有组织的审阅。新的专用 /notebook 页面提供过滤（全部/已添加书签/错误）、类别管理（创建、重命名、删除）以及返回原始会话的直接链接。 QuizViewer 组件现在集成了内联书签和类别控件，因此用户可以在不离开测验流程的情况下组织问题。

Visualize 中的美人鱼图支持

使用第三种渲染类型扩展了可视化功能 - Mermaid。分析代理现在在 svg、chartjs 和 mermaid 之间进行选择，对于结构化图（流程图、序列图、类图、思维导图等）更喜欢 Mermaid。代码生成器和审核代理收到相应的提示更新，前端 VisualizationViewer 通过专用的 <Mermaid> 组件渲染美人鱼图。

嵌入模型不匹配检测

知识库现在记录索引时使用的嵌入模型和维度。加载时，系统将存储的指纹与当前配置的嵌入模型进行比较；不匹配的 KB 带有 embedding_mismatch 和 needs_reindex 标记。当查询不匹配的知识库时，RAG 搜索管道会显示警告，知识页面会显示警报徽章，以便用户知道要重新索引。

系统消息合并以实现 Qwen / vLLM 兼容性

在 AgenticChatPipeline 和 ChatAgent 中将多个系统消息合并为单个合并系统消息，修复了与通过 vLLM 拒绝多系统消息对话的 Qwen 模型的兼容性。上下文生成器现在从存储的历史记录中过滤重复的系统消息以避免冗余。

LM Studio 和 llama.cpp 提供商支持

为 LM Studio (localhost:1234) 和 llama.cpp (localhost:8080) 添加了一流的 ProviderSpec 条目，具有自动基本 URL 检测和 openai_compat 后端，以及嵌入提供程序别名映射。

玻璃主题

引入了新的玻璃主题，具有磨砂玻璃卡片表面、渐变背景和发光按钮。主题切换器现在在光→暗→玻璃之间循环。

深入研究报告代理的弹性

在报告代理中提取了具有可配置重试逻辑的共享 _call_llm_json 帮助程序，替换了三个相同的内联 LLM-call-then-parse 块，用于介绍、节正文和结论生成。

文档迁移

删除了旧版 VitePress docs/ 文件夹；文档已迁移到项目网站。
