DeepTutor v1.2.0

DeepTutor v1.2.0 Release Notes

发布日期： 2026.04.20

亮点

Book Engine — 多代理“Living Book”编译器

推出了全新的图书引擎 (deeptutor/book/)，它将用户输入（聊天历史记录、笔记本、知识库和自由格式意图）编译成结构化、基于块的交互式“活书”。该引擎与 ChatOrchestrator 平行，驱动五级多代理管道：

  1. 构思 — 法学硕士根据用户的意图和源材料提出书籍大纲。
  2. 源探索 - SourceExplorer 代理执行深度 RAG 检索和知识库运行状况检查 (kb_health.py) 以显示最相关的段落。
  3. 脊柱综合 - SpineSynthesizer 代理将提案与探索的来源合并到章节/页面树中 (Spine → Chapter → Page)。
  4. 页面规划 — PagePlanner 代理将每个页面设计为键入块的有序序列。
  5. 块编译 — BookCompiler 将每个块分派到其专用生成器。 第 1 阶段提供 14 种块类型：文本、标注、测验、闪存卡、代码、图形、深入研究、动画、交互式、时间线、概念图、部分、用户注释以及仍在编译的块的 占位符。每个生成器都有自己的双语 (en/zh) YAML 提示，并且可以调用 RAG 助手来获取接地内容。 Web UI (web/app/(workspace)/book/) 包括一个 BookCreator 向导（意图 → 提案 → 书脊确认）、一个用于拖放章节重新排序的 SpineEditor、一个带有大纲导航栏和每块渲染器的 PageReader（概念图渲染为交互式力导向图、内联评分测验、带有翻转动画的闪存卡等）、用于实时编译的 BookProgressTimeline跟踪、用于上下文问答的 BookChatPanel 以及在底层知识库不健康时发出警告的 BookHealthBanner。每本书的 WebSocket 流将编译事件扇出到所有连接的 clients。 后端：POST /api/v1/book/create、POST /confirm-proposal、POST /confirm-spine、POST /compile-page、GET /list、GET /{book_id}、DELETE /{book_id} 以及 WS /ws/{book_id}。 CLI：deeptutor book create、deeptutor book list、deeptutor book show、deeptutor book delete。

旧版指导学习已删除

deeptutor/agents/guide/ 模块（指南管理器、4 个代理、8 个提示 YAML）和整个 /guide Web UI（组件、挂钩、类型、API 路由器 - 约 5,300 行）已被删除。图书引擎以更丰富、更可扩展的架构取代了引导学习。

多文档共同作者工作区

Co-Writer 不再是单文档草稿本。现在，每个文档在 data/user/workspace/co-writer/documents/ 下都有自己的持久目录，并具有原子清单写入 (CoWriterStorage)。 Web UI 路由到每个文档页面 (/co-writer/[docId])，侧边栏显示 CoWriterRecent 部分以供快速访问。新的 API 端点可处理完整文档 CRUD（GET /list、POST /create、GET /{doc_id}、PATCH /{doc_id}、DELETE /{doc_id}）。

交互式 HTML 可视化

可视化功能现在支持第四种渲染类型 - html - 除了 svg、chartjs 和 mermaid。当 LLM 确定用户请求需要“用户交互 + 状态更改 + 混合文本/图形”（例如可拖动演示、分步演练、clickable 练习）时，它会生成一个在 iframe 内呈现的独立单文件 HTML 页面。本地验证通道 (is_valid_html_document) 在服务之前检查输出；如果模型返回无法渲染的内容，则会注入样式化的后备模板。 HTML 页面会跳过 LLM 审核阶段（节省 30-60 秒的延迟，质量损失可以忽略不计）。新的 figure 约束模式将 LLM 限制为仅 svg/chartjs/mermaid — 由 Book Engine 的图形块内部使用。

问题库@-聊天中提及

新的 QuestionBankPicker 组件允许用户直接在聊天编辑器中@提及各个问题库条目。选定的条目由转运行时 (_build_question_bank_context) 解析为结构化 Markdown 上下文（包括问题文本、选项、用户/参考答案和解释），并与笔记本和历史参考文献一起注入，以便法学硕士可以对过去特定的测验表现进行推理。

及时外化——第 2 阶段

继续将硬编码的 LLM 字符串迁移到可编辑的 YAML 文件中：

  • answer_now — question、research、solve 和 visualize 功能现在从 prompts/{en,zh}/answer_now.yaml 加载其快速路径提示。
  • 笔记本代理 — analysis_agent 和 summarize_agent 提示已移至 YAML； Python 模块现在委托给提示管理器。
  • 功能模块（_answer_now.py、deep_question.py、deep_research.py、deep_solve.py、visualize.py）相应精简。

联合作者模块重组

将 deeptutor/agents/co_writer/ 移至 deeptutor/co_writer/（顶级服务模块），以反映其与 deeptutor/book/ 一起的独立性质。

侧边栏大修

  • “引导学习”导航条目替换为书籍（图书馆图标）。
  • 添加了 BookRecent 和 CoWriterRecent 侧边栏部分以及每项导航。
  • 侧边栏折叠/展开状态提升为 AppShellContext，因此它在路线转换中持续存在。
  • 折叠侧边栏经过改进：徽标 + 展开切换分层，悬停显示、圆形“新聊天”按钮、微妙的分隔线和一致的间距。

功能和配置面板刷新

更新了 Quiz、Research、Visualize 和 Math Animator 中的共享类型定义和配置面板，以与新的功能选项（例如 html 渲染模式、扩展的区域设置键）保持一致。 TracePanels 聊天 UI 中的布局和样式得到了改进。

自述文件和本地化更新

所有九个本地化自述文件（AR、CN、ES、FR、HI、JA、PT、RU、TH）均已更新，以反映 Book Engine、多文档 Co-Writer 和其他 v1.2.0 功能。

错误修复

  • 频道管理器导入时崩溃 — loguru.logger 在模块范围内导入，当 TutorBot 依赖项不存在时，导致 ImportError。替换为惰性 _logger() 工厂函数。
  • 过时的 test_app_facade.py — 删除了引用已删除代码路径的过时测试模块。
  • 测试包中缺少 __init__.py — 添加了 tests/agents/、tests/api/、tests/cli/、tests/knowledge/、tests/scripts/、tests/services/llm/、tests/services/memory/、tests/services/search/、tests/services/session/ 和 tests/tools/ 的初始化文件以修复导入分辨率。

测试套件和 CI

  • CI 现在安装 requirements/tutorbot.txt 并将其与服务器/cli 要求一起缓存。
  • 从 CI 测试清单中删除了过时的 test_app_facade。
  • 更新了 conftest.py 用于 RAG 管道测试；刷新了提示奇偶校验、功能运行时、LLM 探针配置、工厂提供程序、模型目录、配置加载器和笔记本服务测试，以匹配重组的导入。
  • 为 PWA 元数据添加了 favicon 和 apple-touch-icon 资产。 完整 Changelog：https://github.com/HKUDS/DeepTutor/compare/v1.1.2…v1.2.0
