DeepTutor v1.5.13

DeepTutor v1.5.13 Release Notes

发布日期： 2026.08.17 v1.5.12 是关于答案材料的来源。这主要是关于书——将材料变成你“阅读”的东西而不是你聊天的东西的表面。一本书可以生成，但不能真正使用：页面在编写时冻结，它声称跟踪的进度从未被记录下来，并且您所获得的内容无法离开应用程序。这一差距是本次发布的主要内容。主屏幕也不再要求您从空白作曲家开始。直接插入——无需迁移，无需重新索引。

新消息

观看正在写的一本书，然后完成它并随身携带

编译比启动它的请求更有效：一旦页面 shell 存在，confirm_spine 就会返回，而它排队的工作会运行几分钟。事件总线由该请求拥有并随之关闭，因此每个后续事件都被丢弃，并且“看着你的书被写”降级为冻结页面。该流现在由进程按book拥有，因此它在请求、刷新和重新连接后仍然存在。 现在实际记录了阅读进度。 visited_page_ids 和 bookmarked_page_ids 已声明，但从未在该功能的生命周期内编写；访问过的页面、书签和测验尝试现在汇总成完成分数和薄弱章节列表。 一本书可以离开应用程序：导出到独立的 Markdown 文档。每个块类型都有一个文本投影，并且固有的视觉块（渲染的动画，交互式小部件）降级为它们的描述加上指针，而不是默默地消失。非 ASCII 标题在下载后仍然存在——中文或带重音的书名用于彻底失败请求。

在批准一本书之前先了解它的价格 - 并且不要支付两次

确认脊柱会启动数十个法学硕士电话和许多分钟的工作。编辑器现在显示从剖面架构师自己的模板派生的实时每章估计，因此该数字不会偏离实际生成的数字，并且在您添加、删除或重新输入章节时保持准确。 两个在生产中不可见的调度缺陷得到了修复：同一个页面可以同时编译两次——计费两次，一个结果被默默丢弃——而且一本书会因供应商中断而继续工作，直到每一章都生成了一半。源扫描也是有界的。无门控的八个知识库针对十几个查询触发了大约一百个并发的提供商调用；现在，上限是循环分配的，因此它不会完全花在前几个垒上。

互联知识库不再默默贡献任何东西

连接的 KB（黑曜石保管库、远程 LightRAG 或 IMA 库、子代理 CLI）没有本地索引，因此 rag_search 不会返回任何内容。不管怎样，书籍一代横扫了它们，空洞的结果与没有相关内容的来源没有什么区别：附上你的金库，没有任何东西告诉你它的贡献为零。检索现在可以区分索引碱基和连接的指针，并相应地路由每个碱基。

三个地方开始，取自你实际做的事情

家庭作曲家现在提供根据您的记忆构建的三个入门建议 - L3 合成以及您在各个表面上的最后几次活动。他们提出了一个需要理解的具体事物，而不是一种重温历史的方法，并且它们根据语言进行了调整，因此不会溢出。新的 recall 内存会读取它们，并且在不加载实体内容的情况下读取快照标记。

掌握路径遵循对话

一条路径比任何一次聊天的寿命都长，并且一次聊天可以按顺序使用多个路径。现在，在路径之间移动实时转向发生在一个地方 - 租用、会话首选项和实时转向一起更改，在获取之前释放 - 因此，被拒绝的切换会让学习者留在原来的位置，而不是半移动。路径状态和回合恢复得到强化，教学内容保持可见，安排定性审查，删除会话可以清理其路径。

腾讯IMA凭证上移至账户

IMA 凭证过去只存在于每个 KB 上。现在，它们还在帐户级别从 知识 → IMA 引擎页面 进行解析，就像 PageIndex 的密钥所做的那样，在完成后，每 KB 对仍然获胜。现有绑定保持不变，并且轮换帐户密钥会更新依赖它的每个 KB。只读 IMA 连接和源文本检索也同时修复。

什锦

  • EPUB 是受支持的知识库格式，Docling 可以针对 Docling 服务服务器 (mode=remote) 远程解析，无需本地安装或模型下载。
  • 生成的代码在到达您之前会被解析。 用于发送的截断代码片段，没有任何内容将其标记为未选中。
  • 概述章节保持单一。 重新确认书脊每次都会长出第二个书脊，并且页面会被批量重建 - 这是绕过 edited_by_user 保护的唯一路径。它的措辞也不再硬编码为中文或英文，而选择器提供了十一种语言。
  • 测验块直接读取问题管道，而不是丢弃最慢块的进度的遗留外观。
  • 知识： 大型上传流通过 Web 层，文档解析在事件循环之外运行，文档存储探针在 kb list 中缓存和重复数据删除，并且 GraphRAG 模型/嵌入兼容性得到强化。
  • **合作伙伴：**每个用户的数据是隔离的，无效的频道配置不再导致其他人瘫痪，工具列表遵循全局聊天切换，并且合作伙伴在其选项卡变为非活动状态后重新连接。
  • 模型和提供程序： 模型目录和提供程序传输恢复而不是保持损坏，目录机密在设置 API 中受到保护，GPT-5 代理工具使用响应 API，提供程序流失败边界保留，并且完成的转向消息 ID 在重新连接时保持不变。
  • **运行时：**活动的 virtualenv 在 bwrap 沙箱内可见，无效的 home 和占位符 OpenAI 密钥被拒绝，Windows .cmd 垫片在 CLI 生成之前解析，控制台异常回溯被保留，并且 mcp 默认安装，以便 PageIndex MCP 服务器连接。

升级注意事项

pip install -U deeptutor； Docker用户拉动ghcr.io/hkuds/deeptutor:latest。没有架构更改，没有重新索引，没有迁移。

  • 在此版本之前编译的书籍没有记录进度。 完成分数和薄弱章节从您下次阅读时开始累积；不会回填任何内容，也不会重写现有页面。
  • 升级时正在编译的书应该恢复，而不是留下。事件流现在由每本书拥有，因此重新打开它会重新附加到实时编译，而不是显示冻结的页面。
  • settings/ima.json 是新的并且是可选的。现有的每 KB IMA 凭证将继续像以前一样工作 — 帐户级对仅填充不包含自己的 KB。 完整 Changelog：https://github.com/HKUDS/DeepTutor/compare/v1.5.12…v1.5.13
