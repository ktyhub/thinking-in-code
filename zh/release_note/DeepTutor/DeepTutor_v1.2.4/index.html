DeepTutor v1.2.4

DeepTutor v1.2.4

DeepTutor v1.2.4 Release Notes

发布日期： 2026.04.25

亮点

聊天中支持更多附件格式

v1.2.3 文档附件管道已扩展到 Office 文件之外。聊天附件现在接受与知识库摄取路由器相同的文本格式：Markdown、纯文本、日志、JSON/YAML/TOML、CSV/TSV、LaTeX/BibTeX、HTML/XML/SVG、样式表、脚本和常见源代码文件（.py、.js、.ts、.tsx、.java、 .cpp、.go、.rs、.sql、.sh 等）。

  • 与 KB 路由的后端奇偶校验 — deeptutor/utils/document_extractor.py 导入 FileTypeRouter.TEXT_EXTENSIONS，因此聊天附件和 KB 上传共享文本/代码格式的一个真实来源。 FileTypeRouter.decode_bytes() 集中了 UTF-8 / UTF-8-BOM / GBK / GB18030 / Latin-1 / CP1252 后备链。
  • SVG 作为可读源 — .svg 已添加到 RAG 文本扩展集中，并被视为文档附件而不是视觉图像，让 LLM 检查 XML 源，同时前端仍然呈现安全的缩略图预览。
  • 键入附件 UX - web/lib/doc-attachments.ts 现在公开 OFFICE_EXTS、TEXT_LIKE_EXTS、SVG 检测、更丰富的 MIME/扩展后备以及代码、shell、JSON、配置、数据、标记、样式表、纯文本、Office 文档和 SVG 的特定于类别的图标。
  • Composer 副本已更新 — 拖放提示现在宣传“图像、Office 文档、代码和文本”，而不是旧的仅限 Office 的列表。

一命令设置教程

scripts/start_tour.py 已从纯粹的配置向导演变为 7 步全新安装路径，可以检测本地环境、安装依赖项，然后指导提供程序配置。

  • 依赖项安装步骤 — 游览检查 Python、uv、Node.js 和 npm；安装后端要求，以可编辑模式安装 DeepTutor，并使用实时终端输出运行前端 npm install。
  • uv pip 兼容性 (#376) — Python 依赖项安装现在更喜欢 uv pip（如果可用），并绑定 --python <current-interpreter>，以便包落在运行游览的解释器中，而不是不相关的 .venv / $VIRTUAL_ENV。
  • Windows npm 检测 (#381) — npm 调用在 Windows 上使用 npm.cmd，修复版本检查并在 npm 作为命令填充程序而不是可执行文件公开的系统上安装命令。
  • 提供商注册表驱动的 LLM 选择 — 向导现在从完整的 PROVIDERS 注册表中读取，按模式对提供商进行分组，突出显示常见服务，并包括较新的选项，例如 custom_anthropic、OpenRouter、SiliconFlow、Volcengine / BytePlus 编码提供商、GitHub Copilot、OpenAI Codex、llama.cpp、OVMS、MiniMax、Mistral、Qianfan、Step Fun 和小米 MiMo。
  • 搜索和配置提示 — Serper 在搜索提供程序列表中可用； Azure/API 版本和代理提示现在显示英文和中文的内联指导。
  • 长列表终端用户体验 — scripts/_cli_kit.py 在滚动窗口内呈现长选择菜单，并带有“更多上方/下方”指示器，防止当提供者列表超出屏幕高度时出现过时的终端行。

聊天 Markdown 导出

聊天页面现在在“保存到笔记本”和“新聊天”旁边有一个“下载 Markdown”操作。 web/lib/chat-export.ts 将当前对话序列化为 Markdown，并带有标题、ISO 导出时间戳、角色标题、功能标签和附件元数据，然后使用经过清理的带日期标记的文件名下载它。这为用户提供了一个轻量级的本地导出路径，用于共享、存档或将对话移动到外部笔记中。

知识库管理 UI 波兰语

知识页面收紧，以实现更密集的日常管理：

  • 创建和上传拖放区现在是更简单的虚线卡，具有简洁的内联上传策略摘要。
  • 知识库卡从四个大型统计面板移动到紧凑的行，显示文档计数、索引准备情况、上次更新时间、提供者、嵌入模型、实时进度和存储路径。
  • 默认/删除操作在视觉上得到简化，降低了卡片高度并使大知识库列表更易于扫描。

文档和本地化更新

自述文件系列已更新，以匹配新的安装故事和提供程序界面：

  • 波兰语自述文件 — assets/README/README_PL.md 添加了项目自述文件的完整波兰语翻译 (#379)。
  • 设置文档 — 主要自述文件和多语言自述文件现在将引导式教程描述为推荐的全新克隆路径：创建 Python 环境，运行 python scripts/start_tour.py，然后使用 python scripts/start_web.py 进行日常启动。
  • 提供商文档 — 刷新了 v1.2.3 提供商注册表的提供商表，包括 custom_anthropic、MiniMax 的规范端点、编码计划提供商、本地提供商以及 OpenAI Codex / GitHub Copilot 的澄清身份验证说明。
  • 发布/新闻部分 - 多语言自述文件现在包括 v1.2.2 和 v1.2.3 摘要、贡献指南标注以及 20k-star 社区里程碑。

UI 和主题修复

  • 主题感知弹出窗口 - 作曲家功能/工具/参考/技能菜单现在使用 --popover 加上背景模糊而不是 --card，提高了 Glass 主题和深色弹出窗口上下文中的对比度。
  • 原生配色方案提示 - 浅色、深色、雪花和玻璃主题根声明了正确的 color-scheme，改进了原生控件和浏览器渲染的表面。
  • 平滑滚动水合 - 全局平滑滚动现在位于 html[data-scroll-behavior="smooth"] 后面，该属性由根布局设置，以避免无意中应用它。
  • 侧边栏徽标大小调整 - 侧边栏徽标图像现在固定显式渲染的宽度/高度类，以防止小的布局变化。

清理

从存储库中删除了过时的 nanobot 子模块指针和已弃用的 scripts/extract_numbered_items.sh 存根。 v1.2.x 代码库现在依赖于树内文档提取和 RAG 路由路径，而不是旧版帮助程序。

测试套件扩展

  • 后端文档提取 — tests/utils/test_document_extractor.py 现在涵盖纯文本、Python 源、JSON、CSV、Markdown、UTF-8-BOM 输入、GBK 回退解码和 SVG 源提取。
  • 前端附件分类 — web/tests/doc-attachments.test.ts 现在涵盖文本/代码接受、SVG 作为文档路由、不区分大小写的 SVG 文件名检测以及代码、JSON、配置、shell、数据、标记、样式表和 SVG 的新图标类别。

发生了什么变化

  • 修复：https://github.com/HKUDS/DeepTutor/pull/381 中的 @jonathanzhan1975 使用 npm.cmd 在 Windows 上进行版本检测

  • 文档：在 https://github.com/HKUDS/DeepTutor/pull/379 中添加 @kKamUL 的自述文件的波兰语翻译
