DeepTutor v1.6.9

DeepTutor v1.6.9 Release Notes

发布日期： 2026.09.21 v1.6.9 以 v1.6.8 为基础，带来了基于文件夹的学习工作区、每日练习循环、重新设计的设置和更清晰的流式对话。学习界面在 /learning/ 下移动，并重定向旧链接；对话删除现在意味着永久删除，并且可以对您想要保留的对话进行存档。

新消息

学习数据的工作区

在开始对话、书籍、掌握路径、阅读或观看课程时选择工作空间。自定义工作区将学习数据保存在 .deeptutor/data/ 中，将生成的文件保存在 outputs/ 中；设置、凭据和内存在您的帐户中保持共享。在 设置 → 工作空间 中管理工作空间及其技能、MCP 服务和知识库。合作伙伴可以保留私有资源或保持与工作区的链接。请参阅工作空间。

具有预览和恢复功能的数据迁移

设置 → 数据迁移 在工作区之间移动数据之前预览涉及的文件、会话和依赖项。传输在清除源之前验证复制的数据，拒绝冲突的目标数据，并在完成后保留恢复快照。中断的操作可以从最近的操作中恢复或回滚。

练习现有的题库

个性化学习→练习为 /space/questions 已有的问题添加了每日复习、错误跟踪和统计。选择题和对错题在服务器端评分；填空题和简答题采用自我评估的方式。导入 .xlsx、.csv、.tsv 或 .json 文件，每次导入最多 500 个问题。掌握问题暂停复习安排；后来的错误答案又恢复了。

专用页面的设置

设置现在具有针对提供者、语言模型、任务模型、语音、多模式生成、使用、数据迁移和存档聊天的分组导航和单独页面。可重复使用的提供者凭证位于其模型之上，具有发现和连接探针。模型编辑将保持暂存状态，直至应用。 OpenAI Codex 登录位于 Providers 下；运行时诊断位于运行时状态。

显示工作顺序的对话

流文本与该工具一起放置，称为它的介绍。一旦得到答案，锻炼就会折叠到可重新打开的活动标题中。问题卡仍然是交流的一部分，跳过的问题显示其跳过的状态。作曲家公开模式、代理、模型和资源，并单click 重用前一轮的资源。

掌握和复习改进

掌握程度评分现在将测验的准确性与概念和设计评估门区分开来，避免了永远无法实现目标的重复测验。研究地图会在回合结束时刷新，并且草稿会在开始回合之前绑定。 Mastery、Book 和 Reading 的 Focus-Check 尝试共享持续的复习记录；重试使用当前尝试的结果。合作伙伴记录的错误答案也会到达题库。

更可靠的数学渲染

数学标准化处理代码范围中嵌入的替代分隔符和公式，同时保留实际代码和普通货币金额。模棱两可的美元符号保持可见，而不是吞噬散文。

用法、语音和模型选择

应答页脚显示回合或会话令牌、缓存使用情况和持续时间。删除对话后，持久的每个帐户使用分类帐仍然可用，而不保留提示、响应或凭据。 Voice通过Volcengine添加豆包语音进行合成和转录。知识库可以绑定自己的嵌入模型，连接的代理支持远程 Hermes 网关。

可靠性修复

读取扩展使用自己的事件循环，并支持在可取消的超时后重试。空的 LlamaIndex 知识库接受其首次上传。 Telegram 线程路由在重新启动后仍然存在，嵌入请求遵循日期格式 Retry-After 标头，文档爬行遵循机器人规则和每个主机的节奏。聊天持续时间涵盖提交到完成，并且存储的会话模式可以在重新加载后继续存在。通过删除重复的英文翻译和延迟动画功能，初始 JavaScript 更小。

升级注意事项

运行pip install -U deeptutor； Docker用户拉动ghcr.io/hkuds/deeptutor:latest。

  • 查看删除行为。 删除将永久删除对话、其导师线程和相关附件。使用存档隐藏对话，同时保持其可恢复。在会话元数据升级期间，旧回收站对话将转换为存档对话；通过设置→存档聊天恢复它们。
  • 自定义工作区是可选的。 现有学习数据会保留其历史存储位置，直到您明确移动它。工作区元数据和旧存档状态记录会自动升级。设置、凭据和内存在帐户级别保持共享。
  • 学习 URL 已移动。 /books/…、/mastery/…、/reading/… 和 /watching/… 重定向到其 /learning/… 等效项。 /settings 仍然可用。
  • 迁移快照使用磁盘空间。 在移动数据之前阅读预览，为副本和恢复快照留出空间，并暂停对受影响目录的外部写入。现有目标数据或冲突的 ID 会阻止传输。
  • 已存档或不可用的工作区拒绝新写入。 在继续之前恢复或重新连接工作区。绑定工作区不可用的合作伙伴会报告错误，而不是默默地切换到其他地方。 完整 Changelog：https://github.com/HKUDS/DeepTutor/compare/v1.6.8…v1.6.9
