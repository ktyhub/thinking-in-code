DeepTutor v1.5.17

DeepTutor v1.5.17 Release Notes

发布日期： 2026.08.25 v1.5.16 连接了 MarginNote 库并解决了一系列网关故障。这改变了合作伙伴的归属：它们不再是只有管理员才能接触的部署范围资源，而是成为每个成员构建、拥有并与其进行私人对话的东西 - 管理员仍然通过赠款将其借出。围绕它的是一个知识库，可跟踪GitHub存储库、“我的代理”下的反重力CLI、在浏览器中绘制的微信二维码而不是日志文件，以及一个保存您声明的可选附加功能的容器。现有合作伙伴继续工作并自行迁移；一项行为更改仅限于非管理员用户，他们现在可以看到以前对他们关闭的合作伙伴页面。

新消息

合作伙伴属于人，而不属于部署

每一条 /api/v1/partners 路线过去都位于一个全面的管理门后面，因此成员可以与管理员分配给他们的合作伙伴交谈，而无需其他任何东西。现在嵌套了三个权限： 管理（其创建者，加上任何管理员）涵盖灵魂、通道、模型、资产、生命周期和删除； 使用 添加管理员分配给它的任何人，意味着进行对话；其他任何人都看不到该合作伙伴的存在——一个无主合作伙伴和一个不可见的合作伙伴的答案都是一样的，所以 id 无法被枚举。 对话是跟着人走的，而不是跟伙伴走的。与同一个同伴交谈的两个人永远不会看到彼此的线程，并且双方都会在自己的帐户下的网络应用程序中读回。赠款仍然存在并且形式没有变化，但它们现在只提供管理员管理的合作伙伴：某人为自己构建的合作伙伴可以共享也可以不共享，因为它的 SOUL.md 通常是个人编写的。

聊天账户可以携带您的 DeepTutor 身份

通过 QQ 或 Telegram 联系的合作伙伴过去只知道频道本地发件人 ID，因此每条入站消息都是匿名的 — 它落在共享线程池中，合作伙伴在管理工作区而不是发件人自己的库中进行答复。在网络应用程序中向您的合作伙伴索要代码，从您想要连接的聊天帐户向其发送 /link <code>，从那时起，发送者就是您：对话对您的帐户是私有的，可以在浏览器中读取，合作伙伴可以像在网络中那样读取您的知识、笔记本和记忆。

两个合作伙伴可以共享一个频道

通道运行时状态（机器人令牌、长轮询光标、对话引用、E2EE 设备存储）位于每个 通道 的一个目录中，而不是每个合作伙伴，因此配置在同一通道上的两个合作伙伴会读取彼此的凭据并覆盖彼此的光标。他们中只有一个人可以在线。状态现在位于 data/partners/<id>/channels/<channel>/ 下，并且当其所有者确定时，旧树会在第一次启动时复制 - 保存的令牌与一个合作伙伴的配置令牌相匹配，或者只有一个合作伙伴启用了该通道。真正的领带会重新验证一次，而不是被交给别人的帐户。

个人微信通过浏览器登录

二维码交换一直有效，但它仅从通道自己的 start() 运行，并在服务器的标准输出上绘制代码 - 在任何容器部署中，该标准输出都是配置合作伙伴的人员无法访问的主管日志（#951）。现在，针对 Web 应用程序运行相同的交换：在合作伙伴的频道页面上按 扫描连接，进行扫描，机器人令牌将写入频道配置服务器端。状态回复表明登录是否成功，而不是登录产生的结果。终端仍会打印代码作为后备。

知识库可以跟踪 GitHub 存储库

将存储库、分支和 glob 注册为 GitHub 源，其 Markdown 会被拉入知识库并根据需要重新同步，因此您遵循的文档保持最新状态，无需重新上传。贡献为 #903；下载目标包含在 KB 的 raw/ 目录内，因为 .. 段或树条目中的绝对路径否则会在基库之外写入（并且在删除分支上删除）。

反重力 CLI 加入我的特工

Google 于 6 月退役了 Gemini CLI，并将其用户引导至 Antigravity CLI，因此使用 Google AI Pro/Ultra 或 Gemini Code Assist 计划的任何人都会留下 gemini 后端，无法检测到 CLI (#828)。 agy 现在有自己的后端——连接它、中途查阅它、恢复它的对话。 Gemini CLI 后端保持不变：它仍然为持有 Gemini API 密钥的任何人运行，并且工作连接不得在升级时中断。

deeptutor doctor

一个命令回答“此工作区是否准备好启动会话？” — 设置、提供者、依赖项、端口。 --online 还向配置的模型提供者发送一个小请求； --format json 为脚本或代理打印相同的报告。贡献为 #959。

容器保存您声明的额外内容

容器是一次性的，因此 docker exec … pip install ".[partners]" 可以一直存活到下一个 compose down (#762)。相反，在部署中声明它们 - DEEPTUTOR_EXTRAS: "math-animator,partners" 和 DEEPTUTOR_APT_PACKAGES 用于系统库 - 并且从它启动的每个容器都会重新应用它们。热容器根据需求支付一次元数据查找费用，pip 缓存位于数据卷上，缺少轮子会导致该功能不可用，而不是导致部署停止。

嵌入在限速提供商中生存

针对低 RPM 提供商重新索引大型库通常需要花费数小时，然后在 429 上崩溃。三件事发生了变化：密钥池在 provider × model 上轮换，每个密钥都有冷却时间，因此一个受限制的密钥不再毒害运行；重试预算会等待 Retry-After，而不是在滑动窗口上耗尽自身；并且进程范围的节流阀在并发重新索引中序列化间隔加帖子，这就是导致手动成功的请求在应用程序内失败的原因。贡献为 #962。

窗口

MinerU 解析使用平台默认值（zh-CN 安装上的 GBK）解码其子进程输出，并在第一个非 ASCII 字节处终止；它的多线程 PDF 渲染器单独损坏了堆。两者均已修复，渲染防护的范围仅限于 Windows (#844)。原子写入现在从保存目标的防病毒软件或索引器重试瞬态 PermissionError，并且代码执行可以在 Windows 主机上运行 (#964)。

什锦

  • 推理工作是针对每个对话的。 现在可以针对单个聊天覆盖 v1.5.9 的模型级控制（#641，贡献为 #958）。
  • 索引失败是有界的而不是挂起。 接受嵌入请求但从未完成它的提供者会永远拖延执行器的未来；现在，在无进展的有界窗口后会引发心跳保护（#946）。
  • MinerU 页面布局块停止被索引为内容。 页眉、页脚和页码在摄取之前被过滤；无法识别的块类型会被索引，而不是使整个运行失败，因此添加一个的 MinerU 版本不会破坏索引（#949）。
  • 语音转录接受 Chrome 记录的内容。 audio/webm;codecs=opus 在线路边界处标准化一次，而不是作为未知格式被拒绝 (#945)。
  • 掌握测验卡不再位于首屏下方。 观看者在流后滚动窗口关闭后安装（#960），并且选项重复标签或答案的测验在注册时会被拒绝，而不是显示为无法回答的卡（#956）。
  • 学习路径保留其名称。 三个表面均从第一个模块派生，因此重建地图重命名路径，并且三个表面可能会不一致；现在有一个函数可以回答，而推导是后备，而不是记录。
  • 首先运行改变回合操作的工具。 在回合中切换掌握路径使其他调用绑定到回合开始时的状态；调度程序现在运行重新绑定工具，重新绑定其他所有内容，然后最后运行暂停工具。
  • 本地 LightRAG 答案引用其来源 (#754)，并且本地 LlamaIndex 管道不再在导入时冻结其进度条决策 (#864)。
  • Azure OpenAI 接受门户提供给您的端点。 经典的 …/openai/deployments/<name>/chat/completions URL 会简化为 /openai/v1 表面，因此在设置探测通过时聊天会停止回答 404 Resource not found。
  • Gemini 在模型支持的地方嵌入图像，对于不支持的图像则拒绝 contents，而不是发布端点将拒绝的部分 (#814)。
  • 页面可以询问是否安装了功能。 插件服务的功能（例如 Whisper 练习室）是由无法兑现它们的库存安装提供的，而轮到了 Unknown capability（[#963]（https://github.com/HKUDS/DeepTutor/issues/963））。
  • 独立的 CLI 包声明它实际导入的内容 (#954)。

升级注意事项

pip install -U deeptutor; Docker用户拉动ghcr.io/hkuds/deeptutor:latest。无需重新索引，也无需手动迁移。

  • 非管理员用户获得合作伙伴页面。 在多用户部署中，成员现在可以创建和管理自己的合作伙伴，并且他们与任何合作伙伴的对话对于他们的帐户来说都是私有的。现有合作伙伴没有 owner_id，因此被视为由管理员管理（正是它们的本来面目），因此您配置的任何内容都不会易手。
  • 每个伙伴的通道状态通过副本移动。 首次启动时，当其所有者明确时，data/partners/<channel>/ 下的状态将复制到 data/partners/<id>/channels/<channel>/。遗留树保持不变，因此可以手动恢复不良结果；所有权不明确的合作伙伴只需重新验证一次即可。
  • 现在仅列出管理员管理的合作伙伴。 成员为自己建立的合作伙伴不会出现在可分配池中。
  • 容器附加功能是可选的。 除非您在 Compose 文件中设置 DEEPTUTOR_EXTRAS，否则不会发生任何变化。使用 python scripts/install_extras.py --dry-run "<name>" 预览一张。
  • Gemini CLI 连接继续工作。 反重力是一个额外的后端，而不是替代品。 完整 Changelog：https://github.com/HKUDS/DeepTutor/compare/v1.5.16…v1.5.17
