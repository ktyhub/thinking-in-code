DeepTutor v1.1.2

DeepTutor v1.1.2 Release Notes

发布日期： 2026.04.18

亮点

带有令牌显示的模式驱动通道选项卡 (#338)

代理页面中的频道选项卡不再针对 Telegram 进行硬编码。现在，它可以自动发现每个频道（Telegram、Slack、Discord、Matrix、电子邮件、飞书等），并直接从每个频道的 Pydantic 配置模式呈现表单 - 不需要每个频道的前端代码。秘密字段（令牌、密码、API 密钥）呈现为带有眼睛切换的屏蔽输入，以便显式显示。当配置更改后实时侦听器无法重新启动时，last_reload_error 横幅会发出警告。

频道秘密屏蔽

API 响应不再暴露原始通道秘密。令牌和密码默认替换为***；管理编辑表单在需要时使用 ?include_secrets=true 获取纯文本。创建和更新响应同样被屏蔽。

通道配置验证和重新加载强化

PATCH /tutorbot/{bot_id} 现在预先验证通道有效负载并返回带有结构化错误的 422，而不是默默地保留错误的配置。 reload_channels 使用每个实例的锁进行序列化，以防止重复侦听器，并且任何失败都会记录在 last_reload_error 中，以便 UI 可以显示它。

RAG 简化为单个管道

删除了约 2,600 行未使用的 RAG 脚手架（分块器、嵌入器、索引器、解析器、检索器、管道编排器、类型定义），这些脚手架作为从未发布的后端的占位符而存在。 RAG 服务现在是单个 LlamaIndex 管道上的薄包装器。旧版 rag_provider 值（例如 lightrag）会默默地强制转换为 llamaindex，并且 KB 会被标记为重新索引。

集中式文件类型路由

将文件类型分类合并到单个 FileTypeRouter 模块和平面 API（get_document_type、classify_files、get_supported_extensions 等）中。旧的每个提供商的扩展助手已经消失了——只有一个提供商。未知的扩展在被拒绝之前仍然会受到内容嗅探的影响。

不再有幽灵知识库

关闭了所有可以针对不存在的 KB 静默调用 RAG 的代码路径：

  • deep_solve — 在未附加 KB 时剥离 rag 工具并警告用户。
  • deep_research — 从源中删除 kb，发出警告，如果没有剩余源则中止。
  • SolveToolRuntime — 返回一个优雅的“未选择 KB”观察结果，而不是崩溃，从而保持 ReAct 循环处于活动状态。
  • ResearchPipeline — 返回结构化的“跳过”事件，而不是回退到旧的 DE-all 占位符。
  • DecomposeAgent — 不再默认为 ai_textbook；当未提供 KB 时禁用 RAG。

外部化聊天提示

将所有硬编码的 zh/en 字符串从 AgenticChatPipeline 移至可编辑的 YAML 文件（每种语言为 agentic_chat.yaml）。现在无需更改代码即可配置阶段标签、系统提示、用户模板和 UI 通知。如果 YAML 丢失，则会优雅地退回。

泰语自述文件 (#337)

添加了带有泰语文档的 README_TH.md。

错误修复

  • 研究管道在没有 KB 的情况下崩溃 — DE-all 后备 KB 在大多数安装中不再存在；现在通过结构化跳过事件进行短路。
  • 分解代理尝试使用 RAG 对抗 ai_textbook — 用 None 和防守后卫替换硬编码的默认值。
  • 错误的通道配置默默地持续存在 — 现在在到达磁盘之前在 API 边界处以 422 被拒绝。
  • 并发 reload_channels 创建了重复的侦听器 — 通过异步锁序列化；失败会使机器人失去通道并出现明显错误，而不是半重建。
  • API 响应中泄露的通道令牌 — 现在默认在所有端点上屏蔽。

测试套件

添加了 6 个新测试模块（总共 1,042 行）：文件类型路由、KB 配置迁移、通道模式自省、通道秘密屏蔽、能力层的 RAG/KB 一致性以及研究管道 RAG 安全性。扩展了工具运行时、知识路由器、TutorBot 路由器和 RAG 管道模块的现有测试。
