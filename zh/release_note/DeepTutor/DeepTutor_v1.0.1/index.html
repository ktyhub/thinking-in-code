DeepTutor v1.0.1

DeepTutor v1.0.1 Release Notes

发布日期： 2026.04.10

亮点

使用 Chart.js/SVG 渲染管道可视化功能

添加了新的 Visualize 功能，可将自然语言数据描述转换为交互式 Chart.js 或内联 SVG 可视化。后端运行三阶段代理管道（分析→代码生成→审查），并支持双语提示（en/zh）。前端提供了两个新组件 - 用于请求配置的 VisualizeConfigPanel 和用于渲染的 VisualizationViewer - 连接到工作区主页和聊天编辑器。

聊天编辑器中的显式参考选择器

在聊天编辑器工具栏中添加了一个明确的“参考”下拉按钮，位于现有的“工具”下拉列表旁边。用户现在可以直接 click @ 参考按钮来附加笔记本记录或聊天历史记录会话作为上下文 - 无需在输入字段中发现隐藏的 @ 触发器。下拉列表显示每个类别的选择计数和总徽章，一目了然地了解附加了多少上下文。原来的 @ 键盘快捷键仍然可以作为高级用户的替代方案。

测验重复预防和生成历史

通过生成器管道引入专用的 previous_questions 参数，与会话 history_context 完全分离，修复了重复的测验问题。 MAX_PREVIOUS_QUESTIONS=20 上限限制了提示大小，并且语言标签被移至 YAML 模板中以避免跨区域设置的语言混合。

o4-mini 和未来的 o 系列型号支持

扩展了 LLM 配置中的 o 系列正则表达式，以识别 o4-mini 和未来的 o 系列型号标识符，确保正确设置 max_completion_tokens，而不是不支持的 max_tokens 参数（关闭 #274）。

服务器日志记录改进

  • 抑制嘈杂的 uvicorn WebSocket 连接/断开日志，这些日志会扰乱服务器输出。
  • 添加了选择性 HTTP 访问日志记录中间件，仅记录非 200 响应，减少日志噪音，同时保留可操作的错误可见性。
  • 为不支持结构化输出的提供者添加了 MiniMax 模型覆盖 (supports_response_format: false)。
