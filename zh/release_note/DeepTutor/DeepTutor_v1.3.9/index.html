DeepTutor v1.3.9

DeepTutor v1.3.9 Release Notes

发布日期： 2026.05.09 v1.3.9 建立在 v1.3.8 多用户基础上，具有更广泛的 TutorBot 部署选项、思维模型的更安全的提供商路由以及更顺畅的 网络入门路径。它添加了 Zulip 和 NVIDIA NIM 支持，改进了启动 人体工程学，并折叠了上一个版本后报告的主要问题修复。

亮点

TutorBot 渠道和提供商扩展

  • Zulip 现在是 TutorBot 频道 - 机器人可以收听私人消息并 流主题，强制执行 allow_from，选择仅提及或开放流 回复，并将 Zulip 的事件队列桥接至异步 TutorBot 总线。
  • 数学和文件在 Zulip 中工作得更好 - LaTeX 已转换为 Zulip 友好型 KaTeX 标记、上传/下载调用使用可配置的重试行为，以及 附件文件名包括上传路径摘要以避免冲突。
  • Zulip 主题将对话分开 - 流主题现在成为一部分 聊天/会话密钥，对于空主题有稳定的 (no topic) 后备。
  • TutorBot 支持 NVIDIA NIM - nvidia_nim 在 TutorBot 中可用 提供程序配置和注册表检测，包括 NIM 的流行为 省略了不受支持的 stream_options。

模型和运行时可靠性

  • 配置的上下文窗口受到尊重 - 安全上限提高到 1,000,000 个代币，而大型模型后备仍为 65,536 个，如此明确 128K 风格的模型设置不再被默默地钳制。
  • Qwen 视觉检测已修复 - Qwen VL 模型被视为 跨 DashScope、OpenAI 兼容和自定义绑定的视觉功能。
  • 最小思维模式是提供商安全的 - DeepSeek、DashScope、VolcEngine、 BytePlus 和 MiniMax 不再收到拒绝的顶级 reasoning_effort=minimal; DeepTutor 发送特定于提供商的禁用 信号代替。
  • 跟踪 DeepSeek v4 成本 - 研究代币会计包括 deepseek-v4-flash 和 deepseek-v4-pro 定价条目。

网页和 CLI 波兰语

  • deeptutor start 推出完整的网络堆栈 - CLI 现在委托给 scripts/start_web.py 所以后端和前端可以从一个启动 命令和启动器故障通过 CLI 退出代码传播。
  • 侧边栏入门更加清晰 - 主要导航图标现在公开 带有描述和键盘焦点支持的范围化、本地化的工具提示。
  • 多行用户消息保持可读 - 聊天消息渲染保留 Shift+Enter 换行符，修复代码块和结构化提示 先前折叠成一行。
  • 分配的资源更容易理解 - 模型选择摘要 和只读知识库操作现在为以下内容提供更清晰的标签 非管理、授权范围的会话。

多用户和会话存储奇偶校验

  • 分配的模型选项与选择器合同相匹配 - 非管理员 LLM 选择 现在返回配置文件名称、模型名称、标签和活动/默认元数据 与网络模型选择器期望的形状相同。
  • PocketBase 会话支持更多聊天流 - 消息元数据可以 持久化，可以查找最后一条消息，并且可以使用消息删除 PocketBase 字符串 ID 以及 SQLite 整数 ID。
  • 重新生成保持存储中立 - 转动重试逻辑可以删除最后一个 助理消息，无需假设支持会话存储使用整数 主键。

测试

  • 添加了用于配置解析、权限检查、重复的 Zulip 通道覆盖 过滤、提及、流主题范围、附件提取、重试 行为、LaTeX 转换、输入状态、发送、上传和启动 失败。
  • 添加了用于注册表检测、模式的 TutorBot NVIDIA NIM 提供程序测试 接受和流请求兼容性。
  • 添加了针对 Qwen 视觉能力、显式上下文窗口的 LLM 回归测试 预算和最低限度思维的提供商 kwargs。
  • 添加了 CLI 覆盖范围，以便 deeptutor start 传播启动器退出代码。
  • 添加了 DeepSeek v4 模型条目的研究代币定价覆盖范围。

升级注意事项

  • 安装或刷新 .[tutorbot] extra 或 requirements/tutorbot.txt，以 在启用 Zulip 机器人之前包含新的 zulip>=0.8.0,<1.0.0 依赖项。
  • 使用 site、email、apiKey、allowFrom 和 allowFrom 配置 Zulip 机器人 groupPolicy；使用 mention 进行更安全的流部署，仅使用 open 每条流消息何时到达机器人。
  • 如果您将 LLM_REASONING_EFFORT=minimal 与 DeepSeek、DashScope 一起使用， VolcEngine、BytePlus 或 MiniMax，保持设置不变； v1.3.9 翻译一下 到正确的提供商特定的禁用有效负载。
  • 现在可以采用大型配置的上下文窗口，而不是限制为 65,536 个代币，因此请验证提供商限制和预期的提示成本行为。
  • 可选的 PocketBase 部署应确保 messages 系列具有 依赖重新生成/会话元数据之前的 metadata_json JSON 字段 平价。
