DeepTutor v1.6.8

DeepTutor v1.6.8 Release Notes

发布日期： 2026.09.14 v1.6.8 收到了 22 个社区拉取请求以及它们背后的一系列报告。 v1.6.7 追求的是在隐藏思维上花费的象征性预算，而这个主要回答了不同的抱怨：*我做了一件事，应用程序却什么也没做。*删除的聊天无法返回，打开图书馆而不是书籍的书籍链接，模型从未提及的附件，后端在启动时被杀死。三个新界面同时出现——回收站、历史搜索和查看您自己的知识库的工具。直接插入——无需迁移。

新消息

删除的聊天记录是可以恢复的

删除对话曾经是最终决定。现在，它将聊天内容移至回收站（侧边栏中的可折叠部分），您可以在其中恢复或永久删除它。附件、掌握状态和聊天的其余工件会在旅途中幸存下来并随之返回，并且只有显式清除才会从磁盘中删除任何内容。

搜索您的整个对话历史记录

历史记录选择器现在搜索消息文本，而不仅仅是标题。匹配结果会附带有关热门话题的简短摘录，以便您可以在打开之前区分两个相似的对话。字面量，不区分大小写，并且对查询和摘录都有限制。

超越您知识库的工具

knowledge_frontier 阅读知识库并寻找其中“不”的内容 - 最近关于同一主题的工作，作为起点而不是答案出现。当回合有 KB 时，它会自动安装在 rag 和 kb_files 旁边：

deeptutor run chat "Find recent work beyond this material" --kb textbook --tool knowledge_frontier

停止思考的推理模型现在这么说

这一轮将其全部预算都花在了隐藏的推理上，并且没有返回任何结果，从而以不透明的失败结束了这一轮。该场景的两个读数现在连续运行：明显达到上限的回合失败，并通过证明它的计数器（回合、推理字符、完成标记）失败，因为这是您可以采取行动的配置。任何其他没有回答的推理都会结束回合，说明它是哪种空。重播的回合保留了发送它的提供者的推理，并且领先的 <think> 块不再吞噬其后的 JSON。

阅读和书籍会在您指向的位置打开

一个有深度的图书网址打开图书馆，让你自己去找书；一旦材料是文档而不是媒体，大纲就会停止跟踪您实际所在的页面；在加载开始之前的节拍期间呈现“无法打开”的阅读材料。这三个都已固定。 macOS 重新压缩的 EPUB 也是如此——Finder 的存档将书包装在一个目录中，过去 DeepTutor 将 __MACOSX/._* 条目视为章节。

模型实际可以看到的附件

先前轮次的图像会重新发送，因此有关图片的后续问题仍然包含图片，上限现在是一个设置而不是常量。文本提取没有产生任何结果的文件（通常是扫描的 PDF）会列出原因，而不是默默地跳过，因此模型可以命名该文件并说明为什么它不能引用它，而不是要求您再次上传它。

设置、启动以及悄然失败的事情

无论如何，应用未更改任何内容的设置会重置每个运行时 client；现在由一个地方决定，而不是五个呼叫站点各自以自己的方式决定。启动器不再杀死仅仅仍在启动的后端。从事件循环中注销的检索进度会到达您而不是消失。当消耗功能的回合停止时，功能将被取消，GraphRAG 工作人员在启动之前修复陈旧的 Arrow 注册，并且在反向代理后面，访问日志记录真正的 client 而不是代理。

值得命名的较小修复

ask_user 卡会删除一个选项，该选项的可见文本与另一个选项重复。没有模板的测验计划会失败，而不是默默地产生任何结果。显式的 retryable: false 会受到状态代码的尊重，而不是被覆盖。 read_skill 正确恢复丢失的文件。死角所举行的会议自行清除。推理探索预算不再像以前那样异常，每个 LLM 预算现在都位于 agents.yaml 中，每个阶段一个条目。

升级注意事项

运行pip install -U deeptutor； Docker用户拉动ghcr.io/hkuds/deeptutor:latest。没有什么需要迁移。

  • 删除聊天现在是可逆的，这改变了“删除”的含义。 删除软删除；该行将一直保留，直到您将其从回收站中清除为止。删除阅读材料仍然会像以前一样删除其会话。
  • agents.yaml 拥有所有法学硕士预算。 阶段级别的 max_tokens 条目移至此处，每个阶段一个。您已经设置的值仍然会被读取；原本没有入口的关卡现在有了入口。
  • 先前图像重新注入上限是可配置的。 它是硬编码的 4。它现在位于系统设置中，0 关闭了该功能。 完整 Changelog：https://github.com/HKUDS/DeepTutor/compare/v1.6.7…v1.6.8
