DeepTutor v1.5.9

DeepTutor v1.5.9 Release Notes

发布日期： 2026.08.04 v1.5.8 是关于内存的，而这个是关于提供者的——Gemini 的原生 Embedding 2 端点、每个模型的推理工作控制、Novita AI 网关——以及它们下面悄悄错误的路径：像文档一样嵌入的查询、none 打开思考、以空白消息形式到达的功能崩溃。适用于大多数安装，但 docker-compose.ghcr.yml 用户可以在下一个 up 之前运行一次性数据迁移。

新消息

Gemini Embedding 2 优于原生 API

Gemini 嵌入配置文件现在默认为 Google 的本机 …/models/<model>:batchEmbedContents 端点和 gemini-embedding-2，通过 x-goog-api-key 进行身份验证，并且端点遵循您选择的模型 - 包括通过网关前缀。现有的 gemini-embedding-001 配置文件故意保留在 OpenAI 兼容路径上：本机路由发送 taskType 并对返回的内容进行 L2 标准化，因此移动它们会更改其文档向量并默默地使从它们构建的索引失效。将 base_url 指向本机 URL 即可选择任何模型。

查询停止作为文档嵌入

检索嵌入现在发挥了作用。 LlamaIndex 标记查询 search_query 和段落 search_document，LightRAG 以相同的方式映射其自己的上下文提示，并且适配器显式选择加入 (SUPPORTS_INPUT_TYPE)，因此从未发送角色的后端始终不发送角色。只有 Cohere（需要该字段并且已经默认为 search_document）今天发生了变化：文档向量保持不变，查询最终获得了正确的角色。没有重新索引。

每个模型一个推理努力选择器

目录中的每个 LLM 模型在其上下文窗口旁边都有一个可选的默认推理深度，仅在提供者实际支持的情况下提供，并以该提供者自己的词汇表进行标记（OpenAI 风格系列的最小/低/中/高/xhigh，自适应，这是唯一的开启模式，其余的简单开/关）。 提供商默认值（自动） 将选择权留给提供商。连接过程中出现了两个人择错误：none 正在以 4096 代币预算“开启”思维，而发送给老年家庭的存储 adaptive 则提取 400 代币预算，而不是默认预算。

Novita AI 和 MiniMax 在正确的平台上

Novita AI 加入 LLM 网关（novita、https://api.novita.ai/openai）。 MiniMax 运行两个独立的平台，其密钥不可互换，并且默认值现在指向全球平台 (api.minimax.io)，而不是中国大陆平台；记录 minimax-m3 和 minimax-m2.7 上下文窗口，检测还会读取 context_size 字段。

Compose 部署保留所有 data/

docker-compose.ghcr.yml 仅绑定安装 data/user、data/memory 和 data/knowledge_bases，因此 data/system（JWT 签名秘密、帐户、拨款、每个所有者 Codex 令牌）、data/users、data/partners 和 data/cli-apps 位于容器的可写层中，并在每次重新创建时被丢弃。现在它会挂载整个树，与其他 Compose 文件相匹配。命名卷和源构建部署从未受到影响。

在本地容器内进行 Codex 登录

默认本地 Docker 和 Podman 部署将浏览器和服务器置于单独的环回网络上，因此 OAuth 回调永远不会到达。现在有一个临时的 compose.codex-oauth.yaml 覆盖（以及等效的 docker/podman 命令），仅在您登录时发布端口 1455/1457 - 通过拆卸，因此这些端口会返回到您的其他 Codex clients。请参阅 CONTAINERIZATION.md。

过去毫无意义的失败

提出的功能或对不存在的功能的请求在没有判决的情况下结束了流，并且回合以 completed 持续存在，答案为空。该错误现在被标记为终止并通过 DONE 事件进行，因此该回合及其消息存储为 failed，并且 UI 显示出了什么问题而不是空气泡。

什锦

  • 首次加载时将采用您保存的界面语言。它位于后端的 ui 设置中，只有“设置”路由会读取该设置，因此所有其他页面都以英语开头，直到您在该浏览器中重新选择它为止。本地选择仍然获胜。
  • 当分析模型在枚举之外创建 render_type 或 visual_genre 时，Visualize 不再中止 - 枚举外值被删除，字段回退到其默认值。
  • 类似凭证的查询参数（key、api_key、token、access_token）在向导、client 和错误消息打印的每个端点中进行编辑。

升级注意事项

pip install -U deeptutor； Docker用户拉动ghcr.io/hkuds/deeptutor:latest。没有架构更改，也没有任何需要重新索引的内容。

  • docker-compose.ghcr.yml 用户：在下一个 up -d 之前复制您的状态。 新的整树挂载意味着空主机目录将隐藏容器可写层中的内容，重新生成身份验证密钥（将所有人注销）并从没有非管理员帐户开始。一个 docker cp 循环位于 CONTAINERIZATION.md → 一次性迁移 中。
  • 中国大陆平台上的 MiniMax： 默认基本 URL 现在是全球端点。将 base_url 设置为 https://api.minimaxi.com/v1（或 https://api.minimaxi.com/anthropic）并使用中国平台密钥 - 密钥是每个平台颁发的。保存的配置文件保留他们已有的任何 URL。
  • Gemini 嵌入： 现有的 gemini-embedding-001 配置文件故意保留在原来的位置。新配置文件和 gemini-embedding-2 使用本机端点。 完整 Changelog：https://github.com/HKUDS/DeepTutor/compare/v1.5.8…v1.5.9
