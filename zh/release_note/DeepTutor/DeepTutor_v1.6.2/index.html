DeepTutor v1.6.2

DeepTutor v1.6.2 Release Notes

发布日期： 2026.08.31 v1.6.2 添加了沉浸式 YouTube 学习和插件驱动的可视化目录，然后增强了阅读、知识、合作伙伴、更新和我的代理。已退役的 Playground API 和 Gemini CLI 连接是唯一的兼容性更改。

新消息

在同步视频旁边学习

粘贴 YouTube URL 以在导师旁边打开隐私增强型播放，将成绩单证据与时间戳绑定，解释当前提示，并在稍后恢复进度。管理员可以选择自托管的 Invidious 源，无需重建材料；本机播放无需可选的公共字幕适配器。

通过可扩展目录进行可视化和咨询

Visualize 现在使用共享代理循环和已安装的 SVG、Mermaid、Chart.js、交互式 HTML、Manim 和可选 GeoGebra 的可视化工具目录。声明性浏览器专用可视化工具 ZIP 在沙盒 iframe 中运行。我的代理添加了 Hermes Agent、OpenClaw 和 DeepSeek Harness 以及六种现有的本地安全带。

更严格的主页、阅读和更新路径

Home 统一了普通、阅读、掌握和观看工作空间中的聊天行为。 Web 源成为安全版本快照，仅在针对轮次材料进行验证时才读取引文链接，LaTeX 选择保持接地，并且“设置”→“关于”可以检查、分类和安全应用合格的 PyPI 更新。

更清晰的知识和合作伙伴运营

除了 PDF 之外，MinerU 现在还接受常见的光栅图像以及 DOCX、PPTX 和 XLSX。知识中心通过准备预检将库与本地、服务器、云和外部引擎分开。合作伙伴渠道卡报告实时连接/设置状态，包括浏览器二维码登录，而不是将例行诊断发送到日志。

升级注意事项

运行pip install -U deeptutor； Docker用户拉动ghcr.io/hkuds/deeptutor:latest。现有数据、知识索引、视频进度、阅读快照无需迁移。

  • 公共字幕辅导是可选的。 安装 pip install -U 'deeptutor[video-learning]' 以启用基于文字记录的视频解释。没有它，YouTube/Invidious 播放仍然可以工作。
  • **Gemini CLI 已作为“我的代理”安全带退役。**现有的 gemini 设置保持不变，但不再注册；旧设置路线重定向到反重力。请连接 Antigravity、Hermes Agent、OpenClaw 或 DeepSeek Harness。
  • Web Playground 和 /api/v1/plugins/* 测试器 API 已删除。 deeptutor plugin list/info 仍然检查运行时工具和功能。浏览器可视化工具现在使用 /api/v1/visualizers 和声明性可视化工具包。
  • 英文和中文指南已在deeptutor.info上一起更新。 完整 Changelog：https://github.com/HKUDS/DeepTutor/compare/v1.6.1…v1.6.2
