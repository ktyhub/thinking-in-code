DeepTutor v1.3.2

DeepTutor v1.3.2 Release Notes

发布日期： 2026.04.29 v1.3.2是继v1.3.1之后的重点稳定版本。它加强了嵌入 端点合约，使 LlamaIndex RAG 更干净地从陈旧或 无效索引，并防止推理模型暂存器输出泄漏 进入长期记忆。

亮点

透明嵌入端点 URL

嵌入配置现在明确说明 DeepTutor 将调用的确切 URL。 这消除了隐藏的“基本 URL 与端点 URL”的歧义，该歧义可能会导致 成功的设置测试的行为与知识库重新索引不同。

  • 设置现在显示嵌入的端点 URL - Web 设置页面 将嵌入 URL 标记为端点 URL 并解释 DeepTutor 发布到 准确可见的 URL，无需在以下位置附加 /embeddings 或 /api/embed 请求时间。
  • 提供商默认为完整端点 - OpenAI、OpenRouter、Jina、vLLM/LM Studio、SiliconFlow默认为/embeddings；奥拉马默认为 /api/embed； Cohere默认为/embed； DashScope 保持其原生特性 多模态嵌入端点。
  • 旧版基本 URL 可以安全迁移 - 使用保存的嵌入配置文件 旧式底座如https://api.openai.com/v1， https://openrouter.ai/api/v1 或 http://localhost:11434 标准化为 完整的端点形式并保留回模型目录。定制 OpenAI 兼容的 URL 保持不变。
  • 配置错误的端点会提前失败 - 嵌入 client 现在会拒绝 已知提供商 URL 指向根/基本路径而不是真实路径 嵌入端点，在索引开始之前带有可操作的消息。
  • OpenRouter 嵌入使用精确 URL HTTP - 公共嵌入提供商 否 通过 OpenAI SDK 的隐藏路径附加行为实现更长的路线。 custom_openai_sdk 仍然可用于旧配置，但被隐藏 设置提供商下拉列表。
  • 连接测试诊断与运行时行为相匹配 - 现在嵌入测试 报告“完全按照设置中显示的方式发布”，与适配器行为相匹配 由 RAG 索引和检索使用。

RAG 重新索引和检索弹性

LlamaIndex 管道现在更积极地刷新嵌入状态 将无效的持久向量转换为清晰的重新索引指导而不是原始向量 Python 或 NumPy 错误。

  • 缓存管道拾取设置更改 - 初始化、搜索和 增量添加路径在使用前重新配置 LlamaIndex，因此寿命较长 管道不会保留嵌入模型、维度或端点设置 较旧的设置会话。
  • 配置更改时嵌入 clients 刷新 - 共享嵌入 当解析的运行时配置更改时，会重新创建 client，并且 LlamaIndex CustomEmbedding 适配器之前对活动配置进行指纹识别 重用缓存的 client。
  • 在检索之前验证持久索引向量 - LlamaIndex 存储现在检查保存的向量存储是否为空、非数字、非有限、 在运行相似性搜索之前丢失或不一致的向量。
  • 无效索引返回重新索引提示 - 已知故障，例如 unsupported operand type(s) for *: 'NoneType' and 'float'，矢量形状 不匹配，并且新检测到的无效持久向量现在返回 needs_reindex: true 带有面向用户的解释。
  • 嵌入连接检查使用相同的验证路径 - 索引前冒烟测试使用同一批验证器验证提供商的输出 在索引和检索期间使用。
  • 当修复已知时，RAG 错误日志会更安静 - 分类为无效 嵌入/索引失败被记录为可操作的警告，而不是噪音 完整的追溯。

思维模型的内存清理

内存刷新现在会在私有推理块成为之前将其剥离 持久的用户记忆。

  • 在写入之前删除思考标签 - 配置文件和摘要重写运行 通过代码围栏清理后的共享 clean_thinking_tags() 帮助程序，所以 推理模型中的 <think> / <thinking> 块不会保存到 PROFILE.md 或 SUMMARY.md。
  • 现有内存文件在读取时自我修复 - 如果较旧的内存文件 已包含封闭或未封闭的思维标签，读取快照清除 内容并在可能的情况下将修复的版本写回磁盘。
  • 手动内存编辑使用相同的清理 - 直接内存写入也可以通过 通过清理器，保持 UI 编辑、刷新和运行时读取保持一致。

设置和运行时优化

  • 嵌入提供商的选择不再那么混乱 - 设置不再提供 公共下拉列表中的旧版 custom_openai_sdk 提供商，而现有的 保存的配置文件继续解析以实现向后兼容性。
  • 模型目录标准化保持 - 目录加载现在保存 规范化更改活动配置文件/模型 ID 或嵌入端点 URL， 防止每次启动时重复相同的迁移。
  • 与 OpenAI 兼容的嵌入错误更清晰 - 非 JSON 或 HTML 嵌入响应现在指向错误的端点/模型配对，而无需 错误地仅建议一种特定于网关的原因。
  • Deep Solve ReAct 调用再次对齐 - 求解器循环不再 将过时的 attachments 关键字传递到 SolverAgent.process() 中，避免 运行时 TypeError，同时在计划器上保留附件转发，并且 在支持的地方重新规划呼叫。

测试

  • 添加了 OpenAI、OpenRouter、Ollama 和自定义的端点迁移覆盖范围 嵌入配置文件。
  • 添加了设置 API 覆盖完整端点提供商选择和隐藏 custom_openai_sdk。
  • 添加了用于端点验证的嵌入 client 覆盖范围、OpenRouter 的原始 HTTP 适配器路径、client 配置更改刷新以及精确的 URL 透明度。
  • 添加了针对陈旧嵌入的 LlamaIndex 覆盖 - client 刷新，重复 设置重新配置、无效持久向量检测和重新索引 无效索引的提示。
  • 增加了封闭和未封闭思维标签的内存覆盖，以及修复 读取期间现有的内存文件。
  • 进行有针对性的 Deep Solve/RAG 功能测试，涵盖解算器运行时接线 在过时的 attachments 参数修复之后。

升级注意事项

  • 设置中嵌入的 URL 现在应该是完整的端点 URL。现有已知的 提供商配置文件会自动迁移，但自定义网关应该 如果他们使用非标准路径，请手动审核。
  • 如果知识库搜索仍然报告无效的嵌入向量，请重新索引 确认活动嵌入提供商、型号、尺寸后受影响的 KB， 和端点 URL。
  • 包含旧 <think> 块的内存文件将在下次运行时被清除 内存页或内存服务读取它们；这个读取可以更新底层 PROFILE.md 或 SUMMARY.md 文件以保留已清理的版本。 完整 Changelog：https://github.com/HKUDS/DeepTutor/compare/v1.3.1…v1.3.2
