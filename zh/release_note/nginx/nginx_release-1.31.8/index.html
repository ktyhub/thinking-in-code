nginx release-1.31.8

nginx-1.31.8主线版本已发布。

请参阅 nginx.org 上的官方 CHANGES。

以下是 GitHub 生成的版本摘要。

发生了什么变化

  • https://github.com/nginx/nginx/pull/1846 中 @pluknet 的版本提升
  • HTTP/3：通过 https://github.com/nginx/nginx/pull/1701 中的 @dgprivate 避免使用空编码器字段值的未定义行为
  • Win32：通过@VadimZhestikov在https://github.com/nginx/nginx/pull/1823中删除了iocp事件模块
  • 控制：记录来自接受的套接字设置的错误。作者：@OskarEichler，https://github.com/nginx/nginx/pull/1720
  • Dav：在 https://github.com/nginx/nginx/pull/1778 中 @VadimZhestikov 恢复了目标映射错误的请求 URI
  • SSL：https://github.com/nginx/nginx/pull/1788 中的 @VadimZhestikov 在使用内核 TLS 关闭后忽略 EIO
  • SSL：@VadimZhestikov 在 https://github.com/nginx/nginx/pull/1599 中针对 i2d_SSL_SESSION() 负值的解决方法
  • 控制API：在https://github.com/nginx/nginx/pull/1819中使用@bavshin-f5更便携的ioctl(FIOASYNC)
  • 修复了 https://github.com/nginx/nginx/pull/1814 中 @nishat-06 在 32 位平台上对大整数的优先级解析
  • JSON：解析器API重构。通过 @ensh63 在 https://github.com/nginx/nginx/pull/1806
  • 修复了 @osokin 在 https://github.com/nginx/nginx/pull/1857 中的拼写错误
  • GH：@saikrishnakumarreddy 在 https://github.com/nginx/nginx/pull/1815 中生成 Windows zip 的工作流程
  • GH：通过 https://github.com/nginx/nginx/pull/1804 中的 @thresheek 请求 id 令牌并将机密传递给 buildbot.yml 中的被调用者
  • 其他：通过 @pluknet 在 https://github.com/nginx/nginx/pull/1859 中使用 GNU sed 修复了“zip”目标
  • HTTP/3：避免 https://github.com/nginx/nginx/pull/1317 中 @daewoo1109 的 Huffman 编码中的未对齐存储
  • @pluknet 在 https://github.com/nginx/nginx/pull/1855 中修复了工作目录
  • nginx-1.31.8-RELEASE 由 @pluknet 在 https://github.com/nginx/nginx/pull/1886 中

新贡献者

  • @dgprivate 在 https://github.com/nginx/nginx/pull/1701 中做出了第一个贡献
  • @OskarEichler 在 https://github.com/nginx/nginx/pull/1720 中做出了第一个贡献
  • @ensh63 在 https://github.com/nginx/nginx/pull/1806 中做出了第一个贡献
  • @osokin 在 https://github.com/nginx/nginx/pull/1857 中做出了第一个贡献
  • @daewoo1109 在 https://github.com/nginx/nginx/pull/1317 中做出了第一个贡献
