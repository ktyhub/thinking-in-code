playwright-mcp v0.0.84

playwright-mcp v0.0.84

✨ 亮点

  • 👥 在一个浏览器中单独进行会话 — 使用多个帐户，无需共享其 cookie 或存储空间。 browser_tabs 和 action: "new" 现在接受 isolatedContext: "<name>"：具有相同名称的选项卡共享上下文，而不同名称保持隔离。忽略它或使用 "default" 作为默认上下文。 Cookie 和存储工具在当前选项卡的上下文中运行。 (微软/playwright#43087)
  • 🙈 编辑 URL 中的运行时值 (#1791) — 在运行时创建的会话和授权值无法提前在机密文件中列出。 --redact-url-params=access_token,code（config redactUrlParams、env PLAYWRIGHT_MCP_REDACT_URL_PARAMS）将工具响应中的命名查询和片段参数值替换为 <redacted>。与 secrets 一样，这是一种便利功能，而不是安全功能。该扩展程序还会在读取连接页面 URL 后将其连接令牌删除。 (微软/playwright#43258)
  • 🔎 绑定查找结果 (microsoft/playwright#42077) — 常见搜索词不再需要在每个匹配项中填写响应。 browser_find 接受正整数 maxResults，返回第一个匹配项及其上下文，并报告总匹配计数。省略它以继续返回所有匹配项；祖先路径不变。 (微软/playwright#42947)
  • 🌐 检查导航中的请求 (microsoft/playwright-cli#479) — 一旦流导航，来自上一页的请求就不再丢失。 browser_network_requests 接受 all: true 以包含保留的历史记录，最多保留来自早期导航的 200 个请求。 browser_network_request 的请求索引在整个导航中保持稳定。 browser_console_messages 还报告与其现有 all 选项一致的计数。 (微软/playwright#43526)
  • 🎯 使用您的语言中的定位器 (#1797) — browser_click 等元素工具现在接受 JavaScript、Python、target 中的 Java 和 C# 定位器，以及快照引用和 CSS 选择器。无效的目标会出现可操作的错误，包括提醒传递裸参考而不是 button [ref=e5]。 (微软/playwright#43539)
  • 📂 跳过不受支持的工作区根请求 (#1798) — 通告根但无法应答 roots/list 的 client 可以阻止第一个工具调用。传递 --ignore-roots (config ignoreRoots: true, env PLAYWRIGHT_MCP_IGNORE_ROOTS=true) 以跳过该请求并使用服务器的当前工作目录作为工作空间根目录。 (微软/playwright#43532)
  • 🍪 按域和路径删除 cookie — 按名称删除 cookie 不再需要删除具有该名称的每个 cookie。 browser_cookie_delete（通过 --caps=storage 选择加入）接受可选的 domain 和 path 过滤器，以保持其他域和路径不变。 (microsoft/playwright#43319)

🐛 修复

  • fix(mcp): allow combining time, text and textGone in browser_wait_for — 与文本条件结合使用时，time 是其超时（上限为 30 秒），而不是检查之前的延迟。现在，同时提供 text 和 textGone 会等待第一个条件发生，而不是同时提供两个条件。 (microsoft/playwright#43011)
  • fix(mcp): allow loopback hosts by default for all bind addresses — HTTP client 可以通过 localhost、127.0.0.1 或 [::1] 连接，无论绑定地址如何。其他主机仍需要--allowed-hosts；绑定到 0.0.0.0 会打印可用的本地主机 URL。 (微软/playwright#42993)
  • fix(mcp): pass credentials from --proxy-server as proxy username/password — 代理 URL 中嵌入的凭据现在作为代理身份验证设置传递到浏览器。 (微软/playwright#43071)
  • fix(mcp): race browser_navigate_back against modal states — browser_navigate_back 报告历史导航期间打开的对话框而不是超时。 (微软/playwright#43252)
  • fix(mcp): normalize bare host URLs and loopback IP addresses — browser_navigate 处理带端口的无方案主机，并将 HTTP 用于环回地址，例如 127.0.0.1:3000 和 [::1]:3000。 (微软/playwright#43264)
  • fix(mcp): do not close the browser twice when the client disconnects — stdio 断开连接让浏览器正常关闭，而不是通过第二次关闭请求强制终止它。当其父进程消失时，仪表板注释进程也会退出。 (微软/playwright#43174)
  • fix(mcp): give each isolated client its own idle timer — 使用 HTTP 传输和 --isolated，即使另一个 client 使共享浏览器保持忙碌，空闲的 client 上下文现在也会过期。 (微软/playwright#43527)
