firecrawl v2.9.0

小版本 发布时间2026年4月10日 来源firecrawl/firecrawl 英文原文

firecrawl v2.9.0

改进

  • 通过 /interact 端点进行浏览器交互 — 抓取页面，然后调用 /interact 对其执行操作 — click 按钮、填写表单、更深层次导航或提取动态内容。通过 prompt 用自然语言描述您想要的内容，或编写 Playwright 代码（Node.js、Python）和 Bash (agent-browser) 进行完全控制。会话在呼叫之间持续存在，并具有用于实时浏览器流的实时视图和交互式实时视图 URL。持久配置文件使您可以跨抓取保存和重用浏览器状态（cookie、localStorage）。提供 JS、Python、Java 和 Rust SDK。
  • query 格式 — 向 /scrape 端点添加了 query 格式 — 传递自然语言提示并在 data.answer 中获得直接答案。
  • audio 格式 — 添加了 audio 格式选项来抓取响应，将音频输出作为文档上的字段返回。
  • onlyCleanContent 参数 — 向 /scrape 端点添加了 onlyCleanContent 参数，该参数从 Markdown 输出中去除导航、广告、Cookie 横幅和其他非语义内容。
  • PDF 解析模式 — 添加了 PDF 解析模式（fast、auto、ocr）和 maxPages 选项来控制提取深度和 OCR 行为。
  • Java 和 Elixir SDKs — 添加了官方 Java 和 Elixir SDKs，并提供完整的 v2 API 支持。
  • 旧版 .doc 文件支持 — 添加了对解析旧版 .doc 文件的支持。
  • 维基媒体引擎 — 为 scraping 维基百科和维基媒体页面添加了专用引擎，并提高了输出质量。
  • 抓取响应中的 contentType — 添加了 contentType 以抓取 PDF 和文档的响应。
  • PDF 管道改进 — 改进了 PDF 管道，具有更好的表格检测、页眉/页脚剥离、混合 PDF 处理、内联图像解析和魔术字节检测。
  • 品牌提取 — 改进了品牌提取以跳过隐藏的 DOM 元素以获得更清晰的输出。
  • HTML 到 Markdown 性能 — 改进了 HTML 到 Markdown 转换性能并修复了转换过程中丢失内容的代码块。
  • 并发队列 — 具有协调器和回填功能的新并发队列系统，可实现更可靠的作业调度。
  • Rust SDK v2 — 添加了 v2 API 命名空间，并为 Rust SDK 提供代理支持。
  • 修复了 Python SDK 参数 timeout、max_retries 和 backoff_factor — 这些参数之前已被接受但默默地被忽略。
  • 将作业超时限制为 48 小时，以防止失控作业消耗资源。
  • 添加了重试限制以防止抓取循环。
  • 现在，二进制内容类型会在抓取管道的早期被拒绝，以避免浪费处理。

修复

  • 修复了在提取作业中使用 o3-mini 模型时的空响应。
  • 修复了已撤销的 API 密钥在删除后最多 10 分钟内仍然有效的问题。
  • 修复了提取作业中导致“作业未找到”崩溃的竞争条件。
  • 修复了 /v1/map 中的 time_taken 始终返回 ~0。
  • 修复了爬网状态响应，现在在发生爬网级别故障时会显示 failed 状态，并显示错误消息和部分数据。
  • 修复了 maxPages 未传递到 PDF 提取器的问题 - 以前，会返回完整的 PDF 内容，而仅对有限的页数收费。
  • 修复了超出 maxCredits 阈值的代理作业错误消耗和计费的免费请求积分的问题。
  • 修复了仪表板由于过时读取而显示不正确的并发限制的问题。
  • 修复了未填充品牌 colors.secondary 的问题。
  • 修复了 removeBase64Images 在变压器管道中在 deriveDiff 之后运行，导致差异问题。
  • 修复了 GCS 获取使用错误的行索引进行缓存信息查找的问题。
  • 修复了 /v1/search 控制器中未处理的 ZodError。
  • 解决了跨依赖项的多个 CVE，包括 handlebars、path-to-regexp、fast-xml-parser、rollup (CVE-2026-27606)、undici 等。
  • 强化了 Playwright 服务以抵御 SSRF 攻击。

API

  • 添加了 GET /v2/team/activity 端点，用于通过基于光标的分页列出最近的抓取、爬网和提取作业（过去 24 小时，每页最多 100 个结果，可按端点类型过滤）。
  • 在爬网请求中添加了 regexOnFullURL 参数，以对包括查询参数的完整 URL 应用 includePaths/excludePaths 过滤。有 JS、Python、Java 和 Elixir SDK 版本。
  • 在爬网请求中添加了 deduplicateSimilarURLs 参数。有 JS、Python、Java 和 Elixir SDK 版本。
  • 已弃用 extract 端点 — 使用 /agent 端点代替。 JS 中现有的 extract 方法和 Python SDK 已标记为已弃用。
  • 根据浏览器/交互请求将 persistentSession 重命名为 profile（writeMode 现在为 saveChanges）。旧的参数名称仍然有效，但不再记录。
