firecrawl v2.10

小版本 发布时间2026年5月15日 来源firecrawl/firecrawl 英文原文

firecrawl v2.10

改进

  • /parse 端点 — 上传最大 50 MB 的本地文件（PDF、DOCX、DOC、ODT、RTF、XLSX、XLS、HTML），并返回干净、LLM 就绪的 Markdown、JSON 或摘要。保留表格和阅读顺序，并为企业计划提供全面的零数据保留支持。适用于 JS、Python、Go、Rust、Java、.NET、PHP、Ruby 和 Elixir SDK。
  • 锁定模式 — 在 /scrape 上设置 lockdown: true 以专门提供来自 Firecrawl 索引的结果，默认情况下具有零出站请求和零数据保留。门控出站路径包括 HTTP 获取、robots.txt、音频下载和媒体。适用于所有 SDK、CLI (--lockdown) 和 MCP。
  • question 格式 — 将自然语言提示传递给 /scrape，并在 data.question 中获得扎实的、无幻觉的答案。在托管模型链上运行，具有自动回退、通过 XML 标记和零宽度空间 escaping 进行提示注入隔离，并且每次调用的令牌数量最多减少 100 倍。
  • highlights 格式 — 返回页面上与您的查询匹配的确切句子、代码块和表格行。连续的句子重新连接成段落，代码行用其原始语言包裹在围栏块中，表行重建为带有标题的 Markdown 表——所有这些都来自源页面，每次调用使用的标记最多减少 100 倍。
  • video 格式 — 添加了 video 来抓取格式。返回受支持网站（例如 YouTube）的签名可下载视频 URL，并带有用于经过身份验证的下载的 cookie 转发和显式锁定门控。
  • /search 域过滤器 — 向 /search 添加了 includeDomains 和 excludeDomains 参数，以便将结果范围限定到一组特定的站点。
  • /search 反馈端点 — 使用 POST /v2/search/:jobId/feedback 提交对搜索结果的评分。每个接受的提交都会退还 1 个积分，每个 UTC 天上限，并可进行幂等重试。
  • 自定义 robots.txt 用户代理 — 添加了 robotsUserAgent 来抓取请求，以根据自定义代理字符串评估 robots.txt 规则和抓取延迟，以及独立于 ignoreRobots 的单独 customRobotsAgent 组织标志。提供 JS、Python 和 Java SDK。
  • 官方 Go SDK — 为 v2 API 添加了第一方 Go SDK，替换了社区模块。包括上下文感知重试退避和正确的 MapData.Links 键入。
  • Ruby SDK — 添加了官方 Firecrawl Ruby SDK v2，具有完整的端点覆盖和 v2 原生类型。
  • PHP SDK — 添加了官方 PHP SDK 以及 Laravel 支持、scrape/search/crawl/map/parse 覆盖范围以及已发布的 firecrawl/firecrawl-sdk Composer 包。
  • .NET SDK — 添加了官方 .NET SDK 以及 v2 API 支持、解析和 firecrawl-sdk NuGet 包。
  • Rust SDK v2 — Rust SDK 已升级为官方 v2 SDK，在抓取、搜索、抓取、地图、代理和解析方面具有同等性。
  • /interact 建议 — 对传递 actions 数组的 /scrape 的调用现在会返回一条警告，建议 /interact 用于有状态浏览器自动化。
  • PDF 大小上限 — 将 PDF 上传大小限制从 10 MB 提高到 30 MB。
  • PDF 页面处理账单 — 更新了 PDF 账单以反映处理的页面而不是原始页面计数。
  • Docker 工具 — 通过 docker-compose 公开 HARNESS_STARTUP_TIMEOUT_MS，供需要更长启动窗口的自托管用户使用。
  • Elixir SDK — 将 parse_file/3 添加到 /parse 端点的 Elixir SDK 中。
  • JS ZZPH100​​ZZ 请求超时 — 向 JS SDK 添加了显式请求超时选项，以防止挂起请求。

修复

  • 解决了 API 和 SDK 上的多个 CVE，包括 axios、postcss、fast-xml-parser、protobufjs、follow-redirects、langsmith、lodash、fast-uri 和 fast-xml-builder。
  • 修复了当 LLM 省略值时错误填充的品牌 colors.secondary — secondary 现在是可选的，不再作为默认值应用。
  • 修复了 Playwright 服务忽略调用者的 User-Agent 请求标头的问题。
  • 通过在签名 URL 过期时强制缓存未命中，修复了 screenshot 签名 URL 从缓存返回陈旧结果的问题。
  • 通过默认将锁定视为零数据保留，修复了锁定请求对 ZDR 计费两次的问题。
  • 修复了在没有发生代理出口时缓存抓取的代理计费错误地收取代理积分的问题。
  • 修复了在纯音频抓取和音频下载上运行的 YouTube 转录脚本不接收 CDP cookie 的问题。
  • 修复了 html-to-md 转换服务忽略零数据保留的问题。
  • 修复了处理某些 PDF 输出时 marked.parse 中的堆栈溢出问题。
  • 修复了本机链接过滤器不支持 robotsUserAgent 且不包含在 JS SDK 爬网有效负载中的问题。
  • 修复了 /v1 状态端点在非 UUID 作业 ID 上返回 500 — 现在返回正确的 400。
  • 修复了空 actions: [] 数组被视为功能标志中的操作的问题。
  • 修复了 JS SDK 观察程序发出重复事件、泄漏超时以及在观察程序超时时挂起 start() 的问题。
  • 修复了 credit_usage 数据字段的 Ruby SDK 展开，并将 skipTlsVerification 默认为 false。
  • 修复了 Python、Java 和 Go SDK 中缺失的负限制验证。
  • 修复了 Java SDK 接受空 API 键和缺少异步生命周期方法的问题。
  • 修复了计费周期时间戳、订阅查找和计划信用报告。
  • 修复了无限制的爬行积压超时 — 现在上限为 48 小时。

API

  • 添加了 POST /v2/parse，用于上传最多 50 MB 的分段文件。返回一个标准文档。解析时不允许的抓取选项：changeTracking、screenshot、branding、actions、waitFor、location、mobile； proxy 仅限于 auto 或 basic。 PARSE_UNSUPPORTED_OPTIONS 因不允许的输入而出现错误。
  • 将 lockdown: boolean 添加到 /scrape。缓存未命中返回 404 和 SCRAPE_LOCKDOWN_CACHE_MISS。计费：启用 lockdown 时 +4 积分，缓存未命中时 1 积分。适用于所有 SDK。
  • 添加了 question 和 highlights t
