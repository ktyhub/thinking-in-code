firecrawl v1.14.0

v1.14.0 发布

我们很高兴地宣布 Firecrawl v1.14.0 发布，其中包含很酷的更新。

  • 经过身份验证的 scraping（加入等候名单此处）
  • 企业零数据保留（请发送电子邮件至 help@firecrawl.com 以启用它）
  • 提高了 p75 速度
  • 新的 MCP 版本，带 maxAge + 更好的工具调用
  • 开放研究员示例（开源研究员）。请参阅存储库
  • 还有更多🔥
