firecrawl v2.4.0

v2.4.0

新功能

  • 新的 PDF 搜索类别 - 您现在可以通过我们的 v2/搜索端点指定 .pdf 类别仅搜索 pdf
  • Gemini 2.5 Flash CLI 图像编辑器 — 使用 Firecrawl + Gemini 2.5 Flash 集成直接在 CLI 中创建和编辑图像 (#2172)
  • x402 搜索端点 (/v2/x402) — 添加了下一代搜索 API，提高了准确性和速度 (#2218)
  • RabbitMQ 事件系统 — Firecrawl 作业现在支持基于事件的通信和从 Postgres 预取（#2230、#2233）
  • 改进爬网状态 API — 使用新的 crawl_status_2 RPC 进行更准确和实时的爬网状态报告 (#2239)
  • 低结果和 Robots.txt 警告 - 当抓取受到 robots.txt 限制或产生很少结果时，用户现在会收到清晰的反馈 (#2248)
  • 增强跟踪 (OpenTelemetry) - 大大改进了分布式跟踪，以实现更好的跨服务可观察性 (#2219)
  • 指标和分析 - 为抓取和搜索端点添加了请求级指标（#2216）
  • 自托管 Webhook 支持 — Webhook 现在可以传送到自托管环境的专用 IP 地址 (#2232)

改进

  • 减少 Docker 图像大小 - 仅安装 Chromium，剧作家服务图像大小减少 1 GB (#2210)
  • Python SDK 增强 — 添加了 "cancelled" 作业状态处理和轮询间隔修复（#2240、#2265）
  • 更快的节点 SDK 超时 — Axios 超时现在可以正确传播，提高重负载下的可靠性 (#2235)
  • 改进了爬网参数预览 - 增强了爬网参数预览的提示和验证（#2220）
  • Zod 架构验证 — 更严格的 API 参数验证，拒绝额外字段 (#2058)
  • 更好的 Redis 作业处理 - 修复了 getDoneJobsOrderedUntil 中的边缘情况，以实现更稳定的 Redis 检索（#2258）
  • Markdown 和 YouTube 修复 — 修复了 YouTube 缓存和空 Markdown 摘要错误（#2226、#2261）
  • 更新了文档和元数据 — 自述文件更新和新元数据字段添加到 JS SDK (#2250、#2254)
  • 改进了 API 端口配置 — API 现在尊重环境定义的端口 (#2209)

修复

  • 修复了递归 $ref 模式验证边缘情况（#2238）
  • 修复了枚举数组被错误转换为对象的问题 (#2224)
  • 修复了线束超时和自托管 docker-compose.yaml 问题（#2242、#2252）
