go-ethereum v1.17.0

小版本 发布时间2026年2月17日 来源ethereum/go-ethereum 英文原文

go-ethereum v1.17.0

这是一个功能版本，包含过去 3 个月积累的所有开发成果。请参阅下文了解亮点。

请注意，此版本包含多个关键安全修复程序以及许多错误修复程序，建议所有用户使用。但是，如果您对升级持谨慎态度，您还可以安装仅具有关键安全修复程序的 v1.16.9。具体来说，此版本修复了 CVE-2026-26313、CVE-2026-26314、CVE-2026-26315。

我们建议在安装此更新后重新创建 p2p 节点密钥，您可以通过在重新启动 geth 之前删除 DATADIR/geth/nodekey 文件来完成此操作。请注意，这将导致 p2p 节点 ID 发生更改，这可能会破坏静态对等互连设置。

亮点

带证明的基于路径的存档节点

基于路径的存档节点现在可以为旧块的状态提供证明（通过 eth_getProof）。

您可以配置支持独立于其他存档状态可用性进行证明的块范围。具体来说，您可以使用 --history.trienode 命令行标志来设置将跟踪树节点的块数量。

默认情况下禁用此功能。请注意，状态历史记录一旦删除就无法轻松恢复，因为它只能通过处理块生成。但是，您可以随时启用三节点历史记录（和/或状态历史记录），将完整节点转变为部分存档节点，并保留从该时间点开始的状态。

#32727、#32621、#33551、#32981、#33399、#32913、#33303、#33584、#33329、#33681、#33103、#33098、#33515、#32247

EraE历史支持

Geth 现在支持 EraE 文件格式，这是一种合并后链历史的存档格式。

#32157, #33827

OpenTelemetry 追踪

RPC 服务器现在支持 OpenTelemetry 跟踪，包括对分布式跟踪的支持。 我们还通过引擎 API 添加了一些用于块处理的跟踪范围，即 engine_newPayload。

#33599, #33452, #33780, #33521

所有更改

盖斯 CLI

  • geth version-check 子命令已被删除。此命令检查 geth 网站是否有已签名的漏洞通知，并告知是否需要更新 (#33498)
  • 现在有一个 --miner.maxblobs 命令行标志来设置构建块中包含的 blob 的限制（#33129、#33302）
  • Geth 现在支持使用 Grafana Pyrscope 进行连续分析 (#33623)
  • 修复了一个可能在 geth --dev 模式下停止区块生产的罕见错误 (#33146)
  • 新的 --rpc.rangelimit 标志配置 eth_getLogs 的最大块范围 (#33163)
  • geth --exitwhensynced 现在将设置 finalized 和 safe 块（#33038）
  • geth --ethstats 现在向统计服务器报告 newPayload 处理时间 (#33395)
  • Geth 命令行标志处理中的许多小问题已得到修复（#33379、#33338、#33330、#32999、#33279、#33252）
  • 当没有提供路径时，evm blocktest 命令现在可以从标准输入读取文件名 (#32824)

分叉实施

  • EIP-8024：向后兼容 SWAPN、DUPN、EXCHANGE（#33095、#33787、#33614、#33361）
  • 我们已经实现了engine_getBlobsV3（#33404，#33444）
  • 引擎 API 现在拒绝有效负载版本错误的调用（#32754，#33322）
  • Fusaka 的 blsync 已更新（#33349、#33272、#33065、#32674）
  • 一些将状态迁移到二叉树的工作已经落地，这取代了 Verkle Tree 实现（#33807、#33739、#33694、#32445、#33461）
  • 在处理 EIP-7928 块级访问列表时修复了一些访问列表语义（#33281、#33637、#33450）

核心

  • crypto/ecies 库允许通过观察响应时间来提取用于密钥派生的私钥。我们建议在应用此更新后轮换节点密钥。 (#33669)
  • 当在 tx 取消索引期间遇到丢失块时，Geth 现在将跳过它并继续前进，而不是进入无限循环。 (#33573)
  • Geth 现在可以选择收集和导出有关总状态大小的指标（#33254、#33376、#33415）
  • 有一个新的 OnStateUpdate 钩子，在提交块的所有状态后调用该钩子。这允许访问块的变更集。 (#33490)
  • 修复了一些小的跟踪错误（#32919、#33148、#33644、#33214）
  • 冷冻库数据库中的各种小问题也已修复（#33747、#33025、#33203、#33344）
  • setHead 操作现在会取消设置最终块，以防回滚块范围在其之前扩展。 (#33486)
  • types.Signer 的 SignatureValues 方法现在报告无效签名大小的错误 (#33647)
  • Geth 打印“慢块”的详细日志消息（#33655、#33525、#33442、#32812、#33659、#33532）
  • Pebble 配置已调整以提高性能（#33697、#33353、#33315）
  • 与重组处理相关的日志索引器中罕见的崩溃已修复 (#33810)
  • 内部状态差异大小计算已得到纠正，因此状态差异现在将更少地刷新到磁盘存储（#33505）
  • 由于以太坊使用的 keccak256 哈希函数变体在标准库中不再具有快速路径，因此我们已将 keccak 实现重新供应到我们的存储库中 (#33323)

图书馆

  • RLP 库现在有一个 RawList 类型，可以以更方便的方式处理未解码的列表（#33755、#33834、#33840、#33841）
  • 低级 RLP 迭代器及其使用得到了改进（#33245、#33188、#33820）
  • Clef 现在可以使用单元证明签署 blob 交易 (#32910)
  • 修复了指标导出中的一些极端情况错误（#33749、#33748）
  • 硬件钱包库现在支持 Ledger Nano Gen5 并为所有支持的版本正确启用 EIP-712 签名
