go-ethereum v1.17.3

修订 发布时间2026年5月11日 来源ethereum/go-ethereum 英文原文

go-ethereum v1.17.3

这是一个维护版本，阿姆斯特丹分叉实施不断取得进展。它还引入了 ETH/70，现已上线。

跟踪 API (debug_trace*) 的重大更改，特别是 structLog（操作码）跟踪器。以下响应字段现在遵循新建立的 client 范围规范 (ethereum/execution-apis#762)，并且 reexec 已从跟踪配置中删除：

  • memory：字以 0x 为前缀并填充为 32 字节
  • storage：键和值以 0x 为前缀
  • error：空时省略（之前序列化为“”）

盖斯

  • 在 blsync 中添加检查点初始化的重试机制 (#33966)
  • 添加用于离线二叉树转换的子命令 (#33740)
  • 添加用于数据库导出的代码导出器 (#34696)

核心

  • 阿姆斯特丹分叉更新：
    • EIP-7928 的先决条件：块级访问列表（#34064、#34644、#34726、#34776、#34799、#33737）
    • EIP-8037 的先决条件：国家创建 Gas 成本增加（#34691、#34712、#34841）
    • EIP-7976：增加 Calldata 底线成本 (#34748)
    • EIP-7981：增加访问列表成本 (#34755)
    • EIP-7610：当存储非空时拒绝合约创建 (#34718)
    • 更新状态测试 (#34671)
  • 实现堆栈竞技场 (#33960)
  • 实施 EIP-7975：eth/70 部分区块接收列表 (#33153)
  • snap/2 协议的先决条件（#34083、#34649、#34654、#34874）
  • 为路径模式存档节点实现历史索引修剪器 (#33999)
  • 为 Hoodi 添加布拉格链段修剪点 (#34714)
  • 允许在 ePBS 下 32 个块内将头重组为父级 (#34767)
  • 当数据不可用时停止服务链段请求 (#34787)
  • 删除发送无效正文或收据的对等点（#34745、#34870）
  • 添加 kzg4844 细胞相关函数 (#34766)
  • 状态数据库重构（#33102、#34700、#34763、#34724）
  • 二进制特里树改进（#34055、#34110、#34670、#34676、#34680、#34690、#34754、#34758、#34777、#34794）
  • 合并所有系统调用的 EIP-4762 访问事件 (#34637)
  • 拒绝路径数据库中的重复图层 (#34642)
  • 省略空 slotNumber 并修复前阿姆斯特丹引擎 API 有效负载中的块值收集 (#34704)
  • 在 EIP-8024 错误消息中包含操作数 (#34635)
  • 修复 vmodule 降级并将详细更改传播到派生记录器 (#33111)
  • 修复索引文件截断的不正确的 fsync 顺序 (#34728)
  • 修复冷冻机错误路径中的文件描述符泄漏 (#34735)
  • 修复路径数据库中的大小计算（#34828）
  • 修复 blobpool 中间隙队列大小上限 (#34831)
  • 通过使用只读锁定来提高 txpool 待处理并发性 (#32924)
  • 用 Feed 替换已弃用的 TypeMux (#32585)
  • 当单个单元证明提取失败时继续进行 blob 检索 (#34891)
  • 在核心消息中使用 uint256 来加快气体计算速度 (#34934)

网络

  • 修复删除过期匹配器时提前退出超时循环的问题（#34743、#34878）
  • 通过在未处理的读取错误之前复制发现缓冲区来防止数据竞争 (#34888)
  • 通过将 nodeFeed 与表互斥体解耦来修复发现 waitForNodes 死锁 (#34898)

密码学

  • 验证 nocgo 签名验证中的哈希长度 (#33839)

远程过程调用

  • 修复 structLog JSON 输出格式并从跟踪配置中删除 reexec (#34093)
  • 在 eth_estimateGas 中应用块覆盖（gasLimit、blobBaseFee）（#34081）
  • 将块覆盖应用于 eth_call 中的标头 (#34842)
  • 将 MaxUsedGas 添加到 eth_simulate 调用结果中 (#34820)
  • 将三节点历史索引进度集成到 eth_syncing 中 (#34633)
  • 当超出块范围限制时，从日志 RPC（eth_getLogs、eth_getFilterLogs、…）返回 -32602 (#34647)

其他

  • 修复状态前跟踪器以区分 EIP-7702 中已清除的代码和未更改的代码 (#34675)
  • 在跟踪器中发出 EIP-7708 ETH 燃烧的日志 (#34623)
  • 通过 mux 跟踪器转发 V2 状态钩子 (#34869)
  • 在 client 断开连接时发送 WebSocket 关闭帧 (#33909)
  • 忽略 RPC 过滤器请求中的空地址/主题字段 (#33884)
  • 添加事件签名不匹配的包级错误（#34076、#34868）
  • 添加用于 OTLP 跟踪导出的 gRPC 传输 (#33941)
  • 在 t8n 命令中添加系统调用跟踪 (#34862)
  • 流式传输 t8n 分配输出以减少内存使用 (#34785)
  • 在 linux/arm64 上启用 fsnotify 观察程序 (#34834)
  • 修复 FreeBSD 构建 (#34784)
  • 修复 RLPx ping 中的断开连接解码 (#34781)
  • 修复 Discv5 findnode 结果的配置单元测试 (#34043)
  • 修复谱号中左括号的截断问题 (#33702)

有关更改的完整概要，请参阅 Geth 1.17.3 发布里程碑。
