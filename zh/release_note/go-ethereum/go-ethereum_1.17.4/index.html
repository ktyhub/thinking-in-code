go-ethereum v1.17.4

修订 发布时间2026年6月22日 来源ethereum/go-ethereum 英文原文

go-ethereum v1.17.4

这是一个维护版本，包含累积的错误修复和改进，建议所有用户使用。它还继续即将到来的阿姆斯特丹硬分叉的实施工作。

有一点值得强调：

  • Clef 已被删除。 独立的 clef 签名者已移至 https://github.com/ethereum/clef (#35097)。

分叉实施（阿姆斯特丹）

  • EIP-7928：块级访问列表：块访问列表现在是在块执行期间构建和验证的，并实现了 eth/71 BAL 消息的服务端（#34652、#34803、#34879、#34957、#34967、#34972、#34977、#35110）
  • EIP-8189：添加了 snap/2，一种基于块级访问列表的新状态同步协议（#34626、#34807、#35098、#35155、#35158、#35163、#35178、#35180、#35181）
  • EIP-8037：国家创建天然气成本增加，已实施（#33601）
    • 追踪系统为多维气体提供了一个新的 OnGasChangeV2 钩子 (#34946)
  • 添加了 engine_newPayloadWithWitnessV5，见证格式现在使用规范规范字段排序 (#35009)
  • 阿姆斯特丹的 evm t8n 工具已更新，添加了 BAL 和槽号支持以及二进制 trie 叶导出（#34843、#35025）
  • 对于 EIP-7843，现在为阿姆斯特丹后的待处理块设置槽号（#34792、#35036）

盖斯

  • 设置缓存时，现在根据 cgroup 内存上限（例如 Docker --memory）调整缓存大小 (#34947)
  • 修复了一些小的命令行标志和日志记录问题（#33880、#34732、#34943、#34948、#35011、#35104、#35116、#35136）
  • 一些长期不推荐使用的命令行标志已被删除 (#35021)

远程过程调用

  • 添加了 eth_baseFee，返回下一个区块的基本费用（#34904，#35023）

  • 添加了 eth_capabilities，让 clients 发现节点可以服务哪些历史数据 (#33886)

  • 添加了 debug_clearTxpool 以清除交易池（#33347、#35130）

  • 状态读取方法（eth_getBalance、eth_getCode、eth_getStorageAt 等）现在在省略时默认块参数为 latest (#35100)

  • 修复了 eth_simulateV1：错误的“基本费用太低”错误代码和上海前提款回归（#34951、#34939）

  • debug_setHead 现在传播倒带错误，而不是默默地忽略它们 (#35001)

  • 零 To 地址的 EIP-7702 交易现在被拒绝 (#35094)

  • HTTP RPC 响应现在始终设置 Content-Length，并且修复了 WebSocket 握手状态代码错误（#35072、#35111）

  • client 现在可以通过 traceparent 标头配置跟踪上下文传播，并且现在可以跟踪响应写入（#35132、#35049）

GraphQL

  • GraphQL 请求正文现在限制为 5 MiB (#35034)
  • 使用 begin > 0 和 end == 0 的日志范围查询现在被拒绝 (#35032)
  • 当块体丢失时，Block.raw 解析器现在返回空字节 (#35027)

核心

  • JUMPDEST 位图的全局缓存可加速 EVM 执行 (#34850)
  • EVM 堆栈操作现在就地计算，避免了每个操作数的副本 (#35156)
  • 添加了新的代码缓存命中/未命中计量表 (#34821)
  • 快照生成中的关闭竞争已修复 (#33540)

发动机 API 和斑点

  • 针对大型 blob 有效负载的引擎 API JSON 编码已得到优化，并且在引擎 API 上禁用了 gzip（#33969、#35057）
  • 添加了 engine_hasBlobs，engine_getBlobs 现在仅计算实际可用的 blob（#34859、#35028）
  • GetBlobs 请求的缓存减少了引擎 API 延迟，并且 otel 跟踪已添加到 GetBlobs 端点（#35124、#35026）
  • 重组的 v0 blob sidecar 交易现在被丢弃而不是转换（#35099）
  • testing_commitBlockV1 已添加为 testing_buildBlockV1 的写入伴侣 (#34995)
  • 现在，无论同步状态如何，新的有效负载都会在创世时导入（#32673）

网络

  • NAT STUN 发现在 IPv6 服务器上不再失败 (#35084)
  • 多个快照同步鲁棒性修复：未覆盖的状态在恢复之前被删除，修复了追赶停顿，当所需的 BAL 不可用时同步重新启动，一旦状态下载完成，枢轴就会被冻结 (#35159)

有关更改的完整概要，请参阅 Geth 1.17.4 发布里程碑。

与我们之前的所有版本一样，您可以找到：

  • 我们的下载页面 上为所有平台预构建了二进制文件。
  • 在 ethereum/client-go 下发布的 Docker 图像（使用“稳定”标签）。
  • 我们的 Launchpad PPA 存储库 中的 Ubuntu 软件包。
  • 我们的 Homebrew Tap 存储库 中的 macOS 软件包。
