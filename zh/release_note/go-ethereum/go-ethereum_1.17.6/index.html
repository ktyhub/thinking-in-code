go-ethereum v1.17.6

修订 发布时间2026年9月23日 来源ethereum/go-ethereum 英文原文

go-ethereum v1.17.6

这是一个维护版本，对块处理和初始同步进行了许多性能改进，建议所有用户使用。

有几点值得强调：

  • 阿姆斯特丹硬分叉计划在 Sepolia 测试网上进行，时间戳为 1791294816（2026 年 10 月 6 日，13:53:36 UTC）。 Sepolia 节点运营商必须在此之前进行升级。
  • Holesky 测试网已被删除，因为该网络已达到生命周期终点。
  • 不再支持 Go 1.24。发布二进制文件和 Docker 映像现在使用 Go 1.27 构建。

分叉实现

  • 安排在 Sepolia 上的阿姆斯特丹分叉 (#35734)
  • 删除 EIP-7610 实现 (#35581)
  • 更新 EIP-2780 和 EIP-8038 气体参数（#35454、#35497）
  • 更新 EIP-7997 确定性工厂合约 (#35458)
  • 更新EIP-8037，吸收子框架后首先偿还未偿还的gas债务（#35633）
  • 实现由块级访问列表驱动的并行块执行（#35264、#35441、#35443、#35459、#35461、#35465、#35575、#35693）
  • 将“常规气体”重命名为“执行气体”以匹配 EIP-8037（#35457、#35486）

核心

  • 删除 Holesky 测试网 (#35591)
  • 优化 JSON 对 engine_newPayload 等大请求的解码 (#35518)
  • 在执行的同时处理布隆构建和根计算的收据 (#35738)
  • 引入预取器、块处理和矿工之间共享的预编译结果缓存（#35388、#35473、#35526、#35578、#35753）
  • 在执行后提交中并行化链数据和状态写入 (#35595)
  • 如果发生数据库错误，请勿密封块 (#35427)
  • 修复当重组缩短渲染块上的链时日志索引器中的恐慌 (#35619)
  • 荣誉 ExecuteConfig.EnableTracer 用于 EVM 级跟踪挂钩 (#35512)
  • 添加计量 LRU 缓存变体 (#33719)
  • 保留块级访问列表和坏块 (#35423)
  • 在每个事务结束时取消设置块级访问列表 (#35498)
  • 修复 blob 缓存初始化 (#35509)
  • 修复分叉尾部组下方的头部截断问题 (#35551)
  • 通过一些防御操作改进 blob 获取器 (#35572)
  • 修复在 eth/70 中重新请求部分收据时的死锁 (#35537)
  • 拒绝 eth/70 中空的部分收据响应 (#35593)
  • 限制稀疏 blob 池中阻塞 blob 事务的总大小 (#35367)
  • 修复 eth/72 中的 Cells/GetCells RLP 编码 (#35428)
  • 在 blob 池中缓存恢复的 blob，以加快为 pre-eth/72 对等点提供服务 (#35543)
  • 在状态转换中添加交易类型的分叉验证 (#35588)
  • 避免向遗留节点宣布稀疏 blob txs (#35589)
  • 添加 eth/71 (EIP-8159) 测试 (#35389)
  • 修复气体示踪剂挂钩和气体测量（#35646）
  • eth/72 blob 缓冲区总计上限为 128 MiB，每个对等点上限为 16 MiB (#35766)

同步

  • 通过并行响应处理来优化状态同步 (#35533)
  • 实现块级访问列表的尽力下载（#35386，#35493）
  • 重新设计同步期间正文和收据检索的安排 (#35680)
  • 添加链段下载和快照同步进度的指标（#35678、#35689）
  • 各种 snap v2 修复和改进（#35299、#35316、#35463、#35477、#35705、#35722）

网络

  • 根据公告者的协议版本验证公告的 blob 交易大小 (#35524)
  • 为 devp2p 添加更多的 diskv5 hive 覆盖范围 (#34770)
  • 将 eth/72 测试和阿姆斯特丹测试数据添加到 devp2p (#35368、#35637、#35647、#35648、#35687)
  • 添加 devp2p discovery listen 以在单个 UDP 套接字上为 Discv4 和 Discv5 提供服务 (#35254)

密码学

  • 直接从数据单元重建 blob，无需 KZG 恢复 (#35528)
  • 通过完整数据单元的快速路径恢复 blob 的完整单元集 (#35529)
  • 通过与上游同步修复 bn256 库中的 G2.Neg (#35686)

发动机 API

  • 添加对可选 TargetGasLimit 的支持并强制执行系统合约代码检查 (#35514)
  • 允许将 headBlock 重组为 finalized (#35519)
  • 修复 engine_forkchoiceUpdatedWithWitnessV3/V4 上的叉门 (#35719)
  • 在 testing_buildBlockV1 中传递 targetGasLimit (#35501)
  • 修复配置单元故障（#35580、#35664）
  • 修复 engine_getBlobsV4 返回 blob 模式缓存条目的空单元格 (#35439)

远程过程调用

  • 拒绝 null 所需的参数 (#35576)
  • 解析消息时取消转义 JSON 对象键 (#35587)
  • 在 fromBlock 之前拒绝使用 toBlock 的 eth_getLogs 范围 (#35070)
  • 在 eth_config 中计算下一个分叉时跳过未配置的分叉 (#35553)
  • 返回 pending 的 null 和 eth_getHeaderByNumber 中无法解析的标签 (#35627)
  • 在 eth_simulateV1 中将合并后难度覆盖视为无操作 (#35672)
  • 拒绝没有 to 的 blob 和 setcode 调用参数 (#35695)
  • 删除 eth_createAccessList 中的授权气体防护罩 (#35698)
  • 在阿姆斯特丹之后返回实际使用的天然气以进行简单的传输估计（#35592）
  • 使 debug_traceCall 的块参数可选（#35583）
  • 将 slotNumber 添加到 GraphQL 块架构 (#35469)
  • 当 ethclient 中的块交易计数为零时返回 NotFound (#35605)
  • 根据 ethclient 中的标头根验证提款列表 (#35610)

Geth 和工具

  • 弃用 state sizer 工具 (#35520)
  • 对 abigen v2 绑定中的自定义错误使用原始 Solidity 名称 (#35332)
  • 从事件订阅流中过滤掉意外的日志而不是终止它（#35701）
  • 遵守结构记录器 OnEnter/OnExit 挂钩中配置的日志限制 (#35360)
  • 添加 t8n 测试以查找缺失的伦敦基本费用配置 (#35636)

构建

  • 放弃对 Go 1.24 的支持并添加对 Go 1.27 的支持 (#35573)
  • 将 -dlgo bootstrap Go 版本升级到 1.27.1 (#35656)
  • 为 Fedora COPR 构建 RPM 包 (#35557)
  • 添加包上传重试机制 (#35510)

有关更改的完整概要，请参阅 Geth 1.17.6 版本
