go-ethereum v1.17.5

修订 发布时间2026年7月27日 来源ethereum/go-ethereum 英文原文

go-ethereum v1.17.5

这是一个维护版本，包含累积的错误修复和改进，建议所有用户使用。它继续即将到来的阿姆斯特丹硬分叉的实施工作。

有几点值得强调：

  • 默认的 GOGC 已从 20 更改为 50，以更高的内存峰值换取更少的 GC 开销。设置 --gogc=20 以保留旧行为。
  • 现在支持 Pebble v2 作为键值存储后端。当 Geth 从头开始​​引导时，使用 Pebble v2，并回退到 Pebble v1 以获取预先存在的数据库。运行 geth db pebble-upgrade 将旧版 Pebble v1 数据库显式升级到 v2。

分叉实现

  • 多个阿姆斯特丹 EIP 已实施或更新：
    • EIP-2780：基于资源的内在交易气体（#35212，#35318）
    • EIP-8037：国家创建天然气成本增加（#35173、#35318、#35301、#35342、#35279）
    • EIP-8038：状态访问 Gas 成本更新（#35216）
    • EIP-8246：删除自毁结构烧毁（＃35219）
    • EIP-8282：构建器执行请求（#35175，#35341）
    • EIP-7997：确定性工厂合同（#35223，#35285）
    • EIP-7954：增加最大合约规模（#35217）
    • EIP-7928：块级访问列表（#35260、#35281、#35261、#35348、#35279）
  • 提高阿姆斯特丹分叉测试覆盖率 (#35364)
  • 引入 --override.amsterdam 标志 (#35213)
  • 从 BPO 计划中删除命名硬分叉 (#35029)
  • 在链配置中引入 Bogota 叉 (#34057)

核心

  • 引入稀疏 blobpool 以减少 blob 事务池内存使用量 (#34047)
  • 在启动时将旧的 blobpoollimbo 条目迁移到新的基于单元的 sidecar 格式 (#35209)
  • 删除 blobpool 中对 v0 blob sidecar 的支持 (#35191)
  • 内联气体扣除以修复性能回归（#35203）
  • 修复 eth/71 块访问列表空标记解码，该解码会错误地断开对等点的连接 (#35286)
  • 提交枢轴块后禁用快照同步模式（#35402，#35405）
  • 加速 debug_setHead 并拒绝无法恢复的目标 (#35252)
  • 修复快照同步无法回填缺少规范哈希映射的块的问题 (#35190)
  • 在有效负载构建中重用链的 JUMPDEST 缓存 (#35378)
  • 支持 Pebble v2 作为数据库后端 (#34009)
  • 支持时代商店中的 .ere 文件 (#34978)
  • 介绍 trie.UpdateBatch API (#32448)
  • 修复不干净关闭后新添加的空表上的冻结截断错误 (#35258)
  • 通过考虑同步状态来改进状态可恢复性报告 (#35400)
  • 修复缺席帐户的帐户预取 (#35256)
  • 各种 snap v2 修复（#35321、#35323）
  • 优化区块验证 (#35403)
  • 各种分配改进（#35234、#35237、#35232）
  • 继续二进制 trie 开发 (#34772)
  • 修复交易大小计算 (#35406)

网络

  • 根据交易包含统计数据保护高价值节点免遭随机丢弃 (#34702)
  • 将无效和无法访问的节点排除在 DNS 发现树之外 (#35312)
  • 支持 devp2p 中的双栈发现侦听器，并提供多个相关修复（#35220、#35298、#35243、#35206）

远程过程调用

  • 引入 --rpc.http-body-limit 标志来配置最大 HTTP 请求正文大小 (#35224)
  • 与 authorizationList 组合时拒绝 gasPrice (#35320)
  • 拒绝既没有数字也没有哈希值的块参数 (#35271)
  • 匹配授权方案时不区分大小写 (#35022)

追踪

  • 遵守结构记录器中配置的日志限制 (#35349)
  • 以 EIP-2780 方式发出跟踪帧 (#35396)
  • 在 ERC-7562 跟踪器输出中包含日志索引 (#35200)
  • 停止在日志跟踪器中错误地捕获 callcode 传输 (#35248)

发动机 API

  • 通过 API 引擎传递 TargetGasLimit (#35372)
  • 使最大重组深度可配置（#35335、#35373、#35391）
  • 从 engine_getPayloadBodiesV2 返回块访问列表 (#35347)
  • 将矿工配置的 MaxBlobsPerBlock 设置为协议限制 (#35295)

Geth 和工具

  • 引入 --gogc 标志并将默认 GOGC 提高到 50 (#35363、#34851)
  • 在 geth export 中写入块级访问列表 (#35369)
  • 保留包含 = 的指标标签值 (#35168)
  • 将 eels 测试更新为 v20.0.0 (#35283)

账户和 ABI

  • 将 blob 费用上限转发给外部签名者 (#35167)
  • 在 abigen v2 生成的合约绑定上引入 GetABI() 方法 (#35221)
  • 修复 abigen v1 绑定以处理库依赖项的部署 (#32164)

构建

  • 更新 ckzg 依赖项 (#35336)
  • 将 -dlgo bootstrap Go 版本升级到 1.25.12 (#35317)

有关更改的完整概要，请参阅 Geth 1.17.5 发布里程碑。
