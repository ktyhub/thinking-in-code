claude-mem v15.14.0

小版本 发布时间2026年11月9日 来源thedotmack/claude-mem 英文原文

claude-mem v15.14.0

新

  • “我的工作”中的重点领域：“我的工作”现在打开，显示您的重点领域的概述。每个区域都会获得一张卡片，其中包含捆绑的概念艺术作品、其目标和实时请求；打开一个以查看其请求。设置显示屏幕使用相同的视图。艺术品可以设置为完整、紧凑或关闭，并且图像随插件一起提供，因此在运行时不会生成或获取任何内容（#5652）。
  • claude-mem 可以自我更新： 工作人员每天检查一次 releases/promoted-release.json 中推广的版本，并且仅在您离开一段时间时仅安装 npm 显示为由发布工作流程发布的较新版本（具有出处）。失败的更新会恢复到以前的版本。 npx claude-mem doctor 显示自动更新行。用CLAUDE_MEM_AUTO_UPDATE=false将其关闭； Claude Code 自己的更新开关（DISABLE_AUTOUPDATER 和朋友）也将其关闭。新安装会在 Claude Code 后台更新关闭的情况下注册市场，因此只有一个更新程序运行。请参阅新的自动更新文档页面 (#5500)。
  • 启动上下文只是时间线： SessionStart 消息现在是标题行，后面跟着时间线，以最新条目结束。较长的工作状态和内存使用指令移至 claude-mem MCP 服务器指令。终端横幅具有相同的形状（#5487）。
  • 更快的挂钩： 挂钩从小型仅挂钩捆绑包运行，而不是从完整的工作捆绑包运行。一个钩子大约需要一半的时间和内存；十几个并行钩子使用大约四分之一的CPU（#5541，感谢@bulanovk）。
  • 原始工具证据搜索（选择加入，本地）： 使用 CLAUDE_MEM_TOOL_USES_SEARCH_ENABLED=true，当观察搜索找不到任何内容时，使用 deep: true 的本地 search 会查看存储的工具输入和输出，并返回 get_tool_uses 的 #T ID（#5167，感谢 @ShitK）。
  • 韩语用户界面： 观众、我的作品、设置和观察电视可以用韩语显示（#5522，感谢@BaeJinSeop）。

隐私和安全

  • 上下文： 隐私过滤器现在也适用于启动时显示的先前会话回复 (#5626)。
  • 备份： SQLite 快照创建后只能由您读取 (#5642)。
  • 媒体： 在您选择退出后，云上传将停止启动 (#5622)。
  • 编辑： cookie 标头值被编辑，与 Cowork 填充程序（#5591，感谢 @DeryFerd）相匹配，并且 Cowork 填充程序现在编辑它仍然逐字发送的关键形状（#5543，感谢 @DeryFerd）。
  • Worker： 从 cwd 解析项目的读取路由受到保护（#5590，感谢 @DeryFerd）。
  • Auth： 存储的非字符串访问令牌将被拒绝（#5506，感谢 @Kirat0201）。
  • 启动器： 在启动器到位之前验证 macOS 签名（#5503，感谢 @Kirat0201）。
  • 遥测： 创建标识符时会保留已保存的同意选择（#5629）。

安装程序和集成

  • 原子配置写入： Codex、OpenCode、OpenClaw、Kimi、Antigravity、Hermes、Grok Bot 和 OMP 配置和挂钩文件以原子方式写入，因此中断的安装不会留下损坏的文件（#5592、#5593、#5594、#5595、#5596、#5597、#5598、#5599，感谢 @DeryFerd）。
  • 光标： uninstall 删除了 install --ide cursor 添加的钩子和 MCP 服务器（#5584，感谢 @tanishqbaweja）。
  • **安装程序：**工具版本探测、浏览器设置工作请求和 npm 子进程受到限制，并且 npm 后代在超时时终止（#5634、#5638、#5644）。
  • **安装程序：**在其配置的文件夹中找到现有主机安装，在运行时发现期间跳过非可执行路径，通过其市场 ID 检测 Roo 代码，并在修复期间使用 PATH 上的兼容树托管程序（#5552、#5556、#5560、#5576，感谢 @Kirat0201）。
  • **钩子：**钩子通过已安装的插件解析器调度（#5504，感谢@Kirat0201）。
  • OpenCode： 一次有界实时观察者切换 (#5621)。 Pi： 工具结果已标准化以作为证据 (#5605)。 Goose： YAML 配置中引用了可执行路径（#5606）。 Devin： 仅翻译其自己的工具映射条目（#5512，感谢@Kirat0201）。 **电报：**发送是有限的（#5636）。
  • 适配器： 明确的工具故障被保留作为证据（#5620）。
  • DSH： 工作线程 MCP 错误结果被传递，并且响应正文读取期间的失败被正确分类（#5604、#5619）。

我的工作

  • 列表按原始活动时间排序，所有者目标按事件顺序重播，对话标题范围仅限于其平台（#5580、#5589、#5561）。
  • 当对话移动时，过时的组证据将被删除，跳过无效的观察文件条目，Git 分支产品归因于已确认的远程更新，并且识别已删除的 Windows 临时文件夹（#5587、#5585、#5533、#5554）。
  • 大型历史记录和目录不受 SQLite 的限制，处理深度嵌套的发布结果，分类帐快照使用独立的原子写入，并保留共享短哈希的可交付修订（#5588、#5549、#5579、#5582、#5536）。
  • 空的规则页面解释说它正在等待代理，第一个实时请求在空列表后宣布，并且设置内存搜索卡显示记录的代理（#5575，感谢@Kirat0201；#5564，#5574）。

搜索、上下文和记忆

  • 智能搜索限制源内存并接受便携式路径过滤器；文件历史排名和索引页更快（#5534、#5586、#5602）。
  • 搜索将多行标题保留在一个表行中，保留零值日期范围，在替换语料库之前传播 SQLite 故障，并保留不同的 DSH 结果（#5583、#5520，感谢 @Kirat0201；#5610、#5548）。
  • 上下文一致地选择相等时间行，在服务器上强制执行模式过滤器，在 shell 读取中尊重文字 ~ 和 + 前缀的文件名（#5608、#5623、#5633、#5510，感谢 @Kirat0201）。
  • 知识语料库保留源证据和身份，重叠操作不能覆盖保存的状态，并且取消的查询不会保存（#5528、#5612、#5648）。
  • 智能导航显示 Rust 特征、实现和数据定义 (#5531)。
  • Dedup 读取受到限制，并且 IDF 模型是从锁定快照重建的（#5632、#5613）。
  • CLAUDE.md 遵循零观察计数，claude-md clean 保留作者缩进（#5508，感谢 @Kirat0201；#5566）。

备份、恢复、导入和同步

  • 恢复在接触实时数据之前拒绝较新的架构快照和远程工作人员恢复，尽管有清理错误也报告提交的交换，保留损坏的恢复对，并保护选定的恢复点不被保留（#5649、#5562、#5624、#5630、#5532）。
  • 备份快照卷上的 WAL 页 (#5627)。
  • 导入保留观察来源和强化历史记录，接受 UTF-8 BOM，一致地索引遗留列表，并在行被拒绝时退出非零（#5609、#5518、#5514、#5516，感谢 @Kirat0201）。
  • 同步会在远程逻辑删除后删除副本向量，在项目重新映射后刷新向量元数据，隔离超出范围的数字，拒绝格式错误的端口并保护过时市场目录中的排除文件夹（#5647、#5645、#5611、#5573、#5525）。
  • Chroma 保留原型命名项目的检查点 (#5607)。 Notion 导出保持在 UTF-8 请求限制内 (#5529)。内存导出通过响应正文保持其截止日期（#5547）。

服务器和 CLI

  • 服务器：生成完成计量一次，推理更正保持在作业的付费发送上限内，操作员生成状态更改被锁定，遗留摄取路由获得使用保护，事件轮询在断开连接时停止，错误后关闭清理完成，队列运行状况读取在 Redis 中断期间受到限制（#5640、#5615、#5650、#5641、#5651、#5628、 #5617).
  • PostgreSQL：保留显式 TLS 策略，恢复失败的池连接，幂等写入跳过推理，链接重新传递的事件，并且范围作业计数不与全局总数进行比较（#5637、#5537、#5538、#5546、#5559）。
  • CLI：不会重试已完成的生成作业，当先前的密钥查找失败时，密钥轮换会停止，命令拥有的作业池关闭，信号终止的子级报告失败，并且搜索可以在没有本地插件的情况下查询工作人员（＃5603，＃5618，＃5639，＃5569，＃5568）。
  • MCP：npm MCP 服务器在调用结账时启动，空的显式端口被拒绝，服务器 MCP clients 看不到不可用的本地操作，并且安装程序打印服务器 MCP 端点（#5553、#5571、#5551、#5563）。
  • SQLite句柄在初始化失败时关闭；遵守被拒绝的工人运行承诺；瞬态媒体云读取保持可重试（#5635、#5616、#5614）。
  • 较小的修复：旧版 SQLite 时间戳显示正确的年份，Unicode 保留了提示历史记录缩短，接受单引号跳过原因，对于已经处于试用版或 Pro 版的帐户跳过 Pro 试用版推介，正确记录尾部流，以及文件夹上下文生成报告不完整的工作（#5557、#5550、#5558、#5545、#5526、#5565、#5572）。

文档

  • 翻译后的自述文件具有固定的链接和标题（#5527，感谢@vietmy1711），并且两个旧的 release note 现在正确描述了云同步和遥测（#5577，感谢@Kirat0201）。
