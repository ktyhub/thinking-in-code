claude-mem v16.0.1

修订 发布时间2026年11月19日 来源thedotmack/claude-mem 英文原文

claude-mem v16.0.1

关键修复

  • 当 claude-mem 运行时，在 Windows 上登录 Codex 再次可用（#6332，感谢 @ffe111，关闭 #6331）。 claude-mem 的应用程序服务器使用的私有 Codex 主目录通过硬链接获取其 auth.json 到您真实的 ~/.codex/auth.json。 Codex 拒绝用多个硬链接 (persist_failed: atomic credential replacement does not support hard-linked files) 替换凭证文件，因此只要该主目录存在，codex login 和令牌刷新就会失败。私人住宅现在获得了一个符号链接，Codex 遵循该符号链接。仅在 Windows 上，并且仅当不允许符号链接（无开发人员模式或提升）时，它才会获得私有副本。任何其他错误仍然会失败。
  • 以 <skip_summary/> 应答的探测器结束配额冷却（#6324，感谢 @vaibhav375，关闭#6322）。达到配额后，工作人员会探测提供者，并在探测存储内存后清除冷却时间。提供者用有效的 <skip_summary/> 回答的探测不会存储任何内容，因此冷却时间永远不会清除，并且只要跳过该会话，工作人员就会每 5 分钟重新探测一次。现在，有效的跳过也会释放冷却时间，无论是在存储路径上还是在内存会话 ID 已知之前的早期路径上。观察者健康的成功仍然需要一个真正的商店。

修复

  • 当 Chroma 速度较慢时，搜索会回退到 SQLite，而不是失败（#6327，感谢 @REI-330，关闭 #6323）。 MCP client 的搜索时间为 30 秒，而每个 Chroma 读取等待长达 60 秒，因此当调用者放弃并且 SQLite/FTS5 回退从未运行时，缓慢的查询仍在运行。现在，搜索在其 Chroma 读取中共享一个 20 秒的预算，并在预算耗尽时回退，而无需重新启动健康的 chroma-mcp。
  • Chroma 重建不再将核心保留数小时（#6299，感谢 @srieteja）。现在，完整回填在每行写入时间乘以 CLAUDE_MEM_CHROMA_BACKFILL_PAUSE_RATIO（默认为 1，0 将其关闭）后暂停，并且 chroma-mcp 在 Windows 之外的 nice（CLAUDE_MEM_CHROMA_PROCESS_NICE，默认为 10）下启动。实时同步未改变。
  • Windows 进程清理正确读取 taskkill （#6328，感谢 @REI-330；#6307）。现在，taskkill 出口 255 是通过指定进程是否仍然存在来判断的，而不是通过其措辞来判断的，因此在 Chroma 拆卸期间不再抛出本地化消息，并且当进程仍在运行时，混合消息不再报告成功。
  • 观察者轮流停止泄漏 SQLite 语句 (#6306)。存储观察者回合的语句被缓存，而不是在每个回合都准备好，这可能会堆积起来，直到 SQLite 耗尽内存并回滚整个回合。
  • 登录通知表明，当观察者没有克劳德代码登录时，它可以使用（#6321，参考#6319）。当终端登录到另一个凭据配置文件时，工作人员不会告诉您运行 /login，而是会记录一条警告，其中包含原因以及登录时读取的通知名称并建议 claude setup-token。
  • 旧版 claude-mem shell 别名在安装和更新时被发现并删除（#6300，感谢 @0xABCD01）。 doctor 报告该情况，status 在工作程序在已解析的插件根目录之外运行时发出警告，多行别名保持不变并发出警告，如果取消重新安装，则不会发生任何更改。
  • /api/health 仅发布探针状态（#6309，感谢 @DeryFerd）。它不再显示身份验证方法、Redis 队列描述符、绝对安装路径或与未经身份验证的调用者的最后交互。
  • 不可读的“我的工作”刷新状态不再破坏设置 (#6305)。损坏的 refresh.json 显示为不运行，需要更换；自动更新程序仍然将其视为繁忙。
  • 当机器用完文件描述符时本地工作保持暂停 (#6303)。安装程序检查将 EMFILE/ENFILE 视为“安装程序仍处于活动状态”，并每集记录一个警告。
  • 时间线文件标签在每个平台上看起来都相同（#6301，感谢@POWDER-RANGER）。
  • 按“我的工作”焦点卡上的任意位置即可打开其区域 (#6315)。相同的修复涵盖列表、团队和按代理行。

新

  • Devin 云会话和 Devin 机器人 (#6334)。组织可以将 plugin/ 作为 Devin 插件安装，并在每个会话中获取挂钩、MCP 搜索和技能。
  • 我在 OpenCode 上的工作刷新（#6330，感谢 @REI-330）。通过 CLAUDE_MEM_WORK_VIEW_AGENT=opencode 选择加入；否则什么都不会改变。
  • PostgreSQL 搜索在 CJK、假名和韩文文本中查找术语（#6329，感谢 @REI-330，参考文献 #3982）。
  • 我的工作卡标题用 5 到 7 个单词来命名任务，而不是复制询问的第一句话 (#6317)。
  • 图像查看器使后面的页面变暗并模糊并投射阴影（#6313）。
  • 安装程序在 GUI 设置之前会要求您提供工作电子邮件和终端中的消息 (#6308)。

测试和文档

  • Grok Bot 和 Zed 测试在 Windows 上通过（#6311、#6312，感谢 @Lupin133）。
  • 使用 bun install 安装社区清扫工作树（#6325）。
