LangBot v4.10.11

LangBot v4.10.11

此版本修复了 OSS 兼容部署中的知识库摄取，并改进了监控、平台兼容性和 API 功能。

亮点

  • 知识库可靠性：修复文档文件传输和嵌套解析器调用；升级到 langbot-plugin==0.5.8，同时保留工作空间和安装隔离。
  • 监控：恢复消息持久性，通过机器人隔离会话，修复会话分析，并使用全范围流量聚合而不是分页列表数据。
  • 平台和提供商支持：添加 Mattermost 和 Codex 订阅登录；改进 n8n 异步响应、Matrix 重新登录和 Langflow 兼容性。
  • API 和 MCP 功能：扩展 API 密钥系统上下文和管理端点，并检测受 OAuth 保护的远程 MCP 服务器。
  • 安全性和可用性：强化密码恢复并显示准确的沙箱限制消息。

发布验证

  • Python 3.11、3.12 和 3.13 单元套件、覆盖范围、快速集成、启动 E2E、Box 集成、Ruff、前端 lint、CodeQL、CLA 和开发映像构建检查已通过。
  • 在v4.10.10上重现了知识库回归； SDK 0.5.8 通过了所有 13 项相关协议和范围测试。新鲜的OSS工作空间之旅也过去了。
  • 通过前端生产构建和 Python 车轮/距离检查；已发布的封装包括 WebUI 和引脚 SDK 0.5.8。干净的 PyPI 安装和 CLI 烟雾测试已通过。
  • 下载并验证了发布存档和 PyPI 发行版。针对 linux/amd64 和 linux/arm64 发布了 Docker 镜像；拉取的 amd64 映像通过了版本和修复检查。
