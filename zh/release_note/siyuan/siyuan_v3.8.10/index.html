siyuan v3.8.10

siyuan v3.8.10

概述

此版本添加了丰富的文档标题、数据库子项和相关视图、工作区级 AI 长期记忆以及内置的轻量级 Markdown 编辑器。

文档树更有效地处理大型目录，而统一的文档和块面包屑使导航更加一致。其他改进包括移动底部表单、模板中的 HTTP 请求、自定义 PDF 页面大小、LAN 同步地址选择和集市兼容性过滤。

Changelogs

以下是该版本的详细变化。

增强

  • 支持统一文档和分块面包屑
  • 支持丰富的文档标题并保留笔记本名称中的斜杠
  • 提高文档树浏览性能和对大目录的访问
  • 支持面包屑按钮可见性和外观配置文件中的排序
  • 支持将嵌入块转换为常规块或块引用
  • 支持配置 Exa API 密钥进行内置网页搜索
  • 支持数据库分项
  • 模板支持HTTP请求
  • 支持AI工作区级长期记忆
  • 改进思维导图摘要输入大小、对齐方式和颜色
  • 改进Android边缘导航栏适配
  • 提高浮动窗口调整大小的响应能力
  • 改进包含撇号文本的关键字搜索
  • 支持自定义PDF页面尺寸
  • 通过“更多”菜单改进移动撤消和重做访问
  • 支持配置浮动停靠栏可见性
  • 支持视频块循环播放
  • 支持内置轻量级Markdown编辑器
  • 支持通过命令行选项禁用固定端口代理
  • 改进多行表头创建
  • 提高移动对话框与底页的一致性
  • 通过选择性删除自动收集的数据库条目来改进标签删除
  • 条目详情支持相关数据库视图
  • 改进多接口和 VPN 环境中的 LAN 同步地址选择
  • 支持集市包兼容性按首发日期过滤和排序

重构

  • 将桌面Electron主进程迁移到严格的TypeScript模块

发展

  • 支持通过插件API打开文档和笔记本菜单
