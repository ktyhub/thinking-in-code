spring-security 7.1.0-RC1

小版本 发布时间2026年4月20日 来源spring-projects/spring-security 英文原文

spring-security 7.1.0-RC1

:star: 新功能

  • 添加 AllRequiredFactorsAuthorizationManager.anyOf #18960
  • 添加 PreFlightRequestFilter 支持 #18926
  • 添加 ConditionalAuthorizationManager #18919
  • 添加 MultiFactorCondition.WEBAUTHN_REGISTERED #18923
  • 添加 PreFlightRequestFilter 支持 #18980
  • 将PrincipalResolver添加到ExchangeFilterFunctions #18888
  • 添加支持 DPoP 定制 #17202
  • 添加基于 XML 的 shouldWriteHeadersEagerly 测试 #19019
  • AuthorizationManagerFactories.when #18920
  • 澄清 @WithSecurityContext 线程范围 #18812
  • 在 BCryptPasswordEncoder 中构造 SecureRandom #18560
  • 通过 JSpecify 在 spring-security-oauth2-authorization-server 中启用 Null 检查 #18937
  • 通过 JSpecify 在 spring-security-oauth2-client 中启用 Null 检查 #17819
  • 通过 JSpecify 在 spring-security-oauth2-resource-server 中启用 Null 检查 #17822
  • 从 nohttp 源集中排除构建输出目录 #18928
  • 在 ImmutablePublicKeyCredentialUserEntity 中实现 equals 和 hashCode #18883
  • 改进 And/Or-RequestMatcher/ServerWebExchangeMatcher API #18479
  • 合并添加 CredentialRecordOwnerAuthorizationManager #19006
  • 将 InetAddressMatcher 移至 spring-security-core #18979
  • 改进了 oauth2-client 测试，缺少 Content-Type 标头 #19008
  • 优先选择调度程序上下文来授权标记 bean #18822
  • 在 WebAuthn 中发布身份验证事件 #18938
  • 在 AtJwtBuilder 中放宽 client_id 验证 #18890
  • 删除 spring-security-access 的编译器警告 #18738
  • 删除 spring-security-web 中的编译器警告 #18820
  • 删除不必要的 ObjectProvider roleHierarchy 参数 #18921
  • 将快照恢复为 Spring Framework 7.0.+ #19024
  • 支持定制器<AdditionalRequiredFactorsBuilder
