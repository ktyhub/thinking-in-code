spring-security 6.4.0-M1

⏪ 重大变化

  • 适应在表单数据中不添加 charset，如果它是 UTF-8 #15275

⭐ 新功能

  • AclAuthorizationStrategyImpl 应该使用 RoleHierarchy #4186
  • 添加 CachingRelyingPartyRegistrationRepository #15341
  • 添加接口 IterableRelyingPartyRegistrationRepository 或类似的接口 #15027
  • 为 DefaultMethodSecurityExpressionHandler 添加 Kotlin 支持 #15093
  • 为 PreFilter 和 PostFilter 注解添加 Kotlin 支持 #15095
  • 为匹配参数添加 RequestMatcher #15342
  • 添加 saml2Logout Kotlin DSL 支持 #14935
  • 添加 SecurityContextRepository 到 Kotlin Reactive DSL #15013
  • 为 CasAuthenticationProvider 添加 userDetailsChecker 的 setter 方法 #10277 #15047
  • 添加对 AnyRequestMatcher 安全过滤链的支持 #15221
  • 添加将 OAuth2AuthorizationRequestResolver 配置为 Bean 的支持 #15237
  • 添加自定义 remember-me cookie 的支持 #15203
  • 添加 PT-BR 语言的缺失翻译 #15181
  • 调整 DefaultSecurityFilterChain 的日志记录级别并简化过滤日志记录 #15096
  • 澄清当 IdP 参与时并发会话管理的行为 #15206
  • 改进单页应用的 CSRF 示例 #15105
  • 在 Kotlin DSL 中弃用 authorizeRequests #15173
  • 弃用 OpenSamlRelyingPartyRegistration #15343
  • 安全匹配器和多个过滤链的描述现在更加详细 #15029
  • 记录 CredentialsContainer 的角色 #15322
  • 在 OAuth2UserAuthority 中公开用户名属性名称 #15012
  • 因无效凭据导致的 LDAP 绑定失败不会触发 AuthenticationFailure 事件 #3834
  • 在 LDAP 文档中提及所有必需的依赖项 #15246
  • OIDC 后台注销应允许具有 typ 标头 logout+jwt 的注销令牌 #15003
  • 删除 Spring LDAP 的过时用法 #15274
  • 将 SAML 元数据的内容类型设置为 application/samlmetadata+xml #15147
  • 在 Kotlin DSL 中支持 GrantedAuthorityDefaults Bean 在 authorizeHttpRequests 中的使用 #15171
  • 在 Kotlin DSL 中支持 RoleHierarchy Bean 在 authorizeHttpRequests 中的使用 #15136
  • 支持签署 SAML 元数据 #14916
  • 更新 Kotlin 示例以使用 MockMvc 和 Spring Security #15177
  • 更新 OAuth2 jwt 和不透明资源服务器文档 #15362
  • 使用 Javadoc 宏 #15386

🪲 错误修复

  • 确认 WebSession 不为空 #15180
  • 文档：修复使用 Kotlin DSL 的响应示例中的导入 #15200
  • 修复漏洞密码检查器文档样本无法运行的问题 #15306
  • 修复 multitenanci.adoc 中的 Java 示例 #15164
  • 修复内存身份验证文档中的链接 #14689
  • 修复 “使用方法参数” 文档中格式错误的列表 #15325
  • 修复文档中的拼写和格式错误 #15353
  • 修复 @PostAuthorize 注解的错误解释 #15222
  • 解决无效 CSRF 令牌值的不一致问题 #15187
  • 文档中引用的 #7537 已关闭 #15263
