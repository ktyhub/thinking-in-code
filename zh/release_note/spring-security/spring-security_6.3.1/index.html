spring-security 6.3.1

修订 来源spring-projects/spring-security

spring-security 6.3.1

⭐ 新功能

  • 当涉及 IdP 时，明确并发会话管理的行为 #15071
  • 在 LDAP 文档中提及所有必需的依赖项 #15245
  • 小幅文档修正 #15144

🪲 Bug 修复

  • AbstractRequestMatcherRegistry#requestMatchers 在使用 MockMvc 时应选择 MvcRequestMatcher #15211
  • 确保 WebSession 不为空 #15179
  • DispatcherServletDelegatingRequestMatcher 在使用 MockMvc 进行测试时会导致错误 #15197
  • 需要在关闭 #12783 后澄清文档 #15208
  • 修复 multitenanci.adoc 中的 Java 示例 #15151
  • 修复 authorize-http-requests.adoc 中的 Kotlin 示例 #15129
  • OIDC 后台注销的文档不正确 #15212
  • IpAddressMatcher.matches(String address) 仍然接受 URL #15172
  • 官方文档中的 LDIF 文件会导致启动过程中断 #15167
  • 指向带有 remember-me-persistent-token 策略的文章链接已损坏 #15149
  • OpenSaml4AssertionValidator 未遵守时钟偏差设置 #15183
  • 解决无效 CSRF 令牌值不一致 #15186
  • spring-security/docs/modules/ROOT/pages/servlet/authorization/method-security #15143
  • SpringOpaqueTokenIntrospector 未正确添加范围作为授予的权限 #15165
