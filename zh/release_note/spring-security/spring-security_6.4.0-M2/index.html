spring-security 6.4.0-M2

预发布 来源spring-projects/spring-security

spring-security 6.4.0-M2

⭐ 新特性

  • (Spring Boot 2.7->3.2) 类层次结构中重复的 @PreAuthorize 注解错误 #15097
  • 添加 @FunctionalInterface 到 AuthenticationManager #15441
  • 添加 RestClient 拦截器 #15437
  • 添加 AssertingPartyMetadataRepository #15349
  • 添加 AuthorizationDeniedException(String) 构造函数 #15607
  • 添加方法以扩展 StrictHttpFi 的允许头和参数 #15048
  • HeadersConfigurer#permissionsPolicy 方法与自定义配置器的返回类型不匹配 #14803
  • 当 nameAttributeValue 为空时修复 NPE #15338 #15407
  • 改进 @AuthenticationPrincipal 元注解 #15344
  • 改进 @CurrentSecurityContext 元注解 #15553
  • 默认登录和注销页面内联 CSS #15303
  • 方法注解应支持 @AliasFor #15436
  • 在 InMemoryUserDetailsManager 中保留自定义用户类型 #15498
  • RelyingPartyRegistrations 通常会产生不可用的 registrationId #15017
  • 验证断言方元数据签名 #12116

🪲 错误修复

  • @DeniedHandler 不应要求 ApplicationContext 来运行 #15496
  • 当接口被继承时，AuthorizationAnnotationUtils.findUniqueAnnotation 失效 #13490
  • EnableMethodSecurity 只应发布一个 AuthorizationAdvisor Bean #15608
