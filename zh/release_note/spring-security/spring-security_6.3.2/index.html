spring-security 6.3.2

修订 来源spring-projects/spring-security

spring-security 6.3.2

⭐ 新功能

  • ActiveDirectoryLdapAuthenticationProvider 不支持多个 URL #15495
  • 记录 CredentialsContainer 的角色 #15321
  • OIDC 后台注销允许带有 logout+jwt 类型头的注销令牌 #15410

🪲 Bug 修复

  • Spring Security 参考中的链接损坏 #15297
  • ServletBearerExchangeFilterFunction 的文档不完整或不正确 #15460
  • EnableMethodSecurity 应该只发布一个 AuthorizationAdvisor Bean #15592
  • 修复 Compromised Password Checker 文档示例不可用的问题 #15305
  • 修复问题 #15172 引入了显著的性能退化 #15324
  • Pre/PostAuthorize 不应忽略 HandleAuthorizationDenied#handlerClass 当未提供 ApplicationContext 时 #15535
  • 将文档中的先决条件更新为 Java 17 #15340
  • 在 Kotlin 示例中使用正确的元注释 #15472
  • 使用 sec:authorize 在 JSPX 中导致 ‘java.lang.NullPointerException: Cannot invoke “jakarta.servlet.ServletRegistration.getClassName()” because “registration” is null’ #15440
