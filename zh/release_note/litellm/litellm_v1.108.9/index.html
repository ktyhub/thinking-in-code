1.108.9 (LTS) 的新增功能

10 个 PR。添加了 2 个，修复了 7 个，更改了 1 个。无需执行任何操作即可升级

变化

  • Azure： 修复了 Azure AI Foundry 上的 Kimi K3 在工具调用后丢失其早期推理并拒绝 reasoning_effort (#51747)
  • Azure： 修复了 Foundry 项目 /openai/v1 基础上的 400 和资源级 /openai/v1 响应基础上的 404 (#51767)
  • AWS Bedrock： 修复了 Converse 型号上 s3:// 图像、PDF 和视频 URL 上的 500 个问题，这些 URL 现在作为 S3 源转到 Bedrock (#50577)
  • AWS Bedrock： 使用 OpenAI 风格的过滤器修复了 Bedrock 矢量商店搜索上的 AWS 400 (#51291)
  • Vertex AI 和 Gemini： 添加了 vertex_request_label_fields，以使用调用者的密钥、团队、组织和项目来标记 Vertex 调用 (#50732)
  • Vertex AI 和 Gemini： 在 Vertex AI 上向 Claude 发送 labels 时修复了 400 Extra inputs are not permitted (#48753)
  • 其他提供商： 在 /v1/decisions 上添加了 Vercel AI Gateway 模型，按 Vercel 报告的成本计费 (#50642)
  • 响应 API： 修复了流式 /v1/responses 在与推理一起到达时丢弃第一个答案片段的问题 (#51356)
  • 响应 API： 修复了使用桥接到响应 API 的功能工具在聊天请求上删除 cache_control 标记的问题 (#51783)
  • 部署： 将 Docker 映像更改为较新的 Wolfi 基础并更新了 opentelemetry、dnspython、tornado 和 soupsieve (#51853)
