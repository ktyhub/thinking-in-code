1.109.0 的新增功能

982 个 PR。添加了 144 个，修复了 424 个，更改了 60 个，改进了 17 个，删除了 9 个。 5 需要行动

需要采取行动

  • 路由和后备： 将字符串后备目标更改为模型名称列表 (#48943)
  • 缓存： 将 cache_params.type 从 disk 切换到 local 或 redis，因为 disk 缓存后端（磁盘缓存）已被删除 (#48114)
  • 路由和后备： 添加 optional_pre_call_checks: ["enforce_model_rate_limits"] 以保持部署的严格 rpm 上限 (#48873)
  • Vertex AI 和 Gemini： 设置 drop_params: true 或停止发送 temperature、top_p 和 top_k 到 Gemini 3.6 Flash、3.5 Flash-Lite 及更新版本 (#47645)
  • 部署： 从自己的图表部署 Lens 并在您的值中设置 lens.* (#49169)

亮点

  • 管理 UI： 添加了带有模型中心、图像生成和使用指标的聊天 UI (#48108)
  • 路由和后备： 添加了中流后备延续，因此流聊天会在配置的后备上继续切断中间答案 (#41127)
  • **部署：**添加了 LITELLM_OFFLINE_MODE，以通过一个开关关闭 LiteLLM 自己进行的每个获取 (#48096)
  • 成本跟踪和定价： 添加了 model_info.pricing_provider 以对来自其他提供商的目录费率的部署进行定价，而不是 0 美元 (#47620)
  • Vertex AI 和 Gemini： 添加了 Gemini 3.1 Flash TTS 支持，包括多扬声器语音和 mp3、opus、alaw 和 mulaw 输出 (#31915)
  • SDK： 修复了 completion() 和 responses() 上的工具调用在基础 SDK 安装上因 No module named 'mcp' 失败的问题 (#45961) 也在 1.108.4
