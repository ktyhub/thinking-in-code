CowAgent 2.2.2

CowAgent 2.2.2

🌐 中文 | 中文

💬 访客页面

将代理共享为独立的聊天页面，或将其作为聊天窗口嵌入到您的网站中。访客无需登录，打开链接即可开始聊天，适合产品查询、知识库问答、客户支持等类似场景：

  • 独立页面：每个页面都有自己的链接，访问者保留他们的聊天记录，并且名称、图标、主题颜色、欢迎消息和建议问题都是可定制的。

<框架> </框架>

  • 嵌入式聊天窗口：单个代码片段将页面嵌入您的网站中，右下角有一个聊天按钮。您可以限制哪些站点可以嵌入它并在配置时预览结果。在 CowAgent 网站 上实时尝试。

<框架> </框架>

  • 数据隔离：为访问者提供服务的代理只能使用为该页面启用的工具、技能和参考。它无法访问您的内存、对话或工作空间，无法运行命令，并且其网络请求仅限于公共地址。新页面从文件写入、文件发送和网络搜索关闭开始。
  • 参考文献：选择您的知识库或其类别之一作为只读参考文献，每个参考文献都附有其用途的注释。
  • 访问控制：支持访问密码、每个访客的每日提问限制和到期日期。可以按访问者查看对话，并且可以随时重置页面链接、暂停或删除页面。

🎨 自定义主题

Web 控制台和桌面 client 现在支持主题，并且两者共享一个主题文件夹：

  • 主题导入：拖入主题 zip 或文件夹进行导入，其中包含自定义颜色、背景壁纸和新聊天图标。主题存储在 ~/cow/system/themes/ 中。
  • 代理生成的主题：描述您想要的样式或附加参考图像，代理生成颜色、壁纸和图标，准备切换到。
  • 内置主题：五种颜色主题：草地、海洋、粘土、樱花和薰衣草，每种主题都适应浅色和深色模式。

🖼 通过主模型更好地理解图像

当主模型支持视觉时，图像会作为多模态输入直接传递给它，因此理解和回答只需一次调用即可完成。这避免了图像理解工具描述二手图像时丢失的细节，并显着改进了 UI 再现和图表分析等任务（感谢 @592774447 #3608）。

  • 适用时：视觉模型设置为“自动”或与主模型相同的模型时生效，无需额外配置。
  • 上下文成本：仅当前回合携带图像。较早的回合保留对其的引用，因此不会再次计算其令牌。如果请求因图像而被拒绝，则会仅以文本形式自动重试。
  • 提供商支持：Claude、Gemini 和 Qwen 接收以其自己的本机格式的图像。
  • 识别精度：图像压缩限制提高至 3 MB / 3072 px，保留更多文本和细节。

🔗 集成和访问地址

配置页面在 Web 控制台和桌面 client 中都有一个新的 集成 选项卡，它将访客页面、聊天 API 和访问地址集中在一起：

  • 地址：在线更改监听IP和端口。该服务无需重新启动即可切换到新地址，如果新地址不可用，则返回到前一个地址。显示本机的 LAN 地址，您可以设置共享链接和嵌入代码的显示地址。
  • HTTPS 和域：一旦配置了证书，控制台就可以直接提供 HTTPS 服务，并且文档现在涵盖了 nginx 反向代理后面的部署（感谢 @anshlakhera048 #3774、@592774447 #3768）。
  • 登录保护：反复输入错误密码的client将被暂时锁定。本地访问是单独计算的，因此从外部猜测密码永远不会将您锁定在这台计算机上。
  • 聊天 API：同一对话中的并发请求按顺序处理（感谢 @rudycelekli #3751）。

🤖 模型能力

  • 新模型：添加了 kimi-k3.1-pro（Kimi 的默认模型）、MiniMax-M3.1-Flash、gpt-6.1-terra（OpenAI 的默认模型）、claude-sonnet-5-5、claude-haiku-5-5 和 gemini-4-argon（Gemini 的默认模型）（感谢 @octo-patch #3791）。
  • Xiaomi MiMo：添加了 mimo-v2.5-asr 用于语音识别；聊天模型升级到V2.6，自动映射旧模型ID（感谢@592774447 #3788）。
  • 模型显示名称：来自自定义提供程序的模型可以有一个显示名称，显示在模型选择器中，而原始模型 ID 仍用于请求（感谢 @592774447 #3852）。
  • 默认上下文：代理的默认上下文限制从 64K 令牌提高到 200K 令牌，最大步数从 30 提高到 100，保留轮数
