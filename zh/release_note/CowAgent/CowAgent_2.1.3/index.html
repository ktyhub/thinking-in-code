CowAgent 2.1.3

CowAgent 2.1.3

🌐 中文 | 中文

🖥 桌面 Client

隆重推出适用于 macOS 和 Windows 的 CowAgent 桌面 client — 您的本地超级 AI 助手，真正可以开箱即用。

下载：CowAgent桌面版

亮点：

  • 开箱即用：捆绑了完整的代理运行时 - 安装后立即启动，无需设置 Python 或其他依赖项
  • 完整的聊天体验：流式回复、会话管理、工具调用步骤显示、Markdown 渲染，以及发送和预览图像/视频/文件
  • 可视化管理：配置、模型、知识库、计划任务、技能和内存页面镜像 Web 控制台，所有这些都可以在本机 UI 中进行管理
  • 频道加入：通过扫描应用程序内的二维码来连接消息频道
  • 自动更新：自动版本检查和一click更新，跨区域下载速度优化
  • 原生体验：首次运行引导、遵循系统语言、平台自适应窗口交互

📚 知识库

  • 创建和导入文档：创建新文档或直接从 UI 导入外部文档
  • 自动索引维护：知识库索引根据实际目录树自动重建，防止索引漂移或丢失文档
  • 矢量化修复：索引现在重用统一的嵌入提供程序，确保真正的语义向量，而不是退回到关键字搜索

谢谢@yangziyu-hhh

文档：知识库

🔌 按需 MCP 工具检索

为了解决连接多个 MCP 工具时的上下文膨胀问题，我们添加了按需工具检索：根据当前任务通过 RAG 向量搜索按需加载相关 MCP 工具，减少不相关工具占用的上下文。

谢谢@fengyl07

文档：MCP 工具

🌏 繁体中文支持

Web 控制台、日志和文档现在支持 繁体中文 (zh-Hant)；界面语言可跟随系统或手动切换。

谢谢@anomixer (#2935)

🤖 新型号

  • 添加了对 claude-sonnet-5 和 claude-fable-5 的支持
  • 添加了对 doubao-seed-2-1-pro 和 doubao-seed-2-1-turbo 的支持

文件：型号

🔒 安全强化

  • 敏感文件读取保护：强化对凭证和其他敏感文件的访问，以防止绕过读取。谢谢@fengyl07 (#2936)
  • 浏览器访问保护：阻止针对内部网络和云服务器内部端点的浏览器请求，降低被欺骗访问内部服务的风险。感谢@Jiangrong-W
  • 更安全的配置解析：以更安全的方式解析配置内容，以避免潜在的代码执行风险。谢谢@shunfeng8421

🛠 改进和修复

  • 自定义提供程序支持：嵌入和视觉模型现在可以使用自定义提供程序；还修复了 Windows 上的内存查询问题。谢谢@HnBigVolibear
  • 更可靠的文件编辑：更好地保留原始缩进，模糊匹配不再触及不相关的内容。感谢@weijun-xia (#2942)
  • 命令输出编码修复：修复命令产生大量输出时出现的中文乱码问题。感谢@weijun-xia (#2941)
  • Azure OpenAI 修复：修复了 Azure OpenAI 的流输出和相关配置问题。谢谢@Tunnello
  • WeCom Smart Bot：添加了 webhook（回调）模式的通道文档。谢谢@6vision
  • Deep Dream 切换：添加了专用的 deep_dream_enabled 开关以独立启用或禁用 Deep Dream 蒸馏。
  • 稳定性：改进了 Web 服务中的连接 recycling 并修复了几个自我进化问题（#2924 感谢 @santipongth，#2904 感谢 @YLChen-007）

📦 如何升级

  • 桌面 client：从下载页面 获取最新版本。
  • 源部署：运行 cow update 进行单 click 升级，或拉取最新代码并重新启动。参见【升级指南】(https://docs.cowagent.ai/guide/upgrade)。
