🤝 多代理团队

CowAgent 现在是一个多代理框架。您可以创建多个代理，每个代理都有自己的角色，以组成一个团队并在单个会话中协作处理复杂的任务。 Web 控制台、桌面 client 和渠道集成支持：

  • 团队管理：创建和维护代理，配置名称、职责、默认模型、技能和知识，并从现有代理复制设置。
  • 资源隔离：每个Agent都有自己的工作空间、内存和会话；知识库和技能可以共享或保持独立。

<框架> </框架>

  • 群组协作：将多个代理添加到一个会话，并使用 @ 将消息定向到特定成员，每个代理使用自己的配置模型。
  • 任务委派：群聊有一个主要代理，可以根据其职责将任务交给最适合的成员，并支持多级委派和可配置的范围、深度和超时。

<框架> </框架>

  • 多个通道实例：同一类型的 IM 通道现在可以运行多个实例，每个实例绑定到单个代理或代理团队。支持微信、WeCom 智能机器人、飞书、钉钉、QQ、Telegram、Slack、Discord 等。

⏰ 计划任务升级

现在可以从控制台创建和管理计划任务，并添加通道接收者和执行记录：

  • 手动创建任务：直接在任务页面创建、编辑和运行任务，并选择通道实例和接收者。
  • 频道收件人管理：维护每个频道实例的 trusted 收件人，因此可以将任务传递给指定的收件人，而不仅仅是创建它的频道。感谢@dajiao Huang (#3043)
  • 执行记录：新的执行记录页面可让您查看历史列表和每次运行的详细信息。谢谢@mengluo04 (#3107)
  • 并发更新修复：修复了并发更新时丢失的任务（感谢@Whxuan0701 #3062）。

📊 上下文使用可视化

上下文消耗现在可见且可控，使代币成本更易于管理：

  • 上下文使用视图：环形视图取代了之前的清晰上下文按钮，并显示了构成上下文的完整详细信息。
  • 上下文操作：在环形视图下方，您可以触发智能压缩、清除上下文或设置最大上下文大小。
  • 上下文计算：使用情况细分是根据模型报告的使用情况自动得出的，agent_max_context_tokens 可用作用户可配置的成本上限。

感谢@chimyves (#3087)、@sufan721 (#3079)

🤖 模型能力

  • 新模型：添加了 deepseek-flash (DeepSeek V4.1 Flash)、gpt-6-astra、claude-fable-5-1、qwen3.8-flash、glm-5.3-flash、gemini-3.8-flash 和视觉模型 deepseek-v4-flash-vision-exp（感谢 @a1094174619 #3094）。
  • 模型回退：在“模型配置”>“主要模型”下配置一个回退模型，该模型会在主要模型发生故障时自动接管，从而防止因单个提供程序中断而造成中断。谢谢@alanyz106 (#3099)
  • 六个新的搜索提供商：
    • AnySearch（支持匿名模式）。感谢@WangPan59 (#3083)
    • Serply（Google/Bing SERP API）。谢谢@googio (#3071)
    • 并行搜索。谢谢@georgeatparallel (#3116)
    • Tavily（搜索针对法学硕士优化的 API）。谢谢@1printf (#3124)
    • SearXNG（自托管搜索引擎，仅需要实例 URL）。谢谢@1printf (#3124)
    • Keenable（支持匿名模式，无需 API 密钥）。感谢@ilya-bogin-keenable (#3122)

📝 工作区文件编辑

现在可以直接在 Web 控制台和桌面 client 中编辑和保存工作区文件、长期记忆文档和技能定义：

  • 就地编辑：可以直接编辑工作区、内存和技能模块中的文本文件（Markdown、代码、CSV、HTML、纯文本等），键盘快捷键为 Ctrl+S 保存、Esc 退出、Tab 缩进。
  • 安全保存：保存时检查文件打开时的修改时间是否存在冲突；如果代理同时更改了文件，系统会首先询问您而不是覆盖它。关闭面板、切换文件、切换会话或切换工作区会提示确认未保存的更改。

谢谢@zkjqd (#3076)

📦 如何升级

  • 源部署：运行 cow update 进行一 click 升级，或拉取最新代码并重新启动。参见【升级指南】(https://docs.cowagent.ai/guide/upgrade)。
  • 桌面 client：检查更新并使用 client 内的一个 click 进行更新，或从 下载页面 获取最新版本。
