caddy v2.11.7

此补丁版本修复了 2.11.6 的回归问题，包括通过 HTTP/2 代理时的崩溃以及一分钟后被切断的流。 如果您使用的是 2.11.6，我们建议升级。 它还添加了对全新 Incremental 标头字段 (RFC 10036) 的支持。

非常感谢我们的赞助商提供的资源让项目保持活力，也感谢我们的维护人员在这个残酷的人工智能新时代孜孜不倦地进行分类和协助。

亮点

  • 修复：由新的空闲超时引起的崩溃和丢失的流。 2.11.6 引入了默认的空闲读/写超时，这导致了一些问题：

    • 在 2.11.6 中，请求正文的空闲截止时间可能比设置它的处理程序寿命更长：

      • 通过 HTTP/2，当反向代理在处理程序返回后仍在读取请求正文时，Caddy 可能会因 nil 指针取消引用而出现恐慌。 （#8101）
      • 通过 HTTP/1.1，对带有正文的请求的流式响应（例如使用 POST 打开流的 SSE clients）在读取正文后恰好 60 秒被切断。 （#8103）

      两者均已在 #8107 中修复。谢谢@steadytao！

    • 通过 HTTP/2，在写入之间暂停时间超过 write_idle（默认情况下 1 分钟）的流响应（例如安静的 SSE 流）会因流错误而重置。如文档所述，只有停止的写入才应计数。谢谢@WeidiDeng！ （＃8118，＃8119）

  • 修复：丢失 cookie 的占位符再次为空。 自 2.11.6 起，保留未知占位符的位置（如 respond 标头）会在 cookie 不在请求中时逐字输出 {http.request.cookie.*}。对于普通 HTTP 请求，{http.request.tls.*} 也发生了同样的情况。两者又都空了。谢谢@steadytao！ (#8019)

  • 新功能：支持 Incremental 标头字段 (RFC 10036)。 它是 NGINX 专有 X-Accel-Buffering 标头的标准替代品。如果上游响应有 Incremental: ?1，reverse_proxy 会立即转发它，与 flush_interval -1 相同，并且 encode 会对其进行流式传输而不是阻止它。非常适合 Mercure、SSE 和其他流媒体应用程序。

    • 如果 request_buffers 或 response_buffers 选项会阻止增量转发，Caddy 将使用 501 Not Implemented 进行响应，而不是按照 RFC 的要求进行静默缓冲。
    • 新的 proxy_status_name 选项向这些响应添加了 Proxy-Status 标头，解释消息被拒绝的原因。

    谢谢@dunglas！ （#8020）

  • 更快的 TLS 握手： 当没有任何内容订阅证书事件并且调试日志记录关闭时，CertMagic 不再为每次握手构建事件数据。每次握手的证书查找速度大约是原来的两倍，分配了 10 次而不是 15 次。感谢 @u5surf！ （#8010）

  • Unix 套接字： 当重新加载将侦听器（或管理端点）移出 Unix 套接字时，旧套接字现在会立即关闭，并且其文件将被删除。之前，连接到旧路径的 clients 将挂起，直到大约 2 分钟后进行下一次垃圾回收。谢谢@littfed！ （#8061）

  • 标头处理程序： JSON 配置的 set 中的多个 Set-Cookie 值现在作为单独的标头字段发送，而不是用逗号连接到 clients 无法解析的一个字段中。谢谢@Indra55！ （#8080）

  • caddy fmt 不再删除输入末尾的左大括号。谢谢@n0liu！ (#8047)

发生了什么变化

  • events：告诉 CertMagic 哪些事件值得 @u5surf 在 https://github.com/caddyserver/caddy/pull/8010 中发出
  • 壮举：通过 @dunglas 在 https://github.com/caddyserver/caddy/pull/8020 中实现增量标头字段 (RFC 10036)
  • caddyfile: 保留一个左大括号，以 https://github.com/caddyserver/caddy/pull/8047 中的 @n0liu 结束输入
  • 侦听器：立即关闭 unix 套接字，并在 https://github.com/caddyserver/caddy/pull/8061 中的@littfed 重新加载时取消链接文件 *反向代理：稳定@steadytao在https://github.com/caddyserver/caddy/pull/8049中的半关闭测试
  • caddyhttp：将缺失的可选占位符保留为空，作者：https://github.com/caddyserver/caddy/pull/8019 中的 @steadytao
  • headers：在https://github.com/caddyserver/caddy/pull/8080中通过@Indra55保留单独的Set-Cookie值
  • caddyhttp：通过https://github.com/caddyserver/caddy/pull/8107中的@steadytao结束请求主体截止日期所有权
  • 超时：修复空闲写入器在 https://github.com/caddyserver/caddy/pull/8119 中 @WeidiDeng 写入之间终止 h2 响应写入器
