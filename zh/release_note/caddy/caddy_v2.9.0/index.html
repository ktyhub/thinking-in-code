caddy v2.9.0

新年快乐！我们很高兴发布 Caddy 2.9。除了一些小的新功能外，此版本主要集中在许多领域的改进和错误修复，包括：

  • 配置加载
  • 活动
  • 日志记录
  • 占位符
  • 反向代理和 HTTP 服务器性能
  • 匹配器
  • HTTP（尤其是 HTTP/3）
  • 指标（每个主机指标）
  • 安全
  • TLS 自动化和 ACME ARI 我们意识到人们对加密 Client Hello (ECH) 和后量子密码有广泛的兴趣。 Go 1.24 预计将支持这些功能，并计划在 2 月份左右发布稳定版本。我们不想强迫用户经历安装 Go 的预发布、非库存安装的不便，即使 RC 非常稳定并且可以用于生产，甚至可以编译 Caddy，考虑到我们的插件生态系统，这很常见。我们预计在不久的将来，基于 Go 1.24 构建的 Caddy 2.10 版本将具有这些功能。 我们希望您会喜欢 2.9 版本。感谢所有贡献者、错误报告者和帮助者，以及那些将预发布版本部署到生产环境以帮助验证补丁和功能的组织。
