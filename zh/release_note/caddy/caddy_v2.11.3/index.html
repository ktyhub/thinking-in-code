caddy v2.11.3

此版本通过小功能、错误修复和安全补丁改进了 Caddy 的多个方面。感谢所有为使此版本成为迄今为止最好的版本做出贡献的所有人和他们的机器人！

安全补丁：

  • fastcgi：继承了 FrankenPHP 的补丁，以解决可能允许执行非 PHP 文件的错误；由 @dunglas、@KC1zs4 和 @chenjj 合作。
  • vars：@everping 和 @vnxme 合作对 https://github.com/advisories/GHSA-m2w3-8f23-hxxf, 进行了更彻底的修复。
  • admin：数组索引规范化，以防止远程管理套接字身份验证绕过，由 @Amemoyoi 和 bot 提供。
  • admin：更严格的路径前缀匹配，以防止远程管理套接字身份验证绕过，由 @Amemoyoi 和 bot 提供。

我们还合并了几个 PR，修复了 quic-go 和 CertMagic 等其他项目中的上游安全错误。感谢@marten-seemann 如此努力地维护 quic-go！
