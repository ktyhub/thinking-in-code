opentelemetry-java-instrumentation v2.30.0

opentelemetry-java-instrumentation v2.30.0

此版本针对 OpenTelemetry SDK 1.64.0。

请注意，许多工件的版本号都附加了 -alpha 后缀，这表明它们将继续进行重大更改。请参阅 VERSIONING.md 了解更多详细信息。

⚠️ 对不稳定的 API 进行重大更改

  • 删除 ExperimentalInstrumentationModule#getModuleGroup()。内置的 invokedynamic 模块现在共享一个 InstrumentationModuleClassLoader，并且每个扩展都是独立的。 (#18859)
  • 删除已弃用的 InstrumentationModule.isIndyModule()；模块是否使用 invokedynamic 现在由代理确定，而不是按模块声明。 (#19140)
  • 从 SqlClientAttributesGetter、CassandraRequest 和 Experimental 中删除已弃用的与查询相关的 API。 (#19165)
  • 从 Spring Security 6.0 库中删除已弃用的 Enduser* 属性捕获 API；请使用 User* 替代品。 (#19168)

🚫 弃用

  • 仅弃用与实验性声明性配置一起使用的 Spring Boot 启动器 ConfigProperties 兼容性 bean，转而使用新的 ConfigProvider bean；它将在 3.0 中被删除。 ConfigProperties bean 仍然支持非声明性配置。 (#19175)
  • 弃用 DeclarativeConfigPropertiesBridge 和 DeclarativeConfigPropertiesBridgeBuilder。直接使用DeclarativeConfigProperties或代替DeclarativeConfigBridge。将在3.0中被移除。 (#19202)
  • 弃用 ConfigPropertiesBackedConfigProvider，转而使用 DeclarativeConfigBridge。它将在 2.31.0 中被删除。 (#19220)

🌟 新的 javaagent 检测

  • 为 HBase client 1.4 添加 Javaagent 检测。 (#19087)

🌟 新的库工具

  • 为 Apache Thrift 0.13 异步服务器添加库检测 (ThriftTelemetry)。 (#19062)

📈 增强功能

  • 将异步服务器跟踪添加到 Apache Thrift 0.13 javaagent 检测；异步服务器处理程序以前未进行检测。 (#18994)
  • 从 MSSQL JDBC URL 提取 db.name 时，支持 database= 作为 databaseName 的别名。 (#19029)
  • 为跨数据库工具的实验性稳定数据库语义约定选择加入 (otel.semconv-stability.opt-in=database) 添加批处理操作支持，包括批处理范围名称、db.operation.batch.size（包括空批处理）和 db.query.summary。 (#19034、#19037、#19054、#19055、#19056、#19057、 #19143、#19147、#19161、#19162、#19164、#19172、 #19189、#19199)
  • 添加对 Lettuce 4.0 反应命令的跟踪，包括异常完成和取消。 (#19071)
  • 添加实验性 Cassandra JMX 指标目标系统。 (#19080)
  • 为 Java 19+ 虚拟线程添加实验性基于 JFR 的 jvm.thread.virtual.pinned 和 jvm.thread.virtual.submit_failed 指标；通过 otel.instrumentation.runtime-telemetry.emit-experimental-jfr-metrics=true 启用。 (#19092)
  • 捕获在查询参数属性中传递给 PreparedStatement.setObject() 的自定义对象值。 (#19093)
  • InstrumentationModule 现在公开了用于 indy 仪器的 injectedClassNames() 和 exposedClassNames()，因此模块作者不再需要 ExperimentalInstrumentationModule 来进行这些帮助程序类声明。 (#19142)
  • 将 captureTemplate 和 captureArguments 选项添加到 log4j、java-util-logging 和
