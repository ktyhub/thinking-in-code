opentelemetry-java-instrumentation v2.26.0

小版本 发布时间2026年3月14日 来源open-telemetry/opentelemetry-java-instrumentation 英文原文

opentelemetry-java-instrumentation v2.26.0

此版本针对 OpenTelemetry SDK 1.60.1。

请注意，许多工件的版本号都附加了 -alpha 后缀，这反映出它们仍然是 alpha 质量，并将继续进行重大更改。请参阅 VERSIONING.md 了解更多详细信息。

⚠️ 对不稳定的 API 进行重大更改

  • 删除已弃用的 AWS Lambda v2.2 包装器和 forceFlush(int, TimeUnit) 重载 (#16170)
  • 删除已弃用的 HTTP client/服务器方法 (#16167)
  • 删除已弃用的数据库检测方法和类（#16164）
  • 删除已弃用的对等服务映射 APIs (#16165)
  • 使运行时遥测弃用的类现在成为内部的（#16173）
  • 删除 AttributesExtractorUtil (#16152)
  • 从 SqlClientAttributesGetter 中删除标记接口（#16205）
  • 将网络/服务器 getter 方法合并到数据库属性 getter 中（#16264、#16268）
  • 将 SQL 清理程序类重命名为 SQL 分析器 (#16269)
  • 重命名内部通用模块包以遵循新的命名约定（#16284、#16308、#16327、#16341、#16373)

🚫 弃用

  • 弃用单个运行时遥测模块类，转而使用统一模块（#16087）
  • 弃用旧的 HTTP 服务器查询参数方法，转而支持敏感查询参数处理 (#16097)
  • 弃用旧的 RPC 属性 getter 方法，转而支持支持稳定语义约定的新方法 (#16130)
  • 作为简化的一部分，已弃用旧的 ClickHouse 检测方法（#16206）
  • 弃用旧的 R2DBC 方法，转而支持支持 db.system.name 的方法（#16251）
  • 已弃用旧的 DbClientAttributesGetter 方法；添加了 getErrorType() 及其实现（#16276）
  • 弃用旧的 RPC 指标方法，转而采用支持稳定语义约定的方法（#16298）
  • 已弃用旧的 DbClientAttributesGetter 方法；添加了 getDbName() 以更好地支持旧的/稳定的 semconv 分割（#16318）

📈 增强功能

  • 添加 Spymemcached 的服务器地址和端口属性 (#15242)
  • 添加 Kafka Connect 作为内置 JMX 指标目标 (#15561)
  • 将 Lettuce 仪器转换为使用 Instrumenter (#15838)
  • OpenSearch Java client：捕获经过净化的搜索查询主体（#15634）
  • 将稳定的语义约定应用于 Camel JMX 指标 (#16088)
  • 添加 jvm.file_descriptor.limit 公制 (#16174)
  • 使用父上下文运行 gRPC client 回调（#16175）
  • SQL 摘要：处理 EXPLAIN 语句 (#16184)
  • 简化 InfluxDB 检测 (#16207)
  • 更新 db.client.operation.duration 的直方图桶（#16222）
  • SQL 摘要：支持 Oracle dblink 语法 (#16230)
  • 添加 ZIO HTTP 服务器路由检测（#16232）
  • 删除数据库稳定 semconv 标志下的网络属性 (#16257)
  • 支持 Javalin 7 (#16261)
  • gRPC：初始稳定的 semconv s
