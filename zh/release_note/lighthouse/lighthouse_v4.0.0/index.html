lighthouse v4.0.0

大版本 发布时间2019年1月16日 来源GoogleChrome/lighthouse 英文原文

lighthouse v4.0.0

新贡献者！

@mattzeunert、@dima74、@jeffbcross、@knoxmic 和 @shogunsea。谢谢！

主要变化

  • 一系列错误修复和性能改进。
  • 获得满分的特殊奖励。
  • PWA 类别的新布局，强调速度、可安装性和完善性。

重大变更

  • 新的 PWA 类别、组织和评分 (#6395)
    • 报告的 PWA 部分有一组徽章，而不是数字分数表（#6526、#6670）
    • webapp-install-banner 审核现在为 installable-manifest (#6630)
    • 以前在webapp-install-banner中的离线检查是新的审计offline-start-url（[#6397]（https://github.com/googlechrome/lighthouse/pull/6397））
  • 审计的 scoreDisplayMode 'not-applicable' 现在是 'notApplicable' (#6783)
  • 由于性能成本而删除了 no-websql 审核 (#6293)
  • speed-index 评分现在根据节流进行缩放（#7007）
  • 空子数组现已从 critical-request-chain 审核结果中删除 (#6211)
  • 现在使用正确的 Nexus 5X 屏幕高度 660，而不是 732 (#6932)
  • mobile3G 下的节流常数重命名为更准确的 mobileSlow4G，值没有变化 (#6163)
  • typescript 定义文件现在位于 types/ 下 (#6617)
  • 计算的工件文件现在位于 lighthouse-core/computed/ 下（#6618） <小时> 完整 Changelog（除了 4.0.0-beta、4.0.0-alpha.1 和 4.0.0-alpha.0 的更改外）

核心

  • 配置：重新排序类别以匹配新的分数计顺序（[#6848]（https://github.com/googlechrome/lighthouse/pull/6848））
  • 驱动程序：处理 Driver.gotoURL 内的导航拒绝（#6739）
  • 驱动程序：使用不安全证书测试页面时提前退出（#6608）
  • 跟踪时驱动程序：waitForFCP (#6944)
  • 处理无效的网络计时数据 (#6780)
  • 修复 ImageElement 的 usesObjectFit 属性 (#6761)
  • 字体：解析相对于样式表的 URL (#6782)
  • 灯笼：删除不必要的排序调用（#6900）
  • Lantern: 从错误消息中删除节点 ID (#6774)
  • 缩小：正确处理正则表达式字符类（#6745）
  • 预连接：如果未使用预连接链接，则添加警告 (#6694)
  • 预加载：发出重复请求时发出警告（#6849）
  • scoreDisplayMode: 将 'not-applicable' 更改为 'notApplicable' (#6783)
  • service-worker: 检查 start_url 是否在 SW 的范围内 (#6678)
  • speedindex：基于节流的尺度评分系数（#7007）
  • 点击目标：用于使用 ClientRects 的辅助函数（#6703）
  • url: 添加 Intent 协议到 NON_NETWORK_PROTOCOLS (#6711)
  • 用户计时：进入计算工件（#6719）
  • 将 displayValue 更改为仅字符串 (#6767)
  • 添加类型检查到 pwmetrics-events (#6980)
  • 更严格的 LR 桌面指标评分 (#6969) *页内函数重构（#6702）

部门

  • 将 axe-core 更新到最新版本 (#7020)
  • 将详细信息-元素-polyfill 更新为 2.2.0 (#6928)
  • 将 tsc 更新为 3.2.2 (#6684)
  • snyk: 更新 snyk 快照 (#6888, #6842)

文档

  • 自述文件：将 speedrank 添加到集成列表 (#6987)
  • 自述文件：添加了有关安装选项的简单指南（#6810） *configuration.md：更新 pwmetrics 的链接（[#6816]（https://github.com/googlechrome/lighthouse/pull/6816））
  • 评分：更新 TTI 参考文献 (#6865)
  • --help：使用 HTTPS 链接到 bit.ly/chrome-flags (#6692)
  • 要求人们首先测试上游的 a11y 问题 (#6764)

扩展

  • 从 runLighthouseInExtension() 返回 runnerResult (#6839)

国际化

  • 本地化 LighthouseError 消息 (#6457, #6812)

报告

  • PWA：向徽章仪表添加工具提示（#6689）
  • 为已通过的有警告的审核添加顶级部分 (#6989)
  • 庆祝所有 100 岁 (#5455)
  • 默认情况下展开“通过审核”中的组 (#6930)
  • 修复分数计包装纸上的边距（#6948、#6972）
  • 支持窄屏幕 (#6857)
  • 审计组摘要的空白更大 (#6688) *清理更多的丛/组/可扩展的残骸（#6982）

测试

  • Smokehouse：在期望中断言 errorCode (#6851)
  • 熏制室：使用节点的原生 URLSearchParams (#6929)
  • 添加类型检查到 cli/tests/ (#6874)
  • 报告：恢复旧的、禁用的失败分组测试（#7006）

其他

  • 描述：更准确的指标描述 (#6508)
  • 模拟：使用正确的 Nexus 5X 屏幕尺寸 (#6932)
  • snyk：仅保留可检测库的漏洞数据（[#6919]（https://github.com/googlechrome/lighthouse/pull/6919））
  • 清理配置中的本地名称（#6950）
