lighthouse v12.5.0

全Changelog 我们预计此版本将在 Chrome 136 的 DevTools 中发布，并在 2 周内发布到 PageSpeed Insights。

显着变化

  • legacy-javascript 已更新为目标 Baseline 而不是 esmodules，用于确定哪些代码被视为“遗留”（#16366）。

核心

  • 启用增强跟踪，将源映射传递给跟踪引擎 (#16396)
  • 将灯笼设置传递给跟踪引擎并添加日志记录 (#16377)
  • 使跟踪引擎 i18n 功能适应 LH i18n 模型 (#16365)
  • 计算工件：不允许未定义的属性 (#16397) *重复-javascript：将阈值从 1 KiB 增加到 10 KiB (#16368)
  • image-delivery-insight：使用字符串而不节省（#16364）
  • 见解：实施 use-cache-insight (#16401)
  • 见解：升级并实施强制回流 (#16395)
  • 见解：默认移至隐藏组 (#16391)
  • 见解：实现字体显示见解 (#16369) *传统-javascript：返工/恢复一些未缩小的捆绑包检测（[＃16394]（https://github.com/GoogleChrome/lighthouse/pull/16394）） *传统-javascript：支持汇总捆绑包（[#16389]（https://github.com/GoogleChrome/lighthouse/pull/16389））
  • 旧版-javascript：支持 esbuild 捆绑包 (#16385) *传统-javascript：支持未缩小的代码（[#16384]（https://github.com/GoogleChrome/lighthouse/pull/16384）） *传统-javascript：改进变换检测（[#16381]（https://github.com/GoogleChrome/lighthouse/pull/16381））
  • script-treemap-data：折叠节点时保留重复信息（#16379）

部门

  • 升级依赖 (#16408)
  • 将trace_engine升级到0.0.47 (#16376)
  • 升级trace_engine，重用cdt bf-cache/弃用字符串（#16362）

国际化

*导入（[#16409]（https://github.com/GoogleChrome/lighthouse/pull/16409））

测试

  • 修复本地摩卡测试未正确设置 isUnderTest (#16399)
  • 修复节点 20.19 中的 i18n 格式 (#16398)
  • 跟踪引擎：修复期望 (#16380)

其他

  • 将支持文件移动到 core/lib/legacy-javascript (#16393)
  • 将旧版 javascript 检测提取到 core/lib (#16392)
  • 构建：使用当前年份作为捆绑许可证版权标头（#16375） *树形图：重组标题以匹配新设计（[#16402]（https://github.com/GoogleChrome/lighthouse/pull/16402））
