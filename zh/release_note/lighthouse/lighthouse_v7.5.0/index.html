lighthouse v7.5.0

全Changelog 我们预计此版本将在 Chrome 92 的 DevTools 中发布，并在 2 周内发布到 PageSpeed Insights。

显着变化

我们正在发布灯塔树状图！ 感谢 webtreemap（我们使用！）或 source-map-explorer，您可能已经熟悉树形图。借助 Lighthouse 树状图，您可以从 Lighthouse 报告中轻松查看页面上的所有 JavaScript 捆绑包，此外还可以提供一些有助于减少页面上 JavaScript 数量的见解。唯一的要求是源地图可访问（公开地或从运行 Lighthouse 审核的同一台计算机安全地访问）。 我们甚至从 Chrome 收集代码覆盖率数据，并推断捆绑包中各个模块的覆盖率： 注意：这仅考虑冷加载：仅在用户交互后使用的代码将被标记为未使用。请继续关注未来的版本，这将使您能够配置用户流并捕获更准确的性能见解。 如果我们检测到多个捆绑包包含一个大模块，我们也会向您发出警报。 您可以从报告中访问 Lighthouse Treemap： 目前，只有使用 Lighthouse 节点 CLI 生成的报告才会连接到 Lighthouse 树状图应用程序。我们正在努力将此功能添加到 DevTools 和 PageSpeed Insights 中的 Lighthouse 中。 演示
