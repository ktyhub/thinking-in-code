  • oopif：附加到所有后代（[#7608]（https://github.com/googlechrome/lighthouse/pull/7608））
  • oopif：跳过某些收集器中的 OOPIF 网络记录 (#7640)
  • 优化图像：执行时间上限为 5 秒 (#7237)
  • 设置：添加灯塔通道 (#7312)

  • 使用-http2：忽略来自 service-worker 的请求 (#7197)

文档

  • 添加插件配方 (#6965)
  • 自述文件：Foo 集成 (#8035)
  • url-shim: 添加公共后缀 lst 的注释 (#7671)

Clients

  • devtools：重构构建脚本（[#7421]（https://github.com/googlechrome/lighthouse/pull/7421），[#7567]（https://github.com/googlechrome/lighthouse/pull/7567））
  • lr：始终使用 X-TotalFetchedSize 标头中的 TransferSize (#7478)
  • lr：从标头收集网络计时数字（[#7888]（https://github.com/googlechrome/lighthouse/pull/7888））
  • lr：添加自定义配置支持（[#7613]（https://github.com/googlechrome/lighthouse/pull/7613））

测试

  • 更好的致命跟踪逻辑错误覆盖率 (#7959)
  • 修复测试覆盖率生成（#7475）
  • 完成移除摩卡咖啡 (#7429)
  • 升级 jest 以修复当前节点 11 版本 (#7413)
  • Smoke：从期望中删除 rawValue 的琐碎使用（[#7780]（https://github.com/googlechrome/lighthouse/pull/7780））
