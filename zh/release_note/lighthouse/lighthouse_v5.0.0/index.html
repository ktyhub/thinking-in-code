lighthouse v5.0.0

#5.0.0 (2019-05-07) 全Changelog

主要新功能

  • 堆栈包 是在 Lighthouse 报告中呈现堆栈特定建议的新方法。此初始版本会检测站点是否在 WordPress 上运行，并向报告中添加有关如何利用 WordPress 插件和配置来提高性能的附加信息（#7243、#8169、#8633、#8536、 [#8778]（https://github.com/googlechrome/lighthouse/pull/8778））。
  • 性能预算 是 Lighthouse 的一项新功能，可帮助防止您的网站性能随着时间的推移而下降。设置页面应加载的资源的预算，并在未满足预算时发出 Lighthouse 警报（#8539、#8522、#8727、#8709、#8427、 #8708)。
  • Lighthouse 插件 是一种向 Lighthouse 运行添加自定义检查的新方法。它们与标准结果一起（或代替）显示在 Lighthouse 报告中，并且可以利用 Lighthouse 中的工具和结果来完成工作。请参阅文档中的示例 (#8728)。
  • 如果您在看完所有屏幕截图后没有注意到，HTML 报告已重新设计！

新审核

  • apple-touch-icon PWA 审核（#8857）
  • performance-budget (#8539)
  • resource-summary (#8522)
  • max-potential-fid（之前在 JSON 输出中，在 HTML 报告中新增）（#8729、#8817）

重大变更

  • 现在需要节点 10 (LTS) 或更高版本 (#8117)
  • rawValue 已从审核结果中删除。如果审核有有意义的数字结果（如指标），则该结果现在将位于 numericValue（#8343、#8385、#8421）
  • 可访问性类别评分已根据严重性重新加权 (#8823)
  • FCP 准确性已提高（在“模拟”节流中），并且可能会显着影响分数 (#7513)
  • 已弃用的 --disable-device-emulation 标志已被删除。使用 --emulated-form-factor（#8289、#8334）
  • dom-size 现在忽略 <head> 中的元素，并将评分限制为仅在正文中的 DOM 节点 (#7241)
  • diagnostics 审核详细信息的 type 值已更改为 debugdata (#8298)
  • screenshot-thumbnails 屏幕截图的格式已更改。它们现在是完整的图像数据 URL (#8299)
