小版本 发布时间2026年6月23日 来源docker/compose 英文原文

compose v5.2.0

发生了什么变化

ℹ️ 该版本在观察状态和预期状态之间引入了新的协调算法。

如果您之前运行的 Compose 工作负载遇到任何问题，请提出问题。

✨ 改进

  • @ndeloof 和 @glours 在 https://github.com/docker/compose/pull/13830 中的和解计划
  • 通过 @rajyan 在 https://github.com/docker/compose/pull/13742 中为提供商插件添加 rawsetenv 消息类型

🐛 修复

  • 修复（构建）：从 https://github.com/docker/compose/pull/13816 中的 @ndeloof 跳过烘焙 fs.read 允许列表中的远程 URL 上下文
  • 在https://github.com/docker/compose/pull/13831中通过@scarab-systems提取配置变量时跳过验证
  • 修复（进度）：通过 https://github.com/docker/compose/pull/13837 中的 @glours 探测 stderr（而非 stdout）以进行 TTY 自动检测
  • 修复（发布）：需要荣誉 env_file：@Ijtihed 在 https://github.com/docker/compose/pull/13848 中丢失的文件为 false

🔧 内部

  • 文档：撰写日志：添加 @thaJeztah 在 https://github.com/docker/compose/pull/13806 中自/直到标志描述的链接
  • Ci：通过 @securityeng-bot[bot] 在 https://github.com/docker/compose/pull/13820 中添加 Dependabot 冷却时间 (20260603-170456)
  • 文档（CLAUDE.md）：请注意，提交必须由 https://github.com/docker/compose/pull/13817 中的 @ndeloof 签署（DCO）
  • 重构：将循环中的 Split 替换为更高效的 SplitSeq，并将 HasPrefix+TrimPrefix 替换为 https://github.com/docker/compose/pull/13810 中 @caltechustc 的 CutPrefix
  • 杂务：修复一些注释以提高 https://github.com/docker/compose/pull/13823 中 @solunolab 的可读性
  • GHA：更新文档上游以将工作流程固定在 https://github.com/docker/compose/pull/13834 中的 sha by @thaJeztah
  • 文档：撰写日志：在 https://github.com/docker/compose/pull/13833 中添加 @thaJeztah 的标志描述的更多链接
  • 修复/进度 tty 线路溢出 13595 by @glours in https://github.com/docker/compose/pull/13840
  • 修复（发布）：通过 @ptrdom 在 https://github.com/docker/compose/pull/13825 中绕过 Docker 桌面代理进行环回注册表
  • 观察：在 https://github.com/docker/compose/pull/13856 中@ndeloof 更改文件时不要重建 dependent_on 服务
  • pkg/e2e：通过 @thaJeztah 在 https://github.com/docker/compose/pull/13857 中修复固定装置中格式错误的 JWT
  • pkg/e2e：通过 https://github.com/docker/compose/pull/13867 中的 @glours 从 getEnv 中删除未使用的运行参数
  • 文档：ps --format json 输出 JSON 行，而不是 @glours 在 https://github.com/docker/compose/pull/13868 中的 JSON 数组
