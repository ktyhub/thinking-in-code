compose v5.5.0

小版本 发布时间2026年8月17日 来源docker/compose 英文原文

compose v5.5.0

发生了什么变化

ℹ️ 此版本彻底修改了图像摘要协调，以防止不必要的容器重新创建。
升级后首次运行 compose up 时，可能会重新创建现有容器，因为使用新逻辑重新评估映像摘要。

compose pull 现在支持 pull_policy 刷新窗口（daily、weekly、every_N）。

✨ 改进

  • @glours 和 @ndeloof https://github.com/docker/compose/pull/14011 https://github.com/docker/compose/pull/14041 的新图像摘要协调流程

🐛 修复

  • 修复（桥接）：跳过为仅构建服务拉取默认图像引用…由 @ericwyles 在 https://github.com/docker/compose/pull/14010 中

  • 修复(config): 解决 https://github.com/docker/compose/pull/14002 中 @glours 计算 —hash 时的服务环境
  • 修复（手表）：跳过不可读的目录，而不是通过 @Endika 在 https://github.com/docker/compose/pull/13992 中使手表失败
  • 修复：忽略https://github.com/docker/compose/pull/14038中@brano-osif向上监视器中的一次性容器事件
  • 修复（bridge）：通过@glours在https://github.com/docker/compose/pull/14003中验证bridge子命令的参数
  • 修复（图像）：允许https://github.com/docker/compose/pull/14028中@ndeloof删除图像记录的容器
