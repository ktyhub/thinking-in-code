helm v4.2.1

Helm v4.2.1 是一个补丁版本。我们鼓励用户升级以获得最佳体验。

社区不断发展，我们很高兴在那里见到您！

  • 加入Kubernetes Slack中的讨论：
    • 提出问题并闲逛
    • 用于讨论 PR、代码和错误
  • 参加公共开发者电话会议：星期四，太平洋时间 9:30，通过 Zoom
  • 测试、调试和贡献图表：ArtifactHub/packages

显着变化

  • 修复了当并发 goroutine（升级 + 回滚、安装 + 卸载）都在同一个 FailingKubeClient 实例上调用 GetWaiterWithOptions 时，由 -race 标志检测到的数据竞争问题 #31925
  • 修复了写入 stderr 而不是 stdout 的 helm 命令成功消息。现在可以正确输出到 stdout #32056
  • 修复了 Helm 4 在使用版本范围限制时发出“无法找到确切版本”的问题 #31757
  • 修复了 WaitForDelete 中的竞争条件，其中状态观察器过早取消监视，导致运行完整测试套件时出现间歇性故障 #32081
  • 将 golang.org/x/net 跳转到 v0.55.0 以解决 GO-2026-5026 #32153
  • 通过升级依赖项修复了 SDK 错误：cli-utils 1.2.1、控制器运行时 0.24.1 和 k8s 1.36.1 #32128
  • 依赖更新
