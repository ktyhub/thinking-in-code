helm v3.22.0

Helm v3.22.0 是一个功能版本。我们鼓励用户升级以获得最佳体验。

社区不断发展，我们很高兴在那里见到您！

  • 加入Kubernetes Slack中的讨论：
    • 提出问题并闲逛
    • 用于讨论 PR、代码和错误
  • 参加公共开发者电话会议：星期四，太平洋时间 9:30，通过 Zoom
  • 测试、调试和贡献图表：ArtifactHub/packages

显着变化

  • 主要是依赖项更新和 k8s-io 组到 0.37.0
