helm v4.2.0

Helm v4.2.0 是一个功能版本。我们鼓励用户升级以获得最佳体验。

社区不断发展，我们很高兴在那里见到您！

  • 加入Kubernetes Slack中的讨论：
    • 提出问题并闲逛
    • 用于讨论 PR、代码和错误
  • 参加公共开发者电话会议：星期四，太平洋时间 9:30，通过 Zoom
  • 测试、调试和贡献图表：ArtifactHub/packages

显着变化

  • 切换到 goreleaser 进行发布版本
  • Kubernetes client 库到 v1.36
  • 增加mustToToml模板功能
  • 弃用未使用的 --hide-notes 和 --render-subchart-notes 标志
  • --dry-run=server 现在尊重 generateName:
