helm v3.21.1

Helm v3.21.1 是一个补丁版本。我们鼓励用户升级以获得最佳体验。

社区不断发展，我们很高兴在那里见到您！

  • 加入Kubernetes Slack中的讨论：
    • 提出问题并闲逛
    • 用于讨论 PR、代码和错误
  • 参加公共开发者电话会议：星期四，太平洋时间 9:30，通过 Zoom
  • 测试、调试和贡献图表：ArtifactHub/packages

显着变化

  • 修复了 ClientOnly 流程中 helm 模板可能发生的零指针恐慌。现在正确返回模板错误 https://github.com/helm/helm/pull/31920
  • 将 golang.org/x/net 跳转到 v0.55.0 以解决 GO-2026-5026 #32152
  • 从 1.25 跳转到 1.26 #32168
  • 依赖版本更新
