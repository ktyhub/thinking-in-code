1.94.0 (2026-10-22)

特点

  • auth: 通过 (01eaba1) 请求代理身份的证书绑定令牌
  • bigquery-jdbc: 添加明确遥测 client (#14607) (c702438)
  • bigquery-jdbc: 公开无作业查询的 QueryStatistics (#14596) (15f472c)
  • bigquery: 从 TableResult 公开 QueryStatistics (#14588) (40b2b1a)
  • bigtable: 添加每个方法的会话转移配置 (#14681) (042dd3e)
  • bigtable: 在会话 client 上支持 SessionCheckAndMutateRow (#14565) (86de9c1)
  • bigtable: 在会话 client 上支持 SessionReadModifyWriteRow (#14585) (8e653b2)
  • firestore: DML (#14703) (11bc071)
  • gax: 实现操作级 client 请求范围 (T3) (#14549) (275063b)
  • gax: 链接尝试跨越到父上下文并在操作完成时清理 (#14459) (0c481bd)
  • gax: 将映射终端可断点续传异常标准化为 ApiException (#14624) (d4961f0)
  • google/devicesandservices/health/v4beta: 添加健康 v4beta (#14600) (95f863c)
  • google/shopping/merchant/reviews/v1: 添加购物商家评论 (#14724) (13310c7)
  • 包含 writerId 作为跟踪 ID 的一部分 (#13488) (ffa8063)
  • 在 LoggingTracer 中记录操作失败时的可操作错误 (#14460) (27559f4)
  • 在 AppendRowsRequest 中填充 client_stats (#14614) (a7a0098)
  • spanner: 添加选项来为每个通道而不是每个池创建 GcpFallbackChannel (#14501) (74f7591)

错误修复

  • api-common: 根据点段验证路径模板变量 (#14641) (4ad59e2)
  • auth: 修复 DownscopedCredentials 和 UrlIdentityPoolSubjectTokenSupplier 中的序列化差距 (#14341) (a3e3324)
  • bigquery-jdbc: 确保 JDBC 默认使用符合 PQC 的算法 (#14560) (b0ffe3d)
  • bigquery-jdbc: 修复异常处理 (#14566) (3e7a206)
  • bigquery-jdbc: 修复丢失的记录器实例 (#14733) (0e822dc)
  • bigquery-jdbc: 修复 pqc 在代理环境中工作 (#14599) (ceb45b4)
  • bigquery-jdbc: 将嵌套 ARRAY 字段格式化为 Struct.toString() 中的有效 JSON (#14720) (bc0126a)
