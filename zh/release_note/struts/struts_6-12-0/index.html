struts 6_12_0

发生了什么变化

  • 为 https://github.com/apache/struts/pull/1827 中 @lukaszlenart 的 Struts 6.12.0 新开发周期做准备
  • WW-5688 当 @lukaszlenart 在 https://github.com/apache/struts/pull/1863 中声明（6.x 向后移植）时，将带有 id 的 REST URI 解析到根命名空间中
  • WW-5700 当 @lukaszlenart 在 https://github.com/apache/struts/pull/1878 中无法转换映射或列表元素时（6.x 向后移植），跳过存储
  • WW-5701 按身份比较转换标记，不等于 https://github.com/apache/struts/pull/1879 中@lukaszlenart 的（6.x 向后移植）
  • WW-5706 将 RestfulActionMapper 操作名称处理与 https://github.com/apache/struts/pull/1881 中的 @lukaszlenart 的 DefaultActionMapper (6.x) 对齐
  • WW-5707 在https://github.com/apache/struts/pull/1883中由@lukaszlenart弃用核心(6.x)中遗留的restful和restful2动作映射器
  • WW-5711 修复（转换）：@lukaszlenart 在 https://github.com/apache/struts/pull/1888 中格式化 BigDecimal 时绑定分数数字
  • WW-5716 通过 @lukaszlenart 在 https://github.com/apache/struts/pull/1903 中绑定 Tiles 插件 (6.x) 中的每个语言环境定义缓存
  • WW-5723 绑定 https://github.com/apache/struts/pull/1913 中 @lukaszlenart 在 REST 插件 (6.x) 中读取的请求正文
  • WW-5724 由 @lukaszlenart 在 https://github.com/apache/struts/pull/1915 中分发缓存的 MessageFormat (6.x) 的克隆
  • WW-5718 修复（rest、bean-validation）：通过 https://github.com/apache/struts/pull/1958 中的 @lukaszlenart 将资源隔离拦截器添加到插件默认堆栈 (6.x)
  • WW-5749 修复（其余）：当 https://github.com/apache/struts/pull/1960 中的 @lukaszlenart 没有目标 (6.x) 时，不从 XML 处理程序中写入任何内容
