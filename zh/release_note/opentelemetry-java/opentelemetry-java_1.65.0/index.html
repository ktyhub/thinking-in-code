opentelemetry-java v1.65.0

小版本 发布时间2026年8月7日 来源open-telemetry/opentelemetry-java 英文原文

opentelemetry-java v1.65.0

注意： opentelemetry-exporter-zipkin 工件已停止发布。它在之前的版本中已被弃用。用户应迁移到 OTLP 或使用与 Zipkin 兼容的收集器导出器。

API

  • 忽略 ImmutableBaggage.put 中的空行李钥匙 (#8658)
  • 在行李解码器中使用 NumberFormatException (#8593)
  • 修复当同一个密钥被删除两次时 TraceStateBuilder.remove 损坏构建器的问题 (#8613)

孵化

  • 将绑定仪器 API（BoundLongCounter、BoundDoubleCounter、BoundLongHistogram、BoundDoubleHistogram、BoundLongUpDownCounter、BoundDoubleUpDownCounter、BoundLongGauge、BoundDoubleGauge）添加到孵化器指标 API (#8527)

扩展

  • 跟踪传播器：修复 JaegerPropagator 行李标头按键大小写敏感度（#8496）
  • 跟踪传播器：不要用 JaegerPropagator 中的空行李覆盖现有行李（#8632）
  • 跟踪传播器：跳过 OtTracePropagator 提取中的空行李键（#8631）
  • 跟踪传播器：在 64 个令牌之后停止解析 jaeger-baggage 标头，包括格式错误的令牌 (#8702)

SDK

  • 更新 SDK 属性实现 (AttributesMap) 以根据 AttributeKey.getKey() 的字符串值强制执行最后值获胜语义 (#8548)

痕迹

  • 添加 Sampler 关闭生命周期：Sampler 现在扩展了 Closeable 并公开了 SdkTracerProvider 关闭时调用的默认 shutdown()； JaegerRemoteSampler 实现它来停止其轮询执行器（#8574）

指标

  • 通过内部遥测版本控制 PeriodicMetricReader 自观测性指标 (#8597)
  • 在 PeriodicMetricReader 中记录失败的集合 error.type (#8650)
  • 测试：修复 LongExemplarAssert.hasFilteredAttributesSatisfyingExactly 以强制执行精确的属性匹配 (#8518)

日志

  • 修复 ReadWriteLogRecord 默认 getObservedTimestampEpochNanos 返回记录时间戳 (#8504)

个人资料

  • 修复配置文件数据模型属性计数参数名称和时间戳文档单元 (#8514)

出口商

  • 警告 Zipkin：删除 opentelemetry-exporter-zipkin；该工件不再发布（#8677）
  • OTLP：在 HttpExporter 警告日志中使用 HTTP 错误响应正文 (#8428)
  • OTLP：修复使用平台默认 trust 存储时的 OkHttpHttpSender mTLS (#8565)
  • OTLP：修复低分配日志封送拆收器中 LogRecord 标志的符号扩展（#8493）
  • OTLP：标准化 OkHttpHttpSender、JdkHttpSender 和 UpstreamGrpcSender 关闭以等待执行器/通道终止（#8495、#8627、#8624）
  • OTLP：当 gRPC 响应帧无效时记录底层异常/离子（#8626）
  • OTLP：避免 Android 上不安全的字符串编码器 (#8637)
  • Prometheus：合并冲突的 Prometheus 标签值（[#8364]（https://github.com/open-telemetry/opentelemetry-java/pull/8364））
  • Prometheus：修复 PrometheusHttpServer.toBuilder() 删除配置的默认处理程序（[#8619]（https://github.com/open-telemetry/opentelemetry-java/pull/8619））
  • 记录：在 SystemOutLogRecordExporter 中输出事件名称 (#8609)
  • 日志记录：包括 LoggingMetricExporter toString 中的聚合时间性 (#8623)

扩展

  • 自动配置：避免在错误消息中暴露配置值（#8669）
  • 声明性配置：修复 Jaeger 采样器轮询间隔配置 (#8668)
  • 声明性配置：删除 DeclarativeConfigPropertyUtil 中重复的 getStringList 解析器 (#8572)
  • 声明式配置：用手动 POJO 生成器替换 jsonschema2pojo (#8600)
  • 孵化器：恢复复合采样器代码和规范之间的合规性（#8450）

垫片

  • 弃用 弃用 OpenCensus shim public API (#8674)
  • OpenCensus：转换为 OpenTelemetry 时保留 OpenCensus 状态描述（#8511）
  • 奥
