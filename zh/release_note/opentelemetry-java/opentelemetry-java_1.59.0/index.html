opentelemetry-java v1.59.0

小版本 发布时间2026年2月6日 来源open-telemetry/opentelemetry-java 英文原文

opentelemetry-java v1.59.0

API

  • 稳定复杂属性 (#7973)
  • 将初始化有效的十六进制数组限制在可以为 true 的范围内 (#7809)

扩展

  • 跟踪传播器：弃用 OtTracePropagator (#8020)
  • 跟踪传播器：弃用 JaegerPropagator (#8019)

SDK

  • 将 io.opentelemetry.sdk.internal 移动到 io.opentelemetry.sdk.common.internal (#8003)
  • 当孵化器可用时，始终返回 ExtendedOpenTelemetry (#7991)

痕迹

  • 修复 SdkSpan#spanEndingThread 中的内存泄漏 (#7984)

指标

  • 返工并发布指标基准 (#8000)
  • 更新 LongLastValueAggregator 算法以避免分配 (#8017)

测试

  • 修复使用嵌套测试类时 OTel JUnit5 扩展清理问题 (#7999)
  • 添加对 Span hasException(null) 的断言支持（#8033）

出口商

  • 弃用：opentelemetry-exporter-zipkin 现已弃用，最后一个版本计划为 1.65.0（2026 年 8 月）（#7974）
  • 重构 http、grpc 发送者并将其推广为公共 API (#7782)

扩展

  • Jaeger 远程采样器：删除未使用的代码 (#7970)
  • 孵化器：添加AlwaysRecordSampler (#7877)

项目工具

  • 对齐生成发布贡献者 (#8023)
