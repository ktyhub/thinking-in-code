opentelemetry-java v1.60.0

小版本 发布时间2026年3月6日 来源open-telemetry/opentelemetry-java 英文原文

opentelemetry-java v1.60.0

API

  • 支持 W3C 跟踪上下文随机标志 (#8012)
  • 澄清 SpanBuilder.setAttribute 允许空值 (#8072)

孵化

  • 实现环境变量上下文传播载体（#8074）
  • 弃用 ExtendedAttributes、ExtendedAttributeKey、ExtendedAttributeType、ExtendedAttributesBuilder (#8060)
  • 弃用 InstrumentationConfigUtil 中的 peerServiceMapping 访问器 (#8088)

SDK

痕迹

  • 使用 TraceIdRatioBasedSampler 作为根采样器时禁用警告（#8065）
  • 用户提供的属性优先于异常派生的属性 (#7993)
  • 从跟踪 SDK 阴影依赖项中排除 META-INF/maven (#8096)
  • 修复 LegacySpanProcessorInstrumentation#finishSpans 中的反转条件 (#8145)

指标

  • 拆分累积存储与增量存储 (#8015)
  • 添加 PeriodicMetricReader 的指标 (#8038)
  • 允许在直方图中配置最小值/最大值 (#8095)
  • 删除已弃用的 otel.experimental.metrics.cardinality.limit 属性 (#8124)
  • 重大错误修复：GlobUtil 和 IncludePatternMatching（用于视图和声明性配置匹配）以前在区分大小写方面不一致。如果存在 glob char（* 或 ?），则按区分大小写的方式对其进行评估。如果不存在全局字符，则以不区分大小写的方式对其进行评估。现在，所有内容都经过区分大小写的一致评估。 （[#8152]（https://github.com/open-telemetry/opentelemetry-java/pull/8152））

日志

  • 稳定 LogRecordBuilder.setException (#8089)
  • 澄清 setTimestamp javadoc 的事件时间戳行为 (#8104)

出口商

  • OTLP：修复空字符串属性的封送处理（#8014）
  • Prometheus：将 Prometheus client 更新为 1.5.0 (#8080)
  • OTLP：将指数直方图和序列化为可选双精度（[#8107]（https://github.com/open-telemetry/opentelemetry-java/pull/8107））
  • OTLP：在 TlsUtil.keyManager() 中使用 KeyManagerFactory.getDefaultAlgorithm() (#8122)
  • OTLP：确保抛出异常时清除原始序列化器 idCache (#8147)

扩展

  • 自动配置：解码资源属性中的加号 (#8059)
  • 声明性配置：更新为 1.0 架构 (#8123)
  • 声明式配置：添加对设置架构 URL 的支持 (#8028)
  • 声明性配置：添加版本不匹配警告（#8069）
  • 声明式配置：在 DeclarativeConfigContext 中缓存组件提供程序（#8070）
  • 声明性配置：添加系统属性替换 (#8073)
  • 声明性配置：添加导出器定制器 (#8081)
  • 声明性配置：添加对设置内部遥测版本的支持（#8045）
  • 弃用查看文件配置机制 (#8133)
  • 自动配置：添加属性以允许自动配置 SDK 遥测版本（#8037）
  • Jaeger 远程采样器：重构以利用发送器 (#8046)
  • 声明式配置：记录 ObjectMapper 配置 (#8075)
  • 声明性配置：删除未检查的警告（#8090）

项目工具

  • 添加架构测试以检测共享内部代码的使用情况（#6978）
  • 将 Xlint 弃用检查替换为自定义的容易出错的检查（#8061） *启用容易出错的 UnnecessarilyFullyQualified 检查（#8078）
  • 小重构使安全性更加清晰（#8083）
  • 返工跨度记录基准并发布结果 (#8031) *添加LogRecordBenchmark（[#8106]（https://github.com/open-telemetry/opentelemetry-java/pull/8106），[#8117]（https://github.com/open-telemetry/opentelemetry-java/pull/8117））

###🙇谢谢 此版本的发布要归功于以下贡献者，他们分享了他们的绝妙想法和出色的成果
