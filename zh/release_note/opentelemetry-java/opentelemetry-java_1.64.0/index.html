opentelemetry-java v1.64.0

小版本 发布时间2026年7月10日 来源open-telemetry/opentelemetry-java 英文原文

opentelemetry-java v1.64.0

API

  • 修复 W3CBaggagePropagator 以允许符合 W3C 规范的空行李值 (#8468)
  • 修复无效百分比编码成员的行李解析 (#8480)

孵化

  • 破坏 删除已弃用的 InstrumentationConfigUtil.peerServiceMapping (#8542)
  • 修复 EnvironmentGetter/EnvironmentSetter，使其不枚举或标准化运营商条目，并一致地标准化空名称（#8474、#8481）

SDK

痕迹

  • 添加 BatchSpanProcessor.create(SpanExporter) 便利工厂到镜像 SimpleSpanProcessor.create(SpanExporter) (#8564)
  • 修复 BatchSpanProcessor 基准辅助计数器 (exportedSpans/droppedSpans) 始终报告零 (#8539)

指标

  • 修复 forEach 期间删除条目时 PooledHashMap 丢弃实时条目的问题 (#8499)
  • 安全初始化 FixedSizeExemplarReservoir 中的示例库存储（#8524）
  • 当导出器繁忙时，在 PeriodicMetricReader 中使用 failExceptionally (#8525)
  • 仅当 false 时才在 AggregatorHandle 中设置 valuesRecorded (#8559)
  • 在 Double/LongLastValueAggregator 中使用 volatile 代替原子 (#8560)
  • 在指标基准中随机化每个线程的记录顺序以避免并发热点（#8550）

日志

  • 修复 BatchLogRecordProcessor 工作线程被非运行时异常杀死的问题 (#8529)

出口商

  • 破坏性 Prometheus：删除已弃用的 PrometheusMetricReader 构造函数（#8541）
  • OTLP：拒绝 EndpointUtil.validateEndpoint 中的无主机端点（#8489）
  • OTLP：用手动实现替换 Jackson OTLP JSON 序列化（#8545）
  • OTLP 配置文件：修复 OtlpGrpcProfileExporter toString 类名 (#8492)
  • Prometheus: 添加翻译策略支持 (#8346)
  • Prometheus：修复数组值作用域和资源属性到 JSON 字符串的序列化 (#8497)

扩展

  • 破坏性 声明性配置：将实验类型移至内部包 (#8530)
  • 声明式配置：将生成的模式 POJO 提交到 git (#8408)
  • 声明性配置：更新为 opentelemetry-configuration v1.1.0 (#8451)
  • 声明性配置：调整 POJO toString/hashCode/equals 以匹配 AutoValue 语义 (#8526)
  • 声明性配置：向生成的模型类添加引用描述 (#8540)
  • 声明性配置：在生成的模型上发出一致的 @JsonProperty 注释（#8563）
  • 声明式配置：删除 DeclarativeConfigPropertyUtil 中重复的解析器（#8579）

项目工具

  • 添加配置策略指导 (#8429)
  • 排除某些 GitHub 操作在叉子上运行 (#8466)
  • 添加偏好参数化测试的指南 (#8469)
  • 使基准路径可配置（#8557）
