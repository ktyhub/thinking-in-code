gpt-researcher v3.7.0

更智能的上下文，无需嵌入

GPT 研究人员现在根据有用性，而不是相似性来选择发送给法学硕士的背景。 针对研究问题抓取的每一篇文章均由 Jev 评分 关于它对于回答这个问题有多大用处，并且只保留有帮助的段落。

以在相同来源上重播的 28 项研究任务为基准：

不需要任何东西。 设置 TYPESAFE_API_KEY 时，使用 Jev。没有一个，或者如果杰夫打电话 失败，GPT Researcher 会回退到本地关键字 (BM25) 排名，因此您不再需要 标准研究的嵌入提供者。报告聊天使用相同的过滤器。

  • 文件：https://docs.gptr.dev/docs/gpt-researcher/gptr/context-filter
  • 基准、方法和代码：evals/context_filter/

⚠️ 需要注意的变化

  • Python 3.12+ 现在是必需的。
  • **默认上下文过滤器：**没有TypeSafe密钥，默认现在是关键字排名而不是 嵌入。它在基准测试中的每个度量上都匹配或击败了嵌入。为了留住旧的 行为，设置 CONTEXT_FILTER=embeddings。

也在这个版本中

  • 检索器插件：通过 gpt_researcher.retrievers 入口点将搜索提供程序作为自己的包发送（#2154）
  • 修复了前端 WebSocket 在新的研究运行中打开第二个连接的问题 (#2159)
  • 多代理部分不再重复彼此的内容 (#2158)
  • 自托管前端资产，无第三方 CDN (#2082)
  • 超过 25 个跨检索器、抓取器和深度研究的社区修复
  • 文档：重新设计的主页，当前模型幻觉排行榜，修复了全新安装的构建

安装： pip install -U gpt-researcher (0.16.0)
