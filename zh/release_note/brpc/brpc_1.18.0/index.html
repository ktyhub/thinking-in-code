brpc 1.18.0

Apache bRPC 1.18.0 扩大了协议覆盖范围和平台支持，并显着强化了解析器和传输内部结构。

特点

  • 添加 MySQL client 协议，包括 @rajvarun77 的无尘室身份验证、文本协议、事务和准备好的语句 (#3330)
  • 支持 TLSv1.3 by @neilxxxxx (#3319)
  • 支持 Protobuf v35 by @wasphin (#3429)
  • 支持 @wasphin 的流控制 gRPC client 请求 (#3430)
  • 通过 @wwbmmm 添加 clients 的 TLS 对等名称验证 (#3408)
  • 支持对附件和正文进行校验和，@yanglimingcn (#3407)
  • 支持 RDMA 握手协议 V3 by @chenBright (#3350, #3326)
  • 支持 RDMA 握手 V3 中的端到端 ECE 协商，作者：@chenBright (#3352)
  • 通过 @zchuago 基于 LD/ST 共享内存语义的 UBShmTransport 进行互连 (#3290)
  • 添加 Power-of-Two-Choices Peak-EWMA (p2c) 负载均衡器，作者：@rajvarun77 (#3367)
  • 添加有界负载一致性哈希 (c_murmurhash_bl) 负载均衡器，作者：@rajvarun77 (#3502)
  • 添加用于零拷贝 I/O 的 IOBuf<->std::iostream 适配器，作者：@chenBright (#3341)
  • 添加@Felix-Gong 的 RISC-V Zvbc 矢量 CRC32C 加速 (#3332)
  • 支持 LeakSanitizer by @chenBright (#3361)

错误修复

  • 通过 @wwbmmm 对公共端口上的内置请求应用身份验证检查 (#3308)
  • 通过 @wwbmmm 修复 HPACK 动态表大小更新递归解码 (#3343)
  • 修复内联 redis 协议消耗 HTTP/2 连接的问题（@rajvarun77）（#3338）
  • 修复 HTTPS 池 client 在意外 SSL EOF 上崩溃的问题，作者：@Felix-Gong (#3316)
  • 通过 @lh2debug-2 修复 rpcz root client 的生命周期 (#3421)
  • 绑定 SSL 握手以防止 @yerixu 泄露 ESTABLISHED 套接字 (#3296)
  • 修复了 @Felix-Gong 的 AdaptiveMaxConcurrency 中的静态初始化顺序失败问题 (#3315)
  • 在连接之前通过 @howzi 设置套接字缓冲区选项 (#3368)
  • @daeho-ro 守护 SO_BINDTODEVICE (#3320)
  • 修复了 @legionxiong 从 RDMA 回退到 TCP 时的竞争问题 (#3406)
  • 修复了 RDMA 握手使套接字失败的问题，而不是回退到 TCP by @chenBright (#3424)
  • 修复了 @chenBright 重新装备 CQ 后 RDMA PollCq 丢失的接收 CQE (#3425)
  • 通过 @chenBright 修复 RDMA 服务器的 Socket::_read_buf 上的数据竞争 (#3505)
  • 修复了 EndRPC 之后的延迟选择性通道重试，作者：@hjwsm1989 (#3359)
  • 修复 @ljcjclljc 的 StreamCreate 失败处理 (#3357)
  • 修复 @lo-tk 添加流失败时的 SetHostSocket (#3386)

  • 在 Bazel 下隐藏 libunwind 的 Unwind* 符号以修复 bthread_tracer 崩溃，作者：@chenBright (#3297)
  • 修复 @wwbmmm 解析空 Redis 命令数组的问题 (#3354)

  • @waterWang 释放并行_http 中的 AccessThreadArgs 数组以避免内存泄漏 (#3491)
  • 通过 @darion-yaphet 从 bthread 中删除未实现的屏障和 rwlockattr API (#3504)
