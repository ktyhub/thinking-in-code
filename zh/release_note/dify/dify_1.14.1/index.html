dify 1.14.1

🚀 v1.14.1 有什么新功能？

v1.14.1 是 v1.14.0 之后的一个补丁版本，专注于安全强化、工作流程和知识库稳定性、部署清理以及持续的 UI 平台迁移。

🔐 安全

  • 自托管 SECRET_KEY 强化 — Docker 部署不再依赖公共默认密钥。当 SECRET_KEY 留空时，API 通过配置的存储后端生成并保留运行时密钥，而显式配置的密钥继续像以前一样工作。感谢 #36049 中的@laipz8200。
  • 内部指标端点保护 - /threads 和 /db-pool-stat 经过强化，以避免未经身份验证的内部运行时和数据库池详细信息的暴露。感谢 #35665 中的 @orbisai0security。
  • 帐户和工具隔离 — 修复了 GET /account/avatar 中的 IDOR 问题，并将内置工具默认凭据清理范围限定到当前租户。感谢 #35771 和 #35887 中的 @NeatGuyCoding 和 @GareArc。
  • 依赖项安全性 — 针对 CVE-2026-42208 升级了 LiteLLM，并刷新了多个后端依赖项，包括 urllib3、gunicorn、gitpython、mako、Google SDK 包、存储库和 OpenTelemetry 导出程序包。感谢@crazywola #35953、#35779、#35791、#35863、#35864、#35958、 #36011、#36012、#36013、#36017 和 #36050。

🧩 工作流程、HITL 和应用程序运行时

  • 工作流程稳定性 - 通过后端 API 恢复工作流程版本加载，修复大型应用程序列表的在线用户轮询，防止预览调整大小观察者循环，并避免试用工作流程中的模式模型冲突。感谢 #35817、#35786、#35936 和 #36061 中的 @hjlarry 和 @lyzno1。
  • 工作流程创作改进 — 修复了子变量的变量引用选择器行为、工作流程节点标题溢出、条件运算符弹出窗口、工作流程清单语义和 KB 元数据筛选字段选择。感谢 #35732、#35740、#35828、#36006 中的 @iamjoel、@hjlarry、@lyzno1 和 @shawny011717，以及#34149。
  • 工作流程执行正确性 - 保留单次运行输入变量类型，修复了 structured_output_enabled 验证，修复了节点输出显示中的文件预览 URL 处理，以及 v1.14.0 工作流程上畅通无阻的插件模型选择器工具。感谢 #35710、#35747、#34150 和 #35794 中的 @Jingyi-Dify、@fatelei、@shawny011717 和 @sawyer-shi。
  • 人工输入 — 公开人机交互流程的选定操作值。感谢 #35451 中的 @Blackoutta。
  • 问题分类器 — 添加了可编辑的类别标签。感谢 #35430 中的 @Blackoutta。

📚 数据、RAG 和知识

  • 知识库图像渲染 — 修复了知识库中的图像渲染失败问题。感谢 #35914 中的@FFXN。
  • 文档索引 — 在矢量嵌入之前跳过空文档并验证缺失的文本索引技术。感谢 #35763 和 #35941 中的 @princepal9120 和 @juyua9。
  • RAG 重复数据删除 — 使用 doc_id 作为跨提供商的重复数据删除密钥，而不仅仅是 Dify 托管的提供商。感谢 #35759 中的 @ki3nd。
  • 数据集元数据过滤器 — 在 API 路径中保留数据集元数据过滤器并修复 KB 元数据过滤器字段选择。感谢 #35700 和 #34149 中的 @princepal9120 和 @shawny011717。
  • 上传文件名处理 — 从 URL 解析干净的上传文件名，并在标准化数据源文件扩展名时避免双点。感谢 #35706 和 #35808 中的 @jonathanchang31 和 @Beandon13。

🎨 Web UI 和设计系统

  • Dify UI 迁移 — 从旧版覆盖层、工具提示、抽屉、选择器、标签和可搜索选择器继续迁移到 @langgenius/dify-ui 基元，包括新的 Drawer、选项卡、ToggleGroup、自动完成和组合框支持。感谢@lyzno1和@CodingOnStar在#35675、#35715、#35720、#35721、#35774、 #35785、#35787、#35792、#35825、#35868、#35881、 #35892、#35896、#35917、#35961、#35962、#35963、 #35965、#35976、#35982 和 #36066。
  • 可访问性和语义 - 改进了网络可访问性，删除了不必要的 data-testid 使用，规范化选择值处理，改进了帮助字形语义，并改进了高级徽章按钮语义。感谢 #35999、#36007、#36008 和 #36026 中的 @lyzno1。
  • 覆盖和导航可靠性 - 恢复应用程序导航创建子菜单交互，修复传输工作区下拉显示，规范化覆盖控制，对齐 Tailwind v4 CSS 迁移，将 CSP 随机数转发到主题脚本，以及对齐标签过滤器下拉图标。感谢 #35681、#35876、#35832、#35829、#35960 中的 @hjlarry、@iamjoel 和 @lyzno1，以及#36041。
  • 发布者和启动流程 - 改进了发布者确认对话框处理并修复了预填充 WebApp 启动描述中的不匹配副本。感谢 #35701 和 #35964 中的 @CodingOnStar 和 @iamjoel。
  • 音频和转录行为 — 显式恢复 AudioContext 并在第一次 TTS 加载时播放音频，并正确传递 end_user.external_user_id 来转录 ASR。感谢 #35901 和 #35898 中的 @ki3nd。

  • TiDB 端点更新 — 修复了 TiDB 状态更改时端点更新的问题。感谢 #35854 中的 @zyssyz123。

升级指南

重要提示

  • 此版本包括用于可配置探索应用程序类别的新数据库迁移。作为升级的一部分运行数据库迁移。
  • Docker Compose 环境变量现在分为 docker/envs/** 下的分类文件。如果您维护自定义的 docker-compose.yaml 或 .env，请仔细检查新布局并重新应用本地自定义。
  • 对于自托管部署，将继续遵循显式配置的 SECRET_KEY 值。如果 SECRET_KEY 为空，Dify 现在会自动生成并保留运行时密钥。

Docker 组合部署

  1. 备份您自定义的 docker-compose YAML 和 env 文件。

    cd docker
cp docker-compose.yaml docker-compose.yaml.$(date +%s).bak
cp .env .env.$(date +%s).bak 2>/dev/null || true

  2. 从发布分支或标签获取最新代码。

    git fetch --tags
git checkout 1.14.1

  3. 停止服务。请在docker目录下执行。

    docker compose down

  4. 备份数据。

    tar -cvf volumes-$(date +%s).tgz volumes

  5. 查看新的 docker/envs/** env 文件布局并重新应用所有本地自定义。

6、升级服务。

docker compose up -d

源代码部署

  1. 停止API服务器、Worker和Web前端服务器。

  2. 从release标签获取最新的代码。

    git fetch --tags
git checkout 1.14.1

3.更新Python依赖项。

cd api
uv sync

  1. 运行迁移脚本。

    uv run flask db upgrade

  2. 重新启动 API 服务器、Worker 和 Web 前端服务器。
