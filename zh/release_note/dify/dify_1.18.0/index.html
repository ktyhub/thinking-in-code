dify 1.18.0

Dify 1.18.0 带来了路由工作流的代理、便携式应用程序包、对嵌套工作流运行的更深入可见性以及选择加入的代理知识库体验。 OpenAPI 和新的 difyctl 扩展了您从命令行构建和管理应用程序的方式。

[!重要] 部署前请阅读下面的升级指南。 将 API、工作线程、代理后端和代理运行时映像一起升级。本地代理沙箱需要非空身份验证令牌，代理后端使用新的运行协议。源安装需要 Python 3.13。安装新的difyctl client并再次登录。保留现有的 PASSWORD_PEPPER 配置。

发布亮点

选择下一步的代理

让代理决定采用哪个工作流分支。启用输出路由，为每个路由指定一个选择条件，并将其连接到下一步 - 例如直接解决请求或将其交给专家。只读 switch 输出公开所选的路线。 (#42599)

工作流编辑器中具有两个分支的输出路由配置。

Plain Agent v2 节点还在生成文本时对文本进行流式传输。结构化结果、路由结果和使用默认值错误处理的节点仍处于缓冲状态。 (#43986)

一个包中的便携式应用程序

将应用程序及其支持的资源移动到单个 .ifpkg 包中。工作流和聊天流包携带内联代理、技能及其文件；导入在目标工作区中重新创建这些资源并重新映射引用。文件和 URL 导入支持包和 YAML，并且显式 YAML 导出仍然可用。 （#42066、#42579、#42626、#42863）

Studio 的 .ifpkg 导入预览。

查看嵌套工作流运行内部

从运行历史记录中打开 工作流工具调用 并检查子工作流的各个步骤。嵌套工具现在作为子图运行，并具有协调的暂停、恢复、停止和文件输出。访问检查可保护源应用程序的详细信息。 （#40277、#42819、#42820、#42821、#42822）

跟踪深入了解成功的工作流程工具调用。

嵌套使用量和总步数仍然可以是近似值，特别是在暂停或停止之后。控制台钻取和外部跟踪导出具有不同的范围；请参阅下面的完整功能详细信息。

代理知识库·测试版

为您的代理创建知识空间，添加文件或连接源，并在一处检查文档处理、元数据、检索跟踪和质量评估。新的知识检索节点和代理集成共享访问控制的 KnowledgeFS 空间。经典知识仍然可用。这是与单独的服务和数据库的选择性集成；请参阅下面的部署要求。 (#44165)

开发者聚焦

使用 OpenAPI 和 difyctl 构建和管理应用程序。 CLI 从服务器的操作目录中发现命令，并提供可搜索的帮助以及对工作流和聊天流创建、DSL 导入/导出、设置、环境变量、发布和版本恢复的支持。草稿哈希保护并发编辑。 （#42487、#42608、#43067）

为构建 Dify 应用程序的代理安装捆绑技能：

difyctl install skills <dir>

新的 client 需要重新登录；请参阅下面的部署说明。 (#43819)

升级指南

兼容性和推出

  1. 首先备份。 保留数据库、矢量存储数据、上传的文件、代理快照/工作区存储以及所有部署机密和环境文件。使用维护时段进行单堆栈升级。
  2. 一起升级代理组件。 /runs 现在接受组合 v2 并拒绝 v1 请求。现有会话快照在读取时进行转换并保存为 v2；旧的运行时无法读取新保存的 v2 快照。 Direct Agent 后端集成必须更新其请求格式。旧的特定于代理的 AskHuman 工具和延迟的恢复路径已被删除：历史代理表单不再恢复执行，而共享工作流人工输入节点仍受支持。 (#43833)
  3. 在接纳新版本流量之前淘汰旧的工作流使用者。 让运行中的运行完成，然后替换旧的工作人员/恢复使用者，这样他们就无法在没有新的取消防护的情况下处理共享队列。可以从现有访问范围内有效保存的调用快照中恢复旧的暂停任务 ID；丢失或无效的快照需要单独恢复。嵌套使用总数保留上述限制。 (#40277)
  4. 重新启动前配置本地沙箱令牌。 通过共享 Compose 插值源提供高熵密钥。 1.17.1 运行时映像不支持新的 --require-auth-token 标志；部署匹配的 1.18.0 代理后端和本地沙箱映像。 (#44152)
  5. 保留密码散列配置。 不带胡椒的现有安装应将 PASSWORD_PEPPER 留空。在升级过程中设置新的胡椒并不是透明的迁移，并且需要明确的密码重置计划。在所有实例中保持任何已配置的胡椒不变，并使用数据库将其恢复。
  6. 检查代理边界。 捆绑的 Nginx 将 X-Forwarded-For 替换为其解析的 client 地址，并且 Compose 启用转发标头处理。将直接 API 访问限制为 trusted 呼叫者。如果负载均衡器或 Cloudflare 位于 Nginx 之前，请在那里配置 trusted 真实 IP 处理；否则访问者可以共享代理”
