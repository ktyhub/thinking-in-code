发生了什么变化

  • 为 JDK Simple JSON API (JEP 540) 添加 feign-jdk-json 编解码器，并修复 @velo 在 https://github.com/OpenFeign/feign/pull/3620 中的 Dependabot 自动合并
  • 从https://github.com/OpenFeign/feign/pull/3613中@hutiefang76的字段查询映射中排除静态字段
  • 将运行时 HeaderMap 值视为 https://github.com/OpenFeign/feign/pull/3612 中 @hutiefang76 的文字
  • 文档：修复 https://github.com/OpenFeign/feign/pull/3659 中@hamidzr 文档中的拼写错误
  • 在https://github.com/OpenFeign/feign/pull/3628中@hutiefang76读取其他Content-Type参数后的响应字符集
  • 通过https://github.com/OpenFeign/feign/pull/3611中的@kdelay读取FormEncoder中引用和大小写混合的字符集参数
  • Logger反映Feign请求的文档，而不是https://github.com/OpenFeign/feign/pull/3544中@ChrisJr404的电汇请求
  • 在https://github.com/OpenFeign/feign/pull/3658中通过@havefunatcode在QueryMap POJO字段和getter上应用@Param扩展器
  • 在https://github.com/OpenFeign/feign/pull/3546中添加@henriquejsza选择加入的目标主机和端口观察标签
  • feign-kotlin：添加非阻塞 WebClient AsyncClient 并通过 @ggoowlgns 在 https://github.com/OpenFeign/feign/pull/3645 中改进协程支持
  • 跳过 private 和 Vary: * @alhudz 在 https://github.com/OpenFeign/feign/pull/3610 中的 HttpCacheInterceptor 响应
  • 通过 @goutamadwant 在 https://github.com/OpenFeign/feign/pull/3462 中强制执行 Java 11 响应主体超时
  • feign-mock：允许通过 https://github.com/OpenFeign/feign/pull/3661 中的 @lxcxjxhx 子集匹配请求标头
  • 修复 URI 片段替换并保留 @hutiefang76 在 https://github.com/OpenFeign/feign/pull/3633 中的目标转义
  • 尊重 @hutiefang76 在 https://github.com/OpenFeign/feign/pull/3627 中未转义 URI 值的保留字符标志
  • 保留 Java11 响应头值顺序并由 @hutiefang76 在 https://github.com/OpenFeign/feign/pull/3638 中重复
  • https://github.com/OpenFeign/feign/pull/3624中@hutiefang76保留文字查询值并扩展数组参数
  • 不区分大小写地识别 HTTP URI 方案 by @wozhenbang2004 in https://github.com/OpenFeign/feign/pull/3665
  • 在 Java11 client 中实现零连接和读取超时（@hutiefang76 在 https://github.com/OpenFeign/feign/pull/3637 中）
  • 恢复 https://github.com/OpenFeign/feign/pull/3634 中 @hutiefang76 的 Apache HTTP4 对无体幂等请求的重试
  • 当委托在 https://github.com/OpenFeign/feign/pull/3630 中抛出 @hutiefang76 的错误时，完成异步 client 期货
  • 在 https://github.com/OpenFeign/feign/pull/3674 中分享 @hutiefang76 与表单编码器的引用感知字符集解析
  • 当 @velo 在 https://github.com/OpenFeign/feign/pull/3673 中未将分块主体读取到末尾时，重用 DefaultClient 保持活动连接
