bookkeeper release-4.17.2

发布 发布时间2025年7月5日 来源apache/bookkeeper 英文原文

bookkeeper release-4.17.2

4.17.2 版本包含多个错误修复和少量依赖项更新。

如果您使用的是 4.17.x，我们鼓励 Apache BookKeeper 用户升级到 4.17.2。 此版本的技术细节总结如下。

亮点

错误

  • 修复 BookieClient 重构回收器后的 NPE 错误 PR #4610
  • 修复 Bookie Client 的 Netty 回收器中的内存泄漏 PR #4609
  • 修复由于错误的条目日志头导致的数据丢失问题 PR #4607
  • 修复 Rocksdb 关闭后调用 KeyValueStorageRocksDB.count 时发生的 coredump PR #4581
  • 修复并改进 RocksDB 配置文件的定位 PR #4560
  • [修复] 由于多个线程挂起的添加回调导致写入卡住 PR #4557
  • 修复位置文件夹中未清理的 SST 文件 PR #4555
  • 修复了tune-runner-vm 操作以在 ubuntu-24.04 映像上正确运行 PR #4536
  • [cli] 修复：恢复命令不接受速率限制参数 PR #4535 *修复pendingDeletedLedgers不删除账本错误PR #4525
  • 修复区域感知放置策略磁盘权重不更新。 PR #4522
  • 修复检查读取失败条目内存泄漏问题。 PR #4513
  • [修复] 在 bookie 离开时删除 address2Region 以获得正确的机架信息 PR #4504
  • 修复：在测试映像构建中安装 netcat-openbsd 而不是 netcat PR #4476
  • [修复][ci] 使用 NVD API 密钥修复 OWASP 依赖项检查下载 PR #4473
  • 修复 checkAllLedgers 时 ReadOnlyLedgerHandle 泄漏问题。 PR #4468 *修复[rocksdb]：修复CFOptions的rocksdb默认配置错误PR #4466
  • [修复] 修复写入账本和删除账本执行并发后数据丢失的问题 PR #4462
  • [BugFix] 修复以防止 3 个类中的资源泄漏 PR #4449
  • 当 bookie 不可用时，更正 RackawareEnsemblePlacementPolicyImpl defaultRack。 PR #4439
  • 修复completionObjects泄漏问题。 PR #4285
  • 问题 2161：设置指标端点内容类型 PR #4208

改进

  • 调整测试中的 DNS 缓存过期时间以减少测试超时失败 PR #4586
  • 将新的集成日志更改为信息级别 PR #4566
  • 将有关 RocksDB 配置的文档添加到 bk_server.conf PR #4561
  • 减少 LedgerHandle 中的元数据锁争用 PR #4549
  • [改进] 当rackaware选择bookie失败时，打印出ensemble列表。 PR #4482
  • 确保为所有 RocksDB 数据库指定 formatVersion PR #4559
  • 将 RocksDB 数据库的默认 format_version 设置为 5 PR #4480
  • [改进] 优化 reorderReadSequence 以检查 WriteSet PR #4478
  • 更新发布脚本说明和 Python 发布脚本 PR #4458
  • 启用 ZooKeeper client 以只读模式建立连接 PR #4244
  • 分配器支持 exitOnOutOfMemory 配置。 PR #3984

依赖项更新

  • 将 commons-beanutils 升级到 1.11.0 以解决 CVE-2025-48734 PR #4608
  • 将已弃用的 commons-configuration 1.x 迁移到 commons-configuration 2.x PR #4604
  • 将 Jetty 升级到 9.4.57.v20241219 以缓解 CVE-2024-6763 PR #4600
  • 将 Netty 升级到 4.1.121.Final PR #4597
  • 升级至 grpc 1.72.0 PR #4591
  • 升级 OpenTelemetry 版本并使用 BOM 调整版本 PR #4589
  • 将 Netty 升级到 4.1.119，tcnative 升级到 2.0.70，io_uring 升级到 0.0.26 PR #4584
  • 将 Apache Commons 库升级到兼容版本 PR #4582
  • 将 vertx.version 从 4.5.7 升级到 4.5.11 以解决 CVE-2024-8391 PR #4545
  • 升级到 Netty 4.1.115.Final 以解决 CVE-2024-47535 PR #4524
  • 将 Zookeeper 升级到 3.9.3 以解决 CVE-2024-51504 PR #4523
  • 将 gRPC 升级到 1.70.0 PR #4512
  • 将 protobuf 升级到 3.25.5 以解决 CVE-2024-7254 PR #4508
  • 升级到 Netty 4.1.113.Final 和 netty-tcnative 2.0.66.Final [PR #4502](https://github.com/apache
