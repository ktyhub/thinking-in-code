mybatis-3 mybatis-3.5.12

发布 发布时间2023年3月1日 来源mybatis/mybatis-3 英文原文

mybatis-3 mybatis-3.5.12

《大扫除》

对用户有影响的更改

  • #2703 按名称引用集合参数失败修复 #2693

  • #2709 修复了在构造映射表时由其他线程调用映射器方法引起的竞争条件

  • #2727 启用向 XMLConfigBuilder 提供自定义配置的能力

  • #2731 在 JPMS 下添加映射器可能会失败

  • #2741 将“affectedData”属性添加到@Select、@SelectProvider 和 <select />

  • #2767 当未提供 resultType 和 resultMap 时，通过名称空间和 id 解析 resultType

  • #2804 按名称解析构造函数参数类型时搜索可读属性

  • 小修正：“布尔值”永远不能为空（原始）

  • 一般库更新

  • 现在使用编译器的参数选项（spring boot 3 需要）（用于反射需求）

代码清理

  • #2816 使用开放重写来部分清理 java 代码
  • #2817 每次开放重写添加私有构造函数
  • #2819 在每次开放重写的适当位置添加最终内容
  • #2825 清理 if 语句中断/返回逻辑
  • #2826 基于 Eclipse 的清理

构建

  • #2820 删除测试 ci 组配置文件，以便更直接地使用 GH-Actions 并更新 README.md 中概述中已弃用的 Surefire
  • 调整构建阴影 ognl 和 javassist 不再抛出警告
  • 现在也使用 jdk 21-ea 构建
  • 各种测试清理、更新和添加
  • 打开所有 Java 代码的自动格式化，包括在自述文件中向贡献者提供的注释，以在代码块中必要时跳过格式化
  • 测试现在可以使用 jdk 11，同时保留 jdk 8 运行时
  • Pom 清理/更好地澄清参数

文档

  • 各种文档更新

对于贡献者：

  • Mybatis 现在使用代码库的自动格式化。 如果贡献需要特殊格式，例如与格式规则冲突的注释或特定 javadoc，请在要忽略格式的代码块周围使用 // @formatter:off 和 // @formatter:on。 如果在 javadoc 中，由于它是注释类型，整个事物都会受到影响，因此只需将其包裹在整个 javadoc 中即可。 尝试确保非格式化块内的代码格式正确，否则可提高可读性。
