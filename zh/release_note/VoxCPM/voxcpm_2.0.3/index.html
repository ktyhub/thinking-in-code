VoxCPM 2.0.3

VoxCPM v2.0.3

此版本侧重于微调可用性、运行时稳定性、更安全的 LoRA 加载和更快的流推理。

亮点

  • 添加了 voxcpm validate 用于飞行前 JSONL 训练清单验证。
  • 在微调数据管道中添加了可选的 ref_audio 支持。
  • 通过显式 --device 支持和更安全的 MPS dtype 行为改进了运行时设备处理。
  • 通过避免冗余重叠解码改进了 VoxCPM2 流 VAE 解码。
  • 使用 weights_only=True 强化旧版 LoRA 检查点加载。
  • 修复了 lora_ft_webui.py 中 LoRA 排名不匹配的处理。

新功能

  • 添加 voxcpm validate --manifest train.jsonl 以在微调之前捕获训练数据问题。
    • 验证 JSONL 格式、必需的 text/audio 字段、音频存在/可读性、采样率、持续时间统计数据、文本长度统计数据和可选的 ref_audio。
  • 添加可选的 ref_audio 支持以微调清单。
    • 训练打包现在支持 [103, ref_audio, 104, text, 101, target_audio, 102]。
    • 损失仅应用于目标音频片段。
  • 为模型推理命令添加 --device CLI 参数。
    • 支持 auto、cpu、mps、cuda 和索引 CUDA 设备，例如 cuda:0。

性能

  • 使用有状态的 StreamingVAEDecoder 改进 VoxCPM2 流式 VAE 解码。
    • 流式解码现在仅处理最新的潜在补丁并在内部携带因果卷积状态。
    • 这消除了冗余重叠解码并减少了流式 VAE 解码开销。

修复

  • 通过使用未编译的特征编码器进行预填充来修复 CUDA Graph 动态形状累积。
  • 通过使用显式的可广播掩码形状修复 CPU SDPA 注意掩码广播。
  • 修复非字符串文本验证顺序以提高预期的 ValueError 而不是 AttributeError。
  • 修复在本地模型加载器中加载 config.json 时的文件描述符泄漏。
  • 通过默认将 Apple Silicon 上的低精度 dtypes 提升为 float32 来修复 MPS 音频质量问题。
  • 修复 VOXCPM_MPS_DTYPE 覆盖验证以匹配支持的数据类型别名。
  • 当检查点排名不同时，通过重新加载模型来修复 lora_ft_webui.py 中的 LoRA 排名不匹配。
  • 通过在构造模型提示之前删除括号来修复 Web 演示控件文本处理。

安全

  • 旧版 LoRA .ckpt / .pth 加载现在使用 torch.load(..., weights_only=True)。
  • 这降低了任意 pickle 有效负载执行的风险，同时保留了仅张量检查点的兼容性。

文档

  • 将 vLLM-Omni 记录为 VoxCPM2 的生产服务选项。
  • 将网络演示用法更新为 python app.py --port 8808。
  • 更新 ModelScope 本地下载示例。
  • 将 Python 要求明确为 >=3.10,<3.13。
  • 将 ComfyUI_RH_VoxCPM 添加到生态系统列表。

测试

  • 添加了训练清单验证的覆盖范围，包括采样率不匹配、丢失音频、相对路径、ref_audio 和 CLI 退出代码。
  • 添加了运行时设备选择测试。
  • 添加了针对仅张量检查点和恶意 pickle 有效负载的 LoRA 检查点安全测试。
  • 添加了针对 --device 默认值和参数转发的 CLI 测试。
