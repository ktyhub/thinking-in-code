AstrBot v4.29.0-beta.2

AstrBot v4.29.0-beta.2

[4.29.0-beta.2] - 2026-10-11

此预发行版包含自 v4.29.0-beta.1 以来的更改。

主要新增内容

  • WebUI：在选定模型旁边和模型/后备菜单中添加了模型设置快捷方式。对于使用该模型的每个配置文件，更改会立即保存。 (#10321)
  • WebUI：添加了控制台日志搜索和关键字突出显示、技能源徽章、ChatUI 中的分阶段图像预览，并记住上次打开的“数据和日志”选项卡。 （#10327、#10339、#10376、#10251）
  • WebUI：在机器人编辑器的侧抽屉中添加了配置文件编辑。 (#10310)
  • Docker：包括用于容器内密码重置的 astrbot CLI。 (#10442)

主要优化

  • WebUI：通过延迟加载 VAD、Monaco、翻译和 ApexCharts 并启用 gzip 响应，显着减少了初始加载开销并提高了加载速度。 (#10413)
  • WebUI：滚动时保持内容边框和角固定，添加 6px 桌面右侧/底部间隙，并在内容窗格滚动时固定配置/设置标题和部分导航。 (#10480)
  • 计算机使用：澄清了本地权限访问模式，在本地隔离不可用时保持执行和文件访问控制可见，并将设置指南链接到综合代理沙盒指南。 （＃10444，＃10445，＃10487）
  • 文档：更新的中英文插件和内置人工智能指南，包括当前工作流程、故障排除和本地化屏幕截图；更新了 Slack 和 Lark/飞书 设置说明。 （#10487、#10353、#10400）

主要修复

  • 代理：停止会话现在会停止其后台代理工作并防止后期主代理唤醒。仅清理一次会话等待程序，并将异步工具生成器保留在同一任务中。 （＃10323，＃10347，＃10474）
  • 代理：当后台任务结果未传递给用户时发出警告，并避免在没有匹配平台的情况下记录 cron 发送。 （＃10398，＃10468）
  • 核心：上下文摘要失败后立即回退，将命令组名称作为整个单词进行匹配，维护一个可编辑的系统默认角色，并在删除角色文件夹时保留子文件夹。 （#10436、#10372、#10287、#10361）
  • 提供程序：使用空流输入保留 Anthropic 工具调用，将自定义服务器工具与注册工具合并，用 gemini-embedding-001 替换已停用的 Gemini 嵌入默认值，并处理 Dify 流中的 CRLF 分隔符。 （#10432、#10437、#10393、#10392）
  • 图像：拒绝未解析和非常规图像引用，而不是构建本地路径，保留音频/视频/文件的待处理路径处理，并在非严格有效负载组装期间跳过无效图像。增加了对超大 Base64 有效负载和长 Windows 路径的容忍度。 (#10434)
  • 音频：在不失败的情况下降级无法解析的语音附件，避免阻塞格式探测，并在请求后关闭 FishAudio TTS clients。 （#10337、#10055、#10358）
  • 平台：修复了 Telegram 中的 UTF-16 偏移量和不区分大小写的机器人提及，并默认将 Telegram 令牌留空。保留 Slack 代码块、引用、列表、链接和提及，并在上传前解析远程 Slack 文件。将 Discord 视频组件作为附件发送，并防止自我回复循环。 （#10367、#10399、#10365、#10380、#10447、#10448、#10355、#10423、#10425）
  • WebUI：发送聊天消息时强制执行会话所有权，以唯一名称存储附件，恢复插件自述文件锚点，以及更正暗模式日志搜索和默认配置文件本地化。 （＃10346，＃10356，＃10341，＃10351，＃10296）
  • WebUI：刷新了导航和提供程序图标，更正了配置测试聊天按钮主题颜色，并更新了插件提交链接和标签。重用徽标令牌并刷新过期的平台缓存。 （#10304、#10332、#10309、#10471、#10294）

导航和配置更改

  • 侧边栏：核心条目分组在系统下；角色、知识库、计划任务、子代理编排和插件视图显示在扩展下。版本显示在侧边栏页脚中。 （＃10304，＃10307）
  • 配置：将管理员和白名单设置移至 访问控制，并将平台重命名为平台和消息。 (#10321)
  • 配置：将文本到图像渲染设置从系统设置移至配置文件的 扩展 部分。每个配置文件现在都有自己的文本到图像设置。 (#10306)
  • 外观：删除了自定义侧边栏功能。 (#10480)
  • 文档：改进了“使用”部分的指南。 (#10487)

中文

本预发布版本包含自 v4.29.0-beta.1 以来的变更。

主要新增

  • WebUI：模型选择器旁及模型、回退模型菜单内新增设置入口，修改后立即影响引用该模型的所有配置文件。 (#10321)
  • WebUI：新增控制台日志搜索与关键词高亮、技能来源标识、ChatUI 发送待图片预览，并记住「数据与日志」页刚才打开的标签。 (#10327, #10339, #10376, #10251)
  • WebUI：支持在机器人编辑器的侧边抽屉中编辑配置文件。(#10310)
  • Docker：镜像内包含astrbot CLI，可在容器中重置密码。 (#10442)

###主要优化

  • WebUI：延迟加载VAD、Monaco、多语言资源及ApexCharts，并启用gzip响应，大幅降低首屏加载开销，提高加载速度。 (#10413)
  • WebUI：滚动时固定内容与圆角对应，桌面端右侧和底部各保留6px间隔；配置页面和设置页面固定顶部及分区导航，仅滚动内容区域。 (#10480)
  • 电脑使用显示：明确的本地权限访问模式，在本地隔离不可用时继续执行与文件访问控制，并通过设置引导弹窗链接到集成后的代理沙箱指南。 (#10444, #10445, #10487)
  • 文档：更新中英文插件及内置AI指南，补充当前操作流程、故障排查与本地化截图；更新Slack和飞书配置说明。(#10487, #10353, #10400)

###主要修复

  • Agent：停止会话时同步停止后台Agent工作，避免稍后重新唤醒主Agent；会话等待器仅清理一次，异步工具生成器始终在同一任务中执行。 (#10323, #10347, #10474)
  • Agent：后台任务结果未发送给用户时提供提示；不存在匹配平台时记录不再cron发送成功。(#10398, #10468)
  • 核心：上下文摘要失败后及时回退，命令组名称按完整单词匹配，保留唯一可编辑的系统默认人格，并在删除人格文件夹时保留子文件夹。(#10436, #10372, #10287, #10361)
  • 模型结构：保留流输入为空的人择工具调用，将自定义服务端工具与已注册工具合并，将以前的Gemini默认嵌入模型替换为gemini-embedding-001，并兼容Dify流式响应的CRLF分区符。(#10432, #10437, #10393, #10392)
  • 图片：无法解析或指向非普通文件的图片不再引用伪装成本地路径；保留音频、视频和文件的待生成路径行为，非严格模式构建请求时跳过无效图片，并兼容超长base64数据及Windows长路径。 (#10434)
  • 音频：无法解析的语音附件不再导致整轮请求失败，音频格式检测不再阻塞，并在请求后关闭 FishAudio TTS 客户端。(#10337, #10055, #10358)
  • 消息平台：修复 Telegram 的 UTF-16 偏移与大小写匹配，默认留空机器人令牌；保留 Slack 代码块、引用、列表、链接及用户偏移，上传前解析远程文件；Discord 视频组件按附件发送，并避免机器人自回复循环。 (#10367, #10399, #10365, #10380, #10447, #10448, ＃10355，＃10423，＃10425）
  • WebUI：发送聊天消息时加密会话归属，附件使用唯一文件名，恢复插件 README 相关点原创，并修复修复模式日志搜索及默认配置文件名称的本地化。 (#10346, #10356, #10341, #10351, #10296)
  • WebUI：更新导航及模型事件图标，修改配置试聊按钮主题颜色，更新插件提交入口及文案；复用徽标令牌并刷新过渡的平台存储。(#10304, #10332, #10309, #10471, #10294)

导航与配置迁移

  • 侧边栏：核心入口归入「系统」；人物、知识库、定时任务、子代理编辑排及插件视图归入「扩展功能」，版本号移至侧边栏底部。 (#10304, #10307)
  • 配置：将管理员、白名单配置迁移到访问控制分区；平台分区更名为「平台与消息」。 (#10321)
  • 配置：将设置中的文本转图片渲染配置迁移到扩展功能分区，文转图配置按配置隔离文件。 (#10306)
  • 外观：删除“自定义侧边栏”功能 (#10480)
  • 文档：完善文档的“使用”部分下的各个文档。(#10487)
