AstrBot v4.25.3

修订 发布时间2026年6月5日 来源AstrBotDevs/AstrBot 英文原文

AstrBot v4.25.3

  • 更新日志(简体中文)
  • Changelog(英语)

发生了什么变化

重点更新

  • 修复钉钉 Stream 任务异常退出后无法持续重连的问题，提升钉钉适配器长连接稳定性。(#8610)
  • Dashboard 登录新增 TOTP 双因素认证。(#8189)
  • Dashboard 侧边栏新增插件 WebUI 入口，并支持 MDI 图标；插件页面现在会同步 Dashboard 主题。(#8569, #8390)
  • 优化未来任务 UI，提高 “创建任务” 的产品化程度。(#8559)
  • 新增 /name 命令用于命名 umo 且在 UI 中展示。 (#8575)
  • MiniMax Token Plan 支持动态获取模型列表，默认模型升级为 M3。(#8475, #8505)
  • 优化上下文压缩，提高压缩质量和 KV-cache 命中率。(#8530, #8226)

修复

  • 修复 Provider 统计遇到 SQLite lock 时未重试的问题。(commit)
  • 修复空 modalities 被当作已配置能力，导致核心图片请求错误路由到视觉 fallback 的问题。(#8451)
  • 修复 Reply 组件 toDict 额外字段导致私聊消息发送失败的问题。(#8477)
  • 修复带 Reply 组件唤醒机器人且用户提示为空时的处理问题。(#8461)
  • 修复 aiocqhttp 适配器无法解析语音的问题，并增加音频文件存在性检查。(#8523, #8529)
  • 修复 OpenAI Embedding 在 SiliconFlow 非 Qwen embedding 模型上的无效参数问题。(#8508)
  • 修复 Gemini Embedding 批量文本在 gemini-embedding-2 上被折叠的问题。(#8537)
  • 修复 WeCom AI 消息链提取纯文本时的空白处理问题。(#8563)
  • 修复 Dashboard 在 launcher 下运行时 frame 安全头过于严格的问题。(#8554)
  • 修复控制台 pip 安装错误展示，改为使用 toast 提示。(#8462)
  • 优化模板配置相关问题。(#8228)

优化与工程

  • 增强 Reply 消息链对 Record 组件的处理。(#8527)
  • Whisper STT 调用 OpenAI 转写接口后会关闭音频文件句柄。(#8528)
  • 防止唤醒命令被记录为群聊上下文。(#8536)
  • 修正中文文本中的 token 术语。(#8465)
  • 更新 GitHub Actions 依赖。(#8533)

更改内容 (EN)

亮点

  • 修复了钉钉流任务恢复问题，使适配器在 SDK 任务意外退出后保持重新连接。 (#8610)
  • 为仪表板登录添加了 TOTP 双因素身份验证。 (#8189)
  • 通过 MDI 图标支持向仪表板侧边栏添加了插件 WebUI 条目，并将仪表板主题样式同步到插件页面中。 （[#8569]（https://github.com/AstrBotDevs/AstrBot/pull/8569），[#8390]（https://github.com/AstrBotDevs/AstrBot/pull/8390））
  • 添加了未来的任务 UI 并引入了 /name 用于命名 UI 中显示的 umo 条目。 （[#8559]（https://github.com/AstrBotDevs/AstrBot/pull/8559），[#8575]（https://github.com/AstrBotDevs/AstrBot/pull/8575））
  • MiniMax Token Plan 现在可以动态获取模型列表，默认模型升级为 M3。 （[#8475]（https://github.com/AstrBotDevs/AstrBot/pull/8475），[#8505]（https://github.com/AstrBotDevs/AstrBot/pull/8505））
  • 改进了长期内存和上下文压缩质量，包括更好的 KV 缓存命中率。 （[#8530]（https://github.com/AstrBotDevs/AstrBot/pull/8530），[#8226]（https://github.com/AstrBotDevs/AstrBot/pull/8226））

错误修复

  • SQLite 锁定时重试提供程序统计信息读取。 (提交)
  • 将空模态视为未配置，因此图像请求不会错误地路由到视觉回退。 （[#8451]（https://github.com/AstrBotDevs/AstrBot/pull/8451））
  • 修复了回复组件 toDict 输出中额外字段导致的私人消息发送失败的问题。 (#8477)
  • 修复了使用回复组件和空用户提示唤醒机器人的问题。 (#8461)
  • 修复了 aiocqhttp 适配器中的语音解析并添加了音频文件存在检查。 （[#8523]（https://github.com/AstrBotDevs/AstrBot/pull/8523），[#8529]（https://github.com/AstrBotDevs/AstrBot/pull/8529））
  • 修复了 SiliconFlow 非 Qwen 嵌入模型的无效 OpenAI 嵌入参数。 (#8508)
  • 在内容中包裹 Gemini 批量嵌入文本，以避免在 gemini-embedding-2 上崩溃。 (#8537)
  • 修复了从 WeCom AI 消息链中提取纯文本时的空白处理。 （[#8563]（https://github.com/AstrBotDevs/AstrBot/pull/8563））
  • 在启动器下运行时放宽了仪表板框架安全标头。 (#8554)
  • 显示控制台 pip-install 错误和 toast 消息。 (#8462)
  • 优化模板配置处理。 (#8228)

改进和维护

  • 增强了记录组件的回复链处理。 (#8527)
  • 在 Whisper STT 中调用 OpenAI 转录后关闭音频文件句柄。 (#8528)
  • 防止唤醒命令被记录为群聊上下文。 (#8536)
  • 修正了中文令牌术语。 (#8465)
  • 更新了 GitHub 操作依赖项。 (#8533)
