AstrBot v4.29.1

我们计划于 2026 年 11 月 1 日停止对 < Python 3.12 版本的支持。如果您的 Python 版本仍然是 3.10、3.11，请及时更换新的 Python 版本。
我们计划于 11 月 1 日终止对 3.12 之前的 Python 版本的支持。如果您当前使用的是Python、3.10或3.11，请升级到较新版本的Python。

[4.29.1] - 2026-10-17

###新增

  • 网页搜索：“网页搜索”能力新增 SerpApi 搜索服务 (Google网页搜索、图片搜索、学术搜索、财经搜索)、DeepSeek搜索服务（网页搜索、网页内容提取）。 (#10599)
  • 插件开发：为插件的单选/多选配置项（列表类型）添加本地化的 subtitles 副标题元数据。

修复

  • ️ 电脑使用：修复部分环境（如 Docker 容器环境）下，本地隔离不可用时，无法保存本地权限的问题。(#10584)
  • 电脑使用：恢复Windows下工作区范围内的文件读取、读取和编辑，通过原始文件句柄检查拒绝重点和硬链接别名。 (#10584)
  • 核心：修复完成开启“会话隔离”功能后可能造成的内存泄漏。在注册消息处理模拟之前群聊会话隔离，确保运行中的任务及停止请求使用正确的会话。 (#10581)
  • Telegram：转换消息时保留隐藏链接。 (#10557)
  • Discord：修复全体成员反对。 (#10563)
  • WebUI：修复移动端点击插件视图信息后浮层立即关闭的问题。 (#10562)
  • Edge TTS：保留原有客户端的User-Agent，避免请求失败。 (#10588)
  • 技能：跳过无法读取的本地及插件技能目录，避免单个目录异常导致整轮代理请求失败。 (#10591)

添加

  • 网页搜索：添加了 SerpApi（Google 搜索、Google 图片搜索、Google 学术搜索和 Google 财经搜索）和 DeepSeek Search API（网页搜索和页面内容提取）。 (#10599)
  • 插件开发：为插件中的单选/多选配置选项（“列表”类型）添加了本地化字幕元数据。

已修复

  • ️ 计算机使用：恢复了 Windows 上工作区范围的文件读取、写入和编辑。本机句柄检查拒绝重分析点和硬链接别名。 (#10584)
  • 计算机使用：修复了隔离不可用时保存本地权限的问题。文件访问仍然是可配置的；需要不可用隔离的执行在工具执行时被阻止。现在，默认设置允许成员无需执行即可访问工作区文件，而管理员则可以通过网络进行整个环境执行。禁用所有访问的旧版 Windows 成员策略会一次性迁移到工作区文件访问，包括相同的手动禁用策略，因为未存储其来源；后面的选择保持不变。 (#10584)
  • 核心：修复了启用“会话隔离”功能时可能发生的潜在内存泄漏。现在，在注册消息处理管道之前执行群聊会话隔离，确保正在进行的任务和终止请求都使用正确的会话。 (#10581)
  • Telegram：转换消息时保留隐藏链接。 (#10557)
  • 不和谐：纠正了每个人都提到的问题。 (#10563)
  • WebUI：在移动设备上点击时，保持插件视图信息弹出窗口打开。 (#10562)
  • Edge TTS：保留本机 client 用户代理以避免请求失败。 (#10588)
  • 技能：跳过不可读的本地和插件技能目录，而不是使整个代理请求失败。 (#10591)

完整 Changelog：https://github.com/AstrBotDevs/AstrBot/compare/v4.29.0…v4.29.1
