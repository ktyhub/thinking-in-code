AstrBot v4.26.8

[4.26.8] - 2026-07-28

我们必须培育我们的花园。 我们必须耕种自己的花园。

我们推出了全新的插件市场：AstrBot Cloud。插件开发者和用户可以使用该平台上传、管理和探索AstrBot插件。来自 AstrBot WebUI 的插件数据将被重定向到该市场。欲了解更多详细信息，请阅读：AstrBot 文档 |插件发布

我们已经发布全新的插件市场系统 AstrBot Cloud，插件开发者和用户可以前往该平台上传、管理和浏览插件。AstrBot WebUI 内的插件市场的数据将从该平台同步。详情请前往 AstrBot 文档 | 插件发布。

添加

  • 向仪表板和插件 API 添加了每个插件的日志级别控制。 (#9342)
  • 添加了对 FishAudio TTS 提供程序的模型配置支持。 (#9381)
  • 添加了平台日志分类和用于隐藏用户聊天条目的控制台切换。 (#9165)
  • 添加了具有多模式模型支持的 DashScope 嵌入提供程序。 (#9137)
  • 向 ChatUI 添加了工作区文件浏览器（仅限项目）。 (#9432)

已更改

  • 尊重 Telegram 消息中的部分回复引用。 (#9236)
  • 报告进程 CPU 使用情况而不阻塞事件循环。 (#9367)
  • 添加了字典配置字段的默认值映射。 (#9414)

已修复

  • 修复了包含非 ASCII 字符的 Windows 路径上的 FAISS 访问，恢复延迟导入以防止启动挂起，并拒绝新索引的无效维度。 （#8323、#9350、#9385）
  • 刷新时间戳，同时保持相关锁并将 cron 调度程序状态与数据库同步分离，以便始终加载持久作业。 （＃9349，＃9419）
  • 在 LLM 请求失败后保留检查点，维护嵌入批处理结果顺序，并在重新生成消息时使用当前提供程序。 （＃9358，＃9359，＃9241，＃9402）
  • 检查引用文本的内容安全性，遵守零值前向解析器限制，并从消息大纲中删除尾随分隔符。 （＃9232，＃9394，＃9390）
  • 解决了 Tavilly 日期过滤器冲突、嵌套 OpenAI 完成选择以及 Bailian 重新排序协议不兼容性。 （＃9234，＃9386，＃9413）
  • 处理钉钉命令错误和富文本提及，返回正确的WebChat图像MIME类型，并更正Discord斜线命令验证。 （＃9389，＃9319，＃9411）
  • 显示插件配置保存进度，防止意外的角色对话框关闭，删除重复的滚动条，并防止本地插件上传挂起。 （＃9327，＃9238，＃9382，＃9406）
  • 改进了对话列表性能并防止过时的异步更新。 (#9226)
  • 将默认 MiMo TTS 模型更新为 mimo-v2.5-tts。 (#9428)
  • 未配置代理时忽略系统代理变量，防止本地 API 请求被拦截。 (#8897)
  • 在排名融合期间保留每个知识库的稀疏检索排名，以避免独立 FTS5 索引之间的顺序失真。 (#9426)
  • 受保护的 C 扩展重新加载以防止进程崩溃。 (#9148)

文档

  • 更新了 README 横幅并推荐官方 QQ bot 集成。
  • 添加了 Windows Docker 桌面部署指南。 (#9339)
  • 扩展了英文和中文插件发布指南。 (#9415)

维护

  • 更新了分组 GitHub 操作依赖项和 docker/login-action。 （＃9333，＃9416）
  • 将 Ruff 固定到 0.15.22。 (#9369)
  • 阻止更新程序路径测试创建杂散目录。 (#9376)

新增

  • 在控制台和插件 API 中新增按插件调整日志级别的能力。 (#9342)
  • 为 FishAudio TTS 提供商新增模型配置支持。 (#9381)
  • 新增平台日志分类，以及在控制台中隐藏用户聊天记录的开关。 (#9165)
  • 新增支持多模态模型的 DashScope Embedding 提供商。 (#9137)
  • 为 ChatUI 新增工作区文件浏览器（仅限项目）。 (#9432)

变更

  • Telegram 消息支持保留局部回复引用。 (#9236)
  • 进程 CPU 使用率统计不再阻塞事件循环。 (#9367)
  • 为字典类型配置字段补充默认值映射。 (#9414)

修复

  • 修复 Windows 非 ASCII 路径下的 FAISS 读写，恢复延迟导入以避免启动卡死，并拒绝为新索引配置无效维度。 (#8323, #9350, #9385)
  • 在持锁期间刷新时间戳，并解耦 Cron 调度器状态与数据库同步状态，确保始终加载持久化任务。 (#9349, #9419)
  • 在 LLM 请求失败后保留检查点，维持嵌入批处理结果顺序，并在重新生成消息时使用当前提供商。 (#9358, #9359, #9241, #9402)
  • 对引用文本执行内容安全检查，正确处理值为零的转发解析限制，并移除消息概要末尾的分隔符。 (#9232, #9394, #9390)
  • 修复 Tavily 日期筛选参数冲突、嵌套 OpenAI completion choices 以及百炼重排序协议兼容问题。 (#9234, #9386, #9413)
  • 修复钉钉命令错误与富文本提及处理、WebChat 图片 MIME 类型以及 Discord 斜杠命令名称校验。 (#9389, #9319, #9411)
  • 显示插件配置保存进度，避免误关人格编辑弹窗，移除重复滚动条，并防止本地插件上传卡住。 (#9327, #9238, #9382, #9406)
  • 提升会话列表性能，并避免异步请求产生陈旧更新。 (#9226)
  • 将 MiMo TTS 默认模型更新为 mimo-v2.5-tts。 (#9428)
  • 未配置代理时忽略系统代理变量，避免本地 API 请求被拦截。 (#8897)
  • 在排名融合时保留各知识库的稀疏检索排名，避免独立 FTS5 索引之间的结果顺序失真。 (#9426)
  • 为 C 扩展重载增加保护，避免进程崩溃。 (#9148)

文档

  • 更新 README 横幅，并推荐使用 QQ 官方机器人接入。
  • 新增 Windows Docker Desktop 部署指南。 (#9339)
  • 扩充中英文插件发布指南。 (#9415)

维护

  • 更新 GitHub Actions 依赖组和 docker/login-action。 (#9333, #9416)
  • 将 Ruff 固定为 0.15.22。 (#9369)
