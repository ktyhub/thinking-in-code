AstrBot v4.28.1

[4.28.1] - 2026-09-14

我们生活在我们共同相信的故事中。

添加和优化

  • 添加了分页 ChatUI 历史记录加载和改进的聊天设置、消息编辑器和流交互。现在默认显示推理，并且工作区代码预览使用 Shiki 突出显示。 （#9667、#10021、#10020、#10023）
  • 在模型选择中添加了提供程序源过滤器和粘性组标题，并改进了提供程序配置对话框。 （＃10084，＃10007）
  • 为内置代理添加了自适应输入图像处理：在需要时调整图像大小或转换图像，并将动画图像转换为帧蒙太奇。在 CUA 沙箱中保留静态图像尺寸，并在图像可能超出提供商上传限制时发出警告。 （＃9703，＃10071）
  • 统一/new和/reset开始新对话，权限可在命令管理中配置。 (#10004)
  • 添加了桌面更新下载进度并减少了捆绑的 WebUI 字体和图表资源。 （＃10050，＃10034）
  • 改进了配置滑块的稳健性。 (#10037)
  • 标准化提供商请求用户代理标头以包含 AstrBot 版本。 (#10082)

修复

  • ️ 事件清理后保留原始图像附件路径，以便代理可以继续访问附件。 (#10042)
  • 通过 URL 和文件安装修复了插件更新。 (#10053)
  • 修复了 WebChat 侧线程中的模型选择，并恢复了主动代理的会话模型回退。 （＃10065，＃10028）
  • 修复了在直播期间提供类似技能的后备回复的问题。 (#10025)
  • 使计划的代理遵守会话上下文压缩设置，并在运行程序以错误状态结束时记录失败。 （＃9992，＃9987）
  • 修复了 api_base 为空时的 OpenAI 端点分辨率。 (#10079)
  • 修复了网络搜索工具中的缺失字段、吞没错误代码和参数验证。 (#9979)
  • 在知识库中间隔开并发 URL 清理速率限制器服务员。 (#10015)
  • 改进了 Lark 私信发送，从拒绝的开放 ID 回退到已知的聊天 ID，而无需重复成功发送。 (#10018)
  • 修复了QQ官方C2C流媒体响应缺少结束帧的问题。 (#10069)
  • 减少 Telegram 轮询和冲突错误日志垃圾邮件。 （＃10027，＃10046）
  • 修复了消息大纲中的提及所有处理。 (#9993)
  • 修复了必须从存储中解析活动对话时删除当前对话的问题，并使用 WebChat 会话标题作为对话历史记录中的后备。 （＃10003，＃9983）
  • 批量控制台日志渲染以防止 WebUI 冻结。 （＃9988，＃9990）
  • 在桌面管理模式下拒绝过时的 WebUI 资产，并从 PyPI 源包中排除临时仪表板构建工件。 （＃9898，＃10036）

升级注意事项

  • /reset 现在跟随 /new：内置代理开始新对话，同时保留旧历史和当前角色。第三方代理后端会重置其存储的会话 ID，并且可能不会保留旧记录。 (#10004)

新增与优化

  • 新增ChatUI历史消息分页加载，优化聊天设置、消息输入框和流交互式体验。默认显示推理过程，工作区代码预览使用Shiki语法高亮。(#9667, #10021, #10020, #10023)
  • 为模型选择器新增首次来源筛选和分组标题吸顶，优化模型创建配置对话框。 (#10084, #10007)
  • 为内置 Agent 新增输入图片处理：缩放、转换格式，将动图转为多帧拼图。在 CUA 沙箱下保留静图尺寸，图片可能超过模型加载限制时给出警告。 (#9703, #10071)
  • 统一 /new 和 /reset 的新建对话行为，并支持在指令管理中配置权限。 (#10004)
  • 新增桌面端更新下载详细资料显示，专业WebUI的字体和图表资源资源。 (#10050, #10034)
  • 改进配置加强的健壮性。 (#10037)
  • 统一模型发起请求的 User-Agent，其包含 AstrBot 版本。 (#10082)

修复

  • ️在事件清理后保留图片附件原图路径，使代理能够继续访问附件。(#10042)
  • 修复通过 URL 或文件安装方式更新插件出现的问题。 (#10053)
  • 修复WebChat侧边线程的模型选择，恢复主动代理对会话模型的回退逻辑。(#10065, #10028)
  • 修复流式模式下技能类回退回复未送达的问题。 (#10025)
  • 使定时任务代理遵循会话上下文压缩设置，并在执行器以错误状态结束时记录任务失败。 (#9992, #9987)
  • 修复 api_base 为空时的 OpenAI 接口地址解析。 (#10079)
  • 修复网页搜索工具的字段丢失、错误码吞没和参数校验问题。(#9979)
  • 修复知识库 URL 清理限制流器中并发等待请求未错开执行的问题。 (#10015)
  • 提高飞书私聊消息发送达可靠性：开放ID被拒绝时回退到已知聊天ID，避免重复已发送成功的消息。 (#10018)
  • 修复QQ官方机器人C2C流式回复缺少结束帧的问题。 (#10069)
  • 减少 Telegram 轮询和冲突错误的重复日志。 (#10027, #10046)
  • 修复消息概要中全体成员提及的处理顺序。 (#9993)
  • 修复需要从持久化存储解析当前对话时的删除行为，并在对话历史中使用 WebChat 会话标题作为回退。 (#10003, #9983)
  • 批量渲染控制台日志，避免WebUI卡顿。(#9988, #9990)
  • 修复桌面端托管模式加载过渡WebUI资源的问题，并从PyPI包中备用临时构建产物。 (#9898, #10036)

升级提示

  • /reset 现在与 /new 行为一致：内置 Agent 会创建新对话，保留旧历史并继承当前人格；第三方 Agent 会重置保存的会话 ID，不保证保留旧记录。群聊默认权限接下来对话隔离设置，已有指令权限设置继续生效。 (#10004)
