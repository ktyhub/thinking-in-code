AstrBot v4.28.0-beta.1

预发布 发布时间2026年9月1日 来源AstrBotDevs/AstrBot 英文原文

AstrBot v4.28.0-beta.1

[4.28.0-beta.1] - 2026-09-02

主要新增内容

  • 重新设计了模型提供者、机器人和配置文件的 WebUI 页面，并将日志、跟踪、对话管理和数据合并到 数据和日志 页面中。从模型提供程序中删除了 Agent Runner 并将其设置嵌入到每个配置文件中。 （＃9820，＃9825，＃9821，＃9883，＃9846）
  • 重新设计了默认和本地 T2I 渲染。 (#9803)
  • 丰富了跨消息传递平台适配器的统一组元数据。 (#9851)
  • 自动记录统一消息源 (UMO) 的可读名称，例如组名和用户名，使它们更容易在 WebUI 中查找。 (#9909)
  • 在 WebUI 和插件配置中添加了敏感值的屏蔽秘密字段。 (#9824)
  • WebUI技能管理页面新增批量删除。 (#9906)
  • 添加了 AnySearch 作为内置网络搜索提供商。 (#9767)
  • 默认情况下添加了对密码式插件配置字段和屏蔽敏感配置文件字段的支持。 (#9824)

主要优化

  • 改进了浏览器密码管理器识别 WebUI 登录页面的方式。 (#9830)
  • 为深色模式调整了模型提供程序图标。 (#9647)
  • 改进了未来任务代理的上下文处理。 (#9818)
  • 使技能编辑器对话框在较小的屏幕上具有响应能力。 (#9873)
  • 通过按名称字母顺序对工具进行排序，稳定了 OpenAI 工具架构顺序。 (#9798)

主要修复

  • 修复钉钉扫描二维码后可能处于未知 CREATING 状态，导致应用无法继续创建的问题。 (#9808)
  • 修复了 Lark 群组中的命令在命令前出现机器人提示时不会触发的问题。 (#9872)
  • 统一消息源 (UMO) 的隔离速率限制。 (#9814)
  • 将 Anthropic API 基本 URL 处理与 OpenAI API 保持一致； /v1 现在必须包含在配置的 URL 中。 (#9802)
  • 修复了 Anthropic 和 Gemini 的缓存令牌使用情况。 （＃9880，＃9881）
  • 将 max_agent_step 配置应用于计划任务和后台任务代理。 (#9801)
  • 保留飞书图文混合消息中的文字。 (#9841)
  • 在移动角色管理器中显示创建文件夹按钮。 (#9812)

主要新增

  • 重新设计WebUI的模型启动页面、机器人页面和配置文件页面，把日志、追踪、对话管理、数据页面综合为「数据与日志」页面。移除模型启动的“代理执行器”，将其内部嵌入到各个配置文件中。(#9820, #9825, #9821, #9883, #9846)
  • 重新设计默认和本地的T2I渲染效果。(#9803)

  • 自动记录统一消息来源（UMO）的裁决名称（如群名、用户名），方便在WebUI查询。 (#9909)
  • 为 WebUI 和插件配置中的敏感值添加掩码关键字字段。 (#9824)
  • 为WebUI技能管理页面新增批量删除功能。(#9906)
  • 新增 AnySearch 内置网页搜索服务商。 (#9767)
  • 插件支持配置项使用密码效果的字段，并默认将配置文件中敏感字段使用密码效果。 (#9824)

###主要优化

  • 改进浏览器自动记忆密码功能对WebUI登录页的识别逻辑。(#9830)
  • 使模型首次图标对称模型。 (#9647)
  • 优化未来任务 Agent 的上下文。 (#9818)
  • 使用技能编辑器车辆小屏幕。 (#9873)
  • 单击工具名字典序稳定 OpenAI 工具架构的顺序。 (#9798)

###主要修复

  • 钉钉部分情况下扫描码后出现CREATING未知状态导致无法继续创建。(#9808)
  • 修复飞书群里当机器人在前而命令在后会无法触发命令的问题。 (#9872)
  • 按统一消息来源（UMO）隔离限流。 (#9814)
  • 使 Anthropic API 基本 URL 逻辑与 OpenAI API 保持一致，需要输入 /v1。 (#9802)
  • 修复 Anthropic 和 Gemini 相关存储令牌的用量统计口径。 (#9880, #9881)
  • 将 max_agent_step 配置应用到定时任务和后台任务 Agent。 (#9801)
  • 保留飞书图文混合消息中的文本。(#9841)
  • 在移动端的人物管理器中显示新建文件夹按钮。 (#9812)
