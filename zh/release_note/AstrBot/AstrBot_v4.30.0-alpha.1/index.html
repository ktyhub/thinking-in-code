AstrBot v4.30.0-alpha.1

[4.30.0-alpha.1] - 2026-11-15

本版本为Alpha测试版，可能存在不稳定或兼容性问题，先建议在测试环境验证。本次涉及对话数据库、代理配置和会话设置迁移。升级前请备份数据与配置；回退旧版本需同时恢复升级前备份。请不要在重要的生产环境使用该版本。

###主要更新

  • 将会话迁移到事件溯源方式，减少重复上下文写入和部分写入放大，优化存储性能；增量保存消息与工具调用，完善执行后续的历史处理。 (#10077, #11158, #11162)
  • 引入新的 Agent 运行时模型。插件可通过 ctx.agent.run_turn() 唤起 Agent 转动。请参阅 调用现有会话的 Agent (#10934, #10936, #11052, #11148, #11153)
  • 重构子代理为具有独立上下文的后台任务，支持通用与专用Agent、追加指令和结果回传。入口由侧边栏移至配置文件 → AI → 能力 → 子代理，按配置文件管理。 (#11053)
  • 将全局规则与会话管理统一至配置文件→管理会话配置映射，支持基础配置与字段覆盖、批量编辑和恢复继承；模型指令与页面共享同一份设置。 (#11097)
  • 新增Windows AppContainer本机沙盒，支持工作区隔离、代码执行与以太网控制。 (#10466)
  • 新增 DeepSeek 语音识别与语音合成工作。 (#11118)
  • 新增 OpenAI Decisions 判断模型，支持选择、布尔判断与评分。 (#10968)
  • 欢迎页 → 总览：展示每日用量、系统资源及机器人异常。 (#11100)
  • 支持在外观设置中将聊天入口放入侧边栏。 (#11090)
  • 升级Markdown渲染，抢占聊天与语法高亮资源。 (#11138)
  • 插件配置支持可折叠分组，并可声明默认收起状态。 (#11067)
  • 插件页面可获取当前主题颜色及其变化。 (#11046)
  • 重整AI开发文档，补充插件配置控件示例与截图。 (#11154)

优化与修复

  • 运行完善中追加输入的保存与继续执行。 (#11141)
  • 跳过运行时不可用的子代理配置，避免主会话。 (#11128)
  • 允许取消选择已取消、取消或运行时不可用的子代理配置。 (#11147)
  • 删除完整工具架构模式下的默认工具调用提示词。 (#11152)
  • 修复模型最后一次重试成功仍被判定为失败的问题。 (#10922)
  • 修复 Anthropic 非流式响应丢失多个文本块的问题。 (#11057)
  • 搜索密钥失效或限额不足时，尝试其他已配置的密钥。 (#10877)
  • 将Gemini TTS默认模型更新为gemini-3.8-flash-tts。(#10828)
  • 修复QQ按钮回复丢失图片、文件等媒体的问题。 (#10903)
  • 避免QQ图片上传失败时记录完整图片发票，减少日志对面板的影响。(#10740)
  • 优化OneBot流式架构，减少长文本的重复扫描。(#10989)
  • Telegram 发送者没有用户名时，使用显示名称。 (#10715)
  • 修复 Firefox 中聊天历史滚动跳动的问题。 (#11036)
  • 修复编辑模型时预览与能力标识配置不一致的问题。 (#10792)
  • 统一WebUI菜单、弹窗样式，优化滚动条和点击反馈。 (#11107, #11090, #11102)
  • 修复EPUB解析丢失链接文字的问题。 (#10794)
  • 保留GIF转换为拼图后的说明，避免历史上下文丢失动画信息。(#10837)
  • 将插件加载及执行失败日志归属于对应插件，方便筛选排查。 (#10904)
  • SSE 流关闭时通知插件页面，避免连接状态滞留。 (#10932)
  • 控制台日志计时器增加日期。 (#9617)

这是 Alpha 版本，可能存在稳定性或兼容性问题。首先在测试环境中进行验证。此版本迁移对话存储、代理配置和会话设置。升级前备份数据和配置；降级还需要恢复升级前的备份。

亮点

  • 将对话迁移到事件源，减少重复的上下文写入和一些写入放大。增量地保留消息和工具调用，并改进中断执行后的历史记录处理。 （#10077、#11158、#11162）
  • 引入新的代理运行时模型。插件可以通过 ctx.agent.run_turn() 调用代理。 （#10934、#10936、#11052、#11148、#11153）
  • 将子代理重建为具有独立上下文、通用或专用配置、后续输入和结果交付的后台任务。将管理从侧边栏移至 配置 → AI → 功能 → 子代理，并具有每个配置文件的设置。 (#11053)
  • 将自定义规则和会话管理合并到配置→管理会话映射，支持基本配置文件、字段覆盖、批量编辑和恢复继承。模型命令和编辑器共享相同的设置。 (#11097)
  • 添加具有工作区隔离、代码执行和网络控制功能的 Windows AppContainer 沙箱。 (#10466)
  • 添加 DeepSeek 语音识别和合成提供商。 (#11118)
  • 添加用于选择、布尔问题和分数的 OpenAI Decisions 模型。 (#10968)
  • 欢迎→概述现在显示日常使用情况、系统资源和机器人错误。 (#11100)
  • 添加外观设置以在侧边栏中显示聊天。 (#11090)
  • 升级 Markdown 渲染并按需加载聊天和语法高亮资产。 (#11138)
  • 添加具有可配置初始状态的可折叠插件配置组。 (#11067)
  • 向插件页面公开当前主题颜色及其更新。 (#11046)
  • 重新整理AI开发指南，添加插件配置控制示例和截图。 (#11154)

改进和修复

  • 提高执行期间添加的输入的持久性和连续性。 (#11141)
  • 跳过运行时不可用的子代理配置，这样它们就不会阻止主对话。 (#11128)
  • 允许取消选择禁用、丢失或运行时不可用的子代理配置。 (#11147)
  • 删除全模式模式下的默认工具调用指令。 (#11152)
  • 修复了成功的最终模型重试被报告为失败的问题。 (#10922)
  • 保留非流式人类响应中的所有文本块。 (#11057)
  • 当某个键无效或其配额耗尽时，尝试其他配置的搜索键。 (#10877)
  • 将默认的 Gemini TTS 模型更新为 gemini-3.8-flash-tts。 (#10828)
  • 保存QQ按钮回复中的图片、文件等媒体。 (#10903)
  • 停止记录QQ上传失败时的完整图像负载，减少其对仪表板的影响。 (#10740)
  • 通过避免重复扫描长文本来改进 OneBot 流分段。 (#10989)
  • 当用户名不存在时，使用 Telegram 显示名称。 (#10715)
  • 修复 Firefox 聊天历史滚动跳转问题。 (#11036)
  • 在编辑提供程序配置时保留模型预览和功能指示器。 (#10792)
  • 统一 WebUI 菜单和对话框，并优化滚动条和按键反馈。 （#11107、#11090、#11102）
  • 解析 EPUB 文件时保留链接文本。 (#10794)
  • 在对话历史记录中保留 GIF 蒙太奇指导，以便保留动画上下文。 (#10837)
  • 将插件加载和执行错误归因于其插件，以便于日志过滤。 (#10904)
  • 当 SSE 流关闭时通知插件页面以避免连接状态过时。 (#10932)
  • 在控制台日志时间戳中包含日期。 (#9617)
