AstrBot v4.20.1

发生了什么变化

新增

  • 补充 MiniMax Provider。（#6318）
  • 新增 WebUI ChatUI 页面的会话批量删除功能。（#6160）
  • 新增 WebUI ChatUI 配置发送快捷键。（#6272）

优化

  • 优化 UMO 处理兼容性。（#5996）
  • 重构 _extract_session_id，改进聊天类型分支处理。（#5775）
  • 优化聊天组件行为，使用 shiki 进行代码块渲染。（#6286）
  • 优化 WebUI 主题配色与视觉体验。（#6263）
  • 优化 OneBot @ 组件后处理，避免消息文本解析空格问题。（#6238）

修复

  • 修复创建新 Provider 后未同步 providers_config 的问题。（#6388）
  • 修复 API 返回 null choices 时的 TypeError。（#6313）
  • 修复 QQ Webhook 重试回调重复触发的问题。（#6320）
  • 修复流式模式下 delta 为 None 导致工具调用时报错的问题。（#6365）
  • 修复模型服务链接说明文字错误。（#6296）
  • 修复 AI 在 tool-calling 模式设为 skills-like 时发送媒体失败的问题。（#6317）
  • 修复 Telegram 适配器中 GIF 被错误转成静态图的问题。（#6329）
  • 将 Provider 图标来源替换为 jsDelivr CDN 地址，修复部分环境下图标加载问题。（#6340）
  • 修复 QQ 官方表情消息未解析为可读文本的问题。（#6355）
  • 修复 WebChat 队列异常时流式结果页面崩溃的问题。（#6123）
  • 修复子代理 handoff 工具在插件过滤时丢失的问题。（#6155）
  • 修复 Cron 提示文案缺少空格及 utcnow() 的弃用警告问题。（#6192）
  • 修复 WebUI 启动时 Sidebar hash 导航抖动/定位问题。（#6159）
  • 修复启动重试过程中移除已移除 API Key 的 ValueError 报错。（#6193）
  • 修复 README 启动命令引用更新为 astrbot run。（#6189）
  • 修复 Plain.toDict() 在 @ 提及场景下空白字符丢失的问题。（#6244）
  • 修复 provider 依赖重复定义问题。（#6247）
  • 修复 Telegram 中普通回复被误判为线程的处理问题。（#6174）

其他

  • 调整 astrbot.service 及 CI 配置，升级 GitHub Actions 版本。

更改内容 (EN)

新功能

  • 添加了 OpenRouter 聊天完成提供程序适配器，支持自定义标头 (#6436)。
  • 添加了 MiniMax 提供程序（#6318）。
  • 在 WebChat 中添加批量对话删除（#6160）。
  • 添加了对 WebChat 输入的发送快捷方式设置和本地化支持 (#6272)。
  • 在 YAML 配置中添加了本地临时目录绑定（#6191）。

改进

  • 改进了 UMO 处理兼容性（#5996）。
  • 重构 _extract_session_id 以进行聊天类型处理（#5775）。
  • 改进了聊天组件行为并使用 shiki 进行代码块渲染 (#6286)。
  • 改进了 WebUI 主题颜色和视觉行为 (#6263)。
  • 改进了 OneBot @ 组件间距处理（#6238）。
  • 改进了 PR 检查表验证和关闭消息传递。

错误修复

  • 修复了创建新提供者后丢失的 providers_config 同步问题 (#6388)。
  • 修复了 API 返回空选项时的 TypeError (#6313)。
  • 修复了重复的 QQ webhook 重试回调 (#6320)。
  • 修复了工具调用流空 delta 处理以防止 AttributeError (#6365)。
  • 修复了文档/配置中的模型服务链接措辞（#6296）。
  • 修复了工具调用模式设置为 skills-like 时 AI 媒体发送失败的问题 (#6317)。
  • 修复了在 Telegram 适配器中将 GIF 作为静态图像发送的问题（#6329）。
  • 将 npm 注册表 URL 替换为 jsDelivr CDN 以获取提供程序图标 (#6340)。
  • 修复了 QQ 官方人脸消息解析为可读文本的问题 (#6355)。
  • 修复了队列错误时 WebChat 流结果崩溃的问题 (#6123)。
  • 在插件过滤期间保留子代理切换工具（#6155）。
  • 修复了 cron 提示间距和已弃用的 utcnow() 用法 (#6192)。
  • 修复了启动时不稳定的侧边栏哈希导航（#6159）。
  • 修复了删除已删除的 API 密钥时重试循环中的 ValueError (#6193)。
  • 将自述文件中的启动命令更新为 astrbot run (#6189)。
  • 在 Plain.toDict() 中保留 @ 提及的空格（#6244）。
  • 删除了重复的依赖项条目（#6247）。
  • 修复了 Telegram 正常回复被视为主题线程的问题 (#6174)。

文档

  • 更新了 rainyun 备份/访问文档 (#6427)。
  • 更新了 package.md 和平台文档，包括 Matrix 和 Wecom AI 机器人文档。
  • 修复了社区文档中的 Discord 邀请链接。

家务事

  • 更新了 PR 模板/清单工作流程、存储库服务配置和自动检查。
  • 更新了存储库自动化和格式维护，并删除了过时的 changelog 脚本。
