AstrBot v4.29.0-beta.1

预发布 发布时间2026年10月1日 来源AstrBotDevs/AstrBot 英文原文

AstrBot v4.29.0-beta.1

[4.29.0-beta.1] - 2026-10-01

此预发布包含自 v4.28.0（提交 a412146401426c0cdff8bbefb8627a03da519da8）以来的更改。

主要新增内容

  • 计算机使用：为本地执行环境添加了特定于操作系统的沙箱支持，仅在带有 Seatbelt 的 macOS 和带有 bubblewrap 的 Linux 上可用。 (#9472)
  • ChatUI：添加了聊天历史记录和侧边栏会话分页、持久输入草稿、每会话模型选择以及切换项目时的输入自动对焦。 （#9667、#10279、#10247、#10301）
  • ChatUI：在模型选择中添加了提供商源过滤器和粘性组，并在技能和 MCP 页面上进行搜索。 （＃10084，＃10217）
  • WebUI：添加了工作区目录选择器并更新桌面应用程序中的下载进度。 （＃10222，＃10227，＃10050）
  • 桌面：为 WebUI 侧边栏和顶栏添加了 macOS 磨砂玻璃效果。 （＃10222，＃10227，＃10050）
  • 核心：添加了代理步骤预算提醒、迁移了旧限制、增加了默认代理步骤限制以及延长了 shell 会话等待时间。 （＃10131，＃10133）
  • 核心：向提供商请求添加了 x-astrbot-conversation-id 会话 ID 标头。 （＃10218，＃10237）

主要优化

  • 改进了侧边栏和顶栏，减少了它们的垂直占用空间以显示更多信息。 （＃10222，＃10227，＃10050）
  • 改进了“数据和日志”页面上的对话数据预览。 （#10021、#10020、#10023、#10108）
  • 添加了具有有限内存使用的可恢复分块上传、压缩仪表板静态资源以及减少捆绑字体和图表资源。 （#10123、#10187、#10034）
  • 改进了流式响应和推理面板滚动，在加载历史记录时保留滚动位置，以及每个动画帧合并自动滚动。 （#10219、#10221、#10243、#10253、#10257、#10271）
  • 改进了模型输入图像准备，保留图像几何形状，限制编码图像大小，并解释了动画到帧到模型的转换。 （#9703、#10071、#10120、#10119）
  • 批量控制台日志渲染，优化提供程序对话框和跟踪更新，并删除不必要的会话和速率限制工作。 （#9990、#10007、#10270、#10273、#10274）

主要修复

  • 恢复了之前的命令行为：/reset 清除当前对话上下文； /new 创建并切换到新对话。修复了持久的对话删除和历史标题。 （＃10118，＃10003，＃9983）
  • 修复了排队请求历史记录刷新、会话锁定之前的附件准备以及禁用 LLM 处理后继续排队的请求。 （＃10238，＃10209，＃10234）
  • 修复了 WebChat 侧线程模型选择、主动代理模型回退、WebChat 唤醒前缀门控和流式回退回复。 （#10065、#10028、#10245、#10025）
  • 修复了计划代理失败报告、上下文压缩和插件过滤器；保留无效编辑后的提醒，澄清任务所有权，并将 cron 失败宽限期增加到 300 秒。 （#9987、#9992、#10163、#10075、#10104、#10183）
  • 修复了与 OpenAI 兼容的端点分辨率、堆叠 SDK 重试、思考标签解析、Gemini 叙述历史、Azure TTS client 生命周期、Xinference 重新排序错误传播和表情符号标记估计。 （#10079、#9669、#10116、#10132、#10101、#10051、#10216）
  • 修复 Lark 私信发送、QQ 官方提及和 C2C 推流补全、OneBot 文件解析、Telegram 轮询日志过多的问题。 （#10018、#9705、#10069、#10098、#10046）
  • 修复了已清除的 Satori 心跳/重新连接设置和微信公众号超时字段禁用预期保护措施的问题。 （＃10248，＃10229）
  • 修复了来自 URL 和文件的插件更新、Windows 长路径插件提取以及默认 GitHub 分支解析。 （#10053、#10193、#10080）
  • 修复了网络搜索参数处理、知识库 URL 速率限制、文件编辑中的文字转义、图像附件生命周期和清理以及分段回复日志记录失败导致的响应丢失。 （#9979、#10015、#10112、#10042、#10090、#10231）
  • 修复了 SQLModel 升级中的日期时间持久性，并比较了 UTC 中的平台消息历史记录截止值。 （＃10211，＃10246）
  • 修复了过时的桌面 WebUI 资源和服务版本检测、移动抽屉行为、暗模式图标和控制台对比度、隐藏对话、旧图标和卸载后的统计计时器。 （#9898、#10156、#10256、#10061、#10135、#10129、#10278、#10272）

中文

本预发布版本包含自 v4.28.0（提交 a412146401426c0cdff8bbefb8627a03da519da8）以来的变更。

主要新增

  • 电脑使用能力：新增适用于本地执行环境（local）模式下按车辆操作系统的沙箱环境（仅支持 macOS Seatbelt 和 Linux bwrap 环境）。 (#9472)
  • ChatUI：新增聊天历史和侧边栏会话分页、输入草稿持久化、按会话记忆所选模型，以及切换项目时自动聚焦输入框。 (#9667, #10279, #10247, #10301)
  • ChatUI：模型选择器新增来源筛选和吸顶分组，技能与 MCP 页面新增搜索。 (#10084, #10217)
  • WebUI: 桌面端新增工作区目录选择器及更新下载文档。 (#10222, #10227, #10050)
  • 桌面端: WebUI 侧边栏和顶栏改装 macOS 的毛玻璃效果。 (#10222, #10227, #10050)
  • 核心：新增 Agent 剩余步数提醒，迁移旧版本步数限制，提高默认步数上限，并延长 Shell 会话等待时间。 (#10131, #10133)
  • 核心: 为模型重大请求新增 x-astrbot-conversation-id 会话 ID 请求头。 (#10218, #10237)

###主要优化

  • 侧边栏和顶栏优化，全景高度以增加信息密集度。 (#10222, #10227, #10050)
  • 优化「数据与日志」页面对话数据预览的效果等。 (#10021, #10020, #10023, #10108)
  • 支持可续传的分块上传并控制内存占用，压缩WebUI静态资源，减少字体与图表资源体积。 (#10123, #10187, #10034)
  • 优化流式回复和推理面板的滚动体验，加载历史时保持滚动位置，并按动画帧滚动自动滚动操作。 (#10219, #10221, #10243, #10253, #10257, #10271)
  • 优化模型输入图片限制处理，保留图片几何比例、编码后结构模型，模型说明动图已转换为多帧拼图。 (#9703, #10071, #10120, #10119)
  • 批量渲染控制台日志，优化模型启动弹窗和追踪记录更新，减少会话查询及限流关闭时的额外开销。 (#9990, #10007, #10270, #10273, #10274)

###主要修复

  • 恢复旧版本的命令语义：/reset 清空当前会话上下文，/new 创建并切换到新会话；修复持久化会话删除和历史标题显示。 (#10118, #10003, #9983)
  • 修复队列请求的历史浏览、会话锁前的附件准备，以及关闭LLM处理后队列请求仍然继续执行的问题。 (#10238, #10209, #10234)
  • 修复WebChat子线程的模型选择、主动代理的模型回退、WebChat唤醒远端限制，以及流式回退回复丢失。 (#10065, #10028, #10245, #10025)
  • 修复定时代理的失败记录、上下文压缩和插件过滤；无效编辑不再丢失提醒，明确任务归属，定位失败的宽限时间延长至 300 秒。 (#9987, #9992, #10163, #10075, #10104, #10183)
  • 修复 OpenAI 兼容地址解析、SDK 重试中心、思考标签解析、Gemini 工具调用前文本历史、Azure TTS 客户端生命周期、Xinference 重排错误传送及表情令牌。 (#10079, #9669, #10116, #10132, #10101, #10051, #10216)
  • 修复飞书私聊消息投递、QQ官方机器人群聊提及和私聊流结束式帧、OneBot文件解析，以及Telegram轮询日志过多的问题。 (#10018, #9705, #10069, #10098, #10046)
  • 修复清空 Satori 心跳/重连配置和微信公众号超时配置后导致相应保护失效的问题。 (#10248, #10229)
  • 修复通过 URL 和文件更新插件、Windows 长路径插件解压，以及 GitHub 仓库默认分支解析。 (#10053, #10193, #10080)
  • 修复网页搜索参数处理、知识库URL清理限流、文件编辑中的字面转义字符、图片附件生命周期与清理，以及分段回复日志失败导致回复丢失的问题。 (#9979, #10015, #10112, #10042, #10090, #10231)
  • 修复SQLModel升级后的日期时间持久化，并统一使用UTC比较平台消息历史的初始化时间。(#10211, #10246)
  • 修复桌面端近期WebUI资源及版本检测、移动端抽屉行为、深度模式图标和控制台恢复、隐藏组件、旧版本图标，以及统计卸载后启动仍预设的问题。 (#9898, #10156, #10256, #10061, #10135, #10129, #10278, #10272)
