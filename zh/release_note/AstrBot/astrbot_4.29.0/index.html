AstrBot v4.29.0

[4.29.0] - 2026-10-14

此版本包含 v4.29.0-beta.1 和 v4.29.0-beta.2 以来的所有更改，以及自 v4.29.0-beta.2 以来的更改。完整的发布系列从 v4.28.0 开始。

主要补充

  • 计算机使用：为本地执行环境添加了特定于操作系统的沙箱支持，仅在带有 Seatbelt 的 macOS 和带有 bubblewrap 的 Linux 上可用。请参考：https://docs.astrbot.app/use/astrbot-agent-sandbox.html (#9472)
  • ChatUI：添加了聊天历史记录和侧边栏会话分页、持久输入草稿、每会话模型选择以及切换项目时的输入自动对焦。 （#9667、#10279、#10247、#10301）
  • ChatUI：在模型选择中添加了提供商源过滤器和粘性组，并在技能和 MCP 页面上进行搜索。 （＃10084，＃10217）
  • 文本到图像设置已从设置移至配置配置文件 → 扩展，现在为每个配置文件单独配置。
  • 管理员和白名单设置已从 配置配置文件 → 平台 移至 配置配置文件 → 访问控制。 (#10321)
  • WebUI：添加了工作区目录选择器并更新桌面应用程序中的下载进度。 （＃10222，＃10227，＃10050）
  • 桌面：为 WebUI 侧边栏和顶栏添加了 macOS 磨砂玻璃效果。 （＃10222，＃10227，＃10050）
  • 核心：添加了代理步骤预算提醒、迁移了旧限制、增加了默认代理步骤限制以及延长了 shell 会话等待时间。 （＃10131，＃10133）
  • 核心：向提供商请求添加了 x-astrbot-conversation-id 对话 ID 标头。 （＃10218，＃10237）
  • WebUI：在选定模型旁边和模型/后备菜单中添加了模型设置快捷方式。对于使用该模型的每个配置文件，更改会立即保存。 (#10321)
  • WebUI：添加了控制台日志搜索和关键字突出显示、技能源徽章、ChatUI 中的分阶段图像预览，并记住上次打开的“数据和日志”选项卡。 （#10327、#10339、#10376、#10251）
  • WebUI：在机器人编辑器的侧抽屉中添加了配置文件编辑。 (#10310)
  • Docker：包括用于容器内密码重置的 astrbot CLI。 (#10442)
  • 日志：添加了组合级别、源、插件、平台和关键字过滤、隐藏用户聊天日志的选项以及 8-16 像素（默认为 12 像素，以 2 像素为单位）的字体大小控制。插件选择器显示带有 ID 的显示名称作为副标题。 (#10514)

主要优化

  • WebUI：改进了侧边栏和顶栏，减少了它们的垂直占用空间以显示更多信息。 （＃10222，＃10227，＃10050）
  • 改进了“数据和日志”页面上的对话数据预览。 （#10021、#10020、#10023、#10108）
  • 添加了具有有限内存使用的可恢复分块上传、压缩仪表板静态资源以及减少捆绑字体和图表资源。 （#10123、#10187、#10034）
  • 改进了流式响应和推理面板滚动，在加载历史记录时保留滚动位置，以及每个动画帧合并自动滚动。 （#10219、#10221、#10243、#10253、#10257、#10271）
  • 改进了模型输入图像准备，保留图像几何形状，限制编码图像大小，并解释了动画到帧到模型的转换。 （#9703、#10071、#10120、#10119）
  • 批量控制台日志渲染，优化提供程序对话框和跟踪更新，并删除不必要的会话和速率限制工作。 （#9990、#10007、#10270、#10273、#10274）
  • WebUI：通过延迟加载 VAD、Monaco、翻译和 ApexCharts 并启用 gzip 响应，显着减少了初始加载开销并提高了加载速度。 (#10413)
  • WebUI：滚动时保持内容边框和角固定，添加 6px 桌面右侧/底部间隙，并在内容窗格滚动时固定配置/设置标题和部分导航。 (#10480)
  • 计算机使用：澄清了本地权限访问模式，在本地隔离不可用时保持执行和文件访问控制可见，并将设置指南链接到综合代理沙盒指南。 （＃10444，＃10445，＃10487）
  • 文档：更新的中英文插件和内置人工智能指南，包括当前工作流程、故障排除和本地化屏幕截图；更新了 Slack 和 Lark/飞书 设置说明。 （#10487、#10353、#10400）
  • 日志：添加了用于内存过滤的结构化源、插件、平台和类别元数据。当滚动到底部时，新日志会自动跟随，并在查看旧条目时保留阅读位置。 (#10514)
  • 代理：将每次运行的计划任务上下文移至对话历史记录之后，以保持系统提示稳定并保留提示缓存重用。 (#10549)

主要修复

  • 恢复了之前的命令行为：/reset 清除当前对话上下文； /new 创建并切换到新对话。修复了持久的对话删除和历史标题。 （＃10118，＃10003，＃9983）
  • 修复了排队请求历史记录刷新、会话锁定之前的附件准备以及禁用 LLM 处理后继续排队的请求。 （＃10238，＃10209，＃10234）
  • 修复了 WebChat 侧线程模型选择、主动代理模型回退、WebChat 唤醒前缀门控和流式回退回复。 （#10065、#10028、#10245、#10025）
  • 修复了计划代理失败报告、上下文压缩和插件过滤器；保留无效编辑后的提醒，澄清任务所有权，并将 cron 失败宽限期增加到 300 秒。 （#9987、#9992、#10163、#10075、#10104、#10183）
  • 修复了与 OpenAI 兼容的端点分辨率、堆叠 SDK 重试、思维标签解析、Gemini 叙述历史、Azure TTS client 生命周期、Xinference 重新排序错误传播和表情符号标记估计。 （#10079、#9669、#10116、#10132、#10101、#10051、#10216）
  • 修复 Lark 私信发送、QQ 官方提及和 C2C 推流补全、OneBot 文件解析、Telegram 轮询日志过多的问题。 （#10018、#9705、#10069、#10098、#10046）
  • 修复了清除 Satori 心跳/重连设置和微信公众号超时字段的问题
