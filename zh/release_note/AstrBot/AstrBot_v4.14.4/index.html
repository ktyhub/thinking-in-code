AstrBot v4.14.4

修订 发布时间2026年2月4日 来源AstrBotDevs/AstrBot 英文原文

AstrBot v4.14.4

发生了什么变化

v4.14.0 的修补程序

修补程序

  • 修复 token 统计错误的问题，修复在多轮 tool call 情况下或者其他极端情况下可能造成 tool 无限调用的问题。
  • 修复 on_llm_request 钩子可能无法应用效果的问题
  • 由 event.request_llm() 过时导致的群聊上下文感知-主动回复功能可能不可用的问题

有何变化 - 又大又漂亮的版本

如果在之前版本使用了 Skill，这次更新之后需要重新配置 Skill Runtime 相关选项。

新增

  • 🔥 新增未来任务系统（Future Tasks）。给 AstrBot 布置的未来任务，让 AstrBot 能够在某一时刻自动唤醒，帮你完成任务。详见 主动任务 。（实验性） (#4697)
  • 🔥 新增子代理（SubAgent）编排器。（实验性）(#4697)
  • 🔥 AstrBot 目前可以直接通过调用 tool 将图片 / 文件推送给用户，大大提高交互效果。
  • 新增 Computer Use 运行时配置，以融合 Skill 和 Sandbox 配置 (#4831)
  • 新增主题自定义功能，可设置主色与辅色
  • 支持在配置页下人格对话框的编辑人格 (#4826)
  • 支持开关 “追踪” 功能；支持在系统配置中设置是否将日志写入 log 文件 (#4822)

修复

  • ‼️ 修复近期版本引入的 missing 2 required positional arguments: 'filter1' and 'filter2' 相关报错问题 。
  • ‼️ 修复 ChatUI 图片、思考等显示异常问题。
  • ‼️ 修复 Skill 上传到 Sandbox 后未自动解压导致 Agent 无法读取的问题。
  • ‼️ 修复配置特定插件集时 MCP 工具被过滤的问题 (#4825)
  • ‼️ 移除 ChatUI 自带的让 LLM 最后提出问题的 prompt (#4824)
  • ‼️ 修复 WebUI 在上传 Skill 失败后仍显示成功消息的 bug (#4768)
  • 修复 MCP 服务器无法重命名的问题 (#4766)
  • 修复插件的 tool 无法在 WebUI 管理行为中看到来源的问题 (#4776)
  • ‼️ 修复 skill-like 的 tool 模式下，调用 tool 失败的问题 (#4775)

优化

  • WebUI 整体 UI 效果优化
  • 部分 Dialog 标题样式统一

更改内容 (EN)

新功能

  • 引入具有一次性任务和增强的仪表板管理的 CronJob 系统
  • 添加具有主色和辅色选项的主题自定义
  • 添加计算机使用的运行时配置以执行技能沙箱（#4831）
  • 将编辑按钮添加到角色选择器对话框（#4826）
  • 添加跟踪日志记录切换和配置 UI (#4822)
  • 使用 cron-tool 触发器添加主动消息传递功能
  • 使用可配置的工具管理策略实施 SubAgent 协调器
  • 支持解析沙箱文件路径并在必要时自动下载
  • 在 MessagePartsRenderer 中添加嵌入图像和音频样式
  • 介绍i18n基础
  • 保留代理交互历史记录
  • 添加文件下载成功/删除的用户通知

错误修复

  • 提高幽灵插件检测准确性
  • 添加错误处理以防止 Ghost 插件崩溃
  • 防止技能包覆盖现有文件
  • 修复沙箱内技能包解压失败的问题
  • 修复配置特定插件集时过滤 MCP 工具的问题 (#4825)
  • 将 ChatUI 角色弹出窗口合并到默认角色中 (#4824)
  • 修复推理块样式
  • 在 truncate_and_compress 提示中添加缺少的逗号
  • 修复前端仍然显示成功消息（#4768）
  • 修复无法重命名 MCP 服务器的问题 (#4766)
  • 删除技能上传中剩余的沙箱运行时处理（#4798）
  • 修复处理程序模块路径构造（#4776）
  • 修复类似技能的工具调用错误（#4775）

改进

  • 技能管理中的运行时提示和精致的 UI
  • cron-job 页面的性能和用户体验改进
  • 一般 WebUI 性能提升
  • 在下拉列表中按插件对工具进行分组
  • 具有填充和文本样式的一致对话框标题
  • 代码格式统一（ruff格式）
  • 4.13.2 的凹凸版本

其他

  • 删除过时的提醒代码
  • 提取主代理模块以获得更好的架构
  • 合并 AstrBot_skill 分支更改
