AstrBot v4.15.0

发生了什么变化

⚠️ 提醒 v4.14.8 用户：由于 v4.14.8 版本 Bug，若您未使用 Electron AstrBot 桌面应用，会被错误地通过 WebUI 对话框跳转到 Github Releases 页。 类似出现如下对话框： <img 宽度=“400”高度=“710” alt=“图像”src=“https://github.com/user-attachments/assets/e9a0e3e1-d41d-42c5-b36c-6b9efe298dac”/> 如果是这种情况，不要下载和安装下面的安装包。您有两种升级方式：

  1. 您可能需要手动重新部署 AstrBot 才能升级。（如果可以打开更新页面切换新版本则可以忽略此提醒）
  2. 下载此文件，解压后放到 AstrBot 的 data 目录下，替换 dist 目录，然后刷新 WebUI 界面，重新点击更新按钮即可恢复原来的更新对话框。

新增

  • 企业微信智能机器人支持主动消息推送，并新增视频、文件等消息类型支持 (#4999)
  • 企业微信应用支持主动消息推送，并优化企微应用、微信公众号、微信客服的音频处理流程 (#4998)
  • 钉钉适配器支持主动消息推送，并新增图片、视频、音频等消息类型支持 (#4986)
  • 人格管理弹窗新增删除按钮 (#4978)

修复

  • 修复 SubAgents 工具去重相关问题 (#4990)
  • 改进 WeCom AI Bot 的流式消息处理逻辑，提升分段与流式回复稳定性 (#5000)
  • 稳定源码与 Electron 打包环境下的 pip 安装行为，并修复非 Electron 场景点击 WebUI 更新按钮时误触发跳转对话框的问题 (#4996)
  • 修复桌面端后端构建时 certifi 数据收集问题 (#4995)
  • 修复冻结运行时（frozen runtime）中的 pip install 执行问题 (#4985)
  • 为 Windows ARM64 通过 vcpkg 预置 OpenSSL，修复相关构建准备问题

优化

  • 更新 pydantic 依赖版本 (#4980)
  • 调整 GHCR namespace 的 CI 配置

更改内容 (EN)

新功能

  • 增强了角色工具管理并改进了子代理编排的 UI 本地化 (#4990)
  • 为 WeCom AI Bot 添加了主动消息推送，支持视频、文件和更多消息类型 (#4999)
  • 为WeCom应用程序添加了主动消息推送，并改进了WeCom应用程序、微信公众号和WeCom客户服务的音频处理（#4998）
  • 增强的钉钉适配器，具有主动推送功能并支持图像、视频和音频消息类型（#4986）
  • 在角色管理对话框中添加了删除按钮以提高可用性（#4978）

修复

  • 改进了 WeCom AI Bot 中的流消息处理，以实现更好的分段和流回复稳定性 (#5000)
  • 稳定了源和 Electron 打包环境中的 pip 安装行为，并修复了非 Electron 模式下 clicking WebUI 更新时出现的意外重定向对话框 (#4996)
  • 修复了桌面后端构建中的证书数据收集（#4995）
  • 修复了冻结运行时中的 pip install 执行 (#4985)
  • 通过 vcpkg 为 Windows ARM64 构建流程准备 OpenSSL

改进

  • 更新了 pydantic 依赖版本（#4980）
  • 更新了 GHCR 命名空间的 CI 配置
