AstrBot v4.29.3

[4.29.3] - 2026-10-24

生活就像一盒巧克力。

###新增

  • 消息追踪：完善进一步消息追踪能力，支持记录和删除所有入站消息事件，以及事件对应的插件调用和代理调用。（需要先在WebUI左下角设置中开启） (#10614)
  • 诊断导出：支持从控制台和系统设置导出支持脱敏的系统诊断包，包含日志、追踪、配置、插件状态和环境等信息。 (#10418, #10659)
  • 安装脚本：增加多语言安装流程和中国大陆镜像支持。 (#10629)

修复

  • 备份：补全定时任务、持久化文件和相关数据目录的备份与恢复，避免数据丢失。 (#10644, #10661)
  • Gemini：支持模型自定义生成参数，保留显式设置的零值；修复非字符串枚举导致工具架构不兼容的问题。 (#10719, #10635)
  • NVIDIA Rerank：保留模型专用API端点路径，避免请求错误的通用地址。(#10732)
  • 电脑使用：修复 Shipyard Bay 执行结果的解析，以及 Windows Shell 超时或取消时的子进程清理。 (#10671, #10729)
  • WebUI：修复配置刷新后模型元数据丢失、默认聊天模型选择、插件侧栏名称本地化、桌面更新通知和配置模板字段默认值。 (#10522, #10663, #10576, #10622, #10517)
  • WebUI：优化配置说明与条件选项显示，修复全屏日志中的Pip安装弹窗、日志流连接等待和页面切换后的重复日志，并明确插件筛选范围。 (#10647, #10608, #10666, #10694, #10691)
  • 数据库：使用跨数据库兼容的JSON查询表达式。(#10664)

添加

  • 消息跟踪：改进了跟踪，以记录和检查所有传入消息事件及其关联的插件和代理调用。首先在 WebUI 左下角的“设置”中启用它。 (#10614)
  • 诊断：从控制台和系统设置导出具有编辑支持的系统诊断包，包括日志、跟踪、配置、插件状态和环境信息。 （＃10418，＃10659）
  • 安装程序：添加了多语言设置和中国大陆镜像。 (#10629)

已修复

  • 备份：包括备份和恢复操作中的计划任务、持久文件和相关数据目录。 （＃10644，＃10661）
  • Gemini：尊重特定于模型的生成参数和显式零值，并处理工具模式中的非字符串枚举。 （＃10719，＃10635）
  • NVIDIA Rerank：保留特定于模型的端点路径，而不是替换通用端点。 (#10732)
  • 计算机使用：正确解析 Shipyard Bay 执行信封并在超时或取消时清理 Windows shell 子进程。 （＃10671，＃10729）
  • WebUI：配置刷新后保留获取的模型元数据；恢复默认聊天模式选择；本地化插件侧边栏名称；修复桌面更新通知和模板字段默认值。 （#10522、#10663、#10576、#10622、#10517）
  • WebUI：明确配置提示和条件设置；保持 Pip 对话框在全屏日志中可见；及时刷新日志流标头；防止导航后出现重复日志；澄清插件过滤器范围。 （#10647、#10608、#10666、#10694、#10691）
  • 数据库：使用可移植的 JSON 查询表达式。 (#10664)
