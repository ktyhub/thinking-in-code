AstrBot v4.29.4

[4.29.4] - 2026-10-31

###新增

  • 消息按钮：新增跨平台按钮组件，支持链接、消息发送和回调插件，并提供交互超时提示。各平台支持的按钮与文档类型相同。 (#9809)
  • 决策模型：在聊天模型的决策提供者和系统一中新增独立功能，提供插件调用交互选择、布尔判断和评分。 (#10775)
  • 网络搜索接入SerpApi Google News，支持新闻来源、作者、发布时间和WebUI引用展示。 (#10773)
  • 会话与用户选择：统一会话来源选择弹窗，支持昵称搜索、平台标识、分页及ID复制；记录发送者信息并补全飞书、QQ官方群名称。管理员配置入口由“添加更多 → 编辑列表项”改为“选择用户”；原会话端点和列表编辑入口统一为“选择会话来源”，“已知会话”改为“已记录的会话来源”。 (#10747)
  • 机器人管理：删除机器人时可选择清理配置、定时任务、会话、消息记录、追踪和用量数据；默认保留对话与历史数据。 (#10761)
  • 定时任务：支持查看群内共享任务列表，并允许管理员删除群任务。 (#10785)
  • 网络设置：新增 PyPI 镜像选择器和测速功能。 (#10657)

优化与修复

  • 稳定性：修复日志输出受阻时 WebUI 和 WebChat 可能无响应的问题，并在诊断包中提供控制台日志输出统计。 (#10902)
  • 上下文压缩：提高设置，将“历史记录达到上限或上下文窗口紧张时的处理方式”改为“压缩策略”，“上下文压缩模型起始ID”改为“压缩模型”；最大轮数、丢弃轮数、压缩指令、近期上部比例及回退窗口大小移至“更多设置”，保留现有配置和运行行为。 (#10753)
  • 模型服务：保留 Anthropic 兼容服务所需的 API Key 请求头；修复 DashScope Agent 超时配置未生效的问题。 (#10787, #10868)
  • Gemini：提供哺乳期参数快速模板，并修改哺乳期配置工具提示。(#10771, #10875)
  • 插件与技能：修复 NAS 等环境中临时目录与 .astrbot 标记文件冲突导致插件安装失败；报告插件配置重载失败；加载技能时优先使用文件读取工具。 (#10784, #10788, #10789)
  • 安全：为默认 PyPI 启用 TLS 证书校验。 (#10685)
  • 音频：支持带 0x03 东南的腾讯 SILK 音频。 (#10744)
  • ChatUI：文件面板使用当前会话的工作目录。 (#10883)
  • WebUI：优化跟踪列表实时更新、统一配置表单样式、删除自定义规则中不支持“全部”选项，并限制滚动条样式仅在 Firefox 中生效。 (#10748, #10755, #10757, #10760)

添加

  • 消息按钮：添加了用于链接、发送消息和插件回调的便携式按钮组件，并带有交互超时通知。支持的操作类型因平台而异；请参阅文档。 (#9809)
  • 决策模型：添加了一个独立于聊天模型的决策提供程序和一个用于结构化选择、布尔问题和插件分数的 System One 适配器。 (#10775)
  • 网络搜索：将 SerpApi Google 新闻与出版商、作者、出版时间和 WebUI 引用集成。 (#10773)
  • 会话和用户选择：统一会话源选择，包括昵称搜索、平台标签、分页和 ID 复制；记录发件人信息，丰富飞书、QQ官方群名。管理员设置从“添加更多”→“编辑列表项目”移至“选择用户”。以前的会话下拉列表和列表编辑器变为选择会话源；已知会话成为记录的会话源。 (#10747)
  • 机器人管理：删除机器人时添加了选择性清理配置、计划任务、对话、消息历史记录、跟踪和使用数据。默认情况下保留对话和历史数据。 (#10761)
  • 计划任务：共享群组任务列表并允许管理员删除群组任务。 (#10785)
  • 网络设置：添加了 PyPI 镜像选择器和速度测试。 (#10657)

改进和修复

  • 稳定性：修复了当控制台输出被阻止时 WebUI 和 WebChat 变得无响应的问题，并在诊断导出中包含控制台日志删除计数器。 (#10902)
  • 上下文压缩：将历史限制或上下文窗口压力的处理重命名为压缩策略，将上下文压缩的模型提供者 ID 重命名为压缩模型。将最大匝数、丢弃的匝数、压缩指令、最近上下文比率和回退上下文窗口大小移至更多设置，保留现有配置和运行时行为。 (#10753)
  • 模型提供程序：为 Anthropic 兼容的提供程序保留 API 密钥标头，并遵守配置的 DashScope Agent 超时。 （＃10787，＃10868）
  • Gemini：添加原生参数快速模板并修正原生工具配置提示。 （＃10771，＃10875）
  • 插件和技巧：修复了 NAS 和类似环境上临时目录与 .astrbot 标记文件冲突时的插件安装问题；报告插件配置重新加载失败；加载技能时首选文件读取工具。 （＃10784，＃10788，＃10789）
  • 安全性：为默认 PyPI 镜像启用 TLS 证书验证。 (#10685)
  • 音频：支持 0x03 前缀的腾讯 SILK 音频。 (#10744)
  • ChatUI：使用文件面板中的活动会话工作区。 (#10883)
  • WebUI：平滑的实时跟踪更新，统一的配置表单样式，从自定义规则中删除了不支持的“全部”选项，并将本机滚动条样式范围限定为 Firefox。 （#10748、#10755、#10757、#10760）
