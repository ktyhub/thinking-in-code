AstrBot v4.26.5

[4.26.5] - 2026-07-07

添加

  • 添加了在通过扫描二维码创建平台时设置自定义机器人 ID 的支持。 (#9067)
  • 添加了 ChatUI 项目工作区。 (#9066)
  • 添加了改进的 ChatUI 附件显示。 (#9134)
  • 在 ToolLoopAgentRunner 中添加了格式错误的工具调用名称卫生。 (#9144)
  • 在选择器和聊天令牌使用指示器中添加了模型元数据。 (#9161)
  • 添加了事件循环诊断和扩展的诊断文档。 (#9168)
  • 添加了跨平台兼容性和 Python 版本支持的文档。
  • 添加了 POSIX 文件 URI 根保存的测试覆盖范围。 (#8906)

已更改

  • 在信息级别记录事件循环看门狗启动。
  • 将模型元数据与提供者分开。 (#9161)
  • 完善 WebUI 中的小吃栏样式。 (#9173)

已修复

  • 仅启用同步的 ModelScope MCP 服务器。 (#9084)
  • 改进了 MCP client 启动和关闭处理，以避免空转并清理错误、超时和取消。 (#9070)
  • 用预检查替换了脆弱的知识库重复名称错误匹配。 (#9121)
  • 提高了针对每个知识库故障的知识库检索弹性和重新排序选择。 (#9122)
  • 清理了有关文档删除的 KBMedia 记录并修复了知识库统计更新。 (#9120)
  • 使知识库 CRUD API 合约与 kb_name、规范有效负载字段和 OpenAPI 类型保持一致。 (#9000)
  • 约束自定义工作空间路径并保留绝对自定义工作空间路径。
  • 改进了网络搜索 API 密钥故障转移。
  • 读取 ChatUI 会话时强制执行所有权。 (#9141)
  • 安全的项目更新临时暂存。 (#9083)
  • 改进了 QQ 官方在 websocket 发送返回 None 时的重试行为。 (#8977)
  • 保留QQ官方引用的消息上下文。 (#9164)
  • 删除了主动回退时的 QQ 官方回复 ID，以便超大被动回复可以通过主动发送成功。 (#9169)
  • 将 MiMo STT 调整为 V2.5 型号并拒绝非 WAV 音频负载。 (#9118)
  • 将网络聊天历史时间戳序列化为 UTC 感知的 ISO 字符串。 (#9159)
  • 在 WebUI 中启用时同步插件激活状态。 (#9156)
  • 在禁用时退出生命周期任务中的 MCP anyio 上下文。 (#9132)
  • 修复了泄漏的 SSE 退出堆栈处理，可能导致 MCP epoll 忙等待。 (#8307) [4.26.5]：https://github.com/AstrBotDevs/AstrBot/compare/v4.26.4…v4.26.5
