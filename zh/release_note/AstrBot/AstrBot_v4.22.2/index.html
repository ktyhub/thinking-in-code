AstrBot v4.22.2

修订 发布时间2026年3月28日 来源AstrBotDevs/AstrBot 英文原文

AstrBot v4.22.2

发生了什么变化

新增

  • 个人微信 新增“对方正在输入…”状态控制能力。（#6977）
  • 配置管理页支持从现有配置复制生成新配置，减少重复创建成本。（#6785）

优化

  • Chat Provider text_chat 接口新增 tool_choice 参数，并为模型空响应引入统一的 EmptyModelOutputError 与增强重试逻辑，改善 “skills-like” 工具调用模式下的稳定性。（#7101、#7104）
  • SSL 证书配置错误时自动回退到非 SSL 模式，而不是程序直接退出。（#7102）

修复

  • 修复 个人微信 Bot 无法发送多媒体文件与 CDN 上传地址兼容性问题，适配新的 upload_full_url 返回格式。#7066）
  • 修复 个人微信 连接超时 / 中断后直接导致微信适配器实例退出的问题，增强了重试机制。（#7041
  • 修复 WebUI Skills 上传对多技能压缩包的处理，允许单个 zip 包内包含多个技能。（#7070）
  • 修复 OpenAI 嵌入模型接口处理相关问题。#7026）
  • QQ 机器人发送语音或音频文件没有响应 （#7007）
  • ChatUI 切换到某个会话，刷新后错误地跳转到最新会话 （#6535）
  • 修复百炼 qwen3-rerank 的请求负载兼容性问题，并忽略不受支持的 return_documents 参数。（#6222）
  • 修复 QQ 下，发送唤醒前缀后，多次空触发 LLM 的问题。（#6893）
  • 修复 GSVI TTS 调用方式与鉴权头构造问题，并补充默认配置值，适配新的 /infer_single API。（#7083）
  • 修复缺失 httpx SOCKS 代理依赖的问题，恢复 SOCKS 代理支持。（#7093）
  • 修复企业微信客服发送失败时无法回退普通消息接口的问题。（#7012）
  • 修复 WebUI 对话管理详情页无法滚动的问题。#6972）
  • 修复 Telegram 附件消息 caption 丢失的问题。（#7020）

更改内容 (EN)

新功能

  • 在 Tool Loop Agent Runner 中添加了 tool_choice，并引入了具有更强重试处理能力的 EmptyModelOutputError，提高了“类似技能”工具调用工作流程的稳定性。（#7101、#7104）
  • 为仪表板添加了 SSL 配置解析和验证，当证书设置无效时自动回退到非 SSL 模式。（#7102）
  • 添加了通过在配置管理页面复制现有配置来创建新配置的功能。（#6785）
  • 更新了QQ官方适配器，支持异步消息解析和附件准备。（#7007）
  • 为微信OC适配器添加了打字状态控制（“用户正在打字…”）。（#6977）

改进

  • 重构聊天 UI 路由和布局，使 UI 模式由 URL 驱动，相关状态范围为 sessionStorage。（#6535）
  • 通过将扩展页面 toast 提示居中并使代码块在深色模式下更具可读性来改进 WebUI 润色。（#6043、#7014）

错误修复

  • 修复了技能安装程序处理，以便单个 zip 存档可以包含多个技能。（#7070）
  • 修复了百联qwen3-rerank负载兼容性并忽略不支持的return_documents参数。（#6222）
  • 修复了空消息上的管道唤醒和请求流程。（#6893）
  • 修复了 GSVI TTS 调用和授权标头构造，并添加了更安全的默认配置值。（#7083）
  • 修复了缺失的 httpx SOCKS 代理依赖项以恢复 SOCKS 代理支持。（#7093）
  • 修复了微信OC入站轮询重试行为以及CDN上传与新的upload_full_url响应字段的兼容性。（#7041、#7066）
  • 修复了WeCom回退行为，以便当KF API返回40096时可以通过常规消息API重试发送。（#7012）
  • 修复了 Telegram 消息中丢失的附件标题。（#7020）
  • 强化 OpenAI 附件恢复并修复嵌入 URL 后缀修剪，以避免恢复失败和意外 URL 字符删除。（#7004、#7026）
  • 修复了预览容器中围绕列表选项标签映射、缺少图标和鼠标滚轮处理的仪表板回归问题。（#6844、#6970、#6972
