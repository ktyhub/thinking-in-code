MoneyPrinterTurbo v1.3.10

修订 发布时间2026年11月7日 来源harry0703/MoneyPrinterTurbo 英文原文

MoneyPrinterTurbo v1.3.10

英语 | 中文

亮点

  • 添加了带有设备代码登录和动态模型选择的 OpenAI Codex 订阅访问，以及单独的 ChatGPT Native OAuth 提供商。本机 OAuth 可用性取决于帐户资格；现有的 Codex 登录保持独立。
  • 添加了 Codex 图像生成 作为材料源。文本和图像生成可以共享应用程序的Codex登录，生成的图像支持现有的静态和慢速缩放效果。
  • 添加了用于 LLM 和视频生成的 Infistar 和 Jalapeno Cloud，以及 Runcrate、CloudGPU 和 Cheapaimodel LLM 提供商。
  • 改进了长时间运行的视频生成反馈，包括生成阶段、经过的时间和轮询状态。任务跟踪不会受到页面刷新和临时查询失败的影响，并防止重复提交。
  • 简化了 WebUI 中的提供商设置和选择，使配置的服务更易于查找和切换。
  • 添加了阿拉伯脚本字幕 shaping，包括连接字母、从右到左布局、混合脚本字体后备以及字形感知包装和背景。
  • 通过子像素渲染使慢速图像缩放更加平滑，消除可见的步进和摆动。
  • 在脚本语言选择中添加了印度尼西亚语，并改进了印度尼西亚语界面翻译。

修复和改进

  • 修复了由于流媒体块之间不必要的延迟而导致的长 Edge TTS 旁白超时问题。添加了对带有脚本子标签的 Edge 语音的支持和更清晰的 Gemini 空音频诊断。
  • 从旁白和内置字幕中删除了表情符号，并澄清 Gemini 和 MiMo TTS 不使用语音速度设置。
  • 改进了围绕时钟时间、全角数字、日期、缩写、名称以及中文和日文标点符号的字幕分割。添加了泰语和老挝语脚本的句子分割。
  • 当字幕修正无法对齐完整脚本时，保留原始定时转录。修复了字幕相似度评分中的空字符串和 Unicode 长度扩展情况。
  • 保留多语言社交标签中的组合标记，排除表情符号标记以及可识别的中文和日文标签分隔符。
  • 当 AI 生成失败时保留现有脚本和关键字，显示可操作的错误，并避免在脚本生成失败后请求关键字。
  • 在脚本顺序库存匹配期间保留重复主题的位置，修复损坏的视频缓存，并添加更清晰的 Pexels 和 Coverr 搜索失败日志。
  • 停止因过早结束或停止 FFmpeg clip 连接而导致的控制台击键。修复了 Windows 上的渲染输出同步和大端灰度 TIFF 亮度。
  • 改进了从包含特殊字符的路径、其他工作目录以及启用 LAN 侦听的 Windows 启动。修复了保存配置时重定向的控制台日志并保留 Windows 路径和不间断空格。
  • 跨工作线程共享 Redis 任务并发限制，具有原子槽预留、租约续订和排队任务恢复。
  • 改进了字幕字体错误消息、API 枚举默认值和 ChatGPT/Codex 登录诊断。澄清了 Docker 配置设置以及从意外安装的 config.toml 目录中恢复的问题。
  • 更新了 CPU 容器依赖关系以解决可修复的安全问题，并添加了容器漏洞扫描。扩大了回归覆盖范围并更正了特定于 Windows 的路径断言。
