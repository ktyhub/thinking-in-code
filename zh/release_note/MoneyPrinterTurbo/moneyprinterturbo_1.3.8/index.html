MoneyPrinterTurbo v1.3.8

修订 发布时间2026年10月3日 来源harry0703/MoneyPrinterTurbo 英文原文

MoneyPrinterTurbo v1.3.8

英语 | 中文

亮点

  • 在素材下载、clip 处理和最终渲染期间添加了连续进度报告，并且来自后台帮助程序线程的任务日志在 WebUI 中可见。
  • 添加了可配置的库存材质和 clip 渲染并发。库存材料并发适用于 Pexels、Pixabay 和 Coverr；两个设置默认为 1（串行处理）。
  • 添加了 VoxCPM 参考音频语音克隆和可选的传递调节，以延续节奏和情感，并使用本地 Whisper 转录来编辑参考转录。
  • 添加了 Fluxion AI、Cheaper Inference、Requesty、FutureInfra、Y-API 和 iFlytek Spark (Astron MaaS) LLM 提供商。
  • 新增MuAPI作为视频素材源，具有模型端点配置和异步生成。
  • 添加了加泰罗尼亚语 WebUI 本地化。
  • 通过在主渲染管道中使用 BT.709 转换矩阵和颜色元数据来提高视频颜色一致性。
  • 添加了一个选择加入的本地视频项目 CLI，具有修订跟踪、更改比较以及在替换场景、旁白或背景音乐时重用未更改的渲染工件。

修复和改进

  • 改进了 Redis 任务更新、队列准入和启动恢复，以减少丢失字段、调度冲突和停滞队列。无效的排队请求不再阻止调度以后可用的任务。
  • 增加了 FFmpeg 操作停滞的最后期限并改进了临时文件清理。失败的编码不再用不完整的文件替换成功的视频输出。
  • 通过隔离作业和视频组合之间的串联清单和中间 clips 来改进并发渲染。
  • 将远程视频下载流式传输到缓存中，添加了下载限制和验证，并改进了缓存标识和清理，以避免重复使用错误的资源或删除新的下载。
  • 改进了本地素材处理，包括支持的上传格式、图像解码、相机方向、CMYK 颜色以及拒绝被错误识别为视频片段的专辑插图。
  • 字幕文本中出现的保留时间戳、Whisper 单词结果中的标点符号以及手动换行符。禁用的字幕不再拾取过时的字幕文件。
  • 改进了字幕计时回退和并发 Whisper 初始化。空字幕结果现在明确失败，而不是在没有提示的情况下发布字幕文件。
  • 跨多个提供商的强化旁白生成：在替换现有文件之前验证音频，在导出失败时保留成功的旁白，并在合成已被接受后停止不安全的重试。
  • 改进了暂停片段组装和 Azure 计时转换，并修复了仅旁白导出而忽略配置的音频音量。
  • 改进了脚本和关键字生成验证，防止提供程序错误消息被接受为生成的内容。更新了 Groq 已退役的默认模型，并通过 stdin 传递 Claude Code 提示。
  • 添加了针对本地材料和自定义旁白的 WebUI 预检验证。改进了设置缓存序列化、活动任务刷新、历史数据处理、版本检查和失败的音频上传清理。
  • 强化上传的文件名、字幕字体路径、媒体大小限制和渲染参数。扩展了 Windows 烟雾覆盖范围并修复了子进程输出解码以使用 UTF-8。
  • 拒绝对多个凭证或可能付费的请求的重定向，减少凭证暴露和意外重复提交。
  • 改进了上传-发布结果验证和恢复跟踪。排队发布会保留所选帐户，并且即使没有生成元数据，YouTube 隐私设置也会保留。
  • 改进了 API 下载 URL、特殊字符 escaping、媒体类型、范围处理、布尔解析、CORS 源规范化和验证错误响应。
  • 更新了提供程序文档、示例配置和代理帮助程序，以更好地匹配支持的 CLI 功能和材料源。

使用及升级注意事项

  • 两种并发设置默认为 1。 较高的库存材料并发可能会触发提供商速率限制；更高的 clip 渲染并发使用更多的 CPU 和内存。根据您的环境增加它们。
  • 当需要合成时，VoxCPM 参考音频和交付记录将发送至 ModelBest。仅使用您自己的声音或您有权使用的录音。可选的本地 Whisper 转录可以在首次使用时下载配置的模型。
  • 本地视频项目工作流程仅限CLI，最初范围为准备本地镜头和旁白。它不添加 WebUI 视频编辑器或自动生成脚本、语音、字幕或转场。保留的源快照和修订需要额外的磁盘空间。
  • 自定义字幕字体必须在项目的 resource/fonts 目录中解析。指向该目录之外的外部路径和符号链接将被拒绝。
  • 重定向生成请求的提供商或网关现在需要直接配置其最终 API 端点。未经确认的付费请求会停止本地处理，而不是自动重新提交；这并不意味着最初的请求没有被收取费用。
  • 新的提供商集成需要相应的 API 凭证和服务配置。 iFlytek Spark 的即用即付和 Token Plan 端点使用不同的凭证；选择与您的帐户匹配的端点。
  • 现有的WebUI生成入口点保持不变。可以根据需要使用新的并发选项、参考音频控件和本地项目 CLI。
