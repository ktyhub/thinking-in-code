MoneyPrinterTurbo v1.3.9

修订 发布时间2026年10月21日 来源harry0703/MoneyPrinterTurbo 英文原文

MoneyPrinterTurbo v1.3.9

英语 | 中文

亮点

  • 添加了官方 mpt 点包装。使用 mpt webui 启动 WebUI 或使用 mpt cli 生成视频。
  • 为本地和人工智能生成的图像添加了静态和慢速缩放图像效果。慢速变焦仍然是默认设置。
  • 添加了具有浏览器授权的 Kimi Code 订阅访问权限，以及对登录对话框、状态更新和取消的改进。
  • 为 OpenAI 兼容的图像素材工作流程添加了可选的本地 SDXL 图像服务器，并具有空闲 GPU 卸载功能。
  • 新增 Opper、onomeo、Muse Spark 和 EmpirioLabs AI LLM 提供商，并完成巴西葡萄牙语 WebUI 翻译。
  • 在 WebUI 中添加了诊断日志记录控件，包括运行时日志级别更改和选择加入带有修订和大小限制的 API 请求跟踪。

修复和改进

  • 修复了灰度图像亮度、透明图像背景、缩放蒙版对齐和字幕背景颜色。改进了短 clips 的过渡、背景音乐淡出以及串联路径中的特殊字符处理。
  • 跨并发作业隔离中间图像文件，改进图像缓存身份并验证缓存下载。当同一批中的另一个视频失败时，已完成的视频将被保留。
  • 修复了多个提供商之间的语音速度、音量和音频容器处理问题。改进了远程音频验证并保留现有音频，直到替换输出准备就绪。
  • 改进了字幕时间戳舍入、长字换行、Unicode 处理和暂停标签识别。仅符号线和分隔符不再扭曲估计的字幕对齐方式。
  • 使用整个脚本修复了中文和日文后备社交标题。改进了 JSON 提取、推理删除、Markdown 清理和生成的搜索项验证。
  • 扩展了支持的本地上传格式，包括多图片相机 JPEG。改进了 WebUI 中的任务历史记录检查、删除状态、字幕预览和模型连接错误消息。
  • 添加了对生成工件的 HEAD 支持，并改进了字节范围下载、验证错误以及 Redis 任务更新和删除保护措施。
  • 减少了丢失响应或重定向后的不安全语音重新提交，保留了 Upload-Post 跟踪句柄，并改进了 WaveSpeed 提交错误检测。
  • 更新了 Edge TTS 以解决 403 故障，限制 PyAV 以实现 Whisper 兼容性，并修复了 Windows 缓存清理和区域设置文件中的 UTF-8 BOM 处理。
  • 改进了代理助手的配置处理和飞行前检查，包括不需要法学硕士的带有准备好的旁白和视觉效果的工作流程。

重点更新

  • 支持通过pip安装官方**mpt包**，使用mpt webui启动界面，或通过mpt cli生成视频。
  • 新增图片动态效果选项，本地图片和AI生成图片渴望选择“静止”或“缓慢放大”，默认保留缓慢放大。
  • 新增Kimi Code订阅状态接入，支持查看器授权登录，并优化登录窗口布局、更新和取消操作。
  • 新增可选的本地SDXL生图服务，通过OpenAI兼容接口接入图片素材生成，支持空闲时释
