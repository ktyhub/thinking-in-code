adk-python v2.12.0

2.12.0 (2026-10-13)

亮点

此版本增强了长时间会话中的执行性能，同时引入了对工具执行、工作流审批和部署安全性的更精细控制。

  • 性能：在长会话中将首次模型请求的时间缩短 40%。 (1754b3e)
  • 工具：在使用 after_tool_callback 将工具输出返回到模型之前拦截和过滤工具输出。 (fdda17c)
  • 工作流程：在通过 require_confirmation 执行工作流程节点之前需要人工确认。 (988fd1a)
  • 部署：使用专用自定义服务帐户将代理部署到代理引擎。 (629e119)
  • Python 3.15：在 Python 3.15 上安装并运行 ADK。 (75aef1e)
