adk-python v2.13.0

2.13.0 (2026-10-22)

亮点

此版本稳定了核心功能，同时引入了 TypeSafe 工作流分类、实时音频交互、MongoDB 集成和执行性能改进。

  • 稳定性：访问 12 个成熟的实验性功能现已提升至稳定状态。详情请参阅单位指南。 (ea298d4)
  • 分类器：通过新的 TypesafeClassifier 和 ClassifierNode 使用 TypeSafe 的 Jev 模型路由工作流程。 Jev 在一次前向传递中返回校准概率，比法学硕士快得多。详情请参阅装置指南。 （[ddf8c55]（https://github.com/google/adk-python/commit/ddf8c55eb6bc5e0c5fb90acbed3b66af939f7d7a），[e8c4bac]（https://github.com/google/adk-python/commit/e8c4bacdfe675ceb5adcaf24ea005af94d271c68））
  • 实时音频：通过插入支持以及 Gemini 语音到文本和文本到语音集成，实现自然的实时语音交互。详情请参阅装置指南。 (2e7ef92)
  • MongoDB 会话和内存：在 MongoDB 中保留会话并使用新的 MongoDbSessionService 在运行器副本之间共享它们。使用 MongoDbMemoryService 添加长期记忆，无需嵌入模型，它可以在任何 MongoDB 部署上通过关键字匹配来回忆过去的轮次，无需向量索引。两者都是实验性的。有关更多详细信息，请参阅会话服务和内存服务指南。 （[0df43f5]（https://github.com/google/adk-python/commit/0df43f572b0c24d0e76123e44e7a090c5a785df2），[e40e349]（https://github.com/google/adk-python/commit/e40e3496cdbe38d4c7194f127d9b2566f1bdbb0c））
  • MongoDB：将 MongoDbToolset 部署到代理引擎，无需打包连接字符串，并让 Atlas 自动嵌入在服务器端嵌入搜索查询，无需 Google 嵌入调用或凭据。详情请参阅装置指南。 (bc3773f、2f6c666、8bbfc33)
  • 性能：字符串模型代理的执行速度提高了 8 倍，并减少了事件加载开销。 (772f139)

重大变更

  • 遥测：默认为 OpenTelemetry GenAI v2（otel_semconv_1_44，删除 call_llm）；设置 ADK_TELEMETRY_SCHEMA_VERSION_OPT_IN=otel_semconv_1_36 以保留旧版 v1 架构。详情请参阅装置指南。 (7838488)
