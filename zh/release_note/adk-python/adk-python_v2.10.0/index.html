adk-python v2.10.0

2.10.0 (2026-09-24)

亮点

该版本引入了先进的技能生命周期管理，扩展了数据库和模型集成支持，并为座席评估带来了更丰富的效率指标。

  • 技能：使用新的短暂生命周期和活动技能限制动态控制资源使用和工具持久性（实验性；使用 ADK_ENABLE_SKILL_LIFECYCLE=1 启用）。 (43b73e4)
  • 数据库集成：使用新的 MongoDB 工具集在代理流程中无缝执行高性能向量和混合搜索。 (0961ced)
  • 评估：使用新的评估指标来跟踪持续时间、令牌消耗和模型调用计数，优化代理执行成本和延迟。 (2d428ea)
  • 模型支持：将 OpenAI 推理模型与自动请求参数自适应和精确推理令牌报告更有效地集成。 (52a2f0f)

行为改变

  • BigQuery 受保护写入模式 现在仅当试运行将其放入会话的匿名数据集中时才运行非 SELECT 语句，因此多语句脚本、CALL、EXPORT DATA 以及试运行未给出目标的其他语句都会被拒绝。 (8b883d0)
  • BigQuery 保护模式 将其 BigQuery 会话保留在进程内存中而不是会话状态中，因此其临时表无法在重新启动后保留或转移到另一个副本。 (094012b)
  • OpenAIResponsesLlm 忽略 thinking_config (thinking_level / thinking_budget) 并发出警告；请改用 OpenAIGenerateContentConfig.effort。 (b3d1392)
  • AgentEvaluator.evaluate 和 evaluate_eval_set 在没有评估评估案例时引发 ValueError，而不是通过。 (9dbc2ae)
  • 指令模板 将 ${var} 和反斜杠转义的 \{var} 保留为书面形式，而不是从状态填充它们。 (0caecd2)
  • google.adk.flows.llm_flows（audio_cache_manager、audio_transcriber、transcription_manager）下的传统现场音频模块在导入时发出 DeprecationWarning；移动到google.adk.live。使用 -W error 运行的测试套件将在这些导入上失败。 (bf2bc56)
