adk-python v2.9.0

2.9.0 (2026-09-10)

亮点

此版本通过引入自动模型故障转移、通过 LiveKit 的本机语音支持以及与 MCP SDK 2.x 的兼容性，重点关注代理弹性和生态系统集成。

  • 模型：当主模型遇到错误时，通过自动故障转移到备份模型来保障代理的正常运行时间。 (c300b8d)
  • 集成：使用新添加的 LiveKit 运行程序构建丰富的语音和电话代理。 (f277d91)
  • 工作流程：通过直接从声明性 YAML 配置创作和加载 ADK 2.0 图形来简化图形工作流程管理。 (2a9461b)
  • MCP：无缝升级到 MCP SDK 2.x 功能，同时保留与 1.x 服务器的完全向后兼容性。 (856acf2)

行为改变

  • 工作流节点恢复：当工作流恢复时，失败的节点现在会再次运行，之前的情况会像已完成一样重播。使节点体幂等：执行外部副作用然后失败的节点将在每次恢复时再次执行该副作用。 (91573eb)
  • GCS 工具本地路径：GCS 工具现在仅在 local_file_root 命名的目录内读取和写入本地文件，并且当该设置不存在时完全拒绝本地文件访问。路径可以是绝对的或相对的，并根据它们解析的位置来判断。 (c569796)
  • 仅限内存中会话：现在，当事件附加到未保存的会话时，InMemorySessionService 会引发 SessionNotFoundError，而不是接受事件并丢弃它。数据库支持的服务已经以这种方式运行，因此这仅影响内存中的会话。 (15b1392)
