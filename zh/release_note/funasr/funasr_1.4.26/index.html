FunASR v1.4.26

最终出版接受

GitHub 版本和 PyPI 1.4.26 已发布。两个官方 PyPI 发行版均已下载并通过 SHA-256 和大小匹配 GitHub：

  • funasr-1.4.26-py3-none-any.whl：1015738字节； SHA-256 104e3704fed0ecfd6c08836468de147a2c6f05745281093b8a6dbe341d1ce831。
  • funasr-1.4.26.tar.gz：1086172 字节； SHA-256 763c7d860a49afd17e4b9c0636ff43f03f6519e68bd0a09a25d68318091e2cf8。

FunASR 1.4.26

来源：cdd82b5cbfd05015f8fb2b167d61f25142c3a9e8 / 标签 v1.4.26。

修复

  • #3874：response_format=text 现在返回裸 HTTP 记录，而不是 JSON 引用的字符串。
  • #3872 / #3883：保留英语和韩语 VAD 片段中的单词分隔符，同时保留 CJK 和仅事件行为。保留原作者的提交。

此根轮不提供独立的 ONNX/Torch 缩写和批量填充时间戳修复。他们的软件包版本是分开的。打开#3861、#3862、#3867，新的热词 PR 未声明已解决。

验证范围

  • #3874 之前通过了 32 个实际的 HTTP/SDK 案例和 213 个相关的 CPU 案例；它的源字节在这里保持不变。
  • #3883 在最初的 230 次通过中通过了 246 个独特的选定 CPU 案例，并完成了 6 个可选依赖案例以及 10 个实际安装的独立轮案例。所有原始的跳过和负运行都将保留。 NumPy 托管的 CI 每个版本有 421 次通过和 27 次仅限 CUDA 的跳过，不接受 GPU 接受。
  • 发布/文档候选检查：{‘contract-green’：{‘testcase’：53，‘failure’：0，‘error’：0，‘skipped’：0}，‘static-remainder’：{‘testcase’：104，‘failure’：0，‘error’：0，‘skipped’：2}，‘installed-behavior-candidate’： {‘testcase’：111，‘failure’：0，‘error’：0，‘skipped’：0}，‘site-boundary-integration’：{‘testcase’：69，‘failure’：0，‘error’：0，‘skipped’：0}，‘site-manifest-integration’：{‘testcase’：21，‘failure’： 0，“错误”：0，“跳过”：0}}。实际安装的根轮最终计数：{‘testcase’: 111, ‘failure’: 0, ‘error’: 0, ‘skipped’: 0}。从根轮测试中显式取消选择独立运行时路径。所有 439 个包文件和 13 个入口点均与接受的源匹配。
  • 根模型/GPU 运行时字节与 1.4.25 相比没有变化，并且仍受其先前接受的 L20Z 证据的约束。没有声称新的 GPU 执行、预训练的 ASR 质量、全套或 Nano 结果。
  • 头、合并主和最终标签托管 CI 和实际结帐树分别接受。最终的 Python 轮和 sdist 是新下载的，并检查元数据、确切的源字节、存档完整性、严格的 Twine、私人离线安装和 CLI 行为。
  • 十个未更改的运行时存档重用完整的缓存字节，并通过存档完整性检查针对新资产和原始运行时版本重新进行了重新哈希。它们没有被重建或重新执行。 SHA256SUMS 涵盖所有 12 个有效负载。
  • 1.4.24 警告仍然适用：使用norm_means=True 和norm_vars=True 训练的检查点需要重新评估识别质量。 norm_vars=False 仍然是默认值。
  • 无生产升级或采用/增长声明。

发生了什么变化

  • 修复（运行时）：通过 @LauraGPT 在 https://github.com/modelscope/FunASR/pull/3876 中将 ONNX 非 WAV 音频加载释放为 0.4.10
  • 修复（服务器）：返回 https://github.com/modelscope/FunASR/pull/3874 中@David-Wu1119 的response_format=text 的纯文本
  • 修复（运行时）：在 https://github.com/modelscope/FunASR/pull/3869 中 @tanishqbaweja 将 funasr_onnx 和 funasr_torch Sentence_postprocess 中拼出的首字母缩略词合并为一个单词
  • 修复（运行时）：在 https://github.com/modelscope/FunASR/pull/3871 中@tanishqbaweja 在 funasr_onnx 和 funasr_torch Paraformer 时间戳之前从 CIF 峰值中修剪批量填充
  • 修复（后处理）：通过 @LauraGPT 在 https://github.com/modelscope/FunASR/pull/3883 中保留当前主 CI 的 VAD 字边界
  • 修复（后处理）：在 https://github.com/modelscope/FunASR/pull/3872 中@David-Wu1119 的丰富转录中保留拉丁语 VAD 片段之间的空格
  • 由 @LauraGPT 在 https://github.com/modelscope/FunASR/pull/3884 中发布 FunASR 1.4.26
