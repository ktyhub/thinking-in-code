peft v0.20.0

亮点

该版本添加了至少九种新的 PEFT 方法，并对周围的基础设施进行了大量工作，例如为方法比较套件添加了新的图像生成基准，并极大地改进了文档结构。

新方法

希拉

@hqsiswiliam 在 PEFT (#2668) 中添加了 “HiRA：大型语言模型的参数高效 Hadamard 高阶自适应”。 HiRA 不是将低阶乘积 BA 添加到基本重量中，而是将其按元素（Hadamard 乘积）与冻结的基本重量相乘。由于基本权重本身是满秩的，因此生成的更新不再被限制为低秩，而可训练参数计数与 LoRA 相同。

格洛拉

@not-lain 在#3098 中贡献了 GLoRA：“One-for-All：用于参数高效微调的通用 LoRA”。它是一种灵活的 PEFT 方法，通过可配置的权重、激活和偏差自适应来扩展 LoRA，提供更丰富的微调，而无需额外的推理成本。当您需要每层灵活性或比普通 LoRA 更强的适应性时，请使用它。对于非线性层（例如 Conv/Embedding）或当标准 LoRA 已经足够并且简单性很重要时，请跳过它。

贝夫特

@whubaichuan 在#3195 中添加了“BEFT：语言模型的偏置高效微调”。 BEFT 建立在这样的观察之上：仅微调偏差项在低数据情况下就可以具有竞争力，但更进一步：它不是训练所有偏差，而是默认针对价值预测，因为作者发现这是最有效的。这使得可训练参数数量减少到总参数的大约 0.01%。

蒙特克洛拉

@victor7246 在 #2943 中集成了 MonteCLoRA，“通过低阶适应的贝叶斯重新参数化对 LLM 进行鲁棒且高效的微调”。众所周知，LoRA 对学习率和批量大小等超参数很敏感。这个新的 LoRA 变体通过将低秩参数视为分布而不是点估计来解决这个问题，并使用蒙特卡罗估计来获得低方差后验估计。这应该会使训练明显更加稳健，而代价只是_O(rank)_个额外参数。

维罗拉

@roymiles 在 #3159 中添加了 VeLoRA：“使用 Rank-1 子代币投影进行内存高效训练”。与大多数 PEFT 方法不同，这种 LoRA 变体的目标是激活内存而不是参数计数：中间激活被分成子令牌，并使用固定的 1 级投影进行压缩，然后缓存用于反向传播，然后在反向传播期间进行重建。从概念上讲，它类似于梯度检查点，具有较低的内存节省但运行速度更快。

Uni-LoRA

@KaiyangLi1992 在 #3257 中贡献了 Uni-LoRA：“一个向量就是你所需要的”。该论文表明，VeRA 和 VB-LoRA 等参数高效的 LoRA 变体都可以被描述为将完整的 LoRA 参数空间投影到更小的子空间，仅在投影的选择上有所不同。 Uni-LoRA 在整个模型中使用单个全局投影，而不是逐层投影，这允许跨层参数共享，因此参数数量非常低。

弗洛德

@Bane-Elvin 在 #3270 中添加了 FRoD，“通过旋转度进行全阶高效微调以实现快速收敛”。它不像 LoRA 那样添加低秩增量，而是使用共享旋转子空间和稀疏可训练系数来重建选定的权重。当快速收敛和更高的满秩容量上限很重要时，它特别有用，并且其大的稀疏旋转子空间也可能有希望用于模型合并。主要的权衡是昂贵的联合分解初始化和比 LoRA 稍慢的前向/后向传递，因此对于一次性单任务微调来说可能不太有吸引力。

米卡

@sr-networks 在 #3260 中贡献了 MiCA，“MiCA 比 LoRA 学习更多知识并进行全面微调”。 MiCA 是一种 LoRA 变体，它从基本权重的 SVD 初始化 B，采用属于最小奇异值的左奇异向量，然后仅训练 A。这个想法是，适应这些未充分利用的方向比适应主导子空间更有效地整合新知识，并且对现有能力的干扰更少。

敏捷

@MAXNORM8650 在 #3342 中添加了 DEFT，“文本到图像模型的分解高效微调”。这种 PEFT 方法将权重更新分为两个学习的低秩部分：一个删除冻结权重子空间的投影，以及一个在其位置注入新内容的低秩更新。使用 DEFT 从一些图像个性化文本到图像模型，同时保留基本模型的指令跟踪/可编辑性，并最大限度地减少遗忘。如果您不需要保留基本模型的其他功能（普通的附加适配器更简单）或对于 Linear/Conv1D 之外的层，那么它不太合适。作为 DEFT 的特例，还支持 PaRa 方法。

增强功能

自动 LoRA 目标选择

@oswaldoludwig 基于 “条件数作为神经单元信息编码的尺度不变代理” 在 #3106 中添加了 KappaTuneSelector。 PR 添加了一个新函数 find_kappa_target_modules，它可以根据基本权重矩阵的条件数自动识别哪些模块最适合作为目标。这消除了在配置 LoRA 或其他 PEFT 方法时选择 target_modules 的一些猜测。

更广泛的量化支持

#3117 添加了对 BOFT、MiSS 和 VeRA 的通用量化支持，#3321 对 SHiRA 做了同样的事情。以前，量化支持必须按方法和后端实现；现在有更多方法可与开箱即用的常见量化后端配合使用。请注意，因此，VeRA 现在使用通用量化后端，而不是之前的位和字节量化后端。如果您因此遇到问题，请告诉我们。

带有 target_parameters 的多个适配器

target_parameters 允许直接定位 nn.Parameter（对于将专家打包到单个参数中的 MoE 模型很有用），现在支持添加和加载多个适配器 (#3350)。

Conv2d 的 AdaLoRA

@Anai-Guo 在 #3196 中添加了 SVDConv2d，因此 AdaLoRA 现在可以定位 torch.nn.Conv2d 层。

文档重组

PEFT 文档 在 #3300 和 #3325 中进行了重新组织，既然 PEFT 支持如此多的方法，这应该会使导航变得更加容易。每种 PEFT 方法还概述了其在 PEFT 基准中的表现。此版本中许多贡献者还对文档进行了长尾改进，感谢所有参与这些工作的人。

变化

AutoGPTQ 弃用

在上一版本中切换为 GPT-QModel 作为后端之后，由于@Qubitium，AutoGPTQ 现已正式弃用 (#3190)。

基准测试

图像生成基准

方法比较套件现在有图像生成基准（#3082）。这补充了现有的 MetaMathQA 基准，并允许在完全不同的任务上比较 PEFT 方法。这让我们更全面地了解不同 PEFT 方法的功能。要检查结果，请访问Gradio Space，然后在左上角选择任务“image-gen”。

查看图像生成基准测试的结果

元数学QA

自上一个版本以来，我们还对 MetaMathQA 基准 进行了多项改进。您应该在Gradio Space中查看更新的结果。在社区的帮助下，我们现在涵盖了更广泛的实验。此外，我们发现了遗忘指标中的一个错误——新的数字现在准确地反映了微调保留了基本模型的原始知识的程度。

PEFT 商店

#3317 添加了一个新的 Gradio Space，其目标是使比较不同的 PEFT 方法变得非常容易，不仅在性能方面而且在功能方面（例如，是否支持量化）。访问此空间，了解哪种 PEFT 方法最适合您的使用案例。
