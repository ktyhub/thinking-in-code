spring-cloud-alibaba 2022.0.0.0-RC2

大版本 来源alibaba/spring-cloud-alibaba

spring-cloud-alibaba 2022.0.0.0-RC2

⭐️ 特性 / 改进

  • [Seata] 优化了 alibaba-seata：使用 feign.RequestInterceptor 传递 XID (#3171)
  • [Seata] 支持 Seata 模块的 GraalVM (#3161)
  • [Sentinel] 解决了 Sentinel OpenFeign 静态编译问题 (#3184)
  • [Sentinel] 解决了注解 SentinelRestTemplate 无法加载到 native-image 问题 (#3168)
  • [Sentinel] 回退支持 FactoryBean (#3135)
  • [Sentinel] Sentinel Feign-Client 支持快速注册 (#3007)
  • [Sentinel] 重构了 Sentinel 示例 (#3144)
  • [Sentinel] 移除了 Sentinel 的 @Validated 注解 (#3122)
  • [Sentinel] 将 PostConstruct 方法设为公开 (#3009)
  • [Dependency] 更新了 2022.x 分支中的 yml 格式 (#3098)
  • [Dependency] 添加了 maven 示例模块 (#3001)
  • [RocketMQ] 移除了重复的依赖项 (#3008)
  • [Nacos] 支持在 SCL 中双栈地址注册和发现 (#3236)
  • [Nacos] 更新了 nacos-config-examples (#3010)
  • [Nacos] 支持在 JSON 配置中添加注释 (#3047)
  • [Enhancements] 将 Maven 版本更新至 3.9.0 (#3228)
  • [Enhancements] 为集成示例添加了 Docker 支持 (#3209)

🐞 Bug 修复

  • [RocketMQ] 修复了可轮询消费者未正确确认消息的问题 (#3248)
  • [RocketMQ] 修复了 RocketMQ SecretKey 泄漏风险 (#3091)
  • [Nacos] 修复了 NacosLoadBalancer 不能与 HintBasedServiceInstanceListSupplier 一起使用的问题 (#3270)
  • [Nacos] 修复了移除无效依赖定义的问题 (#3178)
  • [Nacos] 修复了 nacos 发现/配置日志的问题 (#3166)
  • [Nacos] 修复了 IPv6 地址无效后缀问题 (#3189)
  • [Sentinel] 修复了反应式 Sentinel 断路器测试 (#3054)
  • [Example] 修复了 sidecar-example 示例 (#3267)
  • [Example] 修复了 webClient 无法调用 nacos 服务的问题 (#3254)

  • [Spring Boot] 升级到 3.0.2 (#3184)
