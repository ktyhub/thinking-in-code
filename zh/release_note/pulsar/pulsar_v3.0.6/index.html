  • [fix][broker] 修复启用主题级别复制并构建远程管理员失败时的卡住问题 (#23028)
  • [fix][broker] 修复 oldestBacklogMessageAgeSeconds 持续增加的问题，即使没有积压 (#22907)
  • [fix][broker] 修复在命名空间级别进行复制并设置主题策略时的 updatePartitionedTopic 问题 (#22971)
  • [fix][broker] 修复 TopicName.getPartition(int index) 方法的错误逻辑 (#19841)
  • [fix][broker] 处理 BucketDelayedDeliveryTracker 恢复失败 (#22735)
  • [fix][broker] 立即将已删除和空闲状态的包标记为墓碑 (#22743)
  • [fix][broker] 使 ExtensibleLoadManagerImpl.getOwnedServiceUnits 异步化 (#22727)
  • [fix][broker] 使用主题级别复制时远程集群上的消息丢失 (#22890)
  • [fix][broker] 如果 —stream-storage-port 不是 4181，PulsarStandalone 启动时出错 (#22993)
  • [fix][broker] 从 Subscription.getStats 中移除阻塞调用 (#23088)
  • [fix][broker] 当两个集群之间的分区数量不同时，复制卡住 (#22983)
  • [fix][broker] 支持扩展负载管理器的查找选项 (#22487)
  • [fix][broker] 更新初始化和关闭时间及其他次要逻辑（仅限 ExtensibleLoadManagerImpl） (#22930)
  • [fix][broker] 在健康检查中检测到死锁时，broker 会记录完整的线程转储 (#22916)
  • [fix][broker] 修复禁用主题级别地理复制时的死锁问题 (#22738)
  • [fix][broker] 修复即使禁用主题级别复制，主题分区仍然扩展的问题 (#22769)
  • [fix][broker] 如果主题不存在，在调用 getPartitionedTopicMetadata 时响应未找到错误 (#22838)
  • [fix][broker] 修复 lookupService.getTopicsUnderNamespace 无法与引号模式一起使用的问题 (#23014)
  • [fix][broker][branch-3.0] 不要尝试从非活动源 broker 中清理拥有的包（仅限 ExtensibleLoadManagerImpl） (#23064) (#23077)
  • [fix][broker][branch-3.0] 主题可能引用已关闭的分类帐 (#22860) (#22900)
  • [improve][broker] 在其他操作之前先检查最大生产者/消费者限制以节省资源 (#23074)
  • [improve][broker] 在重用之前清除线程本地 BrokerEntryMetadata 实例 (#22752)
  • [improve][broker] 跟进 #4196 使用 PulsarByteBufAllocator 处理 OOM (#20837)
  • [improve][broker] GetPartitionMetadata 失败时也可以生产消息 (#23050)
  • [improve][broker] 提高 TopicName 缓存的 CPU 资源使用效率 (#23052)
  • [improve][broker] 提高检查消息删除的效率 (#20490)
  • [improve][broker] 改进没有模式的主题检查的异常处理 (#22974)
  • [improve][broker] 在服务器分发中包含运行时依赖项 (#22001)
  • [improve][broker] 优化 PersistentTopic.getLastDispatchablePosition (#22707)
  • [improve][broker] PIP-356 支持从最早位置开始的地理复制 (#22856)
  • [improve][broker] 移除 ClassLoaderSwitcher 以避免对象分配并保持代码风格一致 (#22796)
