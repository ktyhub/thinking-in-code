pulsar v4.2.0

2026-04-01

批准的 PIP

  • PIP-434：将 Netty 通道配置 WRITE_BUFFER_WATER_MARK 暴露给 pulsar conf，并在通道不可写时暂停接收请求
  • PIP-437：消息传递的细化和固定延迟策略
  • PIP-439：通过托管事务包装为 Pulsar 功能添加事务支持
  • PIP-442：在代理和代理上添加 CommandGetTopicsOfNamespace 和 CommandWatchTopicList 的内存限制
  • PIP-443：停止在新代码中使用 Netty 回收器
  • PIP-444：删除账本的速率限制以减轻 zk 压力。
  • PIP-446：支持 Pulsar Java Client 中的本机 OpenTelemetry 跟踪
  • PIP-447：主题指标的可定制 Prometheus 标签
  • PIP-452：具有属性的命名空间的可自定义主题列表
  • PIP-453：改进元数据存储线程模型
  • PIP-454：元数据存储迁移框架
  • PIP-464：弃用 SchemaType.JSON 的旧 Jackson JsonSchema 格式
