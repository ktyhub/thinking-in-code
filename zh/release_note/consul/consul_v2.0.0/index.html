consul v2.0.0

2.0.0 (May 22, 2026)

安全：

  • 连接：将 Envoy 版本升级到 1.37.2 及更新版本 [GH-23469]
  • go: 升级go版本至1.26 [GH-23493]
  • 代理：增加默认 HTTP 服务器超时，以防止破坏长轮询阻塞查询。 read_timeout 和 write_timeout 现在设置为 15 分钟（从 30 秒增加），而 read_header_timeout（10 秒）和 idle_timeout（120 秒）仍然提供针对 Slowloris 攻击的保护。所有超时仍然可以通过 http_config 块进行配置。 [GH-23267]
  • api-网关、终止网关：在 api-网关和终止网关 HTTP 侦听器上应用 HTTP 请求路径规范化，以防止通过非规范化路径绕过 L7 意图 RBAC (CVE-2024-10005)。 [GH-23534]
  • docker：将 ubi 基础镜像更新为 ubi9-minimal:9.7。 [GH-23553]
  • docker：将容器镜像中的 Alpine 边缘的 curl 升级为 >= 8.20.0 以解决 [CVE-2026-6429]（https://www.cve.org/CVERecord?id=CVE-2026-6429）， CVE-2026-4873, [CVE-2026-5773]（https://www.cve.org/CVERecord?id=CVE-2026-5773）， [CVE-2026-6253]（https://www.cve.org/CVERecord?id=CVE-2026-6253）， CVE-2026-6276, CVE-2026-7168, CVE-2026-5545。 Alpine 3.23 stable 尚未搭载补丁版本。 [GH-23750]
  • docker：将 UBI 基础映像更新为 9.8 以修复 [CVE_2026-2100] [GH-23588]

特点：

  • （仅限企业） 更新到 go-licensing/v4 和 go-census/v3 以适应 PAO 的新许可证。
  • 全局速率限制器：（仅限企业） 一种新的“速率限制”配置条目类型，可实现动态、集群范围内的 RPC 速率限制，存储在 Raft 中并自动复制到所有服务器。这允许操作员在运行时应用或调整全局速率限制，而无需重新启动 Consul 服务器——这对于集群负载过重的紧急情况来说是一项关键功能。
  • api-gateway：添加了对 API 网关侦听器的 SDS 证书支持，包括侦听器级默认 TLS 证书和 HTTP/TCP 路由服务 TLS SDS 覆盖。服务覆盖在省略时继承侦听器 SDS 集群，并且网关验证/xDS 生成现在会拒绝冲突的覆盖映射以保持证书选择的确定性。 [GH-23354]
  • api-gateway：添加对网关级默认上游限制的支持以及 MaxConnections、MaxPendingRequests 和 MaxConcurrentRequests 的路由服务级别限制覆盖。 [GH-23396]
  • api：添加了新的 API“/v1/internal/rpc/methods”，列出了所有 RPC 方法名称。 Requires an operator:read ACL token.当用户想要配置排除特定 RPC 端点的速率限制时，这非常有用。 [GH-23329]
  • ca：（仅限企业） 为 Cyberark WIM 添加了新的 Connect CA 提供程序（connect.ca_provider =“pan-distributed-issuer”），使 Consul 能够通过 Cyberark WIM 颁发证书。
  • 服务器：（仅限企业） 添加稳定的集群身份和领导者控制的全局注册表同步以进行服务摘要发布。
  • 遥测：（仅限企业） 用于自我管理 Consul 的产品遥测，具有匿名、选择加入的使用情况报告。
  • mesh：（仅限企业） 在Consul中引入对多端口（命名端口）服务的支持，包括使用端口名称指定和路由流量的能力，以及检索特定服务端口的虚拟IP的能力。它还强制要求某些高级多端口功能仅在 Consul Enterprise 中可用，并包括用于集群命名和 ALPN 协议生成的新实用程序功能。

改进：

  • 代理：（仅限企业） 为企业使用指标添加最终一致的后台缓存，将 GET /v1/operator/usage 延迟从 O(PNK) 减少到 O(1)，并通过手表驱动的维护者 Goroutine 降低高频 scraping 期间的 CPU/内存压力。
  • mesh：（仅限企业） 在Consul中引入对多端口（命名端口）服务的支持，包括使用端口名称指定和路由流量的能力，以及检索特定服务端口的虚拟IP的能力。它还强制要求某些高级多端口功能仅在 Consul Enterprise 中可用，并包括用于集群命名和 ALPN 协议生成的新实用程序功能。
  • terminate-gateway：更新了集群上游 tls 以使用 sds 而不是静态证书，允许动态证书更新而无需重新启动终止网关。 [GH-23288]
  • 遥测：使用 Prometheus 指标（标有数据中心/分区/命名空间）添加证书过期监控、具有可配置严重性阈值的结构化日志记录，以及增强的 Connect CA API 以包含根证书和中间证书的 NotAfter 字段。 [GH-23147]
  • 相关内容：将 github.com/hashicorp/vault/sdk 从 v0.7.0 升级到 v0.25.1，将 github.com/hashicorp/vault/api 从 v1.12.2 升级到 v1.16.0。 [GH-23574]
  • test-integ：集成测试模块中升级testcontainers-go（v0.22.0->v0.40.0）和docker/docker（v24.0.5->v28.5.1）。这将删除 opencontainers/runc 作为测试框架的 Go 依赖项。这些只是测试基础设施依赖项，对 consul 二进制文件或任何 consul 部署没有影响。 [GH-23573]
  • xds：将 Consecutive5xx、ConsecutiveGatewayFailure 和 EnforcingConsecutiveGatewayFailure 字段添加到 PassiveHealthCheck，允许操作员为上游默认值上的 5xx 响应和网关故障 (502/503/504) 配置 Envoy 异常值检测阈值。

错误修复：

  • 审核日志记录：（仅限企业） 修复了为auditReq 主体传递obj 数组时出现的JSON 解组错误。
  • cli：增强了 consul config write 命令中的错误消息，以便在由于网关或路由器的引用而无法修改配置条目时提供可操作的指导。 [GH-22921]
  • xds：修复了 XDS 包，以便在对等互连时为 API 网关生成正确的端点和集群配置，并更新了 API 网关更新处理程序以将网状网关配置传播到其上游。 [GH-23454]
  • XDS：修复了 AWS EKS 上远程模式下的网状网关问题，因为 DNS 主机名分配给 AWS NLB 而不是 IP，并且 Envoy 的 EDS 端点验证期望地址是 IP。现在，对于具有基于主机名的网关的非对等远程网状网关目标，将跳过 EDS 负载分配，从而保持 CDS/EDS 同步。 [GH-23543]
  • api网关：在API网关发现链综合期间解析路由的服务子集。 [GH-23294]
  • ui：修复损坏的文档链接 [GH-23578]
