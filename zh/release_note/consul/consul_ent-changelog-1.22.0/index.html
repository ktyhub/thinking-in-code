consul ent-changelog-1.22.0

1.22.0+ent（2025 年 10 月 24 日）

创建此版本是为了共享 Consul Enterprise changelog 并通知消费者可用性。随附的源代码和资产不包括 Consul Enterprise 代码，不应用于代替官方 Docker 映像或二进制文件。

安全：

  • connect：将Consul的捆绑Envoy版本升级到1.35.3并删除对1.31.10的支持。此更新还包括修复程序，通过仅在存在 CA 捆绑包时配置 TLS 传输套接字来防止 Envoy (v1.35+) 启动失败。 [GH-22824]
  • 安全性：在未启用 ACL 的情况下启用远程/本地脚本检查时添加警告 [GH-22877]
  • 安全性：改进了 Consul KV 端点中 Content-Length 标头的验证，以防止潜在的拒绝服务攻击 CVE-2025-11374 [GH-22916]
  • 安全性：在事件端点上添加最大内容长度以修复拒绝服务 (DoS) 攻击。这解决了 CVE-2025-11375。 [GH-22836]
  • 安全性：重大更改 - 在键/值端点上添加键名称验证以及 DisableKVKeyValidation 配置，以禁用/启用它来修复对配置错误或丢失 ACL 策略的路径遍历攻击。 [GH-22850]

特点：

  • 添加了在具有多个端口的 consul 中注册服务的支持 [GH-22769]
  • 代理：添加了 IsDualStack 实用程序函数，以根据从“agent/self”API 检索到的绑定地址来检测代理是否配置为 IPv4 和 IPv6（双栈模式）。 [GH-22741]
  • 安装：安装后显示的更新的许可证信息
  • ipv6：添加 ip6tables 更改以实现 ipv6 和双堆栈支持 [GH-22787]
  • oidc：使用 JWT 断言和 PKCE 添加 client 身份验证。默认 PKCE 已启用。 [GH-22732]

改进：

  • 安全性：将golang升级到1.25.3。 [GH-22926]
  • ui：修复当前发生的计算属性覆盖问题，并在某些情况下先发制人，因为这已在 ember v4 中被弃用 [GH-22947]
  • ui：删除作为 https://deprecations.emberjs.com/id/ember-component-send-action/ 一部分的发送操作实例 [GH-22938]
  • ui：用组件替换 ember 部分作为升级到 ember v4 的增量步骤 [GH-22888]
  • api：添加了新的 API (/v1/operator/utilization) 以支持企业 API 进行手动快照报告 [GH-22837]
  • cmd：添加了新的子命令 consul operator utilization [-today-only] [-message] [-y] 以生成包含人口普查利用率快照的捆绑包。主流程在consul-enterprise中实现 http：为 /v1/operator/utilization 添加了新的 API 处理程序。 consul-enterprise 中要实现的核心功能 代理：始终启用人口普查指标收集，并具有可配置选项以将其导出到 Hashicorp 报告 [GH-22843]
  • cli：snapshot agent 现在支持使用 Azure 托管服务标识 (MSI) 向 Azure Blob 存储进行身份验证。 [GH-11171]
  • 命令：connect envoy bootstrap 在纯 IPv4 环境中默认为 127.0.0.1，在 IPv6/DualStack 环境中默认为 ::1。 [GH-22763]
  • 连接：默认的upstream.local_bind_address为::1用于IPv6代理绑定地址[GH-22773]
  • 代理：IPv6 代理绑定地址的默认 proxy.local_service_address 为 ::1 [GH-22772]
  • ui：改进了 Consul UI 中的辅助功能，以增强残障用户的可用性 [GH-22770]
  • ui：用pnpm替换yarn以进行包管理[GH-22790]
  • ui：身份验证方法配置值溢出。此 PR 修复了该问题，并为内容较多的表格元素添加了分词符。 [GH-22813]

错误修复：

  • ui: 允许在 Consul Web 界面中显示 FQDN。 [GH-22779]
  • ui：修复了选项卡切换后命名空间消失和欢迎使用命名空间屏幕出现的问题 [GH-22789]
  • ui：修复了删除多个令牌或策略时，右侧的三个点在第一次删除后停止响应的问题。 [GH-22752]
  • cmd：修复 consul operator utilization --help 以仅显示可用选项，无需额外参数。 [GH-22912]
