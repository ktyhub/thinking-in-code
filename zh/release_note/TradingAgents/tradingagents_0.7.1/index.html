TradingAgents v0.7.1

修订 发布时间2026年10月27日 来源TauricResearch/TradingAgents 英文原文

TradingAgents v0.7.1

决策仅在最终收盘时进行评分，并在漫长的市场假期期间结算，模型的未填充日期不再读取运行日期之后提交的文件，并修复了投资组合、价格、SEC 声明、报告、Azure 和 Claude 设置。

从 0.7.0 升级

  • Docker 图像不再包含 .env.enterprise。对于 Docker 中的 Azure OpenAI，请将其密钥放入 .env 中。

已修复

  • 模型通过且没有零填充的日期（例如 2024-7-5）将被读取为该日期。它可以比运行日期之后提交的文件进行比较，然后 SEC EDGAR 送达该文件。 (#1488)
  • 不再对仍在交易的时段的柱进行评分，并且在休市时间超过一周（例如国定假日）之前做出的决定将在交易恢复后结算，而不是保持悬而未决。 （＃1548，＃1539）
  • 回测报告其最后一次结算通行证的失败，并且同一秒开始的两个不再共享一次运行。 （＃1557，＃1549）
  • 以经纪人的拼写（BTCUSDT、700.HK）列出的持股与分析的工具相匹配，并且在文件加载时拒绝非有限的投资组合编号。 （＃1556，＃1509）
  • 价格保持有效数字：低于美分的收盘价不再显示为 0.00，货币对保持其点值。 (#1567)
  • SEC EDGAR 语句每个周期列出一行，因此模型不再读取长期历史中错误季度的数字，并且一百万以下的数字不再打印为 0。（#1517、#1589）
  • 将报告保存到之前使用的文件夹中会删除先前运行的部分。 (#1566)
  • 在开始之前结束的日期窗口将被发送回模型，而不是不返回任何数据。 (#1595)
  • 除年度或季度之外的报表频率将被发送回模型，而不是在该词下提供年度数据。 (#1593)
  • 记忆的最新课程和条目轮换保留，遵循决策日期，因此旧日期的回填不再取代它们。 (#1603)
  • 接近 0% 或 100% 的预测市场赔率显示其与该赔率的距离为两位有效数字。 (#1598)
  • Azure OpenAI 接收 max_tokens 和配置的终结点。 （＃1584，＃1600）
  • 对于过时的模型ID（例如claude-sonnet-4-20250514），克劳德的努力设置是正确决定的。 (#1585)
  • CLI 使用与运行相同的规则检查代码，因此在提示时接受 XAUUSD+，而拒绝 ..。 (#1604)
  • Docker 图像不再包含任何文件夹中的 .env 文件。
  • 修复了因平台原因在 Windows 和 macOS 上失败的测试。 （＃1506，＃1485，＃1541）
