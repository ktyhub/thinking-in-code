TradingAgents v0.7.0

在您的 ChatGPT 计划上运行，回测从每次决定后的第一次关闭开始进行评分，在新版本发布时启动时进行注释，并在每个 GitHub 版本上附加一个轮子。

添加

  • 您的 ChatGPT 计划。 chatgpt 提供商通过 OpenAI 的开源应用程序登录在 ChatGPT Plus 或 Pro 计划（而不是 API 密钥）上运行 TradingAgents。在CLI的提供商菜单中选择“订阅”；对于无人值守运行，Docker 和 Python (llm_provider="chatgpt")，请使用 tradingagents login chatgpt 登录一次。 tradingagents logout chatgpt 撤销登录。 CLI 列出了该计划的模型，推理工作的应用与 OpenAI 一样。 （＃1194，＃1475）
  • 启动时的新功能。 交互式 CLI 提到了一个较新的版本，其中包含当它可以告诉 TradingAgents 的安装方式时升级此安装的命令，以及来自 Tauric Research 的运行版本的通知。它每天最多在后台检查一次，因此运行永远不会等待它；在没有终端的情况下运行从不检查，TRADINGAGENTS_NO_UPDATE_CHECK=1 将其关闭。
  • 版本下载。 每个 GitHub 版本都带有源存档和轮子，因此版本会从其版本页面与 pip install 一起安装，而无需克隆。

从 0.6.0 升级

  • 安装了 cryptography 42 和 packaging 24 或更高版本。
  • 现在，决定是从约会后的第一次结束时开始计分的。已经在内存日志中确定的结果保留了较早的条目、决策日期的结束时间，因此使用 run_id 恢复的回测将两者混合在一起；开始新的运行以进行同类比较。

已修复

  • 不再根据无法交易的新闻对决策进行评分：日期为 d 的运行读取 d 收盘后发布的新闻，因此内存日志和回测在 d 之后的第一次收盘时输入，而不是 d 收盘时输入。 (#1518)
  • 没有终端的运行（例如计划作业或 CI）在开始之前不再联系公告服务器。
  • 当主提供者没有时，另一个提供者上的模型层保留其配置的推理工作、思维水平或克劳德工作。 (#1440)
