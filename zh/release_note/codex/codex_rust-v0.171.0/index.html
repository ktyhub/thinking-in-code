codex rust-v0.171.0

发布 发布时间2026年11月20日 来源openai/codex 英文原文

codex rust-v0.171.0

新功能

  • 将 GPT-6.2 Sol 和 Astra 添加到模型目录中，并将 Sol 作为默认目录选择。 (#62106)
  • 默认情况下启用 TUI 工作区，在主要对话旁边提供可搜索的文档预览、图像预览和子代理记录。 （#61352、#61888、#61889、#61919、#62157）
  • 为非 Vim 提示编辑器添加了可配置的撤消和重做快捷方式，包括恢复附件和大型粘贴。 (#61954)
  • 添加了 codex exec --remote <ADDR> 以在现有应用程序服务器上启动或恢复非交互式会话。 (#61707)
  • 添加了 /rc 和 /remote 以管理本地远程控制并从 TUI 显示设备配对代码。 (#62121)
  • 当启用 tui_extensions_statusline 时，添加了自定义 MCP 状态行选择和通过 /statusline 进行创作。 （#61979、#61988、#62037）

错误修复

  • 切换或恢复会话时保留的草稿、排队的后续内容以及原始线程的中断输入。 (#61216)
  • 更改工作目录时保持权限配置文件完整。 (#61195)
  • 防止延迟完成事件取消对新轮次的批准。 (#61801)
  • 转向主动转弯时，保留了聚合差异中的早期编辑。 (#61820)
  • 修复了插入杂散字符、作曲家插入符跳转以及使用过时的终端尺寸重绘的滚动问题。 （#62139、#62174、#62175）
  • 修复了颁发 ID 令牌而无需刷新令牌的身份提供商的企业 MCP 登录问题。 (#62129)

家务事

  • 将源构建和发布工具更新为 Rust 1.99.1。 (#61205)
  • 更新了 XML 依赖项并删除了过时的安全建议例外。 (#62068)
