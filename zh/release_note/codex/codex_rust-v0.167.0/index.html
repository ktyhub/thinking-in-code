codex rust-v0.167.0

发布 发布时间2026年11月6日 来源openai/codex 英文原文

codex rust-v0.167.0

新功能

  • 使用 codex agents --no-daemon 打开代理命令中心。命令中心和会话选择器现在标记未读结果（#58238、#58239、#58263、#58264）。
  • 从终端会话选择器在连接的后端之间切换，并在切换时保留草稿（#58280、#58457）。
  • 在支持的终端上撰写时预览本地图像附件，并从 clickable 转录路径打开查看的本地图像（#58261、#58446）。
  • 在“以另一种方式登录”下找到 API 密钥和云提供商选项。启用 gcp_setup_wizard 以使用应用程序默认凭据或凭据文件设置 Google Cloud Vertex AI（#57857、#58427）。
  • 从 /experimental 选择进入 macOS 或 Windows 系统代理设置 (#58157)。
  • 当批准提示打开时，直接在记录中展开补丁详细信息 (#58281)。

错误修复

  • 切换模型提供商后，保存的聊天记录仍然可见。如果聊天无法恢复，您可以阅读其记录并准备可编辑的提示以在新聊天中继续 (#58202)。
  • Ctrl+L 清除终端显示，同时通过 Ctrl+T 保留早期消息（#58266）。
  • 删除暴露前导 ! 的文本会在聊天模式下保留普通草稿 (#58412)。
  • 当他们的请求结束时，网络批准提示将关闭。对同一端点的并发请求一次提示一个（#58350、#58351）。
  • 随着文字记录的增长，长时间的实时 V3 对话会将完整的语音保存到聊天历史记录中 (#58221)。
  • 自动上下文压缩现在可以考虑失败响应和缺少令牌使用数据的响应的保留输出 (#58404)。

文档

  • 应用程序服务器自述文件涵盖了 [permissions.network] 和 prompt-user 命令规则下的托管网络约束，需要新的人工批准（#58045、#58182）。
  • 当从已弃用的模型迁移时，openai-docs 技能建议使用记录的替换（#58134）。

家务事

  • DotSlash 清单现在引用该版本附带的 Cargo 包（#58717、#58757）。
  • Linux musl 构建使用更少的分配器区域来减少会话卸载后的空闲内存 (#58399)。
