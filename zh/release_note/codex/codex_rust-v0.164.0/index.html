codex rust-v0.164.0

发布 发布时间2026年10月23日 来源openai/codex 英文原文

codex rust-v0.164.0

新功能

  • 将可重复使用的提示和斜线命令保存在十个编号的 /presets 插槽中，并通过键盘菜单进行快速访问。 （＃54380，＃54381）
  • 使用内联 /model 和 /permissions 参数直接设置模型、推理工作、速度和权限配置文件。 （＃54378，＃54383）
  • 在支持 Kitty 或 Sixel 图形的终端上以全屏脚本预览查看和生成的图像。 (#54216)
  • 使用符合条件的 Codex 帐户授予或专用登录来验证企业 MCP 连接，包括需要机密的 OAuth clients。 （#55334、#55859、#56001）
  • 在支持的远程 Bash 命令和 Zsh 快照会话期间屏蔽凭据，包括来自自定义提供商的凭据。 （#54309、#54432、#56049）
  • 现在默认启用 Amazon Bedrock 设置向导，在检测到凭证时，API 密钥条目将与其他 AWS 登录方法分组在一起。 （＃56033，＃56023）

错误修复

  • 失败的压缩不再在对话历史记录中留下部分摘要，并且背景压缩失败会回退而不会惊慌。 （＃53932，＃55581）
  • 恢复会话现在会查找压缩历史记录并恢复保存的线程设置，而不是用全局默认值替换它们。 （＃54008，＃55923）
  • Windows HTTPS 和 WebSocket 连接现在使用登录用户的 Negotiate 或 NTLM 凭据处理代理身份验证质询。 （#55994，#56000）
  • 当 -c 或 --config 出现在多个子命令级别时，将保留 CLI 配置覆盖。 (#56022)
  • 排队提示现在等待待处理的权限选择解决后再继续。 (#55682)
  • 强化沙箱检查 macOS 上大小写变化的元数据路径以及用于查找可执行文件的可替换符号链接。 （＃54273，＃55384）

家务事

  • 通过修剪未使用的安装、清理废弃的市场结帐和限制守护程序日志来减少磁盘使用。 （#53827、#55149、#55689、#55690、#55856）
  • 通过安全检查更新了嵌入式 JavaScript 运行时，以优化 Array.sort 操作。 (#54519)
