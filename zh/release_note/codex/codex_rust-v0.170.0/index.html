codex rust-v0.170.0

发布 发布时间2026年11月18日 来源openai/codex 英文原文

codex rust-v0.170.0

新功能

  • 在 TUI 中添加了用于实时语音通话的 WebRTC 协商。 (#61172)
  • 为 OpenTelemetry HTTP 导出器添加了自动刷新的身份验证标头。 (#61028)
  • 添加了对跨环境使用相同名称的 MCP 服务器的实验性支持。 (#60905)

错误修复

  • 超大的 WebSocket 请求现在回退到 HTTP，无需进行不必要的重试。 （#60840，#60841）
  • 修复了取消、登录和注销期间的 MCP OAuth 凭证竞争问题。 （＃60849，＃60981）
  • 改进了云对话的自动重新连接，并在 clients 重新连接时保留主动恢复轮次。 （#60969，#61014）
  • 修复了 Windows 文件替换、沙箱权限保存和运行时注册恢复。 （#60872、#60943、#60944）
  • 修复了权限更新和子线程丢失现有沙箱限制的问题。 （#60936，#61134）
  • 删除了重复的文件搜索结果并修复了包含空格的查询的线程搜索片段。 （#60845，#60846）

文档

  • 更新了沙箱文档以解释权限配置文件和文件系统规则。 (#61133)
