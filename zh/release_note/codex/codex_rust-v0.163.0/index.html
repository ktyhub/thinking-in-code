codex rust-v0.163.0

发布 发布时间2026年10月15日 来源openai/codex 英文原文

codex rust-v0.163.0

新功能

  • 打开 /config 跨类别搜索首选项，立即更改支持的设置，并查看哪些更改需要重新启动。 （＃52990，＃53429）
  • 在 Codex 响应时发送后续信息以立即引导它。中断转动还会停止活动的代码模式单元及其嵌套工具调用。 （＃51812，＃51835）
  • 在 /keymap 中配置领导者密钥。默认值为 Ctrl+X，快捷方式提示保持打开状态，直到您选择或取消为止，并且语音静音会移至 F9。 (#52273)
  • 从 /daemon 重新启动托管后台服务器。 Codex 警告重新启动可能会中断工作，然后自动重新连接。 (#53173)
  • Codex 可以并行运行独立的只读工具，包括技能、记忆和对话历史记录查找。 (#52245)
  • 符合条件的帐户默认启用 Daybreak。当服务器提供访问权限时，codex exec 还可以使用 OpenAI API 密钥选择它。 （＃53701，＃53717）

错误修复

  • 恢复已保存的线程可恢复其权限和网络批准，同时遵守显式覆盖和当前托管策略。 （#53150、#53419、#53424）
  • 网络代理现在在 DNS 查找之前检查权限，拒绝重复的 Host 标头，并防止凭据别名绕过检查挂钩。 （#51650、#52661、#53506）
  • 切换线程后返回与 /side 的现有侧面对话。对待处理提示的回答也会返回到提出问题的线程。 （＃52184，＃53436）
  • 在 Windows 上，Ctrl+V 和 Shift+Insert 粘贴文本和图像。在 WSL 上，重复粘贴会重复使用 clipboard 读取器，并且复制尝试会超时而不是挂起。 （#53224、#52967、#53453）
  • 当孩子保持输出管道打开时，本地命令会立即完成。远程命令保留迟到的输出，以便最终轮询仍然可以收集它。 （#52652、#53331、#53622）
  • codex exec 在执行不相关的命令后不再打印相同的文件差异。 (#53444)

文档

  • 更新了捆绑的 OpenAI Docs 迁移到 GPT-6 系列的指南，包括特定于模型的推理、工具使用和数据驻留注意事项。 (#51768)
  • 阐明了 Linux 沙箱如何使用 bubblewrap 进行文件系统隔离和 seccomp 进行系统调用过滤。 (#52610)

家务事

  • Codex 现在使用其标准 shell 执行器，不再捆绑经过修补的 zsh。使用已停用的 shell 标志的配置会收到迁移通知。 （＃52160，＃52213）
  • 通过从打包的二进制文件中剥离符号，同时将它们保留在原始构建输出中，减少了 Linux 和 macOS 发行包的大小。 (#52178)
