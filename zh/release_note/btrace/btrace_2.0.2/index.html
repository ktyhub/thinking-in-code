#Changelog

v2.0.2 (2020-05-24)

全Changelog

已修复问题：

  • @OnMethod 与 @Location(RETURN) 和 @Level 导致 NoSuchFieldError: $btrace$$level #419
  • 跟踪的应用程序可能会在退出时死锁 #417
  • 无法将信息打印到控制台 #416
  • 编译失败，并显示“无法定位平台：‘Java SE 11’，使用工具链：‘JDK 9 (1.9)’。” #404
  • java.lang.VerifyError：分支目标 475 处的堆栈映射帧与 Btrace 2.0 #401 不一致
  • 无法打开套接字文件：目标进程没有响应或 HotSpot VM 未加载 #395

已关闭的问题：

  • Btracec 使用 IBM-JDK 编译失败 #403
  • 我感兴趣的是为什么不在 BTraceUtils 中提供方法来 println 对象的所有字段？ #285
  • 问题：如何通过 MBean 公开聚合详细信息？ #270
  • 可见示例 #217
  • 功能请求：添加本机方法的跟踪 #115
  • [BTRACE-78] 使用 @Location #25 到达特定行号时能够查找局部变量的值
  • 无法跟踪对象创建 #356
  • btrace可以实现热插拔吗？ #346
  • 从 AsyncGetCallTrace 收集堆栈 #310
  • 用 HDRHistogram 替换旧的分析基础设施 #297
  • 如果不处于详细模式，则没有控制台输出 #254
  • [BTRACE-74] 使编写检测对象并发访问的 BTrace 脚本变得更容易。 #77
  • [BTRACE-107] Kind.CALL 事件错过了 #70
  • [BTRACE-121] Kind.CALL 对重叠检测的支持不是最佳的 #69
  • [BTRACE-116] 优化注入处理程序方法中对当前 BTrace 运行时的访问 #68
  • [BTRACE-54] 检测类的对象计数 #38
