seatunnel 3.1.0

3.1.0 Release Note

这是 Apache SeaTunnel 继 3.0.0 版本之后的又一个重要版本！

3.1.0 版本包括 395 个 PR 和 11 个新连接器，重点关注 Zeta 引擎稳定性和 Connector-V2 数据正确性。它还改进了部署、操作和数据转换，使生产数据集成作业更加可靠。

感谢所有贡献者为本次更新所做的辛勤工作。我们相信3.1.0版本将为社区带来更加稳定可靠的数据集成体验。

亮点

  • 原生Kubernetes应用模式：每个作业部署一个专用的Master和固定数量的Worker，作业完成时自动进行资源清理，为一次性数据处理作业和运行大规模批量工作负载的团队提供资源隔离和按需资源释放。
  • 最低 Java 版本提升至 11，最高支持 Java 17。

新连接器

  • 连接器-azure-event-hubs
  • 连接器-cdc-oceanbase
  • 连接器文件-smb
  • 连接器-谷歌-分析4
  • 连接器-http-asana
  • 连接器-http-intercom
  • 连接器-http-paypal
  • 连接器-http-splunk
  • 连接器-http-typeform
  • 连接器-系统日志
  • 连接器-websocket
