[SeaTunnel 引擎]

[功能和改进]

[集群管理器]

  • 支持独立运行 SeaTunnel 引擎。
  • 支持运行SeaTunnel引擎集群。
  • 不依赖第三方服务（zookeeper等）来实现master-worker架构。
  • 自治集群（非集中式）。
  • 自动发现集群成员。

####【核心】

  • 支持以本地模式向SeaTunnel Engine提交作业。
  • 支持以集群模式向SeaTunnel Engine提交作业。
  • 支持批量作业。
  • 支持流作业。
  • 支持批量流集成，所有SeaTunnel V2 Connector的批量流集成功能都可以在SeaTunnel Engine中得到保证。
  • 支持分布式快照算法 Chandy Ramport 算法和两阶段提交。基于这些实现的 Exactly-Once 语义。
  • 支持管道粒度作业调度，保证作业在有限资源下能够启动。
  • 支持管道粒度作业恢复。
  • 任务之间共享线程，实现大量小数据集的实时同步。
