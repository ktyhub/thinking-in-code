    seatunnel 2.3.13¶

    seatunnel 是什么¶

    SeaTunnel是一个多模态、高性能、分布式、海量数据集成工具。

    seatunnel 2.3.13 版本更新了什么¶

    2.3.13 发行说明¶

    This is a great milestone for Apache SeaTunnel project! 2.3.13 版本的发布及其众多新功能和修复将显着提高用户数据集成工作流程的效率。

    我们的贡献者为此更新所付出的奉献和辛勤工作给我们留下了深刻的印象，我们相信这个新版本将受到社区的广泛欢迎。
