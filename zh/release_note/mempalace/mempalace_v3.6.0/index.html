mempalace v3.6.0

v3.6.0 — 安全远程服务、临时事实和弹性恢复

此版本使 MemPalace 的操作变得更加容易，超越单一本地流程，同时加强了保护长期宫殿的保证。新的默认安全 mempalace serve 路径支持通过 TLS 和只读强制进行经过身份验证的远程和团队部署；选择加入 Milvus 后端添加了嵌入式、自托管和托管存储选择；原子知识图谱的取代为不断变化的事实提供了精确的时间边界。对话年表、挖掘会话图推导、项目排除和 LaTeX 覆盖加深了摄取，而启动、元数据和恢复工作使大型宫殿更快、更安全。 MCP 表面现在包含 36 个工具。

特点

  • 交钥匙安全远程/团队服务器。 mempalace serve 通过 HTTP 公开完整的 MCP 表面，并具有安全默认值：非环回绑定需要持有者令牌，生成的令牌以限制性权限存储并通过子环境而不是 argv 传递，支持本机 TLS 1.2+，并且 --read-only 隐藏并拒绝变异工具。包括 Docker Compose、systemd 和环境模板。 （＃1877，＃1897，＃1900）
  • Milvus 存储后端。 新的选择加入 milvus 后端支持 Milvus Lite、自托管 Milvus 和 Zilliz Cloud，具有 COSINE 向量搜索、新集合的本机 BM25 词法搜索、命名空间隔离、目标不匹配保护和可选的依赖项额外功能。 (#1899)
  • 原子知识图事实替换。 supersede() / mempalace_kg_supersede 关闭一个开放事实并在一个共享时刻打开其后继事实。时态查询使用时间戳精度的半开间隔，同时保留仅日期事实的全天语义。 (#1913)
  • **保留对话年表。**抽屉将转录时间保留为 authored_at，搜索结果将其公开，精确的混合分数关系更喜欢最近创作的内容，并且幂等的空运行优先回填更新现有宫殿而无需重新嵌入。 mempalace_list_drawers 还获得 since / before 界限。 （＃1890，＃1891）
  • 挖掘的会话填充关联图。 精确偏向的结构提取器将代码符号、URL、路径和合格标识符记录为抽屉实体；对话挖掘从中派生出走廊，由新的 mempalace hallways CLI 命令公开。 （＃1894，＃1895）
  • 通过 mempalace.yaml 中的 exclude_patterns 按项目挖掘排除，无需更改更正的 --limit 语义。 （＃1213，＃1953）
  • LaTeX 项目覆盖 .tex 和 .bib 散文源。 （＃1901）
  • 共享守护进程写入路由策略 提供了一个一致的策略接缝，用于将可写入的 clients 路由到本地守护进程。 (#2027)
  • 检查点作者归属现在保留归档代理，而不是将每个检查点抽屉硬编码为 checkpoint。 （＃2023，＃2034）

性能

  • MCP 初始化不再等待宫殿范围内的完整性工作。 stdio 立即回答 initialize，同时启动预检在后台运行；并发工具加入相同的判决而不是重复工作。大型宫殿启动 SQLite 探针受到限制，而修复预检仍然严格。 （＃1911，＃1987）
  • Qdrant 元数据计数使用服务器端方面，而不是获取和统计每条记录；嵌入包装器正确转发分面和批量元数据功能。 （＃1868，＃1898）
  • pgvector 仅元数据获取省略文档有效负载，减少传输和解码工作。 (#1892)

错误修复

  • 色度恢复区分派生索引损坏和数据丢失。 有效的全层 0 HNSW 段不再重复隔离；隔离的 FTS5 损坏是在修复期间和挖掘后从完整内容重建的；嵌入的 NUL 字节在到达 ChromaDB 之前会被清理。 （#1716、#1872、#1878、#1927、#1928）
  • SQLite 恢复是有界的、原子的和诚实的。 完整性检查会等待暂时的写入器争用；恢复档案使用原子重命名； repair --mode from-sqlite 重建 FTS5，吸尘，并需要干净的最终 PRAGMA quick_check；清理失败返回非零，而不是打印错误的成功。 （#1945、#2015、#2017）
  • CLI 搜索在打开 ChromaDB 之前检查 HNSW 分歧，将损坏的宫殿直接路由到 SQLite BM25，同时将健康和非 Chroma 后端保留在正常路径上。 (#2016)
  • 写入者租约恢复，而不是搁浅服务器只读。 拒绝写入者在对等体退出后重试并升级；状态无法获得作家租约；可重入持有者在中断期间被释放； checkpoint 和 delete_by_source 被正确分类为突变。 （#1923、#1930、#1934、#1960、#1970、#1971）
  • 状态报告仅检查实际运行的情况。 非 Chroma 后端将 Chroma SQLite 完整性标记为不适用。 （＃1931，＃1946）
  • 对话记录被视为可变的。 附加或重写的会话将在修改时间之前被清除并重新归档，而 Claude Code tool-results/ sidecar 则被排除在扫描之外。 （#1957，#2010）
  • 显式宫殿选择范围派生图形状态，因此采矿走廊和隧道保留在选定的 --palace 旁边。 (#2018)
  • 远程和本地服务器强化。 非环回 HTTP 需要令牌，除非显式覆盖；提供者探针在选择之前不能重复使用环境外部密钥；挂钩脚本和文件复制/修复路径接受更严格的验证；导入 MCP 不再破坏 root 日志记录； HTTP写入安全重入宫锁；例程断开连接不再发出回溯。 （#1859、#1860、#1864、#1885、#2003、#2004）
  • 挖掘和配置正确性。 超大文件会发出明显警告，配置的 ~ 路径一致扩展，wing slugs 处理特殊字符，Windows 后台进程避免控制台闪烁。 （＃923，＃1852，＃1857，＃1863，＃1865）
  • Windows .gitignore 处理显式使用 UTF-8，避免与区域设置相关的故障。 (#1648)
  • 当重要性相关时，L1 唤醒更喜欢最新时刻。 （＃1630）
  • 后端检测需要一个SQLite magic header，防止不相关的文件被误认为是宫殿。 （＃1893，＃1896）

文档

  • 添加了存储后端配置参考、远程/团队服务器部署指南、authored_at 迁移指南，并更新了完整 36 工具 MCP 表面的 OpenClaw 集成。 （#1719、#1877、#1890、#1904、#1905）

内部

  • 扩展了 WAL 崩溃安全性、幂等性和编辑路径覆盖范围；更新了 GitHub 动作和 Ruff；修复了 Ruff 0.15.20 和 Python 3.9 依赖标记的 uv.lock 漂移。 （#1869） 非常感谢所有为此版本做出贡献的人。贡献者和首次贡献者的名单如下。
