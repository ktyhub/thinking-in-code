mempalace v3.1.0

自 2026 年 4 月 6 日 v3.0.0 以来首次 PyPI 削减 — 39 条合并 PR。此版本关闭了 pip/plugin 版本漂移（#290、#296）并进行了第一周的社区修复。

🔒 安全

  • #387 MCP 入口点的输入验证、保存挂钩中的 shell 注入修复、文件大小保护 + 符号链接跳过、SQLite 连接泄漏修复、WAL 审计跟踪、强化文件权限
  • #141 清理保存挂钩中的 SESSION_ID
  • #139 清理 MCP 错误响应，从库代码中删除 sys.exit

🐛 错误修复（亮点）

  • #399 MCP null args 挂起，cmd_repair 无限递归，500 MB OOM 防护
  • #270 Claude + Codex 插件打包 — 一步安装（关闭 #187）
  • #137 无限制 ChromaDB 元数据获取的 10K 安全上限（关闭 #180）
  • #129 Windows Unicode 崩溃修复（关闭#47）
  • #123 --yes 标志绕过所有初始化提示（关闭#179）
  • #78 在挖掘过程中尊重嵌套的 .gitignore 规则（关闭 #233）
  • #236 沉默 ChromaDB 遥测 + Apple Silicon CoreML 段错误（关闭 #163）
  • #324 协商 MCP 协议版本而不是硬编码
  • #145 房间检测根据文件夹路径检查关键字
  • #136 SQLite WAL 模式 + KG 时间线中一致的 LIMIT
  • #66 批量 ChromaDB 读取以避免 SQLite 变量限制
  • #140 Upsert + 确定性 ID 防止数据停滞
  • 还有更多 - 查看完整的提交日志

✨ 特点

  • #61 OpenAI Codex CLI JSONL 标准化器（#59 导入格式中的第一个）
  • #223 规模基准测试套件（106 项测试）
  • #135 缓存 ChromaDB PersistentClient — 性能大胜

📊 基准（诚实版本）

  • #147 诚实的 AAAK 统计数据（基于单词的标记估计器，有损标签）
  • 停用了 recall_any@5 标题 — 请参阅 aa10f8f 自述文件更正和 #27、#29、#39、#214、#168 中正在进行的方法论线程

📦 包装

  • #142 收紧的 chromadb 范围 (>=0.5.0,<0.7) + py.typed 标记
  • #281 测试覆盖率 30% → 85% + Windows 编码修复
  • #131 将测试迁移到 uv，20 → 92 个测试
  • #16 统一软件包和 MCP 版本报告

🙏 谢谢

非常感谢所有在第一周进行审计、发现真正的 bug 并发送干净 PR 的人，尤其是 @lhl、@dial481、@gizmax、@rohithzr、@hugooconnor、@anthonyonazure、@fubak、@fuzzymoomoo、@vanachterjacob、@SethRosenthal100、@cktang88、@adv3nt3、@slapglif、 @skuznetsov、@rusel95、@M0nkeyFl0wer、@EndeavorYen、@bobmatnyc、@kpulik、@kevgathuku、@mvalentsev、@mvanhorn、@jonashertner。 关闭#290 和#296。

📥 安装

pip install --upgrade mempalace
