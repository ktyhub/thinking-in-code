mempalace v3.3.0

mempalace v3.3.0

访问 mempalaceofficial.com 了解此版本背后的完整故事以及架构的视觉指南。

亮点

壁橱在这里

我们设计的建筑——侧翼、房间、壁橱、抽屉——终于完成了。壁橱是可搜索的索引层：紧凑的 AAAK 指针告诉搜索者要打开哪个抽屉。搜索首先（快速）搜索壁橱，然后从抽屉中获取完整的逐字内容。 壁橱是一个增强信号，而不是一个门——直接抽屉搜索总是作为地板进行。壁橱只能改善结果，而不能隐藏它们。

  • R@1: 0.42 → 0.58 (+38%) 带有正则表达式壁橱
  • R@5：锁定在 1.00 — 无回归
  • 可选的LLM壁橱（自带端点）将R@1推送到0.67

BM25 混合搜索

搜索现在将矢量相似度 (60%) 与 BM25 关键字匹配 (40%) 结合起来。捕获嵌入遗漏的确切名称、项目代码和错误消息。带有 Lucene IDF 的真实 Okapi-BM25，而不是占位符。

8 种语言

MemPalace 支持英语、法语、韩语、日语、西班牙语、德语、简体中文和繁体中文。 CLI 输出、AAAK 压缩指令和正则表达式模式均已本地化。通过翻译一个 JSON 文件添加一种语言。

Halls — 内容类型路由

抽屉现在按内容类型标记：技术、情感、家庭、记忆、创意、身份、意识。大厅根据所容纳的内容将侧翼内的房间连接起来——搜索“我项目中的情感时刻”并准确获取这些内容。

多代理安全

文件级锁定可防止并发代理创建重复的抽屉。删除+插入循环现在是原子的——挖掘同一文件的两个代理不能交错。

跨翼隧道

代理可以在项目之间创建明确的链接。 “project_api 中的 API 设计与 project_database 中的数据库架构相关。”四个新的 MCP 工具：创建、列出、删除、跟踪隧道。

背景一切

保存挂钩不再要求客服人员在聊天中写入。对话是从记录中自动挖掘的——无需配置。用于记账的零代币。

新功能（自 v3.1.0 以来）

新功能

  • 壁橱层 - 指向抽屉的可搜索索引
  • BM25混合搜索——关键词+向量组合
  • i18n — 8 种语言以及每种语言的正则表达式模式
  • 日记摄取——基于日期的抽屉，每天一个，随着时间的推移更新插入
  • 跨翼隧道——明确的项目与项目之间的联系
  • 大厅检测 — 内容类型路由（7 个大厅类型）
  • 实体元数据 - 抽屉和壁橱上印有的名称
  • 事实检查器——根据实体注册表+知识图验证文本
  • LLM衣柜再生——自带端点（Haiku、Gemma、任何型号）
  • Drawer-grep — 搜索返回最匹配的块 + 邻居，而不是整个文件
  • 用于可插拔存储的后端接缝（#413）
  • mempalace migrate — 跨 ChromaDB 版本恢复宫殿 (#502)
  • 新的 MCP 工具：抽屉 CRUD、隧道管理、挂钩设置、导出（共 29 个工具）
  • 自动保存使用转录路径 - 不需要环境变量
