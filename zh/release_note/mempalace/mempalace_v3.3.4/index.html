mempalace v3.3.4

修订 发布时间2026年5月1日 来源MemPalace/mempalace 英文原文

mempalace v3.3.4

  • 设置变得智能，本地语言模型可以免费完成这项工作。 Mempalace init 现在使用本地 LLM（如果您正在运行）Ollama 或 LM Studio 或 llama.cpp，无论您喜欢哪一个。零云调用，无需设置 API 密钥，无需任何成本。如果你没有一个正在运行，它会优雅地退回并且永远不会阻塞。你永远不会被困在等待不存在的东西。
  • 宫殿现在将跨项目的想法联系起来。跨翼主题隧道是一项新功能，当两个项目谈论同一主题时，例如您到处使用的框架或跨域出现的人，宫殿将它们连接在一起。因此，当法学硕士扫描您对某个项目的记忆时，它可以沿着线索进入相关项目，而无需您进行任何设置。
  • 设置和第一次摄取现在只需一个步骤。当您运行 mempalace init 时，它会询问您是否要在登录后立即挖掘该目录，并首先向您显示大小估计，这样您就不会因长时间摄取而感到惊讶。一个命令，完成两件事，无需手动第二遍。
  • 存储修复使大宫殿显着变小。有一个错误，随着时间的推移，活跃的宫殿可能会在磁盘上膨胀到许多千兆字节。一位贡献者报告说，修复完成后，他们的宫殿从大约 30 GB 下降到不到 400 MB，之前超时的操作现在立即响应。这个数字是一个人的现场报告，但基本的解决方案已经为每个人准备好了。
  • 后台挂钩现在可以正确识别克劳德代码对话。自动保存会话的挂钩过去常常将对话记录视为源代码，这会导致索引混乱。现在，它们被正确标记为对话，这意味着当您查找您所说的内容时，存储空间更清晰，并且可以更好地回忆。
  • 承诺没有动摇。每个词都准确存储。一切都保留在您的机器上。没有明确告诉它去的地方，任何东西都不会去任何地方。没有遥测。零。每个版本都会强化已有的内容，而不是要求您放弃您关心的内容。
