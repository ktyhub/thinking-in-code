mempalace v3.9.0

v3.9.0 — 每个代理一个中心

现在，一个中心为每个代理提供服务。 CLI 搜索重用实时宫殿索引，而不是加载另一个多 GB 的 HNSW 副本，并发搜索不再相互阻塞，技能优先的协调加上选择加入的释放意识使共享大脑舰队更容易安全操作。

共享中心和搜索

  • mempalace search 重用健康的实时集线器。 在报告的 4.99-million-vector 宫殿上，进行了两次关于 18.6 GB 私人 RSS 的直接 CLI 搜索。可转发搜索现在重用 Hub 集合，同时保留过滤器、排名、输出、身份验证、配置协商和安全回退行为。 (#2379)
  • 集线器读取同时运行。 搜索不再在一个独占 HTTP 调度锁后面序列化；读取共享写入者首选锁，而突变保持排他性。 (#2398)
  • 搜索结果更清晰、更快速地丰富。 公共相似性是原始向量得分，有效排名中保留最近的提升，对源查找建立索引，并删除重复的丰富段落。 （＃2399，＃2143）
  • A private-palace benchmark is included for product search evaluation without exposing private queries or corpus text. （＃2400）

代理协调和操作

  • 技能优先的设置和任务切换。 引导设置技能可以引导私有或共享大脑安装，呈现规范规则，分配稳定的车队身份，并验证日志流准备情况。 Task creation now records an immutable base commit and complete definition of done before controlled launch. （＃2374，＃2361）
  • **发布意识是明确且可选择的。**代理可以显示缓存的更新状态并准备准确的升级计划，而无需阻止、自动安装或静默启用网络检查。 (#2376)
  • Logstream 获得主题路由和反向分页， 使集中协调和最新优先检查变得实用，而不会削弱仅附加游标保证。 (#2397)

正确性和资源安全

  • 不可读的配置永远不会被覆盖。 保留无效文件，写入尽可能是原子的，符号链接保持完整，并且一致地处理 UTF-8 项目配置。 （＃2357，＃2353，＃2369）
  • **抽屉突变清除陈旧的壁橱条目，**通过正在运行的集线器正确挖掘单个对话文件，并且缺失的 SQLite 数据库不再报告错误的干净完整性判决。 （＃2355，＃2282，＃2291）
  • Qdrant 有界读取停止扫描整个集合， 对于内存受限硬件上的长抽屉，可以减少 EmbeddingGemma 内部批次。 （＃2384，＃2383） 非常感谢所有做出贡献的人。此版本包括 29 个合并 PR 和 7 个首次贡献者。 安装： pip install -U mempalace==3.9.0
