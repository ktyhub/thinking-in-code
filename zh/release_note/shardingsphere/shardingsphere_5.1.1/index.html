shardingsphere 5.1.1

新功能

1.内核：支持PostgreSQL修改物化视图

  1. 内核：支持PostgreSQL声明
  2. 内核：支持PostgreSQL丢弃 1.内核：在解析器中添加模式以支持PostgreSQL中的$$ 1.内核：支持MySQL创建表空间语句解析
  3. Scaling：实现停止源码写入和恢复源码写入
  4. 扩展：支持部分表横向扩展 1.DistSQL：新的DistSQL语法：SHOW UNUSED RESOURCES 1、方式：治理中心新增持久化XA Recovery Id 1.模式：数据库发现增加延迟主从延迟功能 1.分布式事务：添加ShardingSphere代理的保存点支持 1.分布式事务：PostgreSQL、openGauss支持事务块报异常自动回滚 1.分布式事务：让Narayana变得易于使用 1.分布式事务：增加ShardingSphere-JDBC的保存点支持

增强

  1. 内核：重构内核以提高性能 1、Proxy：减小ShardingSphere-Proxy的Docker镜像大小
  2. Proxy：ShardingSphere-Proxy支持set name语句 1、Proxy：ShardingSphere-Proxy MySQL支持多语句
  3. 伸缩性：代理集群中只有一个代理节点可以进行数据一致性检查
  4. 缩放：将缩放输入和输出配置字段类型从 int 替换为 Integer
  5. 扩展：更新 MySQL 校验和 SQL
  6. 缩放：改进重置中的缩放作业进度删除以及开始作业前的进度检查
  7. 扩展：当目标表已经与源表有相同数据时，改进FinishCheckJob数据一致性检查
  8. 扩展：当自主键以来存在不支持的表时，尽快中断扩展作业
  9. 扩展：在PipelineAPIFactory中复用代理的ClusterPersistRepository
  10. Scaling：更新jobId生成算法，并使其支持幂等性
  11. DistSQL：支持CREATE/ALTER ENCRYPT RULE时配置数据类型和长度 1.DistSQL：统一SHOW ALL VARIABLES和SHOW VARIABLE的显示结果 1.DistSQL：去掉DROP BINDING TABLE RULES时绑定顺序的影响
  12. DistSQL：在SHOW INSTANCE LIST的结果中添加列mode_type 1.DistSQL：ENABLE/DISABLE INSTANCE时的模式添加验证
  13. DistSQL：检查DROP READWRITE_SPLITTING RULE时是否使用该规则
  14. DistSQL：CREATE READWRITE_SPLITTING RULE时检查重复的资源名称
  15. DistSQL：将列delay_time添加到SHOW READWRITE_SPLITTING READ RESOURCES的结果中 1.DistSQL：DROP RULE时支持IF EXISTS 1.DistSQL：优化ADD/ALTER RESOURCE时连接失败的提示信息 1.模式：添加schema级全局分布式锁 1.模式：添加schema版本号，支持DistSQL批量执行
  16. 模式：集群模式持久化元数据优化 1.方式：数据库发现创建JOB时添加schemaName标识

重构

  1. 内核：重构加密测试用例 1.内核：重构元数据以支持PostgreSQL数据库和模式
  2. 扩展：删除管道模块中的 HikariCP 依赖 1、模式：重构治理中心存储节点结构 1、模式：重构治理中心元数据结构 1.模式：将数据库发现MGR模块调整为MySQL模块

错误修复

  1. 内核：修复无参数函数 1.内核：修复InsertValueContext.getValue强制转换异常
  2. 内核：修复聚合不同列错误
  3. 内核：修复使用 schema 重写参数时的 NPE 1.内核：修复读写分离时GeneratedKeysResultSet不返回columnName导致的NPE 1.内核：修复showtables语句丢失部分单表的问题 1.内核：修复ModShardingAlgorithm存在相同后缀表时路由结果错误的问题 1.内核：修复赋值子句中包含key时的sql解析错误并优化索引解析
  4. 内核：修复分片算法配置 number props 时出现 NumberFormatException
  5. 内核：修复读写分离配置单个数据源时元数据错误的问题 1.内核：修复使用BatchPreparedStatementExecutor时语句关闭异常 1.内核：修复sql包含简写投影时重写小写逻辑
  6. 内核：修复以内存模式启动代理时出现 NullPointerException
  7. Proxy：修复PostgreSQL/openGauss协议中文字可能被错误替换的问题
  8. Proxy：修复ShardingSphere-Proxy PostgreSQL多schema无法被PostgreSQL JDBC Driver 42.3.x连接的问题
  9. Proxy：修复ShardingSphere-Proxy MySQL中时间戳nanos不准确的问题
  10. Proxy：完整的ShardingSphere-Proxy PostgreSQL二进制数字编解码器
  11. Proxy：ShardingSphere-JDBC潜在的性能问题和OOM风险
  12. 修复ShardingSphere-Proxy MySQL偶尔出现ResultSet关闭后不允许操作的问题
  13. Proxy：修复ShardingSphere-JDBCexecuteBatch不使用addBatch导致的NPE问题
  14. 扩展：修复失败或停止的作业无法通过 DistSQL 启动，除非重新启动代理
  15. DistSQL：修复CREATE SHARDING TABLE RULE时内联表达式解析异常
  16. DistSQL：修复ADD RESOURCE语句中密码为关键字password时解析异常 1.模式：修复由于ZooKeeper会话超时导致计算节点丢失的问题 1.模式：修复治理中心表名大小写 1.模式：DistSQL启用禁用实例刷新内存计算节点状态 1.模式：修复数据库发现无法通过DistSQL创建Rule
