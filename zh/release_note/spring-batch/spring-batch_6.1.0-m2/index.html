spring-batch v6.1.0-M2

预发布 发布时间2026年9月24日 来源spring-projects/spring-batch 英文原文

spring-batch v6.1.0-M2

:star: 新功能

  • 允许将 Mongo JobRepository 与任何 PlatformTransactionManager 一起使用 #5508
  • 添加 ResourcesItemReader 构建器，支持通过模式指定资源 #5487
  • 引入BatchConstants #5190
  • 默认读取器/写入器名称为 bean 名称 #5149
  • 支持使用 MultiResourceItemReaderBuilder 中的模式指定资源位置 #5056
  • 在 MongoDB 作业存储库中添加对自定义集合前缀的支持 #4980
  • 为互斥的构建器方法添加编译时安全性 #4888
  • 将架构位置添加到 DatabaseType 以防止元数据表字符串路径中的拼写错误 #4586

:lady_beetle: 错误修复

  • 存储库/DAO 级别的计数方法无法完全验证作业/步骤的存在 #5544
  • @OnSkipInRead/@OnSkipInProcess/@OnSkipInWrite 方法被 ChunkOrientedStepBuilder#listener(Object) 忽略 #5531
  • 回滚块在 ChunkOrientedStep 中算作已写入并完成步骤（OptimisticLockException 的容错重试）#5509
  • 并行作业执行期间 MongoSequenceIncrementer 中的 TransientTransactionError #5507
  • 修复 JacksonExecutionContextStringSerializer 中的 QName 反序列化问题 #5502
  • ChunkOrientedStep 扫描模式将处理后的块传递给 ChunkListener#beforeChunk，并在侦听器抛出时默默地删除扫描项目 #5493
  • 与 FaultTolerantChunkProcessor 不同，ChunkOrientedStep 在块扫描期间不会重新调用 ItemProcessor #5490
  • JpaCursorItemReader.doClose() 缺少对实体管理器的空检查 #5486
  • 修复了 StaxEventItemReader 中编码的不正确的可空性契约 #5483
  • 由于 CRLF，JsonFunctionalTests 在 Windows 上失败 #5481
  • @OnChunkError 永远不会在面向块的步骤上调用 #5468
  • 当项目处理程序也有侦听器注释时，接口侦听器回调将被调用两次 #5466
  • spring.batch.job.launch.count 悄然缺失：JobOperator 在大多数配置路径上保留 ObservationRegistry.NOOP #5463
  • Spring Batch 6.x 中存储和检索之间的 JobParameter 类型处理不一致 #5455
  • ChunkOrientedStepBuilder#listener(Object) 忽略 @BeforeStep/@AfterStep 方法 #5451
  • 将 jetbrains @NotNull 替换为 jspecify @NonNull #5443
  • SimpleJobOperator.restart(JobExecution) 使用误导性的“作业执行已在运行”消息掩盖真正的失败原因 #5439
  • 缺少 MongoDB 持久化模型类和资源的 GraalVM 运行时提示 #5435
  • 修复 JsonFileItemWriter 以在允许自定义页眉/页脚回调附加时生成有效的 JSON #5432
  • 当步骤未定义为 bean 且未分配名称时，步骤名称为 null #5278
  • 使用 MongoCursorItemReaderBuilder 和查询构建时通过 sorts() 方法强制排序传递 #4860
  • 远程分区中作业执行侦听器的调用顺序不正确 #4133
  • 远程分块实现不支持同一作业的并行执行#1372

:rocket: 增强功能

  • 删除与默认方法相同的冗余方法 #5516
  • 构建器方法名称不一致：MultiResourceItemReaderBuilder.setStrict() #5512
  • 改进 DefaultJobParametersConverter 和 JsonJobParametersConverter #5457
  • 在可行的情况下用 isInstance() 替换 isAssignableFrom() #5427
  • 从 JdbcPagingItemReader 中删除未使用的 ClassUtils 导入 #5407
  • 将 @FunctionalInterface 添加到 StepInterruptionPolicy #5402
  • 修复 SimpleJobOperator jobRegistry 状态消息 #5369
  • 将已弃用的 Jackson2JsonMessageConverter 替换为 JacksonJsonMessageConverter [#5350](https
