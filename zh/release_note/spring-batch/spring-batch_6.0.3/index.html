spring-batch v6.0.3

修订 发布时间2026年3月18日 来源spring-projects/spring-batch 英文原文

spring-batch v6.0.3

:star: 新功能

  • 添加配置属性以设置作业实例增量器名称 #5245
  • 添加支持通过环境变量/系统属性配置作业实例增量器名称#5332

:rocket: 增强功能

  • 步骤执行的日志记录不一致 #5279
  • 冗余 null id null 检查 #5250

:lady_beetle: 错误修复

  • 跳过通过 ChunkOrientedStepBuilder#listener 注册的侦听器将被忽略 #5347
  • 本地分块的计数器不正确 #5337
  • 本地分块不会报告异常 #5336
  • CommandLineJobOperator.parse() 截断包含“=”的参数值 #5295
  • ChunkOrientedStep 扫描模式下的 rollbackCount 不正确 #5247
  • JobOperator 创建自己的 MapJobRegistry，忽略应用程序中显式定义的 JobRegistry Spring bean #5229
  • 在使用跳过策略的 ChunkOrientedStep 中进行块扫描之前，事务不会回滚 #5210
  • 通过 ChunkOrientedStepBuilder#listener 注册的多态 StepExecutionListener 被忽略 #5094
  • SQL Server 的 V6 迁移脚本失败 #5276
  • 恢复 StaxEventItemWriter 中无意中删除的受保护方法 #5260

:notebook_with_decorative_cover: 文档

  • 澄清关于空块的 ItemWriter 合约 #5319
  • 修复 JobContext 中不正确的 javadoc 引用 #5342
  • 改进并修复 Javadoc 链接 #5290
  • 缺少有关本地分块中的容错功能处理的文档 #5338

:hammer: 任务

  • 更新测试容器版本 #5288
  • 为 GitHub 操作添加 Dependabot #5259

:heart: 贡献者
