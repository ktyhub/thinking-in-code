eigent v1.0.3

特征 v1.0.3

Eigent v1.0.3 使长时间运行的工作更加可靠，并将每个空间变成持久的、版本化的工作空间。

任务可以从中断中恢复，生成的文件更易于检查和审查，可重用的工作区配置可帮助团队以更少的设置开始复杂的工作。

亮点

  • 持久任务和恢复

    • 刷新或重新启动应用程序后恢复中断的任务。
    • 保留已完成的工作，无需自动重复外部操作。
    • 跨会话保持任务历史记录、已用时间、批准和恢复状态可用。

  • Git 支持的空间

    • 自动初始化 Eigent 管理的空间的版本历史记录。
    • 当选定的文件夹已包含现有 Git 存储库时，重用现有的 Git 存储库。
    • 查看任务范围内的文件更改、差异、检查点、分支和版本历史记录。

  • 会话中浏览器、文件和终端

    • 无需离开会话即可打开网页、生成的文件和交互式本地终端。
    • 在会话之间切换时保留预览选项卡和终端状态。
    • 检查代理产生的实时和历史终端输出。

  • 改进的文件预览

    • 预览本地 HTML、图像、PDF、文本文件和生成的较大工件。
    • 正常打开文件或使用 查看更改 进行任务范围的差异审查。

  • 工作区捆绑包

    • 创建可重复使用的配置，其中包含代理、技能、MCP、模型配置文件、上下文源、权限、环境要求和秘密槽。
    • 在运行捆绑包之前验证并配置它们。

  • 作用域内存

    • 在用户、空间和会话级别保存可重复使用的注释。
    • 搜索、组织、确认和存档内存，同时保持规范的任务历史记录分开。

  • 新模型提供商

    • 添加了 Ant Ling 作为内置 OpenAI 兼容提供商。

可靠性和用户体验改进

  • 改进了批准、取消、超时和中断任务处理。
  • 当工具可能产生外部副作用时，增加了更安全的恢复。
  • 改进了生成文件发现和任务范围的更改边界。
  • 强化终端生命周期管理并过滤类似凭证的环境值。
  • 修复了折叠的任务视图意外滚动的问题。
  • 改进了与现有会话和历史任务数据的兼容性。

兼容性

升级后，现有空间、会话和任务历史记录仍然可用。默认 v1.0.3 体验无需额外配置。

完整 changelog: https://github.com/eigent-ai/eigent/compare/v1.0.2…v1.0.3
