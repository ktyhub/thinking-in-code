eigent v1.0.6

Eigent v1.0.6 引入了重新设计的自动化和模型设置，向入职添加了工作角色步骤，并使会话在切换视图、重新加载或恢复中断的工作时更加可靠。

亮点

  • 重新设计的自动化 - 从六个示例工作流程开始，查看即将进行的运行，并在专用运行仪表板中检查结果。暂停、恢复或请求自动化列表中的运行。时间表编辑现在提供更清晰的本地时间预览和验证，同时保留编辑器无法表示的现有时间表。计划运行需要 Eigent 在此计算机上保持打开状态。
  • 统一模型配置 — 搜索配置的模型、管理提供程序配置，并从“设置”→“模型”中为新会话选择默认值。在专用对话框中添加或编辑模型，发现可用模型或手动输入模型名称，以及控制选择器中显示哪些 Eigent 模型。
  • 您的个人资料中的工作角色 — 在入职期间选择您的角色或跳过此步骤，然后稍后在常规设置中更新。
  • 更清晰的任务结果 — 查看任务完成、停止、失败、超时或中断的原因。当任务失败而没有最终答复时，检查其记录的操作和任何未经确认的结果。
  • 会话之间更好的连续性 — 在切换会话时保留未发送的文本并查看反馈，保留终端回滚，并在粘贴多行文本时保留换行符。

会话和运行时可靠性

  • 在已恢复或之前失败的会话中启动新任务，并在云历史记录仍在恢复时创建新会话。
  • 在窗口重新加载或丢失聊天流后可靠地发送后续消息。
  • 重新加载和恢复后恢复可操作的批准，在请求中断时保留已接受的决策，并在其他批准保持开放状态时让任务保持等待。
  • 通过批准和会话重新加载保持任务计时器稳定，并同步聊天、导航和文件摘要的完成状态。
  • 改进实时任务更新并发布已完成或空闲的事件流。
  • 恢复丢失的任务尝试所持有的工作区访问权限，解释哪个会话正在阻止文件更改，并在任务无法安全恢复时提供更清晰的指导。
  • 启动失败或停止后释放单个代理资源，并在其调用者被取消时完成隔离工作区完成。

型号兼容性

  • 让没有注册工作能力的模型以其提供商的默认值运行，而不是因为选定的思考工作而阻止它们。使用遗留推断功能的模型会回退到最近支持的工作；显式注册的模型仍然强制执行其声明的功能。
  • 为 OpenAI 和 Azure 添加 GPT-6 Sol 工作声明，修复使用别名模型提供程序的启动问题，并更清楚地解释不受支持的工作选择和提供程序中断。

文件、空间和可用性

  • 修复文件中的空白 PDF 预览，并在嵌入的 PDF 无法加载时提供外部打开操作。
  • 从会话摘要中打开本地文件，准确报告预览加载状态，并使浏览器预览与正确的任务相关联。
  • 在版本历史记录中显示直接任务检查点。
  • 改进捆绑包导入恢复，在发布前添加资源引用检查，并使共享选择更易于阅读。
  • 清理已删除的会话数据，并提供一个明确的选项来删除符合条件的会话工作目录，并对未发布的更改发出警告。
  • 避免仅仅因为一次性请求提到了某个空间而将其保存为长期记忆。
  • 正确的主页相对时间戳、默认会话名称、试用使用消息、浏览器端口验证以及在任务运行时退出时会发生什么情况的说明。
  • 加强对传统本地后端路由的授权检查，并使捆绑包安装建议与其原始空间相关联。
