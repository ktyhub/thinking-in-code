eigent v0.0.89

新消息

服务器重构 v1 (#1509)

服务器代码库已重组为域驱动架构，以实现更好的可维护性和可扩展性。没有更改 API 端点或数据库架构。 app/component/ → app/core/ | app/controller/ → app/domains/*/api/ | app/service/ → app/domains/*/service/

其他变化

  • 添加安全审核员作为默认示例技能
  • 通过显示任务和项目总计的工具提示阐明聊天标题中的令牌使用情况
  • 修复长任务文本溢出 ChatBox 任务卡的问题
  • 更新技能创造者

⚠️升级通知（本地部署用户）

此版本包括服务器的重大更改。如果您正在运行本地部署，您必须采取行动： Docker 用户：

cd server
docker-compose up --build -d

非 Docker 用户： 拉取最新代码后重新启动服务器进程。 电子应用程序用户： 只需重新启动应用程序即可。
