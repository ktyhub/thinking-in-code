haystack v3.5.0

小版本 发布时间2026年11月10日 来源deepset-ai/haystack 英文原文

haystack v3.5.0

⭐️ 亮点

🧭 使用 OpenAI Decisions API 进行分类和路由

三个新组件使用 OpenAI Decisions API 来选择如何在没有指令的情况下处理数据。 OpenAIDecisionsTextRouter 将文本发送到每个标签的命名输出，OpenAIDecisionsImageRouter 对图像执行相同的操作，并且可以将低置信度决策发送到后备分支，OpenAIDecisionsDocumentClassifier 回答有关文档的选择、分数和是/否问题，并将答案存储在其元数据中。

from haystack.components.routers import OpenAIDecisionsTextRouter

router = OpenAIDecisionsTextRouter(
    labels={
        "billing": "Payments, invoices, refunds and charges",
        "technical": "Bugs, crashes and errors in the product",
    },
    instructions="Which team should handle this support request?",
    min_confidence=0.6,
)

print(router.run(text="I was charged twice for my subscription."))
# >> {'billing': 'I was charged twice for my subscription.'}

🧱 代理的结构化输出

新的 StructuredOutputHook 根据 Pydantic 模型或 JSON 模式验证代理的最终回复，并将其作为 result["structured_output"] 中的字典返回。如果回复未验证，挂钩会将错误发送回模型并让其重试，最多 max_retries 次。

from pydantic import BaseModel

from haystack.components.agents import Agent
from haystack.components.generators.chat import OpenAIResponsesChatGenerator
from haystack.dataclasses import ChatMessage
from haystack.hooks.structured_output import StructuredOutputHook

class CityInfo(BaseModel):
    city: str
    country: str

agent = Agent(
    chat_generator=OpenAIResponsesChatGenerator(generation_kwargs={"text_format": CityInfo}),
    state_schema={"structured_output": {"type": dict}},
    hooks={"on_exit": [StructuredOutputHook(schema=CityInfo)]},
)

result = agent.run(messages=[ChatMessage.from_user("Which city is the Eiffel Tower in?")])
print(result["structured_output"])
# >> {'city': 'Paris', 'country': 'France'}

对于特工来说，还有一个新功能：实验性的 StepBudgetReminderHook 告诉模型在接近 max_agent_steps 时还剩下多少步，因此它会给出答案而不是被切断。

🎯 多向量嵌入和 MaxSimRanker

Document 有一个新的 multivector_embedding 字段，用于后期交互模型（例如 ColBERT），而新的 MaxSimRanker 通过将每个查询向量与文档向量进行比较并对最佳匹配求和来重新排列候选者。 DocumentJoiner(join_mode="merge_embeddings") 还可以组合针对同一文档并行计算的密集、稀疏和多向量嵌入。

这是 Haystack 中多向量检索的第一步 (#13257)。生成多向量嵌入的嵌入器正在 Haystack Core Integrations 中进行：Sentence Transformers 和 vLLM。

from haystack import Document
from haystack.components.rankers import MaxSimRanker

# Representative multivector embedding for "How do solar panels work?"
query_multivector_embedding = [[1.0, 0.0], [0.0, 1.0]]

documents = [
    Document(content="Wind turbines generate electricity.", multivector_embedding=[[1.0, 0.0], [0.0, 0.2]]),
    Document(content="Solar panels turn sunlight into power.", multivector_embedding=[[0.95, 0.05], [0.15, 0.9]]),
    Document(content="Solar cells absorb light.", multivector_embedding=[[0.9, 0.1], [0.1, 0.9]]),
]

ranker = MaxSimRanker(top_k=2)
result = ranker.run(query_multivector_embedding=query_multivector_embedding, documents=documents)
for document in result["documents"]:
    print(f"{document.score:.2f}: {document.content}")
# >> 1.85: Solar panels turn sunlight into power.
# >> 1.80: Solar cells absorb light.

⚠️ 新的默认 OpenAI 模型

OpenAIChatGenerator、OpenAIResponsesChatGenerator 和基于 LLM 的评估器现在默认为 gpt-5.6-terra，OpenAI 建议使用 gpt-5-mini 的替代品。 OpenAI 于 2026 年 12 月 11 日关闭 gpt-5-mini。使用 model: gpt-5-mini 保存的管道继续使用它，因此在此之前更新其 YAML。

⬆️ 升级注意事项

  • 将支持的最低 openai SDK 版本从 2.6.0 提高到 3.26.0 以支持决策 API。

  • 声明 pydantic>=2.12（Python 3.15 上的 >=2.14）为最低支持版本。 2.11 之前的 pydantic 版本为 create_tool_from_function/@tool、ComponentTool 和 PipelineTool 中的工具参数生成不同的 JSON 模式。

  • 如果您未在 read_excel_kwargs 中设置 keep_default_na 或 na_values，XLSXToDocument 现在会保留 "NA"、"N/A"、"NULL" 和 "None" 等单元格文本，而不是将其视为丢失。因此，包含此类文本的数字列不再转换为浮点数，因此在 CSV 输出中，其整个数字呈现为 1 而不是 1.0。要恢复之前的行为，请传递 read_excel_kwargs={"keep_default_na": True}。

  • 具有 Variadic 输入或连接到多个发送器的 list 输入的组件现在按照发送器与 Pipeline.connect() 连接的顺序接收值。之前，Pipeline.run() 按照发送器运行的顺序传递它们，因此依赖于顺序的组件（例如 DocumentJoiner 和 weights）的结果可能会更改：按照您希望值到达的顺序连接发送器。

    如果您从 YAML 加载管道，请检查 connections 条目的顺序。在此版本之前保存的管道列表 connections g
