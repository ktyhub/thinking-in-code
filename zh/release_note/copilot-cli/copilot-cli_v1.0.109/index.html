copilot-cli v1.0.109

2026-11-10

  • 在设置中添加对沙箱主机允许和拒绝规则的 IPv4/IPv6 CIDR 支持。
  • 在新型号下的模型选择器中添加对 Claude Fable 5.2 的支持
  • 副驾驶帮助输入现在表示 shell 输入开始时的退格键会离开 shell 模式并保留键入的文本，而不仅仅是在空提示符上
  • /subagents 保持其 Overridden 和 Status 列在窄终端上可读，并将代理名称与宽字符对齐
  • 使用 copilot mcp remove 或 /mcp delete 删除内置 MCP 服务器解释了如何禁用它
  • 在 /cd ~ 或 /add-dir ~ 中选择主目录旁边的目录使用正确的完整路径
  • Trusted-文件夹和工作树确认保留 Windows 路径分隔符
  • 当回复仅包含空格时隐藏空的助理回复项目符号
  • 为并行文件操作选择“不再询问”会批准所有涵盖的请求，而不会再次提示
  • 当设置 XDG_CONFIG_HOME 时，让 /terminal-setup 在 Linux 上的 VS Code、Cursor 和 Windsurf 的正确位置配置 Shift+Enter
  • 页脚的 AI 积分现在会在 /compact 完成后立即更新，而不是在下一回合之后更新
  • 使用 —output-format json 的提示模式会发出带有退出状态的最终结果记录，即使运行提早失败也是如此
  • 速率限制错误现在命名与切换对话框相同的模式（Copilot Fusion 模式或自动模式），而不是“自动模式”
  • 在多行提示中，向上和向下现在从左、右、退格、删除或在文本开头或结尾没有任何作用的类似键之后的光标开始，而不是跳转到上一个向上/向下运行的列
  • 按“否，并告诉 Copilot”选项的数字并向上移动后，数字键在 shell 和 URL 批准对话框中继续工作
  • /cd . 和 /add-dir . 现在将当前目录保留在 git 存储库中，而不是选择 .git；目录选择器首先列出 ./，并且仍然在其下面提供隐藏目录
  • 在 ACP 模式下，回答询问的 preToolUse 挂钩现在要求 ACP client 允许或拒绝工具调用，而不是作为主机策略拒绝它
  • /voice 立即报告过长的套接字路径以及如何修复它，而不是在显示一般错误之前等待。
  • 文件移动权限提示显示源路径和目标路径，纯重命名不再显示空差异。
  • 当第二个窗口在会话上工作时，会话历史记录会保留每个回合，而另一个窗口仍然打开
  • beepOnSchedule 设置描述现在表示，它控制在计划的 /every 或 /after 转弯完成时发出蜂鸣声，并且仅在 beep 开启时控制蜂鸣声，而不是在提示触发时发出蜂鸣声
  • companyAnnouncements 设置描述现在显示随机选取的一条消息作为公司公告通知出现在时间线中，而不是出现在启动横幅中
  • copilot help config 不再说关闭 compactPaste 会完整显示每个粘贴；超过 20 KB 的粘贴仍保存到工作区文件中
  • copilot help config 现在将主屏幕选项卡命名为“当前”和“会话”，而不是“会话”和“代理”
  • 键盘快捷键帮助中的 ctrl+h 条目现在表示它会删除本地 Windows 终端中的前一个单词，其中终端为 ctrl+h 和 ctrl+backspace 发送相同的键
  • footer.showModelEffort 设置描述现在表示它仅切换模型名称旁边的推理工作标签，该标签始终显示，并且在取消设置时工作量会在更改后短暂显示
  • copilot help config 不再命名仅限员工和内部设置，例如 taskbarPresence、showTipsOnStartup 和 streamerMode
  • ide.openDiffOnEdit 设置描述现在表示 IDE 差异将打开以等待您批准的文件编辑，并且接受或拒绝它会回答该提示，而不是每次编辑时都进行差异
  • 在 /init 之后输入的文本现在到达模型，作为生成的指令文件的额外指导，并显示在时间线中，而不是默默地删除。
  • /init 使用提示现在显示 [suppress|<instructions>]，因为 /init 之后的文本指导其所写内容，而不是仅列出 suppress
  • inlineImages 设置说明不再说默认使用 Sixel 图形渲染图像； Sixel 仅用于实验性功能
  • 将文本作为具有文本 MIME 类型（例如 text/plain 或 application/json）的 base64 blob 资源返回的 MCP 工具结果现在到达模型，而不是作为空结果到达
  • copilot help providers-env 和 copilot help environment 不再说 COPILOT_PROVIDER_BEARER_TOKEN 始终优先于 COPILOT_PROVIDER_API_KEY：它适用于 openai 和 azure，但 anthropic 会同时发送两者
  • copilot help providers-env 和 copilot help environment 现在表示 COPILOT_PROVIDER_MODEL_ID 和 COPILOT_PROVIDER_WIRE_MODEL 默认为 COPILOT_MODEL 之前的 --model 值，并且电线模型回落到 COPILOT_PROVIDER_MODEL_ID
  • copilot help providers-env 和 copilot help environment 现在表示 COPILOT_PROVIDER_TRANSPORT=websockets 仅适用于提供商类型 openai 和响应线 API，而不是暗示它也适用于 azure 和 anthropic
  • copilot help providers-env 不再表示始终发送 COPILOT_PROVIDER_API_KEY_COMMAND 输出：它表示设置 COPILOT_PROVIDER_BEARER_TOKEN 时不会运行该命令，并且自定义凭证标头的优先级取决于提供程序类型
  • copilot help providers-env 和 copilot help environment 现在表示 COPILOT_PROVIDER_* 变量优先于保存的 providers.json，除非 COPILOT_PROVIDERS_CONFIG 命名文件
  • copilot help providers-local 现在表示 Copilot 仅在这台机器上查找 Ollama，而另一台机器上的 OLLAMA_HOST 会被忽略
  • 在同一主题或以相同单词开头的主题上再次运行 /research 现在会保存一份新报告，而不是尝试覆盖之前的报告。
  • sandbox.auth.git 设置描述现在表示沙盒 git 获取一个屏蔽凭据，沙盒代理仅在该 HTTPS 源处将其交换为真实凭据，并且 GitHub 以外的主机使用您自己的 git 凭据帮助程序，而不是说注入了 GitHub 令牌
  • sandbox.userPolicy.network.proxy.url 设置描述现在表示沙盒流量始终通过内置本地代理到达配置的代理，这使代理凭据远离沙盒命令，而不是说没有主机规则的流量直接使用代理
  • 在会话 API 之外关闭或处置的会话不再保留在 CLI 嵌入式 SDK 服务器的内存中
  • 折叠的 grep 或 glob 行现在仅计算搜索找到的文件或行，而不计算大型结果或附加警告的摘要行，这使得空搜索读取“找到 3 个文件”。
  • 搜索子代理的语义搜索工具现在告诉模型它从 GitHub 的存储库代码索引中返回最多 5 段摘录，而不是声称搜索本地工作区并在内容较小时返回其完整内容。
  • /settings 值列、页脚的型号名称以及无效 allowedUrls 或 deniedUrls 条目的启动警告不再将控制字符从 settings.json 传递到终端。
  • subagents.maxConcurrency 和 subagents.maxDepth 设置说明现在表示在没有基于使用情况的计费的 Copilot 计划上忽略这些设置，而不是说它们仅适用于基于使用情况的计费用户
  • copilot update --help 不再将 stable 称为默认更新通道：没有通道参数且没有 autoUpdatesChannel 设置，预发布版本保持预发布状态
  • 现在，您自己的 mcp-config.json 中输入错误的服务器会在启动时和 mcp 列表中报告，并且无法使用的 mcp-config.json 会命名该文件和真正的问题。
  • 在 Windows 上，运行时在轮流、会话恢复或关闭会话后释放的内存现在返回到系统，而不是继续致力于进程
  • copilot 工作流程运行现在解释了动态工作流程需要实验性功能（或非禁用扩展模式）并以状态 2 退出，而不是因内部错误而失败
  • 取消、拒绝或失败的内存投票现在在时间线中显示“内存更新失败”
  • 不带引号的提示可以获得准确的引用指导，而无需将 CLI 选项转换为提示文本的建议。
  • 在浏览长/技能问题列表时保持选定的技能问题可见
  • 显示错误输入的 —prompt/—interactive 选项的解析器错误，以及与 shell 无关的指导，而不是使用 shell 敏感字符提示的不安全 -i 建议
  • 存储库设置警告指出带有注释或尾随逗号的文件中的实际语法错误
  • 在扩展的 JSON 工具结果中保留文件名、glob 和链接，而不是将它们解释为 Markdown
  • 在简洁的记录中显示搜索模式和工具错误，而不让转义序列改变终端颜色或格式。
  • 在 /settings 或 /config 中更改嵌套设置时保留其他会话保存的设置
  • 重新打开/帮助另一个全屏视图后按 Esc 键返回到提示符，而不会使 CLI 空白且无响应
  • MCP 仪表板现在使仅运行时服务器在本地会话上保持只读状态
  • 当收集的调试包丢失或为空的进程日志时发出警告
  • /rubber-duck 从会话开始时在默认模型上提供，在选择模型后在自动上提供，以及在使用 /model 切换到符合条件的模型后
  • shell 输入开始处的退格键退出 shell 模式并保留键入的文本，因此编辑时进入 shell 模式的提示不再卡在那里
  • 当后台汇总完成时清除压缩指示器，即使工具仍在运行
  • 当选定或保存的模型不可用时显示错误，而不是默默地切换到另一个模型
  • Linux 上的沙箱拒绝路径现在阻止对这些路径内的开发人员工具配置文件的访问。
  • 在会话期间使用添加到 .github/agents/ 的自定义代理，无需重新加载
  • 当您有大量本地会话历史记录时，使用 —session-id 更快地启动会话
  • 当另一个 CLI 会话同时保存不同的设置时保留设置更改
  • 当并行子代理请求批准时（包括恢复会话后），防止重复的 shell 命令处于待处理状态
  • 当 CLI 无法向 IDE 进程发出信号时（包括跨沙箱边界），IDE 发现和自动连接工作
  • 连接到省略可选发现缓存提示的 MCP 服务器，使其工具可供 Copilot 使用
  • MCP 服务器可以使用默认配置文件中存储的机密，无需 —config-dir
  • 恢复早期 CLI 版本保存的会话，其中代码更改行数不可读
  • 使用 —worktree 时确保结帐后挂钩针对预期存储库运行 Git 命令
  • Ctrl+C 关闭对话框或退出反向搜索，而不取消正在进行的 /compact
  • 即使名称包含特殊字符，也可以使用 —resume 或 /resume 按名称恢复会话
  • 存储库扫描跳过嵌套文件系统，避免 statx 可用时 Linux 上的挂载退出延迟
  • 内置文件和文本搜索适用于具有 16 KiB 或 64 KiB 内存页的 ARM64 Linux 系统
  • 取消 Autopilot 确认会使选择器提交的斜杠命令未执行，并且确认仅运行一次
  • 当您 trust 文件夹时，由存储库设置禁用的 MCP 服务器现在会停止，从会话中删除其工具。
  • /mcp 屏幕尊重存储库禁用的服务器，不再将它们标记为会话禁用
  • 使用 Ctrl+O 扩展失败的搜索或诊断调用时显示错误详细信息
  • 从会话信用限额对话框继续，不再显示错误的“已达到会话限制”通知。
  • 当 Auto 使用 Copilot Fusion High 或 Max 时，隐藏 /context 和页脚中不准确的上下文百分比。
  • 在仅更改大小写的情况下重命名文件或通过符号链接目录移动它们时保留文件内容
  • 当任务摘要、通知或移交摘要包含类似 HTML 的文本时，Markdown 会话导出可使后续的记录条目保持可见
  • 停止 ! 后再次按 Ctrl+C shell 命令显示退出警告，而不是立即退出 CLI
  • 使 copilot mcp list 和 copilot mcp get 尊重 --additional-mcp-config 和 --plugin-dir，匹配会话中使用的服务器
  • 从 /tasks 停止后台代理也会停止由它及其子代理启动的附加后台 shell，同时保持分离的 shell 运行
  • 当 COPILOT_HOME 或 —config-dir 是相对路径时，插件挂钩、MCP 服务器和扩展可以工作
  • 当启动时访问模型目录被拒绝时显示策略指南、设置链接和请求 ID
  • 仅当 trusting 文件夹用于当前会话时，在 /skills 中保持禁用存储库的技能处于禁用状态
  • 当 MCP 服务器的身份验证刷新仍在运行时，Esc 和 Ctrl+C 会立即取消挂起的提示
  • 当您的终端遵循操作系统浅色或深色主题更改时，CLI 颜色保持同步
  • 即使 config.json 中的不相关设置具有无效值，MCP 服务器也会启动
  • 现在使用 —context 恢复交互式会话会应用请求的上下文窗口层，而不是保留已保存的层
  • rapid 窗口大小调整后以正确的大小重新绘制 Windows 终端
  • 在文件名包含 ] 的图像标签周围编辑文本时保留附加图像
  • /new 工作树后 DecliZZZZZZZZZ 文件夹保持在原始文件夹中打开而不是退出
  • 当无法应用生成的会话名称时，没有名称的 /rename 将显示错误
  • 当语言服务器延迟加载其项目时，在第一个 LSP 重命名或引用搜索中包括跨文件编辑和引用
  • 在扩展的子代理回复中渲染 Markdown，并防止引用的终端转义序列改变其外观
  • 编辑由 —additional-mcp-config 覆盖的服务器时保留保存的 MCP 服务器设置
  • 已完成的会话显示“完成”，而不是在切换会话后停留在侧边栏中的“工作”状态
  • MCP 允许规则现在批准以其 MCP 服务器公布的方式命名的工具（例如 --allow-tool 'server(weather.lookup)' 或长度超过 64 个字符的工具名称），与拒绝规则已经工作的方式相匹配
  • 在会话历史记录和恢复的会话中保留长响应，即使稍后的继续失败
  • 当格式错误的 frontmatter 将列表值包裹在行或引号范围键上时，恢复指令范围
  • 返回 "additionalContext": null 的 sessionStart 或 preToolUse 挂钩不再将文本 null 发送到模型； null 被视为缺席，就像 userPromptSubmitted 已缺席一样
  • session.usage_info 事件现在仅针对会话的第一个使用报告（如文档所述）将 isInitial 报告为 true，而不是针对每条消息的第一个模型请求。
  • 从 /session info 等对话框复制包装值可保留路径，而无需插入额外的换行符
  • 当 SDK 应用程序在回合运行时使用相同的令牌恢复会话时，HydraFusion 审查和修复阶段不再立即失败。
  • 会话中/恢复现在解释了为什么云历史会话 ID 无法恢复
  • client 拥有的后台任务的进度消息现在上限为最近 20 个，因此长时间运行的 SDK 任务不再使 session.tasks.getProgress 无限制增长或每个进度更新速度变慢。
  • 在计划更改后，在任何会话存在之前列出模型不再因 421 Misdirected Request 而失败；帐户的端点被重新解析，并且列表被重试一次。
  • 当 CLI 在没有 HOME 或 COPILOT_HOME 的情况下启动时，具有 persist: true 的本地模型在运行中重复使用其正在运行的服务器，而不是每次都启动一个新服务器
  • 采用服务器名称的 /mcp 命令（启用、禁用、获取、编辑、删除、验证和添加）现在使用在子命令后键入的完整名称，因此输入错误的多单词名称会报告找不到服务器，而不是对以其第一个单词命名的服务器进行操作。
  • 当无法读取部分搜索树时，折叠的 grep 和 glob 行不再将有关不可读文件的警告行计为结果。
  • 在 Linux 上，语言服务器现在会被告知在工作区目录中创建的文件，这些文件在一个快速步骤中被删除并重新创建，例如构建或代码生成器重新生成其输出目录。
  • 粘贴的文本会删除终端颜色代码和不可见的控制字符，以便模型接收提示中显示的文本
  • 当打包的 CLI 作为参数传递回它时，它会忽略其嵌入的 Node.js 标志，例如 —no-warnings，而不是因意外参数错误而失败
  • 在 Linux 上，将许多文件写入大型工作区的构建不再使 CPU 核心在语言服务器监视文件时忙碌几秒钟。
  • 在客服人员提出的问题中按 Ctrl+G 会再次在编辑器中打开您键入的答案或“其他”答案，而不是取消问题。
  • 在 /sandbox 中，settings.json 列出两次的路径或主机规则现在显示为一行，因此删除它不再将已删除的行保留在屏幕上或使下一次删除删除不同的条目。
  • /pr 当团队名称包含 | 时会显示每个审阅者或 Markdown 字符，而不是在第一个 | 处切断评论行。
  • /lsp test 不再将正在工作的 stdio 语言服务器报告为立即退出：启动检查在监视时保持服务器的输入打开，就像真正的 client 所做的那样。
  • 远程使用 GitHub 的 SSH-over-443 主机 (ssh.github.com) 的存储库现在被识别为其 github.com 存储库，因此会话知道其存储库，而不是将文件夹视为 GitHub 外部。
  • /keep-alive busy 如果其助手在后台会话正在工作时退出，则会在下一轮或会话切换时恢复睡眠预防。
  • 从使用 Git LFS 的 GitHub 或 git 存储库安装插件现在仅下载插件自己的文件夹内的 LFS 文件，因此服务器无法提供的存储库中其他位置的 LFS 文件不再导致安装失败。
  • 当其他内容同时刷新代理列表时，使用 /agent 选择自定义代理不再失败并显示“代理发现输入已被取代”
  • 当 <html 出现在其开头附近时，web_fetch 返回 JSON 或服务器发送的纯文本响应，而不是剥离标记或使用引用的 <meta> 元素名称的编码对其进行解码
  • 索引搜索现在删除它留在缓存中的每个存储库索引，以查找不再存在的存储库和工作树，包括那些在版本 1.0.108 之前编写的索引，这些索引可能会增长到数十 GB
  • web_fetch 拒绝低于 1 的负 start_index 和 max_length 并出现验证错误，而不是从超过 20000 个字符上限的页面末尾读取它们或跳过最后一页的命名延续
  • 粘贴后立即按 Ctrl+C 会清除粘贴的文本以及提示的其余部分，而不是稍后在清除的提示中显示粘贴内容。
  • 打开或关闭语言服务器不再擦除通过 lsp-config.json 中的“disabled”手动禁用的其他服务器的设置：true，因此稍后重新启用语言服务器不会再破坏每个用户语言服务器。
  • 当没有 GitHub 登录的会话恢复时，设备策略助手的策略将再次应用，因此它锁定的设置（例如存储库挂钩）将保持锁定状态
  • 当 CLI 在没有 HOME 或 COPILOT_HOME 的情况下启动时，人员设置将保存到您自己的 ~/.copilot/config.json，而不是工作目录中的 .copilot 文件夹
  • 当模型提供者因“无效的请求正文”或“错误的请求”等一般错误而拒绝请求并且附加的图像已损坏时，现在会忽略损坏的图像，并使用可读图像重试而不是失败。
  • 当模型切换或排队命令快速跟随代理工作时排队的提示时，它会在队列中保持其位置，因此它会在提交时选择的模型上运行
  • 时间线中的子代理行将代理类型和模型绘制为一行上的纯文本，因此其中的转义序列或换行符不再重新调整行的样式、将其部分变成隐藏链接或将其拆分。
  • 使用 /cd 将目录从一个索引文件夹更改为另一个索引文件夹不再会在会话的其余部分禁用索引搜索，而前一个文件夹的索引服务器仍处于停止状态。
  • 使用 /mcp add 添加 OAuth MCP 服务器在保存任何内容之前不再显示“服务器已保存”，并且如果登录后保存配置失败，表单现在会显示原因，而不是报告成功并丢失服务器。
  • 更改 /settings 或 /config 中的屏幕阅读器设置现在会重新启动 CLI 或要求重新启动，并以 —screen-reader 开头提供记住屏幕阅读器模式
  • 当环境中的变量名称或值不是有效的 UTF-8 时，会话不再无法启动；这些变量会被跳过，而不是导致 CLI 崩溃。
  • 在提示中未完成的附件标签后导航或删除图像和文件标签时，图像和文件标签保持完整
  • 从存储库子目录运行的 copilot instruction list 列出每个插件规则一次而不是两次
  • 中断的 --worktree 签出保持不变，并提供手动恢复指导，提醒您保留本地更改并确认 Git 已停止。
  • 在发生暂时性共享索引错误（例如另一个进程短暂持有共享索引缓存）后，索引搜索不再停止会话的其余部分
  • 恢复会话现在会在 /resume 和提示模式下恢复其选定的自定义代理。
  • 从会话侧边栏恢复没有名称的会话不再出现将其重命名为“会话 1”的情况
  • 切换会话时保留最新的模式选择，而不是恢复到计划模式
  • 时间线中已完成的子代理行显示模型名称，而不是散列模型标识符。
  • /research之后，后续请求使用普通会话工具权限。
  • 沙盒路径设置支持环境变量，同时保留设置和编辑器中创作的表达式。
  • 在交互式会话中默认使用缓存感知后台等待超时
  • 保存本地文件时，在 /share 或 /export 遵循符号链接之前要求确认
  • URL 权限提示让您批准当前会话的每个子域
  • 只读 shell 脚本请求许可的频率较低，而更改 git refs 或通过隐藏路径读取文件的脚本现在总是会受到审查
