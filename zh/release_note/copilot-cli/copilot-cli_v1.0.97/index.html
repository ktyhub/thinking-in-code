copilot-cli v1.0.97

copilot-cli v1.0.97

2026-10-13

  • 为自定义代理添加代理范围的声明性挂钩
  • HTTPS 身份验证失败后，远程插件市场和插件获取会使用您登录的 GitHub 令牌重试一次。
  • 当省略 close_notify 时，TLS 拦截代理后面的流式响应完成
  • 修复了使用绝对路径解析 GitHub SCP 遥控器的问题，以便正确解析存储库所有者和名称
  • 即使存储库定义了超过 100 个或深度嵌套代理文件，也能发现所有自定义代理。
  • Autopilot 拒绝 preToolUse 钩子的“询问”决定，而不是在没有人在看的权限对话框上停止
  • 通过使用稳定的图标路径，在 CLI 更新中保持 Windows 任务栏代理图标分组
  • 当 config.json 中的一项无效时，保留已保存的设置，例如关闭的提示、trusted 文件夹和登录，而不是在每次启动时重置它们
  • 在 /config 中，托管权限规则是只读且隐藏的，除非由您的组织设置。
  • 在令牌计费会话的/usage中显示计费的AI积分，包括恢复后
  • 使用不完全是两个元素的 view_range 读取文件，例如单独的起始行，现在在时间轴中显示其行范围和行计数，并且会话导出不再包含未定义的文字文本
  • 拖动以选择转录中的文本不再偶尔突出显示并复制指针下方的行。
  • Power BI 和 Bluebird MCP 服务器在登录期间接受其发布的资源范围
  • 在 —output-format json 输出中安全地编辑秘密，同时保留有效的变量引用
  • 恢复挂起的会话现在会报告中断的工具调用并避免重播取消的写入。
  • 同步/任务 JSON 输出现在包括完成之前失败的子错误和生命周期事件。
  • 显式 GitHub MCP 工具和工具集选择使用正确的端点，因此请求的写入工具保持可用。
  • 当并发工具列表刷新更改目录时，缓存的 MCP 工具调用会重新检查其定义。
  • 来自 —plugin-dir 插件的技能和自定义代理现在可以自动完成和调用，而不是丢失。
  • 修复了从错误的插件列表重建插件挂钩的恢复会话，因此来自存储库本地市场插件的挂钩现在在 --resume 之后继续运行，并且来自您配置禁用的插件的挂钩不再回来
  • 在短终端中进行帐户检查后，保持/用户切换新会话选项可见
  • 现在按请求跟踪不可用的权限恢复尝试，因此不相关的调用不再消耗彼此的重试预算。
  • 当没有前台工作运行时，后台 shell 等待状态不再显示动画
  • 长会话中的紧急内存释放现在可以在 V8 中止之前绕过其冷却时间，因此本来会被 JavaScript 堆内存不足崩溃杀死的会话可能会在压缩历史记录中幸存下来
  • 内联图像默认在支持的终端上渲染，无需启用实验模式。使用 /settings inlineImages false 将其关闭
