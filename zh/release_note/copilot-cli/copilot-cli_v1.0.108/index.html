copilot-cli v1.0.108

2026-11-09

  • 在 settings.json 中添加 sandbox.userPolicy.filesystem.enumeratePaths 以用于 Windows 仅枚举目录授予
  • 添加 /index 命令并默认为符合条件的存储库启用托管共享 tgrep 索引
  • Grok 4.7 和 Grok 4.6 上的 PDF 附件会退回到文件参考而不是失败
  • 打开沙箱后，正在运行的本地 MCP 服务器现在会在 /cd 之后重新启动，因此它遵循新目录的拒绝路径，而不是保留会话留下的目录的路径。
  • 通过 SDK 发送的指向命名管道、套接字或设备的文件附件现在被标记为错误，而不是停止转动直到有东西写入管道。
  • 画布工具现在告诉模型 open_canvas 接受哪些实例 ID，而不是自由形式地调用它们。
  • /model 现在会在 Copilot 使用 421 Misdirected Request 回答模型列表请求时列出模型，例如在计划更改后，通过像聊天轮流那样重新解析您的帐户端点，而不是显示“加载模型列表时出错”。
  • 对 OpenAI 兼容的聊天完成提供商的请求不再包含技能和工具消息的内部消息字段。
  • Ctrl+C 现在停止正在运行的 /compact，就像 Esc Esc 所做的那样，而不是仅装备退出提示并在第二次按下时退出 CLI。
  • /config 帮助不再显示文字反引号或使用模型列表之外的模型作为示例。
  • 现在，当您关闭启动会话选择器而会话仍在加载其模型时，您的 defaultMode 设置将适用，而不是会话停留在之前的模式。
  • 一个disabledSkills条目，skills.disable和skills.enable现在匹配任何字母大小写的技能名称，就像调用技能一样，而不是在大小写不同时默默地不执行任何操作。
  • 使用两个同名的自定义工具创建或恢复 SDK 会话或替换其工具现在会出错。之前，模型提供了第一个定义，而一些 SDK 运行最后一个定义的处理程序。
  • 当 Copilot 无法保存其首次启动时间戳时（例如，因为保存 Copilot 主目录的磁盘已满），启动时 Copilot 不再因未处理的异常而崩溃。记录失败并继续启动。 -“入门”框不再建议在运行 /init 抑制的文件夹中、在已有 Copilot 指令的存储库中或在 git 存储库外部使用 /init。
  • copilot help config 现在命名 .claude/rules 指令文件和 CLI 读取的 .claude/settings.json 存储库设置。
  • copilot 帮助输入现在显示 esc esc 还会停止正在运行的 /compact，并且在 shell 模式下，空提示符上的单个 esc 或 ctrl+c 会离开 shell 模式
  • /help 现在在 Windows 上正确描述 ctrl+d（仅在出现空提示时退出，否则删除下一个字符）和 ctrl+z，并列出 ctrl+j、ctrl+v、ctrl+y 和语音输入键。
  • copilot 帮助限制现在引用本地会话显示的速率限制提示，“切换到 Copilot Fusion 模式？”，而不是“切换到自动模式？”。
  • copilot 帮助 mcp 现在表示，当同一目录具有 .mcp.json 时，目录的 .github/mcp.json 将被忽略，而不是暗示两个文件已合并
  • copilot 帮助监控现在将 github.copilot.sandbox.operation.count 指标描述为按类型计算每个沙箱决策，而不仅仅是重复数据删除的姿势变化。
  • 使用 Ctrl+U、Ctrl+K、Ctrl+W 或向上箭头历史记录清除清除 [image: ...] 标签后再次粘贴图像路径会再次附加图像，而不是插入普通路径。
  • 粘贴后立即按下退格键、箭头键、Ctrl+U 或 Shift+Enter 现在会在粘贴的文本之后起作用，而不是在其前面的文本上。
  • 现在，在添加或编辑表单中按编号选择 MCP 服务器类型会将焦点移至该类型的下一个字段。
  • Autopilot 中的 /permissions 默认值现在会再次询问如何在下一个提示中处理权限，就像 /permissions 手册那样，而不是让 Autopilot 拒绝每个工具请求。
  • 在另一侧答案打开时运行的排队 /ask 或 /btw 现在显示它仍在思考，而不是将先前的答案显示为其自己的完成答案以供 Ctrl+Y 复制。
  • copilot —resume 和 /resume 现在查找名称具有预先组合或分解的重音的会话，无论会话保存时使用哪种拼写。
  • 在 /search 中，向上、向下和 Enter 在您滚动离开后将单个匹配项带回到视图中，并且较短的终端不再将当前匹配项保留在屏幕之外。
  • /security-review help 现在表示，当工作树干净时，它会检查分支差异，而不仅仅是暂存和未暂存的更改
  • 检查点标题、文件名、Copilot 主路径和生成的代理名称中的转义序列不再重新设计 /session 信息或 /agent 向导。
  • /session info 中的长值（例如日志和会话文件路径）现在换行在它们自己的列下，而不是回到标签下
  • 当模型列表重新加载时，切换到另一个会话不再偶尔会将该会话的模型替换为“自动”。
  • /share 的使用不再意味着 /share 单独导出 markdown 文件；它表明裸路径必须包含 /、. 或 ~。
  • 提示中的路径或 URL 路由（例如 /docs/setup.md）不再加载以其第一段（文档）命名的技能，就像您调用了该技能一样。
  • /pr、/lsp、/skills、/plugin、/user 和 /collect-debug-logs 的子命令现在在任何字母大小写下都匹配，因此 /lsp TEST my-server 运行测试而不是显示使用文本。
  • /experimental 和 /theme 的帮助现在将 /experimental on|off 和 /theme <mode> 标记为已弃用并指向 /settings，并且 /mcp disable 不再描述为临时的：它跨会话保存。
  • 运行 /clear <prompt> 或 /new 的存储库 sessionStart 提示挂钩现在启动一个新会话，而不是在它创建的每个会话中启动另一个会话。
  • 子代理上显示的持续时间不再计算其工具调用在权限提示下花费的时间。
  • /subagents 帮助不再承诺默认子代理模型。现在，该命令配置每个子代理的模型和设置，并打开或关闭子代理。
  • 回复、错误消息、代理名称和其他文本中的制表符现在显示为空格而不是被删除，因此制表符分隔的单词不再一起运行。
  • 工具调用上显示的持续时间不再计算在其权限提示处花费的时间，并且在提示打开时不会勾选。
  • /update 频道选择现在表示选择 stable 或 prerelease 也会将其保存为更新频道以供将来更新。
  • 调整终端大小时保留粘贴后排队的输入
  • 内存导入报告格式错误的存储库范围，没有错误的不支持的主机错误
  • 当选定的自定义代理的配置技能丢失或无法加载时显示警告
  • 在 -p --output-format json 输出中包括会话开始、恢复和模型更改事件
  • 打开 /agent 或刷新可用代理时，使用 —agent 保持选中的内置代理处于活动状态
  • 交互式 CLI 会话按字面意思传递本地 MCP 服务器环境值；使用 ${NAME} 引用主机环境变量
  • 当结账仍使用旧名称时，允许语义代码搜索来查找重命名的存储库
  • 当通过路由配置文件选择 Fusion 时，使用 Ctrl+T 显示和隐藏首次传递推理
  • 打开 /search 或 /find 时，保持选定的匹配项在视图中，而不是跳到对话底部。
  • 使用 /keep-alive busy 时，允许系统在后台 MCP 重新加载完成后再次休眠。
  • 当有非空计划可用时，保持页脚的计划提示可见
  • 交互式自动驾驶仪等待您对 MCP 输入和同意请求的响应，而不是自动取消它们
  • /mcp enable 现在遵循禁用 MCP 服务器的存储库设置
  • 使用修补工具重命名文件现在可以成功，无需更改其内容
  • 简明转录中的文件差异将终端转义序列显示为可见字符，并保留添加和删除的线条颜色
  • 当语言服务器监视文件更改时，在大型工作树中构建期间减少 CPU 使用率
  • 无头运行现在在恢复另一个 Copilot 进程正在使用的会话时报告错误，保持其历史记录完整。
  • MCP 拒绝规则现在会阻止以其 MCP 服务器公布的方式命名的工具（例如 server(weather.lookup)），不仅是其经过清理的名称，甚至使用 —allow-all-tools 也是如此
  • 在 Linux 上，当目录被重命名并直接返回时，语言服务器不再被告知目录中的文件已被删除。
  • 在 Linux 上，当创建和删除工作区中的其他目录（例如在软件包安装期间）时重命名目录（删除旧文件，创建新文件）时，语言服务器现在会收到通知。
  • 会话恢复时打开的画布现在会恢复，即使其扩展程序在画布重新打开时重新启动，也不会保持不可用状态。
  • 当 preToolUse 挂钩询问多个并行工具调用时，每个调用都会再次得到自己的确认：回答“否”并提供反馈时，不再不询问而否认其他工具。
  • 附加空 PDF 或 Office 文档不再无法打开本机读取文档的模型；空文件将作为文件引用传递。
  • 连接到已运行的/语音服务器，即使其 PID 文件丢失
  • /limits unset 现在可以清除后续请求的会话 AI 信用上限
  • 来自存储库、URL 或本地路径的 /plugin install 现在显示与 copilot plugin install 打印相同的弃用警告。
  • 当登录时间超过一秒时，启动时不再跳过自动更新
  • /changelog <版本> 可以检索未与 CLI 捆绑的版本的 release note
  • 在会话事件日志无法写入时结束的回合现在仍以 session.idle 结束，因此 sendAndWait 在完成的回合中不再超时。
  • grep 和 glob 工具现在返回当无法读取搜索路径下的文件或目录时找到的匹配项，并附上注释指出跳过的内容，而不是仅因权限错误而失败。
  • 将工具调用期间所做的推理工作更改应用于受支持模型上的下一个模型请求，而无需等待另一个提示
  • 自 1.0.104 起，辅助权限法官呼叫作为代理请求发送，不再算作单独的高级请求
  • 从该版本自己的文档中回答有关 Copilot CLI 行为的问题，并明确说明文档何时未涵盖问题。
  • 保持成功的命令输出和文件差异在简洁转录模式下折叠直至展开，同时保持运行输出和失败详细信息可见。
  • 在输入旁边显示 MCP 表单验证错误，聚焦第一个无效字段，并改进屏幕阅读器标签和光标定位
  • 自1.0.106起，具有辅助权限的飞控不再因权限提示而停止；代理尝试另一种方法并报告它无法采取的操作
  • 状态为“defaultEnabled”的托管插件分配现在默认安装并激活插件，同时保留用户覆盖。
