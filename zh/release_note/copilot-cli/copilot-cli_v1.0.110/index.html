copilot-cli v1.0.110

2026-11-12

  • 实验性：在屏蔽对话框中回答来自代理命令的 git、ssh 和 sudo 密码提示（通过 /experimental 启用）
  • 当组织帐户可用时，避免在 Microsoft Entra 登录期间出现不必要的错误弹出窗口
  • 屏幕阅读器识别当前会话，并在会话需要关注或在会话列表中空闲时宣布
  • /usage model 行在终端宽度处换行，而不是在 100 列处断开
  • / 命令选择器不再列出、预选或运行技能描述隐藏在终端转义序列中的单词的技能；仅描述显示匹配的单词
  • 保留 Ctrl+X 快捷方式窗口关闭时键入的键
  • 在狭窄或短终端的“会话”选项卡中保持会话行和选择光标可见
  • 当 /mcp add 或 /mcp edit 遇到无效的配置文件时保留现有的 MCP 配置，并显示保存错误
  • 当推理仅包含不可见字符时隐藏空思想行
  • 将部分响应和来自中断或失败的尝试的推理标记为不完整，同时保留其文本
  • 从已删除的目录启动 copilot 现在表示该目录不再存在以及如何恢复，而不是因节点堆栈跟踪而崩溃，并且 -C <directory> 现在可以从那里开始工作。
  • 当所有工具权限都预先批准时，工作流运行工具不再告诉模型用户检查每次运行的限制。
  • /compact 尊重会话 AI 信用限额，防止达到限额后产生额外费用
  • Vim 正常模式将 j/k 保留在 $ 或 End 之后的行尾，并在较短的行上使用 Up/Down 时保留光标列
  • 插件列表显示已启用的本地市场插件，其中缺少已启用但未加载的目录，并附有说明
  • /init 抑制立即隐藏入门 /init 提示，并在返回文件夹时保持隐藏状态。
  • 复制换行的提示文本会保留键入的换行符，而不会在视觉换行处添加换行符
  • /worktree HEAD 和 /move HEAD 使用规范化分支名称“head”创建工作树而不是失败。
  • /session prune 及其试运行跳过在其他进程中打开的会话并报告跳过了多少个会话
  • /statusline 预览使页脚段在窄终端上可读
  • /mcp 添加和编辑表单中的 Ctrl+S 保存一次，并显示一条成功消息并重新加载服务器。
  • 当无法读取研究文件夹时，Ctrl+Y 和 /share 研究显示其通常的无报告消息，而不是原始文件系统错误。
  • /lsp list 和 /lsp reload 报告 LSP 配置中的语法错误，而不是误导性的丢失密钥错误。
  • 未命名的会话在“会话”选项卡和/恢复列表中显示其短 ID，在恢复后保持相同的标签
  • 助理回复在恰好在右边缘结束的内联代码范围之后不再缩进或换行
  • 当会话侧边栏停靠时，/lsp logs、/every 日程管理器、/workflows 和 /mcp add 表单适合其旁边的窗格，而不是在其边缘被切断
  • 向上滚动对话中的鼠标选择在提示或状态行上释放时仅复制突出显示的文本
  • /agent 和会话选项卡中的搜索匹配可见文本而不是隐藏的转义序列。
  • Ctrl+R 历史搜索突出显示、滚动到并将光标置于具有分解重音的匹配项上。
  • 当settings.json具有无效值时，安装、卸载、启用或禁用插件，或者添加或删除市场，不再删除您的其他插件和市场设置；该命令现在报告错误并保持文件不变
  • 在空闲提示符下失败的斜杠命令现在显示错误，并包含命令名称和原因
  • 斜杠命令选择器在包含 capital 点状 I 的描述中正确地为匹配字符添加下划线。
  • /cwd、/cd 和 /add-dir 使用您在更新目录建议之前按 Enter 时键入的路径
  • 在权限提示中按 Enter 两次即可批准请求，而不会显示错误的重试警告
  • 提示文本换行，而不拆分适合一行的单词、提前换行或添加杂散的前导空格和空行
  • 在键盘快捷键后输入或通过慢速终端连接粘贴时，保持重音和 CJK 字符完整
  • 使用 copilot config <key> 和 /settings show <key> 读取 JSON 值设置，例如挂钩定义。
  • Ctrl+C 停止 ! shell 命令，即使在提交后立即按下
  • /settings中的内存更改无需重新启动CLI即可生效
  • 在预览和扩展视图中显示 JSON 工具结果时保留准确的数字、重复的键和键顺序
  • 使用 /model —global 或 /model —repo 保存默认值后，当存储库设置覆盖新会话的推理工作时发出警告
  • /context 将加载的自定义指令显示为单独的令牌计数，而不是将它们包含在系统提示中
  • 当 CLI 使用附加目录参数（例如 -Csub 或 -C=sub）启动时，使 /restart 工作
  • 当 /compact 被取消或没有任何可压缩的内容时显示单个状态条目，而不将任何可压缩的内容视为错误
  • 通过使布局适合可用的窗格宽度，保持 /config 和 /settings 在停靠的会话侧边栏旁边可读
  • 当因为禁用绕过权限模式而忽略 —yolo 或 —allow-all 标志时显示警告，包括在非交互式运行中
  • Shell 补全在 —effort、—no-remote-export 和裸 —sync-session 标志之后起作用；重新生成您的完成脚本以应用
  • 报告在 copilot mcp remove 和 /mcp delete 中未找到丢失的 MCP 服务器，而不是建议无法找到它们的禁用命令
  • 当 /new worktree、/fork worktree 或 /resume 在另一个目录中打开会话时仅显示一次 MCP 重新加载通知
  • 对于包含 capital 点 I 的名称，在目录和代理选择器中正确突出显示和表情符号显示。
  • /skills reload 报告与 /skills list 相同的技能计数。
  • 即使 mcp-config.json 无效，也允许大多数服务器使用 copilot mcp enable
  • 对话框和表格适合在会话侧边栏旁边，没有 clipped 文本或列，并且 /sandbox 适合狭窄的终端。
  • 在 /subagents 中显示标记为 user-invocable: false 的自定义代理，以便您可以配置其模型并打开或关闭它们
  • 显示 copilot instruction list 中默认关闭哪些插件规则
  • 显示包含与 /env 中配置完全相同的 Markdown 字符的名称和文件路径
  • 设置 NO_COLOR 时保持文本选择可见而不添加颜色
  • 当 clicking 在提示中的标签内并键入时，保持附件和粘贴的文本完好无损
  • postToolUse 钩子重写 shell 命令的输出，例如编辑秘密，再次更改 Shell 行和 copilot -p 打印的内容，而不仅仅是模型接收的内容
  • 将 /settings 中保存的 URL 规则应用到活动会话，无需重新启动
  • 当会话侧边栏停靠时，保持/模型详细信息可见
  • 显示 /diff 中非 UTF-8 文件名的已更改文件，包括其补丁
  • 使用鼠标从提示复制文本时保留空白行
  • /settings 和 /config 中的鼠标滚动和 clicks 与停靠的会话侧边栏正常工作
  • 完成包含控制字符的文件夹或代理名称后，保持键入的文本可见并保持光标对齐
  • 当 /model 开关排队时使用 Esc Esc 中断转弯时仅显示一次取消
  • 删除 /settings 中的问题，将选择保留在剩余的第一行上，而不是跳转到不相关的行
  • 当工具结果和助理回复包含 Unicode 行或段落分隔符时，保持工具结果和助理回复的可读性和对齐性
  • 编辑短/搜索查询后，使 Enter、Up 和 Down 立即响应，并在底部匹配处开始新查询
  • 当服务器回复包含截断的表情符号时，远程 MCP 工具加载并响应而不会超时
  • 滚动回 /settings 列表中的第一项时保持组标题可见
  • /ask 和 /btw 在启动时等待登录完成并提示已注销的用户运行 /login
  • 滚动或 clicking 会话侧边栏会使配置搜索结果保持不变。
  • 在设置时保留启动时的插件启用设置。json 使用备用键拼写并包含无效值
  • 停止会话拥有的索引搜索服务器时，避免 /exit 和 /cd 出现五秒延迟
  • 尊重文件类型徽章的 NO_COLOR 并在 NO_COLOR 或 TERM=dumb 下禁用滚动条拇指颜色
  • 当命令打印 Unicode 行或段落分隔符时，保持 shell 输出对齐并且没有显示伪影
  • 当 mcp-config.json 是指向尚不存在的文件的符号链接时，允许 copilot mcp 添加和删除
  • 助手回复无可见内容时不再在对话中显示空项目符号。
  • 当存储库定义同名的本地市场时，保留从远程市场安装的插件
  • 在 /ahp sessions 的列限制内保持表情符号完整和宽会话标题
  • 在启用工具搜索的情况下禁用服务器后，保持 /mcp 中剩余 MCP 服务器的工具令牌计数准确
  • 在 /mcp、/skills 和 /plugin 的已安装视图中显示刷新完成，而不是在屏幕上保留刷新状态
  • 取消“达到会话限制”会清除等待消息，而不是发送消息并重新打开每条消息的对话框
  • /mcp 显示自定义代理提供的服务器的正确存储库或插件源
  • 使用 Ctrl+C 退出 shell 模式会清除退出提示，因此下次按下时会在退出前发出警告
  • 调整终端大小时，保持焦点字段及其选项在 MCP 配置表单中可见
  • 保持会话侧边栏帮助的状态图例在较窄的窗格中完全可见
  • 用户查找过期后立即启动多个 CLI 不再查找用户两次并等待第二次查找才开始
  • 一旦会话限制阻止了提示，它阻止的每个后续提示也会报告该限制，而不是以没有回复而结束；在非交互式会话中，每个被阻止的提示都会失败，并出现会话限制错误
  • 当名称已被使用时，防止 /mcp add 和 /mcp edit 覆盖现有的 MCP 服务器
  • copilot -p 现在在无法启动 MCP 服务器时在 stderr 和 JSON 输出中发出警告，例如因为无法解析用户的 mcp-config.json，而不是在没有它们的情况下继续静默
  • 在会话中从 /model 添加和选择的本地模型不再在页脚、/usage 或退出摘要中显示 Copilot 计划配额和 AI 积分
  • copilot 插件市场列表，浏览和更新从存储库的子目录运行，在存储库根目录下而不是在当前目录下查找存储库的相对目录市场
  • 安装同名服务器时保留现有的无效 MCP 服务器配置
  • 在 macOS 13 及更早版本上，CLI 现在表示需要 macOS 14 或更高版本，而不是因本机插件加载错误而退出
  • /remote on 和 /remote share 现在表示您的组织已禁用远程控制，而不是将您发送到 /environments 来启用传入连接，该策略也会阻止该连接
  • 当供应商配置了 json 但选择了 GitHub 托管模型、匹配 /usage 和页脚时，退出摘要会再次显示 AI Credits
  • 当用户设置包含不适用的仅限管理员限制时，遵循辅助权限启动默认设置
  • 当服务器被帐户的第三方 MCP 策略阻止时，在浏览器中等待的 MCP 登录现在会停止，而不是完成登录并为不再使用的服务器保存令牌
  • grep 和 glob 的搜索行不再将 postToolUse 钩子的additionalContext 算作结果，因此不匹配任何内容的搜索不再读取找到的 4 个文件
  • /settings 对话框和 /config 不再向无法使用 /streamer-mode 的帐户显示 streamerMode；设置中已启用该功能的帐户仍会看到该行，因此可以将其关闭
  • 索引搜索在长时间会话中偶尔连接丢失后不断重新连接，而不是在会话的其余部分切换到 ripgrep
  • 即使另一个 MCP 服务器更改状态，也可以接受或拒绝 IDE 差异
  • 使用 copilot --resume 重新打开的会话一打开就被标记为正在使用，因此 copilot -p --resume 和第二个窗口在空闲时不再写入其中
  • 自定义状态行保留第一行的缩进，以便所有行一致对齐
  • 在 /settings 列表项中显示控制字符，而不是应用终端样式或超链接
  • 包含波浪破折号和类似宽符号的 Markdown 表格以正确对齐的行呈现
  • 在 /logout 删除上次保存的具有无效凭据的帐户后显示登录提示，无需重新启动
  • 换行文本使用每行的完整宽度，无需在段落内插入额外的空行
  • copilot mcp add 保留现有的无效服务器条目，并要求您在重新使用其名称之前将其删除
  • 当settings.json包含无效值或无法解析时，在启动时保留插件首选项和设置文件
  • Shell 和搜索结果显示准确的行数和文件数，并在设置 AI 信用限额时省略仅模型成本指导
  • Vim 模式的 j/k 动作在 gg、ge、运算符或 redo 之后使用当前光标列
  • 在 /subagents 中以纯文本形式显示自定义代理名称和模型，保持表格列对齐并防止嵌入终端格式或链接
  • 回复包含单独 UTF-16 代理转义（例如表情符号内剪切的工具描述）的本地 MCP 服务器不再在 60 秒后失败或挂起工具调用 3 分钟；使用替换字符读取回复
  • 插件切换现在支持存储库控制的实时插件设置，并在列表和激活过程中始终使用相同的市场源。
  • 在时间线中显示失败和取消的压缩结果，并通过重新启动和恢复指导来解释内存压力压缩。
  • 功能分支上的 /diff 现在列出名称带有重音或其他非 ASCII 字符、双引号、反斜杠或制表符的已提交文件，而不是将它们排除在文件列表之外。
  • copilot 帮助网络现在引用 Linux 上 untrusted 代理 CA 的 Copilot 报告的证书错误（“证书验证失败”、“无法获取本地颁发者证书”），而不是不再生成的消息
  • copilot help permissions 不再给出 shell(gh pr create) 作为规则示例，它永远不会匹配；它现在使用 shell(gh pr) 并解释说只有第一个子命令是命令名称的一部分。
  • 当无法加载 MCP 配置时，/mcp reload 不再提示服务器已重新启动
  • 还带有顶级密钥（例如 skills、skill、tools 或 messages）的 MCP 工具结果现在可以到达模型，而不是使工具调用失败
  • /every 和 /after 在解析自然语言时间时保留多行提示的换行符和缩进，而不是合并行和折叠重复的空格。
  • 当每个推理部分结束时，“思考”持续时间会更新，并且不再包括流式传输答案所花费的时间
  • 在退出摘要中按名称显示分叉会话，以便更容易识别它们的恢复命令
  • /share file 和 /share html 拒绝目录路径，而不是创建隐藏或放错位置的导出文件
  • 允许副驾驶配置读取和更新仅包含注释的设置。json 文件
  • 缩短的路径在 Linux 和 macOS 上保留包含反斜杠的文件夹名称
  • copilot -p 尊重 trusted 存储库的 includeCoAuthoredBy 提交预告片设置
  • 启动自动安装现在在报告丢失的插件市场之前等待托管设置
  • 分机将会话从自动驾驶仪中切换出来后，交互式提示会正确显示。

  • 更改 /statusline 中的设置会保留选择器打开时由另一个会话更新的其他页脚设置
  • 在更改目录的 shell 命令之后避免不必要的存储库内读取路径访问提示
  • 在 /new 或 /clear 之后保留永久批准的 URL，无需重新启动 CLI
  • JSON提示模式在认证失败或提示为空时发出最终结果记录
  • 拒绝与子命令结合使用的提示选项，而不是默默地删除提示并运行子命令
  • 完成空目录路径后按 Enter 在 Windows 上可靠地运行 /add-dir 或 /cd
  • 使用在 /cd、/cwd 和 /add-dir 中键入的确切目录名称，而不是类似命名的同级目录
  • 在文件夹 trust 对话框中显示控制字符，以便显示文件夹名称，而无需隐藏格式或额外的行
  • 当文件或目录太大而无法读取或列出时显示，而不是在折叠的工具结果中报告误导性的计数
  • 当存储库设置覆盖新会话的已保存默认模型时发出警告，命名仍然适用的模型和设置文件
  • 将空或完全注释的存储库设置文件视为空设置，而不会出现启动警告或解析错误
  • 通过多行输出，在折叠的失败 shell 行中保持命令描述和退出状态可见
  • 在 Ctrl+R 搜索和会话确认中清楚地显示粘贴的终端文本，以便转义序列无法重新着色或隐藏文本

  • 当插件语言服务器成功加载时，保持 copilot lsp list 输出不出现警告

  • 当搜索结果太大而无法列出时，显示输出大小而不是不正确的匹配计数
  • MCP 服务器和技能启用/禁用命令正确报告通过 —additional-mcp-config 或 —plugin-dir 提供的名称的成功
  • 当行以不可见的零宽度字符结尾时，保持对话框边框和填充对齐
