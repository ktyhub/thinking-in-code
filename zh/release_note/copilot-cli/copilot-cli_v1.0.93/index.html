copilot-cli v1.0.93

2026-10-07

  • 添加企业权限.limitTo 以强制执行网络请求的托管域边界
  • 在活动轮次期间立即运行安全/用户命令，在活动轮次期间拒绝不安全的远程命令而不打开对话框，以及对中继主机通告的命令进行排队
  • 重新加载启用的插件后插件技能命令保持可用
  • 沙箱本地网络白名单现在包括本地主机和环回主机。
  • GitHub.com 连接器用户可以就地扩展 GitHub CLI 权限并重试连接，而无需切换登录方法。
  • 启动时荣誉 —context long_context 并在 /context 中显示准确的上下文余量
  • 连接没有所需 GitHub 范围的连接器现在会提示更新您的授权，而不是因身份验证错误而失败
  • 当沙箱被禁用时，温暖的语言服务器在 LSP 请求中保持运行
  • Clicking 截断的紧凑 shell 命令将其扩展
  • 所有用户均可通过 /sandbox 和 —sandbox 使用命令沙箱。
  • MCP 服务器配置更改在轮次之间应用，无需重新启动会话。
  • 模型选择器更新了推荐列表，以优先考虑 GPT-6.1 Sol、GPT-6 Astra/Luna 和 Claude 5.5 模型。
  • 仅从 ~/.copilot/settings.json 读取用户设置； ~/.copilot/config.json 中的用户设置键将被忽略。
