copilot-cli v1.0.100

2026-10-19

  • 添加 —disable-client-telemetry 标志以关闭从 CLI 上传的 client 遥测数据
  • 添加 —trust-folder 用于以 -p 或管道标准输入启动的一次性提示模式会话
  • 通过 copilot 插件安装“ghapp://air/install?…”从 GitHub 安装链接安装经过验证的技能和插件
  • 不带参数打开 /share 可查看用于共享当前会话的全屏操作菜单
  • 当未配置沙箱代理时，沙箱主机规则流量现在支持 HTTPS_PROXY 和 HTTP_PROXY
  • 语音听写不再将 等语言标记插入转录文本中
  • 当托管策略更改时，托管插件会更新现有会话中的激活
  • 当 MCP 服务器在加载工具时挂起时，会话不再停滞几分钟。
  • 当数组参数定义枚举值时，Gemini 工具调用不再失败
  • 在早期工具结果不包含可读内容后，Gemini 聊天不再失败。
  • 沙盒 shell 命令现在可以解释凭证代理证书 trust 失败，并可以在沙盒外提供经批准的重新运行。
  • 在同一会话中重新打开未更改的差异时，保留已保存的 /diff 审阅注释，并具有明确的丢弃操作。
  • 插件启用、禁用、更新和卸载操作现在在插件清单刷新后可靠地路由。
  • 仅推理最大令牌响应不再无限循环，现在在没有取得进展时以明显错误结束
  • 当保存的模型在恢复时自动替换时，显示清晰的警告并保持活动模型显示同步。
  • Linux 上的沙盒命令启动更可靠，不会出现间歇性环回设置失败
  • 在实时元数据刷新期间，从 MCP 返回的资源详细信息保留在列表中
  • 本机聊天可以开始和结束，同时可选的托管插件下载在后台继续进行。
  • 即使 CLI UI 繁忙，双击 Ctrl+C 也会立即退出
  • 目录搜索报告 CONNECT 代理质询的代理身份验证要求
  • HydraFusion 在审核运行时保持通行证扩展，未保留的通行证保持可扩展状态，直到您切换会话或恢复，并且来自中止回合的通行证会说明它们是否被保留
  • 托管帐户策略和旁路模式警告在切换帐户后保持准确，即使发生策略缓存未命中也是如此。
  • 当工具定义被推迟时，避免错误的上下文耗尽和翻转拒绝
  • 声明记录的 search、web 或 todo 工具别名或名称 github-mcp-server/web_search 的自定义代理现在会收到匹配的工具
  • CLI 帮助和版本标志在打印输出后可靠退出
  • 辅助模式下的企业管理询问权限现在允许安全操作，而无需不必要的确认提示。
  • 在登录和令牌续订期间保持您选择的 Microsoft Entra 帐户固定
  • 从会话侧边栏标题操作开始到最后一个可见会话
  • 当启动组件加载且代理工作时，计划、自动驾驶仪和 shell 模式徽章保持可见。徽章取代了用于跟踪活动文本 (Working - plan) 的模式后缀，启动 Loading: 行现在截断其诊断以将状态行保留在一行上
  • 当启用开发人员工具访问时，沙盒命令可以写入包并构建缓存。
  • Windows CLI Git 命令现在可以从线程访问被拒绝的启动失败中恢复。
  • 技能 allowed-tools 规则将逗号保留在其参数内，而不是分开。如果列表的结构不明确，则其无范围规则现在会提示而不是被授予。
  • MCP 资源仪表板在库存适配器刷新时保持交互
  • 当提供商拒绝超大主体时，重试具有较小有效负载限制的图像承载响应请求
  • 当计费数据完整时，完整的使用情况报告在恢复后不再显示部分状态或虚拟的未归属支出。
  • 辅助权限发送嵌套的 PowerShell 和 bash -c 命令，这些命令仅将纯数据环境变量、单引号 PowerShell 以及 PowerShell 变量和别名语句扩展给权限法官，而不需要不必要的手动批准
  • 当代理读取或编辑匹配文件时，现在会自动应用存储库根 .github/instructions 中的特定于路径的指令文件
  • 当进程快照线程枚举失败时，在 Windows 上启动 git、shell 命令和 MCP 服务器
  • 默认情况下，对 /sessions、/session 和 /resume 使用统一的会话浏览器。
  • 会话浏览现在将帐户发现上限限制为 500 条记录，并尊重自动刷新计时的重试提示。
  • 屏蔽主机发生变化时提示更新沙盒代理证书颁发机构
  • 当管理员管理的设置覆盖您选择的模型时显示清晰的通知
  • 默认情况下为在线会话启用语义代码搜索。
  • 通过让您选择缓存帐户或使用其他帐户明确登录来改进 Microsoft Entra 的/登录
  • github.com 上的沙盒 git 可以使用凭证.envVars 中配置的 GITHUB_TOKEN
  • /sandbox 可以保持当前会话启用沙箱，而无需全局启用
  • Trusted 存储库插件在聊天运行之前自动安装和更新。
  • 将内置浏览器插件重命名为浏览器使用，并在升级后保持现有浏览器插件首选项正常工作
  • 沙箱默认允许本地网络访问，因此命令可以到达本地主机和专用网络服务。
