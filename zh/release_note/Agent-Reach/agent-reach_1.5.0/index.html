Agent-Reach v1.5.0

Agent-Reach v1.5.0

##这个版本是什么

代理到达从「工具集合」升级为「能力层」：每个平台 = 首选 + 创业的小区列表，目前最稳的接入方式替代你实测选好、装好、检查好——接入方式换代，你无感。本版选全部型基于2026-06真机实测（32项具体测试）。

平台路由变化

平台 现在的路
小红书 OpenCLI(桌面配置，复用浏览器登录态零)▸ xiaohongshu-mcp(服务器、扫码)▸ xhs-cli(存量氢气，上游已停更)
红迪网 OpenCLI ▸ rdt-cli。 信用口径:Reddit 没有零配置路径(接口已匿名被全面封锁、官方 API 曼哈顿制),必须登录态
B站 bili-cli(搜索/热门/详情,淹没登录)▸ OpenCLI(字幕)▸ 搜索API兜底。yt-dlp退出B站(被412风控全面拦截,实测最新版+代理+Cookie均无效);yt-dlp 继续服务YouTube
推特 twitter-cli 守门(实测稳定)▸ OpenCLI 漏洞，探测装备试

##医生落真检查

  • 真跑命令探测，而不是只看文件存在——能识别「装了但坏了」（典型：系统Python升级后venv断链），并给出可直接复制的重装处方
  • 报告每个多桌面平台当前在用哪条路(doctor --json 的 active_backend)
  • 一个渠道崩塌了不再拖垮整个体检

收纳 OpenCLI(桌面桌面)

agent-reach install --channels opencli：npm自动安装，Chrome扩展商店点（Chrome安全模型，无法代点）。复用你浏览器的登录状态——刷过小红书、登过Reddit就可以直接用一次。桌面+Chrome，服务器自动跳过。

安装与更新体验

  • 安装名称：帮我安装 Agent Reach：https://raw.githubusercontent.com/Panniantong/agent-reach/main/docs/install.md
  • 更新一句话:帮我更新 Agent Reach：https://raw.githubusercontent.com/Panniantong/agent-reach/main/docs/update.md(本体+上游工具+技能一次跟上)
  • 技能重写：「全网调研」「帮我调研」可靠触发；代理干完大活会顺手查版本，有新版在收尾时提示一句（不打断、不重复啰嗦）
  • check-update 修复：本地版本对应于最新版本时不再误“提示更新”（避免降级）

质量

  • 测试 107 → 162(契约/断链场景/头级优先级矩阵/版本比较全覆盖)
  • 经三轮对抗性评论(12项发现全部修复):修改了Twitter路由分数、观看降级提示、死代理开关等会真实伤害到用户的问题
  • 13 32 项真机渠道产品实测全通过
