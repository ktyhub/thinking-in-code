Agent-Reach v1.6.1

修订 发布时间2026年11月1日 来源Panniantong/Agent-Reach 英文原文

Agent-Reach v1.6.1

中文：

  • 全网搜索、Reddit、小红书、B站1.6.0里会出现的几十个“明明能查却报错”或“显示成功但内容是空的”，这版都修好了。
  • 电脑上其他软件占用了浏览器端口时，可以换一个端口，不用关掉那个软件。
  • 复制登录失败时会如实告诉你，不再假装成功。
  • Windows上小红书带特殊符号的链接能正常打开。

英语：

  • 修复了多个 1.6.0 内容可访问但网页搜索、Reddit、小红书或 Bilibili 失败，或报告成功但内容为空的情况。
  • 当您计算机上的另一个程序使用浏览器端口时，Agent Reach 可以使用不同的端口；您不必关闭该程序。
  • 失败的登录副本现在会这样显示，而不是报告成功。
  • 在Windows上，小红书带有特殊字符的链接可以正确打开。

中文（技术细节）：

  • 全网搜索：请求统一带上agent-reach/<版本号>标识，避免被Exa的防护拦截（#877）。
  • Reddit：站内工具临时失败（比如返回网页而不是数据）时，自动改用公开网页搜索和阅读（#880）。
  • 小红书：车辆 OpenCLI 2.0 的返回格式，阅读不再“成功但内容全空”；且搜索评论没有结果时也不再返回一条空数据（#861、#895）。
  • B站：扫码后如果没有存下有效登录，不再显示登录成功；提示改为运行agent-reach login bilibili（#866、#883）。
  • 专用浏览器端口可以改：agent-reach configure browser-port <端口>，9222被其他软件占用时用（#848）。
  • 复制登录：浏览器后台程序没开时不再记一次“复制了0条”；手动login <渠道> --import-existing一条都没有复制到时会明确报错（#879）。
  • Windows：链接里带&的小红书笔记能正常阅读和查看评论（#860）。

英语（技术）：

  • Web 搜索：每个请求都将自身标识为 agent-reach/<version>，因此 Exa 的 Cloudflare 前端不再阻止它 (#877)。
  • Reddit：当站点工具暂时失败时（例如它返回 HTML 而不是数据），搜索和阅读将回退到公共网络 (#880)。
  • 小红书：OpenCLI 2.0 结果已映射，因此空字段读取不再成功；当没有结果时，搜索和评论不再返回一个空行（#861、#895）。
  • Bilibili：未保存可用凭据的二维码登录不再报告为成功，并且提示现在显示 agent-reach login bilibili（#866、#883）。
  • 专用浏览器的端口可使用 agent-reach configure browser-port <port> 进行配置，以便其他工具保留 9222 (#848)。
  • 登录重用：浏览器桥关闭时不会有“复制 0 个 cookies”记录；不复制任何内容的显式 login <channel> --import-existing 现在显然会失败（#879）。
  • Windows：可以读取包含 & 的小红书笔记链接并加载其评论（#860）。
