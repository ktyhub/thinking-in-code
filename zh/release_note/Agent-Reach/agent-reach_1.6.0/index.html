Agent-Reach v1.6.0

小版本 发布时间2026年10月23日 来源Panniantong/Agent-Reach 英文原文

Agent-Reach v1.6.0

中文：

  • 从旧版本升级：把“帮我更新Agent Reach”这句话发给你的AI就行。你的钥匙和设置都保留，旧版本程序会自动删掉。
  • 加一个平台只要说一句，需要的软件都会自动安装好，不需要管理员密码；你只需要登录或者填一个键。
  • 小红书、推特这类要登录的平台，改用Agent Reach自己的专用浏览器，不弹窗、不占用你的浏览器；多个AI可以同时查。
  • RSS订阅和Exa全网搜索合并进了“网页”。以后有新版本，AI会用大白话告诉你改了什么，你同意了才更新。

英语：

  • 从旧版本升级：只需向您的 AI 发送“更新 Agent Reach”句子即可。您的按键和设置将被保留，并且旧程序将被删除。
  • 添加平台只需一句话。它需要的一切都已为您安装，无需管理员密码；您只需登录或输入密钥。
  • 需要登录的平台，例如小红书和X，现在在后台使用Agent Reach自己的浏览器，而不是你的，并且多个AI可以同时搜索。
  • RSS 和 Exa 搜索现在是“网络”的一部分。当新版本发布时，你的人工智能会用简单的语言告诉你发生了什么变化，只有在你同意的情况下才会更新。

1.6 是重建品。代理调用一个命令，agent-reach； Agent Reach 安装或存储的所有内容都位于 ~/.agent-reach/ 下。 1.6 是重构版本：Agent 只调一个命令 agent-reach，Agent 到达安装的、存入的东西全部在 ~/.agent-reach/ 下。

  • 本版发布前已真实测通28/40个动作；以下未在发布机上测通，经维护者批准随本版发布：Reddit（测试网络被拦）、Instagram（限流）、B站字幕、LinkedIn、雪球热帖热股（未登录）、小宇宙（未配Key）。
  • 修复未登录gh消防公开API、公开行情触发浏览器、错误认证提示和未登记存储清理；临时音频/字幕保存在到达内。BOSS站内搜索优先官方OpenCLI，JD上游设备故障单列；PR与发版均检查真实搬运和待验状态。
  • CLI 对已声明的公开搜索/阅读先复用网页工具，成功后不准备浏览器；结果标注来源和内容范围，站内路径明确要求认证时提示才登录。可指定保留保留原有站内能力。
  • 浏览器共用一次登录，闲置十分钟自动关闭，下次使用自动打开。
  • 添加渠道自动准备工具；删除时只清理该网站的登录。默认平台也可以删除，删除后更新不会再回来。
  • 更新时，已测量版本的工具保留在已测量版本，其他工具使用兼容范围内的最新版本。
  • 公开继续内容先读，不强制登录；安装后用简短表格说明能查什么。
  • 保留小宇宙布局；去掉额外模型配置和重复的网站抽象实现。
  • Bridge随专用浏览器管理；按真实页面操作计时、定期保存登录。清理失败保留渠道，卸载只删台账文件。发布前必须有渠道真实验收。
  • 查询默认无头，优先复用本机现有站点登录；显窗登录与无头查询消耗配置。B站字幕、雪球社区自动同步登录，BOSS JD使用上游浏览器接口。华为接口和限流不再误报为需要重登。
  • 专用浏览器按扩展保存在自己配置里的编号识别，不会再把用户日常使用的Chrome认成专用浏览器；登录窗口开着时查询不再把它收掉。
  • 浏览器渠道可以批量查询：同一平台最多2条、总计4条同时运行，多出来的队列而不是立即报“正忙”；登录窗口、退出登录等操作等正在运行结束的查询再做。
  • 没有登录时报“需要登录”而不是“上游工具坏了”：雪球社区（错误码400016）、B站字幕（没有B站登录）、LinkedIn（专用浏览器里没有LinkedIn登录）。
  • 从1.5升级更顺：安装和更新合成一个install.md，先看版本再分流（旧版本指向update.md转到它）；agent-reach update遇到pip/pipx安装的旧版本会自己换成uv安装；setup删除旧版本Agent Reach （只删除它自己，而不是其他工具），安装报告说明保留什么、变了什么、以前用过哪些程序可以恢复。安装地址始终指向最新的正式版本。
  • 平台出错时，报错原话和自带的处理原样替换AI，由AI使用平台名称告诉哪个平台用户暂时有问题；不再用Reach自己编写的覆盖建议（“要登录”仍给Reach自己专用浏览器的登录步骤）。

英语（技术）：

  • 40个行动中有28个在发布前通过了真正的验收；这些未经维护者批准的测试：Reddit（测试网络被阻止）、Instagram（速率受限）、Bilibili 字幕、LinkedIn、雪球热门帖子/股票（无需登录）、小鱼舟（无密钥）。
  • 浏览器通道共享一个配置文件，在十分钟空闲后关闭并根据需要重新打开。
  • 添加频道准备其工具；删除仅清除该站点的登录信息。默认平台可以删除，更新不会将它们添加回来。
  • 更新将具有测试版本的工具保留在该版本；其他工具获得其支持范围内的最新版本。
  • 公共内容保持公共优先，并具有紧凑的能力收据。
  • 保留小鱼舟转录；删除额外的规划器和重复的站点提取。
  • 以只读方式重用现有的本地站点会话；查询默认为无头查询，具有用于人工登录的可见窗口。
  • 专用浏览器由其扩展程序保存在自己的配置文件中的 ID 来标识，因此用户自己的 Chrome 永远不会被误认为是它；查询不再关闭打开的登录窗口。
  • 浏览器通道并行运行查询：每个平台最多 2 个，总共 4 个，其余的将排队，而不是立即失败；登录窗口、注销和浏览器设置等待运行查询。
  • 未登录时报告NEED_LOGIN而不是UPSTREAM_BROKEN：雪球社区（错误400016）、Bilibili字幕（没有Bilibili登录）、LinkedIn（专用浏览器中没有LinkedIn登录）。
  • 从1.5升级更顺畅：安装和更新共享一个指南install.md，它首先检查版本（update.md，1.5向用户发送的地方，指向它）； agent-reach update 自行将 pip/pipx 安装移动到 uv； setup 删除了旧的 Agent Reach 程序（仅 Agent Reach 本身），安装报告解释了保留的内容、更改的内容以及可以重新添加哪些旧频道。安装 URL 始终指向最新版本。
  • 上游错误到达代理时未发生变化（原始消息和帮助）；代理通过平台名称告诉用户哪个平台暂时不可用。 Reach 不再用自己的建议替换它们（NEED_LOGIN 仍然提供 Reach 的专用浏览器登录步骤）。
