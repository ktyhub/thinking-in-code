ray 2.60.0

小版本 发布时间2026年11月4日 来源ray-project/ray 英文原文

ray 2.60.0

  • Ray Data shuffle 和 Parquet 读取： 在此 Ray 版本中，shuffle v2 是连接、聚合的默认 shuffle 策略 (#66260)。 Parquet 现在从每个文件页脚中的行组元数据读取读取任务的大小，而不是根据文件大小进行估计，因此读取任务会打包到准确的字节预算（#65596、#65806、#65821）。
  • Ray Serve 滚动更新： 我们添加了 max_surge_percent，它在停止旧副本之前启动替换副本，因此滚动更新不会降低服务容量 (#66267)。新副本不断失败的滚动更新现在在 DEPLOY_FAILED 停止，并使剩余的旧副本可路由，而不是替换每个健康副本（#66252、#66290）。
  • 安全性： Ray Data 现在拒绝每个从外部输入反序列化 Arrow 数据的读取器中的 pickle 对象列，从而关闭 LeRobot、Databricks、Iceberg、Hugging Face、ClickHouse、BigQuery 和 Delta Shareing 读取器中的远程代码执行路径（#66042、#65769）。 eMudhra CA 妥协后，射线图像和轮子构建引脚 certifi 2026.10.19 和 pip 26.2.2，并且 aiohttp 移动到 CVE-2026-111064 和 CVE-2026-111066 的 3.14.4 (#67295、#67298、#67301、 #67304、#67305、#67350）。

射线数据

🎉 新功能

  • 添加 Dataset.write_orc() 用于写入 ORC 文件 (#65453)
  • 添加一个 unnest() 表达式，将结构值表达式或列扩展为每个字段一列 (#65241)
  • 将 min_bytes_per_file 添加到 write_parquet 以将小块组合到目标输出文件大小（#65636）
  • 支持 write_delta 到 schema_mode 中的嵌套模式演化 (#65858)
  • 支持将列子集附加到现有 Lance 数据集 (#64474)
  • 添加基于速率的集群自动缩放器，该自动缩放器根据测量的操作员吞吐量进行缩放，现在是默认值（#65954）
  • 添加一个积压感知的演员池自动缩放器，现在是默认值； RAY_DATA_ACTOR_AUTOSCALER=DEFAULT 恢复旧的 (#66035)
  • 通过 CheckpointConfig.checkpoint_manager_cls 和 checkpoint_filter_cls 使检查点恢复可插入 (#65676)
  • 添加 ray.data.list_stats_summaries() 开发人员 API 以获取已完成数据集的执行统计信息 (#66294)
  • 将逻辑内存使用图表添加到 Ray Data 仪表板 (#66044)

💫 增强功能

  • 将 pandas 元数据保留在可由 pandas 解析的 Arrow 块上 (#67576)
    将 shuffle v2 设置为默认值，为 sort 添加基于任务的 shuffle v2，并将外部 shuffle 重命名为磁盘 shuffle (#66260、#64875、#66367)
  • 读取 Parquet 页脚以按行组对读取任务进行装箱，并为每个片段使用一个读取器线程 (#65596、#65806、#65821、#65169)
  • 使用 Polars 流式连接进行分区内连接，每个减速器有一个 Polars 线程，hash_partitions 中的 Polars (#66075、#66341、#66269)
  • 使 actor 池具有节点感知能力：跳过耗尽节点上的 actor，并在重新启动后刷新 actor 位置 (#66109)
  • 计算任务池资源使用中的沿袭重建任务，以便数据不会在对象丢失的情况下过度提交 (#66217)
  • 当未指定 num_cpus 时，默认 GPU 映射运算符为 num_cpus=1；将 num_cpus=0 设置为选择退出 (#66202)
  • 通过减少每行工作和副本来加速聚合、排序、行访问和张量到 pandas 的转换（#66194、#66120、#66246、#66254、#66116、#66219、#64961、#66122、#65796）
  • 将 ds.stats() UDF 时间分解为输入准备、函数体和输出构建，可选择每个融合阶段（#65807、#65810）
  • 当操作员配置的 memory 低于其观察到的最大 USS 的 1.25 倍时发出警告 (#65512)
  • 为 OutputBackpressureGuard 添加选择加入的每个运营商发布间隔 (#65202)
  • 跟踪每个节点的自动缩放协调器预留（#66001，#66370）
  • 延迟在 import ray.data 上加载 pyarrow.dataset (#66463)
  • 仅获取 read_lerobot 中每个读取任务的根包 (#65284)
  • S3 ACCESS_DENIED 写入、分区值转换和 V1 读取的更清晰错误，找不到文件（#66033、#66078、#65256）
  • 弃用 RandomAccessDataset (#61287)
  • 数据容错的基础：扇出和扇入任务的沿袭跟踪（#65642、#66136）
  • 重新组织 DataSourceV2，以便非 Parquet 和目录支持的源（例如 Iceberg）可以在其上构建（#65908、#66244、#66066、#66312、#66357、#66390、#66398、#66450、#66478、#66497）

🔨 修复

  • 修复文件读取中途重试时静默数据丢失的问题 (#66011)
  • 修复 ResourceBudget 背压无限期地停止管道 (#64601)
  • 停止将过滤器推过 limit()，这会更改 limit().filter() 返回的行（#66143）
  • 修复分区修剪：保持正确的下推限制，提高不可评估的过滤器，处理完全修剪的清单（#66010，#65990，#65955）
  • 返回空数据集上的全局聚合结果，并修复重复的聚合列名称 (#66218)
  • 当另一侧为空且其架构未知时保留反连接行 (#66126)
    *修复工作人员规模为零后的哈希洗牌（#66043）
  • 不要将非零并发的 MapOperator 融合到后续的 AllToAllOperator (#66350)
  • 在随机减少中尊重 target_max_block_size=None (#66451)
  • 修复融合映射运算符中重复计算的 UDF 时间 (#65776)
  • 修复因 Arrow 支持的 pandas 批次中缺失值而中断的预处理器 (#65272)
  • 在设备到主机传输时保留嵌套的 TorchInference 输出 (#65997)
  • 拒绝未知的 LeRobot delta_timestamps 按键以及 read_images 中的零高度或宽度 (#65857, #65967)
