kylin 5.0.2

经过 6 票绑定（和 2 票非绑定）投票，Apache Kylin 5.0.2 发布。下载链接将很快在网站上更新。

变化亮点： 新功能：

  • [KYLIN-5993] - 网站内表
  • [KYLIN-5996] - 支持内部表缓存预加载
  • [KYLIN-6025] - 支持内部表分区内的文件合并 增强功能：
  • [KYLIN-5995] - 重新排序面筋罐加载器
  • [KYLIN-6000] - Kylin启动后，在Kylin_Home同级目录下生成文件krb5cc_gluten。需要调整文件生成的位置。
  • [KYLIN-6009] - API 性能测试显示相比 Kylin4 有所下降
  • [KYLIN-6020] - 添加系统级/项目级配置以允许直接查询内表。
  • [KYLIN-6022] - 支持内表并行增量加载
  • [KYLIN-6024] - Gluten 元数据缓存支持 RocksDB
  • [KYLIN-6030] - 表响应消息中属性名称样式不一致
  • [KYLIN-6031] - 添加内表OpenAPI，支持查看指定内表详情
  • [KYLIN-6033] - 使用元数据回答 min 和 max 查询时，路由到 Calcite 引擎以避免提交 Spark 任务
  • [KYLIN-6039] - 动态参数长SQL解析性能优化
  • [KYLIN-6051] - 历史代码清理+重构
  • [KYLIN-6052] - Kylin5 内表支持逻辑视图
  • [KYLIN-6053] - 添加OpenAPI用于查看指定内表的详细信息
  • [KYLIN-6054] - 优化分片修剪逻辑以避免查询失败
  • [KYLIN-6060] - 为内表的不同存储类型添加单独的加载方法
  • [KYLIN-6061] - 支持使用 Gluten 构建索引文件
  • [KYLIN-6068] - 春季会话清理以避免 MySQL 死锁警告
  • [KYLIN-6069] - [内表-增量加载] 禁止加载时间范围重叠
  • [KYLIN-6071] - 支持 JDBC 服务发现
  • [KYLIN-6072] - StorageV3 Catalog 重构以避免与 Iceberg Catalog 冲突
  • [KYLIN-6073] - 非时间分区内部表的刷新按钮不应灰显且后端在刷新时返回错误 错误修复： https://issues.apache.org/jira/projects/KYLIN/versions/12355670

感谢所有为此版本做出贡献的人。以下是 release note： https://issues.apache.org/jira/secure/ReleaseNote.jspa?version=12355670&styleName=Html&projectId=12316121

提交： https://github.com/apache/kylin/tree/kylin-5.0.2 (33cfb69)

发布工件使用以下密钥进行签名： https://people.apache.org/keys/committer/liyang.asc
