LocalAI 4.12.0 出来了！

此版本重新设计了 Web UI，并添加了流式语音响应、本机决策路由以及对模型内存和提示状态的更多控制。它还添加了图像升级、实时动作捕捉、Qdrant 存储和经过身份验证的聊天历史记录。这也是为即将发布的版本做准备，其中将包括插件支持。我们的计划是将少数组件（例如 Studio、Talk）移至可从 LocalAI 按需安装的独立附加组件。

亮点：

  • 🖥️ 重新设计的 Web UI：共享控件、浅色和深色主题、更清晰的模型和 Studio 工作流程以及节点范围的后端维护。
  • 🎙️ 流式语音和捆绑音频模型：将 LLM 片段馈送到 Qwen TTS，将显式子句流与其他引擎结合使用，并通过 Parakeet 捆绑包组合音频分析角色。
  • 🧭 本机决策路由：使用决策模型对请求进行分类，并使用新的 /v1/decisions 适配器进行谓词、选择和评分。
  • 🖼️ Studio 中的图像放大：无需离开项目即可使用专用的 /v1/images/upscale API 创建放大的子图像。
  • 🛡️ 隐私和工具配置：响应 PII 过滤、选择拒绝不可检查的媒体、别名配置文件以及远程 MCP 服务器的 OAuth2 client 凭证。
  • 🕺 实时 GEM-X 动作捕捉：将 RGB 帧流式传输到 CPU 或 Vulkan 上的有界、基于会话的姿势 API。
  • 🗄️ 持久 Qdrant 存储：使用具有 TLS 和环境支持凭证的现有存储 API。
  • 💾 推理控制：配置 MoE 专家缓存、惰性张量读取以及显式插槽提示缓存保存和恢复。

面积 总结
🖥️ 网页用户界面 共享视觉工具包、中心导航、重新设计的模型和工作室页面、每个模型的磁盘统计以及受保护的每个节点后端删除。
💬 聊天 帐户范围的服务器历史记录、一个推理工作选择器、可编辑的麦克风听写、扫描的 PDF 图像附件以及单独的沙盒 Canvas 预览。
🎙️ 音频 增量 Qwen TTS、选择加入子句流、Parakeet 捆绑包和扬声器编码器、可配置 VAD 以及声音事件和二值化。
🎵 声音 通过兼容的本机工具聊天模型，YuE2 支持和可选的结构化扩展。 YuE2 权重是非商业性的。
🧭 决定 原生决策模型可以路由请求； /v1/decisions 使谓词、选择和分数适应现有的 SystemOne 管道。
🛡️ 隐私和 MCP 传入响应文本过滤、可选媒体拒绝、受保护术语和相邻词屏蔽、别名配置文件和远程 OAuth2 client 凭据。
🕺 运动 GEM-X 通过有界双工 API 将流式 RGB 帧转换为 SOMA-77 或 SMPL-24 姿势。此集成仅限 API。
🗄️ 商店 Qdrant 通过 /stores/* 提供持久向量，具有显式后端选择、TLS 和分块写入。
💾 推理 moe_cache_mib、lazy_mode 和选择加入插槽保存/恢复添加了特定于工作负载的控制，而无需将其更改为通用性能保证。
🔧 分布式运营 尝试特定的负载取消、租用、配置重新同步和共享根集合发现改进了 PostgreSQL/NATS 架构。

🚀 新功能和主要增强功能

🖥️ 共享的Web UI和更清晰的模型操作

Web UI 使用共享的 CSS/SVG 套件、墨水和青色主题、一致的控件以及权限感知的构建和操作中心。现有 URL 仍然可用。模型公开模型详细信息、变体、放置信息和磁盘使用情况。 Studio 在其工作流程中共享撰写、作业、结果和最新结果布局。

每个模型的存储核算将共享文件与特定于模型的文件区分开来。删除重复共享字节的聚合总数。模型的显示大小不一定是删除它所回收的空间。

远程手动导入现在作为跟踪的图库作业运行。导入页面和编辑器等待获取成功并显示失败或取消。无需下载的本地文件导入保留同步行为。排队导入可以应用推荐的推理默认值，因此在重现配置时显式设置重要参数。

后端支持从一个选定节点确认删除一个具体构建。保护检查和冲突锁可防止在冲突操作期间进行删除。刷新失败会保留最后的已知清单，而不是报告未经验证的空状态。

🔗 PR：#12526、#12551、#12587、#12599、#12785。排队导入：后台采集 和解析器感知队列。

💬 聊天记录、推理控制、更丰富的输入

登录用户可以通过 /api/conversations 同步对话。帐户范围的缓存、持久删除意图和逻辑删除可防止
