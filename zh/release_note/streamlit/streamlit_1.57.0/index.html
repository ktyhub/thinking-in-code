发生了什么变化

重大变化🛠

  • [功能] 将 Starlette 设为默认服务器并删除 https://github.com/streamlit/streamlit/pull/14553 中 @lukasmasuch 的 Tornado
  • [杂务] 从 https://github.com/streamlit/streamlit/pull/14800 中的 @lukasmasuch 删除 plotly_chart 和 vega_lite_chart 中已弃用的 kwargs
  • [杂务] 删除 https://github.com/streamlit/streamlit/pull/14801 中@lukasmasuch 已弃用的 _get_websocket_headers 函数
  • [功能] 直接极坐标到箭头转换绕过 pandas by @lukasmasuch in https://github.com/streamlit/streamlit/pull/14885

新功能🎉

  • [功能] 在 https://github.com/streamlit/streamlit/pull/14697 中隐藏 st.menu_button 和 st.popover 的菜单式图标标签的 V 形图标，作者：@lukasmasuch
  • [功能] 添加药丸、segmented_control 属性和数据帧密钥到 https://github.com/streamlit/streamlit/pull/14518 中的 @lukasmasuch 的 AppTest
  • [功能] 在https://github.com/streamlit/streamlit/pull/14665中添加`title`参数到@lukasmasuch的警报元素
  • [feat] 添加 :shimmer[] markdown 指令，用于 https://github.com/streamlit/streamlit/pull/14055 中的 @lukasmasuch 的动画加载文本
  • [feature] 在https://github.com/streamlit/streamlit/pull/14722中通过@lukasmasuch在`st`命名空间中公开`App`
  • 通过 @sfc-gh-nbellante 在 https://github.com/streamlit/streamlit/pull/14745 中将 OSS 开发与 Streamlit 核心技能捆绑在 pip 包中
  • [修复] 通过 @lukasmasuch 在 https://github.com/streamlit/streamlit/pull/14781 中为视频和地图元素添加边框半径
  • [功能] 在https://github.com/streamlit/streamlit/pull/14861中通过@lukasmasuch将`secrets`参数添加到`st.App`
  • 将应用程序和主题模板添加到 https://github.com/streamlit/streamlit/pull/14746 中 @sfc-gh-nbellante 的捆绑技能中
  • [feature] 在 https://github.com/streamlit/streamlit/pull/14726 中通过 @lukasmasuch 公开 st.bottom 容器

  • [修复] 在https://github.com/streamlit/streamlit/pull/14674中添加@mayagbarnes对CSS颜色级别4的支持
  • [修复] 当 @sfc-gh-lwilby 在 https://github.com/streamlit/streamlit/pull/14708 中观看源重新加载时，驱逐命名空间子项
