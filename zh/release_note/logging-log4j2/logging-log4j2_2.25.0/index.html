logging-log4j2 2.25.0

小版本 发布时间2025年6月16日 来源apache/logging-log4j2 英文原文

logging-log4j2 2.25.0

此次要版本引入了错误修复、行为改进以及对 GraalVM 本机映像生成的完整支持。

GraalVM 可达性元数据

Log4j Core 和所有扩展模块现在都包含嵌入式
GraalVM可达性元数据,
使用开箱即用的 GraalVM 可以无缝生成本机映像，无需手动配置。
有关更多信息，请参阅我们的 GraalVM 指南。

[!注意]
构建第三方 Log4j 插件时，使用新的 GraalVmProcessor
在版本 2.25.0 中引入将自动生成 GraalVM 本机映像所需的可达性元数据。
但是，如果未提供所需的 log4j.graalvm.groupId 和 log4j.graalvm.artifactId 参数，处理器将使构建失败。
详细说明请参见注册插件。

模式布局中的异常处理

模式布局 中的异常处理进行了重大重写。
此更新解决了多个错误并确保所有异常转换器的行为一致。
主要改进包括：

  • 堆栈跟踪现在始终以换行符而不是其他空格作为前缀。
  • 默认异常转换器已从扩展更改为普通，提供更好的性能。
  • 异常转换器中对 {ansi} 选项的支持已被删除。

日期和时间格式

Log4j 历史上曾提供自定义日期和时间格式化程序以提高性能，例如 FixedDateFormat 和 FastDateFormat。
这些现在已被弃用，取而代之的是 Java 标准 DateTimeFormatter。

如果升级后遇到格式化问题（尤其是 n 或 x 指令），您可以通过将 log4j2.instantFormatter 属性设置为 legacy 来暂时恢复到旧版格式化程序。
请通过我们的问题跟踪器 报告任何问题。

Windows 上的 ANSI 支持

现代 Windows 版本（10 及更高版本）提供本机 ANSI 转义序列支持。
因此，对过时的 JAnsi 1.x 库的依赖已被删除。
有关详细信息，请参阅Windows 上的 ANSI 样式。

雅加达 JMS 附加程序

JMS Appender 的雅加达兼容版本现已包含在核心发行版中。

添加

  • 添加 Google OSS-Fuzz 集成 (#2949)
  • 添加 GraalVmProcessor 注释处理器以生成 GraalVM 可访问性元数据。 (#3053)
  • 添加MonitorResource配置选项，以支持除配置文件本身之外的外部文件的监控。 （＃3074，＃3501）
  • 修复了“LoggerConfig.RootLogger.Builder#withtFilter(…)”方法中的拼写错误。创建了新的更正的“withFilter()”方法并弃用了旧方法。 (#3369)
  • 将 collectionName 和 databaseName 参数添加到 MongoDB 附加程序 (#3467)

已更改

  • 删除 JAnsi 库支持。 Windows 10 控制台自 2017 年起支持 ANSI 转义。(#1736)
  • 整合异常渲染逻辑并改进模式布局中的循环引用支持（#2691、#3123）
  • 重写 JAnsiTextRenderer 以在没有 JAnsi 库的情况下工作。 (#2916)
  • 将模式布局中的前缀堆栈跟踪从空格切换为换行符 (#3045)
  • 更改默认配置 使用的布局。 (#3118)
  • 切换到使用 Java 的 DateTimeFormatter 进行日志事件瞬间的日期和时间格式化（#3121、#2943）
  • 将默认异常转换器从扩展异常转换器切换为普通异常转换器 (#3123)
  • 不要因为批处理而关闭 StringReaders。 (#3127)
  • 将状态记录器中的前缀堆栈跟踪从空格切换为换行符 (#3149)
  • MongoDb Appender 不应记录弃用警告 (#3149)
  • 向 StringMatchFilter 添加改进的空/空文本验证。 (#3153)
  • 通过重写 SystemClock 提高 Java 8 中的亚毫秒精度。 (#3217)
  • 如果配置没有记录器/根记录器，则不要覆盖配置的配置名称。 (#3431)
  • 更新 GcpLayout.json 以提高与 Google Cloud Logging 的兼容性 (#3586)
  • 在 Base64Util 中直接调用 java.util.Base64 而不是反射 (#3686)
  • 改进LogEvent.toImmutable()、ReusableMessage.memento()，并删除ThrowableProxy的使用

已弃用

  • ThrowableProxy 及其所有用法（#2691，#3123）
  • AbstractLogger.checkMessageFactory() (#2936)
  • FixedDateTime、FastDateTime 和支持类 (#3121)
  • 在 LoggerRegistry 中使用对 Logger 的硬引用。 (#3143)

已修复

  • 将 MongoDB 测试切换到 Docker (#2229)
  • 添加基于 Jakarta 的 JMS Appender 并弃用 Javax 版本 (#2995)
  • 修复 RollingFileManager 以在 unsu 上重新打开文件
