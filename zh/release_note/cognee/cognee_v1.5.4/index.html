总结

此补丁版本重点关注可靠性、数据摄取便利性和前端优化。它修复了多个迁移、日志记录和来源问题，为摄取工具添加了小但有用的 API 和 Docker 便利性，并包括一系列广泛的前端更新和错误修复。

亮点

  • Docker 映像现在安装“dlt”额外功能，因此常见的数据摄取工具可以开箱即用。
  • API 添加端点接受 raw_data 字符串和 git 存储库 URL，以简化以编程方式添加数据集。
  • 对迁移、日志记录和来源进行多项修复，以提高升级和并发操作期间的稳定性。
  • 前端重组和大量 UI 修复，可改进数据集、仪表板和集成工作流程。
  • 安全性和安全性强化：API 令牌在启动日志中被编辑，并且默认情况下禁用本地文件根访问。

重大变更

  • 删除了“repositories”参数 — “repositories”参数已从受影响的 API/CLI 调用中删除。如果您依赖该参数，请将集成更新为新的调用模式（检查 OpenAPI 或 SDK 文档以获取更新的签名）。
  • COGNEE_ALLOWED_LOCAL_FILE_ROOTS 默认更改 — 现在默认禁用配置 COGNEE_ALLOWED_LOCAL_FILE_ROOTS。如果您之前使用它来允许本地文件访问，请在您的配置中显式重新启用它并验证允许的路径。

新功能

  • Docker 映像中的 DLT extra — 官方 Docker 映像现在安装“dlt”extra（用于数据加载的一组可选包）。这意味着依赖于该额外功能的连接器或摄取流将可以工作，而无需您在容器中手动安装额外的包。
  • 添加端点接受原始数据和存储库 URL — 添加数据的 API 现在接受 raw_data 作为字符串（因此您可以直接 POST 文本），并且还接受存储库克隆 URL。这使得以编程方式从 git 存储库或内联文本添加数据变得更容易，而无需预先上传文件。
  • 前端改进和新页面 - Web UI 在仪表板、数据集、集成和业务/画布页面上进行了大量更新。这些更改重新组织了列表和面板，改进了上传流程，并增强了入门步骤，使日常任务更加清晰和流畅。

改进

  • 每个进程运行一次迁移 - 关系数据库迁移现在只为一个进程执行一次，从而减少了启动期间的重复工作和竞争条件。
  • 改进了日志记录初始化 - 每个进程只初始化一次日志记录，并删除了导致混乱的详细/安静日志记录切换。这减少了重复的日志条目并使日志更易于阅读。
  • DLT 摄取分隔符处理 — 基于 dlt 的摄取管道现在可以正确处理使用不同分隔符（逗号、制表符等）的文件，因此混合源 CSV/TSV 文件导入更加可靠。
  • FastAPI 空数据崩溃已修复 - 修复了可能因空请求数据而崩溃的 FastAPI 错误，提高了 API 在边缘情况下的稳健性。
  • 演示 CLI 显示示例答案，无需额外的 LLM 调用 - CLI 演示模式现在可以完全显示存储的演示答案，无需访问语言模型，从而使演示更快且适合离线使用。
  • LanceDB 谓词引用 — LanceDB 检索谓词中的 ID 被正确引用，以避免某些 ID 格式的查询错误。
  • 将 EMBEDDING_API_BASE 读取为别名 — EMBEDDING_API_BASE 环境变量现在被识别为端点别名，从而简化了备用端点配置。
  • 出处清理 - 对出处处理的修复可阻止从分块内容创建的边的重复所有权，并在模型中声明正确的默认值，以便出处迁移表现一致。
  • 更新授权和所有权修复 - 增量更新现在由数据集 ACL（访问控制列表）授权，块预算查找解析为数据集所有者，并且在完全重建回退时保留原始数据集所有者。

性能

  • 减少来源锁争用 - 检查点已从来源锁中移出，从而减少了锁争用并提高了许多操作写入来源元数据时的并发性。
  • 更稳健的写入顺序 - 现在，在存储操作期间，图是在向量之前写入的，从而减少了部分写入的机会并提高了摄取期间的整体数据一致性。
  • 简化数据库配置 — 数据集数据库仅通过数据集 ID 进行配置，从而简化了配置逻辑并减少了环境设置期间的开销。

安全

  • 启动回显中的 API 令牌编辑 — 入口点不再在其启动回显中打印纯文本 —api-token；令牌经过编辑，因此不会在日志中泄漏。
  • 默认情况下禁用本地文件根 - 现在默认情况下禁用 COGNEE_ALLOWED_LOCAL_FILE_ROOTS 设置，以减少本地文件系统路径意外暴露到服务器的情况。
  • 跳过本地哨兵的租户权限授予 - 前端/服务器现在在运行本地哨兵实例时跳过自动租户权限授予，从而防止开发运行中意外的权限更改。

错误修复

  • 删除了“安静”日志记录模式，该模式会抑制有用的消息并导致混乱。
  • 修复了在某些调用中错误删除存储库参数的问题 - 更新回调表面以匹配新的调用模式。
  • 修复了 FastAPI 在空数据负载上崩溃的问题。
  • 编辑了启动输出中的 —api-token 参数。
  • 修复了 dlt 摄取以正确处理多个文件分隔符。
  • 修复了 DTO 重构回归并将 OpenAPI 附加功能与正在运行的应用程序同步，以便文档和 API 匹配。
  • 修复了块生成的出处边缘被双重拥有的问题。
  • 修复了确保使用正确的数据集所有者上下文解析块预算查找的问题。
  • 修复了数据集、仪表板和集成页面（上传进度、模式、列表渲染和连接器）中的多个前端错误。
  • 修复了 EMBEDDING_API_BASE 的读取行为，以便备用端点配置行为正确。

技术变更

  • 重构迁移：两个修订均使用一个冻结模式模块，并且方言选择由数据库绑定决定；在最近的合并后，进行了几次迁移重新调整以保持单一头。
  • 大量 CI 和测试更新：测试套件的重组、夜间/测试拆分以及为serve() 添加了 e2e 路由测试。
  • OpenAPI 同步和文档调整：小的简介修复和规范附加内容与正在运行的应用程序同步。
  • 各种内部重构和清理：重新设置代理迁移、配置更改和多个测试夹具修复。
