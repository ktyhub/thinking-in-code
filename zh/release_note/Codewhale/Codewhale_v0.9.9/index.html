Codewhale v0.9.9

Codewhale 是 Shannon Labs 的公共产品。 codewhale 命令、npm 包和发布资产名称保留小写技术名称 标识符。旧版 npm 包 deepseek-tui 已弃用，并且 不再收到进一步的发布。来自 v0.8.x 旧版 deepseek 的用户 / deepseek-tui 名称应随 docs/REBRAND.md 一起迁移。

安装

推荐 — npm（一个命令，两个入口点）

npm install -g codewhale

包装器下载匹配的 codewhale 和 codew 命令资产 从本版本开始。两者都包含相同的编译运行时。

Docker / GHCR

docker run --rm -it \
  -e DEEPSEEK_API_KEY="$DEEPSEEK_API_KEY" \
  -v codewhale-home:/home/codewhale/.codewhale \
  ghcr.io/hmbown/codewhale:v0.9.9

该图像公开与 codewhale 和 codew 相同的运行时。的 latest 标签也在发布时进行了更新。

货物（Linux / macOS）

cargo install codewhale-cli --locked

Cargo 包安装 codewhale。 Cargo 无法创建第二个命令 来自一个二进制目标的别名；想要更短拼写的用户可以添加 codew 到已安装的可执行文件的符号链接。 npm、Homebrew、存档、 shell-installer 和容器通道直接安装这两个命令名称。

手动下载——平台档案（推荐）

下面的每个存档都包含 codewhale 下的相同运行时和 codew 命令名称，加上安装脚本：

Unix（Linux / macOS）：

tar xzf codewhale-<platform>.tar.gz
cd codewhale-<platform>
./install.sh

窗户：

  • 对于安装程序路径，运行 CodeWhaleSetup.exe；它安装 codewhale.exe和codew.exe下 %LOCALAPPDATA%\Programs\CodeWhale\bin 并将该目录添加到 当前用户路径。
  • 提取您机器的存档：codewhale-windows-x64.zip 或 codewhale-windows-arm64.zip
  • 运行install.bat（复制到%USERPROFILE%\bin）
  • 将 %USERPROFILE%\bin 添加到您的路径

便携式 Windows 存档会跳过安装脚本 - 从任何目录提取并运行。 NSIS 安装程序当前未签名，可能会触发 Windows SmartScreen，直到签名证书连接到发布管道。

每个平台还有 裸露、未存档 codewhale-<platform> 和 codew-<platform> 资产。七个 codewhale-tui-<platform> 文件名 附加到 v0.9.5 的是字节相同的兼容性副本，仅用于让 已安装的 v0.9.4 clients 发现并跨越这个单一二进制文件 过渡；当前的安装程序不会公开第三个运行时。遗留的 npm 软件包 deepseek-tui 已弃用并且不会重新发布。用于迁移 来自 v0.8.x 旧二进制名称，请参阅 docs/REBRAND.md。

v0.9.9 里有什么

Codewhale v0.9.9 是一个真实且具有弹性的版本：shell 工具无法 当主机耗尽磁盘或描述符时，更长的楔入会话， 未经验证的上下文窗口和输出上限在每个 表面上看，DeepSeek V4 按已公布的高峰/非高峰等级定价，上交所 UTF-8 在每种方言中都无法关闭，舰队阴影可见，bwrap 得到 容器必需品和额外的根，dsh 皮肤包含在捆绑包中 配置文件，agent 工具架构减少到 12 个字段，以及 README/网站 区域设置增加到 18 个和 8 个。

已修复

  • 小写 bash 工具在完全输出溢出时不再楔入 无法创建文件：临时卷已满或描述符表已耗尽 用于失败 每个 呼叫 - 包括 echo ok - 与线束内部 “无法创建流式 shell 输出”并且永远不会恢复，直到 主机被清理了。溢出现在是尽力而为（有界尾部是 仍然返回，并且截断通知说明了为什么完整输出路径是 丢失），并且任何剩余的生成/流失败都会命名为耗尽 资源——磁盘、文件描述符、内存——并表示下一次调用是安全的 重试（#5465；取出所有者自己的 0.9.9 会话的楔子）。
  • 具体的路线/产品输出限制现在超过了保守的 未编目模型的 8,192 个令牌兼容性猜测。路线 发布无输出限制，保持故障关闭，记录模型上限 权威，并且路由限制永远不会提高请求的上限（#5460）。
  • 每个表面的上下文窗口诚实（#5239，#5441）： 上下文窗口阶梯的 model-name hint 和 fallback 梯级是 猜测，现在每个渲染的表面都这么说——状态线， /status、/config、上下文压力消息、模型选择器芯片、 和自动布线器库存。未经验证的窗口仍然推动实际预算 （压缩触发、上下文计量、输出预留）；他们只是停下来 阅读任何人都检查过的功能。从 _Nk 解析的窗口 型号后缀 (qwen3-32b-256k → 256K) 现在是它自己的 model-name hint 低于 catalog，因为它比较乐观 比保守——目录或提供商报告的价值胜过它。的 [providers.<name>] context_window 覆盖仍然是硬修复， 渲染为 configured，没有标记。
  • 输出上限诚实（#5440）：目录所做的人类家庭模型 未描述将 64K 消息层保留为其钳位，而 ChatGPT/ Codex OAuth 路线保留其 4K 政策，但 OutputCeilingSource 获得了 unverified 两者都响铃，因此执行流收据和模型选择器 将它们标记为 unverified/“假设楼层”而不是 documented。夹具 值不变。
  • 遥测默认开启可见（#5441）：codewhale doctor’s 运行时姿势部分获得了 telemetry=on (default) 样式的行 决定它的来源（cli | env | config | default），以及 codewhale config get telemetry 报告已解决的同意及其 在批量发货的机器上使用源而不是 key not found。真相 仅更改；分辨率和行为未受影响。
  • 舰队：侦察兵的只读外壳剥离（#5428）现在受到双方的尊重 姿势门和执行包络线，所以 git log、find | head、 npm view 和其他有界只读命令改为就地运行 被拒绝为“执行”(#5426)。授权范围仍未扩大 权威：角色隔离测试和 docs/SUBAGENTS.md 表明孩子 不能超过其父级的姿势（#5426，#5435）。
  • /rename 和 /title 现在适用于第一回合中期：会话文件确实 直到第一次自动保存才存在，因此重命名失败了 未找到；共享路径现在更喜欢每个会话检查点并且 从应用程序状态重建，通过现场进行 PTY 回归测试 事件循环（#5430）。
  • integrations dsh plan不再拒绝DeepSeek的默认 响应-方言路线（deepseek-v4-flash）；回应和 Anthropic-Messages 路由通过 pi-ai 进行 openai-responses / anthropic-messages 而不是近似值 或拒绝；只有经过验证的基本 URL 仍会被拒绝，并出现错误 命名提供者和模型（#5434）。
  • 实时定价时，会话成本不再为 unverified_live_pricing 无法验证（控制平面 503，仅 Models.dev 功能 覆盖）：DeepSeek V4 的提供商文档捆绑回退率 Fireworks / OpenCode Zen 上的家人恢复可用身材，现场 每个提供商的行仍然获胜，并且 kimi-k3 保持未定价，直到 存在公布的利率（#5241；从#5402 收获）。
  • 发布资产：release.yml 资产新鲜度检查与 释放作业自己的 started_at，因此不会在作业级别重新运行 npm 步骤 不再受到早期上传的毒害（#5429）。
  • macOS CI：agent_focus_pty 自动审核收据测试等待 已经完成并在轨道焦点上运行的工人；现在它成立了 孩子的总结并等待解决的实时行（参考＃5056，＃5403）。
  • DeepSeek V4 定价遵循公布的高峰/非高峰等级（高峰 世界标准时间 01:00–04:00 和 06:00–10:00；非高峰期是高峰期的一半） deepseek-v4-flash 和 deepseek-v4-pro 以美元和人民币计算，解析自 每回合的记录时间；过时的单层行低估了成本上升 到~4×。因为现在每个直接 DeepSeek 第一方费率都是 时间窗口，记分卡未能关闭（missing_recorded_time） 未注明日期的 DeepSeek 回合而不是猜测层（#5470；#5241 后续， 已于 2026 年 8 月 17 日根据 api-docs.deepseek.com 进行验证）。
  • 跨 HTTP/2 数据帧的 SSE UTF-8 分割现在无法在每个 流方言：共享严格解码器、尾部刷新和 decode_failed 传播 (InvalidSseUtf8) 替换每种方言 近似值，带有字节块解码器测试（#5374；取代草案 第5404章）
  • 型号：release_four_read_only_fleet_roles_launch_with_canonical_prompts 舰队孩子们在呼叫阻塞的 JSON 路径时用 SSE 回答； 在慢速 macOS 上重试解析失败并重复计算工作线程 跑步者（#5471；参考文献#5056）。
  • 上下文：每个网络工具表面（Web、web_search、web.run、 fetch_url）现在使用噪声结果软限制，因此大的读取是 像 shell 输出一样压缩，而不是消耗普通的硬限制 （#5474，感谢@h3c-hexin）。
  • 路由：小写保存的选择器（例如 glm-5.2）根据 拥有 Z.ai / DeepSeek 目录行（大小写折叠回退，仅当恰好 一个提供商拥有的线路 ID 匹配），而不是被分类为另一个提供商 提供商的裸模型（#5475，感谢@h3c-hexin；诊断由@asto18089 在 Pinvou/CodeWhale#14）。
  • 模型目录截至 2026 年 8 月 17 日针对官方发布 定价页面：gpt-5.6-terra / gpt-5.6-luna 费率，claude-sonnet-5 保持不变 $2/$10（9月宣布的涨价已撤回），claude-opus-5 添加了 kimi-k3 和 kimi-k2.7-code-highspeed、MiniMax-M2.7-highspeed、 Mistral 第一方行，具有长上下文的 xAI grok-4.5 / grok-4.3 等级、Gemini 和 Qwen 限制以及 RedNote 的 dots3-note 预览版 OpenRouter 行（尚不存在第一方 API） — 每个数字都带有其 源和固定测试 (#5485)。
  • 网站：在 codewhale.net 上复制，用简单的陈述句重写 - 每句话一个想法，数字来自生成的事实，没有自我叙述 — 语音表位于 docs/design/WEB_VOICE.md (#5483)。
  • CI：发布工作流程不再恢复 npm/cargo 缓存 检查调用者提供的 SHA — CodeQL 缓存中毒高点 #88–#107 通过工作流程文件的合同测试结束 (#5463)。
  • 60 列以下的紧凑型 TUI 行不再保留隐藏的会话指标 条，因此狭窄的终端回收该行而不是 clipping 成绩单（#5486）。
  • Ghostty 的真彩色水下场现在使用专用的同步 60 FPS 通道而不是传统的 30 FPS 兼容性上限，具有连续 焦散褪色取代了明显的阶梯式颜色变化。
  • 实时推理的广告 Space:expand 操作现在在 作曲家的第一个字符粘贴突发保持，而活动粘贴中的空格 保留有效载荷。最新的推理预览也只花费真正免费 截断之前的视口行而不是停在固定的 10/12 行 在宽敞的终端上进行回退。
  • 严格的 cargo doc 构建不再在 rustdoc 注释中的裸 URL 上失败； 其余链接是显式 Markdown 目标 (#5489)。

已更改

  • 面向模型的 agent 工具恰好广告了 12 个字段 — action， prompt、type、profile、name、agent_id、message、until、 detached、worktree、write_roots、resume_from — 从 33 下降 （#5324，参考#5123）。预算（max_steps、wall_time_secs、max_depth）、 路由覆盖（model、model_strength、thinking）、工作树路径 旋钮、故意/生成合同字段和等待/状态/中断 额外内容已从广告模式中移出。每个删除的字段都会保留 解析接受并遵守不变（与 token_budget 相同的合同），所以 保存的记录、ACP/MCP clients 和舰队配置按原样重播；的 #5426/#5435 密封夹未受影响。儿童预算现已解决 从角色默认值（60/120 圈、1800 秒壁时间、未改变的夹具）和 新 [subagents] 钥匙 default_max_steps / default_wall_time_secs。 因为工具目录是会话固定提示符前缀的一部分 (docs/CACHE.md)，升级会在每个会话中重新填充一次 KV 前缀。
  • TUI 散文 — 用户消息、助理答案和推理/思考 — 现在在宽终端上以完整内容宽度换行，匹配 工具/状态单元格，而不是停在 105 列的栏上，留下一个 超宽显示器上的右边界（#5436）。
  • 配置的技能提示在会话根和操作中都是稳定的 系统：只有自定义配置的根隐藏其物理路径，普通 工作空间/全局技能保持可发现的隐私安全路径，警告 替换是边界感知的（包括非 UTF-8 Unix 路径），并且 Windows 分隔符呈现为 /。技能提示也是50字节 在不提高运行时合约上限的情况下更精简（#5492，#5473）。
  • 自动路由器分类器请求接受 [auto.router] timeout_secs，同时 当密钥不存在时保留现有的默认值（#5494）。
  • 每个 ci.yml 作业现在都有一个明确的 10-90 分钟超时，适合 它的工作负载，限制陈旧分配的运行者而不是继承 GitHub 的六小时默认值 (#5495)。
  • 文档 shell 和共享 Web 组件现在通过路由本地化副本 打字词典书脊；这是 #5337 的两个增量阶段， 未完成完整的史诗（#5488，#5490）。
  • 依赖项：rusqlite 0.40.2 (#5391)。
  • 文档：过时的 A/B/C 层参考、提供商默认值、模块 描述和线锚点现在与当前代码匹配（#5481）。
