Codewhale v0.10.1

Codewhale 是 Shannon Labs 的公共产品。 codewhale 命令、npm 包和发布资产名称保留小写技术名称 标识符。旧版 npm 包 deepseek-tui 已弃用，并且 不再收到进一步的发布。来自 v0.8.x 旧版 deepseek 的用户 / deepseek-tui 名称应随 docs/REBRAND.md 一起迁移。

安装

推荐 — GitHub 官方发布

新的 macOS/Linux 安装（此版本中的校验和二进制文件）：

curl -fsSL https://codewhale.net/install.sh | CODEWHALE_VERSION="v0.10.1" sh
"$HOME/.local/bin/codewhale" --version

对于 Windows，请使用下面匹配的安装程序或存档。对于现有的 直接安装，运行codewhale update；它打印可执行路径并 保留较新的版本。如果安装目录被不同的版本占用， 使用安装指南中的全新目录迁移。

二次包装——npm 和 Cargo

npm install -g codewhale
# or build from source
cargo install codewhale-cli --locked

包装器下载匹配的 codewhale 和 codew 命令资源 从本版本开始。两者都包含相同的编译运行时。

Docker / GHCR

docker run --rm -it \
  -e DEEPSEEK_API_KEY="$DEEPSEEK_API_KEY" \
  -v codewhale-home:/home/codewhale/.codewhale \
  ghcr.io/codewhale-hq/codewhale:v0.10.1

该图像公开与 codewhale 和 codew 相同的运行时。的 latest 标签也在发布时进行了更新。

货物（Linux / macOS）

cargo install codewhale-cli --locked

Cargo 包安装 codewhale。 Cargo 无法创建第二个命令 来自一个二进制目标的别名；想要更短拼写的用户可以添加 codew 到已安装的可执行文件的符号链接。 npm、Homebrew、存档、 shell-installer 和容器通道直接安装这两个命令名称。

手动下载——平台档案（推荐）

下面的每个存档都包含 codewhale 下的相同运行时和 codew 命令名称，加上安装脚本：

平台 档案 安装脚本
Linux x64 codewhale-linux-x64.tar.gz install.sh
Linux ARM64 codewhale-linux-arm64.tar.gz install.sh
Android ARM64 (Termux) codewhale-android-arm64.tar.gz install.sh
macOS x64 codewhale-macos-x64.tar.gz install.sh
macOS ARM codewhale-macos-arm64.tar.gz install.sh
Windows x64（安装程序） CodeWhaleSetup.exe NSIS 设置
Windows x64 codewhale-windows-x64.zip install.bat
Windows x64（便携式） codewhale-windows-x64-portable.zip —
Windows ARM64 codewhale-windows-arm64.zip install.bat
Windows ARM64（便携式） codewhale-windows-arm64-portable.zip —

Unix（Linux / macOS）：

tar xzf codewhale-<platform>.tar.gz
cd codewhale-<platform>
./install.sh

窗户：

  • 对于安装程序路径，运行 CodeWhaleSetup.exe；它安装 codewhale.exe、codew.exe 和 codewhale.bat 下 %LOCALAPPDATA%\Programs\CodeWhale\bin，将该目录添加到 当前用户路径，并创建一个首选的开始菜单快捷方式 安装后的 Windows 终端 (wt.exe)。
  • 提取您机器的存档：codewhale-windows-x64.zip 或 codewhale-windows-arm64.zip
  • 双click codewhale.bat（不是原始的.exe）推出
  • 运行 install.bat 将二进制文件和启动器复制到 %USERPROFILE%\bin
  • 将 %USERPROFILE%\bin 添加到您的路径

便携式 Windows 存档会跳过安装脚本 - 从任何目录提取并运行 codewhale.bat。 NSIS 安装程序当前未签名，可能会触发 Windows SmartScreen，直到签名证书连接到发布管道。

每个平台还有 裸露、未存档 codewhale-<platform> 和 codew-<platform> 资产。七个 codewhale-tui-<platform> 文件名 附加到 v0.9.5 的是字节相同的兼容性副本，仅用于让 已经安装的 v0.9.4 clients 发现并跨越这个单一二进制文件 过渡；当前的安装程序不会公开第三个运行时。遗留的 npm 软件包 deepseek-tui 已弃用并且不会重新发布。用于迁移 来自 v0.8.x 旧二进制名称，请参阅 docs/REBRAND.md。

验证（推荐）

从该版本下载校验和清单并验证：

# Linux — archive bundles
sha256sum -c codewhale-bundles-sha256.txt --ignore-missing

# Linux — individual binaries
sha256sum -c codewhale-artifacts-sha256.txt --ignore-missing

# macOS
shasum -a 256 -c codewhale-bundles-sha256.txt --ignore-missing
shasum -a 256 -c codewhale-artifacts-sha256.txt --ignore-missing

v0.10.1 里有什么

贡献者集成和可靠性

  • OAuth 重试诊断忽略提供商控制的错误字段；在退役的微信收据超出其存储限制之前，帐户替换就会停止，从而为本地审核保留不确定的工作。
  • 通过符号链接恢复到同一工作区的会话不再显示错误的工作区更改警告。
  • 运行时 clients 可以读取一个工具调用的实际工作区更改并查看技能详细信息（感谢 @gaord、#6817 和 #6869）。动态快照对仍待处理；丢失的对象和损坏的存储库元数据是区分的。
  • 搜索接受有效的首选区域设置，图像尺寸描述发送到模型的相同字节（感谢@asto18089、#6860 和#6858）。自动化删除保留其定义，直到清理成功，而压缩保留其原始摘要锚点（#6864 和 #6857）。
  • 配置/状态/权限命令共享可移植合约，而主机保留突变权限；队列工作人员承认针对临时第一声明争用的计划重试，并诚实地因损坏而失败（感谢@aboimpinto，#6832）。
  • 无限期的问题、批准和升级等待在 TUI 监管机构中仍然存在。答案有时间恢复当前回合；已解决的请求
