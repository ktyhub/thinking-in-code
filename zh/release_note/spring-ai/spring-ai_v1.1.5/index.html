spring-ai v1.1.5

Spring AI 1.1.5 Release Notes

🎯 亮点

此版本包括 9 个错误修复、3 个文档改进和 11 个其他改进。

⚠️ 升级注意事项

  • Pixtral 12B 型号已被删除，Pixtral Large 已被弃用。更新您的模型配置以使用当前推荐的 Pixtral 模型，以避免未来版本中出现问题。 447d2a4

📢 值得注意

  • Pixtral 12B 型号已被删除，Pixtral Large 型号现已弃用。集成测试已更新为使用推荐的替换模型。依赖这些模型的用户应迁移到推荐的替代方案。 447d2a4

🪲 错误修复

  • 修复了 CosmosDB 矢量存储的 doDelete 方法，以正确参数化查询，防止潜在的 SQL 注入漏洞并提高正确性。 6039e57
  • 修复了在 VectorStoreChatMemoryAdvisor 过滤器中未正确应用对话 ID 的问题，这可能会导致跨对话的内存检索不正确。 3cccfdf
  • 更正了向量存储过滤器表达式转换器中的键处理，以确保正确评估过滤器表达式。 01386e2
  • 解决了 BedrockConverse 流令牌使用测试中的测试不确定性，提高了测试可靠性。 4747a3c
  • 更正了测试类命名以正确应用集成测试后缀，确保正确的测试分类和执行。 #5853
  • 更正了 OpenAiSdkChatModel 中 toolChoice 字段的字符串解析逻辑，以确保正确处理工具选择配置。 aeb33b0 通过 #5735
  • 修复了传出 OpenAI API 请求中错误包含 extra_body 参数的问题，这可能会导致意外行为。 4c0120c
  • 解决了 Javadoc 生成和配置问题，以确保正确生成 API 文档。 0a71804
  • 更正了测试旁路条件，以便在环境中未配置所需的 API 密钥时正确跳过集成测试。 bc26dc1

📓 文档

  • 更新了自述文件以包含有关 CPU 架构要求或兼容性信息的注释。 a21e988
  • 添加了解释 MCP 服务器如何从 MCP clients 重新发布工具的文档，阐明了多服务器设置中的工具传播模型。 #5778
  • 改进了文档，以阐明 OpenAI API 请求中 extra_body 参数的预期用法和行为。 3d4d75b

🔨 依赖项升级

  • 将 Spring Boot 依赖项更新为 3.5.14 版本，包含 Spring Boot 团队的最新错误修复和改进。 eb4c9a5
  • 将 Spring Boot 依赖项更新为版本 3.5.13 作为中间升级。 9b902f8
  • 更新了文档解析依赖项：Apache Tika 升级到 3.3.0，jsoup 升级到 1.22.1，Apache PDFBox 升级到 3.0.7，以改进文档处理能力并修复错误。 f25fc52

🔩 构建更新

  • 将 GitHub Actions 工作流依赖项更新为最新版本，以提高 CI/CD 可靠性和安全性。 9b70b38
  • 更改了 PR 检查工作流程以使用 mvn package 而不是 mvn test，以实现更高效的拉取请求验证。 7d2e455
  • 现在在 CI 管道中跳过集成测试以提高构建性能，并且 release notes 生成工作流程已被删除。 #5688
  • 该项目已在发布后升级到下一个开发版本 1.1.5-SNAPSHOT。 400dc42

🔐 安全

  • 强化了用于变压器模型的默认缓存目录，以防止未经授权的访问或篡改缓存的模型文件。 aac6b80
  • 修复了潜在的拒绝服务漏洞，其中格式错误的 PDF 可能会导致文档解析期间内存分配过多。 b61ac6a
