spring-ai v1.0.7

Spring AI 1.0.7 Release Notes

🎯 亮点

此版本包括 5 个错误修复和 6 个其他改进。

⏪ 重大变更

  • 聊天记忆顾问现在需要提供明确的对话 ID。以前，可能使用了默认或隐式 ID，这可能会导致会话之间的内存范围不正确。呼叫者现在必须明确提供对话 ID。 be48f06

⚠️ 升级注意事项

  • 如果您使用的是 PromptChatMemoryAdvisor，请迁移到替换顾问。所有聊天内存顾问现在都需要提供显式的 conversationId - 更新您的代码以在创建或调用聊天内存顾问时传递对话 ID。 be48f06

🪲 错误修复

  • 更正了 Milvus 矢量存储的 doDelete 方法中处理 ID 列表时的字符串 escaping，防止删除操作期间潜在的查询错误。 864ef81
  • 解决了 MCP 服务器中 ObjectMapper 的错误配置，确保正确的 JSON 序列化和反序列化行为。 436c765
  • 更正了影响 MCP 服务器和 Spring WebMvc 服务器设置的自动配置问题。之前的错误修复已恢复并替换为正确的解决方案。 4b21612
  • 更新了 ChatClientAdvisor 的集成测试，以提供显式对话 ID，符合聊天内存顾问中显式 ID 的新要求。 a5fb397
  • 解决了方法调用函数回调的 Anthropic 聊天 client 集成测试中的测试失败问题。 daa1b68

🔨 依赖项升级

  • 通过重大版本跳跃（0.10.0 → 0.18.2）更新了模型上下文协议（MCP）SDK，纳入了许多上游改进、新功能和兼容性更新。 #5958

🔩 构建更新

  • 项目构建现在使用 JDK 17.0.19，确保与最新的 LTS 补丁版本保持一致，以提高构建环境的安全性和稳定性。 1badb6f
  • Spring AI 入门模块已重新定位到专用的 starters/ 目录，改进了项目的目录结构和组织。 36df6b9
  • 项目版本升级至 1.0.7-SNAPSHOT，以在 1.0.6 发布后开始下一个开发周期。 82848f2
