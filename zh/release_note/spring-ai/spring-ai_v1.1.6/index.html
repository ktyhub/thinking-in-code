spring-ai v1.1.6

Spring AI 1.1.6 Release Notes

🎯 亮点

此版本包括 1 项新功能、5 项错误修复、2 项文档改进和 5 项其他改进。

⏪ 重大变更

  • 聊天记忆顾问现在需要提供明确的对话 ID。这是一种行为变化，会影响聊天内存的范围和管理方式。依赖隐式会话 ID 的应用程序必须更新以提供显式 ID。 13cde41

⚠️ 升级注意事项

  • PromptChatMemoryAdvisor 现已弃用，聊天内存顾问需要显式对话 ID。将代码更新为：(1) 将 PromptChatMemoryAdvisor 替换为推荐的替代方案，(2) 确保在使用任何聊天内存顾问时提供显式对话 ID。 917f62e

⭐ 新功能

  • MCP 自动配置现在包括缺少的 @ConditionalOnMissingBean 检查，允许用户提供自己的 bean 定义并按照 Spring Boot 自动配置模式中的预期覆盖自动配置的 MCP bean。 d4025e5

🪲 错误修复

  • 修复了 MilvusVectorStore 的 doDelete 方法错误地转义 ID 列表中的字符串，这可能导致删除操作失败或行为异常的问题。 20206a4
  • 修复了 ChatClientAdvisorTests 测试套件以提供显式对话 ID，使测试与聊天内存顾问中显式对话 ID 的新要求保持一致。 704e5c6
  • 修复了 MistralAiChatModelObservationIT 集成测试，以确保观察功能与 MistralAI 聊天模型提供程序正常工作。 a89145d
  • 纠正了配置选项未正确包含在 MistralAI API 请求中的问题，确保所有用户定义的设置均正确传递。 7bcf32a
  • 解决了使用 Ollama 集成时处理 AssistantMessage.ToolCall.id 的回归问题，恢复正确的工具调用识别行为。 bb9d65e

📓 文档

  • 更正了 MCP（模型上下文协议）文档中的印刷错误，以提高可读性和准确性。 a1ad7f2
  • 修复了文档中损坏的外部参照锚点，以恢复文档部分之间正确的交叉引用导航。 f03c104

🔨 依赖项升级

  • 将 MCP SDK 从版本 0.17.0 更新为 0.18.2，并将 MCP 注释从 0.8.0 更新为 0.9.0，引入了最新的 MCP 协议改进和错误修复。 #5961

🔩 构建更新

  • 更新了项目构建以使用 JDK 17.0.19，确保兼容性并为构建环境纳入最新的 Java 17 补丁版本。 27281e6
  • 通过将 Spring AI 入门模块重新定位到专用的 starters/ 目录来重新组织项目结构，以获得更好的可维护性和清晰度。 22f8676
