bootstrap v5.3.1

修订 发布时间2023年7月26日 来源twbs/bootstrap 英文原文

bootstrap v5.3.1

亮点

  • 颜色模式：
    • 通过将机身颜色的 $gray-500 替换为 $gray-300 来增加暗模式的颜色对比度
    • 将我们的颜色模式切换器 JavaScript 添加到我们的示例 ZIP 下载中
  • 组件：
    • 改进了所有 .nav-link 的禁用样式，提供 .disabled 和 :disabled 与锚点和按钮一起使用
    • 添加对 Home 和 End 键的支持，以便通过键盘导航选项卡
    • 添加了一些基本样式以在不存在修饰符类时切换按钮
    • 修复了深色模式下的轮播颜色
  • 表格：
    • 修复了浮动标签禁用文本颜色
  • 公用事业：
    • .text-bg-* 实用程序现在使用 CSS 变量
  • 萨斯：
    • 添加新的 $navbar-dark-icon-color Sass 变量
    • 删除了重复的 $alert Sass 变量
    • 为 $vr-border-width 添加了一个新变量来自定义垂直线辅助宽度
  • 文档：
    • 在我们的主页添加了搜索
    • 改进了仪表板示例上的响应行为
    • 改进了 Cheatsheet 示例的暗模式渲染
