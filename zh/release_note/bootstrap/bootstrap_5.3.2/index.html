bootstrap v5.3.2

修订 发布时间2023年9月14日 来源twbs/bootstrap 英文原文

bootstrap v5.3.2

亮点

  • 自 Dart Sass v1.65.0 起，不推荐将百分比单位传递给全局 abs()。使用 Dart Sass 编译 Bootstrap 时会导致出现弃用警告。通过更改传递给 divide() 函数的值，此问题已在内部得到修复。 divide() 函数本身尚未修复，因此我们可以继续支持 node-sass 交叉兼容性。在 v6 中，这不会成为问题，因为我们计划放弃对 node-sass 的支持。
  • 在塌陷目标中使用多个 id 不再有效，并且已得到修复。

颜色模式

  • 增加了浅色和深色模式下表单范围轨道背景的颜色对比度。
  • 修复了颜色模式的表格状态渲染，重点关注深色模式下的条纹表格以增加颜色对比度。
  • 允许颜色模式的 <mark> 颜色自定义。

文档

  • 在入门 -> 下载 中添加了替代 CDN 部分。
  • 在 README 和 入门 -> 简介 中添加了 Discord 和 Bootstrap subreddit 链接：
    • Discord 由社区维护
    • Bootstrap subreddit
