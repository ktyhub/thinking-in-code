skywalking v10.2.0

小版本 发布时间2025年3月24日 来源apache/skywalking 英文原文

skywalking v10.2.0

下载

https://skywalking.apache.org/downloads/

####通知 请勿从此页面下载源代码。 如果您想自行构建源代码，请按照构建文档。

没有 H2，更多 BanyanDB

  • 添加 BanyanDB 0.8.0 支持。
  • H2 存储选项已永久删除。

项目

  • 对于Elasticsearch中需要排序或聚合的字段添加doc_values，并禁用所有其他字段。
    • 此更改不会影响我们正式版本用户的现有部署及其功能。
    • 警告 如果我们的 Elasticsearch 索引有自定义查询插件，此更改可能会破坏它们，因为使用意外字段的排序查询和聚合查询被阻止。
  • [重大更改] 将 debugging-query 模块重命名为 status-query 模块。相对暴露的 API 是不变。
  • [重大更改] skywalking-oap-server 的所有 jar 不再通过 Maven Central 发布。我们只会将源 tar 和二进制 tar 发布到网站下载页面，并将 docker 映像发布到 docker 中心。
    • 警告 如果您在项目中使用 skywalking-oap-server 作为依赖项，则需要从网站下载源 tar 并将它们发布到您的私有 maven 存储库。
  • [重大更改] 永久删除 H2 作为存储选项。 BanyanDB 0.8（需要 OAP 10.2）简单、稳定且可用于生产。不再需要 H2 作为默认存储。
  • [重大变更] 将 BanyanDB 服务器版本提升至 0.8.0。此版本与以前的版本不兼容。在将 OAP 升级到 10.2.0 之前，请将 BanyanDB 服务器升级到 0.8.0。
  • 将nodejs升级到v22.14.0以进行最新的UI(booster-ui)编译。
  • 将 tj-actions/changed-files 迁移到 dorny/paths-filter。

OAP 服务器

  • 跳过处理带有 FLAG_NO_RECORDED_VALUE 标志的 OTLP 指标数据点，这会导致异常结果。
  • 为 GraphQL 查询添加自我观察指标，graphql_query_latency。
  • 减少进程索引的数量，并在查询进程索引时增加时间范围。
  • 将 Apache commons-io 升级为 2.17.0。
  • 完善 eBPF so11y 指标并添加查询指标的错误计数。
  • 支持带持续时间参数的查询端点列表（可选）。
  • 将附加列 last_ping 的端点_流量更改为可更新。
  • 为GoZero框架添加组件ID(5023)。
  • 支持Kong监控。
  • 支持为服务/端点级别指标添加额外的 attr[0-5]。
  • 支持异步分析器功能进行性能分析。
  • 为指标topN查询结果添加指标值所有者。
  • 添加 EndpointDependencyBuilder 的命名控制。
  • 删除了索引类型 BanyanDB.IndexRule.IndexType#TREE。现在所有指数都使用IndexType#INVERTED。
  • 向 BanyanDB 添加最大查询大小设置。
  • 修复“BanyanDBTraceQueryDAO.queryBasicTraces”不支持“trace_id”查询的问题。
  • 完善网格数据调度程序：如果实例/端点指标为空，则不生成它们。
  • 在 Istio 1.24 中采用新的元数据标准化。
  • 将 netty 提升至 4.1.115，将 grpc 提升至 1.68.1，将钻孔提升至 2.0.69。
  • BanyanDB：支持OAP启动时更新组设置。
  • BanyanDB：引入索引模式并重构banyandb组设置。
  • BanyanDB：引入新的渐进式TTL功能。
  • BanyanDB：支持OAP启动时更新Schema。
  • BanyanDB：初始化BanyanDB 时加快OAP 启动速度。
  • BanyanDB：在列上支持@EnableSort，以启用IndexRule排序，并将默认设置为false。
  • 支持Get Effective TTL Configurations API。
  • 修复ServerStatusService.statusWatchers并发修改问题。
  • 添加对动态配置更改传播链的保护。
  • 添加 Ruby 组件 ID（HttpClient=2、Redis=7、Memcached=20、Elasticsearch=47、Ruby=12000、Sinatra=12001）。
  • 添加咖啡因成分 ID(160)。
  • 报警：支持存储和查询报警触发时的指标快照。
  • 报警：删除未使用的Alarm Trend查询。
  • 修复 zipkin 查询模块的 span 查询中缺少远程端点 IP 地址的问题。
  • 修复hierarchy-definition.yml配置文件错误打包到start.jar中的问题。
  • 添加 bydb.dependencies.properties 配置文件来定义服务器依赖版本。
  • 修复 AvgHistogramPercentileFunction 没有正确的 ranks 字段定义。
  • BanyanDB：支持新的Property数据模块。
  • MQE：支持top_n_of功能，用于合并多个指标topn查询。
  • 支持OAL引擎中的labelAvg功能。
  • OAL的labelCount函数中添加maxLabelCount参数，限制可统计的标签数量。
  • 适配新的浏览器API(/browser/perfData/webVitals、/browser/perfData/webInteractions、/browser/perfData/resources)协议。
  • 添加熔断机制。
  • BanyanDB：添加对基于BanyanDB服务器的API版本的兼容性检查的支持。
  • MQE：支持&&(and)、||(or)布尔运算符。
  • OAP 自观察性：添加 JVM 堆和直接内存使用指标。
  • OAP 自观察性：添加水印电路中断/恢复指标。
  • AI Pipeline：支持查询基线指标名称并预测指标值。
  • 添加Get Node List in the Cluster API。
  • 在将 Envoy 日志转换为 JSON 进行持久化时添加类型描述符，以避免转换错误。
  • Bseline：支持通过MQE查询基线并在警报规则中使用。
  • 将 netty 升级到 4.11.118 以修复 CVE-2025-24970。
  • 添加Get Alarm Runtime Status API。
  • 查询报警指标窗口值时添加lock。
  • 添加故障安全机制，防止内存和数据库服务器之间的流量指标不一致。
  • 当oap-cluster-internal数据(metrics/traffic)格式不一致时，添加更清晰的日志。
  • 优化当跟踪延迟大于缓存超时时指标缓存加载。
  • 允许调用`lang.groovy。
