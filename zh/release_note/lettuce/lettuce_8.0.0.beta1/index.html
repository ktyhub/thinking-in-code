lettuce 8.0.0.BETA1

Lettuce 团队很高兴地宣布 Lettuce 8.0 的第一个测试版发布！

此版本使得 Project Reactor 不再需要：仅使用同步和异步 API 的应用程序可以排除 reactor-core：

<dependency>
    <groupId>io.lettuce</groupId>
    <artifactId>lettuce-core</artifactId>
    <version>8.0.0.BETA1</version>
    <exclusions>
        <exclusion>
            <groupId>io.projectreactor</groupId>
            <artifactId>reactor-core</artifactId>
        </exclusion>
    </exclusions>
</dependency>

Lettuce 8.0 还删除了基于 Reactor 的 API（其中大部分在 7.8 和 7.9 中已弃用），并更改了 Reactor 类型的扩展点。有关详细信息和重大更改，请参阅 Lettuce 8.0 的新增功能。

PR：[反应堆可选] 通过 @atakavci 在 https://github.com/redis/lettuce/pull/3731 中使“Project Reactor”成为可选依赖项

Lettuce 8.0.0.BETA1 支持 Redis 2.6+ 直至 Redis 8.x 并需要 Java 8 或更高版本。该驱动程序针对 Redis 8.12、8.10、8.8、8.6、8.4、8.2、7.4 和 7.2 进行测试。

我们鼓励您尝试此测试版，特别是在排除 Reactor 的情况下，并在正式发布之前提供反馈。

完整 Changelog：https://github.com/redis/lettuce/compare/7.9.0.RELEASE…8.0.0.BETA1
