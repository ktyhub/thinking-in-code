lettuce 7.8.0.RELEASE

Lettuce 团队很高兴地宣布 Lettuce 7.8.0 次要版本！

生菜 7.8.0 支持 Redis 2.6+ 至 Redis 8.x。在 Java 运行时方面，Lettuce 至少需要 Java 8 和 适用于 Java 24。该驱动程序针对 Redis 8.10、Redis 8.8、Redis 8.6、Redis 8.4、Redis 8.2、Redis 8.0、Redis 7.4 和Redis 7.2。

感谢所有使 Lettuce 7.8.0.RELEASE 成为可能的贡献者。

📗 链接 参考文档：https://lettuce.io/core/7.8.0.RELEASE

⭐ 新功能

  • [Redis 8.10] 在https://github.com/redis/lettuce/pull/3878中添加@uglide对复数值FieldValue的FT.AGGREGATE REDUCE COLLECT支持
  • 通过 @a-TODO-rov 在 https://github.com/redis/lettuce/pull/3915 中准备公共 API 以支持可选的 Reactor
  • 通过 @Dgramada 在 https://github.com/redis/lettuce/pull/3908 中使用附加参数扩展 ZRANGE
  • 由 @viktoriya-kutsarova 在 https://github.com/redis/lettuce/pull/3884 中重新设计 redis 搜索模块的编解码器

🐞 错误修复

  • 在 https://github.com/redis/lettuce/pull/3894 中放松 @ggivo 在没有缓冲命令的情况下移动重新绑定的超时
  • 当 @HwangRock 在 https://github.com/redis/lettuce/pull/3851 中的反应式复杂输出命令出错时，发出 onError 信号而不是挂起
  • 修复 https://github.com/redis/lettuce/pull/3861 中@cfcromn 对顶级标量响应的 ObjectOutput 处理
  • @Dgramada 在 https://github.com/redis/lettuce/pull/3919 中对非字符串编解码器的 LCS 命令进行了破坏
  • 修复：带有 JUSTID 的 XAUTOCLAIM 报告已删除 PEL 条目，作为 @waterWang 在 https://github.com/redis/lettuce/pull/3901 中声明的消息
  • 支持 Sentinel 在 https://github.com/redis/lettuce/pull/3920 中通过 @uglide 实现部分命令界面

⚙️维护

  • 通过 @a-TODO-rov 在 https://github.com/redis/lettuce/pull/3899 中将 Netty 转换为 4.2.17.Final
  • @a-TODO-rov 在 https://github.com/redis/lettuce/pull/3905 中将 Reactor Core 升级到 3.8.7

💡其他

  • 通过 @a-TODO-rov 在 https://github.com/redis/lettuce/pull/3914 中将地理故障转移 API 提升到 GA
  • 在 https://github.com/redis/lettuce/pull/3913 中弃用 @Dgramada 的排序集命令
  • 弃用 https://github.com/redis/lettuce/pull/3897 中@a-TODO-rov 遗留的 client 端缓存支持
  • 使 PooledClusterConnectionProvider 中的分区和 readFrom 易失性 #3777 by @big-cir in https://github.com/redis/lettuce/pull/3783
  • 由 @bobymicroby 在 https://github.com/redis/lettuce/pull/3903 中报告每晚工作流程的测试指标
  • 在 https://github.com/redis/lettuce/pull/3895 中添加 @a-TODO-rov 的预热文档
  • 在 https://github.com/redis/lettuce/pull/3896 中 @a-TODO-rov 发布 7.7 后更新文档
  • 支持在 https://github.com/redis/lettuce/pull/3898 中通过 @uglide 对外部提供的 Redis Enterprise 数据库运行集成测试

❤️ 新贡献者 - 欢迎来到 Lettuce 大家庭！

  • @cfcromn 在 https://github.com/redis/lettuce/pull/3861 中做出了第一个贡献
  • @waterWang 在 https://github.com/redis/lettuce/pull/3901 中做出了第一个贡献
  • @bobymicroby 在 https://github.com/redis/lettuce/pull/3903 中做出了第一个贡献
