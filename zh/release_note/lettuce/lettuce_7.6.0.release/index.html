lettuce 7.6.0.RELEASE

Lettuce 团队很高兴地宣布 Lettuce 7.6.0 次要版本！

✨ 亮点

Lettuce 7.6.0 引入了对 Redis OSS 8.8 版本 的新功能的支持，例如：

  • 新的数组数据结构
  • INCREX：结合 INCR、INCRBY、INCRBYFLOAT、边界和过期的窗口计数器速率限制器
  • XNACK：一个新的流命令 - 允许消费者显式释放挂起的消息
  • ZUNION、ZINTER、ZUNIONSTORE、ZINTERSTORE：新的 COUNT 聚合器
  • JSON.SET：新的 FPHA 参数用于指定同构 FP 数组的 FP 类型

生菜 7.6.0 支持 Redis 2.6+ 至 Redis 8.x。在 Java 运行时方面，Lettuce 至少需要 Java 8 和 适用于 Java 24。该驱动程序针对 Redis 8.8、Redis 8.6、Redis 8.4、Redis 8.2、Redis 8.0、Redis 7.4 和 Redis 7.2 进行测试。

感谢所有使 Lettuce 7.6.0.RELEASE 成为可能的贡献者。

📗 链接 参考文档：https://lettuce.io/core/7.6.0.RELEASE
