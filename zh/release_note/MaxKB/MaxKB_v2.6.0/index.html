MaxKB v2.6.0

小版本 发布时间2026年2月5日 来源1Panel-dev/MaxKB 英文原文

MaxKB v2.6.0

新功能

  • Agent：增加触发激活能力；
  • Agent (X-Pack)：支持设置Agent API Keys的有效期；
  • 代理：在对话日志列表中添加IP地址和来源属性；
  • Agent：支持对会话日志中上传的文件设置独立的清理策略；
  • 工具：添加了触发激活功能；
  • 工具：新增查看执行记录功能；
  • 共享工具（X-Pack）：新增查看执行记录功能；
  • 触发器：为工作区管理员角色添加触发器管理功能；
  • 知识库：通用知识库、网站知识库、飞书知识库均支持直接转换为工作流知识库；
  • 知识库：新增支持文档列表中批量导出文档；
  • 系统管理（X-Pack）：支持设置系统API密钥的有效期。

功能优化

  • 特工：调整了转到对话按钮在特工面板的位置；
  • 代理：为用户输入的日期类型参数的默认值添加了当前时刻设置；设置后，该参数动态获取问答页面当前时间；
  • 模型：阿里云百联视频模型和语音识别模型支持输入API URL参数；
  • 模型：火山引擎提供商的矢量模型支持与多模态矢量模型对接；
  • 模型：火山引擎提供商的语音识别模型支持音频文件语音识别的对接方式；
  • 模型：添加了对在OpenAI提供商的图像生成模型的模型参数中设置响应类型参数（例如response_format=b64_json）的支持；第4538章
  • 系统：优化国际化文案和部分UI界面。

错误修复

  • 代理：修复了导出对话日志时缺少参考段计数和段标题+内容字段的问题；
  • 代理：修复了AI模型调用工具时，如果技能中的工具没有输入参数，则不显示调用过程的问题；
  • 代理：修复了当循环体中的子代理同时存在循环节点时，AI 回复内容混乱的问题 (#4654)；
  • Agent：修复Agent调试时AI回复内容没有自动滚动到底部的问题（#4660）；
  • 登录认证（X-Pack）：修复验证码登录失败次数无法设置为0的问题；
  • 模型：修复科大讯飞 Spark slm 语音识别模型无法将语音转换为文本的问题；
  • 模型：修复了编辑讯飞Spark的iat模型时出错的问题；
  • 文件夹：修复了仅具有文件夹查看权限的用户仍可以创建子文件夹的问题 (#4688)。
