MaxKB v2.10.6-lts

修订 发布时间2026年9月3日 来源1Panel-dev/MaxKB 英文原文

MaxKB v2.10.6-lts

安全漏洞修复

  • 安全性：修复了一个安全漏洞，其中聊天文件上传可能会欺骗应用程序属性并被匿名读取，从而允许将内容注入到应用程序命名空间中。
  • 安全性：修复了文档/段落迁移仅验证源知识库权限的安全漏洞，导致跨租户内容注入和 RAG 中毒。
  • 安全性：修复了 XLSX 嵌入式图像解压缩缺乏像素计数限制的安全漏洞，允许经过身份验证的用户触发内存耗尽拒绝服务 (DoS)。
  • 安全性：修复了问题/batch_association 缺乏所有权验证的安全漏洞，导致跨租户段落内容泄露 (IDOR)。
  • 安全性：修复了匿名应用程序配置文件端点过度序列化数据、导致敏感配置泄露的安全漏洞（/chat/api/application/profile）。
  • 安全性：修复了密码重置验证码端点缺乏猜测尝试限制、允许未经授权的帐户接管的安全漏洞。
  • 安全性：修复了函数库沙箱可被绕过的安全漏洞（dlopen 堆栈检查可绕过 + dlsym(RTLD_NEXT) 未被拦截）(CVE-2026-79919)。
  • 安全性：修复了一个安全漏洞，其中 Python 对文件描述符形式 os.execve(fd,…) 的支持可被利用进入 libc fexecve 调用路径，导致沙箱绕过 (NVDB-CAIVD-2026208648)。
  • 安全性：修复了一个安全漏洞，该漏洞导致来宾会话所有权验证缺失，导致跨来宾会话写入（会话完整性违规）。
  • 安全性：修复了一个安全漏洞，其中默认硬编码的 Django SECRET_KEY 允许离线伪造签名令牌，从而导致未经授权的文件访问。

新功能

  • 工作流程默认模型设置 在 MaxKB v2.10.6 LTS 社区版中，为代理工作流、知识库工作流和工作流工具引入了工作流默认模型设置。此前，多AI节点工作流程需要单独打开每个节点来修改模型配置，相对繁琐。现在，单一配置全局生效，大幅降低维护成本，提高批量模型切换的一致性和效率。默认模型设置的核心功能包括：
  • 工作流级别的默认模型配置条目；
  • 新创建的节点自动继承默认模型；
  • 节点支持灵活的模型选择模式（默认/自定义/参考变量，取决于节点类型）；
  • 一台click即可将默认模型应用于所有节点，将所有节点的模型源统一切换为默认模型；
  • 对默认模型的单次更改会在多个节点上生效；
  • 发布前确保配置完整性。
  • 腾讯混元和腾讯云提供商合并为新的“腾讯云”提供商（与腾讯云TokenHub集成） 由于腾讯云调整，在MaxKB v2.10.6 LTS社区版中，腾讯混元和腾讯云提供商合并为新的“腾讯云”提供商。之前基于腾讯混元或传统腾讯云提供商集成配置的所有型号在升级后将不再可用。升级后，请进入“模型提供商”页面，在提供商列表中选择“腾讯云”，并根据TokenHub集成要求重新配置您的模型接入信息。配置完成后，这些模型将再次可用。 功能优化
  • 知识库：知识库/文档列表选择器现在支持迁移文档/段落时的搜索。
  • 代理：用户输入区域的知识库组件现在支持搜索。
  • 代理：在对话日志页面的“添加到知识库”功能中，知识库和文档列表选择器现在支持搜索。

错误修复

  • 知识库：修复了导入单元格内容过大的 CSV 文件导致读取空和后端出现“字段大于字段限制 (131072)”错误的问题 (#6756)。
  • 知识库：修复了在未识别数据边界的情况下导入 Excel 电子表格导致导入大量空列，导致导入超时的问题 (#6355)。
  • 知识库：修复了命中测试时全文搜索中输入33个连续“-”字符导致搜索错误的问题。
  • Agent：修复了输出内容包含空字符（\u0000、\x00 等）时对话出错的问题 (#6722)。
  • Agent：修复了使用 Ascend MindIE 大模型时高级 Agent 中的 AI 节点无法接收之前节点传递的数据的问题 (#6681)。
  • Agent：修复了高级编排 AI 节点的“角色设置”为空时调用模型出错的问题 (#6662)。
  • Agent：修复了调用工具后，工具执行记录中显示的执行源显示工具名称而不是代理名称的问题 (#6647)。
  • Agent：修复了上传到工作流知识库的文件为临时文件，导致文件清理后预览和下载失败的问题（#6785）。
  • 代理：修复了用作AI对话节点技能的代理无法传递消息以外的参数的问题。
  • 代理：修复了高级代理中将用户输入参数的组件类型更改为知识库后无法设置默认知识库的问题。
  • Agent：修复了清除聊天记录时出错的问题（#6690）。
  • 模型：修复了MiniMax H3文字转视频模型集成成功后使用过程中报错的问题。
