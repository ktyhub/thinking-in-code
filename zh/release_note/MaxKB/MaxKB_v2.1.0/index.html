MaxKB v2.1.0

小版本 发布时间2025年9月4日 来源1Panel-dev/MaxKB 英文原文

MaxKB v2.1.0

#Release Notes

新功能

  • 工具：新增MCP工具管理功能。
  • 应用：新增AI对话节点的工具设置；用户选择自定义工具后，模型可以独立决定是否调用配置的工具。
  • 应用：表单集合节点的参数现在支持变量引用。
  • 应用：新增多行文本框、文件上传、单行多选框组件，形成集合节点。
  • 应用（X-Pack）：应用接入现支持连接企业微信智能机器人，让用户实现AI能力与企业微信办公生态的高效联动。
  • 应用程序（X-Pack）：在显示设置中添加了“显示历史记录”选项。
  • 问答页面：问答页面支持将当前对话记录导出为PDF和PNG图像格式。
  • 知识库：通用知识库和飞书知识库中的文档新增“允许在知识源下载”设置选项。
  • 资源授权：新增资源级授权功能，支持应用、知识库、工具、模型等核心资源对指定用户的授权。
  • 资源授权：系统管理中按用户对资源进行授权时，可以为每个资源设置不同的权限。
  • 模型：向 vLLM 提供商添加了对重新排序模型和语音识别模型的支持。
  • 模型：向腾讯混元提供商添加了对语音识别模型的支持。
  • 模型：科大讯飞 Spark 提供商的语音识别模型增加了对中文语音大模型的支持。
  • 模型：在阿里云百联提供商的语音识别模型中添加了对 qwen-omni-turbo、qwen2.5-omni-7b 和 ASR 模型的支持。
  • 模型：向百度千帆大模型提供商添加了对 API 版本 V2 连接方法的支持。

增强功能

  • 应用：新增用户在通话记录列表中查询的功能。
  • 应用程序（X-Pack）：应用程序连接 Lark 后，AI 回复内容以 Markdown 格式显示。
  • 问答页面：进入问答页面时默认自动创建新对话。
  • 问答页面：优化上传文件或图片时自动生成默认问题的问题。
  • 工具：cli在创建或编辑工具时点击“关闭”或“取消”按钮时添加了二次确认提示。
  • 登录：用户登录系统后必须更改默认密码才能继续使用系统。

错误修复

  • 应用程序：修复了高级编排应用程序中的MCP节点未国际化的问题。
  • 应用程序：修复了在表单收集节点之后使用会话变量时无法读取的问题。
  • 问答页面（X-Pack）：修复了浏览器选项卡中未显示自定义应用程序徽标的问题。
  • 问答页面（X-Pack）：修复了在“访问限制”功能中切换应用程序身份认证方式时，现有认证信息仍然有效的问题。
  • 问答页面：修复了cli点击左侧导航区“折叠”按钮时内容显示样式混乱的问题。
  • 问答页面：修复了会话用户重新登录后提问时出现“缺少参数”提示的问题。
  • 问答页面：修复加载历史记录数据时，对话记录区域不显示对话记录的问题。
  • 问答页面：修复了上传空文件导致提取错误的问题。
  • 问答页面：修复了快问内容过长时标签显示异常的问题。
  • 知识库：修复系统无License授权时命中测试界面输入框显示不完整的问题。
  • 知识库：修复cli文档上传到知识库时点击“返回”按钮没有二次确认的问题。
  • 知识库：修复了在知识库细分详情中按细分内容搜索时搜索结果不正确的问题。
  • 知识库：修复了同一细分可能多次与同一问题关联的问题。
  • 知识库：修复了问题列表中“关联段数”计数不正确的问题。
  • 模型：修复了“所有模型”列表中的模型未按创建时间降序显示的问题。
  • 资源授权：修复了只有知识库查看权限的用户可以在对话日志中添加片段的问题。
  • 文件夹：修复了cli在应用程序和知识库的资源详细信息中点击“返回”按钮始终返回到根目录的问题。
  • 对话用户（X-Pack）：修复同步系统用户时用户密码不同步的问题。
  • 对话用户（X-Pack）：修复了即使不设置用户组也能成功创建新对话用户的问题。
