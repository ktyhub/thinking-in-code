MaxKB v2.3.0

小版本 发布时间2025年11月3日 来源1Panel-dev/MaxKB 英文原文

MaxKB v2.3.0

新功能

  • 知识库：新增“标签管理”功能；
  • 知识库：为知识库中的文档添加“标签设置”功能；
  • 知识库：通用知识库新增“替换原文档”功能；
  • 应用程序：在高级编排应用程序中添加了“文档标签检索”节点；
  • 应用程序：在高级编排应用程序中添加了“视频理解”节点；
  • 应用程序：在高级编排应用程序中添加了“变量拆分”节点；
  • 应用程序：向高级编排应用程序添加了“变量聚合”节点；
  • 应用程序：在高级编排应用程序中添加了“参数提取”节点；
  • 应用程序：在文件上传设置中添加了“视频”文件类型选项；
  • 应用：Judge节点新增“startwith”和“endwith”判断条件；
  • 应用：AI对话节点输出参数新增“历史聊天记录{history}”参数；
  • 应用：知识库检索节点添加了两个检索范围选项（手动选择知识库和变量引用）；
  • 资源授权：支持按用户对文件夹资源进行授权；
  • 资源授权：支持对工作区中的应用程序、知识库、工具进行基于文件夹的资源授权；
  • 系统管理（X-Pack）：新增操作日志清理策略，帮助管理员高效管理日志数据。

功能优化

  • 应用程序（X-Pack）：应用程序连接企业微信、飞书、钉钉后支持用户免密登录；
  • 应用程序：文件上传支持的视频文件类型；
  • 应用：新增对图像理解、图像转视频、视频理解节点的“选择文件”参数的URL地址设置支持；
  • 应用：允许变量赋值节点用作端节点；
  • 应用：支持在工作流编排页面批量选择节点；
  • 应用：接口参数添加描述字段；
  • 应用程序：将“访问限制”中“每个Client的问题限制”选项的最大值调整为每天1000万次；
  • 应用程序：在表单集合节点中添加了对多选框组件的自定义输入支持；
  • Applications：显示根目录下当前工作区的所有应用程序，并支持全局搜索；
  • 工具：在根目录下显示当前工作区的所有工具，并支持全局搜索；
  • 工具：增加了对自定义类型参数的变量解析支持；
  • 知识库：在根目录下显示当前工作区的所有知识库，并支持全局搜索；
  • 角色：调整了普通用户角色的“关于”权限；
  • 模型：添加了对矢量模型的模型参数设置支持。

错误修复

  • 应用程序：修复导出应用程序时循环体中的工具节点未导出的问题；
  • 应用：修复循环体中Form Collection节点之后的节点无法输出循环变量的问题；
  • 应用：修复MCP Call节点中修改第二个参数内容时，第一个参数内容被清除的问题；
  • 应用：修复了使用智普大语言模型并在AI对话节点启用工具功能时对话中Token显示为0的问题；
  • 应用程序（X-Pack）：修复显示设置中历史记录设置选项不生效的问题（#4201）；
  • 问答页面：修复了cli上传文件并在问答页面提问后点击“获取另一个答案”按钮时上传文件丢失的问题（#4180）；
  • 问答页面：修复了在问答页面提问时调整对话窗口大小时对话记录丢失的问题（#4202）。
