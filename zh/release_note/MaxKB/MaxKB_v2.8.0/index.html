MaxKB v2.8.0

小版本 发布时间2026年4月10日 来源1Panel-dev/MaxKB 英文原文

MaxKB v2.8.0

新功能

  • 工具：新增工作流类型工具；
  • 工具：支持自动生成Python代码；
  • 知识库：支持导入导出知识库所有元数据；
  • Agent：支持对话过程中选择模型和知识库；
  • 代理：支持批量选择移动到其他文件夹或进行批量删除；
  • 代理：在高级代理中添加了“图像理解”和“视频理解”节点的思维过程切换设置；
  • 知识库：支持批量选择移动到其他文件夹或进行批量删除；
  • 工具：支持批量选择移动到其他文件夹或进行批量删除；
  • 模型：添加了对来自百度千帆提供商的模型重新排名的支持（#4927）；
  • 系统：统一系统中所有用户名显示字段，显示用户的全名；
  • 代理：高级代理中的“变量聚合”节点现在支持聚合为字典类型变量（#4904）；
  • 代理：优化了高级代理中“变量拆分”节点的拆分表达式组件（#4961）。

错误修复

  • Agent：修复了在 AI Conversation 节点中使用带有系统提示和 Skills/MCP 工具的 vLLM 模型时用户提问的错误；
  • Agent：修复了vLLM模型与推理场不兼容的问题；
  • Agent：修复了使用文档标签检索节点时错误的检索结果（#4942）；
  • Agent：修复高级编排中循环节点折叠状态未保存的问题（#4996）；
  • Agent：修复了图像理解节点在多回合对话过程中中途未发送图像然后再次发送时出现的错误（#4999）；
  • Agent：修复了使用 ECharts 时的空白渲染问题（#4966）；
  • 代理（X-Pack）：修复了从MaxKB对话日志下载后，通过企业微信发送的图片无法打开的问题；
  • 座席（X-Pack）：修复高级座席中启用子座席身份认证后，通话过程中不进行身份验证的问题；
  • 知识库：修复了网站知识库中“允许在知识源中预览”的不准确描述；
  • 模型：修复了阿里云百联重排模型超出代币限制或余额不足时丢失的错误消息（#4928）；
  • 模型（X-Pack）：修复普通用户click共享模型时的权限错误；
  • 角色（X-Pack）：修复了为普通用户自定义“关于”权限时自动检查其他权限的问题（#4954）；
  • 资源管理（X-Pack）：修复资源管理中授权资源时不显示用户角色的问题。

安全漏洞修复

  • 安全：修复了通过 socket.sendto()+MSG_FASTOPEN 绕过沙箱 connect() 挂钩的 SSRF 漏洞，以防止访问内部受限服务 (#CVE-2026-39418)；
  • 安全：修复了通过 env -i LD_PRELOAD 清除环境变量进行沙箱逃逸的远程代码执行漏洞 (#CVE-2026-39420)；
  • 安全：修复了通过 sys.exit(0) 进行结果欺骗的沙箱绕过漏洞，以绕过沙箱结果验证 (#CVE-2026-39419)；
  • 安全：修复了通过 ctypes 和脱钩 SYS_pkey_mprotect 进行沙箱逃逸的关键远程代码执行漏洞 (#CVE-2026-39421)；
  • 安全：修复了由于缺少 MCP 服务器配置验证而导致通过恶意配置进行 Shell 命令注入的远程代码执行漏洞（#CVE-2026-39417）；
  • 安全：修复了一般存储型跨站脚本（XSS）漏洞，并加强了所有场景下的用户输入安全验证（#CVE-2026-39422）；
  • 安全：修复了 iframe_render 中由未经过滤的用户输入引起的存储 XSS 漏洞（#CVE-2026-39426）；
  • 安全：修复了由于未过滤的 HTML 标签而导致 Markdown 渲染 html_rander 中存储的 XSS 漏洞（#CVE-2026-39425）；
  • 安全：通过 Eval 恶意代码注入修复了 echarts_rander 组件中存储的 XSS 漏洞（#CVE-2026-39423）；
  • 安全：修复了将应用程序聊天日志导出到 CSV（CVE-2025-4546 的变体）时未转义的特殊字符导致的 CSV 注入漏洞 (#CVE-2026-39424)。
