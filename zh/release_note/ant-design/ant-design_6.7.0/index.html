ant-design 6.7.0

小版本 发布时间2026年11月4日 来源ant-design/ant-design 英文原文

ant-design 6.7.0

  • 🆕 添加对全局 ConfigProvider variant 的按钮、标签、步骤、警报和时间线支持，以及分隔线样式的特定于组件的 divider.variant 配置。 #59589 #59588 #59578 #59577 #59587 #59576 @QDyanbing
  • 🆕 DatePicker、TimePicker、Select、AutoComplete、Cascader、TreeSelect 新增 suffix 来自定义后缀内容，并为选择组件提供基于状态的渲染。弃用 suffixIcon，转而使用 suffix，同时保留兼容性。 #59240 #59185 @QDyanbing @meet-student
  • 🆕 将 allowClear.tabIndex 添加到 Input、Input.TextArea、Mentions、InputNumber、Select、AutoComplete、TreeSelect、Cascader、DatePicker 和 TimePicker 以控制清除按钮 Tab 顺序。将 allowClear.label 添加到 Input、Input.TextArea、Mentions、DatePicker 和 TimePicker，以获得可访问的清除按钮名称，并具有字段级 ConfigProvider 继承。 #59566 #59567 #59548 @QDyanbing
  • 🆕 在 React 19.3 及更高版本中添加应用程序片段 ref 对 component={false} 的支持。 #59281 @li-jia-nan
  • 🆕 添加 BorderBeam items 属性来配置每个光束的 color、lineWidth、outset 和 size，阵列长度决定光束数量。 #59095 @QDyanbing
  • 🆕 新增 Cascader checkStrictly 在多种模式下独立选择父子选项。 #59566 @QDyanbing
  • 🆕 为 Cascader、TreeSelect 和 AutoComplete 添加组件特定的 ConfigProvider allowClear 设置，以全局配置其清除按钮。 #59593 #59592 #59591 @QDyanbing
  • 🆕 添加 Checkbox.Group 和 Radio.Group classNames 和 styles 以自定义组容器、项目、图标和标签。 #59058 #59059 @QDyanbing
  • 🆕 添加 InputNumber allowClear 和 onClear 以通过可自定义图标、禁用状态和可访问标签清除值。 #59251 @nikzanda
  • 🆕 添加 Space align="stretch" 以沿横轴拉伸子元素。 #59005 @dogledogle
  • 🆕 为闪烁动画文本添加 Typography shimmer 道具，并使用 duration 单独配置运动和等待时间。 #59054 @zombieJ
  • 🛠 对齐 Input、Input.TextArea、Mentions、InputNumber、Select、AutoComplete、TreeSelect、Cascader、DatePicker 和 TimePicker allowClear.disabled 行为，以便 true 删除与 allowClear={false} 一致的清除按钮。 #59548 #59566 #59567 @QDyanbing
  • 💄 将 Alert 容器半径组件代币 borderRadius 替换为 containerBorderRadius；将自定义容器半径覆盖迁移到新令牌。 #59305 @MadCcc
  • 日期选择器
    • 🆕 添加 DatePicker 和 TimePicker components.nowButton 和 components.okButton 独立自定义今天/现在和确认按钮。弃用旧版 components.button，同时保留兼容性。 #59778 @yoyo837
    • ⌨️ 改进 DatePicker 和 TimePicker 键盘和屏幕阅读器支持，包括箭头键导航、Enter/Space 选择和跳过禁用的时间选项，以及今天/现在页脚按钮的键盘激活和本机禁用状态。 #59778 #59367 @yoyo837
  • 🐞 修复 DatePicker 和 TimePicker 当 allowClear 对象省略 clearIcon 时忽略 clearIcon 设置的问题。 #59565 @QDyanbing
    • 🐞 修复原生 Node ESM 环境中的 DatePicker、TimePicker 和 Calendar 依赖项导入。 #59261 @zombieJ
    • 🐞 修复当组件语言环境与全局语言环境不同时 DatePicker 使用 Day.js 解析本地化日期输入的问题。 #59240 @QDyanbing
    • 🌐 修正 DatePicker zh_TW 周选择术语。 #59261 @zombieJ
  • 选择
    • 🆕 添加 Select autoComplete 和 ConfigProvider select.autoComplete 到配置
