crush v0.101.0

#粉碎v0.101.0

技能切换、工具计时器和更快的 Hyper ⚡

此版本是由我们的团队和我们最喜欢的贡献者为您带来的！期待已久的功能即将推出，请继续阅读！

切换技能

现在可以直接从命令面板打开和关闭技能。损坏的技能也很容易被发现！ （它们标有红色×以及失败的原因）

🕐 这需要多长时间？

现在每个工具调用都会显示它已经运行了多长时间。现在，您将知道该测试套件是否只是缓慢或实际上卡住了。

更轻、更快 Hyper ⚡

对 Hyper 的请求现在使用 Brotli 🥦 进行压缩。这意味着每次上传的上传量要小得多，响应速度要快，尤其是在长时间的会话中。 Hyper 现在还支持 Gzip，当 Brotli 不可行时，其他代理可以使用它。

非常感谢@BrunoKrugel 提供的前 2 个很棒的功能！

验证工件

首先，下载checksums.txt文件和checksums.txt.sigstore.json文件文件，例如，wget：

wget 'https://github.com/charmbracelet/crush/releases/download/v0.101.0/checksums.txt'
wget 'https://github.com/charmbracelet/crush/releases/download/v0.101.0/checksums.txt.sigstore.json'

然后，使用 cosign 进行验证：

cosign verify-blob \
  --certificate-identity-regexp '^https://github.com/charmbracelet/crush/\.github/workflows/(release|nightly)\.yml@' \
  --certificate-oidc-issuer 'https://token.actions.githubusercontent.com' \
  --bundle 'checksums.txt.sigstore.json' \
  ./checksums.txt

如果输出是 Verified OK，您可以安全地使用它来验证使用 sha256sum 从版本下载的其他工件的校验和：

sha256sum --ignore-missing -c checksums.txt

完成！您的文物现已得到验证！
