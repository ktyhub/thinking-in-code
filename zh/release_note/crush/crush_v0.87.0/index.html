crush v0.87.0

MCP OAuth、性能等

大家周五快乐！ 我们正在为您发布一些不错的功能，以便您可以享受周末的振动编码。 （或者不，留在外面：sun_with_face：并在周一返回 Crush！：smiley：）。

MCP OAuth

就是这样，终于来了！你们中的一些人长期以来一直在要求这个。 这是某些 MCP 工作所必需的。想知道如何设置吗？ 请参阅自述文件中的此部分。 感谢@joestump 和他的经纪人@joestump-agent 的贡献。当然，我们最喜欢的@taciturnaxolotl 也提供了帮助。

Claude Channels MCP 扩展

@joestump（和他的代理）_还_添加了一个初始实现来支持 Claude Channels MCP 扩展，这意味着 MCP 现在可以在发生某些事件时向 Crush 发送通知。 如果您有兴趣，请尝试一下，并让我们知道它对您的效果如何。

恢复 MCP 提示

MCP 提示在之前的版本中被无意中禁用，但现在又重新添加了！

LSP 性能提升

另一个很酷的贡献是由 @TheJhyeFactor 做出的，他极大地提高了处理大型存储库中的 LSP 服务器时的 CPU 和内存使用率！ 有关优化的更深入说明，请参阅#3370。

Bang 模式性能提升

@TheJhyeFactor_还_改进了在 bang 模式下运行命令时输出流的性能。 检查 #3381 查看一些基准测试。

/etc/crush/crush.json

你没看错！感谢@Muttaqin86，您现在可以在 /etc/crush/crush.json 上拥有系统范围的 Crush 配置。 这样做的动机是提高与 NixOS 的兼容性。

固定副驾驶 + GPT-5.6

现在，通过 GitHub Copilot 运行时，所有三个 GPT-5.6 模型（Sol、Terra 和 Luna）均已修复。感谢@nghiant03！ 虽然数量很多，但社区与 Crush 开发者的互动确实很有趣。 继续碾压！ :tm: 魅力
