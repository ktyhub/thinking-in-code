crush v0.88.0

#.crushrc 来了！ 嘿！希望大家度过了愉快的一周。我们在 Charm 的工作效率非常高，今天我们发布了一些很酷的东西。

bash 配置！ (.crushrc)

是的，.crushrc来了！您现有的 JSON 配置仍然有效，但我们刚刚开始迁移到更灵活的配置！ 举个例子来说明为什么这很酷：如果您在 dotfiles 存储库中管理 Crush 配置，您仍然可以通过使用 source 调用 .gitignore 中的单独文件来进行特定于计算机的覆盖。我确信还有很多其他用例。 要阅读有关此内容的完整文档，请阅读本文档。 查看截图，以便您了解它的外观：

# Add Ollama.
provider add ollama --type ollama --base-url "http://localhost:11434/v1"

# Register a model on Ollama.
model add ollama/llama3.3 --name "Llama 3.3" --context-window 128000

# Auto-approve some tools.
permissions allow view edit

# Add an MCP server
mcp add github \
  --type http \
  --url "https://api.githubcopilot.com/mcp/" \
  --header Authorization "Bearer $GITHUB_TOKEN"

# Load some extra config
source "$XDG_CONFIG_HOME/squid-config.sh"

# Change config based on the machine you're on.
if [[ $HOSTNAME == "babysquid" ]]; then
    option skill-path "$HOME/squid-skills"
fi

想提供反馈吗？加入 Discord 上的 #crush 频道。

更好的 AWS Bedrock SSO 支持

@jan-xyz 做得很好，让这个变得栩栩如生！ 通过 SSO 使用 AWS Bedrock 时，令牌会随着时间的推移而过期，需要刷新。 Crush 现在具有用于身份验证的正确配置和用户体验，并且每当需要刷新令牌时它就会出现。 要了解更多相关信息，请参阅#2886。

更可靠的代理获取

@sven2718 在第一次尝试不起作用时提供了更好的搜索重试。现在搜索将更加可靠，特别是在短时间内进行多次搜索时。

神鬼寓言 5 的修复

@sven2718 还贡献了《神鬼寓言 5》的修复程序。当 Anthropic 出于安全原因决定拒绝您的提示时，我们现在会在 Crush 中显示正确的错误消息。以前，Crush 会直接停止，而不给出原因。

Crush 现在可以在 IlluminOS 上编译

从未听说过 IllumiOS？我们 Charm 中的任何人都没有，但 @timotheosh 调整了代码以确保它现在可以在那里编译！ Go 可以编译到许多环境，看到 Crush 在更多操作系统上运行总是很有趣！顺便问一下，您知道可以在 Android 上使用 Crush 吗？ ：机器人：

增强型 MCP OAuth

在上一个版本中，我们提供了对 MCP 的 OAuth 身份验证的支持。 @BrunoKrugel 进行了一些修复，以使更多需要 OAuth 的 MCP 按预期工作。

代理修复

作为代理的 Crush 也进行了相当多的修复。其中一些是在 Fantasy 上制作并带到 Crush 中的。

新的超级模型

同样重要的是，我们不断对 Hyper 进行更新，它比以往更加稳定，并且现在提供 Minimax M3 和 Qwen3.7-Flash。

这周发生了很多事！我们希望您喜欢，并继续粉碎:tm:！ 魅力
