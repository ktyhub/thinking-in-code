crush v0.100.0

#粉碎v0.100.0

子代理、系统管理模式和 PGP/SSH 提示

这是一件大事！ Crush 现在可以运行一组子代理，权限更加灵活，您现在可以在 Crush 中进行 GPG 和 SSH 身份验证！请继续阅读以了解更多信息。

👩🏼‍🐰‍👩🏽 子代理

最后是分代理。 Crush 现在可以在后台生成一小队友好的子代理，并检查他们、向他们发送中期跟进、阻止他们或将他们转移到不同的模型。

您可以在文字记录、侧边栏和标题中观看它们的工作情况。每个子代理也有自己的名称，因此您始终知道谁在做什么。而且，如果您提到他们的名字，Crush 就会知道您在谈论其中的哪一个！

🚨 系统管理员模式

是否曾经希望 Crush 能够 DROP SCHEMA public CASCADE;？现在可以了，使用系统管理员模式！事实上，在系统管理员模式下，Crush 可以在您的系统上运行任何命令。当心。

在命令面板 (ctrl+p) 中查找系统管理模式，或使用 shift+tab 在所有模式之间切换。

🙅🏻‍♀️ 安全命令

当然，Yolo 模式仍然会阻止危险命令，但现在哪些命令是危险的由您决定。

  • permissions safe 标记命令对于 yolo 来说是安全的
  • permissions block 完全阻止命令
  • permissions unblock 解锁受限命令
# Building is fine
permissions safe "go build" "cargo check"

# Don't touch my infra please
permissions block kubectl terraform

# Curl your heart out
permissions unblock curl

🗝️ PGP 和 SSH

当你使用AI代理时，无法输入SSH密码、激活Yubikey并输入GPG密码，这太烦人了，是吗？嗯，有了 Crush，这种烦恼就成为过去了。

使用人工智能时，您的安全不会再受到影响！
