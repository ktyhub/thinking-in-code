crush v0.86.0

LSP 工具、可滚动侧边栏、可移动附件等等

嘿大家。我们将通过运送一些 LSP 物品和更多好东西来开始新的一周。

全新的 LSP 工具

这些新的 LSP 工具将允许模型更准确地进行一些重构：

  • lsp_rename - 重命名项目中的符号及其所有引用
  • lsp_replace_symbol - 按名称替换、插入之前/之后或删除整个函数/方法/类 如果某些功能未按 LSP 的预期工作，请不要担心。我们将向模型报告错误，以便它可以回退到使用 edit 工具。

可滚动侧边栏

这个非常酷。侧边栏空间不足？别担心，您现在可以滚动其内容！

键盘： * 当聚焦于聊天视图时：l 或 右箭头 聚焦于侧边栏 * j/k 或 向上/向下箭头 上下滚动 * g 滚动到顶部 shift+g 滚动到底部 * h 或 左箭头 重新聚焦到聊天视图 * tab 总是将焦点返回到编辑器 ## 可拆卸附件 现在可以用鼠标删除附件了！只需按 `X` 按钮上的 click 即可： ## 更好的超级 OAuth 在 [Charm Hyper ™️](https://hyper.charm.land/) 或 GitHub Copilot 上进行身份验证时，您现在可以按 u 复制 URL。这在某些情况下是必需的，例如通过 SSH 使用 Crush 时，可能无法自动打开浏览器。 ## 退出对话框提示 当渲染退出对话框时，我们现在显示一个提示，只需按两次 ctrl+c 即可完全跳过确认。 ## 代理修复 * 推理努力级别 `none`
