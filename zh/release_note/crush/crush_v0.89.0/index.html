crush v0.89.0

一些生活质量好东西

我们正在为您发布一些生活质量增强功能:tm:。它们很简单，但这些简单的改进随着时间的推移，使 Crush 变得越来越好。

退出 Crush 的提示

退出 Crush 时，您会看到一个启动屏幕，其中显示如何快速继续您离开的会话。

Bash 工具语法高亮

当使用 Bash 工具显示 Crush 正在运行的内容时，shell 命令现在将具有语法突出显示功能。这是一个很小的补充，但绝对提高了易读性。

哞哞：牛：

ctrl+end 跳转到底部+follow

如果您想快速跳转到聊天底部，现在只需按 ctrl+end 即可。这也将确保 Crush 在新消息到达时能够跟踪聊天。

MCP 改进

我们增强了一些功能，使其更加稳定，并修复了一些边缘情况的错误。 这就是今天的全部内容。下一个版本再见！ 魅力💌
