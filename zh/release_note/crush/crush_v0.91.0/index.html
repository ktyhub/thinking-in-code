crush v0.91.0

文本选择和更好的鼠标支持

只是对周末的提示编辑器和会话选择器进行了一些生活质量改进！

文本选择

按住 shift 并使用箭头键或 click 并用鼠标拖动以选择提示编辑器中的文本。从那里，您可以使用任何新奇的快捷方式👀

  • ctrl+shift+a 选择所有内容
  • ctrl+shift+c 复制所选内容
  • ctrl+shift+x 剪切选区
  • ctrl+shift+v 粘贴文本 键入或粘贴所选文本会将其替换。

## 会话选择器中的鼠标支持 我们已经在会话选择器中缺少鼠标支持太久了！现在，您可以使用鼠标滚轮滚动浏览会话，click 条目以选择它，或双击 click 将其打开。 ## Windows 的一个小修复 在 Windows 上，单独按修饰键可能会将某些对话框发送回顶部。他们现在应该留在原地。 继续碾压！ 魅力💌 ## Changelog ### 新！ * 08552fb918a3b6247c2f8366d330f3b7f02fc891：壮举：文本区域选择（＃3507）（@andrinoff） * 90bc466d6f35b120070b6fd8a73f4262f155086a：会话选择器：添加鼠标支持（@Amolith） ### 已修复 * 8661a1c4baa171f49b6f7ab3d4db7836cf5b5548：修复（Windows）：仅在修饰键上向上滚动（＃3598）（@andrinoff） ### 其他东西 * 37f36e93824e5c4f892e4a817f7f628e2682fe14：杂务：自动更新文件（@charmcli） * 7d78d7422a92918441a68d01d96d48fa3b9fd9db：杂务：标准化 v1.26.6 上的 go 工具链（#3592）（@aleksclark） --- <详情> 验证工件 首先，下载[`checksums.txt`文件](https://github.com/charmbracelet/crush/releases/download/v0.91.0/checksums.txt)和[`checksums.txt.sigstore.json`文件](https://github.com/charmbracelet/crush/releases/download/v0.91.0/checksums.txt.sigstore.json)文件，例如`wget`： ```bash wget 'https://github.com/charmbracelet/crush/releases/download/v0.91.0/checksums.txt' wget 'https://github.com/charmbracelet/crush/releases/download/v0.91.0/checksums.txt.sigstore.json' ``` 然后，使用 [`cosign`](https://github.com/sigstore/cosign) 进行验证： ```bash cosign verify-blob \ --certificate-identity 'https://github.com/charmbracelet/meta/.github/workflows/goreleaser.yml@refs/heads/main' \ --certificate-oidc-issuer 'https://token.actions.githubusercontent.com' \ --bundle 'checksums.txt.sigstore.json' \ ./checksums.txt ``` 如果输出是 `Verified OK`，您可以安全地使用它来验证使用 `sha256sum` 从版本下载的其他工件的校验和： ```bash sha256sum --ignore-missing -c checksums.txt ``` 完成！您的文物现已得到验证！ 想法？问题？我们很高兴收到您的来信。请随时联系 [X](https://x.com/charmcli)、[Discord](https://charm.land/discord)、[Slack](https://charm.land/slack)、[The Fediverse](https://mastodon.social/@charmcli)、[Bluesky](https://bsky.app/profile/charm.land)。
