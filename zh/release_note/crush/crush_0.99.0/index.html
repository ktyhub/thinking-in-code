crush v0.99.0

#粉碎v0.99.0

Hooks，T台v3！

好大一个！ Crush 现在在 Catwalk v3 上运行，Hooks 可以看到运行的每个部分，托管 Crush 的编辑可以获得一套全新的工具，让他们感觉宾至如归。

钩子，无处不在🪝

Hook 不再只是工具。他们现在可以跟踪整个跑步过程：会话、回合、权限等等！

Hooks 现在也可以在工具运行后介入。在模型看到它们之前编辑输出中的秘密、添加注释或停止转动。如果该工具已经做了不应该做的事情，您的钩子可以告诉模型“您在没有运行测试的情况下提交了”。

hook add TurnEnd --name "ding" --command 'afplay /System/Library/Sounds/Glass.aiff'

您可以在[此处]阅读更多信息(https://github.com/charmbracelet/crush/tree/main/docs/hooks#readme)

Client/服务器模式

如果您构建了在其中运行 Crush 的东西，那么此版本适合您：

  • 主机主题：主机应用程序可以通过服务器 API 主题化 TUI，因此 Crush 与您的应用程序相匹配。
  • 主机上下文：主机可以告诉 Crush 正在查看什么，例如打开的文件，以及这些文件出现在补全中。
  • 附加到下一个提示：clients 可以添加代理在下一个提示中读取的文本，而无需开始运行或扰乱聊天。
  • 共享观看：clients 可以看到其他 clients 正在观看哪个会话。
  • 管道权限：设置 CRUSH_PERMISSIONS_PIPED=1，主机会回答权限提示，因此不会询问您两次。
  • 启动服务器时，http:// 地址用作 tcp:// 的别名。

更稳定的服务器

  • SIGHUP 现在重新加载配置而不是停止服务器。
  • 关闭终端或通过服务管理器停止 Crush 现在可以正常关闭，因此可以保存正在进行的工作，而不是看起来卡住了。

[Catwalk v3][catwalk]小概述：

Crush 现在会说 [Catwalk v3][catwalk]。提供商 type 描述了提供商使用的 API 格式，而不是是谁创建的：

  • completions：兼容 OpenAI 的 API
  • responses：OpenAI，或通过它路由的任何东西
  • messages：人类兼容的 API

您的配置在加载时会自动迁移，因此 openai、openai-compat 和 anthropic 可以继续工作。无需编辑。

provider add 和 model add 标志如下：

crush provider add deepseek \
  --type completions \
  --base-url "https://api.deepseek.com/v1" \
  --api-key "$DEEPSEEK_API_KEY"

crush model add deepseek/deepseek-chat --thinking toggleable --max-attachments 5
  • --can-reason 现在是 --thinking always|never|toggleable
  • --max-attachments N 是新的
  • 推理级别在选择器中显示友好的名称，例如“X-High”

【走秀】：https://github.com/charmbracelet/catwalk/releases/tag/v3.0.0
