crush v0.102.0

频道、自定义提示和服务器强化

此版本中有很多好东西，我们对此感到非常自豪。请继续阅读以了解更多信息。

自带提示

最后，您可以将系统提示替换为……任何您想要的内容。不仅是主代理，还提示子代理、计划、压缩、会话标题和 crush init：

option prompt coder ~/.config/crush/prompts/coder.md.tpl
option prompt summary prompts/summary.md

您可以在全局配置中设置提示，在本地配置中覆盖每个项目，或使用 --prompt name=path 覆盖提示。 有关提示的更多信息，请参阅文档。

夜间骑行

Crush 现在附带受《霹雳游侠》启发的 KITT 主题，由 @cdancy 提供。 Rosé Pine Classic、Moon 和 Dawn 现已上市。

## 书呆子与书呆子字体 最后，书呆子字体！自动检测支持，因此他们也永远不会破坏您的终端！ Crush 现在使用他们的图标、LSP 状态和 Git。请注意，如果您通过 SSH 运行 Crush，则需要启用 Nerd 字体 `option ui nerd-fonts true`。 ```bash # Hate nerd fonts? You can turn 'em off, too. option ui nerd-fonts false ``` ## 频道 [Channels](https://code.claude.com/docs/en/channels-reference) 是 Claude 的一项实验性 MCP 功能，由于 @joestump 的出色工作，现在可以在 Crush 中使用。简而言之，通道允许 MCP 服务器在事件发生时将其推送到您的会话中。 ```bash crush --channels server:webhook --channels server:signal ``` 或者在您的 `crushrc` 中永久打开一个： ```bash # crushrc mcp add webhook \ --type http \ --url https://example.com/mcp \ --channel true ``` Crush 使用与 [Claude Channels](https://code.claude.com/docs/en/channels-reference) 相同的协议，因此现有的频道服务器应该可以正常工作™。 ## 服务器加固 Client 服务器模式现在比以往任何时候都更强大。现在它更加安全，并且有大量的小改进、正确性修复和错误修复，尤其是在 Windows 上。 ## 还有更多 - 系统管理模式不再是 yolo 之前的 shift+tab。 - 排队的提示在您提交后立即显示在药丸中。 - 该型号可以使用`sudo`，因此您可以使用Touch ID进行批准。 - 内容拒绝会自动重试。 - 克劳德再次拒绝工作的会议。 - 无法调用工具的 Ollama 模型不再显示在模型列表中。 - 留下子进程的命令不再挂起。 - 计时器一起滴答作响，运行工具计时器将持续运行，直到工具回复为止。 - 切换主题不再重新渲染整个对话。 - 删除会话会保留您在列表中的位置。 - 重播的消息保留空白，并且计划卡正确排列。 祝你好运， 魅力XX🌤️ ## Changelog ### 新！ * 01780cc0384227b90071a8bbf26559410b748efc: feat(lsp): 自动使用 nerd 字体表示 LSP
