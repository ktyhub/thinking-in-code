crush v0.93.1

禁用鼠标支持+更多

嘿，你这周过得怎么样？今天我们进行了一些更改，其中大部分是修复，但也有一些不错的补充。

禁用鼠标支持

想要在 Crush 中禁用鼠标支持吗？感到幸运，因为我们最喜​​欢的贡献者@timotheosh 就添加了这一点。 通过下面的配置你可以实现这一点。也可以通过命令选项板对话框切换它。 crushrc：

option ui mouse false

crush.json：

{ "options": { "tui": { "mouse": false } } }
