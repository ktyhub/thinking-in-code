Druid 29.0.1

Apache Druid 29.0.1 是一个补丁版本，修复了 Druid 29.0.0 版本中的一些问题。

错误修复

  • 添加了 INSERT 和 REPLACE 的类型验证，以验证字符串和字符串数组没有混合 #15920
  • 并发替换 现在允许使用 Supervisor 升级挂起的 Peon 段 #15995
  • 更改了 targetDataSource 属性以返回包含数据源名称的字符串。这将恢复 Druid 29.0.0 中针对 INSERT 和 REPLACE MSQ 查询引入的重大更改 #16004 #16031
  • 减小了分布 Docker 图像的大小 #15968
  • Fixed an issue with SQL-based ingestion where string inputs, such as from CSV, TSV, or string-value fields in JSON, are ingested as null values when they are typed as LONG or BIGINT #15999
  • 修复了 Web 控制台生成的 Kafka Supervisor 规范中 flattenSpec 位于错误位置的问题 #15946
  • Fixed an issue with filters on expression virtual column indexes incorrectly considering values null in some cases for expressions which translate null values into not null values #15959
  • 修复了如果无法解析传入数据则数据加载器崩溃的问题 #15983
  • 改进了 Web 控制台中的 DOUBLE 类型检测 #15998
  • Web console-generated queries now only set the context parameter arrayIngestMode to array when you explicitly opt in to use arrays #15927
  • The web console now displays the results of an MSQ query that writes to an external destination through the EXTERN function #15969

Incompatible changes

EXPLAIN 查询中 targetDataSource 的更改

Druid 29.0.1 includes a breaking change that restores the behavior for targetDataSource to its 28.0.0 and earlier state, different from Druid 29.0.0 and only 29.0.0.在 29.0.0 中，targetDataSource 返回包含数据源名称的 JSON 对象。在所有其他版本中，targetDataSource 返回包含数据源名称的字符串。

如果您从 29.0.0 以外的任何版本升级，则行为不会发生变化。

如果您从 29.0.0 升级，则这是不兼容的更改。

#16004

Dependency updates

  • 将 PostgreSQL JDBC 驱动程序版本更新为 42.7.2 #15931
