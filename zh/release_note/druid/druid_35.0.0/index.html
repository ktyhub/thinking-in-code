druid 35.0.0

Apache Druid 35.0.0 包含超过 229 个新功能、错误修复、性能增强、文档改进以及来自 29 个贡献者的额外测试覆盖范围。

请参阅完整的更改 了解更多详细信息，包括错误修复。

在升级到 Druid 35.0.0 之前，请查看升级说明 和不兼容更改。 如果您要跨多个版本进行升级，请参阅升级说明页面，其中列出了最新 Druid 版本的升级说明。

# 重要功能、更改和弃用

本节包含有关新功能和现有功能的重要信息。

# Jetty

Druid 35 使用 Jetty 12。此更改可能会影响您的部署。更多信息请参见Jetty 12升级说明

# Java 支持

Druid 现在支持 Java 21。请注意，某些版本的 Java 21 在测试过程中遇到了问题，特别是 Java 21.05-21.07。如果可能，请避免使用这些版本。

此外，对 Java 11 的支持已被删除。升级到 Java 17 或 21。

#18424 #18624

# 预测

预测已得到改进：

  • 现在支持静态过滤器
  • 查询的粒度可以匹配UTC时区

此外，性能和可靠性也得到了普遍改进。

#18342 #18535 #18403

# 虚拟存储（实验性）

虚拟存储结构模式使历史服务器能够为比其物理磁盘所能容纳的更多的段提供服务。段不是在发布时加载，而是在查询期间按需加载。任何不需要的段都会从磁盘中删除，但在处理查询需要该特定段时会再次加载。

要启用虚拟存储，请将 druid.segmentCache.virtualStorage 设置为 true。

此功能是实验性的，有一些限制。有关更多信息，请参阅拉取请求：

#18176

# 新输入格式

Druid 现在支持 lines 输入格式。 Druid 从输入中读取每一行作为 UTF-8 文本，并创建一个名为 line 的列，其中包含作为字符串的整行。使用它以简单的形式读取面向行的数据以供以后处理。

#18433

# 多阶段查询任务引擎

MSQ 任务引擎现在是 Druid 的核心功能而不是扩展。它已出现在多个版本的默认扩展加载列表中。

升级之前，请从 common.runtimes.properties 中的 druid.extensions.loadList 中删除 druid-multi-stage-query。

如果扩展名在加载列表中，Druid 35.0.0 将忽略该扩展名。未来版本的 Druid 将无法启动，因为它无法找到扩展。

#18394

# 改进了监视器加载

您现在可以在 common.runtime.properties 中指定监视器，并且每个监视器将仅在适用的服务器类型上加载。以前，您需要在特定的 runtime.properties 文件中为监视器所针对的服务定义监视器。

#18321

# 精确计数扩展名

新的贡献者扩展 (druid-exact-count-bitmap) 添加了对在长列上使用 Roaring Bitmap 进行精确基数计数的支持。

#18021

# 改进了 indexSpec

用户现在可以单独为每个 JSON 列指定格式规范，这将覆盖摄取作业中定义的 IndexSpec。此外，可以使用 druid.indexing.formats.indexSpec 属性设置系统范围的默认值 IndexSpec。
