lobehub v2.3.3

发布 v2.3.3

来自 PR #22891：https://github.com/lobehub/lobehub/pull/22891

🚀 LobeHub 发布 (20261112)

发布日期： 2026 年 11 月 12 日
自 v2.3.2 起： 253 个合并 PR · 252 个提交 · 12 个贡献者

花了一周时间将聊天变成真正的工作空间：具有自己的回复规则的直接频道、每个代理的收件箱身份以及可以直接从存储库创建的项目。

✨ 亮点

  • 直接渠道 — 每个客服人员和群组现在都有一个 IM 风格的对话界面：堆叠的标题头像、标题中的输入、带有 + 菜单的卡片编辑器、日期分隔符、列表行上的回复活动。 （＃22559，＃22583，＃22556，＃22440）
  • 每个代理回复策略 - 每个代理决定何时唤醒：首先拥有自己的规则，后续保持沉默，未寻址的消息得到一个主要响应者，并且运行时记录唤醒发生的原因。 （＃22551，＃22454，＃22847）
  • 代理身份和邮件 — 代理在身份组下获得地址、收件箱和个人资料页面；邮件唤醒运行将他们的结论发布回所有者的频道，并且只能看到他们自己的邮箱。 （#22009、#22010、#22578、#22686）
  • GitHub 中的项目 — 从存储库创建项目，选择其工作位置，编辑或删除工作目录，以及使用选择器、徽章和分组将任务链接到项目。 （#21552、#22612、#22725、#22383）
  • 知识库排序 — 自然前缀排序、排序控件和拖放重新排序，以及调用者范围的业务知识访问接缝。 （＃22866，＃22863）
  • 桌面服务于远程终端 — 桌面应用程序现在可以为网络和移动 clients 提供远程终端服务，同时还可以为远程设备提供本地文件预览。 （＃22852，＃22647）
  • 标志背后的新表面 — Lobe Bench 工作区页面（基准、数据集、实验）、使用 TRPC API 的会议数据模型以及版本化技能档案。 （＃22483，＃21259，＃22590）

🏗️ 频道和对话

  • 侧边栏频道按未读和@提及突出显示进行排序，并且项目的常规频道始终打开。 （＃22859，＃22870）
  • 线程作为页面而不是侧面板打开；实体链接渲染和验收报告在提要旁边打开。 （＃22850，＃22584）
  • 作曲家将突出显示为文本而不是标签，并且作曲家回复栏在提要淡入其中时变软。 （＃22846，＃22839）
  • 代理个人资料卡出现在消息头像中悬停并加入事件线。 （＃22515，＃22836）

🤖 代理运行时和身份

  • 中继模型运行时：路由器尝试运行一个生命周期并在取消时停止，并行工具调用参数保留在其自己的调用上，中流套接字丢弃被归类为 ProviderStreamInterrupted。 （＃22819，＃22718，＃22827）
  • Anthropic、OpenAI 和 OpenAI 兼容代码按协议组织，并提取共享路由器助手。 （＃22785，＃22731，＃22818）
  • 网关步骤按服务器时间排序，丢失锁定后拒绝步骤提交，并再次传递后台子代理结果。 （＃22842，＃22524，＃22530）
  • 内存工作因被禁止的用户而停止，失败的提取记录其真正原因，并且小批量运行长合并合并。 （＃22691，＃22797，＃22596）
  • Claude Code 会话可以通过排队的后续操作进行引导，支持 OpenCode 2.x，并且默认情况下以完全访问权限运行 Copilot / Cursor ACP。 （＃22575，＃22740，＃22574）

📱 项目、任务和目标

  • 新项目默认有一个专用的主代理，侧边栏将项目折叠成一个带有收藏夹和排序的链接，从 GitHub 创建也可以创建该代理。 （#22401、#22320、#22696）
  • 代码项目在项目自己的存储库内的沙箱中运行。 (#22761)
  • 计划任务接受精确的分钟；跨工作空间任务链接在侧面板中打开；重新交付的完成会解决一次运行。 （#22406、#22473、#22637）
  • 贯穿始终的目标修复：门控回合被解读为等待释放，计划回合停止关闭，并且 goal:manage 被授予运行用户发送的权限。 （＃22750，＃22760，＃22726）

🖥️ 台式机和 Clients

  • AppImage 核心 OTA 通过分离的生成重新启动，标题栏在选项卡条上保持可拖动状态，并且开发实例被隔离和标记。 （＃22793，＃22462，＃22823）
  • 任务主题抽屉式标题离开拖动区域，侧边栏代理标题跟随选项卡代理在主页之后。 （＃22831，＃22825）
  • lh 在创建代理时获得 --visibility / --json、mcp 别名、会议命令和 CLI 目标要求编辑。 （#22801、#22626、#22593、#20568）

🔒 安全性和可靠性

  • **安全性：**工作流程回调现在在未经身份验证时无法关闭；邮件唤醒运行的范围仅限于其自己的邮箱； SWR 密钥注册表被冻结，因此新服务器数据路由到本地副本。 （＃22864，＃22686，＃22727）
  • **可靠性：**页面协作为每页保留一棵 Yjs 树，并提供耐用的房间；上下文引擎快照被汇集在一起​​，因此长期运行的跟踪不再呈二次方增长；文件解析不再阻塞事件循环。 （＃22695，＃22522，＃22796）

🔧 工具和维护

  • StyleX 迁移继续使用样式等效验证器，该验证器显示已迁移的后代规则的移动位置。 （＃22041，＃22658）
  • 测试跨模块整合，数据库覆盖率恢复到 100%，并删除无效的 v8 后备。 （#22337、#22719、#21893）
  • 停用了 new_tier_plans 标志、未使用的代理流端点和每日免费视频配额提示。 （＃22611，＃22601，＃22811）
