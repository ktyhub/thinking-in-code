其他变化

  • 杂务：在 @ryannikolaidis 在 https://github.com/Unstructured-IO/unstructured/pull/4607 中发布 0.27.35 后启动 0.27.36-dev
  • 修复（xml）：在 https://github.com/Unstructured-IO/unstructured/pull/4573 中保留 @L4XB 贯穿子元素的文本
  • 修复(pptx)：通过 @feiiiiiii5 在 https://github.com/Unstructured-IO/unstructured/pull/4604 中可见的盒子大小来过滤幻灯片外的形状 *修复（html_table）：在https://github.com/Unstructured-IO/unstructured/pull/4611中通过@Eapp1e在空单元格上保持声明的行距为零
  • 修复（utils）：通过路径包含检测临时文件，而不是https://github.com/Unstructured-IO/unstructured/pull/4609中@Eapp1e的名称前缀
  • 修复（ocr）：通过https://github.com/Unstructured-IO/unstructured/pull/4617中的@Eapp1e将推断的列表元素扩展为每一项一个元素
  • 修复（pdf）：保持 FAST 分区独立于 https://github.com/Unstructured-IO/unstructured/pull/4600 中 @fallenmi 的 ONNX 加载失败 *修复：https://github.com/Unstructured-IO/unstructured/pull/4464中@TrueFurina将`skip_infer_table_types`默认切换为`None`
  • 修复(filetype): 当 https://github.com/Unstructured-IO/unstructured/pull/4625 中的 @tanishqbaweja 的内容类型为 application/octet-stream 时检测文件类型
  • 修复（分区）：仅当https://github.com/Unstructured-IO/unstructured/pull/4630中的@Eapp1e全部为1时，才将文本分类为地址
  • 修复：容忍悬空的 DOCX 页眉/页脚关系，而不是由 @aballman 在 https://github.com/Unstructured-IO/unstructured/pull/4624 中崩溃
  • 杂务：在 https://github.com/Unstructured-IO/unstructured/pull/4631 中由 @aballman 发布 0.27.36
