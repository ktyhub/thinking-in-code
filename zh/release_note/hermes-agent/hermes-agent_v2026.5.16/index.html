hermes-agent v2026.5.16

#爱马仕代理v0.14.0(v2026.5.16) 发布日期： 2026 年 5 月 16 日 自 v0.13.0 起： 808 次提交 · 633 个合并 PR · 更改了 1393 个文件 · 165,061 个插入 · 解决了 545 个问题（12 个 P0，50 个 P1） · 215 个社区贡献者（包括共同作者）

基础版本 — Hermes 可在任何地方安装和运行，附带您真正想要使用的东西，并停止运送您不需要的东西。 xAI Grok 成为 SuperGrok OAuth 提供商，grok-4.3 已达到 1M 上下文窗口。新的 OpenAI 兼容本地代理可将任何 OAuth 授权的 Hermes 提供商（Claude Pro、ChatGPT Pro、SuperGrok）转变为 Codex / Aider / Cline / Continue 可以访问的端点。 x_search 成为一流的 X (Twitter) 搜索工具，具有 OAuth 或 API 密钥身份验证。 Microsoft Teams 堆栈是端到端连接的（图形身份验证 + Webhook 侦听器 + 管道运行时 + 出站交付）。 debloating wave 使安装变得非常轻 - 重量级后端现在在首次使用时延迟安装，[all] extras 会删除延迟安装所覆盖的所有内容，并且当平台上的轮子拒绝时，分层安装会回退。 pip install hermes-agent 从 PyPI 运行。冷启动波将 hermes 的发射时间缩短了约 19 秒。浏览器 CDP 调用速度提高了 180 倍。两个新的消息平台（LINE + SimpleX Chat）使总数达到 22 个。跨会话 1 小时 Claude 提示缓存、实际实时传输会话的 /handoff、Telegram 和 Discord 上 clarify 的本机按钮 UI、Discord 通道历史记录回填、每次写入时的 LSP 语义诊断、统一的可插拔 video_generate、最终与非 Anthropic 提供商合作的 computer_use cua 驱动程序后端， cli可在任何终端中使用 URL、通过 uvx 进行 Zed ACP 注册表集成、本机 Windows 测试版、9 个新的可选技能、OpenRouter Pareto 代码路由器、huggingface/技能作为 trusted 默认点击。 12 个 P0 + 50 个 P1 关闭。

✨ 亮点

  • xAI Grok 通过 SuperGrok OAuth — 并且 grok-4.3 跳转到 1M 上下文窗口 — 如果您为 SuperGrok 付费，您现在可以通过使用您的 xAI 帐户登录来在 Hermes 中使用 Grok — 无需 API 密钥，无需单独计费。线通还将 grok-4.3 映射到 1M 令牌上下文窗口，因此您可以将整个代码库或研究语料库放入单个提示中。包括对权利错误的正确处理，以及当您通过 SSH 连接到远程设备并需要完成 OAuth 流程时使用的 SSH 到隧道文档页面。 (#26534、#26664、#26644、#26592)
  • OAuth 提供商的 OpenAI 兼容本地代理 — 运行 hermes proxy，您将获得一个 http://localhost:port 端点，该端点使用 OpenAI API，但由您登录的任何 OAuth 提供商提供支持 — Claude Pro、ChatGPT Pro、SuperGrok。现在，任何需要 OpenAI 兼容端点的工具（Codex CLI、Aider、Cline、Continue、您的自定义脚本）都可以与您现有的订阅配合使用，无需 API 密钥。一次订阅，每种工具。 (#25969)
  • x_search — 一流的 X (Twitter) 搜索工具 — 代理现在可以直接搜索 X，无需安装技能或连接自定义集成。直接从聊天中搜索时间线、查找话题、显示特定帖子。使用您的 X OAuth 登录名或 API 密钥（无论您有什么）进行身份验证。 (#26763)
  • Microsoft Teams — 端到端 — Hermes 现在可以从 Teams 读取消息并回发。完整的 Microsoft Graph 堆栈结合在一起：auth + client 基础、接收 Teams 事件的 Webhook 侦听器、管道插件运行时和出站交付。连接机器人一次，然后从任何 Teams 频道、DM 或群组与您的客服人员聊天。 （#21408–#21411 的打捞）（#21922、#21969、#22007、#22024)
  • Debloating wave - 更轻的安装，更少的不使用 - 一个干净的 pip install hermes-agent 用于拉下所有内容：每个消息适配器 SDK、每个图像生成 SDK、每个语音/TTS 提供商，无论您是否使用它们。现在，那些重型后端（Slack / Matrix / Feishu / DingTalk 适配器、后见之明 client、codex 应用服务器、Pixverse / Camofox / image-gen SDKs、语音/TTS 提供商）会在您第一次实际使用时自动安装。 [all] 附加功能会删除惰性依赖覆盖的所有内容，当轮子不适合您的平台时，安装程​​序会逐级回退，供应链咨询检查程序会扫描每次安装是否存在不安全版本。安装速度更快、磁盘占用空间更小、传递漏洞更少。 (#24220、#24515、#25014、#25038、#25766、#21818)
  • pip install hermes-agent && hermes — Hermes Agent 现在是一个真正的 PyPI 包。不再需要克隆存储库或运行 shell 安装程序 — 只需一个 pip 命令即可运行。该轮附带 Ink TUI 捆绑包和 shell 启动器，因此开箱即可获得完整的体验。 （打捞[#26350]（https://github.com/NousResearch/hermes-agent/pull/26350））（[#26593]（https://github.com/NousResearch/hermes-agent/pull/26593），[#26148]（https://github.com/NousResearch/hermes-agent/pull/26148））
  • 跨会话 1h Claude 提示缓存 — 当您通过 Anthropic、OpenRouter 或 Nous Portal 使用 Claude 时，提示前缀（系统提示、技能、内存）现在跨会话缓存一小时。启动 /new 会话，第一个响应会更快、更便宜地返回，因为缓存在上次会话中仍然是热的。后台内存审查也会影响缓存，因此它不会每次都付出全价。 (#23828、#25434、#24778)
  • browser_console 评估速度提高 180 倍 — 当代理使用浏览器工具检查页面或运行 JavaScript 时，这些调用现在共享一个与 Chrome 的持久连接，而不是每次都启动一个新的 DevTools 会话。差异是巨大的：过去每次调用需要花费几秒钟的时间才能以毫秒为单位返回。现实世界的页面交互感觉是即时的。 (#23226)
  • 冷启动性能波动 - hermes 启动大约 19 秒 - 运行 hermes 过去会让您等待大量导入开销和网络调用，然后才能看到提示。现在，启动路径大多被推迟：重型适配器仅在您使用它们时加载，模型目录首先来自磁盘缓存，医生检查并行运行，并且 chat -q 完全跳过欢迎横幅。仅 hermes tools 全平台屏幕时间就从 14 秒下降到 1.5 秒以下。 (#22138、#22120、#22681、#22790、#22808、#22831、 #22859、#22904、#22766、#25341)
  • 两个新的消息平台 - LINE + SimpleX Chat - LINE 在日本、韩国和台湾非常受欢迎，现在 Hermes 在 LINE Messaging API 上本地运行。 SimpleX Chat 是一款注重隐私的去中心化通讯工具，没有用户 ID，同时也是一流的平台。这使得 Hermes 的消息传递平台总数达到 22 个，因此无论您和您的团队在哪里聊天，代理都可以在那里。 (#23197、#26232)
  • /handoff 实际上实时传输会话 — 在对话中切换模型或个性通常意味着失去上下文或重新开始。现在，/handoff 将您的活动会话（每条消息、每个工具调用、每一段上下文）实时转移到目标模型、角色或配置文件，而不会丢失任何内容。调试过程中从快速模型切换到深度推理模型，或者在任务的不同部分的配置文件之间传递会话。 (#23395)
  • Telegram 和 Discord 上 clarify 的本机按钮 UI — 当代理使用 clarify 工具向您询问多项选择问题时，它现在会在 Telegram 和 Discord 上显示真正的平台本机按钮，而不是要求您输入选项号。点击按钮，客服人员就会得到您的答案。在移动设备上尤其好。 (#24199、#25485)
  • Discord 频道历史记录回填（默认开启） — 当 Hermes 第一次加入 Discord 频道或线程时，它现在会读取最近的消息历史记录，以便在响应之前知道所说的内容。不再有“我们在说什么？” — 代理拥有屏幕上已经为其他人提供的上下文。 (#25984)
  • vision_analyze 将像素返回到具有视觉功能的模型 — 当您将代理指向具有 vision_analyze 的图像并且活动模型实际上可以看到（GPT-5、Claude、Gemini、Grok-vision）时，Hermes 现在将原始像素直接传递给模型，而不是首先将它们转换为文本描述。您可以获得模型的实际视觉推理，而不是降级的文本摘要往返。 (#22955)
  • 每回合文件突变验证器页脚 - 在写入或编辑文件的每个回合之后，代理现在会得到一个简短的页脚，准确总结磁盘上发生的更改 - 文件路径、行数、实际增量。这意味着当写入未落地或被无提示覆盖时，代理会捕获自己的错误，而不是在文件实际未保存时自信地告诉您“我添加了该功能”。 (#24498)
  • 每次写入时进行 LSP 语义诊断 — 当代理使用 write_file 或 patch 时，Hermes 现在针对已编辑的文件运行真实语言服务器，并在下一轮之前将任何新错误返回给代理。类型错误、未定义的符号、缺少导入——立即捕获。远远超出了 v0.13.0 的基本 Python/JSON/YAML/TOML linting，因为它是实际的语义分析。 （[#24168]（https://github.com/NousResearch/hermes-agent/pull/24168），[#25978]（https://github.com/NousResearch/hermes-agent/pull/25978））
  • 统一的 video_generate 与可插入的提供商后端 — 一种工具，任何视频模型。 Hermes 已经配备了明显的后端，但您可以将新的视频提供程序作为插件放入，而无需触及核心。因此，当新的视频模型下个月发布时，它可以是一个单文件插件，而不是一个分叉。 (#25126)
  • computer_use cua 驱动程序后端 - 现在可与非 Anthropic 型号配合使用 - 计算机使用（控制鼠标和键盘以驱动 GUI 应用程序的代理）过去被锁定到 Anthropic 的 SDK。新的 cua-driver 后端也可以与非 Anthropic 提供商合作，具有适当的焦点安全操作，并在 hermes update 上进行自我更新。现在，任何具有视觉功能的模型都可以驱动您的桌面。 （重新打捞＃16936）（[#21967]（https://github.com/NousResearch/hermes-agent/pull/21967），[#24063]（https://github.com/NousResearch/hermes-agent/pull/24063））
  • 任何终端中的 Clickable URL — 代理输出中的链接现在是真正的 OSC8 超链接，并在任何支持它们的终端中悬停突出显示。 Click 在浏览器中打开 — 不再需要复制粘贴修剪文字记录中的长 URL。仅适用于 iTerm2、Kitty、Ghostty、现代 Windows 终端等。 (@OutThisLife) (#25071、#24013)
  • Zed ACP 注册表 — uvx 安装在一台 click 中 — Hermes 现已列在 Zed 的代理 Client 协议注册表中，因此 Zed 用户可以使用一台 click 来安装它。安装路径使用 uvx，因此没有 npm 依赖项。 hermes acp --setup-browser 引导浏览器工具进行注册表驱动的安装。 （打捞[#25908]（https://github.com/NousResearch/hermes-agent/pull/25908））（[#26079]（https://github.com/NousResearch/hermes-agent/pull/26079），[#26120]（https://github.com/NousResearch/hermes-agent/pull/26120），[#26234]（https://github.com/NousResearch/hermes-agent/pull/26234））
  • 带有 min_coding_score 旋钮的 OpenRouter Pareto 代码路由器 — OpenRouter 的“Pareto”路由器自动选择满足最低质量标准的最便宜的型号。新的 min_coding_score 配置可让您专门为编码任务设置标准 - Hermes 提供最实惠且至少在编码方面表现出色的型号。当中端型号可以时，请停止支付顶级型号的费用。 (#22838)
  • NovitaAI 作为新的模型提供商 — NovitaAI 加入了提供商阵容，为您提供了开源模型托管（Llama、Qwen、DeepSeek 等）的另一种选择及其定价和速率限制。 （打捞#7219）（@kshitijk4poor）（[#25507]（https://github.com/NousResearch/hermes-agent/pull/25507））
  • OpenAI/Codex 模型的 Codex 应用程序服务器运行时 — 当您使用 OpenAI 或 Codex 路径时，可选运行时可在后台驱动 OpenAI 的 Codex CLI。您可以获得会话重用、楔入会话的自动退休以及适当的 OAuth 刷新分类——这种管道可以使长时间的代理运行不会失败。 (#24182、#25769)
  • huggingface/skills 作为 trusted 默认水龙头 — Huggingface.co/skills 上托管的社区技能索引现在默认连接到技能中心。因此，当有人在那里发布有用的技能时，您可以从自己的 hermes skills 浏览器安装它，而无需任何额外的配置。 （关闭#2549）（[#26219]（https://github.com/NousResearch/hermes-agent/pull/26219））
  • 9个新的可选技能 - Hyperliquid（通过SDK和REST API进行perp +现货交易），雅虎财经（实时市场数据，基本面，历史），api测试（REST + GraphQL调试配方），统一EVM多链（一项技能涵盖以太坊+ L2s + Base），darwinian-evolver（进化提示/技能调整）， osint-investigation（针对人员/域/组织的 OSINT 配方）、pinggy-tunnel（将本地服务公开到公共互联网）、观察者（通过 cron no_agent 模式轮询 RSS / HTTP JSON / GitHub 以进行更改检测）以及 2026 年 5 月开发者平台的全面 Notion 检修。 (#23582、#23583、#23590、#25299、#26760、#26729、 #26765、#21881、#26612)
  • API 服务器公开运行批准事件 — 如果您通过 HTTP API 以编程方式驱动 Hermes，则当代理命中需要批准的命令时，长时间运行的运行不再默默地挂起。批准请求现在出现在 API 流上，因此您的 client 可以提示用户并回复 — 不再出现无声的停顿。 （打捞[#20311]（https://github.com/NousResearch/hermes-agent/pull/20311））（[#21899]（https://github.com/NousResearch/hermes-agent/pull/21899））
  • 插件可以通过 ctx.llm 运行任何 LLM 调用 + 通过 tool_override 替换内置工具 — 如果您正在编写 Hermes 插件，您现在可以获得通过活动提供程序和凭据进行 LLM 调用的一流访问权限 — 无需手动 client 连接。新的 tool_override 标志让插件可以干净地用自己的实现替换内置工具。插件作者获得与核心代理使用的相同的模型路由和身份验证管道。 （关闭＃11049）（[#23194]（https://github.com/NousResearch/hermes-agent/pull/23194），[#26759]（https://github.com/NousResearch/hermes-agent/pull/26759））
  • Brave Search（免费层）+ DuckDuckGo (DDGS) 作为网络搜索提供商 — 两个新的免费网络搜索后端加入了 Tavily、SearXNG 和 Exa。 Brave Search 有大量的免费套餐； DDGS 是完全不需要钥匙的 DuckDuckGo 刮刀。选择适合您的预算和速率限制需求的选项。 (#21337)
  • Sudo 暴力阻止 + 3 个危险命令绕过关闭 + 工具错误清理 — 批准门现在阻止 sudo -S 暴力尝试，并将 stdin-fed 或 Askpass 剥离的 sudo 调用分类为危险。三个已知的危险命令检测旁路已关闭（受到 Claude Code 的命令检测工作的启发）。现在，工具错误字符串在重新注入模型上下文之前会被清理，因此恶意文件或远程服务无法通过错误输出将指令传递给代理。 (#23736、#26829、#26823)
  • /subgoal — 用户添加的条件附加到活动的 /goal — 当您运行 /goal 时（持续的拉尔夫循环目标，代理持续运行直到满足条件），您现在可以使用 /subgoal <text> 在运行中将额外的成功条件分层到其上。法官将您的新标准纳入“完成或继续”决策中，而无需重新启动循环。 (#25449)
  • 提供商重命名 — 阿里云 → Qwen Cloud — 阿里云提供商在选择器和配置中重命名为 Qwen Cloud，以匹配世界其他地方的称呼。现有的配置键仍然有效——没有重大变化——但用户界面现在与实际品牌相匹配。 (#24835)
  • 本机 Windows 支持（早期测试版） — Hermes 现在在 cmd.exe 和 PowerShell 上本机运行，无需 WSL。完整的 PowerShell 安装程序可处理 MinGit 自动安装、Microsoft Store python 存根检测和前台 Ctrl+C dance。仍然有一些粗糙的边缘（这是“早期测试版”标记）——大约 40 个仅限 Windows 的后续修复已经出现在窗口中——但基本循环可以在干净的 Windows 机器上端到端地工作。 (#21561)
