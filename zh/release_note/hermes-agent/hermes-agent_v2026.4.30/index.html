hermes-agent v2026.4.30

#爱马仕代理v0.12.0(v2026.4.30) 发布日期： 2026 年 4 月 30 日 自 v0.11.0 起： 1,096 次提交 · 550 个合并 PR · 更改了 1,270 个文件 · 217,776 次插入 · 213 名社区贡献者（包括共同作者）

Curator 版本 — Hermes Agent 现在可以自行维护。一个自主的后台管理员会按照自己的时间表对您的技能库进行评分、修剪和整合。审查要保存什么的自我完善循环得到了实质性的升级。四个新的推理提供商、第 18 个消息平台、第 19 个 via Teams 插件、原生 Spotify + Google Meet 集成、ComfyUI 和 TouchDesigner-MCP 从可选变为默认捆绑，可见 TUI 冷启动减少了约 57%。

✨ 亮点

  • 自治管理者 — hermes curator 作为网关的 cron 代码上的后台代理运行（默认为 7 天周期）。它会对您的技能库进行评分，整合相关技能，修剪无效技能，并将每次运行报告写入 logs/curator/run.json + REPORT.md。存档的技能通过模型​​+启发式进行分类：整合与修剪。纵深防御门可保护捆绑/中心技能免遭突变。统一在 auxiliary.curator 下 — 在 hermes model 中选择策展人的模型，从仪表板进行管理。 hermes curator status 按使用情况（最常用/最少使用）对技能进行排名。 (#17277、#17307、#17941、#17868、#18033)
  • 自我改进循环 - 大幅升级 - 后台审查分叉（Hermes自我改进的核心：在每轮之后决定保存或更新哪些记忆/技能）现在是类优先（基于标题而不是自由形式），主动更新偏向（更喜欢代理刚刚加载的技能），处理references/ / templates/子文件，并正确继承父级的实时运行时（提供者，模型，凭证实际上传播）。仅限于内存+技能工具集，因此它不会蔓延。内存供应商彻底关闭。先行工具消息从摘要中排除，以便分叉看到干净的上下文。 (#16026、#17213、#16099、#16569、#16204、#15057)
  • 技能集成 - 主要扩展 - ComfyUI v5带有官方CLI + REST +硬件门控本地安装，从可选变为默认内置（[#17610]（https://github.com/NousResearch/hermes-agent/pull/17610），[#17631]（https://github.com/NousResearch/hermes-agent/pull/17631），[#17734]（https://github.com/NousResearch/hermes-agent/pull/17734））。 TouchDesigner-MCP 默认捆绑，并扩展了 GLSL、post-FX、音频、几何和 9 个新参考文档（#16753、#16624、#16768 — @kshitijk4poor + @SHL0MS）。 Humanizer 技能移植了一个可以去除 AI 主义的文本清理器 (#16787)。 claude-design HTML 工件技能 + design-md（Google DESIGN.md 规范）+ Airtable 抢救 + external_dirs 中的 skill_manage 编辑 + 直接 URL 技能安装 + /reload-skills 斜线命令。 (#16358、#14876、#16291、#17512、#16323、#17744)
  • LM Studio — 一流的提供商 — 从自定义端点别名升级为成熟的本机提供商：专用身份验证、hermes doctor 检查、推理传输、实时 /models 列表。 （@kshitijk4poor 的 #17061 的抢救。）（#17102）
  • 另外四个新的推理提供程序 - GMI Cloud（一流，#11955 的抢救 - @isaachuangGMICLOUD），具有自动检测功能的 Azure AI Foundry，带有 PKCE 浏览器流程的 MiniMax OAuth（抢救#15203），Tencent Tokenhub（#16860 的抢救）。 (#16663、#15845、#17524、#16960)
  • 可插拔网关平台 + Microsoft Teams — 网关现在是插件主机。嵌入式消息适配器位于核心之外，而 Microsoft Teams 是第一个提供插件的平台。 （#17664 的打捞。）（[#17751]（https://github.com/NousResearch/hermes-agent/pull/17751），[#17828]（https://github.com/NousResearch/hermes-agent/pull/17828））
  • 腾讯元宝 (Yuanbao) — 第 18 个消息传递平台 — 具有文本 + 媒体传输的本机网关适配器。 （[#16298]（https://github.com/NousResearch/hermes-agent/pull/16298），[#17424]（https://github.com/NousResearch/hermes-agent/pull/17424））
  • Spotify — 原生工具 + 捆绑技能 + 向导 — PKCE OAuth 背后的 7 个工具（播放、搜索、队列、播放列表、设备）、交互式设置向导、捆绑技能、hermes tools 中的显示、记录 cron 使用情况。 (#15121、#15130、#15154、#15180)
  • Google Meet 插件 — 加入通话、转录、发言、跟进。实时 OpenAI 传输 + Node bot 服务器，完整管道捆绑为插件。 (#16364)
  • hermes -z 一次性模式 + hermes update --check — 非交互式 hermes -z <prompt> 与 --model/--provider/HERMES_INFERENCE_MODEL。 hermes update --check 预检。选择更新前 HERMES_HOME 备份。 (#15702、#15704、#15841、#16539、#16566)
  • 模型仪表板选项卡 + 浏览器内模型配置 - 丰富的每个模型分析，从仪表板切换主 + 辅助模型。 (#17745、#17802)
  • 远程模型目录清单 - OpenRouter + Nous Portal 模型目录现在从远程清单中提取，因此新模型无需发布即可显示。 (#16033)
  • 本机多模式图像路由 - 图像现在基于模型的实际视觉功能而不是提供商的默认值进行路由。 (#16506)
  • 网关媒体奇偶校验 — 通过 Telegram、Discord、Slack、Mattermost、Email 和 Signal 发送本机多图像；具有 FLAC 支持的集中式音频路由 + Telegram 文档回退。 （[#17909]（https://github.com/NousResearch/hermes-agent/pull/17909），[#17833]（https://github.com/NousResearch/hermes-agent/pull/17833））
  • TUI 赶上（并超越）经典的 CLI — LaTeX 渲染 (@austinpickett)、/reload .env 热重载、可插入忙碌指示器样式 (@OutThisLife, #13610)、选择自动恢复上一个会话、扩展的轻终端自动检测、使用 d 从 /resume 选择器中删除会话、修改鼠标滚轮线滚动，以及一个 /mouse 开关，可以杀死 ConPTY 的幻像鼠标注入 (@kevin-ho)。 (#17175、#17286、#17150、#17130、#17113、#17668、 #17669、#15488)
  • 可观察性 + 成就插件 — 捆绑的 Langfuse 可观察性插件（抢救#16845）+捆绑的 Hermes-achievements 插件，可扫描完整的会话历史记录。 （[#16917]（https://github.com/NousResearch/hermes-agent/pull/16917），[#17754]（https://github.com/NousResearch/hermes-agent/pull/17754））
  • TTS 提供商注册表 + Piper 本地 TTS — 可插入 tts.providers.<name> 注册表； Piper 作为本地本地 TTS 提供商提供服务。 （关闭#8508。）（[#17843]（https://github.com/NousResearch/hermes-agent/pull/17843），[#17885]（https://github.com/NousResearch/hermes-agent/pull/17885））
  • Vercel 沙箱后端 — Vercel 沙箱作为执行代码/终端后端 (@kshitijk4poor)。 (#17445)
  • 默认情况下秘密编辑处于关闭状态 — 默认情况下关闭。防止长期存在的补丁损坏事件，即伪造的秘密形状子字符串破坏工具输出。当您需要时通过 redaction.enabled: true 选择加入。 (#16794)
  • 冷启动性能 - 通过延迟代理 init (@OutThisLife) 可见 TUI 冷启动削减 ~57%、OpenAI / Anthropic / Firecrawl / account_usage 的延迟导入、mtime 缓存的 load_config()、带有 TTL 缓存的 check_fn 结果的记忆 get_tool_definitions()、预编译的危险命令模式。 (#17190、#17046、#17041、#17098、#17206)
  • 可配置的提示缓存 TTL — prompt_caching.cache_ttl（默认 5m，选择加入 1h — 为保持缓存温暖的突发会话节省成本）。 #12659 的打捞。 (#15065)
