hermes-agent v0.23.0

#爱马仕代理v0.23.0

发布日期： 2026 年 11 月 5 日 自 v0.22.0 以来： ~10,080 次提交 · ~1,950 个合并 PR · ~8,720 个文件已更改 · ~725,200 个插入 · ~201,400 个删除 · ~850 个问题已关闭 · 666 个贡献者

壁炉释放。 在古老的赞美诗中，赫耳墨斯守护着门槛，赫斯提亚守护着壁炉，两人并肩受到荣耀。 v0.22.0让新人进门； v0.23.0 点燃了他们聚集的火。标题：您的整个桌面工作区现在在浏览器选项卡中打开，由您自己的网关提供服务。在它下面，每个对话都位于一个地方：单个网关拥有每个会话，CLI、TUI、桌面、编辑器、机器人和 cron 都坐在同一张桌子上，而不是每个都运行自己的代理。从这一个壁炉开始，桌面使您运行 Hermes 的每台机器都保持连接，群聊路由自己的对话，终端最终内联绘制您的图像并让您倒带对话。围绕它：不断更新的插件、付费 MCP 工具的价格标签和支出限制、可插入委托、从大约 600 个条目增长到超过 1,050 个条目的插件目录、更精简的内置技能集，以及长期网关的长期内存和延迟工作。此版本汇总并完整记录了 v0.22.1–v0.22.7 补丁版本。

✨ 亮点

  • 浏览器选项卡中的桌面工作区 — 新的 Web 应用程序从您自己的网关提供完整的桌面工作区：相同的聊天、群聊、插件和设置，在网络上的任何浏览器中或通过登录的公共 URL 后面。 Docker 映像和 Nix 软件包已发货。默认关闭；使用“设置”中的 webapp.enabled 或 Web 访问将其打开。 (#141864、#145598、#145536、#145072、#145153 — @jquesnelle、@BearHuddleston、@IAvecilla、 @Adolanium）

  • 一个网关拥有每一次对话 — 之前，CLI、TUI、桌面、编辑器 (ACP)、消息传递机器人和 cron 都可以针对同一聊天运行自己的代理副本，这就是消息被写入两次或在表面之间丢失的原因。现在，每台计算机都运行一个拥有每个会话的网关，并且每个表面都作为 client 附加到它：您在任何地方打开的聊天都是相同的聊天，具有一个队列和一个历史记录。您甚至可以从桌面引导或编辑排队的提示，而无需它运行两次。 (#106742、#140334 — @unsupportedpastels、@kshitijk4poor)

  • 终端中的图片 — 当您粘贴图像或工具截取屏幕截图时，CLI 和 TUI 现在会在聊天中直接绘制图像，而不是打印文件路径：kitty 和 Ghostty（CLI 和 TUI）以及 iTerm2、WezTerm 和 Konsole（CLI）中的真实像素，其他地方的彩色块，以及打开图像支持时 VS Code 终端中的全分辨率。 (#147293、#148874 — @Adolanium)

  • 倒回对话 — 按 Esc 两次或在 TUI 或经典 CLI 中键入 /rewind，选择较早的消息，然后编辑并重新发送它或从该点分叉新会话。原始会话保持原样。 TUI 还可以在转弯仍在运行时启动 /new；旧的继续在后台工作。 (#144937、#148880 — @SaguaroDev)

  • 一个桌面窗口中的每台计算机 — 桌面现在可以同时连接所有网关，因此可以在该计算机与 SSH 或远程网关之间即时切换。终端选项卡在打开它们的主机上运行，​​群聊可以混合来自不同计算机的机器人。 (#147681、#147708、#148418 — @dskwe、@janviernine)

  • 自行运行的群聊 - 机器人模式房间可以让主导机器人或自动路由器选择谁回答没有透露姓名的消息。预定的工作可以发布到房间中，房间有目的并共享笔记，机器人不再无限循环地互相 ping。房间现在看起来也像正常的 Hermes 聊天，每个机器人都会实时显示它正在做什么（“侦察·终端·7 秒”）。 (#144833、#148417、#148888、#148903、#148422 — @KoNit-K)

  • 保持最新的插件 — hermes plugins update 立即更新所有内容，并且选择加入的自动更新开关（CLI、聊天、桌面和仪表板）使目录和 git 插件保持最新。会阻止而不是应用会破坏您的设置的更新。目录本身从大约 600 个条目增加到超过 1,050 个条目，并且新的“验证”层标记了供应商自己构建的插件。 (#141513、#85794、#143468、#144257 — @charan-rathore、@YS-OH-CORE)

  • 付费工具的价格标签和支出限制 — 付费 MCP 工具（例如 3D 或媒体生成）可以声明通话费用。批准提示显示每个呼叫的
