hermes-agent v2026.8.3

#爱马仕代理v0.20.0(v2026.8.3) 发布日期： 2026 年 8 月 3 日 自 v0.19.0 起： ~3,650 次提交 · ~1,400 个合并 PR · ~5,200 个文件已更改 · ~559,000 个插入 · ~405,000 个删除 · ~1,200 个问题已关闭 · 650 多个贡献者

先驱发布。 Hermes 是诸神的先驱，这一发布使他成为真正的一员：他 说话（带有流式 TTS 的实时对话语音、插入、设备上唤醒词以及跨 CLI、桌面和每个支持音频的网关平台的免提控制），他 将消息传递给其他代理 (A2A v1.0)，他 向您的系统（已签名的出站网络钩子），而他引用了他的来源（具有可验证引用和事实检查的基础研究）。围绕这个脊柱：桌面应用程序变成了一个平台（带有实时预览的工件、插件 SDK、从任何地方快速输入、多个窗口），CLI 获得了一波电源命令（! shell 模式、/init、/diff、/context、/focus），压缩变得更加智能和温和，工具本身现在从自己的故障中恢复，而不是让模型猜测。此版本汇总了 v0.19.1 基础设施补丁标签中的所有内容 - 该窗口已在此处完整记录。

✨ 亮点

  • 与 Hermes 交谈 — 带插入功能的流式对话语音 — 语音模式过去的意思是：说话，等待生成整个回复，然后收听一个长音频文件。现在，Hermes 在响应流中逐条说话，你可以通过说话来打断它的中途（它会停下来，听着，模型会被告知你插话），而忙碌感知静音检测意味着它不会在你说话时说话。这可以在 CLI 语音模式下、在桌面上以及通过网关适配器工作。与 Hermes 交谈终于感觉像是一场对话，而不是语音邮件交流。 (#69511、#73862、#74223、#74000、#69602 — @teknium1、@OutThisLife)
  • 唤醒词和免提控制 - 说出您自己的开放词汇唤醒短语（“嘿 Hermes”，或您选择的任何内容），Hermes 开始监听 - 检测在设备上运行，因此在等待时不会有任何音频离开您的机器。多配置文件语音路由意味着不同的唤醒词可以到达不同的配置文件，并且说“停止”即可结束每个表面上的语音聊天，而无需触摸键盘。现在，您可以在房间的另一边与您的终端进行通话。 (#70509、#73106、#73933 — @teknium1)
  • 全平台语音 — 在 WhatsApp、飞书、钉钉、LINE、QQ、Photon 或微信上向 Hermes 发送语音留言，并得到转录和回复；自动 TTS 回复以平台感知方式交付（平台需要作品的作品、正确附加的标题）。 STT 现在是完全可配置的——它自己的 hermes tools 类别、GUI 切换、仪表板下拉菜单、统一语言解析（因此转录不会以错误的语言返回）以及 OpenAI 的 gpt-transcribe 支持。一个统一的语音文本预处理器可以清除所有 TTS 提供商的语音中的 Markdown、代码和 URL。 (#73515、#73508、#73910、#73513、#73067 — @teknium1)
  • 你可以进行研究 trust — 事实核查的基础引文 — 新的 grounded-citations 技能使 Hermes 进行研究，其中每项主张都有可验证来源的支持：引用与实际页面文本相匹配（不是幻觉），引文链接到确切的证据，事实核查模式对您提交的任何文件或声明都使用相同的机制 — 它告诉您哪些内容已通过，哪些内容未通过，哪些内容不能通过已验证。如果你使用 Hermes 进行研究，这就是“听起来正确”和“来源可证明”之间的区别。 (#71698、#77104 — @teknium1)
  • 出站 webhook — Hermes 将事件推送到您的系统 — 到目前为止，与 Hermes 集成意味着在平台上进行轮询或监听。现在，Hermes 将签名的生命周期事件（会话活动、轮次完成、工具事件）推送到您注册的任何 HTTP 端点 - 使用 HMAC 签名，以便您的接收者可以验证真实性。将 Hermes 连接到您的 CI、家庭自动化、仪表板或任何使用 HTTP 的服务，无需轮询循环。 (#69406 — @teknium1)
  • 桌面应用程序成为一个平台 - 工件、插件 SDK、快速输入 - Hermes 桌面现在呈现 工件：在右轨查看器中带有沙盒实时预览的版本化卡片，因此生成的 HTML/应用程序可以在聊天旁边安全运行。一个真正的 插件 SDK 以看板作为其创始插件，ctx.download 用于处理用户文件、浮动窗格放置和多个 GUI 窗口。全局热键快速输入窗口可以从操作系统中的任何位置将想法捕获到任何会话中。桌面不再是聊天client，而是开始成为工作台。 (#72345、#61173、#74413、#72315、#68259、#73143 — @OutThisLife, @teknium1)
  • Hermes 讲 Agent-to-Agent — A2A v1.0 — 一个新的捆绑插件实现了 Agent-to-Agent 协议，因此 Hermes 可以发现其他 A2A 兼容代理、与之对话并由其驱动。问题 #514 就此结束——存储库中最古老的开放功能请求之一。如果您正在构建具有异构堆栈的多代理系统，Hermes 现在有一个用于连接它们的标准有线协议。 (#77109 — @teknium1)
  • CLI 高级用户浪潮 — !command 立即运行 shell 命令，无需花费模型回合。 /init 扫描您的项目并生成（或更新）AGENTS.md。 /diff 显示任何表面的分阶段/所有/会话更改，/context 准确分解填充上下文窗口的内容，/focus 为您提供带有隐藏线恢复的缩减输出视图，Ctrl+S 将半写提示隐藏到可浏览面板中。另外，hermes import-agent 可通过一个命令将您的 Claude Code 或 Codex CLI 设置迁移到 Hermes。 (#72257、#72178、#72240、#72242、#72302、#72262、 #72190 — @teknium1，几个挽救长期存在的社区 PR）
  • 中途纠正特工 - 重定向 - 如果赫尔墨斯走错了路，你不再需要 /stop 并重新解释。在其工作时输入修正，活动转弯将被重定向：保留飞行中的工作，保留原始提示，并且代理会根据您的新指导进行航向修正。与双 ESC 草稿丢弃和作曲家撤消堆栈配合使用，转向感觉就像编辑，而不是重新启动。 (#63104、#72339、#74736 — @OutThisLife)
  • 自我修复工具 - 全面的自我恢复升级意味着代理在工具摩擦上浪费的次数要少得多：截断的终端输出溢出到代理可以读回的文件，patch 检测已应用的编辑并诊断空白不匹配，write_file 验证磁盘上的内容，搜索不匹配的内容，探测未遂事件并恢复，常见的故障类会返回可操作的提示。默认的工具调用迭代限制也跃升了 90 → 500——长时间的自主运行不再撞到人造墙。 (#77041、#76998、#77024、#77055、#77011、#76992、 #72176 — @teknium1)
  • 尊重你的对话的压缩 - 上下文压缩得到了深入的修改：大窗口模型的主动工具结果修剪，每轮微压缩，分摊成本而不是一次巨大的暂停，有保证的 N 用户消息尾部，因此最近的对话总是存活下来，进度感知超时，停止惩罚缓慢的摘要模型，以及幽灵技能防御，因此修剪的技能永远不会默默地困扰会话。现在可以按模型和绝对令牌配置阈值。长时间的会议保持连贯并且不再停滞。 （#70254、#75345、#70250、#71508、#70275 — @teknium1、@kshitijk4poor，挽救多个社区 PR）
  • 智能审批不断发展 — hermes approvals suggest 将您的审批历史记录挖掘到许可名单提案中，操作员可以自定义智能审批策略，连续拒绝断路器可以阻止行为不当的循环，并且桌面配对审批是配置文件正确的，并有适当的表面来回答它们。加上 docker/podman daemon-redirect 命令的新批准门。少了clicking的“认可”，没有给予一寸的控制权。 (#72259、#72186、#72203、#74446、#71092 — @teknium1、@OutThisLife)
  • 再次更快 - 提示缓存现在涵盖本机 Anthropic 上的工具模式，而不会丢失历史记录。 hermes -w 冷启动下降了约 14 秒 → 约 1.8 秒，hermes update 无操作速度加快了 2-6 秒，重型 SDK 延迟加载了导入路径，配置读取停止了深度复制（遥测门上速度提高了 54 倍），桌面交付了第二个 60 fps 波 — 流传输成本与脚本长度无关，以 60 fps 拖动五个流选项卡，后台空闲 CPU 接近于零。 (#76032、#71637、#74218、#74204、#71835、#72346、 #75218 — @kshitijk4poor、@teknium1、@OutThisLife)
  • 运行和到达的新地方 - Buzz 成为捆绑网关平台（Block 的基于 Nostr 的信使，具有本机 WebSocket 传输和 NIP-42 身份验证），Vercel AI 网关提供商和 Vercel Sandbox 终端后端回归现代化，桌面获得 SSH 远程后端连接模式，Relay 提供了四个阶段的奇偶校验 - 媒体、交互式提示、线程生命周期、打字指示器 - 以及 HSP 个人 + 组织技能同步。 (#73610、#73761、#74518、#68130、#71300–#71624、 #66730 — @teknium1、@yoniebans、@benbarclay)
