hermes-agent v2026.3.30

#爱马仕代理v0.6.0(v2026.3.30) 发布日期： 2026 年 3 月 30 日

多实例版本 — 用于运行隔离代理实例的配置文件、MCP 服务器模式、Docker 容器、后备提供商链、两个新消息平台（飞书/Lark 和 WeCom）、Telegram webhook 模式、Slack 多工作空间 OAuth、95 个 PR 和 2 天内解决的问题 16 个。

✨ 亮点

  • 配置文件 — 多实例 Hermes — 从同一安装运行多个独立的 Hermes 实例。每个配置文件都有自己的配置、内存、会话、技能和网关服务。使用 hermes profile create 创建，使用 hermes -p <name> 切换，导出/导入以进行共享。完全令牌锁隔离可防止两个配置文件使用相同的机器人凭据。 (#3681)
  • MCP 服务器模式 — 通过 hermes mcp serve 将 Hermes 对话和会话公开到任何 MCP 兼容的 client（Claude 桌面、光标、VS Code 等）。浏览对话、阅读消息、跨会话搜索以及管理附件——所有这些都通过模型上下文协议进行。支持 stdio 和 Streamable HTTP 传输。 (#3795)
  • Docker Container — 用于在容器中运行 Hermes Agent 的官方 Docker 文件。支持 CLI 和带有卷安装配置的网关模式。 （#3668，关闭#850）
  • 有序回退提供程序链 — 配置多个具有自动故障转移功能的推理提供程序。当您的主要提供商返回错误或无法访问时，Hermes 会自动尝试链中的下一个提供商。通过 config.yaml 中的 fallback_providers 进行配置。 （#3813，关闭#1734）
  • 飞书/Lark 平台支持 — 飞书和 Lark 的完整网关适配器，包括事件订阅、消息卡、群聊、图像/文件附件和交互式卡回调。 （#3799、#3817、关闭 #1788）
  • WeCom（企业微信）平台支持 — WeCom（企业微信）的新网关适配器，具有文本/图像/语音消息、群聊和回调验证。 (#3847)
  • Slack 多工作区 OAuth — 通过 OAuth 令牌文件将单个 Hermes 网关连接到多个 Slack 工作区。每个工作区都有自己的机器人令牌，根据传入事件动态解析。 (#3903)
  • Telegram Webhook 模式和组控制 — 在 Webhook 模式下运行 Telegram 适配器作为轮询的替代方案 — 响应时间更快，更适合反向代理后面的生产部署。当机器人响应时，新的群组提及门控：始终、仅在@提及时或通过正则表达式触发器。 （[#3880]（https://github.com/NousResearch/hermes-agent/pull/3880），[#3870]（https://github.com/NousResearch/hermes-agent/pull/3870））
  • Exa 搜索后端 — 添加 Exa 作为与 Firecrawl 和 DuckDuckGo 一起的替代网络搜索和内容提取后端。设置 EXA_API_KEY 并配置为首选后端。 (#3648)
  • 远程后端上的技能和凭证 — 将技能目录和凭证文件挂载到 Modal 和 Docker 容器中，以便远程终端会话可以访问与本地执行相同的技能和机密。 (#3890、#3671、关闭#3665、#3433)

🏗️ 核心代理和架构

提供商和型号支持

  • 有序后备提供程序链 - 跨多个配置的提供程序自动故障转移（#3813）
  • 修复提供商切换上的 api_mode - 通过 hermes model 切换提供商现在可以正确清除过时的 api_mode 而不是硬编码 chat_completions，修复具有 Anthropic 兼容端点的提供商的 404 错误（#3726、#3857、关闭#3685)
  • 停止静默 OpenRouter 回退 - 当没有配置提供程序时，Hermes 现在会引发明显的错误，而不是静默路由到 OpenRouter（#3807、#3862）
  • Gemini 3.1 预览型号 — 添加到 OpenRouter 和 Nous Portal 目录（#3803，关闭 #3753）
  • Gemini 直接 API 上下文长度 — 直接 Google AI 端点的完整上下文长度解析 (#3876)
  • gpt-5.4-mini 添加到 Codex 后备目录（#3855）
  • 当探针返回较少模型时，**精选模型列表优于实时 API 探针（#3856、#3867）
  • 用户友好的 429 速率限制消息，带有重试后倒计时 (#3809)
  • 辅助 client 占位符密钥，用于没有身份验证要求的本地服务器（#3842）
  • 信息级日志记录用于辅助提供程序解析（#3866）

代理循环和对话

  • 子代理状态报告 — 当摘要存在而不是一般故障时报告 completed 状态（#3829）
  • 压缩期间更新会话日志文件 — 防止上下文压缩后引用过时的文件（#3835）
  • 省略空工具参数 - 当空时不发送 tools 参数而不是 None，修复与严格提供程序的兼容性 (#3820)

配置文件和多实例

  • 配置文件系统 — hermes profile create/list/switch/delete/export/import/rename。每个配置文件都有独立的 HERMES_HOME、网关服务、CLI 包装器。令牌锁可以防止凭证冲突。配置文件名称的制表符补全。 (#3681)
  • 配置文件感知显示路径 — 所有面向用户的 ~/.hermes 路径替换为 display_hermes_home() 以显示正确的配置文件目录 (#3623)
  • 惰性 display_hermes_home 导入 — 当模块缓存过时的字节码时，在 hermes update 期间防止 ImportError (#3776)
  • 受保护路径的 HERMES_HOME — .env 拒绝写入路径现在尊重 HERMES_HOME 而不是硬编码的 ~/.hermes (#3840)
