hermes-agent v2026.3.12

#爱马仕代理v0.2.0(v2026.3.12) 发布日期： 2026 年 3 月 12 日

自 v0.1.0（最初的预公开基金会）以来的第一个标记版本。在短短两周多的时间里，Hermes Agent 从一个小型内部项目发展成为一个功能齐全的 AI 代理平台——这得益于社区贡献的激增。此版本涵盖来自 63 个贡献者的 216 个合并拉取请求，解决了 119 个问题。

✨ 亮点

  • 多平台消息网关 — Telegram、Discord、Slack、WhatsApp、Signal、电子邮件 (IMAP/SMTP) 和 Home Assistant 平台，具有统一的会话管理、媒体附件和每平台工具配置。
  • MCP（模型上下文协议）Client — 原生 MCP 支持 stdio 和 HTTP 传输、重新连接、资源/提示发现和采样（服务器启动的 LLM 请求）。 (#291 — @0xbyt4、#301、#753)
  • 技能生态系统 — 超过 15 个类别的 70 多种捆绑和可选技能，以及用于社区发现、每个平台启用/禁用、基于工具可用性的条件激活以及先决条件验证的技能中心。 (#743 — @teyrebaz33, #785 — @teyrebaz33)
  • 集中式提供商路由器 — 统一的 call_llm()/async_call_llm() API 取代了跨视觉、汇总、压缩和轨迹保存的分散提供商逻辑。所有辅助使用者都通过具有自动凭证解析的单一代码路径进行路由。 (#1003)
  • ACP 服务器 — 通过代理通信协议标准集成 VS Code、Zed 和 JetBrains 编辑器。 (#949)
  • CLI 皮肤/主题引擎 — 数据驱动的视觉定制：横幅、旋转器、颜色、品牌。 7 个内置皮肤 + 自定义 YAML 皮肤。
  • Git Worktree 隔离 — hermes -w 在 git worktree 中启动隔离的代理会话，以便在同一存储库上安全并行工作。 (#654)
  • 文件系统检查点和回滚 — 在使用 /rollback 进行破坏性操作之前自动快照以进行恢复。 （[#824]（https://github.com/NousResearch/hermes-agent/pull/824））
  • 3,289 次测试 — 从接近零的测试覆盖率到涵盖代理、网关、工具、cron 和 CLI 的全面测试套件。
