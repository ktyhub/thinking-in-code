hermes-agent v0.22.0

#爱马仕代理v0.22.0

发布日期： 2026 年 10 月 13 日 自 v0.21.0 起： ~24,200 次提交 · ~6,080 个合并 PR · ~15,600 个文件已更改 · ~2,045,000 个插入 · ~1,140,000 个删除 · ~7,180 个问题已关闭 · ~2,520 个贡献者

阈值释放。 赫耳墨斯是阈值之神：门口、十字路口、界石。 v0.21.0组装万神殿； v0.22.0 即将进门。现在，全新的桌面安装会在免费试用模型上运行的引导设置聊天中打开，因此新用户在拥有 API 密钥之前就可以与 Hermes 交谈。连接器将代理带到您已经使用的应用程序中，无需启动帐户。本地模型通过 one-click llama.cpp 运行时将其带入您自己的硬件。而且门槛本身变得更加坚固：经过测试的 SemVer 稳定版本默认安装，签名的桌面包（包括 Microsoft Store），以及所有内容下的一个包管理器。围绕着这个脊柱：一个包含 600 个插件的目录、Claude 5.5 / GPT-6 模型 Wave、浏览器的密码管理器登录、一个可以接管的机器人屏幕、一个后端和一个用于每个配置文件的网关，以及一个小三分之一的代码库。这是 Hermes 已发货的最大窗口，大约是 v0.21.0 周期的 2.5 倍，它汇总并完整记录了 v0.21.1–v0.21.7 补丁版本。

✨ 亮点

  • 首次启动自行设置 — 在您从未使用过 Hermes 的计算机上打开桌面应用程序，它会启动简短的设置聊天而不是设置屏幕。它一次一张卡片询问您的姓名、强调色和布局、要连接哪些应用程序、要安装哪些插件，然后进行快速浏览并提供最多四个为您挑选的首要任务。它以免费试用模式运行（nous/welcome，每个操作系统用户一次），因此不需要密钥； 跳过设置结束它，然后设置→再次运行入门将其恢复。该代理还获得了 set_theme，因此“使其紫色，深色模式”适用于任何桌面聊天。 (#137429、#137522、#137807、#134209、#105258 — @alt-glitch、@OutThisLife、 @ethernet8023，@rewebs）

  • 连接器：Hermes 在您的应用程序内部工作 — 代理现在可以通过 Nous 工具网关在 Linear 和 Notion 等托管应用程序中进行操作：请求一个应用程序，在浏览器中登录一次，然后即可立即使用这些工具。您不需要 Nous 帐户即可启动；当您第一次使用应用程序时，Hermes 会创建一个免费的仅限连接器的身份。桌面有一个新的 连接器 页面，将托管应用程序和 MCP 服务器放在一个列表中（它取代了 MCP 选项卡），相同的设置卡出现在 TUI 和 CLI 中，您可以连接一个应用程序的多个指定帐户（work 和 home 帐户）并使用 /connectors 或 hermes connectors 管理它们。 (#106842、#111008、#119074、#135143、#135072、 #135097、#135151、#135173、#137426 — @alt-glitch、@rewbs)

  • 一台 click 中的本地模型 — Hermes 现在可以完全在您的计算机上运行开放模型，无需任何操作：无需帐户，无需 API 密钥。它使用适合您的硬件（CPU、CUDA、Metal、Vulkan 或 ROCm）的引擎安装和维护 llama.cpp，根据您的 GPU 和 RAM 对每个目录模型进行评级，并选择适合的最高质量构建。下载暂停和恢复，服务器随 Hermes 启动和停止，引擎更新都是 click。从 Windows、macOS 和 Linux 上的 设置 → 提供程序 → 本地模型 开始，或者从终端中的 hermes model → 本地模型 开始。该目录包括 Qwen3.8 27B、Qwen3.8 Flash Next（带有 MTP 推测头）、Qwen3.6 35B-A3B 和 DeepSeek V4 Flash，以及来自 Hugging Face 的任何 GGUF。 (#100667、#101823、#128768、#111423、#133111、 #134116 — @jquesnelle, @ethernet8023)

  • 稳定的发布渠道 — Hermes 现在发布经过测试的 SemVer 版本。每个版本都会通过源 CI、Docker、Nix，签名的桌面构建和安装/升级在发布之前在每个操作系统上运行，并且源安装现在默认从一个版本移动到另一个版本，而不是跟踪 main 上的每个提交。更喜欢前沿？ hermes update --set-channel main，或桌面设置→关于中的新频道开关。迁移到旧版本被标记为回滚，并且在没有询问的情况下永远不会发生，并且安装程序重新运行会让您保持在您选择的频道上。 (#102765、#135847、#135949、#136313、#137780 — @ethernet8023、@KoNit-K)

  • 签名的桌面包、Microsoft Store 和一个包管理器 — 桌面应用程序现在是一个密封的签名包，带有自己的 Python 和 Node 并进行自我更新，因此第一次启动不会构建任何内容。 Windows 通过 App Installer 或 Microsoft Store 获取签名的 MSIX（x64 和 ARM64）； macOS 获得了 Apple Silicon 的签名、公证版本。在下面，一个新的统一包管理器 (hermes pm) 拥有每个固定的、经过哈希检查的工具和 Python 环境：更新构建一个新环境，并且仅在通过检查后才进行切换，因此失败或终止的更新不会再让您半应用。 (#102765、#132361、#132386、#120339、#122221 — @ethernet8023)

  • 插件目录：600 个经过审核的插件 — 插件目录在本周期启动，并增长到 600 个条目，每个条目都固定到经过审核的提交，并可从 Hermes Desktop 或 CLI 安装。按类别和星级排名浏览每个插件和每个作者的页面；目录规则阻止列出的插件修补 Hermes 内部或发送不可扫描的二进制文件。内存提供商现在与他们的制造商（Honcho、Supermemory、Hindsight、Mem0、OpenViking、Holographic）共存，Home Assistant、Spotify 和 Langfuse 也是如此：现有用户会自动迁移，默认安装也变得更加精简。 (#69446、#111415、#117808、#113381、#114732、 #131267、#132476、#136436 — @itpartypattaya、@happy5318 和 400 多个插件作者）

  • Claude 5.5 和 GPT-6 模型波 — Claude Fable 5.1、Opus 5.5、Sonnet 5.5 和 Haiku 5.5、GPT-6 Astra、Sol 和 Luna 加 GPT-6.1 Sol 和 Gemini 4 Argon 可在 Nous Portal、OpenRouter 和本地路线上选择哪里提供。现在默认情况下，每个可以读取它的提供者都会重播先前的推理，跨简历、分支和压缩，因此长时间的多步骤工作可以保持其思路。当提供者遇到困难时，Hermes 会在可见的有界周期中等待短暂的 503/529/超时，而不是结束你的回合。 (#100577、#119304、#126842、#134759、#128248、 #137955、#136358、#116353 — @kshitijk4poor、@unsupportedpastels、@100yenadmin、@mssteuer、@xxxigm)

  • 使用密码管理器登录网站 — 浏览器代理可以通过 1Password、Bitwarden 或 Hermes 自己的加密保管库登录来登录网站，并且模型永远不会看到密码。如果未保存任何内容，您会在 CLI、TUI 或桌面中收到保存提示，无需进入对话即可填写一次性代码，结帐时填写的卡和地址需要您确认。 (#106480、#107585、#137084)

  • 机器人屏幕：观察您的机器人工作，在需要时接管 — 在 Linux 网关上运行的机器人可以拥有自己的桌面，Hermes 桌面可以实时流式传输。当它出现登录、2FA 提示或验证码时，您将占据屏幕，自己完成该步骤，然后在机器人继续进行会话时收回控制权。通过 Docker、SSH 或 Singularity 后端，机器人的屏幕、计算机使用和浏览器在沙箱内运行，而不是在您的主机上运行。 (#108914、#121169、#121110)

  • 每个配置文件一个后端和一个网关 — Hermes 现在每台机器运行一个消息网关和一个桌面后端来为您的所有配置文件提供服务，而不是每个配置文件一个进程。创建配置文件使其机器人无需重新启动即可运行，每个配置文件都保留自己的凭据、白名单、cron 作业和会话，并且 hermes update 会自动迁移现有的每个配置文件设置。更少的进程，没有令牌冲突，启动和停止都是一件事。 (#112854、#108928、#118273、#117983、#118246、 #118027)

  • 实时查看和引导您的子代理 — 运行的子代理现在在 CLI (F6)、TUI (Ctrl+T) 和桌面中的作曲家上方保持可见，其中包含每个孩子的任务、经过的时间和实时记录，以及“转向”和“停止”按钮。 /stop 可以到达后台儿童并交回他们的部分工作，而 delegate_task 可以将屏幕截图和模拟传递给有视力的儿童。 (#105593、#115616、#97689)

  • 了解您计划的模型选择器 — 为您最喜爱的模型加注星标，查看订阅量低（“剩余 17% · 下午 3:00 重置”）以及速率限制何时在选择器中解除，并在 hermes model、/model (/model X --reasoning high) 和桌面中选择推理工作作为选择模型的一部分。你可以在撞墙之前而不是撞墙之后切换。 (#126535、#133392、#133408、#110346、#113117 — @OutThisLife、@anotherchu)

  • Hermes 以您的语言，无处不在 — CLI、消息网关、TUI 和桌面中每个面向用户的字符串现在都会经过一个翻译目录，全面覆盖所有 16 种捆绑语言。新语言可以作为插件发布，任何配置文件都可以使用小 YAML 文件覆盖单个字符串。 (#126296)

  • 在各个方面都更加精简 - 整个代码库得到了简化，行为变化为零：源代码从大约 106 万行减少到 698K 行 (−34%)，gateway/run.py 从 34,847 行缩减到 5,512 行。提示也变得更轻：大约 19 个很少使用的工具现在仅在代理搜索时加载，大致将每次调用时发送的桌面工具架构减半，另外约 2.1k 令牌来自固定提示。本地模型每次都会预填充较少的数据。 (#102117、#97979、#106676、#137084 — @alt-glitch)

  • 加起来的小舒适 - CLI 提示中的选择加入 vim 键、状态栏中的 git-branch 字段、Hermes 等待您时的铃声和桌面通知、清除草稿而不是杀死回合的 Ctrl+C、可编辑的 /queue 和 hermes --native 让您自己的终端处理 TUI 滚动和搜索。在桌面上，新的 简单 模式将应用程序变成一个普通的聊天窗口，并且错误现在会说明 one-click 修复出了什么问题。 (#106412、#106434、#101284、#101320、#137065、 #95999、#121035、#118587、#111601 — @saforem2、@TurgutKural、@glitchbunny0、@harshmoney123、@pierrenode、 @abhinav11082001-stack，@OutThisLife）

⚠️ 升级说明

  • Python 3.14 是托管安装的运行时（包管理器为您安装它）。 KittenTTS 在 3.14 上不可用。 (#102765)
  • Windows 桌面仅限 MSIX，需要 Windows 11 22H2 或更高版本； NSIS/MSI 安装程序消失了。 macOS 应用程序仅在默认版本中是 Apple Silicon。 （[#102765]（https://github.com/NousResearch/hermes-agent/pull/102765），[#136603]（https://github.com/NousResearch/hermes-agent/pull/136603））
  • 默认每台机器一个网关。 当没有冲突时，hermes update 将每个配置文件网关折叠到多路复用默认网关中。 (#112854)
  • 聊天不再在空闲/每日计时器上重置。 session_reset 空闲/每日模式已停用（仍然设置它们的配置会记录警告）； /new 或 /reset 全新开始。 （[#105021]（https://github.com/NousResearch/hermes-agent/pull/105021），[#126244]（https://github.com/NousResearch/hermes-agent/pull/126244））
  • 旧会话会自动修剪。 sessions.auto_prune 现在默认为打开：90 天不活动的结束会话将在启动时删除。固定和打开的会话永远不会被触及；设置 sessions.auto_prune: false 保留所有内容。
  • 内存提供商转向目录插件（Honcho、Supermemory、Hindsight、Mem0、OpenViking、Holographic），Home Assistant、Spotify 和 Langfuse 也是如此。现有用户会在更新或首次启动时迁移，且数据完好无损。 ByteRover 和 RetainDB 仍然捆绑在一起。
  • **插件作者：**旧的插件兼容性导入层已消失（#126164），hermes sync（技能同步）已删除（#132465），并且捆绑的提力扫描仪已删除（#133832）。多个工具被重命名（todo → todo_list、cronjob → cronjob_manage、process → process_manage）；旧名称仍然有效。 (#97979)

🚪 入门、免费套餐、连接器和本地模型

首次运行入门

  • 全新桌面安装上的引导设置聊天 （请参阅亮点）。现有安装和远程（SSH、URL、云）后端不会自动获取它；旧的设置配置文件流和 /initiate-setup 被删除。 (#137420、#134215、#108292 — @alt-glitch、@ethernet8023、@OutThisLife)
  • 代理可以重新设计应用程序 - 新的 set_theme 工具设置重音（样本或任何 #rrggbb）、亮/暗/系统模式和布局，或显示选择器； “让它变成紫罗兰色”适用于任何桌面聊天。 (#137522 — @alt-glitch)

Nous 免费套餐

  • 首次桌面启动的免费模型 — 无需提供商或 Nous 帐户的首次桌面安装即可获得免费的 nous/welcome 模型作为一次性试用版（每个操作系统用户一次），因此入门不需要密钥。 CLI、TUI 和网关没有帐户或免费模型。 HERMES_GUEST_ONBOARDING 不见了。 (#137807、#105258、#105260 — @alt-glitch)
  • 登录并保留您的应用程序 — 任何聊天或消息传递 DM 中的 hermes auth upgrade 或 /login 均可将免费身份升级为包含您连接的应用程序的完整 Nous 帐户。 (#105259、#105261 — @alt-glitch)
  • 明确限制 — 免费速率限制随着重置时间立即结束回合；每个免费层故障都有一个代码和一个简单的句子；该应用程序处理帐户服务的浏览器检查；免费套餐用户会看到条款和隐私声明。没有积分的 Nous 帐户可以选择按其持有的订阅计费的模型，并获得免费管理的快速网络搜索。 (#134049、#111970、#133824、#117079 — @alt-glitch、@kshitijk4poor、@rewbs)

连接器

  • 托管应用程序连接器、连接器页面和每个应用程序的多个帐户 （请参阅亮点）。连接器工具还可以将本地文件作为附件发送并保存它们返回的文件。 nous.guest: false 关闭访客身份； tools.connectors.enabled: false 关闭连接器。 (#111238、#138014 — @alt-glitch)
  • 到处都有一个连接流 — 托管应用程序和本地 MCP 服务器共享一张设置卡（桌面对话框、TUI 标注或 CLI 面板），并且代理可以同时使用新工具。在桌面上，manage_connections 可以显示可浏览的应用程序目录。 (#111008、#109517、#137426 — @alt-glitch)

本地模特

  • One-click 本地型号 （参见亮点）。另外：Hugging Face GGUF 下载具有暂停/恢复功能，以及在可以运行推荐模型的机器上安装后提供一次性安装优惠。 (#129506 — @alt-glitch)
  • 引擎更新和更广泛的 GPU 支持 — 立即更新提示更新 click 中的引擎。 Linux 上的 NVIDIA 获得 CUDA，AMD 和 Intel GPU 获得由自己的内存调整大小的 Vulkan，每个后端都运行 llama.cpp b11370。 (#111423、#133111、#131782 — @jquesnelle、@skyecon、@mbeattietex1-star、@Belaquaa)
  • 更好的推荐 — 仅推荐完全适合 GPU 内存的型号，并且 27B 不再适用于运行性能不佳的硬件。 Qwen3.8 Flash Next 带有 MTP 头，适合 128 GB 机器； NVIDIA Spark 建议已调整。 (#108429、#135438、#134116、#112107 — @jquesnelle、@RyanUnderhill)
  • 您自己的本地服务器 — LM Studio 具有提供商配置文件，Ollama 选择器不再闪烁，自启动的 llama.cpp 服务器显示在 /model 中，并且可以回退到桌面管理模型。 (#134320、#113129、#116679、#131795 — @kshitijk4poor、@DaxLee9988、@fangliquanflq、@Finn763、 @albeight）

📦 稳定版本、桌面包和包管理器

稳定的发布和更新渠道

  • 经过测试的 SemVer 稳定版本和通道切换 （参见亮点）。 v0.21.6和v0.21.7率先通过新登机口；分叉保留在 main 上，最新版本之前的安装等待下一个版本。
  • 更轻松的更新检查 — 每天调用一次 GitHub API，每 30 分钟替换一次 git fetch。 (#107648)

桌面捆绑包和 Microsoft Store

  • 密封、签名的桌面包 （参见亮点）。在软件包中，hermes update 指向正确的更新程序（应用程序安装程序、商店或 macOS）。 (#134911)
  • 打包安装端到端工作 - 代理的终端运行 hermes，卸载解释操作系统删除，Python 依赖插件安装在 MSIX 内。 (#134051、#135333 — @alt-glitch)

统一的包管理器

  • hermes pm （参见亮点）：Windows 上固定、哈希检查的 Python 3.14、uv、Node、ripgrep、FFmpeg、Chromium 和 Git/Bash，以及 hermes pm doctor|status|repair|gc。贡献者使用 source ./activate（或 .ps1/.fish）。
  • 依赖环境是一代 - 新环境在使用前会被检查，因此失败的安装会保留工作环境；更新并 hermes pm gc 回收旧的（一台主机上 92 GB 到 18 GB）。 (#124968、#133808 — @JoaoMarcos44)
  • 首次使用时安装可选功能 — 选择加入 SDKs（Anthropic、Bedrock）在会话中加载，无需重新启动； security.allow_lazy_installs: false 将其关闭。 (#122221 — @ethernet8023)
  • 插件声明 Python 依赖项 — 通过跨配置文件的核心进行解决；冲突被拒绝，更新禁用不再适合的插件。 Hindsight、Honcho、Supermemory、Mem0 和 Home Assistant 已移至目录并在使用时自动安装。 (#113851、#122103、#114569、#132469 — @ethernet8023)

安装和更新

  • 更新不能半应用 （参见亮点）。被终止的更新会在下次启动时自行修复。 （[#132361]（https://github.com/NousResearch/hermes-agent/pull/132361），[#120339]（https://github.com/NousResearch/hermes-agent/pull/120339））
  • 更快的更新，更小的结帐 - 更新仅重建发生变化的内容（macOS 上的 16.5 与 32.5 ），克隆是无斑点的，并且部分克隆 .git 增长是固定的。 (#135092、#133016、#131679 — @kshitijk4poor、@ethernet8023、@liuhao1024、@whyyagswhy)
  • 小型、经过哈希检查的安装程序 — install.sh/install.ps1 验证固定的 uv 和 Git，移交给 PM，登录到 logs/install.log，现在可以在 musl Linux（Alpine、Void）、Windows 10 和 Unicode Windows 路径上工作。 (#124964、#125598、#132430 — @JoaoMarcos44、@kshitijk4poor、@Finn763、@OutThisLife)
  • 失败说明原因 - 通过选择遥测、安装、更新、技能和插件失败记录原因。 (#133809)
