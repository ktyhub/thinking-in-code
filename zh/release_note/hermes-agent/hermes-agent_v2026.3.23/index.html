hermes-agent v2026.3.23

#爱马仕代理v0.4.0(v2026.3.23) 发布日期： 2026 年 3 月 23 日

平台扩展版本 — 兼容 OpenAI 的 API 服务器、6 个新的消息传递适配器、4 个新的推理提供程序、使用 OAuth 2.1 进行 MCP 服务器管理、@ 上下文引用、网关提示缓存、默认启用流式传输以及包含 200 多个错误修复的全面可靠性传递。

✨ 亮点

  • OpenAI 兼容的 API 服务器 — 将 Hermes 公开为 /v1/chat/completions 端点，并使用新的 /api/jobs REST API 进行 cron 作业管理，通过输入限制、字段白名单、SQLite 支持的响应持久性和 CORS 源保护进行强化（#1756、#2450、 #2456、#2451、#2472)
  • 6 个新的消息平台适配器 - Signal、DingTalk、SMS (Twilio)、Mattermost、Matrix 和 Webhook 适配器加入 Telegram、Discord 和 WhatsApp。网关自动重新连接具有指数退避功能的失败平台（#2206、#1685、#1688、#1683、#2166、#2584)
  • @ 上下文引用 — Claude 代码风格的 @file 和 @url 上下文注入，在 CLI 中使用制表符补全（#2343、#2482）
  • 4 个新的推理提供程序 — GitHub Copilot（OAuth + 令牌验证）、阿里云/DashScope、Kilo Code 和 OpenCode Zen/Go（#1924、#1879 by @mchzimm、#1673、 #1666、#1650)
  • MCP 服务器管理 CLI — 用于使用完整 OAuth 2.1 PKCE 流程安装、配置和验证 MCP 服务器的 hermes mcp 命令 (#2465)
  • 网关提示缓存 - 缓存每个会话的 AIAgent 实例，轮流保留人工提示缓存，以显着降低长时间对话的成本（#2282、#2284、#2361）
  • 上下文压缩大修 - 具有迭代更新、令牌预算尾部保护、可配置摘要端点和回退模型支持的结构化摘要（#2323、#1727、#2224）
  • 默认启用流式传输 — 默认情况下，CLI 流式传输，在流式传输模式下具有适当的微调器/工具进度显示，以及广泛的换行符和连接修复（#2340、#2161、#2258）
