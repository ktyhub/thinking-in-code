hermes-agent v2026.4.8

#爱马仕代理v0.8.0(v2026.4.8) 发布日期： 2026 年 4 月 8 日

情报发布 — 后台任务自动通知、Nous Portal 上的免费 MiMo v2 Pro、跨所有平台的实时模型切换、自我优化的 GPT/Codex 指导、原生 Google AI Studio、智能不活动超时、批准按钮、MCP OAuth 2.1 以及 209 个合并 PR，其中 82 个已解决问题。

✨ 亮点

  • 后台进程自动通知 (notify_on_complete) — 后台任务现在可以在完成时自动通知代理。启动一个长期运行的流程（AI 模型训练、测试套件、部署、构建），代理会在完成时收到通知 - 无需轮询。代理可以继续处理其他事情并在着陆时获取结果。 (#5779)
  • Nous Portal 上免费的小米 MiMo v2 Pro — Nous Portal 现在支持用于辅助任务（压缩、视觉、摘要）的免费小米 MiMo v2 Pro 模型，并在模型选择中提供免费模型门控和定价显示。 （[#6018]（https://github.com/NousResearch/hermes-agent/pull/6018），[#5880]（https://github.com/NousResearch/hermes-agent/pull/5880））
  • 实时模型切换（/model 命令） — 在 CLI、Telegram、Discord、Slack 或任何网关平台的会话中切换模型和提供商。聚合器感知的解决方案让您尽可能使用 OpenRouter/Nous，并在需要时自动跨提供商回退。 Telegram 和 Discord 上的交互式模型选择器带有内嵌按钮。 （[#5181]（https://github.com/NousResearch/hermes-agent/pull/5181），[#5742]（https://github.com/NousResearch/hermes-agent/pull/5742））
  • 自我优化的 GPT/Codex 工具使用指南 — 代理通过自动行为基准测试诊断并修补了 GPT 和 Codex 工具调用中的 5 种故障模式，显着提高了 OpenAI 模型的可靠性。包括执行纪律指导和结构化推理的仅思考预填充延续。 (#6120、#5414、#5931)
  • Google AI Studio (Gemini) 原生提供商 — 通过 Google 的 AI Studio API 直接访问 Gemini 模型。包括自动 models.dev 注册表集成，用于跨任何提供程序进行实时上下文长度检测。 (#5577)
  • 基于不活动的代理超时 — 网关和 cron 超时现在跟踪实际的工具活动而不是挂钟时间。正在积极工作的长时间运行的任务永远不会被杀死——只有真正空闲的代理才会超时。 （[#5389]（https://github.com/NousResearch/hermes-agent/pull/5389），[#5440]（https://github.com/NousResearch/hermes-agent/pull/5440））
  • Slack 和 Telegram 上的批准按钮 — 通过本机平台按钮而不是键入 /approve 进行危险命令批准。 Slack 获得线程上下文保存； Telegram 可以通过表情符号反应来表示批准状态。 （[#5890]（https://github.com/NousResearch/hermes-agent/pull/5890），[#5975]（https://github.com/NousResearch/hermes-agent/pull/5975））
  • MCP OAuth 2.1 PKCE + OSV 恶意软件扫描 — 用于 MCP 服务器身份验证的完全符合标准的 OAuth，以及通过 OSV 漏洞数据库对 MCP 扩展包进行自动恶意软件扫描。 （[#5420]（https://github.com/NousResearch/hermes-agent/pull/5420），[#5305]（https://github.com/NousResearch/hermes-agent/pull/5305））
  • 集中日志记录和配置验证 — 使用 hermes logs 命令将结构化日志记录到 ~/.hermes/logs/（agent.log + error.log），以进行尾随和过滤。配置结构验证在启动时捕获格式错误的 YAML，然后再导致神秘的故障。 （[#5430]（https://github.com/NousResearch/hermes-agent/pull/5430），[#5426]（https://github.com/NousResearch/hermes-agent/pull/5426））
  • 插件系统扩展 — 插件现在可以注册 CLI 子命令，接收具有相关 ID 的请求范围的 API 挂钩，在安装过程中提示所需的环境变量，并挂钩到会话生命周期事件（最终确定/重置）。 (#5295、#5427、#5470、#6129)
  • Matrix 第 1 层和平台强化 — Matrix 获得反应、阅读回执、丰富的格式和房间管理。 Discord 添加了频道控制和忽略频道。信号获得完整的媒体：标签传递。 Mattermost 获取文件附件。跨所有平台的全面可靠性修复。 (#5275、#5975、#5602)
  • 安全强化通行证 — 整合 SSRF 保护、定时攻击缓解、tar 遍历预防、凭证泄漏防护、cron 路径遍历强化和跨会话隔离。所有后端的终端工作目录清理。 (#5944、#5613、#5629)
