hermes-agent v0.22.2

#爱马仕代理v0.22.2

发布日期： 2026 年 10 月 15 日

v0.22.1 是根据错误的提交构建的。它提供了未发布的网关工作，并且 Microsoft Store 应用程序可以坚持“正在连接”。 0.22.2 是 0.22.1 的预期版本。

已知问题： 在 0.22.1 网关下运行的会话无法在 0.22.2 中删除。

亮点

  • 网关在重新启动后再次启动。 重新启动后，Linux 可以将早期的 PID 交给不相关的进程，网关可能会将其误认为是正在运行的网关，因此受监督的网关（systemd、launchd、Docker）拒绝启动。 Hermes 现在会记录它启动的启动情况，当它无法判断时，它会询问主机锁，只有实时网关才拥有该主机锁。 （#138594，修复#133744）
  • 长本地模型轮流在笔记本电脑上生存。 本地请求始终以提示读取进度进行流式传输（在状态行中显示），停顿计时器会跳过机器休眠的时间，恢复的本地服务器会进行另一次尝试，而不是在以后的每条消息中都失败的断路器，并且当服务器仍在读取长对话时，压缩不再超时。在 Windows 统一内存计算机上，模型启动和提示缓存的大小可用于释放内存。 (#138560)

以下是自 v0.22.0 以来 0.22 发布系列中的所有内容：0.22.1 原本要发布的修复程序以及上面的两个修复程序。仅在 main 上进行的工作随 v0.23.0 一起提供。
