xiaozhi-esp32 v2.5.0

发生了什么变化

  • 壮举：在 https://github.com/78/xiaozhi-esp32/pull/2030 中添加 @Father001 的 wk esp32s3 开发板 *修复：在https://github.com/78/xiaozhi-esp32/pull/2175中恢复@78的WDMomo CGC LCD选择
  • 内容 : 在 https://github.com/78/xiaozhi-esp32/pull/2174 中添加 @shunian11 的waveshare esp32-c6-epaper-1.54
  • 在 https://github.com/78/xiaozhi-esp32/pull/2180 中添加 @ChanchalSakardeQH 的马拉地语 (mr-IN) 印度语言支持
  • feat(m5stack-stopwatch): 支持https://github.com/78/xiaozhi-esp32/pull/2189中@suflanker的显示亮度控制
  • 修复(lichuang-dev): 当 https://github.com/78/xiaozhi-esp32/pull/2204 中 @sebastjanb 缺少 FT5x06 触摸控制器时不会崩溃
  • 在https://github.com/78/xiaozhi-esp32/pull/2191中添加@78的流式通知播放 *修复（otto）：通过https://github.com/78/xiaozhi-esp32/pull/2219中的@txp666从GPIO带检测相机板
  • 修复（df-k10）：通过https://github.com/78/xiaozhi-esp32/pull/2222中的@max-power将self.led_strip.scroll长度钳位到实际LED计数
  • 通过 https://github.com/78/xiaozhi-esp32/pull/2225 中的 @max-power 修复大端 RGB565 传感器 (RGB565X) 的相机格式协商
  • 修复（led）：https://github.com/78/xiaozhi-esp32/pull/2221 中 @max-power 范围 CircularStrip 效果状态到实例 *修复（显示）：在分钟变化时重绘空闲时钟，而不是https://github.com/78/xiaozhi-esp32/pull/2224中@max-power的共享时间戳
  • 修复（构建）：通过 https://github.com/78/xiaozhi-esp32/pull/2211 中的 @zfkun 在 Windows 上正确调用 ESP-IDF idf.py
  • xpowers：通过 https://github.com/78/xiaozhi-esp32/pull/2237 中的 @JackHuang021 在 I2cDevice 上添加通用 PMU 包装器
  • feat(board)：新增 FoloToy AI Passport (ESP32-C3) 板卡支持，由 @Shinku-Chen 在 https://github.com/78/xiaozhi-esp32/pull/2236 中提供
  • 修复（esp-hi）：适应 4MB 资源并在 https://github.com/78/xiaozhi-esp32/pull/2238 中恢复 @78 和 @Copilot 启动的 ST7735
  • 在https://github.com/78/xiaozhi-esp32/pull/2185中添加@epaper1为小智设计的Maza AI板
  • 在 https://github.com/78/xiaozhi-esp32/pull/2243 中添加 @mederix 的 pt-BR（巴西葡萄牙语）语言环境
  • 修复（构建）：拒绝 https://github.com/78/xiaozhi-esp32/pull/2240 中 @QiuLsG 不匹配的板配置
  • 修复 https://github.com/78/xiaozhi-esp32/pull/2227 中 @78 检测 M5Stack Tab5 ST7121/ST7123 显示的问题
  • 通过 @3em0 在 https://github.com/78/xiaozhi-esp32/pull/2021 中将 Otto MCP 响应绑定到原始 WebSocket client
  • 壮举（显示）：在 https://github.com/78/xiaozhi-esp32/pull/2195 中通过 @Vitalymt 在省电模式下关闭 OLED 面板
  • feat: 通过 https://github.com/78/xiaozhi-esp32/pull/1847 中的@quantumnic 将字符串 max_length 验证和 JSON-RPC 错误代码添加到 MCP 服务器
  • 在https://github.com/78/xiaozhi-esp32/pull/2246中通过@78禁用C++异常并将ESP32-S31固件保留在4MB OTA插槽中
