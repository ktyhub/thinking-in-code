LightRAG v1.5.7

重要提示

新功能：向 WebUI 添加面向最终用户的入口点

v1.5.7 添加了第二个面向最终用户的条目 - /workspace - 以及部署需要的品牌和提示控制，然后才能将其交给真正的用户。

  • 最终用户仅供查询的条目：/workspace
  • 可定制的欢迎、登录和空状态页面
  • 全局 USER_PROMPT_PREFIX

/workspace UI 显示聊天界面，仅显示聊天界面 - 没有文档管理，没有知识图，没有 API-docs 链接 - 并且专为移动使用而构建。将 UI_TEMPLATES_DIR 指向 Markdown 文件的小目录加上 manifest.json，LightRAG 会以多种语言提供 您的 欢迎页面、登录页面简介、查询空状态、品牌徽标和版权行，而无需重建 WebUI。声明登录简介和协议文档的区域设置也会打开登录同意复选框。准备复制的捆绑包以 docs/ui_templates_example/ 形式发货。

USER_PROMPT_PREFIX（或 USER_PROMPT_PREFIX_FILE 表示长的多段落文本）将部署范围的指令添加到每个请求的 user_prompt 之前。它为操作员提供了一个位置来为 UI 条目和 API 等设置 LLM 的角色、语气和输出格式（美人鱼图、LaTeX 分隔符、引文样式）。请求永远无法读取或替换它；只有 API 字段 disable_user_prompt_prefix 选择退出。

更多信息请参考：

  • docs/LightRAG-API-Server.md — § /workspace 查询条目
  • docs/UserDefinedUI.md — 完整的 UI 定制指南，加上 docs/ui_templates_example/
  • README.md — USER_PROMPT_PREFIX / USER_PROMPT_PREFIX_FILE
