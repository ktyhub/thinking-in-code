agentscope v2.0.9

修订 发布时间2026年9月28日 来源agentscope-ai/agentscope 英文原文

agentscope v2.0.9

突出显示

  • 标准操作程序（实验性）：添加了 agentscope.sop 模块，用于将任务拆分为有序的里程碑，每个里程碑在下一个里程碑开始之前进行验证，并且运行状态可以保留和恢复。代理服务还公开 /sop 端点来存储过程、启动运行和手动检查步骤。
  • 团队管道：添加了一个 TeamPipeline 类，其中领导代理将任务委托给成员代理，成员代理同时运行并将结果返回。
  • 更多实时语音模型：向实时语音代理添加了 OpenAI Realtime、Gemini Live 和 xAI Grok 语音模型。
  • 终端 UI：引入了 agentscope.tui 模块，这是一个全屏终端界面，用于与代理聊天并通过 launch_realtime_ui 运行实时语音会话。
  • 询问用户工具：添加了 AskUser，这是一种外部工具，可让代理向用户询问多项选择题。
  • MiniMax 模型和基于 Jev 的模型路由：添加了 MiniMax 聊天模型（默认为 M3），以及由新的 agentscope.classifier 模块（支持 Jev）支持的 ModelRouterMiddleware，该模块为每个回复选择聊天模型。
  • 钉钉知识库工具：钉钉渠道的客服人员现在可以搜索钉钉知识库。
  • 更安全的 Shell 权限检查：加强只读命令检测，因此破坏性的 git、sed 和 tee 使用不再跳过权限确认。
