代理

  • 支持 OpenSandbox (#1953)、Daytona (#1943)、K8s (#1933)、Bubblewrap (#2051)

  • 支持 Windows 的 PowerShell (#2132)

抹布

  • 支持 MongoDB (#2008)、Elasticsearch (#2129)

代理即服务

  • 支持基于 SQLAlchemy 的存储 (#2029)

  • 支持作为一个组或组织在用户之间共享资源 (#1998)

型号

  • 添加新的 Dashscope 型号 (#2073)、Kimi K3 (#2141)
  • 实施 Gemini TTS API (#1879)
