agentscope v2.0.8

修订 发布时间2026年9月8日 来源agentscope-ai/agentscope 英文原文

agentscope v2.0.8

突出显示

  • 实时语音代理：引入了具有 DashScope 后端和本地传输支持的实时语音代理。
  • A2A 协议支持：向代理模块添加了 A2AAgent 类，支持代理之间的通信。
  • 新管道模块：添加了一个带有 GoalPipeline 类的新管道模块，用于目标驱动的代理工作流程。
  • 代理驱动的上下文压缩：引入了上下文压缩工具，允许代理管理自己的上下文窗口。
  • RAG 的 LLM 重新排名：添加了基于 LLM 的重新排名支持，以提高 RAG 检索质量。
  • Volcengine Ark 模型：添加了对 Volcengine Ark 聊天模型的支持。
  • MCP 增强：支持 Docker 工作区中的运行时 MCP 标头并改进了 MCP 连接清理。
  • Web UI 优化：聊天体验改进，包括会话自动命名、查询缓存和更好的暗模式支持。
