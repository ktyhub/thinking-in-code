shenyu v2.7.0

#神宇v2.7.0

[v2.7.0]

✨ 新功能

1.将dockerfile java运行时版本8升级到17 2.将SpringBoot升级到3.x 3. 支持神宇管理集群 4.将checkstyle插件升级到3.4.0 5.数据源支持OceanBase 6.支持批量修改选择器/规则状态 7.支持批量修改PathAuth状态 8.升级apache dubbo版本 9.支持Contribute with Gitpod 10.支持配置导出和导入 11.添加神宇client心跳 12. 支持命名空间 13.支持k8s动态扩展 14. 通过实施 Client ID 验证使新登录时先前的令牌失效 15、divide-plugin支持灰度发布 16.支持Kubernetes注册表 17. 添加 shenyu-plugin-wasm

⚡增强

1.添加rocketmq日志e2e测试 2.增强metrics-ratelimiter收集 3. 增强 Sentinel、Resilience4j 和 Hystrix 的指标收集 4.整理沙发常用工具依赖 5.删除过期评论 6. 添加缺少的许可证 7. 设置在Kafka上发送消息的回调 8.使用Dubbo元数据中的负载均衡配置 9. 为从 select 获取的上游添加非空验证 10.设置规则句柄到dubbo rpc上下文的超时时间 11.启用选择器和规则时发布事件 12. 从 NAMESPACE_SESSION_MAP 中删除已关闭的会话 13.为ShenyuClientURIExecutorSubscriber添加测试用例 14.添加ShenyuClientIllegalArgumentException的测试用例 15.添加ShenyuClientRegisterEventPublisher测试用例 16.添加ShenyuClientMetadataExecutorSubscriber测试用例 17.添加AbstractWasmPluginDataHandler测试用例 18.添加ShenyuClientRegisterRepositoryFactoryTest测试用例 19.添加AbstractWasmDiscoveryHandler测试用例 20.升级沙发rpc版本支持 21.将Sign插件的header key添加到CrossFilter配置中 22.加密密码 23.添加AbstractShenyuWasmPluginTest 24. RewritePlugin/ContextPathPlugin支持跨应用程序和插件 25.删除重复路径检查 26. 删除阿里巴巴Dubbo支持 27.支持docker环境设置http路径 28.添加一些代码重构改进 29.支持从cookie\header\param获取token 30、使ShenyuDubboService注解的默认值等于DubboService注解的默认值 31.将db脚本添加到admin包中 32. 摆脱死代码并添加一些改进 33.MotanServiceEventListener测试用例优化 34、删除shenyu-registry-eureka.xml中重复的maven 35.更新了Jwt依赖项 36.打印插件执行时间 37. Discovery Local在Admin中支持上游健康检查 38.关闭规则缓存 39. 减少并发量 40.优化逻辑避免“orElse”执行，更新VersionTwoExtractor.java

♻️重构

  1. spring-integration-jdbc管理分布式锁
  2. 重构beanUtils 3.删除macos ci 4.更新日志记录插件DataBuffer已弃用的方法 5.修改e2e k8s为docker compose
  3. 将 Admin swagger 从 springfox 迁移到 springdoc 7.重构springcloud插件 8.重构一些代码
  4. 删除SO_SNDBUF & SO_RCVBUF
  5. 重构 Shenyu-sync-data-http ：替换 log %s -> {}。 11.优化节点类型监听器 12.重构插件生命周期 13、调整代码顺序，去除无效输入参数

🐛错误修复

1.修复请求插件的重复标头 2.修复删除divideselector时proxy.selector和discovery不删除的问题 3.修复LoggingPlugin错误日志捕获 4.修复日志插件示例bug 5.修复内存溢出 6.修复重写集成测试 7. 修复 AbstractWasmPluginDataHandlerTest 8.修复sql-script/h2/schema.sql中缺少主键 9.修复数据字典页面数据排序异常 10.修复文档错误 11.解决上下文路径更新后仪表板路由不匹配的问题 12.修复etcd同步配置问题 13.修复consul同步问题 14.修复未注册无法查询的bug 15.通过更正插件 ID 查询和更新数据类型来修复插件编辑页面问题 16.修复类AdminConstants有单词拼写错误 17.修复 shenyu-examples-springmvc 启动失败问题 18.修复仪表板菜单子项排序不起作用的问题 19.修复 ShenyuApacheDubboXmlProviderApplication 配置 20.修复代理选择器和发现的数据同步dataId不唯一 21.过滤禁用字典选项 22.修复SpringCloudParser MetaData空数据 23.修复client寄存器验证 24、配置dubboserialize-check-status=DISABLE 25.修复示例TestApacheDubboXmlApplication启动失败 26、修复nacos数据同步模型缺少contextPath配置的问题 27.修复SPI在多线程场景下创建非单例对象的问题 28.修复BadSqlGrammarException 29.修复部分单词拼写错误 30.修复ListUtil->merge异常 31.修复metaData禁用未过滤的问题 32.修复划分日志请求方法 33.修复e2e chunk header错误 34.修复cookie错误和sql检查 35.修复NPE问题 36.修复无效路径错误 37.修复热加载问题 38.修复e2e测试用例无法运行wget命令 39.修复回退问题 40.修复一些ci错误 41.解决rule-sqlmap.xml中的sql错误 42.修复readYmlBuildRepository NPE 43、修复nacos无法在Shenyu-examples-SpringCloud项目中注册的问题 44.修复springCloud规则数据路径设置未使用的问题 45.修复 shenyu-plugin-logging-elasticsearch ：修改 ElasticSearchLogConfig 的 setIndexName 46.修复停止服务时不先从网关离线的问题 47.修复k8s liveness探针无法运行wget命令错误 48.修复AbstractNodeDataSyncService在启动时加载discoverUpstream
