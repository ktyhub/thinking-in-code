incubator-seata v1.5.2

西塔1.5.2发布。

Seata 是一个易于使用、高性能、开源的分布式事务解决方案。

版本更新如下：

###特点：

  • [#4661]支持xid一致性负载均衡
  • [#4676]支持服务器通过挂载SLB来暴露Nacos服务
  • [#4642]支持批量消息并行处理
  • [#4567] 支持where方法条件(find_in_set)

错误修正：

  • [#4515] 修复了数据库未使用时 SeataTCCFenceAutoConfiguration 的错误
  • [#4661] 修复模块控制台中 PostgreSQL 的 sql 异常
  • [#4667] 修复了 RedisTransactionStoreManager 迭代期间更新地图的异常
  • [#4678] 修复密钥传输的错误。enableRmClientBatchSendRequest 缓存穿透如果不配置
  • [#4701] 修复丢失的命令行参数
  • [#4607] 修复跳过锁定检查的错误
  • [#4696] 修复 oracle 数据库插入值
  • [#4726] 修复批量消息发送可能返回 NullPointException
  • [#4729] 修复设置 AspectTransactional.rollbackForClassName 的值错误
  • [#4653] 修复 INSERT_ON_DUPLICATE SQL 中 pk 为非数字时的 sql 异常

###优化：

  • [#4650] 修复一些安全漏洞
  • [#4670] 优化branchResultMessageExecutor的线程池大小
  • [#4662] 优化回滚事务指标
  • [#4693]优化控制台导航栏
  • [#4700] 修复 maven-compiler-plugin 和 maven-resources-plugin 执行失败
  • [#4711] 部署的单独库依赖项
  • [#4720]优化pom描述
  • [#4728] 将 logback 依赖项升级到 1.2.9
  • [#4745] 支持发布包中的 mysql8
  • [#4626] 将 flatten-maven-plugin 替换为 easyj-maven-plugin 以修复 shade 和 flatten 之间的冲突
  • [#4629] 更新全局会话时检查之前状态和之后状态的关系
  • [#4662] 使EnhancedServiceLoader更具可读性

###测试：

  • [#4544] 优化 TransactionContextFilterTest 中的 Jackson 依赖项
  • [#4731] 修复 AsyncWorkerTest 和 LockManagerTest 中 UT 失败的问题

感谢这些贡献者提交的代码。请报告无意的遗漏。
