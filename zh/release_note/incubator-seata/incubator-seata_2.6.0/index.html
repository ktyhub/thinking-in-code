incubator-seata v2.6.0

Apache Seata（孵化中）2.6.0 发布。

Apache Seata(incubating)是一个易于使用、高性能、开源的分布式事务解决方案。

版本更新如下：

特点：

  • [#7485] 为 Seata-server 添加 http 请求过滤器
  • [#7509] 重用连接来合并分支事务
  • [#7492] 升级公共模块中的 HTTP client 以支持 HTTP/2
  • [#7503] 支持 fory 序列化器和 fory undolog 解析器
  • [#7551] XAUtils 添加对 DM 数据库的支持
  • [#7559] 为 TableMetaRefreshHolder 实例引入清理 API
  • [#7669] 添加对 PostgreSQL 数组类型的 Jackson 序列化和反序列化的支持
  • [#7664]支持神通数据库XA模式
  • [#7675] 支持 Oracle 批量插入
  • [#7663] 在 CI 配置文件中添加 Java 25 支持
  • [#7851] 添加对管理事务组的支持
  • [#7857] 支持在控制台显示集群信息
  • [#7826] 支持在 Server Raft 模式下对 Watch API 进行 HTTP/2 响应处理
  • [#7863] 从 JDK 版本低于 25 的构建工作流程中排除命名服务器和控制台模块构建
  • [#7870] 将命名服务器和控制台模块升级到 JDK 25 和 SpringBoot 3.5，并在控制台模块中添加 spring-ai 依赖项。
  • [#7872] 自动计算 JVM 参数的值
  • [#7876]功能：添加MCP自定义配置和验证码
  • [#7878]控制台支持Raft集群事务组的创建和修改
  • [#7893] 添加全局和分支会话以及锁定管理 MCP 工具

错误修复：

  • [#7471] 修复第二阶段回滚中多维数组比较的 SerialArray equals() 方法
  • [#7482] Github Action 工作流程未运行相应的 Kotlin 测试
  • [#7538] 通过 UTC Instant 统一 DmdbTimestamp 比较，以防止回滚失败
  • [#7546] 修复 client spring 版本兼容
  • [#7505] 通过 reconnectExecutor 防止异步通道释放阻塞 Netty I/O 线程
  • [#7563] 修复服务器端过滤器禁用且过滤器链为空时的 NPE。
  • [#7570] 修复 GlobalTransactionalInterceptorHandler 中的 order() 行为，以确保调用处理程序的正确排序
  • [#7596]修复了xss过滤器获取默认关键字时反序列化失败的问题
  • [#7613] 修复了全局锁定查询中日期时间格式时间查询的 SQL 错误
  • [#7622] 调整 org.apache.seata.saga.rm.SagaResourceManage 的顺序
  • [#7624]修复yml配置文件的兼容性问题
  • [#7644]修复java 25时spotless的兼容性问题
  • [#7662] 确保 rm 的可见性和 MockTest 中的方法按顺序执行
  • [#7683] 覆盖 XABranchXid equals() 和 hashCode() 以修复 mysql 驱动程序中的内存泄漏
  • [#7643] 修复 DM 事务回滚不使用数据库自动递增主键的问题
  • [#7708] 使用xaActive判断xaResource是否需要执行end方法
  • [#7747]undo日志表名动态推导
  • [#7749] 修复 Http2HttpHandler 中解析 application/x-www-form-urlencoded 请求时出现的错误
  • [#7761] 特殊处理应用于 Byte[] 类型以确保正确的主键值
  • [#7771] Shentongdata xa 模式应保持相同的连接
  • [#7785]修复失败测试
  • [#7796] 修复 ConsulConfigurationTest 方法上的 NPE
  • [#7839] 解决 TransactionAutoConfiguration 与 Spring Boot 4.x 的兼容性
  • [#7843]修复Dm/KingbaseTableMetaCache中索引类型误判
  • [#7856] 修复 package.json/min-document 中缺少逗号
