incubator-seata v1.5.1

Seata 1.5.1（1.5.0 的发布修复）已发布。

由于 1.5.0 中的插件冲突，seata-all-1.5.0.jar 已发布到中央 Maven 存储库，但存在版本号替换问题。因此，我们紧急发布了1.5.1版本，代码功能与1.5.0完全相同。对于造成的混乱和不便，我们深表歉意。

Seata 是一个易于使用、高性能、开源的分布式事务解决方案。
