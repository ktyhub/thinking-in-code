  • Windows 构建错误 #13081
  • 省略 Databricks Gemini 模型服务的stream_options #12675
  • 过时模型问题 #13054
  • 当提供商报告没有解析模型时显示模型更改 #12914

  • 继承新聊天的活动聊天文件夹 #12941
  • 桌面中绑定长对话渲染 #12976
  • 删除 Bedrock 的 ActionRequired 和 ToolConfirmationRequest 块，而不是发送空白文本 #12843
  • OpenCode Go 和 Zen 中缺少 GLM 模型 #12057
  • 在 goose-acp 中加载实时模型目录 #12962

  • 使用上下文长度 OpenRouter 报告 #12853
  • 上下文冻结保留的消息在压缩期间必须保持用户可见#12692
  • 不要向模型显示压实倒计时 #12902
  • 保持 ACP 中代理模型列表的顺序 #12823
  • 在 OpenAI 响应请求上发送会话 ID 作为 Prompt_cache_key #12420
  • 将 Moonshot 提供商名称映射到 Moonshotai 以进行规范模型查找 #12041
  • 允许 OpenAI 响应流事件上缺少created_at #12241

🔧 改进

  • MCP 工具现在具有提供商安全的公共名称 #12875
  • 使用全局回合限制作为子代理回合限制后备 #12992
  • 优化列表会话数据库查询#12940

  • 将登录 shell 路径留给启动 goose 的人 #12799
