langfuse v4.78.0

发生了什么变化

特点

  • feat(web)：EmptyState，附有 @AbdallahAHO 在 https://github.com/langfuse/langfuse/pull/19864 中绘制的插图
  • 壮举（网络）：@AbdallahAHO 在 https://github.com/langfuse/langfuse/pull/19865 中绘制的带有懒惰产品场景的 LangfuseIllustration
  • feat(topics)：https://github.com/langfuse/langfuse/pull/19947 中 @LysanderKie 在主题设置流程中过滤跟踪
  • feat(rbac)：将成员资格镜像到https://github.com/langfuse/langfuse/pull/19263中@marksalpeter的角色分配中
  • feat(rbac)：添加由 @marksalpeter 在 https://github.com/langfuse/langfuse/pull/19517 中根据用户和密钥策略评估的 USER api 密钥范围
  • feat(web)：始终在组织级别显示 AI Gateway 导航，并从 @wochinge 在 https://github.com/langfuse/langfuse/pull/19977 的项目中链接它
  • feat(events-dispatch)：拥有读取设置并允许 @LysanderKie 在 https://github.com/langfuse/langfuse/pull/19894 中读取 60 秒
  • feat(web)：通过 https://github.com/langfuse/langfuse/pull/19969 中的 @nimarb 将新项目和新组织操作移至切换器标头中
  • 壮举（实验）：通过 @marliessophie 在 https://github.com/langfuse/langfuse/pull/18213 中清理实验列表视图行和工具提示
  • feat(evals): 通过 @wochinge 在 https://github.com/langfuse/langfuse/pull/20001 添加外部 HTTP 代码 eval 调度程序
  • 壮举（ai-gateway）：通过 @wochinge 在 https://github.com/langfuse/langfuse/pull/19999 中使 Bedrock 在每个环境中可用
  • feat(skills)：通过https://github.com/langfuse/langfuse/pull/19996中的@tobi12345通过SKILL.md frontmatter键过滤技能列表
  • feat(topics)：记录@LysanderKie在https://github.com/langfuse/langfuse/pull/20008中的非瞬态主题设置模型测试失败 *壮举（主题）：每晚将每个规则的地图重新调整为连续地图，将手动运行保留为@LysanderKie在https://github.com/langfuse/langfuse/pull/19675中的快照
  • feat(prompts)：在 https://github.com/langfuse/langfuse/pull/20009 中 @tobi12345 的请求范围上标记提示缓存结果
  • feat(scores)：在https://github.com/langfuse/langfuse/pull/19997中通过@marliessophie从添加分数菜单中显示分数配置详细信息 *壮举（ai-gateway）：在各处提供自定义模型并通过@wochinge在https://github.com/langfuse/langfuse/pull/20014中选择他们的连接

修复

  • 修复（web）：从会话中解析force-v3标志，以便v4迁移横幅不会在https://github.com/langfuse/langfuse/pull/19975中由@wochinge闪烁
  • 修复（ai-gateway）：在 https://github.com/langfuse/langfuse/pull/19985 中包装启动横幅描述，而不是由 @marcklingen 截断
  • 修复（web）：将仪表板小部件间隙与 https://github.com/langfuse/langfuse/pull/19988 中的 @nmtrang29 的页面填充相匹配
  • 修复（网络）：从https://github.com/langfuse/langfuse/pull/19987中的@nmtrang29克隆仪表板上的小部件中删除Langfuse徽章
  • 修复(web): 将 V 形部分移动到 https://github.com/langfuse/langfuse/pull/19989 中 @nmtrang29 标题后面
  • 修复（external-media-storage）：将 IAM 角色身份验证显示为升级并遵守 https://github.com/langfuse/langfuse/pull/19992 中 @wochinge 的许可名单
  • 修复（web）：https://github.com/langfuse/langfuse/pull/19995 中的 @wochinge 为仅限网关的成员提供了一条退出 AI 网关的方法
  • 修复（分数）：当https://github.com/langfuse/langfuse/pull/18852中的@marliessophie过滤无效的存储行时发出警告
  • 修复（主题）：通过 @hassiebp 在 https://github.com/langfuse/langfuse/pull/19972 中将 max_completion_tokens 发送到带有自定义基本 URL 的 OpenAI 连接
  • 修复（主题）：将跟踪名称存储在 https://github.com/langfuse/langfuse/pull/20003 中 @LysanderKie 的自动方面摘要上
  • 修复（query-ast）：拒绝 https://github.com/langfuse/langfuse/pull/19971 中 @niklassemmler 具有多个关系的 SELECT 中的不合格列

性能

  • perf(annotation-queues)：首先在 https://github.com/langfuse/langfuse/pull/19949 中 @marliessophie 的排序覆盖索引上按 id 分页队列项目

家务事

  • 修复（deps）：通过 https://github.com/langfuse/langfuse/pull/19973 中的 @nimarb 将 undici 提升到 7.30.2 *修复（deps）：升级AG-UI并删除https://github.com/langfuse/langfuse/pull/19974中@nimarb的provider-utils
  • Chore(query-ast)：@niklassemmler 在 https://github.com/langfuse/langfuse/pull/19807 中对事件谓词进行较低的元数据条件和自由文本搜索
  • 杂务（定价）：在 https://github.com/langfuse/langfuse/pull/20000 中添加@langfuse-bot 的 Claude Fable 5.2 和 Mythos 5.2 默认定价
  • ci：通过 @niklassemmler 在 https://github.com/langfuse/langfuse/pull/19970 中阻止 SQL 等价黄金测试

完整 Changelog：https://github.com/langfuse/langfuse/compare/v4.77.0…v4.78.0
