anything-llm v1.7.4

无代码代理技能构建器已上线 ⚡

大变化

🏗️ 内置的无代码代理流程构建器已上线！

现在，无需一行代码，您就可以无缝地起草和运行_有意义_的代理技能。没有令人困惑的设置 - 只是人工智能技能，完全本地化，并且比 MCP 更容易理解 1000 倍。 阅读有关制作你的第一个技能的文档 ->

PDF 和图像的 OCR 扫描已上线！

现在，当 Anythingllm 收到图像或_非数字化_ PDF 时，我们将自动将文本内容 OCR 到文档中。这是通过正在运行的本地 Tesseract 模型完成的！ 这是 OCR，而不是“视觉”，因此如果内容没有文本 - 将找不到任何内容！ 最后，我们跳过了一些 Docker 版本，使 Docker <=> Desktop 成为相同的发行版本。有两个不同的语义版本令人困惑。他们现在将步调一致地前进。
