anything-llm v1.16.0

显着变化

图像生成

现在，当设置支持的提供程序时，您可以通过 /img 生成图像。

如果您的提供商支持图像编辑，此流程还允许使用图像附件进行编辑、后续操作或组合提示。

代理工具生成图像的能力将在下次更新中提供。

更好的文件选择器用户体验

现在，在文件选择器中，您可以拖动整个文件夹，它们的层次结构将保留在上传面板中。这只会导入文件夹中的 顶级 文件 - 在以后的更新中它将变得更深且递归。

您现在还可以直接将文件拖放到现有文件夹中，而无需移动它。

最后，您不再需要在 URL 获取器中键入 https - 如果省略，它只会假设 https。

我们还针对文件夹中包含数千个文档的情况进行了一些重大性能改进，例如文件夹的延迟加载。

会话中工具切换

现在，在代理聊天期间，您可以随意打开/关闭工具，而无需重新加载或启动新会话。仅已配置的工具（如果需要配置）可用。

停止生成

现在的一个很大的改进是，aborting 响应实际上也完全杀死了推理，这样当中流不再需要时，幽灵推理就不会继续。
