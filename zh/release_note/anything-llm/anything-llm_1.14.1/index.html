anything-llm v1.14.1

会议助手大修

会议助手仅是桌面应用程序

我们对会议助手的大部分进行了彻底改造，使其在所有设备和平台上更小、更快、更高效。

  • 现在支持 Intel、AMD 和 NVIDIA GPU，二进制文件缩小了 92%，处理时间加快了 15%。

    • 如果您已经安装了 NVIDIA GPU 二进制文件，您可以根据需要安全地将其删除。它仍然可以工作并且向后兼容。

  • 支持开发人员 API 进行音频转录（POST：/v1/transcription/transcribe）

  • 会议助手上下文窗口溢出处理现在好多了 - 因此小模型可以总结较长的会议。

  • 引入基本说话人识别，可将任何音频的总结效果提高 60%。

  • 现在为会议提供双通道立体声录音 - 在“完全分类”模式下，发言者识别效果提高 80%。

改进

  • Linux AppImage 现在尺寸缩小了 91%，并缓存 Ollama 引擎下载以加快启动时间。
  • 会议总结后的会议助理标题修复现在会在 UI 中自动更新
  • AgentFLow 变量突出显示，以便清楚什么是有效变量，什么不是有效变量
  • UI 中的“复制聊天链接”，可通过深层链接在桌面/自托管应用程序中快速重新打开聊天。
  • 通过聊天 UI 重新启用音频和视频上传 - 现在使用 Tinyscribe 引擎。
  • 从聊天 UI 将聊天导出为（PDF、JSON、Markdown 等）。
  • 桌面助手设置 - 屏幕截图捕获区域现在可使用高清屏幕截图。
  • 请求批准内部功能现在可用于自定义技能。

错误修复

  • 从 AnythingLLM 中删除了 DPAIS 和 HuggingFace 提供程序（未维护）
  • 修复了嵌入器在服务器进程中不断重新加载导致的内存泄漏
  • 修复了将文件拖放到聊天中且文本已存在于提示中时的文本清除错误。
  • 对长时间运行的聊天的前端 UI 进行了大规模性能改进。
  • Cohere SDK 已删除并移植到 OpenAI SDK 以实现兼容性。
  • 桌面助手捕获区域在 Windows 多显示器设置上不显示。
  • 当分叉有想法的聊天时，从分叉线程名称中去除思考。
  • 修复吐司灯模式始终显示，无论系统主题如何。
  • Mistral 嵌入器编码问题已修复。
  • API 更好的错误消息
  • 忽略 Claude 4.8 的 Claude 基岩中的温度
  • 修复了 web-scraping 服务器进程中的事件发射器泄漏并总结进程
