anything-llm v1.11.1

主页重新设计

AnythingLLM 主主页已完全重新设计，更加现代且用户友好，因此您在入职后打开应用程序后即可立即开始聊天。

原生工具调用

<标注类型=“信息”> 原生工具调用是与您的 LLM 提供商和模型进行工具调用的最佳性能和体验。如果你可以启用它，你应该启用它。 这仅适用于本地 LLM 提供商。它对 OpenAI、Anthropic 或 Azure 等云 LLM 没有影响。 </标注> 我们彻底修改了 @agent 工具调用的工作方式。现在，我们将利用您的 LLM 提供商和模型的新本机工具调用功能。 这对您意味着什么：

  • 您现在可以使用您的 LLM 提供商和模型运行复杂的多步骤工具调用。
  • 您的模型现在将继续工作，直到生成或确定完成您的最终响应。
  • 即使是小型工具调用模型，您也会获得 100 倍更好的响应 我们还实施了保护措施来防止无限循环，每个响应最多调用 10 次工具，以防止任务失控。

限制

大多数提供商不允许我们探测模型是否支持本机工具调用。 如果您的模型支持，以下本地 LLM 提供商将自动支持本机工具调用：

  • 默认内置LLM提供商（AnythingLLM默认）
  • 奥拉马
  • LM工作室 对于其他人，您需要设置一个 ENV 变量以启用支持的提供程序的本机工具调用。
  • 通用 OpenAI
  • 格罗克
  • AWS 基岩
  • 柠檬水
  • 莱特法学硕士
  • 本地人工智能
  • 开放路由器 这可以通过 PROVIDER_SUPPORTS_NATIVE_TOOL_CALLING 环境变量进行设置。
PROVIDER_SUPPORTS_NATIVE_TOOL_CALLING="bedrock,generic-openai,groq,lemonade,litellm,local-ai,openrouter"

AMD 集成的 Lemonade

AMD 的 [Lemonade](https://lemonade-server.ai) 是一个[开源](https://github.com/lemonade-sdk/lemonade) 本地模型运行时，可优化所有类型硬件（包括 AMD GPU 和 NPU）的本地模型（LLM、ASR、TTS、图像生成等）的性能和效率。 我们添加了一流的支持，因此您可以在 AnythingLLM 中使用通过 Lemonade 运行的本地模型，从而在本地硬件上获得最佳应用程序体验。 ----- ## 发生了什么变化 * 修复：贡献指南中的拼写错误，更新项目元数据和 pull_request_temp...md by @dipanshurdev in https://github.com/Mintplex-Labs/anything-llm/pull/5010 * 壮举：通过 @angelplusultra 在 https://github.com/Mintplex-Labs/anything-llm/pull/4996 中更新灯光模式 UI 侧边栏 * 修复（前端）：修复 https://github.com/Mintplex-Labs/anything-llm/pull/5027 中 @dipanshurdev 的 useIsDisabled 钩子中的事件侦听器内存泄漏 * 壮举：https://github.com/Mintplex-Labs/anything-llm/pull/5007 中@angelplusultra 提供的带有系统偏好设置的专用深色主题选项 * 在 https://github.com/Mintplex-Labs/anything-llm/pull/4931 中由 @shatfield4 实施新的主页重新设计 * 修复：GitLab 连接器无限循环和 https://github.com/Mintplex-Labs/anything-llm/pull/5021 中 @angelplusultra 的大型存储库的速率限制崩溃 * 修复：在 https://github.com/Mintplex-Labs/anything-llm/pull/5037 中通过 @angelplusultra 将密码字符验证添加到入职单用户设置中 * @timothycarambat 在 https://github.com/Mintplex-Labs/anything-llm/pull/5071 中调用本机工具 * 修复：解决 https://github.com/Mintplex-Labs/anything-llm/pull/5054 中 @angelplusultra 的工具调用响应上的 Gemini 代理 400 错误 * 修复：防止 CMD/CTRL+箭头滚动覆盖 https://github.com/Mintplex-Labs/anything-llm/pull/5053 中 @angelplusultra 的文本区域光标移动 * 通过 @timothycarambat 在 https://github.com/Mintplex-Labs/anything-llm/pull/5083 中标准化批量刮刀的刮刀运行时参数 * @timothycarambat 在 https://github.com/Mintplex-Labs/anything-llm/pull/5077 中集成柠檬水 ## 新贡献者 * @dipanshurdev 在 https://github.com/Mintplex-Labs/anything-llm/pull/5010 中做出了第一个贡献 **完整 Changelog**：https://github.com/Mintplex-Labs/anything-llm/compare/v1.11.0...v1.11.1
