anything-llm v1.12.0

小版本 发布时间2026年4月2日 来源Mintplex-Labs/anything-llm 英文原文

anything-llm v1.12.0

主要特点

本机工具调用的自动模式

对于支持本机工具调用的选择提供程序，您不再需要使用@agent来使用工具。您现在无需询问即可使用这些工具。 如果您的提示输入没有“@”符号，您的聊天将自动根据需要使用工具。 https://github.com/user-attachments/assets/2ab6af9a-98d0-4d52-a3d3-849d70e64004

智能工具选择

我们添加了一个新功能，称为智能刀具选择。此功能允许您加载 无限 工具供代理使用，以更好的性能在上下文中使用，并在每次聊天时节省高达 80% 的令牌使用量。

文件系统代理

我们添加了一个名为文件系统代理的新功能。此功能允许您使用主机的文件系统来搜索文件和目录。

文档生成代理

我们为[文档生成]（https://docs.anythingllm.com/agent/usage#document-generation-agent）添加了一个新的内置代理。通过文档生成，您可以生成文本文件、PDF、Excel 文件、Docx，甚至整个 PowerPoint 演示文稿。 https://github.com/user-attachments/assets/493e27bb-4944-4a8d-8995-a7c8b3eaadd5

电报机器人

AnythingLLM Docker 和桌面现在支持 Telegram bot，因此您可以连接到世界任何地方的 AnythingLLM 实例。 支持：

  • 文字聊天（流媒体和思考）
  • 图像理解
  • 语音消息和附件
  • 自动模式和@agent支持
  • 工作空间和线程选择
  • 型号选择
  • 引文
  • AnythingLLM 中提供的任何代理技能
