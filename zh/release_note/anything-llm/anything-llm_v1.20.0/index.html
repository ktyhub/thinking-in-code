anything-llm v1.20.0

更新的浏览器扩展

浏览器扩展 已得到改进，超越了最初仅收集文档的功能，现在是一个成熟的 UI 聊天栏，能够右键 click -> 添加上下文（文本和图像）并直接在 Chrome 中聊天。此侧边栏应与传统聊天 UI 的工具和更多功能基本相同。 虽然它向后和向前兼容，但只有当服务器和扩展版本为 1.20.0 或更高版本时，才需要完整的功能。 Chrome 网上应用店 也已更新至此版本。 https://github.com/user-attachments/assets/830069a6-34cb-4f37-80b0-6d52eb4622d0

PowerPoint 工具大修

该代理的 PowerPoint 工具已从头开始重建，可以生成更清晰、美观的演示文稿。 - **主题和布局：**套牌使用新的颜色主题和一组布局，这些布局是根据每张幻灯片的内容而选择的，因此一张又一张的幻灯片不会重复相同的布局。 - **实时幻灯片预览：** 幻灯片在构建时会出现在聊天中，因此您可以观看幻灯片组合在一起的情况。 Click 预览以查看其全尺寸。 - **接地内容：**仅当您的大纲、研究或对话包含数字、图表值和引言时才会保留它们，并且文本大小适合每张幻灯片。 ### Gmail 和 Outlook 的电子邮件批准卡 当客服人员想要使用 [Gmail](https://docs.anythingllm.com/agent/usage/gmail-agent) 或 [Outlook](https://docs.anythingllm.com/agent/usage/outlook-agent) 工具发送或起草电子邮件时，批准请求现在显示为电子邮件卡。在批准之前，您可以直接在卡中编辑收件人、抄送、密件抄送、主题和正文。当您编辑时，批准计时器会暂停，您可以展开已发送的电子邮件以准确查看发送的内容。 ### MCP 改进 - **身份转发：** MCP 服务器现在可以接收正在调用它们的工作区和用户。使用 `anythingllm.forwardIdentity` 选择每个服务器。请参阅[将身份转发到 MCP 服务器](https://docs.anythingllm.com/mcp-compatibility/forward-identity)。 - **每服务器超时：** 在 MCP 服务器上设置 `anythingllm.timeout`（以秒为单位）以控制其工具调用可以运行的时间。默认值为 60 秒。 - **开发人员 API：** 新的 `/v1/mcp-servers` 端点可让您列出、添加、更新、删除、启动、停止和重新加载 MCP 服务器，以及打开或关闭各个工具。 - 具有许多工具的 MCP 服务器现在会加载工具的每一页，启动一台服务器还会拾取任何新保存的服务器，并且可以删除断开连接的服务器。 ---- ## 发生了什么变化 * 修复：将 Markdown 表格包装在窄屏幕滚动容器中（#6852），作者：https://github.com/Mintplex-Labs/anything-llm/pull/6859 中的 @ManojDevarajulu * 修复：返回
