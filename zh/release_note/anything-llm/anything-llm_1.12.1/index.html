anything-llm v1.12.1

anything-llm v1.12.1

显着改进

流式文档嵌入

现在，当您将文档上传到工作区时，会在嵌入过程中报告每个文档的进程。这是性能和用户体验方面的巨大改进。在此过程中，您可以向队列添加和删除文档，甚至可以关闭并离开页面，而不会丢失进度。

应用程序集成

现在有以下应用程序的内置集成，代理技能所需的设置最少甚至为零：

  • Gmail
  • 展望
  • 谷歌日历

其他改进

  • 主 UI 中的图像灯箱
  • 通过自定义 mdpdf fork 为 PDF 生成启用韩文、中文和日文字符支持
  • 更好地引用应用程序集成
  • DDG 在代理技能中默认的网络搜索
  • 当文档生成代理生成时，在计算机上的本机应用程序中打开文档
  • 通过 ENV 设置自动批准代理技能
  • Ollama 升至 0.20.7（Qwen3.5 支持、Gemma 4 等）
  • Unload model when closed 的新自定义 > 聊天设置，用于在用户关闭聊天窗口时卸载模型。
  • 通用 OpenAI 能力检测/ENV 设置
  • 更新 Lemonade 以支持 1.10.0 更改
  • 加泰罗尼亚语翻译
  • 名称字段添加到 API 键
  • 在代理会话中报告聊天 ID，因此现在您可以重新生成聊天、TTS 和更多操作，而无需重新加载页面。
