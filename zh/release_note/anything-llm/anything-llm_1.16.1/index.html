anything-llm v1.16.1

修订 发布时间2026年8月27日 来源Mintplex-Labs/anything-llm 英文原文

anything-llm v1.16.1

活动和思想链大修

我们针对长期代理任务彻底修改了 UI，这些任务显示了多种思维和工具调用，现在汇总成一个干净、可折叠的 UI 元素。

这为您提供了更多的屏幕空间用于实际响应，同时仍然以易于阅读的格式保留重要的调用堆栈和模型产生的想法。

导航警告

最近，我们在每个受支持的 LLM 中添加了真正的中止信号，以便当您取消推理或离开页面时，我们会停止推理以节省您的计算成本。

然而，这会产生意想不到的副作用，即在离开聊天时取消推理，从而阻止后台完成。现在，我们在中止响应之前警告您。

路线图项目： 我们打算让此用户可配置，以便您可以自定义此行为，并允许那些具有更强大或高并发设置（其中多个并行推理会话可行）的人进行后台推理。

Foundry 本地嵌入式（仅限桌面）

<img 宽度=“1280”高度=“720” alt=“图像”src=“https://github.com/user-attachments/assets/d43ba423-83a8-4150-8b62-606ffb6c8882”/>

FoundryLocal 是 Microsoft 构建的推理引擎，预装在 Windows 11（版本 24H2、内部版本 26100 或更高版本）上。

它使用 WinML 跨任何 Windows 硬件配置加载 CPU、GPU 或 NPU 的模型。对于我们没有明确支持的硬件配置来说，这是一个很好的选择。请记住，由于 FoundryLocal 仍在推出，模型的可用性可能会受到限制。目前不提供视觉模型。

我们为此与 Microsoft 合作，如果您有错误或问题，我们可以帮助将其转发给 FoundryLocal 团队

适用于 Snapdragon 的 GenieX（仅限桌面）

<img 宽度=“1280”高度=“720” alt=“图像”src=“https://github.com/user-attachments/assets/866a7cc2-e3e7-4189-af56-6a29c030aab5”/>

[!注意] 这取代了我们之前的 Snapdragon NPU 引擎。旧引擎中的任何先前模型都会在更新时删除，您需要重新下载这些优化的模型。您应该会看到 NPU 模型和常规 GGUF 的性能显着提高。

我们强烈建议该发动机仅使用 GGUF 模型。仅配备 Qualcomm NPU 的型号具有 4K 上下文窗口，会导致代理体验不佳。

GenieX 是由 Qualcomm（以前称为 NexaAI）构建的开源推理引擎，可在 X 和 X2 Elite 设备的 NPU 上高效运行 GGUF 和 Qualcomm AI Hub 模型。

AnythingLLM 通过在下拉列表中选择“AnythingLLM GenieX”提供商来提供完全托管的内置支持。 GGUF 和仅 NPU 型号都可以利用 NPU，为您提供两者的功效和智能。

我们为此与 Qualcomm 合作，如果您有错误或问题，我们可以帮助将其转发给 GenieX 团队，或者您可以在他们的 GitHub 上提出问题。 s/o @zhiyuan8、@alexchen4ai 和 @alanzhuly

新功能

  • Windows (x64/ARM64) 上的 Native Foundry Local SDK - Foundry 提供程序现在完全独立，不再需要单独的 Foundry Local 安装，目录中公开了 GPU/NPU 优化的模型变体
  • GenieX 运行时支持 Windows ARM64 设备
  • AWS Bedrock 跨区域推理配置文件支持 - 地理前缀配置文件 ID（us.、eu.、global.）现在显示在模型下拉列表中并正确路由，以及预设列表之外区域的手动区域输入（GovCloud、专用分区）
  • LocalAI 添加为图像生成提供商，仅列出服务器中支持图像的模型
  • LocalAI 上下文窗口自动检测 - 上下文窗口是从服务器的配置中按模型读取的，手动设置现在是可选覆盖
  • Windows 安装程序的静默/无头安装和卸载标志 - 请参阅 Windows 安装文档

改进

  • 思想链和代理活动现在是一个可折叠组件 - 折叠时为一条线，展开时每个思想有一个连接轨道一步，流式传输时标题中显示实时思想
  • 新的思想链汇总现在反映在助理面板中
  • 离开线程或离开中间推理现在会在响应丢失之前向您发出警告，而不是默默地杀死这一代
  • Foundry Local 在使用内置运行时时不再提示设置，并通过能力检测自动加载模型
  • 载入灯光模式样式和重新设计的 LLM 选择 UI
  • Beacon 现在可以在流式传输时正确渲染思维块和 Markdown 格式，具有可折叠思维并修复了模型详细信息文本溢出的问题
  • Windows 安装程序现在包含侧边栏面板图像
  • 提示输入草稿现在在导航之间保留

错误修复

  • 修复了未固定的 undici 版本上因内容标头长度不匹配而导致的 Gemini 崩溃 - 现在与 v6 和 v7 兼容
  • 修复了在 chat 模式下中止 Anthropic（或 Bedrock Anthropic）响应中流然后发送后续响应时发生的崩溃
  • 修复了泄漏的中止流侦听器造成的内存泄漏，这也导致暂停响应以擦除整个聊天
  • 修复了创建新工作区时的崩溃问题
  • 修复了新的统一模态组件引入的模态上缺失的设置 CTA - 类别和工具视图、社区中心连接键和实验功能拒绝按钮上的预定工作技能设置
  • 修复了中间部分
