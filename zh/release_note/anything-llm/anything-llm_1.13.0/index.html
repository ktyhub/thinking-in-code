anything-llm v1.13.0

小版本 发布时间2026年5月26日 来源Mintplex-Labs/anything-llm 英文原文

anything-llm v1.13.0

此版本的重点是改善代理体验并为代理系统添加新功能，以及转向更加被动、个性化和混合的人工智能体验。

Model Router：首个消费者混合人工智能体验

模型路由器功能是首个用户定义的智能路由系统，它将本地和云人工智能无缝融合成完全由您控制的单一、统一的体验。到目前为止，您必须选择：在本地运行所有内容，或将所有内容发送到云端。这种权衡已经结束。

使用模型路由器，您可以定义规则。您发送的每条消息都会自动分析并路由到适合该特定任务的完美模型，无论是用于快速问题的轻量级本地模型、用于复杂数学的推理模型，还是用于细致入微的法律分析的最强大的云模型。全部来自同一个聊天记录。对用户来说都是不可见的。一切由你定义。

是什么让这如此令人兴奋：

  • 混合人工智能。 在一次对话中将本地模型（Ollama、LM Studio 等）与云提供商（OpenAI、Anthropic、Google）混合并匹配。无需手动切换！
  • 您拥有完全的控制权。 创建可在关键字、令牌计数、一天中的时间或图像附件即时触发的计算规则。或者使用法学硕士分类规则 以简单的英语理解意图。
  • 节省资金而不牺牲质量。 将简单查询路由到廉价或本地模型。为真正需要的消息保留昂贵的 API 呼叫。
  • 智能缓存。 我们先进的粘性路由系统使您在对话线程期间保持在同一模型上，因此您不会在每条消息上在模型之间跳转。

我们相信，这是人工智能助手工作方式的根本性转变。您第一次获得本地模型的隐私、云模型的强大功能以及了解何时使用每个模型的智能。而且它是 100% 开源的。

预定工作：当你不工作时，你的人工智能会工作

如果您的人工智能助手可以按照您定义的时间表在后台自动为您工作，而无需您动手，会怎样？

预定工作 将 AnythingLLM 转变为始终在线的人工智能员工队伍。创建自动运行的重复任务：早间简报、每周报告、数据监控、研究摘要。您通常要求代理做的任何事情，但都是自动化且免提的。您可以设置特定于工作的技能，这样模型就不会被工具淹没，并且结果是可重复的。

为什么这会改变一切：

  • **设置好后就不用管它了。**定义提示，选择工具，选择时间表，然后走开。您的代理会在您需要时准确运行：每天早上 8 点、每周一中午、每小时整点。
  • 不需要技术知识。 我们的可视化 Cron Builder 可让您通过简单的下拉菜单来安排作业。没有神秘的 cron 语法，没有命令行，没有代码。只需点和 click。
  • 完全代理能力，完全自动化。 预定作业可以访问与常规聊天相同的工具：网络搜索、文档分析、自定义技能、MCP 集成等。如果代理可以在对话中完成这件事，那么它就可以按计划完成。
  • 完整的运行历史记录。 每次执行都会记录代理的完整推理、工具调用、生成的文件和最终响应。随时查看过去的运行，或在新线程中从代理中断的地方继续。
  • 推送通知。 即使 AnythingLLM 在后台，也会在作业完成时收到提醒。 Click 直接跳到结果。

企业工具为这种自动化收取数千美元的费用。仅云平台要求您将数据传输给第三方。 AnythingLLM 为您提供预定的 AI 代理，这些代理完全在您的计算机上运行，​​并且数据在您的控制之下。

醒来后会看到隔夜电子邮件的摘要。自动编写每周进度报告。监控网站的变化。可能性是无限的，只要您专注于重要的事情，这一切就会发生。

自动记忆和个性化

AnythingLLM 现在支持自动记忆提取和个性化，因此您的 AI 助手可以记住您谈论的内容，并利用这些知识来个性化其响应。

AnythingLLM 运行后台作业，从聊天中提取记忆并将其存储在内存库中。然后，该记忆库用于个性化您的人工智能助手的响应 - 您可以完全控制记住的内容以及如何使用它 如果您不想让模型花费周期来查看聊天历史记录，您甚至可以手动将记忆添加到内存库中。

记忆有两种类型：

  • 工作空间记忆：这些是特定于当前工作空间的记忆（例如您正在处理的内容、特定于项目的信息等）
  • 全局记忆：这些是特定于整个 AnythingLLM 实例的记忆（例如您的姓名、偏好等）

记忆被注入人工智能助手的系统提示中，因此它可以使用它们来个性化其响应，并且是对人工智能助手知识库的欢迎补充。
