anything-llm v1.16.2

新功能

  • LLMman - OSS 现已作为本地 LLM 提供商提供，取代了 Docker Model Runner
  • Google Vertex AI 现已作为 LLM 提供商提供
  • 新的 generate-image 代理技能，用于从聊天中创建图像
  • You.com 现在是默认的网络搜索提供商，可提供更丰富的网络搜索且零数据保留
  • 代理流变量现在支持可选参数
  • 添加了印地语、保加利亚语和瑞典语支持
  • Windows on ARM 上的 GenieX 现在列出在本地模型目录中找到的模型，并允许您直接从 UI 中的 Hugging Face 中提取模型
  • Click 窗口顶部的版本标签可以更轻松地跳转到您的日志和存储目录

改进

  • 现在默认为代理启用网页浏览
  • 本地提供商现在在聊天中报告模型加载状态，以便您知道为什么第一个响应很慢
  • Ollama 运行时间提升至 0.33.3，并更新了捆绑模型列表
  • 删除了主要内容区域周围的边框，以获得更清晰的桌面布局
  • 重新设计了“新功能”模态布局
  • 表格中的日期现在以人类可读的格式显示
  • 抓取的网页现在保留表格、有序列表和代码块，而不是展平它们
  • PDF 页面现在使用换行符连接，因此单词不会跨页面边界融合
  • Mistral 嵌入现已批量化，使大型文档嵌入速度显着加快
  • 文档搜索现在按字面意思而不是正则表达式匹配您的术语
  • 观看的文档现在会在同步时清除陈旧向量
  • AnySearch 作为网络搜索提供商
  • KoboldCPP 提供商进行了彻底改革和现代化，以匹配我们的其他提供商
  • Keenable 添加为网络搜索提供商
  • OpenRouter服务层选择，用于控制路由成本和优先级
  • 通过参考图像进行 LocalAI 图像编辑
