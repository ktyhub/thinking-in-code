anything-llm v1.19.0

Docker 内置法学硕士

AnythingLLM Docker 现在拥有开箱即用的默认本地 LLM 体验。与 AnythingLLM Desktop 附带的同类内置引擎现在可以在 容器内 运行：Lemonade，来自 AMD 的完全开源 本地推理服务器，使用 llama.cpp 运行您的模型。您不再需要在 AnythingLLM 旁边运行 Ollama、LM Studio 或任何其他推理服务器。

将您的 GPU 传递到容器中，引擎就会在您拥有的任何硬件上加速。它会自动选择最快的后端：适用于 NVIDIA GPU 的 CUDA、适用于 AMD 和 Intel GPU 的 Vulkan 或 CPU。它在 amd64 和 arm64 主机上运行。

打开后，内置将成为入职期间默认的 LLM 提供商，并为您的硬件推荐三种型号。您可以从模型表中下载任何模型，或从 Hugging Face 中提取任何 GGUF 模型。它适用于提供者可以使用的任何地方：系统 LLM、工作区和代理 LLM、聊天窗口模型选择器和 模型路由器。

[!提示] 默认情况下内置 LLM 处于关闭状态。 通过使用 -e ENABLE_BUILT_IN_LLM=true 启动容器来打开它，并添加 --gpus all （或传入您的 AMD 或 Intel GPU 设备）以进行 GPU 加速。有关每种硬件的完整设置，请参阅Docker 的内置 LLM。
