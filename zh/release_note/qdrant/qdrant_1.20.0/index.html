qdrant v1.20.0

小版本 发布时间2026年10月22日 来源qdrant/qdrant 英文原文

qdrant v1.20.0

#Changelog

特点🎶

  • #10750 - BM25 直接在全文负载索引上评分 [docs]
  • 里程碑 #57 - TurboQuant：新的 turbo8 和 turbo16 向量数据类型 [文档]
  • #11125 - 每个元素有效负载索引：新的 nested 索引参数，更快的嵌套条件过滤。 [文档]
  • #11180、#11263 - 用于全文索引的新 code 分词器 [docs]
  • #10466 - 可配置的审核日志输出：audit.output 将审核事件写入 file（默认）、stdout 或 stderr [文档]
  • #10992 - 集合创建时间：在集合信息中记录并返回 created_at [docs]
  • #10711 - 子字符串过滤条件：match: { substring: "..." }（仅限全扫描）[文档]
  • #10231、#10287、#10296 - 新公式查询表达式：acosh、max、min [文档] 和 [文档]
  • #10597、#10598 - 可配置的 ID 跟踪器内存布局 [文档]

改进🎵

  • #11009、#11020 - 更快的 HNSW 有效负载链接构建 - 构建器的大小适合块而不是段，并可重复使用
  • #11083 - 更快的 HNSW 修复 - 有效负载块重用旧的图形链接； m = 0图也能治愈
  • #11166 - 较小的 HNSW 上层 - 级别分配中的 floor() 与 HNSW 论文匹配（6.25 在 m = 16 的级别 1 上的分数的 6.25%，而不是 25%）
  • #10976 - 更快的 PQ 训练 - k-means 样本在一次传递中收集，而不是每个块一个
  • #10975 - 更快的标量量化搜索 - 用于 int8 点积的 AVX512-VNNI 和 AVX-VNNI 内核
  • #10977 - 优化过程中搜索速度减慢 - 整个优化作业以低线程优先级运行
  • #11078、#11080 - 取消的优化更少 - 仅当配置更改时才会重新创建优化器
  • #11234 - 更快的点检索 - 每个段一批解析的 ID
  • #11070 - 更快的快照传输和下载 - 4 MiB 流缓冲区而不是 4 KiB
  • #11253 - 更快的分片传输 - 默认情况下启用 transfer_raw_points 和 transfer_raw_payloads
  • #11206 - 更安全的快照 - 唯一的快照名称，并且存储的快照永远不会被覆盖
  • #11221 - 没有卡住的快照下载 - 服务器从不响应时超时 60 秒
  • #11163 - 遥测超时时没有阻塞线程泄漏 - 超时也适用于阻塞任务内部
  • #11164 - 更清晰的 tar 解包错误 - 发布版本报告错误类型（例如 timed out）而不是“格式错误的存档”
  • #11118 - 日志时间戳尊重时区 - 使用 TZ 环境变量设置，默认为 UTC
  • #10235 - timeout 参数为获取点 API
  • 里程碑 #58 - hnsw_config.inline_storage 的磁盘使用量更少 - 矢量仅存储在 HNSW 图形文件内，没有单独的矢量存储副本
  • #10790 - 有效负载索引上的 enable_hnsw 更改更快 - 就地更新而不是删除并重建索引
  • #10906 - 更快地搜索磁盘上的向量 - 在评分之前使用 madvise(WILLNEED) 预取批量向量
  • #10907 - m = 0 图上的 ACORN - 搜索使用图的有效负载块链接
  • #11255 - 小集群中更好的分片分布 - 自动分片集合在 3 个以上节点集群中每个节点获得 2 个分片，而集合少于节点
  • #11273 - NAT 和负载均衡器后面没有内部请求停滞 - 内部 p2p gRPC 上的 HTTP/2 保持活动
  • #11289 - 可配置的快照存储超时和重试 - S3、GCS 和 Azure 配置中的新 timeout_sec、connect_timeout_sec、max_retries、retry_timeout_sec

错误修复🎼
