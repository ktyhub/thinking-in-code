Qdrant 边缘 :hocho:

Qdrant Edge 是 Qdrant 的进程内版本，它与服务器版本具有相同的内部结构、存储格式和点 API，但设计为本地工作。 Qdrant Edge 与服务器版本兼容，可以读取服务器版本 Qdrant 创建的分片快照。更多文档可用此处。

弃用：警告：

  • 从 v1.17.0 开始，Qdrant 更改了 gRPC 接口中矢量场的响应格式。所有官方 Qdrant client 都应该已采用此更改，因此请确保升级您的 client 库并检查您是否没有使用已弃用的字段。更多信息：https://github.com/qdrant/qdrant/pull/7183

  • 即将弃用：

    • 在 Qdrant v1.18.x 中，所有已弃用的搜索方法将被完全删除，甚至在旧的 client 库中也将不可用。
    • 在 Qdrant v1.17.x 中，我们将完全删除 RocksDB 支持，转而使用 gridstore，这意味着无法从 v1.15.x 直接升级到 v1.17.x。请按照升级说明一次升级一个小版本，以避免出现不支持的存储错误。请注意，Qdrant Cloud 基础架构会自动生成适当的升级步骤，因此您不必担心这一点。
