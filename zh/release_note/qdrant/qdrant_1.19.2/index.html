修订 发布时间2026年10月5日 来源qdrant/qdrant 英文原文

qdrant v1.19.2

改进

  • https://github.com/qdrant/qdrant/pull/10682 - 不要在每次更新插入时重写完整的稀疏发布列表，从而使稀疏向量更新插入速度显着加快
  • https://github.com/qdrant/qdrant/pull/10349, https://github.com/qdrant/qdrant/pull/10445, https://github.com/qdrant/qdrant/pull/10661, https://github.com/qdrant/qdrant/pull/10700 - 使代理段保持其状态，防止 WAL 固定和重启时较长的恢复时间
  • https://github.com/qdrant/qdrant/pull/10686 - 修复 HNSW 构建并不总是使所有分配的线程饱和
  • https://github.com/qdrant/qdrant/pull/10624 - 每个搜索请求仅解析一次过滤器 ID，从而提高性能
  • https://github.com/qdrant/qdrant/pull/10853 - 允许将内部 gRPC 绑定到单独的网络接口
  • https://github.com/qdrant/qdrant/pull/10852 - 如果没有配置 API 密钥，则添加启动警告
  • https://github.com/qdrant/qdrant/pull/10891 - 在 Raft 快照期间不要持有集合锁，这之前会阻止对所有集合的访问
  • https://github.com/qdrant/qdrant/pull/10570 - 等待双倍共识同步时间，以便有时间重新选举
  • https://github.com/qdrant/qdrant/pull/10617 - 在阻塞线程中对队列代理批次进行编码，防止阻塞 Tokio 运行时
  • https://github.com/qdrant/qdrant/pull/10480 - 同步段清单时防止阻塞更新
  • https://github.com/qdrant/qdrant/pull/10541 - 在规划优化时防止阻塞更新
  • https://github.com/qdrant/qdrant/pull/10610 - 将 BM25 稀疏嵌入移至阻塞线程以防止阻塞运行时
  • https://github.com/qdrant/qdrant/pull/10599 - 移动队列代理 WAL 读取和批量构建异步运行时
  • https://github.com/qdrant/qdrant/pull/10794 - 按点数估计的绑定基数
  • https://github.com/qdrant/qdrant/pull/10618 - 在遥测中公开重新分片状态
  • https://github.com/qdrant/qdrant/pull/10458 - 使用并行工作程序使报告内存统计数据更加高效
  • https://github.com/qdrant/qdrant/pull/10813 - 在快照传输注释中报告传输的字节和速率
  • https://github.com/qdrant/qdrant/pull/10781 - 报告遥测中的 Acorn 搜索统计数据
  • https://github.com/qdrant/qdrant/pull/7714 - 在指标中添加失败传输的数量 (collection_shard_transfer_failed)
  • https://github.com/qdrant/qdrant/pull/10542 - 在“尝试读取锁定段”日志行中添加迭代计数
  • https://github.com/qdrant/qdrant/pull/10714 - 支持GCS和Azure Blob存储以收集快照
  • https://github.com/qdrant/qdrant/pull/10715 - 为对象存储快照添加可配置前缀

错误修复

  • https://github.com/qdrant/qdrant/pull/10903 - 当 HNSW 入口点不满足过滤器时修复零搜索结果
  • https://github.com/qdrant/qdrant/pull/10870 - 修复添加命名多重向量到索引集合破坏搜索的问题
  • https://github.com/qdrant/qdrant/pull/10577 - 刷新时不声明未完成的操作，修复数据不一致问题
  • https://github.com/qdrant/qdrant/pull/10507, https://github.com/qdrant/qdrant/pull/10531 - 修复代理段不传播某些命名向量或有效负载索引更改的问题
  • https://github.com/qdrant/qdrant/pull/10837 - 防止所有 Gridstore 存储中的写入撕裂，这可能会损坏存储
  • https://github.com/qdrant/qdrant/pull/10812 - 修复可变负载索引无法在撕裂写入时加载，导致崩溃循环
  • https://github.com/qdrant/qdrant/pull/10643 - 修复了恢复对等点破坏其他对等点时过时的快照传输
  • https://github.com/qdrant/qdrant/pull/10897 - 在具有数组索引的路径上修复 group_by
  • https://github.com/qdrant/qdrant/pull/10567 - 修复带有偏移量的 MMR 分页
  • https://github.com/qdrant/qdrant/pull/10878 - 修复合并前未按向量距离排序的 MMR 候选，提高准确性
  • https://github.com/qdrant/qdrant/pull/10593 - 修复未索引有效负载字段上的 TextAny 匹配
  • https://github.com/qdrant/qdrant/pull/10777 - 修复 2-hop Acorn 没有被封盖的问题
  • https://github.com/qdrant/qdrant/pull/10855 - 修复 alt_api_key 未在内部 gRPC API 调用中使用
  • https://github.com/qdrant/qdrant/pull/10862 - 使用 min_token_len > max_token_len 拒绝全文过滤器
  • https://github.com/qdrant/qdrant/pull/10277 - 不要重新应用共识启动期间已应用的提交条目

安全

  • https://github.com/qdrant/qdrant/pull/10758 - 仅接受内部 gRPC API 上的读写 API 按键
  • https://github.com/qdrant/qdrant/pull/10556 - 在没有收集配置的情况下上传快照时不要公开日志中的路径
