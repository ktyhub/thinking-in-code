crewAI 1.15.38

#crewAI 1.15.38

发生了什么变化

特点

  • 使 gpt-6-luna craftAI 随处可见的默认模型
  • 使用每一行的工具读取客服人员输入中的电子表格 URL
  • 标签评估使用范围包含目标和每次评估 ID
  • 在crewai eval中添加—no-open以进行无头使用

错误修复

  • 将退出并出现错误的crewai eval 运行计为run_failed
  • 仅当crewai eval打开跟踪时创建项目.env所有者
  • 上传crewai eval 启动的失败匿名运行
  • 在第一次调用时检查 openai 兼容提供商的 API 密钥
  • 将记忆的船员方法范围扩展到其实例
  • 当crewai run的项目脚本失败时退出非零
  • Eval 要求共享跟踪，Enter 表示“是”，并解释原因

文档

  • 记录 GET /inputs 上的 required_inputs 以及哪些流字段是输入
