spring-integration v7.1.2

:lady_beetle: 错误修复

  • 从 HttpRequestHandlingController 错误中删除损坏的堆栈跟踪 #11516
  • 拒绝 AMQP 1.0 入站端点中不可转换的消息 #11501
  • PropertiesPersistingMetadataStore 在 IOException 后不会重试刷新 #11498
  • start() 失败后，文件入站消息源保持 running #11426
  • TcpNioServerConnectionFactory.stop() 在正常停止时在错误处记录“选择器已关闭”（INT-3473 的回归）#11424
  • AmqpClientInboundGateway 损坏百分比编码的 AMQP 1.0 回复队列名称 #11422
  • RedisLockRegistry 和 JdbcLockRegistry: lock(Duration) 不会恢复中断状态 #11411
  • 由于选择器关闭/活动标志排序，TcpNioClientConnectionFactory.stop() 在每次正常停止时都会在错误处记录“选择器已关闭”#11398
  • FileWritingMessageHandler：失败的 close() 被吞掉，截断的文件仍被提升 #11394
  • PollableChannel 上的 ReactiveStreamsConsumer 可能会在 stop() 上默默地丢失消息 #11384
  • 如果后台线程终止，请重新启动 Apache Commons Tailer #11382
  • AdviceMessage.equals() 对于具有不同有效负载的消息返回 true #11379
  • AbstractMailMessageTransformer 正在丢失上游标头 #11375

:notebook_with_decorative_cover: 文档

  • 改进 SerializingHttpMessageConverter 安全问题的文档 #11484
