spring-integration v7.2.0-M1

预发布 发布时间2026年8月20日 来源spring-projects/spring-integration 英文原文

spring-integration v7.2.0-M1

:star: 新功能

  • JdbcMetadataStore.putIfAbsent() 对于具有空 METADATA_VALUE 的现有行返回 null #11248
  • 修复 HTTP 模块中与 RestTemplate 相关的弃用问题 #11234
  • 在 AMQP 出站端点中使用简单发布者确认的选项 #11194
  • 保留 DefaultErrorMessageStrategy 中的原始标头 #11160

:lady_beetle: 错误修复

  • CVE-2026-47856：JsonToObjectTransformer 将 json__TypeId__ 消息标头解析为任意类，无需允许列表 #11350
  • CVE-2026-47859：RFC6587SyslogDeserializer 中的无界内存分配（八位字节计数帧）——远程 DoS #11349
  • CVE-2026-47862：ZipTransformer 使用 file_name 标头构建 workDirectory 路径而不进行清理 #11348
  • CVE-2026-47864：SerializingHttpMessageConverter 中不安全的 Java 反序列化 — 远程代码执行 #11347
  • CVE-2026-59324：修复并发情况下 FluxTransform() 中的跨消息标头泄漏 #11346
  • CVE-2026-59321：修复非线程安全引擎的 AbstractScriptExecutor #11345
  • CVE-2026-59322：将 EmbeddedHeadersJsonMessageMapper 默认更改为无标头 #11344
  • CVE-2026-59311：防止 zip 转换器将临时文件写入符号链接 #11343
  • CVE-2026-59292：添加元数据存储文件权限控制 #11342
  • CVE-2026-59307：JdbcMessageStore：setBeanClassLoader 上的新 mapper #11341
  • CVE-2026-59293：将 SMB 默认版本设置为 SMB202 #11339
  • CVE-2026-59274：向 UnzipTransformer 添加大小约束选项 #11336
  • CVE-2026-47880：默认情况下跳过 toHeaders 中的属性 #11331
  • CVE-2026-47861：UDP 适配器向攻击者提供的主机发送 ack：从数据包正文解析的端口，即使在acknowledge=false 时也是如此 #11328
  • FileWritingMessageHandler：同一目标目录的并发自动创建失败，并显示“无法创建目标目录 […]”。 #11253
  • 修复 ZookeeperLockRegistry 测试隔离和中断处理 #11244
  • JdbcMetadataStore putIfAbsent 可能会卡在 MySQL 数据库上的 while 循环中。 #10847
