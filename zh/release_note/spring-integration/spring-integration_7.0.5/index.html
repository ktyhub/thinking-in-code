spring-integration v7.0.5

修订 发布时间2026年6月10日 来源spring-projects/spring-integration 英文原文

spring-integration v7.0.5

:star: 新功能

  • 添加基于标头值匹配模式的消息选择器 #11093
  • 禁用 CrossOrigin 中的 allowCredentials 并引入 originPatterns #11008

:lady_beetle: 错误修复

  • 防止文件写入输出目录之外 #11096
  • RedisLockRegistry 解锁中断线程上的竞争条件 #11059
  • ControlBusCommandRegistry.controlBusCommands 必须是 ConcurrentHashMap #11055
  • 防止从 Redis 注册表中驱逐持有的锁 #11052
  • 防止从 JDBC 注册表中驱逐持有的锁 #11047
  • ZookeeperMetadataStore.replace() 破坏了 CAS 逻辑 #11022
  • ServerWebSocketContainer.registerWebSocketHandlers() 使用 setAllowedOrigins() 而不是 setAllowedOriginPatterns()，导致与 Spring Framework 7 中的allowCredentials=true 不兼容 #10943
  • 输入夏令时后 JDBC 锁存储库失败 #10909
  • 文档：修复 ftp/sftp/smb 的架构链接 #10899

:notebook_with_decorative_cover: 文档

  • 修复 Configuration 部分的导航链接 #11061
