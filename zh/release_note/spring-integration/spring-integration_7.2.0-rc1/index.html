spring-integration v7.2.0-RC1

:star: 新功能

  • 添加 MQTT 出站通道适配器实现 #11530
  • 使 SerializingHttpMessageConverter 需要其构造函数中的 allowedPatterns #11480
  • 基于 hivemq 添加 MQTT 入站通道适配器 #10989
  • Spring Integration JMS DefaultJmsHeaderMapper 没有设置 OutboundHeaderNames 和 InboundHeaderNames 的功能 [INT-4412] #8337
  • 提供 Bean 验证 (JSR 303) 过滤器 [INT-4068] #8009
  • 向 DefaultFtpSessionFactory 添加代理支持 [INT-2505] #6485
  • 如果输入日期字段为空，FeedEntryMessageSource 将失败 [INT-1810] #5797

  • 从 HttpRequestHandlingController 错误中删除损坏的堆栈跟踪 #11515
  • 拒绝 AMQP 1.0 入站端点中不可转换的消息 #11500
  • PropertiesPersistingMetadataStore 在 IOException 后不会重试刷新 #11495

  • 改进 SerializingHttpMessageConverter 安全问题的文档 #11455
