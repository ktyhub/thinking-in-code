spring-integration v7.2.0-M2

预发布 发布时间2026年9月24日 来源spring-projects/spring-integration 英文原文

spring-integration v7.2.0-M2

:star: 新功能

  • 添加 Kafka 共享消费者通道适配器 #11413
  • 摆脱 Apache Derby 依赖和使用 #11387
  • 在 Mail Java DSL 中将 Function<MimeMessage, ?> 设为 CheckedFunction #11280
  • 新的 checkstyle 检查发现的 ExcellentQualifiedType 用法 #11275

:lady_beetle: 错误修复

  • start() 失败后，文件入站消息源保持 running #11420
  • TcpNioServerConnectionFactory.stop() 在正常停止时在错误处记录“选择器已关闭”（INT-3473 的回归）#11418
  • AmqpClientInboundGateway 损坏百分比编码的 AMQP 1.0 回复队列名称 #11414
  • RedisLockRegistry 和 JdbcLockRegistry: lock(Duration) 不会恢复中断状态 #11409
  • 修复 FileWritingMessageHandler stop() 中的竞赛丢失飞行中刷新的跟踪 #11386
  • 如果后台线程终止，请重新启动 Apache Commons Tailer #11381
  • AdviceMessage.equals() 对于具有不同有效负载的消息返回 true #11377
  • FileWritingMessageHandler：失败的 close() 被吞掉，截断的文件仍被提升 #11352
  • AbstractMailMessageTransformer 正在丢失上游标头 #11281
  • 由于选择器关闭/活动标志排序，TcpNioClientConnectionFactory.stop() 在每次正常停止时都会在错误处记录“选择器已关闭”#11269
  • PollableChannel 上的 ReactiveStreamsConsumer 可能会在 stop() 上默默地丢失消息 #11262

:notebook_with_decorative_cover: 文档

  • 波兰语变更历史部分 #11402
  • 杂务：修复文档示例中的拼写错误 #11397
  • 更新更改历史记录中的 JDBC 锁定注册表链接 #11366
