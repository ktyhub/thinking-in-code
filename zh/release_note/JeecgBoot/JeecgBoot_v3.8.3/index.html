升级日志

本次版本围绕组织机构和岗位职级进行了深度改造，支持子公司架构、岗位职级上下级及职级设置，优化了部门人员维护和用户主岗位管理，提升了组织管理的灵活和报表。同时，首页配置实现了多种个性化定制，机场管理更加简单，套餐概念更加明确。

  • 架构架构方面，升级至Spring Boot 3.5.5、Spring Cloud 2025.0.0、Spring Cloud阿里巴巴2023.0.3.3，切换回Tomcat容器，优化启动并支持延迟加载。代码生成支持前左路径配置，菜单SQL自动同步至Flyway目录，提高开发效率。
  • 另外，本版本修复了大量前端组件和后台功能的关键问题，完善了各项支持，升级数据库驱动，提升系统稳定性和性能。AI应用及低代码平台功能也得到增强，为用户带来更流畅、智能的使用体验。 -特别提示：默认主干切换成了Spring Boot 3，全面兼容Java 21生态，提升系统性能和安全性。v3.8.3将是最后一个Spring Boot 2的版本，后续只发布Spring Boot 3版本，Spring Boot 2版本将不再进行升级维护。请用户提前做好升级准备。

#####组织机构大改

  • 1、组织机构大改造、支援子公司、阵地与部门功能划分更加明确（部门右侧增加人员维护功能）
  • 2、岗位支持设置“岗位上下级别”、支持设置“职务级别”；新增职务级别汇报关系
  • 3、职务改造，原人员配置“职务”功能作废改成“部门岗位配置职级”
  • 4、用户支持主岗位和兼职岗位设置
  • 5、首页配置大改造，支持通过角色、用户多维度设置个性化首页
  • 6、机场大改造，更自动化（套餐概念更清晰）
  • 7、新建套餐，增加属性“自动用户配置，是的话，新建用户、要求用户都会默认关联套餐”
  • 8、我的机场下，新增菜单“机场职责”、“机场部门”
  • 9、我的机场下，我的机场改成展示页面

#####巨大的变化

  • 换回tomcat 弃用 undertow
  • 优化后台启动速度，支持lazy-initialization延迟加载启动（解决项目大，启动慢的困扰）
  • 提供 JeecgBoot 运行环境python脚本检查
  • 升级springboot3分支，spring-boot到3.5.5、升级spring-cloud到2025.0.0、升级spring-cloud-alibaba到2023.0.3.3
  • springboot3版本，支持jdk17、jdk21、jdk24
  • 代码生成前端代码支持直接生成到前端项目、菜单sql会自动生成到启动项目的flyway目录
  • 代码生成可以配置两个路径分别对应前端和路由器 · Issue #7197
