WeKnora v0.2.6

修订 发布时间2025年12月29日 来源Tencent/WeKnora 英文原文

WeKnora v0.2.6

[0.2.6] - 2025-12-29

🚀 新功能

  • 新：自定义代理系统
    • 支持创建、配置和选择自定义代理
    • 座席功能指标显示，支持MCP服务能力
    • 内置代理排序逻辑，确保在代理模式下自动启用多轮对话
    • 代理知识库选择模式：全部/指定/禁用
  • 新：Kubernetes 部署的 Helm 图表
    • Kubernetes 部署的完整 Helm 图表
    • Neo4j 模板支持 GraphRAG 功能
    • 版本化图像标签和官方图像兼容性
  • 新：增强的常见问题解答管理
    • FAQ词条检索API支持按ID单词条查询
    • 常见问题列表按更新时间排序（升序/降序）
    • 通过特定领域搜索增强常见问题解答搜索（标准问题/类似问题/答案/全部）
    • 批量更新排除ByTag操作中的FAQ条目
    • 使用 content_only 模式删除标签，仅删除标签内容
  • 新：多平台模型适配
    • 支持多平台型号配置
    • 标题生成模型配置
    • 知识库选择模式，无需强制重新排序模型检查
  • 新：韩语支持
    • 添加了韩语 (한국어) 国际化支持

⚡ 改进

  • 改进：知识库操作
    • 通过 ProcessKBDelete 进行异步知识库删除和后台清理
    • 多知识库搜索支持指定文件ID过滤
    • 通过特定类型的搜索和排序逻辑优化知识块分页
    • 增强了 SearchKnowledgeRequest 结构并具有向后兼容性
  • 改进：提示模板系统
    • 重构提示模板系统，多场景模板配置
    • 统一系统提示，优化坐席选择器界面
  • 改进：标签管理
    • 增强了标签删除功能，支持 ID 排除
    • 异步索引删除任务，优化删除流程
    • 批量TagID更新功能
    • 优化标签名批量查询，提高效率
  • 改进：API 文档
    • 更新了 API 文档链接到新路径
    • 增加了知识搜索API文档
    • 增强常见问题解答和标签删除界面文档
    • 从 Swagger 文档中删除了硬编码的主机配置

🐛 错误修复

  • 已修复：空字符串和 UntaggedTagID 条件的标签 ID 处理逻辑
  • 已修复：不同数据库类型的 JSON 查询兼容性 (MySQL/PostgreSQL)
  • 已修复：忽略零值字段（IsEnabled、Flags）的 GORM 批量插入问题
  • 已修复：Helm 图表版本化图像标签和 runAsNonRoot 兼容性

🔧 重构

  • 重构：删除了安全验证和长度限制，简化了输入处理逻辑
  • 重构：通过改进的选择和状态管理增强了代理配置
