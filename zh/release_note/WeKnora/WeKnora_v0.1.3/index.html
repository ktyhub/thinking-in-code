WeKnora v0.1.3

发生了什么变化

  • 修复：尝试修复 https://github.com/Tencent/WeKnora/pull/275 中 @lyingbug 不支持 ocr avx 的问题
  • 修复：前端依赖 https://github.com/Tencent/WeKnora/pull/277 中的 @lyingbug 的应用程序运行状况
  • 壮举：通过 https://github.com/Tencent/WeKnora/pull/283 中的 @lyingbug 调整应用程序和 Docreader 日志输出
  • 修复（docreader）：通过 https://github.com/Tencent/WeKnora/pull/291 中的 @lyingbug 在 docker 中通过目标架构下载二进制文件
  • 修复（ui）：为了安全起见，@lyingbug 在 https://github.com/Tencent/WeKnora/pull/294 中忽略显示 APIKEY
  • 杂务（文档）：通过 @lyingbug 在 https://github.com/Tencent/WeKnora/pull/295 中修复文档拼写 *修复（ui）：修复https://github.com/Tencent/WeKnora/pull/299中@lyingbug的xss攻击
  • feat: https://github.com/Tencent/WeKnora/pull/300中@begoniezhao修改COS文件服务初始化参数
  • 壮举：通过 @lyingbug 在 https://github.com/Tencent/WeKnora/pull/301 中添加登录页面

🔒 安全功能

  • 新增：添加登录验证功能，增强系统安全性
  • 实现了用户认证和授权机制
  • 添加会话管理和访问控制
  • 修复前端组件中的XSS攻击漏洞

📚 文档更新

  • 在所有自述文件中添加了安全声明（英语、中文、日语）
  • 更新了部署建议，强调内部/专用网络部署
  • 增强安全准则，防止信息泄露风险
  • 修复了文档拼写问题

🛡️ 安全改进

  • 出于安全目的，在 UI 中隐藏 API 密钥
  • 增强的输入清理和 XSS 保护
  • 添加了全面的安全实用程序

🐛 错误修复

  • 修复了 OCR AVX 支持问题
  • 改进了前端健康检查依赖性
  • 增强了目标架构的 Docker 二进制文件下载
  • 修复 COS 文件服务初始化参数和 URL 处理逻辑

🚀 功能和增强功能

  • 改进的应用程序和文档阅读器日志输出
  • 增强的前端路由和身份验证流程
  • 新增完善的用户管理系统
  • 改进了初始化配置处理

🛡️ 安全建议

  • 在内部/专用网络环境中部署WeKnora服务
  • 避免直接接触公共互联网
  • 配置适当的防火墙规则和访问控制
  • 定期更新安全补丁和改进 完整 Changelog：https://github.com/Tencent/WeKnora/compare/v0.1.2…v0.1.3
