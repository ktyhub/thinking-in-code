QwenPaw v2.0.1

修订 发布时间2026年7月24日 来源agentscope-ai/QwenPaw 英文原文

QwenPaw v2.0.1

改变了什么

✨ 已添加

PawApp 平台

  • PawApp SDK 和看板应用程序：一个新的迷你应用程序平台，允许插件在 QwenPaw 之上构建丰富的交互式 UI。附带用于项目管理的内置看板任务板应用程序 (#6150) 自定义代理模式
  • 用户可编辑代理模式：直接从控制台创建和编辑自定义代理循环模式 - 定义迭代限制、停止条件和批准门，无需触摸代码 (#6270)
  • Oh-My-Paw 插件：五个即用型代理循环（UltraQA、Ralph、Ultrawork、Autopilot、Team），用于多代理协作和长时间运行的任务（#5882） 内存和可观察性
  • ReMe Light 索引维护：通过控制台按钮或 API 显式重建索引，改进启动自我修复，并优化大型文档的 Markdown 分块（#6235）
  • ReMe 可靠性改进：运行时内存统计检查、CJK 嵌入安全性和后台摘要器正常关闭（#6098）
  • ReMe 索引保障：增强配置验证和索引稳定性 (#6153)
  • Langfuse 跟踪丰富：跟踪现在携带用户 ID、会话 ID 和包版本，以便更好地过滤和分析 (#5922)
  • 历史保留配置：现在可以从控制台配置滚动上下文保留天数 (#6214) 控制台和桌面
  • 聊天存档：存档旧对话以保持会话列表干净（#6078）
  • 拖放文件上传：将文件直接拖放到桌面应用程序的聊天输入区域中（#6327）
  • 插件市场排序：按下载、更新时间或收藏夹对插件进行排序 (#6349)
  • One-click 代理配置副本：使用单个 click 复制代理配置 (#6262)
  • 可配置的日志轮换：从配置中设置日志文件轮换限制（#6183） 安全与治理
  • Windows 受限令牌沙箱：通过 Windows 受限令牌隔离代码执行以获得额外的沙箱选项 (#5931)
  • 治理规则：用于更细粒度访问控制的新治理规则定义（#6215）
  • 敏感文件检测：更多文件类型被检测为敏感；现在默认允许非敏感路径读取全局文件（#6067） 运行时和多代理
  • 多代理启动控制：控制台中带有部分就绪指示器的有限启动并发（#6198）
  • 静默 cron 交付：计划任务可以静默交付结果，无需通知 (#6080)
  • 事件元数据保存：插件和扩展元数据现在通过实时输出信封进行（#6224）
  • 就绪探针：用于运行状况检查和容器编排的新 /api/healthz 端点（#6028）
  • Trusted 代理身份验证：验证 trusted 代理并解析负载均衡器后面部署的真实 client IP（#6030） CLI
  • 治理中允许 gh CLI：治理策略现在允许 GitHub CLI 命令（#6031）
