QwenPaw v2.2.0

发生了什么变化

✨ 已添加

QwenPaw 中心

  • 自托管具有本地进程或 Docker 运行时、工作区级访问控制、凭证管理和反向代理支持的多用户 QwenPaw Hub（#7112）

QwenPaw 数据

  • 将 QwenPaw Data 部署为原生 PawApp，具有持久分析工作区、打包运行时和单命令 Docker Compose 示例（#6940、#7190）

QwenPaw 邮件

  • 添加智能邮件助手，具有实时监控、搜索、线程感知操作、发件人允许/拒绝规则以及对未知收件人的人工批准 (#6800)
  • 使用桌面应用程序捆绑并启动 Mail MCP (#7170)
  • 保持邮件工具回复在中文对话中可读（#7303）

模型和提供商

  • 使模型设置和选择与统一的提供商发现、能力感知路由、回退策略和思维控制更加一致（#6302）
  • 添加 Volcengine Agent Plan 和 MiMo V2.5 提供商，并更新 Volcengine 目录 (#6515)
  • 添加提示缓存命中并将可观察性写入令牌使用（#7342）

QwenPaw 创建者

  • 创建者 1.1.0 扩展了主流提供商的图像和视频生成，并通过将计划的对话纳入生成提示中来改进叙事视频 (#7167)
  • Creator 1.1.1 添加了录制的网站和桌面操作、Bailian Wan3 视频生成以及可配置的自动视频质量检查（#7274）

控制台和工作区

  • 将子代理对话组织成组并显示完成和未读状态（#7035、#7275）
  • 通过紧凑的任务列表和一致的运行跟踪，使后台工作更容易遵循（#7083、#7319）
  • 显示响应工件并使生成的媒体可直接下载（#7161、#7036）
  • 从工作区 UI 中选择系统提示文件 (#7078)
  • 从工作区 UI 创建文件夹并复制文件（#7151、#7314）
  • 保持项目目录的范围仅限于每个会话，以便并发工作可以安全地使用不同的根目录（#6976）
  • 通过模型和工具调用趋势、每个代理故障以及所有代理视图来扩展令牌使用情况（#7207、#7219）
  • 自动隐藏最大化窗口的 QwenPaw OS 底座 (#7233)
  • 改进编辑器选项卡溢出时的导航（#6983）
  • 复制助理响应，不包含隐藏的推理文本（#7448）

技能、渠道和媒体

  • 保持 Matrix 组会话和内存与每个发送者隔离，并重试暂时登录失败（#7001、#7109）
  • 配置后让钉钉群组共享对话上下文 (#7208)
  • 为钉钉宽屏卡片配置自动布局（#7416）
  • 在代理处理之前将 OneBot 媒体下载到本地 (#6715)
  • 让计算机使用观察相关窗口(#7037)
  • 在将超大图像发送到模型之前可以选择调整其大小（#7294）

  • 自动折叠已完成的辅助进程消息（#7374）
