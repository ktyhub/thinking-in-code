QwenPaw v2.2.2

修订 发布时间2026年10月15日 来源agentscope-ai/QwenPaw 英文原文

QwenPaw v2.2.2

发生了什么变化

✨ 已添加

控制台和工作区

  • 添加六个主题调色板和自定义颜色和角半径，具有实时预览和保存的首选项（#7741）
  • 在聊天中添加经过身份验证的多选项卡终端，并为每个对话提供一个工作目录（#7861）
  • 允许在聊天和设置中将控制台字体大小从 12 像素调整到 20 像素 (#8005)
  • 将多文件夹工作区保存为代理未来任务的默认工作区（#7789）
  • 在其回复的正下方显示代理传递的文件，以便于预览和下载（#7750）

QwenPaw-Flash

  • 本地推荐 QwenPaw-Flash 9B、27B 和 35B-A3B：更新 9B 推荐并添加 27B 和 35B-A3B 选项（#8155）

爪子端口

  • 添加 PawPort 以从 Codex 和 Qoder 导入受支持的对话、内存、技能、插件、MCP 设置、项目和计划任务，并进行兼容性检查和选择性重试 (#6960)

QwenPaw 创建者和数据

  • 将 Creator 升级到 2.0.1：在媒体制作之前检查脚本，防止手动重新生成触发付费下游步骤，并恢复停滞的项目 (#8121)
  • 将 QwenPaw Data 升级到 0.3.0，具有集成分析工作区、交互式说明、内联 HTML 报告以及聊天频道中的 /data 和 /datasource 命令（#7637）

模型和内存

  • 通过候选模型池和每个对话模型以及思维控制来统一模型发现、定价和选择（#7899）
  • 在一个对话框中配置自定义提供商的名称、端点、协议和 API 密钥 (#7826)
  • 在控制台中配置 ReMe 搜索重新排名，包括模型、端点、候选乘数和超时 (#6399)

枢纽

  • 添加中心模型网关，其中包含集中管理的组织模型、成员代币预算、使用仪表板和基于邀请的注册（#7779）
  • 支持从命令行初始化第一个集线器管理员，包括没有 Docker SDK 的仅本地部署 (#7696)

技能、工具、自动化和渠道

  • 添加 view_audio 工具，以便特工可以通过现有转录管道理解音频文件 (#8083)
  • 使用纯文本指令和所选模型配置计划任务，在中断后保留历史记录，并从收件箱检查超时结果和会话 (#7776)
  • 将技能库中选定的技能批量分发到工作区（#7852）
  • 允许将技能分配给自定义通道以及内置通道（#7782）
  • 以插件形式安装或删除技能市场源，包括 QwenPaw、ClawHub、ModelScope 和 Aliyun (#8128)
  • 飞书添加可折叠思维面板，可选生成后自动折叠（#7685）
  • 在回复和完成的流中将 Markdown 表渲染为原生 Telegram 丰富消息，在不支持时进行回退 (#7713)

🔄 已更改

  • 改进控制台中的模型设置和选择交互（#8017）
  • 改进设置导航和搜索，添加更清晰的运行时配置选项卡以及流畅的对话切换（#7956）
  • 统一 /reme <action> key=value 下的内存命令，替换 /dream、/memorize 和 /reme_status (#7444)
  • 将视觉压缩限制为较旧的对话历史记录，保留最近的两个用户回合，并使用 recall_context 检索原始段落（#7703）
  • 通过避免对每个请求进行重复的完整历史数据库检查来减少长时间对话中的延迟（#7639）
  • 重新设计对话历史记录，包括时间、源或未分组视图、小屏幕上的更多空间、更丰富的会话详细信息以及对话 ID 复制（#7665、#7688、#7788、#7846）
  • 默认情况下对对话列表使用源分组（#7972）
  • 将聊天文件抽屉移至右侧（#7704）
  • 通过按需加载聊天依赖项和语言资源来减少初始控制台下载 (#7829)
  • 仅在任务面板展开时流式传输后台工具输出，减少空闲连接（#7831）
  • 将制作技能升级至 2.1，提供更可靠的规划、论证验证和评估指导（#7753）
  • 代理执行时报告每日运行时活动，包括
