QwenPaw v2.2.1

修订 发布时间2026年9月11日 来源agentscope-ai/QwenPaw 英文原文

QwenPaw v2.2.1

发生了什么变化

✨ 已添加

模型、代理和记忆

  • 为每个代理单独配置模型路由，包括提供程序首选项和回退行为（#7501）
  • 添加 Auto Fin 主动内存审查并升级 ReMe 以实现更可靠的长期内存处理 (#7441)
  • 添加 PowerContext 作为可选的长期内存后端，并在控制台中进行配置 (#7080)
  • 围绕请求范围、untrusted 内容、确认、工具使用和完成加强内置代理行为（#7526）

QwenPaw 创建者

  • 在 Creator 1.2.0 中添加蓝图工作台、多时间线比较、可重用视频模板、MiniMax H3 支持、项目快照回滚、更清晰的 Agent 进度以及 Docker 部署 (#7486)

控制台和工作区

  • 在代理、MCP 服务、工具和本地模型共享的统一设置页面中管理环境变量（#7538）
  • 检测可用的插件和 PawApp 更新并使用一个 click 安装它们 (#7605)
  • 通过可定制的导航和改进的会话浏览重新设计侧边栏和设置体验（#7502）
  • 选择会话项目目录时恢复直接路径条目（#7593）
  • 向代理看板添加中文和英文本地化 (#7482)

技能和MCP

  • 让选定的技能预加载其完整指令，以便它们无需额外的激活步骤即可准备就绪 (#7183)
  • 通过指导起草、验证、行为测试和发布工具升级 Make Skill (#7509)
  • 在使用前显示技能版本并验证声明的依赖项（#7609）
  • 配置 HTTP 和 SSE MCP clients 的连接超时 (#7649)

🔄 已更改

  • 为自动内存后端提供一致的生命周期和操作接口，并将 ADBPG 和 PowerContext 作为插件提供（#7561、#7616）
  • 标准化浅色和深色主题的控制台颜色和组件状态（#7487）
  • 改进较小屏幕上的代理选择器 (#7623)

🐛 已修复

控制台、聊天和文件

  • 在流式传输、切换对话或快速提交消息时防止过时的会话状态和排队发送竞争（#7523、#7610、#7237）
  • 将免费模型与专业模型选项卡分开（#7524）
  • 从链接打开聊天时保留选定的循环模式（#7560）
  • 在整个控制台中使用相同的语言选项（#7595）
  • 将 Chrome 扩展选项卡与正确的 QwenPaw 会话分组（#7457）
  • 使导航和主题切换图标在视觉上保持一致（#7499）
  • 当安装的版本和可用的版本不同时显示 PawApp 更新 (#7651)
  • 仅在工作空间内显示文件上传控件（#7667）
  • 恢复表单和 Git 面板一致的 QwenPaw 样式（#7646）

运行时、安全性和兼容性

  • 需要批准关键安全发现，除非政策明确拒绝该操作 (#7525)
  • 在代理运行时路径上强制执行每个 MCP 服务器的工具白名单 (#7504)
  • 将托管 Chromium 安装移出启动路径，以便浏览器设置无法阻止 QwenPaw 启动 (#7539)
  • 防止 ACP 代理在 Windows 上的工作区启动期间停止（#7401）
  • 接受某些模型以 JSON 数字形式发出的数字工具参数 (#6936)
  • 当选定模型接受文本但不接受文档块时，安全地转换 PDF 内容 (#7621)
  • 通过折叠已消耗的思考内容，将长时间对话保持在上下文限制内（#7521）
  • 恢复与旧版身份验证流程响应 HTTP 401 发现的 MCP 服务器的兼容性 (#7627)
  • 防止 shell 子进程与 QwenPaw 竞争交互输入 (#7598)
  • 当请求未知工具的配置时，返回正确的未找到响应（#7498）
  • 当下游工具调用处理程序失败时，在日志中保留完整的异常详细信息，同时向模型返回安全错误（#7578）

内存、集线器和操作

  • 当配置的后端不可用时返回可操作的内存状态，并在其插件无法加载时安全回退（#7544、#7663）
  • 启动集线器运行时而不阻止生命周期操作，并对活动本地运行时的 CLI 请求进行身份验证（#7566、#7631）
  • 通过当前 ClawHub 端点恢复技能发现（#7640）
  • 保留 Unix 权限位以恢复秘密和主密钥 (#7658)
  • 通过支持的聊天渠道正确传送 Base64 编码的图像和其他媒体 (#7647)
