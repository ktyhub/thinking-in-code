QwenPaw v1.1.8

修订 发布时间2026年5月19日 来源agentscope-ai/QwenPaw 英文原文

QwenPaw v1.1.8

✨ 已添加

插件和工具

  • 官方插件分发：从网站浏览并下载官方插件，或在控制台插件管理器中使用一个 click 安装它们（#4482）
  • QwenPaw Pet：带有动画宠物窗口的桌面宠物伴侣插件（#4418、#4516）
  • CloudPaw — 阿里云部署：具有多代理编排、IaC 驱动的云配置以及与阿里云技能中心的 A2A 流式集成的新插件（#4362、#4423、#4506、#4524）
  • 浏览器稳健性：通过崩溃恢复、空闲超时保护和退出时自动清理提高了浏览器稳定性（#4306、#4350）
  • 浏览器选项卡元数据：tabs 操作现在返回每个打开选项卡的 URL 和标题 (#4438) 聊天和控制台
  • 收件箱批量操作：重新设计的收件箱具有批量选择和批量删除功能，可更有效地管理邮件（#4358、#4493）
  • 固定聊天历史抽屉：固定会话抽屉以使其在聊天旁边保持打开状态（#4414、#4416、#4517） 模型和提供商
  • 自定义 HTTP 标头和身份验证模式：适用于所有提供者的自定义标头编辑器，具有身份验证模式选择（API 密钥与承载令牌）（#4413）
  • 每个模型的令牌限制：现在在“设置”→“模型”中为每个模型配置 max_tokens 和 max_input_length (#4417) 代理系统
  • /make-skill 命令：一个新的魔法命令，用于将当前聊天会话转变为可重复使用的技能（#4282）
  • 印度尼西亚代理模板：代理角色降价模板和 Asia/Jakarta 时区 (#4287)
  • Cron 作业超时：可配置 cron 作业的超时（默认 120 秒）（#4425） 安全
  • 技能路径安全：防止技能目录操作中的路径遍历攻击（#4335）
  • 备份 Trust 控制：使用 trust 确认对话框验证导入/恢复时的备份完整性，并加强远程访问控制（#4409、#4429）
  • AgentMd 路径遍历预防：防止代理内存文件操作中的路径遍历（#4511）
  • 插件 API 身份验证：插件管理 API 现在需要身份验证（#4513） 频道
  • Matrix E2EE 验证：使用 E2EE 切换和 SAS 设备验证的密码和访问令牌登录 (#4120)
  • 电报流输出：带有推理指示器支持的实时流回复（#4318）
  • 钉钉流媒体卡：通过AI卡实时流式回复（仅限卡消息模式）（#4420）
  • 飞书 CardKit Streaming：通过 CardKit 进行实时流式回复 (#4480)

🔄 已更改

  • 控制台标题导航：将标题链接合并到文档下拉列表中，其中包含教程、功能演示、Changelog 和常见问题解答条目 (#3875)
  • 飞书/飞书二维码域名：二维码API接受查询参数(#4504)
  • 流任务超时：对于长时间运行的流代理任务，从 300 秒增加到 1800 秒 (#4510)

🐛 已修复

频道

  • WeCom 重复占位符：抑制 rapid 连续消息上的重复“思考…”流 (#4427)
  • 微信投票关闭：修复微信投票线程中退出时崩溃和紧密的错误循环（#4490）
  • QQ 重连循环：防止 IP 白名单拒绝时高频重连 (#4503) 技能
  • QA 代理文档打包：QA 代理现在可以在所有安装方法（pip、Docker、桌面）中正常工作 - 以前可能会丢失一些文档（#4280）
  • 技能中心 URL 验证：修复了带有 www. 前缀的 URL 的技能导入失败的问题 (#4359) 提供商和模型
  • 每模型速率限制器：一个模型的速率限制不再阻止对其他模型的请求（#4487）
  • 每个模型令牌使用情况：令牌使用情况摘要现在包括每个模型的细分以及提示/完成令牌计数（#4476） 控制台和用户界面
  • SSE 连接泄漏：修复了 SSE 连接在页面导航时未关闭的问题，这可能会耗尽浏览器连接限制（#4488）
  • Cron 验证错误：Cron 创建/更新返回本地化的、可操作的错误消息，而不是通用服务器错误（#4495）
  • 会话内存持久性：/mission 和 /skill 信息响应现在持久保存到会话内存中，因此它们可以在页面重新加载后幸存下来（#4523）

📝 文档

  • 网站功能演示：文档演示库，其中包含技能、医生和任务模式的演练视频（#4507）
