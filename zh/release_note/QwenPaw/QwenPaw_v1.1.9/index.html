QwenPaw v1.1.9

修订 发布时间2026年5月27日 来源agentscope-ai/QwenPaw 英文原文

QwenPaw v1.1.9

改变了什么

✨ 已添加

桌面和IDE

  • Tauri 2.x 桌面应用程序：适用于 macOS 和 Windows 的新的基于 Tauri 的本机桌面应用程序 (#3813)
  • 编码模式：具有三面板布局的新 Web IDE — 文件树、带内联差异审查的选项卡式编辑器以及用于分支、暂存和提交的 Git 面板（#4578、#4671） 技能和提供者
  • 技能市场：通过具有跨提供商搜索功能的新技能市场页面，浏览并安装来自多个提供商（Aliyun、ClawHub、ModelScope）的技能（#4518、#4623）
  • OpenCode Go 提供商：OpenCode 和 OpenCode Go 现在共享一个具有可切换 API 端点的提供商（#4536、#4549）
  • 浏览器无头警告：无头浏览器启动现在包含一条警告，其中包含在出现验证页面时切换到有头模式的说明（#4603） 代理系统
  • 后台任务超时：submit_to_agent 现在接受 task_timeout 参数，也可以通过 CLI --task-timeout 标志获得（#4547）
  • 文件块上下文：消息内容中的文件块现在与图像、音频和视频块一起进行处理和标记计数（#4567）
  • Tool Guard 拒绝反馈：当用户拒绝工具调用时，代理会收到明确的指示，不要重试或尝试替代方案（#4569）
  • 隔离 Cron 会话：非共享 cron 作业现在在干净的上下文中执行，而历史记录在统一的每个作业会话中累积（#4602） 聊天和控制台
  • 桌面上的文件下载：聊天中的 Clicking 文件卡现在可以在 pywebview 桌面应用程序中正常工作 (#4566)
  • 聊天输入草稿持久性：聊天输入文本和光标位置在页面导航中保存和恢复（#4598）
  • 聊天历史记录中的内存摘要：聊天历史记录现在包括内存摘要 (#4658) 频道
  • 统一访问控制：每通道白名单/黑名单/待审批系统，带有控制台 UI，用于管理所有通道的用户访问（#4565）
  • QQ工具卫士批准卡：用于QQ频道中批准/拒绝操作的交互式键盘按钮卡（#4667）

🔄 已更改

  • 插件管理器 UI：重新设计的插件管理器页面，包含国际化描述、种类过滤器、名称搜索以及安装/卸载后自动重新加载（#4545、#4588）
  • 技能内容验证：从 zip 导入或通过编辑器保存的技能现在会在被接受之前进行验证（#4591）
  • 控制台 UI 刷新：更新了标题导航布局以及环境和安全设置页面（#4654、#4657）

🐛 已修复

频道

  • 微信消息可靠性：添加了基于内容的重复数据删除以捕获民意调查中的重复项；跳过过期 context_token 的发送；报告 API 发起的消息的准确故障（#4576、#4597、#4618、#4627）
  • 钉钉中文文件名：文件发送中的百分比编码中文文件名现在可以正确解码（#4600）
  • 钉钉 DM Webhook 密钥：DM webhook 存储密钥现在包含 sender_id，以防止不同会话共享相同 conversation_id 后缀时发生冲突 (#4665) 控制台和用户界面
  • MCP Client 密钥路由：修复了包含 / 的 MCP client 密钥的路由（#4560）
  • QwenPaw Pet：修复了 Windows 兼容性，宠物在连续对话中陷入“完成”状态，并将自动启动默认设置更改为选择加入（#4564、#4626）
  • 深色模式可见性：修复了深色模式下不可见的计划面板标题和宠物导入放置区（#4570、#4599）
  • Whisper 语音按钮：聊天页面现在在显示语音按钮之前等待 Whisper 提供商检查，防止配置 Whisper 时浏览器语音短暂闪烁 (#4601) 提供商和安全
  • 代理 Client IP：身份验证绕过白名单现在解析真实的 client IP，而不是使用代理的地址 (#4562)
  • Gemini max_tokens：Gemini 提供商现在可以正确地将 max_tokens 映射到 max_output_tokens (#4621)

🧪 测试

  • 集成测试套件：重构和扩展了具有更广泛覆盖范围的集成测试（#4561）
