QwenPaw v2.1.0

小版本 发布时间2026年8月13日 来源agentscope-ai/QwenPaw 英文原文

QwenPaw v2.1.0

发生了什么变化

✨ 已添加

QwenPaw 操作系统外壳

  • 使用启动器、任务栏、通知和保存的布局在可移动、可调整大小的窗口中打开应用程序 (#6645)
  • 安装的应用程序和市场应用程序现在在应用程序中心和 QwenPaw OS Shell 之间共享一个目录 (#6718) 统一文件工作区
  • 无需离开聊天即可浏览、预览、编辑、比较、上传和下载工作区文件 (#6504)
  • 直接从 QwenPaw OS Shell 打开文件工作区 (#6758)
  • 使用语法突出显示编辑机器人框架文件（#6519） QwenPaw 创建者
  • 与专业代理团队一起将想法或现有镜头转化为成品视频 (#6284)
  • 选择 clips、字幕、效果、资源或文本以进行集中的特工编辑，同时保持直接控制（#6740）
  • 使用图像、视频、语音、字幕、动作、叠加和并行制作步骤进行创建 (#6740)
  • 添加媒体任务恢复、渲染修复、结构化日志和审核反馈（#6556、#6641）
  • 添加设置中心、外部技能、异步媒体生成、更多渲染格式以及改进的 Windows 和窄屏支持 (#6870) 跨线束集成
  • 创建由 Codex 或 Qoder 提供支持的代理，具有每个会话模型、权限、技能和 MCP 服务 (#6397)
  • ACP clients 可以传递临时模型、项目文件夹和 MCP 服务，而无需保存运行时凭据 (#6754)
  • ACP 会话现在向兼容的 clients 报告可用和当前型号（#6531） 浏览器使用
  • 浏览器使用仍处于测试阶段。它可以使用单独的浏览器会话或连接用户登录的 Chrome 中选定的选项卡。浏览器端代码执行不受主机级沙箱保护，并且操作策略尚未强制执行（#6276、#6157） 计算机使用
  • 添加 Windows 桌面应用程序自动化。 macOS 打包和签名已完成，而设备级端到端验证仍在进行中。操作需要每个应用程序的批准，并在用户接管输入时停止（#6424）
  • 本机计算机使用添加了键盘序列，改进了 Windows 模式定位和文本编辑，并使 macOS 菜单、拖动、捕获和聚焦更加可靠（#6891、#6913、#6977） 背景、恢复和长期运行的工作
  • 快照并恢复对话、内存和选定的工作区文件，无需更改项目 Git 历史记录 (#6269)
  • 长对话保留活动任务，而较旧的确切历史记录移至可搜索索引（#6323）
  • 历史搜索返回配对的请求和响应并理解基于日期的查询（#6237）
  • Visual Compact 减少了支持的多模式模型的长上下文输入，同时保持源恢复（#6456）
  • 长时间运行的工具可以在后台继续进行进度、扩展和取消控制（#6151）
  • 工具工作流程可以重复使用结果、分支、循环以及并行运行独立步骤 (#5698)
  • ReMe Light 内存搜索可以选择通过 OpenAI 兼容端点对候选者重新排名，并在重新排名不可用时优雅地回退 (#6398)
  • ReMe Light 添加了经过验证的、可热更新的嵌入设置、日报和服务级别计划、每个代理运行时状态、手动重新索引控件以及独立的搜索和通知选项（#6772） 控制台和模型
  • 代理统计信息现在显示令牌使用情况并将结果范围缩小到当前代理（#6503、#6402、#6862）
  • 项目目录选择可以根据要求包括隐藏文件夹（#6878）
  • 代码块现在共享响应式、主题感知设计，具有语法突出显示、复制和下载操作； LaTeX 和 Mermaid 块添加本地化预览和源选项卡 (#6911)
  • 通过焦点、过滤和简化运动支持探索交互式 3D 图形中的内存关系 (#6922) 频道
  • 飞书、QQ、WeCom、小易和元宝可以使用选择加入的自定义网关端点进行私有部署和本地集成测试，而无需更改其默认值 (#6907)
  • 当另一个正在运行的代理已使用相同的机器人身份时，保存启用的内置通道会发出警告，同时仍然允许显式覆盖（#6909）

🔄 已更改

  • 应用程序中心分离已安装和可用的应用程序，扩展应用程序详细信息，并添加简单模式条目（#6553、#6638）
  • 聊天使循环模式与活动代理保持一致，并列出本地化的 Oh-My-Paw 模式（#6711、#6521）
  • 斜线命令技能显示注入的内容，跳过重复副本，并且可以直接导入 QwenPaw 技能链接（#6345、#6650、#6517）
  • Windows根据当前权限选择沙箱；每个平台上都会报告不受支持的限制（#6383、#6657）
  • OneBot/QQ 保留文本和媒体顺序并扩展引用或转发的消息（#6543、#6769）
  • QwenPaw OS Shell 将简单/桌面模式开关并排放置并缩短桌面模式标签 (#6763)
  • QwenPaw OS Shell 现在使用一个浏览器条目，从桌面内部启动应用程序，并删除过时的编码启动路径 (#6868)
  • 主动模式重用活动工作区，禁用时释放其资源，并使用轻量级 Web 工具进行研究 (#6712)
  • 针对 M3 和 M2.7 代更新了 MiniMax 模型和上下文限制（#6479、#6554）
  • 插件安装更能容忍声明更新兼容性上限的软件包（#6532）

🐛 已修复

QwenPaw 创建者

  • 当输入更改时恢复失败的工作，避免重复的视频渲染，并在最终合成之前审查过时的场景（[#6937]（https://github.com/agentscope-ai/QwenPaw/pull/6937）） 桌面
  • 计算机使用重用已签名的 macOS 应用程序身份，因此权限在启动时仍然保留 (#6590)
  • 桌面启动处理端口错误； Windows 关闭检查受到限制并保持隐藏状态（#6705、#6203）
  • Chrome 在中断后重新连接，在桌面上找到打包的浏览器，Windows 恢复锁定会阻止并发恢复 (#6669)
  • QwenPaw OS Shell 窗口保持菜单栏可见，留在视口内，并允许文本选择和复制（#6801、#6861） 运行时和代理
  • 特定于提供商的工具调用字段在流式传输、历史存储、压缩或重播期间不再丢失（#6759）
  • 当模型报告上下文限制错误时，Scroll 会压缩上下文并重试一次；历史迁移还保留会话身份（#6267、#6068）
  • 当 Codex 运行时不可用时，Codex 支持的代理保持可管理性（#6664）
  • 子座席继承当前会话审批级别；空的批处理字段不再将单个任务转换为批处理请求（#6508、#6595）
  • 旧配置的循环限制被写回，并且每个工具条目的重命名仍然存在（#6530、#6682）
  • Shell 执行保留多行命令，并且不再挂在继承的后台管道上（#6412、#6748）
  • 无头任务构造有效的用户消息，并且工作区提交在未配置时使用本地默认 Git 身份（#6616、#6350）
  • 复制代理不再创建空技能或计划任务脚手架（#6493）
  • 后台子代理任务等待权威分叉完成并报告失败，而不丢弃工作树更改（#6725）
  • 损坏的代理配置和无效的 JSON 会产生可恢复的配置错误，而不是破坏配置加载（#6615）
  • 滚动召回可找到子字符串和多术语搜索的完整 CJK 轮次，并拒绝反向扩展范围 (#6824)
  • 旧会话再次加载本地路径媒体，包括 Windows UNC 路径和百分比编码的非 ASCII 路径 (#6873)
  • 记忆提示不再中断对话，普通的非流式响应可以生成聊天标题（#6360、#6816）
  • 继续摘要尊重残障思维并保留中断或超时行为（#6818）

  • 丰富的消息进入发送队列，多文件预览包含在编辑器中（#6798、#6662）
