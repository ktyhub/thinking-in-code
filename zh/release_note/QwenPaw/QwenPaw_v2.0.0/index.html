QwenPaw v2.0.0

改变了什么

✨ 已添加

核心架构

  • 运行时 2.0：基于 AgentScope 2.0 重构内核（#5078、#4846、#5018、#5552)
  • 代理操作系统驱动程序：统一管理 MCP/A2A/ACP 连接、加密凭证存储和每次调用批准策略 (#5067)
  • 循环工程：具有三个循环模板的新循环门设计：正常模式/任务模式/目标模式（#5665、#5727）
  • 治理和沙箱：具有允许/拒绝/询问规则的策略引擎、合并到单个策略评估路径中的 ToolGuard 检测器以及插件的通用治理模式（#5088、#5546、#5301） 上下文管理
  • 滚动上下文：SQLite 支持的工作历史记录 (history.db)，具有 FTS5 全文搜索、逐出索引、回合级别持久性以及用于按需召回旧回合的沙盒 recall_history_python REPL。默认保留 30 天，启动时自动导入现有会话 (#5321)
  • 本机压缩：使用 AgentScope 2.0 的内置上下文压缩策略进行重构 (#5309) 长期记忆
  • ReMe v0.4.0 后端：用 ReMe v0.4.0 替换内部内存运行时 — 矢量存储、自动跟踪和检索现在由 ReMe v0.4.0 库处理（#5349）
  • 基于回合的跟踪：内存写入现在通过中间件每回合发生，不再与会话关闭相关（#5540）
  • 使用感知搜索：内存搜索现在考虑新近度和频率；配置 UI 中添加了特定于后端的嵌入模型选择（#5820）
  • ADBPG REST 模式：ADBPG 内存后端切换为仅 REST，具有自动搜索功能 (#5296)
  • 搜索 UI 简化：更清晰的内存搜索显示，元数据字段简化为必需品 (#5482)
  • “无”后端：配置选项以完全禁用轻量级部署的内存系统（[#5732]（https://github.com/agentscope-ai/QwenPaw/pull/5732）） 终端用户界面 (TUI)
  • 全屏 TUI：基于文本的终端聊天应用程序 (qwenpaw tui) — 流输出、工具调用渲染、状态栏和会话管理全部在终端中 (#5032)
  • 项目范围的会话：TUI 可以启动范围为特定项目目录的编码模式会话 (#5448)
  • 上下文使用栏：TUI 状态栏中的实时令牌/上下文使用指示器 (#5673)
  • TUI 中的 ACP 命令：/approve、/deny 内联批准命令 + 成绩单面板改进（#5443、#5714） 控制台和用户界面
  • 批准卡：更大的操作按钮，更清晰的差异预览，一click批准/拒绝（[#5855]（https://github.com/agentscope-ai/QwenPaw/pull/5855））
  • 长文本上传：将大文本块直接粘贴或上传到聊天输入中（#5854）
  • 会话级工具批准：覆盖每个会话的全局工具策略（#5685、#5832）
  • 非所有者横幅：查看其他人的会话选项卡时显示“仅查看”横幅（#5664）
  • 移动布局：所有控制台页面的响应式 CSS + 基于抽屉的导航 (#5444–#5470)
  • 工具页面拆分视图：已启用与可用的工具显示在单独的列中；每个工具配置感知切换（#5509、#5604）
  • 技能市场改进：星标/下载计数、启用/禁用拆分、从 CDN 自动同步（#5521、#5706、#5639）
  • 频道页面双布局：启用的频道位于顶部，下方可用 (#5504)
  • 编码模式 50/50 分割：聊天面板占用一半视口 (#5473)
  • 项目浏览器中的隐藏文件夹：现在可以选择 . 前缀目录（#5828）
  • 会话抽屉：具有内联搜索的日期分组会话（[#5728]（https://github.com/agentscope-ai/QwenPaw/pull/5728））
  • 令牌使用弹出窗口：显示每回合令牌/上下文使用情况的环形图，为运行时 2.0 恢复（#5493、#5544）
  • 收件箱过滤器：按源类型过滤推送通知 (#5522)
  • 消息锚点：用户轮流跳转到消息导航器（#5515）
  • 请求超时：可配置的 HTTP 超时 + 用于后端调用的 AbortSignal 传播 (#5764) 模型提供商
  • OpenAI Response API：OpenAI Response API 格式的新提供程序（#5519）
  • DashScope 更新：Qwen3.7 + DeepSeek V4 添加到内置模型列表； generate_kwargs 的 extra_body 直通；每个模型的思维继电器切换（#5646、#5491、#5687、#5730)
  • GitHub 型号：迁移到新的 API 端点；支持细粒度 PAT (#5735)
  • Telegram 自定义基本 URL：自托管 Telegram Bot API 服务器的 api_base_url 配置（#5651） 频道
  • 矩阵流：就地编辑流，不再为每个块发送新消息（#5585）
  • 插件注册通道：插件可以使用自动生成配置 UI 的 JSON 架构注册自定义通道类型 (#4693)
  • 每通道去抖切换：no_text_debounce 标志，因此快速通道不会批处理消息（#5617）
  • Slack：具有多模式附件、线程回复和流式传输的完整通道实现 (#5193)
  • DingTalk 私有部署：本地 DingTalk 实例的 api_endpoint 配置 (#5111)
  • Azure Bot 通道：Azure Bot 通道作为插件添加，并为插件通道提供 i18n/custom-icon/doc_url 支持 (#5849)
  • Discord 附件：下载到本地 media_dir，通过静态文件路由提供服务 (#5468) 桌面
  • Tauri 迁移：桌面构建从 Electron 移至 Tauri — Windows 上更小的二进制文件、本机 Web 视图、NSIS 安装程序（#5734、#4669、#4041）
  • 捆绑 ACP 运行时：Node.js 运行时 + ACP 模块内置于桌面包中，用于开箱即用的代理通信（#5814、#5794）
  • DevTools 手势：8× 徽标 click 打开 Chromium DevTools 进行调试 (#5805) 安全与沙箱
  • Windows AppContainer 沙箱：通过 Windows 本机 AppContainer API 隔离代码执行（#5525）
  • Linux bubblewrap 沙箱：通过 bwrap 挂载命名空间隔离以执行 Linux 代码 (#5310)
  • Cron 工具安全切换：每个作业标记要求/跳过计划任务的工具批准（#5847）
  • 危险命令检测：ToolGuard 检测 find -delete 和类似的破坏性 shell 模式 (#5843)
  • 访问策略：根据功能调用评估声明性允许/拒绝/询问规则 插件
  • AgentScope 中间件挂钩：插件可以使用 semver 版本控制注册与 AgentScope 兼容的中间件（#5221）
  • 版本门控目录：插件市场和 CDN 仅显示与正在运行的 QwenPaw 版本兼容的插件（#5661）
  • 生命周期挂钩：on_uninstall 挂钩、验证器修复和插件作者的公共技能提供者 API (#5008) 工具
  • web_search 和 web_fetch：带有产品标识的内置网络搜索和获取工具 (#5890)
  • grep_search show_file 选项：添加 show_file 标志以显示匹配的文件内容 (#5840)
  • 工具错误直通：工具结果错误状态转发到前端以获得更好的用户体验（#5912） CLI
  • cron update：编辑现有 cron 作业的计划/提示/配置，无需删除+重新创建 (#5210) 可观察性
  • Langfuse 2.0：通过钩子集成恢复跟踪分组；每个代理循环都是一个 Langfuse 生成跨度 (#5511)
