airflow 3.2.1

📦PyPI：https://pypi.org/project/apache-airflow/3.2.1/ 📚 文档：https://airflow.apache.org/docs/apache-airflow/3.2.1/ 🛠 Release Note：https://airflow.apache.org/docs/apache-airflow/3.2.1/release_notes.html 🐳 Docker 图片：“docker 拉 apache/airflow:3.2.1” 🚏 约束：https://github.com/apache/airflow/tree/constraints-3.2.1

重大变化

  • 仅对 DAG 具有读取访问权限的用户将无法再从“/dags`` endpoint, as it now requires additional permissions (``DagAccessEntity.RUN``, ``DagAccessEntity.HITL_DETAIL``, and ``DagAccessEntity.TASK_INSTANCE``). This change was made because the endpoint returns aggregated data from these multiple entities. Please update your custom user roles to include read access for DAG Runs, Task Instances, and HITL Details if those users should still have access to the ``/dags”端点获取数据。 (#64822)

改进

  • 允许 UI 主题配置仅包含 CSS 覆盖、仅图标或空“{}`` to restore OSS defaults. The ``tokens”字段现在在主题配置中是可选的。 (#64552)
