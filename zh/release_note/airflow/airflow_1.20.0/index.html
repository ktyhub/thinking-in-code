airflow 1.20.0

小版本 发布时间2026年3月22日 来源apache/airflow 英文原文

airflow 1.20.0

已删除对旧版本 Apache Airflow <2.11 的支持 (#61018)

Apache Airflow 支持的最低版本现在是 2.11.0。如果您想部署一个 旧版本的 Apache Airflow，请使用最新发布的图表 1.19.0 版本。

workers specific sections have been moved to workers.celery / workers.kubernetes 部分

请相应地更新您的配置：

  • workers.command command is now deprecated in favor of workers.celery.command/workers.kubernetes.command (#60067)。
  • workers.securityContexts command is now deprecated in favor of workers.celery.securityContexts/workers.kubernetes.securityContexts (#60396)。
  • workers.containerLifecycleHooks command is now deprecated in favor of workers.celery.containerLifecycleHooks/workers.kubernetes.containerLifecycleHooks (#61369)。
  • workers.kerberosSidecar section is now deprecated in favor of workers.celery.kerberosSidecar/workers.kubernetes.kerberosSidecar (#61881)。
  • workers.kerberosInitContainer section is now deprecated in favor of workers.celery.kerberosInitContainer/workers.kubernetes.kerberosInitContainer (#60751)。
  • workers.terminationGracePeriodSeconds command is now deprecated in favor of workers.celery.terminationGracePeriodSeconds/workers.kubernetes.terminationGracePeriodSeconds (#61892)。
  • workers.nodeSelector command is now deprecated in favor of workers.celery.nodeSelector/workers.kubernetes.nodeSelector (#61957)。
  • workers.podDisruptionBudget section is now deprecated in favor of workers.celery.podDisruptionBudget。请相应地更新您的配置。 (#61414)
  • workers.keda section is now deprecated in favor of workers.celery.keda。请相应地更新您的配置。 (#61820)
  • workers.resources section is now deprecated in favor of workers.celery.resources and workers.kubernetes.resources。请相应地更新您的配置。 (#61890)

以前的配置选项仍然有效，但已弃用，并将在未来版本中删除。

由于 Git-Sync 不是服务类型对象，因此就绪探针将被删除。 (#62334)

要启用功能行为，请设置“dags.gitSync.recommendedProbeSetting`` to ``true”。该部分本身将在未来版本中删除，以免在升级过程中破坏设置。

由于 Git-Sync 有专用的活性服务，活性探测行为将会改变。要启用功能行为，请设置“dags.gitSync.recommendedProbeSetting`` to ``true”。

请相应地更新您的配置。

从 container_extra_envs and custom_airflow_environment 中删除自动环境变量 (#60750)

Kubernetes 执行器环境变量和机密的自动前缀添加已从“container_extra_envs`` and ``custom_airflow_environment”辅助函数中删除。

改变了什么：

以前，当您将环境变量添加到特定于组件的配置时（例如，将创建“.Values.scheduler.env``), the chart automatically created an additional environment variable (to specified in the ``env`` section) with the ``AIRFLOW__KUBERNETES_ENVIRONMENT_VARIABLES__`` prefix for Kubernetes Executor worker pods. After this change, only the variable specified in ``env”部分。 此外，对于“.Values.secret`` section, the ``AIRFLOW__KUBERNETES_SECRETS__`` prefix is no longer automatically added. Secrets are now passed as-is via ``secretKeyRef”下指定的值，没有工作单元 Pod 的前缀副本。

为什么会发生这样的变化：

  • 防止敏感数据意外泄露，例如“client_secret`` information. Previously, due to prefix, it was recognized as internal Airflow configuration leading to unintended exposure in Airflow UI (under Admin -> Configuration), even when ``AIRFLOW__API__EXPOSE_CONFIG`` is set to ``non-sensitive-only”。
  • 避免意外的环境传播给工作人员：特定于组件的环境配置严格适用于特定组件。以前的行为导致这些变量被传递到工作容器，这可能会导致配置冲突和意外的副作用。

需要迁移：

如果您需要将环境变量专门传递给 Kubernetes Executor Worker Pod，请使用以下方法之一：

选项 1：使用 .Values.env

.. 代码块:: yaml

环境：
  - 名称：my_var
    值：“我的值”

在“.Values.env”下指定的环境变量现在按原样传递，没有自动前缀（与特定于组件的 env 的行为相同）。

选项 2：使用 .Values.config.kubernetes_environment_variables

.. 代码块:: yaml

配置：
  kubernetes_环境变量：
    我的变量：“我的值”

默认 Airflow 图像更新为 3.1.8 (#63392)

与图表一起使用的默认气流图像现在是“3.1.8``, previously it was ``3.1.7”。

特点

  • 支持 podAnnotations and airflowPodAnnotations 值中的 Helm 模板表达式 (#63019)
  • 将分钟级日志保留添加到 clean-logs 脚本中 (#61855)
  • 将 LOG_MAX_SIZE 环境变量添加到日志修饰器 (#61559)

改进

  • 从图表助手中删除自动“KUBERNETES_ENVIRONMENT_VARIABLES`` and ``KUBERNETES_SECRETS”前缀 (#60750)
  • 从触发器、工作者和 dag 处理器中删除 JWT 机密 (#63204)
  • 添加 workers.celery.nodeSelector & workers.kubernetes.nodeSelector (#61957)
  • 添加 workers.celery.terminationGracePeriodSeconds & workers.kubernetes.terminationGracePeriodSeconds (#61892)
  • 添加 workers.celery.resources & workers.kubernetes.resources (#61890)
  • 添加 workers.celery.keda 部分 (#61820)
  • 添加 workers.celery.podDisruptionBudget (#61414)
  • 添加workers.celery.containerLifecycleHooks & “wo
