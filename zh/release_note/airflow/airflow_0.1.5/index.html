airflow 0.1.5

修订 发布时间2026年6月3日 来源apache/airflow 英文原文

airflow 0.1.5

：包：PyPI：https://pypi.org/project/apache-airflow-ctl/0.1.5 ：书籍：文档：https://airflow.apache.org/docs/apache-airflow-ctl/0.1.5 ：锤子和扳手：Release Notes：https://airflow.apache.org/docs/apache-airflow-ctl/0.1.5/release_notes.html

重大变化

  • 添加 dags 下一个执行命令（#66172，#66188）
  • 添加批量删除 Dag Runs (#67095)
  • 添加 rerun_with_latest_version 配置层次结构以清除/重新运行行为 (#63884)
  • 在 API 中实现任务组实例的修补 (#62812)
  • 允许无需身份验证的远程版本检查 (#65099)
  • 为 get_dag_runs 端点添加基于光标的分页 (#65604)
  • 启用新任务排队 (#63484)
  • 为 get_task_instances 端点添加基于光标的分页 (#64845)
  • 将 is_backfillable 属性添加到 DAG API 响应中 (#64644)
  • 将自动生成的命令所需的原始参数公开为位置参数，而不是 --flag 选项。可选参数保持 --flag 形式。遵循 dev-list 关于 airflowctl 参数样式的惰性共识（参见 https://lists.apache.org/thread/m1qvcvow3l17ytv40vhslh40wn3rntrm）(#66768)

错误修复

  • 修复连接导入架构处理 (#67063)
  • 修复文档中损坏的下载 URL 和变量名称 (#67046)
  • 修复缺少的 pyyaml 运行时依赖项 (#65489)
  • 修复 --state 被省略时 dagrun list 崩溃的问题 (#65608)
  • 修复回填参数不覆盖现有 DAG 运行配置的问题 (#64939)
  • 修复 client-py 中的 Ruff 问题 (#64868)

改进

  • AIP-103：添加任务状态和资产状态的核心 API 端点 (#67041)
  • 添加注释以避免在airflowctl PR 中手动编辑 RELEASE_NOTES.rst (#67128)
  • 将 Dag capitalization 从“DAG”对齐到“Dag”以进行airflowctl (#66112)
  • 以 JSON 形式发送回填创建和试运行有效负载 (#65158)
  • 使用airflowctl utils中现有的safe_load函数来加载帮助文本(#65841)
  • 限制 1.0 以下的airflowctl httpx 依赖性 (#65607)
  • 删除未使用的 airflow-ctl/newsfragments 目录 (#65507)
  • 修复不正确的后备逻辑 (#64586)
  • 将非提供商 mypy 检查作为常规预提交静态检查运行，而不是单独的 CI 作业 (#64780)
  • 支持清除、标记成功/失败以及删除多个任务实例 (#64141)
