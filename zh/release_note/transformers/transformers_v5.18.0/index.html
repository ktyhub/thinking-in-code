Nemotron 3 二值化

<img 宽度=“1680”高度=“900” alt=“图像”src=“https://github.com/user-attachments/assets/fe735cb3-9e5b-43ad-8f60-9dec8425aec7”/>

Nemotron 3 Diarization 是一种开放权重流说话者二值化模型，旨在确定现实世界音频中的“谁在何时发言”。它支持流式和离线推理，最多可处理八个扬声器，并根据每个扬声器首次到达输入音频来排序扬声器输出。

该模型使用为 Streaming Sortformer 1、2 引入的到达顺序扬声器缓存 (AOSC) 1 和 FIFO 队列。单个检查点支持可配置的延迟配置文件，从 80 毫秒输入缓冲区到 30.4 离线式缓冲区，以及 10 毫秒倍数的可配置输出帧分辨率。通过分块推理，最大音频持续时间不受限制。

NemotronH Omni

NemotronH Omni 是 NVIDIA 的多模态推理模型，它与 NemotronH 混合动力配对 Mamba-Transformer 语言模型，带有 RADIO 视觉编码器和可选的基于 Parakeet 的声音编码器。 图像（和视频）补丁通过 RADIO 塔和像素洗牌 MLP 投射到语言模型的 在 <image> / <video> 上下文标记位置嵌入空间；音频 clips 以相同的方式投影在 <audio> 位置。结果是一个单一的自回归模型，可以对文本、图像、视频和 声音。

链接： 文档

  • 在 #46509 中添加 @meatybobby 对 Nemotron Omni (#46509) 的支持

HyperCLOVAX Vision V2

HyperCLOVAX Vision V2 是 NAVER 开发的多模态视觉语言模型。它将 HyperClovaX 语言模型骨干与 Qwen2.5-VL 视觉编码器相结合。该模型支持文本、图像和视频输入，并能够通过内置思维令牌（<think>...</think>）进行思维链推理。

链接： 文档

  • 在 #44314 中添加 @jp1924 的 HyperClovaX Vision (#44314)

GTE

GTE是在mGTE：用于多语言文本检索的广义长上下文文本表示和重排序模型中由Xin Zhang、Yanzhao Zhu、Dingkun Long、Wen Xie、Ziqi Dai、Jialong Tang、Huan Lin、Baosong Yang、Pengjun Xie、Fei Huang、Meishan Zhu、Wenjie Li和Min Zhu提出的。

GTE 是一种 BERT 风格的双向编码器，它用 RoPE 替换绝对位置嵌入，使用门控 MLP，并在每个残差连接后应用层归一化。相同的架构支持阿里巴巴的 gte-*-v1.5、gte-multilingual-* 和 gte-en-mlm-* 检查点以及 Snowflake 的 snowflake-arctic-embed-m-v2.0。
