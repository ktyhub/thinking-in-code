transformers v5.23.0

添加新模型

Inkling2

Inkling 2 Small 是 Thinking Machines Lab 的多模式模型，它接受文本和图像输入并生成文本输出，旨在用于英语和其他语言以及多种编码语言。其语言主干有 48 个专家混合解码器层，每个将令牌路由到 384 个专家中的 8 个，总共 594B 个参数和 17B 个活动参数。它保留了 Inkling 解码器（学习相对注意力、短因果卷积、专家混合层）并添加了块注意力残差、具有学习接收器的门控注意力以及动态键/值卷积。图像由基于感知编码器的视觉转换器进行编码，并投影到语言模型嵌入中，每个 40x40 像素块一个嵌入。

JEV

JEV 是一个决策头，它在提示的最后一个标记处使用线性层对单标记标签进行评分，像语言模型头的 logits 一样软上限。 JevForDecision 是检查点及其头部的模型，它读取重量旁边附带的头部文件（JEV 为 head.safetensors 和 judge_config.json）。 GEV 也使用相同的头，读取 pplx-decider 和 d3 的 255 个应答代码，它可以通过实验性 decision 管道运行，也可以直接与 decide 一起运行。

注： JEV 和决策流程目前处于实验阶段。随着开发的继续，它们的 API、配置和行为可能会发生变化。在生产环境中应谨慎使用它们。

链接： 文档

  • 在 #50054 中添加 @ArthurZucker 的 Jev + 决策核心 (#50054)

LFM3

LFM3 是 Liquid AI 的第三代液体基础模型。与 LFM2 一样，它是一种混合架构，将门控短卷积与分组查询注意力相结合，注意力层分为全注意力层和滑动窗口层。注意力层将 RMSNorm 应用于查询和关键头，并使用每个头的 sigmoid 对其输出进行门控。每层在残差相加之前对算子和前馈输出应用三明治范数。

链接： 文档

  • [模型] LFM3 系列：LFM3-Text (#50322) by @paulpak58 in #50322

Dots 3 音符预览

Dots 3 Note Preview 是一个专家混合的因果语言模型，接受本机文本、图像、视频和音频输入。它使用图像和视频的共享视觉编码器以及 Whisper 风格的音频编码器，并且两个编码器在自回归文本生成之前将其输出投影到语言模型的隐藏空间中。支持 BF16 和 FP8 推理。

链接： 文档

  • 在 #47844 中添加@miraclezqc 的dots3-note 预览模型支持 (#47844)

LFM3-VL

LFM3-VL 是 Liquid AI 的视觉语言模型系列，基于 LFM3 语言模型构建。它以原始分辨率拍摄图像和视频以及文本。它将混合视觉编码器（线性修补器、门控深度 2D 卷积层以及具有 2D 旋转嵌入的双向分组查询注意层）与投影仪和 LFM3 语言模型相结合。投影仪通过层规范和两层 MLP 将每个 2x2 块特征合并为一个语言标记。

链接： 文档

  • [型号] LFM3 系列：LFM3-VL (#50392) by @paulpak58 in #50392

IQuestCoder

IQuest-Coder-V1 是由 IQuest Lab 开发的一系列代码语言模型，提供 7B、14B 和 40B 尺寸，以及基础、指令和思维变体。它的架构与 Llama 相同，因此 Transformers 自动类使用 LlamaModel 和 LlamaForCausalLM 加载它，并且只有 IQuestCoderConfig 特定于 IQuestCoder。循环 IQuest-Coder-V1-*-Loop-* 检查点使用不同的体系结构，不受支持。

链接： 文档

  • 在 #50579 中添加 @hmellor 的 IQuestCoder (#50579)

实习生LM3

InternLM3是上海人工智能实验室开发的8B指令调优语言模型（检查点：internlm/internlm3-8b-instruct）。它的架构与 Llama 相同，因此自动类使用 Llama 实现（LlamaModel 和 LlamaForCausalLM）加载它，并且只有 InternLM3Config 特定于 InternLM3。该配置将注意力偏差命名为 qkv_bias，输出投影和 MLP 偏差命名为 bias。 InternLM3Config 将它们加载为 attention_bias 和 mlp_bias 并要求它们相等，因为它们在已发布的检查点中。
