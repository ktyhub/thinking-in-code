mlflow v3.16.0

MLflow 3.16.0 包括几项主要功能和改进

主要新功能

  • 🎨 自定义跟踪视图：用简单的英语设计您自己的跟踪 UI — 描述您想要的视图，然后 MLflow Assistant 为您构建它，准确地布置您关心的字段，无需配置文件或自定义代码。保存、命名和重复使用每个实验的视图，以便您的整个团队在您的轨迹上共享相同的镜头。
  • 🔭重新设计的跟踪体验（现在是默认值）：跟踪浏览器已经从头开始重建，现在是默认值 - 更紧密的行密度、更清晰的导航和重新设计的跨树视图。 重新排序列，从任何跟踪标记或元数据字段添加可配置的自定义列，并通过会话分组查找内联多轮对话。
  • 🔗 跨度链接：跨度很少是独立的。 MLflow 3.16.0 添加了一流的跨度链接，因此跨度之间的关系（检索步骤、工具调用、下游跟踪）都可以被捕获和导航。在 SDK 中记录链接，跟踪浏览器会在专用的“链接”选项卡中显示它们，以直接跳转到目标范围。
