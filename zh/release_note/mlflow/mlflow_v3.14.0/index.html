mlflow v3.14.0

MLflow 3.14.0 包括几项主要功能和改进

主要新功能

  • 🚀 使用 mlflow agent setup 的单命令代理入门：安装 MLflow、设置跟踪并向您最喜欢的编码代理（Claude Code、OpenAI Codex 或 OpenCode）提供 MLflow 技能来检测您的应用程序，所有这些都通过单个命令完成。
  • ⚡ Claude Code 的持久、低延迟跟踪：充满信心地在整个团队中推出 Claude Code 跟踪：预写日志可防止代理减慢、压垮跟踪服务器或在网络故障或崩溃时丢失跟踪。
  • 📝 审查跟踪队列：将跟踪分配给审阅者（或代理）并在 UI 中收集结构化反馈和真实注释，直接写回到跟踪上，以便它们立即可用于评估。
  • 🗂️ 改进的评估数据集 UI：直接在 UI 中浏览、检查、编辑和批量管理评估数据集记录，并通过 click 直达源跟踪。
  • 🧪 用于回归测试的 Pytest 集成：使用 @mlflow.test 标记将 GenAI 回归测试编写为普通 pytest 函数，在 CI 中对它们进行门控，并在 UI 中查看测试历史记录和每个断言判断结果。
  • 🎛️ LLM Playground：使用设置、工具、结构化输出和模板变量，针对您的 AI 网关端点和提示注册表版本迭代浏览器中的提示。

重大变化

  • [模型] 将 mlflow.sklearn serialization_format 默认值从 cloudpickle 更改为 skops (#23987，@copilot-swe-agent)
  • [模型] 将 mlflow.pytorch.log_model 和 mlflow.pytorch.save_model 的 serialization_format 默认值更改为 "pt2" (#23988，@copilot-swe-agent)
  • [模型] 将 mlflow.lightgbm log_model/save_model 中的 serialization_format 默认值更改为 "skops" (#23986, @copilot-swe-agent)
