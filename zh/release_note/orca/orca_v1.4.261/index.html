orca v1.4.261

上一版本：1.4.259 — 主要性能改进、自动清理和集中的子代理视图。

主要性能改进、光标聊天和可定制的+菜单✨

Orca 1.4.261 使繁忙的聊天工作流程响应更快，并释放您数小时未使用的浏览器页面的内存。光标加入聊天，可自定义的 + 菜单让您可以通过首选方式打开选项卡。

  • ⚡ 在繁忙的聊天之间移动，减少等待： 长对话会在页面中加载其历史记录，当您切换对话时，后台回复会减少侧边栏和隐藏聊天的工作量。
  • 🌐 保留浏览器选项卡而不保持加载每个页面： 默认情况下，内存节省程序会在离开视图四小时后释放符合条件的页面，然后在您返回时重新加载它们。使用会话 cookie 的站点还可以让您在重新启动后保持登录状态。
  • 🤖 在聊天中使用光标： 从计算机上的光标登录开始，选择模型、工作量和快速，批准命令，然后稍后重新打开对话。
  • ➕ 将 + 菜单设为您的： 使用新图标行旁边的齿轮重新排序操作、隐藏未使用的选项并设置快捷方式。通过搜索及其快捷方式仍然可以使用隐藏的操作。
  • ⌨️ 准确推进终端工作： 复制上下文、分叉和继续保留终端程序绘制的空间。编辑 → 粘贴以实际具有焦点的分割窗格为目标。

亮点

  • 为主动工作提供更多空间： 内存节省程序也适用于更新的 orca serve 主机上的浏览器选项卡。桌面选项卡保留其标题、历史记录、cookie 和保存的站点数据。设置 → 浏览器可让您更改空闲间隔或关闭内存节省程序。
  • 更多代理选择： Antigravity Chat 可在 Windows 上运行，Pi Chat 显示子代理。普通 Orca CLI 命令可避免在支持的 Mac 上启动 Electron； macOS 13.4 保留现有启动器。
  • 工作区一览： 实验工作区卡显示活动、未读结果、故障和离线主机。从工作区选项中选择经典或实验。窗格处于睡眠状态的特工不断显示“完成”。
  • 电话导航： 配对的电话界面获得桌面项目组以及用于聊天和终端链接的共享浏览器首选项，包括每次询问。在桌面上，收回对手机驱动的浏览器选项卡的所有返回控制。

兼容性和升级说明

  • 聊天历史记录： 现有聊天会在后台或首次打开时转换到新商店。原始聊天文件在此版本中保留。再次降级升级后，旧版本继续的聊天功能恢复；先前转换的对话可以作为第二次聊天显示在其新版本旁边。
  • 浏览器重新加载： 释放的页面重新加载到位；滚动位置和仅页面内存可以重置。当桌面内存保护程序检测到未保存的编辑或无法安全地评估它们时，它会保留页面加载状态。节省的费用取决于哪些页面符合资格。
  • Android： 旧版应用程序指示用户单独安装新的 dev.orca.app；它无法更新到新包中。此桌面版本不安装手机应用程序。
  • 完成的代理： 当进程退出或其 SSH 主机断开连接时，行离开工作区卡、代理列表和仪表板。睡眠窗格保留其“完成”状态。
