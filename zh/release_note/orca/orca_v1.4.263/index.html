orca v1.4.263

先前版本：1.4.262 - 更快的聊天切换，更低的内存使用和 git 指责。

更轻量级的聊天启动，聊天和浏览器扩展侧面板中的 Hermes ✨

重新打开充满聊天的工作区，减少内存使用和启动工作。恢复的聊天界面在首次显示时加载，Orca 不再重写启动时保存的每个对话。当您返回时，打开的聊天会保留其草稿和滚动位置。

  • 💬 在聊天中继续 Hermes 对话： 从新选项卡菜单启动 Hermes，或在会话历史记录条目上选择 在新聊天中恢复 以在其原始工作区和配置文件中继续终端对话。
  • 🌐 将扩展程序保留在页面旁边： 使用侧面板的 Chrome 扩展程序现在可以在 Orca 浏览器中的可调整大小的面板中打开。 Click 扩展的工具栏按钮以在浏览时使用其面板；扩展弹出窗口还接受粘贴、复制和全选。
  • 🖥️ 实现远程工作： 托管 SSH 端口现在有一个 转发 按钮。在 Windows 上，通过映射的 WSL 驱动器号打开的项目可以移动到其发行版的 WSL 主机上。
  • ⌨️ 重启后保持终端输出可见： 在 macOS 和 Linux 上，shell 停止的终端可以使用其下方的新提示恢复其保存的输出。 Windows 保留其现有的还原行为。

亮点

  • 从命令行连接 Linear： orca linear connect 通过标准输入接受 API 密钥并连接您的目标主机，包括无头服务器。每个主机都保持自己的连接。当您省略 --limit 时，线性问题和项目列表现在会返回所有结果。
  • 在 Windows 上设置代理： Claude 和 Codex 聊天提供在代理丢失时安装，然后再次检查以检测安装。 orca agent installed 还列出了当前主机上已启用的代理 CLI，以用于脚本和启动设置。

兼容性和升级说明

  • Hermes： 聊天需要运行工作区的计算机上有 Hermes 0.23.0 或更高版本。很长的导入会显示最近的消息，而 Hermes 会保留完整的对话。 SSH 工作区无法进行聊天；配对的 Orca 服务器支持它。 Hermes 网关停止后的第一次聊天可能需要一分钟才能开始。
  • 浏览器身份： Native 现在是默认设置，解决了之前默认设置中出现的 Cloudflare 验证循环问题。保留明确的身份选择；在“设置”→“浏览器”→“浏览器身份”中更改您的身份。
  • 手机更新： 下面列出的手机 UI 更改需要相应的移动版本。此桌面更新不会更新 Android 或 iOS 应用程序。

已知问题

  • 改为睡眠工作区： 当该工作区中的另一个选项卡正在运行进程时，该选项可能会失败。
  • orca agent installed --worktree: SSH 和配对服务器工作区上的命令错误。
