orca v1.4.257

先前版本：1.4.256 — 更轻松的设备上听写设置和早期的长聊天性能改进。

更流畅的长聊天、保存反馈和更好的听写 ✨

Orca 1.4.257 可减少同时传输多个长聊天 UI 对话时的冻结情况。如果您让多个代理在具有大量历史记录的对话中工作，则此更新会减少 Orca 在回复到达时所做的工作。

  • 🌐 在重新启动时保留浏览器反馈： Orca 浏览器中页面上未发送的文本注释现在会在重新加载或重新启动后返回。关闭包含未发送注释的选项卡会在丢弃它们之前询问，以便您可以留下反馈并稍后返回。在您按“发送”之前，在桌面上运行的代理可以使用 orca tab annotations 读取这些注释。
  • 🎙️ 听写时给自己一些思考的时间： 在 设置 → 语音 → 输入 → 静音后停止，选择 30 秒、一分钟、两分钟或关闭。当您撰写消息或终端命令时，听写可以等待较长的停顿。同一设置页面添加了一个 测试 按钮来录制和回放麦克风，并在语音模型准备就绪时提供文字记录。
  • ⌨️ 在终端连接时粘贴： 粘贴到启动或重新连接终端的命令现在会等待其 shell，而不是被删除。这涵盖了本地、SSH 和远程终端，可粘贴最大 64 KB 的内容；较大的焊膏仍然需要连接端子。
  • 🗂️ 自动化文件夹工作区例程： 现在，当您创建文件夹工作区时，配置的设置脚本将运行，包括通过 CLI。删除之前运行的存档脚本。使用它们来准备项目并运行其清理例程；这些脚本在共享项目文件夹中运行。

亮点

  • 查找属于拆分窗格的内容： 在空拆分窗格中按 / 搜索代理或文件。使用箭头键和 Enter 无需离开键盘即可打开您的选择。
  • 保留您选择的 Claude 模型： 当较早回合的回复到达时，聊天 UI 选择器会保留您的最新选择，而不是快速返回到其模型。
  • 查看您要求 Codex 制作的图像： 生成的图像在回合结束后仍然可见，而无需展开其工具详细信息。对于远程聊天，请更新主机和 client 以获取此行为。
