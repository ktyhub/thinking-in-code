orca v1.4.256

更流畅的性能、更轻松的听写、保存的手机草稿和更清晰的工作区控制 ✨

当代理流式传输工具输出、推理和子代理工作时，长聊天保持更高的响应速度，并在终端和选项卡更新期间减少后台处理。此更新还使听写更易于设置和使用，并使代理和云工作区更易于管理。以下特定于手机的改进需要匹配的手机应用程序更新。

  • 🎙️ 通过更少的设置进行听写： 语音设置会建议适合您的语言的设备上模型，并提供一个设置按钮。添加个人或存储库词汇，删除填充词，并使用自动模式按住快捷键或点击进行切换。设备上的听写功能会在您暂停时插入短语，并且您可以在 Orca 浏览器中的字段中听写。
  • 📱 从上次停下的地方继续： 手机重新启动后重新连接时，聊天会显示他们保存的最近消息。提交消息、PR 描述、评论、审阅笔记、任务和新工作区草稿在关闭应用程序后仍然有效。
  • ⌨️ 通过手机进行更多控制： 终端按键行获得 Shift、Ctrl 和 Alt 锁存器以及带有代理操作的可选智能导轨。浮动听写丸可让您在移动到应用程序中的另一个屏幕时继续说话。
  • 🤖 让代理从聊天中做好准备： 支持的缺失代理在您开始聊天时提供安装和登录指导。 OpenCode 子代理出现在自己的卡片中，并在工作时保持聊天活跃；法典回复可以在倒带后分叉。
  • 🧭 找到您需要的控件： 浏览器将其工具分组为“注释”按钮和一个菜单。设置更容易扫描，并且配方支持的虚拟机工作区通过暂停和恢复操作显示其生命周期。

亮点

  • 语音和听写： 当您开始听写时，听写丸中会提供语音模型更新，包括下载进度、取消和重试。基于语言的设置建议、模型质量信息、使用 GPU 开关、个人和存储库词汇以及对 OpenAI 兼容转录服务的支持。听写丸显示已承诺和未决的单词；失败的录音可以重试。听写时按“发送”或“Enter”会等待单词，然后再发送。
  • 电话和恢复： 重新启动后会返回保存的聊天消息和草稿文本。主页打开时显示最后已知的工作区，访问的终端保持安装状态以实现更快的切换，并且页面资源按需加载。文件夹工作区在手机上有源代码管理，大文件差异保留未更改的行。
  • 聊天和代理： 复制和其他回复操作在最新回复中保持可见，而较早的回复则在悬停或键盘焦点时显示它们。帐户使用情况显示已使用、剩余时间和重置前的时间。 Claude 聊天名称使用 CLI 的标题，问题可以显示选项预览，Codex 失败提供可行的建议，并且“设置”中提供了新的分隔线。到期的使用限制聊天可以一次性继续，并在连续五次失败后自动重试停止。
  • 工作区和远程主机： 设置脚本导入了解更多现有存储库配置。 VM 工作区显示创建进度和失败，并且可以从其工作区控件恢复挂起的 VM。当主机停止应答时，会检测到配对服务器连接失败。
  • 浏览器、编辑器和日常修复： 浏览器注释、绘图和元素捕获共享一个控件，在地址字段中具有缩放和视口状态。保存内联或并排差异选择。线性搜索和问题列表包括项目，代理速度菜单提供所选模型支持的速度。

听写升级说明： 现有的本地语音模型下载可能需要更新才能再次进行听写。在离线听写之前，先从听写丸或语音设置完成下载。
