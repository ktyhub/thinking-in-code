hyperframes v0.9.56

超帧 v0.9.56

发布于 2026 年 11 月 16 日。

Studio 的预览和本地服务器现在仅适用于它们自己的页面。 CLI 将其缓存、历史记录和恢复保留在项目内。 arm64 Lambda 映像仅提供经过审查的 ffmpeg 构建，并且大型预览的构建速度更快。

修复

  • Studio Server： 合成文件服务器不再提供凭证或工具状态文件（014326b40、#7889）。
  • Studio Server： Lint 和探测仅针对来自 Studio 自己页面的请求运行（bbac8900e、#7894）。
  • Studio Server： 历史记录还原保留在项目内部，并且仅使用完整副本（478313ba0、#7902）。
  • Studio： 将回放作品用于其服务器不透明的预览（1e542956d、#7815）。
  • Studio： 预览帧将沙箱原点保留在其主机集（b650d0d19、#7886）。
  • Studio： 当前套牌仅在其自己的站点中打开，并且预览仅读取其自己的框架的消息（4067efc45、#7877）。
  • 核心： 运行时桥在对其进行操作之前会检查每个控制消息（97d8f26e7、#7892）。
  • CLI： render --docker 将主机的页面网络限制保留在容器内（[5d8605eb8]（https://github.com/heygen-com/hyperframes/commit/5d8605eb8e56fa6de714482e99c9f63cd258581a），[#7890]（https://github.com/heygen-com/hyperframes/pull/7890））。
  • CLI: preview --stop 仅停止系统报告持有端口的进程（ace8a78dc、#7882）。
  • CLI： 检查缓存仅保存为项目记录，而不是通过链接文件（[7801e3ff3]（https://github.com/heygen-com/hyperframes/commit/7801e3ff346f65d994ef64d9c5d067f3dcd52b87），[#7884]（https://github.com/heygen-com/hyperframes/pull/7884））。
  • CLI： 检查从项目文件夹读取的历史回合 ID 并编码发送（6efa6b635、#7883）。
  • CLI： 追赶仅列出应用程序在交接后添加的转弯（[0f23f40f8]（https://github.com/heygen-com/hyperframes/commit/0f23f40f8b06761a57922c85721209d6c4943f25），[#7874]（https://github.com/heygen-com/hyperframes/pull/7874））。
  • CLI： 项目下文件夹中的接收文件记录对于渲染计数（1c159c550、#7900）。
  • CLI： 媒体用途仅复制其捆绑索引名称的声音效果（[ed93a1312]（https://github.com/heygen-com/hyperframes/commit/ed93a131251a1ae6c21fd3908c86f9972765d5c6），[#7895]（https://github.com/heygen-com/hyperframes/pull/7895））。
  • 媒体使用： 本地模型从项目外部的文件夹开始（756c2c6c1、#7888）。
  • 引擎： 仅当其文件与固定版本匹配时才使用缓存的浏览器（56a2d0c53、#7865）。
  • 引擎： 时间轴帧预测保留在渲染帧内（f5a74a567、#7885）。
  • 引擎： 每个超集提取都在其自己的文件夹中工作（a4139e9ea、#7901）。
  • 解析器： 在任何输入上读取画布脚手架的宽度和高度都需要同样短的时间（b856a1d63、#7873）。
  • Lint： 特工制作的场景和音效保留在一条时间线通道上（98208241e、#7775）。
  • 技能： 独立安装也可以通过其启动器运行 CLI（3fc3050bc、#7879）。
  • AWS Lambda： 仅当版本与在其构建旁边提交的摘要匹配时（d9488119b、#7872），才会发布arm64 ffmpeg。

性能

  • 核心： 预览版本会读取一个大页面，而无需在每次传递时复制它（082d63683、#7878）。
  • 生产者： 编译和渲染遥测标签扫描所需的时间与页面大小同步（[82fdf406c]（https://github.com/heygen-com/hyperframes/commit/82fdf406c43851ac75a82a0d49aa944cdc955254），[#7896]（https://github.com/heygen-com/hyperframes/pull/7896））。

内部

  • 发布： 每个 npm 发布都会等待 npm-publish 批准（a54de748e、#7870）。
  • 发布： 预构建的 tarball 从不运行发布提交中的代码的作业中发布（af0560c85、#7869）。
  • CI： 发布工作流程仅针对主程序运行（7bd6b9daf、#7875）。
  • CI： 测试装置不再看起来像真正的 HeyGen 钥匙，CI 拒绝了这样的钥匙（5dc3b336a、#7876）。
