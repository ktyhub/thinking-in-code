hyperframes v0.9.59

超帧 v0.9.59

发布于 2026 年 11 月 16 日。

预览播放器有一个全屏按钮，失败的渲染现在说明了原因。渲染、Studio 和 CLI 保留项目自己的文件和公共媒体主机。

特点

  • CLI: Diff —hide 根据项目添加的内容对项目的图层进行评分（e6d5c699b、#7972）。
  • 播放器： 将全屏按钮添加到预览播放器（5be6c1580、#7726）。
  • 核心： 描述回复带有选择器的元素标签，并且工作室导出standInHandle（[51ae92510]（https://github.com/heygen-com/hyperframes/commit/51ae92510502dae5255f997058e9a5dfa399ad77），[#7936]（https://github.com/heygen-com/hyperframes/pull/7936））。

修复

  • 隐藏文件和凭证文件远离 Studio、历史记录和 lint（c68c78445、#7979）。
  • 核心： 标记为另一个站点的页面仅允许该站点播放（c4d607c7f、#7980）。
  • Studio Server： 没有写入路径触及其他工具运行的文件或 trust (2a28e4368、#7964)。
  • CLI： 技能更新检查永远不会读取项目的 git 配置（[e368db138]（https://github.com/heygen-com/hyperframes/commit/e368db138f343e90324801c2c78c6c4baa6420be），[#7975]（https://github.com/heygen-com/hyperframes/pull/7975））。
  • Lint： 从主机自己的线程运行 Studio 和生产者 lint（[778a00564]（https://github.com/heygen-com/hyperframes/commit/778a005641db50f2f37ef8d40cf813c58a30cee4），[#7974]（https://github.com/heygen-com/hyperframes/pull/7974））。
  • 制作人： 探测子组合媒体默认值（95e4e7f88、#7550）。
  • CLI： 使用控制字符作为可见转义符验证并关键帧打印项目文本（[ce8d55d30]（https://github.com/heygen-com/hyperframes/commit/ce8d55d302c3d9949d839cff7043feaf5fd56020），[#7958]（https://github.com/heygen-com/hyperframes/pull/7958））。
  • 检查： 加载失败的媒体源不会报告为超时（5e0c3db12、#7954）。
  • CLI： 帮助显示每个选项的默认值一次（[d7f8d77fb]（https://github.com/heygen-com/hyperframes/commit/d7f8d77fb4a7b0c7096a069649e864ba133e4976），[#7953]（https://github.com/heygen-com/hyperframes/pull/7953））。
  • CLI: 渲染 —json 为每个缺失的工具、一个保留的插槽和一个旧节点提供自己的代码（47d007e5b、#7842）。
  • Sdk Playground： Vite 配置在 22.18 之前在节点 22 上加载（c7876f333、#7805）。
  • 检查： 按其严重性标记对比结果并引用其文本（ec5a4e2a1、#7752）。
  • 播放器： 从此版本中提取了当许多 clips 共享一个长录音时预览冻结的修复，因为它阻止了嵌入预览的应用程序显示编辑（42508c1ef、#7795；已由 33e1a36a3 恢复， #7978)。
  • 快照跳过私人文件，无文本艺术解复用器，转义警告文本（[8959deb00]（https://github.com/heygen-com/hyperframes/commit/8959deb00f2c41f42bf0351a52982a9fd8d23b01），[#7943]（https://github.com/heygen-com/hyperframes/pull/7943））。
  • CLI： Capture 在旁路条目中命名其本地页面服务器的端口（[a9b0371c8]（https://github.com/heygen-com/hyperframes/commit/a9b0371c83656e7c911c041c9bb827c83af068c8），[#7965]（https://github.com/heygen-com/hyperframes/pull/7965））。
  • CLI： 失败的渲染会说明原因，即使在崩溃或无提示退出时也是如此（[2623ded13]（https://github.com/heygen-com/hyperframes/commit/2623ded13684de4af7de4595cad1063eecb0a0a1），[#7957]（https://github.com/heygen-com/hyperframes/pull/7957））。
  • Studio： 来自项目外部的长音频文件永远不会对其波形进行解码（c77cd301c、#7961）。
  • 发布： 仅上传 npm 读取的已检查内容；标签仅发布 main、next 或 alpha 提交（5f4637977、#7959）。
  • 引擎： 媒体 URL 读取仅到达受限页面网络下的公共主机（994fbbde2、#7946）。
  • Cli,engine: 将页面服务器的直接主机固定到显式端口和 Studio 自己的源（dbc9c1826、#7945）。
  • 制作人： 等待长音频混合的渲染器表示它正在处理音频（df698a029、#7952）。
  • 核心： 捕获页面仅在到期时加载没有设定长度的 clip （9e5048772、#7938）。
  • 工作室： 节拍分析永远不会选择比歌曲长的录音（87955b890、#7944）。
  • CLI: 自己的渲染槽锁定目录；拒绝其他帐户可以写入的缓存文件（[071a2da0b]（https://github.com/heygen-com/hyperframes/commit/071a2da0b5b1f3d278650fb432da79b32726990d），[#7951]（https://github.com/heygen-com/hyperframes/pull/7951））。
  • CLI： 切勿通过 .hyperframes 下的符号链接写入项目记录（061ff5bbb、#7950）。

文档和示例

  • Changelog： 每周摘要 2026-11-09-2026-11-16（[af873924d]（https://github.com/heygen-com/hyperframes/commit/af873924dbc8c3a5ac17cd2175214ee64adb90e1），[#7969]（https://github.com/heygen-com/hyperframes/pull/7969））。
  • 发布： 假设发布不等待任何批准，只有管理员推送预发布标签（a707e4737、#7960）。

目录

  • CLI： 转义项目、页面和注册表文本中的控制字符（6f88be394、#7913）。
  • Mcp： 在 mcp-registry 环境中运行 MCP 注册表发布（45ff3526c、#7966）。
  • Ci: main 取代的目录发布运行干净地结束，而不是失败（77e675574、#7816）。
