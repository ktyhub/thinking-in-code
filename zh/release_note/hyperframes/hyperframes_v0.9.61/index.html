hyperframes v0.9.61

超帧 v0.9.61

发布于 2026 年 11 月 17 日。

收到的项目及其到达的文件在渲染、预览和 Studio 中保留在自己的文件夹中，并且密封的预览会在不到一秒的时间内重新加载到位。此版本还包含针对 0.9.60 列出的所有更改。该版本从未到达 npm：它的发布被拒绝，因为它从发布 PR 的合并引用运行，并且自 #8020 以来，稳定版本从推送到合并它的 main 发布。

特点

  • 引擎： 渲染遥测说明为什么页面无法重用静止帧（[c8df284b2]（https://github.com/heygen-com/hyperframes/commit/c8df284b2ed15ae0ade05bf90e95192d05f3d1c6），[#7993]（https://github.com/heygen-com/hyperframes/pull/7993））。
  • Studio： 元素的源解析动画是 Studio API 的一部分（efc91fc87、#8061）。
  • 生产者： 在捕获之前强制执行预期的输出尺寸（8a13b2caf、#7871）。

修复

  • 制作人、解析器： 渲染编译永远不会在另一台计算机上查找场景的资源（524ea46bf、#8063）。
  • CLI： 拒绝媒体代理复制另一个站点请求的播放和静态服务器（[f97e28905]（https://github.com/heygen-com/hyperframes/commit/f97e289058adb5ad5f04982bf8be3245abb59b54），[#8058]（https://github.com/heygen-com/hyperframes/pull/8058））。
  • **制作人：**读者重新检查外部链接的成分，拒绝指定每个表面可以采取的步骤（[4721739ee]（https://github.com/heygen-com/hyperframes/commit/4721739ee702725abaca88e3ebb1dc9af6fd8288），[#8034]（https://github.com/heygen-com/hyperframes/pull/8034））。
  • CLI： 将项目外部的文件排除在 Lambda 和 Cloud Run 站点上传之外（39347da9d、#8060）。
  • CLI： 主持人可以命名预计收到或全部收到的文件的项目（[5ea86450a]（https://github.com/heygen-com/hyperframes/commit/5ea86450a21fe80a9817420a2aab84261f41f3d7），[#8025]（https://github.com/heygen-com/hyperframes/pull/8025））。
  • 核心： 只有 Studio 自己的预览页面才能获得编辑端口，并且撤消仅设置安全属性（55291c00c、#8057）。
  • Lint： 按字面意思匹配定时包装器的关闭标记（3e01f691d、#8028）。
  • Studio： 一旦其保存落地，每个拖动都会显示为自己的撤消步骤（[647bdd4d7]（https://github.com/heygen-com/hyperframes/commit/647bdd4d7c3f376cae2963ace3b093d25ddf1b85），[#8033]（https://github.com/heygen-com/hyperframes/pull/8033））。
  • CLI： 拒绝的反向启动报告 HeyGen 是否发送了拒绝（53080581c、#8053）。
  • 制作人： 限制渲染的总子合成扩展（b29e40d70、#8045）。
  • 检查器： 检查器的 Chrome 以 root 身份或在容器中启动（f91bbf0da、#8050）。
  • 拒绝 ffmpeg 的 image2 解复用器将读取为模式的媒体路径（fe93f9cd4、#8047）。
  • CLI： 项目 .env 提供程序密钥让位于个人自己的凭据（[14c4e4c26]（https://github.com/heygen-com/hyperframes/commit/14c4e4c268dc3dd4df0f4299151260d9839be8d0），[#8041]（https://github.com/heygen-com/hyperframes/pull/8041））。
  • **CLI：**转义音频和媒体使用输出，引脚模型文件（[c4439890c]（https://github.com/heygen-com/hyperframes/commit/c4439890cfbcdbc16d48f1a4b05176abe0138cae），[#8013]（https://github.com/heygen-com/hyperframes/pull/8013））。
  • 生产者： 保持探针阶段的介质预检查与页面大小呈线性关系（e21f56dca、#8044）。
  • Studio： 颜色分级在密封预览中工作（d7d416124、#7999）。
  • 引擎： 通过下载超时绑定代理主机预检查（06b632017、#8048）。
  • 引擎： GPU、主机天花板和 HDR 启动将沙箱保留在主机允许的位置（7b27fbc84、#8038）。
  • Studio Server： 缓存读取永远不会遵循项目附带的链接（70820b386、#8039）。
  • 引擎： 检查代理下载主机；将原始 GIF 下载保持私密（5fcce21a6、#8040）。
  • 技能： Locate.mjs 读取系统字体，而不是共享的 /tmp 副本（5b2990fc1、#8042）。
  • Studio： 字幕编辑在密封预览中进行（915021265、#8002）。
  • 制作人： 将软件编码器限制在核心捕获空闲位置（f89f6d3d4、#8019）。
  • Studio： 密封预览的重新加载会在不到一秒的时间内显示，而不是在 8 秒后显示（9daa7e876、#8015）。
  • 技能： 从技能文件夹而不是工作目录（6115945cf、#8035）运行捆绑的 TTS 帮助程序。
  • 接收到的文件记录会跟随 Studio 重命名、移动和删除，并且嵌套记录无法移出范围（f5bb3e551、#7989）。
  • Studio Server： 除非应用程序对其进行了框架处理，否则将标记没有获取元数据的环回页面（b6e1e8dda、#8017）。
  • Studio： 复制的渲染命令不包含 shell 可以运行的合成文本（19743ea09、#8012）。
  • 开发工作室的渲染遵循接收项目规则，并且接收项目的 .env 密钥永远不会替换该人自己的密钥（8239fe470、#8004）。
  • 制作人： Trusted 渲染拒绝外部链接的合成，除非 —include-outside-files (00d03a412、#8024)。
  • Studio Server： 音频解码是有限的，无人等待时停止，并且其缓存已上限（5f6995fe7、#7991）。
  • Studio： 从弹出窗口或菜单打开的模式首先在 Escape 上关闭（c8235f123、#7976）。
  • 引擎： GPU 探针、HDR 捕获和主机天花板探针保留所需的沙箱（fb5f9e52c、#8018）。
  • CLI: 渲染 —docker 在主机上应用接收项目规则（e58fb3249、#8016）。
  • Studio： 密封预览上的撤消显示到位，而不是在重新加载后显示（fee03bfbe、#8009）。
  • CLI： 来自项目外部的文件仅在获得批准后才会上传（22b615f1a、#7995）。
  • CLI: 比较和关键帧 —shot 仅提供裸 HTML 文件名的文件（346579b6b、#8006）。
  • 预览图像准备不会读取项目外部的 HEIC 或 GIF，除非渲染会读取（f880693cf、#8001）。
  • 引擎： 播放列表文件夹检查会在 ffmpeg 解析时读取冒号、查询和片段名称（38aaad1b2、#8014）。
  • Studio Server： 绑定预览剧照并将代理工作保留到 Studio 自己的页面（bffe8d598、#8007）。
  • 制作人： 本地渲染会忽略项目外部的脚本，除非包含在内（581a43bb6、#7998）。
  • CLI： 只有工作室自己的来源可以构建工作室页面（[02c1fb48e]（https://github.com/heygen-com/hyperframes/commit/02c1fb48e7d8d89efa3746e6f3b0ea16027753e0），[#8000]（https://github.com/heygen-com/hyperframes/pull/8000））。
  • 生产者： 线性探针媒体检查，并渲染超过 16 MB 的垃圾合成 HTML（d53b6059b、#7992）。
  • Studio Server： 历史写入和声明遵循 Studio 的写入规则（32fe10a8b、#7988）。
  • CLI： 错误框和命令失败行将控制字符打印为可见转义符（[5979991d5]（https://github.com/heygen-com/hyperframes/commit/5979991d5f0af542fbb02ba906bdba4de52b2b64），[#7987]（https://github.com/heygen-com/hyperframes/pull/7987））。

＃＃ 内部的
