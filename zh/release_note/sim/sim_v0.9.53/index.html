sim v0.9.53

特点

  • feat(credentials)：从 v2 API、CLI 和 Sim MCP 设置无密钥凭证 (#9875)
  • 壮举（凭证）：无密钥 Snowflake、仅 Microsoft 应用程序和 Google 无密钥、GitHub 和 Bitbucket 令牌、DocuSign JWT (#9869)
  • feat(mistral)：将 PDF 图像提取为文件并在 Mistral Parser 中公开表格格式 (#9856)
  • feat(api)：运行固定部署版本并公开 v2 中暂停的运行点 (#9854)
  • feat(api-keys)：只读 API 密钥并在创建时过期 (#9855)
  • feat(api)：工作流程通过 v2 API 触发运行状况和启用 (#9853)
  • feat(network)：尊重受保护请求的 HTTP_PROXY、HTTPS_PROXY 和 NO_PROXY、AWS SDK clients 和 OTLP 导出 (#9851)
  • feat(credentials)：在一个主机感知检查工厂上保存 21 个令牌和主机块的凭证 (#9849)
  • feat(api)：通过 v2 API 管理工作区成员 (#9852)
  • feat(credentials)：保存了另外 17 个区块的凭证、GitLab 代币和无密钥强化 (#9840)
  • feat(search)：通过共享的 API 和 CLI 管理源权限 (#9845)
  • feat(search)：通过 API 更新 GitLab 权限 CSV (#9841)
  • 壮举（库）：AI 代理开发公司与内部构建：如何决定（#9844）
  • feat(library)：2026 年支持 A2A 协议的最佳 AI 代理平台 (#9843)
  • 壮举（库）：2026 年具有内置 Web 搜索和研究工具的 AI 代理构建器 (#9842)
  • feat(credentials)：保存的凭证和仅凭证块版本，具有无密钥 AWS/Databricks OIDC (#9763)

改进

  • 改进（api）：发布 v2 成员分析、工作流访问中间件和文档的审计后续措施（#9858）
  • 改进（搜索）：当 MCP client 请求更多块时，返回更长的实时读取窗口（#9823）

错误修复

  • 修复（凭证）：更正无密钥设置指令并在每个凭证块上强制执行已保存的凭证合同（#9878）
  • 修复（mistral）：假设 V3 解析上传或引用的 PDF，并将最大图像限制为 100 (#9872)
  • 修复（发布）：拒绝主机的 host_not_allowed、仅内部 JWT 秘密发布和最终发布审核清理（#9870）
  • 修复（sim-setup）：阻止 doctor —fix 将 ${VAR} 引用转换为文字（#9868）
  • 修复（凭据）：将拒绝的主机报告为用户的输入，保留规范化的帐户 ID，限制 Databricks 读取 (#9859)
  • 修复（发布）：无密钥主题唯一性、NO_PROXY IPv6/CIDR、代理启动机密和剩余审核后续工作（#9866）
  • 修复（发布）：小型发布审核清理（#9863）
  • 修复（发布）：仅重用完全访问委托密钥并将空白爬行深度视为未设置（#9857）
  • 修复（安全性）：强化发布审核中保存的凭证、代理出口和无密钥薄荷路径（#9865）
  • 修复（发布）：编辑部署密钥，检查已保存凭证合约中支持操作的工具，并删除 SDK 副本 (#9864)
  • 修复（发布）：在自己的变量上运行固定的异步版本，映射 CLI 密钥创建错误，将 GitLab 令牌显示为当前块（#9862）
  • 修复（sim-setup）：引用包含 $ 的 env 值，因此 dotenv、Bun 和 Compose 不会扩展它们（#9861）
  • 修复（发布）：限制代理的纯 http 响应，从起始 URL 计算 Firecrawl 深度，并在升级时删除过时的路由缓存 (#9860)
  • 修复（firecrawl）：完整的 v2 响应和深度兼容性（#9847）
  • 修复（cli）：将 sim-setup 的容器绑定到环回，修复重置和 env 引用，淘汰旧版 simstudio CLI (#9830)
  • 修复（docker）：保持 ISR 和后缀列表缓存在只读根上可写（#9829）

其他变化

  • 测试（api-keys）：在内部错误装置中使用中性数据库角色名称（＃9877）
  • 测试（凭证）：使用非令牌形状的 GitHub 夹具，以便秘密扫描保持安静（#9876）
  • 文档（发布）：更正 Discord 允许列表注释、Mistral 图像命名和 NO_PROXY 参考 (#9874)
  • 文档（技能）：在添加集成令牌凭据步骤中命名拒绝UnsafeTypedUrl (#9873)
  • 杂务（sdk）：使用实时发布系列作为桌面源的无关发布固定装置（#9850）
  • 杂务(sdk)：删除 TypeScript 和 Python SDK (#9848)
  • 杂务（deps）：采用 vitest 5.1、shiki 4.6、react-hook-form 7.91、MCP SDK 2.4 和小型范围内更新（#9846）
  • 杂务（deps）：将 pi 升级到 1.5.0 (#9826)
  • ci：通过 7 个更新在 2 个目录中碰撞操作组 (#9839)
