appsmith v2.7.0

小版本 发布时间2026年11月12日 来源appsmithorg/appsmith 英文原文

appsmith v2.7.0

⚠️ 重要升级说明

  • Helm 图表：如果您设置了一些 probes 键，则您未设置的键现在将采用新的默认值（10 秒周期，5 秒超时）。如果您将 failureThreshold 调至旧 60 年代时期，则还要设置 periodSeconds: 60。非正整数的探测值现在会失败 helm install 和 helm upgrade。引用的数字（例如 "5"）仍然有效。 (#42571)
  • navigateTo 到不再存在的页面名称现在会失败，并显示“输入有效的 URL 或页面名称”，即使参数值包含点也是如此。之前，它以网址的形式打开名称，例如https://OldPage?file=report.pdf。带有点参数的单字主机（例如 intranet）现在也会失败。请改用完整的 URL。 (#42513)

🔐 安全

  • 更新了捆绑依赖项以解决报告的漏洞。 (#42502)
  • 读取应用程序的自定义 JS 库现在需要对该应用程序的读取权限。 (#42431)
  • 打开使应用程序可分叉现在需要应用程序的导出权限。具有编辑权限的用户仍然可以将其关闭并进行其他更改。 (#42411)
  • S3 兼容和 DynamoDB 数据源现在遵循已涵盖 REST、GraphQL、Elasticsearch、Redis 和 SMTP 的受限主机策略。端点主机被阻止的数据源无法使用 Host not allowed. 进行保存、测试或运行 (#42527)

🛠️ 可靠性

  • 一旦删除了与 Git 连接的应用程序，删除该应用程序就会立即返回。之后会运行本地存储库清理，因此缓慢的磁盘不会再导致删除超时并将应用程序卡保留在原位。 (#42519)
  • MCP read_pages 为每个页面返回一个 layoutId。并行页面读取不再被令牌检查拒绝，失败的读取会重试一次，并且仍然失败的页面会报告原因。 （[#42360]（https://github.com/appsmithorg/appsmith/pull/42360），[#42529]（https://github.com/appsmithorg/appsmith/pull/42529））
  • MCP 拒绝曾经给出损坏或错误结果的输入。示例：wire_event 调用参数中的不平衡大括号、布局工具中另一个应用程序的页面以及命名为 SQL 关键字的列上的结构化 SQL 过滤器。 （[#42536]（https://github.com/appsmithorg/appsmith/pull/42536），[#42537]（https://github.com/appsmithorg/appsmith/pull/42537））
  • 当代理读取页面后页面发生更改时，MCP 布局更新将被拒绝。 (#42538)

✨ 新功能和增强功能

  • 表格自动高度：将表格的高度设置为自动高度（或有限制的自动高度）并选择每页行数。表会增长以适应这些行，并且页面会滚动而不是表。现有表保持固定。 （[#42489]（https://github.com/appsmithorg/appsmith/pull/42489），[#42585]（https://github.com/appsmithorg/appsmith/pull/42585））
  • 应用程序设置 → 导航具有 显示共享 和 显示所有应用程序 切换以隐藏已发布应用程序中的这些按钮。两者均默认开启。共享权限不会改变。 (#42487)
  • 页面导出（页面菜单 → 导出）在每个部分中都有全选：JS 对象、数据库、查询和自定义库。 (#42453)
  • 按钮组按钮可以显示工具提示，就像按钮小部件一样。 (#42583)
  • JSON 表单在样式 → 颜色下有 标题字体颜色 设置。 (#42565)
  • MCP 结构化 SQL 可以使用 coalesce 显示 NULL 列的后备值。 (#42497)
  • MCP结构化SQL可以使用having过滤聚合组。 (#42503)
  • MCP 结构化 SQL 可以在 PostgreSQL 上拆分分隔列并对每个项目进行计数。 (#42504)
  • MCP get_action 返回 MCP 编写的查询的 SQL，只要没有人在编辑器中更改它。 (#42505)
  • 新的 MCP 工具 set_page_visibility 隐藏或显示页面。主页无法隐藏。 (#42506)
  • MCP 导航事件可以传递 URL 参数，例如所选行的 id。 (#42507)
  • 通过 MCP 删除小部件现在需要用户的批准（prepare_remove_widgets、confirm_remove_widgets），就像删除页面或查询一样。 (#42509)
  • MCP JS 对象可以对行进行排序、剪切、求和、平均和分组，以及按天、周或月存储日期。 (#42511)
  • MCP 可以构建条件表单：取决于选择的默认值和限制、日期数学、在一种情况下显示或所需的字段、在表单有效之前禁用的提交按钮以及登录用户的姓名或电子邮件。 (#42540)
  • MCP可以读取编辑器中编写的JS对象。如果设置了审批，则可以在用户审批后进行替换。 (#42538)
  • MCP 将 JS 对象编写为可读的格式化代码。 (#42549)
  • MCP 结构化查询在 Oracle 上生成可运行主体，并在 MongoDB 查询中使用严格值。 (#42538)

🎨 UI 和小部件改进

  • 表 CSV 和 Excel 下载为 HTML 列写入纯文本，而不是原始 HTML。 (#42557)
  • 表单元格中的图标按钮、菜单按钮和视频控件适合行高，因此分页表不再需要滚动条即可到达最后一行。 (#42570)
  • 关闭表格中的无限滚动不再打开允许添加行、搜索、过滤和排序。它们会保持关闭状态，直到您将其打开。 (#42573)
  • 表保存/放弃列禁用字段再次显示其完整绑定。编辑它不再启用每一行的“保存/放弃”。 (#42589)
  • 重置 JSON 表单会使空数组字段保持为空，因此表单保持有效。 (#42226)
  • JSON 表单中的必填日期字段仅在用户触摸后才显示其错误，与其他字段一样。 (#42514)
  • 工作区徽标选择器不再提供服务器始终拒绝的 SVG。现在可以选择 JPG 文件。 (#42594)
  • 编辑器隐藏了已退役的 Appsmith AI 数据源及其查询。该服务于2026年9月30日停止。Ask AI不受影响。 (#42559)

🔧 Git、部署和配置

  • Helm Chart 运行状况探测现在每 10 秒运行一次，超时时间为 5 秒。 Startup允许600秒启动，liveness在180s失败后重新启动容器，readiness在30s后标记pod未就绪。保存重新启动服务器的管理设置不会再导致容器被终止。 (#42571)
  • 备份可以跳过 APPSMITH_BACKUP_EXCLUDE_COLLECTIONS（逗号分隔）中列出的 MongoDB 集合。 (#42581)
  • 服务器记录拒绝 MCP 令牌的原因，例如过期或撤销的密钥。它从不记录秘密。 (#42593)
