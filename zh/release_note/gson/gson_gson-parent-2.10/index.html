发布 发布时间2022年10月25日 来源google/gson 英文原文

gson gson-parent-2.10

最重要的变化

  • 支持序列化和反序列化 Java 记录，Java ≥ 16。(#2201)

  • 添加 JsonArray.asList 和 JsonObject.asMap 视图方法 (#2225)

  • 修复 TypeAdapterRuntimeTypeWrapper 未检测到反射型 TreeTypeAdapter 和 FutureTypeAdapter (#1787)

  • 改进 JsonReader.skipValue() (#2062)

  • 对原始数字类型适配器执行数字转换 (#2158)

  • 添加 Gson.fromJson(..., TypeToken) 重载 (#1700)

  • 修复影响现有 Gson 实例的 GsonBuilder 更改 (#1815)

  • 使 JsonElement 转换方法更加一致并修复 javadoc (#2178)

  • 当不支持 JsonWriter.jsonValue 时抛出 UnsupportedOperationException (#1651)

  • 禁止 JsonObject Entry.setValue(null) (#2167)

  • 修复 TypeAdapter.toJson 为自定义 IOException 抛出 AssertionError (#2172)

  • 将 JsonArray.set 的 null 转换为 JsonNull (#2170)

  • 修复了 nullSafe 的使用。 (#1555)

  • 验证 TypeToken.getParameterized 参数 (#2166)

  • 修复#1702：Gson.toJson 创建未实现 toString 的 CharSequence (#1703)

  • 优先选择现有适配器进行并发 Gson.getAdapter 调用 (#2153)

  • 改进 ArrayTypeAdapter 为 Object[] (#1716)

  • 改进 AppendableWriter 性能 (#1706)
