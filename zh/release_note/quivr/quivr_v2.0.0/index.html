quivr v2.0.0

Quivr 2.0.0

Quivr 是一个开源引擎，用于不断更新的内容。您的应用程序或 Quivr 的来源（RSS、Microsoft 365 邮箱、X 列表）向其发送文档。 Quivr 保留每个文档的每个版本，并使其可以在几秒钟内通过关键字、含义或两者进行搜索。它还会根据您保存的警报检查每个新文档。 Quivr 没有用户界面：您的应用程序通过 HTTP API 与它对话，AI 代理通过 quivr mcp 使用它。

2.0.0 是重写的 Quivr 的第一个稳定版本。阿尔法用于评估。从这个版本开始，Quivr 做出了您可以信赖的承诺。

2.0 的承诺

  • 稳定的 API。 HTTP API 为每个 2.x 版本保留 /v0 路径。 2.x 版本仅添加了：新端点、可选字段、响应字段和枚举值。可能会破坏正常工作的 client 的更改需要等待下一个主要版本。
  • 保留数据的升级。 从一个 2.x 版本升级到另一个版本会运行 quivr migrate，然后滚动工作线程和 API，同时保留您的数据。
  • 检查其兼容性的插件。 插件声明它支持的插件 API 版本，而 Quivr 拒绝激活它无法运行的版本。
  • 每个功能都有清晰的状态。 文档中的所有内容在 2.x 内都是稳定的，除了实验性功能的简短列表外，每个功能都在其页面上进行了标记：搜索测量工具、Jev 重新排名和 Jev 判断警报、专用向量主机和 quivr-autoscaler 二进制文件。

版本和兼容性 有详细信息。 已知限制 列出了 2.0 尚未执行的操作：它仅搜索文本，没有 OCR，没有用户帐户，并且每个文档和每个搜索都有大小限制。

开始吧

  • 在本地尝试： 克隆存储库，运行 make dev，然后按照快速入门 操作，大约十五分钟。
  • 从已签名的发布映像 (linux/amd64) 将其安装在服务器上：请参阅在一台计算机上运行 Quivr，或针对铁路和 Kubernetes 的部署和配置 Quivr。
  • 先了解它： 核心概念 和 Quivr 工作原理。

来自 2.0.0 alpha

不支持就地升级 alpha 安装。开始全新的 2.0.0 安装，或从 alpha 导出文档并将其发送到新安装。

自 2.0.0-alpha.7 起

  • 安全：
    • Quivr 及其镜像是使用 Go 1.27.3 构建的，适用于 CVE-2026-111943；
    • golang.org/x/net、certifi、pillow 以及 SeaweedFS 映像的 curl 和 brotli 已修补。
  • 搜索在数据库重新启动后恢复，其缓冲区已恢复并且其水合工作受到限制。
  • 进口：
    • 连续导入期间队列计数保持可用；
    • 自动缩放器为连接器导入添加批量工作人员。
  • 文档：
    • 为新手重写，添加新页面：Quivr 的工作原理、术语表、版本和兼容性以及已知限制；
    • “评估阶段”警告消失了。

自第一个 alpha 以来的完整更改列表位于 CHANGELOG.md 中。
