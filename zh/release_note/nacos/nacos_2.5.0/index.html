nacos 2.5.0

小版本 发布时间2025年1月21日 来源alibaba/nacos 英文原文

nacos 2.5.0

该版本主要引入配置灰色历史记录功能，并对配置灰色管理进行重构和优化，使用户能够更高效地管理配置发布和灰色配置。需要注意的是，本次更新可能会导致Nacos使用的数据库表结构发生一定变化，升级后首次启动可能需要一段时间进行数据自动迁移（这种情况仅适用于旧版本中已使用测试灰色功能的集群）。 除了上述功能外，该版本还对其他几个功能进行了重大优化和错误修复，包括但不限于以下内容：

  • 统一client寻址逻辑并提供自定义扩展接口。
  • client在请求过程中遇到无权限状态时会自动刷新token，无需等待token过期。 请参阅以下更改的详细信息：
