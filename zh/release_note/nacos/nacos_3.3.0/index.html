nacos 3.3.0

#Nacos 3.3.0

Nacos 3.3.0 是 Nacos 3.x 系列的功能迭代版本。它为稳定版本带来了协议中立的 Agent 管理和发现、共享 AI 资源搜索以及统一的 MCP 生命周期管理。

此版本重点关注：

  • 跨 Agent、AgentSpec、Skill、Prompt 和 MCP 资源的 AI 注册表功能。
  • DNS服务发现和分布式锁。
  • 默认情况下启用动态插件管理和身份验证。
  • Spring Boot 4 和 Jackson 3 兼容性，改进了 client 和服务器可靠性。

主要功能更新包括：

  • 代理注册、版本管理、运行时端点、RAD 发现、传输协商以及通过 Java SDK 和控制台工作流程进行监视/推送。
  • 共享人工智能资源搜索，具有混合关键字和向量检索、工件访问和可选的相关性过滤。
  • MCP起草、审核、发布、在线/离线和可见性管理，并支持历史资源迁移。
  • 可选的 DNS 发现，通过 UDP 和 TCP 进行 A、AAAA 和 SRV 记录。
  • 具有看门狗更新和 Raft 一致性的分布式可重入和不可重入锁。

该稳定版本还提高了跨版本转换的技能元数据一致性，扩展了可见性插件功能，并增强了 Config SDK 的可用性、控制台兼容性以及命名重新连接和集群重新启动后的恢复。

这些注释是累积性的，包括 3.3.0-BETA 和 3.3.0-RC 中提供的更改。

此版本的详细变化：

特点

  • #50 通过 UDP 和 TCP 添加可选的 DNS 服务发现，包括 A、AAAA 和 SRV 记录、指标以及可配置的外部 DNS 转发。
  • #14466 添加具有 Jackson 2 和 Jackson 3 运行时支持的中性 JSON 适配器。
  • #14804 添加协议中立的代理生命周期管理、控制台工作流程、RAD 发现、运行时端点、传输协商、监视/推送和 Java SDK。
  • #15279 添加分布式可重入锁和不可重入锁，包括看门狗更新、FIFO 等待、gRPC 通知、Raft 一致性和 Java 锁 SDK。
  • #15471 支持 SkillSpector 作为 AI 发布管道。
  • #15475 添加统一的动态插件配置、生命周期管理、运行时更新、确定性发现和控制台配置工作流程。
  • #15476#15604 添加插件拥有的可见性授予并撤销技能和 AgentSpec 资源的 API 和控制台管理。
  • #15541 添加代理资源发现，包括搜索、探索、工件检索、可见性过滤、持久索引以及混合关键字和向量检索。
  • #15640 为 RocksDB JNI 加载和启动添加 Linux RISC-V64 兼容性。
  • #15761 添加共享 MCP 生命周期管理，包括草稿、审阅、发布、在线/离线操作、可见性、Java SDK 和历史协调，同时保留现有的配置/命名服务数据。

增强/重构

  • #8354 将强制的 Prometheus client 依赖项替换为可插入的 client 指标 SPI 和无操作默认值。
  • #12064 支持通过单独的 client 属性配置 gRPC 端口偏移。
  • #12734 添加基于请求/结果的 Config SDK 方法、加密的 Config CAS 发布以及具有本地缓存​​重用的条件查询。
  • #13690 记录已解析的 client 日志配置并在订阅日志中包含命名空间 ID。
  • #14804 改进代理控制台工作流程，公开 SDK 发现功能和 A2A 转换帮助程序，并跟踪发现请求来源。
  • #14817 默认情况下禁用选定的已弃用管道和 MCP 导入 API，并提供共享临时兼容性开关。
  • #14932 减少读取路径争用并提高旧版 MCP 缓存中的索引一致性。
  • #14980 支持从 Console v3 取消注册持久命名实例。
  • #15315#15561 改进技能上传预检查、冲突处理和服务器端 ZIP 验证。
  • #15322 删除过时的 Config 迁移兼容性代码并仅保留当前的 ​​Config 存储模型。
  • #15345 返回列表和元数据详细信息响应中缓存的技能前题。
  • #15346 管理服务器上 AI 资源的保留 latest 标签。
  • #15357 默认启用 Client API 身份验证，并在启用身份验证的情况下验证标准集成方案。
  • #15432#15440#15441 删除已审查的未使用的 Java 代码，同时保留所需的兼容性合同。
  • #15448 改进控制台 UI Next 中的英语翻译。
  • #15486 将技能所有者包含在上传权限中
