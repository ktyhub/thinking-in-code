nacos 3.2.4

Nacos 3.2.4 主要是针对 3.2 系列的 bug 修复、安全加固和体验提升版本。

此版本重点关注：

  • 加强JRaft、HTTP/gRPC授权、嵌入式数据库、登录、主动健康检查和MCP导入安全性。
  • 修复独立控制台、提示可见性、配置历史记录、侦听器状态和 MCP 工具身份验证问题。
  • 改进配置详细信息、编辑和历史页面的可用性。

对于集群和 API 运营商，此版本还：

  • 通过滚动升级感知强制措施，向本机 JRaft gRPC 流量添加服务器身份验证。
  • 默认情况下禁用选定的已弃用的 v3 AI API，并提供临时兼容性开关。
  • 为从私有或本地目标导入 MCP 工具添加允许列表策略。

此版本的详细变化：

特点

  • #15687 通过滚动升级感知强制措施，向本机 JRaft gRPC 流量添加服务器身份验证。

增强/重构

  • #14817 为已弃用的 Pipeline 和 MCP 导入 API 添加共享的、默认禁用的兼容性门。
  • #15661 将分布式嵌入式数据库结果解析强化为支持的标量类型和注册的行映射器。
  • #15688 重构控制器上下文路径 URI 解析以实现一致的路由匹配。
  • #15695 通过紧凑的元数据和全屏内容视图改进配置详细信息、编辑和历史记录布局。
  • #15712 通过验证目标地址和禁用不安全的 MySQL JDBC 选项来强化主动运行状况检查。
  • #15749 为 MCP 工具导入添加可配置的出站访问控制，允许公共目标和列入白名单的私有或本地目标。

错误修复

  • #15475 修复来自独立控制台的呼叫者身份转发，以便服务器强制执行特定于呼叫者的 RBAC。
  • #15476 修复列表、详细信息、版本、下载和 Client 读取路径的提示可见性强制执行。
  • #15560 修复了从控制台发布后 MCP 工具直通身份验证丢失的问题。
  • #15634 #15563 修复了 Admin、HTTP/gRPC、Prometheus 和 AgentSpec API 之间的授权元数据和资源解析。
  • #15660 修复了由于缺少配置克隆权限检查器 bean 导致的独立控制台启动失败的问题。
  • #15682 通过标准化登录失败响应来防止用户名枚举。
  • #15701 修复 Derby 上的配置历史记录下一条记录查询并正确应用灰色名称过滤。
  • #15724 在跨集群成员聚合侦听器按 IP 状态时保留命名空间过滤器。

重大变更通知

Nacos 3.2.4 更改了已弃用的 AI API 和私有 MCP 工具导入的默认行为，并引入了不可逆的 JRaft 身份验证强制转换。

受影响的用户：

  • 用户调用已弃用的管道列表/详细信息或旧版 MCP 导入 API。这些 API 现在默认返回 HTTP 410 Gone。

  • 控制台操作员从私有或本地地址导入 MCP 工具。这些目标现在需要管理员管理的白名单。

  • 在所有成员启用 JRaft 身份验证强制执行后，集群尝试混合版本滚动降级。 推荐升级路径：

  • 迁移到规范管道和 /v3/console/ai/import/* API。如果需要额外的迁移时间，请暂时设置nacos.core.api.compatibility.enabled=true。

  • 在每个控制台实例上配置 nacos.console.ai.mcp.import.allowed-private-addresses，并在需要私有目标时重新启动控制台。

  • 升级之前，请验证每个集群成员上的 nacos.core.auth.server.identity.key 和 nacos.core.auth.server.identity.value 的配置是否相同。 Nacos 使用这些值来验证 JRaft gRPC 请求，但不会跨集群同步它们。

  • JRaft 身份验证进入强制模式后，不要依赖混合版本滚动降级。

已经使用规范 AI API、公共 MCP 端点和一致服务器标识的用户不会受到这些兼容性更改的影响。

Java 版本要求

模块 需要 Java
Nacos-服务器/Nacos-控制台 Java 17
Nacos-Client Java 8
Nacos-维护者-Client Java 8
