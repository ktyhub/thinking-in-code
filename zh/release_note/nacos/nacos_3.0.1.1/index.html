nacos 3.0.1.1

修订 发布时间2025年5月23日 来源alibaba/nacos 英文原文

nacos 3.0.1.1

该版本修复了区块问题#13430。其他版本变更请参见3.0.1 以下更改日志来自3.0.1： 该版本基于3.0.0版本，引入了对MCP的多命名空间管理能力和多版本管理能力的支持。 Nacos社区为MCP注册中心API标准做出了贡献，并且是第一个实施该标准MCP注册中心API的社区。 部署Nacos 3.0.1时，可以通过设置参数nacos.ai.mcp.registry.enabled=true来启用标准MCP注册表API，参数nacos.ai.mcp.registry.port（默认9080）指定MCP注册表API的端口。由于 MCP 注册表 API 需要额外的端口和资源，因此默认情况下它在标准配置中保持禁用状态。

由于官方 MCP 注册表 API 标准的更改，MCP 服务器的元数据定义已更新，导致潜在的不兼容数据结构更改。从版本 3.0.0 升级到 3.0.1 可能会导致控制台无法从以前的 MCP 服务器读取数据。 Nacos社区提供了一个迁移工具，可以在执行后将现有的MCP Server重新定位到默认命名空间public。有关使用迁移工具 mcp-migration-tool.jar 的详细说明，请参阅 文档。 随着MCP注册表API现已最终确定，MCP服务器的数据结构已经稳定，确保了未来版本的向后兼容性。 除了新功能外，该版本还优化了Windows系统的初始密码提示和启动脚本，同时还修复了3.0.0版本中存在的多个错误。 3.0.1的详细变化参见：

功能/重构

[#13356] 支持 MCP 功能的多个命名空间。 [#13377] nacos mcp 模块中支持 mcp 注册表 api。 [#13401] 支持 mcp 服务器的版本控制器。

增强/重构

[#13335] 增强 Windowsstartup.cmd 以减少 Secret.token.key 的重复提示。 [#13348] 增强初始化密码的提示。

错误修复

[#13249] 修复配置更改插件返回不兼容的问题。 [#13267] 修复无法删除包含非法字符的服务的问题。 [#13273] 修复创建集群 client 不使用 nacos.remote.client.grpc 配置的问题。 [#13321] 修复 prometheus 指标 api 无法接受的问题。 [#13345] 修复 apiClient readTimeout 必须为零的问题。 [#13368] 修复控制台 ui 中无法删除命名空间的问题。 [#13405] 修复默认命名空间的监听配置问题。 [#13413] 修复 mcp stdio 服务器的提示问题。
