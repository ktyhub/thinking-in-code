echarts 5.4.1

修订 发布时间2022年12月9日 来源apache/echarts 英文原文

echarts 5.4.1

  • [功能] [i18n] 添加匈牙利语(hu_HU) 翻译。 #17978 (ifjkovacsik)
  • [功能] [svg] 支持 SVG 渲染器中背景颜色的渐变和图案。 #959 (平心)
  • [功能] [烛台] 提供 borderColorDoji 选项用于自定义十字星颜色。 #17717 (奥维莉亚)
  • [功能] [sankey] 支持edgeLabel。 #16767 (susiwen8)
  • [功能] [图形] 使图形节点在 none 和 circular 布局中可拖动。 #15428 (孔某某)
  • [功能] [util] 使用本机 Map（如果可用）。 #965 (乔纳斯巴)
  • [功能] [类型] 导出 ECElementEvent 为 TypeScript。 #17892 (keita 确定)
  • [修复] [i18n] 将乌克兰语的语言代码重命名为 UK。 #17812 (striezel)
  • [修复] [饼图] 修复图例更改后百分比不更新的问题。 #17734 (平心)
  • [修复] [pie] 修复设置 minShowLabelRadian 时对 labelLine 的潜在空访问。 #17715 (平心)
  • [修复] [饼图] 修复指定坐标系时 center 可能无法转换为正确点的问题。 #17920 (平心)
  • [修复] [热图] 修复启用 dataZoom 时热图标签可能重叠的问题。 #17876 (平心)
  • [修复] [动画] 修复universalTransition中旧数据项的错误dataGroupId。 #17559 (tyn1998)
  • [修复] [dataZoom] 当值或百分比无效时回退到范围开始/结束。 #17934 (平心)
  • [修复] [时间轴] 修复图表在不显示轴线时无法工作的问题。 #17647 (平心)
  • [修复] [工具提示] 修复边框较宽时工具提示箭头可能覆盖内容的问题。 #17875 (平心)
  • [修复] [标记] 修复使用 x/y 像素但未定义 coord 时 markArea 不显示的问题。 #17217 (jiawulin001)
  • [修复] [标记] Bar系列的markArea现在覆盖了整个指定类别。 #17098 (jiawulin001)
  • [修复] [图例] 修复系列数据同名时图例 inverse 不起作用的问题。 #17510 (蔡武坤)
  • [修复] [仪表] 按照“顺时针”选项的顺序渲染仪表扇区。 #17691 (ZekoZhu)
  • [Fix] [ssr] 修复提取字体大小的错误表达式。 #968 (平心)
  • [修复] [svg] 修复 SVG 渲染器中变形动画完成后形状可能会消失的问题。 (平心)
  • [修复] [类型] 修复 EChartsInitOpts 类型有关高度和宽度的错误。 #17727 (MainHou)
  • [Fix] [type] 将 overflow 属性添加到 AxisLabelBaseOption 接口。 #17808 (breizh24)
  • [修复] [类型] 将 string 和 number 类型添加到馅饼系列的 center 选项中。 #17917 (平心)
  • [修复] [类型] 将缺失的 function 回调添加到线路系列的 lineStyle.color 中。 #17780 (平心)
