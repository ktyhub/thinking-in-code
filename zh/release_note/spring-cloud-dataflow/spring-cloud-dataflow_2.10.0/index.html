小版本 发布时间2022年12月12日 来源spring-cloud/spring-cloud-dataflow 英文原文

spring-cloud-dataflow v2.10.0

春季更新

更新至以下版本：

  • Spring Boot 2.7.6
  • Spring Framework 5.3.24
  • 春云2021.0.5

弹簧外壳

Spring Shell 已更新为 2.1.4。

文档更新

ARM 的容器镜像。

Spring Cloud Data Flow 和 Skipper 以及 Stream Application 项目包含在 ARM 平台上运行时用于创建容器的脚本。 参考指南 有一节描述了脚本的使用。

本地 Kubernetes 开发脚本

我们在 Spring Cloud Data Flow 中添加了一组脚本，可以轻松启动本地 Kuberenetes 集群并使用 MariaDB 和 RabbitMQ 或 Kafka 安装 SCDF。有关详细信息，请参阅参考指南。
