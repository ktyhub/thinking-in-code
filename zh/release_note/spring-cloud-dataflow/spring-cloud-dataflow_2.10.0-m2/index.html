spring-cloud-dataflow v2.10.0-M2

预发布 发布时间2022年9月20日 来源spring-cloud/spring-cloud-dataflow 英文原文

spring-cloud-dataflow v2.10.0-M2

春季更新

更新至以下版本：

  • Spring Boot 2.7.3
  • Spring Framework 5.3.22
  • 春云2021.0.3

弹簧外壳

Spring Shell 已更新为 2.1.0-M5。

添加回 mysql 支持

在 M1 中，我们删除了对 mysql 的支持。此里程碑恢复了使用 MariaDB JDBC 驱动程序对 MySQL 5.7+ 的支持。有关更多详细信息，请参阅参考文档。
