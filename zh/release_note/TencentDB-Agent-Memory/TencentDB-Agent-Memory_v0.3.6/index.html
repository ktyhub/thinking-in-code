TencentDB-Agent-Memory v0.3.6

TencentDB-Agent-Memory v0.3.6

[0.3.6] - 2026-05-28

🚀新功能

  • 回忆上下预算控制 (#71 / #70)：新增 recall.maxCharsPerMemory 与 recall.maxTotalRecallChars 配置，按分数顺序进行超长边界并丢弃浪费部分，避免长连接因记忆膨胀挤占上方。
  • L1 / L2 / L3 提示词按用户输入语言 (#38)：l1-extraction、l1-dedup、scene-extraction、persona-generation 四个提示的自由文本字段现在紧随用户消息语言写入，无需配置 locale。
  • 嵌入 sendDimensions 任选关闭：新增 embedding.sendDimensions 配置项，设置 false 时省略请求体中的 dimensions 字段，可对接 BGE-M3 等固定维度模型。
  • 网关任选承载鉴权 + CORS 白名单：新增 server.apiKey / TDAI_GATEWAY_API_KEY 与 server.corsOrigins / TDAI_CORS_ORIGINS，启用后非 /health 路由需携带承载 token，恒定时间比较防对抗攻击。Hermes Python 客户端同步支持 MEMORY_TENCENTDB_GATEWAY_API_KEY。
  • 卸载collect模式：新增offload.mode: "collect"，仅执行数据采集而不触发L3压缩，适用于纯数据积累或调试场景。

🐛 修复

  • L2 LLM失败导致scene_blocks/被清空 (#88)：LLM错抛时自动从最新备份恢复scene_blocks/，fail-soft设计。
  • 场景文件名含空格导致角色场景导航引用错误：新增filename-normalizer.ts，在SceneExtractor.extract中自动归一化文件名。
  • api.runtime.state 为 undefined 导致注册崩溃 (#78 / #85 / #79)：加任选链 + 回退，支持 runtimeState.resolveStateDir() → OPENCLAW_STATE_DIR → ~/.openclaw 三级降级。
  • contextEngine 插槽 ID 与插件名不一致：改为 memory-tencentdb，避免 openclaw doctor --fix 重置插槽。
  • L1.5结算永不返回导致L2卡死：增加60s超时，未配置Context Engine slot时自动强制结算。
  • 独立文本任务仍暴露工具 (#58 / #59)：enableTools=false 时彻底不传工具列表。
  • L2 冷启动跳过错误更新 l2LastRunTime：仅在确实运行过时更新定时器。
  • sanitizeText 误删 emoji / CJK / Math Bold 等非 BMP 字符 (#30 / #31)：正则加 u 标志，只匹配隔离代理。
  • 紧急截断在MIN_KEEP拒绝下死锁：新增_emergencyTruncateOversized，兜底强制拆除并实行清理。
  • 多轮激进压缩累计计时器：由6轮全量tiktoken改为单趟精准切点，615条消息84s→14s。
  • FP-HEAD-DELETE误删新消息：改用FP-BOUNDARY-DELETE + BOUNDARY-INCR-SKIP，重放场景38s→122ms。
  • 首次组装慢：增加fast-token-estimate前置短路，29s→1.4s。
  • Token计算精度：details 加入 INTERNAL_KEYS；l3TiktokenEncoding 默认改为 cl100k_base。
  • Dockerfile.hermes 生成的 config.yaml 缺 api_key (#77 / #81)：同步写入 model.api_key。
  • 安装脚本多处问题 (#18 / #19 / #20 / #54 / #55)：支持HERMES_AGENT_DIR覆盖、root不再涉及su、systemd环境用绝对路径节点。
  • Cleaner安全胶原：拒绝无效切断、expired/total > 80%阻止删除、最大保留护栏。

✨ 改进

  • l3TiktokenEncoding默认改为cl100k_base，匹配主流国产/开源模型分词器。
  • 卸载日志降级：AGGRESSIVE / EMERGENCY 等降速到调试，仅超10s输出WARN。
  • Docker文档补充cd docker/opensource前置步骤；新增问题/咨询问题模板。

⚠️配置项变化（一致性兼容）

关键 默认值 说明
recall.maxCharsPerMemory 0 0/未设置 = 不办理
recall.maxTotalRecallChars 0 0/未设置 = 不办理
embedding.sendDimensions true false时不携带dimensions，车型BGE-M3等
l3TiktokenEncoding cl100k_base（原o200k_base） 仅以显式依赖 o200k_base 时需手动覆盖
