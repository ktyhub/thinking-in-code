zvec v0.8.0

小版本 发布时间2026年10月21日 来源alibaba/zvec 英文原文

zvec v0.8.0

Zvec v0.8.0 带来更快的查询、更低的索引构建成本和更广泛的平台支持。量化器和距离内核的改进有利于多种格式和指标，其中 INT4 和 Linux ARM64 取得了重大进展。此版本还减少了 IVF/DiskANN 构建期间的峰值内存，加速了 HNSW RaBitQ 构建，并使中文 FTS 可以与嵌入式 Jieba 资源一起使用。平台覆盖范围扩展到桌面和移动设备，同时修复了并发读取、索引重建和过滤正确性。

⚠️ 重大变更和升级说明

  • Jieba 全局字典配置已删除： 默认字典和 HMM 模型现已嵌入本机库中。 Python 用户必须删除 init(jieba_dict_dir=...) 并调用 set_default_jieba_dict_dir() / get_default_jieba_dict_dir()。相应的 C 配置访问器、C 默认目录 APIs 以及 C++ 全局配置字段和注册 APIs 也已被删除。要覆盖主字典，请使用字段的 FtsIndexParam.extra_params.jieba_dict_dir 或 ZVEC_JIEBA_DICT_DIR；字段配置优先。使用user_dict_path添加业务词汇。 (#807)

📦 新功能

  • Intel Mac 和 Windows ARM64 支持： 通过 MSVC 添加了 macOS x86_64 版本和 Windows ARM64 支持。发布工作流程现在包括 Windows ARM64 SDK 软件包和本机 Python 3.11–3.14 轮。 (#713、#352、#824)
  • Windows 和移动设备上的 DiskANN： 通过 I/O 完成端口添加异步、无缓冲 Windows 读取以及对 Android 和 iOS 的便携式 pread 支持。 （[#625]（https://github.com/alibaba/zvec/pull/625），[#656]（https://github.com/alibaba/zvec/pull/656））
  • Windows x86_64 上的 RaBitQ： 添加了对 RaBitQ 索引的 Windows x86_64 支持。 (#780)
  • 嵌入中文FTS词典： 嵌入默认的Jieba词典和HMM模型作为Python车轮和原生SDK的LZ4压缩资源。解析的默认值是共享的，而自定义用户字典在分词器实例之间保持隔离。 （[#807]（https://github.com/alibaba/zvec/pull/807））
  • 更灵活的标识符： 文档 ID 现在接受最多 1,024 字节的有效 UTF-8，集合名称接受 1 到 256 字节的有效 UTF-8，不包括禁止的控制和分隔符。字段名称保留其 ASCII 字符集，扩展至 64 字节，并拒绝保留的内部名称。 (#756)
  • 集合中的统一量化： 添加了统一 UINT4 量化，并将统一 UINT4/UINT7/UINT8 量化器与数据库层和 HNSW 集成。共享量化范围避免了查询期间每个数据点的分数重建，从而加速了搜索。在所有索引点上使用共享的最小值/最大值会增加量化误差并降低召回率。 （[#698]（https://github.com/alibaba/zvec/pull/698），[#754]（https://github.com/alibaba/zvec/pull/754））
  • Turbo PQ 和 FastScan： 添加了 PQ-INT4 和 4 位 PQ FastScan 实现，具有打包块扫描功能，以及 SIMD 和标量距离内核以及用于 IVF 的预计算剩余距离表。 (#664)
  • OPQ 预处理： 在 Turbo 框架中添加了优化乘积量化旋转，并跨 PQ 量化器整合了通用训练和序列化逻辑。 （[#717]（https://github.com/alibaba/zvec/pull/717），[#765]（https://github.com/alibaba/zvec/pull/765））
  • 矢量索引的共享页面缓存： 添加了缓冲区支持存储，并将 HNSW、IVF 和 DiskANN 与共享页面缓存集成。该实现支持固定读取、批量页面访问以及缓存压力下的 DiskANN 直接 I/O 回退。 (#708、#742、#766)

🚀 性能改进

  • 降低 IVF 和 DiskANN 构建内存： 减少冗余矢量副本、流式合并输入、有界临时编码缓冲区，并提前释放已完成的构建器和输入，以减少构建和优化期间的峰值内存。 （[#733]（https://github.com/alibaba/zvec/pull/733），[#762]（https://github.com/alibaba/zvec/pull/762））
  • 更快的 HNSW RaBitQ 构建： 在邻居修剪和批量 Flat 提供者查找和段锁定期间重用原始向量，减少重复读取和锁定获取。 （[#755]（https://github.com/alibaba/zvec/pull/755），[#813]（https://github.com/alibaba/zvec/pull/813））
  • 跨索引系列的 Turbo 距离计算： 将 Flat、HNSW、IVF 和 DiskANN 距离计算或量化路径迁移到 Turbo 并扩展了 AVX2、AVX512、AVX512-FP16、SSE 和 ARM NEON 内核和运行时调度。这种对量化器和距离计算的广泛重构提高了量化格式和距离度量的性能，为 INT4 内核和 Linux ARM 工作负载带来了巨大的收益。 (#716、#735、#773、#678、#687、#710、#689、 #718)
  • Vamana 搜索改进： 引入了分割连续打包布局、优化的候选状态和预取以及更正的中心点选择。现在默认启用两遍图形构建以提高图形质量。 (#701、#727、#738、[#749]
