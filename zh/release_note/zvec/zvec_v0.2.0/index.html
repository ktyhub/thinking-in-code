🚀 Zvec v0.2.0 Release Notes

主要更新侧重于优化、平台扩展和开发人员体验改进。

📦 核心功能和改进

  • 支持设备上嵌入工作流程的 AI 扩展框架 (#88)
  • MMap 存储文件中的自动可扩展段元数据 (#67)
  • 核心中统一搜索调用接口（#15）
  • Linux ARM64 构建支持 (#71)
  • 重复初始化尝试时出现静默失败（#79）

🐞 错误修复

  • 使用键而不是索引修复了 delete_by_filter 逻辑（#84、#87）
  • 更正了量化 int 单元测试（#47）
  • 从 AddColumn API 中删除了不必要的 column_name 参数 (#59)
  • 修复了 HNSW 索引实现中的拼写错误 (#50)
  • 删除了测试中的冗余错误预期（#82）
  • 清理了未使用的 ailego 模块 (#85)

🔧 开发者体验

  • 将 typing_extensions 替换为标准 typing (Python ≥3.10) (#99)
  • 通过 LOG_ERROR 而不是 cerr 改进了 C++ 错误日志记录 (#80)
  • 更新了 Python 绑定的文档字符串和 .pyi 存根 (#41)
  • 删除了过时的 IndexMeta::MetricType 定义 (#53)
  • 向 macOS/Linux CI 矩阵添加了 C++ 示例 (#86)

🤖 CI/CD 和工具

  • 支持分叉 PR 的 CI 运行 (#52)
  • 在仅限 Markdown 的更改中跳过 CI (#55)
  • 添加了问题模板以提供更好的社区支持 (#46)
  • 更新了 CMake 最低版本要求（#44、#57）
  • 基准工具文档刷新（#77）

📚 文档

  • 更新了自述文件徽章和加入我们部分（#45、#54）

👋 新贡献者

  • @SYaoJun — 第一个贡献 (#50)
