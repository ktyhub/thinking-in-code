zvec v0.8.1

修订 发布时间2026年11月6日 来源alibaba/zvec 英文原文

zvec v0.8.1

📦 新功能

  • HNSW 和 IVF 的 PQ： 添加了 PQ4/PQ8 和可选的 OPQ，涵盖训练、搜索、持久性和后续更新。 （[#833]（https://github.com/alibaba/zvec/pull/833））
  • 更广泛的平台支持： 在 Linux、macOS、Android 和 iOS ARM64 以及 Intel Mac 上启用 RaBitQ。 DiskANN 现在支持 Intel Mac 和 Windows ARM64。 （[#832]（https://github.com/alibaba/zvec/pull/832），[#874]（https://github.com/alibaba/zvec/pull/874））
  • C API 中的分组搜索： 添加了分组向量查询和结果管理 API。 (#845)

🚀 性能改进

  • 降低构建内存： 减少 DiskANN、IVF 和选定的 HNSW 构建路径中的矢量复制和临时存储。 (#853、#877、#879、#880)
  • 更快的搜索和构建： 改进了 Flat 批量查询、HNSW 构建和 FP16 距离计算，并完成了 ARM NEON 批量距离内核。 (#862、#871、#856)

🐞 关键修复

  • 增强只读存储保证，修复只读关闭时的索引修改、WAL 恢复边界和可写重新打开行为。 (#834、#840、#870)
  • 修复了 HNSW RaBitQ 评分、缺少外部向量处理、模式更改失败后崩溃以及通过继承的文件描述符保留的集合锁。 (#851、#861、#822、#859)

升级说明： 具有挂起的 WAL 恢复的集合必须首先以可写模式打开和关闭，然后才能以只读方式打开。 (#840)

感谢所有贡献者，并欢迎首次贡献者 @ZoruaSama 和 @ilike314272！
