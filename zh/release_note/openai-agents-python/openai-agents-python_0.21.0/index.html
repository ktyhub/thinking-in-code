openai-agents-python v0.21.0

主要变化

此次要版本并未引入已知的重大 SDK 行为更改。次要版本提升是针对新的提供商中立测试 API 和 OpenAI Python v3 兼容性更新。

亮点：

  • 添加了 agents.testing、agents.realtime.testing 和 agents.voice.testing 实用程序，用于确定性代理、沙盒、实时和语音工作流程测试，无需提供商请求。
  • 更新了 OpenAI 提供程序对 openai>=3.0.0,<4 的兼容性，包括 HTTPX2 感知请求、响应、传输和异常处理。
  • 强化的运行状态中断快照、递归代理工具批准、最大周转最终确定、流式清理和敏感错误编辑。
  • 改进了 MCP 生命周期快照隔离并添加了可配置的重试退避上限。
  • 添加了 Sandbox Runloop 现有秘密支持并收紧了视图图像路径授权。
  • 添加了针对无效通道、帧速率、不完整的多通道帧和非有限音频速率的更严格的语音验证。
