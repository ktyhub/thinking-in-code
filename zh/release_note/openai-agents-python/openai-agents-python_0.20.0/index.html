openai-agents-python v0.20.0

主要变化

版本 0.20.0 是次要版本，因为它更改了隐式默认模型，并包含可能破坏具有自定义本地 HTTP 传输的应用程序的 MCP 依赖项迁移。 MCP v1 仍受支持，受影响的应用程序可以迁移到 httpx2 或引脚 mcp<2。

亮点：

  • 默认型号现在为 gpt-5.6-luna；显式模型、运行级别覆盖和 OPENAI_DEFAULT_MODEL 继续优先。
  • 本地 MCP 连接支持跨 stdio、SSE 和 Streamable HTTP 传输的 MCP Python SDK v1 和 v2。
  • 使用自定义 MCP HTTP 身份验证或 client 工厂的应用程序必须使用已安装的 MCP 主要版本或引脚 mcp<2 拥有的 HTTP 类型。
  • RunState.add_input() 可以在恢复模型调用之前暂存持久的用户输入，并提供防护、持久性和序列化支持。
  • 沙盒安装验证添加了显式的凭证暴露确认，并保留经过编辑的错误合同，而无需序列化凭证权限。
  • 实时输入转录支持 gpt-live-transcribe、gpt-transcribe 和 gpt-realtime-whisper 的 GA 转录设置。
