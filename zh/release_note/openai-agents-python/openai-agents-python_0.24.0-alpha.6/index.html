openai-agents-python v0.24.0-alpha.6

预发布 发布时间2026年11月3日 来源openai/openai-agents-python 英文原文

openai-agents-python v0.24.0-alpha.6

在虚拟环境中使用标准 CPython 3.10–3.14。这些轮子包括本机运行时；不需要 Rust 工具链或源代码构建。此预览版通过 GitHub 版本分发，而不是 PyPI。

运行适合您的平台的命令：

Linux x86_64（glibc 2.39 或更新版本）

python -m pip install "https://github.com/openai/openai-agents-python/releases/download/v0.24.0-alpha.6/openai_agents-0.24.0a6-cp310-abi3-manylinux_2_39_x86_64.whl"

Apple Silicon 上的 macOS 11 或更高版本

python -m pip install "https://github.com/openai/openai-agents-python/releases/download/v0.24.0-alpha.6/openai_agents-0.24.0a6-cp310-abi3-macosx_11_0_arm64.whl"

Windows x64

python -m pip install "https://github.com/openai/openai-agents-python/releases/download/v0.24.0-alpha.6/openai_agents-0.24.0a6-cp310-abi3-win_amd64.whl"

不为 Intel Mac、ARM Linux、ARM Windows、Alpine/musl、PyPy 或自由线程 Python 提供轮子。 cp310-abi3 文件名还支持标准 CPython 3.11–3.14。

检查安装的版本和本机模块：

python -c "from importlib.metadata import version; import agents._native; print(version('openai-agents'))"

0.24.0-alpha.6 或其等效的 Python 包装拼写 0.24.0a6。 SHA256SUMS 包含所有三个轮子的校验和。

Release note

自 0.24.0-alpha.5 以来的变化。此预览扩展了对话控制、状态恢复和工具策略，并包括公共 API 更改。

添加

  • 通过捕获的 Turn、get_result()、被动 events()、手动请求处理、引导和取消来控制提交的工作。使用 Session.submit(..., if_busy="queue") 进行队列提示，或使用 if_busy="steer" 引导活动转弯。
  • 添加 LocalStorage 以从本地配置文件重新打开对话，并扩展便携式 SessionState 捕获和恢复。添加空闲分叉、调用者提供的压缩摘要，并检查功能支持和检查点准备情况。 LocalStorage 配置文件无法导出便携式检查点。
  • 添加 NativeOutput 用于本机严格输出，并添加 PromptedOutput 用于在 Python 中验证的 JSON。可选的 max_retries 无需工具即可执行有界校正或重播任务。 LocalStorage 需要 max_retries=0。
  • 处理实时手动工具请求并恢复来自检查点的受支持的待处理请求。通过 agents.experimental.deferred 和可选的 MCP 任务适配器添加实验性外部作业恢复。
  • 在会话的开放权限内为每个提交或模型步骤选择工具。添加本机网络搜索、本机子清单和本地存储会话的本机目标。
  • 验证 Python 工具返回注释并添加用于检查参数和结果的工具策略。通过支持的 HTTP、stdio 和模型 WebSocket 路径，通过参数替换、结果转换以及应用程序管理的表单和 URL 交互来扩展本机 MCP 支持。
  • 在受支持的 Linux 和 macOS 执行器上为本机命令添加 NetworkPolicy，具体取决于每个平台的网络和 Unix 套接字限制。通过打开会话或运行代理时提供的 Environment 管理远程执行程序的生命周期。
  • 使用 NativeAgents(interactions=True) 启用本机子批准和表单请求。孩子们继续分享会议的工具和应用程序上下文。
  • 配置本机 OpenTelemetry 导出并检查键入的观察结果。 NativeError 现在公开可用的提供程序状态代码、错误代码、请求 ID 和故障类别。
  • 使用 agents.testing.ScriptedResponses 测试真实的 SDK 会话和 Python 工具与本地脚本响应，无需实时模型或 API 密钥。

API 变化

  • 使用Agent.run()或Agent.run_sync()进行一键通话；冗余的 Runner 别名已被删除。
  • 在捕获的回合中将 Turn.wait() 和 Session.wait() 替换为 Turn.get_result()。
  • 将 Session.interrupt() 替换为 Turn.cancel() 进行一根转动，或将 Session.cancel_all() 替换为整个会话。
  • 将 Subagent.submit() 重命名为 Subagent.start()。统一Python回调和FunctionTool下的手动工具；删除单独的 ManualTool 声明。
  • 代理声明是不可变的。创建新代理以更改默认值，使用 with_output_type() 作为输出类型变体，或使用支持的空闲会话更新进行开放对话。
  • 工具选择和会话更新无法扩展会话打开时捕获的权限。恢复的会话使用当前的应用程序工具、凭据和策略。

已修复

  • 在接受的转向、本机延续和以后的提交中保持每个捕获回合的结果稳定。跨受支持的保存和恢复边界保留一次性手动检查点、匹配交互回复以及输出修复状态。
  • 改进原生子取消和会话清理。当结果策略过期时停止本机工作，并在报告根和子结果时保留策略失败原因。
  • 拒绝格式错误的 Python 工具结果包络，并通过 MCP 结果转换保留服务器错误。支持嵌套 OpenAI 扩展表单和使用 client 证书的 HTTP 遥测导出。

文档和示例

  • 将预览源移至公共存储库。重新将安装指南集中在预制车轮上，并将 SDK 构建说明移至 CONTRIBUTING.md。
  • 添加浏览器应用程序、AG-UI 流、延迟作业、评估、可观察性和常见应用程序任务的示例。从预览文档中删除迁移指南。
