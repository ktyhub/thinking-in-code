openai-agents-python v0.24.0-alpha.7

预发布 发布时间2026年11月8日 来源openai/openai-agents-python 英文原文

openai-agents-python v0.24.0-alpha.7

亮点

  • 将经典工作流程与本机执行结合使用。 通过 agents.classic 导入保留的 v0 运行时。此 alpha 版本还更改了执行器写入默认值；在打开现有环境之前检查升级操作。
  • 将对话保留在您自己的存储中。 使用 CustomStorage 添加持久根会话，并在恢复工作之前协调不确定的工具效果。
  • 向本机代理添加语音和托管工具。 将语音工作流程连接到会话，或通过兼容的响应提供程序使用 FileSearch、CodeInterpreter 和 ImageGeneration。
  • 控制上下文、完成和使用。 转换模型输入，在压缩期间保留选定的上下文，审查建议的答案，并限制观察到的根使用。

从 0.24.0-alpha.6 升级

  • 查看环境写入策略。 新环境默认为 write_policy="strict"，这需要兼容的 Linux 或 macOS 执行程序。工作目录保持可写；使用 writable_roots 作为附加目录。要保留以前的远程策略（包括在 Windows 执行程序上），请设置 write_policy="legacy" 并保留 writable_roots=None。本地执行需要严格模式。恢复旧版远程检查点或配置文件时，明确选择旧版；重新开放并不会升级他们的政策。请参阅执行器策略和恢复规则。
  • 检查隐式推理设置。 捆绑模型目录将 gpt-6-astra、gpt-6.1-sol 和 gpt-5.6-sol 的默认推理工作从 low 更改为 medium。如果您需要之前的努力，请明确设置 model_settings={"reasoning_effort": "low"}。这描述了捆绑的元数据；显式设置或提供者模型元数据可以选择另一个值。 (#5517)
  • 重命名 MCP 批准模式。 将 approval_mode="auto" 替换为 "native"，将 "approve" 替换为 "preapproved"。旧的价值观被拒绝；新名称保留了各自的认可行为。
  • 更新子步骤回调。 NativeAgents.before_step 现在接收一个 ChildStepContext，其中包括 context、child 和 step_index，而不是单独的子参数和步骤索引参数。根 before_step 回调保留其现有签名。
  • 单独处理 MCP 表单和 URL。 ElicitationRequest 现在是联合体 FormRequest | UrlRequest。表格使用FormRequest.reply()或respond()；使用 UrlRequest.reply_url_accept() 或 accept_url() 进行 URL 同意。

添加

  • 应用程序拥有的对话存储。 SessionStore、SQLiteSessionStore 和 CustomStorage 保留根历史记录和自动 Python 工具结果。此初始配置文件不包括本机工具、环境、子项、规划工具、生成代码执行、手动工具和可移植检查点。 SQLiteSessionStore 需要一台主机和一个本地 POSIX 文件系统。本地配置文件和自定义存储都可以报告不确定的根调用以进行显式协调；两者都不会自动重播这些效果。 （＃5514，＃5502）
  • 提供商托管的工具和存储。 添加 FileSearch、CodeInterpreter 和 ImageGeneration、代码解释器调用者策略和提供商管理的存储。托管工具需要 API 密钥提供程序和兼容的标准响应模型；它们排除了 Responses Lite 和 Codex 登录。托管网络搜索添加了域和位置控制并保留引用。 (#5576，托管工具指南)
  • 上下文和完成挂钩。 Agent.transform_context 更改采样输入而不更改存储的历史记录。 before_compact 和选定项目保留控制压实。 before_complete 可以接受、返回 ContinueTurn 或停止提出的答案；被拒绝的文本可能已经流式传输并保留在历史记录中。高级 prepare_request 编辑支持受限的 HTTP 配置文件。参见挂钩合约和限制。
  • 观察到的使用预算。 RunBudget 限制根请求准入、报告的令牌或下一个请求之前的估计成本。接受的请求可能会超出限制。儿童被排除在外；默认情况下，缺少使用会停止进一步准入。主动预算操作不能使用便携式检查点。 (#5555)
  • MCP 资源、提示和重新连接。 在会话空闲时，将 Session.list_mcp_resources()、list_mcp_resource_templates()、read_mcp_resource()、list_mcp_prompts() 和 get_mcp_prompt() 与选定的 HTTP 或 stdio 服务器一起使用。检索到的数据不会自动进入模型上下文。范围内的工具选择和显式重新连接可以保留对已接纳工具的控制，而无需重放不确定的调用。 （#5597、#5604、#5556）
  • 本地执行和项目搜索。 Environment.local() 在本地运行支持的执行器工具。在 Linux 上，LocalStorageMount(source=path) 授予对现有规范目录的只读访问权限；源和目的地必须匹配。 project_glob 和 project_grep 在环境的固定工作目录下搜索，而不授予命令执行权限。 （＃5501，＃5575，＃5574）
  • 集成和监督。 通过额外的 a2a、显式 TraceContext、工作流程跟踪控件、API 关键速率限制快照、转向收据、精确转向转向和注意等待，添加本机 A2A client 和服务器适配器。经典集成使用 classic 和 classic-* 附加功能；经典和本机对象以及检查点保持独立。
  • 具有本地历史和策略的语音。 agents.voice.NativeSessionVoiceWorkflow 使用呼叫者拥有的文本输出会话与语音管道。它说接受
