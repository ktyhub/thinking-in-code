graphql-java v26.0.beta-2

预发布 发布时间2026年2月19日 来源graphql-java/graphql-java 英文原文

graphql-java v26.0.beta-2

警告

虽然所有功能都经过测试并且我们认为它们可以使用，但我们不保证这是一个稳定的版本：这意味着在我们达到 26.0 之前将会有更多的重大更改。

此版本旨在用于测试并向 GraphQL Java 团队提供反馈。

发生了什么变化

重大变化

  • 验证规则合并为单个 OperationValidator — graphql.validation.rules.*、AbstractRule 和 RulesVisitor 中的 31 个单独规则类已被删除。规则过滤谓词类型从 Predicate<Class<?>> 更改为 Predicate<OperationValidationRule>（新的 @PublicApi 枚举）。按类引用过滤规则的代码必须迁移到枚举。 (#4228)

  • DirectiveInfo 类已删除 — 使用 Directives.isBuiltInDirective() 和 Directives.BUILT_IN_DIRECTIVES 代替。 GraphQLSchema.Builder.clearDirectives() 也已被删除——所有 7 个内置指令现在始终存在。内置指令现在始终首先出现在 schema.getDirectives() 中。 (#4229)

  • J指定可空性注释 - 大波 2 - 约 50 个用 @NullMarked 和 @Nullable 注释的类。这可能会在使用 NullAway 或 Kotlin 的项目中出现新的警告或错误。 (#4184)

性能

  • 执行吞吐量提高 23-39% — 减少 Async$Many（零拷贝列表）、ResultPath（惰性 toString()）和 GraphQLCodeRegistry（快速路径 DataFetcher 查找，避免一次性 FieldCoordinates 分配）中的分配。 (#4252)

  • 验证速度提高 14-40% — 单个 OperationValidator 消除了每条规则的访问者开销并减少了热路径上的集合分配。 (#4228)

新功能

  • 壮举：GraphQLSchema.FastBuilder，@rstata 在 https://github.com/graphql-java/graphql-java/pull/4197 中实现高性能模式构建
  • 在https://github.com/graphql-java/graphql-java/pull/4248中添加@jbellenger的OneOf可居住性验证
  • 通过 @tinnou 在 https://github.com/graphql-java/graphql-java/pull/4207 中呼叫 ChainedInstrumentation 中的 onExceptionHandled
  • 针对 https://github.com/graphql-java/graphql-java/pull/4209 中复杂删除情况的新 transformSchemaWithDeletes 方法

错误修复

  • 修复 ExecutableNormalizedField 以尊重 https://github.com/graphql-java/graphql-java/pull/4204 中 @Samjin 的 GraphqlFieldVisibility
  • 修复 https://github.com/graphql-java/graphql-java/pull/4213 中间接引用的类型收集
  • 修复并提高 https://github.com/graphql-java/graphql-java/pull/4212 中的现场可见性
  • 代码构建模式现在在 https://github.com/graphql-java/graphql-java/pull/4194 中执行已弃用的非空字段验证（与 SDL 构建相同）
  • 从https://github.com/graphql-java/graphql-java/pull/4247中的`GraphQLSchema.getCodeRegistry()`中删除不正确的`@Nullable`

其他改进

  • AST 指令持有者在 https://github.com/graphql-java/graphql-java/pull/4195 中有 toString()
  • 在https://github.com/graphql-java/graphql-java/pull/4208中添加`additionalTypes`在`GraphQLSchema`中的文档和测试
  • 使用 Java 25 由 @yeikel 在 https://github.com/graphql-java/graphql-java/pull/4173 中构建和测试
  • 由 @m1ngyuan 在 https://github.com/graphql-java/graphql-java/pull/4240 中更新 Objenesis、Spock 和 Groovy
  • 将 Gradle 包装器凹凸至 9.3.1，将 Shadow 凹凸至 9.3.1，将 Kotlin 凹凸至 2.3.0
