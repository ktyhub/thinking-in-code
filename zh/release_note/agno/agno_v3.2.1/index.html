agno v3.2.1

修订 发布时间2026年11月17日 来源agno-agi/agno 英文原文

agno v3.2.1

#Changelog

新功能：

  • 会话压缩：GET /sessions/{session_id}/compactions 列出 SqliteDb 和 PostgresDb 上的会话压缩，最新的第一个，以及每个替换的消息数以及前后的令牌计数。
  • 公司文件：现在可以使用 GET /company/tasks/{task_id}/files 和 GET /company/notes 通过 API 读取任务的文件和共享笔记，每个文件都有一个 /{path} 路径来读取一个文件。请参阅食谱。

改进：

  • LinearTools、DiscordTools 和 ModelsLabTools：现在采用适用于每个请求的 timeout（默认 30 秒，ModelsLab 120）。
  • ExaTools：现在采用 include_text、exclude_text、user_location、moderation、highlights 和 subpages。
  • MCPTools：connect() 现在在连接时返回 True，在未连接时返回 False。
  • Qdrant：async_insert 现在采用 batch_size，就像 insert 一样。
  • WebSearchTools 和 DuckDuckGoTools：搜索错误现在以 JSON 结果返回。
  • 技能：中文和其他非 ASCII 语言的技能说明、参考和脚本输出现在以可读字符的形式到达模型。
  • AntigravityTools 和 AntigravityAgent：现在默认为 antigravity-preview-09-2026。
  • Slack：default_role 为不在 users= 中的 Slack 成员提供托管角色的权限。每个成员仍然被记录为他们自己。

错误修复：

  • SQLTools：现在始终使用您传入的 db_engine，即使还给出了连接字段，并且 run_sql_query 现在在读取结果行失败时返回数据库错误。
  • OpenRouter、Perplexity 和 Requesty：当未设置 max_tokens 时，响应现在使用模型自己的输出限制，因此长答案会完整返回。
  • OpenRouterResponses：运行和消息指标现在包括 OpenRouter 为每个请求报告的 cost。
  • 跟踪：GET /traces 现在从 1 开始计数页面，就像其他跟踪路由一样，并且当没有给出 page 时，JsonDb 和 GcsJsonDb 应用 limit。
  • WebSearchTools 和 DuckDuckGoTools：max_results=0 现在不返回结果，而 search_news 应用 modifier。
  • ExaTools：livecrawl 现已到达 Exa，Exa 的摘要和亮点现已到达模型。
  • PostgresDb：如果在 PostgresDb 或 AsyncPostgresDb 上创建表失败，则在修复原因后，同一数据库实例现在会在下次调用时创建该表。
  • MCPTools：失败或取消的 connect() 现在会关闭连接及其启动的任何 stdio 服务器。
  • Qdrant：insert(batch_size=...) 现在批量发送该大小的文档。
  • CodexAgent：本机权限请求和问题现在适用于 openai-codex 0.163.0 及更高版本。
  • DaytonaTools：agno[daytona] 现在安装 DaytonaTools 支持的 Daytona SDK (daytona<1)，并且导入错误会命名该版本。
  • Mistral：agno[mistral] 现在会跳过 httpx2 2.16.1，因此 MistralChat 和 MistralEmbedder 可以干净地导入。
  • 文件工具和工作空间：read_file 现在返回完全包含 max_file_lines 行的整个文件。
  • PageMarkdownChunking：以文字 # 结尾的标题（例如 C#）现在将其保留在块面包屑和页面上下文行中。
  • DocxReader 和 PPTXReader：从临时流（例如 FastAPI 的 UploadFile.file）读取的 Word 和 PowerPoint 文件现在返回其内容。
  • ModelsLabTools：等待生成的媒体现在停止在 max_wait_time。
  • Sambanova：现在默认为 Meta-Llama-3.3-70B-Instruct，因此无需设置 id 即可工作。
  • Slack：超级特工现在在 AgentOS(authorization=...) 下启动，无需 users=；不在 users= 中的成员可以聊天，除非 default_role 授予权限，否则需要许可的操作将被拒绝。
