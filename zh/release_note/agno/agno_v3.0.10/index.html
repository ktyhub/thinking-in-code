agno v3.0.10

#Changelog

新功能：

  • Azure OpenAI 响应：添加了 AzureOpenAIResponses 以将响应 API 与 Azure OpenAI 部署结合使用。请参阅食谱。
  • Elasticsearch：添加了带有矢量、关键字和混合搜索的 Elasticsearch 矢量数据库。请参阅食谱。
  • DocumentationMarkdown：为 Knowledge.sync_pages 添加了 transform，可将 Mintlify 和 Fumadocs 组件转换为纯 Markdown。请参阅食谱。

改进：

  • MCPConfig：添加了 root_host、path 和 path_aliases，以便在专用主机名或自定义端点路径上为 MCP 提供服务。
  • MCP 服务器卡：/mcp/server-card 现在返回打印精美的 JSON。

错误修复：

  • MCP 工具：将 MCP 工具结果中的 AudioContent 保留为音频工件。
  • Slack：event_id 删除重复的事件重试，而不是丢弃它们。
  • 远程代理：RemoteAgent.role 和 RemoteTeam.role 现在是返回角色而不是绑定方法的属性；使用 .role，而不是 .role()。
  • 阅读器：TextReader、MarkdownReader 和 FieldLabeledCSVReader 现在接受文本流。
  • PPTXReader：阅读分组形状内的文本。
  • JSONReader：async_read() 现在使用分块策略的异步 achunk()。
  • 分块：在分块之前清理文本时保留换行符和制表符。
  • CSVReader：async_read() 使用 RowChunking(skip_header=True) 跨页保存每个数据行。
  • SitemapReader：保持 myindex.html 等文件名完整，并继续发现无效的 .xml.gz 站点地图。
  • 工具和工作流程：在同步工具结果和 Parallel 工作流程步骤输出中保留 0、False 和 [] 等虚假值。
  • agnoctl：agno connect 现在以 UTF-8 格式读取和写入 client 配置（agnoctl 0.2.1）。
  • DynamoDB：将布尔值序列化为本机 BOOL 值。

重大变更：

  • CodingTools：run_shell 现在是选择加入 (enable_run_shell=True)，并且受限模式无需 shell 即可运行命令。
  • PublicSurface：对于 authorization=True 和 PublicSurface(mcp=True)，MCP 现在默认仅接受 localhost；将您的域名添加到 MCPConfig(allowed_hosts=[...])。
