agno v3.1.5

#Changelog

新功能：

  • 沙盒代理存储库：沙盒 ClaudeAgent 或 CodexAgent 采用 repository=Repository(url, branch="main") 并在 /workspace/repository 处启动该存储库中的每个会话。第一个回合固定确切的提交，后面的回合在热重用和检查点恢复中保留固定和工程师的编辑，并且私有存储库使用来自沙箱环境的 GITHUB_READ_TOKEN 进行身份验证。请参阅食谱。 (#11121)
  • S3 检查点存储：S3CheckpointStore(bucket, prefix=..., endpoint_url=...) 将沙箱检查点保存在 S3 兼容存储桶中，因此沙箱代理可以在多个副本上运行，而无需共享文件系统。对象是内容寻址的，上传在 put 返回之前经过验证，并且凭证来自 AWS 环境。请参阅食谱。 (#11133)
  • 打开运行的沙箱检查点：沙箱代理上的 open_run_checkpoint(run_id) / aopen_run_checkpoint 会生成已提交的已完成运行的经过验证的存档，因此主机进程可以读取容器消失后留下的内容。 checkpoint_store 公开代理轮流写入的存储。请参阅食谱。 (#11131)
  • 按需计划：带有空或省略的 cron_expr 的计划永远不会武装自己，并且仅通过其触发路由、通过 HTTP 和 ScheduleManager 运行。 ScheduleResponse.cron_expr 现在是可选的，并将其报告为 null。 (#11118)
  • KeenableTools：用于 Keenable Web 搜索和页面提取的新工具包（web_search、fetch_url_content，具有异步变体）。它不需要 API 密钥，也没有新的依赖项，并且拒绝解析为私有或环回地址的提取。请参阅食谱。 (#9558)

改进：

  • 注册表中的外部代理：Registry(agents=[...]) 接受 ClaudeAgent 和 CodexAgent，AgentOS 代理、团队和工作流响应带有 sandboxed 标志。 (#11127)
  • 计划端点编辑：通过 PATCH /schedules/{schedule_id} 或通过 ScheduleManager 更改计划的 endpoint 现在会更新其目标列，而不是使其过时。 (#11118)

错误修复：

  • FastAPI 0.147 上的 AgentOS 表单默认值：FastAPI 0.147.0 将省略的 bool 表单字段读取为 False，因此当省略 stream 时运行并继续返回 JSON 而不是 SSE 的路由，并继续，而不会出现 regenerate=true 失败并返回 400 的情况。路由现在恢复声明的默认值stream、monitor 和 replace_original。 (#11160)
  • 沙盒在没有 Redis 的情况下运行：在 POST /agents/{agent_id}/runs 上运行的沙盒代理不再在没有 Redis 的 Postgres 持久队列上回答 400。跨副本流式传输和取消仍然需要Redis。 (#11161)
  • 工作流程文件：Parallel、Steps、Loop、Condition 和 Router 步骤中生成的 File 输出现在到达下一步和 workflow_run_response.files。 (#10950)
  • YouTubeTools：从 Shorts、直播、移动、音乐和隐私增强 URL 读取视频 ID，空 ID 在任何请求之前返回 No video ID found。 (#10707)
  • PerplexitySearch 和 PubmedTools：显式的 max_results=0 受到尊重，而不是被默认值替换。 (#10595)
  • InMemoryDb：upsert_user_memory 存储副本，因此在 upsert 后更改 UserMemory 不再更改存储的内存。 (#11016)
