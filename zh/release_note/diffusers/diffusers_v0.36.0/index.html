diffusers v0.36.0

小版本 发布时间2025年12月8日 来源huggingface/diffusers 英文原文

diffusers v0.36.0

该版本具有许多新的图像和视频管道、新的缓存方法、新的训练脚本、新的 kernels 驱动的注意力后端等等。它充满了很多新东西，所以请务必完整阅读 release notes 🚀

新的图像管道

  • Flux2：Flux2是Black Forest Labs最新一代的图像生成和编辑模型。它能够将多个输入图像作为参考，使其适用于不同的用例。
  • Z-Image：Z-Image 是 6B 参数体系中同类最佳的图像生成模型。感谢 https://github.com/huggingface/diffusers/pull/12703 中的 @JerryWu 代码。
  • QwenImage Edit Plus：它是QwenImage Edit的升级版本，能够将多个输入图像作为参考。它既可以充当生成模型，也可以充当编辑模型。感谢 @naykun 在 https://github.com/huggingface/diffusers/issues/12357. 中的贡献
  • Bria FIBO: FIBO 经过最多 1,000 多个单词的结构化 JSON 字幕训练，旨在理解和控制不同的视觉参数，例如照明、构图、颜色和相机设置，从而实现精确且可重复的输出。感谢 @galbria 在 https://github.com/huggingface/diffusers/pull/12545 中贡献此内容。
  • Kandinsky Image Lite: Kandinsky 5.0 Image Lite 是一个轻量级图像生成模型（6B 参数）。感谢 @leffff 在 https://github.com/huggingface/diffusers/pull/12664 中贡献此内容。
  • ChronoEdit：ChronoEdit 将图像编辑重新定义为视频生成任务，使用输入和编辑的图像作为开始/结束帧，以利用具有时间一致性的预训练视频模型。时间推理阶段引入了推理标记，以确保物理上合理的编辑并可视化编辑轨迹。感谢@zhangjiewu 在 https://github.com/huggingface/diffusers/pull/12593. 中贡献此内容

新的视频管道

  • Sana-Video：Sana-Video 是一种快速高效的视频生成模型，由于其结合了线性注意力，可以处理长视频序列。感谢 @lawrence-cj 在 https://github.com/huggingface/diffusers/pull/12634 中做出的贡献。
  • Kandinsky 5：Kandinsky 5.0 T2V Lite 是一款轻量级视频生成模型（2B 参数），在同类开源模型中排名第一。它的性能优于更大的模型，并提供了对开源生态系统中俄罗斯概念的最佳理解。感谢 @leffff 在 https://github.com/huggingface/diffusers/pull/12478 中贡献此内容。
  • Hunyuan 1.5：HunyuanVideo-1.5是一种轻量级但功能强大的视频生成模型，仅用8.3十亿个参数即可实现最先进的视觉质量和运动连贯性，从而能够在消费级GPU上进行高效推理。
  • Wan Animate：Wan-Animate是基于Wan2.1的最先进的角色动画和替换视频模型。给定参考角色图像和驾驶运动视频，它可以使用驾驶视频中的运动为角色制作动画，或者用该角色替换该视频中的现有角色。

新的 kernels 支持的注意力后端

kernels 库 通过为各种环境和加速器提供预构建的内核接口，帮助您节省大量时间。此版本具有三个新的 kernels 支持的注意力后端：

  • Flash Attention 3（+ 其 varlen 变体）
  • Flash Attention 2（+ 其 varlen 变体）
  • 鼠尾草 这意味着如果您的开发环境支持上述任何后端，您应该能够跳过构建相应内核的手动过程，而只需使用：
# Make sure you have `kernels` installed: `pip install kernels`.
# You can choose `flash_hub` or `sage_hub`, too.
pipe.transformer.set_attention_backend("_flash_3_hub")

有关更多详细信息，请查看文档。

TaylorSeer 缓存

TaylorSeer 现在在 Diffusers 中得到支持，可提供高达 3 倍的速度提升，同时质量影响几乎可以忽略不计。感谢 @toilaluan 在 https://github.com/huggingface/diffusers/pull/12648 中做出的贡献。查看文档此处。

新的训练脚本

我们的 Flux.2 集成具有 LoRA 微调脚本，您可以在[此处]（https://github.com/huggingface/diffusers/blob/main/examples/dreambooth/README_flux2.md）查看。我们提供了许多优化来帮助其在消费级 GPU 上运行。

其他

  • 重用 AttentionMixin：从 AttentionMixin 类中创建某些兼容模型子类帮助我们摆脱了 2K LoC。展望未来，用户可以期待更多此类重构，这将有助于使库更加精简和简单。查看 https://github.com/huggingface/diffusers/pull/12463 了解更多详情。
  • SGLang 中的扩散器后端：https://github.com/sgl-project/sglang/pull/14112.
  • 我们启动了 Diffusers MVP 计划，与才华横溢的社区成员合作，他们将帮助我们在多个方面改进库。查看链接以获取更多信息。
