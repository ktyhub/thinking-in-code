diffusers v0.38.0

diffusers v0.38.0

新管道

LLaDA2

LLaDA2 是一系列离散扩散语言模型，通过逐块迭代细化生成文本。 LLaDA2 不是逐个标记地自动回归生成，而是从完全屏蔽的序列开始，并通过多个细化步骤的置信度逐步揭开标记。

  • PR: https://github.com/huggingface/diffusers/pull/13226
  • 文档：https://huggingface.co/docs/diffusers/main/api/pipelines/llada2

Nucleus-MoE

NucleusMoE-Image 是一个以效率为核心进行训练的 2B 主动 17B 参数模型。我们的新颖架构突出了用于图像生成的稀疏 MoE 架构的可扩展性。

  • 公关：https://github.com/huggingface/diffusers/pull/13317
  • 文档：https://huggingface.co/docs/diffusers/main/api/pipelines/nucleusmoe_image

感谢@sippycoder 的贡献。

Ernie-Image

ERNIE-Image是一个强大且高效的图像生成模型，具有8B参数。

  • 公关：https://github.com/huggingface/diffusers/pull/13432
  • 文档：https://huggingface.co/docs/diffusers/main/api/pipelines/ernie_image

感谢@HsiaWinter 的贡献。

LongCat-AudioDiT

LongCat-AudioDiT是美团龙猫推出的文本转音频扩散模型。

  • 公关：https://github.com/huggingface/diffusers/pull/13483
  • 文档：https://huggingface.co/docs/diffusers/main/api/pipelines/longcat_audio_dit

感谢@RuixiangMa 的贡献。

王牌步 1.5

ACE-Step 1.5 根据文本提示和可选歌词生成 48 kHz（10 秒到 10 分钟）的可变长度立体声音频。完整的系统将语言模型规划器与扩散变压器（DiT）合成器配对；该管道包装了该堆栈的 DiT 一半，由三个组件组成：AutoencoderOobleck VAE，将波形压缩为 25 Hz 立体声潜在信号；基于 Qwen3 的文本编码器，用于提示和歌词调节；以及 AceStepTransformer1DModel DiT，使用流匹配在 VAE 潜在空间中运行。

  • 公关：https://github.com/huggingface/diffusers/pull/13095
  • 文档：https://huggingface.co/docs/diffusers/main/api/pipelines/ace_step

感谢@ChuxiJ 的贡献。

Flux.2 小型解码器

使用 Black Forest Labs 推出的这款新型小型解码器模型，让您的 Flux.2 解码速度更快。您可以查看这里。它是由@huemin-art 在此 PR 中贡献的。

模块化管道支持

我们添加了对 LTX-2 和 Hunyuan 1.5 的模块化支持。

  • FlashPack加载
  • 团体卸载+TorchAO
  • ring_anything 作为新的 CP 后端
  • 在扩散器中分析管道
