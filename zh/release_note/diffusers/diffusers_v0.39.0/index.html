diffusers v0.39.0

新管道

宇宙 3

Cosmos 3 is NVIDIA’s unified world foundation model (WFM) for Physical AI — a single omni-model built on a Mixture-of-Transformers (MoT) architecture that combines world generation, physical reasoning, and action generation, replacing the separate Predict, Reason, and Transfer models from earlier Cosmos releases. A single Cosmos3OmniTransformer runs a Qwen-style language model in parallel with a diffusion generation pathway, joined by a 3D multimodal RoPE. This release also lands video-to-video and action-conditioned generation, and a sound encoder.

  • 公关：https://github.com/huggingface/diffusers/pull/13818
  • 文档：https://huggingface.co/docs/diffusers/main/api/pipelines/cosmos3

Thanks to @atharvajoshi10, @yzhautouskay, and @MaciejBalaNV for the contributions.

表意文字 4

Ideogram 4 is a flow-matching text-to-image model that uses a multimodal text encoder and an asymmetric classifier-free guidance scheme: a dedicated unconditional_transformer produces the negative branch with zeroed text features, while the main transformer consumes the full packed text + image sequence. The pipeline ships with structured prompt upsampling and LoRA loading support.

  • 公关：https://github.com/huggingface/diffusers/pull/13859
  • 文档：https://huggingface.co/docs/diffusers/main/api/pipelines/ideogram4

感谢@JinLiIdeogram 的贡献。

韩国2

Krea 2 (K2) 是一种围绕具有分组查询注意力的单流 MMDiT 构建的流匹配文本到图像模型。 A Qwen3-VL text encoder provides the conditioning — hidden states from twelve decoder layers are tapped per token and fused inside the transformer by a small text-fusion stage — and images are decoded with the Qwen-Image VAE. Both the base (midtrain) and TDM (distilled, few-step) checkpoints are supported, alongside a LoRA DreamBooth trainer.

  • 公关：https://github.com/huggingface/diffusers/pull/14045
  • 文档：https://huggingface.co/docs/diffusers/main/api/pipelines/krea2

Thanks to @EleaZhong and @Abhinay1997 for the contribution.

梦想精简版

DreamLite is a text-to-image and image-editing model from ByteDance. It pairs a custom 2D U-Net (DreamLiteUNetModel) with the Qwen3-VL multimodal encoder as its prompt / image-instruction encoder, and uses an AutoencoderTiny (TAESD-style) VAE for fast latent encode/decode.精炼的 DreamLiteMobilePipeline 目标是设备上的低延迟生成。

  • 公关：https://github.com/huggingface/diffusers/pull/13815
  • 文档：https://huggingface.co/docs/diffusers/main/api/pipelines/dreamlite

感谢@Carlofkl 的贡献。

PRX 像素

PRXPixel is a pixel-space text-to-image generation model by Photoroom. A ~7B PRXTransformer2DModel 直接对原始 RGB 图像进行去噪——无需 VAE。 The model is conditioned on a Qwen3-VL text encoder and uses flow matching where the transformer predicts the clean image at each step (x-prediction).

  • 公关：https://github.com/huggingface/diffusers/pull/13928
  • 文档：https://huggingface.co/docs/diffusers/main/api/pipelines/prx_pixel

感谢@DavidBert 的贡献。

主题视频

Motif-Video is a 2B parameter diffusion transformer for text-to-video and image-to-video generation. It features a three-stage architecture (12 dual-stream + 16 single-stream + 8 DDT decoder layers), Shared Cross-Attention for stable text-video alignment over long sequences, a T5Gemma2 text encoder, and rectified flow matching for velocity prediction.

  • 公关：https://github.com/huggingface/diffusers/pull/13551
  • 文档：https://huggingface.co/docs/diffusers/main/api/pipelines/motif_video

感谢@waitingcheung 的贡献。

AnyFlow

AnyFlow from NVIDIA, NUS, and MIT is the first any-step video diffusion framework built on flow maps, enabling a single model (bidirectional or causal) to adapt to arbitrary inference budgets.它提供基于 Wan2.1 主干网络构建的双向和 FAR 因果管道，涵盖文本到视频、图像到视频和视频到视频。

  • PR: https://github.com/huggingface/diffusers/pull/13745
  • 文档：https://huggingface.co/docs/diffusers/main/api/pipelines/anyflow

Thanks to @Enderfga for the contribution.

JoyAI-Image-Edit

JoyAI-Image is a unified multimodal foundation model for image understanding, text-to-image generation, and instruction-guided image editing.它将 8B 多模态 LLM 与 16B 多模态扩散变压器 (MMDiT) 相结合。 JoyImageEditPipeline 支持一般图像编辑以及空间编辑功能，包括对象移动、对象旋转和相机控制。

  • PR: https://github.com/huggingface/diffusers/pull/13444
  • 文档：https://huggingface.co/docs/diffusers/main/api/pipelines/joyimage_edit

Thanks to @Moran232 for the contribution.

DiffusionGemma

DiffusionGemma 是一种块扩散编码器-解码器语言模型。 A causal encoder reads the clean prompt (and any previously generated blocks) into a KV cache, and a bidirectional decoder denoises a fixed-size “canvas” of tokens by cross-attending to that cache, committing the most confident tokens via the new BlockRefinementScheduler.已发布的检查点为google/diffusiongemma-26B-A4B-it。

  • PR: https://github.com/huggingface/diffusers/pull/13986
  • Docs: https://huggingface.co/docs/diffusers/main/api/pipelines/diffusion_gemma

Anima

Anima 是一个 20 亿参数的文本到图像模型，由 CircleStone Labs 和 Comfy Org 合作创建。 It is focused mainly on anime concepts, characters, and styles, but is also capable of generating a wide variety of other non-photorealistic content.

It reuses the CosmosTransformer3DModel with a Qwen3 text encoder, a T5-token text conditioner, and the AutoencoderKLQwenImage VAE.

  • PR: https://github.com/huggingface/diffusers/pull/13732
  • Docs: https://huggingface.co/docs/diffusers/main/api/pipelines/anima

Thanks to @rmatif for the contribution.

新型 LTX2InContextPipeline（上下文 LoRA）和 LTX2HDRPipeline 通过上下文调节和 HDR 视频生成扩展了 LTX-2 系列。
