macOS 安装说明

该应用程序尚未使用 Apple Developer ID 进行签名，因此 macOS 可能会调用 下载的版本 “已损坏” — 这是 Gatekeeper 隔离区，而不是坏文件。 将应用程序移动到应用程序后，清除一次标志，然后正常打开：

xattr -dr com.apple.quarantine "/Applications/OpenHands Agent Canvas.app"

签名+公证在 OpenHands/OpenHands#16774 中进行跟踪。
