AionUi v2.1.54

修订 发布时间2026年8月12日 来源iOfficeAI/AionUi 英文原文

AionUi v2.1.54

亮点

Discord 作为聊天频道

  • Discord 作为内置通道加入 Slack：在“设置”→“通道”中输入 Bot 令牌，测试并启用，然后批准配对请求并管理授权用户。

预览中的链接和图表

  • 当您在聊天或预览中选择链接时，您现在可以选择在内置浏览器或系统浏览器中打开它。相邻的自动链接 URL 过去常常一起运行，因此普通的 click 经常会打开错误的 URL — 现在您可以手动选择确切的 URL。
  • 预览面板中的美人鱼图可以缩放、平移、全屏、复制和下载，而不是固定的静态图像。
  • 可编辑文件在预览工具栏中获得“保存”按钮，因此保存不再需要记住 Ctrl/Cmd+S。

降级时消息更清晰

  • 在较新的 AionUi 上安装较旧的 AionUi 常常会失败，并显示通用的“本地数据迁移失败”对话框，告诉您重新安装或联系支持人员。现在它说明了实际发生的情况，并且更新 AionUi 即可解决问题。

错误修复

  • 修复了在列表到达之前展开文件夹时项目资源管理器面板中的崩溃问题。
  • 从预览选项卡下载 PDF、DOCX、XLSX 或 PPTX 会生成 0 KB 文件。下载现在获取真实字节。

引擎更新（AionCore v0.1.63 → v0.1.65）

  • CLI 版本漂移通知现在实际上已到达您的手中，并且不再被视为错误。
  • 反重力的模型列表已正确解析，因此其模型再次显示。
  • 现在会报告在代理开始之前取消回合，而不是让对话等待。

  • 壮举（预览）：通过 @tcp404 在 https://github.com/iOfficeAI/AionUi/pull/3964 中将保存按钮添加到可编辑文件工具栏
  • 修复（资源管理器）：在 https://github.com/iOfficeAI/AionUi/pull/3966 中通过 @tcp404 停止 React #185 loadMore 循环
  • feat(channel): 通过 @tcp404 在 https://github.com/iOfficeAI/AionUi/pull/3956 中添加 Discord 通道配置 UI
  • 壮举（侧边栏）：https://github.com/iOfficeAI/AionUi/pull/3969 中 @tcp404 的后端驱动分组、分页和引脚保真度
  • 修复（预览）：在 https://github.com/iOfficeAI/AionUi/pull/3973 中下载 @pooya79 的 PDF、DOCX、XLSX 和 PPTX
