AionUi v2.1.59

修订 发布时间2026年8月19日 来源iOfficeAI/AionUi 英文原文

AionUi v2.1.59

亮点

文件资源管理器：拖放 + 新建文件/文件夹

  • 您现在可以直接在项目树中拖动文件和文件夹以跨目录移动它们，不再需要手动剪切/粘贴或终端命令。
  • 添加了“新文件/新文件夹”条目以及用于相关操作的分组右 click 菜单，使文件操作更易于发现。
  • 底层引擎现在通过适当的复制/移动命令支持这些传输，因此拖动传输和文件创建更加可靠。

反馈表

  • 反馈表现在有一个可选的联系电子邮件字段，以便团队可以跟进您报告的问题。

引擎更新 (AionCore v0.1.70)

  • 会话列表现在区分任务子代理和常规后台任务，使任务状态一目了然。

错误修复

  • 修复了聊天 Markdown 标题内的内联标记（粗体/斜体）错误地继承了标题的较大字体大小。
  • 修复了聊天 KaTeX 公式偶尔渲染两次的问题；它们现在在 Shadow DOM 中渲染一次。
  • 修复了代理回复中的相对路径图像无法显示的问题。
  • 修复了桌面渲染器启动失败时的重新加载风暴；重新启动现在已被取消和限制。
  • 修复了单色主题徽标不遵循活动主题颜色的问题。
  • 修复了 HTML 渲染器内联本地资源时的路径遍历问题。
  • 改进了代理回复媒体的图像根目录解析方式，以实现更准确的图像查找。
  • 修复了代理回复中的本机媒体块（图像/文件）未与其相应的文件链接配对的问题。
  • 修复了从 Antigravity 传输文本时偶尔出现的乱码 (U+FFFD)。
  • 修复了团队模式中的反重力不与其他模式经过相同的 CLI 路径，导致行为不一致的问题。
  • 修复了在正常关闭应用程序期间数据目录实例锁未立即释放的问题。
  • 强化了关闭看门狗的强制退出回退功能，以防止应用程序在退出时挂起。
  • 修复了在某些 Windows 设置中 cmd.exe 无法启动后端二进制路径的问题。
  • 修复了通过重用应用程序级对话服务构建 cron 任务状态时的潜在问题。

发生了什么变化

  • feat(explorer)：通过https://github.com/iOfficeAI/AionUi/pull/4090中的@tcp404在项目树中拖动传输文件
  • 修复（markdown）：在 Shadow DOM 中通过 @tcp404 在 https://github.com/iOfficeAI/AionUi/pull/4091 中渲染聊天 KaTeX 公式一次
  • 壮举（反馈）：通过 @tcp404 在 https://github.com/iOfficeAI/AionUi/pull/4096 中添加可选的联系电子邮件字段
  • 修复（安全）：https://github.com/iOfficeAI/AionUi/pull/4097 中的 @tcp404 阻止 HTML 渲染器资源内联中的路径遍历
  • 修复（ui）：使单色徽标遵循https://github.com/iOfficeAI/AionUi/pull/3614中@ChristianLuciani的主题颜色
  • 修复（桌面）：通过 https://github.com/iOfficeAI/AionUi/pull/4100 中的@kaizhou-lab 进行回退和节流重新启动来停止渲染器启动失败的重新加载风暴 *壮举（资源管理器）：新文件/目录+ https://github.com/iOfficeAI/AionUi/pull/4102中@tcp404分组的行菜单
  • 修复（acp）：在https://github.com/iOfficeAI/AionUi/pull/4103中@tcp404渲染代理回复中的相关图像
  • 修复（markdown）：在 https://github.com/iOfficeAI/AionUi/pull/4104 中 @kaizhou-lab 的聊天标题中将内联标记保留在标题大小
  • 重构（媒体）：通过 @tcp404 在 https://github.com/iOfficeAI/AionUi/pull/4105 中从 ConversationContext 读取图像根
  • 杂务：https://github.com/iOfficeAI/AionUi/pull/4107 中 @kaizhou-lab 的 2.1.59 凹凸版本
