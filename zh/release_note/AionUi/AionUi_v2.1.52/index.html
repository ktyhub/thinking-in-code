AionUi v2.1.52

修订 发布时间2026年8月7日 来源iOfficeAI/AionUi 英文原文

AionUi v2.1.52

亮点

源代码控制：更改面板

  • 对话资源管理器获得“更改”面板：查看项目存储库的已修改/添加/删除文件，内联暂存和取消暂存它们，并在操作仅部分成功时获得清晰的结果横幅。
  • 包含多个存储库的项目显示一个存储库切换器，顶部带有标签；单一回购项目直接进行更改。
  • 状态字母（A/M/D…）根据文件实际发生的情况着色，并且存储库状态随着磁盘上的文件更改而实时更新。

错误修复

  • 搜索主页助手下拉列表现在匹配与代理设置页面相同的字段 - 名称、描述、后端、CLI 命令 - 因此输入“ag”也可以找到反重力，而不仅仅是在设置中。
  • macOS 快捷方式现在仅接受 Cmd，因此 Ctrl+B / Ctrl+F 返回系统的文本导航行为，而不是触发 AionUi 操作。 Windows 和 Linux 仅接受 Ctrl。
  • 当规则的选择器包含 :hover、::before、:not() 和类似内容时，自定义 CSS 主题不再中断 - 多个内置预设因此而悄然损坏。
  • 修复了一个罕见的启动状态，即应用程序自己的令牌变暗，而组件库保持亮色，从而留下不匹配的半暗 UI。

安全

  • 图像生成工具既不验证工作区路径也不验证输入图像路径，因此恶意模型响应可以读取或写入工作区之外的文件。路径现在仅限于工作区。感谢@flyzstu 报告并解决了这个问题。

引擎更新（AionCore v0.1.61 → v0.1.62）

  • 实时存储库设置更改流 - 上面“更改”面板的后端部分。

发生了什么变化

  • feat(scm)：通过https://github.com/iOfficeAI/AionUi/pull/3894中的@tcp404更改具有多存储库切换器和存储库标签的面板
  • 杂务（文档）：https://github.com/iOfficeAI/AionUi/pull/3908中@IceyLiu更新微信群二维码为wx-19
  • ci：https://github.com/iOfficeAI/AionUi/pull/3911 中@piorpua 在 PR 检查中提高单元测试和覆盖作业超时
  • 修复（快捷方式）：在 https://github.com/iOfficeAI/AionUi/pull/3909 中使用 @CleverC2200 的平台原生主修饰符
  • 修复（安全）：防止https://github.com/iOfficeAI/AionUi/pull/3906中@flyzstu在图像生成MCP工具中进行路径遍历
  • 修复（主题）：通过 postcss 解析自定义 CSS，而不是通过 https://github.com/iOfficeAI/AionUi/pull/3915 中的 @tcp404 的正则表达式
