AionUi v2.1.58

修订 发布时间2026年8月18日 来源iOfficeAI/AionUi 英文原文

AionUi v2.1.58

亮点

国际化和从右到左 (RTL) 支持

  • 波斯语 (fa-IR) 现在以完整的从右到左布局呈现 - 整个应用程序中的镜像图标、面板和阅读方向。
  • 数字、日期和时间现在根据您在 AionUi 中选择的语言而不是操作系统区域设置进行格式化 - 不再出现不匹配的货币符号或意外的日期顺序。
  • 填补了法语、德语、西班牙语、葡萄牙语等数十个缺失的翻译；下拉列表和对话框中的组件字符串现在可以以 13 种受支持语言中的 11 种（而不是 5 种）正确呈现。
  • 计数文本（例如“1 个文件已更改”）现在使用每种语言的正确复数形式，包括俄语和乌克兰语的三向复数规则。
  • 计划任务标题和文件大小现在使用区域设置感知的日期和数字格式，而不是硬编码格式。

自定义主题

  • 主题现在可以为浅色和深色模式定义一组经过验证的颜色标记，并且新的自定义主题指南将引导您构建自己的主题。尝试设置 → 外观下捆绑的新粗野主义示例。

Markdown 预览：数学公式

  • 文件预览查看器中的多行 LaTeX/KaTeX 数学块不再分解中间公式 - 数学现在可以清晰地呈现为一个整体。

团队模式改进

  • 在模型选择器旁边添加了模型刷新按钮，因此在其他地方进行的模型切换会立即反映在会话中。
  • 添加了运行时重新启动控件，可重建代理进程以获取配置更改，同时保留聊天历史记录。
  • 团队负责人现在可以使用 /clear 清除成员的上下文，并一起读取成员的所有排队消息，而不是一次被打断一条消息。
  • 团队成员现在拥有自己的绑定 MCP 工具，与常规会话相匹配。
  • 成员选择的模型现在仍然存在，并且领导者可以中断成员当前的回合并立即发送新指令。
  • 修复了团队成员偶尔陷入“处理”状态的问题。

引擎更新 (AionCore v0.1.69)

  • Claude 工具调用步骤现在按其实际执行的操作进行标记，以便在工具运行时更轻松地跟踪对话。

错误修复

  • 修复了 AionUi 的内部 PREBUILDS_ONLY 设置泄漏到代理子进程中的问题，这可能会导致第三方 CLI（例如光标代理）崩溃，并在启动时出现“未找到本机构建”错误。
  • 修复了深色模式下不一致的发送/草稿操作按钮颜色，并删除了发送按钮周围的杂散背景伪影。
  • 修复了系统设置中的目录路径在之前的 RTL 修复后对于从左到右的语言未对齐的问题。
