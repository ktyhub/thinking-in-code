AionUi v2.1.49

修订 发布时间2026年8月6日 来源iOfficeAI/AionUi 英文原文

AionUi v2.1.49

亮点

说和听：音频附件和语音输入

  • 音频文件（mp3、wav、m4a、ogg、flac）现在可以通过上传或粘贴来附加，图像和音频可以作为本机内容而不是文件路径到达有能力的代理。当代理对您附加的内容没有本机支持时，芯片会预先告诉您 - 文件仍然会通过，就像路径一样。
  • 对话运行时语音输入保持可用，在紧凑的移动布局中工作，并选择 Cmd/Ctrl+M 快捷方式在任何处于活动状态的作曲家中开始和停止录制 - 包括团队列。

代理可以问您真正的问题

  • 当客服人员提出结构化问题时，它现在会呈现为正确的卡片：单选、多选和您可以输入的“其他”行。一次提交会立即回答卡中的每个问题，因为克劳德会默默地在部分答复中删除未回答的问题 - 因此卡拒绝提交，直到您回答了所有问题，并且驳回它会发送明确的 decline 而不是空洞的批准。
  • 重新打开未回答的问题的对话会重建同一张卡片，而不是纯粹的权限提示。
  • 通过权限通道发送问题的代理现在也可以读取：请求详细信息呈现为格式化的 JSON，而不是唯一一行是工具名称的卡片。

观察命令运行

  • 当 ACP 代理将命令交给 AionUi 运行时，您会实时看到它：该命令、其流输出、其状态，以及一个停止按钮，该按钮可以终止该特定命令，而无需触及该回合的其余部分。

团队模式：消息和任务活动

  • 每个团队成员（包括领导者）始终有一个邮箱和任务板；两者在任何地方都看不到。现在有一个只读板视图显示两者，实时更新，并带有您可以跳转到的依赖项标签。消息与任务一起出现，因为领导者经常通过邮箱直接分配工作。
  • 选择代理头像和聚焦列的输入现在是同一行为。以前，每个栏目都竞相争夺坐骑的焦点，因此焦点输入实际上是随机的，很少是您突出显示的特工。
  • 该视图适用于拥有多名成员的团队。

预览面板，每个项目

  • 预览面板现在适用于每个项目并记住其打开的选项卡，因此切换回来可以恢复您打开的内容。未保存的文本编辑仍然存在；图像、PDF 和 Office 文件会重新获取而不是存储，因此大图像不会使本地状态膨胀。
  • 几种失去工作的途径被关闭。超大文件将被排除在编辑器之外，而不是被默默地截断，并且保存会携带文件的修改时间 - 如果某些内容在您背后更改了文件，您会收到通知，而不是覆盖它。
  • 在磁盘上更改的文件会将其选项卡标记为重新加载，并首先询问重新加载未保存的编辑。

其他地方

  • 单个文件的文件更改卡折叠为紧凑的一行 — 文件名、+/- 计数和预览链接。
  • 计划任务从卡片网格移至紧凑的行列表，使助手头像、计划、下次运行时间、状态和启用开关每行可见。溢出菜单消失了，因为每一行都已经打开了其详细信息页面。
  • 移动 WebUI 文件处理：文件和文件夹选择器适应窄屏幕，项目资源管理器项目获得可见的操作菜单（桌面保持右侧 - click），家庭作曲家提供主机文件和从您所持有的设备上传的文件。

错误修复

  • 长时间运行的命令不再破坏对话视图。 Codex 可以在命令继续运行时结束回合，并且命令随后打印的所有内容都会在几分钟后到达新的回合 ID。两条路径将延迟完成应用于当前的任何回合，因此完成的回合的结局可能会落在您刚刚开始的回合上 - 并且侧边栏停止为每个后续回合显示“生成”。一名用户的日志在一天内的 4 个对话中出现了 1,580 个丢帧。
  • 损坏的代理进程注册表不再中止关闭。文件与后端共享，并发写入可能会破坏它；解析失败会破坏清理，泄漏孤立代理进程，并在生产中破坏消息发送。现在，读取会降级而不是抛出，写入是原子的，并且并发注册的条目在清理过程中仍然存在。
  • 需要一定时间启动的后端不再被报告为损坏的安装。只要后端保持安静 30 秒，包括完好无损的安装，“重新安装/检查防病毒”对话框就会触发 - 一个用户的后端在 47 秒内报告，然后运行良好。该案例收到一条诚实的“启动超时”消息，并且窗口现在为 60 秒。
  • Windows 文件路径在 Y2K Ledger 皮肤中再次显示反斜杠。该主题首先列出了日语字体，Meiryo 和 Yu Gothic 根据旧版 JIS 惯例将 U+005C 绘制为日元符号 - 文本从未改变，只是绘制错误。 -“思考”和“查看步骤”标题中的微调器位于旁边文本下方 3.5 像素处，并在切换为静态图标时跳跃。现在它是像素对齐的，集中固定在两个图标系统而不是每个组件上。

引擎更新（AionCore v0.1.58 → v0.1.59、Aion CLI 运行时 v0.2.8 → v0.2.9）

  • 原生图像和音频内容块，由每个代理声明它可以接受的内容进行门控 - 上面附件工作的后端部分。
  • 只读邮箱和任务 API 及其实时事件，位于团队活动视图后面。
  • Aion CLI：仅产生推理的回合，或其流携带嵌入错误的回合，不再空返回。流错误和丢失终止符现在会失败，而不是默默地通过，工具在第一次空响应重试时保持可用，官方 OpenAI 端点默认为 max_completion_tokens。
