AionUi v2.1.53

修订 发布时间2026年8月10日 来源iOfficeAI/AionUi 英文原文

AionUi v2.1.53

亮点

Slack 作为聊天频道

  • Slack 不再是“即将推出”：在“设置”→“通道”中配置机器人令牌和应用程序级令牌，测试连接，选择模型，并管理哪些 Slack 用户有权与您的代理交谈。

Claude 和 Codex 现在运行您自己的安装

  • AionUi 过去常常发布自己固定的 claude 和 codex 副本，因此相同的提示在 AionUi 中的行为可能与在终端中的行为不同 - 是不可见的。现在，两者都运行您已有的安装，就像 Antigravity 始终采用的方式一样，当您的版本与此版本验证的版本不同时，AionUi 会告诉您。

源代码控制面板，第二轮

  • 面板被重组为可折叠部分，带有可拖动调整大小的分隔线和双 click 重置功能，紧随 VS Code 侧边栏。
  • 更改部分获得树/列表视图切换。
  • 现在可以从工作区根目录下一级发现存储库，因此无需手动设置即可拾取多存储库项目。

从资源管理器复制路径

  • 右键 click 项目资源管理器中的任何文件或文件夹以复制其相对路径或（在桌面上）其绝对路径。

错误修复

  • 修复了打包的桌面版本、WebUI 切换和 Web 版本上的全白屏幕 - 由错误的供应商块分割引起。
  • 在狭窄的窗口中，clicking 项目对话树中的文件现在实际上会打开预览。
  • 右键 clicking 文件夹并选择“添加到聊天”现在会生成一个筹码，并将文件夹实际发送给代理，而不仅仅是显示成功祝酒。
  • AI 回复上的复制按钮现在可以复制整个回合。与工具调用交错的回复或之前的思考丢失了最后一个文本段之前的所有内容。
  • 项目 Markdown 预览中的相对路径图像不再渲染损坏。
  • 浏览技能文件现在可以在 WebUI 中运行，而不仅仅是在桌面上。
  • 反重力再次出现在助理编辑器的代理下拉列表中，其代理字段显示名称而不是原始 ID。
  • 现在会重试失败的文件监视订阅（脱机或重新连接后套接字立即关闭），而不是默默地让该文件夹永远失效。

引擎更新（AionCore v0.1.62 → v0.1.63）

  • 运行后台工作的代理（工作流程、后台 shell、后台子代理）不再在飞行途中被空闲扫描仪杀死。
  • 代理现在会收到项目的真实案例绝对路径，而不是案例折叠的路径。

注意

  • 删除了分叉时代主题设置的一次性迁移。在当前主题系统之前创建的主题不再自动继承。
