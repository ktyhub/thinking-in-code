AionUi v2.1.43

修订 发布时间2026年7月29日 来源iOfficeAI/AionUi 英文原文

AionUi v2.1.43

亮点

项目范围的资源管理器

  • 每个对话工作区文件树被项目级资源管理器取代。在同一项目中切换对话或代理选项卡不再重新安装或重新加载树、预览或文件订阅 - 面板保持不变并保持活动状态。
  • 树条目现在首先对目录进行排序，就像其他文件管理器一样。

ACP 对话的上下文使用指示器

  • 发送按钮旁边的进度环显示代理上下文窗口的使用量（例如“4.8%·12.6K / 262.1K 使用上下文”），完全由代理报告的数据驱动 - 无需猜测模型表。报告会话成本的代理还会获得包含每轮输入/输出/缓存细分的成本线。

团队手动唤醒

  • 现在可以使用模型选择器中的 click 唤醒休眠的队友，补充惰性预热流程 - 当您希望成员在向其分派工作之前做好准备时非常有用。

修复和改进

  • WebUI 文件和文件夹选择器再次工作（为浏览器运行时实现的dialog.showOpen）。
  • 当您切换对话并返回时，思考经过的计时器不再重置。
  • 桌面宠物的启用开关现在从权威值读取其初始状态，而不是猜测。
  • WebUI 减少了冗余的 API 重新获取。

引擎更新（AionCore v0.1.53 → v0.1.54）

  • 多帐户支持基础工作：用户数据现在按帐户进行范围隔离。
  • Project Explorer 后端登陆（运行时、通过 WebSocket 实时文件监视、HTTP 控制平面）——这为上面的新 Explorer 提供了动力。
  • 代理-client 协议 SDK 从 0.11.1 升级到 2.0.0，以便更好地与当前 ACP 代理兼容。

发生了什么变化

  • 修复（webui）：实现dialog.showOpen，以便文件和文件夹选择器由@xsyk在＃3766中工作
  • 修复（对话）：在对话切换中保持 ThoughtDisplay 经过的计时器，由 @kaizhou-lab 在 #3774 中实现
  • feat(explorer)：项目范围的资源管理器在#3763中用@tcp404替换工作区树
  • feat(explorer): 在 #3775 中通过 @tcp404 对树条目目录进行排序
  • 重构（webui）：减少冗余的 API 重新获取并通过 #3768 中的 @tcp404 删除死的前端 fs 访问器
  • 修复（pet）：源pet启用从权威值切换初始状态由@piorpua在＃3777
  • 壮举（团队）：将 click 唤醒手动预热触发器添加到队友模型选择器中，由 @piorpua 在#3776 中添加
  • feat(conversation)：恢复代理报告的 ACP 对话上下文使用指标，由 @kaizhou-lab 在 #3772 中完成
  • 杂务：由 @piorpua 在 #3782 中将版本提升到 2.1.43
