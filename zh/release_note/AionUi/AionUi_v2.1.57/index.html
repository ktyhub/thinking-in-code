AionUi v2.1.57

修订 发布时间2026年8月17日 来源iOfficeAI/AionUi 英文原文

AionUi v2.1.57

亮点

中途插入

  • 您不再需要等待客服人员完成后再输入。在克劳德和 Codex 对话中，输入框在回合运行时保持可用，并且您的消息会显示交付状态徽章，以便您知道它是否落地。其他后端保留现有的队列面板。

资源管理器和源代码管理波兰语

  • 文件树现在使用来自 catppuccin 图标主题的每种类型的文件图标，具有浅色和深色变体，因此图标在两种外观下都保持清晰。
  • 源代码控制存储库行更好地对齐，并且主题库布局是固定的。

错误修复

  • WebUI 访问地址可能会在具有 VPN 或隧道适配器（例如 Cloudflare WARP）的计算机上显示无法访问的 IP。现在它会选择您的实际 LAN 地址。
  • 通过 WebUI 上传文件可能会永远挂在 100%，因为部分上传在路由竞争中被丢弃。固定的。
  • 删除了覆盖 Windows 上面板内容的重复资源管理器折叠控件。

引擎更新（AionCore v0.1.67 → v0.1.68）

  • 中途消息传递——上述插入功能的后端部分。
  • Codex 对话会自动获得标题，并且命令步骤会被标记。
  • 按需安装的首次运行代理现在有时间安装，而不是超时。
  • 代理失败报告真正的原因，而不是不透明的内部错误代码。
  • 现在可以找到通过bun或供应商安装程序安装的代理CLI。

发生了什么变化

  • feat(explorer)：主题文件树图标和 SCM 侧边栏由 @tcp404 在 https://github.com/iOfficeAI/AionUi/pull/4057 中完善
  • feat(chat): 转弯中感叹词 — 允许在转弯飞行时发送 @kaizhou-lab in https://github.com/iOfficeAI/AionUi/pull/4012
  • 修复(web-host): 在https://github.com/iOfficeAI/AionUi/pull/4060中通过@tcp404为WebUI访问URL选择真实的LAN IP
  • 杂务（文档）：https://github.com/iOfficeAI/AionUi/pull/4063中@IceyLiu更新微信群二维码为wx-20
  • 修复（资源管理器）：通过 https://github.com/iOfficeAI/AionUi/pull/4065 中的 @tcp404 删除重复的桌面切换
  • 修复（网络主机）：在拼接之前暂停 client 套接字，以避免 https://github.com/iOfficeAI/AionUi/pull/4066 中的 @tcp404 丢弃上传字节
  • 杂务：https://github.com/iOfficeAI/AionUi/pull/4067 中 @piorpua 的 2.1.57 碰撞版本

完整 Changelog：https://github.com/iOfficeAI/AionUi/compare/v2.1.56…v2.1.57
