clickhouse-java v0.9.7

clickhouse-java v0.9.7

重要提示

  • Client.Builder.addEndpoint(String) 的行为已更改：现在它保存 URL 基本路径（更多信息请参见 https://github.com/ClickHouse/clickhouse-java/issues/2344）。以前此方法忽略基本路径。请注意，该方法仍然会忽略查询参数。端点与 JDBC URL 不同。 Client有指定的构建器方法来设置配置。

重大变更

  • [client-v2] Client.Builder#build() 现在在传递未知配置属性时抛出 ClientMisconfigurationException。以前，未知的属性会被默默地忽略，从而导致意外的行为和问题。要恢复旧行为，请将 ignore_unknown_config_key=true 添加到 client 属性。仅 JDBC 驱动程序属性（例如 ssl）不再转发到底层 ZZPH100​​ZZent。 (https://github.com/ClickHouse/clickhouse-java/issues/2658)

  • [client-v2] Date/Date32 列现在解码为 LocalDate，无需任何时区调整。以前，Date 值可以作为 ZonedDateTime 返回。需要 ZonedDateTime 的应用程序必须使用自己的时区上下文从返回的 LocalDate 构造它。更多了解 - https://clickhouse.com/docs/integrations/language-clients/java/jdbc_date_time_guide (https://github.com/ClickHouse/clickhouse-java/pull/2727)

改进

  • [client-v2] 添加了使用多部分表单编码在 HTTP 请求正文中发送查询参数的选项。通过新的 client.http.use_form_request_for_query 配置属性（或 Client.Builder#useHttpFormDataForQuery()）启用。当查询参数超出 URL 长度限制时很有用。 (https://github.com/ClickHouse/clickhouse-java/issues/2324)

  • [client-v2] QueryResponse、InsertResponse 和 CommandResponse 现在公开 getServerDisplayName() 以检索 X-ClickHouse-Server-Display-Name HTTP 响应标头的值。可通过 getResponseHeaders() 访问白名单响应标头的完整映射。 (https://github.com/ClickHouse/clickhouse-java/issues/2347)

  • [client-v2] 将 getObjectArray() 添加到 ClickHouseBinaryFormatReader 和 GenericRecord，以将 Array(...) 列读取为 Object[]，包括对嵌套数组的递归支持。 getStringArray() 现在还通过返回枚举名称来处理 Array(Enum*)。 (https://github.com/ClickHouse/clickhouse-java/issues/2738)

  • [jdbc-v2] 添加了对 String/FixedString 列的读写 byte[] 的支持。 PreparedStatement#setBytes() 将值编码为 ClickHouse unhex() 表达式以保留原始字节； ResultSet#getBytes() 返回字符串值的 UTF-8 字节。 (https://github.com/ClickHouse/clickhouse-java/pull/2734)

  • [client-v2] 保留传递给构建器方法 `addEndpoint() (https://github.com/ClickHouse/clickhouse-java/pull/2691) 的 URL 的路径部分

日期和时间处理

  • [文档] 添加了一个文档，解释驱动程序如何处理不同的日期/时间值。

  • [client-v2、jdbc-v2] 修复了写入 Date/Time/Timestamp 值，以便显式执行时区转换。以前，时区幼稚编码会导致日移和精度错误，尤其是在使用 Calendar 或非默认 JVM 时区时。 (https://github.com/ClickHouse/clickhouse-java/issues/2701, https://github.com/ClickHouse/clickhouse-java/issues/2065, https://github.com/ClickHouse/clickhouse-java/issues/2496, https://github.com/ClickHouse/clickhouse-java/issues/1220, https://github.com/ClickHouse/clickhouse-java/issues/1117, https://github.com/ClickHouse/clickhouse-java/issues/1048, https://github.com/ClickHouse/clickhouse-java/issues/2381, https://github.com/ClickHouse/clickhouse-java/issues/1735, https://github.com/ClickHouse/clickhouse-java/issues/2542, https://github.com/ClickHouse/clickhouse-java/issues/2557)

  • [client-v2、jdbc-v2] 修复了读取 Date/Time/DateTime 值的一致性和正确性。 Date/Date32 现在解码为 LocalDate（无时区），而 Time/Time64 则解码为基于 UTC 的 LocalDateTime。新的 getLocalTime() API 添加到读卡器中，用于 LocalTime 访问。从 Dynamic 和 Variant 列读取日期/时间也是固定的。 (https://github.com/ClickHouse/clickhouse-java/pull/2727)

  • [jdbc-v2] DatabaseMetaDataImpl#getTypeInfo() 现在按确定的字母顺序返回类型信息，匹配 v1 驱动程序行为。 (https://github.com/ClickHouse/clickhouse-java/pull/2733)

SQL 解析器 (jdbc-v2)

  • [jdbc-v2] 修复了 SQL 解析器无法处理用作表名或列别名的 ClickHouse 关键字（例如 AS value、FROM date）。 ANTLR4 和 JavaCC 解析器现在都维护标识符位置中允许的非保留关键字的列表。还修复了 SELECT 中 DESCRIBE (SELECT ...)、IN 运算符的解析，以及表达式中括号数组访问。 (https://github.com/ClickHouse/clickhouse-java/issues/2718)

  • [jdbc-v2] 更新了 SQL 解析器以识别最近 ClickHouse HEAD 版本中引入的新 ClickHouse 关键字（ABI、ARGUMENTS、DRY、LANGUAGE、RETURNS、RUN）。以前，使用这些关键字作为标识符的查询将无法解析。 (https://github.com/ClickHouse/clickhouse-java/pull/2761)

  • [jdbc-v2] 修复了 SQL 解析器在处理包含 ^（插入符号）运算符（例如 toJSONString(data.^header_index)）的语句时失败的问题。新的 CARET 令牌现已被识别并允许出现在点状标识符链中。 (https://github.com/ClickHouse/clickhouse-java/issues/2768)

数组和集合处理

  • [jdbc-v2] 修复了将嵌套数组转换为字符串时 DataTypeConverter 导致 NPE（例如 Array(Array(...)) 列上的 ResultSet#getString()）。该转换器现在是可重入安全的。之前扔的是NullPointerException。 (https://github.com/ClickHouse/clickhouse-java/issues/2723)
