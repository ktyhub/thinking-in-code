herdr v0.9.0

herdr v0.9.0

添加

  • 从一个 Herdr 窗口管理本地和已保存的 SSH 计算机，具有组合的代理列表、计算机范围的导航、通知和自动重新连接。添加和管理与 herdr machine 的连接；断开连接的机器不会干扰其他机器。 (#3670)
  • 多个 client 现在可以独立查看不同的工作区和选项卡。不同的标签适合他们的观看 clients；当 clients 共享一个选项卡时，最后一个与之交互的选项卡控制其大小。 (#3526)
  • 添加了针对空闲、工作、批准和问题状态的 Muse 代理检测。 （＃2489，谢谢@ohk）
  • 侧边栏文本和元数据标记现在可以使用有序文本或数字规则根据其值更改颜色、粗体和变暗。 (#3693)
  • 当启用自动主题切换时，自定义主题现在可以定义单独的浅色和深色覆盖。 （＃2324，感谢@aneym）
  • 当启用外边框时，ui.pane_borders = "always" 现在可以构建单个窗格。 "auto" 保留仅分割边框，"off" 隐藏它们，并且现有的布尔值继续工作。 （＃3234，感谢@rsmdt）

已更改

  • Client 更新现在可以使兼容服务器及其正在运行的代理保持不变。缺少的服务器功能仅禁用受影响的操作，而不是阻止连接。早于第一代端点的服务器需要一次性升级。更换远程服务器在停止其窗格进程之前会询问，默认答案为“否”；实验性切换仍处于选择加入状态。 (#3509)
  • 终端 UI 现在在每个 client 中运行，减少了繁忙的多 client 会话中的重画工作，并将主题、菜单、复制模式和其他演示设置保留在查看计算机本地。 (#3487)
  • 空闲终端回滚现在使用更少的内存，而不会减少保留的历史记录或更改读取和调整大小。 (#3556)
  • 窗格图像和图形 API 现在在兼容终端中默认启用。设置 terminal.kitty_graphics = false 来禁用它们；旧的 experimental.kitty_graphics 设置仍然被接受。
  • 现在，使用打开的工作树工作区关闭主工作区需要明确的组意图：workspace close --group 或 workspace.close 与 close_group: true。否则整个团体保持开放。 (#2874)
  • 新的生命周期事件订阅现在从实时事件开始，而不是重播保留的历史记录。 API clients 应在拍摄初始快照之前订阅，以避免丢失更改。 (#1270)

已修复

  • 鼠标选择现在保持可见和可复制，同时终端输出继续，包括禁用自动复制。即使在延迟释放鼠标之前，Ctrl+C 和 Cmd+C 也可以复制选择，并且失败的复制不会再中断代理。当主体颜色不可用时，选择突出显示也保持可见。 （#3100、#2708、#3684，感谢@moret 和@Pimpmuckl）
  • Wayland clipboard 副本不再冻结 Herdr，而 wl-copy 提供选择。 (#3014)
  • 实时切换现在保留运行窗格应用程序的鼠标转发。 （#3000，感谢@xkrogen）
  • 主机关闭期间中断的窗格退出不再用空会话或新的默认工作区替换已保存的会话。 (#3415)
  • 终端消失的 SSH clients 现在分离，而不是将运行窗格的大小调整为后备大小并触发昂贵的历史记录回流。 (#3519)
  • 现在，聚焦工作区会滚动侧边栏以使其保持可见。 (#3554)
  • 删除后台工作树工作区不再将焦点更改为其父级。 Windows 工作树也可以在其代理窗格运行时被删除，而无需替换 shell 再次锁定结帐。 （＃3098，＃3532）
  • Worktree 命令现在可以通过 --trust-repository 为一个请求 trust 验证存储库，包括另一个 SID 拥有的可访问 Windows 存储库，而无需更改全局 Git 配置。 (#3044)
  • 超大的小猫图像不再阻止较小的图像出现，并且图像替换不再一次重绘或消失一行。直接图形与拥有它们的 client 保持绑定。 （#3033、#3166、#3549，感谢@kataokatsuki）
  • 当窗格应用程序重新断言 SGR 鼠标报告时，像素鼠标坐标保持正确。 (#3295)
  • prefix+| 等前缀绑定现在可以识别 macOS Option 和自定义键盘布局生成的字符，而精确的和弦保持优先。当 Alacritty 等终端将文本附加到特殊键报告时，箭头导航也可以工作。 （＃3079，＃3328，谢谢@vlcinsky）
  • 直接终端连接现在支持 ui.mouse_capture 并将多行粘贴保留为一个粘贴，而不是单独提交每一行。 （＃2992，＃3054）
  • agent prompt 现在在报告成功提交之前可靠地发送提示和 Enter。使用 --wait，发送到非工作代理的提示需要观察工作或阻止的活动，因此不相关的状态更改无法完成等待。如果终端退出，待处理的提交就会彻底失败。 （＃3506，＃3685）
  • Windows 上的长 Codex 提示现在需要等待足够长的时间才能收到文本，然后再提交 Enter。在开始输入之前，过期的排队提交将被拒绝。 (#3187)
  • 最近的窗格读取现在包括尚未滚动出视口的输出，而不是返回空文本。 (#3444)
  • pane report-agent 和 pane report-agent-session 现在接受窗格 ID 和 --option=value 参数之前的选项。 (#2926)
  • herdr agent explain --file 现在将不可读文件报告为结构化 JSON，而不是原始 Rust 错误。 (#3022)
  • 运行命名服务器现在可以获取另一台服务器下载的检测清单，无需重新启动。 (#2711)
  • 在启动时设置终端标题或进度的代理在首次识别时不再丢失检测信号。 （＃3326，感谢@aneym）
  • 当终端标题不可用时，克劳德代码现在可以识别可见的转弯和后台代理活动，并在后台 MCP 任务继续时保持工作。仅运行后台 shell 的空闲提示不再保持工作状态。 （＃1630，＃3090，＃3414）
  • Claude Code MCP 问题和 Bash 批准提示现在在等待答案时保持阻塞状态，包括不同的选项布局和光标位置。 （#3283、#3383、#2650、#3615，感谢@caner-akca）
  • Claude 代码挂钩现在会忽略 Cursor 的 Claude 兼容事件，从而防止 Cursor 会话保存为 Claude 会话。 (#2832)
  • Codex 不再显示为被阻止，因为早期的输出引用了确认提示，并且其启动更新对话框现在可以正确报告被阻止。显式恢复的会话会在第一次提示之前保存，因此它们可以在服务器重新启动后继续存在。 （＃3301，＃3632，＃3517）
  • GitHub 副驾驶 CLI 现在在等待后台代理时保持工作状态。 （＃3291，＃3403，感谢@LaneBirmingham）
  • Oh My Pi 现在继续完成已安排的延续工作，而不是短暂报告空闲并提前结束 agent wait。 （#2851、#3122，感谢@caner-akca 和@taoeffect）
  • OpenCode 子代理权限和问题提示不再使父窗格在工作继续后卡住。 （＃3669，感谢@markjaquith）
  • 前台工作目录读取现在遵循前台进程组领导者而不是后代，将新窗格保留在预期目录中。 （＃3270，＃3386，感谢@caner-akca）
  • 过大或不可读的 Git 引用文件不再导致重复的繁重状态读取或使工作区使用陈旧的引用数据。 （＃3343，＃3373，谢谢@caner-akca）
  • 选项卡栏状态命令不再显示杂散的 ANSI 转义片段，主机调色板回复会一起应用以避免冗余更新。 （＃3001，＃3580）
  • Unix 插件窗格现在使 PWD 与其请求的工作目录保持一致，除非明确覆盖。 Windows 插件窗格现在解析来自插件根的相关命令并正确处理启动路径。 （＃2984，＃3024）
  • 插件链接处理程序现在接收匹配的 OSC 8 file:// clicks；不匹配的文件链接仍然不会启动系统 URL 打开程序。 (#2941)
  • Windows 窗格现在保留 Kitty 键盘应用程序中的非美国移位文本、物理修改键、Ctrl+/ 和死键组合。 （＃3045，＃2954，＃3546，＃3503）
  • Windows OpenSSH 会话现在可以可靠地接收鼠标输入，而不会丢失报告或将转义片段泄漏到窗格中。远程和仅 LF 多行粘贴保留其换行符和顺序。 （#2810、#3459、#3209、#3172）
  • Windows 窗格现在可以检测到 Cursor 和捆绑的 Pi 启动，并且 PowerShell 代理垫片接受本机参数。 Codex 不再继承 Windows 终端标识，该标识会在恢复期间导致过多的重画和滚动跳转。 （#3032、#3205、#3455、#3127，感谢@Pimpmuckl）
  • 反重力挂钩现在可以在 Windows 上正确运行，并且 Devin 集成设置使用正确的 Windows 配置目录。 （＃3348，＃2724）
  • Windows 安装不再需要单独安装的 Visual C++ 运行时。安装程序路径在 OpenSSH 会话中仍然可发现，并且格式错误的继承环境值将被安全拒绝。 （＃3089，＃3611，＃3430）
  • 端点安全阻止无文件 PowerShell 安装的 Windows 用户可以使用本地 install.cmd 引导程序以及经过校验和验证的下载。 (#2751)
  • WSL 远程会话现在可以粘贴来自 Windows clipboard 的图像。 (#3376)
  • Nix 安装现在通过静态 CDN 获取包，避免从先前端点下载失败。 （＃3505）
  • Unix 安装程序现在解释说 Android/Termux 不受支持，而不是安装无法在其中运行的 Linux 二进制文件。 (#3571)

已删除

  • 删除了单进程 --no-session 模式。所有终端 UI 启动现在都附加到后台服务器； detach 使窗格保持运行，而 server stop 结束会话。
