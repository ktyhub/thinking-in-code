herdr v0.9.4

修订 发布时间2026年10月13日 来源herdrdev/herdr 英文原文

herdr v0.9.4

添加

  • herdr plugin update 一次性或按名称更新从 GitHub 安装的插件。正在运行的插件窗格会继续处理旧文件，新的运行会在不重新加载配置的情况下获取更新。本地链接的插件将被保留。 （＃4245，感谢@JJLiebig）
  • Windows 通知保留在通知中心。 Clicking 会跳转到其窗格并将终端窗口向前移动。 （＃4773，＃4803，感谢@JJLiebig）

已更改

  • 默认情况下，提升的 Windows 服务器现在仅接受管理员 clients。要让同一帐户中的普通 client 进入，请设置 [server] allow_unelevated_clients = true 或使用 --allow-unelevated-clients 启动服务器。权限错误现在会说明如何修复它们，并且您无法访问的会话将显示为不可用而不是停止。 （#4717、#4769、#4777、#4779，感谢@JJLiebig）
  • 在 Linux 和 macOS 上，关闭启动 Herdr 的 shell 不再停止服务器。使用 SIGHUP 停止 Herdr 的脚本应使用 herdr server stop 或 SIGTERM。服务器日志现在说明了服务器停止的原因。 （＃4920，＃4965）
  • 启用鼠标捕获后，当您 click 时，处理链接的插件将首先被选择。关闭捕获以使用终端自己的链接快捷方式，例如 macOS 上的 Command-click。 （#4874，#5064，感谢@JJLiebig）
  • Antigravity 和 Grok 一旦返回提示符就被视为空闲，即使它们自己的后台任务或子代理仍在运行。 （＃3530，＃4735，＃4959）
  • Ctrl+Shift+字母作为 Ctrl 键到达普通 shell，就像在 Alacritty 和 WezTerm 中一样。 Super、Hyper 和 Meta 快捷方式不再在无法读取它们的应用程序中输入转义代码垃圾。 （＃4356，＃5017）

已修复

  • 重新启动 Mac 或关闭 Windows 会保留座席的会话。 Herdr 在系统开始关闭应用程序之前进行保存，以便客服人员返回原来的位置。 （#4414、#5013、#5057、#5092，感谢@JJLiebig）
  • 会话保存在替换旧文件之前写入磁盘，因此崩溃或断电不会留下不可读的保存。 （＃5150，＃5152，谢谢@JJLiebig）
  • 当机器耗尽进程或线程时，服务器会继续运行，而不是让每个窗格都随之关闭。 （＃3324，＃4958）
  • 超出范围的工作区编号将返回 workspace_not_found，而不是导致服务器崩溃。 （＃5096，＃5171）
  • 使用 Ctrl+Z 暂停代理并使用 fg 将其恢复，保留其名称和保存的对话。 （＃1647，＃4964）
  • 当结帐的 Git 数据缓慢或丢失时，恢复会话保持响应。工作树组可以在暂时不可用的签出中幸存下来，并且两次打开同一存储库不再将一个工作区嵌套在另一个工作区中。 （#4926、#4736、#4945、#4770、#4772，感谢@minatoaquaMK2 和@JJLiebig）
  • 首先询问关闭工作区的唯一窗格，就像关闭其最后一个选项卡一样。使用 ui.confirm_close = false 将其关闭。 （＃5143，＃5173）
  • Ctrl+W 等 Ctrl 快捷键适用于非拉丁键盘布局，例如俄语、希腊语或希伯来语。拉丁布局和 AltGr 字符保持其正常含义。 （＃1079，＃4961）
  • 重音键和 AltGr 快捷键可在 Windows 上使用。 （＃4688，＃5021，感谢@JJLiebig）
  • Shift+Enter 和其他增强键在外部终端重置后继续工作，例如在 VS Code 的重新加载窗口后。 （＃4985，＃5088）
  • 快速退出点击可在 macOS 上使用 WezTerm 的 Kitty 键盘模式。 （＃1266，＃5089）
  • Kitty 键盘应用程序可以正确释放按键以及 F1、F2 和 F4，并且当终端发送 Ctrl+H 时，Backspace 可以工作。 （#4184、#4403、#3244、#5017）
  • 键盘和终端颜色回复不再将杂散字符泄漏到窗格输入中，并且半完成的颜色回复不再冻结打字。 （#4856、#4025、#5052、#5017、#5087）
  • 当您调整窗格大小时，Fish 不再重复提示片段。 zsh 和 Powerlevel10k 的相同问题仍然存在，等待 Ghostty 修复。 （＃3672，＃4977）
  • 要求像素鼠标坐标的应用程序可以获取它们，并且 clicks 降落在仅报告单元格的终端上的正确位置。 （#4750、#3675、#5017、#4971）
  • 关闭 Kitty 图形会使窗格停止广告图像支持，因此应用程序会退回到文本。 （＃4978，＃4979）
  • 打字显示得更快，尤其是在 PowerShell 中。 （#4884，#5149，感谢@JJLiebig）
  • 大会话在繁忙的代理和空闲 shell 上使用较少的 CPU，隐藏窗格使用较少的内存，Windows 窗格需要较少的线程。 （#4506、#5083、#4845、#4847、#4849、#4850、#4873、#5085、#5091，感谢@JJLiebig）
  • 新的工作区、选项卡和拆分以正确的大小启动它们的外壳，而不是借用另一个窗格的大小。 （＃4419，＃4873）
  • 不再每秒联系转发的 SSH 代理，这最终可能会破坏 SSH 和 Git 身份验证。 （＃4931，＃4962）
  • 远程计算机上的侧边栏宽度、折叠组和代理排序在重新连接后仍然有效。更换机器时快速切换工作空间不再被取消。 （#4364、#5019、#4536、#5061，感谢@minatoaquaMK2 和@JJLiebig）
  • 当代理列表有滚动条时，侧边栏折叠按钮保持 clickable。 （＃4692，＃4734，感谢@minatoaquaMK2）
  • 欢迎屏幕显示您配置的前缀。 （＃4745，＃4747，谢谢@JJLiebig）
  • Ctrl+[ 离开工作区导航。 （＃1431，＃2340，谢谢@qaz74107410）
  • 使用 + 的键绑定可以在配置重新加载后继续存在，并且 / 在需要 Shift 的布局上打开“转到搜索”。 （#4960、#4963、#4983、#5090，感谢@minatoaquaMK2）
  • 从 Windows 上的 WezTerm 粘贴到远程窗格中不再键入编码的关键数据。复制不再添加重复的 clipboard 历史条目，并且关闭窗格不再挂在待处理的 Enter 上。 （#4725、#4730、#4709、#4872，感谢@JJLiebig）
  • 通过 Scoop 或 32 位包装器启动的 Windows shell 将其工作目录保留在新选项卡中以及重新启动后。 （#4472、#4749、#5062，感谢@JJLiebig）
  • Windows ARM64 计算机可以通过 x64 构建尽最大努力用作远程主机。 (#4752)
  • 当使用 --no-daemon 启动时，Codex 报告已完成集成，其启动更新屏幕显示为已阻止，并且在更多情况下可以识别 Codex 和 Pi 状态。 （#4507、#4811、#4756、#5174，感谢@JJLiebig）
  • 反重力许可、问题和工作区-trust 对话框显示为已阻止，其思维旋转器显示为工作。 （＃3871，＃3419，＃3530，＃4959）
  • Hermes 通过其 Python 安装程序开始被识别，安装或删除其集成可以保持您的 YAML 插件列表完整。 （#4910、#4909、#4911、#4984，感谢@minatoaquaMK2）
  • 在 macOS 上，pane run 和 agent start 对于仍在启动的 shell 来说会拒绝太长的命令，而不是默默地切断它们。 （#4950，#4988，感谢@minatoaquaMK2）

已删除

  • 实验性的 HERDR_WINDOWS_INPUT_BACKEND=crossterm 设置消失了。 Windows 始终使用其本机控制台输入。 (#5017)
