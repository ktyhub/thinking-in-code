jadx v1.5.4

修订 发布时间2026年2月13日 来源skylot/jadx 英文原文

jadx v1.5.4

主要特点

CLI：

  • 实现配置文件加载和保存（#1731）

图形用户界面：

  • 通过 UI 缩放更改字体大小，使用 FlatLaf 字体包
  • 使用支持 CJK 的 FontUtils.getCompositeFont() (PR #2751)

插件：

  • 脚本插件现在是外部的，不包含在发行包中。检查 jadx-script-kotlin 了解安装详细信息。
  • 支持“.apks”文件（PR #2647）
  • 允许使用 .zip 作为插件工件（里面有 jars）
  • 向插件 github 项目报告插件异常
