jadx v1.5.2

主要特点

核心：

  • 自定义 zip 阅读器实施以防止篡改
  • 添加gradle导出模板，支持android app/lib和简单java
  • 对 DEX v41 的初步支持 (#2128)

图形用户界面：

  • 添加带有选项的导出对话框（PR #2378）
  • 树结构使用搜索（PR #2498）
  • 从 UI 主题添加动态代码编辑器主题（PR #2471）
  • 添加预览选项卡功能（PR #2474）
  • 新的 HexViewer（PR #2469）

插件：

  • 添加 APKM 支持（PR #2379）
  • 通过 SMAP 解析和使用 Kotlin SourceDebugExtension 来重命名类和包 (PR #2389)

API：

  • 将“卸载”方法添加到 JadxPlugin (#2463)
  • 为树节点添加弹出菜单条目的方法 (#2412)
  • 添加按名称获取 jadx-gui 图标的方法
  • 添加打开使用对话框的方法
