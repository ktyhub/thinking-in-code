jadx v1.5.3

修订 发布时间2025年9月8日 来源skylot/jadx 英文原文

jadx v1.5.3

特点

  • [aab] 增强 AAB 解析（PR #2557）
  • [gui] 用于搜索文本或二进制资源的新搜索选项（PR #2526）
  • [gui] 允许查看和编辑输入 smali 文件
  • [导出] 使用清单中的 compileSdkVersion，将 AGP 更新为 8.10.1，以及其他改进（PR #2528）

错误修复

  • 正确加载纯文本 XML 文件（PR #2537）
  • 负数的正确十六进制格式 (#2531)
  • 仅在 x86-64 上使用“dev.dirs”JNI 实现 (#2578)
  • 生成 CFG 时使用正确的换行符（PR #2592）
  • [cli] 改善 jadx-cli 中的内存使用情况 (#2524)
  • [cli] 添加缺少的 ‘-XX:+IgnoreUnrecognizedVMOptions’ JVM 标志 (#2554)
  • [gui] 搜索对话框中换行布局重绘问题的解决方法（PR #2521）
  • [gui] 删除 Frida 片段的重复类（PR #2525）
  • [gui] 在 Frida 脚本中使用 var 而不是 let 作为类变量 (PR #2527)
  • [gui] 防止 MethodSearchProvider 中的 IndexOutOfBoundsException (PR #2542)
  • [gui] 如果项目未加载，则禁用调试器操作 (#2547)
  • [gui] 较小的 UI 修复（PR #2549）
  • [gui] 解决代码区域关闭的 NPE
  • [gui] 修复 copyAllSearchResults 中的 NullPointerException (#2580) (PR #2581)
  • [gui] 各种选项卡相关修复（PR #2595）
  • [zip] 允许加载条目中具有重复名称的 zip
  • [gui] 改进菜单图标，例如“在树中选择”和“转到 AndroidManifest.xml”按钮（PR #2543）
  • [导出] 在 AndroidStudio 中禁用 targetSDKVersion 检查（PR #2533）
  • [导出] 在 #2533 中添加缺失的 ExpiringTargetSdkVersion (PR #2538)

完整 Changelog：https://github.com/skylot/jadx/compare/v1.5.2…v1.5.3
