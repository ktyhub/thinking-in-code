paperclip v2026.1005.0

纸clip v2026.1005.0

发布时间：2026-10-05

Paperclip v2026.1005.0 包含 179 次提交，从 2026.1002.0-beta.0 升级。标题是代理携带更多内容：Grok Build 在本机运行器上运行，代理在任务之间保存自己的文件，公司技能从 GitHub 存储库同步，浏览器使用云为代理提供了一个实时浏览器，人们可以观看并接管任务。围绕这些：大多数连接器现在设置在一个 click 中，默认情况下打开 MCP 聚合器，Slack 对话在板和线程之间往返，代理聊天拥有自己的导航并手动完成工作返回对话，任务编辑器为每条消息选择模型和工作量。在下面，长可靠性传递强化了本机运行器、沙箱传输和心跳调度程序，包括修复因永久拒绝的排队运行而导致的服务器崩溃循环。

重大变更

  • 删除了操作员 UI 片段注入。 PAPERCLIP_CLOUD_UI_SNIPPET 和 PAPERCLIP_CLOUD_UI_SNIPPET_B64 设置不再将 HTML 注入静态或开发页面。依赖它们的运营商应该在升级之前将集成转移到插件 UI 贡献中。 (#13789)
  • 键盘快捷键始终打开，并且它们的设置消失了。 实例范围的常规切换和每用户配置文件首选项以及 GET/PATCH /api/auth/preferences 路由都被删除； PATCH /api/instance/settings/general 不再接受 keyboardShortcuts。现在每个登录用户都启用了快捷方式。 （[#14141]（https://github.com/paperclipai/paperclip/pull/14141），[#14643]（https://github.com/paperclipai/paperclip/pull/14643））
  • @-提及代理不再启动运行。 任务注释中的提及将保留为受让人的上下文；只有明确的分配和审查请求才开始工作。使用提及将第二个代理拉到任务上的工作流程必须改为分配或请求审核。 (#14577)

亮点

  • Grok Build 在本机运行器上 — Grok Build 通过 ACP 加入 Paperclip Runner，用于本地和 Daytona 执行，具有单独的订阅登录和 API 密钥凭证路径和受管理工具（#13882）；它在公共安装中附带沙箱拥有的二进制文件，而不是在安装时下载（#14024）。共享线束运行时移至 Codex 0.156.0、Claude Agent SDK 0.3.280 和 OpenCode 1.18.32 (#13838)，模型目录和推理控件在 Claude、Codex、Grok、Gemini、Cursor、Kimi 和 OpenCode 适配器上刷新(#13829)，远程本机 Codex 接受来自 0.149.0 的兼容版本，而不是一个确切的引脚 (#13853)。
  • 代理保留自己的文件 — 代理的目录（AGENTS.md 及其支持文件）现在在任务和会话中持续存在，并与指令编辑器共享；并发运行仅应用它们更改的文件，并且新的保存不再创建修订历史记录（#14420），在具有冲突预检的新纯目录同步传输（#14416）之上。温暖的本机 Codex 会话通过在每轮后仅对更改的文件进行检查点来保存托管文件收集（#14735）。
  • 从 GitHub 同步的技能 — 技能获得“来源”选项卡：通过现有 GitHub 连接选择存储库，选择要导入的技能文件夹，并按需刷新。安装的快照意味着代理永远不会在运行中获取 GitHub，并且刷新失败会保留最后一个好的版本（#14713）。
  • 浏览器使用云，实时参与任务 — 新的浏览器使用云连接器为代理提供了受管理的浏览器自动化，任务显示交互式浏览器选项卡，人们可以在其中跟踪、接管页面并在运行完成后保留浏览器，并根据运行记录成本 (#14627)。
  • 在一台 click 中设置连接 — 连接器设置会折叠到一个屏幕，其中显示其默认设置，并将其余部分隐藏在“更改”和“权限”选项卡后面（#14811）。 Zapier、Arcade、Composio Connect 和 Executor MCP 聚合器默认处于打开状态，并删除了实验切换 (#13964)，并且可以从内联任务卡 (#13879) 进行配置。连接搜索更喜欢本机应用程序，要求用户在设置之前选择外部提供商 (#13941)，并理解自然语言查询 (#14725)。目录中的新增功能：Fireflies 具有摘要就绪例程 (#13890)、默认关闭 enableMemoryConnectors 设置背后的五个实验性内存提供程序（Mem0、Zep、Supermemory、Cognee、Honcho），以及交付给远程本机 Codex 的指定 MCP 工具 (#13942) 和 GitHub 代码审查机器人它自己的卡与 GitHub 工具分开（#14750）。个人粘贴的凭据在设置、运行状况检查和调用时以相同的方式进行验证，并且新连接请求其操作所需的写入范围（#14739）。
  • Slack 是双向的 — 在板上输入的回复到达链接的 Slack 线程并恢复相同的对话，分配的代理在普通任务和计划例程期间获取其 Slack 工具 (#13920)。 Slack 起源的任务使用受管理的工具来阅读周围的讨论、创建后续内容并通过邀请机器人进行协作 (#13828)，并且已回答的对话将停留在“空闲”状态，而不是徘徊在“进行中”(#13809)。
  • 代理聊天成长 — 辅助聊天侧边栏和登陆页面为对话提供了自己的家（#14706）；从聊天委派的任务将其完成情况持久地返回给它（#14408）；在聊天中输入明确的批准即可解决待处理的卡，未回答的问题将进入历史记录，稍后可以回答（#14613）；并且在其本机工作线程丢失后聊天继续（#13813）。
  • 选择运行的编辑器 - 任务编辑器获得每条消息的模型和工作量选择器，该模型和工作量选择器跟随所选代理，保持挂起的卡片在其上方可见，并在移动设备上工作（#14322）；工作选项与每个适配器实际执行的内容相匹配，包括本机运行器上的 Codex（#14568、#14576）。可以仅根据提示创建任务，并由指定的代理为其命名（#14761）。工件获得带有预览的丰富卡片 (#14469)、带有全行链接的图像和视频库 (#13825)，以及在任务选项卡中打开的 Markdown 和文本附件，其中包含渲染、原始和下载视图 (#14297)。
  • 受管理的 API 工具，默认启用 — 无需环境变量即可启用本机运行程序的 search_api 和 call_api 工具 (#14186)；大型 API 响应流到磁盘最多 1 GiB，并且保存的文本在有界页面中可读（#14301）；当指定的应用程序目录使工具合约超出其限制时，代理仍然可以通过搜索和调用来访问这些工具（#14218）。

修复

  • 本机运行器和会话 - 工具结果在关闭和重新启动后仍然存在，而不是记录错误故障（#14734）；失败的热会话在沙箱停止之前退出（#14747），并且恢复的清理遵循运行的最终结果（#14767）；将任务切换到热生命周期会获取可重用的租约（#14187）； OpenCode 事件流在回合中保持打开状态 (#14582) 并交付其关闭解决方案 (#14668)； Codex 帐户通知不再中止回合（#13902）； Claude 和 Codex 配额耗尽被分类为适当的退避（#13831、#13945）； ACP 终端故障会保留其经过编辑的提供商诊断信息 (#14573)，并且身份防护会命名失败的检查 (#14481)；本地日志读取限制为 256 MiB（#14711）；已接受结果的待定最终确定不受过时锁扫描的影响（#14219）；适配器在工作区恢复之前暴露经过验证的提供程序停止（#14311）；热会话在托管 GitHub 访问下继续运行（#13815）；遇到提供商身份验证失败的运行会在任务中提供内联连接卡，以便用户可以修复并继续 (#14629)。
  • 沙箱和工作区 - Daytona 命令在日志套接字关闭后保持活动状态 (#14799)，在恢复租用时确认容器丢失 (1f3ff75d)，清除失败的分配 (#13979)，并且提供程序获取超时遵循驱动程序的默认值（[#14097]（https://github.com/paperclipai/paperclip/pull/14097））。在网关 502 后重试 ACP 输入传送，无需重复输入（#14485），过大的启动有效负载和重复的唤醒上下文不再因 E2BIG 失败（#13793、#13891），进程代理在远程退出后关闭(#13777)，并保留辅助存储库中的相对符号链接(#13953)。工作区导出完成并安全恢复 (#14402)，恢复失败保留适配器的结果并记录失败的内容 (#14035、#14064)，大型 Git 快照流通过磁盘清单，而不是达到 1 MiB 输出限制（#14194、#14253），准备情况检查接受更大的状态输出（#14414），后台扫描停止刷新 Git 索引（#14666），部分任务覆盖保留项目设置命令(#14502)，并且无存储库的低 trust 任务获得私有目录(#14766)。
  • 调度程序和恢复 — 其声明被永久拒绝的排队运行将被取消，而不是使服务器崩溃循环（#14738）；在耗尽期间到达的唤醒保持排队并且中断的纠正运行会得到短暂重试（[#14028]（https://github.com/paperclipai/paperclip/pull/14028））；运行已耗尽重试预算的问题将升级为可见的阻塞状态，而不是永远跳过（[#14046](https://github.com/paperclipai/paperclip/pull/14046)）；延续和重试预算使用持久状态（[#13888](https://github.com/paperclipai/paperclip/pull/13888)）；通过排队运行以原子方式声明任务所有权（[#13973](https://github.com/paperclipai/paperclip/pull/13973)）；过时的延续在分派之前被取消（[#13761](https://github.com/paperclipai/paperclip/pull/13761)）；仍然列出阻塞工作的状态回复使任务继续进行（[#14626](https://github.com/paperclipai/paperclip/pull/14626)）；已完成和已取消的任务使受让人保持释放状态（[#14561](https://github.com/paperclipai/paperclip/pull/14561)）；交互延续保持在其任务范围内 (ded156a9)，并且派生并验证问题接收者 (#14742)；失去审阅路径的 Slack 和 Discord 源任务将在其消息绑定完好无损的情况下进行恢复，而不是使恢复授权检查失败 (#13818)；远程 Grok 在排队消息继续之前运行停止 (#14100)；运行身份锁不再因审核插入而死锁（#14478）；并且不再重播不明确的数据库断开连接（#14773）。
  • 连接和应用程序 — OAuth 登录挑战和重新连接状态返回 422，而不是报告为崩溃（#13786、#13794）； MCP OAuth 设置解释了同意失败或取消的情况 (#13855)；禁用的 Slack MCP 应用程序获取可操作的设置说明 (a7d3b17a)； Broker 和 AgentMail 故障保留列入许可名单的原因代码（#14098、#14768）； Google Chat 以及文档、表格、幻灯片和日历配置文件请求的范围较少（#13820、#14740）；工作产品验证其执行工作空间引用（#14063）；格式错误的 CLI 身份验证挑战 ID 返回 400 (#14095)。
  • Board UI — 主板在服务器重新启动期间恢复，并显示连接消息并重试，保持安装打开的编辑器 (#14560)，并在应用程序在 React 启动之前失败时提供重试屏幕 (#13970)。代码突出显示不再因 Lezer 版本不匹配而崩溃（a3749aac），破坏性确认按钮在浅色主题中可读（#14328），移动选择器保持在键盘上方的视图中并通过触摸滚动（#14022， #14249、#14250、#14599)，较新的草稿在收据清理中幸存下来(#14332)，其他用户的失败运行不属于我的(#14572)， “需要恢复”与“正在进行恢复”（#14326）不同，当恢复被阻止时，不再出现误导性的重试（#13775），新工件在不打开面板的情况下注册选项卡（#14193），任务面板显示祖先(#13823)，并且通过并行服务器读取，任务内容会更快出现(#14727)。另外：属性图标与头像对齐（#13319），跑步者评论与回复对齐（#14716），项目保存指示器堆叠在标签下方（#14765），存档公司导航离开（#13846），实验设置按字母顺序排列，隐藏空组（#13905），光标适配器通过跟踪通知选择真正的错误（#14636）。
  • 可观察性 - 浏览器错误携带 SENTRY_ENVIRONMENT (#13784) 和有界组件上下文 (#13904)；运行错误与后来的异常隔离，并且运行时功能标头被编辑（#13826）；和运行失败报告保留退出详细信息、堆栈、原因、运行时活动和恢复分类（#14575、#14585、#14665、#14639、#14787）。

改进

  • 帐户菜单删除标题链接的个人资料行并获得邀请快捷方式（#14480）；插件可以提供组织切换器（#13832、#13854）； PAPERCLIP_HIDDEN_SETTINGS 接受带有命名异常的通配符，因此新的实验标志会自动隐藏 (#13980)，并且 workspaces.isolation 键会隐藏隔离控件 (#13907)；本地运行器为即将推出的 Cursor、GitHub Copilot 和 Pi 提供商获得共享的丰富 ACP 传输基础（#14430）；本机代理可以通过受管理的 hire_agent 操作雇用队友，该操作从封闭的白名单继承调用者的运行时配置（#13852）；协调技能不再告诉代理通过经理升级，而是询问可以采取行动的人员（#14188）；工作树种子源失败解释了支持的设置（#14795）；当 Google OAuth 验证处于待处理状态时，Google Workspace 连接器会暂时从“连接”页面隐藏，保存的连接和运行时访问权限不会受到影响 (#14774)；并且使用当前线束、指南链接和 npx-first 快速入门（#14741、#14744）刷新自述文件。

升级指南

  • 迁移 0284–0293 在升级时运行：0284 添加并 0289 删除每用户 keyboard_shortcuts 列； 0285将assets.byte_size加宽至bigint； 0286增加API响应捕获预留； 0287 添加了代理指令头、修订版和持久代理文件的工作副本； 0288增加了聊天完成交付和任务交接； 0290 添加了浏览器使用云会话、运行和浏览器； 0291–0292 添加公司技能源和条目，0291 还采用从 github.com 导入的现有技能（每个存储库和跟踪引用一个源，每个技能一个条目，并且 legacySkillSourceId / skillSourcePath 标记到每个技能的元数据中；从 GitHub Enterprise 主机导入的技能、捆绑技能和目录技能保持原样，并且没有提供者请求或发生内容重写）； 0293 增加了 issues.title_needs_generation。
  • 操作员 UI 片段已删除 (#13789)：PAPERCLIP_CLOUD_UI_SNIPPET 和 PAPERCLIP_CLOUD_UI_SNIPPET_B64 被忽略。在升级之前将集成移至插件 UI 贡献。
  • 删除键盘快捷键设置 (#14643)：删除任何调用 /api/auth/preferences 或将 keyboardShortcuts 发送到常规设置路由的自动化。
  • 代理提到不再调度 (#14577)：使用分配或审核请求让另一个代理执行任务。
  • 新默认值：除非将 PAPERCLIP_RUNNER_API_TOOLS_ENABLED 设置为 true 以外的任何值，否则将启用本机运行器的 API 工具； PAPERCLIP_RUNNER_API_TOOLS_COMPANY_IDS 仍然缩小它们的范围（#14186）。 MCP 聚合器无需以前的 enableMcpAggregators 标志即可使用 (#13964)。
  • 新环境变量，全部可选：PAPERCLIP_RUNNER_API_COMPANY_CAPTURE_MAX_BYTES 限制每个公司捕获的 API 响应字节（默认 20 GiB，最小 1 GiB；#14301）； PAPERCLIP_WORKSPACE_GIT_SNAPSHOT_TIMEOUT_MS 限制工作区快照时间（默认 30 分钟，最长 24 小时），PAPERCLIP_WORKSPACE_MANIFEST_MIN_FREE_BYTES 设置快照清单的可用磁盘保留（默认 256 MiB，最小 64 MiB；#14253）。 Codex ACP 运行接受 CODEX_API_KEY 作为 OPENAI_API_KEY 的替代方案 (#14322)。
  • 线束销钉移动至 Codex 0.156.0、Claude Agent SDK 0.3.280 和 OpenCode 1.18.32 (#13838)；共享安装应刷新其提供商 CLI 以匹配。
  • 无需执行其他配置或 API 更改。
