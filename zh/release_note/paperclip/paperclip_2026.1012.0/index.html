paperclip v2026.1012.0

发布时间：2026-10-12

Paperclip v2026.1012.0 进行了 130 次提交，从 2026.1006.0-beta.0 升级。标题是外部助理现在可以加入您的团队：Claude Code、Codex、OpenCode 和任何 MCP client 都可以作为登录人员连接到 Paperclip、审查工作和委派任务，所有这些都在实验设置后面进行。围绕这一点：聊天通过对话旁边的每个代理的任务和工件引导导航，连接目录拉入您已在 Composio 和 Arcade 中链接的帐户，连接携带自动到达您的代理的使用说明，Claude Sonnet 5.5 和 GPT-6.1 Sol 带着更新的安全带到达，代理可以安全地更新公司技能。在底层，Codex 可以在服务器重新启动和模型容量错误的情况下运行，工作区恢复锁会转移到崩溃安全的 SQLite 文件锁，并且默认代理指令会缩小到以前大小的一小部分。

重大变更

  • 工作区恢复锁更改协议；在升级之前停止每个旧进程。 恢复锁和代理文件收集锁现在是 <instance root>/locks/directory-merge/ 下操作系统支持的 SQLite 文件锁，当进程崩溃时由内核释放。旧版本和新版本不得同时写入同一实例根目录：在升级或回滚之前耗尽并停止所有旧服务器和工作进程（包括其他主机或容器），然后将任何剩余的旧 <hash>.lock/ 目录移动到临时位置。切勿删除或移动新的 .lock.sqlite 文件。参见 doc/workspace-restore-locks.md。 (#14869)
  • 存储的工具授权按书面形式强制执行。 scope.allow 列表与工具、连接或应用程序不匹配的授权不再属于更广泛的策略；具有未知选择器或格式错误的限制的授予现在拒绝访问。如果代理丢失了之前使用的工具，请在升级后查看自定义授权。 (#14915)

亮点

  • 助理通过 MCP 加入您的团队 — Connections 中的新“助理连接 (MCP)”卡可让 Claude Code、Codex、OpenCode 和通用 MCP clients 通过浏览器 OAuth 或设备代码同意连接到 Paperclip，并充当登录用户：读取和搜索任务、创建和委派工作、留下人工评论、阅读文档和可交付成果，并通过签名事件 Webhook 跟踪结果（[#14846]（https://github.com/paperclipai/paperclip/pull/14846））。同意显示 client 和组织，可以选择退出写入访问，可以将请求固定到一家公司，并且 paperclip mcp CLI 设备登录桥接本地 stdio clients；默认情况下，它在“设置”→“实验”→“辅助连接 (MCP)”后处于关闭状态，并且需要 HTTPS PAPERCLIP_PUBLIC_URL (#14933)。
  • 聊天引领 — 在简化的 UI（默认 shell）中启用代理聊天后，聊天位于工作导航中的第一行，聊天栏列出了每个符合条件的代理，侧面板显示该代理的最近任务和工件；新的实验性“组合收件箱 + 任务列表”设置将收件箱折叠到任务中作为视图（#15100）。关闭“简化的 UI”的实例会保留旧版导航，并且不会看到这些更改。聊天条目会重新打开您上次访问的对话 (#14848)，聊天标题会显示客服人员的头像 (#14726)。
  • 每个帐户一个目录 — Connections Apps 目录发现已在 Composio、Arcade 和支持的 Executor 网关中连接到上游的帐户，并将它们与本机帐户分组在一张应用程序卡下，并具有源芯片、搜索和分页 (#15254)。 AgentMail 是与代理聊天中内联设置卡的默认连接 (#14772)，Neon 通过 OAuth 或 API 键登录加入目录 (#14980)，Asana 再次使用默认的“使用 Asana 登录”(#14756)，AI 帐户获得“检查”使用”操作读取 Codex、Claude、Grok 和 OpenRouter 的当前提供商限制 (#14936)。
  • 连接携带代理指令 — 连接可以保存可编辑的使用指令，这些指令将通过本机运行器、旧适配器和 HTTP/进程合约传递给每个授权代理。 Honcho、Mem0、Zep、Supermemory 和 Cognee 默认情况下，编辑器出现在设置和权限面板中，代理指令显示只读“来自连接”部分 (#15216)。
  • 新模型，更新的安全带 — Claude Sonnet 5.5 可以为 Claude Code 代理选择，从低到最大工作量，合格的 Claude 运行时移动到 Claude Code 2.1.286 (#14993)； GPT-6.1 Sol 以快速模式和超级努力加入 Codex 适配器，Bedrock 获得 Sonnet 5.5，共享引脚移至 Codex 0.160.0 和 OpenCode 1.18.34 (#14942)。 Claude 和 Codex 模型菜单现在以与 Claude 和 ChatGPT 应用程序相同的顺序列出模型（#14917、#14918）。
  • 代理维护公司技能 - 本地运行代理获得 update_skill 工具，该工具通过版本检查和安全重试重写公司技能，记录在版本历史记录和审核日志中；技能文件 API 获得可选的 expectedVersionId 和 `idempotencyKey
