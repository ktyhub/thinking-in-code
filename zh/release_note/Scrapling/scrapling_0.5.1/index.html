Scrapling v0.5.1

修订 发布时间2026年11月4日 来源D4Vinci/Scrapling 英文原文

Scrapling v0.5.1

小版本提升，大浏览器升级！此版本允许 AI 代理跟踪运动并控制拖放，添加专用的远程浏览器会话，并修复解析、蜘蛛、代理和 shell 🚀

通过此更新，我们扩展了当前人工智能模型的限制 🔥

[!注意] 在 X 上关注我们，获取日常提示和技巧

[!警告] 此版本引入了对远程浏览器连接的重大更改。连接到远程浏览器现在需要新的浏览器会话类。更新前请检查远程会话迁移指南。

🚀 新事物和生活质量的变化

  • AI 代理现在可以跟随运动并更好地控制鼠标（查看 文档）：

    • 观看动态页面：录制短视频并将其作为带有时间戳的帧序列进行共享，以帮助代理了解动画、移动控件以及单个屏幕截图可能错过的更改。将此与现有的连锁操作能力相结合！
    • 拖、检查、调整和放下：按住鼠标按钮，移动项目或滑块，在按住鼠标的同时检查页面，然后调整并释放。支持左、右、中按钮。
    • 重用登录的远程浏览器或从单独的浏览器上下文开始，以便代理可以为作业选择正确的会话。
    • 在工具描述上花费更少的代币，文本更短，重复指导更少。

  • 专用远程浏览器会话，可控制登录重用。 RemoteSession 和 AsyncRemoteSession 通过 HTTP 或 WebSocket CDP 端点连接到现有的 Chromium 浏览器。它们支持常见的隐形会话功能，包括 Cloudflare 解决。这两个类也可以在交互式 shell 中使用。 （查看文档）

    from scrapling.fetchers import RemoteSession

with RemoteSession(cdp_url="http://localhost:9222", new_context=False) as session:
    page = session.fetch("https://example.com")
    • new_context=False 重用浏览器现有的默认上下文和登录状态。当 Scrapling 断开连接时，其上下文设置将继续使用，并且其现有选项卡将保持打开状态。
    • 默认值 new_context=True 创建一个单独的上下文并在会话结束时将其关闭。 Scrapling 在任一模式下都使用自己的选项卡。

  • 使用 log_file_encoding="utf-8" 或其他编码选择蜘蛛的日志文件编码。默认值 None 保留 Python 的默认编码。 （查看文档）

🐛 错误修复

  • XPath 表达式现在可以正确返回其值，包括 string()、count() 和 boolean()。空字符串、零和 false 仍然可以通过 #552 中的 @jayhemnani9910 的常用选择器 API 获得。

  • 修复了没有根元素的 HTML 解析，包括仅空白、仅注释和仅文档类型输入，由 @rushilnimbalker250 在 #536 中完成。

  • 当引用没有可比较的属性时修复了 find_similar(similarity_threshold=0)，由 @Master-Norna 在 #539 中完成。

  • 修复了并发请求到达同一域时重复的 robots.txt 获取，由 @RayenMlayeh 在 #538 中编写。

  • 修复了并发开发缓存写入期间的临时文件冲突，由 @xixihaha-ha 在 #546 中编写。

  • 格式错误的链接不再停止提取同一页面上的有效链接，作者：#548 中的 @dajiao Huang。

  • 修复了使用回车符作为行分隔符的 CSV 提要，同时保留带引号的字段内的换行符，由 #551 中的 @xunguangzlj-cloud 实现。

  • 截断或损坏的 gzip 提要现在遵循站点地图、XML 提要和 CSV 提要蜘蛛中的正常警告和跳过路径，作者为 #522 中的 @cangen185-sudo。

  • 使用百分比编码的用户名和密码修复了浏览器代理身份验证，由 @kevin9327 在 #545 中编写。

  • 改进了会话设置或上下文关闭失败时的浏览器清理，释放拥有的资源，同时保持借用的远程上下文打开。

  • 停止 shell 和 HTTP CLI cookie 解析，删除带有空格或引号的浏览器 cookie 值，包括它们后面的 cookie，作者为 #541 中的 @waw666waw666。修复#540。

  • Curl 转换现在接受 -L 和 --location，保留现有的重定向行为，由 @jayhemnani9910 在 #554 中编写。

  • 修复了 scrapling extract fetch --ai-targeted 未按照记录启用广告拦截的问题，由 @postoso 在 #527 中完成。

🙏 特别感谢社区的持续测试和反馈
