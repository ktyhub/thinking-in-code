Scrapling v0.3.8

Scrapling v0.3.8

包含许多重要更改的新更新

🚀 新事物和生活质量的变化

  • 对于所有基于浏览器的获取器：如果您使用 network_idle ，那些从未完成加载请求的网站现在不会使代码崩溃。
  • 基于浏览器的获取器中收集/检查页面内容的逻辑已更改，以使浏览器现在在 Windows 系统（如 Linux/MacOS）上更加稳定（所有这些行为差异是因为 Playwright 在 Windows 系统上的不同实现）。
  • 重构了所有验证逻辑，这使得所有基于浏览器的获取器完成的所有请求速度提高了 8-15%
  • DynamicFetcher 及其会话中添加了一个名为 extra_flags 的新选项，允许用户在启动浏览器时向现有标记添加自定义 Chrome 标记。
  • 当使用 page_action 时，恢复了用于捕获响应的路由逻辑（在上一个版本中更改）以使用旧的路由版本。添加此功能是为了收集页面内容的最新版本，以防 page_action 在未发出请求的情况下更改页面内容。 （感谢 @gembleman 在 #100 和 #102 中指出它）

🐛 错误修复

  • 修复了 DynamicSession 的 async_fetch 中 load_dom 中的拼写错误
  • 修复了 Cloudflare 求解器的一个问题，该问题使求解器永远等待嵌入式验证码，而该验证码在求解后不会消失。现在它将等待验证码消失 30 秒，然后假设它是不会消失的类型（修复#100）

🔨 其他

  • 现在，Docker 映像会自动推送到 Dockerhub 和 GitHub 的容器注册表，以方便用户。
  • 添加了新文档页面 以展示如何将 Scrapeless 浏览器与 Scrapling 结合使用。 🙏 特别感谢我们的Discord 社区 的持续测试和反馈

向我们最大的赞助商致敬
