Scrapling v0.4.3

Scrapling v0.4.3

包含许多重要更改的新更新🎉

🚀 新事物和生活质量的变化

  • 添加了一个新的 MCP 工具来打开持久的正常/隐形浏览器，以继续将其与其他工具一起使用，并添加另一个新工具来关闭它。 （示例）
  • 添加了新的 MCP 工具以列出所有现有的浏览器会话。旨在与新工具一起使用。
  • 向浏览器会话添加了一个新选项，以自动收集请求期间发生的所有后台请求（解决 #159）[示例]。
  • 添加了新的清理程序，通过删除隐藏/不可见内容来保护 MCP 服务器免受常见的提示注入攻击。
  • 在 Web Scraping 命令中添加了一个名为 --ai-targeted 的新命令行选项，以使内容针对 AI 并安全抵御 MCP 服务器等常见的提示注入攻击。
  • 向浏览器会话添加了一个名为 executable_path 的新选项，以允许设置自定义浏览器路径（解决了 #202）
  • 重构 MCP 服务器代码，使其易于维护，并将所有工具统一为异步。
  • 重构 CLI 命令代码易于维护，并缩短了 210 行。

🐛 错误修复

  • 通过 @karesansui-u 在 #201 中修复了在蜘蛛会话中重试时保留 HTTP 方法的问题
  • 在#197中@haosenwang1018和@D4Vinci添加了获取页面内容的最大重试限制以防止无限循环
  • 在 #196 中 @haosenwang1018 将 _restore_from_checkpoint 中的裸 raise 替换为 return False
  • 在 Texthandler 中将 get_all 替换为 getall 以匹配选择器类别。

覆盖率/测试改进

  • 在 #192 中添加了 @Bortlesboat 的 _normalize_credentials 边缘情况覆盖测试
  • 在 #193 中添加了 @haosenwang1018 的保存/检索往返和核心存储覆盖率测试
  • 在 #194 中添加了 @haosenwang1018 对 TextHandler 正则表达式路径和 TextHandlers.re() 的覆盖
  • 由 @awanawana 在 #200 中添加了 filter、iterancestors 和 find_similar 的边缘情况测试

特工技能提升

  • 修复了 #204 中 @yetval 的技能参考中损坏的降价链接
  • 改进了技能结构，通过Clawhub验证更容易被接受。
  • 当通过命令行命令执行 scraping 时，强制技能使用 --ai-targeted 命令行选项。

文档改进

  • 在 #187 中添加了 @greatsk55 的韩语自述文件翻译
  • 中文和日文自述文件的 CJK 拉丁文间距修复。
  • 修复了旧网站设计中损坏的链接。

🙏 特别感谢社区的持续测试和反馈
