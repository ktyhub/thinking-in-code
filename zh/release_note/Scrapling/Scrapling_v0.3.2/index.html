Scrapling v0.3.2

Release Note 适用于 v0.3.2

🚀 新东西

  • 可选的获取器依赖项：所有获取器现在都是可选依赖项组的一部分，从而减少了核心包的大小。因此，基本 scrapling 模块现在只是解析器，要使用获取器或命令行选项，您必须执行以下操作：pip install "scrapling[fetchers]"。从这里查看详细的安装说明
  • 会话中的每页配置：浏览器获取器的会话类现在支持会话中每页的单独配置。现在，所有获取级别参数都像会话级别参数一样进行验证。有关文档网站的更多详细信息此处
    示例： 
    with StealthySession(headless=True, solve_cloudflare=True) as session:
    page = session.fetch('https://nopecha.com/demo/cloudflare', google_search=False)
  • 改进的基于浏览器的获取器
    • 控制是否等待 JavaScript 执行在页面中完成的新选项（现在默认启用，就像以前一样） 
      with DynamicSession(headless=True, disable_resources=False, network_idle=True) as session:
   page = session.fetch('https://quotes.toscrape.com/', load_dom=False)
    • 隐身模式现在在 DynamicFetcher 及其会话类别中更加可靠。
    • DynamicFetcher 和 StealthyFetcher 现在使用更少的资源（自动查找并关闭由 Playwright API 中的持久上下文打开的默认选项卡）
    • 修复了基于浏览器的抓取器页面轮换中的一个重要逻辑错误 - 以前的页面现在被新的页面替换。 （轮流重复使用的选项卡可能受到之前使用的设置的污染）
    • StealthyFetcher 及其会话类现在稍快一些 (5%)
  • 增强的 .body 属性：现在按原样返回传递的内容而不进行处理，从而启用文件下载和处理非 HTML 请求。下面是下载照片的示例： 
    from scrapling.fetchers import Fetcher

page = Fetcher.get('https://raw.githubusercontent.com/D4Vinci/Scrapling/main/images/poster.png')
with open(file='poster.png', mode='wb') as f:
   f.write(page.body)

🐛 错误修复

  • 已解决编码问题：修复了某些网站在解析器、mcp 模式和提取命令中发生的多个编码问题（还解决了 #80 和 #81）
  • 更快的解析：由于这里和那里的许多变化，该库现在更快，并且反映在更新的基准中

🔨 其他

  • 更新基准：更新的性能基准，以将当前速度改进与类似库的最新版本进行比较
  • 重构了大量代码，并用更好的实现替换了死代码：更少的代码，更干净的代码，更容易维护
  • 添加了 YouTube 视频：包含 MCP 文档的视频内容。
  • 新问题模板：为无法使用当前模板的用户提供简单的新模板。
  • CI 工作流程优化：当仅更改文档或非代码文件时，测试工作流程现在会跳过运行。
  • 更新了依赖项：将各种依赖项升级到最新版本。
  • 代码风格改进：在所有文件中应用新的 ruff 规则。
  • 预提交挂钩：更新了预提交配置。

🎯 重大变更

  • 从同步 StealthySession 中删除了 max_pages 参数以匹配 DynamicSession（在同步版本中没有意义） 🙏 特别感谢我们的 Discord 社区 的持续测试和反馈
