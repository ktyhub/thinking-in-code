Scrapling v0.2.9

Scrapling v0.2.9

改变了什么

新功能

  1. 引入期待已久的对 Scrapling 的异步支持！现在您有了 Fetcher 的 AsyncFetcher 类版本，StealthyFetcher 和 PlayWrightFetcher 都有一个名为 async_fetch 的新方法，具有相同的选项。
>> from scrapling import StealthyFetcher
>> page = await StealthyFetcher().async_fetch('https://www.browserscan.net/bot-detection')  # the async version of fetch
>> page.status == 200
True
  1. 现在，StealthyFetcher 类在其 fetch 方法中具有 geoip 参数，启用该参数后，该类会自动使用 IP 的经度、纬度、时区、国家/地区和区域设置，然后欺骗 WebRTC IP 地址。它还会根据目标区域中语言使用者的分布来计算和欺骗浏览器的语言。
  2. 在 Fetcher/AsyncFetcher 类中添加了 retries 参数，现在您可以设置 httpx 完成的每个请求的重试次数。
  3. 在 Adaptor 和 Fetchers 中添加了 url_join 方法，该方法采用相对 URL 并将其与当前 URL 连接以生成绝对完整 URL！
  4. 向 Adaptor 和 Fetchers 添加了 keep_cdata 方法，以阻止解析器在需要时删除 cdata。
  5. 现在，Adaptor/Response body 方法会在可能的情况下返回原始 HTML 响应（无需在库中对其进行处理）。
  6. 为 Response 类添加日志记录，因此现在当您使用 Fetchers 时，您将获得一个日志，其中提供有关您收到的响应的信息。 示例： 
    >> from scrapling.defaults import Fetcher
>> Fetcher.get('https://books.toscrape.com/index.html')
[2024-12-16 13:33:36] INFO: Fetched (200) <GET https://books.toscrape.com/index.html> (referer: https://www.google.com/search?q=toscrape)
>>
  7. 现在，在 TextHandler（如 .replace()）上使用所有标准字符串方法将产生另一个 TextHandler。它之前返回的是标准字符串。
  8. 对整个库的速度进行了重大改进，并对 Fetchers 类的整体隐身性进行了改进。
  9. 添加了虚拟函数，例如 extract_first`extract`，它返回与父级相同的结果。添加这些函数只是为了在需要时可以轻松地将代码从 Scrapy/Parsel 复制到 Scrapling，因为这些函数在那里使用！ 11.由于重构了大量代码，并在正确的位置使用了缓存，现在批量请求会有很大的速度提升。

重大变更

  • 现在已放弃对 Python 3.8 的支持。 （主要是因为 Playwright 停止支持它，但无论如何它都是一个有问题的版本）
  • debug 参数已从所有库中删除，现在如果要将库设置为调试，请在导入库后执行此操作： 
    >>> import logging
>>> logging.getLogger("scrapling").setLevel(logging.DEBUG)

错误已被消灭

  1. 现在默认启用 WebGL，因为许多保护措施正在检查它是否已启用。
  2. 文档/自述文件中的一些错误和拼写错误。

生活质量的变化

  1. 所有日志记录现在统一在记录器名称 scrapling 下，以便更轻松、更清晰地进行控制。我们之前使用过根记录器。
  2. 将测试文件夹重组为更清晰的结构，并添加了新功能的测试。所有测试都被重写为更干净的版本，并添加了更多测试以获得更高的覆盖率。
  3. 重构了很大一部分代码，使其更清晰、更易于维护。

所有这些更改都是我之前决定用 0.3 添加的更改的一部分，但决定将它们添加到此处，因为距离下一个版本还需要一段时间。现在下一步是完成详细的文档网站，然后开发 0.3 版本

[!注意] 友情提醒，维护和改进 Scrapling 需要花费大量的时间和精力，尽管这变得越来越困难，但我已经愉快地做了几个月了。所以，如果您喜欢Scrapling并希望它不断改进，您可以通过赞助按钮来支持我。
