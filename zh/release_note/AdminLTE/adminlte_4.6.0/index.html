AdminLTE v4.6.0

小版本 发布时间2026年8月18日 来源ColorlibHQ/AdminLTE 英文原文

AdminLTE v4.6.0

来自 @johnnyq 的两份报告均已修复，第二份报告变成了 AdminLTE 3 调色板缺失的功能。

任何颜色都可以是你的 primary — data-lte-primary (#6107)

Bootstrap 将 $primary 编译到其组件中：.btn-primary 附带 --bs-btn-bg: #0d6efd，而不是 var(--bs-primary)。覆盖令牌会重新绘制实用程序，并将每个按钮、分页、复选框和聚焦环保留为蓝色——这就是为什么选择皮肤看起来是半应用的。

现在，两个颜色表都重新连接这些组件，并将它们指向具有一个属性的调色板颜色：

<html lang="en" data-lte-primary="lightblue">

如果没有该属性，任何内容都不会发生变化，并且它适用于任何容器，因此一个页面可以承载多个主页面。

颜色后面的内容： .btn-primary 和 .btn-outline-primary（悬停、活动和禁用状态的阴影与 Bootstrap 本身的阴影完全相同）、.btn-link、链接和 .link-primary、--bs-primary 代币三重奏、.nav-pills、.pagination、.progress-bar、.list-group-item.active、.dropdown-item.active、 .accordion、.form-control / .form-select 焦点、复选框、收音机、开关、.form-range、--bs-focus-ring-color 以及 AdminLTE 的 .card-primary、.direct-chat-primary 和 .toast-primary — 两种颜色模式，具有 Bootstrap 的暗模式链接色调。

  • Bootstrap 自己的主题颜色也是预设的：data-lte-primary="danger" 不需要调色板颜色。
  • 调色板外的品牌颜色只需--bs-primary；在 Sass 中，$lte-palette-custom: ("brand": #7a5af8) 生成完整的预设，包括阴影和对比度文本。
  • 现在，每个皮肤预设都会命名与其配套的主皮肤，因此在 UI → 颜色 或 主题自定义 上应用 皮肤蓝色 也会重新为按钮着色。两个页面都获得了带有实时预览的选择器。

记录在颜色页面 上。

修复

  • d-print-none 在侧边栏和应用程序包装上没有执行任何操作 (#6106)。 4.0.0 的打印布局修复在这两个元素上设置了 display: grid !important / display: block !important，并且后来在级联中击败了 Bootstrap 的 .d-print-none。现在，这两个规则的范围都为 :not(.d-print-none) - 默认情况下仍然应用打印布局，并且显示实用程序在页面要求的地方获胜。
  • 跳过链接在悬停时不可见。 .skip-link:hover 绘制了 var(--bs-primary-emphasis)，Bootstrap 未定义该 var(--bs-primary-emphasis)，因此背景计算为透明并在页面背景上留下白色文本。

维护

两个调色板表中的计算颜色均以十六进制形式发出，而不是 Sass 的 rgb(5.647%, 40.784%, 39.216%)（cleancss 仅将值保留在自定义属性内），这支付了大部分新功能的费用：adminlte-colors.css 是 7.8 kB gzipped，adminlte-colors-v3.css 9.1 kB。 adminlte.css 不变。

安装

npm install admin-lte@4.6.0
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/admin-lte@4.6.0/dist/css/adminlte.min.css" />
<!-- optional: the extended palette, or adminlte-colors-v3.min.css for the AdminLTE 3 originals -->
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/admin-lte@4.6.0/dist/css/adminlte-colors.min.css" />
<script src="https://cdn.jsdelivr.net/npm/admin-lte@4.6.0/dist/js/adminlte.min.js"></script>
