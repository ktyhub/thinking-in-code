AdminLTE v4.7.0

AdminLTE v4.7.0

4.6.0 的打印后续，来自 @johnnyq 再次 (#6108) - 加上一个打印错误，结果比报告的更糟糕。

将页面打印为文档 — data-lte-print="plain"

AdminLTE 的打印样式表中的两条规则无条件地重新设计内容：每个外部链接的目标都打印在其后面，并且按钮以黑色勾勒。两者都是 HTML5 样板约定，在打印网页副本时是明智的，但对于发送给客户的发票、报价或工作订单来说是错误的，其中 Pay online (https://pay.example.com/inv/12345?token=…) 不是任何人想要的纸质内容。

<html lang="en" data-lte-print="plain">

这会关闭两者。文本仍然以白底黑字打印，因此没有任何内容变得不可读，并且如果只有页面的一部分是文档，则它适用于任何容器：

<div class="card" data-lte-print="plain">…the invoice…</div>

在 window.print() 之前从 JavaScript 设置它也可以。使用 Bootstrap 自己的 .d-print-none 隐藏镀铬，它从 4.6.0 开始就在侧边栏和标题上起作用。

注意，.d-print-none 不能在这里选择退出：它“隐藏”一个元素，并且这些规则重新设计要打印的元素。

修复

  • 每个侧边栏项目都打印在黑框内。 大纲规则将 .nav-link 与 .btn 一起列出，并且侧边栏按设计打印（自 4.0.0 打印修复以来），因此打印的页面在所有 85 个菜单项周围都有一个黑色矩形。该大纲现在仅适用于 .btn - 按钮仍然读取为纸上的按钮 - 而导航链接保留节省墨水的透明黑色处理并打印为普通文本。
  • 常见问题解答给出了导致#6107的建议。“如何更改原色？”告诉人们在 :root 上覆盖 --bs-primary，这正是使 .btn-primary 呈蓝色的原因。它现在提供了两种有效的方法：Sass 中的 $primary 或带有调色板表的 data-lte-primary。

文档

新配方：将页面打印为文档 - 属性，将其范围限定为页面的一部分，隐藏镶边，并通过按钮进行打印。

安装

npm install admin-lte@4.7.0
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/admin-lte@4.7.0/dist/css/adminlte.min.css" />
<script src="https://cdn.jsdelivr.net/npm/admin-lte@4.7.0/dist/js/adminlte.min.js"></script>
