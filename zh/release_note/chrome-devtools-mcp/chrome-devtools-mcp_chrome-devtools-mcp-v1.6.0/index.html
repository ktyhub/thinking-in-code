1.6.0 (2026-07-14)

🎉 特点

*为GCF编码的工具响应添加experimentalGcfFormat标志（[#2235]（https://github.com/ChromeDevTools/chrome-devtools-mcp/issues/2235））（[3d21389]（https://github.com/ChromeDevTools/chrome-devtools-mcp/commit/3d2138945c7d3ee95f95c36680ce7c63d24f672f））

  • 在 get_heapsnapshot_details 中打印对象计数和总大小 (#2325) (15a6b78)
  • 支持 —allow-unrestricted-paths 配置 (#2296) (6e56c02)
  • 支持堆快照聚合过滤器 (#2323) (2812902)
  • 将 Lighthouse 更新为 13.4.0 (#2317) (ffc6060)

🛠️修复

  • 在性能工具中强制使用 .gz 而不是 json.gz (#2305) (b06e39b)
  • 保持所选页面仍然打开，而不是退回到第一页 (#2328) (c645eee)，关闭 #2304
  • 在浏览器重新连接时保持页面 ID 唯一 (#2345) (3e8d922)
  • 对 list_network_requests 和 list_console_messages 中的第 0 页进行分页 (#2359) (d0025b3)
  • 当 press_key 键事件失败时释放保持的修改器 (#2347) (78ccb19)
  • 当所选页面被后备自动替换时报告 (#2308) (2c16ac3)，关闭 #2304
  • 仅解析列出页面中的页面 ID (#2332) (eb04951)，关闭 #2304
  • 快照： 解析正确快照上的元素 ID (#2295) (b703f2c)
  • 遥测： 通过嵌套模式包装器解析枚举值 (#2315) (c065fd9)
  • 等待守护进程启动 (#2327) (ed7e95d)

📄 文档

  • 添加 Grok Build CLI 配置部分 (#2294) (aa4be07)
  • 更新内存泄漏调试技巧 (#2330) (c1736a0)

⚡ 性能

  • 根路径解析中的并发 I/O (#2279) (b2c63e6)

🏗️ 重构

  • 清理 McpContext getter (#2340) (5b33deb)
  • 清理更多上下文接口 (#2335) (9cd734b)
  • 清理页面管理 (#2333) (16db01f)
  • 清理页面快照生成 (#2348) (68cfce2)
  • 让收集器按页工作 (#2324) (9bc61b4)
  • 移动并重命名文件 (#2355) (9c3542b)
  • 将 DevTools 宇宙移至 McpPage (#2341) (c006c9b)
  • 移动剩余的 McpContext getter (#2342) (58ba174)
  • 删除隔离上下文 getter (#2336) (8a4ddb3)
  • 使用数组代替 idToClassKey 的 Map (#2321) (ff53b7b)
  • 使用对话框句柄帮助程序 (#2334) (64005f9)
  • 在格式化中使用响应页面 (#2349) (c53c1ec)
