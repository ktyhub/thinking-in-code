chrome-devtools-mcp v1.11.0

1.11.0 (2026-10-15)

🎉 特点

  • 添加 —file-navigations 标志来拒绝文件：URL 导航 (#2853) (54cae57)
  • 添加analyze_heapsnapshot_contexts MCP工具 (#2791) (190aeee)
  • 将ignoreCache选项添加到performance_start_trace (#2931) (3467d40)
  • 在compare_heapsnapshots中添加maxNameLength截断选项 (#3098) (1e1c53e)
  • 添加分页到compare_heapsnapshots (#3140) (daebfd1)
  • config: 添加 ConfigWatcher 来监视配置文件更改 (#3139) (9171f77)
  • 在预定义位置发现配置文件 (#2876) (02c0112)
  • 实现默认启用的无 ffmpeg 截屏工具 (#3123) (8953ea5)
  • 减少文本快照中的 StaticText 噪音 (#2895) (4441325)
  • 通过输入操作打开的报告页面 (#2679) (28fb230)
  • 合并 CLI 和配置文件后解析默认配置 (#2849) (bdeb70d)
  • 从 lighthouse_audit 内联返回失败的审核和 DOM 节点 (#2930) (241fba5)
  • 跳过文本快照中的更多冗余数据 (#2896) (b2f522c)
  • 支持在第三方开发者工具中调试WebMCP工具 (#2900) (0db519f)
  • 支持模拟额外的 CSS 媒体功能 (#2929) (69524f0)
  • 支持从本地文件评估脚本 (#2606) (9cf47a4)
  • get_heapsnapshot_details 支持截断 (#3137) (f827e06)
  • 默认情况下将长名称截断为 100 个字符 (#2893) (5ddb0a3)

🛠️修复

  • 考虑缩小屏幕截图中的滚动偏移 (#2685) (830c693)
  • 连接到现有浏览器时允许 —categoryExtensions (#3041) (d250bc5)
  • 如果命令失败，允许停止 CLI (#3088) (77e238e)，关闭 #2982
  • 避免运行时标题获取 (#2883) (04195d1)
  • 更好地支持 chrome-devtools CLI (#2819) (9624e64)
  • 钳制异步堆栈跟踪分隔符重复计数（[#3035]（https://github.c
