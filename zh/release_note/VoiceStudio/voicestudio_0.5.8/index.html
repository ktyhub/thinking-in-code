亮点

  • OmniVoice GGUF 在 Windows 和 Linux 上通过 Vulkan 使用 AMD、Intel 和 NVIDIA GPU，Intel Arc GPU 运行 OmniVoice
  • 当 PyTorch 下载失败时，安装程序回退到较小的 CPU 版本，当 GPU 失败时，应用程序回退到 CPU
  • Windows 一次加载一个文件，引擎崩溃会指出其原因并提供 CPU 重新启动功能 -dots.tts 语音克隆通过 audio.cpp 在 Windows 上运行，无需 Python 设置
  • 转换可以保留您的交付并拍摄视频；配音首先导出字幕并在说话者之间移动线路

OmniVoice 现在使用您的 AMD、Intel 或 NVIDIA GPU，并且 VoiceStudio 变得更难破解。 OmniVoice GGUF 在 Windows 和 Linux 上的任何 Vulkan GPU 上运行，根据您的卡调整模型大小，并可以在请求之间保持加载状态（选择加入，设置 → 性能），并且 Intel Arc GPU 也运行 OmniVoice。当出现问题时，应用程序现在会继续运行：当 PyTorch 下载持续失败时，安装程​​序会提供更小的 CPU 版本，重试停止的下载，并且当 GPU 失败时，VoiceStudio 会转移到 CPU 并发出通知。在 Windows 上，模型一次加载一个文件，以避免首次启动时崩溃，引擎崩溃会为其背后的库命名并提供 CPU 重新启动功能。

此版本还为 Windows 带来了 dots.tts 语音克隆，无需 Python 设置，转换可保留您的交付并拍摄视频，配音可首先导出字幕并在扬声器之间移动线路，voicestudio 终端命令，后台更新，新的 macOS 安装程序窗口，以及对配音、设置、有声读物和手机应用程序的数百个修复。

新的 macOS 安装程序窗口 (#4001)。

从 0.5.7 更新： 采用 0.5.7 提供的应用内更新，或安装在您现有的应用程序上；声音、项目和设置都会被保留。首次启动时，本地运行时会就地更新其软件包，包括 PyTorch 2.10 安全更新 (#3884)

从 0.5.8 测试版更新： 无需执行任何操作：测试版频道会自动前滚到 0.5.8。要停止获取测试版，请在“设置”→“更新”→“更新频道”中切换到“稳定”。

从源代码运行： 默认情况下不再安装 Gradio 演示和模型训练；如果使用 ui 或 train 则额外添加它们 (#4027)

已更改

  • 更小的安装：默认情况下不再安装 Gradio 和 WebDataset（大约减少 81 MB）； Gradio 演示和模型训练现在使用 ui 和 train 附加功能 (#4027)
  • macOS 安装程序窗口具有新的品牌背景、更大的图标和干净的卷名称，没有处理器后缀 (#4001)
  • 后端启动更轻更快：语音识别引擎在短暂的帮助程序进程中检查，而不是在启动时加载，而损坏的安装仍然报告为不可用（#3924、#3946）
  • 应用程序打开时需要加载的代码更少：音频和视频播放器在播放第一个 clip 时加载，返回的用户会跳过首次运行设置屏幕，将启动包减少约 6%，并且新的离线基准测试对包增长进行 CI 检查，跟踪启动、内存、CPU 和包大小（#3924、#3940、#3943）
  • 设置→ VoiceStudio 帐户将要同步的内容和您的设备列出为紧凑、带有图标的对齐行、带有锁定项目的“获取专业版”链接的专业徽章，以及显示操作系统和每个设备上次活动时间的设备行 (#3937)
  • 运行时设置屏幕适合一个窗口：一个状态行、具有可用空间的安装文件夹、一个主要操作（或确切的修复，例如在驱动器已满时选择另一个文件夹），在选项下有语言、区域、Python 和远程选项，在更多修复下有恢复工具 (#3934)
  • OmniVoice GGUF 可以在请求之间保持其运行时加载，以在每次生成之前跳过重新加载，作为“设置”→“性能”下的选择（#3965、#3654） -audio.cpp运行时更新为v0.9.4；已安装的 Breeze-TTS-2、dots.tts 和 Sortformer 模型无需重新下载即可继续工作，并且之前的运行时将继续运行它们，直到您安装更新 (#3129)
  • 更新现在在后台下载并在退出时安装，并带有一个紧凑的标题栏药丸用于编程
