VoiceStudio v0.5.7

VoiceStudio v0.5.7

首先，道歉。 此版本发布的时间比应有的时间长得多。紧急的家庭事务让我离开了一段时间，对于等待以及同时没有得到解答的问题，我感到很抱歉。感谢您的耐心等待以及每一份报告、修复和善意的话语。

欢迎 Shimul Debnath (velixio) 加入核心团队。 Shimul 现在帮助维护 VoiceStudio — 审查拉取请求、分类问题并保持发布进展 — 因此该项目不再等待一个人。

VoiceStudio 现在可以在没有 GPU 的手机和 PC 上运行，整个应用程序更加平静。 预览 iOS 和 Android 应用程序在手机本身上运行模型，无 GPU 的计算机获得小型 CPU PyTorch 构建，侧边栏、模型、配音、故事和工作流程页面围绕更少、更清晰的控件进行了重新设计。

此版本还添加了一个可选择的 Beta 更新通道、一个底部播放器、一个具有诚实 Radeon 报告的 GPU 加速面板和 Ask VoiceStudio Agent，以及数百个针对克隆、配音、有声读物、下载和听写的修复。

升级： 安装在您现有的 Electron 应用程序上；声音、项目和设置都会被保留。如果安装程序询问，请选择“安装本地运行时”以刷新其依赖项。

  • 远程计算设备、远程工作人员和 GPU 共享已移至 VoiceStudio Pro，不再包含在开源应用程序中；保存的项目、声音和设置不受影响 (#2748)
  • 没有明确商业许可的型号，包括默认的 OmniVoice 型号，一旦进入型号目录，就会要求您接受其许可证；在此之前，API 和使用它们的 MCP 请求会返回许可证错误 (#2689)
  • Docker，通过主机名进行 LAN 或反向代理访问，无需 API 密钥或会话，需要 OMNIVOICE_ALLOWED_HOSTS 中的该名称； IP 地址、localhost、*.ts.net 和 host.docker.internal 的工作方式与以前一样。
  • 从您自己网络上的服务器导入 URL 需要 OMNIVOICE_ALLOW_PRIVATE_URL_IMPORTS=1。
  • 在哪里设置这些变量：对于桌面应用程序，~/.config/omnivoice/env (macOS、Linux) 或 %USERPROFILE%\.config\omnivoice\env (Windows) 中的一行，Docker 中的 -e 中的一行。

从 Tauri 迁移： 关闭应用程序，备份其数据目录，安装 Electron，并在删除 Tauri 之前验证您的声音和项目。请遵循迁移指南。 Tauri v0.5.3 仍然是 Tauri 的最终版本；它的更新程序无法安装 Electron。

安装程序 trust： macOS 安装程序已签名。 Windows 安装程序尚未经过代码签名，因此 SmartScreen 可能会发出警告；上面的安装程序签名表显示了每个平台的结果。请参阅安装指南。
