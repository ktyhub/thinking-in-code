VoiceStudio v0.5.6

VoiceStudio 现在可以与您的其他工具进行对话。 以保存的语音接听 Twilio 电话，并使用有效的可复制设置将 Claude Code、Cursor、Codex CLI 和 OpenAI Agents SDK 连接到 VoiceStudio，包括在 Docker 中，其中 MCP 之前返回 HTTP 405。集成卡现在可以清楚地显示哪些可以与 VoiceStudio 配合使用，哪些是外部链接。

此版本还允许您替换已保存克隆的参考样本、在 OmniVoice 上克隆长参考 clips、在 8 GB GPU 上完成长有声读物章节，并通过关闭电源或移动数据文件夹来保留渲染的章节。

升级： 安装在您现有的 Electron 应用程序上；声音、项目和设置都会被保留。如果安装程序询问，请选择“安装本地运行时”以刷新其依赖项。配置 /mcp 的 MCP client 继续工作；新出口使用/mcp/。兼容 OpenAI 的 /v1 clients 现在会收到 OpenAI 格式错误，HTTP 400 而不是 422，并且 response_format="mp3" 返回真正的 MP3。

从 Tauri 迁移： 关闭应用程序，备份其数据目录，安装 Electron，并在删除 Tauri 之前验证您的声音和项目。请遵循迁移指南。 Tauri v0.5.3 仍然是 Tauri 的最终版本；它的更新程序无法安装 Electron。

安装程序 trust： Electron 安装程序未签名或临时签名，并且未经 Apple 公证。 Windows/macOS 可能会显示 trust 警告。 macOS 自动更新未经验证；使用手动安装程序更新。请参阅安装指南。

亮点

  • 用保存的语音问候语接听 Twilio 电话；默认情况下关闭，并进行本地电话质量测试 (#2291)
  • Claude Code、Cursor、Codex CLI 和 OpenAI Agents SDK 通过工作设置连接到 VoiceStudio（#2289、#2290）
  • 替换已保存克隆的参考样本，并从 OmniVoice 上超过 20 秒的参考进行克隆（#2282、#2281） — 感谢 @Cengokill！
  • 长有声读物章节在 8 GB GPU 上完成，并且在断电或数据文件夹移动后仍能保存（#2287、#2279）——感谢 @Tran-Van-Hieu 和 @castlecreati！
  • 马拉雅拉姆语数字、章节提示表和没有语音标记的字幕（#2280、#2278、#2295）——感谢 @nikhilkilivayil、@shivsin25 和 @kevin9327！

已更改

  • 语音克隆会显示活动引擎使用了多少长参考，而不是要求您修剪到 15 秒 (#2281) — 感谢 @Cengokill！

添加

  • 编辑已保存的语音克隆的参考样本：播放它，通过上传或录音替换它，然后保存回相同的语音（#2282） - 感谢@Cengokill！
  • 以保存的语音接听 Twilio 电话：默认关闭、签名的 Webhook 和一次性流令牌，以及本地电话质量测试 (#2291)
  • 马拉雅拉姆语配音和有声读物用马拉雅拉姆语讲数字、百分比和小数，而不是阅读原始数字 (#2280) — 感谢 @nikhilkilivayil！
  • 在故事或有声读物渲染后下载章节提示表 (HH:MM:SS<TAB>Title)；时间戳与 M4B 的嵌入式章节相匹配，并提供 MP3 便携式章节 (#2278) — 感谢 @shivsin25！
  • OpenAI Agents 集成页面提供了一个可复制的片段，可在 VoiceStudio 上运行 Agents SDK 语音管道 (#2290)
  • 兼容 OpenAI 的 API 增加了 GET /v1/models 和 POST /v1/audio/translations（多语言 Whisper 型号；涡轮型号被拒绝）（#2290）
  • 语音请求接受 stream_format（audio 或 sse）和 OpenAI 的 {"id": ...} 语音对象（#2290）
  • 转录将 language、prompt 和 temperature 传递给 Whisper 引擎，并返回 words 和 timestamp_granularities[]=word (#2290)
  • 集成：Codex CLI (config.toml)、任何 MCP client（HTTP 或 stdio）、VoiceStudio API（curl 和 OpenAI SDK）和 Docker/GHCR 的可复制设置（#2289）

已修复

  • 粘贴和导入的字幕不再显示卡拉 OK 标签、<i>/<font> 标签或 {\an8} 对齐前缀，而保留 SubRip 对话，例如 2 < 3；未更改的 WebVTT 和 SubRip 导出保留原始提示标记 (#2295) — 感谢 @kevin9327！
  • 保存的语音并再次在 OmniVoice 上克隆超过 20 秒上传；最好的段落是自动选择的（#2281）——感谢@Cengokill！
  • VoxCPM2 不再将上限参考与整个 clip 的转录本配对 (#2281)
  • 扬声器二值化使用 Lightning 2.6.6，它会阻止精心设计的检查点的代码执行 (#2296)
  • 8 GB GPU 上的长有声读物章节在渲染时不再超时，并且超时的章节在当前块之后停止使用 GPU (#2287) — 感谢 @Tran-Van-Hieu！
  • 在 Windows 上，一次重置连接不再使后端运行但无法访问 (#2276) — 感谢 @ialexbond！
  • 官方 openai SDK 和 OpenAI 代理 SDK 工作不变：gpt-4o-mini-tts 和当前 OpenAI 语音名称不再因“未知型号”而失败 (#2290)
  • OpenAI instructions 现在到达语音引擎而不是被忽略； OmniVoice 使用其中的语音设计标签 (#2290)
  • OpenAI 指定的语音 pcm 为 24 kHz； aac 和 opus 返回真实的 AAC 和 Opus，缺少编码器是一个明显的错误，而不是错误标记的 WAV (#2290)
