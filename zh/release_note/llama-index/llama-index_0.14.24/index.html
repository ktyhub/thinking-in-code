llama_index v0.14.24

[2026-08-19]

美洲驼索引核心 [0.14.24]

  • 修复：关闭 HotpotQA 评估器文件句柄 (#22113)
  • 修复（核心）：在 CodeSplitter 中保留过大的叶节点（#22119）
  • 修复：保留多块聊天历史记录写入（#22124）
  • 修复（核心）：跳过 HTMLNodeParser 中的空节点（#22125）
  • 修复（核心）：在 MMR 嵌入搜索中尊重 mmr_threshold=0 (#22126)
  • 修复：将每个文档的所有节点保留在 IngestionPipeline upserts 中（重新提交 #22046，而不是 #21456 的重复）（#22133）
  • 修复：不要将 *args/**kwargs 标记为必需的工具参数 (#22135)
  • 修复（核心）：无时默认 MetadataFilters 条件为 AND (#22155)
  • 修复：在 AgentWorkflow 中尊重代理 Structured_Output_fn/Output_cls (#22162)
  • 修复（核心）：在 SemanticDoubleMergingSplitterNodeParser 中使用单词标记化来删除停用词（#22167）
  • 修复（核心）：恢复提示助手回退到提供的 LLM 元数据（#22177）
  • 写入内存时在流式聊天响应中填充响应文本（#22179）
  • feat(property_graph)：将 raise_on_error 添加到 LLM 路径提取器 (#22195)
  • 澄清 FactExtractionMemoryBlock 压缩提示以返回完整快照 (#22213)
  • 修复一些拼写错误 (#22512)
  • 修复（核心）：为每个 CitationQueryEngine 引文节点提供自己的 id 和偏移量（#22537）
  • 修复（核心）：在没有 escaping 非 ascii 的情况下保留 SimpleChatStore （#22538）
  • feat(core)：允许内存接受任何 AsyncDBChatStore (#22541)
  • test(node_parser): 为句子窗口测试启用 pytest 发现 (#22545)
  • 为 LLMRerank 实现异步 (#22597)

llama-index-embeddings-bedrock [0.8.3]

  • 修复：使 aioboto3 在 llama-index-embeddings-bedrock 中可选（#21915）
  • 修复（嵌入）：在 AWS 调用之前验证非空基岩嵌入负载（#22527）

llama-index-embeddings-voyageai [0.6.1]
