cline desktop-v0.0.46

发布 发布时间2026年10月13日 来源cline/cline 英文原文

cline desktop-v0.0.46

  • 对话左侧边缘的新大纲列出了您发送的每个提示。将鼠标悬停在某个标记上可预览提示，然后 click 即可跳转到那里
  • 在会话期间无法加载或出错的插件现在会在聊天中显示状态行，命名插件和错误，而不是默默地丢失其工具
  • 您可以在等待浏览器时取消 Cline 云登录
  • 在网络上重命名的会话标题现在在应用程序中更新
  • 注销时，云设置卡在较小的窗口上保持可见
  • 现在在没有安装 Git 的情况下安装技能会显示需要 Git 以及如何修复它，而不是显示原始克隆错误
  • 计划例程：排队运行现在开始，而不是永远处于挂起状态，模型调用失败的运行（例如，退役模型）被标记为失败并出现错误，并且在停机后，仅运行最近错过的事件，而不是连续运行。例程编辑器现在列出当前型号而不是退役型号
  • 如果没有选择型号，Cline 提供商将使用 Cline 推荐列表中的第一个型号 (Claude Sonnet 5.5)
  • 关闭推理现在适用于每个提供商。无法关闭它的模型保留默认值，并且仅限级别的 Gemini 模型不再因思维预算错误而拒绝请求
  • 屏幕截图和其他图像不再夸大令牌估计，这使得自动压缩在对话接近极限之前就运行了
  • 当目录条目没有上下文窗口时，自动压缩会使用所选模型的上下文窗口
  • 现在加载符号链接的规则文件
  • .claude/skills 中的技能现已被发现
  • 编辑器工具不再接收 null 来代替某些模型中要替换的文本
  • 更新了模型目录。添加 AI/ML API、LowRouter 和 Prime Inference 提供程序。 v0 提供商现在仅提供其默认模型 v0-1.5-md，而 OpenCode Go 使用其新的 https://opencode.ai/inference/go/v1 端点。 Cline 空闲列表添加了第 5 步预览。默认模型更改为 302.AI、CrossModel、Cortecs、DigitalOcean、NEAR AI Cloud 和 Ofox (Claude Haiku 5.5)、DevPass (LLM Gateway)、LLM Gateway 和 Meta (Muse Wonder 1.0)、Aixy (GPT-6.1 Sol)、CloudFerro Sherlock 和 Moark (GLM 5.3)、Ambient、NanoGPT、 Neuralwatt 和 Novita AI 完整 Changelog：https://github.com/cline/cline/compare/desktop-v0.0.45…desktop-v0.0.46
