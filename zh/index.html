方法

STAGS 如何采集、归一化并发布 Release Note。

查看 →
01 采集 定时任务通过 GitHub Releases API 拉取每个追踪仓库的发布记录，跳过草稿、空正文与预发布版本（除非显式开启）。
02 归一化 每条记录被整理为稳定结构：项目、语义化版本、发布日期、发布通道，以及从正文提取的一句话摘要。
03 发布 正文以 Markdown 存入仓库，每次推送即渲染为静态页面，站点保持极快，且每条记录都有稳定 URL。
