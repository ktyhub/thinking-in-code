发布节奏

codebase-memory-mcp 迭代更快：近 90 天发布 3 个版本，continue 是 0 个。

从相邻两次发布间隔看，codebase-memory-mcp 的中位数是 1 天，continue 是 1 天。间隔越短，升级窗口越难规划——但这通常也意味着修复来得更快。

怎么选

需要新功能持续落地
选 codebase-memory-mcp。近 90 天 3 个版本、间隔中位数 1 天，意味着接口面一直在动，配套文档和客户端要跟得上。
希望升级周期可预测
选 continue。间隔中位数 1 天，近 90 天 0 个版本，升级批次更少、回归面更窄。
只想要正式版本
codebase-memory-mcp 有 0 个预发布版本，continue 有 0 个。只看正式版本的话，可用发布数分别是 47 和 20。
