junit5 vs testng

发布节奏

junit5 迭代更快：近 90 天发布 0 个版本，testng 是 0 个。

从相邻两次发布间隔看，junit5 的中位数是 23 天，testng 是 103 天。间隔越短，升级窗口越难规划——但这通常也意味着修复来得更快。

注意：testng 最近一次发布距今已有 302 天，它的节奏数据反映的是历史，不代表当前状态。

怎么选

需要新功能持续落地
选 junit5。近 90 天 0 个版本、间隔中位数 23 天，意味着接口面一直在动，配套文档和客户端要跟得上。
希望升级周期可预测
选 testng。间隔中位数 103 天，近 90 天 0 个版本，升级批次更少、回归面更窄。
只想要正式版本
junit5 有 1 个预发布版本，testng 有 0 个。只看正式版本的话，可用发布数分别是 18 和 12。
