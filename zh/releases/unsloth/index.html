unsloth

收录 11 个版本 · 最新 v0.1.917-beta（2026年11月11日）

unslothai/unsloth ↗

202611

11/11
v0.1.917-beta 预发布

Qwen3.8-27B 带有动态 v3.1 GGUF，可以使用 Unsloth 在本地运行。此版本还带来了重大性能改进、更流畅的 Glass 渲染、改进的代码块和 Thinking UI、HTML/PDF 聊天导出以及新的图像生成和编码代理功能。

 11/06
v0.1.916-beta 预发布

此版本为 Unsloth 带来了巨大的性能修复：在长时间聊天中更快的打字和搜索、更快的图像/视频加载、双 GPU 图像/视频生成。它还为每个聊天添加了单独的浏览器、浮动浏览器窗口。

 11/04
v0.1.915-beta 预发布

此版本引入了 Qwen3.8-Flash-Next Dynamic V3.1，完善了 Glass 主题（现在处于测试版），添加了 Composer 位置滑块，并允许模型与内置浏览器中的文件进行交互。它还带来更低的空闲内存使用量、切换 GGUF 模型时保留的聊天上下文、更快的 MLX 加载和 FP8 LoRA 训练。

 11/03
v0.1.914-beta 预发布

Unsloth 现在拥有 Glass 主题以及更多用于背景、问候语和聊天的自定义选项。此版本还带来了 Unsloth 中更快的生成、更多的多 GPU 训练选项和 CPU 训练。

 10/30
v0.1.913-beta 预发布

通过自定义背景和改进的 UI/UX，打造您自己的 Unsloth。当 VRAM 有限时，此版本还缩短了应用程序更新时间并加快了 Linux 应用程序和 Qwen-Image gen 的速度。 还有新功能：Unsloth 动态 v3.1 GGUF（预览）中的 DeepSeek-V4.1-Flash-1017、低 RAM 计算机上的 FLUX.2-klein-9B、更流畅的聊天和批量 MoE 微调。

 10/28
v0.1.912-beta 预发布

万圣节👻来了。整个十月份，侧边栏中的“不给糖就捣蛋”行会打开十一个万圣节主题、怪异的问候语以及一些蜘蛛和蝙蝠。

 10/26
v0.1.911-beta 预发布

此版本添加了计划任务、FLUX-3 编辑支持、性能改进等。另外还有新产品：MiniMax-M3.1-Flash、图像面部修饰以及 Mac 上更快的性能和聊天。

 10/23
v0.1.910-beta 预发布

Recursive 的 Flint、MOSS-Image 和 NVIDIA 的 Nemotron Bolt 4B 都在这里！在 Unsloth 本地运行它们。还有新功能：仅限聊天的 Unsloth 桌面安装、大于 Mac 内存的 MLX MoE 模型以及兼容 OpenAI 的微调 API。

 10/19
v0.1.909-beta 预发布

DeepSeek-V4.1-Flash-1017 和 FLUX.3 Image Klein 来了！在 Unsloth 中本地运行两者。还有新功能：聊天中的图像和视频、使用 FSDP2（alpha）进行多 GPU 训练以及用于编码代理的单命令 MCP 设置。

 10/15
v0.1.908-beta 预发布

在 Unsloth 中本地运行 NVIDIA 的新 Nemotron 3.5 模型和 Meta 的新 Muse Spark Open。新内容：文本传播法学硕士、DeepSpeed 训练和更好的编码代理提示缓存。

 10/13
v0.1.907-beta 预发布

Unsloth 的性能得到了重大升级！
