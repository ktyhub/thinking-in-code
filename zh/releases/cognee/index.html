 11/12
v1.6.8 修订

此版本的重点是扩展和强化集成（新的 Slack 支持和许多连接器改进）以及为嵌入和数据更新构建可靠的后台工作。您将发现新的 Slack 连接器和应用程序、更好的 Google/Drive/Gmail/Calendar 连接器行为、基于 RabbitMQ 的嵌入工作选项以及许多可靠性和出处（审核）修复，以便您的导入、更新和删除行为更加可预测。

 11/06
v1.6.7 修订

此版本加强了摄取安全性并改进了搜索和检索的行为和执行方式。在提供系统文件或数据库连接信息时，您将看到更严格的保护措施、更正确的范围搜索（针对特定文档类型或命名空间的查询）以及更快、更高效的矢量搜索评分。

 10/29
v1.6.6 修订

此版本的重点是使冲突处理更可靠、更易于管理，以及一些稳定性、矢量和数据布局修复。您将发现新的持久冲突解决 API、更安全地淘汰冲突选择、更快、更安全的缓存/删除路径，以及可节省重新嵌入工作的矢量处理改进。

 10/23
v1.6.6rc1 修订

此版本的重点是为用户提供对内存和搜索历史记录更清晰、更安全的控制，添加多个新连接器，并强化同步可靠性。关键的工作流程更改包括明确的历史记录清除行为、从 CLI/API 中删除搜索历史记录的新标志，以及使 Drive/Asana 同步和索引更加强大的修复。

 10/16
v1.6.5.dev0 修订

此版本的重点是使内存蒸馏更加可靠，改进嵌入的生成和计量方式，以及强化连接器和 LLM 集成。它包括多个错误修复、安全性和操作改进，以及与旧版嵌入表面和本地缓存布局相关的一些重大更改。

 10/16
v1.6.5 修订

此版本加快了跟踪和摄取管道的速度，改进了会话处理，并使代码文档可以在代码图中进行搜索。它还添加了新的 memify API、更好的嵌入兼容性 (base64) 以及一些安全性和连接器强化。

 10/13
v1.6.4.dev0 修订

这个小型开发版本修复了一个关键的向量搜索错误并改进了 Turso 数据库错误处理。它还更新了一些打包依赖项和测试，因此搜索更加可靠并且错误得到一致处理。

 10/13
v1.6.4 修订

此补丁版本修复了有关矢量搜索适配器和 Turso 数据库适配器的多个后端问题，并删除了 LanceDB 支持的存储的不需要的后台修剪任务。这些更改减少了搜索期间的内存使用和错误，使 Turso 打开故障报告保持一致，并添加测试和利用修复以提高可靠性。

 10/07
v1.6.3 修订

此版本增强了 Cognee 的搜索和摄取可靠性：时态查询更加精确且更具包容性，自然语言搜索返回匹配行并跳过不相关的轮次分析，摄取验证器可防止格式错误的数据。一些操作修复改进了容器构建和外部集成。

 09/29
v1.6.2 修订

此版本的重点是使嵌入可靠且透明（不再有静默截断），添加了 Slack 对话导入和同步，并重新组织了“技能”的存储方式，以实现更好的跨平台工具。当嵌入失败时，您将看到更清晰的错误，基于模型令牌限制的更安全的块大小调整，以及更新的 CLI/docs 以匹配这些行为。

 09/24
v1.6.1 修订

此版本增强了 Google 集成（Drive 和 Gmail），改进了大型子图的可视化流，并简化了 GLiNER 安装和遥测。它还增加了更好的来源范围，将外部元数据标记到文档块上，以便检索返回更丰富的结果，并修复了一系列同步、摄取和 UI 问题。

 09/18
v1.6.0 小版本

此版本使得在没有云 LLM 密钥的情况下运行 Cognee 变得更加可用和可预测，增强了管道启动和恢复行为，并完成了端到端图像/音频/嵌入模型的连接。它还引入了面向开发人员的集成工具，加强了遥测隐私，并修复了摄取、召回和 CLI 方面的众多错误。

 09/15
v1.5.4rc1 修订

此版本改进了混合搜索和证据处理，添加了上下文引导的查询分解检索器，确保打包的扩展随 PyPI 轮一起提供，并加强了服务器和遥测强化。这些变化使搜索结果更加准确和可追踪，减少设置摩擦，并提高多组件部署的安全性和可靠性。

 09/04
v1.5.4 修订

此补丁版本重点关注可靠性、数据摄取便利性和前端优化。它修复了多个迁移、日志记录和来源问题，为摄取工具添加了小但有用的 API 和 Docker 便利性，并包括一系列广泛的前端更新和错误修复。
