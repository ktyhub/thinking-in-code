v15.17.1 修订

自 15.16.0 起，工作人员会在启动后五分钟从 Claude Code 的插件缓存中清除旧插件版本，然后每小时清除一次。更新到达时已打开的 Claude Code 会话将继续从旧版本文件夹运行。一旦扫描删除了该文件夹，Claude Code 就拒绝运行该会话的每个 claude-mem 挂钩（“插件目录不存在”），因此该会话默默地停止保存提示、工具调用、观察结果和摘要。
