11/08
v6.9.0 小版本

图像到 PPTX 获得 OCR 文本证据、文本删除的碱基和检查的图像层，现在可以在具有 imagegen.py 参考图像后端的任何视觉主机上运行。 Narration 添加了 OpenAI Realtime 提供程序，imagegen.py 可以在 OpenAI gpt-image-2.6 上生成动画 GIF，并且一轮转换和往返修复可防止源被覆盖或默默更改。

 10/30
v6.8.0 小版本

OpenAI 图像后端现在默认为 gpt-image-2.5-sunburst，并且图像生成接受任何宽：高宽高比。此版本还带来了一轮编辑本机、模板导入和源转换修复，以阻止内容被静默删除，以及 PowerPoint 精确的动画计时。

 10/22
v6.7.3 修订

补丁发布：编辑本机和本机对象修复，阻止往返失败或静默替换内容，并为 PowerPoint 之外的本机公式提供可读的后备。

 10/17
v6.7.2 修订

补丁发布：通过对问题历史记录的审核进行修复。其中大多数会阻止工具在报告成功时丢失、覆盖或重写内容。

 10/16
v6.7.1 修订

Patch release: fixes for work that the live preview, source conversion and source import could lose without a warning, plus a full pass over the UI strings in every language.

 10/08
v6.7.0 小版本

小版本：设计规范的浏览器审查页面，Google 新的 Nano Banana 2.1 作为默认的 Google 图像模型，并修复了源转换和 PPTX/SVG 文本往返过程中在没有警告的情况下丢失的内容。

 09/19
v6.6.0 小版本

Minor release from three days of end-to-end runs since v6.5.0: every route was driven through real decks — same-deck hyperlink navigation, Beautify under Quick, Edit Native with pages dropped and with a foreign PPTX…

 09/16
v6.5.0 小版本

自 v6.4.0 以来的两轮重点发布的次要版本：创建模板/使用模板流程经过审核和重新设计，编辑本机 PPTX 路线在真实的政府和大学平台上进行了练习（多母带、源动画、本机图表、SmartArt、旁白、修订轮次）并在出现问题的地方进行了修复。每项变更都有重现的缺陷或记录的合同差距作为支持；没有添加或删除任何路线。

 09/12

Minor release collecting a week of fixes found by running the pipeline end to end across languages, input types, deck lengths, and a revision round on a delivered deck.
