#Spring AI 1.1.5 Release Notes

🎯 Destaques

Esta versão inclui 9 correções de bugs, 3 melhorias na documentação e 11 outras melhorias.

⚠️ Notas de atualização

  • O modelo Pixtral 12B foi removido e o Pixtral Large está obsoleto. Atualize a configuração do seu modelo para usar os modelos Pixtral atualmente recomendados para evitar problemas em versões futuras. 447d2a4

📢 Notável

  • O modelo Pixtral 12B foi removido e o modelo Pixtral Large agora está obsoleto. Os testes de integração foram atualizados para usar os modelos de substituição recomendados. Os usuários que dependem desses modelos devem migrar para as alternativas recomendadas. 447d2a4

🪲 Correções de bugs

  • Corrigido o método doDelete do armazenamento de vetores CosmosDB para parametrizar adequadamente as consultas, evitando possíveis vulnerabilidades de injeção de SQL e melhorando a correção. 6039e57
  • Correção de um problema em que conversaId não era aplicado corretamente no filtro VectorStoreChatMemoryAdvisor, o que poderia causar recuperação incorreta de memória entre conversas. 3cccfdf
  • Correção do manuseio de chaves no conversor de expressão de filtro de armazenamento vetorial para garantir que as expressões de filtro sejam avaliadas corretamente. 01386e2
  • Resolvido o não determinismo de teste nos testes de uso do token de streaming BedrockConverse, melhorando a confiabilidade do teste. 4747a3c
  • Corrigida a nomenclatura da classe de teste para aplicar corretamente o sufixo do teste de integração, garantindo a categorização e execução adequada do teste. #5853
  • Lógica de análise de string corrigida para o campo toolChoice em OpenAiSdkChatModel para garantir o manuseio adequado das configurações de escolha de ferramenta. aeb33b0 por meio de #5735
  • Corrigido um problema em que o parâmetro extra_body era incluído incorretamente nas solicitações OpenAI API de saída, o que poderia causar comportamento inesperado. 4c0120c
  • Resolvidos problemas com geração e configuração de Javadoc para garantir que a documentação do API seja produzida corretamente. 0a71804
  • Corrigida a condição de bypass de teste para que os testes de integração sejam ignorados corretamente quando as chaves API necessárias não estiverem configuradas no ambiente. bc26dc1

📓 Documentação

  • Atualizado o README para incluir uma nota sobre requisitos de arquitetura de CPU ou informações de compatibilidade. a21e988
  • Adicionada documentação explicando como os servidores MCP podem republicar ferramentas do MCP clients, esclarecendo o modelo de propagação de ferramentas em configurações de vários servidores. #5778
  • Documentação aprimorada para esclarecer o uso pretendido e o comportamento do parâmetro extra_body em solicitações OpenAI API. 3d4d75b

🔨 Atualizações de Dependências

  • Atualizada a dependência do Spring Boot para a versão 3.5.14, incorporando as últimas correções de bugs e melhorias da equipe Spring Boot. eb4c9a5
  • Atualizada a dependência do Spring Boot para a versão 3.5.13 como uma atualização intermediária. 9b902f8
  • Dependências de análise de documentos atualizadas: Apache Tika atualizado para 3.3.0, jsoup para 1.22.1 e Apache PDFBox para 3.0.7 para recursos aprimorados de processamento de documentos e correções de bugs. f25fc52

🔩 Atualizações de compilação

  • Atualizadas as dependências do fluxo de trabalho do GitHub Actions para suas versões mais recentes para melhorar a confiabilidade e segurança do CI/CD. 9b70b38
  • Alterado o fluxo de trabalho de verificação de PR para usar o pacote mvn em vez do teste mvn para uma validação de solicitação pull mais eficiente. 7d2e455
  • Os testes de integração agora são ignorados no pipeline de CI para melhorar o desempenho da construção, e o fluxo de trabalho de geração do release note foi removido. #5688
  • O projeto foi transferido para a próxima versão de desenvolvimento 1.1.5-SNAPSHOT após o lançamento. 400dc42

🔐 Segurança

  • Fortalecido o diretório de cache padrão usado para modelos de transformadores para evitar acesso não autorizado ou adulteração de arquivos de modelo em cache. aac6b80
  • Correção de uma possível vulnerabilidade de negação de serviço em que um PDF malformado poderia causar alocação excessiva de memória durante a análise do documento. b61ac6a
