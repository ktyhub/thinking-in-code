#Spring AI 1.1.6 Release Notes

🎯 Destaques

Esta versão inclui 1 novo recurso, 5 correções de bugs, 2 melhorias na documentação e 5 outras melhorias.

⏪ Mudanças significativas

  • Os consultores de memória de bate-papo agora exigem que um ID de conversa explícito seja fornecido. Esta é uma mudança comportamental que afeta o escopo e o gerenciamento da memória do bate-papo. Os aplicativos que dependem de IDs de conversação implícitos devem ser atualizados para fornecer um ID explícito. 13cde41

⚠️ Notas de atualização

  • PromptChatMemoryAdvisor agora está obsoleto e os consultores de memória de bate-papo exigem um ID de conversa explícito. Atualize seu código para: (1) substituir PromptChatMemoryAdvisor pela alternativa recomendada e (2) garantir que um ID de conversa explícito seja fornecido ao usar qualquer orientador de memória de chat. 917f62e

⭐ Novos recursos

  • A configuração automática do MCP agora inclui a verificação @ConditionalOnMissingBean ausente, permitindo que os usuários forneçam suas próprias definições de bean e substituam os beans MCP configurados automaticamente conforme esperado nos padrões de configuração automática do Spring Boot. d4025e5

🪲 Correções de bugs

  • Corrigido um problema em que o método doDelete do MilvusVectorStore escapava incorretamente de strings na lista de IDs, o que poderia fazer com que as operações de exclusão falhassem ou se comportassem de forma inesperada. 20206a4
  • Correção do conjunto de testes ChatClientAdvisorTests para fornecer um ID de conversa explícito, alinhando os testes com o novo requisito para IDs de conversa explícitos em consultores de memória de chat. 704e5c6
  • Corrigido o teste de integração MistralAiChatModelObservationIT para garantir que a funcionalidade de observação funcione corretamente com o provedor de modelo de bate-papo MistralAI. a89145d
  • Corrige um problema em que as opções configuradas não eram incluídas corretamente nas solicitações MistralAI API, garantindo que todas as configurações definidas pelo usuário fossem transmitidas corretamente. 7bcf32a
  • Resolve uma regressão na forma como AssistantMessage.ToolCall.id é tratado ao usar a integração Ollama, restaurando o comportamento correto de identificação de chamada de ferramenta. bb9d65e

📓 Documentação

  • Correção de erros tipográficos na documentação do MCP (Model Context Protocol) para melhor legibilidade e precisão. a1ad7f2
  • Corrigidas âncoras refex quebradas na documentação para restaurar a navegação de referência cruzada adequada entre as seções da documentação. f03c104

🔨 Atualizações de Dependências

  • Atualizado MCP SDK da versão 0.17.0 para 0.18.2 e anotações MCP de 0.8.0 para 0.9.0, trazendo as mais recentes melhorias do protocolo MCP e correções de bugs. #5961

🔩 Atualizações de compilação

  • Atualizado o build do projeto para usar JDK 17.0.19, garantindo compatibilidade e incorporando o patch release mais recente do Java 17 para o ambiente de build. 27281e6
  • Reorganiza a estrutura do projeto realocando os módulos iniciais Spring AI para um diretório starters/ dedicado para melhor manutenção e clareza. 22f8676
