#WeKnora v0.1.6 #WeKnora v0.1.6 Release Notes Data de lançamento: 24/11/2025

🚀 Novos recursos

Melhorias no analisador de documentos

  • NOVO: Adicionado suporte para análise de arquivos CSV, XLSX e XLS
    • Capacidades aprimoradas de processamento de documentos com suporte a planilhas
    • Extração de dados aprimorada de formatos tabulares
  • NOVO: implementação do analisador de páginas da Web
    • Adicionada classe dedicada de análise de conteúdo da web
    • Suporte otimizado de codificação de imagem para conteúdo da web
    • Gerenciamento aprimorado de dependências para análise da web

Melhorias no processamento de documentos

  • NOVO: introdução do MarkdownTableUtil para formatação otimizada de tabelas
    • Redução de espaços em branco desnecessários em tabelas de remarcação
    • Melhor legibilidade e consistência da tabela
  • NOVO: implementação de classe de modelo de documento
    • Adicionados modelos de documentos estruturados para melhor segurança de digitação
    • Configuração otimizada e lógica de análise
  • ATUALIZADO: analisador de documentos aprimorado para Docx2Parser
    • Melhor tratamento de tempo limite
    • Melhor lógica de processamento de imagem
    • Gerenciamento otimizado de back-end de OCR

🌍 Internacionalização

  • NOVO: Suporte multilíngue (inglês e russo)
    • Adicionada dependência vue-i18n para internacionalização
    • Mensagens codificadas substituídas por funções de tradução
    • Mensagens de erro, saídas do console e texto da interface do usuário atualizados
    • Documentação multilíngue aprimorada com gráfico de conhecimento e guias de configuração do MCP

🐛 Correções de bugs

  • CORRIGIDO: problemas de integração de componentes de menu
  • CORRIGIDO: erro de regex de verificação de memória do sistema Darwin (macOS)
    • Resolvido problema de saída vazia ao verificar o uso de memória no macOS
  • CORRIGIDO: lógica de verificação de disponibilidade do modelo
    • Lógica de verificação de modelo unificada em diferentes interfaces
    • Adicionada tag automática ":latest" para modelos sem versões especificadas
    • Impediu chamadas repetidas de pull de modelo API devido a falsos negativos
  • CORRIGIDO: Vulnerabilidade de segurança na configuração do Docker Compose
    • Resolvido problema de segurança do serviço de sistema de arquivos gravável

🔧 Refatoração e Otimização

  • REFATORADO: registro do analisador e lógica de verificação API
    • Tratamento simplificado de exceções
    • Relatórios e depuração de erros aprimorados
  • REFATORADO: processamento de pedaços
    • Removido o manuseio desnecessário do cabeçalho
    • Exemplo de uso atualizado para melhor clareza
  • REFATORADO: Organização do módulo
    • Arquivos do módulo docreader reorganizados para melhor estrutura
    • Caminhos de importação proto e client atualizados
    • Configuração de construção Docker ajustada
    • Caminhos de importação de módulos unificados para importações absolutas

📚 Atualizações de documentação

  • ATUALIZADO: Documentação de aquisição de chave API
    • Alterado para registro na web e método de recuperação de página da conta
  • ATUALIZADO: Guia de configuração de inicialização do Docker Compose
    • Adicionadas instruções de configuração abrangentes
    • Configuração docker-compose.yml ajustada
  • ATUALIZADO: Documentação multilíngue
    • Adicionado guia de configuração do gráfico de conhecimento
    • Documentação aprimorada de configuração do MCP
    • Documentação atualizada da estrutura de diretórios
  • REMOVIDO: Documentação API de pesquisa híbrida obsoleta

🧹 Limpeza de código

  • REMOVIDO: Parâmetros de construção Docker redundantes
  • ATUALIZADO: regras .gitignore para melhor higiene do repositório
  • OTIMIZADO: instruções de importação e dicas de tipo
  • CLEANED: registro e comentários redundantes

🔄 Melhorias de CI/CD

  • ADICIONADO: Novas ramificações de gatilho para pipeline de CI/CD
  • ADICIONADO: Controle de simultaneidade para processos de construção
  • ADICIONADO: Automação de limpeza de espaço em disco
