#WeKnora v0.2.8

[0.2.8] - 31/12/2025

🚀 Novos recursos

  • NOVO: Agente e ferramentas do analista de dados
    • Adicionado agente Data Analyst integrado
    • Adicionada ferramenta DataSchema para recuperar esquema de arquivos CSV/Excel
    • Suporte para restrições de tipo de arquivo do agente
  • NOVO: Suporte ao modo de pensamento
    • Adicionado suporte de configuração para o modo Thinking
    • Adicionado campo Pensamento à configuração do Resumo
  • NOVO: gerenciamento aprimorado de arquivos e armazenamento
    • Suporte à listagem de buckets e permissões do MinIO
    • Limites de tamanho de upload de arquivos configuráveis
    • Modo de visualização de mesclagem de texto completo
  • NOVO: Melhorias nas conversas
    • Adicionada opção para desativar a geração automática de títulos
    • Parâmetros KnowledgeQAStream aprimorados
    • Suporte para tipos de resposta de streaming e chamadas de ferramentas
  • NOVO: Sistema e configuração
    • Adicionado suporte à variável de ambiente WEKNORA_VERSION
    • Suporte para configuração de espelho APK em Docker
    • Opções aprimoradas de separador de chunking
    • Filtragem de tags de prioridade de dois níveis de perguntas frequentes
    • Atualizar campos de índice ao atualizar tags em lote

⚡ Melhorias

  • MELHORADO: Tratamento de Agente e Modelo
    • Lógica de mensagem de agente unificado não pronto
    • Sincronização otimizada da configuração do agente integrado
    • Lógica de bloqueio de modelo removida para permitir troca livre
    • Seleção aprimorada de modelos e tratamento de erros
  • MELHORADO: Refatoração
    • Estrutura simplificada de solicitação de criação de sessão
    • KnowledgeRefs convertidos em tipo de referências
    • Configuração de fluxo SSE refatorada
    • Lógica de análise de política de bucket refatorada
    • Instalação simplificada do pacote Docker

🐛 Correções de bugs

  • CORRIGIDO: problemas de exibição do espaço reservado de localização
  • CORRIGIDO: criação de tags duplicadas e análise de resposta de stream
  • CORRIGIDO: WebSearchStateService ausente na pesquisa paralela
  • CORRIGIDO: atualização da lista de modelos ao fechar o pop-up de configurações
  • CORRIGIDO: configuração do banco de dados Asynq Redis
  • CORRIGIDO: Lógica de exclusão de menu e atualizações de contagem
  • CORRIGIDO: compatibilidade com OpenAI API (excluindo ChatTemplateKwargs)
  • CORRIGIDO: solicitações Nginx 413 (carga útil muito grande) tratadas
  • CORRIGIDO: Adicionada verificação de existência para tabela de embeddings na migração tag_id Changelog completo: https://github.com/Tencent/WeKnora/compare/v0.2.7...v0.2.8
