#go-ethereum v1.17.2

<!-- Supressor EMF (v1.17.2) -->

Esta é uma versão de manutenção com diversas correções de bugs importantes. Notavelmente, um problema crítico no debug_executionWitness poderia anteriormente corromper os dados do nó, os usuários que dependem deste endpoint RPC são fortemente aconselhados a atualizar.

Geth agora também suporta sincronização com cadeias onde a história pré-Praga foi removida e permite removê-la explicitamente via geth prune-history --history.chain postprague.

Obter

  • Defina o tamanho do cache padrão para 4 GB em todas as redes (#33836, #33975)
  • Adicionado suporte para o histórico da cadeia de poda antes da bifurcação de Praga (#33657, #34036)
  • Adicionado comando fetchpayload para construir testemunhas de execução para blocos específicos (#33919)
  • Importação otimizada do histórico da Era com inserção em lote (#33894)
  • Adicionado alvo womir para o goleiro (#34079)
  • Adicionado suporte para iterar uma única tentativa de armazenamento em geth snapshot traverse-state e geth snapshot traverse-rawstate (#34051)

Núcleo

  • Atualizações do garfo de Amsterdã:
    • EIP-8024: Mude para normalização sem ramificação e estenda EXCHANGE (#33869)
    • EIP-7778: Bloquear contabilidade de gás sem reembolso (#33593)
    • EIP-7954: Aumente o tamanho máximo do contrato (#33832)
    • EIP-7708: As transferências ETH agora emitem logs (#33645)
    • Ordem de medição de gás reformulada (pré-requisito para EIP-7928) (#33648)
  • Melhor construção de carga útil pré-aquecendo nós de teste para cálculo de hash de estado (#33945)
  • Várias melhorias nas tentativas binárias (#33951, #33961, #33989, #34021, #34032, #34022, #34056)
  • Atualizado go-eth-kzg para v1.5.0, reduzindo significativamente as alocações em VerifyCellProofBatch (#33963)
  • Banco de dados de estado refatorado em preparação para integração de teste binário (#33816)
  • Habilitada retenção de histórico de nós de teste em nós existentes (#33934)
  • Indexador de estado histórico otimizado com processamento em lote (#33640)
  • Corrigido potencial impasse no txlookup (#34039)
  • Adicionados novos RLP APIs (#34052, #34048)
  • Corrigir falha de dir.Sync() no freezer no Windows (#34115)

Rede

  • Evite conexões duplicadas ignorando discagens simultâneas de entrada/saída (#33198)
  • Corrigida incompatibilidade de chave de sessão usando manipulação de endereço remoto consistente em testes discv5 (#34031)
  • Adicionada resolução de nome de host DNS para nós de inicialização (#34101)

###RPC

  • Corrigido problema de corrupção de estado em debug_executionWitness; debug_executionWitnessByHash obsoleto (#33931)
  • Adicionado campo MaxUsedGas à resposta eth_simulateV1 (#32789)
  • Manuseio fixo da tampa do tanque em eth_simulateV1 (#33952)
  • Corrigido caso extremo de reversão de nonce durante a criação do contrato no rastreador (#33978)
  • Corrigido eth_createAccessList para retornar uma lista vazia em vez de nula para chaves de armazenamento (#33976)
  • eth_getFilterLogs agora retorna um erro se o segmento da cadeia solicitado tiver sido removido (#33823)
  • Corrigida a codificação do número do slot nas respostas RPC (#34005)
  • Aplicar limites de chamadas RPC para eth_simulateV1 (#34616)
  • Aplicar limites de slots de armazenamento para provas em eth_getProof (#34617)

Observabilidade

  • Várias correções OpenTelemetry (#33927, #33955)
  • Adicionado suporte OpenTelemetry para construção de carga útil (#33773)

Construir

  • Corrigidos problemas de compilação no FreeBSD (#34008)

Para um resumo completo das mudanças, consulte o marco de lançamento do Geth 1.17.2.

Tal como acontece com todos os nossos lançamentos anteriores, você pode encontrar:

  • Binários pré-construídos para todas as plataformas em nossa página de downloads.
  • Imagens Docker publicadas sob ethereum/client-go (use a tag "stable").
  • Pacotes Ubuntu em nosso repositório PPA do Launchpad.
  • Pacotes macOS em nosso repositório Homebrew Tap.
