#go-ethereum v1.17.3

<!-- Injetor Enzimático (v1.17.3) -->

Esta é uma versão de manutenção com progresso contínuo na implementação do fork Amsterdam. Também apresenta o ETH/70, que agora está ativo na rede.

Alteração significativa para rastreamento de APIs (debug_trace*), especificamente o rastreador structLog (opcode). Os seguintes campos de resposta agora seguem a recém-estabelecida especificação client (ethereum/execution-apis#762) e reexec foi removido da configuração de rastreamento:

  • memory: as palavras têm prefixo 0x e são preenchidas com 32 bytes
  • storage: chaves e valores têm prefixo 0x
  • error: omitido quando vazio (anteriormente serializado como "")

Obter

  • Adicionado mecanismo de nova tentativa para inicialização do ponto de verificação no blsync (#33966)
  • Adicionar subcomando para conversão de árvore binária offline (#33740)
  • Adicionar exportador de código para exportação de banco de dados (#34696)

Núcleo

  • Atualizações do garfo de Amsterdã:
    • Pré-requisitos do EIP-7928: listas de acesso em nível de bloco (#34064, #34644, #34726, #34776, #34799, #33737)
    • Pré-requisitos do EIP-8037: Aumento do custo do gás de criação de estado (#34691, #34712, #34841)
    • EIP-7976: Aumentar o custo mínimo de dados de chamada (#34748)
    • EIP-7981: Aumente o custo da lista de acesso (#34755)
    • EIP-7610: rejeita a criação de contrato quando o armazenamento não está vazio (#34718)
    • Atualizar testes de estado (#34671)
  • Implementar arena de pilha (#33960)
  • Implementar EIP-7975: listas de recebimento de blocos parciais eth/70 (#33153)
  • Pré-requisitos do protocolo snap/2 (#34083, #34649, #34654, #34874)
  • Implementar podador de índice de histórico para nós de arquivo em modo caminho (#33999)
  • Adicionar ponto de poda de segmento de cadeia de Praga para Hoodi (#34714)
  • Permitir a reorganização do cabeçalho para o pai dentro de 32 blocos no ePBS (#34767)
  • Pare de atender solicitações de segmentos de cadeia quando os dados estiverem indisponíveis (#34787)
  • Eliminar pares enviando corpos ou recibos inválidos (#34745, #34870)
  • Adicionar funções relacionadas à célula kzg4844 (#34766)
  • Refatoração de banco de dados de estado (#33102, #34700, #34763, #34724)
  • Melhorias nas tentativas binárias (#34055, #34110, #34670, #34676, #34680, #34690, #34754, #34758, #34777, #34794)
  • Mesclar eventos de acesso EIP-4762 para todas as chamadas do sistema (#34637)
  • Rejeitar camadas duplicadas no banco de dados de caminhos (#34642)
  • Omitir slotNumber vazio e corrigir a coleta de valores de bloco em cargas úteis API do mecanismo pré-Amsterdã (#34704)
  • Incluir o operando nas mensagens de erro EIP-8024 (#34635)
  • Corrigir downgrades de vmodule e propagar alterações de verbosidade para registradores derivados (#33111)
  • Correção da ordem fsync incorreta para truncamento de arquivo de índice (#34728)
  • Corrigir vazamento do descritor de arquivo em caminhos de erro do freezer (#34735)
  • Corrigir cálculo de tamanho no banco de dados de caminho (#34828)
  • Corrigir limite de tamanho de fila com lacunas no blobpool (#34831)
  • Melhore a simultaneidade pendente do txpool usando bloqueio somente leitura (#32924)
  • Substitua TypeMux obsoleto por Feed (#32585)
  • Continuar a recuperação de blob quando a extração de prova de célula individual falhar (#34891)
  • Use uint256 na mensagem principal para cálculos de gás mais rápidos (#34934)

Rede

  • Correção da saída antecipada do loop de tempo limite ao remover matchers expirados (#34743, #34878)
  • Evite corridas de dados copiando buffers de descoberta antes de erros de leitura não tratados (#34888)
  • Correção do impasse de descoberta waitForNodes desacoplando nodeFeed da tabela mutex (#34898)

Criptografia

  • Valide o comprimento do hash na verificação de assinatura nocgo (#33839)

###RPC

  • Corrija o formato de saída do structLog JSON e elimine reexec da configuração de rastreamento (#34093)
  • Aplicar substituições de bloco (gasLimit, blobBaseFee) em eth_estimateGas (#34081)
  • Aplicar substituições de bloco ao cabeçalho em eth_call (#34842)
  • Adicionar MaxUsedGas aos resultados da chamada eth_simulate (#34820)
  • Integre o progresso da indexação do histórico de trienodos no eth_syncing (#34633)
  • Retorna -32602 dos RPCs de log (eth_getLogs, eth_getFilterLogs,…) quando o limite do intervalo do bloco é excedido (#34647)

Outros

  • Adicionar transporte gRPC para exportação de rastreamento OTLP (#33941)
  • Adicionar rastreamento de chamadas do sistema no comando t8n (#34862)
