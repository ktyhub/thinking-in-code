#go-ethereum v1.17.5

<!-- Almofada Grav-Torque (v1.17.5) -->

Esta é uma versão de manutenção com correções de bugs e melhorias acumuladas e é recomendada para todos os usuários. Ele continua o trabalho de implementação do próximo hardfork de Amsterdã.

Algumas coisas que merecem destaque:

  • O padrão GOGC mudou de 20 para 50, trocando um pico de memória mais alto por menos sobrecarga de GC. Configure --gogc=20 para manter o comportamento antigo.
  • Pebble v2 agora é suportado como back-end de armazenamento de chave-valor. Pebble v2 é usado quando Geth é inicializado do zero e volta para Pebble v1 para um banco de dados pré-existente. Execute geth db pebble-upgrade para atualizar explicitamente um banco de dados Pebble v1 herdado para v2.

Implementação de garfo

  • Vários EIPs de Amsterdã foram implementados ou atualizados:
    • EIP-2780: gás de transação intrínseco baseado em recursos (#35212, #35318)
    • EIP-8037: Aumento do custo do gás de criação do estado (#35173, #35318, #35301, #35342, #35279)
    • EIP-8038: Atualização do custo do gás de acesso estatal (#35216)
    • EIP-8246: Remover queimadura de AUTODESTRUÇÃO (#35219)
    • EIP-8282: Solicitações de execução do construtor (#35175, #35341)
    • EIP-7997: Contrato determinístico de fábrica (#35223, #35285)
    • EIP-7954: Aumentar o tamanho máximo do contrato (#35217)
    • EIP-7928: Listas de acesso em nível de bloco (#35260, #35281, #35261, #35348, #35279)
  • Melhorar a cobertura do teste de bifurcação de Amsterdã (#35364)
  • Introduzir a bandeira --override.amsterdam (#35213)
  • Remover hardforks nomeados da programação de BPO (#35029)
  • Introduzir o garfo Bogotá na configuração da corrente (#34057)

Núcleo

  • Introduzir um blobpool esparso para reduzir o uso de memória do pool de transações de blob (#34047)
  • Migrar entradas herdadas do limbo do blobpool para o novo formato sidecar baseado em células na inicialização (#35209)
  • Eliminar suporte para sidecars de blob v0 no blobpool (#35191)
  • Dedução de gás em linha para corrigir uma regressão de desempenho (#35203)
  • Corrigida a decodificação do marcador vazio da lista de acesso ao bloco eth/71 que desconectava os peers incorretamente (#35286)
  • Desative o modo de sincronização instantânea assim que o bloco pivô for confirmado (#35402, #35405)
  • Acelere o debug_setHead e rejeite alvos irrecuperáveis (#35252)
  • Correção de falha de sincronização instantânea ao preencher blocos com mapeamentos de hash canônico ausentes (#35190)
  • Reutilize o cache JUMPDEST da cadeia na construção de carga útil (#35378)
  • Suporte Pebble v2 como back-end do banco de dados (#34009)
  • Suporte a arquivos .ere na loja da era (#34978)
  • Apresente o trie.UpdateBatch API (#32448)
  • Corrigido erro de truncamento do freezer em tabelas vazias recém-adicionadas após desligamento incorreto (#35258)
  • Melhore os relatórios de recuperabilidade do estado considerando o status de sincronização (#35400)
  • Correção da pré-busca de contas ausentes (#35256)
  • Várias correções do snap v2 (#35321, #35323)
  • Otimizar validação de bloco (#35403)
  • Várias melhorias de alocação (#35234, #35237, #35232)
  • Continuar o desenvolvimento da tentativa binária (#34772)
  • Corrigir cálculo do tamanho tx (#35406)

Rede

  • Proteja pares de alto valor contra quedas aleatórias com base em estatísticas de inclusão de transações (#34702)
  • Mantenha nós inválidos e inacessíveis fora das árvores de descoberta de DNS (#35312)
  • Suporte a um ouvinte de descoberta de pilha dupla no devp2p, com diversas correções relacionadas (#35220, #35298, #35243, #35206)

##RPC

  • Introduzir o sinalizador --rpc.http-body-limit para configurar o tamanho máximo do corpo da solicitação HTTP (#35224)
  • Rejeite gasPrice quando combinado com um authorizationList (#35320)
  • Rejeitar um parâmetro de bloco sem número nem hash (#35271)
  • Combine o esquema de autorização sem distinção entre maiúsculas e minúsculas (#35022)

Rastreamento

  • Respeite o limite de log configurado no struct logger (#35349)
  • Emitir quadros de rastreamento no modo EIP-2780 (#35396)
  • Incluir o índice de log na saída do rastreador ERC-7562 (#35200)
  • Pare de capturar incorretamente transferências callcode no rastreador de log (#35248)

##Motor API

  • Passe TargetGasLimit pelo motor API (#35372)
  • Torne configurável a profundidade máxima de reorganização (#35335, #35373, #35391)
  • Retornar listas de acesso de bloqueio de engine_getPayloadBodiesV2 (#35347)
  • Limite o MaxBlobsPerBlock configurado pelo minerador ao limite do protocolo (#35295)

Obter e ferramentas

  • Introduza um sinalizador --gogc e aumente o GOGC padrão para 50 (#35363, #34851)
  • Escreva listas de acesso em nível de bloco em geth export (#35369)
  • Preservar valores de tags de métricas contendo = (#35168)
  • Atualizar testes de enguias para v20.0.0 (#35283)

Contas e ABI

  • Encaminhar o limite de taxa do blob para assinantes externos (#35167)
  • Introduzir um método GetABI() nas vinculações de contrato geradas pelo abigen v2 (#35221)
  • Corrigir ligações do abigen v1 para lidar com a implantação de dependências de biblioteca (#32164)

Construir

  • Atualize a dependência ckzg (#35336)
  • Atualize a versão Go de bootstrap -dlgo para 1.25.12 (#35317)
