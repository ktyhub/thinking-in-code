shardingsphere 5.5.0

Mudança API

  1. Proxy: remova a configuração desatualizada do schemaName do proxy
  2. Kernel: Remova a configuração sqlCommentParseEnabled na regra do analisador SQL para reduzir a complexidade do código
  3. Analisador SQL: Considere remover a configuração sqlCommentParseEnabled na regra SQLParser
  4. Federação: Adicionar configuração allQueryUseSQLFederation para federação sql

Correção de bug

  1. Pipeline: Corrige o trabalho de migração de confirmação/reversão que não elimina o trabalho de verificação de consistência relacionado quando o trabalho de verificação não é concluído
  2. Pipeline: correção da exibição do status da verificação de consistência da exibição stop_time
  3. Proxy: Restaure o nome do banco de dados original em connectionSession após unicast
  4. Proxy: Correção de tabelas de exibição podem ser executadas sem usar banco de dados
  5. Proxy: Corrija o banco de dados atual incorreto após roteamento unicast
  6. Proxy: Corrige o problema de que tabelas de exibição podem ser executadas antes de usar o banco de dados
  7. Divisão de leitura e gravação: corrige exceção de verificação ao usar fonte de dados sombra
  8. Governança: Corrigir problema de bloqueio de thread ao criar banco de dados lógico para centro de registro Etcd
  9. Governança: Corrija unidades de armazenamento de registro e crie falhas de regras de recursos ao usar o modo Standalone
  10. Metadados: Corrige o esquema do sistema de banco de dados que não é construído ao criar o banco de dados
  11. Metadados: Corrigir NPE da regra do construtor de esquema do sistema
  12. Analisador SQL: Corrija PostgreSQL NPE ao analisar columnRef
  13. Analisador SQL: Corrija a causa do npe analisando a instrução de janela de seleção MySQL
  14. Fragmentação: Corrija erro de roteamento ao unir tabelas em letras maiúsculas
  15. Fragmentação: corrige a exceção de eliminação de fragmentação da tabela quando o nome da tabela está em letras maiúsculas
  16. Fragmentação: Corrija a chave gerada com o nome da coluna em maiúsculas
  17. Federação: Corrige a exceção do objeto 'DUAL' não encontrado ao executar a seleção 1 de dual com federação sql
  18. Transação: correção de commit automático xa em executeQuery
  19. Proxy: corrige múltiplas instruções com nome de banco de dados especificado

Aprimoramento

  1. Pipeline: Melhore a estabilidade e o desempenho do CDC
  2. Pipeline: MemoryPipelineChannel suporta tamanho de fila zero configurável para menor consumo de memória
  3. Pipeline: mostra erro dedicado quando o tipo de modo não é Cluster
  4. Autoridade: Adicionar opção isSuper para o usuário
  5. Pipeline: Ignorar mensagem de erro no resultado do status DistSQL no cancelamento do trabalho
  6. DistSQL: Use o formato JSON para gerar adereços em RQL
  7. DistSQL: Otimize a lógica REFRESH DATABASE METADATA
  8. DistSQL: SHOW COMPUTE NODES suporta nós JDBC
  9. DistSQL: Otimize a sintaxe de REFRESH DATABASE METADATA
  10. DistSQL: Otimize a saída de SHOW TABLE METADATA
  11. Proxy: Adicione a verificação de parâmetro pré-compilado MySQL para evitar ativar rewriteBatchedStatements=true quando BenchmarkSQL se conecta ao Proxy, causando uma exceção ArrayIndexOutOfBoundsException quando o parâmetro Proxy excede 65535.
  12. Analisador SQL: Adicionar EOF para lançar exceção ao analisar a instrução de migração de reversão distsql
  13. Analisador SQL: suporta mais análise de instrução plsql e adiciona lógica de afirmação de análise plsql
  14. Analisador SQL: suporte para dica de índice de análise
  15. Analisador SQL: Suporte mysql intersecção combinar operação análise sql
  16. Analisador SQL: Supoort analisa espaço em branco chinês para Oracle
  17. Analisador SQL: Corrigir análise da função mysql TimeStampDiff
  18. Analisador SQL: Corrigir análise abreviada não qualificada do sqlServer
  19. Analisador SQL: Suporta análise de palavras não reservadas sqlServer SEARCH
  20. Analisador SQL: Adicionar palavra não reservada MEMBER do servidor sql
  21. Binder: Adicionar lógica ParameterMarkerSegmentBinder para Oracle MergeStatementBinder
  22. Federação: Suporte à instrução de cross join mysql para federação sql
  23. Transação: Adicionar mensagem de aviso em XATransactionCheckPrivilegeFailedException
  24. Fragmentação: Valide a fragmentação duplicada de nós de dados reais
  25. Fragmentação: suporte ao roteamento de valor de condição nula
  26. Proxy: Corrigir opção de múltiplas instruções mysql client no protocolo

Novo recurso

  1. DistSQL: Nova sintaxe para implementação de plugin de consulta (SPI)
  2. DistSQL: Nova sintaxe para gerenciamento da regra SQL_TRANSLATOR

Refatorar

  1. JDBC: mesclar shardingsphere-jdbc-core com o módulo shardingsphere-jdbc
  2. Proxy: Renomeie server.yaml para global.yaml, configure para o banco de dados e mantenha compatível com a configuração antiga
  3. Proxy: Renomeie config-xxx.yaml para database-xxx.yaml
  4. Proxy: Otimizar a lógica MySQLComStmtPrepareExecutor
  5. Criptografar: refatore a interface de criptografia e adicione metadados do algoritmo de criptografia
  6. Infra: Crie um novo módulo de algoritmo em infra e mova o floco de neve, uuid para este módulo
  7. Infra: Modifique o método unmarshal para retornar um objeto padrão quando yaml estiver vazio
  8. Infra: Otimize a lógica do StandardParameterBuilder
