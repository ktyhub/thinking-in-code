shardingsphere 5.2.1

Novo recurso

  1. Adicione o banco de dados do sistema padrão ShardingSphere para oferecer suporte ao gerenciamento global de metadados
  2. Suporte para verificação de consistência de dados assíncronos
  3. Adicionado suporte para centro de governança Consul
  4. Adicionado suporte para centro de governança Nacos
  5. Adicionado suporte para a função de visualização no centro de governança

Aprimoramento

  1. Mecanismo SQL Federation adiciona executor ADVANCED e se adapta ao banco de dados openGauss
  2. Suporte à inicialização do ShardingSphere Proxy após a divisão de leitura e gravação do banco de dados de leitura ser desativada
  3. SQL HINT suporta rota de fragmentação forçada
  4. Mostrar lista de processos suporta exibição de conexões proxy (suspensas, ativas)
  5. Mensagem de erro de configuração da fonte de dados ShardingSphere-JDBC otimizada
  6. ShardingSphere-JDBC suporta versão SpringBoot 3.x
  7. Suporte para carga de metadados de visualização MySQL, PostgreSQL, openGauss e SQLServer
  8. Atualize Snakeyaml para 1.33 e abra o limite de 3 MB do YAML
  9. Reutilize conexões em cache sempre que possível durante a fragmentação unicast
  10. Suporte à análise de ALTER ROLE no Oracle
  11. Adicionar suporte de ALTER RESOURCE COST para Oracle
  12. Suporte à análise de Drop Materialized View no Oracle
  13. Suporte à análise de DROP LIBRARY no Oracle
  14. Suporte à análise de DROP JAVA no Oracle
  15. Suporte à análise de DROP PLUGGABLE DATABASE no Oracle
  16. Suporte à análise de DROP INDEX TYPE no Oracle
  17. Suporte à análise de ALTER PACKAGE no openGauss
  18. Suporta deslocamento de seleção openGauss, análise de instrução de contagem e remoção de sintaxe inútil na gramática PostgreSQL
  19. Adicione max_size à sintaxe openGauss
  20. Otimize a lógica de análise de alteração de visualização/descarte de visualização e corrija o bug de atualização de alteração de visualização
  21. Adicione detalhes de erro do analisador sql a ParseCancellationException
  22. Adicione suporte para análise OptOnConflict para postgres
  23. Melhor suporte para ALTER TABLE e ALTER VIEW em PostgreSQL
  24. Adicione uma palavra-chave ausente na instrução de declaração PostgreSQL
  25. Adicionar suporte à função json ao analisador mysql
  26. O ShardingSphere-Proxy se adapta automaticamente aos limites de memória do cgroup no ambiente Docker
  27. Mostrar status de migração DistSQL responde nova coluna error_message adicionada
  28. Mostrar status de migração responde nova coluna processed_records_count adicionada
  29. Suporte à autenticação MySQL 8 caching_sha2_password em dump incremental
  30. Melhore a configuração do processo de descarte de pipeline
  31. Apoie a migração de tabelas de chaves exclusivas
  32. Suporte para migração de tabela para nova tabela de nomes
  33. Melhore o uso do pool de threads na tarefa e no executor do pipeline
  34. Suporte para verificação de consistência de dados canceláveis
  35. DistSQL: Ao criar ou alterar a regra de divisão de leitura e gravação, verifique recursos duplicados de gravação ou leitura
  36. DistSQL: Adicionar verificação de validade para ALTER SHARDING BINDING TABLE RULES
  37. O modo autônomo H2 suporta metadados persistentes
  38. Corrija a execução do cursor openGauss na transação xa
  39. Adicionadas exceções relacionadas a transações

Correção de bug

  1. Gere espaço reservado adequado para PostgreSQL ao reescrever
  2. Corrigir exceção de análise do conjunto de atualização opengauss
  3. Corrija a exceção de análise ao executar a instrução de inserção com valor negativo
  4. Corrija connectDescriptorUrlPattern errado em OracleDataSourceMetaData
  5. Corrigir inserção de SQL distorcida após fragmentação reescrita em regras especiais
  6. Corrija a exceção ao executar select * from information_schema.tables
  7. Corrija a exceção ao executar alterar a renomeação da visualização
  8. Correção da permissão da fonte de dados de verificação do PostgreSQL ao usar rolsuper
  9. DistSQL: corrija NPE para REFRESH TABLE METADATA quando não há recurso
  10. Corrija metadados de tabela não modificados ao modificar regras
  11. Corrija a descoberta do banco de dados
  12. O algoritmo MySQL.NORMAL_REPLICATION não consegue encontrar o nó primário"
  13. Corrigido o uso do etcd para construir um evento de cluster não reconhecido
  14. Correção de NPE ocorrido quando o gerenciamento de transações não é criado
  15. Correção da exceção de roteamento que ocorre quando o valor de sharding do algoritmo InlineShardingAlgorithm excede Integer

Mudanças no API

  1. Formato de sintaxe SQL HINT ajustado ao formato estilo SQL
  2. DistSQL: Remover sintaxe COUNT DATABASE RULES
  3. Modo ShardingSphere remove configuração de substituição
  4. Agente: Otimize a configuração do agente.yaml
