shardingsphere 5.5.1

Mudanças no API

  1. Autoridade: marque o provedor de privilégios ALL_PERMITTED como obsoleto e será removido no futuro
  2. DistSQL: Remova o parâmetro opcional UsageCount das unidades de armazenamento de exibição
  3. Divisão de leitura e gravação: altere dataSources para dataSourceGroups para YAML

Novos recursos

  1. Kernel: Adicionar novo módulo de analisador doris, hive e presto sql e tipo de banco de dados

Melhorias

  2. DistSQL: verifique nós de dados reais duplicados ao criar ou alterar a regra da tabela de fragmentação
  3. DistSQL: Adicionar suporte semelhante para unidades de armazenamento de exibição
  4. DistSQL: reversão se a configuração do banco de dados de importação falhou
  5. DistSQL: adicionar tipo de tabela ao conjunto de resultados de mostrar tabelas lógicas
  6. Analisador SQL: Suporta replicação de alterações MySQL sem IDs de servidor
  7. Analisador SQL: Suporta aliases de linha e coluna MySQL com ON DUPLICATE KEY UPDATE
  8. Analisador SQL: Suporte MySQL CALL sql com prefixo mysql
  9. Analisador SQL: Suporte MySQL cria função carregável retorna int/dec
  10. Analisador SQL: Suporte à análise de MySQL CREATE TABLESPACE/TABLE em Mysql-8
  11. Analisador SQL: Suporte à análise de MySQL CREATE INDEX com ENGINE_ATTRIBUTE
  12. Analisador SQL: Suporte à análise de MySQL LOAD DATA com @ variável
  13. Analisador SQL: Suporte à análise da instrução MySQL START REPLICA
  14. Analisador SQL: Suporte à análise da função de tabela MySQL json
  15. Analisador SQL: Adicionar coluna MySQL e não análise SQL nula
  16. Analisador SQL: Adicionar análise SQL do conjunto de caracteres MySQL
  17. Analisador SQL: Melhore o resultado da instrução de visita da função mysql json
  18. Analisador SQL: Suporta palavras-chave PostgreSQL COLLATION e CONSTRAINT
  19. Analisador SQL: Suporte PostgreSQL, tabela de funções openGauss e atualização da análise
  20. Analisador SQL: Suporte CTE com PostgreSQL e openGauss
  21. Analisador SQL: Otimize o suporte de fuso horário de PostgreSQLDateValueParser.
  22. Analisador SQL: Suporta limite PostgreSQL e deslocamento como nulo
  23. Analisador SQL: Aprimore a instrução de atualização do Oracle como análise de alias e adicione caso de teste
  24. Analisador SQL: Suporta análise SQL do tipo de unidade de comprimento de coluna Oracle
  25. Metadados: Colete tipo de tabela para PostgreSQL
  26. Kernel: Suporta extração de dica sql quando sql contém comentário de dica dbeaver
  27. Kernel: Adicionar extração e combinar seleção à esquerda no método extractFromSelectStatementWithoutProjection
  28. Kernel: Adicionar nó assistido para criar e excluir bancos de dados
  29. Transação: use o mesmo tipo de transação em uma transação no adaptador JDBC
  30. Transação: suporte para troca de tipos de transação
  31. Federação SQL: Suporte à função bit_count da federação sql para mysql
  32. Federação SQL: Melhore a função sql atan e anan2 para mysql
  33. Federação SQL: Suporte à função bin de consulta federada mysql
  34. Federação SQL: suporte para operador NOT de consulta federada
  35. Proxy: Faça os resultados das tabelas de exibição em ordem
  36. Proxy: aciona a coleta de metadados ao criar e excluir banco de dados e tabela
  37. Proxy: otimize o agente para oferecer suporte à coleta de dados de métricas de várias fontes de dados quando usado com o Driver
  38. Proxy Native: Adicione mais metadados de acessibilidade graalvm para cache de cafeína
  39. Fragmentação: revise todos os índices locais para tabela de fragmentação e adicione spi de nível de exclusividade do objeto para controlar o gerador de token de índice
  40. Fragmentação: adicione NullsOrderType.LOW e NullsOrderType.HIGH para lidar com a ordem NULL no recurso de fragmentação
  41. Fragmentação: adicionar algoritmos de fragmentação in-line que correspondam à verificação dos nós de dados reais
  42. Criptografar: Adicionar verificação não suportada para instrução combinada com colunas criptografadas
  43. Criptografar: Suporta seleção distinta (coluna), criptografia, reescrita e refatoração da lógica de construção SubstitutableColumnNameToken
  44. Criptografar: suporte como reescrita de instrução concat aninhada concat com recurso de criptografia
  45. Pipeline: Adicione SHARDING_TOTAL_COUNT impl de JobExecutorServiceHandler para melhorar os requisitos principais da CPU
  46. Pipeline: consulta de página de suporte para dumper de inventário e consulta de streaming de consistência de dados
  47. Pipeline: use identificadores que não diferenciam maiúsculas de minúsculas para aprimorar o carregador de metadados da tabela
  48. Pipeline: oferece suporte à ordenação de colunas de chave primária para carregador de metadados de tabela de pipeline padrão
