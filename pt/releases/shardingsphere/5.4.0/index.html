shardingsphere 5.4.0

Mudanças no API

  1. Metadados: Alterar tabelas de transmissão de fragmentação para tabelas de transmissão globais
  2. JDBC: Remova o ponto de exclamação (!) para regras globais
  3. DistSQL: Simplifique as palavras-chave ASSISTED_QUERY, LIKE_QUERY na criptografia do DistSQL
  4. DistSQL: Otimize a sintaxe da regra SQL_PARSER
  5. Criptografar: ajuste a criptografia yaml API para distinguir entre configurações de criptografia, semelhante e consulta assistida
  6. Criptografar: Remova a coluna simples e a configuração queryWithCipherColumn no recurso de criptografia
  7. Divisão de leitura e gravação: refatore a divisão de leitura/gravação api
  8. Proxy: Remover configuração do tipo de instância de proxy de propriedade
  9. Proxy: Remover propriedade proxy-backend-executor-suitable
  10. Proxy: Remover propriedade proxy-mysql-default-version
  11. Dimensionamento: refatore o streaming de reversão de commit para descartar o streaming
  12. Fragmentação: Mesclar ShardingCacheRule em ShardingRule (Experimental)

Novos recursos

  1. DistSQL: Nova sintaxe para gerenciar a regra SQL_FEDERATION
  2. Proxy: suporte para soquete de domínio Unix

Melhorias

  1. Dimensionamento: CDC suporta modo incremental puro
  2. Dimensionamento: CDC suporta exportação de dados por transação
  3. Dimensionamento: CDC suporta MySQL e PostgreSQL
  4. Dimensionamento: CDC suporta tabela única
  5. Dimensionamento: CDC suporta todos os tipos de dados openGauss
  6. Dimensionamento: CDC suporta reconexão de replicação
  7. Dimensionamento: Remover DataConsistencyCalculateAlgorithmChooser
  8. Dimensionamento: melhore o desempenho da divisão de dados de inventário de tabela de chave única inteira
  9. Dimensionamento: ajuste o valor padrão da configuração do processo para reduzir o consumo de recursos
  10. Dimensionamento: atualização automática de metadados da tabela para migração
  11. Dimensionamento: compatível com a reutilização do slot de replicação existente do openGauss quando o banco de dados não existe
  12. Dimensionamento: Mostrar resultado do status da verificação de consistência de dados deve estar vazio quando não for concluído
  13. Dimensionamento: Habilite a correspondência CRC32 simultânea na origem e no destino
  14. Dimensionamento: trabalho de pipeline compatível com estratégia de auditoria de regras de fragmentação
  15. Metadados: refatore a estrutura de persistência de metadados
  16. Metadados: Otimize o processo de carregamento de metadados de tabela única
  17. Metadados: Suporte a consultas vazias de tabelas do sistema MySQL/PostgreSQL/openGauss
  18. DistSQL: Adicionar suporte para transactionalReadQueryStrategy para regra de divisão de leitura/gravação
  19. DistSQL: verificação aprimorada das propriedades do algoritmo
  20. Transação: Adicionar verificação de privilégio
  21. Transação: Remova o TransactionTypeHolder e crie apenas o gerenciador de transações atual
  22. Analisador: Suporta instrução MySQL LOAD DATA e LOAD XML com tabela única ou tabela de transmissão
  23. Analisador: Melhore o suporte à análise de instruções SQL de alta prioridade nos resultados do teste do programa de teste MySQL
  24. Analisador: o analisador de dialeto Oracle agora suporta vírgula chinesa
  25. Criptografar: suporte à consulta da coluna criptografada na subconsulta de projeção ao usar o recurso de criptografia
  26. Kernel: Adiciona verificação de metadados de existência de tabela para instruções INSERT, DELETE, UPDATE e SELECT
  27. JDBC: Implementar execução em lote para ShardingSphereStatement
  28. Proxy: Frontend suporta SSL/TLS
  29. Proxy: mensagem de descarga de suporte para proxy PostgreSQL/openGauss
  30. Proxy: suporte a bit de tipo de dados, bool para proxy PostgreSQL

Correções de bugs

  1. Dimensionamento: corrija a persistência e o uso do status de falha do trabalho do pipeline
  2. Dimensionamento: corrige o evento CDC DELETE Record.beforeList é nulo
  3. Dimensionamento: Corrigir problema de aspas únicas do plug-in de decodificação openGauss mppdb
  4. Dimensionamento: Corrige o mecanismo de execução não fechado após a interrupção do trabalho
  5. Dimensionamento: corrija o trabalho interrompido antes do início da tarefa
  6. Metadados: corrige problema de distinção entre maiúsculas e minúsculas ao carregar metadados de esquema com banco de dados H2
  7. Metadados: Corrija a exceção "objeto não encontrado" ao configurar o nome do esquema PostgreSQL/openGauss como nome do banco de dados
  8. DistSQL: Corrige o resultado errado de check_table_metadata_enabled ao executar SHOW DIST VARIABLE
  9. Criptografar: corrige a exceção de reescrita de SQL ao usar o recurso semelhante à criptografia PostgreSQL/openGauss
  10. Fragmentação: suporte à passagem de condição de fragmentação nula para o algoritmo de fragmentação para permitir que o usuário controle a rota de valor nulo
  11. Analisador: Suporte à análise de expressão ENTRE E na projeção MySQL
  12. Máscara: corrige o resultado errado da máscara ao configurar o mesmo valor de from-x e to-y com KEEP_FROM_X_TO_Y
  13. Infra: Correção de ClassNotFoundException pode ocorrer ao faltar pgjdbc
  14. Proxy: Corrige o pacote MySQL fora de ordem quando client envia solicitações de pipeline
