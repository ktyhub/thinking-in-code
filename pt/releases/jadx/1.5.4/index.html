#jadx v1.5.4

Principais recursos

CLI:

  • Implementar carregamento e salvamento do arquivo de configuração (#1731)

GUI:

  • Altere o tamanho das fontes com zoom da interface do usuário, use o pacote de fontes FlatLaf
  • Use FontUtils.getCompositeFont() que suporta CJK (PR #2751)

Plug-ins:

  • Plugin de script agora externo e não incluído no pacote de lançamento. Verifique jadx-script-kotlin para detalhes de instalação.
  • Suporte a arquivos '.apks' (PR #2647)
  • Permitir usar .zip como artefato de plugin (com jars dentro)
  • Reportar exceções de plugin ao projeto plugin github
