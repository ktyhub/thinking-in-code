Principais recursos

Núcleo:

  • Implementação de leitor zip personalizado para combater adulterações
  • Adicione modelos de exportação Gradle, suporte para Android App/lib e Java simples
  • Suporte inicial para DEX v41 (#2128)

GUI:

  • Adicionar caixa de diálogo de exportação com opções (PR #2378)
  • Uma pesquisa de uso de estrutura em árvore (PR #2498)
  • Adicionar tema de editor de código dinâmico do tema UI (PR #2471)
  • Adicionar recurso de guia de visualização (PR #2474)
  • Novo HexViewer (PR #2469)

Plug-ins:

  • Adicionar suporte APKM (PR #2379)
  • Analisar e usar Kotlin SourceDebugExtension com SMAP para renomear classes e pacotes (PR #2389)

API:

  • Adicionar método 'unload' ao JadxPlugin (#2463)
  • Método para adicionar entrada de menu pop-up para nós de árvore (#2412)
  • Adicionar método para obter ícones jadx-gui por nome
  • Adicionar método para abrir a caixa de diálogo de uso
