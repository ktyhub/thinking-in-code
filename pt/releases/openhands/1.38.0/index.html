nota de instalação do macOS

O aplicativo ainda não está assinado com um Apple Developer ID, então o macOS pode chamar um compilação baixada "danificada" - é a quarentena do Gatekeeper, não um arquivo ruim. Depois de mover o aplicativo para Aplicativos, limpe o sinalizador uma vez e abra normalmente:

xattr -dr com.apple.quarantine "/Applications/OpenHands Agent Canvas.app"

Assinatura + reconhecimento de firma são rastreados em OpenHands/OpenHands#16774.
