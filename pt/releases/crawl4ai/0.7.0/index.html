🚀 Crawl4AI v0.7.0: A atualização de inteligência adaptativa

28 de janeiro de 2025 • 10 min de leitura

Hoje estou lançando Crawl4AI v0.7.0 – a atualização de inteligência adaptativa. Esta versão apresenta melhorias fundamentais na forma como o Crawl4AI lida com a complexidade moderna da web por meio de aprendizagem adaptativa, descoberta inteligente de conteúdo e recursos avançados de extração.

🎯 Resumo das novidades

  • Rastreamento adaptativo: seu rastreador agora aprende e se adapta aos padrões do site
  • Suporte para rolagem virtual: extração completa de conteúdo de páginas de rolagem infinita
  • Visualização de link com pontuação de 3 camadas: análise e priorização inteligente de links
  • Semeador de URL assíncrono: descubra milhares de URLs em segundos com filtragem inteligente
  • Análise de PDF: Extraia dados de documentos PDF
  • Otimizações de desempenho: melhorias significativas de velocidade e memória

🧠 Rastreamento adaptativo: inteligência por meio do aprendizado de padrões

O problema: Os sites mudam. Os nomes das classes mudam. As identidades desaparecem. Seus seletores cuidadosamente elaborados quebram às 3 da manhã e você acorda com conjuntos de dados vazios e partes interessadas irritadas.

Minha solução: implementei um sistema de aprendizagem adaptativo que observa padrões, cria pontuações de confiança e ajusta estratégias de extração dinamicamente. É como ter um desenvolvedor júnior que melhora em seu trabalho a cada página que raspa.

Aprofundamento Técnico

O Adaptive Crawler mantém um estado persistente para cada domínio, rastreando:

  • Taxas de sucesso de padrões
  • Estabilidade do seletor ao longo do tempo
  • Variações na estrutura de conteúdo
  • Pontuações de confiança de extração
from crawl4ai import AdaptiveCrawler, AdaptiveConfig, CrawlState

# Initialize with custom learning parameters
config = AdaptiveConfig(
    confidence_threshold=0.7,    # Min confidence to use learned patterns
    max_history=100,            # Remember last 100 crawls per domain
    learning_rate=0.2,          # How quickly to adapt to changes
    patterns_per_page=3,        # Patterns to learn per page type
    extraction_strategy='css'   # 'css' or 'xpath'
)

adaptive_crawler = AdaptiveCrawler(config)

# First crawl - crawler learns the structure
async with AsyncWebCrawler() as crawler:
    result = await crawler.arun(
        "https://news.example.com/article/12345",
        config=CrawlerRunConfig(
            adaptive_config=config,
            extraction_hints={  # Optional hints to speed up learning
                "title": "article h1",
                "content": "article .body-content"
            }
        )
    )
    
    # Crawler identifies and stores patterns
    if result.success:
        state = adaptive_crawler.get_state("news.example.com")
        print(f"Learned {len(state.patterns)} patterns")
        print(f"Confidence: {state.avg_confidence:.2%}")

# Subsequent crawls - uses learned patterns
result2 = await crawler.arun(
    "https://news.example.com/article/67890",
    config=CrawlerRunConfig(adaptive_config=config)
)
# Automatically extracts using learned patterns!

Impacto esperado no mundo real:

  • Agregação de notícias: mantenha uma precisão de extração de mais de 95%, mesmo quando os sites de notícias atualizam seus modelos
  • Monitoramento de comércio eletrônico: acompanhe alterações de produtos em centenas de lojas sem manutenção constante
  • Coleta de dados de pesquisa: crie conjuntos de dados acadêmicos robustos que sobrevivem a reformulações de sites
  • Manutenção reduzida: reduza o tempo de atualização do seletor em 80% para sites que mudam frequentemente

🌊 Virtual Scroll: captura completa de conteúdo

O problema: Os aplicativos web modernos renderizam apenas o que é visível. Role para baixo, novo conteúdo aparece, conteúdo antigo desaparece no vazio. Os rastreadores tradicionais capturam a primeira janela de visualização e perdem 90% do conteúdo. É como ler apenas a primeira página de cada livro.

Minha solução: desenvolvi suporte para rolagem virtual que imita o comportamento de navegação humano, capturando conteúdo à medida que ele carrega e preservando-o antes que o coletor de lixo do navegador atinja.

Detalhes de implementação

from crawl4ai import VirtualScrollConfig

# For social media feeds (Twitter/X style)
twitter_config = VirtualScrollConfig(
    container_selector="[data-testid='primaryColumn']",
    scroll_count=20,                    # Number of scrolls
    scroll_by="container_height",       # Smart scrolling by container size
    wait_after_scroll=1.0,             # Let content load
    capture_method="incremental",       # Capture new content on each scroll
    deduplicate=True                   # Remove duplicate elements
)

# For e-commerce product grids (Instagram style)
grid_config = VirtualScrollConfig(
    container_selector="main .product-grid",
    scroll_count=30,
    scroll_by=800,                     # Fixed pixel scrolling
    wait_after_scroll=1.5,             # Images need time
    stop_on_no_change=True            # Smart stopping
)

# For news feeds with lazy loading
news_config = VirtualScrollConfig(
    container_selector=".article-feed",
    scroll_count=50,
    scroll_by="page_height",           # Viewport-based scrolling
    wait_after_scroll=0.5,
    wait_for_selector=".article-card",  # Wait for specific elements
    timeout=30000                      # Max 30 seconds total
)

# Use it in your crawl
async with AsyncWebCrawler() as crawler:
    result = await crawler.arun(
        "https://twitter.com/trending",
        config=CrawlerRunConfig(
            virtual_scroll_config=twitter_config,
            # Combine with other features
            extraction_strategy=JsonCssExtractionStrategy({
                "tweets": {
                    "selector": "[data-testid='tweet']",
                    "fields": {
                        "text": {"selector": "[data-testid='tweetText']", "type": "text"},
                        "likes": {"selector": "[data-testid='like']", "type": "text"}
                    }
                }
            })
        )
    )
    
    print(f"Captured {len(result.extracted_content['tweets'])} tweets")

Principais capacidades:

  • DOM Recycling Awareness: detecta e manipula o elemento DOM virtual recycling
  • Smart Scroll Physics: Três modos - altura do contêiner, altura da página ou pixels fixos
  • Preservação de conteúdo: captura conteúdo antes de ser destruído
  • Parada inteligente: para quando nenhum conteúdo novo aparece
  • Memória Eficiente: Transmite conteúdo em vez de manter tudo na memória

Impacto esperado no mundo real:

  • Análise de mídia social: capture tópicos inteiros do Twitter com centenas de respostas, não apenas as 10 principais
  • E-commerce Scraping: Extraia mais de 500 produtos de catálogos de rolagem infinita versus 20-50 com métodos tradicionais
  • Agregação de notícias: obtenha todos os artigos de sites de notícias modernos, não apenas o conteúdo acima da dobra
  • Aplicativos de pesquisa: Extração completa de dados de bancos de dados acadêmicos usando paginação virtual

🔗 Visualização de link: análise e pontuação inteligente de link

O problema: Você rastreia uma página e obtém 200 links. Quais são importantes? O que leva ao conteúdo que você realmente deseja? Os rastreadores tradicionais forçam você a seguir tudo ou a construir filtros complexos.

Minha solução: implementei um sistema de pontuação de três camadas que analisa links como um ser humano faria, considerando sua posição, contexto e relevância para seus objetivos.

O sistema de pontuação de três camadas

from crawl4ai import LinkPreviewConfig

# Configure intelligent link analysis
link_config = LinkPreviewConfig(
    # What to analyze
    include_internal=True,
    include_external=True,
    max_links=100,              # Analyze top 100 links
    
    # Relevance scoring
    query="machine learning tutorials",  # Your interest
    score_threshold=0.3,        # Minimum relevance score
    
    # Performance
    concurrent_requests=10,     # Parallel processing
    timeout_per_link=5000,      # 5s per link
    
    # Advanced scoring weights
    scoring_weights={
        "intrinsic": 0.3,       # Link quality indicators
        "contextual": 0.5,      # Relevance to query
        "popularity": 0.2       # Link prominence
    }
)

# Use in your crawl
result = await crawler.arun(
    "https://tech-blog.example.com",
    config=CrawlerRunConfig(
        link_preview_config=link_config,
        score_links=True
    )
)

# Access scored and sorted links
for link in result.links["internal"][:10]:  # Top 10 internal links
    print(f"Score: {link['total_score']:.3f}")
    print(f"  Intrinsic: {link['intrinsic_score']:.1f}/10")  # Position, attributes
    print(f"  Contextual: {link['contextual_score']:.1f}/1")  # Relevance to query
    print(f"  URL: {link['href']}")
    print(f"  Title: {link['head_data']['title']}")
    print(f"  Description: {link['head_data']['meta']['description'][:100]}...")

Componentes de pontuação:

  1. Pontuação intrínseca (0-10): com base em indicadores de qualidade do link

    • Posição na página (navegação, conteúdo, rodapé)
    • Atributos de link (rel, título, nomes de classes)
    • Qualidade e comprimento do texto âncora
    • Estrutura e profundidade do URL

  2. Pontuação Contextual (0-1): Relevância para sua consulta

    • Similaridade semântica usando embeddings
    • Correspondência de palavras-chave no texto e no título do link
    • Análise de meta descrição
    • Pontuação de visualização de conteúdo

  3. Pontuação Total: Combinação ponderada para classificação final

Impacto esperado no mundo real:

  • Eficiência de pesquisa: encontre artigos relevantes 10 vezes mais rápido seguindo apenas links com pontuação alta
  • Análise Competitiva: identifique automaticamente páginas importantes em sites concorrentes
  • Descoberta de conteúdo: crie rastreadores focados em tópicos que permaneçam no caminho certo
  • Auditorias de SEO: identifique e priorize oportunidades de links internos de alto valor

🎣 Semeador de URL assíncrono: descoberta automatizada de URL em escala

O problema: você deseja rastrear um domínio inteiro, mas só tem a página inicial. Ou pior, você deseja tipos de conteúdo específicos em milhares de páginas. Descoberta manual de URL? Esse é um trabalho para máquinas, não para humanos.

Minha solução: criei o Async URL Seeder, um mecanismo turbinado de descoberta de URL que combina diversas fontes com filtragem inteligente e pontuação de relevância.

Arquitetura Técnica

from crawl4ai import AsyncUrlSeeder, SeedingConfig

# Basic discovery - find all product pages
seeder_config = SeedingConfig(
    # Discovery sources
    source="sitemap+cc",        # Sitemap + Common Crawl
    
    # Filtering
    pattern="*/product/*",      # URL pattern matching
    ignore_patterns=["*/reviews/*", "*/questions/*"],
    
    # Validation
    live_check=True,           # Verify URLs are alive
    max_urls=5000,             # Stop at 5000 URLs
    
    # Performance  
    concurrency=100,           # Parallel requests
    hits_per_sec=10           # Rate limiting
)

seeder = AsyncUrlSeeder(seeder_config)
urls = await seeder.discover("https://shop.example.com")

# Advanced: Relevance-based discovery
research_config = SeedingConfig(
    source="crawl+sitemap",    # Deep crawl + sitemap
    pattern="*/blog/*",        # Blog posts only
    
    # Content relevance
    extract_head=True,         # Get meta tags
    query="quantum computing tutorials",
    scoring_method="bm25",     # Or "semantic" (coming soon)
    score_threshold=0.4,       # High relevance only
    
    # Smart filtering
    filter_nonsense_urls=True,  # Remove .xml, .txt, etc.
    min_content_length=500,     # Skip thin content
    
    force=True                 # Bypass cache
)

# Discover with progress tracking
discovered = []
async for batch in seeder.discover_iter("https://physics-blog.com", research_config):
    discovered.extend(batch)
    print(f"Found {len(discovered)} relevant URLs so far...")

# Results include scores and metadata
for url_data in discovered[:5]:
    print(f"URL: {url_data['url']}")
    print(f"Score: {url_data['score']:.3f}")
    print(f"Title: {url_data['title']}")

Métodos de descoberta:

  • Mineração de Sitemap: analisa robots.txt e todos os sitemaps vinculados
  • Rastreamento comum: consulta o índice de rastreamento comum para URLs históricos
  • Rastreamento inteligente: segue links com controle de profundidade inteligente
  • Análise de padrões: aprende estruturas de URL e gera variações

Impacto esperado no mundo real:

  • Projetos de migração: descubra mais de 10.000 URLs de sites legados em menos de 60 segundos
  • Pesquisa de mercado: mapeie ecossistemas concorrentes inteiros automaticamente
  • Pesquisa acadêmica: crie conjuntos de dados abrangentes sem coleta manual de URLs
  • Auditorias de SEO: Encontre todas as páginas indexáveis com pontuação de conteúdo
  • Arquivamento de conteúdo: garanta que nenhum conteúdo seja deixado para trás durante as migrações de sites

⚡ Otimizações de desempenho

Esta versão inclui melhorias significativas de desempenho por meio de manipulação otimizada de recursos, melhor gerenciamento de simultaneidade e redução do consumo de memória.

O que otimizamos

# Before v0.7.0 (slow)
results = []
for url in urls:
    result = await crawler.arun(url)
    results.append(result)

# After v0.7.0 (fast)
# Automatic batching and connection pooling
results = await crawler.arun_batch(
    urls,
    config=CrawlerRunConfig(
        # New performance options
        batch_size=10,              # Process 10 URLs concurrently
        reuse_browser=True,         # Keep browser warm
        eager_loading=False,        # Load only what's needed
        streaming_extraction=True,  # Stream large extractions
        
        # Optimized defaults
        wait_until="domcontentloaded",  # Faster than networkidle
        exclude_external_resources=True, # Skip third-party assets
        block_ads=True                  # Ad blocking built-in
    )
)

# Memory-efficient streaming for large crawls
async for result in crawler.arun_stream(large_url_list):
    # Process results as they complete
    await process_result(result)
    # Memory is freed after each iteration

Ganhos de desempenho:

  • Tempo de inicialização: inicialização do navegador 70% mais rápida
  • Carregamento de página: redução de 40% com bloqueio inteligente de recursos
  • Extração: 3x mais rápido com seletores CSS compilados
  • Uso de memória: redução de 60% com processamento de streaming
  • Rastreamentos simultâneos: processe 5x mais solicitações paralelas

📄 Suporte para PDF

A extração de PDF agora é suportada nativamente no Crawl4AI.

# Extract data from PDF documents
result = await crawler.arun(
    "https://example.com/report.pdf",
    config=CrawlerRunConfig(
        pdf_extraction=True,
        extraction_strategy=JsonCssExtractionStrategy({
            # Works on converted PDF structure
            "title": {"selector": "h1", "type": "text"},
            "sections": {"selector": "h2", "type": "list"}
        })
    )
)

🔧 Mudanças importantes

Mudanças importantes

  • link_extractor renomeado para link_preview (reflete melhor a funcionalidade)
  • Versão mínima Python agora 3.9
  • CrawlerConfig dividido em CrawlerRunConfig e BrowserConfig

Guia de migração

# Old (v0.6.x)
from crawl4ai import CrawlerConfig
config = CrawlerConfig(timeout=30000)

# New (v0.7.0)
from crawl4ai import CrawlerRunConfig, BrowserConfig
browser_config = BrowserConfig(timeout=30000)
run_config = CrawlerRunConfig(cache_mode=CacheMode.BYPASS)
