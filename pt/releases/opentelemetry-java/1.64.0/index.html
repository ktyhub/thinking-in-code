opentelemetry-java v1.64.0

###API

  • Correção de W3CBaggagePropagator para permitir valores de bagagem vazia de acordo com as especificações W3C (#8468)
  • Correção da análise de bagagem para membros com codificação percentual inválida (#8480)

Incubando

  • QUEBRA Remover InstrumentationConfigUtil.peerServiceMapping obsoleto (#8542)
  • Correção de EnvironmentGetter/EnvironmentSetter para não enumerar ou normalizar entradas de operadora e normalizar nomes vazios de forma consistente (#8474, #8481)

###SDK

Traços

  • Adicione a fábrica de conveniência BatchSpanProcessor.create(SpanExporter) para espelhar SimpleSpanProcessor.create(SpanExporter) (#8564)
  • Correção dos contadores auxiliares de benchmark BatchSpanProcessor (exportedSpans/droppedSpans) sempre reportando zero (#8539)

Métricas

  • Correção de PooledHashMap descartando entradas ativas quando uma entrada é removida durante forEach (#8499)
  • Inicialize com segurança o armazenamento de reservatório exemplar em FixedSizeExemplarReservoir (#8524)
  • Use failExceptionally em PeriodicMetricReader quando o exportador estiver ocupado (#8525)
  • Somente configure valuesRecorded em AggregatorHandle quando for falso (#8559)
  • Use volatile em vez de átomos em Double/LongLastValueAggregator (#8560)
  • Randomize a ordem de gravação por thread em benchmarks métricos para evitar pontos de acesso simultâneo (#8550)

Registros

  • Correção do thread de trabalho BatchLogRecordProcessor sendo eliminado por exceções fora do tempo de execução (#8529)

Exportadores

  • QUEBRA Prometheus: Eliminar construtores PrometheusMetricReader obsoletos (#8541)
  • OTLP: rejeita endpoints sem host em EndpointUtil.validateEndpoint (#8489)
  • OTLP: Substitua a serialização Jackson OTLP JSON por uma implementação manual (#8545)
  • Perfis OTLP: Corrija o nome da classe OtlpGrpcProfileExporter toString (#8492)
  • Prometheus: Adicionar suporte à estratégia de tradução (#8346)
  • Prometheus: Corrige a serialização de escopo com valor de array e atributos de recurso para strings JSON (#8497)

Extensões

  • QUEBRA Configuração declarativa: mover tipos experimentais para pacote interno (#8530)
  • Configuração declarativa: Confirme POJOs de esquema gerados para git (#8408)
  • Configuração declarativa: Atualização para opentelemetry-configuration v1.1.0 (#8451)
  • Configuração declarativa: ajuste POJO toString/hashCode/equals para corresponder à semântica do AutoValue (#8526)
  • Configuração declarativa: adicione descrições de referência às classes de modelo geradas (#8540)
  • Configuração declarativa: Emite anotações @JsonProperty consistentes em modelos gerados (#8563)
  • Configuração declarativa: Remover resolvedor duplicado em DeclarativeConfigPropertyUtil (#8579)

Ferramentas de projeto

  • Adicionar orientação sobre política de configuração (#8429)
  • Excluir certas ações do GitHub da execução em garfos (#8466)
  • Adicione orientação para preferir testes parametrizados (#8469)
  • Torne o caminho de benchmark configurável (#8557)
