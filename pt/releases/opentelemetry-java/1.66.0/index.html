opentelemetry-java v1.66.0

###API

  • Correção de Baggage.fromContext() e Baggage.fromContextOrNull() para lidar com um contexto null (#8667)
  • Não codifique metadados de bagagem W3C por porcentagem (#8682)
  • Correção de ArrayIndexOutOfBoundsException em OtelEncodingUtils para caracteres hexadecimais inválidos (#8748)

###SDK

Traços

  • Registre os intervalos processados antes da conclusão da exportação e rejeite novos intervalos no desligamento na instrumentação de auto-observabilidade SpanProcessor (#8735)

Métricas

  • Melhorar o desempenho explícito da contenção do histograma do bucket (#8717)

Registros

  • Registre os logs processados antes da conclusão da exportação e rejeite novos logs no desligamento na instrumentação de auto-observabilidade LogRecordProcessor (#8698)

Exportadores

  • OTLP: Respeite Retry-After em remetentes HTTP OTLP (#8633)
  • OTLP: Adicionar opção setEnabledProtocols aos construtores exportadores HTTP OTLP (#8610)
  • OTLP: Rejeita a mistura de keyManager e sslContext em TlsConfigHelper (#8710)
  • OTLP: correção do mTLS OkHttpGrpcSender ao usar o armazenamento trust padrão da plataforma (#8758)
  • OTLP: Suprime instrumentação de solicitações de exportador em JdkHttpSender (#8757)
  • OTLP: aceita nomes de host RFC 1123 em EndpointUtil.validateEndpoint para remetentes OkHttp (#8746)
  • OTLP: Inclui o número de itens afetados no registro de erros do exportador (#8780)
  • OTLP: Adicione toString a OtlpJsonLogging{Span,Metric,LogRecord}Exporter (#8725)
  • Perfis OTLP: melhore o exemplo de exportação JFR e alinhe o tratamento de elementos nulos LinkData com a especificação (#8349)
  • Prometheus: Remover aviso de log de host padrão em PrometheusHttpServerBuilder (#8679)
  • Prometheus: Alinhe as conversões de unidades de byte UCUM com a tabela de especificações (#8752)

Extensões

  • QUEBRA Configuração declarativa: Renomeie os setters POJO do modelo gerado de with<Prop> para set<Prop> (#8742)
  • Configuração declarativa: Resolva propriedades experimentais em APIs estáveis em POJOs de modelo gerado (#8654)
  • Configuração declarativa: corrige sinalizadores scope_info_enabled e target_info_enabled invertidos no provedor de componentes Prometheus (#8750)
  • Configuração declarativa: Suporte output_stream em otlp_file/development (#8676)
  • Incubadora: Adicione toString a ComposableAnnotatingSampler (#8645)

Ferramentas de projeto

  • Corrigir descobertas de zizmor em fluxos de trabalho de ações GitHub (#8592)
