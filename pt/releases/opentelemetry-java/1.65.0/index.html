opentelemetry-java v1.65.0

NOTA: O artefato opentelemetry-exporter-zipkin parou de ser publicado. Ele foi descontinuado em uma versão anterior. Os usuários devem migrar para OTLP ou usar um coletor exportador compatível com Zipkin.

###API

  • Ignore chaves de bagagem vazias em ImmutableBaggage.put (#8658)
  • Use NumberFormatException no decodificador de bagagem (#8593)
  • Corrigido TraceStateBuilder.remove corrompendo o construtor quando a mesma chave é removida duas vezes (#8613)

Incubando

  • Adicione APIs do instrumento vinculado (BoundLongCounter, BoundDoubleCounter, BoundLongHistogram, BoundDoubleHistogram, BoundLongUpDownCounter, BoundDoubleUpDownCounter, BoundLongGauge, BoundDoubleGauge) às métricas da incubadora API (#8527)

Extensões

  • Propagadores de rastreamento: correção da sensibilidade de maiúsculas e minúsculas da chave do cabeçalho de bagagem JaegerPropagator (#8496)
  • Propagadores de rastreamento: não substitua a bagagem existente por bagagem vazia em JaegerPropagator (#8632)
  • Propagadores de rastreamento: ignoram chaves de bagagem vazias na extração OtTracePropagator (#8631)
  • Propagadores de rastreamento: param de analisar um cabeçalho jaeger-baggage após 64 tokens, incluindo tokens malformados (#8702)

###SDK

  • Atualize a implementação dos atributos SDK (AttributesMap) para impor a semântica de ganho de último valor com base no valor da string de AttributeKey.getKey() (#8548)

Traços

  • Adicionado ciclo de vida de desligamento do Sampler: Sampler agora estende o Closeable e expõe um shutdown() padrão invocado quando o SdkTracerProvider é desligado; JaegerRemoteSampler o implementa para parar seu executor de polling (#8574)

Métricas

  • Gate PeriodicMetricReader métricas de auto-observabilidade por versão de telemetria interna (#8597)
  • Grave error.type em coletas com falha em PeriodicMetricReader (#8650)
  • Teste: correção de LongExemplarAssert.hasFilteredAttributesSatisfyingExactly para impor correspondência exata de atributos (#8518)

Registros

  • Corrigido o padrão ReadWriteLogRecord getObservedTimestampEpochNanos retornando o timestamp do registro (#8504)

Perfis

  • Correção do nome do parâmetro de contagem de atributos do modelo de dados de perfis e unidade de documento de carimbo de data/hora (#8514)

Exportadores

  • AVISO Zipkin: Exclua opentelemetry-exporter-zipkin; o artefato não está mais publicado (#8677)
  • OTLP: Use corpos de resposta de erro HTTP em logs de aviso HttpExporter (#8428)
  • OTLP: correção do mTLS OkHttpHttpSender ao usar o armazenamento trust padrão da plataforma (#8565)
  • OTLP: Corrige extensão de sinal em sinalizadores LogRecord no empacotador de log de baixa alocação (#8493)
  • OTLP: Padronize o desligamento de OkHttpHttpSender, JdkHttpSender e UpstreamGrpcSender para aguardar o encerramento do executor/canal (#8495, #8627, #8624)
  • OTLP: registra a exceção/íon subjacente quando um quadro de resposta gRPC é inválido (#8626)
  • OTLP: Evite o codificador de string inseguro no Android (#8637)
  • Prometheus: Mesclar valores de rótulo Prometheus em colisão (#8364)
  • Prometheus: Corrige PrometheusHttpServer.toBuilder() eliminando o manipulador padrão configurado (#8619)
  • Registro: nome do evento de saída em SystemOutLogRecordExporter (#8609)
  • Registro: Inclui temporalidade de agregação em LoggingMetricExporter toString (#8623)

Extensões

  • Configuração automática: evite expor valores de configuração em mensagens de erro (#8669)
  • Configuração declarativa: correção da configuração do intervalo de pesquisa do amostrador Jaeger (#8668)
  • Configuração declarativa: Remova o resolvedor getStringList duplicado em DeclarativeConfigPropertyUtil (#8572)
  • Configuração declarativa: Substitua jsonschema2pojo por um gerador POJO enrolado à mão (#8600)
  • Incubadora: Restaure a conformidade entre o código dos amostradores compostos e as especificações (#8450)

Calços

  • DEPRECAÇÃO Descontinuar o shim público do OpenCensus API (#8674)
  • OpenCensus: preserva a descrição do status do OpenCensus ao converter para OpenTelemetry (#8511)
  • OpenCensus: Adicione links ao intervalo OpenTelemetry em vez de registrar um aviso e descartá-los (#8635)
  • OpenTracing: Retorna null da extração TracerShim quando a operadora não tem contexto de span (#8505)
  • OpenTracing: Retorna o SpanContext extraído quando ele é amostrado, mas inválido (#8634)

Ferramentas de projeto

  • Fixe a linha de base japicmp em version.gradle.kts (#8591)
  • Atualize o guia de contribuição em resposta ao feedback (#8655)
