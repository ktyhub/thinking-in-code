#mlflow v3.15.0

MLflow 3.15.0 inclui vários recursos e melhorias importantes

Principais novos recursos

  • 🧩 Registro MCP: um catálogo centralizado para registro, controle de versão e compartilhamento de servidores Model Context Protocol — com configurações com versão semântica, aliases promovíveis, tags, ferramentas descobertas automaticamente e instruções de conexão prontas para Claude Code e .mcp.json. Gerencie-o a partir da UI, REST API ou Python!
  • 🤖 Melhorias no MLflow Assistant: O assistente de IA no aplicativo agora oferece suporte a vários provedores LLM (Claude Code, Codex e endpoints compatíveis com OpenAI/Gateway) escolhidos em uma única página de configurações, exibe o uso de token por sessão ao vivo e o custo estimado no compositor e é mais fácil de configurar - mlflow agent setup pode habilitá-lo em um prompt, com chaves API armazenadas com segurança nas conexões LLM do Gateway.
  • 🗂️ Visualizações de tabela compartilháveis: salve visualizações nomeadas da tabela Runs — capturando colunas, ordem, larguras, filtros e classificação — e compartilhe-as por URL.
  • ⚡ Upload/download de artefatos sem proxy por meio de URLs predefinidos: Grandes transferências de artefatos agora podem ignorar o servidor de rastreamento e se comunicar diretamente com o armazenamento em nuvem (por exemplo, S3) por meio de URLs predefinidos, reduzindo a carga do servidor e os tempos limite em arquivos grandes. Voltamos à transferência por proxy automaticamente para compatibilidade com versões anteriores.
  • **🖼️ Anexos multimodais em juízes LLM **: os juízes {{ trace }} criados com make_judge() agora podem ver imagens capturadas em extensões de rastreamento por meio de uma nova ferramenta get_span_image, que busca anexos como URLs de dados base64 e os passa para modelos multimodais (compatível com Antrópico, Gemini e OpenAI via litellm) - permitindo a avaliação de tarefas de visão, capturas de tela e outros conteúdos visuais.
