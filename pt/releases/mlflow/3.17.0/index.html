#mlflow v3.17.0

MLflow 3.17.0 inclui vários recursos e melhorias importantes.

Principais novos recursos

  • Jev Decisions Across Evaluation, Gateway, and Tracing: Use modelos TypeSafe em marcadores integrados e juízes personalizados com feedback booleano ou categórico digitado. (#26100, @B-Etapa 62)
  • Permissões refinadas para recursos compartilhados: controle o acesso a tipos de recursos contidos, incluindo execuções, rastreios e versões, com concessões de curinga e DENY explícito. (#26157, @rrrkharse)
  • Análise mais rápida para grandes conjuntos de dados de rastreamento: reduza a sobrecarga de consulta de análise SQL com resumos diários opcionais e reserva de consulta bruta. (#25991, @HumairAK)
  • Resultados de avaliação mais claros: associe métricas agregadas de avaliação de modelo registrado ao conjunto de dados gerenciado que as produziu. (#25927, @joshuawong-db)
  • Melhorias do Assistente para servidores compartilhados: Mantenha as conversas salvas com escopo para o usuário conectado e redefina a sessão ativa quando as contas mudarem. (#26009, @kriscon-db)

Atualização de banco de dados: servidores com suporte SQL exigem uma atualização de esquema coordenada com todos os gravadores parados e um backup restaurável, mesmo quando os rollups diários permanecem desabilitados. Execute mlflow db upgrade <database-url> antes de reiniciar todas as réplicas na nova versão do MLflow. Atualizações contínuas de versões mistas não são suportadas. Siga as instruções de atualização do banco de dados.
