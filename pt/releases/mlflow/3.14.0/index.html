mlflow v3.14.0

MLflow 3.14.0 inclui vários recursos e melhorias importantes

Principais novos recursos

  • 🚀 integração de agente de um comando com mlflow agent setup: Instale o MLflow, configure o rastreamento e entregue ao seu agente de codificação favorito (Claude Code, OpenAI Codex ou OpenCode) as habilidades do MLflow para instrumentar seu aplicativo, tudo a partir de um único comando.
  • ⚡ Rastreamento durável e de baixa latência para Claude Code: implemente o rastreamento de Claude Code em uma equipe com confiança: um registro write-ahead evita que ele deixe o agente lento, sobrecarregue o servidor de rastreamento ou perca rastreamentos em uma falha ou falha na rede.
  • 📝 Filas de revisão para rastreamentos: atribua rastreamentos a revisores (ou agentes) e colete feedback estruturado e anotações verdadeiras na interface do usuário, escritas diretamente no rastreamento para que possam ser imediatamente utilizadas para avaliação.
  • 🗂️ IU do conjunto de dados de avaliação renovada: navegue, inspecione, edite e gerencie registros do conjunto de dados de avaliação em massa diretamente na IU, com click-through até o rastreamento de origem.
  • 🧪 Integração Pytest para testes de regressão: Escreva testes de regressão GenAI como funções pytest simples com o marcador @mlflow.test, bloqueie-os no CI e revise o histórico de testes e os resultados do juiz por asserção na IU.
  • 🎛️ LLM Playground: Itere os prompts no navegador em relação aos endpoints do AI Gateway e às versões do Prompt Registry, com configurações, ferramentas, saída estruturada e variáveis ​​de modelo.
