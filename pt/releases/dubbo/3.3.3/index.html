O que mudou

Notável

  • Dubbo removeu a dependência dubbo-dependencies-zookeeper-curator5 e dubbo-zookeeper-spring-boot-starter， A dependência de zk é fornecida apenas em dubpo-zookeeper-curator5-spring-boot-starter. Portanto, você pode usar dubpo-zookeeper-curator5-spring-boot-starter para substituir as duas dependências anteriores.
