indolente v0.1.911-beta

Esta versão adiciona tarefas agendadas, suporte para edição FLUX-3, melhorias de desempenho e muito mais. Também novo: MiniMax-M3.1-Flash, retoques faciais para imagens e desempenho mais rápido + chats no Mac.

Destaques

  • Tarefas agendadas: Execute um prompt em um agendamento com um modelo local ou um API
  • MiniMax-M3.1-Flash: 428B MoE do MiniMax (23B ativo) Guia
  • Edição FLUX 3: FLUX 3 agora suporta edição de imagens com prompts
  • Melhorias de desempenho: Grandes ganhos de desempenho do Mac, menos atraso, tamanhos binários reduzidos
  • Predefinições salvas: salve suas configurações de corrida como predefinições nomeadas para cada modelo

Tarefas agendadas

  • Abra Agendado no menu Mais da barra lateral para executar um prompt uma vez, diariamente, durante a semana, semanalmente ou mensalmente; cada resposta é salva como um novo bate-papo.
  • Cada tarefa pode ser executada no modelo carregado, em um modelo em seu dispositivo ou em um modelo de um provedor API conectado.
  • Quando o modelo de uma tarefa não está carregado, o Unsloth pergunta antes de carregá-lo, a menos que você ative Alternar automaticamente quando eu estiver ausente.
  • Cada tarefa pode notificá-lo após cada execução, somente quando falha ou nunca.
  • As tarefas são executadas apenas enquanto o Unsloth está em execução, sem ferramentas ou pesquisa na web.

UI + UX

  • Salve as configurações de execução no seletor de modelos como predefinições nomeadas para cada modelo e depois renomeie, exclua ou alterne entre elas.
  • A predefinição que você escolheu por último é a que o modelo carregará na próxima vez, incluindo carregamentos através do API.
  • As configurações de bate-papo podem lembrar as configurações de amostragem de um modelo ou redefini-las para os valores recomendados do modelo.
  • Os bate-papos do GGUF agora mostram o progresso e o tempo restante durante o processamento de um prompt longo, antes do início da resposta.
  • A página API agora mostra o uso de contexto, velocidade e contagem de solicitações de cada modelo atendido.
  • Cada tipo de botão e ícone agora tem a mesma aparência em qualquer lugar do aplicativo.
  • As páginas Biblioteca e Sistema em Configurações mostram o armazenamento como uma barra de uso, dividida em modelos, caches e espaço livre.

##Mac

  • Os chats MLX agora respondem até 16% mais rápido com modelos de rascunho.
  • Os modelos MLX que vêm com um modelo de rascunho integrado agora o utilizam automaticamente, sem download separado.
  • As renderizações de imagens e vídeos precisam de muito menos memória no final, portanto, os Macs com pouca memória raramente ficam lentos na troca.
  • No Apple Silicon, os Z-Image GGUFs agora criam imagens de texto com o mecanismo MLX por padrão, 1.5-2x mais rápido do que antes.

Imagens + vídeo

  • Faça vídeos a partir de texto ou imagem com o Cosmos3-Edge da NVIDIA na página Vídeo.
  • Na página Imagens, ative o Detalhe para redesenhar rostos, mãos ou outras coisas que você nomear em maior resolução; precisa do SAM 3 e de um modelo que possa ser pintado. Em GPUs NVIDIA anteriores à série RTX 30, Wan2.1 1.3B texto para vídeo clips renderiza cerca de 5x mais rápido.
  • Nas GPUs NVIDIA, muitos modelos de imagem e vídeo carregam mais rápido após a primeira vez, já que o Unsloth salva a versão que cria no primeiro carregamento.
  • FLUX.3 Klein agora pode editar fotos em Imagens > Editar, mantendo as dimensões da foto.

Treinamento

  • Divida cada camada de um modelo entre GPUs para treinamento LoRA e QLoRA, para que cada GPU contenha menos: defina UNSLOTH_TP_SIZE como o número de GPUs e inicie com torchrun.
  • O ajuste fino dos pontos de verificação gpt-oss de 4 bits do Unsloth não trava mais na primeira etapa de treinamento.
  • GRPO gerado com vLLM é executado até 1,9x mais rápido por etapa com LoRA de 16 bits no Linux com GPUs NVIDIA.
  • GRPO gerado sem vLLM é executado até 4,4x mais rápido por etapa para Llama e Qwen3 em GPUs NVIDIA.

Agentes de codificação + API

  • Aplicativos que usam uma chave Unsloth API não podem mais aprovar suas próprias chamadas Python ou de terminal para serem executadas fora da sandbox.
  • Unsloth não encaminha mais IPs client por padrão; atrás de seu próprio proxy reverso, defina UNSLOTH_STUDIO_TRUST_FORWARDED=1 ou todos os usuários compartilham um limite de taxa de login.

Modelos + hardware

  • Execute o MiniMax-M3.1-Flash, o modelo MoE do MiniMax para codificação, uso de ferramentas e fluxos de trabalho de agentes, com até 1 milhão de tokens de contexto. GGUF
  • De 1 bit, o MiniMax-M3.1-Flash precisa de pelo menos 130 GB de RAM e VRAM combinados.
  • Em alguns PCs com Windows, os modelos GGUF carregam novamente em vez de falhar todas as vezes com "llama-server failed to start".
