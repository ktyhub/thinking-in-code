pulsar v4.0.10

####2026-04-27

Aviso de atualização

Esta versão atualiza o Jetty de 9.4.x para 12.1.8 para resolver vários CVEs de alta gravidade no Jetty 9.4.x (#25534). Para informações básicas e discussão, consulte o tópico da lista de desenvolvedores.

A atualização introduz as seguintes alterações importantes:

  1. Alteração da interface AdditionalServlet. A interface org.apache.pulsar.broker.web.plugin.servlet.AdditionalServlet foi acoplada diretamente à classe Jetty 9 org.eclipse.jetty.servlet.ServletHolder. Este acoplamento foi removido, portanto as implementações externas deste plugin API precisam ser atualizadas.

  2. A autenticação Athenz requer Java 17+. pulsar-client-auth-athenz agora depende do Jetty e, portanto, requer Java 17+. O Pulsar Client e o Pulsar Admin client permanecem compatíveis com Java 8+.

  3. Relocação da classe do provedor de métricas Prometheus. As classes de provedor de métricas padrão Prometheus para BookKeeper e ZooKeeper foram substituídas porque os padrões anteriores dependiam do Jetty 9.4.x. Se você estiver usando o arquivo de configuração padrão anterior em sua implantação, atualize as seguintes configurações:

    | Arquivo de configuração | Configuração | Valor antigo | Novo valor | | --- | --- | --- | --- | | bookkeeper.conf | statsProviderClass | org.apache.bookkeeper.stats.prometheus.PrometheusMetricsProvider | org.apache.pulsar.metrics.prometheus.bookkeeper.PrometheusMetricsProvider | | zookeeper.conf | metricsProvider.className | org.apache.zookeeper.metrics.prometheus.PrometheusMetricsProvider | org.apache.pulsar.metrics.prometheus.zookeeper.PrometheusMetricsProvider |

Os usuários do gráfico Apache Pulsar Helm anteriores à versão 4.6.0 precisarão definir a chave bookie.configData.statsProviderClass como org.apache.pulsar.metrics.prometheus.bookkeeper.PrometheusMetricsProvider:

bookie:
  configData:
    statsProviderClass: "org.apache.pulsar.metrics.prometheus.bookkeeper.PrometheusMetricsProvider"
