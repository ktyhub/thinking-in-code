  • [Break] Mudanças significativas em relação ao v5.6.0:
  • O tema padrão foi alterado, incluindo o estilo visual e as configurações de localização padrão de componentes e séries. Por exemplo, a posição padrão da legenda agora está na parte inferior da tela. As novas configurações padrão são mais razoáveis, mas se afetarem o uso existente, use echarts/theme/v5.js para restaurar o estilo visual antigo e as configurações de localização. Consulte #20865.
    • A v5 echarts/src/theme/light.ts agora foi migrada para echarts/theme/rainbow.js.
    • A posição dos eixos cartesianos pode mudar ligeiramente se os nomes ou rótulos dos eixos anteriormente ultrapassaram a tela ou se sobrepuseram, já que os mecanismos anti-overflow e anti-axisLabel-axisName-overlap estão habilitados por padrão. Na maioria dos casos, essas alterações serão indiscerníveis a olho nu. Mas se ocorrer alguma alteração não razoável, você pode usar a opção grid.outerBoundsMode: 'none' para desabilitar o mecanismo anti-overflow e/ou usar a opção xAxis/yAxis.axisLabel.nameMoveOverlap: false para desabilitar o mecanismo de sobreposição anti-axisLabel-axisName. Consulte #21059.
    • A base percentual da opção center (como a base de '33%') em geo, series.map, series.graph e series.tree é alterada. A base percentual anterior está incorreta. Mas se você precisar restaurar, defina legacyViewCoordSysCenterBase: true (no nível raiz de uma opção echarts). Consulte #19807#issuecomment-2974437299.
    • Agora os estilos ricos de etiqueta (fontStyle, fontWeight, fontSize, fontFamily, textShadowColor, textShadowBlur, textShadowOffsetX, textShadowOffsetY) foram alterados para herdar os estilos de etiqueta simples. Você pode usar richInheritPlainLabel: false (no nível raiz de uma opção de echarts ou no mesmo nível das opções de estilo de rótulo) para restaurá-lo. Consulte #20977
