  • [Recurso] Suporte [ajuste inteligente do ponteiro] (https://echarts.apache.org/handbook/en/how-to/interaction/coarse-pointer). #17102 (Ovilia)

  • [Recurso] [tipo] Tipo de exportação ElementEvent. #15291 (Map1en)

  • [Fix] [state] [ênfase] Adicione o tipo ausente number a emphasis.scale para a série scatter/line/graph. #17390 (coração)
  • [Fix] [svg] Codifique caracteres especiais HTML ao gerar string SVG. #17406 (coração)
  • [Fix] [visualMap] Corrige o indicador que não aparece ao passar o mouse no rótulo do mapa. #17346 (coração)
  • [Fix] [custom] Os elementos de correção não podem ser removidos após as atualizações. #17349. (Ovilia)
  • [Fix] [custom] Corrige elementos personalizados que provavelmente não podem ser removidos ao aplicar a transição de saída. #17308 (coração)
  • [Fix] [tema] Corrige o estilo de texto de tooltip no tema macarons. #17551 (mousne)
  • [Consertar] [tema] Corrigir nível normal abandonado em arquivos de tema. #17482 (Liangismo)
  • [Fix] [axis] [log] Fix log axis quebra um único dado cujo valor de log é negativo. #17322 (Ovilia)
  • [Fix] [dataZoom] Corrige erros ao usar sliderZoom em séries de velas com conjunto de dados. #17237 (jiawulin001)
  • [Fix] [sunburst] Corrige log errado para ação obsoleta. #17587 (gitforhlp)
  • [Fix] [type] Garanta compatibilidade com TypeScript 4.8. #17582 (AviVahl)
  • [Fix] [type] Adicione o tipo de valor ausente false para nodeClick, opção para SunburstSeriesOption e TreemapSeriesOption. #17218 (dmzc)
  • [Corrigir] [erro de digitação] Corrigir um erro de digitação no nome do arquivo. src/animation/basicTrasition.ts → src/animation/basicTransition.ts #17193 (kxsoling)
