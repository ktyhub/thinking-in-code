echarts 5.4.1

  • [Recurso] [i18n] Adicionar tradução húngara (hu_HU). #17978 (ifjkovacsik)
  • [Recurso] [svg] Suporta gradientes e padrões para cores de fundo no renderizador SVG. #959 (coração)
  • [Recurso] [castiçal] Fornece a opção borderColorDoji para cores doji personalizadas. #17717 (Ovilia)
  • [Recurso] [sankey] Suporte edgeLabel. #16767 (susiwen8)
  • [Recurso] [gráfico] Torna o nó do gráfico arrastável no layout none e circular. #15428 (kongmoumou)
  • [Recurso] [util] Use Map nativo, se disponível. #965 (JonasBa)
  • [Recurso] [tipo] Exportar ECElementEvent para TypeScript. #17892 (determinado por keita)
  • [Fix] [i18n] Renomeie o código do idioma ucraniano para UK. #17812 (striezel)
  • [Fix] [pie] A porcentagem de correção não é atualizada depois que a legenda é alterada. #17734 (coração)
  • [Fix] [pie] Corrige o potencial acesso nulo a labelLine quando minShowLabelRadian está definido. #17715 (coração)
  • [Fix] [pie] Fix center não pode ser convertido para o ponto correto quando o sistema de coordenadas é especificado. #17920 (coração)
  • [Fix] [heatmap] Correção do rótulo do mapa de calor que pode se sobrepor quando dataZoom está habilitado. #17876 (coração)
  • [Consertar] [animação] Corrigir dataGroupId incorreto para itens de dados antigos em universalTransition. #17559 (tyn1998)
  • [Fix] [dataZoom] Fallback para início/fim da extensão quando o valor ou porcentagem é inválido. #17934 (coração)
  • [Fix] [timeline] O gráfico de correção não funciona quando a linha do eixo não é mostrada. #17647 (coração)
  • [Fix] [dica de ferramenta] Correção da seta da dica de ferramenta que pode cobrir o conteúdo quando a borda é larga. #17875 (coração)
  • [Fix] [marker] Correção markArea não aparece ao usar o pixel x/y, mas coord não está definido. #17217 (jiawulin001)
  • [Fix] [marcador] markArea da série de barras agora cobre categorias inteiras especificadas. #17098 (jiawulin001)
  • [Fix] [legenda] Corrigir legenda inverse não funciona se os dados da série tiverem o mesmo nome. #17510 (caiwukun)
  • [Fix] [gauge] Renderize os setores do medidor na ordem da opção "sentido horário". #17691 (ZeekoZhu)
  • [Fix] [ssr] Corrige expressão errada para extrair o tamanho da fonte. #968 (coração)
  • [Fix] [svg] A forma corrigida pode desaparecer após a conclusão da animação de transformação no renderizador SVG. (simples)
  • [Fix] [type] Corrige erro de tipo EChartsInitOpts sobre altura e largura. #17727 (MainHou)
  • [Fix] [type] Adiciona a propriedade overflow à interface AxisLabelBaseOption. #17808 (breizh24)
  • [Fix] [type] Adicione o tipo string e number à opção center da série de pizza. #17917 (coração)
  • [Fix] [type] Adicione o retorno de chamada function ausente em lineStyle.color para séries de linhas. #17780 (coração)
