#iotdb v1.3.2

Recursos e melhorias

  • Módulo de armazenamento: Melhoria de desempenho na interface insertRecords para gravação
  • Módulo de consulta: nova instrução Explique Analisada adicionada (monitorando o tempo gasto em cada estágio de uma única execução SQL)
  • Módulo de consulta: nova estrutura UDAF (Função agregada definida pelo usuário) adicionada
  • Módulo de consulta: novas funções MaxBy/MinBy adicionadas, suportando a recuperação de valores máximos/mínimos junto com os carimbos de data/hora correspondentes
  • Módulo de Consulta: Melhoria de desempenho em consultas de filtragem de valor
  • Sincronização de dados: a correspondência de caminho suporta padrão de caminho
  • Sincronização de dados: suporta sincronização de metadados (incluindo séries temporais e atributos relacionados, permissões, etc.)
  • Processamento de Stream: Adicionada instrução Alter Pipe, suportando atualizações quentes de plug-ins para tarefas do Pipe
  • Módulo do sistema: as estatísticas de contagem de pontos de dados do sistema agora incluem estatísticas para dados importados ao carregar o TsFile
  • Scripts e ferramentas: Adicionada nova ferramenta de backup de atualização local (fazendo backup dos dados originais por meio de links físicos)
  • Scripts e ferramentas: novos scripts de exportação/importação de dados adicionados, suportando exportação de dados em formatos CSV, TsFile ou instruções SQL
  • Scripts e ferramentas: o ambiente Windows agora suporta distinguir ConfigNode, DataNode e Cli por nome de janela ...

Erros

  • Otimize a mensagem de erro quando ocorre uma NullPointerException (NPE) devido a um tempo limite ao eliminar um banco de dados.
  • Adicione logs para notifyLeaderReady, notifyLeaderChanged e procedimento trabalhador.
  • Adicione tratamento de compatibilidade para dados errados existentes durante a fusão de arquivos.
  • Correção do problema de impasse causado pela liberação de arquivos vazios durante a consulta.
  • Corrigido o problema em que o Ratis parava de responder durante as operações de leitura, gravação e exclusão.
  • Corrigido o bug simultâneo nas operações de carregamento e mesclagem.
  • Correção do problema em que a taxa de compactação do sistema é registrada como um número negativo no arquivo para determinados cenários.
  • Correção do problema de ConcurrentModificationException durante a estimativa de memória para tarefas de mesclagem.
  • Corrija possíveis impasses que podem ocorrer ao escrever, criar automaticamente e excluir bancos de dados simultaneamente. ...
