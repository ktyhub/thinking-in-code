#kops v1.37.0

Consulte o kOps 1.37 release notes completo para obter detalhes, incluindo alterações significativas e descontinuações.

Destaques

  • Suporte para Kubernetes 1.37, com etcd 3.7.3 como padrão para clusters Kubernetes 1.37
  • Repositórios de ativos privados no armazenamento de objetos em nuvem: URLs s3://, gs:// e azureblob:// para KOPS_BASE_URL e spec.assets.fileRepository, com nós autenticados por meio de sua identidade de instância
  • Bootstrap de nó menor e mais resiliente: o download do nodeup cai de cerca de 120 MB para menos de 10 MB, por meio de um binário menor e compactação xz, e o bootstrap tenta novamente tarefas com falha
  • Tempo de execução do contêiner: containerd 2.3.6 e runc 1.5.1 por padrão, com configuração do containerd versão 4; versões containerd anteriores a 2.1.0 não são mais suportadas
  • Expansão Karpenter: Karpenter v1.15.1, tratamento de interrupção gerenciado por kOps (fila SQS e regras EventBridge), configurações de volume raiz em EC2NodeClass, suporte a instanceRequirements e grupos mistos de instâncias GPU e não GPU
  • Permissões mais restritas do AWS IAM para as funções de instância (Route 53, KMS, EC2, SQS) e nenhuma política inline para funções que não precisam de permissões
  • alterações no etcd-manager: imagens empacotadas do etcd montadas como volumes de imagem e suporte para versões personalizadas do etcd a partir de uma imagem fornecida pelo usuário em novos clusters
  • Rede: Calico v3.32.3 com mudança para ClusterNetworkPolicy, suporte de política de rede para AWS VPC CNI, kube-router v2.12.0 com back-end de política de rede nftables experimental e kindnet v1.0.3
  • Azure: solicitações de bootstrap autenticadas com metadados de instância assinados, detecção kops rolling-update cluster de VMs desatualizadas e duas réplicas de gerenciador de controlador de nuvem em planos de controle altamente disponíveis
  • Akamai (Linode): o provedor experimental agora gerencia chaves SSH, redes, sub-redes, instâncias e volumes de armazenamento em bloco
  • Atualizações de componentes: etcd-manager v3.0.20261022 com etcd 3.5.35/3.6.16/3.7.3, Cilium v1.18.16, AWS VPC CNI v1.23.2, CoreDNS v1.15.0, AWS Load Balancer Controller v3.6.2, cert-manager v1.21.3, cluster-autoscaler v1.37.0
  • Removido: suporte para Kubernetes 1.31, Gossip DNS (e protokube), AWS Classic Load Balancers para API e rede Kopeio. Migrar com kOps 1.36 antes da atualização
