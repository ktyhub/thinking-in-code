  • 🆔 Espaço em branco do ID do modelo. Um modelo de espaço de trabalho cujo ID contém um espaço ou uma tabulação agora é recusado no editor, através do API e na importação; uma já armazenada continua respondendo, mas não pode ser salva novamente até ser recriada. Confirmar
  • 🖇️ Renderização do esquema de links. Um link em uma resposta, uma citação ou um resultado de pesquisa na web agora é renderizado apenas quando aponta para um endereço da web, um endereço de e-mail, um número de telefone ou algum lugar dentro desta instância; qualquer outra coisa, um endereço "ftp://" ou um link de aplicativo como "obsidian://" ou "vscode://" entre eles, é mostrado como o texto que é. Duas velhas estranhezas acompanham isso: uma fonte escrita como "HTTP: //" agora se torna um link, e um nome de arquivo contendo apenas as letras http não se torna mais um nome que não leva a lugar nenhum. #29890
  • 🧲 A guia Integrações é opcional. A guia Integrações nas configurações pessoais, onde suas próprias conexões de ferramentas e terminais são gerenciadas, agora fica oculta até que um administrador ative Integrações Diretas em Integrações ou defina "ENABLE_DIRECT_INTEGRATIONS", e ocultá-la deixa as conexões existentes funcionando. Confirmar, Confirmar
