#moby docker-v29.9.3

##29.9.3

Para obter uma lista completa de solicitações pull e alterações nesta versão, consulte os marcos relevantes do GitHub:

  • docker/cli, marco 29.9.3
  • moby/moby, marco 29.9.3

Segurança

Esta versão inclui correções para diversas vulnerabilidades de segurança que afetam o mecanismo Docker e componentes relacionados.

  • CVE-2026-116587 Correção de possível uso excessivo da CPU ao analisar chaves RSA criadas
    GHSA-mgcc-cww5-fp2q
  • CVE-2026-116591 Corrige um possível pânico ao descompactar dados zstd
    GHSA-fpmh-frq8-7rj8
  • CVE-2026-115538 Corrige criptografia ausente e proteções contra falsificação para redes de sobreposição Swarm após o firewalld liberar as regras de iptables do Docker
    GHSA-6jhp-7446-hf7f

A atualização do SwarmKit corrige a seguinte vulnerabilidade de segurança:

  • CVE-2026-115539 Corrigida uma vulnerabilidade em que um invasor com um certificado TLS de nó de trabalho válido e uma chave privada poderia obter um certificado de nó gerenciador logo após uma mudança de líder do Swarm
    GHSA-628g-hv7f-pgjc

A atualização do BuildKit v0.34.2 corrige as seguintes vulnerabilidades de segurança:

  • GHSA-2fqp-xg6f-v7gj: Uma compilação que resolvesse metadados para a mesma referência de origem Git duas vezes poderia travar o daemon por envenenamento do cache do resolvedor.
  • GHSA-w26x-xg27-7qjc: Um client malicioso com acesso ao controle BuildKit APIs pode definir atributos estendidos em arquivos fora do diretório de estado do BuildKit, potencialmente concedendo privilégios elevados a programas no host.

Correções de bugs e melhorias

  • Correção de chaves << literais em arquivos YAML sendo emitidos sem aspas. docker/cli#7461
  • Corrigido o daemon pendurado em solicitações de contêiner, imagem e sistema API sob carga. moby/moby#54041
  • Atualize o BuildKit para v0.34.2. moby/moby#54107
