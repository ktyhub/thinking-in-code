Qdrant Edge :hocho:

Qdrant Edge é uma versão em processo do Qdrant, que compartilha os mesmos componentes internos, formato de armazenamento e pontos API da versão do servidor, mas projetado para funcionar localmente. O Qdrant Edge é compatível com a versão do servidor e pode ler instantâneos de fragmentos criados pela versão do servidor do Qdrant. Mais documentação disponível aqui.

Depreciações: aviso:

  • A partir do v1.17.0, o Qdrant altera o formato de resposta para campos vetoriais na interface gRPC. Todos os Qdrant clients oficiais já devem ter sido adotados para esta mudança, portanto, certifique-se de atualizar suas bibliotecas client e verifique se não está usando campos obsoletos. Mais informações: https://github.com/qdrant/qdrant/pull/7183

  • Próximas depreciações:

    • No Qdrant v1.18.x todos os métodos de pesquisa obsoletos serão completamente removidos e não estarão disponíveis nem mesmo nas bibliotecas client antigas.
    • No Qdrant v1.17.x removeremos completamente o suporte ao RocksDB em favor do gridstore, o que significa que a atualização direta do v1.15.x para o v1.17.x não será possível. Siga as instruções de atualização e atualize uma versão secundária por vez para evitar erros de armazenamento não suportados. Observe que a infraestrutura Qdrant Cloud gera automaticamente etapas de atualização adequadas, então você não precisa se preocupar com isso.
