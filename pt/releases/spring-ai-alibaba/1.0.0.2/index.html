primavera-ai-alibaba v1.0.0.2

Temos o prazer de anunciar o lançamento do Spring AI Alibaba 1.0.0.2, a primeira versão GA! Construído em Spring AI e profundamente integrado com Bailian, Spring AI Alibaba oferece suporte ao desenvolvimento de aplicativos ChatBot, Workflow e Multiagente.

Principais recursos

1. Integração abrangente da estrutura

  • Integração com Alibaba Cloud: Conecte-se perfeitamente aos serviços Alibaba, incluindo Dashscope da Bailian, suportando vários modelos de IA convencionais, como Qwen e Deepseek.

2. Estrutura multiagente

Estrutura multiagente baseada em gráfico: inspirada em Langgraph, Spring AI Alibaba Graph facilita a construção de fluxos de trabalho e aplicativos multiagentes.

3. Soluções de agentes de IA prontas para empresas

  • Registro Nacos MCP
    • Descoberta de MCP distribuída e balanceamento de carga
    • API dinâmico para proxy MCP
  • NL2SQL para transformar consultas de linguagem natural em instruções SQL.
  • Observabilidade

Experiência do desenvolvedor

Guia de início rápido

Inicie seu primeiro aplicativo de IA com Spring AI Alibaba adicionando a seguinte dependência ao seu projeto Spring Boot:

<dependencyManagement>
    <dependencies>
        <dependency>
            <groupId>com.alibaba.cloud.ai</groupId>
            <artifactId>spring-ai-alibaba-bom</artifactId>
            <version>1.0.0.2</version>
            <type>pom</type>
            <scope>import</scope>
        </dependency>
    </dependencies>
</dependencyManagement>

<dependencies>
    <dependency>
        <groupId>com.alibaba.cloud.ai</groupId>
        <artifactId>spring-ai-alibaba-starter-dashscope</artifactId>
    </dependency>
</dependencies>

Spring Boot Iniciadores

  • spring-ai-alibaba-starter-dashscope - Adaptação de serviço de modelo integrado
  • spring-ai-alibaba-graph-core - Componentes principais da estrutura AI Graph
  • spring-ai-alibaba-starter-nl2sql - Componente de conversão de linguagem natural para SQL
  • spring-ai-alibaba-starter-memory - Componente de memória de sessão
  • spring-ai-alibaba-starter-nacos-mcp-client -Nacos MCP client; versão recomendada: Nacos 3.0.1. Para usuários do Nacos 2 Server, use a versão mais antiga (spring-ai-alibaba-starter-nacos2-mcp-client).
  • spring-ai-alibaba-starter-nacos-mcp-server - Servidor Nacos MCP; versão recomendada: Nacos 3.0.1. Para usuários do Nacos 2 Server, use a versão mais antiga (spring-ai-alibaba-starter-nacos2-mcp-server).
  • spring-ai-alibaba-starter-nacos-prompt - Gerenciamento de prompt do Nacos
  • spring-ai-alibaba-starter-arms-observation - Observabilidade ARMS
  • Componentes da comunidade
    • spring-ai-alibaba-starter-tool-calling-* - Componente de chamada de ferramenta
    • spring-ai-alibaba-starter-document-reader-* - Componente de leitura de documentos
    • spring-ai-alibaba-starter-vector-store-* - Componente Vector Store

Exemplos de projetos

A comunidade oficial desenvolveu um [exemplo de Playground] (https://github.com/springaialibaba/spring-ai-alibaba-examples/tree/main/spring-ai-alibaba-playground) que inclui uma UI Frontend completa e Backend baseado em Spring AI Alibaba. O Playground permite que os usuários experimentem todos os recursos básicos da estrutura, como chat, observabilidade, conversas multi-rodadas, geração de imagens, multimodalidade, chamada de ferramentas, MCP e RAG.

Para mais casos de uso, consulte Repositório de exemplos do Alibaba Spring AI.
