appsmith v2.3

🗑️ Remoção de recursos - 30 de setembro de 2026 - EOL

<img width="1213" height="306" alt="image (2)" src="https://github.com/user-attachments/assets/5630ce25-4c46-48b8-8fe1-cd8c315d7d77" />

Após atualizar para a versão 2.3, você não poderá mais adicionar novas conexões ou consultas de fontes de dados do Appsmith AI. Qualquer uma que você tenha atualmente continuará funcionando até 30 de setembro de 2026. Após esse período, todas as fontes de dados do Appsmith AI deixarão de funcionar, independentemente de você ter atualizado ou não.

✨ Novos recursos e melhorias

  • Copiloto de IA nativo para widgets personalizados — Adicionados recursos nativos de Copiloto de IA aos widgets personalizados. (#42063)
  • Ask AI for Community Edition — Trouxe o assistente Ask AI para a Community Edition. (#42065). https://docs.appsmith.com/build-apps/how-to-guides/use-ask-ai
  • Widget de cartão — Adicionado um novo widget de cartão para exibir entidades com uma tela de corpo combinável. (#42026). Mais informações podem ser encontradas https://docs.appsmith.com/reference/widgets/card
  • Estilo de etiqueta do widget de botão — Adicionadas opções de estilo de etiqueta ao widget de botão. (#41998)
  • Navegação pelo teclado — Adicionada uma propriedade tabOrder compartilhada em widgets padrão para melhorar a navegação pelas guias do teclado. (#41895)
  • Atributo de linguagem HTML — Adicionado suporte para personalização do atributo HTML lang. (#41593)
  • Verificações de repositório Git — Adicionadas verificações de integridade para repositórios Git armazenados em Redis. (#41970)

🤖 Melhorias de IA e assistente

  • Tempo limite do AI Assistant — Aumentou o tempo limite do provedor do AI Assistant para melhorar a confiabilidade. (#42096)
  • Feedback de IA de widget personalizado — Feedback aprimorado e tratamento de erros para o Assistente de IA de widget personalizado. (#42095)
  • Ask AI CE Hardening — Implementação do Ask AI Community Edition reforçada após a revisão do CodeRabbit. (#42092)
  • Descontinuação do Appsmith AI – Bloqueio da criação de novas fontes de dados do Appsmith AI e adição de um banner de descontinuação. (#42015)

🔐 Segurança

  • Desvio de autorização de fonte de dados — Corrigida uma vulnerabilidade que poderia permitir a reutilização de fontes de dados ocultas durante operações de importação e bifurcação de aplicativos. (#42066)
  • Git Import Path Traversal — Impediu a travessia de caminho baseada em link simbólico durante as importações do Git que poderia levar à leitura/gravação arbitrária de arquivos. (#41993)
  • Segurança do grupo de permissões — Limites de espaço de trabalho aplicados ao atribuir grupos de permissões. (#42023)
  • Autorização de fonte de dados — Corrigida a autorização de criação/atualização de ação para evitar que os usuários exponham a fonte de dados privada de outro espaço de trabalho para execução não autenticada. (#42018)
  • Acesso à rede da fonte de dados — Acesso restrito à fonte de dados ao endereço de rede da própria instância. (#41985)
  • Segurança dos ancestrais do quadro — Removido o padrão curinga frame-ancestors para evitar políticas de incorporação excessivamente permissivas. (#42012)
  • Segurança de email pré-autenticação — Respostas padronizadas de endpoints de email pré-autenticação e rotas não utilizadas removidas. (#41996)
  • Tenant Endpoint Security — Removidos detalhes de configuração interna das respostas do locatário para usuários anônimos. (#42001)
  • Redirecionamento de abertura de login — Redirecionamentos abertos evitados causados por cabeçalhos Origin forjados durante o login. (#41995)
  • Segurança do Atuador — Evita a autenticação básica do atuador quando a senha interna não está configurada. (#41964)
  • Verificação SMTP TLS — Verificação SMTP TLS aprimorada, validando o nome do host enquanto mantém a conexão com o endereço validado por SSRF. (#42060)
  • Caddy Rate Limiting — Limitação de taxa aprimorada usando IPs trusted client e restringindo proxies trusted. (#42071)
  • CVEs de servidor e plug-in — Vulnerabilidades JAR de servidor e plug-in corrigidas identificadas pelas verificações do Docker Scout. (#42074)
  • Atualização de segurança do npm — Atualização do npm para 11.18.0 para resolver a vulnerabilidade crítica de DoS do node-tar (CVE-2026-59873). (#42064)
  • Atualização de segurança tar — Atualizada a resolução tar para ^7.5.19 para resolver CVE-2026-59873. (#42034)
  • Atualizações de segurança de dependência — Atualizações de dependência aplicadas abordando diversas vulnerabilidades relatadas. (#42091, #42051, #42049, #41969, #41965)

🔧 Git e controle de versão

  • Mensagens de erro do Git aprimoradas — Tratamento de erros do Git atualizado para revelar a causa real das falhas em vez de exibir uma mensagem genérica. (#42053)
  • Otimização de importação do Git — Importações limitadas de entidades de ramificação irmã apenas para os campos obrigatórios durante a importação. (#41972)
  • Estabilidade de lançamento do Git — Removido um controlador Git legado órfão que estava causando problemas de lançamento. (#41974)

🎨 Melhorias na interface e nos widgets

  • Permissões de temas de aplicativos — Permissão de edição necessária ao ler temas de aplicativos no modo de edição. (#42090)
  • Posicionamento do Banner — Corrigido o deslocamento do banner. (#42073)
  • Copiar para aplicativo — Correção da rolagem suspensa e visibilidade aprimorada das notas da fonte de dados no modal de cópia. (#42007)
  • Widget de tabela — Corrigida a largura da coluna do botão de menu. (#41948)
  • Links de widget de texto — Corrigidos links mailto:, tel: e ftp: sendo modificados incorretamente. (#41997)

🛠️ Confiabilidade, testes e experiência do desenvolvedor

  • Interceptações Cypress API — Corrigidas falhas de ganchos de interceptação API consolidados devido ao cy.log. (#42069)
  • Avaliação do Filepicker — Parâmetros irmãos preservados quando os dados binários do Filepicker são passados para uma execução de ação. (#42021)
  • Validação MSSQL — Nomes de bancos de dados MSSQL rejeitados contendo separadores de cadeia de conexão. (#42077)
  • Intl Linting – Corrigido um erro de lint falso Intl is not defined. (#42080)
  • Confiabilidade JDBC — Adicionados keepalive Hikari e tempos limites de soquete limitados para conexões JDBC. (#41851)
  • Testes de configurações de e-mail — Maior confiabilidade do teste, aguardando o corpo HTML do e-mail antes de continuar. (#41893)
  • Client Build CI — Erros de "lista de argumentos muito longa" foram evitados ao determinar arquivos alterados. (#42050)
  • Tratamento de erros do MongoDB — Tratamento aprimorado de erros repetidos do conjunto de réplicas do MongoDB, aguardando a limpeza do sistema existente antes de verificar novamente. (#41963)

🏢 Permissões e configuração

  • Auto Commit Authorization — Adicionadas verificações de autorização antes de ler a configuração do Auto Commit Pro para artefatos de destino. (#42083)
  • Rastreamento Anônimo — Garantido que o sinalizador block-anonymous-tracking seja consistentemente respeitado tanto no client quanto no servidor. (#41973)
  • Rastreamento de uso — Preservado o ID do usuário anônimo para rastreamento de uso quando o segmento é bloqueado para usuários anônimos. (Número PR não fornecido)
