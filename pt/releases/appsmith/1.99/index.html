appsmith v1.99

Correções

  • Evita que as importações corrompam o layoutOnLoadActions publicado. (#41737)
  • Impediu que a inserção automática de ponto e vírgula (ASI) em wrapCode causasse falhas de refatoração. (#41727)
  • Removido um campo nfs extra do objeto persistentVolume. (#41724)
  • Links de gravação do BetterBugs atualizados para usar os novos URLs de pacote. (#41667)
  • PAT substituído por GITHUB_TOKEN no fluxo de trabalho cleanup-dp. (#41699)
  • Corrigidos problemas de estilo com widgets de seleção da barra de rolagem. (#41656)
  • Evitou uma condição de corrida de criação de superusuário. (GHSA-9wcp-79g5-5c3c) (#41681)
  • SSRF bloqueado por meio da validação do host SMTP send-test-email. (GHSA-vvxf-f8q9-86gh) (#41666)
  • Corrigido CVE-2025-70952 crítico. (#41673)
  • handlebars atualizado para 4.7.9 para resolver CVE-2026-33937. (#41672)
  • CVE-2026-22732 atenuado, onde os cabeçalhos HTTP do Spring Security não estavam sendo gravados. (#41669)
  • Corrigido um problema em que as consultas da fonte de dados não falhavam quando o campo createdAt estava faltando. (#41665)
  • E-mails de usuários normalizados ao salvar para remover caracteres Unicode invisíveis. (#41664)
  • Verificações de permissão ACL aplicadas na pesquisa de fonte de dados de retorno de chamada OAuth2. (GHSA-rg2x-4v4h-g78w) (#41640)
  • Validado o nome da tabela temporária do filtro antes de DROP TABLE. (#41642)
  • Injeção de AQL evitada no plugin ArangoDB causada por concatenação de strings insegura. (#41641)
  • Ampliação da lista de bloqueios de metadados para fortalecer a proteção SSRF. (GHSA-9m89-5jw7-q5cr) (#41643)
  • Valor do ambiente administrativo reforçado escaping. (#41637)
  • URLs higienizados em ManualUpgrades para evitar XSS refletido. (#41636)
  • Permissões de edição impostas para exclusão de snapshots do aplicativo. (GHSA-g2hc-wmw2-32jr) (#41624)
