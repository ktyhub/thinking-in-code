appsmith v2.4

🗑️ Lembrete de remoção de recursos - 30 de setembro de 2026 - EOL

Appsmith AI chega ao fim em 30 de setembro de 2026 – três semanas após este lançamento.

Conforme anunciado no v2.3, você não pode mais adicionar novas conexões ou consultas de fontes de dados do Appsmith AI. Qualquer uma que você tenha atualmente continuará funcionando até 30 de setembro de 2026. Após essa data, todas as fontes de dados do Appsmith AI deixarão de funcionar, independentemente de você ter atualizado ou não.

Migre quaisquer consultas restantes do Appsmith AI para uma fonte de dados direta do fornecedor (OpenAI, Anthropic ou Google AI) antes dessa data. Esta versão atualiza as listas de modelos disponíveis para todos os três provedores, para que os modelos atuais estejam disponíveis para migração. (#42114)

⚠️ Notas importantes sobre atualização

  • Segredos das configurações de administrador — Os valores confidenciais retornados por GET /api/v1/admin/env agora são mascarados e os campos editáveis de URL do MongoDB e Redis são substituídos pelo status de conexão somente leitura. Atualize quaisquer scripts ou automação que leiam esses valores do administrador API. O envio de um valor mascarado de volta é tratado como "inalterado", portanto a configuração existente é preservada. (#42169)
  • Respostas de fontes de dados de IA — As fontes de dados OpenAI, Anthropic e Google AI agora listam os modelos atuais. Consultas antrópicas salvas usando IDs de modelo moderno inseridos manualmente podem exigir atualizações de ligação se lerem completion. (#42114)

✨ Novos recursos e melhorias

  • Appsmith MCP Server (BETA) — Um servidor Model Context Protocol integrado e opcional que permite que AI clients compatíveis criem e editem aplicativos Appsmith por meio de uma ferramenta estruturada API. Os agentes nunca criam ligações DSL, SQL, JS ou {{ }} de widget bruto — eles chamam ferramentas que o servidor compila sob as próprias permissões do chamador. Configurar o servidor MCP → (#42185, #42187, #42190, #42193, #42208, #42210, #42212)
    • Desativado por padrão, tanto em novas instalações quanto em atualizações — a atualização para v2.4 não expõe um endpoint do agente. Auto-hospedado: Configurações de administrador → Instâncias → Servidor MCP (BETA) → ativar → Salvar e reiniciar. As contas do Appsmith Cloud com um nome de organização personalizado habilitam-no em Organizações.
    • Chaves por usuário em Configurações de administrador → Perfil → Chaves MCP. Uma chave autentica o client como esse usuário e não concede permissões adicionais. As chaves expiram em 30/60/90/180/365 dias (padrão 30) e são limitadas a 10 chaves não revogadas por usuário; o segredo é mostrado apenas uma vez, na criação ou rotação. Desabilitar o servidor rejeita as chaves existentes, mas não as revoga.
    • Operações destrutivas requerem aprovação humana através de um handshake prepare_* → confirm_* com uma confirmação única vinculada ao alvo e sua revisão de conteúdo atual.
    • Aplicativos conectados ao Git são bloqueados. As mutações devem nomear o branch atual do aplicativo e falhar ao fechar se o estado do git não puder ser lido. Os agentes confirmam apenas dentro do namespace de ramificação reservado mcp/, e cada confirmação do agente carrega um prefixo [mcp] não removível.
    • Nota do operador: criar uma ramificação mcp/ ou confirmar um commit pushs para seu git remoto usando a chave de implantação de instância, para que CI remoto e webhooks observando pushs de ramificação sejam acionados em referências mcp/*.
  • Conexões somente leitura MSSQL — Adicionado modo somente leitura com ApplicationIntent=ReadOnly, incluindo roteamento secundário legível para implantações SQL Server Always On. (#41668)
  • Ajudante de valor avaliado — Melhor posicionamento do pop-up e adição de uma visualização recolhida compacta e persistente. (#42128)

🤖 Melhorias de IA

  • Descoberta de modelo de fonte de dados OpenAI, Anthropic e Google AI atualizada para os modelos GPT, Claude e Gemini atuais. (#42114)

🎨 Melhorias na interface e nos widgets

  • Removido erros de lint obsoletos do JavaScript após limpar os eventos do widget. (#42130)
  • Impediu que valores null em configurações de ECharts personalizados quebrassem a avaliação da página. (#42145)
  • Evitou que grandes erros de sintaxe do widget personalizado JavaScript travassem o construtor. (#42198)
  • Marcadores de campos obrigatórios restaurados em widgets legados Select, MultiSelect e Tree Select. (#41927)
  • Manteve o rótulo de login do formulário “Permitir que todos os usuários se inscrevam” consistente quando alternado. (#42167)

🛠️ Confiabilidade

  • O bloqueio de operações de fonte de dados foi removido dos threads de servidor compartilhados e foram adicionados tempos limite de SMTP e SSH limitados. (#42159)
  • Removidas pesquisas duplicadas de fontes de dados e atualizações de políticas durante a validação da ação. (#42138)

🔐 Segurança

  • Identificadores de biblioteca JavaScript personalizados compartilhados derivados do lado do servidor e permissão de leitura do aplicativo imposta antes de retornar manifestos da biblioteca. (#42108, #42131)
  • Impediu que solicitações de atualização de aplicativos permitissem exportação ou comportamento de bifurcação com credenciais inclusivas. (#42113)
  • Permissão de leitura de aplicativo imposta antes que as rotas do Git resolvam aplicativos ou usem credenciais do Git armazenadas. (#42121)
  • Impediu que os fluxos da fonte de dados OAuth fossem redirecionados para origens que não correspondiam ao host da solicitação. (#42146)
  • Verificações de host restrito reforçadas para representações alternativas de IPv4, IPv6 e IPv4-em-IPv6. (#42132)
  • client atualizado, servidor, observabilidade, ferramentas agrupadas e dependências de imagem base para resolver vulnerabilidades relatadas. (#42103, #42110, #42075, #42154, #42183, #42200)

🔧 Git, implantação e configuração

  • Sincronização aprimorada de ramificações Git com suporte de Redis para repositórios sem ramificações locais. (#42176)
  • Permitiu verificações de inicialização do conjunto de réplicas para aceitar opções mais recentes de URI do MongoDB, como serverMonitoringMode=poll. (#42188)
