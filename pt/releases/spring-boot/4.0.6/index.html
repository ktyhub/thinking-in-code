:lady_beetle: Correções de bugs

  • A segurança padrão é configurada incorretamente quando spring-boot-actuator-autoconfigure está presente e spring-boot-health não está #50188
  • A configuração automática do Elasticsearch Rest5Client configura incorretamente o HTTP client subjacente #50187
  • ApplicationPidFileWriter não lida com links simbólicos corretamente #50185
  • RandomValuePropertySource não é adequado para segredos #50183
  • A configuração automática do Cassandra configura incorretamente o CqlSessionBuilder #50180
  • ApplicationTemp não lida com links simbólicos corretamente #50178
  • Remote DevTools realiza comparação incorretamente #50176
  • spring.rabbitmq.ssl.verify-hostname é aplicado de forma inconsistente #50174
  • Valores de números inteiros são ignorados ao configurar valores esperados mínimo e máximo e limites de SLO para um medidor de resumo de distribuição #50077
  • Faltam vários módulos nos starters clássicos #50071
  • O módulo spring-boot-resttestclient está ausente no spring-boot-starter-test-classic #50069
  • Anotações como @Ssl não funcionam em métodos @Bean ao usar @ServiceConnection #50064
  • EnversRevisionRepositoriesRegistrar deve reutilizar @EnableEnversRepositories em vez de configurar a contraparte JPA #50039
  • O endpoint de links do WebFlux Cloud Foundry inclui string de consulta da solicitação recebida em links resolvidos #50017
  • As importações em uma classe de teste contendo são ignoradas quando uma classe aninhada tem importações #50012
  • Com spring.jackson.use-jackson2-defaults definido como true, FAIL_ON_UNKNOWN_PROPERTIES está habilitado #49951
  • 500 respostas do endpoint env quando o padrão fornecido é inválido #49946
  • O iniciador reativo do MongoDB tem uma dependência transitiva do driver síncrono do MongoDB #49945
  • O método HTTP é perdido ao configurar exclusões em EndpointRequest #49943
  • Honre o HttpMethod para caminhos de endpoint adicionais reativos #49880
  • O suporte do Docker Compose não funciona com imagem Apache/artemis #49869
  • O suporte do Docker Compose não funciona com imagem Apache/activemq #49866
  • PathPatternRequestMatcher.Builder do Spring Security não é configurado automaticamente ao usar WebMvcTest e spring-boot-security-test #49854
  • A estratégia de caminho de versionamento API deve ser aplicada por último, pois não se destina a produzir #49800
