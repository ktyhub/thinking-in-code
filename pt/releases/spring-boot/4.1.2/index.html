  • OriginTrackedResource não implementa equals corretamente #52267

  • JWTs são rejeitados quando issuer-uri está vazio e jwk-set-uri está definido #52260

  • O desligamento normal do Tomcat ou Jetty pode retornar com REQUESTS_ACTIVE quando a parada é chamada imediatamente após shutDownGracefully em um servidor inativo #52197
  • A parada do NettyWebServer pode travar quando chamada imediatamente após shutDownGracefully #52196
  • O balanceamento de carga gRPC client 'grpc' falha ao vincular-se a uma NullPointerException quando nenhuma política filha está configurada #52193
  • Impedir que as propriedades gRPC client substituam as personalizações do usuário #52175
  • O MongoDB não consegue se conectar quando as credenciais contêm um espaço #52168
  • A autenticação falha quando a senha configurada em spring.elasticsearch.uris contém dois pontos #52166
  • O registro em log pode ser perdido quando um contexto é pausado pela estrutura de contexto de teste #52088
  • O suporte do Docker Compose para MongoDB falha na conexão quando as credenciais contêm um caractere que requer codificação de URL #52084
  • Jersey não usa o endpoint ObjectMapper quando o Atuador está sendo executado em uma porta separada #51982
  • Frações de segundo são tratadas incorretamente ao configurar durações de configuração do serviço gRPC #51957
  • As descrições das propriedades de configuração podem ser perdidas ao construir de forma incremental com Gradle #51925
  • BasicJsonParser manipula incorretamente caracteres de escape em listas e mapas aninhados #51908
  • A conversão do valor de semana zero falha com a exceção 'intValue não pode ser extraído de WEEKS' #51894
  • O aplicativo falha ao iniciar ao usar DevTools e configurar manualmente JDBC ou R2DBC sem spring-boot-jdbc ou spring-boot-r2dbc #51890
  • O suporte do Docker Compose reconhece incorretamente MARIADB_ALLOW_EMPTY_PASSWORD em vez de MARIADB_ALLOW_EMPTY_ROOT_PASSWORD #51888
  • A personalização do codec Kotlinx Serialization JSON configurada automaticamente não é aplicada #51877
  • NullPointerException pode ser lançada ao usar uber jars devido a uma condição de corrida em NestedJarFileResources #51745
  • DevTools não detecta um ambiente web reativo #51730
  • spring.http.clients.cookie-handling não tem efeito ao usar um client reativo apoiado por um conector HttpComponents #51724
  • A conexão falha quando o serviço RabbitMQ Docker Compose está configurado para usar SSL #51667
  • Atributos de manifesto relacionados ao SBOM estão faltando nas guerras empacotadas pelo Maven #51651
  • Quando server.reactive.session.cookie.same-site não está definido, os cookies de sessão não possuem o atributo SameSite #51639
  • O servidor de recursos OAuth2 ignora o delimitador de declaração de autoridade quando definido sozinho #51630
  • As configurações developmentOnly e testAndDevelopmentOnly não especificam nenhum atributo que cause possíveis problemas de resolução #51623
  • Em um aplicativo da web reativo, a integração de segurança do Cloud Foundry retorna 500 em vez de 503 quando a URL do controlador de nuvem não está disponível #51614
  • O arquivo temporário da camada não é excluído quando a criação da camada falha #51581
  • A integração Docker Compose para RabbitMQ ignora substitutos de credenciais quando uma variável de ambiente não tem valor #51578
  • Algumas mensagens de asserção nomeiam o parâmetro errado #51574
  • OAuth2ResourceServerProperties.Jwt possui um setter que não corresponde ao seu getter #51562
  • os comandos das ferramentas jarmode imprimem stacktrace em vez de uma mensagem de erro #51547
  • Docker Compose ProcessRunner pode travar ou deixar processos órfãos #51538
  • NestedByteChannel.read(ByteBuffer) retorna incorretamente 0 quando o buffer não pode ser preenchido #51520
  • Verificações nulas do personalizador em construtores HTTP client afirmam o atributo errado #51513
  • As personalizações de configuração do host SSL podem ser perdidas durante a inicialização do Tomcat #51511
  • A integração do SQL Server Docker Compose pode duplicar o parâmetro de criptografia do URL JDBC #51481
  • WritableJson.toByteArray() pode corromper caracteres suplementares #51464
  • As personalizações de configuração do host SSL são perdidas ao recarregar pacotes SSL #51457
  • OAuth2ClientProperties não estão disponíveis quando um bean ClientRegistrationRepository definido pelo usuário é fornecido #51450
  • LdapHealthIndicator reporta UNKNOWN em vez de UP quando o servidor LDAP não expõe uma versão do protocolo #51441
  • JmsHealthIndicator vaza threads de watchdog se a inicialização falhar imediatamente #51433
  • A fonte não é fechada de forma consistente por todos os testadores de marechal JSON #51418
  • O identificador de arquivo no SpringBootJoranConfigurator deve ser fechado #51415
  • Respeite o desembrulhamento de um wrapper ao resolver o DataSource raiz #51410
  • A validação do obsoleto io.buildpacks.stack.id é muito agressiva #51400
  • ReactiveOAuth2ResourceServerWebSecurityAutoConfiguration anotado com condição errada #50778
