  • spring.http.clients.cookie-handling não tem efeito ao usar um client reativo apoiado por um conector HttpComponents #51767

  • As configurações developmentOnly e testAndDevelopmentOnly não especificam nenhum atributo que cause possíveis problemas de resolução #51624

  • ReactiveOAuth2ResourceServerWebSecurityAutoConfiguration anotado com condição errada #51588
  • WritableJson.toByteArray() pode corromper caracteres suplementares #51586
  • O arquivo temporário da camada não é excluído quando a criação da camada falha #51582

  • Algumas mensagens de asserção nomeiam o parâmetro errado #51575

  • os comandos das ferramentas jarmode imprimem stacktrace em vez de uma mensagem de erro #51548
  • Docker Compose ProcessRunner pode travar ou deixar processos órfãos #51539
  • NestedByteChannel.read(ByteBuffer) retorna incorretamente 0 quando o buffer não pode ser preenchido #51521
  • Verificações nulas do personalizador em construtores HTTP client afirmam o atributo errado #51514
  • As personalizações de configuração do host SSL podem ser perdidas durante a inicialização do Tomcat #51512
  • A integração do SQL Server Docker Compose pode duplicar o parâmetro de criptografia do URL JDBC #51482
  • As personalizações de configuração do host SSL são perdidas ao recarregar pacotes SSL #51458
  • OAuth2ClientProperties não estão disponíveis quando um bean ClientRegistrationRepository definido pelo usuário é fornecido #51451
  • LdapHealthIndicator reporta UNKNOWN em vez de UP quando o servidor LDAP não expõe uma versão do protocolo #51442
  • JmsHealthIndicator vaza threads de watchdog se a inicialização falhar imediatamente #51434
