bota de mola v4.1.1

##: aviso: atenção necessária

  • O plugin Gradle do Spring Boot não configura mais automaticamente o gRPC quando o plugin Protobuf é aplicado. Esse comportamento causou problemas para quem usava Protobuf sem gRPC. Para aceitar a configuração do gRPC, configure a extensão protobuf com o plugin grpc usando um bloco vazio. O plugin Spring Boot Gradle irá então configurar automaticamente o uso do protoc-gen-grpc-java como antes. #50822
