bota de mola v4.2.0-RC2

:star: Novos recursos

  • Remover suporte para recarga SSL LDAP #52365
  • Adicionar suporte para X-Forwarded-Prefix com Reactor Netty #52316

:lady_beetle: Correções de bugs

  • Definir management.observations.conventions para telemetria aberta não permite nenhuma convenção semântica #52619
  • PushGatewayTaskScheduler não desliga corretamente o agendador de tarefas quando o contexto é fechado #52591
  • ClearCachesApplicationListener não encontra métodos clearCache() herdados #52589
  • MongoTransactionManager criado por BatchDataMongoAutoConfiguration não é personalizado por TransactionManagerCustomizers #52572
  • O processador de configuração não lida com tipos conhecidos quando eles são totalmente qualificados #52571
  • Host AMQP Rabbit inválido é relatado com o valor errado #52568
  • Evite estouro prematuro ao converter durações para microssegundos #52561
  • A vinculação de um valor de uma árvore de configuração falha depois que uma coleção do mesmo tipo de elemento foi vinculada da mesma árvore de configuração #52559
  • JsonWriter grava JSON inválido quando usingPairs é usado com um membro nomeado #52549
  • O log estruturado GELF de logback grava uma short_message nula quando a mensagem de log é nula #52547
  • KafkaTransactionManager configurado automaticamente não é personalizado por TransactionManagerCustomizers #52542
  • Camadas personalizadas no plugin Gradle incluem conteúdo excluído em vez de excluí-lo #52540
  • Endereços RabbitMQ sem porta usam a porta AMQP quando SSL está habilitado #52538
  • BasicJsonParser não decodifica sequências de escape \b, \f, \n, \r, \t e \uXXXX #52534
  • NestedJarFile.getComment() falha com uma EOFException quando o jar não tem comentários #52513
  • Despejo de thread de texto simples relata threads em Object.wait() como estacionamento em Java 19+ #52511
  • Ao usar spring-boot-amqp-rabbitmq e spring-boot-rabbitmq, as informações de saúde deste último são perdidas #52506
  • As falhas de análise do JSON não produzem mais DockerOutputParseExceptions #52500
  • O registro estruturado do ECS grava objetos vazios de serviço e service.node #52497
  • ConfigurationMetadataAnnotationProcessor produz saída não repetível se vários endpoints compartilharem o mesmo ID #52494
  • O desligamento normal não espera por solicitações ativas após a reinicialização do Tomcat ou Jetty #52490
  • RabbitMQ usa a porta errada por padrão quando um pacote SSL é configurado #52488
  • R2dbcTransactionManager configurado automaticamente não é personalizado por TransactionManagerCustomizers #52485
  • JsonWriter grava NaN e valores infinitos como JSON inválido #52483
  • ZipEndOfCentralDirectoryRecord encontra a assinatura do registro dentro do comentário zip #52481
  • O suporte LLdap Docker Compose falha ao conectar quando LLDAP_LDAP_USER_DN está configurado #52475
  • ZipContent.Entry hasNameStartingWith ignora o deslocamento de nomes de diretórios aninhados virtualizados #52464
  • ZipContent não pode abrir um zip com dados após o término do registro do diretório central #52461
  • ZipContent lê o comentário zip da posição errada quando o arquivo tem dados prefixados #52459
  • A configuração do root logger não pode ser recuperada e não possui nível configurado com Log4j2 #52455
  • A integração do Docker Compose OTLP requer que as portas gRPC e HTTP sejam expostas quando apenas HTTP for usado #52451
  • A configuração automática do Spring Batch JDBC se conecta ao banco de dados na inicialização para detectar seu tipo, sem nenhuma maneira de configurá-lo #52449
  • Os caches OnAvailableEndpointCondition retêm contextos de aplicativos fechados por meio de seu ambiente #52447
  • DataSourceTransactionManagerAutoConfiguration usa uma propriedade antiga e não mais suportada para controlar a tradução de exceções #52445
  • A nova propriedade 'maxLocaleCount' do Tomcat não pode ser facilmente configurada #52443
  • DevTools vaza um thread do File Watcher para cada reinicialização com falha #52441
  • As cifras do pacote SSL e os protocolos habilitados às vezes são ignorados silenciosamente quando o componente subjacente não suporta sua configuração #52438
  • AMQP 1.0 não deve definir nenhuma credencial para usar ANONYMOUS por padrão #52435
  • Porta RabbitMQ AMQP 1.0 padrão para 5671 quando um pacote SSL é configurado #52432
  • Hikari não registra seus próprios MBeans quando a busca de conexão lenta é usada com JMX habilitado #52426
  • As cifras do pacote SSL e os protocolos habilitados são ignorados pelo RabbitMQ clients #52416
  • Cifras de pacote SSL e protocolos habilitados são ignorados por Kafka clients #52413
  • O endpoint de integridade falha com um erro interno para um caminho com um segmento intermediário desconhecido #52411
  • O aplicativo servlet falha ao iniciar quando as propriedades do servidor de recursos de token opaco e JWT estão configuradas #52409
  • Os executores podem ser invocados após o contexto do aplicativo ser fechado durante a inicialização #52408
  • Vincular beans @ConfigurationProperties simultaneamente pode corromper BoundConfigurationProperties e falhar na ligação #52406
  • JavaMailSender configurado automaticamente não aplica cifras de pacote SSL ou protocolos habilitados #52404
  • A raiz do caminho de classe não pode ser resolvida em jars executáveis após #52246 #52402
  • A serialização Kotlin não recua quando JSON-B é o único conversor JSON #52389
  • Os parâmetros da matriz distorcem os valores passados para corresponder a todos os seletores restantes ao usar WebMvc ou WebFlux #52378
  • Pacotes SSL de nome de servidor com nomes de servidor em letras maiúsculas não são usados com Netty #52364
  • Os locais dos dados de configuração com colchetes no caminho não são carregados corretamente #52360
  • Fechar o contexto pode travar quando a suspensão do pool Hikari estiver habilitada #52359
  • OriginTrackedPropertiesLoader elimina a linha após um comentário que termina com uma barra invertida #52357
  • Fechar um contexto filho interrompe o thread keep-alive #52344
  • As cópias MimeMappings de DEFAULT estão vazias e equals é assimétrico #52342
  • StringHttpMessageConverter não pode ser substituído por um personalizador de conversores de mensagens HTTP #52336
  • ConfigurationPropertyName aceita incorretamente um colchete de abertura no final de um nome #52334
  • Diretórios criados pela extração de ferramentas jarmode tornam as camadas Docker não reproduzíveis #52330
  • As propriedades de atualização do cluster de alface são ignoradas quando o cluster não é configurado usando propriedades spring.data.redis.cluster #52328
  • BasicJsonParser manipula incorretamente chaves em valores de string #52326
  • MessageSourceMessageInterpolator manipula mal chaves de fechamento desequilibradas #52324
  • BasicJsonParser não ignora espaços em branco ao redor dos elementos de uma lista #52318
  • ZipContent não lida com nomes de diretórios aninhados com caracteres multibyte #52315
  • RabbitMQ AMQP 1.0 não deve definir uma troca vazia por padrão #52305
  • spring.data.redis.database é ignorado ao configurar nós mestre/réplica #52189
