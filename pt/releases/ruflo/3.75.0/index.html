#ruflo v3.75.0

Esta versão corrige 25 problemas relatados por @sparkling e Dream Cycle.

Correções

  • Escritas atômicas gravam cada byte (#4888, #4909). writeFileAtomic usado para verificar uma chamada writeSync. Em uma breve escrita, ele renomeou um arquivo truncado e ainda relatou sucesso.
  • Os salvamentos de padrão com falha são relatados (#4880, #4913). flushToDisk() retorna false quando a gravação falha, mantém os padrões marcados como não salvos e registra lastFlushError no status de persistência.
  • memory_search_unified (#4876, #4913):
    • Informa quais namespaces falharam (namespaceErrors).
    • searchTime é agora quanto tempo demorou a busca.
    • Pesquisa até 4 namespaces por vez, com classificação inalterada.
  • Pesquisa de padrões (#4714, #4916). Uma pesquisa que não encontra nada retorna degraded: false e um simples "sem correspondência". Uma leitura com falha agora é relatada como um erro e não como um resultado vazio.
  • aidefence_learn (#4862, #4914). O feedback sobre dados pessoais (PII) não é mais registrado como uma injeção imediata perdida. retract: true remove exatamente uma falha registrada.
  • AIDefence CORE-005 (#4715, #4915; @claude-flow/aidefence 3.1.2). Prosa que termina uma frase com "...onde você está agora." não é mais sinalizado como troca de função. Formas disfarçadas ainda são capturadas.
  • Os esquemas de ferramentas indicam os limites reais (#4886, #4892, #4887, #4912):
    • aidefence_scan.input e agentdb_hierarchical-store.value estão limitados a 10.000 unidades de código UTF-16.
    • Os campos identificadores do hooks_post-task agora indicam os caracteres e o comprimento permitidos.
  • IDs de modelo exatos para agent_spawn (#3215, #4917). Ele aceita IDs de modelo de provedor exatos, não apenas os cinco aliases integrados.
  • O modelo de incorporação configurado é usado (#2305, #4919). A memória lê .claude-flow/embeddings.json. Uma loja que já contém vetores mantém sua dimensão.
  • O estado durável segue a raiz do projeto (#2633, #4928; @claude-flow/cli-core 3.7.7). Memória, piloto automático, estado neural e de métricas são resolvidos na raiz do projeto quando você executa comandos de um subdiretório.
  • Coordenador Rainha (#4902, #4908; @claude-flow/swarm 3.0.5). Agora homenageia enableFailover e maxDelegationAttempts.
  • LearningBridge (#4884, #4924; @claude-flow/memory 3.3.0). Um insight acessado após a consolidação inicia uma nova trajetória, portanto continua contribuindo com sinais de aprendizado.
  • AGENTS.md gerado (#3153, #4918). Ele nomeia apenas ferramentas MCP registradas. Um teste verifica cada modelo.

Novo

  • ruflo start all (#1177, #4918). Executa o init do projeto, se necessário, depois o init da memória, inicia o daemon se não estiver em execução e, em seguida, inicia a sessão.
  • ruflo plugins host install|update|uninstall|enable|disable|sync|status (#2854, #4921). Gerencia plug-ins Claude Code e Codex juntos. Ele nunca passa por um shell e --dry-run imprime o argumento exato.
  • Início duplo (#2638, #2640, #4925; @claude-flow/codex 3.0.8):
    • AGENTS.md é a única fonte para as seções compartilhadas e CLAUDE.md as importa.
    • init ignora o que os plugins ruflo instalados já fornecem. Passe --full para copiar tudo.
  • Escopos de memória (#1227, #4923). Um scope (project, local, user) opcional para armazenamento, recuperação e pesquisa de memória, além de uma ferramenta memory_list_scopes.
  • Ferramentas de inventário:
    • agentdb_hierarchical-list e agentdb_hierarchical-get (#4712, #4924) percorrem o armazenamento persistente, inclusive após o cache de 5.000 entradas.
    • agentdb_pattern-list, agentdb_skill-list, agentdb_skill-get e agentdb_hierarchical-stats (#4707, #4926).
  • AutoMemória (#4851, #4852, #4922):
    • O gancho encontra @claude-flow/memory sozinho em árvores de trabalho frescas.
    • Uma chave com entradas duplicadas agora lista os IDs correspondentes.
    • Novos comandos read --all, read-id e dedupe. dedupe apenas visualiza, a menos que você passe --apply.
  • Alternar plug-in PII (#4861, #4920). A federação, a inteligência e o console possuem uma opção piiGuard separada, portanto, as recusas de dados pessoais podem ser desativadas enquanto a triagem secreta permanece ativada.

Também incluído

  • zod ^4.6.7 em reivindicações, ganchos e plug-ins 12 v3 (#4904).
  • Dependências opcionais não registradas removidas dos plugins (#4901).
