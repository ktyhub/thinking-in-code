Verifique a assinatura da imagem Docker

Verifique usando o hash de commit fixado (recomendado): Um hash de commit é criptograficamente imutável, então esta é a maneira mais forte de garantir que você está usando a chave de assinatura original:

cosign verify \
  --key https://raw.githubusercontent.com/BerriAI/litellm/0112e53046018d726492c814b3644b7d376029d0/cosign.pub \
  ghcr.io/berriai/litellm:v1.105.0

Verifique usando a tag de lançamento (conveniência): As tags são protegidas neste repositório e são resolvidas com a mesma chave. Esta opção é mais fácil de ler, mas depende das regras de proteção de tags:

cosign verify \
  --key https://raw.githubusercontent.com/BerriAI/litellm/v1.105.0/cosign.pub \
  ghcr.io/berriai/litellm:v1.105.0
