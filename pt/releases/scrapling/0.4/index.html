Raspagem v0.4

O maior lançamento do Scrapling até agora — apresentando a estrutura Spider, rotação de proxy e grandes melhorias no analisador

Esta versão traz uma estrutura de spider/crawling totalmente assíncrona, gerenciamento inteligente de proxy e alterações significativas no API que tornam o Scrapling mais poderoso e consistente. Por favor, revise a seção de alterações importantes com cuidado antes de atualizar.

🕷️ Estrutura Aranha

Uma nova estrutura de rastreamento assíncrono construída sobre anyio para scraping estruturado e em grande escala:

from scrapling.spiders import Spider, Response

class MySpider(Spider):
  name = "demo"
  start_urls = ["https://example.com/"]

  async def parse(self, response: Response):
      for item in response.css('.product'):
          yield {"title": item.css('h2::text').get()}

MySpider().start()
  • Scrapy-like Spider API: Defina spiders com start_urls, retornos de chamada parse assíncronos, objetos Request/Response e fila de prioridade.
  • Rastreamento simultâneo: limites de simultaneidade configuráveis, limitação por domínio e atrasos de download.
  • Suporte multissessão: Interface unificada para solicitações HTTP e navegadores headless furtivos em um único spider - roteia solicitações para diferentes sessões por ID. Suporta inicialização de sessão lenta.
  • Pausar e retomar: persistência de rastreamento baseada em pontos de verificação. Pressione Ctrl+C para desligar normalmente; em seguida, reinicie para continuar de onde parou.
  • Modo de streaming: Transmita itens copiados conforme eles chegam via async for item in spider.stream() com estatísticas em tempo real - ideal para UI, pipelines e rastreamentos de longa duração.
  • Detecção de solicitação bloqueada: detecção automática e nova tentativa de solicitações bloqueadas com lógica personalizável.
  • Exportação integrada: Exporte resultados por meio de ganchos e seu próprio pipeline ou JSON/JSONL integrado com result.items.to_json() / result.items.to_jsonl() respectivamente.
  • Ganchos de ciclo de vida: on_start(), on_close(), on_error(), on_scraped_item() e mais ganchos para controle total sobre o ciclo de vida do rastreamento.
  • Estatísticas detalhadas de rastreamento: rastreie solicitações, respostas, bytes, códigos de status, proxies, detalhamentos por domínio/sessão, contagens de nível de log e muito mais.
  • suporte uvloop: Passe use_uvloop=True para spider.start() para execução assíncrona mais rápida quando disponível.

🔄 Rotação de proxy

  • Nova classe ProxyRotator com rotação segura para rosca. Funciona com todos os buscadores e sessões: 
    from scrapling import ProxyRotatorrotator = ProxyRotator(["http://proxy1:8080", "http://proxy2:8080"])Fetcher.get(url, proxy_rotator=rotator)
  • Estratégias de rotação personalizadas: crie sua própria lógica de rotação de proxy
  • Substituição de proxy por solicitação: Passe proxy= para qualquer chamada get()/post()/fetch() individual para substituir o proxy de sessão para essa solicitação.

🌐 Melhorias no coletor de navegador

  • Bloqueio de domínio: Novo parâmetro blocked_domains em DynamicFetcher/StealthyFetcher para bloquear solicitações para domínios específicos (subdomínios correspondidos automaticamente).
  • Repetições automáticas: Os buscadores do navegador agora tentam novamente em caso de falha com os parâmetros retries (padrão: 3) e retry_delay (padrão: 1s). Inclui detecção de erros com reconhecimento de proxy.
  • Metadados de resposta: Response.meta dict armazena automaticamente o proxy usado e mescla os metadados da solicitação.
  • Response.follow(): Crie objetos Request de acompanhamento com fluxo de referência automático, projetados para o sistema spider.
  • Sem reprodução automática: as sessões do navegador agora estão bloqueando o conteúdo de reprodução automática, o que causava problemas antes.
  • Velocidade: Furtividade e velocidade aprimoradas ajustando sinalizadores do navegador.

🔧 Correções de bugs e melhorias

  • Otimização do analisador: otimizou o analisador para operações repetidas, melhorando o desempenho.
  • Páginas com erros: Corrigido um bug que fazia com que o navegador não fechasse quando as páginas apresentavam erros.
  • Corpo vazio: trata respostas com corpo vazio.
  • Loop Playwright: Resolvendo um problema ao deixar o loop Playwright aberto quando a conexão CDP falha
  • Segurança de tipo: corrigidos todos os erros mypy e adicionadas dicas de tipo em corpos de função não digitados. Adicionados mypy e pyright ao fluxo de trabalho de CI.

⚠️ Mudanças importantes

  • css_first/xpath_first removido: Use css('.selector').first, css('.selector')[0] ou css('.selector').get().
  • Todas as seleções agora retornam Selectors: css('::text'), xpath('//text()'), css('::attr(href)') e xpath('//@href') agora retornam Selectors (envolvendo nós de texto em objetos Selector com tag="#text") em vez de TextHandlers. Isso torna o API consistente em todos os métodos de seleção e dicas de tipo.
  • Response.body é sempre bytes: Anteriormente poderia ser str ou bytes, agora retorna sempre bytes.
  • Comportamento de get()/getall(): Em Selector: get() retorna TextHandler (HTML serializado ou valor de texto), getall() retorna TextHandlers. Aliases: extract_first = get, extract = getall. O antigo get_all() no Selectors foi removido.
  • Selectors.first/.last: Acessadores seguros que retornam Selector | None em vez de aumentar IndexError.
  • Constantes internas renomeadas: DEFAULT_FLAGS → DEFAULT_ARGS, DEFAULT_STEALTH_FLAGS → STEALTH_ARGS, HARMFUL_DEFAULT_ARGS → HARMFUL_ARGS, DEFAULT_DISABLED_RESOURCES → EXTRA_RESOURCES.

🔨 Outras mudanças

  • Mudanças de dependência: tldextract substituído por tld, removido _html_utils.py interno em favor de w3lib.html.replace_entities, adicionado typing_extensions como um requisito rígido.
  • Revisão de documentos: mudança completa de MkDocs para Zensical, nova seção de documentação do spider, atualização de todas as páginas existentes e adição de novas referências API.
