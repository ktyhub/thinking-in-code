Scrapling v0.3.0 Release Notes

🎉 Lançamento importante — Revisão completa da arquitetura Scrapling v0.3 representa a atualização mais significativa na história do projeto, apresentando uma reescrita arquitetônica completa, melhorias consideráveis de desempenho e novos recursos poderosos, incluindo integração de IA e recursos interativos de shell Web Scraping. Esta versão inclui várias alterações importantes; revise os release notes com atenção.

🚀 Principais novos recursos

Arquitetura Baseada em Sessão

  • Novas classes de sessão: reescrita completa introduzindo suporte de sessão persistente
    • FetcherSession - solicitações HTTP com gerenciamento de estado persistente que funciona com código sincronizado e assíncrono
    • DynamicSession/AsyncDynamicSession - Automação do navegador mantendo o navegador aberto até terminar
    • StealthySession/AsyncStealthySession - Navegação furtiva enquanto mantém o navegador aberto até terminar
  • Gerenciamento assíncrono de guias do navegador: um novo recurso de conjunto de guias por meio do argumento max_pages que gira as guias do navegador para buscas simultâneas do navegador
  • Sessões simultâneas: execute várias sessões isoladas simultaneamente Consulte a seção Fetching no site para obter mais detalhes.

Muitas novas capacidades furtivas/anti-bot

  • 🤖 Cloudflare Solver: [Resolução de desafio Cloudflare Turnstile] automática (https://scrapling.readthedocs.io/en/latest/fetching/stealthy/#cloudflare-protection-bypass) em StealthyFetcher e suas classes de sessão
  • Personificação de impressão digital do navegador: imite impressões digitais TLS de navegadores reais, cabeçalhos de navegador correspondentes à versão, suporte a HTTP/3 e muito mais com a nova classe Fetcher
  • Modo furtivo aprimorado: O modo furtivo para DynamicFetcher e suas classes de sessão agora é mais robusto e confiável (também conhecido como PlayWrightFetcher)

Integração de IA e servidor MCP

  • Servidor MCP integrado: Servidor de protocolo de contexto de modelo para web scraping assistido por IA
  • **6 ferramentas poderosas **: get, bulk_get, fetch, bulk_fetch, stealthy_fetch, bulk_stealthy_fetch
  • Extração inteligente de conteúdo: converta páginas/elementos da web em Markdown, HTML ou extraia uma versão limpa do conteúdo de texto
  • Suporte ao seletor CSS: use o mecanismo Scrapling para direcionar elementos específicos com precisão antes de entregar o conteúdo à IA
  • Anti-Bot Bypass: lidar com a catraca Cloudflare e outras proteções
  • Suporte a proxy: use proxies para anonimato e segmentação geográfica
  • Personificação de navegador: imite navegadores reais com impressão digital TLS, cabeçalhos de navegador reais correspondentes a essa versão e muito mais
  • Processamento paralelo: extraia vários URLs simultaneamente para obter eficiência
  • e mais...

Novo shell interativo Web Scraping

  • **Um novo shell **: shell IPython personalizado com muitos atalhos integrados inteligentes, como get, post, put, delete, fetch e stealthy_fetch
  • Gerenciamento inteligente de páginas: novos comandos page e pages para armazenar automaticamente a página atual e o histórico de todas as solicitações feitas através do shell
  • Integração Curl: Converta comandos curl do DevTools do navegador com funções uncurl e curl2fetcher em solicitações Fetcher
  • e mais...

Raspe do terminal sem programar

  • Novos comandos de extração: scraping baseado em terminal sem programação
    • scrapling extract get/post/put/delete - Solicitações HTTP simples
    • scrapling extract fetch - Scraping de conteúdo dinâmico
    • scrapling extract stealthy-fetch - Desvio anti-bot
  • Baixa páginas da web e salva seu conteúdo em arquivos.
  • Converte HTML em formatos legíveis como Markdown, mantém-no como HTML ou apenas extrai o conteúdo de texto da página.
  • Suporta seletores CSS personalizados para extrair partes específicas da página.
  • Lida com solicitações HTTP e busca por meio de navegadores.
  • Altamente personalizável com cabeçalhos personalizados, cookies, proxies e o resto das opções. Quase todas as opções disponíveis através do código também são acessíveis através do terminal.
  • e mais...

🔧 Melhorias Técnicas

Melhorias de desempenho

  • O Fetcher agora é 4 vezes mais rápido - Sim, você leu certo!
  • DynamicFetcher agora é ~60% mais rápido - Uma versão muito mais rápida dependendo da sua configuração (especialmente no modo furtivo)
  • StealthyFetcher agora é 20–30% mais rápido - Usando a nova estrutura e começando a usar nossa implementação em vez da interface Camoufox Python
  • 50%+ ganhos de velocidade combinados em métodos de seleção de núcleo (find_by_text, find_similar, find_by_regex, relocate, etc.) 🚀
  • ~10% de aumento na velocidade dos primeiros métodos CSS/XPath - css_first e xpath_first agora são mais rápidos que css e xpath
  • Método get_all_text() 40% mais rápido para extração de conteúdo
  • 20% de melhoria na velocidade na realocação de elementos adaptativos
  • Otimização das propriedades de navegação — Propriedades como next, previous, below_elements e outras agora são visivelmente mais rápidas
  • Operações de limpeza de texto 5x mais rápidas
  • Melhorias na eficiência da memória com importações otimizadas e sobrecarga reduzida
  • ⚡ Importações extremamente rápidas: tempo de inicialização reduzido com carregamento otimizado do módulo
  • Melhores benchmarks: Todas as melhorias de velocidade que o Scrapling obteve o tornaram muito mais rápido do que antes, em comparação com outras bibliotecas (1775x mais rápido que o BeautifulSoup e 5,1x mais rápido que o AutoScraper, verifique benchmarks)

Arquitetura/qualidade de código e qualidade de vida

  • Contexto persistente: todos os buscadores baseados em navegador agora usam contexto persistente por padrão. (Resolve #64 também)
  • Usando msgspec para validar todos os buscadores baseados em navegador muito rapidamente antes de executar as solicitações, agora é mais fácil depurar erros.
  • Todos os cookies retornados dos buscadores agora correspondem ao formato aceito pelo mesmo buscador. Assim, você pode recuperar cookies e passá-los novamente para todos os buscadores e suas classes de sessão.
  • Linting e formatação mais rápidos devido à migração para ruff
  • Sistema de compilação moderno: migrado de setup.py para pyproject.toml 📦
  • Melhores ações e fluxos de trabalho do GitHub para desenvolvimento e testes mais suaves
  • **🎨 Dicas de tipo aprimoradas **: cobertura completa de tipos com padrões Python modernos para melhor suporte e confiabilidade IDE
  • Cleaner Codebase: código morto removido e funções principais otimizadas 🧹
  • 🚀 Compatibilidade com versões anteriores: atalhos adicionados para manter a compatibilidade com códigos mais antigos

Mudanças significativas

Versão mínima do Python

  • Python 3.10+ Obrigatório: Suporte eliminado para Python 3.9 e inferiores

Nomenclatura de classes e métodos

Essas renomeações têm como objetivo melhorar a clareza e a consistência, principalmente para novos usuários.

  • Adaptor → Selector: classe de análise principal renomeada (mas ainda pode ser importada como Adaptor para compatibilidade com versões anteriores)
  • Adaptors → Selectors: Classe de coleção renomeada (mas ainda pode ser importada como Adaptors para compatibilidade com versões anteriores)
  • auto_match → adaptive: Parâmetro renomeado em todos os métodos
  • adaptor_arguments → selector_config: Parâmetro de configuração renomeado
  • automatch_domain → adaptive_domain: Parâmetro de domínio renomeado
  • additional_arguments → additional_args: Nome do parâmetro abreviado
  • ⚠️ text/body → content: O parâmetro do construtor do seletor agora aceita os formatos str e bytes
  • PlayWrightFetcher → DynamicFetcher: classe de automação do navegador renomeada (mas ainda pode ser importada como PlayWrightFetcher para compatibilidade com versões anteriores)
  • DynamicFetcher não tem mais a lógica/argumentos do NSTBrowser já que é inútil deixar essa lógica agora de qualquer maneira.
  • O argumento sem cabeça do StealthyFetcher não pode mais aceitar 'virtual' como argumento já que não estamos usando a biblioteca do Camoufox no momento em nada além de obter o caminho de instalação do navegador e o restante das opções de inicialização
