#AstrBot v4.22.3

  • Registro de atualização (chinês simplificado)
  • Changelog(Inglês) <a id="chinês"></a>

O que mudou

Novo

  • Adicionado provedor vllm_rerank para suportar rerank_api_suffix configurável, que pode se adaptar de forma flexível a diferentes caminhos API. (#7278)
  • Adapte o suporte de extração de uso de token do llama.cpp para aprimorar as estatísticas de token e os recursos de análise de faturamento. (#7358)
  • WebUI agrupa arquivos de trabalho do Monaco Editor para evitar falhas de download do CDN. (#7249)
  • Novo painel de estatísticas de visão geral do modelo/plataforma. (#7152)

Otimização

  • Otimize o processamento de mensagens OpenAI, se a lista content estiver vazia, defina-a como None e reduza a taxa de exceção em conteúdo vazio. (#6551)
  • Otimize o layout e o estilo da página do provedor para melhorar a consistência geral do layout da página de configurações. (#7248)
  • Quando o usuário estiver logado, a página de boas-vindas saltará diretamente, reduzindo as etapas para entrar novamente na página de login. (confirmar)

Correção

  • Corrigido o problema em que o executor MCP no Windows não herdava todas as variáveis de ambiente do sistema, causando exceção de inicialização. (#7054)
  • Corrigido um problema em que trechos de reflexão do Gemini vazavam para links de mensagens visíveis ao usuário. (#7196)
  • Corrigido o erro 400 Invalid argument causado pelo requisito de formato function_response no Gemini (OpenAI compatível com API). (#7216
  • Correção de avisos de erro e problemas de recuperação quando a inicialização da base de conhecimento falha. (#7243)
  • Corrigida a compatibilidade do Bailian Rerank com formatos de resposta novos e antigos para evitar falhas de análise. (#7217)
  • A imagem Docker complementa a dependência do codificador AMR e corrige o problema de falta de transcodificação de áudio em alguns cenários de implantação. (#7247)
  • Corrigido o problema de indisponibilidade do proxy SOCKS5 causado pela falta da dependência pysocks na instalação do pip. (#7221)
  • Reparar a lógica de processamento do cached_tokens no _extract_usage para evitar confusão nas estatísticas do token. (#6719)
  • Melhore a proteção contra desconexão SSE, envie ativamente batimentos cardíacos sob transmissão compactada e reduza desconexões acidentais do WebChat. (#7003)
  • Corrigido erro 400 causado por mensagem vazia do assistente sob estrito API. (#7202)
  • Adicionado reparo de dependência qrcode para função de código QR ausente e restaurada a função de geração de código QR. (confirmar)
  • Corrigido o problema de experiência interativa do componente de entrada digital do configurador para evitar desvios de processamento em cenários de entrada anormais. (#7153)
  • Corrigido Record.path sendo tratado incorretamente como um campo obrigatório no Pydantic v2. (#7048) <a id="english"></a>

O que mudou (PT)

Novos recursos

  • Adicionado rerank_api_suffix configurável para o provedor vllm_rerank para suportar caminhos API personalizados.（#7278）
  • Adicionado suporte de extração de uso de token para llama.cpp para melhorar a contabilidade de token.（#7358）
  • Trabalhadores do Monaco Editor agrupados na WebUI para que a edição do código não dependa de downloads externos de CDN.（#7249）
  • Adicionada uma nova visão geral de estatísticas para uso de modelo e plataforma.（#7152）
  • Redirecionou usuários logados para a página de boas-vindas em vez da página de login.（commit）

Melhorias

  • Melhor tratamento de mensagens OpenAI definindo a mensagem content como None quando as listas de conteúdo estão vazias, reduzindo casos extremos de carga útil vazia.
  • Layout e estilo da página do provedor aprimorados para manter as páginas de configurações consistentes.（#7248）
  • Tratamento refinado de sucesso de conexão e mensagens quando os usuários já estão logados.（commit）

Correções de bugs

  • Herdou todas as variáveis de ambiente do sistema no executor do Windows MCP para corrigir problemas de inicialização dependentes do ambiente.（#7054）
  • Partes de pensamento Gemini filtradas de cadeias de mensagens voltadas para o usuário.（#7196）
  • Corrigida a compatibilidade do Gemini function_response para evitar respostas do 400 Invalid argument.（#7216）
  • Melhor tratamento de erros de inicialização da base de conhecimento.（#7243）
  • Correção da análise de reclassificação Bailian para formatos de resposta novos e antigos.（#7217）
  • Adicionado suporte ao codificador AMR nas compilações Docker para corrigir a falta de suporte ao codec de áudio.（#7247）
  • Adicionada a dependência pysocks para que as instalações do pip possam usar o proxy SOCKS5 corretamente.（#7221）
  • Corrigida manipulação de token em cache _extract_usage.（#6719）
  • Enviou pacotes de pulsação SSE para evitar a desconexão do WebChat sob compactação.（#7003）
  • Corrigidos erros 400 causados por mensagens de assistente vazias em APIs estritos.（#7202）
  • Adicionada dependência ausente do qrcode para restaurar a geração do código QR.（commit）
  • Corrigido UX de entrada de número no renderizador de configuração.（#7153）
  • Corrigido Record.path sendo tratado incorretamente conforme exigido no Pydantic v2.（#7048）
