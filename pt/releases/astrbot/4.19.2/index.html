#AstrBot v4.19.2

O que mudou

Novo

  • Adaptador de plataforma KOOK integrado (#5658).
  • Adicionado suporte para Emoji pré-reação do Discord (#5609).
  • Adicionado suporte de telegrama para saída em tempo real de streaming sendMessageDraft API (#5726)
  • Suporta capacidade de acompanhamento de mensagens quando o Agente está em execução, e as mensagens de acompanhamento são injetadas no Agente em tempo real (#5484).
  • Integre o DeerFlow Agent Runner e otimize o streaming (#5581).
  • Adicionado novo shell, ferramenta ipython que contém informações do sistema operacional para melhorar a taxa de sucesso de chamadas de ferramentas no Windows (#5677).
  • Suporte sandbox para Shipyard-neo - Suporte para auto-iteração de habilidades (#5028).
  • Adicionada seleção do modo de transmissão ChatUI WebSocket, OpenAPI Chat API suporta conexão WebSocket (#5410).
  • Suporta mensagem de resposta de erro personalizada e lógica evasiva do Persona (#5547).
  • Empacotar arquivos estáticos da WebUI para rodar e substituir os logs do astrbot CLI por inglês (#5665).
  • Interface de bate-papo aprimorada e experiência responsiva móvel (#5635).
  • Otimize a lógica de tratamento de falhas do plug-in e a experiência de interação de lista estendida (#5535).

Correção

  • Corrigida incompatibilidade de palavra-chave do parâmetro de tempo limite de inicialização do MCP (#5743).
  • Corrigida a condição de corrida da ferramenta MCP que causava o erro "a conclusão não pode ser analisada" (#5534).
  • Corrigido o problema de transmissão transparente direta de URLs não HTTPS no adaptador LINE (#5697).
  • Corrigido o problema de status personalizado instável da barra lateral WebUI (#5670).
  • Corrigido o problema em que o adaptador KOOK gera logs de depuração redundantes ao receber mensagens e respostas de pulsação.
  • Corrigido um problema em que a variável de ambiente DEMO_MODE não era analisada corretamente como um valor booleano (#5676).
  • Corrigido o problema do subagente não conseguir receber corretamente o caminho da imagem local (imagem de referência) (#5579).
  • Corrigido o comando /model causando comportamento enganoso ao mudar para um modelo de provedor diferente (#5578).
  • Corrigido um problema nos registros de conversas onde o deslocamento do fuso horário UTC não era tratado, causando exceções de carimbo de data/hora (#5580).
  • Corrigido um problema em que estatísticas duplicadas da plataforma causavam exceções ao importar backups (#5594).
  • Corrigida a configuração do max_agent_step não sendo aplicada aos Agentes filhos (#5608).
  • Corrigida a classificação da lista de plugins e a lógica de filtragem de pesquisa (#5559).
  • Corrigido o problema em que o ambiente Node.js não era necessário ao usar uv sync.

O que mudou (PT)

Novos recursos

  • Adaptador de plataforma KOOK integrado (#5658).
  • DeerFlow Agent Runner integrado com suporte de streaming otimizado (#5581).
  • feat(telegram): suporta sendMessageDraft API (#5726)
  • Capacidade integrada de autoiteração de habilidades Neo com gerenciamento completo do ciclo de vida (candidato, liberação, exclusão) por meio da sandbox Shipyard Neo (#5028).
  • Adicionado suporte para emoji pré-confirmado do Discord (#5609).
  • Adicionada seleção do modo de transporte WebSocket para a interface de chat (#5410).
  • Adicionadas informações do sistema operacional às descrições das ferramentas com cobertura de testes unitários (#5677).
  • Adicionado tratamento de mensagens de acompanhamento em ToolLoopAgentRunner (#5484).
  • Adicionado suporte para mensagens de resposta de erro personalizadas com lógica de fallback (#5547).
  • Pacote de arquivos estáticos WebUI no pacote wheel e substituição dos logs do astrbot CLI por inglês (#5665).
  • Desempenho de IO assíncrono otimizado e cobertura de benchmark adicionada (#5737).
  • Criação de chave API refatorada e testes de unidade adicionados para rotas API abertas.
  • Mensagens de erro aprimoradas para falhas de execução de IA em executores de agentes.
  • Interface de bate-papo aprimorada e capacidade de resposta móvel (#5635).
  • Melhor tratamento de falhas de plug-ins e UX da lista de extensões (#5535).

Correções de bugs

  • Corrigida incompatibilidade de palavra-chave de tempo limite de inicialização do MCP (#5743).
  • Correção da condição de corrida das ferramentas MCP causando erro completion 无法解析 (#5534).
  • Adaptador LINE corrigido permitindo que URLs não-HTTPS passem diretamente (#5697).
  • Corrigido o estado instável de personalização da barra lateral na WebUI (#5670).
  • Corrigido log de depuração excessivo no adaptador KOOK para mensagens recebidas e respostas de pulsação.
  • Correção da variável de ambiente DEMO_MODE que não era analisada corretamente como booleana (#5676).
  • Corrigida a falha do subagente ao receber corretamente os caminhos da imagem local (imagem de referência) (#5579).
  • Corrigido comportamento enganoso do comando /model ao mudar para um modelo de um provedor diferente (#5578).
  • Correção do deslocamento de fuso horário UTC não tratado, causando carimbos de data/hora incorretos em registros de conversação (#5580).
  • Corrigida falha na importação de backup devido a entradas duplicadas de estatísticas da plataforma (#5594).
  • Corrigida a configuração do max_agent_step não sendo aplicada aos subagentes (#5608).
  • Corrigida a classificação da lista de plugins e a lógica de filtragem de pesquisa (#5559).
  • Corrigido o requisito de ambiente Node.js ausente durante o uv sync.
