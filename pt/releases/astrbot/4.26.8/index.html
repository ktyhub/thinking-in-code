#AstrBot v4.26.8

[4.26.8] - 28/07/2026

Devemos cultivar nosso jardim. Devemos cultivar nossos próprios jardins.

Lançamos um novo mercado de plugins: AstrBot Cloud. Desenvolvedores e usuários de plug-ins podem usar esta plataforma para fazer upload, gerenciar e explorar plug-ins do AstrBot. Os dados de plug-ins do AstrBot WebUI serão redirecionados para este mercado. Para mais detalhes, leia: Documentos AstrBot | Publicação de plug-in

Lançamos um novo sistema de mercado de plug-ins [AstrBot Cloud] (https://cloud.astrbot.app), uma plataforma onde desenvolvedores e usuários de plug-ins podem fazer upload, gerenciar e navegar por plug-ins. Os dados do mercado de plugins dentro do AstrBot WebUI serão sincronizados a partir da plataforma. Para obter detalhes, acesse Documentação do AstrBot | Lançamento do plug-in.

Adicionado

  • Adicionados controles de nível de log por plugin ao painel e plugin API. (#9342)
  • Adicionado suporte de configuração de modelo para o provedor FishAudio TTS. (#9381)
  • Adicionada categorização de log de plataforma e uma alternância de console para ocultar entradas de bate-papo do usuário. (#9165)
  • Adicionado um provedor de incorporação DashScope com suporte a modelo multimodal. (#9137)
  • Adicionado um navegador de arquivos do espaço de trabalho ao ChatUI (somente projetos). (#9432)

Alterado

  • Citações de respostas parciais honradas em mensagens do Telegram. (#9236)
  • Uso relatado da CPU do processo sem bloquear o loop de eventos. (#9367)
  • Adicionado o mapeamento de valores padrão para campos de configuração de dicionário. (#9414)

Corrigido

  • Correção do acesso FAISS em caminhos do Windows contendo caracteres não ASCII, restauração de importações lentas para evitar travamentos de inicialização e rejeição de dimensões inválidas para novos índices. (#8323, #9350, #9385)
  • Carimbos de data e hora atualizados enquanto mantém o bloqueio relevante e o estado do agendador cron desacoplado da sincronização do banco de dados para que os trabalhos persistentes sempre sejam carregados. (#9349, #9419)
  • Pontos de verificação preservados após solicitações LLM com falha, manutenção da ordem de resultados do lote de incorporação e uso do provedor atual ao regenerar mensagens. (#9358, #9359, #9241, #9402)
  • Verificou o texto citado quanto à segurança do conteúdo, respeitou os limites do analisador de encaminhamento com valor zero e removeu os separadores finais dos contornos das mensagens. (#9232, #9394, #9390)
  • Resolvidos conflitos de filtro de data Tavily, opções de conclusão OpenAI aninhadas e incompatibilidades de protocolo de reclassificação Bailian. (#9234, #9386, #9413)
  • Tratamento de erros de comando DingTalk e menções de rich text, retornou tipos MIME de imagem WebChat corretos e correção da validação de comando de barra Discord. (#9389, #9319, #9411)
  • Exibiu o progresso do salvamento da configuração do plug-in, evitou o fechamento acidental da caixa de diálogo da pessoa, removeu barras de rolagem duplicadas e evitou que os uploads de plug-ins locais fossem interrompidos. (#9327, #9238, #9382, #9406)
  • Melhor desempenho da lista de conversas e prevenção de atualizações assíncronas obsoletas. (#9226)
  • Atualizado o modelo MiMo TTS padrão para mimo-v2.5-tts. (#9428)
  • Ignoradas variáveis de proxy do sistema quando nenhum proxy estiver configurado, evitando que solicitações locais API sejam interceptadas. (#8897)
  • Classificações de recuperação esparsas por base de conhecimento preservadas durante a fusão de classificações para evitar ordenação distorcida em índices FTS5 independentes. (#9426)
  • Recarregamentos de extensão C protegidos para evitar falhas no processo. (#9148)

Documentação

  • Atualizados os banners README e recomendado a integração oficial do bot QQ.
  • Adicionado um guia de implantação do Windows Docker Desktop. (#9339)
  • Ampliação dos guias de publicação de plugins em inglês e chinês. (#9415)

Manutenção

  • Atualizadas dependências agrupadas de ações GitHub e docker/login-action. (#9333, #9416)
  • Fixado Ruff em 0.15.22. (#9369)
  • Impediu que testes de caminho do atualizador criassem diretórios perdidos. (#9376)

Novo

Mudança

  • As mensagens do Telegram suportam a retenção de referências de respostas parciais. (#9236)

Correção

  • Corrija a leitura e gravação do FAISS em caminhos não ASCII do Windows, restaure a importação atrasada para evitar congelamentos de inicialização e recuse-se a configurar dimensões inválidas para novos índices. (#8323, #9350, #9385)
  • Atualize o carimbo de data/hora durante o período de bloqueio e separe o estado do agendador Cron do estado de sincronização do banco de dados para garantir que as tarefas persistentes sejam sempre carregadas. (#9349, #9419)
  • Preservar pontos de verificação após falhas de solicitação LLM, manter a ordem de resultados de lote incorporada e usar o provedor atual ao regenerar mensagens. (#9358, #9359, #9241, #9402)
  • Execute verificações de segurança de conteúdo no texto citado, lide corretamente com limites de análise direta com valor zero e remova delimitadores no final do resumo da mensagem. (#9232, #9394, #9390)
  • Corrigido conflito de parâmetros de filtro de data Tavily, opções de conclusão OpenAI aninhadas e problemas de compatibilidade do protocolo de reordenação Bailian. (#9234, #9386, #9413)
  • Corrigidos erros de comando DingTalk com manipulação de menção de rich text, tipos MIME de imagem WebChat e validação de nome de comando de barra Discord. (#9389, #9319, #9411)
  • Exibir o progresso de salvamento da configuração do plug-in para evitar o fechamento acidental da janela pop-up de edição de personalidade, remover barras de rolagem duplicadas e evitar que o upload do plug-in local fique preso. (#9327, #9238, #9382, #9406)
  • Melhore o desempenho da lista de sessões e evite atualizações obsoletas causadas por solicitações assíncronas. (#9226)
  • Modelo padrão MiMo TTS atualizado para mimo-v2.5-tts. (#9428)
  • Ignore as variáveis de proxy do sistema quando nenhum proxy estiver configurado para evitar que solicitações locais API sejam interceptadas. (#8897)
  • Preservar classificações de pesquisa esparsas de cada base de conhecimento durante a fusão de classificações para evitar distorção na ordem dos resultados entre índices FTS5 independentes. (#9426)
  • Adicionada proteção para sobrecarga de extensão C para evitar falhas no processo. (#9148)

Documentação

  • Atualizado o banner README e recomendado o uso do acesso oficial do robô QQ.
  • Adicionado guia de implantação do Windows Docker Desktop. (#9339)
  • Guia expandido de lançamento de plug-ins em chinês e inglês. (#9415)

  • Grupo de dependência de ações GitHub e docker/login-action atualizados. (#9333, #9416)
  • Corrigido Ruff para 0.15.22. (#9369)
