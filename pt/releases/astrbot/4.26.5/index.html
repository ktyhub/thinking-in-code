#AstrBot v4.26.5

[4.26.5] - 07/07/2026

Adicionado

  • Adicionado suporte para definir um ID de bot personalizado ao criar uma plataforma digitalizando um código QR. (#9067)
  • Adicionados espaços de trabalho do projeto ChatUI. (#9066)
  • Adicionada exibição aprimorada de anexos do ChatUI. (#9134)
  • Adicionado saneamento de nome de chamada de ferramenta malformado em ToolLoopAgentRunner. (#9144)
  • Adicionados metadados de modelo em seletores e um indicador de uso de token de chat. (#9161)
  • Adicionados diagnósticos de loop de eventos e documentação de diagnóstico expandida. (#9168)
  • Adicionada documentação para compatibilidade entre plataformas e suporte à versão Python.
  • Adicionada cobertura de teste para preservação de raiz de URI de arquivo POSIX. (#8906)

Alterado

  • Registrar a inicialização do watchdog do loop de eventos no nível de informação.
  • Mantenha os metadados do modelo separados dos provedores. (#9161)
  • Estilo polonês da lanchonete na WebUI. (#9173)

Corrigido

  • Habilitado apenas servidores ModelScope MCP sincronizados. (#9084)
  • Melhor manipulação de inicialização e desligamento do MCP client para evitar rotação ociosa e limpar erros, tempos limite e cancelamento. (#9070)
  • Substituição de correspondência de erro de nome duplicado da base de conhecimento frágil por uma pré-verificação. (#9121)
  • Melhor resiliência de recuperação da base de conhecimento em falhas por base de conhecimento e seleção de reclassificação. (#9122)
  • Limpeza de registros KBMedia sobre exclusão de documentos e correção de atualizações de estatísticas da base de conhecimento. (#9120)
  • Alinhamento do contrato CRUD API da base de conhecimento com kb_name, campos de carga útil canônicos e tipos OpenAPI. (#9000)
  • Caminhos de espaço de trabalho personalizados restritos e caminhos de espaço de trabalho personalizados absolutos preservados.
  • Failover de chave API de pesquisa na web aprimorado.
  • Propriedade imposta ao ler sessões ChatUI. (#9141)
  • Preparação temporária segura de atualização do projeto. (#9083)
  • Melhor comportamento de nova tentativa oficial do QQ quando o envio do websocket retorna None. (#8977)
  • Contexto de mensagem citada oficial do QQ preservado. (#9164)
  • Remoção dos IDs de resposta oficiais do QQ no substituto proativo para que respostas passivas superdimensionadas possam ser bem-sucedidas por meio de envio proativo. (#9169)
  • MiMo STT adaptado para modelos V2.5 e rejeitou cargas úteis de áudio não-WAV. (#9118)
  • Carimbos de data e hora do histórico de webchat serializados como strings ISO com reconhecimento de UTC. (#9159)
  • Status de ativação do plugin sincronizado ativado na WebUI. (#9156)
  • Saiu dos contextos MCP anyio na tarefa de ciclo de vida ao desabilitar. (#9132)
  • Corrigida manipulação de pilha de saída SSE vazada que poderia causar espera ocupada no epoll do MCP. (#8307) [4.26.5]: https://github.com/AstrBotDevs/AstrBot/compare/v4.26.4...v4.26.5
