AstrBot v4.20.1

#AstrBot v4.20.1

O que mudou

Novo

  • Provedor MiniMax complementado. (#6318)
  • Adicionada função de exclusão de lote de sessão na página WebUI ChatUI. (#6160)
  • Adicionada configuração do WebUI ChatUI enviando tecla de atalho. (#6272)

Otimização

  • Otimize a compatibilidade do processamento UMO. (#5996)
  • Refatore _extract_session_id para melhorar o processamento de ramificações do tipo chat. (#5775)
  • Otimize o comportamento do componente de chat e use shiki para renderização de blocos de código. (#6286)
  • Otimize a correspondência de cores e a experiência visual do tema WebUI. (#6263)
  • Otimize o pós-processamento do componente OneBot @ para evitar problemas de espaço na análise do texto da mensagem. (#6238)

Correção

  • Corrigido o problema do providers_config não ser sincronizado após a criação de um novo Provedor. (#6388)
  • Corrigido TypeError quando API retorna null choices. (#6313)
  • Corrigido o problema de retorno de chamada de nova tentativa do QQ Webhook sendo acionado repetidamente. (#6320)
  • Corrigido o problema onde delta se torna None no modo streaming, causando erro ao chamar a ferramenta. (#6365)
  • Corrigido erro de texto de descrição do link de serviço do modelo. (#6296)
  • Corrigido um problema em que a IA falhava ao enviar mídia quando o modo de chamada de ferramenta estava definido como skills-like. (#6317)
  • Corrigido um problema em que GIFs eram convertidos incorretamente em imagens estáticas no adaptador Telegram. (#6329)
  • Substitua a fonte do ícone do provedor pelo endereço CDN jsDelivr para corrigir problemas de carregamento de ícones em alguns ambientes. (#6340)
  • Corrigido o problema em que as mensagens de emoticons oficiais do QQ não eram analisadas em texto legível. (#6355)
  • Corrigido o problema em que a página de resultados do streaming travava quando a fila do WebChat estava anormal. (#6123)
  • Corrigido o problema em que a ferramenta de transferência de subagentes era perdida durante a filtragem do plug-in. (#6155)
  • Corrigido o problema de falta de espaços no texto do prompt do Cron e o aviso de descontinuação do utcnow(). (#6192)
  • Corrigido problema de jitter/posicionamento de navegação de hash da barra lateral quando o WebUI é iniciado. (#6159)
  • Corrigido um erro ao remover ValueError com a chave API removida durante a nova tentativa de inicialização. (#6193)
  • Correção da referência do comando de inicialização README atualizada para astrbot run. (#6189)
  • Corrigido o problema onde caracteres de espaço em branco eram perdidos quando Plain.toDict() era mencionado na cena @. (#6244)
  • Corrigido o problema de definição repetida de dependência do provedor. (#6247)
  • Corrigido um problema no Telegram onde respostas comuns eram mal interpretadas como tópicos. (#6174)

Outros

  • Ajuste a configuração do astrbot.service e CI, atualize a versão do GitHub Actions.

O que mudou (PT)

Novos recursos

  • Adicionado adaptador de provedor de conclusão de bate-papo OpenRouter com suporte para cabeçalhos personalizados (#6436).
  • Adicionado provedor MiniMax (#6318).
  • Adicionada exclusão de conversas em lote no WebChat (#6160).
  • Adicionadas configurações de atalho de envio e suporte de localização para entrada de WebChat (#6272).
  • Adicionada ligação de diretório temporário local na configuração do YAML (#6191).

Melhorias

  • Melhor compatibilidade de processamento UMO (#5996).
  • _extract_session_id refatorado para manipulação de tipos de chat (#5775).
  • Melhor comportamento do componente de bate-papo e uso de shiki para renderização de bloco de código (#6286).
  • Cor e comportamento visual do tema WebUI aprimorados (#6263).
  • Melhor manipulação do espaçamento dos componentes OneBot @ (#6238).
  • Melhor validação da lista de verificação de relações públicas e mensagens de encerramento.

Correções de bugs

  • Corrigida a falta de sincronização do providers_config após a criação de novos provedores (#6388).
  • Corrigido TypeError quando API retorna opções nulas (#6313).
  • Corrigidos retornos de chamada repetidos do webhook QQ (#6320).
  • Correção do tratamento nulo de streaming de chamada de ferramenta delta para evitar AttributeError (#6365).
  • Correção do texto do link de serviço do modelo em docs/config (#6296).
  • Corrigida falha no envio de mídia AI quando o modo de chamada de ferramenta está definido como skills-like (#6317).
  • Corrigido GIF sendo enviado como imagem estática no adaptador Telegram (#6329).
  • URLs de registro npm substituídos por jsDelivr CDN para ícones de provedor (#6340).
  • Corrigida a análise da mensagem facial oficial do QQ para texto legível (#6355).
  • Corrigida falha no resultado do stream do WebChat em erros de fila (#6123).
  • Ferramentas de transferência de subagentes preservadas durante a filtragem de plugins (#6155).
  • Corrigido o espaçamento do prompt do cron e uso obsoleto do utcnow() (#6192).
  • Corrigida navegação hash instável da barra lateral na inicialização (#6159).
  • Corrigido ValueError em loop de nova tentativa ao remover uma chave API já removida (#6193).
  • Comando de inicialização atualizado para astrbot run em READMEs (#6189).
  • Espaço em branco preservado em Plain.toDict() para @ menções (#6244).
  • Removidas entradas de dependências duplicadas (#6247).
  • Corrigida resposta normal do Telegram sendo tratada como tópico de tópico (#6174).

Documentação

  • Documentação de backup/acesso rainyun atualizada (#6427).
  • package.md e documentos da plataforma atualizados, incluindo documentação do bot Matrix e Wecom AI.
  • Corrigido o link de convite do Discord nos documentos da comunidade.

Tarefas

  • Modelos de PR/fluxo de trabalho de lista de verificação atualizados, configuração de serviço de repositório e verificações automatizadas.
  • Automação de repositório atualizada e manutenção de formatação e remoção de scripts changelog obsoletos.
