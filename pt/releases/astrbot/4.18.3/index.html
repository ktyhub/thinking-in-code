#AstrBot v4.18.3

O que mudou

Novo

  • Adicionado recurso de ponte de atualização universal de desktop para facilitar o acesso ao processo de atualização no cliente (#5424).

Correção

  • Corrigido o problema em que o adaptador de linha não era exibido na caixa de diálogo da nova plataforma.
  • Corrigido o problema em que o Telegram não conseguia enviar vídeo (#5430).
  • Corrigido um problema em que as dimensões vetoriais não podiam ser reconhecidas automaticamente ao criar um provedor de incorporação (#5442).
  • Corrigido o problema onde o campo markdown não era limpo ao enviar mensagens de mídia na plataforma oficial QQ (#5445).
  • Corrigido o problema de perda do emparelhamento chamada/resposta da ferramenta quando a política de gerenciamento de contexto -> truncamento de contexto (#5417).
  • Corrigido o problema de substituição de persona_id durante a atualização da sessão e aprimorada a lógica de análise de persona.
  • Corrigido o problema de exibição anormal do endereço proxy GitHub na WebUI (#5438).
  • Corrigido o problema de falha de cópia após a criação de uma nova chave API do desenvolvedor na página de configurações (#5439).
  • Corrigido problema de compatibilidade do formato de mensagem de voz do Telegram com OpenAI STT (usando OGG) (#5389).

Otimização

  • Otimize o processo de recuperação da base de conhecimento, mude para metadados de consulta em lote e corrija o problema de desempenho de consulta N+1 (#5463).
  • Otimize a capacidade de isolamento de sessão do Cron para execução de tarefas futuras e melhore a estabilidade da simultaneidade.
  • Otimize a interação da página do plug-in WebUI.

O que mudou (PT)

Novos recursos

  • Adicionado useExtensionPage que pode ser composto para gerenciamento unificado do estado da página de extensão de plug-in.
  • Adicionada uma ponte genérica de atualização de aplicativos de desktop para oferecer suporte a fluxos de trabalho de atualização no aplicativo (#5424).

Correções de bugs

  • Corrigido o adaptador de linha que não aparecia na caixa de diálogo "Adicionar plataforma".
  • Corrigidos problemas de envio de vídeo do Telegram (#5430).
  • Corrigidos erros de verificação de tipo estático do Pyright (#5437).
  • Corrigida a detecção automática de dimensão de incorporação ao criar provedores de incorporação (#5442).
  • Correção de campos de marcação obsoletos ao enviar mensagens de mídia via plataforma oficial QQ (#5445).
  • Corrigida perda de emparelhamento de chamada/resposta da ferramenta durante truncamento de contexto (#5417).
  • Corrigido persona_id sendo substituído durante atualizações de conversa e lógica de resolução de persona aprimorada.
  • Corrigida exibição incorreta do proxy GitHub na WebUI (#5438).
  • Corrigida falha na cópia da chave API após criar uma nova chave nas configurações (#5439).
  • Corrigida a compatibilidade do formato de voz do Telegram com OpenAI STT usando OGG (#5389).

Melhorias

  • Melhor recuperação da base de conhecimento agrupando consultas de metadados em lote para eliminar o padrão de consulta N+1 (#5463).
  • Melhor isolamento de sessão para futuras tarefas cron para aumentar a estabilidade sob simultaneidade.
  • Interações aprimoradas da página do plugin WebUI.
