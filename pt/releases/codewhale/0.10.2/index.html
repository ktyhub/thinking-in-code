Codebaleia v0.10.2

O que há em v0.10.2

Codewhale v0.10.2 adiciona uma visualização animada de animal de estimação (/pet on), um trabalho de Terminal ao vivo dock, cores do compositor por chat (/color) e uma nota única no primeiro comece após uma atualização que diz o que mudou. Fecha três sessões caminhos de perda de dados e vazamento de sessão codewhale web; adiciona o tempo de execução padrão locais de soquete do daemon para a lista de negação do sandbox; possui um curl ou wget que carrega um credencial; recusa comandos shell contendo Unicode invisível; mantém o Sandbox Linux funcionando quando um diretório de credenciais oculto é um link simbólico; e reduz o trabalho ocioso de redesenho da TUI. /undo recupera um todo solicitação, incluindo prompts longos e de múltiplas linhas. exec --auto explica seu Padrão de acesso total, respeita uma sandbox explicitamente mais rígida e salva execuções habilitadas por ferramenta e seus recebimentos de falha. Os tempos de execução locais aparecem durante integração, /diff funciona fora de um repositório Git, rota de respostas do DeepSeek não rejeita mais o histórico de ferramentas reproduzido e as correções do contribuidor melhoram o token contabilidade, listas de modelos de retransmissão, respostas localizadas e iniciador do Windows orientação. O trabalho delegado continua sem turno ou limites de tempo inventados pelo modelo, e as etapas independentes do fluxo de trabalho podem continuar após a falha de outro filho.

Instalar

Recomendado – lançamento oficial do GitHub

Nova instalação do macOS/Linux (binários com soma de verificação desta versão):

curl -fsSL https://codewhale.net/install.sh | CODEWHALE_VERSION="v0.10.2" sh
"$HOME/.local/bin/codewhale" --version

Para Windows, use o instalador ou arquivo correspondente abaixo. Para um existente instalação direta, execute codewhale update; ele imprime o caminho do executável e mantém compilações mais recentes. Se o diretório de instalação estiver ocupado por uma compilação diferente, use a migração de diretório novo no guia de instalação.

Embalagem secundária — npm e Cargo

npm install -g codewhale
# or build from source
cargo install codewhale-cli --locked

O wrapper baixa os ativos de comando codewhale e codew correspondentes deste lançamento. Ambos contêm o mesmo tempo de execução compilado.

Docker/GHCR

docker run --rm -it \
  -e DEEPSEEK_API_KEY="$DEEPSEEK_API_KEY" \
  -v codewhale-home:/home/codewhale/.codewhale \
  ghcr.io/codewhale-hq/codewhale:v0.10.2

A imagem expõe o mesmo tempo de execução que codewhale e codew. O A tag latest também é atualizada no lançamento.

Carga (Linux / macOS)

cargo install codewhale-cli --locked

O pacote Cargo instala o codewhale. Cargo não pode criar um segundo comando alias de um destino binário; usuários que desejam uma ortografia mais curta podem adicionar um Link simbólico codew para o executável instalado. O npm, Homebrew, arquivo, shell-installer e canais de contêiner instalam ambos os nomes de comando diretamente.

Download manual — arquivos da plataforma (recomendado)

Cada arquivo abaixo contém o mesmo tempo de execução no codewhale e Nomes de comandos codew, além de um script de instalação:

| Plataforma | Arquivo | Instalar script | |---|---|---| | Linux x64 | codewhale-linux-x64.tar.gz | install.sh | | Linux ARM64 | codewhale-linux-arm64.tar.gz | install.sh | | Android ARM64 (Termux) | codewhale-android-arm64.tar.gz | install.sh | | macOS x64 | codewhale-macos-x64.tar.gz | install.sh | | ARM do macOS | codewhale-macos-arm64.tar.gz | install.sh | | Windows x64 (instalador) | CodeWhaleSetup.exe | Configuração do NSIS | | Janelas x64 | codewhale-windows-x64.zip | install.bat | | Windows x64 (portátil) | codewhale-windows-x64-portable.zip | — | | Windows ARM64 | codewhale-windows-arm64.zip | install.bat | | Windows ARM64 (portátil) | codewhale-windows-arm64-portable.zip | — |

Unix (Linux/macOS):

tar xzf codewhale-<platform>.tar.gz
cd codewhale-<platform>
./install.sh

Janelas:

  • Para o caminho do instalador, execute CodeWhaleSetup.exe; ele instala codewhale.exe, codew.exe e codewhale.bat sob %LOCALAPPDATA%\Programs\CodeWhale\bin, adiciona esse diretório ao PATH do usuário atual e cria um atalho no menu Iniciar que prefere Terminal Windows (wt.exe) quando instalado.
  • Extraia o arquivo da sua máquina: codewhale-windows-x64.zip ou codewhale-windows-arm64.zip
  • Duplo click codewhale.bat (não o .exe bruto) para lançamento
  • Execute install.bat para copiar os binários e o inicializador para %USERPROFILE%\bin
  • Adicione %USERPROFILE%\bin ao seu PATH

O arquivo portátil do Windows ignora o script de instalação – extraia e execute codewhale.bat de qualquer diretório. O instalador NSIS não está assinado no momento e pode acionar o Windows SmartScreen até que um certificado de assinatura seja conectado ao pipeline de lançamento.

Cada plataforma também possui vazio, desarquivado codewhale-<platform> e Ativos codew-<platform>. Os sete nomes de arquivo codewhale-tui-<platform> anexadas ao v0.9.5 são cópias de compatibilidade idênticas a bytes usadas apenas para permitir v0.9.4 clients já instalado descobrem e cruzam este binário único transição; os instaladores atuais não expõem um terceiro tempo de execução. O legado npm o pacote deepseek-tui está obsoleto e não foi republicado. Para migração de nomes binários legados v0.8.x, consulte docs/REBRAND.md.

Verificar (recomendado)

Baixe os manifestos de checksum desta versão e verifique:

# Linux — archive bundles
sha256sum -c codewhale-bundles-sha256.txt --ignore-missing

# Linux — individual binaries
sha256sum -c codewhale-artifacts-sha256.txt --ignore-missing

# macOS
shasum -a 256 -c codewhale-bundles-sha256.txt --ignore-missing
shasum -a 256 -c codewhale-artifacts-sha256.txt --ignore-missing
