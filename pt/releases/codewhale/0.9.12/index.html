Codewhale v0.9.12

Codewhale é o produto público da Shannon Labs. O codewhale os nomes de comando, pacote npm e release-asset permanecem técnicos em letras minúsculas identificadores. O pacote npm legado deepseek-tui está obsoleto e não recebe mais lançamentos. Usuários provenientes do legado v0.8.x deepseek / Os nomes deepseek-tui deverão migrar com docs/REBRAND.md.

Instalar

Recomendado – lançamento oficial do GitHub

Nova instalação do macOS/Linux (binários com soma de verificação desta versão):

curl -fsSL https://codewhale.net/install.sh | CODEWHALE_VERSION="v0.9.12" sh
"$HOME/.local/bin/codewhale" --version

Para Windows, use o instalador ou arquivo correspondente abaixo. Para um existente instalação direta, execute codewhale update; ele imprime o caminho do executável e mantém compilações mais recentes. Se o diretório de instalação estiver ocupado por uma compilação diferente, use a migração de diretório novo no guia de instalação.

Embalagem secundária — npm e Cargo

npm install -g codewhale
# or build from source
cargo install codewhale-cli --locked

O wrapper baixa os ativos de comando codewhale e codew correspondentes deste lançamento. Ambos contêm o mesmo tempo de execução compilado.

Docker/GHCR

docker run --rm -it \
  -e DEEPSEEK_API_KEY="$DEEPSEEK_API_KEY" \
  -v codewhale-home:/home/codewhale/.codewhale \
  ghcr.io/hmbown/codewhale:v0.9.12

A imagem expõe o mesmo tempo de execução que codewhale e codew. O A tag latest também é atualizada no lançamento.

Carga (Linux / macOS)

cargo install codewhale-cli --locked

O pacote Cargo instala o codewhale. Cargo não pode criar um segundo comando alias de um destino binário; usuários que desejam uma ortografia mais curta podem adicionar um Link simbólico codew para o executável instalado. O npm, Homebrew, arquivo, shell-installer e canais de contêiner instalam ambos os nomes de comando diretamente.

O que há em v0.9.12

Codewhale v0.9.12 coloca o uso do computador no binário, abre duas novas rotas - Alibaba Model Studio por meio da tabela de provedores baseada em dados e Concentrate como um gateway de respostas BYOK opcional - e adiciona envio na nuvem mais um soquete de controle por sessão controlado por configuração. A casca é a outra metade do lançamento: um novo cartão de lançamento, a superfície de trabalho encaixada sob o compositor, um proprietário de foco para Tab, células de ferramentas que carregam seu próprio estado e fleet como a palavra pública para o coletivo ao vivo. A mudança completa no nível do item o registro é mantido abaixo dos destaques de lançamento categorizados.

Adicionado

  • O uso do computador acompanha o binário. O plugin computer-use – 38 ferramentas em macOS, Windows, Linux e HarmonyOS, observação que prioriza a acessibilidade com substituto de pixel, capturas de tela, zoom, gravação de tela e registro computadores remotos via ssh e hdc - é incorporado no Codewhale e gravado em $CODEWHALE_HOME/builtin-plugins na primeira execução, então cada canal de instalação carrega isso. Ele é listado como builtin · not-reviewed e permanece desativado até você revisa e ativa: enviá-lo não é consentir. O O servidor de uso do computador stdlib-Python que ele substitui desapareceu.
  • Alibaba Model Studio junta-se à tabela de provedores baseados em dados como um Descritor openai-compatible: endpoint de modo compatível internacional, Credencial DASHSCOPE_API_KEY, descoberta /v1/models ao vivo. Qwen 3.8 Flash e Qwen 3.8 Max chegam através da autoridade do catálogo – nunca um ID codificado.
  • Concentrado: gateway de respostas BYOK opcional de primeira classe com modelos ao vivo descoberta e streaming SSE digitado (#5725).
  • Despacho na nuvem: o executor remoto descarrega tarefas do agente de codificação para tarefas isoladas sandboxes na nuvem com autenticação de token de máquina e rastreamento de trabalho estruturado (#5701, #5712).
  • Soquete de controle por sessão: vinculações de tabela [control_socket] controladas por configuração <sessions-dir>/<session-id>/control.sock por sessão de corrida, expondo mensagem, interrupção, reinicialização e verbos JSON-RPC de status (#5533, #5831).

Alterado

  • A contagem de uso anônima está ativada por padrão. A versão 0.9.11 solicitou primeiro; 0.9.12 conta a mesma versão/plataforma agregada, sessão, recurso e totais de erros, a menos que você o desligue, e diga isso uma vez na primeira inicialização (aviso de política versão 5, esquema 3, notice_version substituindo consent_version). Cada desativação registrada permanece desativada: um recurso durável telemetry = false, um decline registrado sob o antigo aviso de aceitação, estado de privacidade ilegível e o CODEWHALE_TELEMETRY=0 / --telemetria false interruptores de eliminação. Mostrando nos registros de divulgação apenas que foi mostrado, nunca uma aceitação. codewhale config set telemetry false gira desliga e limpa as contagens na fila; codewhale config set telemetry true deliberadamente o reativa. Nada de novo é coletado: nenhuma conversa, código, prompts, arquivos, nomes, conteúdo do modelo, credenciais ou IP.

  • A tela de lançamento é o nosso próprio cartão: uma linha superior fina ⑂ branch path; um cartão com borda centralizada com a marca da baleia, Versão Codewhale +, uma linha de anúncio somente quando for verdade (o aviso de ausência de modelo ou notícias MCP) e o menu Nova árvore de trabalho / Currículo session / Changelog / Sair com seus acordes reais alinhados à direita. Entrar executa a entrada destacada, move-a para cima/para baixo e a digitação vai direto para o compositor. O cartão se dissolve na primeira tecla ou comando (≤240 ms, instante sob movimento reduzido) (#5826, #5801, #5815, #5286).

  • A superfície de trabalho fica sob o compositor por padrão, mantendo o histórico legível e deixando o palco livre (#5809).

  • Formas de comando de habilidades: formas de comando FEAT-022 e host retido validação (#5825, #5829).

  • Após a dissolução do cartão, a tela de trabalho mostra ⑂ branch path com ⋮ MCP n/m à direita, a transcrição começa com o Recibo ◆ session_start (nomeando os ganchos de início de sessão configurados), e a regra básica do compositor carrega model (effort) · permission - a leitura de um lançamento da rota. A barra de postura e a linha de métricas aparecem somente quando uma sessão existir.

  • Vocabulário: fleet é o termo público e Pod foi retirado da cópia — lista, configuração, detalhes, tempo de execução do trabalhador e mensagens gerenciadas API agora dizem Frota (/fleet canônico, alias /pod). A ligação do fluxo de trabalho aceita o grafias de papéis canônicos (geral/explorar/planejador/revisor/implementar/ test/advisor) com os pré-renomeados mantidos como aliases de tempo de carregamento, e serializa nomes canônicos.

  • A dica do seletor de modo Operate foi reduzida para caber em 80 colunas.

  • O rodapé sempre mostra a postura de permissão; quando apenas um chip se encaixa, o chip de permissão supera a palavra de modo (#5796).

  • Local Ollama: o cabeçalho nomeia um modelo somente quando o catálogo local puder sirva e diga unknown até saber. A marca de inicialização, web e o ícone do aplicativo carrega a nova baleia com visão lateral (#5795).

  • Um proprietário de foco: Tab e Shift+Tab funcionam independentemente do que está no compositor; Os atalhos alternativos sobrevivem no meio do rascunho; Ctrl+Tab não alterna mais o modo por acidente (#5798).

  • As células de ferramentas carregam seu próprio estado: uma ferramenta em execução, com falha ou avisada lê como tal na própria transcrição, com pontos ferroviários por entrada e glifos com cores familiares (#5799).

  • Web: hub de documentos com pesquisa de tarefas, estados compartilhados de vazio/carregamento/erro, um banner off-line para on-line, /changelog em todas as localidades e real 404s com metadados corretos (#5743).

  • Web: as cores do aplicativo vêm de um arquivo gerado a partir da baleia TUI paleta; redigitar uma cor manualmente falha no Web CI (#5797).

  • Teia: um teto unidirecional no isZh ramificando-se fora da coluna i18n — a contagem só pode diminuir (#5805).

  • Um documento de transferência de agente interno foi removido da árvore pública e .playwright-mcp/ agora é ignorado (#5800).

  • A primeira execução pinta o compositor imediatamente: o Welcome/idioma/provider/ As portas trust não precedem mais o primeiro pressionamento de tecla. Chave faltante e estadia de recuperação do workspace-trust para usuários recorrentes; idioma e provedor permanecer em /setup.

  • A marca canônica do bloco de baleia se propaga além da web para o raster exato superfícies que podem carregá-lo (#5738).

  • Varredura de código morto: exclua auxiliares comprovados não referenciados (construtores não utilizados, wrappers e identificadores restantes) e descartar #[allow(dead_code)] obsoleto onde o item é chamado de produção ou exercido por teste. Nenhum comportamento em tempo de execução mudança (#5791, #5587).

  • A recuperação por controle remoto oferece a cada nova tentativa de pré-despacho um novo arrendamento geração enquanto preserva essa geração em seu início digitado (#5605).

  • O idioma da lista pública é Pod. /pod é a superfície do cliente; frota permanece o nome da conexão interna, do armazenamento e da migração (#5776).

  • O histórico de substituição de compactação mantém uma última rodada de usuário limitada (assistente + resultados da ferramenta) em vez de deixá-los atrás de um resumo. Nomes /context o caminho de compactação e a sobrevivência do /anchor. A compactação falhada ainda não substitua o histórico ao vivo (#4394).

  • Catálogos de provedores: hosts compatíveis (Baseten, Groq, Cerebras, SenseNova, Código de Comando) não compila mais uma lista de modelos congelados. Os descritores nomeiam o ligação, URL e ambiente; live GET /v1/models e um catálogo de propriedade da Codewhale camada são a lista de ofertas. Código de comando é uma linha de catálogo/descritor, não um ProviderKind. A presença no catálogo não é uma disponibilidade, direito ou reivindicação de aceitação do provedor (#5783).

  • A seleção do provedor não investiga mais ou adota uma credencial CLI externa em uso comum do selecionador. A reutilização requer um "Usar credenciais CLI externas" explícito escolha, confirmação do caminho exato e revogação de propriedade do Codewhale (#5772).

  • TUI: a startup não apresenta mais um ASCII aproximado ou baleia de glifo de bloco como a marca do produto. Ele mantém o prompt direto do Tideline durante a varredura exata superfícies permanecem responsáveis pelo ativo canônico.

  • TUI: o compositor da sessão ativa pinta o mesmo envio [↑] de três células target como Startup e clicks através do Enter submit existente despachante (#5771). Compositores compactos/silenciosos ainda omitem o controle.

  • TUI/CLI: Pod é a superfície de escalação pública. Redação da frota voltada para o usuário muda para o pod; chaves de recibo duráveis ​​permanecem compatíveis (#5776).

Adicionado

  • Login nativo do ChatGPT para a rota openai-codex: codewhale auth chatgpt abre um fluxo PKCE do navegador e armazena tokens atualizáveis em Credenciais de propriedade do Codewhale – não é necessária a instalação do Codex CLI. /auth chatgpt-revoke os limpa do loop de eventos (#5784, #5778).

  • Servidores e plug-ins MCP podem ser conectados por autoatendimento a partir da sessão: a fluxo de autenticação unificado com manipulação de token com rotação segura, uma autorização falada URL e atualização de catálogo quando as credenciais armazenadas param de funcionar (#5747).

  • As leituras de /operate correspondem ao contrato CWC OperateRecord: buscando um registro ausente retorna uma visão verdadeira não encontrada em vez de uma visão fabricada operação, e um caminho de evidência vazio é rejeitado em vez de ser resolvido o diretório do espaço de trabalho (#5703).

  • TUI: projeto de automações programadas na faixa superior (⏱ N scheduled · M running, compacto ⏱ N·M) com digitado HistoryCell::Automation recebe quando uma execução nesta sessão assistiu à liquidação. /automation reconhece falhas. O rodapé mesclado não carrega o fato de trabalho (#5748).

  • O servidor de aplicativos pode escutar em um soquete de domínio unix e anunciar um Handshake daemon/attach, para que um client local possa se conectar a um já em execução motor em vez de gerar o seu próprio. O soquete é criado com permissões exclusivas do proprietário e soquetes obsoletos são recuperados na inicialização. Não Unix hosts retornam uma recusa digitada de plataforma não suportada; o pipe nomeado do Windows o endpoint foi nomeado, mas ainda não foi implementado (#5749).

  • Os tipos internos Op/Event do motor e o protocolo de fio Op/ EventMsg agora carrega um gêmeo imposto por compilação para cada variante: adicionando um variante do mecanismo sem uma contraparte de protocolo falha na construção em vez de vagando silenciosamente. Trabalho de durabilidade interna – sem superfície visível ao usuário mude ainda (#5751).

  • Tokens de máquina: com CODEWHALE_API_KEY configurado, o CLI autentica como o Conta Codewhale sem arquivo de sessão local e sem navegador — o CI caminho de autenticação, com formato de token digitado e redação (#5721).

  • Compaction publica um contrato de sobrevivência estruturado para session-tree tipos de lançamento contábil manual (crates/tui/src/compaction/SURVIVAL_CONTRACT.md) e falha quando a última rodada do usuário, resultados da ferramenta, texto /anchor ou o recibo do ponto de verificação desapareceria (#4394, #5782).

  • Interno: codewhale-config ganha RouteAuthoritySnapshot, um imutável autoridade que possui um catálogo de provedores compilado junto com a rota resolvedor projetado a partir dele, portanto, um seletor, uma visualização de prontidão e uma execução path não pode mais ser resolvido em diferentes instantâneos de catálogo sem um sinal de nível de tipo. A resolução ainda passa pelo resolvedor único; o o recibo devolvido distingue uma linha exata do catálogo, uma rota de ponto final personalizado cujos fatos do fornecedor não são deliberadamente reutilizados, e um permitido rota de passagem sem linha de catálogo. Todo estado é livre de segredos. Nenhuma chamada o site foi alterado e nenhum comportamento visível ao usuário foi alterado ainda (#5766).

  • Os registros de sessões de computador agora contam apenas o tempo em que um provedor realmente aceitou o sessão como ativa, com granularidade por segundo. Ocioso, na fila, parado e o tempo de desmontagem é excluído e uma sessão cuja alocação não corresponde a um o perfil padrão é recusado em vez de registrado aproximadamente. Coberto por luminárias herméticas; nenhuma chamada de provedor ativa e nenhuma implantação (#5781).

  • Site: o site público muda para a linguagem de design de águas profundas Tideline (escuro por padrão com uma folha de documentação clara opcional, paleta fundamentada nos tokens WHALE_* da TUI) e a nova marca da baleia no favicon, ícones de aplicativos, manifesto da web, marca de navegação e cartão social (#5573).

  • Adicione codewhale dispatch / /dispatch para que uma sessão local possa propor um Agente de nuvem Codewhale contra um controle remoto github, cnb ou gitee explícito. A confirmação é necessária; credenciais ausentes falham no fechamento; compartilhamento de empregos na nuvem a superfície /jobs existente como kind=cloud. Veja DAYTONA_CLOUD_DISPATCH.md.

  • /login relata a sessão da conta Codewhale e a próxima chave do provedor passos. A credencial interna do agente de nuvem não é a superfície do usuário: há nenhum comando auth set-slot/auth clear-slot, nenhuma dica e nenhuma conclusão entrada para isso - entrar com codewhale login é a única porta.

  • Adicione a família de componentes Tideline da especificação de tradução ratatui (Telas do #5698, seguindo o layout da faixa de trabalho do #5699): inicialização do herói superfície com ações rápidas e faixa de opções, caixa de entrada de notificações, mescladas faixa de rodapé, razão de pod, recibo stream, lista de temas com alternância de movimento, visualização ao vivo, barra de configurações, e o trilho esquerdo - cada um deles um módulo de renderização independente fixado por 28 novos buffers dourados com bytes exatos. A fiação da estrutura segue a aceitação do Tideline portão; NO_COLOR agora é homenageado pela detecção de profundidade da paleta.

As camadas de catálogo são empacotado → models.dev → provedor /v1/models → config.toml → usuário, com política DENY por último e nunca substituída.

As configurações open.bigmodel.cn existentes agora compartilham o modelo oficial da Z.AI namespace e escopo de credencial; IDs de modelos desconhecidos ainda passam.

  • Adicionada a retransmissão de bate-papo gerenciada: comandos de bate-papo de propriedade da conta agora são executados no mecanismo de thread de tempo de execução nativo por meio de um novo módulo runtime_chat_relay em vez de um segundo caminho de execução. Cada tópico do Chat é dedicado, thread de tempo de execução isolado com uma lista de permissões de ferramenta visível ao modelo vazia, um prompt do sistema somente para bate-papo e nenhum espaço de trabalho, memória, habilidade, credencial ou contexto do caminho local; o thread interativo ativo da TUI nunca é reutilizado. O o relé mantém um arquivo de estado durável por escopo atrás de um proprietário de toda a sessão lock, vincula uma sessão salva permanentemente ao seu primeiro alvo remoto, reproduz comandos duplicados exatos dos resultados retidos em vez de iniciar um segundo turno de inferência, terminaliza reservas órfãs na reinicialização e rejeita (nunca entra na fila) em um turno de trabalho local movimentado com uma nova tentativa imediata resultado. Os comandos de parada exigem a identidade exata de execução e virada e um trabalhador anula qualquer conta ou incompatibilidade de destino durante a atualização do token.

  • Adicionado um caminho de embalagem Omarchy/AUR verificado: packaging/aur agora carrega um Modelo PKGBUILD, renderizador e testes .SRCINFO, candidato a lançamento etapa de renderização e documentos; o alias de compatibilidade do AUR ao vivo codewhale-tui -> codewhale é preservado, as dependências do AUR correspondem ao pacote ativo e o o autoatualizador se recusa a combater uma instalação do Omarchy/package-manager.

  • Adicionado um teto de custo/uso de token para toda a frota (R6, #5567): um acumulador além do portão de admissão e do alerta, limitam os gastos de uma corrida inteira entre os trabalhadores.

  • Adicionada a taxa de acerto do cache do provedor real ao /context (C3, DSH #3): o taxa relatada pelo provedor ponderada por token da mesma telemetria /cache agregados, além de um estado honesto de "sem telemetria de cache ainda" quando nada está gravado.

  • Adicionado movimento de custo por etapa: os recibos TurnUsage são avaliados à medida que chegam então a superfície de custo ao vivo se move durante longos turnos de agente, em vez de apenas em TurnComplete (#5578), e o rodapé agora mostra honestamente cost: unknown quando nada pode ser precificado em vez de esconder a linha.

  • Adicionada a superfície da sessão subaquática: a água ambiente lê o estado da sessão do outro lado da sala, sua forma de animação segue a atividade do agente ao vivo e as tonalidades de atenção são constantes (sem respiração) com um tratamento de leitura distinto e nenhuma costura intermediária em janelas altas.

  • Adicionadas menções à linha de longo alcance @path:START-END (#5550, metade do seletor a seguir), um arquivo de backup de última cópia previsível para exportações clipboard com o caminho nomeado quando o clipboard falha (# 5555), wait em vários shell de segundo plano tarefas com until=any|all (#5549, nomeado-matar metade a seguir) e compositor seleção de palavra dupla click / seleção de linha tripla click.

  • Adicionado sucesso parcial do slot paralelo schema do fluxo de trabalho (#5583): um slot que produz um resultado parcial válido para o esquema não falha mais em todo o paralelo filial.

  • Adicionadas dicas de inicialização de falha no carregamento do plugin (#5579) e aplicativo OpenRouter cabeçalhos de atribuição em solicitações de saída.

  • Adicionado codewhale doctor --fix (com --yes para consentimento não interativo): o médico agora calcula um plano de reparo concreto - exclua .tmp* obsoleto sobras de gravações atômicas interrompidas, aperte o arquivo de armazenamento secreto permissões para 0600, desative o MCP estruturalmente quebrado (status de erro) entradas através do caminho de salvamento do MCP atômico e andaime ausente do usuário global Diretórios skills/tools/plugins — mostra e aplica somente depois consentimento explícito. Cada ação tem escopo restrito e é idempotente; JSON e Os modos context-JSON permanecem somente leitura e entram em conflito com --fix (#5552, v1).

  • Adicionado relatório /context da taxa real de acertos do prompt-cache do provedor (C3) junto com a pressão simbólica.

Alterado

  • A pesquisa na Web nativa do provedor agora aplica restrições de domínio antes de aceitar um tentativa, descarta as respostas geradas quando as citações retornadas violam essas restrições e preserva o tempo limite configurado/local do chamador como um orçamento alternativo independente (#5681).

  • As métricas de sessão ociosa omitem zero fatos (0 turns, LLM 0s) até o o tempo de execução tem evidências. O cromo funcional diz in the current em vez de um working genérico.

  • Excluídos nove arquivos de teste runtime_contract/ não compilados. Contratos ativos permanecem model.rs e termination.rs.

  • A primeira varredura de código morto #5587 converte auxiliares somente de teste auditados em #[cfg(test)], mantendo as compilações de produção livres de APIs somente para teste, sem alterando o comportamento do tempo de execução.

  • /plugin reload agora pode ser descoberto quando os pacotes de plug-ins no disco mudam: o próximo envio e /plugin list cutuca uma vez com Run /plugin reload to apply em vez de manter silenciosamente o catálogo obsoleto (#5579). Trust permanece inalterado; isso não recarrega automaticamente.

  • Avisos de pressão de contexto e alertas críticos agora permanecem visíveis na UI fixa status até a compactação ou demissão explícita, em vez de desaparecer em metadados de giro de rolagem (#5620).

  • O armazenamento de threads do Runtime é padronizado como uma raiz por sessão ($CODEWHALE_HOME/sessions/<id>/runtime) então vários processos Codewhale em uma máquina não compartilha mais um bloqueio de proprietário (#5630). A fechadura exclusiva é inalterado; CODEWHALE_RUNTIME_DIR ainda seleciona uma raiz compartilhada quando esta é pretendido.

  • Os totais de tokens de sessão agora incluem deltas de chamada por modelo somente para exibição, enquanto um turn está em execução, incluindo contadores de entrada/saída e de classe de cache; o os totais oficiais de TurnComplete ainda são reconciliados exatamente uma vez (#5581).

  • O foco da transcrição agora expõe ações por bloco: y copia conteúdo, Y copia a visualização de metadados renderizada, Enter abre um pager de bloco em tela cheia e r abre detalhes brutos; os atalhos ferroviários de tarefas existentes permanecem inalterados (#5551).

  • Neutralidade do provedor (#5588): a resolução do modelo de modelos omitidos/alias é agora os padrões nativos do OpenAI relativos ao provedor não são mais roteados tabela de outro provedor, as credenciais CLI permanecem no escopo do provedor e a NVIDIA as credenciais não vazam mais para as chaves do DeepSeek. Teste de neutralidade as matrizes exercem vários provedores em vez de substituir um.

  • O módulo do mecanismo de fluxo de trabalho foi decomposto de seu mega-arquivo de 3k linhas em Módulos journal, usage e report mais um diretório de módulo (#5586 fatias 1a/B/C/D), um movimento livre de semântica verificado por hash de conteúdo normalizado.

  • As recusas de compactação agora são sempre nomeadas (#5577): retenção silenciosa sob contexto a pressão acabou, o medidor de contexto respeita o mesmo prompt cobrado pelo provedor o gatilho usa (T1), e os resultados da remoção são projetados sem clonar o transcrição.

  • Os orçamentos escalonados agora terminam honestamente: uma aterrissagem suave de aproximadamente 80% leva o modelo a escrever seu relatório final, e a exaustão concede exatamente um limite virar relatório de exaustão em vez de morrer silenciosamente (A1/A2).

  • Crédito de contribuidor: contribuidores agentes reconhecidos (por exemplo, Codewhale Agent) agora pode transportar reboques Co-authored-by; trailers de bot/ferramenta desconhecidos são ainda rejeitado pelo portão de crédito.

Corrigido

  • A digitação rápida não corrompe mais o compositor. A heurística paste-burst foi executada em cada sessão até que uma pasta real entre colchetes chegasse, segurando, armazenando em buffer, retro-agarrando e absorvendo Enter em suposições de tempo; é agora somente fallback (desligado quando o terminal fornece colagem entre colchetes), o retro-grab é excluído e Enter no texto do comando retido libera e envia.

  • Ctrl+C funciona no menu de inicialização da pré-sessão e fala em todos os lugares: o primeira pressão arma a janela de saída de dois segundos com um sinal localizado visível Dica "Pressione Ctrl + C novamente para sair" (anteriormente silenciosa), a segunda sai. A entrada do nome da árvore de trabalho mantém Ctrl+C como entrada de cancelamento.

  • Novas sessões interativas não deixam mais uma mensagem fantasma duplicada atrás. A TUI reivindicou um ID de sessão (bloqueio de armazenamento de tempo de execução, falha de inicialização ponto de verificação) enquanto o motor cunhava um segundo; o primeiro SessionUpdated redigitou o aplicativo, o commit de conclusão apagou apenas o ID do mecanismo ponto de verificação, e codewhale --continue posteriormente "recuperou" o órfão ponto de verificação como uma sessão duplicada em vez da sessão real. O motor agora adota o ID de propriedade do host no spawn (EngineConfig::session_id) e /clear cunha o próximo ID no aplicativo, como /new. Um --continue não TTY não é mais promove e consome o ponto de verificação de travamento antes de falhar no terminal verifique e os sinalizadores raiz codewhale --resume <id> / --session-id <id> documentado no runbook de operações agora é analisado em vez de ser engolido como um aviso.

  • Site: /signin, /signup e /auth/callback são públicos com reconhecimento de localidade rotas em vez de 404s localizados. Faça login e crie uma conta para enviar a pessoa para o aplicativo CWC; Os retornos de chamada OAuth vão para app.codewhale.net com a consulta intacto; /login e /register são apelidos. O uso local do CLI não é apresentado como exigindo uma conta (#5767).

  • A lista de negação de leitura do sandbox corresponde ao caminho resolvido de uma regra, bem como ao seu ortografia literal. No macOS /etc e /var são links simbólicos para /private, então uma leitura de /private/etc/sudoers contornou a regra /etc/sudoers, e uma regra escrita contra um diretório com link simbólico nunca disparada de verdade caminho que canonicalize e o processo cwd devolvem.

  • As conchas de fundo são linhas de faixa de trabalho de primeira classe (▾ Shells N) que você pode abra, observe e cancele pelo id shell_* na linha. /jobs cancel all cancela shells em execução; ele não procura mais uma tarefa chamada all. O A migalha de ampulheta do compositor não representa mais uma superfície de concha.

  • codewhale logout e /logout agora limpam a sessão da conta Codewhale e o slot secreto de Daytona, não apenas as chaves do provedor API. A caixa da TUI o caminho login --api-key restante não afirma mais salvar uma chave.

  • As sessões da conta não leem mais as Chaves do macOS. Não assinado ou reconstruído Os binários codewhale sempre foram um novo principal do Keychain ACL, então codewhale web e o TUI exibiram uma caixa de diálogo de senha na inicialização. Sessões agora use ~/.codewhale/secrets/secrets.json (modo 0600), a mesma loja como chaves do provedor. Extraído da metade da aposentadoria das chaves de #5632.

  • Análise de configuração do lado do despachante fortalecida da mesma maneira: ConfigStore cargas e análise de configuração do projeto agora desserializam ConfigToml em um thread dedicado de pilha de 16 MiB (o caminho de salvamento da configuração guiada pode transbordar uma pilha de trabalho de 2 MiB da mesma forma que a análise ConfigFile da TUI fez), e o teste de brinde de confirmação de configuração # 5585 executa seu tempo de execução em um tamanho igual thread em vez de estourar a pilha padrão da libtest.

  • Corrigidos agentes interativos desanexados que relatavam o uso do trabalhador após o pai turno termina com o uso faltando no total da sessão/ao vivo /cost (#5597): turnos interativos adquirem uma concessão de uso de tempo de execução no escopo do proprietário, o uso tardio entra no pool de custos da sessão sem reabrir o selado caixa de correio e contabilidade de trabalhador/sessão/recarga compartilham uma resposta com hash identidade para que as novas tentativas de entrega permaneçam exatamente uma vez.

  • Corrigida a classe de fiasco do subagente: git -C absoluto no espaço de trabalho não é mais aciona o portão shell filho somente leitura com um portão delimitado coerente (#5595), parques finais passam a ser propriedade de crianças, provavelmente, em vez de cancelar silenciosamente eles (# 5596), reivindicações de gravação obsoletas são liberadas pela vivacidade com coordenadas release (#5562), e a descrição da função do verificador corresponde ao seu real superfície (#5562).

  • Correção do tratamento de falhas do ResponseSchema do fluxo de trabalho (nº 5583): reparo limitado com recibos digitados (tipo + tentativa), os recibos de saída bruta persistiram como artefatos que sobreviveram à recarga e surgiram falhas em vez de sucesso nulo (#5528). Instantâneos de proprietário degradados não são mais projetados como execuções concluídas comuns (#5582), tipos de erros de tarefa digitados permitem paralelo/pipeline rápido com falha (R9) e /workflow confirm encontra o rascunho apesar das mensagens intercaladas.

  • Corrigida a sessão DeepSeek que nunca era compactada automaticamente em 842k/1M (#5577): o exato billed_842k_on_a_1m_window_compacts_despite_a_small_estimate a regressão fixa o gatilho.

  • Corrigidos escapes de sandbox e lacunas de autoridade: ferramentas de gravação de espaço de trabalho resolvem arquivos com link físico antes de gravar (S2, #5569), uma lista de negação de leitura opcional limita leituras completas de disco em qualquer postura (S1, #5568) e concessões de sessão correspondem a família de comandos em vez de ampliar toda a ferramenta (R2).

  • Corrigida a robustez do transporte do provedor: as solicitações HTTP sem streaming são limitadas por um tempo limite de leitura (R4) e quadros de erro intermediários de Chat-Completions aparecem em vez de pendurar (R3). A expiração do MCP OAuth agora reage a 401/403 com um nome caminho de recuperação e dica de login em vez de parecer um servidor quebrado (T4, #5572).

  • Corrigidas lacunas no ciclo de vida da frota: trabalhadores destacados são colhidos quando seu gerente morre (R7) e o tempo limite do relógio de parede por tarefa é aplicado (R5); o local O Fleet Host compila em alvos não-Unix; o reparo do esquema desanexado permanece dentro o orçamento de tempo de execução.

  • Corrigida a correção do prompt-cache: o catálogo de ferramentas é impresso em ordem de transferência do provedor (C1), as alterações de prefixo entre as solicitações são sempre declarado (C5) - incluindo o recém-nomeado change:tool_surface de meia volta motivos para admissão de ferramenta adiada, ativação de pesquisa de ferramenta e MCP em tempo de execução chegada da ferramenta - e uma resposta apenas de raciocínio interrompida no limite de saída agora falha honestamente no turno, em vez de reemitir uma solicitação que só pode reproduzir a parada.

  • Corrigido desvio de documentos/superfície pública: REBRAND.md não está mais presente api.deepseeki.com como substituto da China (#5564) e os fatos/ferramenta da web as contagens correspondem ao repositório.

  • Solicitações pull pesadas agora executam o espaço de trabalho real do Linux nextest, doctest e lockfile faixas diretamente nas ações do GitHub em vez de relatar um verde espaço reservado enquanto espera por um espelho CNB específico da filial (#5547).

  • Os membros da lista de frota em uma frota selecionada agora expõem uma capacidade de edição visível e um atalho direto para o seletor de modelo m, enquanto a linha do coordenador permanece somente leitura (#5604, cobre #5589).

  • O inspetor de contexto agora atribui o custo do esquema de ferramenta limitado ao recurso integrado catálogo e cada servidor MCP descoberto sem alterar a montagem do prompt ou comportamento do cache (#5553).

  • O período de silêncio de continuação da meta ([goal] continuation_delay_seconds, adicionado em #5508) agora se aplica a todos os caminhos de despacho. Anteriormente o o gancho de despacho dentro do turno disparou o próximo prompt de continuação imediatamente sempre que uma etapa do modelo terminava com a meta ainda ativa, então CLI era retomado e sessões gerenciadas pelo host nunca observaram o atraso configurado (medido intervalos fim-a-início de ~9 s com um atraso de 300 s configurado). A espera agora funciona incondicionalmente dentro de goal_continuation_message_if_needed, permanece cancelável e pausar/limpar/terminar chamadas update_goal ainda cancelar uma passagem pendente (#5534).

  • Dois testes unitários não dependem mais do estado do ambiente global do processo que testes de irmãos sofrem mutação simultaneamente. route_budget::tests::v4_trigger_uses_window_percent_when_it_fits_spendable_input declarou valores de orçamento de produção sem substituição durante a leitura CODEWHALE_MAX_OUTPUT_TOKENS / DEEPSEEK_MAX_OUTPUT_TOKENS sem segurando lock_test_env(), então um gravador simultâneo poderia inverter o valor afirmação intermediária (o floco de suíte completa dependente da ordem). prompts::tests::system_prompt_prefix_never_leaks_private_content leu o casa real via HOME/USERPROFILE, então uma máquina com ~/.codewhale/instructions.md vazou seu caminho absoluto no prompt e falhou na afirmação de no-private-paths, a menos que o HOME temporário de um irmão o guarda estava ao vivo. Ambos os testes agora seguram a barreira env e fixam o variáveis (o teste de orçamento de rota remove as substituições; o teste de prompts aponta HOME/USERPROFILE para um diretório scratch). Afirmações inalteradas.

  • As sessões TUI agora aplicam um sutil acento de cursor OSC 12 apenas explicitamente terminais suportados e restaurar o padrão do terminal através de normal, pânico, e caminhos de limpeza de sinal (#5554).
