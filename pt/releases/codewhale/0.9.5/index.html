Codewhale v0.9.5

Codewhale é o produto público da Shannon Labs. O codewhale os nomes de comando, pacote npm e release-asset permanecem técnicos em letras minúsculas identificadores. O pacote npm legado deepseek-tui está obsoleto e não recebe mais lançamentos. Usuários provenientes do legado v0.8.x deepseek / Os nomes deepseek-tui deverão migrar com docs/REBRAND.md.

Instalar

Recomendado — npm (um comando, ambos os pontos de entrada)

npm install -g codewhale

O wrapper baixa os ativos de comando codewhale e codew correspondentes deste lançamento. Ambos contêm o mesmo tempo de execução compilado.

Docker/GHCR

docker run --rm -it \
  -e DEEPSEEK_API_KEY="$DEEPSEEK_API_KEY" \
  -v codewhale-home:/home/codewhale/.codewhale \
  ghcr.io/hmbown/codewhale:v0.9.5

A imagem expõe o mesmo tempo de execução que codewhale e codew. O A tag latest também é atualizada no lançamento.

Carga (Linux / macOS)

cargo install codewhale-cli --locked

O pacote Cargo instala o codewhale. Cargo não pode criar um segundo comando alias de um destino binário; usuários que desejam uma ortografia mais curta podem adicionar um Link simbólico codew para o executável instalado. O npm, Homebrew, arquivo, shell-installer e canais de contêiner instalam ambos os nomes de comando diretamente.

Download manual — arquivos da plataforma (recomendado)

Cada arquivo abaixo contém o mesmo tempo de execução no codewhale e Nomes de comandos codew, além de um script de instalação: | Plataforma | Arquivo | Instalar script | |---|---|---| | Linux x64 | codewhale-linux-x64.tar.gz | install.sh | | Linux ARM64 | codewhale-linux-arm64.tar.gz | install.sh | | Android ARM64 (Termux) | codewhale-android-arm64.tar.gz | install.sh | | macOS x64 | codewhale-macos-x64.tar.gz | install.sh | | ARM do macOS | codewhale-macos-arm64.tar.gz | install.sh | | Windows x64 (instalador) | CodeWhaleSetup.exe | Configuração do NSIS | | Janelas x64 | codewhale-windows-x64.zip | install.bat | | Windows x64 (portátil) | codewhale-windows-x64-portable.zip | — | | Windows ARM64 | codewhale-windows-arm64.zip | install.bat | | Windows ARM64 (portátil) | codewhale-windows-arm64-portable.zip | — | Unix (Linux/macOS):

tar xzf codewhale-<platform>.tar.gz
cd codewhale-<platform>
./install.sh

Janelas:

  • Para o caminho do instalador, execute CodeWhaleSetup.exe; ele instala codewhale.exe e codew.exe sob %LOCALAPPDATA%\Programs\CodeWhale\bin e adiciona esse diretório ao PATH do usuário atual.
  • Extraia o arquivo da sua máquina: codewhale-windows-x64.zip ou codewhale-windows-arm64.zip
  • Execute install.bat (copia para %USERPROFILE%\bin)
  • Adicione %USERPROFILE%\bin ao seu PATH O arquivo portátil do Windows ignora o script de instalação – extraia e execute de qualquer diretório. O instalador NSIS não está assinado no momento e pode acionar o Windows SmartScreen até que um certificado de assinatura seja conectado ao pipeline de lançamento. Cada plataforma também possui vazio, desarquivado codewhale-<platform> e Ativos codew-<platform>. Os sete nomes de arquivo codewhale-tui-<platform> anexadas ao v0.9.5 são cópias de compatibilidade idênticas a bytes usadas apenas para permitir v0.9.4 clients já instalado descobrem e cruzam este binário único transição; os instaladores atuais não expõem um terceiro tempo de execução. O legado npm o pacote deepseek-tui está obsoleto e não foi republicado. Para migração de nomes binários legados v0.8.x, consulte docs/REBRAND.md.

O que há em v0.9.5

Codewhale v0.9.5 consolida o aplicativo terminal em um compilado tempo de execução preservando os comandos familiares codewhale e codew. Isso também expande o tempo de execução gerenciado API, facilita o trabalho da sessão e da frota inspecionar e retomar, e remove o backstop de continuação local oculto que poderia encerrar o trabalho produtivo sem uma resposta final do assistente.

Adicionado

  • model = "auto" para seleção de nível baseada em prompt: Quando definido, o O despachante analisa o prompt do usuário antes de delegar à TUI e seleciona deepseek-v4-pro para tarefas complexas ou deepseek-v4-flash para tarefas simples tarefas (PR #5257).
  • Controles de tempo de execução API para metas persistentes, inspeção de memória limitada, MCP gerenciamento do ciclo de vida de servidores e habilidades e evidências duráveis de recebimento de frota.
  • Histórico de árvore de sessão somente anexado com /tree, /branch, /fork e /resume, além de controle remoto /rc e login gerenciado.
  • Uma lista de frota unificada para posturas de despacho integradas e um indicador fixado que mantém o trabalho ativo em segundo plano visível acima do compositor.
  • Atualizações incrementais do registro MCP que retornam o instantâneo local imediatamente e atualize-o em segundo plano.
  • Os agentes Scout e Reviewer podem usar um shell de evidência de comando direto limitado para espaço de trabalho somente leitura, Git e inspeção GitHub e pode manter o trabalho privado notas em suas próprias tarefas, enquanto a transcrição durável retém suas evidências.

Alterado

  • codewhale-cli agora contém o tempo de execução do terminal diretamente. Liberar instaladores expor comandos codewhale e codew com bytes idênticos sem uma TUI separada executável. O conjunto de ativos v0.9.5 sozinho mantém obsoletos Nomes de arquivos codewhale-tui-* como cópias de compatibilidade idênticas a bytes, então v0.9.4 clients instalado pode descobrir e concluir esta atualização.
  • A versão de inicialização verifica pesquisas bem-sucedidas em cache por uma hora. O atualizador baixa e verifica o tempo de execução primário uma vez e, em seguida, atualiza qualquer existente Caminhos de comando codew ou codewhale-tui herdados dos mesmos bytes.
  • O codewhale exec sem cabeça é executado e as implementações de benchmark do verificador não são mais executadas impor um padrão de 100 passos. --max-turns permanece disponível como um explícito teto opcional; Os trabalhadores da frota mantêm o seu orçamento configurado separadamente.
  • Token de meta e orçamentos de tempo são telemetria em vez de parada padrão condições, e a continuação automática da meta é ilimitada, a menos que o usuário configura explicitamente um teto de continuação.
  • A paleta de comandos e o sombreamento de conclusão de barra agora compartilham um reconhecimento de alias contrato de descoberta.
  • As orientações de instalação do site, cópia localizada do produto, controles de navegação, metadados sociais e o pipeline de construção da Cloudflare agora descrevem e implantam o mesmo contrato de lançamento de tempo de execução.

Corrigido

O backstop oculto de 20 etapas sem entrada do usuário não encerra mais curvas produtivas. Resultados da ferramenta, orientação na fila, conclusões secundárias, feedback do REPL e meta todas as continuações podem chegar à próxima etapa do provedor e um assistente final resposta; limites explícitos configurados pelo usuário e proteções genuínas contra loop preso permanecem.

  • Detalhes completos do erro podem ser inspecionados diretamente após uma falha, em vez de deixando o terminal com um fragmento de erro irrecuperável clipped.
  • Uma credencial OAuth recém-criada é adotada na mesma seleção de provedor fluxo em vez de exigir uma segunda viagem do selecionador.
  • Novos títulos de sessão podem substituir um espaço reservado New Session em cache obsoleto, limites de contexto de modelo desconhecido falham ruidosamente e fallbacks de instalação de versão/fonte não solicita mais binários removidos pela conversão de tempo de execução único.
