Codewhale v0.9.13

Codewhale é o produto público da Shannon Labs. O codewhale os nomes de comando, pacote npm e release-asset permanecem técnicos em letras minúsculas identificadores. O pacote npm legado deepseek-tui está obsoleto e não recebe mais lançamentos. Usuários provenientes do legado v0.8.x deepseek / Os nomes deepseek-tui deverão migrar com docs/REBRAND.md.

Instalar

Recomendado – lançamento oficial do GitHub

Nova instalação do macOS/Linux (binários com soma de verificação desta versão):

curl -fsSL https://codewhale.net/install.sh | CODEWHALE_VERSION="v0.9.13" sh
"$HOME/.local/bin/codewhale" --version

Para Windows, use o instalador ou arquivo correspondente abaixo. Para um existente instalação direta, execute codewhale update; ele imprime o caminho do executável e mantém compilações mais recentes. Se o diretório de instalação estiver ocupado por uma compilação diferente, use a migração de diretório novo no guia de instalação.

Embalagem secundária — npm e Cargo

npm install -g codewhale
# or build from source
cargo install codewhale-cli --locked

O wrapper baixa os ativos de comando codewhale e codew correspondentes deste lançamento. Ambos contêm o mesmo tempo de execução compilado.

Docker/GHCR

docker run --rm -it \
  -e DEEPSEEK_API_KEY="$DEEPSEEK_API_KEY" \
  -v codewhale-home:/home/codewhale/.codewhale \
  ghcr.io/hmbown/codewhale:v0.9.13

A imagem expõe o mesmo tempo de execução que codewhale e codew. O A tag latest também é atualizada no lançamento.

Carga (Linux / macOS)

cargo install codewhale-cli --locked

O pacote Cargo instala o codewhale. Cargo não pode criar um segundo comando alias de um destino binário; usuários que desejam uma ortografia mais curta podem adicionar um Link simbólico codew para o executável instalado. O npm, Homebrew, arquivo, shell-installer e canais de contêiner instalam ambos os nomes de comando diretamente.

O que há em v0.9.13

Codewhale v0.9.13 aborda problemas de integridade em 0.9.12: colar multilinha é uma pasta novamente, argumentos de ferramenta truncados não podem mais ser executados, estrito ACP clients se conectam novamente, instâncias simultâneas param de destruir cada uma texto na fila de outros, e o pacote Computer Use inclui o plugin 0.3.1 com um indicador de acessibilidade que não rouba mais o foco. Flash DeepSeek V4.1 (deepseek-flash) é o modelo DeepSeek padrão, rotas com capacidade de raciocínio continue raciocinando fora da resposta mesmo quando um ID de modelo não contém versão número, e /mcp reload não congela mais a interface enquanto os servidores reconectar. O animal de estimação Codewhale chega com /pet: um habitat em tela cheia que mostra o que o mecanismo está fazendo e revela a resposta quando terminar.

Adicionado

  • /pet entrega o terminal ao animal de estimação Codewhale. /pet on (ou vazio /pet) dá ao habitat toda a janela de visualização do conteúdo agora e em cada turno aceito, revela a resposta ou erro real quando o turno termina, e Escape retorna ao compositor sem cancelar nada. /pet off fecha a visualização e interrompe a entrada automática enquanto o companheiro durável mantém o animal de estimação vivo; Endereço /pet appearance|window|source|sound|export|status o companheiro compartilhado. O animal de estimação não mora mais na barra de trabalho: o Watch painel e /workbar watch … desapareceram (#6109, #6110).
  • Codewhale Computer Use 0.3.1 como seu próprio aplicativo Mac autenticado. Baixar a imagem do disco de codewhale.net/computer-use ou o lançamento v0.3.1 (Codewhale-Computer-Use-0.3.1-macos-universal.dmg, arraste para Aplicações; o ZIP permanece para o atualizador no aplicativo). O plugin incluído e o mercado primário fixa as mesmas fontes 0.3.1, então o aplicativo, o O plugin computer-use e /mcp veem uma implementação.

Corrigido

  • A página de download do uso do computador do site resolve seu estado sem o GitHub API (usando GITHUB_TOKEN somente quando vinculado) e cada página é regenerada no Worker novamente: a rota da imagem Open Graph lê SVGs de marca na importação tempo, o que o tempo de execução dos Workers não pode fazer, então codewhale.net estava servindo seu instantâneo em tempo de construção.

  • Operate pode executar fluxos de trabalho estruturados diretamente, com fases nomeadas, modelo atribuições da Frota, resultados de pré-requisitos e orçamentos compartilhados. Independente passos executados juntos; o trabalho dependente espera pelos resultados e portas exigidos. Execuções separadas retornam seu resultado para a conversa proprietária e sem cabeça as sessões permanecem ativas entre as fases até que o handback final seja consumido.

  • Uso do computador 0.3.1: as ações do mouse não roubam mais o foco nem recuperam o primeiro plano quando o usuário troca de aplicativo no meio da ação; digitação em segundo plano, a rolagem e a seleção usam entrada semântica, e as capturas de tela permanecem com escopo definido para o aplicativo de destino. O plug-in incluído e o pin do mercado primário carregam as mesmas fontes 0.3.1. Um ajudante registrado do macOS fica responsável por entrada por meio de seus controles Pause e Stop; um ajudante registrado indisponível produz um erro em vez de ignorar silenciosamente esses controles.

  • O editor Fleet usa o seletor de modelo padrão para gerenciar o modelo de subagente e tarefas de pensamento. Enter edita a linha selecionada sem alterar o executando o modelo da sessão. Provedores não configurados são recusados, falha no salvamento manter a atribuição anterior e um arquivo de equipe alterado ou removido deverá ser reaberto antes que uma escolha possa substituí-lo.

  • O catálogo de provedores inclui Baseten e outros provedores compatíveis modelos como linhas selecionáveis, abrindo seus formulários de configuração pré-preenchidos existentes. As rotas DeepSeek com preços baseados em relógio mostram o pico atual ou fora do horário de pico nível além do custo da sessão, com rótulos traduzidos.

  • Extensões, equipes, fluxos de trabalho e automações suportam a rolagem da roda do mouse. As linhas Plugin e MCP possuem controles de ativação/desativação do teclado e duas etapas remoção; O MCP OAuth pode tentar novamente com escopos mais restritos após uma rejeição de escopo.

  • Os subagentes saudáveis ​​continuam após uma resposta normal dos pais. Corridas sem cabeça manter o mecanismo existente ativo para resultados secundários dentro do prazo de execução. O cancelamento explícito permanece válido quando as filas de resultados estão cheias ou uma conclusão inicia um turno de acompanhamento.

  • O acompanhamento do subagente oferece suporte a vários alvos e a todas as crianças estacionadas, mantém IDs antigos conectados à sua continuação atual e salva a continuação identidade antes de começar a trabalhar. O acompanhamento repetido não bifurca duplicatas.

  • Subagentes validam arquivos de saída declarados e distinguem reivindicações de edição reais de citações de arquivos e alterações não relacionadas no espaço de trabalho. Reivindicações de arquivos separados podem correr juntos; escritores sobrepostos recebem o conflito e as soluções reais. A análise explícita do shell somente leitura requer um sandbox nativo obrigatório e recusa a execução quando essa proteção não está disponível.

  • A profundidade da delegação permanece absoluta através de perfis salvos, trabalhadores aninhados e continuações. Token por chamada, limites de etapa e tempo limitam os limites herdados; continuação retém o uso e os prazos do ancestral. Trabalhadores reservam espaço para um relatório parcial com ferramentas desativadas dentro desses limites e, em seguida, execute o relatório declarado verificações de saída. A falta de uso ou a sala de relatórios indisponível produz um alternativa explícita; o trabalho parcial nunca é marcado como concluído.

Os recibos de conclusão incluem o uso medido de tokens de trabalhadores e descendentes, contar cada continuação uma vez e distinguir o uso não relatado de zero.

  • O recurso de carga rusty-alloc em codewhale-tui e codewhale-cli opta os binários no alocador global rusty_alloc (o mimalloc Arquitetura v2.4.5 refeita em Rust puro - sem compilador C ou script de construção nesse caminho) em vez do mimalloc padrão. Está desativado por padrão e a compilação padrão permanece inalterada; construir com cargo build -p codewhale-tui --features rusty-alloc (#5872).

  • O seletor /theme agora descobre custom:<name> válido de autoria do usuário sobreposições, visualiza suas cores, destaca a sobreposição ativa e preserva quando o seletor é aberto e confirmado sem navegação (#5901).

  • A compactação tem dois botões próximos ao [context] no config.toml: [compaction] summary_instructions (anexado ao prompt do resumidor em cada passagem manual e automática; /compact <focus> ainda compõe depois ele) e [compaction] retained_user_message_tokens (padrão 20 000, fixado em 2.000..=200.000) para o orçamento literal de mensagens do usuário. Ambos são ausente por padrão e ausente significa o comportamento pré-existente. O O recibo /compact nomeia o orçamento efetivo e se o operador instruções aplicadas (#5956).

  • [tools] user_input_max_questions (padrão 6, 1..=10) e [tools] user_input_max_options (padrão 4, 2..=10) substitua o codificado Limites request_user_input; o validador, o esquema da ferramenta e seu a descrição lê um valor, os filhos gerados herdam os tetos dos pais, e uma carga rejeitada nomeia o teto atingido e a chave para aumentar (#5949).

  • O menu de barras mostra a linha de uso de um comando e seus subcomandos assim que um espaço é digitado após o verbo, filtrado pelo que segue, então Tab completa /workspace wor a /workspace worktrees; /help afirma o foco uso do comando em seu slot de detalhes (#5952).

  • As três visualizações /fleet (escalação, trabalhadores ativos, equipes salvas) são uma pilha navegável de volta: Esc em trabalhadores ou equipes salvas retorna à lista com o cursor intacto e ainda fecha a janela na raiz ou no direto entrada; a dica do rodapé Esc diz back ou close de acordo (#5954).

  • /fleet apresenta seu núcleo priorizado (members, setup, teams, workers, help); todos os outros verbos permanecem despacháveis e são documentados sob grupos explícitos em /fleet help. A lista não mostra mais o alias general integrado intocado próximo a worker (# 5888).

  • Provedor codewhale: modelo de acesso apoiado por conta através das chaves do provedor a cliente conectado à sua conta Codewhale. Um URL base (https://api.codewhale.net/v1, substituível por CODEWHALE_API_BASE; HTTPS necessário, exceto em loopback), uma chave API da conta cwc_key_… com o Escopo models:infer (CODEWHALE_API_KEY) e um fio por modelo escolhido entre o GET /v1/models autenticado da conta: os ids são provider/model e cada linha indica chat-completions (/v1/chat/completions) ou anthropic-messages (/v1/messages). Ambos os protocolos autenticam com Authorization: Bearer, nunca x-api-key. A chave é lida de CODEWHALE_API_KEY, o slot de armazenamento secreto codewhale, ou [providers.codewhale] api_key / api_key_env, e uma chave ausente falha antes de qualquer solicitação, em vez de despachar não autenticado. Se o catálogo não pode ser buscada, a rota volta para três ids de bootstrap e diz isso.

  • codewhale account api-keys create --scope agora aceita models:infer ao lado de account:read e agent:run, e um --scope omitido envia todos três explicitamente. --use salva o novo segredo como local desta máquina Credencial do provedor codewhale no mesmo armazenamento secreto codewhale auth usos; nada é carregado.

  • Git desenvolve uma ação commit_plan: um planejador somente proposto que divide o árvore de trabalho em commits atômicos ordenados (#3999). Ele agrupa arquivos inteiros — os arquivos de bloqueio acompanham seu manifesto, os testes acompanham a fonte que eles nomeiam - ordena os grupos para que um commit que defina um símbolo chegue antes do commit que o utiliza e recusa todo o plano quando esse gráfico de dependência tem um ciclo. Ele lê git diff HEAD mais a lista de arquivos não rastreados e grava nada: não git add -N, não git apply --cached, não git commit, então preparar e confirmar estadia com o shell git add / git commit comum caminho onde a porta de aprovação já se aplica. Obrigado @goransh-walia pelo original implementação (PR #5870, correções #3999).
