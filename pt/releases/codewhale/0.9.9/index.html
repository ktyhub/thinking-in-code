Codewhale v0.9.9

Codewhale é o produto público da Shannon Labs. O codewhale os nomes de comando, pacote npm e release-asset permanecem técnicos em letras minúsculas identificadores. O pacote npm legado deepseek-tui está obsoleto e não recebe mais lançamentos. Usuários provenientes do legado v0.8.x deepseek / Os nomes deepseek-tui deverão migrar com docs/REBRAND.md.

Instalar

Recomendado — npm (um comando, ambos os pontos de entrada)

npm install -g codewhale

O wrapper baixa os ativos de comando codewhale e codew correspondentes deste lançamento. Ambos contêm o mesmo tempo de execução compilado.

Docker/GHCR

docker run --rm -it \
  -e DEEPSEEK_API_KEY="$DEEPSEEK_API_KEY" \
  -v codewhale-home:/home/codewhale/.codewhale \
  ghcr.io/hmbown/codewhale:v0.9.9

A imagem expõe o mesmo tempo de execução que codewhale e codew. O A tag latest também é atualizada no lançamento.

Carga (Linux / macOS)

cargo install codewhale-cli --locked

O pacote Cargo instala o codewhale. Cargo não pode criar um segundo comando alias de um destino binário; usuários que desejam uma ortografia mais curta podem adicionar um Link simbólico codew para o executável instalado. O npm, Homebrew, arquivo, shell-installer e canais de contêiner instalam ambos os nomes de comando diretamente.

Download manual — arquivos da plataforma (recomendado)

Cada arquivo abaixo contém o mesmo tempo de execução no codewhale e Nomes de comandos codew, além de um script de instalação:

| Plataforma | Arquivo | Instalar script | |---|---|---| | Linux x64 | codewhale-linux-x64.tar.gz | install.sh | | Linux ARM64 | codewhale-linux-arm64.tar.gz | install.sh | | Android ARM64 (Termux) | codewhale-android-arm64.tar.gz | install.sh | | macOS x64 | codewhale-macos-x64.tar.gz | install.sh | | ARM do macOS | codewhale-macos-arm64.tar.gz | install.sh | | Windows x64 (instalador) | CodeWhaleSetup.exe | Configuração do NSIS | | Janelas x64 | codewhale-windows-x64.zip | install.bat | | Windows x64 (portátil) | codewhale-windows-x64-portable.zip | — | | Windows ARM64 | codewhale-windows-arm64.zip | install.bat | | Windows ARM64 (portátil) | codewhale-windows-arm64-portable.zip | — |

Unix (Linux/macOS):

tar xzf codewhale-<platform>.tar.gz
cd codewhale-<platform>
./install.sh

Janelas:

  • Para o caminho do instalador, execute CodeWhaleSetup.exe; ele instala codewhale.exe e codew.exe sob %LOCALAPPDATA%\Programs\CodeWhale\bin e adiciona esse diretório ao PATH do usuário atual.
  • Extraia o arquivo da sua máquina: codewhale-windows-x64.zip ou codewhale-windows-arm64.zip
  • Execute install.bat (copia para %USERPROFILE%\bin)
  • Adicione %USERPROFILE%\bin ao seu PATH

O arquivo portátil do Windows ignora o script de instalação – extraia e execute de qualquer diretório. O instalador NSIS não está assinado no momento e pode acionar o Windows SmartScreen até que um certificado de assinatura seja conectado ao pipeline de lançamento.

Cada plataforma também possui vazio, desarquivado codewhale-<platform> e Ativos codew-<platform>. Os sete nomes de arquivo codewhale-tui-<platform> anexadas ao v0.9.5 são cópias de compatibilidade idênticas a bytes usadas apenas para permitir v0.9.4 clients já instalado descobrem e cruzam este binário único transição; os instaladores atuais não expõem um terceiro tempo de execução. O legado npm o pacote deepseek-tui está obsoleto e não foi republicado. Para migração de nomes binários legados v0.8.x, consulte docs/REBRAND.md.

O que há em v0.9.9

Codewhale v0.9.9 é uma versão verdadeira e resiliente: a ferramenta shell não pode não interrompe mais uma sessão quando o host fica sem disco ou descritores, janelas de contexto não verificadas e limites de produção são rotulados honestamente a cada superfície, o DeepSeek V4 tem preços nos níveis de pico/fora de pico publicados, SSE UTF-8 falha ao fechar em todos os dialetos, o sombreamento da frota é visível, o bwrap é obtido itens essenciais do recipiente e raízes extras, a capa dsh acompanha o pacote perfil, o esquema da ferramenta agent é reduzido para 12 campos e README/website localidades crescem para 18 e 8.

Corrigido

  • A ferramenta bash em minúsculas não fica mais presa quando sua saída completa é derramada o arquivo não pode ser criado: um volume temporário completo ou tabela de descritores esgotada usado para falhar em todas chamadas - echo ok incluído - com o chicote interno "Falha ao criar saída de shell de streaming" e nunca se recupera até o host foi limpo. O derramamento agora é de melhor esforço (a cauda delimitada é ainda retornado e o aviso de truncamento diz por que o caminho de saída completo é faltando), e qualquer falha de spawn/stream restante nomeia o esgotado recurso – disco, descritores de arquivo, memória – e diz que a próxima chamada é segura para tentar novamente (#5465; a cunha que destruiu a sessão 0.9.9 do próprio proprietário).
  • Um limite concreto de saída de rota/oferta agora supera o conservador Suposição de compatibilidade de 8.192 tokens para um modelo não catalogado. Rotas que não publicar nenhum limite de produção permanece fechado, os tetos do modelo documentado permanecem autoritativo, e um limite de rota nunca pode aumentar o limite solicitado (#5460).
  • Honestidade da janela de contexto em todas as superfícies (#5239, #5441): o Os degraus model-name hint e fallback da escada da janela de contexto são suposições, e cada superfície que renderiza uma agora diz isso - a linha de status, /status, /config, a mensagem de pressão de contexto, os chips seletores de modelo, e o inventário do roteador automático. Janelas não verificadas ainda geram orçamentos reais (gatilho de compactação, medidor de contexto, reserva de saída); eles simplesmente param lendo como capacidades que alguém verificou. Uma janela analisada a partir de um _Nk sufixo do nome do modelo (qwen3-32b-256k → 256K) agora é seu model-name hint ficou abaixo de catalog, porque é bastante otimista do que conservador – um valor relatado por catálogo ou fornecedor é melhor que isso. O A substituição do [providers.<name>] context_window continua sendo a solução difícil e é renderizado como configured sem marcador.
  • Honestidade no teto de produção (#5440): um modelo de família antrópica que o catálogo faz não descrito mantém o piso de mensagens de 64K como seu grampo e o ChatGPT/ A rota Codex OAuth mantém sua política de 4K, mas OutputCeilingSource ganhou uma unverified tocou para ambos, então recibos de fluxo de execução e o seletor de modelo rotule-os como unverified/"piso presumido" em vez de documented. Braçadeira os valores permanecem inalterados.
  • O padrão de telemetria é visível (#5441): codewhale doctor's A seção de postura de tempo de execução ganhou uma linha no estilo telemetry=on (default) com a fonte que decidiu (cli | env | config | default), e codewhale config get telemetry reporta o consentimento resolvido com seu fonte em vez de key not found em uma máquina cujos lotes são enviados. Verdade alterar apenas; resolução e comportamento permanecem intocados.
  • Frota: o escudo somente leitura de um batedor (#5428) agora é homenageado por ambos o portão de postura e o envelope de execução, então git log, find | head, npm view e os outros comandos somente leitura limitados são executados no local de ser recusado como "Executa" (#5426). A delegação ainda nunca se amplia autoridade: o teste de isolamento de função e o pin docs/SUBAGENTS.md que uma criança não pode exceder a postura de seus pais (#5426, #5435).
  • /rename e /title agora se aplicam no meio do primeiro turno: o arquivo de sessão não não existe até o primeiro salvamento automático, então a renomeação falhou Não encontrado; o caminho compartilhado agora prefere o ponto de verificação por sessão e reconstrói a partir do estado do aplicativo, com um teste de regressão PTY por meio do live loop de eventos (#5430).
  • integrations dsh plan não recusa mais o padrão do DeepSeek Rota de dialeto de respostas (deepseek-v4-flash); Respostas e Rotas de Mensagens Antrópicas são realizadas através de pi-ai openai-responses / anthropic-messages em vez de ser aproximado ou recusado; apenas URLs base credenciados ainda são recusados, com um erro que nomeia provedor e modelo (#5434).
  • O custo da sessão não fica mais em unverified_live_pricing com preços ao vivo não pode ser verificado (plano de controle 503, recursos apenas de Models.dev sobreposições): taxas de fallback agrupadas em Provider-Docs para o DeepSeek V4 família no Fireworks / OpenCode Zen restaura uma figura utilizável, ao vivo linhas por provedor ainda vencem e kimi-k3 permanece sem preço até um existe taxa publicada (#5241; coletado de #5402).
  • Liberar ativos: as verificações de atualização de ativos release.yml são comparadas com o libere o próprio started_at do trabalho, portanto, repetições da etapa npm em nível de trabalho não são não está mais envenenado por uploads anteriores (#5429).
  • macOS CI: o teste de recibo de revisão automática agent_focus_pty aguardou um trabalhador que já havia concluído e percorrido o foco do trilho; agora segura o encerramento da criança e aguarda por uma linha ao vivo resolvida (refs #5056, #5403).
  • O preço do DeepSeek V4 segue os níveis de pico/fora de pico publicados (pico 01h00 às 04h00 e 06h00 às 10h00 UTC; fora do pico é metade do pico) para deepseek-v4-flash e deepseek-v4-pro em USD e CNY, resolvidos a partir de o tempo registrado de cada turno; as linhas obsoletas de camada única subestimaram o custo para ~4×. Porque todas as taxas primárias diretas do DeepSeek agora são janela de tempo, o scorecard falha no fechamento (missing_recorded_time) em um turno DeepSeek sem data em vez de adivinhar um nível (#5470; #5241 acompanhamento, verificado em api-docs.deepseek.com em 17/08/2026).
  • SSE UTF-8 dividido em quadros HTTP/2 DATA agora falha ao fechar em todos dialeto de streaming: um decodificador estrito compartilhado, tail flush e A propagação decode_failed (InvalidSseUtf8) substitui o por dialeto aproximações, com testes de decodificador de byte-chunk (#5374; substitui rascunho #5404).
  • CI: release_four_read_only_fleet_roles_launch_with_canonical_prompts responderam crianças da Frota com SSE enquanto chamavam o caminho bloqueador JSON; a falha de análise foi repetida e contabilizou duas vezes o trabalhador no macOS lento corredores (#5471; referências #5056).
  • Contexto: cada superfície de ferramenta web (Web, web_search, web.run, fetch_url) agora usa o limite suave de resultados ruidosos, portanto, buscas grandes são compactado como saída de shell em vez de consumir o limite rígido comum (#5474, obrigado @h3c-hexin).
  • Roteamento: um seletor salvo em letras minúsculas, como glm-5.2, resolve contra o possuir linha de catálogo Z.ai / DeepSeek (substituição case-fold, somente quando exatamente um ID de transferência de propriedade do provedor corresponde) em vez de ser classificado como outro modelo simples do provedor (#5475, obrigado @h3c-hexin; diagnóstico por @asto18089 em Pinvou/CodeWhale#14).
  • Catálogo de modelos atualizado em 17/08/2026 contra o oficial páginas de preços: taxas gpt-5.6-terra / gpt-5.6-luna, claude-sonnet-5 mantém US$ 2/US$ 10 (o aumento anunciado de setembro foi retirado), claude-opus-5 adicionados, kimi-k3 e kimi-k2.7-code-highspeed, MiniMax-M2.7-highspeed, Linhas primárias Mistral, xAI grok-4.5 / grok-4.3 com contexto longo níveis, limites Gemini e Qwen e visualização dots3-note do RedNote como um Linha OpenRouter (ainda não existe API original) - cada número carrega seu fonte e um teste fixado (#5485).
  • Site: cópia em codewhale.net reescrita em frases declarativas simples — uma ideia por frase, números dos fatos gerados, sem autonarração — com uma planilha de voz em docs/design/WEB_VOICE.md (#5483).
  • CI: os fluxos de trabalho de lançamento não restauram mais caches npm/cargo após verificando um SHA fornecido pelo chamador – os altos de envenenamento de cache do CodeQL #88–#107 são fechados com um teste de contrato nos arquivos de fluxo de trabalho (#5463).
  • As linhas compactas da TUI abaixo de 60 colunas não reservam mais métricas de sessão ocultas tira, então terminais estreitos recuperam a linha em vez de clipping o transcrição (#5486).
  • O campo subaquático truecolor do Ghostty agora usa um campo sincronizado dedicado Faixa de 60 FPS em vez do limite de compatibilidade herdado de 30 FPS, com contínuo desbotamentos cáusticos substituindo mudanças de cor visivelmente escalonadas.
  • A ação Space:expand anunciada do raciocínio ao vivo agora é executada antes do o primeiro caractere do compositor é mantido, enquanto os espaços em uma pasta ativa permanece carga útil. A mais nova prévia do raciocínio também gasta apenas genuinamente grátis linhas da janela de visualização antes de truncar em vez de parar na linha fixa de 10/12 fallback em terminais espaçosos.
  • Construções cargo doc estritas não falham mais em URLs simples em comentários rustdoc; os links restantes são alvos Markdown explícitos (#5489).

Alterado

  • A ferramenta agent voltada para o modelo anuncia exatamente 12 campos - action, prompt, type, profile, name, agent_id, message, until, detached, worktree, write_roots, resume_from – abaixo de 33 (#5324, referências #5123). Orçamentos (max_steps, wall_time_secs, max_depth), substituições de roteamento (model, model_strength, thinking), caminho da árvore de trabalho botões, os campos deliberado/contrato de geração e os campos de espera/status/interrupção extras saíram do esquema anunciado. Cada campo removido permanece aceito pela análise e honrado inalterado (mesmo contrato de token_budget), então transcrições salvas, configurações ACP/MCP clients e Fleet são reproduzidas como estão; o Os grampos de contenção #5426/#5435 estão intactos. Orçamentos infantis agora resolvem dos padrões de função (60/120 voltas, tempo de parede de 1800 s, grampos inalterados) e novas chaves [subagents] default_max_steps / default_wall_time_secs. Como o catálogo de ferramentas faz parte do prefixo do prompt fixado na sessão (docs/CACHE.md), a atualização preenche novamente o prefixo KV uma vez por sessão.
  • Prosa TUI – mensagens do usuário, respostas do assistente e raciocínio/pensamento – agora envolve toda a largura do conteúdo em terminais largos, correspondendo células de ferramenta/status, em vez de parar em um trilho de 105 colunas que deixou um margem direita morta em telas ultralargas (#5436).
  • Os prompts de habilidade configurados são estáveis nas raízes da sessão e na operação sistemas: apenas raízes configuradas personalizadas ocultam seu caminho físico, espaço de trabalho/habilidades globais mantêm um caminho detectável e seguro para a privacidade, alertando as substituições reconhecem os limites (incluindo caminhos Unix não UTF-8) e Os separadores do Windows são renderizados como /. O prompt de habilidades também tem 50 bytes mais enxuto sem aumentar o teto do contrato de execução (#5492, #5473).
  • Solicitações de classificador de roteador automático aceitam [auto.router] timeout_secs, enquanto preservando o padrão existente quando a chave está ausente (#5494).
  • Cada trabalho ci.yml agora tem um tempo limite explícito de 10 a 90 minutos, apropriado para sua carga de trabalho, limitando executores atribuídos obsoletos em vez de herdar Padrão de seis horas do GitHub (#5495).
  • O shell de documentos e os componentes da web compartilhados agora encaminham a cópia localizada a lombada do dicionário digitado; estas são duas fases incrementais de #5337, não a conclusão do épico completo (#5488, #5490).
  • Dependência: rusqlite 0.40.2 (#5391).
  • Documentação: referências obsoletas das camadas A/B/C, padrões do provedor, módulo descrições e âncoras de linha agora correspondem ao código atual (#5481).

Adicionado

  • [transcript] prose_measure (número inteiro positivo, opcional): prosa em maiúsculas agrupar em N colunas para proprietários que desejam uma medida de leitura limitada em terminais ultralargos. 0 ou ausente mantém toda a largura; negativo ou valores não inteiros são rejeitados com um erro de configuração claro. Ferramenta, diferença, e as células de status nunca herdam o limite (#5436).
  • Localização: traduções README para Français, Deutsch, 繁體中文, हिन्दी, Türkçe, Italiano, Polski, العربية e Català juntam-se aos nove existentes (#5451); codewhale.net rotas fr, de, ca, hi, tr, it, pl e ar (com encanamento dir="rtl") como localidades parciais (#5453).
  • Documentos: seção README Integrations (incl. o plugin DeepSeek Harness dsh caminho, docs/INTEGRATIONS_DSH.md) localizado em todos os READMEs; Manutenção de RFC o híbrido de revisão automática determinística (#5427); Paridade do Código Claude referência para agentes/fluxos de trabalho/plugins/habilidades (docs/design/CLAUDE_CODE_PARITY.md); config.example.toml /SUBAGENTS.md / TOOL_LIFECYCLE.md alinhado com o código (#5447).
  • Integração dsh: a paleta Codewhale é aplicada através do pacote perfil via overrideTokens documentado do dsh (ativado por padrão; codewhale integrations dsh update --skin false desliga), substituindo o skin CSS exportado 0.9.8 que as variáveis ​​inline do corpo do dsh substituíram (docs/design/DSH_BUNDLE_SKIN.md, docs/INTEGRATIONS_DSH.md) (#5469).
  • Integração dsh: uma cena ambiental do oceano por trás da interface da web DSH - lenta silhuetas de baleias, um cardume de peixes glifos ><>, bolhas - desenhadas em um tela sob um véu translúcido da paleta Codewhale, além de um explícito bloqueio WHALE BROTHERS / CODEWHALE × DEEPSEEK HARNESS responsivo; luz e escuro, limitado a ~30 fps, pausado quando oculto, um quadro estático sob prefers-reduced-motion; ativado por padrão com a skin, codewhale integrations dsh update --ocean false desliga (#5484).
  • Frota: o sombreamento do agente é visível — um emblema de linha de escalação, um bloco de Camadas detalhes do agente e uma seção doctor "Camadas de escala de frota" (JSON operate_fleet.roster.multi_layer), em todas as 15 localidades da TUI. Colapso de camada e migração [fleet.profiles] permanece para 0.9.10 (#5098). Sandbox: os contêineres bwrap recebem o essencial do --dev/--proc/--tmpfs plus raízes extras configuráveis (bwrap_ro_roots / bwrap_dev_roots) para cadeias de ferramentas que ficam fora do espaço de trabalho permanecem acessíveis somente leitura (#5410). Testes: crates/tui/tests/README.md declara a jornada montada sem chave regra e mapeia os itens de aceitação do responsável pela revisão automática para o mecanismo jornadas que os exercitam (#5361).
  • O endpoint padrão do OrcaRouter é classificado como agregador de faturamento superfície, para que os relatórios de preços e custos de sessão usem o faturamento correto postura em vez de tratá-lo como um fornecedor primário (#5493).
  • Dependências: ratatui 0.30.2, este erro 2.0.20.

Removido

  • Integração dsh: o arquivo de skin CSS exportado e seu status de "exportação de skin" linha (substituída pela capa overrideTokens aplicada em pacote, # 5469).
