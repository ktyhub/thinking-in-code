#Agente-Reach v1.5.0

Qual é esta versão?

O Agent Reach foi atualizado de "Coleção de ferramentas" para "Camada de capacidade": Cada plataforma = preferida + lista de back-end ordenada alternativa. O método de acesso mais estável no momento é selecionado, instalado e verificado por meio de testes reais - você não terá que se preocupar com a substituição dos métodos de acesso. Todas as seleções nesta versão são baseadas em testes reais de máquinas em 2026-06 (32 testes ponta a ponta).

Mudanças no roteamento da plataforma

| Plataforma | A estrada atual | |------|---------| | Xiaohongshu | OpenCLI (desktop, reutilização do estado de login do navegador sem configuração) ▸ xiaohongshu-mcp (servidor, código de verificação) ▸ xhs-cli (disponível em estoque, o upstream foi interrompido) | | Reddit | OpenCLI ▸ rdt-cli. Calibre honesto: Reddit não possui caminho de configuração zero (a interface anônima foi completamente bloqueada e o sistema oficial de aprovação API é necessário), e você deve fazer login | | Estação B | bili-cli (Pesquisa/Popular/Detalhes, não há necessidade de fazer login) ▸ OpenCLI (Legendas) ▸ Pesquise API para descobrir. yt-dlp saiu do site B (completamente interceptado pelo controle de risco 412, a versão mais recente + proxy + cookie testados são inválidos); yt-dlp continua servindo o YouTube | | Twitter | twitter-cli Gatekeeper (estável na medição real)▸ Alternativa OpenCLI, detecção e nova tentativa |

médico se tornou um verdadeiro exame físico

  • Execute realmente a detecção de comandos em vez de apenas observar a existência do arquivo - pode identificar "instalado, mas quebrado" (típico: o link venv é quebrado após a atualização do sistema Python) e fornece prescrições de reinstalação que podem ser copiadas diretamente
  • Informar qual caminho está sendo utilizado atualmente por cada plataforma multi-backend (active_backend da doctor --json)
  • O colapso de um canal não prejudicará mais todo o exame físico.

Armazenamento OpenCLI (back-end de desktop)

agent-reach install --channels opencli: o npm é instalado automaticamente, clique uma vez no armazenamento de extensões do Chrome (modelo de segurança do Chrome, não pode ser clicado em nome de). Reutilize o status de login do seu navegador - você pode usá-lo diretamente após navegar no Xiaohongshu ou fazer login no Reddit. Requer desktop + Chrome, servidor ignorado automaticamente.

Experiência de instalação e atualização

  • Instalação em uma frase: 帮我安装 Agent Reach：https://raw.githubusercontent.com/Panniantong/agent-reach/main/docs/install.md
  • Atualize uma frase: 帮我更新 Agent Reach：https://raw.githubusercontent.com/Panniantong/agent-reach/main/docs/update.md (ontologia + ferramentas upstream + habilidades para atualizar de uma vez)
  • Reescrita de habilidade: "Pesquisa em toda a rede" e "Ajude-me a pesquisar" são acionados de forma confiável; depois que o agente terminar um grande trabalho, ele verificará a versão. Se houver uma nova versão, ele dará um lembrete no final (sem interrupção, sem reclamações repetidas)
  • Correção check-update: não solicita mais "atualização" por engano quando a versão local está à frente da versão mais recente (para evitar downgrade)

Qualidade

  • Teste 107 → 162 (Cobertura completa do contrato/cenário de link quebrado/matriz de prioridade de backend/comparação de versões)
  • Após três rodadas de revisão adversa (todas as 12 descobertas foram corrigidas): foram corrigidos problemas como bloqueio de roteamento do Twitter, avisos de downgrade de observação, switches de proxy mortos, etc., que realmente prejudicariam os usuários.
  • Passou em todos os 32 testes completos de máquinas reais em 13 canais

Agradecimentos

Upstreams recentemente incluídos: OpenCLI(@jackwener), xiaohongshu-mcp(@xpzouying).
