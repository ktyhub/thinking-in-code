Notas

Este novo release candidate do Maven 4 foi lançado para obter feedback dos usuários. O Maven 4 tem algumas restrições em comparação ao Maven 3, então certifique-se de executar a ferramenta mvnup antes de tentar projetar com o Maven 4.

Bug de configuração do Bean

Um bug foi encontrado no sistema de configuração do bean onde o estado de acessibilidade do campo é armazenado em cache globalmente. Isso pode causar falha na injeção de configuração do plug-in quando o mesmo campo de configuração é acessado várias vezes ou em contextos diferentes durante uma construção. Isto afeta particularmente os testes de unidade do plugin.

Isso será corrigido por #11433 na próxima versão.

Problema de simultaneidade na v4 API

Um problema de simultaneidade foi encontrado no Maven 4 API (ainda em modo de visualização) e será corrigido por #11428 na próxima versão.

Embalagem BOM

Outro bug foi encontrado na forma como os projetos BOM são processados. Quando um projeto usa empacotamento de BOM, o POM do consumidor não está sendo convertido corretamente para o empacotamento POM padrão e as versões de dependência podem ser perdidas em alguns casos.

Isso será corrigido por #11427 na próxima versão.

macOS: biblioteca nativa JLine pode ser bloqueada pelo Gatekeeper no primeiro uso

No macOS (especialmente Apple Silicon), a primeira invocação de mvn pode falhar ao carregar a biblioteca de terminal nativa JLine com um erro como:

java.lang.UnsatisfiedLinkError: .../libjline-native/Mac/arm64/libjlinenative.jnilib: dlopen(...): code signature ... not valid for use in process: library load disallowed by system policy

Isso ocorre quando a distribuição binária é baixada através de um navegador web, que aplica o atributo com.apple.quarantine extended.

Solução alternativa (correção única):

xattr -r -d com.apple.quarantine /path/to/apache-maven-4.0.0-rc-5/lib/jline-native

Método de download recomendado (evita totalmente o problema):

curl -L -O https://archive.apache.org/dist/maven/maven-4/4.0.0-rc-5/binaries/apache-maven-4.0.0-rc-5-bin.tar.gz
tar -xzf apache-maven-4.0.0-rc-5-bin.tar.gz

Este é um problema conhecido nº 10747 e será resolvido em uma versão futura.
