#leme v4.2.0

Helm v4.2.0 é um lançamento de recurso. Os usuários são incentivados a atualizar para obter a melhor experiência.

A comunidade continua crescendo e adoraríamos ver você lá!

  • Participe da discussão no Kubernetes Slack:
    • para perguntas e apenas para sair
    • para discutir PRs, código e bugs
  • Participe da chamada pública para desenvolvedores: quinta-feira, 9h30 (horário do Pacífico) via Zoom
  • Teste, depure e contribua com gráficos: ArtifactHub/packages

Mudanças notáveis

  • Mude para goreleaser para versões de lançamento
  • Bibliotecas Kubernetes client para v1.36
  • Adicionar função de modelo mustToToml
  • descontinuar sinalizadores --hide-notes e --render-subchart-notes não utilizados
  • --dry-run=server agora respeita generateName:
