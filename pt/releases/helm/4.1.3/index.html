helm v4.1.3

#leme v4.1.3 Helm v4.1.3 é uma versão de patch. Os usuários são incentivados a atualizar para obter a melhor experiência. Observe que não houve lançamento do 4.1.2 devido a um problema de automação de lançamento. A comunidade continua crescendo e adoraríamos ver você lá!

  • Participe da discussão no Kubernetes Slack:
    • para perguntas e apenas para sair
    • para discutir PRs, código e bugs
  • Participe da chamada pública para desenvolvedores: quinta-feira, 9h30 (horário do Pacífico) via Zoom
  • Teste, depure e contribua com gráficos: ArtifactHub/packages

Mudanças notáveis

  • Corrigido um bug onde --dry-run=server não respeitava generateName #31563
  • Corrigido um bug onde recursos CRD vazios causavam um travamento. Agora imprime um erro #31578
  • Corrigido um bug onde as referências OCI com tag+digest falhavam com o erro "byte inválido" #31601
  • Corrigido um bug onde o valor nulo fornecido pelo usuário não era preservado quando o gráfico tinha um mapa vazio ou nenhum padrão para uma chave #31644
  • Corrigida uma regressão desde o Helm 3.18.0, onde a extração de gráficos de repositórios OCI que usam um índice para armazenar imagens de contêiner e gráficos do Helm sob a mesma tag falhava #31776
  • Corrigida uma regressão do Helm 4 em que o corte de espaço em branco do modelo diretamente após os separadores de documentos YAML, quando presentes após a pós-renderização, causava corrupção do arquivo YAML #31868
  • Corrigido um bug em que FailedStatus era tratado como um estado terminal, fazendo com que as atualizações falhassem prematuramente quando os escalonadores automáticos de cluster precisavam de tempo para provisionar nós ou quando os pods estavam sendo excluídos durante atualizações contínuas #31897
  • Corrigida compatibilidade retroativa quebrada para sinalizador --atomic obsoleto no comando de instalação #31901
  • SDK: Corrigido um erro de 'Acesso definido' do Windows se vários processos tentassem baixar a mesma versão do gráfico simultaneamente #31128
  • SDK: Corrigido um bug em que os usuários não recebiam nenhum registro do garçom, causando confusão, pois vários minutos podiam se passar sem nenhum feedback do usuário #31717
  • SDK: Corrigido um bug onde os padrões de aplicação do lado do servidor nem sempre correspondiam aos padrões do CLI #31732
  • SDK: Corrigido um problema de importação Go quando as ferramentas downstream tentavam vender o helm.sh/helm/v4/pkg/kube #31852
