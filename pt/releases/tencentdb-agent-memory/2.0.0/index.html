TencentDB-Agente-Memória v2.0.0

[2.0.0] - 03/08/2026

A versão oficial do v2.0.0 é lançada. Comparado com beta.1, novo arquivamento forçado de habilidades, sincronização agendada CodeGraph, O painel possui recursos como gerenciamento de ativos de comutação/administrador em chinês e inglês, e o processo de implantação e a documentação de acesso foram aprimorados.

Posicionamento do Produto: Deixe a experiência, os documentos e o código do Agente se tornarem ativos reutilizáveis para o próximo Agente Leia arquivos diretamente. Consulte README_CN.md para obter detalhes.

🧠 Quatro ativos de memória · Código totalmente aberto pela primeira vez

Quatro tipos de ativos são depositados automaticamente a partir de "traços de conversa/trabalho":

  • Memória de bate-papo - Extraia camada por camada do registro original L0 → fato L1 → cena L2 → L3 da conversa Cognição de longo prazo; retendo preferências, decisões e histórico de interação entre sessões.
  • Habilidade — Extraia SOPs reutilizáveis de tarefas concluídas, com versões/arquivos de recursos/limites de gatilho/ Etapas de execução/regras de validação. Novo A função de arquivamento forçado foi adicionada para garantir que as principais habilidades não sejam perdidas.
  • Wiki — Transforme documentos em páginas estruturadas + gráfico de links (inspirado na base de conhecimento LLM de Karpathy prática).
  • CodeGraph — Indexar símbolos/arquivos/relacionamentos de chamada/caminhos de influência do armazém, agente altera código Faça uma análise de impacto primeiro. Novo Sincronize automaticamente a função de base de código em intervalos regulares, sem necessidade de fazer isso manualmente após a alteração do warehouse. acionar.

🎛️ Memory Hub · Console voltado para equipe

Painel de gerenciamento (imagem agentmemory/memory-hub, incluindo Painel + Serviço de Conhecimento):

  • Crie Equipe/Agente e gerencie ativos uniformemente por Proprietário/Versão/Status/Visibilidade
  • Visibilidade de nível 3: private/team/restricted (ACL de usuário/função/agente), Mais montagem direcional agent
  • Carregamento do agente: vincule diferentes ativos a diferentes agentes, ajuste prioridades e métodos de uso
  • O workshop Wiki + CodeGraph está integrado ao Hub e pode ser construído automaticamente importando a biblioteca/documentação de código
  • Novo Administrador (Administrador do Sistema) também pode usar a função de gerenciamento de ativos
  • Novo painel suporta totalmente a alternância entre chinês e inglês; estilo de design de página unificado, interação de lista otimizada e experiência de paginação

🔀 Memory Proxy · Agente desliga o canal de memória

agentmemory/memory-proxy permite que agentes de codificação como Claude Code usem diretamente a memória da equipe:

  • Protocolo duplo Antrópico / OpenAI: /claude-code/<spaceId>/v1/messages e /v1/chat/completions todos aceitos
  • Primeira rodada de inicialização: sessionInit permite que os usuários selecionem equipe/agente/através do AskUserQuestion tarefa, proxy lembre-se da ligação
  • Injeção em cada rodada: Injete a memória L2/L3 do agente, habilidade correspondente, wiki/gráfico de código Insira o prompt do sistema e encaminhe o LLM upstream
  • Autenticação: x-tdai-user-key → kernel /v3/meta/auth/verify substituído por user_id, Controlar a visibilidade dos ativos por dimensão do usuário

🚀 Método de implantação

| Método | Descrição | |------|------| | Conjunto de três peças Docker | agentmemory/memory-core / agentmemory/memory-hub / agentmemory/memory-proxy, multi-frame (linux/amd64 + linux/arm64), pull-up start-all.sh com um clique. Inicie o init-admin automático pela primeira vez e gere .admin-key. Depois que start-all.sh passa no autoteste, ele imprime o comando de inicialização copiável do claude | | Execução do código-fonte | Referência INSTALL_CN.md / INSTALL.md |

stop-all.sh --purge pode limpar completamente o volume + tecla de administração para facilitar a redefinição do ambiente.
