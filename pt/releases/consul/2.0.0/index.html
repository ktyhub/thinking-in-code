#cônsul v2.0.0

2.0.0 (22 de maio de 2026)

SEGURANÇA:

  • conectar: atualize a versão do enviado para 1.37.2 e versões mais recentes [GH-23469]
  • go: Atualize a versão go para 1.26 [GH-23493]
  • agente: Aumento do tempo limite padrão do servidor HTTP para evitar a quebra de consultas de bloqueio de pesquisa longa. read_timeout e write_timeout agora estão definidos para 15 minutos (acima de 30 segundos), enquanto read_header_timeout (10s) e idle_timeout (120s) ainda fornecem proteção contra ataques Slowloris. Todos os timeouts permanecem configuráveis ​​através do bloco http_config. [GH-23267]
  • Gateway api, gateway de terminação: aplique a normalização do caminho de solicitação HTTP no gateway api e nos ouvintes HTTP do gateway de terminação para evitar desvio de RBAC de intenção L7 por meio de caminhos não normalizados (CVE-2024-10005). [GH-23534]
  • docker: atualize a imagem base ubi para ubi9-minimal:9.7. [GH-23553]
  • docker: Atualize curl para >= 8.20.0 da borda Alpine na imagem do contêiner para endereçar CVE-2026-6429, CVE-2026-4873, CVE-2026-5773, CVE-2026-6253, CVE-2026-6276, CVE-2026-7168, CVE-2026-5545. Alpine 3.23 estável ainda não traz a versão corrigida. [GH-23750]
  • docker: Atualização da imagem base UBI para 9.8 para correção [CVE_2026-2100] [GH-23588]

RECURSOS:

  • (Somente Enterprise) atualização para go-licensing/v4 e go-census/v3 para se adaptar às novas licenças do PAO.
  • Limitador de taxa global: (somente empresas) um novo tipo de entrada de configuração de "limite de taxa" que permite limitação de taxa RPC dinâmica em todo o cluster, armazenada no Raft e replicada automaticamente para todos os servidores. Isso permite que as operadoras apliquem ou ajustem limites de taxas globais em tempo de execução sem reiniciar os servidores Consul — um recurso crítico para cenários de emergência onde o cluster está sob carga excessiva.
  • api-gateway: Adicionado suporte a certificado SDS para ouvintes do gateway API, incluindo certificados TLS padrão em nível de ouvinte e substituições SDS TLS de serviço de rota HTTP/TCP. As substituições de serviço herdam o cluster SDS do ouvinte quando omitidas, e a validação de gateway/geração de xDS agora rejeita mapeamentos de substituição conflitantes para manter a seleção do certificado determinística. [GH-23354]
  • api-gateway: adiciona suporte para limites upstream padrão em nível de gateway e substituições de limite de nível de serviço de rota para MaxConnections, MaxPendingRequests e MaxConcurrentRequests. [GH-23396]
  • api: Adicionado novo API "/v1/internal/rpc/methods" que lista todos os nomes de métodos RPC. Requer um operador:ler token ACL. Isto é útil quando os usuários desejam configurar limites de taxa que excluem pontos de extremidade RPC específicos. [GH-23329]
  • ca: (Somente Enterprise) Adicionado novo provedor Connect CA para Cyberark WIM (connect.ca_provider = "pan-distributed-issuer"), permitindo que o Consul emita certificados por meio do Cyberark WIM.
  • servidor: (somente Enterprise) adiciona identidade de cluster estável e sincronização de registro global controlada por líder para publicação de resumo de serviço.
  • telemetria: (Somente Empresarial) Telemetria de produto para Consul autogerenciado com relatórios de uso anônimos e opcionais.
  • mesh: (Somente Enterprise) Introduzir suporte para serviços multiportas (porta nomeada) no Consul, incluindo a capacidade de especificar e rotear tráfego usando nomes de porta, bem como recuperar IPs virtuais para portas de serviço específicas. Ele também impõe que certos recursos avançados de múltiplas portas estejam disponíveis apenas no Consul Enterprise e inclui novas funções utilitárias para nomenclatura de cluster e geração de protocolo ALPN.

MELHORIAS:

  • agente: (Somente Empresarial) Adicione cache de segundo plano eventualmente consistente para métricas de uso Empresarial, reduzindo a latência GET /v1/operator/usage de O(PNK) para O(1) e diminuindo a pressão de CPU/memória durante scraping de alta frequência por meio de uma goroutine do mantenedor orientada por observação.
  • mesh: (Somente Enterprise) Introduzir suporte para serviços multiportas (porta nomeada) no Consul, incluindo a capacidade de especificar e rotear tráfego usando nomes de porta, bem como recuperar IPs virtuais para portas de serviço específicas. Ele também impõe que certos recursos avançados de múltiplas portas estejam disponíveis apenas no Consul Enterprise e inclui novas funções utilitárias para nomenclatura de cluster e geração de protocolo ALPN.
  • terminating-gateway: atualizado o tls upstream do cluster para usar sds em vez de certificados estáticos, permitindo atualizações dinâmicas de certificados sem a necessidade de reiniciar o gateway de terminação. [GH-23288]
  • telemetria: Adicione monitoramento de expiração de certificado com métricas Prometheus (rotuladas com datacenter/partição/namespace), registro estruturado com limites de severidade configuráveis e Connect CA API aprimorado para incluir o campo NotAfter para certificados raiz e intermediários. [GH-23147]
  • deps: Atualize github.com/hashicorp/vault/sdk de v0.7.0 para v0.25.1 e github.com/hashicorp/vault/api de v1.12.2 para v1.16.0. [GH-23574]
  • test-integ: atualize testcontainers-go (v0.22.0->v0.40.0) e docker/docker (v24.0.5->v28.5.1) no módulo de teste de integração. Isso remove opencontainers/runc como uma dependência Go da estrutura de teste. Estas são apenas dependências de infraestrutura de teste e não têm impacto no binário cônsul ou em qualquer implantação cônsul. [GH-23573]
  • xds: adicione os campos Consecutive5xx, ConsecutiveGatewayFailure e EnforcingConsecutiveGatewayFailure ao PassiveHealthCheck, permitindo que os operadores configurem limites de detecção de valores discrepantes do Envoy para respostas 5xx e falhas de gateway (502/503/504) em padrões de upstreams.

CORREÇÕES DE ERROS:

  • registro de auditoria: (somente empresa) Corrigido o erro de desempacotamento JSON quando a matriz de obj é passada para o corpo auditReq.
  • cli: Mensagens de erro aprimoradas no comando consul config write para fornecer orientação acionável quando as entradas de configuração não podem ser modificadas devido a referências de gateways ou roteadores. [GH-22921]
  • xds: Corrigido o pacote XDS para gerar endpoints corretos e configurações de cluster para gateways API quando peered, e atualizou o manipulador de atualização do gateway API para propagar a configuração do gateway de malha para seus upstreams. [GH-23454]
  • XDS: corrige o problema com o gateway de malha no modo remoto no AWS EKS, pois os nomes de host DNS são atribuídos aos NLBs da AWS em vez de IPs e a validação do endpoint EDS do enviado espera que o endereço seja um IP. Agora a atribuição de carga EDS é ignorada para destinos de gateway de malha remota não peer com gateways baseados em nome de host mantendo CDS/EDS sincronizados. [GH-23543]
  • Gateway api: resolve subconjuntos de serviço para rotas durante a síntese da cadeia de descoberta do gateway API. [GH-23294]
  • ui: Corrija links de documentação quebrados [GH-23578]
