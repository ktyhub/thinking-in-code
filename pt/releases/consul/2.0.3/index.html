#cônsul v2.0.3

2.0.3 (7 de agosto de 2026)

SEGURANÇA:

  • Atualize brace-expansion para endereçar GHSA-rgw5-rvv9-x895 (DoS por meio de matrizes intermediárias ilimitadas). [GH-23786]
  • Atualize fast-uri para endereçar GHSA-7p8r-x3mc-p8w7 (Host Confusion via introdutor de autoridade de barra invertida). [GH-23786]
  • Atualize golang.org/x/text para v0.39.0 para endereço GO-2026-5970. [GH-23761]
  • Atualize google.golang.org/grpc para v1.82.1 para endereçar GHSA-hrxh-6v49-42gf. [GH-23761]
  • Atualize socket.io-parser para o endereço CVE-2026-69185 (Esgotamento de memória com anexo zero). [GH-23786]
  • Atualize para usar o Go 1.26.5. Isso resolve vulnerabilidades GO-2026-4970 (os). GO-2026-5856 (crypto/tls). [GH-23761]
  • agente: corrigida uma vulnerabilidade de negação de serviço onde GET /v1/agent/connect/ca/roots e POST /v1/agent/connect/authorize usaram o cache do agente incondicionalmente, mesmo quando http_config { use_cache = false } foi configurado pelo operador. Um chamador remoto poderia ignorar essa configuração e aumentar o cache do agente sem limites, variando a solicitação Token ACL. Ambos os endpoints agora ignoram o cache e emitem um RPC direto quando use_cache é desativado. (SECVULN-50292, SECVULN-50293) [GH-23797]
  • agente: Corrigido um pânico de desreferência de ponteiro nulo em ShadowServiceRouterConfigEntry.CheckEnt quando uma entrada de configuração do roteador de serviço continha uma rota com Destination nulo. Um elaborado mensagem de restauração ou replicação de instantâneo contendo tal entrada pode travar o FSM caminho de decodificação. A guarda nula agora trata um destino ausente como dados não empresariais e continua decodificando com segurança. (SECVULN-50291) [GH-23797]
  • agente: Corrigido um desvio de segurança onde um ouvinte público fornecido pelo usuário (envoy_public_listener_json) com um filtro HTTP Connection Manager ignoraria o Consul padrões de normalização de solicitação de entrada. Um invasor pode explorar o caminho não normalizado para ignorar as regras deny de intenção L7 usando equivalentes de caminho codificados por porcentagem. Cônsul agora injeta normalização de caminho (habilitada por padrão, a menos que a opção de configuração de malha InsecureDisablePathNormalization está definido) em cada cadeia de filtros HCM fornecida pelo usuário ouvintes públicos antes que a aplicação da intenção L7 seja aplicada. (SECVULN-50295) [GH-23797]
  • agente: corrigida uma vulnerabilidade de negação de serviço não autenticada onde PUT /v1/agent/check/update/:id, PUT /v1/agent/check/register, PUT /v1/agent/service/register e POST /v1/agent/connect/authorize decodificou corpos de solicitação JSON ilimitados antes de resolver a ACL do chamador ficha. Um chamador não autenticado pode reter vários decodificadores JSON grandes buffers simultaneamente dentro do processo Consul antes de cada solicitação ser rejeitado com HTTP 403, causando crescimento de heap controlado pelo invasor. Todos os quatro os endpoints agora limitam o corpo da solicitação em 512 KiB antes que qualquer decodificação ocorra, retornando HTTP 413 para corpos grandes. Este limite se aplica a pedaços codificação de transferência, bem como Content-Length declarado. (SECVULN-50418) [GH-23796]
  • agente: corrigida uma vulnerabilidade de negação de serviço não autenticada onde o gRPC externo e os ouvintes gRPC-TLS aceitaram um número ilimitado de conexões TCP por IP de origem antes que qualquer processamento de solicitação, verificação de ACL ou limitação de taxa possa ocorrer. Um invasor remoto poderia esgotar os descritores de arquivos do agente, goroutines e memória abrindo muitas conexões e reter o handshake gRPC ou TLS. Um novo limitador de conexão per-client-IP está agora aplicado antes que o servidor gRPC observe a conexão, controlada pelo novo Opção de configuração limits.grpc_max_conns_per_client (padrão 100). O aperto de mão gRPC o tempo limite também foi reduzido do padrão da biblioteca de 120 segundos para 20 segundos. (SECVULN-50294) [GH-23797]

MELHORIAS:

  • ui: migrar testes de aceitação yadda/Gherkin para QUnit nativo (aproveitamento, intenções/criação, componentes, configurações) [GH-23741]
  • xds: Adicione duas novas chaves ProxyDefaults.spec.config opcionais para controlar o cabeçalho de resposta server nos ouvintes HTTP do gateway API: envoy_suppress_envoy_headers (remove o cabeçalho totalmente) e envoy_server_header_name (renomeia-o para um valor personalizado). Se ambos estiverem definidos, suprimir terá precedência. [GH-13027]

CORREÇÕES DE ERROS:

  • agente: pare de registrar o token ACL bruto em logs de tipo de conteúdo em nível de depuração. [GH-23731]
  • api-gateway: corrigida uma regressão que fazia com que um gateway HTTP API rejeitasse sua configuração com um erro de "protocolos inconsistentes" (resultando em 503s intermitentes) quando o service-router de um serviço de back-end compunha uma rota para um destino em um serviço, namespace ou partição diferente durante a síntese da cadeia de descoberta. [GH-23793]
  • serf: Corrige o Flood-join da WAN para ignorar membros de destino não ativos (saindo/saindo/falhando), permitindo que servidores reingressados voltem a funcionar na associação WAN. [GH-23709]
  • xds: Adição de cabeçalhos XFCC à solicitação GPRC semelhante à solicitação HTTP para ouvinte de entrada do proxy de conexão [GH-23744]
