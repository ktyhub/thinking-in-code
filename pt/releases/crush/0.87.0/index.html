crush v0.87.0

esmagar v0.87.0

MCP OAuth, desempenho e muito mais

Feliz sexta-feira a todos! Estamos lançando alguns recursos interessantes para que você possa aproveitar o seu vibecoding de fim de semana. (Ou não, fique lá fora :sun_with_face: e volte para o Crush na segunda-feira! :smiley:). ##MCP OAuth É isso, finalmente chegou! Alguns de vocês vêm pedindo isso há muito tempo. Isso é necessário para que alguns MCPs funcionem. Quer saber como configurá-lo? Consulte esta seção no README. Agradeça a @joestump e seu agente @joestump-agent por esta contribuição. E claro, nosso favorito @taciturnaxolotl também ajudou.

Extensão MCP dos canais Claude

@joestump (e seu agente) também adicionaram uma implementação inicial para suportar a extensão MCP dos Canais Claude, o que significa que os MCPs agora podem enviar notificações para o Crush quando determinados eventos acontecem. Experimente se estiver interessado e diga-nos se funciona bem para você.

Solicitações de MCP restauradas

Os prompts do MCP foram desativados involuntariamente em uma versão anterior, mas agora foram adicionados novamente!

Aumento de desempenho LSP

Outra contribuição interessante foi feita por @TheJhyeFactor, que melhorou bastante o uso de CPU e memória no manuseio de servidores LSP em grandes repositórios! Consulte #3370 para uma explicação mais detalhada das otimizações.

Aumento de desempenho no modo Bang

@TheJhyeFactor também melhorou o desempenho do streaming de saída ao executar o comando no modo bang. Verifique #3381 para ver alguns benchmarking. ##/etc/crush/crush.json Você leu certo! Graças a @ Muttaqin86 agora você pode ter uma configuração Crush para todo o sistema no /etc/crush/crush.json. A motivação para isso foi melhorar a compatibilidade com o NixOS.

Copiloto Fixo + GPT-5.6

Todos os três modelos GPT-5.6 (Sol, Terra e Luna) agora são corrigidos ao funcionar via GitHub Copilot. Parabéns a @nghiant03 por isso! Isso foi muito, mas é muito divertido ver o quanto a comunidade está envolvida com o desenvolvedor do Crush. Continue esmagando! :tm: Charme ##Changelog
