esmagar v0.100.0

Subagentes, modo Sysadmin e prompts PGP/SSH

Este é um grande problema! O Crush agora pode executar uma equipe de subagentes, as permissões são muito mais flexíveis e agora você pode fazer autenticação GPG e SSH diretamente no Crush! Continue lendo para saber mais.

👩🏼‍🐰‍👩🏽 Subagentes

Por fim, subagentes. O Crush agora pode gerar uma pequena equipe de subagentes amigáveis ​​em segundo plano, bem como verificá-los, enviar-lhes acompanhamentos no meio da corrida, detê-los ou movê-los para um modelo diferente.

<p><img width="600" alt="image" src="https://github.com/user-attachments/assets/a8f4f437-dd9a-46bb-ab31-65a14b84c07a" /></p>

Você pode vê-los funcionar diretamente na transcrição, na barra lateral e no cabeçalho. Cada subagente também recebe seu próprio nome, para que você sempre saiba quem está fazendo o quê. E, se você se referir a eles pelo nome, o Crush saberá de qual deles você está falando!

🚨 Modo Sysadmin

Você já desejou que Crush pudesse DROP SCHEMA public CASCADE;? Agora pode, com o modo Sysadmin! Na verdade, no modo Sysadmin, o Crush pode executar qualquer comando no seu sistema. Tome cuidado.

<p><img width="600" alt="image" src="https://github.com/user-attachments/assets/c8ccbd1b-aba2-48cc-bef7-b15045b41241" /><p>

Encontre o modo Sysadmin na paleta de comandos (<kbd>ctrl+p</kbd>) ou alterne entre todos os modos com <kbd>shift+tab</kbd>.

🙅🏻‍♀️ Comandos Seguros

Claro, o Modo Yolo ainda bloqueia comandos perigosos, mas agora você decide quais comandos são perigosos.

  • permissions safe marca comandos seguros para yolo
  • permissions block bloqueia comandos completamente
  • permissions unblock desbloqueia comandos restritos
# Building is fine
permissions safe "go build" "cargo check"

# Don't touch my infra please
permissions block kubectl terraform

# Curl your heart out
permissions unblock curl

🗝️ PGP e SSH

É tão chato quando você está usando um agente de IA e não consegue inserir uma senha SSH, ativar seu Yubikey e inserir senhas GPG, hein? Bem, com o Crush, esse aborrecimento é coisa do passado.

<detalhes> <summary>Verificando os artefatos</summary>

Primeiro, baixe os arquivos arquivo checksums.txt e arquivo checksums.txt.sigstore.json, por exemplo, com wget:

wget 'https://github.com/charmbracelet/crush/releases/download/v0.100.0/checksums.txt'
wget 'https://github.com/charmbracelet/crush/releases/download/v0.100.0/checksums.txt.sigstore.json'

Em seguida, verifique usando cosign:

cosign verify-blob \
  --certificate-identity-regexp '^https://github.com/charmbracelet/crush/\.github/workflows/(release|nightly)\.yml@' \
  --certificate-oidc-issuer 'https://token.actions.githubusercontent.com' \
  --bundle 'checksums.txt.sigstore.json' \
  ./checksums.txt

Se a saída for Verified OK, você poderá usá-la com segurança para verificar as somas de verificação de outros artefatos baixados da versão usando sha256sum:

sha256sum --ignore-missing -c checksums.txt

Pronto! Seus artefatos agora foram verificados!
