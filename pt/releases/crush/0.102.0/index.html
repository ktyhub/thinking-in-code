Solicitações de sua própria bebida

Por fim, você pode substituir os prompts do sistema por… o que quiser. E não apenas o agente principal, mas também solicitações de subagentes, planejamento, compactação, títulos de sessão e crush init:

option prompt coder ~/.config/crush/prompts/coder.md.tpl
option prompt summary prompts/summary.md

Você pode definir o prompt na configuração global, substituir por projeto na configuração local ou substituir o prompt por --prompt name=path. Para obter mais informações sobre prompts, consulte os documentos.

Cavalgando à noite

Crush agora vem com um tema KITT inspirado em Knight Rider, cortesia de @cdancy. Rosé Pine Classic, Moon e Dawn também estão disponíveis.

<p><img width="730" height="528" alt="image" src="https://github.com/user-attachments/assets/2c139b67-92a3-4600-9278-761c813699ed" /></p> ## Nerd com fontes Nerd Finalmente, fontes nerd! O suporte é detectado automaticamente, então eles nunca quebrarão seu terminal também! O Crush agora usa seus ícones, status LSP e Git incluídos. Observe que se você estiver executando o Crush via SSH, precisará ativar as fontes Nerd `option ui nerd-fonts true`. ```bash # Hate nerd fonts? You can turn 'em off, too. option ui nerd-fonts false ``` ## Canais [Canais](https://code.claude.com/docs/en/channels-reference) são um recurso experimental do MCP de Claude, agora disponível no Crush graças ao excelente trabalho de @joestump. Resumindo, os canais permitem que os servidores MCP enviem eventos para sua sessão conforme eles acontecem. ```bash crush --channels server:webhook --channels server:signal ``` Ou ligue um permanentemente em seu `crushrc`: ```bash # crushrc mcp add webhook \ --type http \ --url https://example.com/mcp \ --channel true ``` O Crush usa o mesmo protocolo que [Claude Channels](https://code.claude.com/docs/en/channels-reference), então os servidores de canais existentes devem funcionar™. ## Endurecimento do servidor O modo Client-server está agora mais robusto do que nunca. Agora é mais seguro e tem uma série de pequenas melhorias, correções de correção e correções de bugs, especialmente no Windows. ## E muito mais - O modo Sysadmin não é mais um <kbd>shift+tab</kbd> após o yolo. - Os prompts na fila aparecem na pílula no momento em que você os envia. - O modelo pode usar `sudo`, então você pode aprovar com Touch ID. - As recusas de conteúdo são repetidas automaticamente. - Sessões que Claude continuou rejeitando trabalhos novamente. - Os modelos Ollama que não podem chamar ferramentas não aparecem mais na lista de modelos. - Comandos que deixam processos filhos para trás não travam mais. - Os temporizadores funcionam juntos e os temporizadores da ferramenta em execução continuam até que a ferramenta responda. - A troca de temas não renderiza mais toda a conversa. - Excluir uma sessão mantém seu lugar na lista. - As mensagens reproduzidas mantêm seus espaços em branco e os cartões do plano estão alinhados corretamente.
