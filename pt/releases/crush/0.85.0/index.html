A ferramenta de perguntas

Então! O Crush agora vem com uma ferramenta de perguntas de primeira classe, útil para quando os LLMs querem questionar você. A ferramenta de perguntas vem em vários formatos, como escolha única, múltipla escolha, texto livre e sim/não. As perguntas também podem ser agrupadas para construir um formulário.
