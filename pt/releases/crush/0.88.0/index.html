esmagar v0.88.0

#.crushrc está aqui! Ei! Espero que todos tenham tido uma ótima semana. Fomos bastante produtivos no Charm e estamos lançando algumas coisas legais hoje. ##Configuração do Bash! (.crushrc) Sim, .crushrc chegou! Sua configuração existente do JSON ainda funciona, mas acabamos de começar a migrar para algo muito mais flexível! Um exemplo de por que isso é legal: se você gerencia a configuração do Crush em um repositório dotfiles, ainda pode ter substituições específicas da máquina usando source para chamar um arquivo separado que estará em seu .gitignore. Tenho certeza de que existem muitos outros casos de uso. Para ler a documentação completa sobre isso, leia este documento. Veja um recorte para ter uma ideia de como fica:

# Add Ollama.
provider add ollama --type ollama --base-url "http://localhost:11434/v1"

# Register a model on Ollama.
model add ollama/llama3.3 --name "Llama 3.3" --context-window 128000

# Auto-approve some tools.
permissions allow view edit

# Add an MCP server
mcp add github \
  --type http \
  --url "https://api.githubcopilot.com/mcp/" \
  --header Authorization "Bearer $GITHUB_TOKEN"

# Load some extra config
source "$XDG_CONFIG_HOME/squid-config.sh"

# Change config based on the machine you're on.
if [[ $HOSTNAME == "babysquid" ]]; then
    option skill-path "$HOME/squid-skills"
fi

@jan-xyz fez um ótimo trabalho ao dar vida a este! Ao usar o AWS Bedrock via SSO, os tokens expiram com o tempo e precisam ser atualizados. O Crush agora tem configuração e UX adequados para autenticação, e aparecerá sempre que os tokens precisarem ser atualizados. Busca de agente mais confiável

@sven2718 contribuiu com melhores tentativas nas pesquisas quando não funcionam na primeira tentativa. As pesquisas serão mais confiáveis ​​agora, especialmente quando são feitas muitas em um curto período de tempo.

Crush agora compila no IlluminOS

Na última versão, oferecemos suporte para autenticação OAuth para MCPs. @BrunoKrugel fez algumas correções para fazer com que mais MCPs que exigem OAuth funcionassem conforme o esperado.
