esmagar v0.89.0

Algumas vantagens de qualidade de vida

Estamos lançando algumas melhorias de Qualidade de Vida :tm: para você. Eles são simples, mas essas melhorias simples aumentam com o tempo para tornar o Crush cada vez melhor.

Dica para sair do Crush

Ao sair do Crush, você verá uma tela inicial com instruções sobre como continuar rapidamente a partir da sessão que você saiu. <img width="468" height="351" alt="Captura de tela 12/08/2026 às 16 41 43" src="https://github.com/user-attachments/assets/1b483466-f784-4176-9622-d3e4ca269839" />

Destaque de sintaxe da ferramenta Bash

Ao exibir o que o Crush está executando usando a ferramenta Bash, o comando shell agora terá destaque de sintaxe. É uma pequena adição, mas definitivamente melhora a legibilidade.

Moo :vaca:

<img width="862" height="561" alt="Captura de tela 12/08/2026 às 16 47 25" src="https://github.com/user-attachments/assets/9a8a4523-7a50-4b27-a63c-fb96406f8c9b" />

ctrl+end para pular para baixo + seguir

Se quiser ir rapidamente para o final do bate-papo, basta pressionar <kbd>ctrl+end</kbd>. Isso também garantirá que o Crush acompanhe o bate-papo conforme novas mensagens chegam.

Melhorias no MCP

Melhoramos as coisas para torná-lo mais estável e corrigir alguns bugs extremos. Isso é tudo por hoje. Nos vemos no próximo lançamento! Charme 💌 ##Changelog
