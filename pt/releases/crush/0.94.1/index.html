Modo não interativo: raciocínio

Os usuários do Headless Crush agora têm mais controle com um novo sinalizador --reasoning-effort no crush run. Enlouqueça e orquestre ao máximo! Se você (ou seu agente) digitar incorretamente um esforço de raciocínio, você também obterá os valores aceitos adequados.

crush run --model "hyper/glm-5.3" --reasoning-effort "max"
