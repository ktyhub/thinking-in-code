Ganchos, Passarela v3!

Um grande problema! O Crush agora roda no Catwalk v3, os ganchos podem ver todas as partes de uma corrida e os editores que hospedam o Crush recebem um conjunto totalmente novo de ferramentas para se sentirem em casa.

Ganchos, em todos os lugares 🪝

Os ganchos não são mais apenas ferramentas. Agora eles podem acompanhar toda a execução: sessões, turnos, permissões e muito mais!

Os ganchos agora também podem intervir após a execução de uma ferramenta. Edite segredos da saída antes que o modelo os veja, adicione uma nota ou interrompa a curva. Se a ferramenta já fez algo que não deveria, seu gancho poderá informar ao modelo "você confirmou sem executar os testes".

hook add TurnEnd --name "ding" --command 'afplay /System/Library/Sounds/Glass.aiff'

Você pode ler mais aqui

Client/modo servidor

Se você construir algo que execute o Crush dentro dele, esta versão é para você:

  • Temas de host: o aplicativo host pode criar um tema para a TUI no servidor API, para que o Crush corresponda aos seus aplicativos.
  • Contexto do host: o host pode informar ao Crush o que está em exibição, como arquivos abertos, e esses arquivos aparecem nas conclusões.
  • Anexar ao próximo prompt: clients pode adicionar texto que o agente lê no próximo prompt, sem iniciar uma corrida ou sobrecarregar o chat.
  • Visualização compartilhada: clients pode ver qual sessão outros clients estão visualizando.
  • Permissões canalizadas: defina CRUSH_PERMISSIONS_PIPED=1 e o host responderá aos prompts de permissão, para que você não seja solicitado duas vezes.
  • Os endereços http:// funcionam como alias para tcp:// ao iniciar o servidor.

Servidor mais estável

  • SIGHUP agora recarrega a configuração em vez de parar o servidor.
  • Fechar o terminal ou parar o Crush por meio de um gerenciador de serviços agora é encerrado normalmente, de modo que o trabalho em andamento é salvo em vez de parecer paralisado.

Pequena visão geral de Passarela v3:

Crush agora fala Passarela v3. O provedor type descreve o formato API que um provedor usa, e não quem o criou:

  • completions: APIs compatíveis com OpenAI
  • responses: OpenAI, ou qualquer coisa encaminhada através dele
  • messages: APIs compatíveis com antrópicos

Sua configuração é migrada automaticamente ao carregar, então openai, openai-compat e anthropic continuam funcionando. Não são necessárias edições.

As flags provider add e model add seguem:

crush provider add deepseek \
  --type completions \
  --base-url "https://api.deepseek.com/v1" \
  --api-key "$DEEPSEEK_API_KEY"

crush model add deepseek/deepseek-chat --thinking toggleable --max-attachments 5
  • --can-reason agora é --thinking always|never|toggleable ---max-attachments N é novo
  • Os níveis de raciocínio mostram nomes amigáveis no seletor, como "X-High"

Isso é tudo por enquanto! Charme XX 💫

Primeiro, baixe os arquivos arquivo checksums.txt e arquivo checksums.txt.sigstore.json, por exemplo, com wget:

wget 'https://github.com/charmbracelet/crush/releases/download/v0.99.0/checksums.txt'
wget 'https://github.com/charmbracelet/crush/releases/download/v0.99.0/checksums.txt.sigstore.json'

Em seguida, verifique usando cosign:

cosign verify-blob \
  --certificate-identity-regexp '^https://github.com/charmbracelet/crush/\.github/workflows/(release|nightly)\.yml@' \
  --certificate-oidc-issuer 'https://token.actions.githubusercontent.com' \
  --bundle 'checksums.txt.sigstore.json' \
  ./checksums.txt

Se a saída for Verified OK, você poderá usá-la com segurança para verificar as somas de verificação de outros artefatos baixados da versão usando sha256sum:

sha256sum --ignore-missing -c checksums.txt
