nanobot v0.1.4.post2

#nanobot v0.1.4.post2 🐈 O nanobot v0.1.4.post2 está aqui — 32 PRs mesclados, 14 novos contribuidores! A comunidade está pegando fogo 🔥 Esta versão se concentra na confiabilidade: uma pulsação completamente redesenhada, cache imediato para custos mais baixos do API, compatibilidade reforçada com provedores e dezenas de correções em nível de canal. Menos surpresas, mais estabilidade.

Destaques

  • Heartbeat Overhaul — Substituição da detecção de tokens frágeis por um mecanismo de decisão de chamada de ferramenta virtual; a pulsação agora é verdadeiramente silenciosa quando ociosa (#1102, #1054, #1039, #1036)
  • Otimização de cache de prompt — Contexto dinâmico (tempo, sessão) movido do prompt do sistema para a mensagem do usuário, permitindo acessos persistentes ao cache de prompt (#1115)
  • Confiabilidade do agente — Restrições comportamentais, histórico completo da ferramenta no contexto e dicas de erros acionáveis (#1046)
  • Slack — Sessões isoladas de thread, pós-processamento mrkdwn para artefatos de negrito/cabeçalho, tratamento de erros de soquete (#1048, #1107, #957)
  • Feishu — Extração de imagem rich-text em mensagens postadas, download de arquivo correção API (#1090, #986)
  • E-mail — Envios proativos de trabalho mesmo quando a resposta automática está desativada, remoção de desduplicação mais inteligente (#1077, #959)
  • Correções do provedor — Normalização DeepSeek reasoning_content, filtragem de bloco de conteúdo vazio, recarga a quente da chave API via @property (#947, #955, #949, #1071, #1098)
  • Segurança — Prevenção de passagem de caminho usando relative_to() em vez de startswith() (#956)
  • MCP — Tempos limite configuráveis para evitar travamentos do agente, padrões conflitantes removidos para transporte HTTP (#950, #1062)
  • Memory — Corrigido TypeError quando LLM retorna argumentos dict durante a consolidação (#1061)
  • Discord — Quebra o loop do indicador de digitação em caso de falha HTTP persistente (#1029)
  • CLI — DingTalk, QQ, Email adicionado à saída nanobot status (#982)
  • Embalagem — Modelos de espaço de trabalho movidos para nanobot/templates/ para empacotamento pip adequado (#1043)
  • Documentos — guia de implantação de serviço do usuário systemd (#968)
