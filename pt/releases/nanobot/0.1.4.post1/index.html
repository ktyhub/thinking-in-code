nanobot v0.1.4.post1

#nanobot v0.1.4.post1 🎉 Outro grande lançamento da comunidade 🐈 nanobot — obrigado a todos os colaboradores, especialmente aos nossos 19 novos! Esta versão traz grandes melhorias de canal em Feishu, Slack e Discord, um novo provedor, cache de prompt e uma refatoração significativa de loop de agente. Código mais confiável, mais capaz e mais enxuto 😄.

Destaques

  • Feishu Media — O bot agora pode enviar e receber imagens, áudio e arquivos (#844, #922)
  • Slack Media Upload — Envie arquivos diretamente do agente (#904)
  • Discord Long Messages — Divide automaticamente mensagens com mais de 2.000 caracteres (#900)
  • VolcEngine Provider — Suporte ao novo provedor LLM (#812)
  • Cache de Prompt — Suporte cache_control Anthropic e OpenRouter para custos mais baixos (#854, #905)
  • MCP Auth Headers — Cabeçalhos HTTP personalizados para servidores MCP autenticados (#807)
  • Melhorias no Telegram — Comportamento de resposta configurável, /help ignora ACL (#879, #824)
  • Suporte a subagentes CLI — CLI agora roteia através do barramento de mensagens, permitindo suporte completo a subagentes (#908)
  • Memória confiável — A consolidação de memória usa chamadas de ferramentas estruturadas em vez da frágil análise JSON (#866)
  • Leaner Agent Loop — Lógica de memória extraída, métodos redundantes mesclados, -31% de linhas (#930)
  • Edição de arquivo mais inteligente — edit_file agora mostra uma diferença quando old_text não corresponde (#921)
  • Correções de bugs — reconexão MCP, persistência de chave de sessão, respostas duplicadas, execução cron e muito mais (#892, #902, #832, #821, #823, ...)
