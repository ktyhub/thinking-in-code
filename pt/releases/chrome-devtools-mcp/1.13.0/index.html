1.13.0 (11/11/2026)

🎉 Recursos

  • adicionar logpoints criados no DevTools BreakpointManager (#3211) (0877ee0)
  • adicionar simulações de rede com escopo de página (#3384) (1d692d3)
  • suporta respostas simuladas de rede upstream (#3420) (c4bf342)

🛠️ Correções

  • config: aceita arquivos de configuração com uma BOM UTF-8 (#3365) (63170b1)
  • console: parar de resolver uma cadeia cyclic Error.cause após 10 causas (#3338) (172656a)
  • desativar set_logpoints quando --no-javascript-evaluation estiver definido (#3415) (11fcc59), fecha #3414
  • extensões: digamos que list_extensions lista apenas extensões descompactadas (#3433) (1383bb9)
  • ignore uma versão inválida em cache na verificação de atualização (#3392) (3a9f378)
  • entrada: validar os parâmetros press_key e submitKey no esquema Zod (#3382) (375a269)
  • rede: inicia uma lista de solicitações vazia para navegações sem solicitação (#3357) (b701776)
  • normalizar valores sem erro gerados por manipuladores de ferramentas (#3068) (535a3dc)
  • desempenho: erro quando performance_stop_trace é chamado em uma página sem gravação (#2971) (#3117) (1ab630a)
  • plugin: inicie o servidor Claude Code MCP com npx --prefix (#3353) (a24334d)
  • preservar a serialização da tarefa no cancelamento da solicitação (#3079) (03fd4e8)
  • carregamentos de página de relatório que mantêm o URL (#3395) (3cc38bb)
  • salvar corpos de solicitação binária byte por byte (#3404) (e3eb901)
  • sugerir --headless quando o Chrome não consegue encontrar um servidor X (#3428) (8b0856a)
  • url: desembrulhar fonte de visualização: antes de todas as verificações do esquema em activateUrl (#3335) (7275268)
  • espere: explique a correspondência de texto sensível a espaços em branco (#3350) (81a0379)

📄 Documentação

  • adicionar configuração Pi client (#3364) (bc0d93e)
  • esclarecer opções personalizadas de inicialização e conexão do navegador (#3386) (7e10c08)
  • entrada: observe que press_key não pode gerar pop-ups nativos <select> no macOS (#3288) (8e79bd0)

⚡ Desempenho

  • memória: descarta pais assíncronos de iniciadores de solicitação no NetworkCollector (#3345) (ca6f834), fecha #3344

🏗️ Refatorar

  • reexportar apenas membros de tempo de execução Zod usados do barril de terceiros (#3439) (6b056c8)
  • reutilizar esquemas Zod e validar dimensões de viewport inteiras (#3367) (3c609da)
