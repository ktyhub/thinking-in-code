Meta Muse Glimmer

Muse Glimmer, lançado hoje, é o novo modelo multimodal da Meta, especialmente projetado para casos de uso de agentes. Destilado dos parâmetros Muse até 30B e lançado sob a licença Apache 2.0, ele pode ser implantado em configurações locais para aplicativos com reconhecimento de privacidade, como codificação, análise de documentos, assistentes pessoais, configurações do tipo Claw ou Hermes.

Muse Glimmer é um modelo denso de parâmetros 30B que consiste em:

  • Codificador estilo 2B ViT para visão (Perception Encoder)
  • Decodificador de texto de parâmetro 28B

Mudanças importantes

Os kernels agora são opcionais em vez de obrigatórios para modelos de atenção linear (Mamba, GDN, somente Conv, etc.), portanto, os usuários que dependiam da seleção automática de kernel devem habilitar explicitamente os kernels para manter o comportamento anterior.

  • 🚨 [Kernels] Refatore todos os modelos de attn lineares e fallback de kernels nativos (#47630) por @vasqu

O corte de cache API agora aceita apenas valores negativos (deslocamentos relativos) em vez de tamanhos absolutos, portanto, os usuários que chamam métodos de corte diretamente devem atualizar seu código para passar valores negativos de acordo.

  • 🚨 [cache] O recorte só pode ser feito com valores negativos (#47720) por @Cyrilvallez

T5 e sua família de modelos (MT5, LongT5, etc.) agora suportam SDPA e outros back-ends de atenção via ALL_ATTENTION_FUNCTIONS, o que significa que a implementação de atenção padrão pode mudar e os usuários que dependem do caminho anterior somente ansioso devem definir explicitamente attn_implementation="eager", se necessário.

  • 🚨 Habilite SDPA (e outros back-ends de atenção) para T5 e propague para a família T5 (#47014) por @jiqing-feng

Várias pequenas funções auxiliares privadas (por exemplo, _is_url, _build_image_tokens) foram removidas dos arquivos do processador multimodal, portanto, os usuários ou bibliotecas downstream que importaram essas funções privadas diretamente devem remover ou substituir essas referências.

  • :rotating_light: Processadores atualizam o resto (#46556) por @zucchini-nlp

Atenção

Esta versão inclui várias correções e melhorias de atenção, incluindo a correção da compactação de cache Multi-Head Latent Attention (MLA), otimização do cálculo do comprimento máximo de sequência de Atenção Flash em modelos de visão e correção de bugs na atenção flexível CTRL e pré-preenchimento SDPA com polarização de posição.
