spring-batch v6.0.4

Patch Publicado10 de jun. de 2026 Fontespring-projects/spring-batch Original em inglês

Esta página é traduzida automaticamente. O texto original em inglês é a referência.

lote de mola v6.0.4

:rocket: Melhorias

  • Otimize MongoStepExecutionDao#getLastStepExecution para filtrar e classificar no nível do banco de dados #5385
  • Desempenho em SimpleJobRepository.update(StepExecution) desde Spring Batch 6.x #5360
  • MongoJobExecutionDao.findRunningJobExecutions emite N+1 consultas MongoDB #5356

:lady_beetle: Correções de bugs

  • SkipListener genérico em ChunkOrientedStepBuilder #5412
  • ResourcelessJobRepository::getJobInstanceCount viola o contrato API #5411
  • ScopeNotActiveException com @StepScope e fragmentação local #5398
  • RecordFieldSetMapper rejeita valores nulos para tipos anuláveis após o refinamento de nulidade do jSpecify #5392
  • EmptyResultDataAccessException em getLastJobExecution quando nenhuma execução de trabalho é encontrada #5389
  • FlowStep define o status do trabalho como concluído mesmo quando há mais etapas pendentes #5381
  • Tratamento incorreto da política de salto com infraestrutura JPA #5377
  • ExitStatus#setExitException quebra contrato de imutabilidade #5366
  • O modo de varredura de pedaços não isola cada item digitalizado em sua própria transação #5361
  • ItemReader genérico em ChunkOrientedStepBuilder #5358
  • NullPointerException em JacksonJsonObjectReader.close() e GsonJsonObjectReader.close() #5281
  • MongoJobInstanceDao: getJobNames() viola contrato de interface e getJobInstances() realiza paginação na memória #5274 -appendAllowed(true) quebra o array JSON quando o gravador é aberto/gravado/fechado diversas vezes #5272
  • O sinalizador sujo ExecutionContext nunca é apagado #5249
  • SimpleStepExecutionSplitter não reinicia partições COMPLETED mesmo quando allowStartIfComplete=true #5238
  • JsonItemReaderBuilder não deve substituir recurso nulo por ByteArrayResource #5234
  • A chamada de atualização SynchronizedItemStreamReader não é threadsafe #5201
  • CompositeItemReader não redefine o iterador para execuções de trabalho subsequentes #4926

:notebook_with_decorative_cover: Documentação

  • Falta documentação sobre gerenciamento de transações em etapas multithread #5386
  • Documentação desatualizada na página de referência de escalabilidade #5355
  • Parar/reiniciar amostra README faz referência a um teste que não existe mais #5391
  • Não é possível usar JsonLineMapper com Jackson 2 #5330

:hammer: Tarefas

  • Restaurar a cobertura de teste de suporte LDIF #5236
