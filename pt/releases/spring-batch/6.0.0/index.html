spring-batch v6.0.0

Major Publicado19 de nov. de 2025 Fontespring-projects/spring-batch Original em inglês

Esta página é traduzida automaticamente. O texto original em inglês é a referência.

lote de mola v6.0.0

Spring Batch 6.0 é uma versão principal que vem com vários novos recursos, melhorias e correções de bugs. Esta versão introduz uma série de alterações significativas e descontinuações do API. Consulte o guia de migração para obter a lista completa de alterações.
