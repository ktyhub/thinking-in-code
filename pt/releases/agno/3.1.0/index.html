agno v3.1.0

Novos recursos

  • Gerenciamento/autorização de usuários (RBAC): um novo pacote agno.os.authz adiciona controle de acesso baseado em funções ao AgentOS — um armazenamento de funções, política de escopo, registro de auditoria, diretório de usuários e um roteador de administrador, com mecanismos de autorização conectáveis (um mecanismo nativo mais um mecanismo fga de granularidade fina). Os escopos e o middleware de autenticação foram estendidos para aplicá-lo.
  • Sistema de arquivos AgentOS: um novo sistema de arquivos agno.fs (DbFileSystem) com rotas /filesystem dedicadas (listar/ler/gerenciar arquivos) apoiados por uma tabela agno_fs.
  • Atualizações de configuração/autenticação do MCP: configuração atualizada do servidor MCP e tratamento de autenticação MCP integrado.
  • AIMLAPITools: novo kit de ferramentas para imagem, vídeo, fala e transcrição por meio do AI/ML API.

⚠️ Mudanças importantes

  • Rechaveamento da tabela do sistema de arquivos (agno_fs): v3.1 codifica a tabela do sistema de arquivos por (namespace, user_id, path), onde user_id é a partição do usuário ("" para a partição compartilhada/sem usuário). Uma tabela criada por uma versão anterior é recusada com SchemaOutdatedError até ser atualizada. A rechave nunca é executada automaticamente. Atualize uma vez, com a aplicação parada, usando o script do seu banco de dados (#10530): Isso afetará você somente se você usar DbFileSystem. A tabela é gerenciada por DbFileSystem (seu próprio esquema, que pode ser construído a partir de um db_url simples), portanto, deliberadamente não faz parte de MigrationManager.
python libs/agno/migrations/migrate_filesystem_postgres.py   # PostgreSQL
python libs/agno/migrations/migrate_filesystem_sqlite.py     # SQLite
  • As ferramentas padrão e de ciclo de vida do MCP agora são opcionais: MCPConfig(tools=[...]) agora publica exatamente as ferramentas que você lista - tanto default_tools quanto lifecycle_tools são padronizados como False. Anteriormente, uma configuração tools=[...] também atendia às ferramentas padrão integradas (e ao ciclo de vida continue_run / cancel_run).

Correções de bugs

  • HITL: continuar uma execução pausada com background + stream não duplica mais a execução pausada em seu próprio histórico.
  • OpenAIResponses: recupera solicitações quando a resposta encadeada (anterior) desaparece.
  • DB: uma exclusão assíncrona que com falha não é mais relatada como uma execução que não estava lá — os dois casos são distintos.
  • Saída estruturada: não trava quando um fragmento JSON fornece um escalar antes de uma lista.
  • Resultados da ferramenta Python: distinguir resultados avaliados de None de variáveis ​​ausentes.
  • Chunking: rejeita uma sobreposição que não seja menor que o tamanho do bloco.
  • Leitores CSV: lidam com finais de registros CR (\r).
  • CsvTools: respeita limites explícitos de zero linhas.
  • Ferramentas de comando do shell/espaço de trabalho: respeitam um zero explícito tail.
  • GeminiTools: armazena bytes de vídeo brutos no artefato generate_video .
  • GithubTools: cria links de ramificação a partir da URL da web do repositório (#10509); get_file_content preserva texto válido não ASCII UTF-8
  • LocalFileSystemTools: lê e grava arquivos locais como UTF-8.
  • PubMed: preserva metadados para resumos curtos.
  • Citações de Claude: preserva títulos de documentos anuláveis.
