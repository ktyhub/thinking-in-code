#agno v3.0.10 #Changelog

Novos recursos:

  • Respostas do Azure OpenAI: AzureOpenAIResponses adicionado para usar as respostas API com implantações do Azure OpenAI. Consulte livro de receitas.
  • Elasticsearch: Adicionado banco de dados vetorial Elasticsearch com pesquisa vetorial, por palavra-chave e híbrida. Consulte livro de receitas.
  • DocumentationMarkdown: Adicionado um transform para Knowledge.sync_pages que converte componentes Mintlify e Fumadocs em Markdown simples. Consulte livro de receitas.

Melhorias:

  • MCPConfig: Adicionados root_host, path e path_aliases para servir o MCP em um nome de host dedicado ou um caminho de endpoint personalizado.
  • Placa de servidor MCP: /mcp/server-card agora retorna JSON bem impresso.

Correções de bugs:

  • Ferramentas MCP: preserva os resultados do AudioContent da ferramenta MCP como artefatos de áudio.
  • Slack: desduplica novas tentativas de eventos por event_id em vez de descartá-las.
  • Agentes Remotos: RemoteAgent.role e RemoteTeam.role agora são propriedades que retornam a função em vez de um método vinculado; use .role, não .role().
  • Leitores: TextReader, MarkdownReader e FieldLabeledCSVReader agora aceitam fluxos de texto.
  • PPTXReader: Leia texto dentro de formas agrupadas.
  • JSONReader: async_read() agora usa o achunk() assíncrono da estratégia de chunking.
  • Chunking: preserva novas linhas e tabulações ao limpar o texto antes de fragmentar.
  • CSVReader: async_read() mantém todas as linhas de dados nas páginas com RowChunking(skip_header=True).
  • SitemapReader: mantenha nomes de arquivos como myindex.html intactos e continue a descoberta após um mapa do site .xml.gz inválido.
  • Ferramentas e fluxos de trabalho: mantenha valores falsos como 0, False e [] nos resultados da ferramenta de sincronização e nas saídas das etapas do fluxo de trabalho Parallel.
  • agnoctl: agno connect agora lê e grava configurações de client como UTF-8 (agnoctl 0.2.1).
  • DynamoDB: serializar booleanos como valores nativos BOOL.

Alterações importantes:

  • CodingTools: run_shell agora é opcional (enable_run_shell=True) e o modo restrito executa comandos sem shell.
  • PublicSurface: Com authorization=True e PublicSurface(mcp=True), o MCP agora aceita apenas localhost por padrão; adicione seu domínio ao MCPConfig(allowed_hosts=[...]).
