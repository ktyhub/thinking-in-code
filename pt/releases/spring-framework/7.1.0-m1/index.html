estrutura de mola v7.1.0-M1

##: aviso: atenção necessária

  • começando em Spring Framework 7.1, ForwardedHeaderFilter (Spring MVC) e ForwardedHeaderTransformer (WebFlux) exigem, cada um, um argumento booleano para usar o cabeçalho "Encaminhado" padrão ou os cabeçalhos alternativos "X-Forwarded". Uma propriedade separada permite o uso de "X-Forwarded-Prefix", se necessário. O construtor padrão com o comportamento existente de verificação de ambos os tipos de cabeçalhos ainda está disponível, mas está obsoleto e marcado para remoção. O novo construtor torna o processamento do cabeçalho encaminhado mais determinístico e alinhado com o que é esperado do proxy. Consulte a seção atualizada Considerações de segurança, bem como as alterações relacionadas em Spring Boot https://github.com/spring-projects/spring-boot/issues/51030. #37072
  • A configuração de contexto padrão não é detectada quando a superclasse ou classe envolvente não é anotada com @ContextConfiguration #31456
