estrutura de mola v7.0.9

##: aviso: atenção necessária

  • Em Spring Framework 7.0.9, ForwardedHeaderFilter (Spring MVC) e ForwardedHeaderTransformer (WebFlux) fornecem, cada um, um argumento de construtor booleano para usar o cabeçalho "Encaminhado" padrão ou os cabeçalhos alternativos "X-Forwarded". Uma propriedade separada ativa e desativa o uso de "X-Forwarded-Prefix". Embora o construtor padrão preserve o comportamento existente, recomendamos usar o novo construtor para especificar explicitamente quais cabeçalhos encaminhados usar para tornar o processamento mais determinístico e alinhado com o que é esperado do proxy. Consulte a seção atualizada Considerações de segurança para obter detalhes. No 7.1 com #37072 o construtor padrão está obsoleto e marcado para remoção. #37090
  • No Spring Framework 7.0.9, SimpleEvaluationContext não suporta mais compilação de expressões por padrão, independente do modo do compilador configurado via SpelParserConfiguration ou propriedade de sistema spring.expression.compiler.mode ou propriedade Spring. Os aplicativos que usam intencionalmente SimpleEvaluationContext com expressões trusted e exigem compilação por motivos de desempenho podem optar por participar chamando withCompilationSupported() no construtor SimpleEvaluationContext. Deve-se ter cuidado ao optar pela compilação, pois isso remove as proteções de segurança aplicadas durante a avaliação interpretada. #37035
