copiloto-cli v1.0.100

19/10/2026

  • Adicione o sinalizador --disable-client-telemetry para desligar os uploads de telemetria client do CLI
  • Adicionar --trust-folder para sessões únicas de modo prompt iniciadas com -p ou piped stdin
  • Instale habilidades e plug-ins verificados dos links de instalação do GitHub por meio da instalação do plug-in copilot "ghapp://air/install?..."
  • Abra/compartilhe sem argumentos para visualizar um menu de ação em tela inteira para compartilhar a sessão atual
  • O tráfego de regras de host do sandbox agora respeita HTTPS_PROXY e HTTP_PROXY quando nenhum proxy sandbox está configurado
  • O ditado de voz não insere mais marcadores de idioma como <en-US> no texto transcrito
  • Ativação de atualização de plug-ins gerenciados em sessões existentes quando a política gerenciada muda
  • As sessões não param mais por minutos quando um servidor MCP trava durante o carregamento de ferramentas.
  • As chamadas da ferramenta Gemini não falham mais quando os parâmetros da matriz definem valores enum
  • Os bate-papos do Gemini não falham mais depois que os resultados anteriores da ferramenta não contêm conteúdo legível.
  • Os comandos shell em sandbox agora explicam as falhas do certificado de proxy de credencial trust e podem oferecer uma nova execução aprovada fora da sandbox.
  • Manter comentários de revisão salvos/diff ao reabrir um diff inalterado na mesma sessão, com uma ação explícita de descarte.
  • Ações de ativação, desativação, atualização e desinstalação de plug-ins agora são roteadas de forma confiável após a atualização do inventário de plug-ins.
  • As respostas de token máximo somente de raciocínio não ficam mais em loop indefinidamente e agora terminam com um erro claro quando nenhum progresso é feito
  • Mostre um aviso claro e mantenha a exibição do modelo ativo sincronizada quando um modelo salvo for automaticamente substituído ao retomar.
  • Comandos em sandbox no Linux iniciam de forma mais confiável, sem falhas intermitentes de configuração de loopback
  • Os detalhes do recurso Back from MCP permanecem na lista durante as atualizações de metadados em tempo real
  • Os bate-papos nativos podem começar e terminar enquanto os downloads opcionais de plug-ins gerenciados continuam em segundo plano.
  • Duplo Ctrl+C sai imediatamente mesmo quando a UI do CLI está ocupada
  • A pesquisa de catálogo relata requisitos de autenticação de proxy para desafios de proxy CONNECT
  • HydraFusion mantém um passe expandido enquanto sua revisão é executada, passes que não foram mantidos permanecem expansíveis até você trocar de sessão ou retomar, e passes de um turno abortado informam se foram mantidos
  • A política de conta gerenciada e os avisos de modo de desvio permanecem precisos após a troca de contas, mesmo quando ocorre uma falha no cache da política.
  • Evite o falso esgotamento do contexto e a recusa de rollover quando as definições da ferramenta são adiadas
  • Agentes personalizados que declaram os aliases de ferramenta search, web ou todo documentados, ou nomeiam github-mcp-server/web_search, agora recebem as ferramentas correspondentes
  • A ajuda do CLI e os sinalizadores de versão saem de forma confiável após a impressão de sua saída
  • As permissões de solicitação gerenciadas pela empresa no modo Assistido agora permitem ações seguras sem solicitações de confirmação desnecessárias.
  • Mantenha sua conta Microsoft Entra selecionada fixada durante o login e a renovação do token
  • Das sessões, as ações do cabeçalho da barra lateral passam para a última sessão visível
  • Os emblemas de plano, piloto automático e modo shell permanecem visíveis enquanto os componentes de inicialização são carregados e o agente funciona. O emblema substitui o sufixo de modo usado para rastrear o texto da atividade (Working - plan), e a linha Loading: de inicialização agora trunca seu diagnóstico para manter a linha de status em uma linha
  • Comandos em sandbox podem gravar pacotes e criar caches quando o acesso à ferramenta do desenvolvedor está habilitado.
  • Os comandos Git do Windows CLI agora se recuperam de falhas de inicialização com acesso negado ao thread.
  • Uma regra de habilidade allowed-tools mantém vírgulas dentro de seus argumentos em vez de serem separadas. Onde a estrutura de uma lista é ambígua, suas regras sem escopo agora são solicitadas em vez de concedidas.
  • O painel de recursos do MCP permanece interativo enquanto os adaptadores de inventário são atualizados
  • Tentar novamente solicitações de respostas com imagens com limites de carga útil menores quando os provedores rejeitam corpos grandes
  • O relatório de uso completo não mostra mais status parcial ou gastos fantasmas não atribuídos após a retomada quando os dados de faturamento são concluídos.
  • As permissões assistidas enviam comandos aninhados do PowerShell e bash -c que expandem apenas variáveis de ambiente de dados simples, PowerShell entre aspas simples e variáveis do PowerShell e declarações de alias ao juiz de permissão, em vez de exigir aprovação manual desnecessária
  • Arquivos de instruções específicos do caminho na raiz do repositório .github/instructions agora são aplicados automaticamente quando o agente lê ou edita um arquivo correspondente
  • Inicie comandos git, shell e servidores MCP no Windows quando a enumeração de threads de instantâneo do processo falhar
  • Use o navegador de sessões unificado por padrão para /sessions, /session e /resume.
  • A navegação na sessão agora limita a descoberta de contas em 500 registros e respeita as dicas de repetição após para tempo de atualização automática.
  • Solicitar atualização da autoridade de certificação do proxy sandbox quando os hosts mascarados forem alterados
  • Mostrar um aviso claro quando as configurações gerenciadas pelo administrador substituem o modelo selecionado
  • Habilite a pesquisa de código semântico por padrão para sessões online.
  • Melhore o /login do Microsoft Entra, permitindo que você escolha uma conta em cache ou faça login explicitamente com uma conta diferente
  • O git em sandbox em github.com pode usar seu GITHUB_TOKEN configurado em credenciais.envVars
  • /sandbox pode manter o sandbox habilitado para a sessão atual sem habilitá-lo globalmente
  • Os plug-ins do repositório Trusted são instalados e atualizados automaticamente antes da execução do chat.
  • Renomeie o plug-in integrado do navegador para uso do navegador e mantenha as preferências existentes do plug-in do navegador funcionando após a atualização
  • Sandbox permite acesso à rede local por padrão para que os comandos possam alcançar serviços de host local e de rede privada.
