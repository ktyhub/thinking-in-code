MoneyPrinterTurbo v1.3.5

Inglês | 中文

<h2 id="en-v1.3.5">Destaques</h2>
  • Adicionados provedores de conversão de texto em fala MiniMax e Fish Audio, endpoint regional MiniMax aprimorado e suporte à seleção de voz, vozes Gemini sincronizadas com o catálogo oficial e adicionadas visualizações automáticas de voz na WebUI.
  • Adicionado Anthropic Claude como provedor nativo de LLM.
  • Adicionadas fontes de material de texto para vídeo Shengsuan AI e WaveSpeed.
  • Adicionadas configurações de geração de WebUI reutilizáveis ​​e importação/exportação predefinida, incluindo backup e restauração de chave API opcional.
  • Adicionadas legendas sociais geradas pelo LLM para todas as plataformas de postagem cruzada suportadas, em vez de limitá-las ao YouTube.
  • Adicionada uma tradução WebUI para italiano e um README para japonês.

Segurança

  • Adicionada autenticação de chave API opcional para endpoints /api/v1 e arquivos de tarefas gerados. As instalações existentes permanecem compatíveis com versões anteriores enquanto app.api_key estiver vazio.
  • Entradas de áudio personalizadas restritas a locais permitidos para evitar a passagem do caminho.
  • Impediu que arquivos de tarefas gerados fossem acessados ​​através de links simbólicos escaping.
  • Uploads de materiais locais reforçados com validação mais rigorosa de arquivos e caminhos.
  • IDs de solicitação fornecidos pelo client higienizados antes de usá-los no processamento de tarefas.

Correções e melhorias

  • Corrigida a última linha de legenda sendo clipada para algumas combinações de texto e fonte, incluindo legendas multilinhas e texto sem descendentes.
  • Adicionado um erro de inicialização acionável quando o FFmpeg não está disponível.
  • Corrigidas novas tentativas de instalação da dependência Docker para que falhas persistentes de pacote interrompam a construção em vez de serem ignoradas silenciosamente.
  • Estado da tarefa revertido quando o agendamento em segundo plano falha, evitando que as tarefas permaneçam presas em um estado incorreto.
  • Esquemas de resposta API aprimorados e configuração de modelo migrado para Pydantic v2 ConfigDict.
  • Registrado o roteador de verificação de integridade do ping.
  • Limites de parágrafo preservados em respostas LLM normalizadas.
  • Distinguiu as plataformas Kimi API suportadas na configuração e na WebUI.
  • Tratamento de arquivos de configuração contendo marcadores BOM UTF-8 repetidos.
  • Melhor descoberta de voz MiniMax e áudio gerado validado antes de substituir um arquivo de saída existente.

Notas de atualização

  • Nenhuma autenticação é necessária por padrão. Para proteger o V1 API e os arquivos de tarefas gerados, configure app.api_key em config.toml e envie o mesmo valor no cabeçalho da solicitação x-api-key.
  • As exportações predefinidas de configurações podem conter credenciais do provedor quando o backup da chave API está habilitado. Armazene arquivos predefinidos exportados com segurança e não os submeta ao controle de origem.
  • Fish Audio, MiniMax, Anthropic Claude, WaveSpeed ​​e Shengsuan AI exigem suas respectivas credenciais de provedor antes de poderem ser usados.
