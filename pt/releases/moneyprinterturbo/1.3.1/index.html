MoneyPrinterTurbo v1.3.1

Destaques

  • Adicionados novos provedores e integrações LLM, incluindo AIML API, EvoLink e VolcEngine Ark.
  • Adicionadas novas opções de TTS, incluindo ElevenLabs e Chatterbox TTS compatível com OpenAI auto-hospedado.
  • Adicionada integração opcional de IA de vídeo TwelveLabs para compreensão e reclassificação mais inteligentes do material.
  • Adicionado suporte para publicação de Shorts do YouTube por meio de Upload-Post.
  • Adicionado um fluxo de trabalho CLI puro e exposto mais parâmetros de vídeo baseados em WebUI para geração de linha de comando.
  • Adicionada publicação de imagens GHCR Docker para facilitar a implantação de contêineres.
  • Suporte WebUI multilíngue aprimorado, incluindo atualizações em indonésio e espanhol, além de suporte explícito à geração de script es-ES.

Correções e melhorias

  • Corrigido o fundo da legenda clipping e melhor confiabilidade de renderização de legenda.
  • Corrigida a geração de legendas de áudio personalizadas ao usar o Whisper.
  • Correção do tratamento temporário de áudio do Windows MoviePy para evitar interferência do Windows Defender.
  • Correção do prompt de primeira execução do Streamlit bloqueando a inicialização do WebUI.
  • Corrigida a troca de caixa de seleção do provedor LLM que às vezes exigia a seleção duas vezes.
  • Corrigido o tratamento da margem de segurança da duração do vídeo.
  • Corrigida a compatibilidade de erros de digitação do video_contact_mode usando corretamente o video_concat_mode.
  • Corrigido o endpoint API padrão de polinizações.
  • Análise JSON robusta aprimorada para respostas LLM cercadas ou multilinhas.
  • Exposto match_materials_to_script nos termos API.
  • Melhor correspondência de materiais para seguir melhor a ordem do script.
  • Validação de argumento CLI reforçada para fluxos de trabalho de material de vídeo local.
  • Saída de erro LLM redigida para evitar vazamento de detalhes confidenciais.
  • Agradecimentos atualizados do patrocinador e cópia do fornecedor.
