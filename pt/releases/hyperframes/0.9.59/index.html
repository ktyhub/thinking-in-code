hiperframes v0.9.59

#HiperFrames v0.9.59

Lançado em 16/11/2026.

O player de visualização recebe um botão de tela cheia e uma falha na renderização agora diz o porquê. Renders, Studio e CLI mantêm os próprios arquivos do projeto e os hosts de mídia pública.

Recursos

  • CLI: Diff --hide pontua a camada de um projeto pelo que ela adiciona (e6d5c699b, #7972).
  • Player: Adicione um botão de tela cheia ao player de visualização (5be6c1580, #7726).
  • Core: As respostas Descrever carregam o rótulo do elemento do seletor e o estúdio exporta standInHandle (51ae92510, #7936).

Correções

  • Arquivos ocultos e de credenciais ficam fora do Studio, histórico e lint (c68c78445, #7979).
  • Principal: Uma página marcada para outro site oferece apenas reprodução a esse site (c4d607c7f, #7980).
  • Studio Server: Nenhuma rota de gravação toca em arquivos executados por outras ferramentas ou trust (2a28e4368, #7964).
  • CLI: A verificação de atualização de habilidades nunca lê a configuração git de um projeto (e368db138, #7975).
  • Lint: Execute o Studio e o produtor lint no próprio thread do host (778a00564, #7974).
  • Produtor: Teste padrões de mídia de subcomposição (95e4e7f88, #7550).
  • CLI: Validação e quadros-chave imprimem o texto do projeto com caracteres de controle como escapes visíveis (ce8d55d30, #7958).
  • Verificação: Uma fonte de mídia que falhou ao carregar não é relatada como um tempo limite (5e0c3db12, #7954).
  • CLI: A ajuda mostra o padrão de cada opção uma vez (d7f8d77fb, #7953).
  • CLI: Render --json fornece a cada ferramenta ausente, um slot retido e um Node antigo seu próprio código (47d007e5b, #7842).
  • Sdk Playground: A configuração do Vite é carregada no nó 22 antes de 22.18 (c7876f333, #7805).
  • Verificar: Marque uma descoberta de contraste por sua gravidade e cite seu texto (ec5a4e2a1, #7752).
  • Player: A correção para o congelamento da visualização quando muitos clips compartilham uma gravação longa foi retirada desta versão, porque impediu que um aplicativo que incorporava a visualização mostrasse uma edição (42508c1ef, #7795; revertido por 33e1a36a3, #7978).
  • O instantâneo ignora arquivos privados, sem desmultiplicadores de arte de texto, texto de aviso de escape (8959deb00, #7943).
  • CLI: O Capture nomeia a porta do servidor de página local na entrada de bypass (a9b0371c8, #7965).
  • CLI: Uma renderização que falha diz o porquê, mesmo em uma falha ou saída silenciosa (2623ded13, #7957).
  • Estúdio: Um arquivo de áudio longo de fora do projeto nunca é decodificado para sua forma de onda (c77cd301c, #7961).
  • Publicar: Carregue apenas o que o npm lê como verificado; tags publicam apenas commits principais, próximos ou alfa (5f4637977, #7959).
  • Mecanismo: As leituras de URL de mídia alcançam apenas hosts públicos em uma rede de páginas restritas (994fbbde2, #7946).
  • Cli,engine: Fixe o host direto do servidor de páginas em uma porta explícita e na própria origem do Studio (dbc9c1826, #7945).
  • Produtor: Uma renderização aguardando uma longa mixagem de áudio diz que está processando áudio (df698a029, #7952).
  • Principal: Uma página de captura carrega um clip sem comprimento definido somente quando é devido (9e5048772, #7938).
  • Estúdio: A análise de batida nunca escolhe uma gravação maior que uma música (87955b890, #7944).
  • CLI: Próprio diretório de bloqueio do slot de renderização; recusar arquivos de cache que outras contas possam gravar (071a2da0b, #7951).
  • CLI: Nunca grave registros de projetos através de links simbólicos em .hyperframes (061ff5bbb, #7950).

Documentos e exemplos

  • Changelog: Resumo semanal 2026-11-09-2026-11-16 (af873924d, #7969).
  • Publicar: Digamos que a publicação não aguarde aprovação e apenas os administradores enviem tags de pré-lançamento (a707e4737, #7960).

Catálogo

  • CLI: Caracteres de controle de escape no texto do projeto, página e registro (6f88be394, #7913).
  • Mcp: Execute a publicação do registro MCP no ambiente mcp-registry (45ff3526c, #7966).
  • Ci: Uma execução de publicação de catálogo que superou o principal termina limpa em vez de falhar (77e675574, #7816).
