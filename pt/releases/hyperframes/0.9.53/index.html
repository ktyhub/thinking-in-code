hiperframes v0.9.53

#HiperFrames v0.9.53

Lançado em 15/11/2026.

Páginas com muitos caracteres chineses, japoneses ou coreanos agora carregam suas fontes em algumas pequenas solicitações, para que sejam renderizadas em vez de expirarem. A renderização em nuvem não recusa mais um arquivo que contém apenas nomes de páginas não utilizadas, e os uploads agora listam todos os arquivos que carregam de fora do projeto.

Recursos

  • CLI: Os uploads listam todos os arquivos que carregam de fora do projeto (e426ce4eb, #7831).

Correções

  • Produtor: As transições de shader se misturam no Node quando a página não pode compô-las (fb1a383bd, #7840).
  • CLI: O teste de corte de upload para de falhar em executores Windows ocupados (2ea78c0ab, #7843).
  • Mecanismo: Downloads restritos aplicam a regra de endereço do proxy de captura (125a9446b, #7839).
  • As visualizações do host da LAN e as páginas de reprodução recusam outros sites sem buscar metadados (2ceb682f9, #7836).
  • CLI: Benchmark mantém a regra dos arquivos recebidos; uma chave .env recebida nunca substitui um login (a7266e4c8, #7837).
  • CLI: A renderização em nuvem não recusa mais um arquivo, apenas nomes de páginas não utilizados (45cc331e5, #7812).
  • Principal: Páginas com muitos caracteres CJK buscam fontes em diversas solicitações (6a8f4b5b4, #7823).
  • CLI: O áudio de hiperframes nunca procura mídia no compartilhamento de outro computador (eaf33bc65, #7826).
  • CLI: Uploads deixam de fora scripts externos; .ts conta como vídeo apenas quando for um (04202e8a4, #7818).
  • CLI: Reproduza e apresente, verifique a visualização do Host como; a renderização local deixa de fora arquivos externos para uma composição recebida (ac0247410, #7792).
  • As rotas de mídia do Studio recusam o carregamento entre sites, CLI escapa do texto do terminal, as saídas em lote permanecem em suas pastas (c4d60c347, #7779).
  • CLI: Descubra cenas montadas dentro de modelos (a75e61f31, #7822).
  • Studio Server: Os registros de bloqueio do histórico são substituídos, nunca gravados através de links (0248ea033, #7821).
  • Produtor: Mantenha o servidor de renderização local, a menos que um token o proteja (f667111d1, #7814).
  • Engine,cli: A verificação da pasta da lista de reprodução lê HLS como o ffmpeg; snapshot também o executa (797a622be, #7810).
  • Motor,produtor: A configuração da rede de renderização parece um switch; as sondagens de serviço de renderização permanecem nas entradas verificadas (be740d021, #7807).
  • CLI: Os comandos impressos do Windows leem nomes de pastas literalmente em cada shell (a07d4cf73, #7769).
  • CLI: Registros recebidos aninhados apenas adicionam; um .env recebido nunca escolhe a conta; os nomes das fontes ficam fora dos arquivos do agente (80b09cc94, #7808).
  • As renderizações do Cloud Run alcançam apenas endereços públicos; a pasta de cache de quadros é privada para seu usuário (55b514709, #7777).
  • Deps: Atualize zod, smol-toml, aws-cdk-lib e resoluções relacionadas em bun.lock (28d4ba50f, #7741).
  • Deps: Clique em @mcp-b/global para 6.1.0 para limpar os avisos de @modelcontextprotocol/server (beeb17e85, #7742).
  • Mecanismo: Uma captura paralela com falha nomeia o trabalhador que falhou, não os pares que ela parou (db6b7478a, #7803).
  • Mecanismo: As recusas de renderização nomeiam o endereço que um host mapeado IPv6 ou NAT64 carrega (04ee926d9, #7802).
  • Produtor: Aceite solicitações do navegador somente sob loopback, IP ou nomes de host listados (03e6a1a18, #7798).
  • Analisadores: Nunca procure mídia no compartilhamento de outro computador (2de5c027f, #7797).
  • CLI: Arquivos de upload sempre deixam de fora arquivos env e registros privados (477a3aea1, #7796).
  • Mecanismo: Downloads de mídia remota vinculados por tamanho, codificação e taxa de transferência (5111cf384, #7786).
  • CLI: Inicie programas auxiliares somente a partir das pastas trusted PATH em todas as plataformas (83eae240f, #7787).

Desempenho

  • Lint: Verifica referências de URL CSS em tempo linear (bcf3d177d, #7829).
  • As verificações de url CSS, @import, @font-face, estilo e comentários são executadas em tempo linear (ded5e3eec, #7809).

Catálogo

  • CLI: Adiciona listas de arquivos do registro de uma configuração recebida como recebido (6a7b4df7c, #7820).
  • Catálogo: A verificação de carga útil trata as substituições de legenda opcionais.json como ausentes, não com falha (b7c26ff84, #7813).
  • Registro: Palavras-chave de legenda, emoji e tremor secundário funcionam para palavras fora de a-z (8dbbc1d37, #7804).
  • Documentos: Verifique os valores dos links do catálogo e mantenha-os fora dos comandos copiados (7c7ff6d89, #7783).
