hiperframes v0.9.61

#HiperFrames v0.9.61

Lançado em 17/11/2026.

Os projetos recebidos e os arquivos que eles alcançam permanecem dentro de suas próprias pastas na renderização, visualização e Studio, e uma visualização selada é recarregada em uma fração de segundo. Esta versão também traz todas as alterações listadas para 0.9.60. Essa versão nunca alcançou o npm: sua publicação foi recusada porque executou a partir da referência de mesclagem do PR de lançamento, e desde #8020 uma versão estável publica a partir do push para main que a mescla.

Recursos

  • Mecanismo: A telemetria de renderização diz por que uma página não pode reutilizar quadros estáticos (c8df284b2, #7993).
  • Studio: As animações analisadas na origem de um elemento fazem parte do API do Studio (efc91fc87, #8061).
  • Produtor: Imponha as dimensões de saída esperadas antes da captura (8a13b2caf, #7871).

Correções

  • Produtor, Analisadores: A compilação de renderização nunca procura os recursos de uma cena em outro computador (524ea46bf, #8063).
  • CLI: Recusar cópias de proxy de mídia que outro site solicita no jogo e no servidor estático (f97e28905, #8058).
  • Produtor: Os leitores verificam novamente as composições vinculadas externamente, e a recusa nomeia um passo que cada superfície pode dar (4721739ee, #8034).
  • CLI: Deixe os arquivos de fora do projeto fora dos uploads do site Lambda e Cloud Run (39347da9d, #8060).
  • CLI: Um host pode nomear projetos cujos arquivos recebidos são esperados ou todos recebidos (5ea86450a, #8025).
  • Principal: Somente as próprias páginas de visualização do Studio obtêm a porta de edição e desfazem os conjuntos apenas de atributos seguros (55291c00c, #8057).
  • Lint: Corresponde literalmente à tag de fechamento de um wrapper cronometrado (3e01f691d, #8028).
  • Estúdio: Cada arrasto é mostrado como sua própria etapa de desfazer assim que o salvamento ocorre (647bdd4d7, #8033).
  • CLI: Um início reverso recusado informa se HeyGen enviou a recusa (53080581c, #8053).
  • Produtor: Limite a expansão total da subcomposição de uma renderização (b29e40d70, #8045).
  • Inspetor: O Chrome do inspetor começa como root ou em um container (f91bbf0da, #8050).
  • Recuse caminhos de mídia que o demuxer image2 do ffmpeg leria como um padrão (fe93f9cd4, #8047).
  • CLI: Uma chave de provedor .env do projeto dá lugar à credencial da própria pessoa (14c4e4c26, #8041).
  • CLI: Escape de saída de áudio e uso de mídia, fixe arquivos de modelo (c4439890c, #8013).
  • Produtor: Mantenha as pré-verificações de mídia do estágio de sonda lineares no tamanho da página (e21f56dca, #8044).
  • Studio: A gradação de cores funciona em uma visualização selada (d7d416124, #7999).
  • Motor: Vincula a pré-verificação do host proxy pelo tempo limite do download (06b632017, #8048).
  • Motor: As inicializações de GPU, host-teiling e HDR mantêm a sandbox onde o host permite (7b27fbc84, #8038).
  • Studio Server: As leituras de cache nunca seguem um link enviado pelo projeto (70820b386, #8039).
  • Mecanismo: Verifique hosts de download com proxy; mantenha os downloads de GIF brutos privados (5fcce21a6, #8040).
  • Habilidades: Locate.mjs lê a fonte do sistema no local, não uma cópia /tmp compartilhada (5b2990fc1, #8042).
  • Studio: a edição de legendas funciona em uma visualização selada (915021265, #8002).
  • Produtor: Limite o codificador de software às folhas de captura de núcleos livres (f89f6d3d4, #8019).
  • Estúdio: O recarregamento de uma visualização selada é exibido em uma fração de segundo, não após 8 s (9daa7e876, #8015).
  • Habilidades: Execute auxiliares TTS incluídos na pasta de habilidades, não no diretório de trabalho (6115945cf, #8035).
  • Um registro de arquivos recebidos segue renomeações, movimentos e exclusões do Studio, e um registro aninhado não pode ser movido para fora do alcance (f5bb3e551, #7989).
  • Studio Server: Uma página de loopback sem metadados de busca é marcada, a menos que o aplicativo a enquadre (b6e1e8dda, #8017).
  • Studio: O comando de renderização copiado não contém nenhum texto de composição que um shell possa executar (19743ea09, #8012).
  • As renderizações do dev Studio seguem a regra do projeto recebido, e as chaves .env de um projeto recebido nunca substituem as da própria pessoa (8239fe470, #8004).
  • Produtor: As renderizações Trusted recusam composições vinculadas externamente, a menos que --include-outside-files (00d03a412, #8024).
  • Studio Server: As decodificações de áudio são limitadas, param quando ninguém espera e seu cache é limitado (5f6995fe7, #7991).
  • Studio: Um modal aberto a partir de um popover ou menu fecha primeiro em Escape (c8235f123, #7976).
  • Motor: Sonda GPU, captura HDR e sonda de teto host mantêm uma sandbox necessária (fb5f9e52c, #8018).
  • CLI: Renderizar --docker aplica a regra do projeto recebido no host (e58fb3249, #8016).
  • Estúdio: Um desfazer em uma visualização selada é exibido no local, não após uma recarga (fee03bfbe, #8009).
  • CLI: Arquivos de fora do projeto são carregados somente depois de aprovados (22b615f1a, #7995).
  • CLI: Compare e keyframes --shot servem apenas os arquivos com nomes de arquivo HTML simples (346579b6b, #8006).
  • A preparação da imagem de visualização não lê HEIC ou GIF fora do projeto, a menos que a renderização o faça (f880693cf, #8001).
  • Motor: A verificação da pasta da lista de reprodução lê dois pontos, consultas e nomes de fragmentos conforme o ffmpeg os resolve (38aaad1b2, #8014).
  • Servidor Studio: Vincule imagens estáticas e mantenha o trabalho de proxy nas próprias páginas do Studio (bffe8d598, #8007).
  • Produtor: As renderizações locais omitem scripts de fora do projeto, a menos que sejam incluídos (581a43bb6, #7998).
  • CLI: Somente a própria origem do Studio poderá enquadrar a página do Studio (02c1fb48e, #8000).
  • Produtor: Verificação de mídia de sondagem linear e renderização de composição de lixo HTML acima de 16 MB (d53b6059b, #7992).
  • Studio Server: As gravações e reivindicações do histórico seguem a regra de gravação do Studio (32fe10a8b, #7988).
  • CLI: Caixas de erro e linhas de falha de comando imprimem caracteres de controle como escapes visíveis (5979991d5, #7987).

Interno

  • Publicar: Uma versão estável precisa da aprovação do mantenedor, não de qualquer conta (4807799c4, #8062).
  • Aumente o orçamento do tamanho compactado do produtor para 936.000 bytes (909a9b183, #8054).
  • Publicar uma versão estável do push que mescla sua versão PR (5f6007ffc, #8020).
  • Publicar: uma tag de pré-lançamento é publicada apenas em uma tag dist listada como permitida (9fae4ffd8, #7963).
  • CLI: A visualização de um projeto recebido ainda converte uma foto dentro dele (0ad24ba83, #8021).
