compor v5.7.0

O que mudou

ℹ️ Atenção para usuários do Compose como uma biblioteca: Up agora executa suas fases Criar e Iniciar como um único plano em um único instantâneo de daemon, para up -d (#14290) e up interativo (#14305), como scale, assista a reconstruções e start já faz (#14291, #14296). O CLI se comporta como antes. Se você chamar api.Compose.Up do seu próprio programa:

  • Up agora valida suas opções primeiro, com as mesmas regras dos flags CLI: UpOptions.Validate() retorna um *api.IncompatibleOptionsError (errors.Is(err, api.ErrIncompatibleOptions)) para Start.Wait combinado com Start.Attach, e para um Up desanexado (sem Start.Attach) combinado com OnExit, ExitCodeFrom ou Watch. Essas combinações costumavam ser ignoradas silenciosamente (#14306).
  • Up trabalha no projeto que lhe é fornecido e ignora StartOptions.Project.
  • O daemon não é observado novamente entre as duas fases: um contêiner que sai após a construção do plano não é iniciado novamente e um contêiner removido no meio faz com que seu início falhe em vez de ser ignorado. Um erro de planejamento da fase inicial agora falha antes de qualquer contêiner ser criado.
  • Um Up em primeiro plano agora fornece ao serviço use_api_socket seu /run/secrets/docker/config.json, como up -d faz, e mostra a saída dos ganchos pre_start.
  • O menu do teclado de um up interativo não é mais construído pela biblioteca: configure NavigationMenu: true e passe uma implementação com compose.WithNavigationMenu(...), caso contrário nenhum menu será exibido e um aviso informará isso (#14324).

Outras mudanças na superfície da biblioteca nesta versão: DownOptions.Images agora é um api.ImagePruneMode (constantes não digitadas ainda são compiladas, uma variável string precisa de uma conversão) e um valor inválido é rejeitado antes que Down remova qualquer coisa (#14149); compose.ServiceHash, compose.NetworkHash e compose.VolumeHash não são mais exportados, os helpers foram movidos para um pacote interno (#14405); api.Compose agora é montado a partir de seis interfaces menores, com o mesmo método definido (#14322); PushOptions.IgnoreMissing é adicionado.
