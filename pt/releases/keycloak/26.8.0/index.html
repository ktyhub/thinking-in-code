As opções de configuração existentes funcionam da mesma maneira.</p> </div> <div class="parágrafo"> <p>Para obter mais detalhes, consulte o guia <a href="https://www.keycloak.org/server/outgoinghttp">Configurar solicitações HTTP de saída</a>.</p> </div> </div> <div class="sect3"> <h4 id="_helm_chart_operator_install_experimental">Instalação do operador Helm Chart (experimental)</h4> <div class="parágrafo"> <p>Keycloak agora lança um gráfico experimental do Helm para instalar o Operador.</p> </div> <div class="parágrafo"> <p>Para obter instruções de instalação, consulte o <a href="https://www.keycloak.org/guides#operator">Guia do Operador</a>.</p> </div> </div> </div> <div class="sect2"> <h3 id="_organizations">Organizações</h3> <div class="sect3"> <h4 id="_shared_identity_providers_across_organizations">Provedores de identidade compartilhados entre organizações</h4> <div class="parágrafo"> <p>Os provedores de identidade agora podem ser vinculados a diversas organizações, possibilitando cenários como um único provedor de identidade corporativa atendendo usuários em diferentes unidades de negócios ou subsidiárias, cada uma representada como uma organização separada.
