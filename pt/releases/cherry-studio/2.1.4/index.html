<summary>Release Notes</summary> Cherry Studio 2.1.4 – Novos modelos, conexões de dispositivos e correções de bugs ✨ Novos recursos - [Conexões de dispositivos] Conecte-se através de redes LAN acessíveis ou redes VPN configuradas externamente com suporte IPv4/IPv6, priorização automática de endereços e seleção manual por interface de rede. Ação necessária: atualize para um aplicativo móvel compatível para salvar e verificar endereços adicionais e digitalizar códigos de emparelhamento contendo mais de 16 endereços. - [Mensagens] Adicionar exportação à barra de ação de seleção múltipla: exporte mensagens selecionadas como Markdown, Word ou para Notion/Yuque/Obsidian/Joplin/Siyuan. - [Modelos] Adicionar suporte GPT-6.1 Sol para OpenAI e OpenAI Codex, incluindo configurações de preços e raciocínio. - [Modelos] Adicione Claude Sonnet 5.5 e Opus 5.5 com controles de pensamento e elegibilidade para ferramentas web nativas. - [Modelos] O provedor Claude Code agora oferece Claude Opus 5.5 (com modo rápido) e Claude Fable 5.1. - [Modelos] Adicione o MiniMax M3.1 Flash Preview com cinco níveis de esforço de raciocínio. - [ComfyUI] Adicionar provedor de imagem ComfyUI local: escolha fluxos de trabalho salvos como modelos e gere a partir da página de pinturas. - [Launchpad] Os blocos de aplicativos integrados agora usam superfícies de cartão com reconhecimento de tema. 🐛 Correções de bugs - [Agente] Corrige sessões do Agente que se tornavam inutilizáveis quando o processo anterior do Claude Code demorava para sair. - [Agente] Corrija conflitos repetidos de mensagens e títulos obsoletos em sessões remotas de agente recém-criadas. - [Agente] Corrige a mensagem de erro do ponto de verificação ao editar e reenviar — agora explica o problema claramente. - [Agente] Corrige mensagens de sessão do Agente restantes na lista após uma exclusão bem-sucedida. - [Tarefas do agente] Recuperar espaços de trabalho de pulsação não utilizados junto com agendas órfãs. - [Bate-papo] Corrigido Regeneração usando o provedor errado — agora usa a seleção do compositor. - [Bate-papo] Corrigida nova tentativa de grupo multimodelo usando o modelo padrão do assistente em vez do modelo da própria resposta. - [Bate-papo] Corrija conversas restauradas via arquivo desfazendo saltando quando aberto. - [Bate-papo] Corrija painéis de chamada de ferramentas que não usam a mesma altura de reconhecimento de janela de visualização que o painel de pensamento. - [Bate-papo] Os bate-papos de tópicos não são mais esquemas de ferramentas de navegador embutidos, reduzindo a sobrecarga de vários milhares de tokens. - [Bate-papo] Trate apenas o bloco de tags que abre uma resposta como raciocínio embutido - tags literais nas respostas não truncam mais o conteúdo. - [Conhecimento] Corrigir instalações do pacote MCP (DXT/MCPB) com caminhos diferentes apenas em maiúsculas e minúsculas ou formato Unicode. - [Conhecimento] Corrija instantâneos de URL capturados nomeados com escapes percentuais quando o caminho da página não for ASCII. - [Conhecimento] Lembre-se da última base de conhecimento usada pela caixa de diálogo salvar. - [Habilidades] Correção de instalações de skills.sh para repositórios que armazenam habilidades em .gemini/skills/, .claude/skills/ ou .agents/skills/. - [Habilidades] Corrigida importação de ZIP de habilidades com caminhos diferentes apenas em maiúsculas e minúsculas ou formato Unicode. - [Traduzir] Corrige diagramas Mermaid que não são preservados e renderizados durante a tradução. - [Visualização do arquivo] Corrigida a visualização do arquivo mostrando fragmentos de caminho como idioma para arquivos em diretórios pontilhados ou sem extensões. - [Visualização do arquivo] Corrige a visualização do PDF que não renderiza texto em chinês/CJK que usa fontes CID não incorporadas. - [Ícone de arquivo] Corrija ícones de arquivo para caminhos do Windows – os cartões de artefato agora mostram o ícone correto. - [Markdown] Correção de SVGs no bate-papo sendo renderizados com tamanhos medidos para SVGs renderizados anteriormente. - [Lista de modelos] Mantenha os nomes dos grupos numéricos na ordem dos modelos enquanto um filtro de pesquisa estiver ativo. - [Editor de rich text] A formatação aplicada na barra de ferramentas agora é salva na nota. - [Navegador] Restaure o redimensionamento ao longo de toda a altura do separador da barra lateral do navegador. - [Layout de bate-papo] Use o padrão mais estreito de 280 px para painéis de arquivos e artefatos na primeira execução. - [Diagnóstico] Correção do relatório de verificação de integridade “Nenhuma chave API configurada” para o provedor baseado em Claude Code CLI. - [Diagnóstico] Mostrar link de status, estado de processamento e histórico local para relatórios de diagnóstico. - [Assistente de seleção] Corrige blocos de código de resultado que não são agrupados em larguras estreitas. - [Assistente de seleção] Corrija a tela preta após fechar a janela de ação no macOS em tela cheia. - [Captura de tela] Corrija a captura de tela do Windows em layouts de vários monitores com DPI misto. - [Pesquisa na Web] Corrige a rotação de chaves API que nunca alcança outras chaves quando existe uma entrada duplicada. - [OpenClaw] Corrija o erro enganoso de “incompatibilidade binária” quando a investigação do esquema de configuração era apenas lenta. - [Copilot] Corrija o roteamento do modelo GitHub Copilot GPT-6 selecionando as Respostas API para a família GPT-6. - [DSH] Corrija a limpeza do diretório temporário DSH gerenciado pelo Windows e atualize para 0.2.0-rc.2. - [Agente Claude] Atualize o Agente Claude SDK para 0.3.284 com instruções preservadas no currículo. - [Criação de agente] Remover DeepSeek Harness das opções de tempo de execução do novo agente; os agentes existentes permanecem com suporte. - [Sistema de arquivos] Correção da ferramenta `ls` relatando diretório vazio em vez de erro para caminhos ausentes ou sem diretório. - [API] Correção de streaming compatível com OpenAI eliminando o campo `arguments` obrigatório para ferramentas sem parâmetros. - [Visualização HTML] Corrige o salto do texto quando a barra de rolagem aparece/desaparece no limite de tamanho do conteúdo. - [Tarefas agendadas] Mantenha as seleções de várias horas compactas e suporte expressões Cron editáveis ​​e validadas. - [Composer] Células copiadas do Excel agora são coladas como texto quando rich text está ao lado de uma imagem. - [Configurações do provedor] Esclareça que os modelos Doubao usam Volcengine Ark com URL base API compatível. - [macOS] Correção da janela principal que não reabre no primeiro Dock click após fechar com o botão vermelho. - [Provedor] Manter a posição da lista
