#difícil 1.11.4

🔒 Segurança

Dify agora requer que Node.js 24.13.0 pegue a correção upstream para o AsyncLocalStorage/async_hooks DoS CVE que pode travar aplicativos com entradas profundamente aninhadas. Todas as implantações auto-hospedadas devem atualizar o Node.js. Obrigado a @hyoban em #30945.

Relacionado: #30935.

🛠️ Correções de bugs

  • Redirecionamento após login: resolvemos os redirecionamentos de login para trazê-lo de volta ao destino pretendido sem problemas após o login. Grite para @hyoban para esta correção em #30985.

  • ID e ID da mensagem ausentes: falta o essencial? Não mais! Corrigimos o problema ausente de id e message_id, graças a @fatelei em #31008.

  • Desestruturando propriedades indefinidas: Você já se deparou com aquele erro irritante em que não é possível desestruturar name de value porque é indefinido? Isso também foi destruído, tudo graças a @fatelei em #30991.

Guia de atualização

Docker Compor implantações

  1. Faça backup de seu arquivo YAML composto por docker personalizado (opcional)

    cd docker
cp docker-compose.yaml docker-compose.yaml.$(date +%s).bak

  2. Obtenha o código mais recente da ramificação principal

    git checkout main
git pull origin main

  3. Pare o serviço. Por favor execute no diretório docker

    docker compose down

  4. Faça backup dos dados

    tar -cvf volumes-$(date +%s).tgz volumes

  5. Serviços de atualização

    docker compose up -d

Implantações de código-fonte

  1. Pare o servidor API, o Worker e o servidor front-end da Web.

  2. Obtenha o código mais recente do branch de lançamento:

    git checkout 1.11.4

  3. Atualize as dependências do Python:

    cd api
uv sync

  4. Em seguida, vamos executar o script de migração:

    uv run flask db upgrade

  5. Por fim, execute o servidor API, o Worker e o servidor Web frontend novamente.
