Melhorias de segurança

  • O sandbox local do agente agora é executado atrás de um proxy de encaminhamento Squid dedicado com regras ACL rígidas, evitando que o sandbox alcance serviços internos diretamente. Somente o endpoint /files/ no API e /agent-stub/ no agent_backend são permitidos, ambos protegidos com tokens de acesso de curta duração. Isso reduz significativamente o raio de explosão da execução de código arbitrário na sandbox do agente. (#39544)
  • A comunicação entre o Dify API e o backend do agente agora usa autenticação baseada em token via DIFY_AGENT_API_TOKEN / AGENT_BACKEND_API_TOKEN, fortalecendo o limite de serviço interno. (#39622)
  • Alteração da renderização do modelo Jinja2 para usar SandboxedEnvironment, evitando ataques de injeção de modelo em nós de código de fluxo de trabalho (#39609)
  • Vulnerabilidade de DoS dos componentes do servidor React corrigida (#39539)
  • Usou re.fullmatch no validador de e-mail para rejeitar novas linhas finais, evitando ataques de bypass (#39320)
  • Status da conta validado antes de aceitar convites para espaços de trabalho (#39438)

  • Modos de criação inicial de carregamento lento — Carregamento adiado do código modal de criação até a interação, reduzindo o pacote JavaScript inicial (#39634)

Mudanças nas variáveis de ambiente

Novas Variáveis

| Variável | Padrão | Descrição | |----------|------------|-------------| | DIFY_AGENT_API_TOKEN | dify-agent-run-token-for-dev-only | Token de portador compartilhado para API → autenticação agent_backend. Altere isso na produção. | | AGENT_BACKEND_API_TOKEN | dify-agent-run-token-for-dev-only | O mesmo token no back-end do agente. Deve corresponder a DIFY_AGENT_API_TOKEN. | | PLUGIN_MODEL_PROVIDERS_CACHE_ENABLED | true | Defina como false se os plug-ins forem instalados externamente e o cache não puder ser invalidado. |

[!IMPORTANTE] DIFY_AGENT_API_TOKEN é uma nova variável obrigatória para comunicação segura entre o Dify API e o backend do agente. O valor padrão (dify-agent-run-token-for-dev-only) é inseguro e deve ser substituído na produção. Gere um com:

python -c 'import secrets; print(secrets.token_urlsafe(32))'

Defina o mesmo valor de AGENT_BACKEND_API_TOKEN no backend do agente.

Guia de atualização

Migração de tipo de modelo

[!IMPORTANTE]

Migração única de tipo de modelo legado para atualizações auto-hospedadas

Se esta implantação foi atualizada de uma versão Dify anterior a 1.15.0 e esta migração ainda não foi aplicada, execute-a após a atualização.

Esta migração não está incluída no flask db upgrade. Sem ele, os registros do modelo legado podem fazer com que as solicitações API relacionadas ao modelo falhem com erros, impedindo que os modelos afetados sejam carregados ou usados.

Faça backup do banco de dados antes de aplicar a migração. O comando é executado no modo de teste por padrão; revise a saída antes de executá-la novamente com --apply. A migração é idempotente e pode ser executada novamente com segurança.

Docker Compor

Execute a partir do diretório docker.

# Apply after reviewing the dry-run output
docker compose exec -T api flask data-migrate legacy-model-types --apply \
  > legacy-model-types-apply.jsonl

Implantação do código-fonte

Execute a partir da raiz do repositório após concluir flask db upgrade.

# Apply after reviewing the dry-run output
uv run --project api flask data-migrate legacy-model-types --apply \
  > legacy-model-types-apply.jsonl

Depois de aplicar a migração, execute o comando de simulação novamente. Se não reportar atualizações ou exclusões de linha adicionais, reinicie os serviços relevantes e verifique se os modelos existentes podem ser carregados e invocados com sucesso.

Docker Compor (recomendado)

cd docker
docker compose down
git pull origin main
docker compose pull
docker compose up -d

As migrações de banco de dados serão executadas automaticamente na inicialização.

[!IMPORTANTE] Revise a nova variável DIFY_AGENT_API_TOKEN em .env. O valor padrão é inseguro — gere um token seguro para produção:

python -c 'import secrets; print(secrets.token_urlsafe(32))'

Código Fonte

git pull origin main
cd api
flask db upgrade
