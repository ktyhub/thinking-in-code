#difícil 1.12.0

🚀 Novos recursos: Índice resumido

Estamos apresentando o Índice de Resumo, um aprimoramento poderoso em nosso sistema de recuperação de base de conhecimento que melhora significativamente a precisão da pesquisa ao gerar resumos baseados em IA para blocos de documentos.

Antecedentes

A pesquisa vetorial tradicional depende de incorporações de blocos brutos, que podem perder nuances semânticas e contexto ao corresponder às consultas do usuário. Isso é especialmente desafiador para documentos longos ou conteúdos complexos, onde informações importantes podem estar espalhadas em vários blocos. O Summary Index aborda isso criando resumos concisos e semanticamente ricos para cada parte do documento, que são então vetorizados e usados ​​como uma camada de recuperação adicional.

Principais capacidades

  • Resumo baseado em IA: gera automaticamente resumos concisos para partes de documentos usando modelos LLM configuráveis, capturando informações semânticas essenciais em um formato compacto.
  • Suporte Multimodal: Ao usar LLMs com capacidade de visão (por exemplo, GPT-4V, Claude-3), o sistema pode gerar resumos que incorporam texto e imagens de partes de documentos, proporcionando uma compreensão mais rica do contexto.
  • Precisão de recuperação aprimorada: Os vetores de resumo servem como uma camada de recuperação adicional, melhorando a precisão das pesquisas na base de conhecimento, combinando consultas com o conteúdo original e com resumos gerados por IA.
  • Configuração flexível: Suporta prompts de resumo padrão, permitindo que você personalize o estilo de resumo para atender aos requisitos específicos do seu domínio.
  • Processamento assíncrono: a geração de resumos é executada de forma assíncrona, garantindo que a indexação de documentos permaneça rápida e sem bloqueios.
  • Edição manual de resumos: permite editar e refinar manualmente resumos gerados por IA para melhor alinhamento com o conteúdo original do bloco, garantindo que os resumos reflitam com precisão a terminologia e o contexto específicos do domínio.
  • Compatibilidade de estrutura de índice: Funciona com modos de agrupamento geral e agrupamento pai-filho, com manipulação inteligente de relacionamentos hierárquicos de documentos.
  • Integração de índice de alta qualidade: Disponível exclusivamente para conjuntos de dados que usam a técnica de indexação "high_quality", garantindo desempenho ideal para bases de conhecimento de produção.

Outras melhorias

  • Suporte multimodal do Agent App: O Agent App agora oferece suporte nativo a entradas multimodais (imagens/arquivos).
  • Pesquisa de texto completo Qdrant: Pesquisa de texto completo implementada com suporte a várias palavras-chave para o banco de dados vetorial Qdrant.
  • Aprimoramentos no fluxo de trabalho:
    • Adicionado suporte para registro e leitura de contexto em fluxos de trabalho.
    • Adicionado suporte OpenTelemetry para execuções únicas.
  • Sistema de plugins: Adicionada uma opção para excluir ou manter as chaves API ao desinstalar um plugin.
  • Visualização do modelo antes da criação: Adicionada uma visualização detalhada do modelo de aplicativo com gráficos de fluxo de trabalho ou configurações de aplicativo por tipo de aplicativo.

Guia de atualização

Docker Compor implantações

  1. Faça backup de seu arquivo YAML composto por docker personalizado (opcional)

    cd docker
cp docker-compose.yaml docker-compose.yaml.$(date +%s).bak

  2. Obtenha o código mais recente da ramificação principal

    git checkout main
git pull origin main

  3. Pare o serviço. Por favor execute no diretório docker

    docker compose down

  4. Faça backup dos dados

    tar -cvf volumes-$(date +%s).tgz volumes

  5. Serviços de atualização

    docker compose up -d
