#difícil 1.11.3

🚀 O que há de novo no v1.11.3?

Nosso lançamento mais recente, v1.11.3, traz para você uma série de correções de bugs e recursos focados no desempenho, funcionalidade e experiência do usuário. Aqui está uma olhada no que mudou:

🎬 Novos recursos

  • Melhorias nas ferramentas MCP: Adicionado suporte para embeddedResource e ferramentas MCP exibidas diretamente para acesso mais rápido por @IthacaDream e @fatelei em #30261 e #30019.
  • Operações em lote: operação de reindexação introduzida em operações em lote de documentos por @fatelei em #30275.
  • Atualizações de agentes e fluxos de trabalho: o novo AgentMaxIterationError e melhorias nas verificações do modo de aplicativo tornam os fluxos de trabalho e os agentes mais robustos por @fatelei.
  • Integração OAuth: o login do frontend agora suporta o sinalizador oauth_new_user de @zyssyz123 em #30370.
  • Extração de PDF: Extrator RAG aprimorado para suportar extração de imagens de PDFs por @yangzq50 em #30399.
  • Armazenamento e arquivo: Adicionado armazenamento de arquivo client e configurações de @hjlarry em #30422.
  • Tradução e Internacionalização: Adicionado suporte RSC inicial para traduções para um público global por @hyoban em #30596.

🛠️ Correções de bugs

  • Redis e Cache: Pipelines usados para otimizar exclusões de cache Redis, aumentando a velocidade e a confiabilidade por @fatelei em #30159.
  • Correções de UI/UX: desde a prevenção de falhas de página devido a erros de permissão até a correção do tamanho dos botões, vários problemas relacionados à UI foram resolvidos por vários colaboradores.
  • Operações de dados: erros de acesso ao conjunto de dados corrigidos e tratamento de erros aprimorado em operações em lote por @zhaobingshuang e outros.
  • Desempenho: Referências de estado de tempo de execução lançadas sob alta carga para evitar possíveis vazamentos de memória por @SherlockShemol em #30236.
  • Segurança: Corrigidos problemas de CORS e SSL que poderiam ter afetado integrações de bots e operações do Celery.
  • Internacionalização: as traduções e o conteúdo em coreano foram atualizados para precisão por @sangyun-han em #30347.

🔧 Nos bastidores

  • CI/CD e melhorias de construção: ações GitHub aprimoradas e processos de construção para melhor confiabilidade e menos tempo de inatividade por @bowenliang123 e @hyoban.
  • Otimização de código e consulta: resolveu ineficiências em consultas SQL e manipulação de dados em fluxos de trabalho e no API, melhorando a estabilidade geral.

Esta versão enfatiza a simplificação das operações de back-end, o fortalecimento da segurança e o enriquecimento da interface do usuário para uma experiência mais tranquila e produtiva. Obrigado a todos os colaboradores por refinar o Dify e impulsionar nossa plataforma! 🛠️💡

Guia de atualização

Docker Compor implantações

  1. Faça backup de seu arquivo YAML composto por docker personalizado (opcional)

    cd docker
cp docker-compose.yaml docker-compose.yaml.$(date +%s).bak

  2. Obtenha o código mais recente da ramificação principal

    git checkout main
git pull origin main

  3. Pare o serviço. Por favor execute no diretório docker

    docker compose down

  4. Faça backup dos dados

    tar -cvf volumes-$(date +%s).tgz volumes

  5. Serviços de atualização

    docker compose up -d

Implantações de código-fonte

  1. Pare o servidor API, o Worker e o servidor front-end da Web.

  2. Obtenha o código mais recente do branch de lançamento:

    git checkout 1.11.3

  3. Atualize as dependências do Python:

    cd api
uv sync

  4. Em seguida, vamos executar o script de migração:

    uv run flask db upgrade

  5. Por fim, execute o servidor API, o Worker e o servidor front-end da Web novamente.
