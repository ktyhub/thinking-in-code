qualquer coisa-llm v1.14.1

Revisão do Assistente de Reunião

Meeting Assistant é apenas um aplicativo de desktop

Reformulamos grande parte do Meeting Assistant para torná-lo menor, mais rápido e mais eficiente em todos os dispositivos e plataformas.

  • [x] Agora suporta GPUs Intel, AMD e NVIDIA para um binário 92% menor e tempos de processamento 15% mais rápidos.

    • Se você já tiver o binário da GPU NVIDIA instalado, poderá excluí-lo com segurança, se desejar. Ele ainda funcionará e é compatível com versões anteriores.

  • [x] Suporte ao Desenvolvedor API para transcrição em áudio (POST: /v1/transcription/transcribe)

  • [x] O tratamento de estouro da janela de contexto do Meeting Assistant é muito melhor agora - portanto, modelos pequenos podem resumir reuniões mais longas.

  • [x] Introdução de [Identificação básica de alto-falante] (https://docs.anythingllm.com/meeting-assistant/features#speaker-identification) para resumos 60% melhores de qualquer áudio.

  • [x] Gravações estéreo de canal duplo para reuniões agora - levando a uma identificação de alto-falante 80% melhor no modo "Full Diarization".

Melhorias

  • [x] Linux AppImage agora 91% menor em tamanho e armazena em cache downloads do mecanismo Ollama para tempos de inicialização mais rápidos.
  • [x] Correção do título do Meeting Assistant nas reuniões pós-resumo agora é atualizado automaticamente na interface do usuário
  • [x] Destaque da variável AgentFLow para que fique claro o que é ou não uma variável válida
  • [x] "Copiar link do bate-papo" na interface do usuário para reabrir rapidamente um bate-papo no desktop/aplicativo auto-hospedado por meio de deeplinking.
  • [x] Uploads de áudio e vídeo reativados via interface de bate-papo - agora usa o mecanismo Tinyscribe.
  • [x] Exportar bate-papo como (PDF, JSON, Markdown, etc) da interface do bate-papo.
  • [x] Configuração do Desktop Assistant - Capturas de tela em HD agora disponíveis para área de captura de tela.
  • [x] A função interna de aprovação de solicitação agora está disponível para habilidades personalizadas.

Correções de bugs

  • [x] Provedores DPAIS e HuggingFace removidos de AnythingLLM (sem manutenção)
  • [x] Corrigido vazamento de memória no incorporador devido ao recarregamento constante no processo do servidor
  • [x] Corrigido bug de limpeza de texto ao arrastar e soltar arquivos no chat e o texto já estava presente no prompt.
  • [x] Grandes melhorias de desempenho na interface do usuário para bate-papos de longa duração.
  • [x] Cohere SDK removido e portado para OpenAI SDK para compatibilidade.
  • [x] A área de captura do Desktop Assistant não aparece nas configurações de vários monitores do Windows.
  • [x] Retire o pensamento do nome do tópico da bifurcação ao bifurcar um bate-papo que tinha pensamentos.
  • [x] Corrigido o modo de luz do brinde sempre exibido, independentemente do tema do sistema.
  • [x] Problema de codificação do incorporador Mistral corrigido.
  • [x] Melhores mensagens de erro para API
  • [x] Omitir temperatura em Claude Bedrock para Claude 4.8
  • [x] Corrigido vazamento do emissor de eventos no processo do servidor para web-scraping e processo de resumo
