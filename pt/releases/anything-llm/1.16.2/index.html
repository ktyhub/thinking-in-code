qualquer coisa-llm v1.16.2

Novos recursos

  • [x] LLMman - OSS agora está disponível como um provedor LLM local, substituindo Docker Model Runner
  • [x] Google Vertex AI agora está disponível como provedor LLM
  • [x] Nova habilidade do agente generate-image para criar imagens de chat
  • [x] You.com agora é o provedor de pesquisa na web padrão para pesquisas mais ricas na web com Zero Data Retention
  • [x] Variáveis de fluxo de agente agora suportam argumentos opcionais
  • [x] Adicionado suporte aos idiomas hindi, búlgaro e sueco
  • [x] GenieX no Windows no ARM agora lista os modelos encontrados no diretório de modelos local e permite extrair modelos diretamente do Hugging Face na interface do usuário
  • [x] Click a tag de versão na parte superior da janela para acessar seus logs e diretório de armazenamento com mais facilidade

Melhorias

  • [x] A navegação na Web agora está habilitada por padrão para agentes
  • [x] Provedores locais agora informam o status de carregamento do modelo no chat para que você saiba por que a primeira resposta é lenta
  • [x] O tempo de execução do Ollama atingiu 0.33.3 com uma lista de modelos atualizada
  • [x] Removidas as bordas ao redor da área de conteúdo principal para um layout de área de trabalho mais limpo
  • [x] Redesenhado o layout modal do "novo recurso"
  • [x] As datas nas tabelas agora são mostradas em um formato legível por humanos
  • [x] Páginas da web raspadas agora preservam tabelas, listas ordenadas e blocos de código em vez de nivelá-los
  • [x] páginas PDF agora são unidas com novas linhas para que as palavras não se fundam além dos limites da página
  • [x] Os embeddings Mistral agora são agrupados, tornando a incorporação de documentos grandes significativamente mais rápida
  • [x] A pesquisa de documentos agora corresponde aos seus termos literalmente, em vez de como uma expressão regular
  • [x] Documentos assistidos agora limpam vetores obsoletos na sincronização
  • [x] AnySearch como provedor de pesquisa na web
  • [x] Provedor KoboldCPP revisado e modernizado para corresponder ao restante de nossos provedores
  • [x] Keenable adicionado como provedor de pesquisa na web
  • [x] Seleção de nível de serviço OpenRouter para controlar custo e prioridade de roteamento
  • [x] Edição de imagem LocalAI por meio de imagens de referência
