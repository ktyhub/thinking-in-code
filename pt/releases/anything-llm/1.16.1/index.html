Revisão da atividade e da cadeia de pensamento

<img width="3680" height="2212" alt="image" src="https://github.com/user-attachments/assets/34e52190-51e3-40b5-baeb-d1936319cb4a" />

Revisamos nossa IU para tarefas de agente de longo horizonte que mostram vários pensamentos e chamadas de ferramentas para agora serem agrupadas em um único elemento de IU limpo e recolhível.

Isso oferece mais espaço na tela para a resposta real, ao mesmo tempo que mantém a importante pilha de chamadas e os pensamentos que o modelo produz em um formato de fácil leitura.

Aviso de navegação

<img width="3680" height="2212" alt="image" src="https://github.com/user-attachments/assets/dfa98c30-4bde-4321-86cc-eb0bcd7b9873" />

Recentemente, adicionamos sinais verdadeiros de interrupção em todos os LLM suportados para que, quando você cancelar a inferência ou sair da página, interrompamos a inferência para economizar custos de computação.

No entanto, isso teve o efeito colateral não intencional de cancelar a inferência ao sair de um bate-papo, impedindo a conclusão em segundo plano. Agora avisamos antes de abortar a resposta.

Item do roteiro: Pretendemos tornar esse usuário configurável para que você possa personalizar esse comportamento e permitir inferência em segundo plano para aqueles com configurações mais poderosas ou de alta simultaneidade, onde várias sessões de inferência paralela são viáveis.

Foundry Local Embedded (somente desktop)

<img width="1280" height="720" alt="image" src="https://github.com/user-attachments/assets/d43ba423-83a8-4150-8b62-606ffb6c8882" />

FoundryLocal é um mecanismo de inferência desenvolvido pela Microsoft que está pré-instalado e disponível no Windows 11 (versão 24H2, build 26100 ou posterior).

Isso usa WinML para carregar modelos para sua CPU, GPU ou NPU em qualquer configuração de hardware do Windows. É uma ótima opção para configurações de hardware para as quais não temos suporte explícito. Tenha em mente que a disponibilidade do modelo pode ser limitada, pois o FoundryLocal ainda está sendo implementado. Os modelos Vision não estão disponíveis atualmente.

Temos parceria com a Microsoft para isso, se você tiver bugs ou problemas podemos ajudar a encaminhá-los para a equipe FoundryLocal

GenieX para Snapdragon (somente desktop)

<img width="1280" height="720" alt="image" src="https://github.com/user-attachments/assets/866a7cc2-e3e7-4189-af56-6a29c030aab5" />

[!NOTA] Isso substitui nosso mecanismo Snapdragon NPU anterior. Todos os modelos anteriores do mecanismo antigo serão excluídos na atualização e você precisará baixar novamente esses modelos otimizados. Você deverá ver um aumento significativo de desempenho para modelos NPU e GGUFs regulares.

É altamente recomendável usar apenas modelos GGUF para este motor. Os modelos somente NPU da Qualcomm têm janelas de contexto de 4K e resultarão em uma experiência ruim para o agente.

GenieX é um mecanismo de inferência de código aberto desenvolvido pela Qualcomm (anteriormente NexaAI) que executa com eficiência GGUFs e modelos Qualcomm AI Hub em NPU para dispositivos X e X2 Elite.

AnythingLLM oferece suporte totalmente gerenciado e integrado selecionando o provedor "AnythingLLM GenieX" no menu suspenso. Tanto os modelos GGUFs quanto os somente NPU podem aproveitar o NPU, proporcionando a eficiência energética e a inteligência de ambos.

Temos parceria com a Qualcomm para isso, se você tiver bugs ou problemas podemos ajudar a encaminhá-los para a equipe GenieX ou você pode resolver um problema no GitHub deles. s/o @zhiyuan8, @alexchen4ai e @alanzhuly

Novos recursos

  • [x] Native Foundry Local SDK no Windows (x64/ARM64) - o provedor Foundry agora é totalmente independente e não requer mais uma instalação separada do Foundry Local, com variantes de modelo otimizadas para GPU/NPU expostas no catálogo
  • [x] Suporte de tempo de execução GenieX para dispositivos Windows ARM64
  • [x] Suporte ao perfil de inferência entre regiões do AWS Bedrock - IDs de perfil com prefixo geográfico (us., eu., global.) agora aparecem no menu suspenso do modelo e roteiam corretamente, além de entrada manual de região para regiões fora da lista predefinida (GovCloud, partições especializadas)
  • [x] LocalAI adicionado como provedor de geração de imagens, listando apenas modelos com capacidade de imagem do seu servidor
  • [x] Detecção automática de janela de contexto LocalAI - as janelas de contexto são lidas por modelo na configuração do seu servidor, com a configuração manual agora uma substituição opcional
  • [x] Sinalizadores de instalação e desinstalação silenciosa/sem cabeça para o instalador do Windows - consulte os documentos de instalação do Windows

Melhorias

  • [x] A cadeia de pensamento e a atividade do agente agora são um único componente recolhível - uma linha quando recolhida, uma etapa por pensamento com um trilho conectado quando expandido e o pensamento ao vivo mostrado no cabeçalho durante a transmissão
  • [x] O novo acúmulo de cadeia de pensamento agora está espelhado no Painel do Assistente
  • [x] Sair de um tópico ou navegar no meio da inferência agora avisa antes que a resposta seja perdida, em vez de matar silenciosamente a geração
  • [x] O Foundry Local não solicita mais configuração ao usar o tempo de execução integrado e carrega modelos automaticamente por detecção de capacidade
  • [x] Integração do estilo do modo de luz e uma interface de seleção LLM redesenhada
  • [x] Beacon agora renderiza blocos de pensamento e formatação de markdown corretamente durante o streaming, com pensamento recolhível e uma correção para estouro de texto de detalhes do modelo
  • [x] O instalador do Windows agora inclui uma imagem do painel da barra lateral
  • [x] Os rascunhos de entrada de prompt agora persistem entre a navegação
