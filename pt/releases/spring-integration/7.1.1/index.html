integração de mola v7.1.1

:star: Novos recursos

  • Não converta mensagem errada no JmsOutboundGateway.onMessageSync() apenas para registro de depuração #11197
  • Não avisar que o servidor Redis 7 não suporta DELEX #11137

:lady_beetle: Correções de bugs

  • CVE-2026-47856: JsonToObjectTransformer resolve o cabeçalho da mensagem json__TypeId__ para uma classe arbitrária sem uma lista de permissões #11340
  • CVE-2026-47859: Alocação de memória ilimitada em RFC6587SyslogDeserializer (enquadramento contado por octetos) - DoS remoto #11338
  • CVE-2026-47862: ZipTransformer usa o cabeçalho file_name para construir o caminho workDirectory sem higienização #11334
  • CVE-2026-47864: Desserialização insegura de Java em SerializingHttpMessageConverter — execução remota de código #11332
  • CVE-2026-59324: Corrige vazamento de cabeçalho de mensagem cruzada em fluxTransform() sob simultaneidade #11329
  • CVE-2026-59321: Correção de AbstractScriptExecutor para mecanismos não thread-safe #11326
  • CVE-2026-59322: Altere o padrão EmbeddedHeadersJsonMessageMapper para nenhum cabeçalho #11323
  • CVE-2026-59311: Impede que transformadores zip gravem arquivos temporários no link simbólico #11320
  • CVE-2026-59292: Adicionar controle de permissões de arquivo de armazenamento de metadados #11317
  • CVE-2026-59307: JdbcMessageStore: novo mapper em setBeanClassLoader #11313
  • CVE-2026-59293: Defina a versão padrão do SMB para SMB202 #11310
  • CVE-2026-59274: Adicionar opções de restrição de tamanho ao UnzipTransformer #11308
  • CVE-2026-47880: Ignorar propriedades por padrão em toHeaders #11305
  • CVE-2026-47861: Adaptador UDP envia confirmação para host fornecido pelo invasor: porta analisada do corpo do pacote, mesmo quando reconhecimento=falso #11302
  • FileWritingMessageHandler: a criação automática simultânea do mesmo diretório de destino falha com "O diretório de destino [...] não pôde ser criado." #11257
  • JdbcMetadataStore putIfAbsent pode ficar preso no loop while no banco de dados MySQL. #11255
  • Correção do isolamento do teste ZookeeperLockRegistry e tratamento de interrupções #11245
  • O registro Dynamic IntegrationFlow ignora a injeção de dependência para componentes adicionais e internos #11196
  • Condição de corrida de simultaneidade no AcceptOnceFileListFilter #11185
  • KafkaMessageDrivenChannelAdapter no modo em lote não gera ID de mensagem, causando falha no divisor #11183
  • Os bloqueios Redis não são exclusivos #11180
  • Ajuste a capacidade do cache no JdbcLockRegistry #11172
  • Marcar tipo de retorno de função @Nullable para lockKey e waitLockDuration #11168
  • Bloqueios JDBC não exclusivos #11157
  • Lançar um erro genérico do AbstractWebServiceInboundGateway de volta para o client #11147
  • JdbcLockRegistry e RedisLockRegistry - ReentrantLock compartilhado de DefaultLockRegistry faz com que a entrada APP_LOCK não seja excluída no desbloqueio quando duas chaves de bloqueio diferentes são mapeadas para o mesmo bucket #11146
  • O BaseIntegrationFlowDefinition.REFERENCED_REPLY_PRODUCERS pode ser acessado simultaneamente #11127
  • Correção do deslocamento do cabeçalho de confirmação multibyte em DatagramPacketMessageMapper #11115
  • O PartitionedDispatcher.dispatch() falha com o IndexOutOfBoundsException quando o código hash é o Integer.MIN_VALUE #11114
  • Impedir a remoção de bloqueios retidos do registro ZooKeeper #11113
  • Especificar o nome do canal para componentes JMS de entrada em Java DSL causa falha na inicialização devido à falta de BeanFactory #11107
  • Correção de FileReadingMessageSource para lidar com arquivos canônicos #11103
