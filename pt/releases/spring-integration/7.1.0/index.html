integração de mola v7.1.0

:star: Novos recursos

  • Adicionar seletor de mensagens com base nos padrões de correspondência de valores de cabeçalho #11092
  • Revisar testes usando IntegrationRegistrar para registrar infra beans #11028
  • Permitir ignorar o registro pós-processador da anotação de mensagens em cenários DSL puro #11024
  • construtores poloneses em ExpressionEvaluatingMessageProcessor #11002
  • Desative allowCredentials no CrossOrigin e introduza originPatterns #10988

  • Impedir a gravação de arquivos fora do diretório de saída #11095

  • Impedir a remoção de bloqueios retidos do registro Redis #11044
  • O ControlBusCommandRegistry.controlBusCommands deve ser um ConcurrentHashMap #11042
  • Impedir a remoção de bloqueios retidos do registro JDBC #11041
  • Não propague erro do servidor para o client do GrpcInboundGateway #11040
  • ZookeeperMetadataStore.replace() quebra a lógica CAS #11013
  • Mqttv5PahoMessageHandler falha devido ao uso incorreto de MessageConverter.fromMessage #11011
  • Mqttv5PahoMessageDrivenChannelAdapter ignora payloadType devido ao uso incorreto de MessageConverter.toMessage #10990

  • Corrigido erro de digitação na seção de geração de ID de mensagem #11014
  • Aprimoramento da documentação: descreva ponto a ponto vs ESB centralizado #2886
