integração de mola v7.0.6

:star: Novos recursos

  • Não converta mensagem errada no JmsOutboundGateway.onMessageSync() apenas para registro de depuração #11212

:lady_beetle: Correções de bugs

  • CVE-2026-47856: JsonToObjectTransformer resolve o cabeçalho da mensagem json__TypeId__ para uma classe arbitrária sem uma lista de permissões #11337
  • CVE-2026-47859: Alocação de memória ilimitada em RFC6587SyslogDeserializer (enquadramento contado por octetos) - DoS remoto #11335
  • CVE-2026-47862: ZipTransformer usa o cabeçalho file_name para construir o caminho workDirectory sem higienização #11333
  • CVE-2026-47864: Desserialização insegura de Java em SerializingHttpMessageConverter — execução remota de código #11330
  • CVE-2026-59324: Corrige vazamento de cabeçalho de mensagem cruzada em fluxTransform() sob simultaneidade #11327
  • CVE-2026-59321: Correção de AbstractScriptExecutor para mecanismos não thread-safe #11325
  • CVE-2026-59322: Altere o padrão de EmbeddedHeadersJsonMessageMapper para nenhum cabeçalho #11322
  • CVE-2026-59311: Impede que transformadores zip gravem arquivos temporários no link simbólico #11319
  • CVE-2026-59292: Adicionar controle de permissões de arquivo de armazenamento de metadados #11318
  • CVE-2026-59307: JdbcMessageStore: novo mapper em setBeanClassLoader #11315
  • CVE-2026-59293: Defina a versão padrão do SMB para SMB202 #11312
  • CVE-2026-59274: Adicionar opções de restrição de tamanho ao UnzipTransformer #11309
  • CVE-2026-47880: Ignorar propriedades por padrão em toHeaders #11306
  • CVE-2026-47861: Adaptador UDP envia confirmação para host fornecido pelo invasor: porta analisada do corpo do pacote, mesmo quando reconhecimento=falso #11304
  • FileWritingMessageHandler: a criação automática simultânea do mesmo diretório de destino falha com "O diretório de destino [...] não pôde ser criado." #11258
  • JdbcMetadataStore putIfAbsent pode ficar preso no loop while no banco de dados MySQL. #11256
  • Correção do isolamento do teste ZookeeperLockRegistry e tratamento de interrupções #11246
  • O registro Dynamic IntegrationFlow ignora a injeção de dependência para componentes adicionais e internos #11216
  • Condição de corrida de simultaneidade no AcceptOnceFileListFilter #11195
  • KafkaMessageDrivenChannelAdapter no modo em lote não gera ID de mensagem, causando falha no divisor #11186
  • Os bloqueios Redis não são exclusivos #11182
  • Ajuste a capacidade do cache no JdbcLockRegistry #11173
  • Bloqueios JDBC não exclusivos #11171
  • Marcar tipo de retorno de função @Nullable para lockKey e waitLockDuration #11169
  • JdbcLockRegistry e RedisLockRegistry - ReentrantLock compartilhado de DefaultLockRegistry faz com que a entrada APP_LOCK não seja excluída no desbloqueio quando duas chaves de bloqueio diferentes são mapeadas para o mesmo bucket #11155
  • Lançar um erro genérico do AbstractWebServiceInboundGateway de volta para o client #11148
  • Impedir a remoção de bloqueios retidos do registro ZooKeeper #11135
  • O BaseIntegrationFlowDefinition.REFERENCED_REPLY_PRODUCERS pode ser acessado simultaneamente #11129
  • Especificar o nome do canal para componentes JMS de entrada em Java DSL causa falha na inicialização devido à falta de BeanFactory #11125
  • Correção do deslocamento do cabeçalho de confirmação multibyte em DatagramPacketMessageMapper #11119
  • O PartitionedDispatcher.dispatch() falha com o IndexOutOfBoundsException quando o código hash é o Integer.MIN_VALUE #11117
  • Correção de FileReadingMessageSource para lidar com arquivos canônicos #11104
