Lançamento 3.39.0 - Canguru vai BRRR

  • Implementar perfil de provedor fixo para persistência de configuração API em nível de tarefa (#8010 por @hannesrudolph, PR #10018 por @hannesrudolph)
  • Adicionar suporte para @menções de arquivo de imagem (PR #10189 por @hannesrudolph)
  • Renomeie YOLO para BRRR (#8574 por @mojomast, PR #10507 por @roomote)
  • Adicionar roteamento de proxy no modo de depuração para depuração de chamadas API (#7042 por @SleeperSmith, PR #10467 por @hannesrudolph)
  • Adicionar modelo de pensamento Kimi K2 ao provedor Fireworks AI (#9201 por @kavehsfv, PR #9202 por @roomote)
  • Adicione alto esforço de raciocínio a endpoints compatíveis com OpenAI (#10060 por @Soorma718, PR #10061 por @roomote)
  • Filtre @ mencione os resultados da pesquisa de arquivos usando .rooignore (#10169 por @jerrill-johnson-bitwerx, PR #10174 por @roomote)
  • Adicionar documentação de suporte de imagem à descrição da ferramenta nativa read_file (#10440 por @nabilfreeman, PR #10442 por @roomote)
  • Adicionar zai-glm-4.7 aos modelos Cerebras (PR #10500 por @sebastiand-cerebras)
  • Correção VSCode e CLI básico para executar Roo Code sem cabeça (PR #10452 por @cte)
  • Adicionar instalador CLI para código Roo sem cabeça (PR #10474 por @cte)
  • Adicionar opção para usar CLI para avaliações (PR #10456 por @cte)
  • Lembre-se da última seleção do modelo Roo em avaliações da web e adicione habilidades de avaliação (PR #10470 por @hannesrudolph)
  • Ajuste o estilo dos modos de sugestão de acompanhamento (PR #9260 por @mrubens)
  • Correção: lidar com erro ENOENT do PowerShell no nome do sistema operacional no Windows (#9859 por @Yang-strive, PR #9897 por @roomote)
  • Correção: torne os exemplos de encadeamento de comandos compatíveis com o shell para compatibilidade com o Windows (#10352 por @AlexNek, PR #10434 por @roomote)
  • Correção: preservar blocos tool_use para todos os tool_results em mensagens mantidas durante a condensação (PR #10471 por @daniel-lxs)
  • Correção: adição adicionalProperties: false aos esquemas da ferramenta MCP para respostas OpenAI API (PR #10472 por @daniel-lxs)
  • Correção: evita blocos duplicados de tool_result causando erros API (PR #10497 por @daniel-lxs)
  • Correção: adição de desduplicação explícita para blocos tool_result duplicados (#10465 por @nabilfreeman, PR #10466 por @roomote)
  • Correção: use a configuração API armazenada na tarefa como substituto para o limite de taxa (PR #10266 por @roomote)
  • Correção: remover modelos legados da série Claude 2 do fornecedor Bedrock (#9220 por @KevinZhao, PR #10501 por @roomote)
  • Correção: adicionar campos de descrição ausentes para configuração do debugProxy (PR #10505 por @roomote)
  • Correção: animação de salto de canguru com falha na tela de boas-vindas (PR #10035 por @objectiveSee)
