Novos métodos

Estrada

@ppetrushkov adicionou RoAd: 2D Rotary Adaptation ao PEFT em #2678. RoAd aprende matrizes de rotação 2D que são aplicadas usando apenas multiplicação elemento a elemento, prometendo assim uma inferência muito rápida com adaptadores em estado não mesclado.

Notavelmente, além do LoRA, o RoAd é o único método PEFT que suporta lotes de adaptadores mistos. Isso significa que quando você carrega um modelo com vários adaptadores RoAd, você pode usar todos eles para amostras diferentes no mesmo lote, o que é muito mais eficiente do que alternar adaptadores entre lotes:

model = PeftModel.from_pretrained(base_model, <path-to-road-adapter-A>, adapter_name="adapter-A")
model.add_adapter("adapter-B", <path-to-road-adapter-B>)

inputs = ...  # input with 3 samples
# apply adapter A to sample 0, adapter B to sample 1, and use the base model for sample 2:
adapter_names = ["adapter-A", "adapter-B", "__base__"]
output_mixed = model(**inputs, adapter_names=adapter_names)
gen_mixed = model.generate(**inputs, adapter_names=adapter_names)

ALoRA

LoRA ativado é uma técnica adicionada por @kgreenewald em #2609 para modelos de linguagem causal, permitindo ativar seletivamente adaptadores LoRA dependendo de uma sequência específica de invocação de token na entrada. Isso tem o principal benefício de poder reutilizar a maior parte do cache KV durante a inferência quando o adaptador é usado apenas para gerar parte da resposta, após o que o modelo base assume novamente.

Arrow e GenKnowSub

@TheTahaaa contribuiu não apenas com suporte para Arrow, um algoritmo de roteamento dinâmico entre vários LoRAs carregados em #2644, mas também GenKnowSub, uma técnica construída em Arrow onde a 'biblioteca' de LoRAs disponível para Arrow é primeiro modificada subtraindo adaptadores de conhecimento geral (por exemplo, treinados em subconjuntos da Wikipedia) para melhorar o desempenho específico da tarefa.

###OndaFT

Graças a @Bilican, Wavelet Fine-Tuning (WaveFT) foi adicionado ao PEFT em #2560. Este método treina atualizações esparsas no domínio wavelet de matrizes residuais, que é especialmente eficiente em termos de parâmetros. É muito interessante para geração de imagens, pois promete gerar diversos resultados preservando a fidelidade do assunto.

###DeLoRA

[Adaptação dissociada de baixa classificação] (https://arxiv.org/abs/2503.18225) (DeLoRA) foi adicionada por @mwbini em #2780. Este novo método PEFT é semelhante ao DoRA na medida em que desacopla o ângulo e a magnitude dos pesos do adaptador aprendidos. No entanto, DeLoRA implementa isso de uma forma que promete prevenir melhor as divergências. Além disso, restringe o desvio do peso aprendido impondo um limite superior da norma, que pode ser ajustado através do parâmetro delora_lambda.

###OSF

Ajuste fino ortogonal (OSF) foi adicionado por @NikhilNayak-debug em #2685. Ao congelar o subespaço de alto escalão das matrizes de peso alvo e projetar atualizações de gradiente para um subespaço de baixo escalão, o OSF alcança um bom desempenho em tarefas de aprendizagem contínua. Embora exija um pouco de memória para processos de ajuste fino padrão, definitivamente vale a pena conferir as tarefas em que a degradação do desempenho de tarefas aprendidas anteriormente é uma preocupação.

Melhorias

Referência de geração de texto

Em #2525, @ved1beta adicionou o benchmark de geração de texto ao PEFT. Esta é uma estrutura para determinar e comparar métricas em relação à geração de texto de diferentes métodos PEFT, por ex. tempo de execução e uso de memória. No momento, este benchmark ainda carece de configurações experimentais e de uma visualização, análoga ao que temos no benchmark MetaMathQA. Se isso é algo do seu interesse, encorajamos você a nos informar ou, melhor ainda, a contribuir para esse benchmark.

Interface confiável para integrações

PEFT possui integrações com outras bibliotecas como Transformers e Diffusers. Para facilitar esta integração, o PEFT agora fornece uma [interface estável de funções] (https://huggingface.co/docs/peft/package_reference/functional) que deve ser usada se aplicável. Por exemplo, a função set_adapter pode ser usada para alternar entre adaptadores PEFT no modelo, mesmo que o modelo não seja uma instância PeftModel. Nós nos comprometemos a manter essas funções compatíveis com versões anteriores, por isso é seguro para outras bibliotecas construírem sobre elas.

Manuseio de amarração de peso

Alguns modelos de Transformers podem ter pesos amarrados. Isso é especialmente prevalente quando se trata da incorporação e do cabeçote LM. Atualmente, a forma como isto é tratado no PEFT não é óbvia. Assim, elaboramos um problema para ilustrar o comportamento pretendido em #2864. Isso mostra qual é o nosso objetivo, embora nem tudo esteja implementado ainda.

Em #2803, @romitjain adicionou o argumento ensure_weight_tying a LoraConfig. Este argumento, se definido como True, impõe a vinculação de peso dos módulos direcionados a modules_to_save. Assim, se a incorporação e o cabeçote LM estiverem vinculados, eles compartilharão pesos, o que é importante para permitir, por exemplo, a fusão de pesos. Portanto, para a maioria dos usuários, recomendamos ativar esta configuração se quiserem ajustar totalmente a incorporação e o cabeçote LM. Para compatibilidade com versões anteriores, a configuração está desativada por padrão.

Observe que, de acordo com #2864, a funcionalidade do ensure_weight_tying=True será expandida para incluir também tokens treináveis ​​(#2870) e LoRA (a confirmar) no futuro.

Suporta camadas Conv1d e 1x1 Conv2 em LoHa e LoKr

@grewalsk estendeu LoHa e LoKr para suportar camadas nn.Conv1d, bem como nn.Conv2d com kernels 1x1, em #2515.

Nova inicialização de ajuste de prompt

Graças a @macmacmacmac, agora temos uma nova opção de inicialização para ajuste rápido, inicialização discreta aleatória (#2815). Esta opção geralmente deve funcionar melhor do que a inicialização aleatória, conforme corroborado em nosso [conjunto de comparação de métodos PEFT] (https://github.com/huggingface/peft/tree/main/method_comparison/text_generation_benchmark). Experimente se você usar o ajuste rápido.

Combinando adaptadores LoRA com pesos negativos

Se você usar vários adaptadores LoRA, poderá mesclá-los em um único adaptador usando model.add_weighted_adapter. Porém, até agora, isso só funcionou com pesos positivos por adaptador. Graças a @sambhavnoobcoder e @valteu, agora também é possível passar pesos negativos.

Mudanças

Compatibilidade com transformadores

No momento em que este artigo foi escrito, o lançamento do Transformers v5 era iminente. Esta versão dos Transformers será incompatível com PEFT < 0.18.0. Se você planeja usar Transformers v5 com PEFT, atualize PEFT para 0.18.0+.

Versão Python

Esta versão PEFT não suporta mais Python 3.9, que atingiu o fim de sua vida útil. Use Python 3.10+.

Atualizações para OFT

O método OFT foi atualizado para torná-lo um pouco mais rápido e estabilizar os números em #2805. Isto significa, no entanto, que os pontos de verificação existentes podem dar resultados ligeiramente diferentes após a atualização para PEFT 0.18.0. Portanto, se você usar OFT, recomendamos treinar novamente o adaptador.
