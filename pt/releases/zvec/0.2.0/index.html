#zvec v0.2.0

🚀 Zvec v0.2.0 Release Notes

Uma grande atualização focada em otimização, expansão da plataforma e melhorias na experiência do desenvolvedor.

📦 Principais recursos e melhorias

  • Suporte à estrutura de extensão de IA para fluxos de trabalho de incorporação no dispositivo (#88)
  • Metadados de segmento autoescaláveis em arquivos de armazenamento MMap (#67)
  • Interface de invocação de pesquisa unificada no núcleo (#15)
  • Suporte à compilação Linux ARM64 (#71)
  • Falha silenciosa em tentativas repetidas de inicialização (#79)

🐞 Correções de bugs

  • Correção da lógica delete_by_filter usando chave em vez de índice (#84, #87)
  • Testes unitários internos quantizados corrigidos (#47)
  • Removido parâmetro column_name desnecessário de AddColumn API (#59)
  • Corrigidos erros de digitação na implementação do índice HNSW (#50)
  • Removidas expectativas de erros redundantes em testes (#82)
  • Módulo ailego não utilizado limpo (#85)

🔧 Experiência do desenvolvedor

  • typing_extensions substituído pelo typing padrão (Python ≥3.10) (#99)
  • Registro de erros C++ aprimorado via LOG_ERROR em vez de cerr (#80)
  • Documentos atualizados e stubs .pyi para ligações Python (#41)
  • Removida definição obsoleta de IndexMeta::MetricType (#53)
  • Adicionados exemplos C++ à matriz CI do macOS/Linux (#86)

🤖 CI/CD e ferramentas

  • Suporte a execuções de CI para PRs bifurcados (#52)
  • Ignorar CI em alterações somente de Markdown (#55)
  • Adicionados modelos de problemas para melhor suporte da comunidade (#46)
  • Requisito de versão mínima do CMake atualizado (#44, #57)
  • Atualização da documentação da ferramenta de bancada (#77)

📚 Documentação

  • Selos README atualizados e seção junte-se a nós (#45, #54)

👋 Novos colaboradores

  • @SYaoJun — primeira contribuição (#50)
