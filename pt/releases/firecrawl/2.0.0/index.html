firecrawl v2.0.0

Apresentando v2.0.0

Principais melhorias

  • Mais rápido por padrão: as solicitações são armazenadas em cache com maxAge padronizando 2 dias, e padrões sensatos como blockAds, skipTlsVerification e removeBase64Images estão habilitados.

  • Novo formato de resumo: agora você pode especificar "summary" como formato para receber diretamente um resumo conciso do conteúdo da página.

  • Extração JSON atualizada: a extração JSON e o controle de alterações agora usam um formato de objeto: { type: "json", prompt, schema }. O antigo formato "extract" foi renomeado para "json".

  • Opções de captura de tela aprimoradas: Use o formato do objeto: { type: "screenshot", fullPage, quality, viewport }.

  • Novas fontes de pesquisa: pesquise "news" e "images", além de resultados da web, definindo o parâmetro sources.

  • Rastreamento inteligente com prompts: Passe um prompt de linguagem natural para rastrear e o sistema deriva caminhos/limites automaticamente. Use o novo endpoint crawl-params-preview para inspecionar as opções derivadas antes de iniciar um trabalho.

Lista de verificação de migração rápida

  • Substitua o uso de v1 client por v2 clients: *JS: const firecrawl = new Firecrawl({ apiKey: 'fc-YOUR-API-KEY' })
    • Python: firecrawl = Firecrawl(api_key='fc-YOUR-API-KEY')
    • API: use os novos endpoints https://api.firecrawl.dev/v2/.
  • Atualizar formatos:
    • Use "summary" quando necessário
    • Modo JSON: Use { type: "json", prompt, schema } para extração JSON
    • Captura de tela e Captura de tela@fullPage: use o formato de objeto de captura de tela ao especificar opções
  • Adote fluxos assíncronos padronizados nos SDKs:
    • Rastreamentos: startCrawl + getCrawlStatus (ou garçom crawl)
    • Lote: startBatchScrape + getBatchScrapeStatus (ou garçom batchScrape)
    • Extrato: startExtract + getExtractStatus (ou garçom extract)
  • Mapeamento de opções de rastreamento (veja abaixo)
  • Verifique o rastreamento prompt com crawl-params-preview

Formatos e opções de raspagem

  • Use formatos de string para o básico: "markdown", "html", "rawHtml", "links", "summary".
  • Em vez de parsePDF use parsers: [ { "type": "pdf" } | "pdf" ].
  • Use formatos de objeto para JSON, controle de alterações e capturas de tela:

Formato JSON

 curl -X POST https://api.firecrawl.dev/v2/scrape \
     -H 'Content-Type: application/json' \
     -H 'Authorization: Bearer YOUR_API_KEY' \
     -d '{
       "url": "https://docs.firecrawl.dev/",
       "formats": [{
         "type": "json",
         "prompt": "Extract the company mission from the page."
       }]
     }'

Formato da captura de tela

  curl -X POST https://api.firecrawl.dev/v2/scrape \
      -H 'Content-Type: application/json' \
      -H 'Authorization: Bearer YOUR_API_KEY' \
      -d '{
        "url": "https://docs.firecrawl.dev/",
        "formats": [{
          "type": "screenshot",
          "fullPage": true,
          "quality": 80,
          "viewport": { "width": 1280, "height": 800 }
        }]
      }'

Mapeamento de opções de rastreamento (v1 → v2)
