firecrawl v1.9.0

Lançamento do Firecrawl v1.9.0

O que há de novo:

Melhorias no auto-hospedagem

  • Correções Supabase client
  • Suporte fixo para provedores LLM
  • O rastreamento é muito mais rápido agora
  • Adoção global de sistema de pesquisa armazenável em cache
  • Configuração mais fácil

Melhorias no MCP (v1.11.0)

  • Toneladas de melhorias (prompts, exemplos e como usar parâmetros corretamente)

Melhorias no SDK e API

  • Adicionado controle de alterações para SDK 2.0
  • Suporte para atraso de rastreamento com limitação de simultaneidade por rastreamento
  • Novo exemplo de rastreador Qwen3 via OpenRouter
  • Cancelar endpoint de raspagem em lote

Desempenho e Limites

  • Adoção global de sistema de pesquisa armazenável em cache
  • Aumento do limite de endpoints do mapa de 5.000 para 30.000 links
  • O limite do esquema de pesquisa aumentou de 50 para 100

Correções e estabilidade

  • Melhor tratamento de erros para falhas de SSL
  • Correções de bugs de encadeamento opcionais
  • Validação do campo WaitAction no firecrawl-py
  • Fila de simultaneidade reformulada para priorizar por tempo, não por prioridade

Painel (versão nuvem)

  • Novos registros de atividades
