firecrawl v1.10.0

Temos o prazer de anunciar o lançamento de nosso novo endpoint Search API que combina pesquisa na web com os poderosos recursos scraping do Firecrawl.

Recursos de pesquisa:

  • Pesquise na web e obtenha conteúdo completo dos resultados em uma chamada API
  • Escolha formatos de saída específicos (markdown, HTML, links, capturas de tela)
  • Personalize os parâmetros de pesquisa (idioma, país, intervalo de tempo, número de resultados)
  • Suporte completo SDK para Python e Node.js

Mais recursos

  • Proxy de modo automático para scraping (scrapeURL, js-sdk) #1551, #1602
  • Melhorias no tratamento de tempo limite e tipo de conteúdo para scrapeURL/pdf #1570, #1604, #1592
  • Melhorias no Redis: suporte separado para Redis sem despejo #1600
  • Melhorias na pesquisa: ignoreBlockedURLs, ignore o limite de simultaneidade #1580, #1617
  • Novo endpoint /cclog para registro de simultaneidade #1589
  • A extração de metadados agora inclui atributos itemprop #1624
  • Auto-hospedado: imagem Playwright implantável #1625

Correções e melhorias

  • Melhor manipulação de subdomínio para LLMs.txt + opção de bypass #1557
  • Validação de URL aprimorada e manipulação de caracteres especiais #1547
  • Limpeza de trabalhador zumbi + tratamento de TTL para status de extração #1575, #1599
  • Correção da lógica da fila de simultaneidade e substituição do limitador de taxa #1595, #1593
  • Melhor registro para paginação de pesquisa e busca robusta #1572, #1588
  • Pequenas correções: og:locale:alternate, alternância de adblock, lógica somente Playwright, matrizes de metadados malformadas #1597, #1616, #1574

Testes e documentos

  • Adicionar documentos de variáveis de ambiente MAX_RAM e MAX_CPU #1581
  • Testando melhorias de infraestrutura #1623
