firecrawl v2.4.0

##v2.4.0

Novos recursos

  • Nova categoria de pesquisa de PDF - Agora você pode pesquisar apenas PDFs por meio de nossos endpoints v2/pesquisa especificando a categoria .pdf
  • Gemini 2.5 Flash CLI Image Editor — Crie e edite imagens diretamente no CLI usando integração Firecrawl + Gemini 2.5 Flash (#2172)
  • X402 Search Endpoint (/v2/x402) — Adicionada uma pesquisa de última geração API com precisão e velocidade aprimoradas (#2218)
  • Sistema de eventos RabbitMQ — Jobs Firecrawl agora suportam comunicação baseada em eventos e pré-busca do Postgres (#2230, #2233)
  • Status de rastreamento API aprimorado — Relatórios de status de rastreamento mais precisos e em tempo real usando o novo crawl_status_2 RPC (#2239)
  • Avisos de resultados baixos e Robots.txt — Os usuários agora recebem feedback claro quando os rastreamentos são limitados por robots.txt ou geram poucos resultados (#2248)
  • Rastreamento aprimorado (OpenTelemetry) — Rastreamento distribuído muito aprimorado para melhor observabilidade entre serviços (#2219)
  • Métricas e análises — Adicionadas métricas em nível de solicitação para endpoints Scrape e Search (#2216)
  • Suporte para Webhook auto-hospedado — Webhooks agora podem ser entregues a endereços IP privados para ambientes auto-hospedados (#2232)

Melhorias

  • Tamanho da imagem Docker reduzido — Tamanho da imagem do serviço Playwright reduzido em 1 GB instalando apenas o Chromium (#2210)
  • Aprimoramentos Python SDK — Adicionado tratamento de status de trabalho "cancelled" e correções de intervalo de pesquisa (#2240, #2265)
  • Tempos limites mais rápidos do nó SDK — Os tempos limite do Axios agora se propagam corretamente, melhorando a confiabilidade sob cargas pesadas (#2235)
  • Visualizações de parâmetros de rastreamento aprimoradas — Prompts e validação aprimorados para visualizações de parâmetros de rastreamento (#2220)
  • Validação do esquema Zod — Validação mais rigorosa do parâmetro API com rejeição de campos extras (#2058)
  • Melhor tratamento de tarefas Redis — Corrigidos casos extremos em getDoneJobsOrderedUntil para recuperação mais estável de Redis (#2258)
  • Correções de Markdown e YouTube — Corrigidos erros de cache do YouTube e resumo de markdown vazio (#2226, #2261)
  • Documentos e metadados atualizados — atualizações README e novos campos de metadados adicionados ao JS SDK (#2250, #2254)
  • Configuração de porta API aprimorada — O API agora respeita portas definidas pelo ambiente (#2209)

Correções

  • Corrigidos casos extremos de validação de esquema recursivo $ref (#2238)
  • Arrays enum corrigidos sendo convertidos incorretamente em objetos (#2224)
  • Corrigidos tempos limite de chicote e problemas de docker-compose.yaml auto-hospedado (#2242, #2252)
