firecrawl v2.7.0

Firecrawl v2.7.0 está aqui!

  • Suporte ZDR Search para clientes corporativos.
  • Formato de marca aprimorado com melhor detecção.
  • Integrações com parceiros API agora em beta fechado.
  • Capturas de tela mais rápidas e precisas.
  • Melhorias auto-hospedadas

E muito mais melhorias, confira abaixo!

Novos recursos

  • Extrato de marca aprimorado
    Melhor detecção de logotipo e cor para resultados de extração de marca mais precisos.

  • Sistema de raspagem NOQ (experimental)
    Novo pipeline de scrape com estabilidade aprimorada e verificações de simultaneidade integradas.

  • Manuseio de redirecionamento aprimorado
    Os URLs agora são resolvidos antes do mapeamento, com detecção de cadeia de redirecionamento mais segura e novos tempos limite de interrupção.

  • Parâmetros de pesquisa empresarial
    Novas opções de nível empresarial disponíveis para o endpoint /search.

  • Criação de usuário baseada em integração
    Os usuários agora podem ser criados automaticamente quando provenientes de integrações de referência.

  • Parâmetro de raspagem minAge
    Permite exigir uma idade mínima de cache antes de re-scraping.

  • Extrair créditos de cobrança
    Os trabalhos de extração agora usam o mesmo sistema de cobrança de crédito que outros endpoints.

  • Auto-Host: simultaneidade de rastreamento configurável
    As implantações auto-hospedadas agora podem definir limites de simultaneidade personalizados.

  • Aprimoramentos de Sentinela
    Adicionada integração Vercel AI, taxas de amostragem configuráveis e filtragem de exceções aprimorada.

  • IDs UUIDv7
    Todos os novos recursos usam UUIDv7 lexicograficamente classificável.

Melhorias no API

  • Erros de resolução de DNS agora retornam 200 para tratamento de falhas mais consistente.
  • Lógica de mapeamento de URL aprimorada incluindo correções de mapa de site maxAge, suporte a mapa de site recursivo, normalização de roteador Vue/Angular e ignorar lógica de subdomínio para endereços IP.
  • Resultados parciais para pesquisa de múltiplas fontes em vez de falhar em todas as fontes.
  • Metadados de simultaneidade adicionados para extrair respostas do trabalho.
  • Métricas aprimoradas incluindo tempo total de espera, uso de LLM e detalhes de formato.
  • Atualizações de raspagem em lote
    • Adicionado endpoint /v2/batch/scrape/:jobId/errors ausente
    • Corrigido bug de paginação off-by-one
  • Tratamento de erros mais robusto para mecanismos de PDF/documentos, análise pydantic, validação Zod, validação de URL e casos extremos de cobrança.

Melhorias no SDK

JavaScript SDK

  • Retorna ID do trabalho de métodos síncronos.
  • Melhor manipulação de eventos WebSocket document.
  • Corrigidos tipos, Deno WS e adicionado suporte para ignoreQueryParameter.
  • Aumento de versão com limpeza interna.

Python SDK

  • Adicionados campos extras de metadados.
  • Melhor tratamento de validação de lote.

Qualidade e desempenho

  • Tamanho reduzido do arquivo de log e limpeza aprimorada do arquivo tmp.
  • Versão Express atualizada e pacotes vulneráveis ​​corrigidos.
  • Conversão de markdown desativada para raspagens de mapa do site para melhorar o desempenho.
  • Melhor registro e formatação de pré-rastreamento.
  • Ignorar a reescrita de URL para Google Docs publicados.
  • Evite cabeçalhos de cookies vazios durante retornos de chamada de webhook.

Melhorias auto-hospedadas

  • Aplicação de limite de simultaneidade desativada para modo auto-hospedado.
  • Credenciais PostgreSQL agora configuráveis ​​através de variáveis ​​de ambiente.
  • Instruções de construção do Docker-compose corrigidas.
