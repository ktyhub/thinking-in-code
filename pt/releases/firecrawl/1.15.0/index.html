firecrawl v1.15.0

Firecrawl v1.15.0 está aqui!

  • SSO para empresas
  • Maior confiabilidade do scraping
  • Parâmetros de pesquisa adicionados aos logs de atividades
  • Exemplo FireGEO
  • E mais de 50 PRs mesclados para bugs e melhorias 🔥

Melhorias

  • Suporte OMCE em scrapeURL e transformador HTML
  • Registro aprimorado (parâmetros de pesquisa, idade do cache)
  • Novo campo created_at na resposta /crawl/active
  • Verificações de protocolo de URL que não diferenciam maiúsculas de minúsculas
  • filterLinks portado para Rust

Correções

  • Estabilidade do transformador HTML (árabe, tag base, panic)
  • Bug do índice scrapeURL e exclusão waitFor
  • Bug de faturamento de PDF com parsePDF=false
  • Rastreamento retornando apenas 1 resultado (caso extremo)
  • Bug sem seções do rastreador
  • Nomeação do método Logger
  • Tratamento de tempo limite em API
  • Resiliência crawl-status para trabalhos ejetados

SDK e infra-estrutura

  • Correção de parâmetros de cabeçalho SDK e tratamento de erros assíncronos
  • Porta expressa agora configurável via env var
  • Isenção de expiração de rastreamento temporário

Documentos

  • Atualização de configuração do Kubernetes
