firecrawl v2.5.0

v2.5.0 - Os melhores dados da Web do mundo API

Agora temos dados da web API da mais alta qualidade e mais abrangentes disponíveis, alimentados por nosso novo índice semântico e pilha de navegador personalizada.

Veja os benchmarks abaixo:

<img width="1200" height="675" alt="image" src="https://github.com/user-attachments/assets/96a2ba36-0c7f-4fa3-829e-d6ac91b53705" />

Novos recursos

  • Implementado scraping para arquivos .xlsx (Excel).
  • Introduziu nova arquitetura de rastreamento e sistema de rastreamento de simultaneidade NUQ.
  • Limitação de simultaneidade por proprietário/grupo + cálculo de simultaneidade dinâmica.
  • Adicionado tratamento de pendências de grupo e operações de grupo aprimoradas.
  • Adicionada atualização de preços /search
  • Adicionada bandeira de equipe para pular a verificação do país.
  • Sempre preencha as métricas NUQ para melhorar a observabilidade.
  • Novo aplicativo de site de teste para testes de CI aprimorados.
  • Extraia metadados do cabeçalho do documento para uma saída mais rica.

Aprimoramentos e melhorias

  • Melhor carregamento da lista de bloqueio e mensagens de erro de sites não suportados.
  • Versão x402-express atualizada.
  • Melhor manipulação de includePaths para subdomínios.
  • Pesquisa auto-hospedada atualizada para usar DuckDuckGo.
  • JS e Python SDKs não exigem mais a chave API para implantações auto-hospedadas.
  • Melhorias no tratamento do tempo limite do Python SDK.
  • Rust client agora usa tracing em vez de print.
  • Ruído reduzido nas notificações de recarga automática do Slack.

Correções

  • Avisos de crawl robots.txt garantidos aparecem de forma confiável.
  • Resolvidos impasses de simultaneidade e manipulação de trabalhos duplicados.
  • Corrigidos padrões de país de pesquisa e bugs de lógica de preços.
  • Corrigidos conflitos de porta em ambientes de chicote.
  • Corrigido suporte à dimensão da janela de visualização e comportamento de captura de tela no Playwright.
  • Resolvida a instabilidade do teste de CI (cache de dramaturgo, testes de produção).
