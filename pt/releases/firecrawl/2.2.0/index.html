firecrawl v2.2.0

##v2.2.0

Recursos

  • A versão 3 do MCP está ativa. Suporte estável para cloud mcp com modos HTTP Transport e SSE. Compatível com v2 e v1 de.
  • Webhooks: agora oferecemos suporte a assinaturas + suporte a extração + falhas de eventos
  • O mapa agora é 15x mais rápido e suporta mais URLs
  • Melhorias na confiabilidade da pesquisa
  • O uso agora é rastreado pela chave API
  • Suporte para locais adicionais (CA, CZ, IL, IN, IT, PL e PT)
  • Endpoint de status da fila
  • Adicionado parâmetro maxPages ao scrape v2 API para análise de PDF

Melhorias

  • API:
    • Novo terminal /team/queue-status.
    • Adicionado recurso nuq.
    • Adicionada integração VIASOCKET.
    • Pontos finais históricos de uso de crédito/token com dados expandidos.
  • Programa Estudantil: Suporte para que mais universidades + estudantes obtenham créditos gratuitos por meio de nosso programa estudantil
  • Mapa: 15x mais rápido e aumentou o limite para 100k
  • Scrape API: Adicionado parâmetro maxPages para analisador de PDF.
  • Python SDK:
    • Adicionado get_queue_status ao aio + normalização de documentos nos resultados da pesquisa.
    • SDKs: Adicionada paginação do próximo cursor e suporte para parâmetros de integração.
  • Infraestrutura: Adicionado pool de proxy IP estático + suporte para localização de proxy.
  • Webhooks: Assinaturas implementadas, envio refatorado, adição de eventos de erro de raspagem.
  • Desempenho: Mapa otimizado, nativos Rust convertidos em uma única biblioteca NAPI.
  • CI/CD: CI renovado, ganchos de pré-confirmação adicionados, chicote de plataforma cruzada.

🐛 Correções

  • Escala de limite de simultaneidade corrigida.
  • Corrigidos links/descrições de resultados de pesquisa e mecanismo de nova tentativa para resultados vazios.
  • URLs de captura de tela expirados assinados novamente.
  • Caracteres nulos aparados de títulos PDF + codificação fixa.
  • Correção da análise do mapa do site e adição de suporte ao mapa do site .gz.
  • Corrigida importação de js-sdk zod-to-json-schema.
  • Correção da regressão do formato de dados do webhook.
  • Melhor tratamento de crédito no objeto conta.

🛠️ Tarefas e outros

  • Removidas dependências não utilizadas, CONTRIBUTING.md atualizado.
  • Adicionado registro de depuração, scripts ignorados durante a construção do CI.
  • Vários problemas de dependência e melhorias de construção.
