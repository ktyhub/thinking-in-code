firecrawl v1.14.0

Lançamento v1.14.0

Temos o prazer de anunciar o lançamento do Firecrawl v1.14.0, repleto de atualizações interessantes.

  • Scraping autenticado (entre na lista de espera [aqui] (https://firecrawl.dev/authenticated-scraping))
  • Zero retenção de dados para empresas (envie-nos um e-mail para help@firecrawl.com para habilitá-lo)
  • Velocidades p75 melhoradas
  • Nova versão MCP com maxAge + melhor chamada de ferramenta
  • Exemplo de pesquisador aberto (pesquisador de código aberto). Veja repositório
  • E muito mais 🔥
