#códice rust-v0.163.0

Novos recursos

  • Abra /config para pesquisar preferências em categorias, alterar as configurações suportadas imediatamente e ver quais alterações exigem reinicialização. (#52990, #53429)
  • Envie um acompanhamento enquanto o Codex estiver respondendo para orientá-lo imediatamente. Interromper um turno também interrompe as células ativas do modo de código e suas chamadas de ferramenta aninhadas. (#51812, #51835)
  • Configure uma chave líder em /keymap. O padrão é Ctrl+X, as dicas de atalho permanecem abertas até você escolher ou cancelar e o silenciamento de voz passa para F9. (#52273)
  • Reinicie um servidor gerenciado em segundo plano do /daemon. O Codex avisa sobre o trabalho que a reinicialização pode interromper e depois se reconecta automaticamente. (#53173)
  • O Codex pode executar ferramentas independentes somente leitura em paralelo, incluindo pesquisas de habilidades, memória e histórico de conversas. (#52245)
  • Daybreak está habilitado por padrão para contas qualificadas. codex exec também pode selecioná-lo com uma chave OpenAI API quando o servidor oferecer acesso. (#53701, #53717)

Correções de bugs

  • A retomada de um thread salvo restaura suas permissões e aprovações de rede, respeitando as substituições explícitas e a política gerenciada atual. (#53150, #53419, #53424)
  • O proxy de rede agora verifica a permissão antes de uma pesquisa de DNS, rejeita cabeçalhos Host duplicados e evita que aliases de credenciais contornem os ganchos de inspeção. (#51650, #52661, #53506)
  • Retorne a uma conversa paralela existente com /side após trocar de tópico. As respostas às solicitações pendentes também remontam ao tópico que solicitou. (#52184, #53436)
  • No Windows, Ctrl+V e Shift+Insert colam texto e também imagens. No WSL, as colas repetidas reutilizam o leitor clipboard e as tentativas de cópia atingem o tempo limite em vez de travar. (#53224, #52967, #53453)
  • Os comandos locais terminam imediatamente quando um filho mantém um canal de saída aberto. Os comandos remotos preservam a saída atrasada para que a pesquisa final ainda possa coletá-la. (#52652, #53331, #53622)
  • codex exec não imprime mais o mesmo arquivo diff novamente após um comando não relacionado. (#53444)

Documentação

  • Atualizada a orientação do OpenAI Docs para migrações para a família GPT-6, incluindo raciocínio específico do modelo, uso de ferramentas e considerações de residência de dados. (#51768)
  • Esclarecido como o sandbox do Linux usa bubblewrap para isolamento do sistema de arquivos e seccomp para filtragem de syscall. (#52610)
