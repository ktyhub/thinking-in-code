#códice rust-v0.167.0

Novos recursos

  • Abra o centro de comando do agente com codex agents --no-daemon. O centro de comando e o seletor de sessão agora marcam resultados não lidos (#58238, #58239, #58263, #58264).
  • Alterne entre back-ends conectados no seletor de sessão do terminal e mantenha seus rascunhos ao alternar (#58280, #58457).
  • Visualize anexos de imagens locais enquanto compõe em terminais suportados e abra imagens locais visualizadas de caminhos de transcrição clickable (#58261, #58446).
  • Encontre as opções de chave API e provedor de nuvem em “Fazer login de outra maneira”. Ative gcp_setup_wizard para configurar o Google Cloud Vertex AI com credenciais padrão do aplicativo ou um arquivo de credencial (#57857, #58427).
  • Ative as configurações de proxy do sistema macOS ou Windows em /experimental (#58157).
  • Expanda os detalhes do patch diretamente na transcrição enquanto um prompt de aprovação estiver aberto (#58281).

Correções de bugs

  • Os bate-papos salvos permanecem visíveis depois que você troca de provedor de modelo. Se um bate-papo não puder ser retomado, você poderá ler sua transcrição e preparar um aviso editável para continuar em um novo bate-papo (#58202).
  • Ctrl+L limpa o display do terminal enquanto mantém mensagens anteriores disponíveis através de Ctrl+T (#58266).
  • Excluir texto que expõe um ! inicial mantém um rascunho comum no modo de bate-papo (#58412).
  • Os prompts de aprovação da rede fecham quando suas solicitações terminam. Solicitações simultâneas para o mesmo endpoint solicitam uma de cada vez (#58350, #58351).
  • Longas conversas V3 em tempo real salvam a fala concluída no histórico de bate-papo à medida que a transcrição aumenta (#58221).
  • A compactação automática de contexto agora é responsável pela saída retida de respostas com falha e respostas com dados de uso de token ausentes (#58404).

Documentação

  • O README do servidor de aplicativos cobre restrições de rede gerenciadas sob regras de comando [permissions.network] e prompt-user que exigem nova aprovação humana (#58045, #58182).
  • A habilidade openai-docs recomenda a substituição documentada ao migrar de um modelo obsoleto (#58134).
