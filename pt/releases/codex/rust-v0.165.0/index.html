#códice rust-v0.165.0

Novos recursos

  • Adicionado um provedor Google Cloud Vertex AI integrado, configurado com model_provider = "gcp". (#56265)
  • Adicionado GPT-6.1 Terra aos catálogos de modelos. (#57337)
  • Adicionado um filtro de repositório ao seletor de sessão e agrupamento de diretórios ao centro de comando do agente, facilitando a navegação nas sessões entre árvores de trabalho vinculadas. (#56308)
  • Adicionados garfos de thread anexados experimentais ao servidor de aplicativos API. (#56351)
  • Habilitado alterações de esforço de raciocínio durante uma conversa por padrão para modelos suportados. (#56163)
  • Memória v2 habilitada por padrão para perfis novos e suporte adicionado para importação de memórias de agente externo para ela. (#56211, #56414)

Correções de bugs

  • Foram corrigidas novas sessões de TUI para honrar o revisor de aprovação padrão do servidor quando nenhuma substituição explícita é fornecida. (#56090)
  • Manteve as preferências da TUI editáveis e aplicáveis imediatamente quando as configurações de execução são inválidas. (#56091)
  • Solicitações de ferramentas MCP remotas canceladas quando suas futuras respostas locais são descartadas. (#56132)
  • Impediu que as mensagens do agente na fila reiniciassem o trabalho após uma interrupção ou uma mudança para o modo Plano. (#56330)
  • Interrupção de novas tentativas quando um provedor informa que um modelo não foi encontrado, preservando sua mensagem de erro. (#56445)
  • Foi fechada uma lacuna de validação de URL do mercado que poderia permitir que o Git se conectasse a um host diferente daquele verificado em relação aos padrões permitidos. (#56263) ##Changelog Changelog completo: https://github.com/openai/codex/compare/rust-v0.164.0...rust-v0.165.0
