#códice rust-v0.169.0

Novos recursos

  • O espaço de trabalho do terminal opcional oferece suporte a várias guias de bate-papo paralelo. Alterne entre eles com o teclado ou mouse e reabra os bate-papos paralelos locais salvos após reiniciar o Codex. (#59784, #60152, #60181)
  • Pesquise tarefas mais antigas do centro de comando do agente por nome, visualização de prompt ou diretório de trabalho. (#60286)
  • Ative Recolher detalhes da curva na transcrição em tela cheia para dobrar a atividade concluída abaixo de cada prompt, mantendo as respostas visíveis e a saída da ferramenta pesquisável. (#60554, #60555, #60556, #60557)
  • Adicione ou edite provedores de modelos personalizados no terminal. Com a integração de gateway personalizada habilitada, você pode criar um provedor durante a entrada e usar um código de dispositivo para gateways compatíveis por SSH ou sem um navegador local. (#59779, #60009, #60186, #60486, #60662)
  • Pressione Ctrl+S no editor de relatório do terminal para salvar um ZIP de diagnóstico localmente, mesmo quando os uploads estão desabilitados. (#60542)
  • Com a conexão opcional à nuvem no macOS e Linux, envie imagens, escolha um modelo e esforço de raciocínio e arquive ou restaure conversas na nuvem a partir do terminal. (#59828, #60061, #60635, #60651)

Correções de bugs

  • codex exec mantém a configuração do projeto e servidores MCP desabilitados em diretórios não rusted, mesmo com --sandbox workspace-write. Use --trust com codex exec ou codex review para salvar explicitamente o projeto trust. (#60041)
  • Sim, limpar o contexto e implementar agora entrega o plano completo aprovado para a nova sessão e mantém a sessão atual aberta se a transferência falhar. (#60763)
  • Correção do tratamento de sandbox do Windows para caminhos cmd.exe citados e para sessões do PowerShell cujo diretório de trabalho tem um pai ilegível. (#60624, #60647)
  • As imagens coladas no macOS mantêm a orientação pretendida e usam dados PNG ou JPEG clipboard nativos, quando disponíveis. (#60455)
  • O terminal não fica mais ocupado aguardando servidores MCP que um servidor de aplicativos compartilhado não reportou. (#60280, #60622)
  • Os turnos interrompidos agora fecham de forma limpa e os abortos atrasados ou cancelamentos de aprovação de arquivos não interrompem mais um turno posterior. (#59910, #60700)

Documentação

  • Atualizada a habilidade openai-docs para focar nas questões de trabalho do Codex e ChatGPT e na configuração inicial do API, com orientação dedicada para configurar o Codex em uma equipe. (#59944, #59949)
  • Documentado como o servidor de aplicativos clients pode listar modelos ou autorizar um gateway para um provedor configurado sem alterar o provedor padrão. (#59776, #59819)
