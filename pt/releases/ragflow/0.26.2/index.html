Resumo

Novos recursos

Melhorias

  • Conjuntos de dados
    • Adiciona uma verificação de casos extremos à lógica de ingestão de arquivos para vincular com segurança pastas vazias a um conjunto de dados. #16296
    • Adiciona paginação ao método get_flatted_meta_by_kbs() para evitar falhas CRUD relacionadas a conjuntos de dados com mais de 10.000 documentos. #16095
  • Canais de bate-papo: garantem que os históricos de conversas do usuário final persistam durante as reinicializações, mas ainda separados quando um canal é vinculado a uma nova caixa de diálogo. #16274

###i18n

  • Expande a cobertura i18n e refina as traduções para a UI coreana. #16203;
  • Adiciona traduções faltantes em francês para canais de bate-papo, validação de nome de usuário e edição de modelo. #16217

Correções de bugs

  • Análise de arquivo:
    • Um ValueError foi gerado durante a análise de .docx nos estilos 'Heading'. #16284
    • As tabelas nos arquivos .docx foram removidas silenciosamente pelo analisador de documentos legais. #16155
    • Os cabeçalhos solitários do Markdown foram separados de suas seções subsequentes quando um delimitador DeepDoc foi definido. #16109
    • As tabelas Markdown apareceram duas vezes nos resultados do bloco, uma vez como um bloco independente e novamente dentro de um bloco de texto normal. #16143 -MCP
    • O servidor MCP travou indefinidamente ao encontrar páginas vazias do documento; a página final dos documentos foi descartada silenciosamente devido a falhas na paginação. #16285
    • A conexão MCP e o processo de descoberta do conjunto de dados falharam porque o limite de busca codificado do servidor excedeu a restrição page_size introduzida. #16148
  • Fluxo de dados
    • Restaura o ponto final de reexecução do fluxo de dados e garante que a resposta de ingestão inclui a carga DSL para renderizar de forma confiável a linha do tempo e as visualizações do analisador. #16292
    • Restaura os padrões do analisador de fluxo de dados e retorna a carga útil SSE real, garantindo que o pipeline seja executado corretamente, identificando IDs de mensagens e atualizações de log. #16290
  • LLM: falha ao usar o novo modelo gemini-3.5-flash por meio do provedor Google Cloud (Vertex AI) usando o endpoint da região eu ou us. Isso é resolvido explicitamente por solicitações de roteamento multirregional para os domínios aiplatform.<region>.rep.googleapis.com necessários, em vez de hosts <region>-aiplatform.googleapis.com sintetizados. #15990
  • UI/UX: O modal de adição de metadados envia valores vazios para o backend. #15229
