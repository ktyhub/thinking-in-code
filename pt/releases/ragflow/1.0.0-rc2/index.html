fluxo de fluxo v1.0.0-rc2

1.0.0-rc2 é o segundo candidato a lançamento do v1.0.0. Esta versão corrige vários problemas no rc1 e introduz novos recursos e suporte expandido.

Destaques

  1. Introduzido o modo Agentic para chat, substituindo os níveis de pensamento Baixo, Médio, Alto e Ultra.
  2. Compatibilidade preservada com dados v1.0.0-rc1 existentes, permitindo atualizações diretas.
  3. Adicionado suporte para compartilhamento Team/Me.
  4. Adicionado suporte para provedores de modelos DemonRoute e Opper, ferramentas de pesquisa na web Firecrawl e Search1API e o modelo MinerU 4.
  5. Adicionado suporte de recuperação para tcheco e eslovaco.
  6. Unificou os 12 analisadores de documentos integrados com os analisadores de Pipeline.
  7. Adicionadas imagens Docker para a arquitetura arm64.
