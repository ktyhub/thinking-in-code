fluxo de fluxo v0.25.2

Resumo

Melhorias

  • Refatoração e unificação do API: continua a transição dos APIs da web para convenções RESTful, garantindo compatibilidade com versões anteriores para todos os endpoints legados.

Fonte de dados

  • Introduz um mecanismo leve de instantâneo para sincronizar arquivos excluídos em oito fontes de dados – incluindo Moodle, DingTalk AI Table e RSS – garantindo um reflexo fiel de todas as fontes de dados remotas. #14362#14499

Correções de bugs

  • Problemas de visibilidade de metadados durante atualizações de v0.24.0 para v0.25.0.
  • Saída de bate-papo duplicada.
  • A filtragem de metadados foi realizada na memória em vez de aproveitar o Elasticsearch, gerando gargalos de desempenho. #14576
