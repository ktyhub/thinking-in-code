fluxo de fluxo v0.26.0

Resumo

Novos recursos

  • Fornecedores de modelos
    • Implementa listas de modelos preenchidas automaticamente para vários provedores, eliminando a necessidade de digitar nomes de modelos manualmente. Este recurso atualmente suporta: Ollama, OpenRouter, vLLM, compatível com OpenAI-API, LM-Studio, VolcEngine, Xinference, LocalAI, BaiduYiyan, GPUStack e Fish Audio.
    • Permite configurar múltiplas chaves API para um mesmo modelo de provedor. #14595
    • Preenche dinamicamente os menus suspensos de seleção de modelos na interface do usuário, buscando os modelos atualmente disponíveis diretamente de provedores de modelos remotos. #15711
  • Conectores de fonte de dados: implementa novos conectores de fonte de dados para Outlook, OneDrive, Microsoft Teams, Slack, SharePoint, Salesforce e Azure Blob Storage. #15333#15330#15332#15188#15190#15462#15466
  • Conjunto de dados – Implementa um recurso de ponto de verificação e retomada para extração de comunidade e resolução de entidade, as partes mais caras e demoradas do pipeline de indexação GraphRAG. #15518#15523

Melhorias

  • Remove o buffer de texto <think> para garantir que os modelos com capacidade de raciocínio pareçam mais rápidos e transparentes durante as interações. #15891
  • Marca as migrações do MySQL como aplicadas. #15504

Suporte ao modelo

  • Quatro novos modelos SiliconFlow #15383
  • Modelo MiniMax-M3 #15513
  • Últimos modelos antrópicos #15516
  • Família de modelos Voyage 4 #15516
  • Lista de modelos coerente. #15576

###i18n

  • Conclui a tradução para o coreano. #15863
  • Conclui a tradução italiana. #15729

Correções de bugs

  • O modo de pensamento dos modelos MiniMax não foi habilitado corretamente. #15496
  • Loops infinitos foram acionados quando o modo de pensamento foi habilitado para os modelos Qwen3.5 e Qwen3.6. #15101
  • As respostas transmitidas estavam sendo duplicadas ao usar o endpoint API de conclusões de bate-papo compatíveis com OpenAI. #15286#15443
  • Erros de serialização foram causados durante a conclusão do chat quando pontuações numéricas inválidas como NaN (Not-a-Number) ou Inf (Infinity) foram passadas para o codificador JSON. #15245#15266
  • As conclusões de bate-papo usando provedores LiteLLM falhavam porque parâmetros de configuração interna não reconhecidos não estavam sendo filtrados antes de chegarem aos APIs externos. #15427#15432
  • As conclusões de bate-papo compatíveis com OpenAI API estavam padronizando para respostas transmitidas. #15356#15394
  • Os resultados vazios do AND foram descartados incorretamente durante a filtragem de metadados. #15477
  • Páginas cromadas repetitivas, como cabeçalhos e rodapés, foram extraídas incorretamente como texto principal pelo analisador MinerU. #15335#15387
  • Faltavam títulos de gráficos em inglês durante a extração de documentos no módulo DeepDoc. #15481
  • Saídas vazias foram retornadas pelo TitleChunker para formatos upstream json e chunks #14247#15396
  • Uma mensagem de erro estava faltando quando uma tentativa de upload de arquivo .tsv falhou. #15284
  • Os tokens API sem valores beta causaram erros de recuperação de token. #15405
  • Limita o tamanho máximo da página para corrigir falhas no sistema ou lentidão devido a consultas grandes. #15292
  • Erros Client foram causados ​​​​pela conclusão do bate-papo compatível com OpenAI API padronizando incorretamente as respostas transmitidas. #15356#15394
  • Erros internos do servidor HTTP 500 foram acionados em vez dos erros padrão 4xx client quando os usuários tentaram baixar arquivos ausentes do back-end de armazenamento. #15369#15371
  • A classificação da entidade GraphRAG foi quebrada. #15795#15797
