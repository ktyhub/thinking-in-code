fluxo de fluxo v0.26.3

Resumo

Lançado em 2 de julho de 2026.

Novos recursos

  • Conector de fonte de dados: apresenta o Google BigQuery como um conector de fonte de dados para ingestão de documentos e sincronização incremental. #15871
  • MCP: Adiciona duas ferramentas MCP ragflow_list_datasets e ragflow_list_chats ao servidor RAGFlow MCP. #15384
  • Ingestão de arquivos
    • Integra o analisador SoMark OCR com reconhecimento de layout ao sistema para extrair e indexar elementos complexos de documentos, como tabelas e figuras. #16482
    • API: expõe o endpoint Ingerir documentos para processar documentos usando um pipeline personalizado. #16395

Melhorias

  • Back-end: introduz tratamento de sucesso parcial para uploads de documentos em lote, garantindo que um único arquivo com falha não faça mais com que o lote inteiro seja descartado. #16438
  • UI/UX: refatora o cabeçalho global para alternar dinamicamente entre uma barra de navegação completa no desktop e uma gaveta lateral compatível com dispositivos móveis com base no espaço disponível na tela, resolvendo problemas sobrepostos e melhorando significativamente a experiência do usuário móvel. #15984

Correções de bugs

  • Após configurar o provedor Ollama, o sistema retornou o erro: 'Falha ao acessar modelo(nome) utilizando esta chave api'. #16519
  • A exclusão de um par de mensagens de bate-papo de usuário/assistente removeu por engano a referência do turno de conversação anterior devido a um desalinhamento de índice. #16436
