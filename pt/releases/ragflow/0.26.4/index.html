fluxo de fluxo v0.26.4

Resumo

Lançado em 7 de julho de 2026.

Novos recursos

  • PNL/tokenização: adiciona um lematizador Snowball com reconhecimento de idioma e suporte a 16 idiomas, integra o parâmetro language do conjunto de dados em todo o pipeline de tokenização e adiciona holandês ao front-end. #14140

Correções de bugs

  • O sistema travou com um ValueError ao analisar nomes de modelos do LM-Studio contendo um símbolo '@'. #16467
  • O servidor MCP travou porque a função list_chats esperava uma lista do /chats API, mas em vez disso recebeu um dicionário paginado. #16639
  • O analisador Docling eliminou silenciosamente fórmulas matemáticas de documentos em vez de extraí-las. #16645
  • O sistema não conseguiu persistir as edições in-line feitas nos valores de metadados no back-end. #16655
  • O sistema removeu links existentes ao vincular arquivos em massa a conjuntos de dados. #16587
  • O filtro não usou chinês. #16673
  • O sistema não conseguiu impor que os pesos das tags devem ser maiores que zero. #16657
  • O layout do menu suspenso do prompt do agente foi renderizado incorretamente. #16653
  • O chunker das Leis classificou incorretamente as referências cruzadas de números pontilhados como títulos. #16626
  • O sistema não conseguiu impedir que os usuários salvassem nomes duplicados de servidores MCP durante o processo de edição. #16588
  • O sistema permitiu que os usuários exportassem uma seleção de servidor MCP vazia. #16589
