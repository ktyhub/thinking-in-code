Resumo

Lançado em 20 de maio de 2026.

Novos recursos

  • Adiciona provedores locais e SSH no painel de administração. #15039

Melhorias

  • Caminho de pesquisa de conjunto de dados acelerado, reduzindo a latência em 50–100%, removendo a busca cara de vetores e reclassificando etapas de cálculo de similaridade. #14970
  • Empurra os filtros de metadados para o Infinity, acelerando significativamente a filtragem de metadados. #14974
  • adicionado cache Redis para TTS. #14851
  • atualizações do contador de documentos atômicos #14867
  • Melhor velocidade de inicialização do servidor e uso de memória #14973
  • Agente: agregação de saída estruturada #13384 #14848
  • Agente: reutilização do filtro de metadados. #14849
  • Otimiza o painel do conector. #14979
