fluxo de fluxo v0.26.1

Resumo

Novos recursos

  • Provedor de modelo: permite que os usuários modifiquem o tipo de modelo das configurações de modelo existentes. #16029
  • Canal de bate-papo: permite que os usuários implantem assistentes RAGFlow como chatbots em plataformas de mensagens externas como Discord e Feishu. #15850
  • Observabilidade: Agrupa rastreamentos de bate-papo multiturno por sessão no Langfuse para facilitar a depuração e reprodução de conversas. #15679

###i18n

  • Adiciona cerca de 70 chaves de tradução ausentes para a interface do usuário em francês. #15983

Correções de bugs

  • Provedor de modelo: corrige o faturamento de token impreciso, corrige a incorporação de limites de truncamento para evitar falhas de indexação e refatora o tratamento de erros para revelar as causas raiz dos erros. #15424
  • API: Adiciona um modo legado ao endpoint /chat/completions para restaurar a saída <think> estilo v0.23.0 para compatibilidade com versões anteriores. #16014 Consulte também Converse com assistente de chat.
