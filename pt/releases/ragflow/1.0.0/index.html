ragflow v1.0.0

Major Publicado6 de nov. de 2026 Fonteinfiniflow/ragflow Original em inglês

Esta página é traduzida automaticamente. O texto original em inglês é a referência.

fluxo de fluxo v1.0.0

Após três release candidate, temos o prazer de anunciar o lançamento oficial do RAGFlow 1.0, agora pronto para produção. Construída com base em uma reescrita completa em Go, esta versão reduz significativamente a sobrecarga de implantação e tempo de execução e apresenta uma experiência totalmente nova de Agentic Chat. Incentivamos todos os usuários a atualizar para melhorar a estabilidade, o desempenho e a resposta a perguntas.

Destaques

  • Reescrito em Go para implantação mais leve: as imagens Docker são aproximadamente 10× menores e a inicialização é aproximadamente 10× mais rápida.
  • Simultaneidade aproximadamente 100x maior, com melhorias substanciais na latência de consulta, uso de memória e velocidade de análise de documentos.
  • Chat Agentic totalmente novo: permite raciocínio em várias etapas e respostas a perguntas complexas por meio de recuperação iterativa, chamadas de ferramentas e avaliação de suficiência de evidências.

Bate-papo e Agentes

  • Adicionado modo Agentic Chat, substituindo os níveis de pensamento anteriores Baixo, Médio, Alto e Ultra.
  • Introduziu o modelo de decisão Jev no ciclo de chamada de ferramentas do agente para determinar se a evidência disponível é suficiente para responder a uma pergunta.
  • Adicionado suporte para o modelo de decisão Jev no componente Categorizar agente.
  • Adicionado armazenamento e exibição de prompts, uso de token e tempo de execução no histórico de chat.

Ingestão e recuperação de documentos

  • Unificou os 12 analisadores de documentos integrados com os analisadores de pipeline.
  • Adicionado suporte para várias versões DSL do pipeline de ingestão.

Arquitetura e implantação

  • Migração da fila de mensagens de Redis para NATS.
  • Adotado Kvrocks para armazenamento de cache e checkpoint.
  • Adicionadas imagens Docker para a arquitetura arm64.
  • Reimplementado o RAGFlow CLI em Go.

Estabilidade

  • Correção de vários bugs críticos relatados pela comunidade e problemas identificados durante a fase de release candidate, melhorando ainda mais a estabilidade do tempo de execução.

Referências

  • Obteve 91% de precisão no benchmark de resposta a perguntas multi-hop FRAMES usando RAGFlow Agentic Chat com MiniMax M3.

Atualizando

  • De v1.0.0-rc1, rc2 ou rc3: Os dados existentes são totalmente compatíveis. Você pode atualizar diretamente.
  • De v0.27.2: Você pode atualizar diretamente para v1.0.0. A migração de dados é executada automaticamente quando o contêiner RAGFlow Docker é iniciado.
  • A partir de versões anteriores a v0.27.2: Siga o guia de migração para concluir as atualizações intermediárias necessárias antes de atualizar para v1.0.0.
  • Faça backup de todos os dados antes de atualizar. A migração de dados de v0.27.2 para v1.0.0 é irreversível. Se a migração falhar, restaure o backup completo de pré-atualização antes de tentar novamente.

Compatibilidade e Limitações

  • Os aliases API obsoletos não são mais suportados.
  • O Python SDK não é afetado.
  • Atualmente, o DeepDoc oferece suporte apenas a ambientes de CPU.

Referências relativas

  • Guia de backup e atualização: https://ragflow.io/docs/migration_overview
  • APIs removidos: https://ragflow.io/docs/http_api_reference#removed-api-aliases
