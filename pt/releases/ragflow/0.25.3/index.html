fluxo de fluxo v0.25.3

Resumo

Novos recursos

  • Fonte de dados e análise: Adicionado controle semântico/metadados em nível de coluna para o analisador de arquivo de planilha; introduziu a otimização ETag para sincronização incremental de fontes de dados S3 para evitar transferências desnecessárias de arquivos.
  • Permite atribuir funções específicas, como conteúdo, metadados e chave primária, às colunas da tabela. #13710

Melhorias

  • Refatoração e segurança API
    • Continua a transição de web APIs para convenções RESTful, garantindo compatibilidade retroativa para todos os endpoints legados.
    • Vincula o user_id em POST /api/v1/messages ao principal JWT autenticado. #14745
    • Protege o executor do sandbox contra desvios de execução de código dinâmicos e indiretos. #14690
    • Controle de tempo limite de solicitação LLM
    • Pool de threads de chamada de bloqueio de alta simultaneidade
  • Reduz o tempo de inicialização do servidor de ingestão. #14894

Correções de bugs

  • As imagens em pastas de trabalho do Excel com várias planilhas não tinham escopo por planilha, fazendo com que as imagens fossem atribuídas incorretamente em planilhas diferentes. #14120
  • Passagem de alias de item de iteração
  • Análise de modelo de parâmetro de ferramenta
  • Saída de anexo de execução de código
  • Correção de adição de modelo de vulcão
