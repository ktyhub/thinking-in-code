Esta página é traduzida automaticamente. O texto original em inglês é a referência.

fluxo de fluxo v0.25.1

Resumo

Melhorias

  • Refatoração e unificação API: padroniza APIs da web para convenções RESTful em todos os endpoints, unificando a criação de documentos e fluxos de indexação, mantendo a compatibilidade com versões anteriores.
  • Otimizações de análise: Adiciona backend de PDF OpenDataLoader. #14097
  • Introduz carregamento lento e análise fragmentada para PDFs grandes (>50 páginas), reduzindo significativamente o consumo de memória. #14385

Fonte de dados

Permite a sincronização de arquivos excluídos no Bitbucket, Gmail, Google Drive e Airtable.

Suporte ao modelo

-DeepSeek v4

Fornecedores de modelos

-UCloud

Correções de bugs

  • Problemas de visibilidade de metadados durante atualizações de v0.24.0 para v0.25.0.
  • Saída de bate-papo duplicada.
