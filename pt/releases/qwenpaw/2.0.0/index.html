#QwenPaw v2.0.0

O que mudou

✨ Adicionado

Arquitetura Central

  • Tempo de execução 2.0: Refatore o kernel com base no AgentScope 2.0 (#5078, #4846, #5018, #5552)
  • Agent OS Driver: gerenciamento unificado de conexões MCP/A2A/ACP, armazenamento de credenciais criptografadas e política de aprovação por chamada (#5067)
  • Engenharia de Loop: Novo design de portão de Loop com três modelos de Loop: Modo Normal / Modo Missão / Modo Objetivo (#5665, #5727)
  • Governança e Sandbox: mecanismo de política com regras de permissão/negação/solicitação, detectores ToolGuard mesclados em um único caminho de avaliação de política e um padrão de governança generalizado para plug-ins (#5088, #5546, #5301) Gerenciamento de contexto
  • Contexto de rolagem: histórico de trabalho apoiado por SQLite (history.db) com pesquisa de texto completo FTS5, índice de despejo, persistência em nível de turno e um recall_history_python REPL em sandbox para recuperação sob demanda de turnos mais antigos. Retenção padrão de 30 dias, importa automaticamente sessões existentes na inicialização (#5321)
  • Compressão nativa: refatore usando a estratégia de compactação de contexto integrada do AgentScope 2.0 (#5309) Memória de longo prazo
  • ReMe v0.4.0 backend: Substitua o tempo de execução da memória interna pelo ReMe v0.4.0 - armazenamento de vetores, rastreamento automático e recuperação agora são gerenciados pela biblioteca ReMe v0.4.0 (#5349)
  • Rastreamento baseado em turnos: as gravações de memória agora acontecem por turno via middleware, não mais vinculadas ao fechamento da sessão (#5540)
  • Pesquisa com reconhecimento de uso: a pesquisa de memória agora considera atualidade e frequência; Seleção de modelo de incorporação específico de backend adicionada à UI de configuração (#5820)
  • Modo REST ADBPG: back-end de memória ADBPG alterado para somente REST, com pesquisa automática (#5296)
  • Simplificação da interface de pesquisa: exibição de pesquisa de memória mais limpa, campos de metadados reduzidos ao essencial (#5482)
  • 'none' backend: opção de configuração para desativar totalmente o sistema de memória para implantações leves (#5732) IU do terminal (TUI)
  • TUI em tela cheia: um aplicativo de bate-papo de terminal baseado em texto (qwenpaw tui) — saída de streaming, renderização de chamada de ferramenta, barra de status e gerenciamento de sessão, tudo no terminal (#5032)
  • Sessões com escopo de projeto: a TUI pode iniciar uma sessão de modo de codificação com escopo para um diretório de projeto específico (#5448)
  • Barra de uso de contexto: token ativo/indicador de uso de contexto na barra de status da TUI (#5673)
  • Comandos ACP na TUI: comandos de aprovação em linha /approve, /deny + melhorias no painel de transcrição (#5443, #5714) Console e IU
  • Cartão de aprovação: botões de ação maiores, visualização de diferenças mais nítida, aprovação/negação de um click (#5855)
  • Upload de texto longo: cole ou carregue blocos de texto grandes diretamente na entrada do chat (#5854)
  • Aprovação de ferramenta em nível de sessão: substituir a política de ferramenta global por sessão (#5685, #5832)
  • Banner de não proprietário: mostra o banner "somente visualização" ao visualizar a guia de sessão de outra pessoa (#5664)
  • Layouts móveis: CSS responsivo + navegação baseada em gaveta para todas as páginas do console (#5444–#5470)
  • Visualização dividida da página de ferramentas: ferramentas habilitadas versus disponíveis mostradas em colunas separadas; alternância com reconhecimento de configuração por ferramenta (#5509, #5604)
  • Melhorias no mercado de habilidades: contagem de estrelas/downloads, divisão ativada/desativada, sincronização automática do CDN (#5521, #5706, #5639)
  • Layout duplo da página de canais: canais ativados na parte superior, disponíveis abaixo (#5504)
  • Modo de codificação dividido 50/50: o painel de bate-papo ocupa metade da janela de visualização (#5473)
  • Pastas ocultas no navegador do projeto: diretórios prefixados . agora selecionáveis (#5828)
  • Gaveta de sessões: sessões agrupadas por data com pesquisa in-line (#5728)
  • Popover de uso de token: gráfico de anel mostrando o uso de token/contexto por turno, restaurado para o tempo de execução 2.0 (#5493, #5544)
  • Filtros de caixa de entrada: filtre notificações push por tipo de fonte (#5522)
  • Âncoras de mensagem: navegador de salto para mensagem para turnos do usuário (#5515)
  • Tempo limite da solicitação: tempo limite HTTP configurável + propagação AbortSignal para chamadas de back-end (#5764) Fornecedores de modelos
  • OpenAI Response API: novo provedor para o formato OpenAI Response API (#5519)
  • Atualizações do DashScope: Qwen3.7 + DeepSeek V4 adicionado à lista de modelos integrada; Passagem extra_body para generate_kwargs; alternância de relé de pensamento por modelo (#5646, #5491, #5687, #5730)
  • Modelos GitHub: Migração para novo endpoint API; suporta PATs refinados (#5735)
  • URL base personalizada do Telegram: configuração api_base_url para servidores Telegram Bot API auto-hospedados (#5651) Canais
  • Streaming de matriz: streaming de edição no local, não envia mais uma nova mensagem por bloco (#5585)
  • Canais registrados por plug-ins: plug-ins podem registrar tipos de canais personalizados com um esquema JSON que gera automaticamente a UI de configuração (#4693)
  • Alternância de debounce por canal: sinalizador no_text_debounce para que canais rápidos não enviem mensagens em lote (#5617)
  • Slack: implementação completa do canal com anexos multimodais, respostas de thread e streaming (#5193)
  • Implantação privada do DingTalk: configuração api_endpoint para instâncias locais do DingTalk (#5111)
  • Canal Azure Bot: canal Azure Bot adicionado como um plug-in, com suporte i18n/custom-icon/doc_url para canais de plug-in (#5849)
  • Anexos do Discord: Baixe para media_dir local, sirva via rota de arquivo estático (#5468) Computador
  • Migração Tauri: compilação de desktop movida de Electron para Tauri — binário menor, webview nativo, instalador NSIS no Windows (#5734, #4669, #4041)
  • Tempo de execução ACP incluído: tempo de execução Node.js + módulos ACP são fornecidos dentro do pacote de desktop para comunicação de agente pronta para uso (#5814, #5794)
  • Gesto do DevTools: logotipo 8× click abre o Chromium DevTools para depuração (#5805) Segurança e sandbox
  • Sandbox do Windows AppContainer: execução de código isolada por meio do AppContainer nativo do Windows API (#5525)
  • Linux bubblewrap sandbox: Monte o isolamento do namespace via bwrap para execução de código Linux (#5310)
  • Alternância de segurança da ferramenta Cron: sinalizador por trabalho para exigir/ignorar a aprovação da ferramenta para tarefas agendadas (#5847)
  • Detecção de comando perigoso: ToolGuard detecta find -delete e padrões destrutivos de shell semelhantes (#5843)
  • Política de acesso: regras declarativas de permissão/negação/solicitação avaliadas por chamada de recurso Plugins
  • Ganchos de middleware AgentScope: plug-ins podem registrar middleware compatível com AgentScope com versionamento semver (#5221)
  • Catálogo controlado por versão: o mercado de plug-ins e CDN mostram apenas plug-ins compatíveis com a versão do QwenPaw em execução (#5661)
  • Ganchos de ciclo de vida: gancho on_uninstall, correções de validador e provedor de habilidades públicas API para autores de plug-ins (#5008) Ferramentas
  • web_search e web_fetch: ferramentas integradas de pesquisa e busca na web com identidade do produto (#5890)
  • Opção show_file grep_search: Adicione o sinalizador show_file para exibir o conteúdo do arquivo correspondente (#5840)
  • Transmissão de erro da ferramenta: estado de erro do resultado da ferramenta encaminhado ao frontend para melhor UX (#5912) CLI
  • cron update: Edite agendamento/prompt/configuração de tarefas cron existentes sem excluir+recriar (#5210) Observabilidade
  • Langfuse 2.0: Agrupamento de rastreamento restaurado via integração de gancho; cada loop de agente é um intervalo de geração Langfuse (#5511)

🔄 Alterado

  • relay_reasoning: preserve_thinking renomeado para relay_reasoning; o padrão é desativado para DashScope para evitar raciocínio duplicado na saída (#5876)
  • Limitação de taxa: Limitação de taxa multidimensional (IP + usuário + endpoint) com janelas configuráveis (#5738)
  • Ciclo de vida da memória: comando /compact retrabalhado; novo comando /system_prompt; estado de pesquisa simplificado para evitar incorporações obsoletas (#5450, #5815)
  • Componente SessionItem: todos os renderizadores de sessão consolidados em um componente SessionItem (#5754)
  • Skill UI: componentes SkillPool/SkillMarket refatorados; CSS morto removido (#5753, #5532)
  • Modo de plano removido: a configuração do agente não inclui mais plan_mode; Referências de UI limpas (#5605, #5618)
  • Retenção de versão do plugin: Versões antigas do plugin mantidas em disco após atualização; estado de falha de carregamento limpo na próxima inicialização (#5695)
