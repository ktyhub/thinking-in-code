#QwenPaw v1.1.6

✨ Adicionado

Sistema de Agente

  • Diagnóstico do Windows: qwenpaw doctor agora verifica problemas de ambiente específicos do Windows, incluindo suporte a caminhos longos, modo de linguagem PowerShell e comprimento do caminho do diretório de trabalho (#4032)
  • Status do agente API: novo endpoint GET /agents/{agentId}/agent-status relatando o status do tempo de execução do agente, contagem de tarefas em execução e carimbos de data/hora da tarefa (#4107)
  • Isolamento de sessão Cron: Cron jobs agora suportam uma opção share_session — quando desativado, cada execução agendada cria um contexto de sessão isolado com um ID de cron job (#4117)
  • GPT Image 2 Plugin: Novo plugin de ferramenta para geração de imagens por meio do GPT Image 2 API da OpenAI (#3911)
  • Nome do agente controlado por configuração: use o nome do perfil do agente configurado em vez de um padrão codificado (#4140) Bate-papo e console
  • Entrada de voz Whisper: Substituição do Web Speech API nativo do navegador pela transcrição Whisper do lado do servidor para entrada de voz mais confiável entre navegadores (#3574)
  • Títulos de sessão gerados pelo LLM: as sessões de bate-papo agora são automaticamente intituladas pelo LLM em segundo plano após a primeira mensagem. Configurável por meio do botão "Gerar títulos de sessão automaticamente" no Agent Config (#3829)
  • Tendências de uso de token: Adicionados gráficos de linhas de tendência por modelo e por tipo de token à página de configurações de uso de token para visualizar o uso ao longo do tempo (#4080, #4094)
  • Operações de habilidades em lote: botões Ativar e Desativar adicionados à barra de ferramentas de operação em lote de habilidades com relatório de erros por habilidade (#4091)
  • Renderização de diagrama sereia: blocos de código Markdown com tag de linguagem mermaid agora são renderizados como diagramas interativos em chats e visualizações de arquivos (#4146)
  • Português do Brasil (pt-BR): Adicionado suporte completo à localidade pt-BR para a UI do console e configurações de idioma de back-end (#4009, #4143) Fornecedores
  • Volcano Engine Provider: Volcano Engine adicionado como um provedor integrado compatível com OpenAI com endpoints padrão e de plano de codificação (#3994)
  • Seleção de região do DashScope: URL base do DashScope agora pode ser modificado a partir de endpoints de região predefinidos (#4074)
  • Aliyun Token Plan Provider: Adicionado o Aliyun Token Plan como um provedor integrado (#4122)
  • Anthropic Default Max Tokens: aumento do padrão max_tokens para modelos compatíveis com Anthropic para 16.384 (#4054) Canais
  • Cartões de aprovação interativos Feishu: solicitações de aprovação de proteção de ferramentas no Feishu agora são renderizadas como cartões de botão interativos que são atualizados no local na aprovação/negação, com uma dica de link de documentação quando o retorno de chamada de ação do cartão não está inscrito (#3941, #3982)
  • Compartilhamento de sessão de grupo WeCom: Adicionado botão de alternância share_session_in_group para controlar se os membros do bate-papo em grupo compartilham uma única sessão ou obtêm isolamento por membro (#3948)
  • Contexto do remetente Feishu: O apelido do remetente Feishu agora é passado para o contexto do ambiente do agente (#4098)
  • Cartões de aprovação interativos WeCom: as solicitações de aprovação de proteção de ferramentas no WeCom agora são renderizadas como cartões de modelo interativos (#4112) Segurança
  • Proteção de passagem de caminho de arquivo estático: o serviço de arquivo estático do console agora rejeita caminhos absolutos para evitar desvio de passagem de caminho (#3973)
  • Negação automática em nível de regra: regras de segurança individuais agora podem ser configuradas para negar automaticamente chamadas de ferramenta (#4046) Habilidades e CLI
  • Teste de habilidade CLI: Novo comando qwenpaw skills test para validar o conteúdo da habilidade e executar verificações de segurança (#3999)
  • Instalação/desinstalação de habilidades CLI: novos comandos qwenpaw skills install e qwenpaw skills uninstall para gerenciar habilidades a partir da linha de comando, suportando instalações de espaço de trabalho em nível de pool e por agente (#4053)

⚡ Desempenho

  • Renderização de console: eliminou re-renderizações duplicadas estabilizando comparações de estado de pesquisa de aprovação e memorizando opções de tempo de execução de bate-papo (#4052, #4110, #4153)
  • Navegação no histórico de bate-papo: Ignore a pesquisa no histórico de bate-papo para teclas que não sejam de seta e armazene listas de mensagens do usuário em cache para evitar verificações repetidas a cada pressionamento de tecla (#4130)
  • Limpeza de pesquisa de QR: interrompa imediatamente a pesquisa de código QR e limpe os indicadores de status na conclusão da autenticação ou expiração do código (#4148)

🐛 Corrigido

Canais

  • WeCom Stream Keepalive: Mantenha o fluxo de espaço reservado "Thinking..." ativo com atualizações periódicas para evitar indicadores de status travados no WeCom (#3950)
  • WeCom Reconnect Race: Corrigida a programação de reconexão dupla e desconexão de loop de eventos cruzados no tratamento do WeCom WebSocket (#3963)
  • Tentativa de rede do Telegram: Adicionada espera exponencial e reconexão controlada para erros transitórios da rede do Telegram em vez de morrer silenciosamente (#4039)
  • WeChat Cron Buffer Flush: libera o buffer de mesclagem do WeChat imediatamente para envios cron/proativos que ignoram o caminho de conclusão normal (#4106)
  • Divisão de tabela de markdown: preserva a estrutura da tabela de markdown em blocos de mensagens repetindo linhas de cabeçalho e separadores em cada fragmento (#4119) Sistema de Agente
  • Tempo limite do agente externo: Adicionado tempo limite padrão seguro (60s) para delegate_external_agent para evitar travamentos indefinidos (#3928)
  • Recarregamento de configuração do agente: alterações no arquivo de configuração do agente agora acionam um recarregamento normal com drenagem de tarefas em vez de reinstanciação leve (#4064)
  • Persistência de configuração do agente: corrigido o editor de configuração do agente do console que eliminava configurações aninhadas ao salvar, preservando a estrutura de configuração completa (#4157) MCP
  • Tempo limite de execução do MCP: use sse_read_timeout como o tempo limite de execução da ferramenta MCP em vez do tempo limite de conexão HTTP mais curto (#4058, #4061)
  • Vazamento do ciclo de vida do MCP Client: Corrigimos o vazamento da tarefa do ciclo de vida em que o close() poderia ignorar a interrupção de uma tarefa de reconexão em segundo plano (#4152) Console e IU
  • Segurança substituta de SSE: evite falha no fluxo de SSE em texto substituto malformado, limpando o conteúdo não codificável antes da serialização (#3553)
  • CodeMirror Line Wrapping: Corrigida a quebra de linha em blocos de entrada/saída de chamada de ferramenta (#3960)
  • Nome de exibição padrão do agente: respeite o nome personalizado do agente padrão em todas as superfícies da UI (#4073)
  • Caminhos de visualização de arquivos: correção da remoção redundante de prefixo de URL em caminhos de visualização de arquivos que poderiam causar URLs quebrados (#4089) Infraestrutura
  • Restauração de backup Docker: restaure corretamente os segredos nos pontos de montagem do volume Docker trocando o conteúdo do diretório em vez de renomeá-lo (#3916)
  • Caminhos de bloco de áudio: retorna o caminho do sistema de arquivos resolvido para blocos de áudio de URL file:// e remove código redundante de manipulação de arquivo (#4021, #4048)
  • Rotação de log: Use RotatingFileHandler para rotação de log em todas as plataformas (#4076)
  • Loopback Proxy Bypass: Ignora variáveis de ambiente de proxy para verificações de integridade do loopback API para evitar falhas de conexão por trás de proxies corporativos (#4092)
  • Embalagem Conda: restaure as ferramentas de empacotamento conda antes de executar o conda-pack para evitar quebras no pipeline de empacotamento (#4093)

📝 Documentação

  • WSL2 Timeout FAQ: Adicionada entrada de FAQ para lidar com APITimeoutError ao executar no modo WSL2 NAT (#4005)
  • Atualização da documentação: documentação do site atualizada para refletir novos recursos (#4013)

🧪 Teste e CI

  • Testes de Unidade de Console: Adicionada configuração do Vitest com testes de unidade e componentes cobrindo Chat, camada API e componentes compartilhados (#3559, #4121)
  • Testes de fumaça de integração: Adicionados testes de fumaça de variável de inicialização e configurações/ambiente do aplicativo (#4081)
