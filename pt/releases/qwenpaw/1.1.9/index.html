#QwenPaw v1.1.9

O que mudou

✨ Adicionado

Desktop e IDE

  • Aplicativo de desktop Tauri 2.x: novo aplicativo de desktop nativo baseado em Tauri para macOS e Windows (#3813)
  • Modo de codificação: novo IDE Web com layout de três painéis — árvore de arquivos, editor com guias com revisão de diferenças in-line e um painel Git para ramificação, preparação e confirmação (#4578, #4671) Habilidades e Provedores
  • Skill Market: navegue e instale habilidades de vários provedores (Aliyun, ClawHub, ModelScope) por meio de uma nova página do Skill Market com pesquisa entre provedores (#4518, #4623)
  • Provedor OpenCode Go: OpenCode e OpenCode Go agora compartilham um único provedor com endpoints API comutáveis (#4536, #4549)
  • Aviso de navegador sem cabeça: as inicializações de navegador sem cabeça agora incluem um aviso com instruções para alternar para o modo com cabeçalho se páginas de verificação aparecerem (#4603) Sistema de Agente
  • Tempo limite da tarefa em segundo plano: submit_to_agent agora aceita um parâmetro task_timeout, também disponível por meio do sinalizador CLI --task-timeout (#4547)
  • Contexto de bloco de arquivo: os blocos de arquivo no conteúdo da mensagem agora são processados e contados com token junto com os blocos de imagem, áudio e vídeo (#4567)
  • Feedback de negação do Tool Guard: quando um usuário nega uma chamada de ferramenta, o agente recebe instruções explícitas para não tentar novamente ou tentar alternativas (#4569)
  • Sessões Cron isoladas: cron jobs não compartilhados agora são executados com contexto limpo enquanto o histórico se acumula em uma sessão unificada por job (#4602) Bate-papo e console
  • Download de arquivo no desktop: Clicking cartões de arquivo no bate-papo agora funciona corretamente no aplicativo pywebview para desktop (#4566)
  • Persistência de rascunho de entrada de bate-papo: o texto de entrada do bate-papo e a posição do cursor são salvos e restaurados na navegação da página (#4598)
  • Resumo de memória no histórico de bate-papo: o histórico de bate-papo agora inclui o resumo de memória (#4658) Canais
  • Controle de acesso unificado: sistema de lista de permissões/lista negra/aprovação pendente por canal com uma interface de console para gerenciar o acesso do usuário em todos os canais (#4565)
  • Cartão de aprovação do QQ Tool Guard: Cartões interativos com botões de teclado para ações de aprovação/recusa no canal QQ (#4667)

🔄 Alterado

  • **IU do gerenciador de plug-ins **: página do gerenciador de plug-ins redesenhada com descrições compatíveis com i18n, filtros de tipo, pesquisa de nome e recarga automática após instalação/desinstalação (#4545, #4588)
  • Validação de conteúdo de habilidades: habilidades importadas do zip ou salvas por meio do editor agora são validadas antes de serem aceitas (#4591)
  • Atualização da IU do console: layout de navegação de cabeçalho atualizado e páginas de configurações de ambientes e segurança (#4654, #4657)

🐛 Corrigido

Canais

  • Confiabilidade de mensagens do WeChat: Adicionada desduplicação baseada em conteúdo para detectar duplicatas em pesquisas; pular envios em context_token expirado; relatar falhas precisas para mensagens iniciadas por API (#4576, #4597, #4618, #4627)
  • Nomes de arquivos chineses DingTalk: nomes de arquivos chineses codificados por porcentagem em envios de arquivos agora são decodificados corretamente (#4600)
  • DingTalk DM Webhook Key: as chaves de armazenamento de webhook DM agora incluem sender_id para evitar colisão quando conversas diferentes compartilham o mesmo sufixo conversation_id (#4665) Console e IU
  • Roteamento de chave MCP Client: roteamento fixo para chaves MCP client contendo / (#4560)
  • QwenPaw Pet: Corrigida a compatibilidade do Windows, o animal de estimação ficava preso no estado Concluído em conversas consecutivas e o padrão de início automático foi alterado para ativar (#4564, #4626)
  • Visibilidade do modo escuro: Corrigimos o cabeçalho do painel plano invisível e a zona de recebimento de importação de animais de estimação no modo escuro (#4570, #4599)
  • Botão Whisper Speech: a página de bate-papo agora aguarda a verificação do provedor do Whisper antes de mostrar o botão de fala, evitando um breve flash da fala do navegador quando o Whisper está configurado (#4601) Provedores e segurança
  • Proxy Client IP: A lista de permissões de bypass de autenticação agora resolve o IP client real em vez de usar o endereço do proxy (#4562)
  • Gemini max_tokens: O provedor Gemini agora mapeia corretamente max_tokens para max_output_tokens (#4621)

🧪 Teste

  • Suíte de testes de integração: testes de integração refatorados e expandidos com cobertura mais ampla (#4561)
