herdr v0.9.2

Patch Publicado29 de set. de 2026 Fonteherdrdev/herdr Original em inglês

Esta página é traduzida automaticamente. O texto original em inglês é a referência.

rebanho v0.9.2

Mudanças importantes

  • Os gráficos do painel específico do Herdr API desapareceram. pane.graphics.info, set, clear e stream agora retornam unknown_method. Os aplicativos mostram imagens gravando gráficos Kitty padrão em seus terminais, que o Herdr renderiza nativamente. (#4561)

Adicionado

  • Os agentes podem reportar seu próprio comando de retomada. Herdr então reabre sua sessão exata após a reinicialização do servidor, sem necessidade de integração integrada. Os agentes auto-relatados também são limpos quando seu painel volta ao shell inativo. O novo guia [Adicione suporte Herdr ao seu agente] (https://herdr.dev/docs/add-herdr-support/) cobre estado, currículo e liberação para autores de agentes. (#4687)
  • Utilize mais de uma chave de prefixo: prefix = ["ctrl+space", "ctrl+s"]. Cada entrada entra no mesmo modo de prefixo e prefix+? lista todas elas. (#4653, obrigado @JJLiebig)
  • Ir para mostra cada agente e terminal como sua própria linha, agrupados por área de trabalho, com seu status e caminho. Salto para a esquerda e para a direita entre os espaços de trabalho. (#4384)
  • Vincule keys.clear_pane para limpar a tela do painel em foco e rolar para trás enquanto mantém a linha de prompt atual. Ele é desvinculado por padrão e deixa aplicativos de tela cheia, como o Vim, sozinhos. (#4383)
  • herdr machine status verifica as máquinas salvas sem avisar. herdr machine reconnect finaliza a autenticação SSH, incluindo MFA, em seu terminal. Abra o clients para verificar novamente as máquinas com falha a cada 30 segundos, portanto, nenhuma reinicialização é necessária após consertar uma conexão. (#3763)
  • Interativo machine add encontra as sessões Herdr já em execução no host e permite que você escolha uma. --label é opcional; a máquina recebe o nome de seu host SSH. (#4204, #4678, obrigado @JJLiebig e @dhh)
  • terminal session control aceita eventos terminal.mouse, portanto, a ponte clients pode click botões em aplicativos que permitem relatórios de mouse. (#4685)
  • Os agentes restaurados iniciam um de cada vez, com intervalo de 100 ms por padrão, em vez de todos de uma vez. Altere o espaçamento com [session] startup_per_agent_delay_ms. (#4102, obrigado @JJLiebig)

Alterado

  • As imagens são renderizadas de forma mais rápida e confiável. O Local Ghostty recebe dados de imagem por meio de arquivos temporários em vez da saída do terminal. Pop-ups e notificações cortam imagens em torno de si mesmas, em vez de ocultá-las. As imagens que saem da visualização permanecem carregadas, portanto, rolar para trás não as reenviará mais. (#4561, #4652, #4686)
  • Conexões SSH solicitam compactação. Em links lentos, os painéis remotos são atualizados após a rolagem em uma fração do tempo. (#4340)
  • A saída de rolagem em máquinas salvas envia apenas as linhas que foram alteradas, reduzindo a largura de banda para logs de construção e agentes de streaming. Servidores e clients mais antigos continuam funcionando com o formato anterior. (#4711)
  • Novo conjunto de vidros TERM_PROGRAM=herdr e TERM_PROGRAM_VERSION. Eles não herdam mais IDs de sessão de terminal, como iTerm2 ou marcadores de sessão Claude Code do terminal que iniciou o servidor. (#4104)
  • Os painéis do Windows são padronizados para o PowerShell 7 (pwsh) quando ele é instalado, voltando para o Windows PowerShell. Um default_shell explícito ainda vence. (#4297, obrigado @JJLiebig)
  • Fechar a última aba de um espaço de trabalho agora pede confirmação. (#4379, #4409, obrigado @minatoaquaMK2)
  • As assinaturas de eventos fornecem rajadas completas. Um leitor que fica muito para trás agora recebe um erro events_lost em vez de pular eventos silenciosamente. (#4178, #4225, obrigado @minatoaquaMK2)
  • No Unix, enviar SIGWINCH para um Herdr client relê as cores do terminal host, para que os alternadores de tema que mudam de cor sem uma notificação de claro/escuro possam atualizar os painéis. (#4349, obrigado @dhh)

Corrigido

  • Os layouts salvos sobrevivem ao desligamento do host e às falhas nas restaurações. No Linux com logind, Herdr salva antes de o sistema desligar. Cada plataforma mantém até 48 instantâneos de layout no session-snapshots/ para recuperação manual. (#4320)
  • Cli clicar em um painel não envia mais um Escape perdido que interrompe um agente em funcionamento. (#3480)
  • A primeira tarefa de um agente agora conta como concluída, mesmo quando iniciada com um prompt. Inicialização, sessões restauradas e /new do Pi não disparam mais notificações falsas de conclusão. O status relatado pelo gancho sobrevive à transferência ao vivo. (#3338, #3990, #3916)
  • O servidor usa muito menos CPU com muitos painéis preenchidos. O navegador, as divisões de painel e os destinos nomeados permanecem rápidos em sessões grandes, e as explosões de eventos externos não param mais a renderização. (#4506, #4546, #4426, #4669, #4670, #4671, #4672, obrigado @JJLiebig e @minatoaquaMK2)
  • Os aplicativos que usam saída sincronizada não mostram mais quadros quebrados enquanto você digita. O cursor não pisca mais durante o redesenho de status ou salta em um Codex inativo no Windows. (#2968, #4303, obrigado @JJLiebig)
  • O soquete API continua aceitando conexões após um erro transitório, portanto, os comandos CLI e a transferência ao vivo não falham mais enquanto o servidor continua funcionando. (#4601)
  • As operações lentas do Git durante pesquisas na árvore de trabalho não congelam mais a digitação. (#4492, obrigado @JJLiebig)
  • worktree open não assume mais o espaço de trabalho do próprio repositório, portanto, remover a árvore de trabalho não o fecha mais. (#4293)
  • Os agentes SSH encaminhados continuam trabalhando em painéis remotos após uma reconexão. Comandos --machine repetidos abrem muito menos conexões SSH. (#1931, #4252)
  • Os painéis OpenCode V1 permanecem funcionando ou bloqueados enquanto seus subagentes são executados. Um registro existente em tui.json é respeitado em vez de regenerar tui.jsonc. (#1362, #4240)
  • O Codex não é mais relatado como inativo durante a saída ativa, seus pop-ups de menção são reconhecidos e as chaves de interrupção remapeadas não interrompem mais a detecção. (#4507, #4196, obrigado @JJLiebig e @unmanbearpig)
  • Os prompts de aprovação do Kiro são relatados como bloqueados. Os painéis inativos do Grok são ajustados com títulos OSC personalizados ou desativados. (#4203, #4372, #4333, obrigado @vinayshah1998)
  • As limpezas de rolagem do Droid são respeitadas, portanto, o cabeçalho de boas-vindas e a transcrição antiga não se repetem mais. (#4432, obrigado @factory-ain3sh)
  • O modo de cópia permanece ativo enquanto a saída continua e uma tecla de movimento é pressionada. (#3812, #4281, obrigado @marcomayer)
  • Ctrl+Shift+letra mantém Shift em painéis que não ativaram a entrada aprimorada do teclado, portanto Ctrl+Shift+C não chega mais como Ctrl+C. (#4581, #4597, obrigado @factory-ain3sh)
  • Os relatórios do mouse divididos entre leituras não vazam mais para o shell após uma mudança de foco no SSH. (#4630)
  • Windows: colas de múltiplas linhas no Claude Code não são mais enviadas na primeira nova linha e Shift+Enter é preservado. A captura do mouse sobrevive às mudanças de foco e redimensionamento, Ctrl + Win não abre mais o modo de prefixo com um prefixo ctrl+space e a colagem remota de imagem clipboard funciona novamente. (#4251, #4284, #4470, #4314, obrigado @JJLiebig)
  • Windows: OMP instalado por npm e agentes iniciados por meio de tempos de execução reforçados são detectados. machine add em um host Windows não falha mais como "não está pronto para máquinas salvas". (#4313, #4579, #4309, obrigado @JJLiebig)
  • O destaque da área de trabalho do modo de navegação é visível com theme = "terminal". A pesquisa do navegador de sessão corresponde às palavras de forma independente. A barra lateral revela agentes selecionados por cycling ou atalhos. (#4300, #4408, #4273, #4535, #4355, obrigado @minatoaquaMK2)
  • session attach sem terminal explica o problema em vez de deixar uma nova sessão em execução. (#4393)
  • As respostas de erro de soquete mantêm o ID da solicitação original, incluindo erros de configuração de assinatura. (#4344)
  • plugin install aceita opções antes do repositório. (#4446)
  • Os painéis do Windows selecionam as cores claras ou escuras do terminal host desde o início, para que os aplicativos não sejam mais padronizados para o modo escuro dentro de um terminal claro. (#1530, #4369)
  • Após herdr update, Herdr lista quais servidores em execução ainda estão na versão antiga, com os comandos exatos para reiniciar cada um, e lembra você de atualizar suas máquinas SSH salvas.
