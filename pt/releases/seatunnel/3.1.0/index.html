3.1.0 Release Note

Este é outro lançamento importante para Apache SeaTunnel seguindo a versão 3.0.0!

A versão 3.1.0 inclui 395 PRs e 11 novos conectores, com foco na estabilidade do motor Zeta e na correção dos dados do Connector-V2. Também melhora a implantação, as operações e a transformação de dados para tornar os trabalhos de integração de dados de produção mais confiáveis.

Obrigado a todos os colaboradores pelo seu trabalho árduo nesta atualização. Acreditamos que a versão 3.1.0 trará à comunidade uma experiência de integração de dados mais estável e confiável.

Destaques

  • Modo de aplicativo nativo Kubernetes: Implante um mestre dedicado e um número fixo de trabalhadores por trabalho, com limpeza automática de recursos quando o trabalho termina, fornecendo isolamento de recursos e liberação de recursos sob demanda para trabalhos únicos de processamento de dados e equipes que executam cargas de trabalho em lote em grande escala.
  • Versão mínima do Java aumentada para 11, com suporte até Java 17.
