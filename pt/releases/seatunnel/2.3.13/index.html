#2.3.13 Release Note

Este é um grande marco para o projeto Apache SeaTunnel! O lançamento da versão 2.3.13 com seus tantos novos recursos e correções aumentará significativamente a eficiência dos fluxos de trabalho de integração de dados para nossos usuários.

Estamos realmente impressionados com a dedicação e o trabalho árduo que nossos colaboradores colocaram nesta atualização e estamos confiantes de que esta nova versão será amplamente bem recebida pela comunidade.
