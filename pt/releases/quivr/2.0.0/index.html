quivr v2.0.0

##Quivr 2.0.0

Quivr é um mecanismo de código aberto para conteúdo que continua chegando. Seu aplicativo, ou fontes do Quivr (RSS, caixas de correio do Microsoft 365, listas X), enviam documentos para ele. Quivr mantém todas as versões de cada documento e torna-o pesquisável em segundos, por palavras-chave, por significado ou ambos. Ele também verifica cada novo documento em relação aos alertas salvos. Quivr não possui interface de usuário: seu aplicativo se comunica com ele por meio de HTTP API e os agentes de IA o utilizam por meio de quivr mcp.

2.0.0 é a primeira versão estável do Quivr reescrito. Os alfas foram para avaliação. A partir deste lançamento, Quivr faz promessas que você pode desenvolver.

O que 2.0 promete

  • Um API estável. O HTTP API mantém o caminho /v0 para cada versão 2.x. Uma versão 2.x apenas adiciona: novos endpoints, campos opcionais, campos de resposta e valores enum. Uma mudança que pode quebrar um client em funcionamento aguarda o próximo lançamento principal.
  • Atualizações que mantêm seus dados. Uma atualização de uma versão 2.x para outra executa o quivr migrate e, em seguida, rola o trabalhador e o API, com seus dados no lugar.
  • Plugins que verificam sua compatibilidade. Um plugin declara as versões do Plugin API que suporta e o Quivr se recusa a ativar uma que não pode executar.
  • Status claro para cada recurso. Tudo na documentação é estável no 2.x, exceto uma pequena lista de recursos experimentais, cada um marcado em sua página: ferramentas de medição de pesquisa, reclassificação de Jev e alertas julgados por Jev, o host de vetor dedicado e o binário quivr-autoscaler.

Versões e compatibilidade tem os detalhes. Limites conhecidos lista o que o 2.0 ainda não faz: pesquisa apenas texto, não possui OCR, não possui contas de usuário e possui limites de tamanho por documento e por pesquisa.

Comece

  • Experimente localmente: clone o repositório, execute make dev e siga o Início rápido, cerca de quinze minutos.
  • Instale-o em um servidor a partir das imagens de lançamento assinadas (linux/amd64): consulte Executar o Quivr em uma máquina ou Implantar e configurar o Quivr para Railway e Kubernetes.
  • Entenda primeiro: Conceitos básicos e Como funciona o Quivr.

Vindo de um alfa 2.0.0

A atualização de uma instalação alfa em vigor não é suportada. Inicie uma nova instalação do 2.0.0 ou exporte seus documentos do alfa e envie-os para o novo.

Desde 2.0.0-alpha.7

  • Segurança:
    • Quivr e suas imagens são construídas com Go 1.27.3, para CVE-2026-111943;
    • golang.org/x/net, certifi, pillow e curl e brotli da imagem SeaweedFS foram corrigidos.
  • Search se recupera após a reinicialização do banco de dados, com seus buffers restaurados e seu trabalho de hidratação limitado.
  • Importações:
    • as contagens de filas permanecem disponíveis durante importações contínuas;
    • o escalonador automático adiciona trabalhadores em massa para importações de conectores.
  • Documentação:
    • reescrito para iniciantes, com novas páginas: Como funciona o Quivr, um glossário, Versões e compatibilidade e Limites conhecidos;
    • os avisos da "fase de avaliação" desapareceram.

A lista completa de alterações desde o primeiro alfa está em CHANGELOG.md.
