#argo-cd v3.3.19

[!IMPORTANTE] AVISO DE FIM DE VIDA

Este é o lançamento final da série de lançamentos v3.3. Em 3 de novembro de 2026, esta versão atingiu o fim de sua vida útil e não receberá mais correções de bugs ou atualizações de segurança.

Ação necessária: atualize para uma versão compatível (v3.4.13, v3.5.7 ou v3.6.0).

Início rápido

Não HA:

kubectl create namespace argocd
kubectl apply -n argocd --server-side --force-conflicts -f https://raw.githubusercontent.com/argoproj/argo-cd/v3.3.19/manifests/install.yaml

HA:

kubectl create namespace argocd
kubectl apply -n argocd --server-side --force-conflicts -f https://raw.githubusercontent.com/argoproj/argo-cd/v3.3.19/manifests/ha/install.yaml

Liberar assinaturas e procedência

Todas as imagens do contêiner do CD Argo são assinadas por fiança. Uma Proveniência é gerada para imagens de contêiner e binários CLI que atendem às especificações SLSA Nível 3. Veja a documentação sobre como verificar.
