#argo-cd v3.5.7

Início rápido

Não HA:

kubectl create namespace argocd
kubectl apply -n argocd --server-side --force-conflicts -f https://raw.githubusercontent.com/argoproj/argo-cd/v3.5.7/manifests/install.yaml

HA:

kubectl create namespace argocd
kubectl apply -n argocd --server-side --force-conflicts -f https://raw.githubusercontent.com/argoproj/argo-cd/v3.5.7/manifests/ha/install.yaml

Liberar assinaturas e procedência

Todas as imagens do contêiner do CD Argo são assinadas por fiança. Uma Proveniência é gerada para imagens de contêiner e binários CLI que atendem às especificações SLSA Nível 3. Veja a documentação sobre como verificar.
