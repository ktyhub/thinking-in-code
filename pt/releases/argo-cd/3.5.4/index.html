##Changelog

Correções de segurança

  • CRÍTICO: Uma referência remota do Kustomize pode executar comandos no repo-server (GHSA-9v9p-x54c-58gc)
  • CRÍTICO: Uma página inicial de configuração do Kustomize Helm pode executar comandos no repo-server (GHSA-fw5c-w8rc-j7fx)
  • CRÍTICO: Uma importação Jsonnet pode ler arquivos do servidor repo (GHSA-m3vr-7329-44ww)
  • CRÍTICO: Restrições do AppProject ignoradas pelos ganchos de recursos PreDelete/PostDelete (GHSA-fmxq-cgp8-87wp, CVE-2026-77459)
  • ALTO: O limite de taxa de falha de login pode ser ignorado por meio de solicitações simultâneas (GHSA-4439-h7jw-5cjj, CVE-2025-61560)
  • ALTO: injeção de comando por meio de uma URL de proxy de repositório em repositórios SSH Git (GHSA-j6cw-g6p4-7hch, CVE-2026-55797)
  • MODERADO: O proxy de extensão RBAC ignora o namespace do aplicativo quando aplicativos em qualquer namespace estão habilitados (GHSA-g3ff-q88g-chrj)
  • MODERADO: Um manifesto OCI superdimensionado pode esgotar a memória do servidor repo (GHSA-w996-f2wq-x9c6)

Mudanças potencialmente prejudiciais

  • As compilações do Kustomize que renderizam gráficos do Helm não respeitam mais o helmGlobals.configHome. Os repositórios de gráficos comuns http, https e oci ainda funcionam. Compilações que dependiam de um plug-in Helm registrado nesse diretório não serão (GHSA-fw5c-w8rc-j7fx).
  • Um manifesto OCI maior que 4 MiB agora é rejeitado (GHSA-w996-f2wq-x9c6).
