claude-code v2.1.288

código claude v2.1.288

O que mudou

  • Adicionado $.ui.selection() para mods: retorna o texto que você selecionou pela última vez no modo de tela cheia e, quando a seleção estiver dentro de uma linha de transcrição, essa linha
  • Adicionado um gh api integrado para sessões de nuvem cuja imagem não possui GitHub CLI e corrigido o envio integrado de caracteres de controle de nomes de arquivos, filtros jq ou erros GitHub para o terminal
  • Adicionada recuperação para um prompt limpo com Ctrl+C: pressionar para cima no prompt vazio traz o rascunho de volta, incluindo texto e imagens colados
  • Adicionado um prompt de nova autenticação quando um servidor MCP solicita mais escopo OAuth durante uma chamada de ferramenta
  • Adicionado --max-findings <n>|all a /code-review para relatar mais ou menos descobertas do que o limite normal; a escolha é reutilizada até você passar em --max-findings default
  • Adicionado Ctrl+F para localizar uma sessão por nome e Alt+↑/↓ para alternar entre grupos na visualização de agentes; ambos, e renomear, podem ser recuperados em atalhos de teclado.json
  • Adicionado um anúncio do modo leitor de tela do novo modo de permissão quando você aprova um plano, inclusive com Shift+Tab
  • Corrigidos tempos limite de resposta intermediária do API que falhavam no turno: sessões não interativas e subagentes agora continuam a partir da resposta parcial e respostas somente de pensamento são repetidas
  • Correção de conversas longas que falhavam com "O prompt é muito longo" em vez de compactação automática quando a última resposta relatava zero uso de token
  • Corrigido o --resume que às vezes deixava cair arquivos e outros contextos que uma compactação havia acabado de restaurar
  • Corrigida uma sessão retomada que às vezes não salvava a última resposta de um turno, fazendo com que o próximo --resume mostrasse o prompt sem resposta
  • Corrigida a retomada ocasional do carregamento de uma transcrição interrompida quando a mesma sessão reescrevia o arquivo durante o carregamento
  • Corrigida a retomada de uma conversa iniciada no 2.1.286 ou anterior, eliminando o pensamento anterior do modelo
  • Correção de títulos de sessão, recall de memória e ganchos de prompt falhando no Mantle ou atrás de gateways que rejeitam saídas estruturadas; adicionou CLAUDE_CODE_DISABLE_STRUCTURED_OUTPUTS para desligar saídas estruturadas
  • Corrigidas negações do modo automático apontando para Claude uma regra de permissão do Bash quando a ferramenta bloqueada não era o Bash
  • Correção do modo automático em Bedrock e Mantle alternando para o classificador local pelo resto da sessão após uma solicitação para um modelo mais antigo, como um resumo WebFetch ou um subagente sonnet
  • Foram corrigidas sessões de nuvem que eram reiniciadas em um modelo recém-escolhido, respondendo com esse modelo depois que o servidor o recusou
  • Correção de sessões na nuvem do Cowork que ficavam marcadas como aguardando entrada após um prompt de permissão do WebFetch para um URL não aprovado ficar sem resposta por cinco minutos
  • Corrigidas sugestões de prompt que não apareciam em um telefone que ingressa em uma sessão na nuvem do Cowork iniciada em outro dispositivo
  • Corrigido um botão de mod que às vezes executava uma ação de botão diferente quando pressionado em uma visualização desenhada antes de Claude Code ser reiniciado
  • Corrigido um painel de plugin que não mostrava nada quando um elemento Code continha um diff que não era analisado; agora ele desenha como código simples
  • Servidores LSP de plug-in corrigidos recebendo espaços reservados literais ${user_config.*} e ${CLAUDE_PLUGIN_ROOT} em initializationOptions e settings em vez de valores substituídos ou padrões de manifesto
  • Corrigido o gancho tool.call de um plugin que fazia com que o Bash falhasse e as pesquisas de arquivos lessem a pasta errada em subagentes executados em uma árvore de trabalho
  • Correção de falha na instalação do plug-in git-subdir ou armazenamento em cache de um plug-in incompleto em git mais antigo (antes de 2.39, por exemplo, 2.34 do Ubuntu 22.04)
  • Corrigidos plugins carregados com --plugin-dir que não exibiam "Opções de configuração" em /plugin
  • Correção de sessões em segundo plano que terminavam quando um plugin era recarregado ou desativado enquanto um de seus temporizadores ou leituras ainda estava em execução
  • Corrigidos heredocs em sandbox com um delimitador sem aspas (python3 <<EOF) solicitando aprovação em cada execução na permissão automática de sandbox quando o corpo contém apenas texto simples e referências simples de $VAR
  • Correção da verificação de permissão da ferramenta Bash para avisar antes de uma atribuição BASHPID cujo valor o shell avaliaria como aritmético, em vez de permitir silenciosamente
  • Correção de sessões em tela cheia que saíam com "erro de interface irrecuperável" ao abrir a caixa de diálogo de tarefas em segundo plano enquanto um plugin ou mod exibia linhas acima do prompt
  • Corrigido Claude relatando uma mensagem para outra sessão como entregue quando aquela sessão a realizou: o aviso agora diz que não foi entregue e nomeia a sessão, e nas sessões SDK Claude agora pode saber disso no meio do turno
  • Corrigidos spans OpenTelemetry claude_code.tool.blocked_on_user reportando origem ou decisão unknown em sessões -p e SDK e para aprovações de gancho PreToolUse
  • Corrigidas solicitações de permissão que terminavam sem resposta, em -p ou em curva interrompida, não emitindo nenhum evento tool_decision
  • Correção de edição e nova tentativa em sessões de nuvem do Cowork recusando uma mensagem enviada antes de /compact mesmo que seu histórico ainda estivesse salvo
  • Correção de sessões autônomas (CLAUDE_CODE_RETRY_WATCHDOG) que tentavam novamente por horas após falha em um fluxo de resposta muito longo; Claude Code agora transmite novamente e desiste após três intervalos
  • Correção do relatório /login de "Login bem-sucedido" quando as credenciais não podiam ser salvas no armazenamento seguro; agora mostra a falha e oferece uma nova tentativa quando o novo login não entrou em vigor (anthropics/claude-code#73861)
  • Corrigida uma parada durante a pesquisa de credenciais do Bedrock, que às vezes movia a sessão para um modelo substituto em vez de encerrar a solicitação
  • Corrigida uma segunda abertura de login do navegador gcpAuthRefresh/awsAuthRefresh quando um laptop acorda enquanto outro processo do Claude Code está fazendo login
  • Equipes de agentes corrigidas: um agente definido por plugin gerado por nome agora é executado com seu próprio prompt, ferramentas, disallowedTools e esforço em vez dos padrões
  • Correção de sessões headless (-p / SDK) que ocasionalmente ignoravam o SIGTERM quando um supervisor como timeout ou systemd envia SIGCONT junto com ele
  • Foram corrigidas sessões de nuvem reiniciadas que restauravam um modelo que a lista de modelos impostos da organização recusava
  • Corrigidas chamadas de ferramenta MCP que às vezes eram executadas duas vezes quando o resultado de um servidor remoto ultrapassava 16 MB ou não podia ser analisado
  • Subagentes corrigidos na aba Código do Claude Desktop não obtendo nenhuma das ferramentas de um servidor MCP configurado pelo usuário chamado memory
  • Corrigido Claude no Chrome perguntando antes de cada captura de tela e leitura de página em um site que você permitiu quando o modo automático não está disponível (como no disableAutoMode ou em um modelo mais antigo); digitação, navegação e JavaScript ainda perguntam
  • Correção da falha de claude plugin install para plug-ins de origem GitHub em máquinas macOS e Linux sem chave SSH GitHub: o clone agora volta para HTTPS e imprime um aviso
  • Corrigidas entradas sandbox.credentials.files em arquivos de configuração git que não entravam em vigor enquanto permissions.blockReadsOutsideWorkingDirectories estava ativado
  • Corrigimos o problema de Claude deixando de fora os sistemas de design da sua organização ao iniciar slides ou um design com a ferramenta Artefato em planos Team e Enterprise ou máquinas com configurações gerenciadas
  • Corrigido o teclado que não funcionava no Windows após a reinicialização do Claude Code (primeiro login em um gateway de aplicativos Claude, configuração do provedor, /tui)
  • Corrigida uma trava ao iniciar um agente cujo tools: lista muitas entradas Agent(...)
  • Correção de sessões em Claude 3 Opus e Claude 3 Sonnet que falhavam a cada turno após um PDF inteiro entrar na conversa
  • Corrigido o sucesso do relatório do atualizador automático npm quando o download do binário nativo da plataforma falhava e apenas o stub claude do espaço reservado era instalado
  • Corrigida a limpeza do controle remoto arquivando uma sessão que ainda está conectada ou que acabou de ser reconectada por outro processo do Claude Code
  • Corrigidos os marketplaces do plugin owner/repo mostrando apenas o erro da segunda tentativa quando a busca SSH e HTTPS falhava; ambos os erros são agora mostrados, com o transporte tentado primeiro no topo
  • Correção de arquivos .claude/rules com escopo de caminho e arquivos CLAUDE.md aninhados que não eram carregados quando Write ou Edit criava ou alterava um arquivo em seu escopo (anteriormente, apenas Read os carregava)
  • Corrigido um rm perigoso (como um em / ou no diretório inicial) dentro de um script bash -c ou sh -c executado sem um prompt no modo bypassPermissions ou sob uma regra de permissão de shell (anthropics/claude-code#96300)
  • Corrigidas chamadas de ferramentas LSP suspensas indefinidamente quando um servidor de linguagem usa registro de capacidade dinâmica ou para de responder; as solicitações agora expiram após 60s (por servidor requestTimeout)
  • Corrigidos ganchos de notificação idle_prompt disparando enquanto agentes em segundo plano ainda estão em execução (anthropics/claude-code#93672)
  • Corrigidos os hooks PreToolUse e PermissionRequest sendo ignorados quando a correspondência deles falhava ou a entrada da ferramenta não podia ser serializada para JSON; a chamada agora está bloqueada
  • Corrigida a primeira solicitação em um ambiente novo ou após uma troca de modelo usando o limite de saída integrado e a janela de compactação automática, não o do servidor; essa solicitação agora pode esperar até 1.5 segundos
  • Corrigido o problema "O que Claude deveria fazer em vez disso?" dica exibida na linha Interrompida após enviar mensagens na fila com ctrl+enter
  • Corrigido /login em uma sessão --bare executando um login que a sessão nunca lê, o que poderia substituir seu login salvo; agora diz quais credenciais funcionam
  • Corrigido o gancho InstructionLoaded que omite agent_id e agent_type quando o acesso ao arquivo de um subagente carrega uma regra ou CLAUDE.md aninhado; regras e arquivos CLAUDE.md aninhados carregados no acesso a arquivos agora também relatam esforço
  • Corrigida a ferramenta Agente no claude mcp serve sempre reportando nenhum agente disponível e rejeitando cada subagent_type
  • Corrigido o cursor do terminal que não seguia o texto digitado na pesquisa do visualizador de transcrição em tela cheia e na pesquisa de cores personalizadas do /theme
  • Corrigido /permissions no modo leitor de tela: digitar o número de uma regra agora seleciona-o em vez de abrir a caixa de pesquisa
  • Modo automático aprimorado: quando uma conversa fica muito longa para ser revisada pelo classificador de segurança do lado client, ela agora é compactada em vez de solicitar ou falhar em todas as chamadas de ferramenta
  • Modo de leitor de tela aprimorado: anúncios curtos, como uma palavra excluída, agora permanecem na tela até a próxima tecla ser pressionada ou até que algo acima deles na tela mude
  • Modo de leitor de tela aprimorado: as perguntas respondidas nas caixas de diálogo agora dizem "respondida" ao lado da caixa
  • Melhorada a mensagem /usage-credits mostrada aos membros da equipe e da empresa cuja organização desativou as solicitações de crédito de uso
  • Sessões de nuvem aprimoradas: o primeiro turno de uma nova conversa não espera mais por um servidor stdio MCP cuja configuração define alwaysLoad: false
  • Notas "Você deveria saber" melhoradas para dizer "nós", "o agente principal" ou "você", dependendo de quem foi responsável por uma decisão
  • Melhorado o erro de gravação de banco de dados de artefato recusada no limite de tamanho do banco de dados: agora indica o limite e o que libera espaço
  • Solicitações de permissão Bash aprimoradas para fornecer um motivo mais curto quando parte de um comando não pode ser verificada antes de ser executado
  • Executor auto-hospedado: gh api integrado aprimorado: um comando gh recusado agora imprime seu equivalente gh api, --paginate segue todas as páginas das listas de um repositório e um claude aninhado não o remove mais
  • Recuperação aprimorada do Controle Remoto de uma credencial de servidor expirada: as sessões permanecem conectadas durante a renovação e são mantidas se ele desistir após uma interrupção do servidor
  • Alterado o limite de tempo de comando em segundo plano para aplicar apenas em sessões autônomas (-p, Agente SDK, CI, nuvem); terminal, aplicativo de desktop e sessões de VS Code não têm limite
  • Alterado o classificador de modo automático do lado client para ignorar um pino ANTHROPIC_DEFAULT_SONNET_MODEL que nomeia Claude Sonnet 5.5 ou Opus 5.5 e usar Claude Sonnet 5 em vez disso
  • Alterado claude project purge para claude purge; o nome antigo ainda funciona e imprime um aviso
  • Alterado o filtro n: da visualização dos agentes (e pesquisa Ctrl+F) para que Enter abra a sessão cujo nome corresponda melhor em vez da linha superior
  • /autocompact alterado para salvar a janela de compactação automática por modelo, para que cada modelo mantenha sua própria configuração quando você troca
  • Alterados os prompts de URL do MCP de servidores que não podem informar quando você terminar, para aguardar "Terminei, continue" antes que a chamada da ferramenta continue, para que você possa terminar no navegador primeiro
  • [VSCode] Corrigido um conector claude.ai que permanecia em "Necessita de autenticação" após você autorizá-lo: a caixa de diálogo dos servidores MCP agora oferece Verificar conexão
  • [VSCode] Corrigido o atalho opcional para Nova Conversa (Cmd/Ctrl+N) iniciando uma conversa em todas as visualizações visíveis do Claude, em vez de apenas naquela em que você está
  • [VSCode] Corrigida a visualização do chat retomando a próxima sessão salva após você arquivar aquela que mostra; agora ele inicia uma nova conversa
  • [Sessões na nuvem] Corrigida a opção de sessões na nuvem nas configurações de administração do Claude Code que ficavam bloqueadas enquanto uma configuração de segurança não relacionada estava sendo carregada ou falhava ao carregar
  • [Sessões na nuvem] Foi corrigido um problema ao pressionar Parar enquanto um executor auto-hospedado ainda estava iniciando, sem cancelar a mensagem na fila, que poderia então ser executada assim que o executor estivesse ativo
  • [Claude Tag] Corrigidas as configurações de administrador do Claude Tag oferecendo uma opção "Remover este escopo", que sempre falhava, em canais cujas configurações foram criadas automaticamente
  • [Claude Tag] Melhorou o Claude para também seguir um tópico relacionado do Slack em outro canal que ele apenas lê, para que as atualizações lá cheguem à conversa que depende deles
  • [Claude Tag] Erros de salvamento aprimorados na página de configuração de um canal: instruções de canal muito longas agora dizem para encurtá-las, e um salvamento recusado por perda de acesso não diz mais para tentar novamente
  • Correção de mods de relatório do claude plugin test desativados remotamente quando ele apenas lia uma configuração salva desatualizada
