claude-code v2.1.302

Patch Publicado16 de out. de 2026 Fonteanthropics/claude-code Original em inglês

código claude v2.1.302

O que mudou

  • Adicionado CLAUDE_CODE_AUTO_MODE_MODEL para escolher o modelo que o classificador de modo automático do lado client usa; isso não altera o modelo para o modo automático do lado do servidor
  • Adicionada uma linha Idle compaction ao /config para ativar ou desativar a compactação ociosa; os avisos mostrados após uma compactação ociosa agora dizem como desligá-la
  • Adicionado um aviso para /design-sync e /design-login informando que Claude Design independente (claude.ai/design) fecha em 14 de dezembro de 2026
  • Corrigido um erro "O prompt é muito longo" ao parar um turno enquanto a conversa estava sendo compactada
  • Corrigidas solicitações que falhavam com "diagnóstico: entradas extras não são permitidas" após mudar para Vertex ou Bedrock no meio da sessão
  • Corrigida a ferramenta Ler que carregava um arquivo de imagem de qualquer tamanho, ou um pipe ou dispositivo com nome de imagem, inteiramente na memória; fontes de imagem com mais de 128 MB agora são recusadas
  • Corrigido o salvamento de /autocompact e /effort no modelo errado quando um gateway nomeia Opus 4 ou 4.1 com um prefixo, como anthropic/claude-opus-4-1
  • Corrigida uma falta de cache de prompt quando uma ferramenta adicionada no meio da sessão era carregada novamente por meio do ToolSearch ou após a compactação
  • Correção de claude plugin e outros subcomandos que às vezes saíam antes da conclusão de uma configuração na fila ou gravação de configuração, o que poderia perder a alteração ou deixar um arquivo .tmp para trás
  • Correção da reclonagem de mercados de plug-ins a cada atualização e plug-ins git recém-instalados mostrando a versão "desconhecida", quando o padrão do git é o formato reftable ref
  • Correção da ferramenta PowerShell que não encontrava comandos na pasta bin/ de um plug-in e relatava um erro quando uma pesquisa que não encontrava nada (rg, grep, findstr, git grep) era canalizada para Select-Object ou outro cmdlet de formatação
  • Corrigido Claude no aplicativo de desktop apontando para as configurações de claude.ai ou /mcp para autorizar ou reconectar um servidor MCP onde essa opção não está disponível
  • Corrigidas publicações de artefatos que às vezes falhavam quando Claude enviava uma lista vazia de edições e Claude tentava novamente uma atualização de artefato da maneira errada depois que uma versão mais recente do artefato o rejeitava
  • Correção de classifier_category ausente nos eventos OpenTelemetry tool_decision para a maioria dos blocos classificadores de modo automático e novos atributos tool_decision eliminando tool_use_id, tool_source e tool_parameters quando OTEL_LOGRECORD_ATTRIBUTE_COUNT_LIMIT está baixo
  • Correção de linhas na visualização dos agentes que ficavam em branco após descer uma lista longa ou dobrar uma seção
  • Corrigido claude remote-control --help que não imprimia seu uso e saía quando não estava conectado
  • Corrigido /design consent e /design revoke sugerindo /design-login quando falhavam em uma sessão na nuvem, onde não está disponível; a mensagem agora aponta para claude.ai/design/settings
  • Correção de servidores MCP que não exibiam nenhuma ferramenta ou falhavam em todas as chamadas de ferramenta, quando o servidor negocia a versão do protocolo 2026-07-28, mas omite resultType, ttlMs ou cacheScope
  • Corrigidas sugestões de prompt para gastar créditos de uso em modelos que seu plano paga apenas com créditos: elas agora são ignoradas após uma resposta cobrada em créditos
  • Correção de URLs escritas em crases sendo clickable apenas na primeira linha quando elas quebram; todo o URL agora é um link em terminais que suportam hiperlinks
  • Corrigido claude plugin details <name>@builtin sugerindo claude plugin list, que nunca mostra plugins integrados, quando o plugin não é encontrado; agora aponta para /plugin
  • Corrigido um emoji em que um link começa dentro de uma coluna muito larga, o que o escondia nas visualizações das perguntas e transformava tabelas em listas
  • Corrigido o isolamento da árvore de trabalho, recusando-se a criar ou retomar árvores de trabalho no git 2.56 ou posterior quando um arquivo .git perdido aponta para um diretório que não existe
  • Corrigido o custo e o uso de uma sessão na nuvem, reiniciando do zero após a sessão ser retomada em um novo processo
  • Executor auto-hospedado: Corrigida falha nas buscas do git com "refs/heads de objetos inválidos" em sessões que reutilizam um checkout armazenado no formato reftable do git
  • Windows: Corrigido cada gravação de arquivo recusada ou questionada para projetos em unidades exFAT ou FAT32, inclusive em sessões iniciadas com --plugin-dir
  • Tempo de inicialização aprimorado com muitos plug-ins ativados: os arquivos de comando e agente do plug-in agora exigem muito menos chamadas do sistema de arquivos para serem carregados, principalmente no Windows
  • Modo automático aprimorado com o classificador do lado do servidor: uma conversa muito longa para a verificação de segurança agora é compactada, em vez de todas as chamadas de ferramenta verificadas serem negadas
  • Melhorou a mensagem quando uma sessão em segundo plano reaberta de outra pasta não tem gateway LLM: agora diz o porquê, em vez de "Não conectado"
  • Alteradas as sessões do claude -p e do Agente SDK sem modo de permissão para iniciar no modo default em provedores terceiros, com telemetria desligada ou em uma nova instalação; --permission-mode auto mantém automático
  • Alterados os subagentes fork (subagent_type: "fork") para estarem ativados por padrão no claude -p, no Agente SDK, no aplicativo desktop e no VS Code, pois já estão no terminal; CLAUDE_CODE_FORK_SUBAGENT=0 os desliga e claude mcp serve nunca os oferece
  • Alterado o aplicativo desktop e o VS Code para sempre executar os subagentes da conversa principal em segundo plano, como faz o terminal, ao invés de deixar Claude escolher; as chamadas de agente do próprio subagente em claude -p, o agente SDK, o aplicativo de desktop e o VS Code agora são executados em primeiro plano por padrão
  • Alterada a dica de rodapé do ← for agents para ocultar 10 segundos após a abertura de uma sessão; a contagem de agentes esperando por você ainda aparece
  • Alterado o local onde as instruções do Claude no Chrome ficam no prompt do sistema para que novas conversas possam lê-las no cache de prompt compartilhado
  • Alterados os ganchos de prompt e agente para que no máximo 12 eventos sejam executados por vez; o resto espera a sua vez
  • Alterada a mensagem mostrada quando a política da sua organização desativa o /feedback: agora aponta para problemas do GitHub em vez de um administrador da organização
  • [VSCode] Corrigido o texto após um bloco de código não fechado em uma lista, exibido como texto simples enquanto uma resposta é transmitida e depois se transforma em código
  • [VSCode] Foi corrigido o login do servidor MCP a partir do painel, abrindo uma página de autorização quebrada quando o URL do servidor contém uma string de consulta
  • [VSCode] Corrigido o banner @browser dizendo "Navegador conectado" quando nenhum navegador com a extensão Claude pode ser acessado
  • [Sessões na nuvem] Adicionado um banner na página de uma rotina que informa por que sua última execução não foi iniciada, como por exemplo, sua organização atingiu o limite de sessões simultâneas na nuvem
  • [Sessões na nuvem] Corrigida a falha de "Retroceder até aqui" em todas as mensagens, exceto as mais recentes nas sessões na nuvem; executores auto-hospedados precisam do código Claude v2.1.246 ou posterior
  • [Sessões na nuvem] Corrigida a barra de status da solicitação pull em sessões na nuvem, revertendo uma solicitação pull com conflitos de mesclagem de volta para pronta enquanto GitHub a verificava novamente
  • [Sessões na nuvem] Correção de execuções de rotina exibidas como Concluídas após a sessão na nuvem ser interrompida inesperadamente e como Canceladas quando arquivadas antes de serem iniciadas, em vez de falharem
  • [Sessões na nuvem] Corrigida a visualização de diferenças em sessões na nuvem sem alterações ou falhando no carregamento após o repositório GitHub da sessão ser renomeado ou movido
  • [Sessões na nuvem] Corrigida uma execução de rotina agendada que falhava parcialmente ao ser executada novamente desde o início, uma hora ou mais depois, o que poderia repetir o trabalho, como postar o mesmo relatório duas vezes
  • [Sessões na nuvem] Corrigida uma sessão na nuvem aberta que às vezes não mostrava mensagens enviadas de outro dispositivo até que você recarregasse a página ou cli fosse embora e voltasse
  • [Sessões na nuvem] Melhorou o erro mostrado quando uma sessão na nuvem falha ao iniciar: agora diz "Conexão perdida" ou "Erro no servidor" em vez de "Algo deu errado"
  • [Controle Remoto] Corrigido o painel de um subagente girando para sempre em uma sessão de Controle Remoto depois que seu computador fica offline; agora diz que o controle remoto está desconectado
  • [Claude Tag] Corrigida a mensagem "está pensando..." que permanecia sob uma menção em um canal do Slack ou DM depois que Claude respondeu editando uma de suas mensagens anteriores
  • [Claude Tag] Correção de URLs em blocos de código em uma etapa numerada ou com marcadores das respostas de Claude no Slack sendo colocadas entre colchetes angulares, o que quebrava comandos copiados
  • [Claude Tag] Corrigidas imagens HEIC, SVG, TIFF e BMP anexadas no Slack que nunca chegavam a Claude; eles agora chegam como arquivos em seus arquivos de trabalho, como outros tipos de arquivos
  • [Claude Tag] Corrigida a perda de acesso de novos gerentes de canal a Claude no Slack em organizações que restringem Claude Tag por função; a função de gerente agora também é concedida a Claude Tag no Slack
  • [Claude Tag] Corrigidos conectores personalizados cujos servidores MCP compartilham um host aparecendo como um único conector nas configurações de administração do Claude Tag; cada servidor agora é seu próprio conector
  • [Claude Tag] Corrigido Claude no Slack às vezes respondendo uma mensagem direta com "DMs estão temporariamente indisponíveis" e descartando-a quando uma única pesquisa do Slack travava; agora ele tenta novamente primeiro
  • [Claude Tag] Corrigidas mensagens diretas com Claude em um Enterprise Grid do Slack ignorando o menu suspenso do espaço de trabalho do Slack; eles agora são executados no espaço de trabalho conectado em que você abriu Claude pela última vez
  • [Claude Tag] Corrigido o aviso de Claude no Slack sobre o limite de gasto mensal de um canal, dizendo que um gerente de canal pode aumentá-lo; agora nomeia o proprietário da organização e vincula a página de uso
  • [Claude Tag] Corrigidos links nas respostas do Claude no Slack absorvendo as marcas de fechamento em negrito ou itálico, ou pontuação de largura total, logo após eles, o que quebrava o link e a formatação
  • [Claude Tag] Pesquisa de repositório aprimorada nas configurações de administração do Claude Tag para cobrir até 100 contas GitHub conectadas e encontrar repositórios privados após os primeiros 5.000 de uma instalação do aplicativo GitHub
  • [Claude Tag] Melhoria na adição de local nas configurações de administração do Claude Tag para listar um canal que você digita ou cola imediatamente, em vez de apenas depois que a lista completa de canais da sua organização for carregada
  • [Claude Tag] Adicionar > Domínio aprimorado na página de um espaço de trabalho ou canal nas configurações de administração da Claude Tag para estar disponível assim que a página for carregada, não apenas após o carregamento de cada canal
  • [Claude Tag] Alteradas as configurações de administração do Claude Tag para organizar o acesso de Claude em quatro guias: Pacotes, Conectores, Habilidades e plug-ins e Canais
  • [Claude Tag] Alterou a página Funções nas configurações da organização para agrupar as funções criadas para os gerentes de canal da Claude Tag em uma seção recolhida abaixo das funções da própria organização
  • [Revisão de Código] Corrigida a configuração da Revisão de Código que não era retomada após você sair para conectar o GitHub; de volta às configurações de administrador, agora ele reabre no seletor de repositório
