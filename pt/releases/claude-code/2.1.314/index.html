código claude v2.1.314

O que mudou

  • Adicionado permissions.blockWritesOutsideWorkingDirectories: Write, Edit e NotebookEdit recusam caminhos fora dos diretórios de trabalho em todos os modos de permissão
  • Adicionada uma lista groups opcional aos upstreams do gateway de aplicativos Claude: apenas os desenvolvedores nos grupos de IdP listados são enviados para esse upstream, também no failover
  • Adicionado guardrail_trace aos upstreams Bedrock do gateway de aplicativos Claude, para registrar qual filtro de proteção do Amazon Bedrock foi acionado em uma solicitação, sem o texto correspondente
  • Adicionada compactação ociosa ao VS Code e à guia Code do Claude Desktop: uma conversa de token de mais de 200 mil deixada ociosa é resumida e o resumo é usado em sua próxima mensagem se o cache de prompt tiver expirado
  • Foram corrigidas as sessões que falhavam turno após turno com "Nível de esforço inválido" quando o administrador de uma organização limita o esforço de um modelo: Claude Code agora reduz o esforço, tenta novamente e diz qual nível usa
  • Corrigido claude -p saindo com código 0 e sem saída quando a inicialização falhava; agora imprime o erro e sai 1
  • Corrigidas sessões de Bedrock com muitas imagens falhando a cada turno e /compact com "400 Input é muito longo." em vez de remover imagens antigas e compactar
  • Correção de falha nas sessões do Microsoft Foundry quando o recurso não tem implantação para o modelo padrão Sonnet, Opus ou Haiku: Claude Code agora recorre a um modelo mais antigo dessa família
  • Corrigidas solicitações recusadas repetidas atrás de um gateway que não aceita blocos tool_reference da pesquisa de ferramenta: a solicitação é enviada novamente uma vez sem pesquisa de ferramenta e a sessão lembra
  • Corrigidas falhas nas conexões TLS com UNABLE_TO_GET_ISSUER_CERT quando o armazenamento de certificados do sistema mantém um certificado raiz renovado com assinatura cruzada com seu antecessor
  • Servidores MCP corrigidos que também funcionam sem login mostrando "precisa de autenticação" após o login armazenado parar de funcionar; eles agora são usados desconectados
  • Corrigido o sucesso do relatório do claude mcp logout quando o login do MCP não era removido, por exemplo, enquanto as chaves do macOS estavam bloqueadas por SSH
  • Corrigidas renovações extras de login quando várias sessões compartilham um login de perfil Antrópico e o bloqueio de credenciais está ocupado
  • Corrigido claude ultrareview e claude remote-control fazendo a pergunta trust do workspace em um job de CI que possui terminal; com o CI definido, eles agora recusam uma pasta untrusted de uma só vez
  • Corrigidas configurações TLS trust de um administrador em configurações gerenciadas que não eram aplicadas nas sessões do Claude Desktop
  • Corrigida a troca de modelo sendo recusada em máquinas com configurações de plug-in gerenciadas quando um de seus próprios plug-ins --plugin-dir ou --plugin-url tinha um manifesto quebrado ou falhava no download
  • Corrigida a oferta de atualização dos modelos Bedrock e Vertex que voltava a cada início quando as configurações gerenciadas fixavam o modelo
  • Correção de forceRemoteSettingsRefresh definido apenas em configurações gerenciadas remotamente que não se aplicavam mais depois que a cópia armazenada expirava, o que permitia que as sessões iniciassem sem política quando o servidor não pudesse ser alcançado
  • Correção de "Continuar automaticamente no limite de uso" que continuava mais de três vezes sem uma solicitação sua quando uma tarefa era reiniciada entre esperas (um check-in de /goal, uma tarefa em segundo plano ou agendada)
  • Corrigidas sessões em segundo plano e na nuvem iniciadas com o Ultracode ligando-o novamente na próxima inicialização após ter sido desligado
  • Corrigida a última resposta quebrada e seus prompts de nova tentativa que permaneciam na conversa depois que Claude desistiu de uma chamada de ferramenta que não pôde ser analisada
  • Corrigido um gancho PreCompact com saída muito grande fazendo com que a compactação falhasse ou repetisse; a saída de cada gancho agora é reduzida em 10.000 caracteres
  • Correção de atualizações de diferenças em segundo plano que tomam brevemente o bloqueio de índice do repositório, o que poderia fazer com que um comando git executado no mesmo momento falhasse com "Não é possível criar '.git/index.lock': Arquivo existe"
  • Tabelas de markdown corrigidas saltando entre layouts de grade e empilhados em linhas digitadas pela metade durante o streaming e tabelas longas retornando para tubos brutos
  • Corrigido o seletor /resume mostrando o texto de CLAUDE.md ou CLAUDE.local.md como título de uma sessão quando a sessão executava apenas comandos de barra
  • Corrigida a resposta de /btw na conversa principal quando questionado na transcrição aberta de um subagente
  • Corrigida a colagem de uma imagem via SSH em uma máquina Linux sem fazer nada silenciosamente; o prompt agora diz para copiar o arquivo e colar seu caminho
  • Corrigidas sessões claude remote-control que falhavam ao iniciar quando o serviço de sessão ficava lento por um momento: o registro do trabalhador agora é repetido com esperas crescentes
  • Corrigidas alterações de modelo no Controle Remoto que demoravam mais de 8 segundos, obtendo um erro "ainda pendente" em vez do resultado final
  • Corrigida a descrição da configuração do sandbox.excludedCommands dizendo que os comandos listados sempre são executados fora do sandbox; agora diz que cada comando em uma chamada deve corresponder a uma entrada
  • Corrigidas chamadas de shell e MCP que bloqueavam o modo automático, uma regra de negação ou um gancho PreToolUse ou que de outra forma não eram executadas, como se fossem executadas em um grupo de ferramentas recolhido
  • Corrigidas proteções de sandbox que não se aplicavam a uma árvore de trabalho inserida por claude -p --resume ou --continue
  • Corrigidos ganchos correspondentes ao Bash que não rodavam em comandos shell iniciados pela ferramenta Monitor; tais ganchos podem bloquear ou perguntar, mas não aprovar ou reescrever esses comandos
  • Corrigido um arquivo de configurações excluído com --setting-sources ainda fornecendo algumas configurações, como regras de modo automático e consentimentos de permissão salvos
  • Corrigido o modo automático informando uma chamada como bloqueada e listando-a no /permissions, quando sua verificação de segurança não dava veredicto
  • Correção de um upstream do Vertex do gateway de aplicativos Claude travando por minutos quando um endpoint de token do Google aceita a conexão e nunca responde
  • Corrigido o aviso de inicialização do gateway de aplicativos Claude para uma chave obsoleta do Claude Desktop que ainda serve como escrito dizendo "deixa de ser aceito" após a data de término da chave
  • Corrigido /upgrade abrindo o navegador e iniciando novo login para planos faturados através da App Store ou Google Play; agora diz onde mudar o plano
  • Corrigido --resume, e retrocedendo após uma mudança para outro modelo após uma recusa, movendo uma sessão em um nome de modelo que Claude Code não reconhece para um modelo diferente
  • Corrigidas solicitações que falhavam quando um gateway ou provedor de nuvem recusava um dos cabeçalhos beta do Claude Code pelo nome: a solicitação era enviada novamente sem ele
  • Correção de IDs de modelo escritos com um ponto atrás de um gateway LLM, como claude-opus-4.8, sendo tratados como um modelo mais antigo com janela de contexto, limite de saída, esforço, modo de pensamento e custo incorretos
  • Corrigido controle remoto clients mostrando uma linha perdida "Compactado (ctrl + o para ver o resumo completo)" após /compact
  • Corrigida a dica de sessões na nuvem e o aviso de inatividade do Controle Remoto mostrando quando a política de uma organização desativa esses recursos
