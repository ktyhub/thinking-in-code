código claude v2.1.312

O que mudou

  • Adicionado oidc.user_id_claim ao gateway de aplicativos Claude, para identificar pessoas por uma declaração id_token diferente de sub, como oid do Microsoft Entra ID
  • Adicionado click para enviar: em tela cheia, cli clicar na dica "para enviar agora" em uma mensagem na fila a envia imediatamente, como sua chave faz
  • Corrigidas configurações gerenciadas e política da organização que não eram buscadas durante o restante da sessão após fazer login na extensão do VS Code
  • Corrigido Claude sobrescrevendo um CLAUDE.md muito grande, arquivo de regras ou arquivo @-incluído em um subdiretório após ver apenas seu início; Escreva agora pede para Claude ler tudo ou editar no local
  • Correção de habilidades por diretório e paths: não encontradas após um Bash cd mais profundo em um repositório git
  • Corrigido um caso raro em que a primeira resposta após retomar uma sessão no terminal poderia estar faltando na próxima vez que a sessão fosse retomada
  • Corrigido um comando com um nome inválido que impedia o carregamento de todos os comandos, o que poderia deixar claude -p sem saída
  • Corrigida a falha da ferramenta de leitura que às vezes falhava em páginas PDF com "pdftoppm falhou: não foi possível gravar a imagem" quando a limpeza de arquivos de sessão antigos era executada ao mesmo tempo
  • Corrigido o botão giratório, valores OpenTelemetry effort e transcrições nomeando um nível de esforço recém-escolhido durante uma tarefa antes do modelo aplicá-lo; agora mostram o nível em vigor
  • Corrigido o aviso de cache /model e /effort informando que a releitura aguarda sua próxima mensagem; uma alteração feita enquanto Claude está trabalhando pode acioná-la mais cedo
  • Corrigidas algumas sessões que apareciam como esperando por você quando a última mensagem mencionava apenas itens esperando por você no meio da frase
  • Correção da visualização do agente restaurando o texto de entrada na próxima inicialização após ter sido limpo com Ctrl+C logo antes de sair
  • Correção da reabertura da visualização do agente no modo shell após sair com Ctrl+D de uma entrada ! vazia
  • Corrigido o modo vim d, c e y com uma contagem gj ou gk maior que as linhas restantes excluindo ou copiando texto; como o Vim, agora eles apenas movem o cursor
  • Corrigido /verify mostrando uma descrição longa destinada a Claude em /help e o menu de comando / em vez de uma curta
  • Melhorado o indicador de esforço do prompt: uma alteração feita no meio da tarefa agora diz que pode esperar pela sua próxima mensagem, e a nota é apagada quando não se aplica mais
  • Erros WebFetch aprimorados em sessões de nuvem: um host que não resolve agora é explicado como possivelmente fora dos domínios de rede permitidos, então Claude nomeia o host para permitir
  • Bedrock, Vertex, Foundry e Mantle foram alterados para usar o prompt de sistema mais curto para nomes de modelos que Claude Code não reconhece, como nomes de implantação personalizados e ARNs de perfil de inferência, mesmo quando eles frontam Sonnet ou Haiku; configure CLAUDE_CODE_SIMPLE_SYSTEM_PROMPT=0 para manter o prompt completo
  • Mudanças automáticas de modelos após uma mensagem sinalizada para cobrir também nomes de modelos que Claude Code não reconhece, como nomes de implantação personalizados; configure CLAUDE_CODE_DISABLE_REFUSAL_FALLBACK=1 para desligá-los
  • Mensagens de limite de uso alteradas para chamar a janela de 5 horas de "limite de 5 horas" em vez de "limite de sessão"
  • Sessões de nuvem alteradas iniciadas no CLI para obter seus nomes e nomes de filiais do servidor
  • Alterados os ganchos de prompt e agente para serem executados no máximo 24 por vez por sessão, incluindo subagentes, além de no máximo 12 que esperaram mais do que o tempo limite do evento; um timeout com menos de 1 segundo agora conta como 1 segundo
  • Alterado o autoCompactWindow de um subagente para diminuir a janela definida pelo CLAUDE_CODE_AUTO_COMPACT_WINDOW, onde antes não tinha efeito; ainda nunca levanta aquela janela
  • Alterado OpenTelemetry mcp_server.name para reportar o nome real de servidores MCP remotos de URL fixa declarados por plugins do marketplace oficial da Anthropic, em vez de custom
  • Alterado o Código Claude para parar de enviar o evento claude_code.safety_event OpenTelemetry
  • [VSCode] Correção de sessões que terminavam com um código de saída simples quando as configurações da sua organização não podiam ser carregadas ou eram recusadas na inicialização; a guia agora diz o porquê e oferece Tentar novamente ou Entrar novamente
  • [VSCode] Alteradas as redefinições do limite de uso para mostrar a hora do relógio ("Redefinir às 15h10") e para dizer "Limite de 5 horas"
  • [Sessões na nuvem] Adicionado um nível de esforço ao seletor de modelo ao criar ou editar uma rotina executada na nuvem
  • [Sessões na nuvem] Adicionado um editor Bash com cores, números de linha e um botão Copiar à caixa de script de configuração nas configurações do ambiente de nuvem
  • [Sessões na nuvem] Melhorou a etapa mostrada quando Claude adiciona um repositório a uma sessão na nuvem: abri-lo agora mostra uma pequena tabela do que aconteceu em vez do JSON bruto
  • [Sessões na nuvem] Corrigido o reenvio de uma mensagem inalterada após uma falha no envio em uma sessão na nuvem, às vezes executando-a duas vezes
  • [Sessões de nuvem] Corrigida uma falha na criação de um ambiente de nuvem mostrando seu erro apenas como um brinde fora da caixa de diálogo aberta; agora aparece dentro da caixa de diálogo
  • [Sessões na nuvem] Corrigida a edição no menu de uma rotina na página Rotinas indo para a página da rotina sem abrir sua caixa de diálogo de edição
  • [Controle Remoto] Corrigida uma sessão de Controle Remoto desarquivada que aparecia funcionando até que um computador fosse reconectado; agora aparece como inativo
  • [Claude Tag] Melhorado o aviso de nova tentativa de Claude Tag no Slack para nomear o modelo em uso ou dizer que os limites de taxa foram atingidos, em vez de um erro genérico API
  • [Claude Tag] Corrigido o botão liga/desliga de um canal Claude Tag e as configurações do agente voltando aos padrões do espaço de trabalho quando um canal privado mais antigo do Slack se torna público e obtém um novo ID
  • [Claude Tag] Corrigido Claude no Slack que não respondia em canais cujo ambiente tem acesso à rede definido como Nenhum
  • [Claude Tag] Corrigido Claude no Slack que às vezes postava um arquivo no tópico errado quando estava respondendo em outro tópico do mesmo canal
  • [Revisão de código] Corrigida revisão de código revisando um commit desatualizado, ou nenhum, quando GitHub entregava um evento push com atraso; agora ele analisa o commit atual da solicitação pull
