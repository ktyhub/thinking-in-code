código claude v2.1.287

O que mudou

  • Adicionados Mods Claude: plugins agora podem modificar comportamentos mais profundos
  • Adicionado, você deve saber, um mod integrado onde um agente secundário cuida de você e sinaliza coisas que você ou Claude podem perder. Ligue-o com /plugin enable cc-plugin-you-should-know@builtin (para sessões próprias com telemetria ativada)
  • Adicionado filtro n:<text> à visualização dos agentes que corresponde aos nomes das sessões e tarefas; um filtro agora mostra correspondências em seções recolhidas e Enter abre a primeira correspondência
  • Adicionado prompt_text ao evento OpenTelemetry user_prompt, uma cópia de prompt para backends que aninham chaves pontilhadas; solte ou mascare-o onde quer que você solte ou mascare prompt (anthropics/claude-code#70763)
  • Adicionados prompts de URL de servidores MCP no protocolo 2025-11-25, por exemplo, para entrar. Se um servidor não se conectar mais após esta atualização, adicione "bareElicitationCapability": true à sua entrada de configuração MCP
  • Windows: Adicionado um aviso de inicialização ao negar a ferramenta Bash também desativa a ferramenta PowerShell, então Claude não tem ferramenta shell
  • Executor auto-hospedado: adicionado um gh api integrado (somente REST) para sessões que usam git gerenciado pela Anthropic em máquinas macOS e Linux onde o GitHub CLI não está instalado
  • Corrigido o modo rápido que ficava desativado em sessões remotas pertencentes a um agente sem conta de usuário, mesmo quando a organização permite
  • Corrigido o Controle Remoto que não recebia mensagens por minutos em um momento em que uma solicitação de reconexão não obtinha resposta; agora desiste após 30 segundos e tenta novamente
  • Corrigidos ganchos configurados com asyncRewake acordando Claude repetidamente com notificações de "problemas encontrados" quando o arquivo de script do gancho estava faltando; o gancho quebrado agora é relatado uma vez
  • Corrigidos os batimentos cardíacos da ferramenta que não alcançavam os hosts SDK enquanto o fluxo de resposta do modelo estava paralisado sem a chegada de dados
  • Corrigidas verificações de modelo de inicialização Bedrock e Vertex ignorando uma lista availableModels imposta, que poderia recolher /model para uma linha Opus
  • Corrigido o seletor do navegador Claude no Chrome mostrando um erro de análise JSON quando o Chrome não podia ser acessado
  • Corrigida a escolha de Fable no /model em um login claude.ai salvando o ID da versão atual, então seu padrão salvo agora segue o mais novo Fable como Opus e Sonnet fazem
  • Corrigida a alternância entre Opus 5.5 e Sonnet 5.5 (/model, opusplan) reescrevendo anúncios anteriores de ferramentas MCP, o que poderia eliminar o pensamento estendido anterior
  • Corrigidos blocos do Amazon Bedrock Guardrails que chegavam no meio da resposta, terminando o turno com um erro API em vez da mensagem do guardrail quando a resposta começava com pensamento
  • Corrigido um rm perigoso (como um no / ou no diretório inicial) perdendo sua proteção sempre perguntada quando o mesmo comando também redirecionava a saída para um ~ ou caminho curinga
  • Foram corrigidas as sessões claude -p e SDK que repetiam um modelo substituto em cada mensagem posterior após o modelo ter sido trocado enquanto uma resposta estava em execução
  • Corrigido o CLAUDE.md de uma pasta sendo anexado uma segunda vez após retomar uma sessão ou após uma compactação
  • Foram corrigidas sessões em segundo plano que não podiam ser reabertas do claude agents após o agente sair e remover a árvore de trabalho em que a sessão foi iniciada.
  • Verificações de emparelhamento /advisor corrigidas: o Sonnet 5.5 agora pode avisar Opus 4.7 e 4.8, e os orientadores que o API recusaria são sinalizados antecipadamente em vez de serem descartados silenciosamente
  • Corrigidos prompts de permissão do Bash mostrando nomes de analisadores internos, como "Contém simple_expansion" em vez de uma explicação simples
  • Corrigida uma causa de sessões em tela cheia em máquinas lentas ou ocupadas que saíam com "Claude Code encerrado após um erro de interface irrecuperável" enquanto uma tecla de rolagem era pressionada durante uma longa conversa
  • Corrigidos limites de permissão por ferramenta da organização sendo eliminados silenciosamente para uma ferramenta MCP chamada __proto__
  • Corrigido Claude sendo instruído a paginar grandes resultados de MCP salvos como JSON com deslocamento e limite de leitura, que não pode dividir uma linha longa
  • Corrigido o lembrete de atribuição de commit sendo entregue dentro de um resultado de ferramenta após uma compactação
  • Corrigido modo de leitor de tela deixando o cursor longe do texto digitado em caixas de pesquisa (como /currículo e /permissões) e campos de código de login
  • Corrigido modo de leitor de tela recusando Enter sem nada digitado nas opções de resumo de /rewind, cujo contexto adicionado é opcional
  • Corrigido o modo de leitor de tela mostrando uma dica "Tab para alterar" nos prompts de aprovação, onde Tab não faz nada
  • Correção do modo de leitor de tela listando teclas de seta que não fazem nada em /permissions e /mcp e dizendo "Selecionar com números" em menus vazios ou enquanto uma caixa de pesquisa contém as teclas
  • Corrigido modo de leitor de tela deixando de fora as linhas alteradas nos prompts de aprovação de edição de arquivo e outras diferenças
  • Corrigido modo de leitor de tela enviando a tela de progresso do claude --teleport e um campo de formulário MCP enquanto está sendo verificado para o leitor de tela novamente em cada quadro giratório
  • Corrigido o CLAUDE_CODE_DISABLE_EXPERIMENTAL_BETAS que não removia o formato de saída estruturada das solicitações de título de sessão e prompt-hook, que os gateways apoiados por Bedrock rejeitam
  • Corrigido o modo de leitor de tela deixando de fora as linhas superiores de um segundo prompt de aprovação, uma linha alterada /config ou a linha do plano rejeitado quando a tela anterior era mais alta que a janela do terminal
  • Corrigido --include-partial-messages enviando message_stop de uma resposta curta com atraso ou nunca, para que os aplicativos pudessem mostrar a resposta como ainda em andamento
  • Corrigido claude agents que às vezes não mostrava o prompt de permissão que uma sessão em segundo plano estava aguardando
  • Corrigido /ultrareview dando conselhos sobre .git/info/attributes quando o upload para em um .gitattributes confirmado que ele não consegue ler, como um salvo como UTF-16
  • Correção da falha de claude remote-control ao registrar-se atrás de um proxy HTTP com um erro enganoso "Verifique as permissões da sua organização" (anthropics/claude-code#97352)
  • Corrigidos comandos Bash em sandbox no Linux herdando um identificador aberto no executável Claude Code
  • Corrigido o ponto da ferramenta de execução e três controles giratórios ainda em movimento com a configuração "Reduzir movimento" ativada e a tela de confirmação de /rebobinar atualizando seu tempo "atrás" enquanto você digita uma nota
  • Corrigidos tempos no claude agents mudando a cada segundo no modo leitor de tela; eles agora mudam no máximo a cada 10 segundos
  • Corrigido um login claude.ai revogado mostrando um API Error: 401 genérico em vez de "token OAuth revogado"; no modo -p o erro agora começa com "Falha ao autenticar"
  • Corrigidas recusas de upload do /ultrareview, aconselhando você a copiar uma variável nomeada pelo arquivo de configurações de um repositório em suas próprias configurações de usuário
  • Corrigido --output-format stream-json e SDK que não transmitiam os turnos de uma habilidade context: fork executada digitando /<skill> como prompt, como fazem para o fork da ferramenta Skill
  • Corrigido /feedback e /bug: o problema pré-preenchido do GitHub não inclui mais suas mensagens de erro recentes e a tela de confirmação agora as lista como parte do relatório
  • Corrigidas falhas nas instalações dos plug-ins claude plugin marketplace add --sparse e git-subdir com "transporte 'http' não permitido" quando o repositório é servido por http simples
  • Correção de sessões na nuvem que às vezes perdiam a conversa anterior quando a sessão era reiniciada enquanto estava sendo compactada
  • Corrigido um recarregamento do plugin que sobrepunha o download do --plugin-url na inicialização, corrompendo a cópia em cache da sessão do arquivo do plugin
  • Corrigido /desktop citando saída parcial quando a abertura do Claude Desktop expirou ou imprimiu muita saída; o erro agora nomeia a causa
  • Corrigida uma chamada de ferramenta do conector MCP que ocasionalmente era executada duas vezes ou as chamadas do conector falhavam até a reinicialização, quando o servidor alterava a versão do protocolo MCP suportada
  • Corrigidos ganchos SessionStart de plug-ins sincronizados que não eram executados em novas sessões na nuvem
  • Corrigido o resumo "N ganchos executados" da transcrição e a contagem de ganchos correspondentes do log de depuração detalhado, incluindo os retornos de chamada internos do Claude Code, para que um gancho configurado não seja mais exibido como dois
  • Corrigidos arquivos que Claude enviava da nuvem e sessões de controle remoto falhando quando o upload terminava logo após o tempo limite de 30 segundos; agora espera 35 segundos
  • Repositórios corrigidos adicionados no meio da sessão na nuvem e sessões SDK não carregando suas habilidades e plugins, e carregando CLAUDE.md tarde, depois que Claude mudou de diretório
  • Corrigidas imagens PNG, JPEG e WebP com mais de 8.000 pixels em um lado que falhava no envio de uma sessão remota; Claude agora envia uma cópia reduzida
  • Corrigidas mensagens enviadas dos aplicativos Claude com 17 a 20 arquivos anexados entregando apenas os 16 primeiros
  • Correção de sessões headless que relatavam um servidor MCP como necessitando de autenticação após uma chamada recusada, mesmo que chamadas posteriores fossem bem-sucedidas
  • macOS: sessões corrigidas de controle remoto iniciadas com o claude remote-control parando no meio da rotação quando o Mac entrava no modo de espera ocioso
  • Windows: Corrigido o travamento ou travamento do claude interativo com "Modo Raw não suportado" quando sua entrada é canalizada ou redirecionada; agora diz o porquê e sai (use -p para entrada canalizada)
  • Bedrock, Vertex, Mantle: Corrigidas verificações de disponibilidade do modelo em CLAUDE_CODE_SKIP_*_AUTH enviando um cabeçalho Authorization diferente das solicitações reais quando ANTHROPIC_CUSTOM_HEADERS o repete
  • /config aprimorado: configurações que mostram o ciclo ‹ › e avançam em ambos os sentidos com ←/→, terminais estreitos empilham cada valor sob seu rótulo e PgUp/PgDn pagina a lista
  • Erros de mercado de plug-ins aprimorados para dizer em palavras simples por que um mercado foi ignorado ou recusado e o que fazer
  • Listagens de plug-ins aprimoradas para observar quando as dependências de um plug-in não foram instaladas e a atualização de um plug-in agora tenta novamente uma instalação que não foi concluída
  • Melhorou o erro do gateway de aplicativos Claude quando o Amazon Bedrock rejeita um ID de modelo: os desenvolvedores agora veem qual modelo está indisponível e o log do gateway nomeia o ID que foi enviado
  • Sessões SDK aprimoradas para que uma mensagem enviada com prioridade "agora" não cancele mais uma busca ou pesquisa na web em execução; ele continua carregando em segundo plano
  • /memory aprimorado: as teclas de seta esquerda e direita agora ativam/desativam suas configurações, como memória automática
  • Nomes /skill aprimorados digitados no meio da mensagem: Claude agora é informado de que são habilidades, incluindo as de disable-model-invocation
  • Melhorado o contraste da borda de entrada do prompt em temas claros e do ❯ antes de suas mensagens anteriores
  • Melhor entrega de arquivos que Claude envia de sessões na nuvem e Controle Remoto: um upload que falha no tempo limite, um erro de rede ou um 502, 503 ou 504 agora é repetido uma vez
  • Melhorado o que Claude diz quando um arquivo não pode ser enviado por um motivo que pode ser temporário: agora menciona que você pode solicitar o arquivo novamente em alguns minutos
  • Melhorou o prompt de uma mensagem retida de outra sessão para mostrar a mensagem entre linhas tracejadas, correspondendo a outros prompts de permissão
  • MCP aprimorado e outros prompts de permissão de ferramenta para mostrar a chamada da ferramenta entre linhas tracejadas, correspondendo aos prompts de edição de arquivo
  • Inicialização do MCP aprimorada no modo headless: um servidor remoto cuja primeira conexão falha transitoriamente agora é tentado novamente sem esperar que o servidor mais lento termine a conexão
  • Arquivos aprimorados que Claude envia de uma sessão remota: arquivos grandes agora são transmitidos do disco em vez de serem lidos na memória, e um arquivo acima do limite de tamanho é recusado com o limite do servidor nomeado
  • Melhorada a explicação que Claude dá quando o servidor recusa um arquivo enviado de um Controle Remoto ou sessão na nuvem, como uma imagem grande demais
  • Tratamento aprimorado de grandes resultados de ferramentas MCP: menos memória, arquivos de sessão menores e nenhum upload extra para contar tokens para resultados muito acima do limite
  • Windows: Melhor velocidade da ferramenta Bash removendo um subshell executado antes de cada comando
  • Alterada uma gravação do shell por meio de um link simbólico confirmado pelo repositório em um arquivo confidencial ou fora da árvore de trabalho para nomear onde ele chega e esperar por uma pessoa, também em linhas com um alvo ~
  • Opus 4.7+ e Fable alterados para usar uma janela de contexto de 1M por padrão no Bedrock, Vertex, Foundry e no gateway de aplicativos Claude, sem sufixo [1m] (CLAUDE_CODE_DISABLE_1M_CONTEXT=1 mantém 200K)
  • Alteradas as respostas do claude agents para chegarem como mensagens na fila; comandos de barra diferentes de /stop enviados enquanto um turno está em andamento agora são executados quando ele termina
  • A ferramenta inteira Bash foi alterada para permitir regras e permitir que ganchos solicitem, e não executem, gravações de shell em arquivos. As ferramentas de arquivo do Claude Code recusam completamente (o armazenamento de perfil Antrópico, o arquivo de credenciais do host)
  • Alterada a colagem direita-click no Windows e Linux, e a colagem intermediária click no Linux, para acontecer quando o botão for liberado; afastar o ponteiro antes de soltá-lo cancela-o
  • Servidor MCP alwaysLoad: false alterado para adiar todas as ferramentas desse servidor atrás da pesquisa de ferramentas
  • Alterado modo de leitor de tela para escrever linhas novas ou alteradas sem antes pausar com o cursor no início da linha; configure CLAUDE_AX_PREPARK_MS=50 para restaurar a pausa

  • Solicitações de permissão de espera alteradas para mostrar os mais antigos primeiro, para que um novo prompt não cubra mais o que você está lendo (prompts com uma contagem regressiva ainda abertos na parte superior)

  • [VSCode] Corrigidos links de arquivos de linhas de ferramentas, links de listas de sessões e duas dicas exibidas em texto simples
  • [VSCode] Corrigido um comando ainda em execução de um agente em segundo plano mostrando como falhado após o término do turno principal
  • [VSCode] Corrigido o comando /usage ou /context do próprio usuário abrindo a caixa de diálogo da extensão em vez de ser executado quando escolhido no menu de comando
  • [VSCode] Corrigidos links de arquivos na aba de visualização do plano não fazendo nada quando clicked; agora eles abrem o arquivo como links nas respostas do bate-papo
  • [VSCode] Corrigida a falha ao abrir a entrada ou saída de uma ferramenta em uma guia do editor com "Tempo limite de espera após 1000 ms" em hosts remotos, como WSL, quando a guia demora para aparecer
  • [VSCode] Melhoria na caixa de diálogo Gerenciar plug-ins: uma falha na adição, remoção ou atualização do mercado agora diz o que deu errado
  • [VSCode] Alterada a opção "Ativado por padrão" do Claude no Chrome para conectar também as sessões do próprio editor, que ainda perguntam antes das ações do navegador
  • [Sessões na nuvem] Corrigidas falhas ocasionais de busca ou envio para GitHub quando GitHub recusava brevemente um token de acesso recém-emitido
  • [Claude Tag] Corrigido Claude postando um aviso de falha, como um aviso de limite de gastos, em um tópico do Slack quando um evento em segundo plano como a atividade do GitHub o despertava e ninguém estava esperando uma resposta
