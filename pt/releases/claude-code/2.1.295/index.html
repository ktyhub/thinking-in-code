código claude v2.1.295

O que mudou

  • Adicionado onFailure: "block" para comandos e ganchos HTTP: um gancho que não pode iniciar, expirar ou sair com um código inesperado bloqueia a ação em vez de deixá-la passar
  • Adicionado suporte ao Program Status Protocol (OSC 7501): os terminais que o implementam podem mostrar se o Claude Code está funcionando, esperando por você ou pronto
  • Adicionado texto citado ao seletor /copy, para que uma mensagem redigida seja copiada sem seus marcadores >
  • Adicionado um aviso para claude plugin install, enable, disable e marketplace add quando o arquivo de configurações no qual eles gravam não carrega
  • Adicionada uma linha no stderr, quando é um terminal, que diz o que uma execução claude -p está esperando quando permanece aberta após seu último turno
  • Adicionado suporte para timeouts.upstream_ttfb_ms no Bedrock, Vertex, Foundry e outros upstreams de nuvem do gateway de aplicativos Claude: um valor que você define agora limita quanto tempo um fluxo pode levar para iniciar lá, após o qual ele falha ou obtém um 502
  • Adicionada uma mensagem "Fundo cancelado" quando você para o turno enquanto ← está aguardando a ferramenta atual terminar
  • Adicionada uma lista models opcional a cada gateway de aplicativos Claude upstream: apenas os modelos listados são enviados para lá, também em failover, e um * em uma entrada é um curinga
  • Adicionado suporte para forceLoginMethod: "gateway" e forceLoginGatewayUrl em suas próprias configurações de usuário em máquinas sem configurações gerenciadas, para que /login abra no gateway de aplicativos Claude
  • Adicionado conselho ao claude plugin validate quando o README de um plugin não possui linha de instalação: ele imprime a linha para colar e nunca altera o código de saída, mesmo com --strict
  • Adicionado upstream_request_id ao evento de auditoria inference do gateway de aplicativos Claude: o ID de solicitação do Amazon Bedrock, do Anthropic API ou outro upstream, para casos de suporte
  • Adicionado $.ui.notify para mods: gera uma notificação nativa através de sua própria configuração de notificação e informa qual canal a enviou
  • Adicionados filhos ao Button de um mod: strings e Text, então uma linha de uma lista pode ser pressionada com um chip ou um detalhe escuro dentro
  • Adicionado CLAUDE_CODE_RETRY_WATCHDOG_MAX_WAIT_MS para limitar quanto tempo o modo de nova tentativa autônoma (CLAUDE_CODE_RETRY_WATCHDOG) aguarda os erros 429 e 529
  • Adicionado um cabeçalho request-id às respostas de inferência bem-sucedidas do gateway de aplicativos Claude, para que request_id na telemetria do Claude Code corresponda ao log de auditoria do gateway
  • Corrigidas todas as solicitações que falhavam em um modelo [1m] quando um gateway, Bedrock, Vertex ou Foundry recusava o context-1m beta; Claude Code agora reenvia sem ele
  • Corrigida a saída de texto do claude -p que fazia com que as respostas anteriores fossem interrompidas quando o trabalho em segundo plano iniciava outro turno; a resposta de cada turno agora é impressa quando o turno termina
  • Correção de servidores MCP remotos em sessões headless e SDK que permaneciam desconectados após uma interrupção de mais de 15 segundos ou reconectavam-se em um loop apertado a um servidor que descartava cada conexão logo após a conexão; quedas repetidas agora recuam, até 30s
  • Corrigidas conexões MCP remotas que eram interrompidas quando a resposta de erro de um servidor continha um nome de erro de rede
  • Servidores MCP corrigidos que repetiam um cursor de paginação sendo solicitado para a mesma página até 20 vezes a cada conexão
  • Corrigidos arquivos CSS, JavaScript e XML retornados pelas ferramentas MCP sendo salvos como .bin, o que a ferramenta Read recusa; arquivos de fontes e ícones agora também têm sua própria extensão
