claude-código v2.1.300

O que mudou

  • Adicionado virtualText às decorações de prompt de um mod: texto desenhado na caixa de prompt que nunca entra no rascunho ou no prompt enviado
  • Adicionados cache_creation_5m_tokens e cache_creation_1h_tokens ao evento OpenTelemetry api_request, dividindo as gravações de cache por tempo de vida
  • Adicionado $.ui.view({ agentId }) para mods: mostra a transcrição de um agente na visualização principal quando você pergunta, e $.ui.view({}) volta
  • Adicionado um suporte dir no Text de um mod para texto da direita para a esquerda: no Windows e no terminal do VS Code, suas linhas são lidas nessa direção e ficam alinhadas à direita
  • Adicionado /advisor na plataforma Claude na AWS; nenhum orientador é executado até que você escolha um com /advisor, advisorModel ou --advisor e CLAUDE_CODE_DISABLE_ADVISOR_TOOL=1 o desative
  • Adicionados atributos de convenção semântica OpenTelemetry GenAI para intervalos de rastreamento, como gen_ai.provider.name, gen_ai.conversation.id, gen_ai.tool.name e error.type
  • Adicionado suporte para reescrever prompt e model de um agente de fluxo de trabalho no mod hook agent.spawn, que só poderia recusar agentes de fluxo de trabalho antes
  • Adicionado o mod hook prompt.change, gerado quando o texto da caixa de prompt muda sem uma edição digitada: uma entrada de histórico recuperada, uma limpeza, um desfazer ou um preenchimento de plugin
  • Correção de sessões na nuvem informando a Claude que uma política da organização bloqueava um host quando as configurações de rede da própria sessão o faziam
  • Corrigido o aviso /autocompact sobre alto uso de token quando você escolhe uma janela menor de compactação automática
  • Corrigidos ganchos SessionEnd que às vezes não funcionavam quando você saía enquanto um comando em segundo plano ainda estava em execução
  • Corrigido claude --help nomeando uma ferramenta removida em sua descrição de --restricted
  • Corrigido claude agents que não atualizava o status de nenhuma solicitação pull quando os dados de uma delas voltavam incompletos
  • Corrigido o problema de Claude ser informado de que um agente em segundo plano foi perdido, não recuperável, após a substituição do contêiner de uma sessão na nuvem, quando o agente já havia sido retomado uma vez
  • Correção de subagentes para os quais você digitou mensagens que desapareciam de /tasks logo após terminar, não deixando nenhum caminho de volta para a conversa
  • Corrigido um agente pai completo que deixava a localização atual (seu filho mostrado reenraizado no nível superior) enquanto você estava visualizando o filho
  • Corrigida a visualização dos agentes usando uma palavra digitada como "para cima", "para baixo" ou "escape" para essa tecla quando a entrada chegava em uma explosão, o que poderia mover a espiada no meio da resposta ou limpar um rascunho
  • Correção da busca automática de ferramentas (ENABLE_TOOL_SEARCH=auto) desligada no meio de uma conversa, por exemplo, enquanto os servidores MCP se reconectam após uma retomada
  • Corrigido um login recusado por forceLoginOrgUUID deixando o token da organização recusada armazenado ou ativo após /login
  • Corrigida a visualização de diferenças nas sessões de Claude Desktop e Remote Control, não notando uma escolha seletiva conflitante ou reversão em repositórios reftables
  • Corrigido o verboso e a linha ctrl+o da ferramenta Artefato lendo Artifact("(unprintable path)") enquanto a entrada de uma chamada chega; sua linha agora mostra "Waiting…" e "Running…" como a do Bash faz
  • Corrigida a primeira entrada de transcrição escrita após retomar uma sessão sendo perdida quando uma falha cortava a última linha da transcrição
  • Correção do /branch descartando mensagens e claude purge ignorando projetos de subpastas, quando eles contêm uma linha Unicode ou separador de parágrafo (U+2028, U+2029)
  • Corrigidos os ganchos do plugin WorktreeCreate e WorktreeRemove que não funcionavam quando Claude Code começava com --worktree (ainda não com --tmux)
  • Corrigidos eventos OpenTelemetry tool_result faltando git_commit_id após git commit -q em repositórios usando armazenamento ref reftable
  • Corrigido um aviso de que o gancho prompt.submit de um mod foi reescrito ou descartado e ainda era registrado conforme digitado no evento OpenTelemetry user_prompt e na extensão de interação, e em solicitações de título de sessão
  • Corrigida uma nota destinada a Claude sobre o mod hot-reloading aparecendo na transcrição como se você tivesse digitado
  • Corrigidos ganchos de agente ignorando seu model: aliases como haiku agora são resolvidos, o modelo de um subagente não o substitui mais e um modelo indisponível recorre ao chamador em vez de permitir a ação
  • Correção de sessões --worktree que às vezes iniciavam com o commit errado quando uma tag ou branch era nomeada como um ID de commit, e seu status inicial do git nomeava um branch diferente do da nova árvore de trabalho
  • Corrigido o branch exibido como ".invalid" e --worktree falhando ao reabrir uma árvore de trabalho em repositórios usando o armazenamento ref reftable do git
  • Correção de Claude nomeando arquivos no scratchpad da sessão por um nome de arquivo simples ou caminho relativo em vez de seu caminho completo
  • Corrigidos servidores claude remote-control desistindo de renovar sua conexão após um breve erro de login, como um chaveiro bloqueado; eles agora tentam novamente e avisam quando você precisa executar o claude /login
  • Corrigida falha do --worktree em uma worktree de um repositório vazio quando o branch padrão da origem não pode ser obtido; a base de fallback agora é o HEAD do checkout atual, não o repositório principal
  • Corrigido o início do Claude Code em um terminal integrado VS Code, Cursor ou Devin Desktop, iniciando a ferramenta de linha de comando do editor duas vezes para verificar a extensão; agora lança uma vez
  • Corrigido o gancho prompt.edit de um mod que não era levantado para uma nova linha inserida com o atalho de teclado chat:newline (Ctrl+J ou um Enter rebote)
  • Corrigida uma falha de conversação a cada turno com um erro 400 quando o API rejeitava o esquema de entrada de uma ferramenta MCP; Claude Code agora envia essa ferramenta sem parâmetros para o resto da conversa
  • Corrigida a retomada de uma sessão headless ou do Agente SDK, perdendo as mensagens recentes que uma compactação havia mantido, quando a compactação seguia um corte de resposta no limite do token de saída (compactações a partir desta versão)
  • Corrigido o problema de Claude não ser informado sobre as ferramentas e instruções de um servidor MCP até a próxima chamada de ferramenta, quando o servidor terminava de se conectar após uma compactação
  • Correção de sessões de controle remoto marcadas como interrompidas enquanto ainda estavam em execução, em um computador que atende várias sessões ao mesmo tempo
  • Corrigida a retomada de uma sessão headless ou do Agente SDK, perdendo seu resumo de compactação ou trazendo de volta o histórico de pré-compactação, quando a compactação seguia uma resposta repetida ou inacabada no mesmo turno
  • Corrigido Claude pesquisando o arquivo de saída de um comando em segundo plano ou dormindo enquanto ele é executado
  • Correção de sinalizadores de recursos e implementações graduais que permaneciam obsoletas por trás de um proxy de inspeção TLS cujo certificado é trusted somente por meio do armazenamento de certificados do sistema operacional
  • Foi corrigida a impressão do claude daemon stop --any que “parava” enquanto um serviço em segundo plano travado continuava em execução: agora ele espera, força o encerramento do serviço e diz isso com a saída 1 se ainda estiver lá
  • Corrigida a saída do claude daemon stop sem saída e deixando as sessões listadas como em execução, quando a telemetria está desligada
  • Correção de gravação, edição e NotebookEdit em sessões de nuvem do Cowork relatando sucesso para um caminho em seu próprio computador, onde o arquivo nunca chegava
  • Corrigido Claude procurando por ferramentas adiadas já carregadas anteriormente na conversa quando uma sessão retoma um histórico que nunca as listou
  • Correção do texto secundário (esmaecido) com a mesma aparência do texto normal no tema ANSI escuro e em terminais de 16 cores
  • Correção de sessões na nuvem que travavam 5 minutos por turno quando a política da organização não podia ser lida; o turno agora termina imediatamente e diz o porquê
  • Correção de uma sessão na nuvem que às vezes executava uma mensagem já respondida uma segunda vez após a sessão ser reiniciada durante uma resposta longa
  • Executor auto-hospedado: Corrigido o congelamento do runner e do orquestrador (sem enquetes, desligamento do /healthz ou SIGTERM) enquanto ninguém lê sua saída; os logs mantêm os 256 KiB mais recentes e contam quedas (não no Windows)
  • WebFetch aprimorado nas sessões de nuvem do Cowork para informar ao Claude que uma página falhou momentos atrás, em vez de buscá-la novamente
  • Compartilhamento de mod aprimorado na habilidade plugin-authoring integrada: Claude verifica os arquivos de um mod em busca de chaves antes de abri-los e pergunta antes de digitalizar uma pasta fora do projeto
  • Melhorou a nota que os modelos Claude 3 recebem sobre um PDF mencionado com @, para que respondam com menos frequência sem lê-lo
  • Atualizações de artefatos aprimoradas: Claude agora aplica uma pequena alteração e republica o artefato em uma chamada, e faz edições maiores e republica em uma única resposta
  • Sessões CLAUDE_CODE_PROVIDER_MANAGED_BY_HOST alteradas para ignorar CA-bundle, tool-proxy, git TLS e variáveis de configuração git como SSL_CERT_FILE nas configurações; no Claude Desktop, apenas nas configurações do projeto
  • Alterado o comando exit para forçar o kill em segundo plano, ainda executando o 1.5 segundos após ser solicitado a parar; no modo de tela cheia eles poderiam ser deixados em execução anteriormente
  • Aba Código do Claude Desktop alterada para aplicar configurações gerenciadas quando forceLoginGatewayUrl nomeia um gateway operado pela Anthropic que serve o nome do host da sessão; esse gateway deve estar acessível no início
  • claude gateway alterado para parar no início, nomeando a chave, em uma chave de política desktop: que Claude Desktop não pode usar em um gateway, onde foi iniciado anteriormente com um aviso
  • Alteradas solicitações grandes para api.anthropic.com para usar compactação gzip mesmo quando a telemetria está desativada; configure CLAUDE_CODE_GZIP_REQUEST_BODIES=0 para desligá-lo
  • Alteração da habilidade claude-api para deixar as sessões de Agentes Gerenciados em vigor, a menos que você peça para arquivá-las ou excluí-las
  • Sessões em segundo plano alteradas para retomar um fluxo de trabalho realizado por meio da aprovação da ferramenta Fluxo de trabalho, em vez de executá-lo a partir do arquivo de transferência
  • Alteradas as transcrições da sessão local para registrar também o prompt, as ferramentas e os parâmetros do sistema de cada solicitação do API, para que uma transcrição que você escolha compartilhar possa reproduzir uma solicitação com exatidão
  • Alteradas as opções do modo /sandbox para ler "comandos Sandbox" em vez de "Sandbox BashTool"
  • Alterados os hooks PermissionRequest nas sessões de nuvem do Cowork: uma atualização do setMode na permissão de um hook agora é ignorada; o restante da aprovação ainda se aplica
  • Ganchos alterados: updatedInput dos ganchos PreToolUse e PermissionRequest agora são validados como a entrada do próprio Claude: chaves desconhecidas são descartadas e a entrada que a ferramenta rejeita nega a chamada
  • Removidas as flags --sandbox e --no-sandbox do claude remote-control, que não surtiram efeito; passar agora sai com um erro. Defina sandbox.enabled nas configurações para sessões sandbox
  • [VSCode] Adicionada a configuração claudeCode.attachSelection para impedir que o texto selecionado no editor seja adicionado às suas mensagens
  • [VSCode] Corrigido o modo rápido que permanecia ativado após o término dos créditos de uso, fazendo com que cada solicitação fosse recusada e reenviada; agora ele desliga até você ligá-lo novamente, com um aviso de erro
  • [VSCode] Corrigida a alternância do Pensamento para Desligado em modelos que sempre pensam; a alternância não é mais mostrada para esses modelos
  • [VSCode] Corrigido "Editar prompt" em uma mensagem sinalizada abrindo o arquivo ou menu de comando sobre o prompt restaurado; Digite agora envia como está escrito
  • [VSCode] Corrigido Shift+arrastar um arquivo para o prompt do Windows, inserindo um caminho /c:/… ilegível em vez de uma menção relativa ao diretório de trabalho
  • [VSCode] Corrigidas alterações nas configurações de tamanho da fonte do chat do VS Code que precisavam recarregar a janela ou serem desfeitas por uma mudança de tema; diffs e a visualização do plano agora também os seguem
  • [VSCode] Corrigido "Retomar sessão" e guias restauradas após uma recarga abrindo uma nova conversa vazia em vez de uma que foi movida para uma árvore de trabalho git
  • [VSCode] Corrigido ↑ e Enter em um comando de barra recuperado executando-o sem seus argumentos; os menus de comando e arquivo não abrem mais em um prompt recuperado até que você o edite
  • [VSCode] Corrigido Shift + arrastar um arquivo do Explorer ou de uma guia do editor para o prompt, sem inserir nada nas janelas WSL, SSH e Dev Container
  • [VSCode] Corrigido Ctrl+Alt+F alternando a visualização Focus em vez de abrir Find no Explorer, outras visualizações em árvore ou no Debug Console no Windows e Linux
  • [VSCode] Corrigida a verificação de sessões abertas em outras janelas ou terminais criando processos extras no macOS: agora inicia /bin/ps diretamente em vez de procurar PATH por ps em cada verificação
  • [VSCode] Windows: corrigida uma conversa mostrando "ainda aberta em outro lugar" após uma falha ou perda de energia, quando o Windows foi reiniciado e fornecido o ID do processo antigo para outro programa
  • [Sessões na nuvem] Corrigida a falta de "Permitir para esta tarefa" nos prompts de aprovação do Cowork para ferramentas de conector onde uma organização desativa "Sempre permitir" (regressão em 2.1.292)
  • [Sessões na nuvem] Corrigida a maioria dos comandos no menu /, perdendo suas descrições em sessões na nuvem após o envio de uma segunda mensagem
  • [Controle Remoto] Corrigida a visualização de diferenças nas sessões de Controle Remoto em claude.ai e no aplicativo de desktop mostrando arquivos excluídos e renomeados conforme modificados; requer Claude Code v2.1.296 ou posterior em sua máquina
  • [Claude Tag] Adicionado suporte para canais do Slack Connect: um proprietário ou administrador da Claude Tag pode permitir que Claude no Slack responda em canais compartilhados com outra organização; está desativado por padrão
  • [Claude Tag] Adicionado um cartão privado Permitir uma vez / Negar nos threads do Slack para ações de conector que precisam de sua aprovação, então Claude pede em vez de recusar; outros só veem que está esperando por você
  • [Claude Tag] Adicionado suporte para voz clips do Slack em Claude no Slack: Claude lê a transcrição do Slack de um clip quando o Slack tem um
  • [Claude Tag] Corrigido Claude no Slack que não respondia outro aplicativo que o marcava em um tópico sob uma mensagem que o próprio Claude postou no canal
  • [Claude Tag] O acesso alterado agrupa um administrador anexado a um canal do Slack para continuar aplicando assim que o canal se tornar um canal do Slack Connect, sem necessidade de removê-los e reanexá-los
  • [Revisão de código] Correção da revisão de código ignorando comentários @claude review de pessoas com acesso de gravação cuja associação à organização GitHub é privada; seus comentários agora iniciam uma revisão
  • [Code Review] Corrigido o comentário "pausado para este repositório" do Code Review, enviando administradores para as configurações do Code Review; agora diz quem pode consertar e vincula a página dos provedores Git
