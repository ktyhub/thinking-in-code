código claude v2.1.329

O que mudou

  • Adicionado um aviso de diálogo trust que informa onde os ganchos de uma pasta são declarados
  • Adicionado um aviso na conversa, no Claude Desktop e em outros hosts não interativos, quando os ganchos nas configurações gerenciadas falham ao carregar
  • Adicionadas as tarefas agendadas desta sessão, os wakeups do /loop, o objetivo e os garfos desta conversa no /tasks; x para um depois de perguntar
  • Adicionada uma linha "Mensagem do servidor" à página de um servidor em /mcp que mostra a mensagem de erro JSON-RPC de um servidor HTTP MCP remoto que recusa a conexão
  • Adicionada uma linha "Atualização automática do Marketplace" ao /status que nomeia os mercados gerenciados que não recebem atualizações automáticas e por quê
  • Adicionado suporte para ativar o modo de código enquanto os eventos e métricas OpenTelemetry estão habilitados; cada chamada de ferramenta que o código faz envia seus eventos; o rastreamento ainda o mantém desligado
  • Corrigido o ~/.claude.json que às vezes era redefinido para os padrões quando uma trava de rede ou bloqueio de arquivo o tornava ilegível e apagado durante um salvamento
  • Corrigidas saídas repetidas no macOS quando Claude Code conseguia ler o chaveiro, mas não salvar nele. Essa sessão agora para quando expira e diz o motivo, e outras sessões permanecem conectadas
  • Correção de /terminal-setup que corrompia as configurações do VS Code ou arquivos de atalhos de teclado em torno de comentários de bloco e relatava sucesso ao perder a ligação Shift + Enter onde keybindings.json tinha uma string não fechada
  • Correção de arquivos aceitos por meio do diff IDE sendo salvos sem a última nova linha e perdendo sua marca de ordem de byte (BOM) quando uma edição era aceita salvando o diff no VS Code
  • Corrigida a escolha de uma sessão na nuvem no /teleport substituindo sua conversa aberta: a escolha agora inicia uma nova sessão, como /clear faz, e /resume traz a antiga de volta
  • Corrigido /usage-credits solicitando aos usuários Pro e Max que fizessem login novamente após abrir o navegador, e o link desaparecia após 8 segundos se o navegador não abrisse e uma tarefa fosse interrompida para obter créditos de uso
  • Corrigido /usage informando que os créditos de uso estavam desativados quando acabaram ou atingiram o limite mensal, e /model não informando aos usuários Pro e Max quando esse limite bloqueia um modelo que funciona com créditos de uso
  • Corrigido o menu de limite de gastos mostrando seus gastos como limite mensal e agrupando suas linhas sob o ponteiro em janelas estreitas
  • Corrigido um script de linha de status que imprime sem parar, congelando o prompt e usando gigabytes de memória
  • Corrigida uma tela vazia e congelada após aprovar configurações gerenciadas enquanto o seletor --resume, a caixa de diálogo trust ou outra tela de configuração estava aguardando
  • Corrigida escolha de Padrão no /model substituindo seu modelo salvo pelo padrão da sua organização quando a linha Padrão já mostrava seu modelo salvo
  • Foi corrigido um servidor MCP sendo conectado novamente após você limpar sua autenticação enquanto uma atualização de token estava em execução
  • Corrigidas tarefas MCP em segundo plano que paralisavam após uma reconexão lenta: Claude Code agora reconecta a maioria dos servidores HTTP MCP sozinho quando um é deixado em uma versão de protocolo mais antiga
  • Corrigidos PDFs, imagens e arquivos .docx, .xlsx ou .pptx que servidores ou sites MCP enviam como application/octet-stream sendo salvos como .bin, o que impedia Claude de ler os PDFs e imagens
  • Corrigido o /code-review <pr number> que às vezes revisava o branch com check-out em vez da solicitação pull sem avisar: agora ele lê a solicitação pull com gh pr diff ou diz quando não pode
  • Corrigido /code-review parando em um prompt de permissão, na maioria dos modelos, para procurar um ~/.claude/CLAUDE.md que não existe
  • Executor auto-hospedado: Corrigido --push-outcome-on-release que às vezes excluía o branch de uma sessão no host git

  • Corrigido um loop descontrolado no Modo Código preenchendo a memória da máquina; agora está parado em um limite
