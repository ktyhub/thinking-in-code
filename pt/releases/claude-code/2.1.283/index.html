claude-code v2.1.283

código claude v2.1.283

O que mudou

  • Adicionado x-claude-code-prompt-id aos cabeçalhos de dicas do gateway para que os gateways LLM possam agrupar as solicitações que atendem a um prompt do usuário; opte por CLAUDE_CODE_GATEWAY_HINT_HEADERS=1
  • Adicionada configuração gerenciada availableModelsMatch: com "exact", uma entrada availableModels permite apenas a versão do modelo que nomeia, portanto, novos lançamentos permanecem bloqueados até serem listados
  • Adicionada configuração gerenciada deniedModels para bloquear modelos específicos, mesmo quando availableModels permite
  • Adicionadas ferramentas MCP, saídas WebFetch e WebSearch ao evento span tool.output OpenTelemetry quando OTEL_LOG_TOOL_CONTENT=1
  • Adicionado /doctor prompt-audit (também /checkup prompt-audit) para auditar seus arquivos CLAUDE.md, habilidades, agentes e comandos para padrões de prompt escritos para modelos mais antigos
  • Adicionado click-to-expand para mensagens truncadas de outras sessões em modo de tela cheia
  • Adicionado path às entradas de falha de carregamento --plugin-dir no stream-json system/init plugin_errors, nomeando o diretório que não foi carregado
  • Adicionado um bloco load_test_mode opcional à configuração do gateway de aplicativos Claude: as solicitações são criadas e assinadas, mas não enviadas upstream, e clients recebem uma resposta automática, para que uma implantação possa ser testada em carga
  • Adicionado um provedor upstream mantle ao gateway de aplicativos Claude para o endpoint Mantle do Amazon Bedrock
  • Correção de sessões SDK que perdiam uma chamada de ferramenta adiada ou resultado de ferramenta finalizada quando um turno terminava mais cedo, um prompt de aprovação retido após a reinicialização de um trabalhador e um result.usage de fallback sem streaming
  • Corrigidas notificações de progresso do MCP sendo descartadas quando uma chamada de ferramenta de longa duração era movida para segundo plano; a tarefa em segundo plano agora mostra o progresso mais recente
  • Correção de servidores stdio MCP deixados em execução quando a sessão terminava enquanto eles ainda estavam iniciando
  • Corrigido um breve HTTP 404 de um servidor MCP remoto sem estado (por exemplo, um proxy no meio da reimplantação), deixando esse servidor inutilizável pelo resto da sessão enquanto ainda era mostrado como conectado
  • Corrigida a falha de login do MCP para um servidor sem URL válido com um erro opaco SDK; /mcp não oferece mais autenticação para esses servidores
  • Corrigido o limite semanal de Fábulas que não aparecia no /usage e nos medidores de uso do VS Code quando a telemetria estava desativada
  • Corrigido /model aceitando Soneto 4.6 ou Soneto 5 com [1m] quando o id continha data ou sufixo -v1:0, nos casos em que o id simples era recusado
  • Corrigido o seletor /model mostrando uma versão e preço do Haiku codificado quando ANTHROPIC_DEFAULT_HAIKU_MODEL fixa um modelo diferente
  • Fluxos de trabalho dinâmicos corrigidos iniciados durante um modelo substituto executando todos os agentes no modelo substituto em vez de tentar novamente o modelo configurado
  • Corrigido DISABLE_PROMPT_CACHING_HAIKU sem efeito quando Haiku é o modelo principal da sessão
  • Corrigido claude plugin validate dizendo que Claude Code aceita um plugin ou nome de mercado que não pode ser instalado; tais nomes em marketplace.json agora falham na validação
  • Correção de plug-ins de passagem claude plugin validate cujos caminhos outputStyles, themes, monitors ou lspServers estão ausentes ou apontam para fora do diretório do plug-in
  • Corrigido claude plugin details mostrando 0 servidores MCP para plugins que declaram seus servidores em plugin.json
  • Corrigido claude plugin marketplace remove não dizendo quais plugins instalados ele desinstalou no marketplace; agora ele os lista
  • Corrigido claude plugin uninstall removendo o outro dos dois plugins instalados cujos ids diferem apenas no caso, com suas opções e segredos, quando aquele nomeado não tinha entrada enabledPlugins naquele escopo
  • Plugins corrigidos que declaram que nenhuma versão foi restaurada silenciosamente no commit mais recente de sua fonte, e não no instalado, quando seus arquivos em cache estavam faltando
  • Correção de plug-ins e mercados instalados pelo usuário que não carregavam com "cache-miss" após a movimentação do diretório inicial ou de configuração, por exemplo, em devcontainers montados em bind
  • Corrigido installed_plugins.json mostrando nenhum plugin quando mantém um registro com um ID de plugin inválido; esse arquivo é carregado novamente
  • Corrigido installed_plugins.json sendo reescrito, perdendo registros, quando possui um registro esta versão não consegue ler; Os comandos claude plugin agora nomeiam o registro e dizem como recuperá-lo
  • Caixas de diálogo de permissão corrigidas no modo leitor de tela lendo comandos e caminhos citados como se fossem o próprio texto da caixa de diálogo
  • Corrigido /context sem contar as instruções do servidor MCP: elas agora aparecem como sua própria linha e contam para o total
  • Corrigidos links de markdown no terminal Warp renderizados como texto simples em vez de hiperlinks clickable
  • Corrigido o sucesso do relatório de claude mcp add, add-json e remove quando o usuário ou o arquivo de configuração local não podiam ser gravados, por exemplo, dentro de uma sandbox
  • Corrigidas as primeiras palavras de uma resposta em uma sessão na nuvem que às vezes apareciam atrasadas em vez de serem transmitidas enquanto Claude as escrevia
  • Corrigido o guia de atalhos de teclado integrado do Claude, dizendo que os acordes expiram após 1 segundo em vez de 3, e chamando cmd de um alias de meta, o que poderia produzir atalhos cmd+ que a maioria dos terminais nunca envia
  • Corrigido keybindings.json aceitando silenciosamente um modificador com erro ortográfico como ctl+k; agora avisa no log de depuração e sugere a correção
  • Corrigidas dicas de rodapé que ainda diziam "Enter to view" após footer:openSelected ser rebote ou desacoplado em keybindings.json
  • Chaves corrigidas digitadas rapidamente juntas (digitação antecipada, repetição de tecla, rajadas sobre ssh ou tmux) às vezes sendo tratadas em estado obsoleto
  • Correção de verificações de árvore de trabalho com falha na verificação de certificado (por exemplo, em downloads Git LFS) quando o certificado CA é passado para git como pares de ambiente GIT_CONFIG_COUNT
  • Correção do git em sandbox solicitando aos auxiliares de credenciais que armazenassem o login do proxy sandbox, que imprimia "falha ao armazenar"
  • Corrigidas configurações gerenciadas do sandbox sendo totalmente ignoradas quando um valor aninhado era inválido; o valor inválido agora falha no fechamento e o resto do bloco ainda se aplica
  • Corrigidas as edições de Claude em suas próprias notas de memória automática sendo bloqueadas como gravações de arquivos confidenciais quando o Claude Code era iniciado em um subdiretório de um repositório git
  • Corrigido o controle remoto indisponível em planos pagos quando a telemetria está desativada com DISABLE_TELEMETRY ou DO_NOT_TRACK
  • Corrigido o menu /remote-control cortando sua dica de código QR no meio da palavra em terminais estreitos
  • Corrigido o modo vim . soltando uma nova linha Shift + Enter, deixando o cursor dentro de uma letra acentuada e repetindo uma alteração mais antiga após 3J ou modo visual J na última linha
  • Corrigido o posicionamento do cursor no modo vim: recuperar um prompt com mais de 10.000 caracteres no modo normal não deixa mais o cursor além do final, e V e depois p agora pousam no primeiro não em branco
  • Corrigido o modo vim J unindo linhas com espaçamento diferente do Vim (como um espaço antes de ) ou depois de uma tabulação) e 3J ou modo visual J na última linha sem mover o cursor como o Vim faz
  • Windows: corrigida a ferramenta PowerShell permitindo que cmd /c rd, rmdir, del ou erase excluíssem raízes de unidade, a pasta inicial e outras pastas que Remove-Item recusa
  • Melhoria na lista de ferramentas do /mcp: mostra mais ferramentas de uma vez, rola com as teclas de página e o mouse e marca as ferramentas bloqueadas pela sua organização com um ícone de aviso
  • Resultados aprimorados da ferramenta MCP: as imagens retornadas pelas ferramentas MCP agora também são salvas em um arquivo, para que Bash, Read e outras ferramentas possam abri-las
  • /tasks aprimorado: as linhas mostram um ícone de status, o nome e os fatos completos, o título e as principais dicas permanecem na tela com muitas tarefas, e a lista ganha teclas de paginação, roda do mouse e clicks
  • Listas aprimoradas em /help, /hooks, /copy, /chrome, /memory, /ide, /release-notes, /rewind, /diff, /remote-env, /plugin e outros seletores com teclas de página, roda do mouse e clicks
  • Listas aprimoradas ao lado de uma caixa de pesquisa, como /skills e /artifacts, para deixar o ponteiro esmaecido enquanto a caixa de pesquisa possui as chaves, de forma que apenas um ponteiro seja destacado
  • Melhorado o girador de compactação: seu cronômetro agora inicia quando a compactação começa e conta os tokens do resumo conforme eles são transmitidos, substituindo a barra de porcentagem
  • Melhoria na página do navegador exibida após fazer login em um servidor MCP: layout centralizado, modo escuro e nova arte
  • Melhorada a resposta da ferramenta Skill quando uma habilidade pertence a um plugin que falhou ao carregar, então Claude informa que o plugin não pôde ser carregado em vez de chamar a habilidade de desinstalada
  • prompt-audit aprimorado na configuração do Claude Code: caminhos obsoletos, comandos obsoletos e arquivos de instruções contraditórios agora lideram o relatório e pensando em palavras-chave que os documentos do Claude Code são mantidos
  • Recuperação aprimorada de um installed_plugins.json que não pode ser lido: seu conteúdo é mantido em um arquivo ao lado dele antes de ser reconstruído e o claude plugin list nomeia esse arquivo
  • Leituras aprimoradas do banco de dados de artefatos: uma consulta ordenada que retorna uma página inteira agora diz que é uma página e como ler o resto
  • Latência de primeira resposta aprimorada: uma etapa de compilação de padrões executada no final da primeira resposta de uma sessão agora é executada enquanto a resposta é transmitida
  • Latência de primeira solicitação aprimorada reutilizando a conexão API pré-conectada
  • Inicialização aprimorada: claude -p e Claude Code Remote não carregam mais a interface interativa, e as regras do classificador de modo automático e a ferramenta Artifact são carregadas no primeiro uso, em vez de na inicialização
  • Melhor inicialização para contas claude.ai cujos recursos da ferramenta Artifact ainda não são conhecidos, como na primeira execução: o prompt não espera mais até 1.5 s para verificá-los; a primeira mensagem espera se necessário
  • Alteradas sessões interativas em provedores terceiros ou com telemetria desligada para iniciar em modo automático quando nenhum modo de permissão estiver configurado; permissions.defaultMode ainda o substitui
  • Alterada a caixa de diálogo de inicialização do /ultrareview para informar que a revisão de uma filial local pode carregar alterações não confirmadas nos arquivos rastreados
  • Alterada a linha Opus do seletor /model e o nome do modelo Default para descartar "(contexto 1M)" onde o Opus já possui uma janela de contexto 1M; a janela permanece inalterada
  • Sugestões de prompt alteradas no terminal para aparecerem com menos frequência após 20 seguidas não serem utilizadas; usar um os traz de volta
  • Alterados --system-prompt e --append-system-prompt para aceitarem seus textos e formas -file juntos; o texto do arquivo vem primeiro
  • Alteradas as regras de negação de Skill(anthropic-skills:<name>) para também bloquear essa habilidade quando Claude Desktop a entrega como um plugin, e Skill(skill:<name>) nega para corresponder ao alias e nome de exibição da habilidade
  • Listas /rewind e /diff alteradas para executar as mesmas ações de atalho de teclado de todas as outras listas (select:*); As religações messageSelector:*/diff:* ainda funcionam
  • Alterada a lista de execução do /workflows para dimensionar-se como outras listas: metade do terminal inline e mantém seu título na tela quando o prompt é exibido abaixo
  • claude plugin eval alterado para exigir git 2.31 ou posterior quando o git estiver instalado; uma execução em um git mais antigo é recusada com uma mensagem nomeando a versão
  • Observação de artefato alterada: um relógio que foi armado automaticamente (não aquele que você solicitou) agora termina após 3.5 horas sem atividade; publicar ou assistir o artefato novamente o rearma
  • Executor auto-hospedado: alteração do git dos ganchos de ciclo de vida para ignorar o gancho Git LFS pre-push de um repositório, ignorar um sistema gravável core.hooksPath e não assinar commits sem --configure-git
  • Corredor auto-hospedado: GIT_SSL_CAINFO e GIT_SSL_NO_VERIFY alterados no git gerenciado pela Anthropic: o próprio git do executor sempre verifica a rota git da Anthropic, e as linhas de aviso dizem o que se aplica onde
  • Revertida a reserva 2.1.282 do nome claude-ai: habilidades, comandos, fluxos de trabalho e habilidades e prompts dos servidores MCP assim chamados carregam novamente, e as regras Skill(claude-ai:*) são regras de prefixo comuns
  • [VSCode] Corrigido o indicador do modo de permissão mostrando Padrão enquanto a sessão continuava rodando no modo automático ou bypass após uma falha na troca automática; o switch agora é tentado novamente até pousar
  • [VSCode] Corrigida uma sessão teletransportada da web deixando cair as mensagens enviadas enquanto Claude estava trabalhando
  • [VSCode] Corrigida uma sessão da Web que ficava oculta na lista de sessões e um bate-papo vazio era aberto em seu lugar, quando uma versão mais antiga salvava uma cópia local vazia dela
  • [VSCode] Corrigida uma sessão reaberta dividindo um turno em uma mensagem que Claude recebia no meio do turno, como uma continuação automática
  • [VSCode] Corrigida uma sessão recarregada mostrando uma curva rebobinada ou apenas as linhas antes de uma compactação
  • [VSCode] Corrigida a pílula de agentes do rodapé desenhando seu ícone fora do centro, com o ponto de status contra a borda, em painéis estreitos
  • [VSCode] Corrigida a entrada do chat mostrando seu texto logo abaixo do cursor e seleção após colar linhas que terminam com uma quebra de linha em um prompt longo
  • [Sessões de nuvem] Melhoria na adição de um repositório a uma sessão de nuvem em execução: um repositório privado que sua conta GitHub pode ler, mas não pode enviar por push, agora anexado para leitura
  • [Sessões na nuvem] Correção de sessões na nuvem que ocasionalmente refaziam uma etapa já concluída, como postar um comentário duplicado ou push, após a recuperação de uma reinicialização do servidor
  • [Sessões na nuvem] Novas programações de rotina foram alteradas para serem padronizadas alguns minutos depois da hora, com uma observação de que as rotinas definidas exatamente na hora podem começar vários minutos atrasadas
  • [Claude Tag] Adicionada uma configuração de administrador "Canais que Claude pode pesquisar" que limita a pesquisa de Claude no Slack aos canais públicos aos quais foi adicionado, definidos por organização, espaço de trabalho ou canal
  • [Claude Tag] Adicionado um botão Voltar ao Slack na página mostrada após conectar sua conta Claude, retornando ao tópico em que você começou
  • [Claude Tag] Corrigida a página de configuração de um canal que não lista conectores ou plugins quando o canal obtém seu pacote de acesso através de uma regra de anexação; pacotes anexados a regras agora são mostrados
  • [Claude Tag] Corrigida a pesquisa de repositórios de pacotes de acesso ausentes em instalações do aplicativo GitHub que são limitadas a uma grande lista de repositórios selecionados
  • [Claude Tag] Corrigido Claude ocasionalmente postando a mesma resposta duas vezes quando uma nova mensagem a interrompia no meio da resposta
  • [Claude Tag] Correção de rotinas de canal que paravam de funcionar em canais privados mais antigos cujo ID de canal do Slack foi alterado, por exemplo, após um compartilhamento do Slack Connect
  • [Claude Tag] Corrigidas conversas em um canal definido como "Somente canal", todas terminando quando um membro não convidado entrava e o Slack demorava para confirmar sua adesão
  • [Revisão de código] Corrigidas solicitações de "@claude review" que ficavam silenciosas quando GitHub falhava ao retornar a solicitação pull: a solicitação é repetida uma vez e um comentário explica se ainda falha
  • [Revisão de código] Corrigida a cobrança de uma revisão que parou no limite de tempo sem nada verificado: agora ela aparece como incompleta, não é cobrada e é tentada novamente uma vez
