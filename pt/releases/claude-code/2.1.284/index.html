claude-code v2.1.284

código claude v2.1.284

O que mudou

  • Adicionado Claude Sonnet 5.5 (claude-sonnet-5-5), agora o modelo Sonnet padrão no Antrópico API - contexto de 1 milhão, US$ 2/US$ 10 por Mtok com leituras de cache de US$ 0.20/Mtok
  • Adicionada uma resposta "Sim, mas pergunte novamente na próxima vez" ao prompt do modo automático antes de uma leitura fora dos diretórios de trabalho, para que você possa permitir que alguém leia e ainda seja questionado sobre os posteriores
  • Adicionados valores em dólares ao limite de gastos do gateway de aplicativos Claude em /usage e à linha de status (por exemplo "$271.40 / $500.00 gasto este mês") quando o gateway executa esta versão ou posterior; o rate_limits.spend_limit da linha de status também ganha used_usd, limit_usd e period
  • Adicionadas ações de atalho de teclado effortSlider:decreaseEffort, increaseEffort e toggleUltracode, para que a seta do controle deslizante /effort e as teclas Tab possam ser recuperadas em keybindings.json
  • Adicionado /rate-limit-options ao /help e o menu de comando para assinantes claude.ai, para que os avisos de limite de uso que o mencionam apontem para um comando que você pode encontrar
  • Adicionado /mcp reconnect all no terminal interativo para tentar novamente todos os servidores MCP que não conseguiram se conectar ou precisam de autenticação de uma só vez
  • Adicionados avisos de inicialização do gateway de aplicativos Claude quando o availableModels de uma política gerenciada está vazio ou deixa de fora o modelo em que o Claude Code inicia sem definir model ou enforceAvailableModels
  • Adicionado auth: { google: {} } para destinos telemetry.forward_to do gateway de aplicativos Claude, para que a telemetria possa ser exportada diretamente para o endpoint OTLP do Google Cloud usando as credenciais do Google Cloud do gateway
  • Adicionada autenticação de certificado client (private_key_jwt) entre o gateway de aplicativos Claude e seu provedor de identidade, para provedores de identidade que emitem credenciais de certificado em vez de segredos client
  • Corrigido um fluxo de resposta danificado mostrando erros brutos como "JSON Parse error" ou "indefinido não é um objeto", ou escrevendo a palavra "indefinido" em uma resposta, em vez de ser repetida ou relatada como uma resposta interrompida
  • Corrigido um erro de servidor sobrecarregado ou que ocorria logo após um bloco de pensamento terminar o turno com um erro em vez de ser tentado novamente
  • Corrigidos erros de "O prompt é muito longo" que persistiam após a compactação: quando a solicitação compactada ainda é muito longa, o Claude Code agora compacta mais uma vez, mantendo menos da conversa recente
  • Corrigida uma sessão cujo modelo está indisponível, sem modelo substituto restante, mostrando uma mensagem simples "está indisponível no momento" (ou "Algo deu errado" em sessões na nuvem) em vez do aviso de modelo indisponível e seu link Saiba mais
  • Correção das sessões do Agente SDK travando quando uma mensagem do usuário contém uma imagem com um source malformado e falhando a cada turno posterior após um bloco de documento malformado; uma imagem malformada agora é substituída por uma nota explicativa
  • Corrigidas chamadas de ferramenta MCP em uma sessão retomada que falhava com "Nenhuma ferramenta disponível" enquanto o servidor ainda estava conectado; a chamada agora espera até 10 segundos pelo servidor
  • Corrigidas chamadas repetidas para o endpoint de uso do plano após ele limitar a taxa ou rejeitar seu login: as visualizações de uso /usage, /extra-usage e IDE agora recuam em vez de perguntar novamente
  • Corrigido o sucesso do relatório claude mcp add quando as configurações gerenciadas restringem os servidores MCP a plug-ins; agora recusa e diz o que fazer, em vez de salvar um servidor que nunca carrega
  • Corrigida a tela de configuração do /plugin: as opções booleanas agora são uma escolha verdadeiro/falso em vez de texto livre, as opções numéricas recusam entradas inválidas e ←/→ altera um campo de opções em vez de alternar entre guias
  • Corrigido ANTHROPIC_FOUNDRY_RESOURCE sendo interpolado no host do endpoint Foundry não validado; um valor que não é um nome de recurso simples agora é recusado
  • Correção do Claude Desktop atrás de um gateway de aplicativos Claude que não oferecia opção de contexto de 1M: o gateway agora marca cada modelo compatível com 1M para Desktop automaticamente
  • Corrigido ↓ no modo shell selecionando uma pílula oculta de tarefas em segundo plano, que impedia Backspace e Ctrl+U de editar o prompt
  • Correção da falha da ferramenta Bash no Windows com muitos plug-ins ativados: os diretórios do plug-in bin/ que não existem não são mais adicionados ao PATH e as entradas herdadas não são adicionadas duas vezes
  • Correção dos mercados do plug-in sparsePaths clonando vazios e substituindo uma cópia local funcional no git mais antigo (antes de 2.39), que falhava em todas as atualizações com "o arquivo marketplace.json não está mais presente"
  • Correção da renderização em tela cheia apagando a saída do terminal acima da sessão quando [ no modo de transcrição grava a conversa em scrollback (macOS e Linux)
  • Correção da posição de rolagem em tela cheia, saltando para a mensagem anterior ou para baixo quando uma resposta terminava de ser transmitida enquanto rolava para cima
  • Corrigidas barras de guias em caixas de diálogo como /config e /plugin quebrando o título e os rótulos das guias no meio da palavra em um terminal estreito; uma aba que não cabe agora passa para a próxima linha inteira
  • Corrigido o seletor /model mostrando "modelo +1" abaixo da lista após rolar até o último modelo; a contagem agora cobre apenas os modelos abaixo das linhas visíveis
  • Corrigido /keybindings escrevendo ligações Backspace e Delete para uma ação de rodapé que não faz nada no keybindings.json gerado
  • Corrigida uma tecla de fechamento do painel do agente de recuperação (footer:close) digitando "x" em vez de si mesma na linha do agente que você está visualizando
  • Corrigido o modo vim . que não repetia texto digitado muito rápido (por exemplo, sobre ssh ou no tmux) ou colado sem colar entre colchetes, e deixando o prompt no modo INSERT após repetir uma alteração sem nada digitado (como cw e depois Esc)
  • Corrigido o modo vim deixando o cursor no colchete de abertura de um espaço reservado para imagem após dd na última linha ou yy no final do prompt, onde r ou x quebraria ou excluiria a imagem
  • Corrigida uma tecla pressionada no instante em que o terminal recuperou o foco respondendo ao prompt de habilitação do controle remoto antes de seu curto retardo de segurança ser reiniciado
  • Corrigida a caixa de diálogo trust da área de trabalho que aparecia uma segunda vez após a troca de renderizadores ou atualização quando o Claude Code era iniciado no diretório inicial
  • Corrigidas regras vinculadas simbolicamente ao .claude/rules de fora do projeto sendo ignoradas sem nunca mostrar o prompt de aprovação de importações externas; um diretório .claude com link simbólico de fora do projeto agora pede a mesma aprovação
  • Corrigidos plugins de marketplaces, claude.ai e npm pré-aprovando suas próprias ferramentas via allowed-tools sob gerenciamento allowManagedPermissionRulesOnly; apenas plug-ins de uma fonte oficial da Anthropic ou de uma fonte que gerencia configurações garantem manter essa pré-aprovação
  • Corrigida uma falha no primeiro claude plugin install deixando o plugin habilitado e registrado quando o intervalo de versão de uma dependência não podia ser atendido
  • Corrigido o log de depuração eliminando o stderr de um gancho com falha quando o gancho também grava no stdout e não registrava nada para um gancho com falha sem saída; ganchos com falha agora também registram seu código de status
  • Corrigido {"decision":"block"} retornado pelos ganchos Elicitation e ElicitationResult sendo ignorados; agora declines a elicitação do MCP, como o código de saída 2 faz
  • Corrigidas sessões iniciadas sem a ferramenta SendMessage (como por Claude Desktop) ainda recebendo instruções para enviar mensagens a outras sessões com ela
  • Correção de perda de uma foto enviada do aplicativo Claude pelo Controle Remoto quando a mensagem na fila era puxada de volta para o prompt do terminal para edição e o cursor se movia um caractere para uma foto sem legenda
  • Corrigida a digitação de uma mensagem durante uma espera automática de limite de uso, eliminando a espera do controle da configuração "Continuar automaticamente no limite de uso" quando aquele turno atingisse o limite novamente
  • Corrigidos avisos de limite de uso sugerindo /upgrade para usuários que já possuem o plano Max mais alto; os avisos e o próprio /upgrade agora apontam para /usage-credits quando estiver disponível
  • Corrigida a mudança do subagente Explore para Opus no Claude API quando a sessão executa um ID de modelo que Claude Code não reconhece, como um modelo personalizado atrás de um proxy; Explore agora herda esse modelo
  • Corrigidas atualizações de status do /loop no modo individualizado, muitas vezes não sendo mostradas porque Claude as escreveu apenas em seu raciocínio; Claude agora escreve cada atualização e o resultado quando o loop para, como texto visível
  • Correção da falha do /ultrareview ao carregar a árvore de trabalho quando iniciado a partir de uma árvore de trabalho git que o aplicativo de desktop Claude criou no macOS ou Linux
  • Correção de comandos Bash em sandbox que falhavam ao iniciar no Linux quando o diretório de trabalho era negado para gravação e continha um diretório negado para leitura
  • Corrigidos resultados de gravação do banco de dados de artefatos informando a Claude que cada visualizador vê uma gravação na subárvore privada data/users/ de um visualizador e adicionado um nível de "visualização" a as_level
  • Corrigido o gateway de aplicativos Claude que respondia 431 Request Header Fields Too Large a todas as solicitações de um login cujo provedor de identidade lista muitos grupos; agora aceita cabeçalhos de solicitação de até 256 KiB
  • Melhoria na espera do limite de uso: o estado do limite e a contagem regressiva com a opção de créditos de uso agora são exibidos como um bloco abaixo do prompt e as mensagens de limite não repetem mais a contagem regressiva
  • Melhorado o erro "Nenhuma ferramenta disponível" para Claude em ferramentas do Chrome chamadas sem o prefixo: agora nomeia a ferramenta a ser chamada
  • Melhorias nas linhas de eventos do Monitor para mostrar o que cada evento imprimia em vez de repetir a descrição, e parou de repetir uma linha inalterada "Aguardando N... terminar" após cada evento
  • Melhor proteção de sandbox da ferramenta Workflow para erros gerados por ganchos de script assíncronos
  • Tempo de inicialização e uso de memória aprimorados, criando apenas as partes do esquema de configurações que seus arquivos de configurações realmente usam
  • /claude-api aprimorado: hillclimb não gasta mais rodadas em reformulações de prompts muito pequenas para serem medidas pela avaliação, e uma página extra que você solicita ao lado de report.html é construída como um arquivo local que não carrega nada da rede
  • Listas aprimoradas como /tasks, /copy e /hooks: os detalhes após cada nome agora são alinhados em uma coluna quando cabem e, caso contrário, ficam na borda direita
  • claude plugin marketplace add aprimorado para informar quando substitui um mercado já adicionado com o mesmo nome de uma fonte diferente e como desfazê-lo
  • Melhorada a recusa de inicialização quando as configurações gerenciadas exigem um login (forceLoginMethod ou forceLoginOrgUUID) e uma chave API, token ou apiKeyHelper está configurada: agora nomeia a credencial em uso, onde está definida e como removê-la
  • Carregamento automático de memória aprimorado: caracteres e tags invisíveis que imitam a marcação do próprio Claude Code são neutralizados no MEMORY.md e recuperam notas de memória antes de chegarem a Claude
  • claude remote-control aprimorado: em uma pasta que você ainda não trusted, agora ele pede espaço de trabalho trust no terminal em vez de sair
  • Páginas de artefatos aprimoradas: Claude escreve seu plano de design na página em vez da resposta e usa o nome que você já deu a algo como título da página
  • Melhorada a ferramenta Artefato para que quando Claude receber um chat claude.ai ou link de projeto, um artefato de um chat ou um ID de artefato por conta própria, ele solicite o link correto ou o conteúdo em vez de parar
  • Alterado terminal interativo e sessões de VS Code para iniciar em modo automático quando nenhum modo de permissão estiver configurado, em todos os planos e provedores; permissions.defaultMode ainda o substitui
  • Ultracode alterado para seu próprio botão de alternância no /effort (Tab ou /effort ultracode [on|off]): ele não força mais o esforço xalto e permanece ativado em qualquer nível de esforço
  • Tentativas alteradas após uma queda de conexão no meio da resposta para compartilhar um orçamento com o restante das tentativas da solicitação, para que uma solicitação com falha desista mais cedo
  • Alterado o aviso mostrado quando as salvaguardas de um modelo Sonnet sinalizam uma mensagem para explicar por que isso aconteceu e para oferecer edição e nova tentativa
  • Alteração do modelo relacionado à segurança em sessões que fixam um modelo Opus com ANTHROPIC_DEFAULT_OPUS_MODEL ou modelOverrides: no Anthropic API, o API agora escolhe o modelo para o qual alternar para cada tipo de bandeira, não o modelo fixado
  • Alterado o primeiro turno não interativo para ainda esperar até 2s para conectar servidores MCP nomeados por --allowedTools ou um gancho mcp_tool, mesmo quando CLAUDE_CODE_MCP_STARTUP_WAIT_MS é 0
  • Alterado /recap para decline com um breve aviso quando chega retransmitido de um tópico de bate-papo (inclusive o seu) ou de uma rotina ou webhook; digitado no terminal, os aplicativos Claude, Remote Control, -p ou um host SDK, ele funciona como antes
  • /artifacts alterado para mostrar suas guias de filtro ao lado do título com rótulos de uma palavra (Todos, Meu, Compartilhado), usando a mesma barra de guias que /config e /plugin
  • Publicação de artefato alterada para recusar um arquivo em um compartilhamento de rede (um caminho \\host\share ou uma montagem automática /net), a menos que esteja em uma unidade de rede mapeada adicionada com --add-dir
  • [VSCode] Adicionado um horário opcional acima de cada prompt e resposta, com uma linha de data onde o dia muda (Código Claude: configuração Mostrar carimbos de data e hora da mensagem, desativado por padrão)
  • [VSCode] Adicionados erros de carregamento de plug-ins e notas às linhas Gerenciar plug-ins, com um pop-up para desativar, desinstalar ou copiar o erro
  • [VSCode] Adicionado um botão liga/desliga do Ultracode sob o controle deslizante Esforço, substituindo a parada do Ultracode do controle deslizante; o modelo de pílula mostra "· Ultracode" em qualquer nível de esforço
  • [VSCode] Corrigido o Reload Claude da caixa de diálogo Memória reiniciando antes de um arquivo editado ser salvo
  • [VSCode] Corrigida uma aba restaurada abrindo uma conversa que outro processo do Claude ainda estava aberta; agora pergunta primeiro
  • [VSCode] Correção de seções da visualização Focus que você expandiu fechando sozinhas enquanto um subagente está trabalhando ou quando a primeira etapa da seção é cortada da visualização
  • [VSCode] Corrigida digitação de /model e Enter para imprimir texto de uso no chat em vez de abrir o seletor de modelo
  • [VSCode] Corrigido /feedback em Vertex, Bedrock e Foundry sendo recusado após você pressionar Enviar; o relatório agora está salvo neste computador, como o terminal faz
  • [VSCode] Corrigido login aguardando até um minuto pela extensão Python após recarregar uma janela
  • [VSCode] Corrigidas guias do Claude Code que paravam de responder após reiniciar extensões: agora elas reabrem em suas conversas
  • [VSCode] Corrigida uma mensagem de outro agente sem remetente registrado aparecendo como XML bruto no chat
  • [VSCode] Corrigidas mensagens de outros agentes, sessões ou canais que desapareciam após uma recarga
  • [VSCode] Corrigido o comando /mcp, /config ou /settings do próprio usuário sendo ocultado pela caixa de diálogo da extensão
  • [VSCode] Corrigido Escape parando todos os agentes em segundo plano quando nenhum turno estava em execução
  • [VSCode] Corrigidos links de instalação de plugins substituindo um mercado que você já possui e que usa o mesmo nome
  • [VSCode] Corrigidos erros de "O prompt é muito longo" após a compactação quando um arquivo de texto grande é anexado a uma mensagem
  • [VSCode] Corrigidos links de bate-papo para arquivos com caracteres não ASCII, espaços ou colchetes em seu caminho que não abriam
  • [VSCode] Alterado CLAUDE_CONFIG_DIR na configuração claudeCode.environmentVariables para aplicar apenas quando for um caminho absoluto, e passado para terminais que continuam o chat
  • [Sessões na nuvem] Corrigidos os controles Editar e Duplicar de uma rotina informando que a rotina ainda estava carregando enquanto você estava offline; agora eles dizem que você está offline
  • [Claude Tag] Adicionadas opções de família de modelos, como "Opus (mais recente)" para um tópico, um canal padrão ou seu DM, para que a escolha siga o modelo mais recente dessa família
  • [Claude Tag] Adicionados os gastos que contam para o limite de toda a organização ao gráfico de projeção de gastos analíticos, com quanto do limite é usado
  • [Claude Tag] Corrigido o cartão de progresso e visualizações de link do aplicativo Claude in Slack anterior, omitindo o repositório e o botão Criar PR quando um nome de host GitHub Enterprise contém um sublinhado
  • [Claude Tag] Corrigido Claude ficando em silêncio em um canal cujo ambiente declines para iniciá-lo; agora ele publica um aviso solicitando que você entre em contato com um administrador e tenta novamente quando @-mencionado
  • [Claude Tag] Mudou Claude para postar seu aviso de login privado a cada @menção de alguém que não conectou sua conta de Claude, em vez de ficar quieto após a primeira
  • [Claude Tag] "Notificar membros agora" aprimorado nas configurações de administrador: um toque alcança todos os espaços de trabalho que sua organização reivindicou em um Enterprise Grid e mais membros em grandes espaços de trabalho
