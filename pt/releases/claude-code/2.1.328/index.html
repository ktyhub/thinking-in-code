código claude v2.1.328

O que mudou

  • Adicionado modo automático para Claude Opus 4.6 e Sonnet 4.6 no Amazon Bedrock, Agent Platform do Google Cloud, Microsoft Foundry e gateway de aplicativos Claude; sessões interativas sem modo de permissão são iniciadas nele
  • Adicionado "onFailure": "block" para ganchos mcp_tool, como para ganchos de comando e HTTP: um gancho cuja chamada falha bloqueia a ação
  • Adicionado um aviso quando uma mensagem de uma sessão que ignora solicitações de permissão pode ser retida e descartada por uma sessão na nuvem
  • Adicionado um aviso em /status e claude doctor quando um exportador OpenTelemetry não tem endpoint e seus dados provavelmente seriam perdidos
  • Adicionado CLAUDE_CODE_DISABLE_DEFERRED_TOOL_RESUME, que permite que um host impeça claude -p --resume e --continue de executar uma chamada de ferramenta que um gancho adiou
  • Adicionado suporte para aplicativos que incorporam Claude Code para ativar a opção allowManagedModsOnly do plugin de política; as configurações gerenciadas de um administrador ainda vencem
  • Adicionado um aviso de inicialização ao gateway de aplicativos Claude quando o maxEffortLevel de uma política não é um nível de esforço válido
  • Executor auto-hospedado: Adicionado --repository-folder para nomear a pasta que as sessões usam para um repositório em --capacity 1, no lugar de seu caminho na pasta base, que não pode ser um link simbólico
  • Executor auto-hospedado: Adicionado um aviso de inicialização quando as configurações do host.json definem um modo de permissão padrão que as sessões ignoram
  • Executor auto-hospedado: Adicionado --hook-label a claude self-hosted-runner orchestrator, para entregar rótulos de sessão escolhidos ao gancho spawn-runner
  • Executor auto-hospedado: Adicionado --metadata key=value a claude --environment, para rotular uma sessão para o gancho spawn-runner
  • Executor auto-hospedado: Adicionado claude_code_self_hosted_orchestrator_session_queue_wait_by_reason_seconds ao /metrics do orquestrador, para que a espera de uma sessão reaberta possa ser diferenciada de uma nova
  • Executor auto-hospedado: Adicionada uma métrica de orquestrador, claude_code_self_hosted_orchestrator_sessions_given_up_total, que conta por causa a frequência com que a Anthropic desistiu de iniciar um executor para uma sessão
  • Corrigidos comandos Bash no zsh parando com erro "não encontrado" em uma palavra que começa com =, como echo ==== ou [ a == b ]; =cmd não se expande mais para o caminho de um comando
  • Correção da compactação automática reutilizando o prompt do sistema anterior da sessão em vez de reconstruí-la como o /compact faz
  • Corrigido o congelamento da renderização de markdown em alguma entrada muito longa ou malformada
  • Corrigidos raros congelamentos de tela
  • Corrigido Esc que muitas vezes era perdido em um prompt de permissão ou pergunta quando você digitava logo após; em terminais que enviam Alt como Esc e uma tecla, uma tecla Alt ou Option não utilizada agora é declines lá
  • Corrigido um colar ou uma resposta do terminal sendo digitada no prompt quando uma conexão lenta o cortava em dois
  • Corrigido o salvamento de uma tarefa agendada, apagando outras tarefas salvas do projeto quando o arquivo de tarefas agendadas não pode ser lido, em provedores terceirizados ou com telemetria ou sinalizadores de recursos desativados
  • Corrigida uma tarefa agendada com um erro de digitação no arquivo de tarefas agendadas do projeto sendo excluído na próxima vez que o arquivo fosse salvo
  • Corrigido um caso em que uma sessão de nuvem retomada poderia perder seu resumo de compactação ou mensagens recentes quando uma mensagem era salva com atraso
  • Corrigidas as contagens de tokens no spinner e para subagentes contando uma resposta repetida duas vezes, faltando respostas que não foram transmitidas e ficando parados enquanto Claude pensa
  • Corrigido o erro mostrado quando os créditos de uso acabam no meio da resposta, que nomeava um limite de taxa
  • Correção do modo automático que falhava a cada turno fora do Claude Desktop com CLAUDE_CODE_DISABLE_EXPERIMENTAL_BETAS definido atrás de um gateway rejeitando betas, no gateway de aplicativos Bedrock, Agent Platform, Foundry ou Claude
  • Corrigido CLAUDE_STREAM_IDLE_TIMEOUT_MS que não aumentava o limite de conexão de 5 minutos em gateways, URLs base personalizados e provedores de nuvem
  • Corrigidas algumas sessões do Claude Desktop em provedores terceirizados, além de tarefas agendadas, terminando definitivamente com "O prompt é muito longo" após grandes resultados da ferramenta; os maiores agora ficam de fora
  • Corrigidas ferramentas MCP cujo esquema de entrada começa com anyOf, oneOf ou allOf desaparecendo em provedores terceirizados ou com telemetria ou sinalizadores de recursos desativados
  • Corrigida uma ferramenta MCP com um esquema de entrada inválido que falhava em solicitações em provedores terceirizados ou com telemetria ou sinalizadores de recursos desativados; a ferramenta agora foi deixada de fora e Claude é informado do porquê
  • Correção do esforço sendo desativado para o modelo de um subagente para a sessão se Bedrock, Agent Platform do Google Cloud ou Foundry recusassem a configuração de esforço do resumo de progresso (regressão em 2.1.327)
