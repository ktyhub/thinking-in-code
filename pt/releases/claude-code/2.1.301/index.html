claude-code v2.1.301

código claude v2.1.301

O que mudou

  • Adicionado CLAUDE_CODE_RETRY_WATCHDOG_MAX_USAGE_LIMIT_WAIT_MS para que o modo de nova tentativa autônoma (CLAUDE_CODE_RETRY_WATCHDOG) encerre uma solicitação em um limite de uso que é redefinido muito longe em vez de esperar
  • Adicionada orientação de rastreamento OpenTelemetry à habilidade claude-api, incluindo a configuração de destinos de rastreamento com o ant CLI
  • Adicionado o movimento % ao modo vim: pule para o colchete correspondente, sozinho ou com d/c/y
  • Adicionado rows ao Input de um mod: um campo de texto de várias linhas no terminal, onde Enter envia e Shift+Enter ou uma barra invertida antes de Enter inicia uma nova linha
  • Adicionados classifier_verdict e permission_mode aos eventos OpenTelemetry tool_decision, para que as decisões do classificador de modo automático possam ser diferenciadas das regras de permissão
  • Adicionado classifier_category aos eventos OpenTelemetry tool_decision, nomeando a regra integrada como um bloco classificador correspondente, quando OTEL_LOG_TOOL_DETAILS=1
  • Corrigido o encerramento da remoção de uma árvore de trabalho feita por um gancho WorktreeCreate sem perguntar quando ele pode conter commits não enviados
  • Corrigido o erro de alias do modelo fable (e best) no Anthropic API quando o modelo Fable mais recente não está disponível para sua organização: Claude Code agora tenta novamente uma vez no modelo Fable anterior
  • Corrigido um erro enganoso "Por favor, execute /login" quando um disco cheio impede que o login seja atualizado; o erro agora nomeia o disco e diz para excluir arquivos
  • Corrigido Grep e Glob não reportando correspondências quando o programa de busca falhava inesperadamente antes de retornar qualquer resultado; agora eles retornam um erro dizendo que a pesquisa falhou
  • Correção de agentes de fluxo de trabalho que às vezes pulavam etapas e a execução ainda relatava sucesso, depois de ler a observação do equipamento de que o texto da tarefa não carrega autoridade do usuário
  • Corrigidas atualizações de artefatos sendo recusadas quando um gancho PreToolUse cobre Editar ou Gravar; Claude agora edita o arquivo e depois republica em vez de alterá-lo na chamada de publicação
  • Corrigidas habilidades e comandos com nomes de argumentos muitos ou muito longos que paravam por segundos quando invocados; apenas os primeiros 64 nomes, cada um com até 64 caracteres, agora são preenchidos
  • Corrigidas habilidades, comandos e ganchos que usavam grandes quantidades de memória quando seus argumentos preenchiam muitos espaços reservados
  • Corrigidos caracteres perdidos, como >0q cobrindo o prompt da pasta trust e >4m antes do prompt do shell na saída, em terminais construídos em VTE anteriores a 0.53, como MATE Terminal no RHEL 8
  • Corrigido texto GOK perdido aparecendo no prompt na inicialização em algumas versões do iTerm2
  • Corrigida a mudança para um modelo cujo nome contém application-inference-profile executando o comando awsAuthRefresh e atrasando ganchos de troca de modelo quando o provedor não é Bedrock
  • Corrigidos tempos limite de atualização de login e saídas inesperadas após um comando curto, como claude auth status ou claude plugin list, encerrado no meio de uma atualização de token
  • Corrigida uma chamada de ferramenta interrompida por uma mensagem enviada no meio do giro durante a verificação de permissão sendo reportada ao modelo como rejeitada pelo usuário
  • Corrigido um caso em que mudar para um modelo com uma janela de contexto menor poderia gastar créditos de uso em um resumo do modelo anterior sem perguntar primeiro
  • Correção de conversas sendo compactadas repetidas vezes, em um modelo que você não escolheu, atrás de um gateway LLM cujas respostas nomeiam um modelo diferente daquele solicitado
  • Corrigido o modo vim que às vezes permanecia em INSERT após Escape em uma máquina lenta ou ocupada
  • Corrigido Esc descartando uma resposta digitada do AskUserQuestion no modo vim: o campo de texto livre agora suporta o modo vim NORMAL e Esc cancela apenas no modo NORMAL
  • Corrigida a ferramenta Ler lendo arquivos binários como .xlsm, .parquet, .epub e .heic como texto
  • Corrigida uma tabela Markdown com apenas uma linha de cabeçalho sem desenhar nada quando muito larga para o terminal, inclusive em planos no cartão de aprovação de plano
  • Correção da habilidade /claude-api informando que endpoints de chave externa CMEK não estão disponíveis na plataforma Claude na AWS
  • Corrigidas habilidades que não eram mais listadas no modelo após usar /rewind
  • Corrigida a linha de compactação em uma sessão retomada oferecendo ctrl+o para histórico que não está carregado; agora diz onde as mensagens anteriores foram salvas e também mostra em tela cheia
  • Corrigida a dica "nova tarefa? /clear para salvar tokens" que voltava logo após você interromper uma resposta
  • Corrigido o prompt de permissão para a decisão ask de um plugin ou gancho de habilidade que não mostrava de qual plugin ou habilidade o gancho vem
  • Corrigido o problema de /diff não perceber uma seleção seletiva conflitante ou reversão em repositórios reftables quando uma de suas verificações git expirou ou falhou
  • Correção de scripts de fluxo de trabalho que solicitavam permissão ou eram recusados quando lidos, editados ou executados novamente após um Bash cd na mesma sessão
  • Corrigido texto esmaecido no tema ANSI escuro e terminais de 16 cores: esmaecido dentro de caixas preenchidas, não esmaecido sob seleção e destaques de pesquisa e descrições de lista esmaecidas como outro texto secundário
  • Corrigido um mod $.model.fork retornando nothing-to-fork quando chamado antes da primeira resposta de um novo processo Claude Code ter terminado, como em execuções de claude -p e sessões na nuvem
  • Modo de tela cheia: Corrigido /compact e compactação automática congelando brevemente a IU enquanto a transcrição visível é reconstruída
  • Executor auto-hospedado: Corrigidas sessões iniciadas no Slack que não conseguiam encontrar ou anexar um repositório quando as configurações gerenciadas restringiam os servidores MCP; use deniedMcpServers para manter essas ferramentas desligadas
  • Executor auto-hospedado: sessões corrigidas sendo relatadas como tendo uma ramificação de origem excluída e não sendo tentadas novamente, quando uma configuração não relacionada ou falha de sessão citava o texto de referência ausente do git
  • Executor auto-hospedado: Corrigido o log prometendo uma nova tentativa de liberação de sessão com falha ou declined para uma sessão que está finalizando; falhas repetidas agora mostram uma contagem
  • Windows: Corrigidos comandos do PowerShell em segundo plano interrompidos sem a linha de fechamento [killed] em seu arquivo de saída
  • Melhoria na mudança para um modelo com uma janela de contexto menor: uma conversa muito longa para o novo modelo agora é resumida primeiro pelo modelo anterior
  • Melhor desempenho de renderização enquanto um subagente de longa execução funciona: sua trilha de progresso agora é atualizada de forma incremental em vez de ser totalmente reprocessada a cada renderização
  • Artefatos aprimorados: as páginas que Claude escreve agora pintam a faixa acima de um cabeçalho fixo, para que o texto rolado não apareça mais nos aplicativos móveis
  • Mods aprimorados: no VS Code e nos aplicativos para desktop e dispositivos móveis, uma árvore desenhada acima da caixa de diálogo da pergunta agora pode conter Markdown e até 48 linhas; o terminal mantém 12 linhas simples
  • Alterado o manipulador .catch de um mod hook para ser executado somente quando o gancho é lançado ou expira; eventos gerados sob as próprias chamadas do gancho agora pulam esse gancho sem perguntar ao seu .catch
  • Alterado o $.env.set de um mod para resolver com {} quando a variável é definida ou desativada, ou com { deny } dizendo o porquê quando a gravação não é feita
  • [VSCode] Adicionada renderização matemática LaTeX nas respostas de Claude, incluindo $$ e blocos \[ … \] multilinhas e matemática inline $…$ e \(…\)
  • [VSCode] Adicionado um link "Obter mais uso" ao banner de limite de uso para planos Pro e Max nos painéis VS Code e JetBrains
  • [VSCode] Corrigida uma conversa que travava ou congelava o painel sendo reaberto a cada recarga
  • [VSCode] Corrigida a lentidão do painel de bate-papo durante longas reflexões: ele não analisa mais todo o texto de reflexão a cada atualização
  • [VSCode] Corrigido diagnóstico mostrando "[object Object]" em vez do código de regra (por exemplo, MD013) para alguns servidores de linguagem
  • [VSCode] Corrigido o carregamento do módulo de áudio de ditado nativo, para verificar a permissão do microfone, onde o ditado não é oferecido (logins não-claude.ai, janelas remotas)
