código claude v2.1.285

O que mudou

  • Adicionada variável de ambiente CLAUDE_CODE_DISABLE_WEB_FETCH para desligar a ferramenta WebFetch
  • Adicionado claude --desktop para abrir o aplicativo de desktop Claude no diretório atual ou em uma sessão com --continue / --resume <id>
  • Adicionado claude plugin configure <plugin> para mostrar as opções de um plugin e quais não estão definidas, ou salvar novos valores lidos do stdin com --values-stdin
  • Adicionado <server>.<key>=<value> ao claude plugin install --config, para que as próprias configurações do servidor .mcpb MCP possam ser definidas no momento da instalação e ele seja iniciado sem visitar /plugin → Configurar
  • Adicionada configuração gerenciada allowedProviders para limitar quais provedores API uma máquina pode usar (Anthropic API, um endpoint personalizado, Bedrock, Mantle, Vertex AI, Foundry, Claude Platform na AWS ou um gateway de nuvem)
  • Adicionada variável de ambiente CLAUDE_CODE_NONSTREAMING_TIMEOUT_RETRIES para limitar reenvios de uma solicitação de fallback sem streaming que expirou
  • Corrigido claude -p com CLAUDE_CODE_FORK_SUBAGENT=1: a chamada de agente do próprio subagente agora é executada em primeiro plano, para que o subagente obtenha o resultado do filho
  • Corrigidas instalações e atualizações de plugins e marketplaces via SSH, ignorando o programa ssh definido em GIT_SSH ou em sua configuração do git core.sshCommand
  • Corrigido o código Claude recusando-se a iniciar quando o sistema operacional nega a leitura do arquivo de configurações gerenciadas; agora ele avisa e inicia sem as políticas desse arquivo. Outros erros de leitura e arquivos não analisáveis interrompem todas as sessões
  • Correção de sessões na nuvem que eram reiniciadas após a conversa ser compactada, recusando a próxima atualização de um artefato que a sessão já havia lido ou publicado
  • Corrigido claude plugin disable e enable com um ID name@marketplace completo alterando uma entrada de configurações em outra caixa de letras em vez do próprio plugin instalado
  • Corrigidos arquivos anexados a uma mensagem enviada pelo Controle Remoto sendo deixados de fora após uma única falha no download; um erro de rede, tempo limite ou erro de servidor agora é repetido até duas vezes
  • Foi corrigida a troca de modelos no meio da sessão com uma solicitação set_model (como o setModel do Agente SDK) deixando o novo modelo no limite de token de saída integrado e na janela de compactação automática até a reinicialização
  • Foram corrigidos registros e transcrições editados mostrando parte de uma senha de URL que contém @, ou toda ela quando o URL grava seu @ como %40
  • Correção da senha SSH e prompts de novo host da árvore de trabalho e buscas /teleport assumindo o controle do terminal; essas buscas agora falham rapidamente em vez de perguntar
  • Corrigido o desligamento de um servidor MCP adicionado no meio da sessão nas sessões SDK e -p, deixando suas ferramentas disponíveis
  • Corrigido claude -p --permission-prompt-tool: a solicitação de permissão de um subagente em segundo plano agora vai para a ferramenta de prompt em vez de ser negada automaticamente
  • Corrigido claude mcp list e claude mcp get, e o erro não encontrado de claude mcp remove, login e logout, imprimindo quebras de linha e sequências de escape de terminal de nomes e valores de servidores MCP
  • Correção da permissão automática do sandbox solicitando aprovação em cada execução de muitos scripts in-line (python3 -c, node -e) apenas porque eles contêm =
  • Corrigidos subagentes de fork que não mantinham o modo de plano da sessão ou o modo dontAsk: um fork agora é executado no modo de permissão de seu pai e não pode sair do modo de plano
  • Corrigido claude remote-control --help informando que o padrão --[no-]chrome é a configuração /chrome da máquina; sessões geradas mantêm Claude no Chrome desligado, a menos que --chrome seja aprovado
  • Correção de subagentes em segundo plano no modo automático, solicitando uma segunda resposta redundante após cada relatório
  • Corrigida a criação de sessão na nuvem e o /remote-env lendo apenas os 20 ambientes mais recentes de uma conta
  • Corrigido o controle remoto que marcava uma mensagem como lida assim que chegava, em vez de quando Claude iniciava, e perdia uma mensagem ainda na fila quando o terminal fechava (agora chega na próxima retomada)
  • Corrigida a instalação de um plugin com claude plugin install ou /plugin colocando-o no cache ou pasta de dados de um plugin instalado quando seus ids diferem apenas em ., -, @ ou (macOS, Windows) capitals; a instalação agora foi recusada
  • Corrigidos ganchos e retornos de chamada de permissão SDK vendo um plano ausente ou desatualizado em ExitPlanMode quando o plano foi escrito na mesma resposta
  • Corrigida a primeira resposta em sessões de nuvem chegando com dezenas de milissegundos de atraso, uma regressão em 2.1.283
  • Corrigidas sessões que autenticavam com ANTHROPIC_AUTH_TOKEN contra o Antrópico API nunca carregando a política da organização
  • Corrigida uma falha na chamada agent(), parallel() ou pipeline() que um script de fluxo de trabalho aguarda mais tarde, ou não, sendo tratada como uma rejeição de promessa não tratada, o que poderia encerrar uma sessão em segundo plano
  • Corrigidos ganchos síncronos pendurados no Claude Code enquanto um processo em segundo plano iniciado pelo gancho (por exemplo some-daemon &) mantinha sua saída aberta; o gancho agora termina logo após a saída de seu próprio processo

  • Corrigida uma regra de permissão do Artifact ("não pergunte novamente") permitindo que a ferramenta Artifact publicasse um arquivo fora dos diretórios de trabalho sem perguntar; adicione a pasta do arquivo com --add-dir para que a regra o cubra
