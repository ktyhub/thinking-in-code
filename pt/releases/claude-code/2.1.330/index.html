código claude v2.1.330

O que mudou

  • Adicionado login para organizações gerenciadas no Enterprise Admin Console da Anthropic: após claude auth login, Claude Code aplica as configurações da organização e usa seu provedor de nuvem ou gateway
  • Adicionado cavalete, um mod integrado que desenha gráficos quando solicitado e sob resultados de métricas MCP, no Pro, Max e, quando disponível, Team e Enterprise no macOS e Linux; desativar gráficos automáticos em /config
  • Adicionado CLAUDE_CODE_FULL_SIGN_IN_LINK=1 para imprimir o link de login completo, se o link curto mostrar um erro ou um script ler valores dele
  • Executor auto-hospedado: Adicionado --start-dir / SELF_HOSTED_RUNNER_START_DIR para que Claude inicie seu trabalho em uma pasta de um repositório, enquanto as configurações e os ganchos são carregados como sem ele
  • Adicionado um aviso nas sessões de execução na nuvem e auto-hospedadas quando um mercado de plug-ins não pode ser obtido porque seu repositório não é um dos da sessão
  • Corredor auto-hospedado: Adicionado um aviso quando o git gerenciado pela Anthropic recusa o próprio repositório de um plugin, nomeando o plugin e o que fazer
  • Adicionados resultados de commandPrinted aos claude plugin install --json, verdadeiros quando o comando de instalação do plug-in grava em stderr e commandFailed quando ele sai com um erro, é eliminado ou atinge o tempo limite
  • Adicionado claude_code_self_hosted_runner_order_to_registered_seconds ao /metrics do executor auto-hospedado: segundos desde a ordem de serviço emitida até o registro aceito, em executores gerados pelo orquestrador
  • Adicionado claude_code_self_hosted_runner_order_to_first_session_seconds ao /metrics do runner auto-hospedado: segundos da ordem de serviço até a primeira sessão entregues, em runners iniciados para uma sessão
  • Corrigido o congelamento do Código Claude por vários minutos logo após compactar uma conversa muito longa
  • Corrigido o WebFetch que congelava a sessão por minutos em algumas páginas e retornava um resultado vazio em outras.
  • Corrigido ExitWorktree e a caixa de diálogo de saída da árvore de trabalho excluindo uma árvore de trabalho na qual outra sessão do Claude Code em execução estava funcionando
  • Corrigidas alterações nas configurações do usuário que eram perdidas quando vários processos do Claude Code as salvavam ao mesmo tempo
  • Corrigido --continue e --resume abrindo uma sessão vazia ou falhando quando a última mensagem salva tinha um carimbo de data/hora ausente ou inválido
  • Corrigido o primeiro prompt após um sono de dois minutos ou mais, aguardando três minutos em uma conexão que havia morrido, no Linux e WSL
  • Correção de falhas de turnos com "esquema JSON inválido" e arquivos de sessão crescendo em muitos megabytes, quando muitas ferramentas MCP têm um esquema de entrada que o API recusa
  • Linux: Corrigidos comandos Bash que aguardavam segundos e não mostravam nenhuma diferença de arquivo para o resto de uma sessão em repositórios lentos com grandes pastas ignoradas, como node_modules
  • Windows: Corrigidos comandos Bash rodando mais lentamente durante o resto de uma sessão depois que o Git Bash demorava de 10 a 60 segundos para iniciar, em máquinas sem arquivos de inicialização personalizados
  • Corrigido o problema de /rewind que às vezes restaurava uma versão mais antiga de um arquivo quando dois prompts na fila, ou habilidades empilhadas, eram executados juntos logo após um turno que o alterava
  • Correção de texto e imagens adicionados ao aprovar um prompt de permissão que era descartado quando o comando ou ferramenta aprovado falhava
  • Corrigidos recursos MCP de conectores claude.ai e servidores de plugins que não eram anexados quando mencionados na caixa de prompt do terminal
  • Corrigido um servidor MCP que os subagentes declaravam ter sido desligado quando um deles terminava, enquanto outros subagentes ou a sessão ainda o usavam
  • Corrigido o problema de Claude no Chrome ficar "não conectado" após um breve problema de conexão, mesmo que o Chrome estivesse aberto e conectado
  • Correção de sessões de terminal no Amazon Bedrock (Mantle) iniciadas sem nenhum modelo selecionado, ignorando um modelo Opus fixado e ainda chamando um modelo padrão indisponível após anunciar um substituto
