claude-code v2.1.286

código claude v2.1.286

O que mudou

  • Adicionada uma contagem como "2 de 5" ao prompt de permissão quando várias solicitações de permissão se acumulam
  • Adicionado suporte de mouse para as "mais N" linhas de listas no modo de tela cheia: click um para pular para o final da lista, com estados de foco e pressionado
  • Correção de vários processos do Claude Code e extensões IDE, cada um abrindo um navegador de login quando as credenciais gcpAuthRefresh ou awsAuthRefresh expiram
  • Correção de claude --resume e --continue que às vezes perdiam todos os turnos após um lote de chamadas de ferramentas paralelas quando a sessão anterior travava ou era interrompida
  • Corrigidos erros API 400 após uma ferramenta ou gancho retornar um objeto, número ou booleano em vez de texto, inclusive em sessões retomadas
  • Foram corrigidas sessões na nuvem com históricos muito grandes que nunca eram ativados porque o contêiner foi interrompido enquanto a transcrição ainda estava sendo carregada
  • Foi corrigido o preço do medidor de gastos do gateway de aplicativos Claude para gravações de cache de prompt de 1 hora na taxa mais barata de 5 minutos e contando apenas os tokens de entrada da primeira chamada de modelo em turnos transmitidos que executam uma ferramenta do lado do servidor, como pesquisa na web
  • Corrigidas sessões do macOS que ainda exibiam "Não conectado" ou "Login expirado" após /login ter sucesso em outra janela do Claude Code quando existe um ~/.claude/.credentials.json restante
  • Corrigida falha em cada turno quando o Anthropic API recusa o modelo padrão ou um alias de modelo resolve: Claude Code agora tenta novamente uma vez no modelo anterior do mesmo nível
  • Corrigidas sessões de Controle Remoto (incluindo claude remote-control) que permaneciam conectadas após a política da sua organização desligar o Controle Remoto; eles agora se desconectam com um aviso
  • Corrigida recusa e novas tentativas do --fallback-model falhando quando o modelo substituto não pode ser executado rapidamente; agora eles funcionam em velocidade padrão, com aviso único em sessões interativas
  • Correção de sessões headless que repetiam o lembrete "Servidores MCP exigem autenticação" após uma reautenticação bem-sucedida quando o cache de descoberta do MCP está ativado
  • Corrigido claude auth status relatando uma chave API armazenada no login do Console como claude.ai; agora ele reporta api_key, e a extensão do VS Code trata essa sessão como uma sessão chave API
  • Corrigido /status listando um perfil Antrópico ao lado de uma chave API como se ambos estivessem em vigor; o perfil agora está marcado como não em uso
  • Corrigido o problema de Claude não ser avisado quando um arquivo anexado a uma mensagem enviada pelo Controle Remoto não chegava, e um arquivo às vezes demorava apenas 10 segundos para sua última tentativa de download
  • Corrigida uma mensagem do Controle Remoto que chegava enquanto o Claude Code estava saindo sendo marcada como entregue e nunca respondida; agora ele permanece na fila para a próxima execução da sessão
  • Corrigidas mensagens de erro do MCP mostrando o valor de uma credencial quando "Bearer" ou "Basic" vinha antes do nome da chave
  • Correção de tokens de portador com codificação percentual sendo apenas parcialmente mascarados em mensagens de erro
  • Correção de registros e transcrições editados mostrando um segredo cujo nome de chave tem um caractere invisível dentro, como um espaço de largura zero
  • Correção de logs e transcrições mostrando parte de uma senha de URL que contém pontuação como ), aspas, ], & ou um segundo @, ou que passa de um / para um host entre colchetes como [::1] em um URL ssh
  • Corrigida a transcrição da sessão no zip que /feedback salva em disco contendo linhas JSON inválidas após redação secreta
  • Correção de conectores MCP que não listavam ferramentas por até um dia após o servidor abandonar o handshake MCP antigo
  • Corrigida uma solicitação repetida de login no MCP de Claude, substituindo o link de login pendente, o que poderia impedir o funcionamento desse link
  • Corrigido /usage que não creditava um servidor MCP por uma chamada de ferramenta feita enquanto o servidor ainda estava conectado ou tinha acabado de se conectar, como logo após uma reinicialização
  • Correção de plug-ins ativados em claude.ai que ocasionalmente apareciam no Claude Code em uma sessão após um erro transitório do servidor
  • Corrigida uma mensagem digitada em um subagente em execução que aparecia duas vezes em sua transcrição após o subagente lê-la
  • Corrigidas mensagens de devolução do subagente mostrando um ID de tarefa bruto em vez do nome do agente quando o subagente não tinha nome registrado
  • Subagentes em primeiro plano corrigidos às vezes sem as ferramentas de rastreamento de tarefas (TaskCreate/Get/Update/List, TodoWrite) em sessões que as possuem habilitadas
  • Corrigidos subagentes gerados com o isolamento da árvore de trabalho carregando o projeto CLAUDE.md e suas importações uma segunda vez da cópia da árvore de trabalho na primeira leitura do arquivo
  • Correção de subagentes da ferramenta Workflow sendo reiniciados a partir do prompt original quando uma conexão era interrompida por alguns minutos no meio da resposta
  • Corrigida a digitação de /compact, /clear e /rewind ao visualizar a transcrição de um agente em segundo plano ou colega de equipe agindo silenciosamente na conversa principal: uma caixa de diálogo agora nomeia o alvo e pergunta primeiro
  • Corrigidos trabalhos em segundo plano exibidos enquanto aguardavam sua aprovação
  • Corrigido o lembrete de atribuição de commit sendo reenviado dentro da saída da ferramenta quando um modelo substituto dura apenas um turno
  • Corrigido um click no espaço entre as palavras de uma linha recolhida (como "Pensamento por 4s") destacando a linha sem expandi-la no modo de tela cheia
  • Corrigida uma linha sem detalhes, como uma linha de ação com um nome longo, empurrando os detalhes de todas as outras linhas para a direita nas telas de lista
  • Corrigidos arquivos com nomes muito longos que não alcançavam uma sessão na nuvem quando anexados a ela
  • Erros de plugin corrigidos para um mercado que Claude Code se recusa a carregar: agora eles dizem por que e como consertar em vez de "não encontrado"
  • Corrigida a guia Descobrir do /plugin mostrando um nome de mercado sem aspas em sua linha "Verificando... novos plugins" quando suas linhas já mostram esse nome entre aspas
  • Orientação de commit aprimorada: quando seu projeto ou habilidades de usuário incluem um chamado verify, Claude agora é instruído a executá-lo antes do commit, exceto para commits somente de documentos e somente testes
  • Melhor envio agora (ctrl+enter) na visualização de um subagente: agora move o comando em execução do subagente para segundo plano para que sua mensagem seja lida imediatamente
  • Respostas aprimoradas de agentes em segundo plano às suas mensagens, para que elas não abram mais com uma recapitulação separada do que você disse
  • Leituras aprimoradas do link do artefato claude.ai: o WebFetch agora faz as mesmas perguntas que a leitura da ferramenta Artifact (nenhum prompt de artefato enquanto o acesso à rede da sessão está ativado, um por artefato enquanto está desativado) e um modo automático sim, não conta mais, onde somente você pode responder
  • Busca aprimorada, habilidade, leitura de arquivo, rede sandbox, Claude no Chrome, script de fluxo de trabalho e prompts de permissão de edição de notebook para combinar com a aparência dos prompts de edição de arquivo
  • Solicitações de permissão Bash, PowerShell e Monitor aprimoradas para mostrar o comando entre linhas tracejadas, correspondendo às solicitações de edição de arquivo
  • Barras de rolagem de lista aprimoradas no modo de tela cheia: na maioria das listas, a barra não muda mais conforme as "mais N" linhas vão e vêm, e agora tem setas ↑/↓ que você pode clicar com cli ou segurar para rolar
  • Melhorado o editor externo (Ctrl+G): editores que usam um número de linha agora abrem na linha em que seu cursor está no prompt
  • Melhor capacidade de resposta de sugestões de comandos de barra durante a digitação quando muitas habilidades ou comandos de plug-in estão instalados; as descrições dos comandos agora correspondem ao prefixo da palavra
  • Melhorado o seletor de estilo de saída: agora ele abre no estilo atual em vez do padrão, com a descrição de cada estilo na linha abaixo do nome; teclas numéricas não escolhem mais um estilo
  • /hooks aprimorado: a linha de fechamento da tela de detalhes de um gancho agora diz "este gancho" em vez de "isso"
  • Melhorou o aviso de fallback do modelo e o erro de autocompact-thrashing para informar quando um substituto reduziu a janela de contexto de 1 milhão para 200 mil tokens
  • Melhor capacidade de resposta das sessões SDK e -p quando um host reenvia uma habilitação de servidor MCP para um servidor que já está conectado
  • Melhorada a página de protocolo que um gateway de aplicativos Claude atende no /protocol: agora diz para não rejeitar entradas desconhecidas e corresponde ao que Claude Code envia hoje
  • Alterados os prompts enviados enquanto nada está em execução ou na fila para serem exibidos imediatamente na cor normal do texto, em vez de cinza
  • Alterada a forma como as solicitações API com falha são repetidas: um limite agora cobre uma chamada de modelo inteira, portanto, com as configurações de repetição padrão, uma chamada com falha envia no máximo 14 solicitações
  • --bare alterado para conectar apenas os servidores MCP nomeados na linha de comando, não enviar lembretes do sistema ao modelo e não iniciar tarefas em segundo plano; em --bare, um comando shell que atinge seu tempo limite agora para em vez de passar para segundo plano
  • Alterada a tecla enviar agora (ctrl+enter) para mover o comando shell da própria habilidade para o segundo plano em vez de encerrá-lo
  • Alterado o erro do WebFetch para uma verificação de segurança de domínio com taxa limitada para dizer a Claude para não tentar novamente em um loop
  • Alteradas instalações de plug-ins para recusar fontes npm que sejam repositórios ou pastas git e para instalar dependências de plug-ins apenas de pacotes de registro
  • Alteradas telas de lista (/artifacts, /mcp, /skills, /hooks e outras) para sempre alinhar os detalhes de cada linha em uma coluna após os nomes
  • Alteradas as linhas excedentes das listas para "↑ N mais" / "↓ N mais" em vez de "N mais acima" / "N mais abaixo"
  • /hooks alterado para abrir em uma lista de seus ganchos configurados agrupados por evento, portanto, a visualização de um gancho exige um Enter em vez de três
  • Alterado o seletor de temas para uma lista de rolagem adequada ao seu terminal, em vez de empurrar a visualização para fora da tela; teclas numéricas não escolhem mais um tema
  • Alterada a árvore de trabalho Remove do /exit para ser executada após Claude Code parar os servidores e shells que ele iniciou lá, o que no Windows poderia impedir que a pasta fosse excluída
  • Alterados os exemplos de Agentes Gerenciados da habilidade claude-api para criar ambientes com rede limitada
  • Removido o link do navegador da saída /ultrareview e claude ultrareview
  • Windows: Corrigido claude --bg e a visualização dos agentes recusando uma pasta que claude já trusts quando seu registro trust era salvo com letras maiúsculas diferentes
  • [VSCode] Favoritos adicionados: salve as respostas de Claude e mantenha-as visíveis no painel lateral de Favoritos
  • [VSCode] Adicionadas as perguntas que Claude faz e suas respostas à conversa: depois de responder a um cartão de perguntas, uma linha de Perguntas mostra cada pergunta com suas escolhas
  • [VSCode] Adicionadas visualizações de opções aos cartões de perguntas no painel de bate-papo: o modelo ou snippet da escolha destacada é exibido ao lado ou abaixo das opções
  • [VSCode] Adicionadas linhas em uma mensagem que abre para a saída do terminal, guia do navegador, instruções do navegador e código selecionado enviado com ele
  • [VSCode] Corrigida uma segunda cópia de uma conversa abrindo em uma aba quando ela já estava aberta na barra lateral; a barra lateral agora muda para ela
  • [VSCode] Caixas de diálogo de configurações corrigidas relatando falha no salvamento, sem nova verificação, quando Claude Code imprimia mais de 1 MB de saída
  • [VSCode] Corrigido um botão giratório interminável de "Sessão de teletransporte…" quando a extensão parava de responder
  • [VSCode] Melhoria na caixa de diálogo Gerenciar plug-ins: informa quando um plug-in desativado ainda está ativado devido a outras configurações e explica um conflito de pastas de plug-ins
  • [VSCode] Alterado Stop e Escape para encerrar apenas o turno atual; os agentes em segundo plano continuam em execução e podem ser interrompidos um por um no mapa de agentes
  • [VSCode] Alterado o item da barra de status "✻ Claude Code" para aparecer em todas as janelas, para que você possa abrir o Claude quando nenhum arquivo estiver aberto
  • [Sessões na nuvem] Corrigimos um cartão de perguntas respondidas ou uma chamada de ferramenta aprovada que não recebia resposta quando a sessão ficava inativa após Claude enviar uma mensagem
  • [Sessões na nuvem] Corrigida a limpeza do script de configuração de um ambiente organizacional nas configurações de administrador, deixando novas sessões na nuvem ainda executando o script antigo
  • [Sessões na nuvem] Corrigido o menu de ações do Runner na página de administração de ambientes auto-hospedados fechando sozinho alguns segundos após ser aberto
  • [Sessões na nuvem] Corrigidas execuções de rotina cuja sessão na nuvem nunca começava a aparecer como Bem-sucedida no painel Execuções, na página da rotina e na barra lateral; eles agora aparecem como falhados
  • [Sessões na nuvem] Corrigida a falha do cli em um arquivo de áudio ou vídeo no cartão de saída de uma sessão na nuvem, abrindo uma pesquisa de arquivo vazia em vez de reproduzir o arquivo
  • [Sessões na nuvem] Alteração da página de uma rotina para "Vencimento" com o horário agendado, em vez de um próximo horário de execução no passado, quando uma execução agendada está atrasada e ainda não foi iniciada
  • [Claude Tag] Adicionado um botão Adicionar canal à página de limites de gastos de Claude Tag nas configurações de administrador, para que um limite possa ser definido em qualquer canal, incluindo um privado, a partir de seu ID de canal ou link do Slack
  • [Claude Tag] Corrigido recall de memória que não encontrava nada em organizações que não podem usar o modelo Sonnet padrão
  • [Claude Tag] Corrigido um canal do Slack que perdia suas configurações de Claude quando um administrador do Enterprise Grid o movia para outro espaço de trabalho e a primeira postagem posterior não mencionava Claude
  • [Claude Tag] Corrigido Claude em um tópico do Slack ocasionalmente reiniciando em uma máquina nova, perdendo o trabalho que não havia enviado, quando sua resposta respondia a uma pergunta que acabara de fazer
  • [Claude Tag] Corrigidos nomes de canais públicos na página de limites de gastos de Claude Tag nas configurações de administração, exibidos como IDs brutos do Slack em organizações maiores
