código claude v2.1.307

O que mudou

  • Adicionado /claude-api api-version para mover o código Claude API para a versão API 2026-10-21
  • Adicionado o evento claude_code.safety_event OpenTelemetry para cada chamada de ferramenta, uma regra de permissão, modo automático, uma verificação de segurança, um gancho ou sandbox parado, solicitado ou enviado de volta
  • Corrigidas solicitações que falhavam com um erro de modelo não encontrado quando CLAUDE_CODE_DISABLE_1M_CONTEXT estava definido e o modelo era um alias com o sufixo [1m], como opus[1m]
  • Corrigido o cabeçalho beta prompt-caching-scope sendo enviado atrás de gateways ANTHROPIC_BASE_URL personalizados e no Foundry, onde não tem efeito
  • Corrigidos servidores MCP mostrando "precisa de autenticação" em claude -p no macOS enquanto as chaves de login estavam bloqueadas; agora eles dizem o porquê, e a próxima execução após um desbloqueio conecta sem um novo login
  • Correção de servidores MCP relatados como tendo expirado e falhando em execuções headless, quando um computador macOS ou Linux entrava em suspensão enquanto eles estavam se conectando
  • Corrigidas chamadas da ferramenta HTTP MCP sendo enviadas duas vezes quando a conexão era encerrada no meio da chamada; somente ferramentas somente leitura ou idempotentes agora são tentadas novamente
  • Corrigido um turno que às vezes começava sem as ferramentas mais recentes do servidor SDK MCP quando uma tarefa em segundo plano estava sendo executada
  • Corrigidos alguns erros "Autocompact is thrashing" em turnos que leem muitas páginas PDF, imagens ou outros resultados grandes de ferramentas
  • Corrigido /autocompact em sessões na nuvem voltando para a janela padrão após a sessão ser reiniciada
  • Corrigida uma conversa apagada com /clear que às vezes voltava quando uma sessão de nuvem ou de executor auto-hospedado era reiniciada
  • Corrigido CLAUDE_STREAM_FIRST_BYTE_TIMEOUT_MS sendo ignorado nas sessões de gateway de aplicativos Claude
  • Corrigida a telemetria das sessões do Claude Desktop atrás de um gateway de aplicativos do Claude sendo rejeitada quando o OTEL_EXPORTER_OTLP_HEADERS está configurado
  • Corrigido /permissions > Negado recentemente não mostrando o comando shell negado, e o classificador local do modo automático ignorando uma aprovação de lá quando verifica um comando repetido; aprovar uma linha agora nomeia o comando, não sua descrição
  • Corrigido /help e o menu de comando / mostrando longas descrições voltadas para o modelo para habilidades agrupadas, como /claude-api, em vez de suas descrições curtas
  • Correção das transcrições do subagente que registravam o uso do token de espaço reservado e um motivo de parada vazio para respostas transmitidas
  • Corrigidas trocas de modelo através do setModel() do Agente SDK, e apps construídos nele, sendo recusadas quando o API demorava mais de 5 segundos para confirmar o modelo; Claude Code agora espera até 15 segundos
  • Corrigido um comando em segundo plano interrompido por meio de um aplicativo conectado (como o aplicativo de desktop arquivando uma sessão inativa) sendo relatado a Claude como interrompido pelo usuário; o aviso agora nomeia seu arquivo de saída
  • Correção do WebFetch em sessões de nuvem do Cowork relatando um erro de ferramenta quando um site respondia com status 4xx ou recusa de robots.txt; agora é um resultado normal, como nas sessões locais
  • Corrigidas ferramentas de gravação em um servidor GitHub MCP configurado diretamente, mostrando um formulário que fechava sem criar nada na guia Código do aplicativo de desktop
  • Corrigida falha na leitura da ferramenta Artefato com uma redefinição de conexão quando o servidor fechava uma conexão reutilizada
  • Executor auto-hospedado: sessões corrigidas com --use-anthropic-git-proxy comprometendo um .claude/settings.local.json deixado no clone por uma sessão anterior
  • Executor auto-hospedado: Corrigido arquivamento ou reenfileiramento de uma sessão, ou interrupção do executor, durante seu gancho de checkout, deixando os processos do gancho em execução e o slot do executor mantido
  • Recuperação aprimorada de chamadas de ferramentas não analisáveis: Claude Code agora tenta repetir a chamada até duas vezes antes de encerrar o turno com um erro
  • Subagentes de fork aprimorados lançados juntos: agora cada um é informado sobre qual lançamento é o seu, portanto, é muito menos provável que os forks tentem iniciar o trabalho um do outro
  • Login aprimorado no navegador: a página de sucesso agora aparece assim que o login é concluído, sem esperar o carregamento do perfil da sua conta
  • Erros de pesquisa na web aprimorados em sessões de execução na nuvem e auto-hospedadas: uma pesquisa recusada com um 403 que fornece um motivo agora mostra esse motivo em vez de um "Erro de autenticação" genérico
  • Melhorou o tempo até a primeira resposta em sessões na nuvem quando um dos servidores MCP do aplicativo de desktop não consegue se conectar
  • Melhor tempo de conexão do controle remoto para sessões cuja transcrição contém grandes imagens coladas ou leituras de PDF
  • Alterado o aviso que Claude recebe quando o orçamento do WebSearch se esgota para também instruí-lo a não consultar mecanismos de pesquisa em um navegador ou por meio do uso do computador
  • Alterada a configuração de axScreenReader e CLAUDE_AX_SCREEN_READER em um bloco de configurações env para aplicar apenas a partir de configurações de usuário, gerenciadas ou --settings (desde 2.1.305)
  • Executor auto-hospedado: Ganchos de checkout alterados para serem interrompidos após 30 minutos por padrão, falhando na configuração da sessão; se o seu precisar de mais tempo, aumente --checkout-hook-timeout-min ou defina-o para 0
  • Executor auto-hospedado: Alterado o arquivo de certificado criado para o git gerenciado pela Anthropic para filtrar seus certificados trusted como o CLI faz; uma linha [runner:warn] fornece o número deixado de fora
  • [VSCode] Adicionado um aviso no botão do microfone quando o ditado de voz para sozinho (15 segundos sem fala reconhecida, ou o limite de 2 minutos), informando o porquê e que o texto até agora foi mantido
  • [VSCode] Corrigido um prompt longo expandido com Mostrar mais cobrindo todo o painel de bate-papo: um prompt fixado agora está limitado a 40% do painel e rola
  • [VSCode] Corrigida parte de um item de lista ou célula de tabela com matemática LaTeX colada como uma nova lista ou tabela em editores de rich text
  • [VSCode] Corrigida falha de ditado atrás de um proxy de inspeção TLS quando NODE_EXTRA_CA_CERTS está definido apenas em ~/.claude/settings.json; agora também segue CLAUDE_CODE_CERT_STORE
  • [VSCode] Alterado o aviso "ainda aberto em outro lugar" para cobrir também um processo Claude que sobrou de uma reinicialização de extensão, que geralmente termina sozinho em cerca de 10 minutos
  • [VSCode] Ditado de voz alterado para filtrar seus certificados trusted como o CLI faz
  • [VSCode] Alteradas as próprias solicitações da extensão para filtrar seus certificados trusted como o CLI faz, e para trust o arquivo NODE_EXTRA_CA_CERTS nomeado no ambiente ou nas configurações do usuário
  • [Sessões na nuvem] Corrigido o seletor de repositório dizendo "Nenhum repositório correspondente" enquanto uma pesquisa ainda estava em execução; agora mostra "Pesquisando…" até que os resultados cheguem
  • [Sessões na nuvem] Corrigido o status "Aguardando um runner" em ambientes auto-hospedados sendo cortados; com executores sob demanda agora conta a partir da sua última mensagem e mostra tentativas fracassadas
  • [Revisão de código] Adicionado @claude review stop (também off e pause) à revisão de código, encerrando uma assinatura @claude review always em uma solicitação pull sem iniciar uma nova revisão
