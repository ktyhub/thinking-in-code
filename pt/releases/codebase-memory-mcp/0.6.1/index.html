codebase-memory-mcp 0.6.1

📦 Página de lançamento arquivada — os binários desta versão não são mais publicados. Obtenha o último lançamento.

v0.6.1 — 89 novos idiomas, inteligência entre repositórios, artefato gráfico compartilhado pela equipe, distribuição npm+PyPI

Mais de 50 commits desde v0.6.0. Adiciona 89 gramáticas tree-sitter (66 → 155 idiomas), introduz inteligência cross-repo com bordas CROSS_*, envia artefatos gráficos compartilhados pela equipe (.codebase-memory/graph.db.zst), introduz wrappers de distribuição completos (npm/PyPI/Homebrew/Scoop/Winget/Chocolatey/AUR/Go) com npm + PyPI agora com publicação automática como parte do pipeline de lançamento e implementa um fortalecimento abrangente da segurança do instalador.

Idiomas e análise — 66 → 155

  • 89 novas gramáticas de árvore vendidas, com tokenização limpa de vocabulário e script de auditoria de segurança gramatical
  • Cobertura de especificação de linguagem preenchida para 114 idiomas com tipos de nó adequados — Go (func_literal), JS (do_statement, case_clause obsoleto fixo), importações C#/Python, matrizes compartilhadas
  • 77 novos testes de mapeamento de extensões abrangendo as novas linguagens
  • C#, Rust, gramáticas Scala atualizadas para o upstream mais recente
  • Refator lang_specs: inicializadores designados + ponteiro de fábrica

Inteligência entre repositórios

  • CROSS_ tipos de borda* para dependências entre repositórios e relacionamentos arquitetônicos
  • Detecção de serviço gRPC / GraphQL / tRPC com extração de rota protobuf
  • Detecção de stub gRPC na resolução de chamadas + extração de chamadas encadeadas
  • Layout de UI multigaláxia + visualização resumida da arquitetura entre repositórios

Artefato gráfico compartilhado pela equipe

  • .codebase-memory/graph.db.zst — gráfico de conhecimento compactado em zstd que pode ser confirmado no repositório. Os colegas de equipe inicializam a partir do artefato em vez de executar uma reindexação completa do zero.
  • Zstd 1.5.7 vendido (amalgamado, ~52K LOC) para compactação de 8–13:1
  • Exportação em duas camadas: zstd -9 + index stripping + VACUUM INTO para índices explícitos (melhor proporção); zstd -3 para atualizações automáticas do observador/incrementais (baixa latência)
  • Caminho de importação: descompactar → verificação de integridade → recriar índices automaticamente
  • Auto-bootstrap em index_repository: quando não existe nenhum banco de dados local, mas o artefato está presente, importe primeiro e depois execute a indexação incremental
  • Cria automaticamente .gitattributes com merge=ours para evitar conflitos de mesclagem no artefato binário

Importações e Canais

  • Resolução genérica de pacote/módulo para bordas IMPORTS em 10 idiomas (resolve especificadores básicos como @myorg/pkg, github.com/foo/bar, use my_crate::foo por meio de verificação de manifesto: package.json, go.mod, Cargo.toml, pyproject.toml, composer.json, pubspec.yaml, pom.xml, build.gradle, mix.exs, *.gemspec)
  • Detecção de canal expandida de JS/TS para 8 idiomas

Distribuição

Agora instalável diretamente de registros de pacotes públicos:

npm install -g codebase-memory-mcp     # npm
pip install codebase-memory-mcp         # PyPI
go install github.com/DeusData/codebase-memory-mcp/pkg/go@latest   # Go
  • publicação automática npm + PyPI integrada ao pipeline de lançamento (trabalho publish-registries após verify, então publish-final atômico cancela o rascunho da versão GitHub somente após ambos os registros serem bem-sucedidos - nenhum estado de meio envio)
  • pacote npm usa --provenance (atestados de compilação GitHub OIDC visíveis em npmjs.com)
  • Wrappers de distribuição completos em pkg/ para: npm, PyPI, Homebrew, Scoop, Winget, Chocolatey, AUR, Go

Fortalecimento de segurança

  • Instalador PyPI: reforçado contra ataques tar-slip e esquema-confusão (PR #248 por @dLo999, fecha #246)
  • instalador npm: verificação de soma de verificação, redirecionamentos somente HTTPS, sem injeção de shell
  • Proteção entre instaladores: Unblock-File removido, validação de URL somente HTTPS adicionada
  • vite passou para 6.4.2 — corrige CVE GHSA-4w7w-66w2-5vf9 e GHSA-p9ff-h696-f583
  • Auditoria de segurança gramatical adicionada ao pipeline do fornecedor
  • LEIA-ME: links de varredura VirusTotal (hashes binários), crachá SLSA, seção Segurança e Trust, isenção de responsabilidade de transparência, convite de divulgação responsável
  • crachá de papel arXiv + citação

Estabilidade e Qualidade

  • get_graph_schema agora expõe definições de propriedade por rótulo de nó
  • páginas de estouro do sqlite_writer — corrige o SIGBUS em registros grandes (#139)
  • Recuperação de RSS após delete_project: mem_collect explícito + eliminação imediata
  • Ferramentas MCP / CLI: tratamento de erros, diagnóstico e cancelamento aprimorados
  • Extração escolhida a dedo e melhorias no Cypher do PR #162

Integração Editor/Agente

  • Suporte Kiro CLI (#96)

Correções de plataforma

  • Windows: pass_pkgmap agora usa cbm_strndup (mingw clang não possui POSIX strndup)
  • test_watcher: usa vars env GIT_AUTHOR_* / GIT_COMMITTER_* em vez de alterar a configuração global do git

CI/Fumaça

  • Análise do teste de fumaça JSON corrigido — o modo padrão CLI desembrulha o envelope MCP; smoke agora analisa o JSON interno diretamente
  • Lista de permissões de auditoria de string binária — O esquema telnet URI da primeira gramática é documentado como uma correspondência benigna conhecida

Colaboradores

Obrigado a todos que contribuíram para este lançamento:
