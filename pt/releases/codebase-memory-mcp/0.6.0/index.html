v0.6.0 — Pesquisa semântica, bordas SIMILAR_TO e inteligência entre idiomas

Mais de 85 commits desde v0.5.7. Lançamento principal que adiciona pesquisa semântica baseada em vetores, detecção estrutural de quase clones, resolução de importação entre idiomas e melhorias significativas na qualidade de vida em todas as plataformas.

Pesquisa semântica e incorporações de vetores

  • Ferramenta semantic_query: pesquisa vetorial baseada em palavras-chave em todo o gráfico da base de código por meio da função SQL cbm_cosine_i8
  • Embeddings de código nomic nomic-embed: vetores de token pré-treinados de 40K (768d int8), destilados de nomic-ai/nomic-embed-code com atenção simulada
  • Pontuação combinada de 11 sinais: TF-IDF, indexação aleatória reflexiva, assinaturas API/Tipo/Decorador, perfis estruturais AST, fluxo de dados aproximado, métricas Halstead-lite, MinHash, proximidade do módulo, difusão gráfica
  • Arestas SEMANTICALLY_RELATED: conecte funções com incompatibilidade de vocabulário, mas com finalidade semelhante (pontuação >= 0.80, máximo de 10 por nó, apenas no mesmo idioma)
  • A pontuação min-coseno por palavra-chave substitui a média vetorial mesclada para melhor precisão
  • Pontuação fixada em [0,1] — o multiplicador de proximidade não aumenta mais as pontuações acima de 1.0
  • Clone desduplicação: pares SIMILAR_TO com Jaccard >= limite pular SEMANTICALLY_RELATED

SIMILAR_TO Edges (detecção de quase clone)

  • Impressão digital MinHash: assinaturas de 64 hash de tokens AST somente folha com ponderação estrutural
  • Índice LSH: hashing sensível à localidade baseado em banda para recuperação de candidato O(1)
  • Pontuação paralela: pool de trabalhadores consulta LSH, pontua candidatos, emite bordas
  • Filtros de porta trigrama exclusivos com funções trivialmente curtas
  • Bordas SIMILAR_TO com similaridade Jaccard e flag de mesmo arquivo nas propriedades

Pesquisa de texto completo

  • Pesquisa de texto completo BM25 via FTS5 com tokenizer cbm_camel_split (com reconhecimento de camelCase/snake_case)
  • Reconstrução incremental do FTS5 nas atualizações do índice

Novos tipos e detecção de bordas

  • EMITS / LISTENS_ON bordas para Socket.IO, EventEmitter e padrões de canal genéricos
  • Resolução constante: const EVENT = "foo"; emit(EVENT) resolve nomes de canais por meio de tabelas constantes por arquivo
  • Bordas IMPORTS com resolução de caminho relativo para JS/TS (./foo, ../bar), Python (.helpers, ..utils), Ruby
  • DATA_FLOWS bordas com mapeamento de argumento para parâmetro + cadeias de acesso de campo
  • Descoberta de comunicação entre serviços + Indexação incremental RAM-first
  • Registro de rota baseado em AST substituindo infraestrutura de pré-digitalização
  • Extração de ligação de infraestrutura HCL + correção de falso positivo do decorador de prefixo
  • Registo generalizado de rotas + ponte infra-vinculativa

Consulta de gráfico e melhorias na ferramenta

  • **6 parâmetros anteriormente ignorados conectados **: min_degree, max_degree, exclude_entry_points, include_connected, filtro aspects, since para detect_changes
  • Param include_tests em trace_path — marca arquivos de teste nos resultados do BFS
  • risk_labels em trace_path para rastreamento de caminho sensível à segurança
  • Sinalizador --progress CLI para feedback de indexação em tempo real
  • CBM_CACHE_DIR env var para diretório de banco de dados configurável
  • Modo de índice moderate adicionado ao esquema da ferramenta (entre completo e rápido)
  • Exposição de propriedades do esquema para param_names, param_types, decorators
  • Correção include_connected: entrada e saída do BFS executadas separadamente (estava mesclando incorretamente)

Qualidade de Vida

  • Suporte a .gitignore aninhado: subdiretório gitignores agora respeitado durante a indexação — crítico para monorepos (#178)
  • Consolidação de habilidades: 4 habilidades separadas fundidas em 1 com divulgação progressiva
  • Atualização inteligente: skip update when already on latest version
  • Detecção binária em tempo de execução no comando de instalação (não mais codificado)
  • Suporte ao submódulo Git no observador: detecta estado sujo dentro dos submódulos
  • Detecção rápida → de alteração no modo completo + UI com ativação automática para binário variante da interface do usuário
  • Endpoint de layout: mapeamento de borda O(n*e) substituído por pesquisa binária
  • Layout JSON: trata UTF-8 e NaN inválidos na serialização

Correções de plataforma

  • Windows: caminhos de configuração Zed/VS Code/KiloCode, delimitador PATH, verificação S_IXUSR, detecção de agente usando caminhos relativos a home_dir, teste de configuração de usuário baseado em APPDATA
  • Linux portátil: compatibilidade Alpine musl, auditorias de segurança adicionadas aos testes de fumaça, XDG_CONFIG_HOME em ambiente de fumaça
  • Montagem de blob vetorial multiplataforma: condicionais de pré-processador para macOS Mach-O/Linux ELF/Windows COFF
  • Correção SEGV C++: deref NULL no resolvedor de tipo LSP em arquivos de cabeçalho grandes

Qualidade de código e linting

  • 337 avisos de linter resolvidos em 16 arquivos (constantes nomeadas, extração de complexidade cognitiva)
  • Limite de complexidade cognitiva definido como padrão da indústria (25), divisão de 168 funções
  • Divisão de função divina cbm_write_db (569 → 325 linhas)
  • Todas as supressões NOLINTNNEXTLINE eliminadas, caminhantes AST iterativos
  • Correção de vazamento de ASan no corpus semântico token_map

CI/CD e segurança

  • Portão de segurança desacoplado: segurança estática + CodeQL executado de forma independente, não bloqueia pipeline de teste/construção/fumaça
  • Auditorias de segurança em TODAS as variantes binárias (padrão + UI) — anteriormente os binários da UI não eram auditados
  • Vocabulário de token seguro para AV: 11 palavras de ativação heurística removidas dos embeddings Nomic
  • CI dividido em componentes de fluxo de trabalho reutilizáveis
  • Problemas de dependência de fornecedores: SQLite 3.51.3, Mongoose 7.21, mimalloc 3.2.8
  • Ações alteradas: download-artefato v8.0.1, attest-sbom v2, fiador v4.1.1, msys2 v2.31.0, checkout v6.0.2, cache v5.0.4, upload-artefato v7.0.0, attest-build-provinance v4.1.0, codeql-action v4.35.1
