codebase-memory-mcp v0.10.8

#v0.10.8

Nota sobre v0.10.7: esta versão substitui v0.10.7, que foi perdida para um pipeline de lançamento erro de publicação (publicado sob a tag 0.10.7 em vez de v0.10.7; instaladores de pacotes resolver a tag com prefixo v e a imutabilidade da liberação torna o nome irrecuperável). O npm e os pacotes PyPI 0.10.7 estão obsoletos/retirados por esse motivo — seus binários estavam bem, seus URLs de download não eram. v0.10.8 carrega o conteúdo de código idêntico mais o pipeline endurecimento que evita a recorrência.

Um lançamento de patch pesado para a comunidade: 19 solicitações pull mescladas desde v0.10.6, a maioria de contribuidores. Obrigado a todos!

Correção do gráfico

  • Agregados Cypher não são mais subestimados (#1196). Ambos os mecanismos de truncamento são fixos: varreduras não rotuladas pararam de coletar candidatos em max_rows antes da agregação ser executada (#1323, @Enferlain), e os buffers de expansão de relacionamento foram limitados para que a agregação nunca vi linhas além de um limite de crescimento interno (#1698). count()/collect() agora veja o conjunto completo de jogos; max_rows limita apenas as linhas retornadas, conforme documentado.
  • Python com alias de importação resolve para a definição real (#1371, @Joseph-MingEn). from .gate import execute as bridge_execute agora produz uma borda CALLS para execute em si, em vez de perder a ligação, e as importações de classe base com pseudônimo chegam à classe real nó. Em nosso benchmark Django, isso recuperou 26 arestas INHERITS e 42 OVERRIDE com zero perdas em outros lugares e deixou os gráficos TypeScript idênticos em bytes.
  • Correspondência de sufixos entre idiomas para pesquisas de nomes qualificados (#1647, @rudi193-cmd).
  • search_graph para de retornar fantasmas apenas semânticos — resultados apoiados por nada além de um borda de similaridade não aparece mais como se fossem correspondências definitivas (#1319, @JJordan0C).
  • Os campos com valor de lista são extraídos corretamente em vez de serem recolhidos para o primeiro elemento (#1325, @Enferlain).
  • As respostas do índice relatam a cobertura persistente com sinceridade (#1326, @Enferlain): um a execução incremental que não revisita um arquivo com lacunas de análise registradas não informa mais essas lacunas desapareceram - a resposta agora compõe seus resumos parciais ignorados/analisados do estado de cobertura armazenado, retornando aos dados por execução somente se a leitura falhar.

##Janelas

  • O conteúdo de pesquisa não ASCII não é mais degradado para ? (#1704). A varredura bruta search_code canaliza a saída do PowerShell e o PowerShell 5.1 codifica esse canal no console OEM página de código - portanto, conteúdo cirílico, CJK ou acentuado se transformou em pontos de interrogação dependendo qual console o servidor herdou. O pipe agora está fixado em UTF-8 incondicionalmente.
  • search_code entende caminhos de saída UTF-8 e ganha uma coluna de contexto para correspondências (#1253, @anfedoro).
  • A pesquisa de código é limitada e cancelável — abandonar uma consulta não deixa mais um verificação órfã em execução (#1608, @ertankucukoglu).

Plataformas e ferramentas

  • Suporte FreeBSD (#1467, @PR9000).
  • paginação list_projects: uma resposta padrão enxuta mais deslocamento/limite e include_details para a visualização completa (#1181, @tmonestudio).
  • Scripts shebang sem extensão detectam seu idioma (#1203, @ibaldr89).
  • Reconstrução da capacidade do modo de índice (#1263, @astandrik).
  • detecção is_test para testes/diretórios (#1308) e um **clang-tidy com reconhecimento de diferença gancho ** (# 1310, ambos @Yyunozor).

Pipeline de lançamento (a lição v0.10.7, reforçada)

  • As portas de liberação falham quando fechadas em trabalhos cancelados: uma porta expirada não pode mais ser cascata uma matriz de teste ignorada silenciosamente (#1719).
  • Entradas de versão malformadas são recusadas na simulação - uma versão simples e sem prefixo v nunca pode publique novamente uma tag insolúvel (#1719).

Interno

  • Os equipamentos de teste usam tempos de execução de daemon isolados para que as execuções do conjunto não possam afetar a conta daemon (#1695, @astandrik); Contratos de checkout LF para pontos de entrada do shell e ganchos git (#1314 @mlandolfi90, #1699 com @xumian520); os testes de regressão stdin-gate não são mais dependem do registro enviar uma ferramenta de argumento zero (#1704).
