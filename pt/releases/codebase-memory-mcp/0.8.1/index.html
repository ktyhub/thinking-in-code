codebase-memory-mcp v0.8.1

Uma continuação focada do v0.8.0.

Servidor HTTP primário

O servidor web Graph-UI foi reimplementado do zero como um módulo interno enxuto – um refatorador que remove a última biblioteca de servidor de terceiros do binário. O novo transporte (src/ui/httpd.c) foi desenvolvido especificamente para o que a UI realmente precisa:

  • Somente localhost por construção — vincula 127.0.0.1 exclusivamente, com opções de soquete corretas para a plataforma em cada sistema operacional.
  • Análise estrita de HTTP/1.1 — limites de solicitação rígidos (cabeça de 16 KB/corpo de 1 MB), manuseio rigoroso de CRLF, correspondência de caminho bruto e prazo de recebimento por conexão.
  • Simples por design — uma solicitação por conexão (Connection: close); nenhuma máquina de estado keep-alive, nenhuma codificação fragmentada.

Um novo conjunto de transporte e roteamento de 28 testes cobre a análise de casos extremos, política CORS, envio RPC e comportamento de desligamento. Todas as rotas, códigos de status e a política CORS somente localhost se comportam exatamente como antes.

Também nesta versão

  • Conjunto de gramática mais reduzido — a gramática nim (de longe a maior gramática vendida com 66 MB) foi eliminada; 158 idiomas permanecem suportados.
  • Pacote de atribuição em cada arquivo — os arquivos de lançamento agora incluem THIRD_PARTY_NOTICES.md, um arquivo consolidado com os textos de licença de todos os componentes vendidos. As instalações do Homebrew e do AUR colocam-no ao lado do binário.
  • SBOM mais rico — licença por componente e metadados de versão para tudo compilado no binário.
  • Conjunto de testes: 5.604 testes (+27 vs v0.8.0).
