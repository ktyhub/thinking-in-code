codebase-memory-mcp v0.5.0

Conclua Vá para C Reescrever

v0.5.0 é a primeira versão construída inteiramente a partir de C. Toda a base de código - pipeline, armazenamento, servidor MCP, CLI, observador - foi reescrita de Go para C, com gramáticas de árvore compiladas via CGo substituídas pela fonte C fornecida para todos os 64 idiomas.

O que isso permite

  • Pipeline RAM-first: toda a indexação é executada na memória (leitura compactada LZ4 HC, SQLite na memória, dump único no final). Zero E/S de disco entre o carregamento em massa e a gravação final.
  • Correspondência multipadrão Fused Aho-Corasick: a resolução de chamada usa uma única passagem pelo AST com todos os padrões carregados simultaneamente, substituindo o grep sequencial por função.
  • Resolvedor LSP híbrido C/C++: substituição de modelo, cadeias de ponteiros inteligentes, pontuação de sobrecarga, inferência lambda/decltype, envio virtual – mais de 700 testes dedicados.
  • mimalloc global allocator: rastreia todas as alocações (C + C++ por meio de substituição global), permitindo um orçamento preciso de memória por trabalhador.
  • Sem sobrecarga de limite CGo: toda a análise de tree-sitter acontece em C puro - sem salto CGo por arquivo.

Desempenho

Indexando o kernel Linux (28M LOC, 75K arquivos): Modo completo: 2,1 milhões de nós, 5m33s (Apple M3 Pro) Modo rápido: 1,88 milhões de nós, 1m12s (Apple M3 Pro)

Novo: UI de visualização de gráfico

v0.5.0 é enviado em duas variantes:

  • padrão -- Somente servidor MCP (binário menor)
  • ui -- Servidor MCP + visualização gráfica 3D incorporada Habilite a IU: ```bash codebase-memory-mcp --ui=true --port=9749 ``` Em seguida, abra http://localhost:9749 para explorar visualmente seu gráfico de conhecimento. A IU é executada como um thread de segundo plano no host local, servindo ativos de front-end incorporados e consultas de proxy para uma conexão SQLite somente leitura.

Detecção automática de sessão + índice automático

O servidor MCP agora detecta a raiz do seu projeto no diretório de trabalho no início da sessão. Combinado com o armazenamento de configuração: ```bash configuração codebase-memory-mcp definida auto_index true ``` Quando ativado, novos projetos são indexados automaticamente na primeira conexão MCP e o inspetor os registra para detecção contínua de alterações com base em git. Os projetos indexados anteriormente são sempre registrados no inspetor, independentemente desta configuração. A configuração CLI suporta: `list`, `get <key>`, `set <key> <value>`, `reset <key>`.

Instalação multiagente (8 agentes de codificação)

`codebase-memory-mcp install` agora detecta automaticamente todos os agentes de codificação instalados e configura cada um deles com entradas do servidor MCP, arquivos de instrução e ganchos de pré-ferramenta quando suportados. | Agente | Configuração MCP | Instruções | Ganchos | |-------|-----------|-------------|-------| | Código Cláudio | .claude/.mcp.json | 4 Habilidades (padrão diretivo) | PreToolUse em Grep/Glob/Read | | Códice CLI | .codex/config.toml | .codex/AGENTES.md | -- | | Gêmeos CLI | .gemini/settings.json | .gemini/GEMINI.md | BeforeTool em grep/leitura | | Zé | configurações.json (JSONC) | -- | -- | | Código aberto | código aberto.json | .config/opencode/AGENTS.md | -- | | Antigravidade | mcp_config.json | .gemini/antigravity/AGENTS.md | -- | | Ajudante | -- | CONVENÇÕES.md | -- | | QuiloCódigo | mcp_settings.json | ~/.kilocode/rules/ | -- |

Melhorias no comportamento agente

Os agentes agora preferem ativamente ferramentas MCP em vez de grep/glob/read para descoberta de código:

  • Descrições de habilidades diretivas alcançam aproximadamente 100% de ativação automática (acima de aproximadamente 37% com o antigo padrão descritivo)
  • Ganchos PreToolUse / BeforeTool imprimem lembretes de aconselhamento quando os agentes acessam ferramentas de pesquisa integradas
  • Descrições de ferramentas MCP ricas em palavras-chave melhoram a descoberta da pesquisa de ferramentas de Claude
  • Arquivos de instruções com exemplos concretos e orientações explícitas de fallback para todos os agentes
  • Verificação de atualização de inicialização notifica na primeira chamada de ferramenta se uma versão mais recente estiver disponível Essas melhorias foram impulsionadas por relatórios e contribuições da comunidade:
  • @David34920 -- relatou Claude ignorando ferramentas MCP sem edições CLAUDE.md (#69)
  • @sonicviz – análise detalhada da heurística de seleção de ferramentas de agente (#34)
  • @chitralverma -- relatou Gemini CLI usando ferramentas integradas como padrão (#19)
  • @noelkurian – identificado bug no formato de configuração do Zed e problema de análise do JSONC (#24)
  • @zeval -- OpenCode instala PR com pesquisa de caminho de configuração (#36)
  • @harshil480 -- KiloCode instala PR com formato de configuração e plano de teste (#53)

Correções

  • Zed: Config agora usa args:[""] em vez de source:"custom" quebrado (#24)
  • Zed: o analisador lida com JSONC (comentários + vírgulas finais) nas configurações existentes.json
  • A instalação é idempotente: executar a instalação duas vezes não produz duplicatas - upsert baseado em marcador para instruções, upsert baseado em chave para configurações JSON/TOML

Suporte multiplataforma

Totalmente testado em todas as plataformas com ASan + LeakSanitizer + UBSan: | Plataforma | Testes | Construir | |----------|-------|-------| | macos arm64 | 2030 passou | OK | | macOS AMD64 | OK | OK | | Linux arm64 | 2012 passou | OK | | Linux amd64 | OK | OK | | Windows amd64 | OK | OK (CLANG64) | Dependências de fornecedores (zero requisitos de biblioteca do sistema): sqlite3, mimalloc, tempo de execução tree-sitter, yyjson, zlib, TRE regex (somente Windows).

Atualizando

```bash atualização de memória de código base-mcp ``` Ou nova instalação: ```bash curl -fsSL https://raw.githubusercontent.com/DeusData/codebase-memory-mcp/main/install.sh | festa instalação de memória-mcp de código -y ``` Os índices existentes serão reconstruídos automaticamente – o pipeline C produz um formato de gráfico diferente (melhorado).
