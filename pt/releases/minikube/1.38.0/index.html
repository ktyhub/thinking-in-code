#minikube v1.38.0

📣😀 Por favor, preencha nossa pesquisa rápida de 5 perguntas para que possamos saber como e por que você usa o minikube e quais melhorias devemos fazer. Obrigado! 💃🎉

Release Notes

Versão 1.38.0 - 28/01/2026

Destaques

  • Não é necessário Sudo para vfkit/krunkit no macOS 26+ (requer o vmnet-helper mais recente)
  • Não é necessário Sudo para executar AI Playground em GPUs Macos usando minikube
  • vfkit: Adicionado suporte Rosetta para implantação de imagens AMD64 em Apple Silicon (#22140)

Recursos

  • Adicionar suporte para Kubernetes v1.35.0 (#21650)(#22015)(#22119)(#22328)
  • Drivers VM: adicione suporte para dispositivos de bloco NVMe-oF/TCP (#22464)
  • Drivers VM: habilite símbolos de depuração BTF para suportar ferramentas eBPF em iso (#21800)
  • Adicionada opção para baixar pré-carregamentos do github em vez do GCS através de --preload-source (#22221)
  • Drivers Vfkit/Krunkit: adicionam capacidade de executar vmnet-helper como usuário sem privilégios no macOS 26+ (#22501)
  • adicionar opção para adicionar complementos baseados em helm (#21847)
  • pré-carregamento: download do github quando o gcs não estiver disponível (#21605)

Avisos e depreciações

  • UI: Adicione um aviso ao alterar o tempo de execução padrão para "containerd" na próxima versão (v1.39.0) (#22508)
  • hyperkit: remova compilações de driver e avise os usuários para mudar (#21946)
  • Remova o suporte ao minikube para arquiteturas de 32 bits (#22401)

Melhorias

  • UI: colorida com base no status (lista de perfis, lista de complementos) (#22418)
  • Ignore o cache de binários quando --no-kubernetes estiver definido (#21139)
  • melhore os registros de novas tentativas para imprimir menos linhas duplicadas (#22232)
  • melhorar o ssh runner copiando arquivos cert (#21923)
  • vmnet: Ignora validação no modo somente download (#21635)
  • Melhore o certificado do Windows no kubeconfig: normalize os caminhos de certificado gerados para barras (#21845)
  • Adicionar verificação do freezer cgroup v2 para status do servidor API (#22249)
  • Defina a opção FailCgroupV1 kubelet para kubenetes 1.35+ se cgroup v1 (#22319)
  • containerd: tente novamente em erros EOF transitórios para carregamento de imagem (#22310)
  • cri: aumenta o tempo limite padrão de 2s para comandos crictl (#22214)
  • crio: verifique se as imagens foram excluídas após "image rm" (#22243)
  • Tempo de execução docker: Use CRI para a função ListImages (#22263)
  • salvamento de imagem: adicione lógica de nova tentativa para imagem local em caso de EOF (#22072)
  • HA (plano multicontrole): Atualize kube-vip de v1.0.0 para v1.0.3 (#21699)(#21960)(#22258)

Motoristas
