#Release Notes

Versão 1.35.0 - 15/01/2025

Recursos:

  • Adicione suporte para GPUs AMD via --gpus=amd #19749
  • Use ativos Github como novo failover para imagem base kic #19464
  • Suporte mais recente Kubernetes v1.32.0 #20091
  • Adiciona suporte para kubeadm.k8s.io/v1beta4 (disponível desde k8s v1.31) #19790

Melhorias:

  • Mesclar nvidia-gpu-device-plugin e nvidia-device-plugin. #19545
  • kicbase: Atualizar pacotes nvidia #19738
  • cílio: remova appArmorProfile para k8s<v1.30.0 #19888
  • pausa automática: reinicie o serviço após a configuração #19900
  • Reverter "Alterar lógica MINIKUBE_HOME" #20045
  • não polua a lista de perfis do minikube com erros se o código de saída estiver ausente #19728
  • consulta unificada de status do cluster minikube #18998
  • Driver Vfkit: corrige falha de TestMachineType no macOS #19726
  • Não há mais restrições de arco no nerdctld #19730
  • Correspondência de endereço MAC mais robusta #19750
  • Adicione instruções para resolver o erro de contexto docker #19197

Correções de bugs:

  • corrigir a falha de --wait em funcionar em pods coredns #19748
  • Corrija o pânico quando não houver serviços no namespace com --all especificado #19957
  • correção do tempo limite ao parar a máquina KVM com tempo de execução do contêiner CRI-O #19758
  • Correção de linhas longas em lastStart.txt que não são exibidas nas saídas de log #19740
  • Correção da detecção incorreta do arco kicbase como incorreto #19664

Quebrando mudanças:

  • remova arm64 kvm #19985 #20062
  • remover complemento do leme do leme #19636

  • Melhorar a tradução francesa #19654 #19978
