#minikube v1.37.0

📣😀 Por favor, preencha nossa pesquisa rápida de 5 perguntas para que possamos saber como e por que você usa o minikube e quais melhorias devemos fazer. Obrigado! 💃🎉

Release Notes

Versão 1.37.0 - 09/09/2025

Destaque

Execute cargas de trabalho de IA na GPU do Macbook em Kubernetes usando o novo krunkit driver. Comece com nosso tutorial AI Playground

Recursos

  • Adicionar suporte para Kubernetes v1.34.0 (#21439)
  • Adicionado driver krunkit com suporte para aceleração de GPU no macOS (#20826) Tutorial
  • adicione a abreviatura -m para --memory (#20854)
  • Adicionado suporte ao tempo de execução docker para acesso OCI a GPUs NVIDIA (#20959)
  • Adicione o sinalizador --disable-coredns-log para suprimir logs coredns (#20992)
  • novo complemento: kubetail (#20345)
  • drivers: Adicionado suporte para montagens Virtiofs para vfkit e krunkit (#21149)

Melhorias

  • Melhore o complemento ingress-dns para ipv4 e windows v0.0.4 (#21449)
  • iso: Desativa o tempo limite do grub, acelerando o início do VM em 5 segundos (#20895)
  • melhorar a confiabilidade do serviço docker, atualizar arquivos systemd docker (#21174)
  • Não exija --mount para usar --mount-string e remova a string de montagem padrão (#21250)
  • Atualize as versões Kubernetes suportadas mais antigas (#21490)
  • licença cmd: não falhe se o diretório de saída não existir e baixe primeiro dos ativos github (#21206)
  • remover sinalizador obsoleto proxy-refresh-interval v2 etcd (#21278)
  • vmnet: Suporte para descarregamento para krunkit (#20831)
  • Não chame startKicServiceTunnel para drivers que não sejam kic (#20863)
  • krunkit: Desative o descarregamento para uma rede mais rápida (#21341)
  • HA (plano multicontrole): Atualize kube-vip de v0.9.1 para v1.0.0 (#20999)(#21228)

Depreciação

  • Descontinuar o driver HyperKit com aviso (#21024)

Correções de bugs

  • corrigir versão suja do commit (#21062)
  • Corrigir carregamento de imagem minikube no Windows (#20529) (#20921)
  • Corrija a montagem na mesma pasta causando erro de entrada/saída (#21077)
  • correção: problema de erro de escape de arquivo YAML afetando complementos (#20904)
  • iso: Corrija minikube stop com drivers vfkit e krunkit (#21089)
  • iso: Consertar console para vfkit/krunkit (#20832)

Complementos

  • Addon nvidia-device-plugin: Atualize a imagem nvidia/k8s-device-plugin de v0.17.2 para v0.17.3 (#21225)
  • Addon cloud-spanner: atualize a imagem do emulador / emulador do cloud-spanner de 1.5.34 para 1.5.41 (#20976)(#21040)(#21243)(#21287)(#21359)(#21512)
  • Addon Headlamp: Atualize a imagem do farol de v0.28.0 para v0.34.0 (#21238)(#21508)
  • Entrada de complemento: atualize a imagem do ingress-nginx/controlador de v1.12.2 para v1.13.2 (#20909)(#21232)(#21353)(#21458)
  • Addon inspektor-gadget: Atualize a imagem do inspektor-gadget de v0.40.0 para v0.44.1 (#20873)(#21038)(#21240)(#21462)(#21510)(#21358)
  • Addon kong: Atualize a imagem kong de 3.9.0 para 3.9.1 (#20966)(#21503)
  • Addon kong: Atualize a imagem do controlador de entrada kong/kubernetes de 3.4.5 para 3.5.1 (#20908)(#20969)(#21034)(#21282)
  • Addon kubevirt: Atualize a imagem bitnami/kubectl de 1.33.1 para 1.33.4 (#20911)(#20939)(#21235)(#21283)(#21414)
