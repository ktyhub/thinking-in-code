#minikube v1.33.0

📣😀 Por favor, preencha nossa pesquisa rápida de 5 perguntas para que possamos saber como e por que você usa o minikube e quais melhorias devemos fazer. Obrigado! 💃🎉

Release Notes

Versão 1.33.0 - 19/04/2024

Recursos:

  • Suporte a plano multicontrole - clusters HA --ha #17909 Tutorial
  • Adicionar suporte para Kubernetes v1.30 #18669
  • Suporte à exposição de serviços clusterIP via minikube service #17877
  • Addon gvisor: Adicionar suporte arm64 #18063 #18453
  • Novo complemento: YAKD - complemento do painel Kubernetes #17775

Pequenas melhorias:

  • Adicione kubecontext ativo à saída minikube profile list #17735
  • CNI chita: suporte kubeadm.pod-network-cidr #18233
  • Ponte CNI: certifique-se de que as comunicações do pod sejam permitidas #16143
  • Pausa automática do complemento: remova vazamento de memória e adicione intervalo configurável #17936
  • construção de imagem: adicione docker.io/library aos nomes curtos de imagem #16214
  • cp: Cria diretório se não estiver presente #17715
  • Mover erros ao obter logs para a própria saída de log #18007
  • Adicione sysctls padrão para permitir portas privilegiadas sem recursos #18421
  • Incluir atributos estendidos em tarballs pré-carregados #17829
  • Aplique o rótulo kubeadm.applyNodeLabels a todos os nós #16416
  • Limite a verificação do status do driver a 20s #17553
  • Incluir logs do journalctl se o serviço systemd falhar ao iniciar #17659
  • Correção "Falha ao ativar o tempo de execução do contêiner: sudo systemctl restart cri-docker" #17907
  • Corrigido o download do containerd novamente de imagens existentes ao iniciar #17671
  • Correção do kvm2 não detectando pré-carga do containerd #17658
  • Correção da modificação da configuração binfmt do Docker #17830
  • Corrigir complemento de pausa automática #17866
  • Correção de não uso de pré-carregamento com driver de armazenamento overlayfs #18333
  • Correção de repositórios de imagens que não permitem subdomínios com números #17496
  • Corrigida a parada do cluster ao usar kvm2 com containerd #17967
  • Correção ao iniciar mais de um cluster no kvm2 arm64 #18241
  • Correção de inicialização de clusters kvm2 usando Linux em arm64 Mac #18239
  • Correção de erro de exibição ao excluir cluster inexistente #17713
  • Corrigido o não respeito do limite na reinicialização #17598
  • Correção de não aplicação do rótulo kubeadm.applyNodeLabels aos nós adicionados após o início inicial #16416
  • Correção da saída do delimitador de logs #17734

Erros:

  • Corrigir regex de host local sem escape #18617
  • Correção de regex em ValidNetwork para suportar caracteres especiais #18158

Atualizações de versão:

  • Versão padrão do Bump Kubernetes: v1.30.0 e mais recente: v1.30.0 #18669
  • Farol adicional: atualize a imagem do farol-k8s/farol de v0.23.0 para 0.23.1 #18517
  • Addon inspektor-gadget: Atualize a imagem do inspektor-gadget de v0.26.0 para v0.27.0 #18588
  • Addon istio-provisioner: Atualize a imagem do istio/operador de 1.21.0 para 1.21.1 #18644
  • Servidor de métricas adicional: atualize a imagem do servidor de métricas/servidor de métricas de v0.7.0 para v0.7.1 #18551
  • CNI: Atualizar chita de v3.27.0 para v3.27.3 #18206
  • CNI: Atualize a flanela de v0.24.4 para v0.25.1 #18641
  • Kicbase/ISO: Atualize o buildkit de v0.13.0 para v0.13.1 #18566
  • Kicbase/ISO: Atualize o contêiner de v1.7.14 para v1.7.15 #18621
  • Kicbase/ISO: Atualize cri-dockerd de v0.3.3 para v0.3.12 #18585
  • Kicbase/ISO: Atualizar crun de 1.14 para 1.14.4 #18610
  • Kicbase/ISO: Atualize docker de 25.0.4 para 26.0.1 #18485 #18649
  • Kicbase/ISO: Atualizar nerdctl de 1.7.4 para 1.7.5 #18634
  • Kicbase: Atualize nerdctld de 0.5.1 para 0.6.0 #18647
