Release Notes

Versão 1.39.0 - 01/09/2026

Destaques

  • Adicione suporte para Kubernetes v1.36 e v1.37 (padrão: v1.37.0)
  • O tempo de execução padrão do contêiner agora é containerd
  • Adicionar complemento de entrada baseado no Traefik Helm
  • O driver VirtualBox agora suporta Apple Silicon (VirtualBox 7.1+)

Recursos

  • Adicionado suporte para Kubernetes v1.36 e v1.37 (padrão: v1.37.0) (#23567, #23596)
  • Adicionar complemento baseado em Traefik Helm (#23225)
  • Adicionar Helm ao minikube ISO (#23420)
  • Atualize o Helm convidado padrão client para Helm 4 (#23383)
  • Adicione servidores DNS configuráveis para drivers VM (#23069)
  • Adicione o sinalizador --mdns para ativar o mDNS em cada início de VM (#22964, #23208)
  • drivers: Use endereços MAC determinísticos (#23172)
  • vfkit: seleção automática de rede compartilhada vmnet quando disponível (#23040)
  • virtualbox: Suporte darwin/arm64 com VirtualBox 7.1+ (#22861)
  • ISO: Adicionar systemd-coredump para rastreamentos de pilha de falhas (#23064)
  • ISO: Habilitar nftables de kernel (CONFIG_NF_TABLES) para consumidores knftables (#23518)
  • ISO: Habilite securityfs para Calico 3.32.2 (#23592)
  • ISO: Inclui módulo de kernel openvswitch para aarch64 (#23151)
  • ISO: Habilite CONFIG_TASK_IO_ACCOUNTING e opções de kernel relacionadas (#23271)
  • infra: Baixe pré-carregamentos do GitHub como padrão e GCS como failover (#23087)

Desempenho

  • drivers: inicie drivers VM em paralelo (#23112)
  • Adicione o sinalizador de inicialização --vmnet-offloading para o driver krunkit (#22962)
  • ssh: Prefira cifras AES-GCM para SSH externo client (#23125)
  • ssh: Evite suspensão desnecessária ao aguardar pelo servidor SSH (#23001)

Correções de bugs

  • complementos: corrige falha de verificação do Helm dentro de VMs convidadas (#23253, #23329)
  • Corrija o kubectl exec com cri-dockerd em Kubernetes v1.36+ desativando ExtendWebSocketsToKubelet (#22921)
  • Corrigido --extra-config=etcd.* produzindo configuração kubeadm inválida (#23051)
  • Correção da lógica para aviso CNI de vários nós. (#22779)
  • Corrigido SSHRunner ExitCode sempre retornando 0 para comandos SSH (#23364)
  • Correção da string de uso para comandos do nó minikube. (#22775)
  • kvm: Verifique a associação ao grupo libvirt antes de executar o virsh (#23369)
  • Correção da tag de preservação para referências de registro com uma porta (#23228)
  • Use canais em buffer para evitar vazamento de goroutine no tempo limite de status (#23215)
  • Corrigido aviso contra virtualbox somente quando o sinalizador é explícito (#22960)
  • carregamento de imagem: corrige falha silenciosa ao carregar uma imagem usada por um contêiner (#23034)
  • adição de nó: use SuggestMemoryAllocation em vez de 2.200 MB codificados (#23305)
  • proxy: use os wrappers do RoundTripper para remover o proxy no *http.Transport interno (#22910)
  • vmnet: corrige o caminho de instalação do brew em Macs Intel e suporta o caminho brew bin (#23039)
  • mount: Esclareça a necessidade de regras de firewall bidirecionais (#20442)
  • drivers: Tratamento de concessão de DHCP desduplicado no macOS (#23084)
  • hack/atualização: rastreie o complemento do registro na tag principal (#23586)
  • hack/atualização: atualize a tag da imagem kong para 3 (#23585)
  • ISO: Substitua espaços por tabulações nos arquivos do pacote Buildroot nerdctl-bin (#23438)
  • ISO: Tentativa de corrigir falhas de compilação ISO (#22879)
  • ISO: corrige a confiabilidade do script de construção ISO e tratamento de erros (#23218)
  • ISO: Suporte à construção do ISO arm64 em um host arm64 (#22862)
  • ISO: Use binários para docker buildx em vez de construir a partir do código-fonte (#22942)

Mudanças importantes

  • Altere o tempo de execução do contêiner padrão para containerd (#23562)
  • ISO/KIC: Limite o suporte para cri-dockerd para x86 e arm64 e migre cri-dockerd para binários GitHub pré-compilados (#22922)
