Versão 1.33.1 - 13/05/2024

Erros:

  • Corrigir erros DNSSEC validation failed #18830
  • Corrigir erros too many open files #18832
  • CNI cilium: corrige falha de inicialização dos pods cilium #18846

  • Addon cloud-spanner: atualize a imagem do emulador / emulador do cloud-spanner de 1.5.15 para 1.5.17 #18773 #18811

  • Entrada de complemento: atualize a imagem do ingress-nginx/controlador de v1.10.0 para v1.10.1 #18756
  • Addon istio-provisioner: atualize a imagem do istio/operador de 1.21.1 para 1.21.2 #18757
  • Addon kubevirt: atualize a imagem bitnami/kubectl de 1.29.3 para 1.30.0 #18711 #18771
  • Addon nvidia-device-plugin: Atualize a imagem nvidia/k8s-device-plugin de v0.14.5 para v0.15.0 #18703
  • Cílio CNI: Atualização de v1.15.1 para v1.15.3 #18846
  • Alta disponibilidade: atualize kube-vip de 0.7.1 para v0.8.0 #18774
  • Kicbase/ISO: Atualize docker de 26.0.1 para 26.0.2 #18706
  • Kicbase: Bump ubuntu:jammy de 20240227 a 20240427 #18702 #18769 #18804
