Release Notes

Versão 1.32.0 - 2023-11-08

Recursos:

  • Suporte a GPU NVIDIA com novo sinalizador --gpus=nvidia para driver docker #15927 #17314 #17488
  • sem raiz: suporte --container-runtime=docker #17520
  • Novo complemento kubeflow #17114
  • Novo complemento local-path-provisioner #15062
  • Kicbase: Adicionar opção no-limit aos sinalizadores --cpus e --memory #17491

Pequenas melhorias:

  • Hyper-V: Adicionar validação de memória para números ímpares #17325
  • QEMU: Melhore o tipo de CPU e a detecção de IP #17217
  • Mascarar a senha http(s)_proxy da saída de inicialização #17116
  • --delete-on-faliure também recria cluster para falhas de kubeadm #16890
  • Pausa automática adicional: configure intervalos usando --auto-pause-interval #17070
  • --kubernetes-version verifica GitHub para validação de versão e saída de erro aprimorada para versões inválidas #16865
  • Instale o kit de ferramentas de contêiner NVIDIA durante a construção da imagem (suporte offline) #17516

Erros:

  • QEMU: Corrige complementos que não conseguem ativar #17402
  • Corrigido o download de imagens kubeadm erradas para versões k8s após o lançamento do minikube #17373
  • Correção de ativação e desativação de complementos com cluster inexistente #17324
  • Correção de exclusão se o tempo de execução do contêiner não existir #17347
  • Correção de rede não encontrada não sendo detectada nas novas versões Docker #17323
  • Corrigir registro de complemento que não segue a configuração do nome de domínio DNS do Minikube (--dns-domain) #15585
  • Correção da opção sem limite para validação de configuração #17530

Atualizações de versão:

  • Versão padrão do Bump Kubernetes: v1.28.3 e mais recente: v1.28.3 #17463
  • Addon cloud-spanner: atualize a imagem do emulador / emulador do cloud-spanner de 1.5.9 para 1.5.11 #17225 #17259
  • Farol adicional: atualize a imagem do farol-k8s/farol de v0.19.0 para v0.20.1 #17135 #17365
  • Entrada de complemento: atualize a imagem do ingress-nginx/controlador de v1.8.1 para v1.9.4 #17223 #17297 #17348 #17421 #17525
  • Addon inspektor-gadget: Atualize a imagem do inspektor-gadget de v0.19.0 para v0.22.0 #17176 #17340 #17550
  • Addon istio-provisioner: atualize a imagem do istio/operador de 1.12.2 para 1.19.3 #17383 #17436
  • Addon kong: Atualize a imagem kong de 3.2 para 3.4.2 #17485
  • Addon kong: Atualize a imagem do controlador de entrada kong/kubernetes de 2.9.3 para 2.12.0 #17526
  • Registro adicional: atualize a imagem do registro de 2.8.1 para 2.8.3 #17382 #17467
  • Addon nvidia-device-plugin: Atualize a imagem nvidia/k8s-device-plugin de v0.14.1 para v0.14.2 #17523
  • CNI: Atualizar chita de v3.26.1 para v3.26.3 #17363 #17375
  • CNI: Atualize a flanela de v0.22.1 para v0.22.3 #17102 #17263
  • CNI: Atualizar kindnetd de v20230511-dc714da8 para v20230809-80a64d96 #17233
  • Kicbase/ISO: Atualizar buildkit de v0.11.6 para v0.12.3 #17194 #17486
