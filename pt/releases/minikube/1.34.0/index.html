Release Notes

Versão 1.34.0 - 04/09/2024

Quebrando mudanças:

  • Aumente a versão mínima do podman para 4.9.0 #19457
  • Proibir o uso do Docker Desktop 4.34.0 #19576

Recursos:

  • Aumente a versão padrão do Kubernetes para v1.31.0 #19435
  • Adicione novo driver para macOS: vfkit #19423
  • Adicionar suporte de driver Parallels para darwin/arm64 #19373
  • Adicionar novo complemento de vulcão #18602
  • Addons ingress-dns: Adicionado suporte para todas as arquiteturas #19198
  • Suporta portas privilegiadas no WSL #19370
  • Drivers VM com tempo de execução de contêiner docker agora usam docker-buildx para construção de imagem #19339
  • Suporte para execução de QEMU x86 em arm64 #19228
  • Adicionada opção -o json para o comando addon images #19364

Melhorias:

  • add -d abreviação para --driver #19356
  • adicione -c abreviação para --container-runtime #19217
  • kvm2: Não exclua a rede libvirt "padrão" #18920
  • Atualizar uso de MINIKUBE_HOME #18648
  • CNI: Permissões atualizadas para oferecer suporte a políticas de rede no kindnet #19360
  • GPU: Defina NVIDIA_DRIVER_CAPABILITIES como all quando a GPU estiver habilitada #19345
  • Mensagem de erro aprimorada ao tentar usar mount em sistema sem 9P #18995
  • Mensagem de erro aprimorada ao ativar complementos KVM em cluster não KVM #19195
  • Adicionado aviso ao carregar imagem com arco errado #19229
  • profile list --output json lida com pasta de configuração vazia #16900
  • Verifique a conectividade fora do minikube quando houver problema de conectividade #18859

Erros:

  • Correção de não criação de túnel de servidor API para QEMU com rede integrada #19191
  • Correção de espera pela entrada do usuário no desbloqueio do firewall quando --interactive=false #19531
  • Correção da verificação de nova tentativa de rede quando a sub-rede já está em uso para podman #17779
  • Corrigido tarball vazio ao gerar salvamento de imagem #19312
  • Correção de permissão ausente para conta kong-service #19002
