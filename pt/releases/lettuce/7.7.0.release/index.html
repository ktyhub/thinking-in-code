#alface 7.7.0.RELEASE

A equipe Lettuce tem o prazer de anunciar o lançamento menor do Lettuce 7.7.0!

✨ Destaques

Lettuce 7.7.0 apresenta suporte para os novos recursos do [lançamento Redis OSS 8.10] (https://github.com/redis/redis/releases/tag/8.10.0), como:

  • Novo comando: HIMPORT - inserção em massa de hash compacto de alto rendimento - guia do usuário
  • Novos comandos: LMOVEM, BLMOVEM - mover vários elementos entre listas
  • Novo comando: SUNIONCARD - obtém a cardinalidade da união de múltiplos conjuntos
  • Novo comando: SDIFFCARD - obtém a cardinalidade da diferença entre os conjuntos
  • XREAD, XREADGROUP - novos argumentos MAXCOUNT e MAXSIZE para limitar as entradas e o tamanho da resposta cumulativa
  • Novo comando: FT.ALIASLIST - obtém todos os aliases do índice
  • Suporte Stemmer para idiomas malaio e tagalo

Suporte de recursos para estruturas de dados probabilísticas em Redis:

  • Filtro de flor
  • [Esboço de contagem mínima] (https://redis.io/docs/latest/develop/data-types/probabilistic/count-min-sketch/)
  • Filtro Cuco
  • t-digerir
  • [Top-K] (https://redis.io/docs/latest/develop/data-types/probabilistic/top-k/)

Alface 7.7.0 suporta Redis 2.6+ até Redis 8.x. Em termos de tempo de execução Java, Lettuce requer pelo menos Java 8 e funciona com Java 24. O driver foi testado em Redis 8.10, Redis 8.8, Redis 8.6, Redis 8.4, Redis 8.2, Redis 8.0, Redis 7.4 e Redis 7.2.

Obrigado a todos os colaboradores que tornaram possível o Lettuce 7.7.0.RELEASE.

📗 Links Documentação de referência: https://lettuce.io/core/7.7.0.RELEASE
