#alface 7.2.3.RELEASE

A equipe Lettuce tem o prazer de anunciar o lançamento do patch Lettuce 7.2.3!

Alface 7.2.3 suporta Redis 2.6+ até Redis 8.x. Em termos de tempo de execução Java, Lettuce requer pelo menos Java 8 e funciona com Java 24. O driver foi testado em Redis 8.4, Redis 8.2, Redis 8.0, Redis 7.4 e Redis 7.2.

Obrigado a todos os colaboradores que tornaram possível o Lettuce 7.2.3.RELEASE.
