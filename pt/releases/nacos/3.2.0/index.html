#nacos 3.2.0 Nacos 3.2.0 é um lançamento importante focado no aprimoramento da arquitetura de plugins, expansão do AI Registry, modernização do API e melhorias na qualidade do código. Os principais destaques incluem:

  • AI Registry completa a "AI Triad": Skill Registry e Prompt Registry unem-se ao MCP/Agent Registry existente, com integração do Nacos Copilot para gerenciamento assistido por IA
  • Modernização da arquitetura de plug-ins: gerenciamento abrangente de plug-ins baseado em SPI com interface de console, sincronização em todo o cluster e melhorias no PostgreSQL
  • Limpeza API: suporte UDP PUSH legado removido, /v1 e /v2 HTTP APIs extraídos para submódulos para remoção futura
  • Segurança e qualidade de código: plug-in de autenticação OIDC/OAuth2, diversas correções de FindBugs, remoção de código morto e melhorias de compatibilidade com JDK 17+
  • Modernização do console: suporte de UI dupla para troca de console novo/legado com experiência de usuário aprimorada

⚠️ Mudanças recentes e notas de migração

Alterações no esquema do banco de dados (importante)

Ação necessária: Esta versão introduz alterações significativas no esquema do banco de dados com diversas novas tabelas adicionadas para gerenciamento de plug-ins, registro de IA (habilidade/prompt) e recursos de auditoria aprimorados. Antes de atualizar, você deve aplicar o novo esquema:

  1. Faça backup do seu banco de dados existente
  2. Aplique o script de atualização de esquema: conf/schema.sql (para MySQL) ou script correspondente para seu tipo de banco de dados
  3. Reinicie o servidor Nacos após a migração do esquema A não aplicação das alterações de esquema pode fazer com que o gerenciamento de plug-ins, o AI Registry e outros novos recursos não funcionem corretamente.

Plug-in do adaptador legado API

O plugin api-legacy-adapter e os legados /v1 e /v2 HTTP APIs foram removidos desta versão para reduzir o espaço ocupado. Se sua implantação ainda depende dos legados /v1 ou /v2 APIs, você pode introduzir manualmente o plugin de compatibilidade em: https://github.com/nacos-group/nacos-api-legacy-adapter Baixe e coloque o plugin em seu diretório plugins para restaurar a compatibilidade do legado API.

Módulo de nomenclatura: suporte UDP PUSH removido

O módulo de nomenclatura removeu o suporte legado UDP PUSH, passando para uma arquitetura HTTP API mais limpa. Clients que dependem de atualizações de descoberta de serviço baseadas em UDP devem migrar para mecanismos baseados em HTTP.

📚 O que há de novo no registro de IA

Registro de Habilidades

  • Gerenciamento Centralizado: Crie, atualize e versione habilidades via UI ou API com changelogs
  • Composição de habilidades: encadeie várias ferramentas MCP em recursos significativos para os negócios (por exemplo, "user_onboarding" = verify_email + create_profile + send_welcome_email)
  • Integração MCP: as habilidades declaram explicitamente dependências de ferramentas MCP registradas com validação de integridade
  • Organização baseada em pastas: habilidades exibidas em uma estrutura de pastas de vários níveis para melhor organização
  • APIs amigáveis ao agente: REST/gRPC APIs para estruturas de agente (LangChain, CrewAI, etc.) para descobrir e assinar habilidades
  • Suporte para upload: upload de pacotes de habilidades (formato zip, máximo de 10 MB) com autenticação
  • Verificação de segurança: scanner de habilidades integrado para validação de segurança de habilidades de IA
  • Acesso em nível de dados: visibilidade refinada e controle de acesso (Fases 2 e 3)

Registro de prompt

  • Configuração de primeira classe: armazene prompts com metadados (agentId, modelId, versão, tags) como artefatos de configuração versionados
  • Gerenciamento de várias versões: suporte ao gerenciamento paralelo de várias versões com modelo e rastreamento de mensagens de commit
  • Assinatura baseada em tags: inscreva-se em prompts por tags para atualizações dinâmicas
  • Depuração interativa: teste e compare resultados de prompt entre versões diretamente no console
  • AI Client Proxy: Interface HTTP/gRPC client unificada para operações imediatas

Nacos Copiloto

  • Assistente com tecnologia de IA: assistente de IA integrado para ajudar a otimizar e criar prompts e habilidades
  • Descoberta inteligente: encontre automaticamente habilidades relevantes existentes no registro
  • Integração com console: acessível diretamente do console Nacos para um fluxo de trabalho contínuo
