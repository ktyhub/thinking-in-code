#nacos 3.0.0 3.0.0 (25 de abril de 2025) Esta versão é uma versão GA do 3.0.0. Nesta versão, o Nacos é baseado no Nacos 3.0.0-BETA para suportar o gerenciamento MCP (Model Content Protocol). Nesta versão 3.0.0 GA, Nacos fará estes recursos e alterações importantes:

  1. APIs são categorizados em diferentes tipos, e diferentes tipos de APIs adotarão diferentes estratégias de autenticação padrão.
  2. Autenticação do console nacos habilitada e precisa de mais definições de configuração ao implantar pela primeira vez.
  3. A interface do console Nacos usa o novo console v3 API, substitui o antigo v1 API e desativa o antigo v1 API da interface do console antigo usado.
  4. O namespace padrão public altera seu id de ``(empty string) to public.
  5. Suporta protocolo xDS diretamente. atualmente, suporta EDS, LDS, RDS e CDS.
  6. Atualize spring boot para 3.4.1 e atualize a versão jdk para 17.
  7. Adicione uma série de ADMIN API para Nacos 3.0 para fazer com que o mantenedor e o console personalizado possam manter e obter os dados do Nacos.
  8. Suporte à implantação independente do console Nacos, algumas configurações do servidor Nacos e do console Nacos foram alteradas, verifique applciation.properties antes de fazer a atualização.
  9. Suporte ao gerenciamento de MCP (Model Content Protocol).
  10. Suporte ao bloqueio distribuído de recurso experimental.
  11. Suporte a serviços e configurações de escuta difusa de recursos experimentais. Alterações detalhadas em 3.0.0 consulte:
