🧬 Autoevolução

CowAgent apresenta Self-Evolution, permitindo que o agente vá além da conclusão de uma única tarefa e continue melhorando por meio da colaboração diária com você:

  • Revisão automática após inatividade: quando uma conversa fica inativa, o agente a analisa em segundo plano para corrigir problemas de uma habilidade exposta em uso, criar novas habilidades reutilizáveis, acompanhar tarefas inacabadas e registrar informações importantes na memória e na base de conhecimento
  • Silencioso por padrão, notificar sob demanda: relata o que foi alterado apenas quando realmente fez uma alteração e permanece em silêncio caso contrário
  • Seguro e reversível: Cada revisão tem um backup prévio e pode ser desfeita a qualquer momento. As habilidades integradas são protegidas e todas as leituras e gravações permanecem no espaço de trabalho

Ativado por padrão para novas instalações. Os usuários existentes podem ativá-lo com um único click no console da Web em Configurações → Configuração do agente.

💬 Atualizações do console da Web

A experiência de bate-papo do Web Console recebe vários aprimoramentos:

  • Gerenciamento de mensagens: edite, exclua e gere novamente mensagens de usuários e bots; os blocos de código agora incluem rótulos de idioma e um botão de cópia click
  • Sessões paralelas: execute várias sessões ao mesmo tempo sem interferência, com a transmissão ao vivo retomada automaticamente quando você voltar para uma sessão
  • Refinamentos: Arraste e solte arquivos em qualquer lugar da visualização do chat; mudar automaticamente para uma sessão irmã após excluir a sessão ativa

Obrigado @core-power (#2865)

🧩 Aprimoramentos de MCP multiplataforma

  • Correção de compatibilidade do Windows: Corrigida falha na comunicação stdio no Windows e tornou o tempo limite do servidor configurável via mcp.json
  • Chamadas simultâneas: os transportes sse e streamable-http agora suportam chamadas simultâneas entre sessões para respostas multiferramentas mais rápidas

Obrigado @xliu123321 (#2859)

Documentação: Ferramentas MCP

🤖 Novos modelos e melhorias

  • MiniMax-M3: Adicionado e definido como modelo padrão, com a série M2.7 mantida como opção. Obrigado @octo-patch (#2855)
  • Qwen3.7-plus: Adicionado suporte para conversas multimodais
  • Modelo ASR selecionável: o Web Console agora pode selecionar e persistir o modelo ASR (reconhecimento de fala). Obrigado @nightwhite (#2857)
  • Menu de instalação simplificado: O script de instalação de uma linha simplifica o menu do modelo e adiciona a opção Xiaomi MiMo

Documentação: Visão geral dos modelos

🛠 Melhorias e correções

  • Suporte para Python 3.13: instalação corrigida e compatibilidade de dependência em Python 3.13
  • Internacionalização: A lista de canais agora está ordenada pelo idioma da interface; refinou o substituto automático de idioma no modo auto
  • Cancelamento mais confiável: Corrigidos casos em que uma resposta de streaming não podia ser interrompida
  • CLI: cow status agora mostra o caminho atual do projeto
  • Segurança de implantação reforçada: O bloco de arquivo de credenciais é reduzido para ~/.cow/.env para que outros diretórios não sejam mais afetados (Obrigado @orbisai0security #2863); a conta oficial do WeChat agora rejeita solicitações de webhook quando wechatmp_token está vazio
  • Plugin do quadro de tarefas de grupo: Adicionada a fonte do plugin do quadro de tarefas de grupo. Obrigado @Wyh-max-star (#2853)

📦 Atualização

As implantações de código-fonte podem executar cow update para uma atualização de um click ou extrair o código mais recente e reiniciar manualmente. Consulte o Guia de atualização para obter detalhes.
