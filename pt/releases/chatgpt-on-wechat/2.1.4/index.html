#chatgpt-on-wechat 2.1.4

🌐 Inglês | 中文

🖥 Desktop Client

Seguindo o desktop client lançado na versão anterior, esta versão melhora ainda mais os recursos do navegador, a compatibilidade do sistema e a experiência geral:

  • Suporte a ferramentas de navegador: o client agrupa recursos de navegador e prefere reutilizar o Chrome/Edge instalado no sistema, com inicialização otimizada do navegador e desempenho de acesso.
  • Aperfeiçoamento da interface do usuário: recursos visuais e interações refinados para a visualização do bate-papo, balões de mensagens, etapas de chamada de ferramentas e páginas do canal.
  • Assinatura de código do Windows: os instaladores do Windows agora são assinados por código, reduzindo os avisos de segurança durante a instalação.
  • Suporte para Windows 7/8: suporte client adicionado para sistemas legados como Windows 7/8, cobrindo mais ambientes.
  • Correção de link da base de conhecimento: foram corrigidos links em documentos na base de conhecimento do desktop que não conseguiam navegar.
  • Login com senha: o desktop client suporta a configuração de uma senha de login e corrige um problema em que a janela falhava ao carregar após a definição de uma senha.

Baixar: CowAgent Desktop

Documentos: Desktop Client

🔌 Autorização MCP OAuth

Os servidores MCP remotos agora suportam autorização OAuth. Ao conectar-se a servidores MCP de terceiros que exigem login, a autenticação pode ser concluída por meio do fluxo OAuth padrão — sem necessidade de configuração e manutenção manual de tokens.

Documentos: Ferramentas MCP

⏰ Tarefas agendadas

  • Modo silencioso: crie tarefas agendadas de execução silenciosa que são executadas em segundo plano sem enviar mensagens — ideal para cenários tranquilos, como organização de dados ou arquivamento periódico. (#2954)
  • Execução manual: acione manualmente uma tarefa existente para ser executada imediatamente no console, sem aguardar o próximo agendamento. (#2958)
  • Preservar configuração na edição: foi corrigido um problema em que a edição de uma tarefa no console da Web poderia eliminar campos ocultos, como o tipo de modo. (#2959)
  • Comando de tarefa entre canais: adicionado o comando de gerenciamento /tasks, compatível entre canais. (#2965)

Obrigado @AaronZ345

Documentos: Tarefas agendadas

💬 Melhorias no canal Feishu

O canal Feishu ganha uma série de melhorias na exibição de mensagens e na interação para uma melhor experiência.

  • Aperfeiçoamento de cartão de streaming: os cartões de streaming adicionam painéis dobráveis ​​que mostram o processo de pensamento, chamadas de ferramentas e tempo de execução. (#2963)
  • Formatação Markdown: para respostas sem streaming e pushes programados, as mensagens contendo Markdown são renderizadas como cartões para uma exibição mais clara. (#2962)
  • Cartões agendadores: o comando /tasks é apresentado como cartões, com a capacidade de ativar ou desativar tarefas diretamente no cartão. (#2961)
  • Contexto de mensagem citada: quando um usuário cita uma mensagem, o conteúdo citado é automaticamente adicionado ao contexto enviado ao Agente. (#2966)
  • Renderização remota de imagens: links de imagens remotas agora podem ser renderizados dentro de cartões Feishu. (#2967)
  • Cancelar na recuperação de mensagem: recuperar uma mensagem Feishu cancela automaticamente sua tarefa correspondente em execução ou na fila. (#2978)

Obrigado @AaronZ345

Documentos: Feishu

💾 Backup e restauração de dados

Adicionados os comandos cow backup e cow restore para exportar e restaurar dados locais — configuração, base de conhecimento, memória e muito mais — com um comando, facilitando a migração e o backup. Obrigado @AaronZ345 (#2957)

Documentos: Backup de dados

🤖 Novos Modelos

  • Adicionado suporte para kimi-k3
  • Adicionado suporte para gpt-5.6-luna, gpt-5.6-terra e gpt-5.6-sol

Documentos: Modelos

🛠 Melhorias e correções

  • Direção de tarefa ativa: adicionado o comando /steer para injetar novas instruções durante a execução da tarefa, orientando ou redirecionando a tarefa em execução em tempo real. Obrigado @AaronZ345 (#2977)
  • Edição de arquivos: foi corrigido um problema em que a correspondência difusa poderia localizar a posição errada ao editar arquivos. Obrigado @weijun-xia (#2945)

📦 Como atualizar

  • Implantação de origem: execute cow update para uma atualização de um click ou extraia o código mais recente e reinicie. Consulte o guia de atualização.
  • Desktop client: verifique se há atualizações e atualize com um click dentro do client ou obtenha a versão mais recente na página de download.
