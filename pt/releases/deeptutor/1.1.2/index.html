#Deep Tutor v1.1.2 #DeepTutor v1.1.2 Release Notes Data de lançamento: 2026.04.18

Destaques

Guia Canais orientados por esquema com revelação de token (#338)

A guia Canais na página Agentes não está mais codificada para o Telegram. Ele agora descobre automaticamente cada canal (Telegram, Slack, Discord, Matrix, Email, Feishu, …) e renderiza um formulário diretamente do esquema de configuração Pydantic de cada canal – sem necessidade de código front-end por canal. Campos secretos (tokens, senhas, chaves API) são renderizados como entradas mascaradas com alternância ocular para revelação explícita. Um banner last_reload_error avisa quando os ouvintes ao vivo falham ao reiniciar após uma alteração na configuração.

Mascaramento secreto do canal

As respostas API não expõem mais segredos brutos do canal. Tokens e senhas são substituídos por *** por padrão; o formulário de edição administrativa usa ?include_secrets=true para buscar texto simples quando necessário. As respostas de criação e atualização também são mascaradas.

Validação de configuração de canal e proteção de recarga

PATCH /tutorbot/{bot_id} agora valida antecipadamente as cargas úteis do canal e retorna um 422 com erros estruturados em vez de persistir silenciosamente uma configuração incorreta. reload_channels é serializado com um bloqueio por instância para evitar ouvintes duplicados, e qualquer falha é registrada em last_reload_error para que a UI possa exibi-la.

RAG simplificado para um único pipeline

Foram removidas cerca de 2.600 linhas de andaimes RAG não utilizados (chunkers, incorporadores, indexadores, analisadores, recuperadores, orquestrador de pipeline, definições de tipo) que existiam como espaços reservados para back-ends nunca enviados. O serviço RAG agora é um wrapper fino sobre o pipeline LlamaIndex único. Os valores rag_provider legados (por exemplo, lightrag) são coagidos silenciosamente para llamaindex e a KB é sinalizada para reindexação.

Roteamento centralizado de tipo de arquivo

Classificação consolidada do tipo de arquivo em um único módulo FileTypeRouter com um API plano (get_document_type, classify_files, get_supported_extensions, etc.). Os antigos auxiliares de extensão por provedor desapareceram – há apenas um provedor. Extensões desconhecidas ainda passam pela detecção de conteúdo antes de serem rejeitadas.

Chega de bases de conhecimento fantasmas

Fechado todos os caminhos de código que poderiam chamar RAG silenciosamente em uma KB inexistente:

  • deep_solve — remove a ferramenta rag quando nenhum KB está anexado e avisa o usuário.
  • deep_research — descarta kb das fontes, avisa e aborta se nenhuma fonte permanecer.
  • SolveToolRuntime — retorna uma observação elegante "nenhum KB selecionado" em vez de travar, mantendo o loop ReAct ativo.
  • ResearchPipeline — retorna um evento estruturado "ignorado" em vez de retornar ao antigo espaço reservado DE-all.
  • DecomposeAgent — não é mais o padrão ai_textbook; desativa o RAG quando nenhum KB é fornecido.

Solicitações de bate-papo externalizadas

Todas as strings zh/en codificadas de AgenticChatPipeline foram movidas para arquivos YAML editáveis (agentic_chat.yaml para cada idioma). Rótulos de palco, prompts do sistema, modelos de usuário e avisos de UI agora podem ser configurados sem alterações de código. Retorna normalmente se o YAML estiver faltando.

LEIA-ME tailandês (#337)

Adicionado README_TH.md com documentação em idioma tailandês.

Correções de bugs

  • O pipeline de pesquisa travou sem um KB — o KB substituto do DE-all não existe mais na maioria das instalações; agora entra em curto-circuito com um evento de salto estruturado.
  • Agente de decomposição tentou RAG contra ai_textbook — substituiu o padrão codificado por None e uma guarda defensiva.
  • A configuração incorreta do canal persistiu silenciosamente — agora rejeitada no limite API com um 422 antes de chegar ao disco.
  • reload_channels simultâneo criou ouvintes duplicados — serializados por meio de um bloqueio assíncrono; a falha deixa o bot sem canal com um erro claro em vez de parcialmente reconstruído.
  • Tokens de canal vazaram nas respostas API — agora mascarados por padrão em todos os endpoints.

Conjunto de testes

Adicionados 6 novos módulos de teste (1.042 linhas no total): roteamento de tipo de arquivo, migração de configuração de KB, introspecção de esquema de canal, mascaramento de segredo de canal, consistência RAG/KB na camada de capacidade e segurança RAG de pipeline de pesquisa. Testes existentes estendidos para o tempo de execução da ferramenta, roteador de conhecimento, roteador TutorBot e módulos de pipeline RAG.
