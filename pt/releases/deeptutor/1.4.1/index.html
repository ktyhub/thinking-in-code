#Deep Tutor v1.4.1 #DeepTutor v1.4.1 Release Notes Data de lançamento: 2026.05.27 v1.4.1 é um patch de segurança e estabilidade em v1.4.0. Ele trava a sandbox da ferramenta TutorBot, isola recursos por usuário, corrige um bate-papo v1.4.0 regressão, adiciona um HTTP API para conversar com um TutorBot específico e envia um correção de fallback de imagem multimodal para provedores para os quais o DeepTutor não tem entrada de visão.

Novidades

TutorBot Tool Sandbox está ativado

A ferramenta shell exec não está mais registrada, a menos que um administrador defina allow_shell_exec, e todo o acesso ao sistema de arquivos + shell está confinado ao bot espaço de trabalho por padrão. As listas de negação de comando foram reancoradas no comando limites, e allow_shell_exec não pode ser ativado por meio da carga útil de atualização.

Isolamento de recursos por usuário

Raízes de livros, bancos de dados de sessão, armazenamentos de tempo de execução e diretórios TutorBot têm escopo definido por usuário e as conversas web/API são codificadas por sessão - portanto solicitações entre usuários não podem alcançar os dados uns dos outros.

HTTP/SSE API para um TutorBot

Novos endpoints POST /{bot_id}/chat e /chat/execute-stream (SSE) com contexto de início automático e persistente por sessão, para conversas em vários turnos com um bot específico de clients externos.

Fallback de imagem multimodal

As imagens são enviadas de forma otimista para todos os provedores; se uma solicitação contendo imagens falha e o modelo não está na lista de permissões de visão conhecida, o turno tenta novamente somente texto. Corrige imagens descartadas silenciosamente no Doubao / VolcEngine e outros modelos multimodais que carecem de entrada de capacidade.

Upload ZIP seguro + configurações de rede

Os uploads de conhecimento .zip expandem membro por membro por meio do validador de documentos com limites de tamanho/contagem/taxa de compressão e guardas de escape de caminho; o o arquivo em si nunca é indexado. Uma nova página /settings/network apresenta portas, base pública API e origens CORS (normalizadas para tolerar host:port e barras finais), além de uma ação "buscar modelos" listando IDs de modelo de um Endpoint compatível com OpenAI.

Correções e mudanças na comunidade

Segurança — TutorBot RCE fechado por meio da ferramenta shell (#518), passagem de caminho em a ferramenta de sistema de arquivos (# 517), bypass de autenticação de gerenciamento de arquivos cross-bot (# 516), desvio de autorização de regeneração de turno entre sessões (#515), autorização de confirmação de livro bypass (#514) e ExecTool executando comandos shell LLM por chat (#506, endurecido pela primeira vez em PR #507). Correções de bugs — entrada de bate-papo desativada após o primeiro turno (regressão v1.4.0, #520), falha na incorporação da base de conhecimento em documentos longos (#521 / PR #509), novos usuários não conseguem criar um perfil em Docker (#512 / PR #513), Qwen modelos de raciocínio que falham na chamada de ferramenta nativa (#527/PR #528) e o GPT-5 parâmetro de token do assistente de inicialização (PR #508). PRs mesclados/reformulados — ferramenta nativa que solicita modelos de raciocínio (nº 528), truncamento de evento de sessão superdimensionado (#524), botão de perfil em estado vazio (#513), correção de chunking-pipeline (nº 509), teste GPT-5 (nº 508), fortalecimento do ExecTool (nº 507). Contribuições #522 (upload zip) e #523 (busca de modelo + pesquisa de notebook) foram reimplementados localmente e enviados para cá. Solicitação de recurso — HTTP API para bate-papo multiturno com um TutorBot específico (#511).

Notas de atualização

  • Entrada de v1.4.0: pip install -U deeptutor; Os usuários do Docker puxam ghcr.io/hkuds/deeptutor:latest.
  • TutorBot shell exec agora está desabilitado por padrão. Se você confiou nele, defina allow_shell_exec no bot; o acesso à ferramenta permanece confinado ao espaço de trabalho.
  • Para autenticação HTTPS entre sites, defina origens CORS explícitas e cookie_secure=true.
