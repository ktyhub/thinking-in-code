adk-python v2.12.0

2.12.0 (13/10/2026)

Destaques

Esta versão melhora o desempenho de execução em sessões longas, ao mesmo tempo que introduz um controle mais preciso sobre a execução de ferramentas, aprovações de fluxo de trabalho e segurança de implantação.

  • Desempenho: reduza o tempo para a solicitação do primeiro modelo em 40% em sessões longas. (1754b3e)
  • Ferramentas: intercepte e filtre as saídas da ferramenta antes de retorná-las ao modelo usando after_tool_callback. (fdda17c)
  • Fluxos de trabalho: exigem confirmação humana antes de executar nós de fluxo de trabalho via require_confirmation. (988fd1a)
  • Implantação: implante agentes no Agent Engine usando contas de serviço personalizadas dedicadas. (629e119)
  • Python 3.15: Instale e execute o ADK em Python 3.15. (75aef1e)
