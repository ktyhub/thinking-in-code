adk-python v2.11.0

2.11.0 (01/10/2026)

Destaques

Esta versão adiciona cancelamento elegante e confirmação de ferramenta aos fluxos de trabalho, uma ferramenta para consultar outro modelo no meio da tarefa e um serviço de memória SQLite integrado.

  • Cancelamento de execução: Passe um abort_signal para Runner, Workflow e nós para interromper uma execução normalmente; /run_sse agora cancela a execução quando o client é desconectado. Consulte o guia da unidade para obter mais detalhes. (ef5bbcf, 3d73603)
  • Confirmação de ferramenta em fluxos de trabalho: os nós de ferramenta agora pausam para aprovação do usuário via RequestInput, da mesma forma que um LlmAgent faz, em vez de transmitir um erro downstream. (ce132b9)
  • ModelConsultTool: permite que um agente consulte outro modelo no meio da tarefa, limitado por orçamentos por turno e por sessão. Consulte o guia da unidade para obter mais detalhes. (84cc99a)
  • Serviço de memória SQLite: mantém a memória do agente em um banco de dados SQLite local, selecionado com um URI de serviço de memória sqlite://. (9625b06)
  • MCP SDK 2.x: Conecte-se a servidores MCP por meio do protocolo moderno por meio de um novo caminho opcional. (e738c26)
