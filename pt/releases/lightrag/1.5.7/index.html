LightRAG v1.5.7

Notas importantes

Novo recurso: Adicionar ponto de entrada voltado para o usuário final à WebUI

v1.5.7 adiciona uma segunda entrada voltada para o usuário final — /workspace — junto com a marca e os controles de prompt que uma implantação precisa antes de poder ser entregue a usuários reais.

  • Uma entrada somente de consulta para usuários finais: /workspace
  • Páginas personalizáveis de boas-vindas, login e estado vazio
  • Um USER_PROMPT_PREFIX global

A UI do /workspace mostra a superfície de bate-papo e nada mais - sem gerenciamento de documentos, sem gráfico de conhecimento, sem links de documentos API - e foi desenvolvida para uso móvel. Aponte UI_TEMPLATES_DIR para um pequeno diretório de arquivos Markdown mais um manifest.json, e o LightRAG exibe sua página de boas-vindas, sinopse da página de login, estado vazio da consulta, logotipo da marca e linha de direitos autorais - em vários idiomas, sem reconstruir a WebUI. Uma localidade que declara uma sinopse de login e um documento de contrato também ativa uma caixa de seleção de consentimento de login. Um pacote pronto para copiar é enviado em docs/ui_templates_example/.

USER_PROMPT_PREFIX (ou USER_PROMPT_PREFIX_FILE para texto longo com vários parágrafos) acrescenta instruções para toda a implantação a cada user_prompt da solicitação. Ele dá ao operador um local para definir a função, o tom e o formato de saída do LLM - diagramas Mermaid, delimitadores LaTeX, estilo de citação - para entradas da UI e também para o API. As solicitações nunca podem lê-lo ou substituí-lo; apenas o campo API disable_user_prompt_prefix é desativado.

Para mais informações, consulte:

  • docs/LightRAG-API-Server.md — § A entrada de consulta /workspace
  • docs/UserDefinedUI.md — o guia completo de personalização da UI, além de docs/ui_templates_example/
  • README.md — USER_PROMPT_PREFIX / USER_PROMPT_PREFIX_FILE
