LightRAG v1.4.7

Notas importantes

  • O recurso de filtragem de blocos baseado em ID de documento foi removido do armazenamento vetorial PostgreSQL.
  • O modelo de prompt foi atualizado, invalidando todos os caches LLM
  • O valor padrão da variável de ambiente FORCE_LLM_SUMMARY_ON_MERGE foi alterado de 4 para 8. Este ajuste reduz significativamente o número de chamadas LLM durante a fase de indexação da documentação, encurtando assim o tempo geral de processamento de documentos.
  • Adicionado suporte para vários provedores de reclassificação (Cohere AI, Jina AI, Aliyun Dashscope). Se a reclassificação foi habilitada anteriormente, e o novo env var deve ser definido para habilitar a reclassificação novamente:
RERANK_BINDING=cohere
  • Introduzida uma nova variável de ambiente, LLM_TIMEOUT, para controlar especificamente o tempo limite do Large Language Model (LLM). A variável TIMEOUT existente agora gerencia exclusivamente o tempo limite do trabalhador Gunicorn. O tempo limite padrão do LLM é definido como 180 segundos. Se você anteriormente dependia da variável TIMEOUT para configuração de tempo limite do LLM, atualize suas configurações para usar LLM_TIMEOUT:
LLM_TIMEOUT=180
  • Adicione configurações abrangentes de variáveis de ambiente para ligações OpenAI e Ollama Large Language Model (LLM). A variável de ambiente genérica TEMPERATURE para controle de temperatura LLM foi descontinuada. Em vez disso, a temperatura do LLM agora é configurada usando variáveis de ambiente específicas da ligação:
# Temperature setting for OpenAI binding
OPENAI_LLM_TEMPERATURE=0.8

# Temperature setting for Ollama binding
OLLAMA_LLM_TEMPERATURE=1.0

Para mitigar loops de saída intermináveis e evitar decodificação gananciosa para Qwen3, defina o parâmetro de temperatura para um valor entre 0.8 e 1.0. Para desativar o modo "Pensando" do modelo, consulte a seguinte configuração:

### Qwen3 Specific Parameters depoly by vLLM
# OPENAI_LLM_EXTRA_BODY='{"chat_template_kwargs": {"enable_thinking": false}}'

### OpenRouter Specific Parameters
# OPENAI_LLM_EXTRA_BODY='{"reasoning": {"enabled": false}}'

Para obter uma lista completa de opções de suporte, use o seguinte comando:

lightrag-server --llm-binding openai --help
lightrag-server --llm-binding ollama --help
lightrag-server --embedding-binding ollama --help
  • Uma lista completa de novas variáveis de ambiente adicionadas ou novos valores padrão:
# Timeout for LLM requests (seconds)
LLM_TIMEOUT=180

# Timeout for embedding requests (seconds)
EMBEDDING_TIMEOUT=30

### Number of summary segments or tokens to trigger LLM summary on entity/relation merge (at least 3 is recommended)
FORCE_LLM_SUMMARY_ON_MERGE=8

### Max description token size to trigger LLM summary
SUMMARY_MAX_TOKENS = 1200

### Recommended LLM summary output length in tokens
SUMMARY_LENGTH_RECOMMENDED=600

### Maximum context size sent to LLM for description summary
SUMMARY_CONTEXT_SIZE=12000

### RERANK_BINDING type:  null, cohere, jina, aliyun
RERANK_BINDING=null

### Enable rerank by default in query params when RERANK_BINDING is not null
# RERANK_BY_DEFAULT=True

### chunk selection strategies
###     VECTOR: Pick KG chunks by vector similarity, delivered chunks to the LLM aligning more closely with naive retrieval
###     WEIGHT: Pick KG chunks by entity and chunk weight, delivered more solely KG related chunks to the LLM
###     If reranking is enabled, the impact of chunk selection strategies will be diminished.
KG_CHUNK_PICK_METHOD=VECTOR

### Entity types that the LLM will attempt to recognize
ENTITY_TYPES=["person", "organization", "location", "event", "concept"]
