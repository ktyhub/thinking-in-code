LightRAG v1.4.0

Notas de importância

  • Após a atualização, limpe os documentos e o cache e reindexe-os para que o recurso de exclusão de documentos funcione corretamente. Lembre-se de selecionar a opção “limpar cache simultaneamente” ao limpar documentos. Se a funcionalidade de exclusão de documentos não for necessária imediatamente, não há necessidade de reindexar os documentos. *Esta atualização inclui alterações nos parâmetros QueryParam. Se você integrou LightRAG anteriormente usando QueryParam, atualize sua passagem de parâmetro de acordo com o API mais recente. Consulte os parâmetros do endpoint /query na página API da UI da web.
  • A integração do Reranker nesta versão melhora significativamente o desempenho de consultas mistas. Recomendamos usar o modo de consulta mista como padrão quando o Reclassificador estiver ativado.
