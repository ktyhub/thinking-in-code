rocketmq rocketmq-all-5.3.4

Esta é uma versão de correção de bugs que inclui inúmeras melhorias para melhorar a estabilidade, o desempenho e a correção. Os principais destaques incluem atualizações de dependências críticas (por exemplo, Netty, OpenTelemetry), melhorias significativas de estabilidade, como o mecanismo de snapshot TimerWheel para recuperação confiável, e uma ampla gama de correções de bugs em módulos como Broker, Proxy e Client.
