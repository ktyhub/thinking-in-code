daily_stock_análise v3.5.0

Adicionado

  • 📊 Gaveta de relatório completo da UI da Web (Correções #214) — a página de histórico adiciona o botão "Relatório Completo" para exibir o relatório completo de análise de Markdown em uma gaveta lateral; novo terminal GET /api/v1/history/{record_id}/markdown
  • 📊 Acompanhamento de custos de LLM — todas as ligações de LLM (análise, agente, revisão de mercado) registradas na tabela llm_usage; novo endpoint GET /api/v1/usage/summary?period=today|month|all retorna uso de token agregado por tipo e modelo de chamada
  • 🔍 Provedor de pesquisa SearXNG (Correções #550) — substituto de pesquisa auto-hospedada sem cota; prioridade: Bocha > Tavily > Brave > SerpAPI > MiniMax > SearXNG
  • 🔍 Provedor de pesquisa na web MiniMax — MiniMaxSearchProvider com disjuntor (3 falhas → resfriamento de 300s) e filtragem de tempo duplo; configurado via MINIMAX_API_KEYS
  • 🤖 Descoberta de modelos de agente API — GET /api/v1/agent/models retorna implantações de modelo disponíveis (primário/fallback/fonte/api_base) para o seletor de modelo de UI da Web
  • 🤖 Exportação e envio de bate-papo do agente (#495) — exporta a conversa para um arquivo .md; enviar para canais de notificação configurados; novo POST /api/v1/agent/chat/send
  • 🤖 Execução em segundo plano do agente (#495) — a análise continua ao mudar de página; notificação de crachá na conclusão; cancelar automaticamente o fluxo em andamento na troca de sessão
  • 📝 Report Engine P0 — Validação de esquema Pydantic para LLM JSON; Modelos Jinja2 (markdown/wechat/brief) com fallback legado; verificações de integridade de conteúdo com nova tentativa; modo breve (REPORT_TYPE=brief); comparação de sinal histórico
  • 📦 Importação inteligente — importação multifonte de imagem/CSV/Excel/clipboard; Vision LLM extrai código+nome+confiança; resolvedor de nome→código (mapa local + pinyin + AkShare); confirmação em níveis de confiança
  • ⚙️ Configuração GitHub Actions LiteLLM — o fluxo de trabalho suporta LITELLM_CONFIG/LITELLM_CONFIG_YAML para configuração flexível do provedor de IA
  • ⚙️ Refator do mecanismo de configuração e sistema API (#602) — registro de configuração unificado, validação e exposição API
  • 📖 Guia de configuração LLM — novo docs/LLM_CONFIG_GUIDE.md cobrindo configuração de 3 camadas, início rápido, Visão/Agente/solução de problemas

Corrigido

  • 🐛 analyze_trend sempre reporta Sem dados históricos (#600) — agora busca no DB/DataFetcher em vez do get_analysis_context quebrado
  • 🐛 Fullback da estrutura do chip quando o LLM o omite (#589) — preenchimento automático dos dados do chip da fonte de dados para exibição consistente entre modelos
  • 🐛 Os pontos de atirador do histórico mostram texto bruto (#452) — prioriza strings originais em vez de valores numéricos compactados
  • 🐛 GitHub Actions ENABLE_CHIP_DISTRIBUTION configuráveis (#617) — não é mais codificado, suporta substituição de vars/segredos
  • 🐛 O salvamento do .env preserva comentários e linhas em branco — As configurações da Web não destroem mais a formatação do .env
  • 🐛 Correções de descoberta de modelo de agente — o modo legado inclui provedores nativos do LiteLLM; detecção de origem alinhada com o tempo de execução; implantações substitutas não são mais expandidas por chave
  • 🐛 Semântica de fechamento anterior das ações da Stooq US — não faz mais uso indevido do preço de abertura como fechamento anterior
  • 🐛 Regressão de pré-busca de nome de estoque — prioriza STOCK_NAME_MAP local antes de consultas remotas
  • 🐛 Cálculo de limite para cima/para baixo do AkShare (#555) — estatísticas fixas de análise de mercado
  • 🐛 Índice de campo de origem AkShare Tencent e mapeamento de cotação de ETF (#579)
  • 🐛 Paginação de cache de nome de estoque Pytdx (#573) — evita estouro de cache
  • 🐛 Grupamento de relatório superdimensionado PushPlus (#489) — segmenta automaticamente conteúdo longo
  • 🐛 Cancelamento e troca de bate-papo do agente (#495) — o cancelamento não é mais relatado erroneamente como falha; a troca rápida não substitui mais o estado do fluxo
  • 🐛 Status de pesquisa MiniMax no comando /status (#587)
  • 🐛 config_registry duplicado BOCHA_API_KEYS — removeu a entrada duplicada do dict que substituiu silenciosamente a configuração

Alterado

  • 🔎 Observabilidade de falhas do buscador — registra início/sucesso/falha com tempo decorrido, transições de failover; Efinance/Akshare inclui endpoint upstream e categorias de falhas classificadas
  • ♻️ Resiliência e limpeza da fonte de dados (#602) — otimização da cadeia de fallback
  • ♻️ Extensão de resposta API do extrato de imagem — novo campo items (código/nome/confiança); codes preservado para compatibilidade com versões anteriores
  • ♻️ Importar mensagens de erro de análise — motivos de falha específicos para Excel/CSV; registro aprimorado com tipo e tamanho de arquivo

Documentos

  • 📖 Guia de configuração LLM refatorado para maior clareza (#583)
  • 📖 image-extract-prompt.md com documentação completa e imediata
  • 📖 Documentação TTL do cache substituto do AkShare
