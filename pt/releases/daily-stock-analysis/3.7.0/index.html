daily_stock_análise v3.7.0

Novos recursos

  • 💼 Gerenciamento de posição P0 totalmente funcional online (#677, correspondente à edição #627)
    • Lista principal e loop fechado de snapshots: Adicione novas contas, transações, fluxo de caixa, comportamento corporativo, cache de posição, snapshots diários e outros modelos de dados principais e endpoints API; suporta reprodução de método de custo duplo FIFO / AVG; a ordem dos eventos no mesmo dia é fixada em 现金 → 企业行为 → 交易; a gravação de instantâneo de posição usa transações atômicas.
    • Importação de Broker CSV: Suporta o primeiro lote de adaptações de Huatai/CITIC/China Merchants, incluindo compatibilidade de alias de listagem; interface de dois estágios (visualização da análise + envio de confirmação); Prioridade trade_uid, desduplicação idempotente de hash de campo-chave; os códigos de estoque zero iniciais são completamente mantidos.
    • Relatório de risco de portfólio: risco de concentração (posições superiores + calibre do setor de ações A), monitoramento de retração histórica (suporta preenchimento de instantâneos ausentes), aviso de abordagem de stop loss; conversão unificada de múltiplas moedas para o calibre CNY; quando a extração falhar, use a taxa de câmbio bem-sucedida mais recente e marque como obsoleto.
    • Página de posição na Web (/portfolio): visão geral do portfólio, detalhes da posição, gráfico de concentração, resumo de risco, troca completa de portfólio/conta única; lançamento manual de transações/fluxo de capital/comportamento corporativo; entrada de criação de conta incorporada; Análise CSV + submissão em circuito fechado e seletor de corretagem.
    • Ferramenta de posição do agente: Adicionada ferramenta de dados get_portfolio_snapshot, resumo compacto padrão, detalhes de posição opcionais e dados de risco.
    • Consulta de evento API: Adicionado GET /portfolio/trades, GET /portfolio/cash-ledger, GET /portfolio/corporate-actions, suportando filtragem de data e paginação.
    • Extensible Parser Registry: registro compartilhado em nível de aplicativo, suporta registro em tempo de execução de novos corretores; interface de descoberta GET /portfolio/imports/csv/brokers recentemente adicionada.
  • 🎨 Sistema de design front-end e biblioteca de componentes atômicos (#662)
    • Introduzindo uma arquitetura progressiva de tema duplo (token de design variável HSL), limpando o CSS legado histórico; refatoração de mais de 20 componentes principais, como botão/cartão/crachá/dobrável/entrada/seleção, etc.; adição de ferramentas de mesclagem de nomes de classe clsx + tailwind-merge; melhorando a legibilidade do histórico, configuração do LLM e outras páginas.
  • ⚡ Análise do contrato assíncrono API e otimização de inicialização (#656)
    • Padronizar o contrato de devolução da solicitação assíncrona POST /api/v1/analysis/analyze; otimizar a lógica auxiliar de inicialização do serviço; corrigir o problema de alinhamento entre a definição conjunta do tipo de relatório front-end e a resposta back-end.

Correção

  • 🔔 Compatibilidade com versões anteriores da variável de ambiente Discord (#659): Adicionada leitura de fallback de DISCORD_CHANNEL_ID → DISCORD_MAIN_CHANNEL_ID durante o tempo de execução; usuários de configuração histórica podem restaurar notificações do Discord Bot sem modificação; todos os documentos relacionados estão alinhados com .env.example.
  • 🔧 Atualização do Nó 24 de ações GitHub (#665): Atualize todas as ações oficiais do GitHub para versões compatíveis com o Nó 24, eliminando o aviso de descontinuação do Node.js 20 no log de CI (afeta a janela de atualização forçada de 02/06/2026).
  • 📅 Localização da data padrão na página de posição: A data padrão no formulário de entrada manual foi alterada para a hora local (getFullYear/Month/Date) para corrigir o problema de deslocamento de data para usuários no fuso horário UTC-N na noite do mesmo dia.
  • 🔁 Reforço da lógica de desduplicação de importação de CSV: o hash de desduplicação incorpora o número de série da linha como um fator distintivo para garantir que transações legais separadas no mesmo campo não sejam dobradas incorretamente; ao mesmo tempo, o hash também persiste quando trade_uid existe para evitar escrita repetida de fontes mistas.

Mudança

  • POST /api/v1/portfolio/trades retorna 409 quando trade_uid entra em conflito na mesma conta.
  • Um novo campo sector_concentration é adicionado à resposta ao risco de posição (expansão incremental), e o campo concentration original permanece inalterado.
  • Analisar documentação contratual de comportamento assíncrono da interface API analyze; atualização conjunta do tipo de relatório front-end.

Teste

  • Adicionados novos testes de serviço central de posição (venda parcial FIFO/AVG, sequência de eventos no mesmo dia, retorno trade_uid repetido 409, contrato instantâneo API).
  • Adicionada idempotência de importação de CSV, desduplicação de transação de divisão legal, limite de desduplicação, limite de risco e teste de comportamento de downgrade da taxa de câmbio.
  • Adicionado teste de chamada da ferramenta Agente get_portfolio_snapshot.
  • Adicionada análise do teste de regressão de contrato assíncrono API.
