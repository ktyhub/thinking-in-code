#dubbo-go v3.3.1

##3.3.1

Resumo

Esta versão apresenta melhorias importantes no protocolo Triple, melhorias nos centros de configuração e registro (Nacos, Apollo, Zookeeper) e refatoração extensiva de módulos principais para melhorar a estabilidade e o desempenho. Esta versão também atualiza a compatibilidade para Go 1.24.

Novos recursos

  • Suporte curingas de grupo e versão para correspondência exata de interface. #3080
  • Suporte à injeção de dubbo.tag em metadados de serviço. #3069
  • Expor APIs relacionados ao roteador. #3066
  • Atualização Suporte à versão Go para Go 1.24 e remove o uso obsoleto de rand.seed. #3046
  • Introduzir uma ferramenta de formatador de importações e integrá-la às verificações de CI. #3019
  • Adicionar capacidade de recarregamento a quente da configuração. #2992
  • Suporte para execução de servidores HTTP/2 e HTTP/3 simultaneamente. #2972
  • Adicionar opção WithInterface para inicialização do client. #2946
  • Adicionar suporte de ferramentas para gerar documentação OpenAPI para serviços Triple. #2951
  • Adicionar suporte experimental HTTP/3 para o protocolo Triple. #2916
  • Redesenhar TLS APIs e adicionar nova configuração TLS para protocolo triplo. #2852 #2891
  • Suporte Modo não IDL na nova implementação Triple. #2858
  • Adicionar suporte para Apollo como centro de configuração. #2857
  • Suporte decodificação Hessian do fluxo para melhorar o desempenho na transmissão de pacotes grandes. #2841
  • Adicionar suporte de chamadas genéricas para o novo protocolo Triplo. #2818

Correções de bugs

  • Corrigir falha de cancelamento de registro do Nacos durante o desligamento. #3108
  • Evite pânico ao recuperar metadados de provedores Java. #3092
  • Ajuste nível de log de Erro para Avisar quando os parâmetros da aplicação estiverem vazios no Tag Router. #3035
  • Corrigir desreferência de ponteiro nula em vários módulos. #3071
  • Resolver perda de parâmetro de URL no método SetParams. #3022
  • Tratar falhas de criação de extensões de cluster em vez de entrar em pânico. #3021 #3064
  • Corrigir caminhos de rotação de log incorretos para evitar perda de arquivos. #3014
  • Corrigir lógica de decremento do contador em caso de erro. #3013
  • Corrigir falhas de recuperação de metadados causadas por erros meta-v e parâmetros de armazenamento remoto vazios. #2952 #2953
  • Corrigir carregamento de configuração do provedor em dubbo.Load(). #2941
  • Corrigir problemas de passagem de anexos do servidor para client no protocolo Triplo. #2928 #2854
  • Corrigir A configuração de peso do Nacos não entra em vigor. #2937
  • Reduz a latência na percepção do nó Zookeeper client. #2930
  • Corrigir erros de EOF de prefixo de leitura na camada de comunicação. #2912
  • Corrigir problemas de substituição de instância do Nacos. #2882
  • Resolver problemas de loop infinito lógico. #2879
  • Corrigir problemas de assinatura do Nacos em que serviços recém-registrados não eram detectados. #2859
  • Corrigir Lógica de configuração da opção de peso Nacos. #2843
  • Corrigir propagação de erro em marshalRequest. #2817
  • Corrigir Tratamento de erros de anexo de contexto em chamadas de streaming triplo. #2810

Aprimoramentos de código

  • Refator: Desacoplamento de configuração. Dependências desacopladas do pacote config para resolver dependências circulares em módulos de registro, filtro e TLS.
  • Otimize o desempenho pré-compilando padrões regex. #3067
  • Melhorar RoundRobin ponderado adicionando o campo lastUpdate ao armazenamento de estado. #3053
  • Corrigir múltiplas importações de pacotes na geração de código triplo. #3052
  • Endereço vazamentos de memória relacionados ao gerenciamento de goroutines, identificadores de arquivos e caches de extensão. #3023
  • Refator módulo de registro e adicione testes de unidade abrangentes. #2838 #2993
  • Reescrever Makefile para melhorar a consistência da construção e a experiência do desenvolvedor. #2975
  • Use errgroup para melhorar o tratamento de erros durante o desligamento normal. #2973
  • Substituir operações CAS obsoletas por CompareAndSwap. #2962
  • Harden Tratamento de erros triplo openServer para erros de configuração. #2945
  • Adicionar controle de tempo limite para desligamento normal no protocolo triplo. #2943
  • Migrar interface{} para any em toda a base de código para compatibilidade com Go 1.18+. #2848

Observabilidade

  • Adicionar registro para o ciclo de vida de registro do serviço. #3043
  • Alinhar nomes de escopo de rastreamento com especificações OpenTelemetry. #3041
  • Adicionar opção Insecure à configuração de rastreamento. #3028
  • Atualizar dependências do OpenTelemetry para v1.21.0. #2971

Documentação e CI

  • Adicionar comando make check-fmt ao pipeline CI. #3055
  • Atualizar informações de contato README e corrigir links inválidos em README_CN. #3020
  • Integrar importadores de formatador e verificações de cabeçalho de licença no CI. #2961 #2957
  • Resolver vários falsos positivos do SonarQube/SonarCloud e avisos de bots de IA. #2902
