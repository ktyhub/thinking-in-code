Projeto

Servidor OAP

  • Corrigida camada errada da métrica user error no monitoramento do DynamoDB.
  • O armazenamento ElasticSearch não verifica os tipos de campo quando o OAP é executado no modo no-init.
  • Suporte para vincular o status TLS como parte do componente da topologia de serviço.
  • Corrigido bug de prioridade de ID de componente.
  • Correção do ID do componente de sobreposição de topologia devido a bugs na camada de armazenamento.
  • [Alteração significativa] Aprimore o armazenamento JDBC mesclando tabelas e gerenciando a rolagem de tabelas com base no dia.
  • [Alteração significativa] Implementações e testes de Sharding-MySQL são removidos porque temos o mecanismo de rolagem baseado em dia por padrão
  • Correção da regra otel k8s-cluster e adição de dimensão de namespace para cálculo de agregação MAL (status de implantação, réplicas de especificações de implantação)
  • Suporte ao recurso de perfil contínuo.
  • Suporte para coleta de métricas relacionadas ao nível do processo.
  • Fix K8sRetag lê o serviço k8s errado do cache devido a uma possível incompatibilidade de namespace.
  • [Alteração significativa] Suporte ao perfil de rastreamento entre threads. A estrutura de dados e a consulta dos APIs foram alteradas.
  • Correção da resposta PromQL HTTP API /api/v1/labels sem rótulo service.
  • Corrigido possível NPE ao inicializar IntList.
  • A expressão PromQL de análise de suporte possui rótulos vazios entre colchetes para consulta de metadados.
  • Suporte à métrica de alarme OP !=.
  • A consulta de métricas de suporte indica se o valor == 0 representa realmente zero ou nenhum dado.
  • Correção de NPE ao consultar índices de série inexistentes no armazenamento ElasticSearch.
  • Suporte à coleta de métricas de buff/cache de memória no monitoramento de VM.
  • PromQL: Remova valores vazios do resultado da consulta, corrija o parâmetro /api/v1/metadata que limit pode causar fora do limite.
  • Suporte ao monitoramento do número total de métricas de k8s StatefulSet e DaemonSet.
  • Suporte ao monitoramento do gateway Amazon API.
  • Aumente o graphql-java para corrigir cve.
  • Aumente Kubernetes Java client.
  • Suporte ao monitoramento Redis.
  • Adicione o ID do componente para amqp, amqp-producer e amqp-consumer.
  • Suporte ao modo sem proxy para receptor aws-firehose
  • Aumente a armeria para 1.23.1
  • Suporte ao monitoramento Elasticsearch.
  • Correção da resposta PromQL HTTP API /api/v1/series sem rótulo service ao corresponder à métrica.
  • Suporte ServerSide TopN para BanyanDB.
  • Adicione o ID do componente para Jersey.
  • Remova o suporte do OpenCensus, os códigos e documentos relacionados como está sendo encerrado.
  • Suporte à configuração dinâmica de searchableTracesTags
  • Suporte exportErrorStatusTraceOnly para exportar os segmentos de rastreamento de status de erro através do canal Kafka
  • Adicione ID de componente para Grizzly.
  • Corrija o potencial NPE no receptor Zipkin quando o Span estiver faltando alguns campos.
  • Filtre os dados da métrica desconhecido_cluster.
  • Suporte ao monitoramento RabbitMQ.
  • Suporte à coleta de logs lentos Redis.
  • Corrija a perda de dados ao consultar o registro de tarefa de criação de perfil contínuo.
  • Adapte a consulta de tarefa de criação de perfil contínua GraphQL.
  • Suporta Expressão de Consulta de Métricas (MQE) e permite que os usuários façam cálculos simples do estágio de consulta por meio da expressão.
  • Protocolo obsoleto de consulta de métricas v2.
  • Protocolo de consulta de registro obsoleto.
  • Adicione o ID do componente para go-redis.
  • Adicione OpenSearch 2.8.0 ao caso de teste.
  • Adicione o módulo ai-pipeline.
  • Suporta formatação HTTP URI através de ai-pipeline para fazer reconhecimento de padrões.
  • Adicione novo mecanismo de agrupamento HTTP URI com benchmark.
  • [Alteração significativa] Use o novo mecanismo de agrupamento HTTP URI para substituir o antigo mecanismo baseado em regex.
  • Suporte sumLabeled em MAL.
  • Migrar de kubernetes-client/java para fabric8 client.
  • As métricas de relação geradas pelo Envoy ALS consideram que os códigos de status http >= 400 apresentam um erro no lado client.
  • Adicionar campo de mensagem de causa ao consultar tarefa de criação de perfil contínua.

  • Reverter: função cpm5d. Este recurso foi cancelado no back-end.

    4. No mesmo nível, liste os nós de cima para baixo em ordem alfabética.

  • Adicionar menu AWS API Gateway.
  • Altere o protocolo de perfil de rastreamento.
  • Adicione o menu Redis.
  • Otimize os tipos de dados.
  • Suporte ao sinalizador isEmptyValue para consulta de métricas.
  • Adicione o menu elasticsearch.
  • [Limpe os modelos de UI antes da atualização] Defina showSymbol: true e faça com que o ponto de dados seja exibido no gráfico de linha. Limpe o índice ui_template no armazenamento elasticsearch ou a tabela no armazenamento JDBC.
  • [Limpe os modelos de UI antes da atualização] Modelos de UI: simplifique o nome da métrica com o rótulo.
  • Adicionar menu MQ.
  • Adicione o ícone Jeysey.
  • Correção: defina os seletores de endpoint e instância com parâmetros de URL corretamente.
  • Aumente as versões de dependências ícones-vue 1.1.4, element-plus 2.1.0, nanoid 3.3.6, postcss 8.4.23
  • Adicionar suporte ao protocolo de log OpenTelemetry.
  • [Alteração significativa] A chave de configuração enabledOtelRules foi renomeada para enabledOtelMetricsRules e a variável de ambiente correspondente foi renomeada para SW_OTEL_RECEIVER_ENABLED_OTEL_METRICS_RULES.
  • Adicione ícone pardo.

  • Aplique MQE nos modelos de interface do usuário da camada General e Virtual-Database.
