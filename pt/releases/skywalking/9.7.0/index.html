Aviso

Não baixe códigos-fonte desta página. Por favor, siga o documento de construção, se você quiser construir códigos-fonte sozinho.

Modo escuro

O modo de estilo dafult foi alterado para o modo escuro e o modo claro ainda está disponível.

Nova visualização de registro de design

Um novo design para a visualização do log está disponível no momento. Mais fácil de localizar os logs e mais espaço para o texto bruto.

Projeto

  • Transfira o agente Java para 9.1-dev nos testes e2e.
  • Aumente netty para 4.1.100.
  • Atualize Groovy 3 para 4.0.15.
  • Suporte ao empacotamento do projeto em JDK21. A origem e o destino do compilador permanecem no JDK11.

Servidor OAP

  • ElasticSearchClient: Adicione deleteById API.
  • Corrigir regras de alarme personalizadas substituídas por 'resource/alarm-settings.yml'
  • Suporte ao monitoramento Kafka.
  • Suporte ao monitoramento do servidor Pulsar e do servidor BookKeeper.
  • [Alteração significativa] O armazenamento Elasticsearch mescla todos os índices de dados de gerenciamento em um índice management, incluindo ui_template，ui_menu，continuous_profiling_policy.
  • Adicione um mecanismo de liberação para janelas de alarme quando expirar em caso de OOM.
  • Corrija a resposta do receptor de rastreamento Zipkin: faça o código de status HTTP de 200 a 202.
  • Atualize BanyanDB Java Client para 0.5.0.
  • Corrija a consulta getInstances no BanyanDB Metadata DAO.
  • BanyanDBStorageClient: Adicione keepAliveProperty API.
  • A tabela de correção existe, verifique no plug-in de armazenamento JDBC.
  • Melhore a extensibilidade da biblioteca do servidor HTTP.
  • Ajuste o comprimento da coluna alarmMessage AlarmRecord para 512.
  • Corrigido evento de construção EventHookCallback: construa a camada de Service's Layer.
  • Corrigido AlarmCore doAlarm: captura exceção para cada retorno de chamada para evitar interrupção.
  • Otimize queryBasicTraces em TraceQueryEsDAO.
  • Corrija o envio de mensagens incorretas do WebhookCallback, adicione uma exceção de captura para cada postagem HTTP de retorno de chamada.
  • Correção da validação da expressão AlarmRule: adicione dados simulados de métricas rotuladas para verificação.
  • Suporte para coleta de métricas de pool de memória ZGC.
  • Adicione um ID de componente para Netty-http (ID=151).
  • Adicione um ID de componente para fibra (ID=5021).
  • BanyanDBStorageClient: Adicione define(Property property, PropertyStore.Strategy strategy) API.
  • Corrija o formato do arquivo e corrija erros de digitação nos nomes dos arquivos para monitorar os testes e2e do Kafka.
  • Suporte para extração de carimbo de data e hora de string de data e hora padronizada em LAL.
  • Suporta parâmetros-chave de saída nos logs de inicialização.
  • A correção não pode consultar rastreamentos zipkin com o parâmetro annotationQuery no armazenamento relacionado ao JDBC.
  • A correção de limit não funciona para findEndpoint API no armazenamento ES.
  • Isole o cache do MAL CounterWindow pelo nome da métrica.
  • Corrija a ordem de consulta do log JDBC.
  • Altere a estratégia DataCarrier IF_POSSIBLE para usar a implementação ArrayBlockingQueue.
  • Altere a política da fila (DataCarrier) no trabalhador agregado da métrica L1 para o modo IF_POSSIBLE.
  • Adicione a métrica de auto-observabilidade metrics_aggregator_abandon para contar o número de métricas de abandono.
  • Suporte ao monitoramento Nginx.
  • Corrigir BanyanDB Metadata Query: fazer com que a consulta de instância/processo único retorne tags completas para evitar NPE.
  • Substitua go2sky E2E pelo agente GO.
  • Substitua o protocolo Metrics v2 por MQE em modelos de UI e teste E2E.
  • Corrigir regras de hotel de métricas apisix incorretas.
  • Suporte Scratch The OAP Config Dump.
  • Suporte à função increase/rate na linguagem de consulta MQE.
  • Agrupe terminais de serviço em _abandoned quando os terminais tiverem alta cardinalidade.
