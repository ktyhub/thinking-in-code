agente hermes v2026.4.23

Agente Hermes v0.11.0 (v2026.4.23)

Data de lançamento: 23 de abril de 2026 Desde v0.9.0: 1.556 commits · 761 PRs mesclados · 1.314 arquivos alterados · 224.174 inserções · 29 colaboradores da comunidade (290 incluindo coautores)

O lançamento da Interface — uma reescrita completa do React/Ink do CLI interativo, uma arquitetura de transporte conectável sob cada provedor, suporte nativo ao AWS Bedrock, cinco novos caminhos de inferência, uma 17ª plataforma de mensagens (QQBot), uma superfície de plug-in dramaticamente expandida e GPT-5.5 via Codex OAuth. Esta versão também inclui todos os destaques adiados do v0.10.0 (que enviou apenas o Nous Tool Gateway) – cobrindo aproximadamente duas semanas de trabalho em toda a pilha.

✨ Destaques

  • Nova TUI baseada em Ink — hermes --tui agora é uma reescrita completa do React/Ink do CLI interativo, com um back-end Python JSON-RPC (tui_gateway). Compositor fixo, transmissão ao vivo com suporte para OSC-52 clipboard, teclas de seleção estáveis, barra de status com cronômetro por turno e ramificação git, confirmação /clear, predefinição de tema claro e uma sobreposição de observabilidade de geração de subagente. ~310 compromete-se com ui-tui/ + tui_gateway/. (@OutThisLife + Teknium)
  • Transport ABC + Native AWS Bedrock — A conversão de formato e o transporte HTTP foram extraídos de run_agent.py em uma camada agent/transports/ conectável. AnthropicTransport, ChatCompletionsTransport, ResponsesApiTransport e BedrockTransport possuem, cada um, sua própria conversão de formato e formato API. O suporte nativo do AWS Bedrock por meio do Converse API vem além da nova abstração. (#10549, #13347, #13366, #13430, #13805, #13814 - @kshitijk4poor + Teknium)
  • Cinco novos caminhos de inferência — NVIDIA NIM nativo (#11774), Arcee AI (#9276), Step Plan (#13893), Google Gemini CLI OAuth (#11270) e Vercel ai-gateway com preços + descoberta dinâmica (#13223 — @jerilynzheng). Além disso, o Gemini é roteado através do AI Studio API nativo para melhor desempenho (#12674).
  • GPT-5.5 sobre Codex OAuth — O novo modelo de raciocínio GPT-5.5 da OpenAI agora está disponível por meio do ChatGPT Codex OAuth, com descoberta de modelo ao vivo conectada ao seletor de modelo para que novos lançamentos OpenAI apareçam sem atualizações de catálogo. (#14720)
  • QQBot — 17ª plataforma suportada — Adaptador QQBot nativo via QQ Official API v2, com assistente de configuração de digitalização para configuração de QR, cursor de streaming, reações de emoji e controle de política de DM/grupo que corresponde à paridade WeCom/Weixin. (#9364, #11831)
  • Superfície de plug-in expandida — Os plug-ins agora podem registrar comandos de barra (register_command), despachar ferramentas diretamente (dispatch_tool), bloquear a execução de ferramentas a partir de ganchos (pre_tool_call pode vetar), reescrever resultados de ferramentas (transform_tool_result), transformar a saída do terminal (transform_terminal_output), enviar back-ends image_gen e adicionar guias de painel personalizadas. O plug-in de limpeza de disco incluído é ativado por padrão como uma implementação de referência. (#9377, #10626, #10763, #10951, #12929, #12944, #12972, #13799, #14175)
  • /steer — cutucadas do agente no meio da execução — /steer <prompt> injeta uma nota que o agente em execução vê após sua próxima chamada de ferramenta, sem interromper o turno ou quebrar o cache de prompt. Para quando você deseja corrigir o curso de um agente durante o voo. (#12116)
  • Shell hooks — Conecte qualquer shell script como um gancho de ciclo de vida Hermes (pre_tool_call, post_tool_call, on_session_start, etc.) sem escrever um plugin Python. (#13296)
  • Modo de entrega direta do Webhook — As assinaturas do Webhook agora podem encaminhar cargas diretamente para um bate-papo da plataforma sem passar pelo agente — notificações push de LLM zero para alertas, verificações de tempo de atividade e fluxos de eventos. (#12473)
  • Delegação mais inteligente — Os subagentes agora têm uma função orchestrator explícita que pode gerar seus próprios trabalhadores, com max_spawn_depth configurável (padrão simples). Subagentes irmãos simultâneos compartilham o estado do sistema de arquivos por meio de uma camada de coordenação de arquivos para que não atrapalhem as edições uns dos outros. (#13691, #13718)
  • Modelos auxiliares - UI configurável + modelo principal primeiro - hermes model tem uma tela dedicada "Configurar modelos auxiliares" para substituições por tarefa (compressão, visão, session_search, title_generation). O roteamento auto agora é padronizado para o modelo principal para tarefas secundárias em todos os usuários (anteriormente, os usuários do agregador eram roteados silenciosamente para um padrão barato do lado do provedor). (#11891, #11900)
  • Sistema de plug-in de painel + troca de tema ao vivo — O painel da web agora é extensível. Plugins de terceiros podem adicionar guias, widgets e visualizações personalizadas sem bifurcação. Emparelhado com um sistema de tema de troca ao vivo – os temas agora controlam cores, fontes, layout e densidade – para que os usuários possam trocar a aparência do painel sem recarregar. A mesma disciplina temática que o CLI possui, agora na web. (#10951, #10687, #14725)
  • Aperfeiçoamento do painel - i18n (inglês + chinês), layout da barra lateral do roteador react, responsivo a dispositivos móveis, implantação Vercel, rastreamento de chamadas API real por sessão e botões de atualização + reinicialização do gateway de um click. (#9228, #9370, #9453, #10686, #13526, #14004 - @austinpickett + @DeployFaith + Teknium)
