Agente Hermes v0.21.7

Data de lançamento: 11 de outubro de 2026

Lançamento de patches. Esta tag reúne cerca de 204 PRs mesclados desde v0.21.6 em uma versão estável para o aplicativo de desktop (macOS Apple Silicon, Windows), Microsoft Store e MSIX, o instalador, Docker e Hermes Cloud. Notas completas com curadoria para esta janela são enviadas com v0.22.0.

<!-- HERMES_BUILDS_TABLE -->

O que este patch fornece para instalações de origem (hermes update e o atualizador do aplicativo de desktop em uma finalização de compra do git):

  • As atualizações agora seguem os lançamentos marcados. Uma instalação de código-fonte do repositório oficial atualiza para a última versão publicada do vX.Y.Z em vez de cada commit no main. Uma instalação já mais recente que a versão mais recente permanece onde está e aguarda a próxima; nada é movido de volta. Para continuar acompanhando cada commit: hermes update --set-channel main. Garfos e espelhos continuam seguindo main. As instalações da loja, do MSIX e do pacote de desktop permanecem inalteradas.
  • Escolha o canal no aplicativo de desktop. Configurações ▸ Sobre ▸ Atualizações tem uma opção Atualizar canal (Versões estáveis/Cada commit) para instalações de origem, e a caixa de diálogo de atualização agora mostra em qual canal você está.
  • O raciocínio sobrevive à retomada. O pensamento assinado é reproduzido após hermes chat --resume e na próxima curva do gateway, e os modelos de raciocínio do Bedrock Converse não são mais rejeitados nas sessões retomadas.
  • As atualizações não falham mais atrás de alguns firewalls. As instalações no main não buscam mais um registro de lançamento que os firewalls regionais poderiam responder com 403. A verificação estável usa seu token GitHub quando um está definido (GITHUB_TOKEN ou gh auth login) e relata um limite de taxa GitHub como limite de taxa.

Sobre este lançamento

Medido no commit 1fd18277267152893a8a24792b79213e7ca3f899, a janela desde v0.21.6 contém 740 commits sem mesclagem em 4.156 arquivos alterados (+86.775 / -26.980), 204 PRs mesclados e 69 problemas fechados.

Também na janela, não documentado aqui propositalmente: plug-ins executando ações integradas do aplicativo Desktop (ctx.runAction) e um plug-in SDK pet bubble (ctx.pet.say); solicitações Codex feitas pelo núcleo para que os plug-ins nunca mantenham o token; habilidades instaladas no meio da sessão atingindo o modelo sem uma reconstrução imediata; Krea 2 Medium Turbo como faixa de imagem padrão para novos assinantes pagos, com um fallback FAL quando o Krea gerenciado recusa uma solicitação; atualizações mais rápidas da área de trabalho (a passagem do React Compiler armazenada em cache pelo conteúdo, o renderizador compilado reutilizado quando apenas o carimbo de instalação foi alterado, entradas nativas inalteradas deixadas no lugar); instalações fixadas que verificam apenas o pino; marcas de compactação emitidas para o Relé; e novos plug-ins da comunidade, incluindo escudo de memória, ledger de comando, Memoria, Model Router, wyoming-voice-bridge, codex-account-switch e redline.

release notes com curadoria completa para esta janela são fornecidos com v0.22.0, que documentará tudo, desde v0.21.0 em diante - destaques, áreas de recursos e créditos completos do colaborador. Nada nesta janela é ignorado.

Atualizando

  • Aplicativo de desktop: atualiza-se sozinho. A Microsoft Store instala a atualização por meio da Store.
  • CLI: hermes update, ou execute novamente o instalador one-liner.
  • Docker / Nuvem Hermes: nousresearch/hermes-agent:stable (ou :latest).
