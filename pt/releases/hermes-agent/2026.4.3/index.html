agente hermes v2026.4.3

Agente Hermes v0.7.0 (v2026.4.3)

Data de lançamento: 3 de abril de 2026

A versão de resiliência — provedores de memória conectáveis, rotação de pool de credenciais, navegador antidetecção Camofox, visualizações de diferenças em linha, proteção de gateway em condições de corrida e roteamento de aprovação, além de correções de segurança profundas em 168 PRs e 46 problemas resolvidos.

✨ Destaques

  • Interface de provedor de memória conectável — A memória agora é um sistema de plug-in extensível. Back-ends de memória de terceiros (Honcho, armazenamentos de vetores, bancos de dados personalizados) implementam um provedor simples ABC e registram-se por meio do sistema de plug-ins. A memória interna é o provedor padrão. Integração Honcho restaurada para paridade total como plug-in de referência com resolução de host/peer com escopo de perfil. (#4623, #4616, #4355)
  • Pools de credenciais do mesmo provedor — Configure várias chaves API para o mesmo provedor com rotação automática. A estratégia least_used thread-safe distribui a carga entre as chaves e as falhas 401 acionam a rotação automática para a próxima credencial. Configure através do assistente de configuração ou configuração do credential_pool. (#4188, #4300, #4361)
  • Backend de navegador antidetecção Camofox — Novo backend de navegador local usando Camoufox para navegação furtiva. Sessões persistentes com descoberta de URL VNC para depuração visual, bypass SSRF configurável para backends locais, instalação automática via hermes tools. (#4008, #4419, #4292)
  • Pré-visualizações de diferenças inline — As operações de gravação de arquivos e patches agora mostram diferenças inline no feed de atividades da ferramenta, fornecendo confirmação visual do que mudou antes que o agente prossiga. (#4411, #4423)
  • Continuidade de sessão do servidor API e streaming de ferramentas — O servidor API (integração Open WebUI) agora transmite eventos de progresso da ferramenta em tempo real e oferece suporte a cabeçalhos X-Hermes-Session-Id para sessões persistentes entre solicitações. As sessões persistem no SessionDB compartilhado. (#4092, #4478, #4802)
  • ACP: Servidores MCP fornecidos por Client — Integrações de editores (VS Code, Zed, JetBrains) agora podem registrar seus próprios servidores MCP, que Hermes utiliza como ferramentas de agente adicionais. O ecossistema MCP do seu editor flui diretamente para o agente. (#4705)
  • Gateway Hardening — Maior estabilidade em condições de corrida, entrega de mídia fotográfica, controle de inundação, sessões travadas, roteamento de aprovação e espirais mortais de compressão. O gateway é substancialmente mais confiável na produção. (#4727, #4750, #4798, #4557)
  • Segurança: Bloqueio de exfiltração secreta — URLs de navegador e respostas LLM agora são verificadas em busca de padrões secretos, bloqueando tentativas de exfiltração por meio de codificação de URL, base64 ou injeção imediata. As proteções de diretório de credenciais foram expandidas para .docker, .azure, .config/gh. A saída da sandbox Execute_code é editada. (#4483, #4360, #4305, #4327)
