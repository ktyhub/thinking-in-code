Agente Hermes v0.22.2

Data de lançamento: 15 de outubro de 2026

v0.22.1 foi construído a partir do commit errado. Ele enviou um trabalho de gateway não lançado e o aplicativo Microsoft Store poderia permanecer em “Conectando”. 0.22.2 é o lançamento que 0.22.1 deveria ser.

Problema conhecido: As sessões executadas no gateway 0.22.1 não podem ser excluídas no 0.22.2.

<!-- HERMES_BUILDS_TABLE -->

Destaques

  • O gateway inicia novamente após uma reinicialização. Após uma reinicialização, o Linux pode entregar um PID inicial para um processo não relacionado, e o gateway pode confundi-lo com um gateway em execução, portanto, um gateway supervisionado (systemd, launchd, Docker) recusou-se a iniciar. O Hermes agora registra a inicialização em que foi iniciado e, quando não consegue saber, solicita o bloqueio do host, que apenas um gateway ativo mantém. (#138594, corrige #133744)
  • Longas voltas do modelo local sobrevivem em laptops. As solicitações locais sempre são transmitidas com o progresso da leitura imediata (mostrado na linha de status), os temporizadores de parada ignoram o tempo em que a máquina estava adormecida, um servidor local recuperado faz outra tentativa em vez de um disjuntor que falhou a cada mensagem posterior, e a compactação não expira mais enquanto o servidor ainda está lendo uma conversa longa. Em máquinas com memória unificada Windows, a inicialização do modelo e o cache de prompt são dimensionados para liberar memória. (#138560)

Abaixo está tudo na linha de lançamento do 0.22 desde o v0.22.0: as correções que o 0.22.1 deveria enviar, mais as duas acima. O trabalho que está disponível apenas no main é fornecido com o v0.23.0.
