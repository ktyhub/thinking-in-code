Agente Hermes v0.4.0 (v2026.3.23)

Data de lançamento: 23 de março de 2026

O lançamento de expansão da plataforma — servidor API compatível com OpenAI, 6 novos adaptadores de mensagens, 4 novos provedores de inferência, gerenciamento de servidor MCP com OAuth 2.1, referências de contexto @, cache de prompt de gateway, streaming habilitado por padrão e uma passagem de confiabilidade abrangente com mais de 200 correções de bugs.

✨ Destaques

  • Servidor API compatível com OpenAI — Exponha o Hermes como um endpoint /v1/chat/completions com um novo /api/jobs REST API para gerenciamento de tarefas cron, reforçado com limites de entrada, listas de permissões de campo, persistência de resposta apoiada por SQLite e proteção de origem CORS (#1756, #2450, #2456, #2451, #2472)
  • 6 novos adaptadores de plataforma de mensagens — Os adaptadores Signal, DingTalk, SMS (Twilio), Mattermost, Matrix e Webhook unem-se ao Telegram, Discord e WhatsApp. O gateway reconecta automaticamente plataformas com falha com espera exponencial (#2206, #1685, #1688, #1683, #2166, #2584)
  • **@ referências de contexto ** — Injeção de contexto @file e @url estilo Claude Code com preenchimento de tabulação no CLI (#2343, #2482)
  • 4 novos provedores de inferência — GitHub Copilot (OAuth + validação de token), Alibaba Cloud/DashScope, Kilo Code e OpenCode Zen/Go (#1924, #1879 por @mchzimm, #1673, #1666, #1650)
  • Gerenciamento de servidor MCP CLI — Comandos hermes mcp para instalação, configuração e autenticação de servidores MCP com fluxo OAuth 2.1 PKCE completo (#2465)
  • Cache de prompt de gateway — Armazena em cache instâncias do AIAgent por sessão, preservando o cache de prompt Anthropic entre turnos para redução drástica de custos em conversas longas (#2282, #2284, #2361)
  • Revisão da compactação de contexto — Resumos estruturados com atualizações iterativas, proteção de limite de orçamento de token, endpoint de resumo configurável e suporte a modelo substituto (#2323, #1727, #2224)
  • Streaming ativado por padrão — Streaming do CLI ativado por padrão com exibição adequada do progresso do girador/ferramenta durante o modo de streaming, além de extensas correções de quebra de linha e concatenação (#2340, #2161, #2258)
