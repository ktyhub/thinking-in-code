Agente Hermes v0.14.0 (v2026.5.16)

Data de lançamento: 16 de maio de 2026 Desde v0.13.0: 808 commits · 633 PRs mesclados · 1.393 arquivos alterados · 165.061 inserções · 545 problemas fechados (12 P0, 50 P1) · 215 colaboradores da comunidade (incluindo coautores)

A versão básica — o Hermes é instalado e executado em qualquer lugar, enviado com o que você realmente deseja usar e para de enviar o que você não deseja. xAI Grok chega como um provedor SuperGrok OAuth com grok-4.3 atingindo uma janela de contexto de 1 milhão. Um novo proxy local compatível com OpenAI transforma qualquer provedor Hermes autenticado por OAuth – Claude Pro, ChatGPT Pro, SuperGrok – em um endpoint que Codex/Aider/Cline/Continue pode atingir. x_search chega como uma ferramenta de pesquisa X (Twitter) de primeira classe com autenticação de chave OAuth ou API. A pilha do Microsoft Teams é conectada de ponta a ponta (autenticação gráfica + ouvinte de webhook + tempo de execução do pipeline + entrega de saída). Uma onda de desinflação torna as instalações dramaticamente mais leves – back-ends pesados ​​agora são de instalação lenta no primeiro uso, os extras [all] descartam tudo coberto por deps preguiçosos e uma instalação em camadas recua quando uma roda é rejeitada em sua plataforma. pip install hermes-agent funciona a partir do PyPI. A onda de inicialização a frio reduz cerca de 19 segundos do lançamento do hermes. As chamadas CDP do navegador são 180x mais rápidas. Duas novas plataformas de mensagens (LINE + SimpleX Chat) elevam o total para 22. Cache de prompt Claude de sessão cruzada de 1 hora, /handoff que realmente transfere sessões ao vivo, UI de botão nativo para clarify no Telegram e Discord, preenchimento de histórico de canal Discord, diagnóstico semântico LSP em cada gravação, um video_generate conectável unificado, um back-end de driver cua computer_use que finalmente funciona com provedores não antrópicos, cli URLs compatíveis em qualquer terminal, integração com Zed ACP Registry via uvx, Windows beta nativo, 9 novas habilidades opcionais, roteador OpenRouter Pareto Code, huggingface/skills como um toque padrão trusted. 12 fechamentos P0 + 50 P1.

✨ Destaques

  • xAI Grok via SuperGrok OAuth — e grok-4.3 salta para uma janela de contexto de 1M — Se você pagar pelo SuperGrok, agora você pode usar Grok dentro do Hermes fazendo login com sua conta xAI — sem chave API, sem cobrança separada. O wire-through também coloca o grok-4.3 em uma janela de contexto de token de 1M, para que você possa colocar bases de código inteiras ou corpora de pesquisa em um único prompt. Inclui tratamento adequado para erros de autorização e uma página de documentos SSH para túnel para quando você estiver usando SSH em uma caixa remota e precisar concluir o fluxo OAuth. (#26534, #26664, #26644, #26592)
  • Proxy local compatível com OpenAI para provedores OAuth — Execute hermes proxy e você obterá um endpoint http://localhost:port que fala o OpenAI API, mas é apoiado por qualquer provedor OAuth no qual você esteja conectado — Claude Pro, ChatGPT Pro, SuperGrok. Agora, qualquer ferramenta que espera um endpoint compatível com OpenAI (Codex CLI, Aider, Cline, Continue, seus scripts personalizados) funciona apenas com sua assinatura existente, sem necessidade de chave API. Uma assinatura, todas as ferramentas. (#25969)
  • x_search — ferramenta de pesquisa X (Twitter) de primeira classe — O agente agora pode pesquisar X diretamente sem instalar uma habilidade ou conectar uma integração personalizada.   • Microsoft Teams — ponta a ponta — Hermes agora pode ler mensagens do Teams e postar de volta. A pilha completa do Microsoft Graph se junta: auth + client Foundation, um ouvinte de webhook que recebe eventos do Teams, um tempo de execução de plug-in de pipeline e entrega de saída. Conecte o bot uma vez e converse com seu agente em qualquer canal, DM ou grupo do Teams. (resgates de #21408–#21411) (#21922, #21969, #22007, #22024)

A revisão da memória em segundo plano também atinge o cache, portanto, não paga o preço total a cada turno. (#23828, #25434, #24778)

A diferença é enorme: coisas que costumavam levar alguns segundos por chamada retornam em milissegundos. As interações com páginas do mundo real parecem instantâneas. (#23226)
