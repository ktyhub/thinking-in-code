Agente Hermes v0.16.0 (v2026.6.5)

Data de lançamento: 5 de junho de 2026 Desde v0.15.2: 874 commits · 542 PRs mesclados · 1.962 arquivos alterados · 205.216 inserções · 46.217 exclusões · 399 problemas fechados (2 P0, 62 P1, 16 com tags de segurança) · 170 colaboradores da comunidade (incluindo coautores)

O Surface Release. A Hermes encontra você onde quer que você trabalhe. Um novo aplicativo de desktop nativo - desenvolvido com 100 PRs e 159 commits em uma única semana - oferece o Hermes como um aplicativo macOS/Linux/Windows real: instalação click, atualização automática no aplicativo, arrastar e soltar arquivos no bate-papo, um seletor de modelo embutido na barra de status, sessões simultâneas de vários perfis, uma tradução completa em chinês simplificado e a capacidade de conectar-se a um gateway Hermes remoto via OAuth ou nome de usuário/senha. Junto com ele, o painel da web cresceu um painel de administração completo baseado em navegador (catálogo MCP, canais de mensagens, credenciais, webhooks, memória, OIDC conectável / login de nome de usuário-senha) e a configuração inicial obteve um caminho de “Configuração rápida via Portal Nous” que leva você da instalação até a primeira mensagem em segundos. O conjunto de habilidades padrão foi reduzido para o que você realmente precisa, NVIDIA / habilidades se juntaram aos toques do trusted Skills Hub, o seletor de modelo agora pode ser pesquisado em qualquer lugar (desktop, web, TUI, CLI) e /undo finalmente permite que você retome os últimos N turnos. 2 fechamentos P0 e 62 P1 acompanham, além de uma rodada de segurança (pino Starlette CVE-2026-48710, endurecimento fora do loop SSRF, remoção de credenciais de subprocesso).

✨ Destaques

  • Hermes Desktop — um aplicativo nativo real, não um wrapper de terminal — Este é o título. Agora existe um aplicativo apps/desktop/ Electron que é instalado como qualquer outro aplicativo de desktop no macOS, Linux e Windows, se atualiza de dentro do aplicativo e oferece uma GUI sofisticada para tudo o que o Hermes faz. Você obtém uma janela de bate-papo adequada com streaming, uma lista de sessões que você pode arquivar e pesquisar, arrastar e soltar arquivos em qualquer lugar da área de bate-papo, colagem de imagens clipboard, uma paleta de comandos Cmd + K e um seletor de modelo diretamente na barra de status. Se você disse aos amigos "é um agente CLI" e viu seus olhos brilharem - agora você pode simplesmente enviar-lhes um instalador. Nada disso existia há uma semana. (#20059, #35607, #37099, #37379, #38631 - @OutThisLife, @jquesnelle, @ethernet8023, @austinpickett, @benbarclay)
  • Execute o aplicativo de desktop em um Hermes remoto — faça login com OAuth ou nome de usuário/senha — O aplicativo de desktop não precisa executar o Hermes localmente. Aponte-o para um gateway Hermes remoto (seu homelab, uma caixa hospedada, um servidor de colega de equipe) e ele se conecta através de um WebSocket seguro, autenticando com OAuth ou um login de nome de usuário/senha - sem mexer com sinalizadores --insecure ou tokens de sessão copiados manualmente. Cada perfil pode ter como destino seu próprio host remoto e você pode executar sessões simultâneas em vários perfis em uma janela com links @session de perfil cruzado. A versão prática: seu laptop executa uma GUI fina, o agente pesado é executado onde quer que seu API seja chaveado e computado ao vivo. (#37888, #38851, #39330, #39778 — @benbarclay, @OutThisLife, @ teknium1)
  • O painel da web agora é um painel de administração completo — configure tudo no navegador — O painel cresceu de "visualizar suas sessões" para uma superfície de administração completa. Há uma página de canais que configura todas as plataformas de mensagens de gateway (Telegram, Discord, Slack, etc.) do navegador, um painel de administração para o catálogo MCP com alternância de ativação/desativação, gerenciamento de credenciais, criação de webhook e gancho, configuração de memória, controles de gateway e uma página do sistema com verificação antes da atualização e um click Debug Share. Você não precisa mais usar SSH e editar config.yaml para conectar um novo canal de mensagens ou servidor MCP - agora é tudo apontar e click. (#36704, #36736, #37211, #38205, #38600 — @ teknium1)
  • Hermes Desktop fala chinês simplificado — 简体中文 completo na GUI de bate-papo — O aplicativo de desktop agora fornece uma tradução completa em chinês simplificado (简体中文) em todas as superfícies da interface do usuário — a própria janela de bate-papo, barra lateral, configurações, centro de comando, cron, mensagens, perfis, habilidades, agentes, tudo. O inglês continua sendo o padrão; mude o idioma nas configurações de aparência e a escolha persiste na sua configuração (display.language). Ele é construído em uma camada i18n digitada adequadamente, portanto, adicionar mais idiomas a partir daqui é simples. (#38241 — @JimLiu)
  • Conjunto de habilidades padrão mais enxuto — Hermes envia apenas o que você realmente precisa — O conjunto de habilidades agrupadas recebeu um corte deliberado. Habilidades que eram redundantes ou mortas desapareceram (spotify — substituído pelas 7 ferramentas do plugin nativo do Spotify; linear — substituído por hermes mcp install linear; kanban-codex-lane, debugging-hermes-tui-commands, um órfão domain obsoleto e vários marcadores de categoria vazios). Habilidades mais pesadas ou de nicho passaram de agrupadas para opcionais (o conjunto criativo Baoyu, dspy, subagent-driven-development, minecraft-modpack-server, pokemon-player, hermes-s6-container-supervision) — ainda a um hermes skills install de distância, mas não carregadas por padrão. E uma nova porta de relevância environments: mantém as habilidades específicas do contexto (kanban, docker/s6) fora do índice de habilidades para usuários que nunca as usarão, enquanto ainda as carrega mediante solicitação explícita. O resultado: uma lista de habilidades padrão menor e mais nítida, menos ruído no seletor e um prompt mais leve. O curador agora também pode remover habilidades integradas não utilizadas (não apenas aquelas criadas pelo agente), com o uso rastreado para cada habilidade. (#39028, #36701, #36228 — @ teknium1)
  • NVIDIA/skills agora é um toque de habilidades trusted integrado — NVIDIA/skills se junta a OpenAI, Anthropic e HuggingFace como um toque trusted padrão no Skills Hub — detectável, navegável, pesquisável e com atualização automática por meio do mesmo pipeline. As habilidades verificadas da NVIDIA para CUDA-X, AIQ, cuOpt e o restante de sua pilha de produtos estão a uma instalação de distância, com rótulos de categoria reais do sidecar skills.sh.json do repositório. (#34333 — @ teknium1)
  • Configuração rápida via Portal Nous — desde a instalação até a primeira mensagem em segundos — A configuração inicial foi reduzida a dois caminhos claros: Configuração rápida (faça login no Portal Nous, obtenha um seletor de modelo, comece a conversar imediatamente) ou Configuração completa (o assistente detalhado para usuários avançados). hermes portal agora é o alias legível por humanos que executa todo o fluxo Nous de configuração rápida. O menu de primeira execução explica a diferença in-line para que os recém-chegados não adivinhem. O objetivo: um novo usuário não precisa ler documentos para enviar sua primeira mensagem. (#35723, #36227, #38449, #38465 — @ teknium1, @kshitijk4poor)
  • Seletor de modelo difuso, em qualquer lugar — digite algumas letras, encontre seu modelo — O seletor de modelo agora faz pesquisa difusa no aplicativo de desktop, painel da web, TUI e CLI. Superfícies tipo "v4fl" e deepseek-v4-flash; provedores de vários terminais são agrupados em uma linha, em vez de sobrecarregar a lista com duplicatas, e cada linha carrega uma descrição para que você saiba o que está escolhendo. O catálogo é atualizado de hora em hora, em vez de diariamente, para que os novos modelos apareçam no mesmo dia do lançamento. Novidade nesta janela: deepseek-v4-flash, MiniMax-M3 com contexto 1M, qwen3.7-plus. (#36928, #35227, #35756, #35659, #36214 — @kshitijk4poor, @teknium1)
  • /undo [N] — retome os últimos N turnos — Disse a coisa errada ou mandou o agente para um caminho ruim? /undo faz backup de N turnos do usuário, preenche previamente sua última mensagem para que você possa editar e reenviar e exclui suavemente os turnos intermediários. Funciona no CLI, no TUI e em plataformas de mensagens (Telegram, Discord, etc.) com paridade total. Fecha uma solicitação de longa data (#21910). (#36229, #36699 — @ teknium1)
  • Escolha sua interface padrão — cli ou tui — Agora você pode definir se hermes chat leva você para o CLI clássico ou para o Ink TUI por padrão, com um sinalizador --cli para substituir por invocação. A TUI também possui um único comando /model unificado e uma sobreposição de sessões para alternar entre sessões ao vivo. Use a interface que você realmente gosta. (#37782, #37112 — @OutThisLife)
