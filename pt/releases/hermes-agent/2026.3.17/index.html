agente hermes v2026.3.17

Agente Hermes v0.3.0 (v2026.3.17)

Data de lançamento: 17 de março de 2026

O lançamento de streaming, plug-ins e provedor - entrega unificada de token em tempo real, arquitetura de plug-in de primeira classe, sistema de provedor reconstruído com Vercel AI Gateway, provedor Antrópico nativo, aprovações inteligentes, conexão ao vivo do navegador Chrome CDP, integração ACP IDE, memória Honcho, modo de voz, shell persistente e mais de 50 correções de bugs em todas as plataformas.

✨ Destaques

  • Infraestrutura de streaming unificada — Entrega token por token em tempo real no CLI e em todas as plataformas de gateway. As respostas são transmitidas à medida que são geradas, em vez de chegarem como um bloco. (#1538)
  • Arquitetura de plug-ins de primeira classe — Coloque arquivos Python no ~/.hermes/plugins/ para estender o Hermes com ferramentas, comandos e ganchos personalizados. Não é necessário bifurcar. (#1544, #1555)
  • Provedor Antrópico Nativo — Chamadas diretas do Anthropic API com descoberta automática de credenciais do Claude Code, fluxos OAuth PKCE e cache de prompt nativo. Não é necessário intermediário OpenRouter. (#1097)
  • Aprovações Inteligentes + Comando /stop — Sistema de aprovação inspirado no Codex que aprende quais comandos são seguros e lembra suas preferências. /stop encerra a execução do agente atual imediatamente. (#1543)
  • Integração de memória Honcho — Gravações de memória assíncronas, modos de recuperação configuráveis, integração de título de sessão e isolamento multiusuário no modo gateway. Por @erosika. (#736) Modo de voz — Push-to-talk no CLI, notas de voz no Telegram/Discord, suporte ao canal de voz do Discord e transcrição de sussurro local por meio de sussurro mais rápido. (#1299, #1185, #1429)
  • Execução simultânea de ferramentas — Múltiplas chamadas de ferramentas independentes agora são executadas em paralelo por meio do ThreadPoolExecutor, reduzindo significativamente a latência para giros de várias ferramentas. (#1152)
  • Redação de PII — Quando privacy.redact_pii está ativado, as informações de identificação pessoal são automaticamente limpas antes de enviar o contexto aos provedores de LLM. (#1542)
  • /browser connect via CDP — Anexe ferramentas do navegador a uma instância ativa do Chrome por meio do protocolo Chrome DevTools. Depure, inspecione e interaja com páginas que você já abriu. (#1549)
  • Vercel AI Gateway Provider — Encaminhe a Hermes através do Vercel AI Gateway para acessar seu catálogo de modelos e infraestrutura. (#1628)
  • Roteador de provedor centralizado — Sistema de provedor reconstruído com call_llm API, comando /model unificado, detecção automática de provedor no switch de modelo e substituições diretas de endpoint para clients auxiliares/delegação. (#1003, #1506, #1375)
  • Servidor ACP (integração IDE) — VS Code, Zed e JetBrains agora podem se conectar ao Hermes como um back-end de agente, com suporte completo a comandos de barra. (#1254, #1532)
  • Modo Shell Persistente — Os back-ends de terminal local e SSH podem manter o estado do shell durante chamadas de ferramenta — cd, env vars e aliases persistem. Por @alt-glitch. (#1067, #1483)
  • Agentic On-Policy Distillation (OPD) — Novo ambiente de treinamento de RL para políticas de agentes de destilação, expandindo o ecossistema de treinamento Atropos. (#1149)
