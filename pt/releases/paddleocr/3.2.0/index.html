#PaddleOCR v3.2.0

2025.8.21 v3.2.0 lançado

  • Adições significativas de modelo:

    • Introduziu treinamento, inferência e implantação de modelos de reconhecimento PP-OCRv5 em inglês, tailandês e grego. O modelo inglês PP-OCRv5 oferece uma melhoria de 11% em cenários ingleses em comparação com o modelo PP-OCRv5 principal, com os modelos de reconhecimento tailandês e grego alcançando precisões de 82.68% e 89.28%, respectivamente.

  • Atualizações de capacidade de implantação:

    • Suporte total para versões do framework PaddlePaddle 3.1.0 e 3.1.1.
    • Atualização abrangente da solução de implantação local PP-OCRv5 C++, agora com suporte para Linux e Windows, com paridade de recursos e precisão idêntica à implementação Python.
    • A inferência de alto desempenho agora suporta CUDA 12, e a inferência pode ser realizada usando backends Paddle Inference ou ONNX Runtime.
    • A solução de implantação orientada a serviços de alta estabilidade agora é totalmente de código aberto, permitindo que os usuários personalizem imagens Docker e SDKs conforme necessário.
    • A solução de implantação orientada a serviços de alta estabilidade também suporta invocação por meio de solicitações HTTP construídas manualmente, permitindo o desenvolvimento de código do lado client em qualquer linguagem de programação.

  • Suporte de referência:

    • Todas as linhas de produção agora suportam benchmarking refinado, permitindo a medição do tempo de inferência de ponta a ponta, bem como dados de latência por camada e por módulo para auxiliar na análise de desempenho.
    • A documentação foi atualizada para incluir métricas importantes para configurações comumente usadas em hardware convencional, como latência de inferência e uso de memória, fornecendo referências de implantação para usuários.

  • Correções de bugs:

    • Resolvido o problema de falha no salvamento do log durante o treinamento do modelo.
    • Atualizado o componente de aumento de dados para modelos de fórmula para compatibilidade com versões mais recentes da dependência de albumentações e avisos de impasse corrigidos ao usar o pacote tokenizers em cenários de vários processos.
    • Corrigidas inconsistências nos comportamentos dos switches (por exemplo, use_chart_parsing) nos arquivos de configuração do PP-StructureV3 em comparação com outros pipelines.

  • Outras melhorias:

    • Dependências principais e opcionais separadas. Apenas dependências básicas mínimas são necessárias para o reconhecimento básico de texto; dependências adicionais para análise de documentos e extração de informações podem ser instaladas conforme necessário.
    • Suporte habilitado para placas gráficas NVIDIA RTX série 50 no Windows; os usuários podem consultar o guia de instalação para as versões correspondentes da estrutura PaddlePaddle.
    • Os modelos da série PP-OCR agora suportam o retorno de coordenadas de um único caractere.
    • Adicionadas AIStudio, ModelScope e outras fontes de download de modelos, permitindo aos usuários especificar a fonte para downloads de modelos.
    • Adicionado suporte para conversão de gráfico em tabela por meio do módulo PP-Chart2Table.
    • Descrições de documentação otimizadas para melhorar a usabilidade.

2025.8.21 v3.2.0 发布

  • 重要模型新增：

    • 新增 PP-OCRv5 英文、泰文、希腊文识别模型的训练、推理、部署。**其中 PP-OCRv5 英文模型较 PP-OCRv5 **

  • 部署能力升级:

    • 全面支持飞桨框架 3.1.0 e 3.1.1 版本。
    • 全面升级 PP-OCRv5 C++ 本地部署方案, 支持 Linux, Windows, 功能及精度效果与 Python 方案 保持 一致。
    • 高性能推理支持 CUDA 12,可使用 Paddle Inference,ONNX Runtime e 后端推理。
    • 高稳定性服务化部署方案全面开源，支持用户根据需求对 Docker 镜像和 SDK进行定制化修改。

  • A solução de implantação baseada em serviços de alta estabilidade suporta invocação através da construção manual de solicitações HTTP, o que permite que o código do cliente seja escrito em qualquer linguagem de programação.

  • Suporte de referência:

    • **Todas as linhas de produção suportam o benchmark refinado da linha de produção, que pode medir o tempo de inferência ponta a ponta da linha de produção, bem como os dados demorados, camada por camada e módulo por módulo, que podem ser usados para auxiliar na análise de desempenho da linha de produção. **
    • **O documento complementa os principais indicadores das configurações comumente usadas de cada linha de produção em hardware convencional, incluindo tempo de inferência e uso de memória, etc., para fornecer uma referência para implantação do usuário. **

  • Correções de bugs:

    • Corrigido o problema de falha ao salvar logs de treinamento durante o treinamento do modelo.
    • A parte de aprimoramento de dados do modelo de fórmula foi atualizada para compatibilidade de versão para se adaptar à nova versão da dependência de albumentações, e um aviso de impasse que aparece ao usar o pacote de dependência de tokenizers em vários processos foi corrigido.
    • Corrigido o problema de que o comportamento de switches como use_chart_parsing no arquivo de configuração PP-StructureV3 não é consistente com outras linhas de produção.

  • Outras atualizações:

    • **Dependências necessárias separadas e dependências opcionais. Ao usar a função básica de reconhecimento de texto, apenas algumas dependências principais precisam ser instaladas; se funções como análise de documentos e extração de informações forem necessárias, os usuários poderão optar por instalar dependências adicionais conforme necessário. **
    • ** Suporta usuários do Windows para usar placas gráficas NVIDIA série 50 e pode instalar a versão correspondente da estrutura paddle de acordo com a documentação de instalação. **
    • **Os modelos da série PP-OCR suportam o retorno de coordenadas de texto único. **
    • Novas fontes de download como AIStudio e ModelScope são adicionadas ao modelo. Você pode especificar a fonte de download relevante para baixar o modelo correspondente.
    • Suporta conversão de gráfico em tabela Capacidade de raciocínio do módulo de função única PP-Chart2Table.
    • Otimize as descrições em alguns documentos de uso para melhorar a facilidade de uso.
