#grafql-java 25.0.beta-6

Esta é outra versão beta para a próxima versão 25.

Ele contém várias alterações, especificamente melhorias de desempenho para o novo recurso de carregador de dados encadeado.

Uma palavra de advertência

Embora todos os recursos sejam testados e os consideremos prontos para serem usados, não garantimos que esta seja uma versão estável: isso significa que haverá mais alterações significativas até chegarmos ao 25.0.

Esta versão destina-se a testar e fornecer feedback à equipe GraphQL Java.
