difusores v0.41.0

[!TIP] Esta versão traz Qwen-Image 2.1 para difusores, com geração de texto para imagem, edição de imagem, transparência nativa e treinamento LoRA.

A partir deste lançamento, estamos adotando a filosofia de lançamento do Transformers: coordenar lançamentos secundários em torno de integrações de novos modelos, ao mesmo tempo que incluímos outras alterações mescladas desde o lançamento anterior. Os lançamentos de patches permanecem focados em correções. Consulte nossa política de lançamento.

Imagem Qwen 2.1

Qwen-Image 2.1 unifica a geração e edição de imagens em um modelo. Seu componente de geração visual possui parâmetros 7B e suporta múltiplas imagens de referência e saída RGBA nativa para imagens transparentes. Confira os documentos para mais detalhes.

Obrigado a @naykun pela integração do modelo (#14804).

Outros destaques

  • Carregamento de ponto de verificação paralelo ao tensor: cada classificação lê sua própria fatia de pesos fragmentados diretamente, reduzindo a memória necessária durante o carregamento. (#14544)
  • LTX-2.5 DFR: novos pipelines suportam geração com slots de quadro-chave e refinamento espacial e temporal combinável. (#14567)
  • Cosmos 3: Suporte SeaCache e eliminação de ruído mista W8A8/W8A16 para pontos de verificação ModelOpt FP8. (#14663, #14664)
  • Difusores modulares: Wan 2.2 VACE ganha blocos modulares e o carregamento de caminhos locais existentes evita downloads de peso desnecessários. (#14432, #14797)
  • Mais carregadores de arquivo único: suporte para Krea 2 e MiniMax-H3. (#14914, #14839)
  • Testes: removemos o conjunto de testes monolítico test_pipelines_common.py para estabelecer mais modularidade e implementação transparente de testes. Consulte https://github.com/huggingface/diffusers/pull/14669/ para mais detalhes.

Descontinuações e compatibilidade

🚨 O suporte ONNX está obsoleto; use fluxos de trabalho Optimum para ONNX Runtime. (#14658)

Os APIs anteriormente obsoletos foram removidos, incluindo os aliases LuminaText2ImgPipeline e Lumina2Text2ImgPipeline. Use LuminaPipeline e Lumina2Pipeline. Integrações mais antigas devem revisar os caminhos de código removidos antes de atualizar.

Obrigado a todos que contribuíram para este lançamento!
