Fundição em camadas

PyTorch suporta torch.float8_e4m3fn e torch.float8_e5m2 como armazenamento de peso dtypes, mas eles não podem ser usados para computação em muitos dispositivos devido ao suporte de kernel não implementado. Isso é conhecido como fundição de peso em camadas. Isso pode reduzir potencialmente os requisitos de VRAM de um modelo em 50%.   <detalhes>

### Descarregamento de grupo
O descarregamento de grupo é o meio termo entre o descarregamento sequencial e de modelo. Ele funciona descarregando grupos de camadas internas (`torch.nn.ModuleList` ou `torch.nn.Sequential`), que usa menos memória do que o descarregamento em nível de modelo. Também é mais rápido que o descarregamento em nível sequencial porque o número de sincronizações de dispositivos é reduzido. 
Em dispositivos CUDA, também temos a opção de habilitar o uso de pré-busca de camada com [CUDA Streams](https://pytorch.org/docs/stable/generated/torch.cuda.Stream.html). A próxima camada a ser executada é carregada no dispositivo acelerador enquanto a camada atual está sendo executada, o que torna a inferência substancialmente mais rápida, ao mesmo tempo que mantém os requisitos de VRAM muito baixos. Com isso, introduzimos a ideia de sobreposição de computação com transferência de dados.
Uma coisa a notar é que o uso de fluxos CUDA pode causar um aumento considerável no uso de CPU RAM. Certifique-se de que a CPU RAM disponível seja 2 vezes o tamanho do modelo se você optar por configurar `use_stream=True`. Você pode reduzir o uso de RAM da CPU configurando `low_cpu_mem_usage=True`. Isso deve limitar a RAM da CPU usada para ser aproximadamente igual ao tamanho do modelo, mas introduzirá uma ligeira latência no processo de inferência.  
Você também pode usar `record_stream=True` ao usar `use_stream=True` para obter mais acelerações às custas de um uso de memória ligeiramente aumentado.

from diffusers.utils import export_to_video

	onload_device=onload_device, 
	offload_device=offload_device, 
	offload_type="leaf_level", 
	use_stream=True
)

    "The panda's fluffy paws strum a miniature acoustic guitar, producing soft, melodic tunes. Nearby, a few other "

)
