Mudanças notáveis

Removido o executor de navegação legado

O sinalizador --legacy-navigation no CLI, a função legacyNavigation() no nó API e a caixa de seleção "Navegação legada" no painel DevTools foram todos removidos.

Novos artefatos DevtoolsLog e Trace

Para auditorias customizadas, os artefatos devtoolsLogs['defaultPass'] e traces['defaultPass'] foram descontinuados em favor de DevtoolsLog e Trace. Veja nossos documentos de plugins para ver exemplos de uso. devtoolsLogs e traces ainda existem para fins de compatibilidade, mas serão removidos em uma versão futura.
