#d2v0.7.0

Recursos 🚀

  • Ícones:
    • as conexões podem incluir ícones #12
  • Sintaxe:
    • suspend/unsuspend para definir modelos e instanciá-los #2394
  • Globos:
    • suporte para filtragem de bordas com base nas propriedades dos nós terminais (por exemplo, &src.style.fill: blue) #2395
    • Filtro level implementado #2473
  • Renderizar:
    • markdown, látex e código podem ser usados como rótulos de objetos #2204
    • shape: c4-person para renderizar a forma de uma pessoa como o modelo C4 prescreve #2397
  • Ícones:
    • border-radius deve funcionar no ícone #2409
  • Diversos:
    • As legendas dos diagramas são implementadas #2416

Melhorias 🧹

-CLI: - Suporte ao comando validate. #2415 - O modo Watch ignora arquivos de backup (por exemplo, arquivos criados por determinados editores como Helix). #2131 - Suporte para bandeira --omit-version. #2377 - A caixa é ignorada para nomes de plugins #2486

  • Compilador:
    • links podem ser configurados para o caminho raiz, por ex. /xyz. #2357
    • Ao importar um arquivo, tente resolver primeiro as substituições no escopo do arquivo importado #2482
    • validar paradas de cores gradientes. #2492
  • Analisador:
    • impõe o comprimento máximo da chave. É quase certamente um erro se um ID for muito longo, por ex. citações faltantes #2465
  • Renderizar:
    • preenchimento horizontal adicionado para etiquetas de conexão #2461

Correções de bugs ⛑️

  • Compilador:
    • corrige o pânico quando o valor da forma sql_shape tinha letras mistas #2349
    • corrige o pânico ao importar de um arquivo com substituições de spread em vars #2427
    • corrige suporte para center em d2-config #2360
    • corrige o pânico quando linhas de comentários aparecem em arrays #2378
    • corrige inconsistências quando objetos estavam entre aspas duplas #2390
    • corrige globs que não se aplicam a substituições de spread #2426
    • corrige o pânico quando as classes foram misturadas com camadas incorretamente #2448
    • corrige o pânico quando cores gradientes são usadas no modo de esboço #2481
    • corrige o pânico usando filtros de e comercial glob com valores compostos #2489
    • corrige o filtro de folha comercial quando usado com importações #2494
  • Formatador:
    • corrige substituições entre aspas entre texto #2462 -CLI:
    • buscar e renderizar imagens remotas do tipo MIME octet-stream corretamente #2370
  • Composição:
    • cenários/etapas de importação de spread não estavam sendo herdados corretamente #2460
    • os campos importados não estavam se fundindo com os campos/bordas atuais #2464
  • Remarcação:
    • corrige substituições var aninhadas que não funcionam #2456

Para obter as alterações mais recentes do d2.js, consulte changelog separado.
