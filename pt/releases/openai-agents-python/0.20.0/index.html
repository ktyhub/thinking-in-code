openai-agentes-python v0.20.0

Principais mudanças

A versão 0.20.0 é uma versão secundária porque altera o modelo padrão implícito e inclui uma migração de dependência MCP potencialmente disruptiva para aplicativos com transportes HTTP locais customizados. O MCP v1 permanece com suporte e os aplicativos afetados podem migrar para httpx2 ou fixar mcp<2.

Destaques:

  • O modelo padrão agora é gpt-5.6-luna; modelos explícitos, substituições em nível de execução e OPENAI_DEFAULT_MODEL continuam a ter precedência.
  • As conexões MCP locais suportam MCP Python SDK v1 e v2 em transportes stdio, SSE e Streamable HTTP.
  • Os aplicativos que usam autenticação HTTP MCP personalizada ou fábricas client devem usar os tipos HTTP pertencentes à versão principal do MCP instalada ou ao pino mcp<2.
  • RunState.add_input() pode preparar entradas duráveis ​​do usuário antes de uma chamada de modelo retomada, com proteção, persistência e suporte de serialização.
  • A validação de montagem em sandbox adiciona confirmações explícitas de exposição de credenciais e preserva contratos de erro editados sem serializar a autoridade de credencial.
  • A transcrição de entrada em tempo real suporta as configurações de transcrição GA para gpt-live-transcribe, gpt-transcribe e gpt-realtime-whisper.
