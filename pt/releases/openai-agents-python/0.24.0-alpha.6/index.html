#Instale a pré-visualização

Use CPython 3.10–3.14 padrão em um ambiente virtual. Essas rodas incluem o tempo de execução nativo; nenhum conjunto de ferramentas Rust ou compilação de código-fonte é necessário. Esta visualização é distribuída por meio de versões GitHub, não por PyPI.

Execute o comando para sua plataforma:

Linux x86_64 (glibc 2.39 ou mais recente)

python -m pip install "https://github.com/openai/openai-agents-python/releases/download/v0.24.0-alpha.6/openai_agents-0.24.0a6-cp310-abi3-manylinux_2_39_x86_64.whl"

macOS 11 ou mais recente no Apple Silicon

python -m pip install "https://github.com/openai/openai-agents-python/releases/download/v0.24.0-alpha.6/openai_agents-0.24.0a6-cp310-abi3-macosx_11_0_arm64.whl"

Windows x64

python -m pip install "https://github.com/openai/openai-agents-python/releases/download/v0.24.0-alpha.6/openai_agents-0.24.0a6-cp310-abi3-win_amd64.whl"

As rodas não são fornecidas para Macs Intel, ARM Linux, ARM Windows, Alpine/musl, PyPy ou Python de thread livre. Os nomes de arquivo cp310-abi3 também suportam o padrão CPython 3.11 – 3.14.

Verifique a versão instalada e o módulo nativo:

python -c "from importlib.metadata import version; import agents._native; print(version('openai-agents'))"

Espere 0.24.0-alpha.6 ou sua grafia equivalente na embalagem Python, 0.24.0a6. SHA256SUMS contém somas de verificação para todas as três rodas.

#Release notes

Mudanças desde 0.24.0-alpha.5. Esta visualização expande o controle de conversação, recuperação de estado e políticas de ferramentas, e inclui alterações públicas do API.

Adicionado

  • Controle de trabalhos submetidos através de um Turn capturado, com get_result(), events() passivo, tratamento manual de solicitações, direcionamento e cancelamento. Enfileirar avisos com Session.submit(..., if_busy="queue") ou direcionar a curva ativa com if_busy="steer".
  • Adicione LocalStorage para reabrir conversas de um perfil local e estender a captura e recuperação portátil do SessionState. Adicione garfos ociosos, resumos de compactação fornecidos pelo chamador e verificações de suporte a recursos e prontidão de pontos de verificação. Os perfis LocalStorage não podem exportar pontos de verificação portáteis.
  • Adicione NativeOutput para saída estrita nativa e PromptedOutput para JSON validado em Python. O max_retries opcional executa correções limitadas sem ferramentas ou repetição da tarefa. LocalStorage requer max_retries=0.
  • Lidar com solicitações de ferramentas manuais em tempo real e retomar solicitações pendentes suportadas em pontos de verificação. Adicione recuperação experimental de trabalho externo por meio do agents.experimental.deferred e de um adaptador MCP Tasks opcional.
  • Selecione ferramentas para cada etapa de envio ou modelo dentro das permissões de abertura da Sessão. Adicione pesquisa nativa na web, listas de verificação de filhos nativos e metas nativas para sessões de armazenamento local.
  • Validar anotações de retorno da ferramenta Python e adicionar políticas de ferramenta para inspecionar argumentos e resultados. Amplie o suporte nativo ao MCP com substituição de argumentos, transformações de resultados e formulários gerenciados por aplicativos e interações de URL em caminhos HTTP, stdio e modelo WebSocket suportados.
  • Adicione NetworkPolicy para comandos nativos em executores Linux e macOS suportados, sujeito à rede de cada plataforma e aos limites de soquete Unix. Gerencie a vida útil do executor remoto através de um Environment fornecido ao abrir uma Sessão ou executar um Agente.
  • Habilite aprovações de filhos nativos e solicitações de formulário com NativeAgents(interactions=True). As crianças continuam a compartilhar as ferramentas e o contexto de aplicação da Sessão.
  • Configure a exportação nativa do OpenTelemetry e inspecione as observações digitadas. NativeError agora expõe códigos de status de provedor disponíveis, códigos de erro, IDs de solicitação e categorias de falha.
  • Teste sessões SDK reais e ferramentas Python em relação a respostas de script locais com agents.testing.ScriptedResponses, sem modelo ao vivo ou chave API.

Mudanças no API

  • Use Agent.run() ou Agent.run_sync() para chamadas únicas; os aliases redundantes do Runner foram removidos.
  • Substitua Turn.wait() e Session.wait() por Turn.get_result() no Turn capturado.
  • Substitua Session.interrupt() por Turn.cancel() para um Turno raiz ou Session.cancel_all() para toda a Sessão.
  • Renomeie Subagent.submit() para Subagent.start(). Unifique retornos de chamada e ferramentas manuais do Python no FunctionTool; remova a declaração ManualTool separada.
  • As declarações do agente são imutáveis. Crie um novo agente para alterar os padrões, use with_output_type() para uma variante de tipo de saída ou use atualizações de sessão ociosa suportadas para uma conversa aberta.
  • A seleção de ferramentas e as atualizações da Sessão não podem expandir as permissões capturadas quando a Sessão foi aberta. As sessões restauradas usam ferramentas, credenciais e políticas de aplicativos atuais.

Corrigido

  • Mantenha o resultado de cada turno capturado estável em direção aceita, continuações nativas e envios posteriores. Preserve pontos de verificação manuais únicos, respostas de interação correspondentes e estado de reparo de saída em todos os limites de salvamento e restauração suportados.
  • Melhore o cancelamento de filhos nativos e a limpeza de sessões. Interrompa o trabalho nativo quando as políticas de resultados expirarem e preserve os motivos de falha da política ao relatar resultados raiz e secundários.
  • Rejeite envelopes de resultados da ferramenta Python malformados e preserve erros do servidor por meio de transformações de resultados MCP. Suporta formulários de extensão OpenAI aninhados e exportação de telemetria HTTP com certificados client.

Documentação e exemplos

  • Mova a fonte de visualização para o repositório público. Refocalize as orientações de instalação em rodas pré-construídas e mova as instruções de construção do SDK para CONTRIBUTING.md.
  • Adicione exemplos para aplicativos de navegador, streaming AG-UI, trabalhos adiados, avaliação, observabilidade e tarefas comuns de aplicativos. Remova os guias de migração da documentação de visualização.
