#vllm v0.26.0

#vLLM v0.26.0 Release Notes

Destaques

Esta versão apresenta 411 commits de 212 colaboradores (61 novos)!

  • Nova família de modelos Inkling com uma pilha de suporte completa: modelagem básica (#48799), suporte a gráficos CUDA por partes (#48822), atenção relativa Hopper FA4 (#48858), decodificação especulativa MTP=1 (#48869), LoRA (#48884) e quantização ModelOpt NVFP4 padrão (#48990).
  • Aumento de desempenho do DeepSeek-V4 entre fornecedores: um kernel de roteamento especializado (2.94% E2E TPOT, #48660), fused_topk_bias (kernel 1.5–2x, #47463) e remoção redundante de repetição/cópia (1.8% E2E TPOT, #48137), além de compressor ROCm de dois estágios para pré-preenchimento de HCA (#47718), esparso otimizações de decodificação/preenchimento (#48519, #48788, #46275) e decodificação especulativa DSpark em AMD (#47419) e XPU (#47677).
  • fp32 lm_head para modelos de geração via head_dtype (#48390), estendido para o caminho LoRA (#48525) e com um caminho rápido ROCm torch.mm (#48688), melhorando a precisão dos cabeçotes de geração.
  • Backends de atenção flexíveis: o backend de atenção agora pode ser selecionado por grupo de cache KV (#48012), e o suporte a janelas deslizantes agora é um recurso de backend explícito (#48011) — melhorando o suporte para modelos híbridos.
  • Descarregamento de KV e armazenamento secundário em camadas amadureceram substancialmente: métricas de transferência (#45958, #47666, #47679), manipulação de eventos de propriedade da camada (#46544, #47923), camada secundária de armazenamento de objetos com identidade de carga de trabalho (#47063, #47274, #48150), camadas com reconhecimento de réplica de DP (#47987) e Conectores de cache do codificador (EC), incluindo descarregamento de CPU (#42433, #47423).
  • O front-end Rust ganhou vídeo multimodal (#47959) e áudio (#48554), um analisador de ferramenta Seed-OSS (#47741) e uma porta vllm-bench nativa (#48107).
  • Transformers 5.13.0 (#47867) com mais modelos migrados para o back-end de modelagem de Transformers: Olmo/Olmo2 (#48100), MistralLarge3 (#48153) e HunyuanVL (#47872).

Suporte ao modelo

  • Novos modelos: família Inkling (#48799, #48822, #48858, #48869, #48884, #48990), BertForMaskedLM (#48463), RobertaForTokenClassification / XLMRobertaForTokenClassification (#47991), incorporação de n-gram LongCat-Flash-Lite (#47857), Cosmos3 Edge Reasoner (#48291) e registro Cosmos3-Super (#48211), TranslateGemma-12b-it (#41599).
  • Migrações de backend de transformadores: Olmo/Olmo2 (#48100), MistralLarge3 para AutoWeightsLoader (#48153), processador de transformadores nativos HunyuanVL para transformadores 5.13 (#47872).
  • GLM5.2: migre o suporte de sequência paralela do MoE para o caminho não compilado pela tocha (#47881).
  • LoRA: FlashInfer MoE LoRA para modelos BF16 (#48632), LoRA para torre/conector em LlavaNextVideo (#48594), fp32 lm_head no caminho LoRA (#48525), TrtLlmLoRAExperts otimizado (#48759).
  • Multimodal: fallback automático para paralelismo de dados ViT quando TP não está disponível (#49046).
  • Correções: pontuações de agrupamento corretas para pré-preenchimento fragmentado em torch.compile (#48901).

Núcleo do motor

  • fp32 lm_head para modelos de geração via head_dtype (#48390); menos memória para capturar grandes tamanhos de gráficos CUDA (#48483); persistência opcional e reutilização do resultado do perfil de memória entre inicializações (#47388); carregamento aprimorado do InstantTensor (#46868).
  • Atenção: selecione um backend de atenção diferente por grupo de cache KV (#48012); janela deslizante como um recurso backend explícito (#48011); Refatoração do layout do cache KV, empacotando K/V no conteúdo dim nos back-ends (#44455); PCP de lote virtual MRV2 para MLA (#46570).
  • Decodificação especulativa: atualização de peso do rascunho em tempo de execução (#46725), híbrido (SWA + atenção total) redatores DFlash (#47914), suporte SWA para qwen-eagle3 (#47568), modelo de rascunho Gemma4-12B DSpark (#47216), DSv4 DSpark em AMD (#47419), kv_cache_dtype separado para speculative_config (#48787).
  • Descarregamento de KV: métricas básicas de descarregamento (#45958), divisão do uso do cache da CPU em medidores de leitura/gravação (#47666) e atraso de pesquisa de camadas em histogramas sincronizados/assíncronos (#47679), manipulação de eventos de propriedade da camada e eventos BlockStored (#46544, #47923), camada secundária de armazenamento de objetos com identidade de carga de trabalho (#47063, #47274, #48150), camadas com reconhecimento de réplica DP (#47987), configuração blocks_per_chunk para grupos KV heterogêneos (#48878), vars de ambiente de host/porta padrão P2P (#47636).
  • Cache: acerto parcial de cache de prefixo para modelos híbridos (#46384), retenção seletiva de cache híbrido (#47782), blocos reutilizados de cache de prefixo de relatório no modo de relatório completo (#45261).
  • Raciocínio: otimize o TPOT para pensar no orçamento quando usado com decodificação especulativa (#46662).
  • RLHF: abstrações de envio de treinador com estado (#48042).
  • Correções: vazamento de memória do host de new_block_ids não drenado (#44490), DSv3.2 + MTP + precisão de sequência paralela (#48036).

Hardware e desempenho

  • DeepSeek-V4: kernel de roteamento especializado (2.94% E2E TPOT, #48660), fused_topk_bias 1.5 –2x (#47463), remoção redundante de repetição/cópia (1.8% TPOT, #48137).
  • GEMMs de roteador MoE: roteador BF16x3 GEMM (#47973), roteador FP32 GEMV (#48335), roteador genérico CuteDSL LL BF16 GEMM (#42562); Kernel modular TRTLLM BF16 MoE (#45182); escreva FlashInfer combine na saída final (#47156).
  • Qwen: fundir mais RMSNorm + redução total em Qwen3.5 (#46998), substituir MoE redução total por dispersão reduzida (#47006), otimização Qwen3.5 H20 (#48350), expandir a cobertura de aquecimento do Triton (#47546).
  • MLA: caminho MHA denso para sequências curtas de MLA esparsas (#47327); Indexador de decodificação de contexto longo MiniMax-M3 em sm100 (#48582).
  • Kernels: kernel CUDA para ReLUSquaredActivation / relu^2 (#39058), registro lento do kernel Helion (#48264), vetorizar _copy_mamba_state_block para uint64 (#48110), parar de upcasting logits para fp32 no sampler (#48641).
  • ROCm: caminho rápido fp32 head_dtype torch.mm (#48688), kernel de compressor de dois estágios DSv4 (#47718), otimizações de decodificação/pré-preenchimento esparsas (#48519, #48788, #46275), heurística de divisão KV MLA esparsa DSv3.2 (#46832) e modo de gráfico MTP CUDA (#45149), MXFP8 GEMM para MiniMax-M3 (#46117), atenção de página esparsa AITER + decodificação de especificações para MiniMax-M3 (#47287, #47984), norma QK fundida MiniMax-M2 + redução total via AITER (#44849), kernel linear HybridW4A16 (#40977), Qwen3-30B-A3B Fusão de tempo de execução QK-Norm+RoPE+KV (#42749).
  • XPU: kernels invariantes em lote (#41934), suporte a layout HND KV (#47975), decodificação de especificação DSpark para DSv4 (#47677), publicação de imagens noturnas/de lançamento (#47880, #48126).
  • CPU: decodificação especulativa DFlash para modelos GDN em CPU (#46090), topologia s390x NUMA (#40714), construções nativas de roda de CPU macOS arm64 (#48289); Otimização da função matemática do POWER VSX (#47321) e versões do IBM Power docker usando rodas pré-construídas (#46017).
  • Fusão distribuída: FlashInfer MNNVL fusão quant RMS totalmente reduzida (#48064).
  • Construção/ajuste automático: construções de imagem arm64 Blackwell SM10x/SM110 (#48041); pule o ajuste automático CuTeDSL fp4_gemm por padrão (#48268).

Servido e distribuído em grande escala

  • Decode Context Parallel (DCP): suporte de atenção híbrida (#40996), DCP + Eagle para backends Tokenspeed MLA (#48180).
  • Desagregação PD: pré-preenchimento paralelo de pipeline NIXL no modo push (#45880).
  • Conectores de cache do codificador: parâmetros de transferência EC (#42433) e conector EC de descarregamento de CPU (#47423).

Quantização

  • Humming w[2-7]a[4,8] inferência somente de peso com tensores comprimidos (#46390); quantização int4 para backend de emulação MoE (#48451); Quant linear somente de peso INT2 XPU (#47521).
  • NVFP4/MXFP4: quantização MoE online nvfp4_per_token (#48538), quantização CuTe-DSL FlashInfer MXFP4 (#48417); memória de pico limitada ao reembalar pesos MoE FP4 para Marlin (#47851) e para carregamento de peso NVFP4 MoE (#46276).
  • MLA: suporte kv_cache_dtype_skip_layers (#47309).
  • ROCm: kernel linear HybridW4A16 (#40977).

API e interface

  • Frontend Rust: vídeo multimodal (#47959) e áudio (#48554), analisador de ferramenta Seed-OSS (#47741), porta vllm-bench nativa (#48107), manipulação de continue_final_message com renderizador sentinela (#47844).
  • Compatibilidade OpenAI: bad_words em /v1/completions (#46793), expor logprob_token_ids em endpoints OpenAI Python (#43463), parâmetro include_reasoning para modelos não Harmony (#44301), preencher num_cache_creation_tokens em respostas de mensagens (#48535).
  • Estrutura de plug-ins de endpoint (#47454); /abort_requests no roteador RLHF dev API (#47173); Back-end de decodificação de vídeo Deepstream (#42424); sobrepõe o pré-processamento e a computação para agrupar modelos em inferência offline (#47699).
  • UX: inteiros legíveis por humanos para mais argumentos CLI (#47608), barra de progresso de compilação CuTeDSL (#48881), escopo/anotações de configuração do perfilador de GPU expandido (#37524), código de saída do trabalhador de log quando um processo morre inesperadamente (#38641).
  • Estabilidade/correção: lidar com falhas de compilação gramatical sem travar o mecanismo (#47312), corrigir colisão de token-string logprobs de espaços SentencePiece (#48674).

Segurança

  • Substitua o diskcache para eliminar a desserialização pickle (#44549).
  • Correção de uma corrida simultânea esparsa e invariante que contornou a correção de CVE (#48583).
  • Adicionar validação de limites de recursos para endpoints de renderização (#47260); limpar caminhos de arquivos do servidor a partir de respostas de erro de validação (#46415); vincula a lista de prompts de conclusão para evitar a distribuição ilimitada do mecanismo (#47845); guarde a compilação regex do lm-format-enforcer com um tempo limite (#47595).

Dependências

  • Transformadores 5.13.0 (#47867), FlashInfer 0.6.14 (#47669), NIXL 1.3.1 (#47559), inferência de tpu v0.24.0 (#47835), nvidia-cutlass-dsl 4.6.0 (#47442), vllm_xpu_kernels v0.1.11.1 (#48942).
  • FlashAttention 3 fixado no commit ABI estável da tocha (#47995); Compilação FlashMLA estável para ABI (#48174).

Depreciações e remoções

  • Modelos removidos: TeleChat (#47989), Persimmon e Fuyu (#48096).
