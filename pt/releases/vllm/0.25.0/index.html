#vllm v0.25.0

#vLLM v0.25.0 Release Notes

Destaques

Esta versão apresenta 558 commits de 232 colaboradores (64 novos)!

  • Model Runner V2 agora é o padrão para todos os modelos densos (#44443). Com base no suporte ao modelo quantizado da versão anterior, MRv2 agora é o caminho de execução padrão, com novo suporte para EVS (#46535), embeddings em tempo real (#46762), cache de prefixo para modelos híbridos Mamba (#42406), atenção bidirecional com prefixo multimodal (#46942) e decodificação especulativa dinâmica compatível com gráficos CUDA completos (#45953).
  • PagedAttention foi removido (#47361). A implementação de atenção legada foi excluída agora que os back-ends V1/MRv2 são o caminho padrão.
  • O back-end de modelagem do Transformers agora é tão rápido quanto o vLLM nativo (#47187) e ganhou suporte FP8 MoE (#46820), gráfico CUDA + correções de escala incorporadas (#48010) e migração de GPTBigCode/Starcoder2 (#30966) e RoBERTa (#47452).
  • Novos modelos: LLaVA-OneVision-2 (#44785), Unlimited OCR (#46564, #47102), MOSS-Transcribe-Diarize (#47729), openai/privacy-filter (#41026) e Hy3 (#47192). GLM-5 / DeepSeek-V3.2 pousou no zoológico modelo (#46808) com ajuste GLM-5.2, e MiniMax-M3 ganhou paralelismo de pipeline (#45810) e suporte NVFP4 (#46756).
  • Novo mecanismo de análise de streaming (#46610) — uma estrutura unificada de análise de chamada de ferramenta/raciocínio, com um novo analisador Kimi k2.5/k2.6/k2.7 e portas de seed_oss (#46314) e DeepSeek V4 (#45877). O front-end Rust continua a amadurecer com HTTPS/mTLS (#45890), um supervisor DP (#47076) e rotas de controle de perfil (#46306).
  • Decodificação especulativa universal para vocabulários heterogêneos (TLI) (#38174), além dos novos redatores DSpark (#46995) e DFlash (#46770, #46853).

Suporte ao modelo

  • Novos modelos: LLaVA-OneVision-2 (#44785), Unlimited OCR (#46564) com backend Triton R-SWA (#47102), MOSS-Transcribe-Diarize (#47729), openai/privacy-filter (#41026), Hy3 com sufixo de token e suporte a array de esquema JSON (#47192).
  • Família GLM-5: GLM-5 / DeepSeek-V3.2 adicionado ao zoológico modelo (#46808), porta GLM-5.2 FP32 (#47410), correção de norma pós-final GLM MTP (#47448), correção de inicialização GLM4V (#47155).
  • MiniMax-M3: paralelismo de pipeline (#45810), análise de raciocínio de streaming (#45718) e tok_sparse_select de MSA substituindo kernels Triton (#47502).
  • Back-end de Transformers: agora tão rápido quanto vLLM nativo (#47187), correção FP8 MoE (#46820), dimensionamento incorporado + correção de gráfico CUDA (#48010), migração GPTBigCode/Starcoder2 (#30966) e RoBERTa (#47452), correção M-RoPE mm_token_type_ids (#46552), correção lm_head.bias de incorporação vinculada (#46835).
  • Voxtral: migrou para áudio 1.11.5 comum mistral API (#46705) e correção de travamento de feedback de token em tempo real (#44461).
  • Família Gemma: correções de atenção de janela deslizante/FA4 Gemma4 (#47217, #47332), correção quant_config Gemma4 MTP (#47091); Paralelismo do tensor DiffusionGemma (#45719) e semântica da janela de estabilidade HF (#45965).
  • Outras correções: LoRA de backbone de linguagem MiniCPM-V 4.6 (#46740) e correção de grade de espaço reservado (#45918), dimensionamento de janela deslizante Whisper em pool (#47071, #47437), correção de falha de ponto de verificação Mamba/Mamba2 sem architectures (#46037), correções de tamanho oculto e estado oculto auxiliar DeepSeek-V2 (#46986, #46973).

Núcleo do motor

  • Model Runner V2: padrão para todos os modelos densos (#44443); EVS (#46535), embeddings em tempo real (#46762), cache de prefixo híbrido Mamba (#42406), atenção bidirecional de prefixo multimodal (#46942), aquecimento de atenção cruzada/correções de tabela de blocos (#46753, #47308), correção de falha do Mamba2 (#47428), agendamento de contabilidade de slot (#46974), limpeza de referência de modelo no desligamento (#47483), memória limitada para solicitações de grandes logprobs (#46746).
  • Decodificação especulativa: decodificação de especificação universal para vocabulários heterogêneos (TLI) (#38174); Suporte ao ponto de verificação do redator DSpark + especuladores (#46995, #47093); Seleção de backend DFlash (#46770), fusão RMSNorm por camada (#46761), suporte de CPU (#44029), SWA+DFlash para MiMo (#46104), redator Laguna XS.2.1 (#46853); MTP para modelos híbridos de Bailing (#44880); verificação de bloco para amostragem de rejeição (#46781); comunicação TP reduzida para tokens de rascunho (#46448).
  • Modo de suspensão: abstração de back-end do modo de suspensão conectável (RFC #34303, #44074) com sinalizadores de capacidade independentes do comunicador (#47243).
  • Atenção: Restrição de tamanho de bloco FlashAttention removida para modelos híbridos (#36701), back-end FLASH_ATTN_MLA_SPARSE Hopper sparse-MLA (#46189), cache DCP + FP8 KV na decodificação MLA (#44044), kernels de decodificação XQA (#43232).
  • Descarregamento de KV: encanamento métrico de camadas (#45959), solicitação de correção do ciclo de vida (#46284), pesquisa em lote em C (#46713), enum LookupResult (#46363).
  • Diversos: VLLM_GPU_SYNC_CHECK env var (#44800), infraestrutura de semáforo VRAM (#44465), pular destokenização na pesquisa de feixe online (#46422), várias correções de overflow int32 em kernels de amostragem/atenção (#46560, #47383, #47671).

Hardware e desempenho

  • GLM-5.2 / DeepSeek: kernel fused_indexer_q_rope_quant Triton (taxa de transferência 1.9 – 3.3% E2E) (# 46862), redução total de dispersão MoE (3.1 – 3.2% E2E) (# 46635), fusão operacional para GLM5 / DSV3.2 (# 46876), token_to_req_indices cache para DSv4 (aceleração de kernel de 5 a 6x) (#47474), melhor kernel DSv4 MXFP8 (#47229), remoção de operação redundante (#47198, #46651).
  • NVIDIA/Blackwell: FlashInfer fundiu all-reduce ajustado para world_size=16 em GB300 (#46392), restaurou zero-init em escala swizzled NVFP4 para recuperar a taxa de transferência de decodificação Blackwell (#45739), infra-estrutura de aquecimento CuTeDSL/FA4-MLA (#46182), pular top-K cooperativo em SM120 (#47164), back-end B12x para não bloqueado MoEs (#43328).
  • Kernels: Helion fused_qk_norm_rope (#44010) e silu_and_mul_per_block_quant (#43994), Triton MLA logits workspace (#46819), otimização swap-AB para MoE fundido (#36559), fp32 moe_sum vetorizado suportando qualquer top-k (#46643), bloqueando eventos CUDA para evitar polling ocupado no bloqueio do driver (#47081).
  • AMD/ROCm: movido para tocha 2.11 ABI estável (#47128); AITER FlashAttention MLA back-end de pré-preenchimento ROCM_AITER_FA (#45033); especialista compartilhado fundido para GLM-4.5/6/7 (#44313) e MiniMax-M3 (#46474, #46545); Otimização AITER MoE para DeepSeek-V4 (#46122); Redução total personalizada do AITER no CudaCommunicator (#46065); Quantização INT3 para redução rápida (#45666).
  • Intel XPU: kernel linear W8A8 FP8 com quantificação multigranularidade (#43645), correção de precisão paralela de pipeline (#47253), gráfico CUDA de lote uniforme para FA2 (#46555), modelos de rota mm_prefix para atenção do Triton (#47688), C++ get_memory_info (#47134).
  • CPU: MoE não quantizado acelerado para AArch64 (#46353), correção de travamento do macOS/Apple Silicon via OpenMP (#46769) e correção de instalação quebrada (#47457), tensor compactado w8a8 int8 MoE (#42920), Mamba ShortConv (#35059), pré-preenchimento fragmentado + cache de prefixo para Qwen3.5 (#46202), gelu mais rápido via tanh AOR (#44639).
  • RISC-V: caminho RVV para W4A8 INT4 GEMM (#45269), BF16 em hardware VLEN=256 (#45243), pressão LMUL reduzida em INT4 LUT dequant (#47538). POWER: suporte fp16 no PowerPC (#46135).
  • Plataforma: get_memory_info independente de acelerador (#44825).

Servido e distribuído em grande escala

  • Paralelismo de sequência sem necessidade de DP, melhoria de rendimento 1.9 – 5.0% E2E (#47070).
  • Distribuído: memória simétrica NCCL estendida para AllGather e ReduceScatter (#46703), FlashInfer all-reduce padrões para MNNVL em nó único (#47219, #47589), back-end de tolerância a falhas para detectar falhas de pares all2all e evitar saída corrompida (#43637).
  • Paralelo de dados: acelerador de pré-preenchimentos com base no trabalho de pré-preenchimento local (#46532), rotação do desempate do balanceador de carga para evitar polarização do motor (#47420), supervisor DP por meio do frontend Rust (#47076), correção de travamento DP MTP (#40589).
  • Desagregação PD: implementação de camada secundária (#42285), conector Mooncake GDN (Qwen3.5) + suporte MLA (DeepSeek-V4-Flash) (#46807), suporte NIXL Mamba1 (#45019), fusão MultiConnector kv_transfer_params (#46777), campo de uso exposto para serviço desagregado (#42748).
  • DCP: suporte FlashInfer MLA (#43729), suporte FLASHINFER_MLA_SPARSE (#46076), correções de base de log LSE (#47079); Carga KV paralelizada Mooncake (#45971) e correção de pesquisa DCP>1 (#46855).
  • ROCm: DBO de alto rendimento estabilizado para DP+EP (#46990), EPLB para Quark OCP MXFP4 MoE (#47220).

Quantização

  • Inferência somente de peso quantizada por pacote de 2/3/5/6/7 bits (Humming) (#46389), quantização de cache KV Triton INT4 por cabeça de token (#40835).
  • NVFP4: desquantização de peso fundida com computação no kernel MoE MLP Triton (#44667), cache NVFP4 KV com janela deslizante de camadas saltadas (#42890), suporte MiniMax-M3 ModelOpt NVFP4 (#46756).
  • FP8: preenchimento de pesos para quantização online por bloco (#44763); descontinuada a antiga classe de quantização MoE on-line do FP8 (#44514).
  • Marlin: preenchimento de thread-tile estendido para MoE (WNA16 + FP8/MXFP8) (#45703), int8 agrupado WNA16 MoE (#47154); FlashInfer MXINT4 MoE para SiLU fechado (#46518).
  • Correções: regressão de seleção de esquema int-quant W8A8 (#46860), embeddings quantizados vinculados para ModelOpt Gemma4 (#45544), falha NVFP4 + MTP em Qwen3Next (#46316), precisão mista ModelOpt para configurações esparsas (#47318), CPU w4a8_int8 MoE path (#46739), erro acionável em incompatibilidade de tamanho de grupo/TP (#46230).

API e interface

  • Streaming Parser Engine (#46610): análise unificada de chamada de ferramenta/raciocínio com um novo analisador Kimi k2.5/k2.6/k2.7; portado seed_oss (#46314) e DeepSeek V4 (#45877).
  • Compatibilidade OpenAI: ferramentas de namespace API de respostas (#47024), campo metrics de tempo por solicitação em respostas de bate-papo/conclusões (#46768), compensações de token em endpoints de renderização (#44226), return_loss_mask para geração de dados de treinamento (#46846), HTTP 422 para URLs de imagem não processáveis ​​(#47165).
  • gpt-oss / Harmony: renderizador Harmony dedicado (#46800), process_eos() flush (#46437), recuperação de saída bruta em análise não terminal (#47062, #47379).
  • Frontend Rust: HTTPS estático e mTLS para HTTP e gRPC (#45890), supervisor DP (#47076), rotas de controle do profiler (#46306), parâmetro de amostragem repetition_detection (#46684), interface de analisador unificada/combinada (#46583), cópias reduzidas de tensor multimodal (#47581), além de muitas correções de analisador e validação.
  • Vídeo: TorchCodec adicionado como backend de decodificação de vídeo (#46609).
  • CLI/UX: Impressão TTFT e TPS em vllm chat (#46775), model_class_overrides para desenvolvimento/depuração (#47148).
  • Ferramentas/validação: muitas correções no analisador de ferramentas (Kimi K2 IDs #46344, PoolsideV1 #46486/#47311, argumentos não-ASCII #46308, reentrada thinking_token_budget #43757); rejeição de valores de configuração inválidos (#44070, #44002, #46612) e structured_outputs degenerado que trava o EngineCore (#45346).

Segurança

  • Impedir a negação de serviço OOM da bomba de descompressão de imagem (#47010).
  • Evite um loop infinito no split_audio com amostras de áudio NaN (#46463).
  • O tokenizer vinculado funciona quando um truncation_side explícito é definido (#47007).
  • Bloquear seleção de back-end de vídeo GPU em nível de solicitação (#47259).
  • Documente a interface gRPC como insegura, somente para uso privado (#45903).

Dependências

  • DeepGEMM atualizado para habilitar suporte SM120 (#47304), FlashAttention 3 construído contra o API estável da tocha (#46644), TLS de frontend Rust alterado de rustls para nativo-tls/OpenSSL (#46696).

  • Modelos removidos: Baichuan (#46362), Aquila (#46605), Grok (#46706), Tarsier / Tarsier2 (#47143), AyaVision / MusicFlamingo (#47263), Mantis (#46806).
