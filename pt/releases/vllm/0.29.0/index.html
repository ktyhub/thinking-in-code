#vllm v0.29.0

#v0.29.0

Destaques

Esta versão apresenta 594 commits de 277 colaboradores (91 novos)!

  • Model Runner V2 agora é o padrão para todos os modelos (#53183), completando a implementação que começou com modelos de pooling (#48290). MRV2 também ganhou perfil de memória gráfica CUDA para dimensionamento automático de cache KV (#53306), amostragem fragmentada em lote que corta a memória de logits por etapa em 1/TP (#50465), incorporações de prompt (#42963), especulação extract_hidden_states (#49811), envio de cudagraph COMPLETO acolchoado para decodificação uniforme sob decodificação de especificação (#53407) e salto de sincronização DP antes Pré-preenchimento de rascunho EAGLE/MTP (#53694). O MRV1 permanece em uso para alguns modelos ROCm e recursos que o MRV2 ainda não suporta.
  • Novos modelos: Hy4-preview, MoE ativo 770B/49B da Tencent com Gated DeepSeek Sparse Attention e MTP nativo (#54160); Qwen3.8-Flash-Next com BF16/FP8/NVFP4 e MTP (#53896); GraniteSWA e GraniteMoeSWA (#52706); NemotronH_Omni_Reasoning_V3 com MTP (#52929, #53121); Pontos de verificação Kimi K3 NVFP4 (#53132).
  • Desempenho de Kimi-K3 e DeepSeek V4: finalização MXFP4 top-k fundida na cauda latente K3 (cerca de 5% de latência E2E, #53152), preparação de metadados K3 Mamba em um lançamento Triton (aceleração de kernel 6.6-7.6x, #52388), GEMM de baixa latência Hopper ajustado (#54088) agora também despachado em SM100 (#53534) e usado para eh_proj (12.9-25.2% aceleração do kernel, #53942), GEMM-RS estendido para GEMM-AR (#53053), porta MLA mesclada na projeção QKV-A (#54015), K3 DCP com DSpark (#52188) e hits de cache de prefixo parcial DCP (#50493); DeepSeek V4 compartilhou especialistas fundidos em MegaMoE (#53040), largura adaptativa top-k re-aterrada (#52823), um kernel de fixação SwiGLU nativo para Humming MoE (#53685) e um back-end especialista FlashInfer moe_ep opcional (#49636).
  • Decodificação especulativa: estatísticas de aceitação por solicitação em respostas OpenAI API via --per-request-spec-decode-metrics (#48915), verificação adaptativa estendida para logprobs (#52242), SM100 MLA esparso para GLM-5.2 (#52783) e DeepSeek V4 em SM90 (#52795), rascunhos Qwen3-Omni DSpark (#52560), PLAMo3 EAGLE-3/DFlash (#54239) e carregamento DFlash2 do formato especulador (#53797).
  • Sincronização de peso RL: um novo back-end sharded_rdt P2P onde cada trabalhador puxa apenas sua fatia TP/EP sobre NIXL ou Ray Direct Transport (#43375), atualizações de peso IPC locais de classificação (#52497), atualizações esparsas de coordenadas de pontos de verificação por meio de carregadores de peso nativos (#50723, #53751) e carregamento especializado roteado para gpt-oss (#52209).
  • Cache de prefixo Mamba: pontos de verificação internos de pré-preenchimento proporcionam uma melhoria de TTFT de 9% a 25% (#52789); prefix_cache_retention_interval agora é um argumento CLI com padrão 0 (#52216), com retenção densa restaurada automaticamente para modelos híbridos usando EAGLE/MTP (#55760, #55861).
  • Novos padrões: FlashInfer all-reduce habilitado por padrão para grupos TP CUDA, desative com VLLM_ALLREDUCE_USE_FLASHINFER=0 (#52998); prefix-cache NONE_HASH é determinístico por padrão, então os usuários de cache KV distribuído não precisam mais fixar PYTHONHASHSEED (#51875); novos sinalizadores de controle de admissão --max-num-queued-reqs / --max-num-queued-tokens (#49445).
  • Alterações importantes: dez arquiteturas de modelo obsoletas removidas (#53608); FlexOlmo, Olmo3 e Hunyuan V1/VL migraram para o backend de modelagem de Transformers (#53615); Back-end do decodificador de vídeo PyAV removido (#54231); python -m vllm.entrypoints.openai.api_server foi descontinuado em favor de vllm serve (#52131); VLLM_TEST_FORCE_FP8_MARLIN (#52182) e VLLM_ROCM_USE_AITER_FP4_ASM_GEMM (#53141) removidos.

##: aviso: descontinuação do modelo Runner V1 Agora que o Model Runner V2 é usado por padrão, estamos considerando o Model Runner V1 obsoleto e visando v0.32 para sua remoção. Não pretendemos aceitar mais melhorias ou otimizações específicas do MRV1.

Alguns recursos ainda não são suportados no MRV2, mas estamos planejando que essas lacunas sejam eliminadas nas próximas 2 a 3 semanas. Isso inclui paralelismo de sequência, sobreposição de lote duplo, paralelismo elástico especializado, processadores logits personalizados e certos métodos de decodificação especulativos. Por enquanto, o vLLM ainda usará o MRV1 se algum desses recursos estiver configurado.

  • CLI e ferramentas: vllm launch executa as verificações de argumento de serviço (#52825), run_batch.py movido para fora da pasta openai (#53500) com sua nova tentativa de upload corrigida (#50588), vllm bench avisa sobre um cache de prefixo quente para execuções aleatórias (#53920) e restaura conjuntos de dados multimodais no back-end de taxa de transferência vllm (#52168), e a ferramenta de receitas vLLM ganhou recomendações de varredura e análise de alias (#53325, #53946).

Segurança

  • Comprimento cache_salt limitado a 1024 para evitar o esgotamento da CPU do agendador (#54353).
  • Mídia superdimensionada rejeitada antes do download completo (#51896); VLLM_MAX_AUDIO_CLIP_FILESIZE_MB aplicado em todos os caminhos de áudio (#53561).
  • Validação do comprimento do prompt do decodificador aplicada para processadores que ignoram a verificação (#46588); Desvio do limite do slot do decodificador PyNvVideoCodec corrigido (#52126).
  • api_key e hf_token editados dos logs de inicialização, fatores de cache de compilação e log de inicialização do frontend Rust (#52523, #53625, #53738).

Dependências

  • FlashInfer 0.6.18 (#54313), huggingface-hub 1.28.0 (#52797), inferência tpu v0.28.0 (#54020), NIXL 1.3.2 (#51777).
  • InstantTensor adicionado às dependências CUDA; o carregador não está habilitado por padrão (#52801). A restrição CuPy foi relaxada para excluir apenas 14.1.0 (#44284).
  • Imagem base ROCm: atualização ROCr/CLR (#53712), rocprofiler-sdk 1.3.2 (#53182), visualização TheRock 7.14 (#49925), pacotes de conectores LMCache (#51208).
  • XPU: vllm_xpu_kernels 0.1.14.1 (#54203), instalação UCX atualizada (#53817).
  • A compilação falha ao fechar quando a variante CUDA pré-compilada selecionada não está disponível (#52545).

Quebrando alterações e depreciações

  • Dez arquiteturas obsoletas removidas: Arctic, Chameleon, Cheers, Fairseq2Llama, FireRedLID, GritLM, HCXVision, MPT, os aliases RWForCausalLM e StableLMEpochForCausalLM e PrithviGeoSpatialMAE (substituído por Terratorch) (#53608).
  • FlexOlmo, Olmo3, Hunyuan V1 e Hunyuan VL agora são atendidos por meio do back-end de modelagem do Transformers (#53615).
  • Backend do decodificador de vídeo PyAV removido; use OpenCV ou Torchcodec (#54231).
  • python -m vllm.entrypoints.openai.api_server está obsoleto; use vllm serve (#52131).
  • O Model Runner V2 é o corredor padrão para todos os modelos (#53183).
  • Padrão prefix_cache_retention_interval alterado de denso para 0 para modelos SWA/SSM; o env var está obsoleto em favor do argumento (#52216).
  • FlashInfer all-reduce habilitado por padrão (#52998).
  • VLLM_TEST_FORCE_FP8_MARLIN removido em favor de --linear-backend / --moe-backend (#52182); VLLM_ROCM_USE_AITER_FP4_ASM_GEMM removido (#53141); --attention-config.use_prefill_decode_attention morto removido (#52557); outros parâmetros obsoletos foram limpos (#53559).
