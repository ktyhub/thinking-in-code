#FastGPT v4.16.0-beta2

📦 Guia de atualização

1. Limpe a configuração histórica do modelo do sistema

Esta versão começa a usar Schema estrito ao inicializar e salvar modelos de sistema. Strings numéricas, gradientes de preço em formato de string ou campos ausentes salvos em versões anteriores podem causar falha na verificação inicial. Após a atualização, execute primeiro o teste para visualizar a configuração do modelo que precisa ser processada; a simulação não modificará os dados nem atualizará o cache:

curl -X POST 'https://你的域名/api/admin/dataClean/cleanSystemModelConfigs' \
  -H 'Content-Type: application/json' \
  -H 'rootkey: 你的ROOT_KEY' \
  -d '{"dryRun":true}'

Após confirmar que não há dados no invalidSamples que requeiram processamento manual, realize a limpeza formal:

curl -X POST 'https://你的域名/api/admin/dataClean/cleanSystemModelConfigs' \
  -H 'Content-Type: application/json' \
  -H 'rootkey: 你的ROOT_KEY' \
  -d '{"dryRun":false}'

A limpeza converte strings numéricas legais em números, converte priceTiers como uma string em uma matriz e remove números opcionais ilegais. Números obrigatórios ilegais ou ausentes usam os valores padrão do sistema: maxContext/maxResponse/quoteMaxToken para LLM é 16000/16000/13000, defaultToken/maxToken para incorporação é 500/3000 e o preço é 0. functionCall permanece opcional e o weight ausente na incorporação é substituído por 0.

A execução formal grava dados de maneira uniforme e atualiza imediatamente o cache do modelo do sistema; o cache de tempo de execução é reconstruído mesmo se não houver registros para atualizar. A interface é segura para ser executada novamente; quando for executado novamente, wouldUpdate deverá ser 0. Os registros que não puderem passar pelo esquema completo do modelo atual não serão gravados e todos os detalhes serão retornados em invalidSamples.

🚀 Novo conteúdo

  1. A configuração do sistema da aplicação de workflow é movida para o painel de configuração independente na barra de ferramentas do lado esquerdo da tela, que será aberta automaticamente ao criar uma nova aplicação de workflow.
  2. A declaração de abertura suporta configuração independente de várias perguntas predefinidas e pode ser classificada arrastando e soltando.

⚙️ Otimização

  1. Reconstrua a página do canal de lançamento, exiba-a em grupos por canais nativos e canais de terceiros e exiba a quantidade configurada de cada canal.
  2. A atualização em lote do mercado de ferramentas suporta a exibição de alguns itens com falha, nova tentativa ou desinstalação individualmente e melhora a exibição de versões instaladas e status de atualização.
  3. O limite superior do número de aplicativos rápidos na página do portal é ajustado para 3, e as configurações históricas que excederam o limite superior são compatíveis.
  4. O analisador de PDF usa corte dinâmico de bordas em vez de corte fixo de bordas para evitar o corte do conteúdo real.

🐛 Correção

  1. Corrigido o problema de que os parâmetros dinâmicos da versão antiga da ferramenta HTTP de fluxo de trabalho não restauravam corretamente o método de entrada padrão.
  2. Corrigido o problema de que ao criar uma nova aplicação de fluxo de trabalho, os recursos internacionais não eram pré-carregados, fazendo com que a cópia da configuração inicial ficasse anormal.
  3. Corrigido o problema em que os parâmetros da ferramenta de fluxo de trabalho podiam ser renderizados repetidamente.
  4. Corrigido o problema em que as variáveis ​​de arquivo não podiam fazer upload de arquivos após o lançamento do aplicativo.
  5. Corrigido o problema de que o parâmetro de arquivo da ferramenta de fluxo de trabalho compartilhado não consegue fazer upload de arquivos.
  6. Corrigido um problema em que chaves de objeto S3 e nomes de arquivos contendo caracteres especiais, como espaços, %, #, ? e barras, podiam causar upload, análise, visualização ou download anormais.
  7. Corrigir o problema de que o modelo padrão do sistema não filtra informações confidenciais, de modo a evitar que a resposta da interface de inicialização do sistema retorne a chave do modelo API, endereço de solicitação e configuração interna.

🛠️ Otimização de código

  1. O arquivo de log de auditoria não será mais excluído, mas será transferido para o arquivo frio do S3.
  2. Adicione verificação e limpeza de dados para configuração administrativa.
  3. Cancele o SSR da conta/* página.
