MaxKB v2.10.8-lts

#Max KB v2.10.8-lts

Correções de segurança

■ Segurança (X-Pack): corrigida uma vulnerabilidade em que o endpoint de configuração de autenticação de login não editava campos confidenciais, expondo credenciais de aplicativos de login de terceiros (como DingTalk app_key, corp_id e app_secret) em texto simples, o que poderia levar ao controle do aplicativo corporativo.

Correções de bugs

■ Base de conhecimento: foi corrigido um problema em que caracteres especiais como , /, :, * e ? poderia ser inserido ao criar rapidamente um documento em branco.

■ Base de conhecimento: foi corrigido um problema em que usuários com apenas a função de administrador do espaço de trabalho eram redirecionados para a página de lista de agentes ao cli clicar em importar documento em uma base de conhecimento do Feishu.

■ Base de conhecimento: foi corrigido um problema em que títulos com o mesmo conteúdo, mas com níveis diferentes em um arquivo Markdown, eram reconhecidos incorretamente durante a segmentação.

■ Base de conhecimento: foi corrigido um problema em que a exclusão de um documento após carregá-lo em uma base de conhecimento geral por uma função personalizada retornava um erro indicando nenhuma permissão.

■ Base de conhecimento: corrigido um problema em que o nó de recuperação de tags de documento passava parâmetros de consulta ao recuperar as tags das bases de conhecimento selecionadas, fazendo com que o limite de comprimento fosse excedido quando havia muitas bases de conhecimento (#7199).

■ Base de conhecimento: foi corrigido um problema em que uma saída de lista de documentos vazia pela ferramenta de fonte de dados causava falha na gravação na base de conhecimento.

■ Agente: foi corrigido um problema em que o botão para gerar o prompt do sistema não era ativado automaticamente quando o modelo padrão era usado em um nó de conversação de IA.

■ Agente (X-Pack): Corrigimos um problema em que um usuário comum era solicitado sem permissão ao cli clicar em Salvar após criar um novo agente que referenciasse uma ferramenta compartilhada (#7360).

■ Agente: foi corrigido um problema em que o título da página não exibia o nome do agente após a atualização da página de conversa do agente.

■ Agente (X-Pack): corrigido um problema em que a lista de ferramentas compartilhadas exibia incorretamente itens de MCP e habilidades que deveriam ser filtrados ao adicionar um componente de ferramenta em um fluxo de trabalho (#7361).

■ Ferramenta compartilhada (X-Pack): foi corrigido um problema em que um usuário comum não conseguia chamar uma ferramenta compartilhada no tempo de execução do fluxo de trabalho após adicioná-la a uma base de conhecimento do fluxo de trabalho.

■ Gerenciamento de recursos (X-Pack): foi corrigido um problema em que o administrador do sistema não conseguia importar documentos para uma base de conhecimento de fluxo de trabalho no Gerenciamento de recursos.

■ Gerenciamento de recursos (X-Pack): foi corrigido um problema em que ferramentas compartilhadas que não tinham autorização de espaço de trabalho podiam ser adicionadas ao editar um agente em um espaço de trabalho no Gerenciamento de recursos.

■ Gerenciamento de recursos (X-Pack): foi corrigido um problema em que o administrador do sistema não conseguia fazer download do documento original de uma base de conhecimento e era solicitado sem permissão.

■ Gerenciamento de recursos (X-Pack): foi corrigido um problema em que o criador do documento ficava vazio quando o administrador do sistema criava um documento para uma base de conhecimento no Gerenciamento de recursos.

■ Gerenciamento de recursos (X-Pack): foi corrigido um problema em que o administrador do sistema não conseguia visualizar o histórico de lançamento de um agente.
