#orca v1.4.263 Lançamento anterior: 1.4.262 — Troca de bate-papo mais rápida, menor uso de memória e culpa.

Inicialização de bate-papo mais leve, Hermes no bate-papo e painéis laterais de extensão do navegador ✨

Reabra espaços de trabalho cheios de bate-papos com menos uso de memória e menos trabalho de inicialização. As interfaces de bate-papo restauradas são carregadas quando mostradas pela primeira vez, e o Orca não reescreve mais todas as conversas salvas na inicialização. Os bate-papos abertos mantêm os rascunhos e a posição de rolagem quando você retorna.

  • 💬 Continue as conversas do Hermes no bate-papo: Inicie o Hermes no menu Nova guia ou escolha Retomar no novo bate-papo em uma entrada do histórico da sessão para continuar uma conversa do terminal em seu espaço de trabalho e perfil originais.
  • 🌐 Mantenha as extensões ao lado da sua página: As extensões do Chrome que usam painéis laterais agora podem abrir em um painel redimensionável no navegador do Orca. Click botão da barra de ferramentas da extensão para usar seu painel durante a navegação; Os pop-ups de extensão também aceitam Colar, Copiar e Selecionar tudo.
  • 🖥️ Alcance seu trabalho remoto: As portas SSH gerenciadas agora têm um botão Avançar. No Windows, os projetos abertos por meio de uma letra de unidade WSL mapeada podem ser movidos para o host WSL de sua distribuição.
  • ⌨️ Manter a saída do terminal visível após uma reinicialização: No macOS e Linux, um terminal cujo shell parou pode restaurar sua saída salva com o novo prompt abaixo dele. O Windows mantém seu comportamento de restauração existente.

Destaques

  • Conectar Linear a partir da linha de comando: orca linear connect aceita uma chave API por meio de stdin e conecta o host de destino, incluindo um servidor headless. Cada host mantém sua própria conexão. As listas lineares de problemas e projetos agora retornam todos os resultados quando você omite --limit.
  • Configurar agentes no Windows: Os bate-papos de Claude e Codex oferecem Instalar quando o agente estiver faltando e, em seguida, Verificar novamente para detectar a instalação. orca agent installed também lista os agentes CLIs habilitados no host atual para scripts e configuração de inicialização.

Notas de compatibilidade e atualização

  • Hermes: O bate-papo requer Hermes 0.23.0 ou posterior na máquina que executa o espaço de trabalho. Importações muito longas mostram mensagens recentes enquanto Hermes retém a conversa completa. O chat não está disponível para espaços de trabalho SSH; um servidor Orca emparelhado suporta isso. O primeiro bate-papo após a parada do gateway Hermes pode demorar um minuto para começar.
  • Identidade do navegador: Nativo agora é o padrão, abordando o ciclo de verificação da Cloudflare visto com o padrão anterior. As escolhas de identidade explícitas são preservadas; altere o seu em Configurações → Navegador → Identidade do navegador.
  • Atualizações do telefone: As alterações na interface do telefone listadas abaixo exigem uma versão móvel correspondente. Esta atualização de desktop não atualiza aplicativos Android ou iOS.

Problemas conhecidos

  • Espaço de trabalho suspenso: A opção pode falhar quando outra guia nesse espaço de trabalho estiver executando um processo.
  • orca agent installed --worktree: Os erros de comando em SSH e espaços de trabalho de servidores emparelhados.
