#openhuman v0.63.9

A atualização de confiabilidade de lançamento

Esse conjunto de lançamentos fortalece o pipeline de envio e mantém o branch de lançamento em movimento suave – para que as compilações permaneçam ecológicas e a entrega rápida. 🎉

Destaques

Liberar sincronização de branch e resolução de conflitos 🔀

Mantivemos release em sintonia com main por meio de uma série de promoções, garantindo que o último trabalho acumulado chegue de forma limpa onde as construções de produção são cortadas.

Uma promoção também exigiu uma cuidadosa resolução de conflitos para preservar as versões de lançamento já cortadas e, ao mesmo tempo, apresentar o conjunto completo de alterações do main. (#5203, #5242, #5256) — Obrigado @M3gA-Mind!

Desbloqueio de lançamento do Linux AppImage 🐧

Os testes de fumaça de lançamento do desktop Linux estão de volta aos trilhos: uma falha de inicialização do AppImage no Ubuntu 23.10 + foi resolvida ajustando o comportamento sysctl do namespace do usuário usado durante o trabalho de lançamento, desbloqueando execuções de produção. (#5251) — Obrigado @M3gA-Mind!

Créditos do Colaborador

Obrigado a todos que contribuíram para este lançamento: @M3gA-Mind, @github-actions[bot].
