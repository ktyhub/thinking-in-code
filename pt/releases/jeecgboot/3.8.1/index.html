#JecgBoot v3.8.1

Registro de atualização

Lançou uma série de novidades; As funções da plataforma de aplicativos de IA são estáveis; suporta aplicativos de desktop Electron; Função OpenAPI baseada em autenticação AK e SK; a importação de usuários oferece suporte à importação de departamentos e funções; a geração de código suporta controles de registro associados, melhorias js e botões personalizados, etc.

Novos recursos
  • [Grande atualização] A função do módulo de aplicação de IA foi estabilizada e atingiu os padrões online.
  • [Novo recurso] Suporta empacotamento de aplicativos de desktop eletrônico, usando Vite + Vue3 + Electron para construir aplicativos de desktop cliente (suporta três plataformas principais: Windows, Linux e macOS)
  • [Nova função] "Função OpenAPI baseada em autenticação e autenticação AK e SK" para resolver as necessidades de API externo
  • [Novo recurso] A importação de usuários suporta a importação de departamentos e funções
  • [Novo recurso] Fornece modelo de gerador de código para a nova versão do uniapp
  • [Novos recursos] A geração de código suporta controles de registro associados, aprimoramento de js e métodos vazios de geração de botões personalizados;
  • Caixa de diálogo [AI] AI suporta terminal móvel
  • [Otimização] Suporta nova versão da lógica de login DingTalk
  • [Otimização] Uso simplificado de funções multilocatários
  • [Novo recurso] Fornece exemplos de AI OCR
  • Gerenciamento do meu departamento, permitindo adicionar e excluir subdepartamentos
  • Remova o código jsqlparse e migre-o para o minidao. A atualização não é mais afetada pela compatibilidade do jsqlparse.
  • [AI] Compatível com jdk21, para que o programa possa ser iniciado, mas avisa que a orquestração do processo de IA não pode ser usada
  • Processo [AI], os campos obrigatórios nos parâmetros de entrada não são verificados
  • [AI] Quando o processo habilita multilocação, a chamada da interface avisa que o processo não existe.
  • [AI] A interface do processo de chamada do processo foi alterada para não exigir login.
  • Atualize JVxetable para a nova versão 4.13.31
  • Atualize o jsqlparser para 4.9
  • Adicionadas anotações de permissão para funções relacionadas a aplicativos de IA
