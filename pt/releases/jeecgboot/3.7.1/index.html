#JecgBoot v3.7.1

Versão atual: v3.7.1 | 12/09/2024

Registro de atualização

Destaques desta versão: O gerador de código é bastante otimizado para suportar a geração de subpacotes com vários diretórios e mais detalhes, a versão mais recente do relatório de bloco de construção suporta a função de relatório, o painel é atualizado para uma nova versão, a configuração do gateway de microsserviço é simplificada, vários componentes subjacentes são atualizados, otimização de função online, etc.

Novos recursos

  • Atualizado o building block report para a versão mais recente, com função de design e preenchimento de formulário.
  • Atualize o painel do building block para a versão mais recente
  • Atualize nacos para 2.3.2, que suporta o banco de dados Dameng doméstico por padrão.
  • Atualize xxl-job para a versão 2.4.1 para evitar CVE-2024-24113
  • Atualize o autopoi para a versão mais recente 1.4.11
  • Adicionada inicialização docker com um clique para front-end e back-end único e de microsserviço
  • Configuração simplificada de gateway de microsserviço, suporta replicação, exclusão lógica e lixeira
  • Otimização dos detalhes da interface das funções do sistema
  • A modificação das permissões do usuário conectado no momento terá efeito direto, sem sair e fazer login novamente.
  • Atualizar dados provinciais e municipais
  • A interface de login da filial sas se adapta ao login da filial principal do front-end original e encurta o comprimento do token
  • Altere a permissão de gerenciamento da lista de permissões para solicitar o método de anotação
  • websocket sempre quebra, mude a forma de escrever
  • Otimize a função de dessensibilização de dados

Otimização do gerador de código

  • A geração de código suporta diretórios multiníveis de subpacotes
  • A geração de código suporta a geração de instruções de permissão de front-end v-auth
  • A geração de código suporta novo dicionário JPopupDict de controle
  • O controle de intervalo de condições de consulta gerado pelo código foi substituído por belos efeitos: intervalo de datas, intervalo de números, intervalo de valores, etc.
  • Os componentes de usuário e departamento são configurados de acordo com o campo Armazenamento online e campo de exibição ao gerar o código.
  • O formulário nativo falhou na verificação e não rolou para os campos que falharam na verificação.
  • O formulário não nativo falhou na verificação e não rolou para os campos que falharam na verificação.
  • A página de detalhes acionou uma correção de verificação
  • As colunas de operação da subtabela estilo ERP não são flutuantes
  • Quando o tipo de controle de página é uma caixa suspensa, o código vue de front-end gerado possui vírgulas extras.
  • O código gera condições de consulta para campos do tipo int, que não são renderizados em caixas de entrada numéricas.
  • Seja ERP nativo ou não nativo, quando a tabela principal não é selecionada, a subtabela é exportada diretamente e todos os dados são exportados.
  • O ERP um para muitos também pode ser alterado para selecionar uma linha clicando nela
  • Um par de embelezamento estilo Tab
  • Suporte para novo valor padrão de controle de geração de código para ano, mês, semana e trimestre
  • O dicionário pop-up de subtabela um para muitos não é gerado
