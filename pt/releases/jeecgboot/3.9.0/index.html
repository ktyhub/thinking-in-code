#JecgBoot v3.9.0

Tempo de lançamento: v3.9.0 | 01/12/2025

Registro de atualização

Esta atualização atualiza langchain4j para 1.3.0, fortalece as funções de IA, adiciona suporte a MCP e plug-in, permite operações de negócios no estilo chat (como "criar usuário em uma frase") e expande os recursos de chat de IA e orquestração de processos. Integre modelos Antrópicos (Claude), de pesquisa de rede e de raciocínio para melhorar as capacidades de pensamento profundo do sistema. Concluída a atualização do POI para a versão 5 e otimizadas funções de gerenciamento do sistema, como usuários, departamentos e locatários. A partir do v3.9.0+, a atualização simultânea para o Spring Boot versão 2 será interrompida.

Aprimoramento da função AI
  • Atualize langchain4j para a versão 1.3.0.
  • Os aplicativos de IA adicionam suporte para MCP e plug-ins.
  • A função de bate-papo AI suporta extensões MCP e plug-in.
  • A orquestração de processos de IA adiciona suporte a MCP e plug-in.
  • Suporte ao bate-papo com IA para fazer negócios (por exemplo: crie um usuário em uma frase)
  • Adicionado suporte ao fornecedor do modelo Antrópico (Claude).
  • O bate-papo com IA oferece suporte a modelos de raciocínio para melhorar as capacidades de pensamento aprofundado.
  • O processo de IA suporta funções de exportação e importação
  • O nó de script AI suporta escrita na linguagem Python
  • O chat AI integra o modelo Qianwen e suporta a função de pesquisa online
  • Suporta mais de 2.000 vetores dimensionais, a versão do pgvector deve ser maior que 0.7
Atualização da arquitetura funcional
  • A partir da versão v3.9.0+, a versão Spring Boot 2 não será mais atualizada simultaneamente.
  • Exclua logs de modificação em lotes para melhorar a legibilidade do código
  • POI atualizado para a versão 5.
  • Atualize o número da versão secundária do pacote dependente em package.json
  • O relatório do bloco de construção foi atualizado para a versão mais recente v2.2.0.
  • O Building Block BI foi atualizado para a versão mais recente v2.2.0, com uma nova função de comutação multitela, e o design de tela grande suporta exportação e importação.
  • Integrar vite-plugin-pwa para implementar Progressive Web Applications (PWA), melhorando significativamente a velocidade de carregamento da primeira tela.
  • Os recursos do sistema são carregados de forma assíncrona e os menus respondem mais rapidamente.
  • A senha de login é transmitida usando criptografia AES para evitar a transmissão de texto não criptografado e melhorar a segurança.
  • Suporta a configuração do período de validade das sessões de login do APP e do PC separadamente.
  • Suporta configuração flexível de regras de login:
  • Se deve permitir que a mesma conta faça login em vários lugares ao mesmo tempo.
  • Se deseja ativar o lembrete de login de senha padrão.
  • Se deseja ativar a verificação do código de verificação de login.
  • Os usuários de login suportam regras de login diferenciadas (distinguindo entre PC e APP) e registram informações do dispositivo terminal para facilitar a implementação da função push do APP.
  • O gerenciamento de departamento adicionou a função de visualizar os chefes de departamento.
  • O gerenciamento do departamento oferece suporte ao ajuste de arrastar e soltar das relações entre superiores e subordinados do departamento para melhorar a conveniência operacional.
  • As posições dos usuários são ajustadas a uma estrutura de tabela relacional para otimizar o gerenciamento da associação de dados.
  • Minha interface de locatário foi revisada para melhorar a experiência geral do usuário.
  • Otimize as regras de senha padrão para aumentar a segurança.
  • Suporta ocultar informações de contato do usuário para proteger a privacidade.
  • Otimização do editor de rich text: imagens em artigos copiados de blogs são baixadas e enviadas automaticamente para armazenamento em nuvem
  • Adicionada função de seleção de departamento à página de login
  • A página de lista BasicTable suporta a especificação de colunas de exportação ao exportar para Excel
  • a função uniapp push suporta mensagens online e offline (já conectadas aos anúncios do sistema)
  • O nível de log é ajustado de informações para depuração para reduzir a quantidade de saída de log.
  • Otimize algumas falhas funcionais causadas por atraso no carregamento e corrija falhas de anotação ignoradas de token.
  • Os códigos gerados são exportados uniformemente para o formato xlsx
  • Minhas mensagens suporta exclusão em lote de mensagens lidas
  • Atualize shardingsphere-jdbc para 5.5.0 para simplificar a configuração da fonte de dados ShardingSphere
  • O gerenciamento de usuários oferece suporte à consulta de usuários por estrutura organizacional (suporta seleção múltipla)
  • Novos campos de classificação são adicionados ao gerenciamento de usuários e funções como componentes de seleção de pessoas e catálogos de endereços são exibidas de acordo com os campos de classificação.
