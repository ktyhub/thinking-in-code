# PaddleOCR v3.3.3

## 2026.1.20 v3.3.3 发布

- PaddleOCR-VL现在支持指定自定义模型名称和API密钥，并且可以与SiliconFlow和Novita AI等第三方平台的推理服务无缝集成。
- PP-StructureV3 MCP Server 支持使用千帆平台上的托管服务作为底层推理引擎。
- PP-OCRv5和PaddleOCR-VL的文档得到了全面改进，修复了已知错误以增强可读性和准确性。
- 增加了对 Muxi GPU 推理的支持，进一步扩展了硬件兼容性和部署灵活性。

## 2026.1.20 v3.3.3 发布
