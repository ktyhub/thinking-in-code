# PaddleOCR v3.0.0

- **发布全场景文字识别模型PP-OCRv5：**单模型支持五种文字类型和复杂手写体识别；整体识别精度较上一代提升13个百分点。
 
- **发布通用文档解析方案PP-StructureV3：**支持多场景、多版本式PDF解析，在公开饮用水中领先的货物开源和闭源方案。

- **发布智能文档理解方案PP-ChatOCRv4：**初步支持文心大模型4.5 Turbo，精度较上一代提升15个百分点。

- **重构部署能力，统一推理接口：** PaddleOCR 3.0融合了飞桨PaddleX3.0工具的基础能力，全面升级推理、部署模块，优化2.x版本的设计，统一并优化了Python API和命令行接口（CLI）。部署能力现覆盖高性能推理、服务化部署及侧部署三大场景。

- **惯性飞桨框架3.0，优化训练流程：**新版本已兼容飞桨3.0的CINN编译器等最新特性，静态图模型存储文件由`xxx.pdmodel`改为`xxx.json`。

- **统一模型名称：**对PaddleOCR3.0支持的模型命名体系进行了更新，采用更规范、统一的命名规则，为后续迭代与维护奠定基础。
