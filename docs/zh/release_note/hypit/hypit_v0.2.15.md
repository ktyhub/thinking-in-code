# hypit v0.2.15

## 亮点

- 保持长而稀疏的超帧渲染本地到所请求的绝对帧选择。每帧不再扩展一次；动画、文本、可见性、浏览器程序、媒体插槽和资源发现现在从间隔或更改索引推进，而不是重新扫描整部电影。
- 边界渲染工作集而不更改请求的工作人员或框架语义。完整的输出 PNG 流传输至 FFmpeg，解码的源帧共享渲染本地字节预算，并且连续的源需求在小窗口中解码。
- 避免暂存编译器拥有的工件，这些工件可证明与渲染选择不相交。不透明的浏览器程序、字体和未知的 CSS 使用仍然明显保守。
- 从一次性的每次构建索引中推进实时构建，并通过引用保留转发的结果输出，避免重复的全状态扫描和不必要的复合物化。
- 添加跟随浏览器的 Studio 浅色主题，并且可以从顶部栏覆盖。
- 修复了 Chrome 专用网络访问所需的 OAuth 回调预检。

## 升级

安装 `@hypit/hypit@0.2.15`。现有视频项目和材料无需迁移。此版本仅更改 Hypit npm 发行版；没有单独的技能更新。

0.2.14 从未发布到 npm，因为 CI 无法解析测试依赖项。 0.2.15 包含其所有更改以及修复。

## 验证

打包的发行版在结帐之外安装，用于编译捆绑的项目组件、准备其字体和托管浏览器、渲染和导出 240 帧 MP4，并成功解码完整的输出。
