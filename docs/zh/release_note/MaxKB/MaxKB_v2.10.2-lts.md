# MaxKB v2.10.2-lts

# 功能优化
- **问答页面**：优化语音输入逻辑以附加转录文本，而不是覆盖现有输入内容（#6212）；
- **问答页面**：添加了用户在输入框中输入内容后清除输入内容的功能（#6212）；
- **问答页面**：当会话1正在生成回复时，用户切换到会话2后可以正常发送新问题；
- **代理**：通过表单提交的文件可以从对话日志中下载（#5271）；
- **代理**：高级代理开场白`html_render`标签中的`sendMessage`方法支持传递API参数和用户输入参数；
- **代理**：高级代理工具节点操作菜单中新增工具来源信息显示；
- **Agent (X-Pack)**：显示设置中添加对话共享的权限控制配置；
- **Agent (X-Pack)**：输入“/new”自动创建一个全新的对话，用于第三方应用集成；
- **知识库**：文档列表中的栏目支持手动调整宽度；
- **知识库**：文档列表新增创建者字段，新上传文档的创建者会被记录（#5240）；
- **知识库**：提供两种导出模式，允许用户在导出知识库时选择是否导出原始源文件（#6137）；
- **知识库**：优化标签管理分页逻辑，防止单个标签下数据过多导致前端卡顿；
- **模型**：添加了对 Gemini 提供程序下的 Imagen 图像生成模型的支持（#5234）；
- **模型**：添加了对 Gemini 提供商下的 VEO 视频生成模型的支持（#5234）；
- **模型**：更新了所有模型提供商的模型下拉列表以显示最新模型；
- **权限管理**：仅具有工具查看权限的用户禁止访问工具编辑页面；
- **工作区（X-Pack）**：优化工作区列表的延迟加载性能。

# 错误修复
- **问答页面**：修复节点执行进度显示不受执行详情切换开关控制的问题；
- **问答页面**：AI回复暂停时隐藏节点执行进度，clickingContinue后恢复显示进度；
- **Agent (X-Pack)**：修复第三方集成对话中预览知识源 PDF 文件失败的问题 (#6202)；
- **工具**：修复了创建新的 MCP 工具时名称输入框缺少必填字段标记的问题；
- **知识库**：修复了从 v2.3.1 升级到 v2.10.1 后损坏的下载 DOCX 源文件 (#6238)；
- **知识库**：修复了工作流调试期间写入知识库节点抛出的执行错误；
- **模型**：修复了从阿里云白联提供商添加 qwen3-tts-flash 模型时出现的错误 (#6236)；
- **登录设置**：修复了允许社区版用户无需验证码即可登录的漏洞（#6214）。
