# MaxKB v2.10.4-lts

# 安全漏洞修复
- **漏洞**：修复了允许匿名访问资源的系统文件权限缺陷；
- **漏洞**：修复了管理员聊天日志中的 IDOR 漏洞，该漏洞允许绕过应用程序路径身份验证来读取跨应用程序聊天记录；
- **漏洞**：增加了代理和工作流工具调度的独立授权验证机制；
- **漏洞**：修复了 UpdateStoreTool 获取外部应用商店 URL 时缺少主机验证的问题；
- **漏洞**：修复了水平提权问题，使用户能够跨知识库访问和修改未经授权的文档和片段；
- **漏洞**：修复了在 `/chat/api/mcp` 端点可用的过期代理 API 密钥；
- **漏洞**：修复了MCP工具授权逻辑缺陷导致的水平权限提升；
- **漏洞**：修复首页排名页面应用ID暴露，可能导致其他用户应用节点被非法调用的问题；
- **漏洞**：修复了查看和编辑模型参数表单时跨工作空间权限提升的风险；
- **漏洞**：修复提示注入漏洞，降低代理命令执行风险；
- **漏洞**：改进了 Web 文档导入和同步爬虫的内部 IP 验证，以修复 SSRF 风险。

# 错误修复
- **Agent**：修复了高级代理中新添加的图像理解节点视觉模型未实时显示在模型列表中的问题（#6402）；
- **代理**：修复删除基础代理绑定的LLM后，对话时提示信息不正确的问题；
- **代理**：修复代理调用共享模型时出现错误“模型不存在”的故障；
- **知识库**：修复了当 Word 文件中表格和后续内容之间没有空行时将分段文本错误分类为表格内容的问题 (#6396)；
- **知识库**：修复了拖动和重新排序文档片段时片段位置数据的跨文档污染问题（#6373）；
- **首页**：修复了排名详情页无法按名称搜索无用户权限的代理商的问题；
- **触发器**：修复了计划触发器列表的任务详细信息中重复的任务显示；
- **触发器**：修复了触发场景下高级代理的用户输入参数缺少默认值传递，导致参数值为空的问题 (#6320)；
- **触发器**：修复了当代理用户输入包含触发器中的切换类型参数时的参数传递错误；
- **用户管理**：修复了列出 API 的用户仅返回前 200 个用户，无法获取所有用户记录的问题 (#6375)。
