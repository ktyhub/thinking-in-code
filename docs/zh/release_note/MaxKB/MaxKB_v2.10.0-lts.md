# MaxKB v2.10.0-lts

# 新功能
- **首页**：新增工作区首页统计，管理员可以概览所有工作区资源、运行监控趋势以及资源使用情况排名。
- **知识库**：新增可定制术语库；自定义术语在文档分词和检索期间优先（#5031）。
- **代理**：对 AI 对话节点的完整多模式输入支持（#5276）。
- **代理**：用户输入的参数可以直接内联显示在输入框中进行配置。
- **Agent**：用户输入参数和表单采集节点的可见性条件配置，实现字段之间的联动。
- **系统**：支持自定义语言包；自定义语言环境文件可以放置在 MaxKB 容器内的 `/opt/maxkb/local/locales` 下，并且在服务重新启动后可以选择自定义语言 (#5120)。

# 功能优化
- **问答页面**：开始新对话时隐藏用户输入参数（#5298）。
- **代理**：在问答页面上显示当前正在运行的节点的名称以及 AI 响应 (#5092)。
- **代理**：添加了表单集合节点内参数的可见性切换。
- **代理**：为多重召回节点添加了输出参数 `Result List for Direct Reply`。
- **知识库**：文档分割预览时冻结右上角的操作按钮（#965）。
- **知识库**：在分段预览上以 Markdown 格式呈现分段内容。
- **模型**：MiniMax 提供程序新支持文本到图像、文本到视频和图像到视频模型。
- **模型**：阿里云百联添加了多模态嵌入模型支持（#5142）。
- **模型**：阿里云白联支持Wan2.7图像转视频模型（#5232）。
- **模型**：参数配置可用于对所有提供商的模型进行重新排名。
- **角色管理（X-Pack）**：将代理创建权限和复制权限拆分为独立的权限位（#5284）。

# 错误修复
- **安全漏洞**：修复了 MaxKB 中 MCP 权限绕过导致的身份验证后 RCE 漏洞。
- **知识库**：修复了在没有相应工作流授权的情况下无法上传工作流知识库中文档的问题（#5296）。
- **Agent**：修复嵌入式移动布局、浮动窗口布局和共享页面样式显示异常的问题 (#6130)。
- **代理**：修复了当一个对话中生成多个图表时，页面刷新后所有 ECharts 图表都会被第一个图表覆盖的问题。
- **代理**：修复了高级代理中对话结束后，上传的文件在页面刷新后消失的问题（#5253）。
- **代理**：修复导出的对话日志仅显示用户名而不是全名，从而阻碍用户匹配。
- **共享知识库（X-Pack）**：修复了导入创建共享知识库后出现空结果的问题（#5274）。
- **用户管理**：修复了管理员重置用户密码时的验证错误（#5301）。
- **系统登录（X-Pack）**：修复第三方用户登录时丢失操作日志的问题。
