# MaxKB v2.10.3-lts

# 功能优化
- **知识库**：新增文件上传可视化进度显示；上传失败的文件支持一click重新上传。
- **代理**：支持代理对话日志清理策略的批量配置（#6213）。
- **Agent (X-Pack)**：为 WeCom 机器人集成启用语音输入功能。
- **代理**：优化总览页文案，使其视觉风格与首页保持一致。
- **角色权限（X-Pack）**：为普通用户和工作区管理员添加了主页查看权限配置。

# 错误修复
- **代理 (X-Pack)**：修复了与 WeCom 集成时多个代理共享同一 `chat_session_id` 导致的对话中的 500 错误 (#6325)。
- **代理**：修复了调试期间无法为高级代理中的接口参数变量赋值的问题（#6271）。
- **Agent (X-Pack)**：修复了启用免责声明后移动输入框覆盖喜欢和不喜欢按钮的 UI 问题 (#6249)。
- **代理**：修复了外部用户输入参数的无效可见性控制逻辑。
- **问答页面**：修复移动设备上回复中视频内容样式呈现异常的问题。
- **知识库**：修复了上传包含特殊字符的 PDF 文件时的解析错误。
- **知识库**：修复知识库导出时未导出知识库中存储的视频文件的问题。
- **知识库**：修复了阻止普通用户通过工作流知识库中的 MCP 调用节点加载工具列表的权限错误。
- **知识库**：修复了导入工作流知识库后循环块内工具的参考链接缺失，导致工具节点不可用的问题。
- **知识库**：修复了文档上传后分段预览中分段内容偶尔重复显示的问题。
- **模型**：修复了在多路径召回节点中从 vLLM 提供程序调用 Qwen3-VL-Reranker-8B 重新排序模型时出现的错误 (#6321)。
- **系统设置 (X-Pack)**：修复了配置自定义徽标时页面刷新后默认 MaxKB 徽标短暂闪烁的问题 (#6295)。
