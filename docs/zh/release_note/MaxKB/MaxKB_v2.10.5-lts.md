# MaxKB v2.10.5-lts

### 安全漏洞修复
- **安全漏洞**：修复了聊天共享链接端点缺少所有者检查的问题，其中聊天令牌可能被滥用来共享其他用户的对话内容。
- **安全漏洞**：修复了权限升级，允许普通用户通过 API 获取其他工作区的用户信息（#6576）。
- **安全漏洞**：修复了任何用户的 API 密钥可用于删除任意文件的权限升级。
- **安全漏洞**：修复了普通用户可以通过 API 获取其他用户的电子邮件地址等敏感信息的问题 (#6577)。

### 错误修复
- **知识库**：修复了对话中从知识库返回的图像加载失败的问题。
- **知识库**：修复了上传的 PDF 标题和正文内容中包含相同文本时段落内容异常的问题 (#6543)。
- **知识库**：修复了 Web 知识库导入文档模式中“允许在知识源中预览”选项的错误显示。
- **代理**：修复了复制长对话文本时被截断的内容 (#6568)。
- **代理**：修复了当代理嵌入第三方页面时无法访问的人工智能生成的图像。
- **代理**：修复了代理图像生成节点生成的无法访问的图像。
- **代理**：修复了代理调试完成后弹出的错误消息，该错误消息阻止了对执行详细信息的访问。
- **代理**：修复了能够针对未发布的知识库检索配置运行检索的基本代理（#6519）。
- **代理**：修复了文件内容提取节点提取图像后图像加载失败的问题。
- **代理**：修复代理触发任务执行失败的问题。
- **代理**：修复了工作流程工具节点输出未写入对话日志的问题。
- **代理**：修复代理开场白中的`sendMessage`方法无法传递用户参数，导致用户问题丢失的问题。
- **代理**：修复了问答页面知识源面板权限不足导致文件预览/下载失败的问题。
- **代理**：修复了从对话日志下载多个上传文件时对部分文件的权限拒绝提示。
- **代理**：修复了由于对话日志清理后残留未清理数据而导致概述页面上不准确的活动用户统计信息。
- **角色（X-Pack）**：修复了某些功能缺失的权限位控制。
- **共享资源 (X‑Pack)**：修复了系统管理员 click 在共享知识库中“上传文档”时的错误页面重定向。
- **共享资源 (X‑Pack)**：修复了对工作区中共享知识库的命中测试结果的访问。
