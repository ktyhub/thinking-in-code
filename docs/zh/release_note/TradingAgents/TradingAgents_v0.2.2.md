# TradingAgents v0.2.2

## 总结

TradingAgents v0.2.2引入了专业的五级评级框架，统一的LLM提供商集成，并提高了系统可靠性。

### 决策框架
- 五级评级量表（买入/增持/持有/减持/卖出），包含结构化执行摘要和投资论文
- 投资组合经理作为标准化的最终决策代理人
