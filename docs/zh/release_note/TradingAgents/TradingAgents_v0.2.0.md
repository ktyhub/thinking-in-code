# TradingAgents v0.2.0

## 总结

TradingAgents v0.2.0 引入了多提供商 LLM 支持和系统架构改进。

- 具有工厂模式的多提供商LLM支持（OpenAI、Google、Anthropic、xAI、OpenRouter、Ollama）
