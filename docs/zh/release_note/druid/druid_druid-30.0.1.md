# druid druid-30.0.1

Apache Druid 团队很自豪地宣布发布 Apache Druid 30.0.1。 
Druid 是一个用于事件驱动数据的高性能分析数据存储。

Apache Druid 30.0.1 包含 [CVE-2024-45384](https://www.cve.org/CVERecord?id=CVE-2024-45384)、[CVE-2024-45537](https://www.cve.org/CVERecord?id=CVE-2024-45537) 的安全修复程序。
该版本还包含较小的文档和任务监视器修复。

源代码和二进制发行版可以从以下位置下载：
https://druid.apache.org/downloads.html
