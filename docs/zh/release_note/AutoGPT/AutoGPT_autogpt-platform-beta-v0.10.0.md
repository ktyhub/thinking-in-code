# AutoGPT autogpt-platform-beta-v0.10.0

## 🔥 有什么新内容？

### ⚠️ 重大变更

- **#15970** - 自托管 Docker Compose 每次安装都会生成自己的服务密码，没有它们就无法启动：在 `docker compose up` 之前运行 `make init-env`（或安装程序）。 PostgreSQL、RabbitMQ、Redis、FalkorDB 和 ClamAV 现在仅在 `127.0.0.1` 上收听。现有安装：请参阅[升级：每次安装都会生成服务密码](https://github.com/Significant-Gravitas/AutoGPT/blob/master/docs/platform/getting-started.md#upgrading-service-passwords-are-generated-per-install)（作者：@ntindle）
- **#12206** - 外部 API v1 已弃用，取而代之的是新的 v2，并继续工作到 2027 年 1 月 31 日（由 @Pwuts 提供）
