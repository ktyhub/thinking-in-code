# open-webui v0.9.6

### 添加

- 📦 **官方知识库同步工具。** 来自 Open WebUI 的新配套工具 oikb，使知识库与本地目录、GitHub 存储库、S3 存储桶、Confluence 空间或 40 多个其他源中的任何一个保持同步，使用此版本中添加的增量同步支持仅上传新的和更改的文件。 [oikb](https://github.com/open-webui/oikb)
- 📂 **知识库的智能目录同步。** 本地目录现在可以通过一个操作同步到知识库：将文件校验和与已存储的内容进行比较，仅上传添加或修改的文件，同时清理已删除的文件和孤立的子目录，自动镜像目录结构并显示每个文件的进度。 [#19190](https://github.com/open-webui/open-webui/issues/19190)、[#19394](https://github.com/open-webui/open-webui/issues/19394)、[提交](https://github.com/open-webui/open-webui/commit/60c9db1cb81d021589cb49bee8744a799b51211f)、[提交](https://github.com/open-webui/open-webui/commit/73bdf86766d3f44467cdec436786fe089481baf3)、[提交](https://github.com/open-webui/open-webui/commit/9835b3f1dd7aa9c92ff08a634a0f97cc2a046e42)、[提交](https://github.com/open-webui/open-webui/commit/97252fa609440573251d8e75090f347ed1e51e1d)、[提交](https://github.com/open-webui/open-webui/commit/8f2d346e10c47b57bf6b5a6aa02d453488a88b89)、[提交](https://github.com/open-webui/open-webui/commit/1527eb6e01d441225c979d12d78b7625edf1086f)
- 🗂️ **知识库文件夹。** 知识库内的文件现在可以组织到嵌套文件夹中，并使用面包屑导航，使管理和查找大型集合中的内容变得更加容易。 [提交](https://github.com/open-webui/open-webui/commit/c2cbc47ca76ebfa21e1d36279dbd859283cbbfb1)、[提交](https://github.com/open-webui/open-webui/commit/ab0ee858b73738c5b77d1d455e66e66bc61df1c4)、[提交](https://github.com/open-webui/open-webui/commit/2ad327a4dce64a8eedf5eb41c73b8520344fdd82)、[提交](https://github.com/open-webui/open-webui/commit/171150c1e12b5713f77a5ea0dd19c6581c7bef2e)、[提交](https://github.com/open-webui/open-webui/commit/e7d2ddbb1d14c03a52797751d24a98132aac0cd8)、[提交](https://github.com/open-webui/open-webui/commit/32a417bbf66ed28a5ca8a759ad3a87b2a2aa358a)
- 🧰 **用于知识库的文件系统工具。** 通过“ENABLE_KB_EXEC”环境变量启用的新内置工具，可让 AI 模型使用熟悉的文件系统命令（例如“ls”、“cat”、“grep”、“find”、“head”、“tail”和“sed”）（包括它们之间的管道）浏览和搜索知识库内容。 [提交](https://github.com/open-webui/open-webui/commit/5b125c24d4eae925d3287efa626595bab29d5c33)、[提交](https://github.com/open-webui/open-webui/commit/ecec86dd32aa396dd5a383e9be5b0f16c4346c48)、[提交](https://github.com/open-webui/open-webui/commit/9ef579ce4be5b82f9281b085a621fed5b04e0d26)、[提交](https://github.com/open-webui/open-webui/commit/2f642754ac6b8c430228a7fc289357a6c6652235)、[提交](https://github.com/open-webui/open-webui/commit/3b00e5721a60518ea317c4fd61a6d0d182961a2f)、[提交](https://github.com/open-webui/open-webui/commit/4e78b355efe0611f27fddef591c69f7c1259a9f6)、[提交](https://github.com/open-webui/open-webui/commit/74f95a9b0d6b89b241701422170d54e21e701baa)、[提交](https://github.com/open-webui/open-webui/commit/cc16e06c32de48bdf464db5814483a49f3527b63)、 [提交](https://github.com/open-webui/open-webui/commit/1ea54c3217f487990b6a4c0f0d8ea675a479b6e1)
- ✏️ **知识库中的文件重命名。** 现在可以直接从工作区重命名知识库内的文件，无论引用文件的位置都会反映新名称。 [提交](https://github.com/open-webui/open-webui/commit/3127f1b46255626ea92eb0b598e45078287303f1)
- 😀 **消息输入中的表情符号选择器。** 富文本格式工具栏中的新表情符号按钮可让您浏览表情符号并将其直接插入消息中。 [#24704](https://github.com/open-webui/open-webui/pull/24704)
- 🪄 **每聊天技能切换。** 现在可以直接从聊天集成菜单打开或关闭对话的技能，与工具和功能已经工作的方式相同，而不仅仅是通过模型预设。 [#25036](https://github.com/open-webui/open-webui/issues/25036), [#25037](https://github.com/open-webui/open-webui/pull/25037)
- 🔎 **用户和组的访问预览。** 管理员现在可以准确预览给定用户或组可以访问哪些模型、知识库和工具，从而更轻松地审核和验证权限设置。 [提交](https://github.com/open-webui/open-webui/commit/9c14740ffb009d550dcbd5d6c599dac57053f112)
- 📄 **可配置的知识库文件页面大小。** 管理员现在可以在通过 API 列出知识库文件时请求更大的页面大小，从而减少检索大型集合所需的请求数量，而不是通过固定增量 30 进行分页。[#25148](https://github.com/open-webui/open-webui/issues/25148)，[提交](https://github.com/open-webui/open-webui/commit/a4d1b3e9378a61a11dd9822a8dbb525f39753081)
- 🔃 **知识文件的持久处理指示器。** 知识库中仍在处理的文件现在会在页面重新加载时保持显示处理指示器，因此您可以在离开和返回后知道仍在摄取哪些内容。 [#25031](https://github.com/open-webui/open-webui/issues/25031)，[提交](https://github.com/open-webui/open-webui/commit/ad9f2eeb15a448147d5e47e6a391cabb9aefd0ea)
- 📑 **MinerU 文件类型配置。** 管理员现在可以通过新的“MINERU_FILE_EXTENSIONS”设置配置 MinerU 文档加载器处理哪些文件类型，将其从 PDF 扩展到 DOCX、PPTX 和 XLSX 等格式。 [提交](https://github.com/open-webui/open-webui/commit/d4030a8aa5d48c2a1cb06c461566844aca2530ab)
- 📃 **旧版 Word 文档支持。** 除了现代的“.docx”格式之外，较旧的“.doc”Word 文件现在还可以由默认文档提取引擎提取其文本。 [提交](https://github.com/open-webui/open-webui/commit/9e3e24e304f8ff210494380b46f614a2984cafb3)
- 📁 **从文件夹标题创建子文件夹。** 聊天文件夹现在可以直接从聊天视图中的文件夹标题创建子文件夹，而不仅仅是从侧边栏创建。 [提交](https://github.com/open-webui/open-webui/commit/1f0948bcbef2af73b155535ea27762c522260afc)
- ⚡ **更快的初始页面加载。** 在每次页面访问时加载的配置端点不再运行不必要的用户计数查询，从而使数据库上的初始应用程序负载更轻，尤其是在具有许多用户的实例上。 [提交](https://github.com/open-webui/open-webui/commit/0adc090dcbe636c9c9645d8ec7f6b89ea514870b)
- 🚀 **更快的支持工具的聊天完成。** 使用多个工具的聊天完成现在启动速度更快，因为它们引用的工具是在单个批量查询中从数据库中获取的，而不是每个工具一个查询。 [#24808](https://github.com/open-webui/open-webui/pull/24808)，[提交](https://github.com/open-webui/open-webui/commit/cc94a90b4d4d690bc7cb9f7124f2d6e552973970)
- 🏎️ **负载下的网页搜索响应速度更快。** 通过 SearXNG、Google PSE、Brave、Serper 和 Serpstack 进行的网页搜索现在使用非阻塞网络调用，因此服务器在搜索进行时保持对其他用户的响应，并且并发多查询搜索可以更快地完成。 [提交](https://github.com/open-webui/open-webui/commit/b94245d2ee191e8ef118bf9de1ff7539503bfec9)
- 🐎 **更轻的 Ollama 后端连接。** 对 Ollama 后端的请求现在重用共享连接池，而不是每次打开一个新会话，从而减少了频繁轮询 Ollama 或配置多个后端的安装的 TCP 和 TLS 握手开销。 [提交](https://github.com/open-webui/open-webui/commit/5d9a09a88a9094ebfcd249340be3aaee544b34d0)
- 💽 **更少的冗余模型列表写入。** 在 Redis 支持的多实例部署上，模型列表在未更改时不再重写，从而减少了冗余写入的主要来源。 [#25469](https://github.com/open-webui/open-webui/issues/25469)、[#25474](https://github.com/open-webui/open-webui/pull/25474)、[提交](https://github.com/open-webui/open-webui/commit/fd76b51ab2ad4c4192f2c98153e47888712c2009)
- 📉 **更快的 websocket 断开连接清理。** 从协作会话断开连接不再触发对整个 Redis 键空间的扫描，而是使用每个会话索引，这使得大型部署中的断开连接成本较低。 [#25466](https://github.com/open-webui/open-webui/issues/25466)，[提交](https://github.com/open-webui/open-webui/commit/c7de057a4a54cc80f366ad949417e78fae756d4c)
- 📝 **Frontmatter 自动填充工具、函数和技能。** 打开工具、函数或技能编辑器现在会自动填充文件 frontmatter 中的名称、id 和描述字段，从而使您无需重新输入源中已声明的元数据。 [#24649](https://github.com/open-webui/open-webui/pull/24649)，[提交](https://github.com/open-webui/open-webui/commit/ef975649b26d3e7cd589c49be2fc77cee80fad8f)
- 🪪 **自定义标头中有更多用户占位符。** 用于直接连接和工具服务器的自定义标头模板现在支持“{{USER_EMAIL}}”和“{{USER_ROLE}}”以及现有的用户和会话占位符。 [提交](https://github.com/open-webui/open-webui/commit/ed73ef3d8df988b0e9646b82df5b1a453202ef8d)
- ⏱️ **可配置的 MCP 连接超时。** 现在可以通过新的“MCP_INITIALIZE_TIMEOUT”设置来配置与 MCP 工具服务器初始握手的超时，因此启动缓慢或暴露许多工具的服务器可以完成连接而不是超时。 [#25011](https://github.com/open-webui/open-webui/pull/25011)，[提交](https://github.com/open-webui/open-webui/commit/4297c02b121180e239a61c483ac8477cc557d4ef)
- 📐 **个人资料图像大小限制。** 管理员现在可以通过新的“PROFILE_IMAGE_MAX_DATA_URI_SIZE”设置限制内联个人资料图像的大小，限制内联头像和模型图标可以消耗的数据库和缓存空间。 [#25468](https://github.com/open-webui/open-webui/issues/25468), [#25476](https://github.com/open-webui/open-webui/pull/25476)
- 🎫 **通配符 OAuth 角色映射。** 管理员现在可以在允许的 OAuth 角色中设置“\*”，以将用户角色授予任何经过身份验证的 OAuth 用户，而不必枚举每个接受的角色。 [#25062](https://github.com/open-webui/open-webui/pull/25062)，[提交](https://github.com/open-webui/open-webui/commit/07cbc91a8eba3a9a3b39588b2ae5de916930af70)
- 📊 **分页反馈历史记录。** 反馈和评估历史记录列表现在已分页，使其能够响应已积累大量反馈条目的实例。 [提交](https://github.com/open-webui/open-webui/commit/160a6694e4bd66fc42e6361947516e8e15414ef3)
- 🔘 **批量启用或禁用自动化。** 现在可以从自动化页面上的操作菜单批量启用或禁用自动化，而不是单独切换每个自动化。 [提交](https://github.com/open-webui/open-webui/commit/675e9bee5af8b9fb390fcb235a6c2c4766e78c75)
- ➡️ **可选自动重定向到单点登录。** 管理员现在可以启用“OAUTH_AUTO_REDIRECT”，这样，在使用单点登录提供商且没有其他登录方法的部署中，用户将直接发送到提供商，而不是首先看到登录页面。 [#25067](https://github.com/open-webui/open-webui/pull/25067)，[提交](https://github.com/open-webui/open-webui/commit/d64ef1803d2f5cedb7b3a308151d08ff2cd2b8e1)
- ☁️ **带有 Entra ID 的 Azure AI Foundry v1。** Open WebUI 现在支持 Azure AI Foundry 的 OpenAI v1 端点以及 Microsoft Entra ID 身份验证，因此这些连接无需手动解决方法即可工作。 [#24761](https://github.com/open-webui/open-webui/issues/24761)、[#24985](https://github.com/open-webui/open-webui/pull/24985)、[提交](https://github.com/open-webui/open-webui/commit/eb4eebc3ce1042cb0d393bf890c1895db6e08b19)
- 🌎 **Linkup Web 搜索提供程序。** 管理员现在可以从管理设置中选择 Linkup 作为 Web 搜索提供程序，并提供配置 API 密钥和搜索深度的选项。 [#24752](https://github.com/open-webui/open-webui/pull/24752)，[提交](https://github.com/open-webui/open-webui/commit/56c0d00e13c74d665124ec9f1cae78e83ca60b6a)
- 🧊 **Valkey 向量数据库支持。** Valkey 现在可以用作向量数据库后端，可通过新的“VALKEY_URL”和相关设置（包括索引类型、距离度量和 HNSW 调整）进行配置。 [#24769](https://github.com/open-webui/open-webui/pull/24769)，[提交](https://github.com/open-webui/open-webui/commit/c0f1aa291938bbef62db8d4013dbc498b0abea15)
- 🔄 **一般改进。** 在整个应用程序中实施了各种改进，以增强性能、稳定性和安全性。
- 🌐 **翻译更新。** 西班牙语（西班牙）、瑞典语、德语、韩语、加泰罗尼亚语、俄语、爱尔兰语、简体中文、繁体中文、芬兰语、波兰语、土耳其语和马来语的翻译得到增强和扩展。

### 已修复

- 🛡️ **安全建议**：此版本包括安全和访问控制修复。我们建议您尽早更新生产部署。并非此版本中的所有安全修复程序都可以在“已修复”部分中列出 - 有些修复程序可能会暂时保留，以便管理员有时间进行升级。 [咨询](https://github.com/open-webui/open-webui/security)
- 🛡️ **工具服务器权限强制执行。** 现在，内联工具服务器的每用户权限在聊天完成请求上强制执行，因此没有该权限的用户无法再通过直接在请求中提供工具服务器来绕过管理设置。 [提交](https://github.com/open-webui/open-webui/commit/5cc1eb517094e3507915664817285f1e6e37a16d)
- 🔒 **搜索工具中的知识库访问检查。** 内置的知识搜索工具现在会在通过 ID 搜索知识库之前验证调用者是否可以访问知识库，从而防止用户读取他们未被授予访问权限的知识库内容。 [#25113](https://github.com/open-webui/open-webui/pull/25113)
- 🗄️ **对检索集合的跨用户访问。** 现在解析用于检索的文档会验证调用者对每个引用文件的访问权限，并拒绝 client 提供的集合名称，从而防止精心设计的请求将其他用户的文件或矢量集合拉入其上下文。 [提交](https://github.com/open-webui/open-webui/commit/ee47c9c833f8889f3abe99d2266c56e8f8d40230)
- 🔣 **集合名称验证。** 现在，矢量集合名称将被拒绝，除非它们仅包含安全字符，从而防止格式错误的名称到达矢量存储或破坏数据库查询表达式。 [#24982](https://github.com/open-webui/open-webui/pull/24982)
- 🚫 **默认情况下拒绝无范围检索集合。** 现在默认情况下会拒绝非管理员对与已知文件、内存、网络搜索或知识库不对应的集合名称的检索请求，并使用新的“ENABLE_RETRIEVAL_UNSCOPED_COLLECTIONS”设置来在需要时恢复以前的行为。 [提交](https://github.com/open-webui/open-webui/commit/c93f071700520a60833b7f9616c292b11f210880)
- 📜 **提示历史授权。** 比较、删除和恢复提示版本现在可以验证历史记录条目是否属于您已授权的提示，从而防止访问或修改另一个提示的版本历史记录。 [#25056](https://github.com/open-webui/open-webui/pull/25056)
- 🚦 **遗留路径上的代码解释器权限。** 遗留代码执行路径现在强制执行与当前路径相同的权限和功能检查，因此没有代码解释器权限的用户无法再通过它触发代码执行。 [#24724](https://github.com/open-webui/open-webui/pull/24724)
- 🧱 **API 密钥端点限制绕过。** 限制 API 密钥可以到达的路径的端点允许列表现在直接与路由请求路径进行匹配，从而防止精心设计的请求绕过限制。 [#25123](https://github.com/open-webui/open-webui/pull/25123)
- 🚧 **通过请求参数绕过系统提示。** 外部 clients 无法再通过请求参数设置跳过模型配置的系统提示的标志，因此无法从 API 绕过管理员配置的系统提示。 [#25156](https://github.com/open-webui/open-webui/pull/25156)
- 🚪 **终端代理路径遍历。** 终端代理现在在验证请求路径之前对其进行完全解码，从而阻止可能逃脱预期路径的多编码有效负载。 [#25157](https://github.com/open-webui/open-webui/pull/25157)
- 🪤 **缓存文件路径遍历。** 缓存文件服务器现在需要精确的目录边界匹配，从而缩小名称以缓存目录名称开头的同级目录可用于从其外部提供文件的间隙。 [#25086](https://github.com/open-webui/open-webui/pull/25086)
- 🔀 **Ollama 后端选择访问检查。** 请求不能再通过索引定位任意 Ollama 后端；现在，根据实际服务于所请求模型的后端来验证调用者提供的后端选择器。 [提交](https://github.com/open-webui/open-webui/commit/7139797be04030b9d1016782f1dbb251c5fe68bb)
- 🔓 **通过图像 URL 进行跨用户文件渗透。** 当聊天消息通过“image_url”字段中的 id 引用文件时，服务器现在仅为其所有者、管理员或具有显式读取授权的用户解析该文件，从而防止其他经过身份验证的用户通过模型路由来提取文件内容。 [#24625](https://github.com/open-webui/open-webui/pull/24625)，[提交](https://github.com/open-webui/open-webui/commit/c75fe8e74b72617c51282cc3ea0a2e8d9cdd9140)
- 📌 **聊天文件附件访问检查。** 将文件附加到聊天现在仅链接调用者可以读取的文件，从而防止用户将其他用户的文件与其聊天关联以访问其内容。 [#25054](https://github.com/open-webui/open-webui/pull/25054)
- 🧾 **模型知识文件所有权检查。** 创建或更新模型现在会验证附加到该模型的任何知识文件是否是编辑器可以访问的文件，从而防止其他用户的文件附加到模型。 [#25055](https://github.com/open-webui/open-webui/pull/25055)，[提交](https://github.com/open-webui/open-webui/commit/27fb20c13a4bf8501f7a485abe0654eb5880980d)
- 📅 **日历事件移动授权。** 更新日历事件以将其移动到不同的日历现在需要目标日历上的写入权限，从而防止用户将事件注入到他们无法写入的日历中。 [#24764](https://github.com/open-webui/open-webui/pull/24764)
