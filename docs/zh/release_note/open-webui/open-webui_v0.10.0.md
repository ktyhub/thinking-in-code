# open-webui v0.10.0

### 添加

- 🤝 **与您的团队共享文件夹。** 您现在可以与具有读取或写入权限的特定用户、群组或所有人共享文件夹及其内的聊天内容；与您共享的人可以在其侧边栏中看到共享文件夹，并在不是所有者时以只读视图打开聊天，并且管理员通过新的“文件夹共享”权限控制谁可以共享文件夹，该权限默认情况下处于关闭状态。 [提交](https://github.com/open-webui/open-webui/commit/5019af79a0c45743ede8c9ff37d68f768e7f6174)、[提交](https://github.com/open-webui/open-webui/commit/38920c0ed1f6ad5fe3bb9d12898fa968ead3634a)、[提交](https://github.com/open-webui/open-webui/commit/d65ac445a43348c5f0323d54c37397ae7f483cb8)、[提交](https://github.com/open-webui/open-webui/commit/c783fd30f20d6be5028cf337bc5e5c2f9afbd3f8)、[提交](https://github.com/open-webui/open-webui/commit/45fcf272ef51c84cb01c1454589da3f98e4adc2c)、[提交](https://github.com/open-webui/open-webui/commit/76854d14246660af8222a5302513020e1f36c4f3)、[提交](https://github.com/open-webui/open-webui/commit/084d040e220ee39f62757d928d839646e813fb25)、[提交](https://github.com/open-webui/open-webui/commit/10558173fb155c63403aa8d80f16f8a3ccfa72a6)
- 🗜️ **针对长聊天的自动上下文压缩。** 现在可以自动总结超过可配置令牌阈值的对话，以便它们保留在模型的上下文窗口中，并在发生时显示通知；管理员可以启用它、设置阈值、自定义汇总提示以及降低每个模型的阈值。默认情况下它是关闭的。 [提交](https://github.com/open-webui/open-webui/commit/3f0c0e0a0ddff841b015f96f9649c6999a435c73)、[提交](https://github.com/open-webui/open-webui/commit/7f08376f0c06e1a7fba983a2fa93deb8dfbe7cb0)、[提交](https://github.com/open-webui/open-webui/commit/8934bfb04bf366aece872028944e280c25e36d3e)、[#19594](https://github.com/open-webui/open-webui/issues/19594)
- 🖥️ **Open WebUI 计算机代理支持。** Open WebUI 现在可以通过其 OpenAI 兼容网关连接到 Open WebUI 计算机，让聊天在您自己的计算机上运行完整的代理会话，并具有文件、终端、git 和 Web 访问权限。 [GitHub](https://github.com/open-webui/computer)
- 🚀 **大型知识库上的混合搜索速度更快。** 混合搜索现在在 pgvector 设置的数据库中本地运行，而不是将整个集合加载到内存中，因此查询大型知识库的速度显着加快。 [提交](https://github.com/open-webui/open-webui/commit/223f484ded01d092979693341dc03351a9fa17fa)，[#20737](https://github.com/open-webui/open-webui/discussions/20737)
- 🗂️ **外部知识库。** 知识库现在可以通过可配置的外部知识连接由外部检索源支持，因此您可以从聊天中搜索现有的外部系统，而不仅仅是 Open WebUI 的内置商店。 [提交](https://github.com/open-webui/open-webui/commit/15c7e374384488effc3d6059d09b3a8aa79c618d)
- 🧠 **重新设计的记忆系统。** 记忆已通过不同的记忆类型（长期的个人记忆和每次对话上下文）进行了彻底改造，通过结构化的添加、更新和删除流程进行管理，为模型提供了更可靠的方式来记住和应用他们所了解的有关您的信息。 [提交](https://github.com/open-webui/open-webui/commit/dbdcfd8c6080c284024052a482e589de226dbf05)、[提交](https://github.com/open-webui/open-webui/commit/7e13fd7ad19c28ba34502bde6c709665f7a6808c)、[提交](https://github.com/open-webui/open-webui/commit/2560533c1a8a2b2a0f7b47becf3703031053ad30)、[提交](https://github.com/open-webui/open-webui/commit/8977a10a2b1e150393635dc5c24e59660d0f2da9)、[提交](https://github.com/open-webui/open-webui/commit/260f3c3a22c55f15ca8f06c5314b23f2a9eb1739)、[提交](https://github.com/open-webui/open-webui/commit/b0487dd6dd942a757828a25aba92e9feef685275)、[提交](https://github.com/open-webui/open-webui/commit/a285a390c12e27e614d1ba9ffb92d1a0e49e7dfa)、[提交](https://github.com/open-webui/open-webui/commit/70e4ffcc6526c1bc90dbfdc0287283574b12c18b)、 [提交](https://github.com/open-webui/open-webui/commit/2c4e1fce8f40b0cb5028f1afcb184b6e58c33041), [提交](https://github.com/open-webui/open-webui/commit/c7e634776d7e77556d149b6cc884ed64363648a9)
- 🧩 **新的插件原语：Event 函数。** 管道、过滤器和操作函数都在对话中运行，新的 Event 函数是第一个与系统本身挂钩的原语：它运行您自己的 Python 来响应整个应用程序中发出的事件 - 注册、配置更改、文件上传、角色更改、删除、启动和关闭等。这使得直接在 Open WebUI 内部实现一类新的行为成为可能，从入门和访问控制到审计、生命周期自动化和外部集成。函数编辑器中附带入门样板。 [提交](https://github.com/open-webui/open-webui/commit/e124c2656a4c2092b070e570e35b2f0fb7f584de)，[文档](https://docs.openwebui.com/features/extensibility/plugin/functions/event)
- 🔔 **带有 webhook 的新事件系统。** Open WebUI 现在为各种系统活动发出事件 - 登录、配置更改、启动以及跨聊天、知识、文件等的操作。管理员可以将这些作为出站 Webhook 发送，将它们路由到特定用户或组，并从新的事件设置管理页面管理哪些事件去往何处。 [提交](https://github.com/open-webui/open-webui/commit/b5c43968db0ea1556b228d143ae5946dc4e944ba)、[提交](https://github.com/open-webui/open-webui/commit/745396867888718289a2dfcf0809b3e162e00629)、[提交](https://github.com/open-webui/open-webui/commit/5576e6ed8a80a4032b7c6cb3ee0cda0254019355)、[提交](https://github.com/open-webui/open-webui/commit/7b55a63fc7ee323e9114713ce1d2f3f688aa37e6)、[提交](https://github.com/open-webui/open-webui/commit/1a8e1a993928a28b9d814c77b2aef0361b630f27)、[提交](https://github.com/open-webui/open-webui/commit/ede39d82de05eeb7591329679c8cab97753e5ff0)、[提交](https://github.com/open-webui/open-webui/commit/8f890f0b43aed3d42b9e3d954e25e54e37d526d0)、[提交](https://github.com/open-webui/open-webui/commit/741b64edb6c2ff04c4b787528cfca1c5b66a1a27)、 [提交](https://github.com/open-webui/open-webui/commit/303c426c3fffafc2369205021a82659ee8715a85)、[#1240](https://github.com/open-webui/open-webui/issues/1240)、[#16426](https://github.com/open-webui/open-webui/pull/16426)
- 🔐 **从管理面板配置身份验证。** LDAP 和 OAuth/OIDC 设置现在有一个专用的身份验证设置页面，因此可以从管理界面配置提供程序。 [提交](https://github.com/open-webui/open-webui/commit/5cdcdbaeec9fc8156721c38c33ec37956962871c)，[#12945](https://github.com/open-webui/open-webui/pull/12945)
- 🏷️ **更多自定义标头变量。** 自定义请求标头现在支持“{{USER_MESSAGE_ID}}”、“{{USER_MESSAGE_PARENT_ID}}”和“{{TASK}}”，让连接的服务区分真实的用户消息和自动后台请求（例如标题、标签和后续生成）。 [提交](https://github.com/open-webui/open-webui/commit/f85cb27ef835aa76aff7de6176bf2159ba392061)
- 📄 **文件详细信息转发到外部文档提取器。** 外部自定义文档提取服务器现在接收文件的 ID、名称和内容类型，这些也可用作自定义标头变量，因此可以针对每个文件定制提取。 [提交](https://github.com/open-webui/open-webui/commit/b1c2536ed2f8639efade04618018e6de9b332df2)，[#26259](https://github.com/open-webui/open-webui/issues/26259)
- 🎰 **为新插槽预先选择的最后一个模型。** 当您将另一个模型添加到多模型聊天中时，该插槽现在默认为您最后选择的模型，而不是开始为空。 [#25974](https://github.com/open-webui/open-webui/pull/25974)
- ⚡ **更快的模型概述。** 管理模型概述现在通过批量查询加载其反馈历史记录和标签，因此在具有许多聊天的实例上打开速度明显更快。 [提交](https://github.com/open-webui/open-webui/commit/40c09167cd6de1c853a5dd03c88b4fdcb279dfe1)
- 🏎️ **更轻量的频道个人资料预览。** 频道中的个人资料预览现在仅当您将鼠标悬停打开一个人时才加载人员的详细信息，而不是预先为每条消息获取它们。 [提交](https://github.com/open-webui/open-webui/commit/4f69c33de0e9a8fde4f16d0b2f1ed8aac8741772)
- ↩️ **将权限重置为默认值。** 组和默认权限对话框现在包含一个按钮，可一步将所有权限恢复为其内置默认值。 [#25931](https://github.com/open-webui/open-webui/pull/25931)
- 📥 **聊天导入权限。** 管理员现在可以通过新的“允许聊天导入”权限来控制是否允许用户导入或克隆聊天。 [提交](https://github.com/open-webui/open-webui/commit/edf3ae920989b01383be543e7379d3eade03c0b6)、[提交](https://github.com/open-webui/open-webui/commit/9ccda6715c3b2dc2cbc1302d2396b2f0233bdea8)、[提交](https://github.com/open-webui/open-webui/commit/ed4cb358a06fc6962b378f20ef846fd2b0af90bc)、[#25927](https://github.com/open-webui/open-webui/pull/25927)
- 🔔 **每组用户 Webhook 权限。** 管理员现在可以使用新的“用户 Webhooks”权限来控制哪些用户可以设置个人通知 Webhook。 [#25923](https://github.com/open-webui/open-webui/pull/25923)
- ✍️ **可自定义的自动完成提示。** 管理员现在可以从管理界面设置中设置用于自动完成生成的自定义提示模板。 [提交](https://github.com/open-webui/open-webui/commit/4dbb2f94a66d6e0035e2da857ddb6a841a68f862)，[#25879](https://github.com/open-webui/open-webui/pull/25879)
- 🔑 **可配置的密钥长度。** 现在可以使用新的环境变量设置自动生成的密钥长度，而不是始终使用固定长度。 [提交](https://github.com/open-webui/open-webui/commit/e473ab1231abedcb188c259b42ae7f2390739223)，[#25906](https://github.com/open-webui/open-webui/pull/25906)
- 🏟️ **可通过环境配置的竞技场评估模型。** 现在可以通过环境变量定义竞技场评估模型，而以前无法以这种方式设置。 [提交](https://github.com/open-webui/open-webui/commit/fd56086e793a0eceb07a55ff972a5492d8f8a285)
- ✏️ **从菜单编辑提示。** 提示列表现在每个提示的菜单中都有一个“编辑”选项，可将您直接带到其编辑器。 [#25789](https://github.com/open-webui/open-webui/pull/25789)
- 📋 **克隆自动化。** 自动化的菜单中现在有一个克隆选项，因此您可以复制一个作为起点。 [#25790](https://github.com/open-webui/open-webui/pull/25790)
- 🔁 **重复日历事件。** 日历事件编辑器现在包含重复选项，因此事件可以按计划重复发生。 [#25865](https://github.com/open-webui/open-webui/pull/25865)
- 🧷 **独立的技能导入和导出权限。** 管理员现在可以独立控制技能的导入和导出，并具有新的技能导入和导出权限。 [#25921](https://github.com/open-webui/open-webui/pull/25921)
- 🏷️ **按标签过滤管理模型。** 管理模型设置页面现在有一个标签过滤器，可通过基本模型标签缩小模型列表。 [提交](https://github.com/open-webui/open-webui/commit/2bdd2ab94eefd3d75dd6511c445e302f82221b5d)
- 📊 **可排序的分析聊天列表。** 分析中的模型聊天列表现在具有可排序的列标题，因此您可以按标题、上次更新或用户对其进行排序。 [提交](https://github.com/open-webui/open-webui/commit/3730a9eaac68dff60b3ae5b4ed160b91480d66eb)，[#26168](https://github.com/open-webui/open-webui/pull/26168)
- 🔐 **Argon2 密码哈希选项。** 密码哈希现在可以通过可配置的算法设置使用 Argon2，消除了之前默认设置的 72 字节密码长度限制。 [提交](https://github.com/open-webui/open-webui/commit/33cd199e6dffddd4ee8974af41ebb894871d74c1)、[提交](https://github.com/open-webui/open-webui/commit/a70a6589afad0b429cdd77afa62163391f406a87)、[#25656](https://github.com/open-webui/open-webui/pull/25656)
- 🔐 **静态阀门值的可选加密。** 现在可以通过新的选择加入设置对工具和功能阀门值进行静态加密，现有存储值会自动迁移，因此 API 密钥等敏感设置不会以明文形式保存。 [提交](https://github.com/open-webui/open-webui/commit/b4073f6378392b23a3954e33031bf5e1d98e090a)，[#23721](https://github.com/open-webui/open-webui/pull/23721)
- 🗄️ **AWS RDS IAM 数据库身份验证。** 数据库连接现在可以通过新的选择加入设置使用 AWS RDS IAM 令牌进行身份验证，而不仅仅是静态密码。 [提交](https://github.com/open-webui/open-webui/commit/c0c6c2181a8dc57b62e8a5eabd550bf89db7ffed)，[#23580](https://github.com/open-webui/open-webui/pull/23580)
- 🔓 **使用 OAuth 2.1 工具对模型进行自动身份验证。** 当模型使用需要 OAuth 2.1 的工具时，Open WebUI 现在会自动启动授权流程，而不是使请求失败。 [提交](https://github.com/open-webui/open-webui/commit/ae5d23f2267845922c2acb507a4a432908d03b41)、[#23325](https://github.com/open-webui/open-webui/pull/23325)、[#23272](https://github.com/open-webui/open-webui/issues/23272)
- 🔤 **用于基于标记的文本拆分的自定义标记生成器。** 基于标记的文档拆分现在可以使用可配置的 Hugging Face 标记生成器模型，因此分块可以与您使用的模型的标记生成器相匹配。 [提交](https://github.com/open-webui/open-webui/commit/bb6b2db88b1e82395531f67db4f6accd49d8b9eb)，[#24139](https://github.com/open-webui/open-webui/pull/24139)
- 🔒 **限制从 MCP 服务器请求的 OAuth 范围。** 新设置允许管理员在连接到 MCP 服务器时限制哪些 OAuth 范围打开 WebUI 请求。 [提交](https://github.com/open-webui/open-webui/commit/7be009649a0a94008484335c492ab0af18fde41f)、[#25981](https://github.com/open-webui/open-webui/pull/25981)、[#25978](https://github.com/open-webui/open-webui/issues/25978)
- 🧩 **过滤器出口挂钩现在可以在 API 请求和响应上运行。** 过滤器函数的出口挂钩现在可以为直接 API 调用者运行，包括流响应，因此响应后处理不仅限于 Web 界面；这是由新设置控制的，并且默认情况下处于打开状态。 [提交](https://github.com/open-webui/open-webui/commit/390e200f76877b185002c88b4dda27b123d29e83)，[#25650](https://github.com/open-webui/open-webui/pull/25650)
- 🖥️ **终端侧边栏自动打开的设置。** 新的界面设置控制当您选择终端时文件侧边栏是否自动打开。 [提交](https://github.com/open-webui/open-webui/commit/958237473f8cbde97eb0df8c21f2a4de088c4459)，[#25628](https://github.com/open-webui/open-webui/pull/25628)
- 📌 **通过拖动重新排序固定笔记。** 现在可以拖动侧栏中的固定笔记来重新排序。 [#25677](https://github.com/open-webui/open-webui/pull/25677)
- 🔎 **搜索中的聊天操作。** 搜索对话框现在在每个结果上提供上下文菜单，因此您可以直接从搜索中对聊天进行操作。 [#25490](https://github.com/open-webui/open-webui/pull/25490)
- 🔎 **聊天搜索结果中的片段。** 现在搜索聊天会在每个结果中显示匹配内容的片段，以便您一眼就能区分结果。 [提交](https://github.com/open-webui/open-webui/commit/0eba3df1199f56e8ac77213772a41313a3237296)、[提交](https://github.com/open-webui/open-webui/commit/67a7b23b85d2e3ce6b094b682ba9f07dc453d355)、[提交](https://github.com/open-webui/open-webui/commit/8927c9bb3d4b04f4fc8e443f42089f2a551276bc)、[#25178](https://github.com/open-webui/open-webui/pull/25178)
- 📝 **格式化阀门描述。** 工具和功能的阀门描述现在呈现 Markdown，因此它们可以包含格式和链接。 [提交](https://github.com/open-webui/open-webui/commit/7c0b0e42f5afb0e9c39bd2d42e4822d64d0c7b3e)
- 🔽 **阀门选项的下拉输入。** 阀门和确认输入现在可以将一组选项呈现为下拉列表而不是自由文本，从而使固定选择设置更易于配置。 [提交](https://github.com/open-webui/open-webui/commit/422a4768ea7428b5dd6d401ccfba00e1e86eb98a)，[#26278](https://github.com/open-webui/open-webui/pull/26278)
- 🔌 **控制 MCP 连接器的 OAuth 资源参数。** MCP 连接器现在可以设置为始终发送、从不发送或自动决定是否包含 OAuth 资源参数，以便它们与拒绝它的提供商合作。 [提交](https://github.com/open-webui/open-webui/commit/5576e6ed8a80a4032b7c6cb3ee0cda0254019355)
- 🔎 **SERPHouse 网络搜索。** SERPHouse 现在可以用作网络搜索提供商。 [提交](https://github.com/open-webui/open-webui/commit/3a232f5e9a4d31a6b74cb34d007b581feeb2f005)、[提交](https://github.com/open-webui/open-webui/commit/dd4f43bfdb793c4276e6468b65fc32d9b881578a)、[#26254](https://github.com/open-webui/open-webui/pull/26254)
- 🔎 **Microsoft Web IQ 网络搜索。** Microsoft Web IQ 现在可以用作网络搜索提供程序，并具有匹配的页面浏览加载器。 [#26178](https://github.com/open-webui/open-webui/pull/26178)

### 已修复

- 🛡️ **安全建议**：此版本包括安全和访问控制修复。我们建议您尽早更新生产部署。并非此版本中的所有安全修复程序都可以在“已修复”部分中列出 - 有些修复程序可能会暂时保留，以便管理员有时间进行升级。 [咨询](https://github.com/open-webui/open-webui/security)
- 🔐 **上传时强制执行知识库写入权限。** 将上传的文件附加到知识库现在需要与 API 的其余知识相同的写入权限，因此没有写入权限的用户无法再通过引用其 ID 将文件添加到集合中。 [#26001](https://github.com/open-webui/open-webui/pull/26001)
- 🗝️ **在所有关键端点上强制执行 API 密钥权限。** 查看和删除 API 密钥现在尊重 API 密钥权限，与已应用于密钥创建的保护相匹配。 [#25992](https://github.com/open-webui/open-webui/pull/25992)
- 🔊 **在语音端点上强制执行文本转语音权限。** OpenAI 语音代理现在尊重文本转语音权限，因此不允许使用该功能的人无法再使用它。 [#25993](https://github.com/open-webui/open-webui/pull/25993)
- 🎲 **在竞技场回退时强制执行模型访问。** 通过后台和任务请求上的竞技场模型间接访问模型现在会强制执行该模型的访问规则，从而关闭可能绕过它们的路径。 [#26046](https://github.com/open-webui/open-webui/pull/26046)
- ⏰ **针对停用帐户的计划自动化停止。** 计划自动化现在会在每次运行之前重新检查所有者的帐户状态和权限，因此当帐户停用或自动化访问权限被撤销时，它们会停止。 [#26047](https://github.com/open-webui/open-webui/pull/26047)
- 🚧 **在代理后面拒绝大量编码的路径。** 在重复解码后仍然编码的请求路径现在被拒绝而不是转发，从而防止可能漏掉的路径遍历。 [#26050](https://github.com/open-webui/open-webui/pull/26050)
- 🌐 **图像 URL 获取针对 DNS 重新绑定进行了强化。** 现在，获取用户提供的图像 URL 会在连接时重新检查目标地址，从而关闭可用于到达公共主机名后面的内部地址的路径。 [#25960](https://github.com/open-webui/open-webui/pull/25960)
- 🛂 **Web 获取阻止列表与主机名匹配。** Web 获取过滤器现在将条目与域边界上的请求主机名进行匹配，因此被阻止的主机不再能够通过添加的路径溜过，并且相似的域不再被误认为是允许的域。 [#25949](https://github.com/open-webui/open-webui/pull/25949)
