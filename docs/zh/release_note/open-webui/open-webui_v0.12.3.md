# open-webui v0.12.3

### 添加

- 🔐 **端到端加密聊天。** 私信和私人群组频道现在可以进行临时的端到端加密聊天：成员在频道菜单中选择加密聊天，其他成员会看到带有加入链接的“加密聊天正在进行中”，最大 16 KiB 的消息在浏览器中使用 MLS 加密，并且仅通过服务器而不保存，参与者可以通过比较代码来相互验证并查看其他人何时打字，当您离开或离开时，聊天将被清除当频道成员资格或访问权限发生变化时重新加载并结束。管理员在“管理设置”>“常规”>“加密通道”下或使用“ENABLE_ENCRYPTED_CHANNELS”将其打开，并授予它新的加密通道权限，默认情况下关闭或使用“USER_PERMISSIONS_FEATURES_ENCRYPTED_CHANNELS”设置，并且它需要 Websocket 服务器注销和生产中的 HTTPS 连接。 [提交](https://github.com/open-webui/open-webui/commit/7dc91de86c41866f4170602f074c39dbf1609377)、[提交](https://github.com/open-webui/open-webui/commit/0b3812f2857b4c65fd1ab931f40de4f1264edc46)、[提交](https://github.com/open-webui/open-webui/commit/b1e876896caee5bf30a010fb414a9249ec7f59a2)、[提交](https://github.com/open-webui/open-webui/commit/4dedaaf6e2292c2c4fb48668eee1292cfd7de2d0)
- 📡 **使用 Redis 实现更轻量的流式传输。** 使用 Redis，流式回复现在存储在自己的密钥下，并且新文本会附加到其中，而不是在每次更新时将整个回复重写为共享哈希，并且在升级期间仍会读取在旧实例上启动的回复；打开房间频道后，每个实例现在仅订阅与其连接的人员的房间，因此 Redis 不再向其发送其不服务的聊天的实时更新。 [提交](https://github.com/open-webui/open-webui/commit/f5a26f53a089eeb9683ead687a1fd3e9125132a6) [提交](https://github.com/open-webui/open-webui/commit/362b01d0b2ba677858a5af85caf3dd8544c5e6df) [#32478](https://github.com/open-webui/open-webui/issues/32478)
- 🔍 **比较视图选项和撤消。** 比较修订视图有一个比较选项菜单，可以忽略空格、忽略强调标记或仅显示折叠未更改的行的更改，还有一个撤消按钮，可以按顺序退回两个窗格中的编辑，以及现在按匹配文本排列的已更改行。 [提交](https://github.com/open-webui/open-webui/commit/d0750f6617acd3b57ce58ba1d543c37e6c793c8d)、[提交](https://github.com/open-webui/open-webui/commit/a087aa1deb4d999b122f882335fd08af8f06e72c)、[提交](https://github.com/open-webui/open-webui/commit/10ce0d23651fc2c96fd0d276147cd48105e21b84)、[提交](https://github.com/open-webui/open-webui/commit/3288fe010a5e8f8a59e1e5d2262957d175e56bde)
- 📝 **更丰富的 Markdown 文件预览。** 在终端文件浏览器中打开的 Markdown 文件现在使用与聊天回复相同的渲染器进行渲染，包括数学、脚注、突出显示的代码块、警报和美人鱼图，以及与 Markdown 混合的 HTML 块，布局为紧凑文档，并且可以勾选可编辑文件中的任务列表复选框以保存对文件的更改。 [提交](https://github.com/open-webui/open-webui/commit/c9a52208da9e8deeac6f2df7fcacbe519c2acb29) [提交](https://github.com/open-webui/open-webui/commit/7c3980338b72c5faa7e7f3a088deb477644fef40) [提交](https://github.com/open-webui/open-webui/commit/15ac5163ea00a934ec0c68d2bb7f6bc5c655223e) [#32514](https://github.com/open-webui/open-webui/issues/32514)
- 👀 **共享聊天中的实时协作者。** 聊天的顶部栏现在显示当时打开相同聊天的其他人的照片，最多三个，其余的计数，以及可打开其个人资料卡的协作者列表。 [提交](https://github.com/open-webui/open-webui/commit/4dedaaf6e2292c2c4fb48668eee1292cfd7de2d0)、[提交](https://github.com/open-webui/open-webui/commit/8191ac30dd79b4a39130fe83ffc16035776be484)、[提交](https://github.com/open-webui/open-webui/commit/8e9519240fcdcd568a9b951ba06e523c58e68350)
- ✏️ **在带有回复的共享聊天中编辑和重新生成。** 在允许回复的共享文件夹的聊天中，可以编辑消息的人现在可以编辑提示以启动新分支并重新生成任何回复，不仅回复自己的消息，而且查看聊天的其他人也会停留在他们选择的分支上。 [提交](https://github.com/open-webui/open-webui/commit/2a6e0da057d3b6eb6ba506346c4db788cab735f0)、[提交](https://github.com/open-webui/open-webui/commit/788a61180be76aef27761b051300d6eefa715947)
- 🗄️ **文件夹编辑器中的文件夹访问。** 现在共享文件夹是通过“编辑文件夹”对话框中的“访问”按钮而不是文件夹菜单中的“共享”项进行的，可以在添加任何人之前设置共享模式，并且子文件夹注意授予父文件夹的访问权限也适用于它们。 [提交](https://github.com/open-webui/open-webui/commit/f4557ca06b8331c8914bac9e8f54ce63b0445c21)、[提交](https://github.com/open-webui/open-webui/commit/4a70253bc8586ad1d2a97241665b2060324bab37)
- 🔎 **工作区搜索。** 搜索窗口现在可以搜索您的聊天记录、与您共享的文件夹中的聊天记录、与您共享的聊天记录、频道和直接消息以及注释，并可在一个位置搜索内容类型、文件夹或频道、内容是否由您创建或与您共享的过滤器、突出显示的匹配项、使用 Ctrl/Cmd + Enter 预览每个结果、复制链接以及打开线程的频道结果滚动到匹配的消息。 [提交](https://github.com/open-webui/open-webui/commit/b4db56ae96651d926adb4aefc6ec1275f35c6b6f)、[提交](https://github.com/open-webui/open-webui/commit/ef28e99e587a2845a2852bb6ab8c182dc1588980)、[提交](https://github.com/open-webui/open-webui/commit/1a1a81d8e09330900ac74e4bc97a48e1e0d52a8a)
- 💭 **文档预览中的评论。** 在终端文件浏览器中打开的 Word、Excel、PowerPoint 和 PDF 文件现在会显示其评论和回复，标记它们在文档中的位置，并通过悬停或点击标记来打开，旧的 .xls 电子表格现在也可以预览。 [提交](https://github.com/open-webui/open-webui/commit/ba0b2169e1799e1915c6dbb071c56d54896467fb)
- 🧹 **清除输入选择快捷方式。** 从聊天输入中清除模型覆盖、选定的工具和过滤器以及网络搜索、图像生成和代码解释器切换现在是您可以在“设置”>“快捷方式”中更改的快捷方式，默认情况下仍然是“退出”。 [提交](https://github.com/open-webui/open-webui/commit/9cf48f4fb0a8aef30010294912a3a5674850beaf)
- 🙋 **从文件浏览器询问文件。** 在终端文件浏览器中打开的文件中选择文本现在会显示一个“询问或编辑...”框，该框将您的请求发送到带有附加文件和引用的选择的模型，以便它可以在同一终端中回答或编辑该文件；未保存的编辑可以在发送之前保存，并且在回复运行时发送的请求在队列中等待。 [提交](https://github.com/open-webui/open-webui/commit/af34515131d9efd41cfeae5c1ea50a7f7ed84443)
- ☁️ **Google 云端硬盘访问权限仅限于所选文件。** Google 云端硬盘选择器现在仅要求访问用户选择的文件，而不是对其整个云端硬盘的读取权限，因此自托管安装不再需要 Google 的限制范围验证，并且用户不再看到“Google 尚未验证此应用程序”警告。 [#32531](https://github.com/open-webui/open-webui/pull/32531) [提交](https://github.com/open-webui/open-webui/commit/ed5c2d7522c126b6163aad56762790025b31ec0b) [#29537](https://github.com/open-webui/open-webui/issues/29537)
- 📜 **长状态行的全文。** 回复上方的状态行，例如函数发送的令牌使用摘要，现在可以通过 clicked 显示其全文，并且通过多个状态行，历史记录可以完整显示每个条目。 [#32532](https://github.com/open-webui/open-webui/pull/32532) [提交](https://github.com/open-webui/open-webui/commit/291b57bec24ec670050b996ede45ea6dd56c7f9f) [#30056](https://github.com/open-webui/open-webui/issues/30056)
- 📏 **技能读取限制。** 管理员可以在“管理设置”>“常规”下使用“技能读取限制”和“技能预览长度”或“SKILL_CONTENT_MAX_CHARS”和“SKILL_PREVIEW_MAX_CHARS”环境变量（默认为 20000 和 5000）设置模型一次读取技能的字符数以及较长指令的预览时间。 [提交](https://github.com/open-webui/open-webui/commit/92e64c1d59cdd99b5f33a108186a1d368daab964)
- 🔄 **一般改进。** 在整个应用程序中实施了各种改进，以增强性能、稳定性和安全性。
- 🌐 **翻译更新。** 葡萄牙语（巴西）、中文（繁体）、阿拉伯语、孟加拉语、希伯来语、格鲁吉亚语、旁遮普语、斯洛伐克语、塞尔维亚语、乌尔都语、乌兹别克语和越南语的翻译得到增强和扩展。 [#32440](https://github.com/open-webui/open-webui/pull/32440)、[#32482](https://github.com/open-webui/open-webui/pull/32482)、[#32501](https://github.com/open-webui/open-webui/pull/32501)

### 已修复

- 🧾 **审核日志中的 API 密钥标头请求。** 使用 x-api-key 标头中的 API 密钥进行身份验证的请求（如 Anthropic SDK 发送的那样），或使用“CUSTOM_API_KEY_HEADER”设置的标头中的请求现在显示在密钥所有者下的审核日志中，并且使用错误密钥的失败尝试在没有用户的情况下进行记录，审核日志中缺少这些请求。 [#32443](https://github.com/open-webui/open-webui/pull/32443)，[提交](https://github.com/open-webui/open-webui/commit/f7c8ad012ddcf458c39cdf8a96b41c410655196c)
- 📚 **知识共享不断重命名。** 具有写入权限的协作者编辑共享知识库的名称或描述时，不再关闭他们无法自行设置的共享，例如公共。 [#32450](https://github.com/open-webui/open-webui/pull/32450)、[提交](https://github.com/open-webui/open-webui/commit/08f6023427cdad6179b8fc5f656c99f3f0ad44f8)、[#32449](https://github.com/open-webui/open-webui/issues/32449)
- 🤝 **提示和工具共享保持保存状态。** 具有写入权限的协作者保存共享提示或工具时不再将其设为对所有人私有；他们无法自行设置的共享现在被保留。 [#32493](https://github.com/open-webui/open-webui/pull/32493)、[提交](https://github.com/open-webui/open-webui/commit/5dff6489d2f6a6c33c49ca035e5384ff5dd29006)、[#32492](https://github.com/open-webui/open-webui/issues/32492)
- 📄 **长笔记和聊天的 PDF 导出。** 长笔记和聊天现在下载为 PDF，其中 Firefox 因“画布超出最大尺寸”而失败，而 Chrome 保存了黑色 PDF。 [#32459](https://github.com/open-webui/open-webui/pull/32459)、[提交](https://github.com/open-webui/open-webui/commit/f78e46ef44ecc1a7ea8a4951edc17e22bf1d5cad)、[#18334](https://github.com/open-webui/open-webui/issues/18334)、[#26373](https://github.com/open-webui/open-webui/issues/26373)、[#19583](https://github.com/open-webui/open-webui/discussions/19583)
- ⏩ **继续对多个模型进行响应。** 继续响应现在会继续 clicked 下的回复，在与多个模型的聊天中，它可以扩展另一个模型的回复。 [#32456](https://github.com/open-webui/open-webui/pull/32456)、[提交](https://github.com/open-webui/open-webui/commit/3c82fda4e813e00d33ca16a8ddd61596296a2066)、[#32455](https://github.com/open-webui/open-webui/issues/32455)
- 🏷️ **导入的聊天的标签。** 导入的聊天现在显示其标签，并且标签显示在标签建议中，其中帐户中缺少的标签在导入时不会创建。 [#32454](https://github.com/open-webui/open-webui/pull/32454)、[提交](https://github.com/open-webui/open-webui/commit/fd47370e851c3fcb55ba69aec39488aaec7f4b02)、[#32453](https://github.com/open-webui/open-webui/issues/32453)
- 🔖 **已存档聊天的标签。** 在侧边栏搜索所有聊天已存档的标签不再删除该标签，该标签在聊天取消存档时会丢失其原始名称。 [#32452](https://github.com/open-webui/open-webui/pull/32452)、[提交](https://github.com/open-webui/open-webui/commit/58b821a4642480b2202320b45146bace72962f3b)、[#32451](https://github.com/open-webui/open-webui/issues/32451)
- ⌨️ **频道中的输入法。** 使用输入法（例如日语、中文或韩语）输入时按 Enter 确认单词，不再在单词输入之前发送和清除频道消息。 [提交](https://github.com/open-webui/open-webui/commit/9d0aa791ad70ef2a7771c74955e2c9304021609e)
- 🖱️ **离开聊天后出现滚动错误。** 在打开 Notes 之前滚动聊天不再在浏览器控制台中记录 TypeError。 [#32458](https://github.com/open-webui/open-webui/pull/32458)、[提交](https://github.com/open-webui/open-webui/commit/9245e31ccba8e464054297b1f3660ab3e7f77969)、[#32457](https://github.com/open-webui/open-webui/issues/32457)
- 📐 **新聊天中的第一轮稳定。** 新聊天中的最新消息和回复现在在保存聊天和重新加载消息列表时保持其真实高度，因此第一轮视图不再跳跃。 [提交](https://github.com/open-webui/open-webui/commit/bbccff89c1cf318c21cd9eeb4228f98882a33736)
- 💬 **在频道中发送。** 当服务器确认时，您自己的频道消息现在会保持在原位，而不是重新绘制，并且频道会在您发送时滚动到您的新消息，它可以在其中跳转或保留旧的滚动位置。 [提交](https://github.com/open-webui/open-webui/commit/99457b373e6b81fe50df0d18a75d126706237841)
- 📂 **新聊天中的终端文件夹。** 在新聊天中，您附加的文件将上传到终端文件浏览器中打开的文件夹中，创建聊天后文件浏览器将保留在该文件夹中，上传内容可以转到默认文件夹，浏览器会跳回该文件夹。 [提交](https://github.com/open-webui/open-webui/commit/7ca62fdf93f6177e929cca20c712f3d958e1d935)
- 📁 **共享文件夹设置和访问。** 编辑共享文件夹的模型、系统提示或文件不再重置其共享模式，并且以写访问权限共享的文件夹中的子文件夹在直接以读访问权限共享时仍保持可写状态。 [提交](https://github.com/open-webui/open-webui/commit/f4557ca06b8331c8914bac9e8f54ce63b0445c21), [提交](https://github.com/open-webui/open-webui/commit/4a70253bc8586ad1d2a97241665b2060324bab37)
- 🔑 **使用 client_secret_basic 进行 OAuth 令牌刷新。** 当“OAUTH_TOKEN_ENDPOINT_AUTH_METHOD”为 cliZent_secret_basic 时，令牌刷新现在会像登录一样在 Basic 标头中发送 client 凭据，其中仅接受 Basic 的提供商拒绝刷新，并且 Open WebUI 删除了用户的 OAuth 令牌，从而破坏了模型在下次登录之前使用它们的连接和工具服务器。 [#32507](https://github.com/open-webui/open-webui/pull/32507)、[提交](https://github.com/open-webui/open-webui/commit/ae6793dd4f209455387bcc418a5c775eec0b16c3)、[#32506](https://github.com/open-webui/open-webui/issues/32506)
- 🛠️ **登录后的 OAuth 工具。** 当模型具有默认工具时，OAuth MCP 工具现在在登录重定向后保持打开状态，并使用 ?tools= 链接打开列出的工具。 [#32488](https://github.com/open-webui/open-webui/pull/32488)、[提交](https://github.com/open-webui/open-webui/commit/81722918384cb56608a2ab26ca03059b3a811758)、[#32476](https://github.com/open-webui/open-webui/issues/32476)
- 🔤 **保留管理员默认字体。** 保存设置 > 界面不再将管理员的默认字体和图像压缩大小存储为您自己的设置，因此以后对这些默认值的更改仍然可以到达您。 [#32497](https://github.com/open-webui/open-webui/pull/32497)、[提交](https://github.com/open-webui/open-webui/commit/e979a1f9e2c86d60c7ee3ba48fb0dc42a3b65aa0)、[#32496](https://github.com/open-webui/open-webui/issues/32496)
- 🔊 **用缓慢的语音大声朗读。** 当语音引擎生成下一句的时间比播放当前句子所需的时间长时，朗读在第一句之后不再停止。 [#32484](https://github.com/open-webui/open-webui/pull/32484)、[提交](https://github.com/open-webui/open-webui/commit/7da8653e71cda807609d9ec64912cd319c0d6ccf)、[#32446](https://github.com/open-webui/open-webui/issues/32446)
- 🖼️ **每个聊天终端上的内联 HTML 预览。** 当打开终端聊天上下文为每个聊天时，回复中的内联 HTML 预览现在会在聊天自己的终端工作区中查找文件，其中显示“找不到文件”。 [#32485](https://github.com/open-webui/open-webui/pull/32485)、[提交](https://github.com/open-webui/open-webui/commit/ec39df7da56f6947fde17a9be2c146251f891b26)、[#32477](https://github.com/open-webui/open-webui/issues/32477)
