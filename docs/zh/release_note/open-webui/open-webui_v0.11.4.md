# open-webui v0.11.4

### 添加

- 📉 **小得多的 slim 镜像。** slim 版本现在大小约为 175 MB，比上一个版本小了近 89%，本地模型、它们周围的软件包以及安装它们的工具都消失了；实例行为方式的变化在下面的“更改”和文档中列出。 [提交](https://github.com/open-webui/open-webui/commit/cb942bb94c8dc7941336088fb3392e2398ff56c1)、[提交](https://github.com/open-webui/open-webui/commit/d27aa72ab4a7b5632b4ad49e8467081ad3d7ebb4)
- 📦 **较小的标准图像。** 该图像不再带有 Python 的第二个副本、从未加载的两组字体、未导入的包或安装它们的工具，从而比标准构建节省了约 170 MB 的空间。 [#29731](https://github.com/open-webui/open-webui/pull/29731)、[#29723](https://github.com/open-webui/open-webui/pull/29723)、[#29725](https://github.com/open-webui/open-webui/pull/29725)、[#29726](https://github.com/open-webui/open-webui/pull/29726)、[#29728](https://github.com/open-webui/open-webui/pull/29728)、[提交](https://github.com/open-webui/open-webui/commit/91f8775b28b52c9ae7f2ab990cf2490bda8055d6)、[提交](https://github.com/open-webui/open-webui/commit/98fcb844e1b19f7dd6289af26273cdec5447dc52)、 [提交](https://github.com/open-webui/open-webui/commit/508de20779168003e538bb936b49a31d4a8fb8bb)、[提交](https://github.com/open-webui/open-webui/commit/a1c02098aa2687c72482a59117efe643b785df51)
- 🧑‍💻 **来自终端的技能。** 连接的终端服务器提供的技能现在位于工作区技能旁边，在任何地方都可以选择技能 - “$”和“/”菜单、集成菜单和技能面板，每个都标记为终端 - 并且使用方式相同：选择一个将其指令、其文件夹及其附带的文件放在模型前面，仅被告知存在技能的模型可以自行打开它。它们遵循选择的终端，并在终端发生变化时清除。 [提交](https://github.com/open-webui/open-webui/commit/e69236bccb1e12d14045b09b76ebac0490014851)
- 📔 **终端指令文件。** 现在，使用终端的模型将位于该终端主目录中的 AGENTS.md 交给您，在每次开始时重新读取，以便您保存在工作旁边的指令无需粘贴即可到达模型。 [提交](https://github.com/open-webui/open-webui/commit/946be432375057dc18dbcc7c3513feb322a83a4b)、[提交](https://github.com/open-webui/open-webui/commit/f6922a4c4293449805938c80fbe54174994a1fc6)
- 📇 **自动技能发现。** 您可以达到的每一项技能现在都按名称和描述列出到模型中，并且仅在决定使用一项技能时才加载其全文；之前，您在消息框中未选择的技能对它来说是不可见的，这适用于具有内置工具的模型。 [提交](https://github.com/open-webui/open-webui/commit/e69236bccb1e12d14045b09b76ebac0490014851)
- 🌄 **模型背景图像。** 工作区模型现在可以携带背景图像，在其编辑器中上传并在选择该模型时在聊天后面绘制，位于文件夹自己的背景下方和您个人的背景上方，并且它通过导出和导入与模型一起移动。 [提交](https://github.com/open-webui/open-webui/commit/66addbd6b47bfb25cf9aa37ec70d24db5b28b6b6)
- 📓 **从聊天中创建技能。** 在已包含内容的聊天中键入“/skills:create”，并选择终端，会将您刚刚经历的工作流程转变为可重用技能，写入该终端的根工作目录下的“.agents/skills”，而不是 shell 恰好位于其中的任何文件夹，并根据 Open WebUI 的技能标准编写。 [提交](https://github.com/open-webui/open-webui/commit/113c56fc8c1986359556107a20e206159ca32f59)、[提交](https://github.com/open-webui/open-webui/commit/924a4a10fbd0be508a69faf66bf08ac9761bc24d)、[提交](https://github.com/open-webui/open-webui/commit/58078ab3045cc7aee409d9215f68adf0e02c9165)、[提交](https://github.com/open-webui/open-webui/commit/d25f6c7135e0aee93dc2c840ce320d97617a6e47)、[提交](https://github.com/open-webui/open-webui/commit/a096961a31499be23890b98a040ecf2917405568)
- 🖥️ **每个命令的终端选项卡。** 终端窗格现在为模型与您自己的 shell 一起运行的每个命令提供一个选项卡，因此您可以在它们运行时观察它们，在它们之间移动并自己获取 shell，每个选项卡都使用生成它的命令打开。打开该窗格会将您置于一个选项卡中，在没有任何其他运行的情况下启动 shell，然后关闭最后一个选项卡会再次折叠该窗格。 [提交](https://github.com/open-webui/open-webui/commit/54a7a7a7ce22725074c29c7e827446f5dce1421c)、[提交](https://github.com/open-webui/open-webui/commit/f3eade42aead0a3b96ada3a300d6c294c89f74a8)、[提交](https://github.com/open-webui/open-webui/commit/de1203f9b5d3d8b2a84bf5c89d1c61542469367a)、[提交](https://github.com/open-webui/open-webui/commit/675b9839f17df94f866c871cbdb9881323a18a8a)
- 📂 **文件夹上传到终端。** 终端旁边的文件浏览器现在会获取一个文件夹，将其拖放到该文件夹​​上或从其菜单中的“上传文件夹”条目中选取，然后重建其中的内容、子文件夹和所有内容，而在拖放之前，仅上传位于顶部的文件。 [提交](https://github.com/open-webui/open-webui/commit/f80ef8bd001d7ef650fb278d6fbd05bea4afad0f)、[提交](https://github.com/open-webui/open-webui/commit/4cc0d48b4d83503199bcc5f2322881722971a499)、[提交](https://github.com/open-webui/open-webui/commit/674760bfc1122e0a19fe299e05a86d1cbb528e6f)
- ⚖️ **并排文件比较。** 在文件浏览器中选择两个文件会点亮一个“比较”按钮，将它们并排或一个放在另一个之上，对行进行编号，标记添加和删除的内容到行中发生更改的部分，对两个文件进行计数，并让您交换哪个是哪个或在其中保留空格，这是它记住的选择；太旧而无法进行比较的终端会这样说，而不是静静地失败。 [提交](https://github.com/open-webui/open-webui/commit/8556033c6b64fa53e44152ebab1f889a578529af)、[提交](https://github.com/open-webui/open-webui/commit/3808eace6c2beb1904f0f04fdd443ec544f94acb)
- 🌐 **以您的语言提供建议提示。** 全新安装现在会以界面设置的语言提供建议的入门提示，而不是为每个人提供相同的四种英语提示，并且一旦编辑了自己的建议，模型默认值面板就会返回到这些默认值。 [提交](https://github.com/open-webui/open-webui/commit/30881dbcc966206cc15fb0b2276b41d88f7c0f09)、[提交](https://github.com/open-webui/open-webui/commit/9fba2843b16a111b035949f5865e29ec6cf5ac9c)
- 📏 **Exa 结果长度上限。** 通过 Exa 进行的 Web 搜索可以将每个结果保留一定数量的字符，在管理 Web 搜索设置中将其设置为“EXA_MAX_CONTENT_LENGTH”。 [提交](https://github.com/open-webui/open-webui/commit/12b14124b9376eccf2ba7cf3dba92bc145493703)
- 🇪🇺 **欧洲网络搜索选项。** 现在可以选择 Staan 作为网络搜索提供商，为需要在欧盟内部进行搜索的部署提供一个无需自行托管的选项，可以通过管理网络搜索设置或通过“STAAN_API_KEY”、“STAAN_MARKET”和“STAAN_MAX_SNIPPETS”进行配置。 [#30138](https://github.com/open-webui/open-webui/pull/30138)、[#26006](https://github.com/open-webui/open-webui/discussions/26006)、[#30303](https://github.com/open-webui/open-webui/pull/30303)、[#30301](https://github.com/open-webui/open-webui/issues/30301)
- 🗣️ **每种语言的名称和描述。** 模型、工具、技能、功能、横幅或竞技场条目现在可以为每种语言保存一次其名称、描述、入门提示和阀门标签，在其自己的编辑器中的可搜索表中编写或作为 JSON 文件引入，如果翻译删除原始填充的占位符之一，则拒绝该文件。界面显示其设置的语言的措辞，并回退到纯文本语言没有。 [提交](https://github.com/open-webui/open-webui/commit/7b6562e3358956ec71eed05352538a646d047734)、[提交](https://github.com/open-webui/open-webui/commit/858ab727d2d80bb3c9ef40f01a32de7a12ca75c9)、[提交](https://github.com/open-webui/open-webui/commit/3facfa61d413945d7144d26b827fcce1f3aef7c5)、[提交](https://github.com/open-webui/open-webui/commit/85b11a4f3504434bd9cd0748629b8a84817fb4f2)
- ✏️ **您可以重写的界面文本。** 管理员现在可以用管理设置中面板中的语言替换界面自己的措辞语言，替换会被拒绝，因为它会删除原始填写的占位符之一。[提交](https://github.com/open-webui/open-webui/commit/67ac1a4e937271a02bfb02a330aa99dc8192cbf4)
- 🔓 **关闭登录表单。** 现在可以从身份验证设置中将要求电子邮件地址和密码的框从登录页面中删除，到目前为止，只能在服务器启动之前进行设置，留下单点登录或用于登录的目录。[提交](https://github.com/open-webui/open-webui/commit/c4a349651e34bf5d0920bb5e26707ae9961ac39f)
- 🏷️ **自定义文件元数据。** 附加到上传文件的元数据现在与文件被分割成的片段一起传输，并与检索到的源一起到达，超大和内部字段被遗漏，操作员可以在“RAG_SOURCE_METADATA_KEYS”中命名模型本身可以在文本旁边看到哪些字段。 [#29499](https://github.com/open-webui/open-webui/pull/29499)、[#29486](https://github.com/open-webui/open-webui/issues/29486)、[提交](https://github.com/open-webui/open-webui/commit/894655f66b9563890e63c76090ddecc90a311eb2)、[#29502](https://github.com/open-webui/open-webui/pull/29502)、[#29696](https://github.com/open-webui/open-webui/pull/29696)
- 🗑️ **快速删除快捷方式。** 在列表或网格中的注释上或在自动化页面上的一行上按住 Shift 键，将其尾随控件变成删除按钮，删除一个 click 中的条目，而不是菜单及其确认所要求的三个条目。 [#29635](https://github.com/open-webui/open-webui/pull/29635)、[#29633](https://github.com/open-webui/open-webui/issues/29633)、[#29640](https://github.com/open-webui/open-webui/pull/29640)、[#29637](https://github.com/open-webui/open-webui/issues/29637)
- 🔀 **差异被绘制为差异。** 回复中的差异或补丁块现在被布局为一个，其中包含文件和块标题、旧行号和新行号、添加和删除的行，直至更改的行部分，以及一个切换到纯文本和返回的按钮。 [提交](https://github.com/open-webui/open-webui/commit/254e29b9af634145dde0450451a36f0dfbd8f421)
- ✒️ **笔记的格式开关。** 您可以编辑的笔记在其菜单中带有格式开关：关闭时，您键入或粘贴的 Markdown 保持为您编写的字符，粘贴保留其纯文本，网址保留为文本，而笔记中已有的格式保持不变。 [提交](https://github.com/open-webui/open-webui/commit/d8f27e745bd31c89efa25cbe0f41bb0f70576fc5)
- 🎛️ **管理模型列表过滤器。** 管理设置中的模型页面现在可以缩小到连接提供的基本模型或工作区中内置的模型，以及启用、禁用、可见和隐藏的过滤器。 [提交](https://github.com/open-webui/open-webui/commit/9e634c0c56e0a060717f1e24a11b082daf664036)
- 🔍 **设置按名称搜索。** 设置中的搜索框现在匹配每个设置自己的名称和描述，而不是每页保留的关键字列表，无论您使用哪种语言，无论口音如何，它都会忽略您的权限不允许您更改的任何内容，并且打开结果不再清除您键入的内容。 [提交](https://github.com/open-webui/open-webui/commit/7cbaabe02fc3c7c040008e82cf85f590bd0c346a)、[提交](https://github.com/open-webui/open-webui/commit/9d98ffcddf792be8d567ea39370d39fcac649acd)、[提交](https://github.com/open-webui/open-webui/commit/c82634b9d01adadbf9780ff84a0a8168fdc4fdea)
- 🆘 **每次聊天都有一个模型。** 打开模型已停用的对话不再使其陷入无选择状态；它会回退到您的默认模型，然后是配置的默认模型，然后是第一个可用的模型，并且仍然具有实时模型的聊天会保留它。 [#29757](https://github.com/open-webui/open-webui/pull/29757)
- ⚡ **非阻塞搜索。** 搜索聊天和知识的文本，并且 grep 模型在知识库上运行，现在在服务器的其余部分而不是在其前面运行，因此长时间搜索不再让其他请求等待。 [#29621](https://github.com/open-webui/open-webui/pull/29621)，[提交](https://github.com/open-webui/open-webui/commit/d9c8de9c39fca7c4756e0f9bd599b09ebe435208)
- ✴️ **更轻量的共享笔记编辑。** 由几个人同时编写的笔记不再将每个观察者的每次击键回显到服务器一次；两个编辑之间的流量会下降一半，并且随着更多人的加入而继续下降，因此随着房间的扩大，共享笔记保持顺畅。 [#28185](https://github.com/open-webui/open-webui/pull/28185)
- 🔢 **排序的知识列表。** 模型在知识库上运行的“ls”、“tree”和“find”命令现在按名称排序，并采用“-t”、“-S”和“-r”表示最新的优先、最大的优先和反向。 [#29840](https://github.com/open-webui/open-webui/pull/29840)
- 🪪 **身份验证类型标头。** 对 OpenAI 或 Ollama 连接的请求现在携带“X-OpenWebUI-Auth-Type”，说明其背后的人是通过浏览器登录还是使用 API 密钥调用；其名称设置为“FORWARD_USER_INFO_HEADER_AUTH_TYPE”，“{{AUTH_TYPE}}”适用于自定义标头。 [提交](https://github.com/open-webui/open-webui/commit/ee46e2664ab23bacc536fed21c06ab19067d695b)
- 💡 **后续幽灵文本。** 回复完成后，它建议的第一个后续问题现在在空消息框内以及回复下方呈灰色：Tab 将其写出，然后键入您自己的任何内容将其清除。 [提交](https://github.com/open-webui/open-webui/commit/7aaa4a692e949724913834efc47c57572042703b)
- 🪵 **模型拒绝日志记录。** 因“找不到模型”而被拒绝的请求现在会写入一条警告，指出帐户、模型以及拒绝原因，而调用者看到的消息仍然像以前一样模糊。 [提交](https://github.com/open-webui/open-webui/commit/f5fcf4c89fb27ed39825875d573446fa84aa2a5b)
- 🤲 **Redis 背后的聊天请求更便宜。** 当多个服务器通过 Redis 共享其 websocket 流量时，聊天请求不再从 Redis 中提取整个共享模型列表来询问几个模型；每个工作人员都会保留自己的副本，并且仅在列表实际更改时才重新获取，因此成本不再随着配置的模型数量而增加。 [#28176](https://github.com/open-webui/open-webui/pull/28176), [#28167](https://github.com/open-webui/open-webui/issues/28167)
- 💽 **长对话流更便宜。** 写入或读取单个消息不再加载、检查和重写整个对话以更改几百个字节，因此流式传输到长聊天不会随着其增长而变得更加昂贵，并且消息事件的整个往返成本下降到数千条消息对话的一小部分。 [#28184](https://github.com/open-webui/open-webui/pull/28184), [#28169](https://github.com/open-webui/open-webui/issues/28169)
- 🧱 **就地流式附加。** 流式回复可以通过 CPython 的就地字符串附加进行组装，通过“ENABLE_CHAT_RESPONSE_STREAM_INPLACE_APPEND”打开，并在逐步推出时默认关闭。 [提交](https://github.com/open-webui/open-webui/commit/113c56fc8c1986359556107a20e206159ca32f59)、[提交](https://github.com/open-webui/open-webui/commit/924a4a10fbd0be508a69faf66bf08ac9761bc24d)、[#30066](https://github.com/open-webui/open-webui/pull/30066)
- 📘 **直接连接指导。** 个人设置中的连接和集成页面现在清楚地表明，直接连接依靠浏览器会话来保持请求运行，这适合测试和临时使用，而不是日常工作。 [提交](https://github.com/open-webui/open-webui/commit/5d66dd6ad291db17894953714c01fd4303093e7e), [提交](https://github.com/open-webui/open-webui/commit/15e2259a2ae1b7dec1f93a52078304dd3a79a14c)
- 🔄 **一般改进。** 在整个应用程序中实施了各种改进，以增强性能、稳定性和安全性。
- 🌐 **翻译更新。** 日语、繁体中文、韩语、芬兰语、俄语、乌克兰语、德语、西班牙语、葡萄牙语（巴西）、阿拉伯语、阿拉伯语（巴林）、阿塞拜疆语、保加利亚语、孟加拉语、藏语、波斯尼亚语、加泰罗尼亚语、宿务语、捷克语、丹麦语、巴斯克语、克罗地亚语、荷兰语、意大利语、土耳其语、简体中文、波斯尼亚语、加泰罗尼亚语、丹麦语、爱沙尼亚语的翻译芬兰语、加利西亚语、克罗地亚语、卡比尔语、挪威语博克马尔语、葡萄牙语（葡萄牙）、罗马尼亚语和土库曼语得到增强和扩展。

### 已修复

- 🛡️ **安全建议**：此版本包括安全和访问控制修复。我们建议您尽早更新生产部署。修复部分中并未列出此版本中的所有安全修复。有些可能会被暂时保留，以便管理员有时间进行升级。 [咨询](https://github.com/open-webui/open-webui/security)
- 🔑 **令牌不会出现在日志中。** 使用身份提供商登录时发生的故障不再将其提交的凭据写入应用程序日志，而是记录提供商及其报告的错误。 [#29709](https://github.com/open-webui/open-webui/pull/29709)
- 🔐 **登录角色映射。** 身份提供商发送的角色在某些设置中未应用，将帐户保留为默认角色，并且角色无法读取的登录现在会被拒绝而不是允许通过。 [提交](https://github.com/open-webui/open-webui/commit/10d1cfe6375f207acaa531e857edb575ded2cfc3)

- 🔌 **终端工具需要一个终端。** 提供了一种模型，可以读取您的终端并在其中输入内容，无论聊天是否已打开并连接到您的浏览器中的终端，这样它就可以找到不存在的终端；这些工具现在仅移交给聊天已打开的终端。 [提交](https://github.com/open-webui/open-webui/commit/ca1eefe2937081b010ffef3985997d17d3332fa3)、[提交](https://github.com/open-webui/open-webui/commit/1ddba7e2c6f625fbc2c131eb24d3b9775ad898ad)
- 🔤 **自定义标头编码。** 一旦填充了值，连接发送的自定义标头就会被编码，因此，携带除普通 ASCII 之外的任何内容（包括换行符）的人名或组不再中断请求或以其他方式到达另一端。 [提交](https://github.com/open-webui/open-webui/commit/7a4a4b93dca34f8ce0c481b180d3eea23797e984)
- 🆎 **Chromium 拼写检查更正。** 从消息框中浏览器自己的拼写菜单中选择建议不会执行任何操作，或者直接将拼写错误放回去，因为在选择内容上绘制了用于注释编辑器的突出显示，并在其下方重建了文本，同时保留了浏览器的拼写标记；该突出显示现在不显示在消息框中，并且仅在不使用编辑器的地方绘制。 [#29952](https://github.com/open-webui/open-webui/pull/29952)、[#29944](https://github.com/open-webui/open-webui/issues/29944)
- 🈁 **重命名时的 IME 组合。** 现在，通过使用输入法编辑器键入，使用 Enter 或 Escape 确认聊天重命名即可完成组合，而无需保存或取消重命名，按键立即生效。 [提交](https://github.com/open-webui/open-webui/commit/85146206f60a22385ed27dae30d4f00e7e2675eb)
- 🐳 **无点主机地址。** 打开本地网络抓取后，指向同一网络上的容器名称的地址（“http://apprise:8000”等）现在会被接受，而不是被视为无效而被拒绝。 [#29945](https://github.com/open-webui/open-webui/pull/29945)、[#28161](https://github.com/open-webui/open-webui/issues/28161)
- 🪧 **虚假技能提及。** 像 Perl 和其他语言一样，消息中写为“<$fh>”的内容会被视为提及技能，并在模型看到它之前悄悄删除，并作为芯片绘制在屏幕上；仅提及命名存在且已打开的技能现在被视为提及。 [提交](https://github.com/open-webui/open-webui/commit/0edd731c7422870aa109fd0b758c6d68c06655da)
- 🎒 **技能设置在保存后仍然有效。** 从编辑器中保存技能会清除它所带有的标签和翻译，并将其切换回已禁用的位置，所有这些现在在保存后仍然有效。 [#30185](https://github.com/open-webui/open-webui/pull/30185)
- 🫥 **Webhook 头像转发。** 关闭“ENABLE_PROFILE_IMAGE_URL_FORWARDING”会阻止浏览器发送到外部图片地址，并且频道 Webhook 的图片无论如何都会发送；现在，它像其他内容一样在 webhooks 对话框和消息列表中提供内置图片，其中对话框将每个查看者的浏览器直接发送到外部地址。 [#29889](https://github.com/open-webui/open-webui/pull/29889)、[#29892](https://github.com/open-webui/open-webui/pull/29892)
- 🪟 **统计窗口起源。** 与社区共享聊天统计数据的窗口接受来自任何打开它的页面的请求并回复到任何地方；现在，它仅读取和回复另一端的社区站点。 [#29918](https://github.com/open-webui/open-webui/pull/29918)
- 🖼️ **工具图像渲染。** 如果工具使用隐藏在对象或列表中的图像而不是单独的图像来回答，则图像会作为原始文本写入对话中，单个屏幕截图会花费数十万代币并排挤其他所有内容；现在，这样的图像无论位于何处都会被取出并附加到回复中，因此模型会收到图片并且您会看到它。一个较旧的错误是让每隔一个图像不受影响地通过，并且在保存的聊天中，这样的图像现在被保存为文件并被引用，而不是写入对话本身，因此聊天保持很小。 [#29665](https://github.com/open-webui/open-webui/pull/29665)、[#29208](https://github.com/open-webui/open-webui/issues/29208)、[提交](https://github.com/open-webui/open-webui/commit/d372bec70427fe2d568e052ce5e1529e2ad41da9)
- ⏱️ **停止回复状态。** 按停止将回复保存为已完成，而其中的部分仍标记为正在运行，因此一个块继续读取“正在思考...”或“正在执行...”，并在每次重新加载后以这种方式返回；现在，当回复停止时，这些部分会被关闭，并且打开的选项卡会立即解决，而不是仅在重新加载后才解决，而仍在等待您批准的工具调用会保持提示。 [#29495](https://github.com/open-webui/open-webui/pull/29495)、[#29281](https://github.com/open-webui/open-webui/issues/29281)
- 🩺 **知识同步错误。** 失败的知识库同步现在会命名它发生的文件以及浏览器所说的内容，而不是报告“访问目录时出错”之外的任何内容。 [#29507](https://github.com/open-webui/open-webui/pull/29507)
- 🚧 **终端代理限制。** 现在，传递到终端服务器的请求在针对该服务器的管理端点时被拒绝，不会继续到其他地方，并且在路径携带解析器将重写的字符的地方被拒绝。 [提交](https://github.com/open-webui/open-webui/commit/51bb8cb142f72503e861eeee25ae4dc73c26c36b)
- ⛔ **格式错误的工具调用。** 如果模型请求一个工具，而该工具的参数根本不是对象，只是一个列表或字符串，则回复会在那里停止；现在，模型被告知调用出了什么问题，可以重试。 [提交](https://github.com/open-webui/open-webui/commit/fed94c9f5af8a59660425d52df09e15fbedb25bc)
- 📡 **流报告损坏。** 如果在从“/api/chat/completions”流式传输答案的过程中出现问题，流就会停止，留下 client 等待永远不会完成的答案；它现在关闭并出现错误并正确结束流。 [提交](https://github.com/open-webui/open-webui/commit/c0fb36c9b833a85a3a7364e195cf54f3d6c7a787)
- 🧷 **聊天在错误后解锁。** 由于内容过滤器或配额耗尽而失败的回复，导致聊天拒绝您在其后键入的所有内容并停止消息队列。现在只有失败的回复结束，因此聊天继续，多模型答案中的其他回复继续写入。 [提交](https://github.com/open-webui/open-webui/commit/dbb17a5725f9d7f844a6eee63ffca0bd077c7d94)
- 🫙 **清空历史记录中的失败回复。** 当您发送下一条消息时，以错误结束且未写入任何内容的助手回合不再作为对话的一部分返还给模型。 [提交](https://github.com/open-webui/open-webui/commit/dbb17a5725f9d7f844a6eee63ffca0bd077c7d94)
- 📭 **空页面上传。** 将网址添加到知识库，但返回时没有任何文本，失败并显示“错误上传文件”，并且在上传本身被拒绝的情况下，将该行留在列表中；现在，您已经收到了原因，并且该行已被取消。 [提交](https://github.com/open-webui/open-webui/commit/6786ae1797eadaad7464a147213790e2d272822b)
- 🎞️ **工具嵌入范围。** 工具调用可以要求显示的框架，这些框架运行自己的脚本，在渲染消息的任何地方绘制，其中的一个通道；现在，它们只会出现在您所在聊天的回复中，而不会出现在频道中。 [#29985](https://github.com/open-webui/open-webui/pull/29985)
- 🚰 **拒绝的图片地址。** 带有服务器拒绝的图片地址的模型条目不再将该地址保留在内存中，任何登录的人都可以将它们堆积起来。 [#29971](https://github.com/open-webui/open-webui/pull/29971)
- 🖌 **编辑存储的图像。** 要求模型编辑此实例已保存的图像现在可以在其地址名称的任何主机上工作，其中容器名称、默认端口或自行组成的主机导致编辑失败并出现一般加载错误。 [#29691](https://github.com/open-webui/open-webui/pull/29691)、[#29220](https://github.com/open-webui/open-webui/issues/29220)
- 🧪 **内存回复携带较少。** 内存工具不再将每个内存存储的元数据交给模型，并且内存现在记录模型的 id 而不是整个模型条目。 [提交](https://github.com/open-webui/open-webui/commit/e9a0164690a8b1e190bdc8f4613e9d918b26d327)
- 🔇 **内存完全关闭。** 内存关闭后，存储的内存不再折叠到回复的上下文中，并且不再向模型提供内存工具，两者都在开关后面继续访问它。 [#30228](https://github.com/open-webui/open-webui/pull/30228), [#30227](https://github.com/open-webui/open-webui/issues/30227)
- 🧠 **切换背后的内存审查。** 当内存关闭或帐户被禁止时，从对话中起草新记忆的后台审查将不再运行，它会在每个间隔回合中花费一次任务模型调用并在写入时失败。 [#30309](https://github.com/open-webui/open-webui/pull/30309)
- 🏗️ **终端服务器保存按钮。** 保存终端服务器现在会在对话框关闭之前等待保存完成，并且不能被第二个 click 触发两次。 [提交](https://github.com/open-webui/open-webui/commit/1cdd7aa459d6e96905324b452600ff56369d8a4e)
- 🗺️ **终端文件面板路径。** 终端旁边的文件面板现在可以打开模型刚刚编写的文件，即使它是用相对路径命名的，面板无法匹配名称，会跳转到根目录并拖动会话的工作目录。 [#30282](https://github.com/open-webui/open-webui/pull/30282)、[#30051](https://github.com/open-webui/open-webui/issues/30051)
- 🍴 **分叉聊天文件夹。** 分叉聊天会将副本放入原始文件夹中，即使您无法写入该文件夹；除非可以，它现在是在任何文件夹之外创建的。 [#30069](https://github.com/open-webui/open-webui/pull/30069)

- 🗝️ **只读文件夹在任何地方都是只读的。** 作为查看者与您共享的文件夹不再在空聊天页面上显示其编辑控件，它们出现在其中，并且保存成功或失败取决于页面从未检查的权限。 [提交](https://github.com/open-webui/open-webui/commit/ee3ece1e2b8c9a38c94faf354ca020d66aba801d)
- 🚿 **删除文件夹，保留聊天记录。** 删除文件夹并保留其中的聊天记录会被拒绝，因为帐户不允许删除聊天记录，即使没有删除任何内容，现在已经完成了。 [#30163](https://github.com/open-webui/open-webui/pull/30163)
- 🏷️ **删除后的标签清理。** 删除其他人的聊天记录的管理员会从自己的帐户而不是所有者的帐户中清理未使用的标签，从而使所有者留下没有任何意义的标签。 [#30171](https://github.com/open-webui/open-webui/pull/30171)
- 🌱 **分叉过去未完成的回复。** 聊天中任何地方都有中断的回复，从那时起拒绝每次分叉，并且永远不会恢复；现在，分叉仅等待实际生成的回复，并且为工具批准而暂停的回合仍会分叉并显示提示。 [#30131](https://github.com/open-webui/open-webui/pull/30131), [#30128](https://github.com/open-webui/open-webui/issues/30128)
- 💾 **删除工具内存。** 删除工具或函数，只要服务器运行，其整个代码就会保留在内存中；现在它与其他部分一起被放弃了。 [#29983](https://github.com/open-webui/open-webui/pull/29983)
- 🐌 **登录速率限制。** 通过 Redis 计算登录尝试次数在 Redis 应答之前不再停止整个工作线程，因此缓慢的 Redis 会停止冻结所有其他请求。 [#29977](https://github.com/open-webui/open-webui/pull/29977)
- ♻️ **会话池清理。** 清除废弃的 websocket 会话的任务现在通过 Redis 的错误继续进行，而不是永久结束，并在关闭时正确停止。 [#29976](https://github.com/open-webui/open-webui/pull/29976)、[#29979](https://github.com/open-webui/open-webui/pull/29979)
- 🛰️ **跨工作人员的直接连接。** 通过直接连接流式传输的回复不再在多个服务器通过 Redis 共享其 Websocket 流量的过程中保持安静；它所依赖的事件现在像其他事件一样在工人之间传播。 [提交](https://github.com/open-webui/open-webui/commit/0180efecf362d487e0c30f040f5948c325fbe337)
- 🫧 **空文档 ID。** 根本没有 ID 的文档的保存会针对该空 ID 进行归档，并且从未清除，因此任何登录的人都可以将它们堆积起来；现在还没有提出任何申请。 [#29980](https://github.com/open-webui/open-webui/pull/29980)
- 🔬 **页面获取 CPU 旋转。** 通过浏览器驱动的加载器获取页面永远不会返回该页面打开 WebSocket 的位置，在进程的生命周期中将工作线程保持在满 CPU 状态，并且在每次进一步获取时都会消耗另一个核心，这使得整个实例变慢。 [#30050](https://github.com/open-webui/open-webui/pull/30050)、[#30024](https://github.com/open-webui/open-webui/issues/30024)
- 🔁 **重复的搜索回溯。** 矢量数据库中断为每个集合和查询对写入了两次完整的回溯，将一次中断变成了每个副本上每条消息数百个相同的堆栈跟踪；现在，单个记录会命名每个失败的集合。 [#29981](https://github.com/open-webui/open-webui/pull/29981)

- 📤 **工具导出范围。** 一次导出所有工具会返回该帐户可以看到的所有工具，包括共享阅读的工具的来源；现在，它仅返回可以编辑的工具，与单一工具导出和模型已导出的方式相匹配。 [#29310](https://github.com/open-webui/open-webui/pull/29310)
- 🗳️ **部分工作区导出。** 从工作区导出提示或模型只会写出您碰巧正在查看的页面，因此大部分内容都被悄悄地排除在文件之外；现在两者都可以导出您允许的所有内容。 [#30187](https://github.com/open-webui/open-webui/pull/30187)
