# claude-mem v15.14.0

## 新

- **“我的工作”中的重点领域：**“我的工作”现在打开，显示您的重点领域的概述。每个区域都会获得一张卡片，其中包含捆绑的概念艺术作品、其目标和实时请求；打开一个以查看其请求。设置显示屏幕使用相同的视图。艺术品可以设置为完整、紧凑或关闭，并且图像随插件一起提供，因此在运行时不会生成或获取任何内容（#5652）。
- **claude-mem 可以自我更新：** 工作人员每天检查一次 `releases/promoted-release.json` 中推广的版本，并且仅在您离开一段时间时仅安装 npm 显示为由发布工作流程发布的较新版本（具有出处）。失败的更新会恢复到以前的版本。 `npx claude-mem doctor` 显示自动更新行。用`CLAUDE_MEM_AUTO_UPDATE=false`将其关闭； Claude Code 自己的更新开关（`DISABLE_AUTOUPDATER` 和朋友）也将其关闭。新安装会在 Claude Code 后台更新关闭的情况下注册市场，因此只有一个更新程序运行。请参阅新的自动更新文档页面 (#5500)。
- **启动上下文只是时间线：** SessionStart 消息现在是标题行，后面跟着时间线，以最新条目结束。较长的工作状态和内存使用指令移至 claude-mem MCP 服务器指令。终端横幅具有相同的形状（#5487）。
- **更快的挂钩：** 挂钩从小型仅挂钩捆绑包运行，而不是从完整的工作捆绑包运行。一个钩子大约需要一半的时间和内存；十几个并行钩子使用大约四分之一的CPU（#5541，感谢@bulanovk）。
- **原始工具证据搜索（选择加入，本地）：** 使用 `CLAUDE_MEM_TOOL_USES_SEARCH_ENABLED=true`，当观察搜索找不到任何内容时，使用 `deep: true` 的本地 `search` 会查看存储的工具输入和输出，并返回 `get_tool_uses` 的 `#T` ID（#5167，感谢 @ShitK）。
- **韩语用户界面：** 观众、我的作品、设置和观察电视可以用韩语显示（#5522，感谢@BaeJinSeop）。
