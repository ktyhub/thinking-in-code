# faster-whisper v0.10.0

* 支持“large-v3”模型
  * 能够从`preprocessor_config.json`加载`feature_size/num_mels`和其他
  * 粤语的新语言标记 (`yue`)
* 更新 `CTranslate2` 要求以包含最新版本 3.22.0
* 更新 `tokenizers` 要求以包含最新版本 0.15
* 更改集线器以从 [Systran 组织](https://huggingface.co/Systran) 获取模型
