# Vane v1.10.0

## 发生了什么变化  
- 为 Ollama 模型添加 `keep_alive` 参数，以指定模型在内存中保留的时间。  
- 添加文件上传，允许根据上传的文件生成答案（目前支持 PDF、TXT 和 DOCX）。  
- 添加Gemini聊天模型提供商。  
- 添加元搜索代理类以提高可维护性并促进焦点模式创建。  
- 修复用户界面错误（颜色错误、内容溢出）。  
- 添加用于生成博客式答案的新提示。  
- 更新聊天模型提供商并包含最新模型。  
- 当用户切换到另一个视频时，在灯箱模式下暂停当前正在播放的视频。  
- 修复与自定义 OpenAI 处理相关的错误。  
- 确保仅删除属于聊天的消息，而不是所有消息。  
- 添加自动图像和视频搜索功能。  
- Add new settings page with live config refresh.  
- 仅当发送用户消息时滚动进入视图。  
- 删除后端并将所有功能移至 Next.js 路由。  
- 添加思维模型支持。  
- Use a standalone build to reduce build sizes (from 1.8GB and 1.6GB to ~220MB).
