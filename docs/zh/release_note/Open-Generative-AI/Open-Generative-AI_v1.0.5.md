# Open-Generative-AI v1.0.5

## 新消息

- **标题中突出的设置按钮** (#111) — 将裸露的按键/头像图标替换为带标签的齿轮按钮，以便用户可以一目了然地找到 API 键 + 本地模型设置。适用于桌面应用程序和 Web shell。
- **子模块安全设置** (#110) - `git clone --recurse-submodules` 现在是记录路径，并且 `npm run setup` 自动初始化子模块，因此 `next build` 不再因 `Module not found: Can't resolve 'ai-agent'` 而失败。
