# Open-Generative-AI v1.0.0

## 桌面应用程序 — One-Click 安装程序

下载适合您平台的安装程序：

|平台|建筑|文件 |
|---|---|---|
| macOS |苹果芯片 (M1/M2/M3/M4) | `Open Higgsfield AI-1.0.0-arm64.dmg` |
| macOS |英特尔 (x64) | `Open Higgsfield AI-1.0.0.dmg` |
|窗户 | x64 + ARM64 | `Open Higgsfield AI Setup 1.0.0.exe` |

### 安装

**macOS：** 打开 `.dmg`，将应用程序拖至 `/Applications`。如果 macOS 显示“身份不明的开发人员”警告，请右键 click 应用程序 → **打开**。

**Windows：** 运行 `.exe` — 使用“开始”菜单快捷方式静默安装到 `%LocalAppData%`。

### 要求
- [Muapi.ai](https://muapi.ai) API 密钥（首次启动时通过“设置”输入）
- macOS 10.12+ 或 Windows 10+

> 应用程序当前未签名。 macOS Gatekeeper 和 Windows SmartScreen 可能会在首次运行时显示警告 - 这对于未签名的版本来说是正常的。
