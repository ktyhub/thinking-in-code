# Scrapling v0.3.14

**一个小的维护更新，以修复 v0.3.13 中某些设备发生的问题**

- 禁用 `StealthyFetcher` 及其会话类中的隐身模式，因为它使 cookie 无法在 Windows 设备上的页面上持久存在。它在 MacOS 和 Linux 上没有发生（修复 [#123](https://github.com/D4Vinci/Scrapling/issues/123)，感谢 @frugality4121 提出它并感谢 @gembleman 指出解决方案）。
- 固定了 browserforge 的最新版本，为使用旧 browserforge 版本的用户解决旧标头模型的问题。


_🙏 特别感谢我们的[Discord 社区](https://discord.gg/EMgGbDceNQ) 的持续测试和反馈_
