# Scrapling v0.4.14

**快速维护版本可修复 `uv` 的安装 🔧**

  > [!注意]
  > **[在 X 上关注我们，获取日常提示和技巧](https://x.com/Scrapling_dev)**

  ## 🐛 错误修复

  - **修复了 `uv` 默认拒绝安装 v0.4.13 并默默回退到旧版本的问题**。以前的版本需要 `curl_cffi` 的预发行版本，除非明确启用，否则 `uv` 不允许使用预发行版本。
  所有依赖项现在都解析为稳定版本。 （修复[#407](https://github.com/D4Vinci/Scrapling/issues/407)）
