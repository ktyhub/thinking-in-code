# spring-cloud-openfeign v4.3.2

## :lady_beetle: Bug Fixes

- Feature "warn when GET method has unannotated parameters" causes incorrect warning for methods with a single URI parameter. [#1326](https://github.com/spring-cloud/spring-cloud-openfeign/issues/1326)
- The configuration value `spring.cloud.openfeign.oauth2.clientRegistrationId` is only accepted with CamelCase and not with dash-case [#1270](https://github.com/spring-cloud/spring-cloud-openfeign/issues/1270)
