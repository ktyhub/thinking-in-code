# spring-cloud-openfeign v5.0.4

## What's Changed
* Update Maven wrapper to 3.9.16 by @spring-builds in https://github.com/spring-cloud/spring-cloud-openfeign/pull/1403
* Resolve placeholders before parsing request headers by @yashdotdev13 in https://github.com/spring-cloud/spring-cloud-openfeign/pull/1405
* Fix circuit breaker Feign builder direct usage by @hutiefang76 in https://github.com/spring-cloud/spring-cloud-openfeign/pull/1390
* Bump antora from 3.2.0-rc.2 to 3.2.0-rc.3 in /docs by @dependabot[bot] in https://github.com/spring-cloud/spring-cloud-openfeign/pull/1409
* Bump antora from 3.2.0-rc.3 to 3.2.0 in /docs by @dependabot[bot] in https://github.com/spring-cloud/spring-cloud-openfeign/pull/1414
* Scope repeated Client resolution warning to the application context by @kdelay in https://github.com/spring-cloud/spring-cloud-openfeign/pull/1417
* Update Antora UI bundle to v0.4.26 by @spring-builds in https://github.com/spring-cloud/spring-cloud-openfeign/pull/1423
* Match path variables used inside a header value by @kdelay in https://github.com/spring-cloud/spring-cloud-openfeign/pull/1425
* Choose an instance when retry is disabled by @kdelay in https://github.com/spring-cloud/spring-cloud-openfeign/pull/1426
* Update Maven wrapper to 3.10.0 by @spring-builds in https://github.com/spring-cloud/spring-cloud-openfeign/pull/1433
* Send HttpHeaders header maps when Spring Data is absent by @kdelay in https://github.com/spring-cloud/spring-cloud-openfeign/pull/1434
* Bump @antora/atlas-extension from 1.0.0-alpha.5 to 1.0.0-alpha.6 in /docs by @dependabot[bot] in https://github.com/spring-cloud/spring-cloud-openfeign/pull/1440
* Bump antora from 3.2.0 to 3.2.1 in /docs by @dependabot[bot] in https://github.com/spring-cloud/spring-cloud-openfeign/pull/1439
* Do not decode the body of a ResponseEntity<Void> by @kdelay in https://github.com/spring-cloud/spring-cloud-openfeign/pull/1442
* Normalize the client URL configured in properties by @kdelay in https://github.com/spring-cloud/spring-cloud-openfeign/pull/1446
