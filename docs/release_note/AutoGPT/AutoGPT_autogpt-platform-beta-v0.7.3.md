## 🔥 What's New?

### New Features
- **#14003** - Replace the email system with the Briefing/Alert/Verdict/Ops design (by @Torantulino)
- **#14156** - Add selectable ask_question options and Needs-You prompting rule to Copilot (by @Abhi1992002)
- **#14143** - Show live compaction progress in the Copilot chat (by @0ubbe)
- **#14099** - Add expert team tools and copilot chat polish behind flags (by @Abhi1992002)
- **#14165** - Fire Google Ads conversions across the signup-to-paid journey (by @0ubbe)
- **#14184** - Report a DataFast `paywall_view` goal from onboarding (by @ntindle)
- **#14188** - Recommend Ornith 1.5 for local users (by @ntindle)

### UI/UX Improvements
- **#14164** - Drop the new-tool-ui flag and commit to the tool chain UX (by @0ubbe)
- **#14158** - Chain UI polish — card resize, expert skeletons, minimap and artifact tweaks (by @Abhi1992002)
- **#14142** - Call the adoptable list "Your workflows" and match heading sizes (by @0ubbe)
- **#14073** - Show budgets in dollars and stop tab panels clipping run cards (by @Abhi1992002)

### Bug Fixes
- **#14155** - Make expert delegation and team state stale-proof (by @Abhi1992002)
- **#14147** - Provision the platform User row on first authenticated touch (by @ntindle)
- **#14145** - Route read-only Cypher through GRAPH.RO_QUERY (by @ntindle)
- **#14141** - Fix MCP OAuth popup failing with 'Sign-in window was closed' on COOP providers (by @0ubbe)
- **#14167** - Send the DataFast signup goal under the name the funnel expects (by @ntindle)
- **#14173** - Keep the DataFast signup goal named `signup` (by @ntindle)

### Developer Experience
- **#14157** - Add dev-only token/context devtool in the composer tray (by @Abhi1992002)

### Documentation
- **#14170** - Sync GitBook documentation into dev (by @ntindle)

### Dependencies & Maintenance

- **#12352** - Bump docker/login-action from 3 to 4 (by @dependabot[bot])
