# consul v4.1.9

## Fixed

* OpaqueSigner now supports unrecognized public key types again (#325, fixes a regression in v4.1.5)
* Parsing a JWK with an unsupported elliptic curve, or a too-big RSA modulus, now returns ErrUnsupportedKeyType (https://github.com/go-jose/go-jose/pull/327)
