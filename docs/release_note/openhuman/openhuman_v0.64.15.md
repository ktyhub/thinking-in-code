# openhuman v0.64.15

# The Installed-Build Reliability Upgrade

This release focuses on keeping installed apps rock-solid—especially when loading key modules like search and memory. Onward and upward! 🎉

## Highlights

### Modules & installed builds 🧩
A targeted hotfix improves module admission in installed builds so critical modules load correctly again—unblocking both search (`tinysearch`) and memory (`tinymemory`) where they could previously fail due to module directory permission checks.  

([#7155](https://github.com/tinyhumansai/openhuman/pull/7155)) — Thank you @senamakel!
