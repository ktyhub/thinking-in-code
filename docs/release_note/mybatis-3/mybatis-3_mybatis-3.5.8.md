# mybatis-3 mybatis-3.5.8

List of changes:

- Avoid `NullPointerException` when mapping an empty string to `java.lang.Character`. #2368 
- Fixed an incorrect argument when initializing static object. This resolves a compatibility issue with [quarkus-mybatis](https://github.com/quarkiverse/quarkus-mybatis). #2284 
- Performance improvements. #2297 #2335 #2340 
- And many doc updates!

Please see the [3.5.8 milestone page](https://github.com/mybatis/mybatis-3/issues?q=is%3Aclosed+milestone%3A3.5.8) for the complete list of changes.
There is no known backward incompatible change since 3.5.7.
