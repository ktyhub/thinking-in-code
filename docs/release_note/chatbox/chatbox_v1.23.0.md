### What's Changed

1. Added persistent memory for global use or individual Copilots
2. Added Soul settings for Work Mode personality and boundaries
3. Added queued and immediate messages while a reply is generating
4. Working directory and permission settings now carry over between tasks
5. Full Access no longer pauses every 25 steps by default
6. Vision-capable models can open local and downloaded images
7. Improved context retention for long-running tasks
8. Added bulk archive clearing and tool-result text previews
9. Added Tencent Hunyuan, Xiaomi MiMo, LongCat, GLM Coding Plan, OpenCode Zen, OpenCode Go, and self-hosted SearXNG
