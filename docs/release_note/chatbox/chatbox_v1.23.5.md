### What’s Changed

1. Fixed external one-click MCP setup links failing to open the prefilled server dialog when the app was not running
2. You can now edit the last output of a Work Mode reply
3. Fixed Image Creator history going blank or failing to finish loading when a record is incomplete
4. Fixed undoing a new topic sometimes deleting the previous conversation
5. Fixed leftover digits in the message input after pasting during nine-key typing

### 更新说明

1. 修复应用未启动时，通过外部链接一键添加 MCP 服务无法打开预填配置窗口的问题
2. 工作模式的助手回复现在可以编辑最后一段输出
3. 修复图片创作历史记录不完整时页面白屏或无法继续加载的问题
4. 修复新建话题后撤销会误删原来聊天记录的问题
5. 修复九键输入过程中粘贴后输入框出现一串数字的问题
