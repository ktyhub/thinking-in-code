# spring-cloud-kubernetes v3.2.3

## :lady_beetle: Bug Fixes

- Cannot disable leaderElection for /info endpoint [#2085](https://github.com/spring-cloud/spring-cloud-kubernetes/issues/2085)
- fix issue 2008 (3.2.x) [#2015](https://github.com/spring-cloud/spring-cloud-kubernetes/pull/2015)
- DiscoveryServer packaging changed in latest release [#2012](https://github.com/spring-cloud/spring-cloud-kubernetes/issues/2012)
- Skipping configmap events due to The current number of PropertySources does not match the ones loaded from Kubernetes - No reload will take place [#2008](https://github.com/spring-cloud/spring-cloud-kubernetes/issues/2008)
- KubernetesCatalogWatch.catalogServicesWatch throws an NPE when endpointslices are not set [#1971](https://github.com/spring-cloud/spring-cloud-kubernetes/issues/1971)
- Loadbalancer with SERVICE mode cannot discover newly created services [#1970](https://github.com/spring-cloud/spring-cloud-kubernetes/issues/1970)
- [Fabric8] `KubernetesClient` is closed too early during shutdown [#1968](https://github.com/spring-cloud/spring-cloud-kubernetes/issues/1968)
- Remove commons-lang dependency [#1966](https://github.com/spring-cloud/spring-cloud-kubernetes/issues/1966)
- KubernetesReactiveDiscoveryClient doesn't respect order [#1963](https://github.com/spring-cloud/spring-cloud-kubernetes/issues/1963)
- spring-cloud-kubernetes-fabric8-leader - NullPointerException on pod termination [#1953](https://github.com/spring-cloud/spring-cloud-kubernetes/issues/1953)
- ExternalConfig Array Merging Issue in Kubernetes vs Local Environment [#1935](https://github.com/spring-cloud/spring-cloud-kubernetes/issues/1935)
