# crewAI 1.15.40

## What's Changed

### Features
- Remove chromadb from the embedding function layer.
- Add exact historical state lookup by row id.
- Wire jsonl into rag data type discovery.
- Scaffold standalone agents as JSON by default.
- Add backend record lifecycle and pagination tests.

### Bug Fixes
- Run after_llm_call hooks on async calls.
- Stop an agent whose apps CrewAI AMP cannot resolve.

### Documentation
- Update Arize agent evaluation guide URL.
