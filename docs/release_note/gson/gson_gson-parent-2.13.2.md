# gson gson-parent-2.13.2

The main changes in this release are just newer dependencies.

## What's Changed
* Improved packaging of JPMS module declaration in Gson jar\
  This fixes an issue where Eclipse and VS Code users could not refer to the Gson module name `com.google.gson`. See issue https://github.com/google/gson/issues/2679.
* Remove internal class `GsonPreconditions` by @Marcono1234 in https://github.com/google/gson/pull/2879
* Switch to using central-publishing-maven-plugin by @eamonnmcmanus in https://github.com/google/gson/pull/2900

## New Contributors
* @MukjepScarlet made their first contribution in https://github.com/google/gson/pull/2852
