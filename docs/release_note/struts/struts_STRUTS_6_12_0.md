# struts STRUTS_6_12_0

## What's Changed
* Prepare for a new development cycle of Struts 6.12.0 by @lukaszlenart in https://github.com/apache/struts/pull/1827
* WW-5688 Resolve id-bearing REST URIs into the root namespace when declared (6.x backport) by @lukaszlenart in https://github.com/apache/struts/pull/1863
* WW-5700 Skip the store when a map or list element cannot be converted (6.x backport) by @lukaszlenart in https://github.com/apache/struts/pull/1878
* WW-5701 Compare the conversion marker by identity, not equals (6.x backport) by @lukaszlenart in https://github.com/apache/struts/pull/1879
* WW-5706 Align RestfulActionMapper action name handling with DefaultActionMapper (6.x) by @lukaszlenart in https://github.com/apache/struts/pull/1881
* WW-5707 Deprecate legacy restful and restful2 action mappers in core (6.x) by @lukaszlenart in https://github.com/apache/struts/pull/1883
* WW-5711 fix(conversion): bound fraction digits when formatting BigDecimal by @lukaszlenart in https://github.com/apache/struts/pull/1888
* WW-5716 Bound the per-locale definition caches in the Tiles plugin (6.x) by @lukaszlenart in https://github.com/apache/struts/pull/1903
* WW-5723 Bound the request body read in the REST plugin (6.x) by @lukaszlenart in https://github.com/apache/struts/pull/1913
* WW-5724 Hand out a clone of the cached MessageFormat (6.x) by @lukaszlenart in https://github.com/apache/struts/pull/1915
* WW-5718 fix(rest,bean-validation): add the resource-isolation interceptors to the plugin default stacks (6.x) by @lukaszlenart in https://github.com/apache/struts/pull/1958
* WW-5749 fix(rest): write nothing from the XML handlers when there is no target (6.x) by @lukaszlenart in https://github.com/apache/struts/pull/1960
