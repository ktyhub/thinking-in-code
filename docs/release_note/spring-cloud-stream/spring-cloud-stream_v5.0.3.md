# spring-cloud-stream v5.0.3

## Security

* [CVE-2026-59302](https://spring.io/security/cve-2026-59302) — Potential for logging sensitive data in Spring Cloud Stream
* [CVE-2026-59303](https://spring.io/security/cve-2026-59303) — Dynamic destination cache size is not properly bound in Spring Cloud Stream
* [CVE-2026-59304](https://spring.io/security/cve-2026-59304) — Improper caching of the original content type in Spring Cloud Stream Avro
* [CVE-2026-59305](https://spring.io/security/cve-2026-59305) — Partition interceptor may be improperly added while sending message
* [CVE-2026-59306](https://spring.io/security/cve-2026-59306) — Potential for deserialization of untrusted types in Spring Cloud Stream
