# outlines 1.3.1

## What's Changed
* Add semver and MAC address custom types by @Yeuvoir in https://github.com/dottxt-ai/outlines/pull/1863
* Update docs with OrcaRouter guide by @xilema2 in https://github.com/dottxt-ai/outlines/pull/1865

* Mark non-required JSON-schema properties NotRequired in TypedDict conversion by @iamsharduld in https://github.com/dottxt-ai/outlines/pull/1883

* fix: make json-schema-derived dataclasses kw_only so optional-before-required fields don't crash by @CrypticCortex in https://github.com/dottxt-ai/outlines/pull/1872
* fix(dsl): keep None unquoted for Optional nested in containers by @sarathfrancis90 in https://github.com/dottxt-ai/outlines/pull/1880
* fix(types): convert JSON Schema type arrays to a Union by @sarathfrancis90 in https://github.com/dottxt-ai/outlines/pull/1889
* Migrate to src layout by @Youssefares in https://github.com/dottxt-ai/outlines/pull/1879
* Fix the documentation preview workflow by @RobinPicard in https://github.com/dottxt-ai/outlines/pull/1891
