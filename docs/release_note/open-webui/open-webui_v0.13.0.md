# open-webui v0.13.0

### Added

- 📑 **Tabbed workspace.** The Tabs button at the top of a chat now opens a workspace for files, multiple terminal sessions, artifacts, previews, voice calls and comments. Add tabs from the + menu, drag to reorder them, and create and save new files directly into the selected terminal. Keep the conversation and its working files together while coding, analyzing data or reviewing generated documents. [Commit](https://github.com/open-webui/open-webui/commit/2d7cf5ec99c3fa5c7ee48b91823fb8021b846cf3), [Commit](https://github.com/open-webui/open-webui/commit/5b58b1ebc03024fca1efd498aeabe4d9880dc3aa), [Commit](https://github.com/open-webui/open-webui/commit/a06aa230f75cc2d3512d1bca197a98f3c35da96f), [Commit](https://github.com/open-webui/open-webui/commit/cdc6feecd3769aac41844d81bd775dfb69b44912)
- 🖥️ **Open Terminal Desktop tab for computer use.** Open the Desktop tab from the + menu to view and control the desktop provided by your connected Open Terminal, with mouse, keyboard, clipboard and audio support where available. With a model that can call its desktop tools, you can follow computer-use workflows in the same desktop and step in yourself: operate graphical apps, inspect generated documents or handle a step that needs manual input. Requires an Open Terminal connection with desktop support enabled. [Commit](https://github.com/open-webui/open-webui/commit/b51e68fbb3e641e7f9027f5164fcf6b0e111cf27), [Commit](https://github.com/open-webui/open-webui/commit/3bd0cdd0f3cc075420540462f2bf246c73236495), [Commit](https://github.com/open-webui/open-webui/commit/03401a6e331d25425533933da85d3e5496deca3f), [Commit](https://github.com/open-webui/open-webui/commit/6dd3cc216f63085d2a1105117c65064c3e0ca3b6)
- 🌐 **Browser tab for browser use and web app testing.** Open websites and local development servers beside your chat, with navigation controls, multiple tabs and a mobile viewport. On a compatible Open Terminal connection, Chrome mode gives you and the model a shared browser session for browser automation: navigate sites, interact with forms and test the web apps the model builds. You can watch the work and interact with the page yourself; Proxy mode remains available for previews. Requires browser support on the selected terminal, and Chrome availability for browser-use tools. [Commit](https://github.com/open-webui/open-webui/commit/fbe69b01fd58a374211d348a28eb5988b11d41de), [Commit](https://github.com/open-webui/open-webui/commit/3bd0cdd0f3cc075420540462f2bf246c73236495), [Commit](https://github.com/open-webui/open-webui/commit/9260e312fb4238b504652eff0d8ca45445ca0821)
- ↔️ **Full-width tabs.** On larger screens, expand the tabbed workspace to fill the chat area, with the main conversation kept as its own tab. Switch between the chat, code, browser and desktop with more room to work, or return to the side-by-side layout; your layout choice is remembered. [Commit](https://github.com/open-webui/open-webui/commit/09030d5dd2def4324d98c25f92cf54b1ec1844f1), [Commit](https://github.com/open-webui/open-webui/commit/1ce8616ab9587ca717015d5af9cb26ee4296311f)
- 💻 **Open WebUI Desktop 0.1.x.** The separately installed app for macOS, Windows and Linux now focuses on setting up and running Open WebUI on your own computer, with optional llama.cpp local models. The 0.1.0–0.1.4 updates bring a slimmer interface, searchable settings, startup logs, optional automatic Desktop updates, start-to-tray controls and image copying and saving. They also improve screen sharing, knowledge folder uploads, Linux graphics and shortcuts, and NVIDIA/AMD local-model setup and updates. Use it for a managed local installation and local AI workflows. [Desktop changelog](https://github.com/open-webui/desktop/blob/v0.1.4/CHANGELOG.md), [Download v0.1.4](https://github.com/open-webui/desktop/releases/tag/v0.1.4)
- 🌿 **Git in the side panel.** When the selected terminal's folder is a Git repository, a Git panel in the tabbed side panel now lets you review diffs, stage, discard and commit changes, manage branches and worktrees, push and pull, browse history and work with GitHub pull requests, and open files can show their changes with Show diff. [Commit](https://github.com/open-webui/open-webui/commit/58926cfe7b98aab83c2544714d26cdbcc90722a3), [Commit](https://github.com/open-webui/open-webui/commit/3e24a08f8ec8472dcbbc46e7e39ab35aaa4a6f4f), [Commit](https://github.com/open-webui/open-webui/commit/30f0779d12072f98b2c3ce1b08819c72ab9c66d8), [Commit](https://github.com/open-webui/open-webui/commit/295b0778938cb9a133712b1bda4a18df92406375), [Commit](https://github.com/open-webui/open-webui/commit/250108302e6d73406c643a51eb5d9f80d39ddc03)
- ⚡ **Live terminal updates.** On terminals that support it, the Git panel, the list of open ports and the running processes and their output now update as soon as something changes instead of every few seconds. [Commit](https://github.com/open-webui/open-webui/commit/c4c10aa2559e10883797e3dd6702e16dc36eff19), [Commit](https://github.com/open-webui/open-webui/commit/70c5e38fc7ce3864426b484c07ee201cba2b9d07)
- 💭 **Side chats.** Typing "/side" or "/btw" in a chat, or choosing Side chat in the side panel, now opens a temporary side conversation using the chat so far as context. Ask a quick question or explore an alternative without adding the detour to the main conversation; the side chat disappears when you close its tab. Available to administrators and users given the new Allow Side Chat permission, which is off by default. [Commit](https://github.com/open-webui/open-webui/commit/321701c1af09d58f9ed6b67a22416ab8ddcfa165), [Commit](https://github.com/open-webui/open-webui/commit/151f7a84d1ca6949234671cd86d697abbce76444), [Commit](https://github.com/open-webui/open-webui/commit/27963030eccda5b8b27905ec0a35d5d9f09788e6)
- 💬 **Comment threads.** Administrators can now turn on Comments in Admin Settings > General or with "ENABLE_COMMENTS", which lets users leave comments with replies, reactions and mentions on the chats, notes, models, knowledge bases, prompts, skills and tools they can open, including on a selected passage of a chat message, which then stays highlighted in the reply, or of a note page, shown in a Comments tab in the chat's side panel, which "/comments" opens, and with comment counts in the workspace lists. [Commit](https://github.com/open-webui/open-webui/commit/9d1b4ef362f103f2dda05760a44c96df82c064fd), [Commit](https://github.com/open-webui/open-webui/commit/91e8deee74c627fee29c4c81833766040334170f), [Commit](https://github.com/open-webui/open-webui/commit/63312766f8de94bc8a054d7923f2f83410b841a2), [Commit](https://github.com/open-webui/open-webui/commit/04d78a483de671dbe789082b79638f9e44078819)
- 🔔 **Notification inbox.** A new Inbox in the sidebar collects comments on your items, replies to your comments, mentions in comments and channels, replies in channels, failed automation runs and upcoming calendar events with an unread count, and administrators can turn it off in Admin Settings > General or with "ENABLE_NOTIFICATIONS". [Commit](https://github.com/open-webui/open-webui/commit/3814b7b2f152c671fd3789e5a0099313d5316467), [Commit](https://github.com/open-webui/open-webui/commit/1a870d9481630861fe6d63de835d983df50b72c3), [#19539](https://github.com/open-webui/open-webui/issues/19539)
- 🧩 **MCP Apps in chat.** Tools from MCP servers that come with an interactive app now show that app right in the chat after they run, in a sandboxed frame that can only reach the sites the server declares, and every tool call the app wants to make waits for you to confirm it. [Commit](https://github.com/open-webui/open-webui/commit/0e0ba872a4d3e70c4e19e5c62b05fd7187b917f3), [Commit](https://github.com/open-webui/open-webui/commit/4ab90a6c1ff9526640e73ad37e67e88e693e2172), [#21040](https://github.com/open-webui/open-webui/discussions/21040), [#20915](https://github.com/open-webui/open-webui/discussions/20915)
- ✨ **Generate title from top bar.** The rename field at the top of an open chat now has the same sparkle button as the sidebar, which generates a title from the conversation and saves it right away. [#33382](https://github.com/open-webui/open-webui/pull/33382)
- 📐 **Side panels on tablets.** On screens from 768 pixels wide, such as tablets and narrow windows, channel threads and the pages list and chat in notes now open beside the content instead of over it, picking a terminal opens its files beside the chat as well, and the search dialog shows its preview there by default and remembers whether you turned it on or off at any window size. [Commit](https://github.com/open-webui/open-webui/commit/cbeb8e3630cafd7ef6fd28b552bf7114729f21b9), [Commit](https://github.com/open-webui/open-webui/commit/c5981aaea6b25bb9b9601e62b9ff75da33aaaf4e)
- 📊 **More PowerPoint charts.** The PowerPoint preview now draws pie, doughnut and horizontal bar charts as well as values below zero, and shows "Chart preview unavailable" for charts it cannot draw. [Commit](https://github.com/open-webui/open-webui/commit/09fbbd6d69293084d9e09cbb7d3b93e5d305ec5c), [#32884](https://github.com/open-webui/open-webui/issues/32884)
- 🧊 **3D model previews.** GLB, glTF, STL, OBJ and PLY files in a terminal's file browser and in files shown in chat replies now open in a 3D viewer that you can rotate and zoom. [Commit](https://github.com/open-webui/open-webui/commit/fe0d22cc24ddc2421b4e36a66a174188cc61d265)
- 🔘 **Switch tools on and off.** Tools in Workspace > Tools now have an on and off switch for everyone who can edit them, and a tool that is switched off can no longer be picked or run in any chat, including chats where it was already selected. [Commit](https://github.com/open-webui/open-webui/commit/9d1b4ef362f103f2dda05760a44c96df82c064fd)
- 🛠️ **Tool creation from chat.** Models with native function calling can now create a private Python tool in your workspace when you ask them to, for administrators and users allowed to create workspace tools, and it can be turned off per model under Tool Creation in the model editor's builtin tools. [Commit](https://github.com/open-webui/open-webui/commit/91241306e2541e984591435d8c25e9ab1442db6b)
- 🤝 **Multi-model sub-agents.** The model editor now lets you choose other models for a model to delegate work to, enabling multi-agent workflows such as assigning research, coding and review to different models. The parent model chooses among the configured models the user can access; previously, sub-agents always used the same model as the parent. [Commit](https://github.com/open-webui/open-webui/commit/789a0f402abe05e028bc8e0a8824d58b94e26d8f)
- 📏 **Knowledge base file limits.** Administrators can now cap how many files a knowledge base holds, how large each of its files may be and how many files go into it in one upload, for all knowledge bases in Admin Settings > Documents or with "KNOWLEDGE_MAX_FILE_COUNT", "KNOWLEDGE_MAX_FILE_SIZE" and "KNOWLEDGE_MAX_UPLOAD_COUNT", and a knowledge base's owner can set its own file count and size limits under Advanced when creating it or from Settings in its menu, while the global limits always apply. [Commit](https://github.com/open-webui/open-webui/commit/7618df3f53a8db2ad5352a789c88673a736b07a4), [Commit](https://github.com/open-webui/open-webui/commit/5c4fb61d862b011cf9efda6b2289de637ba8d6bb), [#33318](https://github.com/open-webui/open-webui/issues/33318), [#24845](https://github.com/open-webui/open-webui/discussions/24845)
- 📄 **File sizes in previews.** Opened terminal files now show their size in the file toolbar, so you can check a document or generated output without leaving its preview. [Commit](https://github.com/open-webui/open-webui/commit/2e55c365645e538c54b0d31b7bc8a977f6bb8b85)
- 🗂️ **Sort files by date added.** The terminal file browser can now sort files by when they were added, next to name, size and date modified, on terminals that report creation times. [Commit](https://github.com/open-webui/open-webui/commit/8c308e4e88c48924209f0018d73beb82a4ba2d94)
- ↕️ **Move blocks in notes.** Every paragraph, heading and other block in a note now has a handle beside it that you can drag to move the block, or click to move it up or down. [Commit](https://github.com/open-webui/open-webui/commit/3bb962f2bbd82ebe8ccad6f64304956aee2f4f97)
- 📋 **Copy code in notes.** Code blocks in notes now have a Copy button and use clearer syntax colors in light mode. [Commit](https://github.com/open-webui/open-webui/commit/ab71357980dab80de23b3597a13a41557a11df99), [Commit](https://github.com/open-webui/open-webui/commit/ee8b69e718aa7f0b962309e0137aa81f557093eb), [#33455](https://github.com/open-webui/open-webui/issues/33455)
- ⏸️ **Approvals shown in sidebar.** Chats in the sidebar now show a "Waiting for approval" marker while a tool call in them waits for you to allow or deny it. [Commit](https://github.com/open-webui/open-webui/commit/ddb43c83bac60553b002f148265db0900bc2b9f4), [Commit](https://github.com/open-webui/open-webui/commit/2840f0e07b398b76db04978334e3232fe8b89c31)
- 🏷️ **Role prompt variable.** System prompts, saved prompts and chat requests through the API can now use "{{USER_ROLE}}", which is replaced with the signed-in user's role, such as admin or user. [#33441](https://github.com/open-webui/open-webui/pull/33441), [#4765](https://github.com/open-webui/open-webui/discussions/4765)
- ♿ **Accessibility improvements.** Screen reader users now hear a name for every window, form field, setting and icon button, including Admin Settings, Valves, filters and channel message actions, and keyboard users can answer tool approvals, dismiss notifications, open model details in Admin Analytics, sort Analytics and group member tables, resize the sidebar, open notebook cells for editing, use multi-select lists in Valves, pick a status emoji, choose tag and voice suggestions, open the sources of a web search, use the menus in the Search window, stay inside the full-size image viewer and side drawers until they close them and reach every event on the calendar. Closing a window opened from a menu now returns focus to the menu button, Tab cancels shortcut recording, task-list checkboxes are named by their text, and unselected Analytics tabs have better contrast in Accessibility Mode. [Commit](https://github.com/open-webui/open-webui/commit/a671146b9172407d11240b8130eda9e92dfb2225), [Commit](https://github.com/open-webui/open-webui/commit/0171427a10f168da0d5b733fa5d0786c4d63b851), [Commit](https://github.com/open-webui/open-webui/commit/51cef9e26f17ad5baf1f6d51f72d87651d7e98e4), [Commit](https://github.com/open-webui/open-webui/commit/0a18dfc1841f99b143ae697eff0e51a24057d4fd)
- 🔄 **General improvements.** Various improvements were implemented across the application to enhance performance, stability, and security.
- 🌐 **Translation updates.** Translations for Portuguese (Brazil), Latvian, Azerbaijani, Basque, Bengali, Bosnian, Bulgarian, Cebuano, Croatian, Czech, Danish, Dutch, Estonian, Faroese, Filipino, Galician, German, Greek, Hebrew, Hungarian, Indonesian, Irish, Japanese, Korean, Lithuanian, Malay, Norwegian Bokmål, Persian, Polish, Punjabi, Romanian, Russian, Serbian, Slovak, Slovenian, Spanish (Spain), Tamil, Turkish, Turkmen, Ukrainian and Vietnamese were enhanced and expanded.

### Fixed

- 🛡️ **Security Advisory**: This release contains **security fixes**. We **strongly recommend updating** all deployments **as soon as possible** to have the latest security fixes in place. These fixes are **not listed in this changelog**; we will publish the security advisories for them immediately following CVE assignment. [Advisories](https://github.com/open-webui/open-webui/security)
- 🔃 **New chats stay in sync.** A chat started from the home page keeps syncing with the server again after it is created, so files removed from the chat's Controls no longer come back after a reload and the owner of a chat shared with Allow replies gets Regenerate on other people's replies again. [#33377](https://github.com/open-webui/open-webui/pull/33377), [#33376](https://github.com/open-webui/open-webui/issues/33376)
- 📂 **Temporary Chat on folder pages.** Turning Temporary Chat on or off on a folder's page, with the button at the top or with "/temporary", now keeps you on the folder page, so the next chat is still saved in the folder and gets its system prompt, default model and knowledge. [#33456](https://github.com/open-webui/open-webui/pull/33456), [#33448](https://github.com/open-webui/open-webui/issues/33448)
- 🧵 **Thread reply focus.** Choosing Reply in Thread on a channel message now puts the cursor in the thread's reply box, also when the thread panel is already open. [#33467](https://github.com/open-webui/open-webui/pull/33467), [#33466](https://github.com/open-webui/open-webui/issues/33466)
- 🪟 **Thread message actions visible.** Hovering the top message in a channel thread now shows its whole actions toolbar instead of cutting off its top half at the edge of the panel. [Commit](https://github.com/open-webui/open-webui/commit/08f197ad8d87b4f71be311888541c601942e96b9), [#33472](https://github.com/open-webui/open-webui/issues/33472)
- 📞 **Interrupting realtime calls.** Interrupting the model while it speaks in a realtime voice call no longer ends the whole call when the reported playback position does not match the audio. [Commit](https://github.com/open-webui/open-webui/commit/e5a2e6438e6f7455c7f0dcc304cd1b08329afe8b), [#33550](https://github.com/open-webui/open-webui/issues/33550)
- 📶 **Temporary chats after reconnecting.** A reply that is still being written in a temporary chat now keeps arriving after the connection drops and comes back, and a reply that could not finish shows "Connection lost. Please retry." instead of loading forever. [Commit](https://github.com/open-webui/open-webui/commit/321701c1af09d58f9ed6b67a22416ab8ddcfa165)
- 🏠 **New chat initialization.** Opening or reloading the home page or a folder now selects the model and applies chat URL parameters again, instead of leaving the model empty and ignoring the link’s settings. [Commit](https://github.com/open-webui/open-webui/commit/082df44d92178b6895153774bf6656c538cbce40)
- ✍️ **Restored chat drafts.** Saved draft text now returns to the message input after the new-chat editor mounts, instead of disappearing during initialization. [Commit](https://github.com/open-webui/open-webui/commit/4ea29c0d6198e44a84aae01475b003c8bc192e5b)
- 🧩 **Nested code previews.** Preview now opens code blocks inside lists, quotes and details blocks, so embedded examples and generated artifacts can be inspected directly. [Commit](https://github.com/open-webui/open-webui/commit/aec5796a535beaf3730e8c8a8b0426a94b3b1b44)
- 🖼️ **Image drops from photo apps.** Images dropped into chats and channels are now recognized from their contents when the source omits the file type, including photos dragged from macOS Photos, instead of being treated as generic files. [Commit](https://github.com/open-webui/open-webui/commit/563d621854e7a465a7713a811e996729a3e23499)
- 📏 **Live context usage estimates.** The context indicator now accounts for output arriving after the latest reported token usage and avoids counting assistant text twice when it also appears in structured output, making it easier to track context-window usage during long agent runs. [Commit](https://github.com/open-webui/open-webui/commit/8e61cc02106e4f698494c7813fa6602fd46f5f87)
- 🔌 **Responses-backed API streaming.** Clients using Open WebUI’s Chat Completions API now receive the expected streaming format even when the upstream model uses the Responses API, including text, reasoning, tool calls, token usage and completion reasons. [Commit](https://github.com/open-webui/open-webui/commit/e789513ea62eb0c56f36d7c48996f084931f1c49)
- 😀 **Channel reaction names.** Hovering a reaction on a channel message now shows who reacted when those names are available, instead of showing only the count. [Commit](https://github.com/open-webui/open-webui/commit/ea1c60fbdf3cfc08ddf4128ab33007380228e86c)
- 📊 **Analytics activity scrolling.** The activity chart now tracks the element actually being scrolled, keeping its visible rows in sync when browsing longer activity lists. [Commit](https://github.com/open-webui/open-webui/commit/f0e7d718caaba875621bf686c13c9c021d28643d)
- 🔑 **Saved OAuth provider settings.** OAuth providers now load their saved connection settings when Open WebUI starts. Admin Settings also explains that changes to provider connections require restarting every Open WebUI instance. [Commit](https://github.com/open-webui/open-webui/commit/bab66b2c2ff0e48b2a07a278d73e490b6577297c)

### Changed

- ⚠️ **Database Migrations**: This release includes database schema changes; we strongly recommend backing up your database and all associated data before upgrading in production environments. If you are running a multi-worker, multi-server, or load-balanced deployment, all instances must be updated simultaneously, rolling updates are not supported and will cause application failures due to schema incompatibility.
- 🎛️ **Controls in the model menu.** The chat files, valves, system prompt and advanced parameters moved from the Controls panel at the top of the chat to Controls in the model controls menu next to the message input, and the button at the top now opens the tabbed side panel. [Commit](https://github.com/open-webui/open-webui/commit/2d7cf5ec99c3fa5c7ee48b91823fb8021b846cf3), [Commit](https://github.com/open-webui/open-webui/commit/950da84bdb57423d9d2ddd6d29659d56174d8c22)
- 🗺️ **Overview in the chat menu.** The chat Overview, the map of all messages and their branches, now opens as a full-screen window from Overview in the chat's menu instead of as a tab in Chat Controls. [Commit](https://github.com/open-webui/open-webui/commit/fe0d22cc24ddc2421b4e36a66a174188cc61d265)
- 🔁 **Higher tool-call limit.** A single response with native function calling can now run up to 1024 rounds of tool calls before it stops with "Tool-call limit reached", up from 256, and setting "CHAT_RESPONSE_MAX_TOOL_CALL_ITERATIONS" to 256 keeps the old limit. [#33384](https://github.com/open-webui/open-webui/pull/33384)
- 🔓 **No sub-agent limits by default.** The sub-agent limits in Admin Settings and through "SUBAGENTS_MAX_CONCURRENT", "SUBAGENTS_MAX_ASYNC", "SUBAGENTS_MAX_ITERATIONS" and "SUBAGENTS_MAX_OUTPUT" now default to no limit, and leaving one empty means no limit, where they defaulted to 20 at once, 20 in the background, 30 tool loops each and 30000 characters of output. [Commit](https://github.com/open-webui/open-webui/commit/f0cc1bb86e52ec629993f5cd26f5f001bd5b72a6)
- 🧠 **Context compaction and prompt caching.** When the same model handles the conversation and its compaction summary, eligible requests now reuse the conversation’s prompt structure so the provider can use its prompt cache. This can reduce the cost of summarizing long conversations and agent workflows; other requests retain the separate summary path. [Commit](https://github.com/open-webui/open-webui/commit/a8b478ed7b8d22fe5b8f96be3c4cfd08cd30affb)
- 💻 **Desktop 0.1.x upgrade changes.** Open WebUI Desktop no longer switches between remote servers, bundles Open Terminal, or provides the old Spotlight and global voice overlays. Existing remote-connection users should review [Open WebUI Tether](https://github.com/open-webui/tether). The Open Terminal Desktop and Browser tabs described above use a separately configured Open Terminal connection. [Desktop 0.1.0 release notes](https://github.com/open-webui/desktop/releases/tag/v0.1.0)
- 📭 **File processing alerts removed.** Personal notifications in Settings > Notifications no longer offer "Retrieval Content process failed", so notification webhooks no longer receive an alert when a file fails to process. [Commit](https://github.com/open-webui/open-webui/commit/3814b7b2f152c671fd3789e5a0099313d5316467)
