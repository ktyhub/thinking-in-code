# open-webui v0.13.1

### Added

- 🦾 **Coding agents as models.** On an Open Terminal that offers agents, coding agents such as Claude Code, Codex and Pi now appear in the model picker. You can chat with them or call them by voice, choose their reasoning effort and service tier, and approve their tool requests in the chat. Each conversation uses one agent, and agent chats cannot be regenerated, continued or edited and resent. If an agent's terminal goes away, its chats and new chats fall back to the default model and earlier replies keep the agent's name. Autocompletion in agent chats uses the task model, or is skipped when there is none. [#33843](https://github.com/open-webui/open-webui/pull/33843), [#33860](https://github.com/open-webui/open-webui/pull/33860), [#33880](https://github.com/open-webui/open-webui/pull/33880), [#33857](https://github.com/open-webui/open-webui/pull/33857)
- 🪢 **Introducing Tether.** [Tether](https://github.com/open-webui/tether) is the new desktop companion app for macOS, Windows and Linux that ties your own computer to Open WebUI. Sign in once and your computer shows up under Your devices in the terminal menu, so models, coding agents and automations can work in your real files, repositories and tools, and you can reach them from any browser, including your phone. Tether connects out to Open WebUI, so there are no ports to open, its terminal output resumes after a dropped connection, and it delivers notifications to your desktop even when no Open WebUI page is open. It signs in with a renewable session that expires after 90 days without use by default, set with "SESSION_EXPIRES_IN".
- 💸 **Much cheaper tool chats.** Chats that use tools now cost much less. Citation instructions, memory recall, the skills list and attached knowledge are no longer rewritten into the system prompt or your message on every tool round, so the start of the conversation stays the same between requests and providers can serve it from their prompt cache. Custom pipes see a different message layout as a result; see Context as hidden tool results under Changed. [#33852](https://github.com/open-webui/open-webui/issues/33852)
- 🚦 **Auto tool permissions.** Administrators can now turn on Auto, a third tool permission mode next to Full access and Ask for approval (off by default). A review model checks each tool call and runs it right away only when it judges that no confirmation is needed. The review sends the tool, its arguments and your last few messages to the configured scoring API, and any call it cannot review, because of an error, a timeout or too much context, asks for approval.
- 📚 **Full text for small files.** Files whose extracted text is shorter than a new threshold (50,000 characters by default, set with "RAG_FULL_TEXT_CHAR_THRESHOLD" or in the admin Documents settings) are now included in full instead of through retrieval. This applies both when Preload files adds the content to the conversation and when the model reads an attached file with its file search tool, and the file viewer shows when it happens.
- ⏱️ **Faster large chats.** Large chats now open about twice as fast, and marking a chat as read or unread or removing a tag from it is 4 to 6 times faster. [#33665](https://github.com/open-webui/open-webui/pull/33665), [#33666](https://github.com/open-webui/open-webui/pull/33666)
- 🏎️ **Faster chat access checks.** Sending messages, typing indicators, shared links, comments and file access no longer load the whole conversation just to check who may access it, which helps most on large chats. [#33667](https://github.com/open-webui/open-webui/pull/33667), [#33669](https://github.com/open-webui/open-webui/pull/33669)
- 🔧 **More forgiving tool calls.** Tool calls with arguments wrapped in code fences, encoded twice or sent as text instead of numbers and booleans now run, and tool calls a model writes out as plain text markup are recognised and executed. [#33868](https://github.com/open-webui/open-webui/issues/33868)
- 🛑 **Tool loop stops.** A tool call that fails twice in a row with the same arguments now ends the tool loop so the model writes a final answer, and a reply cut off by the token limit no longer runs its unfinished tool calls.
- 🛠️ **Default tools for models.** The Model Defaults section in the admin Models settings now has a Tools picker, models without their own tool list start new chats with those tools enabled, and the new model form preselects them. [#33749](https://github.com/open-webui/open-webui/pull/33749), [#33787](https://github.com/open-webui/open-webui/pull/33787)
- 🚀 **Faster channels.** The channel list, the channel messages and the replied-to messages in a channel now load much faster, especially with many channels or many replies, and new database indexes speed up channel threads and reactions. [#33690](https://github.com/open-webui/open-webui/pull/33690), [#33691](https://github.com/open-webui/open-webui/pull/33691), [#33688](https://github.com/open-webui/open-webui/pull/33688)
- 🪶 **Lighter reasoning streams.** Long reasoning replies from providers such as OpenRouter now send far less data to the browser and to Redis while they stream. [#33698](https://github.com/open-webui/open-webui/pull/33698)
- 🗂️ **Faster sidebar chat list.** The chat list in the sidebar now appears as soon as its own data is ready instead of waiting for the channel list. [#33686](https://github.com/open-webui/open-webui/pull/33686)
- ⌨️ **Faster typing after large pastes.** Typing in the chat input after pasting 16,000 lines of text is now about 117 times faster, down from 8.6 seconds to 74 milliseconds per keystroke. [#33729](https://github.com/open-webui/open-webui/pull/33729), [#12087](https://github.com/open-webui/open-webui/issues/12087)
- 🧮 **Faster Redis filter lookups.** With Redis enabled, chat requests now look up the filters of a model faster. [#33668](https://github.com/open-webui/open-webui/pull/33668)
- 🪟 **Split tab panes.** On large screens, dragging a tab or a chat to the edge of the workspace, or pressing the new Split screen button, splits it into resizable panes, so several tabs, including the chat, stay visible side by side. Tabs can also be reordered and moved between panes with a long press and drag on touch screens. [Commit](https://github.com/open-webui/open-webui/commit/b5eaa59d0a5f85a85940bd2ec1afb4aa4ff21a80)
- 🧳 **Tabs remembered per chat.** The open tabs, split layout and selected terminal of each chat are now saved privately for each user on the server and restored when you reopen the chat, even on another device. Signing out warns you about unsaved file edits. [#33899](https://github.com/open-webui/open-webui/pull/33899), [#33885](https://github.com/open-webui/open-webui/pull/33885)
- 🪣 **Batched Tool Search calls.** With Tool Search on, the model can run several independent tools it found in a single call_tool request, which saves model turns and so lowers the cost of tool-heavy chats.
- 🧭 **Tool Search engines.** Tool Search in the admin Interface settings can now match tools with embeddings from the Documents embedding model (kept in memory, not stored) or by sending the query and tool definitions to a relevance-scoring API, besides the default keyword search.
- 🏷️ **Readable tool call labels.** Administrators can now turn on Tool Call Labels in Admin Settings > Interface or with "ENABLE_TOOL_CALL_LABELS", off by default, to ask the model for short descriptions in the user's language of what each tool call is doing and what it did. [Commit](https://github.com/open-webui/open-webui/commit/2416b1fc0b83571652e0efff83f9591c89b62a64)
- ✂️ **Chat read limit.** Admins can limit how much of an earlier chat the Chat History tools return, with "VIEW_CHAT_MAX_CHARS" or the new Chat Read Limit field in Admin Settings > General, and the newest messages are kept while older ones are cut. [#33695](https://github.com/open-webui/open-webui/pull/33695), [#33608](https://github.com/open-webui/open-webui/issues/33608)
- 🌍 **Client IP header placeholders.** Custom headers of connections can now use "{{USER_IP}}" and "{{X_FORWARDED_FOR}}" to pass the client address on to the upstream provider, and both are empty for automations and background jobs. [#33833](https://github.com/open-webui/open-webui/pull/33833), [#33819](https://github.com/open-webui/open-webui/issues/33819)
- ✉️ **Non-ASCII email addresses.** The sign-up page and the add and edit user dialogs now accept email addresses with non-ASCII characters. [#33693](https://github.com/open-webui/open-webui/pull/33693), [#33681](https://github.com/open-webui/open-webui/issues/33681)
- 🕒 **Reply finish time.** Assistant replies now show the time they finished instead of the time the prompt was sent. [#33895](https://github.com/open-webui/open-webui/pull/33895)
- 🧐 **Channel message search.** Each channel header has a Search button that searches the messages of that channel.
- 🔔 **Notifications open their chat.** Clicking a desktop notification now brings Open WebUI to the front and opens the related chat, channel or calendar.
- 📮 **MCP Apps message the chat.** An MCP App can now send a text message to the chat, which you confirm first in a Confirm Prompt from Embed dialog. [#33907](https://github.com/open-webui/open-webui/pull/33907)
- 🖱️ **Drag chats into side panel.** Dragging a chat from the sidebar onto the chat area opens it as a side chat tab, and a side chat can now also be started from an empty new chat.
- 🪄 **Quick open files.** A new shortcut, Cmd+P (Ctrl+P elsewhere), opens a search box that finds files in the selected terminal by name or path and opens the one you pick in a tab.
- 🎹 **Tab keyboard shortcuts.** New shortcuts, which can be changed in Settings > Keyboard, open the Files, Desktop, Comments, new chat, new file, new terminal and new browser tabs, close and switch between tabs and toggle the split screen.
- 🗺️ **Working directory picker.** The message input has a working directory menu with folder search, a Recently Used list kept per user on the terminal and an Open Folder dialog.
- 📂 **Folder default terminal.** A folder can now have a default terminal and working directory in its Advanced settings, used for new chats in that folder.
- 🧾 **Editable spreadsheets.** Excel files in the file view can now be edited in the preview, with a formula bar, pasting from other spreadsheets and resizable columns, and saved back to the file, while formula cells and protected sheets stay read-only.
- 🖋️ **Markdown and code editing.** Markdown files in the file view now open in a rich text editor that saves back to Markdown, where pasted or dropped images are uploaded to the terminal, and the code editor suggests words that already appear in the file. Other text files and the Source view of previews now use the code editor directly, without a separate Edit step. [Commit](https://github.com/open-webui/open-webui/commit/b5eaa59d0a5f85a85940bd2ec1afb4aa4ff21a80)
- 🌳 **Clone Git repositories.** The file browser and the folder pickers can now clone a Git repository from an HTTP(S) or SSH URL into the chosen folder of the selected terminal.
- 🧬 **Git changes in the editor.** The code editor now marks the lines of a file that were added or changed since the last commit.
- 🔖 **File browser Git status.** Files and folders in the file browser are marked with a Git status letter such as M, A, D or U, and folders show that they contain changes.
- 🌿 **Git panel feedback and resizing.** The Git panel now shows what it is doing, such as staging, pushing or fetching, and its file list can be resized.
- 🧹 **Discard any Git change.** The Git panel can now discard staged and new files too, and its confirmation warns that files not in the last commit are deleted and that this cannot be undone.
- 🧲 **Drag files into chat.** Files from the terminal file browser can be dragged, one or several at once, into the message input to attach them, also with a long press on touch screens.
- 🗃️ **Multiple Files tabs.** The + menu can now open several Files tabs for the same terminal, each with its own folder and the folder name as its tab title, and moving files refreshes the other Files tabs on that terminal. [Commit](https://github.com/open-webui/open-webui/commit/0b7e7b3f707023c626ae51cc66a4db1c19ed7056)
- 🔲 **Drag to select files.** Several files in the file browser can now be selected by dragging a selection box over them.
- 🪂 **Spring-loaded Files tabs.** Holding a dragged file over a Files tab for half a second switches to that tab, so files can be moved into folders of another tab.
- ⚡ **Faster terminal rendering.** The terminal tab now renders with WebGL where the browser supports it and takes in bursts of output in larger batches, so heavy output is handled faster.
- 🩺 **Terminal system info.** The terminal menu now has a System info view with the terminal's CPU, memory, disk, network, uptime and top processes.
- 🖌️ **Edit images from the terminal.** The image edit tool can now take source images from the selected terminal by file path, as PNG, JPEG, WebP or GIF up to 25 megapixels. [#33824](https://github.com/open-webui/open-webui/issues/33824)
- 🎙️ **Voice notes in files.** A new shortcut, Cmd+Alt+M (Ctrl+Alt+M elsewhere), records a voice note, can transcribe it, and saves the recording with a Markdown note in the current folder of the selected terminal, then opens the note in a tab. Escape cancels a recording. [#33902](https://github.com/open-webui/open-webui/pull/33902), [#33903](https://github.com/open-webui/open-webui/pull/33903)
- 📢 **Model availability events.** Open WebUI now publishes model.available and model.unavailable events when a model appears in or disappears from the fetched model list.
- 🗒️ **Descriptions in model pickers.** The tool, skill, filter, action and sub-agent pickers in the model editor now show each item's description under its name. [#33723](https://github.com/open-webui/open-webui/pull/33723)
- 🔢 **Grouped token counts.** Whole numbers in the token usage tooltip are now grouped by thousands for the interface language, for example 26,678,623. [#33896](https://github.com/open-webui/open-webui/pull/33896)
- 🎼 **Notification sound styles.** The notification sound setting now offers Chime, Soft, Bell and Tap sounds, with a play button to preview each one.
- 🔄 **General improvements.** Various improvements were implemented across the application to enhance performance, stability, and security.
- 🌐 **Translation updates.** Translations for Portuguese (Brazil), Azerbaijani, Basque, Bengali, Bosnian, Bulgarian, Cebuano, Croatian, Czech, Danish, Dutch, Estonian, Faroese, Filipino, Galician, Georgian, German, Greek, Hebrew, Hindi, Hungarian, Indonesian, Irish, Japanese, Kabyle, Korean, Lithuanian, Malay, Norwegian Bokmål, Persian, Polish, Punjabi, Romanian, Russian, Serbian, Slovak, Slovenian, Spanish (Spain), Swedish, Tamil, Thai, Tibetan, Turkish, Turkmen, Ukrainian, Urdu, Uyghur and Vietnamese were enhanced and expanded.

### Fixed

- 🛡️ **Security Advisory**: This release contains **security fixes**. We **strongly recommend updating** all deployments **as soon as possible** to have the latest security fixes in place. These fixes are **not listed in this changelog**; we will publish the security advisories for them immediately following CVE assignment. [Advisories](https://github.com/open-webui/open-webui/security)
- 🗄️ **Redis Cluster chats.** Sending a chat message on a Redis Cluster deployment no longer fails while the personal terminal relay starts. [#33766](https://github.com/open-webui/open-webui/pull/33766)
- 🚪 **Automatic SSO sign-in.** With automatic SSO redirect on, an expired session now signs you back in without a state mismatch error. [#33791](https://github.com/open-webui/open-webui/pull/33791), [#33783](https://github.com/open-webui/open-webui/issues/33783)
- 🎨 **OpenAI image default model.** Image generation with the OpenAI engine now defaults to GPT-IMAGE 2 instead of the shut-down DALL·E 2, and the shut-down DALL·E models are no longer offered. [#33694](https://github.com/open-webui/open-webui/pull/33694), [#33578](https://github.com/open-webui/open-webui/issues/33578)
- 🖼️ **Default GPT image requests.** OpenAI image generation and editing with no model explicitly set no longer send an unsupported response format to the default GPT image model. [#33875](https://github.com/open-webui/open-webui/pull/33875)
- 🔐 **Terminal Session authentication.** Terminal connections set to Session authentication now accept an API key, so Verify Connection, the policy settings and the terminal tools work again. [#33699](https://github.com/open-webui/open-webui/pull/33699), [#30001](https://github.com/open-webui/open-webui/issues/30001), [#33579](https://github.com/open-webui/open-webui/issues/33579)
- 🦙 **Ollama broken tool calls.** Chats with Ollama models no longer get stuck after a tool call with cut-off, rejected or empty arguments. [#33697](https://github.com/open-webui/open-webui/pull/33697), [#33671](https://github.com/open-webui/open-webui/issues/33671)
- 🧠 **Complete compaction summaries.** Context compaction summaries are no longer cut off at 1000 tokens, which could leave reasoning models with an empty or truncated summary. [#33726](https://github.com/open-webui/open-webui/pull/33726)
- 💾 **Prompt cache on tool results.** Tool results sent through OpenAI-compatible gateways now keep their prompt cache marker, so Anthropic models behind OpenRouter or LiteLLM can cache the prefix in tool loops. [#33757](https://github.com/open-webui/open-webui/pull/33757), [#33755](https://github.com/open-webui/open-webui/issues/33755)
- 📖 **File read size limit.** Reading a file by line range now stops at the same size limit as other reads, so one read can no longer overflow the context window of the model. [#33696](https://github.com/open-webui/open-webui/pull/33696), [#33607](https://github.com/open-webui/open-webui/issues/33607)
- 🧰 **Tool Search retries.** A malformed tool call with Tool Search on no longer disables tools for the rest of the reply, so the model can correct its arguments and try again. [#33872](https://github.com/open-webui/open-webui/pull/33872)
- 🧩 **Split tool calls.** When a model sends several tool calls glued into one, the chat no longer shows an extra tool call that never gets a result. [#33779](https://github.com/open-webui/open-webui/pull/33779), [#33778](https://github.com/open-webui/open-webui/issues/33778)
- 🔎 **External knowledge base queries.** External knowledge bases now search with every generated query at the same time instead of using only the results of the first one. [#33704](https://github.com/open-webui/open-webui/pull/33704), [#33184](https://github.com/open-webui/open-webui/issues/33184)
- 📊 **Large spreadsheet uploads.** Uploading a large, sparsely filled spreadsheet no longer takes minutes and stalls the server. [#33770](https://github.com/open-webui/open-webui/pull/33770), [#33768](https://github.com/open-webui/open-webui/issues/33768)
- 🧱 **Milvus knowledge base uploads.** Adding a file to a knowledge base on Milvus no longer processes the file a second time or stores its chunks twice. [#33745](https://github.com/open-webui/open-webui/pull/33745), [#33744](https://github.com/open-webui/open-webui/issues/33744)
- 📄 **MinerU 4.1 servers.** The MinerU document loader in local mode now works with MinerU 4.1 servers, where every document used to fail. [#33719](https://github.com/open-webui/open-webui/pull/33719), [#33718](https://github.com/open-webui/open-webui/issues/33718)
- 🔑 **MCP OAuth stays signed in.** The login to an MCP tool server that uses OAuth is no longer lost when the provider has a temporary outage while the token is refreshed. [#33805](https://github.com/open-webui/open-webui/pull/33805), [#33803](https://github.com/open-webui/open-webui/issues/33803)
- 📍 **Location lookup delays.** With location access turned on, sending a message no longer waits for a slow or unanswered browser location request.

Closing a channel thread, a note panel or a chat menu returns focus to where it was, and the sign-in skip link moves focus to the form. The show password button is now wide enough to hit, and holding Shift no longer swaps row buttons for Delete while a keyboard user has focus.

### Changed

- ⚠️ **Database Migrations**: This release includes database schema changes; we strongly recommend backing up your database and all associated data before upgrading in production environments. If you are running a multi-worker, multi-server, or load-balanced deployment, all instances must be updated simultaneously, rolling updates are not supported and will cause application failures due to schema incompatibility.
- 💥 **Preload files off by default.** With native function calling, the default, attached files are no longer added to the conversation automatically, and models read them with their file tools instead. Models without tool support or without the Files built-in tool can no longer see attached files until you turn on Preload files in the model's Capabilities. Legacy function calling, and API requests that do not come from a chat in the web UI, keep the old behavior. [#33815](https://github.com/open-webui/open-webui/pull/33815)
- 🎯 **Retrieval defaults.** Unless you saved your own values, "RAG_TOP_K" and "RAG_TOP_K_RERANKER" now default to 10 instead of 3, and "CHUNK_SIZE" to 1024 instead of 1000. Each query now retrieves more text, so prompts with knowledge get longer. The new chunk size applies to files processed from now on; existing knowledge keeps its chunks until it is reindexed.
- 🧷 **Context as hidden tool results.** With native function calling, memory recall, the skills list and the attached knowledge list now arrive as hidden tool results after your message instead of in the system prompt. This is what keeps tool chats cacheable, and it means custom pipes can see a tool message as the last message.
- 🗨️ **Side chats are saved.** Side chats, which were always temporary in 0.13.0, are now saved as regular chats and appear in the chat list. They stay temporary only when you turn on Temporary Chat in the side chat or your admin enforces temporary chats.
- 🚧 **Tool call limit.** Reaching the tool call limit now makes the model write a final answer without tools, instead of ending the reply with the "Tool-call limit reached" error.
- 🔦 **Tool Search prompt.** With Tool Search on, the model no longer sees a list of the hidden tools and finds them only by searching.
- ✏️ **Always Use Full Text.** The Full Context Mode setting in the admin Documents settings is now called Always Use Full Text and includes complete documents regardless of the full text threshold.
- ↔️ **Always full-width tabs.** On large screens the tabbed workspace now always fills the chat area, with the chat as one of its tabs, and the full-width toggle added in 0.13.0 is gone.
- 🔀 **Integrations moved into + menu.** The Integrations button is now part of the + menu in the message input, and the new Show Input Selections setting, off by default, controls whether selected tools, skills, filters and capabilities are shown beside it.
- 🔓 **Side chat permission.** The Allow Side Chat permission no longer requires the Temporary Chat permission.
- 🕸️ **Chrome first in Browser tab.** The Browser tab now starts in Chrome mode when the terminal offers it, and switches to Proxy mode with a message if Chrome fails to start.
- ⛔ **Terminal select setting removed.** The Show Files on Terminal Select setting has been removed from the Interface settings. [#33855](https://github.com/open-webui/open-webui/pull/33855), [#33840](https://github.com/open-webui/open-webui/issues/33840)
