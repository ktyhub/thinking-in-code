# spring-cloud-gateway v5.1.0-RC2

## What's Changed
* Update Antora UI bundle to v0.4.26 by @spring-builds in https://github.com/spring-cloud/spring-cloud-gateway/pull/4295

* Bump antora from 3.2.0 to 3.2.1 in /docs by @dependabot[bot] in https://github.com/spring-cloud/spring-cloud-gateway/pull/4312
