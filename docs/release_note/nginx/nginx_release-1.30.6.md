# nginx release-1.30.6

[nginx-1.30.6](https://nginx.org/en/download.html) stable version has been released, with fixes for [buffer overflow](https://nginx.org/en/security_advisories.html) vulnerability when using alias with rewrite (CVE-2026-15176), [buffer overflow](https://nginx.org/en/security_advisories.html) vulnerability when evaluating string expressions with variables (CVE-2026-93479), [request body injection](https://nginx.org/en/security_advisories.html) vulnerability in HTTP/3 (CVE-2026-95101), [session forgery](https://nginx.org/en/security_advisories.html) vulnerability when using TLS session ticket key rotation (CVE-2026-97629), and [use-after-free](https://nginx.org/en/security_advisories.html) vulnerability when using ngx_http_ssi_module with AIO (CVE-2026-97205).

See official [CHANGES-1.30](https://nginx.org/en/CHANGES-1.30) on nginx.org.
