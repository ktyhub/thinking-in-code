# nginx release-1.31.7

[nginx-1.31.7](https://nginx.org/en/download.html) mainline version has been [released](https://blog.nginx.org/blog/nginx-1-31-7-native-geoip2-support-http-2-priorities-and-quic-improvements), with fixes for [buffer overflow](https://nginx.org/en/security_advisories.html) vulnerability when using alias with rewrite (CVE-2026-15176), [buffer overflow](https://nginx.org/en/security_advisories.html) vulnerability when evaluating string expressions with variables (CVE-2026-93479), [request body injection](https://nginx.org/en/security_advisories.html) vulnerability in HTTP/3 (CVE-2026-95101), [session forgery](https://nginx.org/en/security_advisories.html) vulnerability when using TLS session ticket key rotation (CVE-2026-97629), and [use-after-free](https://nginx.org/en/security_advisories.html) vulnerability when using ngx_http_ssi_module with AIO (CVE-2026-97205).

See official [CHANGES](https://nginx.org/en/CHANGES) on nginx.org.
