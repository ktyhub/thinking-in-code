# orca v1.4.253

## A little update ✨

We released two updates today! Check out the [v1.4.252 release notes](https://github.com/stablyai/orca/releases/tag/v1.4.252) for chat forking and Plan mode, a smoother phone experience, and workspace organization across machines.

A small release with a few minor improvements. A bigger one is coming later 🫣

## What's changed

* Reduce repeated work during host-status updates by @nwparker in https://github.com/stablyai/orca/pull/39340
* Reduce process launches when reading Linux process start times by @OrcaWin in https://github.com/stablyai/orca/pull/39439
* Dim the chat message rail until hover, focus or scroll by @nwparker in https://github.com/stablyai/orca/pull/39369
