# MaxKB v1.10.15-lts

### Bug Fixes
- **Security Vulnerability**: Fixed flaws in permission verification to block a high-risk privilege escalation vulnerability where anonymous application session tokens could be exploited to obtain the administrator's system API Key.
- **Knowledge Base**: Fixed garbled paragraph content when uploading PDF files where the title text is identical to the body content.
