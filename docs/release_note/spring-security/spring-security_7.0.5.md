# spring-security 7.0.5

## :star: New Features

- Add XML Based shouldWriteHeadersEagerly tests [#19018](https://github.com/spring-projects/spring-security/pull/19018)
- Merge Add CredentialRecordOwnerAuthorizationManager [#19005](https://github.com/spring-projects/spring-security/pull/19005)

## :beetle: Bug Fixes

- Add equals and hashcode to HttpMethodRequestMatcher [#18963](https://github.com/spring-projects/spring-security/issues/18963)
- auth\_time claim doesn't show the time of the original authentication [#18282](https://github.com/spring-projects/spring-security/issues/18282)
- auth\_time validation fails when SSO session is renewed [#18978](https://github.com/spring-projects/spring-security/issues/18978)
- Fallback defaultTargetUrl if refererHeader is empty [#18981](https://github.com/spring-projects/spring-security/issues/18981)
- Fix HttpSessionRequestCache#getMatchingRequest query string parsing [#18972](https://github.com/spring-projects/spring-security/issues/18972)
- Merge Handle null value in OnCommittedResponseWrapper header methods [#18990](https://github.com/spring-projects/spring-security/pull/18990)
- OAuth2 client sessionManagement ineffective with DefaultOidcUser [#19022](https://github.com/spring-projects/spring-security/issues/19022)
