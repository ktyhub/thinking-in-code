# druid druid-30.0.1

The Apache Druid team is proud to announce the release of Apache Druid 30.0.1. 
Druid is a high performance analytics data store for event-driven data.

Apache Druid 30.0.1 contains security fixes for [CVE-2024-45384](https://www.cve.org/CVERecord?id=CVE-2024-45384), [CVE-2024-45537](https://www.cve.org/CVERecord?id=CVE-2024-45537).
The release also contains minor doc and task monitor fixes.

Source and binary distributions can be downloaded from:
https://druid.apache.org/downloads.html

**Full Changelog**: https://github.com/apache/druid/compare/druid-30.0.0...druid-30.0.1
