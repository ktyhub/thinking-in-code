# Open-Generative-AI v2.0.0

## What's New in v2.0.0

### New Features
- **Audio Studio** — dedicated audio generation tab
- **Vibe Motion** — new motion effect capability
- **Clipping Tab** — video clipping workflow
- **Design Agent** — AI-powered design assistant integration
- **EN/ZH Language Switcher** — internationalization across all studio components
- **Interactive Command Generator Playground** — MCP CLI studio improvement
- **Custom Local-AI Storage Directory** — choose where local models are stored

### Fixes & Improvements
- **Wan2GP:** keep default endpoints available without metadata; endpoint fallback support
- **Studio:** re-prompt for API key on 401/403 responses and harden header visibility
- **Models:** correct Z-Image Base download URL filename casing
- **McpCliStudio:** remove duplicated helpers and orphan code that broke Vite build
- **Local-AI:** include model name and ID in download error messages
- **Linux:** bundled local inference packaging for Linux builds
- **Workflow/Design Agent:** updated UI components and Tailwind/jsconfig paths
