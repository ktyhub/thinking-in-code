# Open-Generative-AI v1.0.11

## Fix

- **Video Studio:** the end-frame picker (for FLF image-to-video models like kling / veo / seedance) no longer triggers the API-key modal when a Wan2GP local model is selected. It now mirrors the start-frame picker's local-aware gating — routing uploads through Wan2GP and bypassing the auth prompt for local models.
