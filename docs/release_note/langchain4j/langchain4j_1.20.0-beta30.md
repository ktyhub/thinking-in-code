# langchain4j 1.20.0-beta30

## Notable Changes
* Reactor support for the non-blocking AI Service modes, and Spring's executor for offloaded work by @dliubarskyi in https://github.com/langchain4j/langchain4j-spring/pull/211

## Other Changes
* Test starters with stubbed providers instead of real APIs by @dliubarskyi in https://github.com/langchain4j/langchain4j-spring/pull/204
* Test every property of the OpenAI starters, and fix what that uncovered by @dliubarskyi in https://github.com/langchain4j/langchain4j-spring/pull/206
* Test every property of the Anthropic starters, and fix what that uncovered by @dliubarskyi in https://github.com/langchain4j/langchain4j-spring/pull/207
* Report which HTTP client failed, and never throw an exception with no message by @dliubarskyi in https://github.com/langchain4j/langchain4j-spring/pull/208
* Fix nightly build by @dliubarskyi in https://github.com/langchain4j/langchain4j-spring/pull/209
* Remove GitHub Models Spring Boot starters by @dliubarskyi in https://github.com/langchain4j/langchain4j-spring/pull/210
