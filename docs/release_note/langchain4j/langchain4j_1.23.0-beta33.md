# langchain4j 1.23.0-beta33

## What's Changed
* Update wiremock.version to v3.13.2 by @renovate[bot] in https://github.com/langchain4j/langchain4j-spring/pull/229
* Update tinylog.version to v2.8.1 by @renovate[bot] in https://github.com/langchain4j/langchain4j-spring/pull/227
* Clarify @AiService placeholders: Javadoc, error message and tests by @dliubarskyi in https://github.com/langchain4j/langchain4j-spring/pull/235
* Use the Spring task executor for offloaded work on Spring Boot 4 too by @dliubarskyi in https://github.com/langchain4j/langchain4j-spring/pull/237
* Support non-blocking AI Service calls with the Spring Boot starters by @dliubarskyi in https://github.com/langchain4j/langchain4j-spring/pull/236
* Update actions/upload-artifact action to v7 by @renovate[bot] in https://github.com/langchain4j/langchain4j-spring/pull/233
* Update spring boot by @renovate[bot] in https://github.com/langchain4j/langchain4j-spring/pull/226
* Add Azure DocumentDB Spring Boot 3 and 4 starters, deprecate the Cosmos DB Mongo vCore starters by @SandraAhlgrimm in https://github.com/langchain4j/langchain4j-spring/pull/218
* SpringRestClient: use HTTP/1.1 for plain http:// URLs when the JDK client is detected by @dliubarskyi in https://github.com/langchain4j/langchain4j-spring/pull/239
* Apply Spring Boot's HTTP client settings in the Spring Boot starters by @dliubarskyi in https://github.com/langchain4j/langchain4j-spring/pull/242
* Log configured bean references when registering @AiService beans by @Marisha-Sahay in https://github.com/langchain4j/langchain4j-spring/pull/225
* Update dependency co.elastic.clients:elasticsearch-java to v8.19.23 by @renovate[bot] in https://github.com/langchain4j/langchain4j-spring/pull/223
* Update dependency org.sonatype.central:central-publishing-maven-plugin to v0.12.0 by @renovate[bot] in https://github.com/langchain4j/langchain4j-spring/pull/244
