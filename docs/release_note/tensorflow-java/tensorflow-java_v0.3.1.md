# tensorflow-java v0.3.1

*Note: TensorFlow Java is still in alpha release and is not covered by [TensorFlow API stability guarantees](https://www.tensorflow.org/guide/versions)*

## Bug Fixes and Other Changes

* Fix memory leaks occurring with new TensorFlow 2.4.1 layout of string tensors 
* Fix and use JavaCPP deallocator for releasing graph sessions
