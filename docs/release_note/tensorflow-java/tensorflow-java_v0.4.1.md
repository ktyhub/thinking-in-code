# tensorflow-java v0.4.1

*[TensorFlow Java](https://github.com/tensorflow/java) is still only available as an alpha release and is not covered by the [TensorFlow API stability guarantees](https://www.tensorflow.org/guide/versions)*

## Bug Fixes and Other Changes

* Upgrade to TensorFlow 2.7.1 with CVE fixes (https://github.com/tensorflow/java/pull/412)
* Bumping to protobuf 3.19.4, error-prone 2.10.0 (https://github.com/tensorflow/java/pull/412)
* Fix NullPointerException issue. (https://github.com/tensorflow/java/pull/407)
