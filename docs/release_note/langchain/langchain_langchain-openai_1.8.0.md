# langchain langchain-openai==1.8.0

**`langchain-openai` 1.8.0 drops support for Python 3.10**, which has reached end-of-life. The minimum supported version is now Python 3.11, and the minimum `langchain-core` version is now 1.8.0. Users on Python 3.10 will continue to resolve `langchain-openai` 1.7.x.

Changes since langchain-openai==1.7.4

release(openai): 1.8.0 (#41841)
feat(openai): add OpenAIClassifier for the GA Decisions API (#41787)
chore(model-profiles): refresh model profile data (#41828)
feat(partners): Remove EOL'd Python 3.10 from partner packages (#41268)
