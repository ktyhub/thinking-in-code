# langchain langchain==1.5.0

**`langchain` 1.5.0 drops support for Python 3.10**, which has reached end-of-life. The minimum supported version is now Python 3.11, and the minimum `langchain-core` version is now 1.8.0. Users on Python 3.10 will continue to resolve `langchain` 1.4.x.

Changes since langchain==1.4.10

release(langchain): 1.5.0 (#41798)
fix(langchain): mark `ModelRouterMiddleware` as beta (#41797)
feat(langchain): Remove EOL'd Python 3.10 from langchain_v1 (#41301)
feat(langchain): add model router and auto mode middleware (#41766)
docs(langchain): explain Baseten minimum version (#41777)
