# spring-ai-alibaba v1.1.0.0

The official Spring AI Alibaba release that built on [Spring AI 1.1.0](https://github.com/spring-projects/spring-ai/releases/tag/v1.1.0) and [Spring AI Alibaba Extensions 1.1.0.0](https://github.com/spring-ai-alibaba/spring-ai-extensions/releases/tag/v1.1.0.0).

Please check the <a href="https://java2ai.com/docs/overview" target="_blank">documentation</a> on our website for usage and upgrade guide. 

> Please submit issues and follow the updates on the official website. We will try our best to keep the documentation up to date in the next few weeks.
