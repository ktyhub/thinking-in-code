# spring-ai-alibaba v2.0.0-M1.1

## Highlights

Milestone release upgrading to **Spring AI 2.0.0-M1** and **Spring Boot 4.0.0**.

## Dependency Upgrade

- Spring AI: 1.1.2 → 2.0.0-M1
- Spring AI Alibaba Extensions → 2.0.0-M1.1
- Spring Boot: 3.5.8 → 4.0.0
- Redisson: 3.22.0 → 3.52.0
- Removed explicit driver dependency versions for MySQL, PostgreSQL, and Oracle (now managed by Spring Boot BOM)
